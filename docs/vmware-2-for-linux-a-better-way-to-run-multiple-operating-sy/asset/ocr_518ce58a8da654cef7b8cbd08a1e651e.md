# Conclusion

Based on circumstantial evidence (such as the fact that you bought this book!), I might conclude that you prefer Linux's high-power workstation and server capabilities to those of Windows NT. But VMware makes it easy to make that choice almost irrelevant, giving you the flexibility of both Linux and Windows NT simultaneously on your PC.

You can happily run Windows NT in VMware without delving into some of the more esoteric regions of NT configuration, while keeping Linux's familiar reliability in the wings as well.
