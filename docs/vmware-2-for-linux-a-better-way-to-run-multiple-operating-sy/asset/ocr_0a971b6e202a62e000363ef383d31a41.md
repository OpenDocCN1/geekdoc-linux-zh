> VMware recommends the Mitsumi driver, but if for whatever reason you are dissatisfied with the Mitsumi driver, you can use a wide range of ATAPI-compliant CD-ROM drivers for DOS, including the OAKCDROM.SYS driver included with Windows 95/98. Be warned, though, that some work worse than others with VMware, so if you pass on the recommended Mitsumi driver be prepared to experiment a bit.
