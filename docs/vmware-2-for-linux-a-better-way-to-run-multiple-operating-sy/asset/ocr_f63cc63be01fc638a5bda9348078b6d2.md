# Using a Windows 2000 Virtual Machine

Although Windows 2000 is relatively new, if you have more than a vague familiarity with Windows 95/98, you should feel at home with the basic point-and-click functionality. At the same time, a little experience with Windows NT will give you the necessary background to understand the system administration tools, many of which are a little easier to handle in Windows 2000. And of course, there are already several reference guides that can provide more detailed information.

Although you can expect the same robust, transparent emulation experience VMware provides for other operating systems, you might experience sound card trouble in Windows 2000. VMware, Inc. claims that its Windows 2000 driver should work as well as any other, but in my experience, the sound driver sometimes freezes the virtual machine (but not the rest of Linux). I recommend disabling the Windows 2000 startup sound in the Sounds and Multimedia control panel because that seems to be the most frequent culprit.
