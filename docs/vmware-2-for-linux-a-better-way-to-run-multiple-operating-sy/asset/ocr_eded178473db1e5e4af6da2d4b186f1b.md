# Saving Changes in the Exit BIOS Screen

When you have finished tinkering, you need to decide whether to commit to your changes. The screen is shown in Figure A.16:

+   - Exit Saving Changes—The option to use when you are satisfied with your BIOS adjustments and want to continue booting your virtual machine.
+   - Exit Discarding Changes—Reboots the virtual machine without saving any of the adjustments you made since entering setup. Use this option when you don't want to make any changes—even if you don't think you've made any. It is considerably safer, on the off chance you accidentally changed an important setting.
+   - Load Setup Defaults—If your configuration is completely out of control, you might try this. If you follow the guidance in this appendix, your BIOS is unlikely to ever need this dramatic measure.
+   - Discard Changes—Restores the BIOS to the state it was in when you first entered setup. Use this if you do want to make changes but have made a mistake and want a fresh start.
+   - Save Changes—Saves the current BIOS settings and allows you to continue editing. Essentially a "save your work" option.
