It's not for everyone. But if you're a Linux power user, or you aspire to be but don't want to worry about causing massive damage in the process, it can be useful to have a second, simultaneous Linux environment on your computer.

# Carbon-Copy Your Desktop

Although it might not seem like the most adventurous option, you can turn a Linux virtual machine into an exact duplicate of your host computer. If you are experimenting with new software or are a developer, it might be useful to have a controlled environment that closely resembles your normal Linux system.

> A nearly identical Linux virtual machine with a nonpersistent or undoable virtual disk makes a terrific place to test new Linux kernel patches, revisions, or hacks. You get to see the results without threatening the integrity of your core system or having to muddle around with creating a backup kernel, a new entry in LILO, and so forth.

Depending on how precise you want the duplicate to be, you could simply install the same Linux distribution and software in your virtual machine or create a backup (or a very large .tar archive) of your host system and extract it to a VMware-compatible virtual, raw, or plain disk.

Because VMware emulates hardware rather than give Linux (or any other guest OS) direct access, you cannot make a VMware session match the exact behavior of your host OS. Obviously, VMware makes a poor environment to test hardware device drivers, but it is an exceptionally good software test bed.

> You cannot, nor would you ever want to, boot your virtual machine from your host Linux partition. In fact, extremely bad things happen if any virtual machine tries to directly (that is, not through a host or bridged networking protocol) access a host's physical hard drive while it is in use by the host OS.

# Expand Your Horizons

If you're not a highly technical type, probably the best reason to run Linux in VMware is to experiment with new or different distributions from the one you currently use on your computer. Advocacy in the Linux community over which distribution is best can get even more violent and difficult to decipher than arguments over which operating system is superior. How better to judge between distributions than to run them side-by-side?
