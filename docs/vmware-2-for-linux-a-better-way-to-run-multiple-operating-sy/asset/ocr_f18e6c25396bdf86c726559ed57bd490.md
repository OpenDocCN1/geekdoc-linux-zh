# Adjusting the Power BIOS Screen

The Power BIOS screen is best left alone. If you want to use APM in conjunction with the virtual machine suspend option, you might want to turn on Power Savings. Because you don’t actually save any power in the bargain (your Linux PC will still be running as hot as before), it’s usually not worth the trouble.

Advanced Options allow you to tweak the system IRQ settings, but IRQ conflict is not a problem with most conceivable virtual machine configurations.

# Adjusting the Boot BIOS Screen

More useful than it might seem at first, the Boot BIOS screen (shown in Figure A.15) lets you control the order in which the virtual machine will poll attached devices for a bootable drive.

Use the Enter key to expand device trees (indicated by +), and use the + and – keys to move devices up and down; you can also move devices within a tree up and down within their mini-hierarchy.

I recommend the order in Figure A.15: floppy (Removable Devices), CD-ROM, Hard Drive, Network Boot. Within Hard Drive, PM indicates the Primary Master drive on the virtual IDE chain, and SM indicates the Secondary Master on the virtual IDE chain. If you want to boot from your secondary master disk, you should move the SM entry above PM.
