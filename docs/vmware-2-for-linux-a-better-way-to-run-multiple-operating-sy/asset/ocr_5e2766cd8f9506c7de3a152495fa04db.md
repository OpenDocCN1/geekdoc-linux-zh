+   8. The Window Refresh Rate controls how often the MacOS screen is updated. Lower values indicate less frequent updates, which can make the screen look jerky but can result in faster overall emulation performance. Unless you have a slow machine, start with 60Hz or 30Hz, and lower the value only if Basilisk II seems to be running too slowly.

+   9. If sound is installed on your system, you should be able to leave Disable Sound Output unchecked, but it might be wise to turn off audio on a slow PC.

+   10. The Serial/Network tab should automatically configure Basilisk II to point at your available serial ports. Ethernet configuration is an advanced topic that requires a considerable amount of extra work.

+   11. The Memory/Misc tab (see Figure 17.11) controls the gritty details of the emulator. Your first order of business is to type the path and name of the Macintosh ROM you acquired into the ROM File field.

+   12. Set the MacOS RAM using the included slider. As a rule of thumb, use at least 8MB for System 7.0 or 7.1, at least 16MB for System 7.5 or 7.6, and at least 32MB for System 8 or 8.1. Because your PC can run VMware, you should have this much to spare.
