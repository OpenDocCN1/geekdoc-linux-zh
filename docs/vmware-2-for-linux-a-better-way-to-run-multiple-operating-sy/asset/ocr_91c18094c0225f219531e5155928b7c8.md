In this case, go back to the console (Ctrl+Alt+F1 or Ctrl+Alt+F2 should do it), log in, and type killall wine. Wine should exit taking its sickly program along with it, leaving your X session unharmed. Pressing Alt+F7 will take you back to XWindows on most systems.

Wine dates back to 1993, when Windows 3.1 was the norm. Although its feature set has expanded to include the new features and functionality of Windows 95/98 as well as their look and feel, some legacies of 3.1 remain. For instance, minimizing a Wine application creates a small icon on your desktop even if you use a window manager that treats minimized programs differently (such as in a Windows 95-style taskbar at the bottom of the screen).



Given the healthy amount of warnings and uncertainty I've given you about Wine, it might not sound all that enticing. I merely want to prepare you for the fact that although it offers a great deal of promise, at present it should be reserved for special, non-essential tasks.

Wine's development future actually looks quite bright. Many of the advances Corel had to make to port WordPerfect Office have not yet been incorporated into the Wine source code, but when they are, it should open new possibilities both for Wine developers and end users.

For now, consider Wine your Windows compatibility flyswatter: If you only have a small pesky problem to deal with, such as searching for alien life as shown in Figure 16.8, you might not always need to bring the VMware sledgehammer to bear.
