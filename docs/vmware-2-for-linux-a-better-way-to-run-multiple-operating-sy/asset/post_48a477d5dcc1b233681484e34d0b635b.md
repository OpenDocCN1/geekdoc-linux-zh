
## Installing and Configuring Windows 3.1

There is very little difference between a Windows 3.1 and Windows for Workgroups (3.11) installation, so I make no special mention of the differences except the obvious extra network configuration step in Windows for Workgroups:

- 1. Start with a fresh reboot of the DOS virtual machine you just prepared for Windows 3.1.

- 2. If you are installing Windows from floppies, remove any CD-ROMs from the drive. Windows scans all attached drives for Windows-compatible programs and creates program groups and icons for programs on your CD, which in most cases is a bad idea.

- 3. Start the Windows 3.1 installation by typing setup at the appropriate drive prompt. The Microsoft "blue screen" installer appears, as seen in Figure 14.19.

![](img/b2b6702758c230ce537468351fc8af15_310_0.png)

Figure 14.19 Windows 3.1 installation starts with a text screen.

- 4. Press Enter to start the installation. When prompted, you can safely select an Express Setup unless you specifically know you want to avoid installing certain Windows components.

- 5. Windows 3.1 scans the virtual machine for hardware (not especially well) and then copies files to the virtual disk (see Figure 14.20).

- 6. Soon after, the Windows graphical environment will load, and your mouse pointer should work. If you are installing Windows for Workgroups, Windows tries (and fails) to identify your network card. When asked to enter your name, organization, and serial number as shown in Figure 14.21, follow the prompts and click Continue.

Figure 14.20

![](img/b2b6702758c230ce537468351fc8af15_311_1.png)

Figure 14.21

- 7. Windows installs various system components (or asks you to select which you want to install if you requested a Custom installation).

- 8. After the wave of copying, Windows asks you to install a printer. If you have a printer configured in Linux and have the parallel port active, select the printer from the list.

> Because the 3.1 printer drivers date back to 1992 or 1993, don’t be too surprised if you can’t find your printer listed. You’ll have to track down a Windows 3.1 driver from the manufacturer and install it later if that’s the case.

- 9. If you are using Windows for Workgroups, you are asked to configure the network. When the Network Setup window appears (see Figure 14.22), click Networks to bring up the detailed configuration screen.

> Remember, this section configures a host-only style virtual network adapter. If you want bridged networking, you need Trumpet WinSock. Windows 3.11 does not come with TCP/IP networking.

![](img/b2b6702758c230ce537468351fc8af15_312_0.png)

Figure 14.22 Windows 3.11 allows you to configure a network adapter.

- 10. Click Install Microsoft Windows Network. If you want to enable old-style Novell, Banyan, or Sun networking, you can use the additional network prompt to add the protocol. Click OK when finished.

- 11. Click the Advanced button on the main Network Setup window.

- 12. As you see in Figure 14.23, the Network Drivers window is blank because Windows 3.11 does not have the AMD driver you need. Click the Drivers button.

- 13. Click Add Adapter. The window shown in Figure 14.24 appears. Select Unlisted or Updated Network Adapter, and click OK.

- 14. Windows prompts you to enter the directory that contains the driver. Point it to C:\amd31 (or wherever you placed the AMD NDIS2/NDIS3 driver) and click OK.

- 15. A new entry for an Advanced Micro Devices PCNET Family card appears. Click OK.

![](img/b2b6702758c230ce537468351fc8af15_313_0.png)

Figure 14.23 Windows 3.11 lacks the necessary driver to support the virtual Ethernet card.

![](img/b2b6702758c230ce537468351fc8af15_313_1.png)

Figure 14.24

- 16. Windows configures NetBEUI and IPX/SPX networking by default (see Figure 14.25). You can change these settings to suit your LAN, or click Close to accept the setup.

- 17. To complete the network setup, you are asked to enter a username and workgroup. Make sure these entries match a username permitted to access the host VMware Samba server and that the workgroup matches the Samba server settings (WORKGROUP by default).
