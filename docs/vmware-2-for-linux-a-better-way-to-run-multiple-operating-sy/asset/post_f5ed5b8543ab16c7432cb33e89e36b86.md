
1. If you're not already in VMware, start the main program by typing /usr/bin/vmware at a command prompt.
2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
3. Click Next to clear the first greeting screen.
4. Highlight MS-DOS from the list of guest operating system choices, and then click Next to proceed.
5. Enter a path to the new directory that will house the VMware configuration files as well as the virtual disk. By default, VMware asks to create a new directory called /vmware/dos in the current user's home directory.
6. VMware now asks whether you want to create a new virtual disk or use an existing physical disk. Click Next.

> You would be extremely hard-pressed to fill up more than 2GB with DOS programs, so it's probably best to stick with virtual disks.

7. Enter a size for the new virtual disk. Although 2,000MB is the default, you can go as high as 2,047MB. Remember that the disk grows as data is added, but you cannot change its maximum size later. Click Next to proceed.

> Remember that DOS itself is very small, as are most DOS utilities and games. You might be able to get by with just a few hundred megabytes, as shown in Figure 14.1.

![](img/b2b6702758c230ce537468351fc8af15_290_0.png)

Figure 14.1 DOS virtual machines do not always need huge virtual disks.

8. VMware should detect your CD-ROM. Leave the default settings as is (to enable CD-ROM access and make it available when the virtual machine boots), and click Next.

9. VMware now asks about floppy access. Unless you have a compelling reason to disable the floppy, leave this setting alone as well. Click Next.

10. The wizard asks how the virtual machine should be able to access the network. Because of certain limitations of networking in DOS, not all of the usual guidelines apply. If you want to try file sharing between the host and guest, use host-only networking. If you have a LAN, a DOS machine can participate in some fashion, so enable bridged networking. Attempting to use both can prove difficult and is not covered here.

> Networking from DOS is substantially more difficult than from any other operating system, because unlike Windows 95 and beyond, Linux, and FreeBSD, it was not really designed for networked environments. This chapter covers some of the basics and refers you to other, more definitive sources for networking in DOS.

11. The wizard summarizes the virtual machine it will create. An example is shown in Figure 14.2. If everything looks appropriate, click Done.

## Adjustments with the Configuration Editor

You should verify that the wizard has created everything to your satisfaction in the Configuration Editor before starting the installation:

1. Open the Configuration Editor in the Settings menu.
2. Verify that the wizard created a Primary Master (P-M) IDE virtual disk in the DOS configuration directory of the size you created (it might appear to be one megabyte less than you specified) and a Secondary Master (S-M) CD-ROM, most likely pointing to /dev/cdrom.

> Using CD-ROM drives on the virtual SCSI controller in DOS should be considered an advanced project, only for the extremely curious. You need to research the SCSI driver at http://www.mylex.com/support/download/manuals/scsistd.html. Virtual hard drives can, however, be used on the SCSI controller in DOS.

3. If you want the virtual machine to have direct access to your serial or parallel ports, configure them now as described in Chapter 5, “Running VMware for the First Time.” Remember that serial ports start at /dev/ttyS0, and parallel ports start at /dev/lp0 on most Linux machines.
4. If your Linux PC has sound configured and running and you want the virtual machine to have sound access, click the Sound option and then click Install in the sound configuration window.
5. VMware recommends 16MB of RAM for DOS, which is perfectly ample for most DOS applications and should not need to be changed.
6. Turn on APM support. It will come in handy later, even though DOS itself doesn’t make much use of power management. You can change the rest of the settings according to your personal preferences.
7. Click Save when finished in the Configuration Editor.

## Installing DOS in VMware

One of your choices is MS-DOS 6.22, the last release of the operating system that put Microsoft on the map. Although not readily available for sale, if you don’t already have a copy, you should be able to scourge one up quite easily.

Another option is Lines’s DR DOS 7, currently available for sale from http://www.drdos.com. You can also download a disk image for evaluation that runs inside the DOSEMU emulator.
