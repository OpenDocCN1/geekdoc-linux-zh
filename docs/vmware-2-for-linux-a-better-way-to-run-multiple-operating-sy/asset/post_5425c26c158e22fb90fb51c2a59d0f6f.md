
## Installing Windows 2000 Server

Let's shake things up a bit and cover the more complicated OS install first. In the next section, I detail the streamlined portions of the Windows 2000 Professional installation:

> Windows 2000 is a "young" operating system that Microsoft is aggressively patching. If things appear to be drastically different from what's outlined here, consult with a Windows 2000 authority for help.

- 1. If you're not running VMware already, start it by typing /usr/bin/vmware and select your Windows 2000 configuration when prompted, as shown in Figure 12.6.

![](img/b2b6702758c230ce537468351fc8af15_252_0.png)

Figure 12.6 Load your Windows 2000 configuration after starting VMware.

- 2. Insert the Windows 2000 Server, and power on the virtual machine.

> After you start the power to the virtual machine, activate full-screen mode. The Windows 2000 installation is fairly graphical, and graphics render faster in full-screen mode.

- 3. The initial, text-based installation program (see Figure 12.7) scans its own files for device drivers and OS modules and pre-loads the most useful portions. When it finishes, press Enter to start the installation.

![](img/b2b6702758c230ce537468351fc8af15_253_0.png)

Figure 12.7 The early stages of a Windows 2000 installation use a text screen.

- 4. Setup can't find any data on your virtual disk, so it assumes it is new or blank (right the first time!), so you don't need to worry about the warning about destroyed data. Press C to continue.

- 5. You are prompted to read and accept the Microsoft end-user license agreement. Read it, and then press F8 to accept.

- 6. Using a text-based interface, you can partition and configure your virtual drive. By default, setup creates one large partition on your virtual disk, as shown in Figure 12.8, which is a good configuration unless you have a special need. Press Enter on the partition you want to use for Windows 2000.

- 7. You can choose between the NTFS and FAT file systems. It is difficult to imagine a scenario where FAT would be useful (normally, NT/2000 partitions are formatted as FAT only if they need to be directly mounted by DOS, Windows 3.1, or early Windows 95 operating systems without using a network). Stick with NTFS.

- 8. Setup formats the virtual disk, and then starts copying pre-installation files to the drive. (This step takes quite a long time.) After the copying is complete, the virtual machine reboots and starts the graphical portion of the installation, displayed in Figure 12.9. (Don't remove the CD-ROM from the drive.)

- 9. More waiting ensues as setup uncompresses and sorts through various system files. Eventually, you are asked to click Next. (If you've wandered off, it proceeds by itself after a short wait.) Windows 2000 tries to detect all of your system hardware...which also requires waiting.

![](img/b2b6702758c230ce537468351fc8af15_254_0.png)

Figure 12.8 Windows 2000 automatically suggests using one large partition on your virtual disk.

![](img/b2b6702758c230ce537468351fc8af15_254_1.png)

Figure 12.9

Resist the urge to do a lot of multitasking on the Linux host while the installation drags on. You'll only make it take even longer.

- 10. After the hardware recognition phase, you are asked to localize Windows 2000, which should default to the settings of whatever country or territory you bought the software in. If you need to make these changes, click the appropriate Customize button and follow the prompts. If not, click Next to continue the main installation.

- 11. Enter your name and organization, and click Next. Setup prompts for your license code. Enter it, and then click Next to continue.

- 12. Setup asks which licensing mode you want to implement. This decision is between you and your IT support staff. The decision has no bearing on how VMware functions, only how Windows 2000 Server can support Windows-based clients.

- 13. Setup asks you to define a computer name (choose anything as long as it’s not already in use by another virtual machine) and then to define an administrator password. Enter one and click Next.

- 14. You can select which Windows 2000 Server components should be installed and activated. Don’t rush through this step; an awful lot of functionality is left unselected by default that you might want to use right out of the box. In particular, pay attention to the Internet Information Services (IIS) section, shown in Figure 12.10, which leaves the FTP server unchecked by default. If you want to activate the FTP server, click the IIS entry, click the Details button, and then check the FTP Server option. You might want to do the same for selections in Networking Services, Windows Media Services, or other areas.

- 15. Windows 2000 asks you to set the day and time and time zone. The day and time should be read accurately from your Linux system clock.

![](img/b2b6702758c230ce537468351fc8af15_255_0.png)

Figure 12.10 Enable the IIS FTP server if you want to share files between the host and the virtual machine using a Linux FTP client.
