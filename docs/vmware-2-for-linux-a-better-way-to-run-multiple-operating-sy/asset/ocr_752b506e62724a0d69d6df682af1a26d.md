If Windows 95 and 98 are just too "light" for your Windows application needs, you might consider NT 4. Now supplanted by Windows 2000, it remains a valid choice for people who need a robust, protected operating system but don't have the kind of money to outfit their systems properly for Windows 2000.

Some of the hype surrounding Windows NT 4 intimidates people, but it's really not that difficult to install and run. To be sure, if you plan to run mission-critical servers on your Windows NT guest, I highly recommend picking up at least one Windows NT administration guide. But for a basic workstation or even server configuration, your intuition and this chapter are enough to put you on the right track.

Even if you're an NT whiz, you might be surprised at how well NT works in VMware. Because of the streamlined virtual hardware environment, this might be the fastest and most painless Windows NT installation you'll ever do.

# Preparing the Virtual Machine

Any good VMware guest OS installation begins with the Configuration Wizard.

# Starting with the Wizard

Although Windows NT's storage requirements may prompt you to do some heavy-duty work in the Configuration Editor to add more virtual disks, or perhaps a raw or plain disk, the basic configuration can still be done within the wizard.

+   1. If you're not already in VMware, start the main program by typing `/usr/bin/vmware` at a command prompt.
+   2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
+   3. Click Next to clear the first greeting screen.
+   4. Select Windows NT 4.0 from the list of guest operating system choices, and then click Next to proceed.

> VMware doesn't care whether you plan to install the server or workstation version of NT 4, although you might need to slant your later decisions to account for any heavy-duty applications you plan to run.
