## Sharing Files via FTP

Yes, it lacks a certain elegance. Yes, it's early 80s technology. But my friends, I tell you plainly, it is the easiest and most convenient way to swap files between your host PC and your virtual machines. NFS works well but requires additional configuration, and Samba, in a Linux-to-Linux setting, does not offer significantly greater advantages over FTP for most users. See Figure 10.26 for a Linux-to-VMware FTP session.

> Samba and NFS-based file sharing are covered in detail in Appendix B, "File Sharing with Samba and NFS in VMware."

Most Linux distributions run an FTP server by default. If you shut yours off for security purposes, turn it back on or just leave the server in your virtual machine enabled when you install its copy of Linux. For demonstration purposes, I assume the FTP server is running on the host, however.

There are literally dozens of FTP clients to choose from, ranging from plain-text terminal varieties such as ftp and ncftp (both standard in Linux distributions) as well as elaborate GUI implementations. There is copious documentation on FTP available anywhere you care to look, including the built-in man help pages in Linux.

![](img/b2b6702758c230ce537468351fc8af15_214_0.png)

Figure 10.28 The host (in the top Terminal window) is logged in to the virtual machine, and the virtual machine is logged in to the host!

To share files over FTP, simply open a session from the virtual machine to the host. If you are using bridged networking, connect to the IP address of the host's eth0 Ethernet device (192.168.20.2, in my example). If you are using host-only networking, connect to the IP address of the host's vmnet1 device (192.168.71.1, in my example).

Log in with a username and password that are valid on the host machine, and begin swapping files. Note that some FTP servers by default will not let you log in as root, to protect the system from possible grave tampering. You can consult an advanced text on FTP servers if you need to change features such as this.

> Actually, the example at the start of this section is pure proof-of-concept overkill. Because you can upload as well as download files (put as well as get, in FTP lingo), it's unnecessary to run FTP clients on both sides. But it's nice knowing it can be done!

If you have NFS available on your computer, you can also share drives that way. See Appendix B for details. Also some very clever FTP clients can help make accessing the networked drives virtually transparent.

If you connect over bridged networking, the domain name servers that your computers communicate with might cache the network name of your host PC, allowing you to drop the cumbersome IP address.

## Sharing an Internet Connection

If you take advantage of VMware’s bridged networking capabilities, you might be able to access a local area network or the Internet directly from the virtual machine.

A bridged networking connection looks and behaves to the outside world as a separate computer. It just happens to share your host computer’s bandwidth.

Internet connections over a LAN (often in a corporate setting, but increasingly found at home) work extremely well in VMware. Many include DHCP servers that automatically assign IP addresses to the clients on the network—including your VMware session. If there is no DHCP server, you have to research what IP address can be safely assigned to the virtual machine to give you access without conflicting with anyone else on the network. You can see a Linux guest connected to the outside Internet in Figure 10.27.

If your Internet connection does not lend itself to being shared using a bridged networking connection (some modem dial-up accounts fall under this category) you have two options.

You can set up an Internet proxy server on your host Linux machine and point the virtual machine to the proxy server on the host across either a bridged or host-only network connection. Proxy servers are readily available for Linux, although their configuration and maintenance falls squarely under the “advanced” category and will require some extra reading on your part.
