
When a game speaks of a "music card," that generally means it is looking for a MIDI device, and VMware's sound emulation does not provide MIDI. If you are playing a DOS game that asks you to configure separate "sound" and "music" cards, you need to set the music card to PC Speaker or Silence.

If you do have a problem with excessive speed, try using the program MOSLO.COM, which some classic collections include on CD-ROM. You can also download it from http://www.hpaa.com/moslo.

Finally, try to play games in full-screen mode. Video performance is much faster.

## Windows Gaming Configuration

Aside from the very obvious piece of advice (make sure you have installed VMware Tools and the custom video driver before you even dream of playing games in Windows!), you face a couple of configuration concerns if you want to play compatible Windows games through VMware.

In Windows, as long as you have the Windows SoundBlaster 16 driver loaded, audio should work more or less without fail unless the game requires DirectSound features. But the emulation layer between the virtual machine and your real Linux sound card is rather complex and time-consuming, and you might find that games with frequent sound effects or digitized speech stutter the sound, cause jerky video motion, or both. You might need to get selective about when you turn on sound and rely on text cues or subtitles more often than you might like.

![](img/b2b6702758c230ce537468351fc8af15_325_0.png)

Figure 15.5 StarCraft, one of the most addictive multiplayer games in recent years, running in a Windows virtual machine.

By now, I have made it abundantly clear that DirectX-loving games will not work in a Windows virtual machine. Unfortunately, that does not necessarily mean that all non-DirectX games will be "load and go." A number of non-DirectX games require very specific screen modes: often 640x480 at 256 colors. This is by no means a challenge for the VMware video driver (and almost certainly not a challenge for your video card), but it is a problem if you are running your Linux system in 16- or 24-bit color, which many, if not most, Linux users do.

A Windows virtual machine cannot change the color depth of your XWindows desktop, so if you plan to play a game that requires 640x480x256, you need to start XWindows at 8-bit color depth before you try to play the game.

Depending on the settings you used when you installed Linux, you might have 8-bit color modes available. Exit XWindows to the Linux console, and try to re-launch X using the command

```
startx -- -bpp 8
```

If you have 8-bit screen modes available, you should start in a 256-color XWindows desktop, and the Windows virtual machine should have no trouble switching to the right screen mode. You might see a minor error message when VMware launches, and the customary VMware configuration window backdrop will not appear, but VMware works perfectly well in 256 colors.

If X does not start in 256 colors, you might not have any 8-bit screen modes configured. If you like, you can use the X configuration tool of your choice, such as XF86Config or Xconfigurator, and add a few 8-bit modes. (It is probably a good idea to include 640x480, as well as your normal high-resolution mode.)

![](img/b2b6702758c230ce537468351fc8af15_326_0.png)

Alternately, if you have a fairly standard XFree86 setup, you should be able to make the changes manually. To edit your X configuration to include 8-bit (256-color) modes, follow these steps:

- 1. Locate your XF86Config file. Ninety-nine percent of the time, you will find it in /etc or /etc/X11.
- 2. Edit the file. (You might need to use the su command to become root to have the right to edit or save your changes.)
- 3. At the very bottom of the configuration file, you should see a listing for “accelerated servers,” along with an entry for your Linux PC’s video card. Look at the area marked Subsection “Display”.
- 4. If you do not have 8-bit screen modes, chances are you have 16- or 24-bit depth modes instead. To add 8-bit modes, first copy and paste the lines between Subsection “Display” and EndSubsection just below the EndSubsection line.
- 5. In the newly pasted subsection, change the Depth line to 8.
- 6. In the newly pasted subsection, change the Modes entries to those appropriate to your video card. Be sure to enclose each entry in quotes, with a space between each one. A common entry might be “640x480” “800x600” “1024x768”.
- 7. Re-start X using startx -- -bpp 8. As with DOS games, it’s better to play games in full-screen mode to optimize video performance.
