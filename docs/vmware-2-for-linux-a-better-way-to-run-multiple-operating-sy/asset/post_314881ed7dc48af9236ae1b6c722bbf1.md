If Windows 95 and 98 are just too "light" for your Windows application needs, you might consider NT 4. Now supplanted by Windows 2000, it remains a valid choice for people who need a robust, protected operating system but don't have the kind of money to outfit their systems properly for Windows 2000.

Some of the hype surrounding Windows NT 4 intimidates people, but it's really not that difficult to install and run. To be sure, if you plan to run mission-critical servers on your Windows NT guest, I highly recommend picking up at least one Windows NT administration guide. But for a basic workstation or even server configuration, your intuition and this chapter are enough to put you on the right track.

Even if you're an NT whiz, you might be surprised at how well NT works in VMware. Because of the streamlined virtual hardware environment, this might be the fastest and most painless Windows NT installation you'll ever do.

## Preparing the Virtual Machine

Any good VMware guest OS installation begins with the Configuration Wizard.

### Starting with the Wizard

Although Windows NT's storage requirements may prompt you to do some heavy-duty work in the Configuration Editor to add more virtual disks, or perhaps a raw or plain disk, the basic configuration can still be done within the wizard.

- 1. If you're not already in VMware, start the main program by typing `/usr/bin/vmware` at a command prompt.
- 2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
- 3. Click Next to clear the first greeting screen.
- 4. Select Windows NT 4.0 from the list of guest operating system choices, and then click Next to proceed.

> VMware doesn't care whether you plan to install the server or workstation version of NT 4, although you might need to slant your later decisions to account for any heavy-duty applications you plan to run.

![](img/b2b6702758c230ce537468351fc8af15_221_0.png)

5. Enter a path to the new directory that will house the VMware configuration files as well as the virtual disk in the window shown in Figure 11.1. By default, VMware asks to create a new directory called /vmware/nt4 off your home directory, although it might make sense to be more specific about which edition (server or workstation) you will run, as in /vmware/nt4work or /vmware/nt4server.

6. VMware asks whether you want to create a new virtual disk or use an existing physical disk. Unless you are familiar with the advanced disk and configuration modes described in Appendix A, "Advanced VMware Configuration," it is best to accept VMware's offer to create a new virtual disk. Click Next.

7. Enter a size for the new virtual disk (see Figure 11.2). Although 2,000MB is the default, you can go as high as 2,047MB. Remember that the disk grows as data is added, but you cannot change its maximum size later. Click Next to proceed.

8. VMware should detect your CD-ROM. Leave the default settings as is (to enable CD-ROM access and make it available when the virtual machine boots), and click Next.

9. VMware asks about floppy access. Unless you have a compelling reason to disable the floppy, leave this setting alone as well. Click Next.

> You might need a boot floppy to install the OS, depending on the vintage of the Windows NT CD.

10. The wizard asks how the virtual machine should be able to access the network, shown in Figure 11.3. If you plan to keep the Windows VM completely isolated, you can click No networking. If you have an Ethernet card installed and your PC is on a LAN, use Bridged networking, which lets the virtual machine share your Ethernet card and appear as a standalone computer on the network. Host-only networking allows Samba file sharing between the VM and your Linux PC (provided you installed the VMware Samba server at installation or have one of your own running), and Bridged and Host-only networking combines the two. If you have a LAN, stick with Bridged for now. If you do not, use Host-only or none. Click Next to reach the final step.

> See Chapter 9, "Using Your Windows 95/98 Virtual Machine," and Appendix B, "File Sharing with Samba and NFS in VMware," for extended file sharing and networking tips for Windows.
