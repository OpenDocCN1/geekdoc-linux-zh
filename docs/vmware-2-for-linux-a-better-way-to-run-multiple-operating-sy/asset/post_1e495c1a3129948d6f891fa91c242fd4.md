
Or you can simply make the Internet dial-up connection directly from the virtual machine. VMware should have no trouble whatsoever accessing an internal or external modem that works on your Linux setup. Because you’ll be using Linux to make the connection, you can probably just export your configuration files to the virtual machine (over an FTP link as described earlier, for example) and dial out from the virtual machine over the modem as needed.

> This isn’t sharing, strictly speaking, because you have to disconnect the host from the Internet every time you want to dial from the virtual machine, but it is an option worth considering before you give up.

## Mounting a Virtual Disk on the Host

There will probably be times when you want to get data to or from your virtual machine’s virtual disk, but VMware isn’t running, you don’t have enough system resources to load it, or you just don’t want to bother with the network protocols. It would certainly be convenient if you could access virtual disks directly from the Linux host.

Luckily for VMware fans, the programmers have thought of that. A handy little program called vmware-mount.pl lets you address a virtual disk as you would any standard Linux drive.

> Do not attempt to mount a virtual disk while it is in use by a running virtual machine. Although there are safeguards against this, don’t push your luck by trying anyway. Also, it is wise not to tinker too much with a virtual disk that is in suspend mode.

vmware-mount.pl is currently part of the standard VMware distribution. To mount a virtual drive, follow these steps:

- 1. Quit all sessions of VMware.
- 2. You need root access. Type su and enter the root password.
- 3. Use the vmware-mount.pl program to first display the partition table of the drive you want to mount. You need to know the location and name of your virtual hard drive first. A common name for a Linux virtual hard drive is ~/vmware/linux/linux.dsk.
- 4. Type vmware-mount.pl -p ~/vmware/linux/linux.dsk, substituting the final argument for the actual path of your Linux virtual disk. See the results in Figure 10.28.

![](img/b2b6702758c230ce537468351fc8af15_217_0.png)

Figure 10.28 vmware-mount.pl shows the partition table of the Linux virtual disk.

- 5. You see a partition table. For a common Linux virtual machine, you see one swap partition and one or more standard Linux partitions. Make a note of the number (in the first column) of the partition you want to mount.

- 6. To actually mount the drive, type vmware-mount.pl ~/vmware/linux/linux.dsk 1 /mnt/vhd, substituting the first path with the actual path to your virtual disk and the number 1 with the actual partition number you want to mount based on your virtual disk’s configuration. If vmware-mount.pl complains that you are lacking the "Network Block Device," you may need to manually load the nbd.o module, or recompile your kernel with this support.

- 7. If you type cd /mnt/vhd, you find yourself at the root of your Linux virtual machine’s hard drive. You can access any file in the virtual disk and copy items to and from the rest of your Linux file system. Remember that your changes are permanent, so be careful!

- 8. Don’t forget to disconnect the virtual drive when you’re done, before attempting to load from the virtual disk in VMware in particular. Unfortunately, you have to use brute force: Click on the terminal you used to launch the vmware-mount.pl program, and press Ctrl+C to quit.

> Accessing a virtual disk in this fashion can, under certain circumstances, make your system unstable if you perform large sustained writes to the virtual disk. If you need to write large amounts of data to the virtual disk, consider using VMware’s networking capabilities instead of directly mounting the virtual disk. Watch VMware’s Web site for future updates to the vmware-mount.pl program that will fix this problem.

VMware can create a virtual computer for any number of the top Linux distributions on the market. Whether you need a protected place to work on configuration changes to your core system or you want to experiment with really wild modifications to the operating system, VMware can give you a transparent virtual machine to carry out your plans.
