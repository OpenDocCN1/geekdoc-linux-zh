
## Chapter 5: Running VMware for the First Time

- Fit is used when VMware is displayed in a window on your Linux desktop. It snaps the virtual machine window to be large enough to display the entire virtual machine screen at once. If you resize the window to be too small, scroll bars appear so you can pan across the guest OS screen.
- Autofit tells VMware to always keep the virtual machine window large enough to show the entire guest OS screen, even if the guest OS changes its size. Unless you have low desktop resolution or a good reason to turn this off, you should keep this on whenever using VMware on the desktop.
- Toolbar toggles on and off the list of buttons (Power On, Reset, and so on).
- Status Bar toggles on and off the information at the bottom of the VMware screen. The status bar, shown in Figure 5.9, includes virtual LEDs to show when the virtual machine accesses a disk or its emulated Ethernet card.
- Icons replaces the text toolbar buttons with small icons.

### Help Menu

Last but not least, here's where you turn if this book can't answer your questions:

- Help invokes your default HTML browser and loads the included VMware help file, which mostly addresses configuration and interaction issues rather than troubleshooting and tips.
- Product Information is essentially a bookmark to VMware's main product description site. This requires a live Internet connection.
- Technical Support is a bookmark to VMware's technical support Web site. This, too, requires that you be online.
- About VMware shows you the current version and build number of your VMware software, as well as your license key details.

### Using the Configuration Wizard

Creating a new virtual machine profile in the standard Configuration Editor can be a little overwhelming for someone completely new to virtual machines and emulators in general and VMware in particular. For a number of virtual machines, the wizard is all you need to get a usable configuration, and it's much easier to adjust a few settings later than build them all from scratch.

For this example, I demonstrate setting up a Windows 98 guest operating system session. The procedure is virtually identical for any guest OS.

> If you are skipping around in this book and have not yet read about VMware resource requirements in Chapter 3, "Equipping Your PC for VMware," now is an excellent time to do so.

1. Start the VMware Configuration Wizard by clicking on the File menu and then selecting Wizard. The welcome screen appears, and is shown in Figure 5.10.

![](img/b2b6702758c230ce537468351fc8af15_83_0.png)

*Figure 5.10*

2. Click Next to advance to the guest OS selection screen.

3. All of VMware's fully supported operating systems are listed, including an option for Other if you want to experiment. For this demonstration, choose Windows 98 from the Guest Operating System screen pictured in Figure 5.11, and click Next to continue.

![](img/b2b6702758c230ce537468351fc8af15_84_0.png)

*Figure 5.11*

4. On the screen shown in Figure 5.12, VMware asks where you want to store configuration files related to this virtual machine. By default, VMware creates a directory named after the guest OS off of a vmware branch in your home directory, in this case '/home/[yourname]/vmware/win98/'. If you decide to relocate it, don't forget your selection. Click Next when you are ready to proceed.

![](img/b2b6702758c230ce537468351fc8af15_84_1.png)

*Figure 5.12*

5. VMware now wants you to assign a hard drive to the virtual machine. In the wizard, you can only create a new virtual disk or assign an existing physical hard drive to be used as a raw disk. Because virtual disks are easier to configure and use, stick with the default selection in Figure 5.13 and click Next.

6. VMware aggressively assumes you want to create a 2GB virtual disk, the maximum allowed. If you know you’re low on disk space or don’t want to make a huge commitment just yet, you can make a smaller drive by typing in a new value in the window shown in Figure 5.14. Click Next when finished.
