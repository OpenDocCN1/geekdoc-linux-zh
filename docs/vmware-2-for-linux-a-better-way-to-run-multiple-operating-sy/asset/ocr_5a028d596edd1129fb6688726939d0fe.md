16. For a common networking environment, you can safely accept the Typical Settings option when asked about your networking configuration. If you need custom settings, chances are you know that already and should know how to adjust for them.

17. To enable Samba file sharing with the Linux host over host-only networking, select No, this computer is not on a network, or is on a network without a domain on the screen shown in Figure 12.11. (Remember, it means Windows NT/2000-style domains, not traditional Internet domains.) Enter the workgroup name assigned to the Samba server on Linux (which is WORKGROUP by default).

18. Setup installs and configures your chosen OS and networking components. This requires a significant wait. When the installation is finished, you are prompted to remove the CD and reboot the virtual machine.

> Remember that you might need to disconnect the CD-ROM from VMware and manually unmount the CD in Linux before you can eject it. Be sure to re-attach the CD-ROM drive after you remove the CD.

19. After the 2000 boot screen appears (see Figure 12.12), press Ctrl+Alt+Del to sign on and then enter the administrator password you assigned during the setup process.
