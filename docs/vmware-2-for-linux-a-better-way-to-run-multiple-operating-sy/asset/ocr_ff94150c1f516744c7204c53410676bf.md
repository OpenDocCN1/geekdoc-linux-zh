This is the procedure to install UAE from source code:

+   1. Download the source code archive (such as uae-0.8.12.tar.gz) from http://www.freiburg.linux.de/~uae, and place it in a new directory.

+   2. Open the source code archive with the command tar -zxvf uae-0.8.12.tar.gz. This creates a new directory named after the archive.

+   3. Use the cd command to change to the directory that was just created (as in cd uae-0.8.12).

+   4. Before UAE can compile properly, it must collect some information about your system. To start the process, type ./configure at the prompt. A large amount of text scrolls by.

+   5. When the configuration program is finished, type make. UAE is being compiled. Screens full of text scroll by, and the compile process can take several minutes. The program being compiled is called uae and will be stored in the current directory.

+   6. When complete, copy your Amiga ROM images to the same directory as uae. Name the ROM you plan to use most frequently (which will likely be either version 1.3 or version 3.1) kick.rom. This will be the ROM loaded by default the first time you run UAE. For the sake of convenience, you might also want to copy any ADF files to this directory as well or store them somewhere logical.
