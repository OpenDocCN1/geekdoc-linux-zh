Windows 95 has a known incompatibility with the AMD K6-2 chip at speeds of 350MHz and above. It is considered transient in that it may not show up every time you boot Windows 95, but the problem was severe enough that I actually had to use a second PC to write this chapter. Although a patch is available from Microsoft and AMD, it really only works with Windows 95 OSR2, and even then it does not work particularly well in VMware. If you have a K6-2 CPU, I strongly urge you to use Windows 98. This problem does not affect K6, K6-III, or AMD Athlon processors.

If you're unsure what version of Windows 95 you have installed, you can check the System Properties window after installation. Right-click the My Computer icon and select Properties (see Figure 7.1 for an example). You should see a string starting with 4.00.950. If it has no accompanying letter, you have the original Windows 95. An A or B indicates you are using intermediate revisions, which correct some important bugs. C (also OSR2.5) shows that you are using the most up-to-date major release of Windows 95, which integrates Internet Explorer into the operating system much as Windows 98 does.

You can install incremental bug fixes and patches from Microsoft in your virtual machine, just as you would on a regular computer.
