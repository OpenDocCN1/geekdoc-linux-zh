What happens next depends on the rest of your virtual machine configuration. If, for example, you install a drive full of Windows data in your PC and add it as a raw disk in an existing Windows virtual machine, the new partitions should automatically be recognized and configured by Windows, as shown in Figure A.5.

Many Linux environments also automatically recognize and configure new hard drive partitions.

If your raw disk is blank, you need to use an OS installation CD or floppy to format and partition the drive. The strategies outlined in the OS-specific chapters of this book to format and install to virtual disks are essentially the same for raw disks.
