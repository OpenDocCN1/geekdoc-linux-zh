15. If the startup disk asked you about CD-ROM options before, you are asked again. Start the virtual machine with the same options you used the first time.

16. You still need to format the new partition you created. At the A:\> prompt, type format C: /s.

## Carrying Out the Main Installation

Now that the virtual disk is properly prepared, you can begin the main installation of Windows 95:

- 1. At the DOS prompt, change to your virtual CD-ROM drive. This is usually D: or E:, depending on the setup of your virtual machine. Switch to the correct drive by typing d: or e: and pressing Enter, as appropriate.
- 2. Start the installation by typing setup and pressing Enter.
- 3. At the beginning of the installation, and later in the process, you see prompts about "performing routine checks." Simply do what the installer program asks at each occurrence.

4. Setup should run ScanDisk (the first but not the last time you'll see that charming program), report that all is well, and proceed to the graphical Windows 95 setup screen, shown in Figure 7.12. Click Continue to proceed.

![](img/b2b6702758c230ce537468351fc8af15_142_0.png)

Figure 7.12 At last, the Windows GUI is running, although the OS is not yet installed.

5. The Windows Software License Agreement appears. Click Yes to continue.

6. The Windows Setup Wizard starts. Click Next.

7. The wizard asks where it should install Windows. Unless you have a compelling reason to change it, leave the default alone and click Next.

8. The Setup Wizard scans the hard drive and then asks how thorough the installation should be (see Figure 7.13). Because Typical setup does not properly install the networking components VMware needs, select Custom and click Next.

9. Windows asks for your Certificate of Authenticity code, found on the booklet that came with the operating system. Type it and click Next.

10. Windows asks for your name and company name for login purposes. Enter whatever you like and click Next.

11. You do not need to change anything on the Setup Components screen unless you want to install additional Windows bundled software. Click Next when done.

12. The next screen, Network Configuration, is important if you plan to use a virtual Ethernet card. Click Add, select Adapter, find the listing for Advanced Micro Devices (AMD), and add the network adapter named AMD PCNET Family Ethernet Adapter (PCI&ISA).
