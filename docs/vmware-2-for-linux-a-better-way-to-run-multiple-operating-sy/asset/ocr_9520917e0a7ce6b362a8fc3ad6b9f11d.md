5. Enter a path to the new directory that will house the VMware configuration files as well as the virtual disk in the window shown in Figure 11.1. By default, VMware asks to create a new directory called /vmware/nt4 off your home directory, although it might make sense to be more specific about which edition (server or workstation) you will run, as in /vmware/nt4work or /vmware/nt4server.

6. VMware asks whether you want to create a new virtual disk or use an existing physical disk. Unless you are familiar with the advanced disk and configuration modes described in Appendix A, "Advanced VMware Configuration," it is best to accept VMware's offer to create a new virtual disk. Click Next.

7. Enter a size for the new virtual disk (see Figure 11.2). Although 2,000MB is the default, you can go as high as 2,047MB. Remember that the disk grows as data is added, but you cannot change its maximum size later. Click Next to proceed.
