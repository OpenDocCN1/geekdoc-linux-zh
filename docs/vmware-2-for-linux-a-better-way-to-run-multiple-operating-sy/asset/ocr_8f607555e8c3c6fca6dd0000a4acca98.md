The cream of the crop of DOS Internet applications is Arachne, a freeware, pure DOS Web browser with a pleasant range of features. You can download it from the project's home page, http://home.arachne.cz.

> Deluxe versions of DR DOS come with DR-Webspyder, a commercial product based on Arachne's core code but with some interesting enhancements.

Before you install and run Arachne, you should run your packet driver, running a mouse driver is also highly recommended. Unless your network has DHCP or BOOTP capabilities, you need your network configuration information on hand.

Arachne's installer is extremely easy to use: Run the self-extracting archive, accept the default settings, and go! When the first graphical screen appears (see Figure 14.17), be sure you select the 640×480, 16-color graphics mode; anything else won't work properly.

Arachne can configure a PPP dial-up script if you want to use a modem, and it can also detect a running packet driver for your virtual Ethernet card. The prompts are done "wizard-style" and should be easy to follow if you've ever configured Windows or Linux networking. After you set the options, you are rewarded with the finest Web experience DOS has to offer, demonstrated in Figure 14.18.

The DOS browser runs rather slowly because of the inefficient default VGA driver. Because there are no VMware Tools for DOS, video performance suffers greatly.
