VMware Tools is a small application that runs inside a virtual machine on the guest operating system—in this case, on Windows 95 and above. Running VMware Tools is technically optional but highly recommended, and in fact there is no good reason not to run it.

In essence, the tools are a "glue layer" that ties the virtual machine to your Linux PC more closely, giving you better performance and making it easier to switch between the virtual machine window and the Linux side of your computer. It's not an exaggeration to say that the tools make the difference between a tolerable and an excellent VMware experience. VMware only provides VMware Tools for the operating systems it explicitly supports; without it, you have less external control over how the virtual machine works, and your graphics performance will suffer.

You should have installed the tools after ensuring that your Windows virtual machine was running properly. After the installation, VMware Tools and the accompanying high-resolution video driver automatically load every time you start your Windows virtual machine.

> In this chapter, I demonstrate the use of VMware Tools in Windows 98. The differences in Windows 95, NT 4, and 2000 are negligible.
