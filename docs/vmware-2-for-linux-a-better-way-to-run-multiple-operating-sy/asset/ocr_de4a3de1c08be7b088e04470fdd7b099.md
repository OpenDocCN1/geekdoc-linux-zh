# Understanding the Virtual Machine BIOS

![](bbox=[0.068, 0.074, 0.516, 0.374])

Figure A.14  In the Security screen, you can set a password or restrict disk access.

> Any BIOS security settings can be easily circumvented by simply deleting the .nvram file that stores BIOS preferences in any VMware configuration directory. Do not count on any of these features to provide unbreakable security.

+   - Set User Password—Ghosted by default until Password On Boot is enabled. Allows you to password-protect the virtual machine; it will not boot unless the password is entered.
+   - Set Supervisor Password—Allows you to password-protect the BIOS setup screens.
+   - Password on boot—Enable, and then use Set User Password, to protect the virtual machine from unauthorized users.
+   - Fixed disk boot sector—If you are extremely concerned about viruses affecting your virtual machine, you can turn on this setting, and the boot sector (a popular target) will be write-protected. This setting may protect the virtual machine from some types of viruses.
+   - Diskette access—Can safely leave as Supervisor.
+   - Virus check reminder and System backup reminder—The system will print a message encouraging the user to run a virus scan, back up the system, or both on a daily, weekly (on Monday), or first-of-the-month basis.
