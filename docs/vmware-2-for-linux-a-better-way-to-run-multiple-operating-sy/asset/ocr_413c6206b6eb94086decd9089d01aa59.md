+   1. Add at least one user to the Windows NT system other than administrator, using the User Manager for Domains under Administrative Tools (Common) in the Programs Start menu.
+   2. Run the Internet Service Manager, found under Microsoft Internet Server (Common), on the Programs Start menu.
+   3. Double-click on the FTP service icon. An FTP management window will appear, like the one shown in Figure 11.30.
+   4. Turn off Allow Only Anonymous Connections on the main configuration tab.
+   5. Click on the Directories tab, and change the default path to C:\ (or a more useful directory path). You can add other paths if you have other drives or you do not want to open up such broad-ranging access. Write access is off by default; be sure to enable it if you want to be able to copy files to Windows NT via the NT FTP server. The end result should resemble Figure 11.31.
+   6. Be sure to apply all changes before closing any windows.
