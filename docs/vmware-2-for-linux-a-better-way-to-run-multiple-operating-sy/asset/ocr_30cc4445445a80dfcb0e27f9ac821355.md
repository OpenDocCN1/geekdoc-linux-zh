# Devices Menu

The contents of the Devices menu (see Figure 5.7) change depending on how many virtual disks you attach to VMware. There should always be an entry for the virtual machine's RTC (Real Time Clock), as well as a list of every storage device (real or virtual) you have connected to the virtual machine.

![](bbox=[0.05, 0.845, 0.32, 0.925])

Figure 5.7 You can disconnect or change the storage devices you have connected to a virtual machine on-the-fly.

The storage devices have two options: Disconnect and Disconnect and Edit. Disconnect makes the device temporarily invisible to VMware, and Disconnect and Edit also immediately brings up the Configuration Editor so that you may change the device you want to connect to VMware. After you have made changes in the Configuration Editor, the Disconnect command changes to Connect, and you can re-attach the drive to VMware.
