## Installing Windows NT 4 Server

The step-by-step for a Windows NT 4 Server installation is virtually identical.

A few questions show up in the server installation that do not in the workstation version. The first is the choice of whether you want to use Per Server or Per Seat Windows NT networking licensing, shown in Figure 11.16. The decision must be left up to you, the needs of your network, and your available licenses if you plan to do any serious serving from the virtual machine.

The same applies to the Server Type prompt (see Figure 11.17). Unless you need to and know how to set up a Windows NT domain, stick with Stand-alone Server mode.

## Upgrading Windows NT and Installing VMware Tools

If you've already gone through a VMware guest OS installation using this book, you're waiting for me to immediately admonish you to install VMware Tools. Ready for a change of pace? Don't install VMware Tools just yet.

### Installing a Service Pack Upgrade

Although Windows NT Service Pack 1 will boot in VMware, it's really not what you want to use over anything remotely like the long term. In fact, your first order of business should be to install Service Pack 3 or later (see Figure 11.20).

### Installing VMware Tools

With Windows NT updated, you can safely install the VMware Tools and SVGA driver. Start with a fresh reboot of Windows NT, and switch to windowed mode by pressing Ctrl+Alt+Esc:

- 1. On the VMware application window, select Settings, VMware Tools Install.
- 2. If this is your first time installing VMware Tools, you might want to take the opportunity to read the online help when prompted.
- 3. Double-click My Computer and the Floppy icon. This opens the virtual floppy VMware mounted when you started the tools install process.
- 4. Double-click the VMware Tools icon, shown in Figure 11.21.
- 5. Accept the default settings in the VMware Tools Installation Wizard and proceed with the installation.
- 6. When prompted to enable clear-text passwords, answer Yes. Although they are not always strictly necessary to connect to a Linux-hosted Samba server, they make things much easier.
- 7. When the Tools installation is complete, Windows opens the Display Properties control panel, shown in Figure 11.22. Click the Display Type button to start installing the SVGA driver.
- 8. You need to change the VGA Compatible Display Adapter to the custom VMware driver. Click the Change button, and then select Have Disk on the Change Display window. When Windows asks where it should search for the new driver, specify A:\winnt.
