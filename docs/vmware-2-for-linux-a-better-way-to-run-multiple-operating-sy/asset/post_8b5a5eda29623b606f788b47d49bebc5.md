
## Sharing Documents

It's hardly a secret that Linux is not the overwhelming, industry-wide choice for desktop publishing. It just doesn't get a fair shake sometimes.

With a Windows virtual machine, you gain virtually 100 percent compatibility with some of the most popular desktop publishing (DTP) and Web design programs in the world. If you love Apache for Web serving but are less than thrilled with the range of Web design programs for Linux, there's nothing wrong with using Macromedia Dreamweaver or Microsoft FrontPage to build your Linux-hosted pages.

You might want to convince your office to switch to Linux word processing and use Windows and Linux to demonstrate portability. You might prefer preparing your documents in a Linux word processor or editor but need to save the final product in a 100 percent Windows format. Or you might simply like the flexibility of a very large desktop publishing toolkit. See Figure 9.9 for a suggestion.

Tips for document portability and sharing follow:

- Whenever possible, save formatted documents to a relatively software-neutral format, such as Rich Text Format (RTF). Although RTF isn't perfect across all platforms and word processors, it's safer than relying on sometimes-questionable import filters.

Figure 9.9 Use VMware and Linux DTP programs in conjunction, to verify that your new document or template can be viewed equally well in several different environments.

- If you do need to save to a proprietary format, such as Microsoft Word, save in the earliest version possible that preserves all the formatting. Filters are generally more accurate, the farther back you go.
- Keep your Linux office suite up to date! Both commercial and open-source Linux productivity programs tend to be updated quite frequently. That can help you match the features and capabilities of Windows DTP programs.
- Unless you’re specifically designing a Web page, don’t use HTML as an intermediate format between word processors or between a word processor and a Web design program. Different programs have different ideas of how to import and re-interpret HTML formatting codes.
- When necessary, fold. Windows under VMware can access your Linux printer as though it were attached directly to a Windows PC. If a document just doesn’t look right in a Linux word processor, there’s no shame in sticking with your Windows virtual machine.

## Sharing Images

Fortunately, graphics formats are an open book compared to word processor file layout. You should have no trouble whatsoever swapping high-resolution, 24-bit color images with impunity between a Linux image editor and Windows graphics software.

Why do such a thing? Well, the field of computer graphics is decades old, and there is still no such thing as the "perfect" program. Linux’s best-known image editor, The GIMP, is loaded with features, as is Adobe Photoshop for Windows. Then other Windows programs, such as Paint Shop Pro, offer a large feature set at a fraction of Photoshop’s price and with (arguably) a much cleaner interface than The GIMP and Newtek’s Aura, which focuses on special effects and animation.

Aside from having unprecedented freedom to use the right imaging tool for the job (and as many tools as you see fit), there is a more pragmatic reason you might need to put both Linux and Windows through VMware to work on an imaging project.

Because VMware cannot see scanners over a SCSI interface, you need to use scanning software such as SANE (Scanner Access Now Easy) if your flatbed scanner uses SCSI rather than the parallel port. VMware can see some parallel port scanners, so you might be able to use standard Windows drivers for those. If you can’t, scan the image using a GIMP plug-in or another scanner front end, and then you can export it to an image editor running on the Windows VM using Samba or FTP, as shown in Figure 9.10.

Tips for document portability and sharing follow:

- When swapping image files, be sure to use a non-lossy format such as TIFF or BMP. Only save files as JPEGs when you're sure you don't have any more work to do, and even then save a non-lossy version of the same picture first, just in case.
- LZW-compressed TIFF is the best intermediate format most of the time, but in The GIMP, be sure to save files as MSB to LSB (most significant bit to least significant bit), not the other way around, because some Windows programs have trouble with the default format.
- If you use Photoshop for Windows, download the psd2 plug-in from The GIMP's home page (http://www.gimp.org). psd2 lets you load Photoshop layered project files. Another plug-in, psd save, can save GIMP projects in the same format.
- As with word processing, don't force yourself to use a Linux tool when one in a Windows virtual machine will do the job faster and easier. The end result can be enjoyed by all.
