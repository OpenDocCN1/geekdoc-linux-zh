## Using Windows 2000 Services

Although Linux certainly has an impressive array of intranet/Internet service capabilities, you might find it important or necessary to leverage certain Microsoft implementations, such as COM, or some new Windows 2000 network security features. You might also want to research how to convert certain existing services currently handled by a Linux server on your network (such as the NNTP news protocol) to a Windows 2000-based server.

VMware also provides an excellent opportunity to test interconnectivity between a Linux server (which can be the host machine or another computer on your network) and a guest Windows 2000 server. You can isolate bugs, inconsistencies, or potential security holes or "disagreements" before rolling out a hybrid server environment.

Spend some time in the Configure Your Server interface of Windows 2000, shown in Figure 12.23. Some interesting networking possibilities might present themselves.

## Configuring the IIS FTP Server

If you installed IIS (Internet Information Services), you might want to activate Windows 2000's FTP server. (Windows 2000 activates Samba networking without even being asked.)

1. Add at least one username and password to the Windows 2000 system other than administrator, using the Computer Management program under Administrative Tools in the Programs Start menu.
2. Run the Internet Service Manager, also found under Administrative Tools on the Programs Start menu.
3. Click to expand the tree on your virtual machine's network name. You see a list of all available Internet services, very much like the one shown in Figure 12.24.

![](img/b2b6702758c230ce537468351fc8af15_265_0.png)

Figure 12.23 Configure Your Server helps eliminate a lot of fumbling around in individual server maintenance tools.

![](img/b2b6702758c230ce537468351fc8af15_265_1.png)

Figure 12.24 IIS lists all available network services.

4. Right-click Default FTP Site and click Properties.

5. Click the Home Directory tab, and change the local path to point at the root of the directory structure you want to share via FTP (probably C:\).

6. You should enable Write if you want to be able to upload files to the Windows 2000 server using an FTP client on the Linux host or another virtual machine. You might also want to switch the directory listing to UNIX-style for consistency with your other operating system. The Default FTP Site Properties window is shown in Figure 12.25.

![](img/b2b6702758c230ce537468351fc8af15_266_0.png)

7. By default, anonymous logins have access to the FTP site. Click on the Security Accounts tab if you want to deny anonymous connections.

8. Click OK to commit to the changes.

## Configuring the IIS Web Server

Earlier versions of IIS's Web server lacked a certain degree of flexibility. As is Microsoft's custom, it has since added a wide variety of features and customizable options. You can read more about IIS in the Windows 2000 literature, but here are some helpful tips:

- In truth, most of the default settings are just fine for a prototyping, intranet, or light-duty environment.
- Be conscious of security updates for any network service running in a VMware guest operating system. A virtual machine is just as vulnerable to attack as any other PC if it is on bridged networking.
- Activate directory browsing in the Home Directory tab if you want to be able to easily download files from the Win 2000 server with a Web browser on the host, another virtual machine, or elsewhere on the LAN.
- Process throttling in the Performance tab might come in very handy if your IIS Web server sees a lot of traffic, considering that your CPU must be shared with Linux as well.
