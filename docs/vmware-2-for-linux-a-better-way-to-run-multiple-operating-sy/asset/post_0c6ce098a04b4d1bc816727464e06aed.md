## Installing FreeBSD in a Virtual Machine

Your FreeBSD virtual machine is prepared. All it lacks is the operating system.

For purposes of demonstration, I walk through an installation of FreeBSD 4.0. VMware supports FreeBSD 3.x and some versions of 2.x, but in general it is a good idea to stay up to date for any guest OS.

- 1. If you're not already in VMware, start the program and load the FreeBSD configuration defined in the previous section.
- 2. Insert FreeBSD 4.0 CD-ROM #1 in the CD-ROM drive.
- 3. Power on the virtual machine.
- 4. The CD automatically boots and starts the installation process.
- 5. When prompted, skip the kernel configuration, as shown in Figure 13.6. The default options are fine for VMware. (There's still plenty of configuring to be done later!)
