# Sharing the Network

If you've been a careful student, you're aware of all these network nuances already, but it's worth repeating: A VMware virtual machine looks and acts just like any other networked computer on a LAN when in bridged networking mode.

That means if you feed your Windows VM the same network configuration settings as your Linux workstation (except, of course, for assigning the VM its own, unique IP address), the virtual machine enjoys all the same benefits of network membership. If you have a pipeline to the Internet, any Windows network client you can imagine—including Web browsers, streaming media players, and file exchange software—all run with ease. You can access resources on the internal LAN or the Internet just as you would from your host Linux PC.

Server software also runs on VMware Windows guests, although certain tasks are still best left to dedicated computers. The VMware environment isn't set up to run network load-balancing software or a LAN-wide firewall in a virtual machine, and doing so is so difficult to configure that it isn't worth the time.

Because you can run multiple virtual machine sessions while the host continues to run, you can use VMware to create an entire "virtual intranet" and test file and network resource sharing before deploying intranet technology to the rest of the computers in an office.

You can use a Windows VM for something as humble as verifying that your Web pages look just as good in Internet Explorer as they do in Netscape and Opera for Linux. If you're so inclined, you can even set up a Web server such as Apache for intranet purposes (see Figure 9.11).

According to the Apache documentation, there are various security flaws in the Windows version that don't appear anywhere else. If you're in the mood to help out the Apache Software Foundation, what better way than by hammering on (and maybe fixing!) the security holes using your virtual machine environment?

# Conclusion

Combining advanced open-source Linux tools with the vast software library available for Windows is a reality with VMware—and, I might add, a major advantage of the virtual machine environment over a dual-boot system.

After you've fully exploited your Windows 95 or 98 virtual machine, don't be afraid to branch out and experiment with how other operating systems, running in tandem with your Linux host, can help you to be more productive.
