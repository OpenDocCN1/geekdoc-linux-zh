# Run multiple operating systems on one computer!

With VMware® installed on a Linux® computer, running Windows® programs is a snap. As a Linux enthusiast, you can run Windows applications side by side with Linux programs and avoid the inconvenience and inefficiency of "dual booting." VMware breaks through the "one computer, one operating system" barrier and allows your Linux PC to simultaneously run two or more operating systems inside a window. This book guides you through the installation process and demonstrates in a straightforward manner how to configure the software to best suit your needs. Providing valuable tips and tricks for maximizing the power of this revolutionary software, this book is sure to be close at hand for any VMware user.

Jason Compton is a contributing editor for Linux Magazine. He is also a regular contributor to the Chicago Tribune, Smart Business, and CRM Magazine.
