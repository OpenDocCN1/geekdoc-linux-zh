# Exploring the “Other” UNIX Alternative

Linux gets great press for a number of things, including being a zero-cost drop-in replacement for many of the programs and tasks normally reserved for expensive UNIX systems. But the truth is that until fairly recently, the UNIX-alike operating system FreeBSD (earlier NetBSD) was ahead of Linux in features, functionality, and stability.

FreeBSD is derived from a different source tree but is similar to Linux in that it is an open-source operating system based around classical UNIX principles, with an eye toward establishing itself in all sectors of the computing market.

Discussions about Linux versus FreeBSD can get just as impassioned as any other operating-system evangelism. It is often contended, for example, that FreeBSD’s TCP/IP networking is more robust than Linux’s. Many developers prefer the looser terms of the Berkeley open-source license that governs FreeBSD. The General Public License (GPL), which applies to the Linux kernel and many of its most important components, requires companies and developers to disclose information many consider vitally proprietary.
