+   4. The setup program should detect your virtual IDE CD-ROM drive. Ignore the prompt for additional device drivers, and press Enter to continue.
+   5. Because you are using a new virtual disk, setup claims your disk is "new or has been erased" and warns that installing Windows NT will destroy any data. You don't care, so proceed with the formatting and partitioning of the virtual drive by pressing C.
+   6. You are prompted to read and accept the Microsoft end-user license agreement. Read it and then press F8 to accept.
+   7. Setup makes some guesses about your hardware; items such as the keyboard and mouse are easy to detect, so it's right, you don't need to make any changes. Press Enter on The above list matches my computer to continue.
+   8. Windows NT doesn't use fdisk, but a custom text interface for partitioning disk drives. It creates one large partition on your virtual disk, which is a good configuration unless you have a special need. Press Enter on the partition you want to use for NT when you see a screen that resembles Figure 11.8.
+   9. Windows NT asks you to choose between the FAT and NTFS file system. NTFS is faster and works perfectly well in VMware, so use it unless you have a compelling reason to use FAT (such as you want to create a dual-boot configuration with DOS, Windows 3.1, or an early version of Windows 95 on your virtual drive).
+   10. Setup quickly formats the virtual disk and then asks for a directory to install the system to (\WINNT by default). Press Enter to proceed.
