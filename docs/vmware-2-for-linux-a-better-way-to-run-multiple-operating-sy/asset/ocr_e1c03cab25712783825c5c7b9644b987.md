# Sharing an Internet Connection

If you take advantage of VMware’s bridged networking capabilities, you might be able to access a local area network or the Internet directly from the virtual machine.

A bridged networking connection looks and behaves to the outside world as a separate computer. It just happens to share your host computer’s bandwidth.

Internet connections over a LAN (often in a corporate setting, but increasingly found at home) work extremely well in VMware. Many include DHCP servers that automatically assign IP addresses to the clients on the network—including your VMware session. If there is no DHCP server, you have to research what IP address can be safely assigned to the virtual machine to give you access without conflicting with anyone else on the network. You can see a Linux guest connected to the outside Internet in Figure 10.27.

If your Internet connection does not lend itself to being shared using a bridged networking connection (some modem dial-up accounts fall under this category) you have two options.

You can set up an Internet proxy server on your host Linux machine and point the virtual machine to the proxy server on the host across either a bridged or host-only network connection. Proxy servers are readily available for Linux, although their configuration and maintenance falls squarely under the “advanced” category and will require some extra reading on your part.
