Alternately, you can download the latest version of UAE from the UAE home page, http://www.freiburg.linux.de/~uae. Although the developers issue fair warning that even-numbered distributions might be unstable, in my experience you are usually better off using the latest "developer" release because they tend to update the "stable" release infrequently.

As of this writing, the latest developer release is version 0.8.12. The UAE home page contains both the stable and developer source code libraries. The filenames have the form uae-0.8.12.tar.gz, although the version numbers might be newer by the time you download them. You also may be able to download and use some older pre-built binary files, depending on your system configuration.

Before you can run UAE, at the very least you need to obtain an Amiga ROM code image. The UAE source code package comes with a program called transrom, which you can run on any Amiga to obtain the ROM image. After you install a proper Amiga ROM, you can boot to the Amiga "Kickstart" screen, shown in Figure 18.2.

You also need Amiga software. Because PC floppy drives cannot read Amiga floppy disks, you need to use the transdisk program on an Amiga, also provided, to create disk images in the ADF format. There are also some ADFs available from UAE support sites online.
