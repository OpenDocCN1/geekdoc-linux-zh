4. Select Windows 2000 from the list of guest operating system choices, and then click Next to proceed.

> VMware doesn’t care whether you plan to install the Server or Professional version of Windows 2000, so you might need to alter your memory setting later.

5. Enter a path to the new directory that will house the VMware configuration files as well as the virtual disk. By default, VMware asks to create a new directory called /vmware/win2000 off your home directory, although it might make more sense to be more specific about which edition (Server or Professional) you will run, as in /vmware/win2000pro or /vmware/win2000serv. See Figure 12.1 for an example.

6. VMware asks whether you want to create a new virtual disk or use an existing physical disk. Unless you are familiar with the advanced disk and configuration modes described in Appendix A, “Advanced VMware Configuration,” it is best to accept VMware’s offer to create a new virtual disk. Click Next.

> If you plan to do serious work with Windows 2000, it would behoove you to learn the concepts in Appendix A because Windows 2000 uses up space in a big hurry, particularly the Server version.
