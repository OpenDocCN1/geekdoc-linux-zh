In general, it's smarter to run your server applications on the host, but if you can't or don't want to install potentially sensitive programs such as FTP and Web servers on the host machine, installing them on the guest is a good second choice.

9. Corel Linux asks about disk allocation. Because you're using a fresh virtual disk, you can safely use the Take over disk option. Select it and click Next. A warning dialog appears telling you that all information will be erased, but because it's a clean virtual disk, you don't care. Click Yes to confirm your decision.

10. The installation wizard summarizes the (rather few) decisions you've made up to this point, as shown in Figure 10.10. If you have second thoughts, you can click Back until you can make the correction. Otherwise, click Install to start the ball rolling. (You can safely leave off Scan for bad blocks on a clean new virtual disk.)

11. Corel Linux formats the virtual disk and copies Linux to your hard drive. The installation might look like it gets "stuck" at 98 percent, but watch the hard drive and CD-ROM activity lights at the bottom of the VMware window; they should blink for a long time. The Corel wizard just isn't very good at estimating how much time is left.

12. After the installation is complete, eject any floppy disks you might have in the drive, and click OK in the box shown in Figure 10.11 to reset the virtual machine.
