If you continue to have trouble, follow these steps:

+   1. Shut down the Windows 2000 session.
+   2. Temporarily remove the sound driver from VMware in the Configuration Editor.
+   3. Boot Windows 2000, and then remove the sound driver in the System control panel.
+   4. Shut down the virtual machine.
+   5. Re-add the VMware sound driver in the VMware Configuration Editor.
+   6. Re-install the sound driver. (It should be automatically detected by Windows 2000; if not, use the Add New Hardware Wizard and select the SoundBlaster 16 driver.)

With that out of the way, an important next step is confirming your network configuration. If you accepted the default network settings when you installed Windows 2000, your virtual Ethernet adapters look for a DHCP server to configure their IP address and access details.

Open a Windows Command Prompt window and type ipconfig. You will see a screen much like Figure 12.19.

If you only selected host-only or bridged networking, you should see just one Local Area Connection entry; if you are using both, you see another. The host-only networking adapter should be able to acquire an address from the special VMware DHCP server, which is on the special host-only subnet identified by VMware when you installed the host software.

If you don't have a DHCP server on the bridged LAN, you need to call up the Network and Dial-up Connections control panel, shown in Figure 12.20. Each LAN or dial-up connection has its own icon in the control panel.

Unfortunately, with every major revision of Windows, Microsoft changes the way the networking interface looks. No worries; just right-click on the interface you want to edit and select Properties. A window similar to the one shown in Figure 12.21 will appear.
