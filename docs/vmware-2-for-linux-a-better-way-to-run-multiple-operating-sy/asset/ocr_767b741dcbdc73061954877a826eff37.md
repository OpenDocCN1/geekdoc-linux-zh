# Installing Windows 3.1 in VMware

Windows 3.1 was, to put it politely, a curiously designed operating system, especially compared to its successor, Windows 95. It was at the same time more transparently a shell on top of DOS, yet with arguably less integration between the GUI and command line.

Is Windows 3.1 good for anything more than an academic trip back to the early 90s? Perhaps. A reasonable number of applications from that era work equally well in Windows 95 and 3.1, and its resource requirements are lighter. (Windows 3.1 can run comfortably in 8MB of RAM.) Still, I recommend moving to a newer edition of Windows if you're really serious, or you value your time, because Windows 3.1 requires a lot of post-installation enhancement.

> In terms of needing outside software support, Windows 3.1 is easily the most demanding, and therefore frustrating and time-consuming, of all the operating systems VMware supports. I strongly recommend using Windows 95 instead, unless you absolutely demand the look and feel of 3.1.
