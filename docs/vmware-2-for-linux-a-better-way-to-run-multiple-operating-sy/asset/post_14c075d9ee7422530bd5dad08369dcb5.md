VMware Tools has three major headings: Options, Devices, and Shrink. Options focuses mainly on mouse and keyboard settings, Devices provides a convenient way to detach and re-attach Linux system devices from the virtual machine, and Shrink helps you manage your virtual disks.

## Using the Toolbox Options

You can run as many virtual machines as you have memory and disk space for, but you probably only have one keyboard and mouse. Managing when and how the virtual machine takes control of your input devices (known as input focus) pays off quickly in helping you to avoid all kinds of frustration.

Not all the options on the screen in Figure 8.3 are duplicated anywhere else in VMware. (See, I told you running the Tools is important!)

BUZZWORD
Input focus:
Determines whether a virtual machine or the host Linux OS captures mouse and keyboard input. When you type into a VMware-hosted OS and application, VMware is said to have input focus.

The default settings are actually quite nice, and appropriate for most users, but you might want to customize the settings, so it's a good idea to understand just what your choices are.

Changing the settings is as simple as clicking the checkmark box. You don't have to reboot, apply, or even close the VMware Tools window for changes to take effect; they work immediately.

## Release Input Focus

The first option is one half of what is, in my opinion, the neatest feature of VMware Tools. When the option Release input focus is enabled and you move the virtual machine's mouse pointer past the edge of the virtual desktop, the pointer is "given back" to Linux. In other words, input focus returns to Linux as soon as it looks like you want to use the mouse in Linux. You don't even have to click the Linux desktop first.

This feature is useful when you have VMware in a window and need to move between Linux and VMware quickly or often, and you don't want to get bogged down using the Ctrl+Alt+Esc key combination to release input focus from VMware. It can get frustrating if you're doing precision work in an art program near the borders of the screen or playing a game using the mouse.

This feature does nothing when the virtual machine is in full-screen mode; the virtual machine maintains input focus at all times until you press Ctrl+Alt+Esc.

## Capture Input Focus

Capture input focus is the match to Release input focus. When this option is turned on, VMware automatically grabs input focus as soon as you scroll the pointer inside the VMware window.

> It's only sensible to turn on Release input focus if this is active, because it's fairly inconvenient to use the Ctrl+Alt+Esc key combination to get the input focus back on Linux if your pointer accidentally strays into a VMware desktop.

This feature does nothing when the virtual machine is in full-screen mode because the mouse is always within the virtual machine until you exit full-screen mode by pressing Ctrl+Alt+Esc.

## Scroll When Mouse Nears Edge

You only need to worry about the feature Scroll when mouse nears edge if you have a situation where your virtual machine's desktop is larger than the VMware window on your Linux desktop. This could happen if you temporarily make the VMware window smaller or if you are using a virtual machine desktop larger than your computer can display (a 1,280x1,024 Windows desktop on a Linux PC whose desktop is only 800x600, for example).

> If you want to be able to change the size of the VMware window on-the-fly, you need to disable Autofit under View on the VMware window settings. Note that this does not affect the size of the Windows desktop itself, just how much you can see at once!

In Figure 8.4, you see a Windows desktop that cannot be fully displayed because the VMware window is too small. With the Scrolling option enabled, VMware automatically pans across the desktop when the mouse nears the edge of the screen. Otherwise, you would need to restore input focus to Linux and drag the window scrollbars to change the visible area of the desktop.

## Hide Cursor

The option Hide cursor is nothing more than a glorified "mouse blanker," but it can help avoid the confusion of seeing two mouse pointers on the same screen. When enabled, the mouse pointer in the Windows virtual machine disappears if the input focus is on Linux rather than VMware.
