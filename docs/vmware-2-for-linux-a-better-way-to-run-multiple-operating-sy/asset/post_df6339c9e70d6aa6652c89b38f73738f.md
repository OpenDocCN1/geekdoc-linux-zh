
If you decide on Windows 98, you're not done. Should you use Windows 98 or Windows 98 SE (Second Edition)? If you have the choice, I recommend sticking with the original Win 98. Aside from some bug fixes and Year 2000 corrections, most of the extra functionality in Win 98 SE is either of questionable value in the virtual machine or easy to add on to Windows 98.

It is foolish and impractical to use a virtual machine Win 98 SE's Internet Connection Sharing as an Internet gateway for a LAN: Such a task is much better suited to the host Linux OS on your PC, or even better, a standalone server or network device. Enhanced USB support is meaningless in a virtual machine that doesn't support direct access to USB and is not likely to in the near future. And Win 98 SE standard software such as Internet Explorer 5 and the Y2K bug fixes are all available free from Microsoft's Web site, if you feel the need to update Windows 98 original.

## Preparing the Virtual Machine

If your mind is made up, it's time to prepare a virtual machine custom-tailored for Windows 98.

> This installation sequence assumes you are using a Windows install disk labeled "For distribution with a new PC only" or similar. There are some minor differences in upgrade editions.

## Starting with the Wizard

Any new VMware virtual machine should start with the Configuration Wizard.

- 1. If you're not already in VMware, start the main program with /usr/bin/vmware at a command prompt.
- 2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
- 3. Click Next to clear the first greeting screen.
- 4. Select Windows 98 from the list of guest operating system choices, shown in Figure 6.1, and then click Next to proceed.

> If you have an upgrade edition of Windows 98, you should select the operating system you will first install, and at each upgrade stage, edit the Guest OS setting in the Configuration Editor before proceeding. If you have to upgrade from DOS to Windows 3.1 to Windows 95 to Windows 98, however, this might be so mind-numbing that it is worth your while to buy a fresh copy of Windows 98 and install it directly.

5. Enter a path to the new directory that will house the VMware configuration files as well as the virtual disk. By default, VMware asks to create a new directory called /vmware/win98 off of your home directory.

6. VMware now asks whether you want to create a new virtual disk or use an existing physical disk. Unless you are familiar with the advanced disk and configuration modes described in Appendix A, "Advanced VMware Configuration," it is best to accept VMware's offer to create a new virtual disk. Click Next to bring up the virtual disk creation screen, displayed in Figure 6.2.

![](img/b2b6702758c230ce537468351fc8af15_105_1.png)

Figure 6.2

- 7. Enter a size for the new virtual disk. Although 2000MB is the default, you can actually go as high as 2047MB. Remember that the disk grows as data is added, but its maximum size cannot be changed later. Click Next to proceed.
- 8. VMware should detect your CD-ROM. You need a CD-ROM to install Windows 98, so leave the default settings as is (to enable CD-ROM access and make it available when the virtual machine boots), and click Next.
- 9. VMware now asks the same question about floppy access. Unless you have a compelling reason to disable the floppy, leave this setting alone as well. Click Next.
- 10. The wizard asks how the virtual machine should be able to access the network using the screen shown in Figure 6.3. If you plan to keep the Windows VM completely isolated, you can click No networking. If you have an Ethernet card installed and you are on a LAN, use Bridged networking, which lets the virtual machine share your Ethernet card and appear as a standalone computer on the network. Host-only networking allows Samba file sharing between the VM and your Linux PC (provided you installed the VMware Samba server at installation or have one of your own running), and Bridged and Host-only networking combines the two. If you have a LAN, stick with Bridged for now. If you do not, use Host or none. Click Next to reach the final step.

> Even if you don’t install any networking, there is still an easy way to exchange files between your Linux PC and virtual disks. It involves mounting the virtual disk as a Linux-readable file system, and it is covered in depth in Chapter 9, “Using Your Windows 95/98 Virtual Machine.” I personally think it’s easier and more convenient than host-only Samba networking for most file-sharing needs.
