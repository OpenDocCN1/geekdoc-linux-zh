+   11. Enter your name and organization, and click Next. Setup prompts for your license code. Enter it, and then click Next to continue.
+   12. Setup asks which licensing mode you want to implement. This decision is between you and your IT support staff. The decision has no bearing on how VMware functions, only how Windows 2000 Server can support Windows-based clients.
+   13. Setup asks you to define a computer name (choose anything as long as it’s not already in use by another virtual machine) and then to define an administrator password. Enter one and click Next.
+   14. You can select which Windows 2000 Server components should be installed and activated. Don’t rush through this step; an awful lot of functionality is left unselected by default that you might want to use right out of the box. In particular, pay attention to the Internet Information Services (IIS) section, shown in Figure 12.10, which leaves the FTP server unchecked by default. If you want to activate the FTP server, click the IIS entry, click the Details button, and then check the FTP Server option. You might want to do the same for selections in Networking Services, Windows Media Services, or other areas.
+   15. Windows 2000 asks you to set the day and time and time zone. The day and time should be read accurately from your Linux system clock.
