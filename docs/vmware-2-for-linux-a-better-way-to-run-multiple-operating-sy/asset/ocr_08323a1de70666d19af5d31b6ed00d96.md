13. After the reboot, Corel Linux displays five boot choices. You need to type 3 to enter console mode fairly quickly, or else the system boots into graphical mode and you are forced to reboot the virtual machine.

14. Corel Linux works from this point in console mode, but it is in your best interest to install VMware Tools before you go any further. Do not boot Corel Linux in standard mode, or start the KDE desktop environment, before you have installed VMware Tools.

> Most other Linux distributions default to a console mode when they are first installed. Make sure you don’t tell your virtual machine’s Linux to boot to X before you have a chance to install VMware Tools! At best, you’ll get really lousy graphical performance, and at worst you’ll crash the guest session and have to install VMware Tools after sitting through a reboot.

# Installing VMware Tools

Even if you do most of your work at an all-text console in Linux, you should install VMware Tools in the virtual machine before you do anything else:

> The first step of this process is relevant only to Corel Linux because of its unique design. For other Linux distributions, log in as root using the root password you defined during the installation process, and make sure you stay at the console prompt: Do not start XWindows!

+   1. (For Corel Linux.) After booting to console mode for the first time, you are asked to enter the root password. In Corel Linux, you do not define a root password when you first install the system, so just pressing Enter gets you in. See the login in Figure 10.12.
+   2. Prepare to install VMware Tools for Linux by clicking VMware Tools Install under the Settings menu on the VMware window, shown in Figure 10.13. (Remember, you might need to use Ctrl+Alt+Esc to free the keyboard and mouse from VMware’s control.)
+   3. If you want extra reinforcement of these instructions, you can answer Yes when asked whether you want to view the VMware Tools documentation. Close the window when you’re done.
+   4. By clicking VMware Tools Install, you attach a virtual floppy image to the virtual machine. That floppy contains the VMware Tools software. You install that software from the command prompt.
