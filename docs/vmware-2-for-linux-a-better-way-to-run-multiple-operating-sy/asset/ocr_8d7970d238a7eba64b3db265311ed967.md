# Video Cards

More good news if you're the kind of person who likes to keep things simple: If your video card is properly supported in XFree86, you have nothing to worry about. If you have an extremely old video card (with 2MB of video memory or less), you will find your choice of screen resolution rather limited after you install a guest OS, but the limitations are exactly the same as they are in Linux.

The real key is the version of XFree86 you're running. VMware strongly recommends version 3.3.4 or better (version 4 is not yet officially supported, but may work properly). If you're running a VMware-approved distribution of Linux, you have nothing to fear because your distribution incorporates the proper version of XFree86.

> If you're not sure what version of XFree86 your system is running, or you are simply curious, type xdpyinfo at any terminal prompt. The version number appears toward the top of the page in the vendor release number field. The number is returned without periods, so 335 means you have XFree86 version 3.3.5.

In most supported operating systems, a VMware guest OS can use the full SVGA resolution and color capacity of your computer's own graphics card. However, in DOS, Windows 3.1, and unsupported operating systems, VMware only emulates a standard VGA video card, which tops out at a very modest 640×480 screen with only 16 colors! This is good enough for a few basic applications and some games but is hardly impressive to look at.

To fully exploit your graphics card in VMware, you need to be sure to install the VMware Tools in each guest operating system. More information on VMware Tools is coming up in Chapter 8, "Understanding the VMware Tools for Windows."
