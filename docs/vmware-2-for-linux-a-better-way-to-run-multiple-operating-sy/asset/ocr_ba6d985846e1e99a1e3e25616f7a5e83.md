4. Setup can't find any data on your virtual disk, so it assumes it is new or blank (right the first time!), so you don't need to worry about the warning about destroyed data. Press C to continue.

5. You are prompted to read and accept the Microsoft end-user license agreement. Read it, and then press F8 to accept.

6. Using a text-based interface, you can partition and configure your virtual drive. By default, setup creates one large partition on your virtual disk, as shown in Figure 12.8, which is a good configuration unless you have a special need. Press Enter on the partition you want to use for Windows 2000.

7. You can choose between the NTFS and FAT file systems. It is difficult to imagine a scenario where FAT would be useful (normally, NT/2000 partitions are formatted as FAT only if they need to be directly mounted by DOS, Windows 3.1, or early Windows 95 operating systems without using a network). Stick with NTFS.

8. Setup formats the virtual disk, and then starts copying pre-installation files to the drive. (This step takes quite a long time.) After the copying is complete, the virtual machine reboots and starts the graphical portion of the installation, displayed in Figure 12.9. (Don't remove the CD-ROM from the drive.)

9. More waiting ensues as setup uncompresses and sorts through various system files. Eventually, you are asked to click Next. (If you've wandered off, it proceeds by itself after a short wait.) Windows 2000 tries to detect all of your system hardware...which also requires waiting.
