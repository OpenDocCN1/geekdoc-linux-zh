
- 2. Download the VICE source archive from http://www.cs.cmu.edu/~dsladic/vice/vice.html. It should be named vice-1.4.tar.gz, possibly with a newer version number. Place it in a convenient directory. (It can be, but does not have to be, the directory you created in Step 1.)

- 3. Open the archive with tar -xzvf vice-1.4.tar.gz. A new directory, vice-1.4, is created.

- 4. Change to that directory with cd vice-1.4.

- 5. VICE comes with a configure program. If you run configure with no options, VICE sets up to install the VICE emulators to /usr/local/bin. I recommend placing the files in the c64 directory you created in Step 1. Run ./configure --prefix=~/c64 if you want to place the emulators in the new directory from Step 1 or just ./configure if you are content to place the emulators in /usr/local/bin. The screen fills with text while the configuration process runs.

> You might need to use the su command to become root for Steps 6 and 7.

- 6. Type make to begin the compile process.

- 7. Type make install to install the VICE emulators and support files.

## Running Programs in VICE

To launch the emulator, type /usr/local/bin/x64 (or ~/c64/x64). You should see the classic blue-on-blue Commodore 64 startup screen, shown in Figure 18.11.

![](img/b2b6702758c230ce537468351fc8af15_379_0.png)

VICE has a variety of options and settings controlled through two menus—one invoked by left-clicking on the VICE window, the other invoked by right-clicking. Generally speaking, the left-click menu controls floppy disk and cassette tape images (files that contain C64 programs), and the right-click menu controls operational matters, such as the speed of the emulator.

Commodore 64 emulators use the D64 disk image format, which you can find through a variety of emulation sites. To load a disk image, left-click, select Attach Disk Image, Unit 8, and then select the D64 image from the file requester shown in Figure 18.12.

![](img/b2b6702758c230ce537468351fc8af15_380_0.png)

Many disks can be started with the Autostart button on the Attach Disk Image window. To load others, you might need to learn a little about the way the C64 loads and runs programs. Here’s an extremely short tutorial:

To read a C64 disk image directory, type

```
LOAD"*",8
```

and then LIST the results. Or you can use the Contents button on the Attach Disk Image window to look at a disk image’s directory.

To load a particular file, use LOAD"FILENAME",8 and then RUN. Some programs might require LOAD"FILENAME",8,1 instead. In no time, you’ll be off and running classic games, such as Karateka, shown in Figure 18.13.

Joystick support in VICE is controlled through the right-click menu, Joystick Settings. If you don’t have joystick support enabled in Linux, you need to use the numeric keypad arrows and the keypad 0 as the fire button.

The Commodore 64 had low screen resolution—just over 320×200. To create a window easier to see on a large monitor, use the right mouse button menu, Video Settings, Double Size. You might also want to enable Double Scan, to eliminate the black lines Double Size creates. Each step requires additional computing power, however, so you might have to live with the smaller display on a slower computer.

![](img/b2b6702758c230ce537468351fc8af15_381_0.png)

Figure 18.13 Karateka, the forerunner to the classic Prince of Persia, shown running on VICE.

C64 users who remember its unique keyboard layout can re-create the classic key positioning using the right-click menu, Keyboard Settings, Keyboard Mapping Type, Positional Mapping. The emulator uses Symbolic Mapping by default, meaning that the keys you see on your keyboard correspond to what the C64 sees.

Sure, the C64 is dated; that's why some of its most classic games are based around dated themes such as skateboarding. (See Figure 18.14 for proof.) But VICE can provide some low-impact fun when the world of high-tech virtual machines is old hat.

![](img/b2b6702758c230ce537468351fc8af15_381_1.png)

Figure 18.14 VICE is running Skate Or Die from Electronic Arts, from the height of the skateboarding craze of the 80s.
