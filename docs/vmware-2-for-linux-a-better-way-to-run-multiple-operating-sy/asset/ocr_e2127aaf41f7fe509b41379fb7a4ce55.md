# Updating Linux, if Necessary

VMware runs on a wide variety of Linux installations, so it’s fairly likely that if you have kept your system up-to-date, you’re ready to run VMware.

+   - Red Hat Linux 5.x and 6.x
+   - Caldera OpenLinux 2.2 and 2.3
+   - SuSE Linux 6.0, 6.1, 6.2, and 6.3
+   - TurboLinux 6.0

> You should also make sure that the Linux kernel header source code is installed on your system before installing VMware because VMware needs certain Linux source files to build itself.
