
5. 请注意，无需您进行任何干预，也无需在VMware中进行特殊配置，Corel Linux的图形安装程序即可顺利加载。如果鼠标无法工作，请检查您的配置。

> 图形安装程序不错，但因为还不能运行VMware Tools，视频性能会非常非常慢。对于提供选择的Linux发行版，您可能更倾向于基于文本的安装。

> Corel Linux和其他较新的Linux发行版应能自动检测您已配置的任何虚拟以太网适配器，但对于较旧的发行版，如OpenLinux 1.3和Red Hat 5.x，您可能需要手动选择AMD PC/Net 32或PCI NE2100驱动程序。

6. 加载一段时间后，会出现许可协议（参见图10.8）。阅读并点击“接受”。

7. Corel Linux提示您输入用户名。选择一个（您可能希望使用与主机操作系统上常用的相同名称），然后点击“下一步”。

# 安装VMware Tools

即使在Linux中大部分工作都在纯文本控制台进行，您也应该在其他操作之前先在虚拟机中安装VMware Tools：

> 此过程的第一步仅适用于Corel Linux，因为其设计独特。对于其他Linux发行版，请使用您在安装过程中定义的root密码以root身份登录，并确保停留在控制台提示符下：不要启动XWindows！

- 1.（仅适用于Corel Linux。）首次启动到控制台模式后，系统会要求您输入root密码。在Corel Linux中，首次安装系统时并未定义root密码，因此只需按Enter即可进入。参见图10.12中的登录界面。
- 2. 通过在VMware窗口的“设置”菜单下点击“VMware Tools Install”来准备安装VMware Tools for Linux，如图10.13所示。（请记住，您可能需要使用Ctrl+Alt+Esc将键盘和鼠标从VMware的控制中释放。）
- 3. 如果您想要这些说明的额外强化，可以在被询问是否查看VMware Tools文档时回答“是”。完成后关闭窗口。
- 4. 点击“VMware Tools Install”会将虚拟软盘映像附加到虚拟机。该软盘包含VMware Tools软件。您可以从命令提示符安装该软件。
