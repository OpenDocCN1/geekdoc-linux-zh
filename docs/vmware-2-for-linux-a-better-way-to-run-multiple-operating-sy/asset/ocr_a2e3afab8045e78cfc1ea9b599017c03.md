# Installing Windows 2000 Server

Let's shake things up a bit and cover the more complicated OS install first. In the next section, I detail the streamlined portions of the Windows 2000 Professional installation:

> Windows 2000 is a "young" operating system that Microsoft is aggressively patching. If things appear to be drastically different from what's outlined here, consult with a Windows 2000 authority for help.

+   1. If you're not running VMware already, start it by typing /usr/bin/vmware and select your Windows 2000 configuration when prompted, as shown in Figure 12.6.

![](bbox=[0.07, 0.52, 0.48, 0.75])

Figure 12.6 Load your Windows 2000 configuration after starting VMware.

+   2. Insert the Windows 2000 Server, and power on the virtual machine.

> After you start the power to the virtual machine, activate full-screen mode. The Windows 2000 installation is fairly graphical, and graphics render faster in full-screen mode.

+   3. The initial, text-based installation program (see Figure 12.7) scans its own files for device drivers and OS modules and pre-loads the most useful portions. When it finishes, press Enter to start the installation.
