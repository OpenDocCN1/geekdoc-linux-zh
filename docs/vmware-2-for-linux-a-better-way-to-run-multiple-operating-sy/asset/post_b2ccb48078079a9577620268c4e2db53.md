## Figure 18.1 An old-style Amiga desktop running on UAE.

Alternately, you can download the latest version of UAE from the UAE home page, http://www.freiburg.linux.de/~uae. Although the developers issue fair warning that even-numbered distributions might be unstable, in my experience you are usually better off using the latest "developer" release because they tend to update the "stable" release infrequently.

As of this writing, the latest developer release is version 0.8.12. The UAE home page contains both the stable and developer source code libraries. The filenames have the form uae-0.8.12.tar.gz, although the version numbers might be newer by the time you download them. You also may be able to download and use some older pre-built binary files, depending on your system configuration.

Before you can run UAE, at the very least you need to obtain an Amiga ROM code image. The UAE source code package comes with a program called transrom, which you can run on any Amiga to obtain the ROM image. After you install a proper Amiga ROM, you can boot to the Amiga "Kickstart" screen, shown in Figure 18.2.

You also need Amiga software. Because PC floppy drives cannot read Amiga floppy disks, you need to use the transdisk program on an Amiga, also provided, to create disk images in the ADF format. There are also some ADFs available from UAE support sites online.

> You can purchase the Amiga Forever cross-platform package, containing a fully legal, licensed version of AmigaOS software and ROMs, from http://www.cloanto.com. As of this writing, the package is $29.95.

This is the procedure to install UAE from source code:

- 1. Download the source code archive (such as uae-0.8.12.tar.gz) from http://www.freiburg.linux.de/~uae, and place it in a new directory.
- 2. Open the source code archive with the command tar -zxvf uae-0.8.12.tar.gz. This creates a new directory named after the archive.
- 3. Use the cd command to change to the directory that was just created (as in cd uae-0.8.12).
- 4. Before UAE can compile properly, it must collect some information about your system. To start the process, type ./configure at the prompt. A large amount of text scrolls by.
- 5. When the configuration program is finished, type make. UAE is being compiled. Screens full of text scroll by, and the compile process can take several minutes. The program being compiled is called uae and will be stored in the current directory.
- 6. When complete, copy your Amiga ROM images to the same directory as uae. Name the ROM you plan to use most frequently (which will likely be either version 1.3 or version 3.1) kick.rom. This will be the ROM loaded by default the first time you run UAE. For the sake of convenience, you might also want to copy any ADF files to this directory as well or store them somewhere logical.

I don't have space for a complete treatise on the history of the Amiga operating system. Suffice it to say that older games prefer Kickstart version 1.3, but newer games and most modern Amiga productivity software prefer Kickstart version 3.1.

- 7. You are ready to run UAE. Type ./uae to launch the emulator. UAE should load a basic kickstart screen, as well as show you a GUI configuration interface.
- 8. The UAE display will likely appear rectangular and squished. This is normal. For some odd reason, some versions of UAE default to an 800x300 Amiga display. Simply press Save Config on the UAE Control GUI and then quit. You need to edit the UAE configuration file to change the screen size.
- 9. After quitting UAE, edit the newly created configuration file ~/.uaerc. (UAE Control creates this file when you click Save Config.)
- 10. In .uaerc, look for an entry named gfx_height. It should be set to 300. If you believe you have a reasonably fast computer, proceed to Step 11. If your computer is not very fast (under 400MHz), proceed to Step 12.
- 11. With a fast PC, change the entry for gfx_height to 600. Then, change the entry for gfx_linemode from none (the default) to either double or scanlines. (double requires a faster computer than scanlines). Proceed to Step 13.
- 12. With a not-so-fast PC, change the entry for gfx_height to 480. Change the nearby gfx_width entry to 640. Finally, change the entry gfx_correct_aspect to true.

If your computer is conspicuously slow, you might find that you need to go down to 320x200, but it won't look very good. You can also help out a slow computer by reducing the accuracy of the Amiga sound emulation, or disabling it altogether, which is described in the UAE manual.

- 13. You are now ready to run a good-looking Amiga emulation.

If things get really bad and you don't enjoy working with the .uaerc configuration file, you can always bail out, download the Windows version of UAE, and run it in a VMware virtual machine. WinUAE has a friendlier configuration GUI. However, the speed hit from the VMware layer might be more noticeable for Amiga emulation than it is for the Basilisk II Macintosh emulator.
