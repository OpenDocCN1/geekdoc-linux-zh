## Playing Arcade Games with MAME

To launch MAME, use the command

```
/usr/bin/xmame -x11/games/xmame.x11 <ROM name>
```

where <ROM name> is the name of the zip file archive, the .zip suffix, of the ROM archive you placed in the XMAMEROOT directory (such as /usr/games/lib/xmame).

When MAME is up and running and you see the video game demo screen, you need to feed the emulator some virtual quarters. By default, the 5 key feeds quarters (keys 6 through 8 also work if the arcade game had more than one coin slot), and buttons 1 through 4 represent Player 1 through Player 4. Start.

Inside the game, the arrow keys control movement, with the left Ctrl key and left Alt keys being your first two fire buttons.

If you want to adjust the game settings, press the Tab key to bring up the in-game menu. (You might also want to press P to pause the game if you're playing.) See Figure 18.7 for an example of the MAME configuration screen.

![](img/b2b6702758c230ce537468351fc8af15_377_0.png)

Figure 18.9 Loosely inspired by Isaac Asimov's novel, I, Robot is a fun MAME diversion.

Most arcade games do not use a screen larger than 640×480, but if you encounter some that do, you need to increase that value to 800×600 or possibly beyond. At the same time, some older games are 320×200, which is extremely small on a modern desktop and might be hard to see. If you are playing a game that is too tiny to make out on your monitor, set the scale variables to 1.5 or 2 so you have a larger field of play. (This can slow down the emulation somewhat. Many old games can still run at full speed on modern PCs, however, even when their screen size is doubled.)

## Using VICE Commodore 64 Emulator for Linux

Before there was the Amiga, there was the Commodore 64. Remembered primarily as a game computer, the C64 was arguably the most powerful of all the 8-bit computers, and it is the best-selling single computer architecture of all time. (Although there are many, many more PCs in the world, the C64's CPU, graphics and sound, and RAM remained essentially unchanged throughout its entire lifecycle.)

To recapture 8-bit glory on your Linux PC, all you need is VICE, the Versatile Commodore Emulator. It is “versatile” in that in addition to the 64, VICE includes emulators for nearly every 8-bit computer Commodore made in the 70s and 80s, including the Commodore VIC 20 and 128. But the 64 is the real draw. Four VICE emulators make cameo appearances in Figure 18.10.

![](img/b2b6702758c230ce537468351fc8af15_378_0.png)

Figure 18.10 VICE can emulate a slew of machines: clockwise, from upper left, the Commodore 64, the Commodore 128, the Commodore PET, and the Commodore VIC 20

> Commodore 64 emulation requires OS ROMs, much like any other emulation. Because Commodore went bankrupt in 1994 and its intellectual property rights have bounced around the globe, and because 8-bit technology rights in general have only been lightly enforced, emulator authors have taken the liberty of including the Commodore ROM code in their emulators. If this makes you uncomfortable, it is best not to proceed.
