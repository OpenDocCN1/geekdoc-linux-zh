## Sharing Between a Linux Host and a FreeBSD Guest

Because of the strong similarities between Linux and FreeBSD, Chapter 10 tells you just about everything you need to know about sharing data between your Linux PC and your new FreeBSD virtual machine. There are only a few minor technical details you should be aware of.

The major difference in taking stock of your network configuration is that the syntax for FreeBSD's ifconfig command is slightly different. To obtain the right level of detail, type ifconfig -a. Instead of looking for eth0 as you would with a Linux guest, look for ln0.

FreeBSD's default FTP server is among those that automatically deny service requests from users claiming to be root, so you need to either create new user accounts using /stand/sysinstall or other administrative tools or consult FreeBSD documentation to remove the security restriction.

> Even if you don’t install any networking, there is still an easy way to exchange files between your Linux PC and FreeBSD’s virtual disk. It involves mounting the virtual disk as a Linux-readable file system. The process for FreeBSD guests is virtually identical to Linux guests, so see the section of Chapter 10 titled “Mounting a Virtual Disk on the Host” for details.

## Conclusion

FreeBSD offers an interesting alternative to Linux on the desktop. Although the current momentum for end-user software favors Linux, a variety of interesting server and infrastructure applications are uniquely tailored to FreeBSD. As FreeBSD matures, you might be interested in incorporating FreeBSD into your current computing environment, and a VMware virtual machine provides a safe, efficient way to test the marriage.

### DOS Survives, After All These Years

It's been quite some time since the computing world held its breath over the latest incremental release of MS-DOS or thrilled to the cutthroat competition between Microsoft, Digital Research, and IBM for dominance in the text-based operating system market.

Of course, one of Microsoft's worst-kept secrets is that MS-DOS never really went away; it is the core of Windows 95 and 98 and will be the core of Windows Millennium Edition as well. Although most programs are designed these days to take advantage of the Windows "graphical shell," the world is not so removed from DOS as it might seem. I'd say that the sheer volume of software from the DOS heyday is enough reason to set up a little virtual museum on your Linux PC. If that's not enough, I'll point out that some of the software was actually quite good.

Because there are some disappointments in VMware's DOS support (not all of which are VMware's fault), I recommend you familiarize yourself with VMware by first installing and using a Windows or Linux virtual machine.
