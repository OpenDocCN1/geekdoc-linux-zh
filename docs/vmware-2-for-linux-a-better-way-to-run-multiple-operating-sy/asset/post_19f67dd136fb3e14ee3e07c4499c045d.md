## Testing the Installation

Without VMware Tools installed, video performance will be very slow. Still, you can run a couple of diagnostics on the new operating system to make sure everything is running smoothly:

- Check the System Control Panel. Specifically, make sure you see the devices you expect to see, such as a virtual network card and sound card, if applicable. Also look for yellow exclamation points. As you see in Figure 6.19, you might get IRQ conflicts on printer ports because VMware tries to configure all four serial and both parallel ports, even if you don't assign any to the virtual machine. You can safely remove some or all of the unused ports, which should clear up the problem.
- Load a basic included app, such as WordPad, and use it for a few minutes, just to ensure that the operating system is stable. Type a short document, save it, and re-load it.
- If you have bridged networking enabled, use the built-in Telnet or FTP client in Windows to connect with a known address, as shown in Figure 6.20. If you're using host-only networking, open Network Neighborhood and verify that you can see your Linux PC.

## Installing VMware Tools

When you're satisfied that Windows 98 is running as it should, take the time to install VMware Tools. You'll get much better graphics performance, as well as the ability to share the clipboard between Linux and the Windows VM.

> Because you need to access the VMware window toolbar, you'll need to do this operation in windowed mode, not full-screen mode. Remember, use Ctrl+Alt+Esc to return to windowed mode.

- 1. Start with a clean reboot of the Windows 98 virtual machine.
- 2. On the VMware application window, select Settings, VMware Tools Install. (See Figure 6.21.)
- 3. If this is your first time installing VMware Tools, you might want to take the opportunity to read the online help when prompted.
- 4. VMware has temporarily mounted a special virtual floppy disk image in the Windows 98 virtual machine. Go to My Computer and double-click the Floppy icon to open the image.
- 5. Double-click the VMware Tools icon, shown in Figure 6.22.
- 6. VMware Tools installs with a standard wizard, shown in Figure 6.23. Accept the default settings and proceed with the installation.
