## Adjustments with the Configuration Editor

The wizard is reliable, but not thorough. You should make a quick stop in the Configuration Editor to make a few minor adjustments before you launch the virtual machine and start the Windows installation:

- 1. Open the Configuration Editor in the Settings menu.
- 2. Verify that the wizard created a primary master (P-M) IDE virtual disk in the Win 98 configuration directory of the size you created (it might appear to be one megabyte less than you specified) and a secondary master (S-M) CD-ROM, most likely pointing to /dev/cdrom.

> You might want to come back later and reassign /dev/cdrom to be a virtual SCSI CD-ROM drive, but because VMware does not support booting from a virtual SCSI CD-ROM and the Windows 98 boot floppy does not support the VMware SCSI controller, you need the CD-ROM in virtual IDE mode to install Windows 98.

- 3. If you want the virtual machine to have direct access to your serial or parallel ports, configure them now as described in Chapter 5, "Running VMware for the First Time." Remember that serial ports start at /dev/ttyS0 and parallel ports start at /dev/lp0 on most Linux machines.
- 4. If your Linux PC has sound configured and running and you want the virtual machine to have sound access, click the Sound option and then click Install in the sound configuration window, shown in Figure 6.5.

![](img/b2b6702758c230ce537468351fc8af15_108_0.png)

- 5. If the wizard's memory suggestion seems inappropriate (VMware usually suggests 48MB for Windows 98, unless you have less than that available for virtual machines), you can increase or decrease it in the Memory setting (see Figure 6.6). A setting of 64MB is comfortable for Windows, but more is better. Try not to dip below 32; if you don't have 32MB comfortably available for Windows 98, you might want to consider switching to Windows 95.

![](img/b2b6702758c230ce537468351fc8af15_108_1.png)

You can change VMware's suggested RAM allocation, but don't exceed your total allowed for all virtual machines, usually no more than 64MB less than your computer's total.

- 6. You might want to make changes in the Misc settings list. It might make sense to enable APM suspend right away, although the other options are best left alone until the operating system is installed and working properly. You could assign the redo log directory (say, to a safe place on your system drive) if you plan to use undoable or nonpersistent disks in the near future.
- 7. Click Save when finished in the Configuration Editor.

## Installing Windows 98

Your virtual machine should be ready to run the Windows 98 installation program. Windows 98 CD-ROMs are autobooting and VMware virtual machines can boot from virtual IDE CD-ROMs, so you should have no need for the boot floppy that comes with some copies of Win 98.

> Again, remember that even if your real CD-ROM is SCSI, it can be made to look like an IDE CD-ROM to the virtual machine.

- 1. If you're not running VMware already, start it with /usr/bin/vmware, and select your Win 98 configuration from the window shown in Figure 6.7 when prompted.
- 2. Insert the Windows 98 installation CD. If the virtual machine doesn't start with the CD connected, connect it now.
- 3. Click Power On to launch the virtual machine. The virtual machine boot screen, shown in Figure 6.8, should appear.

![](img/b2b6702758c230ce537468351fc8af15_109_0.png)

- 4. Two text menus appear. On the first, select to boot from CD-ROM rather than Hard Disk, and then select to Start Windows 98 Setup from CD-ROM from the second menu, shown in Figure 6.9.
