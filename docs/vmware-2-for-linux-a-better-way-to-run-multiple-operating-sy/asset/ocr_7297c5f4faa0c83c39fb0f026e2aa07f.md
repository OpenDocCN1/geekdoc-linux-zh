Although it is possible to add a raw disk to your system from the Configuration Wizard, I recommend that you either edit an existing virtual machine configuration or complete the wizard and then go back and use the Configuration Editor to create the raw disk.

+   1. Open the virtual machine configuration in the Configuration Editor.
+   2. Find a free slot in the IDE or SCSI Drives section.

If you plan to boot from your raw disk, it is a good idea to use the Primary IDE (P-M) slot.

+   3. Set the Device Type to Raw Disk.
+   4. Type a name for your raw disk in the Name box. This will be the name of the “safe raw disk,” a small file stored in your VMware configuration directory that describes the layout of your hard drive to VMware. At this point, your screen should look much like Figure A.1.
+   5. Click Create Raw Disk. A new window should pop up, prompting you for the device name of the hard drive you want to use for the raw disk.
+   6. Type the name of the hard drive you want to use. Normally, this will have the form /dev/hda (where a can be b, c, d, or possibly higher) for IDE drives or /dev/sda (or sdb, sdc, and so on) for SCSI devices.
