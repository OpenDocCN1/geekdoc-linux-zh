I don't have space for a complete treatise on the history of the Amiga operating system. Suffice it to say that older games prefer Kickstart version 1.3, but newer games and most modern Amiga productivity software prefer Kickstart version 3.1.

+   7. You are ready to run UAE. Type ./uae to launch the emulator. UAE should load a basic kickstart screen, as well as show you a GUI configuration interface.

+   8. The UAE display will likely appear rectangular and squished. This is normal. For some odd reason, some versions of UAE default to an 800x300 Amiga display. Simply press Save Config on the UAE Control GUI and then quit. You need to edit the UAE configuration file to change the screen size.

+   9. After quitting UAE, edit the newly created configuration file ~/.uaerc. (UAE Control creates this file when you click Save Config.)

+   10. In .uaerc, look for an entry named gfx_height. It should be set to 300. If you believe you have a reasonably fast computer, proceed to Step 11. If your computer is not very fast (under 400MHz), proceed to Step 12.

+   11. With a fast PC, change the entry for gfx_height to 600. Then, change the entry for gfx_linemode from none (the default) to either double or scanlines. (double requires a faster computer than scanlines). Proceed to Step 13.

+   12. With a not-so-fast PC, change the entry for gfx_height to 480. Change the nearby gfx_width entry to 640. Finally, change the entry gfx_correct_aspect to true.

If your computer is conspicuously slow, you might find that you need to go down to 320x200, but it won't look very good. You can also help out a slow computer by reducing the accuracy of the Amiga sound emulation, or disabling it altogether, which is described in the UAE manual.

+   13. You are now ready to run a good-looking Amiga emulation.

If things get really bad and you don't enjoy working with the .uaerc configuration file, you can always bail out, download the Windows version of UAE, and run it in a VMware virtual machine. WinUAE has a friendlier configuration GUI. However, the speed hit from the VMware layer might be more noticeable for Amiga emulation than it is for the Basilisk II Macintosh emulator.
