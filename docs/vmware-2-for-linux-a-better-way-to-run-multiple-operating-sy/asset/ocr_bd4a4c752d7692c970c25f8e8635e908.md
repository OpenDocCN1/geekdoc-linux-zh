Tips for document portability and sharing follow:

+   - When swapping image files, be sure to use a non-lossy format such as TIFF or BMP. Only save files as JPEGs when you're sure you don't have any more work to do, and even then save a non-lossy version of the same picture first, just in case.
+   - LZW-compressed TIFF is the best intermediate format most of the time, but in The GIMP, be sure to save files as MSB to LSB (most significant bit to least significant bit), not the other way around, because some Windows programs have trouble with the default format.
+   - If you use Photoshop for Windows, download the psd2 plug-in from The GIMP's home page (http://www.gimp.org). psd2 lets you load Photoshop layered project files. Another plug-in, psd save, can save GIMP projects in the same format.
+   - As with word processing, don't force yourself to use a Linux tool when one in a Windows virtual machine will do the job faster and easier. The end result can be enjoyed by all.
