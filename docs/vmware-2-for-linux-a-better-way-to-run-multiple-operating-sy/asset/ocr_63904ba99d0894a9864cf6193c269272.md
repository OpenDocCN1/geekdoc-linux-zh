10. The wizard asks how the virtual machine should be able to access the network (see Figure 7.4). If you plan to keep the Windows VM completely isolated, you can click No networking. If you have an Ethernet card installed and your PC is on a LAN, use Bridged networking, which lets the virtual machine share your Ethernet card and appear as a standalone computer on the network. Host-only networking allows Samba file sharing between the VM and your Linux PC (provided you installed the VMware Samba server at installation or you have one of your own running), and Bridged and host-only networking combines the two. If you have a LAN, stick with Bridged for now. If you do not, use Host or none. Click Next to reach the final step.
