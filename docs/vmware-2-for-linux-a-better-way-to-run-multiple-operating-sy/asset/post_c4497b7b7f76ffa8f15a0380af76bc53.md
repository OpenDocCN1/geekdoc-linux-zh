
Depending on the virtual machine's configuration, the program might not be in your default path. If you need to use the whole path, type
`/usr/X11R6/bin/vmware-toolbox &`.

You should start VMware Tools every time you run your Linux virtual machine and leave it open for the entire session. When you get comfortable, you might want to consider adding the command to your Linux or XWindows startup script.

The VMware Tools window in Linux is virtually identical to the Windows version, and like the Windows version, it offers certain functions not available from any other settings menu.

## Managing Virtual Devices

VMware Tools (see Figure 10.17) provides more convenient access to the Devices settings also found in the VMware window toolbar. In full-screen mode, the toolbar is inaccessible, making VMware Tools the only way to attach and release devices without dropping back to windowed mode with Ctrl+Alt+Esc.

This screen controls four types of virtual devices:

- RTC, the Real Time Clock. All PCs have an RTC device, but VMware has to share the benefits of good timekeeping. Normally, you should leave this setting alone. (In other words, leave the virtual machine attached to the RTC.)

- Floppy drives, normally starting at floppy0. Unless you have a stubborn mounted floppy that isn't going away, you shouldn't need to use this setting.
- IDE or SCSI-connected CD-ROMs. Because of the way Linux (both the host and the guest!) handles CD-ROMs, you might not be able to eject or unmount a CD-ROM in some circumstances. > Input focus: Determines whether a virtual machine or the host Linux OS captures mouse and keyboard input. When you type into a VMware-hosted OS and application, VMware is said to have input focus.

### Using the Toolbox Options

The Options tab, shown in Figure 10.18, helps you fine-tune VMware's input focus settings.

1. Select an option to enable it.
2. Release input focus when the mouse leaves the virtual machine.
3. Capture input focus when the mouse enters the virtual machine.
4. Hold center when the virtual machine loses input focus.
5. Bring the virtual machine to top when a get input focus.
6. Allow copy and paste to top when a get input focus.

## Scroll When Mouse Nears Edge

You only need to worry about the feature Scroll when mouse nears edge if you have a situation where your virtual machine’s desktop is larger than the VMware window on your Linux desktop. This could happen if you temporarily make the VMware window smaller or if you are using a virtual machine desktop larger than your computer can display (a 1,280×1,024 Linux desktop on a Linux PC whose desktop is only 800×600, for example).

> If you want to be able to change the size of the VMware window on-the-fly, you need to disable Autofit under View on the VMware window settings. Note that this does not affect the size of the guest operating system’s desktop itself, just how much you can see at once.

## Hide Cursor

The option Hide cursor is nothing more than a glorified “mouse blanker,” but it can help avoid the confusion of seeing two mouse pointers on the same screen. When it is enabled, the mouse pointer in the virtual machine disappears if the input focus is on the host rather than VMware.

> If you turn this option off, the guest’s pointer remains visible wherever it was when you changed the input focus back to the host. If you turn away from the screen and then turn back, you might get confused about which is the active mouse pointer until you actually start moving the mouse.

## Bring the Virtual Machine to Top

The option Bring the virtual machine to top is turned off by default. When on, it immediately brings the VMware window to the foreground whenever VMware is given the input focus. You might want to turn this on if you have a cluttered desktop and it might be difficult to move the VMware window to the top yourself.
