## Installing Peripheral Support

Unlike Windows, Linux, and FreeBSD, DOS doesn't make any appreciable effort to detect and configure devices connected to the virtual machine. Therefore, you need to spend a few minutes tightening up the DOS configuration files before you have a 100 percent working installation.

> Throughout the rest of the chapter, I advocate using a DOS-formatted floppy to transfer small files to the virtual machine. If you want to copy files to floppy while VMware is running, you need to use the Devices menu on the VMware window to disconnect the floppy when you plan to write to it from Linux. Reconnect the floppy to VMware when you want DOS to read from the disk.

## Installing a CD-ROM Driver

You can be forgiven if you've been spoiled by the easy CD-ROM access provided in Linux and Windows and by how easy it's been to get virtual machines to see your CD-ROM drive. But back in the DOS days, it wasn't quite load and go. You have to install and configure a CD-ROM driver, but the good news is that it's easy to do.

> If you run DR DOS, this installer does not work properly. You can either extract and install the driver manually (the VMware documentation will help you) or rename the file c:\drdos\nwcdex.exe as c:\drdos\mscdex.exe.

- 1. On your Linux host, browse to http://www.mitsumi.com/enduser/1_drivers.html and download the file ide158.exe.
- 2. Transfer the file to the DOS virtual machine. Because the file is small, I recommend using a DOS-formatted floppy and using the common Linux MS-DOS disk access tools to copy the file. On most systems, typing mcopy ide158.exe a: at a Linux shell prompt does the trick.

> You could also mount the virtual DOS disk and copy the file that way using the vmware-mount.pl program as described in Chapters 9, “Using Your Windows 95/98 Virtual Machine,” and 10, “Installing Linux on VMware.”

- 3. Start the virtual machine. If the file is still on a floppy, copy it to a working directory, such as c:\vmware.
- 4. Run the program ide158.exe from the DOS virtual disk. An automatic file decompressor will run.
- 5. Run the program setupd.exe. A text menu should appear asking you to select a language.
- 6. The main CD-ROM installer window should appear (see Figure 14.10). Select Begin Installation.
- 7. You can safely accept the default when prompted for an installation directory.
- 8. After the installation finishes, reset the virtual machine. The CD-ROM driver is now active on drive D:.

When the reboot is complete, you should see new CD-ROM-related information in the DOS startup messages. To test the driver, simply insert a CD-ROM into the drive and type dir d: at the DOS prompt. Sample output is shown in Figure 14.11.

## Installing Networking Support

Whenever possible, stick with swapping floppies and mounting the DOS virtual disk in Linux to transfer files. But if you want to get adventuresome, it is possible to do real networking on a DOS virtual machine.

LAN and Internet access under DOS is not an exact science, and the various tips, tricks, pitfalls, and workarounds could fill a book. If you plan to get serious about using network applications under DOS, you should visit http://www.tdisk.com and http://www.oldskool.org/~tvdog/internet.html. They both have comprehensive information on DOS Internet tools and configuration tips.

You can use a modem for SLIP or PPP access in DOS, but it's quite tricky. You need to make sure the virtual machine's COM1 is active. The Tvdog site will help guide you, but I recommend you let your Linux PC bear the brunt of your dial-up modem work.

The virtual Ethernet card requires a driver before it can run in DOS. You can download the PCNet Family packet driver from http://www.amd.com/products/npd/software/pcnet_family/drivers/pktdrv.html, or check out the /AMD NIC Drivers directory on the CD included with this book.

For some perverse reason, AMD has taken to archiving DOS programs with a program that requires Windows to decompress them. As such, you might find it rather frustrating just to get at the software you need to install networking. You need the services of a real Windows PC or a Windows virtual machine you can easily start and transfer programs from.

Here's the procedure:

- 1. Obtain the pktdrv.exe program from AMD or this book's CD, and uncompress it in a Windows virtual machine or on a Windows PC.
- 2. Copy the resulting programs to a floppy.
- 3. Load your DOS virtual machine and create a new directory, C:\AMD.
- 4. Copy the uncompressed files to the new directory on the virtual disk.
- 5. When you want to activate the Ethernet driver, type pcntpk.com int=0x60 from the C:\AMD directory.

> If you decide you want Ethernet access to load automatically when you start DOS, add the line c:\amd\pcntpk.com int=0x60 to the autoexec.bat file.
