# Speed Is King

Raw power is important for a happy virtual machine experience. In most cases, you have just one CPU in your machine. When two or more operating systems start making demands on it, things can get hairy if it doesn't have enough juice to go around.

VMware recommends a Pentium II processor at 266MHz as a good functional minimum. Will VMware run on less? Yes. Will you want to be there when it does? Probably not.

As an extremely rough rule of thumb, ask yourself, "Would I be happy running both my main Linux system and my guest OS at half of the current speed of my CPU?" Because it is unlikely that both VMware and your host OS will be making equal demands on the CPU at the same time, this scenario is unlikely, but it should give you some sort of idea.

If the answer is "no" or even "maybe," think about a system upgrade. At the time of this writing, reputable dealers are selling new motherboard and CPU combinations with 500+ MHz AMD K6-2 and Intel Celeron processors for under $200. Complete, prebuilt systems with those specifications are coming in at well under $1,000.

That sort of speed should be enough to comfortably run Linux along with most VMware guest operating systems. If you know that you plan to run some CPU-intensive tasks in a virtual machine, up the stakes. Gigahertz processors are now a reality, after all.
