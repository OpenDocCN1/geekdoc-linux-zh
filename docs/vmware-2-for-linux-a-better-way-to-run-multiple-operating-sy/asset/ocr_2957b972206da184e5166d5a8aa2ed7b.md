> Don’t configure a drive in a slave slot unless there is a master as well, or virtual machine disk access might be erratic or completely non-functional. This doesn’t work well in a real machine, either.

At this stage of the configuration, you can designate a virtual disk to run in one of the special protected modes, either nonpersistent or undoable. Click the Mode tool and select the new level of protection. The VMware Configuration Wizard always configures new virtual disks as persistent because that is the most useful type for most situations.

> The Shrink button isn’t useful right now, but it will be later if you use an officially-supported guest OS. Although virtual disks grow as they are used, they can’t automatically shrink when you delete data. Using the Shrink tool in conjunction with VMware Tools can cut the unused space in virtual disks back down to size.

The IDE configuration window also enables you to create raw or plain disks, which are covered in Appendix A, “Advanced VMware Configuration.”
