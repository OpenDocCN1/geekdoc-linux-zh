If you decide on Windows 98, you're not done. Should you use Windows 98 or Windows 98 SE (Second Edition)? If you have the choice, I recommend sticking with the original Win 98. Aside from some bug fixes and Year 2000 corrections, most of the extra functionality in Win 98 SE is either of questionable value in the virtual machine or easy to add on to Windows 98.

It is foolish and impractical to use a virtual machine Win 98 SE's Internet Connection Sharing as an Internet gateway for a LAN: Such a task is much better suited to the host Linux OS on your PC, or even better, a standalone server or network device. Enhanced USB support is meaningless in a virtual machine that doesn't support direct access to USB and is not likely to in the near future. And Win 98 SE standard software such as Internet Explorer 5 and the Y2K bug fixes are all available free from Microsoft's Web site, if you feel the need to update Windows 98 original.

# Preparing the Virtual Machine

If your mind is made up, it's time to prepare a virtual machine custom-tailored for Windows 98.

> This installation sequence assumes you are using a Windows install disk labeled "For distribution with a new PC only" or similar. There are some minor differences in upgrade editions.

# Starting with the Wizard

Any new VMware virtual machine should start with the Configuration Wizard.

+   1. If you're not already in VMware, start the main program with /usr/bin/vmware at a command prompt.
+   2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
+   3. Click Next to clear the first greeting screen.
+   4. Select Windows 98 from the list of guest operating system choices, shown in Figure 6.1, and then click Next to proceed.

> If you have an upgrade edition of Windows 98, you should select the operating system you will first install, and at each upgrade stage, edit the Guest OS setting in the Configuration Editor before proceeding. If you have to upgrade from DOS to Windows 3.1 to Windows 95 to Windows 98, however, this might be so mind-numbing that it is worth your while to buy a fresh copy of Windows 98 and install it directly.
