> Commodore 64 emulation requires OS ROMs, much like any other emulation. Because Commodore went bankrupt in 1994 and its intellectual property rights have bounced around the globe, and because 8-bit technology rights in general have only been lightly enforced, emulator authors have taken the liberty of including the Commodore ROM code in their emulators. If this makes you uncomfortable, it is best not to proceed.

# Installing VICE for Linux

Getting VICE to run on your Linux PC requires a little bit of planning and a brief foray into the world of source code makefiles, but the VICE developers make it reasonably painless.

+   1. Create a new directory for the VICE emulator and the various C64 files. I suggest a directory named c64 off your home directory, as in /home/jcompton/c64. You can use the command mkdir ~/c64.
