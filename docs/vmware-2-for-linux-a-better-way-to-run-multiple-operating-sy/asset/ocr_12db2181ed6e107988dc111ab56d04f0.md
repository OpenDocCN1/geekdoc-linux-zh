# Adjustments with the Configuration Editor

The wizard is reliable, but not thorough. You should make a quick stop in the Configuration Editor to make a few minor adjustments before you launch the virtual machine and start the Windows installation:

+   1. Open the Configuration Editor in the Settings menu.
+   
+   2. Verify that the wizard created a Primary Master (P-M) IDE virtual disk in the Linux configuration directory of the size you created (it might appear to be one megabyte less than you specified) and a Secondary Master (S-M) CD-ROM, most likely pointing to /dev/cdrom.

> You might want to come back later and reassign /dev/cdrom to be a virtual SCSI CD-ROM drive, but because VMware does not support booting from a virtual SCSI CD-ROM drive, your best bet is to install from a virtual IDE CD-ROM.
