> Windows NT 在重新启动时可能需要很长时间。虽然它有时会在重新启动过程中挂起，但你应该在放弃并在 VMware 中执行硬重置或电源循环之前，至少等待 4 到 5 分钟且没有磁盘活动。（不要重置你的 Linux 计算机；只需在 VMware 中使用重置和电源工具。）

## Windows NT Setup

- Windows NT needs to install the complete network adapter
- Enter complete adapter for a network
- Select the network
- Your computer is connected to a network by an Ethernet adapter
- Your computer is connected to a network by a dial-up adapter
- Your computer uses a modem to connect to a network

![](img/b2b6702758c230ce537468351fc8af15_230_0.png)

Figure 11.11 Add an AMD PCNET adapter manually if Windows NT does not detect all of the virtual Ethernet cards you specified in the Configuration Wizard or Configuration Editor.

21. Windows NT 会自动配置 TCP/IP 网络，这对于常见的网络任务，包括你可能进行的所有文件共享来说已经足够了。如果你计划集成到 IPX 网络或需要 NetBEUI，请启用这些选项并点击 Next。

22. 如果你配置了任何网络适配器，在 NT 网络设置完成之前会看到一个特殊的配置窗口。图 11.12 显示了此窗口。点击 10Base-T Port 并点击 Continue 返回到安装程序。

![](img/b2b6702758c230ce537468351fc8af15_230_1.png)

Figure 11.12 The virtual Ethernet card has its own small configuration tool.

23. 如果你配置了第二个网络适配器，另一个配置窗口会出现（见图 11.13）。将所有设置保持原样（10Base-T 端口选项除外，应勾选），然后点击 Continue。

![](img/b2b6702758c230ce537468351fc8af15_230_2.png)

Figure 11.13 If you use a second virtual Ethernet card, a larger configuration window appears.

24. 当提示关于 DHCP 时，如果你使用的是仅主机网络或你的局域网使用 DHCP（用于桥接网络），请选择 Yes。你可以随时稍后更改设置。

25. Setup 安装各种驱动程序，然后要求启动网络。如果你计划使用 Samba 文件共享（无论是通过仅主机网络与你的 Linux PC 还是与“真实”的 Windows PC），请确保 Workgroup 字段匹配。（对于仅主机，WORKGROUP 是默认设置。有关更多信息，请参阅附录 B。）除非你将此虚拟机用于真实的 Windows NT Server 网络，并且你非常确定自己知道自己在做什么，否则不要使用 Domain 设置。完成后点击 Next。

26. 点击 Finish 完成安装。你将被要求设置日期、时间和时区。

27. 显示属性窗口出现。保留默认值（640×480，16 色）；你可以通过稍后安装 VMware Tools 来改善这种情况。

28. 在大量磁盘活动之后，setup 会要求你取出 CD-ROM 并点击重新启动计算机。请记住，在你能够弹出光盘之前，可能需要从 VMware 中断开 CD-ROM 并在 Linux 中手动卸载 CD。确保在取出 CD 后重新连接 CD-ROM，以便你可以读取其他光盘，然后点击 Restart。

29. 当 NT 启动菜单出现时，按 Enter 选择顶部（默认）设置。在 NT 闪屏出现后，按 Ctrl+Alt+Del 登录，然后输入你在安装过程中分配的管理员密码。
