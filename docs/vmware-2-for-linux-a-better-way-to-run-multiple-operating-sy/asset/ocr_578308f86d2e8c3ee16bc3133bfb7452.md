+   - If you do need to save to a proprietary format, such as Microsoft Word, save in the earliest version possible that preserves all the formatting. Filters are generally more accurate, the farther back you go.
+   - Keep your Linux office suite up to date! Both commercial and open-source Linux productivity programs tend to be updated quite frequently. That can help you match the features and capabilities of Windows DTP programs.
+   - Unless you’re specifically designing a Web page, don’t use HTML as an intermediate format between word processors or between a word processor and a Web design program. Different programs have different ideas of how to import and re-interpret HTML formatting codes.
+   - When necessary, fold. Windows under VMware can access your Linux printer as though it were attached directly to a Windows PC. If a document just doesn’t look right in a Linux word processor, there’s no shame in sticking with your Windows virtual machine.

# Sharing Images

Fortunately, graphics formats are an open book compared to word processor file layout. You should have no trouble whatsoever swapping high-resolution, 24-bit color images with impunity between a Linux image editor and Windows graphics software.

Why do such a thing? Well, the field of computer graphics is decades old, and there is still no such thing as the "perfect" program. Linux’s best-known image editor, The GIMP, is loaded with features, as is Adobe Photoshop for Windows. Then other Windows programs, such as Paint Shop Pro, offer a large feature set at a fraction of Photoshop’s price and with (arguably) a much cleaner interface than The GIMP and Newtek’s Aura, which focuses on special effects and animation.

Aside from having unprecedented freedom to use the right imaging tool for the job (and as many tools as you see fit), there is a more pragmatic reason you might need to put both Linux and Windows through VMware to work on an imaging project.

Because VMware cannot see scanners over a SCSI interface, you need to use scanning software such as SANE (Scanner Access Now Easy) if your flatbed scanner uses SCSI rather than the parallel port. VMware can see some parallel port scanners, so you might be able to use standard Windows drivers for those.
