![](bbox=[0.05, 0.09, 0.18, 0.22])

In some configurations of the Linux host operating system, changing CD-ROMs might not work properly. If this happens, disconnect and then reconnect the CD-ROM device using this menu.

The RTC entry has only Disconnect. There is no reason why you should need to disconnect the RTC in normal operation; this option is mostly a debugging tool.

![](bbox=[0.05, 0.31, 0.18, 0.43])

If the RTC is disconnected or otherwise unavailable to a Windows 98 guest, it may not be able to keep time properly in that virtual machine. The Sync Time option in VMware Tools can fix this problem.
