eth0 is the standard designation for the first Ethernet card in your host PC. (If you have multiple Ethernet cards, look at the one responsible for your main LAN or Internet connection.) There’s a mass of information there, but you’re only interested in one entry: inet addr. There it is; that’s your Linux PC’s IP address. (In this case, my computer is located at 192.168.20.2.) That is the address a virtual machine using bridged networking needs to point at.

vmnet1 is a virtual Ethernet card used to connect to virtual machines running host-only networking. You only have a vmnet entry if you opted to install the host-only networking components when you installed VMware. Again, there is a bunch of spurious information; all you care about is inet addr. Mine is 192.168.71.1.

Note that the IP address for the host-only vmnet “virtual card” is notably different from the IP address in use by your real Ethernet card. That’s by design: VMware looks for an unused range of addresses that can be devoted entirely to virtual machine host-only networking. Other computers on your LAN or the Internet will not be able to access your computer over the vmnet interface; only virtual machines configured for host-only networking can see it.

Remember, the IP addresses in this book are just examples. Yours might wind up looking similar or substantially different, depending on your network configuration. What is important is to note which entry refers to which type of networking, so when you execute these commands on your computer, you recognize the pattern and can apply the information here to your unique situation.

Next, run `/sbin/ifconfig` on your virtual machine.

Things are just a little more complicated on the virtual machine side because if you run both host-only and bridged networking, they both show up as eth-style devices. But because you know the IP addresses assigned to your host PC’s real Ethernet card and the virtual vmnet adapter, sorting things out is a snap.

If you use both host-only and bridged networking, the virtual machine appears to have two Ethernet cards.

If you use host-only networking and properly installed the host-only Samba and DHCP components, the virtual machine should be able to automatically grab an IP address from the DHCP server running on your host PC. That address starts in the same family as the address for the vmnet1 adapter (in the example, 192.168.71) and then counts up starting at .128 for the first virtual machine.
