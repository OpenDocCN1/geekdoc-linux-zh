
DR DOS 7 is arguably better than MS-DOS: Its memory requirements are lighter, it supports multitasking, and it has a nice configuration program. If you're serious about using DOS, I recommend you investigate it.

> Some VMware customers report success using IBM's PC DOS 2000, available for sale online direct from http://www.ibm.com.

## Installing the DOS Core

If you have a set of original (non-"upgrade") MS-DOS disks, getting started is as simple as inserting Disk 1 and starting the installation. Upgrade versions require that an operating system be installed on a disk before they work; you need to find some way (possibly using a Windows virtual machine and mounting the virtual disk as a secondary drive) to get a preliminary version on the virtual disk before starting the upgrade.

Some older CD-ROM distributions of DOS (such as those that came with retail PCs) might not be able to boot from CD-ROM to start the installation process. You might need to use a boot disk that offers CD-ROM support, such as the one that accompanies Windows 95 and 98.

Because of the disparity in DOS versions, there is no single "authoritative" installation. Because MS-DOS is generally familiar and well understood, I walk through and illustrate installing DR DOS 7 from CD-ROM. You might have to find your own way, depending on the version and distribution of DOS you wind up using:

- 1. Boot the virtual machine with the DR DOS 7 CD-ROM inserted.
- 2. You should see an error message before you reach the DOS prompt because there is no usable hard drive yet. You need to partition and format the virtual disk. Run fdisk.
- 3. You should see a prompt asking to initialize the disk. Answer Yes.
- 4. Choose option 4, Select alternate fixed disk from the screen shown in Figure 14.3.
- 5. Select option 1, Create Partition. Create a DOS primary partition, and let fdisk use all the available space.

> DR DOS's fdisk insists on verifying all the disk blocks, which is time-consuming. It does automatically format the disk as part of the process, which is nice.

- 6. After it finishes, exit fdisk and reset the virtual machine. Leave the CD-ROM in the drive.
- 7. The installation process starts, as shown in Figure 14.4.
- 8. Select Continue with installation.
- 9. Read and then accept the DR DOS license.
- 10. Enter your name, organization, and serial number if applicable.
- 11. Some versions of DR DOS 7 come with a Novell NetWare-ready networking system. It takes up little space. You should accept the defaults from the screen shown in Figure 14.5 and continue.
