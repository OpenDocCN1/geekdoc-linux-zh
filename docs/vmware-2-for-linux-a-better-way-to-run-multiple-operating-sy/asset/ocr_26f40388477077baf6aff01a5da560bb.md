# Managing Virtual Disks

Remember: Virtual disks are great because even though they can have the potential to store up to 2GB of data, they only take up as much space on your Linux PC's hard drive as you put into them.

That's only part of the story, however. Although it's true that the virtual disks grow as more data is added to them, they don't get smaller as you take data away. If you filled your virtual disk to bursting and then deleted 90 percent of its contents, you would wind up with a virtual disk that takes up the full 2GB even though only a few files are actually stored there.

VMware Tools can help you reclaim space on your hard drive. The process is not dissimilar to disk defragmentation, which sorts and re-orders the data on a disk, eliminating wasteful zones where deleted material lives.

The VMware shrink process not only sorts the data, but also it reduces the size of the virtual disk file by cutting out unused space.

> Virtual disks can also be defragmented inside the virtual machine. This can give you a modest performance boost if the disk has become cluttered, but it does not shrink the physical size of the disk on your host hard drive.
