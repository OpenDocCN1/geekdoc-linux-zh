However, just because a device works in Linux does not necessarily mean that it will work in a VMware virtual window. Some hardware that works under Linux is only indirectly supported in VMware, and others simply don't work at all.

> VMware Hardware Compatibility Rule #2: Just because hardware works in Linux does not necessarily mean it will work in VMware, and if it does work, it might not be directly supported.

Here's a more complete look at VMware-friendly hardware.

# Mice

In general, almost any common PS/2 or serial mouse you can easily attach and use in Linux will work just fine in VMware. Specifically, mice that adhere to the PS/2, Microsoft serial, Mouse Systems, Logitech MouseMan Serial, or Microsoft IntelliMouse PS/2 standards are supported. VMware limits you to a standard two- or three-button mouse inside the virtual machine; however, wheel or scroll mice are not supported in VMware, even if you manage to enable the wheel in Linux. The wheel can act as a third button when clicked, however.

# Keyboards

The news for keyboards is much the same as it is for mice: If it's a standard, Linux-supported keyboard (as most are), you won't have any difficulties. VMware emulates a 101/102 key keyboard, although some of the extra features found on "multimedia" keyboards can be supported if you have the proper drivers for the guest operating system.

> In some more esoteric environments, VMware might have trouble recognizing your keyboard. If you are using the recommended XFree86 video software but VMware can't see the keyboard, you need to edit the file ~/.vmware/config (the VMware configuration file on your local machine, in your user directory), and add the following line:

```
xkeymap.uskey codeMap = true
```

If your PC is accessing a remote XFree86 video server, add the following instead:

```
xkeymap.uskeycodeMapIfXFree86 = true
```
