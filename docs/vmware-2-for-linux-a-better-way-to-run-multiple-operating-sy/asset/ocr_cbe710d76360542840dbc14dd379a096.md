On a real computer, you would have the option of shutting off your CPU's caches to slow down the works, but because you are sharing the CPU between VMware and your host Linux OS, this is not possible. VMware's BIOS does not include a cache disable option, and it is not recommended to try using a cache shutoff program in DOS or Windows. You can use other tricks to slow down your virtual machine to deal with an old game, but your options are more limited because you do not want to cripple the host in the process.

# The Good News: Games That Work

So, what's left? Only thousands of games! No, perhaps not all your favorites, but probably enough to keep you entertained on a fair number of Sunday afternoons.

If you have a large stock of games already in your library, simply experiment. Install them, and try launching them. At the absolute worst, an incompatibility problem might lock up the guest OS, requiring you to manually power down the virtual machine. More likely, the game will simply refuse to run or crash back to the DOS prompt or Windows desktop.
