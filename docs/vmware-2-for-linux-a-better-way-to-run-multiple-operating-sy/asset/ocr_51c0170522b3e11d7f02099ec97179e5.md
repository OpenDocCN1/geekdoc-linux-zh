# Conclusion

VMware can create a virtual computer for any number of the top Linux distributions on the market. Whether you need a protected place to work on configuration changes to your core system or you want to experiment with really wild modifications to the operating system, VMware can give you a transparent virtual machine to carry out your plans.

I charge you to go forth and install as many Linux-based virtual machines as you have hard drive space for. Odds are if you’ve been in the Linux community for any length of time, you have a small stack of trial version distributions lying around that you’ve never experimented with because you didn’t want to compromise your primary system. VMware gives you an unlimited controlled testing lab for Linux distributions, Linux programs, and all types of networking techniques. You can even use it to build your knowledge of UNIX-to-UNIX networking and file-sharing techniques!
