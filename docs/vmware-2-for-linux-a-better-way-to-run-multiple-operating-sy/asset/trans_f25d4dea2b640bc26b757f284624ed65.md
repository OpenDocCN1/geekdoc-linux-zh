## Using the Toolbox Options

你可以在内存和磁盘空间允许的情况下运行任意多个虚拟机，但你可能只有一个键盘和鼠标。管理虚拟机何时以及如何接管你的输入设备（称为输入焦点）会迅速带来回报，有助于避免各种挫败感。

BUZZWORD
Input focus:
Determines whether a virtual machine or the host Linux OS captures mouse and keyboard input. When you type into a VMware-hosted OS and application, VMware is said to have input focus.

默认设置其实相当不错，并且适合大多数用户，但你可能想要自定义设置，因此了解你的选择是什么是个好主意。

更改设置非常简单，只需点击复选框即可。你不需要重启、应用或甚至关闭 VMware Tools 窗口，设置就会立即生效。

## Release Input Focus

第一个选项是我个人认为 VMware Tools 中最酷的功能之一的一半。当选项 Release input focus 启用时，并且你将虚拟机的鼠标指针移动到虚拟桌面的边缘之外，指针就会被“交还”给 Linux。换句话说，只要看起来你想在 Linux 中使用鼠标，输入焦点就会立即返回到 Linux。你甚至不需要先点击 Linux 桌面。

当你将 VMware 置于窗口中并需要在 Linux 和 VMware 之间快速或频繁切换时，此功能非常有用，而且你不想因使用 Ctrl+Alt+Esc 键组合来释放 VMware 的输入焦点而感到拖累。如果你正在屏幕边缘附近进行艺术程序中的精细工作或使用鼠标玩游戏，这可能会令人沮丧。

此功能在虚拟机处于全屏模式时不起作用；虚拟机在你按下 Ctrl+Alt+Esc 之前始终保持输入焦点。

## Capture Input Focus

Capture input focus 是 Release input focus 的对应功能。当此选项打开时，只要你将指针滚动到 VMware 窗口内部，VMware 就会自动获取输入焦点。

> 只有在该功能激活时才有意义打开 Release input focus，因为如果你的指针意外进入 VMware 桌面，使用 Ctrl+Alt+Esc 键组合将输入焦点重新获取回 Linux 会相当不方便。

此功能在虚拟机处于全屏模式时不起作用，因为在你通过按下 Ctrl+Alt+Esc 退出全屏模式之前，鼠标始终在虚拟机内部。

## Scroll When Mouse Nears Edge

你只有在虚拟机桌面大于 Linux 桌面上的 VMware 窗口时才需要担心 Scroll when mouse nears edge 功能。这可能发生在你临时缩小 VMware 窗口时，或者你使用的是比计算机能显示的更大的虚拟机桌面（例如，在桌面仅为 800x600 的 Linux PC 上使用 1,280x1,024 的 Windows 桌面）。

> 如果你想能够实时更改 VMware 窗口的大小，你需要在 VMware 窗口设置中在 View 下禁用 Autofit。请注意，这不会影响 Windows 桌面本身的大小，只会影响你一次能看到多少内容！

在 Figure 8.4 中，你看到一个 Windows 桌面无法完全显示，因为 VMware 窗口太小了。当启用滚动选项时，VMware 会在鼠标接近屏幕边缘时自动平移桌面。否则，你需要将输入焦点恢复到 Linux 并拖动窗口滚动条来更改桌面的可见区域。

## Hide Cursor

Hide cursor 选项不过是一个更高级的“鼠标隐藏器”，但它可以帮助避免在同一屏幕上看到两个鼠标指针造成的混淆。启用后，当输入焦点在 Linux 而非 VMware 上时，Windows 虚拟机中的鼠标指针就会消失。
