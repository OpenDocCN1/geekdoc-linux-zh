8. VMware should detect your CD-ROM. Leave the default settings as is (to enable CD-ROM access and make it available when the virtual machine boots), and click Next.

9. VMware asks about floppy access. Unless you have a compelling reason to disable the floppy, leave this setting alone as well. Click Next.

> You might need a boot floppy to install the OS, depending on the vintage of the Windows NT CD.

10. The wizard asks how the virtual machine should be able to access the network, shown in Figure 11.3. If you plan to keep the Windows VM completely isolated, you can click No networking. If you have an Ethernet card installed and your PC is on a LAN, use Bridged networking, which lets the virtual machine share your Ethernet card and appear as a standalone computer on the network. Host-only networking allows Samba file sharing between the VM and your Linux PC (provided you installed the VMware Samba server at installation or have one of your own running), and Bridged and Host-only networking combines the two. If you have a LAN, stick with Bridged for now. If you do not, use Host-only or none. Click Next to reach the final step.

> See Chapter 9, "Using Your Windows 95/98 Virtual Machine," and Appendix B, "File Sharing with Samba and NFS in VMware," for extended file sharing and networking tips for Windows.
