## 下载 RHCE 学习材料以准备认证

你可以下载 RHCE 考试材料来为实际认证过程做好有效准备。你可以从红帽官方网站或任何授权的 RHCE 培训伙伴处获取这些材料。

有几种可以下载的材料供你准备。首先，你必须获取红帽手册，这些手册通常以 PDF 格式格式，以便你可以在家里学习。还有书籍和电子书可以作为你参加 RHCE 考试时的指南。

红帽 whizlabs 和其他考试模拟器在你的备考期间也非常有用。大多数此类模拟器不是免费的，但你可以利用供应商提供的免费试用功能。

还有一些全面的单次下载考试准备包供你使用。这类学习材料将包含你所需的一切内容。该包通常由手册、学习指南、模拟器、测试题和评估测试组成。

当你加入一家红帽认证培训伙伴时，你将从他们那里下载 RHCE 课程材料。这些通常是免费的，并包含在整个培训包中。

在准备 RHCE 认证考试时，你有很多选择。如果你想省钱，只需下载那些可以免费获取的材料。你也可以为你你不太熟悉的话题购买培训包。

但你必须记住，RHCE 是一项基于性能的考试。仅仅阅读大量的学习材料是不够的。你需要拥有红帽的实际经验，才能正确解决考试期间向你提出的问题。

获得 MCSE 和 RHCE 认证将让你的 IT 职业真正进入快车道。这是因为这些认证将清晰地展示你在 Windows 和 Linux 服务器环境方面的专业知识。

MCSE 是微软为系统工程师提供的，而 RHCE 认证是由红帽授予服务器管理员和工程师的。由于这些认证，公司一定会注意到你的简历。

参加 MCSE 会更容易且成本更低。然而，这并不意味着考试的难度更小。你必须为 MCSE 认证考试做好充分准备。

最好在获得红帽 RHCE 认证之前先获得 MCSE 认证。这是因为 RHCE 要求你投入更多的时间、更多的资源和巨大的精力。如果你已经有了 MCSE，你的下一个逻辑选择将是 RHCE。

在两个认证之间，红帽的 RHCE 声望更高。IT 专家和从业人员对这一点赞同。因此，你必须为 RHCE 花费更多的准备时间。

有一些提供 MCSE 和 RHCE 课程的培训中心。如果你能获得包含这两项认证考试的培训包，那将是一个实用的选择。另一方面，如果你想节省培训费用，可以自学 MCSE，并为 RHCE 参加培训课程。

你还应该为这两场考试分别准备独立的练习平台。这样，你将能够完全掌握构建 Windows 和红帽服务器所使用的方法。

## 考试结构与通过标准

红帽认证工程师（RHCE）认证考试的目标是衡量 IT 人士在实际系统中的胜任能力。RHCE 认证考试的重点基本上是红帽操作系统的实现。通过 RHCE 认证考试意味着个人具有配置网络服务以及确保运行红帽操作系统的服务器安全的技能。

RHCE 认证考试耗时约为 5 小时 30 分钟。其中包括包含 40 到 50 道题的选择题考试，剩下的 5 小时由两场实操考试组成。由于这些实操部分，RHCE 考试是按计划安排的。

由于 RHCE 认证考试更多倾向于实操而非客观题型，因此猜题的空间较小。IT 人士应该对 Linux 的所有方面了如指掌。还必须作为运行 Linux 的系统的管理员拥有丰富的经验。

为了评估自己的知识，可以参加红帽网站提供的预评估考试。这将让个人了解自己对测试的准备程度以及需要做多少学习才能通过考试。IT 人士必须记住，及格线是 80%，且在三个部分中的任何一个得分都不能低于 50%。因此，他们必须选择与自己的知识和技能水平合适的 RHCE 课程。红帽网站提供几门 RHCE 课程，每门课程都根据个人的经验水平进行设计。因此，为了通过考试，必须做好准备并选择正确的课程。

此外，RHCE 考试分为三个部分，包含两个通用部分。通用部分是故障排除和系统维护，最长可用时间为两个半小时；安装和配置部分，最多可用时间为 3 小时。

为了确保通过 RHCE 考试，候选人可以参加任何授权的红帽课程。他们可以进行技能在线评估以确定自己的薄弱环节在哪里，并帮助他们决定需要参加的课程。

## RED HAT LINUX 概览

`Red Hat Linux` 由红帽公司（`Red Hat company`）编译，是一种基于 Linux 的知名操作系统，直到在 2004 年停止支持。1994年11月3日，`Red Hat Linux 1.0`（称为“红帽商业版 Linux”）发布。它是第一个使用软件包系统的 Linux 发行版；其所使用的软件包格式是 `RPM` 软件包管理器。这也是许多 `Yellow Dog Linux` 和 `Mandriva Linux` 等其他发行版的来源。

然而，红帽公司已停止了 `Red Hat Linux` 系列，以为旨在企业环境的 `Red Hat Enterprise Linux (RHEL)` 铺路。与此同时，`Fedora` 也被开发出来作为免费版本来补充家庭环境。因此，`Red Hat Linux` 系列在最后一个发行版本 `Red Hat Linux 9` 之后停止了发布。该系列于 2004 年正式结束。不过，更新一直持续到 2006 年直到 2007 年初。

`Red Hat Linux` 实际上呈现出不同的特性。例如，3.0.3 版本是早期支持可链接和可执行格式（`Linkable and Executable Format`）而非 `a.out` 格式的发行版之一。`Red Hat Linux` 还引入了一个名为 `Anaconda` 的图形化安装程序，旨在简化初学者的使用。该程序也被多个 Linux 发行版采用。

此外，版本 7 也作为 2.4 内核的基础得以发布。随后，`Red Hat Linux 8.0` 被推出，作为系统的默认字符编码。稍后，版本 9 被发布，以支持原生 `POSIX` 线程库（`Native POSIX Thread Library`）。

寻求降低成本和提高效率的企业无需另寻他处了。红帽软件可以为企业节省数万美元的许可费用。然而，用户可能会对某些问题产生担忧，这让他们犹豫是否切换到红帽软件。

这些问题是什么？

第一个问题是操作系统之间的差异。一直使用 `UNIX` 的用户不需要担心必须为 Linux 学习另一个系统。如果他精通 `UNIX` 命令行工具，那么他就可以在新环境中使用这些工具。他所需要的只是进行简单的网页浏览。

他可以下载一些在 `Windows` 上原生运行的工具，如 `grep`、`awk`、`gawk` 和 `vim`。更好的解决方案是安装 `Cygwin`。该产品提供了一个类 `UNIX` 环境，运行和看起来都像 `UNIX shell`。可以在网上免费下载 `Cygwin`。

第二个问题是应用程序的访问。如果一个用户一直是 `Windows` 用户并被要求迁移到 Linux 桌面，他可能会有一些担心。这些担心涉及到他的许多使用 `Microsoft Office` 格式的文档。他会认为可能无法在红帽软件下读取或编辑这些文档。或者他可能担心创建的新文档无法被 `MS Office` 用户读取。

这些在红帽软件下并不是问题。他可以使用 `OpenOffice` 或 `StarOffice`，它们包含了与 `MS Office` 产品兼容的办公自动化软件。此外，`OpenOffice` 是一个开源产品，可以免费下载。

## Red Hat Linux 4 面临的新挑战

在拥有 `Red Hat Linux 3` 超过 16 个月后，`Red Hat Linux 4` 发布了。红帽 Linux 用户可能因为其新的部署特性而被迫升级。红帽 Linux 4 有许多新增内容。

首先，2.6 Linux 内核取代了经过大量补丁和修改的红帽 2.4 内核。它还提供了更好的扩展性和更广泛的硬件支持。其次，它提供了安全性增强、桌面软件的升级与添加，以及与活动目录（`Active Directory`）认证的集成。

有人说红 Hat Linux 4 并没有提供太多新东西。2.6 内核下的许多功能已经在 `Red Hat Linux 3` 中实现。此外，据说安全性增强子系统已集成到许多外部服务中，如 `BIND`、`NTP` 和 `Apache`。

与此同时，桌面软件的升级和添加被认为对红帽企业 4 的桌面版和工作站版是有益的。然而，对于 `AS`（高级服务器）和 `ES`（企业级服务器）版本来说，这些并不有用，更多被视为一种缺点。

尽管受到一些用户的批评，红帽企业 Linux 4 相比竞争对手仍然具有一个主要优势，那就是它的多样性。它提供四种版本：高级服务器、企业服务器、工作站和桌面版。这些是为了服务特殊用途而定制的，但所有版本基于同一个核心。这确保了用户可以针对各种任务手握多种工具。

## 红帽网络及其益处

红帽网络（通常称为 `RHN`）是由红帽运营的一个系统。它基本上为订阅者提供 `Red Hat Linux` 和 `Red Hat Enterprise Linux` 中包含的包的更新、补丁和错误修复。它还提供系统的配置和监控。

红帽网络的用户如果想从 `RHN` 进行相应的更新，可以使用 `update` 或 `yum` 程序。这与其他种类型的自动系统维护工具类似，例如微软提供的那些工具。

为什么要使用红帽网络？

首先，红帽网络简化了红帽 Linux 系统的管理。它为用户提供了一种简单直接的方法来识别过时的包并获取适当的替换。自动更新功能还允许单机在没有用户干预的情况下进行更新。

其次，单个系统管理员可以管理包含在红帽全球教育计划中的高级管理级功能。它可以同时监督和更新数百甚至数千个系统。然而，管理员必须意识到这种安排有一个缺点。到红帽网络的并发连接可能会导致带宽急剧消耗。这可以通过程序自带的 `RHN` 代理服务器来解决。

红帽网络可以提供很多好处，特别是对于教育系统而言。学校和大学可能因为有用性和成本效益而探索使用红帽网络的可能性。最近，还宣布了红帽网络将开源，这将使其开发速度更快。
