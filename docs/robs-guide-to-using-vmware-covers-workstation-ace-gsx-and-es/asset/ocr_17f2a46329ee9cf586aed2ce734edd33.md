This means that all data access to and from the physical disk is directly written and read. It is not like a virtual disk where everything is stored in a single file.

A partition can be added to a virtual machine from the Add Hardware Wizard.

+   1. Open the virtual machine configuration utility via the Settings control panel, and click the Add button to open the wizard. The first selection that you must make is the disk type. Select Use a physical disk (for advanced users) to add an existing partition to the virtual machine.
+   2. In the next screen, select the physical disk where the partition resides, and select whether you want to use the entire disk or individual partitions. Selecting to Use individual partitions will open the next screen with a list of partitions.
