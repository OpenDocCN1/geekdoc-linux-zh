# 12.4 Generating New SIDs

Working with Security Identifiers (SIDs) is not something that is related specifically to virtual machines. However, it is very likely that you will copy virtual machines, in order to use them multiple times. By doing so, you can end up in the situation where two machines have the same SID. This situation will cause problems, especially when working with NT or Active Directory domains.

One method for creating unique identities is to use the SYSPREP utility from Microsoft. This will remove all identification information from the machine and shut it down. It can be copied or imaged, and when the copy and/or the original are started, a mini setup wizard will start and will ask for a computer name, domain name, or a workgroup to join. This will also create a new SID for your machine.

There are also tools available on the Internet which can help you generate new SIDs. One freeware tool is NewSID which is available from Sysinternals. The tool is available via their website at www.sysinternals.com.
