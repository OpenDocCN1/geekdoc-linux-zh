# VMware Registration Service log file

All general VMware GSX Server activity is logged in a file called vmware-serverd.log. It is stored in the following directories:

For Windows:

```
C:\Windows\Temp
```

For Linux:

```
/var/log/vmware
```

# Installation log files

During the installation of VMware software, an installation log is created. For Windows, the file is called VMInst.log. It is saved in the TEMP directory for the user who performed the installation. An example is `C:\Documents and Settings\Administrator\Local Settings\Temp`. On a Linux host, the log file is called locations and it is stored in `/etc/vmware`.
