In the performance window, click the plus sign in the toolbar (see Figure 8.4) to add counters to your monitoring environment. The Add Counters window (Figure 8.5) appears.

⚠️ Note: The performance counters are not available in the 64-bit version of Windows. If you want to monitor performance on a 64 bit platform, you need to use the 32 bit version of the utility (C:\Windows\SysWOW64\perfmon.exe).

From the Performance object drop down list select VMware. Next, select one or all of the counters that you want to monitor. An overview of counters is listed in Table 8.1, later in this section.

Select which virtual machine(s) you want to monitor. You can select more then one machine by pressing the Ctrl-key while clicking the machine names.

Or, select the All instances radio button to monitor all current virtual machines. If you open new virtual machines, they will not be automatically added when you have chosen All instances.
