On a Windows host, the DHCP configuration is stored in a text file called vmnetdhcp.conf located at C:\Documents and Settings\All Users\Application Data\VMware. DHCP leases are stored in a file in the same directory with the name vmnetdhcp.leases. On a Linux host, the configuration is stored in a file called dhcpc.conf which is located in a subdirectory dhcpd in the virtual network adapter configuration directory in /etc/vmware. For a default installation, this is /etc/vmware/vmnet1/dhcpd. For a Linux host, the host-only DHCP configuration can be modified by editing this file.

Note: Before modifying a configuration file, always make a backup copy.
