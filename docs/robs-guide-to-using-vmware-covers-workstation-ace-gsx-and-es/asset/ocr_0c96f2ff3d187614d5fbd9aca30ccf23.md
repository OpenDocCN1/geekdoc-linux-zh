The other Power Options from the settings screen in Figure 4.2 are self explanatory:

+   - Power on after opening this virtual machine.
+   - Enter full screen mode after powering on.
+   - Close after powering off or suspending.

Use these options to configure a machine that runs without the user controlling it. By automatically starting and entering full screen mode, a user would never have to know that he or she is working inside a virtual machine.
