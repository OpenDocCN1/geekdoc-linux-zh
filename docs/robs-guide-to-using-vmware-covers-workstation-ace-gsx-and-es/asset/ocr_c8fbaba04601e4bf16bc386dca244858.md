# Linux

You can use Samba (smbclient) to attach a Linux workstation to a Windows host, or a Samba server to attach a Windows workstation to a Linux host. Another method is to use SSH and specifically Secure Copy (SCP), which is available as open source for Linux and Windows.

# NetWare

When you install the NetWare client in your Windows host, you can login to the server. Or, you can use Native File Access (CIFS) to use normal Windows networking. For Linux hosts, you can use NFS to mount a NetWare server’s volume.
