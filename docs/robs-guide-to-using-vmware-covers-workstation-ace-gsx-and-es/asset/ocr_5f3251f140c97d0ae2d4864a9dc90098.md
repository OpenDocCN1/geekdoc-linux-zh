# 5.9 Running the Deployed Virtual Machine

After the package is deployed to the end user's computer, it can be started from the start menu or the shortcut on the desktop. When the virtual machine is configured for password management, the user is prompted for a new password the first time that the application runs.

When the machine is running, a user will see a status bar that is somewhat similar to a terminal services window. The user can access the host by just clicking on the window. Because the tools will be installed, the mouse pointer will seamlessly go out of the virtual machine and into the host operating system.
