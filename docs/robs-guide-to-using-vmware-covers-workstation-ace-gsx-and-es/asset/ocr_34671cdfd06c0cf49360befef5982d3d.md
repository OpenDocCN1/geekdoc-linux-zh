# 12.5 Disable the “why do you shutdown your server?” Dialog Box

This is a new feature of Windows Server 2003. Disable it by following these steps:

Go to Start → Run type gpedit.msc Click OK. Go to Local Computer Policy → Computer Configuration → Administrative Templates → System. Select Display Shutdown Event Tracker and disable it.
