# Virtual Network Editor

The list below shows which virtual networks have host virtual adapters - virtual Ethernet adapters that allow the host computer to connect to the network.

| Network Adapter | Virtual Network | Status |
|---|---|---|
| VMware Network Adapter VMnet1 | VMnet1 | Enabled |
| VMware Network Adapter VMnet8 | VMnet8 | Disabled |

Figure 11.14: Virtual adapters can be added by using the Virtual Network Editor.

Select the virtual host-only network that you want to use ranging from VMnet2 to VMnet9. Notice that VMnet8 is not listed because it is used by default by NAT networking for VMware.

![](bbox=[0.5, 0.72, 0.92, 0.86])

Figure 11.15: Select the new virtual network.

A New Device will now show up in the list of Host Virtual Adapters. Click OK to save this configuration and close the Virtual Network Editor. Now open Network Connections from the Control Panel on the host operating system. A new adapter, Local Area Connection # was added to your PC. For your convenience, rename this adapter to VMware Network Adapter VMnet2 to make it easier for you to distinguish the adapter that you are configuring. At this time, also assign an IP address in the subnet range to the adapter which you will be using for this second virtual network.
