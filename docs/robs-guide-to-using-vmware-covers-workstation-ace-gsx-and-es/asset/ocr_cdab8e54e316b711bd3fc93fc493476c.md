+   9. Select the SCSI bus type for this virtual machine: Buslogic or LSI Logic.
+   10. Select a disk type to add to the virtual machine.
+   11. Select the size for the virtual machine.
+   12. Select a disk mode for the virtual machine.
+   13. A window will be displayed, explaining that VirtualCenter is ready to submit the task to the ESX Server.

To access the console of a virtual machine, you can select the Console tab in the client application.
