| Variable | Description |
| :------- | :---------- |
| manpath | A list of directories for the $MANPATH environment variable. |
| nologin | If present, the user cannot log in. |
| path | A list of directories for the $PATH environment variable. |
| priority | Priority (nice) for the user's processes (see Chapter 21). |
| requirehome | User must have a valid home directory to log in. |
| setenv | A comma-separated list of environment variables and their values. |
| shell | The full path of a shell to be executed upon login. This overrides the shell in /etc/master.password. The user's $SHELL, however, contains the shell from the password file, resulting in an inconsistent environment. Playing games with this is an excellent way to annoy your users. |
| term | The default terminal type. Just about anything that tries to set a terminal type overrides this. |
| timezone | The default value of the $TZ environment variable. |
| umask | Initial umask setting; should always start with 0, see builtin(1). |
| welcome | Path to the login welcome message, usually /etc/motd. |

Remember, changes to a class affect all users in that class. If a user needs a change from the class settings, you'll need to change their class.
