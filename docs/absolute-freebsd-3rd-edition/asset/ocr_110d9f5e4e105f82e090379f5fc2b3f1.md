```
OK lsdev
1 cd devices:
disk devices:
2 disk0: BIOS drive C (33554432 X 512):
3 disk0p1: FreeBSD boot
disk0p2: FreeBSD swap
disk0p3: FreeBSD ZFS
4 zfs devices:
zfs:zroot
```

The loader checks for CD drives 1 and doesn’t find any. (The loader finds CD drives only if you boot from a CD, so don’t be alarmed by this.) It finds a hard drive, known to the BIOS as drive C 2. It then describes the partitions on that hard drive. As we’ll see in Chapter 10, GPT partitions identify partitions with the letter *p* and a number. The partition disk0p1 3 is a FreeBSD boot partition used to bootstrap FreeBSD from the BIOS. You might find this knowledge useful on an unfamiliar system that’s having trouble booting. The loader can also identify the ZFS pools 4 on the host.

# ### Loader Variables

The loader has variables set within the kernel and by a configuration file. View these variables and their settings with the `show` command, and use the spacebar to advance to the next page.

```

LINES=24
acpi.oem=VBOX
acpi.revision=2
acpi.rsdp=0x000e0000
-- snip--
```
