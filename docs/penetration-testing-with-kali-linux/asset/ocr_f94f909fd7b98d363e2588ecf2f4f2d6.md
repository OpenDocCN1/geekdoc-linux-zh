At the heart of this technique is clever search strings and operators²21⁷ for the creative refinement of search queries, most of which work with a variety of search engines. The process is iterative, beginning with a broad search, which is narrowed using operators to sift irrelevant or unintended results.

We'll start by introducing several of these operators to learn how they can be used.

The site operator limits search to a single domain. We can use this operator to gather a rough idea of an organization's web presence.
