The Title field will give easily the vulnerable application name along with its respective version and the function of the exploit.

The Type field designates one of the following: dos, local, remote, or webapp.

The Platform field designates which kind of system(s) are affected by the exploit. This can be any operating systems, hardware, or code language services such as PHP.

The last field designates the Author of the exploit.
