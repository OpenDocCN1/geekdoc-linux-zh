In order to simulate a real DNS setup, we can make FELINEAUTHORITY a functional DNS server using dnsmasq. Dnsmasq is DNS server software that requires minimal configuration. > Listing 604 - Using nslookup for exfiltrated-data.corp

This returns NXDOMAIN, which is expected because we haven't configured any records for exfiltrated-data.corp. This may be subtle, but it illustrates that we can transfer small amounts of information (exfiltrated data) from the network to the outside, without a direct connection, by making DNS queries.

Exfiltrating chunks of plaintext is one thing, but imagine we have a binary file to exfiltrate from PGDATABASE01. How might we do that?

This would require a series of sequential requests. We would convert a binary file into a hex string representation, split this string into smaller chunks, then send each chunk in a DNS request for hex-string-chunk.feline.com. On the server side, we would log all the DNS requests and convert them from a series of hex strings back to a binary. We won't go into further details here, but this should clarify the general concept of DNS network exfiltration.
