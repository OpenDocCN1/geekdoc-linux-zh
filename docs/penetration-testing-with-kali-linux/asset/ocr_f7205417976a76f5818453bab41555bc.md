While URL inspection can provide some clues about the target web application, most context clues can be found in the source of the web page. The Firefox Debugger tool (in the Developer menu) displays the page's resources and content, which varies by application. The Debugger tool may display JavaScript frameworks, hidden input fields, comments, client-side controls in HTML, JavaScript, and much more.
