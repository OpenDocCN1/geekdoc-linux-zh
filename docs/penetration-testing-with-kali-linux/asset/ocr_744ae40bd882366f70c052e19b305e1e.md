AD contains so much information that it can be hard to determine where to start enumerating. But since every AD installation fundamentally contains users and groups, we'll start there.

To start gathering information, we will use net.exe which is installed by default on all Windows systems. More specifically, we will use the net user sub-command. While we can use this tool to enumerate local accounts on the machine, we'll use /domain to print out the users in the domain.

```
C:\Users\stephanie>net user /domain
The request will be processed at a domain controller for domain corp.com.
```

The output from this command will vary depending on the size of the organization. Armed with a list of users, we can query any information about individual users.

Administrators often have a tendency to add prefixes or suffixes to usernames that identify accounts by their function. Based on the output in Listing 712, we can show that the jeffadmin user because it might be an administrative account.

```
C:\Users\stephanie>net user jeffadmin /domain
```
