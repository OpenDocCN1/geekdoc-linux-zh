The Intruder³34⁷ Burp feature, as its name suggests, is designed to automate a variety of attack angles, from the simplest to more complex web application attacks. To learn more about this feature, let's simulate a password brute forcing attack.

Since we are dealing with a new target, we can start a new Burp session and configure the Proxy as we did before. Next, we'll navigate to http://offsecwp/wp-login.php from Firefox. Then, we will type “admin” and “test” as respective username and password values, and click Log.
