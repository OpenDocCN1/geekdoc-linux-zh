# OffSec Penetration Testing with Kali Linux

![](bbox=[0.235, 0.095, 0.765, 0.415])

Shelter can run in either Auto or Manual mode. In Manual mode, the tool will launch the PE we want to use for injection and allow us to manipulate it on a more granular level. We can use this mode to highly customize the injection process in case the automatically selected options fails.

For the purposes of this example however, we will run Shelter in Auto by selecting A at the prompt.

Next, we must select a target PE. Shelter will analyze and alter the execution to inject and execute our payload. For this example, we will use the Windows 32-bit executable installer for the popular music player Spotify$^{389}$ as our target PE. At time of this writing, Spotify offers only the 32-bit version of the installer.

> For real engagements, it is best practice to pick a new, less scrutinized application as Shelter's author explains.$389}$

To start, we need to tell Shelter the Shelter installer location on our local Kali machine. In this case, it is `/home/kali/desktop/spotifysetup.exe`. Before analyzing and altering the original PE in any way, Shelter will first create a backup of the file.
