## 9.3.2 Non-Executable Files

In this section, we will examine how file uploads can have severe consequences. Even if the application only allows non-executable files (like .txt or .jpg), there might be ways to bypass these restrictions.

- Remote Execution (Command Injection / RCE)
- Local File Inclusion (LFI)
- Remote File Inclusion (RFI)
- File Upload Vulnerabilities

### Remote Execution (Command Injection / RCE)

Remote execution occurs when an attacker can execute arbitrary commands on the server. This often happens when an application fails to properly sanitize user input.

### Local File Inclusion (LFI)

Local File Inclusion occurs when an application includes a file that is present on the local filesystem. This can be used to read sensitive files, such as configuration files or passwords.

### Remote File Inclusion (RFI)

Remote File Inclusion occurs when an application includes a file that is hosted on a remote server. This can be used to execute code on the server.

### File Upload Vulnerabilities

File upload vulnerabilities occur when an application allows users to upload files to the server without proper validation. This can lead to remote code execution if the attacker can upload a web shell.
