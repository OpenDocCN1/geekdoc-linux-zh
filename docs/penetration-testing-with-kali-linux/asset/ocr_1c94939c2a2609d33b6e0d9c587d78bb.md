Listing 259 - Calculating the keyspace for the specified character set, we have a keyspace of a five-character password with 916,132,832. This number determines how many unique variations can be generated for a five-character password with this character set. Now that we have the keyspace in the context of this example, we also need the hash rate to calculate the cracking time. The hash rate is a measure of how many hash calculations can be performed in a second.

For the hash rate, we use Hashcat's benchmark mode to determine the hash rates for various hash algorithms on our particular hardware.

We'll use hashcat -b to initiate benchmark mode. First, we'll benchmark a CPU by running it without any GPUs. Following along on a local system, the results may differ.

Listing 260 - Benchmark CPU with MD5, SHA1, and SHA-256

The benchmark displays hash rates for all supported modes of Hashcat. The listing above is shortened, since Hashcat supports many hash algorithms. For now, we are only interested in MD5, SHA1, and SHA-256. The values of the hash rates are in MH/s in which 1 MH/s equals 1,000 hashes per second. Note that results will vary on different hardware. We make a note of the hash rates shown in the CPU benchmark in this Listing and run a GPU benchmark so we can compare the results.
