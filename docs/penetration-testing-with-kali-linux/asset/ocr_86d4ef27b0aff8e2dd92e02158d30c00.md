# 22.2.4 Silver Tickets

In the previous section, we obtained and cracked a PGS-REP hash to retrieve the plaintext password of an SPN. Now we go one step further and forge our own service tickets.

Remember the inner workings of the Kerberos authentication, the application on the server executing in the context of the service account checks the users' passwords from the group memberships in the service ticket. However, the user and group memberships in the service ticket are not verified by the application in a majority of environments. In this case, the application blindly trusts the integrity of the service ticket since it is encrypted with a password hash that is, in theory, known only to the service account and the domain controller.
