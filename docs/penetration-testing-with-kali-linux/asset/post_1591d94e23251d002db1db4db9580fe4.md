Listing 777- Domain Share Query

Listing 777 shares from three different servers. Although some of these are default domain shares, we should investigate each of them in search of interesting information.

In this instance, we'll first focus on SYSVOL¹1055 as it may include folders and files that the domain controller itself. This particular share is used for various domain policies and scripts. By default, the SYSVOL folder is mapped to %SystemRoot%\SYSVOL\domain-name on the domain controller and every domain user has access to it.

```
PS C:\> ls \dc1.corp.com\sysvol\corp.com
Directory: \dc1.corp.com\sysvol\corp.com
```

Penetration Testing with Kali Linux

Listing 781 - Checking contents of old-policy-backup.xml

Due to the name of the folder and the name of the file, it appears that this is an older policy. This is a common artifact on shares as system administrators forget when implementing new policies. In this particular case, the XML file describes the current policies (GPO) helpful for learning about workstations. Even though GPO-stored passwords are encrypted with AES-256, the private key for the encryption has been redirected from MSDN. We can use this to decrypt these passwords. In this case, we will use the gpg script in Kali Linux that decrypts the given string:

```
kali@root:~# gpg +bsY0V3D/KgXv3YD/vyeppAN1zMFTIQ0DAg63V
```

Listing 781 - Using gpg to decrypt the password
