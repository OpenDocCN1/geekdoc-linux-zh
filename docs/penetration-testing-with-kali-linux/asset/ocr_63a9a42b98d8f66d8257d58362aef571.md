In the menu bar, we'll click on *File > New Text File*. We'll then save the empty file as configLibrary-ms on the offsec user's desktop. As soon as we save the file with this file extension, it is displayed with an icon. While the icon doesn't look dangerous, it is not commonly used by Windows and may raise suspicions.
