The output reveals a swap partition and the primary ext4 disk of this Linux system.

> Keep in mind that the system administrator might have used custom configurations or scripts to mount drives that are not listed in the /etc/fstab file. Because of this, it is good practice not to mount /etc/fstab, but also to gather information about mounted drives using mount.

Furthermore, we can use `lsblk^647` to view all available disks.

```
joe@debian-privesc:-$ lsblk
NAME      MAJ:MIN SIZE TYPE MOUNTPOINT
sda       8:0    0   32G disk 
|-sda1    8:1    0   31G part /
|-sda2    8:2    0   1K part 
|-sda5    8:5    0   975M part [SWAP]
sr0      11:0  1024M disk
```

Listing 472 - Listing all available drives using lsblk

We noticed that the sda drive consists of three numbered partitions. In situations, showing information for all local disks on the system might reveal partitions that are not mounted. Depending on the system configuration (or misconfiguration), we might be able to mount partitions and search for interesting documents, credentials, or other information that could allow us to escalate our privileges or get a better foothold in the network.

Another common privilege escalation technique involves exploitation of device drivers and kernel modules. We will explore exploit tactics later in this Module, but first let's examine some important enumeration techniques.
