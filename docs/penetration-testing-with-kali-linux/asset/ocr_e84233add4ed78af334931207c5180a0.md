Listing 842 - Creating a process with a users NTLM password hash

At this point, we have a new PowerShell session that allows us to execute commands as jen.

At this point, running the whoami command on the newly created PowerShell session would show jeff' identity instead of jen. While this could be confusing, it is the intended behavior of the whoami utility which only checks the current process's token and it does not inspect any imported kerberos

Let's list the cached Kerberos tickets with klist

```
PS:\Windows\system32> klist

Current LogonId is 0:0x1583eae

Cached Tickets:: (0)
```
