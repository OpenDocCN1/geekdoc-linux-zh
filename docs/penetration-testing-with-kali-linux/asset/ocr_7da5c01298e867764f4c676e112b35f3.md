Listing 286 - Failed cracking attempt with Hashcat

Unfortunately, we receive an error indicating that hash caused a "Token length exception". When we research with a search engine, several discussions⁴⁰ suggest that modern private keys and their corresponding passwords are created with the aes-256-ctr⁴¹ cipher, Hashcat's mode 2221 does not support.

This reinforces the benefit of using multiple tools like John Ripper (JTR) can handle this cipher.

To be able to use created rules in JTR, we need to add a name for the rules and append them to /etc/john/john.conf configuration file. For this demonstration, we'll name the rule sshRules with a "List.Rules" syntax (as shown in Listing 287). We'll use sudo sh -c to append the contents of our rule file into /etc/john/john.conf.

```
kali@kali:~/passwordattacks cat ssh.rule
[List.Rules:sshRules]
c $1 $3 $7 $!$
c $1 $3 $7 $#$
c $1 $3 $7 $#
```

```
kali@kali:~/passwordattacks sudo sh -c 'cat /home/kali/passwordattacks/ssh.rule >>
/etc/john/john.conf'
```
