Next, we'll gather information about the actual target machine, its configuration, and applications running on it.

Following the list from 376, let's check the operating system, version, and architecture. We can use systeminfo to gather this information.

```
PS C:\Users\dave> systeminfo
systeminfo
Host Name:               CLIENTWK220
OS Name:                Microsoft Windows 11 Pro
OS Version:             10.0.22000 N/A Build 22000
...\System Type:           x64-based PC
```

Listing 382 shows that our bind shell runs on a Windows 11 Pro. To get the exact version, we can use the build number and review the existing versions⁷⁴⁹ of the identified operating system. In our case, build 22000 is the version 21H2 of Windows 11.

Additionally, the output contains information that our shell runs on a 64-bit system. This information becomes relevant when we want to run binary files on the system, since we cannot run a 64-bit application on a 32-bit system.
