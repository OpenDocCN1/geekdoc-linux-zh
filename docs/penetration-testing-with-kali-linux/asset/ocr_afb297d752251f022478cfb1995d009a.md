# Ubuntu 16.04 LTS / 18.04 LTS / 20.04 LTS : Sudo vulnerabilities (USN-4705-1)

### Synopsis
The remote Ubuntu host is missing one or more security updates.

### Description
The remote Ubuntu 16.04 LTS / 18.04 LTS / 20.04 LTS has packages installed that are affected by multiple vulnerabilities referenced in the USN-4705-1.

+   - Sudo before 1.92 has a Heap-based Buffer Overflow, allowing privilege escalation via root subdivit and contains an argument that allows an arbitrary file write (CVE-2021-3156).
- The vulnerability of Sudo before 1.92 also has a heap corruption allowing arbitrary directory test bypass by using sudo_edit race condition in replacing a user-controlled directory by a symlink to an arbitrary path (CVE-2021-22952).

### Solution
Update the sudo and sudo-ldap packages.
