Every time we obtain new information, we should evaluate what we already know. For our situation, this means we have already obtained the information that daniela has an SPN to INTERNALSRV1. Our assumption at this point is that daniela may be able to log in to the WordPress login page successfully.

Since daniela is kerberos, we can attempt to retrieve the user's password this way. If we can crack the TGS-REP^26 password hash, we may be able to log in to WordPress and gain further access to INTERNALSRV1.

If this attack fails, we can use WPScan and other web enumeration tools to identify potential vulnerabilities on INTERNALSRV1 or switch to MAIRS1.
