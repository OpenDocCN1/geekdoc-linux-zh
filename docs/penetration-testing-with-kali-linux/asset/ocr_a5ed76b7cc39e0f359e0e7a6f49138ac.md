Analyzing the findings of a single target provides us with a lot of detailed information. However, we often want to get an overview of the most important vulnerabilities of all targets. This Nessus has a feature to provide a prioritized view of vulnerabilities named VPR Top Threats, which utilizes the Vulnerability Priority Rating (VPR).¹ The findings in the VPR list consist of the top vulnerabilities of the scan.
