Penetration Testing with Kali Linux

On modern systems, the systems in the SAM are stored as NTLM hashes. This hash implementation addresses many weaknesses of LM. For example, passwords are case-sensitive and are no longer split into smaller, weaker parts. However, NTLM hashes stored in the SAM database are not salted.

Salts^{649} are random bits appended to a password before it is hashed. They are used to prevent an attack in which attackers pre-compute a list of hashes and then perform lookups on these precomputed hashes to infer the plaintext password. A list or table of precomputed hashes is called a Rainbow Table^{650} and the corresponding attack is called a Rainbow Table Attack.

> We "NTLM hash" to refer to the formally correct NTHash. Since "NTLM hash" is more commonly used in our industry, we use in this course to avoid confusion.

We cannot just copy, rename, or move the SAM database from C:\Windows\system32\config while the Windows operating system is running because the kernel keeps an exclusive file lock on the file.

Fortunately, we use the Mimikatz^{651} tool to do the heavy lifting for us and bypass this restriction. Mimikatz provides the functionality to extract plain-text passwords and password hashes from various sources in Windows and leverage them in later attacks like the hash^{652}. Mimikatz also includes the sekurl module, which extracts passwords from the Security Authority Subsystem (LSASS)^{653} process memory. LSASS is a process in Windows that handles authentication, password changes, and access token^{654}.

LSASS is important because it caches NTLM hashes and other credentials, which we can extract using the sekurl Mimikatz module. We need to understand that LSASS runs under the SYSTEM user and is therefore more privileged than a process started as Administrator.

Due to this, we can extract passwords if we are running Mimikatz as Administrator (higher) and have the DebugPrivilege^{655} access right. This access right grants us the ability to debug not only our processes, but also all users' processes.
