> Listing 661 - Display output of Meterpreter HTTPS non-stated payload

Listing 661 shows that the payload used by a Meterpreter session is established. The output displays the handling of requests until the Meterpreter session is established. If a defender monitors the payload's communication, it seems like HTTPS traffic. Furthermore, if they check the address of the communication endpoint (Kali machine in this example), they'd only get a Not page with HTTP code 404 in the browser.

In a penetration test, we can use this exploit to improve our chances of bypassing technology and defenders. However, as Metasploit is one of the best-known exploit frameworks, the detection rates of Meterpreter payloads are quite high by security technologies as antivirus solutions. Therefore we always attempt to obtain an initial foothold with a raw TCP shell and deploy a Meterpreter as soon as we have disabled or bypassed potential security technologies. However, this obfuscation is outside of the scope of this Module.
