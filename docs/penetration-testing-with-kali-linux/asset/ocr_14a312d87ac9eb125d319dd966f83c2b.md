Listing 355 - Listing the content of the exploits directory

Manually searching the Exploit Database is by no means ideal, especially the large quantity of exploits in the archive. This is where the searchploit utility comes in handy.

We can run searchploit from the command line without any parameters to display its usage:

```
kali@kali:~$ searchploit
Usage: searchploit [options] term [term2] ... [termN]
```

Listing 356 - The searchploit command syntax

As the built-in examples reveal, searchploit allows us to search through the entire archive and display results based on various search options provided as arguments.

```
Examples

searchploit afd windows local
searchploit -t oracle windows
searchploit -p 39446
searchploit linux kernel 3.2 --exclude="(PoC)/dos"
searchploit -s Apache Struts 2.0.0
searchploit linux reverse password
searchploit -j 55555 | json_pp
```

For more examples, see the manual: https://www.exploit-db.com/searchploit
