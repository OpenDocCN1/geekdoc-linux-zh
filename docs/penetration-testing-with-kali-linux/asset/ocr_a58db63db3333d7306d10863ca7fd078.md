List 203 - Enabling xp_cmdshell feature

After logging in our Kali VM to the MSSQL instance, we can enable advanced options by setting its value to 1, then applying the changes to the running configuration via the RECONFIGURE statement. Then, we will enable xp_cmdshell and apply the configuration again using RECONFIGURE.

With this feature, we can execute any Windows shell command through the EXECUTE statement followed by the name.

```
SQL> EXECUTE xp_cmdshell 'whoami';
```

List 204 - Executing Commands via xp_cmdshell

Since we have full control over the system, we can now easily upgrade the SQL shell to a standard reverse shell.

Although the various MySQL database variants don't offer a single function to escalate to RCE, we can abuse the SELECT INTO_OUTFILE⁶⁴ to write files on the web server.

> For this attack to work, the file location must be writable to the OS user running the database software.

As an example, let's use the UNION payload on our MySQL target application we explored previously, querying the query that writes a webshell⁶⁵ on disk.

We'll use the UNION SELECT keywords to include a single PHP line into the first column and save it as webshell.php in a writable web folder.

```
' UNION SELECT "<?php ($_GET['cmd']);?>", null, null, null, null INTO OUTFILE
"/var/html/tmp/webshell.php" -- /
```
