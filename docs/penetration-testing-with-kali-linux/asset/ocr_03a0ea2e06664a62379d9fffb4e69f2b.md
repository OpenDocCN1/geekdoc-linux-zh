# 23.1.3 Pass the Hash

The Pass Hash (PtH) technique allows an attacker to authenticate to a remote system or service using a user's NTLM hash of the associated plaintext password. Note that this will not work for Kerberos authentication but for servers or services using NTLM authentication. This lateral movement sub-technique is also mapped in the MITRE Framework under the Use Alternate Authentication Material generic:

Many third-party tools and frameworks use PtH to authenticate and code execution, using *PsExec* from Metasploit,¹1143 *Passing-the-hash toolkit*¹1144 and *Impacket*¹1145 The mechanisms behind them are more or less the same as that attacker connects to the victim using the *Server Message Block (SMB)* protocol and performs authentication using the NTLM hash.¹1146

Most tools that are built to abuse PtH can be leveraged to start a Windows service (for example, cmd.exe or an instance of PowerShell) and communicate with it using *Named Pipes*¹1147 This is done using the Service Control Manager¹1148.API.

> We want to gain remote execution code to create a Windows service for any other use, such as accessing an SMB share.

Similar to PsExec, this technique requires an SMB connection through the firewall (commonly port 445) and the Windows File and Printer Sharing feature to be enabled. These requirements are common in international enterprise environments.
