Listing 650 - Compatible Meterpreter payloads of the exploit module and 64bit meterpreter_reverse_tcp

Listing 650 shows that there are Meterpreter payloads compatible for the currently activated module.

At this point, we note that all Meterpreter payloads are staged. However, the output of show payloads contains staged and non-staged payloads. The difference between these two types is how the Meterpreter payload is transferred to the target machine. The non-staged version includes all components required to launch a Meterpreter session when the staged version uses a first stage to load these components. The network creates some traffic and may alert defense mechanisms. In situations where our bandwidth is limited or we use the same payload to compromise multiple systems in an assessment, a non-staged Meterpreter payload performs quite nicely. For the rest of the Module, we will use the non-staged version whenever we use a Meterpreter payload.
