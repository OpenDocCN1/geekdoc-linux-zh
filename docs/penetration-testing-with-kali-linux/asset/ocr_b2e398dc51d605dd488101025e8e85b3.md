Listing 380 - Display local groups in CLIENTWK220

Listing 380 displays the non-standard groups aminteam, BackupUsers, and helpdesk.
The aminteam group may be of interest to us since it contains the "admin" and has a custom description text, indicating the members are admitted to all workstations on the second floor. However, we don't currently have any further information regarding floors exist or departments are on floors.

Another interesting finding is the group BackupUsers as we use BackupAdmin before.
Backup solutions have extensive permissions to perform their operations on the file system, making both potentially valuable targets.

Apart from the non-standard, there are several built-in groups we should analyze, such as Administrators, Backup Operators, Remote Desktop Users, and Remote Management Users.

Members of Backup Operators can capture and restore all files on a computer, even those files they don't have permissions for. We must not confuse this with non-standard groups such as BackupUsers in our example.

Members of Remote Desktop Users can access the system with RDP, while members of Remote Management Users can access with WinRM.

For this example, let's review the members of aminteam and Administrators. We can do this with Get-LocalGroupMember, passing the group name as an argument.

```
PS C:\Users\dave> Get-LocalGroupMember aminteam
Get-LocalGroupMember aminteam
```

| User CLIENTWK220\daveadmin Local |

```
PS C:\Users\dave> Get-LocalGroupMember Administrators
Get-LocalGroupMember Administrators
```
