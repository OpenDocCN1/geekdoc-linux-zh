CORP\RAS and IAS Servers

Listing 770 - Converting the SecurityIdentifier into name

According PowerView, the SID in the SecurityIdentifier property belongs to a default AD group named RAS and IAS Servers¹⁰⁵⁴

Taking this information together, the RAS and IAS Servers group has ReadProperty access rights to our user. This is a common configuration in AD and likely won't give us an attack vector, we have used the example to make sense of the information we have obtained.

In short, we are interested in the DirectoryRights and SecurityIdentifier for each object we enumerate going forward.

The highest access permission we can have on an object is GenericAll. Although there are many interesting ones as discussed in this section, we will use GenericAll as an example in this case.

We can continue to use Get-ObjectAD and select only the properties we are interested in, namely DirectoryRights and SecurityIdentifier. While the ObjectSID is nice to have, we don't need when we are enumerating specific objects in AD as it will only contain the SID for the object we are in enumerating.

Although we should enumerate all the domain, let's start with the Management group for use. We will check if any of us have GenericPermissions.
