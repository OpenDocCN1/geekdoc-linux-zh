List 46 - Using dnsrecon to perform a standard scan

Based on the output, we have managed to perform a successful DNS scan on the name records against the megacorpone.domain.

Let's try to brute force hostnames using the list.txt we created previously for forward lookups.

```
kali@kali:~ $ cat list.txt
www
ftp
mail
owa
proxy
router
```

To perform a brute force attack, we will use the -d option to specify a domain name, -D to specify a file name containing potential subdomain strings, and -t to specify the type of enumeration to perform, in this case brt for brute force.

```
kali@kali:~ $ dnsrecon -d megacorpone.com -D ~/list.txt -t brt
[+] Using the dictionary file: /home/kali/list.txt (provided by user)

```
