### 20.1.1 Setup and Work with MSF

Although the Metasploit Framework comes preinstalled on Kali Linux, it's not a starting database in its default configuration. While using a database is not mandatory to run Metasploit, there are compelling reasons to do so, such as storing information about target hosts and keeping track of successful exploitation attempts. Metasploit uses PostgreSQL⁹⁷² as a database service, which is neither active nor on boot time on Kali.

We can start the database service as well as create and initialize the msfdb init

```bash
kali@kali~$ sudo msfdb init
[+] Starting database
[+] Creating database user 'msf'
[+] Creating databases 'msf_test'
[+] Creating databases 'msf_test'
[+] Creating configuration file '/usr/share/metasploit-framework/config/database.yml'
[+] Creating initial database schema
```

## Penetration Testing with Kali Linux

Before we jump into performing operations within Metasploit, let's discuss one important concept first: workspaces. Let's assume we have performed penetration test and Metasploit stored all information about our target and its infrastructure in the database. When we start the next penetration test, to address this and avoid mixing assessment's results with different assessments, we can use workspaces. Metasploit workspace command lists all previously-created workspaces. To create a new workspace, we have to provide the workspace name as argument to the command we'll store the results of this section and the next one.

```bash
msf6 > workspace
* default

msf6 > workspace -a pen200
[*] Added workspace: pen200
[*] Workspace: pen200
```

Listing 622 - Creating workspace pen200
