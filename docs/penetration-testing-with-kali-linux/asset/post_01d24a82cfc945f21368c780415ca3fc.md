# 10.3.2 Automating the Attack

The SQL injection process we followed was automated using several tools pre-installed on Kali Linux. In particular, sqlmap can identify and exploit SQL injection vulnerabilities against various database engines.

Let's run sqlmap on our sample application. We will set the URL we want to scan with -u and specify the parameter to test using -p

```
kali@kali:~$ sqlmap -u http://192.168.50.19/blindsqli.php?user=1 -p user

# 10.3.4 Running sqlmap to Dump Table

We're dealing with a blind time-based SQL vulnerability, the process of fetching the entire database's table is slow, but eventually we manage to obtain all users' hashed credentials. Another sqlmap feature is the --shell parameter, which provides us with a interactive shell. Due to high latency, time-based SQLi is not ideal when interacting with a shell, so we will use UNION-based SQLi.
