# 12.3.3 Automating the Process

Now that we have learned how to manually evade an AV via PowerShell, let's explore how to automate AV evasion payloads.

Shelter²⁸⁵ is a dynamic shell injection tool and one of the most popular free tools capable of bypassing antivirus software. It uses a number of novel and advanced techniques to backdoor a valid and non-malicious executable file with a malicious shellcode.

While the details of the techniques Shelter uses are beyond the scope of this Module, it essentially performs a thorough analysis of the target PE file and the execution paths. It determines where it can inject its shellcode without relying on traditional injection techniques that are easily caught by AV engines. Those including changing of PE section permissions, creating new sections, and etc.

Finally, Shelter attempts to use the existing PE Import Address Table (IAT)²⁸⁶ entries to locate functions that will be used for the memory allocation, transfer, and execution of our payload.

> A Shelter Pro version that supports both 32 and 64-bit binaries, which includes stealthy anti-AV features, is also available.

With a little bit of theory behind us, let's attempt to bypass our current Avira antivirus software using Shelter. We can install Shelter in Kali Linux using the apt command.

```
kali@kali:-$ apt-cache search shelter
shellter - Dynamic shellcode injection tool and dynamic PE injector
kali@kali:-$ sudo apt install shelter
```

Since Shelter is designed to run on Windows operating systems, we will also install wine,²⁸⁷ a compatibility layer for running wine32 applications on several POSIX-compliant operating systems.

```
kali@kali:-$ sudo apt install wine
root@kali:-# dpkg --architecture i386 && apt-get update &&napt-get install wine32
```

Once everything is installed, running the shelter command in the local Kali terminal will provide us with a new console running under wine.
