| Listing 847 - Exporting Kerberos protocol TGT/TGS to disk |

The above command exports the LSASS Kerberos ticket in memory for any TGT/TGS, which is then saved to disk in the kirbi minimkat format that initiated a session, we can try to inject one of the tickets into the user's sessions.

We can verify newly generated tickets with dir, filtering out the kirbi extension.

```
PS C:\> dir *.kirbi
```
