Listing 892 - Examing the Git repository

Listing 892 shows there are two commits in the repository. One is labeled as **Removed staging script and internal network access**. That's interesting as it indicates that the machine previously had access to the internal network. In addition, the first commit may contain a staging script that was removed.

We could switch back to a specific commit using **git checkout** and a commit hash. However, this could break the functionality of the web application and potentially disrupt the client's day to day.

A better approach is to use **git show**, which shows differences between commits. In our case, we'll supply the hash of the latest commit to compare as we are interested in the changes after the first commit.

```
root@websrv1:/srv/www/wordpress# git show 612ff5783c53dbd1e088523dba8374a84aaf1
commit 612ff5783c53dbd1e088523dba8374a84aaf1 (HEAD, master)
Author: <root@websrv1>
Date: Tue Sep 27 14:16:25 2022 +0000
```

Removed staging script and internal network access
