> Listing 813 - Using impacket-GetUserSPNs to perform Kerberoasting on Linux

Listing 813 shows that we successfully obtained the TGS-REP hash.

> If impacket-GetUserSPNs throws the error KRB_AP_ERR_SKEW (Clock skew too great), we need to synchronize the time of the Kali machine with the domain controller. We can use ntpdate¹¹¹⁴¹¹⁵ to do so.

Now, let's get the TGS-REP hash in a file named hashes.kerbero2 and crack it with Hashcat as we did before.

```
kali@kali:~ sudo hashcat -m 13100 hashes.kerbero2 /usr/share/hashcat/rules/rockyou.txt -r /usr/share/hashcat/rules/best64.rule --force
```
