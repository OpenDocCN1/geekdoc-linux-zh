# 21.2.2 Enumerating Active Directory using PowerShell and .NET Classes

There are several ways we can use to enumerate Active Directory. PowerShell cmdlets like Get-ADUser1016 work but they are only installed by default on domain controllers as part of the Remote Server Administration Tools (RSAT). 1017 RSAT is very rarely presented on clients in a domain and we must have administrative privileges to install them. While we can, in principle, the DLL required for enumeration ourselves, we will look into other options.

We'll develop a tool that requires only basic privileges and is flexible enough to use in real-world engagements. We will mimic the queries that occur as part of RSAT's regular operation. This will help us understand the basic concepts used in the pre-built tools we will use later.

Specifically, we'll use PowerShell and .NET classes to create a script that enumerates the domain. Although PowerShell development can seem complex, we'll take it one step at a time.
