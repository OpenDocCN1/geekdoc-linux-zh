Once we're done with the connection, we need to remember to delete the firewall rule we just created.

Using netsh advfirewall firewall, we can delete the rule, referencing it by its catchy name: "port_forward_ssh_2222".

```
C:\Users\Administrator>netsh advfirewall firewall delete rule name="port_forward_ssh_2222"
```

Deleted 1 rule(s). Ok.

> Listing 584 - Deleting the firewall rule with Netsh.

The command completes successfully, and we receive confirmation that the firewall rule was deleted.

We can also delete the port forward we created. This time we'll use the netsh interface subcontext we created. We will reference the forwarding port (v4ipv4) and the listenaddress and listenport we used when creating the rule, so Netsh can determine which rule to delete.

```
C:\Windows\Administrator> netsh interface proxy delete v4ipv4 listenport=2222 listenaddress=192.168.0.54
```
