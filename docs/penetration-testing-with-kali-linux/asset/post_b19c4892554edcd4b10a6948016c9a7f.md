## 2.2 Enumerating Active Directory using PowerShell

There are several ways to enumerate Active Directory. While net.exe is useful, PowerShell cmdlets are more powerful and flexible for modern environments. For example, the Active Directory module provides a wide range of commands to retrieve detailed information.

To start, we can use the Get-ADUser cmdlet to list all users in the domain:

```powershell
PS C:\>> Get-ADUser -Filter *
```

This allows us to see all user objects, which can then be filtered or de-facto de-facto de-facto de-facto look for specific attributes.
