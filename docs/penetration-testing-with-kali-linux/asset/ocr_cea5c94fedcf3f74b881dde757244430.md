856 - Basic work environment for this penetration test

Now that we set up a work environment, we are ready to enumerate the first target machine, MAILSRV.

> Documenting your findings is a crucial process for every penetration test. For this Module, we'll store in the basic work environment we just set up. However, Markdown editors, such as Obsidian,¹¹⁷³ have become quite popular for documenting findings and data in real assessments as they are application-independent and contain functions that will simplify writing and collaboration.¹¹¹⁷⁴

Let begin with a port scan of MAILSRV using Nmap. A port scan is often the first information gathering method we'll perform to get an overview of open ports and accessible services.

> In a penetration test, we would also use passive information gathering techniques such as Google Dorks and leaked password databases to obtain additional information. This would provide us with usernames, passwords, and sensitive information.

We'll use -sV to enumerate service and version detection as -sC to Nmap's default scripts. In addition, we'll enter -O to create an output file containing the scans.

```
kali@kali:~/beyond$ sudo nmap -sC -sV -on mailsrv1/nmap 192.168.50.242
```
