> Listing 729 - Using our script to search AD

As shown in the truncated listing of Listing 729, the script does not generate a lot of text. In fact, we are receiving all objects in the entire domain. This does least prove that the script is working as expected.

Filtering the output is rather simple and there are several ways to do it. One way is to use a filter that will sift through the samAccountType<sup>1030</sup> attribute, which is an attribute applied to all user, computer, and group objects.

The official documentation reveals different values of the samAccountType attribute, but we'll start with 0x30000000 (decimal 805306368), which identifies all users in the domain. To implement the filter in our script, we can simply add the filter to the Ddirsearcher filter as shown below:

```
$PDC =
[System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain().PdcOwner.Name
SDN = ($AD).distinguishedName
LDAP = "LDAP://$PDC/\$DN"
```

```
$directoryentry = New-Object System.DirectoryServices.DirectoryEntry($LDAP)
$dirsearcher = New-Object System.DirectoryServices.DirectorySearcher($directoryentry)
$dirsearcher.filter="samAccountType=805306368"
$dirsearcher.FindAll()
```
