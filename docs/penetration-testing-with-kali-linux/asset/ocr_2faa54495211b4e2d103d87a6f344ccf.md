Listing 257 - Successful Dictionary Attack on the Login Form

In this case, our dictionary attack was successful and we identified a valid password (121212) for our user. Let's try to log in to confirm the credentials.

![](bbox=[0.177, 0.345, 0.822, 0.498])

According to the output in Figure 22, we logged in. Nice!

With any dictionary attack, this generates a lot of noise and many enemies. If installed, a Web Application Firewall (WAF)⁶⁰⁵ would block this activity quickly. Other brute force protection applications could also block this, as fail2ban⁶⁶ locks a user out after a set number of failed login attempts. However, we serbers aren't afforded this type of protection, making this a highly effective vector against those targets.

In general, dictionary attacks can be quite effective, especially if we begin with some type of known information and balance our attack in consideration of potential defense mechanisms.
