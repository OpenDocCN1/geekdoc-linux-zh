As an alternative method to WMI for remote management, WinRM can be employed for remote hosts management. WinRM is the Microsoft version of the WS-Management protocol and it exchanges XML messages over HTTP and HTTPS. Its use TCP port 5985 for encrypted HTTPS traffic and port 5986 for plain HTTP.

In addition to your PowerShell built-utilities, which we will cover later in this section, WinRM is implemented in numerous wins (Windows Remote Shell).

The wins utility can be invoked by specifying the target host using the -r argument and the username and password with -u and -p, respectively. As a final argument, we want to specify the commands to be executed on the remote host. For example, we want to run the hostname and whoami commands to prove that they are running on the remote target.

Since wins works for domain users, we execute the whole command once we logged in as jeff on CLIENT74 and jen's command arguments.

```cmd
C:\Users\jeff>wins -r:files04 -u:jen -pNexus123! "cmd /c hostname & whoami"
FILES04
corp\jen
```

The output confirms that we have executed the commands remotely on FILES04.
