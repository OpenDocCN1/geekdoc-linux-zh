# 6.2.1 Whois Enumeration

Whois²¹ is a TCP server, tool, and type of database that can provide information about a domain name, such as the name server²¹² and registrar²⁴ This information is often public, since registrars charge a fee for provision.

We can gather basic information about a domain name by executing a standard forward search and passing the domain name, megacorp.com, into whois, providing the IP address of our Ubuntu WHOIS server as an argument of the (-h) parameter.

```
kalikal@~$ whois megacorp.com -h 192.168.50.21
```
