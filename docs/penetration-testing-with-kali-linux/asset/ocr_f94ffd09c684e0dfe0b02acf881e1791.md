Before crafting any attack strategy, we need to know the exact number of columns in the target table. Although the above output shows that four columns are present, we should not assume based on the application layout, as there may be extra columns.

To discover the correct number of columns, we can submit the following injected query into the search bar:

```
' ORDER BY 1 --
```

> Listing 196: Verifying the exact number of columns

The above statement orders the results by a specific column, meaning it will fail whenever the selected column does not exist. Increasing the column value by one time, we'll discover that the table has five columns, so ordering by column six returns an error.
