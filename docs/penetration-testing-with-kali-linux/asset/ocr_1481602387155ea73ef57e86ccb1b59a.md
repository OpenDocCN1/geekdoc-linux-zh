# Figure 242: The network layout from our perspective so far

One of the first things to notice about this diagram is there are two named networks: the Wide Area Network (WAN) on the left and the Demilitarized Zone (DMZ) on the right. Our Kali machine is in the WAN, the PostgreSQL database server PGDATABASE01 is in the DMZ, and the Confluence server CONFENCE straddles both.

A WAN is a network that is large and expanse. Some large organizations will refer to their large internal network as a WAN, or internal WAN. In this case, since we're simulating an attack from an external network, the WAN represents a large corporate network, or the internet itself.

> Throughout the exercises in this Module, our Kali machine will be situated in the WAN. We will be able to route directly from our Kali machine to hosts that are also on the WAN.

A DMZ is a network containing devices that may be more exposed to a wider, less trusted network. DMZ helps create a buffer zone between hosts on the wider, less trusted network and internal hosts. In this way, it serves a similar function to a real-world Demilitarized zone. In this scenario, the DMZ is the buffer network segment between the WAN and whatever other network we may find.

CONFLU01 is straddling both the WAN and DMZ to illustrate that it is able to communicate on both networks. CONFLU01 is also listening on TCP port 8090, illustrated by the "open socket" attached to the icon.

PGDATABASE01 is within the DMZ network boundary - it does not straddle the WAN/DMZ. Our Kali machine is not in the DMZ, so we cannot route directly to PGDATABASE01 PGDATABASE01 also has an "open socket" attached to it, illustrating that there's something listening on TCP port 5432 (this is likely a PostgreSQL server, since the default port is 5432).

> The only thing we know about PGDATABASE01 is so far that it exists, we don't know if it's attached to any other networks. If later we find PGDATABASE01 is attached to other networks, we will expand our network diagram.

With the credentials found on CONFLUENCE1, we want to connect to this PostgreSQL port from our Kali machine.
