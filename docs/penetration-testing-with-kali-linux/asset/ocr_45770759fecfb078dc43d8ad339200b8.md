# 8.4.2 JavaScript Refresher

JavaScript is a high-level programming language that became one of the main components of modern web applications. All modern browsers include a JavaScript engine that runs JavaScript code from within the browser itself.

When a browser processes a server's HTTP response containing HTML, the browser creates a DOM tree and renders it. The DOM is composed of forms, inputs, images, etc. related to the web page.

JavaScript's role is to access and modify the DOM, resulting in a more interactive user experience. From an attacker's perspective, this also means that if we inject JavaScript code into the application, we can access and modify the DOM. With the DOM, we can redirect login forms, extract passwords, and steal cookies.

Like many other programming languages, JavaScript can combine a set of instructions into a function.³364

```

  return x * y;
}

```

When declaring a variable, we don't assign any type to the variable, since JavaScript is a loosely typed language.³365 This means that the actual type of the variable is inferred as a Number based on the type of the invoked function, which are Number types.
