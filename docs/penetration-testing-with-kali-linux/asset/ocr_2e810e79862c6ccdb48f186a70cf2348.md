Listing 777- Domain Share Query

Listing 777 shares from three different servers. Although some of these are default domain shares, we should investigate each of them in search of interesting information.

In this instance, we'll first focus on SYSVOL¹1055 as it may include folders and files that the domain controller itself. This particular share is used for various domain policies and scripts. By default, the SYSVOL folder is mapped to %SystemRoot%SYSVOL\domain-name on the domain controller and every domain user has access to it.

```
PS C:\> ls \dc1.corp.com\sysvol\corp.com
Directory: \dc1.corp.com\sysvol\corp.com
```
