We will perform this attack with ntlmrelax, another tool from the impacket library.⁶⁷ This tool does
the heavy lifting for us setting up an SMB server and relaying the authentication part of an
incoming SMB connection to a target of ours.

Let's get into the attack by starting ntlmrelax, which we can use with the pre-installed
impacket-ntlmrelax package: we use --no-http-server to enable the HTTP server since we are
elaying an SMB connection and --smb2support⁸⁸ to add support for SMB2 We'll also use -t to set
the target to FILES02. Finally, we'll set our command with -c, which will be executed on the target
system as the relay. We'll use a PowerShell shell one-liner,⁸⁹ which'll be base64-
encode and execute as we've done before in this course. We should note
that the base64-encoded PowerShell shell one-liner is shortened in the following list,
it it uses the IP of our Kali machine and 8080 for the relay to connect.

```
kali@kali:~ sudo ntlmrelax --no-http-server -smb2support -t 192.168.50.212
Impacket v0.9.24 Copyright 2021 SecureAuth Corporation
```

