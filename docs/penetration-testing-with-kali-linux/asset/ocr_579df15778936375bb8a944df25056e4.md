Figure 13 shows that the web application blocked our upload, stating that PHP files are not allowed and with PHP file extensions are blacklisted. Since don't know exactly how the file is implemented, we'll use a trial-and-error approach to bypass it.

One method to bypass this is by changing the file extension to .php40 such as phps or php7. This might allow us to bypass simple filters that only check for the most common file extensions, php and phtml. These alternative file extensions were mostly used for older versions of PHP or specific cases, but are still supported for compatibility in modern PHP versions.

Another way we can bypass is by changing characters in the file extension to upper case. The blacklist may be implemented by comparing the file extension of the uploaded file to a list of strings containing only lower-case PHP extensions. If so, we can update the uploaded file extension with upper-case characters to bypass the filter.

Let's try the second method, updating our simple-backdoor.php file extension from .php to .PHP. After renaming the file in the terminal or file explorer, we'll use it via the web.
