To perform this, we will use Mimikatz on a domain-joined Windows machine, and impact-secretsdump128 on our non-domain joined Kali machine for the examples of this section.

Let' begin with Mimikatz and start connecting to CLIENT75 as jefadmin with the password RouhahaTungerateBroom2023!. As jefadmin is a member of the Domain Admins group, we already have the necessary rights assigned.

Once connected via RDS, let's open a PowerShell window and launch Mimikatz in C:\Tools. For Mimikatz to perform this, we use the lsadump:dcsync module and provide the domain username for which we want to obtain credentials as an /user. For the purposes of this example, we'll target the domain user dave.

PS C:\Users\jefadmin> cd C:\Tools\
PS C:\Tools> .\mimikatz.exe
