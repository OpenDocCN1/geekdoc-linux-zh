Penetration Testing with Kali Linux

According to the prompt, Mimikatz is running and we can enter through its command-line environment. Each command consists of a module and a command delimited by two colons, for example `privilege:debug.

We can use various commands to extract passwords from the system. One of the most common Mimikatz commands is sekursasa:logpasswords, which attempts to extract cleartext passwords and hashes from all available sources. Since this generates a huge amount of output, we will use lsadump:sam, which will extract the NTLM hashes from the SAM. For this, we must first enter token:elevate to SYSTEM user privileges.

For both commands, sekursasa:logpasswords and lsadump:sam, we must have the SeDePrivilege access enabled, which we will accomplish with `privilege:debug.

```
mimikatz # privilege:debug
Privilege '20' OK

mimikatz # token::elevate
Token Id : 0
User name :
```

> Listing 292 - Enabling SeDePrivilege, elevating to SYSTEM user privileges and extracting NTLM hashes

The output shows that we successfully enabled the SeDePrivilege access right and obtained SYSTEM user privileges. The output of the lsadump:sam command reveals two NTLM hashes, for one offsec and for nelly. Since we know that the NTLM hash of offsec was calculated from the plaintext password 'lab', we will skip it and focus on nelly's NTLM hash.

Let's copy the NTLM hash and paste it into nelly.hash in the passwordattacks directory on Kali machine.

```
kali@kali:~# passwordattacks$ cat nelly.hash
3ae8e5f0ffabb3a627672e1600f1ba10
```
