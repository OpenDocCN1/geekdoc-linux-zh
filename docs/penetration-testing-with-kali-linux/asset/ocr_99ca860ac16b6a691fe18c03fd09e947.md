In this Learning Unit, we will focus on Nessus, which is one of the most popular vulnerability scanners, containing over 67000 CVEs²297 and 168000 plugins²298

Nessus is available as Nessus Essentials and Nessus Professional²299 We will use the free version, Nessus Essentials, which comes with some restrictions and constraints. For example, we can only scan 16 IP addresses, and some templates and functions are not available. However, Nessus Essentials will give us insight into how to use the full commercial version and the general concepts discussed in this section will also apply to most commercial scanners.

# 7.2.1 Installing Nessus

For this Learning Unit, we will need to install Nessus on the Kali Linux VM, which is used to connect to the PEN-200 lab environment. An internet connection and email address will be necessary to download and activate Nessus. The minimum hardware requirements Tenable recommends³300 are 4 CPU cores and 8GB of RAM. However, we need to meet these requirements for our exercises.

Nessus is not available in the Kali repositories and must be installed manually. We can download the current version of Nessus as a 64 bit deb¹301 file from the Tenable website²302, we also get the SHA256³303 and MD5⁴304 checksums for the installer.

Let's select Linux - deb: amd64 and download the installer.
