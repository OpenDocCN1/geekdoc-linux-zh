# 20.4.1 Resource Scripts

Resource scripts can chain a series of Metploit console commands and Ruby code.
Meaning, we can use either the built-commands of Metploit or write code in Ruby¹100⁴ (as it's
t the language language is developed in) to manage control flow as well as develop advanced
logic components for resource scripts.
