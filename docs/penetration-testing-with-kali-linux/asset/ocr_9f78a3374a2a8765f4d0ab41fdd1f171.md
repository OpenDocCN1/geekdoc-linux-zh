# 10.3.2 Automating the Attack

The SQL injection process we followed was automated using several tools pre-installed on Kali Linux. In particular, sqlmap46 can identify and exploit SQL injection vulnerabilities against various database engines.

Let's run sqlmap on our sample application. We will set the URL we want to scan with -u and specify the parameter to test using -p

```
kali@kali:~$ sqlmap -u http://192.168.50.19/blindsqli.php?user=1 -p user
```

> Listing 207 - Running quickly to find SQL injection points

We submitted the entered URL after the -u speculator with the ?parameter set to a dummy value. Once launched, we can press Return on the default options. Sqlmap then returns confirmation that we are dealing with a time-blind SQL injection and provides additional fingerprinting information such as the web operating system, web application technology stack, and the backend database.

Although above command confirmed that the target URL is vulnerable to SQLi, we can extend our tradecraft by using sqlmap to dump the database table and steal user credentials.
