> > Listing 748 - Querying users in the domain

Get-NetUser enumerates all attributes on the user objects. This presents a lot of information, which can be difficult to digest.

In the script we created, we used loops to print attributes based on the information obtained. However, with PowerShell we can simply pipe the output into select, where we can choose the attributes we are interested in.

The output from Listing 748 shows that the cn attribute holds the username of the user. Let us pipe the output into select and choose the cn attribute:

```
PS C:\Tools> Get-NetUser | select cn
---

Administrator
Guest\krbtgt
dave
stephanie
jeff
jeffadmin
iis_service
pete
jen
```
