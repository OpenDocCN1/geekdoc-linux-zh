We should note that installing Telnet requires administrative privileges, which could present challenges if we are running as a low-privilege user. However, we could get the Telnet binary located on another development machine of ours at c:\windows\system32\telnet.exe and transfer it to our Windows machine we are testing.

Once we have enabled Telnet on the testing machine, we can connect to the target machine and perform enumeration from Kali.

# 6.3.6 SNMP Enumeration

Over the years, we have found that the Simple Network Management Protocol (SNMP) is not well-understood by many network administrators. This results in SNMP misconfigurations, which can result in significant information leaks.

SNMP is based on UDP, a simple, stateless protocol, and is therefore quite susceptible to IP spoofing and replay attacks. Additionally, the commonly used SNMP protocols 1, 2, and 2c offer no traffic encryption, meaning that SNMP information and credentials can be easily intercepted over a local network. Traditional SNMP protocols also have weak authentication schemes and are commonly left with default public and private community strings.
