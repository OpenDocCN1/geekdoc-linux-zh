Figure 131: Using with parameters that our input triggers an error.

The output in the Response section shows commands that our input triggers an error. This happens due to the space between the command and the parameters. There are different techniques we can use to bypass this limit, such as using Input Fields (IFS)⁴03 or URL encoding. Encoding a space is as "%20".⁴04

Let's replace the space with %20 and see.
