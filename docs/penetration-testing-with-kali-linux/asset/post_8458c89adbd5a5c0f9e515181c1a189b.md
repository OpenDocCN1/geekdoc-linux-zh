The DirectorySearch class queries against AD using LDAP. When creating an instance of DirectorySearcher, we must specify the AD service we want to query in the form of the SearchRoot property. According to Microsoft's documentation, this property indicates where the search begins in the AD hierarchy. Since the DirectoryEntry encapsulates the LDAP path that points to the top of the hierarchy, we pass that as a variable to DirectorySearcher.

The DirectorySearcher documentation lists FindAll(), which returns a collection of all the entries found in AD.

Let's implement these two classes into our script. The code below shows the relevant part of the script:

```powershell
$PDC =
[System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain().PdcOwner.Name
$DN = (($adsi').distinguishedName
$LDAP = "LDAP://$PDC\$DN"

$directory = New-Object System.DirectoryServices.DirectoryEntry($directory)
$dirsearcher = New-Object System.DirectoryServices.DirectorySearch($directory)
$dirsearcher.FindAll()
```

Listing 728 - Directory and DirectorySearch to our script

As indicated in Listing 728, we have added the $directory variable, which is encapsulating our LDAP path. The $dirsearcher variable contains the $directory variable and uses the information as the SearchRoot, pointing to the top of the hierarchy where DirectorySearch will run the FindAll().
