# Penetration Testing with Kali Linux

Due to the wealth of information gathering within DNS, it is often a lucrative target for information gathering.

Let's demonstrate this by using the `host` command to find the IP address of **www.megacorpome.com**.

```
kali@kali:~ host www.megacorpome.com
www.megacorpome.com has address 149.56.244.88
```

> Listing 38 - Using host to find the Host record for megacorpome.com

By default, the host command searches for an A record, but we can also query other fields, as MX or TXT records by specifying the record type in your query using the `-t` option.

```
kali@kali:~ host -t mx megacorpome.com
megacorpome.com mail is handled by 10 fb.mail.gandi.net.
megacorpome.com mail is handled by 20 spool.mail.gandi.net.
megacorpome.com mail is handled by 50 mail.megacorpome.com.
megacorpome.com mail is handled by 60 mail2.megacorpome.com.
```

> Listing 39 - Using host to find the MX records for megacorpome.com

In this case, we run the host command to fetch megacorpome.com MX records, which returned four different mail records. Each server has a different priority (10, 20, 50, 60) and the server with the lowest priority will be used to forward mail addressed to the megacorpome.com domain (fb.mail.gandi.net).

We then ran host command to retrieve only the megacorpome.com TXT records, which returned two entries.

```
kali@kali:~ host -t txt megacorpome.com
megacorpome.com descriptive text "Try Harder"
megacorpome.com descriptive text "google-site-verification=U7B_b0HnEbty4YQQZSYEFFCj32HMNV3Gtc0wWqSpA
```

> Listing 40 - Using host to find the TXT records for megacorpome.com

Let's host this hostname.

```
kali@kali:~ host www.megacorpome.com
www.megacorpome.com has address 149.56.244.88
```

> Listing 41 - Using host to search for a valid host

Now let's determine if megacorpome.com has a server with the hostname "idontextext". We'll observe the difference between the query outputs.

```
kali@kali:~ host idontextext.megacorpome.com
Host idontextext.megacorpome.com not found: 3 (NXDOMAIN)
```
