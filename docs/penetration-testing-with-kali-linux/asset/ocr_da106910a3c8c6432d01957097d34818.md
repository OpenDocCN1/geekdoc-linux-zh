As mentioned earlier, any Nmap service and OS enumeration output should be taken with grain of salt, as none of the algorithms are perfect.

Unlike Nmap's OS fingerprinting options we explored earlier, OS enumeration via NSE scripting provides extra information, such as the domain and other details related to Active Directory Domain Services.²⁷ This approach will also likely go unnoticed, as it produces less traffic that can also blend into normal enterprise network activity.

Having discussed SMB enumeration via Kali, let's learn how to enumerate it from a Windows client.

One useful tool for enumerating SMB shares within Windows environments is **view**. It lists domains, resources, and computers to a given host. As an example, connected to the client01 VM, we can find on dc01

```
C:\Users\student>net view \dc01 /all
Shared resources at \dc01
```

# 6.3.5 SMTP Enumeration

We can also gather information about a host or network from vulnerable servers. The Simple Mail Transport Protocol (SMTP)²⁷⁸ supports several interesting commands, such as VRFY and EXPN. A VRFY asks the server to verify an email address, while EXPN asks the server for the membership of a mailing list. These can often be used to verify existing users on a mail server, which is useful during a penetration test. Consider the following:

```
kali@kali:~$ nc -nv 192.168.50.8
(UNKNOWN) [192.168.50.8] (smtp) open
220 mail ESMP Postfix (Ubuntu)
VRFY root
252 2.0.0 root
VRFY identext
```
