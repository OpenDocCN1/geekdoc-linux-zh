Listing 654 - Start a active channel and background it

Now, let's list all active channels and interact with channel 1. To list all active channels, we can enter channel -l and interact with one,, we can use channel -l and the channel ID as argument.

```
meterpreter > channel -l
-----
Id  Class Type
---
1   3     stdapi_process
2   3     stdapi_process
```

```
meterpreter > channel -i 1
Interacting with channel 1...
```

```
uid=1(daemon) gid=1(daemon) groups=1(daemon)
```

Listing 655 shows we execute commands in the context of channel 1 again. Using channels will help us tremendously manage system access and perform post-exploitation operations.
