To create the previously created PSCredential object, a user first needs to create a SecureString to store the password. Then, the user can create the PSCredential object with the username and the password. The resulting variable, containing the object, can be used as argument for -Credential in commands as Enter-PSSession.
Let's copy the highlighted commands and paste it into our shell.

```
PS C:\Users\dave> $password = ConvertTo-SecureString "qwertqwert123!" -AsPlainText -Force
$password = ConvertTo-SecureString "qwertqwert123!" -AsPlainText -Force

PS C:\Users\dave> $cred = New-Object System.Management.Automation.PSCredential("daveadmin", $password)
