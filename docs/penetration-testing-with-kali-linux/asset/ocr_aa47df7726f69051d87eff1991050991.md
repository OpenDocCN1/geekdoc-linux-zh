Listing 731 - Recurring all users in the domain on samAccountType

This is great information to have, but we need to develop it a little further. When enumerating AD, we are interested in the attributes of each object, which are stored in the Properties field.

Knowing this, we can store the results from our search in a new variable. We will iterate through each object and print property on our own line via a nested loop as shown below.

```
$domainObj = [System.DirectoryServices.ActiveDirectory.Domain]::GetCurrent()
$SPOC = $domainObj.PdcRootOwner.Name
$DN = (($adsi)).distinguishedName
$LDAP = "LDAP:$SPOC"
```

```
$dentry = New-Object System.DirectoryServices.DirectoryEntry($LDAP)
$dsearcher = New-Object System.DirectoryServices.DirectorySearcher($dentry)
$dsearcher.filter="$samAccountType=80530638"
$result = $dsearcher.FindAll()
```

```
foreach($obj in $result)
{
    foreach($prop in $obj.Properties)
    {
        $prop
    }
    Write-Host "----------------------------------------------------------------"
}
```

Listing 732 - Adding a nested loop which will print property on its own line

This complete script will search through AD and filter the results based on the samAccountType of our choosing, then place the results into the new $result variable. It will further filter the results based on two loops. The first loop will extract the objects in $result and place them into the $obj variable. The second loop will extract the properties for each object and store the information in the $prop variable. The script will print $prop and present the output in the terminal.

While the Write-Host command is not required for the script to function, it does print a line between each object. This helps the output easier to read.
