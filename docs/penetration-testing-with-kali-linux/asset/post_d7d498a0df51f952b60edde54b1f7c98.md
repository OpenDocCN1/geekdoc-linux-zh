### 8.3.1 Debugging Page Content

A good place to start our web application information mapping is with a URL address. File extensions, which are sometimes part of a URL, reveal the programming language the application was written in. Some extensions, php, are straightforward, but others are more cryptic and vary based on the frameworks used.
