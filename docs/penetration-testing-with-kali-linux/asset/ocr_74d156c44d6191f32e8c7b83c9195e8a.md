Table-top sessions are part of Business Continuity Planning (BCP).⁸⁰ BCP also includes other aspects such as live drill responses to situations like ransomware and supply-chain compromise. # 3.4.7 Continuous Patching and Supply Chain Validation

Another defensive technique known as continuous automated patching is pulling the upstream source code and applying it to the lowest development environment. Next, the change is tested, and only moved to production if it is successful. We can leverage cloud provider infrastructure to easily spin up complete replicas of environments for testing these changes. Rather than continuously running a full test environment, we can create one with relative ease using our cloud provider, run the tests, then delete it. The primary risk of this approach is supply chain compromise.

Continuous supply chain validation occurs when people and systems validate that the software and hardware received from vendors is the expected material and that it't been tampered with, as well as ensuring output software and materials are verifiable by customers and partners. Continuous supply chain validation is difficult, and sometimes requires more than software checks, such as physical inspections of equipment ordered. On the software side of supply chain security, we can use deeper testing and inspection techniques to evaluate data more closely. We might opt to increase the security testing duration to attempt to detect sleeper malware in upstream sources. Sleeper malware is software that is inactive within a system or for a period of time, potentially weeks, before it starts action.

Utilizing a bill of materials (SBOM)⁸¹ as a way to track dependencies in the application build process greatly helps evaluate supply chain tampering. If we identify the software dependencies, create an SBOM with them, and package the container and SBOM together in a cryptographically-verifiable way, then we can verify the container's SBOM signature before loading it into production. This kind of process presents additional challenges for adversaries.
