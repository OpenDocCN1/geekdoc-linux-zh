# 13.3.2 传递 NTLM

在上一节中，我们获取了一个 NTLM 哈希并破解了它。根据密码的强度，这可能是耗时的或不可行的。在本节中，我们将演示如何利用用户名和 NTLM 哈希的有效组合而不是明文密码，对本地或远程目标进行身份验证。

首先，我们将演示哈希传递（pass-the-hash, PtH）技术。
