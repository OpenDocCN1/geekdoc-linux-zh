Listing 815 - Accessing the web page on Web0 as user jeff

Listing 815 shows that we cannot access the web page as jeff. Let's start collecting the information needed to create a silver ticket.

Since we are a local Administrator on this machine where iis_service has an established session, we can use Mimikatz to retrieve the SPN password (NTLM hash of iis_service), which is the first piece of information we need to create a silver ticket.

Let's start PowerShell as Administrator and launch Mimikatz. As already learned, we can use privilege:debug and sekurlsa::logonpasswords to extract AD credentials.

```
mimikatz # privilege:debug
Privilege '20' OK

mimikatz # sekurlsa::logonpasswords
```

Listing 816 shows the password hashes of the iis_service user account. The NTLM hash of the service account is the first piece of information we need to create the silver ticket.

Now, let's get the domain SID, the second piece of information we need. We can use whoami /user to get the SID of the current. Alternatively, we could also retrieve the SID of the SPN user account from the output of Mimikatz, since domain user accounts exist in the same domain.
