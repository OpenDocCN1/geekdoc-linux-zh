Whereas previously, a cloud service may have been required to obtain different authorizations for different federal agencies, FedRAMP allows a cloud service to obtain a single authorization for all government agencies. Its goal is to accelerate the government's adoption of cloud services while ensuring that these services are secure. The controls are based off of NIST SP 800-53 Revision 4 and enhanced by a number of additional controls that pertain specifically to cloud computing. # 3.6 Career Opportunities in Cybersecurity

This Learning Unit covers the Learning Objective:

+   - Identify career opportunities in cybersecurity

There are increasingly many jobs available within the larger field of Cybersecurity. The field expands extremely fast, and organizations use disparate titles to describe similar roles, making it impossible to list every potential career.

With this in mind, let's explore various cybersecurity roles. We will describe their day-to-day functions and provide some guidance regarding the kind of person that might be interested in pursuing different roles. We will also mention areas in the OffSec Training Library where learners can pursue Modules to match each role.

# 3.6.1 Cybersecurity Tester Career Opportunities: Attack

**Penetration Tester**: A Penetration Tester¹⁰ is responsible for discovering and exploiting vulnerabilities that exist in a targeted network. This career may be a good choice for someone who has a strong understanding of networking and systems and enjoys finding ways of subverting their security measures. This role also benefits from technical writing abilities. To learn such skills, we suggest reviewing OffSec's PEN courses at the 100, 200, and 300 levels.

**Web Application Tester**: A Web Application Tester¹¹ is responsible for testing web applications for security weaknesses. A good candidate for this role likely has a strong knowledge of web application vulnerabilities, enjoys testing them, and subverting the security measures they employ. The skills required to become a Web Application Tester are covered in the WEB at 100, 200, and 300 levels. These Modules teach the basics of how web applications work as well as black-box and white-box approaches to web testing.

**Cloud Penetration Tester**: A Cloud Penetration Tester¹² is responsible for performing penetration testing on cloud infrastructure. This may be a good career path for someone who has knowledge and experience in cloud infrastructure and penetration testing. With other penetration testing positions, you may enjoy this role if you have infrastructure for weaknesses and figuring out ways to exploit them. CLD-100 teaches learners how to test, attack, and exploit cloud technologies.
