Penetration Testing with Kali Linux

If we browse to the /ui path we'll discover the entire APIs' documentation. Although this is common during white-box testing, is not a luxury we normally have during a black-box test.

Let's first inspect the /users API with curl.

```
kali@kali:~$ curl -i http://192.168.50.16:5002/users/v1
```

> Listing 108 - Obtaining Users' Information

The application returned three users, including an administrative account that seems to be worth further investigation. We can use this information to attempt another brute force attack with gobuster, this time targeting the admin user with a smaller wordlist. To verify if any API property relates to the username we found, we expand the API path by inserting the admin at the end of the url.

```
kali@kali:~$ gobuster dir -u http://192.168.50.16:5002/users/v1/admin/ -w /usr/share/wordlists/dirb/common.txt
```
