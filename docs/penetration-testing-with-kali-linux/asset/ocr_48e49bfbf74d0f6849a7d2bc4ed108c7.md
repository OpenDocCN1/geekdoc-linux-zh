# 14.1.4 Fixing the Exploit

Let's closely review the C code. Further inspection reveals the use of a return address located in the Visual Basic 6.0 runtime msvvm60.dll, which is not part of the vulnerable software. Examining the modules in the debugger on our Windows client, we notice that this DLL is absent, meaning the return address is not valid for our target.

To verify this, we first need to start the Sync Breeze Service on the Windows 10 client. We can launch Immunity Debugger as administrator, click File -> Attach, and select the syncbr process. Once attached, click the View menu, Execute modules. From there, we can verify that msvvm60.dll is not present by checking the Name and Path values.
