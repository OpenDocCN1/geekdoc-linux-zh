# 8.3.2 Inspecting HTTP Response Headers and Headers

We can also search server responses for additional information. There are two types of tools we can use to accomplish this. The first is a proxy, like Burp Suite, which intercepts requests between a client and a web server, and the other is the browser's Network tool.

We will explore both approaches in this Module, but let's begin by demonstrating the Network tool. You can learn from the Firefox Web Developer menu to review HTTP headers and responses. This tool shows network activity that occurs after it launches, so we must refresh the page to display traffic.
