List 258: Comparing hash values for secret and secret1

In this example we used 'secret' to show that the resulting hash is always the same. Notice that the hashes for 'secret' and 'secret1' are completely different when the input strings are similar. Note also that the hash for 'secret1' matches our captured hash. This means we have determined the plaintext password ('secret1') associated with that hash. Very cool.

However, this is a very simple and awkward way to crack passwords. Fortunately there are much better tools available. Hashcat and John Ripper (JRR) are two of the most popular cracking tools. For example, JRR is more of a CPU-based cracking tool, which also supports GPUs, while Hashcat is a GPU-based cracking tool that also supports CPUs. JRR can be run without any additional drivers using only CPUs for password cracking. OpenCL or CUDA for GPU processing. For most algorithms, a GPU is much faster than a CPU since GPUs contain cores, each of which can share part of the workload. slow hashing algorithms (like bcrypt) work better on CPUs.

It's important to become familiar with different tools since they don't support all the algorithms. We will examine these tools in this Module.

Before we begin cracking passwords, let's calculate the cracking time of various hash representations. The cracking time can be calculated by dividing the keyspace with the hash rate.

The keyspace consists of the character set to the power of the number of characters or length of the original information (password). For example, if we use the lower-case Latin alphabet (26 characters), uppercase alphabet (26 characters), and the numbers from 0 to 9 (10 characters), we have a character set of 62 variations for every character. If we are faced with a five-character password, we are facing 62 to the power of five possible passwords containing these five characters.

It's important to be able to calculate this, let's use a terminal to calculate the keyspace for a five-character password by echoing our character set with -c to count every character. We will again specify -n for the echo to strip the newline character. We can then use python3 for the calculation, -c to execute the calculation and print to display the result.

```
kali@kali:$ echo -n 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'
| wc -c
62
```
