Listing 385 - Active network connections on CLIENTW220

The output of listing 385 shows that 40 and 83 are listening, indicating that a web server is running on the system. Additionally, one port of 3306 is indicative of a running MySQL⁴ server.

The output also shows Netcat connection on port 444 as well as an RDP connection from 192.168.119.4 on port 3389. We are not the only user currently connected to the system. One may manage to elevate privileges, using Mimikatz and attempt to extract credentials of the user.

Next, we'll check installed applications. We can query registry keys⁷⁵⁵ to list 32-bit and 64-bit applications in the Windows Registry with the Get-ItemProperty⁷⁵⁶ Cmdlet. We pipe the output to select with the argument displayname to only display the application of names. We will begin with the 32-bit applications and display the 64-bit applications.

```
PS C:\Users\ave> Get-ItemProperty
HKLM:\SOFTWARE\W6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* | select
```
