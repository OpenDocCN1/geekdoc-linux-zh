In this section, we will focus on the vuln category to learn Nmap as a lightweight vulnerability scanner.

On our Kali VM, the NSE scripts can be found in the /usr/share/nmap/scripts/ directory with the nmap filetype. This directory also contains the script.db file, which serves as an index to all currently available NSE scripts. We can use it to get a list of scripts in the vuln category.

```
kali@kali:$ cd /usr/share/nmap/scripts/
kali@kali:/usr/share/nmap/scripts$ cat script.db | grep '\"vuln\"'
Entry { filename = "afp-path-vuln.nse", categories = { "exploit", "intrusive", "vuln" } }
Entry { filename = "broadcast-avahi-dos.nse", categories = { "broadcast", "dos", "intrusive" } }
Entry { filename = "clamav-vuln.nse", categories = { "exploit", "vuln" } }
Entry { filename = "distsec-cve2004-2687.nse", categories = { "exploit", "intrusive", "vuln" } }
Entry { filename = "dns-update.nse", categories = { "intrusive", "vuln" } }
```

Each entry has a file name and categories. The file names represent the type of the NSE script in the NSE directory.

Some of the standard NSE scripts are quite outdated. Fortunately, the vulners^337 script integrated, which provides current vulnerability information about detected service versions from the Vulners Vulnerability Database^338 The script itself has the categories safe, vuln, and external.

Before we start our first scan with the NSE, we will examine the Nmap -script parameter. This parameter is responsible for determining which scripts get executed in a scan. The arguments for this parameter can be a category, a Boolean expression, comma-separated lists, the file path or wildcard-name of a NSE script in script.db, or an absolute path to a specific script.

Let's start with an Nmap scan using all the NSE scripts from the vuln category. The command we'll use the previously mentioned -script parameter with the vuln argument, which specifies all of the scripts with this. Furthermore, we will use -SV to activate the Nmap's service detection capabilities. Finally, we use -p to scan port 443.

```
kali@kali:$ sudo nmap -SV -p 443 --script "vuln" 192.168.50.124
[sudo] password for root:
Starting Nmap 7.92 (https://nmap.org)

PORT STATE SERVICE
443/tcp open Apache http 2.4.44 (Unix))
```
