# ## 24.3.1 Domain Credentials

In this section, we'll attempt to identify combinations of usernames and passwords on MAILSRV1. Let's begin by using the current information in creds.txt file to create a list of usernames and passwords. Let's begin by reviewing the current information in creds.txt.

```
kali@kali:~/$ creds.txt
daniela:tequieromucho (SSH private key password)
wordpress:DanielKeyboard3311 (WordPress database connection settings)
john:dqsTwTpZpn# (fetch-current.sh)
```

Other identified users:\marcus

Based on Listing 894, we'll create a list of usernames for marcus, john, and daniela.
