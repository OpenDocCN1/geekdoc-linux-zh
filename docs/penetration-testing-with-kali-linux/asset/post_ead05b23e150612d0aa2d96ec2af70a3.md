Listing 461 - A list of running processes on Linux

The output lists several processes running as root that are searching for possible vulnerabilities. We notice the ps command we ran listed in the output, out by the current user. We can also filter the specific-user owned process from the appropriate username.

The next step in our analysis of the target is to review network interfaces, routes, and open ports. This information can help determine if the compromised target is connected to multiple networks and therefore could be used as a pivot. The presence of specific virtual interfaces may indicate the presence of virtualization or antivirus software.

> An attacker may use a compromised target to pivot, or move between networks. This may amplify network vulnerability and allow the attacker to target hosts not directly reachable from the original attack machine.

We also investigate port bindings to see if a service is available on a loopback address, rather than on a routable one. Investigating a privileged process or service listening on the loopback interface could expose our attack surface and increase our probability of a privilege escalation attack's.

Depending on the Linux, we can check the TCP/IP configuration of every adapter either with ifconfig or addr. While the former displays interface statistics, the latter provides a compact view of the same information. Both commands accept the flag to display all information.

```
joe@debian-prevesc:$- ip a
lo:<LOOPBACK,UPPER,LOWER> mtu 65536 qdisc no state UNKNOWN qlen 1000
loopback 00:00:00:00:00 inet 127.0.0.1/8 lo
```
