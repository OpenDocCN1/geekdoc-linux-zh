## 13.3.4 Relaying-NTLMv2

In this section, we will have access to FILES01 as a privileged user (files0admin), which means we cannot run Mimikatz to extract passwords. Using the steps from the previous section, we obtained the Net-NTLMv2 hash, but couldn't crack it because it was too complex.

What we can assume on the username that the user may be a local administrator on FILES02. Therefore, we can try to use the hash on another machine in what is known as a relay attack:

In this attack, we again use the dir command in the shell to create an SMB connection to our Kali machine. Instead of merely printing the Net-NTLMv2 hash in the authentication section, we'll step forward to FILES02. If files0admin is a local user of FILES02, the authentication is valid and accepted by the machine. If local administrator privileges, we can use it to authenticate and then execute commands over SMB with methods similar to those used by psexec or wmieec.

> In this example we don't use the local Administrator user for the relay attack as we did for the pass-the-hash attack. Therefore, the target system needs to have UAC remote restrictions disabled or the command execution will fail. If UAC remote-restrictions are enabled on the terminal we can only use the local Administrator for the relay attack.

We will perform this attack with ntlmrelax, another tool from the impacket library.⁶ This tool does the heavy lifting for us setting up an SMB server and relaying the authentication part of an incoming SMB connection to a target of ours.

Let's get into the attack by starting ntlmrelax, which we can use with the pre-installed imppacket-ntlmrelax package: we use --no-http-server to enable the HTTP server since we are relaying an SMB connection and --smb2support⁸ to add support for SMB2. We'll also use -t to set the target to FILES02. Finally, we'll set our command with -c, which will be executed on the target system as the relay. We'll use a PowerShell shell one-liner,⁹, which'll be base64-encode and execute as we've done before in this course. We should note that the base64-encoded PowerShell shell one-liner is shortened in the following list, it uses the IP of our Kali machine and 8080 for the relay to connect.

```
kali@kali:~ sudo ntlmrelax --no-http-server -smb2support -t 192.168.50.212
Impacket v0.9.24 Copyright 2021 SecureAuth Corporation
```
