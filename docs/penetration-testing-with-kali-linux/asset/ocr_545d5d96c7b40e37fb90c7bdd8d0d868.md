DevSecOps DevSecOps¹² (an abbreviation for Development, Security and Operations) is an approach to software development that integrates security into all stages of the software development lifecycle, rather than postponing it to the end. A DevSecOps Engineer¹³ is responsible for automating security and other security-related processes. This role might be a good fit for someone who has an understanding of Continuous Integration / Continuous Development (CI/CD) pipeline tools, an interest in security testing automation, and the ability to work in a fast-paced environment.

The OffSec Library contains a considerable number of resources that can help learners with software development, understanding the different attack vectors to automate testing and for types of automation tools available. This information can be found in the WEB and PEN courses at 200 and 300 level. CLD-100 also provides details about Docker and Kubernetes: essential tools for DevSecOps.

Site Reliability Engineer: A Site Reliability Engineer¹⁴ is responsible for ensuring and improving the availability and performance of software systems. A person may wish to be a Site Reliability Engineer if they have software development experience and are interested in using automation to monitor for, alert, and respond to reliability-related issues. learners can learn about and Kubernetes, some of the key technologies used to support SRE, by following CLD-100 in the OffSec library.

System Hardener (System Administrator). A System Hardener¹⁵ is responsible for configuring systems to reduce their security risk. This involves changing insecure configurations, removing unused programs, ensuring firewalls are appropriately restrictive, etc. A person may seek out this course if they have experience with system administration, are familiar with techniques, and enjoy making systems and the data they store more secure. Many of the skills required for this position are covered in the PEN track at 100, 200 and 300 level. PEN-100, for instance, explores some of the basics of networking and system administration. PEN-200 describes some of the common techniques that attackers use. PEN-300 teaches advanced techniques that attackers use to bypass defenses.
