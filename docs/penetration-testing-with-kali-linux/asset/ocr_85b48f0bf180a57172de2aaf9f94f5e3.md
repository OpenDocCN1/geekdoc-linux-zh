# 2.3.3 Web Application and Client Side Attacks

It is now time to start learning perimeter attacks. perimeter attacks, we mean methods of infiltration that can be reliably done from the internet. In other words, attacks that can be initiated without any sort of access to an organization's internal network.

We begin with an extensive exploration of Web Application attacks. There are two primary reasons for starting here. The first is that Web vulnerabilities are among the most common attacks vectors available to us, since modern web apps allow users to submit data to them. The second is that web applications are inherently visual and therefore provide us with a nice interface for understanding why attacks work in the way they do.

Introduction to Web Applications begins by covering a methodology, a toolset, and an enumeration framework related to web applications that will help us through the course. It then covers our first vulnerability class: Cross-Site Scripting (XSS). XSS is an excellent vulnerability to start with because it targets the user of a web application as opposed to the server running it. Since the vast majority of our regular-to-day usage of web applications is as normal users, XSS can be unintuitive, compared to other types of attacks.

> Due to the fact that XSS targets users, it can be considered both a Web Application attack and a Client-Side attack as we'll learn soon.

In our exploration of web application attacks in Common Web Application Attacks, we survey four different kind of vulnerabilities. Directory Traversal provides us with an example of how we can access information that's not supposed. File Inclusion shows us what can happen when configurations are not set judiciously by a web administrator. Upload Vulnerabilities demonstrate how we can take advantage of the ability to upload our files to a web server. Command Injection allows us to run any code of our choice on the web server itself.

Our examination of web-based attacks includes a detailed Module on SQL Injection, otherwise known as SQLi. This vulnerability class is particularly important not only because of how common it is, but because it teaches us how weaknesses can arise in a system due to multiple components interacting with each other in complex ways. In the case of SQLi, a web server and a database need to be set up in precise ways so that we attackers cannot abuse them.

Client-Side Attacks are another very common class of attacks. They generally deal with methods of attacking human users of computer systems. In this Module, we'll learn how to perform reconnaissance on a system, attack users of common programs like Microsoft Office, and even how to abuse Microsoft Library Files.
