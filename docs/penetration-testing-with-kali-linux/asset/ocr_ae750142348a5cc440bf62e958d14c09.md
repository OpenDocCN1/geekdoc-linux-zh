Penetration Testing with Kali Linux

By Kerberos authentication, an attacker could send to the domain controller on behalf of any user. After obtaining the AS-REP from AS-REQ the domain controller, an attacker could perform an offline attack against the encrypted part of the response. This attack is known as AS-REP Roasting.¹1107

By default, the AD user account Do not require Kerberos preauthentication is disabled, meaning that Kerberos preauthentication is performed for all users. However, it is possible to enable this account manually. In assessments, we may find accounts with this option enabled as policies and technologies require it to function properly.

Let's perform this attack from our Kali machine, first then Windows. On Kali, we can use impacket-GetNPUers¹¹⁰⁸ to perform AS-REP roasting. We need to enter the IP address of the domain controller as an argument --dc-ip, the name of the output file in the AS-REP hash will be stored in Hashcat format --outputfile, and --request to request the TGT.

Finally, we need to specify the authentication information in the format domain/user. For this example, we will use pete with the password Nexus123! The following command is shown:

```
```\ikal@kali:$ impacket-GetNPUers -dc-ip 192.168.0.50 -request --outputfile\hashes.asreproastcorp.com/petenImpacket v10.0 - Copyright 2022 SecureAuth Corporation\```
```
