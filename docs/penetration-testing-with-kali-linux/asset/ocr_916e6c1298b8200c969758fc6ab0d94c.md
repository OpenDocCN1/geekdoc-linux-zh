# 23.2.2 Shadow Copies

A Shadow Copy,$1168$ also known as Volume Shadow Service (VSS) is a Microsoft backup technology that allows creation of snapshots of files or entire volumes.

To manage shadow copies, the Microsoft signed binary vshadow.exe,$1169$ is offered as part of the Windows SDK.$1170$

As domain admins, we have the ability to use the shadow utility to create a Shadow Copy that will allow us to extract the Active Directory Database NTDS.dit database.$1171$ Once we have obtained a copy of said database, we can extract every user credential on our local Kali machine.

To start off, we connect as the jeffadmin domain to the DC1 domain controller and launch from an elevated the vshadow utility with -nw options to disable writers,$1172$ which speeds up backup creation and include the -p option to save the copy on disk.

```
C:\Tools\vshadow.exe -nw -p C:
```
