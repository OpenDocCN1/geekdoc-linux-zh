Listing 623 shows the results of the port scan performed with Nmap. As stated before, if the database service is running, Metasploit will log findings and information about discovered hosts, or credentials in a convenient, accessible database.

To get a list of all discovered hosts up to this point, you can enter hosts.

```
msf6 > hosts

```
