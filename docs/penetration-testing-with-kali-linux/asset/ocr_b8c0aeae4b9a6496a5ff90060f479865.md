# Linux Kernel - 4.13.9 (Ubuntu 16.04 / Fedora 27) - Local Privilege Escalation
linux/local/40510.c

Using searchsplit to find privilege escalation exploits for our target

Let's try the exploit as it targets local/45010.c, since it seems to be newer and matches our kernel version as it targets any version below 4.13.9.

We'll use gcc⁸⁷ on Linux to compile our exploit, keeping in mind that when compiling, we must match the target architecture. This is es important in situations where the target machine does not have a compiler and we are forced to compile the exploit on our attacking machine or in a sandboxed environment that replicates the OS and architecture.
