Listing 597 - Using ss to check if SOCKS port has opened

SOCKS port 1080 is listening on the loopback interface of the Kali machine. Let's use this to connect to the SSH server on PGDATABASE01. In Redirection and SSH Tunneling, we created SOCKS ports with both dynamic forwarding and we've not yet run SSH itself through SOCKS proxy. SSH does not offer a generic SOCKS proxy command, instead it offers a ProxyCommand option. We can either write this into a configuration file or pass it as part of the command line. ProxyCommand accepts a shell command used to open a proxy-enabled channel. The documentation suggests using the OpenBSD version of Netcat, which does not support SOCKS proxy. However, we use Ncat, the alternative written by the writers.

## 19.2 DNS Tunneling Theory and Practice

This Learning Unit covers the following Objectives:

- Learn about DNS tunneling
- Perform DNS tunneling with dnscat2

DNS is one of fundamental protocols and has been abused by attackers for nefarious purposes. For example, it can be used to tunnel data. To understand exactly how this works, let's present a simplified course. We will then learn how to perform DNS tunneling with a tool called dnscat2.

### 19.2.1 DNS Fundamentals

IP addresses are not human-readable-names. Whenever we want to access a domain by name, we first obtain its IP address. Let's walk through the process. In most cases, we use the recursive resolver provided by an ISP (which is usually pre-programmed into the stock router), but other well-known public recursive name servers can be used. For example, Google has a public DNS server at 8.8.8.8.
