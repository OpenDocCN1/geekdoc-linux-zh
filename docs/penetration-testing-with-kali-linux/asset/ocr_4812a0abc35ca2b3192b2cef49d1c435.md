# Listing 717 - Example of a Distinguished Name

The Listing above shows a few names we haven't seen earlier in this Module, as CN and DC. The CN is the Common Name, which specifies the identifier of an object in the domain. While we normally refer to "DC" as the Domain Controller in AD terms, "DC" mean Domain Component when we are referring to a Distinguished Name. The Domain Component represents the top of an LDAP tree and in this case we refer to it as the Distinguished Name of domain itself.

When reading a DN, we start with the Domain Component on the right side and move to the left. In an example, we have four components, starting with two components DC=corp,DC=com. The Domain objects as mentioned above represent the top of an LDAP tree follow the required naming standard.

Continuing through the DN, CN=Users represents the Common Name for the container where the user object is stored (also known as the parent). Finally, all the way to the left, CN=Stephanie represents the Common Name for the user object, which is also lowest in the hierarchy.

In our case for the LDAP path, we are interested in the Domain object, which is DC=corp,DC=com. Im we would restrict ourselves by only being able to search objects within that given container.
