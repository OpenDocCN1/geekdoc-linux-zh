# 21.3.4 Enumerating Object Permissions

In this section, we will enumerate permissions that are associated with Active Directory objects. Although the technical details of these permissions are complex and out of scope of this Module, it's important that we discuss the basic principles before we start enumeration.

In an short, AD may have a set of permissions applied to it with multiple Access Control Entries (ACE).¹1049 These ACEs make the Access Control List (ACL).¹1050 Each ACE defines whether access to the specific object is allowed or denied.
