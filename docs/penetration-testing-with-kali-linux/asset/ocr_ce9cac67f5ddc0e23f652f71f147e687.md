We're dealing with a blind time-based SQLi vulnerability, the process of fetching the entire database's table is quite slow, but eventually we manage to obtain all users' hashed credentials.

Another sqlmap core feature is the --shell parameter, which provides us with a fully interactive shell.

Due to their high latency, time-based SQLi is not ideal when interacting with a shell, so we will use first UNION-based SQLi example.

First, we need to intercept the POST request via Burp and save it as a local text file on our Kali VM.
