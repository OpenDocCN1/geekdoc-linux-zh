We create a new directory using mkdir, move the ovpn file by mv and then change our working directory with cd.

We're now ready to connect to the VPN. We'll connect with the openvpn command followed by the full name of the ovpn file. Once again we must use sudo, openvpn requires elevated permissions. That sudo caches our password for a short time. If we enter this second sudo command shortly after the first, we will not need to re-enter the password.

> Listing 9 - Connecting to the VPN

The output of Listing 9 may seem intimidating at first. Now, simply note that the last line of the output reads: 'Initialization Sequence Completed', indicating that we have successfully connected to the VPN. Make sure you can find it on your own connection!

We must keep this command open. Closing it will disconnect the VPN connection.

We can open another terminal by clicking File > New Tab.

Once we are connected to the PWK VPN, we will be provided with a TUN0 network interface, which we can view with the IP address. The address assigned to the TUN0 interface will be 192.168.119.x, where x is some value between 1 and 255. Every time we reconnect to the VPN, we might get a different value for x.

In addition, all lab machines in the PWK environment will have addresses that follow the format 192.168.x.y, where x is the same as the third octet of our TUN0 address, and y is the specific octet associated with the machine.

In the course material, we will use different IP addresses for our TUN0 network interface as well as for the lab machines. Please make sure you use the IP addresses assigned to you via TUNO and the OLP so you can access the machines properly.
