Listing 928 - Enumerating SMB with CrackMapExec and proxies

Listing 928 shows that john does not have actionable or interesting permissions on any of the discovered shares. As we already established via a pre-built BloodHound query and now through the scan, john as a normal user does not have administrator privileges on any of the machines in the domain.

> CrackMapExec 5.4.0 may throw the Error NETBIOS connection with the remote host is timed out for DCSRV1, or doesn't provide any output at all. Version 5.4.1 contains a fix to address this issue.¹1203

The output also states that MAILSV1 and INTERNALSRV1 are SMB signing set to False. Without this security mechanism enabled, we can potentially perform relay attacks if we can force an authentication request.

Next, let's use Nmap to perform a port scan on ports commonly used by web applications and FTP servers targeting MAILSV1, DCSRV1, and INTERNALSRV1. We have to specify -ST to perform a TCP connect scan. Otherwise, Nmap will not work over proxies.

```
kali@kali:~$ sudo proxies -q nmap -sT -oN nmap_servers -Pn 21,80,443
172.16.6.240 172.16.6.241 172.16.6.254
```
