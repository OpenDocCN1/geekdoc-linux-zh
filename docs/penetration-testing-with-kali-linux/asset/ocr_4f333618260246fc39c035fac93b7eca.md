The list shows that KeePass is installed in the system. If we are unfamiliar with this program, we would research it, eventually discovering that the KeePass database is stored as a kdbx file and there may be more than one database on the system. For example, a user may maintain a personal database and an organization maintain a department-level database. Our next step is to locate the database files for searching all. .kdbx files on the system.

Lets use PowerShell with the Get-ChildItem cmdlet to find files in specified locations. We'll use -Path C to search the whole drive. We'll use **Include** to specify the file types we want to use **File** and **Recurse** arguments to get a list of files and search subdirectories. Finally we'll set -ErrorAction SilentlyContinue to silence errors and continue execution.

```
PS C:\Users\jason> Get-ChildItem -Path C:\* -Include *.kdbx -File -Recurse -ErrorAction SilentlyContinue
```

Directory: C:\Users\jason\Documents
