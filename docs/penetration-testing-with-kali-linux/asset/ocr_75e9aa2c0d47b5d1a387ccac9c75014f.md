Besides being behind an active session and execute modules through it, we can also load extensions directly inside the active session with the load command.

One example of this is Kiwi, which is a Meterpreter extension providing the capabilities of Mimikatz. Because Mimikatz requires SYSTEM rights, let's exit the current Meterpreter session, start the listener again, execute met.exe in the shell, and then getsystem

msf6 exploit(windows/local/bypass_uacl) > exploit/reverse/handler

```

```
msf6 exploit(multi/handler) > run
