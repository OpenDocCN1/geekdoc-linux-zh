Penetration Testing with Kali Linux

Table 781 - Checking contents of old-policy-backup.xml file

Due to the name of the folder and the name of the file, it appears that this is an older domain policy. This is a common artifact on shares as system administrators forget when implementing new policies. In this particular case, the XML file describes an policy (helpful for learning more about the current policies) and an encrypted password for the built-in Administrator account. The encrypted password could be extremely valuable for.

Historically, system administrators often changed local workstations through Group Policy Preferences (GPO)¹⁰⁵⁶.

Even though GPO-stored passwords are encrypted with AES-256, the private key for the encryption has been redirected from MSDN¹⁰⁵⁷ We can use this to decrypt these encrypted passwords. In this case, we will use the gpg-decrypt¹⁰⁵⁸ ruby script in Kali Linux that decrypts the given encrypted string:

```
kali@root:~# gpg-decrypt "+bsY0V3D4/KgXv3YD0/vyeppPFAN1zMFTIQ0QDAgR63V2JE"
$$
```
