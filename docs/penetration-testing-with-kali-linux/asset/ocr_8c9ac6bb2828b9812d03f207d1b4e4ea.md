# ### 7.3.1 NSE Vulnerability Scripts

As an alternative to Nessus, we can also use the NSE scripts³⁵ to perform automated vulnerability scans. NSE scripts extend the basic functionality of Nmap to a variety of networking tasks. These tasks are grouped into categories such as vulnerability detection, brute force, and network discovery. The scripts can also extend the version and information gathering capabilities of Nmap.
