DNS is one of the fundamental protocols and has been abused by attackers for nefarious purposes. For example, it can be used as a mechanism to tunnel data indirectly and out of restrictive network environments. To understand exactly how this works, let's present a simplified "crash course" in DNS. We will then learn how to perform DNS tunneling with a tool called dnscat2.
