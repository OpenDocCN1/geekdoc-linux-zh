# 4.4.3 One Potential

There are many ways to fix our chmod problem. The simplest solutions involve finding a 'clean' version of chmod file and replacing it. The more complicated solutions include running one binary in the context of another that has the correct permissions. Let's explore one particularly interesting solution.

We need to do what our chmod file can do, but we also need permission to do it. To put this another way, our goal is to find what chmod can do, but that has the permissions of another file, so as ls.

We'll start by making a copy of a file that we have the permission we set. Since we checked in the ls command, let's copy that file into a new file named chmodfix.

```
kali@kali:~$ cp /usr/bin/ls chmodfix
kali@kali:~$ ls -l chmodfix
-rwxr-xr-x 1 kali 141716 Jun 8 08:16 chmodfix
Listing Copying a file with cp.
```

Our new chmodfix is a perfect copy of ls. It can be run in the same way as ls, we can use the same options, and so on. In other words, anywhere we have used ls, we can use this instead. Let's running it on itself.

```
kali@kali:~$ ./chmodfix -l chmodfix
-rwxr-xr-x 1 kali 141716 Jun 8 08:16 chmodfix
Listing - Anything ls can do, chmodfix can do.
```

The output is the same as before. This is progress!
Since the only file that seems to be "broken" with our chmod file is the permissions (as far as we know, the contents of the file itself are fine), let's try to copy only the contents of the file and not the permissions. In other words, we only need the contents of the file - not the entire file.

First, we'll run ls so that we can easily confirm whether or not the file changes.

```
kali@kali:~$ ls -l chmodfix
-rwxr-xr-x 1 kali 141716 Jun 8 08:16 chmodfix
kali@kali:~$ cat /usr/bin/chmod > chmodfix
kali@kali:~$ ls -l chmodfix
-rwxr-xr-x 1 kali 64448 Jun 8 08:21 chmodfix
Listing - Sending the contents of chmod to chmodfix.
```
