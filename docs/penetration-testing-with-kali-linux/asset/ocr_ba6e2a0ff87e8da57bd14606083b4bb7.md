Penetration Testing with Kali Linux

Neo4j is essentially an open source graph database (NoSQL)¹⁰⁶⁷ creates nodes, edges, and properties instead of rows and columns. This facilitates the visual representation of our collected data. Let's go ahead and start the Neo4j service.

```
kali@kali:~ sudo neo4j start
Directories in use:
home:       /usr/share/neo4j
config:     /usr/share/neo4j/conf
logs:       /usr/share/neo4j/logs
plugins:    /usr/share/neo4j/plugins
import:     /usr/share/neo4j/import
data:       /usr/share/neo4j/data
certificates: /usr/share/neo4j/certificates
licenses:   /usr/share/neo4j/licenses
run:        /usr/share/neo4j/run
```

Started neo4j (pid:334819). It is available at http://localhost:7474
There may be a short delay until the service is ready.

Listing 790 - Starting Neo4j service in Kali Linux

As indicated in the output, the Neo4j service is now running and will be available via the web interface at http://localhost:7474. Let's browse this location and authenticate with the default credentials (neo4j) as username and password:
