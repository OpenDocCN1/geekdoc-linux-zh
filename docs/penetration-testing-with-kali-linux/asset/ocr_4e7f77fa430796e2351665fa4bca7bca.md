We can filter by any property of object type. In the example below we have made two changes. We have changed the filter to use the name property to only show information for jeffadmin. Additionally, we have added member to the S property to only display the groups jeffadmin is a member of:

```
$dirsearch = New-Object System.Directory.Services.DirectorySearch($dentry)
$dirsearch.filter="name=jeffadmin"
$result = $dirsearch.FindAll()
ForEach($obj in $result {
    ForEach($prop in $obj.Properties {
        $prop.member
    }
    Write-Host "----------------------------------------------------------------"
}
```
