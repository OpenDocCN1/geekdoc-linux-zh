Since we execute our command through the PHP shell function, we should be aware that the command may be executed via the Bourne Shell⁴⁰⁵ also known as sh, rather than Bash. ## 9.2.2 PHP Wrappers

PHP offers a variety of protocol wrappers to enhance the language's capabilities. For example, PHP wrappers can be used to represent and access local or remote filesystems. We can use these wrappers to bypass filters or obtain code execution via File Inclusion in PHP web applications. When we only the php/filter and data://wppers, many are available.
