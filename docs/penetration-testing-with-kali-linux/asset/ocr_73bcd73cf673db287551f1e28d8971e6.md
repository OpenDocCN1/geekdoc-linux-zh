# 21.4 Active Directory - Automated Enumeration

This Learning Unit covers the following Learning Objectives:

+   * Collect domain data using SharpHound
* Analyze the data using BloodHound

As we've seen in this Module, manual enumeration can be relatively time consuming and generate a wealth of information that can be difficult to organize.

Although it is important to understand the concepts of manual enumeration, we can leverage automated tools to speed the enumeration process and quickly reveal attack paths, especially in large environments. Manual and automated tools each have their merits, and professionals leverage a combination of the two in real-world engagements.

Some automated tools, like PingCastle,¹⁰⁵⁹ generate reports reports most require paid licenses for commercial use. In our case, we focus on BloodHound,¹⁰⁶⁰ an free tool that's extremely useful for analyzing AD environments.

It's worth noting that automated tools generate a great deal of network traffic and many administrators will likely recognize a spike in traffic when we run these tools.

# 21.4.1 Collecting Data with SharpHound

We'll use BloodHound in the next section to analyze, organize and present the data, and the companion data collection tool, SharpHound¹⁰⁶¹ to collect the data. SharpHound is written in C# and Windows API functions and LDAP namespaces similar to those we used manually in previous sections. For example, SharpHound will attempt to use NetWktaUserEnum¹⁰⁶² NetSessionEnum¹ to enumerate logged-sessions, just as we did earlier. It also runs queries against the Remote Registry service, which we leveraged earlier.
