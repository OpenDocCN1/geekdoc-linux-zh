List 697 - Setting up a SOCKS proxy using the autoroute module

We can now update our proxies configuration file (/etc/proxychains4.conf) to take advantage of the SOCKS proxy.

After editing the configuration file, it should appear like:

```
kali@kali:~$ tail /etc/proxychains4.conf
# proxy types: http, socks4, socks5, raw
# * raw: The traffic is simply forwarded to the proxy without modification.
# 
# auth types supported: "base"-http "user/pass-socks"
[ProxyList]
# add proxy here ...
# meantime
# defaults set to "tor"
socks5 127.0.0.1 1080
```

List 698 - Updated proxychains configuration
