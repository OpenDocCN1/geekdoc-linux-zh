Although we don't run sshuttle, in theory, it should set up the routing on our Kali machine so that any requests we make to the subnets we specify will be pushed through the SSH connection. Let's test if this is working by trying to connect to the SMB share on HRSHARES in a new terminal.

```
kali@kali:$ smclient -L //172.16.50.217/-U hr_admin --password=Welcome123
```
