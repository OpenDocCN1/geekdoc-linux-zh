# OffSec

Penetration Testing with Kali Linux

To begin, we'll click Scan on the Nessus dashboard.

![](bbox=[0.372, 0.125, 0.627, 0.203])

Figure 62: Creating a Scan

Even though all Nessus templates accept user credentials, we'll use the Credential Patch Audit scan template, which comes preconfigured to execute local security checks against the target.

The difference between this and the Basic Network Scan template with provided credentials, is that the Credential Patch Audit scan only uses local security checks and will not be a regular vulnerability check from an external perspective. The Credential Patch Audit template will not only scan for operating system patches, but also for outdated applications, which may be vulnerable to privilege escalation attacks.³321

![](bbox=[0.166, 0.373, 0.833, 0.603])

Figure 63: Select Credential Patch Audit

Once again, we will provide a name for the scan and set the target to DESKTOP.
