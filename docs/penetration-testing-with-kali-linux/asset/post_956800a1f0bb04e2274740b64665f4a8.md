## VULNERABILITY SCAN

![](img/336d6ea891e7464f18ad64426619ced4_173_0.png)

Figure 43: Nessus Policy Templates

The Compliance category is only available in the enterprise version as well as Mobile Scan. The only template in the Discovery category is Host Discovery, which can be used to create a list of live hosts. The Vulnerabilities category consists of templates for critical vulnerabilities.

Nessus provides three general scanning templates:

- The Basic Network Scan performs a full scan with the majority of settings predefined. It will detect a broad range of vulnerabilities and is therefore the recommended scanning template. We also have the option to customize these settings.
- The Advanced Scan is a template without any predefined settings. We can use this when we want to fully customize our vulnerability scan or if we have specific needs.
- The last general scanning template, Advanced Dynamic Scan, also comes without any predefined settings. The biggest difference between the two templates is that the Advanced Dynamic Scan, we don't need to select plugins manually. The template allows us to configure a dynamic plugin filter.

Nessus plugins are written in the Attack Scripting Language (NASL) that contain the information and the algorithm to detect vulnerabilities. Each plugin is assigned to a plugin family, which covers different use cases. We will work with the Advanced Dynamic template and plugins in the last section of this Nessus.
