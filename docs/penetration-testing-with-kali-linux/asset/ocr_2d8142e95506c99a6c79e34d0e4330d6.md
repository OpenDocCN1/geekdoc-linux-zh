After applying the filter, the list is empty. In order to analyze the service binary, we should try restarting the service as the binary will then attempt to load the DLLs.

In PowerShell, we use Restart-Service with BetaService as argument, while Process Monitor is running in the background.

```
PS:\Users\steve> Restart-Service BetaService
WARNING: Waiting for 'BetaService (BetaService)' to start...
Listing 430 - Restarting BetaService
```

Listing 430 shows that we could successfully restart BetaService.

Checking Process Monitor, we notice that numerous events appeared. Scrolling down in the list, various CreateFile calls can be found in the Operation column. The CreateFile function can be used to create or open a file.

Figure 241: Add Filter for BetaService.exe

Figure 241 shows that the CreateFile calls attempted to open a file named myDLL in several paths. The Path states NAME NOT FOUND for these calls, which means that a DLL with this name could not be found in any of these paths.

The consecutive calls follows the DLL search order from Listing 427, starting with the directory where the application is located and ending with the entries in the PATH environment variable. We can confirm this by displaying the contents of the environment variable with $Env:path.

```
PS:\Users\steve> $env:path
C:\Windows\System32;C:\Windows\System32;C:\Windows\PowerShell\v1.0;C:\Windows\System32\OpenSSH;C:\Users\steve\Local\Microsoft\WindowsApps;
```
