We receive an interesting result. Our query found the **robots.txt** file, containing the following content:

```
User-agent: *
Allow: /
Allow: /nanites.php
```

| Listing 37 - robots.txt file |

The **robots.txt** file instructs web crawlers, such as Google's search engine crawler, to allow or disallow resources. In this case, it revealed a specific PHP page (/nanites.php) that was otherwise hidden from the regular search, despite being **allowed** by the policy.

The ext operator could also help to discern which programming languages might be used on a web site. Searches like **ext.php**, **ext.xml**, and **ext.py** will find indexed PHP Pages, XML, and Python pages, respectively.

We can also modify an operator using - to exclude particular items from a search, narrowing the results.

For example, to find interesting non-HTML pages, we can use **site:megacorpone.com** to limit the search to **megacorpone.com** and subdomains, followed by **-filetype:html** to exclude HTML pages from the results.
