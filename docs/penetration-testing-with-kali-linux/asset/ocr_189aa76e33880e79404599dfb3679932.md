For example, the iptables-persistent#89 package on Debian saves firewall rules in specific files under /etc/iptables by default. These files are used by the system to restore netfilter#84 at boot time. These files are often left with weak permissions, allowing them to be read by any local user on the target system.

We can also search for files by the iptables-save command, which is used to dump the firewall configuration to a file specified by the user. This is then used as input for the iptables-restore command and to restore the firewall rules at boot time. If a system administrator has run it, we could search the configuration (/etc) or grep the file for iptables to infer the file location. If the file has has insecure permissions, we could use its contents to find the firewall rules configuration running on system.

```
joe@debian-privesc:~$ cat /etc/iptables/rules.v4
# Generated by xtables-v1.8.2 on Aug 18 12:53:22 2022
#filter
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -p tcp -m tcp --dport 1999 -j ACCEPT
COMMIT
# Completed on Aug 18 12:53:22 2022
```

Listing 465 - Inspecting custom iptables

Since this file is read-only by any users other than root, we can inspect its contents. We'll notice a non-default rule that allows the destination port 1999. This configuration detail stands out and should be noted for later investigation.

Next, lets examine scheduled tasks that attackers commonly leverage for privilege escalation attacks. Systems acting as servers periodically execute automated, scheduled tasks. When these systems are misconfigured, the user-created files are left with insecure permissions, we can modify these files that will be executed by the scheduling system at a high privilege level.

The Linux-based job scheduler is as cron#84 Scheduled tasks are listed under the /etc/cron.* directories, where *represents the frequency at which the task will run. Examples tasks that run will be found under /etc/cron.daily. Each script is listed in its own subid.

```
joe@debian-privesc:~$ ls -lah /etc/cron*
-rw-r--r-- 1 root 1.1K Oct 11 2019 /etc/crontab
/etc/cron.daily:
total 24K
drw-xr-x 2 root 4.0K Aug 16 04:25 .
drwxr-xr-x 2 root 12K Aug 18 12:37 .
-rw-r--r-- 1 root 102K Oct 11 2019.placeholder
-rw-r--r-- 1 root 285K May 19 2019 anacron
```
