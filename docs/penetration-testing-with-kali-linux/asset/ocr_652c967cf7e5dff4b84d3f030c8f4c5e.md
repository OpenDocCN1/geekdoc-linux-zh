# 24.6.2 Lateral Movement

In this section we'll leverage the domain admin privileges to get access to the domain controller and, achieve the second goal of the penetration test.

Because we've obtained the clear text and NTLM hash for becky, we can use impacket-psexe to get an interactive on DCSRV1. While we could use either of them, let's use the NTLM hash. Once we have a command line shell, then we have privileged access on DCSRV1 (172.16.6.240).
