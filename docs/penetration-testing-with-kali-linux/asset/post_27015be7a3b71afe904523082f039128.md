## 6.3.5 SMTP Enumeration

We can also gather information about a host from vulnerable servers. The Simple Mail Protocol (SMTP) supports several interesting commands, such as VRFY and EXPN. VRFY asks the server to verify an email address, while EXPN asks the server for the membership of a mailing list. These can often be used to verify existing users on a mail server, which is useful during a penetration test. Consider the following:

```
kali@kali~$ nc -nv 192.168.50.8
220 mail Postfix (Ubuntu)
VRFY root
252 2.0 root
```

> Listing 78 - Using nc to validate SMTP servers

We can observe how the success and error messages differ. The SMTP server readily verifies that the user exists. This procedure can be used to help guess usernames in an automated fashion. Next, let's consider the following Python script, which uses a TCP socket, connects to the SMTP server, and issues a VRFY command for a given username:

```python
#!/usr/bin/python

import socket
import sys

if len(sys.argv) != 3:
    print("Usage: vrfy.py <username> <target_ip>")
    sys.exit(0)

# Create a Socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Connect to the Server
ip = sys.argv[2]
connect = s.connect((ip,25))

# Receive the banner
banner = s.recv(1024)

# VRFY a user
user = (sys.argv[1]).encode()
s.send(b'VRFY ' + user + b'\r\n')
result = s.recv(1024)

print(result)

# Close the socket
s.close()
```

> Listing 79 - Using Python to script the SMTP server enumeration

We can run the script by providing the username to be tested as a first argument and the target as a second argument.

```
kali@kali~$ python3 smtp.py root 192.168.50.8
b'220 mail SMTP Postfix (Ubuntu)\r\n'
b'252 2.0.0 root\r\n'
```

```
kali@kali~$ python3 smtp.py johndoe 192.168.50.8
b'220 mail SMTP Postfix (Ubuntu)\r\n'
b'550 5.1.1 <johndoe>: Recipient address rejected: User unknown in local recipient table\r\n'
```
