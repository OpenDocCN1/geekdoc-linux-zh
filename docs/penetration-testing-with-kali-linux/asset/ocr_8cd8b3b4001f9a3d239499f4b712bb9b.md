# 10.2.2 UNION-based Payloads

When we're dealing with in-band SQL injections and the result of the query is displayed with the application-returned value, we should also test for UNION-based SQL injections.

The **UNION**⁴⁵⁹ keyword alerts exploitation it enables execution of an EXTRA SELECT statement and provides the results in the query, concatenating two queries into one statement.

For **UNION** SQLi to work, we first need to satisfy two conditions:

+   1. The injected UNION query has to include the same number of columns as the original query.
2. The data types need to be compatible with each column.

To demonstrate this concept, let's test a web application with the following preconfigured query.

```
$query = SELECT * from customers WHERE name LIKE '$._POST["search_input'].%%";
```
