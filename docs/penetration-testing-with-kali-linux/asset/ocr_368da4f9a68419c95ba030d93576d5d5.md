PowerShell also has built-in capabilities to allow PowerShell remoting.¹¹ which can be invoked via the New-PSSession cmdlet by providing the IP of the target host along with the credentials in a credential format similar to what we did.

```
PS C:\Users\jeff> $username = 'jen'
PS C:\Users\jeff> $password = 'Nenus123'
PS C:\Users\jeff> $secureString = ConvertTo-SecureString $password -AsPlaintext Force
PS C:\Users\jeff> $credential = New-Object System.Management.Automation.PSSredential -ComputerName 192.168.50.73 -Credential $credential
$username, $secureString;
```
