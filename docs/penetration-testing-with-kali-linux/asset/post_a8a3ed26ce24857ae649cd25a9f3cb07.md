
## 2.3.3 Web Application and Client Side Attacks

It is now time to start learning perimeter attacks. perimeter attacks, we mean methods of infiltration that can be reliably done from the internet. In other words, attacks that can be initiated without any sort of access to an organization's internal network.

We begin with an extensive exploration of Web Application attacks. There are two primary reasons for starting here. The first is that Web vulnerabilities are among the most common attacks vectors available to us, since modern web apps allow users to submit data to them. The second is that web applications are inherently visual and therefore provide us with a nice interface for understanding why attacks work in the way they do.

Introduction to Web Applications begins by covering a methodology, a toolset, and an enumeration framework related to web applications that will help us through the course. It then covers our first vulnerability class: Cross-Site Scripting (XSS). XSS is an excellent vulnerability to start with because it targets the user of a web application as opposed to the server running it. Since the vast majority of our regular-to-day usage of web applications is as normal users, XSS can be unintuitive, compared to other types of attacks.

> Due to the fact that XSS targets users, it can be considered both a Web Application attack and a Client-Side attack as we'll learn soon.

In our exploration of web application attacks in Common Web Application Attacks, we survey four different kind of vulnerabilities. Directory Traversal provides us with an example of how we can access information that's not supposed. File Inclusion shows us what can happen when configurations are not set judiciously by a web administrator. Upload Vulnerabilities demonstrate how we can take advantage of the ability to upload our files to a web server. Command Injection allows us to run any code of our choice on the web server itself.

Our examination of web-based attacks includes a detailed Module on SQL Injection, otherwise known as SQLi. This vulnerability class is particularly important not only because of how common it is, but because it teaches us how weaknesses can arise in a system due to multiple components interacting with each other in complex ways. In the case of SQLi, a web server and a database need to be set up in precise ways so that we attackers cannot abuse them.

Client-Side Attacks are another very common class of attacks. They generally deal with methods of attacking human users of computer systems. In this Module, we'll learn how to perform reconnaissance on a system, attack users of common programs like Microsoft Office, and even how to abuse Microsoft Library Files.

## 2.3.4 Other Perimeter Attacks

It is relatively common to encounter various types of external-facing services on a penetration test that are vulnerable to different kinds of attacks. However, penetration testers we will rarely have time to write our exploits from scratch in the middle of an engagement.

Luckily, there are several ways in which we can benefit from the experience of the information security community. Locating Exploits will portray several different means of working with exploits that are available on Kali Linux and on the internet.¹² Then, Fixing Exploits will help us adapt these exploits to suit our specific needs.

We explore the very surface of a very exciting subject: Antivirus Evasion. While Antivirus (AV) evasion isn't itself a penetration, having knowledge of how to avoid AV will be helpful since most modern day enterprises deploy AV solutions.

Finally, we complete our review of perimeter attacks with an analysis of cryptography and Password Attacks. Weak or predictable passwords are extremely common in most organizations. This Module covers how to attack network services and how to obtain and crack various kinds of credentials.

## 2.3.5 Privilege Escalation and Lateral Movement

Once we gain access to a machine, we suddenly have a set of new actions and activities open to us. We may want to increase our privileges¹³ on the machines so that we can fully control it, or we may want to use it to gain access to other machines on the network.

Windows Privilege Escalation demonstrates how compromising a Windows target, we can use our legitimate permissions to become an Administrator. We will learn how to gather information, exploit various types of services, and attack different Windows components.

Then, Linux Privilege Escalation goes through the same process with Linux targets and obtaining root level permissions. It reinforces the methodology learned in the previous Module and covers Linux-specific techniques.

Escalating permissions is instrumental on an engagement because giving us more access. But as penetration testers, we always want to ask ourselves the best impact our attacks on the network to provide the most value for our clients. Sometimes, it can be even more effective to gain access to another machine owned by the organization. When we move from one network to another on the same network, we call this pivoting¹⁴ and when we move into another subnet we tunnel the basics of these persistence skills, while Tunneling Redirection and Deep Packet Inspection showcases a particular technique that can be used to evade a common network-layer defense.

## 2.3.6 Active Directory

Active Directory⁷ is one of the most complex and important technologies for us to learn as penetration tests because it is ubiquitous in today's environment. PWK dedicates three Modules to this activity: Active Directory Enumeration and a picture of how to think specifically Windows machines. We will learn how to gather information and set ourselves up to thoroughly compromise a network.

Then, Attacking Active Directory Authentication provides us with several techniques to increase our presence within the network by attacking or bypassing authentication protocols. Finally, Lateral Movement in Active Directory helps us understand how to apply many of the pivoting concepts we've learned in complex AD environments.
