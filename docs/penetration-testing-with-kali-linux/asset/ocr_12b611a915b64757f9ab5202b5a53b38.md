Listing 789 - SharpHound generated files

We will use this file in the next section as we analyze the data with BloodHound. SharpHound created bin cache file to speed up data collection. This is not needed for our analysis and we can safely delete it.

One to note is that SharpHound also supports looping, which means that the collector can run cyclical queries of over a period of time. While the method we used created a snapshot over the domain, running it in a loop may gather additional data as the environment changes. The cache file speeds up the process. For example, if a user logged on after we collected a snapshot, we would have missed it in our analysis. We will not use the looping functionality, but recommend recommending it in the training labs and inspecting the results in BloodHound.
