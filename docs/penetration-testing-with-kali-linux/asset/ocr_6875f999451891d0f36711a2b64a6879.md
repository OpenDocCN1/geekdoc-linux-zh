Listing 429 - Displaying permissions on the binary of BetaService

Listing 429 shows that we don't have permissions to replace the binary since we only have Read and Execute permissions as steve. Therefore, we need to investigate a bit more.

We can use Process Monitor¹⁸⁰¹ to display real-time information about any process, thread, file system, or registry related activities. Our goal is to identify all DLLs loaded by BetaService as well as detect missing ones. Once we have a list of DLLs used by the service binary, we can check their permissions and if they can be replaced with a malicious DLL. Alternatively, if we find that a DLL is missing, we could try to replace our own DLL by backing the DLL search order.

Unfortunately, we need administrative privileges to start Process Monitor and collect this data. However, the standard procedure in a penetration test would be to copy the service binary to a local machine. In this system, we can install the service locally and use Process Monitor with administrative privileges to list all DLL activity.

In this example, we'll simulate this by starting Process Monitor as backupadmin. We can browse in the Windows Explorer to double-click on Procmon64.exe. A window will appear asking us for administrative credentials as shown in the following figure. Once we enter the password admin123admin123! for backupadmin and accept the terms, the program starts.
