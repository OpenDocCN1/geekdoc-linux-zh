# 4.2.2 Expect the Unexpected

There is another unique challenge that we will face in learning cyber security. This field is consistently focused on trying to prepare for situations we can't possibly predict.

Let's consider a couple of simple examples. We might learn about Enterprise Network Architecture, which examines how a business organizes servers, workstations, and devices on a network. Unfortunately, in-depth as Module might go, it's likely to cover the exact network architecture that we will encounter in some future scenario. In another Module, we might thoroughly and perfectly understand a specific attack vector, and we even be able to execute it in the lab environment, but that doesn't mean we encounter every actor in future environments.

We also must take into account that the entire field of cyber security is constantly evolving. New vulnerabilities are discovered all the time. A network that is secure today may not be secure in six months. A student must be able to extend their initial training in order to remain effective in the field.

In this way, learning about cyber security is learning transferable skills like leadership, communication, and teamwork. With these skills, we cannot afford to focus on memorizing a series of steps to take. There is no simple, straightforward standard operating procedure for exploit development. Instead, we need to focus on understanding methods, techniques, and the purpose behind certain actions.

Let's return briefly to our example of learning how to secure a network. We mentioned that "A network that is secure today may not be secure in six months." The best approach to this problem is not to learn a series of steps we can follow to make network secure today, then learn a new set of steps in six months. The solution is to learn the methodology and the purpose behind each step. When new risks arise, we'll apply the same methodology, adapting and evolving along the changing threat landscape.

Later in this Module we will discuss potential approaches that can help us do this.
