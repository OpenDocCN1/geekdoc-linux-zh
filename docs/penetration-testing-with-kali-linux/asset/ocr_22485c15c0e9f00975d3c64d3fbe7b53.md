Listing 860 - Performing lateral movement and persistence using the golden ticket and PsExec

We have an interactive command prompt on the domain controller and notice that the whoami command returns us part of the Domain Admin group. Listing group memberships that we are now member of multiple powerful groups including the Domain admins. Excellent.

Note that by creating our own TGT and then using PsExec, we are performing the overpass by leveraging Kerberos authentication as we discussed earlier in this Module. If we were to connect PsExec to the IP address of the domain controller from the hostname, we would instead force the use of the NTLM authentication and access would still be blocked by the listing shows.
