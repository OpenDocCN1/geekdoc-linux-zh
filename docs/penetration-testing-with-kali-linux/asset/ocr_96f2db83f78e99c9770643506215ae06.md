> List 926 - Creating a SOCKS proxy to access the internal network from our Kali machine

The SOCKS5 proxy is active and we can use proxies to access the internal network. Let's confirm that /etc/proxchains.conf still contains the necessary settings from previous Modules. Meaning, the SOCKS5 proxy from the following list should be active:

```
kali@kali:~/beyonds cat /etc/proxchains.conf
socks5 127.0.0.1 1080
```

> List 927 - proxchains configuration file settings

Finally, we set up to enumerate the network via Proxies.
Let's begin with CrackExec's SMB to retrieve basic information of the identified servers (such as SMB targets). We'll also provide the credentials for john to list the SMB shares and their permissions with -shares. Because CrackMapExec doesn't have an option to specify an output file, we will collect the results and manage them later.

```
kali@kali:~/beyonds proxchains -q crackmapexec smb 172.16.6.240-241 172.16.6.254 -u
john -d "DqStTwZpZpn#nL" --shares
```
