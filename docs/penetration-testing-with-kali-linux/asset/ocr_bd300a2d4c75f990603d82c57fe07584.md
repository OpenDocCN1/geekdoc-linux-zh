We have now completed the first step of the cracking methodology and can proceed to the next step, transforming the hash into a format tool we can use.

The JIR suite includes various transformation scripts like ssh2john636 and keeppass2john637 which can format a broad range of different file formats, and they are installed by default on our Kali machine. We can use these scripts to format hashes for Hashcat.

Let's use the keeppass2john script to format the database file and save the output to keeppass.hash.

```
kali@kali:~$ passwordattacks ls -la Database.kdbx

```
