Listing 294 - Hashcat mode for NTLM hashes

The output indicates that the correct mode is 100.

We now have everything to start cracking the NTLM hash. We've already extracted the hash because Mimikat outputs a format. The next step is choosing a wordlist and rule file. For this example we will use rockyou.txt with the best64.rule file, which contains 64 effective rules.

Let's provide all arguments and values to the hashcat to start the process.

```
kali@kali:~/passwordattacks$ hashcat -m 1000 nelly.hash
/usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best64.rule --force
hashcat (v6.2.5) starting
```
