Grey-box testing occurs whenever we are provided with limited information on the target's scope, including authentication methods, credentials, or details about the framework.

# # 8.2.1 Fingerprinting Web Servers with Nmap

As covered in a previous Module, Nmap is the go-to for initial activity enumeration. We start web application enumeration from its core component, the web server, since this is the common denominator of any web application that exposes its services.

Since we find port 80 on our target, we can proceed with service discovery. To get started, we'll run the nmap service scan (-sV) to grab the web server (-p80) banner.

```
kali@kali:~$ sudo nmap -p80 -sV 192.168.50.20
Starting Nmap 7.92 (https://nmap.org ) at 2022-03-29 05:13:27 EDT
Nmap scan report for 192.168.50.20
Host is up (0.1ms latency).
```
