Listing 929 shows that Nmap identified the open ports 80 and 443 on 172.16.6.254 (INTERNALSRV1). For now, we can skip the latter as it's most likely the web page and service we enumerated from an external perspective.

While we use the SOCS proxy and proxies to browse to the open port on 172.16.6.241, we will use chisel$^{1204}$ as it provides a more stable and interactive browser session. From the release page,$^{1205}$ we download the Windows and Linux amd64 versions and extract the binaries in /home/kali/binary/

On our Kali, we will use chisel server in mode to receive incoming connections on port 8080.

```
kali@kali:~/$ chmod+x chisel
```

