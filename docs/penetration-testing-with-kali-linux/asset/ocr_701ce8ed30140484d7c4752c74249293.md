> Listing 185 - Retrieving the Windows OS Version

Our query returned valuable information about the running version of the MSSQL server along with the Windows version, including its build number.

> When using a SQL command line tool like sqlcmd, we must omit our SQL statement ending with a semicolon followed by GO on a separate line. However, when running the command remotely, we can omit the GO statement since it's not part of the MSSQL TDS protocol.

> Listing 186 - Inspecting the Available Databases

Since master, tempdb, model, and msdb are default databases, we want to explore the custom offsec database because it might contain data belonging to our target. We can review this database by querying the tables in the corresponding information_schema.

```
SQL>SELECT * FROM offsec.information_schema.tables;
TABLE_CATALOG
TABLE_SCHEMA
TABLE_NAME
TABLE_TYPE
```
