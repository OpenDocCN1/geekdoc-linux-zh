Penetration Testing with Kali Linux

An AD environment has a critical dependency on the Domain Name System (DNS) service. As typical, a domain controller will also host a DNS server that is authoritative for a given domain.

To ease the management of various objects and assist, system administrators often organize these objects into Organizational Units (OUs).¹1008

OUs are comparable to file folders in that they are containers to store objects within the domain. Computer objects represent actual servers and workstations (part of the domain), and user objects represent accounts that can be used to log in to domain-joined computers. In addition, all AD objects contain attributes which will vary depending on the type of object. For example, a user may include attributes such as first name, last name, username, phone number,

AD relies on several components and communication services. For example, when a user attempts to log to the domain a request is sent to a Domain Controller (DC).¹1009 which checks whether or not the user is allowed to log in the domain. Or when more DCs act as the hub and core of the domain, since the DC is such a central domain component, we will pay attention to it as we enumerate AD.

Objects can be assigned to AD groups so that administrators can manage such object as a single unit. For example, users in a group could be given access to a file server or given administrative access to various clients in the domain. Attackers target high-privileged groups.

Members of Domain Admin¹1010 are among the most privileged objects in the domain. If an attacker compromises a member of this group (often referred to as domain administrators), they essentially gain control over the domain.

This attack vector could extend beyond a single domain since an instance can host more than one domain in a domain tree or multiple domains in a forest. While there is a Domain Admin group for each domain in the forest, members of the Enterprise Adm group are granted full control over all the domains in the forest and Administrator privilege over all DCs. This is obviously a high-value target for an attacker.

We will leverage these other concepts in this Module as we focus on the extremely important aspect of AD enumeration. This important discipline can ensure our success during the attack phase. We will use a variety of tools to manually enumerate AD, most of which rely on the Lightweight Directory Access Protocol (LDAP). Where we've introduced techniques, we will leverage automation to perform enumeration at scale.¹1011
