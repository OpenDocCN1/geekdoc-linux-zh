# OffSec Penetration Testing with Kali Linux

If this is not an option, we could use information from publicly-available exploits to find a reliable return address that match our target environment. For example, if we needed a return address for an ESP injection on Windows 2019, we could search for it in exploits leveraging different vulnerabilities targeting that operating system. This method is less reliable and can vary depending on the protections installed on the operating system.

During a "vanilla" buffer overflow, we would need to rely on hard-coded jump ESP addresses from system DLLs, these are all randomized at boot time as ASLR. Instead, we would try to find these entries in non-ASLR modules inside the vulnerable application whenever possible.

We could also obtain a return address from the target machine. If we have access to our target as an privileged user and run an exploit that will elevate our privileges, we can catch the DLLs that we are interested in our attack machine. We can then leverage tools, such as disassemblers which is installed on Kali.
