Denial of Service (DoS) results results in a simple crash and no exploit path. We should ideally avoid DoS exploits whenever we have better alternatives, in our case. Let's focus on the last two entries.

The vulnerability is present in the HTTP server module where a buffer overflow condition is triggered on a POST request. While we are reading the entire Python code, the core functionality of the exploit script can be summarized using the following code:

```
offset = "A" * 780
jMP_ESP = "\x83\x0c\x09\x10"
shellcode = "\x90" * 16 + msf_shellcode
exploit = offset + JMP_ESP + shellcode
```

Listing 312 - Sync Breeze 10.0.28 ESP instruction's Summary

At 780, we overwrite the instruction pointer with a JMP ESP instruction located at the memory address 0x1090c83. Next, we add the shellcode with 16 NOPs. The exploit buffer is included in the HTTP request and sent.

Since we're more familiar with how the vulnerability works and how it is exploited, let's briefly review the differences between scripting languages such as Python and a compiled language as C. While there are plenty of differences between the two languages, we will focus on main differences that affect us: memory management and string operations.

The first difference is that scripting languages are executed through an interpreter and not compiled to create executable. Because scripting languages require an interpreter, we cannot run a Python script in environments where Python is not installed. This could limit us in the field, especially if we need to run standalone (like privilege escalation). As an alternative, we could consider using PyInstaller which packages Python applications into executables for various operating systems. However, given the nuances of exploit code, we suggest porting by hand. Another difference between Python and C is that in a scripting language like Python, concatenating a string is easy and usually takes the form of addition:

```
kali@~$ python
>>> string1 = "This is"
>>> string2 = " test"
>>> string3 = string1 + string2
>>> print(string3)
This is test
```

Listing 313 - String concatenation example in Python

Concatenating strings in this way is not allowed in a programming language as C. C programs require more precautions as opposed to those written in Python. We will learn how to do this in C since this will provide us with useful knowledge during penetration testing.

## 14.1.3 Cross-Compiling Exploit Code

To avoid compilation issues, it is generally recommended to use native compilers for the specific operating system targeted by the code; however, this may not always be an option. In some scenarios, we might only have access to an attack environment (like Kali), but we need to leverage an exploit for a different platform. In such cases, a cross-compiler can be extremely helpful. We will use the popular minw-w64 cross compiler in this section. If it's not already present, we can install it via apt:

```
kali@kali~$ sudo apt install minw-w64
```
