Penetration Testing with Kali Linux

The Test-NetConnection²⁶⁷ function checks if an IP responds to ICMP and whether a specified TCP port on the target host is open.

For instance, for the Windows 11 client, we can verify if the SMB port 445 is open on a domain controller as follows.

```
PS:\Users\student> Test-NetConnection -Port 445 192.168.0.151
ComputerName        : 192.168.0.151
RemoteAddress       : 192.168.0.151
RemotePort          : 445
InterfaceAlias      : Ethernet0
SourceAddress       : 192.168.0.152
TcpTestSucceeded    : True
```

> Listing 71 - Port scanning SMB via PowerShell

The returned value in the TcpTestSucceeded parameter indicates that port 445 is open.

We can further script the whole process in order to scan the first 1024 ports on the Domain Controller with the PowerShell-liner shown below. To do so we need to use a TcpClient Socket object as Test-NetConnection adds additional traffic that is not needed for our purposes.

```
PS:\Users\student> 1..1024 | % { (New-Object Net.Sockets.TcpClient).Connect("192.168.0.151", $_) | echo "TCP port $_ is open" 2>$null TCP port 88 is open
```

> Listing 72 - Automating the PowerShell portscanning

We by piping the first 1024 integer into a for-loop which assigns the incremental value to the $_ .. Then, we create a Net.Sockets.TcpClient object and perform a TCP connection against the target IP on specific port, and if the connection is successful, it prompts a message that includes the open TCP port.

We've covered the starting point of PowerShell's abilities, which can be further extended to match the traditional Nmap features.
