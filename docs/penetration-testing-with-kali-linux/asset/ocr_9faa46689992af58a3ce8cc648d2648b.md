# 11.1.1 Information Gathering

In this section, we will discuss various methods of enumerating a target's installed software without interacting with the target machine. These techniques are best-suited for situations in which we have no way to interact with the target. Since we are not interacting with the target, we won't alert monitoring systems or leave forensic traces of our inquiry.

One approach is to inspect the metadata tags⁷⁶ of publicly-available documents associated with the target organization. Although this data can be manually sanitized, it is often not. These tags (categorized by group tags⁷⁷) can include a variety of information about about document including author, creation date, the name and version of the software used to create the document, operating system of the client, and much more.

In some cases, this information is stored explicitly in the metadata, and in some cases it is inferred, either way the information can be quite revealing, helping us to build an accurate profile of software installed on clients in a target organization. Bear mind that our findings may be outdated if we are inspecting older documents. In addition, different branches of the organization may use different software.

Although this is a "hands-off" approach to data gathering, the trade-off is that we may not get accurate information. This, approach is viable and effective.

Let's review some samples of the techniques we can learned in the Information Gathering Module. For example, we can use the site.example filetype:pdf to find pdf files on a target's web page. If we want to target a specific branch or location, we can add information via keywords to narrow the results.

If we want to interact with the target's web site, we could also use tools like gobuster⁷⁸ with the -x parameter to search for specific file extensions on the target's web site. This is noisy and will generate log entries on the target. We can also browse the target website for other specific information useful in a client-side attack, but we won't delve into that subject in this section.

Let's practice searching for and retrieving documents from the Mountain Vegetables website. We'll open Firefox and navigate to http://192.168.50.197.
