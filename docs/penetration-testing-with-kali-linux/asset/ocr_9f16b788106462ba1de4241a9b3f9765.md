# 15.3.3 Nmap NSE Scripts

Nmap is one of the most popular tools for enumeration. One very powerful feature of this tool is the Nmap Scripting Engine (NSE).⁷²⁷ as its name suggests, introduces the ability to automate various tasks using scripts.

Along with exploit services, the NSE comes with a variety of scripts to enumerate, brute force, fuzz, and detect. A complete list of scripts provided by the NSE can be found under **grep** to search for the word "exploits" in the NSE scripts which returns a number of results.

```
kali@kali:~$ grep /usr/share/nmap/scripts/*.nse
/usr/share/nmap/clamav-exec.nse:Exploit ClamAV servers vulnerable to unauthenticated command execution.
/usr/share/nmap/http-statestats.nse:Exploit a remote execution vulnerability in Awat SSL up to 1.4
/usr/share/nmap/http-dir-traversal.nse:Exploit a directory traversal vulnerability in Apache Axis2 version 1.4
/usr/share/nmap/http-fileupload-exploit.nse:Exploit insecure file forms in web applications
/usr/share/nmap/http-livespeed-source-code-download.nse:Exploit a null-byte vulnerability in Livespeed Web 4.0.x.
...
```

Listing 362 - Listing NSE scripts containing the word "Exploits"

We can display the information of specific NSE scripts by running **nmap** with the **--script-help=clamav-exec.nse**. Let's analyze an example with **nmap --script-help**

```
kali@kali:~$ nmap --script-help=clamav-exec.nse
Starting Nmap 7.92 (https://nmap.org ) at 2022-06-02 16:23 EDT
```
