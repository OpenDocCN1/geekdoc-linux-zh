# 18.3.2 SSH Dynamic Port Forwarding

Local port forwarding has one limitation: we can only connect to one socket per SSH connection. This can be quite tedious to use. Luckily, OpenSSH also provides dynamic port forwarding¹⁶ From a single listening port on the SSH client, packets can be forwarded to any socket that the SSH server has access to.

SSH dynamic port forwarding works because the listening port that the SSH client creates a SOCKS¹⁷ proxy server port. Like a postal service, a SOCKS server accepts packets (with a SOCKS protocol header) and forwards them to wherever they're addressed.

This is powerful. In SSH dynamic port forwarding, packets can be sent to a single listening SOCKS port on the SSH client machine. these will be pushed through the SSH connection, forwarded to anywhere the SSH server can reach. The only limitation is that the packets have to be properly formatted - most by SOCKS-compatible client software. In some cases, software is not SOCKS-compatible by default. We will work through this limitation later in the section.
