# OffSec

Penetration Testing with Kali Linux

We mainly showcase active information gathering techniques that we execute using pre-installed tools on our local Kali machine. However, in some cases during a penetration test, we won't have the luxury of running our favorite Kali Linux tool. In an assumed breach scenario as this, we are typically given a Windows-based workstation by the client and use what's available on Windows.

When "Living off the Land," we can leverage several pre-installed and trusted Windows binaries to perform post-compromise analysis. These binaries are shortened as LOLBins, or more recently, LOLBAS²245 to include binaries, Scripts and Libraries.

> Strictly speaking, LOLBAS binaries are typically used in a way other than by design. In this case, we relax the definition to include using standard Windows binaries "as they are" to perform information gathering.

In the upcoming sections, we are going to showcase the most popular LOLBAS techniques with common Kali tools used for active gathering.

# 6.3.1 DNS Enumeration

The Domain Name System (DNS)²246 is a distributed database for translating user-friendly domain names into IP addresses. It is one of the most critical systems on the internet. This is facilitated by a hierarchical structure that is divided into several zones, starting with the top-level root zone.

Each domain can use different types of DNS records. Some of the most common types of DNS records include:

+   - NS Nameservers contain the name of the authoritative servers hosting the DNS records for a domain.
- A Also known as a host record, the "record" contains the IPv4 address of a hostname (such as www.megacorpone.com).
- AAAA: Also known as a quad host record, the "aaaa record" contains the IPv6 address of a hostname (such as www.megacorpone.com).
- MX Exchange records contain the name of the servers responsible for handling mail for the domain. A domain can contain multiple MX records.
- PTR: Pointer records are used in reverse lookup and can find the records associated with an IP address.
- CNAME: Canonical Name Records are used to create aliases for other host records.
- TXT: Text records contain any arbitrary data and can be used for various purposes, such as domain ownership verification.
