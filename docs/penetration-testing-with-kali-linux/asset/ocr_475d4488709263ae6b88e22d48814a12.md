# 14.1.1 Buffer Overflow in a Nutshell

In a general, buffer is a memory area intended to hold content that is often sent by the user for later processing. Some buffers have a dynamic size, while others have a fixed, preallocated size.

Buffer overflows are one of the earliest memory corruption vulnerabilities that have undermined software since the late 1980s, and although many mitigations have been developed during the years, they are still relevant today.
