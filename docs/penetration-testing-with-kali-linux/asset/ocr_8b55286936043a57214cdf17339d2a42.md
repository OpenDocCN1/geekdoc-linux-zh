# OffSec

A port forward can be set up OpenSSH's -L option, which takes two sockets (in format IPADDRESS:PORT separated with a colon as an argument (e.g. IPADDRESS:PORT:IPADDRESS:PORT)). The first socket is the listening socket that will be bound to the SSH machine. The second socket is where we want to forward the packets to. The rest of the SSH command is as usual - pointed the SSH server and user we wish to connect.

In this case, we will use SSH to listen on all instances on port 4455 ON CONFLUENCE01 (0.0.0.0:4455), then forward all packets (through the SSH tunnel to PGDATABASE01) to port 445 on the newly-found host (172.16.50.217:445).

> We are listening on port 4455 ON CONFLUENCE01 because we are running as the confluence user: we don't have the permissions to listen on any port below 1024.

Let's create the SSH connection from CONFLUENCE01 to PGDATABASE01 using ssh, logging as database_admin. We will use the local port forwarding we just put together by -L and -N to prevent us from using the shell.

```
confluence01:/opt/atlassian/confluence/bin$ ssh -N -L
0.0.0.0:4455:172.16.50.217:445 database_admin@10.40.521
```

Listing 537 - Running the local port forward command.

Once we've perceived, we receive no output. When running SSH with the -N flag, this is normal. The -N flag prevents SSH from executing any remote commands, meaning we will only receive output related to our port forward.

> If the connection or the port forwarding fails for some reason, and the output we get from the SSH session isn't sufficient to troubleshoot it, we can pass the -v flag in ssh to receive debug output.

This reverse shell from CONFLUENCE01 is now occupied with an open SSH session, we need to connect to CONFLUENCE01. We can do this by listening on another port and modifying our CVE-2022-26134 payload to return a shell to that port.

Once we have another reverse shell from CONFLUENCE01, we can confirm that the shell we just started from our other shell is listening on 4455 using ssh.

```
confluence@confluence01:/opt/atlassian/confluence/bin$ ss -ntplu
ntptu
```
