# OffSec

Due to its brute force nature, Gobuster can generate a lot of traffic, meaning it will not be helpful when staying under the radar is necessary.

Gobuster supports different enumeration modes, fuzzing and dns, but for now, we'll only rely on the dir mode, which enumerates files and directories. We need to specify the target IP using the -u parameter and wordlist -w. The default running threads are 10; we can reduce the amount of traffic by setting a lower number via the -t parameter.

```
kali@kali$ gobuster dir -u 192.168.50.20 -w /usr/share/wordlists/dir/common.txt -t 5
```
