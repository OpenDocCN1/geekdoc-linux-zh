Listing 542 - The Proxychains configuration, pointing towards the SOCKS proxy set up on CONFLUENCE01.

With Proxychains configured, we can now list the available shares using smclient from our Kali machine. Rather than connecting to the port on CONFLUENCE01, we will write the smclient command as we have a direct connection to PGDBATABASE. As before, we will specify -L to list the available shares, pass the username with -U, and without password.

Next, we can simply prepend proxychains to the command. Proxychains will read the configuration file, and process all traffic through the SOCKS proxy we specified.

```
kali@:- proxychains smclient -L //172.16.50.217/ -U hr_admin
password=welcome12234
[proxychains] config file: /etc/proxychains4.conf

[proxychains] DLI init: proxychains-ng 4.16
```

Listing 543 - smclient connecting to HRSHARES through the SOCKS proxy using Proxychains.

The connection was a success! We managed to connect to HRSHARES and list its shares, including interesting folder scripts. We receive some extra output from Proxychains, including the parts that were interacted with while the process was running.

Let's escalate this and port scan HRSHARES through our SOCKS proxy using Nmap. We'll use a TCP-connection scan (-sT), skip DNS resolution (-n), skip the host discovery stage (-Pn) and only check the 20 ports (-top-ports=20). We will then prepend proxychains to the command again to push all packets through the SSH daemon forward SOCKS proxy. We will also increase the verbosity with -vv.
