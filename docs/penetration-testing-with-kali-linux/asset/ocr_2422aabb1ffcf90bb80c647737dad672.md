Before we head into the next section, let's briefly review modules again. As stated, modules are used to perform tasks in Metasploit as scanning or exploiting a target. The framework includes several thousand modules, divided into categories.

The categories are displayed on the splash screen summary, but we can also see them with the show-h command.

```
msf6 > show -h parameters for the "show" command are: all, encoders, nops, exploits, payloads, auxiliary, post, plugins, info, options
[*] Additional module-specific parameters are missing: advanced, evasion, targets, actions
```

626 Help for the show command

626 shows the categories of Metasploit's modules. To activate a module, we need to enter use with the module name. The modules all follow a common slash-delimited hierarchical syntax (module type/of, vendor, app, operation or protocol/module name), which makes it easy to explore and use the modules. We'll be begin exploring auxiliary modules in the next section and dive into exploit modules.

# 20.1.2 Auxiliary Modules

The Metasploit Framework includes auxiliary modules that provide functionality as protocol enumeration, port scanning, fuzzing, sniffing, and more. Auxiliary modules are useful for many tasks, including information gathering (under the gather/hierarchy), scanning and enumeration of services (under the scanner/hierarchy), and so on.

There are too many to cover here, but we will demonstrate the syntax and operation of two very auxiliary modules. To list all auxiliary modules, we can run the show auxiliary command. This will present a long list of all auxiliary modules as shown in the truncated output below:
