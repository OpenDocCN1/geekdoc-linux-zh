The PHP code snippet was written to Apache's log file. By including the log file via LFI vulnerability, we can execute the PHP code snippet.

To execute our snippet, we will update the page request in the current Burp request with a relative path.

```
../../../../../../../var/log/apache2/access.log
```

Listing 142- Relative path for the 'page' parameter

We also need to add the cmd parameter to the URL to enter a command for the PHP snippet. First, let's enter the ps command to verify that the poisoning is working. Since we want to provide values for the two parameters (page or the relative path of the log and cmd) for our command, we use an ampersand (&) as a delimiter. We also remove the User Agent line from the Burp request to avoid poisoning the log again, which would lead to multiple executions of our command due to PHP snippets included in the log.
