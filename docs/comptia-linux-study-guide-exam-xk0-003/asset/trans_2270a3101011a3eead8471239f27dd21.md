**防火墙** 1. 用于阻止对计算机上特定端口或网络程序访问的程序或内核配置。 2. 配置为路由器并包含可限制其管理的网络之间访问的防火墙软件的计算机。

**FireWire（火线）** Apple 对 IEEE-1394 的首选名称。

**字体服务器** 一个向同一台计算机（有时也包括其他计算机）上的客户端程序提供字体位图映射的程序。字体服务器可以直接使用字体位图，也可以从 PostScript Type 1 或 TrueType 等轮廓字体生成位图。

**fork（进程创建）** 1. 一个进程创建另一个进程的方法。 2. 从一个早期项目创建一个新的软件开发项目。随后每个项目独立开发。例如，X.org-X11 是 XFree86 的一个分支。

**仅转发 DNS 服务器** 一种不为客户执行*完全递归 DNS 查询*，而是将整个请求转发给另一个 DNS 服务器的 DNS 服务器。这种配置在小网络中很常见，并可以提高网络的整体 DNS 性能。

**第四扩展文件系统（ext4 或 ext4fs）** *第三扩展文件系统*（*ext3* 或 *ext3fs*）的一种变体，增加了使用更大磁盘（最大支持 1 艾字节，而 ext3fs 为 16 太字节）以及一系列性能增强功能的能力。

**碎片化的** 形容词，描述那些内容被分割到磁盘的几个部分而非连续放置的文件。文件碎片化往往会降低磁盘性能，因为它增加了读取文件时的磁头移动。

**帧** 在网络中，与网络硬件（如以太网）相关的数据包，与软件（如 TCP/IP）相对。

**帧缓冲** 软件和视频硬件之间一种低层但标准化的接口。X 在许多非 x86 计算机上使用帧缓冲接口。

**自由软件基金会（FSF）** 一个总部位于马萨诸塞州剑桥的组织，赞助开源软件的开发并倡导其使用。FSF 创建了通用公共许可证（GPL）和 GNU 项目，该项目开发了 Linux 中使用的许多软件。

**常见问题（FAQ）** 1. 经常被问到的问题，特别是在 Usenet 新闻组或其他在线讨论论坛上。 2. 收集了许多常见问题（含义 1）及其答案的文档。

**FSF** 参见*自由软件基金会*（*FSF*）。

**FTP** 参见*文件传输协议*（*FTP*）。

**FTP 主动模式** 一种操作模式，FTP 客户端发起与服务器的命令连接，然后服务器向客户端发起数据连接。这是大多数 FTP 会话的默认操作模式。

**FTP 被动模式** 一种操作模式，FTP 客户端发起与服务器的命令连接和数据连接。这种操作模式在某些防火墙配置下比主动模式更有效。

**全双工** 一种通信模式，数据可以同时双向传输。

**完全递归 DNS 查询** 一种名称解析方法，其中一个 DNS 服务器查询一系列其他 DNS 服务器，每个服务器都有关于越来越具体的网络的信息，以查找与主机名相关联的 IP 地址。

## G

**网关** 在两个网络之间作为路由器工作的计算机。

**GB** 参见*吉字节 (GB)*。

**GDM** 参见*GNOME 显示管理器 (GDM)*。

**通用公共许可证（GPL）** 一种流行的开源软件许可证。Linux 内核和许多重要的 Linux 程序都在 GPL 下发布。

**GID** 参见*组 ID (GID)*。

**千兆以太网** 一种以太网变体，可以每秒传输 1,000 兆比特（1 千兆比特）。

**吉字节 (GB)** 一种数据大小度量，通常指 2³⁰（1,073,741,824）字节。虽然这种含义在计算机领域很常见，但*gigabyte*（吉字节）在技术上更准确地指 10⁹（1,000,000,000）字节，2³⁰ 字节更合适的称呼是“吉比字节”（GiB）。

**glibc** 一种特定的 C 库，自 1990 年代末以来在 Linux 系统上使用。

**全局唯一标识符（GUID）** 一个 16 字节的数字，旨在作为特定数据结构或数据类型的唯一标识符——例如硬盘上的分区或其包含的文件系统类型。GUID 常用于磁盘文件系统、磁盘分区以及某些网络应用中。

**GMT** 参见*格林威治标准时间 (GMT)*。

**GNOME 显示管理器（GDM）** Linux 上一种流行的 XDMCP 服务器。

**GNU** GNU's Not Unix 的递归缩写。GNU 是一个自由软件基金会（FSF）项目，其目标是构建一个像 Unix 一样工作的完全开源操作系统。一些非 FSF 项目也使用该术语。

GNU/Linux 完整 Linux 操作系统的通用术语，用于将完整的操作系统与单独的内核区分开来。Debian 青睐使用此术语；大多数其他发行版仅使用“Linux”。

GNU 隐私保护工具（GPG） 一种加密软件，允许加密和解密文件或对文件进行“签名”，以便接收者可以验证文件确实来自声称的发送者且未被篡改。

GPG 参见 GNU 隐私保护工具（GPG）。

GPL 参见 通用公共许可证（GPL）。

GPT 参见 GUID 分区表（GPT）。

大统一引导加载程序（GRUB） Linux 上一种流行的引导加载程序。GRUB 可以引导 Linux 内核或将引导过程重定向到非 Linux 分区中的另一个引导加载程序，从而引导其他操作系统。与竞争的 Linux Loader（LILO）类似。另见引导加载程序。

图形用户界面（GUI） 一种人机交互方式，其特征是图形显示、用鼠标在屏幕上移动指针，以及通过指向屏幕上的对象并点击鼠标按钮来执行操作。

格林威治标准时间（GMT） 英国格林威治的时间，未经夏令时调整。Linux 系统内部使用此时间，并通过知道系统时区来调整为本地时间。

组 一组用户。文件由一个用户和一个组拥有，组成员可以被授予对文件的独立访问权限，与所有者和所有其他用户无关。此功能可用于增强协作能力，例如给予组内成员对特定文件的读/写访问权限，同时排除非组成员。系统管理员也可以用它来控制对系统文件和资源的访问。

组管理员 对组拥有管理权限的人。组管理员可以向组中添加或删除成员并执行类似的管理任务。

组 ID（GID） 与特定组关联的数字。类似于用户 ID（UID）。

组所有者 文件所属的组，在文件所有者之后，该组与文件最紧密关联。

GRUB 参见 大统一引导加载程序（GRUB）。

GUI 参见 图形用户界面（GUI）。

GUID 参见 全局唯一标识符（GUID）。

GUID 分区表（GPT） 一种支持大于 2 太字节（2TB）大小磁盘的分区方案。GPT 很可能是自 1980 年代以来在 x86 和 x86-64 计算机上占主导地位的 MBR 分区方案的继任者。

## H

- **黑客（hacker）** 1. 一个擅长使用或编写计算机程序的个人，并且喜欢以建设性的方式使用这些技能。许多 Linux 程序员在此意义上自认为黑客。 2. 破坏者（另见*破坏者*）。这种用法在大众媒体中更普遍，但在 Linux 社区中不受欢迎。

- **半双工** 一种数据传输类型，数据每次只能向一个方向发送。

- **硬链接** 文件的一个目录项，该文件拥有另一个目录项。所有硬链接都是访问文件的同等有效方式，且必须删除所有链接才能删除文件。另见*软链接*。

- **硬件地址** 唯一标识单个网络接口的代码。此地址内置于设备本身，而不是在 Linux 中分配的。

- **哈希** 一种加密方法，文件或字符串以不可逆的方式编码。哈希通常比用于创建它们的文件短得多。哈希常用于密码存储以及作为校验和的更安全变体等。另见*校验和*。

- **HDD** *硬盘驱动器*的缩写。

- **头文件** 包含库中软件例程接口定义的文件。使用库的程序源代码必须引用相关的头文件。

- **高性能并行接口（HIPPI）** 一种支持通过光纤电缆达到 1600Mbps 速度的网络硬件类型。

- **HIPPI** 参见*高性能并行接口（HIPPI）*。

- **主目录** 与账户关联的目录，其中存储用户的文件。

- **主机名** 计算机的易读名称，例如 `persephone.example.com`。

- **热备用** RAID 阵列的一个可选功能，如果软件检测到主驱动器之一故障，可能会自动激活备用驱动器。

- **热插拔** 在计算机开机的情况下添加或移除硬件。

- **HOWTO 文档** 描述如何完成任务或使用特定程序的 Linux 文档。HOWTO 通常是教程性质。它们归档在 `http://tldp.org`，所有主要发行版也随附这些文档。

- **HTTP** 参见*超文本传输协议（HTTP）*。

- **HTTPS** 参见*超文本传输协议安全（HTTPS）*。
