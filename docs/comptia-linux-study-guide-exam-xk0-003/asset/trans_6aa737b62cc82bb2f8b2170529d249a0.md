
**集线器** 一种作为网络中中心交换点的网络硬件类型。每台计算机都有一根连接到集线器的电缆，因此所有数据都会通过集线器。集线器会将接收到的所有数据回显给所有与其连接的其他计算机。另见*交换机*。

**挂起** 用于描述停止响应用户输入、网络请求或其他其应当响应的输入类型的程序的术语。挂起的进程有时会消耗大量的CPU时间。

**超文本传输协议 (HTTP)** 一种用于将网页从Web服务器传输到Web浏览器的协议。

**安全超文本传输协议 (HTTPS)** HTTP的一种变体，启用了安全套接层 (SSL) 加密。

**IEEE-1394** 一种用于连接高速外部设备（如硬盘、扫描仪和视频设备）的外部总线技术。

**IMAP** 见*Internet Message Access Protocol* (IMAP)。

**增量备份** 一种仅备份自上次备份以来发生变化的文件的备份类型。这用于减少备份计算机所需的时间，代价是恢复的复杂性可能增加。

**工业标准架构 (ISA)** 原始IBM PC上使用的扩展总线。大多数制造商大约在2001年开始从主板上淘汰ISA。

**info 页面** 一种类似于 man 页面（见*man 页面*）的文档类型，但每个文档内部具有更复杂的超链接结构。自由软件基金会（FSF）和其他一些开发人员现在更倾向于使用 info 页面而非 man 页面。

**inode** 文件系统（指定义1）中包含了文件关键信息（如其大小和在磁盘上的位置）的数据结构。

**输入/输出 (I/O)** 一个描述从外部源接收数据或向外部源发送数据的术语。在某些情况下，“外部源”可能是计算机内部的，例如硬盘与CPU或内存之间的I/O。在其他情况下，I/O显然是外部的，如网络I/O。

**已安装文件数据库** 通过计算机的软件包管理器（如RPM或Debian）安装的文件数据库，以及相关的信息（如依赖关系）。也称为“软件包数据库”。

**内部传输速率** 设备内部的数据传输速率。这通常应用于硬盘和类似设备，以描述它们从物理介质读取或写入数据的速度。

**国际标准化组织 (ISO)** 一个在国际许多领域发布技术标准的非政府国际组织。在计算机领域，例子包括ISO-9660（一种常见的CD-ROM文件系统）和ISO/IEC 26300:2006（办公文件的OpenDocument格式，由OpenOffice.org和几个其他Linux生产力程序实现）。

**互联网 (internet)** 任何由路由器连接在一起的计算机网络集合。另见*Internet*。

**Internet** 地球上最大的网络，它连接了全球的计算机。以此方式使用时，该单词始终大写。另见*internet*。

**Internet 消息访问协议 (IMAP)** 一种用于交换邮件消息的协议。接收方发起IMAP会话。IMAP与POP的不同之处在于，IMAP允许接收方将消息保留在服务器上的组织好的文件夹中；而POP要求接收方下载消息以便进行整理。

**Internet 数据包交换 (IPX)** 支撑Novell原始网络协议大部分的协议。尽管名字中有Internet，但该协议与Internet无关。

**Internet 打印协议 (IPP)** 一种用于网络打印的协议，在Linux中由通用Unix打印系统（CUPS）服务器使用。

**Internet 协议 (IP)** TCP/IP栈中负责处理网络寻址的低级部分。另见*IPv4*和*IPv6*。

**Internet 软件联盟 (ISC)** 见*Internet 系统联盟 (ISC)*。

**Internet 系统联盟 (ISC)** 一家非营利公司，开发了多个重要的网络服务器，包括BIND、标准的Linux DHCP服务器以及NTP服务器。

**中断请求 (IRQ)** 外围设备（如SCSI主机适配器、声卡等）向CPU发出信号表示需要关注的一种方法。IRQ还指特定的中断信号线。基本的32位x86架构支持16个IRQ，编号为0–15，但IRQ 2和9是联动的，因此在传统架构中实际上只有15个IRQ，其中许多被软盘等基本硬件使用。现代计算机通常支持比传统x86架构的15个IRQ更多的IRQ。

**入侵检测系统 (IDS)** 能够检测计算机或网络上的可疑活动并向操作员发出警报的软件。

**I/O** 见*input/output (I/O)*。

**IP** 见*Internet Protocol (IP)*。

**IP 地址** 计算机的数字TCP/IP地址，例如 192.168.45.203。

**IPP** 见*Internet Printing Protocol (IPP)*。

**IPX** 见*Internet Packet Exchange* (IPX)。

**IRQ** 见*interrupt request* (IRQ)。

**ISA** 见*Industry Standard Architecture* (ISA)。

**ISC** 见*Internet Systems Consortium* (ISC)（前身为*Internet Software Consortium*）。

**ISO** 见*International Organization for Standardization* (ISO)。

## J

**Java** 由Sun Microsystems创建的一种编程语言。Java用于从手机到大型服务器计算机等多种多样的设备。

**Java 虚拟机 (JVM)** 一种运行使用Java编程语言编写的跨平台计算机软件的方法。

**JFS** 见*Journaled Filesystem* (JFS)。

**日志文件系统 (JFS)** Linux的几种日志文件系统之一。JFS由IBM为其AIX操作系统开发。随后创建了OS/2的实现版本，Linux的JFS派生于此代码。

**日志文件系统** 一种维护其操作记录的文件系统类型。此类文件系统通常能在断电或系统崩溃后快速恢复。常见的Linux日志文件系统是ext3fs、ext4fs、ReiserFS、JFS和XFS。另见*filesystem*。

**JVM** 见*Java Virtual Machine* (JVM)。

## K

**KDE 显示管理器 (KDM)** Linux上流行的XDMCP服务器。

**KDM** 见*KDE Display Manager* (KDM)。

## K

**内核** 任何操作系统（OS）的核心程序。内核提供软件与硬件之间的接口，并控制所有其他程序的操作。从技术上讲，Linux内核是*唯一*的Linux组件；其他所有内容，如shell、X和库，都存在于其他类Unix系统中。

**内核模块** 一个驱动程序或其他内核级程序，可根据需要加载或卸载。

**内核模块自动加载器** 一个实用程序，根据内核的需求加载和卸载内核模块，从而免除了手动加载和卸载内核模块的需要。

**内核环形缓冲区** 由Linux内核生成的最近消息的记录。在Linux系统启动后立即，此缓冲区包含由驱动程序和主要内核子系统生成的启动消息。可以使用`dmesg`命令查看此缓冲区。

## L

**L2TP** 见*Layer 2 Tunneling Protocol (L2TP)*。

**第2层隧道协议 (L2TP)** 一种通过单个连接（如VPN）传递多个网络协议的方法。

**LBA** 见*linear block addressing (LBA)*。

**LDAP** 见*Lightweight Directory Access Protocol (LDAP)*。

**libc** 见*C library (libc)*。

**库** 一个可能对许多程序都有用的代码集合。这些代码可以存储在独立于使用库的程序的文件中，以在运行这些程序时节省磁盘空间和RAM。

**轻量级目录访问协议 (LDAP)** 一种在特定类型的数据库中存储数据并通过网络访问它的工具。LDAP有时用作基于网络的认证形式。

**LILO** 见*Linux Loader (LILO)*。

**线性块寻址 (LBA)** 一种使用单个扇区号来检索该扇区数据以访问磁盘数据的方法。LBA与柱面/磁头/扇区 (CHS) 寻址形成对比。一些资料将LBA称为*逻辑*块寻址。

**Linux** 1. 由Linus Torvalds设计的类Unix操作系统（OS）核心的开源内核。 2. 围绕Linus Torvalds的内核构建的完整OS。另见*GNU/Linux*。

**Linux 加载器 (LILO)** 一种流行的Linux引导加载程序。LILO可以启动Linux内核，或者将引导过程重定向到非Linux分区中的另一个引导加载程序，从而启动其他操作系统。LILO与竞争产品Grand Unified Boot Loader (GRUB)相似。另见*boot loader*。
