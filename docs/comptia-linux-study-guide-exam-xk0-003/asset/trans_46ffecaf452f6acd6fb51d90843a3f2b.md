## 复习题答案

1. C。选项 A 将路径设置为仅包含 `/usr/local/bigprog/bin` 目录，而不是将该目录添加到现有路径中。选项 B 和 D 使用 `tcsh` 语法来设置路径，且选项 B 的使用方式不正确（`/etc/profile` 用于在 Bash 中设置环境变量，而不是在 `tcsh` 中）。

2. A。root 用户可以在 `/etc/profile` 或其他系统级配置文件中设置环境变量，用户可以在 `.bashrc` 或其他用户级配置文件中设置自己的环境变量，或者手动输入。由于用户的设置在后，因此如果有冲突，它们将覆盖系统默认设置。

3. C。当前目录指示符在 root 的 PATH 环境变量中特别危险，因为不怀好意的本地用户可以利用它诱骗 root 运行不怀好意的用户设计的程序。

4. A。脚本，就像二进制程序一样，通常至少设置了一个可执行位，尽管它们可以在某些情况下无需此功能即可运行。没有标准的 `/usr/bin/scripts` 目录，脚本可以驻留在任何目录中。脚本是解释型程序，这意味着它们不需要编译。输入 `bash scriptname` 将运行该脚本。病毒在 Linux 中极其罕见，由于你刚刚创建了脚本，它可能包含病毒的唯一方式是你的系统已经感染，或者你将其编写为病毒。

5. C。`[Ss]` 匹配集同时匹配 `skin.txt` 中的大写 S 和 `scan.txt` 及 `skin.txt` 中的小写 s。这是匹配所有所需文件名的必要条件，但它也匹配所有不需要的文件名。后面的 `*` 匹配任意数量的中间字符。末尾的 `n.txt` 匹配所有三个目标文件名的结尾，但不匹配任何不需要的文件名。因此，选项 C 是正确的。选项 A 匹配所有文件（包括需要和不需要的）。选项 B 不匹配 `skin.txt`，但匹配 `skinny.txt`；因此，它不起作用。由于选项 D 以小写 s 开头，它不匹配 `skin.txt`。该选项还错误地匹配了所有不需要的文件名。

6. C。默认情况下，`ln` 创建硬链接，但大多数文件系统不允许子目录之间的硬链接。此外，如果当前目录和目标目录位于不同的底层文件系统上，则无法在它们之间创建硬链接。因此，该命令很可能会失败。选项 C 中指定的 `ln` 的 `-s` 选项创建的是符号链接而不是硬链接。由于指向目录和跨文件系统的符号链接是合法的，因此该命令很可能会成功。如选项 A 所示，将 `ln` 更改为 `mv` 会使命令变成尝试移动目录，这可能有效也可能无效，但肯定不是所期望的。选项 B 的更改将没有影响；链接不需要与其链接到的文件或目录具有相同的名称。选项 D 是尝试明确定义被链接到的目录是一个目录。它也将没有影响。

7. A, C。除非你以异常方式配置你的账户或指定在启动 `xterm` 时运行的其他程序，否则在登录或启动 `xterm` 窗口时会自动启动 shell。输入 `sh` 或 `csh` 不会启动 shell，因为没有标准的 shell 名为 `sh` 或 `csh`。（不过，输入 shell 名称是可以完成工作的。）计算机启动时通常不会启动 shell；你必须先登录。

8. B。当你在输入命令或文件名时按下 Tab 键，Bash 会检查你目前输入的字符是否足以唯一识别该命令或文件名。如果是，Bash 将补全该命令或文件名，为你节省按键操作。

9. D。输入 `chown ralph:tony somefile.txt` 将文件的所有者设置为 `ralph`，组设置为 `tony`。`chmod` 命令用于更改文件权限，而不是所有权。选项 C 颠倒了文件名和所有者的顺序。答案 D 使用了正确的命令和选项。

10. D。选项 D，`027`，移除了组的写权限和所有 world 权限。（文件通常不设置执行权限，但在移除读权限时显式移除 world 权限可确保目录的合理行为。）选项 A，`640`，是所需的 `rw-r-----` 权限的八进制等效值，但掩码设置的是要从权限中移除的位，而不是要设置的位。选项 B，`210`，将移除所有者的写权限，但不会移除组的写权限，这是不正确的。这将导致所有 world 权限保持开放。最后，选项 C，`022`，不会移除 world 读权限。

11. A。`-l` 参数生成长列表，包括文件大小。`-a` 参数生成目录中所有文件的列表，包括点文件。结合两者即可生成所需信息（以及其他文件的信息）。

12. D。从一个分区或磁盘移动到另一个时，`mv` 必须读取并复制文件，然后如果复制成功则删除原始文件。如果两个文件系统都支持所有权和权限，它们将被保留；`mv` 不需要 `--preserve` 选项来做到这一点，且这种保留并不依赖于拥有完全相同的文件系统类型。虽然 `mv` 在单个底层文件系统内移动时不会物理重写数据，但当你复制到单独的底层文件系统（例如从硬盘到软盘）时，这种方法无法工作；如果数据未写入新位置，当磁盘插入另一台计算机时，数据将无法访问。

13. A, B。如果你尝试在一个不存在的目录中创建目录，`mkdir` 会响应 *No such file or directory*（没有那个文件或目录）错误。`--parents` 参数告诉 `mkdir` 在这种情况下自动创建所有必要的父目录。你还可以通过单独创建每个必要目录手动完成此操作。（如果目录 `one` 已经存在，那么在这个例子中单独使用 `mkdir` 可能就不必要了。尝试创建已存在的目录不会有害，尽管 `mkdir` 会返回 *File exists*（文件已存在）错误。）

14. A。`tail` 命令的 `-f`（或 `--follow`）选项使其监视文件并在添加内容时显示文件中的新增内容。因此，选项 A 完成了指定任务。`vi` 命令是一个文本编辑器，`chmod` 更改文件权限；因此，B 或 C 都无法实现预期目的。选项 D 的 `monitor --logs` 命令是虚构的。
