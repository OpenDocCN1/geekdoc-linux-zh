The design of a multiplatform applications can be very complex regarding the goal you want to achieve by developing them. In many cases you will have to choose if you want to get the best experience for each particular OS you target (whatever the similarity of the application on the different OS) or provide uniformized experience whatever the OS your application is executed on.

This choice will make you choose one type of GUI rather than another one. Finding the best combination for all these factors is a tricky part for choosing the development type of your user interface. By following the best practices presented, you will be able to produce a great GUI design for your application and respond to the user wishes in that domain.
