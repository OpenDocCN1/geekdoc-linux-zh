# 8.6.2 Presentation of QML.NET

QT provide a complete integrated solution for the development of multiplatform applications in C and C++, so why review this tool in a book using .NET Core 3?

Of course, that’s because a wrapper for this framework has been officially released since 2018 and make QT, and more precisely QML a great language to use for the development of GUI desktop application with .NET Core 3.

The QML is a declarative language for the description of GUI. It has a syntax inspired from C and JSON it allows to have a minimal file size for his implementation. It is a subset of QT Quick.

QML implement several key concepts:

+   * The objects are described as C structure.
+   * An object can be described as a combination of other objects (heritage).
+   * “State”, “Transition”, “Animation” can be associated to the widgets (QT Quick controls in our case).
