# B) Install GTK

Once you have achieved a proper MSYS2 install and rebooted, you now can install GTK runtime and development libraries. This Install can be done through the use of the appropriate “pacman” (Package Manager) command in the mingw environment.

```
`~ pacman -S mingw-w64-x86_64-gtk3`
```
