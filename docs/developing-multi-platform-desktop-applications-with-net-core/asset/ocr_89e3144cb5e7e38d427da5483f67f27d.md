# 5.6 Using unmanaged dependencies

The multiplatform development with .NET core 3 will sometimes implies the use of platform specific dependencies (.dll files with Windows, .so file with ubuntu, .dylib file with macOS).

The capability for the developer to access unmanaged methods from his .NET Core 3 program is mandatory for conducting many types of projects.

You have to keep in mind that, in the multiplatform context, you have to get the natives library file (or its equivalent for the platform) for each platform, in our case Linux, macOS, Windows. So, verify if the library you plane to use for your multiplatform project will be available for each OS you target before actually using it in your development on the Windows platform.

For example, many system functions are accessible only throw natives API, for doing so you should know basic concepts for the use of unmanaged code with .NET Core 3 (who is managed code):

+   * P/Invoke
+   * Marshalling
+   * Establishing the running OS
