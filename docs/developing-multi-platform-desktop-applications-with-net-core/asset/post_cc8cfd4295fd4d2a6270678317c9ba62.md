
With this line of code, the web application is executed inside an Electron window.

## G) Initialization of the application:

The first time you start the Electron application you have to "Initialize" it with the command described below (you have to be in the application folder).

```bash
c:\appPath>dotnet electronize init
```

This command will create the "electron.manifest.json" file which is used by the "electronize" command for the execution of the program (this file describes the Electron context).

## H) Execute the application:

After that, you can execute the Electron.NET ASP.NET Core application with the command "start" as described below (in the application folder for Windows and in the solution folder for ubuntu and macOS).

```bash
c:\appPath>dotnet electronize start
```

On ubuntu and macOS you have to use the "electronize" command without the "dotnet" part as described below.

```bash
$ electronize start
```

With this command the application is executed in a classical desktop application window (not in the browser, but this is still a web application).

## 8.3.5 Electron.NET application example

As Electron.NET is a popular wrapper around Electron, you will find plenty of code examples (check GitHub) for helping and guiding you for the development of your Electron.NET application (see reference links).

These examples make often an intensive use of the SPA (Single Page Application) techniques and use specialized JavaScript frameworks like Vue.JS or React... The reason is that the desktop application experience requires a minimum of blinking screen for being likely by the user and looked as a tangible desktop application.

So, the development of an application with Electron.NET implies an intensive use of JavaScript for making the buffer between the web development back-end and the desktop Front-End (who have a natural tendency to blink as a common web application).

The Electron.NET, ASP.NET Core example application we will review is the “ElectronNET-API-Demos” application from the Electron.NET repository.

This is the application of reference for this type of application. That illustrates the use of many Electron.NET features. Most of the source code is exposed in the application itself for teaching purpose.

In this sample, you will find a couple of useful techniques specific to the Electron.NET application type, these techniques can be reused in your application. These samples can be a good starting point in the study of Electron.NET. Among those techniques we can review in detail the native menu and the native dialog window.

Electron.IpcMain.On("information-dialog", async (args) =>

# Use system dialogs

The Electron.NET allows you to use native system dialogs for opening files or directories, saving a file, or displaying informational messages.

This is the main reason we use the process is more efficient with native UIs and it allows the user to be in the process of interacting with the Electron.net and the renderer process.

![](img/3d310cc066dda6e2dfa67a650614076f_163_0.png)

`Error Dialog`
```csharp
public static void Error() {
  var dlg = new ErrorDialog();
  dlg.ShowDialog();
}
```

`Information Dialog`
```csharp
public static void Information() {
  var dlg = new InfoDialog();
  dlg.ShowDialog();
}
```

In this demo, the `InfoDlg` class is used to send a message to the renderer process. The renderer process will intercept the `InfoDlg` message and respond to the `InformationMsg` message from the UI thread that is being displayed in the renderer process.

In addition, the `Msgs` will be the `Msgs` that will be the renderer process.

An information dialog can display any custom content, including:
- Title
- Message
- Icon
