## 8.6.2 Presentation of QML.NET

QT provides a complete integrated solution for the development of multiplatform applications in C and C++, so why review this tool in a book using .NET Core 3?

Of course, that’s because a wrapper for this framework has been officially released since 2018 and makes QT, and more precisely QML, a great language to use for the development of GUI desktop applications with .NET Core 3.

QML is a declarative language for the description of GUIs. It has a syntax inspired by C and JSON that allows it to have a minimal file size for its implementation. It is a subset of QT Quick.

QML implements several key concepts:

- The objects are described as C structures.
- An object can be described as a combination of other objects (inheritance).
- “State”, “Transition”, “Animation” can be associated with the widgets (QT Quick controls in our case).
  - State: is a named statement that describes a set of properties when a specific condition is met.
  - Transition is a declaration that spreads a change over time.
  - Animation describes the evolution of an object (the look) resulting from the change of its properties.

Here is a sample snippet of QML implementation (a rectangle polygon that changes color when it is clicked):

```
Rectangle {
  width: 200
  height: 200
  color: mouse.pressed ? "blue" : "red"
  Text {
    text:"Hello World !"
    anchors.centerin: parent
  }
}
```

QML.NET allows .NET Core 3 developers to use this language for the GUI's design of the application with the use of the QML wrapper: QML.NET.

The implementation of a QT wrapper for .NET is not new, but with this version: QML.NET reaches another level. It is now a company-supported solution that is available right now.

QML.NET is open source and available for the developer on a dedicated GitHub repository.

You can notice that the current version targeted by the QML.NET example projects are .NET Core 2.2, but the wrapper is implemented using the .NET Standard 2.0 and so is usable by every .NET framework (of course including the .NET Core 3).

The MIT license used allows you to freely use QML.NET for any kind of project you can do with (permissions for commercial use, modification, distribution, and private use).

This GitHub repository contains all the tools needed for the development with .NET Core 3:

- QML.NET: The wrapper
- QML.NET sample application.
- QML runtime: Runtime installation script for Windows, Linux and macOS.

QML.NET allows the .NET Core 3 developer to use the .qml file format for the specification and the design of the application.

The .qml file can be edited with the appropriate dedicated software: QT Design Studio.

The .qml file format, a text-based file format, can also be edited with a classical text editor but requires in this case much more expertise on the QML language itself. Even if it looks like the hard way to develop with QML, the knowledge of the many capabilities the QML language offers could be extremely helpful for the development of real-world applications (especially if you work with designer exported designs).

We recommend the review of the "qmlbook" website for a detailed view of the QML language, especially for the development of effects and interactivities in the GUI (this is C, C++ oriented). You can find more information about the QML.NET usages on the reference links.

![](img/3d310cc066dda6e2dfa67a650614076f_222_0.png)

Besides the source code of the wrapper, QML.NET can be included in your project by using several NuGet packages (depending on the platform you target in your project).

![](img/3d310cc066dda6e2dfa67a650614076f_222_1.png)

Thus, you also have to add a specific dependency of the runtime for each platform type your development intends to work on.

For getting familiar with the QML language, we will review more deeply the dedicated freely available WYSIWYG editor: QT Design Studio.

## 8.6.3 QT Design Studio

QT Design Studio is a RAD tool for the development of .qml interface files.

The community version of this product is free and available for the three platforms we are interested in (Windows, Linux, macOS).

As shown (*Figure 1*) it furnishes to the developer (or interface designer) all the features needed for the design of quality GUIs.

![](img/3d310cc066dda6e2dfa67a650614076f_223_0.png)

(*Figure 1*)

This interface is composed of three main parts. For experienced developers, you will be familiar with this application since it uses the standard format (nothing official) of a graphic interface designer.

The three main panels match a specific feature for the GUI design:

- On the left: The toolbox presenting the list of the controls available for the current form designed.
- In the center: The form designer for the setting of the position, the scale and the selection of the controls.
- On the right: The view of the properties of the selected control.

Added to the visual editor, a vertical tab control allows the developer to edit the source code manually (switch to a text editor). The visual editor is used to easily and interactively produce a QML file (which is actually a text file as mentioned before). QT Design Studio allows you to design applications with animation and effects (triggered by signal/events) for producing high-end look interfaces. The software includes (even in the community edition) various tutorials for learning more easily the basic concepts used by the product.

Several tutorials about QT Design Studio are already on YouTube and could be particularly useful for starting to use this tool.
