# 8.7.5 Sample GUI program with Avalonia

For helping you in the development of an Avalonia application we will review two distinct projects:

+   An application using almost each Avalonia control (a reference from the AvaloniaUI site).

+   A basic application that could be used as a starting point for your own development project.

Both of these examples have been developed with .NET Core 3 and Visual Studio 2019 (even if you have to build the first sample with the SDK CLI command line tool).

# 8.7.5.1 The "ControlCatalog" program example

The example program we review in this section is the classical "ControlGallery" program, this example come from the Avalonia main repository and constitute itself a reference for the use of a large number of widgets (controls, dialogs and windows) already available inside the Avalonia framework.

We have upgraded the original sample for targetting the .NET Core 3 framework without meeting any particular issue on each platform. The code of this example program is downloadable on GitHub (the original version and the .NET Core 3 version).
