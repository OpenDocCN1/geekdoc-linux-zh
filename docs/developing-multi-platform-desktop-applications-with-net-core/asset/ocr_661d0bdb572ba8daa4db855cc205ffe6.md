# 8.3.3.3 On Windows

On Windows, you have to install Npm and Node.JS. The setup of the Node.JS version from the Visual Studio Installer program is not adapted for the building of an Electron.NET application (as you also need Npm to be installed). We recommend to not use this version for this specific task.

The much simpler solution consists in the setup of the Node.JS/Npm from the dedicated web site, it will ensure you install the latest version available (the link is provided in reference previously).
