# 6.4.2.2  Ubuntu 18.04 Install

The .NET Core 3 for Linux is downloadable under tar.gzx format. You can install it simply by using the following command line instruction.

```
```
$ mkdir -p $HOME/dotnet && tar zxf dotnet-sdk-xxxx-linux-x64.tar.gz -C $HOME/dotnet
$ export DOTNET_ROOT=$HOME/dotnet
$ export PATH=$PATH:$HOME/dotnet
```
```

Xxxx : is the version number of the .NET Core 3 you want to install. (the file name changes for each release of a new .NET Core)

As you can see the directory DOTNET is also created and then added to the path for having access to the dotnet program from every location. You should consider to had the two-last line to your user’s variable environment (/users/<>/)
