#### 8.7.5.1 The "ControlCatalog" program example

The example program we review in this section is the classical "ControlCatalog" program. This example comes from the Avalonia main repository and constitutes itself a reference for the use of a large number of widgets (controls, dialogs, and windows) already available inside the Avalonia framework.

We have upgraded the original sample for targeting the .NET Core 3 framework without meeting any particular issue on each platform. The code of this example program is downloadable on GitHub (the original version and the .NET Core 3 version).

```

.NET Core 3 version:

https://github.com/netcor3/CodeBook/Chapter 8/7/ControlCatalogStandalone
```

This example, called "ControlCatalogStandalone", is a multipage application presenting the main widgets you can use in your Avalonia application.

The architecture of the project is original, as the main application functionalities are not in the main program project ("ControlCatalog.NetCore") but in a dependency project ("ControlCatalog") .dll file.

This .dll file has been developed using .NET Standard 2.0; this architecture improves the general portability of the application. Of course, you will not have to use the same implementation architecture for your project, but it is a good guarantee of Avalonia's multi-platform capabilities.
