The roadmap (*figure 1*) of the different releases could be subject to changes, and the features included are not yet been defined. That is because .NET Core Is under Opensource license and many features are proposed and implemented by the community (mainly Microsoft professionals and independent developers).

For example, if the community make it clear that a feature should be include in the next version, the feature will be added to the next version (when is it technically possible). So, if you have great ideas for the framework do not hesitate to post a request on .NET Core development web site (reference link below) and if it happen to be validated by the development team your feature will be integrated in future.NET Core release.
