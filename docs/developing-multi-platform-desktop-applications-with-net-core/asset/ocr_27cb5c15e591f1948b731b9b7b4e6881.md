# 9.2.1    dotnet build

The "build" command generate a .NET Core assembly of a project and all its dependencies. This command performs the “implicit”
restoration of the dependencies too.

You can compile and build your .NET Core 3 project directly from the command line as presented below (you have to be in the folder containing the .csproj file).

```
C:\>dotnet build
```

Of course, you can define more complex building command line instruction as presented below.

```
C:\>dotnet build -r win-X64 --configuration
Release
```

Here is the explanation of the most commonly used options presented in the previous command line instruction.

+   -   -c (or --configuration): Define the configuration to use for the
+       build, the default value is "Debug" (Specify "Release" if
+       needed)

+   -   -o (or --output): Define the target folder for the assembly
+       produce by the build command.

+   -   -r (or --runtime): Specify a target runtime (see Rid references)
