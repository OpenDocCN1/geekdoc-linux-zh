# 8.7.4 Avalonia ThemeEditor

Like WPF, Avalonia provide theming support of the widgets it provides. This theming allows the developer to customize the appearance of the controls for the specifications of his own application (or requirements).

The developer can consider the use of a specific tool for the development of this customization it is named "Avalonia ThemesEditor".

![](bbox=[0.08, 0.46, 0.92, 0.76])

(ThemeEditor application)

As you can view above, this tool allows you to specify the colors, fonts, alignments... Everything for building an original XAML theme for your application.

This is an Opensource tool, the source code is available on GitHub (you will find also several tools for developing with Avalonia).
