This application includes the use of animation and interactive update inside the QML code, there is no use of the C# back-end in this application. The purpose of the “photoshopGUIForm” example is the illustration of what can achieved by the QML language in the animations and effects domains.

This is only a glimpse of the features offered by QT for the implementation of a graphic dynamic interface, but this sample will help you to familiarized yourself with the QML language and its use within a .NET Core 3 application.
