# Use system dialogs


The Electron.NET allows you to use native system dialogs for opening files or directories, saving a file, or displaying informational messages.

This is the main reason we use the process is more efficient with native UIs and it allows the user to be in the process of interacting with the Electron.net and the renderer process.


![](bbox=[0.34, 0.295, 0.63, 0.365])

`Error Dialog`
```
public static void Error() {
  var dlg = new ErrorDialog();
  dlg.ShowDialog();
}
```

`Information Dialog`
```
public static void Information() {
  var dlg = new InfoDialog();
  dlg.ShowDialog();
}
```

In this demo, the `InfoDlg` class is used to send a message to the renderer process. The renderer process will intercept the `InfoDlg` message and respond to the `InformationMsg` message from the UI thread that is being displayed in the renderer process.

In addition, the `Msgs` will be the `Msgs` that will be the renderer process.

An information dialog can display any custom content, including:
- Title
- Message
- Icon
