# Chapter 10. The text Widget and html_library

markID The character just after the mark named markID.

tagID,first The first occurrence of tag tagID.

tagID,last The last occurrence of tag tagID.

windowName The name of a window that was placed in this text wid get with the window create widget command.

imageName The name of an image that was placed in this text widget with the image create widget command.

end The last character in the text widget.

The modifier field in an index may be one of:

+   +num chars The location moves forward or backward by the defined number of characters or lines. The "+" symbol moves
-num chars the location forward and the "-" symbol moves
-num lines backward.

+   linestart The index refers to the beginning or end of the line that includes the location index. NOTE: {1.0 lineend} is equivalent to {1.end} and {1.0 linestart} is equivalent to {1.0}.
lineend

+   wordstart The index refers to the beginning or end of the word that includes the location index.
wordend

# Index Examples

+   0.0 Not a valid index, line numbers start at 1. This will be mapped to the beginning of the text widget, index 1.0.

+   {.b wordend} If a letter follows window .b, this refers to the location before the first space after the .b window.

+   If window .b is at the end of a word, this refers to the location just after the space that follows window .b
