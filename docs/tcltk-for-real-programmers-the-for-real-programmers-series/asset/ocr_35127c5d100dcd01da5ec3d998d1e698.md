+   * tk_messageBox
Creates a dialog window in one of several defined styles. Returns the name of the button that was clicked.
This widget creates a new window that takes focus until interaction with this widget is complete.

Syntax: tk_messageBox ?option value?

tk_messageBox
Create a new window with a message. When a button is clicked, the window is destroyed and the value of the button that was clicked is returned to the script that created this widget.

option value
Options for this widget include:

+   -message The message to display in the box.
-title The title to display in the window border.
-type The type of message box to create. The type of message box will determine what buttons are created. The options are:

+   abortretryignore Displays three buttons: abort, retry, and ignore.
ok Displays one button: ok.
okcancel Displays two buttons: ok and cancel.
retrycancel Displays two buttons: retry and cancel.
