# Chapter 3. Introduction to the Tcl Language

a

Open file for write-only access. File already exist, and new data will be appended to the file.

a+

Open file for read and write access. Create the file if it doesn't exist. Append data to an existing file.

?permissions?

If a new file is created, this parameter will be used to set the permissions. The permissions argument will be an integer, with the same definitions as the argument to the create system call on the operating system being used.

# File Output and Input Example

```
# Open a file for writing
set outputFile "testfile" "w"

# send a line to the output file.
puts outputFile "This is line 1"
puts outputFile "This is line 2"
puts outputFile "This is line 3"

# Close the file
close $outputFile

# Reopen the file for reading
set inputFile "testfile" "r"

# Read a line of text
set numBytes [gets $inputFile string]

# Display the line read
puts "Gets returned $numBytes characters in the string: $string"

# Read the rest of the file
set string2 [read $inputFile]
puts "Read: $string2"

puts "\nopening a Pipe\n"
# Open a pipe to the ls command
set pipe [open "|ls /" "r"]
```
