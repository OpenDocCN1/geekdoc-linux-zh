# Chapter 6. Procedure Techniques

# 6.1.2 Default Values for Procedure Arguments

The technique for setting a default value for an argument is to define the argument as a list; the first element is the argument name, and the second is the default value. When the arguments are defined as a list and a procedure is called with too few arguments, the Tcl interpreter will substitute the default value for the missing arguments, instead of generating a no value given for parameter...error.

# Example 6.1.2-1

```
#
# A proc that expects at least one arg, and has defaults for 2
#
proc showDefaults {arg1 {numberArg 0} \
    {stringArg {default string}}}
    puts "arg1: $arg1"
    puts "numberArg: $numberArg"
    puts "stringArg: $stringArg"
}
```
