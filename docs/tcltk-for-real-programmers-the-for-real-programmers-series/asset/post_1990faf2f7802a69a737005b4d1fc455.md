
## D.12.3 Unpacking the megaWidget Distribution on a Macintosh

For the Macintosh, the files are packaged in the file packages: mega_wid:widget09.hqx. You can drag and drop this file to the StuffIt icon to unpack the files.

- 1. Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive and confirm that it creates an icon on your screen when it loads.
- 2. Double-click the CD-ROM icon and step through the directories to packages:mega_wid.
- 3. Drag the widget09.hqx icon to the StuffIt Expander icon.

This will unpack the SpecTcl package into a directory on your desktop.

## E.3 TclTutor

TclTutor is a computer-aided instruction package for learning Tcl. It provides a brief description and an interactive example for all the Tcl commands. Experience has shown that people completely unfamiliar with Tcl can complete the Tutorial and be doing productive programming in just a few hours.

The TclTutor package is distributed as a self-extracting zip file and as a packaged runnable system (using the Scripts Pro Wrapper) for Windows systems, as a gzipped tar file for Unix/Linux installations, and as a BinHex archive file for Macintosh systems.

The version of the TclTutor program created with the Scripts Tcl Pro Wrapper program (tutor.exe) can be executed directly from the CD-ROM.

If you want to install TclTutor onto your hard drive, you must have wish installed on your system before starting the installation.

### E.3.1 Installing TclTutor under MS-Windows

To install TclTutor under MS-Windows:

- 1. Place the Tcl/Tk for Real Programmers CD-ROM in your CD-ROM drive. The rest of these instructions assume that this is drive D.
- 2. Select Start and then Run from the Windows task bar.
- 3. Enter or browse to D:\devel\tcltutor\tutor097.exe and run that program.
- 4. The first window will inform you that this is the TclTutor installation package. Click the OK Button.
- 5. You'll see the familiar progress bar as TclTutor is installed into a temporary directory, following which the TclTutor installation menu should be displayed.

![](img/fdcc2919568b5b6c9f5301d50a10e8d7_702_0.png)

- 6. The installation window will allow you to select the destination for this installation, or the wish interpreter to use (if you wish multiple interpreters installed on your system).

If you do not want the default destinations (C:\TclTutor) enter the path to use in the entry widgets.

Click the Install button.

- 7. A new window will open showing you the installation progress.
- 8. When the installation is complete, the new window will display that information, and the Abort button will change to an INSTALL COMPLETE - EXIT NOW button.

### E.3.2 Installing TclTutor under Unix

To install TclTutor on a Unix/Linux system:

- 1. Mount the Tcl/Tk for Real Programmers CD-ROM.
- 2. Change directory to the top of your source tree.
   cd /home/example/src
- 3. Unpack the TclTutor distribution.
   gunzip -c /cdrom/devel/tcltutor/tutor097.tgz | tar -xvf -
- 4. Change to the TclTutor directory.
   cd TclTutor
- 5. Install the package by running the Configure script.

Configure

When the Configure script starts up it will display a screen resembling this:

![](img/fdcc2919568b5b6c9f5301d50a10e8d7_704_0.png)

You can select the wish interpreter to use from the Possible Wish interpreters pull-down menu.

The Perl interpreter is used for the demonstration perl lessons. The default perl interpreter can be selected from the Possible Perl interpreters pull-down menu.

The installation directories for the lessons and binary objects can be selected by typing a new path into the Tclutor Lessons Directory or Tcl Tutor Program Directory entry widget.

If you select the enable logging button, Tclutor will log when a user enters a lesson, run examples, or changes verbosity levels.

This data file can be used by an instructor to monitor a student's progress.

If you select the mail/purge log file entry, the file will be cleared and mailed every five lessons. The default mail address in the mail field is the package author (me). In this case, the data is used to determine what lessons are accessed most often, and which should be modified.

Modify these items until they match your requirements.

Click the Install button.

- 9. If the Program directory selected is in your default path, you will be able to execute Tclutor.tcl by typing Tclutor.tcl. If it is in your path, you'll need to change the installation directory in order to run Tclutor.

### E.3.3 Installing TclTutor on a Macintosh

Tclutor is packaged in a BinHex archive (tclutor097.hqx) for the Macintosh. You can drag and drop this file to the StuffIt Expander icon to unpack it. This version of Tclutor can be run by starting a wish session, using the cd command to change to the directory where Tclutor is installed, and then source Tclutor.tcl.

```
% cd ..
% ls Tcl/Tk Folder
% cd Tclutor
% source Tclutor.tcl
```
