A Tcl extension can be built for several purposes, including:
- Adding graphics to an existing library
- Adding new features to Tcl interpreter
- Creating rapid prototyping from library

A Tcl extension must include:
- ExtName_Init function.
- Code to implement each Tcl command.

A Tcl extension should also include:
- An include named extName.h
- A Makefile.

A Tcl extension may include other files as make it maintainable, modular set of code.

New Tcl commands are defined with:
```c
Syntax: int Tcl_CreateObjCommand (interp, cmdName, func, clientData)
```
