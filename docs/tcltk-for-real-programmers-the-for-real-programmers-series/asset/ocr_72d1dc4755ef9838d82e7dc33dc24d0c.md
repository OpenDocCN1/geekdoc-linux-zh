# 9.4 More Canvas Widget Subcommands

$canvasName find -closest 100 50 0 8
would return item 9, the item immediately
below 8.

The next example shows some overlapping items and how their position in
t display list changes the appearance of the display. This example redefines
t default font for the text items. This will be explained in the next section.

Note how the upvar command is used with the array argument. In Tcl,
arrays are always passed by reference, not by value. Thus, if you need to
pass array to a procedure, you will call the procedure with the name of
t array and use upvar to reference the array values.

# 9.4.4-1

```
######################################################################
# proc showDisplayList (canv array)-
# Prints the Display List for a canvas.
# Converts item ID's to item names via an array.
# Arguments
#   canv                Canvas to display from
#   array               The name of an array with textual names for the
#                       display items
# Results
#   Prints output on the stdout.
```

```
proc showDisplayList {canv array} {
 upvar array id
  set order [$canv find all]
  puts "display list (numeric): $order"
  puts -nonline "display list (text): "
  foreach i $order {
    puts -nonline "$id($i)"
  }
  puts ""
}
```
