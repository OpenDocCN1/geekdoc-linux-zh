# 10.3 Text Widget Subcommands

A mark can be removed with the versionName mark unset command.

Syntax: versionName mark unset markName ?markName2??... \ ?markNameN?

textName unset
Remove a mark from the text widget textName.
markName The name of the mark to remove.

You get a list of all the marks defined in a text widget with the text-Name mark names command.

Syntax: versionName mark names
textName names

Return the names of all marks defined in text widget
textName.

You can search for marks before or after a given index position with the
textName mark next and textName mark previous commands.

Syntax: versionName mark next index
Syntax: versionName mark previous index

textName mark next
textName mark previous

Return the name of the first mark after (next) or before
(previous) the index location.

index
The index from which to start the search.
