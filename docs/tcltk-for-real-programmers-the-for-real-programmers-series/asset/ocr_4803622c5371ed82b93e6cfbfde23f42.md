# 9.7 The image Object

image objects can be shrunk, zoomed, subsampled, and moved from image object to image object. The image objects can be displayed in other widgets including buttons, labels, and text widgets.

The standard Tk distribution supports images defined in the X-Bitmap, GIF, Portable Pixmap, and Portable GrayMap formats. Some extensions exist that provide support for other formats such as JPEG and PNG. (See Chapter 13 for Jan Nijmans's patch to add more image support to Tk.) This section will explain how to create and use image objects.

# 9.7.1 The image Command

In order to create an image item on a canvas, you must first create an image object. The image command supports creating, deleting, and getting information about the image objects within the Tk interpreter.

The create command creates an image object from a file or internal data and returns a handle for accessing that object.

Syntax: image create type ?name ?options?

image Create an image object of the desired type, and return a handle for referencing this object.

type The type of image that will be created. Tk versions 8.0 and 8.1 support:

+   - photo-a multicolor graphic.
- bitmap-a two-color graphic.

?name The name for this image. If this is left out, the system will assign a name of the form imageX where X is a unique numeric value.

?options These are options that are specific to the type of image being created. I'll discuss the appropriate options with the bitmap and photo.

An image can be deleted with the image delete command.
