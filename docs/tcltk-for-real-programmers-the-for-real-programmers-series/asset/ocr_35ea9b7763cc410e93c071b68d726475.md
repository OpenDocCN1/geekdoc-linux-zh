# Chapter 8. Introduction to Tk Graphics

Syntax: label labelName ?option1? ?option2? ...
label Create a label widget.
lblName The name for this widget.
option Valid options for label include:

+   -font fontDescriptor
Defines the font to use for this display.
Font descriptors will be discussed in Chapter 10.
-textvariable varName
A variable that contains the display text.
-text displayText
Text to display. If -textvariable is also used, the variable will be set to this value when the widget is created.

Note that the options can be defined in any order in the following example.

# Example 8.6-1

```
Example Script
set txt [label .11 -relief raised -text \
  "Labels can be configured with text"]
pack $txt
set var [label .12 -textvariable label2Var -relief sunken]
set label2Var "Or by using a variable"
pack $var
```

| Or by using a variable |
