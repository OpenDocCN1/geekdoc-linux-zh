# D.12.3 Unpacking the megaWidget Distribution on a Macintosh

For the Macintosh, the files are packaged in the file packages:mega_wid:widget09.hqx. You can drag and drop this file to the StuffIt icon to unpack the files.

+   1. Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive and confirm that it creates an icon on your screen when it loads.

+   2. Double-click the CD-ROM icon and step through the directories to packages:mega_wid.

+   3. Drag the widget09.hqx icon to the StuffIt Expander icon.

This will unpack the SpecTcl package into a directory on your desktop.
