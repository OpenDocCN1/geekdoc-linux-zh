# 8.8.3 listbox

The listbox widget allows the user to select items from a list of items. The listbox widget can be configured to select one entry, similar to a radiobutton, or multiple entries, similar to a checkbox.

The listbox can be queried to return the positions of the selected items. This can be used to index into a list or array of information, or the listbox can be queried about the text displayed at that position.
