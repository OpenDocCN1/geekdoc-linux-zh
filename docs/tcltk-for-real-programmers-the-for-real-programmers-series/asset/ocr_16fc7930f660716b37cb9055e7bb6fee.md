# 12.5 Bottom Line

+   A Tcl extension can be built for several purposes, including:

+   - Adding graphics to an existing library
- Adding new features to a Tcl interpreter
- Creating a rapid prototyping interpreter from a library
- Creating a script-driven test package for a library

+   A Tcl extension must include:

+   - ExtName_Init function.
- A code to implement each new Tcl command.

+   A Tcl extension should also include:

+   - An include file named extNameInt.h
- A Makefile.

+   A Tcl extension may include other files as necessary to make it a maintainable, modular set of code.

+   New Tcl commands are defined with the Tcl_CreateObjCommand or Tcl_CreateCommand commands.

```
Syntax: int Tcl_CreateObjCommand (interp, cmdName, func, clientData, deleteFunc)
```

```
Syntax: int Tcl_CreateCommand (interp, cmdName, func, clientData, deleteFunc)
```
