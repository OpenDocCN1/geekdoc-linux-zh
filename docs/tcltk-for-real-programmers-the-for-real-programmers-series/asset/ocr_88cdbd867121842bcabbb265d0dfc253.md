# Chapter 5. Using Lists and Arrays

var1 The name of a variable in the higher scope to link to a local variable.

localVar1 The name of a variable in the local scope. This variable can be used in this script as a local variable. Setting a new value to this variable will change the value of the variable in the other scope.

Note that an individual array index may not be passed by value to a procedure, Tcl does not pass entire arrays by value. Whenever you need to pass an entire array to a procedure, you must use the upvar command to link to the array in the calling script's scope.

############################################################
# proc TreeGetNameParts (name Base IdNum) --
# Internal proc for splitting a name into parts
# Arguments:
# name: The name of the Tcl variable to receive the base name
# Base: The name of the Tcl variable to receive the ID number
# IdNum: The name of the Tcl variable to receive the ID number
# No valid Return, sets two variables in the calling proc.

```
proc TreeGetNameParts (name Base IdNum) {
    global Tree_InternalArray

    upvar $Base base
    upvar $IdNum idNum

    set namelist [split $name "."]\n    set base [index $namelist 0]
    set idNum [index $namelist 1]
}
```
