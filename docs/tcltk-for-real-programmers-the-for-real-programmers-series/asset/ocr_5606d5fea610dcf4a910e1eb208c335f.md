# 10.3.4.3 Using Tags

Tags are the interface into the text widget that allows you to bind actions
to events on sections of text, set colors, set fonts, margins, set line
spacing, etc. This section will discuss a few of the things that can be done
with tags and provide an example of how to use tags. The complete list of
options you can set with a tag is in the online documentation.

An action can be bound to an event on a tagged area of text using the tag
bind command.
