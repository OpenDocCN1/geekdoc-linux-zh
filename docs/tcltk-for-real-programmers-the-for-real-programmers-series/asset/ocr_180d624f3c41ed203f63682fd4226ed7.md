# 12.4 Complex Data

Tcl_NewListObj
Returns a pointer to a new Tcl_Obj that is a list object
pointing to each of the objects in the obj array of objects.

int count
The number of objects defined in the obj array of objects.

Tcl_Obj *objv[]
An array of pointers to Tcl objects that will be included in
list.
