# 11.4 A Scrolling Listbox Megawidget

The scrolledListBox widget configure subcommand is similar to the standard Tk configure command except that it will accept a subwidget argument. If the subwidget argument is supplied, then the configuration options will be applied only to those subwidgets. If no subwidget argument is supplied, the configuration options will be applied to the entire widget and all the subwidgets.

Syntax: scrolledListBoxName configure ?subwidget? -option? ?value?

+   scrolledListBoxName configure

+   Return the value of an option, or set an option, if a value is supplied.

+   The name of a subwidget or subwidgets to be configured or queried. If the widget is queried and multiple subwidget names are present, the return value will be a list of configurations in the order in which the subwidgets appear in the list.

+   subwidget

NOTE: This field is different from standard widget usage.

+   An option name. If multiple options are set, there may be multiple -option value pairs. If the configuration is being queried, only one -option argument may be present.

+   -option

+   The value to assign to a configuration option.

+   value

The insert and delete subcommands pass their arguments to the listbox subwidget with no further parsing. Thus, they exactly duplicate the behavior of the listbox subcommands.

Syntax: scrolledListBoxName insert index string

+   scrolledListBoxName insert

+   Inserts an item into the listbox at the requested index position.

+   index

+   The location in the list before which this entry will be inserted. Any index value appropriate for a listbox widget may be used.

+   string

+   The text to insert into that location of the listbox.
