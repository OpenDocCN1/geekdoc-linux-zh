For lists this technique works well. However, the time for the lsearch command to find an entry increases linearly with the position of the item in the list. Lists longer than 5000 entries become noticeably sluggish.

The pairing of data to a key value can also be done with associative arrays. The arrays use hash tables instead of a linear search to find a key, so the speed does not degrade as more records are added.

# 5.2 Using the Associative Array

The Tcl associative array can be used just like a C or Fortran array by setting the indices to numeric values. If you are familiar with Fortran or Basic programming, you might be familiar with coding constructs like this:

```
C Arrays                   Tcl Array
int values[5];             set values(0) 1;
char desc[5][80];          set desc(0) "First"
```
