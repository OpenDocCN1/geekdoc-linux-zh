# E.3.2 Installing TclTutor under Unix

To install TclTutor on a Unix/Linux system:

+   1. Mount the Tcl/Tk for Real Programmers CD-ROM.
2. Change directory to the top of your source tree.
   cd /home/example/src
3. Unpack the TclTutor distribution.
   gunzip -c /cdrom/devel/tcltutor/tutor097.tgz | tar -xvf -
