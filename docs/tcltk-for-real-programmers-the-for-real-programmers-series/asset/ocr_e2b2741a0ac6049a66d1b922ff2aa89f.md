# C5 incr_tcl

To unpack the distribution using the StuffIt Expander follow these steps:

+   1. Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive and confirm that it creates an icon on your screen when it loads.
2. Start the StuffIt Expander program.
3. Click the File menu in the upper-left corner of your screen.
4. Click the Expand menu from that menu. Clicking the Expand option will bring up a file browsing window to select the installation file. Select the file to the sequence:
   * Select the desktop
   * Double-click the name of the CD-ROM
   * Double-click incr_tcl
5. Double-click the 68000 or Power PC distribution of [incr Tcl] to install.
   * itcl_68K.hpc: For 6800-based Macintoshes
* itcl_ppc.hpc: For Power PC-based Macintoshes
6. Select the destination directory for the [incr Tcl] package.
7. Click the Unstuff button to unpack this distribution.

When StuffIt Expander is finished, you will have a new icon for [incr Tcl], and new interpreters to use.

# C.5.2 Installing the [incr Tcl] Extension under MS-Windows

To install this distribution:

The [incr Tcl] extension is created with InstallShield. You can install [incr Tcl] by executing the imghlp3.exe file.

When you execute the imghlp3.exe program, you'll see the familiar blue screen. If you choose the defaults this program will install [incr Tcl] in C:\Program Files\Itcl12.2.
