# B.2 Installing Tcl/Tk on Windows 95 or Windows NT

The Tcl/Tk distribution Microsoft Windows platforms is a self-extracting installation file created with InstallShield.
To install Tcl/Tk:

+   1. Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive. The rest of these instructions assume that this is drive D.
2. Select Start and then Run from the Windows task button.
3. Enter or browse to D:\tcl_dist\win\8.0\tcl180p2.exe and run that program.
