# 9.5 The bind and focus Commands

```
<<virtualEvent>>
```

A virtual event defined by your script
with the event command.

```
<modifier-type-detail>
```

This format precisely defines any event
that can occur. The fields of an event
descriptor are described below. Where
two names are together, they are syn-
onyms for each other. For example, either
Button1 or B1 can be used to the left
mouse button click.

modifier There may be one or more occurrences of the modifier field,
which describes conditions that must exist when an event
defined by the type field occurs. For example, Alt and
Shift may be pressed at the same time as a letter KeyPress.

Not all computers support all the available modifiers. For
instance, few computers have more than three buttons on
the mouse, and most general-purpose computers don't
support a Mod key.

The modifiers Double and Triple define double or triple
mouse clicks.

Valid values for modifier are:

| Button1 | Button2 | Button3 | Button4 | Button5 |
| --- | --- | --- | --- | --- |
| B1 | B2 | B3 | B4 | B5 |
| Mod1 | Mod2 | Mod3 | Mod4 | Mod5 |
| M1 | M2 | M3 | M4 | M5 |
| Meta | Alt | Control | Double | Triple |
| M | Lock | |

type This field describes the type of event. Only one type entry
is allowed in an event descriptor.
