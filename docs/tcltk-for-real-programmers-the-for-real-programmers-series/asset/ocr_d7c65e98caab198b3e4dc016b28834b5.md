# 8.8.2 Pull-down Menus: menubutton and menu

The Tk menubutton widget is the ubiquitous pull-down menu that we've all become so fond of.

Creating a pull-down menu with Tk requires two widgets: the menubutton that appears on the screen and a nondisplayable menu that is attached to the menubutton and contains the menu entries.

Syntax: menubutton buttonName ?options?

menubutton Create a menubutton widget.

buttonName The name for this menubutton.
