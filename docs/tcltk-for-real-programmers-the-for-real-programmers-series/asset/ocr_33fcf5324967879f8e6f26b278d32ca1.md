# Tcl Code Examples

This chapter will show how Tcl can be used. It will cover command evaluation and substitutions in a series of examples.

The first example in this chapter is a program to open a socket to a remote Post Office Protocol (POP) server and check for mail. This example demonstrates how Tcl I/O and string commands can be used to develop an Internet client.

The second series of examples goes through methods for extracting a particular piece of information from a mass of data. It will demonstrate how to use the list commands and string commands and will introduce regular expressions and subroutines.

# 4.1 Pop Client

This example uses several of the commands described in Chapter 3 to make a POP-3 mail client that will contact a remote mail server and report if there are pieces of mail waiting for you.
