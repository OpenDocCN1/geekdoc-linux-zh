tk_dialog
Create a new window with a message. When a button is clicked, the window is destroyed and the value of the button that was clicked is returned to the script that created this widget. Options for this widget include:
- -message The message to display in the box.
- -title The title to display in the window border.
- -type The type of message box to create. The type of message box will determine what buttons are created. The options are:
- abortretry Displays three buttons: abort, retry, and ignore.
- ok Displays one button: ok
- okcancel Displays two buttons: ok and cancel.
- retrycancel Displays two buttons: retry and cancel.
- yesno Displays two buttons: yes and no.
- yesnocancel Displays three buttons: yes, no, and cancel.

## 11.1 Standard Dialog Widgets

tk_dialog
Create a dialog box and wait for one or more buttons labeled with text provided in the line. When the user clicks a button, the first button number is "0". If the user destroys the window "-1" is returned. This widget creates a new window in the center of the screen and disables the other windows in the task that invoked it.

Syntax: tk_dialog win title bitmap default string
- -win The name for this dialog box.
- -title A string to place in the border of the new window. Whether or not the window is displayed with a border depends on the window manager you are using.
- -text The text to display in the message box.
- -bitmap If this is not an empty string, it must be a bitmap object or file name (not an image object) to display.
- -default A numeric value that describes the default button choice for this window. The buttons are numbered from 0.
- -string The strings to place in the buttons.

- tk_megawidget creates a popup menu window at a given location on the display (not constrained within the window). The menu appears with a tearoff entry and takes focus. Note that this is not a modal widget. The command after tk_popup will be evaluated immediately; it will not wait for the user to select an item from this widget. The following example shows the popup bound to a left button to display a question based on the contents of a text widget.

**Syntax:** tk_popup menu x y entry

tk_popup
Create a popup menu somewhere on the display. This need not be within the Tcl/Tk application window.
- -menu A previously defined menu object.
- -x The x and y coordinates for the menu in screen coordinates.
- -entry A numeric value that defines a position in a menu. The defined position will be selected (active), and the menu will be placed with that entry at the x, y position requested.

Example
```tcl
proc question {} {
  global var
# Remove any existing .m menu.
# Use catch in case there is no previous .m menu.
catch (destroy .m)
# Create a menu for this popup selector
menu .m
.m add radiobutton \
  -label "This dialog is from Abbot & Costello's 'Who's on First?' routine" \
  -variable var -value 1
.m add radiobutton \
  -label "This dialog is from War_and_Peace_" \
  -variable var -value 2
.m add radiobutton -label \
  "This dialog is from Monty Python's Parrot sketch" \
  -variable var -value 3

# Get the size and location of this window with the "winfo"
# command, which returns the geometry as
# WIDTHHEIGHT+XPOS+YPOS
# The scan command is similar to the C standard library "sscanf" function.
scan [winfo geometry .] "%dx%d+%d+%d" \
  width height xpos ypos

# Put the popup near the bottom, right hand edge of the parent window.
tk_popup .popup [expr $xpos + ($width/2) + 50] \
  [expr $ypos + $height - 40] 1

# Create a text window, display it, and insert some text from a famous dialog.
text .t -height 12 -width 75
pack .t
set dialog {
  "C: Tell me the names of the ballplayers on this team.\n"
  "A: We have Who's on first, What's on second, I'm third.\n"
  "C: I'm asking you who is on first.\n"
  "A: Who's on first.\n"
  "C: I'm asking you who is on second.\n"
  "A: What's on second.\n"
  "C: I'm asking you who is on third.\n"
  "A: I'm third.\n"
  "C: I don't understand who is on first.\n"
  "A: That's right.\n"
  "C: Give me the name of first.\n"
  "A: Who's on first.\n"
  "C: Give me the name of second.\n"
  "A: What's on second.\n"
  "C: Give me the name of third.\n"
  "A: I'm third.\n"
  "C: Now you tell me who is on first.\n"
  "A: Who's on first.\n"
  "C: Now you tell me who is on second.\n"
  "A: What's on second.\n"
  "C: Now you tell me who is on third.\n"
  "A: I'm third.\n"
}
insert .t 0.0 $dialog
```

## 11.2 Tk Megawidgets

- tk_messageBox creates a dialog window in one of several defined styles. Returns the name of the button that was clicked.
- tk_dialog creates a new window that takes focus until interaction with this widget is complete.
- tk_megawidget creates a popup menu window at a given location on the display.

### 11.2.1 Display in Application Window

Many of the megidgets included in the standard distribution are useful when loaded into the application window, but some are better when they are displayed as toplevel windows.

### 11.2.2 Modal versus Modelless Operation

Most of the megidgets in the standard distribution operate in a modal style, freezing any other activities until the user has completed the interaction. In some circumstances this is appropriate, and in others it is not.

### 11.2.3 Widget Access Conventions

Megidgets can be built to mimic the behavior of the standard widgets (as later examples in this chapter will do) or to follow their own conventions.

### 11.2.4 Widget Frames

Megidgets have a parent frame that holds their subwidgets. This frame can be created by the widget creation command or provided by the calling procedure.

### 11.2.5 Configuration

The default values you choose for a megawidget when you design it may not be what the next person to use the library needs.
