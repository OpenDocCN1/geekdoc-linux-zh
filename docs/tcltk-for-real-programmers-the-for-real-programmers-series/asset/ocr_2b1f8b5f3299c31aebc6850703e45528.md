# B.3 Installing Tcl/Tk on Unix/Linux Systems

# B.3.2 Large Systems Installation

If you need to install Tcl/Tk on many machines you won't want to compile Tcl/Tk on each machine and perform the install.

The best solution is probably to NFS mount a common bin and library directory tree. If that's not possible you can distribute the software across your network using packages like rdist or surd.

If neither of these options are appropriate for your site, the Tcl Makefile can be used to install the Tcl package in a directory other than the one it was compiled for. For example, lets you compile Tcl for /usr/local, and install it under /tmp/usr/local. You can then make an installation file from /tmp to use when installing the binaries on other systems.

The steps for doing this are:

+   1. Unpack and configure as above.

+   2. Edit the Makefile.

> Add a path for the temporary directory to the INSTALL_ROOT parameter.
For example:
```nINSTALL_ROOT = /tmp
```

+   3. Make the distribution.

+   4. Create the empty directory tree for the installation.

```
```nmkdir /tmp/usr
mkdir /tmp/usr/local
```
```

+   5. Make install.

+   6. Change to the parent of the temporary directory.

```
```ncd /tmp/usr/local
```
```

+   7. Create a tar archive.

```
```ntar -cvf tcl.install.tar
```
```

+   8. Copy the tar archive to the destination system and untar it.

```
```nbar> login foo
foo> cd /usr/local
foo> ftp bar
```
```
