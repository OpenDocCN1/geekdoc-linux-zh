# 5.4 Trees in Tcl

Syntax: treeSetTreeValue anyNode Key Value
treeSetTreeValue

Set a Key and Value pair in an entire tree.

anyNode
The handle for any node in the tree.

Key
The identifier for this datum.

Value
The value for this datum.

Syntax: treeGetTreeValue anyNode Key
treeGetNodeValue

Returns the value associated with a Key in this tree.

anyNode
The handle for any node in this tree.

Key
The identifier for this datum.
