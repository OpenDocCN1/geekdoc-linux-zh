# Chapter 14. Programming Tools

The online help list lists the available commands in this debugger:

```
% debug 1
dbg1.3> h step into procedure
s [#] step over procedure
n [#] step over procedures, commands, and arguments
N [#] continue
c continue until return to caller
r move scope up level
u [#] move scope down level
d [#] go to absolute frame if # is preceded by "#"
w show stack ("where")
w -w [#] show/set width
w -c [0|1] show/set compress
b show breakpoints
b [-r regexp-pattern] [if expr] [then command]
b [-g glob-pattern] [if expr] [then command]
if pattern given, break if command resembles
pattern if expr given, break if expr true
if command given, execute at break-point
b - delete breakpoint
b - delete all breakpoints
```

While in the debugging mode, the normal prompt resembles Dbg2.3>, where the digit 2 represents the current stack level and the 3 represents the number of interactive commands that have been executed.

In the sample debugging session shown next, the optional patterns and if/then statements are used with the break command to display the contents of the variable 1st when the breakpoint is encountered.
