
# 9.4 More Canvas Widget Subcommands

```cl
canvas .c -height 150 -width 150
pack .c

# Create an outline box for the boundaries.

.c create rectangle 3 3 147 147 -width 3 -outline black \
  -fill white

# Create a star item
.c create polygon 1 15 3 10 0 5 5 8 0 10 5 16 5 12 10 \
  14 15 8 12 -fill black -outline black -tag star
# Set the initial velocity of the star
set xoff 2
set yoff 3
#
# Move the item
while {1} {
  set box [index box 0]
  set left [index box 0]
  set top [index box 1]
  set right [index box 2]
  set bottom [index box 3]
  # If the star has reached the left margin, heading left,
  # or the right margin, heading right, make it bounce.
  # Reduce the velocity to 90% in the bounce direction to
  # account for elasticity losses, and reverse the X
  # component of the velocity.
  if {($xoff < 0) && ($left <= 3)) ||
    (($xoff > 0) && ($right >= 147))} {
    set xoff [expr -.9 * $xoff]
  }

# The same for the Y component of the velocity.
  if {($yoff < 0) && ($top <= 3)) ||
    (($yoff > 0) && ($bottom >= 147))} {
    set yoff [expr -.9 * $yoff]
  }
```

## 9.4.4 Finding Items, Raising and Lowering Items

The canvas can be searched for items that meet certain criteria, such as their position in the display list, their location on the canvas, or their tags. The canvas widget subcommand that searches a canvas is the find subcommand. It will return a list of unique IDs for the items that match its search criteria. The list is always returned in the order in which the items appear in the display list, the first item displayed (the bottom if there are overlapping items) first, etc.

The items in a canvas widget are stored in a display list. The items are rendered in the order in which they appear in the list, thus items that appear later in the list cover items that appear earlier in the list.

An item's position in the display list can be changed with the raise and lower subcommands.

```cl
Syntax: canvasName raise tagOrId ?aboveTagId?
```

- raise: Move the identified item to a later position in the display list, making it display above other items.

- tagOrId: A Tag or unique ID that identifies the item.

- ?aboveTagId?: The Id or Tag of an item this should be above. By default, items are moved to the end position in the display list (top of the displayed items). With this option, an item can be moved to locations other than the top. In fact, you can raise an item to just above the lowest item, lowering the item.

```cl
Syntax: canvasName lower tagOrId ?belowtagOrId?
```

- lower: Move identified item to an earlier position in the display list, making it display below other items.

- tagOrId: A Tag or unique ID that identifies the item.

- ?belowtagOrId?: The Id or Tag of an item this item should be directly below. By default, items are moved to the first position in the display list (bottom of the displayed items). With this option, an item can be moved to locations other than the bottom. You can lower an item to just below the top item, effectively raising the item.

```cl
Syntax: canvasName find searchSpec
```

- find: Find displayable items that match the search criteria and return that list.

- searchSpec: The search criteria. May be one of:

- all: Return all the items in a canvas in which they appear in the display list.

- withTag: Returns a list of all items with this tag.

- above tagOrId: Returns the single item just above the one defined by tagOrId. If a Tag refers to multiple items, then the last (topmost) item is used as the reference.

- below tagOrId: Returns the single item just below the one defined by tagOrId. If a Tag refers to multiple items, then the first (lowest) item is used as the reference.

- enclosed x1 y1 x2 y2: Returns the items that are totally enclosed by the rectangle defined by x1, y1 and x2, y2. The x and y coordinates define opposing corners of a rectangle.

- overlapping x1 y1 x2 y2: Returns the items that are partially enclosed by the rectangle defined by x1, y1 and x2. The x and y coordinates define opposing corners of a rectangle.

- closest x y ?halo? : Returns the item closest to the X/Y location described with the x and y parameters. If more than one item overlays the X/Y location, the one that later in the display list is returned. The halo parameter is a positive integer that is added to the actual bounding box of items to determine whether they cover the X/Y location. The start parameter can be used to step through a list of items that overlap the X/Y position. If this is present, the item returned will be the highest item before the item defined by start.

The next example shows some overlapping items and how their position in the display list changes the appearance of the display. This example redefines the default font for the text items. This will be explained in the next section. Note how upvar command is used with array. In Tcl, arrays are always passed by reference, not by value. Thus, if you need to pass array to a procedure, you will call the procedure with the name of array and use upvar to reference the values.

```cl
######################################################
# proc displayList (canv array)
# Prints the Display List for a canvas.
# Converts item IDs to item names via an array.
# Arguments
#   canv                Canvas to display
#   array               The name of an array with textual names
# Results
#   Prints output on stdout.

proc displayList {canv array} {
  upvar array id
  set order [$canv find all]
  puts "display list (numeric): $order"
  puts "display list (text): "
  foreach i $order {
    puts "$id($i)"
  }
  puts ""
}
```

# Example Script
```cl
canvas .c -height 150 -width 170
pack .c

# create a light gray rectangle with dark text.
set tclSquare \
    [.c create rectangle 10 20 110 140 \
    -fill gray70 -outline gray70 ]
set tclText [.c create text 60 50 -text "Tcl\nTcl" \
    -fill black -anchor center -font {Times 22 bold} \
    -justify center]

# create a dark gray rectangle with white text.
set tclSquare \
    [.c create rectangle 60 20 160 140 -fill gray30 \
    -outline gray30 ]
set tclText [.c create text 110 50 -text "Tcl\nTops" \
    -fill white -anchor center -font {Times 22 bold} \
    -justify center]

# Initialize the array with the names of the display items
# linked to the unique number returned from the canvas create.
foreach nm [list tclSquare tclText tclSquare tclText] {
    set id([subst $$nm]) "$nm")
}

# Update the display and canvas
update:

# Show display list
puts "\nAt beginning"
displayList .c id

# Pause to admire the view
after 1000

# Raise the tclSquare and tclText items to the end
# (top) of the display list
.c raise $tclSquare
.c raise $tclText

# Update, display the new list, and pause again
update;
puts "\nAfter raising tclSquare and tclText"
displayList .c id after 1000

# Raise the tkText to above the tclSquare (but below tclText)
.lower $tkText $tclText

# Update and confirm.
update;
puts "\nAfter 'lowering' tkText"
displayList .c id

puts ""
puts "Find reports that $id[.c find above $tclSquare] \
is above tclSquare"
puts "Find reports that $id[.c find below $tclSquare] \
is below tclSquare"
puts "and items: [.c enclosed 0 0 120 150] are \
enclosed within 0,0 and 120,150"
```
