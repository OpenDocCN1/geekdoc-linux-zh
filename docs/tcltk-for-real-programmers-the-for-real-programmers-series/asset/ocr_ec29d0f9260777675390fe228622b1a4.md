# Chapter 11. Tk Megawidgets

**Syntax:** `tk_getOpenFile ?option value?`

```
tk_getOpenFile
```

Create a file browsing widget to find an existing file.

`?option value?`nThe options supported by the `tk_getOpenFile` megawidget get include:

+   -defaultextension extension

The extension string will be appended to a file name entered by users if they do not provide an extension. The default is an empty string. This option is ignored on the Macintosh.

+   -filetypes patternList

This list is used to create menu entries in the **Files of type:** menubutton. If file types are not supported by the platform that is evaluating the script, this option is ignored.

+   -initialdir directory

The initial directory for the directory choice menubutton. Note that on the Macintosh the *General Controls* panel may be set to override application defaults, which will cause this option to be ignored.

+   -initialfile fileName

Specifies a default file name to appear in the selection window.

+   -parent parentWindow

Specifies the parent window for this widget. The widget will attempt to be placed over its parent but may be placed elsewhere by the window manager.
