# Installing Tcl/Tk Extensions

The CD-ROM contains several extensions to Tcl. Most of these are distributed as source code to be compiled with the Tcl library to create a new Tcl interpreter or loadable library.

The [incr Tcl], img, dash, plus, and TclX extensions are available as binaries for MS-Windows.

Only the [incr Tcl] extension is compiled for the Macintosh.

# C.1 BLT

The BLT extension included on the CD-ROM is revision 2.4e, which can be used with Tk revisions 4.1, 4.2 and 8.0. This version is supported only for Unix, Linux, etc.
