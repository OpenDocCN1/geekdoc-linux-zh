# 10.3.3 The mark Subcommands

The text mark subcommands are used to manipulate marks in the text
widget. Marks are used when you need to remember a particular location in the
text. For instance, you can use marks to define an area of text to highlight,
for a cut-and-paste operation, etc.

A mark is defined with the textName mark set command.

Syntax: textName mark set markName index

textName mark set

Set a mark in the text widget textName.

markName The name to assign to this mark.

index The index of the character to the right of the mark.
