# 5.5.3 Creating a New Child Node

The proc to create a new node is treeCreateChild. This proc creates a node, adds its handle to the parent node's list of children, and puts the parent's handle in the parent index of the new node. The treeCreateNode proc calls two internal procs: one to create a node (TreeCreateNode) and another to link the node to the parent (TreeAddChild).

TreeCreateNode creates an orphan node, with no parent and no children.

Syntax: TreeCreateNode treeID

TreeCreateNode
Create a new node. Confirm that the tree exists, and increment the unique ID.

treeName
The name of the tree, either treename.base or a node name.

Syntax:TreeAddChild parent child

TreeAddChild
Confirms that the child exists. Adds the child's handle to the parent's child list and sets the child's parent index.
