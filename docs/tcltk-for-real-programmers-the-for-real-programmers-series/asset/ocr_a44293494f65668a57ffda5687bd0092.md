# Appendix B. Installing Tcl/Tk Distributions

If you can use binaries compiled for BSD/OS 3.0 or RedHat 5.0 Linux system you'll find pre-compiled binaries on the CD-ROM, ready to install in /usr/local. (Skip to B.3.3).

# B.3.1 Compiling Tcl/Tk

To compile the Tcl/Tk distributions, you'll need:

+   - a C compiler (gcc is good, even the portable C compiler will work)
- gunzip (to uncompress the distribution)
- tar (to unpack the distribution)

You must compile the Tcl distribution before you can compile the Tk distribution.

+   1. Mount the Tcl/Tk for Real Programmers CD-ROM (I'll assume it's mounted on /cdrom)
2. Create a parent directory for the distributions, if necessary. I prefer to have all the Tcl distributions under /usr/src/TCL instead of /usr/src
3. Change to the parent directory for this distribution.

```
$ cd /usr/src/TCL
```

+   4. Unpack the distributions.

(Note that true tar uses -xovf, while pax-based tar does not use the -o flag, and modern tar programs do not require the dash.)

```
$ gzcat /cdrom/tcl_dist/unix/8.0/tcl8.0p2.tar.gz | tar -xvf -
$ gzcat /cdrom/tcl_dist/unix/8.0/tk8.0p2.tar.gz | tar -xvf -
```

+   5. Change to the distribution/unix directory.

```
$ cd tcl8.0/unix
```

+   6. Run configure to examine your system and create a Makefile.

```
$ configure
```

You can get a list of options to set when configure is run with the
-help flag:

```
$ configure -help
```

Usage: configure [options] [host]
Options: [defaults in brackets after descriptions]
