Note the way the -side option is used in the previous example. The buttons are packed with -side set to right. The pack command will place the first widget with a -side option set against the requested edge of the parent frame. Subsequent widgets will be placed as close to the requested side as possible without displacing a widget that previously requested side of the frame.

The -fill x option to the pack $resultFrame allows the frame that holds the $tax and $result widgets to expand to the entire width of the window, as shown in the With -fill result.

By default, a frame is only as big as it needs to be to contain its child widgets. With the -fill option, the $resultFrame would be the narrowest of the frames and would be packed in the center of the middle row, as shown in the Without -fill result.
