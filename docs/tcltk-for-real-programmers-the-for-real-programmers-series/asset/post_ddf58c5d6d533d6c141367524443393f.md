As a compromise between ease of use and ease of debugging, the process Options procedure returns a list of the results of the catch ... configure calls. This is a list of success and failure codes (0 or 1) in the order of the widget and options.

If processOptions is called with a list of two options and two widgets, there will be four return codes in the list: the results of widget1-option1, widget2-option1, widget1-option2, and widget2-option2. Using this list, scripts that need to know what failed or succeeded check the results, and scripts that simply need to set any valid option can ignore the return.

## 11.4 A Scrolling Listbox Megawidget

```tcl
proc processOptions {optionlist widgetlist (parent {})} {
  set return ""

  # Loop through the options and widgets.
  # If an option is not valid for a widget, fail silently
  # and continue processing

  foreach {option value} $optionlist {
    foreach widget $widgetlist {
      if {[string length $value] > 0} {
        lappend return \
          [catch "$parent$widget \
            configure $option\
            $value"]
      } else {
        catch "$parent$widget configure \
          option val
          lappend return $val
      }
    }
  }
  return $return
}
```

### 11.4.1 scrolledListBox Description

The scrolledListBox widget configure subcommand is similar to the standard configure command except that it will accept a subwidget argument. If the subwidget argument is supplied, then the configuration options will be applied only to those subwidgets. If no subwidget argument is supplied, the configuration options will be applied to the entire widget and all subwidgets.

Syntax: scrolledListBoxName configure ?subwidget? -option? ?value?

- scrolledListBoxName configure
- Return the value of an option, or set an option, if a value is supplied.
- The name of a subwidget or subwidgets to be configured or queried. If the widget is queried and multiple subwidget names are present, the return value will be a list of configurations in the order in which the subwidgets appear.
- subwidget (NOTE: This field is different from standard widget usage.)
- An option name. If multiple options are set, there may be multiple -option value pairs. If the configuration is being queried, only one -option argument may be present.
- -option
- The value to assign to a configuration option.
- value

The insert and delete subcommands pass their arguments to the listbox subwidget with no further parsing. Thus, they exactly duplicate the behavior of the listbox subcommands.

Syntax: scrolledListBoxName insert index string

- scrolledListBoxName insert
- Inserts an item into the listbox at the requested index position.
- index
- The location in the list before which this entry will be inserted. Any index value appropriate for a listbox widget may be used.
- string
- The text to insert into that location of the listbox.
