
## D.10 SpectTcl

1. Change to the SpectTcl1.1/bin directory.
2. Edit SpectTcl and specJava.

- Set the DIR variable to point to the current directory.
- Optionally set the WISH variable to point to the version of wish you want to use.
- Add $DIR/SpecTcl1.1/bin path to your $PATH environment variable, or copy the specTcl and specJava variables to a directory in your search path.

### D.10.3 Installing SpectTcl on a PPC-Based Macintosh

The SpectTcl distribution for the Macintosh is a self-extracting BinHex archive. This file includes a stub for the Power PC version of the Macintosh. This will not work with a 680x0-based Macintosh. See Section D.10.4.

The first step is to convert the packed file into an installation file using the Aladdin Systems StuffIt Expander package. The StuffIt Expander program is distributed with Netscape and can be obtained from http://www.aladdinsys.com.

The second step is to run the distribution using the StuffIt Expander follow these steps:

To unpack the distribution:
1. Place the Tcl/Tk for Real Programmers CD-ROM drive and confirm that it creates an icon on your screen when it loads.
2. Start the StuffIt Expander program by double-clicking the Expander icon.
3. Click the File menu in the upper-left corner of your screen.
4. Click the Expand option from that menu.

Clicking the Expand option will bring up a file browsing window to select the installation file. Select the file to extract with the sequence:

- Select the desktop
- Double-click the name of the CD-ROM
- Double-click devel
- Double-click spec_tcl
5. Double-click the entry `SPEC_SEA.HQ`.
6. Click the **Desktop** button. The contents of the desktop will now appear in the window, and the **Unstuff** button will no longer be grayed out.
7. Click the **Unstuff** button, or press the **Return** key.
8. StuffIt Expander will now convert the distribution file to an executable program on your desktop area.
9. When StuffIt Expander has completed the expansion of the distribution file, there will be a new icon on your desktop named SpecTcl 1.1 Installer.
10. Click the SpecTcl 1.1 Installer icon. This starts the SpectTcl installation.
11. The first window you see will have the Tcl/Tk license agreement. Click the **Continue** button.
12. The next window informs you that this installation program will install the SpecTcl GUI Builder. Click the **Install** button.
13. The next window will allow you to select where you'd like to place the Tcl/Tk package.

### D.10.4 Installing SpecTcl on a 680x0-based Macintosh

A modified version of the SpecTcl GUI builder is in the file level:spec_tcl:tcl.hq which can be unpacked into a directory with the StuffIt Expander.

1. Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive and confirm that it creates an icon on your screen when it loads.
2. Double-click the CD-ROM icon and step through the directories to level:spec_tcl.hq.
3. Drag the spectcl.hq icon to the StuffIt Expander icon.
This will unpack the SpecTcl package into a directory on your desktop.

## D.11 SWIG

SWIG distribution is done as a gzipped archive for Unix systems, as a self-extracting zip file for MS-Windows systems, and as a self-extracting BinHex archive for the Macintosh.

### D.11.1 Installing SWIG under MS-Windows

The SWIG distribution has been repackaged as a self-extracting zip file for this CD-ROM.

To install SWIG under MS-Windows:

- Place the Tcl/Tk for Real Programmers CD-ROM in your CD-ROM drive. The rest of these instructions assume that this is drive D.
- Select Start and then Run from the Windows taskbar.
- Enter or browse to D:\devel\swig\swig11p.exe and run that program.
- The first window will inform you that this is the SWIG installation package. Click the OK button.
- The next window will allow you to select the destination for this installation. If you do not want the default destinations (C:\swig) enter destination path. Click the Unzip button.
- You'll see the package is fully installed, a window will appear informing you that SWIG is installed.
- When the process finishes, a window will appear you that 1152 files were successfully installed. Click the OK button.
- Close the installation window.

Instructions for compiling SWIG with C++ or Borland C++ are in the file win\readme.txt under the directory you installed SWIG into.

### D.11.2 Installing SWIG under Unix

To install SWIG under Unix:

- Mount the Tcl/Tk for Real Programmers CD-ROM.
- Change directory to the directory where you wish to install SWIG.
1. Unpack the swig distribution.
   gunzip -c /cdrom/devel/swig/swig11p5.tgz | tar -xvf -
2. Change to the SWIG.1p5 directory. Check the README file for more options. To make a default installation, continue these instructions.
3. Create the Makefile by running configure.
   configure
4. Make the swig executable with make.
   make
5. Install the new executable with make install.

### D.11.3 Installing SWIG on a Macintosh

The SWIG distribution for the Macintosh is a self-extracting BinHex archive. Note that this distribution is for a Power PC-based Macintosh. This executable will not work on a 680x0-based Macintosh.

The first step is to convert the packed file into an installation file using the Aladdin Systems StuffIt Expander package. The StuffIt Expander program is distributed with Netscape and can be obtained from http://www.aladdinsys.com.

The second step is to run the installation program to install SWIG.

2. Start the StuffIt Expander program by double-clicking the Expander icon.
3. Click the File menu in the upper-left corner of your screen.
4. Click the Expand menu option from that menu. Clicking the Expand option will bring up a file browsing window to select the installation file. Select the file to extract with the sequence:
- Select the desktop
- Double-click the name of the CD-ROM
- Double-click devel
- Double-click swig
5. Double-click the entry SWIG_SEA.HQX.
6. Click the Desktop button. The contents of the desktop will now appear in the window, and the Unstuff button will no longer be grayed out.
7. Click the Unstuff button, or press the Return key.
8. Stuffit Expander will now convert the distribution file to an executable program on your desktop area.
9. When StuffIt Expander has completed the expansion of the distribution file, there will be a new icon on your desktop named SpecTcl 1.1 Installer.
10. Click the SpecTcl 1.1 Installer icon. This starts the SpectTcl installation.
11. The first window you see will have the Tcl/Tk license agreement. Click the **Continue** button.
12. The next window informs you that this installation program will install the SpecTcl GUI Builder. Click the **Install** button.
13. The next window will allow you to select where you'd like to place the Tcl/Tk package.
The SWIG will be unpacked into the directory you selected.

## D.12 megaWidget

Jeff Hobbes' megaWidget package is included in the packages/mega_wid directory. This package is discussed in Chapter 11.

This package is being distributed as a gzipped archive for Unix-based systems, as a self-extracting zip file for MS-Windows-based systems, and as a BinHex archive for the Macintosh.

### D.12.1 Unpacking the megaWidget under Windows

The megaWidget package has been repackaged as a self-extracting zip file for the Windows users.

To unpack the self-extracting zip files:

- Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive.
- Open the Run dialog box.
- Enter or browse to D:\packages\mega_wid\widget09.exe. Select this as browse to the file to run.
- Run the self-extracting zip file.
- Click the OK button.
- The next window gives you the chance to select the installation directory. You may accept the default installation directory (C:\widget) or type in the directory path you prefer.
- Click the Unzip button.
- You will see the usual progress bar as the extension is installed.
- When the installation is complete click the OK button.
- Exit the installation program by clicking the Clear button.
- Run the TOUR.tcl example with a command resembling C:\programl\tcl\bin\wish tour.tcl.

### D.12.2 Unpacking the megaWidget Distribution under Unix

To unpack the megaWidget package on a Unix/Linux system:

- Mount the Tcl/Tk for Real Programmers CD-ROM.
- Change directory to the top of your source tree. cd /home/example/src
- Unpack the widget09 source distribution. gunzip -c /cdrom/packages/mega_wid/widget09.tgz | tar -xvf -
- Change to the widget directory. cd widget
- Run the TOUR.tcl example with a command resembling: /usr/local/bin/wish TOUR.tcl
