# 9.4 More Canvas Widget Subcommands

tagOrId

A Tag or unique ID that identifies the item.

The Id or Tag of an item this should be above. By default, items are moved to the end position in the display list (top of the displayed items). With this option, an item can be moved to locations other than the top. In fact, you can raise an item to just above the lowest item, lowering the item.

Syntax: canvasName lower tagOrId ?belowtagOrId?

lower Move identified item to an earlier position in the display list, making it display below other items.

tagOrId A Tag or unique ID that identifies the item.

?belowtagOrId?

The Id or Tag of an item this item should be directly below. By default, items are moved to the first position in the display list (bottom of the displayed items). With this option, an item can be moved to locations other than the bottom. You can lower an item to just below the top item, effectively raising the item.

Syntax: canvasName find searchSpec

find Find displayable items that match the search criteria and return that list.

searchSpec The search criteria. May be one of:

+   all Return all the items in a canvas in which they appear in the display list.

+   withtag Tag Returns a list of all items with this tag.

+   above tagOrId Returns the single item just above the one defined by tagOrId. If a Tag refers to multiple items, then the last (topmost) item is used as the reference.
