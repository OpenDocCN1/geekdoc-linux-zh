# 8.7.5 Working Together

The different layout managers can be used together to get the screen layout you desire. In the rules defined in the following, .f1 and .f2 are frames that contain other widgets.

Within a single frame, any single layout manager can be used.

This is valid:
pack .f1.bl -side left
grid .f2.bl -column 1 -row 3

Within a single frame, the grid and pack managers cannot be mixed.

This is not valid:
pack .f1.bl -side left
grid .f2.bl -column 1 -row 3

The place can be used with either the grid or pack command.

This is valid:
pack .f1.bl -side left
place .f1.label -x 25 -y 10
grid .f2.bl -column 1 -row 3
place .f2.label -xrel .1 -yrel .5

Frames can be arranged with either grid or pack regardless of which layout manager is used within the frame.

This is valid:
pack .f1.bl -side left
grid .f2.bl -column 1 -row 3
grid .f1 -column 0 -row 0
grid .f2 -column 1 -row 0
