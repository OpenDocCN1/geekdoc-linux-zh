+   * Use eval to set command line arguments.

Again, if you are familiar with C, you are familiar with parsing command line arguments using code that resembles this:

```
foreach arg $argv {
    switch $arg -- {
        "-alpha" {set alphaMode 1}
        "-debug" {set debugMode 1}
        ...
    }
```

When you need to add a new command line option, you need to add new code to the switch statement.

In Tcl, you can write code that resembles this:

```
foreach arg $argv {
    set varName [format "%sMode" $arg]
    eval set $varName 1
}
```

With this example, adding new options does not require changing the parse code.
