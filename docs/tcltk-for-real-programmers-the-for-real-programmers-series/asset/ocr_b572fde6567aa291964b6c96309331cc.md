# 10.3 Text Widget Subcommands

Alternatively, you can get a list of all the index ranges that are tagged with a particular tag with the tag ranges command.

**Syntax:** `tagName tag ranges tagName`

+   - `tagName`: The widget that contains the tags.
- `tag ranges`: Return a list of index ranges that have been tagged with `tagName`.
- `tagName`: The name of the tag to search for.

# Example 10.3.4.2-1 Example Script

```
t . -height 5 -width 70
pack .t

t insert end "Text can have multiple tags at any \ngiven index.\\n" T1
t insert end "You can get a list of tags at an index \
with 'tag names'.\n" T2
t insert end "You can search the tag with prevrange and \nnextrange.\\n" T3
t insert end "You can get the ranges where a tag is \ndefined with 'ranges'\\n" T4

t tag add firstchar 1.0
t tag add firstline 1.0 (1.0 lineend)
t tag add firstpage 1.0 end

t tag add secondline 2.0

t tag add firstchar 2.0
t tag add firstchar 3.0
t tag add firstchar 4.0

puts "These tags are defined: \n [.t tag names]"
puts "These tags are defined at index 1.0: [.t tag names 1.0]"
puts "Tag firstchar is defined for these ranges: \\n [.t tag ranges firstchar]"
puts "Tag T2 is defined for the range: \n [.t tag ranges T2]"
```
