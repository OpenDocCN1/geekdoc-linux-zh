# 4.3.4 Using the string match instead of string first

There are other options that can be used for the test in the if statement.

# Example 4.3.4-1

# Search Using a string match Test

```
% foreach item $sUrlList {
  if {[string match *[Ss]scriptics*} $item} {
    puts "SCRIPTS PAGE:\n
    $item"
  }
}
```

# Script Output

SCRIPTS PAGE:
"http://www.scriptics.com/" "Scriptics Corporation"

Notice that the pattern argument to the string match command is enclosed in braces to prevent Tcl from performing command substitutions on it. The pattern includes the asterisks because string match will try to match a complete string, not a substring. The pattern {*[Ss]scriptics*} causes string match to accept as a match that has the string scriptics or Scriptics with any sets of characters before or after.
