# # 6.5 Working with Global and Local Scopes

```
# display the value of x at absolute stack levels
for {set i 0} {$i < 3} {incr i} {
    upvar #$i localX
    puts "X at upvar #$i is $localX"
}
uts ""

proc b1 {} {
    # Declare that X exists in the global scope
    # do not create an x in the local scope.
    global x;
    puts "X in global scope is: $x"
}
```

# Example Script

```
set x 0;
puts "X at global scope is $x"
stack1
b1
```
