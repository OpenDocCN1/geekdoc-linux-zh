# E.4 Accessing the Extra Documentation

The docco directory contains additional documentation for using Tcl in Postscript format. These files include:

+   - eng_man.ps The Tcl Engineering Manual that describes conventions for creating Tcl Extensions.
- style.ps The Tcl Script style manual.
- tkref40.tgz Paul Raines Tcl/Tk pocket reference guide for Tcl revision 7.4 and Tk revision 4.0.
- tkref80.tgz Paul Raines Tcl/Tk pocket reference guide for Tcl and Tk revision 8.0.
