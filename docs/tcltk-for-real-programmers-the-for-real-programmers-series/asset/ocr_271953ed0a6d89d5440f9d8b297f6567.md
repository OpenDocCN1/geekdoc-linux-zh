# B.1 Installing Tcl/Tk on a Macintosh

13. The next screen allows you to select for a PowerPC or a Motorola 680x0-based Macintosh.

![](bbox=[0.258, 0.183, 0.709, 0.442])

Click on the selection, which describes your system. If your Macintosh is more than a few years old, it is probably a 680x0-based system. If it is new, it is probably a Power PC-based system.

After you've selected your system, click the **Install** button.

14. The next window will allow you to select where you'd like to place the Tcl/Tk package.

![](bbox=[0.237, 0.606, 0.673, 0.788])

After you've selected the workspace for Tcl/Tk (perhaps the main desktop) click the **Install** button.
