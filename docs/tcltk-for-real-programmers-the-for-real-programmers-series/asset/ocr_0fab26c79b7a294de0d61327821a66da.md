# 14.5 Tcl Compilers

The compilers generate Tcl bytecode files or complete executable programs. Shipping bytecode files will hide your source, and shipping an executable program allows the user to execute your application without having to install a Tcl interpreter and libraries.

Interpreted code is fast to develop but runs slowly, whereas compiled code runs quickly but is slow to develop. The ICE Tcl compiler helps you get the best of both worlds.

The compiler comes in two varieties. The version 1.3 compiler compiles Tcl 7.X scripts into C. This can speed up your 7.X script by factors between 5 and 15 depending on the script. The C output is compiled and linked with Tcl libraries to create an executable. The compiled C code produced by the 1.3 compiler is about 50% faster than the interpreted Tcl 8.0 code.

The version 2.0 compiler (under development until 1998) will be able to generate Tcl object code, Java code, or C object code and will perform compiler optimizations including constant folding, subexpression elimination, and loop unrolling.
