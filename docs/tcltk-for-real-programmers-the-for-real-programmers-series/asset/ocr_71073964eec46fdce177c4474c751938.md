The foreach command is used to iterate through a list of items.

**Syntax:** `foreach listVar list body`

| foreach | Evaluate the body for each of the items in list. |
| listVar | This variable will be assigned the value of the list element currently being processed. |
| list | A list of data to step through. |
| body | The body of code to evaluate on each pass through the loop. |

# Foreach Loop Example

```
foreach element [list one two three] {
    puts "this is element: $element"
}}
```

# Script Output

```
this is element: one
this is element: two
this is element: three
```

# 3.3.5 String Processing Commands

The string and format commands provide support for manipulating strings. The string subcommands include commands for searching for substrings, identifying string matches, trimming unwanted characters, and converting case. The format command generates formatted output from a format descriptor and a set of data.
