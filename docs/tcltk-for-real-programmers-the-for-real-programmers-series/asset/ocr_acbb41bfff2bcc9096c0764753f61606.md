# 9.6 Creating a Widget

Now that we know how to create drawable items in a canvas and bind
actions to events in that canvas, we can create our own widgets.

For example, suppose we want an MS-Windows/Netscape-style toolbar
button that displays information when the cursor hasn't moved for 2
seconds.

To create this we need to write a package that will create a canvas, draw some-
thing appropriate in that canvas, and bind scripts to the appropriate events.

Here is a specification for a toolbar button:

+   - Will be invoked as toolbarbutton name ?-option value?
- Required options will be
  -bitmap bitmapName
  -command script
  -info infoText
- Optional arguments will be
  -height number
  -width number
