This chapter will discuss debugging, some common mistakes, some techniques to make your code more maintainable, and a bunch of odds and ends that haven't been covered in previous chapters.

# 15.1 Debugging Techniques

The debuggers discussed in Chapter 14 are very useful tools but are not the only way to debug code. Tcl has some features that make it easy to debug code without a debugger.

Because of the interpreted nature of Tcl, you may find it easier to do much of your debugging without a debugger. Since there is no separate compilation stage in Tcl, you can easily add a few debugging lines and rerun your test.
