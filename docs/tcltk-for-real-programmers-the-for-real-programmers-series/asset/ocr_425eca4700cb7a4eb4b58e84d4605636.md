Chapter 10. The text Widget and html_library

```
# Find the close parenthesis, and place the image
#   just before it.
set closeParenLocation [.t search "] 1.0]
.t image create $closeParenLocation -image $img

# Create a new text widget for columnar text.
text .t2 -height 5 -width 40 -relief flat

# Insert some prose.
.t2 insert end "This is a separate text widget\n"
.t2 insert end "a few lines of text in it that will\n"
.t2 insert end "be placed next to another copy of the \n"
.t2 insert end "image". This is more aesthetically \n"
.t2 insert end "pleasing."

# Place the new window and image side by side in the
#   primary text widget.
.t window create end -window .t2
.t image create end -image $img
```
