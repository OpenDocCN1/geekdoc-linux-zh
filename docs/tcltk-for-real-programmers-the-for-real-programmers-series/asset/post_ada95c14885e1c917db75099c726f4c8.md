## 10.3.5 Inserting Images and Widgets into a text Widget

You can insert an image created with the image create command into a text widget with the text image create command, and other Tk widgets can be inserted into a text widget with the window create command.

Syntax: text image create index ?options?

text image create

Insert an image into a text widget.

index The index at which to insert the image.

?options? The options for the image create command include

-image handle
The image object handle returned when the Tk image object was created. (See Section 9.7.1.)

-name imageName
A name to use to refer to this image. A default name will be returned if this option is not present.

Syntax: .textName create index ?options?

textName window create
Insert a Tk widget into the text widget.

index The index at which to insert the Tk widget.
?options? The options for the window create command include

-window widgetName
The name given to this widget when it was created.

-create script
A script to evaluate to create the window if the -window option is not used.

The new image or widget will be inserted into the text at the requested index. Images and windows are inserted into the text widget just like another character. If they are inserted into an existing line, the height of the line will be increased to the size of the image. If you want to create a display with columnar format, you'll have to put the text and image into separate widgets and then place those widgets in the primary text widget.

## 10.4 Display Package

HTML is currently the most portable protocol for distributing formatted text, and the odds are good that HTML will continue to be important for the next few years. The text widget tags make it possible to use the text widget to display HTML text with little work.

Stephen Uhler wrote html_library, a library that will display HTML in a text widget. The html_library is a good example of what you can do with the text widget, so we'll look at it a bit. The HTML library is not a part of the standard Tk distribution. It is distributed as a standalone module (from ftp.sml.com /pub/tcl/html_library-0.3.tar.gz) and as part of the webt 1.0 program available from http://sunscript.sun.com/TclCore/. In the webt package, the HTML library code is in the file lib/dpackage.tcl.

### 10.4.1 Display Text

Using the html_library package to display text is very simple:

- 1. Source the html_library code.
- 2. Create a text widget to contain the displayed HTML text.
- 3. Map the text widget to pack, place, or grid.
- 4. Initialize the HTML library by calling init_win.
- 5. Display your HTML by calling parse_html.

The following example shows a text window used to display HTML and a dump of the first couple of lines.

# Example 10.4.1-1

Example Script

```
source "html_library.tcl"
text .t -height 6 -width 50
pack .t
init_win .t
```

```
set txt {
<HTML><BODY>
Test HTML
<P><B>Bold Text</B><I>Italics</I></P>
</BODY></HTML>
}
```

```
parse_html $txt
set textDump [.t dump 1.0 4.0 -all]
foreach (id data index) $textDump {
  puts "[format %8s %-5s %6s] $id $data"
}
```
