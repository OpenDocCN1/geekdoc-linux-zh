# Chapter 15. Tips and Techniques

Notice the eval in the eval exec tar -cvf $archive $flist line in the previous Unix example. If you simply used

```
# won't work
exec tar -cvf $archive $flist
```

The contents of $flist would be passed as a single argument to the exec command, which would pass them as a single argument to the tar program. Since there is no file named file1 file2.., this results in error.

The eval command concatenates all of the arguments into one string and evaluates that string. This changes the list from single argument to as many arguments as there are file names in the list.

+   * exec cd $Directory is probably not what you want.
The change directory command is part of a shell. It changes the current directory within the shell. It's not an external program. Use the built-in Tcl command cd if you want to change the working directory for your script.

# Calculating the time: Numbers in Tcl.

Numbers in Tcl can be represented in octal, decimal, or hexadecimal. The base of a number is determined by the first (or first two) digits.

If the first digit is not a 0, then the number is interpreted as a decimal number.

If the first digit is a 0 and the second character is x, then the number is interpreted as a hexadecimal number.

If the first digit is a 0 and the second digit is between 1 and 7, then the number is interpreted as an octal number.

If the first digit is a 0 and the second digit is 8 or 9, then this is an error.

In versions of Tcl without the clock command, it was common to split a time or date string and try to do calculations on the parts of the time. This would work most of the time. Note that at 08:00 the command

```
set minutes [expr [lindex [split $time ":"] 0]*60]
```

will generate an error, since 08 is not a valid octal number.
