# # Bonus Book
and Tutorials

Tcl/Tk for Real Programmers includes a bonus book! Several chapters that were originally written for a book about using Tcl/Tk in the Real World have been added to the CD-ROM.

The CD-ROM also includes several tutorials, and four reference guides.

# ## E.1 Accessing the Real World Tcl Chapters

To access these chapters simply load the CD-ROM into your CD-ROM drive, point your browser at the file index.htm on that device and follow the references.

# ## E.2 Accessing the Tutorials

The CD-ROM contains textual and HTML-based tutorials and the TclTutor package.
