# D.11 SWIG

SWIG distribution is done as a gzipped archive for Unix systems, as a self-extracting zip file for MS-Windows systems, and as a self-extracting BinHex archive for the Macintosh.

# D.11.1 Installing SWIG under MS-Windows

The SWIG distribution has been repackaged as a self-extracting zip file for this CD-ROM.

To install SWIG under MS-Windows:

+   Place the Tcl/Tk for Real Programmers CD-ROM in your CD-ROM drive. The rest of these instructions assume that this is drive D.

+   Select Start and then Run from the Windows taskbar.

+   Enter or browse to D:\devel\swig\swig11p.exe and run that program.

+   The first window will inform you that this is the SWIG installation package. Click the OK button.

+   The next window will allow you to select the destination for this installation. If you do not want the default destinations (C:\swig) enter destination path. Click the Unzip button.

+   You'll see the package is fully installed, a window will appear informing you that SWIG is installed.

+   When the process finishes, a window will appear you that 1152 files were successfully installed. Click the OK button.

+   Close the installation window.

Instructions for compiling SWIG with C++ or Borland C++ are in the file win\readme.txt under the directory you installed SWIG into.

# D.11.2 Installing SWIG under Unix

To install SWIG under Unix:

+   Mount the Tcl/Tk for Real Programmers CD-ROM.

+   Change directory to the directory where you wish to install SWIG.
