# Chapter 5. Using Lists and Arrays

type  Returns the type of a file.
Types include:

+   - file `pathName` is a normal file.

+   - directory `pathName` is a directory.

+   - link `pathName` is a link to another file.

+   - characterSpecial `pathName` is a character-oriented device.

+   - natename Returns `pathName` in the proper format for the current platform.

+   - delete Deletes the file referenced by `pathName`.

+   - exists Returns 1 if `pathName` exists, 0 if not.

+   - isdirectory Returns 1 if `pathName` is a directory, 0 if not.

+   - isfile Returns 1 if `pathName` is a regular file, 0 if not.

`pathName` The path to the directory entry with which to interact. Arguments that `subCommands` require.
