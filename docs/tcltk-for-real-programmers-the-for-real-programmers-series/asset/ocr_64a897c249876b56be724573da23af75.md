# Chapter 8. Introduction to Tk Graphics

**Syntax:** listboxName curselection

curselection

Returns a list of the indices of the currently selected items in the listbox.

**Syntax:** listboxName get first ?last?

get Returns a list of the text displayed in the range of entries identified by the indices.

first The first entry to return.

last The last entry to return. If this is not included, only the first entry is returned. The range returned is inclusive.

In the next example, some selections were made before the graphic report were created.

# Example 8.8.3-1

# Example Script

```
# Create the left listbox, defined to allow only a single
# selection
listbox .Single -selectmode single -exportselection no
grid .Single -row 1 -column 0
.Single insert "top" "middle" "bottom"
```

```
# Create the right listbox, defined to allow multiple items to
# be selected.
listbox .Multi -selectmode multiple -exportselection no
grid .Multi -row 1 -column 1
.Multi insert "MultiTop" "MultiMiddle" "MultiEnd"
```

```
# Create a button to report what's been selected
button .report -text "Report" -command "report"
grid .report -row 0 -column 0 -sticky e
```
