As a compromise between ease of use and ease of debugging, the process Options procedure returns a list of the results of the catch ... configure calls. This is a list of success and failure codes (0 or 1) in the order of the widget and options.

If processOptions is called with a list of two options and two widgets, there will be four return codes in the list: the results of widget1 -option1, widget2 -option1, widget1 -option2, and widget2 -option2. Using this list, scripts that need to know what failed or succeeded check the results, and scripts that simply need to set any valid option can ignore the return.
