# 1.9 Bottom Line

Tcl/Tk is:

+   1. A shell scripting language
2. A multiplatform language
3. An extensible interpreter
4. An embeddable interpreter
5. A graphics programming language

Tcl/Tk is useful for:

+   1. Rapid prototyping
2. Shippable product
3. GUI-based projects
4. Multiplatform products
5. Adding GUIs to existing text-oriented programs
6. Adding new functionality to old code libraries
