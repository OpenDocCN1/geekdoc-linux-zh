# D.10.4 Installing SpecTcl on a 680x0-based Macintosh

A modified version of the SpecTcl GUI builder is in the file level:spec_tcl:tcl.hq which can be unpacked into a directory with the StuffIt Expander.

+   1. Place the Tcl/Tk for Real Programmers CD-ROM in the CD-ROM drive and confirm that it creates an icon on your screen when it loads.
2. Double-click the CD-ROM icon and step through the directories to level:spec_tcl.hq.
3. Drag the spectcl.hq icon to the StuffIt Expander icon.
This will unpack the SpecTcl package into a directory on your desktop.
