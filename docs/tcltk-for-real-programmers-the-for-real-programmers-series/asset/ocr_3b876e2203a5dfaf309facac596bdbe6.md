# Appendix E. Bonus Book and Tutorials

The Perl interpreter is used for the demonstration perl lessons. The default perl interpreter can be selected from the Possible Perl interpreters pull-down menu.

The installation directories for the lessons and binary objects can be selected by typing a new path into the Tclutor Lessons Directory or Tcl Tutor Program Directory entry widget.

If you select the enable logging button, Tclutor will log when a user enters a lesson, run examples, or changes verbosity levels.

This data file can be used by an instructor to monitor a student's progress.

If you select the mail/purge log file entry, the file will be cleared and mailed every five lessons. The default mail address in the mail field is the package author (me). In this case, the data is used to determine what lessons are accessed most often, and which should be modified.

Modify these items until they match your requirements.

# E.3.3 Installing Tclutor on a Macintosh

Tclutor is packaged in a BinHex archive (tclutor::097.hqx) for the Macintosh. You can drag and drop this file to the StuffIt Expander icon to unpack it.

This version of Tclutor can be run by starting a wish session, using the Tcl cd command to change to the directory where Tclutor is installed, and then source Tclutor.
