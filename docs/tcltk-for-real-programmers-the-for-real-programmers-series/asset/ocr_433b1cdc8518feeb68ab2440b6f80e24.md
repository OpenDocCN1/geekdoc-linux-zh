# Create the image we will use for this example

set img [image create photo -data logo]

# And create and display the primary text widget

```
text .t-height 14 -width 60
pack .
```

# Insert some lines into the text

```
.t insert 1.0 \
  "\This is a line with an image in the middle of it.\"
.t insert end \
  "\As you can see it makes a large space between the\"
.t insert end \
  "\line line with the image, and line below it.\""
```
