# 9.4 More Canvas Widget Subcommands

# 9.3.1 An Example

The following example creates some simple graphic items to display a happy face.

Example 9.3.1-1

Example Script

```
# Create the canvas and display it.
canvas .c -height 140 -width 140 -background white
pack .c
# Create a nice big circle, colored gray
. create oval 7 7 133 133 -outline black -fill gray80 -width 2
# And Two little circles for eyes
. create oval 39 49 53 63 -outline black -fill black
. create oval 102 63 88 49 -outline black -fill black
# A Starfleet insignia nose
. create polygon 70 67 74 81 69 77 67 81 -fill black
# A big Happy Smile!
. create arc 21 21 119 119 -start 225 -extent 95 -style arc \
-outline black -width 3
```
