puts "SCRIPTS SITE: [findUrl Scripts $urls"

# Script Output

SCRIPTS SITE: http://www.scripts.com/
SCO SITE: http://www.sco.com/Technology/tcl/Tcl.html

In this example, we've used the -nocase switch in the tcl switch, instead of using the regex atom. This lets us call the proc with a simple string and not worry about case. When regexp finds a match, it places that line in the match variable.

The url variable is set with another regexp command that extracts a string within quotes that starts with the characters "http: from the match variable.
