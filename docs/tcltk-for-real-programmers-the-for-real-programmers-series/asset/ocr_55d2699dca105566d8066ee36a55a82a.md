# 5.5.2 Creating a New Tree

The command for creating a new tree in this package is treeCreate. It increments the counter in Tree_InternalArray(base), creates the new tree name, and sets the Tree_InternalArray(treeName.base) counter to 0, the start value for the node ID numbers. After this is done, a new node is created to be the top node in this tree, and the handle for the new node is returned.
