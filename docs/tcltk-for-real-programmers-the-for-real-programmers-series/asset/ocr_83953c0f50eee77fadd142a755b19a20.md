# # About the CD-ROM

The CD-ROM included with this book contains everything you need to start programming with Tcl/Tk:

+   - Binary Tcl/Tk distributions for Macintosh, Windows 95, Windows NT, Linux, and BSD/OS. Revisions 7.6p2, 8.0p2, 8.1a2 and 8.0.3 (new in September 1998). See Appendix B for installation instructions. To install one of these distributions, you will need 5 MB of free space.
- To install Tcl/Tk distribution on a Macintosh, you should have 16 MB of RAM (Tcl7.6 will run on an 8 MB 680x-based Macintosh).
- To install Tcl/Tk on an MS-Windows platform, you must have at least 8 MB of RAM. Tcl/Tk will run on any 386-, 486-, or Pentium-based system, but is sluggish if the clock speed is slower than 100 MHz.
- To install Tcl/Tk on a Linux or BSD/Os system, you must have at least 8 MB of RAM. To run Tcl you must have windows installed. Tcl/Tk will run on any 386-, 486-, or Pentium-based system, but is sluggish if the clock speed is slower than 100 MHz.
- Source code distributions for Tcl and Tk. Revisions 7.6p2, 8.0p2, 8.1a2 and 8.0.3 (new in September 1998) are included. See Appendix B for installation instructions.
- A bonus book of Real World Tcl application discussions. Mount the CD-ROM and point your browser to the index.htm file on the CD-ROM to find these.
- Extra Tcl Tutorials. The TclTutor CAI program and HTML-based tutorials that you can browse are included; for more information, point your browser to the index.htm file on the CD-ROM. See Appendix E for installation instructions.
