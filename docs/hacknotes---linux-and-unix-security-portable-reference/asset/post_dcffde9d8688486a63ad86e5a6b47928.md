## Allow Only Local Connections

Do not allow hosts outside the intranet to connect to MySQL services. Ensure firewall rules are preset to block such connection attempts. Authorized external users should be encouraged to use secure tunneling tools such as SSH to establish remote connections.

Although the MySQL source code can be edited to change the version information that is displayed immediately upon connect, it is likely that doing so will break MySQL clients.

## AUTOMATED BANNER-GRABBING

Netcat is a tool to read and write data across network connections using TCP or UDP. It can be used to connect to servers like the command-line telnet client. 

Netcat can be used to grab the SMTP banner in the following way:

```bash
[bash]$ nc 192.168.1.1 25
220 192.168.1.1 SMTP Sendmail 8.10.2+Sun/8.10.2; Tue,
14 Jan 2003 09:28:02 -0500 (EST)
```

With a little bit of shell programming, you can use Netcat to perform automated banner-grabbing. For example, consider the following script (let us call grab.bash):

```bash
#!/bin/bash

if [ $ -lt 1 ]
then
	echo Usage: $0 host
	exit 1
fi

i=21
```

# Chapter 3: Enumeration

```bash
while [ "$i" -lt 26 ]
do
  nc -v $1 $i < /dev/null
  i=$(expr $i + 1)
  echo
```

This script consists of a while loop for the values of the variable i from 21 to 25. Within the while loop, a connection to a host (the first parameter passed to the script, i.e., $1) is made on ports of value i (21 to 25), and /dev/null is given as input to the Netcat connection. Since /dev/null is a special file that contains nothing (null), Netcat will immediately terminate after grabbing the first line of the banner (if any).

Before attempting to execute the preceding script, execute permissions by:

```bash
[bash]$ chmod u+x ./grab.bash
```

Now run the script:

```bash
[bash]$ ./grab.bash 192.168.1.1
```

If the preceding script needs to be executed on various hosts, you can write a wrapper against your grab.bash script like this:

```bash
#!/bin/bash
for i in `cat hosts.txt`
do
  ./grab.bash $i
  echo
```

The preceding script, which could be called wrapper-grab.bash, will execute our original script grab.bash against hosts listed in the file hosts.txt. The hosts.txt file must contain hostnames or IP addresses of target hosts like this:

```
192.168.1.1
10.0.0.1
somecompanyasanexample.com
```

Though the preceding script will work with most services, recall that you need to issue a HEAD request in order to obtain a HTTP banner.
