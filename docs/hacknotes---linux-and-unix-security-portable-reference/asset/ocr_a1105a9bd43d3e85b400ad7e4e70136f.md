Change the STMP greeting message. Edit the sendmail.cf file and change the value of SmtGreetingMessage to reflect the new banner. Alternatively, you can edit sendmail.mc and change the value of confSMTP_LOGIN_MSG to the new greeting.

EXPN and VRFY are two commands supported by the SMTP protocol for username enumeration. You should turn them off by editing sendmail.cf and ensuring that PrivacyOptions is set to authwarnings, noexpn, novrfy, restrictqun. Alternatively, you can edit the sendmail.mc file and ensure the following line is present:

define('CONFPRIVACY_FLAGS', 'authwarnings, noexpn, novrfy, restrictqun')dnl

Other flags such as goaway, restrictmail, restrictqun, and nobodyturn can also be set. Please see the Sendmail documentation for details.

Use smrush as the MDA (mail delivery agent) is a program for sh; it limits the commands that can be run using the "command" syntax of Sendmail. To enable smrush, ensure the following line is present in sendmail.mc:

FEATURE('smrush', '/path/to/smrush')dnl

Make sure the following files and directories have the appropriate permissions:

| File or Directory | User | Group | Permissions |
| /etc/aliases | root | root | -rw-xr-r-- |
| /etc/mail | root | root | drxr-xr-x |
| /var/sp/mail | root | mail | drxr-xr-x |
| /var/sp/mqueue | root | mail | drxr-xr-x |

Check the contents of /etc/mail/access. This file contains hostnames that are allowed to relay through the Sendmail server. Do not place untrusted hostnames in this file. This can be done by setting the value of confMAX_MESSAGE_SIZE in sendmail.mc, for example:

define('confMAX_MESSAGE_SIZE', '1048576') dnl

Or, edit the sendmail.cf file and change the value of MaxMessageSize to the appropriate value.
