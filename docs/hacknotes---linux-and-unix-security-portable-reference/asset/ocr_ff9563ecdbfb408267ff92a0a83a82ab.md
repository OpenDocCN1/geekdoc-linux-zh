# Hacking Tools

The following table lists the most popular hacking tools used by hackers today. Most of the tools mentioned in this table are used throughout Part I of this book from which these tools can be downloaded are also provided.

| Name | Description | Location |
|---|---|---|
| Airsnort | Popular WEP cracker (802.11b) | http://airsnort.shmo.com/ |
| Adore | Backdoor | http://www.team-teso-teso/releases.php |
| Amap | Identifies remote applications | http://www.thc.org/releases.php |
| Cheops | GUI based tool that identifies TCP traffic information about hosts on a network | http://www.marko.net/cheops/ |
| Desproxy | Command-line tool that tunnels TCP traffic through web probes | http://desproxy.sourceforge.net/ |
| Dsniff | A suite of network sniffing tools | http://monkey.org/-/dungsong/dsniff/ |
| Ethereal | GUI based network sniffer | http://www.ethereal.com/ |
| Ettercap | Ncursed based network sniffer | http://ettercap.sourceforge.net/ |
| Fata-Jack | Performs Denial of Service attacks on 802.11 networks | http://www.loud-fat-bloke.com/w80211.html |
| Firewalk | A tool similar to tracer determines gateway access control lists | http://www.packetfactory.net/projects/firewall/ |
| Fragoute | Intercepts, modifies, and rewrites network traffic | http://www.monkey.org/-/dungsong/fragoute/ |
| Hping2 | Command-line TCP/IP packet assembler and analyzer | http://www.hping.org/ |
