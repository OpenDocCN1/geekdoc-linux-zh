# Allow Only Local Connections

Do not allow hosts outside the intranet to connect to MySQL services. Ensure firewall rules are preset to block such connection attempts. Authorized external users should be encouraged to use secure tunneling tools such as SSH to establish remote connections.

Although the MySQL source code can be edited to change the version information that is displayed immediately upon connect, it is likely that doing so will break MySQL clients.

# AUTOMATED BANNER-GRABBING

Netcat is a tool to read and write data across network connections using TCP or UDP. It can be used to connect to servers like the command-line telnet client

Netcat can be used to grab the SMTP banner in the following way:

```

14 Jan 2003 09:28:02 -0500 (EST)
```
