# SMTP (Simple Mail Transfer Protocol): 25 (TCP)

SMTP is a protocol used on the Internet to transfer e-mail messages.

Sniffing Since SMTP is a clear-text protocol, it is possible to capture data being sent across the network.

# Sniff SMTP Traffic

The mailnarf program, a tool that is part of the Dsniff package, can be used to capture SMTP data on a network. While mailnarf watches SMTP data on the network, it must be run on a machine that is on the same network segment as the victim.
