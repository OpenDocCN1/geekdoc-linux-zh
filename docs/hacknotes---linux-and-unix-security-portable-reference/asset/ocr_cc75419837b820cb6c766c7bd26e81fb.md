# " IN PATH

When a user executes a command, the command shell searches for the location of the command in the list of directories contained in the PATH environment variable:

```
[bash]$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/home/joe:/bin
```

Suppose the root user has the current directory (“.”) in his PATH:
:/usr/local/sbin:/usr/local/bin:/usr/bin:/bin

Now, every root user executes a command such as ls, the first looks for “ls” in the current directory, and then it searches the other directories as listed in the PATH variable.
