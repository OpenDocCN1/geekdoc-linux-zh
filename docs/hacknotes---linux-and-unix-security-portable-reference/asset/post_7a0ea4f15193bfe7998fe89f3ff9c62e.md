# DNS (Domain Name System): 53 (TCP/UDP)

DNS is a protocol used to translate between domain names and IP addresses.

# Obtain BIND Version Information

# Configure BIND to Not Display Version Information

Edit the BIND configuration file, named.conf, and override the version number:

```
options {
  version "Not available";
}
```

You might also want to configure BIND with specific ACLs and limit queries from specific hosts. See the BIND documentation for details. More information about BIND can be found at http://www.isc.org/products/BIND.

# Finger: 79 (TCP)

Finger is a user information lookup program. Fingering a remote host will provide information such as usernames, IP addresses, idle time, and real names of the individuals logged on the host at time.

# Enumerate Remote Users by the Finger Command

If the remote host is running a finger daemon, the command-line finger tool can be used to query the host:

```bash
finger @host
```

Example:

```bash
[bash]$ finger @192.168.1.1
Login Name TTY Idle When Where
bob Bob pts/1 8 Wed 14:26 bobsaddress.bobsisp.org
rob Robert Smith pts/4 51 Wed 14:36 dhcp.rhomeisp.org
tang Tang pts/3 1:08 Wed 10:07 somecaseanexample.com
```

It is also possible to finger a specific username. Querying for a specific username will yield some information about the user even if the user is not logged on at the time:

```bash
finger username@host
```

Example:

```bash
[bash]$ finger root@192.168.1.1
Login name: root In real life: Sys Admin
Directory: / Shell: /usr/local/bin/tcsh
Last login Jan 11 14:26:51 on tty2
```

# Disable Finger

If you are running the finger server, it is strongly recommended that you consider the following suggestions:

- Consider disabling the finger service if possible. It provides far too much information about your system to local users and intruders. If you use inetd, finger can be disabled by commenting out the appropriate line in `/etc/inetd.conf`. If you use xinetd, edit the file name in inetd.d directory and make the following line exists:
`disable = yes`

- You must restart inetd or inetd in order for changes to take effect. If you must run the finger server, configure your firewall to drop incoming connections to port 79. This will prevent users on external networks from querying.

# HTTP (Hypertext Transfer Protocol): 80 (TCP)

HTTP is a stateless protocol used to distribute various media. Is most widely used to serve WWW (World Wide Web) content.

# Obtain the HTTP Server Banner

In order to grab banner from HTTP servers, telnet to the port they are listening on and issue the following request:

```bash
HEAD /HTTP/1.0
```

Example:

```bash
[bash]$ telnet somecompanyexample.com 80
Trying 10.0.0.100...
Connected to somecompanyexample.com.
HEAD /HTTP/1.0
HTTP/1.1 200 OK
Date: Wed Jan 15 2003 17:59:12 GMT
Server: Apache/1.3.27 (Unix) PHP/4.2.1 mod_jk/1.2.0 mod_ssl/2.8.12 OpenSSL/0.9.6
Content-Location: index.html
Vary: Accept
Last-Modified: Thu 09 May 2002 19:47:31 GMT
Accept-Ranges: bytes
Content-Length: 267
Content-Type: text/html
Expires: Wed 15 Jan 2003 17:59:12 GMT
Connection closed by foreign.

Some web servers do not allow HEAD requests. In this case, we must perform a GET query:

```bash
GET / HTTP/1.0
```

This query will return the banner information, with the default index page (such as index.html). If you want a particular web page, say contact.html, you will need to append its name with the GET request:

```bash
GET /contact.html HTTP/1.0
```

Sometimes, a single web server can be used to serve content for multiple domain. In such cases, the specific domain name must be specified in the request. This can be done by typing "Host: domain-name" after the GET request. For example:

```bash
GET / HTTP/1.0
Host: domainname.com
```

# Change the HTTP Server Banner

If you are running Apache, edit your httpd.conf file and make sure the following directives are present:

```
ServerSignature Off
ServerTokens Prod
```

Disabling the ServerSignature instructs Apache to not print version information when an error page such as “404 Not Found” is displayed. The ServerTokens directive, when set to Prod, instructs Apache to only display “Server: Apache” in the banner. If you do not want to display “Apache” in the Server tag but to display fake information as “Server: Not-allowed,” you will need to:

1. Download the Apache source code.
2. Edit the file httpd.h and change the value of the string “Apache” in the line:
   #define SERVER_BASEPRODUCT "Apache"
   #define SERVER_BASEPRODUCT "Not-allowed"
3. Recompile, reinstall, and restart Apache.

# POP3 (Post Office Protocol 3): 110 (TCP)

POP3 is a protocol used to access e-mail from a mailbox server.

# Obtain the POP3 Server Banner

Telnet to 110 to get the POP3 server banner information:

```bash
[bash]$ telnet 10.0.1.1 110
+OK POP3 10.0.1.1 v4.39 server ready
```

# Change the POP3 Server Banner

Many POP3 servers require their source code to be edited in order to change the server banner. In these cases, you must obtain the source code to your POP3 server and search for the version string using the grep command. Once you have edited the source code to reflect the new banner information, recompile and reinstall the POP3 server. Some POP3 servers allow for banner information to be changed by editing appropriate configuration files. Please see your POP3 server documentation for details.

# Portmapper: 111 (TCP)

RPC (remote procedure call)-based services such as NIS (Network Information Service) do not listen on static ports. These services register their port numbers with the Portmapper.

# Query Portmapper for RPC Services

The Portmapper server can be queried for the RPC services registered with it using the rpcinfo tool:

```bash
rpcinfo -p hostname
```

For example:

```bash
[bash]$ rpcinfo -p 192.168.1.1
program vers port
100000 4 tcp 111 portmapper
100000 3 tcp 111 portmapper
100000 2 tcp 111 portmapper
100000 4 udp 111 portmapper
100000 3 udp 111 portmapper
100000 2 udp 111 portmapper
100024 4 udp 111
```
