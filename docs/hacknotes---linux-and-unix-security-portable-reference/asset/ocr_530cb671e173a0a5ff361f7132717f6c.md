Nessus is designed to support a client/server architecture. The Nessus server (nessusd) is in charge of performing vulnerability checks against target hosts. The Nessus client program (nessus) can be used to connect to the server to configure and spawn checks. Comunication between the Nessus client and server is encrypted.

Since the design of Nessus is very modular, it is easy to write your own security checks. Nessus security checks can be written using the C programming language or Nessus’s NASL (Nessus Attack Scripting Language). See Chapter 10 for details on NASL.
