# Do Not Use Telnet

Do not use a clear-text protocol such as telnet. Consider using SSH instead.

**Software Vulnerabilities** The telnet daemon involves a few remotely exploitable vulnerabilities. The next paragraph describes a vulnerability that was quite one of the easiest to exploit.

+   ■ Solaris in.telnet TTYPROMPT Buffer Overflow Vulnerability The version of /bin/login shipped with Solaris 2.6-2 was found to have a vulnerability involving the environment variable TTYPROMPT. In order to attack this vulnerability, the attacker would need to set the value of TTYPROMPT to a six-character string and send a string of 64 cs and the literal \ after the username and upon connect. For example, consider an attacker attempting to exploit this vulnerability by logging in as the user bin:

```
[bash] telnet
telnet> environ TTYPROMPT abdef
```
