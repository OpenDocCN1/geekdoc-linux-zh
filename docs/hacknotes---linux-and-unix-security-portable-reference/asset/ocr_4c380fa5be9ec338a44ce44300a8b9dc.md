```
openssl s_client -connect:server_ipaddress:443
```

OpenSSL is available at http://www.openssl.org.

# rexec: 513 (TCP)

The reexec command can be used to run commands on a remote host and display its output. Since reexec uses similar mechanisms as login, please see the following "login: 513 (TCP)" section.

# login: 513 (TCP)

The login command is used to establish a terminal session with a remote host.

Brute-forcing Since a username and password combination is required to authenticate with login, a brute-forcing tool such as Hydra can be used.

Sniffing The login service uses a clear-text protocol. Network sniffer tools such as Ettercap or Ethereal can be used to sniff login traffic on the network.

login Misconfigurations In order to facilitate password-less logins, a user may have to place a file .hosts in his home directory with the following contents:

```
mukumouse.somecompanyasanexample.com jack
```

This will allow user jack from mukumouse.somecompanyasanexample.com to login into his account on the host where the preceding .hosts is placed without any password.
