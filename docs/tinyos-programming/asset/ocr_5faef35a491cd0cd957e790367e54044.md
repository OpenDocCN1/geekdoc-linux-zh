This code’s first step is to note the message’s arrival time by calling the get command of the Counter<TMicro, uint32_t> interface. Counter is a hardware-independent interface for counting time. Like other other time interfaces, Counter takes type arguments which indicate the precision (millisecond (TMilli), microsecond (TMicro), etc.), and width (16-bit (uint16_t), 32-bit (uint32_t), etc.) of its time measurements:
