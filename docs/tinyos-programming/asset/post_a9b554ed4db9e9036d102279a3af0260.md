
DetectorC sets the prescaler to a value (ATM128_ADC_PRESCALE_16) that reduces A/D conversion time to 28 µs. This potentially improves SoundLocalizer’s precision by 2.9 cm (85 µs · 340 m/s).

The resulting “loud sound” detection code is simple, though very specific to the micaz platform and the mts300 microphone:

```
module DetectorC {
  uses interface Atm128AdcSingle;
  ...
}

implementation {
  // The threshold for a loud sound (determined experimentally)
  enum { THRESHOLD = 768 };

  void detect() {
    call Atm128AdcSingle.getData(... microphone A/D channel ...,
                          ATM128_ADC_VREF_OPF, FALSE,
                          ATM128_ADC_PRESCALE_16);
  }

  async event void Atm128AdcSingle.dataReady(uint16_t data, bool precise){
    /* If we’re the current ADC owner: check ADC completion events to
       see if the microphone is above the threshold */
    atomic
      if (granted)
        if (precise && data > THRESHOLD)
        {
          signal Detector.detected();
          ... post a task to release A/D converter, power off microphone
          and signal done ...
        }
        else
          detect();
      }
    ...
  }
```

The dataReady event handler checks that DetectorC currently owns the A/D converter. If so, A/D results above the threshold indicate that a loud sound was detected. If not, another A/D sample is requested.
