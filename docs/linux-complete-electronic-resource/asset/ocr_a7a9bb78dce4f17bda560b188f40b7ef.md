# # Logout Icon Tab

**Tiles Enabled**  This checkbox will enable background tiles for all Logout buttons on the Panel.

**Tile Filename (Up)**  This is the name and path of the image file you wish to use for the tile in the up position (inactive, not pressed). You may press the Browse button to search for the file. Logout button tiles must be enabled to access this option.

**Tile Filename (Down)**  This is the name and path of the image file you wish to use for the tile in the down position (active, pressed). You may press the Browse button to search for the file. Logout button tiles must be enabled to access this option.

**Border Width (Tile Only)**  This determines the width of the border around a tile. Logout button tiles must be enabled to access this option.

**Depth (Displacement When Pressed)**  This determines the depth a tile will displace when pressed. Logout button tiles must be enabled to access this option.

# # Miscellaneous Tab

**Tooltips Enabled**  This enables tooltips for items on the panel. Tooltips are pop-up help dialog boxes that appear when your cursor is over an element on the panel.

**Show Small Icons**  This will enable small icons in the Main menu.
