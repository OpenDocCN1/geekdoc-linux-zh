In order to have LILO boot Linux from OS/2's Boot Manager, you only want to install LILO on your Linux root filesystem (in the above example, `/dev/hda2`). In this case, your LILO config file should look something like the following:

```
boot = /dev/hda2
install = /boot/boot.b
compact

image = /vmlinuz
label = linux
root = /dev/hda2
vga = ask
```

Note the change in the boot line. After running `/sbin/lilo` you should be able to add the Linux partition to Boot Manager. This mechanism should work for boot loaders used by other operating systems as well.
