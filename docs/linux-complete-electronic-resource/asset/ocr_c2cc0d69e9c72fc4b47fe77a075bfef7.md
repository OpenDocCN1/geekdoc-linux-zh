# ## AUTHORS

The primary Info-ZIP authors (current semi-active members of the Zip-Bugs workgroup) are: Greg "Cave Newt" Roelofs (UnZip); Onno van der Linden (Zip); Jean-loup Gailly (compression); Mark Adder (decompression, fnZip); Christian Spieler (VMS, MS-DOS, Windows 95, NT, shared code, general Zip and UnZip integration and optimization); Mike White (Windows GUI, Windows DLLs); Kai Uwe Rommel (OS/2); Paul Knitz (Amiga, Windows 95); Chris Herborsth (BeOS, QNX, Atari); Jonathan Hudson (SMS/QDOS); Karl Daws and Sergio Monesi (Acorn RISC OS); Harald Dencer (Atari, MVS); John Bush (Solaris, Amiga); Hunter Goatley (MVS); Steve Salisburg (Windows 95, NT); Steve Miller (Windows CE GUI); Johnny Lee (MS-DOS, Windows 95, NT); and Robert Heath (Windows GUI). The author of the original unzip code upon which Info-ZIP was based is Samuel H. Smith; Carl Mascott did the first Unix port; and David P. Kirschbaum organized and led Info-ZIP in its early days with Keith Petersen hosting the original mailing list at WSMr:PlimTef2. The full list of contributors to UnZip has grown quite large: please refer to the CONTRIB file in the UnZip source distribution for a relatively complete version.
