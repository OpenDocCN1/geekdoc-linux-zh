WaveLAN device names are "eth0", "eth1", etc.

The WaveLAN card is a spread spectrum wireless LAN card. The card looks very like an Ethernet card in practice and is configured in much the same way.

You can get information on the WaveLAN card from Wavelan.com (see http://www.wavelan.com/).

# Serial NULL Modem Cable

Not all NULL modem cables are alike. Many null modem cables do little more than trick your computer into thinking all the appropriate signals are present and swap transmit and receive data. This is ok but means that you must use software flow control (XON/XOFF), which is less efficient than hardware flow control. The following cable provides the best possible signaling between machines and allows you to use hardware (RTS/CTS) flow control.
