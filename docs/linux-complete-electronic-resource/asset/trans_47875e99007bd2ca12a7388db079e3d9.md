## 常用 Linux 命令总结

| 命令 | 操作 |
| :--- | :--- |
| at | 在指定的日期/时间执行命令 |
| awk | 模式处理语言 |
| batch | 当负载允许时执行命令 |
| bc | 交互式 C 风格计算器（仅限整数） |
| cal | 打印日历 |
| calendar | 调用提醒服务 |
| cancel | 取消打印机请求 |
| cat | 连接文件并显示其内容 |
| cd | 更改当前工作目录 |
| chgrp | 更改文件的组所有权 |
| chmod | 更改文件的访问模式（权限） |
| chown | 更改文件的用户所有权 |
| clear | 清屏 |
| cmp | 比较两个文件 |
| copy | 复制目录中的文件组 |
| cp | 复制文件 |
| cpio | 归档和提取文件 |
| cron | 时钟守护进程（执行 batch 和 at 命令） |
| crontab | 按固定间隔调度命令 |
| crypt | 加密、解密文件（限制分发） |
| csh | 调用 C shell |
| csplit | 将一个文件拆分为多个文件 |
| cu | 呼叫另一个 Unix 系统 |
| cut | 从文件的每一行中截取选定的字段 |
| date | 显示当前日期（如果为 root，允许更改日期） |
| dd | 转换并复制文件 |
| df | 报告文件系统中的空闲块 |
| diff | 比较两个文本文件 |
| diff3 | 比较三个文本文件 |
| dircmp | 比较两个目录 |
| du | 报告磁盘使用情况 |
| echo | 在标准输出上回显参数 |
| ed | 面向行的编辑器 |
| egrep | grep 的“扩展”版本 |
| eject | 从驱动器弹出媒体（例如，CD-ROM） |
| expr | 求值布尔和算术表达式 |
| false | 返回非零（假）退出状态 |
| fgrep | grep 的“快速”版本 |
| file | 报告文件类型 |
| find | 查找匹配的文件并执行指定操作 |
| finger | 报告用户信息 |
| format | 格式化磁盘和盒式磁带 |
| ftp | 在远程系统之间传输文件 |
| grep | 在文件中搜索正则表达式匹配 |
| groff | 格式化文件以用于打印 |
| head | 显示文件的前几行 |
| insmod | 加载内核模块 |
| join | 显示两个文件的连接（具有公共字段的行） |
| kill | 向进程发送信号（默认情况下，终止该进程） |
| ksh | 调用 Korn shell |
| line | 读取一行（shell 脚本用法） |
| ln | 创建指向文件的链接 |
| logout | 获取登录名称 |
| lp, lpr | 向打印机发送请求 |
| lpc | 管理打印机队列 |
| lpq | 从打印队列中移除打印任务 |
| lps | 报告打印机状态 |
| ls | 列出目录内容 |
| lsmod | 列出已加载的内核模块 |
| mail | 发送和接收邮件 |
| man | 打印在线手册中的参考页 |
| mesg | 授予或拒绝接收其他用户写入消息的权限 |
| mkdir | 创建新目录 |
| mknod | 构建特殊文件 |
| more | 一次显示一页文件 |
| mount | 挂载特殊文件，或报告其状态 |
| mtools | 读取和写入 MS-DOS 或 Windows 磁盘 |
| mv | 移动（重命名）文件 |
