
## 文件

- `/etc/fstab` 文件系统表
- `/etc/mtab` 已挂载文件系统表
- `/etc/mtab~` 锁定文件
- `/etc/mtab.tmp` 临时文件

## 参见

`mount`(2), `umount`(2), `fstab`(5), `umount`(8), `swapon`(8), `nfs`(5), `mountd`(8), `nfsd`(8), `mke2fs`(8), `tune2fs`(8), `losetup`(8)

## 缺陷

损坏的文件系统可能会导致系统崩溃。

某些 Linux 文件系统不支持 `-o sync` 选项（ext2fs 在挂载时指定 `sync` 选项时，确实支持类似 BSD 的同步更新 [即按 BSD 方式]）。

`-o remount` 可能无法更改挂载参数（例如，除了 `sb` 以外的所有 ext2fs 特定参数都可以通过重新挂载进行更改，但你无法更改 *fatfs* 的 `gid` 或 `umask`）。

## 历史

`mount` 命令最早出现在 Version 6 AT&T Unix 中。

# NETSTAT(8)

## 名称

`netstat` 显示网络连接、路由表、接口统计和伪装连接。

## 摘要

```
netstat [-v[ea]oc] [--tcp|-t] [--udp|-u] [--raw|-w] [--unix|-u] [-inet|-ip] [--ax25] [--ipx] [--netrom]
netstat [-v[enc]] [-inet] [-ipx] [--netrom] [--ddp] [--ax25] [-route|-r]
netstat [-veeanic] {--interfaces | -i} [iface]
netstat [-enc] [--masquerade | -M]
netstat [-statistics] [-s]
netstat [-V] --version [-h] --help
```

## 描述

`netstat` 显示 Linux 网络子系统的相关信息。

- **（无选项）** 您可以通过列出打开的套接字来查看网络连接的状态。这是默认操作：如果您没有指定任何地址族，则会打印出所有已配置地址族的活跃套接字。使用 `-e` 可以获取一些额外信息（用户 ID）。使用 `-v` 开关可以让 `netstat` 报告内核不支持的已知地址族。`-o` 选项显示关于网络定时器的额外信息。`-a` 打印所有套接字，包括正在侦听的服务器套接字。地址族 `inet` 将显示 `raw`、`udp` 和 `tcp` 套接字。
- **`-r`、`--route`** 使用 `-r`、`--route` 选项，您可以获得与 `route -e` 使用格式相同的内核路由表。`netstat -er` 将使用 `route` 的输出格式。详情请参见 `route(8)`。
- **`-i`、`--interface` `iface`** 如果您使用 `-i`、`--interfaces` 选项，将打印所有（或指定的 `iface`）网络接口的表格。输出使用 `ifconfig -e` 格式，并在 `ifconfig(8)` 中有描述。`netstat -ei` 将打印一个表格或单个接口条目，就像 `ifconfig` 所做的那样。使用 `-a` 开关，您可以包含未配置的接口（即未设置 `UP` 标志的接口）。
- **`-M`、`--masquerade`** 也可以查看所有伪装会话的列表。使用 `-e` 开关，您可以包含更多关于序列编号和由 `FTP` 会话（`PORT` 命令）中数据重写引起的增量信息。伪装支持用于向外部世界隐藏具有非官方网络地址的主机，如 `ipfw(4)`、`ipfwadm(8)` 和 `ipfw(8)` 中所述。
- **`-s`、`--statistics`** 显示从 `/proc/net/snmp` 读取的 Linux 内核网络子系统的统计信息。

## 选项

- **`-V`、`--verbose`** 通过冗长的描述告知用户正在发生什么。特别是打印关于未配置地址族的一些有用信息。
- **`-n`、`--numeric`** 显示数值地址，而不是尝试确定符号主机名、端口或用户名。
- **`-A`、`--afamily`** 使用不同的方法设置地址族。*family* 是一个由逗号 (`', '`) 分隔的地址族关键字列表，如 `inet`、`unix`、`ipx`、`ax25`、`netrom` 和 `ddp`。这与使用长选项 `--inet`、`--unix`、`--ipx`、`--ax25`、`--netrom` 和 `--ddp` 的效果相同。
- **`-c`、`--continuous`** 这将导致 `netstat` 每秒在屏幕上连续打印选定的表格，直到您中断它。

## 输出

### 活跃的互联网连接 (TCP, UDP, RAW)

- **`Proto`** 套接字使用的协议 (`tcp`、`udp`、`raw`)。
- **`Recv-Q`** 连接到此套接字的用户程序尚未复制的字节数。
- **`Send-Q`** 远程主机尚未确认的字节数。
- **`Local Address`** 套接字的本地地址（本地主机名）和端口号。除非给出 `-n` 开关，否则套接字地址将解析为其规范主机名，端口号将转换为相应的服务名称。
- **`Foreign Address`** 套接字的远程地址（远程主机名）和端口号。与本地地址：端口类似，`-n` 开关关闭主机名和服务名称解析。
- **`State`** 套接字的状态。由于 `RAW` 没有状态，且 `UDP` 通常不使用状态，此行可能留空。通常，它可以是几个值之一：
  - *`ESTABLISHED`* 套接字已建立连接。
  - *`SYN_SENT`* 套接字正在积极尝试建立连接。
  - *`SYN_RECV`* 连接正在初始化。
  - *`FIN_WAIT1`* 套接字已关闭，连接正在关闭中。
  - *`FIN_WAIT2`* 连接已关闭，套接字正在等待远程端关闭。
  - *`TIME_WAIT`* 套接字在关闭后等待远程关闭重传。
  - *`CLOSED`* 套接字未在使用。
  - *`CLOSE_WAIT`* 远程端已关闭，等待套接字关闭。
  - *`LAST_ACK`* 远程端已关闭，套接字已关闭。正在等待确认。
  - *`LISTEN`* 套接字正在侦传入站连接。只有当设置 `-a`、`-l` 侦听开关时，才显示这些套接字。
  - *`CLOSING`* 两个套接字都已关闭，但我们尚未发送完所有数据。
  - *`UNKNOWN`* 套接字的状态未知。
- **`User`** 套接字所有者的名称或 UID。
- **`Timer`** （这部分需要撰写。）

### 活跃的 UNIX 域套接字

- **`Proto`** 套接字使用的协议（通常是 `unix`）。
- **`RefCnt`** 引用计数（即通过此套接字附加的进程）。
- **`Flags`** 显示的标志为 `SO_ACCEPTON`（显示为 `ACC`）、`SO_WAITDATA`（`W`）或 `SO_NOSPACE`（`N`）。`SO_ACCEPTON` 用于未连接套接字，当其对应进程正在等待连接请求时。其他标志通常不感兴趣。
- **`Type`** 有几种套接字访问类型：
  - `SOCK_DGRAM` 套接字以数据报（无连接）模式使用。
  - `SOCK_STREAM` 这是一个流（连接）套接字。
  - `SOCK_RAW` 套接字作为原始套接字使用。
  - `SOCK_RDM` 此套接字用于可靠传递的消息。
  - `SOCK_SEQPACKET` 这是一个顺序包套接字。
  - `SOCK_PACKET` 原始接口访问套接字。
  - `UNKNOWN` 谁知道未来会给我们带来什么——只需在此处填写 :-)
- **`State`** 此字段将包含以下关键字之一：
  - `FREE` 套接字未分配
  - `LISTENING` 套接字正在侦听连接请求。只有当设置 `-a`、`-listen-ing` 开关时，才显示这些套接字。
  - `CONNECTING` 套接字即将建立连接。
  - `CONNECTED` 套接字已连接。
  - `DISCONNECTING` 套接字正在断开连接。
  - *(空)* 套接字未连接到另一个套接字。
  - `UNKNOWN` 此状态不应发生。
- **`Path`** 这显示了套接字对应进程附加的路径名。
- **`Active IPX sockets`** （这部分需要由了解相关细节的人完成。）
- **`Active NET/ROM sockets`** （这部分需要由了解相关细节的人完成。）
- **`Active AX.25 sockets`** （这部分需要由了解相关细节的人完成。）

## 文件

- `/etc/services` 服务转换文件。
- `/proc/net/dev` 设备信息。
- `/proc/net/snmp` 网络统计信息。
- `/proc/net/raw` RAW 套接字信息。
- `/proc/net/tcp` TCP 套接字信息。
- `/proc/net/udp` UDP 套接字信息。
- `/proc/net/unix` Unix 域套接字信息。
- `/proc/net/ipx` IPX 套接字信息。
- `/proc/net/ax25` AX25 套接字信息。
- `/proc/net/appletalk` DDP (appletalk) 套接字信息。
- `/proc/net/nr` NET/ROM 套接字信息。
- `/proc/net/route` 内核 IP 路由信息。
- `/proc/net/ax25_route` 内核 AX25 路由信息。
- `/proc/net/ipx_route` 内核 IPX 路由信息。
- `/proc/net/nr_nodes` 内核 NET/ROM 节点列表。
- `/proc/net/nr_neigh` 内核 NET/ROM 邻居。
- `/proc/net/ip_masquerade` 内核伪装连接。

## 参见

`route(8)`, `ifconfig(8)`, `ipfw(4)`, `ipfw(8)`, `ipfwadm(8)`

## 缺陷

偶尔，如果在查看时套接字发生变化，可能会出现奇怪的信息。这种情况发生的可能性很小。`netstat -i` 选项的描述基于 nettools 软件包 BETA 版本代码清理后应如何工作的假设。
