# ## Multimedia Applets

# ### Keyboard Bell

The Keyboard Bell capplet (see Figure 15.34) allows you to change the bell sound that is produced by your CPU speaker when a keyboard error or message is sent.

+   - **Volume** Changes the actual volume of the bell.
+   - **Pitch Slider** Changes the pitch of the note that is played. By default it is set to 440Hz or the A above middle C.
+   - **Duration** Changes the length of time the tone is played.
+   - **Test** Allows you to hear the current settings of your keyboard bell.
