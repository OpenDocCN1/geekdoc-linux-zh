# ## BOOKS ON CULTURE, HISTORY, AND PRAGMATICS

The New Hacker's Dictionary (Third Edition) Raymond, Eric S. MIT Press, 1996. ISBN 0-262-68092-0. 547 pages.  See `http://www-mitpress.mit.edu/book-home .tcl?isbn=0262680920`.

Um, er. A guide to Internet culture. Lots of people like it. An HTML version is available at the Jargon File Resource Page (`http://www .tuxedo .org` ).

A Quarter Century of Unix Salus, Peter H. Addison-Wesley, 1994. ISBN 0-201-54777-5. 256 pages. See `http://www.awl .com/cp/authors/salus/unix/unix.html` .

Linux is part of the Unix tradition. This book is an oral history of Unix—how it originated, how it evolved, how it spread—by the people who were there.

The Mythical Man Month (Anniversary Edition) Brooks, Frederick P. Addison-Wesley, 1995. ISBN 0-201-83595-9. See `http://heg-school .awl .com/cseng/authors/ brooks/mmm-ae/mmm-ae.html` .

The one book on software engineering that everyone should read.
