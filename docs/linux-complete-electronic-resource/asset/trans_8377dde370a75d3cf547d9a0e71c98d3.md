### 警告

探测使用启发式方法（通过检测是否存在合适的“魔数”），因此可能会识别出错误的文件系统类型。

可以在逗号分隔的列表中指定多种类型。在文件系统类型列表前添加**no**前缀，可以指定不应执行任何操作的文件系统类型。（使用 **-a** 选项时，这种用法可能具有实际意义。）

例如，命令

```
mount -a -t nomdos,ext
```

将挂载除 *msdos* 和 *ext* 类型之外的所有文件系统。

- **-o**
  选项通过 **-o** 标志后跟一个逗号分隔的选项字符串来指定。其中一些选项仅在出现在 */etc/fstab* 文件中时才有用。以下选项适用于任何正在挂载的文件系统：

  - *async*：对文件系统的读写操作应异步进行。
  - *atime*：每次访问时更新 inode 的访问时间。这是默认设置。
  - *auto*：可以使用 **-a** 选项进行挂载。
  - *defaults*：使用默认选项：**rw**、**suid**、**dev**、**exec**、**auto**、**nouser** 和 **async**。
  - *dev*：解释文件系统上的字符或块特殊设备。
  - *exec*：允许执行二进制文件。
  - *noatime*：不更新该文件系统上的 inode 访问时间（例如，为了加快新闻服务器的访问速度，可以加速新闻邮箱的访问）。
  - *noauto*：只能显式挂载（即 **-a** 选项不会导致挂载该文件系统）。
  - *nodev*：不解释文件系统上的字符或块特殊设备。
  - *noexec*：不允许在挂载的文件系统上执行任何二进制文件。此选项对于拥有包含其他架构二进制文件的文件系统的服务器可能很有用。
  - *nosuid*：不允许设置用户标识符或组标识符位生效。
  - *nouser*：禁止普通（即非 root）用户挂载文件系统。这是默认设置。
  - *remount*：尝试重新挂载已挂载的文件系统。这通常用于更改文件系统的挂载标志，尤其是将只读文件系统变为可写。
  - *ro*：以只读方式挂载文件系统。
  - *rw*：以读写方式挂载文件系统。
  - *suid*：允许设置用户标识符或组标识符位生效。
  - *sync*：对文件系统的读写操作应同步进行。
  - *user*：允许普通用户挂载文件系统。此选项隐含了 **noexec**、**nosuid** 和 **nodev** 选项（除非被后续选项覆盖，如选项行 **user,exec,dev,suid**）。

## 文件系统特定挂载选项

以下选项仅适用于某些文件系统。我们按文件系统对其进行分类。它们都跟在 **-o** 标志之后。

### AFFS 的挂载选项

- **uid=value** 和 **gid=value**：设置文件系统根目录的所有者和组（默认：**uid=gid=0**，但如果选项 uid 或 gid 未指定值，则取当前进程的 uid 和 gid）。
- **setuid=value** 和 **setgid=value**：设置所有文件的所有者和组。
- **mode=value**：将所有文件的模式设置为 value & 0777，忽略原始权限。为具有读权限的目录添加搜索权限。值以八进制表示。
- **protect**：不允许更改文件系统上的保护位。
- **usemp**：在首次同步或卸载时，将文件系统根目录的 uid 和 gid 设置为挂载点的 uid 和 gid，然后清除此选项。有点奇怪...
- **verbose**：为每个成功的挂载打印一条信息消息。
- **prefix**=*string*：在跟随链接时，卷名前使用的前缀。
- **volume**=*string*：在跟随符号链接时，`/` 前使用的前缀（长度最多为 30）。
- **reserved**=*value*：（默认：2。）设备开头处未使用的块数。
- **root**=*value*：显式指定根块的位置。
- **bs**=*value*：指定块大小。允许的值是 512、1024、2048、4096。
- **grpquota / noquota / quota / usrquota**：接受这些选项但忽略它们。

### COHERENT 的挂载选项

无。

### EXT2 的挂载选项

无。注意 ‘ext’ 文件系统已过时。不要使用它。自 Linux 2.1.21 版本起，extfs 不再包含在内核源代码中。

### EXT2 的挂载选项

‘ext2’ 文件系统是标准的 Linux 文件系统。由于内核中的一个 bug，它可能会使用随机的挂载选项进行挂载（已在 Linux 2.0.4 中修复）。

- **bsddf / minixdf**：设置 *statfs*() 系统调用的行为。

*minixdf* 行为是在 *f_bfree* 字段中返回文件系统的总块数，而 **bsddf** 行为（这是默认值）是减去 ext2 文件系统使用的开销块，这些块无法用于文件存储。因此

```
% mount /k - o minixdf; df /k; mount /k
Filesystem 1024-blocks Used Available Capacity Mounted on
/dev/sda6 2630655 86954 2412169 3% /k
% mount /k - o bsddf; df /k; mount /k
Filesystem 1024-blocks Used Available Capacity Mounted on
/dev/sda6 2543714 13 2412169 0% /k
```

![](img/a3584dae761d2e3abed8bf40d7637389_871_0.png)

### 说明

> 此示例表明，可以将命令行选项添加到 /etc/fstab 中给出的选项中。

- **check / check=normal / check=strict**：设置检查级别。当设置这些选项中的至少一个时（并且默认设置 **check=normal**），挂载时会检查 inode 和块位图（在大磁盘上可能需要半分钟左右）。严格检查时，块释放检查要释放的块是否位于数据区。
- **check=none / nocheck**：不进行任何检查。
- **debug**：每次（重新）挂载时打印调试信息。
- **errors=continue / errors=remount-ro / errors=panic**：定义遇到错误时的行为。（要么忽略错误并仅标记文件系统有错误并继续，要么以只读方式重新挂载文件系统，要么引起恐慌并停止系统。）默认值在文件系统超级块中设置，可以使用 **tune2fs**(8) 更改。
- **grp**id 或 **bsdgroups** / **nogrp**id 或 **svfgroups**：这些选项定义新创建文件获得的组 id。当设置 **grp**id 时，它取创建所在目录的组 id；否则（默认）取当前进程的 fsuid，除非目录设置了 setgid 位，在这种情况下，它取父目录的 gid，并且如果它本身是一个目录，也设置 setgid 位。
- **resgid**=*n* 和 **resuid**=*n*：ext2 文件系统预留了可用空间的特定百分比（默认 5%，见 **mke2fs**(8) 和 tune2fs(8)）。这些选项确定谁可以使用预留的块。（大致来说：具有指定 uid 的人，或属于指定组的成员。）
- **sb=n**：使用块 n 作为超级块，而不是块 1。当文件系统损坏时这可能很有用。通常，每 8192 个块就会找到一个超级块的副本：在块 1、8193、16385...（因此，在大型文件系统中会得到数百甚至数千个超级块副本。我不知道 mke2fs 有哪个选项会导致写入较少的副本。）
- **grpquota / noquota / quota / usrquota**：接受这些选项但忽略它们。

### FAT 的挂载选项

![](img/a3584dae761d2e3abed8bf40d7637389_872_0.png)

> **说明**  
> *FAT 不是一个独立的文件系统，而是 msdos、umsdos 和 vfat 文件系统的通用部分。*

- **blocksize=512 / blocksize=1024**：设置块大小（默认 512）。
- **uid=value** 和 **gid=value**：设置所有文件的所有者和组。（默认：当前进程的 uid 和 gid。）
- **umask=value**：设置 umask（权限位图中*不*存在的位的位掩码）。默认是当前进程的 umask。值以八进制表示。
- **check=value**：可以选择三种不同的严格程度：
  - **r**elaxed：接受大写字母和小写字母，并且它们是等效的；长名称部分会被截断（例如 verylongname.foo-bar 变为 *verylong*.foo）；每个名称部分（名称和扩展名）中接受前导和嵌入式空格。
  - **n**ormal：类似于“relaxed”，但拒绝许多特殊字符（*、?、<、空格等）。这是默认设置。
  - **s**trict：类似于“normal”，但名称不能包含长部分，并且拒绝有时在 Linux 上使用但 MS-DOS 不接受的特殊字符。(*、+、=、空格等)
