# # THE GNOME FILE MANAGER

GNOME includes a file manager that allows you to manipulate the files on your system in a comfortable, powerful, graphical environment. This file manager is known as GMC for GNU Midnight Commander. GMC is based on the Midnight Commander file manager which can be run in a terminal.

Midnight Commander has long been known for its power and ease of use. GMC has taken that power and ease of use from MC and added the GNOME graphical front end.

As mentioned in the previous chapter, the GNOME File Manager (see Figure 15.11) provides the desktop functionality for GNOME. The GNOME File Manager also provides a place to manipulate files on your system by using the GNOME File Manager window.

![](bbox=[0.12, 0.34, 0.9, 0.81])

**FIGURE 15.11:** GNU Midnight Commander—the GNOME File Manager

There are two main windows within the GNOME File Manager. On the left is the tree view which represents all of the directories on your system by their hierarchical position. On the right is the directory window which will show you the contents of the directory that you have selected in the tree view.
