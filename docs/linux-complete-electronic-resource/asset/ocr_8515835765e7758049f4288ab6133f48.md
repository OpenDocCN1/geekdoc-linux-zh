+   1. **file *name*** Reads options from *file* *name* (the format is described below). The file must be readable by the user who has invoked pppd.

+   2. **lock** Specifies that pppd should create a UUCP-style lock file for the serial device to ensure exclusive access to the device.

+   3. **mru *n*** Sets the MRU [Maximum Receive Unit] value to *n*. Pppd will ask the peer to send packets of no more than *n* bytes. The minimum MRU value is 128. The default MRU value is 1500. A value of 296 is recommended for slow links (40 bytes for TCP/IP header + 256 bytes of data).

+   4. **mtu *n*** Sets the MTU [Maximum Transmit Unit] value to *n*. Unless the peer requests a smaller value via MRU negotiation, pppd will request that the kernel networking code send data packets of no more than *n* bytes through the PPP network interface.

+   5. **passive** Enables the “passive” option in the LCP. With this option, pppd will attempt to initiate a connection; if no reply is received from the peer, pppd will then just wait passively for a valid LCP packet from the peer, instead of exiting, as it would without this option.

# OPTIONS

<*local_IP_address*>>:<*remote_IP_address*>	Set the local and/or remote interface IP addresses. Either one may be omitted. The IP addresses can be specified with a host name or in decimal dot notation (e.g. 150.234.56.78). The default local address is the (first) IP address of the system (unless the *noipdefault* option is given). The remote address thus be obtained from the peer if not specified in any option. Thus, in simple cases, this option is not required. If a local and/or remote IP address is specified with this option, pppd will not accept a different value from the peer in the IPCP negotiation, unless the *ipcp-accept-local* and/or *ipcp-accept-remote* options are given, respectively.
