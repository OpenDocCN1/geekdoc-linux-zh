+   - **Ctrl+Tab or Ctrl+Shift+Tab** Cycle through your desktops

+   - **Alt+F2** Command line

+   - **Alt+F3** Window Menu

+   - **Alt+F4** Close the current window

+   - **Ctrl+F1-F8** Switch to a specific desktop

+   - **Ctrl+Alt+Esc** Window destroyer (every window you click will be destroyed)

+   - **Ctrl+Alt+Backspace** This exits KDE (without saving!); use this as a last resort

+   - **Ctrl+Alt+Numpad +** Cycles to the next screen resolution

+   - **Ctrl+Alt+Numpad −** Cycles to the previous screen resolution

# ## Mouse Techniques

+   - **Click the border or the titlebar** Left: Activates and raises the window, Middle: Activates and lowers the window, Right: Shows window menu if the window is active, activates it otherwise.

+   - **Double-click the window title** Maximizes the window

+   - **Drag the titlebar** Moves the window around

+   - **Drag corners or edges** Resizes the window

+   - **Alt+Left button** Moves the window around

+   - **Alt+Middle button** Raises the window

+   - **Alt+Right button** Resizes the window

+   - **Click the Icon on the top left** Window Menu

+   - **Click the Sticky Button** Toggles sticky

+   - **Click Maximize** Left: Maximizes the window, Middle: Maximizes only vertically, Right: Maximizes horizontally

+   - **Click Close** Closes the window, program asks you whether to save your work or not.
