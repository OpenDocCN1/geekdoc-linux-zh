# # Chapter 14
## IP CHAINS

L **inux's** packet firewalling capabilities will be essential if your Linux machine is connected to a dedicated Internet connection like a cable modem, DSL line, or the ether-net in a connected office environment. For such an application, you should almost certainly be using the latest 2.2. *x* Linux ker-nel, which includes the “ipchains” packet filtering system.

This document aims to describe how to obtain, install, and configure the enhanced IP firewalling chains software for Linux, as well as some ideas on how you might use them.

This document is reprinted from the Linux IPCHAINS HOWTO, version 1.0.6, of Jan 18, 1999 by Paul Russell <Paul.Russell@rustcorp.com.au>
