# ## Chapter 7

# ### Networking Overview

This chapter provides a complete overview of Linux’s networking capabilities. Each feature or available package is briefly described and pointers to more information, as well as the tools themselves, are given.

You can use this chapter as a reference each time you have a new networking-related problem to solve. So many people use Linux these days that someone is bound to have had the same problem already, and, thanks to the spirit of the Linux community, it’s quite likely that they’ve shared their solution with everyone. If so, it’ll probably be described here.

> “Networking Overview” is reprinted from the Linux Networking Overview HOWTO, version 0.2 of 10 July 1998, by Daniel López Ridruejo.
