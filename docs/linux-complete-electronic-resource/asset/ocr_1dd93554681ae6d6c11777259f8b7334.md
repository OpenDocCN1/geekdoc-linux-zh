+       - recommended

# **NOTE**

+   5.  After compiling the kernel, you should compile and install the modules:

+   6.  Then you should add a few lines to your */etc/rc.d/rc.local* file (or any file you think is appropriate) to load the required modules, which reside in */lib/modules/2.0.x/ipv4/*, automatically during each reboot:
+   
+   `/sbin/depmod -a`
+   `/sbin/modprobe ip_masq_ftp`
+   `/sbin/modprobe ip_masq_audiod`
+   `/sbin/modprobe ip_masq IRC`
