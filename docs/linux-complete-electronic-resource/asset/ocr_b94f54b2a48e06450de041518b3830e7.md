# # Linux COMPLETE

*Linux Complete* is a one-of-a-kind computer book—valuable both for its broad content and its low price. This book contains the essentials you need to know about using the world's most popular free operating system. *Linux Complete* is a collection of documents written by the Linux Documentation Project (LDP), a collaboration of hard-core Linux enthusiasts, including developers, working to provide comprehensive, reliable, and up-to-date Linux documentation.

With *Linux Complete*, you'll learn how to get the most out of Linux—from installing and creating your own network, to connecting to remote computers and the Internet.

Learn how to turn Linux into a desktop-friendly operating system with GNOME and KDE graphical desktops. *Linux Complete* also shows you how to provide access to your own Web site. Keep hacks out of your local and network machines, and print seamlessly.

As you become more proficient with Linux, you'll find the Linux *Command Reference*, *Linux Reading List*, and *Linux HOWTOs* invaluable daily tools. These comprehensive references quickly put all the information and resources you need at your fingertips.
