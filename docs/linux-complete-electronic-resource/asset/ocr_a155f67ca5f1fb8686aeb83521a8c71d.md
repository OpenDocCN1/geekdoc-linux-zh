# ## Time fields

+   - %k\nHour ( 0..23 )

+   - %l\nHour ( 1..12 )

+   - %M\nMinute ( 00..59 )

+   - %p\nLocale's AM or PM

+   - %r\nTime, 12-hour (hh:mm:ss [AP]M)

+   - %s\nSeconds since 1970-01-01 00:00:00 UTC (a nonstandard extension)

+   - %S\nSecond ( 00..61 )

+   - %T\nTime, 24-hour (hh:mm:ss)

+   - %X\nLocale's time representation (%H:%M:%S)

+   - %Z\nTime zone (e.g., EDT), or nothing if no time zone is determinable

# ## Date fields

+   - %a\nLocale's abbreviated weekday name (Sun..Sat)

+   - %A\nLocale's full weekday name, variable length (Sunday..Saturday)

+   - %b\nLocale's abbreviated month name (Jan..Dec)

+   - %B\nLocale's full month name, variable length (January..December)

+   - %c\nLocale's date and time (Sat Nov 04 12:02:35 EST 1989)

+   - %d\nDay of month ( 01..31 )

+   - %D\nDate (mm/dd/yy)

+   - %h\nSame as %b

+   - %j\nDay of year ( 001..366 )

+   - %m\nMonth ( 01..12 )

+   - %U\nWeek number of year with Sunday as first day of week (00..53)

+   - %w\nDay of week ( 0..6 ) with 0 corresponding to Sunday
