# Getting Help

Help is available basically everywhere. On the desktop, just use the right mouse button and choose Help On Desktop. On the KDE panel, open the application menu and choose Help. Every KDE program has a help menu. Every help is HTML-based, so using the help system is as easy as using your favorite Web browser!
