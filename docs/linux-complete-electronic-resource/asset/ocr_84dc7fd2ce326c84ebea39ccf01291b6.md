选项此选项卡允许你更改文件的处理选项。你可以定义如何打开、查看和编辑文件。如果你需要在终端窗口中打开它，你可以选择需要终端运行复选框。

# **注意**

如果你从桌面上的图标打开属性对话框，你可以更改该文件的图标在选项选项卡中。

权限此选项卡允许你更改文件的权限和所有权，如果你有权这样做。你可以为用户、组和其他人选择读、写和执行权限。你还可以定义谁拥有该文件，使用UID、GID和粘滞位。

# 更改文件管理器的偏好设置

你可以为GNOME文件管理器配置许多设置。这些设置可以从GMC偏好设置对话框中访问。通过从编辑菜单中选择偏好设置，你可以启动此对话框。
