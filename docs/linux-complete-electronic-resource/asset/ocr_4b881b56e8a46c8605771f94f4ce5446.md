# ## Starting PPP at the Server End

While the pp-on-dialer script is fine for servers that automatically start pppd at the server end once you have logged in, some servers require that you explicitly start PPP on the server.

If you need to issue a command to start up PPP on the server, *you do* need to edit the pp-on-dialer script.
