# Using ipchains-save

Setting up firewall chains just the way you want them and then trying to remember the commands you used so you can do them next time is a pain.

So, ipchains-save is a script which reads your current chains setup and saves it to a file. For the moment I'll keep you in suspense with regards to what ipchains-restore does.

ipchains-save can save a single chain or all chains (if no chain name is specified). The only option currently permitted is -v that prints the rules (to stderr) as they are saved. The policy of the chain is also saved for input, output, and forward chains.

```
$ ipchains-save > my_firewall
Saving 'input'.
Saving 'output'.
Saving 'forward'.
Saving 'ppp-in'.
Saving 'ppp-out'.
$ 
```
