# ## Summary of Common Linux Commands *(continued)*

| COMMAND | ACTION |
| :--- | :--- |
| test | Test various expressions and files |
| time | Display elapsed time (execution, process, and system times) for a command |
| touch | Update time/date stamps on files |
| tr | Substitute sets of characters |
| true | Return zero (true) exit status |
| tset | Set terminal modes |
| tty | Report name of terminal |
| umask | Set file-creation mode (permissions) mask |
| umount | Unmount a device |
| uname | Display a name of current system |
| uniq | Report any duplicate lines in a file |
| uptime | Report system activity |
| uucp | Copy files between two Unix systems |
| uulog | Report on UUCP status |
| uname | List UUCP sites known to this site |
| uudecode | Decode to binary after uuenocode transmission |
| uuenocode | Encode binary file for email transmission |
| ustat | Report status for or cancel UUCP jobs |
| uupick | Receive public files sent via uuto |
| uuto | Send public files to another Unix system |
| ux | Execute command on remote Unix system |
| vi | A screen-oriented (visual) text editor |
| wall | Sends a message to all users (root) |
| wait | Await completion of background processes |
| wc | Count characters, words, or lines in one or more files |
| who | Report active users |
| whois | Search for user information |
| write | Send message for another user (see *msg*) |
