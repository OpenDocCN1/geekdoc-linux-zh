their login, *slogin* is executed. The *slogin* then searches its configuration file `/etc/s1ip.hosts` for an entry with a login name that matches that of the caller. If it locates one, it configures the line as an 8-bit clean line, and uses an *ioctl* call to convert the line discipline to SLIP. When this process is complete, the last stage of configuration takes place, where *slogin* invokes a shell script that configures the SLIP interface with the relevant IP address, netmask, and sets appropriate routing in place. This script is usually called `/etc/s1ip.login`, but in a similar manner to *getty*, if you have certain callers who require special initialization, then you can create configuration scripts called `/etc/s1ip.login.loginname` that will be run instead of the default specifically for them.

There are either three or four files that you need to configure to get *slogin* working for you. I will detail how and where to get the software and how each is configured in detail. The files are:

+   - `/etc/passwd`, for the dial-in user accounts.
+   - `/etc/s1ip.hosts`, to contain the information unique to each dial-in user.
+   - `/etc/s1ip.login`, which manages the configuration of the routing that needs to be performed for the user.
+   - `/etc/s1ip.tty`, which is required only if you are configuring your server for *dynamic address allocation* and contains a table of addresses to allocate
+   - `/etc/s1ip.logout`, which contains commands to clean up after the user has hung up or logged out.

# Where to Get slogin

You may already have the *slogin* package installed as part of your distribution, but if not then *slogin* can be obtained from: MetaLab.unc.edu (see `ftp://Metalab.unc.edu/pub/linux/system/Network/serial/s1login-2.1.1.tar.gz`). The tar file contains both source, precompiled binaries, and a *man* page.

To ensure that only authorized users will be able to run *slogin* program, you should add an entry to your `/etc/group` file similar to the following:

```
s1ip::13:radio,fred
```
