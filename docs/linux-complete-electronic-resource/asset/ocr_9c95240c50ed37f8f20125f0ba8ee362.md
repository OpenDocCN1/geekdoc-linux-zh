# ## I Want to Translate This HOWTO into Another Language. What Should I Do?

Make sure the lanuage you want to translate to is not already covered by someone else. A list of available HOWTO translations is available at the Linux IP Masquerade Resource (http://ipmasq . cjb . net/ ).
