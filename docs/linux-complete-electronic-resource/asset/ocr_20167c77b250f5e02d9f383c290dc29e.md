# Requirements for Using IP Masquerade on Linux 2.0.x

The requirements for using IP Masquerade on Linux 2.0.x are as follows:

+   - Kernel 2.0.x source, available from http://www.kernel.org/. (Most of the modern Linux distributions, such as Red Hat 5.2, have a modular kernel with all IP Masquerade kernel options compiled. In such cases, there is no need to compile again. If you are upgrading your kernel, then you should be aware of what you need, mentioned later in the HOWTO.)

+   - Loadable kernel modules, preferably 2.0.0 or newer, available from http://www.pi.se/blox/modules/modules-2.0.0.tar.gz (modules-1.3.57 is the minimal requirement.)

+   - A well set up TCP/IP network, covered in Linux NET-3 HOWTO (see Chapter 8) and the Network Administrator's Guide (http://metalab.unc.edu/mdw/LDP/nag/nag.html). Also check out the Trinity OS Doc (http://www.ecst.csumicho.edu/~dranch/LINUX/TrinityOS.wri), a very comprehensive guide on Linux networking.

+   - Connectivity to the Internet for your Linux host, covered in Linux ISP Hookup HOWTO (http://metalab.unc.edu/mdw/HOWTO/HOWTO-Hostup-ISITO.html), Linux PPP HOWTO (see Chapter 9), Linux DHCP mini-HOWTO (see Chapter 11), and Linux Cable Modem mini-HOWTO (see Chapter 10).

+   - Ipfwadm 2.3 or newer, available from ftp://ftp.xos.nl/pub/linux/iptfadm/iptfadm-2.3.tar.gz. More information on version requirements is on the Linux Iptfwadm page http://www.xos.nl/linux/iptfadm/.

You can optionally apply some IP Masquerade patches to enable other functionality. More information is available at the IP Masquerade Resource at http://ipmasq.cjb.net/. (These patches apply to all 2.0.x kernels.)
