# LPD(8)

## 名称

**l**pd 行式打印机缓冲守护进程。

## 概要

**l**pd [-1] [端口号]

## 描述

**l**pd 是行式打印机守护进程（缓冲区处理器），通常在系统启动时由 rc(8) 文件调用。它会对 printcap(5) 文件进行单次遍历，以了解现有打印机的情况，并打印在崩溃后遗留的任何文件。然后，它使用系统调用 listen(2) 和 accept(2) 来接收打印队列中文件的请求、将文件传输到缓冲区域、显示队列或从队列中删除作业。在每种情况下，它都会派生一个子进程来处理请求，以便父进程可以继续监听更多请求。

## 选项

- * 端口号 用于与其他进程汇合的互联网端口号通常通过 getserbyname(3) 获取，但可以通过端口号参数进行更改。

访问控制通过两种手段提供。首先，所有请求必须来自 /etc/hosts.equiv 或 /etc/hosts.lpd 文件中列出的机器之一。其次，如果在被访问打印机的 printcap 条目中指定了 rs 能力，则 lpr 请求仅会被授予在该打印机所在机器上拥有账户的用户。

每个缓冲目录中的 minfree 文件包含需要保留的空闲磁盘块数，以防止行式打印机队列完全占满磁盘。minfree 文件可以用您喜欢的文本编辑器编辑。

守护进程在成功设置独占访问锁（稍后描述）之后开始处理文件，并扫描以 cf 开头的缓冲目录中的文件。每个 cf 文件中的行指定要打印的文件或要执行的非打印操作。每行这样的行都以一个键字符开头，指定如何处理该行的其余部分。

- J 作业名称。用于突发页面上的作业名称的字符串。
- C 分类。用于突发页面上的分类行的字符串。
- L 字面量。该行包含来自密码文件的标识信息，并导致打印横幅页。
- T 标题。用作 pr(1) 标题的字符串。
- H 主机名。调用 lpr 的机器名称。
- P 人员。调用 lpr 的人员的登录名。这用于 lprm 验证所有权。
- M 当当前打印作业完成时，向指定用户发送电子邮件。
- f 格式文件。要打印的已格式化文件的名称。
- 1 类似于"f"，但传递控制字符并且不产生换页。
- p 使用 pr(1) 作为过滤器进行打印的文件名称。
- t Troff 文件。该文件包含 troff(1) 输出（照排机命令）。
- n Ditroff 文件。该文件包含设备无关的 troff 输出。
- r DVI 文件。该文件包含来自斯坦福大学的 TeX i 输出 DVI 格式。
- g 图形文件。该文件包含由 **plot**(3) 生成的数据。
- c Cipplot 文件。该文件包含由 *cipplot* 生成的数据。
- v 该文件包含光栅图像。
- r 该文件包含带有 FORTRAN 回车控制字符的文本数据。
- 1 Troff 字体 R。用于替代默认字体的字体文件名称。
- 2 Troff 字体 I。用于替代默认字体的字体文件名称。
- 3 Troff 字体 B。用于替代默认字体的字体文件名称。
- 4 Troff 字体 S。用于替代默认字体的字体文件名称。
- W 宽度。更改 `pr`(1) 和文本过滤器使用的页面宽度（以字符计）。
- I 缩进。要缩进的字符数（以 ASCII 计）。
- U 解除链接。打印完成后要删除的文件名称。
- N 文件名。正在打印的文件的名称，或者当 `lpr`(1) 在管道中调用时为标准的输入的空白。

如果文件无法打开，将通过 `syslog`(3) 使用 `LOG_LPR` 设施记录消息。**Lpd** 将尝试最多 20 次重新打开它预期存在的文件，之后将跳过要打印的文件。

**Lpd** 使用 `flock`(2) 提供对锁文件的独占访问，并防止多个守护进程同时激活。如果守护进程被杀死或意外终止，无需删除锁文件。锁文件以可读的 ASCII 格式保存，包含两行。第一行是守护进程的进程 ID，第二行是当前正在打印作业的当前作业控制文件名。第二行更新为反映 **lpdf** 的状态，供程序 **lpq(1)** 和 **lprm(1)** 使用。

## 文件

- /etc/printcap 打印机描述文件
- /var/spool/* 缓冲目录
- /var/spool/*/minfree 保留的最小可用空间
- /dev/lp* 行式打印机设备
- /dev/printer 本地请求套接字
- /etc/hosts.equiv 列出允许打印机访问的机器名称
- /etc/hosts.lpd 列出允许打印机访问的机器名称，但不受同一管理控制。

# MKE2FS(8)

## 名称

**mke2fs** 创建 Linux 第二扩展文件系统。

## 概要

```
mke2fs [-c | -l 文件名] [-b 块大小] [-f 碎片大小]
		[-i 每inode字节数] [-m 保留块百分比]
		[{-o 创建者操作系统}|-q] [-r 文件系统修订级别] [-R raid_选项]
		[-s 稀疏超级块标志] [-v] [-F] [ -L 卷标签]
		[-M 最后挂载目录] [-S] 设备 [块数]
```

## 描述

**mke2fs** 用于在设备（通常是磁盘分区）上创建 Linux 第二扩展文件系统。

*设备* 是对应设备的特殊文件（例如 /dev/hdXX）。

*块数* 是设备上的块数。如果省略，**mke2fs** 将自动计算文件系统的大小。

## 选项

- **-b 块大小** 指定块的大小（以字节计）。
- **-c** 在创建文件系统之前检查设备的坏块，使用快速的只读测试。
- **-f 碎片大小** 指定碎片的大小（以字节计）。
- **-i 每inode字节数** 指定字节/inode 比率。**mke2fs** 为磁盘上每“每inode字节数”字节的创建一个 inode。此值默认为 4096 字节。“每inode字节数”至少必须为 1024。
- **-l 文件名** 从文件名读取坏块列表
- **-m 保留块百分比** 指定保留给超级用户的保留块百分比。此值默认为 5%。
- **-o** 手动覆盖文件系统“创建者操作系统”字段的默认值。通常，创建者字段默认为 mke2fs 可执行文件的原生操作系统。
- **-q** 安静执行。如果在脚本中运行 mke2fs，则很有用。
- **-s 稀疏超级块标志** 如果稀疏超级块标志为 1，则开启稀疏超级块标志。如果为 0，则关闭稀疏超级块标志。（目前，稀疏超级块标志默认为关闭。）**警告：** Linux 2 内核不支持此功能。也不是所有 Linux 2.1 内核都支持；除非您知道自己在做什么，否则请不要使用此功能！
- **-v** 详细执行。
- **-F** 强制 mke2fs 运行，即使指定设备不是块特殊设备。
- **-L** 设置文件系统的卷标签。
- **-M** 设置文件系统的最后挂载目录。对于依赖于最后挂载目录来确定文件系统应挂载位置的实用程序可能有用。
- **-r 修订版本** 为新文件系统设置文件系统修订版本。请注意，1.2 内核仅支持修订版本 0 的文件系统。
- **-R raid_选项** 为文件系统设置 RAID 相关选项。RAID 选项用逗号分隔，并可能使用等号（'='）符号采用参数。目前支持的唯一参数是 stride，它采用 RAID 条带中的块数作为参数。
- **-S** 仅写入超级块和组描述符。如果所有超级块和备份超级块都损坏，并且希望采取最后的恢复方法，这将非常有用。它会导致 mke2fs 重新初始化超级块和组描述符，而不触及 inode 表和块和 inode 位图。使用此选项后应立即运行 e2fsck 程序，并且不保证可以恢复任何数据。

# 错误

mke2fs 接受 -f 选项，但目前忽略它，因为第二扩展文件系统尚不支持碎片。可能还有其他一些情况。请向作者报告它们。
