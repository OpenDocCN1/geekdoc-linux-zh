The \texttt{/etc/passwd} file is then used to store user and group names, used by programs like \texttt{/bin/ls} to map the user ID to the proper username in a directory listing.

The \texttt{/etc/shadow} file then only contains the username and his/her password, and perhaps accounting information, etc when the account expires, etc.

To enable shadow passwords, run \texttt{pwpconv} as root, and \texttt{/etc/shadow} should now exist, to be used by applications. Since you are using RH 4.2 or above, the PAM modules will automatically adapt to the change from using normal \texttt{/etc/passwd} to shadow passwords without any other change.

Since you\u2019re interested in securing your passwords, perhaps you would also be interested in generating good passwords to begin with. For this you can use the \texttt{pamcracklib} module, which is part of PAM. It runs your password against the Crack libraries to help you decide if it is too easily guessable by password cracking programs.
