# Appendix C

+   Mac Terminal mini-HOWTO, by Robert Kiesling <kiesling@terracom.net>. How to use an Apple Macintosh as a serial terminal. Updated 9 November 1997.

+   Mail Queue mini-HOWTO, by Leif ErLingsson <leif@llege.com>. How to queue remote mail and deliver local mail. Updated 3 September 1997.

+   Mail2News mini-HOWTO, by Robert Hart <iweft@ipax.com.au>. How to set up a mail to news gateway. Updated 4 November 1996.

+   Man Page mini-HOWTO, by Jens Schweikhart <schweikh@noc.dfn.de>. How to write man pages. Updated July 1998.

+   Modules mini-HOWTO, by Rilev H. Williams <rhh@bigfoot.com>. How to set up and configure kernel modules. Updated 14 November 1997.

+   Multiboot using LILO mini-HOWTO, by Renzo Zanelli <rzanelli@southeast.net>. How to multiboot between Windows 95, Windows NT, and Linux. Updated 26 March 1998.

+   NCD X Terminal mini-HOWTO, by Ian Hodge <ihodge@norite.ca>. Describes how to connect an NCD X terminal to a Unix host. Updated 3 April 1998.

+   NFS-Root mini-HOWTO, by Andreas Kostyrka <andreas@aq.or.at>. How to set up diskless Linux machines. Updated 8 August 1997.

+   NFS-Root-Client mini-HOWTO, by Ofer Maor <ofer@hadar.co.il>. How to set up diskless Linux machines using NFS. Updated 2 February 1999.

+   Netrom-Node mini-HOWTO, by Karl Larsen <ksdi@yahoo.com>. How to set up the ax25-utilities package for Amateur Radio such as making Netrom Nodes. Updated 19 October 1998.

+   Netscape+Proxy mini-HOWTO, by Sarma Seetamaraju <sarma@usa.net>. How to set up a proxy server for Netscape. Updated 15 August 1997.

+   Netstation mini-HOWTO, by Kris Buytaert <Kris.Buytaert@advalvas.be>. How to hook up a IBM Netstation to your local network using a Linux box as server. Updated 22 February 1998.
