**Dialog Buttons Have Icons** Some dialog buttons (for example the OK button) can have icons on them. By default, the applications that provide this have the icons turned on. If you wish not to see them, you may turn off this feature.

**Menu Items Have Icons** Some menu items in applications will have icons. If you wish not to see these icons in applications that use them, you may turn off this feature.

# The Dialogs Caplet

The Dialogs caplet (see Figure 15.40) allows you to change the default settings for dialog boxes in GNOME-compliant applications. A dialog box is a window that is launched by an application to help perform a task needed by that application. An example of a dialog box is a Print dialog box that appears when you press a Print button. The dialog box allows you to set print options and start the print process.
