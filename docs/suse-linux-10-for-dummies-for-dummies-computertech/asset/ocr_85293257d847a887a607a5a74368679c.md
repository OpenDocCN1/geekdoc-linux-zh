# Editing Images with The GIMP

The GIMP is an image-manipulation program written by Peter Mattis and Spencer Kimball and released under the GNU General Public License (GPL). SUSE Linux comes with this program, although you may have to specifically select a package to install it. The GIMP is comparable to other image-manipulation programs such as Adobe Photoshop or Corel PHOTO-PAINT.

To try out the GIMP, choose Main Menu➔Graphics➔Image Editing in KDE or Main Menu➔Graphics➔Image Editing➔The GIMP in GNOME.
