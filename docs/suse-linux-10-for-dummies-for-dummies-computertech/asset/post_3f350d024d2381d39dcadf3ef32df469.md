### Viewing PDF and PostScript Files

Both KDE and GNOME come with applications for viewing and printing PDF documents. As you might know, PDF stands for portable document format and, as the name implies, it’s widely used as the format for documents that can be viewed on almost any system that has a PDF viewer. PDF files typically have a .pdf extension. In KDE, you can use KPDF or KGhostView to view PDF documents. In GNOME, use GPDF to open PDF files. You can find these viewers in the Document Viewer submenu under Office applications menu.

To open a PDF file in KPDF or GPDF, choose File→Open and select the file from the Open dialog box.

KGhostView in KDE and GNOME GhostView (GGV) in GNOME are ideal for viewing and printing PostScript documents. (These files typically have the .ps extension in their names.) For a long document, you can view and print selected pages. You can also view the document at various levels of magnification by zooming in or out. GGV can also open PDF files.

I describe KGhostView next, but you can use GGV in GNOME in a similar manner.

To run KGhostView, choose Main Menu➜Office➜Document Viewer➜PS/PDF Viewer (KGhostView) from the KDE desktop. The KGhostView window appears. In addition to the menu bar and toolbar along the top edge, a vertical divide splits the main display area of the window into two parts.

To load and view a PostScript document in KGhostView, choose File➜Open, or click the Open icon on the toolbar. KGhostView displays a dialog box. Use this dialog box to navigate the file system and select a PostScript file. You can select one of the PostScript files that come with Ghostscript. For example, open the file `tiger.ps` in the `/usr/share/ghostscript/8.15/examples` directory. (If your system has a version of Ghostscript later than 8.15, you have to use the new version number in place of 8.15.)

To open the selected file, click the Open File button in the File Selection dialog box. KGhostView opens the selected file, processes its contents, and displays the output in its window, as shown in Figure 15-14.

## Chapter 16: What’s a Shell and Why Do I Care?

### In This Chapter

- Exploring the bash shell

Sometimes things just don’t work. What do you do if the GUI desktop stops responding to your mouse clicks? What if the GUI doesn’t start at all? You can still tell your SUSE Linux system what to do, but you have to do it by typing commands into a text screen. In these situations, you work with the shell — the SUSE Linux command interpreter. I introduce the bash shell (the default shell in SUSE Linux) in this chapter.

After you figure out how to work with the shell, you may even begin to like the simplicity and power of the Linux commands. And then, even if you’re a GUI aficionado, someday soon you may find yourself firing up a terminal window and making the system sing and dance with two- or three-letter commands strung together by strange punctuation characters. (Hey, I can dream, can’t I?)

### Opening Terminal Windows and Virtual Consoles

First things first. If you’re working in a GUI desktop such as GNOME or KDE, where do you type commands for the shell? Good question.

The easiest way to get to the shell is to open a terminal (also called console) window. In KDE, click the icon that looks like a monitor covered by a seashell (for a shell, get it?) to open a terminal window. In GNOME, select Applications➔System➔Terminal➔Gnome Terminal and that should open up a terminal window. Now you can type commands to your heart’s content.
