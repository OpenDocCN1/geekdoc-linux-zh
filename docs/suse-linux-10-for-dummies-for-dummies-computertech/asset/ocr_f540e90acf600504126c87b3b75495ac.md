In SUSE Linux, ping continues to run until you press Ctrl+C to stop it; then it displays summary statistics showing the typical time it takes to send a packet between the two systems. On some systems, ping simply reports that a remote host is alive. However, you can still get the timing information by using appropriate command line arguments.

![](bbox=[0.12, 0.432, 0.207, 0.504])

The ping command relies on ICMP messages that many firewalls are configured to block. Therefore, ping may not always work and is no longer a reliable way to test network connectivity. If ping fails for a specific host, do not assume that the host is down or not connected to the network. You can still use ping to successfully check connectivity within your local area network.
