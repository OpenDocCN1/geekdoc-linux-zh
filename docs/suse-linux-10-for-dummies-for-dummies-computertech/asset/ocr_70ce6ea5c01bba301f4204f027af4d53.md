# What You’ll Find on the DVD

This section provides a summary of the software and other goodies you can find on the DVD. If you need help installing the items provided on the DVD, refer back to the installation instructions in the preceding section.

![](bbox=[0.118, 0.251, 0.207, 0.319])

GNU software is governed by its own license, which is included in the folder of the GNU software. There are no restrictions on the distribution of GNU software. See the GNU license at the root of the DVD or at the back of this book for details. As required by the GNU license, Novell makes the SUSE Linux source code available. You can download the source code for SUSE Linux from the following URL:

```
http://ftp.opensuse.org/pub/opensuse/distribution/SL-OSS-stable/inst-source/suse/src/
```

The DVD includes a Special Edition of SUSE Linux 10.0. The version of SUSE Linux on the companion DVD includes all the basics that come with SUSE Linux 10.0 OSS from the openSUSE project and a few extras:

+   - Your choice of KDE or GNOME graphical desktop environments
+   - Konqueror Web browser and file manager
+   - Multimedia tools for playing CDs and DVDs, burning CDs, and ripping audio CDs
+   - Office software in the form of the much-acclaimed OpenOffice.org suite
+   - Photo and graphics editing software such as The GIMP, and much more
+   - Extra goodies such as Acrobat Reader, RealPlayer 10, and Macromedia Flash plug-in for the Web browser

In short, the version of SUSE Linux that accompanies this book gives you everything you need for a typical home- or small-office computer.

SUSE does offer a commercial version of SUSE Linux that includes many servers; software development tools; additional word processing, database, and spreadsheet programs; and many more extra programs.
