+   - **Category 5e (Cat 5e):** Similar to Cat 5, but with improved technical parameters such as near-end cross talk and attenuation. Cat 5e cables support 10BaseT, 100BaseT4, 100BaseT, 100BaseTX, and 1000BaseT Ethernet. Nowadays Cat 5e is the minimum acceptable wiring.
+   - **Category 6 (Cat 6):** Similar to Cat 5e, but capable of carrying signals up to a frequency of 250 MHz. Cat 6 cables can support all existing Ethernet standards and are expected to support Gigabit Ethernet standard 1000BaseTX that will use two pairs of wires in each direction as opposed to all four pairs for 1000BaseT Ethernet over Cat 5e cables.

To set up a 10BaseT or 100BaseT Ethernet network, you need an Ethernet hub — a hardware box with RJ-45 jacks. (These look like telephone jacks.) You build the network by running twisted-pair wires (usually, Category 5, or Cat5, cables) from each PC’s Ethernet card to this hub.
