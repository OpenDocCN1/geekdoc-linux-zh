You aren't limited to the built-in functions in the gawk program. If you're working on an application that uses lots of specialized algorithms, you can create your own functions to process the algorithms, then use those functions in your own code. You can also set up a library file containing all of the functions you use in your awk programs, saving you time and effort in all of your coding.
