# Plugins

The Plugins tab provides control over the plugins used in gedit. Plugins are separate programs that can interface with gedit to provide additional functionality. The Plugins tab is shown in Figure 7-14.

There are several plugins available for gedit, not all of them are installed by default. Table 7-4 describes the plugins that are currently available in gedit.

Plugins that are enabled show a check in the checkbox next to their name. Some plugins, such as the External Tools plugin, also provide additional configuration features after you select them. It allows you to use a shortcut key to start the terminal, where gedit displays output, and the command to start the shell session.

Unfortunately, not all plugins are installed in the same place in gedit menubar. Some plugins appear in the Tools menubar item (such as the Spell Checker and External Tools plugins), while others appear in the Edit menubar item (such as the Change Case and Insert Date/Time plugins).
