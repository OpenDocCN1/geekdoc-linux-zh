Since zenith doesn't support the menu dialog window, I used a radiolist window for the main menu, as seen in Figure 15-13.

The radiolist uses two columns, each with a column heading. The first column is the radio buttons to select. The second column is the item text. The radiolist also doesn't use tags for the items. When you select an item, the full text of the item is returned to STDOUT. This makes a life much more interesting for the case command. You must use the full text from the items in the case options. If there are any spaces in the text, you need to use quotation marks around the text.

Using the zenith package, you can add a Windows feel to your interactive shell scripts in the GNOME desktop.

# Summary

Interactive shell scripts have a reputation for being dull and boring. You can change that by using a few different techniques and tools available on Linux systems. First, you can create menu systems for your interactive scripts by using the case command and shell functions.

The case command allows you to paint a menu, using the standard echo command, and read a response from the user, using the read command. The case command then selects the appropriate shell script function based on the value entered.
