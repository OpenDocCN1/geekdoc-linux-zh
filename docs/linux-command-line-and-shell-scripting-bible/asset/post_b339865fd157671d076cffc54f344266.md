# Advanced Shell Scripting

```bash
# using zenity to create a menu

temp=`mkktemp -t temp.XXXXXX`
temp2=`mkktemp -t temp2.XXXXXX`
```

```bash
function diskspace {
  df -k $temp
  zenity --text-info --title "Disk space" --filename=$temp
  --width 750 --height 10
}
```

```bash
function whose {
  who > $temp
  zenity --text-info --title "Logged in users" --filename=$temp
  --width 500 --height 10
}
```

```bash
function memusage {
  cat /proc/meminfo > $temp
  zenity --text-info --title "Memory usage" --filename=$temp
  --width 300 --height 500
}
```

```bash
while [ 1 ]

  zenity --list --radiolist --title "Sys Admin Menu" --column "Select" \
  --column "Menu Item" FALSE "Display disk space" FALSE "Display users" \
  FALSE "Display memory usage" FALSE "Exit" > $temp2
  if [ $? -eq 1 ]
    then
      break
```

```bash
selection=`cat $temp2`
case $selection in
  "Display disk space")
    diskspace ;;
  "Display users")
    whose ;;
  "Display memory usage")
    memusage ;;
  "Exit")
    break ;;
  *)
    zenity --info "Sorry, invalid selection" ;;
esac
done
```

# Summary

Interactive shell scripts have a reputation for being dull and boring. You can change that by using a few different techniques and tools available on Linux systems. First, you can create menus for interactive scripts using the case command and read response from the user using the read command. The case command then selects the appropriate shell function based on the value entered.

You can liven up text menus using ANSI control codes to set colors such as blinking and bold text. Often changing the colors of a menu helps make the script experience more enjoyable. The dialog program provides several prebuilt widgets for creating text-based objects. You can create dialog boxes for displaying text, choosing files and dates using the dialog program. This brings even more life to your shell script.

If you're running your shell scripts in a graphical environment, you can utilize more tools in interactive scripts. For the KDE desktop, there's the kdialog program which provides widgets for all functions. For the GNOME desktop, there are dialog and zenity programs. Each of these programs provides widgets that blend into the desktop just like a real application.

## Text Manipulation

Chapter 7 showed how to edit text files using different editor programs available in the Linux environment. These editors allow you to easily manipulate text contained in a text file, using simple commands or mouse clicks.

There are times though you'll find yourself wanting to manipulate text in a text file on the fly, without having to pull out a full-fledged interactive editor. In these situations, it would be useful to have a simple command line editor that could easily format, insert, modify, or delete text elements automatically.

The Linux system provides two common tools for doing just that. This section describes the two popular command line editors used in the Linux world, sed and awk.

# The sed editor

The sed editor is called a stream editor, as opposed to a normal interactive text editor. In an interactive text editor like vim, you interactively use keyboard commands to insert, delete, or replace text in the data. A stream editor edits a stream of data based on a set of rules you supply ahead of time, before the editor processes the data.

The sed editor can manipulate data in a data stream based on commands you enter into the command line or store in a command text file. It reads one line of data at a time from the input, matches that with the supplied commands, then outputs the new data in the stream to STDOUT. After the stream editor matches all of the commands against a line of data, it reads the next line of data and repeats the process. After the stream editor processes all of the lines of data in the stream, it terminates.

Since the commands are applied sequentially by line, the sed editor only has to make one pass through the data stream to make the edits. This makes the sed editor much faster than an interactive editor, allowing you to quickly make changes to a data file on the fly.

The format for using the sed command is:

```bash
sed options script file
```

The options parameters allow you to customize the behavior of the sed command, and include the options shown in Table 16-1.

### TABLE 16-1
The sed Command Options
| Option | Description |
| :--- | :--- |
| -e script | Add commands specified in the script to the commands run while processing the input. |
| -f file | Add the commands specified in the file to the commands run while processing the input. |
| -n | Don't produce output for each command, but wait for the print command. |
