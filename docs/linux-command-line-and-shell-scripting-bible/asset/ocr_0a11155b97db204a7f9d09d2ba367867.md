# Part II Shell Scripting Basics

```
$ echo $?
40
$
```

You should be careful with this feature though, as the exit status codes can only go up to 255. Watch what happens in this example:

```
$ cat test1l4b
#!/bin/bash
# testing the exit status
var1=10
var2=30
var3=$[$ var1 * var2 ]
echo The value is $var3
exit $var3
$
```

Now when you run it, you get:

```
$ ./test1l4b
The value is 300
$ echo $?
44
```

The exit status code is reduced to fit in the 0 to 255 range. The shell does this by using modulo arithmetic. The modulo of a value is the remainder after a division. The resulting number is the remainder of the specified number divided by 256. In the case of 300 (the result value), the remainder is 44, which appears as the exit status code.

# Summary

The bash shell allows you to string commands together into one script. The most basic way of creating a script is to separate multiple commands on the command line using a semicolon. The shell executes each command in order, displaying the output of each command on the monitor.

You can also create a script file, placing multiple commands in the file for the shell to execute in order. The shell script file must define the shell used to run the script. This is done in the first line of the script, using the # symbol, followed by the full path of the shell.

Within the script you can reference environment variables by using a dollar sign in front of the variable. You can also define your own variables for use within the script, and assign values and even the output of a command by using the backtick character. The variable value can be used within the script by placing a dollar sign in front of the variable name.
