# # calculating factorials the ksh93 way

```
value=1
while (( $value <= 10 ))
do
  factorial=1
  counter=1
  while (( $counter <= $value ))
  do
    factorial=$((factorial * $counter))
    counter=$((counter + 1))
  done
  print "The factorial of $value is $factorial"
  value=$(( $value + 1 ))
done
```

# Command redirection

In the ksh93 shell you can't use the backtick to redirect the output of a command to a variable.
Instead, you must use the:

```
variable=$$( command )
```

This format assigns the output of a command to the variable:

```
$ value=$( date )
$ echo $valuelel
Mon Jan 14 19:23:14 EST 2023
$ 
```

This feature comes in handy in your shell scripts, when you need to extract data from the output of a command (more on that in Chapter 27).
