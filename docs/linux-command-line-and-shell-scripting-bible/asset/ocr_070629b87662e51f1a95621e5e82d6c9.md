# Part III Advanced Shell Scripting

```
$ echo "beet" | awk --re-interval '/be[1,2]t/(print $0)'
beet
$ echo "beeet" | awk --re-interval '/be[1,2]t/(print $0)'
$
```

In this example, the e character can appear once or twice for the pattern match to pass; otherwise, the pattern match fails.

The interval pattern match also applies to character classes:

```
$ echo "bt" | g --re-interval '/b[ae][1,2]t/(print $0)'
$
$ echo "bat" | g --re-interval '/b[ae][1,2]t/(print $0)'
bat
$ echo "beet" | g --re-interval '/b[ae][1,2]t/(print $0)'
bet
$ echo "beat" | g --re-interval '/b[ae][1,2]t/(print $0)'
beat
$ echo "beet" | g --re-interval '/b[ae][1,2]t/(print $0)'
beet
$
$ echo "beeet" | g --re-interval '/b[ae][1,2]t/(print $0)'
$
$ echo "baeet" | g --re-interval '/b[ae][1,2]t/(print $0)'
$
$ echo "baeaet" | g --re-interval '/b[ae][1,2]t/(print $0)'
$
```

This regular expression pattern will match if there are exactly one or two a's or e's in the text pattern, but it will fail if there are any more in any combination.

# The pipe symbol

The pipe symbol allows you to specify two or more patterns that the regular expression engine uses in a logical OR formula when examining the data stream. If any of the patterns match the data stream, the test passes. If none of the patterns match, the data stream fails.

The format for using the pipe symbol is:

```
expr|expr...
```

Here's an example of this:

```
$ echo "The cat is asleep" | g '/cat|dog/(print $0)'
The cat is asleep
$ echo "The dog is asleep" | g '/cat|dog/(print $0)'
The dog is asleep
$ echo "The sheep is asleep" | g '/cat|dog/(print $0)'
$
```
