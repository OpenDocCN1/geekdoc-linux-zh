# More gawk Built-In Variables

| Variable | Description |
|---|---|n| ARGC | The number of command line parameters present. |
| ARGIND | The index in ARGV of the current file being processed. |
| ARGV | An array of command line parameters. |
| CONVFMT | The conversion format for numbers (see the printf statement). The default value is %6 g. |
| ENVIRON | An associative array of the shell environment variables and their values. |
| errno | The system error if an error occurs reading or closing input files. |
| FILENAME | The name of the data file used for input to the gawk program. |
| FNR | The current record number in the data file. |
| IGNORECASE | If set to a non-zero value, gawk all string functions (including regular expressions); ignore the case of characters. |
| NF | The total number of data fields in the data file. |
| NR | The number of input records processed. |
| OFMT | The output format for displaying numbers. The default is %.6 g. |
| RLENGTH | The length of the substring matched in the match function. |
| RSTART | The start index of the substring matched in the match function. |

# Assigning variables in the command line

You can also use the gawk command line to assign values to variables for the gawk program. This allows you to set values outside of the normal code, changing values on the fly. Here's an example of using a gawk command variable to display a specific data field in the file:

```
$ cat script1
BEGIN(FS="-")
 print $n
$ gawk -f script1 n=2 datal
$ gawk -f script1 n=3 datal
```

This feature is a great way to process data from your shell scripts in the gawk script.
