Finally, the chage command helps us manage the password aging process for user accounts. There are several parameters to set individual values, shown in Table 6-4.

The change date values can be expressed using one of two methods:

+   - A date in YYYY-MM-DD format
- A numerical value representing the number of days since January 1, 1970

One neat feature of the chage command is that it allows you to set an expiration date for an account. Using this feature, you can create temporary user accounts that automatically expire on a set date, without having to remember to delete them! Expired accounts are similar to locked accounts. The account still exists, but the user can't log in with it.
