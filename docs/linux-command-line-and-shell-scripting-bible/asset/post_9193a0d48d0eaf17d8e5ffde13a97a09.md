## Catching disk hogs

If you're responsible for a Linux server with lots of users, one problem that you'll bump up against is who's using all of the disk space. This age-old administration question is sometimes harder to figure out than others.

Unfortunately, for the importance of tracking disk space usage, there's no one Linux command that can provide information for you. Instead, you need to write a shell script piercing other commands together to extract the information you're looking for. This section walks you through this process.

The first tool you'll need to use is the du command (see Chapter 4). This command displays the disk usage for individual files and directories. The -s option lets you summarize at the directory level. This will come in handy when calculating the total disk space used by an individual user. Just use this command for the /home directory contents to summarize for each user's HOME directory:

```
# du -s /home/*
40 /home/barbara
9868 /home/jessica
40 /home/katie
40 /home/lost+found
107340 /home/rich
5124 /home/test
#
```

Okay, that's a start. You can now see the total listing (in KB) for the $HOME directory totals. Depending on how your /home is mounted, you may or may not see a special directory lost+found, which isn't a user account.

> NOTE: To get statistics for all of the user HOME directories, you must be logged in as the root account when running this script.

To get rid of that, we use the grep command with the -v option, which prints all of the lines except ones that contain the specified text:

```
# du -s /home/* | grep -v lost
40 /home/barbara
9868 /home/jessica
40 /home/katie
107340 /home/rich

```

Next, let's get rid of the full pathname so all we see are the user names. This sounds like a job for the sed command:

```
# du -s /home/* | grep -v lost | sed 's/home\//'
40 barbara
9868 jessica
40 katie
107340 rich
5124 test
#
```

Much better. Now, let's sort this output so that it appears in descending order:

```
# du -s /home/* | grep -v lost | sed 's/home\///' | sort -g -r
107340 rich
9868 jessica
5124 test
40 katie
40 barbara
#
```

The sort command sorts numerical values when you use the -g option, and will sort in descending order when you include the -r option.

There's just one more piece of information that you're interested in, and that's the total amount of space used for all of the users. Here's how to get that value:

```
# du -s /home
122420 /home
#
```

This is all the information you'll need to create the disk hogs report. Now you're ready to push this into a shell script.

## Creating the script

Now that you know how to extract the raw data for the report, it's time to figure out a script that can read the report, parse the raw data values, and display it in a format that is presentable to a user.

Part V Advanced Topics

The easiest way to manipulate data for reports is with the gawk command. The report will have three sections:

- A header with text identifying the columns
- The body of the report, showing the user, their total disk space used, and a percentage of the total they're consuming
- A footer which shows the total disk space usage for all users

The gawk command can perform all of these functions as a single command, using the BEGIN and END tags (see Chapter 16).

Here is the script that puts all of the elements together:

```bash
# cat diskhogs
#!/bin/bash
# calculate disk usage and report per user

TEMP=$(mktemp -t tmp.XXXXX)
du -s /home/* | grep -v lost | sed '//home/' | sort -gr > $TEMP
TOTAL=$(du -s /home | gawk 'print $1')
cat $TEMP | gawk -v n="$TOTAL"
BEGIN {
    print "Total Disk Usage by User"
    print "User\tSpace\tPercent"
}
{
    printf "%s\t%d\t%.2f\n", $2, $1, ($1/n)*100
}
END {
    print "-"
    printf "Total %d\n", n
}
rm -f $TEMP
```

The script sends the result from the formula to generate the raw data to a temporary file, then stores the result of the total disk space formula in the variable $TOTAL.

Next, the script retrieves the raw data in the temporary file, and sends it to the gawk command. The gawk command retrieves the $TOTAL value and assigns it to a local variable called n.

The code in the gawk command first creates the report header in the BEGIN section:

```awk
BEGIN {
    print "Total Disk Usage by user"
    print "User\tSpace\tPercent"
}
```

It uses the printf command to format and rearrange the text from the raw data:

```awk
{
    printf "%s\t%d\t%.2f\n", $2, $1, ($1/n)*100
}
```

This is the section that processes each line of output from the du command. The printf command allows us to format the output to make a nice table. If you happen to have long usernames on your system, you may need to judge the formatting to get it to turn out.

The other trick here is that the diskhogs script passes the $TOTAL variable to the awk script via the awk command line parameter: -v n=$TOTAL

Now the gawk variable n is equal to the total user disk space, and you can use that value anywhere in the gawk script.

Finally, the script ends the output display by showing the total amount of user disk space used:

```awk
{
    printf "--------------------------------"
    printf "Total\t%d\n", n
}
```

This uses the n variable, which contains the value from the $TOTAL shell variable.

## Running the script

Putting it together, when you run the script you should get a nice report:

```bash
# ./diskhogs
Total Disk Usage Space Percent
rich 107340 87.6%
jessica 9868 8.1%
test 5124 4.2%
katie 40 0.0%
barbara 40 0.0%
Total 122420
```

Now you've got a report that you can send off to boss.

> NOTE: If you really do disk hogs on your system, it may take a long time for the du command to calculate all the space. Be patient!

Watching CPU and memory usage

The core statistics of any Linux system are the CPU and memory usage. If these values start out of control, things can go wrong very quickly. This section demonstrates how to write scripts to monitor and track.

With the other scripts shown so far, the first step is to determine exactly what data you want to produce. The basic system command is the uptime command:

```bash
$ uptime
09:57:15 up 3:22, 3 users, load average: 0.00, 0.08, 0.28
```

The uptime command gives us a few different pieces of information we use. Another great command for extracting system information is the vmstat command. Here's an example of the output from the vmstat command:

```bash
$ vmstat
procs--memory----swap--system----cpu----
r b swpd free buff cache si bo bi in cs us sy id wa s
0 178660 13524 4316 72076 8 10 80 22 127 124 3 1 92 4 0
0 178660 12845 4245 71890 8 10 80 22 127 124 3 1 86 10 0
```

The first time you run the vmstat command, it displays the average values since the last reboot. To get the statistics, you must run the vmstat command with line parameters:

```bash
$ vmstat 1 2
procs--memory----swap--system----cpu----
r b swpd free buff cache si bo bi in cs us sy id wa s
0 178660 13524 4316 72076 8 10 80 22 127 124 3 1 92 4 0
0 178660 12845 4245 71890 8 10 80 22 127 124 3 1 86 10 0
```
