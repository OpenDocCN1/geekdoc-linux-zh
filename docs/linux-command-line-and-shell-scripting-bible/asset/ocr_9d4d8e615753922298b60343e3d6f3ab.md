# Using a Database

If you've manually downloaded and installed the MySQL binary package, you'll need to create the default MySQL database files (these aren't included as part of the distribution package). As the Linux root user account, enter this command:

```
# /usr/local/mysql/scripts/mysql_install_db --user=mysql
```

After MySQL creates the default database, you can change the owner of everything but the database directory back to your user using these:

```
# cd /usr/local/mysql
# chown -R root
# chown -R mysql data
```

You're ready to start the MySQL server.

# Starting the MySQL server

If you installed MySQL using your Linux distribution's software installer, it's usually configured to start automatically the next time you boot your system. You can check by using our friend the ps command (check Chapter 4):

```
# ps ax | grep mysql
2084 ? S 0:00 /bin/sh /usr/bin/mysql_safe --datadir=/var/lib/mysql --socket=mysql.sock --log-error=/var/log/mysql.log --pid-file=/var/run/mysqld.pid
2141 ? S 0:03 /usr/libexec/mysql --basedir=/usr --datadir=/var/lib/mysql --user=mysql --pid-file=/var/run/mysqld.pid --skip-external-locking --socket=/var/lib/mysql/mysql.sock
8825 pts/1 S+ 0:00 grep mysql
```

The mysql_safe script is used to start the MySQL server using the mysql user account.

If the MySQL server isn't running, you'll need to start it. Many Linux distributions include some type of service utility that allows you to view the services that the system starts at boot. In Fedora 8 and OpenSUSE10.3 this feature is in the Administrative area.

Make to sure that the MySQL server service on your Linux system is set to start automatically.

If you installed the software manually, you'll need to start the MySQL server yourself using the mysql_safe script:

```
# /usr/local/mysql/bin/mysql_safe --user=mysql &
```
