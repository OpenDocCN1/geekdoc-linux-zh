# Part I The Linux Command Line

The memory locations are grouped into blocks pages. The kernel locates each page of memory in the physical memory or the swap space. The kernel then maintains a table of the memory pages that indicate which pages are in physical memory, and which pages are swapped out to disk.

The kernel keeps track of which memory pages are used and automatically copies memory pages that have not been accessed for a period of time to the swap area (called swapping out), even if there's other memory available. When a program wants to access a memory page that has been swapped out, the kernel must make room for it in physical memory by swapping out a different memory page, and swap in the required page from the swap space. Although, this process can slow down a running process. The process of swapping memory pages for running applications continues for as long as the Linux system is running.

You can see the current status of virtual memory on your Linux system by viewing the special /proc/meminfo file. Here's an example of a sample /proc/meminfo entry:
