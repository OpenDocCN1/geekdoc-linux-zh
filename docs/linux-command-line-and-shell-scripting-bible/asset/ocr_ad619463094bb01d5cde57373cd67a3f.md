# Using arithmetic

Chapter 8 showed three ways to express a mathematical operation in the bash shell script:

The ash and dash shells support the expr command and the double parentheses method but don't support the square bracket method. This can be a problem if you've got lots of mathematical operations that use the square brackets:

```
$ cat test5
!/bin/dash
# testing mathematical operations

value1=10
value2=15

value3=$[ value1 * $value2 ]
echo "The answer is $value3"
./test5
.test5: 7: value1: not found
The answer is
$
```

The proper format for performing mathematical operations in ash or dash shell scripts is to use the double parentheses method:

```
$ cat test5b
!/bin/dash
# testing mathematical operations

value1=10
value2=15

value3=$(( value1 * $value2 ))necho "The answer is $value3"
./test5b
The answer is 150
$
```

Now the shell can perform the calculation properly.
