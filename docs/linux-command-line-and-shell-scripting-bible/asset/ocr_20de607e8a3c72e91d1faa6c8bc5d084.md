# Part IV Alternative Linux Shells

```
echo "This is an example of a function"
count=1
while [ $count -le 5 ]
do
  funccl
  count=$(( $count + 1 ))
done
echo "This is the end of the loop"
funccl
echo "This is the end of the script"
$ ./test9
./.test9: 4: Syntax error: "( unexpected"
$
$
```

Instead of assigning the function code to the function, the dash shell executed the code within the function definition, then complained about the format of the shell script.

If you're writing scripts that may be used in the ash or dash environment, always use the second method of defining your functions:

```
$ cat test10
#!/bin/dash
# testing functions

funccl() {
  echo "This is an example of a function"
  count=1
  while [ $count -le 5 ]
  do
    funccl
    count=$(( $count + 1 ))
  done
echo "This is the end of the loop"
funccl
echo "This is the end of the script"
$ ./test10
This is an example of a function
This is an example of a function
This is an example of a function
This is an example of a function
This is an example of a function
This is the end of the loop
This is an example of a function
This is the end of the script
$
```
