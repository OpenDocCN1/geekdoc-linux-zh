It's not always convenient to send just line of text in the message body. Often you'll need to send an entire output as the e-mail message. In those situations, you can always redirect text to a temporary file, use the cat command and redirect the output to your mail program.

Here's an example of sending a larger amount of data in an e-mail message:

```
$ cat diskmail
#!/bin/bash
# sending the current disk statistics in an e-mail message

date=$(date +%m%%%d%%Y)
MAIL=$(which mail)
TEMP=$(mktmp tmp.XXXXX)

df -k $TEMP
cat $TEMP | MAIL -s "Disk stats for $date" $1
rm -f $TEMP
$ ./diskmail rich
$ mail
```
