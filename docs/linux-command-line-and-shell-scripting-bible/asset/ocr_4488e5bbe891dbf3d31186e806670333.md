After creating the archive file you can send it to your favorite compression utility to reduce its size:

```
$ ls -l archive.tar
-rw-r-- 1 rich 30720 2008-02-06 12:26 archive.tar
$ gzip archive.tar
$ ls -l archive*
-rw-rw-r-- 1 rich 2928 2008-02-06 12:26 archive.tar.gz
$
```

You now have the first component to archive your system.
The next step is to create a rolling archive system. If you save your working directory on a regular basis, you not necessarily want the newest archive copy to immediately overwrite the previous archive copy.

To prevent this, you'll need to create a method to automatically provide a unique filename for each archive copy. The easiest way to do that is to incorporate the date and time in your names.

As you've seen from the "Monitoring System Statistics" section, you can format the date command to produce information in just about any format you desire. This comes in handy when creating unique filenames.

For example, if you want to create a filename using the two-digit year, the month, and the date, you'd do something like this:

```
$ DATE=`date +%y%m%d`
$ FILE=tmp$DATE
$ echo $FILE
tmp080206
$
```

While it might look odd to squish the $DATE variable at the end of a text string, it's perfectly legal in the bash shell. The shell appends the variable's value to the string, creating a unique filename.

> Using a date to uniquely identify a file get tricky when looking for the most recent file version. Make sure you remember the format you use to tag the date (such as month-day-year or year-month-day). When sorting file names it is good to specify the year first, then the month, and finally, the day.
