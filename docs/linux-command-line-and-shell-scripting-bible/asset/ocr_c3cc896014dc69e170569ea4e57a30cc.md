# Default files

When you use the ksh93 shell as a login shell, it reads commands from two files:

+   - /etc/profile
- $HOME/.profile

You should store commands that are executed by all users in the /etc/profile file, while commands for individual users should be stored in the appropriate $HOME/.profile.

# Environment variables

The ksh93 shell environment variables to set features and provide information about the shell environment. Table 22-2 shows the default environment variables available in the ksh93 shell.

> TABLE 22-2

# The ksh93 Environment Variables

| Variable | Description |
|---|---|
| CDPATH | The search path for the cd command |
| COLUMNS | The terminal width in characters for edit mode |
| EDITOR | The default editor used for command line editing |
| ENV | Defines a file used for specifying parameter expansion, command substitution, and arithmetic substitution (commonly $HOME/.kshrc) |
| IGNORE | The set of filenames ignored when performing filename matching |
| FPATH | Search path for functions |
| HISTCMD | The number of the current command in the history file |
| HISTEDIT | The default editor for the history command |
