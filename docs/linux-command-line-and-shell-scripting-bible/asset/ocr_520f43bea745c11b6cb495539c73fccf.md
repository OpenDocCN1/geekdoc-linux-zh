That's a lot of functions you to use! Using them is as easy as just including the function name and parameters in your shell script code:

```
$ cat test1
!/bin/ksh93
# testing the ksh93 math functions

value1=9
value2=$(( sqrt($value) ))
value3=$(( int(10.52) ))
value4=$(( sin(45) ))
print "The square root of $value is $value2"
print "The integer part of 10.52 is $value3"
print "The sine of 45 is $value4"
$ ./test1
The square root of 9 is 3
The integer part of 10.52 is 10
The sine of 45 is 0.850903525434 $
```

As you can see from the examples, the ksh93 math functions can also work with floating-point numbers.
