## Using buffers in emacs

The emacs editor allows you to edit multiple files at the same time by having multiple buffer areas. You can load files into buffer and switch between buffers while editing.

To load a new file into a buffer while you're in emacs, use the C-x C-f key combination. The emacs find a file mode. It takes you to the bottom line in the window and allows you to enter the name of the file you want to start edit. If you don't know the name or location of the file, just press the Enter key. This brings up a file browser in the edit window, as shown in Figure 7-3.

From here, you can browse to the file you want to edit. To traverse a directory level, go to the double dot entry, and press the Enter key. To traverse down a directory, go to the directory entry and press the Enter key. When you've found the file you want to edit, just press the Enter key, and emacs will load it into a new buffer area.

You can list the active buffer areas by pressing the C-x C-b extended command combination. The emacs editor splits the editor window and displays a list of buffers in the bottom window. There are always two buffers that emacs provides besides your main editing buffer:

- A scratch area *scratch*
- A message area called *Messages*

The scratch area allows you to edit LISP programming commands, as well as enter notes to yourself. The message area shows messages generated by emacs while operating. If any errors occur while using emacs, they will appear in the message area.

There are two ways to switch to a different buffer area in the window:

- C-x o to switch to the buffer listing window. Use the arrow keys to move to the buffer area you want, and press the Enter key.
- C-x b to type in the name of the buffer area you want to switch to.

When you select the option to switch to the buffer listing window, emacs will open the buffer area in the new window. The emacs editor allows you to have multiple windows in a single session. The following section discusses how to manage multiple windows in emacs.

## Using windows in console mode

The console mode emacs editor was developed many years before the idea of graphical windows appeared. However, it was advanced for its time in that it could support multiple editing within the main window.

You can split the window into multiple windows using two commands:

- C-x 2 splits the window horizontally.
- C-x 3 splits the window vertically.

To move from one window to another, use the C-x 0. You'll notice that when you create a new window, emacs uses the buffer area from the original window. To load a new file, you can use C-x C-f. To close all windows except the one you're in, use C-x 1. To close a window, use C-x c.

If you've already used emacs in console mode, you should be fairly familiar with the key commands. All of them are available as menu items. The menu contains the following:

- File allows you to open files, create new buffers, close buffers, and print.
- Edit allows you to cut and copy text to the clipboard, paste data to the cursor position, search for text, and replace text.
- Options provides settings for many features such as highlighting, word wrap, and setting fonts.
- Buffers lists current buffers and allows you to easily switch between areas.
- Tools provides access to advanced features such as the command line interface, spell checking, comparing text files (like diff), sending email, and the calculator.
- Help provides the emacs manual online for help on specific functions.

## The KDE Family of Editors

If you're using a Linux distribution that uses the KDE desktop, there are a couple of options for text editors. The KDE project officially supports two editors:

- KWrite: A single-screen text editing package
- Kate: Full-featured text editing package

Both of these editors are graphical text editors that contain many advanced features plus extra niceties not found in standard text editors. This section describes each of the editors and shows some of the features you can use to help with your shell scripting.

## The KWrite editor

The basic editor for the KDE environment is KWrite. It provides simple word-processing-style text editing, along with support for code syntax highlighting and editing. The default KWrite editor is shown in Figure 7-5.

You can't tell from Figure 7-5, but the KWrite editor recognizes several types of programming languages and uses color coding to distinguish constants, functions, and comments. Also, notice that the function has an icon that links the opening and closing braces. This is called a folding marker. By clicking the icon, you can collapse the function into a single line. This is a great feature when working through large applications.

The KWrite editing window provides full cut and paste capabilities using the mouse and the arrow keys. As in a word processor, you can highlight and (or copy) text anywhere in the buffer area and paste it at any other place.

To edit a file using KWrite, you either select KWrite from the KDE menu system on your desktop or start it from the command line prompt:

```bash
$ kwrite factorial.
```

The kwrite command has several command line parameters you can use to customize how it starts:

- -stdin causes KWrite to read data from the standard input device instead of a file.
- -encoding specifies a character encoding type to use for the file.
- -line specifies a line number in the file to start in the editor window.
- -column specifies a column number in the file to start at the editor window.
