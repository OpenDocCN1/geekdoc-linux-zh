Besides the standard mathematical functions, awk also provides a few functions for bitwise manipulating of data:

+   - and(v1, v2): Performs a bitwise AND of values v1 and v2.
- compl(val): Performs the bitwise complement of val.
- shift(val, count): Shifts the value val count number of bits left.
- or(v1, v2): Performs a bitwise OR of values v1 and v2.
- rshift(val, count): Shifts the value val count number of bits right.
- xor(v1, v2): Performs a bitwise XOR of values v1 and v2.
- The bit manipulation functions are useful when working with binary values in your data.

# String functions

The awk programming language also provides several functions you can use to manipulate string values, shown in Table 19-5.

Some of the string functions are fairly self-explanatory:

```
$ awk BEGIN(x = "testing": print toupper(x); print length(x) )
TESTING
7$
```

However, some of the string functions can get pretty complicated. The asort and asort functions are new awk functions that allow you to sort an array variable based on either the data elements (asort) or the index values (asort). Here's an example of using asort:

```
$ awk BEGIN(
var["a"] = 1
var["g"] = 2
var["m"] = 3
var["u"] = 4
asort(var, test)
for (i in test)
  print "Index:",i," - value:",test[i]
)
Index: 4 - value: 4
Index: 1 - value: 1
Index: 2 - value: 2
Index: 3 - value: 3
$
```
