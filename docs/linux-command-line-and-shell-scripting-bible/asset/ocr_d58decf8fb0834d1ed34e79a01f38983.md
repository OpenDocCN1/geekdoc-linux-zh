# Part II Shell Scripting Basics

```
IFS.OLD=$IFS
IFS='\n'
for entry in cat /etc/passwd
do
  echo "Values in $entry -"
  IFS=
    for value in $entry
      echo " $value"
  done
done
```

This script uses two different IFS values to parse the data. The first IFS parses the individual lines in the /etc/passwd file. The inner for loop next changes the IFS value to the colon, which allows you to parse the individual values within the /etc/passwd lines.

When you run this script, you'll get something like this:

```

```

The inner loop parses each individual value in the /etc/passwd entry. This is also a great way to process comma-separated data, a common way to import spreadsheet data.
