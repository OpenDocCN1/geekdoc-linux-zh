```
export PATH USER LOGNAME MAIL HOSTNAME HISTSIZE INPUTRC
for i in /etc/profile.d/*.sh; do
  . "$i";
dfi
if [ -r "$i" ]; then
  $i
done
```

Most of the commands and scripts you in this file are covered in more detail later on in Chapter 8. The important thing to notice now is the environment variables that are set in this startup file. Notice the export line near the bottom of the file:

```
export PATH USER LOGNAME MAIL HOSTNAME HISTSIZE INPUTRC
```

This ensures that environment variables are available to all child processes spawned from the login shell.
