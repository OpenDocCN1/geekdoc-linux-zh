Trying to just extract individual numbers will be difficult. Chapter 18 discussed how to deal with a problem just like this.

The key to solving this is to write a sed script that can search for the data heading. When you find it, you can then go to the correct line to extract the data. We're fortunate in this example in all of the data we need are on lines by themselves. We should be able to solve this with just the sed script. If there had been other text on the same line, we'd need to get out the gawk tool to filter out just the data we needed.

Perfect. Now, you can use these two sed scripts in a shell script that first captures the lynx output of the Web page to a temporary file, then applies the two sed scripts to the Web page to extract only the data you're looking for. Here's an example of how to do:

```
$ cat weather
!/bin/bash
# extract the current weather for Chicago, IL

URL="http://weather.yahoo.com/forecast/USIL0225.html"
LYNX=`which lynx`
TMPFILE=`mktemp tmpXXXXXX`
LYNX -dump $URL > $TMPFILE
```
