# The C-Style for Command

If you've done any programming using the C programming language, you're probably surprised by the way the bash shell uses the for command. In the C language, a for loop normally defines a variable, which it then alters automatically during each iteration. Normally, programmers use this variable as a counter, and either increment or decrement the counter by one in each iteration. The bash for command can also provide this functionality. This section shows how you can use a C-style for command in a bash shell script.
