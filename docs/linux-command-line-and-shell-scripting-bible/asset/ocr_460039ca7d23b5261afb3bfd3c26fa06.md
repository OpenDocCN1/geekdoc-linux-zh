When using the Lynx program, you can use the standard shell scripting techniques to extract individual data elements from the dumped Web page.

What I like using curl is for batch downloading files. These days it seems like I'm constantly downloading the latest Linux distribution ISO file. Since the ISO files are so large, I need to start the download and walk away while it's downloading. Once I know the URL for an ISO file, I can create a simple shell script using curl to automate the process:

```
$ cat downld
!/bin/bash
# download latest cURL file automatically
```
