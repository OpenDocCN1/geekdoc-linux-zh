# Basic bash Shell Commands

Notice that first, the -R parameter shows the contents of the current directory, which is a file
(file) and two directories (test1 and test2). Following that, it traverses each of thendirectories, showing if any files are contained within each directory. The test1 directory shows
two files (my1 and my2), while the test2 directory doesn't contain any files. If there
had been subdirectories within the test1 or test2 directories, the -R parameter would\have continued to traverse those all. As you can see, for large directory structures this can
come a large output listing.

# Modifying the information presented

As you can see in the basic listings, the ls command doesn't produce a whole lot of informa-
about each file. For listing additional information, another popular parameter is -l. The
-1 parameter produces a long format listing, providing more information about each file in the
directory:

```
$ ls -l
total 2064
drwxr-xr-x 2 rich 4096 2007-08-24 22:04 4rich
-rw-r--r-- 1 rich 176625 2007-08-24 15:34 backup.zip
drwxr-xr-x 3 rich 4096 2007-08-31 22:24 Desktop
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Documents
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Download
drwxr-xr-x 2 rich 4096 2007-07-26 18:25 Drivers
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Music
-rw-r--r-- 1 rich 30 2007-08-23 21:42 myprog
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Pictures
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Public
drwxr-xr-x 5 rich 4096 2007-08-24 22:04 store
-rw-r--r-- 1 rich 98772 2007-08-24 15:30 store.sql
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Templates
drwxr-xr-x 2 rich 4096 2006-11-01 04:06 Videos
[rich]test~$
```

The long list format lists each file and directory contained in the directory on a single line.
Besides the filename, it shows additional useful information. The first line in the output shows
total number of blocks contained within. Following that, each line contains the
information about each file (or directory):

+   - The file type (such as directory (d)), file (-), character device (c), or block device (b)
- The permissions for the file (see Chapter 6)
- The username of the owner of the file
