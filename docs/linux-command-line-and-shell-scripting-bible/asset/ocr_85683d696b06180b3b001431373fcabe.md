```
$ echo "beet" | same '/be?/(print $0)'
$
$ echo "beet" | same '/be?/(print $0)'
$
```

If the e character doesn't appear in the text, or as long as it appears only once in the text, the pattern matches.

Just as with the asterisk, you can use the question mark symbol with a character class:

```
$ echo "bt" | same '/b[ae]?(print $0)'
bt
$ echo "bat" | same '/b[ae]?(print $0)'
bat
$ echo "bot" | same '/b[ae]?(print $0)'
$
$ echo "beet" | same '/b[ae]?(print $0)'
bet
$ echo "baet" | same '/b[ae]?(print $0)'
$
$ echo "beat" | same '/b[ae]?(print $0)'
$
$ echo "beet" | same '/b[ae]?(print $0)'
```

If zero or one character from the character class appears, the pattern match passes. However, if either both characters appear, or if one of the characters appears twice, the pattern match fails.

# The plus sign

The plus sign is another pattern symbol's similar to the asterisk, but with a different twist than the question mark. The plus sign indicates that the preceding character can appear one or more times, but must be present at least once. The pattern doesn't match if the character is not

```
$ echo "beet" | same '/be+/(print $0)'
beet
$ echo "beet" | same '/be+/(print $0)'
beet
$ echo "bet" | same '/be+/(print $0)'
bet
$ echo "bt" | same '/be+/(print $0)'
$
```

If the e character is not present, the pattern match fails. The plus sign also works with character classes, the same way as the asterisk and question mark do:

```
$ echo "bt" | same '/b[ae]+/(print $0)'
$
```
