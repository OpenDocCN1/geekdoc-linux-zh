```
$ cat test12
!/bin/bash
# returning an array value

function arraydblr (
  local origarray
  local newarray
  local elements
  local i
  origarray=$(echo "$@")
  newarray=$(echo "$@")
  elements=$# - 1
  for (( i = 0; i <= $elements; i++ ));
    newarray[$i]=$[origarray[$i]] * 2
  done
  echo ${newarray[*]}
}

myarray=(1 2 3 4 5)
echo "The original array is: ${myarray[*]}"
arg1=${myarray[*]}
result=$(arraydbl $arg1)
echo $result
$./test12
The original array is: 1 2 3 4 5
The new array is: 2 4 6 8 10
```

The script passes the array value, using the $arg1 variable to the arraydbl function. The arraydbl reassembles the array into a new array variable, and it makes a copy for the output array variable. It iterates through the individual array variable values, doubles each value, and places it in the copy of the array variable in the function.

The arraydbl function then uses the echo statement to output the individual values of the array variable values. The script uses the output of the arraydbl to reassemble a new array variable with the values.
