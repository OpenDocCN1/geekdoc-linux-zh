## Adding Color

In the old days of Unix, script programmers were limited to monochrome terminals, so interactive shell scripts didn't have to worry about using colors. These days, with all of the fancy terminal emulation packages around, adding colors and special effects to your interactive scripts has almost become a necessity. This section discusses and demonstrates how to add special text features to your script output.

# Part III: Advanced Shell Scripting

## The ANSI escape codes

Most terminal emulation software recognizes the ANSI escape codes for formatting output. The ANSI escape codes begin with a control sequence indicator (CSI), which tells the terminal that the data represents an escape code, followed by data indicating the operation to perform on the display.

There are ANSI escape codes for positioning the cursor at a specific location on the display, erasing parts of the display, and what we're interested in is, controlling the display format. To control the display format, you must use the Select Graphic Rendition (SGR) escape codes. The format of an SGR escape code is:

```
CSI[k]m
```

The m in the code indicates the SGR escape code. The n and k parameters define which display control is used. You can specify just one parameter or two at the same time, separating them using the semicolon. There are three classes of display control parameters:

- Effect control codes
- Foreground color control codes
- Background color control codes

Table 15-1 shows the effect control codes available.

Thus, to set the display to use italic font, you send the code:

```
ESC[13m
```

## The ANSI SGR Effect Control Codes

| Code | Description |
|---|---|
| 0 | Reset to normal mode |
| 1 | Set to bold intensity |
| 2 | Set to faint intensity |
| 3 | Use italic font |
| 4 | Use single underline |
| 5 | Use slow blink |
| 6 | Use fast blink |
| 7 | Reverse foreground/background colors |
| 8 | Set foreground color to background color (invisible text) |

If you want to set the display to use italic font and blink, you send the code:

```
ESC[13;5m
```

The foreground and background color control codes use a two-digit code. Foreground colors use a two-digit value starting with a 3, while background colors use a two-digit value starting with a 4. The second digit in each denotes the specific color. Table 15-2 shows the color control codes available.

Thus, to specify a white foreground color, you send the code:

```
ESC[37m
```

which specifies the 3 to represent the foreground color and a 7 to specify the white color. To send a white background color, you'd use the code:

```
ESC[47m
```

You combine up to two attributes in each control code. Thus, to set the background color to black, and the foreground color to red, you'd send the code:

```
ESC[31;40m
```

Next, it's time to look at how to send the actual codes to the terminal.

## Displaying ANSI escape codes

Now that you know the ANSI escape codes, you're probably wondering how you can use them in your shell scripts. You can send the ANSI escape codes to the terminal session by using the echo command, just like normal text. The only tricky part is creating the CSI character.

| Code | Description |
|---|---|
| 0 | Black |
| 1 | Red |
| 2 | Green |
| 3 | Yellow |
| 4 | Blue |
| 5 | Magenta |
| 6 | Cyan |
| 7 | White |

The CSI character is normally a two-character sequence. This sequence is the ESC ASCII value, followed by the left square bracket. Creating the ESC ASCII value in a script can be a challenge.

Obviously you can't just hit the Esc key on your keyboard, since most text editors interpret it to something else. Fortunately, there's a common key sequence that most editors recognize allow you to insert the ESC ASCII value in your script. That's the Ctrl-v combination, followed by the Esc key. When you enter this key combination, the characters ^[ appear.

You'll often see the ^characters in scripts that use ANSI escape codes. When you see that character combination, remember that it is generated using the Ctrl-v ESC key.

So, a complete ANSI escape control code looks like:

```
ESC[...m
```
