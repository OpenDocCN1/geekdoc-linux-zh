One of my favorite features of the Kate editor is the built-in terminal window, shown in Figure 7-10.

The tab at the bottom of the text editor starts the built-in terminal emulator in Kate (using KDE Konsole emulator). This feature horizontally splits the current editing window, creating a new window with Konsole running in it. You can now enter command lines, start programs, or check on system settings without having to leave the editor To close the terminal, just type exit at the command prompt.

As you can tell from the terminal feature, Kate also supports multiple windows. The Window menu item provides options to:

+   Create a new Kate window using the current session
Split the current window vertically to create a new window
Split the current window horizontally to create a new window
Close the current window

To set the configuration settings in Kate, select the Configure Kate item under the Settings menu bar. The Configuration dialog box, shown in Figure 7-11, appears.
