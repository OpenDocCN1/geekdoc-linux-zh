# Performing Math

Another feature crucial to any programming language is the ability to manipulate numbers. Unfortunately, shell scripts this process is a bit awkward. There two different ways to perform mathematical operations in your shell scripts.

# The expr command

Originally, the Bourne shell provided a special command that was used for processing mathematical equations. The expr command allowed the processing of equations from the command line, but it is extremely clunky:

```
$ expr 1 + 5
```
