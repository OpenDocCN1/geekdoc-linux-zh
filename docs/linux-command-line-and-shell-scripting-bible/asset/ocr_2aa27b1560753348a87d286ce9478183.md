One way to get to a CLI is to take the Linux system out of graphical desktop mode and place it in text mode. This provides nothing more than a simple shell on the monitor, just like the days before graphical desktops. This mode is called the Linux console, as it emulates the old days of a hard-wired console terminal, and is a direct interface to the Linux system.

The alternative to being in the Linux console is to use a terminal emulation package from within the graphical desktop environment. A terminal emulation package simulates working on a dumb terminal, all within a graphical window over the desktop. Figure 2-1 shows an example of a terminal emulator running in a Linux desktop environment.

Each terminal emulation package has the ability to emulate one or more specific types of dumb terminal. If you're going to work with the shell in Linux, unfortunately you'll need to know a little bit about terminal emulation.

Knowing the core features of the dumb terminals will help you decide which emulation type to select when you're using a graphical terminal emulator, and all of the available features to their full capabilities. The main features used in the dumb terminal can be broken down into two areas: the graphics capabilities and the keyboard. This section describes these features and how they relate to the different types of terminal emulators.
