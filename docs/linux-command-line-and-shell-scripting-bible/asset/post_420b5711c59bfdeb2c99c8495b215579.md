
# Introducing sed and gawk

To terminate the gawk program, you must signal that the data stream has ended. The bash shell provides a key combination to generate an End-of-File (EOF) character. The Ctrl-D key combination generates an EOF character in bash. Using that key combination terminates the gawk program and returns you to a command line prompt.

# Using data field variables

As I mentioned, one of the primary features of gawk is its ability to manipulate data in the text file. It does this by automatically assigning a variable to each data element in a line. By default, gawk assigns the following variables to each data field it detects in the line of text:

- $0 represents the entire line of text.
- $1 represents the first data field in the line of text.
- $2 represents the second data field in the line of text.
- $n represents the nth data field in the line of text.

Each data field is defined in a text by a field separation character. When gawk reads a line of text, it delineates each data field using the defined field separation character. The default field separation character in gawk is a whitespace character (such as the tab or space characters).

To demonstrate this, here's an example gawk program that reads a text file and displays only the first data value:

```
$ cat data3
One line of test text.
Two lines of test text.
Three lines of test text.
$ awk '{print $1}' data3
One
Two
Three
$
```

This program uses the $1 field variable to display only the first data field for each line of text.

If you're reading a file that uses a different field separation character, you can specify it by the -F option:

```
$ awk -F: '{print $1}' /etc/passwd
root
bin
daemon
adm
lp
sync
shutdown
halt
...
```

# Using multiple commands in the program script

A programming language would not be very useful if you could only execute one command. The awk programming language allows you to combine commands into a normal program. To use multiple commands in the program script specified on the command line, just place a semicolon between each command:

```
$ echo "My name is Rich" | awk '{$4="Dave"; print $0}'
My name is Dave
$
```

The first command assigns a value to the $4 variable. The second command then prints the entire field. Notice from the output that the awk program replaced the fourth data field in the original text with the new value.

You can also use the secondary prompt to enter your script commands one line at a time:

```
$ awk '$(
> $4="testing"
> print $0'
This is not a good test.
This is not testing good test.
$
```

After you open the single quotation mark, the bash shell provides the secondary prompt for more data. You can add commands one at a time on each line until you are entering the single quotation mark. To exit the program, just press the Ctrl-D key combination to signal the end of the data.

# Reading the program from a file

Just as the sed editor, the awk editor allows you to store your programs in a file and refer to them in the command line:

```
$ cat script2
( print $5 "userid is $1"
$ awk -f script2 /etc/passwd
root's userid is root
bin's userid is bin
PostgreSQL Server's userid is postgres
FTP User's userid is ftp
GDM User's userid is gdm
HTDIG User's userid is htdig
```

postfix's userid is postfix

```

The script2 program script uses the print command to print the comment data field (field variable $5) of the /etc/passwd file, a short text message, then the userid data field (field variable $1).
