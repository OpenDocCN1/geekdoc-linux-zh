# Advanced if-then Features

There are two relatively recent additions to the bash shell that provide advanced features that you can use in if-then statements:

+   - Double parentheses for mathematical expressions
- Double square brackets for advanced string handling functions

The following sections describe each of these features in more detail.

# Using double parentheses

The double parentheses command allows you to incorporate advanced mathematical formulas in your comparisons. The test command only allows for simple arithmetic operations in the comparison. The double parentheses command provides more mathematical symbols that programmers from other languages are used to use in. The format of the double parentheses command is:

```
(( expression ))
```

The expression term can be any mathematical assignment or comparison expression. Besides the standard mathematical operators that the test uses, Table 9-4 shows the list of additional operators available for use in the double parentheses command.

You can use the double parentheses command in an if statement, as well as a normal command in the script for assigning values:

```
$ test23
#!/bin/bash
# using double parentheses

all=10

if (( $val ** 2 > 90 ))
then
  (( val2 = $val ** 2 ))
  echo "The square of $val is $val2"
```
