# Part III Advanced Shell Scripting

The CSI character is normally a two-character sequence. This sequence is the ESC ASCII value, followed by the left square bracket. Creating the ESC ASCII value in a script can be a challenge.

Obviously you can't just hit the Esc key on your keyboard, since most text editors interpret it to something else. Fortunately, there's a common key sequence that most editors recognize allow you to insert the ESC ASCII value in your script. That's the Ctrl-v combination, followed by the Esc key. When you enter this key combination, the characters ^[ appear.

You'll often see the ^[characters in scripts that use ANSI escape codes. When you see that character combination, remember that it is generated using the Ctrl-v ESC key

So, a complete ANSI escape control code looks like:

```
^[[0m
```

This specifies effect control 0, which resets the display to the default settings.

You can test ANSI escape control codes from your command line interface prompt:

```
$ echo[[41m is a test
This is a test
$
```

Of course, you can't tell from the book example, but this statement sets the background color to red on the terminal screen. The text appears in the default foreground color and with red as the background color. If you do this in your terminal emulator, you'll notice that after the shell prints the text from the echo command, the new prompt still uses the color control code. This is an important thing to remember.

> ANSI color control codes remain active until another ANSI color control code changes the output.

To solve this problem, it's a good idea to use the reset control code (0) to reset the terminal display to normal:

```
$ echo ^[[4mThis is a test^[[0m
This is a test
$
```

After this test, the new shell prompt reverts to its original color scheme.

The same applies to effect control codes:

```
$ echo ^[[1mThis is a test^[[0m
This is a test
$
```
