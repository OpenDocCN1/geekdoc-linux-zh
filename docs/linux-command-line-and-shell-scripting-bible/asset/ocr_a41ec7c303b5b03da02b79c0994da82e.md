# Part V Advanced Topics

This script will monitor the available disk space on a specific volume, and send out an e-mail message if the available disk space goes below a set threshold.

# The required functions

To automatically monitor the available disk space, you'll first need to use a command that can display that value. The best command to monitor disk space is the df command (see Chapter 4). The basic output of the df command looks like:

```
$ df
FileSystem K-blocks Used Available Use% Mounted on
/dev/hd1  3197228 2453980 508036 81% /\nvarrun     127544 100 127444 81% /var/run
varlock   127544 4 127540 1% /var/lock
udev       127544 44 127500 1% /dev
devshm    127544 0 127544 0% /dev
/dev/hd3  801636 139588 621328 19% /
```

The df command shows the disk statistics for all of the real and virtual disks on the system. For the purposes of this exercise, we'll monitor the size of the root filesystem. We'll first need to parse the results of the df command to extract only the line for the root filesystem.

There are a couple of different ways to do this. The easiest is to use the sed command to search for the line that ends with a forward slash:

```
/dev/hd1  3197228 2453980 508036 81% /
```

The sed script to build this uses the dollar sign (to indicate the end of the line), and the forward slash (which you'll need to escape since it's a sed special character). That will look like:

```
$ df | sed -n '\/\$/p'
/dev/hd1  3197228 2453980 508036 81% /
```

Now that you've got the statistics for the root filesystem, the next step is to isolate the percentage value used in the line. To do that, you'll need to use the awk command:

```
$ df | sed -n '\/\$/p' | awk '{print $5}'
81%
```

This is close, but there's still one small problem. The awk command let you out the fifth data field, but the value also includes the percent symbol. You'll need to remove that so you can use the value in a mathematical expression. That's easily accomplished by using the sed command:

```
$ df | sed -n '\/\$/p' | awk '{print $5}' | sed 's/%//'
81
```

Now you're in business! The next step is to use this information to create the script.
