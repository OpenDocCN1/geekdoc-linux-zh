# Time functions

The awk programming language contains a few functions to help you deal with time values, shown in Table 19-6.

The time functions are often used when working with log files that contain dates that you need to compare. By converting the text representation of a date to the epoch time (the number of seconds since January 1, 1970) you can easily compare dates.

Here's an example of using the time functions in a gaw program:

```
$ awk 'BEGIN{
> date = system()
> day = strftime("%A, %B %d, %Y")
> print day
> }'
Friday, December 28, 2002
$
```

TABLE 19-6

| Function | Description |
| --- | --- |
| mktime(datespec) | Converts a date specified in the format YYYY MM DD HH SS [DST] to a timestamp value. |
| strftime(format [, timestamp]) | Formats either the current time of day timestamp, or timestamp if provided, into a formatted day and date, using the date() shell format. |
| system() | Returns the timestamp for the current time of day. |
