Using this technique, you can both save data in files and display the data on the monitor for your users:

```
$ cat test22
!/bin/bash
# using the tee command for logging

tempfile=test22file

echo "This is the start of the test" | tee $tempfile
echo "This is the second line of the test" | tee -a $tempfile
echo "This is the end of the test" | tee -a $tempfile
$ ./test22
This is the start of the test
This is the second line of the test
This is the end of the test
$ cat test22file
This is the start of the test
This is the second line of the test
This is the end of the test
$
```

Now you can save a permanent copy of your output at the same time that you're displaying it to your users.

## Summary

Understanding how the bash shell handles input and output can come in handy when creating your scripts. You can manipulate how the script receives data and how it displays data, to customize your script for any environment. You can redirect the input of a script from the standard input (STDIN) to any file on the system. You can also redirect the output of a script from the standard output (STDOUT) to any file on the system.

Besides the STDOUT, you can redirect any-error messages your script generates, by redirecting the STDERR output. This is accomplished by redirecting the file descriptor associated with the STDERR output, which is file descriptor 2. You can redirect STDERR to the same file as the STDOUT output or to a completely separate file. This enables you to separate normal script messages from any error messages generated by the script.

The bash shell allows you to create your own file descriptors for use in your scripts. You can create file descriptors 3 through 9 and assign them to any output file you desire. ## Generating signals

The bash shell allows you to generate signals. If you need to stop a process, you can send it a SIGINT signal. If you need to pause a process, you can send it a SIGSTOP signal. If you need to terminate a process, you can send it a SIGKILL signal.

## Interrupting a process

The Ctrl-C combination generates a SIGINT signal, which interrupts the current process. This is useful when you have a program that is taking too long or you want to stop it.

```
$ sleep 100
```

## Pausing a process

The Ctrl-Z combination generates a SIGTSTP signal, which pauses the process. This allows you to stop a program in the middle of its execution and come back to it later.

```
$ sleep 100
[1]+ Stopped sleep 100
```
