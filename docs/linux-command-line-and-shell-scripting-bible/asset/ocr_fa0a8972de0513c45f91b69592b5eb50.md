# Basic bash Shell Commands

On my Fedora Linux system, it looks like this:

```
[rich@testbox ~]$
```

You can configure the prompt to provide basic information about your environment. The first example above shows three pieces of information in the prompt:

+   - The username that started the shell
- The current virtual console number
- The current directory (the tilde sign is shorthand for the home directory)

The second example provides similar information, except it uses the hostname instead of the virtual console number. There are two environment variables that control the format of the command line prompt:

+   - PS1: Controls the format of the default command line prompt
- PS2: Controls the format of the second-tier command line prompt

The shell uses the default PS2 prompt for initial data entry into the shell. If you enter a command that requires additional information, the shell displays the second-tier prompt specified by the PS2 variable.

To display the current settings for your prompt, use the echo command:

```
rich[1~]$ echo $PS1
\u@1[W]\$
rich[1~]$ echo $PS2
>
rich[1~]$
```

The format of the prompt environment variables can look pretty odd. The shell uses special characters to signify elements within the command line prompt. Table 3-2 shows the special characters that you can use in the prompt string.

Notice that all of the special prompt characters begin with a backslash (\). This is what delineates a prompt character from normal text in the prompt. In the earlier example, the prompt contains both prompts and a normal character (the "@" sign, and the square brackets). You can create any combination of prompt characters in your prompt. To create a new prompt, just assign a string to the PS1 variable:

```
rich@testbox ~]$ PS1="[\t][\u]$
[14:40:32]$rich]$
```

This new prompt now shows the current time, along with the username. The new PS1 definition only lasts for the duration of the shell session. When you start a new shell, the default shell prompt definition is reloaded. In Chapter 5 you'll see how you can change the default shell prompt for all sessions.
