variable by one. When you've reached the end of the getopts processing, you can just use the OPTIND with the shift command to move to the parameters:

```
$ cat test20
!/bin/bash
# processing options and parameters :ab:cd opt

while getopts :ab:cd opt

    case "$opt" in
        a) echo "Found the -a option"; ::
        b) echo "Found the -b option, with value $OPTARG";
        c) echo "Found the -c option"; ::
        d) echo "Found the -d option"; ::
        *) echo "Unknown option: $opt";
    esac
done
shift $ $OPTIND - 1

count=1
for param in "$@"
done
    echo "Parameter $count: $param"
    count=$[$count + 1]
done
$ ./test20 -a -b test1 -d test2 test3 test4
Found the -a option
Found the -b option, with value test1
Found the -d option
Parameter 1: test2
Parameter 2: test3
Parameter 3: test4
$ 
```

Now you have a full-featured command line option and parameter processing utility you can use in all of your shell scripts.
