# Using Patterns

The awk program supports several types of matching patterns to filter data records, similar to how the sed editor does. Chapter 16 already showed two special patterns in action. The BEGIN and END keywords are special patterns that execute statements before or after the data stream has been read. Similarly, you can create other patterns to execute statements when matching data appears in the data stream.

This section demonstrates how to use matching patterns in your awk scripts to limit what records a program script applies to.

# Regular expressions

Chapter 17 showed how to use regular expressions as matching patterns. You can use either a Basic Regular Expression (BRE) or an Extended Regular Expression (ERE) to filter lines in the data stream the program script applies to.

When using a regular expression, the regular expression must appear before the left brace of the program that it controls:

```
$ awk 'BEGIN(FS="=") /11/(print $1)' datal
datal
```

The regular expression /11/ matches records that contain the string 11 anywhere in the data fields. The awk program matches the defined regular expression against all the data fields in the record, including the field separator character:

```
$ awk 'BEGIN(FS="=") /.d/(print $1)' datal
datal
```
