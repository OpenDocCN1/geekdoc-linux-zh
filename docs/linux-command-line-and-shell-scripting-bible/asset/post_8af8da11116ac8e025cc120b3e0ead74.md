## The ulimit command

The ulimit command is a great addition to the dash shell. It allows you to restrict system resources to prevent overuse in the shell. The limits you apply to the shell from which the ulimit command is run.

There are two types of limits you can use in the dash shell:

- A soft limit, which can be reset by the owner user account for the shell.
