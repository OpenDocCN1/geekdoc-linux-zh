Common control code functions are the carriage return (return the cursor to the beginning of the line), line feed (put the cursor on the next horizontal row), horizontal tab (shift the cursor over a preset number of spaces), arrow keys (up, down, left, and right), and the page up/page down keys. These control codes mainly emulate features that the cursor is placed on the monitor, there are also other control codes, as clearing the entire screen, and even a bell ring (emulating the old typewriter end-of-carriage bell).

Control codes were also used in controlling the communication features of dumb terminals. Dumb terminals were connected to the computer system via some type of communication channel, often a serial communication channel. Times deata were needed on the communication channel, so developers devised special control codes for data communication purposes. While these codes are not necessarily required in modern terminal emulators, many support these codes to maintain compatibility. The most common codes in this category are the XON and XOFF codes, which start and stop data transmission to the terminal.

# Block mode graphics

As dumb terminals became more popular, manufacturers started experimenting with rudimentary graphics capabilities. By far the most popular type of "graphical" dumb terminal used in the Unix world was the DEC VT22 series of terminals. The turning point for dumb terminals came with the release of the DEC VT100 in 1978. The DEC VT100 was the first terminal to support the complete ANSI character set, including block mode graphics characters.

The ANSI character set contains codes that not allowed monitors to display text but also rudimentary graphics symbols, as boxes, lines, and blocks. By far one of the most popular dumb terminals used in Unix operations during the 1980s were the VT102, an upgraded version of the VT100. Most terminal emulation programs emulate the operation of the VT102 display, supporting all of the ANSI codes for creating block mode graphics.

# Vector graphics

The Tektronix produced a series of terminals that used a display method called vector graphics. Vector graphics deviated from the DEC method of block mode graphics making all screen images (including characters) a series of line segments (vectors). The Tektronix 4010 terminal was the most popular graphical dumb terminal produced. Many terminal emulation packages still emulate its capabilities.

The 4010 terminal displays images by drawing a series of vectors using an electron beam, like drawing with a pencil. Since vector graphics does not use to create lines, it has the ability to draw geometric shapes with higher precision than most dot-oriented graphics terminals. This was a popular feature among mathematicians and scientists.
