SOURCE=/home/rich/test

The script retrieves the day and month values from the command line, along with the times-used to uniquely identify the archive file. It uses that information to create the archive directory for the day (or just enlist if it already exists). Finally, the script uses the tar and gzip commands to create the archive and compress it.

# Storing backups off-site

While creating archives of important files is a good idea, it's certainly no replacement for a full backup that's stored in a separate location. In large Linux systems, administrators often have the luxury of tape drives to copy important files of the server for safe storage.

For smaller entities this is not always an option. Just because you can't afford a fancy backup system doesn't mean you have to have your important data at risk. You can put together a shell script that automatically creates an archive file, then sends it outside of the Linux system. This section describes how to do that.
