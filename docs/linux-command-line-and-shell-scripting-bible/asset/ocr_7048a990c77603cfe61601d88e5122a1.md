The asterisk wildcard character allows you to list only files that match a certain criteria. For example:

```
$ ls -al da*\n-rw-r--r-- 1 rich rich 45 Nov 26 12:42 data
-rw-r--r-- 1 rich rich 25 Dec 4 12:40 data.tst
-rw-r--r-- 1 rich rich 180 Nov 26 12:42 datal
-rw-r--r-- 1 rich rich 45 Nov 26 12:44 data2
-rw-r--r-- 1 rich rich 73 Nov 27 12:31 data3
-rw-r--r-- 1 rich rich 79 Nov 28 14:01 data4
-rw-r--r-- 1 rich rich 187 Dec 4 09:45 datatest
```

The da* parameter instructs the ls command to list only the files whose name starts with da. There can be any number of characters after the da in the filename (including none). The command reads the information regarding all of the files in the directory but only displays the ones that match the wildcard character.

Regular expression wildcard patterns work in a similar way. The regular expression patterns contain text and/or special characters that define a template for the sed editor and the gawk program to follow when matching data. There are different special characters you can use in a regular expression to define a specific pattern for filtering data.
