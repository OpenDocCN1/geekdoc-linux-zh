Notice in this example I did something different in the if statements:

```
if [ -d "$file" ]
```

In Linux it's perfectly legal to have directory and filenames that contain spaces. To accommodate that, you should include the $file variable in double quotation marks. If you don't, you'll get an error if you run into a directory or filename that contains spaces:

+   - /test6: line 6: [: too many arguments
- /test6: line 9: [: too many arguments

The bash shell interpret the additional words as arguments within the test command, causing an error.
