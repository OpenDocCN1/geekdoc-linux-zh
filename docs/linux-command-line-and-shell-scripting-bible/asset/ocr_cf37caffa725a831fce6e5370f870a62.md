# The do-while statement

The do-while statement is similar to the while statement but performs the statements before checking the condition statement. The format for the do-while statement is:

```
do
  statements
  while (condition)
```

This format guarantees that the statements are executed at least one time before the condition is evaluated. This comes in handy when you need to perform statements before evaluating the condition:

```
$ awk '
> total = 0
> i = 1
> do
>   total += $i
>   i++
> ) while (total < 150)
> print total ' data5

160
315
5
```

The script reads the data fields from each record and totals them until the cumulative value reaches 150. If the first data field is over 50 (as seen in the second record), the script is guaranteed to read at least the first data field before evaluating the condition.
