The transform command is a global command, that is, it performs the transformation on any character found in the line automatically, without regard to the occurrence:

```
$ echo "This 1 is a test of 1 try." | sed 'y/123/456/'
This 4 is a test of 4 try.
$
```

The editor transformed both instances of the matching character 1 in the text line. You can't limit the transformation to a specific occurrence of the character.

## Printing revisited

The "Substitution Options" section showed how to use the p flag with the substitution command to display lines that the editor changed. There are three commands that also can be used to print information from the data stream:

- The lowercase p command to print a text line
- The equal (=) command to print line numbers
- The 1 (lowercase L) command to list a line

The following sections look at each of these three printing commands in the sed editor.

## Printing lines

Similarly to the p flag in the substitution command, the p command prints a line in the sed editor output. On its own, it's not much exciting:

```
$ echo "this is a test" | sed 'p'
this is a test
this is a test
$
```

All it does is print the data that you already know is there. The most common use for the print command is printing lines that contain matching text from a text pattern:

```
$ sed -n '/number 3/p' data6
This is line number 3.
$
```

By using the -n option on the command line, you can suppress all of the other lines and only print the line that contains the matching text pattern.

You can also use this as a quick way to print a subset of lines in a data stream:

```
$ sed -n '2,3p' data6
This is line number 2.
```

Another use for the print command is when you need to see a line before it gets altered, such as with the substitution or change command. You can create a script that displays the line before it's changed:

```
$ sed -n '/3/l
p
s/line/test/p
' data6
This is line number 3.
This is test line number 3.
$
```

This sed editor searches for lines that contain the number 3, then executes two commands. First, the script uses the p command to print the original version of the line, then it uses the s command to substitute text, along with the p flag to print the resulting text. The output shows both the original line text and the new line text.

## Printing line numbers

The equal sign command presents the current line number for the line within the data stream. Line numbers are determined by the newline character in the data stream. Each time a newline character appears in the data stream, the sed editor assumes that it terminates a line of text.

The basic use of the equal sign command isn't too exciting:

```
$ sed '=' datal
1
The quick brown fox jumps over the lazy dog.
2
The quick brown fox jumps over the lazy dog.
3
The quick brown fox jumps over the lazy dog.
4
The quick brown fox jumps over the lazy dog.
$
```

The sed editor prints the line number before the actual line of text. The equal sign command comes in handy if you're searching for a specific text pattern in the data stream:

```
$ sed -n '/number 4/l
=
p
' data6
4
This is line number 4.
$
```

## Listing lines

The list command (l) allows you to print both the text and nonprintable ASCII characters in a data stream. Any nonprintable characters are shown using either their octal values, preceded by a backslash, or the standard C-style nomenclature for common nonprintable characters, such as \t for tab characters:

```
$ cat data8
This line contains tabs.
$ sed -n '1' data8
This$line\tcontains\tabs.
$
```

The tab characters are shown with the \t nomenclature. The dollar sign at the end of the line indicates the newline character. If you have a data stream that contains an escape character, the list command displays it using the octal code:

```
$ cat data9
This line contains an escape character
$ sed -n '1' data9
This line contains an escape character \033[44m$
$
```

The data9 file contains an escape control code (see Chapter 15) to change the display color. When you use the cat command to display the text file, you don't see the escape control code; it just changes the color of the display.

However, using the list command you can display the escape control code used. The \033 is the octal value of the ASCII code for the escape key.

## Using files with sed

The substitution command contains flags that allow you to work with files. There are also regular sed commands that let you do without having to substitute text.

## Writing to a file

The w command is used to write lines to a file. The format for the w command is:

```
[address]w filename
```

The filename can be specified as an absolute or relative pathname. The address can be a line number, a text pattern, or a range of lines.

The w command writes lines to a file. Here's an example that prints only the first two lines of a data stream to a file:

```
$ sed -n '1,2w test' data6
This is line number 1.
This is line number 2.
$
```

Of course, if you don't want the lines on STDOUT, you can use the -n option. The sed editor writes to a file only the lines that match the pattern.

```
$ sed -n '/pattern/w filename' file
```

## Reading data from a file

You've already seen how to insert and append text to a data stream. The command (r) allows you to insert data from a file. The format of the read command is:

```
[address]r filename
```

The filename specifies either an absolute or relative pathname. You can't use a range of addresses for the read command. You can only specify a single line number or text address. The sed editor inserts the text from the file after the address.

```
$ cat dataall
This is line line.
This is the second line.
This is line number 3.
This is line number 4.
$ sed '3r dataall' data6
This is line number 1.
This is line number 2.
This is line number 3.
This is the second line.
This is line number 4.
$
```

The sed editor inserts into the data stream all of the text lines in the data file. The same technique works when using a pattern address:

```
$ sed '/number 2/r dataall' data6
This is line number 1.
This is line number 2.
This is line line3.
This is the second line.
This is line number 3.
This is line number 4.
$
```

If you want to add text to the end of a data stream, just use the dollar sign address symbol:

```
$ sed '$r dataall' data6
This is line number 1.
This is line number 2.
This is line number 3.
This is line number 4.
This is line line3.
This is the second line.
$
```

A cool application of the read command is to use it in conjunction with a delete command to replace a placeholder in file with data from another file. For example, suppose that you had a form letter stored in a text file that looked like this:

```
$ cat letter
Would the following people:
LIST
please report to the office.
$
```

The form letter uses the generic placeholder LIST in place of a list of people. To insert the list of people after the placeholder, all you need to do is use the read command. However, this still leaves the placeholder text in the output. To remove that, just use the delete command. The result looks like this:

```
$ sed '/LIST/(
> r data10
> d
```
