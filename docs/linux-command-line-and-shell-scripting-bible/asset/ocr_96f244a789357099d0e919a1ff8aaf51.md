# Getting to the Shell

# The current screen commands

The current screen commands section sends commands to the xterm emulator that affect which screen is the currently active screen.

+   - Show Tek Window: Display the Tektronix terminal window along with the VT100 window.
- Switch to Tek Window: Hide the VT100 terminal window and display the Tektronix terminal window.
- Hide VT Window: Hide the VT100 terminal window while displaying the Tektronix terminal window.
- Show Alternate Screen: Display the data stored in the VT100 alternate area.

The xterm emulator provides the ability to start in either VT100 terminal mode (default) or in the Tektronix terminal mode (using the t command line parameter). After you start in either mode, you can use this menu to switch to the other mode during your session.

# The VT fonts menu

The VT fonts menu sets the font style used in the VT100/220 emulation mode. You can access this menu by holding the Control key and clicking on mouse button (the right button on a right-handed mouse, or the left button on a left-handed mouse). Figure 2-6 shows what the VT fonts menu looks like.
