Each of these packages allows you to interact with your local Linux mailbox, as we connect to remote servers to read mail messages. Figure 26-4 shows a sample KMail session.

To connect to remote servers, both KMail and Evolution support the Post Office Protocol (POP), and the more advanced Internet Message Access Protocol (IMAP). While the KMail and Evolution MUA programs are great for desktop Linux, they aren't so useful in shell scripting.

# Setting Up Your Server

Before you can start sending your automated e-mail messages off the universe, you'll need to ensure that your Linux system has an MTA package running and it's configured correctly. This is no small task in itself, but fortunately, some Linux distributions provide some basic tools to help you out.
