# The sed Editor Basics

The key to successfully using the sed editor is knowing its myriad commands and formats, which are available to customize your text editing. This section describes some of the basic commands and features you can incorporate into your script to start using the sed editor.

# More substitution options

You've already seen how to use the s command to substitute new text for the text in a line. However, there are a few other options available for the substitute command that can help make your life easier.

# Substitution flags

There's a caveat to what the substitute command replaces matching patterns in the text string. Watch what happens in this example:

```
$ cat data4
This is a test of the test script.
This is the second test of the test script.
$ sed 's/test/trial/' data4
This is a trial of the test script.
This is the second trial of the test script.
$
```

The substitute command works fine in replacing in multiple lines, but by default it replaces the first occurrence in each line. To get the substitute command to work on different occurrences of the text, you must use a substitution flag. The substitution flag is set after the sub-command strings:

```
$s/pattern/replacement/flags
```

+   - A number, indicating the pattern occurrence for which new text should be substituted.
- g — Indicates that new text should be substituted for all occurrences of the existing text.
- p — Indicates that contents of the original line should be printed.
- w file — Write the results of the substitution to a file.

In the first substitution, you can specify which occurrence of the matching pattern the sed editor should substitute with new text for:

```
$ sed 's/test/trial/2' data4
This is a test of the trial script.
This is the second test of the trial script.
$
```
