# Presenting Data

```
echo "This is a test file." > $tempfile
echo "This is the second line of the test." >> $tempfile
echo "The temp file is located at: $tempfile"
cat -f $tempfile
./test20
temp file is located at: /tmp/tmp.Ma3390
This is a test file.
This is the second line of the test.
$
```

When mtemp creates the temporary file, it returns the full pathname to the environment variable.
You then use that value in any command to reference the temporary file.

# Creating a temporary directory

The -d option allows the mtemp command to create a temporary directory instead of a file. You can use that directory for whatever purposes you need, such as creating additional temporary files:

```
cat test21
!/bin/bash
# using a temporary directory
tempdir=`mtemp -d dir.XXXXXX`ncd $tempdir
tempfile1=`mtemp temp.XXXXXX`
tempfile2=`mtemp temp.XXXXXX`
exec 7 > $tempfile1
exec 8 > $tempfile2
```

```
echo "Sending data to directory tempdir"
echo "This is a test line of data for $tempfile1" >&7
echo "This is a test line of data for $tempfile2" >&8
$../test21
sending to directory dir.outT8S
ls -al
```
