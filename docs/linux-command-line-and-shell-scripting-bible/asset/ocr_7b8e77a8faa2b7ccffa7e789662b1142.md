# Part III Advanced Shell Scripting

You should recognize a few of variables from your shell script programming. The ARGC and ARGV variables allow you to retrieve the number of command line parameters and their values from the shell. This can be a little tricky though, as awk doesn't count the program script as part of the command line parameters.

```
$ awk 'BEGIN(print ARGC,ARGV[1])'
2 data1
$
```

The ARGC variable indicates that there are two parameters on the command line. This includes the awk command parameter (remember, the program script doesn't count as a parameter). The ARGV array starts with an index of 0, which represents the command. The first array value is the first command line parameter after the awk command.

> NOTE Note that unlike shell variables, when you reference a awk variable in the script, you don't add a dollar sign before the variable name.

The ENVIRONMENT variable may seem a little odd to you. It uses an associative array to retrieve environment variables. An associative array uses text for the array index instead of numeric values.

The text in the array index is the shell environment variable. The value of the array is the value of the shell environment variable. Here's an example of this:

```
$ awk '
> BEGIN[
> print ENVIRONMENT["HOME"]
> print ENVIRONMENT["PATH"]
> ]'\n/home/rich
/usr/local/bin:/bin:/usr/bin:/usr/X11R6/bin
$
```

ENVIRONMENT["HOME"] retrieves the environment variable value from the shell. Likewise, ENVIRONMENT["PATH"] retrieves the PATH environment variable value. You can use this technique to retrieve any environment variable value from the shell to use in your awk programs.

The FNR, NR, and NF variables are handy when you're trying to keep track of data fields and records in your awk program. Sometimes you're in a situation where you don't know how many data fields are in a record. The NF variable allows you to specify the last data field in record without knowing its position.

```
$ awk 'BEGIN(FS=":") OFS=":") {print $1,$NF}' /etc/passwd
rich:/bin/bash
testy:/bin/csh
mark:/bin/bash
dan:/bin/bash
```
