# Grabbing all the data

There are situations where you'll want to grab all of the parameters provided on the command line and iterate through all of them. Instead of having to mess with using the $$ variable to determine how many parameters are on the command line, having to loop through all of them, you can use a couple of special variables.

The $* and $$ variables provide one-stop hitting for all of your parameters. Both of these include all of the command line parameters within a single variable.

The $* variable takes all of the parameters supplied on the command line as a single word. The word contains each of the values as they appear on the command line. Basically, instead of treating the parameters as multiple objects, the $* treats them all as one parameter.

The $$ variable on the other hand, takes all of the parameters supplied on the command line as separate words in the same string. It allows you to iterate through the value, separating out each parameter supplied. This is most easily accomplished using the for command.

It can easily get confusing as to how these two variables operate. If you take them at face value, you won't even see the difference:

```
$ cat test11
#!/bin/bash
# testing $* and $$
```
