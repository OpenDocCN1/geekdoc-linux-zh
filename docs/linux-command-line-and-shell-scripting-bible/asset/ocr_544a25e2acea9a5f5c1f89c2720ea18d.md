You'll also notice that similarly to the tsh shell, the ksh93 shell supports using standard mathematical operators when comparing numerical values.

> NOTE ksh93 shell also supports the bash-style numerical comparators (such as gt, -lt, and -eq), they're considered obsolete and may go away in future versions of the

The ksh93 uses the same file and directory tests as the bash shell, such as -d for directories, -f for readable, and -x for executable. Here's an example using the directory comparison symbols.

```
$ cat test3
#!//bin/ksh93
# testing the non-math comparison
```

```
if [ -d $HOME ]] && [[ -f $HOME/testing ]] then
    print "The file exists.
else
    print "Sorry, the file doesn't exist.
fi
./test3
Sorry, the file doesn't exist.
$ touch $HOME/testing
./test3
The file exists.
$
```

You can also see from this example that the ksh93 shell supports the use of logical AND (&&) symbols. It also supports logical OR (|) as well.
