# Summary

This chapter discussed working in an ash shell environment. The ash shell is not a common shell you'll find in Linux distributions, but it does appear in the NetBSD and FreeBSD Unix distributions. A derivative of the ash shell is the dash shell, which is used in many Debian-based Linux distributions, although not as as a login shell.

The ash and dash shells are smaller versions of the Bourne shell, so they don't support as many features as the bash shell. You need to take this into consideration if you're writing shell scripts that may be used in an ash or dash shell environment.
