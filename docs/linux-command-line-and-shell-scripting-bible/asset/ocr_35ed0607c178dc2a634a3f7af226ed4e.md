zip [-options] [-b path [-t mmddyyyy] [-n suffixes] [zipfile]
[-xi list]

The default action is to add or replace zip entries from list,
which can include the special name - to compress standard input.
If zipfile is omitted, zip compresses stdin to stdout.

+   - f freshen: only changed files -u update: only changed or new files
- d delete entries in zipfile -m move into zipfile (delete files)
- r recurse into directories -j junk directory names
- 0 store only -c Convert LF to CR
- 1 compress faster -9 compress better
- q quiet operation -v verbose operation
- c add one line comments -z add zip file
- @ read names from stdin -o make file as old as last latest entry
- x exclude the following names -i include only these entries
-f fix zipfile (-F try harder) -d do not add directory entries
-j junk file prefix (unzipsfx)
-T test zipfile integrity -X exclude Extra file attributes

A adjust self-extracting exe
-y store symbolic links as the link instead of the referenced file
-R (zip) recursion (see manual)
-n don't compress these suffixes
$ 

The power of the utility is in its ability to compress entries of files into a single pressed file. This makes it ideal for archiving directory structures:

```
$ zip -r testzip
adding: test/ (stored 0%)
adding: test/test1/ (stored 0%)
adding: test/test1/myprog2 (stored 0%)
adding: test/test1/myprog1 (stored 0%)
adding: test/myprog.c (deflated 39%)
adding: test/file3 (deflated 2%)
adding: test/file4 (stored 0%)
adding: test/test2/ (stored 0%)
adding: test/file1.gz (stored 0%)
adding: test/file2 (deflated 4%)
adding: test/myprog.gz (stored 0%)
$ 
```

This example creates the zip file testzip.zip, and recurs through the directory test, adding each file and directory found to the zip file. Notice the output that not all of the files stored in the zip file were compressed. The zip utility automatically determines the best compression type to use for each individual file.

> CAUTION When you use the recursion feature in the zip command, files are stored in the same directory structure in the zip file. Files contained in subdirectories are not zip when extracting the files, the unzip command will rebuild the entire directory structure in the new location. Sometimes this gets confusing when you have lots of subdirectories and files.
