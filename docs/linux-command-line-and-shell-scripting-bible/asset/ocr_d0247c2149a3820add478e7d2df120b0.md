# The Korn Shell

The -l and -u parameters work great in converting strings on the fly:

```
$ types -u testing
$ testing="This is a test"
$ echo $testing
THIS IS A TEST
$
```

It doesn't get any easier than that!

Use the -n parameter to allow one variable to reference the value in a separate variable. This can get confusing, so be careful when using it. Here's an example of how this works:

```
$ ntest1=100
$ typeset -n ntest1=ntest2
$ ntest2=1
$ echo $ntest1
1
$ ntest1=100
100
$ echo $ntest2
$
```

The typeset command forces the ntest1 variable and the ntest2 variable to reference the same memory location. Whatever value you assign to one, the other one also references. When I assigned a value of 1 to the ntest2 variable, it replaced the existing value in ntest1. When I displayed the value of the ntest1 variable, it showed the same value as assigned to ntest2. The same applied to ntest2 when I assigned a value to the ntest1 variable.

# Using arrays

Just like the bash shell, the ksh93 supports the use of numerical array variables:

```
$ mytest=(one two three five)
$ echo $mytest
one
$ echo \${mytest[2]}
tree
$ echo \${mytest[*]}
one two three five
$
```

The ksh93 also supports associative arrays. Associative arrays allow you to use strings as the index values instead of numbers. Before you can define the values in an associative array, you must declare the variable you'll use. You do that with the typeset command:

```
$ typeset -A test2
$
```
