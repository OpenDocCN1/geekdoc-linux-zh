# The zsh shell

+   - **global.rc**: If not set, the zsh shell doesn't run the global startup files, but it still runs local startup files.

+   - **rc**: If not set, the zsh shell runs /etc/zhenv startup file, but no others.

The initialization options allow you to specify which (any) zsh shell startup files are run in your shell environment. You can also set these values within startup files themselves to limit which ones the shell executes.

# Scripts and functions

The scripts and functions allow you to customize the shell scripting environment in the zsh shell. This is a handy way to set the way functions perform within the shell.

+   - **c_bases**: Display hexadecimal numbers in C format (0xddddd) instead of shell format (16#ddddd)

+   - **err_exit**: If a command exits with a non-zero exit status, perform the command in the ZERR trap and exit.

+   - **err_return**: If a command has a non-zero exit status, return immediately from the enclosing function.

+   - **eval_line**: If set, the line numbers of expressions evaluated using the eval built-in command are tracked separately from the rest of the shell environment.

+   - **exec**: Execute commands. If this option isn't set, read commands and report errors, but don't execute the commands.

+   - **function_argzero**: Set $0 to the name of the function or script.

+   - **local_options**: If set, when a function returns, all of the options that were set before the function are restored.

+   - **local_traps**: If set, when a signal trap is set within a function, the previous status of the trap is restored when the function exits.

+   - **multios**: Perform implicit tees or cats when multiple redirections are attempted.

+   - **octal_zeros**: Interpret any integer string starting with a zero as an octal number.

+   - **typeset**: If not set, using typeset with the name of a parameter displays the current value of the parameter.

+   - **verbose**: Displays input lines as they are read by the shell.

+   - **xtrace**: Displays commands and their arguments as the shell executes them.
