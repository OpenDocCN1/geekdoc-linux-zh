# The Linux Command Line

. .bashrc file does two things. First, it checks for a common bashrc file in the /etc directory. Second, it provides a place for the user to enter personal aliases (discussed later in the Using Command Aliases section) and private script functions (described in Chapter 14).

The common /etc/bashrc startup file is run by everyone on the system who starts an interactive session. On your Linux distribution it looks like this:

```
$ cat /etc/bashrc
# /etc/bashrc
```

# Environment setup goes in /etc/profile

```
# By default, we want this to get set.
# Even for non-interactive, non-login shells.
if [ $UID -gt 99 ] && [ "id -gn" = "id-un" ]; then
    umask 022
else
    umask 022
fi

# are we an interactive shell?
if [ "$PS1" ]; then
    case $TERM in
        if [ -e /etc/sysconfig/bash-prompt-xterm ]; then
            PROMPT_COMMAND=/etc/sysconfig/bash-prompt-
xterm
        else
            PROMPT_COMMAND='echo -ne\n\[033]0;$(USER)@$(HOSTNAME%%.*):$(PWD/#$HOME~)\'; echo -ne '\[007\'
            fi
        ::)
        if [ -e /etc/sysconfig/bash-prompt-screen ]; then
            PROMPT_COMMAND=/etc/sysconfig/bash-prompt-
screen
        else
            PROMPT_COMMAND='echo -ne\n\[033]_\$(USER)@$(HOSTNAME%%.*):$(PWD/#$HOME~)\'; echo -ne '\[033]\*'
            fi
        *)
        if [ -e /etc/sysconfig/bash-prompt-default ] &&
            PROMPT_COMMAND=/etc/sysconfig/bash-prompt-default
        ::
    esac
# Turn on checkwinsize
shopt -s checkwinsize
```
