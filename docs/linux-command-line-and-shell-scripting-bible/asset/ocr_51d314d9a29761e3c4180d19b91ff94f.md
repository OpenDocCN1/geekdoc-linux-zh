This section walks you through the basics of the two most popular e-mail MTA programs used in Linux: sendmail and Postfix. While there have been complete books written on properly configuring each of these packages, we'll just look at the basics of how to get e-mails off the Linux system and into your inbox.

# sendmail

The sendmail MTA package is one of the most popular open source MTA packages used by Internet mail servers. In the past it has been plagued with stories about backdoors and security flaws; however, it has been rewritten not only to remove the security flaws but also to incorporate many newer MTA features such as spam control. The newer versions of the sendmail program have proven to be secure as well as versatile.

# Parts of the sendmail program

The main executable program is called sendmail. It normally runs in background mode, listening for SMTP connections from mail servers, and forwarding messages from local users.

Unless you're running the main mail server for a corporation or Internet service provider, you'll need to worry about the sendmail.cf configuration file. In fact, many Linux distributions use sendmail default and configure a core sendmail.cf configuration file for you automatically that should work fine in most simple applications.

# The sendmail.cf file

The sendmail program needs to be told how to handle messages as they receive them. As an MTA, sendmail processes incoming mail and redirects it to another mail package, either on a remote system or on the local system. The configuration file is used to direct sendmail how to manipulate the destination mail addresses to determine where and how to forward the messages. The default location for the configuration file is /etc/mail/sendmail.cf.

The sendmail.cf file consists of rule sets that parse the incoming mail message and determine what actions to take. Each rule is used to identify certain mail formats and instruct sendmail how to handle that message.

As the sendmail program receives a message, it parses the message header and passes the message through the various rules to determine an action to take on the message. The configuration file includes rules that allow sendmail to handle mail in many different formats. Mail received from an SMTP host has different header fields than mail received from a local user. The sendmail program must know how to handle any mail situation.
