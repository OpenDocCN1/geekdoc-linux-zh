If you've already used emacs in console mode, you should be fairly familiar with the X Windows mode. All of the key commands are available as menu items. The emacs menu contains the following:

+   - File allows you to open files in the window, create new windows, close windows, save buffers, and print buffers.
- Edit allows you to cut and copy selected text to the clipboard, paste clipboard data to the current cursor position, search for text, and replace text.
- Options provides settings for many more emacs features, such as highlighting, word wrap, cursor type, and setting fonts.
- Buffers lists current buffers available and allows you to easily switch between areas.
- Tools provides access to the advanced features in emacs, such as the command line interface, spell checking, comparing text files (like diff), sending an e-mail message, calendar, and the calculator.
- Help provides the emacs manual online for access to help on specific emacs functions.
