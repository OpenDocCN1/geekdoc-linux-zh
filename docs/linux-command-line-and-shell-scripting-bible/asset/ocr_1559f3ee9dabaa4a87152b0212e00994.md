print User\tSpace\tPercent

It uses the printf command to format and rearrange the text from the raw data:

```
{
    printf "%s\t%d\t6.2f\n", $2, $1, ($1/n)*100
}
```

This is the section that processes each line of output from the du command. The printf command allows us to format the output to make a nice table. If you happen to have long usernames on your system, you may need to judge the formatting to get it to turn out.

The other trick here is that the diskhogs script passes the $TOTAL variable to the awk script via the awk command line parameter:
-v n=$TOTAL

Now the gawk variable n is equal to the total user disk space, and you can use that value anywhere in the gawk script.

Finally, the script ends the output display by showing the total amount of user disk spaced used:

```
{
    printf "--------------------------------"
    printf "Total\t%d\n", n
}
```

This uses the n variable, which contains the value from the $TOTAL shell variable.
