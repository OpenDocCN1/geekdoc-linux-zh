# Part V Advanced Topics

After the download completes, you should have a file on your system that looks something like this (the version number of the file you downloaded may vary):

```
```mysql-5.0.45-linux-i686.tar.gz```
```

If you remember from Chapter 4, the .tar.gz file extension indicates that the file is a gzipped file. It contains all of the files for the MySQL server archived into a single file using the tar command, compressed using the gzip compression utility.

You'll need to extract it using the tar command to a directory to use the files in it contains. However, there are a few other steps to perform first:

+   1 Create a unique user and group account responsible for the running MySQL server. Usually this account and group are called mysql. As the root Linux user account, perform these changes:

```
```groupadd mysql
useradd -g mysql mysql```
```

+   2 Select a directory where you want to place the MySQL software. The recommended location is /usr/local. Extract the files using the tar command, and create a link from the resulting obnoxiously long directory name to a directory called mysql:

```
```cp mysql-5.0.45-linux-i686.tar.gz /usr/local
cd /usr/local
tar -zxzf mysql-5.0.45-linux-i686.tar.gz
ln -s mysql-5.0.45-linux-i686 mysql```
```

+   3 Change the owner and group of the new mysql directory to the mysql user and group accounts you created:

```
```cd mysql
chown -R mysql
chgrp -R mysql```
```

So now you have your MySQL server and client files conveniently located in the /usr/local/mysql directory on your Linux system.
