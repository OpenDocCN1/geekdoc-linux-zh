# Shell startup files

If you don't use the tcsh shell as a login shell, just an an interactive shell, you must deal with a different set of files when the shell starts up.

The default system-wide startup file is:

+   * /etc/csh.csh

After executing this file (if it exists), the tcsh shell proceeds to the user's $HOME directory and looks for either of the following files:

+   - $HOME/.cshrc
- $HOME/.tcshrc

If both exists, it will only execute the .tcshrc file. You can test the order in which the tcsh shell executes these files by performing a simple test using the echo statement:

```
$ tcsh
This is the /etc/csh.tcshrc file
This is the /home/test/.tcshrc file
$
```

When started a new tcsh shell, it executed the /etc/csh.tcshrc file first, then the .tcshrc file in the $HOME directory.

The shell startup files also execute if you use the tcsh shell for a shell script:

```
$ cat test2
!/bin/tcsh
# test run a script
echo "This is a test"
$ ./test2
This is the /etc/csh/cshrc file
```
