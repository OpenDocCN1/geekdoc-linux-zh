# The shell startup files

When you start a new zsh as a login shell (either by logging into the system, or by running the zsh shell program), the zsh shell looks for commands in two files.

The default system-wide zsh startup file is:

```
/etc/zhenv
```

After executing this file (if it exists), the zsh shell proceeds to the user's $HOME directory and looks for the file:

```
$HOME/.zhenv
```

You can test the order in which the zsh shell executes these files by performing a simple test using the echo statement in each file:

```
% zsh
This is the /etc/zhenv file.
This is the .zhenv file in HOME.
%
```

When I started a new zsh shell, I executed the /etc/zhenv file first, then the .zhenv file in the $HOME directory.

The shell startup files also execute if you use the zsh shell for a shell script:

```
% cat test1
#!/bin/zsh
# test run a script
echo "This is a test"
% .test1
This is the /etc/zhenv file.
This is the .zhenv file in HOME.
This is a test
%
```
