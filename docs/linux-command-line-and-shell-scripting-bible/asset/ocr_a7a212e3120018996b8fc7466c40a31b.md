One MUA program that takes advantage of the ncurses library is the Mutt program. When you start Mutt it paints a user-friendly menu on the terminal display, listing the messages similar to the output of the Mailx program. You can select a message and view it in the display, as shown in Figure 26-3.

The Mutt program uses key combinations to perform standard functions, such as read a message and start a new message. Possibly the most useful feature for shell script programmers is the ability to send messages directly from the command line, without going into text-graphics mode. We'll be covering the Mutt program in much more detail later on "The Mutt Program" section.
