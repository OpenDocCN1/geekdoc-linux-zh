# Watching CPU and memory usage

The core statistics of any Linux system are the CPU and memory usage. If these values start out of control, things can go wrong very quickly on the system. This section demonstrates how to write scripts to monitor and track the CPU and memory usage on your Linux system, using a couple of basic shell scripts.

# The required functions

As with the other scripts shown so far in this chapter, the first step is to determine exactly what data you want to produce with your scripts. There are a few different commands that you can use to extract CPU and memory information for the system.

The basic system statistics command is the uptime command:

```
$ uptime
09:57:15 up 3:22, 3 users, load average: 0.00, 0.08, 0.28
```

Another great command for extracting system information is the vmstat command. Here's an example of the output from the vmstat command:

```
$ vmstat
procs--memory----swap--io--system----cpu----
r b swpd free buff cache si bo bi in cs us sy id wa st s
0 178660 13524 4316 72076 8 10 80 22 127 124 3 1 92 4 0
0 178660 12845 4245 71890 8 10 80 22 127 124 3 1 86 10 0
```

The first time you run the vmstat command, it displays the average values since the last reboot. To get the statistics, you must run the vmstat command with line parameters:

```
$ vmstat 1 2
procs--memory----swap--io--system----cpu----
r b swpd free buff cache si bo bi in cs us sy id wa st s
0 178660 13524 4316 72076 8 10 80 22 127 124 3 1 92 4 0
0 178660 12845 4245 71890 8 10 80 22 127 124 3 1 86 10 0
```
