# Core Linux distributions

A core Linux distribution contains a kernel, one or more graphical desktop environments, and just about every Linux application that is available, precompiled for the kernel. It provides one-stop shopping for a complete Linux installation. Table 1-6 shows some of the more popular core Linux distributions.

In the early days of Linux, a distribution was released as a set of floppy disks. You had to down-load groups of files and copy them onto disks. It would usually take 20 or more disks to make an entire distribution! Needless to say, this was a painful experience.

Nowadays, with computers commonly having CD and DVD players built in, Linux distributions are released either as CD or a single DVD. This makes installing Linux much easier.

However, beginners still run into problems when they install one of the Linux distributions. To cover just any situation where someone might want to use Linux, a single distribution has to include lots of application software. They include everything from high-end Internet database servers to common games. Because of the quantity of applications available for Linux, a complete distribution takes four or more CDs.
