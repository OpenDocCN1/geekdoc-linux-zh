# The inputbox widget

The inputbox widget provides a simple textbox area for the user to enter a text string. The dialog command sends the value of the text string to STDERR. You must redirect that to retrieve the answer. Figure 15-4 demonstrates what the inputbox widget looks like.

As you can see in Figure 15-4, the inputbox provides two buttons, OK and Cancel. If the Cancel button is selected, the exit status of the command is one; otherwise, the exit status will be zero:

```
$ dialog --inputbox "Enter your age: 10 20 2>age.txt
$ echo $?
0
$ cat age.txt
12$
```

You'll notice when you use the cat command to display the contents of the text file that there is no newline character after the value. This enables you to easily redirect the file contents to a variable in a shell script to extract the string entered by the user.
