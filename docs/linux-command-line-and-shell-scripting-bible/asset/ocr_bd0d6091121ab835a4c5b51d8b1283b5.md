# The GNOME desktop

The GNOME Network Object Model Environment (GNOME) is another popular Linux desktop environment. First released in 1999, GNOME has become the default desktop environment for many Linux distributions (the most popular being Red Hat Linux).

While GNOME choose to depart from the standard Windows look-and-feel, it incorporates features that many users are comfortable with:

+   - A desktop area for icons
- Two panel areas
- Drag-and-drop capabilities
