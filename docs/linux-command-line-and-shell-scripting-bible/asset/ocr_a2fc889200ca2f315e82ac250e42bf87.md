# Part IV Alternative Linux Shells

# Defining the variable type

A feature in the ksh93 shell that's not available in the bash shell is the typeset command. The command allows you to set attributes for variables and functions. One of the attributes you can set is the data type that the variable uses. Table 22-3 lists parameters used with the typeset command.

The typeset command is a great way to convert numbers between different bases:

```
$ typeset -i2 a
$ typeset -i8 b
$ typeset -i16 c
$ a=100
$ b=100
$ c=100
$ echo $a $b $c
2#1100100 8#144 16#64
$
```

Each of the variables appears using a different base (the base appears before the pound sign when displaying the value).

TABLE 22-3

# The typeset Command Parameters

| Parameter | Description |
| -A | Make the variable associative array. |
| -b | The variable can contain any number of data bytes. |
| -En | Make the variable double-precision floating-point number with n significant figures. |
| -Fn | Make the variable double-precision floating-point number with n decimal places. |
| -f | Assign a name for a function. |
| -i | Convert all upper-case characters to lower-case. |
| -L | Remove leading blanks and left-justify the text. |
| -n | Declare the variable to be a reference to another variable. |
| -r | Make the variable read-only. |
| -R | Add leading blanks to right-justify the text. |
| -u | Convert all lower-case characters to upper-case. |
| -x | Mark the variable for automatic exporting. |
| -Z | Right-justify and fill with leading zeros. |
