Creating an archive directory hierarchy

![](bbox=[0.128, 0.159, 0.69, 0.558])

Now you have a new challenge to solve. Your script must create the individual month and day directories automatically, and know that if they already exist, they don't need to be created. As it turns out, this isn't as hard as it sounds!

If you use the line options for the mkdir command (see Chapter 3), you'll find the -p command line option. This option allows you to create directories and subdirectories in a single command, plus the added benefit in that it doesn't produce an error message if the directory already exists. Perfect!

We're now ready to create the archivehourly script. Here's what it looks like:

```
$ cat archhourly
#1/bin/bash
# archive a working directory hourly

DAY=`date +%d`
MONTH=`date +%m`
TIME=`date +%k%M`
```
