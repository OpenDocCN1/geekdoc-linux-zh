# The Linux Command Line

```
umount /home/rich/mnt: device is busy.
[root@testbox #] cd /home/rich
[root@testbox #] ummount /home/rich/mnt
[root@testbox #] ls -l mnt
total 0
[root@testbox #]
```

In this example, even I was not using a file from the mounted .iso image file, I was still in a directory within the filesystem structure, so the unmount command wouldn't let me unmount the image file. Once I moved out of the image filesystem, I was able to successfully unmount the image file.

# Using the df command

Sometimes you need to see how much disk space is available on an individual device. The df command allows us to easily see what's happening on all of the mounted disks:

| $ df | K-blocks Used Available% Mounted on |
| Filesystem | | | |
| /dev/sda1 | 1821068 7703964 45% / |
| /dev/sda2 | 101086 16880 77187 20% /boot |
| tmpfs | 119536 0 119536 0% /dev/shm |
| /dev/sdb1 | 127462 113892 13570 90% /media/disk |

The df command shows each filesystem contains data. You can see from the mount command earlier, some mounted devices are used for internal system purposes. The command displays:

+   - The device location of the device
- How many 1024-byte blocks of data it can hold
- How many 1024-byte blocks are used
- How many amount of used space as a percentage
- The mount point where the device is mounted

There are few different command parameters available with the df command, most of which you will never use. One popular parameter is -h, which shows the disk space in human-readable format, usually as an M for megabytes or a G for gigabytes:

| $ df | Size Used Avail% Mounted on |
| Filesystem | | | | |
| /dev/sdb2 | 18G 7.4G 45% / | |
| /dev/sda1 | 99M 19M 76M 20% /boot |
| tmpfs | 117M 0 117M 0% /dev/shm |
| /dev/sdb1 | 125M 112M 14M 90% /media/disk |
