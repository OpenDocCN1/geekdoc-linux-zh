# The PostgreSQL command line interface

The PostgreSQL command line client program is called psql. This program provides complete access to the database objects configured in the PostgreSQL server. This section describes the psql program and shows how to use it to interact with your PostgreSQL server.

# Connecting to the server

The psql client program uses the command line interface to the PostgreSQL server. As you would expect, it uses command line parameters to control what features are enabled in the client interface. Each option uses either a long or short name format. Table 24-3 shows the command parameters available.

# TABLE 24-3

| Short Name | Long Name | Description |
| --- | --- | --- |
| -a | --echo-all | Display all sql lines processed from a script file in the output. |
| -A | --no-align | Set the output format to unaligned mode. Data is not displayed as a formatted table. |
| -c | --command | Execute the specified SQL statement and exit. |
| -d | --dbname | Specify the database to connect with. |
| -e | --echo-queries | Echo all queries to the screen. |
| -E | --echo hidden | Echo hidden psql meta-commands to the screen. |
| -f | --file | Execute SQL commands from the specified file and exit. |
| -F | --field-separator | Specify the character used to separate column data when unaligned mode. The default is a comma. |
| -h | --host | Specify the IP address or hostname of the remote PostgreSQL server. |
