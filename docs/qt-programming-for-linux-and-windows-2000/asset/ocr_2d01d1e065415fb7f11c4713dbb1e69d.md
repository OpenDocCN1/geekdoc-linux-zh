Obviously, these two examples of text input are supported by the Qt toolkit, but there are other ways to accept user text input as well. The following widgets describe the widgets provided with the toolkit and some possible variations on their default behaviors.

QComboBox QComboBoxes (Figs. 3.25 and 3.26) are a blending of text field and popup menu functionality. There are two flavors: read-only and read-write. The read-only variety provides only a popup menu of possible values from which the user may choose. The read-write variety permits the user to input whatever value he wishes, or can be constrained by a validator.
