# KDevelop

If you do most of your work in a UNIX environment (as I do), you will want to take a look at what the KDevelop environment offers. This IDE promises to become the standard IDE for Linux platforms. It supports development for KDE, Qt, C++, or C applications, provides “wizards” for framework generation, and the usual array of C++ development tools such as class browsers, language savvy editors, and the like.

Windows developers are not likely to see a binary for Windows platforms.
