# USER INTERACTION OBJECTS

I define *user interaction objects* as those objects that permit the end-user of an application to input information, to change operating parameters, or to trigger operations. This includes objects that permit a user to select something from a list.

Where it makes sense to do so, I have included supporting objects that don't directly provide an interface or interaction.

# Buttons

These objects provide user interaction in the form of pushbuttons, radio buttons, toolbars, checkboxes, and classes that are used to manage them.

# QCheckBox

A check box is a boolean indicator and input widget that consists of a graphic box that either provides a check mark or an "x" (depending on the style) and an optional text label. An example is shown in Figure 3.1.
