# Composite Widget Support

This section describes the composite widgets (my own definition) of the Qt toolkit. For clarity, a *composite widget* is any widget that integrates two or more widgets that can be used by themselves outside that composite widget, and that provide no event loop such as that provided by the convenience dialogs. This is (currently) a very short list, as you will notice. The next release (or maybe the one after that) will provide others. I’m sure.

**QMainWindow** A QMainWindow (Fig 3.22) provides most of the functionality that you will typically need for a given application including a menu bar, tool bar support, and a status bar. You will typically subclass QMainWindow. See the Qt example programs for many variations.
