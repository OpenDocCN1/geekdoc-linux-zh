void
PartNum::verify( const QString &s )
{

    static bool busy = false;
    char bp[6];  // OK-range invalid for 118n
    int i;

    if(busy == true) return;
    memset( bp, 0, 6);
    strncpy(bp, s, 5);
    if(strlen(s) > 5) {

        busy = true;
        setText( bp );
        busy = false;
    }
    if(bp[0] >= 'a' && bp[0] <= 'z') {
        bp[0] = toupper(bp[0]);
        busy = true;
        setText( bp );
        busy = false;
    }
    if(bp[0] >= 'A' && bp[0] <= 'Z') {
        for(i=1;i<5;i++) {
            if(!isdigit(bp[i])) break;
        }
        if(i == 5) {
            if(_valid == false) {
                _valid = true;
                emit valid( _valid );
            }
        }
        return;
    } else {
        bp[i] = '\0';
        busy = true;
        setText( bp );
        busy = false;
    }
    }
    if(_valid == true) {
        _valid = false;
        emit valid( _valid );
    }
    return;
}

The busy flag in the verify routine is to prevent the recursion (and the subsequent stack overflow) that you can expect when you cause a slot to call itself as the verify routine does by calling the set(Text) method.

## QSpinBox

A spin box (Fig. 3.30) is a text field that accepts (usually) integer data. It includes a pair of pushbuttons that permit the user to increment or decrement the displayed value. The step rate and range are programmable.

![](img/64220583cb3d8a303f33ac97f5433b04_123_1.png)

Figure 3.30 QSpinBox widget

### A Possible Instantiation

```cpp
QSpinBox *sb = new QSpinBox( this );
```

### Example Use

```cpp
// Create a spinbox for invoice payment
// period allowance.
// Minimum = 10, Maximum = 90, step = 10
// Default to COD, (-1 from sb->value())
QSpinBox *sb = new QSpinBox( 10, 90, 10, this );
sb->setSuffix( " days net" );
sb->setSpecialText( "C.O.D." );
```

Methods are provided to reinterpret value types other than integer values, but the value must eventually be evaluated as an integer. To make dramatic changes to QSpinBox's functionality usually requires a reimplementation of the widget. An example of a spinbox that operates on time t values is included on the CD-ROM.
