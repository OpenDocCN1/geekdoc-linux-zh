**QGroupBox** A convenience subclass of QGroupBox, QHGroupBox organizes widgets in a group with a single horizontal row.

**QVGroupBox** Another convenience subclass of QGroupBox, QVGroupBox organizes widgets in a group with a single vertical column.

**QButtonGroup** This class provides a way to manage multiple QButton widgets as a logical group. This widget is commonly instantiated in one of two ways: either with the optional frame and text label, or without any visual component. If you need to manage an array of buttons, this class will probably be useful. Fig 3.16 represents six push buttons within a button group.
