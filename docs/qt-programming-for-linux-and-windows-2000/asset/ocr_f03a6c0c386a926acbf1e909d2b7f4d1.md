# QToolBar

Toolbars (see Figs. 3.4 and 3.5) are a set of commonly used push/toggle buttons that provide for both an icon and a text label, arranged either horizontally or vertically. They are purely a convenience to the end-user and aren't always needed or useful. However, since nearly every new software package provides a toolbar (whether it makes sense to or not), you may find your latest project specification includes a section describing the toolbar.
