So, once you install all the software that you want on your Linux server and you want to update them, all you need to do is use the *upgrade* command. See the syntax below:

```
$ sudo apt-get upgrade
```

What the above command will do is it will see whether the program in the repository is newer than the one you have on the server. If the version of the program that you have is older than the ones in the repository, it will bring down that information and it will ask you whether you want to update your software or not. If you say Yes, it will automatically update all the software that you have on your computer.
