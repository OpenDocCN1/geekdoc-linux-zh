
Slackware 似乎是“尖端黑客”的一员，他们喜欢紧贴操作系统，并且每隔几天就更新一次内核——我们没有用过它，所以这只是道道。S.uSE 发行版在欧洲非常流行。它看起来可能是一个“德国式稳固”的通用发行版，安装简单且声誉极佳。另一个知名且受尊敬的发行版是 Caldera，据说其目标是企业用户——这有许多缺陷；Mandrake 发行版是 RedHat 的克隆版本，更新频率比正统的 RedHat 更高（RedHat 倾向于减少更新频率，以免产生过多的版本）。Mandrake 似乎非常流行。它们是针对特定国家或语言的“本地化”Linux 版本（如韩语、日语等）……默认可能包含了这些国家的用户想要看到的所有黑客技术（优化）。

此外还有“特殊用途”发行版，例如 Linux 的“实时”版本（如果你从事自动化、机器人等领域可能会很有用）、非常小的发行版（可能适用于下一代 CD/MP3 播放器，或者如果你喜欢从小型软盘运行 Linux 的想法）、并行计算和集群系统（如果你计划做自己的任何事情，这可能非常棒 :-)；这里的差异会更大，但这些发行版并非为了“通用”设计。作为一个新手，你不想从其中任何一个开始，尽管你可能会被其吸引。它们无疑展示了 Linux 的强大和可行性——它可以在计算机集群上运行，构建出世界上最快的系统。

你需要的发行版取决于你拥有的硬件。对于你的包含 Intel 386 处理器、486、Pentium、Cyrix、K6 或类似处理器的 PC 硬件，你需要二进制发行版“Intel”或“386”。[除非你准备好从自己编译 Linux 源码开始，这对于新手来说并不典型 :-] 这种情况发生是因为由于还有其他平台的二进制发行版（PowerPC、Alpha 以及可能还有十种更多）——它们并不不适用于你的 PC 兼容机，肯定无法工作。

简而言之，新手会对多个 Linux 发行版感到困惑，但拥有不同的发行版是有原因的。这应该被视为 Linux 的优势而非弱点。

本指南侧重于（Intel）平台上的 RedHat 5.2、6.0 和 6.1。许多答案适用于其他发行版或平台，但我们并未尝试。

## 1.2 Linux 的硬件要求是什么？

开箱即用的 Linux 运行在带有 8 MB 内存的 386  PC 上，但低端电脑对于纯文本应用程序（无 X-Windows）是实用的。配备 16 MB 内存和 600 MB 空闲（未分区）硬盘的 486 足够运行 X-Windows。我的那台带有 64 MB 内存的 586-900 MHz 运行如飞。我的带有 64 MB 内存的 Pentium 2 237 MHz 体验非常完美，即使在并发运行多个大型应用程序时也能几乎瞬时响应。我的带有 8 MB 内存和 1 GB 硬盘的 486-32 MHz 内存太小，无法在 GUI 下独立运行，但在我的家庭网络环境中很有用（一台486 类机器如果至少有 16 MB 内存，独立运行也恰好足够）。我那台旧的带有9 MB 内存和 120 MB 硬盘的 Toshiba 386-SX-20 MHz 便携式电脑在 MS Windows 3.11 下运行“旧应用程序”，并连接到我们的家庭网络，因此仍然有用。我们也在这台 Toshiba 上尝试了 Debian，它在文本模式下运行良好。

如果你愿意多克服一些困难，你应该能够在只有 4 MB 内存的环境下运行 Linux，但对于通用的家庭 Linux 机器来说，这可能不值得费力。我会说：至少获取 16 MB 内存，如果可能的话，32 或 64 MB —— 在并发运行多个 GUI 应用时，内存会产生差异。现在的内存很便宜。

网络是 Linux 异彩之处，所以考虑 10-base T 卡——它们并不贵，而且非常适合连接你的两台或多台电脑。此外，寻找一些 Windows 认为过时的旧卡——它们可以低价购买且在 Linux 下运行良好。如果只连接两台电脑，一根用于以太网卡直连的交叉线就足够了。要连接 2 台以上的电脑，你需要一个集线器（约 30 至 80 美元）和普通（非交叉）线缆。如果你有以太网卡，你也可以考虑在电脑上安装多一个以太网卡，使用交叉线进行直连，从而节省费用。10-baseT 系统使用“巨型电话”接头，所有机器都连接到一个盒子上（称为集线器）。集线器有一个额外的连接（称为“上行链路”），如果你以后与外界建立永久连接，就会用到它。
