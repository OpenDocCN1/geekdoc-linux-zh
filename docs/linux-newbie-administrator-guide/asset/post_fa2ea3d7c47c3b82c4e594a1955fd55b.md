## 1.6 I have RedHat CD but no install. What do I

If your computer boot from the CD drive (most computers), you don't need a boot diskette to install Linux. Have a look at your BIOS setup, the boot option can be set off by you. My computer has the CD drive specified as the first boot device in the BIOS yet still cannot boot from the CD drive. So the BIOS setup does not necessarily mean you can just insert the RedHat CD into the CD drive and reboot the computer to enter the RedHat Linux installation program.

If you don't know how to access your BIOS setup, read this paragraph. The BIOS setup can typically be entered at boot time by pressing the key at the right moment (often when a is briefly displayed). Often, it is the <Del> key. Here is a list of key combinations used by popular BIOSes:

- Acer notebooks: <F2> during Power-On Self-Test (POST).
- American Megatrends (AMI): <Del> during Power-On Self-Test.
- Award: <Del>, or <Ctrl><<Alt><<Esc>.
- Compaq: <F10> after the square appears in the top right corner of the screen during boot-up.
- Dell: <Ctrl><Alt><Enter>.
- DTK: <Esc><Ins> during Power-On Self-Test.
- IBM Aptiva 535: <F1> while the square with the wavy lines is displayed in the upper right corner during power-on.
- IBM PS/2: <Ctrl><Alt><Del>, then <Ctrl><Alt><Ins> when the cursor is in the top right corner.
- Mr. BIOS: <Ctrl><Alt><S> during Power-On Self-Test.
- Packard Bell: for some <F1> or <F2> during Power-On Self-Test.
- Phoenix: <Ctrl><Alt><Esc> or <Ctrl><<S>, or <Ctrl><Alt><Enter>.

If you cannot boot your CD drive, make a boot diskette under DOS or the MS Windows DOS mode. (You have to go to "Shutdown" and "Restart" in MS-DOS mode, not just a DOS window). From, you may try the program:

```
EZSTARTART.BAT
```

which is on my RedHat CD from "cheabyytes".

It is important that you have a perfectly good floppy (without one bad cluster). The program that makes the diskette not check if the floppy was written properly. Also don't count that the DOS FORMAT utility will find a faulty floppy--it probably won't. If I were you, I would make two or three floppy boots at once--you would be surprised how many diskettes have problems. For me, the third floppy worked! If you install diskette not boot, make another one--it definitely boot.

If you don't have the EZSTART.BAT, here are the essential commands. To make the floppy run:

```
F:\dosutils\rewrite.exe -f F:\images\boot.img -d a: -n
```

To make the supplemental (optional) diskette run:

```
F:\dosutils\rewrite.exe -f F:\images\supp.img -d a: -n
```

This assumes your CDROM is the drive "F:

You may find it easier to rewrite without any argument--it will interactively prompt you for the input image and output file.

From under Linux, you can make a boot disk by mounting the RedHat CDROM and typing the commands (as root user):

```
cd /mnt/cdrom/images/
diff if=boot.img of=/dev/fd0
```

The ''dd' command copies files. The above command specifies that the input file ("if") is "boot.img" and the output file ("of") is /dev/fd0, which is the first floppy drive, number zero (if you want to write to your second floppy drive, /dev/fd1).

## 1.7 What do I need to read before installation?

You may want to read the RedHat manual. If you don't have the printed copy, an html version is on your CD so you can read it using any web browser, e.g. Netscape for Windows. Look here to see how to access this manual and some additional reading material.

It is also helpful to get some UNIX orientation if you don't have any. A good Linux manual or your Unix behold. Almost all basic commands will run under Linux. Manuals for MS Windows are useless (click this, click that), manuals for Linux/Unix are typically great (giving you an understanding of the system, a lasting benefit).

You may want to learn about your hardware: how many and what size drives have, the type, number, and size of all partitions on each drive, where are your DOS/Windows partitions, which one is the DOS/Windows boot partition (if you plan to have dual boot), what type of mouse you have, what video card and how much memory, monitor (max synchronization frequencies), etc.

Go to BIOS to see the number and geometry of your drives. Run DOS "idisk" to display your hard drive(s) partition table(s). Switch your system to learn about the type of video card and the amount of video memory. Boot MS Windows, to the control panel-devices and write down the sound card, network card types and settings (name, type, IRQ, i/o address, DMA channel). Read the label underneath to see the type of mouse you have. (Next time you buy a mouse, get a Linux-3 Logitech or Linux makes use of all buttons). Dust off your monitor manual to find the maximum synchronization frequencies (vertical and horizontal) that your monitor supports. Never use frequencies off the monitor specification—this may damage your monitor.

## 1.8 Can I have MS Windows and Linux installed on the same computer?

Yes, you can. Many use dual dual. This is typically achieved by installing MS Windows on one hard drive partition and Linux on another partition. Linux comes with a simple boot manager LILO, which will let you choose at the boot time the operating system you boot. Install MS Windows first and only afterwards else MS Windows installation program will disable your access to Linux. Have a boot floppy ready if you need to re-install MS Windows–MS will surely disable your access to Linux and you will have to boot from the floppy and re-run the command lilo to get back to business.

From Linux, you will be able to read and write to your MS Windows partitions so that data exchange between MS- and Linux-based program is seamless. You will also be able to use your existing MS Windows-based resources: sound files, backgrounds, pictures, fonts, etc. (First check if it does not violate your license agreement :-) For products that are rent to you from Microsoft, it probably would. With my Linux computers, I am proud to have no pirated software on my system whatsoever.)
