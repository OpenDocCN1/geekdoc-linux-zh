| <Ctrl><Alt><F1> | Switch to the first terminal. Under Linux you can have several terminals opened at the time. |
| <Ctrl><Alt><Fn> | (n=1,6) Switch to the nth terminal. |
| <Ctrl><Alt><F7> | Switch to the first terminal (if one is running). |
| <Ctrl><Alt><Fn> | (n=7,12) Switch to the nth GUI terminal (if GUI terminal is running on screen n-1) |
| <Tab> | Autocomplete the command (in frame). THIS SHORTCUT IS GREAT! It works at LILO prompt! |
| <ArrowUp> | Scroll and edit the command history. Press [Enter] to exit. |
| <Shift><PgUp> | Scroll terminal output. Work at the login prompt, so you can scroll through bootup messages. |
| <Shift><PgDown> | Scroll terminal output. (in X-Windows) if you set the X-server to more than one resolution. For multiple resolutions on your system VGA card/monitor, have the following line in the file /etc/X11/xFree8Config when the first resolution resolution starts, determines the size of the "virtual screen": Modes "1024x768" "800x600" "640x480" "512x384" "480x300" "400x300" |
| <Ctrl><Alt><+ | (in X-Windows) Change to the X-server resolution. |
| <Ctrl><Alt><BSpace> | (in X-Windows) Kill the X-windows server. Use if the X-windows server crashes and cannot be exited normally. |
| <Ctrl><Alt><Del> | Shut down the system and reboot. This is the normal shutdown command for a user at the text-mode console. Don't just press "reset" button for shutdown! |
| <Ctrl>c | Kill the process. |
| <Ctrl>d | Logout from the current terminal. |
| <Ctrl>d | Send [End-of-File] to the current process. Don't press it twice you also log out (see the previous command). |
| <Ctrl>s | Stop the transfer to the terminal. |
| <Ctrl>q | Resume the transfer to the terminal. Try if your terminal mysteriously stops responding. |
| <Ctrl>z | Send the current process to the background. |
| reset | Restore a we-terminal (a terminal showing funny characters) to default setting. If you tried to "cd into a binary file. You may not be able to see the command as you type it. |
| <MiddleMouseButton> | Paste the text which is currently highlighted somewhere else. This is the normal "copy-paste" operation in Linux. It doesn't work with Notepad and Word use the Windows-style "copy-paste". Best used with a Linux-ready 3-button mouse (Logitech or similar). (tide) My home directory.
