### 3.6.2 How do I write a simple GUI program (using Tk)?

Tk is a GUI extension of the easy yet powerful tcl programming language. For example, I may use pico to create a text file that will contain a simple tk program:

```
pico try_tk
```

and type in a simple example of tk code to see if it works:

```wish
#!/usr/bin/wish
button .my_button -text "Hello World" -command exit
pack .my_button
```

The first line (starting with the "#!") pound-bang) tells the shell what utility to execute my text file. The next two lines are examples of a simple tk program. First, I created a button called "my_button" and placed it at the root of my class hierarchy (the dot in front of "my_button"). To the button, I tied the "Hello World" and a command that exists the program (when the button is pressed). Last line makes my program's window adjust its size to big enough to contain my button.

After saving the file, I can make it:

```
chmod a+x try_tk
```

after I can run it by typing (in the X-terminal, because it requires X-windows to run):

```
./try_tk
```

Tk is a very popular for building GUI front ends.

### 3.6.3 How do I write a simple perl script?

Perl is a scripting language for its power, flexibility and perhaps cryptic syntax. It is also very popular among linux and unix (and not only gurus). I used pico (or any other text editor of choice) to create a simple perl script. The script below does nothing useful, yet illustrates some features of perl:

```perl
#!/usr/bin/perl -w
#sample perl program
# name of scalar variables start with $
$a=2;
$b=3;
print $a**$b, "\n";
$hello_world='Hello World';
print $hello_world,"\n";
system "ls";
```

The first line tells the shell how to execute my text file. The option "-w" causes perl to print some additional warnings, which may be useful for debugging. The following lines are almost self explanatory: I assign values to two variables ($a and $b), put $a to power $b and print the result. The "\n" prints a new line, just like the "c" programming language. Then I define another variable to contain the string "Hello World" and, in the next line, I print it to the screen. Finally, I execute the local operating system command "ls", which on Linux prints the listing of the current directory content. Really stupid script.

Surely, I must remember to save the file, then make it executable (see the previous answers) and then I am ready to run it.

### 3.6.4 How do I compile a simple C program?

Start your favourite text editor and type in your source code. For example, I may use pico:

```
pico hello.c
```

and type in the Keringham and Richie (the creators of "c") intro example of a C program:

```c
#include <stdio.h>
void main(void) {
    printf("hello world\n");
}
```

I save the file and then invoke the GNU C compiler to compile the file "hello.c":

```
gcc hello.c
```

The gcc compiler produces an executable binary file "a.out", which I can run:

```
./a.out
```
