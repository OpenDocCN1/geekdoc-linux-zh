## 3.1 Basics

### 3.1.1 Filenames

Linux is case-sensitive. Filenames can be up to 256 characters long and typically contain letters, numbers, underscores, dots, etc. Here is the meaning of some metacharacters:

- * = Matches zero or more characters (except for dot at the beginning of a filename).
- ? = Matches any single character.
- [abc1] = Matches a single character in the enumerated set. In this example the set is 'a', 'b', 'C', or '1'.
- [a-z] = Matches any lower-case letter.
- [-F] = Matches any upper-case letter from A to F in the Latin alphabet.
- [0-9] = Matches any digit.
- [a-zA-Z0-9] = Matches any letter (lower or upper case) or any digit.

Examples: This command will show every filename in the current directory, with the exception of filenames starting with "." (dot):

```
ls *
```

An equivalent to this command is to type just "ls" or "dir". Files with names starting with "." are not shown because "." as the first character of a filename is not matched by "*". Use ls -a (list with the option "all") or ls .* to see "dot" files. dot-files are in the user home directories and are typically used to hold user-level configurations.

To manipulate files with names that contain metacharacters, I use a pair of ' (apostrophes), so that the shell does not interpret their meaning. For example, to remove a file*, I would use:

```
rm 'file*'
```

Please note that quoting with " (quotation marks) is generally weaker than quoting with ' (apostrophes).

This command will show any filename that contains a dot:

```
ls *.*
```

This command will show any filename that contains two dots:

```
ls *.*.*
```
