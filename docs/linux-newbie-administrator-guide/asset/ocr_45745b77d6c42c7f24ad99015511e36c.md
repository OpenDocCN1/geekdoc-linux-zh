Check that the options

domain master = yes
domain logons = yes

are enabled in /etc/smb.conf. You probably want them.

Under RH6.0, you may also perform a basic samba setup (as root):

```
netconf
```

The third step is to configure your MS Windows 95 (or whatever) for networking. This is done exactly as if you were connecting to a WinNT server. Make sure to enable the networking ('client for Microsoft Network') and fill up the group name. Login to the network when booting MS Windows, use your Linux user ID and password. To see if it worked, click on the icon 'Network Neighborhood' and you should be listed there, and underneath you should see the shared directories and printers you chose to share in the file /etc/smb.conf.

If you can't see or use the public directories, make sure that you created them and set the proper read/write permissions for all users.

MS Windows 95b and older (95c, 98, and newer NTs) use password encryption. This will make your logins from the Windows' machine fail, and you may need to enable this option in the /etc/smb.conf file:

```
encrypt passwords = yes
```

On the Linux server, you can start, stop, restart and check the Samba status using these commands (as root):

```
samba start
samba status
samba restart
samba stop
```

You need to re-start samba after making changes to your /etc/smb.conf file.

You can browse the net using Netscape for Windows if you are connected to your Linux computer through Samba and the Linux machine is currently connected to the Internet. To do this, the IP masquerading must be set up on the Linux machine with the modem (described here [p 85]) and you must enable the Samba dns resolution in /etc/smb.conf:

```
dns proxy = yes
```

and then tell Windows to enable the dns server, specify the Linux server name and IP address (in ControlPanel-Network-TCP/IP).
