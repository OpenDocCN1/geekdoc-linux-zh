If my space on the hard drive is really restricted, I may consider a two-partition setup like this (for a lean 600 MB total dedicated for Linux):

| mount point | type | size |
| / | ext2 | 600 MB |
| swap | swap | 50 MB |

In this example, I dedicate 600 MB to contain the base of the operating system, applications, and documents/data, and give 50 MB for the swap partition (for the operating system to use as the virtual memory). The 50-MB swap would be quite sufficient for medium duty operations. The limitation of 600 MB for the operating system, applications and user data means that you will have to select to which applications you install or else risk running out of hard drive space. Try pressing <F1> when installing the optional software that comes on Red Hat CD—will give you a short description of what the software does so you could decide if you really need it. You can easily finish the RedHat installation with 200 MB free on your Linux partition (of 600 MB used in this example) if you make reasonable choices. Please note that "bundling together" the root partition and the /home directory will likely save you some disk space, but it is not the safest solution.

It is possible to install Linux on even less disk space than the example above, but you will have to be more selective as to what you need.

For a larger hard drive space, I may consider the following setup (for a comfortable total of 6 GB dedicated for Linux):

| mount point | type | size |
| / | ext2 | 400 MB |
| /usr | ext2 | 2000 MB |
| /usr/local | ext2 | 2500 MB |
| /home | ext2 | 800 MB |
| swap | swap | 300 MB |

Please note that the mount points can reside on different hard drives.

Another consideration when setting up the partitions. Many older BIOS have the restriction that the boot partition cannot extend the 1024th cylinder on your first hard drive. To overcome this limitation, simply make the first (bootable) partition that it ends before the cylinder number1023 (which makes this partition approximately 512 MB in size, which is plenty for the "/" root partition). Once Linux boots, the BIOS restriction does not matter anymore as Linux can also access the partition(s) by the cylinder number1023.

When and installing Linux, your drives are devices with the following names: hda--first IDE drive (for "hard drive", i.e. the master drive on the first IDE interface), hdb--second IDE drive (i.e., the slave drive on the first IDE interface), hdc--third IDE drive (i.e. the master drive on the second IDE interface), hdd--fourth IDE drive (i.e. the slave drive on the second IDE interface).
