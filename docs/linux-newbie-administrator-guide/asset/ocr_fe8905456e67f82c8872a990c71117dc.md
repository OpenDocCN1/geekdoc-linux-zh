Then, I configure automount by editing the files /etc/auto.master and /etc/auto.misc, e.g. (as root):

pico /etc/auto.master

My /etc/auto.misc looks like that:

```
/misc /etc/auto.misc --timeout 1
```

This says that my automount devices will be mounted in the directory/(which must exist and be empty). My automount drives will automatically unmount one second after I stop them (for example, after I exit the directory). This is a short time--you may choose a longer one. The detailed config file /etc/auto.misc . Here is mine:

```
kernel-ro,soft, intent ftp ftp.kernel.org:/pub/linux
cdrom -fstype=auto, ro :dev/cdrom
floppy -fstype=auto, ro :dev/fd0
zipdrive -fstype=vfat, ro :dev/sda4

hacker_cdrom -fstype=nfs, ro hacker:/mnt/cdrom

hacker_usr -fstype=nfs, ro hacker:/usr
```

Each line contains 3 space defined fields. The first field is the "key" which will be the name of the subdirect(under/misc) to which the device will be mounted. This device MUST NOT exist. It will not be visible when I use the command ls ,but I can cd to it and my device will then mount. Don't ask me why it is so, and how to use this automount in GUI I don't know. The hacker stuff in my auto.misc is the cdrom and floppy from another computer in my home network.

I automount to the directory /misc (not /mnt) so that I can also mount filesystems manually, without using automount, to the directory /mnt.
