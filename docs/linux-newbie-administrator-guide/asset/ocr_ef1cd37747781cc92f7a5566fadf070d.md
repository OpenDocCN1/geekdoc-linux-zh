# 5.5 Should I have a choice to download either the patch or the full source.

Now you have a choice to download either the patch or the full source.
If you're upgrading from 2.0x kernel series you will have to download the full source.
If you're upgrading to a 2.2.x kernel series you can download only the patch, which is of course smaller than the full source. The patch contains only the differences.
If you would like more detailed info on patches and take a look at this link:
http://www.linuxpower.org/display_item.html?id=101 .
Now grab your choice and download it. I highly suggest you download it to /usr/src/ directory.
I suggest downloading the file with the .tar.gz extension (if you're downloading the full source).
For patches I suggest .bz2 extension. Please note that the examples which follow will be based on this decisions (about file types).

# 5.6 Unpacking the download file

# 5.6.1 Unpacking the patch

We are assuming that you downloaded the patch to /usr/src/ directory. For our example lets say the filename is patch-2.2.12.bz2. Before using it we must first unpack it .bz2 extension is bunzip2 format. By using the following command to unpack the file:

```
command =
bunzip2 patch-2.2.12.bz2
```

No visual output will be shown. Check what files are located in the directory now. You will notice that the patch-2.2.12.bz2 is gone and patch-2.2.12 is there of a bigger size.
