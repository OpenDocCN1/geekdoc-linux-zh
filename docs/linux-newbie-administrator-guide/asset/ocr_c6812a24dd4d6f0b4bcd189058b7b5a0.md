# 5.9 What about next kernel upgrade?

Well everything should be the same one thing not. If you will be patching the kernel you will first have to remove the old patch before applying the new one. This is done by first typing -R -p1 < ../patchfile (where patchfile is the name of the old patch) and then applying the new patch with the -E switch. Everything else should be the same.
