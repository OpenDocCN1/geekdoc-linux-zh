# # 1. Before Linux Installation

# ## 1.1 Which Linux distribution should I use?

The differences between the distributions ("distros") are minor: the installation program, choice of the bundled tools/applications, arrangement of a few things on the hard drive (most of Linux is still at the same, standard hard drive location in all distributions). Whichever distribution you decide to install, you will end up essentially the same Linux.

We mostly use "Red Hat Linux" (also called RedHat or RH) for these reasons:

+   (1) RedHat is very popular (both advantage for a newbie and a testimony to RedHat quality).
(2) RedHat is a general-purpose distribution.
(3) RedHat comes with a relatively easy setup program.
(4) RedHat contributions to Linux are "open software" (this means that all the software written by RedHat and included on the RH CD is licensed under the General Public License, GPL, so that it can be legally copied, given away, reused, etc.).
(5) RedHat can be obtained nearly free if you don't care for commercial support. This is a consequence of (4).

In short, as a newbie, you can safely bet on "Red Hat" unless you like something else or have specialized needs. The most recent RedHat release (October 1999) is version 6.1 (RH6.1) which is only a relatively minor upgrade over the previous version of Red 6.0 (RH6.0) which hit the street in May 1999. This previous version was Debian 5.2 and was very popular for quite a while. Be sure to check the most recent version if ordering your software from a dealer-many likes to clear their inventory by sending you old version (this applies not only to Linux). The authors have no connection to RedHat (or any other Linux distributor) whatsoever.

Our recommending RedHat for newbies does not mean that other distributions don't offer benefits or unique features which make RedHat in specific areas. We believe that we would benefit from an exposure to a different distribution because it help us understand Linux better.

We tried Debian and we liked it very much. It was as easy as RedHat, but it seems common (hence, being newbies, we picked up RedHat). The great benefit of Debian is that it is 100% non-commercial (put together by volunteer hackers, the true Linux) and it probably strictly adheres to Linux standards (it probably sets the standards too). Another benefit is that Debian on their numerous distribution CDs of tools and applications—easily more than any other distribution. All tools/apps are nearly "packaged" (for ease of installation) and tested for compatibility. This makes Debian distro look monumental, safe, conservative, and always slightly outdated. So yes, we would have no problem recommending Debian for a great general-purpose Linux.

Core is currently beta-testing their own Linux distribution geared towards a newbie and easy path to run the Core suite of applications: WordPerfect wordpress, QuattroPro spreadsheet, Core Presentations, Paradox database, CoreDraw artist package.... The Corel Linux is based on Debian. If you think about using Corel in the future, picking Debian may be your smart choice now.
