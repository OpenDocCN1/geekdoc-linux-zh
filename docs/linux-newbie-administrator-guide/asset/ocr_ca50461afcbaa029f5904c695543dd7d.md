As an example, you can deny access to telnet and ftp your home server from any machine from outside your home network by inserting the following entry in the file /etc/hosts.deny :

```
in.telnetd, in.ftpd: ALL EXCEPT LOCAL, .your_home_domain.name
```

For more info, check the excellent "Linux Network Administrator Guide" which is surely present on your RedHat (or whatever) distribution CD. I printed this book and had it hardcover.
