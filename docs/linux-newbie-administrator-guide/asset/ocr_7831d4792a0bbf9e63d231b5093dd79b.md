If you cannot boot your CD drive, make a boot diskette under DOS or the MS Windows DOS mode. (You have to go to "Shutdown" and "Restart" in MS-DOS mode, not just a DOS window). From, you may try the program:

```
EZSTARTART.BAT
```

which is on my RedHat CD from "cheabyytes".

It is important that you have a perfectly good floppy (without one bad cluster). The program that makes the diskette not check if the floppy was written properly. Also don't count that the DOS FORMAT utility will find a faulty floppy--it probably won't. If I were you, I would make two or three floppy boots at once--you would be surprised how many diskettes have problems. For me, the third floppy worked! If you install diskette not boot, make another one--it definitely boot.

If you don't have the EZSTART.BAT, here are the essential commands. To make the floppy run:

```
F:\dosutils\rewrite.exe -f F:\images\boot.img -d a: -n
```

To make the supplemental (optional) diskette run:

```
F:\dosutils\rewrite.exe -f F:\images\supp.img -d a: -n
```

This assumes your CDROM is the drive "F:

You may find it easier to rewrite without any argument--it will interactively prompt you for the input image and output file.

From under Linux, you can make a boot disk by mounting the RedHat CDROM and typing the commands (as root user):

```
cd /mnt/cdrom/images/
diff if=boot.img of=/dev/fd0
```

[The ''dd command copies files. The above command specifies that the input file ("if") is "boot.img" and the output file ("of") is /dev/fd0, which is the first floppy drive, number zero (if you want to write to your second floppy drive, /dev/fd1).
