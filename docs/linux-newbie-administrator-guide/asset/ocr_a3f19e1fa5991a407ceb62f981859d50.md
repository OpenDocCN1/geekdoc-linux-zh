# AUDIO CDs

+   - Audio tracks have to be in files of *.cdr (I guess it is the same as *.cdda.raw), *.wav (wave), or *.au format before you can write them to a CD.
- The utility sox converts between the various audio file formats (sox converts quite a few of them). For example, this will convert a .wav file to a .cdr file:

```
sox my_file.wav my_file.cdr
to do the conversions manually - cdrecord supports *.wav and *.au directly (it is a conversion from *.wav or *.au to *.cdr "on the fly”). This is very convenient because audio files tend to be large.
```

+   - CDs don't contain a filesystem, they store "raw data". This means you cannot mount an audio CD. Also, each track is written separately, i.e., as if it were a different "partition" on the CD.
- To read audio tracks from an audio CD and write them to a suitable file on your hard drive (typical format is *.raw or *.wav), you need a "cd ripper". A popular CD ripper is "cdparanoia". After downloading the source for cdparanoia, install it (use the autocompletion <Tab> shortcut when typing the long filenames):

```
cd /usr/local
tar -xzf
/the_path_to_you_downloaded/cdparanoia-III-alpha9.6.src.tgz
ls
cd cdparanoia-III-alpha9.6
./configure
make
make install
```

The installation program places a proper link to the executable
(/usr/local/bin/cdparanoia) so I don't have to create the link manually.

To rip the first track from an audio CD, I can use:
cdparanoia 1

which will put the first track from the CD into the wave file "cdda.wav" in the current directory.
