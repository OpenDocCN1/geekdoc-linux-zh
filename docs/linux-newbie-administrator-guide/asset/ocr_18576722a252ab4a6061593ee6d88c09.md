For example, regular (non-root) users have the permission to mount the cdrom (the "user" option
is specified), they can mount it using a command like this:

```
mount /mnt/cdrom
```

The command which uses root options for mounting (see here [ 63 ] will not work for a regular user
because the user is restricted by the options in /etc/fstab and therefore s/cannot
specifically minimum both the device and the mountpoint.

For a regular user to be able to write to a disk or execute a program on it, s/he must also be given the
appropriate permission to the "mountpoint" directory. For example, this will give all the users all
permissions (read, write, execute) on the directory /mnt/floppy :

```
chmod +rwx /mnt/floppy
```

Now (also the "rw" option is specified for the floppy in the /etc/fstab) the user will be able
nto write to a floppy. If the "exec" option was also enabled in the /etc/fstab, the user would also be able
to execute programs from the floppy.
