The only difficulty is that IP address is dynamically allocated to you by your Internet Service Provider (ISP) from their IP address, and therefore the IP is not the same time when you connect (unless you made specific arrangements with your ISP). Telnet, ftp, or access your web pages (served by your apache web server) from the outside world, one has to know your current IP address. To find out my current IP address, I use this "interface configuration" command which, when run without any parameters, just displays info on all network interfaces present on your machine:

```
/sbin/ifconfig
```

On this machine displays three displays of information on: eth0 (the first ethernet interface that leads to other computers on my home network), lo (the loopback-only interface, the one with IP 127.0.0.1, which is present on every machine), and ppp0 (the first point-to-point protocol interface). My current IP address, assigned to me by my ISP, is displayed under the ppp0 heading. (Your Linux machine can have multiple IP addresses at the same time, so if you have a "static" IP that you use on your home network, it is still visible only on your network.
