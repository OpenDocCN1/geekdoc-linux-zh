## 7.8 Netscape and Lynx (web browsers)

You may have installed a 4.xx version of Netscape during your RedHat installation. To run it, try (in X-terminal):

```
netscape
```

If you didn't install Netscape, you may want to put your RedHat CD into the CDROM, mount it using, for example (as root):

```
mount -t auto /dev/cdrom /mnt/cdrom
```

and then, from the command line, glint (for RH5.2) or gnorpm (for RH6.0) to browse the available packages and perhaps install netscape from your RedHat CD. If you prefer to do the installation from the command line, after mounting the CDROM:

```
cd /mnt/cdrom
cd RedHat/RPMS
rpm -i netsca
```

Netscape is a very good browser, with the same look, feel, and power for Netscape for MS Windows, so you will have no problems navigating. On the dark side, Netscape sometimes crashes (it disappears from the screen, no damage, you have to restart it). Also, in some configurations, Netscape does not like to be a run without a connection to the Internet (depending on your configuration, Netscape can take it up to a couple of minutes to figure that there is the problem for me). Any Netscape version 4.xx seems to have similar problems, upgrading to a slightly higher version does not seem to help. Take your heart, tuned-up, Netscape runs quite well, and is quite definitely usable (I use it all the time). Gecko (the already famous, revolutionary offspring of Netscape) is under way so you hold head high :)

For now, if your Netscape is too buggy to use, you may want to empty your mail "trash" bin and compress the folders for regular basis, and disable Java (in the menu Edit-Preferences-Advanced). This seems to make Netscape more stable. If Netscape "freezes" when you work off, disabling the automatic checkpoint for e-mail solved the problem for you.

If Netscape crashes and on a subsequent re-start complains about the presence of a lock file, it might have left a lock file in your home directory. Just quit any instance of Netscape that you might be running and delete the "lock" file from the directory ".netscape" under your home directory:

```
cd ~
cd .netscape
rm lock
```

If your ISP connection is really slow, you may prefer a text-based browser:

```
lynx
```

which is a real piece of art and does not have problems whatsoever.

Another choice of a Internet browser is your KDE help utility (click on the "book with the lightbox" button on K-bar). This is really an html browser so if you are connected to the Internet (e.g. using your kpppp), you can browse almost anything using this simple utility.

To compose html pages, use Netscape (WYSIWYG view) and WebMaker (code view).
