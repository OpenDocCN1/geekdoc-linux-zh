# ## 5.7 Compiling new kernel

# ### 5.7.1 Using the patch

If you downloaded the patch you will need to go that you are located in /usr/src/ directory. We have unpacked the patch (Section 5.6.1). We will now move to the kernel directory (assuming linux). Type cd linux.

Now we are located in the kernel directory. We have a lot of options and questions. Is your first patch of the kernel? No? We won't go into details and we will assume that this is your first patch kernel. We are now to patch the kernel.

To do this we will use the patch utility. For more detail and wider information about this I suggest checking out the article from the www://www.linuxpower.org web site, at this url: http://www.linuxpower.org/display_item.html?id=101

Type patch -p1 /patch-2.2.12

Lots of text will fly by. If it fails it will stop anywhere but only at the end (otherwise it will ask you a question) everything went ok. If not, then you might have a problem (you already patched a kernel, or something went really wrong).
Everything went ok on. Now it's time to configure the kernel and compile it. We now have 2 choices. One is to compile the new kernel from scratch, the other is to re-compile it using the old configuration. Since you are assuming that you're gonna compile with the old configuration. If you don't want, read section 6.2 where you should use the steps there follow. The only difference is in step 1,

This is the re-compile of the kernel using the old configuration. Follow these steps:

+   1. type makeconfig

At this point you could have been asked for new drivers and development ones. Unless you really need them answer (n).

+   2. type make de

+   3. type make clean

+   4. type make Image (if this fails be bImage, which stands for big zImage)

+   5. type make modules (if you enabled them)

+   6. type make modules_install (if you typed #5)
