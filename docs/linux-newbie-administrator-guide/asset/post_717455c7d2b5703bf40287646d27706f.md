# ftp server

Ftp another machine. It is also ncftp which adds extra features and grep for GUI ().Ftp is good copy files to/from remote. Try "anonymous" if you don't have an account on the remote server. After connection, use "?" to see the list of available ftp commands. The essential ftp command are: ls (see the files on the remote system), ASCII,binary (set the file transfer mode either text or binary, important to select the proper one), get (copy a file from the remote system to local), mget (get many files at once), put (copy a file from the local system to the remote), mput (put many files at once, disconnect). For a script, you may want to use ncftp and ncftpget, for example:
ncftp -u my_user_name -p my_password -a remote.domain remote_dir -a

## 6.4 Process control

(ps status) Display the list of currently running processes with their process IDs (PID) numbers. Use "ps axu" to see all processes running on your system (also those of other users or without a controlling terminal),

fg PID Bring a background process to the foreground.

bg PID Send the process to the background. Opposite to fg.

any_command& Run any command in the background. The symbol "&" means running in background.

kill PID Force a process to shutdown. Determine the PID of the process to kill.

killall program(s) by name.

program_name (in an xwindow) Kill a GUI-based program. Point with your mouse at the window you want to kill.)

lpc (as root) Check and control the process. Use "top" to see the list of available commands.

job_number Remove a printing job from the queue.

nice program_name Run program adjusting its priority. Since the priority is not specified in this example, it will be adjusted by 10 (the default 0). The lower (of "nicness" to others), the higher the priority. The priority value may be in the range -20 to 19. Only root may set negative values. Use "top" to display the priorities of the running processes.

renice -1 PID (as root) Change the priority of a process to -1. Normal users can only adjust processes they own from the current value.

Please note the following shortcuts: <Ctrl>c, <Ctrl>z, <Ctrl>s, and <Ctrl>q. They were described previously.

## 6.5 Administration commands

- setup (as root) Configure mouse, sound, keyboard, X-windows, system services.

- linuxconfig (as either in text or graphical). You can change hundreds of settings from it. Very powerful—don't change many things at the same time, and be careful with changing things you don't understand.)

- xvolume (In terminal). Adjust the settings of the graphical display for all resolutions so to eliminate black bands, shift the display right/left, use the adjustments to your monitor to fit text mode correction. To make changes permanent, display the frequencies on screen.
