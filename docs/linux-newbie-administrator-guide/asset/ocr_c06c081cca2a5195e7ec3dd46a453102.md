# ## 4.5 Setting up a network

# ### 4.5.1 Would it be worth to set up my home network?

This is an excellent idea. It will let you the machines that are in your closet now because they were not powerful enough to run standalone. The benefits include sharing hard drives, ziprives, CDROMs, modem, printers, even scanners, running programs remotely (the text or graphics mode), browsing the Internet on all computers at the same time over one connection. If you lose control of your machine, you may also be able to shut it down remotely and avoid possible problems--see the answer on shutting for details.

# ## 4.5.2 How to set up my home network?

Hardware. Your hardware must be set up properly. Your network card should have been set up during the initial RedHat Installation. If it wasn't, you may want to set up your network card from X-windows. If you more than one network card on your computer, you must also set up the second cards manually, since Linux autodetect 1 network card

Start an X-terminal, execute "su" (to make yourself a root) and then run:

```
/usr/bin/kernelcfg
```

Under Linux, most drivers for network cards are implemented as modules. So setting up a card involves just inserting the module with its parameters. You don't need to recompile the kernel, nor ever reboot your computer (unless you have an uncommon card). To figure out what module(s) and parameters you need, see the Linux Network Administrator Guide (file/usr/LDP/nag on your system or check http://metalab.abc.org/mdw/index.html#). This guide is known as nag.

The parameters (IRQ and address) were a problem during my setup of two network cards on one computer--you must make sure that you don't have any hardware conflicts. A common source of the problems is that the card wants to configure IRQ 5, which is occupied by the SoundBlast, or IRQ 3 which conflicts with the serial port (COM2, cual,tty1). Inspect the files /proc/interrupts, /proc/ioport and rebooting boot messages may help.

For example, your WD8013 card (same as SMC Elite and SMC Elite plus, under IRQ 10 (set by a jumper on the card and I specified the IRQ in the kernel module setup) under the address 0300 and used the "WD" module. My "SMC EtherZ" card (no jumper settings on the card) runs under IRQ 9, address 0240 and uses "SMC EtherZ" module. Please make sure you don't omit the leading "0x" in the address--it means "hexadecimal" and there be be else the number be interpreted as decimal.
