# 6.3 Basic operations

| | |
|---|---|
| set|more | Show the current environment.
| echo $PATH | Show the content of the environment variable "PATH". This command can be used to show other environment variables as well. Use "set" to see the full environment.
| dmesg | less | Print kernel messages (the content of the so-called kernel ring buffer). Press "q" to quit "less". Use less /var/log/dmesg to see what "dmesg" dumped into the file after reboot.
| any_command -help |more | Display a help on a command (works with more commands). "--help" works similar to DOS /h switch. The "more" pipe is needed if the output is longer than one screen.
| ls | List the content of the current directory. Under Linux, the command "dir" is an alias to ls. Many users have "ls" to be an alias to "--color"
| ls -l | List the content of the current directory, all files (those also starting with a dot), and in long form. Pipe the output through the "more" command, so that the display pauses after each screen.
| cd directory | Change directory. Using "cd" with the directory name will take you to your home directory and is a convenient way to toggle between two directories.
| cp source destination | Copy files.
| mcopy source destination | Copy a file from/to a DOS file system (no mounting requirement). E.g., autoexec.bat . See man tools for related commands: mdir, mcr, mren, mden, mnd, m format...
| mv source destination | Move or rename files. The same command is used for moving and directories.
| ln source destination | Create a hard link destination to the file called "source". The link appears as a copy of the original file, but in reality only one of the file is kept, just two (or more) directory entries point to it.. Any changes the file are automatically visible throughout. When one entry is removed, the other(s) stay(s) intact. The limitation of the hard links is: the links to directories or special files are impossible.
| ln -s destination | Create a symbolic (soft) link destination to the file called "source". The symbolic link specifies a path where to look for the file. In contradiction to hard links, the source and destination do not have to be on the same filesystem. In comparison the drawback of symbolic links is: if the original file is removed, the link is "broken", symbolic link can also create circular references (like circular references in spreadsheets or databases, e.g., "a" points to "b" and "b" points back to "a"
| rm files | Remove (delete) files. You must use the file in order to remove it.
| mkdir directory | Make a directory.
| rmdir directory | Remove an empty directory. (recursive) Remove files, directories, and their subdirectories. Careful with this command as root—you delete all files on the system with such a command executed on the top of your directory tree, and this is not unless in Linux (yet). But if you really want to do it (consider), here is how (as root): rm -rf |
| cat filename more | View the content of a text file "filename", one page at a time. The "|\ is the pipe symbol by many American keyboards it shares with (/) The pipe makes the output stop after each screen. For long files, it is sometimes convenient to use the commands head and tail that display just the beginning and the end of the file. If you happen to use "cat" a binary file and your terminal displays funny characters afterwards, you can restore it with the command "reset".
