# 3.6.3 How do I write a simple perl script?

Perl is a scripting language for its power, flexibility and perhaps cryptic syntax. It is also very popular among linux and unix (and not only gurus). I used pico (or any other text editor of choice) to create a simple perl script. The script below does nothing useful, yet illustrates some features of perl:

```
#!/usr/bin/perl -w
#sample perl program
# name of scalar variables start with $
$a=2;
$b=3;
print $a**$b, "\n";n$hello_world='Hello World';
print $hello_world,"\n"
system "ls";
```

The first line tells the shell how to execute my text file. The option "-w" causes perl to print some additional warnings, which may be useful for debugging. The following lines are almost self explanatory: I assign values to two variables ($a and $b), put $a to power $b and print the result. The "\n" prints a new line, just like the "c" programming language. Then I define another variable to contain the string "Hello World" and, in the next line, I print it to the screen. Finally, I execute the local operating system command "ls", which on Linux prints the listing of the current directory content. Really stupid script.
