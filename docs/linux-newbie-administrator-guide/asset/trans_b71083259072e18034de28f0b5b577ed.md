
可移动介质不会自动出现在这些子目录中——你必须“挂载”你的驱动器。详情请参见后面的答案。在弹出介质之前，你应该先卸载驱动器。

你可以在 Linux 下访问（读写）各种驱动器和系统。这包括原生 Linux 分区、DOS 和 MS Windows 分区（在硬盘或软盘上）、ZIP 和 Jazz 驱动器以及 CDROM 驱动器。还支持许多常见的文件系统。这意味着你可以使用 Windows 版 Netscape 下载 Linux 软件，将下载的文件保存到你的 Windows 硬盘分区，然后启动 Linux并将下载的软件从 Windows 分区拷贝到你硬盘的 Linux 分区，最后在 Linux 上安装该软件。

## 4.2.2 我如何访问我的 CDROM？

挂载它。挂载会将你 CD 中的所有驱动器和文件添加到你的 Linux 目录，这样你就可以无需驱动器号轻松访问它们。

作为 root 用户，你可以可以使用这样的命令挂载 CDROM：

```
mount -t auto /dev/cdrom /mnt/cdrom
```

如果此操作有效，你的 CD 内容将立即出现在 /mnt/cdrom 目录中——你可能需要对其进行自定义。以下是工作原理。

该命令告诉操作系统挂载一个自动检测文件系统类型的文件系统（"-t auto"）。设备是 /dev/cdrom。挂载点（进行“挂载”操作的目录）是 /mnt/cdrom。此目录必须存在且为空。如果它不存在，使用以下命令创建它：

```
mkdir /mnt/cdrom
```

如果挂载命令失败，请确保检查设备 /dev/cdrom 是否存在。如果不存在，你的 CDROM 在哪里？如果你有一个 IDE CDROM，它很可能是类似 /dev/hdb 之类的设备。尝试在上面的挂载示例中使用 /dev/hdb 代替 /dev/cdrom。如果此操作仍然失败，且你的 CD 是 IDE CDROM，你可以尝试 /dev/hdc 或 /dev/hld。如果这些都不是你的 CDROM，那么你拥有的可能不是驱动器，而是 SCSI CDROM？尝试 /dev/sda1、/dev/sda2 等。“["hda”是主 IDE 主驱动器，“hdb”是主 IDE 从驱动器，如果你的电脑上有两个接口，“hdc”是次级 IDE 主驱动器，“hdd”是次级 IDE 从驱动器，“sda”是第一个 SCSI 接口后面加上数字。]

总之，拥有一个 /dev/cdrom 设备是一个好主意，因为某些程序假设它存在。如果它在你的系统中不存在，你可以创建一个符号链接，例如：

```
ln -s /dev/hdb /dev/cdrom
```
如果你的 cd 是 /dev/hdb 驱动器。

如果你因为“设备已挂载或目录忙”而无法挂载，可能是挂载点 /mnt/cdrom 是你当前的目录。你必须切换到其他目录才能挂载；例如，通过此命令将当前目录更改到根目录：

```
cd /
```

要卸载已挂载的 CD，编辑 /mnt/cdrom 目录并以 root 身份输入：

```
umount /mnt/cdrom
```

如果没有挂载，CDROM 可能拒绝弹出介质。此外，如果上一个 CD 未卸载，挂载下一个 CD 时可能会遇到问题。如果你因为“设备忙”而无法卸载，可能是 /mnt/cdrom（或任何子目录）就是你所在的目录？你需要将当前目录切换到挂载点之外的地方才能卸载设备。

## 4.2.3 如何挂载软盘、zip 驱动器、DOS/Windows 分区或网络驱动器？

与 CDROM 非常相似——如果你没看之前的答案，请查看。

软盘。我可以通过如下（以 root 身份）挂载我的软盘：

```
mount -t auto /dev/fd0 /mnt/floppy
```

再次，确保 /mnt/floppy 目录存在且为空。此外，mnt/floppy/ 不能是你当前的目录。

挂载成功后，软盘文件将出现在 /mnt/floppy/ 目录。所有用户都能读取文件，但只有 root 可以修改/删除文件。如果你希望用户能够向软盘写入，请继续阅读。

卸载软盘（在弹出磁盘之前你“必须”这样做！）请使用：

```
umount /mnt/floppy
```

如果你因为“设备忙”而无法挂载，可能是 /mnt/floppy/ 目录是你当前的目录。通过输入（例如）退出该目录：

```
cd
```
这将你的当前目录更改到家目录。

Zip 驱动器。我通过以下命令挂载并行端口外部 zip 驱动器（scsi 模拟）：

```
mount -t vfat /dev/sda4 /mnt/zipdrive
```

使用 -t vfat 是因为 zip 磁盘是以 vfat 文件系统预先格式化的，这是支持长文件名的 MS Windows 文件系统。如果不卸载它，你将无法弹出磁盘。

Linux（1999年4月）支持所有 zip 驱动器（内部 SCSI 和 IDE，外部 SCSI 和并行端口），但不支持 USB。

DOS/Windows 分区。我在同一台电脑上使用了运行 Linux 和 MS Windows 的双启动系统。通过以下命令挂载后，我可以访问所有的 DOS/Windows 分区：

```
mount -t vfat /dev/hdal /mnt/dodsrive
```
