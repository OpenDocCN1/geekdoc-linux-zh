(-change mode) Change the file access permission for the files you own (unless you are root in which case you can change any file). You can make a file accessible in three modes: read (r), write (w), execute (x) to three of classes: owner (u), members of the same group as the owner (g), others on the system (o). Check the current access permissions using:
l -l filename
The first is accessible to all users in all if it will show:
The triplet shows the file permission for the owner, of the file, for his/her group, the third for others. A "no permission" will add the permission to read the file "junk" to all (=user+groups):
chmod a++ junk
This will remove the permission to execute the file from junk:
chmod o-x junk

chown new_owner filename Change the file owner. You should use these two commands after you copy a file for use by somebody else.

chgrp new_group filename (substitute id) Assume the super (root) identity (you will be prompted for the password). "exit" to return to your position. Don't work on your machine as root. rpm -ivh filename.rpm (=RedHatPackageManager, install, hashes displayed to show progress, as root.) Install a content of RedHat rpm package(?) and print info on what happened. Keep if you are reading a GUI installation.

rpm -qpi filename.rpm (=RedHatPackageManager, query, package, list.) Read the info on the content of a uninstalled package.rpm.

rpm -ql filename.rpm (=RedHatPackageManager, query, package, information.) Find the files contained in a uninstalled package filename (on your hardrive) belongs. 

rpm -e packagename (=RedHatPackageManager, erase-uninstall.) Install a package package. Packagename is the same of the .rpm (without the dash and version number).
