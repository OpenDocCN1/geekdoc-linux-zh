Fifth, if everything goes well, I find the executable in the new program. The names of executablesndisplay in green when running this command:

```
ls --color
```

Now, I can run the executable:

```
./the_executable
```

Sixth, if I plan to run the program more often, I create a symbolic link to the executable from thendirect /usr/local/bin:

```
cd /usr/local/bin
ln -s /usr/local/the_new_program_subdir/the_executable .
```

This way, the executable (actually, a symbolic link to it) is on my PATH and it can be run by simplyntyping its name (no need to type the full path to the executable any). Some programs will put the executable (or a link to it) in a binary directory so you can skip the last step.
