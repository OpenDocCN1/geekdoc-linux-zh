your /etc/fstab may look like example:
/dev/sda4 /mnt/zipdrive vfat noauto,users,rw,exec,umask=000 0 0

This gives absolutely every the permissions on your zipdrive (mounting, unmounting, read, write, execute).

To summarize, the file /etc/fstab is the place to keep your defaults on how to mount filesystems and what kind of access is allowed for users. You really want to customize it to simplify mounting on your system. Linux default mounting scheme is restrictive so to be secure, you may want to remove some restrictions when setting up Linux at home.

# 4.2.7 Mounting command is so long, how can I simplify it with an alias?

An alias is an abbreviation of a more complex or often used operating system. For creating aliases, I as root, the file /etc/bashrc This way the aliases are available for all the users on the system. For creating user-specific aliases, I edit the file .bashrc in the user home directory.) The relevant part of my /etc/bashrc looks like this:

```
alias cdomrom="mount -v /mnt/cdrom"
alias ucdrom="mount -v /mnt/cdrom"
alias dosdrive="mount -v /mnt/dosdrive"
alias udosdrive="mount -v /mnt/dosdrive"
alias zipdrive="mount -v /mnt/zipdrive"
alias uzipdrive="mount -v /mnt/zipdrive"
alias floppy="mount -v /mnt/floppy"
alias ufloppy="mount -v /mnt/floppy"
```

The option "-v" stands for "verbose", i.e., it tells Linux to talk to me a lot during mounting. For the aliases to take effect, the user has to re-login. Now the user can mount the floppy using this simple command:

```
floppy

ands/he can unmount using

ufloppy
```

# 4.2.8 Can I automount?

You can. Automount will automatically mount a filesystem as you access it and unmount when you stop using it.

To set up automount, I first run the programs setup (as root). Go to the option "netsysv" (RH5.2) or "System Services" (RH6.0) and make sure that automount service ("autofs") is enabled.
