# 6.2 Common Linux commands--system info

| Command | Description |
|---|---|
| pwd | Print working directory, i.e., display the name of my current directory on the screen. |
| hostname | Print the name of the local host (the machine on which you are working). Use netconf (as root) to change the name of the machine. |
| whoami | Print my login name. |
| id username | Print user id (uid) and group id (gid), effective id (if different from the real id) and the supplementary groups. |
| date | Print or change the operating system date and time. E.g., change the date and time to 2000-12-31 23:57 using this command. date 123123572000. To set the hardware clock from the system clock, use the command (as root) setclock |
| time | Determine the amount of time it takes for a process to complete + other info. Don't confuse it with date command. E.g. I can find out how long it takes to display a directory content using: time ls |
| who | Determines the users logged on the machine. |
| rwho- | Determine all users logged on network. The rho service must be enabled for this command to run. If it isn't, set up root to enable "rwho". |
| finger user_name | Show system info about you. Try: finger root last Show the last users logged on your system. |
| history | Show the last (1000 or so) commands executed from the command line on the current account. The "more" causes the display to stop after each screen. |
| uptime | Amount of time since last reboot. |
| ps | (print status) List the processes currently running by the current user. |
| ps axu | more | List all the processes currently running, even those without the controlling terminal, together with the name of the user that each processes. |
| top | Keep listing the currently running processes, sorted by cpu usage (top users first). In KDE, you can get GUI-based top from "K menu" under "System-Task Manager (or by executing "top" in an X-terminal). |
| uname -a | Info on your server. |
| free | Memory info (in kilobytes). (=disk free) Print disk info about all the filesystems (in human-readable format) |
| du /bh | more | Print detailed disk usage for each subdirectory starting at root (in human legible form). |
| cat /proc/cpuinfo | Cpu info. Note that the files in /proc directory are not real files. They are hooks to look at information available to the kernel. |
| cat | List the interrupts in use. |
| /proc/interrupts | |
| cat /proc/version | Linux version and other info. |
| cat | Show the types of filesystems currently in use. |
| /proc/filesystems | |
| cat /etc/printcap | (as root. Use /sbin/lsmod to execute this command when you are a non-root user.) Show the kernel modules currently loaded. |
| lsmod | |
