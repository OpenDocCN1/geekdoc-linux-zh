| less filename | Scroll through a content of a text file. Press q when "Less" is roughly equivalent to "more", the command you know from DOS, although very often "less" is more convenient than "more". |

| pico filename | Edit a text file using the simple and standard text editor pico. |

| pico -w filename | Edit a text file, while disabling the line wrap. Handy for editing configuration files, /etc/fstab. |

| lynx file.html | View an html file or browse the net from the text mode. |

| tar -xvf | Untar a tarred and compressed tarball (*.tar.gz or *.tgz) that you downloaded from the Internet. |

| filename.tar.gz | Untar an uncompressed tarball (*.tar). |

| gunzip filename.gz | Decompress a file (*.gz or *.z). Use gunzip (also zip or compress) if you want to compress files. |

| bzip2 filename.bz2 | Decompress a file (*.bz2) with bzip2 compression utility. Used for big files. |

| unzip filename.zip | Decompress a file (*zip) using a compression utility that could also be used PKZIP for DOS. |

| find -name "filename" | Find the file name containing the string on your filesystem search from the root directory "/" . The "filename" may contain characters (*). |

| locate filename | Find the file name containing the string "filename". Easier and faster than the previous command which depends on a database that normally builds at. |

| mc | A good text-mode mail reader. A good and standard one is "elm". Your Newscat will read the mail from your Internet account. Pine let you read the "local" mail, the mail your son or a cron process seeks to you from a computer on your network. The command could also be used for reading/compiling mail messages environment--it is meant to be used in scripts for automation. |

| talk username1 | Talk to another user currently logged on your machine (or use "talk username@hostname" "talk username"). If someone is trying to talk to you and it disrupts your work, you may use the command "msg n" to refuse accepting messages. You may want to use "who" or "who're" to determine the the users who are currently logged in. |

| mc | Launch the "Midnight Commander" file manager (like "Norton Commander" for Linux). |

| telnet server | Connect to another machine using the TELNET protocol. Use a remote machine name or IP address. You will be prompted for your login name and password--you must have an account on the remote machine to login. Telnet will connect you to another machine and let you operate it if you were sitting at its keyboard (almost). Telnet is not very secure--everything you type in open text, except your password! |

| rlogin server | (=remote) Connect to another machine. The login name/password from your current session is used; if it fails you are prompted for a password. |

| rsh server | (=remote) Yet another way to connect to a remote machine. The login name/password from your current session is used; if it fails you are prompted for a password. |
