(sp status) Display the list of currently running processes with their process IDs (PID) numbers. Use "ps axu" to see all processes running on your system (also those of other users or without a controlling terminal), each with the name of the owner. Use "top" to keep the processes currently running.

fg PID Bring a background process to the foreground.

bg PID Send the process to the background. Opposite to fg. The same can be accomplished with <Ctrl>z.

any_command& Run any command in the background (the symbol "&" means running the proceeding command in background).

kill PID Force a process to shutdown. Determine the PID of the process to kill us.

killall Kill program(s) by name.

program_name (in an xwindow terminal) Kill a GUI-based program with mouse. (Point with your mouse cursor at the window of the process you want to kill and click.)

lpc (as root) Check and control the process. Use "top" to see the list of available commands.

job_number Remove a printing job "job_number" from the queue.

nice program_name Run program adjusting its priority. Since the priority is not specified in this example, it will be adjusted by 10 (the process running since, from the default value (usually 0)). The lower (of "nicness" to others on the system), the higher the priority. The priority value may be in the range -20 to 19. Only root may set negative values. Use "top" to display the priorities of the running processes.

renice -1 PID (as root) Change the priority of a process to -1. Normal users can only adjust processes they own from the current value (make them slower).

Please note the following shortcuts: <Ctrl>c, <Ctrl>z, <Ctrl>s, and <Ctrl>q. They were described previously [p 107].
