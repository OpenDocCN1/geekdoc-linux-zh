This sets up the default policy to "deny" and explicitly masquerades two machines with IPs 192.168.1.1 and 192.168.1.3. It also masquerades any machine from the network 192.168.2.0. The number/32 stands for point-to-point networking (this means "machine-to-machine"), the option /24 identifies a class C network. The -D 0.0.0.0 identifies the default route that the machines are masqueraded to go out to the Internet.

ON RED HAT 6.0 THE NAME OF THE COMMAND is ipfwadm-wrapper (instead of ipfwadm) and I had to use the second, more secure method (setting up masquerading as the default policy does not work on any system at).

If you would like to have this command(s) always executed on your system startup, add it as the last line(s) to the file /etc/rc.rc.local. This file is like AUTOEXEC.BAT in DOS. As always, it is recommended to read the manual page and documentation to see what the command(s) does and what are the other options:

```
less /usr/doc/HOWTO/mini/IP-Masquerade
man ipfwadm
```

# 4.5 How to use Samba?

Samba (smb) is for Linux-MS Windows networking. It is a program that makes a Linux computer pretend to be a Windows NT server, and lets your MS Windows 3.1/95/98-based computers connect to the network printer. Samba not replaces WinNT-it is acclaimed to be a much better job than WinNT!

One of the three machines on my home network is a dual Linux/Win95 boot. I configured my network so that if I boot Win95, another Linux machine acts as a Samba server. This way, the Win95 machine has access to the network printer, shared directories on Linux, the Internet through a medium on Linux, can telnet, browse the I can also access the files on the remote Win95 machine from Linux computers.

It is necessary to configure Samba only on one Linux machine.

First, I ran setup as, choose "System Services" (RH6.0) or "ntsyserv" (RH2.5) from the menu, and make sure that the "samba" service is enabled. (The program setup has help if you were curious what the different services are for.) If samba is not installed, there may you not install it during your RedHat setup? You may want to put your RedHat CD into the CDROM, the cd start (RH5.2) or gnornp (RH6.0) installation utility (as root) and Samba to your system.

The second part is to configure Samba. This is relatively simple since the Samba configuration is done through a single, well commented file: /etc/samba.conf. The minimum setup includes specifying the workgroup name. Note that if you don't fill the "host" option, all hosts are allowed, which is probably ok for the home network. The other options in the example /etc/samba.conf supplied with your RedHat CD may require adjustment to suit your particular needs, but they don't have to be changed to be a Windows machine connected to your Samba server.
