### 4.5.2 How to set up my home network?

If you have more than one network card on your computer, you must also set up the second cards manually, since Linux autodetect 1 network card.

Start an X-terminal, execute "su" (to make yourself a root) and then run:

```bash
/usr/bin/kernelcfg
```

Under Linux, most drivers for network cards are implemented as modules. So setting up a card involves just inserting the module with its parameters. You don't need to recompile the kernel, nor ever reboot your computer (unless you have an uncommon card). Inspect the files /proc/interrupts, /proc/ioport and rebooting boot messages may help.

For example, your WD8013 card (same as SMC Elite and SMC Elite plus, under IRQ 10 (set by a jumper on the card and I specified the IRQ in the kernel module setup) under the address 0300 and used the "WD" module. My "SMC EtherZ" card (no jumper settings on the card) runs under IRQ 9, address 0240 and uses "SMC EtherZ" module. Please make sure you don't omit the leading "0x" in the address—it means "hexadecimal" and otherwise the number will be interpreted as decimal.

After the module is added from kernelcfg and the kernel is re-run (kernelcfg provides this, see the menus), inspect the file /proc/modules to see if the module is indeed loaded (or run lsmod as root). Information from kernelcfg goes to the /etc/conf.modules so if you encounter difficulties (for example, I had difficulty removing modules inserted by mistake), just edit and adjust this manual, e.g., using pico.

Try to invent something that does not exist—it will make your life easier if you have a permanent connection.

As for the DNS server (also called "named") RedHat 5.2 and 6.0 comes with DNS preinstalled as "caching-only"—it is so easy to choose. You may also choose not to use DNS at all—if DNS is up a server and can find it.
