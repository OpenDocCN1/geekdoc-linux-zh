```
# run-parts root run-parts /etc/cron.hourly
01 * * * root run-parts /etc/cron.daily
02 4 * * root run-parts /etc/cron.weekly
22 4 1 * root run-parts /etc/cron.monthly
```

You can see that there are four categories of cron jobs: performed hourly, daily, weekly and monthly.
You can modify those or add your own category. Here is how it works.

The columns in the entries below show: minute (0-59)

Thus, in the example quoted, the hourly jobs are performed every time the clock clock shows "and one minute," which happens every hour, at one minute past the hour. The daily jobs are performed every time the clock shows 2 minutes past 4 o'clock, which happens a day. The weekly jobs are performed at 22 minutes past four o'clock on Sundays. The monthly jobs are performed 42 minutes past four o'clock on the first day of every month. The directory with the script file that contains the command(s) is to executed as the last entry on each line.

If you wanted jobs to be performed at noon instead of 4 in the morning, change the 4s to 12s. Cron wakes up every minute and examines if /etc/crontab has changed so there is no need to re-start after you make your changes.

If you wanted to add a job to cron, place a script which runs your job (or a link to your script) in the directory /etc/cron.hourly or cron.daily or /etc/cron.weekly, or /etc/cron.monthly.

# 3.4 Swap space

Swap is an extension of the physical memory of the computer. Most likely, you created a swap partition during the initial RedHat setup. You can verify the amount of swap space available on your system:

```
/proc/meminfo
```

The general recommendation is that one should have: at least 4 MB swap space, at least 32 MB total (physical+swap) memory for a system running command-line-only, at least 64 MB of total (physical+swap) memory for a system running X-windows, and swap space at least 1.5 times the amount of the physical memory on the system.

If this is too complicated, you might want to have a swap twice as large as your physical (silicon) memory, but not less than 64 MB.
