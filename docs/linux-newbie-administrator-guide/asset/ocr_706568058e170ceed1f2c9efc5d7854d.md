# The Linux Kernel mirror at Sunsite.uio.no

All transfers are logged. If you don't like this policy please disconnect.

Welcome to the Linux Kernel Archives. This is an official mirror site for the Linux kernel source. Please see
http://www.kernel.org/mirrors/ for information about how to connect to another kernel-mirror.site.

| Protocol | URL |
|---|---|
| HTTP | http://linux-kernel.uio.no/pub/ |
| FTP | ftp://linux-kernel.uio.no/pub |

What is Linux?A Unix clone written from scratch by Linus Torvalds with a loosely-knit team of hackers across the Net. It aims towards POSIX compliance.
