

UNIX 提示的注意事项：例如：Netscape、NETSCAPE 和 nEtscape 是三个不同的命令。同样，my_fiE、my_file 和 my_fILE 是三个不同的文件。你的用户登录和密码也是区分大小写的。（这符合 UNIX 和 "C" 编程语言区分大小写的传统。）

- 1. 文件长度最多可达 256 个字符，可以包含字母、数字、."（点）、_（下划线）、-（连字符）以及其他不推荐的字符。
- 2. 以 ".*" 开头的文件通常被 ls（列出）或 dir 命令显示。将这些文件视为“隐藏”文件。使用 `ls -a` 查看这些文件。
- 3. "/" 等同于 DOS 的 "\"（根目录，意味着所有其他目录的父目录）。
- 4. 在 Linux 下，所有目录都出现在单一目录树下（没有 DOS 风格的驱动器号）。
- 5. 在配置文件中以 # 开头的行是注释。

## 6.1 Linux 基础快捷键和常用命令

| 快捷键 | 描述 |
|---|---|
| <Ctrl><Alt><F1> | 切换到第一个终端。在 Linux 下，你可以同时打开多个终端。 |
| <Ctrl><Alt><Fn> | (n=1,6) 切换到第 n 个终端。 |
| <Ctrl><Alt><F7> | 切换到第一个终端（如果正在运行）。 |
| <Ctrl><Alt><Fn> | (n=7,12) 切换到第 n 个 GUI 终端（如果屏幕 n-1 正在运行 GUI 终端） |
| <Tab> | 自动补全命令（帧）。这个快捷键非常好！它在 LILO 提示符下也有效！ |
| <ArrowUp> | 滚动并编辑命令历史。按 [Enter] 退出。 |
| <Shift><PgUp> | 滚动终端输出。在登录提示符处工作，可以滚动查看启动信息。 |
| <Shift><PgDown> | 滚动终端输出。（在 X-Windows 中）如果你将 X 服务器设置了多个分辨率。如果你的系统 VGA 显卡/显示器有多个分辨率，当第一个分辨率启动时，在文件 /etc/X11/xFree8Config 中包含以下行，用于确定“虚拟屏幕”的大小：Modes "1024x768" "800x600" "640x480" "512x384" "480x300" "400x300" |
| <Ctrl><Alt><+ | （在 X-Windows 中）更改 X 服务器的分率。 |
| <Ctrl><Alt><BSpace> | （在 X-Windows 中）杀死 X-windows 服务器。当 X-windows 服务器崩溃且无法正常退出时使用。 |
| <Ctrl><Alt><Del> | 关机并重启。这是文本模式控制台用户的正常关机命令。不要只按“reset”按钮关机！ |
| <Ctrl>c | 杀死进程。 |
| <Ctrl>d | 退出当前终端。 |
| <Ctrl>d | 向当前进程发送 [文件结束 (EOF)]。不要按两次，否则也会退出（见上一个命令）。 |
| <Ctrl>s | 停止向终端传输。 |
| <Ctrl>q | 恢复向终端传输。如果你的终端其妙停止响应，请尝试此。 |
| <Ctrl>z | 将当前进程发送到后台。 |
| reset | 将异常的终端（显示奇怪字符的终端）恢复到默认设置。如果你尝试“cd 进入一个二进制文件”，你可能在输入命令时看不到它。 |
| <MiddleMouseButton> | 粘贴当前在其他某处高亮的文本。这是 Linux 中标准的“复制-粘贴”操作。它在记事本和 Word 中不起作用，它们使用 Windows 风格的“复制-粘贴”。最好配合支持 Linux 的 3 键鼠标（罗技或类似产品）。 |
| ~ | 我的家目录。例如，cd ~/my_dir 将我的工作目录更改到家目录下的子目录 "my_dir" 中。仅输入 "cd" 等同于命令 "cd"。 |
| . | 当前目录。例如，./my_program 将尝试执行位于当前工作目录下的 "my_program" 文件。 |
| .. | 当前 . 的父目录。 |

|---|---|

| rwho- | 确定所有登录到网络的用户。必须启用 rho 服务才能运行此命令。如果没有启用，请配置 root 以启用 "rwho"。 |

| history | 显示当前账户从命令行执行的最后（约 1000 条）命令。使用 "more" 会导致显示在每页屏幕后停止。 |
