- passwd group_name 修改你当前账户的密码。如果你是 root，可以使用 `user_name` 更改任何用户的密码。

- chmod (-更改模式) 更改你所拥有文件的访问权限（除非你是 root，在这种情况下你可以更改任何文件）。你可以通过三种模式使文件可访问：读 (r)、写 (w)、执行 (x)，适用于三类用户：所有者 (u)、所有者所在组的成员 (g)、系统上的其他用户 (o)。使用以下命令检查当前访问权限：
`ls -l filename`
如果对所有用户都可访问，它将显示：
三元组显示了文件所有者的权限、文件所属组的权限，第三个是针对其他人的权限。“无权限”将向对读取文件“junk”的权限添加到所有用户 (=user+groups)：
`chmod a+ junk`
这将移除 junk 文件的执行权限：
`chmod o-x junk`
也可以在此处尝试获取更多信息。
你可以使用命令 `umask` 为你创建的新文件设置默认权限（参见 man umask）。

- chown new_owner filename 更改文件所有者。当你复制一个文件供他人使用后，应该使用这两个命令。

- chgrp new_group filename (替换 id) 假设是超级（root）身份（将提示你输入密码）。输入 "exit" 返回原来的位置。不要在你的机器上以 root 身份工作。root 账户用于管理，sudo 命令确保你在需要时具有管理访问权限。

- rpm -ivh filename.rpm (=RedHat软件包，安装，显示哈希以显示进度，以 root 身份运行。) 安装 RedHat rpm 包的内容并打印发生情况的信息。如果你正在进行 GUI 安装，则可以保留它。

- rpm -qpi filename.rpm (=RedHat软件包，查询， 软件包, 列表。) 读取未安装的 package.rpm 内容的信息。

- rpm -ql filename.rpm (=RedHat软件包，查询， 软件包, 信息。) 查找未安装的软件包文件名（在你的硬盘上）中包含包含的文件。

- rpm -e packagename (=RedHat软件包，删除-卸载。) 安装包。Packagename 与 .rpm 相同（不带连字符和版本号）。
