You can access (read and write) a variety of drives and file systems from under Linux. This includes native Linux partitions, DOS and MS Windows partitions (on hard drives or floppies), ZIP and Jazz drives, and CDROM drives. Many common file system types are also supported. # 4.2.2 How I access my CDROM?

Mount it. The mounting adds all the drives and files from your CD to your Linux directory so you can easily access them without the drive letter.

As root, you can mount the CDROM with a command like this:

```
mount -t auto /dev/cdrom /mnt/cdrom
```

If this works, the content of your CD appears in the directory /mnt/cdrom right away—you may have to customize it. Here is how it works.

The command tells the operating system to mount a filesystem autodetecting the filesystem type ("-t auto"). The device is /dev/cdrom. The mountpoint (the directory where which "mounting" takes place) is /mnt/cdrom. This directory must exist and be empty. If it does not exist, create it with:

```
mkdir /mnt/cdrom
```

If the mounting command fails, make sure that check the device /dev/cdrom exists. If it doesn't, where is your CDROM? Chances are it something like /dev/hdb if you have an IDE CDROM. Try /dev/hdb instead of /dev/cdrom in the mount example above. If this fails, you can try /dev/hdc or /dev/hld, if your cd is an IDE CDROM. If none of them is your CDROM, you might not have a drive but a SCSI CDROM? Try /dev/sda1, /dev/sda2, etc. ["hda" is the primary IDE master drive, "hdb" is the primary IDE slave drive, "hdc" is the secondary IDE master if you have two interfaces on your computer, hdd is the secondary IDE slave, "sda" is the first SCSI interface and the number is.]

It is a good idea to have a device /dev/cdrom anyway because some programs assume that it exists. If it does not exist on your system, you may create it as a symbolic link, for example:

```
ln -s /dev/hdb /dev/cdrom
```

if your cd is the /dev/hdb drive.
