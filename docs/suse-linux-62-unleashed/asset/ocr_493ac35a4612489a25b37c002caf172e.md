After you have formatted a floppy, don't forget to use mkfs to build a filesystem on it. (See the "Creating New Filesystems" section earlier in this chapter.)

# CD-ROM Drives

The CD-ROM device is fundamentally another kind of read-only block device. They are mounted in just the same way as other block devices. CD-ROMs almost always contain standard ISO 9660 filesystems, often with some optional extensions. There is no reason, however, why you could not use any other filesystem (such as hpf s for a Macintosh CDROM). Once you have mounted your CD-ROM, it behaves like any other read-only filesystem.

You can set up and mount your CD-ROM drive by using the mount command:

```
# mount /cdrom
```

Of course, if you'd manually mount your CD-ROM to a different point in the filesystem (as previously shown in the section titled "The mount Command").

```
# mount /dev/cdrom -t iso9660 /mnt/cdrom
```
