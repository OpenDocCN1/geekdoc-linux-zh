# SuSE System Administration
PART III

If you have trouble deciding which filter to select, look at the /var/lib/apsfilter/doc/printer file to find a match for your printer. After selecting a filter, select the printer format (such as letter), the port printer is connected to, and the device name, as shown in Figure 24.5.

# FIGURE 24.5
Select the parallel port assigned to your printer.

![](bbox=[0.298, 0.215, 0.725, 0.345])

After selecting the correct port, you can then choose a printing resolution (which must match your printer's capabilities). When finished, press the Tab key and press Enter when the Install button is selected. The vast command will run the apsfilter configuration software and report that it has created three different printers, the apsfilter as shown in Figure 24.6.

# FIGURE 24.6
The apsfilter script will create three /etc/printcap entries to your printer.

![](bbox=[0.298, 0.563, 0.725, 0.693])

Carefully note these three printer names; each describes your configuration's capabilities:

+   - ascii—The designated printer name to use when printing text documents; forces
