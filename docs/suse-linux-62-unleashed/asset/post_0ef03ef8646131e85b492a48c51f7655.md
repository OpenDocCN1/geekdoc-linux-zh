# Note

Most EIDE hard drives allow primary partitions. However, some computers, especially laptops, may use a special partition for "save-to-disk" hibernation or power saving. Do NOT delete or change a power-management partition, or you could render that power-management feature useless. If you see a partition equal to twice the size of your computer's RAM listed in the partition table, leave it alone (and make note of the partition device, size, and type).

You'll be asked to choose a primary partition, such as /dev/hda2, /dev/hda3, or /dev/hda4 (see Figure 2.10).

FIGURE 2.10
Choose a device when choosing a primary partition.

![](img/cbac72550c7126a22162e94d91a0c360_64_0.png)

After you choose the partition device number, you'll be asked to choose a partition size (see Figure 2.11). This is an important step. SuSE Linux will automatically choose the first available cylinder, and use this number for the Starting cylinder.

FIGURE 2.11
Choose the starting and ending cylinder numbers of a new partition.

![](img/cbac72550c7126a22162e94d91a0c360_64_1.png)

The End of partition is used to determine the partition's size. To make things easier, you can use notation "+132M" to create a 132MB partition. Otherwise, you will need to calculate the storage capacity of each cylinder and enter the ending cylinder number. To make the install even easier, create this partition to equal the size of the Linux swap for your installation. For example, if you have a 64MB computer, create a 128MB partition. When finished, Tab to select the Continue button and press Enter.
