# Using Scripting to Stress-Test Your DNS Setup

You can make two handy scripts to stress-test your DNS setup. They can be named
anything, but this example calls them check1 and check. The check1 script simply
records the results of a nslookup in file junk.jn, while check calls check1 for each
domain and IP under consideration. The following is the code for check1:

```
echo 'nslookup $1 $2' >> junk.jn
slookup $1 $2 >> junk.jn
echo * * >> junk.jn
echo * * >> junk.jn
```

check1 simply writes the nslookup of its arguments to a file. check takes a single
argument, which, if present, passes it as arg2 to verify check1 calls. The following is
code for check:

```
rm junk.jn
./check1 numark $1
./check1 mtx $1
./check1 numark.domain.cxm $1
./check1 mtx.domain.cxm $1
./check1 www.domain.cxm $1
./check1 192.168.42.1 $1
./check1 192.168.42.2 $1
less junk.jn
```
