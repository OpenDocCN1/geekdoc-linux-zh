Another great debugging technique, especially after you've restarted it, is to look at the system log. You can find what file contains the appropriate log by looking in /etc/rsyslog.conf. Default for SuSE 6.2 is /var/log/messages. Because you're interested only in recent measures, grab the tail end of the file with the following command:

```
# tail -n /var/log/messages ; less -N
```

All log entries have date and time, so if you need to be read back more than 400 lines. Look especially for error, not found , no such , fail, and so on. Carefully evaluate any error messages and try to figure what they mean and what caused them.

# Other DNS Documentation

Although this chapter covers the most needed DNS information, a complete discussion of DNS could easily fill a large book. The following are some further sources of DNS documentation.

# /usr/doc/howto/en/DNS-HOWTO.gz

This file, installed on your SuSE 6.2 machine, presents a slightly deeper view of DNS than this chapter.

# /usr/doc/LDP/nag/index.html

The Network Administrator's Guide, which contains a simple overview of DNS.

# /usr/doc/packages/bind/

Note that the contents of this directory might be different, depending on your SuSE distribution. This directory contains the FAQ, the README.linux file, and several other useful files and a Perl script.

# http://www.math.uio.no/~jan1/DNS/

Documentation for the old DNS 4.

# http://www.dns.net/dnsrrd/

The DNS Resources Directory.
