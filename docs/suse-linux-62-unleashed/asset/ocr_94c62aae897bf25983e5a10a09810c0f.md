You can also manage a filesystem. It is important if you want to mount a floppy disk as a msdos filesystem. The following command will mount a floppy disk to /mnt/floppy. Remember to unmount the disk before removing it.

```
mount -t msdos /dev/fd0 /mnt/floppy
```

Unmounting is just a simple command:
unmount /mnt/floppy

Rather than specifying the mount point, you can also use mount with the name of the device:
mount /dev/fd0
