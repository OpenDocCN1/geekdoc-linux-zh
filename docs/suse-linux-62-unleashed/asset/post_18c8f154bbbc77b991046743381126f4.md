# Starting the Server Manually

The Apache server, httpd, has a few command-line options you can use to set some
defaults specifying where httpd will read its configuration directives. The Apache httpd
executable understands the following options:

```
httpd [-d directory] [-f file]
  -C "directory" -c "directory"
  -v [-V] -h [-l] [-L] [-S] [-t]
```

The -d option verifies the location of the ServerRoot directory. It sets the initial value of
the ServerRoot variable (the directory where the Apache server is installed) to whichever
path you specify. This default is usually read from the ServerRoot directive in
httpd.conf.

The -f flag specifies the location of the main configuration file, conf/httpd.conf. It reads
and executes the configuration commands found in ConfigurationFile on startup. If
Configuration is not an absolute path (it doesn't work with a /), its location is
assumed to be relative to the path specified in the ServerRoot directive in httpd.conf.
By default, this value is set to ServerRoot/httpd.conf.

The -v option prints the development version of the Apache server and terminates the
process.

The -V option shows all of the settings that were in effect when the server was compiled.

The -h option prints the following usage for the server:

```
Usage: httpd [-d directory] [-f file]
  -C "directory" [-c "directory"
```
