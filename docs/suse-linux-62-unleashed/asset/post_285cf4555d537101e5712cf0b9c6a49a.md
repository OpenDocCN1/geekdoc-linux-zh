## Playing Games with the Emacs Editor

If you don't want to specify a timer, press Enter after starting the game. To move the pawn up two squares from the lower rank, enter e2e4 and press the Enter key. The computer makes its moves, and new piece positions are updated on your display. To quit, type the word quit and press Enter. The program has more than 23 command-line options and features displaying play modes, hints, and timed games.

The Emacs editor included with SuSE Linux not only edits texts, reads mail, and handles your appointments, but also comes with 18 wacky games and modes that you can use to pass the time, such as doctor, dunnet, psychoanalyze-pinhead, and yow.

To play dunnet, a text adventure, use Emacs from the command line:

```
# emacs -batch -1 dunnet
```

### Strategy Games for X11
This section introduces you to some popular strategy games for X11. There are literally hundreds of games that will work with SuSE Linux. Many games are graphic renderings of classic games, such as chess, backgammon, or mahjong, while others are original games.

### Play Chess with the 3Dc Client
Chess is a classic game, and one of major challenges you can face is playing chess against your computer. You'll find a unique game, 3Dc, included with SuSE Linux, that plays chess in three dimensions (see Figure 30.2). Veteran Linux users and chess players will also be familiar with the 3Dc client, shown in Figure 30.3. This program uses the GNU chess engine and can play chess over the Internet.
![](img/cbac72550c7126a2216e94d91a0c360_972_1.png)

### Graphics, Multimedia, and Productivity Tools

The 3Dc X11 client plays three-dimensional chess.

The 3Dc client recognizes many X11 toolkit options, such as geometry settings, and has 54 different command-line options. If you have a display smaller than 1024×768 pixels, use the -minsize command-line option to fit the board on your screen, like this:

```
# xboard -size
```

The chess board window appears and controls for using a timer, switching players and positions, or controlling other aspects of the match.

### Play Solitaire with xpat2
Although there are many different solitaire games for X11, one of the best is the xpat2 X11 client, created by Heiko Eissfeldt and Michael Bischoff. This program (shown in Figure 30.4) features 14 different solitaire games with scoring, built-in help, and sound. Start the game from the command line of a terminal window, like this:

```
# xpat2
```

If Linux is configured to work with your computer's sound card, you'll hear whooping when you win, "goodbye" when you quit. Although the xpat2 client is not included with this book's SuSE Linux distribution, you can find a copy at http://metalab.unc.edu/pub/games/solitaires/. If you use KDE, you'll find the kpat client offers at least 10 different solitaire games you can play right away. See "Games for the K Desktop Environment" later in the chapter.

The xboard client uses the GNU chess engine to play devastating chess matches.

### Playing Backgammon with xgammon
The xgammon client, by Lambert Klassen and Detlef Steuer (shown in Figure 30.5), will provide hours of backgammon fun and practice. This game (unlike other X11 games) runs comfortably on an 800 × 600 pixel display. Start xgammon from the command line of a terminal window like this

```
# xgammon
```

The xgammon game provides a challenge and features various types of play.
![](img/cbac72550c7126a2216e94d91a0c360_975_0.png)

> Note
> For the xgammon client on a favorite game site or try Gary Wong's GNU gnubg backgammon client, available at http://www.gnu.org/software/gnubg.html.

The xgammon client has 21 different command-line options. For an interesting variation, try watching your computer play itself.

```
# xgammon -g cvc
```

Other challenging games may be created by editing the board and placing backgammon stones in different positions before play.

### Playing Mah-jongg with mahjongg
The mahjong client, included with the popular KDE Desktop Environment, is a beautiful rendition of the tile solitaire game. This game, by Mathias Mueller, also runs comfortably on an 800 × 600 pixel display. Although most users will start the game by clicking on the K desktop panel's Application Starter button, selecting Games, and then clicking the Mahjong menu item, mahjongg may be launched from the command line of a terminal window like this:

```
# mahjongg&
```

The mahjongg game is a colorful and easy-to-play game of tile solitaire.
