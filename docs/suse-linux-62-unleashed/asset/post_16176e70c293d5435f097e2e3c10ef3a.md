## FIGURE 24.6
The apsfilter script will create three /etc/printcap entries to your printer.

![](img/cbac72550c7126a22162e94d91a0c360_761_1.png)

Carefully note these three printer names; each describes your configuration's capabilities:

- ascii—The designated printer name to use when printing text documents; forces...
- lpr—The (auto)printer name used to print PostScript documents and graphics; automatically recognizes different types of documents by the extension (such as .ps)
- raw—The printer used when raw output and speed are required when printing, such as straight text documents

These printer definitions are created in /etc/printcap, and each will have its own /var/spool/lpd directory. The apsfilter filter and associated scripts reside in a directory, or printer queue, under /var/spool/lpd with the assigned names.

After setting up your printer, you can then use the -P option of the lpr command, followed by the printer's name and the name of the file you'd like to print. For example, to print a file called myfile.txt, enter the following:

```bash
# lpr -P myfile.txt
```

An even better test of the capabilities of the apsfilter system is to print a PostScript graphic on your printer. For example, if you're using X11, use the g command to load the file tiger.ps like this:

```bash
# g /usr/share/ghostscript/5.10/examples/tiger.ps
```

You'll see the graphic shown in Figure 24.7.

## Creating Remote Printers with YaST
To set up SUSE Linux to be able to print to a remote printer, you must first run the apsfilterSETUP script, located under the /var/lib/apsfilter directory, like this:

```bash
/var/lib/apsfilter/SETUP
```

After you press Enter, you'll see the dialog shown in Figure 24.8.

![](img/cbac72550c7126a22162e94d91a0c360_763_0.png)

Scroll down and press Enter on the ENTRY menu, as shown in Figure 24.8. You'll then see a dialog to start configuration for remote printer (see Figure 24.9).

![](img/cbac72550c7126a22162e94d91a0c360_763_1.png)

Select the DEVICE item and press Enter. You'll then see a dialog offering the choice of several different printers (see Figure 24.10). Scroll down, select the REMOTE menu item, and press Enter. You'll see the Host Name dialog, as shown in Figure 24.11. Type in a hostname of the computer with the remote printer, and press OK. This information will be used in the REMOTE entry created by SETUP afterwards shown in Figure 24.12.

This dialog is used to save your remote printer definition. Scroll down to the Add menu item and press Enter. The SETUP command should report that a remote printer entry has been created. In /etc/printcap:

```
### BEGIN apsfilter: ### remote printer aptiva ip
# Warning: Configured for apsfilter, do not edit the labels!

# setup Mon Sep 27 17:48:10 EDT 1999
# remote|lp|aptiva-lp|aptiva lp|
:lp=:
:rm=aptiva|
:rp=lp|
sd=/var/sp/lpd/aptiva-lp|
:lf=/var/sp/lpd/aptiva-lp/log/
:af=/var/sp/lpd/aptiva-lp/acct/
:ark=mx@:
:tr=cl-sh

### END apsfilter: ### remote aptiva lp ###
```

The rm and rp entries define the remote host and printer. The remote machine (aptiva in this example) has a configured printer name lp and should also have a properly configured hosts.lpd file under the /etc directory. For example, to enable printing on the lp queue from other computers, you should enter a list of allowed remote hostnames in aptiva's /hosts.lpd file, like this:

- ascentia.home.org
- presario.home.org
- hitachi.home.org

This allows print jobs from the three listed computers. However, in order to print properly prepared streams of text, you will need to configure filters for the remote computer. After you add the remote printer, return through the SETUP menu to the DEVICE section and press Enter. You'll again see the dialog as shown in Figure 24.10. This time, scroll down and select the PREFILTER menu item. You'll then see a dialog listing configured printers (see Figure 24.14).
