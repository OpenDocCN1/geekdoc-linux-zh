For now, press Enter to continue. You will be able to allow the SuSE Linux installer to write this partition table to your hard drive. Select Yes and press Enter. SuSE will write the partition table to drive your drive. The installer will then ask you to select the partition for Linux swap, as shown in Figure 2.17.

FIGURE 2.17
After writing your partition table to disk, SuSE Linux will ask you to select the swap partition for formatting.

![](bbox=[0.31355, 0.46438, 0.92355, 0.70938])

Select the partition and press Enter after highlighting the Continue button. This will format your Linux swap partition. This can take a little time, depending on the size of your swap partition. When finished, the SuSE installer will display a list of filesystems, as shown in Figure 2.18.

This dialog is used to tell SuSE Linux which filesystems should receive what parts of the Linux directory tree or mount point. Press F4 to specify the mount point. These mount points are listed in Figure 2.19.
