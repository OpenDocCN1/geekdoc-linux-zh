# Introduction and Installation SuSE Linux
PART I

In this example, I am going to scroll down, highlight /dev/hda2, then press F4 to delete this partition. Why? Because I am going to have two partitions: one for the SuSE Linux software, and another for a Linux swap drive. After confirming the delete, SuSE Linux will then see the dialog shown in Figure 2.8.

Figure 2.8
Even though existing hard drive partition has been deleted, there is still space for an install.

![](bbox=[0.31, 0.222, 0.903, 0.477])

If you look at Figure 2.8, you'll see that the F5, or Create, button is now available. Even though the dialog does not list the free space available, I know that there should be about 1.36GB of storage for my Linux swap and native partitions. To create a new partition, press F5.

You'll then be asked if you want to create a primary or extended partition (see Figure 2.9). Since there is only one primary partition now on the drive (for DOS), you can select to create a primary partition.

Figure 2.9
You can choose to create a primary or extended hard-drive partition.
