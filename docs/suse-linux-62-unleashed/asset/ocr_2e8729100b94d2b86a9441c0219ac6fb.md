# xtp

Like ftp and nfcpt, John Christy's xtp command can be used to log in and automatically retrieve one or more files from remote computers. For example, the xtp command with a complete FTP command-line address:

```
# xtp ftp://bball@aptiva.home.org/home/happy2.jpg
```

This logs in to the remote FTP server with your username (you'll be prompted for password), retrieves the file happy2.jpg, and quits the connection. The xtp command has a number of command-line options. For details, see the xtp man page or use the text-only lynx browser to read xtp's online documentation:

```
# lynx /usr/doc/packages/ImageMagick/www/xtp.html
```
