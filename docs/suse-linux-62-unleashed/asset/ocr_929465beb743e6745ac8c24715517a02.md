# Components of the XFree86 System

The X Window System is the foundation of the graphical interface for SuSE Linux. Although you can use Linux without X, you'll be less productive and will miss out on a lot of useful programs.

If you installed XI1 when you first installed SuSE Linux, you'll find that most of the X Window system resides under the /usr/X11R6 directory. The yeast command is used during installation to install the XFree86 software. However, you should take care finishing your installation to install the X server appropriate for your hardware. For example, if you have a Mach64-based graphics card, you should install the xserver-mach64 package. See “Configuring Your XFree86 System” later in this chapter.
