# fc

The fc command is used to edit the history file. The parameters passed to it, if there are any, can be used to select a range of commands from the history file. This list is then placed in an editing shell. Which fc uses is based on the value of the variable FCEDIT. If no value is present for this variable, the command looks at the EDITOR variable. If it is not there, the default editor is used, which is vi.

# fdformat

This command only performs a low-level format of a floppy disk. You must then use the mkfs command to place a specified filesystem on the disk.

# fetchmail

This program by Eric S. Raymond gets your mail from your Internet Service Provider (ISP), and can handle a number of electronic mail protocols besides the Post Office Protocol (POP). You use this program by itself or in a shell script to get your mail after you've established a Point-to-Point (PPP) connection.
