# Networking and Internet Services
PART II

It is a pretty standard control file—very similar to all the others in the /sbin/init.d
directory. It starts off by checking that all the various networking services are running; then,
dending on what argument is passed to it (start, stop, status, restart), it performs
t appropriate action. Most of the work is performed in the rc.news file, an example of
is displayed in Listing 10.2.

# LISTING 12.2 Contents of /usr/lib/news/bin/rc.news

```
#/bin/sh
## $Revision: 1.22.2.1 $
## News boot script. Runs as "news" user. Requires inndstart be
## setuid root. Run from rc.whatever as:
## su news -c /path/to/rc.news > /dev/console

  /usr/lib/news/lib/insshellvars

AZ=ABCDEFGHIJKLMNOPQRSTUVWXYZ
az=abcdefghijklmnopqrstuvwxyz
## Pick ${INND} and ${INNDSTART}
WHAT=$${INNDSTART}
## Set to true or false
  : ${DOINWATCH}=true
DOINWATCH=echo "${DOINWATCH}" | tr ${AZ} ${az}
if [ -z "${DOINWATCH}" = "on" \
  -o "${DOINWATCH}" = "true" \
  -o "${DOINWATCH}" = "yes" ]; then
DOINWATCH=true
else
  DOINWATCH=false

: ${DOCNFSSTAT}=false
DOCNFSSTAT=echo "${DOCNFSSTAT}" | tr ${AZ} ${az}
if [ -z "${DOCNFSSTAT}" = "on" \
  -o "${DOCNFSSTAT}" = "true" \
  -o "${DOCNFSSTAT}" = "yes" ]; then
DOCNFSSTAT=true
else
  DOCNFSSTAT=false
```
