```
$cat /proc/cpuinfo

vendor_id : AuthenticAMD
cpu family : 5
model : 8
model name : AMD-K6(tm) 3D processor
stepping : 12
cpu MHz : 350.804507
fdiv_bug : no
hlt_bug : no
sep_bug : no
f00f_bug : no
fpu : yes
fpu_exception : yes
cuid level : 1
wp : yes
flags : fpu vme de pse tsc mce cx8 sep pse mmx 3ndown
bogomips : 699.60
```

```
$ cat /proc/interrupts

1: 251230 XT-PIC keyboard
2: 0 XT-PIC cascade
4: 996021 XT-PIC serial

13: 1 XT-PIC fpu
14: 4253923 XT-PIC ide0
15: 4713316 XT-PIC ide1
```

* sound reports the current sound system configuration and the installed services:

```
$ cat /proc/sound
OSS/Free:3.8s++971130
Load type: Driver compiled into kernel
Kernel: Linux maya.dydnds.2.2.5 #2 Thu Apr 15 18:34:07 EDT 1999 1586
```
