# tcpdump

tcpdump basically works as a packet sniffer—it listens to the network, looks at all packets that come by (whether destined for the host on which it is running or not), and operates on it. It can store all or some interesting parts of the traffic it sees, or perform a rudimentary analysis of the information it contains.

tcpdump works by setting the network card into what is known as promiscuous mode. Normally, a network card will only see packets that are meant for it. However, in promiscuous mode, it will see all packets that pass through the network and pass them to the operating system above. The OS passes the packets to tcpdump, which can then filter and display or store them. Since it modifies the configuration of the network card, tcpdump must be run by root.
