Communications between the two areas (back end and front end) are controlled by the postmaster. The postmaster is a daemon process that runs constantly and manages the connections and memory allocation and also performs the necessary initializations when connections are made. Basically, the front end indicates to the postmaster that it needs a database connection. The postmaster makes the necessary preparations and connects to the back-end server.

# Configuring PostgreSQL for First Use

There is a bit of configuration that must be done after installing the necessary pieces. You need to make sure the postmaster daemon is running and set yourself up as a PostgreSQL user. You can then go about the business of creating databases and manipulating data.

The installation should have placed a copy of the extensive documentation on your system, possibly at /usr/doc/postgresql-x.x.x, where x.x.x is the version number you are using. All of common startup problems are well detailed here.
