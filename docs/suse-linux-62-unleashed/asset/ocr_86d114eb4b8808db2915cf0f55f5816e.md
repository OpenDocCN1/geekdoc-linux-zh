# /sbin/ifconfig eth0 10.1.1.1 netmask 255.255.255.0 10.0.1.255

As its name implies, the optional netmask parameter sets the netmask for the route, which
will be applied to the target address. If omitted, the netmask will be taken from either the
def netmask for the IP address (or in case of routes to local networks) from the
interface's netmask. (See "Network and Network Classes" in this chapter for more
information on the default netmask.)

The optional dev parameter sets the interface on which the packets to this destination wille sent. If omitted, the route command checks the current routing table to find which
interface has a route to the gateway. If no gateway is provided, it determines which
interface can be used to get directly to the target.
