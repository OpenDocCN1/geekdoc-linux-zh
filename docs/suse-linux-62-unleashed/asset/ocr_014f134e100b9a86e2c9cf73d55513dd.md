This section of .twrc contains menu labels followed by an appropriate command for the tw window manager. For example, for "kill", you press your left mouse button on the desktop, drag down to select the Kill menu item, and then press your mouse over the top of a desired window-twwm removes the selected window. Notice that the blank areas in the new menu definition have been spiced up with hyphens for a bit more readability. After making your changes, save the new .twrc file. # Features of the GNU Window MakerWindow Manager

WindowMaker, the GNU X11 window manager (shown in Figure 5.26), is an improved version of the AfterStep window manager. This window manager is named wmaker, and its system-wide configuration files are located under the /usr/X11R6/share/WindowMaker directory. A directory named Gust is installed in your home directory to hold your personal settings. WindowMaker also supports themes-custom collective settings for the desktop. Saving these personal settings (and the state of any running clients) for your X1 session is also known as session management. To start an X session using the windowmaker manager with the startx command, use the windowmaker keyword at the command line:

```
# startx windowmaker
```
