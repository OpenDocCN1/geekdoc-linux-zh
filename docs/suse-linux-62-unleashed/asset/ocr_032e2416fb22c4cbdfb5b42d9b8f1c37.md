# Graphics, Multimedia, and Productivity Tools
PART IV

The software is available at http://www.uk.research.att.com/vnc. A compressed archive of binaries for Linux is available, or you can download the 2.1MB UNIX source code tarball.

# Building and Installing the vnc Software

If you download the binaries, decompress the file with the tar command like this:

```
# tar xvzf vnc3.3_x86_linux_2.0.tgz
```

This creates a vnc directory. Read the included readme file in the directory, or copy the files Xnc, vncserver, vncviewer, and vncpasswd to the appropriate directory.

If you download the vnc source, decompress the archive with the tar command like this:

```
# tar xvzf vnc3.3_3_unixsrc.rgz
```

This creates the vnc_unixsrc directory. Navigate to the directory and then start the build with the xmkmf command like this:

```
# xmkmf
# make World
```

Navigate into the Xnc directory and build the vnc x server like this:

```
# cd Xnc
# make World
```

Finally, install the vnc software (as root) onto the desired installation script, specifying an installation directory like this:

```
./vncinstall /usr/local/bin
```

This completes your Linux software installation. However, if you want to work on the desktops of other computers, you need to download and install the vnc software for the desired platform. For example, if you want to work with a Windows 95 or Windows 98 desktop, download the Win32 vnc software onto the desired computer.
