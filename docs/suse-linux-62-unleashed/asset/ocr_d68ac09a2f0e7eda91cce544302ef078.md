# Playing Mah-jongg with mahjongg

The mahjong client, included with the popular KDE Desktop Environment, is a beautiful rendition of the tile solitaire game. This game, by Mathias Mueller, also runs comfortably on an 800 × 600 pixel display. Although most users will start the game by clicking on the K desktop panel's Application Starter button, selecting Games, and then clicking the Mahjongg menu item, mahjongg may be launched from the command line of a terminal window like this:

```
# mahjongg&
```
