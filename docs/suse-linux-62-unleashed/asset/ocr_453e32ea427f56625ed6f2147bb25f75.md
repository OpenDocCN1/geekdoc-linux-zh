The reader should follow documentation about the configuration of the proptfd server and check with either http://www.cert.org or http://www.proptfd.org for the latest updates.

The main configuration file is the proptfd.conf file, usually located in the /etc or /usr/local/etc directories. If you are familiar with Apache configurations, you may recognize many of the commands utilized in proptfd. If you download the proptfd source from http://www.proptfd.org, sample configuration files are located in the sample configuration directory. SuSE 6.2 has customized the proptfd.conf file and a sample is shown next:

# This is a basic ProFTPD configuration file. It establishes a single
# server and a single anonymous login. It assumes that you have a
# user/group "nobody//"nogroup" for normal operation and anon.

```
ServerName              "powered by SuSE Linux"
ServerType             inetd
ServerAdmin             ftpadm@localhost
DeferWelcome            off
DefaultServer           on
```

Port                    21
# Umask 022 is a good standard umask to prevent new dirs
