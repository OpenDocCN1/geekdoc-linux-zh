> Note
/sbin/init.d/apache is a shell script and is not the same as the Apache server
located in /usr/sbin/httpd is the program executable file, and
/sbin/init.d/apache is a shell script that helps control that program.

You can use the following options when executing the apache script.

+   - start The system uses this option to start the Web server during bootup.
nYou, as root, can also use this script to start the server.

+   - stop The system uses this option to stop the server gracefully. You
You should use this script, rather than the kill command, to stop the
server.

+   - reload You can use this option to send the HUP signal to the httpd server
to have reread the configuration files after modification. (This
option is not available with Caldera's script, or the apachectl
script).

+   - restart This option is a convenient way to stop and then immediately stop
the Web server.

+   - status This option indicates whether the server is running, and if it is, it
pro own the various PIDs for each instance of the server.

For example, to check on the current status, use the following command:

```
/sbin/init.d/apache status
```

That command prints this output:

Checking for service httpd: OK

This indicates that the Web server is running.

> Tip
Use the reload option if you are making many changes to the various server
configuration files. This saves time when you're stopping and starting the server
by having the system reread the configuration files—without requiring
y to remember the PID for the Web server. If you need to know the PID, the
ps aux command can provide that information. Also, the system keeps the PID
(and many other PIDs) in a file located in /var/run.
