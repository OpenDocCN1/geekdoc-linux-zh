# Networking and Internet Services
PART II

Once the configuration files are completed, you need to identify the inet daemon process.
It can be found using the following command:

```
humf2:/etc # ps aux | grep inetd
root      146 0.0 1440 296 ? S 17:32 0:00 /usr/sbin/inetd
root      1564 0.0 1.3 1208 416 ? S 22:38 0:00 grep inetd
```

The process ID is PID 146 is an example—it may be different on your system.
Once the modifications have been made to the inetd.conf file, you need to get the system
reread the configuration file. It is done by sending a HUP signal to the process using the
kill -1 option.

```
humf2:/etc # kill -1 146
```
