Next, try running the following commands:

```
ping 192.168.42.1
ping 192.168.42.2
```

Do each ping from each server. If any IP ping fails, there's a network connectivity problem
that must be solved before you attempt to activate DNS. Once connectivity is proved, do
the following:

```
ping numark
ping mtx
ping numark.domain.cxm
ping mtx.domain.cxm
ping www.domain.cxm
```

Each of the preceding ping commands should succeed and deliver the right IP. If each of
these commands succeeds, try the following:

```
nslookup numark
nslookup mtx
nslookup numark.domain.cxm
nslookup mtx.domain.cxm
slookup www.domain.cxm
nslookup 192.168.42.1
nslookup 192.168.42.2
```

Each command should quickly deliver the expected results. If you have sendmail up and
running, test the IN MX statements with email operations.

Troubleshooting is essentially a process of elimination. Try to determine whether it's the
forward or reverse lookups that are giving you problems. Try to narrow it down to a single
domain, server, or Use ping to make sure you have network connectivity.
