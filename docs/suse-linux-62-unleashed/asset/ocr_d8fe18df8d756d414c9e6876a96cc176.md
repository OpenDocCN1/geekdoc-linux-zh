# # Loading or Creating Configurations

After your Linux native partition is formatted, you'll see the YaST software installation dialog, as shown in Figure 2.21. This is your entry point to installing SuSE Linux.

![](bbox=[0.138, 0.255, 0.88, 0.605])

This menu is used to choose the type of software installation or create a custom software installation configuration. Highlight the Load Configuration menu item and press Enter. You'll see a predefined list of software configurations to choose from, as shown in Figure 2.22.

![](bbox=[0.138, 0.725, 0.883, 0.815])

These configurations range from a minimum 65MB system without X11, development tools, or many network services, to a full 1.36GB installation of everything included in this book's CD-ROM.
