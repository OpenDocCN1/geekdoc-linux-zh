In a manner similar to uninstall, RPM’s query mode uses the name of the package, not
t name of the file in which the package came. You can use the -l option if you want to
 a list of all files “owned” by the kernel package:

# rpm -q1 lx_suse

This outputs the following (partial) list of files:

```
/usr/src/linux
/usr/src/linux-2.2.10.SuSE/COPYING
/usr/src/linux-2.2.10.SuSE/CREDITS
/usr/src/linux-2.2.10.SuSE/Documentation
```

Not all the output is shown here (the SuSE kernel package contains hundreds of
files). In getting a list of the files, you can determine their state by using the -s
option:

# rpm -qs lx_suse
