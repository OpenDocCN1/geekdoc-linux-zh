# kmix

kmix is a KDE family mixer. It is more icon-oriented than kmix. kmix is installed as part of the SuSE 6.2 multimedia initial installation and the selection of the KDE window manager. If you have KDE and did not install the multimedia package, the installation steps are described earlier in this chapter and the files are located on the distribution disk or at http://www.kde.org. Figure 27.8 shows the kmix interface.

> Tip
 obtain a listing of the kmix icons, right-click the mouse in the kmix panel over one of the icons, select Options, and then select Channels for a listing of functions.

kmix has icons instead of labels. It also features context-sensitive help by placing the mouse over a sliderbar for a function; a dialog box appears that shows the name of the function, and if you right-click on the mouse, additional functionality will be shown.

# kmixer

kmixer is an X-11 package that is standard across a number of platforms and operating systems. kmixer is not included in the SuSE distribution, but is a very popular mixer that is available via the Internet at major archive sites.
