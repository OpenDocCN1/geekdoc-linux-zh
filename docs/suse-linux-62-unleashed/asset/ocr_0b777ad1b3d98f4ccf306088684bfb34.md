# Configuring Networking

You'll be asked if you want to set up networking (see Figure 2.30). If you have a network card, select Real Network and press Enter. If you don't use networking, select Loopback Only.

### FIGURE 2.30
Select Real Network or Loopback during

![](bbox=[0.228, 0.213, 0.638, 0.335])

If you configure networking, you'll be asked if you want your computer to be set up as a DHCP client (automatically assign an IP address over a network). If you select No, you'll see a manual configuration dialog, as shown in Figure 2.31.

### FIGURE 2.31
You can manually configure your SuSE network IP address during installation.

![](bbox=[0.228, 0.433, 0.638, 0.653])

You can choose to configure networking during installation, or you can wait until after SuSE Linux is installed. If you choose to abort network configuration, you can later use the y command to configure a network interface. Press Enter to continue the installation after choosing the Loopback Interface or Real Network. If you choose Real Network, you'll also be asked to configure Sendmail, and can choose a permanent or temporary network connection configurations.

After finishing network configuration, press Enter and the SuSE installer will restart your system, as shown in Figure 2.32.
