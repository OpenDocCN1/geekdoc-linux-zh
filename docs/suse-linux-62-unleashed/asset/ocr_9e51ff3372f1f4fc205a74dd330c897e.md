# Networking and Internet Services
Part II

The name you enter should be the one assigned to by your ISP. Click OK and then scroll down in the main dialog box and enter your password. If your IP address is assigned automatically, ensure that asterisk (*) is between the brackets in the Automatic DNS field. You can toggle this feature by pressing the spacebar. When finished, you can select other features, such as tone or pulse dialing, PBX, or other methods of logging in. Your configuration dialog box may look something like Figure 16.6.

# Figure 16.6

Scroll down to the login menu item and click the Select button. You're then asked, as shown in Figure 17.7, to select a type of login, such as PAP/CHAP, CompuServe, Germany T-Online or a non-standard login.

When finished, click Select, and you'll end up at the dialog box shown in Figure 17.5. Select the Exit button and press Enter. To start and test your PPP connection, scroll down to the Run Wvdial menu item and press Enter. The command will launch the wvdial command to dial out and start your connection.
