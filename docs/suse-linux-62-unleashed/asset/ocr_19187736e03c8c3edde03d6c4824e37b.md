# Samba
CHAPTER 16

### TABLE 16.2 Programs Comprising the Samba Suite
| Program | Description |
| smbd | The daemon that provides the file and print services to SMB clients, such as Windows for Workgroups, Windows NT, or Lan Manager. (The configuration for this daemon is described in smb.conf.) |
| nmbd | The daemon that provides NetBIOS nameserving and browsing support. |
| smbdclient | This program implements FTP-like client that is useful for accessing SMB shares on other compatible servers. |
| testparam | This utility enables you to test the /etc/smb.conf configuration file. |
| smbdstatus | This utility enables you to tell who is currently using the smbd server. |
| smbppasswd | This utility changes a user's SMB password in the smbppasswd file. |
| smbrun | This is an interface program between smbd and external programs. |
| smbtar | This is a shell script for backing up SMB shares directly to a UNIX-based tape drive. |
| smbmount | Use this utility to mount an SMB filesystem. |
| smbmnt | Called by smbd to do the work. Generally not called directly. |
| smamount | A utility that unmounts an SMB filesystem.

# Configuration Option Documentation

Samba has hundreds of configuration options. For complete information, search for these three strings on the smb.conf man page: "COMPLETE LIST OF GLOBAL PARAMETERS", "COMPLETE LIST OF SERVICE PARAMETERS", and "EXPLANATION OF EACH PARAMETER". All the same information is accessible in the smb.conf man page.

# Other Documentation

The smb.conf file supports a number of variable substitutions. The %H and %u substitutions are discussed earlier in this chapter. For a complete list and description of these substitutions, search the smb.conf man page for the VARIABLE SUBSTITUTIONS.

The smb.conf file has several options related to name mangling. Name mangling is a method of interfacing with old DOS 8.3 filename conventions and modern filenames conventions. It also relates to case sensitivity, default case, and so on. To see a complete treatise on the subject, search for the string NAME MANGLING in the smb.conf man page.
