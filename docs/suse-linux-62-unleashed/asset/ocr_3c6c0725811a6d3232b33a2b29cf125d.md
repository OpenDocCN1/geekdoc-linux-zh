# Using PostgreSQL psql

Although describing SQL syntax is far beyond the scope of this book, look at a couple of entries in the psql monitor and their results.

The psql monitor environment acts like a shell or command line to the user. Rather than a regular shell prompt, you have a prompt like this:

```
variable=>
```

# Short Exercise

In this short exercise, we will create a table (PostgreSQL calls this *class*). This presents the use of the slash commands and SQL statements while using the psql monitor.

First list the databases:

```
variable=> \1
```

| datname |datba|datpath |
|--------+------+----------|
| template1|100|template1|
| vegetable|501|vegetable |

Try some SQL. Use the CREATE statement to create a table called names, where you will store records of your vegetables. The class will have attributes (also called *fields*).

```
variable=> CREATE TABLE names (vegie_name varchar(40), quantity int);
CREATE
```

The CREATE response lets you know the statement completed, but take a look at the result of that statement by listing the tables:

```
variable=> \d
```

| Database = vegetable |
+----------+------+-------+
| ! Owner | Relation | Type |
+----------+------+-------+
| johndoe | names | table |
