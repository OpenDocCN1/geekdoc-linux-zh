# Introduction and Installation SuSE Linux

PART I

# FIGURE 3.1
The yast installation dialog is used to create or edit boot-configuration for SuSE Linux.

![](bbox=[0.318, 0.085, 0.853, 0.335])

The Append-Line for Hardware Parameter is used to enter messages to the Linux kernel to support various hardware. Most PC users will probably leave this line blank. If you press Enter, you'll then be asked where to install LILO. The yast command offers several choices, as shown in Figure 3.2.

# FIGURE 3.2
The yast command offers at three choices of where to install LILO: the MBR, boot sector of the root (Linux) partition, or on floppy.
