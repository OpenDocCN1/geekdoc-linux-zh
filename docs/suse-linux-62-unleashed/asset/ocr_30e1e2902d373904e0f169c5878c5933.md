# Networking and Internet Services
PART II

TABLE 7.9 Most Common ipchains Options
| Option | Specifies |
| --- | --- |
| [!] -y | Packet is a SYN packet; only for rules that specify -p top. |
| -icmp-type type | ICMP type is type; only for rules that specify -p icmp. |
| -1 | Log the packet to syslog.-n or -numeric. Using with the -I option. Displays numeric host and addresses instead of names. |

Some of these options allow the use of the I! (short for not) sign. The sign can be used to negate or reverse the condition. For example, specifying -! icmp in a rule will match packets whose protocol is not ICMP to the conditions of this rule.

The source and destination addresses can be specified in several ways. To specify a particular host, you may use its IP address or its hostname. To specify a network, you can either use the CIDR notation or its expanded dotted-quad format. Thus, 1.1.1.0/24 is equivalent to 1.1.1.0/255.255.255.0. Source and destination port numbers can be specified numerically or by service name (mapped from /etc/services). You may also specify a range of ports by using a colon (:) to separate the beginning and ending ports.

The -y option is used to allow TCP connections in one direction only. When building a firewall, you may want to allow your internal hosts to connect to the outside without leaving outside agents connect to the internal hosts. Because a connection needs going both ways, blocking packets coming from the outside is a naive approach.

The solution is to block those packets used to initiate a connection. These packets are called SYN packets because they have the SYN flag set in their headers and the FIN and ACK flags cleared. The flags are specific bits in the packet's header. If you block any packets with the SYN bit set, your hosts can talk to hosts on the outside without allowing the outside hosts to initiate the connections to your hosts.

The Internet Control Message Protocol (ICMP) is used for control messages, such as host not found or ping responses. It is usually most secure to disable ICMP messages. However, some types are needed by various utilities or other parts of the system. The -icmp-type option matches packets with a specific ICMP message type. For example, ICMP messages such as destination unreachable are used extensively by TCP and UDP. You may also want to allow your internal users to use other utilities such as ping or traceroute.
