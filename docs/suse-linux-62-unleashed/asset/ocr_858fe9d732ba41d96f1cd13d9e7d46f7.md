FIGURE 19.10
To perform local installation from a remote FTP site, you must configure YaST to the contact site with the correct permissions.

![](bbox=[0.305, 0.345, 0.735, 0.563])

In the dialog box shown in Figure 19.10, enter the name, such as ftp.mydomain.com, or IP address of the FTP server (where the SuSE software is available. If a SuSE Linux CD-ROM is mounted on a remote Linux and you are not going to use anonymous FTP, this will most likely be the /mnt/cdrom directory (however, the mount point could be anywhere on the remote system). If you are going to use anonymous FTP, the CD-ROM or SuSE software should be available in the server's pub directory.

If you are going to log in with a username and password, enter these now. When finished, press F10 to set the method. The yast command will attempt to connect and log in to the server. It will then search the remote directory for the required software and package information and then display the software management dialog box shown in Figure 19.1.
