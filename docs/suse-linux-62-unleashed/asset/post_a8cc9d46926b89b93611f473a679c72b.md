## Perl Command-Line Switches

Perl has a variety of command-line options (switches) that subtly change Perl's behavior. These switches can appear on the command line or can be placed on the # line at the beginning of the Perl program.

> Note
> Several command-line switches can be stacked together, so that -pie is the same as -p -i -e.

The following are all the available command-line switches.

- -@[digits]
Specifies the input record separator ($) as an octal number. $/ is usually a newline, so that you get one line per record. For example, if you read a file into an array, this will give you one line per array element. The value 00 is a special case and causes Perl to read in your file one paragraph per record.

- -a
Turns on Autosplit mode when used with -n or -p. That means each line of input is automatically split into the @ array.

- -c
Tells Perl to perform syntax checking on the specified Perl program without executing it. This is invaluable, and the error messages given are informative and readable and tell you where to go to begin looking for the problem, which is a rarity in error messages.

- -d
Runs the script under the Perl debugger. See perldebug for more information.

## Note

The syntax used to print the mail message is called a here document. The syntax is as follows:

```perl
print <<EndText;
....
EndText
```

> Note
> Note that the @ sign in the email addresses needs to be escaped within single quotation marks (''). Perl does not interpolate (evaluate variables) within single quotation marks, but does within double quotation marks and here documents.

## Sending Mail

There are several ways to get Perl to send email. One method that you see is opening a pipe to sendmail (shown in 25.8). Another method is using Mail::module, which uses socket directly. The latter method is faster because it does not have to launch an external process.

## LISTING 25.8 Sending Mail Using Sendmail

```perl
open (MAIL, | /usr/bin/sendmail -t);
print MAIL <<EndMail;
To: dpitts@mk.net
From: rbowne@mk.net
Subject: Email notification
David,
Sending email from Perl is easy!
EndMail
close MAIL
```

The EndText value must be identical at the beginning and at the end of the block, including any whitespace.

## LISTING 25.9 Sending Mail Using Mail::Sendmail Module

```perl
use Mail::Sendmail;
%mail = ('To' => 'dpitts@mk.net',
'From' => 'rbowne@mk.net',
'Subject' => 'Email notification',
'Message' => 'Sending email from Perl is easy!',
);
sendmail(%mail);
```

Perl ignores the comma after the last element in the hash. It is convenient to leave it there; if you want to add items to the hash, you do not need to add the comma. This is purely a style decision and is not required.
