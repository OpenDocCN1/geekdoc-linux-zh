# The fvw2 Window Manager

The fvw2 window manager (see Figure 5.4) is a configurable taskbar, 3D window frames, buttons, scrollbars, and the capability for extensive customization.

**5.4**
The fvw2 window manager provides many sophisticated window controls.

![](bbox=[0.298, 0.446, 0.908, 0.703])

This window manager's default startup file is found under /usr/X11R/lib/fvwm2 directory as system.fvwm2rc. Copy this file to your home directory as .fvwm2rc and make changes to customize your X sessions. If you do not use an X11 display manager to log in insert **fvwm2** in your **start command line:

```
# startx fvwm2
```
