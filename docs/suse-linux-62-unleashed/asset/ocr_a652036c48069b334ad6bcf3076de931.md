To launch a specific Appixware tool, such as Spreadsheets, use this:

```
install-dir/appix -ss
```

The program documentation provides the options for launching each program.

Besides using the command-line options, Appixware allows you to specify a filename that causes the proper Appix tool to be opened. You'd use the following to open a Words document:

```
install-dir/appix report34.aw
```

These features make creating desktop shortcuts to specific tools or documents a simple task under most window managers.
