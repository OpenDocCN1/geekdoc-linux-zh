Make can also aid in the portability of your program through the use of macros. This allows users of other operating systems to easily configure a program build by specifying local values, such as the names and locations, or pathnames of required software tools. In the following, macros define the name of the compiler (CC); the installer program (INS); where the program should be installed (INSDIR); where the linker should look for required libraries (LIBDIR); the names of required libraries (LIBS); a source code file (SRC); the intermediate object code file (OBS); and the name of the final program (PROG):

```
# a sample makefile for a skeleton program
CC= gcc
INS= install
INSDIR = /usr/local/bin
LIBDIR = -L/usr/X11/lib
LIBS = -L1m -LSM -LICE -Lxt -LX11
SRC= skel.c
OBJS= skel.o
PROG= skel
```

```
skel: ${OBJS}
$(CC) -o ${PROG} ${SRC} ${LIBDIR} ${LIBS}
```

```
install: ${PROG}
$(INS) -g root -o root ${PROG} ${INSDIR}
```

Using this approach, you can build the program with this:

```
# make
```

To build a specified component of your makefile, use a target definition on the command line. To just build the program, use make with the skel target like this:

```
# make skel
```

If you make any changes to any element of a target object, such as a source code file, make will rebuild the target. To build and install the program in one step (using the example), specify the install target like this:

```
# make install
```

Larger software projects may have any number of traditional targets in the makefile, such as:

+   * test—To run specific tests on the final software.
* man—To process an include troff document with the -man macros.
