Scanners and tablets are the other types of devices that assist in creating graphics. There are numerous scanners that work under Linux. The first preference is SCSI scanners, because SCSI can be used for other purposes (such as connecting disk drives and tapes). Other scanners can connect via the USB or parallel port, but Linux support is on a case-by-case basis. Consulting the scanner hardware is the best thing to do. SuSE has a nice hardware database of supported scanners at http://cddb.suse.de/cdb/english. You must supply the vendor or model number of a scanner to see if it is supported.
