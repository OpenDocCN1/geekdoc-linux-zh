The Screensaver dialog box, shown in Figure 5.15, has a number of settings, such as the type of screensaver, the time delay before activating the screensaver, a random setting to cycle through installed screensavers, and if you want to require a password to go back to work. After you make your changes, click the Apply button; click OK to close the dialog box.

> Note
Right-click different corners of the sample display in the Screensaver dialog box to set automatic screen-saving or screen-locking. A small pop-up menu appears, and you can select Ignore, Save Screen, or Lock Screen for each corner. For example, if you set the lower-left corner of the sample display to start screen saving, the next time you move your mouse pointer into the left corner of the display (and leave it there for a second), screen saving starts.
