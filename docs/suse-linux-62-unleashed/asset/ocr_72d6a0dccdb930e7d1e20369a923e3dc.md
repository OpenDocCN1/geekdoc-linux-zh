# # The init Process

Once your selected Linux kernel has loaded, it then loads a special process, init, which is the ancestor of all other processes in the system's uptime. This process always has ID 1. You can verify this by piping the output of the ps command through grep:

```
# ps aux | grep init
bball 391 0.0 1.2 2320 776 1 S Sep 5 0:00 init /home/bball/.xi
bball 8519 0.0 0.6 1280 384 p3 S 13:05 0:00 grep init
root 1 0.0 0.3 196 ? S Sep 5 0:03 [2]
```
