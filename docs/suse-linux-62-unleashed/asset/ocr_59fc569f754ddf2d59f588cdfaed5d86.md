The power of GIMP is that you can create your own scripts and plug-ins, and interface with Perl routines. The best way to starting and creating your own customization is to modify existing scripts; you can also search for plug-ins that have been placed in the public domain or have a favorable license—such as GPL. It is important that you ensure the proper work environment is set prior to creating scripts or plug-ins or before using the Perl interface.

One example is to make sure that the proper Perl libraries and Perl versions are installed.

+   1. Click Xtns and choose Perl Control Center (see Figure 26.11).
2. Click the View Perl Feature Status button and you will see the dialog box shown in Figure 26.12. The GIMP manuals and Help dialog boxes are a good reference source to make sure that the correct Perl binaries and libraries are installed.
