# Networking and Internet Services
PART II

Usage Policy (AUP). You can read a server's MOTD at any time with the /MOTD
command.

First, join a channel. You can do this with the JOIN command:

```
/JOIN #new2irc
```

When you join a channel, a message similar to this appears:

```
chat-newbie(newbie@linux.home.com) has joined channel #New2IRC
*** Topic for #New2IRC: Channel for newbies to IRC!
*** #New2IRC W 930912929
*** Users on #ircbar: acb jaman jackie chat-newbie
*** #New2IRC End of /NAMES list
*** #New2IRC 838552852
```

As you can see when you join a new channel, it executes the /NAME command so you can
see at a glance who is online. Depending on the time you connect, this channel can have a
lot of IRC newbies connected. Others can try #newuser and #chatback. If none of
these have many people online, then try #ircbar.

Now that you are connected to a channel, you can join in the current conversation by typing
whatever it is you'd like to say. If you type what I just typed, it will look like this:

> > What I just typed

Other people will see this:

> <your nickname> What I just typed

Here are other commands that you might find useful:

+   * /WHOIS chat_newbie gives information on the chat_newbie or whatever nickname nyou specify.
* /MSG cool-guy your message sends a one-line message to cool-guy. cool-guy doesn't need to be on the same channel you're on.
* Any number of /JOIN #channelname commands. Each time you issue a /JOIN command, the new channel adds to the channels you have already joined. Be careful! If you select busy channels, you might get bombarded with messages and might be unable to keep up with it all!
* Many clients have a /HELP command. This gives a list of commands that are valid. From there you can get further help if required.
* /LEAVE #channelname disconnects you from the specified channel.
