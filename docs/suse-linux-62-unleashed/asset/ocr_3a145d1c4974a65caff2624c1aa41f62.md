Before you can begin compiling programs for Linux, you must have installed the required
development software tools (such as the egcs compiler suite, the GNU as assembler, and
d linker) and software development libraries (such as glibc-devel*). You can install this
software by inserting SuSE Linux CD-ROM and (as root) start YaST from the
command line of your console or X11 terminal window.

The typical first C program is a cliché—the Hello, World program, which prints
t simple line Hello, World. Listing 25.1 contains the source code of the program.

# LISTING 25.1 Source Code of the Hello, World Program

```
main()
{
    printf('Hello, World\n');
}
```

This program can be compiled and executed as follows:

```
$ gcc hello.c
$ ./a.out
```

Hello, World
$

> Note
If the current directory is not in your path, you must execute a.out by typing the
following:
./a.out
