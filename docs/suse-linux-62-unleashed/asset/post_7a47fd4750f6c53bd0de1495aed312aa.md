When you join a channel, a message similar to this appears:

```
chat-newbie(newbie@linux.home.com) has joined channel #New2IRC
*** Topic for #New2IRC: Channel for newbies to IRC!
*** #New2IRC W 930912929
*** Users on #ircbar: acb jaman jackie chat-newbie
*** #New2IRC End of /NAMES list
*** #New2IRC 838552852
```

As you can see when you join a new channel, it executes the /NAME command so you can see at a glance who is online. Depending on the time you connect, this channel can have a lot of IRC newbies connected. Others can try #newuser and #chatback. If none of these have many people online, then try #ircbar.

Now that you are connected to a channel, you can join in the current conversation by typing whatever it is you'd like to say. If you type what I just typed, it will look like this:

> > What I just typed

Other people will see this:

> <your nickname> What I just typed

Here are other commands that you might find useful:

- /WHOIS chat_newbie gives information on the chat_newbie or whatever nickname you specify.
- /MSG cool-guy your message sends a one-line message to cool-guy. cool-guy doesn't need to be on the same channel you're on.
- Any number of /JOIN #channelname commands. Each time you issue a /JOIN command, the new channel adds to the channels you have already joined. Be careful! If you select busy channels, you might get bombarded with messages and might be unable to keep up with it all!
- Many clients have a /HELP command. This gives a list of commands that are valid. From there you can get further help if required.
- /LEAVE #channelname disconnects you from the specified channel.

See the following section for resources that help with your first IRC experience.

## IRC, ICQ, and Others
### IRC Resources

For more information on any aspect of IRC, there are plenty of resources on the Internet:

- http://www.irc.net is probably the definitive guide to IRC for any platform. It contains information on the history of IRC, some IRC user guides and tutorials, pointers to many different IRC clients, information on all the different IRC networks including server names, and much more.
- http://www.efnet.net is the home page for the original IRC network.
- http://www.irchel.org contains many different help files and FAQs.
- http://ftp.undernet.org/irc contains servers and clients for many platforms and various IRC-related things.

This should give you a jumpstart. However, if what you need is not listed here, query one of many Internet search engines.

## Chatting with ICQ

Over the past couple of years, a new type of chat network has taken the Internet by storm: ICQ is a way of communicating with friends and work colleagues, while surfing the Net at the same time. ICQ also has the capability to notify you when someone on your friends list comes online!
