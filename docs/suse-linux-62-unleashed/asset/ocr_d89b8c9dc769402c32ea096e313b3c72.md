# Installation Overview and
Post-Installation Issues

Installing SuSE Linux usually involves at least four distinct steps:

+   - Partitioning the hard drive
- Booting to the install and copying the software to the new Linux partition
- Configuring the boot loader
- Post-installation and hardware/software configuration (X11, sound, printer,
networking)

Partitioning can be accomplished with DOS tools included in this book's CD-ROM (the
FIPS command), or through the use of commercial software tools, such as PowerQuest's
PartitionMagic. Boot to the install may be accomplished locally using boot disks created
from software images included on this book's CD-ROM, or by booting directly off the
SuSE Linux CD-ROM. The boot may be started by specifying another hard drive or
mounted partition. You can also start an install over a network from a remote FTP site or
NFS-mounted volume. Configuring the boot loader using LILO is covered in Chapter 3,
but commercial software, such as PowerQuest or U Communication's System
Commander, may also be used to boost SuSE Linux. Post-installation issues for configuring
the Window System to work with your computer are covered in Chapter 4, “The X
Window System." SUSE Linux includes a graphic configuration program named that
You can use to configure X11, but you will also find the graphic XF86setup command and the
text-only xf86config command included with FreeX86. All three commands may be used
to X11 on your system. Printer configuration issues are covered in Chapter 24,
"Printing with SuSE Linux." For details about establishing a PPP connection with your
ISP to connect to the Internet via modem, see Chapter 17, "Internet Connections."
networking issues, such as setting up FTP service or using other protocols and services are
covered in various network and server chapters in this book.

Installing SuSE Linux from a DOS hard-drive partition is only one method of
taking advantage of existing partitions: You can also install SuSE Linux on and
boot from a FAT or VFAT partition. This is called a USMSDOS install. Look for the
file USMSDOS-HOWTO under the /usr/doc/howto/en directory after installation.
