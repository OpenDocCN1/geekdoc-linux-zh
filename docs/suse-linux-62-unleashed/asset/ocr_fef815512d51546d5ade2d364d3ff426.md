# Booting to the Install

After booting, the installation program greets you with Welcome to SuSE Linux! boot:
prom. Wait about 10 seconds, or press Enter to go to the next screen.
It asks what language you prefer to use during the installation process. The default is
Deutsch, but other options include English, Espanol, Français, Hellenic, Indonesia,
Italiano, Magyar, Nederlands, Polski, Portugues Brasileiro, Romania, Russian,
Czech, and Slovenia. Use the arrow keys to highlight your choice and press the Tab key
to move to the OK button. Press Enter to continue. You're then asked which kind of display
(color or monochrome) to use. Again, make a selection and press Enter after highlighting
the OK button.
The next dialog box asks which keyboard configuration you have (see Figure 2.1). Scroll to
select the correct one and press Enter.

You'll then see SuSE's main installation menu (see Figure 2.2).

Press Enter to start your installation. You'll then see an installation menu that lets you
an installation, boot to an installed system, use SuSE's rescue system (to recover data or fix
system errors), and to start SuSE Linux using a CD-ROM filesystem. Select Start
Installation and press Enter.
