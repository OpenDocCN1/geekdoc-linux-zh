# Appendices
Part V

This appendix is a handy cross-reference to the software included in this book's CD-ROM.
SuSE Unleashed includes SuSE, Inc.'s evaluation CD-ROM, a specially selected collection
of from SuSE's commercial six CD-ROM collection (so you can imagine how big
this appendix would be to document CD-ROMs!). Table A.1 can help you,
build, and install a custom configuration for your system or LAN. This is especially helpful
if you have constraints such as hard drive storage or to create custom network
multimedia configurations for your install. By using this appendix's table of packages,
can choose to build any system, from a minimal configuration to a full install. This
apendig might also helped experienced SuSE Linux installs save time and can be used as a
pre-flight checklist for selected software.

The appendix was created with the rpm command. Because SuSE Linux is distributed in
rpm arrays, the table was quickly built using rpm's package query commands, along
with the --queryformat option, and the NAME, SIZE, and DESCRIPTION fields. By filtering
t output of the command through the tr (or transliterate) command (to create single-line
table descriptions with a carriage return at the end of every line), the table is quickly built

```
# rpm -qa --queryformat '%(NAME)%%(SIZE)%%(SUMMARY)\n' sort >table.txt
```
