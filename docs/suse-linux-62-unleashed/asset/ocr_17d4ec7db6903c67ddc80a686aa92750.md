# FIGURE 19.6

When removing software with YaST, you will have a chance to choose where a backup of the software package will be located.

> NOTE: This is not a replacement for a 'file backup' which would take the entire installation. The modified files will be packed into a compressed .tar.gz archive and will be stored in the directory you specify.

 you would like this to be a backup, please specify about a directory where these backup files should be created. If you select a subdirectory on the path to root partition it will be created automatically. Press "Yes" to continue, otherwise no backup files will be created.

![](bbox=[0.315, 0.495, 0.735, 0.545])

After YaST finishes installing or removing software, you will end back at the main install dialog box (shown in Figure 19.7). From there you can choose to perform additional software management.
