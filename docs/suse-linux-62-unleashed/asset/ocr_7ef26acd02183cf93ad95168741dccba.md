# GNU C/C++ Compiler Command-Line Switches

Many options are available for the GNU C/C++ compiler, and many of them match the C
and C++ compilers available on other UNIX systems. Table 25.2 shows the important
switches. Look at the man page for gcc or the information file on the CD-ROM for the full
list and description.

Table 25.2 GNU C/C++ Compiler Switches
| Switch | Description |
| -x language | Specifies the language (C, C++, and assembler are valid values). |
| -c | Compiles and as only (does not link). |
| -S | Compiles (does not assemble or link); generates an assembler code (.s) file. |
| -E | Preprocesses only (does not compile, assemble or link). |
| -o file | Specifies the output filename (a.out is the default). |
| -l library | Specifies the libraries to use. |
| -I directory | Searches the specified directory for files. |
| -L directory | Searches specified directory for libraries. |
| -w | Inhibits warning messages. |
| -pedantic | Strict ANSI compliance required. |
| -Wall | Prints additional warning messages. |
| -g | Produces debugging information (for use with gdb). |
| -ggdb | Produces native-formative debugging info (and gdb extensions). |
| -p | Produces information required by prof. |
| -pg | Produces information for use by gprof. |
| -0 | Optimizes.|

# New Features of the GNU egcs Compiler System

The egcs (pronounced "eggs") program suite was originally an experimental version of
t gcc compiler whose development was first hosted by Cygnus Support (http://nwww.cygnus.com/).

According to Cygnus, egcs is an experimental step in the development of gcc. Since its
first release in late summer 1997, egcs has incorporated many of the latest developments
features from parallel development of gcc with many new developments of its own,
such as a built-in FORTRAN front end. At the time of this writing, egcs also includes
compiler support for the Java language.
