# Supernetting

As you saw in the subnetting section, adding one bit to the network mask splits the network in half. To double a network's size, you simply take away one bit from the network mask. To continue with the visualization tests, assume you were working with the 192.168.126.0/24 and 192.168.127.0/24 networks. Now say you wanted to be able to have all the IPs from both 24-bit networks communicate in their own expanded, or super network. This would define the range of 192.168.126.0-192.168.127.255, which looks like the following written out:

```
10000000 10101000 01111111 00000000 (192.168.126.0)
```

```
10000000 10101000 01111111 11111111 (192.168.127.255)
```

11111111 11111111 11111111 00000000 (255.255.254.0 or 23-bit)
The resulting netmask has 23 bits, so the new supernet is represented as 192.168.126.0/23. It has a network number of 192.168.126.0 and a broadcast of 192.168.127.255. There are now 510 assignable IPs in this logical IP network.

This prefix/bit-count notation does not work when joining any ranges of numbers. For example, look at the range of 192.168.10.0-192.168.13.255:

```
10000000 10101000 00001010 00000000 (192.168.10.0)
```

```
10000000 10101000 00001011 00000000 (192.168.11.0)
```

```
10000000 10101000 00001100 00000000 (192.168.12.0)
```

```
10000000 10101000 00001011 01111111 (192.168.13.255)
```

11111111 11111111 11111111 00000000
