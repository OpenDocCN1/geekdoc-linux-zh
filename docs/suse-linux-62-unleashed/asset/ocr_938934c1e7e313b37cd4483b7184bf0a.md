# SuSE System Administration
PART III

This chapter shows you how to configure and use your printer with SuSE Linux. Many different programs, files, and directories are essential to supporting printing under Linux, but you'll find that with little effort, you will be able to get to print nicely formatted documents and graphics.

If you can print to your printer from DOS, Windows 98, or Windows NT, don't worry! Chances you'll be able to print under Linux, and you'll probably be pleasantly surprised by the additional printing capabilities you won't find in the commercial operating system installed on your PC.

# Printer Devices

Under Linux, each piece of your computer's hardware is abstracted to a device file (hopefully with an accompanying device driver either compiled in the kernel or available as a loadable kernel module (see Chapter 23, “Kernel Management,” for more details). Printer devices, traditionally named after line printers, are character mode devices and will be found in the /dev directory. Some of these devices, along with the traditional port assignments, are shown in Table 24.1.

Table 24.1 Parallel Printer Devices
| Device Name | Printer | Address |
| /dev/lp0 | First parallel printer | øx278 |
| /dev/lp1 | Second parallel printer | øx378 |
| /dev/lp2 | Third parallel printer | øx3f8 |

Serial printers are assigned to serial devices such as /dev/ttySX, where X is usually a number from 0 to 3. Quite a few tty devices are listed in /dev. Generally, if you're going to use a serial printer, you have to use the setserial command to make the printer's serial port set to the correct IRQ or fastest baud your printer supports.

In some special cases, such as using an Apple LaserWriter as a serial printer (it has a Diablo print-wheel emulation mode using the Courier font), you must define your printer or edit an entry in your system's printer capabilities database, the /etc/printcap database. Sometimes you can manipulate the printer to get a higher speed. For example, here's a 10-year-old trick, posted to the comp.laser-printers newsgroup by Dale Carstens, for increasing the serial port speed of the Apple LaserWriter Plus to 19200:

%!

```
0000 % Server Password
statusid begin 25 scbatch 0 ne 19200 ne or
server begin exitserver (pop end stop) ifelse
statusid begin
```
