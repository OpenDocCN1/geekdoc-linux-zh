# 27.2 xanim Options

TABLE 27.2 Description
| Option | Description |
|---| Sr | Allows user to resize animations on-the-fly. Default is off. |
| Ss# | Scales size of animation by # before displaying. |
| Sh# | Scales width of animation by # before displaying. |
| SV# | Scales height of animation by # before displaying. |
| SX# | Scales animation to have width # before displaying. |
| Sy# | Scales animation to have height # before displaying. |
| Sc | Copies display scaling factors to buffer scaling factors. |
| SS# | Scales size of animation by # before buffering. |
| SH# | Scales width of animation by # before buffering. |
| SV# | Scales height of animation by # before buffering. |
| SX# | Scales animation to have height # before buffering. |
| SY# | Scales animation to have height # before buffering. |
| SC | Copies buffer scaling factors to display scaling factors. |
| W[opts] | Window submenu. |
| W# | X11 Window ID of window to draw into. |
| Wd | Doesn't refresh window at end of animation. |
| Wnx | Uses property x for communication. |
| Wr | Prepares animation, but doesn't start playing it. |
| Wr | Resizes X11 Window to fit animation. |
| Wx# | Positions animation at x coordinate #. |
| Wy# | Positions animation at y coordinate #. |
| Wc | Positions relative to center of animation. |

Normal Options
Uncompresses and buffers ahead of time. Default is off.

+   - Uses X11 shared memory extension if supported. Default is on.
- Disables looping for nonloop IFF animations. Default is off.
- Debugs 0 (off to 5) for level of detail. Debugs is 0.
- Enables dithering for certain video codes only. Read readme for monochrome displays. Default is on.
- Doesn't load animations into memory, but reads from file as needed. Default is off.
- # is the number of milliseconds between frames. If 0, default depends on the animation. Default is 0.
- Loops animation # times before moving on. Default is 1.
- Ping-pongs animation # times before moving on. Default is 0.
- No display. Useful for benchmarking.
- Turns on certain optimizations. Read readme. Default is on.
- Uses Pixmap instead of image in X11 (buffered only). Default is off.
