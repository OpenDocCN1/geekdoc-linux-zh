This is how it works: traceroute starts by sending a packet with a TTL of 1. The packet gets to gateway

traceroute sends three packets with each TTL and reports the round-trip time by each packet.

traceroute is usually used as ping—by giving it an address. Listing 7.1 shows an example of the output from traceroute:
