# Plug-and-Play Support

This contains options to enable kernel support of generic plug-and-play devices and to enable probing of devices attached to the parallel port peripherals to the parport modules. In general, probing parallel ports for IRQ numbers can cause problems. A better option is to explicitly specify your port options through the append line in /etc/lilo.conf (see "Parallel Ports (parport)").

# Block Devices

The Block Devices dialog contains options for disks, from ancient MFM and RLL IDE drives through modern IDE/ATAPI devices to Parallel-Port IDE and ATAPI and RAID systems.

# Floppy Disk Driver

Because of its use for other devices (such as tape backup units) and its capability to run multiple disk controllers, the floppy disk driver is also be configured through boot commands by using the following options:

+   floppy=daring for well-behaved (usually all-modern Pentium systems) controllers. This option allows for optimizations that can speed up floppy access, but may fail on incompatible systems.

+   floppy=one_fdc tells the driver that only one controller is available. This is the default setting for the FDC driver.

+   floppy=two_fdc or floppy=address,two_fdc tells the driver to use two controllers, with the second at the specified address. The default address is 0x370, or will be taken from CMOS memory if the cmos option is selected.

+   floppy=think alerts the driver to the inverted convention for the disk change line that's used in ThinkPad laptops.
