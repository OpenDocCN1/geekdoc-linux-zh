From the preceding description, you can see that the DNS is a large, distributed database containing hostnames and IP addresses, but it contains others as well. When a program such as sendmail delivers mail, it must translate the recipient's hostname into an IP address. This bit of DNS data is known as an A (Address) record, and it is the most fundamental data about a host. A second piece of host data is the MailXchanger (MX) record. An MX record for a host such as a.whizzer.com lists one or more hosts willing to receive mail for it.

What's the point? Why shouldn't a.whizzer.com simply receive its own mail and be done with the process? Isn't a postmaster's life complicated enough without having to worry about mail changers? Well, although it's true that the postmaster's life is often complicated, MX records serve several useful purposes:

+   - Hosts not on the Internet (for example, UUCP-only hosts) designate an Internet host to receive their mail and also to have Internet addresses. Use of MX records allows non-Internet hosts to appear on the Internet (but only to receive email).

+   - Hosts can be off the Internet for extended times for unpredictable reasons. Thanks to MX records, if your host is off the Internet, its mail can queue on other hosts until your host returns. The other hosts are onsite (that, in your domain), offsite, or both.

+   - MX records hide information and allow you more flexibility to reconfigure your local network. If all your correspondents know that your email address is joe@whizzer.com, it doesn't matter whether the host that receives mail for whizzer.com is named zippy.whizzer.com or pinhead.whizzer.com. It also doesn't matter if you decide to change the name to white-whale.whizzer.com; your correspondents will know the difference.

# Mail Delivery and MX Records

When an SMTP client delivers mail to a host, it must do more than translate the hostname into an IP address. First, the client asks for MX records. It sorts them by the priority in the record. For example, whizzer.com might have MX records listing the hosts mailhub.whizzer.com, walrus.whizzer.com, and mailer.gonzo.com to receive mail for it (the "host” whizzer.com might not exist except as an MX record, meaning that no IP address be available for it). Although any of these hosts will accept mail for whizzer.com, the MX priorities specify which host the SMTP client should try, first and properly behaved SMTP clients will do so.
