# Introduction to NNTPCache

As mentioned before, many companies and individuals run NNTPCache instead of getting a full newsfeed. This is because NNTPCache saves money. The NNTPCache described in this chapter is probably the most popular. At the time of writing, NNTPCache was not shipping with SuSE Linux, but it is easily downloadable from http://www.nntpcache.org it should be noted that NNTPCache is free for individuals and non-profit organizations, but it should be licensed for commercial environments. See the LICENSING file in the directory for more information.

# How NNTPCache Works

NNTPCache was designed to look a regular NNRP-based server that any newsreader can connect to—but with a difference. If you are configuring the default news server that NNTPCache gets its articles from; this is normally your ISP's news server. For example, if you are reading the comp..linux.advocacy newsgroup each article you choose to read is retrieved from your default news server and a copy is kept on your NNTPCache server—this process is called caching the articles.

Not only articles are cached, but the news server's active lists are as well. An active list is the current newsgroup listing for that particular news server. This is useful because the list doesn't have to be refreshed every time you open your newsreader.

Another NNTPCache feature is that it can connect to multiple news servers. There are a number of public news servers that are usually related to a particular topic. For example Microsoft provides a news server called msnews.microsoft.com and has specific newsgroups on Microsoft-related topics (Newsgroups are named microsoft.*) SuSE has a news server, but it is not publicly accessible. To make full use of this neat feature, configure NNTPCache to talk to specific servers and link newsgroups with these servers. When you are at the reader, it makes browsing through all the different news servers transparent, and it caches all for you.

Obviously, make full use of NNTPCache's caching abilities, you will need a reasonably permanent internet connection and many people using your NNTPCache. Even if you use casual dial-up connections, it is still of use. You might, however, want to configure NNTPCache to a smaller amount of disk space for its cache, or turn off altogether.
