# SuSE System Administration
PART III

| TABLE 18.1 mount Options |
| Option | Description |
| --- | --- |
| exec | Indicates the kernel that it should allow the execution of programs on the filesystem. This option is more frequently seen as noexec, which indicates to the kernel that execution of programs on this filesystem shouldn't be allowed. This is generally used as a security precaution or for NFS filesystems mounted from another machine that contain executable files of a format unsuitable for this machine (for example, intended for a different CPU). |
| noauto | Opposite of auto. |
| nodev | Opposite of dev. |
| noexec | Opposite of exec. |
| nosuid | Opposite of suid. |
| nouser | Opposite of user. |
| remount | Allows the mount command to change the flags for an already-mounted filesystem without interrupting its use. You can unmount a filesystem that is currently in use, and with this is basically a workaround. The system startup scripts, for example, using the command mount -n o remount,ro / to change the root filesystem from read-only (if this starts off) the -n option indicates to mount that it shouldn't update /etc/fstab because it can't do while the root filesystem is still read-only |
| ro | Mount the filesystem read-only. This is the opposite of the option rw |
| rw |s the filesystem read/write. This is the opposite of the option ro |
| suid | Allows the set user ID and set group ID file bits to take effect. The opposite of this option is nosuid. The nosuid option is more usual; it is used for some sorts of readers that is needed |
| sync | All write operations cause the calling program to wait until the data has been committed to the hardware. This method of operation is slower but a little more than its option, asynchronous I/O, which is indicated by the option async. |
| user | Allows ordinary users to mount the filesystem. When there is a user option in /etc/fstab, ordinary users indicate which filesystem they want to mount or unmount by giving the device name or mount point; all the other relevant information is taken from the /etc/fstab file. For security reasons, user implies the noexec, nosuid, and nodev options. |

> Note
