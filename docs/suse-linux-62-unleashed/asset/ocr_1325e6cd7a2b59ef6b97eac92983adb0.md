# # yast --mask install

The program will start as shown in Figure 19.1. A help screen on the subject of software management with the program is displayed when press F1. To see a list of installed software packages, press Enter. You will then see the dialog box shown in Figure 19.2.

Figure 19.2
The yast command will display information about the amount of software and remaining drive space on mounted partitions.

![](bbox=[0.308, 0.219, 0.725, 0.458])

Your CD-ROM will activate, and you will see a list of series, or groups of software displayed. You can scroll through this list, which shows the series name, title, and amount of software (in megabytes) currently installed on your system. You'll also see the amount of used and free space on mounted filesystems at the bottom of the dialog.

To see or change the status of individual software packages, scroll through the list of package series and press Enter. You will see the dialog box shown in Figure 19.3.

Figure 19.3
The series information dialog shows the status information about a package and offers installation, upgrade, removal, and further query
