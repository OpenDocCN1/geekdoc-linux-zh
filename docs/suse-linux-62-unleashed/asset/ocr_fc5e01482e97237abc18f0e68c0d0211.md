INSTALLATION OF APSFILTER
This is a convenient way to configure apples, a universal printer filter.
If you choose install, the changes are written to
your printer configuration file (/etc/printcap). The names (ip, id, etc.) of
the created printers are then displayed.

![](bbox=[0.215, 0.395, 0.63, 0.535])

Under SuSE Linux, most print documents are converted to PostScript before printing.
However, if you do not have a PostScript printer, these documents must be converted to a
printer language understood by your printer. First, select a printer type. You'll
have the choice of PostScript, HP Deskjet, or Other (as shown in Figure 24.3). After you
press Enter, you select a printer name (the actual name of a software filter),
as shown in Figure 24.4.
