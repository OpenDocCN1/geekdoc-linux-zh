## Examining the xf86Config File

Before you try to start an X11 session using your new XF86Config settings, open the file in your favorite text editor, making sure to disable line wrapping, and check the settings. Doing this can be an important step, especially for laptop users, to check the created settings, enable or disable some X server options, enter the correct amount of video memory, and fine-tune monitor settings. You can open the file (as the root operator) with the pico text editor:

```
# su -c "pico -w /etc/XF86Config"
```

The next sections describe several of the more important parts of the XF86Config file you've generated. For an overview of the XF86Config file, see the XF86Config man page.

## XF86Config ServerFlags Section

The ServerFlags, shown in Listing 4.2, can be used to configure special options allowed by your XFree86 X server. Enable a particular action by adding one or more of the server flag options in the XF86Config man page, such as DontZap, which disallows Ctrl+Alt+Backspace to kill the X server, or DontZoom, which disallows Ctrl+Alt+Keypad+ (plus) or Ctrl+Alt+Keypad- (minus) to prevent video-mode switching.

The AllowMouseOpenFail option will let your X11 session start, even if a pointing device is not detected.

### LISTING 4.2 XF86Config's ServerFlags Section

```
Section "ServerFlags"
AllowMouseOpenFail
EndSection
```

> A handy option to use in your X86Config Keyboard section is XkbOptions ctrl:swapaps, which will effectively switch the function of the Caps Lock and left Ctrl keys. This can be especially handy for a laptop user with a crowded keyboard.

## X86Config Pointer Section

The Pointer section in Listing 4.4 tells the X server what pointer or mouse to use and how the buttons are handled. Note that Listing 4.4 shows a configuration for a PS/2 mouse. Other Protocol settings are Auto for a serial mouse and BusMouse for a bus mouse. The device entry, /dev/mouse, is a symbolic link to the actual device (such as /dev/psaux for a PS/2 mouse or /dev/tty0 for a serial mouse). Two-button users will need to enable a three-button element, which a simultaneous depressing of both buttons simulates the mouse (or Button 2). One common use of Button 2 is to paste text or graphics. For more information about configuring a mouse, see the README.mouse file under //X11R6/lib/X11/doc.

- **LISTING 4.4** `X86Config's Pointer Section`

| Section 'Pointer' | |

## XF86Config Monitor Section

The first parts of the sax-generated XF86Config file are easy to understand, but many users whose initial XF86Config file does not work until you pay attention to the Monitor section (a sample for 800 × 600 is shown in Listing 4.5), the Device section (Listing 4.6). The Monitor section contains specific details and settings for your monitor, such as your monitor's name, its horizontal and vertical ranges, and critical modelines (one for each resolution example: 640 × 480, 800 × 600, 1024 × 768). Understanding modeline is key to fine-tuning your X11 display.

> If you choose to use another tool, such as XF86Setup, or the xf86config command to create your XF86Config file, the content and listing will be different from those in this section. However, your XF86Config file will work as well. For the best details, see the VideoModes.doc files under /X11R6/lib/X11/doc before fine-tuning modelines in XF86Config file. Another good tutorial is XFree86-Video-Timings-HOWTO under /doc/.

The basic parts of modeline are 10 different values (from left to right):

- A label of the screen resolution, such as 800 × 600
- A driving clock frequency in MHz
- The number of visible dots per line
- The Start Horizontal Retrace (number of pulses before video sync starts)
- The End Horizontal Retrace (end of sync pulse)
- The total number of visible and invisible dots on display
- The Vertical Display End (number of visible lines of dots)
- The Start Vertical Retrace (number of lines before the sync pulse)
- The End Vertical retrace (number of lines at the end of the sync pulse)
- The Vertical Total value (number of visible and invisible line on display

## XF86Config Graphics Device Section

The Graphics Device section in Listing 4.6 contains details about your video chipset, such as RAM or clock speeds. Note that you can remove the pound sign in front of the VideoRam setting in this part of the XF86Config file and enter your graphic's RAM amount, or change this value later if you add more RAM to your card or motherboard.

This section of XF86Config file is critical—the device definition used to tell the X server what type of video chipset and options to support. (Your XF86Config may look different from this, especially if you specifically set a graphics card type.) For a list of Identifiers and options, please see the readme file under /usr/X11R/lib/X11/ directory corresponding to your chipset. In graphics will be automatically detected and proper settings enabled by the X server.

### LISTING 4.6 XF86Config Device Section

```
Section "Device"
Identifier "Primary-Card"
VendorName "---AUTO DETECTED--"
BoardName "---AUTO DETECTED---"
```
