# Using YaST to Configure IP Addresses

The second step required is to actually configure your Ethernet card so that it uses the proper IP address, netmask and gateway. To do this, select System Administration from YaST's main menu, and then select Network Configuration. Select the first option, Network Base Configuration. You will be presented with a screen where you activate or deactivate network devices, and configure their IP addresses, which is shown in Figure 7.6. To activate or deactivate a device, move over the desired device using the arrow keys, and press F4. This will toggle whether the device is active.

To configure and/or modify IP addresses, highlight the appropriate device and press F6. You will be presented with a screen that will allow you to set this interface's IP address, netmask, default gateway, and IP address of a Point-to-point fairly, if necessary. After selecting Continue at the bottom of the screen, and pressing F10, you will need to type `/etc/rc.d/init.network` to start these interfaces up. The next time you start system, they will be configured automatically.

# Using YaST to Change Your Hostname

It can be a tricky process to change a system's hostname because several files need to be modified for this to happen. The easiest way to do it is to use YaST. From the main menu, select System Administration, then Network Configuration, and then Change Host Name. You will be presented with a screen where you can type in the system's new hostname and domain name. After accepting your changes, the hostname will be immediately changed to the new values.
