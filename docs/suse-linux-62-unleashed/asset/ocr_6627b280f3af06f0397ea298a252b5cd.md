# Arcade Games for X11

For more action, try some of the video arcade games available for X11. There are hundreds included on the CD-ROMs accompanying this book, and many provide plenty of action and stereo sound. The following is a list of just a few of the more popular titles:

+   - abuse—Futuristic combat game.
- acm—Aerial combat simulator.
- battalion—A MESA library-enhanced 3D game.
- doom—Cult classic destroy-them-all game.
- koules—Smash-balls-into-the-wall game.
- Maelstrom—X11 port of an asteroid-like game for the Apple Macintosh.
- paradise—A networked combat game.
- quake—Successor to Doom (see “Quake II for Linux” below).
- rocksniamonds—Collect objects while navigating a maze.
- scavenger—Lode-runner for X11.
- xboing—Classic break-out game.
- xchomp—Classic Pac-Man-like game.
- xjwel, xtrojka, xbl—Falling blocks games.
- xlander—A lunar lander game.
- xpilot—Networked combat game.

> Note Look for the lincity-1.11.tar.gz file at http://metalab.unc.edu/pub/Linux/games/strategy/. You can quickly and easily build and install this simulation for SuSE Linux.
