LILO (The Linux Loader) allows you to boot Linux from a hard disk. To configure LILO, fill in the fields. Then, create and/or edit your boot configuration operation will be handled automatically after the boot delay. You must create at least one boot configuration (F4). After that, you can commit your configuration by pressing (Enter) and LILO will be installed.

In the Configuration Name field, type the word linux whenever you want to boot Linux. Next, press Enter. Next, select Boot Linux as the operating system to boot for this configuration. You'll then select the root partition to boot (in our example, there's only one Linux partition, or /dev/hda3 is selected). The SuSE installer will then verify if a bootable kernel is found. When finished, highlight the Continue button and press Enter. If you want to boot another operating system, press F4, but this time, create a DOS boot configuration, as shown in Figure 2.28.
