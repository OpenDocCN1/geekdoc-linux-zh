# Using startx and Multiple Sessions

If you don't use a display manager, you'll most likely use the startx command, a handy shell script that will pass command-line options to your X server for your X sessions. The startx command is typically used to pass starting color-depth information to the X server, as well as to find client commands or options to run for the session (usually your .xinit file in your home directory). However, the startx command included with Su Linux has been modified to offer additional options (see “Starting Specific Window Managers” later in this chapter).

# Using Different Color Depths

Unless you've used the DefaultColordepth option in your system XF86Config file to set a specific color depth, using startx by itself will start an X session using 8-color bitplanes or 256 colors. However, you can pass color-depth options to your server using the argument separator and -bpp option:

```
# startx -bpp 16
```

This command line will start an X session (if supported by your computer's graphics card and monitor) using thousands of colors. Color values typically passed with the -bpp option also include 24 and 32 for millions of colors.
