# XF86Config Graphics Device Section

The Graphics Device section in Listing 4.6 contains details about your video chipset, such as RAM or clock speeds. Note that you can remove the pound sign in front of the VideoRam setting in this part of the XF86Config file and enter your graphic's RAM amount, or change this value later if you add more RAM to your card or motherboard.

This section of XF86Config file is critical—the device definition used to tell the X server what type of video chipset and options to support. (Your XF86Config may look different from this one, especially if you specifically set a graphics card type.) For a list of Identifiers and options, please see the readme file under /usr/X11R/lib/X11/ directory corresponding to your chipset. In graphics will be automatically detected and proper settings enabled by the X server.
