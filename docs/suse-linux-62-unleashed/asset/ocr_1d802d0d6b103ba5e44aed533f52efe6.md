The hosts that you add put into the /var/yp/ypersvers file. As an alternative to running the yp command, you can manually edit the /var/yp/ypvers file and then run make using the preceding sequence.

# Starting the Daemons on Boot

To start the NIS server automatically at boot time, you need to create a symbolic link from the runlevel 3 startup directory. By default these are already created, but the following is how you would create them if needed:

```
[client@root#]# cd /sbin/init.d/rc3.d
[client@rc3.d]# ln -s ../ypersvers $15ypasswdd
```

The ypasswd daemon allows users from NIS clients to change their passwords on the NIS server. By default these are already created, but the following is how you would create them if needed:

```
[client@root#]# cd /sbin/init.d/rc3.d
[client@rc3.d]# ln -s ../ypasswdd $15ypasswdd
```

If you want to start the daemons by hand so you don't need to reboot, simply run the following:

```
[client@root#]# /sbin/init.d/ypserv start
[client@root#]# /sbin/init.d/ypasswd start
```
