# Configuring Linux Kernel

Is your lio.conf file prepared to find the new kernel? Do you have a backup kernel and a boot disk? Do you have enough disk space? These may seem trivial questions, but they are important. An error in any of these items may leave your system in an inoperable state and entirely devour your weekend. Even if all are going to set a few /proc values or add a network interface on the boot prompt, it is good defensive driving to consider the recovery plan.

If you need to add or remove modules, set parameters such as your sound IRQs, or if you are upgrading to a new kernel version, the next step is to run one of the kernel configuration programs. The Linux Makefile provides four methods of setting your configuration options:

+   - make config A command-line terminal program
- make menuconfig An ncurses-based console program
- make xconfig A tk/tcl-based X11 GUI program
- make oldconfig A semiautomatic update program
