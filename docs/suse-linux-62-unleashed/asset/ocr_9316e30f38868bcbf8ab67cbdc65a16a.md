# Other Clients

Other clients for graphics include XPaint and KPaint. XPaint is a straightforward tool that provides basic functionality as shapes, coloring, and shading. Also, it can generate an image quickly and efficiently. XPaint runs on many platforms, including Sun Solaris and HP HP-UX. The 234KB zipped tar XPaint package is available at http://metalab.unc.edu/pub/linux/apps/graphics/draw/ KPaint is a painting tool that is part of the standard SuSE Linux 6.2 KDE environment setup.

> Tip XPaint is sensitive to the native color depth of the X-Windows screen. This means that if your X-Windows is set to 8-bit color and you load a 24-bit image using XPaint, color information will be lost. To solve this problem, make sure that the color depth of the X-Windows screen is at least to or better than the color depth of the image. For more information, see the section on X-Windows setup.
