# # vncserver

You will require a password to access your desktops.

Password:

Enter a password used to allow remote access, and press Enter. The script then loads and starts the Xvnc11 server (a customized X116.3 server based on XFree86 3.3.2). If you wish to work on the remote desktop of a networked Win32 computer, the vnc software for Win32 must be downloaded and copied onto the remote computer. The Win32 software must then be extracted with an archive utility, such as WinZip.

Decompress the Win32 vnc software and install the software using the VNC Setup. To start the server, click the Install Default Registry Settings menu item from the vnc folder on your desktop's Start menu. Next, click the WinVNC menu item, as shown in Figure 29.10.
