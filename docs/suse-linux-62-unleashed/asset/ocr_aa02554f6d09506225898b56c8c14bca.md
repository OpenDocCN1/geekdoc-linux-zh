# # Summary

Automation offers enormous opportunities for using your Linux computer to achieve the goals you set. The examples in this chapter demonstrate that every Linux user can immediately begin to exploit the techniques and attitude of automation. Some of the major automation mechanisms provided by Linux include background processes, scheduling, and sophisticated software tools. As you gain experience by overcoming required administrative tasks, you’ll build your own approaches to system administration automation.
