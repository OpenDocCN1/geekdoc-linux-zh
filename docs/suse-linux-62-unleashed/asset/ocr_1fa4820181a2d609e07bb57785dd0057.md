clock settings. Note that your earlier choice will aid to avoiding probing the clocks (because a
clock is not used).

# Handy Command-Line Diagnostics

Probing your video card for clock settings is one way to fine-tune your
XF86Config file. Another handy way to diagnose your XF86Config settings before
you start your X session is to use a tip detailed by Eric S. Raymond in his
XFree86-HOWTO (found under the /usr/doc/howto/en directory). This method
saves the output of the chosen server, as XF86_SVGA, while it reads your
XF86Config file. You can save the output to a file like myX11.txt with a
command line like: if you jump into your X session, will kill the
session by holding down the Alt+Ctrl keys and pressing the Backspace key. you
can then read the X server's output with the more-or-less command less
myX11.txt to ensure that everything is okay. This command is handy because the
output normally scrolls too fast to be read.
