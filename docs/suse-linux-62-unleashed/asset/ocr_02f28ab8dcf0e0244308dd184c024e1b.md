SuSE Linux comes with a number of different window managers:

+   - AfterStep—An X11 window manager with a sophisticated look and feel featuring styled menus, icons, and a window dock for client icons, called a Wharf
- fvwm—A basic X11 window manager featuring virtual desktops, window controls, and a small memory footprint
- fwm2—An improved and highly configurable version of Fvwm
- icewm—An X11 window manager designed to look like OS/2, Windows 95, Motif, or 39 other desktop themes
- KDE—A complete X11 desktop environment with more than 100 clients and a consistent interface
- mwm—A Motif-like window manager included with the LessTif X11 software distribution
- olwm—A minimalistic window manager, part of Sun Microsystems' aging OPEN
- twm—A bare-bones window manager included with XFree86
- WindowMaker—The GNU X11 window manager, an improved version of AfterStep
