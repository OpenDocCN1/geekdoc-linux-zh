# Emulating the Apple Macintosh with Executor

Executor by ARDI, is a commercial software emulator you can use to run Macintosh applications under Linux (although a Windows version is also available). According to ARDI, Executor on a 90MHz Pentium can run most applications “almost as fast as a 50MHz 68040.” The Executor software is distributed in a series of .rpm archives, and a demo version is available through http://www.ardi.com.
