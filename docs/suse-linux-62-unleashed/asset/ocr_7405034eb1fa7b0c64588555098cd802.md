# The Default Mode for a File or Directory

The default mode for a file or directory is set with umask, which uses the numeric system to define its value. To set umask, you must first define the value you want the files to have. For example, a common file permission set is 644, with which the owner has read and write permission and the rest of the world has read permission. After the value is determined, you subtract it from 777. Keeping the same example of 644, the value would be 133. This value is themask value. Typically, this value is placed in a system file that is read when a user first logs on. After the value is set, all files created will set their permissions automatically using this value.

# Passwords—A Second Look

The system stores the user's encrypted password in the /etc/shadow file. A value of * blocks login access to the account, as * not a valid character for an encrypted field. This field should never be edited by hand (after it is set up). Instead, a program, such as passwd, should be used so that proper encryption takes place. If this field is changed, the password is no longer valid and will have to be changed by root. SuSE Linux uses a shadow password, value placed in the /etc/passwd field (between the first and second colon) is x.

A password is a secret set of characters set up by the user and known only by the user. The system asks for the password, compares the input to the known password, and, if there is a match, confirms the user's identity and lets user access the system. It cannot be said enough: Do not write down your password. A person who has a user's name and password is, from the system's perspective, that user—and has all of that user's rights and privileges.
