# # xanim -h

Usage:

xanim [+V#] [ [+-opts ...] animfile [ [+-opts] animfile ... ]

A + turns an option on, and a - turns off.

| TABLE 27.2 xanim Options |
| Option | Description |
| A[aopts] | Audio submenu. |
| Addev | AI audio only. dev is audio device. |
| Ae | Enables audio. |
| Ak | Enables video frame skipping to keep in sync with audio. |
| Ap# | Plays audio from output port # (sparc). |
| AV# | Sets audio volume to #; range 0 to 100. |
| C[c] | Color submenu. |
| C1 | Creates cmap from first TrueColor frame. Map the rest to this first cmap (could be slow). |
| Ca | Remaps all images to single new cmap. Default is off. |
| Cd | Uses floyd-steinberg dithering (buffered only). Default is off. |
| CF4 | Better color map for TrueColor animations. Default is off. |
| Cg | Converts TrueColor animations to grayscale. Default is off. |
| Cn | Be Nice: Allocates colors from default cmap. |

G[gopts] Gamma submenu.

Ga# Sets animation gamma. Default 1.000000.

Gd# Sets display gamma. Default 1.00000.

S[sopts] Scaling and Sizing submenu.

Si Half the height of IFF animations if interlaced. Default is off.

Sn Prevents X11 window from resizing to match animation's size. Default is off.
