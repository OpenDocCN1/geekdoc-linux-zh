There are many other excellent newsreaders available; search http://www.freshmeat.net to find other newsreaders if you don't care for trn.

# Summary

In this chapter, you see how learned how to install and configure the Internet News service, INN, and how to set up a caching NNRP server using NNTPCache. The steps involved might seem a little overwhelming, but if you take them slowly and check everything carefully, you'll be surprised how little time it takes to have a functional newsfeed on your Linux machine. Remember that you do need a connection available to a newsfeed before you complete and test the INN configuration. Setting up TCP/IP and UUCP connections are explained elsewhere in this book.
