
# Setting Up PPP

Most ISPs today use PPP instead of SLIP. PPP is good for you because PPP is a faster and more efficient protocol. PPP and SLIP are both designed for two-way networking; in other words, your machine talking to one other machine—usually ISP—and no other machines at the time (although it is possible to communicate with computers on your internal network). PPP is not a replacement for a LAN protocol such as TCP/IP, but PPP can coexist with TCP/IP (which provides a transport protocol for data).

One of the major hurdles Linux users face is setting up PPP and connecting to the Internet. If you're new to Linux, you don't have to understand the intricacies of the protocol to use PPP, and setting PPP on your system is not as scary as you might suspect (although you want to examine the gritty details, look at the ppp.c file under the /usr/src/linux/drivers/net directory). You can set up PPP manually from the command line or by using the command. Both approaches produce the same results. However, using the command line offers the advantage that you get understand what is going on.
