password. Two special usernames—anonymous and ftp—have been set aside for the

Users accessing the FTP server are placed in their home directories when they first log in.
At that point, they can change to any directories on the system to which they have
permission. Anonymous users, on the other hand, have several restrictions.

Anonymous users are placed in the home directory for the FTP users. By default, a user,
FTP, and a directory, /home/ftp, should be created using YaST. After the users get,
the FTP server executes a chmod system, effectively changing the program's root
directory to the FTP users' directory. Access is denied to any other directories in the
system, including /bin, /etc, and /lib. This root directory protects the
server from seeing /etc/passwd, /etc/group, and other necessary binaries (such as /bin/
is). To make up for this change, the server package creates bin, /etc, and lib directories
under /home/ftp. It is where necessary libraries and programs (such as ls) are placed.
It's also where the server software can access them even after the chmod system call has
been made.

For security reasons, files placed under the /home/ftp directory have their permissions
such that only the server can see them. (This is done automatically during another
install.) Any other directories created under /home/ftp should be set up so they are world-
readable. Most anonymous FTP places place such files under the pub subdirectory.
