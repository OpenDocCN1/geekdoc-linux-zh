## Appendix
PART V

The information in Table B.1 is a handy cross-reference to a collection of documents called HOWTO. These documents are installed under the /usr/doc/howto/en directory. They contain pointers, and reference information on more 200 different subjects. You can access these documents through an index provided by the SuSE help command, which launches Netscape. Or, you can read individual documents with the gzip command (the documents are compressed to save space on your hard drive); however, only 17MB is required because they are compressed with the gzip command. This command will display UUCP-HOWTO on your console or in X11 terminal window. Without compression, these HOWTO documents take up more than 25MB of drive space. Table B.2 contains an index of the mini-HOWTOs, which are smaller than regular HOWTOs and contain information about more specific subjects.
