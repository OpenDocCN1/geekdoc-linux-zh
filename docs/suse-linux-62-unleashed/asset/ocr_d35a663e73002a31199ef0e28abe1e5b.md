CHAPTER 29

Change the pathname following the Path entry to the path of your Windows root partition (mount point). Because Wine is used to run programs and applications for DOS, Windows 3.1, and Win32, you must have a copy of Windows installed on your system. For example, if you mount your Windows partition like this: 

```
# mount t vfat /dev/hda1 /mnt/dos
```

you would need to change the path entry to your mount point like this:

```
Path=/mnt/dos
```

If you have your Windows partition mounted, you can then try to play a game of solitaire by typing this:

```
# wine /mnt/dos/windows/sol.exe
```
