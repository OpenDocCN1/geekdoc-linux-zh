Although these steps vary, always follow the instructions enclosed with the source code. It is a good idea to generally start by reviewing a file called readme.

These are the general steps you will follow:

+   1. Obtain copies of the source files.
2. Unpack them (using the tar and/or gzip commands).
3. Review the enclosed documentation for instructions.
4. "Make" and install the source files following the instructions contained in the README or INSTALL files included with the source code package.

# Using Emacs

One way or another, you now have Emacs installed. Free it for up:

$ emacs file-name

file-name can be a new file that you are creating or an existing file that you want to modify.
