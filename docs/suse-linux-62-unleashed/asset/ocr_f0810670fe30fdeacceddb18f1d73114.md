# Features of the icew Window Manager

The icew window manager (in Figure 5.5) is designed to look like OS/2 or Windows 95 (and other window managers). It features numerous mouse and keyboard commands, and its configuration files and directories are located under the /usr/X11R/lib/X11/icew manager. To start an X session window manager, type start icew at the command line, and press Enter.

```
# start icew
```
