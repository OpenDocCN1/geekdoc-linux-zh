Remember that you do not have to set up a slave NIS server. Setting up a slave server is only useful if you have a large number of NIS clients and the need to distribute the load they generate.

If you have not already set your domain name, the following initialization will error out with a message that says The local host's domain name hasn't been set. Please set it. To initialize the master server, use the following commands. First, start the remote server, if they haven't already started:

```
root@vesta /root# /sbin/init.lib/yp/rpc start
root@vesta /root# /sbin/init.d/ypserv start
```

Then you can successfully start the ypinit program:

```
root@vesta /root# /usr/lib/yp/ypinit - m
```
