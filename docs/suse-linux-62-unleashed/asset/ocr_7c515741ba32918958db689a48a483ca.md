than 13 command-line options you can use to control your printer. For example, to save
money on print cartridges by using less ink, you can use hpset to tell your printer to print


The hpset command also has an Interactive mode, so you can test your printer, set different

printing.

# PostScript Printers

If you want a printer spooler specifically designed for PostScript printers, gave Dave
Chappell's PPR a try. PPR works with printers attached to parallel, serial, and AppleTalk
(LocalTalk) ports, along with other network interfaces. PPR also works like other
non-PostScript printer filters and converts a number of graphics file formats for printing.

You can find PPR at http://ppr-dist.tricoll.edu/pub/ppr/.

# Printer Accounting

Use printer accounting if you want to know how much printing you or your users have
doing being and at what cost. Linux comes with several different commands to set up
accounting reports and track printer usage. See the main pages for the pac command, which
you can use to track usage and costs when printing. You'll also need to read the main pages
of the printcap database to see how to enable printer accounting.

# Infrared Printer Support

For those fortunate enough to have a printer with infrared support (such as the Canon
BJC 80 or BJC 50) and a Linux system with an infrared port (such as a laptop), here is good
news: You can print without a printer cable! Recent effects Linux device driver
development has yielded infrared printing (and networking) support, and the latest Linux
kernels know how IrDA support built in. IrDA support is supplied as a series of loadable
kernel modules and support features such as system logging, networking, serial-port
emulation, and printing.

You'll need to read Werner Heuser's IR-HOWTO, found under the /usr/doc/howto/en
directory. You also need to download the latest set of IrDA utilities
