TABLE 3.1 /etc/lilo.conf Configuration Parameters
| Parameter | Description |
| --- | --- |
| prompt | Requires you to type a boot prompt. |
| timeout=<secs> | Sets a timeout (in tenths of a second) for keyboard input, which is handy if you want to boot right away or wait longer the default five seconds. To make LILO wait indefinitely for your keystrokes, use a value of -1. |
| Allows input from the designated serial line and the PC's keyboard to LILO. A break on the serial line mimics a Shift-key press from the console. For security, password-protect all of your boot images when using this option. The parameter string has the syntax `<port>, <psp> <bits>`, as in /dev/ttyS0,8N1. The components <psp>, <parity>, and <bits> can be omitted. If one of these components is omitted, all of the following components will be omitted as well. Additionally, the comma must be omitted if only the port number is specified. See LILO's documentation for details. |
| Ignore | Ignore correct password-protect your boot images. |
| password=<password> | Use this option if you do not have lilo.conf set to read-only permission (-rw-------), LILO issues a warning--the password is not encrypted! |
| unsafe | This keyword is placed after a definition for a partition. The keyword tells LILO not to attempt to read the MBR or that disk's partition table entry. You can declare all of the partitions in your system as a log of all existing partitions and then place the unsafe keyword to prevent LILO from reading it. 

After making your changes to lilo.conf, make sure to run /sbin/lilo after installing a new kernel. The changes will not take effect.

# Installing or Reconfiguring LILO with the YaST Command

Using the SuSE YaST command is an easy way to install or reconfigure LILO. You must be the root operator in order to use YaST. Although you can navigate through YaST's menu to reach the LILO configuration section, a much easier way to jump right to LILO management is to use YaST's --mask option, followed by the keyword lilo, like this:

```
# yast --mask lilo
```
