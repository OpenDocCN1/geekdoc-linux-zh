If you have an ISA PnP card, you would use a similar methodology, except that you would need to make sure that you have the card configured using isapnp command. There would also be extra parameters (IRQ, DMA, I/O address, and so on) that need to be passed to the kernel when using the modprobe command.

If you would like to make the modules load automatically, one approach is to edit the /etc/conf.modules file. SuSE has a custom /etc/conf.modules file that includes the OSS drivers and the other modules. The first step is to edit the file using your favorite editor and comment out the entries by placing a # as the first character of the line. You also need to uncomment or remove the # from the sound card that you want to load automatically.

The next step is test sound using the standard KDE sounds. Open the KDE Control Center; on the lefthand side of the box is a Sound button. Two options appear when you click the button: Bell and System Sounds. Enabling the System Sounds check box enables the KDE system sounds (see Figure 27.1).
