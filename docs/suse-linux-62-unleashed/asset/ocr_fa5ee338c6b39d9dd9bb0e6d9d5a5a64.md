# Linux Multimedia CHAPTER 27

# TABLE 27.2 anim Options

| Option | Description |
| --- | --- |
| q | Quiet mode. |
| r | Allows color cycling for IFF single images. |
| +root | Tiles video onto root window. Default is on. |
| R | Allows color cycling for IFF animations. See default. |
| T# | Title option. See readme. |
| v | Verbose mode. Default is off. |
| V# | Uses visual. # is obtained by +X option. |
| X | X11 verse mode. Displays visual information. |
| Ze | Has anim exit after playing cmd line. |
| Zp# | Pauses at specified frame number. |
| Zpe | Pauses at end of animation. |

# Window Commands

| Option | Description |
| --- | --- |
| q | Quit. |
| Q | Quit. |
| g | Stops color cycling. |
| r | Restores original colors. Useful after g. |
| <space> | Toggles. Starts/stops animation. |
| ' | Single-steps back one frame. |
| " | Single-steps forward one frame. |
| < | Goes back to start of previous animation. |
| > | Goes forward to start of next animation. |
| m | Single-steps back one frame staying within animation. |
| / | Single-steps forward one frame staying within animation. |
| = | Increases animation playback speed. |
| 0 | Decreases animation playback speed. |
| 1 | Resets animation playback speed to original values. |
| 2 | Decreases audio volume 5 percent. |
| 3 | Decreases audio volume 1 percent. |
| 4 | Increases audio volume 1 percent. |
| 5 | Increases audio volume 5 percent. |
| 8 | Sends audio to headphones. |
| 9 | Sends audio to speakers. |
| $ | Mutes audio. |"

# Mouse Buttons

| Option | Description |
| --- | --- |
| <Left> | Single-steps back one frame. |
| <Middle> | Toggles. Starts/stops animation. |
| <Right> | Single-steps forward one frame. |
