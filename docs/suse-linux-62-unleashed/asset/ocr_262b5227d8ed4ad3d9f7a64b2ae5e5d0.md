As the root operator, you can customize this for system-wide features and programs for all users. If you want to make your own custom twm features, copy this file as .twrc and save it in your home directory.

twm (shown in Figure 5.25) comes with the Free86 X Window distribution and is included with Linux distributions. You will find this window manager installed if you XFree86, and it provides the basics of window management for X:

+   - Custom keyboard commands
- Custom mouse commands
- Icon dock
- Icons
- Resizable windows
- Window titles
