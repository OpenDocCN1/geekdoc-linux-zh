# import

import reads an image from any visible window on an X server and outputs it as an image file. You can capture a single window, the entire screen, or any rectangular portion of the screen. You can use the display (display(1)) utility for resizing, printing, editing, formatting, image processing, and so on of the captured image.

The target window can be specified by id or name may be selected by clicking the mouse in the desired window. If you press a button and drag, a rectangle will form that expands and contracts as the mouse moves. To save the portion of the screen defined by the rectangle, just release the button. The keyboard bell is rung once at the beginning of the screen capture and twice when it completes.

# animate

animate displays a sequence of images on any workstation running an X server. animate first determines the hardware capabilities of the workstation. If the number of unique colors in an image is less than or equal to the workstation can support, the image is displayed in an X window. Otherwise the number of colors in the first is reduced to match the color resolution of the workstation before it is displayed.

This means a continuous-tone, 24 bits/pixel image can display on an 8-bit, pseudo-color device or monochrome device. In most instances the reduced-color image closely resembles the original. Alternatively, a monochrome or pseudo-color image sequence can display on a continuous-tone, 24 bits/pixels device.

# montage

montage creates a composite image by combining several separate images. The images are tiled on the composite image with the name of the image optionally appearing just below the individual tile.
