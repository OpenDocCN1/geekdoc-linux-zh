# Teaser and the Firecat

An exciting new system on the horizon is known as the Teaser and the Firecat. At the time of writing it was still in the very early stages, but it makes big promises. What is the promise of this new protocol? There are multiple Teasers (the server) around the Internet and users use a client, called the Firecat. This is rather than having an ICQ number, which is mostly meaningless! A user has an account at a particular Teaser; the email address would be something like username@teaser.whatever.com. If you would like more information on this, check out http://www.bowerbird.com.au/teaser.
