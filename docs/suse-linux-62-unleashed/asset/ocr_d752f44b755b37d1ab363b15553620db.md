Just as insmod installs a module, rmmod removes one (if possible). The modprobe command loads a group of modules, or just the first one to work (as the first ethernet module to work), and depmod determines which other modules on which a given group of modules might depend.

Under SuSE Linux, settings for kernel modules are generally stored in the conf.modules file under the /etc directory. You will find several default settings for such hardware as your printer:

```
alias parport_lowlevel parport_pc
options parport_pc io=0x38 irq=none,none
```

The Alias keyword provides a pointer to a particular module and configuration listed in the conf.modules. In this case, the kernel is instructed to load the parallel-port driver using a starting address of 0 x378 to load for any installed hardware. Kernel modules are installed under the /lib/modules/2.2.x directory, where X is the version of the kernel used by the system. For SuSE 6.2, this is the /lib/modules/2.2.10 directory. This directory contains additional directories containing modules for the system's CD-ROM, various filesystems, networking hardware, PC card devices, SCSI devices, video hardware, and miscellaneous devices, as pointers, infrared ports, sound cards, or tape drives.
