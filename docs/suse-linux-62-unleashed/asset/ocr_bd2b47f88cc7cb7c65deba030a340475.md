# TABLE 29.2 Executor Command-Line Switches

| Option | Action |
| --- | --- |
| applzone n[k] | Uses n kilobytes of memory for an application |
| applzone n[MB] | Uses n megabytes of memory for an application |
| bpp n | Uses n bits per pixel (1 or 8) |
| desperate | Minimalist mode (only for DOS) |
| geometry heightwidth | Standard X settings |
| grayscale | Uses grayscale when running |
| help | Prints help message on options and quotes |
| info | Prints system information |
| keyboard keyboard | Uses specified keyboard |
| keyboards | Prints available keyboard maps |
| memory n | Creates n megabytes of use for system memory |
| nobrowser | Disables file browser when starting |
| nodiscache | Disables internal disk cache |
| notfiles | Doesn't list filenames beginning with a period |
| nosound | Disabled sound |
| privatemap | Uses a private colormap for X |
| refresh n | Refreshes every n 60th of a second |
| size heightwidth | Uses initial window of height and width pixels |
| stack n[k] | Uses n kilobytes of stack memory for the system |
