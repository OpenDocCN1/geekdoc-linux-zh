*.mycompany.com read,post next file to configure is config. This file is read by NNTPCache when it starts. You should probably only change the organization field to get yourself up and running:

# Organization MyCompany Pty Ltd

This fills in the organization field when the newsreader does not specify one. You can also force this to be the organization by changing the next parameter from no to yes:

ReplaceOrganization yes you may find that there are other parameters you need to tweak later, but this will do for now.

The final file that you need to edit is servers. This is where you specify all the newsfeeds you want to use with your NNTPCache The servers file came with the NNTPCache distribution has many examples that you might want to refer to, I suggest renaming the existing servers file to servers.old and creating a new one with the following entries in:

```
# /* timeouts
# host:port Interface Active Act.tim Newsgrp
- Group Xover Arts
news.mysisp.net:119 DEFAULT 10m 12h 12h
- 10m 60d
msnews.microsoft.com:119 DEFAULT 24h 4d 4d
- 60m 60d
```

Make sure this new servers file is owned by the users and the news group. The first three entries specify which servers to use. Replace news.mysisp.net with the name of the news server that your ISP provides. Notice that I have included the Microsoft news server. You will see that there are a few timeout entries in the servers file after each news server. I will describe what each one is used. The Active parameter directs how long the active file will be kept before retrieved again. Act.tim is in the active files. Newsgroup is referring to the newsfiles, which has all the newsgroup descriptions contained in it. The next one, Group, is the amount of time for which the NNTP group command is cached.
