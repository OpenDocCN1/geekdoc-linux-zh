KPaint is another straightforward tool that is part of the standard SuSE Linux 6.2 KDE installation. Figure 26.15 shows the initial dialog box and Figure 26.16 shows a simple design capability.

SuSE Linux 6.2 KDE installation also includes a number of tools that can be used for displaying scientific/mathematical functions such as fractals, Fourier transforms, and raytracing tools. The two fractal tools include Fractals Generator, (Kfract——see Figure 26.17), and Mandel Ultimativ (see Figure 26.18). The Transformada de Fourier tool can assist math, physics, and engineering students in the areas of Fourier transforms and Fast Fourier Transforms (FFT). Figure 26.19 shows a sample of a raytracing tool called Gray.
