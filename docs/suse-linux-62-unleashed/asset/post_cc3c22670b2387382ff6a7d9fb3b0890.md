## Schwartzian Transform

Named for Randall, the Schwartzian transform is a way of sorting an array by something that is not obvious. The sort function sorts arrays alphabetically; that's pretty obvious. If you want to sort an array of strings by the third word ![](img/cbac72550c7126a2216e94d91a00.png), perhaps you want something more useful, such as sorting a list of files by size? The Schwartzian transform creates a new list that contains the information you want to sort, by referencing the first list. You then sort the new list and use it to figure out the order that the first list should be in. Here is a simple example that sorts a list of strings by:

```perl
@sorted_by_length =
map { length($_) } # Extract original list
sort { $a <=> $b } # Sort by transformed value
map { $_ } # Map to element lengths
@list;
```

Because each operator acts on the item immediately to the right of it, it helps to read this from right to left (or bottom to top, the way it is written here). The first thing that acts on the list is the map operator. It transforms the list into a hash, in which the keys are the list elements and the values are lengths of each element. This is where you put in your code that does the transformation you want to sort. The next operator is the sort function, which sorts the list by the values. Finally, hash is transformed back into an array by extracting its keys. The array is now in the desired order.

## Command-Line Processing

Perl is great at parsing the output of various programs. This is a task for which lot of people use tools such as awk and sed. Perl gives you a larger vocabulary for performing these tasks. This following example is very simple, but illustrates how you might use Perl to chop up some output and do something with it. In the example, Perl is used to list only those files that are larger than 10KB.

```bash
ls -la | perl -nae 'print $F[0]\n' if $F[4] > 10000;
```

The -n switch indicates that you want the Perl code to run for each line of the output. The -a switch automatically splits the output into @F. The -e switch indicates that the Perl code follows on.

## awk Programming

awk, or GNU awk, is one of the newer versions of the awk language created for UNIX by Alfred V. Aho, Peter J. Weiner, and Brian W. Kernighan in 1977. The awk name comes from the initials of the creators' last names. Kernighan was also involved with the creation of the C programming language and UNIX; Aho and Weiner were involved with the development of UNIX. Because of their backgrounds, you will see many similarities between awk and C.

Several versions of awk exist: the original awk, naw, POSIX awk, and—of course—gawk was created in 1985 and is the version described in The awk Programming Language. POSIX awk is defined in the IEEE Standard for Information Technology, Portable Operating System Interface, Part 2: Shell and Utilities Volume 2, ANSI-approved, April 5, 1993. (IEEE is the Institute of Electrical and Electronics Engineers, Inc.) GNU awk is based on POSIX awk.

SuSE Linux users will find that the awk command, under both the /bin and /usr/bin directories, is a symbolic link to the /usr/bin/gawk program. In addition to a short manual page for gawk included under the /man directory, the awk command follows in all versions. The awk program can be entered a number of ways—on the command line or in a file. awk can accept input from a file, piped in from another program, or even directly from the keyboard. Output normally goes to the standard output, but that can be redirected to a file or piped into another program. Output can also be sent directly to a file instead of standard output.

The awk program can be as simple as one line or as complex as several thousand lines. (I once developed an awk program that summarizes data at several levels with multiple breaks; it just short of 1,000 lines.)

## Using awk from the Command Line

The simplest way to use awk is to code the program on the command line, accept input from the standard input device, and send output to the standard output device (screen). Listing 25.12 shows this in its simplest form; it prints the number of fields, or words, in the input record or individual line, along with the record itself, for the text from file.txt.

```bash
$ cat file.txt | awk '{print NF ": " $0}'
6: Now is the time for all
7: Good Americans to come to the Aid
3: of Their Country.
16: Ask not what you can do for awk, but rather awk can do for you.
$ 
```

> Note The entire awk script is contained within single quotation marks (\')language.

NF is a predefined variable set to the number of fields on each record. $0 is that record. The individual fields can be referenced as $1, $2, and so on.

You can store your awk script in a file and specify filename on the command line by using the -f flag. If you do that, you don't have to contain the program within single quotation marks.

> Note gawk and other versions of awk that meet the POSIX standard support the specification of multiple programs through the use of multiple -f options. This enables you to execute multiple awk programs on the same input. I tend to avoid this just because it gets a bit confusing.

## Applications of awk

You'll find many possible uses for awk, including extracting data from a file, counting occurrences within a file, and creating reports.

The basic syntax of awk matches the C programming language; if you already know C, you know most of it. In many ways, awk is an easier version of C because of its built-in features.
