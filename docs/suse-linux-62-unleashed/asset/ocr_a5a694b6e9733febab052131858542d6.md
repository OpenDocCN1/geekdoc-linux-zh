# Using WordPerfect

Now that WordPerfect is configured, start using it desktop icon that calls the xwp WordPerfect executable. xwp is found in the install-directory/wordperfect/wpbin directory. You could also call this program from the command line, as long as you are in an X Window environment.

The keybindings and cursor movement keys are fairly standard: Ctrl+C copies highlighted text, Ctrl+V pastes text, arrow keys move the cursor, and so on. The toolbar and layout are similar to Microsoft Word, which would make for an easy transition to WordPerfect for most users.
