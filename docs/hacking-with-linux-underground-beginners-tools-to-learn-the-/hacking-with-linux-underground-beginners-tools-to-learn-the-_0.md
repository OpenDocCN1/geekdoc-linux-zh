## Cloud flare websploit

我们甚至有第二组 websploit 命令可以用于处理云技术。Cloud flare 是网站最重要的安全层之一，目前正维护并保护多达 200 万个网站免受危险攻击。

首先，要使用 cloud flare 模块，你需要在 websploit 模块列表列表中找到它，如下所示：
```
example@ linuxwar : websploit select cloudfare www.exampleweb.com
```
现在获取界面后，你可以在任何示例网站上安装 cloud flare，以检查它是否有效。Cloud fare 的工作原理是将系统的原始网络地址更改为其服务器之一。因此，如果发生任何注入攻击或暴力破解，它将立即停止或封锁该地址。Cloud fare 像是一个极低成本的网站入侵检测系统。

### 为什么 cloud flare 仍然容易被绕过？

正如我们之前提到的，它只是用 IP 地址对攻击者进行欺骗。许多黑客开始收集数百个 Cloudflare 地址，并在每次攻击时放弃它们。某些技巧仍然可以使用，例如使用此 cloud flare 扫描器来查找该网站托管的所有 IP 地址。

以下是使用 `uniscan` 确定操作系统的命令：

Uniscan 还提供了类似于 `NMap` 的开放端口检测工具。它会专门检查服务器的操作系统版本并扫描服务。Uniscan 还提供了通过导出选项报告扫描结果的方法，如下例所示：

## Sublist3r

网站由许多子域名组成。通常，范围内的域名可以很容易使用 `burp suite` 等应用程序进行操纵。例如，`Gmail` 有许多子域名，如果我们能找到其中一个的访问权限，就可以轻松地操纵整个网站。这就是为什么子域名枚举是黑客应该学习的最重要概念之一。我们有很多工具可以帮助我们寻找子域名。在本节中，我们将使用 `sublist3r` 来完成此任务。`sublist3r` 未在 Kali Linux 的工具列表中。由于这个原因，我们需要从 git 仓库安装它。下面我们解释了如何安装 `sublist3r`。你可以使用这种方法安装 Kali Linux 仓库中不可用的任何第三方应用程序。

### 安装 sublist3r

1) 使用 `cd` 命令选择你希望安装工具的目录。
```bash
example@ linuxwar : cd install sublist3r
```

2) `GitHub` 是一个在线仓库，让程序员在克隆应用程序时变得简单。它与包管理器不同，因为人们可以使用 `git` 控制台主动对应用程序做出贡献。这里是用于安装 `sublist3r` 的命令：
```bash
git clone (URL)
```

3) 现在，每个 git 文件夹都有一个 `requirements` 文件，它将帮助系统安装运行软件所需的其他工具。这些工具被称为依赖项。黑客应该对此有良好的理解，因为会遇到很多错误。我们将通过一个完美的例子让你理解依赖项。想象你正尝试安装一个像 `Android studio` 这样的 java 应用程序。如果系统中没有安装 `java`，你就无法安装和使用 `Android studio`。这就是依赖项的含义。

在下一节中，我们将解释 `sublist3r` 的工作原理。请跟随学习详细内容。

### 启动 sublist3r 工具

运行以下命令启动子域名搜索工具。
```bash
example@ linuxwar : run sublist3r
```

我们将获得从该工具中可选的许多选项。输入 `-h` 时，我们还会有一个帮助部分，解释可以使用的命令。以下是该工具可以执行的详细功能：

a) 域名 `-d`：你可以输入此参数插入你想查找子域名的域名。
b) 暴力破解：此参数可用于使用文本文件中输入的大量域名列表启动暴力破解攻击。当你有很多域名需要测试时，这特别有用。
c) 端口：端口是可用于方便子域名引用的功能。此参数可以帮助用户通过开放端口发现漏洞的子域名。

除了这些基本参数外，你还可以使用输出功能从 shell 界面获取结果到文本文件中。我们现在提供一些示例命令，让你详细了解子域名枚举：

1) `python sublist3r.py -d [amazon.com]`：此命令将启动执行，并显示使用 `d` 参数后存在的所有子域名。
2) 你可以使用此命令对文本文件中存在的前 100 个域名进行暴力破解：
```bash
python sublist3r text.txt
```

通过这些简单的技术，你可以找到子域名。找到子域名列表后，你可以使用侦察（recon）等技术进一步挖掘关于它们的大量信息。在尝试破解 Web 应用程序时，黑客应该优先使用这种方法，以轻松找到进入应用程序的方法。到此，我们完成了对可用 Web 应用程序工具的简要解释，在下一节中，我们将开始详细解释网络工具。让我们开始！

# 第 6 章：网络攻击工具

黑客攻击中最重要且处理最复杂的是处理网络。通俗地说，网络就是一个互连的网系统。互联网是改变生活的最大网络。公司和许多行业都通过互连的网络运行。每当黑客成功进入一个网络时，他都会尝试破解其他的子网络。在本章中，我们将学习许多网络概念和命令，这些将使黑客能够轻松破解网络。让我们开始吧！

### 什么是网络？

网络是一组结合在一起工作的系统，或者从总体上说，用于从每个系统之间交换信息。为了评估这个定义，我们使用了许多用于交换信息的设备设备。其中一些设备是路由器、调制解调器、天线、电线，甚至是一组为了 GPS 的工作而持续跟踪地理变化的卫星群。

Kali Linux 包含许多网络工具，可以用于连接到嵌入式系统或作为服务器维护工具。我们甚至在安装操作系统期间使用过网卡配置和无线集成。在下一节中，我们将讨论 `ifconfig`，这是最重要的网络工具之一，可用于学习我们正在处理的网络细节。我们只需要发送数据包信号，我们将进行详细学习。

### ifconfig

`ifconfig` 通常是黑客用来获取网络信息的默认命令。它将显示许多信息，如以太网地址、物理 MAC 地址、IP 地址，甚至是网络掩码。还有一个部分描述了发送和接收的数据包数量。另一行描述了网络数据包的冲突。虽然其中某些对黑客来说可能没用，但它们可以用来确定他们试图利用的系统的网络强度。下面是一个显示 `ifconfig` 的命令和输出：

```bash
ifconfig
```

以下是 `ifconfig` 命令可以做的几件事：

a) `ifconfig` 可指定带有子网掩码的 IP 地址。此命令可用使用网络路由器进行无线数据包注入时。这里是命令：
```bash
example@ linuxwar : ifconfig netmask 223.2.1.2
```
b) `ifconfig` 本身也可以用于确定系统所在的广播地址。可以通过子网掩码的偏差进一步操纵。这里是命令：
```bash
example@ linuxwar : ifconfig broadcast 212.11.1.1
```
c) `ifconfig` 可用于结束网络设备。就像杀死进程一样，黑客有时需要结束他们连接的网络驱动程序或设备以消除嗅探或留下任何痕迹。这里是关闭以太网驱动程序的命令：
```bash
example@ linuxwar : ifconfig eth0 212.1.1.1
```

通过这种方式，我们可以使用 `ifconfig` 开启或关闭网络驱动程序。然而，`ifconfig` 通常只帮助我们理解已可用的信息，不会帮助我们操纵任何网络信息。由于此，我们必须使用高级嗅探或点击劫持软件来操纵配置文件和资源。
