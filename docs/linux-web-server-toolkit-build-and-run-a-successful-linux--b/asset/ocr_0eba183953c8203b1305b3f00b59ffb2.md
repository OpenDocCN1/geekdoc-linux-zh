Table 4-5 shows the nine access rights that you can grant to a file or directory. Note that the meaning of the permissions is slightly different in some cases for files and for directories.

# TABLE 4-5 File Access Permissions

| Permission | When Granted to Owner | When Granted to Group | When Granted to Other |
| --- | --- | --- | --- |
| Read | That user can read the file's contents. | Any user in that group can read the file's contents. | Any user on the system can read the file's contents (files that are to be read by people browsing your Web site should have this right set). |
| Write | That user can alter/write to the file. | Any user in that group can alter/write to the file. | Any user on the system can alter/write to the file (though most Web browsers still can't alter files, even if they have rights, carefully avoiding Write for Other set on files for your Web site). |
| Execute | That user can execute the file (used for binary files or scripts). | Any user in that group can execute the file. | Any user on the system can execute the file. |

The same set of access permissions for files can also be assigned to directories, but the meaning of each permission can be slightly different for directories.
