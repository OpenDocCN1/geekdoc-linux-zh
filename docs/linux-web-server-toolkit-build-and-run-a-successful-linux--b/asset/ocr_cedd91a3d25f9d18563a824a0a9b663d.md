# The Future of Linux Web Servers

The future of Web software for Linux looks very good. The growing acceptance of Linux as a viable production operating system and the growing number of Linux Web sites encourage everyone to keep Linux in their development plans. Hobbyists continuing leading-edge development of Web servers for Linux; commercial companies see more and more potential for sales of Linux Web servers, and more companies use commercial Linux products to create their Web servers.

Apart the Web servers that we've focused on, Internet servers for many purposes continue to be run on Linux. This promotes the development of new features that extend the Internet and the Web. When these features show up on Linux systems and then are ported to other systems, it can only bode well for Linux.

# Summary

This chapter introduced you to Linux by describing the Linux distributions that can be purchased from organizations that base their offerings on the freely Linux kernel and related utilities. Key factors in choosing the right Linux distribution for your needs were outlined, with discussion of the distribution included on the CD-ROM in this book. Web server software for Linux was also discussed, the main distinctions between freely available Web servers such as Apache and commercial secure Web servers as Netscape FastTrack Server.
In this chapter you've learned the following:

+   - Because Linux distributions differ in the way they work, applications work on one Linux system may not work perfectly on another Linux system. If an application doesn't run, check the options file, recompile the libraries, and it will usually run.
- Creators of commercial Linux applications must either support an undetermined number of Linux versions with unknown differences or develop for a single, specific version of Linux.
- The differences between Linux distributions are most noticeable in the following areas: installation, filesystem standard, initialization scripts, included software packages, and philosophy.
