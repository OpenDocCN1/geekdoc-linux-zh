# Chapter 10: Basic Scripting and Forms

![](bbox=[0.056, 0.103, 0.663, 0.437])

Figure 10-3: A browser in Windows uses interface elements that are standard in all Windows programs. Any forms that are displayed have the same look and feel as other Windows programs.

Between the beginning and ending <FORM> tags are the individual elements of the form, along with any text, tables, images, or other HTML tags that you want to include to make the form more attractive and readable. A list of available elements is shown in Table 10-2.

# Table 10-2 Tags That You Can Use to Make Forms

| Interface Element | HTML Tag |
| --- | --- |
| Text box (single-line) | <INPUT TYPE= TEXT ..> |
| Password entry box (single-line) | <INPUT TYPE= PASSWORD ..> |
| Check box | <INPUT TYPE= CHECKBOX ..> |
| Radio button | <INPUT TYPE= RADIO ..> |
| Hidden field (nothing displayed) | <INPUT TYPE= HIDDEN ..> |
| Text box (multiline) | <TEXTAREA..> ... </TEXTAREA> |
| Menu (drop-down) | <SELECT ..> ... <OPTION> .. </SELECT> |
| Submit button | <INPUT TYPE= SUBMIT ..> |
| Reset button | <INPUT TYPE= RESET ..> |
