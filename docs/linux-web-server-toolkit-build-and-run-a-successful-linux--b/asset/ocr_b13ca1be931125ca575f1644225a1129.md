# FILE TYPING AND ICONS

Each of the icons in the window is assigned automatically by the Desktop according to a set of built-in rules. The rules say things like "if a file has the following string in the first 50 characters, it is a WordPerfect document. Display it with this icon and give it this default and secondary actions" – pretty complex rules.

You can click the right mouse button on an icon to see the default and secondary actions, or choose Edit File Actions to add or change the actions that are listed.
The rules for assigning types to files on the Desktop are contained in two configuration files:

```
/usr/visix/lg/default/lg_ftc/data.ftc
/usr/visix/lg/default/lg_ftc/prog.ftc
```
