# Processing Queries with Scripts

Once you've gone to the effort of creating a form, you need to have a tool on your Web server to use the data sent by the browser. These tools are normally scripts that you create to record the user's comments, to query the database, to log the order, or for whatever else you think of.

I'm going to use the Perl language for all the scripts in this section. You can use any language you prefer, including C, C++, shell scripts, various BASIC versions, or any other Linux-programming language that you prefer. The only requirement is that it conform to the cgi-bin standard so that it can communicate with the Web server to get data and provide a response back to the browser.

I choose Perl for several reasons, but not because it's easy to use. Perl is a good choice because it is:

+   * A popular language for Web server scripts
* Very fast on Linux systems
* A cross-platform tool (Perl scripts run without modification on any system that has Perl)
* A language optimized in many ways for dealing with text strings, which is the bulk of what Web server scripts do
