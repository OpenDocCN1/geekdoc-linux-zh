# # FastTrack Server Basics

In Chapter 7 you learned how to use the -ps command to make sure the FastTrack server is installed and running. As you begin to configure and administer the FastTrack Server, it's important to remember that there are really two programs running.

+   - The FastTrack Web server, which services requests from browsers and is probably started automatically when you start your OpenLinux system.
- The Administration server, which you configured in Chapter 7, and which is started only when you begin to use it. This program changes the FastTrack Web server configuration for you according to instructions you provide.

Before you read any further, make sure that your FastTrack Server is running, and that you followed the instructions in Chapter 7 to prepare the Administration server for use (by running the config script in /opt/fasttrack).
