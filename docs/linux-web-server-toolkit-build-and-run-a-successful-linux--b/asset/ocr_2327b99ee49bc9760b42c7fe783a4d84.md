# Chapter 20: Backups and Disaster Recovery

Restoring files from after a system failure is where a commercial solution can be even more useful. By helping you label backup media in an organized fashion, keeping separate records of what each archive contains, and adding tracking information into the archive files, a commercial backup product can take the guesswork out of restoring one file or a complete system from your archives.

# REMOTE BACKUPS

Both the tar and most commercial backup utilities allow you to back up your Linux system either to a local backup device such as a tape drive connected to your server, or to devices attached to a remote system. Backups to devices on a remote system can have several advantages and are as easy to use as local backups because the remote access capabilities of Linux are so powerful. Remote backups eliminate the need for an additional tape drive or other archive device. Remote backups also provide additional security by storing data at a location separate from your server.

For example, you can remotely access a tape drive or writable CD-ROM drive at another location to save your Web archives. If fire damaged your Web server, the archives at the remote site would remain safe. To learn more about remote access, review the manual page for the mount command or the manual for your commercial backup software.
