# Planning Your Web Server

The first four chapters of this book provide vital background information on the Web, Web servers, and Linux. You'll learn the history and benefits of Linux, as well as how to create a plan for your site and define a presence on the Web and how to choose a Linux distribution as well as Web server software, based on your requirements. The last chapter in Part I discusses the Internet, the Web, and UNIX and how they are related, and includes an introduction to the graphical interfaces of Linux and OpenLinux.
