Figure 5-10: The mouse configuration screen for XFree86. From this screen, you set the protocol, port, and options for using your mouse in the graphical system.

Once you get the mouse working well, click on the Keyboard button on the top of the screen if you need to change your keyboard settings. You can set a lot of options, if you're using a U.S. English keyboard, you shouldn't need to use this screen.

Now choose the Card page from the buttons at the top of the screen. You can configure your video card in one of the following two ways:

+   - You can select your card brand and model from a list.
- You can enter the exact details about your card (chipset, memory, RAMDAC, special features, and so forth). This screen is shown in Figure 5-11.

Obviously, I would recommend the first option. You can change the screen between these options by pressing the Detailed Setup button. I won't explain here all the options on the Detailed Setup screen; many of them only apply to a few cards. I will explain about the sections in the configuration file that this utility creates. These explanations might be helpful if you're having problems getting X working correctly.

Now click the Monitor button and choose a setting that fits your monitor. Remember the warnings about not choosing a high-frequency monitor if you don't have one. You won't get better graphics, you'll just run your monitor.

Most monitors are multisync, that they can display at a variety of scan rates). Hence, the red bars appear in this window across the scan ranges if you select a multisync model, as shown in Figure 5-12.
