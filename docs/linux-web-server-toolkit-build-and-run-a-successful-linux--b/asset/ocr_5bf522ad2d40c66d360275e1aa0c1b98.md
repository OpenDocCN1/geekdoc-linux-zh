# Adding Links

Links are what make a plain old Web document into hypertext. In the same way you use a URL to load a Web document in your browser, you can embed a URL within a document so that a user can jump to another document with one click. The document you link to can be anywhere on the Web.

The <A> tag is used to create a link ("A" stands for anchor). The text you enclose between the <A> starting tag and the </A> ending tag is normally displayed as blue text or underlined in the browser. This indicates to the user where to click to jump to another document. Most browsers also change the mouse cursor when you place it over a link and display the place where the link jumps to in a status line at the bottom of the browser window.

Just like graphics using the IMG tag, links use a parameter to specify a piece of data: in this case, a URL to jump to if the link is selected by the user. A couple of simple links are shown here:

```
<A HREF=/doc/manual_index.html>Index</A>
<A HREF=http://www.tory.org/doc/toc.html>Table of Contents</A>
```
