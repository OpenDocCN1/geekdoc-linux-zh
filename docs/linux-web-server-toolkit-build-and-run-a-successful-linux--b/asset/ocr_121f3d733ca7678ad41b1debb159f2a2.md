CHECK BOXES
Check boxes allow you to provide a way for readers to respond to a Yes or No question. An <INPUT> tag with the CHECKBOX type displays only a small box that the user can check. You must place text near the check box so that the user knows what Yes/No question is being answered by checking the box.

Every check <INPUT> tag must have a unique NAME parameter because every check box can be selected independently. This is different from the radio buttons that are described next. The only additional option that can be used with a check box <INPUT> tag is the CHECKED option, which makes the check box start out already selected. A sample entry using an <INPUT> tag for a check box is shown in the following with the corresponding browser display shown in Figure 10-5; note that there is no <P> tag between the <INPUT> tag and the text describing the check box's purpose:

```
<P>
<INPUT TYPE=CHECKBOX NAME=SENDINFO CHECKED>
Send a brochure about this city.
<P>
```

![](bbox=[0.168, 0.465, 0.705, 0.655])

Figure 10-5: A check box within a form allows a user to make a Yes/No choice.

When the form data from a check box is returned to the Web server, it will have a name=value pair of either SENDINFO=YES or SENDINFO=NO, depending on whether the check box was left checked (the default in the previous example) or unchecked.

# RADIO BUTTONS

Radio buttons present the user with a choice of one option among several. They are often used in conjunction with check boxes, but you must carefully determine which input method fits what options the user wants to have.
