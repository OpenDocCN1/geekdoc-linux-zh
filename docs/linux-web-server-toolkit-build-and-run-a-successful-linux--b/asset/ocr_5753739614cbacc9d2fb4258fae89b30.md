# A Final Note About HTML

The following online sources offer more information on using basic tags and show the latest tags that have been proposed (or are in use) by the latest browser versions:

+   * The latest HTML specifications, and all previous specifications, are contained on the World Wide Web Consortium at: http://www.w3.org.
* Netscape maintains a list of tags that are supported by different versions of the Netscape Navigator or Communicator browsers at http://www.netscape.com.

If you're going to be creating a lot of your own Web pages, I also recommend getting a complete HTML book as IDG Books Worldwide's HTML For Dummies.

More numerous than these tags are the options and parameters that can be added to the tags I described in this chapter. Parameters supported by many browsers today allow you to do things like centering paragraphs, flowing text around graphics, and determining the font size for any text.
