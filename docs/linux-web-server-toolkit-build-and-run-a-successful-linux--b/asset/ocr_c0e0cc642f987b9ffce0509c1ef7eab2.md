# Chapter 2: Using Linux for Your Web Server

Linux supports several HTML validation tools that can check your HTML pages for consistency and coding errors as well as spelling mistakes before one of your customers points out the error on your pages. Several standard spell checkers in multiple languages also support the creation of error-free Web documents and are included with standard Linux distributions including the OpenLinux Lite CD-ROM.
The list shows several of the free HTML validation tools that are available for Linux (Chapter 19 covers HTML validation tools in detail):

+   - Linkscan from Electronic Publishing Corporation (at http://www.elsop.com/linkscan/index.html)
- VWbot, a shareware Web site traverser (at http://vancouver-webpages.com/VWbot)
- webthreads from Webethreads, LLC (at http://www.webthreads.com)

# STATISTICAL TOOLS

By tracking how your Web site is used, you can learn a great deal about what your customers are interested in and how well your Web site is meeting their needs. Statistical tools allow you to track many facets of Web site activity, including how visitors are using your Web site to find information. You can track things like the most popular pages, the busiest times of day, and the worldwide appeal of your pages. Web statistics are described in more detail in Chapter 13.
Linux has many script and C-based statistical tools that can analyze log files, create dynamic graphs, and help you determine the usage patterns for your Web site. Most of these are free, including the following tools:

+   - Lilypad tool from Streams (at http://www.lilipad.net)
- wwstat from Roy Fielding at the University of California at Irvine (at http://www.ics.uci.edu/pub/websoft/wwstat)
- gwstats, written by Qiegang Long (at http://dis.cs.umass.edu/stats/gwstat.html)

# DOO DADS

More and more toys are livening up Web sites, as visitor counts, little animations, logging visitors', and hundreds other doodles. Linux supports as many of these add-ons as any other operating system. Most are written either in C (Linux includes full, standard support for these binaries, plus a compiler and debugger) or in a scripting language such as Perl (included in Linux, but not with other operating systems).
