# Linux Web Server Toolkit

> CAUTION Changing the Administration server settings involves security issues. You should only change them from a browser that's actually running on the same machine as the Administration server.

# Completing Basic Administration Tasks

Configuring and administering every complex aspects of the FastTrack server is easy from the browser-based interface described in this chapter. If you read any of Chapter 11 about configuring the Apache Web server that's included with the CD-ROM in this book, you'll quickly see that the concepts are the same for both servers. It's just a lot easier to use a browser than it is to edit configuration files.

When you select the link for a specific Web server from the Server Selector page (shown in Figure 12-2), the Administration page appears, as shown in Figure 12-4. This is your main control center for completing all configuration and administration of your FastTrack Server.

Notice the first row of buttons across the top of Figure 12-4: System Settings, Access Control, Encryption, Programs, Server Status, Config Styles, and Content Management. These are the areas of configuration and administration. System Settings opens automatically when you first choose a Server to manage, as shown in Figure 12-4.

Next, notice the column of options down the left side of the page in Figure 12-4: On/Off, View Server Settings, Restore Configuration, and so forth. These are links to the System Settings options that you can configure. When you select one of these links, the right side of the page will change, showing you a new set of information that you can review or alter.

If you select a different category from the buttons on the top of the page, the options on the left side change to reflect that category.

Finally, the two buttons above the top row of buttons (one to the right, and one to the left). The button on the left, which reads, Choose, takes you back to the Server Selector page (shown in Figure 12-2) where you choose which FastTrack Server you want to administer. The button on the right side labeled Apply applies the changes you have made while you were in that particular page. Clicking the Apply button after you make changes on a configuration page is the same as using the kill -SIGHUP command with Apache to restart the server with the latest configuration settings.
