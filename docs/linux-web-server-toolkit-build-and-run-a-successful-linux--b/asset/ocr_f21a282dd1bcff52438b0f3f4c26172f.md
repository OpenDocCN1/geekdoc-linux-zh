When you start the browser from the OpenLinux Lite desktop, points to a file URL (file:///usr/doc/html/index.html) rather than an http URL, so it doesn't get a file from the /home/httpd/html directory. If you create a copy file into the /home/httpd/html directory, you can launch the browser and enter a URL to see it “transferred” from one process on your Linux system to another. For example, if you create a simple file called test.html, you can enter the following URL to view it:

```
http://localhost/test.html
```

Be sure you set file permissions to test.html so that all users have read access. Use the following command:

```
chmod a+r /home/httpd/test.html
```

If you want to remove the Desktop top screens from the Web server document area, you can do so. Because they are accessed using a Web server-based script rather than a simple file read, they may not work if you move them. On the other hand, users will never be able to see a list of what's in your document root directory (/home/httpd/html) so it doesn't matter if you leave the dt/ directory as it stands.

# Summary

This chapter covered how to install and set up your Web server software – either the Apache server that comes as standard on the OpenLinux Lite CD-ROM, or the FastTrack Server, which you can purchase if you need a secure Web server. It also showed you how to access basic system administration information used by your Web server.

In this chapter you've learned the following:

+   - The Apache server is installed automatically on your OpenLinux system when you use the default installation on this book's CD-ROM. Apache is actually running and ready to use. You can review its status with a few simple utilities such as ps and rpm.
- The FastTrack Server is a commercial Web server for Linux that provides secure transactions. It is easy to install on your Linux system and uses a graphical adminisration server for all Web server configuration. We reviewed setting up the administration server.
