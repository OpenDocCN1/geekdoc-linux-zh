# Choosing an Internet Connection Type

With so much press about the Internet, many people may think that connecting to the Internet is a single, monolithic process, like filing your tax return. (And about as difficult, would guess.) It can certainly pose some obstacles along the way, but there are many ways you can connect your system to the Internet. Some are expensive, others are very reasonable. Some are extremely stable, others require more oversight.

In the sections that follow, I describe the key decisions and trade-offs that you'll make as you connect to the Internet. You'll learn what being connected really means, and the different ways you can get connected.
