# Maintaining Statistical Data for Your Site

YOUR WEB SITE CAN quickly become an important part of your business, so it's important to know how well it's working for you. Web server statistics provide you with measures of that success, so you know what's working and what isn't. Topics in this chapter include:

- How you can use Web statistics to improve your site
- Understanding server log files
- Using statistical tools

# How You Can Use Web Statistics

After all effort you've put into creating and maintaining your Web site, wouldn't you like to know how it's being received by the general public? Wouldn't you like to know things like

- How many people are viewing your most important pages
- Where most of your visitors are from?
- How much data is being downloaded from your site?
- Which pages are never seen?
- Are there any error messages that your users use?

The log kept by your Web server contain all this data and more, of course, because they contain a record of every transaction, including every error message generated by the Web server. But if you have thousands of people visiting your site each day, you can't tell all by scrolling through the access log files.

Fortunately, several helpful individuals have developed Web statistics programs that gather the data from your access and error log files and prepare summary information for you. This information includes who is visiting your site, which pages they are accessing, the total amount of data you are sending through your Web server, and other valuable information.
