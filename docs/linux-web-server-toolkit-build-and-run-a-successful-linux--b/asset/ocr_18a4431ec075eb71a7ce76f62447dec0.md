Second, you can define one or more referrer hosts that are ignored. This is primarily-used to avoid recording your own site as a referrer when people are browsing around the links on your pages.
```
ReferrerIgnore www.myserver.com
```

Of course, you can add others to this list if circumstances demand it.

# CONFIGURING THE LOG FILE

If the Common Logfile Format described above doesn't fit your needs, you can define in detail how you want the log information recorded.
To do this, first add the mod_log_config module to Apache. Then add a LogFormat directive to define how you want the components of the log file ordered and which ones you included. The available components are basically the same as the Common Logfile Format, but you can arrange them differently or leave out any that you aren't interested in.

There is a mechanism, however, that allows you to add to the log file information in the browser's headers or in the Web server response headers. This can be very useful, particularly if new header fields become available in some browsers; you'll be able to immediately log and analyze them without changing your Web server.

More information about the configurable log file options is given in the Apache Web server documentation.

# Using Statistical Tools

Many statistical tools are available for your Web site. Most will work with any of the major Web servers because they use the same Common Logfile Format. I'm assuming here that you're using the Apache Web server included with this book.

An easy-to-use program to generate basic Web server statistics is getstats by Kevin Huges. Getstats uses a command line option to generate one of several basic reports, summarizing data in the access_log file.
