# POINTING DEVICES

To use the X Window System interface, you must have a pointing device. Many programs have keyboard shortcuts, but the overall interface does not.

Your pointing device uses a specific protocol (there's that word again) to communicate with the system. The common protocols for pointing devices are Microsoft Mouse and Mouse Systems. Most devices can use one of these common protocols in emulation, even if they have a different one as their standard. Your pointing device also connects to your system via a port on the back of the computer. The options for this are: 

+   - PS/2 port (a special serial port using a small, round 5-pin connector)
- serial port 1, 2, 3, or 4 (usually a rectangular 9-pin connector)

# VIDEO CARD AND MONITOR

After signing the praises of the video capabilities of the X Window System in Chapter 4, it's time to admit that this is the most difficult part of installing Linux. Configuring your video card and monitor to use all the features of X for your graphical interface can be a challenge. Of course, a Web server doesn't need a graphical interface, so it's possible to avoid setting up the X Window System entirely, in which case you don't need to know anything about your video card and monitor. You'll probably want a graphical interface for your Web server, either for system administration or just to have a nice looking screen to work from.

The hard part about configuring the video card for the X Window System is that there are no drivers in the sense you may be used to. Instead, you choose an X server program that matches the type of chip on your video card, or a generic screen resolution. If you specify all the details to get your video card to what you want it to.

Installation of X is getting easier every time. The X system included on the CD-ROM means an intuitive graphical installation program with a list of hundreds of popular video cards. You may be able just to pick the card and go. If that isn't possible, you'll need to know some things about your video card, as follows:

+   - the chipset it uses (examples include strange things like S3, ET4000)
- the amount of memory on the card
- any special options that your video card includes

There will also be a series of hints in the X Configuration utility to help you decide how to configure your specific card.
