I'm going to start with a description of how scripts operate, then back up and talk about Server-Side Includes.

Refer again to Figure 10-1; after you enter information in the fields of the form and press a Submit button of some sort, the browser packages up all the information that you have entered and sends it to the Web server. There are a couple of methods that can be used to send information from a Web page visitor to your server that I will describe in a minute.

Once the information reaches the Web server, the URL that the browser used a script. The Web server starts that script and makes the data entered in the browser form available to the script using the Common Gateway Interface, hence the name CGI and the cgi-bin directory, where executable files using CGI are stored.

You don't really need to know how CGI works. You need only know how to get the information from a browser submission to use in your scripts. You'll see shortly, but an example will help you.
