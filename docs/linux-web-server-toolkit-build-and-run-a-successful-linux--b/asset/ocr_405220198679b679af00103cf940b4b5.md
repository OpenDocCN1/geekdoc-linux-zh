The following list shows just a few of the add-ons that are available for your Linux-based Web server – there are dozens of others, but this cross-section will give you some idea about the range of tools available:

+   * AppGen 4GL application generator written by Andrew Whaley – don’t confuse you with the company named AppGen that makes a complete business system for Linux (at http://www.man.ac.uk/~whaley/ag/appgen.html)

+   * Gifmap Image Navigator package written by Bob Friesenhahn (at http://www.cyberrampp.net/~bfriesen/gifmap)

+   * heintl server-side extensions for database interactivity from H.E.I. (at http://www.heintl.com/)

+   * Mapedit for image maps from Boutell, Com, Inc. (at http://www.boutell.com/mapedit)
