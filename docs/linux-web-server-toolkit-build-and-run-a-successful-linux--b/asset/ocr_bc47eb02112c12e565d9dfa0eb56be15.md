# Configuring the X Window System

After you restart your new OpenLinux system and log in, the first thing you'll probably want to do is get the graphical system up and running. OpenLinux Lite comes with the XFree86 version of the X Window System graphical interface. XFree86 includes a nice graphical configuration utility. Just follow these steps to set it up.
First, log in as root. You can't create the configuration file unless you're the root user.

> If you are logged in as another user and need to do something that only root can do, enter the command su, followed by the root password when prompted. You are switched to root until you exit.

Next, start the configuration utility by entering the following command:

```
$ XF86Setup
```

This starts the graphical setup utility using the lowest graphical setting, VGA. Now you just follow the onscreen instructions to set up each part of the graphical system. There's a good chance that you will need to set up your video card and monitor.

Select the mouse icon first from the upper left corner. The mouse configuration screen is shown in Figure 5-10.

If your mouse already works (you can move it around the screen), you can skip this part. If your mouse doesn't work yet, use the keyboard to select a different mouse protocol or device name. To see how to use the keyboard, press Alt+H. Once you've entered different mouse values, choose the Apply button to see if the mouse works with the new settings.
