# Using Tables

The last feature I'll talk about in detail in this chapter is tables. Although tables were late coming to the HTML standard, they are so important to creating pages that you should really know about them. Not all browsers use them, but most professional Web designers feel the additional flexibility in page layout for some loss in compatibility, so you check for general readability on browsers that don't translate tables.

The great benefit of tables being able to divide your Web page into vertical columns, just like paragraphs and headings you divide it into horizontal sections. Tables are used not only for tabular data, though that's useful. They are also used (without visible grid lines) to arrange complex layouts that include content listings, graphics, headlines, and regular text.
