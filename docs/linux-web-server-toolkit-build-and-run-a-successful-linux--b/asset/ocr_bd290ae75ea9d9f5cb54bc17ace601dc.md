# # Chapter 11: Configuring the Apache Web Server

With the default, any host can access the Web server. The other settings are restrictive enough to allow this without any real concerns.

# ## Understanding Script Directory Security

The Script directory, /home/httpd/cgi-bin/, has the same security as the Document tree, but with no allow directive explicitly included. It includes the following:

Options None
AllowOverride None

# ## Understanding the Options Directive

For each directory container, you can have an Options directive with one or more options after it. Table 11-1 describes each of the possible parameters for the Options directive.

TABLE 11-1 Possible Parameters for the Options Directive Within a Directory
Container in access.conf

| Parameter | Description |
| Indexes | Allows a directory listing to be generated by the Web server and returned to the requesting user if no index.html or other configured default file is found. If Indexes are not allowed and no index.html exists, the user receives an error. |
 Includes | Including the Options option may let users see files that intended to be viewed or it may reveal information about the server that poses a security risk. Allows files in this directory to server-side includes (SSI), a type of server preprocessing of html files which can present security risks. (Server-side includes are described in Chapter 10.) |
| FollowSymLinks | Allows files in this directory that are symbolic links to other files to be followed so the file link points to be sent. If this parameter is not included and the user requests a file that is a symbolic link, an error will be returned ("file not found"). |
| | Including this option allows users to access any part of your Web server outside the DocumentRoot area by a link to it. If a user can create or modify a file on your server, following a symbolic link can allow the user to get anything on your system. |
