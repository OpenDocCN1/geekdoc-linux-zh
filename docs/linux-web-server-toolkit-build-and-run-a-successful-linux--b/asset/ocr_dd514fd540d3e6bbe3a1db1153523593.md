# Chapter 4: Internet and UNIX Technologies

One of the programs that is always running in the background is a superserver called inetd (usually prototyped net-net-det), which stands for the Internet Daemon. inetd constantly watches the networking ports (connections) to see if a request is coming in. The configuration file of inetd provides it with instructions for which program to start for each possible request that comes in. In most cases, inetd will route the incoming request to a running program such as a Web server or else start a program to deal with the incoming request.

Following is part of a sample configuration file for inetd, with instructions that are provided for when network traffic is detected in each of several services. Another file, /etc/services, contains additional information on the ports that are being serviced by inetd.

```
# Shell, login, exec and talk are BSD protocols.
shell stream tcp nowait root /usr/sbin/tcpd.rshd
login stream tcp nowait root /usr/sbin/tcpd.logind
exec stream tcp nowait root /usr/sbin/tcpd.rexec
talk dgram udp wait root /usr/sbin/tcpd.ntalk
```

The inetd program is used to manage all the information that enters at your Linux computer. Each request for service from the Internet comes into a certain port on your Linux system. At the ports the inetd program watches for activity.

# Ports

A port is like a connection socket on your computer. One computer can establish a connection with your computer through a certain port at the same time that another computer is connected to your computer using a different port. It's a software method of multiplexing several connections over a single Internet connection.
