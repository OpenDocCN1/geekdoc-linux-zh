There are two dangers when using Web authoring tools. First, if the tool makes poorly formed HTML code, you cannot easily see it and haven't been practicing with real tags enough to know how to fix it. Second, Web authoring tools have a hard time keeping up with the latest tags from Netscape and Microsoft. If you're planning on using the latest and greatest Web page tricks, you'll need to use a text editor.

# Viewing Existing Pages

Have you ever used the Document Source menu option on your browser? If you haven't, you'll want to start. Open your browser and go to one of your favorite Web pages. Now choose the Document Source item from the File or Edit menu (it's called slightly different things in different browsers).

Don't be intimidated by the mess you probably see. Soon you'll be studying code to see how your favorite pages were created. HTML provides a great tool because it's always in plaintext, so you can see exactly how a developer created the effects you see on the screen.
