# Linux Web Server Toolkit

# ARE PEOPLE TRYING TO BREAK INTO MY SITE?

Security is always a concern with Web sites. Other sections of this book address the topic more thoroughly, but statistics for your Web site can tell you some things because they record every transaction or attempted transaction.

Simple reviews of your error log and access log can give you a warning of people looking to cause you grief with their hacking. Use your statistical tools or the grep utility (with others) to review things like this:

+   - Is a single hostname listed in the error log more than ten times in a single day?

If someone is exploring your site for unlisted documents by trying various URLs, he'll get a lot of "Document Not Found" errors in the process. If he's trying to get into a password-protected document, he'll get a log of "Access Not Allowed" errors as he tries to break the password.

+   - Is a single hostname listed in the access log more than ten times in the same document or script file?

Unless you're taking a lot of orders from the same people, multiple accesses to a form document or a script file can indicate someone trying to submit data to a script in order to pass through a command to disrupt your Web server.

# ARE PEOPLE RETURNING TO MY SITE AT REGULAR INTERVALS?

Repeat visits are a key to long-term success for any organization. Answering this question can tell you if your Web site is helping you achieve this goal. Used in connection with some of the questions you ask (for example, how long are visitors browsing your site), you can judge the usefulness of your site over time. The first thing you have to do is keep statistical data for a period of time. This may be several days or several months, depending on your expectations and what people on the Web are doing with your site.

All that you do to determine repeat visits is correlate list of unique hostnames from a previous period with those of a current period. If many are the same, you repeat visitors! Don't expect a really high correlation so many people may be visiting your site in passing, like windows wandering around the Web. It may be more useful to look at actual numbers of repeated hostnames instead of percentages. For example, if you note that 500 of the same hostnames appeared in February's report as in January's report, you know that 500 people returned to your site. (Be sure to use the list of unique hostnames so you count one per hostname, not one for every hit.)
