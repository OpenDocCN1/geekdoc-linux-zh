# USING GET FOR-FORM-BASED SCRIPTS

Using the GET method is really just like using a normal URL to retrieve a document except that you "ask for" a script file and add on the data for the script to process. The script generates a response based on the data and sends the response back to the browser.

You can use the same type of request without using a form at all. Just use a regular <A> tag link.

Suppose you had a script that processed small database queries using a single query. Instead of providing a form, you could offer several links for your users to choose from, with each link including the necessary URL to query the database and return the correct results. It might look like the following HTML code fragment:

```
<P>
<B>Choose which type of area restaurants you wish to see:</B>
<A href="http://www.city.com/cgi-bin/restaurants.pl?type=Italian">Italian</A>
<A href="http://www.city.com/cgi-bin/restaurants.pl?type=French">French</A>
<A href="http://www.city.com/cgi-bin/restaurants.pl?type=Chinese">Chinese</A>
<A href="http://www.city.com/cgi-bin/restaurants.pl?type=Others">Others</A>
<P>
```

This technique is often used with the <INDEX> tag. This special tag causes the browser to display a single text entry. When a user enters text and presses return, the text is sent in GET format to the current document URL with the query string appended to the URL. For example, a script named query.pl can be requested using the following:

```
http://www.server1.com/query.pl
```

In the following example, the script detects that no keywords are part of the URL, so it returns this line:

Please enter keywords to search for: <INDEX>

The user then enters keywords in the text field created by the <INDEX> tag and presses Enter. The resulting URL sent to the server would look like the following:

```
http://www.server1.com/query.pl?Houston=salsa
```

The query.pl script detects that keywords are included with the URL this time, instead of responding with the <INDEX> tag, the script responds with search results based on the keywords ("Houston") and "salsa").
