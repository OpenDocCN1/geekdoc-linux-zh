# # High Performance

UNIX has been around for a long time – more than 30 years. In that time it has been added to, passed around, and fixed by a dozen companies. When Linux Torvalds started to create a UNIX-like system similar to the AT&T System 5 UNIX, he and those who helped him started from scratch with the benefit of nearly 30 years' of UNIX history but without 30 years' of burdened software code to accommodate.

The result is that Linux has a small, fast kernel. It enables the standard features that all UNIX systems have, like true multitasking (Linux seems to crash), multiuser access, virtual memory, and networking support in the operating system kernel.

Comparing Linux to other operating systems for speed remains mostly anecdotal at this point, because few research studies have been done on Linux, but it is starting to appear as an option on surveys that list other UNIX systems.

One real estate office decided to use a Windows NT system for its Web server. To create a system with it using adequate speed, the folks had a dual Pentium Pro 200 with 512MB of RAM. I've seen a Pentium 120 running Linux with 128MB of RAM handle more than 60,000 Hets per day for a large company.

In another set of tests using BYTE magazine's benchmarking software, Linux running on a Pentium 133MHz scored 22, a Sun Spac 50MHz with dual CPU, normally considered to be much faster than Intel hardware, scored 14.1, and HP 9000 755 (RISC processor-based system) scored 14.1. Visit this URL for details on these tests: http://www.silkroad.com/linux-bm.html.

# # Stability

What do I mean when I say Linux is stable? Basically, it never crashes. Linux goes and goes. Most users of Windows NT or SCO UNIX are not surprised to have to reboot their systems every week or two to keep things running, a well-configured Linux system seems never to go. One Calder system in Canada has been running 24 hours per day, seven days per week for more than 400 days without ever going down.

A study by the University of Wisconsin adds strength to the Linux argument. In a series of tests, each of the major UNIX vendors' products were 'beaten' with random data to see how they performed under stress. Compared to UNIX systems from IBM, SCI, HP, Sun, and others, Linux had the fewest utility crashes.

During testing of numerous system utilities in 1995, Linux hung or crashed in only 9 percent of tests, compared to 18 to 43 percent for commercial UNIX systems. Visit http://www.cs.wisc.edu/-bart/fuzz/fuzz.html for full details and a copy of the research report.

For ultimate flexibility, Linux includes full source code. No Linux user is held captive by a software company; there is an expert nearby—on the Internet or in the next cubicle—who can resolve a problem, because all the code is available for review and alteration.
