# Linux Web Server Toolkit

TABLE 11-3 Advanced Features Available in the Apache Web Server (Continued)

| Feature | Module Required | Description |
| --- | --- | --- |
| Cookies | Yes | Cookies allow a script running on the Web server to keep track of browsers making requests based on previous actions, such as be getting the next record of a database. Though this can be implemented in other ways, cookies provide a simpler solution to making HTTP a more stateful protocol. |
| Configurable logging | Yes | The contents of the access log file can be configured to include a variety of data points. |
| Error messages | No | The error messages sent to a browser when a file cannot be found, when no more clients can connect, or when other errors occur, each can include a specific message. |
| As-Is files | No | A special file type called as-is can be used to send files without the headers normally generated by the Web server. This requires a knowledge of the standard headers so a browser can read the file, but it allows things such as GIF animations to be sent as a single file, saving overhead time. |

# Summary

In this chapter, we've seen how to configure the Apache Web server, the standard Web server that comes with the OpenLinux Lite CD-ROM in this book. We've seen how the standard configuration is set up and some changes that you should make before using it as a full-time Web server.
in this chapter you've learned the following:

+   * All Apache configuration files use directives — simple commands — to define how the Web server operates.
* The httpd.conf file contains information about the general operation of the Web server program.
* The srm.conf file contains information about the resources used by the Web server, such as how documents are processed before sending them to a browser.
