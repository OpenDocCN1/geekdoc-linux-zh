# Strong Web Tools

The rest of this book will be talking about all the Web-related things you can do with Linux, but here's a quick preview. This list includes a few of the things available, almost all for free, to help you create and maintain your Linux-based site.

## WEB SERVERS

First, there are Web server programs – the software that makes your computer capable of sending Web pages to browsers. The next chapter talks about the many that are available for Linux, both free and commercially supported. Web servers are robust and fast. Many also secure transaction capabilities using First Virtual, Verisign, or similar technologies. The following list gives just a few of the Web servers available for Linux:

- AOLServer from America Online (at http://www.aolserver.com/server/index.html)
- Apache from the Apache Project (at http://www.apache.org)
- Stronghold SSL Web Server, based on Apache, from UKWeb (at http://stronghold.ukweb.com)
- Netscape FastTrack for OpenLinux from Caldera, Inc. with an exclusive license with Netscape (at http://www.caldera.com)
- Zeus httpd server from the National Center for Supercomputing Applications (at http://hohooo.ncsa.uiuc.edu)

## FIREWALLS

Most Web servers also require security between your computer systems and the Internet. Firewalls are the most common way of providing this.

There is commercial firewall software available for Linux. These packages allow you to configure which network packets reach your Web server or other computers into your network, as well as plugging up many potential security holes. The powerful IP filtering functions inherent in Linux may be sufficient for you, but one of the main benefits of add-on firewall software is that it makes security a great deal easier to set up and maintain. The following list gives a few of the firewall tools available for Linux:

- Firewall Toolkit from TIS (at http://www.tis.com/docs/products/fwtk/index.html)
- ipfwadm utility, an IP firewall administration utility from X/OS in the Netherlands (at http://www.qos.nl/linux/ipfwadm)
- WatchGuard firewall from WatchGuard Technologies (at http://www.watchguard.com)
- WebFilter, part of the CERN web server (at http://www.w3.org/pub/WWW/Daemon)

## HARDWARE SUPPORT

All of the special hardware that you might need to set up a Web server or a complete Internet server is supported by Linux. That includes terminal servers, ISDN boards, frame relay boards, router boards, high-speed networking cards, 256-port serial cards, and more.

In Part II, you will read more about using some of these peripherals as you decide how to connect your Web server to the Internet. Specific information regarding some of the most popular hardware options is provided in Chapter 4.

## HTML CONVERSION TOOLS

Many conversion filters are available to help you create HTML documents from your existing material. If you have documents in WordPerfect, Word RTF, FrameMaker, LaTeX, text files, or many other formats, free filters are available for Linux. Several commercial filters are also available. The following list shows popular HTML tools (see Chapter 1 for a more comprehensive list of cross-platform conversion tools:

- Empress DataWEB from Empress Software, Inc. (at http://www.empress.com)
- LaTeX2HTML, a free software project (at http://cbl.leeds.ac.uk/nikos/latex2html/html/latex2html.html)
- Web+, a Web-to-database integration tool from Talentoft (at http://www.talentoft.com)
- WebTuk, a free graphical HTML editing tool (at http://www.sunscript.sun.com)

## HTML VALIDATION TOOLS

After documents have been converted from original formats into HTML, or HTML pages have been created from scratch, HTML validation tools are often used to check the quality of Web pages.

Linux supports several HTML validation tools that can check your HTML pages for consistency and coding errors as well as spelling mistakes before one of your customers points out the error on your pages. Several standard spell checkers in multiple languages also support the creation of error-free Web documents and are included with standard Linux distributions including the OpenLinux Lite CD-ROM.

The list shows several of the free HTML validation tools that are available for Linux (Chapter 19 covers HTML validation tools in detail):

- Linkscan from Electronic Publishing Corporation (at http://www.elsop.com/linkscan/index.html)
- VWbot, a shareware Web site traverser (at http://vancouver-webpages.com/VWbot)
- webthreads from Webethreads, LLC (at http://www.webthreads.com)

## STATISTICAL TOOLS

By tracking how your Web site is used, you can learn a great deal about what your customers are interested in and how well your Web site is meeting their needs. Statistical tools allow you to track many facets of Web site activity, including how visitors are using your Web site to find information. You can track things like the most popular pages, the busiest times of day, and the worldwide appeal of your pages. Web statistics are described in more detail in Chapter 13.

Linux has many script and C-based statistical tools that can analyze log files, create dynamic graphs, and help you determine the usage patterns for your Web site. Most of these are free, including the following tools:

- Lilypad tool from Streams (at http://www.lilipad.net)
- wwstat from Roy Fielding at the University of California at Irvine (at http://www.ics.uci.edu/pub/websoft/wwstat)
- gwstats, written by Qiegang Long (at http://dis.cs.umass.edu/stats/gwstat.html)

## INTERNET INTEGRATION

In addition to doodad support, when you use Linux as your Web server, you get a complete Internet server with all the other Internet protocols already integrated.

Web servers are at their best when they can interact with other Internet and local resources to process information. Because Linux can connect to many systems and includes so many diverse Internet services in its standard installation, your Web pages can assume those services are available and immediately take advantage of them.

Many of these additional services are described in Chapters 10 and 14. For example, a simple script on a Linux-based Web server can receive data from a form. With two lines of code, the script can send the data as an-mail to someone on the Internet using the SMTP mail server that is included as part of Linux.

## Growing Linux Acceptance

For some of you, the benefits listed in this chapter may not dispel the feeling that Linux is a toy or a research tool rather than an OS fit for a production system. Yet Linux is widely used in Fortune 500 companies, top universities, and small businesses around the world.

Linux began its popularity growth among longterm system administrators and developers. Many stories are told of developers creating a Linux port and placing it on the shelf to wait until management decided to sell it. There are also tales of programmers developing a company's products on their home Linux systems and then porting to the system for which they were actually writing them. These people don't seem to want their names listed here.

As a grassroots movement, Linux is very strong. As a corporate solution, it is also very powerful.

Consider the following facts: Linux groups number about 175 around the world, with active memberships ranging from 15 to 400. User groups are organized in countries such as Australia, Denmark, the Czech Republic, Poland, Turkey, Greece, India, Israel, Argentina, Brazil, Lithuania, Singapore, Canada, and the United States (which alone has 78 groups), according to one recent list.

The number of press stories on Linux has skyrocketed, following a similar pattern to stories about the Internet in 1995. A recent review showed the number of stories jumping from 11 to 67 on Linux and Linux companies in two consecutive quarters. International press coverage of Linux is even stronger than in the U.S. Linux has been on the cover of the top GNU UNIX magazine (IX Multiuser) and on the cover of the Italian version of PC Magazine, to name just two examples.
