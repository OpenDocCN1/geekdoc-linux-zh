# Maintaining Your Site
from Day to Day

Now that you have a connected, operating Web server, the following seven chapters describe the ups and downs of maintaining it. Document creation is explained in a basic HTML tutorial with pointers to tools and information. You'll also learn how to publicize your site and keep visitors coming back. Both Apache and FastTrack Web Server configurations are described in detail. Basic issues of scripts, forms, usage statistics, and day-to-day security and administration issues are also discussed.
