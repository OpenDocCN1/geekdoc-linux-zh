To use this feature, the UNIX crypt() routines or the utilities in the /sbin directory that were installed as part of Apache to create a user file with usernames and passwords. It might look like the following (remember, the passwords must be generated by a utility, not made up):

```
nwells:45Ge7dD8k1ws9swk2
admin:L908SS80kwnfw8S
```

You can also create a group file that names the users from the first file that are part of groups that you define, for example, in the following:

```
guests: nwells bird paull
```

Then you can use a set of directives for a directory that you want to protect requiring the browser to return a correct username and password before the document will returned. The directives look like the following:

```
<Directory Name /docs/protected>
AuthName Protected
AuthType Basic
```
