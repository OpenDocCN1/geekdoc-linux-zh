Figure 5-12: Selecting a monitor type to configure the X Window System using the XF86Setup utility (most monitors will be one of the last three categories).

The ranges provided for each monitor type and shown in Figure 5-12 (for example, 1280 x 1024 at 70 MHz) are the maximum for the monitor. This enables the X server to keep within the safe range for your monitor. You can always try lower resolutions and restart this utility and try a little higher one. Sometimes your card will not respond correctly to the higher resolutions even though the monitor can support them. Sometimes tinkering is needed.
