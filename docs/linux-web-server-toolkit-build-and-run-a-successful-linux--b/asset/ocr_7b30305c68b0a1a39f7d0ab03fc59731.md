# Linux Web Server Toolkit

TABLE 16-2 Database Gateways (Continued)

| Package | URL | Description |
|---|---|--|
| FormGate | http://www.mpi-sb.mpg.de=/brahm/formgate.html | A Lotus-Notes-to-HTML forms gateway. With the release of Domino from Lotus, gateways between the Web and Notes are less prominent, but several good packages are available for free. |
| InterNotes Web Publisher Development Site | http://www.internotes.lotus.com/ | A commercial tool that converts Lotus databases into HTML documents. |
| Sgate | http://ls6-www.informatik.uni-dortmund.de/Sgate/Sgate.html | A CGI interface to provide HTML-formatted information from WAIS servers. |
| WLU | http://tpl1.brunel.ac.uk:8080/wlu.html | A package that provides a Web interface to X.500 directory databases. |
| dbedit | http://www.dbacademy.org:8001/uu-gna/tech/dbedit/dbedit.html | Freely available toolkit for creating Web-accessible databases. |
| GSQL | http://www.ncsa.uiuc.edu/SDG/People/jason/pub/gsql/startheme.html | A Mosaic-to-SQL gateway (which might be useful on other browsers as well). |
| Oracle | http://www.yahoo.com/Computers_and_Internet/Internet/World_Web/Databases_and_Searching/Oracle | There are many products developed for interfacing Oracle databases with the Web, including operable (a Perl toolkit), OracleGate, and orayww, an interface for nonprogrammers to access Oracle databases, build previously built forms. |
| WDB | http://www.dtv.dk/~bfr/wdb/ | A software toolset that simplifies many types of Web-to-database connectivity. |
