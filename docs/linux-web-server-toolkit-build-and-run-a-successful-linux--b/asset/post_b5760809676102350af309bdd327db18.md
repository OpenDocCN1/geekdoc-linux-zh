# THE ROUTE UTILITY

A related utility is the route utility (also located in the /sbin directory). The route utility inserts instructions into the Linux kernel, so that when a packet is received that is not for your computer, the kernel knows where to send it to its final destination.

Routing can be very complex and often involves computers at other sites, including your ISP. But the routing tables (lists showing where to send things) your computer can be very simple if you are not acting as a router for many other systems.

When you add a new interface using the ifconfig utility, you usually follow it with the route command to indicate how to route packets that pass through that network interface. # THE ROUTE UTILITY

A related utility is the route utility (also located in the /sbin directory). The route utility inserts instructions into the Linux kernel, so that when a packet is received that is not for your computer, the kernel knows where to send it to its final destination.

Routing can be very complex and often involves computers at other sites, including your ISP. But the routing tables (lists showing where to send things) your computer can be very simple if you are not acting as a router for many other systems.

When you add a new interface using the ifconfig utility, you usually follow it with the route command to indicate how to route packets that pass through that network interface. For example, if your machine has two Ethernet cards and is acting as a gateway, packets might be routed from one network to the other. If the computer is acting as a firewall, the route might prevent any packets from moving to the other network.

When you set up all the routes for your computer, you include a default route that packets follow if they don't match any of the other routes listed.

You can see the current routing tables by entering the route command without any options, as follows:

```
$ route
Kernel routing table
Destination Gateway Genmask Flags MSS Window Use Interface
localnet * 255.255.255.128 U 1436 0 160458 eth0
loopback * 255.0.0.0 U 1936 0 13825 lo
default igw.venture.com * UG 1436 0 15418 eth0
```
