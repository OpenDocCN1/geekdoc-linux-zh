You should also be aware that rpm files are divided into program rpm files and source code rpm files. The source code rpm file is intended for those who want to work on the development of a piece of software. If you want only to use the software, you need only the program rpm file. The source code rpm files are located in the col/sources/SRPMS directory on the OpenLinux Lite CD-ROM. Each rpm file containing source code for a software package uses the file extension .src.rpm.
