# 第一章

## 规划你的网站

购买这本书意味着你（或其他人）已经决定公司需要一个网站，并且已经决定为功能全面的 Web 服务器分配资源。Web 服务器是任何存储 Web 页面并使用互联网协议（如 TCP/IP）响应浏览器请求的计算机。

本章应该增强你的信心，并希望解决你对这一蓬勃现象可能存在的某些问题。它还提供了一些可以传递给比你更有热情的人的事。

本章涵盖的话包括：

- Web 的爆发
- 为什么需要网站？
- 什么是好的网站？
- 什么是糟糕的网站？
- 定义你的 Web 存在
- 为你的网站制定计划
- 法律考虑

第2章开始讨论 Linux，以及为什么它是一个理想的 Web 服务器平台。

## Web 的爆发

想想 Web 增长得如此快，真是令人惊叹。它就像微波炉或传真机一样——我认识的人几乎无法想象没有 Web 的生活。突然之间似乎每个人都想浏览 Web，甚至想拥有自己的页面或网站。在1994年，有一个“新内容”页面，大家向其提交页面和服务器的 URL。我非常喜欢查看这些列表，看看人们在 Web 上发布的内容是多么多样。
