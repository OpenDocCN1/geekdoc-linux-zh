# DEFINITION LISTS

Definition lists are not used as commonly as bulleted lists and numbered lists.
They're intended for things like glossary entries, where you have a short item fol-\owed by a description or definition. Definition lists don't include a character, such
as a bullet, before the text. They only define the indentation and may be the font
style (depending on the browser).

To create a definition list, start with the <DL> tag and end with the </DL> tag.
Within the <DL> tag pair, your list items consist of pairs of Definition Terms using
the <DT> tag and Definition Descriptions using the <DD> tag. You can use multiple
<DT> tags before a <DD> tag, or multiple <DD> tags before another
<DT> tag. The two tags just determine the indentation and font used for the text
that follows. Figure 9-6 shows a sample definition list for the HTML code below.

```
<DL>
<DT>Cairo
<DD>Visit the pyramids. Memphis, the old city, cruise the Nile, and
enjoy the national museum.
<DT>Luxor
<DD>Visit the Temple of Karnak and the Valley of the Kings. Take an
expedition tour to a desert oasis.
```
