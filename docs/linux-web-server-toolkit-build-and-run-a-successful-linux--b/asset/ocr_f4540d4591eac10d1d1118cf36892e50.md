# Preface

Imagine being able to provide your customers, no matter where they reside, with immediate access to your organization's most current information. A Web server can do just that—it can provide a unique and comprehensive communications medium.

Many of you may find the thought of setting up and maintaining a Web server daunting. It can also be a very expensive endeavor if you don't choose Linux as an operating system. In fact, and what you'll learn as you read this book, the process is not overly complicated. You'll need to install an operating system, configure your Web server software, and create the content for your Web site.

This book provides all of the software you need for a Web server and instructions on how to use that software. It describes each of the steps for installing a powerful 32-bit Linux operating system, configuring Web server software, and maintaining that server from day to day.

Setting up a Web site without first considering related business issues can lead to wasted resources and a poorly designed site that visitors find uninviting. Perhaps a worse, a lack of technical understanding about the Web may mean your site isn't designed to be efficient and friendly for your customers, or it may open your organization to security risks.

This book walks you through the business issues you should consider as you set up a stable, secure Web server. But more than that, it's a toolkit that provides all the software and instructions you need to set up and manage a new Web server as it becomes a key part of your organization' communication.

This book teaches you how to:

+   - Effectively plan your Web server as a cohesive part of your business strategy
- Determine what content will be placed on the Web server
- Install the Linux operating system included on the book's CD-ROM
- Configure and test the Web server software included on the book's CD-ROM
- Create simple Web pages in HTML
- Add functionality to your Web server, such as statistical charts, Java pages, database connectivity, and so forth
- Complete system management tasks on your Web server, like backing up the server and upgrading software packages
