# Linux Web Server Toolkit

To assign a style, just select a style from the drop-down list of styles and enter a URL in the URL field provided. Press OK to complete your assignment.
You can list all the assignments currently in use on your server by using the next page, List Assignments. Each URL and corresponding style name are listed. Assigning a style is like using the <DIRECTORY> contains in the access.conf file for Apache or other web servers. It's a little different in its application, because all the features are contained in a style with a name you select, instead of just listed under the directory where you want them to apply. But that is the same.
