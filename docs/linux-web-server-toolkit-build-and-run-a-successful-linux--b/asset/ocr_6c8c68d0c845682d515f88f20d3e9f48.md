To find out more about the supported hardware, you can check the Supported Hardware HOWTO page at http://www.caldera.com/LDP/HOWTO/HardwareHOWTO.html. This HOWTO document, which is updated regularly, will include references to specific components that you must install or to support specific hardware. For example, you might need a certain driver, with a certain version of the system library files (libc), with a certain kernel version number (2.1.49 or something... be careful if the hardware is supported only by a development kernel). Links to the needed pieces are almost always provided when you view the HOWTO document on a Web site.

On the other hand, if the hardware you have (or want to have) isn't on the list of supported devices, even in the latest version of Linux, what should you do? Follow these two things:

+   1. Find a similar piece of hardware that is supported, as the same type of hardware (for example, 100MB Ethernet) from another vendor, or a different model from the same vendor. Locate the person who wrote or maintains the support for Linux for that hardware and e-mail address will always be provided in the MAINTAINERS or CREDITS file on the OpenLinux CD-ROM or in the HOWTO document, Web page, or driver module itself. Now send polite e-mail asking about support for the model you prefer to use. Often you'll hear back that your model is also supported but not explicitly listed, or that support is coming, or that it can't be supported for and such reasons.

+   2. Make sure to take this step, no matter what response you get from Step 1. Contact the manufacturer of the hardware piece and ask if there is a Linux driver for it. The purpose of this is not to get the driver; in 80 to 90 percent of cases, they won't have one. The purpose is to make a loud noise so the manufacturer will start to create Linux support at the outset and will provide information to the Linux community to create support for its hardware. This increases sales and makes your life easier next time.

You can go ahead with the installation without knowing for certain all your hardware is supported by Linux. But before you start, you need to gather some information about your hardware (maybe) and your network (definitely). The next section discusses what information you'll need before you do the install.
