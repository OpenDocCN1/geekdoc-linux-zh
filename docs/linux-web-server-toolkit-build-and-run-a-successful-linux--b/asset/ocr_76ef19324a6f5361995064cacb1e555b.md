Hypertext Reference, you use the NAME parameter to mark the anchor as a landing place for a link. Basically, you're naming that section of the document.

Your names should not include spaces. Assume that the names are case sensitive, like other data provided as part of parameters, although this may not be true in some browsers.

Once that is in place, you can refer to it from any other document using a hash mark (#) to separate the filename and the named anchor in the URL. For example, you can create a named anchor on a headline like this:

```
<A NAME= PART_TWO>Part Two - Employee Benefits/>
```

Then you can always create a link so that the headline is at the top of the browser screen using a URL like the one in the A tag in this example:

```
<P>
<A HREF=#PART_TWO>employee benefits section</A>
<P>
```

In the previous example, the named anchor and the link to it are in the same document, the reference in the <A> tag starts with a hash mark (#). If the link was in another document, a link directly to the Employee Benefits section of the other file may appear like this:

```
<A HREF=/public/handbook.html#PART_TWO>employee benefits section</A>
```

> When you enclose text in an <A> tag to make a link, the preferred writing style is to enclose words that make sense even if the document is not online (even if the link is not accessible or the document has been printed out on paper). For example, instead of saying “For information on our new product, click here,” remove the “click here” phrase and say “You can also see more information about our new product,” with a link on the words “new product.”
