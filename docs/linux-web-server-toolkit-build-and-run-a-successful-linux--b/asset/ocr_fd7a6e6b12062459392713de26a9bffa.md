# Chapter 13: Maintaining Statistical Data for Your Site

TABLE 13-1 Some Popular Web Server Statistics Tools (Continued)

| Name | Free or Commercial | Description |
| --- | --- | --- |
| Gwstat | Free | Graphics toolkit for turning statistics files (from wwwstat) into simple charts in GIF format that show what is happening on your Web server. Because graphics are created in GIF format, they are immediately usable on your Web site to show visitors any information you wish to publish about your site. |
| Statbot | Free | Automatically generated database file that regularly updates system statistics. Easy to configure and use. |
| AccessWatch | Free | Tool that creates prose (paragraph style) descriptions of how your server is being accessed, with additional details in tabular format. |
| WebTrends | Commercial | Powerful and complete package for tracking the progress of your Web site. Includes many graphing and charting capabilities, plus general and detailed statistical information in HTML formatted pages. |
| Net.Analysis | Commercial | Powerful commercial tool that uses Informix database to track your Web server activity in real time. Provides many custom reports and automatic graph formats |

Other free and commercial products are available to analyze log files as well. You can search for new and updated tools by reviewing the list on Yahoo. Go to http://www.yahoo.com and choose Computers, World Wide-Web, HTTP, Servers, and Log Analysis Tools from successful menus.

# Automating Your Statistical Tools

Once you become familiar with the statistical tools you want to use regularly, you should consider adding them to regularly scheduled events on your Linux system. Doing this means the statistical information you come to depend on your site is always available and to date.
Just add the command lines or script names for the statistical programs to your /etc/crontab file (see the man page for doing on this by entering the command man crontab at any command line). It's important to choose regular intervals
