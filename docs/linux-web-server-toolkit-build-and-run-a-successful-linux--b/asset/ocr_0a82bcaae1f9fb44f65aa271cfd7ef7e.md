The search engine sites are not the only place to advertise. Many major media sources and publications offering advertising banner space on their Web sites. For example, visit Time magazine (http://www.time.com), CNN (http://www.cnn.com), U.S. News (http://www.usnews.com), or Business Week (http://www.business.com).

When you're considering advertising your Web site on someone else's Web site, be sure to investigate the number of hits site experiences per day, the creative help offered, method of charging, and ability to focus your banner impressions to a specific market using search keywords or other methods.
