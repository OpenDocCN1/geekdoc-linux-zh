# Keep Them Coming Back

It's lot easier and less expensive to sell again to a previous customer than to locate, educate, and convince a new customer that you have something worth taking.

On the Web, it's easy to visit ten sites in one minute, so you have to visit your site, and easy for them to find what they want.
