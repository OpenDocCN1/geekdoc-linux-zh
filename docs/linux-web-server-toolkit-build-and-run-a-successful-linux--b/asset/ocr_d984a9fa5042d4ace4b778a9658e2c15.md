+   Documents, image files, and scripts on your Web server are stored in standard directories. You can select the root directory for documents on your Web server. All Web servers have the ability to generate documents that list the contents of document directories, unless you turn off that feature for security reasons. An index.html file provides a default document when any directory is requested as a URL.
