# INSTALLING LILO

One of the final steps of the installation program is to install the Linux boot loader program, LILO. As I stated earlier in this chapter, LILO is a boot manager for Linux that starts the operating system for you and can also start other operating systems on your hard disk.

LILO is a small program that reads a configuration file and gives you options for which operating system should be started. Once you make a choice, it passes control to another program on the hard disk.

The hardest part about using LILO is deciding where to put it. The basic options are follows:

- **On the Master Boot Record of the first hard disk:** This is the safest way to get Linux to boot, but it is a little dangerous. It can be hard to fix a problem with the Master Boot Record. If the next option works, use it instead.

- **On the root of the Linux partition:** This enables the Master Boot Record to pass control to LILO without altering that important part of your hard disk. If a problem occurred with the Linux Partition, you could erase the partition and start over, without losing the entire hard disk.

If you use this option, the Installation utility will mark this as the active partition, so that the MBR will pass control to LILO.

- **On a floppy disk:** This is a backup system, but you don't really need to do this. The only reason to use a floppy LILO is, for some reason, you don't want to alter the booting sequence of your system in any way. It gives you the most control to booting Linux.

A scenario when this might be appropriate is when you have another operating system such as Windows NT on your computer. Windows NT doesn't work very well as a dual boot with Linux (the previous note). With LILO on a floppy disk, you can just pop the disk in to start your machine when you want to run Linux. This also provides a more secure method; if you don't have the disk, you can't easily start up the machine in Linux.

If you don't install LILO on a floppy disk and you have a problem where your system won't boot correctly to Linux, you can use the installation disk created at the beginning of the installation procedure. Press Enter to use the default name for your standard Linux system. If you used any parameters when you started the installation, they should be entered here. They are stored in the LILO configuration file, so you don't have to enter them each time you start your system.

# Configuring the Window System

Finally, choose the X server that you want to use, based on the chipset used on your video card. It's not a bad idea to choose VGA, which is always selected, SVGA, which makes a nice compromise if you can't get a higher resolution to work.

Follow the onscreen instructions to set up each part of the graphical system. There's a good chance that you will need to set up your video card and monitor.

Select the mouse icon first from the upper left corner. The mouse configuration screen is shown in Figure 5-10.

If your mouse already works (you can move it around the screen), you can skip this part. If your mouse doesn't work yet, use the keyboard to select a different mouse protocol or device name. To see how to use the keyboard, press Alt+H. Once you've entered different mouse values, choose the Apply button to see if the mouse works with the new settings.

After you restart your new Linux system and log in, the first thing you'll probably want to do is get the graphical system up and running. OpenLinux comes with the XFree86 version of the X Window System graphical interface. XFree86 includes a nice graphical configuration utility. Just follow these steps to set it up.

First, log in as root. You can't create the configuration file unless you're the root user.

> If you are logged in as another user and need to do something that only root can do, enter the command su, followed by the root password when prompted. You are switched to root until you exit.

Next, start the configuration utility by entering the following command:

```bash
$ XF86Setup
```

This starts the graphical setup utility using the lowest graphical setting, VGA. Now you just follow the onscreen instructions to set up each part.
