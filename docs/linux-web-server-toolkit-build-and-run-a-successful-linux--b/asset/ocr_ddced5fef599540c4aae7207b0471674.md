# Understanding HTML

HTML, or Hypertext Markup Language, was developed in the early 1990s as part of the original plan for the Web. It was created to meet the need for a simple language that could express graphical elements and hypertext links in documents passed back and forth on the Web. As started out as a very straightforward and simple tool you could learn in an hour or two. For better or worse, it's got a lot more complicated than that, more complicated than the information provided in this book. This chapter starts out by providing an overview of HTML. After that, I explain how HTML is organized and how browsers use to display documents from the Web. I'll also describe some of the tools you can use to create HTML pages.
