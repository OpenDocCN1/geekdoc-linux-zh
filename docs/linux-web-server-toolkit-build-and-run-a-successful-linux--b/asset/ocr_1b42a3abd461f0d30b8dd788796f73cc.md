| TABLE 4–8 Key UNIX Commands (continued) |
| Command | Description | Example(s) |
| --- | --- | --- |
| mv | Moves a file or directory from one location to another. Also used to rename files (as the second example – in effect moving within the same directory to a different name). | mv /tmp/newversion/home/nick mv newversion working.file |
| rm | Removes (deletes) a file. Usually requires a confirmation for each file deleted. Nonrecoverable. Be very careful using options that circumvent the confirmation of each deletion. | rm *.tmp rm -r /oldstuff |
| ls | Lists the files in a directory, including (optionally) owner, permissions, and so on. | ls -l /etc |
| ps | Lists the processes started by the current user or (optionally) by all users on the system. | ps ps -aux |
| more | Displays a text file, pausing after each screen until the user hits a key (equivalent to TYPE file | MORE in DOS). The less command is similar and provides additional flexibility. | more testfile.txt |

Command-line utilities are great for getting into the nitty-gritty of your system, but most users prefer to have a graphical dialog box available whenever possible. To this end, the next section introduces you to the X Window System, the graphical system used by virtually every UNIX system in the world.
