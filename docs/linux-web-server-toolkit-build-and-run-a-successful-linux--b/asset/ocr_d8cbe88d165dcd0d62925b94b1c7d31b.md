Remember, however, that files created in a text editor will not automatically have the execute bit set because you created an HTML file; HTML files normally never have the execute bit set. If you add an SSI command to one of your HTML files, you must then use this command to set the execute bit for that file:

```
chmod a+x newfile.html
```
