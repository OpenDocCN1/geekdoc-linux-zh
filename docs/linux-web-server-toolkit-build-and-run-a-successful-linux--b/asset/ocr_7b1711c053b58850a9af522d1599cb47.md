# ## COLOCATING A WEB SERVER

There's a middle ground between having your Web site and having a Web server at your location — it's referred to *colocating* a Web server at your ISP. This option is gaining in popularity because it combines the best aspects of hosting and having your own Web server.

When you colocate a Web server, you provide a separate computer with your Web server and page information on, but place that computer at your ISP's office. You get the control, flexibility, scalability, and so forth having your own server, but can drastically reduce the costs because it doesn't require that you install a high-speed line at your office.
