# Appendix A

# What’s on the CD-ROM

The COMPACT DISC (CD-ROM) that accompanies Linux Web Server Toolkit contains the OpenLinux Lite product from Caldera, Inc. (see http://www.caldera.com). It includes all the Web server tools and utilities you'll need, as well as many that dont want to apply to using a Web server but that you might find interesting (a great version of Tetris, for example). This appendix describes the contents of the CD-ROM.

If you want to install OpenLinux Lite immediately, you can begin by changing to the /col/launch directory and reading the README file in that directory. Full installation instructions are provided in Chapter 5 of this book.

The CD-ROM contains a directory named /col (for Caldera OpenLinux). Within the /col directory are the following subdirectories:

+   * /Bin
* /Contrib
* /Data
* /Doc
* /Install
* /Launch
* /Pgp-keys
* /Sources
* /Tools

The contents of each directory are discussed in the sections that follow. The top level directory and several of the main subdirectories (such as launch and tools) contain README files that summarize what is located in that directory.

# Bin: Various Programs

The Bin directory contains several utility programs you can use if you need to create a nonstandard installation of OpenLinux Lite. Note that if you follow the installation procedure described in Chapter 5, you don't need any programs from the /Bin directory.
