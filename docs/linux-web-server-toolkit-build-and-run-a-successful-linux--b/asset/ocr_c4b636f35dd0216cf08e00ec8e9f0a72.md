The Desktop includes about 2,000 icons that you can specify for particular types of files. You can also add your own or modify an existing icon using the Icon Editor. To start it, choose Icon Editor from the Run menu of the Desktop. Choose the System Galley from the menu and double-click on the icon you want to edit. # MANAGING FILES

From the Desktop window, you can use the menu items to move and copy files, sort them, view all their properties (try the View menu), or drag any icon to the Desktop for quick access or to another folder to move or copy it.

The Desktop makes an easy place to manage the ownership and permissions described earlier in this chapter. To do this, select a file in a Directory window by clicking on its icon. Now choose the Information item from the File menu of the Directory window (not from the top menu of the Desktop). A dialog box appears, as shown in Figure 4-5.
