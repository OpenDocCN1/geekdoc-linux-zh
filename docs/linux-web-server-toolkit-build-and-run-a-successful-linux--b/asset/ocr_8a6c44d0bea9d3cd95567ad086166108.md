# Checking the Status of Apache

Unless altered something from the default installation, the Apache Web server is running each time you boot into OpenLinux. To make certain it is really running, try the following command at any command-line prompt (the text you enter is in boldface, the response is in regular font):

```
$ ps -waux | grep httpd
body 29136 0.0 4.4 1104 476 ? S 22:37:00 httpd -f
/etc/httpd/apache/httpd.conf
```

The grep command following the ps command uses a UNIX pipe to search the output of the ps command for the string httpd, the name of the Web server program.

![](bbox=[0.059, 0.403, 0.153, 0.458])

If you were connected to the Internet and were actually using the Web site when you entered the command mentioned previously, you might see many lines in the output, each listing httpd. I'll explain why in Chapter 11, where the configuration files are discussed in detail.

You might be wondering why or how Apache is started automatically when you start your system. If you're familiar with DOS and the AUTOEXEC.BAT file, it's done by using a similar feature in UNIX. The Linux initialization information is contained in many files that are executed in a certain sequence. In addition to systemwide startup scripts, each user can have specific commands executed each time a new login session is started. This is sort like NetWare login scripts, with a system startup script and individual user login scripts, except that Linux can have multiple login scripts for both system startup and individual login scripts.

The system startup script that contains instructions to start Apache on any OpenLinux system is located in file: /etc/rc.d/S85httpd. The information that is used to start the Web server is located in the configuration file at /etc/sysconfig/daemons/httpd. This configuration file defines which Web server is started. It also checks to see that there is a valid configuration file before starting the Web server (a good security precaution) and decides at boot time to start the Web server.

If you prefer that the Web server not started by default, just change the ONBOOT option in the /etc/sysconfig/daemons/httpd file to “NO” as follows:

```
ONBOOT= no
```
