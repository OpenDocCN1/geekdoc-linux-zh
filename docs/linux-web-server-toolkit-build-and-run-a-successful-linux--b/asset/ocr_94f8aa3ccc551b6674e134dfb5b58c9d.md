# Linux Web Server Toolkit

The Web server included with OpenLinux Lite Apache, the most widely used Web server on the Internet, but unfortunately, it is not the secure version of Apache, and so it transmits data such as credit card numbers across the Internet without encryption—obviously not anything we want to do or ask our customers to do. There are several commercial web servers available for Linux. The two most popular are commercial version of Apache, which is produced by Stronghold, Inc., and the Netscape FastTrack Server, which is sold through Caldera, Inc.
