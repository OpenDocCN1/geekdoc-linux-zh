When the screen pauses with messages, you can use the Left-Shift+PgUp or PgDn to scroll up and see the messages that flashed by too quickly. They contain information about what hardware was recognized by the kernel during the booting process.

Press Enter again to continue the installation. After a moment, a screen with a menu box appears in the middle as the installation program starts and loads various parts of the program.

After the installation program gets started, the next step is to make certain that it recognizes enough of your hardware that the installation can proceed. This is discussed in the next section.

# Hardware Identification

The installation program now tries to recognize the IDE devices on your computer and shows a list of what it finds. After you press Enter, you are asked whether all the devices needed to install your system were listed.

> You need to have your Ethernet card recognized if you want to install the network using Network File System (NFS). Otherwise, you can add your Ethernet card later. Of course, it's more convenient to do it all during installation if you can.

At this point in the installation process, you should have your hard disk and your CD-ROM drive listed (if you're going to install from CD-ROM). If you don't see one or the other listed, you'll need to autoprobe or manually load a kernel module in order for the OpenLinux program to recognize them. If a hardware component on your system is not listed but is not needed to complete the installation (for example, a sound card), don't worry about right now. You can easily set that piece of hardware after the installation is completed by loading a module or performing a couple of alternate steps.

If you know what hardware is missing from the list, such as a CD-ROM drive or an SCSI adapter, your best bet is to go to the Kernel Module Manager screen of the Installation program by selecting No when autoprobing is offered as an option. If you're not sure what's missing, autoprobing is a good choice.
