Figure 16-3: The e-mail sent automatically from an e-mail gateway that responds to the form in Figure 16-2 might look something like this. Many formatting and e-mailing options are provided with some e-mail gateway packages.

There are many e-mail gateway packages available, several of which are listed in Table 16-1. Most of these packages are freely available because creating an e-mail gateway is an easy task, especially on Linux. Once a script has all the form data collected from a Web page, it can be e-mailed using a single command, or a standard data pipe can be opened to send the data directly to the e-mail server for processing.

You can try writing your own simple e-mail gateway using Perl or a shell script as bash. Use one of best, the free downloadable packages listed in Table 16-1 as a code sample to guide you, if you prefer. I have tried to indicate in Table 16-1 whether the e-mail gateway is a generalized solution that requires very little effort on your part, or whether the package is a toolkit that you can use to customize a solution for your own forms or Web sites needs.
