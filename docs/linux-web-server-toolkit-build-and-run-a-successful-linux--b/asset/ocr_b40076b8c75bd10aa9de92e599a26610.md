# PRACTICING WITH HYPERTEXT LINKS

The following example shows you a couple of simple hypertext links using the <A> tag. The example as it would display in a browser is in Figure 9-9.

```
<P>
More information about Cairo is also available through the <A HREF= http://www.egyptian.org >Egyptian Tourist Board.</A>
<P>
```

![](bbox=[0.14, 0.542, 0.594, 0.683])

Figure 9-9: Links allow users to jump to any document on the Web. Using the A tag, you can indicate what text to highlight and where the link should jump to if selected.

You can also include graphics within links, so that the link appears as a graphic instead of text. Just place the <IMG> tag within the <A> tag. The border around the graphic will appear blue and the mouse cursor in the browser will change when placed over the graphic to indicate that it will link to a new document.
