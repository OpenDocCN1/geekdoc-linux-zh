I will explain a few of these settings. The third line defines how many incorrect logins are allowed before the FTP daemon rejects the connection. The sixth line defines which file is displayed automatically when a user logs in.

Lines 8 through 13 defines what different users are permitted to do. In this default file, anonymous users are not permitted to delete files, rename files, overwrite files, or change the permissions of a file. The 14th line defines that all users, both anonymous and real, are to have all transfers logged, (downloading) and outbound (uploading). These transfers are logged to the file /var/log/ftpaccess_log.

More information about FTP site administration is available in several specialized books, or by typing the command man ftppd or man ftpaccess.
