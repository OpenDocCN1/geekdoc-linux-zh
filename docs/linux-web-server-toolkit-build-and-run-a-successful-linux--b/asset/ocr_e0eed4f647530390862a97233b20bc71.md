# THE ADMINISTRATION PORT

After you press Enter, another screen appears where you select the port that will be used by the administration server to administer your FastTrack server, as follows.

Administration port [45676]:

This port can be any port over 1024. The configuration utility chooses a port automatically, which you can keep if you prefer by pressing Enter. But you have to remember the port, whatever it is. If you have several administration servers in your organization (this isn't technically necessary, but may be preferred politically), then you could have all administration servers use the same port to aid in overall system administration.

Press Enter to accept the default port chosen for you, or enter a different port that you've selected and press Enter.

You'll collect the administration server (and therefore do all the administration for your FastTrack Server) by entering a URL that includes the port you select. For example, if you choose the port 7070, and your standard Web server is reached by the:

```
http://www.tommy.com
```

Then your administration server would be reached by entering the following URL:

```
http://www.tommy.com:7070
```

Keep in mind that you can administer several FastTrack Servers running on several different computers all from the same administration server.

# NAMES AND PASSWORDS

Next, you select the user that the administration server will run as. That is, the administration server program will run with the permissions to access files and directories as if it run by the user you enter in the:

Run administration server as [root]:

Press Enter to accept the default in brackets, or enter another Linux username on your system.

Your FastTrack Web servers (called Public Services in the configuration utility) will usually run as nobody for security reasons, so that scripts on the Web server cannot inadvertently access areas that Web browsers shouldn't.

The administration server has many safeguards. You can have the administration server run as root if you like, so that you can completely control the FastTrack Server from the Web browser administration screens. All the configuration files created with this utility will be written to this user as their owner.
