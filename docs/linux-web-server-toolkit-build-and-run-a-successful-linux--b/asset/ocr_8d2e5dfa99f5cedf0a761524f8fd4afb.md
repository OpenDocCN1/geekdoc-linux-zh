# ## A Summary of Security Issues

The Internet is a very open and widely dispersed network that is administered by hundreds of individuals. That's what makes it so powerful, and that's why there's so much concern about sending data, such as a financial transaction, through the Internet. Understanding that fact can help you set your expectations correctly for what you can and cannot do with an Internet server.

Of course, you can use Internet technologies and all the Web server tools discussed in this book within a private network or intranet. An intranet is not subject to the same number of security dangers as a server connected to the Internet. But no system is completely secure because human intelligence and human error are always involved.
