# THE BROWSER WARS

The original graphical browser, Mosaic, understood a complete set of HTML tags. But as new browsers came on the commercial scene, particularly Netscape and Microsoft, they began to add their own list of tags to what their browsers understood. This allowed browser developers to make documents look nicer on their browser and have an advantage over the competition (for a week, anyway). The other companies quickly adopted the same tags so the documents using them would look good on their browsers, as well. The good result of this is that HTML has grown a lot in functionality and power. The bad result is a lot of browser incompatibility.

At the time this book was written, HTML 2.0 was the standard supported by all browsers, and the latest buzz about town is HTML 4.0, which includes numerous additions proposed by either Netscape or Microsoft. These Netscape or Microtags are widely used. You'll see buttons on Web pages indicating "Best viewed with Netscape 3.0" or something similar, which means these pages use HTML features that are only known to be supported in that version of Netscape's browser. The page might look strange on other browsers or other versions of Navigator because they cannot recognize the new HTML tag.

You must be aware of the tags you use according to the compatibility you want to achieve. There are many different browsers used on the Web, from the Lynx and Spybrowser character-based browsers on DOS and Linux (actually very common), to graphical browsers on Atari or Amiga computers, and to the latest versions of Net Navigator and Internet Explorer running on Windows 95.

If you want most of the online population to be able to read your Web pages, you have to restrict yourself to HTML 2.0 tags (again, at the time this book was written HTML 2.0 tags were the standard).

Conversely, you might not care that only the users with the latest browser can easily read what you provide. If you're using your Web server mainly for an intranet or a well-defined audience, you can judge what most users will have as their browser.

This isn't as stringent as it might sound. Most browsers ignore tags they don't recognize. If your pages are well designed, they can often include many features that are only supported in later browsers, but still look fine (and be easily read) in older or character-based browsers. The key is to view your pages using several browsers and several versions of each browser if you're concerned about compatibility with a wider audience.
