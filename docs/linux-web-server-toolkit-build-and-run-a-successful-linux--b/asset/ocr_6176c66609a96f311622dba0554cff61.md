# Chapter 11: Configuring the Apache Web Server

Another large task of its directives is determining how information returned to browsers is marked for its type. Each response to a browser request includes several lines of header information, just as you see in an e-mail message. These headers come with the browser request and tell the server about the browser, the user, and the information requested. They are also sent from the browser to describe the information that is being sent in response. These often relate to the MIME types described earlier (and more later on in this section).

# DOCUMENTROOT

The DocumentRoot directive gives the location of the documents that will be served out from your Web server, as follows:

```
DocumentRoot /home/httpd/html
```

If one requests a file in the "root" of the Web server (that is, without a path), such as the following:

```
http://www.travelbuddies.com/
```

The file will be taken from the directory /home/httpd/html on the Web server.
A in the DocumentRoot directory can be a symbolic link to a file located elsewhere on the Web server, and aliases can let documents in the DocumentRoot tree refer to other areas. But you should be careful about the security of your site if you use these to give a Web browser access to other areas. In particular, you can set a directive to disapp symbolic links.

# USERDIR

The UserDir directive defines the name of a subdirectory within a user's home directory that can be used to create personal Web pages, as follows:

```
UserDir public_html
```

Any user on your OpenLinux system can have a subdirectory named public_html (or whatever you set this directive to) and can serve Web pages using his or your username. The URL to do this would be, for example, as follows:

```
http://www.bigcorp.com/~nwells/myvacation
```

This URL would return to the browser the file /home/nwells/myvacation.html. Having this UserDir option allows users who do not have control over the Web server or the DocumentRoot area still serve documents using the Web server that is already running.
