The intention of SGML — and HTML in the beginning — was to mark up documents by content instead of by appearance. For example, instead of marking something "Bold" you would mark it as a "Title." The display application then determines how to display Titles, which may be on one system or underlined on another system, according to user preferences or system capabilities. This was a perfect system for a world, diverse Internet protocol.

But it didn't stick. The desire of Webmasters and users became ever stronger to have more control over the appearance of what browsers displayed and more features to make things look like. Thus, the original, pure HTML became polluted (yes, I am a purist at heart) with dozens of tags used to directly affect the appearance of the document the user sees on the browser screen. A tag is an instruction code within an HTML page, instead enclosed within angle brackets and looks something like this one, which defines the start of a table.

```
<TITLE>
```

You'll read a lot more about tags throughout this chapter.
You'll probably come to really appreciate those tags, however, because they can make your Web pages look great.

> The Web page is used all the time, but it isn't really an accurate term. An entire HTML file will be loaded in the browser, instead of its contents may be too long to display on a single screen. So, the user will scroll to the bottom of what is actually equivalent to 20 pages of text, but it's still considered one Web page because it is a single HTML file.

# Writing in HTML

HTML is a plaintext format. That means you can use any regular text editor on any computer to write an HTML page. If you use a word processor to write HTML pages, you need to save your file as ASCII Text or plaintext or similar thing. Web browsers don't understand WordPerfect or FrameMaker files, only plaintext.

Of course, more and more word processors have HTML modes that enable you to write a document and save it as HTML. These features usually convert the standard underlying word processor codes into HTML documents with tags that do the same things as the word processor codes. Basic rules of tags are discussed next.
