Figure 5-2 shows you how files can be scattered all over a hard disk. What a mess! The DEFRAG command moves all your files to the front of the hard disk and arranges the complete contents of each file in a single contiguous block on the hard disk, providing more efficient access. After optimizing your hard disk, the files are arranged like Figure 5-3.
