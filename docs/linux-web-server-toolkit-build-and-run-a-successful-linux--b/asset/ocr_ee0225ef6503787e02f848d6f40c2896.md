Remember all that you talk about Linux being multitasking? Once you are at a command prompt, you can use the features of the bash shell to manage multiple processes (programs) running at the same time.

When you enter a command at a shell prompt, the prompt doesn't normally present a prompt again until the command or program you entered finished execution or you press Ctrl+C to break the prompt.

But you can make a program run in the background as a separate task from the shell by adding an ampersand (&) after the program name. This frees the shell to start the program you requested, then immediately displays the command prompt again, waiting for other commands. This is best demonstrated on a graphical system where you can see windows opening up with programs while you continue to work in a command-line window.

For example, you can enter the following command:

```
$ xv &
$ 
```

You can immediately start entering other commands while the xv graphics prompt starts up.

If you forget to add the ampersand, the $ prompt does not return. The xv program is running in the foreground (visibly) within that command-line window. You can push it to the background by typing Ctrl+Z (the program pauses and the command-line prompt returns), and then entering bg to place the program in the background (the program is active, but you still have the command-line prompt to do work.

Another useful command is ps, which lists all the processes (programs) that you have started. If you use the -aux option as follows, all the processes on the system are listed, with statistics and the owner of each process:

```
$ ps -aux
```
