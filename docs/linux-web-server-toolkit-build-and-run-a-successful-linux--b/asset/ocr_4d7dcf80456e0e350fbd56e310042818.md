# Chapter 6: Installing Your Web Server Software

You will often see files on the Internet that end with .tar extensions. You can view the contents of these files with the following command:

```
tar tvf filename.tar
```

Or you can extract the tar file for use with the following command:

```
tar xvf filename.tar
```

The tar command doesn't automatically compress files, so you'll often see files with a .tgz extension, indicating a compressed tar file. You can uncompress them with the following command:

```
tar xvfz filename.tgz
```

Another package format within the Linux world is the Debian package format. Similar to the rpm format in some ways, it provides descriptive information, installation and deinstallation tools, and a variety of helpful options for developers. Apache should be running comfortably on your OpenLinux system at this point, ready to start serious configuration in Chapter 11. # Installing Netscape FastTrack Server

The Netscape FastTrack Server is not part of the OpenLinux Lite CD-ROM with this book, but because it is the most widely recognized commercial Web server for Linux, I will describe the basics you'll need to know about setting it up on your Linux system.

Netscape FastTrack Server is available from Caldera, Inc. You can also purchase a version of OpenLinux that includes the FastTrack Server fully configured and ready to use.
