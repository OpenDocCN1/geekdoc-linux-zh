
The character tags in this table can be used in combination. For example, if you want a piece of code rendered in bold courier font, you can use tags like this:

```
<P>
Enter the command <CODE><B>start</B></CODE> to begin using the graphical system.
<P>
```

# Using Headings

Different heading levels help your reader quickly scan the document for the part he or she considers most important. They provide a context for what you write and help you organize your Web pages.

HTML provides up to seven levels of headings. I recommend using no more than three. Using HTML headings is very simple. A capital H followed by the heading level. Enclose the title text in the opening and closing heading tags. For example:

```
<H1>Master Tax Guide</H1>
```

Depending on the arrangement of your documents, a certain Web page might not start with an H1. If reader are working through sections of a large document, it might make more sense to start a subsection that is a separate file with an H2 or H3 heading to give the reader a sense of proportion to the rest of the document.

As you start to use graphics in this chapter, you may not need to put any text in heading tags because you're using a banner-style graphic as the heading for your page instead.

In simple documents like the example follows, you should plan heading levels to indicate subordination of ideas, rather than a certain look onscreen. In this example, I've used simple <Hx> tags so that the browser controls the font style and size for each heading level. (Advanced HTML tags, which are not described here, allow you to control the font used for different headings.)

This example has several heading levels:

```
<HTML>
<HEAD>
<TITLE>Headings Test</TITLE>
</HEAD>
<BODY>
<H1>This is a Top Level Heading H1</H1>
This is a top level introduction.
<H2>Second Level H2</H2>
This is a second level introduction.
<H3>Third Level H3</H3>
This is a third level introduction.
<H4>Fourth Level H4</H4>
This is a fourth level introduction.
</BODY>
</HTML>
```

# Using Lists

Itemized lists categorize and organize information and are a common element of many documents you are presenting. HTML includes three list types:

- Ordered list: Numbers are automatically assigned to each item in the list.
- Bulleted list: This type of list consists of items that have no order.
- Definition list: consists of a term and paragraph (like a glossary entry).

# BULLETED LISTS

Bulleted lists are the most common type of list in an HTML document, and referred to as unordered lists because the items in the list are not associated with numbers (like steps). A bullet list starts with the <ul> tag (for Unordered List) and must end with a </ul> tag. Between the opening and closing tags, each item in the list should be enclosed in <li> tags (for List Item). The ending </li> tag is very often omitted without problems because the browser can easily tell what's happening when the next <li> tag appears or the list ends with a </ul> tag.

# A Word About Paragraph Tags

As you create lists, pay close attention to where you place paragraph <P> tags. Each browser has certain rules for spacing before list items and after lists (before the next paragraph or heading). Because list opening tags and list item tags include starting a new line, browsers also follow rules for how to treat paragraph tags when they occur right before or after a list. You may want paragraph tags to make extra spaces or highlight parts of your lists. But if you're sloppy about where you include paragraph tags in your lists, your lists will look funny and have inconsistent spaces, especially across different browsers.

Here's an example of a simple unordered list. Figure 9-4 shows how the bulleted list would be displayed in a browser.

Visit the following cities online:

```
<ul>
<li>Caracas</li>
<li>Maracaibo</li>
<li>Buenos Aires</li>
<li>Lima</li>
<li>Montevideo</li>
</ul>
```

Figure 9-4: A simple bulleted list using the <ul> tag with list items <li>.

# ORDERED LISTS

Ordered lists are numbered lists. They're created the same way as unordered lists, using the <OL> tag instead of the <ul> tag. The list items are marked the same way, using the <li> tag. The browser assigns numbers to the list as it's being viewed.

Here's an example of a simple ordered list, with a browser showing how it would be displayed in Figure 9-5.

To order a replacement card, follow these steps:

```
<OL>
<li>Get a copy of your birth certificate</li>
<li>Have two passport-sized pictures taken</li>
<li>Write a brief letter explaining the card was lost</li>
<li>Send all materials to your standard address</li>
</OL>
```

# DEFINITION LISTS

Definition lists are not used as commonly as bulleted lists and numbered lists. They're intended for things like glossary entries, where you have a short item followed by a description or definition. Definition lists don't include a character, such as a bullet, before the text. They only define the indentation and may be the font style (depending on the browser).

To create a definition list, start with the <DL> tag and end with the </DL> tag. Within the <DL> tag pair, your list items consist of pairs of Definition Terms using the <DT> tag and Definition Descriptions using the <DD> tag. You can use multiple <DT> tags before a <DD> tag, or multiple <DD> tags before another <DT> tag. The two tags just determine the indentation and font used for the text that follows. Figure 9-6 shows a sample definition list for the HTML code below.

```
<DL>
<DT>Cairo</DT>
<DD>Visit the pyramids. Memphis, the old city, cruise the Nile, and enjoy the national museum.</DD>
<DT>Luxor</DT>
<DD>Visit the Temple of Karnak and the Valley of the Kings. Take an expedition tour to a desert oasis.</DD>
</DL>
```
