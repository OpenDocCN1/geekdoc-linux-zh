## Completing Basic Administration Tasks

Configuring and administering every complex aspects of the FastTrack server is easy from the browser-based interface described in this chapter. If you read any of Chapter 11 about configuring the Apache Web server that's included with the CD-ROM in this book, you'll quickly see that the concepts are the same for both servers. It's just a lot easier to use a browser than it is to edit configuration files.

When you select the link for a specific Web server from the Server Selector page (shown in Figure 12-2), the Administration page appears, as shown in Figure 12-4. This is your main control center for completing all configuration and administration of your FastTrack Server.

Notice the first row of buttons across the top of Figure 12-4: System Settings, Access Control, Encryption, Programs, Server Status, Config Styles, and Content Management. These are the areas of configuration and administration. System Settings opens automatically when you first choose a Server to manage, as shown in Figure 12-4.

Next, notice the column of options down the left side of the page in Figure 12-4: On/Off, View Server Settings, Restore Configuration, and so forth. These are links to the System Settings options that you can configure. When you select one of these links, the right side of the page will change, showing you a new set of information that you can review or alter.

If you select a different category from the buttons on the top of the page, the options on the left side change to reflect that category.

Finally, the two buttons above the top row of buttons (one to the right, and one to the left). The button on the left, which reads, Choose, takes you back to the Server Selector page (shown in Figure 12-2) where you choose which FastTrack Server you want to administer. The button on the right side labeled Apply applies the changes you have made while you were in that particular page. Clicking the Apply button after you make it changes it.

### Configuring the System Settings
As I mentioned previously, the first set of options presented after you select a server are the System Settings (12-4).

### On/Off
The On/Off page is used simply to turn the server on or off. Turning a server off doesn't affect any of the configuration information you've set; it only means that the server is not currently running, no requests can be processed.

### View Server Settings
The View Server Settings page lists all the current settings for this server, including the server root directory, the port (default), the number of threads and processes, and information about the content settings.

Each of the items listed includes a link to the page where that item can be changed. The View Server Settings page enables you to view all the settings. They are altered according to the different areas they fit in.

The View Server Settings page is shown in Figure 12-5. This is the first time you've seen a division between "Technical" and "Content" sections.

The top section of the View Server Settings page is indicated as Technical Settings, with the magnus.conf mentioned. The bottom section is indicated as Content Settings, with the filename obj.conf mentioned. Note that the configuration information is divided into these two categories, and those two files contain the settings you're viewing in. In rare cases, you may want to view these configuration files directly.

### Restore Configuration
The FastTrack Server stores previous configuration information whenever you make a change. The default is to save the previous configurations, but you can easily change that number up or down.

The Restore Configuration page displays a list of the previous configurations, with a date and time stamp next to each. You can choose the View button next to that date and time in order to view the settings for that configuration. Or, you can choose the Restore button next to a previous setting in order to revert to the settings in effect at that date and time. Just remember to press the Apply button in the top right corner to make the latest (restored) configuration active on your server.
