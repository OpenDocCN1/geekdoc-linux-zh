# Providing Variety

Users like a Web site that doesn't look like every other site on the Web. That becomes a real challenge for those of us who aren't artistically inclined, providing a variety of information keeps your site interesting and fun to browse.
Changing the look or graphics on your site, as well as keeping information updated, provides variety that users will appreciate.
