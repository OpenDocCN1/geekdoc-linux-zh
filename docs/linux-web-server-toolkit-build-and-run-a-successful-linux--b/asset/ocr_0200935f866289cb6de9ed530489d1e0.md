# Chapter 13: Maintaining Statistical Data for Your Site

For example,

getstats -c

produces a concise report of about 15 lines, listing only the number of requests and errors, plus a few other details. On the other hand, a monthly report

getstats -m

generates a graph-type list of how many requests were serviced in each month included in the log file. Several other options are available as well, as shown in Figure 13-1. You can get a copy of getstats from http://www.eit.com/software/getstats/getstats.html.

Figure 13-1: The getstats program uses simple line options to prepare a variety of simple reports summarizing Web server usage.

Wstats is probably the most used free statistics program on the Web. It creates a comprehensive file containing a summary of how much data was transferred, which hosts requested data, and many other facets of your Web site activity.
