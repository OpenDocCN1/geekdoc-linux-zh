# Introduction to the Apache API

The Apache server's API is a very generalized interface to the server. In fact, most of the functions described in Chapter 11 are implemented as modules to the core server. This includes all the URL management (aliases, user directories, and so forth), user authentication and password files, and access control functions that check whether a host is allowed to access the requested file. Other examples include all log management (which is totally configurable if you load in the optional log file module) and server side modules.

Some Apache modules are specifically written as "handlers" that deal with a particular type of data on the Web server. For example, one module might handle processing for all requests for JPEG graphics. Because of this design, you can easily add your own module to handle a new data type, or to replace a handler for an existing data type. For example, you can add a data type that utilizes a different method for automatically compressing files based on the headers sent by the client browser. Or, if one of your pages uses a part of the standard functionality of Apache, as the image map functions, you can recompile Apache without that module to save space in memory for each running copy of the server.

17-1 lists several modules and their functions.

| Module | Purpose |
| --- | --- |
| mod_log_config | Provides totally configurable logging, based on any header information submitted by the client browser. (This functionality is briefly described in Chapter 11.) |
| mod_cookie | Allows for cookie maintenance. (Cookies are a session in HTTP that maintain state information between browser sessions.) In later versions of Apache, this module is replaced by mod_usrack, which provides additional functionality. |
| mod_auth_msql | Authentication to an MSQL database. The code for this database tool can be used as a prototype for many different database applications on your Apache Web server. |
| mod_auth_anon | This module provides for Anonymous user authentication, like an FTP server, so that users are logged in but don't have to know a certain username and password. |
| mod_cern_meta | Provides support for HTTP header metafiles, based on the standard from CERN. |
