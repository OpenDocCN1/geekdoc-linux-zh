> Using non-standard logfile formats can prevent some Web statistics from functioning correctly if they expect only the Common Logfile Format. Be certain to check the box in the Log Preferences page to include the format string in the log file. This string will tell more advanced statistics programs how the data in each log entry is organized.

The Log Preferences page gives you a variety of options for how your Web site records the number of times it is accessed, also known as the number of hits. The top part of the Log Preferences page is shown in Figure 12-14.
