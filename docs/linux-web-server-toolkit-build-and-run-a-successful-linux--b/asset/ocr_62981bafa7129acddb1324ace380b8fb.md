Creating dozens of nice HTML pages is a lot of work. If you have simple design requirements and a small budget, you can create them yourself or find an HTML coder in your organization.

Larger projects or more demanding requirements (such as choosing a site's specific "feel," as described previously) may make you lean towards using a professional designer or agency to create your Web pages. The ironic about these professionals, as I mentioned, is that they are just designers who have learned HTML. Schools have now started to offer HTML courses, but you won't find anyone with a degree in HTML page design. Overall, the technology is too simple to require it; creativity is the key. So I recommend using a professional designer in many cases, look carefully at the work the person or agency has done to see if he or she has completed a project that shows or her skill in Web page—and even Web design.

The Web pages I've been speaking of here are mostly the home page and the main navigation pages that link off the home page. These might include things like the press releases and the products page. Apart from those critical Web pages, you will have hundreds, if not thousands, of pages of existing material (from the list earlier) that must be converted from their current format into HTML for presentation on the Web site. This is the actual content that you want to provide. It should, of course, match the "look" of the main Web pages but can emphasize the content instead of the design elements that define your site.

Conversion tools exist for almost all common file formats. Free filters are available on the Web for many formats. Word processors can now save files in HTML format. As you consider what information you will have on your Web site, consider also who will provide the existing original files, what they are in, and who will prepare them in HTML format.
