# Selling Products or Services

Although a Web site shouldn't be just a sales tool (See the sections later in this chapter on what not to do), more customers are looking at the Internet as an option for buying goods. Accordingly, more Web sites are offering a method of purchasing products or services straight from the Web site. For customers who are comfortable doing this, Web-based transactions are simple and convenient. If you have something to sell, consider making it available directly from your site. I'll discuss this in later chapters.

Initial concerns about secure transactions over the Internet have largely been eliminated by the introduction of several completely secure methods of exchanging credit card numbers or other sensitive information over the Internet. Linux is a leader in this area, with many secure Web servers that use encryption technologies for browser requests. One of the most popular of these is the Netscape FastTrack, described in Chapter 12.
