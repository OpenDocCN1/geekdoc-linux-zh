# Chapter 9: Creating HTML Pages

Lists are used in most Web pages, but graphics and links are what make the Web so interesting. In the next section I'll show you how to add these types of tags to your documents.

# Using Graphics and Links

Lists are nice, but to really make your Web pages shine, you need to add graphics and links. Images add visual appeal, while links make the hypertext in HTML reality, allowing you to mark any point in your document as a jumping off place to any other document on your Web server or some other Web server. This section explains how to add basic graphics and links to your documents.

# Adding Graphics

Graphics can be any size and can be created with any program, as long as they end up as GIF format bitmapped graphics when you use them in your Web pages. Numerous other graphics formats are supported by different browsers, especially JPEG graphics. For embedding in your Web pages, you always need to use GIF images.

A forthcoming format for Graphics is Portable Network Graphics (PNG). PNG is a compressed graphics format that is intended as a replacement for GIF (which is a patented format) and in some cases for JPEG. Some browsers (such as Arena and Amaya) already support PNG, and in other browsers should be coming in 1998. For more information on PNG, see http://www.w3.org/Graphics/PNG.

GIF has several advantages that made it the choice for the Web. It has a selected number of colors to be stored, making files smaller and reducing the need for colors on the Browser. It is compressed by default, so it takes less time to download. GIF also has several standard features that are used in Web pages, the primary one being the capability to define a transparent color for an interesting visual effect.

Two GIF formats are available: gif87 and gif89. If you create your images with a program that supports gif89, you can select one of the colors in your graphic as the transparent color. When a Web browser loads a graphic, the transparent-color blends into the background, creating an eye-catching contrast to the image's solid colors.

Another great feature of the GIF format is that it saves the files so that they are interlaced in sets of scan lines instead of just being saved to top bottom. When a browser loads this type of graphics file, you see on screen every tenth line or so, followed by the second, eleventh, and so forth. This lets you see what the entire graphic will look like before it's completely translated.
