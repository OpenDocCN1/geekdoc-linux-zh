
# Chapter 4: Internet and UNIX Technologies

## Protocols

You're about to start hearing the word protocol a lot. Whether it's used by humans in the diplomatic corps or by computers, a protocol is just a pattern of communication. A protocol for a computer defines what one computer should "say" to elicit a particular action or response from a computer that is listening.

For example, the specification for the Web protocol, HTTP, says something like this: "GET filename" and the Web server should respond by sending the file requested by the client.

The protocols get a little harder to understand at the lower levels (defining data packets for Ethernet, for example), but the principle is identical. So each time you read about another protocol, just think of it as another set of rules to facilitate a particular type of communication.

## The Internet Protocol

Let's back up a little and talk about how the computers on the Internet communicate with each other. The quick answer is: via the Internet Protocol. But as that doesn't tell you much, I'll go further. The Internet Protocol (IP) was created as part of the original plans for the Internet. It is therefore the standard networking protocol for all UNIX systems, including Linux systems. No matter what type of wire connects you to the Internet - Ethernet, telephone lines, microwave, or others — the communication is done via IP.

Networking using IP requires each computer on the network to have a unique identifying number called an IP address. These IP addresses are in the form of four numbers separated by periods (called dotted quad notation). So, for example, the following is an example of an IP address:

207.49.12.1

IP addresses come from the Network Information Center (NIC, or InterNIC), administered by Network Solutions ((703) 742-4777, or visit http://internic.net), but most computers get their IP addresses from their Internet Service Provider (ISP). ISPs who expect to grow any size to the InterNIC for a block of IP addresses. They then administer these addresses, doing them out to customers who connect through their site, as well as using them internally.

Different sites have different needs for IP addresses. A major research university may need thousands of IP addresses and also need to administer them all. You, on the other hand, may need more than ten for your organization and may need only one for now.

IP addresses are divided into classes for purposes of passing out and administering them. You can identify the class of an IP address by looking at its first number. Table 4-1 shows the different classes of IP addresses, their number ranges, the number of network nodes available, and assignment rules for each.

## TABLE 4-1 Classes of IP Addresses

| Class of IP Address | Range of the First Number of the Address | Number of Network Nodes Available | Assignment Rules |
| --- | --- | --- | --- |
| A | 0-127 | hundreds of thousands | The first number is assigned; you assign the last three numbers to computers on your network. |
| B | 128-191 | tens of thousands | The first two numbers are assigned; you assign the last two numbers to computers on your network. |
| C | 192-223 | 256 | The first three numbers are assigned; you assign the last 253 numbers to computers on your network. |

This table tells you how to determine what class of address you're looking at. For example, the address 207.34.12.1 is a Class C address because the first number, 207, is in the range for C addresses. You are assigned certain numbers in an address, and choose other ones. So for example, when you receive a Class A address, you're assigned only the first number. You decide the last three numbers for every computer on your network. If you receive a Class C address, you're assigned the first three numbers (207.34.12 in the last example), and you assign the last number, with a range of 0 to 255, to various computers within your network.

It's interesting to note that because of the popularity explosion of the Web, the Class A addresses are long gone; places like MIT, it's pretty hard to get a full Class C address. In fact, the Internet is running out of IP addresses. A new standard called IPv6, which provides plenty of space for the foreseeable future, is now in testing and will soon be available generally. Linux is one of the top testing platforms, and will likely be the most advanced platform for IPv6.

The Internet Protocol (IP) is the base that all Internet communication is built on. In the next section, you'll learn about some other protocols that are built on top of IP and communicate at a higher level.
