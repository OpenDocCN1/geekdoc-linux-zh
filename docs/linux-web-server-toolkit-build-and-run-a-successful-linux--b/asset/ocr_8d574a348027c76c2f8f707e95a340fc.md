# Chapter 10: Basic Scripting and Forms

A set of radio button <INPUT> tags all have the same NAME, with different VALUE
options that specify what value should be returned if that radio button is selected.
As with the other form tags, you must supply the text that describes each
radio button is for. You can use the CHECKED option to select one of the radio-
tons as the default.
The following example creates a set of radio buttons; the corresponding browser
display is shown in Figure 10-6:

<P>
Select one of the following options for shipment:<P>
<INPUT TYPE=RADIO NAME=SHITYPE VALUE=UPS_GROUND CHECKED>
United Parcel Service, Ground (4-7 days)<P>
<INPUT TYPE=RADIO NAME=SHITYPE VALUE=UPS_2DAY > United Parcel
Service, Blue Label 2nd Day (2 days)<P>
<INPUT TYPE=RADIO NAME=SHITYPE VALUE=FEDEX > Federal Express
(next day)<P>

Figure 10-6: A set of radio buttons allows a user to select one item
from several choices.

In the example just shown, if the first radio button was selected – as it is by
default using the CHECKED option – the browser would return the name-value pair
of SHITYPE=UPS_GROUND. If the last radio button was selected, the name-value
pair would be SHITYPE=FEDEX.
