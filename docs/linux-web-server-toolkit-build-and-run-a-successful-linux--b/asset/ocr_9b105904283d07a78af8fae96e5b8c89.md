# Linux Web Server Toolkit

Linux continues to maintain the Linux kernel, with contributions coming in from people over the world who have expertise and interest in contributing their time and effort to a project that gives them a little notoriety, a lot of goodwill, and good software. Linux Torvalds graduated and moved to Northern California in 1996, but the Linux project continues under his leadership.

In the time since Linux first asked for suggestions on his kernel experiments, Linux has developed into all-featured an operating system as anything available in the computer industry. Experts in networking, graphics, device drivers, virtual memory, and multiprocessing–just to make a few components of Linux–all have contributed to making Linux powerful and complete system.

Why did Linux succeed well in such a short time? For two reasons. The first is the Internet environment in which it was created. This worldwide infrastructure allowed people to work together across continents and time zones. It allowed people of diverse backgrounds to contribute their unique talents without constraints of time and place that a standard development team would face. In addition, the goal of the contributors always seemed to be create the best software. If you read the e-mail and newsgroup traffic of the development teams, you'll notice great professionalism and very little ego.

# Web Server Requirements

As everyone scrambles to get on the Web, organizations and individuals seem to be running Web servers on any system at hand. While any Web server may be better than no Web server, the following is a list of requirements for a Web server platform:

+   * Multitasking: This an operating system to handle multiple Web client requests at the same time and to process scripts at the same time as it prepares Web Pages. This requirement excludes Windows 3.1 from the running.

+   * Support for popular Web scripting languages: Thousands of standard scripts are available for languages as Perl and Tcl. Operating systems that don't really support these languages are at a real disadvantage.

+   * High performance: Busy Web servers place a heavy load on an operating system. Tasks such as running scripts, sending Web pages over the network, and accessing many files simultaneously tax all parts of a system. This requirement places Windows 95 and most Macintosh systems on the blacklist for Web servers.

+   * Adequate software tools: Web server platforms should have Java, secure servers, and HTML tools.
