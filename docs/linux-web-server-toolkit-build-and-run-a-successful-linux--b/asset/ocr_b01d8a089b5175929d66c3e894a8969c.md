# Linux Web Server Toolkit

In the early stages of the Internet, all the computers connected to it were large UNIX systems running university computer centers, government installations, and corporate data processing centers.

UNIX was ideal for a networked connection because it was designed for its beginnings. UNIX is multiuser, so remote users with network connections could be logged in at the same time. That also meant UNIX had to have a set of security standards to allow users to keep their information private (that security is a bit less now than it was back then). Because of the environment in which it was developed, strong networking systems were important for UNIX from the beginning. Connecting to the Internet just meant connecting to an extra wire; the networking was already part of the operating system design.

So how does Linux fit into this picture? The standards that drive the Internet all, except for Java, come from UNIX. Because Linux was designed as a UNIX clone, Linux also included the same Internet standards from the beginning.

# # How Alternate Operating Systems Measure Up to UNIX

The features discussed above are in sharp contrast to other operating systems. DOS machines were first built to be inexpensive, small enough to fit in available RAM. Thus DOS had no multiuser or multitasking capabilities, no security features — turn it into on and start working — and no networking features, because it was always intended to be used as a standalone system. In fact, Microsoft DOS (the most-used version) still doesn't have any of those features, although the DOS 7 underneath Windows 95 has the beginnings of some of them.

All of the networking capabilities of DOS and Windows were added after the operating systems were completed. This means that DOS and Windows networking don't include support for all UNIX and Internet standards. Even with add-on packages, parts of DOS and Windows actually interfere with complete integration into the Internet. For example, the multitasking of UNIX networking through the use of ports and streams can't really be duplicated in DOS or Windows.

Here's the really interesting part: DOS, Windows, Windows NT, Macintosh, Amiga, Atari, and all the others connect to the Internet by adding UNIX functionality to their existing operating systems. So now aren're glad you're using Linux? Linux provides a real UNIX-like operating system, and its power wasn't just an afterthought.
