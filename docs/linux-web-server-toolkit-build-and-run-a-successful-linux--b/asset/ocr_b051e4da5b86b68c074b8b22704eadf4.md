# The Variety of Linux Distributions

Considering that all Linux distributions are basically packaged Internet downloads consisting of a kernel and some utilities, you wonder why ten different Linux systems exist. The differences between distribution types are really not that big, but because we're talking about your operating system, they have far-reaching effects.

The UNIX operating system became fragmented over time because different companies licensed it and creating different versions. That meant an application that ran on an SGI UNIX machine would not run on an IBM RS/6000 machine. These machines were based on different microprocessor chips, but even UNIX systems running on Intel-based PCs have separate versions: one for SCO UNIX, one for Solaris, and so forth—despite the fact that the applications are probably 98 percent identical and in many cases can be recompiled from one system to the other in a matter of days.

Unfortunately, the same sort of thing is starting to happen in the Linux world. Different distribution makers have arranged things in the way they think best. But applications that work on one Linux system may not work perfectly on another Linux system. The problem is not so serious because most applications that Linux currently run source code. So if the application doesn't run, check the options file, recompile the application, move the libraries, and it will usually run.

Other, commercial Linux distributions do not have that luxury. The result is that commercial software companies must do one of the following:

+   * Support an undetermined number of Linux versions with unknown differences (because the user has unlimited ability to alter the system)
* Develop for a single, specific version of Linux.

Most software developers who want to enter the Linux market seem to be taking the second route. As a result, you see AppWare for Red Hat Linux or AppGen for OpenLinux. These applications may run on other Linux systems, but they are developed with a single Linux as a reference platform, and that is usually the only platform on which they are supported by the manufacter.

# The Basic Differences Between Distributions

The differences between Linux distributions are most noticeable in the areas:

+   * Installation
* Filesystem standard
* Initialization scripts
* Included software packages
* Philosophy
