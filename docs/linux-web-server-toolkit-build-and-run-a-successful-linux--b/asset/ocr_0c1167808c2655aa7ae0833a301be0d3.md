# TABLE 11-2 Possible Parameters for the AllowOverride Directive Within a Directory Container

Parameter | Description

AuthConfig | Allows local access files to include per-user authentication data (as described in the section on advanced features).

FileInfo | Allows local access files to add or change file description information using MIME-related directives such as AddType and AddEncoding.

# Using the Order Directive

The order directive gives you a lot of flexibility in determining site security, especially because you can use it in local access control files (.htaccess is the default, as described previously). This means you can set specific access for a particular subdirectory within your document tree.

The allow and deny directives (allow is only used in the default setting) let you determine exactly who can access your document tree or a subdirectory of it. Both allow and deny can use the word "all" or an IP address or a domain name. For example, if you wanted to restrict access to only your own domain name, you could use the following lines:

```
order deny, allow
deny from all
allow from *.fishing.com
```

Or, if you've had a problem with students from a local university trying to hack into your system, you can use the following lines to let everyone but them access your documents:

```
order allow,deny
allow from all
deny from *.michigan.
```
