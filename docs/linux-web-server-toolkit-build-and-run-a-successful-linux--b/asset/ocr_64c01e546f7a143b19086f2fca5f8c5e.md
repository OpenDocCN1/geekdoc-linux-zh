# Chapter 5: Installing Linux

First, list the partitions on the hard disk by entering the p command. A list of partitions is shown like the one below. Each partition has a size and filesystem type. One partition will be marked as active. In the following example, most of the hard disk has been cleared for free space for Linux, so only one partition is listed.

```
Command (m for help): p
Disk /dev/hda: 64 heads, 63 sectors, 786 cylinders
Units = cylinders of 4032 * 512 bytes
```

```
Device      Boot  Begin  Start  End   Blocks Id    System
/dev/hda1   *     1       1      152   306400+6    DOS 16-bit
```

```
Command (m for help):
```

Now enter the n command to create a new partition. This will be a primary partition, enter p next.
Enterter the partition number. Choose the number after the last one listed from the p command. So, if there is one partition already, make this new partition number 2.
Enter starting cylinder of the hard disk (use the first number suggested in parentheses). It's a good idea to start with the swap partition, the smaller of the two you create.

```
Command (m for help): n
Command action
  extended
  p primary partition (1-4)
p
Partition number (1-4): 2
First cylinder (153-786): 153
```

For the swap partition, the easiest way to enter the size of the partition is to type the size in megabytes. So, to make a 32MB swap partition, you would enter +32MB:

Last cylinder +size or +sizeM +sizeK ([153]-786): +32M

```
Command (m for help):
```

The last thing is to change the new partition to the right type. Enter the t command, followed by the partition number (2 in this example), followed by 82, the type identifier for the Linux swap partition.

```
Command (m for help): t
Partition number (1-4): 2
Hex code (type L to list codes): 82
```
