Next, start the Administration server by opening your browser and entering the URL to reach the Administration server. Remember that instead of the standard HTTP port of 80, you selected a different port for the Administration server to use. If you can't remember what it was, check the configuration files in /opt/fasttrack. The URL that you use will look something like this (in this example, 5050 is the administration port selected during configuration):

```
http://localhost:5050
```

Once you've entered this URL in your browser, the HTML page shown in Figure 12-1 appears. This is where you enter a valid username and password before you can start to configure your FastTrack server. The username and password are those you entered during the configuration of the Administration server. The username is normally admin.

After you enter a username and password, you see the first configuration page, the Server Selector page shown in Figure 12-2. This page lists all the FastTrack servers that you can administer and configure from this browser.

![](bbox=[0.181, 0.463, 0.258, 0.555])

> You can only administer a FastTrack server if your browser is running on a system that is listed as a valid location (with both IP address and domain name) in the Administration Server configuration file. This prevents someone from learning your username and password and changing your FastTrack server from across the Internet.

Note in Figure 12-2 the FastTrack server listed includes an On/Off switch on the left side. This switch provides a simple way for you to shut down or start your FastTrack servers.

Additional servers can be added from the Administration Page within the browser, once you have it running for a single server. If you have several FastTrack servers running on your network, you can easily administer and configure any of them using the same interface, by simply selecting one of the servers listed on the page.

In addition to being able to select a server to administer from the page shown in Figure 12-2, you can also complete a couple of other tasks using the buttons at the bottom of this first Server Selector page.

The first button, which installs a New Netscape FastTrack Server, lets you enter the basic information like a hostname and port number that allows you to run another FastTrack Server on the same computer. A servername entered here will be listed on the Server Selector page as an administerable server.
