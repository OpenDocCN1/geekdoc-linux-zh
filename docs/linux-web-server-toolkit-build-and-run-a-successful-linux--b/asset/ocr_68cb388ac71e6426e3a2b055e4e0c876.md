# Linux Web Server Toolkit

# DIRECTORYINDEX

Whenever a browser requests a URL that ends in a path, the Web server will search for the filenames given in the DirectoryIndex directive (separate multiple filenames with spaces) as follows:

```
DirectoryIndex index.html
```

If none of the files listed as values of the DirectoryIndex directive is found, the Web server creates a directory listing of the subdirectory according to the other rules in the srm.conf file.

# FANCYINDEXING

The FancyIndexing directive indicates that you want the Web server to create a "fancy" listing of files if an index.html file is not present, as follows:

```
FancyIndexing on
```

+   A fancy listing includes icons for different file types and descriptions of the file. The alternative, FancyIndexing off, returns a plain list of files.

+   Many of the directives listed for this file apply to directory listings created when FancyIndexing is turned on (the default).

# ADDICON DIRECTIVES

The following is an abbreviated list of the Addicon directives in the srm.conf file:

```
AddiconByEncoding (CMP,/icons/compressed.gif) x-compress x-gzip
AddiconByType (TXT,/icons/text.gif) text*/
AddiconByTypeImage (IMG,/icons/image2.gif) image*/
Addicon/binary.gif .bin exe
Addicon/world2.gif .wrl .wr1 .vrm .iv
Addicon/compressed.gif .Z .tgz .gz .zip
Addicon/text.gif .txt
```

The Addicon directives define what to use when creating a fancy index list. Each AddiconByEncoding directive gives an encoding style as the last parameter (x-compress, for example) and the filename for an icon to be displayed with that filename. AddiconByType gives a MIME type as the last parameter, with the filename for an icon to be used to display files of that type. Finally, each Addicon defines file extensions that should use a particular icon for their display. Note that many file extensions can be included in each line for the named graphic.

Many Addicon lines are included in the default file. You shouldn't need to add more unless you become aware of a new format that you are storing on your system and want to identify using a particular icon.
