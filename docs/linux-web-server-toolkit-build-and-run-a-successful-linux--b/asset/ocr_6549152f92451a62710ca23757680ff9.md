# DEFAULTTYPE

The DefaultType directive defines the MIME type for documents that are not defined by any other type of information, as follows:

```
DefaultType text/plain
```

The DefaultType directive will usually apply to documents that have no file extension or a file extension that isn't listed in the mime.types file.

# Using Content Negotiation

Many late-model browsers such as Netscape Navigator are able to exchange information with the Apache server to determine a best match between what the server can do and what the browser can handle. Several directives in srm.conf define what the server can do.

# ADDENCODING

The AddEncoding directive defines methods of preparing data to send to a browser. Multiple methods can be enabled on your Web server. In the following two examples of the AddEncoding directive, the Apache Web server is instructed to use either of two compression techniques for any browser that declares it can handle compression type:

```
AddEncoding x-compress Z
AddEncoding x-gzip gz
```

By using these AddEncoding directives, documents can be compressed on the fly to send over the Internet. The browser then decompresses the file before displaying it.
Encoding files, particularly for compression, is a handy feature, and as more browsers will have the ability to decompress files, and compression will greatly reduce transmission times. But if your Web server is overloaded, do not use AddEncoding directives for a while. Trying to compress documents on the fly during the processing of a browser's request adds a burden on your CPU.
