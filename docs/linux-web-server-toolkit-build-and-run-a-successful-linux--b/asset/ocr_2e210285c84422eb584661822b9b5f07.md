# Chapter 19: Maintaining Your Web Pages

| Type of Analysis | Sample Questions |

Messages/Positioning

Does the information on this page fit our overall goals and
messages as an organization?

Does the information on this page contradict anything we've
said said publicly (especially if it's on another page on our site)?

Have the necessary people (management) approved the
content/messages of this page?

HTML

Have all cross-browser considerations been resolved?

Does this page contain HTML coding errors that will cause some
elements to display incorrectly in major browsers?

Will this page support text-only browsers?

Are META tags adopted by our organization as standards used
sistently?

Has the page passed an automated HTML check?

Legal

Do we have legal rights to any images or graphic elements?

Have any trademarks or other legal issues (quotes, etc.) been
mentioned/linked/to/approved?

Links (After posting
to the site)

Have all links on this page been checked to see that they are:

+   * Valid (correct HTML code)

+   * Correct (we refer to the page we expect to refer to)

+   * Active (actually display the page when selected; especially
important to check when linking to Web sites other than
your)

+   * Worded consistently across pages

sible parties for each of the checks listed in Table 19-1 and being very specific
 defining the tasks each person or persons are responsible for. You should also
make sure to organize the flow of pages from creation to posting and beyond.
