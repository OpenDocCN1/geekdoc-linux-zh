Log files never stop growing. If you have a busy Web server, you can add thousands of lines per day to your access log file. The file has to be archived for two reasons:

+   - To keep it from getting so big that it causes problems with your system (like running out of hard disk space or slowing performance of your Web server while adding entries to log files)

+   - To allow you to review long-term trends in your Web server usage

Because the Web server is continually writing to the log, you don't want to lose data during your archiving process. The logrotate command described in Chapter 11 can archive and review your access log. I recommend that you regularly archive your access log, preferably at the same time every night, every weekend, or the first of every month, depending on how busy your site is. This allows you to run the statistical programs on each file to prepare data on each day. You can then use consecutive sets of files to track long-term growth trends.

# Making Statistics Available on Your Site

It used to be popular to have a link on your Web site to a statistics page, where you posted the most recent statistics file generated for your site. The file was generated every night or every weekend, and showed your visitors how busy your site was and where people were coming from.

For several reasons, this doesn't do as much anymore primarily because of the information that it provides about your site. With more businesses coming to the Web, the need to protect "trade secrets" is so much greater, openness over numbers of visitors, location of visitors, and so forth isn't something you readily share. After all, if you post the statistics file generated by wwwstat or a similar program, anyone on the Web can download it and answer many of the same questions listed in this chapter that you can answer.

On the other hand, if you're part of an organization that's not really "in business", it can be fine to include a link on your home page that shows the traffic your site is generating and lists the hostnames or geographic locations of your visitors. You can even post a reduced version of the statistics files or just a graph to show how widely appreciated your efforts are.

Many people now include odometer-like counters on their home page. This is a graphical counter that shows the number of visitors to the page: In some cases these are for visitors to see, but I wouldn't spend a lot of time installing or maintaining this.
