# Chapter 9: Creating HTML Pages

# A Word About Paragraph Tags

As you create lists, pay close attention to where you place paragraph <P> tags. Each browser has certain rules for spacing before list items, and after lists (before the next paragraph or heading). Because list opening tags and list item tags include starting a new line, browsers also follow rules for how to treat paragraph tags when they occur right before or after a list tag. You may want paragraph tags to make extra spaces or highlight parts of your lists. But if you're sloppy about where you include paragraph tags in your lists, your lists will look funny and have inconsistent spaces, especially across different browsers.

Here's an example of a simple unordered list. Figure 9-4 shows how the bulleted list would be displayed in a browser.

Visit the following cities online:

+   <ul>
<li>Caracas
<li>Maracaibo
<li>Buenos Aires
<li>Lima
<li>Montevideo
</ul>

# ORDERED LISTS

Ordered lists are numbered lists. They're created the same way as unordered lists, using the <OL> tag instead of the <<ul>> tag. The list items are marked the same way, using the <<li>> tag. The browser assigns numbers to the list as it's being viewed.
