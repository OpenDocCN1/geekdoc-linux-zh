# Brute Force Attacks

Any password can, with time, be discovered by a computer. Computers are ideal for this repetitive task. You can make this easy task for hackers if you choose passwords poorly. A program created to determine passwords can try every word in a dictionary to see which gains access. Even many passwords, such as those formed by substituting a 5 for an "s" or a zero for an "o" by inserting a period or other punctuation mark in the middle of a word, can be checked by a good "crack" program. Choosing a good password becomes a challenge. Combinations of family names, fictional names, product names, with punctuation and mixed case.

As you know now, your Linux system has a user root, but the root user is often not allowed to log in remotely because of the risk it poses to security. Therefore, a hacker may try to find out another account to break into. Once the attacker accesses your system using any username, he can obtain the password file containing the list of all usernames and the encrypted passwords and that file to prepare other attacks. Your Web server can actually act as an accomplice in a brute force attack by sending a copy of the password file (/etc/passwd) to an intruder who is able to exploit a design flaw in a CGI script. This danger was explained in detail in Chapter 10.

You sometimes detect attempts of a brute force attack by reviewing your log files for numerous bad login attempts by the same user or from the same remote location.

If you suspect someone is attempting this type of attack, you can alert the administrator at the company or the ISP serving that user's site. If your passwords are well chosen, you would be fairly safe from this attack, but refer to Chapter 20 to learn why it's very important to back up all of your data.

Shadow password systems (which are available on Linux systems) separate user account information from the encrypted passwords for those accounts. If a person is able to obtain account information, the encrypted password is not available to attempt decryption. With a shadow password system in place, passwords can also be monitored more effectively—regular password changes, numerous encryption options, and other similar security enhancements can be used.
