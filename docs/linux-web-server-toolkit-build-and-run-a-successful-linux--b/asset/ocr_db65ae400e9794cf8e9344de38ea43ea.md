# # Chapter 5: Installing Linux

Be forearmed! If you do not configure your monitor correctly, you can toast your monitor. Again, if you set the wrong values for your monitor, you may damage it.

Each monitor has the following three values associated with it:

+   - a vertical scan rate (or refresh rate) expressed in Hz (hertz), which determines how many lines can be displayed on the screen
- a horizontal scan rate (or overall monitor clock rate) expressed in KHz (kilohertz), which determines the amount of information that can be displayed on each line
- a bandwidth rate, expressed in MHz (megahertz), for how fast the monitor can process screen information

You can see more detailed information on how monitors function by visiting these sites: http://www.xfree86.org/3.1.1/VideoModes-3.html and http://www.xfree86.org/3.1.1/VideoModes-4.html.

Most new monitors are multisync, meaning they use a variety of screen frequencies. This is expressed in the monitor specifications as something such as a vertical scan rate of 50 to 70Hz and a horizontal scan rate of 60 to 80KHz.

If you tell the X Window System configuration that your monitor has higher scan rates than it really does, X will instruct the video card to send signals that are not compatible with the monitor. This can literally fry the monitor's circuits. Read your monitor's user manual if you're not out of its cases.

# # NETWORKING

Linux supports a variety of networking devices. Because installation configures only the Ethernet card, it is the only device mentioned here.

Ethernet cards are generally recognized automatically. However, you should learn the interrupt and software port number (something like 15,320) used by your Ethernet card. The Ethernet can be configured after Linux is installed, but it's easier to do it during installation.

More important than the Ethernet card information is the networking that you get from your network administrator and supply during the installation. If you can provide the correct information during installation, the OpenLinux CD-ROM will install with networking completely set up. This means that when you reboot after installation, the Web server will start automatically. You'll need the following pieces of information about your network: 

+   - IP address: This is the computer's unique address. It must be assigned by your ISP or a system administrator at a site who controls a block of IP addresses.
