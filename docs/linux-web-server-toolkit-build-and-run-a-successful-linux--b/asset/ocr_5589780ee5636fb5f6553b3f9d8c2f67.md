# Chapter 6

# Installing Your Web Server Software

WITH A COMPLETE LINUX system installed, this chapter starts you on the road to using your Web server software. The topics covered in this chapter include the following:

+   - Installing the Apache Web server
- Installing the Netscape FastTrack Web server software
- Checking the status of the Web server
- Automating parts of your Web server

In this chapter, you'll learn how to install the two most popular Web servers. The chapter begins with how to install the Apache Web server, which comes on the OpenLinux Lite CD-ROM included with this book. You may need a commercial (secure) Web server to provide electronic commerce on your Web site, so after the section on installing Apache comes a section on how to install Netscape FastTrack Server, the most popular commercial Web server.

# Installing Apache

If you haven't already installed the OpenLinux Lite CD-ROM that comes with this book, you may want to do so before reading this section. If you have already installed the OpenLinux Lite CD-ROM you may be surprised to find out that you already have a complete Web server running on your system. Pretty cool, right?

> > CAUTION  It's important to note that the version of Apache Web server that comes on the CD-ROM is not a secure, commercial version. You shouldn't use this version to send sensitive information over the Internet.
