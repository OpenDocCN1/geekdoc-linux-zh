# Chapter 12: FastTrack Configuration and Administration

Almost all username files in Linux follow the same format, so all you need to know the filename containing the list of users to import.

From the drop-down list of user databases on your Web server, select which database the imported users should become a part of. Enter the name of the file containing the user data. Check the boxes for the features that you want to implement during the import operation. Then simply choose OK to complete the import operation.
