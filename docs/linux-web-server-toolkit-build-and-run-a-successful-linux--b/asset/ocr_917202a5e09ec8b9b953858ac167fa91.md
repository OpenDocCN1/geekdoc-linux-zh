# Monitor Current Activity

The Monitor Current Activity page is one of the nicest features of FastTrack. It shows you (in real-time) how your server is being used. The page has a button that allows you to view the server monitor page. Once you click that button, the information that is displayed is updated every five seconds.

The items shown on the monitor page include the amount of processor time (as a percentage) for several activities that your Web server works on as requests are processed. Examples include writing rules (retrieving files and running scripts) and processing hostnames (resolving IP addresses and checking security settings).

You can use the server monitor to view the overall system load, or thread utilization, and the percentage of return codes that are successes and errors. The Monitor page is shown in Figure 12-13.

# Archive Log

The log files that record every error and every transfer grow continuously as your Web server is in. In fact, on a busy server, they grow quite fast. As mentioned in Chapter 11 and Chapter 13, you have to archive log files so that they can be examined, stored, or whatever you choose, without threatening to use all your available hard disk space.

A simple script can be used to rotate log files without losing any log entries. FastTrack provides an even easier method with a click of the Archive button.

A second set of buttons allows you to select a standard time for archiving the log files each day at a certain time, or on any days of the week that you choose.

The statistics automatically generated by FastTrack include the Generate Report page, but you may also want to use some of the other statistical tools available for Linux, as described in Chapter 13. Archiving your log files makes them conveniently available for analysis with other programs later on.
