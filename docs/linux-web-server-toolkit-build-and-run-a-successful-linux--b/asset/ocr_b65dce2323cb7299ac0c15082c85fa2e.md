# # Configuring the System Settings

As I mentioned previously, the first set of configuration options presented after you select a server are the System Settings (shown in Figure 12-4). The configuration areas listed down the left side of the page allow you to set the FastTrack Server settings to control how the Server interacts with the network and responds (in a general sense) to client requests.

# # On/Off

The On/Off page is used simply to turn the current FastTrack Server on or off. Using the button shown in this page is just like using the On/Off switch displayed on the Server Selector page (Figure 12-2).

Turning a server off doesn't affect any of the configuration information you've set up. It only means that the server program is not currently running, no browser requests can be processed. You can turn on the server again and all the same configuration information applies; the server is immediately able to accept requests from browsers.

# # View Server Settings

The View Server Settings page lists all of the current settings for this FastTrack Server, including the server root directory, the port (80 is the default, remem-), the number of threads and processes used, and information about the content settings on the server.

Each of the items listed includes a link to the page where that item can be changed. The View Server Settings page only enables you to view all the settings. They are altered according to the different areas that they fit in. If you select any of the items in the View Server Settings page, you jump to the page where you can change that item.

The View Server Settings page is shown in Figure 12-5. This is the first time you've seen a division between "Technical" and "Content" sections.

The top section of the View Server Settings page is indicated as Technical Settings, with the filename magnus.conf mentioned. The bottom section is indicated as Content Settings, with the filename obj.conf mentioned. Note that the configuration information is divided into these two categories, and that those two files contain the settings you're viewing in your Netscape browser. In rare cases, you may want to view these configuration files directly.

# # Restore Configuration

The FastTrack Server stores previous configuration information whenever you make a change. The default is to save the previous ten configurations, but you can easily change that number up or down.
