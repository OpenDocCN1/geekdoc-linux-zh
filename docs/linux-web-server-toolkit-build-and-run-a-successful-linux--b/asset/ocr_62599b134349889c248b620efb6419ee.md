# Chapter 7: Connecting to the Internet

Your ISP is of a certain type, with digital connections at the telephone company local office and a digital link from there to the ISP's modem.

Your ISP will give you a number to call in for your personal, dedicated connection. You'll use a protocol called Point-to-Point Protocol (PPP) to make the connection. PPP lets you run TCP/IP packets over the phone line as if you were on an Ethernet connection with your ISP. It makes you a peer on the network. For PPP to work, your ISP must be set up to allow a PPP connection. You should also ask your ISP what type of authentication security is used for PPP.

When you use PPP to connect, you usually use the Domain Name Server at your ISP instead of setting up DNS on your Web server. The ISP server will also act as your main router. You are technically a peer on the network, but it's more like you're on a tether out in space sometimes. You don't want to get cut off the motherhood, because that's where all the resources are that keep you alive.

# TESTING YOUR MODEM

To use PPP, you should test your modem to see that it's working. You should know which port it's using (first serial, second serial, and so on). Serial ports in UNIX have several names. If your modem is in the first serial port, it should be named /dev/ttyS0.

It's common to use a symbolic link (an alias) so that the file /dev/modem points to the correct serial device for your modem. The Seyon program, which you'll use to test your modem in a moment, always looks for the device /dev/modem. To make your serial device aliased to /dev/modem, enter the following command; if your modem is attached to the first serial port, cua0, the command is:

```
ln -s /dev/ttyS0 /dev/modem
```

Test your modem is functional with the following steps:

+   1. Start the graphical system with the command startx.
2. Move the mouse pointer into the blue background area.
3. Press and hold the left mouse button so that the menu appears.
4. Move the mouse pointer down to the Applications menu.
5. Move the mouse pointer to the right and down to the Internet Connectivity menu.
6. Move the mouse pointer to the right and down to the first item, Seyon.
7. When Seyon is highlighted, release the mouse button.

The Seyon program starts and tries to initialize your modem. If there is a problem with your modem, you'll see a message to that effect.
