Figure 12-2: After the username and password are entered, the first of the Administration Server pages appears. This page lists all relevant FastTrack servers and an on/off switch for each one.

The final button on the Server Selector page (Figure 12-2) is labeled Configure Administration Server. Choosing this button takes you to the Administration configuration page, shown in Figure 12-3. From here, you can set configuration information for the Administration server that controls all the FastTrack Servers on your network (or perhaps just on this machine). You'll recognize the options on this page as the same ones you entered in the text-based configuration script that was described step-by-step in Chapter 7. Now that the system is configured and running, you can change any of those settings using this graphical interface.
