Next, choose the partition you want to install Linux on. This might be harder if you have multiple hard disks or several Linux partitions. Linux and DOS partitions are listed. Don't use a DOS partition (UMDSOS installation) for your Web server. Choose the Linux partition where you want to install the root filesystem of Linux.

If you have multiple Linux partitions where you will store data files for your Web site, you can merge them after installation so they're all accessible from the root filesystem as separate directories. This is a lot easier to set up after the installation.

You must confirm the use of the partition you select to install Linux on, because the installation program will format that partition before installing Linux. Any data that you have left on that partition will be destroyed by the formatting operation. After you confirm the use of that partition, you will see a black screen of data for a few seconds while the formatting operation takes place. Then the menus will return.

With the hard disk ready to go (finally), you will choose what parts of Linux you want to install. I'm going to recommend and assume that you choose the default installation. You can choose the minimal installation without X, if you don't have much space, and still use the Web server, but pieces you want to use may be missing, and you will have to install them separately from the CD-ROM later.

If you're familiar with Linux or UNIX, you might want to use the Package Selection option. This lets you specify exactly what you want from the 50 or more packages of software on the Linux CD-ROM. If you're not familiar with Linux or UNIX, the short descriptions will not be of much help in learning it here and now; stick with the default installation!

After you make your choice, the software packages will be installed on your hard disk. This will take from 10 to 50 minutes, depending on the speed of your CPU and CD-ROM drive.
