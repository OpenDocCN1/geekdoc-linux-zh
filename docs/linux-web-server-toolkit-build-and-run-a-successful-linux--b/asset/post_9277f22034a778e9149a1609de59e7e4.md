
Number of bytes sent (typically the size in bytes of the requested file, plus the size of a few header lines). The number of bytes sent is used mainly for recording the level of traffic flow during different parts of a day or a week. By using the date and time in conjunction with the number of bytes, a statistics program can tell you what period of the day is placing the highest demand on your Internet connection, or conversely, which day of the week and time of day is the slowest, so you know when to plan upgrades.

Programs that analyze the log files simply do what you can't quickly. This includes things like counting all the entries with a certain file, counting how many bytes are transmitted in each hour of the day, and keeping a list of all hostnames requested files.

If you want to watch the access log grow as people access your Web server, enter this command, which shows you the last few lines of the access log, updated every few seconds.

```
tail -f /etc/httpd/apache/logs/access_log
```

## Checking Log Files Manually

Before you install and use the fancy log analysis tools that are available, you can also use simple UNIX commands from your Linux command line to get some ideas about your Web site activity and about what the log analyzers will be doing.

One of the best tools for answering simple questions is the grep utility. This lets you search for a pattern in a file, printing each line where the pattern is found, or just printing the number of lines that the pattern occurs in.

A couple of examples are in order. Suppose you want to see how many times the main file of your Web site was returned to a browser. The following command would print that number.

```
$ grep -c /index.html /etc/httpd/apache/logs/access_log 452
```

The pattern in this case is index.html. The slash indicates the document root; otherwise, you would also be counting entries for index.html in other directories. The -c option indicates that the grep command should print the number of lines on which the pattern occurs, instead of printing every line.

The grep command uses UNIX regular expressions, which are a powerful pattern-matching tools. I can't explain all the details here, but another example will give you an idea of the power of UNIX regular expressions. Note that when you want to search for one of the special characters used in this example

```
$ grep -c [0-9] *.gif /etc/httpd/apache/logs/access_log
```

This example searches the log file for lines that have the word log icon, followed by a single digit, 0 through 9, followed by anything else, and ending in .gif. The number of lines that match this description is printed out on the screen.

You can learn more about the grep command by using man grep. Commands that can be helpful in doing preliminary reviews of your log files include wc, which shows the number of words, characters, and lines in a text file; find, which can be used like grep for complex searching operations; and sort, which can sort lines in a file according to many different criteria, keys, and orderings.

## Setting Up Logging Options in Apache

Web browsers often send a lot of information to the server that is never logged in the access files. In fact, if the information isn't used to decide what to send back to the browser, it's simply discarded after the transaction is completed. This information can include things like the user's name (e-mail address), the plug-ins supported by the browser, and the default language of the browser.

One of the latest features in the Apache Web server included on the book's CDROM is the capability to configure exactly what the log files will contain. Instead of the standard logging format, you can create your own log file format that includes some of the regular log files.

You won't be able to use most standardized Web statistics tools to use this feature, but you may be able to get a more useful information from your site by examining the log files with your handcrafted programs.

Apache-configurable logging requires that a special module be added to the Apache Web server. You can get a copy of the latest version of this module to learn all about how to use configurable logging by referring to the Apache Web site at http://www.apache.org.

## ADDING AGENT LOGGING

The Apache Web server allows you to add a module (mod_log_agent) that records the user agent is using. If you add this module, you should also add the following directive to your srm.conf file to define where the user agents for each request are logged:

```
AgentLog logs/agent_log
```

## ADDING REFERRER LOGGING

Apache also lets you add a module (mod_log_referrer) that records the referring Web page that linked to your page. If you add this module, there are two directives you can add to your srm.conf file to make it work well for you. First, you must define where the referrers are logged. Indicate a file with the following directive.

```
ReferrerLog logs/referrer_log
```

Second, you can define one or more hosts that are ignored.

```
ReferrerIgnore example.com
```

## CONFIGURING THE LOG FILE

If the standard format doesn't fit your needs, you can define a custom format using the `LogFormat` directive. For example, to include the user-agent and the referrer, use:

```
LogFormat "%h %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\" common
```

Where:
- `%h`: The remote host (client IP).
- `%l`: The remote log (usually a hyphen).
- `%u`: The remote user (usually a hyphen).
- `%t`: The time of the request.
- `%r`: The first line of the request (method, path, protocol).
- `%s`: The HTTP status code.
- `%b`: The size of the response in bytes.
- `%{Referer}i`: The Referer HTTP header.
- `%{User-Agent}i`: The User-Agent header.

## Using Statistical Tools

Many statistical tools are available to analyze your access logs. One of the most popular is AWStats, which provides detailed reports on your Web site traffic. Another is GoAccess, which allows you to create custom reports.

By using these tools, you can gain valuable insights into your visitors' behavior, identify your most popular pages, and troubleshoot potential issues.
