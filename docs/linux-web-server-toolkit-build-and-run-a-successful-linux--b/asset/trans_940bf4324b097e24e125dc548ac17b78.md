

## 第3 章：选择你的软件

由于书后附了许多 Linux CD-ROM，且市场上还有没有文档的收缩包装产品，你可能会好奇手册有什么用处。Linux —— 这对于所有的 UNIX 系统都是如此 —— 如果你想完全理解它或让它发挥最大的性能，它就是一个非常复杂的系统。阅读你的 Linux 系统附带的文档可以引导你了解该系统提供的无数功能。这其中包含了 OpenLinux。本书侧重于创建一个 Web 服务器，但你也可以使用 Linux 许多许多其他事情，这些功能在 Caldera 随完整产品提供的用户手册中有所描述。

除了安装说明（这些说明本真的应该放在印刷版手册中）之外，你还应该查询 Linux 系统包含多少在线文档。我见过的多数文档都有几千页的内容，通常取自 Linux 文档项目（一种自由软件类型的文档）以及关于特定主题（如在 Linux 中设置 PPP 连接或在 Linux 中打印）的 Linux HOWTO 文档。

## 选择 Web 服务器功能

一旦你选择并安装了 Linux 发行版（附录 A 解释了如何安装附带的 OpenLinux Lite CD-ROM），你就可以选择你的 Web 服务器软件了。回顾一下，Web 服务器是运行在你的 Linux 操作系统上的程序，接受来自 Web 客户端（如 Netscape Navigator 等浏览器）的请求，处理这些请求并通过互联网或组织内部网返回信息。Web 服务器也称为 HTTP 服务器或 HTTP 守护进程——这是后台程序或进程的 UNIX 称呼。协议和术语将在下一章详细定义。

在选择 Web 服务器时，你应该考虑后续段落中提到的因素。根据你的组织目标和关注点，考虑哪些因素对你最重要。你可以使用表 3-2 来决定除了附带的 Apache 服务器外，是否有其他 Web 服务器更好地满足你的需求，无论是立即还是随着你网站的增长和发展。

## Web 服务器功能

后续段落中列出的功能是你选择 Web 服务器软件时应该考虑的。每个人都希望拥有最好的特性，但妥协是所不可避免的。你为了更稳定的产品而牺牲速度，为了获得免费的 Web 服务器而放弃安全性，以此此类推。

## 速度

速度既指 Web 服务器程序响应 Web 客户端请求的速度（延迟），也指一次可以处理的请求数量（吞吐量能力）。快速响应大量客户端请求涉及许多方面，其中最不重要的一点是 Web 服务器与 Linux 机器上其他运行进程交互的效率。一个繁忙的 Web 服务器在同一秒内可能正在为几十个客户端服务。Web 服务器加载文件、检查权限、运行 CGI 脚本、传递数据和其他因素的算法效率会影响 Web 服务器响应请求的速度，并因此影响 Web 服务器在给定计算机上变得拥堵之前能够同时处理的客户端请求数量。

不同的 Web 服务器有不同的技术优势。尽管我提到过免费软件有多好，但你仍然会发现一个 Web 服务器并不一定比另一个快。有些是从其他平台移植过来的并针对 Linux 进行了大量优化。另一些是作为实验或为了关注某些功能（例如扩展 HTTP 功能）而创建的。如果你担心服务器的速度，因为你的电脑较慢或预计 Web 服务器负载很重，那么这些服务器可能不是你的最佳选择。

## 稳定性

你不应该尝试任何不完全稳定的 Web 服务器，除非你正在尝试实现了改进或你想要添加的新功能的测试版本。表 3-2 中列出的 Linux Web 服务器适用于运行你的 Web 服务器，但你可能听过的最新、不稳定版本或实验性 Web 服务器可能不适用于你的网站。作者通常在评估他们发布的软件版本的稳定性方面非常专业。

然而，我认为可以很地说，如果大型网站的稳定性对你来说是一个关注点，在决定 Web 服务器之前，请阅读本章后面名为“声誉”的部分。

## 功能与管理

功能和管理是你选择 Web 服务器软件时应该考虑的。每个人都希望拥有最好的特性，但妥协总是需要的。你为了更稳定的产品而牺牲速度，为了获得免费的 Web 服务器而放弃安全性，以此此类推。功能和管理结合在一起的，因为你最可能寻找的功能是管理功能！Web 服务器的核心实际上非常简单。它们接收请求并向脚本发送文件，HTTP 这种传输协议非常稳定，将在第 17 章中详细讨论。

对于大多数用户来说，最重要的 Web 功能是配置，Web 服务器的管理正变得非常简单。在许多情况下，默认安装就足够了。但是对于那些可以更改的项目，Web 服务器正在迅速扩展。对于新接触 Web 的人，Web 服务器基本上有两种管理方式：通过编辑特定格式的文件，或者通过易于使用的 Web 页面。

## 跨平台

如果你在异构计算环境中工作，那么一个适用于多种硬件或操作系统的 Web 服务器对你来说可能很重要。这可以减少管理你的服务器的头疼问题和管理开销。

表 3-2 中提到的某些 Web 服务器适用于多个 UNIX 版本。有些也适用于 Windows 或非 UNIX 操作系统。

## 声誉

你可能想从一家你听过的、让你感到熟悉的公司选择 Web 服务器，但大多数 Linux 服务器并不是由你听过的公司创建的；大多数是由一组 Web 专家作为一个项目创建的，然后免费供他人使用。支持、升级等问题软件作者通常不考虑，除非请求错误报告并在时间允许时发布新的测试版本。

如果你觉得从一家知名公司购买产品更放心，你实际上只有两个选择。如果你的公司对 Linux 技术精通，你可以选择 Red Linux 或 Caldera。两者都有广告，并在 Linux 社区中拥有知名度。如果你的组织没有参与 Linux 社区，并且对软件开发并不了解，你的最佳选择是 Caldera。在 Novell、Netscape 和 Sun 等软件巨头的支持和合作伙伴关系下，Caldera 可以提供营销材料和官方形象，让大公司放心使用 Linux 技术作为 Web 服务器。

## 安全性

Web 每月被越来越多地用于商业交易。尽管对网络安全有许多负面报道且缺乏商业标准，熟悉 Web 的人知道在互联网上进行购买有几种方法。

虽然在互联网上传递明文卡号可能不是什么可怕的，但我们大多数人都反感这样做。安全的 Web 服务器（也称为商业服务器）通过提供一种机制，让支持安全功能的浏览器（大多数流行的浏览器都是如此）向 Web 服务器发送回加密信息来解决这个问题。这些问题将在后面的章节中详细讨论，但如果处理你的网站销售额的安全性是你计划的一部分，你应该使用安全的 Web 服务器。遗憾的是，所有的 Web 服务器都是商业性的；你必须购买其副本。这是由于这些产品使用的安全/私钥加密所涉及的许可费用。
