# Chapter 5: Installing Linux

To make the modules disk, follow the same steps as for the installation disk, but use the name MODULE.IMG (or modules.img in Linux) instead of INSTALL.IMG (or install.img).

As with the installation disk, later versions of the modules disk image provide support for more devices may be on the Caldera FTP site if your hardware doesn't have a module on the disk that you make from the CD-ROM.

# Starting the Installation

We're really ready to start now. Just follow along. Start the installation process using one of the methods outlined in the previous section (bootable CD-ROM, booting from DOS, or installation floppy).

![](bbox=[0.04, 0.373, 0.133, 0.439])

If you want to install Linux over a network, with the CD-ROM in place or copied to a networked device, you'll need to start your system with an installation floppy unless you can reach the networked LOADLIN command from DOS.

Once you've started the installation process, the following screen appears:

Caldera OpenLinux
Copyright (C) 1994-1997 Caldera, Inc. Provo, Utah, USA

28Jan97 050

Welcome to Caldera OpenLinux.
This installation will autodetect your hardware and load necessary components as you proceed. If any hardware cannot be autodetected, consult the Getting Started Guide for information about boot parameters that can be entered below to assist the hardware detection.

See http://www.caldera.com/ for the most recent information.

Press <Enter> to begin the installation, or type install with needed boot parameters (e.g. install hdc=cdrom)

boot:

From the boot: prompt (the last line of the screen above) enter any boot parameters you need to get the installation program to recognize your hardware components correctly.

The first time through, assume that you won't need any boot parameters. Just press Enter to start the installation program loading from the disk or CD-ROM. This can take a few minutes. Soon text will start scrolling down the screen.
