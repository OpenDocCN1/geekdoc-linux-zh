# CROSS-PLATFORM

If you are working in a diverse computing environment, it may be important to you to have a Web server that is available on several different hardware or operating system platforms. This may reduce the headaches and administrative overhead of administering your multiser server.

Several of the Web servers mentioned in Table 3-2 are available for multiple versions of UNIX. Some are also available for Windows NT or other non-UNIX operating systems.

# REPUTATION

You may want to choose a Web server from a company that you have heard of and with which you feel comfortable, but most Linux servers are not created by companies that you have heard of; most are created as a project by a small group of Web experts, which then makes the server available freely for others to use. The issues of support, upgrades, and so forth are not considered by software authors, except to request bug reports and promote a new beta release when time permits. that it may not make your company president comfortable.

If you feel more comfortable with a product from a well-known company, you really have only two choices. If your company is technically savvy about Linux, you can go with Red Linux or Caldera OpenLinux. Both advertise and have names that are well known in the Linux community. If your organization is not involved in the Linux community and doesn't understand much about the development of software, your best is Caldera. Backed by strong advertising and partnerships with software industry heavyweights like Novell, Netscape, and Sun, Caldera can provide the marketing material and official presence to make larger companies comfortable using Linux technology for a Web server.

# SECURITY

The Web being used more every month for commercial transactions. Despite all the bad press about security on the Internet and the lack of commercial standards, people who are familiar with the Web know that there are several ways to make purchases over the Internet.

Though passing a cleartext card number over the Internet may not be a terrible risk, most of us are averse to doing it. Secure Web servers, also called commercial servers, solve that problem by providing a mechanism for security-enabled browsers (and most of the popular ones are) used to send encrypted information back to the Web server. These issues are discussed in detail in later chapters, but if security in processing sales from your Web site is part of your plans, you should use a secure Web server. Unfortunately, all Web servers are commercial; you must pay for a copy of them. This is due to the licensing fees that are part of the secure/private key encryption that these products use.
