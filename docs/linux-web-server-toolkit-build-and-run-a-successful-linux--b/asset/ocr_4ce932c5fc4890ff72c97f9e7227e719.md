There is one caveat about starting the FastTrack Server automatically at boot time. Once you get a certificate for using the secure encryption features of FastTrack, you will have to enter a password when you start the server. If you have that as part of your automated boot process in the rc.local file, the entire boot process will stop and wait for a password for the FastTrack Server. This is not good if you're hoping for an automatic reboot after a power outage.

# CHECKING THE SERVER STATUS

As with the Apache web server described earlier in this chapter, you can use the ps command to see the FastTrack and administration servers running on your Linux system. If you use the command ps -auxw, you can locate the lines with /opt/fast-track/bin for the FastTrack Web server and the lines with /opt/fasttrack/admserver if the administration server is running.
