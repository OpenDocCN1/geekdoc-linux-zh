# Configuring Styles

Styles are a feature of the FastTrack configuration that allows you to assign a name to a set of configuration settings, then apply style name to a subdirectory of documents on your site. Rather than set everything specifically for every directory, you can define several styles that meet your different needs, then apply all the settings as part of that style to a directory with a single action.

For example, if you think you have regular document directories that everyone on the Web can access, client directories that require a username and password, and internal directories that are intended for communication within your organization, you may have three styles that are relevant to each type of directory. When you start a new project or add a product section to your Web site, you can assign one of the styles to the new directory with a single action, and all of the associated features (security, logging, scripts, and so forth) apply to that directory immediately.

The Configure Styles section contains several pages that let you set up or edit styles. Most of these pages will be self-explanatory: you can add a new style or remove a style, for example.

The Edit Style and Assign Style pages deserve a little more attention. Remember, you can press the Help button at any time to also review the online Administrator's Guide to the FastTrack Server.
