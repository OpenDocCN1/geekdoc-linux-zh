# Chapter 5: Installing Linux 147

This chapter has taken you from ground zero to a complete Linux system, the graphical interface and networking all configured and running. You should now understand more about the hardware that Linux is using and how you can configure and manage the hardware and software that make up your Linux system.

# Summary

This chapter walked you through all the steps needed to install this book's OpenLinux Lite CD-ROM as a complete Linux system on your computer. As part of that installation, you configured the graphical and networking systems in preparation for running your Web server on your Linux system.
 this chapter you've learned the following:

+   - Linux supports many types of hardware and can use kernel modules to add hardware support easily, during or after installation. Kernel modules sometimes use parameters that you provide to define the configuration of hardware options.
- A single hard disk can be shared with multiple operating systems. The FIPS program can be used to shrink an existing DOS or Windows disk partition to make room on the same hard disk for a Linux installation.
- Configuring the graphical system of Linux (the X Window System) can be challenging, but the system provides tremendous flexibility. A graphical tool is used to select your video card and monitor.
- Networking for Linux is configured as part of the installation process but can be updated or tested using several simple programs as ifconfig, ping, and route.

In the next chapter, you'll learn how to set up and test your Web server software. You'll see how to check its status and begin doing some basic configuration before you connect to the Internet and start posting Web pages to the world.
