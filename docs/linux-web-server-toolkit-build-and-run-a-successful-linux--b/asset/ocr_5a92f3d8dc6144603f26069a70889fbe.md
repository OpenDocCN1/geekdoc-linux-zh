But documents change frequently on the Web. The default for Apache is to instruct any proxy server capable of understanding that documents should not be cached. If you uncomment this directive, this instruction will not be sent to proxy servers. Your documents will be cached at proxy servers around the world when people request your documents.

If your documents are not likely to change often, for example, if your Web site is an archive of old literature, you can use the CacheNegotiatedDocs directive by removing the comment symbol #. This will save your visitors time if they visit your site frequently. For most business applications, caching is probably not helpful for keeping your customers informed, leave the CacheNegotiatedDocs directive as a default setting, as:

```
#CacheNegotiatedDocs
```

# TIMEOUT

The number of seconds that the Web server will wait for data passing between browser and Web server assuming the connection is dead and timing out is defined by the value of the Timeout directive, as:

# Timeout 400

The default value of 400 is about seven minutes. That's a pretty long wait but it allows for slow modems and busy connections.

A high timeout value is convenient for some users but it ties up resources on your Web server. The http process that's waiting can't serve another request in the meantime. If you have a busy Web server and think you might be short on resources at times, and if you won't have a lot of modern connections (though this is very hard to judge), then you could reduce this timeout value by half or more. A browser can request that a Web server maintain a persistent connection in order to improve the efficiency of a Web page transfer when the browser is making requests in rapid succession.

# KEEPALIVE

The KeepAlive directive determines how many requests can come in on one of these persistent connections. The KeepAliveTimeout directive determines how long the http server will wait between requests before dropping the connection and shutting down. The following is what those directives look like:

```
KeepAlive 5
KeepAliveTimeout 15
```
