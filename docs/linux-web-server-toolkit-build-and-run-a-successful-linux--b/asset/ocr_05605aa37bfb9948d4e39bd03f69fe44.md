Chapter 11: Configuring the Apache Web Server

# Adding Advanced Features

We, we've covered the basic features of Apache configuration. There are many more features that you can experiment with to add power and flexibility to your Web server. All are described more fully in the documentation that accompanies the Apache server. I'm just going to summarize some key features to give you an idea of what you can do.

Some of the features described in this section require that you add modules to your standard Apache configuration. These modules are simple server add-ons that extend the Web server you can do. You can also read about adding modules in the Apache documentation. You can also find additional modules on the Apache Web site (http://www.apache.org) and from other locations on the Web. But be careful about using modules from spurious sources – they invite security problems. Table 11-3 describes some features or directives that can be used with Apache.

Table 11-3 Advanced Features Available in the Apache Web Server

| Feature | Module Required | Description |
| --- | --- | --- |
| Alias | No | Any directory on your Web server can be accessed using a standard directory within the DocumentRoot area by specifying an Alias directive in the srm.conf file. A fake directory indicated by a browser is mapped (aliased) to a real directory on your system |
| Redirect | No | Any requested file can be redirected to another file on your Web server or on another server, using a complete URL. The browser will see the Redirect code and often retrieve the document from the redirected location. This is used when files have been moved or deleted but are still being requested. |
| AddType...cgi | No | A special use of the AddType command lets you define a type for scripts. This provides a more secure execution system. |
| Server-side includes | No | HTML documents can include special codes that cause the Web server to insert text into the document each time it is sent to a browser. Though they add a burden and possible security holes, this feature provides great flexibility for up-to-date documents.
