If a platform such as Sun Solaris or Windows NT has a JVM, you can run a Java program on that system just as you can run any other program. In fact, you can run the same Java program on any system that has a JVM. That means your Java applications are not tied to a single operating system or hardware platform – a huge break with the past.

This feature of Java makes it ideal for the Web. Just as a browser can download pages from a Web server and display them, the browser can download applications from a Web server and run them. This can be done regardless of the platform that the application was developed on. The only requirement is that the user has a Java-enabled browser.

# Interpreted versus Compiled Languages

Java is interpreted. But what does that mean?

When you write a program, you use keywords and an organized system based on the language you're using — Visual Basic, Pascal, or some other computer language. But the computer doesn't use that set of keywords. The computer uses numeric codes that make no sense at all to humans reading them.

The conversion from human-readable programming language to computer-usable numeric codes can take place when the program is either written or executed.

If this conversion takes place when a program is written, the program is being compiled. Conversion as the program is being executed occurs for interpreted languages — usually scripts or some types of BASIC.

The advantage of compiled languages is that they can be optimized to run efficiently when they are first created, and the source code (what the human programmer wrote) can't be seen. Interpreted languages are much slower, because each line of code must be converted when the program is run, each time the program is run. The source code is also visible to others, something that the programmer may not want.

But interpreted languages have the advantage of being cross-platform. For example, any computer with a version of the Perl language (or BASIC language in the old days) can run a program written in that language. The program isn't specifically for one computer type. Until Java, no widely accepted compiled language had that advantage of interpreted languages.
