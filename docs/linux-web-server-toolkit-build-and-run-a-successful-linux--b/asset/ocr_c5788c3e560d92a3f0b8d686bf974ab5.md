# Chapter 6: Installing Your Web Server Software

Each time you access the administration server from your Web browser, you must enter a username and password before you are permitted to do anything, as shown in Figure 6-2.

![](bbox=[0.068, 0.203, 0.663, 0.583])

Figure 6-2: The administration server always requires that you enter a username and password before you can access the administration tools for the FastTrack Server.

The next item lets you select a username and password for the user that you will log in as, as follows:

Access username [admin]:

You can press Enter to accept the default, which is always admin, or enter a different username if you prefer – just keep it to eight characters or less. It would be more secure to use a username different from admin, because all FastTrack administration servers will use admin as the default user, but there are numerous other security measures, and using a different username is one more thing to remember.

Next, enter a password for this administrative user as follows; you'll enter it twice to be sure you typed it correctly:
