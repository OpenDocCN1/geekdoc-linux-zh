# Basic System Setup Options

The Apache Web server uses three configuration files for all basic system setup options: HTTPD.CONF, SRM.CONF, and ACCESS.CONF. Other options are handled through additional utility programs (located in /USR/SBIN and listed in Table 6-1) or through features such as server-side includes that are not directly related to a configuration file.

The three configuration files are located in the directory /etc/httpd/apache/conf. Table 6-2 provides descriptions of each.

| Configuration File | Description |
| --- | --- |
| httpd.conf | Core Web server configuration, such as which user to run the server as, and where the log files are stored |
| srm.conf | Details of where Web document files are located and how requests from browsers are to be processed and displayed |
| access.conf | Access control and security information for the Web server; who can access files in each document directory, and so forth |

Two copies of each of these files are included in the /conf/ directory. One copy has -dist added to the end of the filename and should be left unaltered as a backup to the default values that were originally installed. For example, you should not alter the file access.conf-dist because it is the backup to access.conf. The files listed in Table 6-2 are the files that are actually read by the Web server. The access and other options are set to "safe" values for most uses by default. If you install your OpenLinux system while you have a live Internet connection and your machine is visible on the Internet, anyone can immediately use the Web server on your OpenLinux system. But the configuration is such that you shouldn't worry about security.

In addition to the three files just mentioned, another file in the conf/ directory is mime.types. MIME refers to Multipurpose Internet Mail Extensions, a system of defining the type of a file so that it can be acted upon by the appropriate application. This is something like associating a file with the .GIF extension to open in a graphics viewer. The mime.types file defines all the data types that the Web server recognizes, with an associated file extension.

For example, the default mime.types file includes the following line:

```
video/quicktime                qt mov
```

If you include a link to a file with the extension .qt or .mov, the Web server can indicate to the requesting browser in its header information that the file is of video/quicktime. If the browser has data type included in its configuration file, it will know what application to start that file when it is downloaded.

The mime.types file on the Web server is just a service to browsers. Each browser may also have a similar configuration file and ignore the information provided by the Web server with the incoming file. Still, you should keep the mime.types file up to date when you become aware of other data types that you are delivering as part of your pages.

# Installation Options

There are a few common ways to install software packages in Linux: the rpm package system, the tar format, and the Debian package format.

An rpm formatted package places all files needed for a new piece of software, with startup scripts and descriptive information, into a single compressed file. Using a single command — the rpm utility — you can install a new software package. The rpm command follows the installation script that is stored in the software package file to know where to place everything. It also updates a systemwide database of installed packages, which you can query for information about what is installed on your system.

The rpm format is widely used in the Linux world; you will find that many packages you want to try are available as a single rpm file.
Another common format is used is tar. The tar format is more universally used in the UNIX world. It is a tape backup format that merges a complete tree and all its subdirectories into a single file. The tar command is not as flexible as rpm because it requires that the files be located in a single directory. It also does not provide the descriptive or package capabilities of the rpm system.

You will often see files on the Internet that end with .tar. You can view the contents of these files with the following command:

```
tar tvf filename.tar
```

Or you can extract the tar file for use with the following command:

```
tar xvf filename.tar
```

The tar command doesn't automatically compress files, so you'll often see files with .tgz, indicating a compressed tar file. You can uncompress them with the following command:

```
tar xvfz filename.tgz
```

Another package format within the Linux world is the Debian package format. Similar to the rpm format in some ways, it provides descriptive information, installation and deinstallation tools, and a variety of helpful options for developers.
