In addition to making window management easier, the desktop metaphor can be used to manage your files. A graphical desktop, like the Macintosh or Windows 95 interfaces, lets you manage files in an intuitive way, eliminating the need to memorize all the UNIX commands to get your work done. The next section describes the OpenLinux Desktop interface included in this book's CD-ROM.

# The Caldera OpenLinux Desktop

The OpenLinux Lite CD-ROM included with this book includes a trial version of the Caldera Desktop interface, which is a Linux version of the Looking Glass Professional Desktop from Visix Software. The Desktop will function for only about 90 days. The graphical environment (the X Window System) will continue to work, and all your files will remain intact.

This section describes some of the features of the Desktop that you can experiment during the trial period and to manage your system. Some of the features of this Desktop are as follows:

+   * Filesystem management windows
* File typing and automatic icon associations and icon editor
* Configurable layouts
* Programmable icon bar
* Graphical preference setting for many system defaults

As you start the X Window System after installing OpenLinux Lite from the CD-ROM, the Desktop in Figure 4-2 will appear automatically on the X background. The Desktop background provides a place to put icons for commonly used programs and data files. You can place any file on the Desktop for quick access. The icon bar and menus provide access to the Desktop functionality.

If you want to change the icon bar, choose Icon Bar from the Options menu. A dialog box appears, where you can change the order of the icons by dragging them, activate or deactivate the standard icons, or add your own icons with commands that you choose.
