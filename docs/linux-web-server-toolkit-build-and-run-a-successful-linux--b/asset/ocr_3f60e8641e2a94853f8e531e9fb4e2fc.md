The OpenLinux CD-ROM (including the one in the back of this book) contains a selection of what Caldera considers to be the highest-quality products in each category among all the free software available for Linux. This differs from some vendors who have chosen to provide, a separate product, an archive of six to ten CD-ROMs containing everything on the Internet for Linux. Certain packages on the OpenLinux CD are installed by default; others are not installed but remain available on the CD-ROM.

OpenLinux and Caldera emphasize the commercial end user who wants a stable running Linux and relationships with commercial software vendors such as Novell and Netscape, and is not concerned about having the latest version of the Linux kernel. However, Caldera also supports the version that it sells and guarantees that all its applications and tools run on that version. Caldera's services include annual support contracts, partner programs, and the widest range of Linux products by any Linux vendor.

The CD-ROM in the back of this book contains the OpenLinux distribution from Caldera, with a couple of additional pieces of software thrown into the /CONTRIB directory for things I talk about in the book – things such as Web statistics, HTML validation tools, and additional Web server software.

+   * The complete Linux operating system

* TCP/IP routing support, including IP masquerading
* Name server for DNS
* The Apache Web server
* Other Internet services such as FTP, e-mail, gopher, and POP
* Other connectivity services such as SLIP, PPP, and BOOTP
* Editing tools for your HTML pages (a complete graphical text editor)
