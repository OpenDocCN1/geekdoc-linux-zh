As you plan for what information will be included, I recommend that you create a site map. Creating this map is much easier before the site is completed and running, having it will help you track the location and organization of information. Updates to your site are easier with a site map because you can immediately see where cross-reference links to related information are appropriate.

A site map can start by including just a page's headline and the major links that are on that. Linked pages are shown beneath the main page. By nature, hypertext (HTML is one type of hypertext) should allow the reader to jump all over the document tree, without following a single preset path. But the document tree will still be organized according to one or two defaults, or most likely navigation scenarios. An example beginning-stage map is shown in Figure 1-7. In addition, you can see an online example of a site map for users at the Ford Motor Company by visiting http://www.ford.com.
