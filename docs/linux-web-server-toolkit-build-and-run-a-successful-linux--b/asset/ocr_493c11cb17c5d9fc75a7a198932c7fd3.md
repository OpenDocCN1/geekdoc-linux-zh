# GATHER DATA SENT USING POST

There are two ways that scripts gather form data using POST. If you're using an older version of Perl or do not have the Perl CGI library, your script can read in the Standard Input and divide it into separate variables. Later versions of PERL include the CGI library, which makes the job a lot easier. Include the library at the top of your script as:

```
require cgi-lib.;
```

Then the script can read in process the POST form data using the following-command:

```
&ReadParse;
```

Then the value of any one of the POSTed items can be accessed in the script by referring to its NAME. If your user were submitting a form with an input line like the following:

```
<P>
Your First Name: <INPUT TYPE=TEXT NAME= first_name >n<P>
```
