# THE XF86CONFIG SERVERFLAGS SECTION

This section of XF86Config is used for special options that are needed to get a video card to work. These options are similar to the Other page in the XF86Setup utility. Most of the time, you'll see only comment lines in this section (lines that start with a # are comments). The section is as follows:

Section ServerFlags
EndSection

# THE XF86CONFIG KEYBOARD SECTION

This section of XF86Config is where keyboard options are listed. X provides a lot of control over the keyboard, and can trap any keystroke to us for commands in the window manager (we won't get into this—enter fwwm for details.).

Important items in this section are the protocol, almost always “Standard,” and the autorepeat values. Most international keyboards can be supported in X with a simple option and the correct key map files (see the HOWTO documents in the online documentation). The section is as follows:

```
Section Keyboard
Protocol Standard
XkbRules xfree86
XkbModel pc101
XkbLayout us
EndSection
```

# THE XF86CONFIG POINTER SECTION

The mouse or other pointer device is defined in this section of XF86Config. This section has only two values: the protocol and the device name. Because most PC can emulate the Microsoft Mouse or Mouse Systems Mouse, you can usually get this to work without trouble. The device name might be more difficult if you're not sure where your mouse is plugged in. The PS/2 port is called /dev/aux, /dev/ttyS0 for the first serial port, and so forth.
