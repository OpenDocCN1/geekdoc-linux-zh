# Chapter 5: Installing Linux

![](bbox=[0.043, 0.096, 0.813, 0.523])

Figure 5-3: After a hard disk has been defragmented in Windows 95 or Windows NT, the free space is located at the last part of the hard disk (offscreen). All the files are grouped at the front of the hard disk.

Once you have defragmented your hard disk, you're ready to use FIPS to cut the contiguous available space off as a separate, empty DOS partition. Then you can use the Linux fdisk utility during the installation to make that partition available to Linux.

The FIPS program is located in the \COL\TOOLS\FIPS15 directory on the accompanying CD-ROM. I will walk through each of the steps you'll follow as you run FIPS. Things that you are indicated in boldface. Requests to print prompts are not in boldface.

+   1. Start the FIPS program at a DOS command line (substitute the correct drive letter for your CD-ROM drive):
   E:\COL\TOOLS\FIPS15\FIPS
2. Read the information about the warranty (there is none) and the warning messages (back up everything before using this utility). Then, press any key to continue.
