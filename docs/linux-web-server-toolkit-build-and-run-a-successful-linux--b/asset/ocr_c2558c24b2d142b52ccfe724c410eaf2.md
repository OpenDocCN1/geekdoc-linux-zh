# Install: Software Packages Archive

The Install directory is where all the software packages that make up OpenLinux Lite are stored. The Install directory contains several subdirectories that divide the software packages into groups based on subjects, such as networking and the X Window System. Installation options presented when you install OpenLinux Lite (such as default, minimal, and so forth) allow you to select which software packages in this directory are installed.

The RPMs subdirectory in the Install directory contains all the software packages in OpenLinux (except those are stored in the Contrib directory, described previously). Links to the software packages are listed both in the RPMs directory and in one of the subject directories. The installation program will install the correct package according to which installation option you.

If you want to install any other software packages after installing OpenLinux Lite, you can change to the /col/Install/RPMs directory and use the rpm command. The use of the rpm utility is described in greater detail in Chapter 21.

What is contained in the Install directory? Over 600MB of compressed software packages, with well over 1,000 individual utilities and programs. Some of the highlights include the following:

+   - Apache web server

+   - Servers for finger, NNTP, FTP, and e-mail

+   - Complete X Window System with multiple window managers, graphical utilities, and games

+   - Desktop interface (Looking Glass)

+   - Complete networking protocols and utilities (TCP/IP, PPP, SLIP, terminal server support, DNS, NIS, and others)

+   - Developer tools, including C compiler, other languages, debuggers, text editors, and other development utilities

+   - Text processing utilities, including the complete LaTeX system, emacs, and more

+   - Graphical applications, including graphics tools (gimp, xv, etc.), graphical system administration utilities, screen savers, graphical programs, and games
