# LANGUAGE DIRECTIVES

The following directives are also for content negotiation:

+   - AddLanguage en .en
- AddLanguage fr .fr
- AddLanguage de .de
- AddLanguage it .it
- LanguagePriority en de fr

The AddLanguage directive gives a standard Internet language code followed by the filename suffix used for that of type. The LanguagePriority directive gives an order that should be used instead in case of a conflict or a browser that can accept multiple languages.

The AddLanguage and LanguagePriority directives assume a browser is being used that can negotiate the language preferred by the user. The default srm.conf file contains several AddLanguage statements that are not included here. The LanguagePriority is arranged by default according to the largest markets in which Caldera says. You should rearrange these priorities to your area and target users.

Here's a simple example of how the language directives are used. Suppose you created an index.html file for your home page. When you translated it into German. Finally, you made a copy of the English version named index.html.en and a copy of the German version named index.html.

Now a browser asking for index.html, specifying German (with de as the Internet code for this) as the preferred language. The server notes from the AddLanguage directive that uses the extension .de, so it looks for index.html, find it, and sends it off. If English and German had both been acceptable, the English file would have been sent instead because of the LanguagePriority directive.
