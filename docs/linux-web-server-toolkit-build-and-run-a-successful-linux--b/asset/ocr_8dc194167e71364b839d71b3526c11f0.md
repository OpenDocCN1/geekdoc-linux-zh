# Speed of Interchange

The Internet in general (via e-mail, chat rooms, and other services) and the Web in particular change the way the world works in several ways. Let’s back up little and consider the computer as a business tool.

The computer changed how businesses worked. One person could process so many orders, write so many more letters, and so forth. Expectations rose and business processes changed. But that was all within a single office.

Things like the fax machine and overnight package delivery continued to change business processes, this time between offices and companies. Changes don’t come easily for most people, of course. When a Harvard graduate first proposed an overnight package delivery service, his professor ridiculed the idea. Who would want things overnight?

The Internet is the culmination of this trend. You can exchange a letter, photographs, or any document with anyone in the world. You can do it instantaneously via e-mail or the Web. And you can do it at very low cost. You can post information where millions can view it, or encrypt a message so only the recipient can read it. All of these transactions take place without interference of customs officials or delays of mail. The Internet differs from the telephone and fax because you can send any type of information at low cost in virtually real time. A manager based in Hong Kong can click an icon and print a report that resides on a server located in London. A user can write a message in New York and have it on the screen of 500 colleagues all over the world in literally three minutes.

The Internet changes how people view delays and what they expect from the people they do business with. It’s no longer acceptable to blame the Post Office or even Federal Express. If something is ready, you can e-mail it to me immediately so that I can start reviewing it. There is no time buffer left.
