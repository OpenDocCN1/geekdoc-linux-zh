In this chapter you learned:

+   - Creating a process that reviews pages for a list of potential problems will make your Web pages much less prone to errors. Problems with a page can be grammatical, legal, or message oriented, among others.

+   - Spell checking tools are available for your Web pages to correct credibility-damaging spelling errors before they are posted to your site.

+   - Many commercial and free HTML checking tools are available. Some are stand-alone programs. Others are Web sites that you submit your page to for checking.

+   - Automated development of HTML pages using scripts saves a lot of effort in assuring correctness of your pages and should be used whenever possible.

+   - In the next chapter, you'll see how important system backups and regular maintenance are to running a stable and effective Web site.
