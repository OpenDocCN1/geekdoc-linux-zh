# Tools for Creating HTML

In addition to the growing number of word processors that can export HTML-formatted documents, there are a variety of specialized Web publishing tools you can use to create your Web pages. Many of these integrate graphics with drag and drop actions, check the validity of links and HTML syntax, or even import existing HTML files as a starting place for your work (watch those copyrights!).

Nevertheless, I'm going to prevent you're doing the hard way: in a text editor, hand editing each tag. That's the best way to learn what's happening. (I'm going to make my kids learn Latin, too.)

Table 9-1 lists some of these HTML authoring tools, with their capabilities. Many of the tools listed are commercial products. You can visit the Yahoo search page for a list of dozens of other tools, many of which are free (http://www.yahoo.com/Computer_and_Internet/Software/Internet/World_Wide_Web/HTML_Editors).
