# Using Command-Line Utilities

Though you can edit configuration files directly or use the LISA utility to enter
new networking information, there are a couple of commands that are used to
update some networking information: the ifconfig utility, and the route utility.
These commands use the information in the configuration files, either during sys-
t startup or when LISA updates your system. Learning about these commands
will be very helpful as you become more involved in setting up your Web site and
managing the networking on your Linux system.

Both of the utilities mentioned here should be used only by the root user. If any
other user can use them, they pose a security risk. You can learn all the
options and use of these utilities from the online documentation, including the
man page (enter man ifconfig, for example).

# THE IFCONFIG UTILITY

The ifconfig utility (for Interface Configuration) is used to view or configure the
networking interface used by the Linux kernel. Using ifconfig tells the Linux kernel
how to process network packets, where to send information, and so forth.

Each possible network interface on your system has a separate configuration,
with associated IP addresses and network traffic. For example, if you have a system
with two Ethernet cards installed, it can act as a gateway between two networks.
Each of the Ethernet cards is a separate networking interface. Each one has a dif-
erent IP address and different characteristics that determine how network traffic is
treated, including the process of routing packets between the two networks.

You can see the network interfaces that are configured on your system by
entering the ifconfig command without any options, as follows:
