# Linux Filesystems, Users, and Programs

In order to use Linux effectively, you should understand a little about how Linux arranges things on the hard disk, how users and groups are created and managed, and how to interact with the command line to control programs that you've started. Because a standard Linux distribution is over 100MB when installed (and the OpenLinux Lite installation includes even more than that), where to find things can be a big help as you start configuring your system.

Linux uses a filesystem standard that is similar to most UNIX systems. However, as described in Chapter 3, each distribution may have a slightly different incarnation of the filesystem arrangement. What I describe here applies to OpenLinux Lite and for the most part, to all other Linux distributions.

To begin, you must know that everything in UNIX is part of the filesystem, or the directory tree. All floppy disk drives, hard disks, and other devices are accessed through a single filesystem. Everything starts at the root of the filesystem, which is indicated by a forward slash (/). (Note that this is the opposite direction to the slash used in DOS and Windows directory paths, and that no drive letter belongs the directory path.) Even hard disks on remote computers can be "mounted" so that they appear as part of your local filesystem via a simple directory path.
