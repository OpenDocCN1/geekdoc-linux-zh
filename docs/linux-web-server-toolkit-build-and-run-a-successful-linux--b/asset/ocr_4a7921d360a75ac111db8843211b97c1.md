# Using Headings

Different heading levels help your reader quickly scan the document for the part he or she considers most important. They provide a context for what you write and help you organize your Web pages.

HTML provides up to seven levels of headings. I recommend using no more than three. Using HTML headings is very simple. A capital H followed by the heading level. Enclose the title text in the opening and closing heading tags. For example:

```
<H1>Master Tax Guide</H1>
```

Depending on the arrangement of your documents, a certain Web page might not start with an H1. If reader are working through sections of a large document, it might make more sense to start a subsection that is a separate file with an H2 or H3 heading to give the reader a sense of proportion to the rest of the document.

As you start to use graphics in this chapter, you may not need to put any text in heading tags because you're using a banner-style graphic as the heading for your page instead.

In simple documents like the example follows, you should plan heading levels to indicate subordination of ideas, rather than a certain look onscreen. In this example, I've used simple <Hx> tags so that the browser controls the font style and size for each heading level. (Advanced HTML tags, which are not described here, allow you to control the font used for different headings.)

This example has several heading levels:

```
<HTML>
<HEAD>
<TITLE>Headings Test</TITLE>
</HEAD>
<BODY>
<H1>This is a Top Level Heading H1</H1>
This is a top level introduction.
<H2>Second Level H2</H2>
This is a second level introduction.
<H3>Third Level H3</H3>
This is a third level introduction.
<H4>Fourth Level H4</H4>
This is a fourth level introduction.
</BODY>
</HTML>
```
