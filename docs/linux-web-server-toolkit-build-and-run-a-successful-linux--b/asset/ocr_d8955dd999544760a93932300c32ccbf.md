# Chapter 10: Basic Scripting and Forms

The Reset and Submit buttons complete the list of <FORM> tags. In the next section I will describe a complete form example that uses all of the <FORM> tags.

# Form Example

The next example uses almost all of the tags that were described in the previous section. Although this is a very simple form, it will help you to see the tags all used together. This form also provides something to refer to as scripts are discussed in the next section.

The following presents a full-screen survey for a user to fill out: Figure 10-11 shows how the survey looks on a browser:

```
<FORM ACTION= http://www.traveltips.com/cgi-bin/survey.pl
METHOD= POST>
Thank you for filling out our survey. All responses are confidential. Summary results will be posted on this Web site on December 1.<P>
Enter your name (optional): <INPUT TYPE= TEXT NAME=MYNAME <P>
Enter your e-mail address (optional): <INPUT TYPE= TEXT NAME= EMAIL <P>
<INPUT TYPE= CHECKBOX NAME= SEND_RESULTS > Do you want to e-mailed a copy of the survey results?<P>
<HR>
Your age:
<INPUT TYPE= RADIO NAME=AGE VALUE=UNDER20 > Under 20
<INPUT TYPE= RADIO NAME=AGE VALUE=21T035 > 21-35
<INPUT TYPE= RADIO NAME=AGE VALUE=36T055 > 36-55
<INPUT TYPE= RADIO NAME=AGE VALUE=OVER55 > Over 55
<P>
Your income:
<INPUT TYPE= RADIO NAME=INCOME VALUE=UNDER20 > Under $20K
<INPUT TYPE= RADIO NAME=INCOME VALUE=21T045 > $21-$45K
<INPUT TYPE= RADIO NAME=INCOME VALUE=45T080 > $45K-$80K
<INPUT TYPE= RADIO NAME=INCOME VALUE=OVER20 > Over $80K
<P>
Which of these airlines have you personally flown in the past 12 months? (Select all) that apply)<P>
<SELECT NAME= AIRLINES SIZE=5 MULTIPLE>
<OPTION SELECTED>Delta
<OPTION>American
<OPTION>United
<OPTION>British Airways
<OPTION>Alitalia
<OPTION>Air France
<OPTION>Lufthansa
<OPTION>KLM
</SELECT>
<HR>
Select the destination you are most interested in visiting (select one from this list):<P>
<SELECT NAME= DESTINAT SIZE=3 >
```
