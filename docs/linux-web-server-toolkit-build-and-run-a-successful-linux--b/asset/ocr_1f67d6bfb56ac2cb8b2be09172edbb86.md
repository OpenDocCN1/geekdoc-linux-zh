# Using Spell Checking Tools

One of the most unprofessional errors on a Web site is also one of the easiest to
correct: spelling errors. If an employee finds a spelling error in an internal com-
pany memo, it’s not a big deal, but a user finding one on a corporate Web site is
eequivalent to spelling errors in the annual report or in a weekly news-
magazine like Time. It catches your eye and says “These folks aren’t very careful—
how can I trust them if they can’t spell?”

# Professional Tools

Whether your Web pages were created by an agency or outside contractor
or by someone in your organization, the final responsibility of making sure they
are up to par rests with your organization. The old saying goes, never assume
that the fellow who runs the printing press can spell; it’s not his job to prove
ddocuments.

All that said, spelling is a lot easier to check now than ever before. Most of the
commercial tools for developing Web pages like Adobe Site Mill, HotTMetal, Pro, or
various MS Word templates incorporate corporate spell checking into their systems. These
professional tools will even ignore HTML tags and check the value of attributes
without trying to check the names of the tags themselves.

Numerous stand-alone tools are also available specifically to spell check HTML
skipping tags and only looking at the words that will appear on the screen
in the browser. Several of these are mentioned in the section that follows about
checking for correctness of HTML.
