# The Proxy Server

You can enable the ProxyRequests directive to use the proxy server feature of Apache as follows:

```
#ProxyRequests On
```

> NOTE ProxyRequests directive is not used in default configuration.

The Apache server is a proxy server when it acts as a gateway sending a browser's request on to another server.
In association with the proxy server feature, you can enable caching of documents, so that frequently requested documents are stored on this server and returned to a browser without going to the place where the documents were originally stored. This is illustrated in Figure 11-1.
