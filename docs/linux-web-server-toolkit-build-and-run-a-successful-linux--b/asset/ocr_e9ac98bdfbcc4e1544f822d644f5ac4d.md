# The Relationship Between the
Internet, the Web, and UNIX

Unless you've been hiding under a rock for the past four or five years, you know that the Internet is a global collection of networks, all tied together by high-speed data communication lines, and that the World Wide Web defines only a single type of data that is transmitted over the Internet. Even so, the Web has become the most widely known part of the Internet and arguably the most useful to businesses. Many Internet servers (servers connected to the Internet) don't include the ability to transmit Web data. Web data is not even the most voluminous type of data on the Internet, it's just the fastest growing and most marketed, consumer-oriented part of the Internet.

Because Linux is basically a UNIX operating system without the trademark, I'll begin this discussion with a little background on UNIX and how it relates to the Internet.
