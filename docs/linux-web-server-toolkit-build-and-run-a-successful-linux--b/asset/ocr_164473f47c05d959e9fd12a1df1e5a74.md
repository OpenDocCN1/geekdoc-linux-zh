Be aware, however, that environment variables apply only within the scope in
which they are created. The simple explanation of this is that if you add a new
variable using the Desktop, then exit the Desktop and start a program, the variable
that you created will not be available to the program. Only programs started from
within the Desktop (by double-clicking on an icon), for example will see the new
variable that you created.

# OTHER PREFERENCE SETTINGS

You can open the main Preferences window by selecting Preferences from the
Windows menu on the Desktop. From the Preferences window, double-click on the
icon for the type of preferences that you want to see or change. A separate window
appears for each group of settings.

For example, to set the colors of the Desktop, choose the Colors icon. You can
select background, foreground, or shading colors for the Desktop windows.
Or, to set the default text editor used when you double-click on a text file,
choose the Execution preferences and look at the Default editor. The default
editor will be the CRISP- editor that comes with Linux. If you are already
a UNIX fan, you can change to the vi or emacs editors by changing this line. The
preferences you can set are too numerous to list here, so be sure to explore this
feature to get a full understanding of how you can customize your system.
