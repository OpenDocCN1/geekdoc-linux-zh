# Overview

The Visible Human Project is an outgrowth of the NLM's 1986 Long-Range Plan. It is creating a complete, anatomically detailed, three-dimensional representations of the male and female human body. The current phase of the project is collecting transverse CT, MRI and cryosection images of representative male and female cadavers at millimeter intervals.

The long-term goal of the Visible Human Project is to produce a system of knowledge structures that will effectively link visual knowledge formats to symbolic formats such as the names of body parts.
