# Troubleshooting Your Network

If the tests in the last section don't work, the problem is usually in the configuration files mentioned in Table 5-4. Checking these files for correct IP addresses using a text editor—or better, using the configuration utility described in the next section—will usually solve the problem.

Networking can be exceedingly complex. Serious problems can arise from variety of sources to mention here. On that beat, I'll list a few problems to show what sorts of things you can look for. Complete troubleshooting is beyond the scope of this book, though more is covered relative to Web servers in later chapters. The experts at your ISP are usually worth the price to get a troublesome networking error fixed with the least downtime possible. Some possible causes of networking errors include the following:

+   - You are using several subnets and you have your network and netmask addresses set incorrectly.

+   - You are using several different protocols on your network and they are interfering with one another.

+   - You have not informed the person managing your master name server to add the hostname you chose.

+   - You didn't use the IP address that was given to you and that was entered in router tables for you at the main gateway.

+   - The name server IP address is wrong, so only pings with IP addresses work.
