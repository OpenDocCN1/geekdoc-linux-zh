# Complex Disaster Plan

This plan is much more complex than the simple plan. It assumes that keeping your Web site running is an important part of your organization. It provides systems to keep your Web site available to the public in all but the most serious outages as when the Internet itself is down. An outline might look something like the following:

+   * Preparation

+   * Obtain a second server to act as a mirror to the current Web server, with a router to split requests between the two.

+   * Obtain an additional hard disk, network card, and so on for quick swaps of any device that fails.

+   * Obtain sufficient backup devices to complete backups of the Web site on a single set of media.

+   * Obtain uninterinterruptible power supplies for each server, sufficient to maintain the server for six hours.

+   * Obtain a second, slower connection with another ISP that connects to the Internet backbone using a different provider from your main ISP. Tie this connection to another router at your site and keep it live for outgoing traffic.

+   * Review the disaster plan of your ISP to determine how stable it is.

+   * Review this disaster plan with MIS and Webmaster staffs.

+   * Backups

+   * Backups for both mirrored servers are completed each night by MIS staff at different times onto a rotated set of storage media, with two weeks of backups kept on file as part of the rotation. Each week the latest copies of the backup media are taken to an off-site location.

+   * Failures

+   * In of hardware failures on a server, all traffic will be routed to the other server. Replace the failing part, or the entire server if necessary, using spare parts and backup media from previous night to restore data.
