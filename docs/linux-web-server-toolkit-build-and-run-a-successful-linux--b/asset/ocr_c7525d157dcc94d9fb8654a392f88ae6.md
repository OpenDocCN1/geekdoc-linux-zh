Regardless of whether you have already installed the Apache server from the CD-ROM or not, you're probably asking: What exactly is installed as part of the default OpenLinux Lite installation? The answer is: the complete Apache server, with all configuration files and documentation. That includes all of the files, directories, and components listed in Table 6-1.

# ### Table 6-1 Apache Components Installed as Part of OpenLinux Lite Default Installation

| File or Directory | Description |
|---|---|n| /etc/httpd/apache/conf | Directory where configuration files are located |
| /etc/httpd/apache/logs | Directory where logs are located (an alias to the var/log/httpd/apache directory, where the log files are actually located) |
| /home/httpd | The home directory for the Web server, where all documents, scripts, and so on are normally stored |
| /usr/doc/apache-httpd-1.1.1-11 | Basic documentation directory for things such as the license and README file |
| /usr/man/man8/httpd.8 | The manual page for the Web server program |
| /usr/sbin/ | Several units are installed in this standard program directory, including: dbmanage, htdigest, httppasswd, httpd_monitor, log_server_status, httpd.apache, resolve, rotateles |
| /var/log/httpd/apache | Directory where log files are located |
| /home/httpd/apache/doc/manual.ps.gz | The manual for the Apache Server |

> If you have a PostScript printer you can print the manual for the Apache server (mentioned in Table 6-1) with a command, such as the following:
cat manual.ps.gz |l1
