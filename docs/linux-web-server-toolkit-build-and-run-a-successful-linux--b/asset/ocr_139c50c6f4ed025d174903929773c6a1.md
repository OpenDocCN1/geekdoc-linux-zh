# Chapter 12: FastTrack Configuration and Administration

After you've found the group you want to edit, you can choose the Edit Group page, where you can enter the group name and choose the Get Group Data button.
With the group membership listed, as shown in Figure 12-9, you can make any edits that are needed before choosing OK to save your changes to the database. If you remove users from the group membership list, they may not be part of any group until you edit that user and add them to a specific group.
