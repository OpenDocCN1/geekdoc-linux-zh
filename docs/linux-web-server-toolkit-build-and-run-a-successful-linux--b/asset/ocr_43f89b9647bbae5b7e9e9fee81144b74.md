# Installation Options

There are a few common ways to install software packages in Linux: the rpm package system, the tar format, and the Debian package format.

An rpm formatted package places all files needed for a new piece of software, with startup scripts and descriptive information, into a single compressed file. Using a single command — the rpm utility — you can install a new software package. The rpm command follows the installation script that is stored in the software package file to know where to place everything. It also updates a systemwide database of installed packages, which you can query for information about what is installed on your system.

The rpm format is widely used in the Linux world; you will find that many packages that you want to try are available as a single rpm file.
Another common format is used is tar. The tar format is more universally used in the UNIX world. It is a tape backup format that merges a complete file tree and all of its subdirectories and files into a single file. The tar command is not as flexible as rpm because it requires that all the files be located in a single directory. It also does not provide the descriptive or package database capabilities of the rpm system.
