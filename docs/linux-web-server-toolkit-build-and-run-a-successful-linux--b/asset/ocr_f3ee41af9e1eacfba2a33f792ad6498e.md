# What’s in This Book

Before you can install and create your Web server, you need to think about how it’s going to fit into your organization. Once your Web server is planned, you can install it and begin using it. Day-to-day maintenance then becomes your priority, with occasional decisions to add advanced features as they are needed. This book is divided into four parts that fit those four stages of development for your Web server.

# Part I: Planning Your Web Server

In Part I (Chapters 1-4), you learn about the various business decisions that play into the creation of your Web server. These include how different departments in your organization use or influence the Web site content, what corporate goals the Web site meets, and who has responsibility for different aspects of your Web server project.

# Part II: Installing Your Web Server

In Part II (Chapters 5-7), you learn step-by-step how to install and configure the Linux operating system and Web server software included in the book’s CD-ROM. You also learn how to connect that installed server to the Internet, so that Web site content you create is visible on the rest of the Internet.

# Part III: Maintaining Your Site from Day to Day

In Part III (Chapters 8-14), you learn about the management of your Web server and the creation process for content that you’ll use on your Web server each day. Creating HTML pages and associated server scripts is covers in Chapters 9 and 10. Management tasks like Web server software administration and Web site statistics are also covered in Part III.

# Part IV: Adding Advanced Features to Your Web Server

In Part IV (Chapters 15-21), you learn about features you can add to your Web site to provide value for your customers and make your site more interesting so visitors return often. You learn about Java and JavaScript, and about how to interface your Web site with many other types of data (like e-mail and database systems). Advanced system maintenance that shows you how to back up, secure, and upgrade your Web server software is also covered in this part.
