# Changing Your Network Configuration

If you prefer not to edit text files to update your network configuration with new or corrected information, you can use the LISA utility to accomplish the same things. The LISA utility actually stores your responses in the same configuration behind the scenes, but saves you the trouble of changing each file, learning the syntax of each one, and so forth.

Log in as root to use the LISA utility. Start the LISA utility from a command line as follows:

```
$ lisa
```

The initial screen of LISA is shown in Figure 5-15.

![](bbox=[0.176, 0.523, 0.545, 0.693])

> Figure 5-15: The first screen of the LISA utility, where you can configure aspects of your Linux system (including users, networking, and hardware analysis).

You can configure many things from the LISA menus, including adding new users, configuring hardware devices, and updating your dual-boot information. To check networking on your Linux system, select System Configuration from the first menu, followed by Network Configuration.

A list of network configuration options appears as shown in Figure 5-16. You can choose any of the options to update that part of your networking. When you exit the LISA utility, the configuration files are updated for you. You may need to restart networking on your system to make the changes effective. To do this, log in as root and enter the following commands from any command line:

```
/etc/rc.d/init.d/network stop
/etc/rc.d/init.d/network
```
