The configuration pages for the Administration server that are shown throughout this chapter use HTML frames. HTML frames divide a page into sections which are individually controlled by their links. When frames are used, the Back button in your browser will often not work as you expect it to. It is safer to just use the Back button provided on the HTML page itself.
