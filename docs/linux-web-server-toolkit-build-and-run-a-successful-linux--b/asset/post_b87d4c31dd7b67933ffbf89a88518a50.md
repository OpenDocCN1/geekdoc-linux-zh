# Acquiring an IP Address

A quick answer to how you get a domain and IP address for your site is. As described in Chapter 4, your ISP has control over a block of IP numbers. The ISP can give them out to customers, provided their use is justified. You can't have 200 IP addresses just because you ask for them. It's probably reasonable to ask for it to a dozen or two IP addresses for you directly from your ISP.

You can start this process by going to the InterNIC Web page at http://internic.net/. If you get an IP address from the InterNIC, you will need to give information to your ISP to facilitate routing your network onto the Internet.

Because the Internet is running out of IP addresses, you'll have trouble getting any that you don't need — least until the larger address space, IPv6, is firmly in place.

Remember also that you can use the reserved IP addresses starting with 192.168 for your Internet networks without getting "real" Internet addresses for them. You can also use the IP masquerading feature of Linux to provide live Internet access to an entire network using only one real IP address on the computer that is acting as the gateway to the Internet.

# Acquiring a Domain Name

Getting a domain name is a little easier than getting an IP address, but it can seem like they are running out faster than IP addresses. In addition, domain names cost money.

Domain names used to be free, with the explosive growth of the Internet and everyone fighting for names, a small yearly fee now pays for administration and costs people from grabbing names and not using them. The fee is $50 per year, with the first two years paid at the time of registration.

There are rules, of course, about what your domain name can be, but those rules are probably not as important as the problem of finding one that's not already in use. The main categories that are available to anyone — com, net, and org are so full that it's hard to get the one you want. Part of the problem is that local and state boundaries are not applicable to domain names. For example, of all the radio stations in the country using name K96 or ARROW103.5, only one can have the corresponding domain name.

There are several solutions to that problem. The first is to stop reading and try to get your domain name before someone else does. The value of a certain domain name to an organization can be very high, and this has led to a lot of unscrupulous behavior among some people on the Internet. For example, if you find a site that claims the availability of the domain you want, in some cases the site's owners may register the name you try to check and sell it to you later at a profit. The InterNIC is aware of these problems, however, and is taking legal measures to prevent fraud and unfair treatment of legitimate organizations on the Internet.

The normal method for obtaining a domain name is as follows:

1. For checking conflicting domains using two command-line utilities to search the domain name servers for a server. (Try name-I-want and nslookup name-I-want.)
2. If no conflicts are found, get your ISP to create your domain in the ISP's name server with the appropriate identification information for your organization and the person who administers your Internet connection and server.
3. Go to the InterNIC Web page (http://internic.net/) and register the domain name, paying the fee. This locks up the name for you. After the InterNIC has gone over your application, it will add your name to your name servers, query your ISP's name server, and start propagating your domain through the Internet so that it can be used by everyone to visit your site.

# TESTING YOUR MODEM

To use PPP, you should test your modem to see that it's working. You should know which port it's using (first serial, second serial, and so on). Serial ports in UNIX have several names. If your modem is in the first serial port, it should be named /dev/ttyS0. It's common to use a symbolic link (an alias) so that the file /dev/modem points to the correct serial device for your modem. The Seyon program, which you'll use to test your modem in a moment, always looks for the device /dev/modem. To make your serial device aliased to /dev/modem, enter the following command; if your modem is attached to the first serial port, cua0, the command is:

```
ln -s /dev/ttyS0 /dev/modem
```

Test your modem is functional with the following steps:

1. Start the graphical system with the command startx.
2. Move the mouse pointer into the blue background area.
3. Press and hold the left mouse button so that the menu appears.
4. Move the mouse pointer down to the Applications menu.
5. Move the mouse pointer to the right and down to the Internet Connectivity menu.
6. Move the mouse pointer to the right and down to the first item, Seyon.
7. When Seyon is highlighted, release the mouse button.

The Seyon program starts and tries to initialize your modem. If there is a problem with your modem, you'll see a message to that effect.
