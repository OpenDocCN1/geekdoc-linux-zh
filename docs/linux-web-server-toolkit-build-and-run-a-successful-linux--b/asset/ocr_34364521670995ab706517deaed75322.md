# NESTING LISTS

All three list types can be nested within other lists, to several levels depending on the browser. The browser normally determines how much to indent the list items, how much space to leave between them, the bullet character to use, and so forth.
You can nest lists any way that fits your needs. Bulleted lists can be nested in numbered lists (see Figure 9-7) and vice versa. Definition lists can contain long sections that include ordered lists with bulleted lists as part of one step. You can think of these different lists as tools for controlling the subordination within body text, with the effect shown by indentation in the browser instead of larger text, as with headlines.

> Be careful about nesting lists more than two or three levels. Browsers may treat nested lists in unexpected ways, and readers may lose track of the visual cues as to which level they are reading.
