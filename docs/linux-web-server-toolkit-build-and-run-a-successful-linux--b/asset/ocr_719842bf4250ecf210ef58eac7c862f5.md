# Chapter 11: Configuring the Apache Web Server

The Apache server is already configured and running when you first install your system.

But it also means that you'll want to change some information in each of the configuration files before you're ready to serve Web pages to the world. This section describes how you should alter the httpd.conf file after installation to make it ready to act as a Public Web server.

The changes in the httpd.conf configuration file don't affect system security. They relate to how efficiently your Web server can process requests and serve documents. I recommend that you make the following updates to your httpd.conf file:

+   * If you're very concerned about performance, and don't intend to do much with Web site statistics (as discussed in Chapter 14), change the HostnameLookup directive to off as follows:

```
HostnameLookup off
```

This should be one of the last things you do to improve performance, and should probably be a temporary measure until you improve your hardware, because having hostnames in log files is very useful for statistical purposes and reviewing anomalies.

+   * If you installed your system before your Internet connection was established, check the ServerName directive to see that it contains your true Web server name as you want it to be recorded and propagated. A standard value might be as follows:

```
ServerName www.myservername.com
```

+   * If you expect to have many very slow connections to your Web site, you can increase the timeout value on connections from the default of 400 to something like 1000 (16 minutes). If you are concerned about slow connections dragging your server, you could reduce this to two or three minutes, as follows (this may anger some users, however):

```
Timeout 200
```

+   * MinSpareServers and related directives have default values that are appropriate for a stand-alone using Apache for an online help engine. You should definitely change all these directives for your real Web server. The values are hard to determine precisely without knowledge of your hardware and a solid understanding of the load your server experiences. The following are generally good starting values:

```
MinSpareServers 5
MaxSpareServers 5
MaxClient 200
MaxRequestsPerChild 30
```
