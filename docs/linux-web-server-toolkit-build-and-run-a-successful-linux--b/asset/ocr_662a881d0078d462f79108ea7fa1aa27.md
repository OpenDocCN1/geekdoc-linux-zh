# Maintaining Your
Web Pages

THE LARGER YOUR Web site becomes, the more important it is to your organization.
But large Web sites are a challenge to maintain effectively. When you have numer-
ous people preparing documents for your Web site, maintaining your HTML pages
can be a challenge. This chapter will help you inspect and update Web page content
more effectively. Topics include:

+   * Recognizing problems
* Implementing maintenance processes
* Using spell checking tools
* Using HTML analysis tools

# Recognizing Potential Problems

By their very nature, large Web sites are extremely dynamic – that's why they're so
useful. But that's also why it takes so much work to maintain them. A major site
with several dozen navigation and introduction pages and hundreds or thousands
of other pages of data typically several full-time Webmasters busy building
and maintaining pages.

Many Webmasters find it impossible to stay on top of constant information
updates and changes in technology. As a result, any or all of the following may
occur:

+   * Information on your site is not updated consistently. For example, product
and promotional descriptions, prices, and dates are not current.
* There's a lack of interoffice communication, so vital information is not
post on time.
* Your pages contain errors in HTML code, which cause pages to display
incorrectly or not at all on many Web browsers.
