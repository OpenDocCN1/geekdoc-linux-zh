# 308 Linux Web Server Toolkit

```
AuthUserFile /etc/httpd/apache/users
<Limit GET POST>
require valid-user
</Limit>
</Directory>
```

This set of directives indicates that no document in the protected directory will be returned unless a valid username and password, as found in the UserFile, are provided.

The AuthType is always Basic for now, and the AuthName is always Protected for now. The AuthUserFile or AuthGroupFile is the path and filename containing the users or groups to be checked.

You can use several forms of the require directive. The following form allows any of the users in the UserFile to access documents in this directory:

require valid-user

The following allows only nwells (with the correct password) to access documents in this directory:

require user nwells

And the following form of the require directive allows only users who are listed in the guest and special groups to access documents in this directory:

require group guest special

> The user authentication feature is useful for restricting documents to certain individuals or groups but it does not provide encrypted security. The username and password are sent in cleartext over the Internet to the Web server. Other AuthType options are being discussed by the World Wide Web Consortium and major browser vendors that would allow for encrypted exchanges, but at the time of writing, they were not available.
