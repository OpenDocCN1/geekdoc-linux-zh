OpenLinux includes a full set of utilities and development tools, such as compilers and debuggers, scripting editors, graphical tools, games, Internet tools and servers, command-line utilities and online documentation. It also uses a packaging system called RPM that is popular among many Linux distributions these days. RPM facilitates easy installation and upgrades of software by placing all files for an application plus initialization scripts and other components into a single file. The RPM utility maintains a database of installed software on the system. An example of the power of RPM is that you can install a large, complex program on your Linux with a single command that copies the files, places them in the correct directories, and executes any initialization scripts that are required to set up the program. This simple installation process is also used by the commercial software that Caldera develops, which makes it very easy to add applications to a running Linux system without starting up your C compiler.
