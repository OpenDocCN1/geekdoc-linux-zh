# Summary

This chapter described the use and misuse of Web server statistics, explaining how to find what you want and how to use what you find. You also learned about popular Web statistics tools you can add to your Web server and how to create graphs and even provide the statistical information for those who visit your site. In this chapter you learned:

+   - Web servers record a lot of data in log files. These files can be analyzed by Web statistics programs, but the data must be viewed carefully because of the nature of the log files.
- Many important facts about your visitors and how they use your Web site can be surmised from statistical analyses of the log files.
- Log files include information about who the visitor is, what system is making a request, the Web server response, and more. You can configure some features of loggings or even create custom logging tools.
- Effective log rotation and placing some statistical data on your site for visitors to see are peripheral issues when considering statistics and log files on your site.

In the next chapter, you'll learn about adding additional services to your Web site, so you can have files ready for FTP downloading, accept e-mail from browsers, and use other popular Internet services.
