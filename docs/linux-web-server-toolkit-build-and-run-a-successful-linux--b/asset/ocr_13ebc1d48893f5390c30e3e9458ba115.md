# # Summary

This chapter explained how gateways can make virtually anything accessible via a Web site, and you've seen how valuable that can be to organizations needing to share data that is regularly created or already exists in other formats.
In this chapter you've learned the following:

+   - Gateways are used to make non-Web data types available to those who browse your Web site.

+   - E-mail gateways are useful for processing data from forms that users submit, or for providing Web pages to users who have only e-mail access to the Internet.

+   - Database gateways are an important capability added to many Linux Web servers because much important data is stored in database formats. Web gateways make this data available via a Web browser.
