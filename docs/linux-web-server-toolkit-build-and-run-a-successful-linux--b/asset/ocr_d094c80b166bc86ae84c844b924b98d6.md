# Chapter 14: Additional Information Services

If you set up an FTP site, you can store large files or files in a nonstandard format in the FTP area. Then you can just link from a Web page that describes the item to the FTP site where the file is located. When a user clicks on link on the Web page, a dialog box will appear in the user's Web browser so the user can download the complete file from the FTP site.

Compared to accessing most FTP clients, this Web-based method saves the user of work. Most FTP clients require the user to log in using a separate program and enter some other cryptic commands if it isn't a graphical program.

Using a Web browser lets the user integrate access to the Web site with your Web pages. This is possible because the Web browser actually has FTP client capabilities built in, so it knows how to use the FTP protocol (and others) within the same standardized graphical environment.

# Using Anonymous Login

One reason that FTP became so popular (it's much older than the Web) is that you can use a standard username to log in to any public FTP server and get files from that server. To log in to another system, you need a valid username and password. To log in to an FTP server (or only to the FTP section on server), you generally use the username “anonymous,” and enter your e-mail address as the password.

Whenever a visitor to your FTP site uses the "ftp:// style for a URL to link a Web page to an FTP site, the Web browser automatically uses the “anonymous” user as the login name. In addition to using links that you provide in your Web pages, a visitor to your FTP site can simply enter an FTP URL to use a Web browser to access your FTP site. For example, Figure 14-1 shows a Web browser displaying this:

```
ftp://ftp.caldera
```

If you have your own user account on another server and want to download files from that server using your Web browser, you can use a different username by entering a URL like this one:

```
ftp://myfile@ftp.server1.com/
```

You will be prompted for your password, and then a directory on the server will appear in the browser (which directory depends on your permissions on this server).
