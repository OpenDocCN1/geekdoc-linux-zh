The following examples use the archive device (an Iomega Jaz drive, shown here as a symbolic link from my SCSI device) and compression to dump a complete system archive, starting at the root directory, / directly onto the Jaz cartridge:

```
tar cvWfz /mnt/jaz/12oct97.tgz /
```

Once you have a tar file on your hard disk or a backup device, you can examine the tar file in many ways. The easiest way is to look at a list of what the tar file contains, including the directory that each file goes in. This can help you see which files are part of each archive file and how the filesystem is organized. The following example demos the list of files to another file (a large archive will have a large file list); the list of files, list.txt, can be loaded into a text editor for review:

```
tar tvf website.tar >list.txt
```

Other options let you list the size of each file within the archive as part of the listing of files, restore one from the tar file, or restore the entire tar file. This is called extracting the files from the tar file. Many other options are also available.

> Another UNIX utility called cpio is similar to the tar command and is widely used for backup operations. Many complex backup utilities actually use tar or cpio as the core of their operations, surrounding them with scheduling and tracking features to add backup operations and planning.

# COMMERCIAL BACKUP UTILITIES

Several powerful and commercial backup utilities are available for Linux. You can learn more about these from places such as the Caldera online Linux Products catalog (see http://www.caldera.com/ivpo.html) and the Linux Commercial HOWTO (see http://www.caldera.com/LDP/HOWTO/Commercial-HOWTO.html). One of the best-known of these commercial utilities is BRU (Backup and Restore Utility).

These commercial utilities usually add ease-of-use features to the standard backup techniques of the tar command. For example, you could write your own scripts to define when the tar command archives your system, with separate script lines for each subdirectory to archive and complex cron commands to set the time when the script executes.

If you use a commercial package, you can generally select directories to backup, method of backup, and time to perform backups from easy to use graphical menus or using comprehensive command line utilities that remove the complexities of the UNIX commands.
