# Chapter 20: Backups and Disaster Recovery

+   - Fire or other natural disaster damages your connection to the Internet or destroys your office.

+   - All resources that you use to create Web site content are suddenly unavailable (your designer passes away or your agency goes out of business).

All of these frightening scenarios should be considered if your organization places a high value on your Web site.

# Preparing a Disaster Plan

Without wanting to sound alarmist, the best way to avoid losing sleep over a system failure is to plan on having one. That is, prepare a plan for what you will do in case of each foreseeable failure. Implement that plan by following the actions that you decide. The plan can be a sticky note – the phone number of your friend who can fix anything—or in a red binder behind glass. The following sections outline two plans, one simple and a little more complex. These plans will give you some ideas to base your own plans.

# Simple Disaster Plan

This is the one-page version of a disaster plan. It outlines how to find the solutions to failures so that they don't become problems with no solutions. It doesn't look like much but it's a big help when the person who knows all the answers isn't around. It might look something like the following:

+   - Preparation: Install a Jazz drive and the cartridge.

+   - Backups: Write a script that dumps the data on the hard disk to the Jazz disk every Sunday morning at 4 A.M.

+   - Failures: In case of hardware failures, contact your computer supplier (the name and phone number be included here) for a repair or replacement part. They can usually do this within 24 hours. Reload the Openlinux CD-ROM on the main hard drive if needed, reload the data from the Jazz cartridge.
