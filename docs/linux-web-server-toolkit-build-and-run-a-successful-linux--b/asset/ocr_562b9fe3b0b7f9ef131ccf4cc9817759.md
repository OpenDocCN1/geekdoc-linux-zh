# Chapter 16: Gateways: Providing Everything via the Web

# Other Types of Gateways

There are many other types of information available on the Internet about gateways in addition to those I've mentioned in this book. A Good Web browser supports many formats, including FTP, gopher, multiple graphics formats, and others. But so many formats exist that you'll see many more Web gateways come use in the next couple of years.

The Web is becoming so strong and prevalent in the computer area that any type of information, especially on the Internet, will likely be available via a Web page before load. The other formats supported by a browser are great for reading those formats natively, but more, and more, data will be provided in HTML format to place the burden on the server instead of the client. I say this in spite of the number of client-side enhancements (plug-ins) that allow various multimedia additions to existing browsers.

Some of the data formats or protocols that can be made available now over the Web using gateways include the following (see Table 16-3 for example URLs):

+   * WAIS: Servers providing on the Wide Area Information Service, a server indexing program that you search across many servers for relevant information. (see Table 16-2.)

+   * Finger: The personal information service finger provides a username, full name, and a couple of facts about your user's account, as whether the user is currently logged in. This is a standard UNIX information service that is traditionally entered at a command line.

+   * Newsgroups for newsgroup-capable browsers: Newsgroups are very popular, but not all have the ability to process newsgroups and allow for reading and posting messages. Gateways for the NNTP news server protocol can allow newsgroups to be read and responses posted using standard HTML pages and forms.

+   * Mailing list archives: Described under the e-mail gateways section above, gateways for mailing list archives provides thousands of messages from active mailing lists in an easy-to-read format with searching, indexing, and color-coding of messages.

+   * Other proprietary formats: Other formats, both those on the Internet and those that are created or maintained by businesses for their special needs, are finding Web gateways an ideal way to promote easy access to their information.
