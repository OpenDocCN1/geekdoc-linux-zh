# # Preparing Your Hard Disk

Linux uses a filesystem format that is different from DOS and Windows (of any version). Because of this, it requires a separate partition on your hard disk. This section describes how to set up a separate partition on your hard drive where Linux can be installed. It will also describe how to "share" the hard drive between two or more operating systems (this is called a dual-boot system).

# # Getting to Know Your Hard Disk

A partition is like a slice of your hard disk that is formatted in a certain way. Each partition has a *type* assigned to it lets the various operating systems know how data is stored on that section of the hard disk.

One of the partitions on the main hard disk is marked as *active*. When your computer boots, instructions in the Master Boot Record of the hard disk are read and executed. These instructions generally start the operating system located on the active partition.

Linux, like other operating systems such as OS/2, enables you to install a boot loader that can start any one of several operating systems on the same computer (located on one or several hard disks) each time you turn on your computer. The most popular Linux boot loader (and the one included with OpenLinux Lite) is called LIL0, for Linux Loader. I'll say more more about it later in this chapter.
