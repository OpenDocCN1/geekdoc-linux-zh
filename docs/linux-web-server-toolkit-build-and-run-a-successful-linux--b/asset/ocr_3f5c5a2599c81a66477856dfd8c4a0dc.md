# Linux Web Server Toolkit

The commands in the /etc/rc.d/local file are executed when you start your Linux system and configure your networking within Linux, based on the information in the configuration files.

# Testing Your Network Connection

Before you dive in and try using a Web browser, you can also try some simpler tests to see if your network configuration is accurate. More information about setting up your network, including setting up high-speed connections, is provided in Chapter 6.

To try these tests, go to a command prompt either at the character mode screen or within the graphical system. The ping command simply sends a packet to a computer and receives an acknowledgment packet return, without exchanging data. If you can reach another computer, you know that basic networking is functioning. First, try the ping command to your own machine as follows:

```
$ ping localhost
PING sah.venture.com (127.0.0.1): 56 data bytes
64 bytes from 127.0.0.1: icmp_seq=0 ttl=64 time=2.0 ms
64 bytes from 127.0.0.1: icmp_seq=1 ttl=64 time=1.2 ms
64 bytes from 127.0.0.1: icmp_seq=2 ttl=64 time=1.1 ms
64 bytes from 127.0.0.1: icmp_seq=3 ttl=64 time=1.5 ms
```

+   - venture ping statistics
4 packets transmitted, 4 packets received, 0% packet loss
round-trip min/avg/max = 1.1/1.4/2.0 ms

Stop the ping command by pressing Ctrl+C.
Localhost is a special hostname that every UNIX system has; it refers to itself. With this command, you are pinging yourself. This works on UNIX you can connect from one process to another in a multitasking operating system. If pinging localhost works, it means that one portion of your network configuration is working correctly.

Next, try to ping a machine on your network using that machine's IP address, as follows:

```
$ ping 208.142.216.118

64 bytes from 208.142.216.118: icmp_seq=3 ttl=92 time=34.4 ms
```
