# Table 9-4: Standard HTML List Tags

| Tag | Description |
| --- | --- |
| <UL> | Unordered list (bulleted list). The browser inserts bullet before each item in the list and indents the entire list. Unordered lists require an ending tag. List items are marked by the <li> tag. |
| <OL> | Ordered list (numbered list). The browser inserts a number before each item in the list and indents the entire list. The ordered list requires an ending tag. List items are marked by the <li> tag. |
| <DL> | Definition list. The browser indents the list items and definitions. Requires an ending tag. List items are of two types: <DT> tags with some indentation. Definitions are marked by <DD> tags, usually with further indentation. |
| <LI> | A list item for an ordered or unordered list. Requires no paragraph <P> tag, as a separate line is implied. No ending tag is required, but is still suggested. |
| <DT> | A term within a definition list. Indented. This tag is intended for short words or phrases and can be used in multiples before a <DD> tag. |
| <DD> | A definition within a definition list. Indented further than a <DT> tag. Intended for paragraph blocks of text. This can be used in multiples after a <DT> tag to split the definition of a Term into several paragraphs |

# BULLETED LISTS

Bulleted lists are the most common type of list in an HTML document, and referred to as unordered lists because the items in the list are not associated with numbers (like steps).

A bullet list starts with the <ul> tag (for Unordered List) and must end with a </ul> tag. Between the opening and closing tags, each item in the list should be enclosed in <li> and <li> tags (for List Item). The ending </li> tag is very often omitted without problems because the browser can easily tell what's happening when the next <li> tag appears or the list ends with a </ul> tag.
