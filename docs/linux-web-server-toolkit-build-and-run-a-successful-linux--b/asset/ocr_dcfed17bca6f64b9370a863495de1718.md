You can exit the fdisk utility and return to the installation program by entering the q command (for quit).
After the partition information is written to your hard disk, you'll see a message that you need to reboot your computer so the partition table on the hard disk can be reread and everything reset. This is a little annoying at this point, but if it didn't happen, you'd risk having all Linux information written into the wrong place—on top of OS/2, for instance.
Follow the onscreen directions to reboot your system and follow all the same steps up to where you started the fdisk utility. But this time you don't have any changes to make, so you can answer No and continue with the installation.
