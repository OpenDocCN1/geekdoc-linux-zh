# Looking at the X Configuration File

Configuring the X Window System has become a lot easier in the last two years, but that's not to say it's really easy. The graphical utility you just used helps a lot, but it also hides a lot of complexity and a few options that you might need someday.

The configuration file /etc/XF86Config is read each time you start X by entering startx. While some video cards require special commands in this configuration file that aren't covered here, some basic information about how the file is arranged can help you troubleshoot problems. For more information, you can read the online manual pages by entering one of the following commands:

```
man 5 XF86Config
man X
```

There's also a separate manual page entry for each of the XFree6 servers. You can try any of the following commands to learn more about a particular X server:

```
man XF86_Accel
man XF86_Mono
```
