# # CD-ROM Installation Instructions

The following instructions guide you through the steps of starting the OpenLinux Lite installation program.

There are several methods you can use to start the OpenLinux Lite installation program. A lot of newer systems have bootable CD-ROM drives. Try the following experiment to find out if your drive is bootable:

+   - Place the book's CD-ROM in your system's CD-ROM drive.
- Restart your computer (turn it off and on again or use Ctrl+Alt+Delete).

If a banner with the Caldera name appears on screen, you have a bootable CD-ROM drive and the installation program will start.
If the Caldera banner does not start, follow these steps:

+   - Place the accompanying CD-ROM in your system's CD-ROM drive.
- Go to a DOS prompt with no other programs running, including TSR or background programs.
- From the DOS prompt execute the following command from the OpenLinux Lite CD-ROM directory.

```
E:\COL\LAUNCH\DOS\LOADIN.EXE
```

This command dumps DOS from system memory and starts the Linux installation program.
If neither of these things worked, you'll need to create an installation floppy disk to boot your system. The information to make the floppy is on the CD-ROM as well as in the following steps

To make an installation floppy disk, follow these steps from an existing DOS system. These steps apply to making a 1.44MB disc on floppy drive A: Using another size or location of floppy drive is also possible and is described in the README file on the CD-ROM.

+   - Insert the accompanying CD-ROM into your CD-ROM drive.
- Insert a blank floppy disk.
- Enter the following command (changing the drive letter to match the CD-ROM drive on your system).

```
E:\COL\TOOLS\RAWWRITE3
```

+   - Enter the drive letter for your floppy drive.
- Enter the name of the installation floppy image on the CD-ROM:

```
E:\COL\LAUNCH\FLOPPY\INSTALL.IMG
```
