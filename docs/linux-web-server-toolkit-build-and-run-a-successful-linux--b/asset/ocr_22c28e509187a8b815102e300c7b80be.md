You should make the swap partition at least 16MB. If you can spare the hard disk space, it wouldn't hurt to make it 32 or 64MB. And if you have a lot of RAM — 128MB or more — you could move towards the maximum swap partition size of 128MB. There are a lot of tricks UNIX experts use to fine-tune the speed of their systems, like putting the swap partition on a separate hard disk, or placing different parts of the filesystem on different hard disks according to how that part of the filesystem is going to be used (for example, home directories versus program files).

# USING THE FDISK UTILITY

Back to the installation—after you finish with the Kernel Module Manager, you are asked if you need to alter the hard disk partitions on your system. If you answer Yes, a menu appears that lists the hard disks on your system. When you select a hard disk, this option runs the Linux fdisk command, where you can create the partitions you need from the free space on your hard disk.

Choose the correct disk if more than one is installed on your system (you should be able to tell which one you want by the size that is listed for each hard disk).

A black screen appears with partition information listed for the hard disk that you selected. You are now running the Linux fdisk command. Keep your wits about if you've got another operating system sharing this hard disk. It's a simple process, but you could ruin your other operating system data if you're not careful (hence I told you to back up everything). The basic commands in fdisk that use are shown in Table 5-3. I'll walk you through the process next.

# TABLE 5-3 Basic Commands of the Linux fdisk Utility

| Command | Description |
| p | List partitions on the hard disk. |
| n | Create a new partition from existing free space. |
| a | Mark a partition as active (checked by the initial boot process). |
| t | Mark a partition as being of a certain file type. |
| d | Delete an existing partition (use with caution). |
| w | Write the changes you've made and exit the utility (use with extreme caution). |
