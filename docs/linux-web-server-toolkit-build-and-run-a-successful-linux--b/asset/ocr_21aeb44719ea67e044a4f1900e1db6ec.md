# Chapter 18: Web Security Issues and Internet Firewalls

Internet is addressed by your computer system. For example, if an FTP request arrives from an FTP client, this file tells the correct FTP server to go ahead and handle the FTP request. If an e-mail message arrives at the server, this file specifies the e-mail correct server that will route the message. A part of the /etc/inetd.conf file is shown in Listing 18-1. If you alter the /etc/inetd.conf file by removing or commenting-out lines, then kill any running servers that monitor those ports, those services won't be provided, and the packets addressed to them will not be routed to those servers.

Listing 18-1: Part of the /etc/inetd.conf file, which specifies how packets arriving on specific network ports are to be served

```
# <service_name> <sock_type> <flags> <user> <server_path>
args
# Echo, discard, daytime, and charger are used primarily for
testing.
# To re-read this file after changes, just do a killall -HUP inetd
echo stream tcp    nowait root    /usr/sbin/tcpd in.ftpd -l -na
telnet stream tcp    nowait root    internal
echo dgram udp    wait   root    internal
discard dgram udp  wait   root    internal
discard dgram udp  wait   root    internal
daytime stream tcp  nowait root    internal
daytime dgram udp  wait   root    internal
charger stream tcp  nowait root    internal
charger dgram udp  wait   root    internal
#
```
