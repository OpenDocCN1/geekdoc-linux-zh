To set the permissions of any file so that everyone can read it, use the chmod command at any command line prompt. You must be logged in either the root user or as the user who owns the file named in the chmod command in order to use this command. The command is shown in the following example:

```
chmod a+r filename
```

# SERVERADMIN

The ServerAdmin directive gives the complete e-mail address of the system administrator who should be notified of any problems with this Web server. The address listed in the ServerAdmin directive is used by the Web server to send e-mail to the Web administrator if a problem is found. The directive is used as follows:

```
ServerAdmin root
```

The OpenLinux default is root, because your domain name isn't automatically known. You should change this value to your complete e-mail address. It's common to use Webmaster as the user here, but if you do, be sure to set up an e-mail alias for Webmaster in /etc/aliases.

# SERVERROOT

The ServerRoot directive specifies the directory where the server's configuration files, error logs, and log files are stored, as shown in the following:

```
ServerRoot /etc/httpd/apache
```

Files in the ServerRoot directory are not visible to users browsing your Web site. Specific filenames for the configuration and log files can also be set using other directives described in this section.
