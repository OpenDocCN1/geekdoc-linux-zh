# E-Mail Gateways

E-mail on the Internet is actually more popular than the Web. The Web just gets all the good press. That is, even more people have e-mail accounts than have Web browsing access, and anyone who can browse the Web has an e-mail account as well.

For these reasons, one of the most-used types of gateways on the Web is an e-mail gateway. There are two types of e-mail-to-Web interfaces, both of which can be called gateways. They are the following:

+   - Gateways to send Web pages to people with only e-mail access
- Gateways to forward Web page form data as e-mail

# Gateways to Return Web Pages by E-Mail

Many people who want to access the Web don't have the ability to browse Web pages because of country restrictions, router restrictions, delays over the Internet, or other problems. All these users can really do on the Internet is receive e-mail.
