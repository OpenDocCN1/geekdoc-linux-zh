Figure 13-2: The wwwstats program creates a comprehensive file of transfer statistics for the period covered in the access log. The top part of the large browser-viewable page is shown here.

Because it's so popular, wwwstats also has several programs that work with the data it generates, including gwstat for graphing the results (see Table 13-1 for a list of statistical tools). Wstats was written by Roy Fielding. It's available from http://ics.uci.edu/WebSoft/wwwstats.html.
