# What Being Connected

Connecting to the Internet means very simply that you are connected to the world-wide network of computers that we commonly call the Internet. Depending on the security restrictions you place on your system, you can connect to anyone else's computer that's connected to the Internet and anyone else's computer on the Internet can connect to your system. It's a lot like a peer-to-peer network in your office using a networking operating system such as Windows for Workgroups, Lantastic, or Personal NetWare.

# TERMINAL AND PEER CONNECTIONS

Remember in Chapter 4 the discussion about peer connections and terminal connections? A terminal connection lets you see the output on your screen from a program that is running on another computer, which may be connected to the Internet. If you're using only a terminal-emulation-style connection, no one on the Internet can connect to your computer, and you can't provide services - a Web page - to anyone on the Internet. All you have a "window-dow," to, because you're not on the Internet, or a terminal to, a machine that can do those things because it's connected to the Internet.

A peer connection, on the other hand, means your computer has equal status with all the other computers on the Internet. As a peer, you can exchange files between your computer and other Internet computers to which you have access rights.
