To use DNS, a computer on a network specifies a name server where computer looks to see how a hostname converts to an IP address.
All DNS name servers on the Internet are configured to exchange updated information regularly on hostnames, domains, and IP addresses using the DNS protocol. Each name server maintains large tables that are used to respond to inquiries from networked computers.
Many computers attached to the Internet, even as Internet servers, use the Domain Name Server of their Internet Service Provider rather than setting up and configuring their machine as a name server. We'll talk about the basics of setting up a name server in Chapter 7, but it's not a simple task.
Another thing you should know about hosts is that there are two ways that a computer on a network can find the IP address of another computer from its domain name. Each computer that uses IP addresses has a file called hosts, which contains lists of computers with their domain names and their IP addresses. The operating system can look in the hosts file to see if a computer is listed. This saves the time of sending a request over the network to the name server to resolve the name into an IP address. If the name of the computer is not listed in the hosts file, the name server must be used to determine the IP address.
