## What Makes a Web Site Bad?

There are also common things that some Web sites include that make them less than they could be. Many of these “bad” elements are just the opposite of the “good” things listed earlier.

## Bandwidth-Hungry

Bandwidth-hungry sites assume that the user has nothing to do wait for their pretty pictures or huge text files to download. But there are so many tools and tricks that Web sites can use to decrease the bandwidth needed to load a page. Examples of these techniques include such as employing reduced color palettes in graphics, reusing the same graphic to take advantage of caching, using tiny Javascript applets, breaking large documents into sections with navigation bars and links, and so forth. Leaving huge downloads in your pages is careless unless a specific application requires them, in which case you can note the size for the user before he she selects the link.

The worst place for a huge graphic is where everyone wants to put: the first page of the site. Everyone would like to use graphics to make the best impression, others often want to visit or revisit a site quickly to see if anything new has put up or to see what the company's site has to say or looks like.

How do you handle this dilemma? Good design techniques can enable you to include large, colorful graphics while also reducing the color palette used and the compressed size of the file (GIF is a compressed graphics format). Small graphics wisely around the page, especially if you can use tables, make the whole page look nice even though most of it is text, which transfers very quickly. Graphics and HTML are discussed in Chapter 9.

## Unprofessional Design and Content

Web sites used to consist mostly of bulleted lists with a logo at the top. Now people spend thousands of dollars to have sites designed by Web professionals. These professionals are simply designers who have carved a new home for themselves in the Web market. But make no mistake, a skilled designer's work really stands out on a site.

Chapter 9, which covers HTML page creation, gives details on points to avoid, but some of these are easy to identify. It's a shame that so many sites don't follow these guidelines:

- Don't use more than three fonts on a page.
- Don't vary font size or style too much on a page.
- Don't use all capital letters.
- Don't fill an entire screen with text without graphics or even margins and page breaks.
- Don't ramble. Be concise in your writing.
- Don't use background images or color combinations that make the text hard to read (even professionals regularly do this, for some reason).

There are more don'ts, but you get the idea.

## What Feel Should This Web Site Have?

To get consistent, strong design, even from a professional Web designer, you should provide direction for the "feel" of your Web site you intend to create. One of the greatest things about the Web for small businesses (and there are a lot more small businesses online than large businesses) is that everyone can look as big as they want on the Web. All you have to do is decide how to use a look that says what you want to say about your company.

For example, even a small company can decide to have a conservative, corporate feel on its Web site. To do this, might forego the fluorescent colors that so many employ, use more graphic elements and fonts, and write the HTML pages to reflect a conservative approach. Another organization might want to highlight what a fun group of people works, so your site could be very colorful, with graphics and copy that reflect a less stuffy approach. Both goals are perfectly valid. Each looking to achieve a different end.
