# CLIENTS AND SERVERS

When people use a gateway or server in their organization to browse the Web or access their e-mail, they are, in a certain way, connected to the Internet. Depending on their network, they may have several different types of access, but they are accessing the Internet only as a client. They are using only client software, such as a Web browser; they are not using a Web server.

This is also true of many online services, such as America Online, which provide client access to the Internet for users to read newsgroups, browse the Web, and so forth. They don't allow users to provide any services to other computers and users on the Internet. They may provide a separate service called Web hosting (covered in this chapter) but they are not providing a complete connection to the Internet.

# FULL-TIME OR PART-TIME

The Web is always open. This means people can access it at any time of the day or night, no matter what part of the world they are located in. A Web server and the information you place on it aren't a grocery store, where you can place a “Closed” sign up so you don't have to staff the store 24 hours per day. On the Web, if you're closed, you don't exist at all, and a customer is likely not to trust you when you might be open.

This is another difference between a Web server and the client, many people are more familiar with: the client connections are part-time. People log in, read e-mail, and log out. After that session, they have no connection whatsoever to the Internet.

A Web server requires a full-time connection, which means it is available 24 hours per day, seven days per week. A Web server requires a different type of connection from the dial-in connection you might use to browse the Web. A Web server might still use a modem (as you'll see later) but its connection certainly costs more than a client connection.

# Connection Options

Several issues are important to consider when you plan your Internet connection. The major ones are discussed in the sections that follow.

# HOSTING

One option many people use for their Web presence is called Web site hosting. This refers to your ISP having a dedicated area on one of its Web servers where your Web pages are stored. The ISP manage the use of your domain name with your permission so the ISP Web server actually responds to browser requests for your Web address. It just looks to your customers as though you have your own site, but you don't really have an in-house Web server.
