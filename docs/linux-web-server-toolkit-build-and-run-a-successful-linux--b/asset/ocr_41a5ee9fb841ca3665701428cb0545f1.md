# Linux Web Server Toolkit

You can't edit the user information here, but this page is useful for finding the exact username so you can pull up the information for editing in the Edit User page (which is discussed next).

To list the users, select the database that you want the list taken from and press the Show button. If you want to restrict the number of users listed, you can enter a pattern in the Filter field, as j* to list all users (login names) starting with the letter j. After you enter something in the filter field, press the Show button again to update the list of users shown.

# Edit User

The Edit User page is very similar to the Create User page, except that you start the process by pulling information from a user that is already in the database.

First, you enter a login name that you want to edit and press the Get Data button (Make sure the correct database for the user you want to edit is selected from the drop-down list.). The data for the login name you entered is shown in the fields, where you can edit them and then choose OK to save your changes to the user information.

# Create Group and Remove Group

Creating a group involves only a group name, just like in Linux. A group is like a container. You can assign users to one of the groups you create, and then grant access to any of your Web pages based on which group a user is part of. This makes it much easier to grant access to a large number of individual users. Access is granted to the group, and doesn't need to be altered by adding users regularly. Each new user is simply a member of the group when that user account is created. All access granted to the group will be available to the user immediately.

To create a group, select the database that the group should be part of, then enter a name for the group. Remember that group membership cannot cross databases.

Removing a group is just as easy. Select the database that the group is part of and enter the name of the group in the field provided on the Remove Group page.
If you remove a group, all access control selections based on that group name are invalid. None of the users will have access as is granted only to a group that doesn't exist any longer. If you remove a group, you can't restore it without creating a new group and editing the profile of each user to be sure the user is listed as being in the correct group.

# List Groups and Edit Group

Listing and editing groups works just like listing and editing usernames. First, you can use the List Groups page to see all the groups that are part of any of the user/group databases on your system. You can use a filter to reduce the number of groups listed if needed, as m* to list all the groups that start with the letter m.
