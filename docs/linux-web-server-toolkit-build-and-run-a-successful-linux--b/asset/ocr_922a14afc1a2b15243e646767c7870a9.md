# # Launch: Starting the Installation

The Launch directory contains programs that start the OpenLinux installation process. The CD-ROM provides several methods of starting the installation, mostly using the programs in the different subdirectories of the Launch directory. The different methods of starting the installation process are as follows:

+   - If you have a bootable CD-ROM drive, place the CD-ROM in your CD-ROM drive and restart your computer. The installation program will begin.

+   - Create an installation floppy diskette using the rewrite.exe program. Use the disk images in either the floppy subdirectory or the 2.88MB subdirectory. Boot your computer from the Installation 이때 that you created. The process for creating these diskettes is described in Chapter 5, as well as in the README file in the floppy and 2.88MB subdirectories.

+   - Start your computer in DOS and execute the loadlin program contained in the DOS subdirectory.

+   - If you have an existing Linux system used, use the instructions in the README file of the Linux subdirectory to boot the OpenLinux kernel in that subdirectory.

Additional options are contained in the Special subdirectory, but these are only used if you are having trouble installing OpenLinux on your hardware. See the README file in that subdirectory for more information.

# # Pgp-Keys: Security Information

The Pgp-Keys directory contains the public keys for Calder, Inc. These keys are given here so that you can confirm patches and security bulletins from Calder are signed by a valid Calder public key. Thus, you can be certain that they really come from Calder, Inc.

More information about the PGP security system is included in the online documentation (see the Doc directory described previously). The README file in the Pgp-Keys directory also describes the PGP keys and how they are used.
