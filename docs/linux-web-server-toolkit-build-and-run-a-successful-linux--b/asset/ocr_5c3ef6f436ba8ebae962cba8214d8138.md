# Working with New Packages

The OpenLinux system uses a software packaging format called RPM. This format was mentioned in Chapter 4 on installation. It's the Red Hat Package Management system, developed by Red Hat Software. It allows a single file to contain all the pieces necessary to install and run a complete software package, along with the scripts and startup information needed to prepare your system to use it.

For example, an RPM file can contain a description of a software package, the program files, instructions on how to store them, and an installation script that it runs when the program is first installed.
