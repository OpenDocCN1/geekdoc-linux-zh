# Linux Web Server Toolkit

A domain is like a network. It usually corresponds to the IP class address that you receive from the INTERNIC. For example, if you receive a Class C address of 192.45.13.x (you define the last number for your computers), you might decide on a domain name of scrutatime.com for the network defined by your Class C address. Each computer that you place on your Class C network will have a hostname such as marketing, ocean, or anything you choose. You assign each computer specific IP address within your network. For example, the computer ocean might be assigned the IP address of 192.45.13.7. Using the computer's hostname, and the domain name of your Class C address, scrutatime.com, the complete name of that computer on the Internet would be ocean.scrutatime.com.

In larger organizations, which typically have Class A addresses, domain names may be assigned to larger and smaller networks. The California Institute of Technology has a Class B IP address starting with 131.215. While the entire network is caltech.com, smaller networks are also defined within that large address space. For example, a network in the Chemistry Department might have the IP address of 131.215.48.1-255, with the domain name of chem.caltech.edu. A single computer connected to the Internet in that department might have a full domain name of carbon.chem.caltech.edu, with an IP address of 131.215.48.33.

These simplified examples show how an address and a name can be mapped to make things easier for humans. Any IP address can be mapped to a computer with any domain name and hostname. In this way, your Internet Service Provider can control your domain name for you on its DNS server, while you own the IP addresses that the domain name is mapped to.

In every case, to access that computer in the Chemistry Department, an IP address must be used. DNS is the system that maps the IP address of that computer to the domain name that we can easily understand.

DNS is included with all Linux distributions, including OpenLinux Lite. The ability to request an IP address for a hostname, known as resolving the name, from a DNS server is installed by default and provides easy connectivity to the Internet using the domain names that we all associate with the Internet. You can also install a DNS server on your Linux computer so that it will act as the one mapping the IP addresses to hostnames for other computers that send requests for name resolution.
