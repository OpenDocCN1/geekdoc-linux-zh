# Automating the Administration Server

If you've installed the Netscape FastTrack Server on an existing OpenLinux or other Linux system, you may need to add a command to your initialization files if you want the server to start automatically when you boot your system.
nYou can do this by adding the following line to the file /etc/rc.d/rc.local to start the FastTrack Server program:
nYou can do this by adding the following line to the file /etc/rc.d/rc.local to start the FastTrack Server program:

```
/opt/fasttrack/bin/httpd
```

> You don't have to start the administration server at boot time. The administration server is started automatically whenever someone requests the URL with the administration port that you defined in the configuration.
