# Placing Files for FTP Use

You can have any file available for FTP download, including an HTML file. If you use your Web browser to view an FTP site and it points to an HTML or cleartext file, the Web browser will usually display the contents instead of a download log box. You can create a download dialog box for any link (including any link on a Web page) by holding down the Shift key before you click on a link.

All you need to do is make a file for FTP download from your Web site is place it in the correct directory with correct permissions and make a link to it your Web pages. For example, suppose you have a file called demo in your home directory. Assuming you are logged in as root, you can use these commands:

+   1. Make a subdirectory for all related programs.
mkdir /home/ftp/pub/myprograms
2. Copy the program to the FTP area.
cp /home/tom/demo/home/ftp/pub/myprograms
3. Change the file permissions so that anyone can read (download) the program.
chmod a+r /home/ftp/pub/myprograms/demo
Now just include a link in one or more of your Web pages like this:

```
<A HREF=http://ftp.server1.com/pub/myprograms/demo >Try our new demo version</A>
```

# FTP Site Administration

Although FTP is set up and working automatically on your OpenLinux system, there are many other features you can offer additional services to users, to track how your FTP service is being used, and to make it more secure if it's used a lot.

When an anonymous user logs in to FTP site, a message is displayed for the user to see. This is the file welcome.msg, located in the directory /home/ftp/

Most of the FTP administration settings are saved in a set of files located in the /etc directory. These include the files ftusers, ftgroups, and ftaccess. The default contents of the ftaccess file, which is the only file you must have, are shown below:

```
class all real. guest. anonymous *
-email root@localhost
```
