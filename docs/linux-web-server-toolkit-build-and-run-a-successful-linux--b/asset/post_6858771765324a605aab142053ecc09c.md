
# To Anne

# Preface

Imagine being able to provide your customers, no matter where they reside, with immediate access to your organization's most current information. A Web server can do just that—it can provide a unique and comprehensive communications medium.

Many of you may find the thought of setting up and maintaining a Web server daunting. It can also be a very expensive endeavor if you don't choose Linux as an operating system. In fact, and what you'll learn as you read this book, the process is not overly complicated. You'll need to install an operating system, configure your Web server software, and create the content for your Web site.

This book provides all of the software you need for a Web server and instructions on how to use that software. It describes each of the steps for installing a powerful 32-bit Linux operating system, configuring Web server software, and maintaining that server from day to day.

Setting up a Web site without first considering related business issues can lead to wasted resources and a poorly designed site that visitors find uninviting. Perhaps a worse, a lack of technical understanding about the Web may mean your site isn't designed to be efficient and friendly for your customers, or it may open your organization to security risks.

This book walks you through the business issues you should consider as you set up a stable, secure Web server. But more than that, it's a toolkit that provides all the software and instructions you need to set up and manage a new Web server as it becomes a key part of your organization's communication.

This book teaches you how to:

- Effectively plan your Web server as a cohesive part of your business strategy
- Determine what content will be placed on the Web server
- Install the Linux operating system included on the book's CD-ROM
- Configure and test the Web server software included on the book's CD-ROM
- Create simple Web pages in HTML
- Add functionality to your Web server, such as statistical charts, Java pages, database connectivity, and so forth
- Complete system management tasks on your Web server, like backing up the server and upgrading software packages

# This Book Is For You

If you are responsible for determining the feasibility of setting up a Web server for your organization or for actually deploying that Web server, this book is for you! This book provides a clear understanding of how your Web server software interacts with the operating system (Linux) and with the Internet as a whole to deliver Web pages to those who visit your site. In addition, this book describes how to create Web server content: the HTML pages and server scripts interact with those pages. Finally, this book shows you the things you'll need to keep your Web site in secure working order.

This book assumes that you are familiar with basic computer terms like "disk drive" and "keyboard," but you don't need to know anything about the Internet, the Web, or programming. If you are familiar with the UNIX operating system or with using command line utilities, the sections on configuration in Chapter 5 and the scripts in Chapter 10 will be more familiar territory.

# What You Need Before You Begin

To get the most out of this book, you should have an Intel-based computer as your Web server. A Pentium system is preferred, but a 486 will also work. The computer should have at least 16MB of RAM; 32MB is highly preferred and 64MB is nice, depending on how busy your Web site ends up being. You will install the Linux operating system on either a separate hard drive or a separate partition that you create on your main hard drive. In either case, you should have about 500MB of free space to install the operating system and install your Web pages. A 3.5-inch floppy diskette and a CD-ROM drive are needed to install the Linux operating system.

You also need hardware to connect to the Internet. This is discussed at length in Chapter 7, but basically you need either a modem or high-speed connection like an ISDN modem or frame relay board. The software to use these devices is included in the book's CD-ROM or with the hardware itself.

# The CD-ROM

The CD-ROM included with this book is the complete OpenLinux Lite product from Caldera, Inc. (see http://www.caldera.com). It includes all the Web server tools and utilities you'll need, as well as many that don't apply to using a Web server that you might find interesting (a great version of Tetris, for example).

Note that Chapter 10 includes a few sample scripts, but these are not included on the Caldera CD-ROM. These sample scripts are not long, so it shouldn't be tedious to use them straight from the book.

# What’s in This Book

Before you can install and create your Web server, you need to think about how it’s going to fit into your organization. Once your Web server is planned, you can install it and begin using it. Day-to-day maintenance then becomes your priority, with occasional decisions to add advanced features as they are needed. This book is divided into four parts that fit those four stages of development for your Web server.

# Part I: Planning Your Web Server

In Part I (Chapters 1-4), you learn about the various business decisions that play into the creation of your Web server. These include how different departments in your organization use or influence the Web site content, what corporate goals the Web site meets, and who has responsibility for different aspects of your Web server project.

# Part II: Installing Your Web Server

In Part II (Chapters 5-7), you learn step-by-step how to install and configure the Linux operating system and Web server software included in the book’s CD-ROM. You also learn how to connect that server to the Internet, so that Web content you create is visible on the Internet.

# Part III: Maintaining Your Site from Day to Day

In Part III (Chapters 8-14), you learn about the management of your Web server and the creation process for content you’ll use each day. Creating HTML pages and associated server scripts covers Chapters 9 and 10. Management tasks like Web server administration and Web site statistics are also covered in Part III.

# Part IV: Adding Advanced Features to Your Server

In Part IV (Chapters 15-21), you learn about features you can add to your Web site to provide value for your customers and make your site more interesting so visitors return often. You learn about Java and JavaScript, and about how to interface your Web site with many other types of data (like e-mail and database systems). Advanced system maintenance that shows you how to back up, secure, and upgrade your server software is covered in this part.
