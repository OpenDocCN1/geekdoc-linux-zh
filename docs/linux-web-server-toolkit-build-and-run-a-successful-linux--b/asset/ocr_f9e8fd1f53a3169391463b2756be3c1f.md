# WEB SERVERS

First, there are Web server programs – the software that makes your computer capable of sending Web pages to browsers. The next chapter talks about the many that are available for Linux, both free and commercially supported. Web servers are robust and fast. Many also secure transaction capabilities using First Virtual, Verisign, or similar technologies. The following list gives just a few of the Web servers available for Linux:

+   - AOLServer from America Online (at http://www.aolserver.com/server/index.html)

+   - Apache from the Apache Project (at http://www.apache.org)

+   - Stronghold SSL Web Server, based on Apache, from UKWeb (at http://stronghold.ukweb.com)

+   - Netscape FastTrack for OpenLinux from Caldera, Inc. with an exclusive license with Netscape (at http://www.caldera.com)

+   - Zeus httpd server from the National Center for Supercomputing Applications (at http://hohooo.ncsa.uiuc.edu)

# FIREWALLS

Most Web servers also require security between your computer systems and the Internet. Firewalls are the most common way of providing this.

There is commercial firewall software available for Linux. These packages allow you to configure which network packets reach your Web server or other computers into your network, as well as plugging up many potential security holes.
