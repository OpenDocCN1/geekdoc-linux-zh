In many cases, you'll see just a blank screen and a cursor after you complete the installation of X. Press the left mouse button to see a menu of options, which will always include Shells or something similar, from which you can open a commandline window to start programs.

The screen that you see is controlled by the window manager, which is a lowlevel program that provides the graphical services to programs, allowing them to interface with the lower-level X Windows System interface. The window used by OpenLinux (and many other Linux systems) is called fwm. Other window managers for Linux include Motif (a commercial product) and twwm.

When you have a window open in X, you can resize it, move it, and minimize or maximize it, just as in other windowing systems such as Macintosh or Windows. The fwwm window manager can be completely configured using text files. explore the text files in the directory usr/X11R6/lib/X11/fvwm.
