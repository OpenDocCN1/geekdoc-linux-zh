# BUTTONS

The buttons on a form cause the browser to take action. While other elements wait patiently while a user enters data, as soon as a button is pressed, the browser does something. Basically, the browser can do one of two things: clear the form using a Reset button or submit data to the server using a Submit button.

If you include a Reset button on the form, the browser will clear all the fields on the page and redisplay it. This provides a convenience for users in many cases but is not strictly necessary. In a browser, it's not too hard to Reload or an equivalent button. But the Back button on a browser will generally retain the user's data, so a Reset button can help.

A Reset button is created with the <INPUT> tag using TYPE=RESET. No name option is used, because there is no user data passed as part of the button being pressed. You can provide a VALUE, which will be the text displayed on the button. If you don't provide a VALUE options, the word "Reset" is displayed on the button.

The second action a browser can take is to submit the form data to the web using a Submit button. The Submit button is identical to the Reset button, except that instead of clearing the form, it packages up the data, and sends it to the URL listed in the ACTION option of the <FORM...> tag.
