# The Relationship Between the Internet, the Web, and UNIX

Unless you've been hiding under a rock, you know that the Internet is a global collection of networks, all tied together by high-speed communication, and that the World Web defines only a type of data. Many Internet servers (servers connected to Internet) don't include the ability to transmit Web data. Even so, the Web has become the most widely known and marketed part of the Internet.

Because Linux is basically a UNIX operating system without the trademark, I'll begin this discussion with a little background on UNIX and how it relates to the Internet.

# Web Server Toolkit

In the early stages of the Internet, all the computers connected to it were large UNIX systems running university computer centers, government installations, and corporate data centers.

UNIX was ideal for a networked connection because it was designed for it. UNIX is multiuser, so remote users with network connections could be logged in at the same time. That also meant UNIX had to have a set of security standards to allow users to keep their information private (that security is a bit less now than it was back then). Because of the environment in which it was developed, strong networking systems were important for UNIX from the beginning. Connecting to the Internet just meant connecting to an extra wire; the networking was already part of the operating system.

So how does Linux fit into this picture? The standards that drive the Internet all, except for Java, come from UNIX. Because Linux was designed as a UNIX clone, Linux also included the same Internet standards from the beginning.

# How Alternate Operating Systems Measure Up to UNIX

The features discussed above are in sharp contrast to other operating systems. DOS machines were first built to be inexpensive, small enough to fit in available RAM. Thus DOS had no multiuser or multitasking capabilities, no security features—turn it on and start working—and no networking features, because it was always intended to be used as a standalone system. In fact, Microsoft DOS (the most-used version) still doesn't have any of those features, although the DOS 7 underneath Windows 95 has the beginnings of some of them.

All of the networking capabilities of DOS and Windows were added after the operating systems were completed. This means that DOS and Windows networking don't include support for all UNIX and Internet standards. Even with add-on packages, parts of DOS and Windows actually interfere with complete integration into the Internet. For example, the multitasking of UNIX networking through the use of ports and streams can't really be duplicated in DOS or Windows.

So now aren're glad you're using Linux? Linux provides a real UNIX-like operating system, and its power wasn't just an afterthought.
