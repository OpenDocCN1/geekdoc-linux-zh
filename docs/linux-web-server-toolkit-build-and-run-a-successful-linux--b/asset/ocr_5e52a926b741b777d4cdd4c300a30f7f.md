Each line includes how many hits come from that domain. The last three in this list are from German, French, and Italian hosts, respectively. While I wouldn't use these numbers as hard figures (as I mentioned earlier, they are not true indicators), they nevertheless can be taken in summary to tell you how prevalent each nation and other type of host are among visitors to your site.

For example, if you are starting to advertise in Germany and you see your hits from German hosts grow from 1 percent to 5 percent of your site's total traffic during the week that advertising begins, you can be fairly certain that your advertising is at least increasing awareness of your organization in Germany.

You'll probably be shocked to the number of counts listed in your statistics. The two-letter country codes used can be cryptic (see the statistics programs for an interpretation), but don't be surprised if you see visitors from 50 countries listed.

One caveat to be aware of: Many international users have .com addresses. They connect through an Internet provider who has U.S. connections, to provide faster access or to avoid discouraging U.S. contacts who think they're too far away. You will miss some international contacts in this statistical analysis. You'll know them only when you get an e-mail in German with a .com return address.

# HOW MANY PEOPLE VISIT MY SITE EACH DAY?

This is a tricky question, but a very important one. With printed advertising, you can't expect a sale every time person sees your ad, but you want to know how many impressions you're making on a potential customer. All the rules don't hold true, but knowing how many users come to your site tells you a lot about how well you are publicizing it and how it is received and revisited.

The quick-and-dirty (and inaccurate) method of determining a user count is to simply use the number of hits. That is, "we have 5,400 hits, so we have 5,400 people visit our site." This method doesn't work, for all the reasons outlined earlier in this chapter.

A simple way to determine the number of unique users who visit your site is to run statistics for a single day and count the number of unique hostnames listed in that report. This doesn't account for people using the same hostname as a Web gateway, but it makes a fairly accurate guess.

If you generate daily statistics file, you can load it into a text editor, chop everything but the hostname list, then use the following command to see how many lines are in the remaining file (the first number that we reports is the number of lines).

```
$ wc hostname_list
452 1786 47.866
```

This method doesn't work well beyond a single day because you want to know if people are revisiting your site on multiple occasions. Counting hostnames within an entire month-long period doesn't account for that. (See the question below repeat visits.)
