# Linux Web Server Toolkit

If you're thinking of using Web hosting, setting up a Linux-based Web server as an in-house staging area can still make good sense. You can create all the pages exactly as you want them to appear, then have them uploaded to your ISP. But you don't have to have a high-speed, permanent internet connection.

Personal users who want a home page or a small business Web hosting as a low-cost means of achieving a Web presence. The ISP server is always up and running and provides good bandwidth for those reading your pages. Small Web pages can be added to your home page without extra charge; these personal Web sites often allow users to include up to 5MB of HTML and graphics files. Because they are hosted on your ISP's computer, a personal Web site like this will usually have a URL that refers to your domain name. For example, if a large ISP is hosting Web sites for several businesses, they might each have a home page URL that looks like this:

```
http://www.fastnet.com/~travelers/index.html
```

Not all ISPs are equipped to provide Web hosting, but larger sites can offer the additional service of your own domain name, which is administered by the ISP and points to its server. This always costs extra (usually at two to three times as much), because a domain name implies a business account. But it's certainly impressive for a business to have a URL such as the following:

```
http://www.travelers.com
```

The benefits of hosting may outweigh the disadvantages for some users. In my opinion, the falling cost of a complete Linux Web server on an Intel computer makes hosting less attractive every month. Table 7-1 goes into more detail about the differences between Web hosting and on-site Web servers.

# Table 7-1 Web Hosting Versus On-Site Web Servers

| Attribute | Hosted Web Server | Your Own Web Server |
|---|---|-|
| Control | Less control — you don't control the Web server configuration and you must log in to change anything. | You control all aspects of the Web server configuration and have immediate access to all your files. |
| Flexibility | You probably can't do as much with scripts and server add-ons. Most hosting sites will expect simple HTML and graphics pages. | Anything goes — all the advanced features that make for great Web sites are available to you. |
