目前有很多电子邮件网关软件包可用，表 16-1 列出了其中几个。大多数此类软件包都是免费提供的，因为创建一个电子邮件网关是一项简单任务，特别是在 Linux 上。一旦脚本收集了 Web 页面所有的表单数据，就可以使用单个命令发送电子邮件，或者打开一个标准数据管道将数据直接发送到电子邮件服务器进行处理。

你可以尝试使用 Perl 或如 bash 的 shell 脚本编写你自己的简单电子邮件网关。如果你愿意，可以使用表 16-1 中列出的优秀且免费下载的软件包之一作为代码示例来指导你。我尝试在表 16-1 中标明该电子邮件网关是需要你极少投入的通用解决方案，还是一个你可以用来为自己的表单或 网站需求定制解决方案的工具包。

请记住，这些网关位于 Web 服务器和电子邮件客户端之间，某些工作是双向的。这些并不是不同类型电子邮件系统之间的网关。这些软件包都使用 Linux 和 UNIX 上的标准电子邮件系统以及用于电子邮件的 SMTP 标准。它们不允许你从 Lotus CC: 发送到互联网，或从 Novell MHS 发送到 Lotus CC:。那需要与我们所讨论的不同的网关。

还有其他类型的软件可能也被称为电子邮件网关。一种是一种在你感兴趣的 Web 页面更新时向你发送电子邮件通知的服务。

另一种是能够自动提供邮件列表存档作为 HTML 文档集合的软件包，维护讨论线程和时间顺序，并在文章之间创建方便的链接。我认为这二者对电子邮件网关的定义都有些宽泛，但它们都有用，你可能在某点需要它们。

对于许多 Web 服务器来说，另一种重要的网关是数据库网关，它允许数据轻松地传递到 Web 页面中。这些网关将在下一节中描述。

# 数据库网关

Web 数据库网关可能是网关技术最重要的用途。我之所以这么说有两个原因。首先，使用 Web 作为递送机制可以消除开发专门数据库客户端软件的需要。在许多情况下，这减轻了软件开发人员的巨大负担。

你可能还记得几年前的一些特殊的数据库客户端开发工具。例如 Borland Object Vision 等工具的出现，其主要重点是方便创建一个特殊的数据库客户端，以访问组织内部某处的大型数据库。但是，即使你花费了时间创建一个 Object Vision 程序来访问数据并美观地显示在用户的屏幕上，你仍然只为了一个平台提供了支持。如果另一个部门的人恰好有另一种系统（Macintosh, Amiga, UNIX），那么 Object Vision 程序就没有任何帮助。

为 Web 服务器配备数据库网关将所有的编程和开发都放在 Web 服务器上。这不像 Object Vision 那么容易（尽管有很多工具可用；见表 16-2），但它很好地解决了更大的问题：一旦你写了程序使数据库信息可以通过 HTML 文档或表单可用并升级，组织的每个人都可以访问这些信息。

数据库网关之所以如此关键，是因为存储在数据库格式中的业务信息比任何其他格式都多。网关允许通过 Web 将所有信息的潜力传递给用户。

由于世界各地数据库中存储了大量的业务信息，数据库网关是产生商业参与最多的网关类型。因此，除了针对专用系统和通用解决方案的许多商业解决方案外，你还有许多用 Perl 或 C 编写的、免费供下载尝试的强大方案。

这些软件包中的一些是工具包，你可以根据数据库的要求设计你自己的脚本。另一些是完整且通常复杂的系统，它们将与特定类型的数据库接口。表 16-2 描述了几个数据库网关产品。记住，这只是可用产品（免费和商业）的抽样。
