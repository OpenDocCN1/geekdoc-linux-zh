# Summary

In this chapter, you've learned about the security that you should put in place to protect your Web site from prying eyes and wily hackers. You've learned about some of these dangers and how you can protect your Web site using standard Web server configurations and other tools like firewalls.

In this chapter you learned:

+   - Security issues are a key part of managing any computer system, especially one connected to the Internet. Security threats come in many guises, and the hackers behind them have a variety of goals.
- A Web server can use several simple precautions to improve security. These include careful review of scripts run on the Web server and watching log files for suspicious activity.
- Firewalls are an important part of a secure system. They can take several forms, including packet-level filters and application proxies that restrict the actions that can be performed via a network.
