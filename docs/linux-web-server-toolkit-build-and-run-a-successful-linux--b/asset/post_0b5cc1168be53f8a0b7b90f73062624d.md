# Installing OpenLinux Lite

In this section, you'll install the OpenLinux CD-ROM onto your computer system by following the onscreen prompts and the step-by-step instructions that I'll provide. # Starting the Installation Program

There are several methods you can use to start the OpenLinux installation program. A lot of newer systems have bootable CD-ROM drives. Try the following experiment to find out if your drive is bootable:

- 1. Place the book's OpenLinux CD-ROM in your system's CD-ROM drive.
- 2. Restart your computer. (turn it off and on again or use Ctrl+Alt+Delete).

If a banner with the Caldera name appears on screen, you have a bootable CD-ROM drive. If that doesn't happen, follow these steps to start the installation program:

- 1. Place the accompanying OpenLinux Lite CD-ROM in your system's CD-ROM drive.
- 2. Go to a DOS prompt with no other programs running, including TSR or background programs.
- 3. From the DOS prompt, execute this command from the OpenLinux Lite CD-ROM directory:

```
E:\COL\LAUNCH\DOS\LOADLIN.EXE
```

This command dumps DOS from system memory and starts the Linux installation program.

If neither of these things worked, you'll need to create an installation floppy disk to boot your system. The information to make the floppy is on the CD-ROM as well as in the following steps.

To make an installation floppy disk, follow these steps from an existing DOS system. These steps apply to making a 1.44MB diskette on floppy drive A: Using another size or location of floppy drive is also possible and is described in the README file on the CD-ROM:

- 1. Insert the accompanying OpenLinux Lite CD-ROM into your CD-ROM drive.
- 2. Insert a blank floppy disk.
- 3. Enter this command (changing the drive letter to match the CD-ROM drive in your system):

```
E:\COL\TOOLS\RAWWRITE
```

- 4. Enter the drive letter for your floppy drive.
- 5. Enter the name of the installation floppy image on the CD-ROM:

```
E:\COL\LAUNCH\FLOPPY\INSTALL.IMG
```

If you want to create the floppy from an existing Linux system, you can use the dd command instead:

```
dd if=/mnt/cdrom/col/launch/floppy/install.img of=/devfd0
```

> The install.img file is a disk image. This type of file is an exact copy of everything that needs to be on the installation disk. The latest, greatest installation disk images may not be on the accompanying CD-ROM because updates occur frequently. Later images may include additional security fixes, hardware support, or updates. If you're concerned about hardware support or having the latest security information, check the Caldera Web site. There may be a later installation disk image.

You may also want to make a modules disk from the disk image in the same directory. The modules disk contains all the extra kernel modules that you might need to recognize your hardware. It's fairly common to need a modules disk, and it saves the trouble of coming back to this point and restarting if you make the modules disk when you make the installation disk.

# Hardware Identification

The installation program now tries to recognize the IDE devices on your computer and shows a list of what it finds. After you press Enter, you are asked whether all the devices needed to install your system were listed.

> You need to have your Ethernet card recognized if you want to install the network using Network File System (NFS). Otherwise, you can add your Ethernet card later. Of course, it is more convenient to do it all during installation.

At this point in the installation process, you should have your hard disk and your CD-ROM drive listed (if you're going to install from CD-ROM). If you don't see one or the other listed, you'll need to autoprobe or manually load a kernel module in order for the OpenLinux program to recognize them. If a hardware component on your system is not listed but is not needed to complete the installation (for example, a sound card), don't worry about right now. You can easily set that piece of hardware after the installation is completed by loading a module or performing a couple of alternate steps.

If you know what hardware is missing from the list, such as a CD-ROM drive or a SCSI adapter, your best bet is to go to the Kernel Module Manager screen of the Installation program by selecting No when autoprobing is offered as an option. If you're not sure what's missing, autoprobing is a good choice.
