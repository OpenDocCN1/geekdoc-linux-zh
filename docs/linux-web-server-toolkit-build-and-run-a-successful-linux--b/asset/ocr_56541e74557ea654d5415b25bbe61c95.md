I will assume here that you have a network card installed that was recognized by the installation program. In this case, answer Yes to the question about having a network card.

The default device in the next screen will usually show as eth0. This refers to the device located at /dev/eth0, which is the first Ethernet card or something else, such as Token Ring; if your networking card is something else, you can enter device instead (Token Ring will be tr0).

As requested in each of the screens that follow, enter the IP address of your system, the network mask, the broadcast address, and the information about your router/gateway if you have one.

Finally, if you have a DNS name server that you will use to convert from domain names to IP addresses, enter Yes, and enter the IP address of the name server (as shown in Figure 5-7). The name server might be another machine on your local network or a computer at your Internet Service Provider. Even if you use this machine as a DNS name server, you can enter the IP address of another name server, such as the one at your ISP. It's normal to have a primary and secondary (or backup) name server, so that your system can still resolve names to IP addresses if one name server machine is unavailable for some reason.
