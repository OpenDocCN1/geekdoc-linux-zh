The XF86Config file is divided into sections. Each section gives information on a part of the hardware: the pointing device, the monitor, the video card, and so on. Each of these sections can contain several devices, with an arbitrary name given to each one. The final section of the file tells how to put the devices together to display in a certain mode.

For example, a subsection of the final section might say something like: Use monitor A and video card B with this resolution. This explanation is greatly simplified, as you see. Three important sets of keystrokes to know when using X are following:

+   * You can usually switch between different resolutions listed in the configuration file by holding down the Ctrl + - keys on the 10-key keypad. This can be disabled in the configuration file.

+   * You can exit X back to character mode by pressing Ctrl+Alt+Bksp. This keystroke command can also be disabled (either on purpose, or by a really bad crash).

+   * You can switch to character virtual consoles while leaving X running by pressing Left-Ctrl+Left-Alt+F2 or F3, and so on. The console from you started X will not be usable (usually this is console F1). You can switch back to graphics mode by pressing Left-Alt+F7.

You can view the XF86Config file after you create it with the XF86Setup utility by entering the following command:

```
more /etc/XF86Config
```

The main sections of the XF86Config file are described in the sections that follow.

# THE XF86CONFIG FILE

This section of XF86Config lists the files that are used by the X server. Specifically, it lists the fonts and color files. Each font path, for example, is a directory for a size or type of font. These are used when X presents a list of available system fonts to programs. The files are listed as follows:

| Section Files |
| RgbPath | /usr/X11R6/lib/X11/rgb |
| FontPath | /usr/X11R6/lib/X11/fonts/misc:unscaled |
| FontPath | /usr/X11R6/lib/X11/fonts/75dpi-unscaled |
