There are two points to note on this code listing. First, in the permissions list on the left side of each line, if the first character is a "d", this indicates a directory instead of a file. The remaining access permissions are then listed, first for the owner, then for the others.

For example, at the first line in Listing 4-3, for the file Anne_ws. The owner of this file is nwells, the group assigned to this file is users. The permissions block on the far left breaks like this: the first character is blank (shown as “-\”), so this is not a directory. The next three characters (r w ) are the permissions granted to the owner, nwells. He can read and write this file, but not execute it, because it is not a binary program or shell script. The next three characters (r -- ) are the permissions granted to everyone in the group users. They can read this file, but they cannot write it (change or update it). Finally, the last three characters of the permissions area,-- -- are the permissions granted to anyone who is not logged in as nwells or as a user who is a member of the group users. Because of these permissions are set, the other users cannot read the file.

The second thing to note about Listing 4.3 is that the group is the same as the owner for many of the files. Several Linux systems use a concept called User-Groups in which a group with a single user is created by default for each new user. This provides additional security on a system with many users who are not associated in their work (such as an ISP server).

To change the owner, group, or permissions of a file, you can use command-line utilities or graphical utilities. More instructions on using and learning about different command-line utilities are provided in the next section. Table 4-7 lists the command-line utilities you can use to change owner, group, or access permissions to a file.

# Table 4-7 Commands for Changing File Owner, Group, and Access Permissions

| Command | Description | Example |
|---|---|--|
| chown | Change the owner of a file or directory (you must be the owner or the root user to change the owner) | chown nwells /etc/testfile |
| chgrp | Change the group assigned to a file or directory | chgrp testgroup /home/testing |
| chmod | Change the access permissions to a file or directory | chmod og+w /home/testing/file1 |

You can also use the OpenLinux Lite Desktop interface (described later in this chapter) to change ownership and set access permissions for any file or directory.
