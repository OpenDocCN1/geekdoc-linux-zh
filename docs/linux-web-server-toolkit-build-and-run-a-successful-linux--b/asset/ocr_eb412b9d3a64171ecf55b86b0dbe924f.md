# SOFTWARE PACKAGES INCLUDED

The Internet contains much software for Linux than a single distribution can include. Although all distributions will include standard items like the X Window System from the FreeX86 Project, Inc., the inclusion of many other pieces is at the discretion of the people who create the distribution. Even if you buy a distribution and all the software packages that you wanted on its CD-ROM, the default installation may not put everything wanted on your system. You then have to spend additional time locating and installing specific packages.

Software packages are installed using one of several common methods that may ease the installation process. These include the Debian package format, the RPM package format (widely used), or simple tar files (supported by all UNIX and Linux systems). Installing packages from a CD-ROM other than your original distribution usually causes inconsistencies in your system's database of installed software.

# PHILOSOPHY

Besides the technical issues just discussed, most creators of a distribution have a philosophy, or a particular mission for their product. They aim their products at a certain part of the market and have certain goals in doing so. Understanding the goals of the company whose you use is also important. It affects to some degree all of the technical factors mentioned in the previous sections.

For example, if you believe strongly in the free software model, you might select the Debian distribution even if you're a novice user who might otherwise prefer an easier installation program. However, the philosophy of Debian developers leads them to choose certain packages for default installation while avoiding entirely the commercial add-ons offered with other Linux distributions. This might affect your decision should you desire completely different default installation packages.
