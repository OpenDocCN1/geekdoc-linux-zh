# Chapter 6: Installing Your Web Server Software

# Configuring the Administration Server

Once you have installed FastTrack, you need to configure it before using it. Because the configuration utility installs right into the browser as its final step, it's helpful to start the config utility from within a graphical window. If you don't know how to do this, instructions are provided at the end of this section.

When you're ready to complete the configuration, you can start the configuration by changing to the FastTrack directory as follows:

```
cd /opt/fasttrack
```

Then run the configuration utility with the following command:

```
./config
```

The following screen appears:

Netscape Communications Corporation Netscape FastTrack Server QuickStart Installation

This program allows you to configure and install a new server. Configuration for the server will be done through a forms-capable network navigator.

To start configuration, you must enter your machine's full name. A full name is of type <hostname>.<domainname> such as foobar.widgets.com

To accept the default shown in brackets, press return: Full name [www.tommy.com]:

If you configured your networking correctly as described in Chapter 5, correct, fully qualified hostname is shown in brackets, and you can just press Enter to accept the default hostname and continue with the configuration of the administration server. Your hostname may not start with www as in the previous example. You can easily configure the server name to point to any machine name you choose when www is used. For example, if you had a machine named pisa.tommy.com, you can make the name actually go to pisa.tommy.com by configuring the DNS name server. (This is described in further detail in Chapter 7.)
