# Making the Connection

This section describes the steps to follow to set up your connection. It assumes that you have an account with an ISP and have decided on a connection type (modem, ISDN, relay, and so on). While I'm trying to provide all the detail I can in these sections, the complications can be tricky at times. It's a good idea to keep your ISP's support number handy.
