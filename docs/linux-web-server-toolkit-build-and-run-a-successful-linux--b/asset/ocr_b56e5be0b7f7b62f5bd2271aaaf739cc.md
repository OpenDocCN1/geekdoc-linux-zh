# LINKING WITHIN A DOCUMENT

I suggested keeping Web page short – to three screens when possible. But sometimes that doesn't make sense. You need more information on one page. Links using the <A> tag allow you to jump to a certain point within a document, including jumping to a different point within the same document.

For example, if you decide to have a long document as a single Web page (in a single file), you could have a table of contents at the top of the document, with links on individual sections. When a reader clicks on the browser automatically scrolls the large document down to that particular section of the document.
