Although copyright protects only the expression of an idea (not the way it was created), there aren't a lot of different ways to create the same effect in HTML. The safest thing to do is to study other people's Web pages to learn about the things that are available. When you're going to start creating your own, start from a blank page, with only your HTML tag reference sheet beside you.

The second danger is the quality of other people's pages. HTML syntax checkers and spell checkers aside, many people post documents that are incorrectly formed, or use sloppy forms or poor tagging practices (running all the tags and text onto one line so you can't read anything unless viewing the page in a browser). You can learn a lot by reviewing other people's work, but you can also learn techniques and habits. Decide on some sound practices for your formatting and learn what the correct format is for your HTML tags.

# Creating Basic Pages

The simplest HTML page consists of just a headline and a few paragraphs of text. These pages still need the meta tags that define a well-formed HTML document, and they are very simple to create. Here's an example of a basic HTML page:

```
<HTML>
<HEAD>
<TITLE>My First HTML Page</TITLE>
</HEAD>
<body>
<h1>My First HTML Page</h1>
<P>
```
