# Chapter 6: Installing Your Web Server Software

After you press any key to continue, the configuration utility starts to configure the FastTrack Server program. Because this is done via a browser, you start by entering the name of the browser that you want to use for this configuration. Netscape Navigator is the default. You should enter here the command to start the browser from a command line, with any parameters you need to make it work on your system (color or display options, for example), as follows:

```
Network navigator [netscape]:
```

After you enter this command name for the browser, the configuration utility will attempt to start the browser pointing to the administration server.
If you've been running the configuration utility in character mode, the browser won't work (unless you made it display on another machine). You will still see the command that the utility is trying to execute, however. You will recognize the port you selected for the administration server. It might look like the following:

```
Attempting to run:
netscape http://www.tommy.com:7070/ &
```

If this doesn't work because you're in character mode, or if you want to stop configuring the FastTrack Server right now and come back to later, just re-enter the URL that appears on your screen, with your machine, port, and so on, in your browser. You will enter the administration server and can configure the FastTrack Server from there at any time.

# Starting the Administration Server

After you've configured the administration server you can start it up from a Web browser on any computer that is allowed to access the administration server. To start the administration server, just use the port number you defined during the setup in the last example. For example, you would enter the following URL:

```
http://www.tommy.com:7070/
```

An authentication window appears, where you must enter the administration username and password. These are the ones that you entered during the configuration.
After you have entered the the administration username and password, the first screen of the administration server appears in the browser window. This screen is shown in Figure 6-3.
