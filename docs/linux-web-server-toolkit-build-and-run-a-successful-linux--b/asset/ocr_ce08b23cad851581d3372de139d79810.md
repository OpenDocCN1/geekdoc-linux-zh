# Linux Web Server Toolkit

# TABLE 8-1 Top Search Engine Sites for Web Site Registration (Continued)

| Site | Description | URL |
|---|---|--|
| Altavista | A complete searchable word index of the Internet. This site is used by millions every day. It's usually very helpful if you know what you want, but it can give you a flood of information on every search. | http://www.altavista.digital.com |
| InfoSeek | A category-based catalog of Web sites; this site is good, but it's not as popular as Yahoo. | http://www.infoseek.com |
| Lycos | A category-based catalog of Web sites; this site is good, but it's not as popular as Yahoo. | http://www.lycos.com |
| Webcrawler | A category-based catalog of Web sites produced by an automated searching program, in conjunction with submissions from sites. | http://www.webcrawler.com |
| Virtual Library | A topical index provided by the World Wide Web Consortium; it's very good for academic subjects but not widely used anywhere. | http://www.w3.org |
