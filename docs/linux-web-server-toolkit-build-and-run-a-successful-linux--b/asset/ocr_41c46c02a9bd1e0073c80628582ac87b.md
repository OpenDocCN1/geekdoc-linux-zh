# Table 4–6 Access Permissions to Directories

| Permission | When Granted to Owner | When Granted to Group | When Granted to Other |
| --- | --- | --- | --- |
| Read | That user can list the files in the directory (but any user who knows an exact filename doesn't have this right to the directory). | Any user in that group can list the files in the directory. | Any user on the system can list the files in the directory. |
| Write | That user can create new files in the directory. | Any user in that group can create new files in the directory. | Any user on the system can create new files in the directory. |
| Execute | That user can alter subdirectories in the directory. | Any user in that group can alter subdirectories in the directory. | Any user on the system can alter subdirectories in the directory. |

When you're trying to determine why someone can't access a file or directory, you need to see the owner, group, and permissions for a file are currently set to. You can view these settings for any file or subdirectory by entering the ls command with the long option at any Linux command-line prompt. Listing 4-3 shows the output of the long option for the ls command.
