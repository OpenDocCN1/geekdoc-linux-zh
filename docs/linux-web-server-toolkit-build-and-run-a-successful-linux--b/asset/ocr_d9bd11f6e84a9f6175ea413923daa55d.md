# Linux Web Server Toolkit

The graphics tag is the first tag I've mentioned in this book that uses a parameter. The tag for a graphic is <IMG> but it has to be used with the name of the graphics file, which is given inside the tag as part of the SRC parameter (for source file). The filename of the graphic is enclosed in quotation marks. Here are some example image tags:

```
<IMG SRC=/graphics/logo.gif
<IMG SRC=http://www.usabank.com/images/banner1.gif
```

Following are a couple of other points about the filename of a graphic:

+   - The path and filename are case sensitive. They must match the directory and filename on your Web server exactly.
- A common error is close to the IMG tag with an angle bracket, forget the closing quotation mark. The rest of the Web page won't work very well if you do this.

<IMG> tells a browser to place a graphic in the middle of the screen, with no text on either side. Your first thought might be inflexible that is, or how much you want to do with your document design. You can place graphics vertically anywhere on a page by adding parameters inside the IMG tag or using other tags like the <FIG> tag. For information on these advanced uses of image placement, see an HTML reference like Creating HTML 3.2 Web Pages, 3rd Edition, from ID Books Worldwide. Until you become familiar with these modifiers, you should place IMG tags on separate lines between two <P> tags, the unlinked image is guaranteed to be a small one that fits on a line.

The example shown next and as displayed in a browser in Figure 9-8 shows a simple document with an IMG tag used to add a small logo to the headline and a larger graphic in the body of the text.

```
<H1>IMG SRC= graphics/logo.gif >Welcome to Utah</H1>
<P>This Web site introduces you to some of the spectacular scenery and travel opportunities waiting for you in the state of Utah. Let s start by seeing a few scenes from the five national parks in Utah.
<P>This is Bryce Canyon National Park.
<P><IMG SRC= graphics/bryce.gif
```
