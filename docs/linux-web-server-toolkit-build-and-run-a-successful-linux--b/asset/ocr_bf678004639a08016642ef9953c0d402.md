# # Basic Scripting and Forms

ONE of the MOST important uses of the Web is providing an interactive service for those who visit your site. This chapter explains how to construct basic forms and write simple scripts to interact with the forms. Topics covered in this chapter include the following:

+   * Understanding how scripts work
* What server-side includes are and how to use them
* Creating standard forms in your HTML documents
* Writing simple scripts to use forms on your site

# # Understanding most How Scripts Work

One of the most powerful features of your Web server is the ability to send to a browser information that is tailored to an individual request – data that matches exactly what the user wants instead of just a copy of an existing file on the server.

While you can't read the user's mind, scripts allow you to receive instructions from the user (via a browser) that can be used to give individual attention to the document that is returned to the browser. You've probably seen this in your browser. It's most obvious when you see a fill-in form like the one in Figure 10-1, which you use to submit and receive back information based on what you entered in the form. That's the type of thing we're going to cover in this chapter.

There are at least three ways that you can create personal interaction with a user:

+   * Server-side includes (sometimes called SSI); these are described briefly in this chapter.

+   * Scripts on the server, using the Common Gateway Interface; this is the focus of this chapter.

+   * Javascript and Java programs that come from the server and are executed by the browser; these are described in Chapter 15.
