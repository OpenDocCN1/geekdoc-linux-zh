# USING THE POST METHOD

Though the GET method is convenient for things such as submitting query strings, most forms use the POST method to send information back to the server. The advantages of the POST method for forms are twofold, as:

+   - You can send as much data from a form as you want — several thousand characters if necessary — while GET is very limited in size.

# Using Environment Variables in Scripts

The Web server automatically sets many environment variables that can be used by your scripts to examine the conditions under which your script invoked. Though each Web server adds its own environment variable, the following table lists that you should be able to use for any Web server, including the Apache Web server.

Accessing the information provided by these variables allows advanced scripts more precisely to determine what HTML text to return to users. For example, using the HTTP_USER_AGENT variable, a script might decide not to use some advanced features in the document that it returns because the user's browser doesn't support them.

# 10–3 Environment Variables Accessible by Scripts

| Variable | Description |
| --- | --- |
| SERVER_SOFTWARE | The name and version of the Web server calling the script; for example, Apache 1.0.3. |
| SERVER_NAME | The hostname of the computer running the script; for example, www.traveltips.com. |
| SERVER_PORT | The port that the Web server is running on, usually 80. |
