The rpm command has hundreds of options, which you can start to explore by entering the following command at any OpenLinux command prompt:

```
rpm -help | more
```

A simple command to query the package database to see that the Apache Web server is installed is the following:

```
rpm -q apache-httpd
```

# Basic System Setup Options

The Apache Web server uses three configuration files for all basic system setup options: HTTPD.CONF, SRM.CONF, and ACCESS.CONF. Other options are handled through additional utility programs (located in /USR/SBIN and listed in Table 6-1) or through features such as server-side includes that are not directly related to a configuration file.

The three configuration files are located in the directory /etc/httpd/apache/conf. Table 6-2 provides descriptions of each.

| Configuration File | Description |
| --- | --- |
| httpd.conf | Core Web server configuration, such as which user to run the server as, and where the log files are stored |
| srm.conf | Details of where Web document files are located and how requests from browsers are to be processed and displayed |
| access.conf | Access control and security information for the Web server; who can access files in each document directory, and so forth |

Two copies of each of these files are included in the /conf/ directory. One copy has -dist added to the end of the filename and should be left unaltered as a backup to the default values that were originally installed. For example, you should not alter the file access.conf-dist because it is the backup to access.conf. The files listed in Table 6-2 are the files that are actually read by the Web server.
