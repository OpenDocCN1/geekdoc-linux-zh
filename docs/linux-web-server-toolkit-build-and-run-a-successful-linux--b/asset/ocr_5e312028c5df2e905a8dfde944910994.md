HARDWARE SUPPORT
All of the special hardware that you might need to set up a Web server or a complete Internet server is supported by Linux. That includes terminal servers, ISDN boards, frame relay boards, router boards, high-speed networking cards, 256-port serial cards, and more.

In Part II, you will read more about using some of these peripherals as you decide how to connect your Web server to the Internet. Specific information regarding some of the most popular hardware options is provided in Chapter 4.

# HTML CONVERSION TOOLS

Many conversion filters are available to help you create HTML documents from your existing material. If you have documents in WordPerfect, Word RTF, FrameMaker, LaTeX, text files, or many other formats, free filters are available for Linux. Several commercial filters are also available. The following list shows popular HTML tools (see Chapter 1 for a more comprehensive list of cross-platform conversion tools:

+   - Empress DataWEB from Empress Software, Inc. (at http://www.empress.com)
- LaTeX2HTML, a free software project (at http://cbl.leeds.ac.uk/nikos/latex2html/html/latex2html.html)
- Web+, a Web-to-database integration tool from Talentoft (at http://www.talentoft.com)
- WebTuk, a free graphical HTML editing tool (at http://www.sunscript.sun.com)
