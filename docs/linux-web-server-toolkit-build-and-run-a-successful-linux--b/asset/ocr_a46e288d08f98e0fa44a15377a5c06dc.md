# Sources: Source Code to Software Packages

The Sources directory contains the source code to most of the software packages contained in OpenLinux. The source code is contained in an RPM package format, just like the program itself (the binary). All source rpm are contained in the SRPMs subdirectory of the Sources directory. You can install a source code RPM using the rpm command, just like you would install a binary program file, as described in Chapter 21.

Note that not all programs include source code packages because of the licensing terms that the programs are distributed under.

# Tools: Preparing for OpenLinux Lite Installation

The Tools directory contains several utility programs that you may need to use as you prepare to install OpenLinux Lite. The three programs in the Tools directory (each contained in its own subdirectory) include:

+   - Loadlin, a program to start the OpenLinux installation program from within DOS. This program is also contained in the /col/launch/dos directory, but the /col/tools/loadlin directory contains additional documentation about using the loadlin program.
- Rewrite, a program used to create installation floppy diskettes from disk images stored on the CD-ROM or the Caldera FTP site. This program is also contained in the /col/launch/floppy directory, but the /col/tools/rewrite directory contains additional documentation about using the rewrite program.
- Fips, a program used to change the size of a DOS partition on your hard disk without erasing the data on that partition. In effect, the Fips program splits a DOS partition into two partitions, one of which contains no data. You can then delete this partition and make it your Linux partition before installing OpenLinux. The use of the Fips program is described in the documentation contained in this directory, as well as the installation steps in Chapter 5.
