# Linux Web Server Toolkit

If you want to use NIS, choose Yes at the next screen. NIS, the Network Information System, is a type of distributed network resources management system created by Sun. The implementation of NIS in Linux is good, but a little limited. I won't be talking about it in this book, but if your local network uses NIS or NIS+, you can choose to be an NIS client so you can be managed by the NIS system.

Next, choose whether your system clock is using Local Time (with a time zone) or GMT (Greenwich Mean Time, with a + or - to indicate the local time). UNIX systems use GMT because they want to know the time relative to networks that connects to. Local time is used by DOS and Windows, so if you're using one of those operating systems on your machine as a dual-boot system, you should use Local Time. Choose your time zone as shown in Figure 5-8.

> Figure 5-8: Choose your time zone. The time zone is used to mark files and e-mail with the correct time at your location. For e-mail, this will also appear relative to GMT, so recipients around the world can tell when the e-mail was sent.

Choose your mouse type. This is used only for the DOS emulation configuration file. You'll need to select your mouse type again when configuring the X Window System.

Enter the correct information to set any printer that you have connected to your system, including page size, and so on.

Enter a password for the root user (superuser) of your system. If you forget this password, you'll probably have to reinstall your system. Enter the password twice to be certain you typed it correctly.

Because the root user can do absolutely anything on a UNIX system, you should log in as root only when you are doing system administration tasks as creating new users. Create a regular user account for your day-to-day work using the adduser command as:

```
adduser nweils
```

During the installation, a regular user named col (CalderaLinux) is created for you.
