# Chapter 7: Connecting to the Internet

Next, set up an options file for the PPP program. This file must be stored as /etc/ppp/options. The following is a good sample to start with:

```
# PPP options file
mru 296
crtscts # use hardware handwriting
modem # use the modem control lines
defaultroute # make this the default route for all network traffic
```

Finally, you can execute the pppd command to make the connection to your ISP. Just use this command line, adjusting for the device used by your modem:

```
pppd /dev/ttyS0 115200 connect chat -f /etc/ispconnect.chat
```

This single command says to connect – don't wait for the remote computer to respond – using the given device at a speed of 115200 baud. The script is executed before the pppd command and prepares the connection that pppd uses.

![](bbox=[0.03, 0.468, 0.11, 0.526])

> Always use a higher speed than your modem when defining your connection. The speed in the previous pppd command indicates how fast data can be sent to the modem. If your 33.6k modem has a burst using compression of 90K, you don't want the data stream from your programs to hold up its progress.

pppd uses the options in the second file you created as it starts up. pppd has many options that you can view by entering man pppd.

Once you run this script, the connection with your ISP begins and you can immediately use network commands such as ping or a Web server. You're live on the Internet through your ISP.

Problems usually occur with setting up correct domain name resolution and IP addresses, as your gateway. Adding the debug option to the pppd options file /var/log/messages. You can also start to diagnose any problems with PPP using the ifconfig command, which will list the PPP connection, and the route command, which will list the PPP connection as the default route. Other networking parameters, such as the Web server's IP address, are assigned automatically during the PPP connection process. You can, however, have ISP assign you a specific IP address each time to make your Web programming and security easier to manage.
