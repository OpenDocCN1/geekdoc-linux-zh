Figure 8-2 shows a sample form that you might use to submit your information to a search engine. You will find that each site's forms are different, similar. If you have a basic set of business information at hand, you can quickly fill out the submission forms. There are many and more services that offer to sign you up for "over 200 search-index sites for one low fee." These may save you some time, but I would discourage you from using them for two reasons. First, 95 percent of users will go to the top ten or search engines—those listed in this section. You can easily fill out submissions to these sites and saving a fee. Second, these services are not likely to tailor your business case according to the types of queries or different markets served by different search engines. If you do it yourself, you get more accurate, carefully crafted inclusion in the indexes. For quality, not quantity. If you register with the sites listed in Table 8-1, you'll be included in 95 percent of Web searches.
