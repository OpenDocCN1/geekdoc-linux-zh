

-   出于对运行未知程序的安全考量，在浏览器中运行的 Java 程序无法访问大多数系统资源。在非浏览器环境（Java 虚拟机）中运行的 Java 程序则没有该限制。

-   在接下来的章节中，你将学习更多关于使用脚本和其他机制作为网关，通过你的网站提供多种类型的数据。本章还讨论了你可以为自己的特殊需求而创建的各种工具。

## 第 16 章

## 网关：通过 Web 提供一切

正如**人们所说的那**，Web 已经变成了中心（我当然也同意他们的观点），但世界并不是围绕着 Web 转的，Web 的存在时间也不够长，以让它的标准化影响力像最终可能的那样在许多领域得到体现。由于这些原因，许多人们希望通过 Web 作为一种易用且广泛传播的机制来访问或分发的数据格式，实际上与 Web 并不兼容。

网关允许你提供浏览器通常支持之外的其他类型的数据，因为它使非 Web 数据能够通过与 HTML 文档相同的系统进行传输。本章的题涵盖包括：

-   为什么要使用网关
-   电子邮件网关
-   数据库网关
-   其他类型的网关

## 为什么要使用网关

Web 的强大以及它如此迅速流行的原因在本书的第一部分已经讨论过。提醒你一下，它流行的最主要原因之一是，地球上几乎每台计算机都可以获得免费的 Web 浏览器并以通用格式访问数据。

像 Lotus Notes 这样的程序试图为组织内的每个人提供一个通用的数据库，但它们仍然要求在每个不同的平台上提供一个软件。Web 已经解决了这个问题。

网关背后的想法是允许非 Web 数据通过与 HTML 文档相同的系统进行传输。也就是说，让那些并非专为通过 Web 传输而开发的数据，尽管仍然能够通过每个人办公桌上已有的浏览器变得可用。

下一节将提供一个示例，解释了为什么网关如此有价值，并演示了如何使用它们。

## 使用网关的示例

假设你的非营利组织中有一个内网站点。你使用该站点提供所有的营销文档、人力资源表格以及各种其他内容，如年度报告和公司简报。所有这些文档最初是以 HTML 格式准备的，要么被转换为 HTML 格式以便在公共网站上提供，因为它们作为 HTML 文档比在文字处理器中更有用（浏览网站的人比阅读纸质简报的人多）。这个内网站点似乎非常成功。

一天，CEO 来你办公室建议说，如果能够实时跟踪呼入热线的操作员人数、每月到目前收到的捐款金额以及该机构赞助的儿童数量将非常有帮助。他希望能够随时通过浏览器访问内网站点来查看这些内容。

现在，如果这个 CEO 像大多数人一样，他不经常使用电脑；而如果你像大多数员工一样，当 CEO 说“如果……该多好”时，你就会花下周时间来实现它。

这些数据的问题在于，他想查看的内网站点位于一个大型 UNIX 服务器上，由一个与 Web 无关的专用软件包处理着。

你需要一个网关。

想象以下安排。你创建了一个 Web 页面，上面有三个图表，每个对应 CEO 想要看到的三个件事之一。每个图形都链接到你 Web 服务器上的一个小型脚本。然而，这些脚本在 Web 服务器上或配合 HTML 文档无法工作。当其中一个脚本被调用时，它会连接到拥有所有所需信息的 UNIX 服务器，并使用你从专用软件供应商那处学到的特殊调用，查询各种数据库以获取回答 CEO 问题所需的数字。

一旦脚本接收到这些数据，它就可以轻松准备一个 HTML 页面，将信息整合到好看的格式中，但这些数据是从一个不与 Web 通的系统中实时检索的。你创建的脚本充当了你组织使用的专用软件与如今人们可以在浏览器中查看的 Web 格式之间的网关。

## 网关如何工作

当然，这个示例非常简单，并不能真正描述一个可以访问专用软件上任何信息的通用接口。大多数网关都尝试提供这种通用接口，以便你从另一个源访问你需要的任何内容。

网关通常是运行在你的脚本之外的独立程序。你找到一个可以用来来访问另一种数据类型的网关，你的脚本可以查询处理与其他系统接口的网关程序，如图 16-1 所示。在其他时候，使用直接与目标数据系统接口的脚本更高效。或者网关可以提供整个接口，以便你的 Web 页面可以直接使用网关作为脚本来处理来自表单的请求，而你不需要编写其他内容。

## 电子邮件网关

互联网上的电子邮件实际上比 Web 更流行。Web 只是获得了所有的正面报道。也就是说，拥有电子邮件账户的人比拥有 Web 访问权限的多，而且任何可以浏览 Web 的人也有电子邮件账户。

由于这些原因，Web 上最常用的网关类型之一是电子邮件网关。有两种类型的电子邮件转换接口，两者都可以被称为网关。它们是：

-   向只有电子邮件访问权限发送 Web 页面的网关
-   将 Web 表单数据转发为电子邮件的网关

## 通过电子邮件返回 Web 

许多想要访问 Web 的人由于限制、路由器限制、互联网延迟或其他问题无法浏览 Web 页面。这些用户在互联网上唯一能做的的就是接收电子邮件。

## Linux Web 服务器工具包

这种电子邮件网关允许用户通过电子邮件向网关系统的特殊电子邮件地址发送 URL，并由网关将 Web 页面邮件回给他。这并没有保留页面中的图形，也不是通过 Netscape 实时完成的。它允许任何拥有电子邮件账户的人缓慢地——浏览 Web 页面——检索现在 Web 上的丰富信息。

## 将表单数据转换为电子邮件的网关

这种电子邮件网关可能正是你设想的。当你读到 Web 页面上表单的使用时，你可能会想：我只想让表单信息通过邮件发给我，以便我处理。

有许多工具允许你创建完全执行此要求的页面。有工具包可以让你编写或安排这些内容。还有非常通用的接口，可以接受任何 Web 表单的数据——因此你几乎不需要编程或干预——并以标准的结构化格式将其发送到指定的电子邮件地址。
