# TABLE 4–4 Main Linux Directories

| Subdirectory | Contents |
| --- | --- |
| /bin | Executable programs used by the root user. |
| /dev | Access to hardware devices such as printers, hard disks, and so on. Not accessed directly, but referred to when indicating system components. |
| /etc | Configuration files for many system programs, including password and graphics configuration files. |
| /sbin | Executable programs used by the root user. |
| /tmp | Temporary files created by programs (such as in-process e-mail messages) or by users exchanging or storing files. Be careful what you store here; on busy systems, the /tmp directory is completely erased each night. | used as a place to mount (attach) local devices or remotely networked filesystems so that they can be accessed as part of the local filesystem. |
| /lib | Library files (program code components used by several programs). These files are used mostly by the programs in /bin and /sbin |
| /root | The home directory for the root user. |
| /home | Home directories for all users on the system (except root). Contains a subdirectory for each user where all personal files are stored. |
| /proc | A special directory where pseudo-files with system information are stored for programs to access when querying system status. |
| /var | Storage area for system files, such as system logs, incoming e-mail messages for users, and so forth. |
| /usr | Executable programs, libraries, and other files used by the end users on the system. Contains several subdirectories, including /usr/bin for programs, /usr/src for source code to use programs (particularly applicable for Linux systems). |
