Three options are available for regular or password text fields, as follows:

+   - One option allows you to set the width of the text entry box that appears in the browser using the SIZE option.

+   - You can also set the maximum length of text that can be entered with the MAXLENGTH option. The MAXLENGTH value can be larger than the SIZE value; the browser will scroll in the entry field as the user types. The SIZE option lets you design a form with many text fields that still looks attractive. If you don't include SIZE or MAXLENGTH options, the browser will use its own defaults.

+   - Finally, you can have text in the box before the user enters anything, as a default value. This is added with the VALUE option. If you don't include the VALUE option, the text entry field will be blank.

An entry field using <TYPE= PASSWORD > would also look like Figure 10-4, until a user started, then asterisks will be displayed instead of the text used.
