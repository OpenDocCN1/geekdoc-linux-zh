Hardware parameters are sort of messy and are one reason Linux can be
hard to install. Not everyone has to use them, but if you do, they require that you
understand a lot about your hardware and that you use arcane formats to input the
required numbers or options. On the upside, you can get anything to work,
and work well, with Linux!

The parameters for modules I've just described are called insmod parame-
ters, because they are used with the insmod command when you instruct Linux tonInsert a Module. (During the installation of Linux, they are referred to as insmod
parameters even though you never have to use the insmod command.)

A related feature of Linux is the capability to use boot parameters when you
start your system. Boot parameters are set right to the kernel. They can provide
information about the overall system, as well as information about specific
hardware options, such as your OS CD-ROM drive. The problem is that the boot
parameters and the insmod parameters can use different formats (both difficult) for
the same information.

In addition to peripheral-specific information, boot parameters can define things
the location of the root filesystem, whether to ignore the map coprocessor,
and the location of a CD-ROM drive (which interface it's using). You enter boot
parameters when you first boot (start up) your computer system, just as control is
passing to the Linux kernel. You will learn a little after you've gone through the
installation.

Even though you can use boot parameters and insmod parameters to do a lot of
the same things, the general rule is to use insmod parameters whenever you can.

A table of common insmod and boot parameters is provided in the appendices
of the online documentation and in the online help during installation of
OpenLinux. For more parameters, you can check the Kernel HOWTO or the
Boot Parameter HOWTO documents on the Web (one URL for those documents is at
http://www.caldera.com/LDP/HOWTO/Kernel-HOWTO.html).

An example of what a boot parameter or insmod parameter looks like is shown
in following:

```
aha152=0x340,110
```
