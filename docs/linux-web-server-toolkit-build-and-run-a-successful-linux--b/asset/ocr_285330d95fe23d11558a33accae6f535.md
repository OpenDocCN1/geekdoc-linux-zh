# Using Scripts

An alternative method for soliciting e-mail is to display a form where the user enters the username, e-mail address, and comments. Then when the form is submitted, it is e-mailed to a certain address by the script on your Web server that processes the form (see Chapter 10). This has the advantage of not requiring any mail services at the client's location. It has the disadvantage of requiring that you write a form and a script to handle the mail features that the browser may already built in.

Of course, most users who have Web access will also have an e-mail account, so you rarely risk removing someone's ability to communicate with by not having a form and script. Because the mailto URL is so simple, you might consider using it regularly and having a special comments page with form for those who don't use the ubiquitous script.

If you have an e-mail server on your Linux Web system (see the "Accepting E-mail" below), you can use simple commands in your script to send a message to the e-mail system on the same computer. You can read these messages using a standard e-mail reader such as elm or the Netscape Navigator Bold. Two methods of sending e-mail are:

+   If you have a file to send, execute a command that includes the elm command with options that indicate the recipient and the file to mail. This method is easier but requires the information you want to mail is already in a single file. A sample command is shown here with the subject line, recipient and to send.

```
elm -s Subject line here john@server1.com < filemail.txt
```

+   If you are generating lines of text to send, you can open the SENDMAIL mail server and write lines to that output. This method is efficient for the server but takes more work in the script.

# Using a Mailto Link

From any point in your Web, you can use a standard anchor tag with a mailto-style URL. The browser uses the e-mail address you include in the URL as the destination for the message user enters in a dialog box the browser creates. For example, you may have a link in your HTML page that looks like this:

For more information, <A HREF=mailto:sales@tropicalfish.com > contact the sales department.</A>
