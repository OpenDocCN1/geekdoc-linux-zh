# DEFAULTICON

The Defaulticon directive gives a name for a graphic that is displayed if none of the Addicon directives apply, as follows:

```
Defaulticon /icons/unknown.gif
```

# ADDDESCRIPTION

You can use the AddDescription directive, which is not used in the default file, to place a one-line description after any file in the directory listings. For example, to have GIF graphics include a description, you could include the following line in srm.conf.

AddDescription Compurse GIF graphics format *.gif
