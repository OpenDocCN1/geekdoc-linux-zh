# Linux Web Server Toolkit

# TABLE 7-3 (continued)

| Connection Type | Speed | Cost | Stability | Scalability |
| :--- | :--- | :--- | :--- | :--- |
| SDN | Fast | Low — under $500 for a card, plus your ISP's hardware | Very good — but probably notas good as frame relay, depending on location | Poor — scaling completely new hardware and telecom connection |
| T1 (partial or shared) | Very fast | Medium to — expansion cards are $1000 to $2000; external router often required for $2000 to $4000 | Very good | Very good — to expand capacity of a partial T1 line; hardware allows expansion to multiple or leased lines |
| T1 (leased line) | Very fast | High — high expansions cards and routers as above; telecom connection much more expensive to set up | Very good | Good — expensive but relatively simple to expand to multiple T1 or T3 line |
| T3 | Extremely fast | Extremely expensive — expansion cards, routers, dedicated terminal servers, and so on | Very good — you'll likely get additional tech support with this option | Poor — but then, what would you scale to? ATM connection at 600MB|

The following costs are associated with obtaining an Internet connection; not all apply to every connection option:

+   * Web server hardware: The obvious costs are your Intel-based PC and monitor. The hardware required for your Internet connection can include an expansion card for your system, maybe a separate CSU/DSU unit, and even a separate router if your server is not also acting as your router, which Linux usually does unless you anticipate a lot of traffic.
