NOW THAT YOU'RE MORE familiar with Linux system and how to plan your Web server, this chapter discusses choosing a Linux system and the Web server software that you will install and use to run your Web site. # Choosing a Linux Distribution

Before you can install your Web server, you need to have an operating system already chosen to run it. Because you purchased this book, I assume you've either already chosen Linux or are leaning heavily towards it (good move). But as Chapter 2 pointed out, Linux is not so much a product as it is a technology. You still have to choose which Linux distribution to install on your computer.

This may seem like a moot point, because the CD-ROM in the back of this book contains a complete Linux distribution, from start to finish, with everything you need to install a new Linux operating system and get a complete Web server running on it.

However, as many users have almost religious feelings about the Linux distribution they choose to run on their systems, it seems to present a few options. Later chapters of this book focus on using the software included with the CD-ROM. But the differences in Linux systems will not even be relevant to our discussions in many cases, so you can apply what you read to the Linux system you choose to install.
