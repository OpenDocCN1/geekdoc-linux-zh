# Using Lists

Itemized lists categorize and organize information and are a common element of many HTML documents you are presenting. HTML includes three standard list types:

+   - Ordered list: Numbers are automatically assigned sequentially to each item in the list.
- Bulleted list: This type of list consists of items that have no inherent order.
- Definition list: This consists of a term and a paragraph defining the term (like a glossary entry).
