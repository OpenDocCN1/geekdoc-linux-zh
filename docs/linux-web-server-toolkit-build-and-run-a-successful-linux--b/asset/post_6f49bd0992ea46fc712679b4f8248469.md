# Sharing a DOS/Windows Hard Disk

This section describes in detail the steps to take if you plan on sharing a single hard disk between Linux and one or more operating systems. Sharing a hard disk between operating systems is a common occurrence for Linux users, especially as they first become familiar with Linux. For a production Web server, sharing a hard disk isn't as common as, but reviewing this section can be very helpful in understanding the options presented during installation.

![](img/e01f1106dd2902613fa07890c8baa7e6_137_0.png)

The method discussed in this section saves you from having to back up and restore your entire system as part of the process. You should still back up all important data for the sake of safety, because altering partitions is always a risky business.

This method uses a DOS program called FIPS to shrink your current DOS or Windows partition without losing any data (at least that's how it's supposed to work). Using the Linux fdisk command for the regular installation enables you to create an area for Linux in the free space that FIPS left on the hard disk.

Because FIPS is a much program, you can shrink the existing partition only on a DOS or Windows system. If you have OS/2 or a second UNIX system, you'll have to back up your system and reform your hard disk to create free space for Linux.

Before you use FIPS, you need to defr your hard drive, so that the files are all stored at the front of your hard disk. Otherwise there is no contiguous block of space to free up your hard disk because files are scattered all over. First, I'll tell you how to defragment your hard drive using DOS (directions for Windows operating systems follow).

If you want to defragment your hard drive using DOS, you can use the DEFRAG command. The DEFRAG command is included in recent versions of DOS, such as MS DOS 6.0 or later.

![](img/e01f1106dd2902613fa07890c8baa7e6_137_1.png)

In some versions of DOS, the DEFRAG command may be called OPTIMIZE.

# Dual Boot with Linux and Windows 95 or Windows NT

The new filesystems and highly automated installation that come with Windows 95 and Windows NT 4.0 make it little harder to follow the procedures in this section, and I would expect the same from from later versions of these operating systems. In fact, it seems that if you install Linux and then install Windows 95, the Microsoft installation will take over the hard disk and erase the Linux Boot Manager, so you can't get back to Linux without some headaches.

Always install Linux after your Windows systems are already installed and running. These new Windows systems and Linux can coexist very nicely;they're harder to put on the same hard drive.

For detailed information, with anecdotes and sample configurations, see the mini-HOWTO documents about your version of Windows at http://www.caldera.com/LDP/HOWTO.

Exit all other programs and operating systems, such as Windows, that might write to the disk drive. Then execute the following command:

```
C:\\DEFRAG
```

If you're using Windows 95, viewing the Properties of the hard disk from the desktop using the right mouse button menu (shown in Figure 5-1) will give you a Defragment option that will defragment your hard disk. Just follow these steps:

- 1. Double-click the My Computer icon on Windows 95 or Windows NT desktop.
- 2. Select the hard disk you want to defragment (for example, C:) by clicking the right mouse button on the icon that represents the desired drive.
- 3. Click the left mouse button on the Properties menu item (the bottom item) to open the Properties dialog window (shown in Figure 5-1).
- 4. From the tabs across the top of the Properties dialog window, choose the Tools tab.
- 5. Within the Tools tab, click the Defragment Now button to begin defragmenting your hard disk.
- 6. If your hard disk is not too fragmented, a message will inform you that the drive doesn't need defragmenting at this time. Do it anyway. Press the Start button to continue.
- 7. A window appears that shows you the progress as the hard disk is defragmented. The window will close automatically when the operation is completed.

# Chapter 5: Installing Linux

Once you have defragmented your hard disk, you're ready to use FIPS to cut the contiguous available space off as a separate, empty DOS partition. Then you can use the Linux fdisk utility during the installation to make that partition available to Linux.

The FIPS program is located in the \COL\TOOLS\FIPS15 directory on the accompanying CD-ROM. I will walk through each of the steps as you run FIPS.

- 1. Start the FIPS program at a DOS command line (substitute the correct drive letter for your CD-ROM):
E:\COL\TOOLS\FIPS15
- 2. Read the information about the warranty (there is none) and the warning messages (back up everything before using this). Then, press any key to continue.
- 3. If you have more than one hard disk, choose which one to use FIPS. You need only press the number; you don't need to press Enter afterwards:
- 4. A partition table for that hard disk is shown. Enter the partition you want to split off as free space for Linux. Choose your DOS/Windows partition. If the hard disk has several partitions, you can identify the correct partition from either the size (the far column) or the System (filesystem type):
- 5. A screen of statistics is shown as FIPS checks the partition you selected.
- 6. Insert a bootable floppy (you can make one with the SYS command in DOS) in the first floppy drive and press y:
- 7. The partition size information is shown in megabytes, with the cylinder boundary for where the split will occur between the existing partition and the new (free space) area:
- 8. Use the arrow keys to make the New Partition size equal to the amount of free space you want for Linux system (the swap and main Linux partitions). Press Enter when it's adjusted the way you want.
- 9. The new partition table is displayed with your edits in place (you're making two partitions out of one).
- 10. Press c to continue or r if you want to try changing the sizes of the partitions again:
