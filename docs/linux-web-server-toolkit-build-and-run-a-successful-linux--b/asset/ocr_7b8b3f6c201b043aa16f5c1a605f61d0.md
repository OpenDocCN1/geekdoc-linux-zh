# # Reviewing Document Locations

No which Web server you are using – Apache, FastTrack, or another Linux server – the documents that you provide to browsers are stored in the same location on your OpenLinux system: in the directory /home/http/html.

The scripts used for image maps, database queries, and other similar tasks are normally stored in /home/http/cgi-bin. More about that in a later chapter.

Other Linux systems have other standard locations for documents. They are usually in the same /home/http and cgi-bin subdirectories, even if located in a different place from /home/httpd.

The OpenLinux system comes with a few documents already installed in the /html directory – specifically, the help screens for the Desktop interface. The access and security options are set up by default so that no one can see anything on your system unless he she knows the name of a specific file.

Anything you place in the /html directory is visible on the Web if you're connected to the Internet. If a browser requests a URL such as http://www.corp.com/ with no file specified, the Web server tries to find a file index.html in the requested directory.
