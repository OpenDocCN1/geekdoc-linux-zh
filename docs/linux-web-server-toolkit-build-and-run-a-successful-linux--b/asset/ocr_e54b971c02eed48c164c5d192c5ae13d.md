# STORAGE DEVICES

When it comes to different types of storage, the easiest thing for the installation program to detect your hard disk – they are standardized on all PC systems. CD-ROM drives can be a lot harder than the interface used to connect CD-ROM drives on PCs is not standardized; though new systems use an IDE interface to the CD-ROM can vary, and older computer systems (more than two years old) may use a variety of proprietary CD-ROM interfaces.

If you have a large hard disk (over 1GB), you might need to know the count for bays, cylinders, and sectors per cylinder. These figures are usually printed on a label attached to the hard disk. Needing this information is rare, however. This is fortunate, for every new PC seems to have a hard disk over 1GB these days.

For your CD-ROM drive, you may need to know the type of interface used by the CD-ROM drive, as well as the interrupt and port numbers that it uses to provide data to your system. The CD-ROM drive interface is one of the following types:

+   * It may be IDE or EIDE, in which case it probably connects through one of the hard drive cables (most hard disks are IDE in new computers).
* It may instead be SCSI, in which it connects through a separate controller card for SCSI devices. You may also have a hard disk or other device attached to the same controller card, but these cards are not the norm for new PC systems.
* It could be connected through a proprietary controller card that is neither IDE nor SCSI.

The interface card that controls your CD-ROM drive uses specific software interrupts and software ports to communicate with the system. These have defaults, such as interrupt 13 and port 340. But if the Linux installation program cannot find the CD-ROM drive, you may have to restart the installation and indicate specifically what the correct values are.

Storage devices (such as tape backup systems and Zip drives) are not used for installation, so they are not covered in this section.
