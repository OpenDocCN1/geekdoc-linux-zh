# What's a URL Really Made Of?

As of most of you probably know, a URL (You-Are-Else, sometimes called an Earl, but not by me) is a Uniform Resource Locator. It is a standardized format for identifying a location on the Internet and the protocol by which that location is accessed. But you know the different components of a URL and what they do? Here's the breakdown:

+   1. The protocol, followed by a colon. The most commonly seen protocol is http, which indicates a Web site. Many others are used in Web browser links. (Other protocols are described in Chapter 4).
2. The server on the Internet, beginning with a double forward slash (bottom left to top right). The server can be specified by an IP address or by a domain name, which is what we prefer—something like //www.newmovie.com. (IP addresses and domain names are described in Chapter 4).
3. A file on the specified server with a complete path to reach it, with a single forward slash. A default file is sent if a filename is not given; if the server's home page is indexed, the slash is left off, giving just http://www.newmovie.com. An example of the path is /doc/brochures/index.html.

Several other things can be tucked inside a URL, including the port number to access the server and the username to log in for certain protocols. But you usually don't see these on movie posters.
