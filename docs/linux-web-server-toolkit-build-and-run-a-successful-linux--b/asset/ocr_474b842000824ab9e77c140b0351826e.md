# Understanding the AllowOverride Directive

For each directory container you can have an AllowOverride directive with one or more options after it. Each of the options listed indicates something that a local access control file .htaccess is the default described earlier — can alter from the settings in the current file.

These settings are cumulative through subsequent subdirectories. That is, if the main access.conf file allows overrides on something, an .htaccess in a subdirectory can contain a new AllowOverride directive for all subdirectories below it so that the settings in that .htaccess file cannot be changed.
