# Summary

In this chapter, you've learned how to configure and administer the basic options in the FastTrack Server running on OpenLinux. You've become familiar with security and resource options as well as using a single Administration server to manage multiple FastTrack Servers. Though additional options are available that weren't discussed here, the information here should enable you to explore and use the Administration server's browser-based interface to complete other more advanced administration tasks.

In this chapter you learned:

+   - The FastTrack Server is administered using a Web browser. Web pages with forms options where you can select how your Web server operate.

+   - Multiple Web servers can be configured and maintained from a single Administration server using the browser. Multiple virtual servers can also be created within a single copy of FastTrack.

+   - Basic configuration options for server and Web document usage are easily configured by selecting options or filling in forms. Online help is available for each option.

+   - More advanced options are also configured from the browser, including Access Control, Secure servers, logging, and aliased directories.

In the next chapter, you'll see how to track on the many events that occur on your Web site using the Web server log files and statistical analysis programs. You'll see how information can be useful to you, and where you can get free or commercial tools to complete reviews of your site on an ongoing basis.
