## Adding Security Patches

If you're using your Linux system in your organization, one of your top priorities is probably secure. Most people who are familiar with the Internet and use Linux consider Linux to be about the most secure system available. Why is that? Mostly because there are so many people working on keeping it secure.

If a security problem is found on Linux, it's usually reported and fixed within days, compared to months for other operating systems. All you have to do is to watch a good security alert web page such as Caldera's at http://www.caldera.com/tech-ref/security. Every security issue discovered on a standard Linux software package is listed on that page; a tested patch to fix the problem or a description of how to avoid it altogether is posted at the same time or soon after. Additional security resources are also listed on that page. See Chapter 18 for more information.

From this Caldera security page you can download patches for problems that have been discovered. Because the rpm system is used in OpenLinux, updating a package with the new version that's been tested to correct the security problem is very easy. All you have to do is download the new file – it will be in rpm format. Then execute the rpm update command to replace the current files on your system with the newly updated version. The following is an example:

```bash
rpm -U filename.rpm
```

After using this command to update the software, read the README file that accompanied the update to see if other changes need to be made to enhance the security of your system.

## Appendix A

### What’s on the CD-ROM

The COMPACT DISC (CD-ROM) that accompanies Linux Web Server Toolkit contains the OpenLinux Lite product from Caldera, Inc. (see http://www.caldera.com). It includes all the Web server tools and utilities you'll need, as well as many that don't want to apply to using a Web server but that you might find interesting (a great version of Tetris, for example). This appendix describes the contents of the CD-ROM.

If you want to install OpenLinux Lite immediately, you can begin by changing to the /col/launch directory and reading the README file in that directory. Full installation instructions are provided in Chapter 5 of this book.

The CD-ROM contains a directory named /col (for Caldera OpenLinux). Within the /col directory are the following subdirectories:

- /Bin
- /Contrib
- /Data
- /Doc
- /Install
- /Launch
- /Pgp-keys
- /Sources
- /Tools

The contents of each directory are discussed in the sections that follow. The top level directory and several of the main subdirectories (such as launch and tools) contain README files that summarize what is located in that directory.

### Bin: Various Programs

The Bin directory contains several utility programs you can use if you need to create a nonstandard installation of OpenLinux Lite. Note that if you follow the installation procedure described in Chapter 5, you don't need any programs from the /Bin directory.

Linux Web Server Toolkit

However, if you're using a different distribution of Linux, you could enhance it by installing these utilities. The program you're most likely to install is the rpm utility, which is a software package installer.

### Contrib: Additional Software Packages

The Contrib directory contains software packages that were added to OpenLinux after the main Linux system was put together or that are distributed under special licensing terms. The Contrib directory contains two subdirectories, RPMs directory with the additional software packages and SRPMs with the source code to many of those packages (some packages may not include source code).

You can easily install one of the packages in the Contrib/RPMs directory by executing the rpm command after you have installed OpenLinux. Installing additional packages with rpm is described in Chapter 21.

The Contrib directory contains the following additional, updated, or special software packages:

- Apache Web server, latest version (this is also included in the main installation directory and is installed by default)
- JDK Java Development Kit for Linux, from Sun
- Expect, a scripting language
- Tcl/TK packages (latest version)

### Data: Message Files

The Data directory contains message string files in English and German, which are accessed by the installation program during the installation process.

### Doc: Online Documentation

The Doc directory contains a collection of online documentation material for OpenLinux Lite. While much of the online documentation is installed when you install OpenLinux, you can also access the documentation from the CD, either before installing OpenLinux or after. The information in Doc directory is stored in several formats, but the most useful format for most users is HTML. To use the online documentation directly from the CD-ROM, point your browser to the /col/doc/html/index.html file on the CD-ROM. This will guide you through the HTML version of the documents.

### Install: Software Packages Archive

The Install directory is where all the software packages that make up OpenLinux Lite are stored. The Install directory contains several subdirectories that divide the software packages into groups based on subjects, such as networking and the X Window System. Installation options presented when you install OpenLinux Lite (such as default, minimal, and so forth) allow you to select which software packages in this directory are installed.

The RPMs subdirectory in the Install directory contains all the software packages in OpenLinux (except those are stored in Contrib directory, described previously). Links to the software packages are listed both in the RPMs directory and in one of the subject directories. The installation program will install the correct package according to which installation option you.

If you want to install any other software packages after installing OpenLinux Lite, you can change to the /col/Install/RPMs directory and use the rpm command. The use of the rpm utility is described in greater detail in Chapter 21.
