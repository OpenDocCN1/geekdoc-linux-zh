# Overview of a Form

All HTML forms are created between a beginning and ending <FORM> tag. The <FORM> tag also indicates to the browser what action to take when the Submit button on the form is pressed, and how the data collected from the user should be submitted to the Web server. A form outline looks like the following:

```
<FORM ACTION= http://www.toys.com/cgi-bin/survey.pl METHOD=POST>
..</FORM>
```

Notice in Table 10-2 that the <INPUT...> tag is used for a lot of form elements. According to the <TYPE> parameter, different elements are displayed by the browser. There are other parameters used by each tag, hence the ellipses (...) within the browser. I'll review each of these elements in detail.

As you prepare forms and the scripts that process the data from forms, remember the following point: you are always working with name-value pairs. That means that each piece of data entered in a form must have a name. That name (which you choose) is associated with a value that the user enters in the form.

The ACTION parameter in the <FORM> tag and the URL in the Submit button tag tell the name of script that the data is passed to. When the script starts to process the data, it do so by requesting the value of named items that the script expects to be submitted from that form. I show some examples of the name-value pairs that are passed to the Web server from the sample forms.

# TEXT ENTRY FIELDS

Text entry fields provide a box in which a user can enter a line of text. You have several options that can control the entry of text. The basic division shown in Table 10-2 is that the TYPE can be either TEXT for a regular text, or PASSWORD to have the contents appear as asterisks on the screen as the user types.

![](img/e01f1106dd2902613fa07890c8baa7e6_285_1.png)

Although the PASSWORD option prevents users (or anyone in the room) from seeing the password as it is being typed, the text is encrypted but is sent in plaintext over the Internet to the Web server.

As with all form tags you'll see here, you must include a NAME option that provides the name of a text entry field. Use short, easily remembered names without spaces or special characters. The NAME option is what your script will use to process the text entered by the user.

Three options are available for regular or password text fields, as follows:

- One option allows you to set the width of the text entry box that appears in the browser using the SIZE option.
- You can also set the maximum length of text that can be entered with MAXLENGTH option. The MAXLENGTH value limits the number of characters the user can type.
- Finally, you can use the VALUE option to provide a default value for the text field.

The following example shows a text field with a default value:

```
<P>
Enter your name:<P>
<INPUT TYPE=TEXT NAME=USERNAME SIZE=25 VALUE="John Doe">
```

## CHECKES

Check boxes allow you to provide a way to respond to a question. Every <INPUT> tag must have a unique NAME because check boxes can be selected independently.

The following example shows a set of check boxes; note that multiple boxes can be checked:

```
<P>
Would you like to receive our brochure?<P>
<INPUT TYPE=CHECKBOX NAME=SENDINFO VALUE="YES" CHECKED>
<P>
<INPUT TYPE=CHECKBOX NAME=SENDINFO VALUE="NO">
```

![](img/e01f1106dd2902613fa07890c8baa7e6_287_0.png)

Figure 10-5: A check box allows a user to make a Yes/No choice.

# RADIO BUTTONS

Radio buttons present the user with a choice of one option among several. They are often used in conjunction with check boxes, but you must carefully determine which input method fits what options the user wants.

A set of radio button <INPUT> tags all have the same NAME, with different VALUE options that specify what value should be returned if that radio button is selected. As with other form tags, you must supply the text that describes each radio button is for. You can use the CHECKED option to select one of the buttons as the default.

The following example creates a set of radio buttons; the corresponding browser display is:

<P>
Select one of the following options for shipment:<P>
<INPUT TYPE=RADIO NAME=SHITYPE VALUE=UPS_GROUND CHECKED>
United Parcel Service, Ground (4-7 days)<P>
<INPUT TYPE=RADIO NAME=SHITYPE VALUE=UPS_2DAY > United Parcel
Service, Blue Label 2nd Day (2 days)<P>
<INPUT TYPE=RADIO NAME=SHITYPE VALUE=FEDEX > Federal Express
(next day)<P>
