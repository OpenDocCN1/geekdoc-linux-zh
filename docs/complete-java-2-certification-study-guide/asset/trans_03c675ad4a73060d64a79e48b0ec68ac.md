

# 列表 (Lists)

列表是 Java 集合中最直接的一种集合。List 按照元素被添加的顺序保留其元素。List 的每个元素都有一个索引，从 0 开始。因此，你可以将 List 认为类似于可以根据需要增长的数组（但不能包含基本类型）。

`java.util.List` 除了包含从 `java.util.Collection` 接口继承的方法外，还包含几个方法。这些包括：

```java
void add(int index, Object x) // 在索引处插入。后续每个元素的索引都加 1，因此索引保持不变
```

```java
Object get(int index) // 返回指定索引处的元素。
```

```java
int indexOf(Object x) // 返回 x 首次出现的索引，如果 List 不包含 x，则返回 -1
```

```java
Object remove(int index) // 移除索引处的元素。后续每个元素的索引都减 1，因此索引保持不变```

实现 List 最常用的类是 `Vector`，它提供了该接口的简单实现。`Vector` 的方法是同步的，因此多个线程访问同一个实例时不需要担心破坏 vector 的内容。以下代码展示了 Vector 中封装的元素 101 到 110，并使用 `Iterator` 检索并打印了它们：

```java
1. for (int i=101; i<=110; i++)
2. vec.add(i);
3.
4. Iterator iter = vec.iterator();
5. while (iter.hasNext())
6. System.out.println(iter.next());
```

第 2 行对 Vector 来说看起来是一个 `int`，但 Vector 存储基本类型；它们只存储对象引用。List 通过将 `int` 装箱为相应的 `Integer` 利用了这一点。该代码等同于：

```java
vec.add(new Integer(i));
```

除了 `Vector` 外，`java.util.List` 还有三个类。它们是 `Stack`、`ArrayList` 和 `LinkedList`。前两个很简单。`Stack` 继承自 `Vector`，增加了 `push(Object)`、`pop()` 和 `peek(Object)` 方法以支持经典的栈行为。`ArrayList` 与 `Vector` 几乎相同，但它的方法不是同步的。

`LinkedList` 是一种实现，用于支持经典链表和双端队列数据结构的操作。除了 `List` 接口的方法外，`LinkedList` 还有 `addFirst()`、`getLast()`、`getFirst()`、`getLast()`、`removeFirst()` 和 `removeLast()` 方法。这些允许你在 List 的两端添加、检索和移除。

# 集合 (Sets)

你已经看到 Lists 是基于其成员的排序的。Sets 没有顺序的概念。Set 仅仅是对象引用的集合。

Sets 不得包含重复元素。如果你尝试向已包含该元素的 Set 添加该元素，`add()` 调用将返回 `false` 且 Set 不会改变。你可能会期望一个 `true` 返回。Sets 使用 `equals()` 方法而不是 `==` 运算符来检查元素的重复。你可能会对以下代码感到惊讶：

```java
1. void addTwice(Set set) {
2.   set.clear();
3.   Point p1 = new Point(10, 20);
4.   Point p2 = new Point(10, 20);
5.   set.add(p1);
6.   set.add(p2);
7.   System.out.println(set.size());
8. }
```

`java.awt` 包中的 `Point` 类是一个包含 `x` 和 `y` 值的简单类。该类的 `equals()` 方法在两个点具有相同的 `x` 和 `y` 值时返回 `true`。在第 2 行和第 3 行创建的 `Point` 实例是不同的但相等的。Sets 使用 `equals()` 来检查成员重复，第 6 行不会影响 Set，第 7 行将打印出 1 而不是 2。

- 3. `Iterator` 可以以某种顺序呈现元素。
