# Streams, Readers, and Writers

```
void writeFloat(float b) throws IOException
void writeInt(int i) throws IOException
void writeLong(long l) throws IOException
void writeShort(int s) throws IOException
void writeUTF(String s) throws IOException
```

All methods convert their input to bytes in the obvious way, with the exception of writeBytes(), which writes out only the low-order byte of each character in its string. As usual, there is a close() method. Again, chains of output streams should be closed in reverse order from their order of creation.
