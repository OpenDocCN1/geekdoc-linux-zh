+   1. B, C, D, F. The loops iterate from 0 to 1 and j from 0 to 2. However, the inner loop executes a continue statement when the values of i and j are the same. The output is generated inside the inner loop, after the continue statement, no output is generated when the values are the same. Therefore, the outputs suggested by options A and E are skipped.

+   2. D. It seems the variable i will take the values 0 and 1, and for each of these values, j will take values 0, 1, and 2. However, whenever i and j have the same value, the outer loop is continued before the output is generated. Because the outer loop is target of the continue statement, the statement of the inner loop is abandoned. Therefore, only the line to be output is shown in option D.

+   3. In A, the declaration for i is illegal. This type of declaration is permitted only in the first part of a for() loop. In B, the outer loop expression—the variable in this case—is of type int. A boolean expression is required. C is valid. Despite the complexity of declaring one value inside the for() construction and outside (along with the use of the comma operator in the end part), this is entirely legitimate. D would be correct, if the label omitted from the second line, which should read loop: {

+   4. D. The first test at line 2 fails, which immediately cuts control to skip to line 10, bypassing both tests that might result in the output of one message or two. So, even though the test at line 3 would be true, it is never made; A is not. At line 10, the output is false, so the message at line 1 is skipped, but message, at line 14, is output.

+   5. D is incorrect because the code does the expression at line 5: the expression is a constant. B is incorrect because the switch can take a long argument. Only short, char and int are acceptable. The output results from the value 2 like this, the option case 2 is selected, which output value is two. However, there is no break statement between lines 4 and 5, so the execution enters the next case and outputs value 13 from line 6. The default: part of a switch() is executed only when no options have been selected, or if no break precedes. Neither of these situations holds, so the output consists only the two messages listed in D.

Only one catch block is executed, so control passes to the finally block, which results in the message at line 18 being output; so E is part of the correct answer. Execution continues after the finally block, resulting in the output of the message at line 20; so F is also part of the correct answer.

+   7. A, F. With no exceptions, the try block executes to completion, so the message Success from line 6 is printed and A is part of the answer. No catch is executed, so B, C, and D are incorrect.
