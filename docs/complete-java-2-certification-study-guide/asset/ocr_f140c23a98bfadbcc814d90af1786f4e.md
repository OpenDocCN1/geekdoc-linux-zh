A good example of a low-level reader is the FileReader class. Its commonly used constructors are

+   - FileReader(String pathname)
- FileReader(File file)

Of course, any file passed into these constructors must genuinely contain UTF strings. The corresponding writer is the FileWriter class:

+   - FileWriter(String pathname)
- FileWriter(File file)
