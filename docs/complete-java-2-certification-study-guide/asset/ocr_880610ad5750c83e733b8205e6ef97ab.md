# Arithmetic Promotion of Operands

Arithmetic promotion of operands takes place before any binary operator is applied so that all
numeric operands are at least int. This promotion has an important consequence for the
unsigned right-shift operator applied to values that are narrower than int.

The diagram in Figure 2.2 shows the process by which a byte is shifted. The first byte
promoted to int, treating the byte as a signed quantity. Next, the shift
occurs, and 0 bits are propagated into the top bits of the result—but these bytes are not
of the original byte. When the result is cast down to a byte again, the higher-order bits of
that byte appear to have been created by a signed shift, rather than an unsigned one.
is why you should generally not use the logical right-shift operator with operands smaller thannanint: It is unlikely to produce the result you expected.

| Expected result was: | 00001100 |
