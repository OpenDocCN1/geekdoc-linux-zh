# Primitive Data Types

A primitive is a simple non-object data type that represents a single value. Java’s primitive data types are

+   - boolean
- char
- byte
- short
- int
- long
- float
- double

The apparent bit patterns of these types are defined in the Java language specification, and their effective sizes may vary.

> NOTE Variables of type boolean may take only the values true or false. Their representation size may vary.

# TABLE 1.2 Primitive Data Types and Their Effective Sizes

| Type | Effective Representation Size (bits) |
| byte | 8 |
| int | 32 |
| float | 32 |
| char | 16 |
| short | 16 |
| long | 64 |
| double | 64 |
