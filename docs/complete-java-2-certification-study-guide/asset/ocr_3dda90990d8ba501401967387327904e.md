Note that you specify the class name, not the class filename, so there's no .class suffix. To specify the entire class name, including package prefixes (x.y, in this example). The text file can have any name at all. It is not inserted into the jar file. Instead, the jar program reads and copies its information into the manifest file, which the jar program creates.

Now build your jar file, using the -m option to tell the jar file to look in for manifest information. For example, if your Main-Class line is in a file called many.txt, your command would be

```
jar -cvfm my_archive.jar many.txt .class
```

The jar program reads the main class declaration in many.txt and builds a manifest inside the jar, containing the main class declaration and a bit of extra information. Inside the jar directory named META-INF is created, and in META-INF is a plain-text file called MANIFEST.MF. Here's what MANIFEST.MF looks like for our example:

```
Manifest-Version: 1.0
Created-By: 1.5.0 (Sun Microsystems Inc.)
Main-Class: MyMainClass
```
