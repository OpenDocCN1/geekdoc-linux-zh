# setFont()

The setFont() method dictates which font component will use for rendering any text it might display. The setFont() method takes one argument of type Font whose constructor takes three arguments: a font family, and a size. The family is a string. Different platforms offer different fonts, but you can count on “Serif”, “SansSerif”, and “Monospaced” a fixed-width font such as Courier. The style may be Font. PLAIN, Font.BOLD, Font.ITALIC, or the bit-width combination Font.BOLD.ITALIC. The size argument defines the point size of the font.

# setEnabled()

The setEnabled method determines whether a component can respond to input. The method takes a single boolean argument. A disabled component changes its appearance to a slightly greyed-out. A component should be disabled if the input is in a state that cannot accept input from the component.

Disabling is preferable to the two commonly seen alternatives:

+   - Leave the component enabled. When the user uses the component, display some sort of “unavailable” message.
- Remove unusable areas from the screen until they become usable, creating a visually unstable area.

Judicious use of setEnabled() helps create a GUI that clearly reflects the application’s state to the user.

# Basic Swing Components

The Swing components can be found in the javax package. The component class names begin with the letter J. The remainder of the class name is the name of the component, with each word starting with a capital letter. For example, a scroll bar is represented by the javax.swing.JScroll
