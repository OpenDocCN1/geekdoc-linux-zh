# The Wrapper Classes

Character have a static method valueOf(String s), which parses a string and returns an instance of the same type as the class method was called. So, for example, Long.valueOf("23*") constructs an instance of the Long class that wraps the value 23.

One of static wrapper methods is the parseXX() methods. These are Byte.parse(),Short.parseShort(),Integer.parseInt(),Long.parseLong(),Float.parseFloat(), and Double.parseDouble(). Each of these takes a String argument and returns the corresponding primitive type. They throw no NumberException.

Other static methods are mentioned in the example objectives are the getXXX() methods. These are Boolean.getBoolean(),Integer.get(),Long.getLong(). Each of these takes a String argument as the name of a property and returns the value of the property. The property returns a primitive boolean or a wrapper Integer or Long encapsulates the property value, provided the property is not empty, and is compatible with the respective type. Integer.get() and Long.getLong have overloaded forms that take a second argument, which is a primitive of the respective type. The second argument is a default value that is wrapped and returned in case the property is not empty, or is not compatible with the respective type.

All the wrapper classes provide toString() methods. In addition, the Integer and Long classes provide toBinaryString(),toOctalString(),toHex(), which return strings in 2, 8, and 16.

> All wrapper classes have an inconvenient feature: The values are immutable. After an instance is created, the encapsulated value cannot be changed. It is tempting to try to subclass the wrappers, so that the subclasses inherit the full functionality of the original classes while offering mutable contents. Unfortunately, this strategy doesn't work because the wrapper classes are final.

To summarize the major facts about the primitive wrapper classes:

+   - Every primitive type has a corresponding wrapper class type.
- All wrapper types can be constructed from primitives. All except Character can also be constructed from strings.
- Wrapped values can be tested for equality with the equals() method.
- Wrapped values can be extracted with all XXXValue() methods. All numeric wrapper types support all six numeric XXXValue() methods.
- Wrapper classes provide many utility methods, including the static valueOf() and parseXXX() methods, which parse an input string.
- Wrapped values cannot be modified.

Java's wrapper classes are useful in situations where a primitive must act like an object: as element in a vector, for example, or as key or value in a Map. Unfortunately, dealing with the wrapped value has historically been inconvenient.
