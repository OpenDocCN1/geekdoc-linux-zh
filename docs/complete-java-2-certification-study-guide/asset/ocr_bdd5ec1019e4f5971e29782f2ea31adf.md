# Chapter 8 · The java.lang and java.util Packages

The following code shows how to use two of these methods to modify a string. The original string is "5 + 4 = 20". The code starts off the leading blank space and then converts the addition sign to a multiplication sign:

+   1. s = "5 + 4 = 20";
2. s = s.trim(); // "5 + 4 = 20"
3. s = s.replace('*', 'x'); // "5 x 4 = 20"

After line 3, s returns with appearance as shown in the line 3 comment. Of course, the modification has not taken place within the original string. The trim() call in line 2 and the replace() call of line 3 construct and return new strings; the address of each new string in turn gets assigned to the reference variable s. Figure 8.3 shows this graphically.
Figure 8.3 shows that the original string is only shown, but it is actually replaced, because strings are immutable. If much modification is required, this process becomes very inefficient—the garbage collector cleaning up all the old strings, and it takes time to copy the contents of the old into the new ones. The next section discusses two classes that address these problems by representing mutable strings. These are StringBuilder and StringBuilder classes.

# The StringBuilder and StringBuilder Classes

Java's StringBuilder and StringBuilder classes represent strings that can be dynamically modified.

The most commonly used StringBuilder constructor takes a String as input. You can also construct an empty string buffer (probably with the intention of adding characters to it later). An empty string buffer can have its initial capacity specified at construction time. The three constructors are

+   StringBuilder() Constructs an empty string buffer.

+   StringBuilder(int capacity) Constructs an empty string buffer with the specified initial capacity.

+   StringBuilder(String initialString) Constructs a string buffer that initially contains the specified string.
