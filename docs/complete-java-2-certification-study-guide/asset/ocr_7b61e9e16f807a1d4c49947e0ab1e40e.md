When you retrieve a member of a generic vector, you may assign the retrieved value to a variable of the vector's type without casting. The following code is legal:

+   1. Vector<Dragon> myVec;
2. myVec = new Vector<Dragon>();
3. Dragon ulaShan = new Dragon();
4. myVec.add(ulaShan);
5. Dragon d = myVec.get(0);

The compiler thinks that myVec contains dragons, on line 5 the cast that would otherwise be required is omitted.
