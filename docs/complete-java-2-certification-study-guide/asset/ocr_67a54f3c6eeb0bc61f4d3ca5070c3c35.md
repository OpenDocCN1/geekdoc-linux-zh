# Chapter 11 · Swing Components

If a cell is editable, the model's setValue() method is called by when the user hits the Enter key (with keyboard input focused on the editable cell).
That's really all there is to creating your own model class. To create a table that uses a custom model, create an instance of the model class and pass it into the JTable constructor. Let's look at an example.

The following model class has a constructor argument which is a setting strings. The corresponding table has two columns. The first column contains the strings, sorted in alphabetical order. The second column contains the string lengths.

```
1. import java.util.*;
2. import javax.swing.*;
3. import javax.swing.table.*;
4.
5. public class StringLengthTableModel extends AbstractTable {
6.     private String[] strings;
7. 
8.     public StringLengthTableModel(String[] strings) {
9.         this.strings = strings;
10.    }
12.    public int getRowCount() {
13.        return strings.length;
14.    }
15. 
16.    public int getColumnCount() {
17.        return 2;
18.    }
19. 
20.    public Object getValueAt(int row, int col) {
21.        if (col == 0)
22.            return strings[row];
23.        else
24.            return strings[row].length;
25.    }
26. 
27.    public String getColumnName(int col) {
28.        return (col == 0) ? "String" : "Length";
29.    }
30.
```
