the value of the boolean expression. In this way, for example, the body of the if() and else parts can be swapped. Consider these two equivalent code fragments:

```
1. public Object Object(Object x) {
2.   if (x instanceof String) {
3.     // do nothing
4.   }
5.   else
6.     x = x.toString();
7.   }
8.   return x;
9. }
```

and

```
1. public Object Object(Object x) {
2.   if (!x instanceof String) {
3.     x = x.toString();
4.   }
5.   return x;
6. }
```

In the first case, a test is made at line 2, but the conversion and assignment, at line 6, only if the test failed. This is achieved by the somewhat cumbersome technique of using only the else part of an if/else construction. The second fragment uses the complement operator that the overall test performed at line 2 is reversed; it may read as, "If it is false that x is an instance of a string," or more likely, "If x is not a string." Because of this change to the test, the conversion can be performed at line 3 in the situation that the test has succeeded; else part is required, and the resulting code is cleaner and shorter.
