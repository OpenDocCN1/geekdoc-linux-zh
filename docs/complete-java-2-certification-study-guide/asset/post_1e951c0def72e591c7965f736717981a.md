
## The Wrapper Classes

Each Java primitive type has a corresponding wrapper class. A wrapper class is simply a class that encapsulates a single value. For example, the Integer class wraps an int value, and the Float class wraps a float value. The wrapper classes do not perfectly match the corresponding primitive names. Table 8.2 lists the primitives and wrappers.

TABLE 8.2 Primitives and Wrappers

| Primitive Data Type | Wrapper Class |
|---|---|
| boolean | Boolean |
| byte | Byte |
| char | Character |
| short | Short |
| int | Integer |
| long | Long |
| float | Float |
| double | Double |

The wrapper classes can be constructed by passing the value to be wrapped into the appropriate constructor. The following code shows how to construct an instance of each wrapper type:

```
boolean primitiveBoolean = true;
Boolean wrappedBoolean = new Boolean(primitiveBoolean);
byte primitiveByte = 4;
Byte wrappedByte = new Byte(primitiveByte);
char primitiveChar = 'M';
Character wrappedChar = new Character(primitiveChar);
short primitiveShort = 3133;
Short wrappedShort = new Short(primitiveShort);
int primitiveInt = 1234568;
Integer wrappedInt = new Integer(primitiveInt);
long primitiveLong = 12345678965421L;
Long wrappedLong = new Long(primitiveLong);
float primitiveFloat = 1.1f;
Float wrappedFloat = new Float(primitiveFloat);
double primitiveDouble = 1.111111;
Double wrappedDouble = new Double(primitiveDouble);
```

There is another way to construct any of these classes, with the exception of Character: you can pass into the constructor a String that represents the value. Most of these constructors throw NumberFormatException because there is the possibility that the constructor will not represent a valid value. Boolean does not throw this exception; the constructor accepts any String and returns a true if the string (ignoring case) is true. The following code fragment shows how to construct wrappers from strings:

```
try {
    boolean primitiveBoolean = "true";
    Boolean wrappedBoolean = new Boolean(primitiveBoolean);
    byte primitiveByte = "4";
    Byte wrappedByte = new Byte(primitiveByte);
    short primitiveShort = "3133";
    Short wrappedShort = new Short(primitiveShort);
    int primitiveInt = "1234568";
    Integer wrappedInt = new Integer(primitiveInt);
    long primitiveLong = "12345678965421";
    Long wrappedLong = new Long(primitiveLong);
    float primitiveFloat = "1.1f";
    Float wrappedFloat = new Float(primitiveFloat);
    double primitiveDouble = "1.111111";
    Double wrappedDouble = new Double(primitiveDouble);
} catch (NumberFormatException e) {
    System.out.println("Bad Number");
}
```

The values wrapped inside wrappers of the same type can be checked for equality using the equals() method discussed previously. For example, the following code fragment checks two instances of Double:

```
Double d1 = new Double(1.0105);
Double d2 = new Double(1.11348);
if (d1.equals(d2)) {
    // Do something.
}
```

After a value has been wrapped, you may eventually need to extract it. For an instance of Boolean, you can call booleanValue(). For an instance of Character, you can call charValue(). The other six classes extend abstract superclass Number, which provides methods to retrieve the wrapped value as a byte, a short, an int, a long, a float, or a double. In other words, the value of any wrapped number can be retrieved as any numeric type. The retrieval methods are:

- public byte byteValue()
- public short shortValue()
- public int intValue()
- public long longValue()
- public float floatValue()
- public double doubleValue()

The wrapper classes are useful whenever it would be convenient to treat a piece of primitive as if it were objects. A good example is the Vector class, which is a dynamically growing collection of objects of arbitrary type. The method for adding an object to a vector is

`public boolean add(Object obj)`

Using this method, you can add any object of type to a vector; you can even add an array (you saw why in Chapter 4, "Converting and Casting"). You cannot, however, add an int, a long, or any other primitive to it. No special methods exist for doing so, and `add(Object obj)` will not work because there is no automatic conversion from a primitive to an object. Thus, the following code will not compile:

```
Vector vec = new Vector();
boolean boo = false;
vec.add(boo); // Illegal
```

The solution is to wrap the boolean primitive, as shown here:

```
Vector vec = new Vector();
boolean boo = false;
Boolean wrapper = new Boolean(boo);
vec.add(wrapper); // Legal
```
