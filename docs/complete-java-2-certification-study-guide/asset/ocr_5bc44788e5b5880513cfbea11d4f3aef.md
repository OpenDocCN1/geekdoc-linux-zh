# Answers to Review Questions 99

+   11. A, B. Since the method in the superclass is overridden in a different package, the superclass must be public or protected. (Default methods may be overridden only if the subclass is in the same package as the superclass; private methods may not be overridden at all.) An overriding method's access mode must be the same as, or more open than, the superclass version's access mode.

+   12. F. A is false because the compiler forbids construction of an abstract class. B is false because abstract classes need not contain any abstract methods (though if a class does contain abstract methods, it must be abstract). C is false because there is no such as an abstract data field. D is false, when you really think about it, it doesn't make any sense; the compiler compiles classes one at a time and has no interest in whether or not a class is overridden. E is false because there is no compiler requirement that an abstract class must declare that it implements any interface.

+   13. C, D. If a class does not provide implementations for all methods of all interfaces that the class implements, then class must be declared abstract. Abstract classes may not be instantiated.

+   14. A, B, C. Classes, data, and methods can be declared final. Variables cannot.

+   15. B, C, D. Data and methods may be static, and even if they are. When the static keyword is followed by a code block, the block is a static initializer and is executed when the class is loaded.

+   16. A, C, D. An overriding method's access mode must be the same as, or more open than, the superclass version's access mode.

+   17. B. An object that inherits a protected method from a superclass in a different package may call that method on itself but not on other instances of the same class.

+   18. D. There is only one restriction on a final class: A final class may not be extended.

+   19. D. Since x is static, there is only one variable, which is shared by all instances along with the class. Thus the last assignment wins.
