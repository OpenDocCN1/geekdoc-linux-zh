# Appendix A · Practice Exam

14. B, E. When the exception is thrown, the current pass through the try block is abandoned, so “I threw” isn't printed. The first catch block that is compatible with the exception's type is executed. This is the block for ObjectstreamException, which is a superclass of the thrown type. Only one catch block is executed per exception; execution then continues to the Finally block, which prints "Finally".

15. D. Since ArrayOutOfBoundsException is a runtime exception, it indicates a faulty algorithm that not be released. The only appropriate response is to find and fix the bug.

16. C, D. The purpose of IllegalArgumentException is to predict a precondition violation in a public method. The core Java classes use this way, and so we should. The JVM does not throw IllegalArgumentException.

17. A, B, D. All four statements are legal. A and C are examples of boxing, which allows assignment from a wrapper to a primitive. B is an example of boxing, which allows assignment from a primitive to a wrapper. D is assignment of a literal to a short, which is legal because the right-hand side of the assignment is a literal rather than a value.

18. A, C. StringBuilder is nearly identical to StringBuffer. The main differences are that StringBuilder is not threadsafe, and it is generally faster than StringBuffer.

19. A, B and D correctly use a random access file. A reads and discards the leading doubles; B seeks past them. C doesn't work because readers are for files that contain only 8-bit; they don't work on UTF doubles; D and E use a file input stream. D correctly reads and discards the leading doubles and then the UTF string. E does not work because the DataInputStream class doesn't have a seek() method.

20. C. For a file that contains only 8-bit text, use a reader. A reader interprets 8-bit text according to the current locale. Readers read their input by character to assemble the characters into lines of text, chain on a LineReader and call its readline() method.

21. B, E. There are two ways to ensure a class can be serialized: implement Serializable, which is tagging interface that defines no methods, or implement Externalizable, which defines the readExternal() and writeExternal() methods.

22. D. Default deserialization is only bypassed if the readObject() method has access.

23. B, C. If a class implements Externalizable, it must have a no-args constructor. If a class implements Serializable and does not implement java.Externalizable, its non-externalizable subclass must have a no-args constructor.

24. C, D. Date formatting is determined by the locale and by the style. Style constants are defined as static ints in the dateFormat class: SHORT, MEDIUM, LONG, and FULL.

25. A. NumberFormat instances should be obtained by calling the static getInstance() method, not by calling a constructor. To format a number, pass the number (and no other arguments) into the NumberFormat'format() method.
