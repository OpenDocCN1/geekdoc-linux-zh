
# W

**waiting state** A nonexecuting thread state, entered when a thread executes an object's wait() method and terminated when the object's notify() or notifyAll() method is invoked.

**weight** A GridBag property that determines the amount of space allocated to a component when its container resizes.

**widening conversion** Conversion from a narrower to a wider numeric data type.

**wrapper class** A class that encapsulates a single, immutable value. Each Java primitive data type has a corresponding wrapper class.

# Y

**yield** To voluntarily give up the CPU. A thread yields by executing its yield() method.
