Let's summarize the key points about constructors before we move on to inner classes:

- Constructors are not inherited in the same way as normal methods. You can create an object only if the class defines a constructor with an argument list that matches the one you provide calls.

- If you define no constructors in a class, then the compiler provides a default that takes no arguments. If you define a single constructor, this default is not provided.

- It is common to provide multiple overloaded constructors—that is, constructors with different argument lists. One constructor can call another using the syntax this(arguments).

- A constructor delays running its body until the parent parts of the class have been initialized. This happens because of an implicit call to super() added by the compiler. You can provide your own call to super(arguments) to control how the parent parts are initialized. If you do so, it must be the first statement of the constructor.

# The Enclosing Reference and Construction

When an instance of an inner class is created, normally the outer class must act as context. Consider this example, which is expanded from:

```java
1. public class OuterOne {
2.   private int x;
3.   public class InnerOne {
4.   private int y;
5.   public void innerMethod() {
6.     System.out.println("y is " + y);
7.     }
8.   }
9.   public void outerMethod() {
10.    System.out.println("x is " + x);
11.  }
12.  public void makeInner() {
13.    InnerOne anInner = new InnerOne();
14.    anInner.innerMethod();
15.  }
16.  // other methods...
17. }
```

You will see two changes in this code when you compare it to the earlier version. First, innerMethod() now only outputs the value of y, which is defined in InnerOne, but also, line 6, outputs the value of x, which is defined in OuterOne. The second change is in lines 13-14, the code creates an instance of the Inner class and invokes innerMethod() upon it.

Sometimes you want to create an instance of an inner class from a static method or in some other situation where there is no available. The situation arises in a main() method or if you need to create the inner class from a method of some object of an unrelated class. You can achieve this by using the new operator as though it were a member of the outer class. Of course, you must still have an instance of the outer class. The following code, which is a main() method in isolation, could be added to the code so to produce a complete example:

```java
public static void main(String args) {
    OuterOne.Inner i = new OuterOne().new InnerOne();
    i.innerMethod();
}
```

From the point of view of the inner class instance, this use of two new statements on the line is a compacted way of doing the following:

```java
public static void main(String args[]) {
    OuterOne o = new OuterOne();
    OuterOne.Inner i = o.new InnerOne();
    i.innerMethod();
}
```
