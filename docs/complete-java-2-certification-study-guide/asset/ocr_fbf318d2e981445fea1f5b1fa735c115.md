You will see two changes in this code when you compare it to the earlier version. First, innerMethod() now only outputs the value of y, which is defined in InnerOne, but also, line 6, outputs the value of x, which is defined in OuterOne. The second change is in lines 13-16, the code creates an instance of the Inner class and invokes innerMethod() upon it.
The accessibility of the members of the enclosing class is crucial and very useful. It is possible because the inner class has a reference to the outer class instance that was the current context when the inner class was created. In effect, it ensures that the inner class and the outer class belong together, rather than the inner being just another member of the outer instance.

> Sometimes you want to create an instance of an inner class from a static method or in some other situation where there is no object is available. The situation arises in a main() method or if you need to create the inner class from a method of some object of an unrelated class. You can achieve this by using the new operator as though it were a member of the outer class. Of course, you must still have an instance of the outer class. The following code, which is a main() method in isolation, could be added to the code so to produce a complete example:

+   1. public static void main(String args) {
2. OuterOne.Inner i = new OuterOne().new InnerOne();
3. i.innerMethod();
4. }

From the point of view of the inner class instance, this use of two new statements on the line is a compacted way of doing the following:

+   1. public static void main(String args[]) {
2. OuterOne o = new OuterOne();
3. OuterOne.Inner i = o.new InnerOne();
4. i.innerMethod();
5. }
