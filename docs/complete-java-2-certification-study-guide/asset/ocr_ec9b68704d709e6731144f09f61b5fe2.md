# Anonymous Classes

Some classes that you define a method do not need a name. A class called an anonymous class. Anonymous classes can be declared to extend another class or implement a single interface. The syntax does not allow you to do both at the same time or implement more than one interface explicitly (or, of course, if you extend a class and the parent class implements it, then it is a subclass of java.lang.Object). If you declare a class that implements a single interface, then it is a direct subclass of interface.

Because you do not know the name of an anonymous class, you use the new keyword to create an instance of that class. In fact, the definition, construction, and first use (often in an assignment) of an anonymous class all occur in the same place.
