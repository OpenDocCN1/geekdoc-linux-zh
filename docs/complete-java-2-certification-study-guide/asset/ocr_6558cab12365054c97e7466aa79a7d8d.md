# Ordinary Components

In this section, we'll discuss eight ordinary components. They are in the sense that they are the components in which the user directly inputs data, in contrast to containers. We will review the following component types:

+   * JLabel
* JButton
* JCheckBox
* JRadioButton
* JScrollBar
* JTextField
* TextArea
* JComboBox
