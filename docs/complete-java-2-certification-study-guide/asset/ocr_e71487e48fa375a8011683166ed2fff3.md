# Formatting Text

Formatting text is the art of generating human-language deice in read-able and correct ways. Text formatting in the early releases of Java required amounts of custom coding. Later releases have included a-classes that relieve programmers of the burden of inventing formatting algorithms. This relief comes at a price: some the classes have significant learning curves. Here we'll look at how Java's formatting classes allow us to format text in general and give special formatting for numbers, dates, and currency.

Sometimes appropriate formatting varies place to place. For example, in Europe, Java's formatting classes use a comma instead of a period as a decimal point: 3.14159. Some of Java's formatting classes are sensitive to regional variations of customs.

A cultural or linguistic region is represented in Java by the Java.util.Locale class. A look at the US, and the API page for Locale is a great place to start. To get the locale for the current computer, call the static method Locale.getDefault(). (The locale system default might use orics to figure out where it is-the operating system gives locale, and the method asks the operating system.)

If you're playing with locales, it's useful to know how the getDisplay() method. This returns the name of the country in human-recognizable form.

The getCountry() method returns a two-letter code.
Java's formatting methods have several over-loaded versions where you can specify a different locale. These overloaded versions are useful for making code that produces results in locales other than the default. We'll learn on how to format text in specific situations later.
