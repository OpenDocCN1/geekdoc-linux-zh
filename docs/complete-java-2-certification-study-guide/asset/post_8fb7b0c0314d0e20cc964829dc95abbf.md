
# Chapter 2 · Operators and Assignments

All the operators used up to this point have produced a value as a result of the operation. The expression 1 ? 2, for example, results in a value 3, which can then be used in some further way—perhaps assignment to a variable. The assignment operators in Java are considered to be operators because they have a returning value. So, given int a, b, and c, the state a = b = c = 0; is entirely legal. It is executed from right to left, so that first c is assigned into the variable c. After it has been executed, the expression c = 0 takes the value that was assigned to the left side—that, 0. Next, the assignment of b takes place, using the value of the expression to the right—again, 0. Similarly, assignment takes the value that was assigned, finally the variable a is also set to 0.

Although execution order is determined by precedence and associativity, evaluation order of the arguments is not. But since you understand the points made in the Section “Evaluation Order” at the start of this chapter.

# Summary

We have covered a lot of material in this chapter, so let's recap the key points. The unary operators were the first topics we covered. Recall that they take only a single operand. The seven unary operators are ++, --, +, ~, !, !, and (). Their key points are as follows:

- The ++ and -- operators increment and decrement expressions. The position of the operator (prefix or suffix) is significant.
- The + has no effect on an expression other than to clear that a literal constant is positive. The - operator negate an expression.
- The ! operator invert the value of a boolean expression.
- The ~ operator invert the bit of an integral expression.
- The (type) operator is used to persuade the compiler to permit certain assignments that the programmer believes are appropriate, but break the normal rigorous rules of the language.

Next we covered arithmetic operators. We discussed the familiar operators, which perform addition, subtraction, multiplication, and division. Recall that this group is further split into subgroups. There are five arithmetic operators:

- Multiplication: *
- Division: /
- Modulo: %
- Addition: +
- Subtraction: -

The arithmetic operators can be applied to any numeric type. Also, the + operator performs concatenation if either of its operands is a String object. Under the conditions where one operand in a expression is a String object, the other is forced to be a String object, too. Conversions are performed as necessary. They might result in cryptic text but they are definitely legal. Under conditions of arithmetic overflow or similar errors, accuracy is generally lost. Only division by zero can throw an exception. Floating-point calculations can produce NaN—indicating Number has no meaning—or infinity.

We also discussed bitwise operators, which are sometimes used to save storage, for instance. There are three bitwise operators: &, ^ and |. They are usually named AND, Exclusive-OR (XOR), and OR respectively. For these operators, the following points apply:

- In bitwise operations, each result is calculated on the basis of the two bits from the same position.
- For the AND operation, result is 1 if the first and second operand bit are 1.
- For the XOR operation, result is 1 if exactly one operand bit is 1.
- For the OR operation, result is 1 if the first or second operand bit is 1.

We described assignment operators, which set the value of a variable. The key points about assignment operators are as follows:

- Simple assignment, using =, assigns the value of the right operand to the left operand.
- The value returned is the value of the contents.
- Assignment and conversions are discussed in detail. They return a value that can be used within larger expressions.
- Compound assignment operators, of the form op=, exist for all binary non-boolean operators except that their effects are evaluated only once.

The ternary operator ?: (also referred to as conditional operator) requires three operands and provides the programmer with a more compact way to write if-else statement. The short-circuit operators && and || are binary operators that allow the program to circumvent evaluating one or more expressions, thereby making the code more efficient at runtime. The remainder of the operators discussed in this chapter are the comparison operators <, >=, and instanceof.

# Exam Essentials

Understand the functionality of all the operators discussed in this chapter. These are unary operators, the cast operator, binary arithmetic operators, comparison operators, bitwise operators, short-circuit operators, the conditional operator, and assignment operators.

Understand when arithmetic promotion takes place. You should know the type of the result of unary and binary operations performed on operands of any type.

Understand the difference between object equality and reference equality. Object equality checks two references point to the same object. Know the functionality of the equals() method of Object, Boolean, and String classes. The Object version uses reference equality check; the Boolean and String versions compare encapsulated data.
