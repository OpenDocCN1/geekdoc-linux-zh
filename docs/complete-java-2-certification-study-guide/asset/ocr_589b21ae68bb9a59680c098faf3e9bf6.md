The keys to this loop are in the three parts contained in the brackets following the for keyword:

+   - The statement is executed immediately before the loop itself is started. It is often used to set up starting conditions. You will see shortly that it can also contain variable declarations.

+   - The must be a boolean expression and is treated exactly the same as in the while() loop. The body of the loop will be executed until the condition ceases to be true. As the while() loop, it is possible that the body of for() loop might never be executed. This occurs if the condition is already false at the start of the loop.

+   - The expression (short for "iteration expression") is executed immediately after the body of the loop, just before the test is performed. Commonly, it is used to increment a loop counter.

If you have already declared an int x, you can code a simple sequence-counting loop like this:

```
1. for (x = 0; x < 10; x++) {
2. System.out.println("value is " * + x);
3. )
```

This code would result in 10 lines of output, starting with

value is 0

and ending with

value is 9

In fact, because for() loops commonly need a counting variable, you are allowed to declare variables in the statement part. The scope of such a variable is restricted to the statement or block following the for() statement and the for() part itself. This limitation protects counter variables from interfering with each other and prevents leftover loop count values from accidental re-use. The result is code like this:

```
1. for (int x = 0; x < 10; x++) {
2. System.out.println("value is " * + x);
3. )
```

It might be useful to look at the equivalent of this code implemented using a while() loop:

```
1. {
2. int x = 0;
3. while (x < 10) {
4. System.out.println("value is " * + x);
5. x++;
6. }
7. )
```
