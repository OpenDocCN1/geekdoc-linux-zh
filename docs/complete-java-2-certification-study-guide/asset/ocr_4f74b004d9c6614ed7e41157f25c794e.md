# Strings

Java uses the String, StringBuffer and StringBuilder classes to encapsulate strings of characters. Java uses 16-bit Unicode characters to support a broader range of alphabets than would be possible with traditional 8-bit characters. Both strings and buffers contain sequences of 16-bit Unicode characters. The next sections examine these two classes, as well as Java's string-concatenation feature.
