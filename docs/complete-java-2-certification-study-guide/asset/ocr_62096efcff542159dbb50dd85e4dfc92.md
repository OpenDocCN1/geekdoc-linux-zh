always occurs, and val ends up as either 1 or 2, depending on the original value returned by the random() method. In all cases, the value of test is true, because ever val starts out at 0, or it starts at 1 and the test (val == 2) is true.

So, the essential points about the && || || operators are as follows:

+   * They accept boolean operands.
* They evaluate the right operand only if the outcome is not based solely on the left operand. This is determined using these identities:
    * false AND X = false
    * true OR X = true

The next section discusses the conditional, ternary, operator. Like the short-circuit logical operators, this operator may be less familiar than others, especially to programmers without a background in C, C++, or C#.

# The Conditional Operator

The conditional operator—?:—also known as a ternary operator, because it takes three operands) provides a way to code simple conditions (if/else) into a single expression. The (boolean) expression to the left of the ? is evaluated. If true, the result of the whole is the value of the expression to the left of the colon; otherwise, it is the value of the expression to the right of the colon. The expressions on either side of colon must be assignment-compatible with the result type. For example, if a, b, and c are int variables, and x is a boolean, then the statement a = x ? b : c; is directly equivalent to the textually longer version:

```
1. if (x) {
2. a = b;
3. }
4. else {
5. a = c;
6. }
```

Of x, a, b, and c can all be complex expressions if you desire.

> Many people do not like the conditional operator, and in some companies its use is prohibited by the local style. This operator keeps source code more concise, but in many cases an optimizing compiler will generate equally compact and efficient code from the longer, and arguably more readable, if/else approach. One particularly effective way to abuse the conditional operator is to nest it, producing expressions of the form a = b ? c ? d : e ? f : g : h ? j ? k : l; Whatever your feelings or corporate mandate, you should at least be able to read this operator, because you will find it used by other programmers.
