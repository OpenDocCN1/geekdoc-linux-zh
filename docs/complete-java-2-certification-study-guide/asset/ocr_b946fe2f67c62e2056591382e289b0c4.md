# FIGURE 13.1 A socket and its streams

![](bbox=[0.248, 0.153, 0.597, 0.345])

The following code constructs a socket connected to port 1234 on a server named mangfalo, then reads and prints a byte sent by the server, and then sends a byte to the server:

```
try {
  // Make the socket.
  Socket sock = new Socket("mangfalo", 1234);

  // Get the streams.
  OutputStream ostr = sock.getOutputStream();
  InputStream istr = sock.getInputStream();

  // Read & print.
  System.out.println(istr.read());

  // Transmit.
  ostr.write(7);

  // Clean up.
  istr.close();
  ostr.close();
  sock.close();
} catch (IOException x) {
  System.out.println("Stress: " + x.getMessage());
}
```
