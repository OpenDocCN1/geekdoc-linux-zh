DateFormat class. To obtain a formatter for the current locale that uses a specific style, pass the style into the getInstance() call. Here's a piece of code that prints out a date in each of the formats (The locale is the U.S.)

```
int[] styles = { DateFormat.SHORT, DateFormat.MEDIUM,
DateFormat.LONG, DateFormat.FULL };

Calendar cal = Calendar.getInstance();
Date date = cal.getTime();nfor (int style:styles) {
DateFormat df = DateFormat.getInstance(style);
System.out.println(df.format(date));
}
```

Here's the output:

1/17/05
Jan 17, 2005
January 17, 2005
Monday, January 17, 2005
