+   6. C. The native method is an indicator to the Java Virtual Machine that the method actually lives in a library of Java. The System.loadlibrary() method is required to indicate which library contains the method. See Chapter 3 for more information.

+   7. An object denoted as final cannot have its data changed; however, the address location is determined as unchanging. The third statement is false because a final method cannot be overridden, and the second statement is false because a final class cannot be subclassed. See Chapter 3 for more information.

The extending class will have access to all the available methods in the extended class, and the methods may be called as they are defined in the extending class. If the extending class defines a method that exists in the extended class, that is said to be overriden the extended class. Because the extending class does not define any of the methods available in the extended class, it is that the subclass X is "a". See Chapter 6 for more information.
