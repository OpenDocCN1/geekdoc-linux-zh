# Assertions

A new facility called assertions was introduced in the Java 1.4 release. Assertions provide a convenient mechanism for verifying that a class's methods are correctly called. This mechanism can be enabled or disabled at runtime. The intention is be enabled during development and disabled in the field.

```
assert Expression1;
assert Expression1:Expression2;
```

Expression1 must be boolean. Expression2 may have any type. If assertions are disabled at runtime (the default state), the assert statement does absolutely nothing. If assertions are enabled at runtime (via a command-line argument to the JVM), Expression1 is evaluated. If its value is true, no further action is taken. If its value is false, an AssertionError is thrown, where it is converted to a String and used as the error message.
