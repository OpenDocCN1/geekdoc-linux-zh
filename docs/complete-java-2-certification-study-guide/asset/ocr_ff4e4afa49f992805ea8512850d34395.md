# # Conventions used in This Book

This book uses a number of conventions to present information in as readable a manner as possible. Tips, Tips, Notes, and Warnings, shown here, appear from time to time in the text in order to call attention to specific highlights.

![](bbox=[0.125, 0.233, 0.196, 0.273])

![](bbox=[0.125, 0.301, 0.196, 0.342])

This is a Note. Notes contain important side discussions.

![](bbox=[0.125, 0.369, 0.207, 0.409])

This is a Warning. Warnings call attention to bugs, design omissions, and other

This book takes advantage of several font styles. **Bold font** in text indicates something that the user types. A `monospaced font` is used for code, output, URLs, and directory names. A `monospaced italic font` is used for code variables mentioned in text.

These conventions are intended to facilitate your learning experience with this book—in other words, to increase your chances of passing the exam.

If you type, compile, and run the sample code in this book, you may observe slightly different results than what you see in the book. This is particularly true with code that has a GUI platform-with its owning system that displays buttons, check boxes, and so on.

We've included several testing features in this book and on the CD at the back of the book. These tools will help you retain vital exam content as well as prepare to sit for the actual exam. Using our custom test engine, you can identify areas up front and develop a solid studying strategy using each of these robust testing features. Your thorough `readme` will walk you through the quick and easy installation process.

Take this test before you reading the book. It will help you define the areas you may need to brush up on.
