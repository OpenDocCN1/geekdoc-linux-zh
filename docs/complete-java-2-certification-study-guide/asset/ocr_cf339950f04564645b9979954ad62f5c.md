# JTable

A first glance at javax.swing.JTable is overwhelming: the description is huge. A second glance is worse: numerous obscure event classes and listener interfaces are involved in ways that are not clear at all from reading the API page.

Fortunately, most of the methods needed to be called, and most of the events are just for the class' internal parts to communicate with one another. Still, you need to understand which parts of the class can sensibly manipulated. The way to really understand JTable is to understand the Model-View-Controller design pattern.
