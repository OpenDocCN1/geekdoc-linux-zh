This code fragment shows an example of how instanceof may be used. Assume that a class hierarchy exists with Person as a base class and Parent as a subclass:

+   1. public class Classroom {
2.   private Hashtable inTheRoom = new Hashtable();
3.   public void enterRoom(Person p) {
4.     inTheRoom.put(p.getName(), p);
5.   }
6.   public Person getParent(String name) {
7.     Object p = inTheRoom.get(name);
8.     if (p instanceof Parent) {
9.       return (Parent)p;
10.    }
11.  } else {
12.    return null;
13.  }
14.  }
15. }

The method getParent() at lines 6–14 checks to see if the Hashtable contains a parent with the specified name. This is done by first searching the Hashtable for an entry with the given name and then testing to see if the entry is returned is actually a Parent. The instanceof operator returns true if the left argument is the same as, or some subclass of, the class specified by the right operand equally.

You can also use the instanceof operator to test whether a reference refers to any array. Because arrays are objects in Java, this is natural enough, but the test that performed actually checks two things: First, it checks whether the object is an array, and then it checks whether the element type of array is subclass of the element type of the right argument. This is a logical extension of the behavior that is shown for simple types and reflects that an array of, say, Button objects is an array of Component objects, because a Button is a Component.
