# Container Components

Container components are components that can contain other components (including other containers). Containers use layout managers to determine the size and position of their children. The code examples in this chapter use the very basic FlowLayout manager. If you are unfamiliar with this class, just be aware that it arranges contained components in an evenly spaced row.

The container components that we will cover are

+   - JFrame
- JPanel

# JFrame

JFrame is an independent window that can be moved around on the screen independently of any other GUI windows. Any application that requires a GUI must have one or more frames to contain the desired components. The following code displays an empty JFrame:

```
1. import java.swing.*;
2.
3. public class FrameDemo {
4.     public static void main(String[] args) {
5.         JFrame f = new JFrame("Frame Demo");
6.         f.setSize(350, 250);
7.         f.setVisible(true);
8.     }
9. }
```

Line 5 demonstrates a constructor whose argument is a string that newly constructed JFrame has zero width and height and must be given a size before it is shown. You can set size explicitly, in line 6, or call pack() which respects preferred sizes and layouts of its components. Line 7 is necessary because a newly created JFrame is not visible on the screen. If, at some point, you want to remove a visible frame from the screen, you can call setVisible(false).

An empty frame is not very useful. Frames are intended to be populated with child components. Readers familiar with Java AWT know that the Frame implementation allows for child components to be directly added. The JFrame class is different in that it is not a container. You access the content portion of the frame by calling the JFrame's getContentPane() method. The following application displays a frame whose content pane contains three buttons.
