# Scanning Text

Text scanning is the art of extracting information from text. This can be daunting because human-language text is designed to have its information extracted by human minds. Release 5.0 helps by providing a class called java.util.Scanner.

The API page for this class calls "A simple text scanner which can parse primitives and strings using regular expressions." In this context, parse means to extract the strings from their natural language context. The term simple is subject to debate. It's easy enough to figure out how to use this class, except for one detail: regular expressions.

Regular expressions are an extensive topic in their own right, dating back to the early days of Unix. You can use a regular expression as a string that encodes a description of a general text pattern. For example, the regular expression \s+ one or more blank spaces. Encoding a representation for a more sophisticated pattern, such as an optional sign by five to seven digits followed by a period, takes considerable effort. If you look at the description of regular expressions in the API (it's on the page for java.util.regex.Pattern), you'll see it is so extensive that can't be possible to know it by heart. So you can treat this as an overview and just use the basic idea. As long as you recognize a very simple regular expression you will do fine on the exam.

> The description of regular expressions in the API is on the Pattern class in the java.util.regex package. This package also contains a class named Matcher. A matcher is an engine that scans input, using a pattern to guide its behavior. You rarely ever use these classes directly. Instead, you use classes like Scanner, which in turn use Pattern and Matcher.

A scanner breaks up an input into tokens and delimiters. Tokens are parts of a string that have meaning. Delimiters are used to set tokens. For example, if you're trying to extract the numeric values from the comma-separated string "12, 3.1415, 49", then the tokens are 12, 3.1415, and 49, because those are the parts of the string that convoy meaning to you. The commas are delimiters.

The Scanner class has a large number of constructors. The simplest one is

```
public Scanner(String source)
```

The source is to be scanned for tokens. Other constructor versions specify different text sources, such as files or input streams. After a scanner is constructed, it must know what delimiter or delimiters to use. This is done by calling the scanner's useDelimiter() method, passing in a regular expression that represents the delimiter. For example, suppose your input string consists of integer numbers, separated by x characters. You can set up your scanner as follows:

```
String scanMe = "123x2x3x";
String delim = "x";
```
