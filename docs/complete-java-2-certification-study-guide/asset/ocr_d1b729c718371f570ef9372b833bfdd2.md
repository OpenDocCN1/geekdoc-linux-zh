20. What does the following code print?

```
public class A
{
    static int x;

    public static void main(String[] args) {
        A that1 = new A();
        A that2 = new A();
        that1.x = 5;
        that2.x = 1000;
        x = -1;
        System.out.println(x);
    }
}
```

+   A. 0

+   B. 5

+   C. 1000

+   D. -1
