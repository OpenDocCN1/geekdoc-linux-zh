# The Addition and Subtraction Operators: + and -

The operators + and - perform addition and subtraction. They apply to operands of any numeric type, uniquely, + is also permitted where either operand is a String object. Java does not allow the programmer to perform operator overloading, but the + operator is overloaded by the language. This is not surprising, because most languages that support arithmetic types, the arithmetic operators (+, -, *, /, and so forth) are overloaded to handle different types. Java, however, overloads the + operator to support concatenation—that is, joining together with String arguments performs conversions, and these can be succinct and expressive if you understand them, first we consider the use of the + operator in its conventional role of numeric addition.

> Overloading is the term when the same name is used for more than one piece of code, and the code that is to be selected by the argument or operand types provided. For example, the println() method can be given a String or an int. These two actually refer to entirely different methods; only one is reused. Similarly, the symbol is used to indicate the addition of int values, but the exact same symbol is used to indicate the addition of float values. These two forms require entirely different code to execute; again, the operands are used to decide which code to run. Where an operator can take different operand types, we refer to operator overloading. Some languages, but not Java, allow you to use operator-loading for your own types. Overloading is described in detail in Chapter 6, "Objects and Classes."

Where the + operator is applied to purely numeric operands, its meaning is simple and familiar. The operands are added together to produce a result. Of course, some promotions might take place, according to the normal rules, and the result might overflow. Generally, numeric addition behaves as you would expect.
