Instance methods have an implicit variable named, which is a reference to the object executing the method. In static code, you can refer to a variable or method without specifying which object's variable or method you mean. The compiler assumes you mean this. For example, consider the following code:

+   1. class Xyzy {
2. int w;
3. 
4. void bumpW() {
5. w++;
6. }
7. )

On line 5, the programmer has not specified an abbreviation for object's to be incremented. The compiler assumes that line 5 is an abbreviation for this.w++.

With static methods, there is no this. If you try to access an instance variable or call an instance method within a static method, you will get an error message that says, "Undefined variable:" The concept of "the that is executing the current method" does not mean anything, because there is no such instance. Like static variables, static methods are not associated with any individual instance of their class.
