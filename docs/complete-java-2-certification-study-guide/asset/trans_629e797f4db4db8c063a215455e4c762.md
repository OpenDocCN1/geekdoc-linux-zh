
反斜符非常棘手。假设你想使用 `"\s"` 作为一个指定分隔符的正则表达式。以下代码将无法工作：

```
scanner.useDelimiter("\s");
```

事实上，这一行无法通过编译！正则表达式处理器并不是唯一一个在字面量字符串中使用反斜符的组件。Java 编译器也是如此，而且它不会将 `"\s"` 识别为转义序列。该行代码会产生一个“非法转义字符”的错误：

```
scanner.useDelimiter("\s");
```

第一个反斜符告诉编译器第二个反斜符应该被接受，而不是将其视为对 `"\s"` 进行特殊处理的指令。编译器会剥离第一个反斜符，并在内部存储 `"\s"`。遗憾的是，正则表达式编程要求你像你所想的那样去思考，并问自己你的源代码是否与表达式处理器使用的表达式一致。

现在，假设你需要扫描一个输入字符串，其中的标记可能由一组一个或多个 `"\x"` 字符分隔。该输入可能是 `"132xxxx555"`。目前的扫描器状态：输出将在 `"132"` 和 `"555"` 之间产生几行空行。这是因为扫描器将这些连续的 `"x"` 视为条目之间的分隔符，每个条目都打印在单独的一行中。

我们需要一个表示一个或多个 `"\x"` 的分隔符正则表达式。我们想要的字符串是一个或多个，`"+"` 表示表示一个或多个 `"\x"`。`"+"` 符号被称为量词。量词是正则表达式中的一种符号，表示输入字符的序列。你在考试中应该掌握的量词有：

- + 匹配前一个模式的零次或多次出现
- * 匹配前一个模式的一次或多次出现
- ? 匹配前一个模式的零次或一次出现

如果你查看正则表达式（在 `java.util.regex.Pattern` 的 API 页面），你会发现这些量词中的每一个都可以被设置为“贪婪的（greedy）”、“懒惰的（reluctant）”或“独占的（possessive）”。这种区别非常简单，而考试只需要你了解默认行为，即“贪婪的”。贪婪量词匹配最大的字符序列。

你可以使用括号对字符进行分组，然后对该组应用量词。例如，`"(ab)*"` 匹配一个或多个 `"ab"` 的出现，如 `"abab"` 或 `"abababab"`。

`String` 类有一个新方法（从 5.0 版本开始）称为 `split()`，它使用正则表达式将字符串拆分为子字符串数组。语法如下：

```
public String[] split(String regex)
```

## 295 扫描和格式化文本

字符串包含不变的文本和针对值的格式化指令。让我们来看一个简单的例子：

```
StringBuilder sb = new StringBuilder();
Formatter f = new Formatter(sb);
boolean b = false;
f.format("The value is %b", b);
System.out.println(sb);
```

输出是：`The value is false`

第一个反斜符告诉第二个反斜符被接受。如果你想调整顺序，可以在 `%` 后面紧跟一个数字和一个美元符号（`$`），如下：

```
StringBuilder sb = new StringBuilder();
Formatter f = new Formatter(sb);
boolean b = false;
f.format("%2b? %f", true);
System.out.println(sb);
```

`$` 符号用于指定参数而不是下一个。输出是：`true? 3.141592653589793`

实际上，特殊代码不需要与参数一一对应。如果你想调整顺序，可以在 `%` 后面紧跟一个数字和一个美元符号（`$`），如下所示：

```
StringBuilder sb = new StringBuilder();
Formatter f = new Formatter(sb);
boolean b = false;
f.format("%1f? %b", true);
System.out.println(sb);
```

输出是：`3.141592653589793 true`

到目前为止，你可能对格式化器并不感兴趣，但这是因为你只看到了它们能做的基础，而且如果你只停留在基础，你比普通的字符串拼接并没有好到哪里。毕竟，最后一个代码示例产生的输出是单行的：

```java
System.out.println("Would you like some %s ? %s" + Math.PI);
```

输出是：`Would you like some 3.141592653589793`

格式化的真正威力在于你进行微调以使字符串更具可读性。格式化中的一个非常强大的功能是字段宽度指定。这是一个数字（可以是正或或负），决定了值的表示的字符宽度。字段宽度紧跟在 `%` 后面（就像参数规范但没有美元符号）。如果宽度为正，则值将在字段中右对齐；如果宽度为负，则值将左对齐。这里有一个例子：

```
StringBuilder sb = new StringBuilder();
Formatter f = new Formatter(sb);
int a = 1234;
int b = 5;
f.format("*%7d and b = %-7d!!!", a, b);
System.out.println(sb);
```

输出是：

```
a = 1234        b = 5      !!!
```

注意 `a` 的值占据了字段的右侧，左侧用空格填充。`b` 的值占据了字段的左侧，右侧用空格填充。
