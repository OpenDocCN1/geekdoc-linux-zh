The format() call uses its first argument as a guideline. Any text up to a special character is appended literally to the string builder. The % sign is a special code that indicates the method's second argument is to be formatted and inserted into the text. The argument index is followed by a dollar sign ($), which is followed by formatting. In the simplest cases, formatting information is a single letter. The format codes you need to know about are these:

- %b a value (wrapper or primitive)
- %c an integer
- %d a floating-point number
- %s an object, generally by calling its toString() method

Now you can see how our first example worked. The format string was appended to the string builder until the %b code was reached. This meant that the method's second argument is to be formatted as text representing a boolean value and appended to the string builder. After that the remainder of the format string (since it has no more special characters) was to be appended.

If a format string has more than one special character, the formatter expects the format() method to have one argument for each special character. By default, they are formatted in the order of appearance. For example, here's a format string with two format codes and two additional arguments:

```
StringBuilder sb = new StringBuilder();

boolean b = false;
```

The real power of format comes into play when you make subtle adjustments to make your strings more readable to humans. A very powerful feature of formatting is the field width specification. This is a number (it may be positive or negative) that dictates how many characters wide a value's representation will be. The field width comes right after the % (just like the argument spec but without the dollar sign). If the width is positive, the value will be right-justified in a field of the specified width; if the width is negative, the value will be left-justified. Here's an example:

```
StringBuilder sb = new StringBuilder();
Formatter f = new Formatter(sb);
int a = 1234;
int b = 5;
f.format("*%7d and b = %-7d!!!", a, b);
System.out.println(sb);
```

The output is

```
a = 1234        b = 5      !!!
```

Notice that the value of a occupies the right end of its field, with the left end padded with spaces. The value of b occupies the left end of its field, and the right end is padded with spaces.
