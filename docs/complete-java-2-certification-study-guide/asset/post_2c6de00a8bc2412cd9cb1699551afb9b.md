
49. Suppose you want to run the following command line on a Windows system:

```
java -classpath somewhere;elsewhere aaa.bbb.MyApplication
```

```
java -classpath somewhere:elsewhere aaa.bbb.MyApplication
```

- D. The file MyApplication.class must be found either in somewhere\aaa\bbb or in elsewhere\aaa\bbb. (Substitute forward slashes for backslashes on a Unix system.)
