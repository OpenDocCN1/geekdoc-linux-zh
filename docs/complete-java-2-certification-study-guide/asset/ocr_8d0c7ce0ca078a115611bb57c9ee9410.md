There is another way to construct any of these classes, with the exception of Character: You can pass into the constructor a String that represents the value to be wrapped. Most of these constructors throw NumberFormatException, because there is the possibility that the constructor will not represent a valid value. Boolean does not throw this exception; the constructor accepts any String input and returns a true value if the string (ignoring case) is true. The following code fragment shows how to construct wrappers from strings:

```
1. Boolean wrappedBoolean = new Boolean('True');
2. try {
3. Byte wrappedByte = new Byte('41');
4. Short wrappedShort = new Short('31313');
5. Integer wrappedInt = new Integer('12345678');
6. Long wrappedLong = new Long('1234567897654321');
7. Float wrappedFloat = new Float('1.11f');
8. Double wrappedDouble = new Double('1.11111111');
9. }
10. catch (NumberFormatException e) {
11. System.out.println("Bad Number");
12. }
```
