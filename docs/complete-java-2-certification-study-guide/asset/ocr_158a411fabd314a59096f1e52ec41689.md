Another family of tags with @ and extends to the end of the line. The @tags are
@author
@version
@see
@return
@param
@throws

The first three of these tags are for commenting a class. The last three appear in method comments. Here's a fully commented VectorOfStrings class that uses each kind of tag you've seen so far:

```
package xyz;
import java.util.*;
import java.io.*;
```
