17. D. Variables may not be synchronized. Making the variables volatile or static doesn't address the problem. Shared data in a multithreaded environment should be protected from corruption by ensuring that all access to the data is via synchronized methods. Moreover, all methods should synchronize on the same lock.

18. D. The only way to ensure that multithreaded deadlock is to be careful. There is no single technique that can guarantee non-deadlocking code.
