consider the java.util.Date class, which represents a moment in time. Suppose you have two
references of type Date: d1 and d2. One way to compare them is with the following line of code:

```
```java
if (d1 == d2) {
    }
```
```

The comparison will be true if the reference in d1 is equal to the reference in d2. Of course, this
is the only case when variables refer to the same object.

Sometimes you want a different kind of comparison. You don't care which d1
d2 refer to the same Date object. You know they are different objects. What we care about is the two objects, which encapsulate date and time information, represent
the same moment in time. In this case, you don't want the shallow reference-level comparison
of ==; you need to deeply look into the objects themselves. The way to do that is with the

```
equals(d1.equals(d2))
```

The version of equals() provided by the Object class is not very useful because it just does
an == comparison. All classes should override equals() so that it performs a useful comparison.
just is what most of the standard Java classes do; they represent the relevant information
two objects.

The purpose of the toString() method is to provide a string representation of an object's
state. This method is useful for debugging.
The toString() method is similar to equals() in that version provided by the Object
class is not especially useful—it prints the object's class name, followed by a hash
code. Many classes override toString() to provide more information. Java's
string-concatenation facility makes use of this method, as you will see later in this chapter, in
the "String Concatenation The Easy Way" section.

The Object class provides a clone method, which returns a copy of the current object. In
other words, the clone has the same class as the original, and all its values are identical.
Thus all references in the clone point to the same objects as those pointed to in the original.
Object's version of clone() is protected, so a class clone() may not be called by any
code anywhere. If you want a class clone() to be public, you need to insert something like
the following:

```
```java
public Object clone() {
    throws CloneNotSupportedException {
    return super.clone();
}
```
```

Notice the CloneNotSupportedException. It is a runtime exception, so it must be dealt
with classes that override clone() generally declare that they implement java.lang.Cloneable,
which defines the single clone() method.
