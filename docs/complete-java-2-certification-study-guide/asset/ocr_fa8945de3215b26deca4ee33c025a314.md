And here, the 0 operand bits also result in a 0 result.
The OR operation again takes a similar approach, but with its own rules for calculating the result bits. Consider this example:

```
00110011
11110000
--------
11110011
```

Here, the two operand bits are 1 and 0, so the result is 1.

```
00110011
11110000
--------
11110011
```

However, in this calculation, both operand bits are 0, which is the condition that produces a 0 result bit for the OR operation.
 programmers usually apply these operators to the bits in integer variables, it is also permitted to apply them to Boolean operands.

# Boolean Operations

The comparison operators behave in fundamentally the same way when applied to arguments of boolean, rather than integral, types. However, instead of calculating the result on a bit-by-bit basis, deis, the boolean values are treated as single bits, with true corresponding to a 1 bit and false to a 0 bit. The general rules discussed in the previous section may be modified like this when applied to boolean values:

+   - For AND operations, true AND produces true. Any other combination produces false.
- For XOR operations, true XOR produces true, false XOR produces true. Other combinations produce false.
- For OR operations, false OR produces false. Any other combination produces true.
