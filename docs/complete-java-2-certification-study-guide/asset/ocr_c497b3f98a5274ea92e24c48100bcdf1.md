Modern operating systems know what part of the world they are operating in—they are
given this information when they are installed. The machine's locale is accessible to the JVM.
By default, the encoding used by a reader or writer is the one appropriate to the machine's
locale. However, readers and writers have forms of constructors that allow you to specify any
desired locale. (You specify a locale by providing a string that identifies it.)
When the data written by a writer is to be read within the same locale, you don't need to con-
s encoding to use; the default encoding will be appropriate. On the other hand, it may
be that the data will cross a locale boundary. The writer might be connected to a socket, which
communicates with a machine in a different locale. Or perhaps the writer is writing to a file
of a floppy disk that will be carried across a boundary. In such cases, the people involved must
agree on encoding; the common practice is to use the U.S. ASCII encoding. For programmers
in the United States, this is conveniently the default. Others must specify this encoding when
constructing readers and writers. The strings that denote encoding names are determined by
standards committees, so they are not especially obvious or informative. For example, the U.S.
ASCII encoding is not USASCII as you might expect, but rather IS08859-1.

# Object Streams and Serialization

As you have seen, input and output streams allow you to read and write primitives and
strings, rather than individual bytes. Object streams go one step beyond data streams by allow-
ing to read and write entire objects.

The process of writing an object is called serialization. To serialize an object, first create
in instance of io.ObjectOutputStream. This class, like DataOutputStream, expects
to be chained onto a lower-byte-oriented stream such as a file output or a socket's
output stream. The method uses an object stream to store a string buffer in a file named
suffer.

```
void writeStringBuffer(StringBuffer writeMe)
  throws IOException {
    FileOutputStream fos = new FileOutputStream("buf.ser");
    ObjectOutputStream oos = new ObjectOutputStream(fos);
    oos.writeObject(writeMe);
    oos.close();
    fos.close();
}
```
