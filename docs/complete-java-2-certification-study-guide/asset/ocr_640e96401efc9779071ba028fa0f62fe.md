# Server Sockets in Java

From a programmer's point of view, the main difference between a client and a server has to do initiation. A client always gets to assume that a server is available. You can see this assumption when you construct a Socket instance: the constructor automatically connects to the specified server's port.
A server, on the other hand, makes itself available and waits for clients to initiate connections. This is done with an abstraction called a server socket, which in Java is represented by the java.net.ServerSocket class. The most useful form of the ServerSocket constructor is

public ServerSocket(int portNumber)
