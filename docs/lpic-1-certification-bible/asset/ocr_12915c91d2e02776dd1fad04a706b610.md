# Setting up the installer

The installation begins by booting off either the Red Hat CD-ROM or boot floppies. The easiest and fastest method is the CD-ROM, if your computer has a BIOS new enough to do that. If you put in the CD-ROM and it does not boot off it the first time, check your BIOS setup for an option. Normally this option will be listed as the boot order for the system. If it is set to a hard disk or the floppy first, change it to the CD-ROM option.

![](bbox=[0.18, 0.44, 0.25, 0.49])

To create the boot disks you can use the Raw Write (rawrite.exe) tool, which is available on the Red Hat site under douutils. The available boot disks are boot.img, bootnet.img, drivers.img and pcmcia.img. The boot.img is for CD-ROM installs, and bootnet.img is for network installs. You should make the drivers.img disk, which contains network card drivers, unless you are using a notebook, for which the pcmcia.img is used.
