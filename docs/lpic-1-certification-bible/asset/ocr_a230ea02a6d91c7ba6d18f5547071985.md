The bootp/rapd process provides bootp/rapd, a server process which provides the information needed by distant clients in order for them to successfully boot. Bootp/rapd looks first in /etc/bootp/rastras for an entry for that particular client, if a local bootp/rapd file doesn't exist, it looks at the appropriate Network Information Service (NIS) map. Some network boot loaders (notably Sunrk) rely on special boot server code on the server, in addition to the RARP and TFTP servers. Unresolved Dependencies
Many software packages depend on other packages or libraries in order to work correctly. To make sure your system has all the packages it needs in order to work, Red Hat Linux checks these package dependencies each time you install or remove a package. If one package requires another package that has not been installed, unresolved dependencies exist.

+   - - Do not install packages that have dependencies
