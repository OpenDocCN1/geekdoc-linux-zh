# route

The `route` utility is used to display, delete, and add a route. The most common options for `route` are shown in Table 15-9. Having a default gateway configured in the routing table is imperative. Without this entry, no data will be delivered beyond the local network segment. The `route` command can also be used to configure the system to act as a router when multiple network interfaces are installed. With proper configuration, Linux is capable of routing information between connected network segments. When Linux receives information, it maintains a cache of destinations. This allows it to quickly route information to frequently requested destinations. The following is an example of the data displayed using the `route` command.
