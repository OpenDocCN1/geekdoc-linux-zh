The command syntax is shown next.

```
SYNOPSIS
  ls [OPTION]... [FILE]...
```

This is followed by a description of the command. After the description the command options are displayed and explained.

```
DESCRIPTION
  List information about the FILEs (the current directory by default).  Sort entries alphabetically if none of -cftuvSX nor --sort.

  -a, --all
    do not hide entries starting with .

  -A, --almost-all
    do not list implied . and ..

  -b, --escape
    print octal escapes for nongraphic characters

  --block-size=SIZE
    use SIZE-byte blocks

  -B, --ignore-backups
    do not list implied entries ending with ~
```
