# Displaying files backwards

The `tac` utility is used to display lines of a file in reverse where, by default, a new
line begins after the line feed character. This is the opposite of the `cat` command in
spelling and function.

The syntax for the `tac` utility is as follows:

```
# tac options file
```

The options used with this utility are shown in Table 4-14.
