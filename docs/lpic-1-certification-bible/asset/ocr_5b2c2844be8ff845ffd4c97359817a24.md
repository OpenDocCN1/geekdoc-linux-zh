The ps command is useful for providing a snapshot of the process status. However, there are times that you may want real-time information on the system processes. The top command is used for this purpose. Because this process itself is as CPU intensive, it should be used only when necessary. The information presented by top can be arranged according to CPU usage, memory usage, and runtime. The most common way to run top is simply to type the command name at the command line. From within the top utility type the s command and then specify the option that you wish to use. The options used with top are displayed in Table 2-6.

# Table 2-6
Options Used with top

| Option | Use |
| :--- | :--- |
| d | Specifies the seconds between updates. |
| q | Specifies that there should be no delay between updates. |
| S | Specifies that child process information should be included in the information displayed. |
| s | Runs the process in secure mode. |
| i | Specifies that idle processes are to be ignored. |
| c | Displays the full command line of processes. |
