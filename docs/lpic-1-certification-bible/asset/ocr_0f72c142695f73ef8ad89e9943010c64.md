Remote Windows and Samba shares can be mounted as a local file system, which is sometimes more convenient than using smclient. The syntax for this is as follows:

```
mount -t smbfs -o username=<username>//server/share /mount_point
```

For this to work, the smb file system support must be compiled into the kernel.
