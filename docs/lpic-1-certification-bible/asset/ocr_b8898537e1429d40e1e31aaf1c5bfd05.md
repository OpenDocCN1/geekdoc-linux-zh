# Using make xconfig

The easiest interface to use is *make xconfig*. Figure 13-2 shows an example of this interface. This provides a nice point-and-click interface, but requires a X Window system to be installed and functional. Like *menuconfig*, *xconfig* is a menu structure, and options are selected with * meaning compiled into the kernel and M meaning compiled as a module.

The *make xconfig* interface requires the installation of the TCL/TK toolkit. Most Linux distributions install this toolkit by default.
