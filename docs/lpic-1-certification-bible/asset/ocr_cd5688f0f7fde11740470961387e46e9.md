| Miscellaneous Capabilities | Functions |
| --- | --- |
| `shutdown <path>` | The server periodically checks the file specified in <path> to see if the server is going to be shut down. The file has the following format: <year><month><day> <hour><minute><second><deny_offset> <time_zone> <disc_offset> <text>, <deny_offset> and <disc_offset> specify the offset times before shutdown when connections will be denied and then disconnected. |
| `daemonaddress <address>` | Defines the IP addresses that the server will listen on. By default it is all addresses. |
| `virtual <address><root|bannner|logfile><path>` | Enables virtual server capabilities. |

| Permission Capabilities | Function |
| --- | --- |
| `chmod <yes|no> <typelist>` | Sets the ability to change file permissions. |
| `delete <yes|no> <typelist>` | Sets the ability to delete files. |
| `overwrite <yes|no><typelist>` | Sets the ability to overwrite files. |
| `rename <yes|no> <typelist>` | Sets the ability to rename files. |
| `umask <yes|no> <typelist>` | Sets the ability to set file creation permissions. |
| `passwd-check<none|trivial|rfc822>(<enforce|warn>)` | Sets the level of password checking done by the server for anonymous FTP. The following options are available:<br><br>`none` – No password checking is performed.<br><br>`trivial` – The password must contain an `@` character.<br><br>`rfc822` – The password must be an rfc822 compliant address.<br><br>The following two parameters set what happens when the check fails:<br><br>`warn` – Warn the user, and allow the user to log in.<br><br>`enforce` – Warn the user and then log the user out. |
| `path-filter <typelist><mess><allowed_charset>(<disallowed regexp>...)` | Defines a regular expression that limits the possible characters used in filenames or paths. |
