| Table 16-26 options Statements |  |

| Statement | Function |
|:---|:---|
| `version "string";` | Change the version number reported to clients. Some people consider this more secure. |
| `directory "path";` | The full path of the working directory of the server. Other paths in the configuration file may be relative paths to this directory. |
| `notify yes\|no;` | If this server is a master server for others, notify the slave servers when a change is made to a zone database. |
| `also-notify <server address> ...;` | Also notify other servers not listed in your configuration file. Useful for sites that have separate internal servers that are not advertised to the world. |
| `recursion yes\|no;` | By default the DNS server will check recursively through the namespace to find an answer to a client’s query. This statement can disable this function. |
| `maintain-ixfr-base yes\|no;` | Send changes only to other servers, not the entire database, during zone transfers. |
| `transfers-in <number>;` | Limit the number of inbound zone transfers at one time. |
| `transfers-out <number>;` | Limit the number of outbound zone transfers at one time. |
| `forwarders (ip addresses);` | A list of servers that queries are forwarded to, instead of being resolved by this server. |
| `forward only \| first;` | If set to *only*, this server will only forward requests to other servers and not resolve them itself. If set to *first*, the server tries to forward the query, but if that fails, it will resolve the query itself. |
| `allow-query {address match list};` | Limit the clients that can query your DNS server. |
| `allow-transfer {address match list};` | Limit the systems that can request zone transfers from your server. |
| `blackhole {address match list};` | Systems in this list cannot communicate with your DNS server. |
