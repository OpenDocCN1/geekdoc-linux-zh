# Removing modules

Modules are removed with the `rmmod` command. The syntax for this command is as follows:

```
`rmmod module-name`
```

Table 13-2 shows the available options for `rmmod`. For a module to be removed, it must not be in use, and it should be set as autoclean. The `-r` option can be used to remove modules recursively, by removing all modules referenced by the named module.
