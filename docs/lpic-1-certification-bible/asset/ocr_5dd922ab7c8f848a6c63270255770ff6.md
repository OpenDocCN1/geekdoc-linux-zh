In this example, for the user `json`, the first field in the shadow file is the user name. The second field is `json`’s password in encrypted form. The third field is the day the password was set. This value is in the form of the number of days since January 1, 1970. The fourth field is the number of days the user must wait between password changes, in this case that is zero days. The fifth field is the number of days the password remains valid, which for `json` is 99,999 days. The sixth field is the number of days before the password expires that the user will be warned to change the password. The user `json` will be warned one week before the password expires. The last three fields are unused in this file. The seventh value contains the number of days after password expiration to wait before treating the login as expired. The eighth field specifies a number of days from January 1, 1970, to wait before expiring the login. The ninth field is reserved for future use.
