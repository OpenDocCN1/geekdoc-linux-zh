# 引言

有不同类型的黑客具有不同的意图。根据其操作方式，我们可以将黑客分为以下几类：





# 1. 白帽黑客

他们是好人，因为他们没有恶意。也许他们之所以被称为“白帽”黑客，是因为白色象意着纯洁和清洁。他们黑入系统是为了消除其漏洞，或者作为为专注于计算机安全的公司或学校进行研究的手段。他们也被称为伦理黑客。他们执行渗透测试并评估计算机系统的漏洞。

# 2. 黑帽黑客

黑帽黑客在黑入时带有恶意，意图是打破书面上的所有规则。他们为了个人利益以及金钱目的而黑入。众周知他们来自非法社区，完全符合计算机罪犯的刻板印象。黑帽黑客利用网络的弱点使系统瘫痪。如果有机会，这些黑客还会破坏你的数据和信息。当这些黑客进入你的系统时，他们会威胁要向公众公开你的隐私信息，目的是迫使你做他们想要的任何事情。不用说，黑帽黑客不会修复你计算机系统或网络中的漏洞，而是会利用它们对你。

# 3. 灰帽黑客

灰帽黑客的意图与上述的黑客无法相比。这些黑客会搜寻互联网寻找计算机系统或网络中的弱点并黑入其中。他们这样做可能是向网络管理员展示网络中的漏洞，并就特定价格建议纠正这些漏洞的方法。

# 4. 蓝帽黑客




据说，蓝色代表执法人员，尽管这仅仅是一种惯例。这些黑客是自由职业者，他们将自己的黑客技术作为服务出售。计算机安全公司聘请黑客专家来测试它们的网络，以便在发布给公众之前检查是否存在弱点、漏洞和缺陷。蓝帽黑客是“好人”，与灰帽黑客不同，后者的意图可能不可预测。

# 第 2 章：黑客过程

## A. 黑客过程是如何运作的，以及攻击者如何隐藏踪迹

计算机作为一台独立的硬件设备，并不是一台智能机器。是为计算机编写的程序决定了它能做什么和不能做什么。本章将教你一些编程的基本原理，以及如何选择编程语言。在本章结束，你将发现一个练习，它将帮助你用 `Python` 计算机语言编写一个程序。

### 为什么学习黑客需要学习编程语言
计算机通过一系列开关进行运行。这些电子开关以不同的组合被打开/关闭。这构成了计算机的功能。为了让计算机打开或关闭开关，计算机程序使用二进制代码发送消息。二进制代码是 `0` 和 `1` 的序列，其中 `0` 表示开启，`1` 表示关闭。

二进制代码的问题在于它是极其复杂的。即使是高级程序员，花费很长时间来解释代码，更不用说修改它来完成他们想要的操作了。这就是编程语言大显身场的地方。

编译器将编程语言中的预定义命令翻译成计算机可以读取的二进制代码。

### 关于编程语言的一些考虑（以及关键术语）
为了选择最适合学习的程序，你应该考虑你想用你的黑客/计算机知识做什么。在学习不同编程语言的过程中，你可能会遇到一些常用术语：

#### 语言代
总的来说，随着技术的进步，计算机语言也在进步。目前有五代计算机语言：
- 第一代（`1GL`）是最原始的。它们很难编写，因为它们是用二进制代码（`0` 和 `1`）编写的。
- 第二代（`2GL`）通常被称为汇编语言。这是第一步，允许程序员使用命令符号名称，而不仅仅是二进制代码。
- 第三代（`3GL`）是另一个进步，开发了如 `Javascript`、`Java`、`C` 和 `C++` 等高级语言。`3GL` 允许在编程中使用命令和单词。
- 第四代（`4GL`）是一种类似于人类语言的编码类型。这种编程常用于数据库访问，最常见的是 `ColdFusion` 和 `SQL`。
- 第五代（`5GL`）是目前最先进的语言，其应用是神经网络。神经网络模拟人类大脑的内部运作机制，应用于人工智能领域。

## B. 实战中的侦察
黑客在决定攻击系统（服务器、网络等）时，做的最重要的事情之一就是尽可能收集关于该系统的数据。

这样想：当你想要去一个没去过的地方/国家度假时，你在做什么？最可能是在做功课。这意味着你对那个位置感兴趣。你正在 `Google` 上寻找不同的信息（你在那里可以做什么，如天气/食物、该地区的评价等）。换句话之，你正在获取关于目标的信息。

黑客在决定攻击系统时，正是通过这个过程。你有多种方法了解更多关于/服务器的信息，最简单的方法之一是在 `Google` 上搜索关于它的信息。

通过简单的命令如 `nslookup`（或 `dig`），你可以找到一个网站的 IP 地址，通过 `whois` 命令你可以找到更多关于该域名的信息。

```
nslookup google.com
whois google.com
```

`Reconnaissance`（侦察，或信息收集）这一术语源于在采取行动之前对特定主题进行研究和获取信息的想法。简而言之，它基本上意味着在行动之前进行记录。从时间的角度来看，这个过程最“昂贵”。为什么？因为攻击者需要有充分的准备，他需要了解细节，否则（正如我们在第 5 步中所说的）将冒他自己的自由。

## C. 扫描系统
“黑客过程”的下一步是扫描。一旦黑客获取了更多关于目标的信息，他将开始学习更多信息（这次是技术性的）。他将如何做呢？使用各种工具（如 `Nmap`）扫描网络、服务器，并提供关于网络拓扑、所用设备、操作系统等更清晰的信息。

为什么它们很重要？为什么对黑客来说知道特定的 Web 服务器运行在 `Windows` 还是 `Linux` 上很重要？因为一旦拥有这些信息，他就可以在 `Google` 上进行少量研究后进一步行动（第 3 步），发现一些已存在的漏洞并尝试利用它们以获取该系统的访问（或提取某些数据）。

## D. 获取系统访问权限
在完成准备工作（研究、扫描网络/服务器、从不同来源——`Google`、`Facebook`、论坛——获取关于目标的信息）后，黑客可以开始攻击。攻击应该经过仔细考虑以处于隐身模式（不触发警报并且——如果可能——不产生太多的日志）。

有很多工具（`Burp Suite`、`SQLmap`、`Metasploit` 等）可以生成网络攻击，一切取决于技术和目标。

获取访问可以通过多种方式和从多个视角实现：
- 在 `Linux` 服务器上获取 root 权限
- 获取网站管理面板的访问
- 获取特定网络设备（路由器、防火墙、交换机等）的访问
- 获取网络终端设备（智能手机、平板电脑、笔记本电脑等）的访问

一旦黑客获取了上述列出的项目之一，他就渗透了网络，并可以获取关于他所属（数字）的大量信息。

## E. 维持访问权限
一旦进入网络，黑客就有保留访问的选项。在很多情况下，当大公司（`Yahoo`、`Google`、`Microsoft` 等）的不同服务器被攻破时，黑客总是留下后门以重新进入系统。

这些后门被称为“后 door”，是黑客故意留下的（甚至是你我每天使用的任何应用程序的软件开发者留下的），以便以后访问系统。这样他们就可以不断提取数据，跟踪组织内发生的情况，保持控制，然后对这些数据进行某些操作，这些数据通常在黑市出售（`Deep Web`）。

## F. 隐藏踪迹
这是一个非常重要的过程（“Trace Coverage”，即踪迹覆盖/隐藏）。许多黑客（特别是那些在路边的人）为了不被发现而忽略了它。他们只是没有注意到（或意识到）隐藏踪迹会导致被捕获（在美国，通过 `FBI`、`CIA` 或 `NSA`）并在法庭上受到处罚。

## G. 报告
另一个重要的步骤，特别是在伦理黑客过程中，是报告。黑客生成一份关于发现的（以及被利用的）漏洞的报告，以及修复这些问题的信息。

## H. 使用 BURP SUITE 进行 WEB 攻击
目前在线最强大的工具是“Suite”。`Suite` 是一个提供 Web 服务和渗透测试的应用程序。当它充分发挥时，其使用的可能性是无限的。以下是 `Burp Suite` 的一些功能：
- `Intercepting Proxy`：监控应用程序和浏览器之间通信的功能。
- `Spider`：指定所有存在于网络上的文件列表和特征的功能。
- `Web Scanner`：扫描服务器中漏洞的重要功能。
- `Intruder`：用于对网络发起攻击的功能，扫描漏洞并利用它们。
- `Repeater`：代表用户发送自定义请求的功能。
- `Sequencer`：检查令牌的真实性功能。
- `Extensions`：允许用户直接从数据库安装自定义插件的功能。

## I. WORDPRESS 安全与黑客攻击
到目前，你应该已经了解什么是黑客攻击。现在我们将概述保护你、你的系统和信息免受威胁的基本准则。这些方法被成功地用于以防止计算机系统被恶意用户攻击。

### 更新你的操作系统（操作系统）
操作系统面临各种类型的攻击。每天都有新的病毒发布；这本身应该让你警惕，因为你的操作系统可能是脆弱的。保护自己免受新威胁的最佳方法是每周或每月更新操作系统。

### 更新你的软件
在上一节中，我们谈到了更新的重要性。更新软件配备了更多的效率和便利性，甚至具有更好的安全功能。因此，经常更新你的应用程序和浏览器。

### 杀病毒
根据我们的研究，我们看到某些操作系统面临许多攻击，特别是 `Windows` 平台。保护系统免受病毒的方法是通过安装杀病毒程序。一个杀病毒程序可以在许多方面帮助你。恶意黑客可以通过互联网在你的系统上植入病毒，但通过良好的杀病毒程序扫描，你可以发现威胁并消除它。

### 反间谍软件
这个程序同样重要，因为你不希望系统上被木马程序入侵。你可以在互联网上获得许多反间谍程序；只需确保你选择的是评分良好的一个。

### 针对 Macintosh
`Macintosh` 操作系统非常流行，因此许多黑客针对它。然而，`Macintosh` 对许多威胁是免疫的。你可能读过文章和博客说 `Macintosh` 操作系统并不安全；然而，`Macintosh` 是一个安全的平台。

### 避免可疑网站
当你浏览 `Facebook` 时，你可能会遇到给你发送链接的陌生人，有些是点击诱饵的形式。此外，你必须避免那些承诺提供好得难以置信的网站。有些网站是由寻找损害你电脑方法的恶意黑客运行的。注意，在某些恶意网站上，你甚至不需要点击任何东西就会被破解。良好的浏览器会在带你那里之前提醒你。

### 防火墙
如果你是在公司工作的计算机专家，你可能会遇到多个操作系统处于网络的情况。在这种情况下，你必须安装提供安全的防火墙软件。该功能有多个版本，包括 `Windows XP`、`Windows Professional`、`Windows10`。

### 垃圾邮件
你可能通过垃圾邮件被攻击。邮件提供商已根据一组参数对邮件进行分类。有些邮件直接发送到收件箱，有些发送到垃圾箱。为了安全，避免打开看起来可疑的邮件。有些带有你不应该附件。

### 备份选项
无论你是经营业务还是作为伦理黑客为公司工作，备份你的工作都是关重要的。某些文件包含机密信息，如个人文件和工作相关文档，你无法失去这些。你应该注册 `Google Drive`、`OneDrive` 和其他云盘以便你上传文件。你还可以购买外部硬盘并将所有重要文件传输传输。采取所有这些安全措施，因为无论你安装了什么杀病毒软件，单个恶意软件都可以扰乱你的数据。始终保留备份。

### 密码
这是安全最重要的方面。强密码的重要性怎么强调都不为过。从你的邮箱甚至一个安全的服务器开始，良好的密码是防御威胁的第一道也是最后防线。密码分为两类：弱和强。弱密码是通过使用你的电话号码、名字、家人的名字或容易猜到的内容生成的。避免使用这种密码。使用生日或特殊纪念日的人仍然是不安全的。创建密码时，花时间做一些基础数学，因为密码必须包含字母和数字。例如，如果你的初始密码是 `jack`，你可以将其改为 `Jack@007`。这样的密码几乎不可能被猜，尽管它是简单的。此外，避免写下你的密码；密码不是必须属于你私人的文件。确保你使用强密码。然而，请记住，强密码并不能让你完全安全。




- 后门（Backdoor），也被称为加密系统或算法，是绕过密码等正常安全控制的方法。它们可以是授权的（针对特定目的），也可以由攻击者添加。无论何种情况，它们都会产生漏洞。
- 拒绝服务攻击（Denial-of-service attacks）的目标是使计算机或资源不可用。这可以通过多次输入错误密码导致账户锁定，或者通过请求过载系统来阻塞所有用户。这些攻击可能源于僵尸电脑，甚至可能通过诱导无辜系统发送意外流量。
- 窃听（Eavesdropping）顾名其实义——监听网络主机之间的私人通信。某些政府机构使用特定程序对互联网服务提供商（ISP）进行“审计”。当电磁传输被监控时，这种广泛的做法还会延伸到闭式系统。
- 通过伪造数据以获取未经授权的数据访问权限，这种行为被称为欺骗（Spoofing），它有多种形式：电子邮件伪造（伪造发件地址）、MAC 伪造（更改介质访问地址以伪装成合法用户）、生物识别伪造（伪造生物识别样本）、IP 地址伪造（更改源 IP 地址以隐藏身份或冒充另一个系统）。
- 通过物理访问或直接访问攻击，攻击者可以复制数据、破坏安全、安装监听设备或蠕虫等。即使是受保护的系统也容易受到此类攻击。
- 钓鱼攻击（Phishing）经常利用电子邮件伪造或即时消息，通过看起来与合法网站几乎相同的界面，引导用户输入机信息。
- 通过权限提升（Privilege escalation），攻击者可以欺骗系统授予受限数据或资源的访问权限，从而提升其访问级别。
- 点击劫持（Clickjacking）字面意思是劫持用户点击指向非预目标网站的链接或图标。点击劫持尤为狡猾，它会将点击（有时是按键输入）路由到无关的页面。
- 通过冒充机构、银行、客户或其他实体，社会工程会导致用户泄露密码、信用卡号和其他隐私信息。据报道，这种诈骗每两年给美国企业带来的损失超过 20 亿美元。

如果没有计算机，世界将回到工业革命之前的模式。技术简化了生活的方方面，特别是对于企业和其他公共实体，其中一些正面临着日益严重的风险。

### 金融系统
金融监管机构、投资银行和商业银行吸引了网络犯罪分子，他们看到了市场操纵和非法获利的途径。任何允许资金转账或购买商品的网站也是目标，ATM 机也是如此，它们经常被黑客获取客户数据和 码。

### 公用事业与工业
包括电网、核电站、水网和气网在内的关键服务由计算机控制。事实证明，即使是那些未连接互联网的计算机控制系统也容易受到攻击。

### 航空
大型机场的一次停电会对航空交通产生动荡连锁反应。无线电传输将被中断，可能发生机载攻击、系统完整性和飞机的丢失，以及航空管制故障，这些只是可能的结果之一。

### 个人设备
人们用来简化生活的各种奇妙设备——智能手机、平板电脑、智能手表、活动追踪器——都可以通过内置摄像头和其他设备被利用。攻击者可以收集健康或其他个人信息，或将设备网络作为攻击路径。

### 公司
身份盗窃和信用卡信息等数据泄露一直针对 Target 公司和 Equifax 等大型公司。在某些情况下，外国政府试图通过攻击传播宣传或进行间谍活动。医疗诈骗让每个人都受害，而冒充患者获取非法用途的药物也是常见的。尽管存在这些活动，62% 的组织在 2015 年没有加强安全培训。

### 汽车
如今的车辆实际上可以自动驾驶，这一天已不远。巡航控制、安全气囊、防锁刹车和其他功能让驾驶变得更加愉快，并希望更加安全。WIFI 和蓝牙保持汽车连接，并增加了安全漏洞的可能性。

### 政府
对政府和军事系统的攻击会造成混乱、中断服务，并在极端情况下被归类为恐怖行为。无论是活动分子、外国政府或其他黑客，结果都是人员记录、警察及其他急响应人员的通信、学生记录、交通控制和金融系统的基础设施故障。护照和准入卡等个人身份物品的广泛计算机化也导致了该领域的漏洞。

### 物联网 (IoT)
带有传感器、软件或任何类型的网络连接以存储和共享数据的物理对象是物联网的一部分。一栋建筑、一个车辆或家用电器组成物联网，这种现代现象的扩散产生了物理（而非仅仅虚拟）威胁的可能性。例如，被盗的手机可以解锁住宅或酒店房间的门。

### 医疗系统
病毒、敏感医疗数据泄露、诊断设备和其他设备都是攻击的潜在目标。这些威胁被认为极可能发生，因此美国食品药品管理局（FDA）在 2016 年为医疗设备制造商制定了安全维护指南。然而，其中并未包含具体的建议或实施结构。

### 恶意软件
各种类型的恶意软件是普通组织日常运营的最大威胁，它们具有直接影响关键数据和资产可用性的潜力。因此，如果希望有效对抗这种威胁，无论大小的组织都需要提高警惕性，同时评估它们在响应、检测、准备和对潜在威胁规划方面的能力。由于新类型破坏性恶意软件必然会随着推推演变，不仅了解组织将如何准备已知威胁至关重要，了解它将如何准备未知威胁也同样关重要。

### 分布向量
具有潜在破坏性的恶意软件经常具有针对大型系统的能力，这些系统随后可以在给定网络中的多个点同时执行。因此，组织定期评估其运行环境以寻找可能指示恶意软件传播或交付的异常通道至关重要。值得关注的系统包括：

- 企业级应用，特别是那些可能与多个主机和终端直接接口的程序。常见示例包括补丁管理系统、资产管理系统、远程协助软件、防病毒软件、集中备份服务器、文件共享和网络管理系统。
- 虽然不仅限于恶意软件，但以下威胁者可能破坏资源，最终影响关键应用程序的可用性。此类类型的潜在威胁包括集中存储设备、高风险分区或数据存储、网络设备、路由表和关键网络资源。




## 成功策略

虽然普通组织需要定期处理许多潜在的恶意软件向量，但也有许多不同的策略可以使防止恶意软件于门外变得更易管理。

其中第一点是确保始终通畅的通信流。同时，确保你的通信流路径不仅定义良好，而且经过了授权或记录也同样重要。从此开始，你应该努力提高对系统的意识，这些系统可以根据需要被用作网关进行横向移动，或直接连接到位于整个企业范围内任何地方的终端端点。无论你采取什么措施，重要地要尽可能确保这些系统被维护在这些受限的 `VLANs` 中，并根据需要实施适当的网络访问控制和分段。

在确保对谁可以访问什么内容拥有足够的控制权时，对于能够直接与大量终端建立接口的企业级系统，任何交互式登录都必须要求双因子身份验证。此外，确保授权用户被限制在组织人员的特定子集内也非常重要。无论你如何，确保默认用户组不具备直接身份验证或访问这些系统的能力这一点。

你还需要确保为每个涉及企业级应用程序的服务记录并使用唯一的域帐户。在向各种账户分配这些权限的上下文中，应始终完整记录，并配置为让尽可能多的用户拥有尽可能少的权限。这样做可以使企业能够追踪和监控基于分配的服务器帐户所执行的操作。

这就是为什么避免为服务帐户提供交互式或本地登录权限至关重要的原因。事实上，服务帐户应该被明确拒绝此类权限，特别是当其能够访问关键数据位置或重要的网络共享时。此外，用于身份验证中央服务器的帐户不应包含具有高权限的下游系统，因为这可能允许一个更容易被攻破的系统感染通常保护得更好的系统。

## 恢复计划

在准备应对系统遭受严重攻击的应急计划时，业务影响分析是一个至关重要的组件。该计划应为你的组织提供两个关键部分：相互依赖关系，以及相关组件的分类和特征。

为了应对这种场景制定计划，组织需要解决可用资源的可访问性，包括关键任务应用程序和系统、关键外部联系人的联系方式、基本人员的联系方式，以及每个项目都提供的安全通信通道。同样，拥有所有主要供应商的联系详情、组织采购方面的联系人，以及所有关键应用程序和系统的备份 `ISO` 文件也是重要的。

## 遏制

如果组织经历了大规模恶意软件爆发，首要关注点应是遏制，以希望减少攻击的整体范围，并最大限度地减少额外系统受到影响的概率。

为了制定遏制策略，最好的起点是确定所有出现问题的系统所共同拥有的向量（或多个向量），这些向量可能曾被用于传递恶意病毒。常见的选项包括：

- `DNS Server`
- 网络边界或分段
- 权限高于平均水平的用户帐户
- 中央文件共享
- 集中应用程序




一旦你发现了一个可能的分布向量，就可以开始实施额外的缓解措施了，首先是实施网络控制列表，以拒绝应用程序与其他系统直接通信的能力。这样做将立即变得更容易对特定资源进行隔离和沙箱化，从而让你能够更准确地确定问题所在。你可以使用内部 DNS 来执行此任务，只需为任何已识别的应用程序或服务器的 DNS 区域添加一个空指针，就可以轻松地看到哪些是运行中的，哪些是未识别的。

### D. 防火墙以及你的防火墙选择
这是一种网络过滤措施，曾通过作为邮件附件发送的加密 PDF 文件被绕过，这些文件既可以包含命令，也可以收集数据（例如邮件内容和元数据）。这些 PDF 文件可以使用 PDF 查看器打开，但实际上只包含一个 1x1 像素的白色图像，显示为空白页。`Outlook` 中存在合法的自动化邮件管理系统被用来隐藏这些命令与控制邮件，因此，紧盯着收件箱的用户只能看到邮件的一闪而过，漏洞程序就会在不留留任何记录的情况下将其删掉。桌面通知也被阻止了。该漏洞程序带有一份预设的电子邮件地址列表，它可以向 `Turla` 报告，但也有添加备份电子邮件地址的方法，以防原始地址被封。

### E. 关于加密和数字签名你需要了解的知识
加密和哈希的通性问题在于，一旦部署，这些算法就会保持不变，但计算能力的进步使得这些安全措施的安全性被破解的可能性增加。因此，使用旧软件变成了一场赌博，随着时间的推移，这种赌博越来越可能让你崩溃；但更新并不总是最佳选择，因为这需要成本并干扰你的工作流。你不必义务在软件一发布时就立即更新到最后一个版本——除非其他人依赖于你。

另一方面，公司确实应该尽一切努力加强其网络安全工作并防止数据泄露，这是一种发生得惊人的常态。当你的电脑被黑时，你可以丢失银行数据，但同样很容易地拨打银行撤销任何交易；当 `Facebook` 被黑时，数百万人的最私密数据，从聊天记录到相册将暴露在黑客面前，并可能在未来的某个时间点被利用。

医院和机场是非常脆弱的目标，在它们受到勒索软件攻击之前，我们并不会考虑到它们。勒索软件是一种锁定系统直到向黑客支付某些资金（通常是加密货币）的恶意软件。2017 年 5 月，`WannaCry` 勒索软件影响了全球超过 20 万台计算机，包括医院、银行和机场的计算机。这些机构中的一些在支持日期之后仍在使用 `Windows XP`，这使得黑客可以轻而易举地进入办公室，插上受感染的 `USB` 并锁定他们的整个网络。是谁制作了 `WannaCry`？据说是由 `NSA` 制造的黑客工具，被黑客组织盗取并改用于盗窃。

无论如何，硬件和软件故障都会发生；因此，最明智的举措是备份你的数据，这是防止攻击的唯一可靠方法。尽可能将原始数据和备份分离，最好一个放在云端，另一个放在断开网络连接的外部硬盘上。在备份中包含照片、语音消息和其他个人琐事，这样这些珍贵的记忆就不会因为黑客攻击而丢失。

### F. 什么是 VPN 以及如何使用它保护自己的安全
如今大多数用户都有路由器，将手机、平板和平电脑等设备连接到互联网。你的互联网服务提供商会给路由器一个公共 IP 地址，每个连接到互联网的设备将获得一个私有 IP 地址。由路由器提供。每当你将电脑连接到互联网时，看起来就像你的电脑就是路由器。在用户只有一台电脑的情况下，他们可以直接将其连接到互联网，他们的 `ISP` 会分配一个公共 IP 地址。由于分配的 IP 地址是公开的，另一端的主可以追踪你的上网活动。

`VPN`（虚拟专用网络）允许用户连接到另一个网络。`VPN` 将你的电脑提供自己的 IP 地址。`VPN` 可用于隐藏你的原始 IP 地址，你的 `ISP` 提供的 IP 地址将被隐藏。`VPNs` 不仅用于隐藏 IP 地址。你可以访问你组织的任何网络，这些网络可能被某些网络封锁。互联网上有许多商业和免费的 `VPN` 及代理服务。使用这些服务，你可以通过新的 IP 地址连接到互联网，你的原始 IP 地址将被隐藏。

### G. TOR 隧道和代理链
`Linux` 支持经典的多程序设计方案。`Linux` 支持并行（如果只有一个处理器则为准并行）用户进程。每个进程都运行在自己的虚拟地址空间中，即进程之间相互保护，其中一个进程的崩溃不会影响其他运行的进程以及整个系统。在没有另一个进程“许可”的情况下，一个进程无法从另一个进程的内存中读取或或写入）任何内容。系统允许进程之间的授权交互。

`内核` 提供了创建新进程和管理生成进程的系统调用。由于 `SMP`（对称多处理器架构）的发展，`Linux` 内核引入了线程或控制机制。线程是在虚拟内存中运行的进程，与该进程的其他线程一起使用。

如果 `shell` 遇到对应执行文件的命令，解释器会执行它，并从入口点开始。对于 `C` 程序，入口点是 `main` 函数。运行中的程序也可以创建进程，即运行某个程序且其执行也从 `main` 函数开始。

### H. 网络安全的优势
当涉及到确保移动设备网络安全的重要性时，只有你才能准确确定除机器之外还有什么面临风险。然而，对于现在的大多数移动设备，如果小偷成功访问了存储其中的信息，除了设备本身，还有更多东西面临风险。

你可能听过关于某大公司高管在不该留的地方离开电脑或手机引发骚动的故事。这类机密信息可能会给公司带来不可估量的损失，特别是当它有需要隐藏的时候。即使你的设备中没有严重的秘密，如果错误的人访问了它，普通智能设备上的信息足以让你的生活变得非常困难。在保护移动数据隐私时，请记住以下几点。密码保护一切：无论访问设备额外多花 30 秒，这一个简单的步骤就能将设备被错误人员访问的概率降低 100% 以上。它简单、随手，且在首次设置设备时就有选项，没有理由不充分利用。




# 将你的财产视作珍宝

在智能设备无处不在的今天，当你外出时，很容易对它们掉以轻心，尤其是当你忙碌或赶时间时。无论相关设备本身的个人成本如何，不仅要考虑设备丢失时的物理价值，还要考虑为了更改你所拥有的每一个密码和信用卡/借记卡而浪费的时间，这是非常重要的。此外，还要考虑保持身份安全的潜在价值，并采取相应的行动。

同样，你应该养成在使用设备时留意周围环境的习惯，尽管这可能说起来易、做起来难。尽管如此，你应该尝试注意你周围的人，包括任何可能试图越过你的肩膀偷看你那些宝贵数据的人。通常情况下，如果你目前不需要使用设备，最好将其隐藏在他人窥探的目光之外，以防万一。如果你使用的是公司笔记本电脑，你可能还会考虑使用可以设置的第三方报警，确保任何未经你许可尝试访问计算机的人都会受到“不友的警醒”。

无论你的信息有多重要，将你所有的数据至少备份一份并存储在安全位置（或更有可能是云端）都是至关重要的。这样一来，你就能确保能够尽可能快地回到原来的状态，你也会确切知道哪些信息现在面临风险，从而根据需要采取额外的措施。

## 如果设备被盗该怎么办

你首先想做的应该是向适当部门报报被盗案，因为他们可能针对此类事件制定了你可能并不了解的程序。此外，尽快取消设备上的任何移动数据服务也很重要，以尽可能地延迟罪犯，并为你留出时间在期间更改所有相关密码。

## 确保你的数据安全

### 添加额外的保护层
虽然便携式设备自然会有固有的安全选项，但其本质决定了它们比你拥有的任何其他东西更容易成为攻击目标，这意味着，根据你通常传输的数据类型，采取尽可能多的安全措施是有关重要的。同样重要的是要记住，如果你的设备将连接到不安全的网络连接，那么它也容易受到网络攻击，并据此制定计划。

### 分开存储重要数据
现在有各种极其安全的外部存储选项可用，这意味着有许多方法可以保护你的敏感数据免受窥视，并将其与最有可能被盗窃的设备完全分离。尽管存储空间非常普及，但这种选项的使用频率远低于其应有的水平，这意味着你还将拥有出其不意的竞争优势。你甚至可以将数据一直随身放在口袋里，几乎可以确保你任何时候都知道它在哪里。

### 不要仅依赖密码
如果你正在处理敏感文件，不要仅仅信任密码来防御它们。相反，要采取加密这些文件的额外步骤，确保即使设备最终落入他人之手，数据在很大程度上仍然是安全的。通过增加额外的加密层，你可以确保即使数据物理上落入他们手中，未经授权的人也不会查看数据。请记住，保留这些密码列表非常重要，并确保该列表无法从你的计算机直接访问，以避免让这一切变得毫无意义。

### 确保你的病毒防护软件是最新版本
与更有可能保持开启状态并接收自动更新的个人电脑不同，便携式设备（尤其是公司提供的设备）往往被零散使用，这意味着确保所有内容定期更新将是你的责任。养成每月检查一次新安全更新的习惯，并确保设备上的病毒和间谍软件软件也是最新版本。

### 维护强力防火墙
在保护个人电脑安全方面，防火墙是一个好主意，但对于你的便携设备来说，这更为重要，因为你的设备将连接到各种不同的网络，其中极少有网络是你能以任何程度确定其是安全的。如果你要在旅行期间使用设备，你希望确保防火墙设置始终处于最高设置，以防万一。

## I. 网络管理及许多欺骗地址的方法

你可以利用你的黑客能力通过几种方法进入网络。

### Ping（封包）
每个 Wi-Fi 都有一个分配给它的 IP 地址。即使是你用来入侵他人系统的计算机也会有一个 IP 地址。IP 地址是一系列对该路由器是唯一的数字。然而，单凭 IP 地址本身无法告诉你太多信息。

要转换地址，你将使用 `ping` 选项。`DNS` 也有助于获取域名称。`Ping` 代表“数据包互联网探测器”（packet internet groper），它存在于客户端使用的所有 Windows 版本中。

在你登录互联网后，你需要打开 DOS 命令行界面（shell），然后输入 `ping` 命令。这将查找域名并将其显示在你正在使用的计算机上。

使用 `ping` 通常是你尝试尝试入侵网络时会采取的第一步。`ping` 会连接到你的目标并告诉你它是在线还是离线。多个 IP 地址将无法转换为域名。当你想要对 `ping` 进行更多控制时，你将使用 `ping` 命令。

### Ping sweep（Ping 扫描）
这涉及 `ping`，但不是用它进入系统，而是搜索你周围特定区域开放的 IP 地址。这种方法只有在你不确定想从哪里攻击时才有用，因此你将知道在哪里可以进入，而不必一定知道目标是谁或他们在哪里。

### Tracert（路由跟踪）
该程序是另一个可以获取关于无论多远主机信息的工具。它使用 `ICMP`。`Tracert` 通过从源计算机向目标计算机发送数据包来定位数据，目标计算机在连接后会回传 IP 地址，从而揭示你到互联网连接开始的所有站点。如果无法通过 `ping` 显示名称，那么该程序可以提供它，甚至可以提供攻击者访问的最后一个站点。

### 端口扫描
当目标系统列在在线时，下一步要做是扫描系统以寻找任何可用于进入的开放端口。你可以选择的端口扫描器非常多，可以在网上找到。然而，这些扫描器的大部分使用的技术由于过时，增加了黑客被抓获的概率。`nmap` 不仅会扫描系统上打开的所有端口，还会告诉你计算机上使用的操作系统和程序版本号。

# 答案

### 1. 免费使用的软件
与其前身 `BackTrack` 一样，`Kali Linux` 可免费使用。根据开发者的说法，他们打算保持这种状态，使该工具无需任何付费墙即可下载和使用，且所有用户都能获得 `Kali Linux` 发行版的完整功能。

### 2. 开源开发树
`Kali Linux` 属于免费软件，与其他许多免费软件和许多 Linux 发行版一样，它也是开源的。`Kali Linux` 的开发者致力于使用开源开发模型，允许他们的开发树公开。此外，`Kali Linux` 中使用的所有源代码都由开发者持续提供，以供任何根据特定需求微调或修改 `Kali Linux` 的用户。

### 3. 文件系统层级结构 (FHS)
`Kali Linux` 软件遵循 `FHS`，即“文件系统层级标准”，这使得 Linux 用户能够更容易导航和定位特定文件，例如二进制代码、支持文件、软件库等。使用这一标准提供了便利性和易用性，这是 `Kali Linux` 相比许多其他类似软件的优势之一。

### 4. 广泛的设备支持
`Kali Linux` 的开发者尽力让 `Kali Linux` 尽可能对用户友好且功能丰富，使其兼容大量的平台。`Kali Linux` 受多个操作系统支持，其中最大的特点之一是 `Kali Linux` 本身支持无线设备的使用。`Kali Linux` 不仅兼容多种软件设置，还兼容大量的硬件设置，开发者正尽力包含尽可能硬件配置。这一点非常值得注意，尤其是对无线设备的支持，因为对大多数 Linux 发行版的常见批评之一就是它们往往缺乏对无线硬件的支持，而 `Kali Linux` 提供了这一点。

### 5. 自定义内核
`Kali Linux` 的开发团队首先是渗透测试员，这意味着他们经常需要进行无线评估，因此 `Kali Linux` 的内核不断包含注入补丁，以保持更新。

### 6. 安全开发环境
`Kali Linux` 团队由“白帽”黑客和渗透测试员组成，因此他们敏锐地意识到对安全的需求，特别是涉及到“白帽”经常使用的软件时，因为软件本身的漏洞或 Bug 可能会导致灾难性和广泛的后果。因此，开发团队受到限制，他们是唯一提交包并与 `Kali Linux` 仓库交互的人，所有这些操作都在多重安全协议下进行，以确保保真和安全。此外，`Kali Linux` 的软件包和仓库经过了 `GPG` 签名，`Kali Linux` 包含的所有包都由负责构建和提交它的个人开发者进行签名，每个仓库也会对包进行签名，从而形成了一套安全的软件包和仓库。

### 7. 多语言支持
尽管许多编码和许多渗透工具是基于英语构建的，但 `Kali Linux` 尝试包含多语言支持，允许非英语母语者使用其母语言进行操作，使他们能够更容易利用 `Kali Linux` 及其功能，使他们能够更有效地执行任务。

# 结论
我们已经读到了本书的末尾。`Kali Linux` 是一个非常强大的 Linux 发行版，特别是对于渗透测试而言。该操作系统自带许多工具，可以帮助你对系统和应用程序进行渗透测试。这使得 `Kali Linux` 成为用于渗透测试的最佳操作系统。在将你的系统部署到工作或生产环境之前，先通过渗透测试对其进行测试是很好的，这样你就可以确保它没有漏洞。通过渗透测试，你可以识别系统中的漏洞并在生产前将其封堵。这将帮助你防止可能因黑客利用而导致的灾难。
