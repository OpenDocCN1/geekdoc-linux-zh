# POETRY IN MOTION

Tom Oinn's approach to movement gave Triangula unparalleled mobility

"The wheels (on Triangula) are BaseBot," Tom explained "They were made up of other rollers that are 90 degrees in this case to the primary motion. So you drive the wheel as the normal, but it can also slide at the 90-degree vector. So effectively, you can take any direction as the sum of two other vectors, you can think of any direction as a combination of the main vector the wheel's driving at, plus a quantity of the perpendicular, which can"

"So we wanted to use the dynamics of steering like this, which makes our overall motion in terms of the translation of the centre-point and the rotation. From that, we then solve for the two-dimensional velocity vector for each. For each of those, the wheels will point in the direction you'll go while turning. And when we drive the motors, and we end up with a control system which we can easily translate and rotate starting point."

"This project is on GitHub - user BaseBot(github.com/BaseBot), which is my previous project. There is also a video which contains the Python code for this, for the Arduino, also some documentation - I wrote my own Python library to handle the PlayStation controller."
