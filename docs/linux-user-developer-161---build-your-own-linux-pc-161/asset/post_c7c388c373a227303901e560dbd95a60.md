# Resolve errors

From time to time you may encounter errors with your PiBeacon, specifically in persuading the status to switch "DOWN" to "UPRUNNING".

Restarting the device is no good here. Instead, you need to reset the hci device. First, enter hcconfig to configure the hci device name. Usually, this is how.

Next, enter `sudo hci reset`. This essentially clears every out and lets you start again. To check, input hcconfig again, where you should see the status now reads "UPRUNNING".

```
sudo hcconfig hci reset
```

# 10 Choosing PiBeacon vs NFC

As you have may before, there are some similarities in us and NFC, especially when it comes to smart home applications. Which one should you use for your project?

Android without beacon produces an NFC beacon functionality to the Raspberry Pi, which can prove very useful for any project that requires contact between an NFC tag and your phone.

And this is really where the distinction lies. If your project requires physical contact, use NFC. Otherwise, the PiBeacon solution should be adequate.
