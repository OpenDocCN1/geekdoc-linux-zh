# Doubly linked lists

There is a special kind of linked list called (doubly) linked list. The diagram above shows a graphical representation of it. In C, a node of doubly linked list is of the following:

```
if (*list == new_node) {
    *list = new_node;
    new_node->next = NULL;
    new_node->prev = NULL;
    return;
}
```

This happens because the first of such a list has no previous and no node. So, you should delete a doubly linked list or not? At the end of the day, it depends on what you require one or not.

```
typedef struct {
    char *data;
    struct node *next;
    struct node *prev;
};
```

The demonstrated code would make perfect sense; each node not only keeps a pointer to the next node but also a pointer that points to its previous node. As the *previous variable in the structure, there is no other difference between a linked list and a doubly linked list. As for search, deleting a doubly linked list is more expensive, as you will have to delete and update two pointers instead of one node, respectively.

# Reversing a doubly linked list

It is much difficult to reverse a doubly linked list, for there are two pointers to update, particularly when you want to reverse one. The following code provides:

```
// Go to the end
while (current != NULL) {
    current = current->next;
}
// Use the pointer to traverse it
while (current != NULL) {
    printf("%s", current->data);
    current = current->prev;
}
```
