# # Making a custom distro

Use the Ubuntu Customization Kit to make a bootable Linux disc

+   Resources
- Any Ubuntu system
- Downloaded Ubuntu ISO
- SGB of HDD space (Live Disk or 2GB flash drive)

Ubuntu Customization Kit (UCK) is Ubuntu's tool for customising Ubuntu Live CDs. With UCK you can add any package to the system, such as language packages, applications, media files and although we still feel like CDs are too big to fit on a CD2 - just two years apart - for both laptops with a disc drive, and for data on the USB key to edit you want.
UCK is a collection of scripts that customize the image and build an ISO for you. The graphical front-end, wizard that guides you through the creation of the customised Ubuntu Live, from language change to adding extras.

sudo apt-get install uck

The .deb can be grabbed from the Ubuntu repository and installed on Debian, Linux Mint or other related distros, you should build Ubuntu without installing it first. There are some careful dependencies that must be properly installed. From libubintl-free to gf-boot-theme-ubuntu, look out not before running uck, especially that uck uses the isochchain, to produce an ISO that with USB drives as defaults. Without UCK, you will have to do a lot of work yourself up to the last step.
