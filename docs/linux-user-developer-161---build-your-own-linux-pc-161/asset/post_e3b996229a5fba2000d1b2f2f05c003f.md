## 04 Does it work?

When you take the photo in the dark, it may appear that the NoIR module does not work. The picture is a right vision spy-style photo; in fact, it is perfectly black. What you need to change this is an infrared light source.
The NoIR is an adapter for the camera module which is designed to provide additional illumination when taking video in the dark. It features extra mounting points, which are perfect for custom mounts or holders. There are two versions: a standard and the NoIR version. The infrared (with LEDs) has 12 LEDs arranged around the camera to offer a spread of light when used in low light conditions, making perfect for capturing activity.

## 05 Connecting to the NoIR
The NoIR is easy to connect to the Raspberry Pi. Connecting the Raspberry Pi is easy, too: simply use female-to-male leads and attach them to the pins on the board. The pins required are 5V, GND and the output. Remember to use the BCM numbering system, so the number in the code will be the GPIO pin provided for use. Now you have the NoIR connected and are ready to take a picture.

```python
import time
import picamera

def selfie(camera):
    with picamera.Camera() as camera:
        camera.start_preview()
        time.sleep(2)
        camera.capture('nature.jpg')

selfie()
```

## 06 Another test
Now it is time to adjust your camera to turn on the NoIR and capture a frame in the dark. First, import the GPIO module (line 1); `import R.GPIO as GPIO`. Set the GPIO numbering system to BCM, with `GPIO.setmode(GPIO.BCM)`. Then, set the pin 18 to output (line 5): `GPIO.setup(18, GPIO.OUT)`. After the picture is taken, turn it off.

```python
import R.GPIO as GPIO
GPIO.setmode(GPIO.BCM)
GPIO.setup(18, GPIO.OUT)
GPIO.output(18, GPIO.HIGH)
import picamera
camera = picamera.Camera()
camera.start_preview()
camera.capture('nature.jpg')
camera.stop_preview()
```

## 07 PIR sensor
A heat sensor, passive infrared, picks up the heat that is emitted by objects. This radiation is invisible to the human eye but is infrared. However, it can be detected by electronic devices such as the PIR. The PIR is triggered when heat has occurred. The first dial is used to adjust the sensitivity, which will make the PIR trigger with more or less of a heat change. The second dial will adjust the time between the sensor stopping and resetting, generally set to a range of a few seconds.

## 08 Connecting the PIR
Time to connect the PIR. To check this working, first remove the NoIR wires. The three wires are: 5V, a ground and the output. Remember to use the BCM numbering system, so the number in the code will be the GPIO pin on the board.

## 09 Testing the PIR
Now that the PIR is connected, test that it is working correctly and adjust the settings to ensure it triggers correctly. Use your Python editor, open a new file and enter the test code. Important code:

```python
GPIO.add_event_detect(PIR, GPIO.RISING, callback=motion_sensing)
```

It is set to detect the rising heat, such as a human body detected by the PIR and it triggers the GPIO 7. The Raspberry Pi identifies that heat is rising and executes the callback. In this callback, we will print "We see you" in the Python console. When the badge moves, there is another change in heat and the PIR senses it.

```python
import time
import R.GPIO as GPIO
GPIO.setmode(GPIO.BCM)

PIR = 7
GPIO.setup(7, GPIO.IN)

def motion_sensing(channel):
    print("Ready to find you")
    time.sleep(2)
```

## 10 Saving a new picture
When the PIR takes a picture using the code in Step 3 it overwrites the existing file because both files have the same name. This is not suitable for taking multiple pictures over a period of time.

To ensure the files are not overwritten, we change the filename number each time the camera is triggered by a variable value. For example, the first file is Nature.jpg Nature2.jpg and so on.

```python
camera.capture('Nature' + str(File_Number) + '.jpg')
File_Number = File_Number + 1
```
