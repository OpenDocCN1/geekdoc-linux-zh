# 02 Install WooCommerce

Now that the config is set, start the web server and
open the default page. You should see the WordPress
registration page. Enter your username, password and
email id. Then you have WordPress installation ready.
The next step is to install WooCommerce by downloading
t WooCommerce plugin from their website, extract the
files to the webroot folder. Log in to WordPress and go to
tPlugins page on the left menu bar, click Add New and Select
Search for WooCommerce then install the plugin.
activate directly from there. If you encounter
errors related to permissions to solve, you will need
to create folders and change them now.

Browse for the folder dummy-data (inside the
WooCommerce source and then select the
dummy-data.xml in the text, select the user you want
to attribute to all content and check the box that says
Import only. Now you have all content on your site. To
cross-check, click on Products link on the menu bar
an see your products listed.

# 03 Import data

Now that you want to test the various features
and that you have the necessary content ready to
populate your shop, it is time to import the dummy
data to WooCommerce installation. This will make
clearer as you explore WooCommerce. A dummy data
is available on the WooCommerce source folder itself. To
import it to use ImportWP. If not already
installed, will install the WordPress import plugin. Once
installed, click on Activate and import now.

Since we already imported data, you will see
many products listed. To add a new product
is easy; just click on Add Product link. In the product
after appears, fill in the product details like name,,
description, price and image. With the WooCommerce
blog post feature, find this very page, with
one important change. By the description field, you will
find the product data, and this is where all the
specific settings are. These settings include product,
general settings, inventory related settings, shipping,
linked products and product attributes.
