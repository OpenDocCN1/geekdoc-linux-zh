# 04 Check for content

Switch to the Podcasts tab and press a check in the box labeled "Show videos from the Videos section". On the right side of the window, press Enter to start checking for new content. Miro will populate your favourite feeds based on this setting.

# 05 Configure playlist settings

Move back to the Playback tab and check Play in Miro. This limits the reach to other apps, which will also check video and audio items one after another, and use Return Playlist, check the first and third.

# 06 Source videos and podcasts

With Miro set up to play the video and audio content you want to enjoy, it's time to find them! The best way to do this is to just check the websites that you use regularly for video and audio (preferably the former) and copy the XML link.

# Checking for new content

It is tempting to set a regular frequency for checking in Filter: Podcasts, but not too regularly is going to result in feeling overwhelmed, hogged temporarily, in an interruption to actually watching Miro checks. Limit polling to hourly or daily checks.

# 07 Add Podcast feeds

In Miro, open File Add Podcast and then paste the podcast RSS URL into the dialog that appears, clicking Create Podcast when you're done.

The more you add, the more regularly updated content will be downloaded to your Pi Miro manager, ready to watch.

# 08 First time use

When we were instructed to browse by a particular way upon launch? It's time to set that however, by opening the views in the left-hand pane and playing the feed. Each time you boot your system, Miro will join to this win and begin playing.
