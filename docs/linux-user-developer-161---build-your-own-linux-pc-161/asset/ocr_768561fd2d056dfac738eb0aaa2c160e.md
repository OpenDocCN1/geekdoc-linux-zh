# BCM

GPIO pins are physical interface between the Pi and other devices. At the simplest level, you can use them as switches to turn on or off. You can also program the pins to turn them on or off. The BCM numbering option means that you refer to the pins by the 'Broadcom channel' number, instead of the pins by the physical numbers printed on the board.

# 06 Another test

Now it is time to adjust your camera to turn on the LISAPI and capture a frame in the dark. First, import the GPIO module (line 1); import RPi.GPIO as GPIO. Set the GPIO numbering system to BCM, with GPIO.setmode(GPIO.BCM). Then, set the pin 18 to output (line 5): GPIO.setup(18, GPIO.OUT). After the picture is taken, turn it off.

```
import RPi.GPIO as GPIO
GPIO.setmode(GPIO.BCM)
GPIO.setup(18, GPIO.OUT)
GPIO.output(18, GPIO.HIGH)
import picamera
camera = picamera.Camera()
camera.start_preview()
camera.capture('nature.jpg')
camera.stop_preview()
```

# 07 PIR sensor

A heat sensor, passive infrared, picks up the heat that is emitted by objects. This radiation is invisible to the human eye but is infrared. However, it can be detected by electronic devices such as the PIR. The PIR is triggered when heat has occurred. The first dial is used to adjust the sensitivity, which will make the PIR trigger with more or less of a heat change. The second dial will adjust the time between the sensor stopping and resetting, generally set to a range of a few seconds.

# 10 Saving a new picture

When the PIR takes a picture using the code in Step 3 it overwrites the existing file because both files have the same name. This is not suitable for taking multiple pictures over a period of time.

To ensure the files are not overwritten, we change the filename number each time the camera is triggered by a variable value. For example, the first file is Nature.jpg Nature2.jpg and so on. This saves each new file with a different name and won't overwrite the existing images.

```
camera.capture('Nature' + str(File_Number) + '.jpg')
File_Number = File_Number + 1
```
