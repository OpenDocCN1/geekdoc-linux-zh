# Free Pascal Compiler 3.0.0

Speedy cross-platform compiler for the user-friendly language

Free Pascal Compiler - FPC - a compiler both for the Object Pascal dialect, Free Pascal, and for other Delphi dialects. FPC compiles to many platforms and processors, with no change to the source code. For cross-platform Pascal as well, the IDE - built with Free Pascal - works perfectly. Binaries are available for some distributions already, FPC hadn't reached the Ubuntu PPA when we tested, but by adding Debian experimental to our /etc/sources.list and installing with:

For other distros, a complete package and install script is on the download site. FPC has astonishing met our demands (we your PC has more than enough power) with assembler and supports Raspberry Pi without anyone can run at all, even if you have a much more powerful build.

Free Pascal is an object-oriented language, with PostgreSQL andMySQL-it's growing all beyond the teaching language of the Seventies. The documentation is, and if you've never used Pascal a quick look at one of the tutorials, then grab the score for one of the games at pascaldevelopment.com.

Pros
Blazing IDE that includes many dialects, integrates with assembler and supports databases

Cons
Not many Pascal projects to join, but hopefully that will change in the near future

Great for...
Language learners and those who want to review freeppascal.org
