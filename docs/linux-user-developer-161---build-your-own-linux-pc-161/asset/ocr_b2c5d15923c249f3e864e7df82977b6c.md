The system() call

The atex() system call allows you to register a function to be called at normal termination. The functions are registered in the reverse order of their registration. The thing is that no arguments are passed. A function can be registered multiple times and it will be called for each registration. Additionally, a program must finish using the return() or the exit() system call in the order for the atex registered functions to be called. This essentially means that if a program is killed

normally by a signal, then the registered functions will not be called at all. Keep a sharp eye out for this: C program that uses atex() as well as its output normal. The atex() function returns 0 on success, -1 otherwise. If you want to de-register a registered function, then it is de-registered. As the function exits, it is called last-like the stack-data structure.
