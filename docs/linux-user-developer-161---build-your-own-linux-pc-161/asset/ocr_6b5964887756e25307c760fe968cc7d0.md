# Draw the player (lines 51-60)

Currently, the variable is used to store the CUR ID and it can be moved using x = x + player during each draw calculation. The unit is the distance from the center of the screen. The player is then drawn using aPlot.

```
DEF drawPlayer
COL = yellow
x = cos((playerAngle + 90) * playerRadius)
s = sin((playerAngle + 90) * playerRadius)
height = 0
Plotstart
Plot( (x + s * 5, y + s * 5), playerX, 5)
Plot( (x - s * 5, y + s * 5), playerX, 5)
Plot( (x - s * 5, y - s * 5), playerX, 5)
Plot( (x - s * 2, y - s * 2), playerX, 2)
Plot( (x + s * 2, y - s * 2), playerX, 2)
Plot( (x - s * 5, y - s * 5), playerX, 5)
Plot( (x + s * 5, y - s * 5), playerX, 5)
Plot( (x + s * 5, y + s * 5), playerX, 5)
Plot( (x - s * 7, y + s * 7), playerX, 7)
Plot( (x + s * 7, y + s * 7), playerX, 7)
Plotend
ENDPROC
```
