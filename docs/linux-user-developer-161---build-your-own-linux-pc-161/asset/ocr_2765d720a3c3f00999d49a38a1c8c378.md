# Capturing sound

# Capturing sound

We have to admit that KWave offers the best-designed dialog with clear controls for recording and source. KWave does capture without our preliminary setup, but we get low-quality records with cracks and clicks – when ALSA based apps do not interact well with the PulsAudio editor.

Sweep offers a different approach to recording: in raw format, then selects the area you want to fill and finally presses the red circle on the bottom panel. Since Sweep was updated in 2008, it works for any de-vice. To fix this, launch Sweep with a special PulseAudio recorder: `pasid sweep`.

# Effects-and-post-processing

# Effects-and-post-processing

KWave has the most basic set of features, for entry-level sound editing. You get several options, including equalizer, low-pass, band pass, notes and perhaps more. Enough to add a small touch to an amateur recording, but nothing beyond. The only feature-rich part of KWave was the editor, designed to export to MP3 or OGG.

Sweep is a very lightweight audio editor that is focused on simple tasks, at least as it was planned in Plan Audio Mastering and later features, which helped develop Sweep. Likewise, only basic cut-paste features are found without filters or any sort of effects.

# Performance

# Performance

There is a useful window setup on OptionsMemory where you control the limits for physical memory (RAM), virtual memory leveraging to all advantage this made feature. When you have enough space, KWave is stable, though it can't cache large of files as well.

After the effects, we were surprised that it turned out to be the fastest and most productive software for our group team. Sweep interface stays responsive even when a massive WAV file is loaded. It is easy to select, copy and paste in seconds, and can change the waveform without ever having to restart.

# Multi-track-and-mixing

# Multi-track-and-mixing

There are grounds for multi-track support in KWave – you can create a file with custom number of tracks to turn on or off when needed. Currently KWave cannot save your work as a project, and when you record new sound, KWave wants to close the current file and create a new one. The only way to switch between files is to separate KWave instances.

As you might expect, there is no multi-track support in Sweep, and very few mastering either. Sweep works with its own user color, an adding tool for mastering records. It should be Scrubby – a play-way cursor that can be drawn around the amplitude waveform in the same way you might move it over a vinyl record.

# Overall

# Overall

Neat but very basic sound editor with good stability and nicely designed interface. Easy to get with grips, but not one that we would recommend for anyone looking to do more than a light tweaking.

Very robust and responsive but nowhere as packed with features as Audacity or Rekound. A very fast package, but not one that can actually do much if you're looking to be creative.
