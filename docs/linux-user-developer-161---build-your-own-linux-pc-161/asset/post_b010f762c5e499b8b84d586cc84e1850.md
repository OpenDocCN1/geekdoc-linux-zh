## Apple open-sources Swift

### Protocol-oriented language released on GitHub

Apple has announced that it is releasing Swift programming language under an open source license, making it a competitive option sign to foster adoption. Designed for the company's iOS and macOS operating systems and since Swift, which was released in June 2014 as a more resilient alternative to Objective-C for building apps, uses "protocol-oriented programming." To aid adoption of the Swift language, Apple released the open source project under the Apple License 2.0.

The release, published by the company's newly-set GitHub repository, includes source code for the compiler, LLDB debugger, REPL, standard class libraries, and other projects. The project has also indicated it will accept pull requests from contributors, of open source either hosts. The company also set out swift.org, the dedicated website. To encourage the growth of the language, Swift is open to the community and issues tracking, a mailing list, tutorials, design guidelines, and how to contribute to Swift development.

"Swift makes it easy to write software that is incredibly fast and safe by design. Now is open source, you can make the best general purpose programming language available somewhere." Apple boasted of its release in a statement published on the swift.org.
