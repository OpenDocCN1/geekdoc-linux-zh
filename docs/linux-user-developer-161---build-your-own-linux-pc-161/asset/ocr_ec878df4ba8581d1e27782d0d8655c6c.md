05 Product types and settings
By default there are four product types. Also, you can set any of these as virtual/ downloadable. The first product type is Simple: used for standalone products. Next is a Grouped: a collection of related products that can be purchased individually. Note Variable products with many configurations like 64 GB international size can form a grouped product.

An External or Affiliate product is something that is sold outside of your site. A Variable product has variations that have different SKU, price and stock quantity. For example, after the weight you can set the sale price. For the virtual and downloadable product, it is used to sell digital items or can be used to give access to files following a – think ebook.

# 06 More settings

The General tab allows you to set the regular price and sale price for a product. You can also choose to schedule the sale for a limited time on the Schedule link next to the sale price. In the Inventory tab, you can manage stock at the product level – this way, the number of items in stock will be tracked and updated after every sale.
Linked Products can be used to set related products for upsells and cross-sells. This displays recommends products on products with attributes like size, color, and etc., to the product page. There is the Advanced tab to help you set an optional product note to be sent to customers after a purchase, and to enable reviews, set customer menus under, etc. The product settings fields, you can also find the short description on the product page. If you fill it in, that short description will be available on the product page.

# 07 WooCommerce settings

Now that you have an idea of how to manage products in WooCommerce, let's take a look at basic settings. In WooCommerce settings to see the settings pages with different tabs. To start, check out Checkout. You can find basic settings here location, shipping, and tax. The Products tab manages units, product downloads, downloadable settings. Under the tax tab, you can enable tax-related calculations for products and services. The Checkout tab allows you to set like coupons code, supported payment methods. The Shipping tab is for setting up shipping zones and methods. The Accounts tab helps set up the users accounts management, password management and the login. The Emails tab lets you set out the notifications for various matters during the order life. The API tab is used for integrating WooCommerce with other plugins. You can use- REST APIs for the integration.
