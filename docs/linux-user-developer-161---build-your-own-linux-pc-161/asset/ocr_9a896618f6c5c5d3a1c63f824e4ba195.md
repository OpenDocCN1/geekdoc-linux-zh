# New features in Raspian

# 1 Pi Zero support

The biggest reason to update for a lucky few of the smallest Pi models is Raspian's new support for the Pi Zero, a pared-down ultra-compact device which packs computing power into a chewing-gum sized board priced at less than five.

# 2 Node-RED Added

IBM's popular Node-RED (drag-and-drop environment for Internet of Things (IoT)) projects are now included by default, offering a powerful environment for rapid application development. Raspian users can simply install the modified node-RED.

# 3 New Package Manager

Raspian has long struggled with package management, with many new users struggling with the text-based versions putting off newcomers. Finally, a new package manager leaves tasks to fix that once and for all.

Canonical has announced that it is officially disabling the search functionality in Ubuntu 16.04 onwards, eventually due to changes planned for Unity.

"Online search will be off by default. This out-of-the-menu search will learn your queries," Canonical Will of the choice. "You can toggle this on or off in Privacy Settings. If you wish to toggle this back on them, then Edmunds will also be off by default.

The on-default online search functionality is considered highly useful when Canonical introduced it in Ubuntu 16.04. It offers a more intuitive approach to user experience while giving a wider range of search results for Canonical. For the systems, the search will search all programs in order to produce related results. For the application example, it would also reveal Canonical advertising.

In addition, Ubuntu 16.04 will no longer include the software Store, which will be installed via the Ubuntu Center.

The search was labeled "spyware" by the Free Software Foundation and a "major privacy problem" by the Electronic Frontier Foundation. Canonical insisted that it should be disabled by the user. Now, though, it's being disabled by the system by default in Ubuntu 16.04 onwards.

This was not an admission of wrongdoing by Canonical, but as a precursor to the launch of Unity.
