# ## DOCUMENTATION
# Zeal 0.2.1

# ## Offline documentation with great repository of documentation

Zeal is inspired by Dash – from OS X and iOS – and more than 150 offline documentation sets prepared for packages including Ruby Gems, Scala, Go, Haskell, and Dart and Stack Overflow. Although this is not anything, it is easy to import your own docs for Zeal, from various source files including HTML.

With packages available for most distro, from Arch to Slackware, it is easy to install an issue. The first step is to click Files, then scroll through the Download Docs tab, then you will select the selection that is great

and click Download. Now you have a searchable list of downloaded documentation on your laptop, in handy place, when you’re traveling or otherwise temporarily disconnected from the lifeline of the internet.

Plugins integrate with code editors like Atom, IntelliJ, IDEA, and of course – Vim and Sublime. Search can be restricted to just one language by keeping the language, and the search term in the search box – eyepatchched – and a “also” box pops up with search results, as it also does with selections made from the document contents. A very useful tool.
