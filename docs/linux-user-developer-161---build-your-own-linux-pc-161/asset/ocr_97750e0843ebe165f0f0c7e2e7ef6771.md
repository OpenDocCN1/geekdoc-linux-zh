This tutorial will present the system calls and explain the techniques that will allow you to deal with processes, which is a relatively tricky subject because you cannot completely control a Linux process.
As you already know, any C programs start with the execution of the main function which takes two arguments and returns an integer; the first argument which is an integer, is called argc (argument count) and holds the total number of command arguments passed to the program. Its minimum value is 1. The second argument is called argv (argument vector) and is an array of strings pointing to the command arguments. The first string is always the executable name.
The adjacent image shows the source code of a small C program args() that prints all command line arguments. It also shows how to use argc to help you access the command line arguments.

```
#include <stdio.h>
#include <string.h>
int main(int argc, char *argv[]) {
    if (argc != 4) {
        printf("Argument count is not %d; expected %d\n", argc, 4);
        return 1;
    }
    for (int i=0; i<argc; i++) {
        printf("Argument %d: %s\n", i, argv[i]);
    }
    printf("Argument 0: %s\n", argv[0]);
    printf("Argument 1: %s\n", argv[1]);
    printf("Argument 2: %s\n", argv[2]);
    printf("Argument 3: %s\n", argv[3]);
    return 0;
}
```
