# Why use Snort?

+   - apache for the web server
- mysql-server for the database
- phpps for the server-based script
- php-mysql (php graphics)
- php-pear (PHP Extension and Application Repository)

Snort is considered as the first choice for network intrusion detection systems in many countries. Its effectiveness and the many parameters between the selection with the several flexibility make it very popular. Open source Snort is easy to use once you learn how to configure it to the needed environments of various features.

You can apt-get all of these programs, either one at a time (example, sudo apt-get install apache2) or all at once (sudo apt-get install package2). As next step, we need to create the set of directories required for successful running of Snort. Use the following commands to create these files:

| SI | Variable | Description |
|---|---|---|
| 1 | HOME_NET | Specifies the IP address of the system you are protecting. When you use Snort, you will need to configure your actual home network IP address - do not set this to the default value of any. |
| 2 | ORACLE_PORTS | Used to specify the port that Snort is listening on.
| 3 | RULE_PATH | Points to the location of the rules file in your snort system. Typically, rules are stored in /etc/snort/rules, so make sure you use the full path or where the location is on your system.
