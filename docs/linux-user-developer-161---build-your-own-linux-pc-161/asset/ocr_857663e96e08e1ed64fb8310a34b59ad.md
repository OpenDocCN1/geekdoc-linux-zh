# Install Miro

With Wheeezy installed to your SD card and your Pi booted up, open Terminal and enter:

```
sudo apt-get install miro
```

+   01 Set up your Pi with Raspian
Sadly, Miro cannot run on Raspberry Pi, so make sure you're using Wheeezy, available via raspberrypi.org/downloads/rasbian. Ensure your Pi is connected to a TV or display via HDMI.

# 02 Set Miro to launch at startup

Make sure Miro is configured to launch at startup. Open File -> Preferences and check 'Automatically run Miro when I log in' and 'When starting up Miro remember what I was when I last quit'. Also set your Pi to boot into X using the raspi-config utility.
