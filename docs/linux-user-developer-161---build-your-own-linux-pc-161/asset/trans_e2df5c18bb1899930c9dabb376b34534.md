## 微软推出官方 Linux 认证

## AMD 推出全新图形工具包挑战 NVIDIA

多年来一直在数据中心支持 Linux 的微软，已与 Linux 基金会（The Linux Foundation）合作，推出一项联合认证。该认证面向那些使用 Linux 虚拟机的用户，将其作为进入微软 Azure 云计算平台 Linux 的入场券。今日的公告显示，Azure 认证技术官 Mark Rusinovich 表示，在完成“实施 Azure 基础设施解决方案”和“Linux 基金会认证系统”考试后，有支持在 Azure 上运行 Linux 的需求。

“如今对专业人士的需求比任何时候都要大，而那些排队管理这一新格局的人们正寄予厚望，”Linux 基金会执行主任 Jim Merlin 在公告中表示，“由微软颁发并要求 Linux 基金会认证管理员的认证，将让专业人士脱颖而出，并让他们有机会应对工作中各种有趣的挑战。”

“Linux 基金会是代表开源生态系统利益相关者利益的领先组织，”微软强调道，“结合其对专业性、发行版灵活性和认证的承诺，使其成为从事 Azure 认证的人士的自然选择。”

“微软认证解决方案助理 Linux（Microsoft Certified Solutions Associate Linux）”认证现已推出，该认证承诺证明用户具备设计、架构、实施和部署利用 Azure 开源能力应用程序的能力，并验证你的 Linux 管理技能，证明你精通当今的云原生世界。

AMD 宣布推出了一套名为 GPUOpen 的新开发者源码工具包。为了与 NVIDIA 竞争，GPUOpen 将为游戏开发者提供视觉效果、工具、库和 SDK，以最充分地利用 GPU。

随着 Radeon RX 7000 系列的发布，AMD 计划包含 DirectX ShadowFX、GeometryFX 和 ADFX 示例，用于实现真实的光线追踪对象和环境遮蔽；GPUOpen 还包含包括 Fireliner Ray Tracer、Fenirix 以及 DirectX 11 和 12 代码示例的库和 SDK，以及 CodeX 调试工具。GPUOpen 提供的工具将采用 MIT 许可证并发布在 GitHub 上。

目前，AMD 拥有一个闭源的 Catalyst 驱动程序和一个开源驱动程序。未来，AMD 将拥有两个驱动程序：一个用于游戏的闭源驱动，另一个是开源，即 AMD 图形驱动程序为：GPUOpen。凭借 Mesa 和 Linux 对 AMD GPU 的支持，以及 GPUOpen 作为厂商中立的工具集，AMD 正在拥开源作为其未来一年战略的核心。

## Apple 将 Swift 开源

### 面向协议的语言在 GitHub 上发布

Apple 宣布以开源许可证发布 Swift 编程语言，使其成为一个具有竞争力的选择以促进采用。Swift 是为公司的 iOS 和 macOS 操作系统设计的，自 2014 年 6 月发布以来，它作为 Objective-C 更具韧性的替代方案用于构建应用，并使用了“面向协议的编程”。为了帮助 Swift 语言的采用，Apple 在 Apple License 2.0 下发布了该开源项目。

该发布由公司新设立的 GitHub 仓库发布，包含了编译器、LLDB 调试器、REPL、标准类库以及其他项目的源代码。该项目还表示将接受来自开源托管平台贡献者的拉取请求（pull requests）。公司还设立了专用网站 swift.org。为了鼓励语言的增长，Swift 向社区开放，并设有问题跟踪、邮件列表、教程、设计指南以及如何贡献 Swift 开发的说明。

“Swift 让编写在设计上极快速且安全的软件变得简单。现在它是开源的，你可以在某处提供最好的通用编程语言。”Apple 在 swift.org 发布的一份声明中对其发布表示自豪。

对于学生来说，学习 Swift 是接触现代编程概念和最佳实践的绝佳途径。

# 移动

## Mozilla 将 Firefox OS 转向 IoT

## Firefox OS 手机的坏消息

Mozilla 确认已已停止作为第三方平台的基于 HTML 驱动的 Firefox OS 开发，并将将其核心架构用于物联网（IoT）项目平台。2013 年，运行该软件的首批设备初始开发遭遇了阻碍：Web 性能糟糕，且围绕该问题缺乏第三方社区开发。在当地没有新的 OEM 合作伙伴的情况下，Mozilla 选择了为该项目收结。

“我们现在将利用作为 Firefox OS 开发一部分的技术进行原型设计，这为我们在连接设备方面提供了动力，”Asia Jacobi 说。“我们将为这项探索留出空间，通过不同的运营商构建并交付智能手机。”

现有平台开发工作的停止意味着不再有软件更新（包括安全更新和 bug 修复），这将任何想要将应用程序迁移到该平台的公司化为流。

> “物联网，正如许多人一样，将影响我们每一个人。”
