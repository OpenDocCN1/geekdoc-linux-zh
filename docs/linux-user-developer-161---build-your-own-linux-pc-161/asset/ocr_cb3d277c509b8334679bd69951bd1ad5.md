# Dell enables firmware updates within Linux

The first of a stream of manufacturers making our lives easier

![](bbox=[0.062, 0.345, 0.438, 0.833])

Dell has confirmed that it has the capacity to sign up to the Linux Vendor Firmware Service (LVFS), a project which seems to be the first to update firmware from within Linux rather than requiring users to boot into a program.

Created by Hughes, the LVFS and its associated package became as a means for Hughes' Colorostro calibration hardware moved forward as the first to update the firmware from within Linux. With membership, the supported method of updating firmware from multiple manufacturers first.

To support these users means improving the LVFS process. From the release in Fedora 24, the metadata will be automatically refreshed after logging in and it will be possible to be notified when new firmware is available. The fwupd included in Fedora 24 will also be the first system to support using.

Dell use of fwupd will benefit with the company's Dell Edge 5000/5500 Series hardware, which the company has been trying through the LVFS. Support is due to expand in the future, however:
