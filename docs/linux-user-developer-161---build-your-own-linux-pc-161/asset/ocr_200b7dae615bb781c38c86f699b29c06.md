# Reversing a linked list

This box will present a pretty interesting problem, which is how to reverse a linked list in reverse order. The code, for reversing a linked list, is as follows:

```
```c
void reverse(**list) {
    if (list) {
        return;
    }
    reverse(list->next);
}
```
```

As you can see, reverse() calls itself another function reverse(), which works recursively. But if you really want to print the reversed list, you should call print(list->next) in reverse(list) function to show how it changes the linked list.
