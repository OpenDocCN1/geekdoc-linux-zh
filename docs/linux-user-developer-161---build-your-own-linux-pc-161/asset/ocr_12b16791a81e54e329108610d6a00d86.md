# Structure your data by creating, manipulating and sorting linked lists to simplify traversal and editing

Strictly speaking, a linked list is a structure with a finite set of elements. Each element contains at least two locations: one for the data and a for pointer that links the current element to the next one in the sequence of elements that construct the list. This is also known as a singly linked list.

Linked lists enable you to delete or insert elements at will. Additionally, all operations that can be performed on any kind of list are easy to understand and simple to code; you will not write very much code, or put restrictions in your code.

kind of a linked list where each element is inserted at one end head and removed from the other end tail.

The first thing that you should do when defining a linked list is to keep the head of the list inside a variable. The head is the only thing that you need in order to access a list.

The biggest advantages of linked lists are that they are easy to understand, easy to implement and generic enough that they can be used in many different situations and in many kinds of programs.

The lookup function of a linked list is the most important function because it decides whether an element is in the list or not, depending on what you want to do with it. The sooner the lookup function returns with an answer, the better it will be for you, you'll know where you are in the list and quicker your program will be.
