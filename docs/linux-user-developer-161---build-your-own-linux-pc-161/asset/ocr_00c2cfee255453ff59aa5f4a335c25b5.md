# Linux From Scratch – Live

linuxfromscratch.org/livedec

Everyone should consider building Linux From Scratch (BLFS) at least once. Following an online tutorial, you build a complete but minimal GNU/Linux system from source code, which is customised and secured, as well as learning about the internals of the operating system which will be helpful when diagnosing problems (or writing software for GNU/Linux system).

LFS manages a number of sub-projects. Beyond Linux From (BLFS) extends the OS, and Hardened Linux version (HLFS) provides a known good tool for compiling LFS - for using non-Linux PCs, or drives with plugs that show up under heavy compilation loads and doubles as a live USB rescue with interesting tools.

LFS Live lacks documentation - but it is helpful to have built LFS before. Braille and speech output work on the default version, but customization is necessary to avoid a starting with COSA, or for familiar users with other tools.
