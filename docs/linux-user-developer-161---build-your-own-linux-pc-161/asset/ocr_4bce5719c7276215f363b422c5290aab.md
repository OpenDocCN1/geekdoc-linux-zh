# Waiting for a process terminate

When a process terminates, either normally or abnormally, the kernel notifies the parent by sending a signal. Please note that if a signal cannot be caught, the parent process has two options: either ignore the SIGCHLD signal, or handle it using a signal handler. Additionally, there exist two more functions to reap the child: wait() and waitpid(2).
