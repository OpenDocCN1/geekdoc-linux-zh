## POETRY IN MOTION

Tom Oinn's approach to movement gave Triangula unparalleled mobility.

"The wheels (on Triangula) are BaseBot," Tom explained "They were made up of other rollers that are 90 degrees in this case to the primary motion. So you drive the wheel as the normal, but it can also slide at the 90-degree vector. So effectively, you can take any direction as the sum of two other vectors, you can think of any direction as a combination of the main vector the wheel's driving at, plus a quantity of the perpendicular, which can"

"So we wanted to use the dynamics of steering like this, which makes our overall motion in terms of the translation of the centre-point and the rotation. From that, we then solve for the two-dimensional velocity vector for each. For each of those, the wheels will point in the direction you'll go while turning. And when we drive the motors, and we end up with a control system which we can easily translate and rotate starting point."

"This project is on GitHub - user BaseBot(github.com/BaseBot), which is my previous project. There is also a video which contains the Python code for this, for the Arduino, also some documentation - I wrote my own Python library to handle the PlayStation controller."

## Optimus Pi

PyroBot returned with a wholly new vision that is Optimus Pi. It's built around an Ais ML with outside chassis featuring four motors and wheels - these are easily removable. Inside is an Arduino with a controller, and on the top is a Raspberry Pi connected to it, which is what I use for my menu. I'm using a Proto HAT here, just to add cameras and sensors that will make the robot a bit more clever.

"Some of the programs are set up to the compass, but I found it a bit unsolvable so I ended up dead-end. Now I'm using the joystick to control the menus; I've got a little screen that shows the IP address and dates, and this is in a highly populated so because I used my PS3 DualShock, a manual is an option, otherwise wouldn't be. I've also placed a clear case for the Raspberry Pi, and then by turning on and off during the changes the back I just got this little I2C hub, because everything connects through I2C. So the chassis goes down to the Raspberry Pi. And now I have a sensor for proximity alert, and then at the moment I got the fight for the front which I was using for the opponent's balloon. I got a 3D printer off and used it to make these components. And I've got a little Wi-Fi and Bluetooth USB adapter; so avoid needing a HAT but I bought this extra combo unit. Technically I don't need Wi-Fi, but then if it goes wrong with the robot and I need to fix it, I used an off-the-shelf kit, which I put a strip on top of this year. It's all scratch-build, so it's smaller and better built from the ground up. Now you can find out more at optimus.pi.myblog.com
