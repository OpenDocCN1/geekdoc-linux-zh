# # WIN! FUZE
Special Edition

![](bbox=[0.029, 0.213, 0.971, 0.513])

With decidedly retro roots, the award-winning FUZE is a programmable computer and electronics workstation. Born out of a passion for programming and low of electronics, the solid case features a keyboard, a specially designed GPIO header and a breadboard for simple electronics. Housed around a Raspberry Pi below the keyboard, the FUZE comes with FUZE BASIC already installed.

support, including image and scaling, angle and alpha controls and rotation, FUZE BASIC is fully configured to run with all models of the Raspberry Pi. The FUZE system is more than just interpreter.

FUZE BASIC is an advanced, modernised version of the BASIC programming language, widely accepted as the easiest beginner language to learn and teach. Featuring a redesigned interface and advanced graphics

The FUZE Special Edition pays tribute to home computers like the BBC Micro and Comic, and comes with a robotic arm kit to integrate with your projects. The FUZE Special Edition also provides you with exclusive tutorials and online resources at FUZE Lar, giving you everything you need to get started. For more information, head over to **fuze.uk**.
