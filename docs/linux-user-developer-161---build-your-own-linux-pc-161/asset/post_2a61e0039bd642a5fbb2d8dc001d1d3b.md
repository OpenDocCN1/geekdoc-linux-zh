# Step up your UNIX game and get to grips with the complex subject of processes on your Linux machine.

This tutorial will present the system calls and explain the techniques that will allow you to deal with processes, which is a relatively tricky subject because you cannot completely control a Linux process.

As you already know, any C programs start with the execution of the main function which takes two arguments and returns an integer; the first argument which is an integer, is called argc (argument count) and holds the total number of command arguments passed to the program. Its minimum value is 1. The second argument is called argv (argument vector) and is an array of strings pointing to the command arguments. The first string is always the executable name.

The adjacent image shows the source code of a small C program args() that prints all command line arguments. It also shows how to use argc to help you access the command line arguments.

```c
#include <stdio.h>
#include <string.h>
int main(int argc, char *argv[]) {
    if (argc != 4) {
        printf("Argument count is not %d; expected %d\n", argc, 4);
        return 1;
    }
    for (int i=0; i<argc; i++) {
        printf("Argument %d: %s\n", i, argv[i]);
    }
    printf("Argument 0: %s\n", argv[0]);
    printf("Argument 1: %s\n", argv[1]);
    printf("Argument 2: %s\n", argv[2]);
    printf("Argument 3: %s\n", argv[3]);
    return 0;
}
```

# The system() call

The atex() system call allows you to register a function to be called at normal termination. The functions are registered in the reverse order of their registration. The thing is that no arguments are passed. A function can be registered multiple times and it will be called for each registration. Additionally, a program must finish using the return() or the exit() system call in the order for the atex registered functions to be called. This essentially means that if a program is killed normally by a signal, then the registered functions will not be called at all. Keep a sharp eye out for this: C program that uses atex() as well as its output normal. The atex() function returns 0 on success, -1 otherwise. If you want to de-register a registered function, then it is de-registered. As the function exits, it is called last-like the stack-data structure.

## Processes and Programs

It is important to understand exactly what a process is and how it differs from a program. A process has its own execution environment which contains instructions, user and system data and other kinds of resources that are obtained during execution.

On the other hand, a program is a file that contains executable code and static data, which represents the instruction and data parts of a process.

The only way to execute a process on Linux is through the fork() system call. When fork() is called, a new process is created. The only way to create a new process is a copy of the existing process.

When you execute a system by system call, you create a new process that is a copy of the calling process's data and system data parts and the parent process both execute the same instructions from the same point.

Although used individually neither fork nor exec is sufficient to run a program; it is vital to make sure you completely understand the differences and similarities of processes and programs.

There exist functions in the family: execi, execp, execve, and execv. The i signifies that the arguments are given as a list whereas the v signifies that the arguments are given as a vector. The e at the end of the name indicates that you are executing a process with an environment which should be used when searching for a program. As you can see in next, you cannot use both p and e in the same system call!

When you use one of the exec system calls to execute a program, the new program replaces the process and starts execution in its main function.

execv is used for executing a program with an argument list. This list contains the path of the program to be executed. The new program is executed in its (main) function. Both user and stack data are replaced by the parts of the new process. Therefore, a successful call to exec does not return any value. If it fails, it returns -1 which happens when the path does not exist.

execve is used for the environment that the new process will execute. The environment will be executed, the same as the argument to the exec(), which is given as an array of pointers to strings, like

The path argument should be absolute or relative (like "/ls") for the list of arguments to be properly terminated.

The next three calls put the arguments into an array instead of listing them - the same happens with the return function and the arg variable. This is necessary when you do not know the number of arguments at complete time.

With execvp(), the first argument is the path to the executable. The rest of the process remains the same except for heap, stack, user data and file descriptors. The process does not keep any file descriptors.

## How a process is terminated

There are many ways to terminate a running process; some are normal and some are handled by the process while others are abnormal and violently terminate a process. An example of abnormal termination is when a process receives a signal SIGKILL, which is used to terminate a process by cutting it off with the power of a switch; used if you need it.

A normal termination happens when you normally exit via a menu or an option - this allows the process to perform any necessary cleanup. System terminates a process normally: exit(1), exit(2) and exit($2). You can also terminate the process with the return() function; however the following two calls are equivalent when called:

```c
exit(0);
return();
```

All three functions take a single integer argument that specifies the exit status, which is if needed. The C standard defines two constants, EXIT_SUCCESS and EXIT_FAILURE, that may be passed to exit indicate successful or unsuccessful termination, respectively. If you want to write perfectly portable, you can use either exit or EXIT_SUCCESS to indicate a successful termination.
