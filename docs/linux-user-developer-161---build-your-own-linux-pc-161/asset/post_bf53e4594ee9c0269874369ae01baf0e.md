## BROWSER
### Otter Browser 0.9.08

A free replacement for the much missed Open Web.

![](img/a54b3b473771472dd2321ddda1014be1_91_0.png)

Otter Browser is a free replacement for the much missed Open Web. It aims to recreate the best aspects of Opera using the Qt framework. The first thing you notice is its responsiveness. With some improvements, Otter is a fast and efficient browser for many areas.

Plugins integrate with code editors like Atom, IntelliJ, IDEA, and of course – Vim and Sublime. Search can be restricted to just one language by keeping the language, and the search term in the search box – and a “also” box pops up with search results, as it also does with selections made from the document contents. A very useful tool.

The browser is not quite finished, so while features are arriving fast it is well worth investigating.
