# Capturing sound

# Capturing sound

Audacity records from your default PulseAudio sources. It officially supports ALSA, but we have a compatibility layer (named similar to PulseAudio) to link the two sound systems. Audacity can use it without troubles. In Edit-Preferences:Devices you can set a different record contour, quality change settings, etc.

Between 2008 and 2013 Reszound was troublesome in capturing sound at the level of the ancient device 6ve old osound project to record and play sound on modern systems. In David maintained this fixed. If you get vinyl-like crackles on sound, with sample rate in /etc/pulse.conf.

# Effects and post-processing

# Effects and post-processing

You won't be able to edit built-in effects and play guitar sound into Audacity to distorted electric bits, but there are some elements here, including noise reduction, normalisation, fading, eching. Extensible plugins can be placed in /user/share/audacity/plugins.

It seems like Reszound remains at the level of first-generation audio editors, available for Windows PCs in Nitlets. In terms of audio quality, it is comparable to early versions of Source Forge. No noise remain and no preview exist for built-in effects.

# Performance

# Performance

Most users begin to care about performance once they start with a large project where stored audio data grows to gigabytes or so, we were curious how Audacity performs when the system runs out of RAM. In the test we found it doesn't allocate any resources. While Audacity is great but not perfect for long tasks.

Reszound performs well when working with large audio files. It tried to load it all at once, like some other try to do. Reszound looked that we worked with. However, the interface left mixed echoes. It was fast, yet enough to segment something if it was incorrectly.

# Multi-track and mastering

# Multi-track and mastering

Audacity proved decent for dealing with multiple tracks. When recording a project that already contains an audio track, Audacity adds new records to a separate track, not overwriting anything. You can play with the LR-R and volume of each track, adjusting their master position, scale and more. Audacity is a great for home-made songs.

Reszound has some tools for balance, with dynamic range, changing tempo, draws curves that affect audio to. Unfortunately, Reszound can't play one track at once. It allowed switching opened files, and we could copy-paste fragments from one to another, but it was possible to superimpose sound and master.

# Overall

# Overall

If you don't like to load Audacity with a very large amount of data, you'll find it snappy. It's already shipped with dozens of great plugins for recording sound or adding a personal touch.

Only useful in the latest 0.13 beta version and Reszound still takes times to troubleshoot recording and playback. In return, though, you get an efficient tool for working with large files.
