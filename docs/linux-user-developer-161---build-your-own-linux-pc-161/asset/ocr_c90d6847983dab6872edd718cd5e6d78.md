# WHAT IS PI WARS?

Held for the first time last year, Pi Wars was hosted as part of the Cambridge Raspberry Pi contestants on 6 December 2014. The event saw contestants win great prizes by entering their Raspberry Pi powered robots into challenges: an obstacle course, a line-following challenge, a three-point turn, a sumo wrestling match where robots need to push the opponent out of the ring.

One year on, Pi ran in style with upgraded robots and matches. From first-time creators to established experts, everyone was involved. This was an event we will never forget. The line-following challenge and obstacle course were significantly re-worked, and new challenges were introduced: Pi Noon and Skittles. We interviewed Tim Richardson to find out more about how the robots and their owners through their paces...

# When did you start organising Pi Wars?

The original one started around September of last year, but this one we started earlier. We started thinking about it while we were building around July. It's been a long process of planning before it happened.

# What's your favourite robot so?

There are some absolutely beautiful robots, but particularly Triangula. It's just the three-wheeled robot and can go in any direction—it's beautifully engineered.

# Did you enjoy each challenge?

It's been hectic out! I've spent a lot of time recently creating the EduKit 3, which is the robotics kit. I wrote the worksheets and designed the challenges and wrote all the worksheets for the kids - I used my own information about electronics before I started, so I was teaching myself to do that. I'm getting them all out because everything is awesome, and I'm trying to get affordable kits for people to explain examples. An example is the robot that shows you how programming works, even without like competitions, but she has built an EduKit 3 robot into it. It's absolutely gorgeous!

# So, what about the new challenges for this year?

Pi Noon is a replacement for the duel. There was a Pi-Pi duel originally, the sumo wrestling: there was one robot to push the other one out, and another. We wanted to do something different where robot didn't have an advantage, and this seemed like it was likely to be "size doesn't matter".

# What do you think of the robots built for the Skittles event?

We expected people to push that robot - that's all we thought then but we have people being able to knock that ball. We had to put cardboard boxes around it, just to stop them from smashing the windows! We really didn't expect the engineering that they have come up with.

# Any plans for the next year?

We have some things in place that we can't explain yet. It's going to be another exciting year. We have another Pi Wars but it might not be next year - we haven't decided yet. We're just taking one event at a time.
