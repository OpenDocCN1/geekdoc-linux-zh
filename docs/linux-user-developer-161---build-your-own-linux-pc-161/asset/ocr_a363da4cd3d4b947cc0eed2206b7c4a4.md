**Luke Mulcahy** is the FUZE-team's in-house programmer. At 15 years old, Luke is adept in many languages, though he doesn't have to push FUZE BASIC through its paces.

Welcome to the final episode of our FUZE BASIC tutorial. Over the last two issues we've built up a shooter game inspired by the classic Tempest. Now we will add a few more features and polish our code to make this into a fully functional game.

At almost 900 lines, 73MP357 is not a small project. You will need to download the full program as well a few sound effect and music files, all of which are available to download from this

issue's FileSilo page or from fuze.co.uk/tutorials/73MP357.zip

Download and decompress the files, then save the resulting folder to your project folder. This final version is exactly as we wanted: it has levels, explosions, music and sound effects, collision and an attract screen. One more thing: FUZE BASIC has been updated since the last tutorial and as such we highly recommend you update it.
