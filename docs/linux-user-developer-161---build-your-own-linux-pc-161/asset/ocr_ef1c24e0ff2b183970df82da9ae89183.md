# # Convert tabs to spaces

Learning about the beauty of text processing how to translate a tab into multiple spaces

> The issue we look at this is converting a tab to a given number of space characters and versa. This particular functionality is often needed in text editors and is often off in programming. Two C programs are developed to do this. The number of space characters is provided as a command line argument. Similarly, s2t uses a separate function to replace spaces with tabs once the number of space characters is provided. You might have given 8, 10, as the number of characters and implementation of s2c is easier than s2t because a tab is a single character whereas it is represented as ' and space character.

There are two approaches for solving this problem using separate function for each task or both. The first approach is more generic and both s2c and s2t will use a separate function named s2c and s2t, respectively which will take a string and an integer as input and return. The integer variable will return the number of space characters that replace a tab and the number of space characters replaced in the string by a tab, respectively.

The input is processed by character using pointer arithmetic, the code loop (while) runs until it reaches the NULL pointer. If you are unfamiliar with pointer arithmetic it first dereferences the pointer and then increments the pointer to the next character. As the ASCII value of NULL is 0 it is the end of the string which terminates the loop.

The difficulty in s2t is that if the input string is full of tabs the memory is going to return. The worst-case scenario is when the input string is full of tabs therefore malloc() does the necessary memory allocation for the new line using the worst-case scenario.
