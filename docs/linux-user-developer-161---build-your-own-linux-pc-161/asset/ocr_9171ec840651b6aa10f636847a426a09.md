# ### 01 Prepare your Pi

To set Raspberry Pi up as a PiBeacon, begin with
a fresh, updated version of Raspberry, perhaps upgrade commands using
NOOBE. Follow the instructions on the update and ensure
that your Raspberry is fully up to date. When this
done, you can proceed to install the libraries required for the
PiBeacon project.

With Bluetooth Beacon (yet), iBeacon from
Apple uses Bluetooth and an iPhone 45 or later in proximity
to trigger an app or message. Google, meanwhile, has its own
version, and Raspberry developers investigate
this technology with the addition of a low-cost Bluetooth Low-Energy
PiBeacons' (BLE) USB module, available from ModPi at bit.ly/1MTdbjC

It will take a little bit of time to download and
install. Once the libraries are installed, however, you'll be able to
proceed and set up Bluetooth.
