# # Optimus Pi

PyroBot, returned with a wholly new vision that is Optimus Pi. It's built around an Aisis ML-X kit with an outside chassis featuring four motors and wheels - these are easily removable. Inside is an Arduino with a controller, and the UBER. On the top is a Raspberry Pi connected to it, which is what I use for my menu. I'm using a Proto HAT4 here, just to add cameras and sensors that will make the robot a bit more clever on.

"Some of the programs are set up to the compass, but I found it a bit unsolvable so I ended up dead-end. Now I'm using the joystick to control the menus; I've got a little screen that shows the IP address and dates, and this is in a highly populated so - because I used my PS3 DualShock, a manual is an option, otherwise it wouldn't be. I've also placed a clear case for the Raspberry Pi camera, and then by being turning on and off during the changes

"On the back I just got this little I2C hub, because everything connects through I2C. So the chassis goes down to the Raspberry Pi. And now I have a sensor for the proximity alert, and then at the moment I got the fight for the front which I was using for the opponent's balloon. I got a 3D printer off and used it to make these components. And that I've got a little Wi-Fi and Bluetooth USB adapter; so avoid needing a HAT but I bought this extra combo unit.

"Technically I don't need Wi-Fi, but then if it goes wrong with the robot and I need to fix it, I used an off-the-shelf kit, which I put a strip on on top of this year. Year it's all scratch-build, so it's smaller and better built from the ground up. Now you can find out more at optimus.pi.myblog.com"
