# Content Management Systems

+   1. **Help System:** Manages the help desk.
+   2. **Galaxia Workflow Engine:** Allows management of complex workflow processes.
+   3. **Wiki:** Collaborative documentation system; also allows authorized users to create and edit content for static HTML pages, and offers a WYSIWYG HTML editor and spell-checker, among other advanced features.
+   4. **Articles:** Organizes and manages articles.
+   5. **Blogs:** Weblog administration.
+   6. **Directory:** Link manager that categorizes links.
+   7. **File Gallery:** Organizes and manages uploaded files.
+   8. **FAQs:** Manages FAQs for the site.
+   9. **Maps:** Allows you to display interactive maps.
+   10. **Trackers:** Manages and organizes custom data for you.
+   11. **Hotwords:** Allows you to embed links from certain words on your site.
+   12. **Contact Us:** Easy form that allows users to contact you.
+   13. **Stats:** Manages site stats, for every active module possible.
+   14. **Referrer Stats:** Manages stats for referring sites.
+   15. **Debugger Console:** Assists a developer in debugging the site.

Other features that are pre-installed, but need only to be activated with the click of a button include:

+   1. **Comments:** Allows users to comment on images, articles, and other content throughout the site.
+   2. **Image Gallery:** Allows users to rank, view, and upload images.
+   3. **Newsreader:** RSS feed for news.
+   4. **Polls:** Manages online polls.
+   5. **Quizzes:** Allows users to take a quiz and be graded.
+   6. **Featured Links:** Manages links that open within your Tiki site; keeps track of link stats.
+   7. **Banners:** Manages banner campaign and click-throughs.
+   8. **Newsletters:** Manages newsletter broadcasts for the site and allows users to subscribe.
+   9. **Forums:** Manages forums.
+   10. **Shoutbox:** Allows users to display short lines of text in a dynamic window.
+   11. **Surveys:** Manages online surveys.
+   12. **Ephemerides:** Allows you to display images and text customized for each day of the year.
+   13. **Live Support System:** Allows users to request help from the live help desk.
+   14. **Babelish translation:** Allows users to translate portions of the site.
+   15. **Integrator:** Allows you to import external HTML pages into the site.
