Local cd (lcd) At this point, Sam realizes he has not created the new directory to hold the files he wants to download. Giving in an ftp mkdir command would create a new directory on the server, but Sam wants a new directory on his local system. He uses an exclamation point (!) followed by a mkdir memos.hold to invoke a shell and run mkdir on the local system, creating a directory memos.hold in his working directory on the local system. (You can display the name of the working directory on the local system with pwd.). Next, because Sam wants to copy files from the server to the memos.hold directory on his local system, he has to change his working directory on the local system. Giving the command cd memos.hold will not accomplish what Sam wants to do because the exclamation point will spawn a new shell on the local system, which is not the shell that ftp is running under.
