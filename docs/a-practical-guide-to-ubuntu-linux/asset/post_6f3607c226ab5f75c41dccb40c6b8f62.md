## JUMPSTART II: SETTING UP A LOCAL OR REMOTE PRINTER USING THE CUPS WEB INTERFACE

![](img/45ff4cd21497435daa35084a84b95d07_607_0.png)
Figure 14-10 The Add Printer page

Clicking the Administration tab near the top of the page displays the Administration page. On this page click Add Printer to display the first Add Printer page (Figure 14-9). Click the printer you want to install and then Continue to display the second Add Printer page (Figure 14-10). Enter the name of the printer in the text box Name; this name must start with a letter and not contain any spaces. You must supply a name—any name you like. Optionally, you can fill in the text boxes Description and Location with text that help users identify the printer. Put a tick in the box labeled Sharing if you want to share the printer. Click Continue.

### Specifying a device
The next screen allows to select the model of the printer you want to set up (Figure 14-11, next page). Select the printer you want to use. Click Add Printer.

If the printer is PostScript capable but is not listed, select a PostScript printer such as the Apple LaserWriter 12/640ps. If the printer is not PostScript capable and is not listed, check whether the printer supports PCL; if it does, select another, similar PCL printer. If all else fails, determine which printer is most similar to the one you are configuring and specify that printer. You can also try configuring the printer using system-config-printer (page 550), which offers a different choice of models.

After you click Add Printer, the CUPS Web interface displays the Set Default Options page. This page allows you to set printer options and configuration information. Click the buttons at the top of the page, browse through the selections, and make any changes you like. Frequently you need change nothing. Click Set Default Options.

![](img/45ff4cd21497435daa35084a84b95d07_608_0.png)
Figure 14-11 The third Add Printer

After displaying a brief message, the CUPS web interface displays the Printer page (Figure 14-12) showing the new printer. Maintenance↔Print Test to confirm the new setup works. If you want to make this the default printer, click the button labeled Administration and select **Set As Server Default.**

The buttons at the bottom of the Printer page enable you to cancel or move jobs in the print queue. In addition to these tasks, you may be able to reprint jobs. Figure 14-12 shows the Printer page displaying information about how a job is printing.

## TRADITIONAL UNIX PRINTING

Before the advent of GUIs and WYSIWYG (page 1181) word processors, UNIX users would create documents using an editor such as vi and a typesetting markup language such as Tex or nroff, converting the result files to PostScript using an interpreter, and send the PostScript files to the printer using lpr (BSD) or lp (System V). Ubuntu implements both BSD and System V command-line utilities for compatibility. However, these utilities are now wrappers around the equivalent functionality in CUPS rather than core components of the printing system. The corresponding utilities are functionally equivalent; whichever you prefer (Table 14-2).

The *cups-bsd* package holds the BSD utilities; the *cups-client* package holds the System V utilities. From the command line, you can print a text, PostScript, or PDF file using lp:

```bash
$ lp 1 memo.txt
request id is MainPrinter-25 (1 file(s))
```

### Table 14-2 BSD and System V command-line print utilities

| Command | Purpose |
|---||---|
| lpr | sends job(s) to the printer |
| lpq/lpstat | displays the status of the print queue |
| lprm/cancel | removes job(s) from the print queue |

The preceding command adds memo.txt to the print queue of the default printer as job 25. When printer is available, it prints the file. You can specify a using the -d option:

```bash
$ lp -d ColorPtr graph.ps
request id is ColorPtr-26 (1 file))
```

The lp -P option is equivalent to the lp -d option. 

Without arguments, lp and lpr send their standard input to the printer:

```bash
$ cat memo2.txt | lp
request id is MainPrinter-27 (1 file))
```

The lpq and lpstat commands display information about the print queue:

| Job ID | User | Size | Date |
|---|---|---|---|
| MainPrinter-25 | zach | 13312 | Sun Feb 21 18:28:30 2010 |
| ColorPtr-26 | zach | 75776 | Sun Feb 21 18:28:48 2010 |
| MainPrinter-27 | zach | 8192 | Sun Feb 21 18:28:57 2010 |

Use cancel or lprm to remove jobs from the print queue. By default, only the owner of a print job or a user working with root privileges can remove it.

```bash
$ cancel 27
$ lpstat
| MainPrinter-25 | zach | 13312 | Sun Feb 21 18:28:30 2010 |
| ColorPtr-26 | zach | 75776 | Sun Feb 221 18:28:48 2010 |
```
