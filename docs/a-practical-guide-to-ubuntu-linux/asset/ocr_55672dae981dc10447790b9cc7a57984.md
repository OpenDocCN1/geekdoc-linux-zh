a local filesystem—by using the form LABEL=xx, where xx is the volume label. Refer to e2label on page 458.

A remote directory hierarchy appears as hostname:pathname, host-name is the name of the remote system that has the filesystem, and pathname is the absolute pathname (on the remote system) of the direc-
tory is to be mounted.

+   2. Mount point—The name of the directory file that the filesystem/directory
hierarchy is to be mounted on. If it does not already exist, create this
directory using mkdir. See pages 35 and 507.

+   3. Type—The type of filesystem/directory hierarchy that is to be mounted.
Local filesystems are generally of type ext2, ext4, or iso9660, and remote
directory hierarchies are of type nfs or cifs. Table 12-1 on page 505 lists
filesystem types.

+   4. Mount options—A comma-separated list of mount options, such as
whether the filesystem is mounted for reading and writing (rw, the default)
or read-only (ro). See pages 508 and 778, and refer to the mount and nfs
pages for lists of options.

+   5. Dump—Used by dump (page 603) to determine when to back up the
filesystem.

+   6. Fck—Specifies the order in which fsck checks filesystems. Root (/))
have a 1 in column. Filesystems that are mounted to a directory
below the root directory should have a 2. Filesystems that are mounted
an another filesystem (other than root) should have a 3 for.
ample, if local is a separate filesystem from /usr and is mounted on /usr
(as/local), then local should have a 3. Filesystems and directory hier-
archies that do not need to be checked (for example, remotely mounted
directory hierarchies and CDs/DVDs) should have a 0.
