# WORKING WITH FILES

A handle is a name that you can use in a Perl program to refer to a file or process that is open for reading and/or writing. When you are working with the shell, handles are referred to as file descriptors (page 987). As you are working with the shell, the kernel automatically opens handles for input (page 243), standard output (page 243), and standard error (page 297) before it runs a program. The kernel closes these descriptors after a program finishes running. The names for these handles are STDIN, STDOUT, and STDERR, respectively. You must manually open handles to read from or write to other files or processes. The syntax of an open statement is

Opening a file and assigning a handle

```
`open(file-handle, ['mode'], 'file-ref');`
```

where file-handle is the name of the handle or a variable you will use in the program to refer to the file or process named file-ref. If you omit specify a mode of <, Perl opens the file for input (reading). Specify mode as to truncate and write to a file or as to append to a file.

See page 1082 for a discussion of reading from and writing to processes.

```
`print [file-handle] "text";`
```

where file-handle is the name of the handle you specified in an open statement and text is the information you want to output. The file-handle can also be STDOUT or STDERR, as explained earlier. Except when you send information to standard output, you must specify a handle in a print statement. Do not place a comma after file-handle. Also, do not enclose arguments in print within parentheses so create processes.
