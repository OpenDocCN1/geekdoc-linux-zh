## 1081 示例

随后你可以在 Perl 程序中引入该模块。下面的示例使用了时间戳模块来生成一个唯一文件名：

```
$ cat fn.pl
use Timestamp::Simple qw(stamp);
```

```
# 将时间戳存入变量
$ts = stamp, "\n";
```

```
# 去掉年份
$ts =~ s/...(.*)\/\/1;
```

```
# 创建唯一文件名
$sfn = "myfile." $ts;
```

```
# 打开文件、写入内容并关闭文件
open (OUTFILE, '>', "$sfn");
print OUTFILE "HI here.\n";
close (OUTFILE);
```

```
$ perl fn.pl
myfile.090518310
```

你可以使用 `substr` 函数代替正则表达式来去掉年份。要这样做，请将以 `$ts =` 开头的行替换为以下行。在这里，`substr` 取了字符串 `$ts` 从第 4 位开始一直到字符串末尾的值：

```
$ts = substr ($ts, 4);
```

## 示例

本节提供了一些 Perl 程序。首先原样运行这些程序，然后对它们进行修改以学习更多关于 Perl 编程的知识。

第一个示例在 Linux 下运行，并显示作为参数的用户的用户所属的用户列表。如果不提供参数，它将显示运行程序的用户所属的用户列表。在 Perl 程序中，`%ENV` 哈希存储了来自调用 Perl 的 shell 的环境变量。该哈希中的键（key）是环境变量名；哈希中的值（value）是对应变量的值。程序的第一行将用户名赋值给 `$User`。`shift` 函数（第 105 页）获取第一个命令行参数的值，如果存在剩余参数则将其向后移动。如果用户带参数运行程序，`argument` 将被赋值给 `User`。如果命令行上没有参数，`shift` 将失败，Perl 将执行逻辑或（`||`）之后的语句。该语句提取 `%ENV` 中与 `USER` 键关联的值，即运行程序的用户名。

接收输出：第三条语句初始化了数组 `@list`。虽然该语句并非来自进程，但包含它是良好的习惯，可以使代码更易读。下一条语句打开词法变量 `$fh`。此 `open` 语句中文件引用（第 1666 页）部分结尾的管道符号（`|`）告诉 Perl 将管道符号之前的命令行传递给 shell 执行，并在程序从文件句柄读取内容时接收该命令的标准输出。在这种情况下，命令使用 `grep` 过滤 `/etc/group` 文件（第 492 页）中包含 `Suser` 中用户名的行。如果 Perl 无法打开句柄，`die` 语句将显示错误信息。

### $ cat groupfind.pl

```perl
$Suser = shift || $ENV{"USER"};
say "$Suser belongs to these groups:";
@list = ();
open ($fh, "grep $Suser /etc/group |") or die "Error: $!\n";
while ($group = <$fh>) {
    chomp $group;
    $group =~ s/(.*):.*/1;
    push @list, $group;
}
close $fh;
@slist = sort @list;
say @slist;
```
