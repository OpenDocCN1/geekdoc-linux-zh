Working with root privileges, use a text editor to set the following configuration
variables in /etc/exim4/update-exim4.conf:

```
dc_eximconf_configtype='internet'
dc_other_hostnames='mydom.example.com'
dc_local_interfaces='
```

Configuration type Set dc_eximconf_configtype to internet allows exim4 to send mail to
nonlocal systems as specified by the DNS MX record (page 828) for the domain
mail addressed to and to accept email on the interfaces specified by
dc_local_interfaces (next page). This line should appear exactly as shown above.

Other hosts The dc_other_hostnames configuration variable specifies the FQDNs or IP addresses
that the local server receives mail addressed to. Replace mydom.example.com with semi-
icolons. These values do not necessarily include the FQDN or the IP address of
the local server.

Local interfaces Set dc_local_interfaces to the interface you want exim4 to listen. Set it to the null
value ('') to listen on all interfaces.

As Just Start you may need to change the value of /etc/hostname (page 718).
For Boolean variables in this file, exim4 interprets the null value (specified by '') as
false. The file should look similar to this:

```
$ cat /etc/exim4/update-exim4.conf
...
dc_eximconf_configtype='internet'
dc_other_hostnames='mydom.example.com'
dc_local_interfaces=''
dc_readhost=''
dc_relay_domains='false'
dc_minimaldomains='false'
dc_relay_nets=''
dc_smarthost='644'
FILEMODE='
dc_use_splitconf='false'
dc_hide_mailname=''
dc_mailname_in_oh='true'
dc_localdelivery='mail_spool'
```

See page 724 for more on exim4 configuration variables. Once you
have restarted exim4, it will accept mail addressed to the local system. To receive\mail addressed to a domain, the DNS MX record (page 828) for that domain must
oint to the IP address of the local system. If you are not running a DNS server, you
mask your ISP to set up an MX record or else receive mail at the IP address of
the server. If you receive email addressed to an IP address, set dc_other_hostnames
to that IP address.
