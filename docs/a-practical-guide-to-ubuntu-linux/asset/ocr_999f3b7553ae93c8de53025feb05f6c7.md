Install Ubuntu in text mode—Installs a graphical Ubuntu system using the debian-install textual installer. For more information refer to “The Ubuntu Text Installer” on page 85.

Check disc for defects—Verifies the contents of the CD/DVD you are booting from; see the tip on page 56. Ubuntu reboots the system after checking the disk.

Test memory—Run memtest86+, a GPL-licensed, stand-alone memory utility for x86-based computers. Press C to configure the test; press ESCAPE to exit and reboot. For more information see we.memtest.org.

Rescue a broken system—Provides tools to repair a system that may not boot or that has a problem with the filesystem mounted at /(root). see page 83.

Install Ubuntu Server—Installs a Ubuntu server using the textual installer. For more information refer to “The Ubuntu Installer” on page 85. During installation, the installer displays the Software selection screen, which asks you to install various servers, a DNS server (Chapter 24), a LAMP server (includes Apache [Chapter 26], MySQL [page 628], and PHP), and OpenSSH server (Chapter 18), a Samba server (Chapter 23), and others. Use the ARROW keys to move the highlight to the space between the brackets ([ ]) and the space bar to select a choice.

Install Ubuntu Enterprise Cloud—Brings up a private cloud. For more information see www.ubuntu.com/cloud/private.

The boot: prompt You can press ESC from any of these menus to display a prompt.

# THE FUNCTION KEYS

Along the bottom of each screen is a series of labeled key names. Pressing each function key displays information or a menu that may be helpful if you experience a problem while booting Ubuntu or in a live session. Some of the keys allow you to change parameters.

+   F1 The F1 key displays the help window shown in Figure 3-21 (next page). Pressing a function key while this window is visible displays another help window. A function key when this window is not displayed has the effect described in the following paragraphs. Press ESC to close the help window.

+   F2 Language The F2 key displays the language overlay (Figure 3-1, page 52). Use the Arrow keys to highlight the language you want the live session or the installer/installed system to use and press RETURN. Ubuntu gives you the opportunity to change this selection for the installed system as you install the system.
