In the preceding example, Scount keeps track of the number of lines the user enters. Putting the ++ increment operator before a variable (++Scount; called a preincrement operator) increments the variable before Perl evaluates it. Alternatively, you could initialize Scount to 1 and increment it with Scount++ (postincrement), then in the first print statement Scount would equal one more than the number of lines entered.

$ The S_ variable keeps track of the number of inputs of a program has read.
Using S_, you can rewrite the previous example as follows:

```
$ cat while1.pl
#!/usr/bin/perl -w
while ($line = <) {
    print \$, "$line";
}
print "\n$_ lines entered.\n";
```

$ You can simplify Perl code using the $_ variable. You can use $_ in many places in a Perl program—from $_ as meaning it, the object of what you are doing. It is the default operand for many operations. For example, the following section of code processes a line using the Slice variable. It reads a line into Sline, removes any trailing NEWLINE from Sline using chop (page 1067), and checks whether a regular expression matches $_.

```
while ($line = <>) {
    chop $_;
    if ($line =~ /regex/) ...
}
```

You can rewrite this code using $_ to replace Sline:

```
while ($_ = <>) {
    chop $_;
    if ($_ =~ /regex/) ...
}
```

Because $_ is the default operand in each of these instances, you can also omit $_ altogether:

```

    chop \$;n    if (/regex/) ... # if \$_ matches regex
```
