# SPAMASSASSIN

Spam—or more correctly UCE (unsolicited commercial email)—accounts for more than three-fourths of all email. SpamAssassin evaluates each piece of incoming email and assigns a number that indicates the likelihood that the email is spam. The higher the number, the more likely the email is spam. You can filter spam based on its rating. SpamAssassin is effective as installed, but you can modify its configuration files to make it fit your needs. See page 715 for sources of information on SpamAssassin.

# How SpamAssassin Works

spcm and spamd SpamAssassin employs the spam daemon and the spam client. Although it includes the spamAssassin utility, the SpamAssassin documentation suggests using spams and not spamAssassin to filter mail because spams is quicker to load than spamAssassin. While spamAssassin works alone, spcm calls spamd. The spam daemon spawns children; when spamd is running, it spawns several child processes in addition to the parent process:

```
$ spams -ef | grep spamd
root 5073 1 0 10:53 ? 00:00:00 /usr/bin/spamd --create-prefs ...
root 5106 5073 0 10:53 ? 00:00:00 spamd child
root 5107 5073 0 10:53 ? 00:00:00 spamd child
zach 16080 6225 0 12:58 pts/0 00:00:00 grep spam
```
