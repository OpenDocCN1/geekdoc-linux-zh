# EFFECTIVE RIGHTS MASK

The line that starts with mask specifying the effective mask. This mask limits the effective permissions granted to ACL groups and users. It does not affect the owner of the file or the group file is associated with. In other words, it does not affect Linux permissions. However, because setfac sets the effective rights mask to the least restrictive ACL permissions for the file, the mask has no effect unless you set it explicitly after setting up an ACL for the file. You can set the mask by specifying mask or by setting a name in a setfac command.

The following example sets the effective mask to read for the report file:

```
$ setfacl -m mask:r-- report
```

The mask line in the following setfacl output shows the effective mask set to read (r--). The line displays Sam's file access permissions they still set to read and write. However, the comment at the right of the line shows that his permission is read.

```
$ setfacl report
# file: report
# owner: max
# group: max
user::rw-
user:sam:rw--
group::r--
mask::r--
other::r--
#effective:r--
```

As the next example shows, setfacl can modify ACL rules and set more than one ACL rule at a time:

```
$ setfacl -m sam:r--,u:zach:rw-- report
```

```
$ setfacl --omit-header report
user::rw-
user:sam:r--
user:zach:rw--
group::r--
mask::rw--
other::r--
```

The -x option removes ACL rules for a user or a group. It has no effect on permissions for the owner of the file or the group file is associated with. The next example shows setfacl removing the rule that gives Sam permission to access the file:

```
$ setfacl -x u:sam report
```

```
$ setfacl --omit-header report
user::rw-
user:sam:r--
user:zach:rw--
group::r--
mask::rw--
other::r--
```
