# CHAPTER 1 WELCOME LINUX

MINIX Two professors created their own stripped-down UNIX look-alikes for educational purposes: Doug Comer created XINU and Andrew Tanenbaum created MINIX. Linus Torvalds created Linux to counteract the shortcomings in MINIX. Every time there was a choice between simplicity and efficiency/features, Tanen chose simplicity (to make it easy to teach with MINIX), which meant this system lacked features people wanted. Linux went in the opposite direction.

You can obtain Linux at no cost on the Internet (page 43). You can also obtain the GNU code via the U.S. mail at a modest cost for materials and shipping. You can support the Free Software Foundation (www.fsf.org) by using the GNU (GNU) code in higher-priced packages, and you can buy commercial releases of Linux (called distributions), as Ubuntu Linux, that install instructions, software, and support.

GPL and GNU software are distributed under the terms of the GNU Public License (GPL, www.gnu.org/licenses/licenses.html). The GPL says you have the right to copy, modify, and redistribute the code under the agreement. When you redistribute the code, however, you must also distribute the same license with it, making the code and the license inseparable. If you get source code for the Internet under an accounting program that is under the GPL and then modify the modified source code and redistribute an executable version of the program, you must also distribute the modified source code and the GPL agreement with it. Because this arrangement is the reverse of a normal copyright copy works (it gives rights instead of limiting them), it has been termed a copyleft. (This paragraph is not a legal interpretation of the GPL; it is intended to merely give you an idea of how it works. Refer to the GPL itself when you want to make use of it.)

# HAVE FUN!

Two words for Linux are “Have Fun!” These words pop up in prompts and documentation. The UNIX—now Linux—culture is steeped in humor that can be seen throughout the system. For example, less is GNU has replaced the Linux paging utility more with an improved utility less. The utility to view PostScript documents is named ghostscript, and one of several replacements for the editor is named elvis. While machines with Intel processors have “Intel Inside” logos on their outside, some Linux machines sport “Linux Inside” logos. And Torvalds himself has been seen wearing a T-shirt bearing a “Linux Inside” logo.
