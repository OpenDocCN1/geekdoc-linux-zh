# PROCESSING THE COMMAND LINE

$ echo There is $((60*60*24*365)) seconds in a non-leap year.
 are 31536000 seconds in a non-leap year.

The next example uses wc, arithmetic expansion, and command substitution (page 362) to estimate the number of pages to print the contents of the file letter.txt. The output of the wc utility used with the -l option is to get the number of lines in the file, in columns (character positions) 1 through 4, followed by a SPACE and the name of the file (the first command following). The cut utility with the -c1-4 option extracts the first four columns.

```
$ wc -1 letter.txt
351 letter.txt
$ wc -1 letter.txt | cut -c1-4
351
```

The dollar sign and single parentheses instruct the shell to perform command substitution; the dollar sign and double parentheses indicate arithmetic expansion:

```
$ echo $((($wc -1 letter.txt | cut -c1-4)/66 + 1))
```

The preceding example sends standard output from wc via a pipe. By command substitution, the output of both commands replaces the commands between $ ( and the matching ) on the command line. Arithmetic expansion divides this number by 66, the number of lines on a page. A 1 is added because the integer division results in any remainder being discarded.

# Fewer dollar signs ($)

> tip When you use variables in $(($ and )), the dollar signs that precede individual variable references are optimal:

```
$ x=23 y=37
$ echo $((2*$x + 3*$y))
157
$ echo $((2*x + 3*y))
157
```

Another way to get the same result without using wc is to redirect the input to wc instead of getting its input from a file name on the command line. When we redirect its input, we do not display the name of the file:

```
$ wc -1 letter.txt
351
```

It is common practice to assign the result of arithmetic expansion to a variable:

```
$ npages=$(( $(wc -1 < letter.txt)/66 + 1 ))
```

The let builtin evaluates arithmetic expressions just as the $(( )) syntax does. The following command is equivalent to the preceding one:

```
$ let "npages=$$(wc -1 < letter.txt)/66 + 1")
```
