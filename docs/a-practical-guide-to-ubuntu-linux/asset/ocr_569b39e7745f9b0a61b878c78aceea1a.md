# GCOS

See GECOS.

# GECOS

General Electric Comprehensive Operating System. For historical reasons, the user information field in the /etc/passwd file is called the GECOS field. Also GCOS.

# gibibyte

Giga binary byte. A unit of storage equal to 2³⁰ bytes = 1,073,741,824 bytes = 1024 meibytes (page 1159). Abbreviated as GIB. Contrast with gigibyte.

# gigabyte

A unit of storage equal to 10⁹ bytes. Sometimes used in place of gigibyte. Abbreviated as GB. See also large number on page 1156.

# glyph

A symbol that communicates a specific piece of information nonverbally. A smiley (page 1172) is a glyph.

# GMT

Greenwich Mean Time. See UTC on page 1179.

# graphical display

A bitmap monitor that can display graphical interfaces. Contrast with ASCII terminal (page 1135).

# graphical user interface

See GUI.

# group (of users)

A collection of users. Groups are used as a basis for determining file permissions. If you are not the owner of a file and you belong to the group file is assigned to, you are subject to the group access permissions for the file. A user can simultaneously belong to several groups.

# group (of windows)

A way to identify similar windows so they can be displayed and acted upon. Typically windows started by a given application belong to the same group.

# group ID

A unique number that identifies a set of users. It is stored in the password and group databases (/etc/passwd and /etc/group files) or the group database associates GIDs with group name. Also GID.

# GUI

Graphical user interface. A GUI provides a way to interact with a computer system by choosing items or manipulating pictures drawn on a screen instead of typing command lines. Under Linux, the Window System provides a graphical display and mouse/keyboard input. GNOME and KDE are two popular desktop managers that run under X. Contrast (page 1140).

# hacker

A person who enjoys exploring the details of programmable systems and learning how to stretch their capabilities, as opposed to users, who prefer to learn the minimum necessary. One who programs enthusiastically (even obsessively) or who enjoys programming rather than just theorizing about programming. Contrast with cracker (page 1143).

# half-duplex

A half-duplex device can only receive or transmit at a given moment; A hub (page 1152) is typically a half-duplex device. Contrast with full duplex (page 1149).
