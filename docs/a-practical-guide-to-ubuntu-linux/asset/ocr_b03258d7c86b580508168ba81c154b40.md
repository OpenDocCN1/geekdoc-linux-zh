The Views tab sets several defaults, including view the File Browser displays (Icon, List, or Compact view), the arrangement of the objects, the default zoom level, and default settings for the Compact view.

The Behavior tab controls how many clicks it takes to open an object and what Nautilus displays when it opens an executable text object (script). For more confident users, this tab has an option that includes a Delete selection in addition to the Move selection on several menus. The Delete selection immediately removes the selected object before moving it to the Trash folder. This also holds the check labeled Open each folder in its own window that is described in the next section.

The Display tab specifies which information Nautilus includes in object (icon) captions. The three drop-down lists specify the order in which Nautilus displays as you increase the zoom level of the View pane. This tab also specifies the date Nautilus uses.

The List Columns tab specifies columns Nautilus displays, and in what order it displays, in the View pane when you select List View.

The Preview tab controls when Nautilus displays or previews of files (Always, Local Only, Never).

The Media tab specifies which action Nautilus takes when you insert media such as a CD/DVD, or connect devices such as a USB flash drive, to the system.

Click the Main Toolbar, Side Pane, Location Bar, and Status selections in the View submenu to display or remove these elements from the window. Show Hidden Files selection displays in the View pane those hidden filenames (page 204).

The Go selections display various folders in the View pane.

Bookmarks appear at the bottom of this menu and in the Side pane under Places. The Bookmarks selections are explained under “Places” on page 278.

The Help selections display local and online information about Nautilus.

# # THE NAUTILUS SPATIAL VIEW

Nautilus gives you two ways to work with files: the traditional File Browser view described in the previous section and the innovative Spatial view shown in Figure 8-7. By default, Ubuntu displays the Browser view.

The Spatial view (as in “having the nature of space”) view has more powerful features but may take getting used to it. It always provides one window folder. By default, when you open a folder, Nautilus displays a new window.

Turn on the Spatial view by selecting File Browser menu: Edit→Preferences. Then click the Behavior box labeled Open each folder in its own window, click Close, and close the File Browser window. Next time you open a File Browser window, it will display a Spatial view.
