eximstats The eximstats displays statistics based on exim4 log files. Call this utility with an argument of the log file, such as /var/log/mainlog or /var/log/mainlog2.gz. Without any options, eximstats sends information on the log file in text format to standard output. When you include the -html option, eximstats generates output in HTML format, suitable for viewing with a browser:

```
$ exim -html /var/log/exim4/mainlog.gz > exim.0720.html
```

If you are not a member of the adm group, you must run the preceding command with root privileges. See the eximstats man page for more information.

# CONFIGURING AN EX4 MAIL SERVER

exim4 daemon is a complex and capable MTA that is configured by /etc/default/exim4 and the files in the /etc/exim4 directory hierarchy. The former allows you to specify how the daemon is to run; the latter configs all aspects of exim4. You can configure exim4 by editing its configuration files with a text editor (discussed in the next section) or by dpkg-reconfigure (page 726).
etc/default/exim4 The default /etc/default/exim4 file sets QUEUERINNER to combined, which starts one daemon that runs both the queue and listening for email. QUEUEINTERVAL 30m, which causes the daemon to run the queue (that is, check whether the queue contains mail to be delivered) every 30 minutes. See the comments in the file for more information.

# USING A TEXT EDITOR TO FIGURE EXIM4

The files in the /etc/exim4 directory hierarchy control how exim4 works—how it interfaces with, whether it uses a smarthost or sends directly to its destination, and which systems relays email, and so on. You can also create exim4.conf.localmacros to turn on/off exim4 functions (see page 737 for an example). Because of its flexibility, exim4 uses many configurations. You can establish the values of these variables in two ways: You can edit a single file, as the JumpStart sections of this chapter explain, or work with the approximately 40 files in the /etc/exim4/conf.d directory hierarchy. By working with the single file update-exim4.conf.conf is sufficient. This section describes the variables in that file but does not discuss working with the files in conf.d. Refer to the exim4 specification if you need to set up a more complex mail server.
