
## GLOSSARY

1165

# peripheral device
See device on page 1145.

# persistent
Data that is stored on nonvolatile media, such as a hard disk.

# phish
An attempt to trick users into revealing or sharing private information, especially passwords or financial information. The most common form is emailing to be from a bank or vendor that requests a user fill out a form to “update” an account on a phoney Web site disguised to appear legitimate. Generally sent as spam (page 1173).

# physical device
A tangible device, such as a disk drive, that is physically separate from other, similar devices.

# PID
Process identification, usually followed by the word number. Linux assigns a unique PID number as each process is initiated.

# pipe
A connection between programs that standard output of one program is connected to standard input of the next. Also pipeline.

# pixel
The smallest of a picture, typically a single dot on a display screen.

# plaintext
Text that is not encrypted. Also cleartext. Contrast with ciphertext (page 1141). See also “Encryption” on page 1110.

# Pluggable Authentication Modules
See PAM on page 1164.

# point-to-point link
A connection limited to two endpoints, such as the connection between a pair of modems.

# port
A logical channel or UDP endpoint in a communications system. The TCP (page 1176) transport layer protocols used on Ethernet port numbers to distinguish different logical channels on the same network interface on the same computer.

The /etc/services file (see the binding of this file for more information) or the NIS (page 1162) services database specifies a unique port number for each application program. The network links incoming data to the correct service (program). Standard, well-known ports are used by everyone: Port 80 is used for HTTP (Web) traffic. Some protocols, such as TELNET and HTTP (which is a special form of TELNET), default ports are mentioned earlier but can use other ports as well. UDP.

# port forwarding
The process by which a network port on one computer is transparently connected to a port on another computer. If port X is forwarded from system A to system B, any data sent to port X on system A is sent to system B automatically. The connection can be between different ports on the two systems. Also tunneling (page 1178).

# portmapper
A server that converts TCP/IP port numbers into RPC program numbers. See “RPC Network Services” on page 406.

1166 GLOSSARY

printable character
one of the graphic characters: a letter, number, or punctuation mark. Contrast with a nonprintable, or CONTROL, character. Also printing character.

private address
IANA (page 1153) has reserved three blocks of IP addresses for private internets or LANs:

```
10.0.0.0 - 10.255.255.255
172.16.0.0 - 172.31.255.255
192.168.0.0 - 192.168.255.255
```

You can use these addresses without coordinating with anyone outside of your LAN (you do not have to register the system name or address). Systems using these addresses cannot communicate directly with hosts using the global address space but must go through a gateway. Private addresses have no global meaning, routing information is not stored by DNSs and most ISPs reject privately addressed packets. Make sure that your router is set up to forward these packets onto the Internet.

privileged port
A port (page 1165) with a number less than 1024. On Linux and other UNIX-like systems, only a process running with root can bind to a privileged port. Any user on Windows 98 and earlier Windows systems can bind to any port. Also reserved port.

procedure
A sequence of instructions for performing a particular task. Most programming languages, including machine languages, enable a programmer to define procedures that allow the procedure code to be called from multiple places. Also subroutine login instead.

process
The execution of a command by Linux. See “Processes” on page 328.

profile file
A startup file in a user's home directory where the Bourne or Z executes when you log in. The TC Shell executes login. You can use the profile file to run commands, set variables, and define functions.

program
A sequence of executable instructions contained in a file. Linux utilities, applications, and shell scripts are all. Whenever you run a command that is not built into a shell, you are executing a program.

PROM
Programmable read-only memory. A kind of nonvolatile storage. ROM (page 1169) that can be written using a PROM programmer.

prompt
A cue from a program, usually displayed on the screen, indicating that it is waiting for input. The prompt displays, a set of interactive features, such as mail. By default the Bourne and Z Shell use a dollar sign ($) as a prompt, and the TC Shell uses a percent sign (%).

protocol
A set of formal rules describing how to transmit data, especially across a network. Low-level protocols define the electrical and physical standards, but by byte ordering, and transmission, error detection, and correction of the bit stream. High-level protocols deal with data formatting, including message syntax, terminal-computer dialog, character sets, and sequencing of messages.

proxy
A service that is authorized to act for a system without being part of that system. See also proxy gateway and proxy server.

GLOSSARY 1167

proxy gateway
A computer that separates clients (such as browsers) from the Internet, acting as a trusted agent that passes requests for data to a remote server. The proxy gateway returns data to the client. A proxy gateway should be transparent to the user.

A proxy gateway often runs inside a firewall (page 148) and hides the IP addresses of local computers from Internet users outside.

You can configure browsers, such as Mozilla/Firefox, to use a different proxy gateway for each URL access method including FTP, SNMP, HTTPS, and HTTP.

proxy server
A proxy gateway that usually uses a cache (page 1139) that holds frequently used pages so that the next request is available locally (and more quickly). The terms proxy server and gateway are frequently used.

Python
A simple, high-level, interpreted, object-oriented, interactive language that bridges the gap between C and shell programming. For rapid prototyping or as an extension language for C applications, Python supports packages, modules, classes, user-defined extensions, a good C interface, and dynamic loading of C modules. It has no arbitrary restrictions. For more information, see python.org.

quote
When you quote a character, you can use any special meaning that it has in the current context. You can quote a character by preceding it with a backslash. When you are interacting with the shell, you can also quote a character by surrounding it with single quotation marks. For example, the command echo \* displays *. The command echo displays a list of the files in the working directory. ambiguous file reference (page 1134), metacharacter (page 1159), regular character (page 1168), regular expression (page 1168), and special character (page 1173). See also escape on 1147.
