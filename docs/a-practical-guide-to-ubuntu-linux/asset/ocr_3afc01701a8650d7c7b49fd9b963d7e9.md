# SYMBOLIC LINKS

In addition to hard links, Linux supports symbolic links, also called soft links or symlinks. A hard link is a pointer to a file (the directory entry points to the inode), whereas a symbolic link is an indirect pointer to a file (the directory entry contains the pathname of the pointed-to-file—pointer to the hard link to the file).

Advantages Symbolic links were developed because of the limitations inherent in hard links. You cannot create a hard link to a directory, but you can create a symbolic link to a directory.

In many cases the Linux file hierarchy encompasses several systems. Because each filesystem separates control information (that is, separate inode tables or filesystems) for the files it holds, it is not possible to create hard links between different systems. A symbolic link can point to any file, regardless of where it is located in the file structure, but a hard link to a file must be in the same filesystem as the hard link(s) to the file. When you create links among files in your home directory, you will not notice this notification.

A major advantage of a symbolic link is that it can point to a nonexistent file. This ability is useful if you need to link to a file that is periodically removed and recreated. A hard link keeps to a “removed” file, which the links keep even after a new file is created. In contrast, a symbolic link points to the newly created file and does not interfere when you delete the file. For example, a symbolic link could point to a file that gets checked in or out a source control system, a .o file that is re- by the C compiler each time you make, or a log file that is repeatedly appended.

Although they are more general than hard links, symbolic links have some disadvantages. Whereas all hard links to a file have equal status, symbolic links do not have the same status as hard links. When a file has multiple hard, it is analogous to a person having full legal names, as many married women do. In contrast, symbolic links are analogous to nicknames. Anyone can have one or more nicknames, but these nicknames have a lesser status than legal names. The following sections describe some of the peculiarities of symbolic links.
