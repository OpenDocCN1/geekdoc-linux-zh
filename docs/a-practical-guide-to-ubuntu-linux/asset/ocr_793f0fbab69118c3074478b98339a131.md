The next example uses a statement to display a prompt on standard output and uses the statement $entry = <> to read a line from standard input and assign the line to the variable $entry. Reading from standard input, working with other files, and use of the magic file handle (<>) for reading files specified on the line are covered on page 1066.

Perl uses different operators to compare numbers from those to compare strings. Table 28-2 lists numeric and string comparison operators. In the following example, the expression in the if statement uses the == numeric operator to compare the value the user entered and the number 28. This operator performs a numeric comparison, so the user can enter 28, 28.0, or 00028 and in all cases the result of the comparison will be true. Also, the comparison is numeric, Perl ignores the whitespace and the NEWLINE following the user's entry. The -w option allows Perl to issue a warning if the user enters a nonnumeric value and the program uses in an arithmetic expression; without this Perl silently evaluates the expression as false.

```
$ if2.pl
!/usr/bin/perl -w
print "Enter 28: <> ";
if ($entry == 28) { # use == for a numeric comparison
    print "Thank you for entering: 28.\n";
}
```

```
$ ./if2.pl
Enter 28: 28.0
Thank you for entering 28.
End.
```
