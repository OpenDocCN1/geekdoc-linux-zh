## 始终对参数进行测试

> 为了保持书中示例的简短并专注于特定概念，验证参数的代码通常会被省略或缩写。在他人将使用的 shell 程序中，对参数进行测试是一个良好的习惯。在脚本中使用 so 可以使它们更容易运行和调试。

`[]` 是 test 的同义词。接下来的示例——chkargs 的另一个版本——以更符合 Linux shell 脚本传统的测试方式检查参数。此示例使用了 test 的方括号 (`[]`) 同义词。与其在脚本中使用 test 单词，不如用方括号包围要测试的参数。括号周围必须有空格（空格或制表符）。

```bash
$ cat charkargs2
if [ $# -eq 0 ];
then
    echo "Usage: charkargs2 argument..." 1>&2
    exit 1
fi
echo "Program running."
exit 0
$ ./charkargs2
Usage: charkargs2 argument...
$ ./charkargs2 abc
Program running.
```

用法消息 charkargs2 显示的错误信息是用法消息，并使用 1>&2 将其输出重定向到标准错误（第 297 页）。在发布用法消息后，charkargs2 以退出状态 1 退出，表示发生了错误。脚本末尾的 exit 0 命令导致 charkargs2 在程序无错误运行完毕后以 0 状态退出。如果你省略该代码，Bourne Again Shell (bash) 会返回 0 状态。

用法消息通常用于指定脚本所接受的参数的类型和数量。许多 Linux 工具都提供与 charkargs2 相似的用法消息。如果你用错误的数量或类型的参数调用工具或其他程序，它通常会显示用法消息。以下是当你不带任何参数调用 cp 时，cp 显示的的用法消息：

```bash
$ cp
cp: missing file operand
Try 'cp --help' for more information.
```

## if...then...else

else 语句的引入将 if 结构转变为图 27-2 所示的双分支结构。if...then...else 控制结构具有以下语法：

```bash
if test-command
then
    commands
else
    commands
```

由于分号 (;) 像换行符一样结束命令，你可以将 then 与与 if 放在同一行，只需在它前面加一个分号。（因为 if 和 then 是独立的内置命令，它们之间需要一个命令分隔符；分号和换行符效果相同[第 304 页]）。有些人出于审美考虑偏于这种表示法；另一些人喜欢它是因为节省空间。

```bash
if test-command; then
    commands
else
    commands
```

## if...then...elif

if...then...elif 控制结构（图 27-3）具有以下语法：

```bash
if test-command
then
    commands
elif test-command
then
    commands
else
    commands
```

if...then...elif 结构允许测试两个两个条件。如果第一个 *test-command* 为真，则执行第一个 *then* 之后的命令。如果为假，shell 将评估 *elif* test-command。如果它为真，则执行 *elif then* 之后的命令。如果所有测试的条件都为假，则执行 *else* 块。

下面的示例展示了一个 if...then...elif 结构：

```bash
$ cat example
if [ $1 -eq 0 ]; then
    echo "Number is zero"
elif [ $1 -gt 0 ]; then
    echo "Number is positive"
elif [ $1 -lt 0 ]; then
    echo "Number is negative"
else
    echo "This should not happen"
fi
```

## Inks 脚本

以下脚本演示了 if...then 和 if...then...elif 控制结构。该脚本查找其第一个参数（文件名）的硬链接。如果你在第二个参数中提供目录名称，Inks 将在以该目录为根的目录层次中搜索链接。如果你没有指定目录，Inks 将搜索工作目录及其子目录。此脚本不定位符号链接。

```bash
$ cat Inks
#!/bin/bash
# $ - links to a file
# Usage: Inks file [directory]

if [ $# -eq 0 -gt 2 ]; then
	echo "Usage: Inks file [directory]" 1>&2
	exit 1
fiif [ -d "$1" ]; then
	echo "First argument cannot be a directory." 1>&2
	echo "Usage: Inks file [directory]" 1>&2
	exit 1
else
	file="$1"
fi
# ... (script继续)
```
