## Control Structures

Control flow statements alter the order of execution of statements within a Perl program. Starting on page 954, Chapter 27 discusses bash structures in detail and includes flow diagrams. Perl control structures perform the same functions as bash counterparts, although the two languages use different syntaxes. The description of each control structure in this section references the discussion of the same control structure under bash.

In this section, the bold italic in the description are the items you use to cause the syntax to have the desired effect, the non-bold italic words are the keywords Perl uses to identify the control structure, and [...] represents a block (page 1045) of statements. Many of these structures use an expression, denoted as expr, to control their execution. if/unless (next) for an example and explanation of a syntax description.

## if/unless

The if and unless control structures are compound statements that have the following syntax:

- if (expr) [...]
- unless (expr) [...]

These structures differ only in the sense of the test they perform. The if structure executes the block of statements if expr evaluates to true; unless executes the block of statements unless expr evaluates to true (i.e., if expr is false).

The if appears in non-bold type because it is a keyword; The expr is an expression; Perl evaluates and executes the block (page 1045) of statements represented by [...] if the expression evaluates as required by the control structure.

The expr in the following example, -r memo, uses the -r file operator to determine if a file named memo exists in the directory and if the file is readable. Although this operator only tests whether you have read permission for the file, the file must exist for you to have read permission; thus it implicitly tests that the file is present (Perl uses the same file test operators as bash; Table 27-1 on page 957). If this expression evaluates to true, Perl executes the block of statements (in this case statement) between the braces. If the expression evaluates to false, Perl skips the block of statements. In either case, Perl then exits and returns control to the shell.

```perl
$ if1.pl
!/usr/bin/perl -w
if (-r "memo") {
    say "The file \"memo\" exists and is readable.";
}
```

```perl
$ ./if1.pl
The file "memo" exists and is readable.
```

Following is the same program written using the postfix syntax. Which syntax you use depends on which part of the statement is more important to reading the code.

```perl
$ if1.pl
!/usr/bin/perl -w
say "The file \"memo\" exists and is readable." (-r "memo");
```

The next example uses a statement to display a prompt on standard output and uses the statement $entry = <> to read a line from standard input and assign the line to the variable $entry. Reading from standard input, working with other files, and use of the magic file handle (<>) for reading files specified on the line are covered on page 1066.

Perl uses different operators to compare numbers from those to compare strings. Table 28-2 lists numeric and string comparison operators. In the following example, the expression in the if statement uses the == numeric operator to compare the value the user entered and the number 28. This operator performs a numeric comparison, so the user can enter 28, 28.0, or 00028 and in all cases the result of the comparison will be true. Also, the comparison is numeric, Perl ignores the whitespace and the NEWLINE following the user's entry. The -w option allows Perl to issue a warning if the user enters a nonnumeric value and the program uses it in an arithmetic expression; without this Perl silently evaluates the expression as false.

```perl
$ if2.pl
!/usr/bin/perl -w
print "Enter 28: <> ";
if ($entry == 28) { # use == for a numeric comparison
    print "Thank you for entering: 28.\n";
}
```

```perl
$ ./if2.pl
Enter 28: 28
Thank you for entering: 28.
```

## Table 28-2 Comparison operators

| Numeric operators | String operators | Value returned based on the relationship between the values |
| :--- | :--- | :--- |
| == | eq | True if equal |
| != | ne | True not equal |
| < | lt | True if less |
| > | gt | True if greater |
| <= | le | True if less or equal |
| >= | ge | True if greater or equal |
| <> | cmp | 0 if equal, 1 if greater, -1 if less |

The next program is similar to the preceding one except it tests for equality between strings. The chop function (page 67) removes the newline from the user's entry—without which the strings in the comparison would never match. The eq operator compares strings. In example the result of the string comparison is true when the user enters the string five. Leading or trailing whitespace will yield a result of false, as the string contains it.

```perl
$ cat if2.pl
!/usr/bin/perl -w
print "Enter the word 'five': ";
$entry = <>
chomp($entry);
if ($entry eq "five") { # eq for a string comparison
    print "Thank you for entering 'five'.\n";
}
print "\n";
```

```perl
$ ./if2.pl
Enter the word 'five': five
Thank you for entering 'five'.
```

if...else control structure is a compound statement that is similar to the bash if...then...else structure (page 95). It implements a two-way branch using the following syntax: the next program prompts the user for two different numbers and stores those numbers in $num1 and $num2. If the user enters the same number twice, the if structure executes die, which sends its argument to standard error and aborts execution. If the user enters different numbers, the if...else structure reports which number is larger. Because expr performs numeric comparison, the program accepts numbers that include decimal points.

```perl
$ cat ifelse.pl
!/usr/bin/perl -w
print "Enter a number: ";
$num1 = <>
print "Enter another, different number: ";
$num2 = <>
```

```perl
if ($num1 == $num2) {
    die("Please enter two different numbers.\n");
}
if ($num1 > $num2) {
    print "The first number is greater than the second number.\n";
} else {
    print "The first number is less than the second number.\n";
}
```

```perl
$ ./ifelse.pl
Enter a number: 8
Enter another, different number: 8
Please enter two different numbers.
```

```perl
$ ./ifelse.pl
Enter a number: 5.5
Enter another, different number: 5
The first number is greater than the second number.
```

## if...elsif...else

Similar to the bash if...then...elif control structure (page 961), the Perl if...elsif...else structure is a compound statement that implements a nested set of if...else structures using the following syntax:

```perl
if (expr) {...} elsif (...) {...} else {...}
```

The next program implements the functionality of the preceding if...else program using an if...elsif...else structure. A print statement replaces the die statement because the last statement in the program displays the error message; the program terminates after executing such statement. You can use the STDERR handle (page 1066) to cause Perl to send this message to standard error instead of standard output.

```perl
$ cat ifelsif.pl
!/usr/bin/perl -w
print "Enter a number: ";
$num1 = <>
print "Enter another, different number: ";
$num2 = <>
```

```perl
if ($num1 > $num2) {
    print "The first number is greater than the second number.\n";
}
elif ($num1 < $num2) {
    print "The first number is less than the second number.\n";
} else {
    print "Please enter two different numbers.\n";
}
```

## foreach/for

The Perl foreach and for keywords are synonyms; you can replace one with the other in any context. These structures are compound statements that have two syntaxes. Some programmers use one syntax with foreach and the other syntax with the for, although there is no need to do so. This book uses foreach with both syntaxes.

### foreach: SYNTAX 1

The first syntax for the foreach structure is similar to the shell's for...in structure (page 967):

```perl
foreach[var] (list) [...]
```

where list is a list of expressions or variables. Perl executes the block of statements for each item in list, sequentially assigning var the value of one item in list on each iteration, starting with the first item. If you do not specify var, Perl assigns values to the $_ variable (page 1065).

The following program demonstrates a simple foreach structure. On the first pass through the loop, Perl assigns the string $_ to the variable $item and the say statement displays the value of this variable followed by a NEWLINE. On the second and third passes through the loop, $item is assigned the value of Larry and Curly. When there are no items left in the loop, Perl continues with the statement following the foreach structure. In this case, the program terminates. See feature 'say' on page 1047 if this program complains about say not available.

```perl
$ cat foreach.pl
foreach ("Mo", "Larry", "Curly") {
    say "$_ says hello.";
}
```

```perl
$ perl foreach.pl
Mo says hello.
Larry says hello.
Curly says hello.
```

Using $_ (page 1065), you can write this program as follows:

```perl
$ cat foreach.pl
foreach ("Mo", "Larry", "Curly") {
    say "$_ says hello.";
}
```
