opendir: The next example introduces opendir and readdir. The opendir function opens a directory in a manner similar to the way open opens an ordinary file. It takes two arguments: the name of the directory and the name of the directory to open. The readdir function reads the name of a file from an directory.

In the example, opendir opens the working directory (specified by .) using the $dir lexical. If opendir fails, Perl executes the statement following the or part: die sends an error message to standard error and terminates the program. With the directory opened, while loops through the files in the directory, assigning the filename that readdir returns to the lexical variable $entry. If an statement executes print only for those files that are directories (-d). The print function displays the name of the directory unless the directory is named .. When readdir has read all files in the working directory, it returns false and passes control to the statement following the while block. The closed function opens the directory and print displays a NEWLINE following the list of directories displayed.

```
$ cat dirsa2.pl
!/usr/bin/perl
print "The working directory contains these directories:\n"

```

```
opendir my $dir, '.' or die "Could not open directory: $!\n"
while (my $entry = readdir $dir) {
    print $entry, unless $entry eq '.' || $entry eq '..';
}
closedir $dir;
print "\n";
```
