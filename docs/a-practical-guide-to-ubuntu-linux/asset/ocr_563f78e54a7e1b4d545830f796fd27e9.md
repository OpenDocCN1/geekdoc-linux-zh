# asynchronous

An event that does not occur regularly or synchronously with another event. Linux system signals are asynchronous; they can occur at any time because they can be initiated by any nonregular events.

# attachment

A file that is attached to, but is not part of, a piece of email. Attachments are frequently opened by programs (including your Internet browser) that are called by your mail program so may not be aware that they are not an integral part of an email message.

# authentication

The verification of the identity of a person or process. In a communication system, authentication verifies that a message comes from its stated method. Methods of authentication on a Linux system include `/etc/passwd` and `/etc/shadow files, LDAP, Kerberos 5, and SMB authentication.

# automatic mounting

A way of demand mounting directories from remote hosts without having them configured into `/etc/fstab`. Also called automounting.

# avoided

An object, such as a panel, that should not normally be covered by another object, such as a window.

# back door

A security hole deliberately left in place by the designers or maintainers of a system. The motivation for creating holes is not always sinister; some operating systems, for example, out of the box with privileged accounts intended for field service technicians or the vendor's maintenance programs.

Ken Thompson's 1983 Turing Award lecture to the ACM revealed the existence, in early UNIX versions, of a back door that may be the deadliest security hack of all time. The C compiler contained code that would recognize when the login command was being compiled and would insert some code recognizing a password chosen by Thompson, giving him entry to the system whether or not an account had been created for him.

Normally such a back door could be removed by removing it from the source code for the compiler and recompiling the compiler. To recompile the compiler, you have to use the compiler, so Thompson arranged that the compiler would recognize when it was compiling a version of itself. It would insert into the recomiled compiler the code to insert into the recomiled login to allow Thompson entry again the next time. After doing this, he was then able to recompile the compiler from the original sources; the hack perpetuated itself, leaving the back door in place and active but with no trace in the sources.

Sometimes called a wormhole. Also trap door.

# background process

A process that is not running in the foreground. Also called a detached process, background process is initiated by a command line that ends with an ampersand (&). You do not have to wait for a background process to run to completion before giving additional commands. If you have job control, you can move background processes to the foreground, and vice versa.
