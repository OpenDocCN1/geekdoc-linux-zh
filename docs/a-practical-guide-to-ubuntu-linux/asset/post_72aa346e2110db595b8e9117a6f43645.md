## THE OBJECT PROPERTIES WINDOW

The Object Properties window displays information about a file, including its owner, permissions, size, location, MIME type, ways to work with it, and more. This window is titled *filename*, where filename is the name of the file. To display this window, right-click an object and select Properties. The Properties window has several tabs, which are discussed next.

**Basic** The Basic tab displays information about the file, including its MIME type, and allows you to set the icon. If the icon is not listed in the box, an easy way to change it is to open the file at `/usr/share/icons` and drag and drop it into the box.
