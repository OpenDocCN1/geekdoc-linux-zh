# DELETING A PARTITION

Before you delete a partition, make sure it does not contain any data you need. To use gparted to highlight the partition you want to delete, click the circle with a line through it, and then click the green check mark on the toolbar.

# The GNOME DISK UTILITY

The Palimpsest disk utility can create, remove, and modify partitions and filesystems on many types of media, including internal and external hard disks, CD/DVDs, and USB flash drives. It can encrypt partitions and change passwords on already encrypted partitions.

Open the Palimpsest Disk Utility window by selecting Main menu: System→Administration→Disk Utility (just above GParted in Figure 3-10 on page 64). To display information about a hard disk, a hard disk under Storage Devices/Peripheral Devices on the left side of the window.

With a hard disk, the palimpsest Disk utility is divided into three sections (Figure 3-13): Storage Devices holds a list of CD/DVD drives, hard disks, and other devices; Drive section holds information about the hard disk that is highlighted in the list of storage devices; and Volumes displays information about the partition that is highlighted in the graphical representation of the hard drive.

When you select a hard disk in the Storage Devices sections, palimpsest displays information about that disk in the Drive section of the window. Click one of the partitions in the graphical representation of the hard disk and palimpsest displays information about that partition in the Volumes section.

From this window you can view, create, and delete partitions. Although you can create partitions using palimpsest, you cannot specify the mount point (page 35) for it—this step must wait until you are installing Ubuntu and using the ubiqu partition editor. # DISPLAYING THE CONTENTS OF A FILESYSTEM

To display the contents of a filesystem, select the partition holding the filesystem as described above and click Mount Volume in the Volumes section of the Disk Utility window. Figure 3-13 shows Unmount Volume because the partition is already mounted. When palimpsest displays the highlighted filesystem, the mounted filesystem appears as a directory (folder) on the desktop. When you click the mount point (the link following Mount Point: mounted at) in the Volumes section or double-click the directory icon on the desktop, Nautilus displays the files in a file browser (page 107). When you have finished examining the contents, click Unmount Volume to unmount the filesystem.

# WRITING A PARTITION TABLE

A new disk does not have a partition table (page 33) and looks similar to the disk highlighted in Figure 3-14. In the Drive section of Disk Utility window, Following Partitioning label, the graphical representation of the disk is marked Unknown, and Usage is blank. If the disk you are working with already has a partition table, skip to the next section.

To partition a hard disk, click Format in the Drive section of Disk Utility window: palimpsest opens a window holding a drop-down list Scheme. Select a scheme. In most cases you will want to accept the default scheme of Master Boot Record. Click Format. After checking that you really want to format the drive, palimpsest creates the partition table. Following Partitioning label, the graphical representation of the disk is marked Free (free space), and Unallocated Space follows Usage label.

If you want to create a single filesystem that occupies the entire disk, instead of following the instructions in the preceding paragraph, click Volume in the Volumes section of Disk Utility window: palimpsest opens a whole-disk volume window. To create a filesystem, follow the instructions for Create window in the next section.

# CREATING A PARTITION AND A FILESSTEM

Once you have created a partition table, you will be able to create a partition that holds a filesystem in the free space. When you click Create, palimpsest opens Create window (Figure 3-15).

![](img/45ff4cd21497435daa35084a84b95d07_119_0.png)

Figure 3-15 The palimpsest Create window

In this window, use the slider labeled Size, or the adjacent spin box, to specify the size of the new partition. Next specify a filesystem type; ext4 filesystems are the most common. You can optionally enter a disk label in the text box. This name is the mount point for the disk. Typically you will want to own the filesystem, so allow the text to remain in the check box Take ownership of system. If you want the filesystem to be encrypted, put a tick in the check box Encrypt underlying device. Click Create. After checking, palimpsest creates the filesystem. Now the graphical representation of the disk is divided to represent the division of the hard disk and Usage corresponds to the highlighted section of the graphical representation (Filesystem or Unallocated Space). If you do not use all the free space, you can create additional partitions and filesystems in the same manner.

# Deleting a Partition

Before deleting a partition, make sure it does not contain any data you need. Use the palimpsest utility to delete a partition, highlight the partition you want to delete in the graphical representation of the hard disk and click Delete Partition. After checking, palimpsest deletes the partition.

# ubiquity: Setting UP PARTITIONS

While you are installing Ubuntu, ubiquity offers two ways to partition a disk: guided and manual. Guided partitioning sets up partitions—one for swap space (page 37) and one for /root, where the entire Ubuntu file systems mounted; page 37), The amount of space occupied by root depends on which guided option you select. Manual partitioning enables you to set up partitions of any type and size; you can also specify the mount point for each partition.
