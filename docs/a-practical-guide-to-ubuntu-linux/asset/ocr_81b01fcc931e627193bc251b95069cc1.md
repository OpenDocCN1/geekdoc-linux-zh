Other classes of networks exist. When you run netstat -nr on a Linux system, you can see whether the machine is a member of a multicast network. A 224.0.0.0 in the Destination column [Table-2] that netstat displays indicates a class D, multicast address (Table 10-2). A multicast is a broadcast, but only hosts subscribed to the multicast group receive the message. To use Web terminology, a broadcast is like a "push." A host pushes a broadcast to the network, and every host on the network must check each packet to see whether it contains relevant data. A multicast is like a "pull." A host will see a multicast only if it registers as subscribed to the multicast group or service and pulls the appropriate packets from the network.
