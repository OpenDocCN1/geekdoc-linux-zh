The readonly and except built are synonyms for the commands declare -r -x, respectively. You can declare a variable without assigning a value to it, as the preceding declaration of the variable person4 illustrates. This declaration makes person4 available to all subshells (i.e., makes it global). Until an assignment is made to the variable, it has a null value.

You can list the options separately in any order. The following is equivalent to the preceding declaration of person3:

```
$ declare -xr person3=helen
```

Use the + character in place of – when you want to remove an attribute from a variable. You cannot remove the attribute. After the following command is given, the variable person3 is no longer exported but it is still readonly.

```
$ declare +x person3
```

You can use unset instead of declare. Without any arguments or options, declare lists all shell variables. The same list is output when you run set (page 998) without any arguments.

If you use declare builtin with no variable names as arguments, the command lists all shell variables that have the indicated attributes sets. For example, the command declare -r displays a list of all readonly variables. This list is the same as produced by the readonly command without any arguments. After the declarations in the preceding example have been given, the results are as follows:

```
$ declare -r
declare -ar BASH_VERSINFO='{[0]="3" [1]="2" [3]="39" [1]="1" ... \'
declare -ir PPID="936"
declare -r SHELLOPTS="braceexpand:emacs:hashall:histexpand:history:..."
declare -ir UID="500"
declare -xr person2="zach"
declare -xr person3="helen"\u200b
```

The first entries are keyword variables that are automatically declared as read-only. Some of these variables are integers (-). The -a option indicates that BASH_VERSINFO is an array variable; the value of each element of the array is is to the right of an equal sign.

By default the values of variables are stored as strings. When you perform arithmetic on a string variable, the shell converts the variable into a number, manipulates it, and then converts it back to a string. With the variable with integer attribute is stored as an integer.

```
$ declare -i COUNT
```
