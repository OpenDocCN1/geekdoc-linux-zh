## Shell features
There are several ways to customize the shell's behavior. You can use options on the command line when you call bash. You can use the bash `set` and `shopt` builtins to turn features on and off.

Command-line When it processes a command line, the Bourne Shell may replace some words with expanded text. Most types of command-line expansion are invoked by the appearance of a special character within a word (for example, a leading `$` denotes a variable). Table 9-6 on page 326 lists these special characters. The expansions take place in a specific order. Following the history and all expansions, the common expansions are parameter and variable expansion, substitution, and pathname expansion. Surrounding a word with double quotation marks suppresses all types of expansion except parameter and variable expansion. Single quotation marks suppress all types of expansion, as does quoting (escaping) a special character by preceding it with a backslash.

The following is a summary of networking concepts discussed in the chapter:

- **Types of Networks**: An intranet is a network that connects resources at a school, community, or organization but unlike the Internet, typically restricts access to internal users.
- **How They Work**: An intranet is very similar to a LAN (local area network) but is built on Internet technology. An intranet can provide database, email, and Web page access to a limited group of people, regardless of their geographic location.
- **Network Protocols**: The ability of an intranet to connect dissimilar machines is one of its strengths. Think of all the machines you can find on the Internet: systems, PCs running different versions of Windows, machines running UNIX and Linux, and so on. Each of these machines can communicate via IP (page 380), a common protocol. So is it with an intranet: Dissimilar machines can talk to one another.
- **Network Utilities**: Another difference between the Internet and an intranet is that the Internet only uses one protocol: IP. In an intranet, another can be set up to use a number of protocols, such as IP, IPX, AppleTalk, DECNet, XNS, or other developed developed by vendors. Although these protocols cannot be transmitted directly over the Internet, one can set up special gateway boxes at routers that tunnel or encapsulate these protocols into IP packets and then use the Internet to pass them.
