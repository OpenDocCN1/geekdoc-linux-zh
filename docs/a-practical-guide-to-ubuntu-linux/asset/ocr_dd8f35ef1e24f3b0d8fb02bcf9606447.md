# UPGRADING TO A NEW RELEASE

Upgrading a system is the process of installing a new release of Ubuntu over an older one. All user and configuration files are preserved and all software is upgraded to the most recent version consistent with the new release of Ubuntu. Ubuntu advises against systems that have packages installed from repositories (page 522) to not control. These packages may corrupt the software package database, causing the upgrade to fail. For release notes that detail features that will not effect with any upgrade, see www.ubuntu.com/getubuntu/releasesnote

# Use a standard upgrade procedure

Do not use procedures for upgrading a new release of Ubuntu other than the ones specified in this section or at www.ubuntu.com/getubuntu/upgrading. Specifically, do not use apt-get-upgrade, aptitude full-upgrade, or any Debian tools.

# Upgrading from an LTS to a non-LTS release

When you start the Update Manager from the Main menu, it does not offer you the option of upgrading from an LTS release to a non-LTS release. To upgrade from an LTS release to a non-LTS release, you must enter update-manager--c on a command line (from a terminal emulator or Run window (ALT+F2)) to open the Update Manager window.

# Watch for Pop-up windows

During the installation phase of an upgrade, some packages open windows that ask about how you want to handle the upgrade of a package. These windows can be hidden by other windows on the software. If the upgrade stops for no apparent reason, drag windows around to see if a window with a question is hidden below another window. When you respond to the question, the upgrade will continue.

Before you upgrade a system, it is a good idea to back up all user files on the system. Also make sure the drop-down list labeled Show new distributions in the Updates tab of the Software Sources window (page 132) displays the type of release you want to upgrade to.
