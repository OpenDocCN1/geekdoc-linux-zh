Ubuntu runs the GNOME desktop manager (Figure 1-3; gnome.org) by default, but it can also run KDE (kde.kde.org) and a number of other desktop managers.

A window manager is a program that runs the desktop manager and allows you to open and close windows, run programs, and set up a mouse effects depending on how and where you click. The window manager also gives the screen personality. Whereas Microsoft Windows allows you to change the color of key elements in a window manager under X allows you to customize the overall look and feel of the screen: You can change the way a window looks and works (by giving different borders, buttons, and scrollbars), set up virtual desktops, create menus, and more.

Several window managers run under X and Linux. Ubuntu Linux provides both Metacity (the default under GNOME) and kwin (the default under KDE). Other window managers, such as Sawfish and WindowMaker, are also available. Chapters 4 and 8 present information on GUIs.

# (INTER)NETWORKING UTILITIES

Linux network support includes many utilities that enable you to access systems over a variety of networks. In addition to sending email you can access files on disks mounted on other computers as if they were located on the local system, manage your files available to other systems in a similar manner, copy files back and forth, run programs on remote systems while displaying the results on the local system, and perform many other operations across local area networks (LANs) and wide area networks (WANs), including the Internet.
