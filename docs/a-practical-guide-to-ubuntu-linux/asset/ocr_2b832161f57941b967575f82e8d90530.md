In a similar manner, a program's input, which normally comes from a keyboard, can be redirected so that it comes from a disk file instead. Input and output can device independent; that is, they can be redirected to or from any appropriate device.

As an example, the cat utility normally displays the contents of the file on the screen. When you run a cat command, you can easily erase its output to go to a disk file instead of the screen.

# SHELL FUNCTIONS

One of the most important features of the shell is that users can use it as a programming language. Because the shell is an interpreter, it does not compile programs for it but rather interprets programs each time they are loaded from the disk. Loading interpreting programs is time-consuming.

Many shells, including the Bourne Again Shell, shell functions that the shell holds in memory so it does not have to read them from the disk each time you execute. The shell also functions in an internal format so it does not have to spend as much time interpreting them.

# JOB CONTROL

job control is a shell feature that allows users to work on several jobs at once, switching back and forth them as desired. When you start a job, it frequently runs in the foreground so it is connected to the terminal. Using job control, you can move the job you are working with to the background and continue it while working on or observing another job. If a background job needs your attention, you can move it to the foreground so it is once again attached to the terminal. (The concept of job control originated with BSD UNIX, where it appeared in the C Shell.)

# A LARGE COLLECTION OF USEFUL UTILITIES

Linux includes a family of several hundred utility programs, often referred to as commands. These utility perform functions that are universally required by users. The sort utility, puts lists (or groups of lists) in alphabetical or numerical order and can be used to sort lists by part number, last name, ZIP code, telephone number, age, size, and cost. The sort is an important programming tool that is part of the standard Linux system. Other utilities allow users to create, display, print, copy, search, and delete files as well as format, and typeset text. The man (for manual) and info utilities provide online documentation for Linux.

# INTERPROCESS COMMUNICATION

Linux enables users to establish both pipes and filters on the command line. A pipe sends the output of one program to another program as input. A filter is a special kind of pipe that processes a stream of input data to yield a stream of output data.
