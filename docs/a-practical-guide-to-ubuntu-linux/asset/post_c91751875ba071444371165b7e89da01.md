## The GnuPG system includes the gpg program

GPG is frequently referred to as gpg, gpg is actually the main program for the GnuPG system.

Gnu offers a good introduction to privacy, The GNU Privacy Handbook, which is available in several languages and listed at www.gnu.org (click Documentation-HOWTOS-Gnu Privacy Guard (GnuPG) Mini Howto, which steps through the setup and of gpg). And, of course, there is a gpg info page.

In addition to providing encryption, gpg is useful for authentication. For example, you can use it to verify that the person who signed a piece of file is the person who sent it.

## FILE SECURITY

From an end user's perspective, file security is one of the most critical areas of security. Some file security is built into Linux: chmod (page 216) gives you basic security control. ACLs (Access Control Lists) allow more fine-grained control of file access permissions. ACLs are part of Solaris, Windows NT/2000/XP, VAX/VMS, and mainframe operating systems. Ubuntu Linux supports ACLs (page 221). Even these tools are insufficient, however, when your account is compromised (for example, by someone watching your fingers on the keyboard as you type your password). To provide maximum file security, you must encrypt your files. Even someone who knows your password cannot read your files. (Of course, if someone knows your key, that person can decrypt files if she can get to them).

## EMAIL SECURITY

Email security overlaps file security, and as discussed later, network security. GnuPG is the tool most used for email security, although you could also use P. PEM (Privacy Enhanced Mail) is a standard rather than an algorithm and is used less frequently.

## MTAS (Mail Transfer Agents)

An increasingly commonplace MTA is STARTTLS (Start Transport Layer Security); www.sendmail.org/~ca/email/starttls.html). TLS itself usually refers to SSL (Secure Sockets Layer) and has become the de facto method for encrypting TCP/IP traffic on Internet. The sendmail and exim4 daemons can be built to support STARTTLS, and much documentation exists on how to do. STARTTLS enhancements are also available for Qmail (page 715) and Postfix (page 715) and other popular MTAs. It is important to recognize that this capability provides encryption between two mail servers not necessarily between your machine and the mail server. Also, the advantages of using TLS are negated if the email must pass through a relay that does not support TLS.

## MUAS (Mail User Agents)

Many popular mail user agents, such as mut, elm, Thunderbird, and emacs, include the ability to use PGP or GnuPG for encryption. Evolution, the default MUA has built-in GnuPG support. This approach has become the default way to exchange email securely.

## NETWORK SECURITY

Network security is a vital component for ensuring the security of computing site. However, with the right infrastructure, providing network security is difficult, but not impossible. For example, if you run a shared network such as Ethernet, and have in public locations that allow anyone to plug in to the network (page 164) you cannot have potential security. Another common security hole relates the use of telnet for logins. Because telnet sends and receives cleartext, also “listening in” on the line can easily capture usernames and passwords. Do not allow any unauthenticated PC on the network for the following reasons:

- Shared network topology: a network in which each packet may be seen by machines other than its destination.
- Shared means that 100 megabits per second bandwidth is shared by all. Do not make the mistake of assuming that you have security just because you have a switch. Switches are designed to allocate bandwidth, not to guarantee security.
- The term port has many meanings; here is a number assigned to a specific service. For example, port 21 is used by FTP, and port 23 is used by TELNET.
- LPD. Normally a data switch on a LAN automatically protects machines from snooping on the network. In high-load situations, switches have been known to behave unpredictably, directing packets to the wrong ports. Certain programs can overload the switch tables that hold information about which machine is on which port. When these are overloaded, the switch becomes a repeater and broadcasts all packets to all ports. The attacker on the same switch as you can potentially see the traffic system sends and receives.

## NETWORK SECURITY SOLUTIONS

One solution to shared-network problems is to encrypt messages between machines. IPSec (Internet Protocol Security) provides appropriate technology. IPsec is commonly used to establish a secure point-to-point network (VPN, port 80) that allows two hosts to communicate securely over an insecure channel. This protocol protects integrity, confidentiality, authenticity, and flexibility of implementation that supports multiple vendors. IPSec is an amalgamation of protocols (IPSec = AH + ESP + IPComp + IKE):

- Authentication Header (AH)—A cryptographically irreversible checksum for an entire packet. AH guarantees that the packet is authentic. 
- Encapsulating Security Payload (ESP)—Encrypts a packet to make the data unreadable.
- IP Payload Compression (IPComp)—Compresses a packet. Encryption can increase the size of a packet, and IPComp counters this increase.
- Internet Key Exchange (IKE)—Provides a way for the endpoints to negotiate a common key. For AH to work, both ends of the exchange must use the same key to prevent “man-in-the-middle” (see footnote 3 on page 1114) from spoofing the connection.

While IPSec is an optional part of IPv4, IPv6 (page 387) mandates its use. It may be some time before IPv6 is widely implemented, however.

## NETWORK SECURITY GUIDELINES

Some general guidelines for establishing and maintaining a secure system follow. This list is not complete but rather is meant as a guide.

- Fiberoptic cable is more secure than copper cable. Copper is subject to both active and passive eavesdropping. With access to copper cable, all a data thief needs to monitor your network traffic is a passive device for measuring magnetic fields. In contrast, it is much more difficult to tap fiberoptic cable without interrupting the signal. Sites requiring top security keep fiberoptic cable in pressurized conduits, where a change in pressure signals that the physical security of the cable has been breached.
- Avoid unused ports in public areas. If a malicious user can plug a laptop to the network without being detected, you are at risk of a serious security problem. Network drops that will remain unused for extended periods be disabled at the switch, preventing them from accepting or passing network traffic.
- Many network switches have provisions for binding a hardware address to a port for enhanced security. If someone unplugs one machine and plugs in another machine to capture traffic, chances are the second machine will have a different hardware address. When it detects a device with a different hardware address, the switch can disable the port. This solution is no guarantee, however, as some programs enable you to change or mask the hardware address of a network interface.

- Install a small kernel and run all the programs you security Linux systems contain a huge number of programs, although useful, significantly reduce the security of the host. Install the smallest operating system kernel that meets your needs. For Web and FTP servers, install the needed components and not install a graphical interface. Users may require additional packages.
