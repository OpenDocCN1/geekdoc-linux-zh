# apt-get source: DOWNLOADS SOURCE FILES

The apt-get source (dpkg package) command downloads and unpacks in the working directory source code from repositories specified with deb-src lines in sources.list (page 523). APT does not index and cache for source files as it is for binary files. With the --download-only option, this command does not unpack the source code. With the --compile option, it unpacks and compiles the source code. You do not have to run this with root privileges; it requires only write access to the working directory. Following is an example:

```
$ apt-get source adduser

dpkg-info: extracting adduser-3.112ubuntu
dpkg-info: unpacking adduser_3.112ubuntu.tar.gz
$ ls -ld adduser*
drwxr-xr-- 7 sam sam 4096 2010-01-27 00:54 adduser_3.112ubuntu
-rw-r--r-- 1 sam sam 1141 2010-01-27 03:04 adduser_3.112ubuntu.dsc
-rw-r--r-- 1 sam sam 299038 2010-01-27 03:04 adduser_3.112ubuntu.tar.gz
```

# dpkg: The DEBIAN PACKAGE MANAGEMENT SYSTEM

The Debian package (dpkg) management system database tracks which software packages are installed on a system, where each is installed, which version is installed, and which packages depends on.
The dpkg management system comprises many utilities. These utility install, upgrade, query, and verify software packages. The original and primary utility is dpkg Although you can use dpkg for most tasks using the dpkg management system, other tools can make your job easier. Some of the most commonly used of them are described here:

+   * apt-cache—Displays information about and manipulates the APT cache (page 530).
* apt-file—Similar to apt-cache except that it works with packages that have not been installed and packages that have not been downloaded, in addition to those that are installed on the local system (page 521).
* aptitude—Retrieves software packages and dpkg to install and remove them (page 519 and 526).
* apt-get—A textual interface to APT; similar to aptitude.
* dpkg—The primary dpkg management system utility (page 534).
* dselect—A pseudographical front-end for dpkg.
* Synaptic—A graphical interface to APT (page 133).
