# X WINDOW SYSTEM

History of X The X Window System (www.x.org) was created in 1984 at the Massachusetts Institute of Technology (MIT) by researchers working on a distributed computing project and a campuswide distributed environment, called Project Athena. This system was not the first windowing software to run on a UNIX system, but it was the first to become widely available and accepted. In 1985, MIT released X (version 9) to the public, without a license. Three years later, a group of vendors formed X Consortium to support the continued development of X, under the MIT. By 1998, X Consortium had become part of the Open Group. In 2001, the Open Group released X version 11, release 6.6 (X11R6.6).

The X Window System was inspired by the ideas and features found in earlier proprietary window systems but is written to be portable and flexible. X is designed to run on a workstation, typically attached to a LAN. If you can communicate with a remote computer over a network, running an X application on that computer and sending the results to a local display is straightforward.

Although the X protocol has remained stable for a long time, additions to it in form of extensions are quite common. One of the most interesting—albeit one that not yet made its way into production—is the Media Application Server, which aims to provide the same level of network transparency for sound and video as X does for window applications.

XFree86 and X.org Many distributions of Linux used the XFree86 X server, which inherited its license from the original MIT X server, through release 4.3. The stack The Linux GUI is built in layers (Figure 8-1). The bottom layer is the kernel, which provides the interfaces to the hardware. On top of the kernel is the X server, which is responsible for managing windows and drawing basic primitives such as lines and bitmaps. Rather than directly generating X commands, most programs use Xlib, the next layer, which is a standard library for interfacing with X server. In recent years, the popularity of X has grown outside the UNIX community and extended beyond the workstation class of computers it originally conceived. Today X is available for Macintosh computers as well as for PCs running Windows.
