# DETAILS

Chapter 1 presents a brief history of Linux and explains some of the features that make it a cutting-edge operating system. The “Conventions Used in This Book” (page 19) details the typefaces and terminology used in this book.

Part I, “Installing Ubuntu Linux,” discusses how to install Ubuntu Linux. Chapter 2 presents an overview of the process of installing Ubuntu Linux, including hardware requirements, downloading and burning a CD or DVD, and planning the layout of the hard disk. Chapter 3 is a step-by-guide to installing Ubuntu Linux from a CD or DVD, using the graphical or textual interface.

Part II, “Getting Started with Ubuntu Linux,” familiarizes you with Ubuntu Linux, logging in, the GUI, utilities, the filesystem, and the shell. Chapter 4 introduces desktop features, including the Top and Bottom panels and the Main menu; explains how to use the Nautilus File Browser to manage files, run programs, and connect to FTP and HTTP servers; covers finding documentation, dealing with problems, using the window manager; and provides some suggestions on how to find documentation, including manuals, tutorials, software notes, and HOWTOs. Chapter 5 introduces the command-line interface, and provides a tutorial on the vim editor. Chapter 6 discusses the Linux hierarchical filesystem, covering files, filenames, pathnames with directories, access permissions, and symbolic links. Chapter 7 introduces the Bourne Again Shell (bash) and discusses command-line arguments and options, redirecting input to output from commands, running programs in the back-ground, and using the shell to generate and expand filenames.

# Experienced users may want to skip Part II

If you have a UNIX or Linux system before, you may want to skip or some or all of the chapters in Part II. Two sections that all readers should take a look at are: “Conventions Used in This Book” (page 19), which explains the typographic and layout conventions used in this book, and “Where to Find Documentation” (page 136), which points out both local and remote sources of Linux and Ubuntu documentation.

Part III, “Digging into Ubuntu Linux,” goes into more detail about working with the system. Chapter 8 discusses the GUI (desktop) and includes a section on how to run a program on a remote system and how the display appear locally. The section on GNOME describes several utilities and goes into more depth about the Nautilus File Browser. Chapter 9 extends the bash coverage from Chapter 7, explaining how to redirect error output, overwriting files, and work with job control, processes, startup files, import builtin commands, parameters, shell variables, and aliases. Chapter 10 explains network security, and discusses types of networks, subnets, protocols, addresses, hostnames, and various network utilities. The section on distributed computing describes the client/server model and some of the servers you can use on a network. Details of setting up and using clients and servers are reserved until Part V.
