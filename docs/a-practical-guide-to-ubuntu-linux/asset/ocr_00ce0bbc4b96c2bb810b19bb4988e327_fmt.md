
# Configuring Printers

## Classes

`CUPS` allows you to organize similar printers into a group called a class. To clients, a class of printers appears as a single printer. For each class, you must specify a name; otherwise, you can specify a location and description. A printer can belong to more than one class. `CUPS` prints jobs sent to a class as the first available printer in the class. For example, you may be able to divide your print jobs into black-and-white jobs and color jobs. If more than one printer can fulfill each of these roles, you can allow users to select a printer manually, or define two printer classes (`black-and-white` and `color`) and have users send their jobs to a certain class of printers.

## Plan for the Future

If you expect to add printers to the network, you may want to configure classes containing existing printers when you set up the network. You can then add printers later without having to change printer configurations on client systems.

To define a class, first click the `Administration` tab near the top of the page and click `Add Class`. At a minimum, you must enter a name for the class. You may also enter a description and location. The `Members` list displays the names of all `CUPS` printers and classes. Highlight the printers you want to be members of the class you are defining; hold `SHIFT` to highlight more not adjacent in the list, define the class to have a single printer and then modify the class after you create it to add other printers. To modify existing classes, click `Manage Classes` in the `Administration` tab.

# CUPS On The Command Line

In addition to using the Web interface, you can control `CUPS` and manage print queues from the command line. This section describes the utilities that you use to manage printers and print queues and establish quotas.

## lpinfo: Displays Available Drivers

`PPD` files. The `lpinfo` utility provides information about the printer drivers and interfaces to `CUPS`. The `-m` option displays the list of available PostScript Printer (`PPD`) files.

```
$ lpinfo -m | head
```
