As you run commands and your history list becomes longer, it may run off the top of the screen when you use the history builtin. Pipe the output of history less to browse through it, or give the command history 10 or history tail to look at the ten most recent commands.

# A handy history alias

Creating following aliases makes working with history easier. The first allows you to give the command h to display the ten most recent commands. The second alias allows the command h string to display all events in the history list that contain string. Put these aliases in your ~/.bashrc file to make them available each time you log in. See page 344 for more information.

```
$ alias 'h-history | tail'
$ alias 'hg-history | grep'
```

# REEXECUTING AND EDITING COMMANDS

You can reexecute any event in the history list. This feature can save you time, effort, and aggravation. Not having to reenter command lines allows you to reexecute events more easily, quickly, and accurately than you could if you had to retype the command line in its entirety. You can recall, modify, and reexecute previously executed events in three ways: you can use the fc builtin (covered next), or the Readline Library (page 335), which uses a one-line vi or emacs-like editor to execute events (page 340).

# Which method to use?

If you are more familiar with emacs and less familiar with the C or TC Shell, use fc or the Readline Library. If you are more familiar with the C TC Shell, use the exclamation point commands. If it is a toss-up, try the Readline Library; it will benefit you in other areas of Linux more than learning the exclamation point commands wills.

# fc: DISPLAYS, EXITS, AND REECUTES COMMANDS

The fc (fix command) enables you to display your history list to edit and reexecute previous commands. It provides many of the same capabilities as the command-line editors.

# VIEWING THE HISTORY LIST

When you call fc with the -l option, it displays commands from the history list. Without any arguments, fc -l lists the 16 most recent commands in a numbered list, with the oldest appearing:

```
$ fc -1
1024 cd
1025 view tiny letter.adams01
1026 vim.tiny letter.adams01
1027 aspell -c letter.adams01
1028 vim.tiny letter.adams01
1029 lpr letter.adams01
1030 cd ..members
```
