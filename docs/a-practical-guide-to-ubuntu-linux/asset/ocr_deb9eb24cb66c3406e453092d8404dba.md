# COMPRESSING ARCHIVING FILES 177

```
$ ls -l1 max*
-rw-r--r-- 1 sam 1564560 2010-04-12 15:51 make-3.80.tar.gz

$ gzip max*
$ ls -l1 max*
-rw-r--r-- 1 sam 6072320 2010-04-12 15:51 make-3.80.tar

$ tar -xvf max*
make-3.81/
make-3.81/config/
make-3.81/configpaths.m4
...
make-3.81/tests/run_make_tests.pl
make-3.81/tests/test_driver.pl
```

The first command lists the tarred and gzipped file: make-3.80.tar.gz (about 1.2 megabytes). The asterisk (*) matches any characters in the filenames (page 257), so ls displays a list of files whose name begin with max; in this case there is only one. Using an asterisk saves typing and improves accuracy with long filenames. The gzip command decompresses the file and yields make-3.80.tar (.gz extension), which is about 4.8 megabytes. The tar command creates the make-3.80 directory in the working directory and unpacks the files into it.

After tar extracts the files from the archive, the working directory contains two files whose name start with max: make-3.80.tar and make-3.80. The -d (directory) option causes ls to only show file and directory names, not the contents of directories as it normally does. The final ls command shows the files and directories in the make-3.80 directory. Refer to the info page for more information.
