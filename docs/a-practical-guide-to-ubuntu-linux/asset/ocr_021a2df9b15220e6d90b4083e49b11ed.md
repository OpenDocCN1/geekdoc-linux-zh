# CHAPTER 2 INSTALLATION OVERVIEW

i86 (Intel x86) Software on an Ubuntu PC (Intel x86) CD/DVD is compiled to run on Intel x86-compatible processors, including most machines with Intel and AMD processors, almost all machines that run Microsoft Windows, and newer Apple Macintosh that use Intel processors. If you are not sure which type of processor machine you have, as has this type of processor.

amd64 (AMD64 and Intel EM64) Software on an Ubuntu 64-bit PC (AMD64) CD/DVD is compiled to run on AMD64 processors, including the Athlon64, Opteron, and Intel 64-bit processors that incorporate EM64t technology, such as the E664 Xeon. Some features of proprietary third-party applications are not available for 64-bit architecture, you may want to run Ubuntu compiled for a 32-bit (Intel x86) processor or a system with a 64-bit processor.

arm+dove refers to the Marvell Dove System-on-Chip (code name for the Armada 500). This all-in-chip chipset features an ARM general processor and a specific set of peripherals. For more information see wiki.ubuntu.com/products/whatisubuntu/arm and wiki.ubuntu.com/ARM/LucidReleaseNotes.

powerpc (PowerPC) Ubuntu does not officially support the IBM/Motorola PowerPC (used by older Apple Macintosh computers), but community support for this architecture is available. See wiki.ubuntu.com/PowerPCFAQ for more information about running Ubuntu on a PowerPC. You can download PowerPC versions of Ubuntu from wiki.ubuntu.com/PowerPCDownloads.

sparc (Sun SPARC) Ubuntu supports UltraSPARC machines, including those based on the multicore UltraSPARC T1 (Niagara).

ia64 (Intel IA-64) Ubuntu supports Itanium family of 64-bit Intel processors.

# INTERFACES: INSTALLED AND INSTALLED SYSTEM

When you install Ubuntu, you have a choice of interfaces to use while you install it (to work with the installer). You also have a choice of interfaces to work with the installed system. This section describes the two basic interfaces: textual and graphical.

Textual (CLI) A textual interface, also called a command-line interface (CLI) or character-based interface, displays characters and some graphical symbols. It is line oriented; you give it instructions using a keyboard only.

Graphical (GUI) A graphical user interface (GUI) typically displays a desktop (such as GNOME) and windows; you can give instructions using a mouse and keyboard. You can run a textual interface within a GUI by opening an emulator window (page 125). A GUI uses more computer resources (CPU time and memory) than a textual interface.

Pseudographical A pseudographical interface is a textual interface that takes advantage of graphical elements on a text-based display device such as a terminal. It may also use color. This interface uses text elements, including simple symbols, to draw rudimentary boxes that emulate GUI windows and buttons. Pressing the TAB key moves the cursor to the next and pressing the return key selects the element the cursor is on.
