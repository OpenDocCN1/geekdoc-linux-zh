The fc builtin can take zero, one, or two arguments with the -l option. The arguments specify part of the history list to be displayed:

```
fc -l [first |last]]
```

The fc builtin lists commands beginning with the most recent event that matches first. The argument can be an event number, the first few characters of the command line, or a negative number, which is taken to be the nth previous command. Without last, fc displays events from the most recent. If you include last, fc displays commands from the most recent event that matches first through the most recent event that matches last.

The next command displays the history list from 1030 through 1035:

```
$ fc -l 1030 1035
1030  cd ..memos
1031  1s
1032  rm *0405
1033  fc -1
1034  cd
1035  whereis aspell
```

The following command lists the most recent event that begins with view through the most recent command line that begins with whereis:

```
$ fc -1 view whereis
1025  view calendar
1026  vim.tiny letter.adams01
1027  aspell -c letter.adams01
1028  vim.tiny letter.adams01
1029  lpr letter.adams01
1030  cd ..memos
1031  1s
1032  rm *0405
1033  fc -1
1034  cd
1035  whereis aspell
```

To list a single command from the history list, use the same identifier for the first and second arguments. The following command lists event 1027:

```
$ fc -l 1027 1027
1027  aspell -c letter.adams01
```
