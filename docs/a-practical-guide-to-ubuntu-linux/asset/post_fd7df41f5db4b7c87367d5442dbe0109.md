## EXAMPLES 1081

You can then incorporate the module in the Perl program. The following example uses the timestamp module to generate a unique filename:

```
$ cat fn.pl
use Timestamp::Simple qw(stamp);
```

```
# Save timestamp in a variable
$ts = stamp, "\n";
```

```
# Strip off the year
$ts =~ s/...(.*)\/\/1;
```

```
# Create a unique filename
$sfn = "myfile." $ts;
```

```
# Open, write to, and close the file
open (OUTFILE, '>', "$sfn");
print OUTFILE "HI here.\n";
close (OUTFILE);
```

```
$ perl fn.pl
myfile.090518310
```

You can use the substr function in place of the regular expression to strip off the year. To do so, replace the line that starts with $ts = with the following line. Here, substr takes the value of the string $ts starting at position 4 and continuing to the end of the string:

```
$ts = substr ($ts, 4);
```

## EXAMPLES

This section provides some Perl programs. First running these programs as is, and then modify them to learn more about programming with Perl.

The first example runs under Linux and displays the list of users that the user given as the argument is a member of. Without an argument, it displays the list of users that the running program is a member of. In a Perl program, the %ENV hash holds the environment variables from the shell that called Perl. The keys in this hash are the names of environment variables; the values in this hash are the values of the corresponding variables. The first line of the program assigns a username to $User. The shift function (page 105) takes on the value of the first command-line argument and shifts the rest of the arguments, if remain. If the user runs the program with an argument, argument is assigned to User. If no argument appears on the command line, shift fails and Perl executes the statement following the Boolean OR (||). This statement extracts the value associated with the USER key in %ENV, which is the name of the user running the program.

Accepting output The third statement initializes the array @list. Although this statement is not from a process it is good practice to include it to make the code easier to read. The next statement opens the $fh lexical. The trailing pipe symbol (|) in the file-ref (page 1066) portion of this open statement tells Perl to pass the command line preceding the pipe symbol to the shell for execution and accept standard output from the command when the program reads from the file handler. In this case the command uses grep to filter the /etc/group file (page 492) lines containing the username in Suser. The die statement displays an error message if Perl cannot open the handle.

### $ cat groupfind.pl

```perl
$Suser = shift || $ENV{"USER"};
say "$Suser belongs to these groups:";
@list = ();
open ($fh, "grep $Suser /etc/group |") or die "Error: $!\n";
while ($group) {
    chomp $group;
    $group ~ s/(.*):.*/$1;
    push @list, $group;
}
close $fh;
@slist = sort @list;
say "@slist";
```

### $ perl groupfind.pl

User belongs to these groups:
admin audio cdrom dialout dip floppy kvm lpadmin ...

The while structure in groupfind.pl reads lines from standard output of grep and terminates when grep finishes executing. The name of the group appears first on each line in /etc/group, followed by a colon and other information, including the names of the users who belong to the group. Following is a line from this file:

sam:x:1000:max,zach,helen

The line

```perl
$group ~ s/(.*):.*/$1;
```

uses a regular expression and substitution to remove everything except the name of the group. The chomp statement removes the trailing newline. The push statement adds the value of $group to the end of the @list array. Without chomp, each group would appear on a line by itself. The while structure processes input from grep, sort sorts @list and assigns the result to $slist. The final statement displays the sorted list of groups the user belongs to.

opendir: The next example introduces opendir and readdir. The opendir function opens a directory in a manner similar to the way open opens a file. It takes two arguments: the name of the directory and the name of the directory to open. The readdir function reads the name of a file from directory. In the example, opendir opens the working directory (specified by .) using $dir. If opendir fails, Perl executes the statement following the or part: die sends an error message to standard error and terminates the program. With the directory opened, while loops through the files in the directory, assigning the filename that readdir returns to the lexical variable $entry. If an statement executes print only for those files that are directories (-d). When readdir has read all files in the working directory, it returns false and passes control to the statement following the while block. The closed function opens the directory and print displays a newline following the list of directories displayed.

```perl
$ cat dirsa2.pl
!/usr/bin/perl
print "The working directory contains these directories:\n"

opendir my $dir, '.' or die "Could not open directory: $!\n"
while (my $entry = readdir $dir) {
    print $entry, unless $entry == '.' || $entry == '..';
}
closedir $dir;
print "\n";
```

```
$ dirsa2.pl
The working directory contains these directories:
two one
```
