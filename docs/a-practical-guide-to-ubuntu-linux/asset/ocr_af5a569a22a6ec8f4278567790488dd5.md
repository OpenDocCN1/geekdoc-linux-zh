# ypasswd: The NIS Password Update Daemon

The NIS password update daemon, passwd, runs only on the master server; it is not necessary to run it on slave servers. (If the master server is down and you try to change your password from a client, passwdd (page 748) on a client, this utility exchanges information with the passwd daemon to update the user's password (and optionally other) information in the NIS shadow (and optionally /etc/passwd) map and on /etc/shadow. Password change requests are sent to syslog (page 625).

If the server system is running a firewall, open a port for passwdd. Refer to "Fire-wall" on page 751.

# ALLOW GECOS AND LOGIN SHELL MODIFICATION

The /etc/default/nis file controls whether passwdd allows users to change GECOS (page 1150) information and/or the login shell when they run passwdd. As shipped, passwdd allows users to change their login shell but not their GECOS information. You can change these settings with options on the command line when you start passwdd or, more conveniently, by modifying the /etc/default/nis configuration file. The -e ch option allows passwdd users to change their GECOS information; if you set the options in /etc/default/nis, these values are automatically set each time passwdd runs. Set YPCHANGEOK in the comments.

```
$ cat /etc/default/nis
...
# Do we allow the user to use ypch or ypfn? The YPCHANGEOK
# fields are passed with -e to passwdd, see it's manpage.
# Possible values: "chsh", "chfn", "chsh,chfn"
YPCHANGEOK=chsh
...
```
