exim4 init script When you install the exim4 package, the dpkg postinst minimally configures
ex4 and starts the exim4 daemon. After you configure exim4, call the exim4 init
script to restart exim4:

```
$ sudo service exim4 restart
```

After the exim4 configuration on an active server, reload in place of
restart to reload exim4 without interrupting the work exim4 is
The exim4 init accepts several nonstandard arguments:

# service exim4
Usage: /etc/init.d/exim4 {start|restart|reload|status|[force-stop]}

The status and arguments display information about exim4. The force-stop
argument immediately kills all exim4 processes.

# NOTES

Firewall An SMTP server normally uses TCP port 25. If an SMTP server system that
receives nonlocal is running behind a firewall, you need to open this port. To do so,
use ufw (page 876) to set a policy that allows SMTP service.

Log files You must be a member of the ad group or work with root privileges to view the
log files in /var/log/exim.

sendmail Although it does not work the same as sendmail. Ubuntu configures exim4
ex4 as a drop-in replacement for sendmail. The exim4-daemon-light package, which is
part of the exim4 virtual package, includes /usr/bin/sendmail, which is a link to
ex4. Because the exim4 daemon accepts many of sendmail's options, programs
that depend on sendmail will work with exim4 installed in place of sendmail.

Local and nonlocal systems The exim4 daemon sends and receives email. A piece of each exim4 receives
orinate on a local system or a nonlocal system. Similarly, that exim4 receives
sends can be destined for a local or nonlocal system. The exim4 daemon processes
e piece of mail based on its origin and destination.
