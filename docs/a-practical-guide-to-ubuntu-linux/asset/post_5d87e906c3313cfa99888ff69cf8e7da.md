## THE DESKTOP DIRECTORY

The files on the desktop are held in a directory that has a pathname (205) of /home/username/Desktop, where username is your login name, or if you are logged in on a live session, ubuntu. The simple directory is Desktop. When you select Main menu: Places->GNOME opens a File Browser window showing the files on the desktop (Figure 4-8). Initially there are no files. The buttons below the toolbar and to the right of Places show the pathname of the directory Nautilus is displaying (sam/Desktop in Figure 4-8).

To see the correspondence with the graphical desktop and the Desktop, right-click anywhere within the clear area of the Desktop File Browser window. Select Create->Empty File. Nautilus creates a new file on the desktop and displays its objects in window. When you create this file, GNOME highlights the new file under the file: You can type any name you like at this point. Press RETURN when you are finished entering the name. If double-click the new file, Nautilus assumes it is a file and opens it in a gedit window (The gedit utility is a simple text editor). Type some text and click Save on the toolbar. Close the window either using the File menu or by clicking the x at the left of the titlebar. You have created a text document on the desktop. You can now double-click the object on the desktop or in the File Browser window to open and edit it.

# SELECTING OBJECTS

The same techniques can be used to select one or more objects in a File Browser window or on the desktop. Select an object by clicking it; GNOME highlights the object. Select additional objects by holding down the CONTROL key which will click each object. To select a group of adjacent objects, highlight the SHIFT key, click the first object and, while holding down the last object; GNOME highlights all objects between the two objects you clicked. Alternatively, you can use the mouse pointer to drag a group of objects To experiment with these techniques, open a File Browser window displaying your home folder. Display the Examples folder by double-clicking it. Select a few objects, right-click, and select Copy. Now move the mouse pointer over an empty part of the desktop, right-click, and select Paste. You have copied the selected objects from the Examples folder to the desktop. You can drag and drop objects to move them.
