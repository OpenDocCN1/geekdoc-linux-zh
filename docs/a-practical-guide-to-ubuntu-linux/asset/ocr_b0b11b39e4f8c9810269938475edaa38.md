# ## Select an image

Ubuntu is distributed in four types of images described below:

# ### Desktop CD

The desktop CD allows you to boot Ubuntu without changing your computer, and at your convenience to install it afterwards. You will need at least 256MB of RAM to install and use from this CD.

There are two images available, each for a type of computer:

# #### PC (amd64) DVD-CD

For all PCs, this includes machines with Intel/AMD processors and almost all computers except Microsoft Windows, as well as Apple Macintosh systems based on Intel processors. Choose this if you are one of them.

# #### 32-bit PC (i386) DVD-CD

Choose this for full support of computers on the i386 or ELIM37 architecture (e.g. Atom).

Many sites mirror (hot copies of) the Ubuntu ISO image files and BitTorrent torrent files. Some mirrors use HTTP, while others use FTP; you can use a browser to download files from any type of site. FTP and HTTP sites appear slightly different. Point a browser at http://ubuntu.com/ubuntu/downloadmirrors to locate a mirror site. Scroll down a bit to reach the list of mirror sites. Then scroll through the list to find a site near you, and click that site's URL. The browser displays a page similar to the one shown in Figure 2-3.

Click on the page that includes the name or release number (e.g., Lucid or 10.04; click 31) of the version of Ubuntu you want to install. The browser displays a page similar to the one shown in Figure 2-4.

Downloading an ISO image At this point, some sites display a page with two links: **Parent directory and release**. If the browser displays this page, click **release**. The browser displays a page with the name and number of the release at the top, followed by a description of the different types of CDs.
