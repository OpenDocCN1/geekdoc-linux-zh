# LOGIN SECURITY

Without a secure host, good login security cannot add much protection. Table C-1 on page 124 lists some of the best login security tools, including replacement daemons for telnetd, rlogind, and rsh. Many sites use ssh, which comes as freware and a commercially supported package that works on UNIX/Linux, Windows, and Macintosh platforms.

The PAM family (page 478) allows you to set up multiple authentication methods for users in series or in parallel. In-series PAM requires multiple methods of authentication for a user. In-parallel PAM uses one of a methods for authentication.

Although not the most popular choice, you can configure a system to take advantage of one-time passwords. S/Key is the original implementation of one-time passwords by Bellcore. OPIE was developed by the U.S. Naval Research Labs, an improvement over the original Bellcore system. In one permutation of one-time passwords, the user gets a piece of paper listing a set of one-time passwords. Each time a user logs in, she enters a password from the piece of paper.
