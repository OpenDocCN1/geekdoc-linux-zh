Accepting output The third statement initializes the array @list. Although this statement is not from a process it is good practice to include it to make the code easier to read. The next statement opens the $fh lexical. The trailing pipe symbol (l) in the file-ref (page 1066) portion of this open statement tells Perl to pass the command line preceding the pipe symbol to the shell for execution and accept standard output from the command when the program reads from the file handler. In this case the command uses grep to filter the /etc/group file (page 492) lines containing the username in Suser. The die statement displays an error message if Perl cannot open the handle.

# $ cat groupfind.pl

```
$ Suser = shift || $ENV("USER\nsay "$Suser belongs to these groups";
@list = ();
open ($fh, "grep $Suser /etc/group |") or die "Error: $!\n";
while ($group) {
chomp $group;
$group ~ s/(.*):\*/$1;
push @list, $group;
}
close $fh;
@slist = sort @list;
say "@slist";
```

# $ perl groupfind.pl

User sam belongs to these groups:
admin audio cdrom dialout dip floppy kvm lpadmin ...

The while structure in groupfind.pl reads lines from standard output of grep and terminates when grep finishes executing. The name of the group appears first on each line in /etc/group, followed by a colon and other information, including the names of the users who belong to the group. Following is a line from this file:

sam:x:1000:max,zach,helen

The line

```
$group ~ s/(.*):\*/$1;
```

uses a regular expression and substitution to remove everything except the name of the group from each line. The regular expression .* would perform a greedy match of zero or more characters followed by a colon; putting question mark after the asterisk causes the expression to perform a nongreedy match (page 1076). Putting parentheses around the part of the expression that matches the string needs to display enables Perl to use the string that the regular expression matches in the replacement string. The .* replaces the rest of the line. Perl replaces the $ in the replacement string with the string the bracketed portion of the regular expression (the part between the parentheses) matched and assigns this value (the name of the group) to $group.
