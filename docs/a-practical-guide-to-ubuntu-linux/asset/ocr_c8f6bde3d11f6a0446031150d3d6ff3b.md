# 842 CHAPTER 24 DNS/BIND: TRACKING DOMAIN NAMES AND ADDRESSES

The root zone is required only for servers that answer recursive recursive queries: If a server responds to recursive queries, it needs to perform a series of iterative starts- at the root domain. Without the root domain hint file, it would not know where to find the root domain servers.
