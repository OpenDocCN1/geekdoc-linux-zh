# WORKING WITH FILES

This file handles case Perl program to work like many Linux units: It reads from standard input unless the program is called with one or more arguments, in which case it reads from the files named by the arguments. See page 248 for an explanation of how this feature works with cat.

The print statement in the first line of the next example includes the optional handle STDOUT; the next print statement omits this handle; the final print statement uses the STDERR file handle, which causes print's output to go to standard error. The first print statement prompts the user to enter something. The string that this statement outputs is terminated with a SPACE, so the user can enter information on the same line as the prompt. The second line then uses a magic file handle to read one line from standard input, which assigns to $. Because of the magic file handle, if you call file1pl with an argument that is a filename, it reads one line from that file instead of standard input. The command line that runs file1pl uses >2 (see "File descriptors") on page 297) to redirect standard error (the output of the third print statement) to the file1.err file.

```
$ file1.pl
print STDOUT "Enter something: ";
$userline =
print "1>>$userline<<"
chomp($userline);
print "2>>$userline<<"
print STDERR "3. Error message.\n\n
```

```
$ file1.pl 2> file1.err
Enter something: hi there
<<<
1>>>hi there<<<
2>>>hi there<<>
```

```
$ file1.err
3. Error message.
```

chomp The two print statements following the user input in file1.pl display the value of $userline immediately preceded by greater signs (>) and by less than signs (<). The first of these statements demonstrates that $userline includes a NEWLINE. The less than signs removes the string entered after on the line following the string. The chomp function removes a trailing NEWLINE, if it exists, from a string. After chomp processes $userline, the print statement shows that $userline no longer contains a NEWLINE. (The chomp function is similar to chomp, except it removes any trailing character from a string)
