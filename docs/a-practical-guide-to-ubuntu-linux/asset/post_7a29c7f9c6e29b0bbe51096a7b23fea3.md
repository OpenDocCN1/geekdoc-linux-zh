## KEY TOPICS COVERED IN THIS BOOK

This book contains a lot of information. This section distills and summarizes its contents. In addition, “Details” (starting on page xlvi) describes what each chapter covers. Finally, the table of contents provides more detail. This book:

## Installation

- *Describes*

- Describes how to download Ubuntu ISO images from the Internet and burn the Ubuntu live/install Desktop CD, the DVD, or the Ubuntu Alternate or Server CD.
- Helps you plan the layout of the system's hard disk. It includes a discussion of partitions, partition tables, and mount points, and assists you in using ubiquity, palimpsest, or gpart graphical partition editor or the Ubuntu textual partition editor to examine and partition the hard disk.
- Explains how to set up a dual-boot system so you can install Ubuntu Linux on a Windows system and boot either operating system.
- Describes in detail how install Ubuntu Linux from a live/install Desktop CD using the ubiquity graphical installer. It also explains how to use the textual installer found on the Alternate CD, the Server CD, and the DVD. The graphical installer is fast and easy to use. The textual installer gives you more options and works on systems with less RAM (system memory).
- Covers testing an Ubuntu CD/DVD for defects, booting command-line parameters (boot options), and creating a RAID array.

## Working with Ubuntu Linux

- *Introduces* the GNOME desktop (GUI) and explains how to use desktop tools, including the Top and Bottom panels, panel objects, the Main menu, context menus, the Workspace Switcher, the Nautilus File Browser, and the GNOME terminal emulator.
- Explains how to use the Appearance Preferences window to add and modify themes to customize your desktop to please your senses and help you work more efficiently.
- Details how to set up 3D desktop visual effects that take advantage of Compiz Fusion.
- Covers the Bourne Again Shell (bash) in three chapters, including an entire chapter on shell programming that includes many shell scripts. These chapters provide clear explanations and extensive examples of how bash works both from the command line in day-to-day and as a pro programming language in which to write shell scripts.
- Explains the textual (command-line) interface and introduces more than 30 command-line utilities.
- Presents a tutorial on the vim textual editor.
- Covers types of networks, network protocols, and network utilities.
- Explains hostnames, IP addresses, and subnets, and explores how to use host and dig to look up domain names and IP addresses on the Internet.
- Covers distributed computing and the client/server model.
- Explains how to use ACLs (Access Control Lists) to fine-tune user access permissions.
- Explains how to use the Ubuntu graphical and textual (command-line) tools to configure the display, DNS, NFS, Samba, Apache, a firewall, a network interface, and more. You can also use these tools to add users and manage local and remote printers.
- Goes into detail about using sudo to allow specific users to work with root privileges (Super User) and customizing the way sudo works by editing the sudoers configuration file. It also explains how you can unlock the root account if necessary.
- Describes how to use the following tools to download and install software to keep a system up-to-date and install new software:
- *The Software Windows controls which Ubuntu and third-party repositories Ubuntu downloads software packages from and whether Ubuntu downloads updates automatically. You can also use this window to download Ubuntu and install security updates automatically.
- *If you do not have an Internet connection, you can use the Software Sources to set up the DVD included with this book as a soft-repository. You can then install any software packages that Ubuntu supports from this repository.
- *Based on how you set up updates in the Software Sources window, the Update Manager window appears on the desktop to let you know when software updates are available. You can download and install updates from the Update Manager window.
- *The Ubuntu Software Center window provides an easy way to select, download, and install software.
- *Synaptic allows you to search for, install, and remove software.
- *APT downloads and installs software from the Ubuntu Software Center.
- *BitTorrent is a good choice for distributing large amounts of data such as the included DVD.
- *Covers graphical system tools, including the GNOME Main menu.

## KEY TOPICS COVERED IN THIS BOOK

- Explains system operation, the boot process, init scripts, recovery (single-user) and multiuser modes, and steps to take if the system crashes.
- Describes the new Upstart init daemon, which replaces the System V init daemon.
- Explains how to use Cacti network monitor to graph system and network information over time, including installing and setting up LAMP (Linux, Apache, MySQL, PHP) stack.
- Describes files, directories, and tables, including types of files and systems, fstab (the filesystem), and automatically mounted filesystems, and explains how to fine-tune and check the integrity of filesystems.
- Covers backup utilities, including tar, cpio, dmp, and restore.
- Describes compression/archive utilities, including gzip, bzip2, compress, and zip.
- Explains how to customize and build a Linux kernel.

## Security

- Helps manage security issues using ssh (secure shell), vsftpd (secure FTP server), Apache (Web server), iptables (firewalls), and more.
- Describes how to use the textual firewall (ufw) and its graphical interface (ufw) to protect the system.
- Covers the use of firestarter to share an Internet connection over a LAN, run a DHCP server, and set up a basic firewall to protect the system.
- Provides instructions on using iptables to share an Internet connection over a LAN and to build advanced firewalls.
- Describes how to set up a chroot jail to help protect a server.
- Explains how to use TCP wrappers to control who can access a server.

## Clients and servers

- Explains how to set up and use the most popular Linux servers, providing a chapter on each: Apache, Samba, exim4, DNS, NFS, FTP, gufw and iptables, and NIS/LDAP (all of which are supported by Ubuntu Linux).
- Describes how to set up a CUPS printer server.
- Explains how to set up and use a MySQL relational database.
- Describes how to set up and use a DHCP server either by itself or from firestarter.

## Programming

- Provides a chapter on the Perl programming language and a full chapter covering shell programming using bash, (ufw), including many examples.
