## 选择镜像

Ubuntu 以四种类型的镜像发行：

### Desktop CD
桌面 CD 允许您在不更改计算机的情况下启动 Ubuntu，并方便稍后安装它。您至少需要 256MB 的 RAM 来安装和使用此 CD。有两个镜像可用，适用于类型的计算机：

#### PC (amd64) DVD
适用于所有 PC，包括带有 Intel/AMD 处理器的机器以及除 Windows 以外的所有基于 Intel 处理器的系统。如果您是其中之一，请选择此项。

适用于 i386 架构的计算机（例如 Atom）。在此找到可用镜像列表，包括 ISO 文件。如果您需要刻录这些镜像的帮助，请查看镜像指南。

许多站点镜像了 Ubuntu 镜像文件和 torrent 文件。某些镜像使用 HTTP，另一些使用 FTP；您可以使用浏览器从任何类型的站点下载文件。FTP 和 HTTP 站点略有不同。将浏览器指向 http://ubuntu.com/ubuntu/downloadmirrors 以查找镜像站点。向下滚动到达镜像站点列表。然后遍历列表找到靠近您的站点并点击该站点的 URL。浏览器将显示一个与图 2-3 类似的页面。

下载 ISO 镜像在此处，某些站点显示两个链接：**父目录**和**发行版**。如果浏览器显示此页面，点击**发行版**。浏览器在顶部显示显示发行版的名称和编号，随后是不同 CD 类型的描述。页面底部是文件列表，每行显示文件名称、创建日期和大小。每个文件名都是链接。以下两行描述了 Lucid Lynx (10.04) 的 x86 桌面镜像以及允许您使用 BitTorrent 下载相同镜像文件的 torrent 文件。ISO 镜像文件约为 700 兆字节；torrent 文件为 28 千字节。

点击指定您想要下载的发行版（例如 10.04）、版本（例如 desktop 或 alternate）以及架构（例如 i386 或 amd64）的文件/链接。例如，点击 ubuntu-10.04-desktop-i386.iso 下载 i386 架构的 Lucid (10.04) 桌面版 ISO 镜像。将名为 SHA1UMS 的文件（位于顶部）保存到硬盘。保存文件的一种简单方法是右键点击它，选择“链接另存为”，并将其保存到有足够空间文件的目录中。查看下一节有关如何使用 SHA1UMS 验证 ISO 镜像是否正确下载的说明。

要下载 DVD ISO 文件，请访问 cdimage.ubuntu.com/releases 并按照“下载镜像”下的说明操作。您可以通过名称中的 *dvd* 字符串识别 ISO 镜像文件。确保您有足够的磁盘空间：DVD ISO 文件占用 4 兆字节。下载 DVD 的时间是 CD 镜像的五倍。
