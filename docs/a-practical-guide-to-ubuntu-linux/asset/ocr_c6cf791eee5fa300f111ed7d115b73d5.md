The next program runs under Linux and lists the usernames of users with UIDs greater than or equal to 100 listed in the /etc/passwd (page 494) file. It uses a while structure to read lines from passwd into $user, and uses split to break the line into substrings by colons. The line begins with @row assigns each of these substrings to element of the @row array. The if statement evaluates to true if the third substring (the UID) is greater than equal to 100. This expression uses the >= numeric comparison operator because it compares two numbers; an alphabetical comparison would use the ge string comparator.

The print statement sends the UID number and the associated username to the $sortout file. The open statement for this handle establishes a pipe that sends its output to sort -n. The sort utility (page 168) does not display any output until finishes reading all of the input, split3.pl does not display any output until it finishes reading the passwd file.

```
$ split3.pl
!/usr/bin/perl -w

open($pass, "/etc/passwd");
open($sortout, "| sort -n");
while ($user <$pass>) {
    @row = split (/, $user);
    if ($row[2] >= 100) {
        print $sortout $row[0]\n";
    }
}
close($pass);
close($sortout);
```

```
..
```

The next example counts and displays the arguments it was called with, using @ARGV (page 1068). A foreach structure loops through the elements of the @ARGV array, which holds the command-line arguments. The ++ preincrement operator $Count before it is displayed.

```
$ cat 10.pl
!/usr/bin/perl -w

$count = 0;
$num = @ARGV;
print "You entered $num arguments on the command line:\n";nforeach $arg (@ARGV) {
    print ++$count, ". $arg\n";n}
```
