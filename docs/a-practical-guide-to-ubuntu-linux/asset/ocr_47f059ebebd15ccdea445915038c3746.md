+   - Focus-strictly-under-mouse (enter-exit focus)—Gives the input focus to a window when you move the mouse pointer onto the window. Window maintains the input focus until you move the mouse pointer off the window, at which point no window has the focus. When you move a window off a window and onto the root window, the window that had the input focus loses it, and from the keyboard.

You can use the Window Preferences window to change the focus. To display this window, select Main menu: System>Preferences>Windows or give the command gnome-window-properties from a terminal or Run window (ALT+F2). Put a tick in the check box next to Windows moves over them to select the focus-follows-mouse policy. When there is no tick in this check box, click-to-focus is in effect. Click Close. Focus-strictly-under-mouse is not available from this window.

To determine which active window has the focus, compare the window borders. The border color of the active window is different from the others, or a monochrome display, is darker. Another indication that an active window is that the keyboard cursor is a solid rectangle; in windows that are not active, the cursor is an outline of a rectangle.

Use the following tests to determine which keyboard focus method you are using. If you position the mouse pointer in a window and that does not get the input focus, your window manager is configured to use the click-to-focus method. If the border of the window changes, you are using the focus-follows or focus-strictly-under-mouse method. To determine which of the latter methods you are using, start typing something, with the mouse pointer positioned on the active window. Then move the mouse pointer over the root window and continue typing. If characters continue to appear within the window, you are using focus-follows; otherwise, you are using focus-strictly-under-mouse.

# CHANGING THE RESOLUTION OF THE DISPLAY

The X server (the base for the Linux graphical interface; page 268) starts at a specific resolution and color depth (page 1141). Although you can change the color depth only when you start an X server, you can change the resolution while the X server is running. The number of resolutions depends on the display hardware and the configuration of the X server. Many users prefer to do most of their work at a higher resolution but might want to switch to a lower resolution for some tasks, such as playing games. You can switch between display resolutions by pressing either CONTROL-KEYPAD+- or CONTROL-KEYPAD-, using the + and - keys on the keyboard’s numeric keypad. You can also use the Monitor Resolution window (Main menu: System>Preferences>Monitors) to change the resolution of the display.
