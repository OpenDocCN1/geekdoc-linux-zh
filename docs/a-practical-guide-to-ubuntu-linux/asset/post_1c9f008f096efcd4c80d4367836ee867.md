```

Working with root privileges, you can edit these files and change the values within the market to change what the apt cron script does. Each line must end with a semicolon. The following list explains each of the directives in these files.

APT::Periodic::Package-Lists "days";

Synchronizes indexes with their corresponding repositories (page 528) every days. Set days to 0 to disable this directive.

APT::Periodic::Download-Upgradeable-Packages "days";

Downloads (but does not install) the packages necessary to upgrade all packages on system (page 528) every days. Set days to 0 to disable this directive.

APT::Periodic::AutocleanInterval "days";

Clears the APT cache (page 524) of packages that can no longer be downloaded every days. Set days to 0 to disable this directive.

APT::Periodic::Unattended-Upgrade "days";

Installs updates to replace system security every days and writes a log to /var/log/unattended-upgrades. Make sure the unattended-upgrades package is installed; for more information see /usr/share/doc/unattended-upgrades/README. Set days to 0 to disable this directive.

APT::Archives::MaxAge "days";

Deletes files from the APT cache (page 524) older than days days. Set days to 0 to disable this directive.

APT::Archives::MinAge "days";

Causes files younger than days not to be deleted from the APT cache (page 524). Set days to 0 to disable this directive.

APT::Archives::MaxSize "MB";

Establishes the maximum size of the APT cache (page 524). When the cache grows larger than MB megabytes, the apt cron script deletes files until the cache is smaller than this. It deletes the largest files first. Set MB to 0 to disable this directive.

## aptitude Options

This section describes some of the options you can use with aptitude commands.

- --show-deps: Displays information about what would install.
- --download-only: Does not unpack or install.
- --purge-unused: Removes packages that are longer needed because they were.
- --help: Displays a summary of usage, commands, and options.
- --simulate: Displays what command would do, without taking any action.
- --assume-yes: Assumes yes response to most prompts.

## aptitude safe-upgrade AND aptitude full-upgrade: UPGRADE THE SYSTEM

There are two aptitude commands that upgrade all packages on the system: safe-upgrade, which upgrades all packages that do not require new packages to be installed, and full-upgrade, which upgrades all packages on the system, installing new packages as needed.

The following example uses the aptitude safe-upgrade packages on the system that depend only on packages that are already installed. This command will not install new packages (packages that are not already on the system). Before running this command, run aptitude update (page 528) to make sure the local package indexes are up-to-date.

```
$ sudo aptitude update
$ sudo aptitude safe-upgrade
