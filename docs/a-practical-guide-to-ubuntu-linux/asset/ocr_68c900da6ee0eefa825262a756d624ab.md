# KEY TOPICS COVERED IN THIS BOOK

Part IV IV covers system administration. Chapter 11 discusses concepts such as the use of sudo, working with root privileges, system operation including a discussion of the Upstart init daemon, chroot jails, TCP, general information about how to set up a server, DHCP, and PAM. Chapter 12 explains the Linux system, getting into detail about types of files, including special and device files; the use of fsck to verify the integrity of and filesystems; the use of tune2fs to change filesystem parameters. Chapter 13 explains how to keep a system up-to-date by downloading software from the Internet and installing it, including examples that use APT tools such as aptitude, apt-get, and apt-cache to perform these tasks. It also covers the dpkg packaging system and the use of some dpkg utilities. Chapter 14 explains how to use the CUPS printing system so you can print on both local and remote systems. Chapter 15 details customizing and building up user accounts, backing up files, scheduling automated tasks, tracking disk usage, solving general problems, and setting up a MySQL relational database. Chapter 17 explains how to set up a local area network (LAN), including both hardware (including wireless) and software configuration, and how to set up Cacti to monitor the network.

Part V Part V goes into detail setting up and running servers and connecting to them using clients. Where appropriate, these chapters include JumpStart that get you off to a quick start in using clients and setting up servers. The chapters in Part V cover the following clients/servers:

+   • OpenSSH—Set up an OpenSSH server and use ssh, sc, and sftp to communicate securely over the Internet.

+   • FTP—Set up a vsftpd secure server and use any of several FTP clients to exchange files with the server.

+   • Email—Configureim4 and use Webmail, POP3, or IMAP to retrieve email; use SpamAssassin to combat spam.

+   • NIS and LDAP—Set up NIS to facilitate system administration of a LAN and LDAP to maintain databases.

+   • NFS—Share filesystems between systems on a network.

+   • Samba—Share filesystems and printers between Windows and Linux systems.

+   • DNS/BIND—Set up a domain nameserver to other systems on the Internet knows the names and IP addresses of local systems they may need to contact.

+   • firestarter, ufw, gufw, and iptables—Set up a firewall to protect local systems, share a single Internet connection between systems on a LAN, and run a DHCP server.
