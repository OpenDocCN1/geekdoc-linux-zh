To this setup, no network traffic originating outside of the local system can enter the local system. You must set up rules to allow this traffic to pass. The next section covers setting up rules. You can change the default setup by changing the selections in the Incoming and Outgoing drop-down lists. This section assumes the default setup.

# ADDING RULES

To add a rule, click the button labeled Add; gufw displays the Add Rule window (Figure 25-11). This window has a check box labeled Show extended options and three tabs labeled Preconfigured, Simple, and Advanced.
