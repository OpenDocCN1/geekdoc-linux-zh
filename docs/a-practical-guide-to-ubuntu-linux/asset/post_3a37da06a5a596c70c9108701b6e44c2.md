# If you have a system running Ubuntu, upgrade install of

Ubuntu recommends that, if you have a system running Ubuntu and to run a newer release, you upgrade the release on the system. The rationale for this recommendation is twofold. First, the upgrade path is more aggressively tested by Ubuntu developers than the installers. You are less likely to run into problems with an update. Second, an upgrade preserves the system settings and applications, making an upgrade easier than a clean install.

Upgrade replaces all installed software packages with the most recent version available on the new release. During an upgrade, the installation program preserves both configuration and user data files. An upgrade brings utilities that are present in the old release up-to-date and installs new utilities. # SETTING UP THE HARD DISK

A hard disk must be prepared in several ways so Linux can read and write from it. Low-level formatting is the first step in preparing a disk for use. You do not need to perform this, as it is done at the factory where the hard disk is manufactured. The next steps in preparing a hard disk for use are to create a partition table and to create partitions on the disk. Finally, you need to create a filesystem on each partition. A partitioned disk that is not occupied by partitions is called free space. A new disk has no partition table, no partitions, and no free space. Under DOS/Windows, the term formatting means creating a filesystem on a partition; see “Filesystems”

A partition table holds information about the partitions on a hard disk. The first partition can be created on a disk, the program creating it must set up an empty partition table on the disk. As partitions are added, removed, and modified, information about these changes is recorded in the partition table. If you remove the partition table, you can no longer access information on the disk except by extraordinary means.

Filesystems Before most programs can write to a partition, a data structure (page 1144), called a filesystem, needs to be written to the partition. This data structure holds nodes (page 501) that map locations on the disk that store files to the names of files. At the top of the data structure is a single unnamed directory. As will be explained shortly, this directory joins the system directory when the filesystem is mounted.

When the Ubuntu installer creates a partition, it automatically writes a filesystem to the partition. You can use the mkfs (filesystem; page 458) utility, which is similar to the DOS/Windows format utility, to manually create a filesystem on a partition. Table 12-1 on page 505 lists some types of filesystems. Ubuntu Linux typically creates ext4 filesystems for data; Windows uses FAT16, FAT32, and NTFS filesystems. Apple uses HFS+ (Hierarchical File System) and OS uses either HFS+ or UFS. Different types of filesystems can coexist in different partitions on a single hard disk, including both Windows and Linux filesystems.

# THE LINUX DIRECTORY HIERARCHY

# Skip this section for a basic installation This section briefly describes the Linux directory hierarchy so you may better understand some decisions you need to make when installing. You do not have to read this section. See the beginning of Chapter 6 for a more thorough explanation of the directory hierarchy.

A namespace is a set of names (identifiers) in which each name is unique.

As differentiated from a Windows machine, a Linux system presents a single namespace that holds all files, including directories. The Linux system namespace is called the directory hierarchy or directory tree. Under Windows, C:\ is a separate namespace from D:\ The directory hierarchy rooted at C:\ is separate from the directory rooted at D:\ and there is no path or connection between them. Under Linux, the single namespace is rooted at /, which is the root directory.

# MOUNT POINTS

A filesystem on a partition holds no information about where it will be mounted in the directory hierarchy (the top-level directory of a filesystem does not have a name). When you use the installer to create more partitions, you specify the type of filesystem to be written to the partition and the name of a directory that Ubuntu associates with the partition.

Mounting a filesystem associates the filesystem with a directory in the directory hierarchy. You can mount a filesystem on any directory in the directory hierarchy.
