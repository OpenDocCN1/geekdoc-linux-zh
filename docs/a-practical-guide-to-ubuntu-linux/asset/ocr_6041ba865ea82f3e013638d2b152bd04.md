Standards With the idea of making life easier for system administrators and software developers, a group got together over the Internet and developed the Linux Filesystem Hierarchy Standard (FSSTND, FHS). Before this standard was adopted, key programs were located in different places in Linux distributions. Today you can sit down a Linux system and expect to find any given standard at a consistent location (page 213).

Links A link allows a given file to be accessed in the same directory as the original file or in another directory. Generative links can make the same file appear in several users' directories, enabling those users to share the file easily. Windows uses the term *shortcut* in place of *link* to describe this capability. Macintosh users will be more familiar with the term *alias*. Under Linux, an *alias* is different from a *link*; it is a command feature provided by Unix (page 346).

Security Like most multiser operating systems, Linux allows users to protect their data from access by other users. It also allows users to share selected data and programs with other users by means of a simple but effective protection scheme. This level of security is provided by file permissions, which limit the users who can read from, write to, or execute a file. More recently, Linux has implemented Access Control Lists (ACLs), which give users and administrators finer-grained control over file access permissions.
