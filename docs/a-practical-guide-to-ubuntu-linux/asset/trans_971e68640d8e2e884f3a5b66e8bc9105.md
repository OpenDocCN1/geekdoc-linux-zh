# 执行命令

fork 和 sleep：当你给 shell 一个命令时，它通常会 fork [使用 `fork()` 产生] 系统 (sys) 子进程来执行该命令。当子进程正在执行命令时，父进程会 sleep [实现为 `sleep()` 系统调用]。当进程处于睡眠状态时，它不占用任何计算机时间；它保持空闲状态，等待唤醒。当进程完成命令执行时，它会通过其退出状态告诉父进程其成功或失败，然后父进程（在 shell 中运行）会被唤醒并提示另一个命令。

后台进程：当你通过在命令末尾加上和符号 (&) 在后台运行一个进程时，shell 会 fork 一个进程而不会进入睡眠等待子进程运行完成。正在执行 shell 的父进程会报告子进程的任务号和 PID，并提示另一个命令。子进程在后台运行，独立于父进程。

内置命令：尽管 shell 会 fork 进程来运行你提供的多数命令，但某些命令是内置在 shell 中的。shell 不需要 fork 进程即可运行它们。更多信息请参阅第 261 页的“内置命令”（Builtins）。

变量：在进程内部（例如你的登录 shell 或子 shell）中，你可以声明、初始化和更改变量。但默认，变量是进程局部的。当进程 fork 子进程时，父进程不会将变量的值传递给子进程。你可以使用 `export` 内置命令 (992) 使变量值对子进程可用（全局）。

# 历史记录

历史机制是一种适配自 C Shell 的功能，维护了一个最近使用的命令行列表（也称为事件），提供了一种快速重新执行列表中任何事件的快捷方法。该机制还允许你执行以前命令的变体，并复用它们的参数。你可以使用历史列表来复制之前在登录会话或之前的会话中使用过的复杂命令和参数，并输入它们。你可以使用历史列表来重复制你之前在登录会话或之前的会话中使用过的复杂命令和参数。参阅第 995 页的 $$: PID Number 了解如何指示 shell 报告 PID 号。
