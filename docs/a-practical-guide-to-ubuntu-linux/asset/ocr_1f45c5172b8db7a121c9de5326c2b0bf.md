The iSCSI (page 1155) selects a partition on a remote system.

To create a partition table, highlight the disk you want to create partition table on and press RETURN. The installer asks if you want to create a new partition table on the device and warns that doing so will destroy all data on the disk. Highlight Yes and press RETURN. The installer displays the Partition overview screen showing the disk with a single block of free space as large as the disk (see Figure 3-29). The Partition overview screen displays additional choices because the hard now has a partition table.

Creating a partition To create a partition, highlight the line containing words **FREE SPACE** and press RETURN. The partition editor asks you how to use the free space; highlight **Create new partition** and press RETURN. The partition editor asks you to specify the size of the new partition. You can enter a percentage (e.g., 50%) or a number of gigabytes by **GB** (e.g., 30 GB). Press RETURN. The partition editor asks you to specify the type of the new partition (primary or logical; page 34) and asks whether you want to create the partition at the beginning or the end of the free space. It does not matter where you create the partition. After answering each of these questions, press RETURN. The partition editor displays the Partition settings (see Figure 3-30).
