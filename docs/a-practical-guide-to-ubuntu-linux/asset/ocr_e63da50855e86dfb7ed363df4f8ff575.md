# lsUsb: LISTS USB DEVICES

The lsusb utility displays information about USB buses and USB devices. Use the -v (--verbose) option to display additional information.

```
$ lsusb
Bus 002 Device 0005: ID 04f9:0033 Brother Industries, Ltd
Bus 002 Device 0004: ID 051d:0002 American Power Conversion Uninterruptible Power Supply
Bus 002 Device 0003: ID 045e:000dd Microsoft Corp.
Bus 002 Device 0002: ID 046d:c018 Logitech, Inc.
```

# CONFIGURING THE SYSTEMS

Once the hardware is in place, you need to configure each system so it knows about the NIC that connects it to the network. Normally Ubuntu detects and configures new hardware automatically when you install Ubuntu or the first time you boot the system after installing a NIC. You can use nm-connection-editor (page 643) to augment the information Ubuntu.
