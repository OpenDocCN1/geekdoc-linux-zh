set owner/mode for '.?' [yn]

Answer y to this prompt when you are restoring entire filesystems or files that have been accidentally removed. Doing so will restore the appropriate permissions to the files and directories being restored. Answer n if you are restoring a dump to a directory other than the one it dumped. owner will then be set to those of the user doing the restore (typically root).

A variety of device names can access the /dev/st0. Each name accesses a different device number that controls some aspect of how the tape drive is used. After you complete a dump using /dev/st0, the tape drive automatically rewinds the tape. Use the nonrewinding SCSI tape device (/dev/nst0) to keep the tape rewinding on completion. This feature allows you to back up multiple filesystems to the same volume.

Following is an example of backing up a system where the /home, /usr, and /var directories reside on different filesystems:

```
$ dump -ouf /dev/nst0 /home
$ dump -ouf /dev/nst0 /usr
$ dump -ouf /dev/st0 /var
```

The preceding example uses the nonrewinding device for the first two dumps. If you are using the rewinding device, the tape rewinds after each dump, and you are left with only the last dump on the tape.

You can use mt (magnetic tape), which is part of the cio package, to manipulate files on a multivariable dump tape. The following mt command positions the tape (fsf 2 instructs mt to skip past two files, leaving the tape at the start of the third file). The restore command restores the /var filesystem from the previous example:

```
$ mt -f /dev/st0 fsf 2
$ dump restore rf /dev/st0
```

It is a good practice to schedule certain tasks to run automatically. For example, you may want to remove old core files once a week, summarize accounting data daily, and rotate system log files monthly.

# cron AND anacron: SCHEDULE ROUTINE TASKS

The cron daemon executes scheduled commands periodically. This daemon can execute commands at specific times on systems that are always running. The anacron utility executes scheduled commands when it is called. It works well on laptops and other systems that are not all on the time. The anacron init script, calls anacron, will not run commands when a system is running on batteries (i.e., not on AC).
