# 1164 GLOSSARY

# packet

A unit of data sent across a network. Packet is a generic term used to describe a unit of data at any layer of the OSI protocol stack, but it is most correctly used to describe network or application layer (page 380) data units (“application protocol unit, APDU”). See also frame (page 1149) and datagram (page 1144).

# packet filtering

A technique to use block network traffic based on specified criteria, such as the origin, destination, or type of packet. See also firewall (page 1148).

# packet sniper

A program or device that monitors packets on a network. Sniff on page 1173.

# pager

A utility that allows you to view a file screen at a time (for example, less and more).

# paging

The process by which virtual memory is maintained by the operating system. The contents of process memory is moved (paged out) to the swap space (page 1175) as needed to make room for other processes.

# PAM

Linux-PAM or Linux-Pluggable Authentication Modules. These modules allow a system administrator to determine how various applications authenticate users. Refer to “PAM” on page 478.

# parent process

A process that forks other processes. See process (page 1166) and child process (page 1140).

# partition

A section of a (hard) disk that has a name you can address it separately from other sections. A disk partition can hold a filesystem or another structure, such as the swap area. Under DOS and Windows, partitions (and sometimes disks) are labeled C:, D;, and so on. Also disk partition and slice.

# PASV FTP

Allows FTP to work by allowing the flow of data to be initiated and controlled by the client FTP program instead of the server. Also called PASV FTP because it uses the PASV command.

# passphrase

A string of words and characters that you type in authenticate yourself. A passphrase differs from a password in length. A passphrase is usually short—6 to 10 characters. The greater length is much longer—up to 100 characters or more. The greater length makes a passphrase harder to guess or reproduce a password and therefore more secure.

# password

To prevent unauthorized access to a user’s account, an arbitrary string of characters chosen by the user or system administrator used to authenticate the user when logging in. See also passphrase.

# PAS FTP

See passive FTP.

# pathname

A list of directories separated by slashes (/) and ending with the name of a file, can be a directory. A pathname is used to trace a path through the file structure to locate or identify a file.

# pathname, last element of a

The part of a pathname following the first /, or the whole filename if there is no /. A simple filename. Also basename.

# pathname element

One of the filenames that forms a pathname.
