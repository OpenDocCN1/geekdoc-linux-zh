# Recovery rescue modes

Recovery mode is the new name for what was formerly single-user mode. When you bring a system up in recovery mode, Ubuntu boots from the hard disk and displays the pseudographical Recovery menu. This section explains how to bring a system up to recover mode.

When you bring a system up to rescue a broken system, Ubuntu boots from a Server CD, an Alternate CD, or a DVD as explained on page 83 and select Rescue a broken system from the Ubuntu boot menu. Ubuntu displays the pseudographical Rescue menu (Figure 3-24, page 84).
