# CHAPTER SUMMARY

OpenSSH is a suite of secure network connectivity tools that encrypt all traffic, including passwords, helping to thwart malicious users who might eavesdrop, hijack connections, and steal passwords. The components discussed in this chapter are ssh (the server daemon), ssh (runs a command or logs in on another system), scp (copies files to and from another system), sftp (securely replaces ftp), and ssh-keygen (creates, manages, and converts authentication keys).

To ensure secure communications, when an OpenSSH client opens a connection, it verifies that it is connected to the correct server. Then OpenSSH encrypts communication between the systems. Finally OpenSSH makes sure that the user is authorized to log in or copy files to from the server. You can secure many protocols—including POP, X, IMAP, and WWW—by tunneling them through ssh.

OpenSSH also enables secure X11 forwarding. With this feature, you can run securely a graphical program on a remote system and have the display appear on the local system.
