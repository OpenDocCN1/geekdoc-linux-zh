# WORKING WITH exim4 MESSAGES 721

```
tail -3 /var/log/exim4/mainlog
2010-07-19 23:13:12 1IB1jk-0000t8t-8L <= zachs@example.com U=sam P=local S=304
2010-07-19 23:13:17 1IB1jk-0000t8t-8L = zachs@example.com R=dnslookup T=remote_smtp
H=filter.mx.meer.net [64.13.141.12]
2010-07-19 23:13:17 1IB1jk-0000t8t-8L Completed
```

The next entry on each line except the Completed is a two-character status flag that tells you which kind of event line describes:

+   < Received a message
=> Delivered message normally
-> Delivered message normally to an additional address (same delivery)
* Did not deliver because of -N command-line option
** Did not deliver because the address bounced
== Did not deliver of of temporary failure

Information following the flag is preceded by one of the following letters, which indicates the type of information, and an equal sign:

+   H Name of remote system (host)
U Username of the user who sent the message
P Protocol used to receive the message
R Router used to process the message
T Transport used to process the message
S Size of the message in bytes

The first line in the example indicates that exim4 received a 304-byte message to zachs@example.com from sam on the local system. The next line indicates that exim4 looked up the address using DNS (dnslookup) and delivered it to the SMTP server (remote_smtp) at filter.mx.meer.net, which has an IP address of 64.13.141.12.

The following log entries describe a message that exim4 received from a remote system and delivered to the local system:

```
2010-07-19 23:13:32 1IB1k-0000lt-8L <= zachs@gmail.com H=wx-out-0506.google.com
[66.249.82.229] P=smtp S=1913 ID=715425d5db007192312y3930a2b27y3f... @mail.gmail.com
2010-07-19 23:13:32 1IB1k-0000lt-8L => sams@example.com R=local_user T=mail_spool
2010-07-19 23:13:32 1IB1k-0000lt-8L Completed
```

See the exim4 specification for more information on log files. If you send and receive a lot of email, the mail can grow quite large. The logrotate (page 622) exim4-base file archives and rotates these files regularly.
