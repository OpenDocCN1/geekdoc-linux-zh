If you are unable to solve a problem yourself, a thoughtful question to an appropriate newsgroup (page 1103) or mailing list (page 1103) can elicit useful information. When you send or post a question, make sure you describe the problem and identify the local system architecture carefully. Include the version numbers of Ubuntu Linux and any packages that relate to the problem. Describe the hardware, if appropriate. There is an entropy to posting questions—see www.catb.org/faq/smart-questions.html for a good paper by Eric S. Raymond and Rick Moen “How To Ask Questions the Smart Way.”

The author’s home page (www.sobell.com) contains corrections to this book, answers to selected chapter exercises, and pointers to other sites.

# LINUX NEWSGROUPS

One of the ways of getting specific information is through a newsgroup (refer to “Usenet” on page 407). You can often find the answer to a question by reading postings to the newsgroup. Try using Google Groups (groups.google.com) to search through newsgroups to see whether the question has already been asked and answered. Or open a newsreader program and subscribe to appropriate groups. If necessary, you can post a question for someone to answer. Before you do, make sure you are posting to the correct group and that your question has not already answered.

The newsgroup comp.os.linux.answers provides postings of solutions to common problems and periodic postings of the most up-to-date versions of FAQ and HOWTO documents. The comp.os.linux.misc newsgroup has answers to miscellaneous Linux-related questions.

# MAILING LISTS

Subscribing to a mailing list (page 733) allows you to participate in an electronic discussion. With most lists, you can send and receive email to a specific topic and from a group of users. Moderated lists do not tend to stray as much as unmoderated lists, assuming the list has a good moderator. The disadvantage of a moderated list is that some discussions may be cut off when they get interesting if the moderator deems that the discussion has gone on too far. Mailing lists described as bulletins are strictly undirectional: You cannot post information to these lists but are can only receive periodic bulletins. If you have the subscription address for a mailing list but are not sure how to subscribe, use the word help in the body and/or header of email you send to the address. You will usually receive instructions via return email. Ubuntu hosts several mailing lists; go to lists.ubuntu.com for more information. You can also use a search engine to search for mailing list linux.
