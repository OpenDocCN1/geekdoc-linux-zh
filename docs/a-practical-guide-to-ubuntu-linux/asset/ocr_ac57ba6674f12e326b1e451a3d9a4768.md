# DELETING TEXT

x (Delete character) You can delete a single character by moving the cursor until it is the character dw (Delete word) you want to delete and giving the command x. You can delete a word by positioning the cursor dd (Delete line) on the first letter of the word and giving the command dw (Delete word). You can delete a line of text by moving the cursor until it is anywhere on the line and giving the command dd.

# UNDOING MISTAKES

u (Undo) If you delete a character, line, or word by mistake or give any command you want to reverse, give the command u (Undo) immediately after the command you undo. The vim editor will restore the text to the way it was before you gave the last command. If you give the u command again, vim will undo the command you gave before the one you just und. You can use this technique to back up over many of your actions. With the compatible parameter (page 193), however, vim can undo the most recent change.

r (Redo) If you undo a command you did not mean to, give a Redo command: CTRL-R or r (followed by a RETURN). The vim editor will redo the undo. With the Undo command, you can get the Redo command many times in a row.

# ENTERING ADDITIONAL TEXT

i (Insert) When you want to insert new text within existing text, the cursor so it is the character that follows the new text you want to enter. Give it the i (Insert) command to put vim in Input mode, enter the new text, and press ESC to return to Command mode. Alternatively, you can position the cursor on the character that precedes the new text and use a a (Append) command.

o (Open) To enter one or more lines, position the cursor on the line where you want the new text to go. Give the command o (Open). The vim editor opens a blank line below the line the cursor was, puts the cursor on the new, empty line, and goes into Input mode. Enter the new text, ending each line with a RETURN. When you are finished entering text, press ESC to return to Command mode. The command works in the same way o works, except it opens a blank line before the cursor is.

# CORRECTING TEXT

To correct text, use dd, dw, or x to remove the incorrect text. Then use i, a, o, or O to insert the correct text.

For example, change the word pressing by hitting in Figure 5-19 on page 190, you might use the ARROW keys to move the cursor until it is on top of the p in pressing-ing. Give the command dw to delete the word pressing. Put vim in Input mode by giving an i, enter the word hitting followed by a SPACE, and press ESC. The word is changed and vim is in Command mode, waiting for another command. A shorthand for the two commands dw followed by a i if the i is (Change word). The command cw puts vim into Input mode.
