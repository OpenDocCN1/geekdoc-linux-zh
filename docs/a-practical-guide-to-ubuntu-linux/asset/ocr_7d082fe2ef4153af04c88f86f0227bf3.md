On a client, enable X11 forwarding by the ForwardX11 (default is no; see page 675) and ForwardX11Trusted (default is no, but set to as installed; see page 675) declarations to use in the /etc/ssh/ssh_config or ~/.ssh/ssh_config file.

When you enable X11 forwarding on a client, the client connects as a trusted client, which means the client serves is given full access to the X11 display. With full access to the X11 display, in some situations a client may be able to modify other clients of the X11 display. Make a trusted connection only when you run the remote system (You do not want someone tampering with your client.). If this concept is confusing, see the tip "Roles of X client and server may be counterintuitive" on page 269.

An ssh client can connect to an ssh server as a trusted or an untrusted client. A untrusted client is given limited access to the X11 display and cannot modify other clients of the X11 display.

Few clients work properly when they run in untrusted mode. If you are running an X11 client in untrusted mode and encounter problems, try running in trusted (assuming you run the remote system). Ubuntu Linux sets up ssh clients to run in untrusted mode by default.

When you start an ssh client, you can use the -Y option (page 672) on the command line to start the client in trusted mode. Alternatively, you can set the ForwardX11 and ForwardX11Trusted declarations to use in a user's ~/.ssh/ssh_config file (page 675), or working with root privileges, in the global /etc/ssh/ssh_config file (page 675) on the client to enable trusted X11 tunneling.

To use untrusted, you can use the -X option (page 672) or set the ForwardX11 declaration to yes and set the ForwardX11Trusted declaration to no in one of the configuration files (page 675) on the server.

With X11 forwarding turned on, on ssh tunnels the X11 protocol, setting the DISPLAY environment variable on the system it connects to and forwarding the required port. Typically you will be running from a GUI, which usually means that you are using ssh on a terminal emulator to connect to a remote system. When you give an X11 command from an ssh prompt, OpenSSH creates a secure channel that carries the X11 data and the graphical output from the X11 program appears on the screen. Typically you will need to start the client in trusted.

```
$sam@dog:~ ssh plum
$sam@plum:~ echo DISPLAY
localhost:10.0
```
