# IMPLICIT MATCH EXTENSIONS

Help Implicit extensions are loaded (somewhat) automatically when you use a --protocol command (described below). Each protocol has its own extensions. Follow the protocol with -h to display extensions you can use with that protocol. For example, the following command displays TCP extensions at the end of the Output:

```
$ iptables -p tcp -h
...
tcp match options: match when TCP flags & mask == comp
--tcp-flags [!] match comp (Flags: SYN ACK FIN RST RST PSH ALL NONE)
[!] --syn match only when SYN flag set (equivalent to --tcp-flags SYN, RST, ACK SYN)
--source-port [!][port]: match source port(s)
--sport --
--destination-port [!][port]: match destination port(s)
--dport --
--tcp-option [!] number match if TCP option set
```

This section does not describe all extensions. Use -h, as in the preceding example, to display a complete list.

--protocol [!] -p Loads the proto module and matches if the packet uses the proto protocol. The proto can be a name or number from /etc/protocols, including tcp, udp, and icmp (page 1153). Specifying all or 0 (zero) matches all protocols and is the same as not including this in a rule.

The criteria load the TCP module and match TCP protocol packets coming from port 22 (ssh packets):

```
--tcp tcp --source-port 22
```

The following command expands the preceding match to cause the kernel to drop all incoming ssh packets. This command uses ssh, which iptables looks up in /etc/services, in place of 22:

```
$ sudo iptables --protocol tcp --source-port ssh --drop
```
