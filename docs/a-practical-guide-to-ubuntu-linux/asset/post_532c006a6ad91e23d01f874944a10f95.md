
If you want to delete the entire command line, type the kill character (page 151). You can type this character while the cursor is anywhere in the command line. If you want to delete from the cursor to the end of the line, press CONTROL-K.

## READLINE COMPLETION

You can use the TAB key to complete words you are entering on the command line. This facility works in both vi and emacs modes. Several types of completion are possible, and which one you use depends on which part of the command you are typing.

### COMMAND COMPLETION

If you are typing the name of a command (usually the first word on the command line), TAB initiates completion in which bash looks for a command whose name starts with the part of word you have typed. If no command starts with the characters, bash beeps. If there is one command, bash completes the name. If there is more than one choice, bash does nothing. Pressing TAB a second time causes bash to display a list of commands whose names start with the prefix you typed. In this example, the user types b and the shell beeps (the user in emacs mode) enters another TAB to cause the shell to display a list of commands that start with b followed by the command line as the user entered so far:

```
$ b
(beep)
TAB
cat
less
grep
more
$ bc
```

The next user types c and presses TAB. The shell displays the two commands that start with bc. The user follows this with TAB. At this point the shell completes the command because only one command starts with bc:

```
$ bc
(beep)
TAB
$ less
```

### PATHNAME COMPLETION

Pathname completion, which also uses TAB, allows you to type a portion of a pathname and have bash supply the rest. If the portion of the pathname you have typed is sufficient to determine a unique pathname, bash displays the pathname. If more than one pathname would match, bash completes the pathname to the point where there are choices. When you are entering a pathname including a filename and press TAB, the shell beeps (if the shell is in emacs mode—in vi mode there is no beep). It extends the command line as far as it can:

```
$ /
(beep)
TAB
/
```

Every file that starts with / as the next characters, bash cannot extend the line further without making a choice among files. The shell leaves the cursor just past the character. At this point you can continue typing the pathname or press TAB twice. In the case of ambiguity, bash displays your choices, redisplays the command line, and again leaves the cursor just after the character:

```
$ /usr
(beep)
TAB
/usr/
```

To distinguish between the two possible files and press TAB, bash displays the unique pathname. If you enter p followed by TAB, the shell completes the command:

```
$ /usr/p
/usr/bin
```

### VARIABLE COMPLETION

When you are typing a variable name, pressing TAB results in variable completion wherein bash attempts to complete the name. In case of ambiguity, pressing TAB twice displays a list of choices:

```
$ echo $
HOME
HOSTTYPE
$ echo $HOME
```

## Pressing RETURN executes the command

Pressing RETURN causes the shell to execute the command regardless of where the cursor is on the command line.

## .inputrc: CONFIGURING THE READLINE LIBRARY

The Bourne Again Shell and other programs that use the Readline Library read the file specified by the INPUTRC environment variable to obtain initialization information. If INPUTRC is not set, these programs read ~/.inputrc file. They ignore .inputrc files that are blank or start with a hash (#).

## VARIABLES

You can set variables in .inputrc to control the behavior of the Readline Library using the following syntax:

```
set variable value
```

Table 9-1 (on the next page) lists some variables and values you can use. See Readline Variables in the bash man or info page for a complete list.

| Variable | Effect |
| :--- | :--- |
| editing-mode | Set to vi to start Readline in vi mode. Set to emacs to start Readline in emacs mode (the default). Similar to the set-vi and set-o emacs commands (page 340). |
| horizontal-scroll-mode | Set to on to cause long lines to extend off the right edge of the display area. ## KEY BINDINGS

You can specify bindings that map keystroke sequences to Readline commands, allowing you to change or extend the default bindings. Like the emacs editor, the Readline Library includes many commands that are not bound to a keystroke sequence. To use an unbound command, you must map it using one of the following forms:

```
keyname: command_name
```

```
"keystroke_sequence": command_name
```

In the first form, spell the name for a single key. For example, CONTROL-U would be written control-u. This form is useful for binding commands to single keys.

In the second form, specify a string that describes a sequence of keys that will be bound to the command. You can use the emacs-style backslash escape sequences to represent the special keys CONTROL (C), META (M), and ESCAPE (e). Specify a backslash by escaping it with another backslash: \\. Similarly, a single or double quote mark can be escaped with a backslash: \" or \'.

The kill-whole-line command, available in emacs mode, deletes the current line. Use the following to determine which key sequence is bound:

```
$ q kill-whole-line
kill-whole-line can be invoked via "\C-r".
```
