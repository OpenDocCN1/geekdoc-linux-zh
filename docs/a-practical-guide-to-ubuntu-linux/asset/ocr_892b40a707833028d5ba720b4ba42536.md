# 186 CHAPTER 5 THE LINUX UTILITIES

Many email programs are available for Linux, including the original character-based mail program, Mozilla/Thunderbird, pine, mail through emacs, KMail, and evolution. Another popular graphical email program is sylphed (sylphed.good-day.net).

Two programs are available that can make any email program easier to use and more secure. The procmail program (procmail.com) creates and maintains email servers and mailing lists; preprocesses email by sorting it into appropriate files and directories; starts various programs depending on the characteristics of incom-ing; forwards; and so on. The GNU Privacy Guard (GPG or GnuPG, page 1113) encrypts and decrypts email and makes it almost impossible for unauthorized person to read.

Refer to Chapter 20 for more information on setting email clients and servers.

Network addresses If the local system is part of a LAN, you can generally send email to receive email from users on other systems on the LAN by using their usernames. # TUTORIAL: USING vim TO CREATE AND EDIT A FILE

This section explains how to start vim, enter text, move the cursor, correct text, save the file to the disk, and exit from vim. The tutorial discusses three of the modes of operation and explains how to switch from one mode to another.

vimutor In addition to this tutorial, you may want to try vim's instructional program, named vimutor. Give its name as a command to run it.

vimutor and vim help are not installed by default

tip To run vimutor and get help as described on page 190, you must install the vim-runtime package; give the command sudo aptitude vim-runtime to install this package.

Specifying a terminal Because you take advantage of features that are specific to various kinds of terminals, you must tell what type of terminal or terminal emulator you are using. On many systems, and usually when working on a terminal, your terminal type is set automatically. If you need to specify your terminal type explicitly, refer to “Specifying a Terminal” on page 1106.

# Starting vim

Start vim with the following command to create and edit a file named practice:

```
$ vim practice
```

When you press RETURN, the command line disappears, and the screen looks similar to the one shown in Figure 5-16.

The tilde (~) at the left of the file indicate that the file is empty. They disappear as you add lines of text to the file. If your screen looks like a distorted version of the one shown in Figure 5-16, your terminal type is probably not set correctly.
