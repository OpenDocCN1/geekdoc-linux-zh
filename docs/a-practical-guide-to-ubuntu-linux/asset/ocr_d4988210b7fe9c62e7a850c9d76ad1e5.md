Move around: Use the cursor, or "h" to go left,
"j" to go down, "k" to go up, "l" to go right.
Close window: Use "<Esc>"
Get out of vim: Use "<q>" (careful, all changes are lost!).

Jump to a subject: Position the cursor on a tag (e.g. |bars|) and hit CTRL-\.
"set mouse" to enable the mouse (in xterm or GUI).
Double-click the mouse button on a tag, e.g. |bars|.
Jump back: Type CTRL-T or CTRL-O (to repeat back).

Get help: It is possible to go directly to whatever you want
in, by giving an argument to the :help command.
It is possible to further search the context:

```
*help-context*
PREPEND  EXAMPLE
Normal mode command
(nothing) :help x
```

# MOVING THE CURSOR

You need to be able to move the cursor on the screen so that you can delete,
in, and insert text. While vim is in Command mode, you can use the RETURN
key, the space bar, and the ARROW keys to move the cursor. If you prefer to use the
hand to the center of the keyboard, if your terminal does not have arrow
keys, or if the emulator you are using do not support them, you can use the h,
j, k, and l (lowercase "l") keys to move the cursor left, down, and right,
respectively.

```
<Insert> or *Insert* *<Insert>
Insert text before the cursor [times].
using CTRL-o in insert mode | CTRL-o the count
is not supported.
```

```
*I* Insert text before the first non-blank in the line
[times].
when the q flag is present in 'options' and the
line only contains blanks, start just before
the last line.
```

```
*gt* Insert text in column 1 [times]. (not in vi)
```

```
*gi* Insert text in the same position as Insert mode
was stopped last time in the current buffer.
This undo the mark is different from "i"
when the marker is past the end of the line.
```
