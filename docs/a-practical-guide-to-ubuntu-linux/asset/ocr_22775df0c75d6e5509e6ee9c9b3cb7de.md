# SysVinit(rc) Scripts: Start and Stop System Scripts

the init (initialization) scripts, also called rc (run command) scripts, are shell scripts located in the /etc/init.d directory. They are run symbolic links in the /etc/rc.n directories, where n is the runlevel the system is entering.

# Most of the files in the /etc/rc.d and /etc/init.d directories will go away

On page 434, Ubuntu emulates runlevels using Up to migrate and provide compatibility with software for other distributions. This section explains how init scripts work (emulated) runlevels to control system services. Many of the scripts in the /etc/rc.d and /etc/init.d directories described in this section suggest you use the corresponding initctl commands in these directories have been replaced by job control files in /etc/init.d (page 434).

The /etc/rc.d directories contain scripts whose names begin with K (K19cusys, K20dhcp, K7bluetooth, and so) and whose names begin with S (S15bind, S18inis, S20shim, and so on). When entering a runlevel, each K (kill) script is executed with an argument of stop, and each S (start) script is executed with an argument of start. Each of the K files is in numerical order. The S files are in similar fashion. This arrangement allows the person sets up files to control which services are started, and stopped, and in what order, when the system enters a runlevel. Using scripts with start and stop arguments promotes flexibility because it allows one script to start both and kill a process, depending on which argument it is called.

To customize system initialization, you can add scripts to the /etc/init.d directory and place links to these files in the /etc/rc.d directories (although in practice it is better to use sysrc-conf [discussed here] to create the links).

The following example shows links to the cups script. These are linked by the run script to start or stop the cups daemons at various runlevels:

```
$ ls -1 /etc/rc.d/*.cups$
1rwxr-wx root 1 root 2010-02-26 10:19 /etc/rc.1/K80cups -> ../init/cups
1rwxr-wx root 1 root 2010-02-26 10:19 /etc/rc.2/S50cups -> ../init/cups
1rwxr-wx root 1 root 2010-02-26 10:19 /etc/rc.3/S50cups -> ../init/cups
1rwxr-wx root 1 root 2010-02-26 10:19 /etc/rc.4/S50cups -> ../init/cups
1rwxr-wx root 1 root 2010-02-26 10:19 /etc/rc.5/S50cups -> ../init/cups
```

Each link in /etc/rc.d points to a file in /etc/init.d. For example, the /etc/rc.2/S50cups is a link to the file named cups in /etc/init.d. The filenames of the links in the /etc/rc.d directories may change from one release of Ubuntu to the next, but the scripts in /etc/init.d always have the same names.
