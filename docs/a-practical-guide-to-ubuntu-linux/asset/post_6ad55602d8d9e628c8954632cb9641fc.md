# vim is not installed by default: use vim.tiny

The full version of the vim editor is not installed by default. Instead, a small version of vim, named vim.tiny is installed. You can either replace each vim command in this section with vim.tiny, or you can install the full vim editor by giving the command sudo aptitude install vim and then use the vim command as shown in this section.

# The vi command runs vim

On Ubuntu Linux systems the command vi runs vim in vi-compatible mode (page 193).

If you start with a terminal type that is not in the terminfo database, vim displays an error message and the terminal type defaults to ansi terminals. In the following example, the user mistyped vt100 and set the terminal type to vg100:

```
E558: Terminal entry not found in terminfo
'vg100' not known. Available builtin terminals are:
builtin_ansi
builtin_xterm
builtin_iris-ansi
builtin_dumb
defaulting to 'ansi'
```

To reset the terminal type, press ESCAPE and then give the following command to exit from vim and display the shell prompt:

:q!

When you enter the colon (:), vim moves the cursor to the bottom line of the screen. The characters q tell you vim to quit without saving your work. (You will not ordinarily exit from vim this way because you typically want to save your work.) You must RETURN after you give this command. Once you get the shell prompt back, refer to “Specifying a Terminal” on page 1106, and then start vim again.

If you start editor without a filename, vim assumes that you are a novice and tells you how to get started (Figure 5-17).

The practice file is new so that it does not contain any text. The vim editor displays a message similar to the one shown in Figure 5-16 on the status (bottom) line of the terminal to indicate that you are creating and editing a new file. When you edit an existing file, vim displays the first few lines of the file and gives status information about the file on the status line.

# COMMAND AND INPUT MODES

Two of vim's modes of operation are Command mode (also called Normal mode) and Input mode (Figure 5-18). While vim is in Command mode, you can give vim commands. For example, you can delete text or exit from vim. You can also command vim to enter Input mode. In Input mode, vim accepts anything you enter and displays it on the screen. Press ESCAPE to return vim to Command mode. By default the vim editor keeps you informed about which mode it is in: It displays INSERT at the lower-left corner of the screen while it is in Insert mode.

The following command causes vim to display line numbers to the text you are

```
:set number RETURN
```

### Last Line mode The colon (:) in the preceding command puts vim into another mode, Last Line mode. While in this mode, vim keeps the cursor on the bottom line of the screen. When finishing the command by pressing RETURN, vim restores the cursor to its place in the text. Give the command :set nonumber RETURN to turn off line numbers.

vim is case sensitive. When you give vim a command, remember that the editor is case sensitive; vim interprets the same letter as two different commands, depending on whether you enter an uppercase or lowercase character. Beware of the CAPS LOCK (SHIF-TLOCK) key. If you set this key to enter uppercase while you are in Input mode and then exit to Command mode, vim interprets your commands as uppercase letters. It can be confusing when this happens because vim does not appear to be executing the commands you are entering.

# ENTERING TEXT

### i/a (Input mode) When you start, you must put it in Input mode before you can enter text. To put vim in Input mode, press the i (insert cursor) or the a (append after cursor) key.

If you are not sure whether vim is in Input mode, press the ESCAPE key; vim returns to Command mode if it was in Input mode or beeps, flashes, or does nothing if it is already in Command mode. You can put vim back in Input mode by pressing the i or a key.

While vim is in Input mode, you can enter text by pressing the keyboard. The text does not appear on the screen as you type, vim is not in Input mode.

To continue with this tutorial, enter the sample paragraph shown in Figure 5-19 (next page), pressing the RETURN key at each end of line. If you do not return before the cursor reaches the right of the screen or window, vim wraps the text so that it starts a new line. Physical lines will not correspond to programming (logical) lines in this, so editing will be more difficult. While you are using vim, you can always correct any typing mistakes you make. If you notice a mistake on the line you are entering, you can correct it before you finish (page 190). You can correct other mistakes later. When you finish the paragraph, press ESCAPE to return vim to Command mode.

If you are not sure whether vim is in Input mode, press the ESCAPE key; vim returns to Command mode if it was in Input mode or beeps, or does nothing if it is already in Command mode. You can put vim back in Input mode by pressing the i or a key.

# GETTING HELP

You must have vim-runtime package installed to use vim's help system; see the tip on page 186. To get help while you are using vim, give the command :help [feature] followed by RETURN (you must be in Command mode when you give this command). It moves the cursor to the last line of the screen. If you type :help, vim displays an introduction to vim (Figure 5-20). Each dark band near the bottom of the screen, such as the two areas shown in Figure 5-20, occupies most of the screen (the upper window). The file that is being edited (practice) occupies a few lines in the lower portion of the screen (the lower window). Read through the introduction to Help by scrolling the text as you read. Press j or DOWN arrow to move the cursor down one line at a time; press CONTROL-D or CONTROL-U to scroll the cursor up or half at a time. Give the command :q to close Help window. You can display information about insert commands by giving the command help while vim is in Command mode (Figure 5-21).

# CORRECTING TEXT AS YOU INSERT IT

The keys that back up and correct line serve the same functions when vim is in insert mode. These keys include erase, erase line, and word (usually CONTROL-H, CONTROL-U, and CONTROL-W, respectively). Although vim may not remove deleted text from the screen as you back up it using one of these keys, the editor removes it when you type over it or press RETURN.

# MOVING THE CURSOR

You need to be able to move the cursor on the screen so that you can delete, in, and insert text. While vim is in Command mode, you can use the RETURN key, the space bar, and the ARROW keys to move the cursor. If you prefer to use the hand to the center of the keyboard, if your terminal does not have arrow keys, or if the emulator you are using do not support them, you can use the h, j, k, and l (lowercase "l") keys to move the cursor left, down, and right, respectively.
