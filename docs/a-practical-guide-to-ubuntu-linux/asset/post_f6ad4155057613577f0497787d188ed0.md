Ubuntu runs the GNOME desktop manager (Figure 1-3; gnome.org) by default, but it can also run KDE (kde.kde.org) and a number of other desktop managers.

A window manager is a program that runs the desktop manager and allows you to open and close windows, run programs, and set up a mouse effects depending on how and where you click. The window manager also gives the screen personality. Whereas Microsoft Windows allows you to change the color of key elements in a window manager, under X allows you to customize the overall look and feel of the screen: You can change the way a window looks and works (by giving different borders, buttons, and scrollbars), set up virtual desktops, create menus, and more.

Several window managers run under X and Linux. Ubuntu Linux provides both Metacity (the default under GNOME) and kwin (the default under KDE). Other window managers, such as Sawfish and WindowMaker, are also available. Chapters 4 and 8 present information on GUIs.

# (INTER)NETWORKING UTILITIES

Linux network support includes many utilities that enable you to access systems over a variety of networks. In addition to sending email you can access files on disks mounted on other computers as if they were located on the local system, manage your files available to other systems in a similar manner, copy files back and forth, run programs on remote systems while displaying the results on the local system, and perform many other operations across local area networks (LANs) and wide area networks (WANs), including the Internet.

Layered on top of this network access is a wide range of application programs that extend the computer's resources around the globe. You can carry on conversations with people, gather information on a wide variety of subjects,

# SOFTWARE DEVELOPMENT

One of Linux's most impressive strengths is its rich software development environment. Linux supports compilers and interpreters for many computer languages. Besides C and C++ languages available for Linux include Ada, Fortran, Java, Lisp, Pascal, Perl, and Python. The bison utility generates parsing that makes it easier to write build compilers (that parse files containing structured information). The flex utility generates scanners (code that recognizes lexical patterns in text). The make utility and the GNU Compiler and Build System make it easier to manage complex development projects. Source code management systems, such as CVS, simple version control. Several debuggers, including pcs and gdb, can help you track down and repair software defects. The GNU C compiler (gcc) works with the gprof profiling utility to help programmers identify potential bottlenecks in a program performance. The C compiler includes options to perform extensive checking of C code, making the code more portable and reducing debugging time. # CONVENTIONS USED IN THIS BOOK

This book uses conventions to make its explanations shorter and clearer. The following paragraphs describe these conventions.

- **Widgets**: A widget is a simple graphical element that a user interacts with, such as a text box, radio button, or combo box. When referring to a widget, this book specifies the type of widget and its label. The term "tick" refers to mark the you in a checkbox, sometimes called a check mark. For example, "put a tick in the check box Run in terminal." See the glossary for definitions of various widgets.

- **Tabs and frames**: Tabs allow to display sets of related information, one at a time. For example, Figure 4-12 on page 114 shows the Appearance Preferences window, which has four tabs; The Theme is highlighted. A frame isolates a set of information within a window. See Figure 14-3 on page 551 for an example.

- **Menu selection path**: The menu selection path is the name of or the location of the menu, followed by a colon, SPACE, and the menu selections separated by markers. The entire menu selection path appears in bold type. You can read Main menu: System-Preferences Appearance as "From the Main menu, select System; from System, select Preferences; and then select Appearance."

- **Text and examples**: The text is in this type, whereas examples are shown in a monospaced font (also called a fixed-width font):

```
$ C practice
```

**Keys and characters**: This book uses SMALL CAPS for three kinds of items:

- Keyboard keys, such as the space bar and the RETURN, ESCAPE, and TAB keys.
- The characters that generate, such as the spaces generated by the space bar.
- Keyboard keys that you press with the CONTROL key, such as CONTROL-D. (Even though D is an uppercase letter, you do not have to press the SHIFT key; enter CONTROL-D by holding the key down and pressing d.)

# CHAPTER SUMMARY

The Linux operating system grew out of UNIX heritage to become a popular alternative to traditional systems (that is, Windows) available for microcomputer (PC) hardware. UNIX users will find a familiar environment in Linux. Distributions of Linux contain the expected complement of UNIX utilities, contributed by programmers around the world. The Linux community is committed to the continued development of this system. Support for new microcomputer devices and features is added soon after the hardware becomes available, and the tools available on Linux continue to be refined. Given the many commercial software packages available to run on Linux platforms and the many hardware manufacturers offering Linux on their systems, it is clear that the system has evolved well beyond its origin as undergraduate project to become an operating system of choice for academic, commercial, professional, and personal use.
