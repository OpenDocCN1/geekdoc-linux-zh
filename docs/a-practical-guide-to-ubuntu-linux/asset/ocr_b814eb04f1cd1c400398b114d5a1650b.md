# WORKING WITH WINDOWS SHARES FROM LINUX

Samba enables you to view and work with files on a Windows system (client) from a Linux system (server). This section discusses several ways of accessing Windows files from Linux.

# smbtree: DISPLAYS WINDOW SHARES

The smbtree utility displays a hierarchical diagram of available shares. When you run smbtree, it prompts you for a password; do not enter a password if you want to browse shares that are visible to the guest user.
