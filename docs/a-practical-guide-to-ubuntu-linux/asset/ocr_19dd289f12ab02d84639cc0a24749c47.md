Logging Logging is turned on by the Logging clause. Logging is separate from named messages which goes to syslog. The Logging clause in the preceding example opens two logging channels: one logs information to /var/log/bind/misc.log and one that logs information to /var/log/bind/query.log. When either of these grows to 4 megabytes (size 4m in the file statement), it is renamed appending .1 to its file name and a new log is started. The numbers of these, similarly logs are incremented. Any log would have a larger number than specified by the versions keyword (4 in the example) is removed. See logrotate (page 622) for another way to maintain log files.

The print statements determine whether the time, severity, and category of information are sent to the log: specify as YES or NO. The category determines information is logged to the channel. The queries are sent to the query channel. Refer to the named.conf page for more details.

named.conf The origin for the reverse zone file (named.conf) is 0.168.192.in-addr.arpa (as specified in the Zone clause that refers to this in named.conf). Following the SOA and NS resource records, the first three PTR records equate address 1 in the subnet 0.168.192.in-addr.arpa (192.168.0.1) with names gw.sam.net., www.sam.net., and ftp.sam.net., respectively. The next three PTR records equate 192.168.0.3 with mark.sam.net., and 192.168.0.4 with mail.sam.net., and 192.168.0.6 with ns.sam.net.

```
$ /etc/bind/named.conf.local
$TTL 3D ns.sam.net. mgs@sobell.com. (
      20110501 : serial
      8H : refresh
      2H : retry
      4W : expire
      10D : minimum

      IN NS ns.sam.net.
      IN PTR gw.sam.net.
      IN PTR www.sam.net.
      IN PTR mark.sam.net.
      IN PTR mail.sam.net.
      IN PTR ns.sam.net.
```

sam.net The zone file for sam.net takes advantage of many BIND features and includes TXT (page 830), CNAME (page 828), and MX (page 828) resource records. When you query for resource records, named returns the TX record along with the records requested. The first of two NS records specify an unqualified name (ns) to BIND appends the zone name (sam.net), yielding a FQDN of ns.sam.net. The second nameserver is specified with an FQDN name that BIND does not alter. The MX records specify mail servers in a similar manner and include priority number at the start of the data where lower numbers indicate preferred servers.
