pwgen utility (the pwgen package) generates a list of almost random passwords. With a little imagination, you can pronounce, and therefore remember, some of these passwords.

# USING VIRTUAL CONSOLES

When running Linux on a personal computer, you will frequently work with the display and keyboard attached to the computer. Using this physical console, you can access as many as 63 virtual consoles (also called virtual terminals). Some are set up to allow logins; others act as graphical displays. To switch between virtual consoles, hold the CONTROL and ALT keys and press the function that corresponds to the console you want to view. For example, CONTROL-ALT-F5 displays the fifth virtual console. This book refers to the console you see when you press CONTROL-ALT-F1 as the system console, or just console.

# WORKING FROM THE COMMAND LINE

Before the introduction of the graphical user interface (GUI), UNIX and Linux provided only a command-line (textual) interface (CLI). Today, a CLI is powerful when you log in from a terminal, a textual emulator, or a textual virtual console, or when you use ssh (secure; page 667) or telnet (not; page 391) to log in a system.

This section introduces the Linux CLI. Chapter 5 describes some of the more important utilities you can use from the command line. Most of the examples in Parts IV and V of this book use the CLI, adding examples of graphical tools where available.

Advantages Although the concept may seem antiquated, the CLI has a place in modern computing. In some cases an administrator may use a command-line tool either because a graphical equivalent does not exist or because the graphical tool is not as powerful or flexible as the textual one. Frequently, on a server system, a graphical interface may not be installed. The first reason for this is that a GUI consumes a lot of system resources; on a server, those resources are better dedicated to the main task of the system. Additionally, security considerations mandate that a server system run as few tasks as possible because each additional task can make the system more vulnerable to attack.

You can also write scripts using the CLI. Using scripts, you can easily reproduce tasks on multiple systems, enabling you to scale to larger environments. When you are the administrator of only one system, using a GUI is often the easiest way to configure the system. When you act as administrator for many systems, all of which need the same configuration installed or updated, a script can make the task go more quickly. Writing a script using command-line tools is easily easy, whereas the same task can be difficult to implement using graphical tools.

Pseudographical Before the introduction of GUIs, resourceful programmers created textual interfaces that included graphical elements such as boxes, borders outlining rudimentary windows, highlights, and, more recently, color. These textual interfaces, called pseudographical interfaces, bridge the gap between textual and graphical interfaces.

One example of a modern utility that uses a pseudographical interface is the dpkg-reconfigure utility, which reconfigures an installed software package.

# CORRECTING MISTAKES

This section explains how to correct typographical and other errors you may make while you are logged in on a textual display. Because the shell and most other utilities do not interpret the command line or other text until after you press RETURN, you can readily correct your typing mistakes before you press RETURN,

You can correct such mistakes in several ways: erase one character at a time, back up a word at a time, or back up to the beginning of the command line in one step. After you press RETURN, it is too late to correct a mistake: At that point, you must either wait for the command to run to completion or abort execution of the program (page 151).

# ERASING A CHARACTER

While entering characters from the keyboard, you can back up and erase a mistake by pressing the erase key once for each character you want to delete. The erase key backs over as many characters as you wish. The default erase key is BACKSPACE. If these keys do not work, try pressing CONTROL-H.

# DELETING A WORD

On a command line, the shell replaces the characters ! with the last argument (word) of the previous command. This technique is useful if you forget to use sudo (page 421) before a command. In this case, if you use sudo !!, the shell will repeat the previous command preceded by sudo.

The command ^old^new returns the previous command, substituting the first occurrence of old with new. Also, on a command line, the shell replaces the characters ! with the last argument (word) of the previous command.

# DELETING A LINE

To delete the line, press CONTROL-U. When you press this, the cursor moves to the beginning of the line. The default delete key is CTRL-K. If these keys do not work, try CONTROL-X.

# ABORTING EXECUTION

Sometimes you may want to terminate a program. To terminate a program from a textual display, press the interrupt key (CONTROL-C or sometimes DELETE). When you press this key, the operating system sends a termination signal to the program. Exactly what effect this signal has on the program: Some programs execution immediately, ignore the signal, and some take other actions. When the shell receives a termination signal, it displays a prompt and waits for another command.

If these methods do not terminate the program, try pressing the suspend key (typically CONTROL-Z), giving jobs command to verify the number of the running program, and using kill to abort the job. The job number is the number within the brackets at the left of the line displayed by jobs ([1]). In the next example, the kill command (page 455) uses -TERM to send a termination signal to the job specified by the job number, which is preceded by a percent sign (%1).

```
$ jobs
[1]+ Stopped bigjob
$ jobs bigjob
[1]+ Stopped
$ kill -TERM %1
$ RETURN
[1]+ Killed bigjob
```

The kill command returns a prompt; press RETURN to see the confirmation message. For more information refer to "Running a Command in a Background" on page 254.

# REATING/EDITING COMMAND LINES

To repeat a previous command, press the UP ARROW key. Each time you press, the shell displays an earlier command line, press RETURN. Press the DOWN ARROW key to browse through the command lines in the other direction.
