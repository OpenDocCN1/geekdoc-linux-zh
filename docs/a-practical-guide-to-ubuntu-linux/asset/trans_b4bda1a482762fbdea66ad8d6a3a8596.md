

# 1176 术语表

符号链接（symbolic link）指向另一个文件路径的目录项。在大多数情况下，指向文件的符号链接可以像硬链接一样使用。与硬链接不同，符号链接可以跨越文件系统并连接到目录。

系统管理员（system administrator）负责维护系统的人员。系统管理员有权以 root 身份登录或使用 sudo 以 root 权限进行操作。另请参考超级用户（Superuser）。

系统控制台（system console）请参阅第 1142 页。

系统模式（system mode）系统正在执行系统工作时的状态标识。一些示例包括发出系统调用、运行 NFS 和 autofs、处理网络流量以及代表系统执行内核操作。与用户模式（user mode，第 1179 页）对比。

System V UNIX 系统的两个主要版本之一。

TC Shell tesh。BSD UNIX shell 程序 csh 的增强版且完全兼容的版本。

TCP 传输控制协议（Transmission Control Protocol，又称传输控制协议）。互联网上最常用的传输协议。这种面向连接的协议构建在 IP（第 1154 页）之上，几乎总是以 TCP/IP（IP 之上的 TCP）的形式出现。TCP 增加了可靠的通信、排序和流量控制，并提供了全双工的进程到进程的连接。UDP（第 1178 页）同样是非连接的，是运行在 IP 之上的另一种协议。

tera（太）在二进制系统中，前缀 tera- 乘以 2^40（1,099,511,627,776）。Tera 是该前缀的常用用法。缩写为 T。另请参考第 156 页的大数。

termcap 终端能力（Terminal capability）。在较旧的系统中，`/etc/termcap` 文件包含各种类型终端及其特征的列表。System V 用 terminfo 系统取代了该文件的功能。

终端（terminal）与工作站（第 1181 页）的区别在于其缺乏智能性，终端连接到运行 Linux 的计算机。工作站则运行在自身上。

termininfo 终端信息（Terminal information）。`/usr/lib/termininfo` 目录包含许多子目录，其中包含若干文件。每个文件都以特定终端的命名并存储了该终端功能特征的总结。如 vim 等视觉化程序会使用这些文件。它是 termcap 文件的替代方案。

文本框（text box）允许用户输入文本的 GUI 控件（第 1180 页）。

主题（theme）定义为一种隐式或循环的事件，在 GUI 中用于描述桌面所有元素保持一致的外观。示例参见 themes.freeheat.net。

粗缆网（thicknet）用于以太网网络的一种同轴电缆（粗）。设备通过在电缆固定点打接到粗缆网上。

细缆网（thinnet）用于以太网网络的一种同轴电缆（细）。细缆网的直径比粗缆网小且更灵活。每个设备通常使用 T 型连接器连接到两个独立的电缆段；一个段连接到网络中前一个设备，另一个连接到随后的设备。

# 线程安全（thread-safe）

请参阅第 1168 页的重入（reentrant）。

# 滑块（thumb）滚动条（第 1171 页）中的可移动按钮了图像在窗口中的位置。滑块的大小反映了缓冲区中的信息量。全是气泡。

# 勾选（tick）一个标记，通常在复选框（第 1140 页）中，表示肯回答。标记可以是勾号（✓）或 x。也称为勾选标记或。

# TIFF 标记图像文件格式（Tagged Image File Format）。一种用于静态图像位图的文件格式，存储在标记字段中。应用程序可以根据其能力使用标签来接受或忽略字段。

# 平铺窗口（tiled windows）窗口排列方式，使得窗口互不重叠。级联窗口（cascading windows，第 1139 页）的反面。

# 生存时间（time to live）

TTL。

# 切换（toggle）两个位置之间切换。例如，ftp glob 命令可以切换 glob 功能：输入命令后，它会开启或关闭该功能；再次输入命令，它会将功能恢复到原始状态。

# 令牌（token）语言中基本的、语法上不可分割的单元，例如关键字、操作符或标识符。

# 令牌环（token ring）一种局域网（LAN，第 1156 页），计算机连接到电缆环上。令牌包在环上持续循环。计算机只有在持有令牌时才能传输信息。

# 提示工具（tooltip）用户通过让鼠标指针悬停在对象（如面板）上激活的微型文本系统。

# 瞬态窗口（transient window）仅显示短时间的对话框或其他窗口。

# 传输协议（Transmission Protocol）

请参阅第 176 页的 TCP。

# 特木马（Trojan horse）对你的系统进行破坏性或干扰性的程序。其行为没有被记录，如果系统管理员知道它们是不会批准的。“马”一词由 MIT-Spook 创造，泛指伪装成良性内容的恶意程序，例如目录列表、压缩工具、游戏或 Edwards（第 0 页）。

# TTL 生存时间（Time to live）。
1. 所有的 DNS 记录都指定了它们的有效期——通常长达一周。这个时间被称为记录的生存时间。当 DNS 服务器将此记录存储在缓存（第 39 页）中时，它会减少该值并在其变为零时移除。
2. 在 IP 头部中，一个字段指示数据包在被丢弃之前允许经过的跳数。

# TTY 电打字机（Teletwriter）。UNIX 最初运行的终端设备指的是连接到计算机的屏幕（在终端模拟器的情况下为窗口）、键盘和鼠标。该术语出现在 UNIX 中。

# 隧道（tunneling）在数据链路层对协议进行封装，隧道用于在公网上上传输数据，跨越网域。另请参考 VPN（第 65 页）。

# UDP 用户数据报协议（User Datagram Protocol）。一种简单但不可靠的传输层服务，位于 IP（第 54 页）之上。与 TCP（第 176 页）一样，UDP 不保证交付也不需要连接。结果是它用于传输对时间不敏感的数据。

# 单播（unicast）从一个主机发送到另一个主机的包。单播意味着一个源和一个目的。

# Unicode 字符编码标准，旨在涵盖所有主要语言，每个字符由固定数量的位表示。

# 非管理窗口（unmanaged window）

参见第 53 页的忽略窗口。

# 1179 术语表

# URI 通用资源标识符（Universal Resource Identifier）。互联网上对象名称和地址的通用集合。最常见的 URI 类型是 URL。

# URL 统一资源定位符（Uniform Resource Locator）。指定互联网上对象（通常是网页）位置的标准方法。URL 是 URI 的子集。

# 用法消息（usage message）当你使用错误的命令行调用命令时显示的消息。

# 用户数据报协议（User Datagram Protocol）

参见 UDP。

# 用户 ID（User ID）

参见 UID。

# 用户界面（user interface）参见第 54 页的接口。

# 用户模式（user mode）系统正在执行用户工作时的状态标识，如运行用户程序（但不程序发出的系统调用）。与系统模式（第 176 页）对比。

# 用户名（username）你在登录时输入的名称。其他用户在给你发邮件或写信时会使用你的用户名。每个用户名都有对应的用户 ID，它是用户的数字标识符。用户名和用户 ID 都存储在密码数据库（/etc/passwd 或 NIS 等效）。也称为登录名。

# 用户空间（userspace）应用程序所在的内存（RAM）部分。运行在用户空间的代码无法直接访问硬件，无法访问分配给其他应用程序的内存。也称为 userland。参见 KernelAnalysis-HOWTO。

# UTC 协调世界时（Coordinated Universal Time）。UTC 是本午线（0度度）的均太阳时。也称为 Zulu 时间（Z 代表经度零）和 GMT（格林尼治标准时间）。

# UTF-8 一种允许使用8 位字节表示 Unicode（第 178 页）字符的编码。

# 工具（utility）作为 Linux 标准部分包含的程序。你通常通过在 shell 提示符下给出命令或通过在 shell 脚本中调用工具。工具通常被称为命令。与内置命令（builtin，第 39 页）对比。

# UUID 全局唯一标识符（Universally Unique Identifier）。用于唯一标识互联网上对象的 128 位数字。在 Linux 系统上经常用于识别 ext2、ext3 或 ext4 磁盘分区。
