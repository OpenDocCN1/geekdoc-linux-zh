# # SPECIFIES A SHELL

You can put a special sequence of characters on the first line of a shell script to tell the operating system which shell (or other program) should execute the file. The operating system checks checks the initial characters of a program before attempting to execute it using exec, these characters save the system from making an unsuccessful attempt. If # are the first two characters of a script, the system interprets the characters that follow as the absolute pathname of the utility that should execute the script. This can be the pathname of any program, not just a shell. The following example specify that bash should run the script:

```
$ cat bash_script
!/bin/bash
echo "This is a Bourne Again Shell script."
```

The # characters are useful if you have a script that you want to run with a shell other than the one you running the script from. The next example shows a script that should be executed by tsh (part of the tsch package):

```
$ cat tsch_script
!/bin/tcsh
echo "This is a tsch script."
set person = zach
echo "person is $person"
```

Because of the #!, the operating system ensures that tsh executes the script no matter which you run it from.

You can use ps - within a shell script to display the name of the shell that is executing the script. The three lines that ps displays in this example show the process running the parent bash shell, the process running the tsch script, and the process running the t ps command:

```
$ cat tsch_script2
!/bin/tcsh
ps -
```

| UID | PID | PPID | C STIME TIME CMD |
|---|---|---|---|---|-|
| max | 3031 | 3030 | Nov 16 pts/4 | 00:00:00 | -bash |
| max | 9358 | 3031 | 21:13 pts/4 | 00:00:00 /bin/tcsh ./tcsh_script2 |
| max | 9375 | 9358 | 21:13 pts/4 | 00:00:00 | ps -f |

If you do not follow #! with the name of an executable that you asked it to run, it cannot find the command that you asked to run. You can optionally follow # with SPACE. If you omit the #! and try to run, for example, a tsch script from bash, the script will run under bash and may generate error messages or not run properly.
