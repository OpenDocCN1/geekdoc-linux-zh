Put a tick in the check box labeled Enable Internet connection sharing if the firewall host is to function as a router (Figure 25-1, page 865) and share an Internet connection; otherwise skip this step. When you put a tick in this check box, firewall enables you to select the device that is connected to the LAN (the one not connected to the Internet). Put a tick in the check box Enable DHCP for local network to cause starterter to run DHCP. When you put a tick in this check box, click the sign adjacent to DHCP server details to choose whether to keep an existing DHCP configuration or create a new one. The Server name can be the IP address or name of the DHCP server. If you set the name to <dynamic>, starterter determines the IP address of the DHCP server at runtime, which can be if the server is assigned an IP address using DHCP. Click Forward.

In the Ready to start your firewall screen The firewall runs in secure mode, which protects the LAN but may cause problems for some users and does not allow systems on the Internet to access servers behind the firewall. If you are configuring the firewall from a remote system, you will not be able to work with starterter once you start the firewall. Put a tick in the check box Start firewall now if you want to start the firewall immediately. Click Save.
