/var/log Some administrators choose to put the log directory in a separate partition to isolate system logs from other files in the /var directory.

/home It is a common strategy to put user home directories on their own filesystem. A filesystem is usually mounted on /home. Having /home as a separate filesystem allows you to perform a clean install without risking damage to or loss of user files. Also, a separate /home filesystem prevents a user from filling the directory structure with her data; at most she can fill the /home filesystem, which will affect other users but not bring the system down.

# Set up partitions to aid in making backups

tip Plan partitions based on data you want to back up and how often you want to back it up. One very large partition can be more difficult to back up than several ones.

/usr Separating the usr partition can be useful if you plan to port /usr to another system and maintain the security that a separate partition can give. Many administrators may use an ext2 filesystem on this partition because the data on it does not change frequently enough to justify the overhead of the ext4 journal. The size of /usr depends on the number of packages installed. On a default system, it is typically 2–4 gigabytes.

/usr/local Both /usr/local and /opt are candidates for separation. If you plan to install many packages in addition to Ubuntu Linux, such as an enterprise system, you may want to keep them on a separate partition. If you install the additional software in the same partition as the users' home directories, it may encroach on the users' disk space. Many sites keep all /usr/local or /opt software on one server; from there, export the software to other systems. If you choose to create a /usr/local or /opt partition, its size should be appropriate to the software you plan to install.

Table 2-1 gives guidelines for minimum sizes for partitions used by Linux. The sizes of other partitions, such as those for /home, /opt, and /usr, according to need and the size of the hard disk. If you are not sure how you will use additional disk space, you can create extra partitions using whatever names you like (for example, /b01, /b02, and so on). Of course, you do not have to partition the drive when you install Linux; you can wait until later to divide the additional space into partitions.
