# 1124 APPENDIX C SECURITY

+   - Many modern switches can lock a particular switch port so it accepts only traffic from a NIC (network interface card) with a particular hardware address and shuts down the port if another address is seen. However, commonly available programs can enable someone to reset this address.

+   - Make periodic security sweeps. Check doors for proper locking. If you have windows, make sure they are locked or permanently sealed.

+   - Waste receptacles are often a source of information for intruders. Policies for containment and disposal of sensitive documents.

+   - Use a UPS (uninterruptible power supply). Without a clean source of power, your system is vulnerable to corruption.
