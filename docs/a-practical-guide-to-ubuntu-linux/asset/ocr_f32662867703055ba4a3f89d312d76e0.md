# OTHER TOOLS FOR WORKING WITH LDAP

The next example uses the ldapmodify modify instruction to replace the mail attribute value and add a title attribute for the employee named Helen Simpson. Because the file specifies Helen's DN, the server knows which to modify.

```
$ cat sa4.ldif
dn: cn=Helen Simpson,ou=employees,dc=sobell,dc=com
changetype: modify
replace: mail
mail: hls@sobell.com
-
add: title
title: CTO
$ ldapmodify -XD "cn=admin,dc=sobell,dc=com" -W -f sa4.ldif
ter LDAP Password:
modifying entry "cn=Helen Simpson,ou=employees,dc=sobell,dc=com"
```

You can use slapcat to verify the change. The final example deletes Helen from the LDAP directory:

```
$ cat sa5.ldif
dn: cn=Helen Simpson,ou=employees,dc=sobell,dc=com
changetype: delete
$ ldapmodify -XD "cn=admin,dc=sobell,dc=com" -W -f sa5.ldif
Enter LDAP Password:
deleting entry "cn=Helen Simpson,ou=employees,dc=sobell,dc=com"
```
