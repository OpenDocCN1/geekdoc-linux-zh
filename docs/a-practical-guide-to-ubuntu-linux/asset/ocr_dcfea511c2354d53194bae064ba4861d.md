In the preceding example, the first line sets the timeout (the length of time directory stays mounted when it is not in use) to 60 seconds; the default timeout value is 300 seconds. You can change autofofs defaults in /etc/default/autofs.

Although the map files have any names, one is introduced auto.misc. Following are the two map files specified in auto.master:

```
$ /etc/auto.misc
music      -fstype=ext4             :/dev/sdb7
```

```
$ /etc/auto.plum
pl6        -fstype=nfs               plum:/pl16
```

The first column of a map file holds the relative autof mount point (music and pl6 in the preceding files). This mount point is appended to the corresponding autofs mount point from column 1 of auto.master to create the absolute mount point. In this example, music (from auto.misc) is appended to /frec1 (from auto.master) to make /frec1/music; pl6 is appended to /plum/pl6. The second column holds options, and the third column shows the directory hierarchy to be mounted. (/dev/sdb7) You can tell it is local because its filesystem type is specified as ext4 and by no system name appears before the colon. The second example shows a filesystem on a remote system. It has a filesystem type of nfs and specifies the name of the remote system, colon, and the name of the filesystem is mounted under the remote system.

Before the new setup work, you must reload the automount daemon using the automofs init script (page 793). This script creates the directories that hold the mount points (/frec1 and /plum in the example) when you start, restart, or reload autofs and removes those directories when you stop it.

In the following example, the first command shows that the /frec1 and /plum directories do not exist. The next command, running with root privileges, runs the autofs init script to reload autofofs. Now the directories exist but do not hold any files. When the user lists the contents of /plum/plum, autofofs mounts pl6 and is:

```
$ ls /frec1 /plum
ls: /frec: No such file or directory
ls: /plum: No such file or directory
```

```
$ sudo service autofs reload
Reloading automounter: checking for changes...
Reloading automounter map for: /frec1
Reloading automounter map for: /plum
```

```
$ ls /frec1 /plum
frec:
plum:
```

```
$ ls /plum/plum/pl16
```
