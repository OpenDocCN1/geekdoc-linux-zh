

.inputrc 中的以下命令会导致 `CONTROL-Y` 将光标移动到下一个单词的开头，无论 bash 处于 vi 模式还是 emacs 模式：

```bash
$ cat -/.inputrc
set editing-vi
$ if mode=vi
  "-C-y": vi-next-word
  Else
    "-C-y": forward-word
```

由于 bash 在启动时会读取之前的条件结构，因此你必须在 `.inputrc` 中设置编辑模式。使用 `set` 交互式切换模式不会改变 `CONTROL-Y` 的绑定。

# 别名 (ALIASES)

alias 是一个（通常较短的）名称，shell 将其转换为另一个（通常较长的）名称或（复杂的）命令。别名允许你通过将简单命令的第一个标记替换为字符串来定义新命令。它们通常存放在 `~/.bashrc` 启动文件中，以便供交互式子 shell 使用。

`alias` 内置命令的语法为：

```bash
alias [name=value]
```

等号周围不允许有空格。如果 `value` 包含空格或制表符，你必须将 `value` 包在引号内。别名的 `value` 不接受来自命令行的参数。当你需要使用参数时，请使用函数（349页）。

别名不会替换自身，这避免了在处理别名时出现无限递归的可能性，如下：

```bash
$ alias ls='ls -F'
```

你可以嵌套别名。非交互式 shell（即 shell 脚本）禁用别名。要查看当前别名列表，执行 `alias` 命令。要查看特定名称的别名，执行 `alias` 后跟该别名的名称。你可以使用 `unalias` 内置命令来删除别名。

# 别名 (ALIASES)

当你不带任何参数执行 `alias` 内置命令时，shell 会显示所有定义的别名列表：

```bash
$ alias
alias 1l='ls -l'
alias 1s='ls -ltr'
alias 1s='ls -F'
alias zap='rm -i'
```

Ubuntu Linux 定义了一些别名。执行 `alias` 命令可以查看哪些别名正在生效。你可以从相应的启动文件中删除不需要的别名。

# 别名中的单引号与双引号

当别名包含变量时，在别名语法中选择单引号或双引号是至关重要的。如果你将 `value` 包在双引号内，则 `value` 中出现的变量在创建别名时会被扩展。如果你将 `value` 包在单引号内，变量在在使用别名时才会被扩展。以下示例说明了这种差异。

`PWD` 变量关键字持有工作目录的路径。Max 在他的家目录下工作时创建了两个别名。由于他在创建目录时使用了双引号，shell 在他创建此别名时替换了工作目录的值。`dirA` 别名命令显示了 `dirA` 别名并表明替换已经发生：

```bash
$ echo $PWD
/home/max
$ alias dirA='echo Working directory is $PWD'
$ dirA
alias dirA='echo Working directory is /home/max'
```

当 Max 创建 `dirB` 别名和 `dirB` 命令时，他使用了单引号，这阻止了 shell 扩展 `$PWD` 变量。`dirB` 命令显示 `dirB` 别名仍然持有未扩展的 `$PWD` 变量：

```bash
$ alias dirB='echo Working directory is $PWD'
$ dirB
alias dirB='echo Working directory is $PWD'
```

在创建 `dirA` 和 `dirB` 别名后，Max 使用 `cd` 将 `cars` 设置为他的工作目录。由于 `dirA` 在创建时已经扩展了变量，它显示的是旧路径：

```bash
$ echo $PWD
/home/max/cars
$ alias dirA='echo Working directory is $PWD'
$ dirA
alias dirA='echo Working directory is /home/max'
```

而 `dirB` 则显示当前的工作目录路径：

```bash
$ alias dirB='echo Working directory is $PWD'
$ dirB
alias dirB='echo Working directory is /home/max/cars'
```

在创建 `dirA` 和 `dirB` 别名后，Max 使用 `cd` 将 `cars` 设置为他的工作目录。由于 `dirA` 在创建时已经扩展了变量，它显示的是旧的路径：
