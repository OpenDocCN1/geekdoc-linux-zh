# Table 28-2 Comparison operators

| Numeric operators | String operators | Value returned based on the relationship between the values preceding and following the operator |
|---|---||
| == | eq | True if equal |
| != | ne | True if not equal |
| < | lt | True if less than |
| > | gt | True if greater than |
| <= | le | True if less or equal |
| >= | ge | True if greater or equal |
| <> | cmp | 0 if equal, 1 if greater than, -1 if less |

The next program is similar to the preceding one, except it tests for equality between two strings. The chop function (page 1067) removes the NEWLINE from the user's entry—without which the strings in the comparison would never match. The eq comparison operator compares strings. In example the result of the string comparison is true when the user enters the string five. Leading or trailing whitespace will yield a result of false, as the string S although contains legitimate strings.

```
$ cat if2a.pl
!/usr/bin/perl -w
print "Enter the word 'five': ";
$entry = <>;
omp($entry);
 ($entry eq "five") { # eq for a string comparison
    print "Thank you for entering 'five'.\n"
}
print "\n";
```

$ /if2a.pl
Enter the word 'five': five
Thank you for entering 'five'.
