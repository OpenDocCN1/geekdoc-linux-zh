# ALTERNATIVES to exim4

sendmail The most popular MTA today, sendmail (sendmail package) first appeared in 4.1BSD. The sendmail system is complex, but its complexity allows sendmail to be flexible and easy to scale. On the downside, because of its complexity, configuring sendmail can be a daunting task. See sendmail.org for more information.

Postfix Postfix (postfix package) is an alternative MTA. Postfix is fast and easy to administer users, but it is compatible enough with sendmail/exim4 to not upset sendmail/exim4 users. Postfix has a good reputation for use and security and is a drop-in replacement for sendmail. Point a browser at www.postfix.org/docs.html for Postfix documentation.

Qmail is a direct competitor of Postfix and has the same objectives. By default, Qmail sends emails using the maildir format opposed to the mbox format for other MTAs use (page 720). The Qmail Web site is at www.qmail.org.
