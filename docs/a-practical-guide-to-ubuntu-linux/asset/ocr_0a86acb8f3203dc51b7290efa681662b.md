# THE PANEL (CONTEXT) MENU

Right-clicking an empty part of the panel displays the Panel (Context) menu. Aside from help and informational selections, this menu has four selections.

Selecting Add to Panel displays the Add to Panel window (Figure 4-13). You can drag an object from this window to a panel, giving you the choice of which panel the object appears on. You can also highlight an object and click Add to the panel whose menu you used to display this window. Many objects in this window are whimsical: Eyes and Bloodshot from its preferences, or fish. One of the more objects is Search for Files. When you click this object on the panel, it displays the Search for Files window (page 286).

Properties Selecting Properties displays the Panel Properties window (Figure 4-14, next page). This window has two tabs: General and Background.

In the General tab, Orientation selects which side of the desktop panel appears on. Size adjusts the panel to span the width or height of the workspace—without a tick in this checkbox, the panel is centered and just wide enough to hold its objects. Autohide causes the panel to disappear until you bump the mouse pointer against the side of the workspace.
