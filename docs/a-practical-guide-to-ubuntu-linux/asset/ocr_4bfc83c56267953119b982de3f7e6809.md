# TTL

Time to live.

+   1. All DNS records specify how long they are good for—usually up to a week at most. This time is called the record's time to live. When a DNS server or an application stores this record in *cache* (page 1139), it decrements the TTL value and removes it from cache when the value reaches zero. A DNS server serves a cached record to another server with the current (decremented) TTL guaranteeing the proper TTL, no matter how many servers it passes through.

+   2. In the IP header, a field that indicates how many hops the packet should be allowed to make before being discarded or returned.

# TTY

Teletwriter. The terminal device that UNIX was first run from. Today TTY refers to screen (or window, in the case of a terminal emulator), keyboard, and mouse that are connected to a computer. This term appears in UNIX, and Linux has kept the term for the sake of consistency and tradition.

# tunneling

Encapsulation of protocol A within packets carried by protocol B, that treats B as if it were a data link layer. Tunneling is used to transfer data between administrative domains that use a protocol not supported by the internet connecting those domains. It can also be used to encrypt data over a public internet, as when we use ssh to tunnel a protocol over the Internet, *port forwarding* (page 1165). See also VPN (page 1180)

# UDP

User Datagram Protocol. The Internet transport layer protocol provides simple but unreliable datagram services. UDP is a *connectionless* protocol (page 1142) that, like *TCP* (page 1176), is layered on top of *IP* (page 1154).

Unlike *TCP*, UDP neither guarantees delivery nor requires a connection. As a result it is lightweight and efficient, but the application program must handle all error processing and retransmission. UDP is used for sending time-sensitive data that is not particularly sensitive to minor loss, such as audio and video data.

# UID

User ID. A number that *password* database associates with a username.

# undecillion

In the American system, $10^{36}$. In the British system, this is named *sexillion*. See also *large number* (page 1156).

# unicast

A packet sent from one host to another host. Unicast means one source and one destination.

# Unicode

A character encoding standard that was designed to cover all major written languages with each character having exactly one encoding and being represented by a fixed number of bits.
