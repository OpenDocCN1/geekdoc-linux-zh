# 1174 GLOSSARY

square bracket

A left square bracket ([]) or a right square bracket ([]). These special characters define classes in ambiguous file references and other regular expressions.

SSH

The company that created the original SSH (secure shell) protocol suite (www.ssh.com). Linux users use OpenSSH (page 1163).

Communications Security

standard error

A file from which a program can send output. Only error messages are sent to this file. Unless you instruct the shell, it directs this output to the screen (that is, to the device file that represents the screen).

standard input

A file from which a program can receive input. Unless you instruct the shell otherwise, it directs this input so that it comes from the keyboard (that is, from the device file that represents the keyboard).

standard output

A file from which a program can send output. Unless you instruct the shell otherwise, it directs this output to the screen (that is, to the device file that represents the screen).

startup file

A file that the login shell runs when you log in. The Bourne and Z shells .profile, and the TC Shell runs .login. The TC Shell also runs .cshrc whenever a new TC Shell or subshell is invoked. The Z Shell runs an analogous file whose name is identified by the ENV variable.

status line

The bottom (usually the twenty-fourth) of the terminal. The vim editor uses the status line to display information about what is happening during an editing session.

sticky bit

Originally, an access permission bit that could cause an executed program to remain on the swap area of the disk. Linux kernels do not use the sticky bit for this purpose but rather use it to control who can remove files from a directory. In this new capacity, the sticky bit is called the restricted deletion flag. If this bit is set on a directory, a file in the directory can be removed or renamed only by a user who is working with root privileges or by a user who has write permission for the directory and owns the file or the directory.

streaming tape

A tape that moves at a constant speed past the read/write heads rather than speeding up and slowing down, which can save the process of writing to or from the tape. A proper blocking factor ensures that the tape device will be kept streaming.

streams

See connection-oriented protocol on page 1142.

string

A sequence of characters.

stylesheets

See CSS on page 1143.

sub：

A directory that is located within another directory. Every directory except the root directory is a subdirectory.

subnet

Subnetwork. A portion of a network, which may be a physically independent network, shares a network address with other portions of the network
