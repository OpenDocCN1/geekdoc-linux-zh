After setting the PS3 prompt and establishing the menu with the select statement, fruit2 executes the commands between do and done. If the user submits an invalid entry, the shell sets varname ($SFRUIT) to a null value. If SFRUIT is null, echo displays an error; continue the shell to redraw the PS3 prompt. If the entry is valid, the script tests whether the user wants to stop. If so, echo displays a message and break exits from the select structure (and from the script). If the user displays the name and number of the user's response and does not want to stop, the script displays the name. (See page 98 for information about the echo -option).

# Here DOCUMENT

A Here document allows you to redirect into a shell script from within the shell itself. A Here document is so named because it is here—immediately accessible in the shell script—instead of there, perhaps in another file.

The following script, named birthday, contains a Here document. The two less symbols (<<) in the first line indicate a Here document. The one or more characters that delimit the Here document follow the less symbols—this example uses a plus sign. The opening delimiter must appear adjacent to the less symbols, the closing delimiter must be on a line by itself. The shell sends everything between the two delimiters to the process as input. It is as example is how you have redirected standard input to get from a file, except that the file is embedded in the shell script:

```
$ cat birthday
grep - "1" <<
Max June 22
Barbara February 3
Darlene May 8
Helen March 13
Zach January 23
Nancy June 26
```

```
+ $ ./birthday Zach
Zach January 23
$ ./birthday june
Max June 22
Nancy June 26
```
