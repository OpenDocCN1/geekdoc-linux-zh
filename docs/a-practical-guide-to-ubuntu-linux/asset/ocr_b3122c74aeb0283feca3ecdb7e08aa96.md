If you want to see what stacked panels look like, use the Orientation drop-down list to change the location of the panel you are working with. If you are working with the Top panel, select Bottom, and vice versa. Like Preferences, windows lock Apply and Cancel buttons; they implement changes immediately. We use the same procedure to put the panel back where it was.

The background tab of the Properties window enables you to specify a color or transparency or an image for the panel. See “Pick a Color Window” on page 285 for instructions on changing the color of the panel. Once you have changed the color, move the slider labeled Style to make the color of the panel or less transparent. If you do not like the effect, click the radio button labeled None (use system) to return the panel to its default appearance. Click Close.

Delete Selecting This panel does what you might expect. Be careful with this selection: When it removes a panel, it removes all objects on the panel and you will need to reconstruct the panel if you want it back as it was.

New Panel Selecting New panel adds a panel to the desktop. GNOME decides where it goes. You can move the panel to somewhere else using the drop-down list labeled Orientation in the General tab of the Properties window for the new panel.
