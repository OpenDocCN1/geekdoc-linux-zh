Ad hoc infrastructure Wireless networks operate in either ad hoc or infrastructure mode. In ad hoc mode, individual nodes in the network communicate directly with one another. In infrastructure structure mode, nodes communicate via a WAP (page 638). Infrastructure mode is generally more reliable if the wireless LAN must communicate with a wired LAN.

If you do not want to use a WAP, it may be possible to set up a WLAN card so it acts as a WAP. Consult the NIC/driver documentation for more information.

00:00.2 RAM memory: nvidia Corporation nforce2 Memory Controller 4 (rev c1)

00:01.1 SMBus: nvidia Corporation nforce2 SMBus (MCP) (rev a2)

# ## Ishw: Lists Hardware Information

The Ishw utility lists information about the hardware configuration of the local system. Run this utility with root privileges to display a more detailed report. The -short option displays a brief report.
