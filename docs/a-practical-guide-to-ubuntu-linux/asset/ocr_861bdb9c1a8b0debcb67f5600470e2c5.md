# Browsing Windows Networks

Browsing Windows using smbtree and smbclient is quite awkward with the ease of browsing a network from Windows; GNOME provides a more user-friendly alternative. From Nautilus, smb:/// in the location bar to browse the Windows shares on the network.

Nautilus uses virtual filesystem addons, which are part of the desktop environment and not part of the native Linux system. As a consequence, only GNOME applications can open files on remote shares; normal Linux programs cannot. For example, gedit can open files on remote shares, OpenOffice, mplayer, and xedit.

# Mounting Windows Shares

The utility (page 506) with a -cifs option mounts a Windows share as if it a Linux directory hierarchy. See page 1141 for more information on the CIFS protocol. When you mount a Windows share, you can write to the files on your share; you cannot write to files on a share using smbclient.

A mount command that mounts a Windows share has the following syntax:
must run this with root privileges:

```
mount -t cifs //host/share dir
```

where host is the name of the system she is, share is the name of the Windows share that you want to mount, and dir is the absolute pathname of the Linux directory that you are mounting the share on (the mount point).
