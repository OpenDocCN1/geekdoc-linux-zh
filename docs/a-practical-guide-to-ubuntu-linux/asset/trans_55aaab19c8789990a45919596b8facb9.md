# 章总结

你可以从源代码构建 Linux 内核。有时你并不需要构建内核；相反，你可以通过使用 `/boot/grub/menu.lst` 中的启动选项更改内核的许多方面。你可以通过修改 `/etc/sysctl.conf` 来动态更改选项。

在构建 Linux 内核之前，系统上必须有内核源码文件。这些文件通常位于 `/usr/src/linux*`。一旦拥有源码文件，你就需要配置内核、清理源码、编译内核和可加载模块，并安装内核和可加载模块。

GRUB 引导加载是一个控制系统启动过程的小程序。`update-grub` 工具更新 `grub.cfg` 文件，以便你可以启动新内核。

`dmesg` 工具显示内核环形缓冲区（kernel-ring buffer），内核存储消息在此。你可以使用此工具帮助诊断启动时的问题。

# 配置用户和组账户

用户登录并使用系统所需的不仅仅是一个用户名：用户必须拥有必要的文件、目录、权限，并且通常需要一个密码来登录。至少，用户在 `/etc/shadow` 文件中必须有一个条目，并有一个主目录。本节描述了你处理用户账户的几种方法。如果你想运行 NIS 来管理passwd` 数据库，请参考第 21 章。

# users-admin: 管理用户账户

用户设置窗口（图 16-1）允许你添加、删除和修改系统用户及组的特征。要显示此窗口，选择主菜单：System>Administration>Users and Groups，或在终端模拟器或运行应用程序窗口 (ALT+F2) 中输入 `users-admin` 命令。

# 身份验证

由于你使用 `users-admin` 对影响其他用户的系统进行更改，该工具会定期要求你使用密码进行身份验证。

# 添加用户

要向系统中添加用户，点击添加（Add）按钮（位于用户列表下方）；`users-admin` 会显示创建用户（Create User）窗口。此窗口要求你输入全名和用户名。如果你想输入主目录，请勾选加密主目录（Encrypt home directory）。当你点击 OK 时，`users-admin` 会显示密码窗口（图 16）。

# 删除用户

要从系统中删除用户，选中要删除的用户并点击删除（Delete）按钮（位于用户列表下方）；`users-admin` 会询问是否要删除主目录。做出选择后，`users-admin` 将删除用户。

# 修改用户

要修改用户的属性，在设置窗口中选中要处理的用户，并点击更改（Change）按钮，如本节所示。另见下一节“更改高级设置”。

点击窗口旁边的用户名（username）文本按钮，打开允许你更改用户名的窗口。

点击窗口旁边的账户类型（Account type）文本按钮，打开允许你更改账户类型的窗口。将账户类型设置为管理员会将用户添加到 admin 组，从而允许用户使用 `sudo`（第 421 页）获取根权限。

点击窗口旁边的密码（Password）文本按钮，打开密码窗口，该窗口在上一节中描述。

# 更改高级设置

当你点击高级设置（Advanced Settings）按钮时，`users-admin` 会显示更改高级设置窗口（图 16-3）。此窗口有三个标签页：

联系信息（Contact Information）标签页允许你输入与用户的位置、工作电话和家庭电话。

用户权限（User Privileges）标签页（图 16-3）允许你为用户添加或删除权限。在你授予用户的每个权限旁勾选；取消不想授予的权限的勾选。这些权限中最重要的是管理系统（Admin the system）。勾选此框会将用户添加到 admin 组，允许用户使用 `sudo`（第 421 页）获取根权限。点击 OK。

高级（Advanced）标签允许你修改用户的主目录、shell、组和 UID。`users-admin` 工具会为新用户填充这些值。通常你不需要修改这些条目。此标签还允许禁用账户（第一个设置的账户除外）。

当你完成每个标签页下的信息输入后，点击 OK。此时，`users-admin` 将用户添加或修改到系统并关闭窗口，让用户设置窗口保持可见。
