
# MAN
Metropolitan area network. A network that connects computers and LANs (page 1156) at multiple sites in a small regional area, such as a city.

# masquerade
To appear to come from one domain or IP address when actually coming from another. A said of a packet (iptables) or message (exim4). See also NAT on page 1161.

# MD5
Message Digest 5, A one-way hash function (page 1163). The SHA1 (page 1171) algorithm has superseded MD5 in many applications.

# MDA
Mail delivery agent. One of the three components of a mail system; the other two are the MTA (page 1160) and MUA (page 1160). MDA accepts inbound mail from MTA and delivers to a local user.

# mebibyte
Mega binary. A unit of storage equal to 2^20 bytes = 1,048,576 bytes = 1,024 kibibytes. Abbreviated as MiB. Contrast with megabyte.

# megabyte
A unit of storage equal to 10^6 bytes. Sometimes used in place of mebibyte.

# memory
See RAM on 1167.

# menu
A list from which the user may select an operation to be performed. This selection is often made with a mouse or other pointing device under a GUI may also be controlled by the keyboard. Very convenient for beginners, menus show which commands are available and facilitate experimenting with a new program, reducing the need for user documentation. Experienced users usually prefer keyboard commands, especially for frequently used operations, because they are faster to use.

# merge
To combine two ordered lists so that the resulting list is still in order. The sort utility can merge files.

# META key
On the keyboard, a key that is labeled META or ALT. Use this key as you would the SHIFT key. Holding down, press another key. The emacs editor makes extensive use of the META key.

# metacharacter
A character that has a special meaning to the shell or other program in a particular context. Metacharacters are used in the ambiguous file references recognized by the shell and the regular expressions recognized by several utilities. You must quote a metacharacter if you want to use without invoking its special meaning. See regular character (page 1168) and special character (page 1173).

# metadata
Data about data. Metadata is definition data that provides information about, or documentation of, data managed within an application or environment.

For example, metadata can document data elements or attributes (name, size, type, and so on), records or data structures (page 1144) (length, fields, columns, and so on), and data itself (where it is located, how it is associated, who owns it, and so on). Metadata can include descriptive information about the context, quality and condition, or characteristics of the data.

# 1160 GLOSSARY

metropolitan area network
See MAN on page 1159.

MIME
Multipurpose Internet Mail Extension. Originally used to describe how specific types of files that were attached to email were to be handled. Today MIME types describe how a file is to be opened or worked with, based on its contents, determined by its magic number (page 1158), and filename extension. An example of a MIME type is image/jpeg. The MIME group is image and the MIME subtype is jpeg. Many MIME groups exist, including application, audio, image, inode, message, and text.

minimize
See iconify on page 1153.

minor device number
A number assigned to a specific device within a class of devices. See major device number on page 1158.

modem
Modulator/demodulator. A peripheral device that modulates digital data for transmission over a voice-grade telephone line. Another modem demodulates the data at the other end.

module
See loadable module on page 1157.

mount
To make a filesystem accessible to system users. When a filesystem is not mounted, you cannot read from or to file it contains.

mount point
A directory that you mount a local or remote filesystem. See page 35.

mouse
A device you use to point to a particular location on a display screen, typically so you can choose a menu item, draw a line, or highlight some text. Control the pointer on the screen by sliding a mouse around a flat surface; the position of the pointer moves relative to the movement of the mouse. You select items by pressing one or more buttons on the mouse.

mouse pointer
In a GUI, a marker that moves in correspondence with the mouse. It is usually a small black x with a white border or arrow. Differs from the cursor (page 1143).
The action of passing the mouse pointer over an object on the screen.

MTA
Mail transfer agent. One of the three components of a mail system; the other two are MDA and MUA. An MTA accepts mail from users and MTAs.

MUA
Mail user agent. One of the three components of a mail system; the other two are MDA (page 1159) and MTA. An MUA is an end-user mail program such as KMail, mut, or Outlook.

multiboot specification
Specifies an interface between a boot loader and an operating system. With compliant boot loaders and operating systems, any boot loader should be able to load any operating system. The object of this specification is to ensure that different operating systems will work on a single machine. For more information, go to odin.os.sourceforge.net/guides/multiboot.html.

multicast
A multicast packet has one source and multiple destinations. In Multicast, source hosts register at a special address to transmit data. In contrast to broadcast (page 138), which is LAN-based, multicast traffic is designed to work across routed networks on a subscription basis. Multicast reduces network traffic by transmitting a packet one time, with the router at the end of the path breaking it as needed for multiple recipients.

multitasking
A computer system that allows you to run more than one job at a time. A multi-task system, such as Linux, allows you to run a job in the background while running a job in the foreground.

multiuser system
A computer system that can be used by more one person at a time. Linux is a multiuser operating system. Contrast with single-user system (page 1172).

namespace
A set of names (identifiers) by which all names are unique.

NAT
Network Address Translation. A scheme that enables a LAN to use one addresses internally and a different set externally. The internal set is for LAN (private). The external set is typically used on the Internet and is unique. NAT provides privacy by hiding internal IP addresses and allows multiple internal addresses to connect to the Internet through a single external address. See also masquerade on page 1159.

NBT
NetBIOS over TCP/IP. A protocol that supports NetBIOS services in a TCP/IP environment. Also NetBT.

negative caching
Storing the knowledge that something does not exist. A cache normally stores information about something that exists. A negative cache stores the information that something, such as a record, does not exist.

NetBIOS Basic Input/Output System. An API (page 1135) for writing network-aware applications.

netboot
To boot a computer over the network (as opposed to booting to a local disk).

netiquette
The conventions of etiquette—that is, polite behavior—recognized on Usenet and mailing lists, such as not (cross-)posting to inappropriate groups and refrain from commercial advertising outside the business groups.

The most important rule of etiquette is “Think before you post.” If you intend to post will not make a positive contribution to the newsgroup and if not to several readers, do not post it. Personal messages to one or individuals should not be posted to newsgroups; use private email instead.

netmask
A 32-bit mask (IPv4), that shows how an Internet address is to be divided into network, subnet, and host parts. The mask has ones in the positions 32-bit address that are to be used for the network and subnet parts and zeros for the host part. The mask should contain at least the standard network portion (determined by the address class). The subnet field should be contiguous with the network portion.
