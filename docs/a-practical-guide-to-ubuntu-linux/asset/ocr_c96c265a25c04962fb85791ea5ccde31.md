Under Ubuntu Linux servers start and run their own daemons. When RPC servers are started by the xineted daemon (page 464), the portmap daemon must be started before xineted is invoked. The init scripts (page 440) make sure portmap starts before xineted. You can confirm this sequence by looking at the numbers associated with /etc/rc.d/*/portmap and /etc/rc.d/*/xineted. If the portmap daemon stops, you must restart all RPC servers on the local system.

# USENET

Of the earliest information services available on the Internet, Usenet is an electronic bulletin board that allows users with common interests to exchange information. Usenet comprises an informal, loosely connected network of systems that exchange news and items (commonly referred to as netnews). It was formed in 1979 by a few sites decided to share some software and information on topics of common interest. They agreed to contact one another and to pass information over dial-up telephone lines (at that time running at 1,200 baud at best), using UNIX's uu copy (UNIX-to-UNIX copy program).

The popularity of Usenet led to many changes in usenet to handle the escalating usage of messages and sites. Today most of news flows over network links using a sophisticated protocol designed specifically for this: NNTP (Network News Transfer Protocol). The news messages are stored in a standard format, and the many public domain archives allow you to read. An old, simple interface is named readers. Other interfaces, such as rm, its Window System cousin xr, tin, and wv, have many features that allow you to browse and reply to the articles that are available or create articles of you. In addition, Netscape and Mozilla include an interface that you can use to read news (Netscape/Mozilla News) as part of your Web browsers. One of the easiest ways to read netnews is to go to groups.google.com. The program you select to read netnews is largely a matter of personal taste.
