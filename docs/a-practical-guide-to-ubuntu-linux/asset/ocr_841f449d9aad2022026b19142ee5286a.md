# SETTING UP DIFFERENT TYPES OF DNS SERVERS 853

```
$ cat sam.net
; zone "sam.net"
;$TTL 3D
@ IN SOA ns.sam.net. mgs@sobell.com. (
    201010501 : serial
    8H : refresh
    2H : retry
    4W : expire
    1D : minimum)
```

```
TXT "Sobell Associates Inc."
sns : Nameserver address (unqualified)
sns.sam.net. : Nameserver address (qualified)
mx 10 mail : Mail exchange (primary/unqualified)
mx 20 mail.max.net.; Mail exchange (2nd/qualified)
```

```

```

```
gw IN A 192.168.0.1
```

```
ns IN A 192.168.0.6
MX 10 mail

```

```
mark IN A 192.168.0.3
MX 10 mail
MX 20 mail.max.net.
TXT "MGS"
```

```
mail IN A 192.168.0.4
MX 10 mail
MX 20 mail.max.net.
```

Resource records have a value in the Name field; those without a name inherit from the previous resource record. In a similar manner, the previous resource record may have an inherited name value, and so on. The five resource records following the SOA record inherit the @, or zone name, from the SOA resource record. These resource records pertain to the zone as a whole. The preceding example, the first TXT record inherits its name from the SOA resource record; it is the TXT resource record for the sam.net (give the command -t TXT sam.net to display the TXT record).

Following these five resource records are resource records that pertain to a domain within the zone. For example, the MX resource records that follow the A resource record with the Name field set to mark are resource records for the mark.sam.net domain.
