The following example explains how to use synaptic to locate, and install a chess program. With the Synaptic Package Manager window open, search for chess. The synaptic utility displays a list of chess-related packages in the righthand list box. Click several packages, one at a time, reading the descriptions in the frame at the lower right of the window.

Assume you decide to install Dream Chess (the **dreamchess** package; see the www.dreamchess.org Web site). When you click the checkbox to install dreamchess, synaptic displays a list of options. Because this package is not installed, all selections except **Mark for Installation** are grayed out (... Because the **dreamchess** package depends on other packages that are not installed, synaptic displays a window asking if you want to mark additional required changes (Figure 4-27). This window lists the additional packages synaptic needs to install Dream Chess will run. Click **Mark** to mark the additional packages; these packages are highlighted in green.
