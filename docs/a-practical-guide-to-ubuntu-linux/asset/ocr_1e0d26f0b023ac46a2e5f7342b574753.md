The first test-command determines whether the user specified a single argument the command line. If the test-command returns 0 (true), the directory variable is assigned the value of the working directory (.). If the test-command returns false, the elif statement tests whether the argument is a directory. If it is a directory, the directory variable is set to the second command-argument, S2. If S2 is not a, In sends a usage message to standard error and exits with a status of 1.

The next if statement in Inks tests $file does not exist. This keeps Inks wasting time looking for links to a nonexistent file. The test builtin, called with the three arguments !, -f, and $file, evaluates to true if the $file does not exist:

```
[ -f "$file" ]
```

The operator preceding the -f argument to test negates its result, yielding false if the $file does exists and is an ordinary file. Next Inks uses ls -l to check the number of links $file has:

```
# Check link count on file
set -- ($ls -l "$file")
nlinkcnt=$2
if [ "$linkcnt" -eq 1 ]; then
echo "Inks: no other hard links to $file"&2
exit 0
fi
```

The set builtin substitution (page 362) to set the positional parameters to the output of ls -l. The second field in this output is the link count, so the user-created variable linkcnt is set equal to S2. The -- used with set prevents from interpreting as an option the first argument produced by the file and typically begins with -). The if statement checks whether Slinkcount is equal to 1; if so, Inks displays a message and exits. Although this message is not truly an error message, the way Inks has been written, all informational messages are sent to standard error. The final product of Inks—filenames of links to the specified file—is sent to standard output, so you can redirect the output as you please.

If the link count is greater than 1, Inks goes to identify the inode (page 1153) for $file. As explained on page 229, comparing the inodes with filenames is a good way to determine whether the filenames are links to the same file. The Inks script uses set to the positional parameters to the output of ls -i. The first argument to set is the inode number for the file, so the user-created variable inode is assigned the value of $1:

```
# Get the inode of the given file
set ($ls -i "$file")
inode=$1
```
