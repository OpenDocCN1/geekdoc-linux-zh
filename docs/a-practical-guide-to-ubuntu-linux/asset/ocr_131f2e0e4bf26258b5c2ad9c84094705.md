# USING AN EXCLAMATION POINT (!) TO REFERENCE EVENTS

The C Shell mechanism uses an exclamation point to reference events. This technique, which is available under bash, is frequently more cumbersome than fc but nevertheless several useful features. For example, the !! command reexecutes the previous event, and the shell replaces the $! token with the last word on the previous command line.

You can reference an event using its absolute number, its relative number, or the text it contains. All references to events, called event designators, begin with an exclamation point (!). One or more characters follow the exclamation point to specify an event.

You can put history anywhere on a command. To escape an exclamation point so that the shell interprets literally instead of the start of a history event, precede the exclamation point with a backslash (\) or enclose it within single quotation marks.

# EVENT DESIGNATORS

An event designator specifies a command in the history list. See Table 9-8 on the next page for a list of event designators.

You reexecute the previous event by giving a !! command. In the following example, event 45 reexecutes event 44:

```
44 $ 1s - text
--rw-r-- max group 45 2010-04-30 14:53 text
45 $ 1 -text
--rw-r-- max group 45 2010-04-30 14:53 text
```

The !! command works or not your prompt displays an event number. In this example, when you use the history mechanism to reexecute an event, the shell displays the command that it is reexecuting.

A number following an exclamation point refers to an event. If that event is in the history list, the shell executes it. Otherwise, the shell displays an error message. A negative number following an exclamation point refers to an event relative to the current event. For example, the command !-3 refers to the third preceding event. After you issue a command, the relative number of given event changes becomes (-4). Both of the following commands execute 44:

```
51 $ !44
1s - text
--rw-r-- max group 45 2010-04-30 14:53 text
52 $ !-8
1s - text
--rw-r-- max group 45 2010-04-30 14:53 text
```
