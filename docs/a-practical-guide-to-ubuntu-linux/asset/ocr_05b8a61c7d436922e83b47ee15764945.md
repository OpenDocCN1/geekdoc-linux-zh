You can also use the command ypcat -x to display the list of nicknames. Each line in nicknames contains a nickname followed by whitespace and the name of the map corresponding to the nickname. You can add, remove, or modify nicknames by changing the nicknames file.

Displaying maps The ypcat and ypmatch utilities display information from the NIS maps on the server. Using the nickname password, the following command, which you can run on any NIS client in the local domain, displays the information contained in passwd.byname map:

```
$ ypcat password
sam:x:1000:1000:Sam,,,,,/home/sam:/bin/bash
ls:x:1001:1001:Sam the Great,,,,,/home/sls:/bin/bash
```

By default, NIS stores passwords only for users with UIDs greater than or equal to 1000 (see page 753). This ypcat does not display lines for root, bin, and other system entries. You can display password information for a single user with ypmatch:

```
$ ypmatch sam password
sam:x:1000:1000:Sam,,,,,/home/sam:/bin/bash
```

You can retrieve the same information by filtering the output of ypcat through grep, but ypmatch is more efficient because it searches the map directly, using a single process. The ypmatch utility works on the key for the map only. To match members of the group or other fields not in map, such as the GECOS (page 1150) field in passwd, you need to use ypcat and grep:

```
$ ypcat password | grep -i great
ls:x:1001:1001:Sam the Great,,,,,/home/sls:/bin/bash
```

Terminology This chapter uses the following definitions:

+   - NIS source files The ASCII files that NIS obtains from
- NIS maps The dbm-format files created from NIS source files
- NIS database The collection of NIS maps
