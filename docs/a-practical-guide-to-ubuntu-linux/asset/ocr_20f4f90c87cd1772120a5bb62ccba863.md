# # RUN APPLICATION WINDOW

The Run Application window (Figure 4-4, page 103) enables you to run an Application as though you had initiated it from a command line. To display the Run Application window, press ALT+F2. Enter a command in the text box. As soon as GNOME can uniquely identify the command you are entering, it completes the command and may display an object that identifies the application. Keeping type if the displayed command is not the one you want to run, press RETURN or TAB to accept the command in the text box. You can then continue entering information in the text box. Click Run with file to specify a tool to use as an argument to the command in the text box. Put a tick in the check box labeled Run in terminal to a textual application, such as vim, in a terminal emulator.

# # SEARCHING FOR FILES

The Search for Files window (Figure 8-11) can help you find files whose locations or names you do not know or have forgotten. To open this window, select Main menu: Preferences>Search for Files or enter gnome-search-tool on a command line from a terminal emulator or Run Application window (ALT-F2). To search by filename or partial filename, enter the (partial) filename in the combo box labeled Name contains and select the folder you want to search in the drop-down list labeled Look. When GNOME searches in a folder, it searches subfolders to any level (it searches the directory hierarchy). Select File System from the drop-down list labeled Look in folder. Select Other to search a folder not included in list; GNOME opens the Browse/Save window (page 110). Once you have entered the search criteria, click Find. GNOME displays the list of files matching the criteria in the list box labeled Search results. Double-click a file in this list box to open it.

To refine the search, you can enter more search criteria. Click the sign to the left of Select more options to expand the window and display more search criteria.
