/dev/pts A to the Linux kernel. This pseudofsystem is part of the pseudoterm support. Pseudotystems are used by remote login programs, such as ssh and telnet, as well as xterm and graphical terminal emulators. The following sequence of commands demonstrates Sam is logged in using /dev/pts/2. After who am i to verify the pseudoterm he is logged in and using is echo to show that Sam redirects the output of an echo command to /dev/pts/2,

```
$ sam who am i 2010-05-31 17:37 (dog.bogus.com)

0 2
$ echo Hi > /dev/pts/2
Hi here
```

/dev/random Interfaces with the kernel's random number generator. You can use either file with dd
and create a file filled with pseudandom bytes.
/dev/urandom

```
$ dd if=/dev/urandom of=randfile bs=1 count=100
100+ records in
100+ bytes (100 B) copied, 0.000884387 seconds, 113 KB/s
```

The preceding command reads from /dev/urandom and writes to the file named randfile. The block size is 1 and the count is 100; thus randfile is 100 bytes long.
For bytes that are more random, you can read from /dev/random. We use the random\and random man pages for more information.

# optional wiping a file

You can use a similar technique to wipe data from a file before deleting, making it
almost impossible to recover data from the deleted file. You might want to wipe a
file for security reasons.
In the following example, ls shows the size of the file named secret. Using a block
size of 1 and a count corresponding to the number of bytes in secret, dd wipes the
file The conv=trunc ensures that dd writes over data in the file and
not another (either) place on the disk.

```
$ ls -l secret
-rw-r--r-- 1 sam sam 5733 2010-05-31 17:43 secret
$ dd if=/dev/urandom of=secret bs=1 count=5733 conv=trunc
5733+ records in
5733+ bytes (5.7 KB) copied, 0.03581466 seconds, 160 KB/s
$ rm secret
```

For added security, run sync to flush the disk buffers after running dd, and repeat
the two commands several times before deleting the file. See wipe.sourceforge.net
for more information about wiping files.
