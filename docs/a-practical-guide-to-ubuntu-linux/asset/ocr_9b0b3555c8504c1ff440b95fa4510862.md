# gzip versus zip

Do not confuse gzip and gunzip with the zip and unzip utilities. These last two are used to pack and unpack archives containing several files into a single file that has been imported from or is exported to a system Windows. The zip utility constructs a zip archive, whereas unzip unpacks archives. The zip and unzip utilities are compatible with PKZIP, a Windows program that compresses archives and files.

# tar: PACKS AND UNPACKS ARCHIVES

The tar utility performs many functions. Its name is short for tape archive, as its original function was to create and read archive and backup tapes. Today it is used to create a single file (called a tar file, archive, or tarball) from multiple files or directory hierarchies and to extract files from a tar file. The utility (page 602) performs a simple function.

In the following example, the first ls shows the files g, b, and d. Next tar uses -c (create), -v (verbose), and -f (write or read from a file) options to create an archive named alltar from these files. Each line of output displays the name of the file appending to the archive it is creating.

The tar utility adds overhead when creating an archive. The next command shows the archive alltar occupies 9,700 bytes, whereas the sum of the three files is 6,000 bytes. This overhead is much more appreciable on smaller files, such as the ones in this example:

```
$ ls -l g b d
-rw-r--r-- 1 zach other 1178 2010-08-20 14:16 b
-rw-r--r-- 1 zach 3783 2010-08-20 14:17 d
-rw-r--r-- 1 zach 1302 2010-08-20 14:16 g

$ tar -cvf all.tar g b d
g
b
d
$ ls -l1 all.tar
-rw-r--r-- 1 zach 9728 2010-08-20 14:17 all.tar
-rw-r--r-- 1 zach /other 1178 2010-08-20 14:16 b
-rw-r--r-- 1 zach /jach 3783 2010-08-20 14:17 d
```

The final command in the preceding example uses the -t option to display a table of contents for the archive. Use -x instead of -t to extract files from a tar archive. Omit the -v option if you want tar to work silently²

> ² Although the original UNIX tar did not use a leading hyphen to indicate an option on the command line, the GNU/Linux version accepts hyphens, but works without them. This book precedes tar options with a hyphen for consistency with most other utilities.
