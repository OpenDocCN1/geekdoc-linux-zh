ssrc server Contains initialization routines. When a user on a client connects to

~/.ssh: USER FILES
OpenSSH creates the ~/.ssh directory and the known_hosts file therein automatically
when a user connects to a remote system.

authorized_keys server Enables a user to log in or copy files to and from another without
supplying a user login password (page 677). However, the user may need to supply a
passphrase, depending on how the key was set up. No one except the owner should
 able to write to this file.

config client User's OpenSSH configuration file (page 674). Entries however override
t in /etc/ssh/ssh_config.

environment server Contains assignment statements that define environment variables on
server when a user logs in ssh.

id_dssa client User authentication DSA keys generated by ssh-keygen (page 677). Both files
id_dssa.pub public file should be owned by the user in whose home directory they appear.
id_dssa.pub public file should be readable by anyone but writable by its owner
(644 permissions). The id_dssa private file should not be readable or writable by
anyone except its owner (600 permissions).

id_rsa client User authentication RSA keys generated by ssh-keygen (page 677). Both files
id_rsa.pub public file should be owned by the user in whose home directory they appear. The id_rsa.pub
public file should be readable by anyone but writable by its owner
(644 permissions). The id_rsa private file should not be readable or writable by
anyone except its owner (600 permissions).

known_hosts client Contains public keys (default) of hosts the user has connected to.
SSH automatically adds entries each time the user connects to a new server
(page 668). Refer to "HostKeyAlgorithms" (page 675) for information on using
DSA keys. If HashKnownHosts (page 675) is set to yes, the hostnames and addresses
in this file are hashed to improve security.
