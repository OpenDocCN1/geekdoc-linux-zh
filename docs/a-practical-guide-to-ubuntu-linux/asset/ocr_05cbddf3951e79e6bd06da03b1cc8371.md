# OPTIONS

This section describes the options you can use on the mysql command line.
The options preceded by a single hyphen and those preceded by a double hyphen
are equivalent.

--disable-reconnect

Does not attempt to connect to the server again if the connection is dropped.
See --reconnect.

--host=hostname -h hostname

Specifies the address of the MySQL server as hostname. Without this option
MySQL connects to the server on the local system (127.0.0.1).

--password=[password]

-p[password]
Specifies the MySQL password as passed. For improved security, do not spec-
ify the password on the command line; MySQL will prompt you for it. By default,
MySQL does not use a password. In the short form of this option, do not put a
SPACE between the -p and password.

--reconnect

Attempts to connect to the server again if the connection is dropped (default).
Disable this behavior using --disable-reconnect.

--user=user -u user

Specifies the MySQL user as user. When you first install MySQL, there is one
user, and root that does not have a password.

--verbose -v Increases the amount of information MySQL displays. Use this option multiple
times to increase verbosity.

# THE .my.cnf CONFIGURATION FILE

You can use the .my.cnf file to set MySQL options. The following example shows
Max's .my.cnf file. The [mysql] specifies the MySQL group. The next lines show Max's
password to mpassword. With this setup, Max does not have to use -p on the
command line; MySQL logs in automatically.

```
$ /home/max/ .my.cnf
[mysql]
password="mpassword"
```

# WORKING WITH MySQL

Adding a user Before to start with the database, create a user so you do not have to work
as the MySQL root user. If the MySQL username you is the same as your Linux
username, you will not have to use a username on the MySQL command line.
in this example, Max works as the MySQL user named max with a password of
massword maxdb and the MySQL user named max supplies the password
in response to the Enter password prompt, Max supplies the password
the MySQL user named root. The GRANT statement gives Max the permissions
needs to work with the maxdb database. You must work as the MySQL root user
to set up a MySQL user. The -p option causes MySQL to prompt for the password.
