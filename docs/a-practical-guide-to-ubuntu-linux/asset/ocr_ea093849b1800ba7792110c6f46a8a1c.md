Separating the physical control of the display (the server) from the processes needing access to the display (the client) makes it possible to run the server on one computer and the client on another computer. Most of the time, this book discusses the X server and client applications on a single system. "Remote Computing and Local Displays" uses X in a distributed environment.

You can run x (X event) by giving the command from a terminal emulator window and then watch the information flow from the client to the server and back again. This utility opens the Event Tester window, which has a box in it, and asks the X server to send it every time anything happens, moving as the mouse pointer, clicking a mouse button, moving the mouse into the box, typing, or resizing the window. The x utility displays information about each event in the window you opened it from. You can use xev as an educational tool: Start it and see how much information is processed each time you move the mouse. Close the Event Tester window to exit xev.

# ## STARTING X FROM A CHARACTER-BASED DISPLAY

Once you have logged in a virtual console (page 149), you can start an X Window system by using startx. See "rc-sysinit task and inittab" on page 439 for information on creating a /etc/initab file that allows Linux to boot into (single-user) mode, where it displays a textual interface. When you run startx server displays an screen, using the first available virtual console. The following command allows start to run in the background so you can switch back to this virtual console and give other commands:
