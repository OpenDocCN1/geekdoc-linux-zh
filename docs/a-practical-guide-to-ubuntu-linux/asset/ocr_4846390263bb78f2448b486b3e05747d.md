multicast A multicast packet has one source and multiple destinations. In Multicast, source hosts register at a special address to transmit data. Destination hosts register at the same address to receive data. In contrast to broadcast (page 1138), which is LAN-based, multicast traffic is designed to work across routed networks on a subscription basis. Multicast reduces network traffic by transmitting a packet one time, with the router at the end of the path breaking it as needed for multiple recipients.

multitasking A computer system that allows a user to run more than one job at a time. A multi-task system, such as Linux, allows you to run a job in the background while running a job in the foreground.

multiuser system A computer system that can be used by more one person at a time. Linux is a multiuser operating system. Contrast with single-user system (page 1172).

namespace A set of names (identifiers) by which all names are unique.

NAT Network Address Translation. A scheme that enables a LAN to use one IP addresses internally and a different set externally. The internal set is for LAN (private). The external set is typically used on the Internet and is unique. NAT provides privacy by hiding internal IP addresses and allows multiple internal addresses to connect to the Internet through a single external IP address. See also masquerade on page 1159.

NBT NetBIOS over TCP/IP. A protocol that supports NetBIOS services in a TCP/IP environment. Also NetBT.

negative caching Storing the knowledge that something does not exist. A cache normally stores information about something that exists. A negative cache stores the information that something, such as a record, does not exist.

NetBIOS Basic Input/Output System. An API (page 1135) for writing network-aware applications.

netboot To boot a computer over the network (as opposed to booting to a local disk).

netiquette The conventions of etiquette—that is, polite behavior—recognized on Usenet and mailing lists, such as not (cross-)posting to inappropriate groups and refrain from commercial advertising outside the business groups.

The most important rule of etiquette is “Think before you post.” If you intend to post will not make a positive contribution to the newsgroup and if not to several readers, do not post it. Personal messages to one or individuals should not be posted to newsgroups; use private email instead.

netmask A 32-bit mask (IPv4), that shows how an Internet address is to be divided into network, subnet, and host parts. The mask has ones in the positions 32-bit address that are to be used for the network and subnet parts and zeros for the host part. The mask should contain at least the standard network portion (determined by the address class). The subnet field should be contiguous with the network portion.
