dc_minimaldns='bool'
Set bool to true to minimize DNS lookups (useful for dial-up connections) or to
false to perform DNS lookups as needed.

dc_other_hostnames='bool-list'
The host-list is a semicolon-separated list of IP addresses and/or FQDNs the local
system accepts (but does not relay) email for; localhost (127.0.0.1) is assumed to be
in this list.

dc_readhost='hostname'
The hostname replaces the local mailname in the headers of email originating on
local systems. This setting is effective only if dc_hide_mailname is set to true and
c_exim_configtype is set to smarthost or satellite.

dc_relay_domains='bool-list'
The host-list is a semicolon-separated list of IP addresses and/or FQDNs the local
system accepts mail for, but not deliver to local systems. The local system
relays mail to these systems. For example, the local system may be a secondary
relay for these systems.

dc_relay_nets='bool-list'
The host-list is a semicolon-separated list of IP addresses and/or FQDNs of
the local systems relay mail for. The local system is a smarthost (page 717) for
semes systems.

dc_smarthost='bool-list'
The host-list is a semicolon-separated list of IP addresses (preferred) and/or FQDNs
the local system sends email for relaying to nonlocal systems (a smarthost;
page 717). See “JumpStart” on page 716 for an example.

dc_use_split_config='bool'
Controls which files update-exim4.conf uses to generate the configuration file for
exim4.conf. See “Split configuration” (page 725) for more information.

# dpkg-reconfigure: CONFIGURES exim4

The dpkg-reconfigure utility reconfig the installed copy of a software package. It
dis a pseudographical window that can be used from any character-based
device, including a terminal emulator. The following command enables you to
reconfigure exim4 interactively:

```
$ sudo dpkg-reconfigure exim4-config
```

The first window this command displays briefly the differences between the
split and unset configurations (page 725), where you can find more informa-
t on this topic, and asks if you want to set up the split configuration (Figure 20-1).
If you choose to set up a split configuration, dpkg-reconfigure assigns a value to
dc_use_split_config (“Split configuration” on page 725) and continues as though
you have chosen to use an unsplit configuration: It does not modify files in the
/etc/exim4/conf.d directory hierarchy. This setup allows update-exim4.conf to read
files in the /etc/exim4/conf.d directory hierarchy, incorporating any changes you
make to those.
