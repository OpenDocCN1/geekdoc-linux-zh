The first two lines of the following program assign values to the @colors array and display these values. Each of the next two pairs of lines uses sort to put the values in the @colors array in order, assign the result to @colors, and display @colors. These sorts put uppercase before lowercase letters. Observe the positions of Orange and Violet, both of which begin with an uppercase letter, in the sorted output. The first assignment statement in these two pairs of lines uses the full sort syntax, including the block {a cmp b} that tells Perl to use the cmp subroutine, compares strings, and put the result in ascending order. When you omit the block in a sort statement, as is case in the second assignment statement, Perl also performs an ascending textual sort.

# $ cat sort3.pl

```
@colors = ("red", "Orange", "yellow", "green", "blue", "indigo", "Violet");
```

```
say "@colors";
```

```
@colors = sort {$a cmp $b} @colors;
# ascending sort
say "@colors";
```

```
@colors = sort @colors;
# an implicit block
say "@colors";
```

```
@colors = sort {$b cmp $a} @colors;
# descending sort
say "@colors";
```

```
@colors = sort {lc($a) cmp ($b)} @colors;
# ascending folded sort
say "@colors";
```

# $ perl sort3.pl

```
red yellow green blue indigo Violet
Orange Violet blue green indigo red yellow
Orange Violet blue green red yellow
yellow red green blue Violet Orange
blue green indigo Orange red yellow
```

The third line in the preceding example reveals the positions of Sa and Sb in the block to specify a descending sort. The last sort converts the strings to lowercase before comparing them, providing a sort wherein the uppercase letters are before the lowercase letters. As a result, Orange and Violet appear in alphabetical order.

To perform a numerical sort, specify the <> subroutine in place of cmp. The following example demonstrates ascending and descending numerical sorts:

# $ cat sort4.pl

```
@numbers = (22, 188, 44, 12);
```

```
print "@numbers\n";
```

```
@numbers = sort {$a <=> $b} @numbers;
print "@numbers\n";
```

```
@numbers = sort {$b <=> $a} @numbers;
print "@numbers\n";
```
