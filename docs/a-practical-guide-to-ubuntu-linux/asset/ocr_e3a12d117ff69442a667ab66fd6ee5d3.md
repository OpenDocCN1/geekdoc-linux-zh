# THE WINDOW MANAGER

A window manager—the program that controls the look and feel of the GUI—runs under a desktop manager (such as GNOME or KDE) and controls all aspects of the windows in the Window System environment. The window manager defines the appearance of the windows on the desktop and controls how you operate and position them: open, close, move, resize, and so on. It also handle some session management functions, such as how a session is paused, restarted, or ended (page 116).

Window decorations A window manager controls window decorations—that is, the titlebar and border of a window. Aside from the aesthetic aspects of changing window decorations, you can alter their functionality by modifying the number and placement of buttons on the titlebar.

The window manager takes care of window manipulation so client programs do not need to do so. This setup is very different from many other operating systems, and what that GNOME deals with window managers is different from more than simply manage windows—they provide a useful, good-looking, graphical shell where you can work. Their open window design allows users to define their own policies, down to the fine details.

Theoretically GNOME is not dependent on any particular window manager and can work with any of several window managers. Because of their flexibility, you would not see major parts of the desktop environment change if you were to switch from one window manager to another. A desktop manager collaborates with the window manager to make your work intuitive and easy to use. Although the desktop manager does not control window placement, it gets information from the window manager about window placement.

# UBUNTU WINDOW MANAGERS

Metacity and Compiz—the default window managers for GNOME—provide window management and start many components through GNOME panel objects. They also communicate and facilitate access to other components in the environment. The Visual Effects tab of the Appearance Preferences window (page 115) allows you to switch between Metacity and Compiz.

Using the standard X libraries, programmers have created other window managers, including blackout, fluxbox, and WindowMaker. You can use synaptic (page 133) to install any of these packages.
