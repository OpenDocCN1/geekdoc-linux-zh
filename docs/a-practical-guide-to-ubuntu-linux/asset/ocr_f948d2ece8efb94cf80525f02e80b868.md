# The --help option

tip Many utilities display a (sometimes extensive) help message when you call them with an argument of --help. All utilities developed by the GNU Project (page 4) accept this option. An example follows.

$ bzip2 --help
bzip2, a block-sorting file compressor. Version 1.0.5, 10-Dec-2007.

```
usage: bzip2 [flags and input files in any order]
-h --help               print this message
-d --decompress        force decompression
-z --compress          force compression
-k --keep              keep (don't delete) input files
-f --force              overwriting output files
```

If invoked as 'bzip2', default action is to compress.
as 'bunzip2', default action is to decompress.
as 'bzcat', default action is to decompress to stdout.
