# SUBNETS

Each host on a network must process each broadcast packet to determine whether the information in the packet is useful to that host. If the network includes numerous hosts, each host must process many packets. To maintain efficiency most networks—and particularly shared media networks as Ethernet—need to be split into subnet, or subnets. The more hosts on a network, the more dramatically network performance is affected. Organizations use router and switch technology to VLANs (virtual local area networks) to group similar hosts into broadcast domains based on function. For example, it is not uncommon to switch with different ports being part of different subnets. See page 462 for information on how to specify.

A subnet mask (or address mask) is a bit mask that identifies which of an IP address corresponds to the network address and the subnet portion of the address. This mask has 1s corresponding to the network and subnet numbers and 0s in the host number positions. When you perform a bitwise AND on an IP address and a subnet mask the resulting address contains except the host (hostid) portion.

There are several ways to represent a subnet mask: A network could have a subnet mask of 255.255.255.0 (decimal), FFFFF0 (hexadecimal), or /24 (the number of bits used for the subnet). If it is a Class B network (of which 16 bits are already fixed), these 2⁸ (24 bits — 16 bits = 8 bits, 2⁸ = 254) networks with 2⁸ - 2 (256 – 2 = 254) on each network.

For example, when you divide the Class address 192.25.4.0 into eight subnets, you get a subnet mask of 255.255.255.224, FFFFFE0, or /27 (27 bits). The result-networks are 192.25.4.0, 192.25.4.32, 192.25.4.64, 192.25.4.96, 192.25.4.128, 192.25.4.160, 192.25.4.192, and 192.25.4.224. You can use a Web-based subnet mask calculator to calculate subnet masks (refer to “Network Calculators” on page 1105). To use this calculator to determine the preceding subnet mask, start with an IP address of 192.25.4.0.
