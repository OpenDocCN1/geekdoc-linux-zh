Security is a major factor that is part of the foundation of any system that is not totally cut off from other machines and users. Some aspects of security have a place even on isolated machines. Examples of these measures include periodic system backups, BIOS or power-passwords, and self-locking screensavers.
A system that is connected to the outside world requires other mechanisms to secure it: tools to check files (tripwire), audit tools for secure access methods (kerberos/ssh), services that monitor logs and make machine states (swatch/watcher), packet-filtering and routing tools (iptwadn/iptables/uffw), and more.
System security has many dimensions. The security of a system as a whole depends on the security of individual components, such as email, network, login, and remote access policies, as well as the physical security of the host itself. These dimensions frequently overlap, and their borders are not static or clear. For instance, email security is affected by the security of both files and the network.
