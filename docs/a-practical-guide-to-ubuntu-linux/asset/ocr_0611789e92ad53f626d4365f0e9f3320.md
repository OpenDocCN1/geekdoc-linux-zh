To terminate a program from a textual display, press the interrupt key (CONTROL-C or sometimes DELETE or DEL). When you press this key, the Linux operating system sends a termination signal to the program you are running and to the shell. Exactly what effect this signal has on the program. Some programs stop execution immediately, ignore the signal, and some take other actions. When the shell receives a termination signal, it displays a prompt and waits for another command.

If these methods do not terminate the program, try sending a program quit signal (CONTROL-). If all fails, try pressing the suspend key (typically CONTROL-2), giving a jobs command to verify the number of the running program, and using kill to abort the job. The job number is the number within the brackets at the left of the line displayed by jobs ([1]). In the next example, the kill command (page 455) uses -TERM to send a termination signal^ to the job specified by the job number, which is preceded by a percent sign (%1). You can omit -TERM from the command, as kill sends a termination signal by default.

```
$ jobob
[1]+ Stopped bigjob
$ jobs bigjob
[1]+ Stopped
$ kill -TERM %1
$ RETURN
[1]+ Killed bigjob
```

The kill command returns a prompt; press RETURN to see the confirmation message. For more information refer to "Running a Command in a Background" on page 254.

# REPEATING/EDITING COMMAND LINES

To repeat a previous command, press the UP ARROW key. Each time you press, the shell displays an earlier command line, press RETURN. Press the DOWN ARROW key to browse through the command lines in the other direction.

You can also repeat the previous command using !!. This technique is useful if you forget to use sudo (page 421) before a command. In this case, if you use sudo !!, the shell will repeat the previous command preceded by sudo.
