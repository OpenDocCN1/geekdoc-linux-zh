# How to prevent the shell from invoking an alias

tip The shell checks only single, unquoted commands to see if they are aliases. Commands given as relative or absolute pathnames and quoted commands are not checked. When you want to give a command that has an alias but do not want to use the alias, precede the command with a backslash, specify the command's absolute pathname, or give the command as /.command.

If you use the command -ls frequently, you can create an alias that substitutes ls -ltr when you use the command:

```
$ alias r='fc -s '
```

Another common use of alias is to protect yourself from mistakes. The following example substitutes the interactive version of the rm utility when you give the command: zap:

```
$ alias zap='rm -i'
$ zap fo
rm: remove 'fixtam.icn'? n
rm: remove 'flute.ps'? n
rm: remove 'floor'? n
```

The -i option allows rm to ask you to verify that each file would be deleted, helping you avoid deleting the wrong file. You can also alias rm with the rm -i command: alias rm='rm -i'.
