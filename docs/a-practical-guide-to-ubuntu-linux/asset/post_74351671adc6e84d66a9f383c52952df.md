The first statement sends the string enclosed within double quotation marks to standard output (the screen unless you redirect it). In double quotation marks, Perl expands variable names to the value of the named variable. The first say statement displays the values of three variables, separated from each other by SPACES.

The third say statement sends the string enclosed within single quotation marks to standard output. Within single quotation marks, Perl interprets all characters literally, so it displays the string exactly as it appears between the quotation marks.

# ARRAY VARIABLES

An array variable is an ordered container of scalars whose name begin with a sign (@) and whose first element is numbered zero (zero-based indexing). Because an array can hold zero or more scalars, it is a plural variable. Arrays are ordered; hashes (page 1056) are unordered. In Perl, arrays grow as needed. If you reference an uninitialized element of an array, such as an element beyond the end of the array, Perl returns undef.

The first statement in the following program assigns the values of two numbers and a string to the array named @arrayvar. Because Perl uses zero-based indexing, the first say statement displays the value of the second element of the array (the element with index 1). This statement specifies the variable $arrayvar[1] as a scalar (singular) because it returns a single value. The second say statement specifies the variable @arrayvar[1,2] as a list (plural) because it returns multiple values (with the indexes 1 and 2).

```
$ cat array1.pl
!/usr/bin/perl -w
@arrayvar = (8, 18, "Sam")
say $arrayvar[1];
say "@arrayvar[1,2]";
```

```
$ perl array1.pl
18
Sam
```

# HASH VARIABLES

A variable, sometimes called an associative array variable, is a plural data structure that holds an array of key-value pairs. It uses strings as keys (indexes) and is optimized to return a value quickly when given a key. Each key must be unique scalar. Hashes are unordered; arrays (page 153) are ordered. When you assign a hash to a list, the key-value pairs are preserved, but their order is neither.

Perl provides two syntaxes to assign values to a hash. The first uses a single assignment statement for each key-value:

```
$ hash1.pl
!/usr/bin/perl -w
$hashvar{boat} = "tuna";
$hashvar{"number five"} = 5;
$hashvar{4} = "fish";
```

```
@arrayhash1 = %hashvar;
say "@arrayhash1";
```

```
$ .hash1.pl
boat 4 fish number five 5
```

With an assignment statement, the key is located within braces to the left of the equal sign; the value is on the right of the equal sign. As illustrated in the preceding example, keys and values can take on either numeric or string values. You do not need to quote keys unless they contain SPACE.

The next example shows the other way of assigning values to a hash and illustrates how to use the keys and values functions to extract keys and values from a hash. After assigning values to the %hash2 hash, hash2.pl calls the hash function with argument of %hash2 and assigns the resulting list of keys to the @array_values array.

```
$ hash2.pl
!/usr/bin/perl -w
%hash2 = (
boat => "tuna",
"number five" => 5,
4 => "fish",
);
```

```
@array_keys = keys(%hash2);
say "Keys: @array_keys";
```

```
@array_values = values(%hash2);
say "Values: @array_values";
```
