The **diff -u** command breaks headers, multiline text into **hunks**. Each hunk is preceded by a line starting and ending with two signs at (@@). This hunk identifies the starting line number and the number of lines from each file for this hunk. In Figure 5-8, the hunk covers the section of the colors.1 file (indicated by a minus sign) from the first line to the sixth line. The **+1,5** indicates that the hunk covers colors.2 from the first line to the fifth line.

Following these headers, **diff -u** displays each line of text with a leading minus sign, a leading plus sign, or a SPACE. A leading minus sign indicates that the line occurs only in the file denoted by the minus sign. A leading plus sign indicates that the line occurs only in the file denoted by the plus sign (neither a plus sign nor a minus sign) occurs in both files in the same location. Refer to the diff info page for information.
