# WORKING WITH exim4 Messages 723

You can also send email to standard input of a command by preceding the command with the pipe character (l). This technique is commonly used by mailing software such as Mailman (page 734). For each list it maintains, Mailman has entries, such as the one for painting_class, in the aliases file:

painting_class: "/var/lib/mailman/mail/mailman post painting_class"

See the exim4_files page for information on exim4-files, including aliases. After you edit /etc/aliases, you must run newaliases while you are working with root privileges. The /usr/bin/newaliases is a symbolic link to exim4. Running newaliases calls exim4, which rebuilds the exim4 aliases database.

~forward Systemwide aliases are useful in many cases, but nonroot users cannot make or change them. Some times you want to forward your own mail to one address or perhaps you want to forward your mail from several systems to one address while you are working at another office. The -forward file allows ordinary users to forward their email.

Lines in a .forward file are the same as the right column of the aliases file explained earlier in this section: Destinations are listed one per line and can be a local user, a remote email address, a filename, or a command preceded by the pipe character (l).

Mail that you forward does not go to a local mailbox. If you want to forward mail and keep a copy in your local mailbox, you must specify your username preceded by a backslash to prevent an infinite loop. The following example sends Sam's to himself on the local system and on the system at:

```
$cat ~/.forward
sams@example.com
sams
```

# RELATED PROGRAMS

exim4 packages include several programs. The primary program, exim4, reads from standard input and sends an email to the recipient by its argument. You can use exim4 from the command line to check that the mail delivery system is working and to email the output of scripts. Use "Test" on page 718 for an example. The command apropos displays a list of exim4-related files and utilities. In addition, you can call exim4 with options (page 721) or using links to perform various tasks.

exim4 -up When you call exim4 with the -bp option, or when you call the mail utility (which is a symbolic link to exim4), it displays the status of the outgoing mail queue. When there are no messages in the queue, it displays nothing. Unless there are messages in the queue usually indicate a problem with the local or remote MTA configuration or network problem.

```
$ sudo exim4 -bp
24h 262 LIBhyI-0006it-7Q <sam@ *** frozen *** zachs@example.com
```
