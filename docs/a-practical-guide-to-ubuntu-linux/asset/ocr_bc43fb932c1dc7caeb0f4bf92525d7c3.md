# GRAPHICAL PARTITION EDITORS

A partition editor displays and can add, delete, and modify partitions on a hard disk. This section describes three graphical partition editors you can use to configure a hard disk in the process of installing Ubuntu. The gparted and palimpsest editors are available from a live session. The other partition editor is part of the ubiquity installer and is not available by itself. See page 87 for information on using the textual partition editor, which is available when you use the textual installer.
