If you want to have the whoson function always be available without having to startup files enter it each time you log in, put its definition in ~/.bash_profile. Then run using the .() command to put the changes into effect immediately:

```
$ cat ~/.bash_profile
export TERM=vt100
stty kill '^C'
whoson()
{
  date
  echo "Users Currently Logged On"
  who
}
. ~/.bash_profile
```

The following function allows you to export variables using tcsh syntax. The env builtin lists all environment variables and their values and verifies that setenv works correctly:

```
$ cat .bash_profile
# setenv keep tcsh users happy
function setenv()
{
  if [ $# -eq 2 ];
  then
    eval $1=$2
    export $1
  else
    echo "Usage: setenv NAME VALUE 1>&2"
  fi
}
. ~/.bash_profile
$ setenv TCL_LIBRARY /usr/local/lib/tcl
$ env | grep TCL_LIBRARY
TCL_LIBRARY=/usr/local/lib/tcl
```
