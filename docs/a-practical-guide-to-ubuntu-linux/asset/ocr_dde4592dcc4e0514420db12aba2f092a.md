# top: LIST PROCESS USING THE MOST RESOURCES

The top utility is a useful supplement to ps. At its simplest, top displays system information at the top and the most CPU-intensive processes become the system information. The top updates itself periodically; press q to quit. Although you can use command-line options, the interactive commands are often more helpful. Refer to Table 16-2 and the top page for more information.

Table 16-2 top: interactive commands

| Command | Function |
| A | Sorts processes by age (newest first). |
| h ? | Displays a Help screen. |
| k | (kill) Prompts for a PID number and type of signal sends the process that does signal. Defaults to 15 (SIGTERM); specify 9 (SIGKILL) only when 15 does not work. |
| M | Sorts processes by memory usage. |
| P | (processor) Sorts processes by CPU usage (default). |
| q | Quits top. |
| s | Prompts for time between updates in seconds. Use 0 (zero) for continuous updates; updates can slow the system by consuming a lot of resources. |
| SPACE | Updates the display immediately. |
| T | Sorts tasks by time. |
| W | Writes a startup file ~/.toprc so that the next time you start top, it uses the same parameters it is currently using. |
