# 854 CHAPTER 24 DNS/BIND: TRACKING DOMAIN NAMES AND ADDRESSES

The resource record for localhost is followed by two CNAME resource records that specify www(sam.net) and ftp(sam.net) aliases for the nameserver ns.sam.net. For example, a user connecting to ftp.sam.net will connect to 192.168.0.6. The resource records gw, ns, mark and mail are resource records for domains within the sam.net zone.

Log files before restarting named, create the directory for the log files and give permissions and ownership as shown below. If you are running named in a chroot jail, create the bind directory in /var/log/named/var/log.

```
$ mkdir /var/log/bind
$ sudo chown bind:bind /var/log/bind
$ ls -ld /var/log/bind
drdw-xr-x 2 bind 4096 2010-04-26 17:43 /var/log/bind
```

With the log directory in place, and the named.conf, db.root, named.conf.local, and sam.net zone files in /etc/bind or in /var/log/named/etc if you are running named in a chroot jail), restart named and check the log files. # A SLAVE SERVER

To set up a slave server, copy the /etc/bind/named.conf file from the master server to the slave server, replacing the master type with type slave and adding a masters (1.2.3.4); directive. Remove any zones the slave server will not be acting as a slave for, including the root (.), if the slave server will not respond to recursive queries. Now, create the /var/log/bind directory for log files as explained at the end of the previous section.
