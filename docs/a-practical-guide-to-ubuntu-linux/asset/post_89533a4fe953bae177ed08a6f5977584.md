## GREEDY MATCHES

By default Perl performs greedy matching, which means a regular expression matches the longest possible (page 1093). In the following example, the regular expression /\{.*\}/ matches an opening brace followed by any string of characters, a closing brace, and a SPACE (remove me) may have two (keep me). Perl substitutes a null string (/) for this match.

```
$ cat Sha.pl
$string = "A line (remove me) may have two {keep me} pairs of braces.";
$string = s/{}///g;
print "$string\n";
```

```
$ perl Sha.pl
A line pairs of braces.
```

Nongreedy matches the next example shows the matching of the shorter brace-enclosed string from the previous example. This type of match is called nongreedy or parsimonious matching. Here are the regular expression matches:

- 1. An opening brace followed by
- 2. A character belonging to the character class (page 1091) that includes all characters except a closing brace ([^\}]) followed by
- 3. Zero or more occurrences of the preceding character (*) followed by
- 4. A closing brace followed by
- 5. A SPACE.

(A caret as the first character of a character class specifies the class of all characters that do not match the following characters, so [^\]] matches any character that is not a closing brace.)

```
$ cat re5b.pl
$string = "A line (remove me) may have two {keep} pairs of braces."
$string = s/\{[^\}]\}/g;
print "$string\n";
```

```
$ perl re5b.pl
A line may have two {keep} pairs of braces.
```

Perl permits allows you to specify a nongreedy match. In the following example, the question mark in [.*?] causes the regular expression to match the shortest string that starts with an opening brace followed by any of characters followed by a closing brace.

```
$ cat re5c.pl
$string = "A line (remove me) may have two {keep} pairs of braces."
$string = s/\{.*\}/g;
print "$string\n";
```

```
$ perl re5c.pl
A line may have two {keep} pairs of braces.
```

## BRACKETING EXPRESSIONS

As explained on page 1094, you can bracket parts of a regular expression and recall those parts in the replacement string. Most Linux utilities use quoted parentheses [i.e., \[ \]] to bracket a regular expression. In Perl expressions, parentheses are special characters. Perl permits the backslashes and uses unquoted parentheses to bracket regular expressions. To specify a parenthesis as a regular character within a regular expression in Perl, you must quote it (page 1093).

The next example uses unquoted parentheses in a regular expression to bracket part of the expression. It assigns the part of the string that the bracketed expression matched to the variable that the string in Perl searched for.

First the program assigns the string My name is Sam to $stg. The next statement looks for a match for the regular expression /My name is (.*)/ in the string held by $stg. The part of the regular expression bracketed by parentheses matches Sam; the $1 in the replacement string matches the first (and only in this case) matched portion of the regular expression. The result is that the string in $stg is replaced by the string Sam.

```
$ cat rell.pl
$stg = "My name is Sam";
$stg = s/My name is (.*)/$1;
print "Matched: $stg\n";
```

```
$ perl rell.pl
Matched: Sam
```

The next example uses regular expressions to parse a string for two numbers. Two variables are initialized to a string that contains two numbers. The third line of the program uses a regular expression to isolate the first number in the string. The \D matches a string of zero or more characters that do not include a digit: The \D special characters match any single digit character. The trailing asterisk matches this part of the regular expression to perform a greedy match that does not include a digit (matches What is). The bracketed regular expression \d+ matches a string of one or more digits; they allow $1 in the replacement string to match what the bracketed regular expression matched. The final \* matches the rest of the string. This line assigns the value of the first number in the string to $string.

The next line is similar but assigns the second number in the string $string2. The print statements display the numbers and the result of subtracting the second number from the first.

```
$ cat reff.pl
$string = "What is 488 minus 78";
$string2 = $string;
$string = s/\D(\d).*/$1;
$string2 = s/\D\d+\D(\d).*/$1;
```

```
print "$string\n";
print "$string2\n";
print $string - $string2, "\n";
```

```
$ perl reff8.pl
488
78
410
```

The next few programs show some of the pitfalls of using unquoted parentheses in regular expressions when you do not intend to bracket part of the regular expression. The first of these programs attempts to match parentheses with unquoted regular expression, but fails because the parenthesis is a special character.

```
$ perl -le if ("ag") =~ /\(/ { print "true"; } else { print "false"; }
false
```

When you quote the parenthesis, it is treated as a regular character and finds a match:

```
$ perl -le if ("ag") =~ /\(\)/ { print "true"; } else { print "false"; }
true
```

## CPAN MODULE

CPAN (Comprehensive Perl Archive Network) provides Perl documentation, FAQs, modules (page 1045), and scripts on its Web. It holds more than 16,000 distributions (page 1045) and provides links, mailing lists, and versions of Perl compiled to various operating systems. One way to locate a module is to visit and use the search box or click one of the classes of modules listed on that.

This section explains how to download a module from CPAN and how to run the module. Perl provides a hierarchical name for modules, separating components of a name with double colons (:). The example in this section uses the module named Timestamp:Simple, which you can read about and download from search.cpan.org/dist/Timestamp-Simple. The timestamp is the date and time in format YYYYMMDDHHMMSS.

To use a Perl module, you first download the file that holds the module. For this example, the search.cpan.org/~shoop/Timestamp-Simple-1.01/Simple.pm Web page has a link on the right side labeled Download. Click this link and save the file to the directory you want to work in. You do not need to use a privileged user until the last step of process, when you install the module.

Most Perl modules come as compressed files (page 176). With the working directory, decompress the file:

```
$ tar xvzf Timestamp-Simple-1.01.tar.gz
Timestamp-Simple-1.01/
Timestamp-Simple-1.01/Simple.pm
Timestamp-Simple-1.01/Makefile.PL
Timestamp-Simple-1.01/test.pl
Timestamp-Simple-1.01/Changes
Timestamp-Simple-1.01/MANIFEST
Timestamp-Simple-1.01/ARTISTIC
Timestamp-Simple-1.01/GPL
Timestamp-Simple-1.01/META.yml
```
