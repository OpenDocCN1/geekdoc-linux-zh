Items you enter Everything you enter at the keyboard is shown in a bold typeface. Within the text, this bold typeface is used; within examples and screens, this one is used. In the pre- example, the dollar sign ($) on the first line is a prompt that Linux displays, so it is not; the remainder of the first line is entered by a user, so it is bold.

Utility names Names of utilities are printed in this sans serif typeface. This book references the emacs text editor and the ls or lm command (or just ls) but instructs you to Enter ls–a command line. In this way the text distinguishes between utilities, which are programs, and the instructions you give on the command to invoke

Filenames Filenames appear in a bold typeface. Examples are memos5, letter.1283, and reports. Filenames may include uppercase and lowercase letters; however, Linux is case-sensitive (page 1139), so memo5, MEMOS, and Memo name three different files.

Character strings Within the text, characters and character strings are marked by putting them in a bold typeface. This convention avoids the need for quotation marks or other delimiters before and after a string. An example is the following string, which is displayed by the passwordsw prompt: Sorry, passwords do not match

Buttons and labels Words appear in a bold typeface in the sections of the book that describe a GUI. This indicates you can click a mouse button when the mouse pointer is over these words on the screen or over a button with: Click Next.

Keys and characters This book uses SMALL CAPS for three kinds of items:

+   - Keyboard keys, such as the space bar and the RETURN, ESCAPE, and TAB keys.
- The characters that generate, such as the spaces generated by the space bar.
- Keyboard keys that you press with the CONTROL key, such as CONTROL-D. (Even though D is an uppercase letter, you do not have to press the SHIFT key; enter CONTROL-D by holding the key down and pressing d.)

Prompts RETURNING Most examples include the shell–prompt that Linux is waiting for command–as a dollar sign ($), a hashmark (#), or a percent sign (%). The prompt does not appear in a bold typeface in this book because you do not enter it. Do not type the prompt on the keyboard when you are experimenting with examples from this book. If you do, the example will not work.

Examples omit the RETURN keystroke you must use to execute them. An example of a command is

```
$ vim.tiny memo.1204
```

To use this as a model for running the vim text editor, the command vim.tiny memo.1204 and press the RETURN key. (Press ESC ZZ to exit from vim; page 186 for a vim tutorial.) This method of entering commands makes the examples in the book correspond to what appears on the screen.

8. Different keys use different keys to move the cursor to the beginning of the next line. This book always refers to the key that ends a line as the RETURN key. Your keyboard may have a RET, NEWLINE, ENTER, or other key. Using the corresponding key on your keyboard each time this book asks to press RETURN.
