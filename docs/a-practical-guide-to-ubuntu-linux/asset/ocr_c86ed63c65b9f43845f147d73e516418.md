The ordering of View clauses within named.conf is critical the view that is presented to a client is the first view that contains: one for local users and one for public users, in that order. named.conf holds two View clauses: one for local users and one for public users, Local users are defined to be those on the 192.168.0/24 subnet or localhost (127.0.0.1); public users are defined to be any users. If you reversed the order of the View clauses, all users—including local users—would get the view intended for the public and no users would see the local view.

Many statements from the Options clause can be used within View clauses, where they override statements in the (global) Options clause. The recursion statement, which can appear within an Options clause, appears in each View clause. named.conf file sets up a server that provides recursive answers to queries that originate and iterative answers to queries from the public. This setup provides quick, complete answers to local users, limiting the network and processor bandwidth that is devoted to other users while continuing to provide authoritative name service for the local servers.
