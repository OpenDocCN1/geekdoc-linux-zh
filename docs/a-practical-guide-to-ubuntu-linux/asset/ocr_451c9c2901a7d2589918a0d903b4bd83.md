# DNS WORKS

Application programs do not issue DNS queries directly but use the gethostbyname() system call. The system comes up with the corresponding IP address transparent to the calling program. The gethostbyname() calls the hosts line in /etc/hosts.conf (page 475) to determine which files it should examine and/or which services it query and in what order to obtain the IP address corresponding to a domain name. When it needs to query DNS, the local system (i.e., the DNS client) queries the DNS database by calling the resolver library on the local system. This returns the required information to the application program.

# NOTES

+   Terms: The name of the DNS server is named. This chapter uses “DNS” and “named” DNS and named interchangeably.

+   Firewall The server normally accepts queries on TCP and UDP port 53. If the system is running a firewall, you need to open these ports. Using gufw (page 876), opens this port by setting a policy that allows service for DNS.

+   chroot jail The bind-chroot.sh script sets up named in a chroot jail. After you run this script, all files that control BIND are located within this jail. In this case the files used in this chapter are symbolic links to the files in the chroot jail. See page 847 for more information.
