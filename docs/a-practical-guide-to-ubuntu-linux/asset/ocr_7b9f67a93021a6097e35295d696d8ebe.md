The second command changes the secondary prompt to *secondary prompt:* followed by a SPACE. A multiline echo demonstrates the new prompt.

# IFS: SEPARATES INPUT FIELDS (WORD SPLITTING)

The IFS (Internal Field Separator) variable specifies the characters you can use to separate arguments on a command line. The default value is SPACE TAB newline. Regardless of the value of IFS, you can always use one or more SPACE or TAB characters to separate arguments on the command line, provided these characters are not quoted or escaped. When you assign IFS values, these characters can also separate fields—but only if they undergo expansion. This type of interpretation of the command line is called *word splitting*.

**Be careful** changing IFS has a variety of side effects, so work cautiously. You may find it useful to save the value of IFS before changing it. Then you easily restore the original value if you get unexpected results. Alternatively, you can fork a new shell with a *bash* command before experimenting with IFS; if you get into trouble, you can *exit* back to the old shell, if IFS is working properly.

The following example demonstrates how IFS can affect the interpretation of a command line:

```
$ a=w:x:y:z

$ cat a
cat w:x:y:z: No such file or directory
$ IFS=""

$ cat a
cat w: No such file or directory
cat x: No such file or directory
cat y: No such file or directory
cat z: No such file or directory
```
