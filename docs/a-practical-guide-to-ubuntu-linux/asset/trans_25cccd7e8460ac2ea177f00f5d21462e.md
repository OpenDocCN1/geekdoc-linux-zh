  Ubuntu: YES

# DISPLAY

- 本节描述了可以如何通过控制 vsftpd 显示信息的方式来提高安全性能的参数。

hide_ids
YES 在目录列表中将所有用户和组列为 ftp。NO 列出真实的所有者。

- 默认：NO

- setprotitle_enable
NO 会导致 `ps` 将运行 vsftpd 的进程显示为 vsftpd。YES 会让 `ps` 显示 vsftpd 当前正在执行的操作（如上传等）。将此参数设置为 NO 以获得更安全的系统。

- 默认：NO

- text_userdb_names
NO 通过在目录列表中显示数字 UIDs 和 GIDs 来提高性能。
YES 显示名称。

- 默认：NO

- use_localtime
NO 会导致 `ls`、`mls` 和 `modtime` FTP 命令显示 UTC（第 1179 页）。
YES 会导致这些命令显示本地时间。

- 默认：NO

# 708 第 19 章 FTP：跨网络传输文件

ls_recurse_enable YES 允许用户执行 `ls -R` 命令。将此参数设置为 YES 可能会带来安全风险，因为在大型层级结构目录的顶端执行 `-R` 命令可能会消耗大量的系统资源。

- 默认：NO

# LOGS

默认情况下，日志记录是关闭的。然而，Ubuntu Linux 分发的 `vsftpd.conf` 文件开启了它。本节描述了控制日志细节和位置的参数。

log_ftp_protocol YES 在 `xferlog_std_format` 设置为 NO 的情况下，记录 FTP 请求和响应。

- 默认：NO

xferlog_enable YES 在 `/var/log/vsftpd.log`（或由 `xferlog_file` 指定另一个文件）中维护传输日志。NO 则不创建日志。

- 默认：NO
Ubuntu: YES

xferlog_std_format YES 当显式设置了 `xferlog_file` 时，会将传输日志（不包括连接）写入标准的 xferlog 格式（如 wu-vsftpd 使用的格式）。如果 `xferlog_std_format` 设置为 YES 但未显式设置 `xferlog_file`，则关闭日志。默认的 vsftpd 日志格式比 xferlog 格式更易读，但无法由生成 xferlog 文件统计摘要的程序处理。在互联网上搜索 xferlog 以获取有关该命令的更多信息。

- 默认：NO

xferlog_file 见 xferlog_enable 和 xferlog_std_format。

- 默认：/var/log/vsftpd.log

# CONNECTION PARAMETERS

你可以允许客户端建立被动和/或主动连接（第 689 页）。设置超时和最大传输速率可以提高安全性能。本节描述了控制客户端可以建立的连接类型、vsftpd 在建立连接时的等待时间以及针对不同类型用户的连接速度的参数。

# PASSIVE (PASV) CONNECTIONS

pasv_enable NO 防止使用 PASV 连接。

- 默认：YES

pasv_promiscuous NO 导致 PASV 执行一个安全检查，确保数据和控制连接来自同一个 IP 地址。YES 禁用此检查；对于安全的系统不建议这样做。

- 默认：NO

# 设置 FTP 服务器 (vsftpd) 709

pasv_max_port vsftpd 为 PASV 连接分配的端口号，有助于设置防火墙。

- 默认：0（使用任意端口）

pasv_min_port vsftpd 为 PASV 连接分配的最低端口号，有助于设置防火墙。

- 默认：0（使用任意端口）

pasv_address 指定除客户端连接服务器以外的 IP 地址。

- 默认：none

# ACTIVE (PORT) CONNECTIONS

port_enable NO 防止使用 PORT 连接。

- 默认：YES

connect_from_port_20
当 `connect_from_port_20` 设置为 YES 时，在服务器上指定端口 20（ftp-data，特权端口），某些客户端需要这样做。NO 允许 vsftpd 以较低权限运行（在非特权端口）。

- 默认：NO
Ubuntu: YES

ftp_data_port
当 `connect_from_port_20` 设置为 NO 时，指定 vsftpd 用于 PORT 连接的端口。

- 默认：20

# TIMEOUTS

accept_timeout vsftpd 在建立连接时的等待秒数。

- 默认：60

connect_timeout vsftpd 在建立连接时的等待秒数。

- 默认：60

data_timeout vsftpd 等待数据传输的秒数。

- 默认：300

idle_timeout vsftpd 等待空闲的秒数。

- 默认：300

session_timeout vsftpd 在断开连接前的等待秒数。

- 默认：300

# 760 710 第 19 章：跨网络传输文件

local_max_rate 本地用户的最大传输速率（字节/秒）。零 (0) 表示不限制。

- 默认：0

anon_max_rate 匿名用户的最大传输速率（字节/秒）。

- 默认：0

# MISCELLANEOUS 描述在其他地方未讨论的参数。

rsa_cert_file 指定用于加密连接的 RSA 证书。

- 默认：/etc/ssl/certs/vsftpd.pem

rsa_key_file 指定用于加密连接的 RSA 密钥。

- 默认：/etc/ssl/private/vsftpd.key

tcp_wrappers 如果为 YES，vsftpd 使用 tcp_wrappers 限制访问。

user_config_dir 指定包含配置文件的目录。

- 默认：/etc/vsftpd
