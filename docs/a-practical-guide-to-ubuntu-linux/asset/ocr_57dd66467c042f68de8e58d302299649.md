# WORKING WITH DIRECTORIES

need to delete a directory that has files in, first use rm to delete the files and then delete the directory. You do not have to (nor can you) delete the . and .. entries; rmdir removes them automatically. The following command deletes the promo directory:

```
$ rmdir /home/max/literature/promo
```

The rm utility has a -r option (rm -rf filename) that recursively deletes files, including directories, within a directory and deletes the directory itself.

Use rm -r carefully, if at all

caution Although rm -r is a handy command, you must use it carefully. Do not use it with an ambiguous file reference such as *. It is frighteningly easy to wipe out your entire home directory with a single short command.

# USING PATHNAMES

Use a text editor to create a file named letter if you want to experiment with the examples. After, you can use touch to create an empty file:

```
$ cd
$ pwd
/home/max
$ touch letter
```

With /home/max as the working directory, the following example uses cp with a relative pathname to copy the file letter to the /home/max/literature/promo directory. (You will need to create again if you deleted it earlier.) The copy of the file has the same filename letter.0610:

```
$ cp letter literature/promo/letter.0610
```

If Max does not change to another directory, he can use vim as shown to edit the copy of the file he just:

```
$ vim.tiny literature/promo/letter.0610
```

If Max wants not to use a long pathname to specify the directory, he can use cd to make promo the working directory before:

```
$ cd literature/promo
$ pwd
/home/max/literature/promo
$ vim.tiny letter.0610
```

To make the parent of the working directory (named /home/max/litr) the new working directory, Max can use the following command, which takes advantage of the : directory entry:

```
$ cd ..
$ pwd
/home/max/literature
```
