# bunzip2 and bzcat: DECOMPRESS A FILE

You can use the bunzip2 utility to restore a file that has been compressed with bzip2:

```
$ bunzip2 letter_e.bz
$ ls -l
-rw-r--r-- 1 sam 584000 2010-03-01 22:31 letter_e
$ bzip2 zachcat.jpg.bz2
$ ls -l
-rw-r--r-- 1 sam 33287 2010-03-01 22:40 zachcat.jpg
```

The bzcat utility displays a file that has been compressed with bzip2. The equivalent of cat for .bz files, bzcat decompresses the compressed data and displays the decompressed data. Like cat, bzcat does not change the source file. The pipe in the following example redirects the output of bzcat instead of being displayed on the screen; it becomes the first two lines of the file:

```
$ bzcat letter_e.bz | head -2
eeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee
eeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee
```

After it is run, the contents of letter_e.bz are unchanged; the file is still stored on the disk in compressed format.

# gzip: COMPRESS A FILE

gzip and zcat
The gzip (GNU) utility is older and less efficient than bzip2. Its flags and operation are very similar to those of bzip2. A file compressed by gzip has a .gz extension. Linux manual pages use gzip format to save disk space; likewise, those you download from the Internet are frequently in gzip format. Use gzip, gunzip, and zcat as you would use bzip2, bunzip2, and bzcat, respectively.

# gzip versus zip

Do not confuse gzip and gunzip with the zip and unzip utilities. These last two are used to pack and unpack archives containing several files into a single file that has been imported from or is exported to a system Windows system. The zip utility constructs a zip archive, whereas unzip unpacks archives. The zip and unzip utilities are compatible with PKZIP, a Windows program that compresses archives and files.

# tar: PACKS AND UNPACKS ARCHIVES

The tar utility performs many functions. Its name is short for tape archive, as its original function was to create and read archive and backup tapes. Today it is used to create a single file (called a tar file, archive, or tarball) from multiple files or directory hierarchies and to extract files from a tar file. The utility (page 602) performs a simple function.

In the following example, the first ls shows the files g, b, and d. Next tar uses -c (create), -v (verbose), and -f (file) options to create an archive named alltar from these files. Each line of output displays the name of the file appending to the archive.

The tar utility adds overhead when creating an archive. The next command shows the archive alltar occupies 9,700 bytes, whereas the sum of the three files is 9,000 bytes. This overhead is much more appreciable on smaller files, such as the ones in this example:

```
$ ls -l g b d
-rw-r--r-- 1 sam 1178 2010-08-20 14:16 b
-rw-r--r-- 1 sam 3783 2010-08-20 14:17 d
-rw-r--r-- 1 sam 1302 2010-08-20 14:16 g
$ tar -cvf all.tar g b d
$ ls -l all.tar
-rw-r--r-- 1 sam 9728 2010-08-20 14:17 all.tar
-rw-r--r-- 1 sam 1178 2010-08-20 14:16 b
-rw-r--r-- 1 sam 3783 2010-08-20 14:17 d
-rw-r--r-- 1 sam 1302 2010-08-20 14:16 g
```

The final command in the preceding example uses the -t option to display a table of contents for the archive. Use -x instead of -t to extract files from a archive. Omit the -v option if you want tar to work silently. Although the original UNIX tar did not use a leading hyphen for options on the command line, the GNU/Linux version accepts hyphens but works without them. This book precedes tar options with a hyphen for consistency with other utilities.

# tar: the -x option may extract a lot of files

caution tar archives contain many files. To list the files in the archive without unpacking, run tar with -t option and the name of the tar file. In some cases you may want to create a new directory (mkdir), move the tar file into that, and expand it. That the unpacked files will not mingle with existing files. This strategy also makes it easier to delete the extracted files.

# tar: the -x option can overwrite files

caution The -x option will overwrite a file that has the same filename as file you are extracting. Follow the suggestion in the preceding command to avoid overwriting files.

optional You can combine the gunzip and tar commands on one command line with a pipe (|), which redirects the output of gunzip so that it becomes the input to tar:

```
$ gunzip -c make-3.81.tar.gz | tar -xvf -
```

The -c option allows gunzip to send its output through pipe instead of creating a file. The final hyphen (-) causes tar to read from standard input. Refer to "Pipes" (page 251) and gzip (page 175) for more information about how this command works.

A simpler solution is to use the -z option to tar. This option allows tar to call gunzip (or gzip when you are creating an archive) directly and simplifies the preceding command line:

```
$ tar -xvzf make-3.81.tar.gz
```

In a similar manner, the -j option calls bzip2 or bzip2.
