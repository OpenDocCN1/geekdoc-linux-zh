# CONFIGURING AND COMPILING THE Linux Kernel 579

Go through the options and make the features you would like to be configured in the new kernel. At any time during the configuration process, you can store the recently defined configuration to a file, load a configuration from a file, or exit without saving your changes. The selections to do are available in Menubar: File:Save and close the window. When you are done, select Menubar: File

# CLEANING THE SOURCE TREE

After generating a .config file, but before or recompiling the kernel, purge source tree of potentially stale *.o files using the following command:

```
$ make-kpkg clean
exec make kpkg_version=12.032 -f /usr/share/linux-package/ruleset/minimal.mk clean
n===== making target minimal [new prereqs] ======
```

This is kernel package version 12.032.

# COMPILING A KERNEL IMAGE FILE AND LOADABLE MODULES

See "Prerequisites" on page 572 for a list of packages that must be installed to compile the source code. Give the following command to compile the kernel and modules; it generates a vmlin file in the path of the working directory.

```
$ make-kpkg --indent rootfakeroot --append-to=$(date +%s) kernel_image
exec make pkg.version=12.032 -f /usr/share/linux-package/ruleset/minimal.mk deb APP
END_TO_VERSION=1271202298 INTRO_ROOT=fakeroot [new prereqs] ======
```

This is kernel package version 12.032.
