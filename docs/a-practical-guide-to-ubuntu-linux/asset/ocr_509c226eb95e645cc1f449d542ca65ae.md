The CURDATE() function returns today's date. Because the default values for read-
perm, writeperm, and executeperm are 0, you do not have to specify values for
fields.

Deleting rows using Next a DELETE FROM statement deletes rows that meet the specified criteria. WHERE clause Here the criteria are specified using equalities in a WHERE clause:

```
mysql> DELETE FROM people
-> where person='bailey' OR person='perc';
Query OK, 2 rows affected (0.02 sec)
```

Selecting rows You can also use a LIKE clause to specify criteria. The following SELECT statement displays all rows that contain the letter m. The % operators are wildcards; match any characters.

```
mysql> SELECT * FROM people
-> where person LIKE '%m%';
+------------------------------------------------------+
| person | password | created | readperm | writeperm | executeperm |
+------+------+------+------+------+------+
| max | NULL | 2008-02-17 | 1 | 1 | 1 |
| sam | NULL | 2009-02-28 | 1 | 0 | 0 |
+------------------------------------------------------+
2 rows in set (0.00 sec)
```

Modifying data In the example, the PASSWORD() function returns a hash (page 1151) of the text as its argument. The UPDATE statement assigns this hash to the pass- column in which the person column holds a value of sam. This example- does not change the MySQL password information that is kept in the database named mysql; this statement works with the maxdb database.

```
mysql> UPDATE people
-> SET password=PASSWORD("sampass")
-> where person='sam';
Query OK, 1 row affected (0.00 sec)
Rows matched: 1 Changed: 1 Warnings: 0
```

More queries The next query searches for rows where the password is null (NULL) and (AND) executeperm is true (=true).

```
mysql> SELECT person,password,executeperm
-> FROM people
-> WHERE person IS NULL AND executeperm=true;
+--------------------------------++
| person | password | executeperm |
+------+------+------+
| max | NULL | 1 |
| topsy | NULL | 1 |
+------+------+------+
2 rows in set (0.00 sec)
```
