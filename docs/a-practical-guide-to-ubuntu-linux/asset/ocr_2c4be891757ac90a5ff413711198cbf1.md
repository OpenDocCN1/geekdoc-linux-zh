+   * To display a hostname in place of an IP address, highlight the entry you want to change, right-click, and select Lookup Hostnames (Figure 25-7).

* You can specify the columns that firestarter includes in the Blocked Connections by selecting from the menu displayed by Firestarter menu: Events>Show Column (Figure 25-8).

As Figure 25-7 shows, the right-click menu also allows you to change the rule for the highlighted system and port (service). Inbound and outbound connections present menus. The inbound menu includes the following selections:

+   * **Allow Connections from Source**—Enables the originating system on the Internet that the highlighted event blocked to make any type of connection to client systems or the firewall host. This rule only if you completely trust the source system.
* **Allow Inbound Service for Everyone**—Enables any system on the Internet to connect to the service (port) that the highlighted event blocked. This set rule will allow the public to access servers behind the firewall.
* **Allow Inbound Service for Source**—Enables the originating system on the Internet to connect to the service (port) that the highlighted event blocked. The port protected by this rule is a *stealth port* because it is invisible to all systems on the Internet except the specified system.
