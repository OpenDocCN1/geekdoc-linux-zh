# NETWORK SERVICES

Linux Internet services are provided by daemons that run continuously or by a daemon that is started automatically by the inet or xinet daemon (page 464) when a service request comes in. The /etc/services files list network services (for example, telnet, ftp, and ssh) and their associated numbers. Any service that uses TCP/IP or UDP/IP has an entry in it. IANA (Internet Assigned Numbers Authority) maintains a database of all permanent, registered services. The /etc/services file lists a small, commonly used subset of services.

Most of the daemons (the executable files) are stored in /usr/bin. By convention the names of daemons end with the letter d to distinguish them from utilities (one common daemon whose name does not end in d is sendmail). The prefix in- or rpc is often used for daemon names. Refer to “The Upstart Event-Based init Daemon” on page 432 and “SysInit (rc) Start and Stop System Services” on page 440 for information about starting and stopping these daemons.

To see how a daemon works, consider what happens when you run ssh. The local system contacts the ssh (sshd) on the remote system to establish a connection. The two systems negotiate the connection according a fixed protocol. Each system identifies itself to the other, and then they take turns asking each other specific queries and waiting for valid replies. Each network service follows its own protocol.

# COMMON DAEMONS

In addition to the daemons that support the utilities described up to this point, many other daemons support system-level services that you will not interact with. Table 10-4 lists some of these daemons.

| Table 10-4 Common daemons |
| Daemon | Used for by | Function |
| --- | --- | --- |
| acpid | Advanced configuration and power interface | Flexible daemon for delivering ACPI events. Replaces apmd. |
| anacron | anacrontab | Used for periodic execution of tasks. This daemon looks in /etc/anacrontab file. When a task comes for execution, anacron executes it as the user who owns the file that describes the task. |
| apache2 | HTTP | The Web server daemon (Apache, page 899). |
