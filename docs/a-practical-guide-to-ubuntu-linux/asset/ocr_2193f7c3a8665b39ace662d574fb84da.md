# CHAPTER SUMMARY

The exim4 daemon is an MTA (mail transfer agent). When you send a message, exim4 works with other software to get the email to the proper recipients. You can set up exim4 to send to an SMTP server that relays the email to its destination or you can send exim email directly to the SMTP servers for the domains receiving the email. By default, exim4 stores incoming messages in the spool directory, /var/mail/.

The /etc/exim4/update-exim4.conf file controls many aspects how exim4 works. After you edit this file, you must use the exim4 init script to restart exim4 so it rereads its configuration files. The system administrator can use the /etc/aliases file and other users can use -forward to reroute email to one or more local or remote addresses, to files, or as input to programs.

You can use a program as SpamAssassin to grade and mark email as the likelihood of being spam. You can then decide what to do with the marked email: You can look at each piece of potential spam and decide where to put it, or have your MUA automatically put potential spam in a mailbox for spam.

Other programs that can help email include SquirrelMail, which provides mail services, and Mailman, which provides mailing list support. IMAP (Internet Access Protocol) and POP (Post Office Protocol) allow users to retrieve and manipulate email remotely. The Dovecot system provides IMAP and POP servers.
