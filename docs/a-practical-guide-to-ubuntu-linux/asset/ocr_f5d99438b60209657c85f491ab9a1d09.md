# INSTALLING APACHE

After Apache is installed, modify the configuration files as explained on page 903; if you do not make these modifications, Apache will display errors when it starts but work anyway. Use the apache2 script to restart the httpd daemon (page 902). Cacti supplies the content.

The /etc/cacti/apache.conf file controls the location and accessibility of Cacti on the Apache server. You do not have to modify this file. By default, Cacti is available as localhost/cacti, or from a remote system, by IP/cacti, where IP is the IP address of the system running Cacti. The default cacti.conf follows:

```
$ cat /etc/cacti/apache.conf
Alias cacti /usr/share/cacti/site
```

“Alias” (page 923) and “Allow” (page 930) for more information.
