# MANUAL PARTITIONING

When you select Manual from the Partitioning method screen (Figure 3-27), the textual partition editor displays the Partition overview screen, which lists the hard disks in the system and partitions on those disks. If a hard disk has no partitions, the partition editor displays only information about the hard disk. Figure 3-28 shows a single 200-gigabyte hard disk (highlighted) that has no partition table (and no partitions). (Note: 214.7 GB equals 200 GiB—Figure 3-28 should show GiB in space of GB. See the raid on page 37.)

If you want to set up RAID, see page 91 before continuing. If the Partition overview screen shows no partitions and no free space on a hard disk, as it does in Figure 3-28, the hard disk does not have a partition table: You need to create one. If the screen shows at least one partition or free space, the disk has a partition table and you can continue with “Creating a partition” on the next page.
