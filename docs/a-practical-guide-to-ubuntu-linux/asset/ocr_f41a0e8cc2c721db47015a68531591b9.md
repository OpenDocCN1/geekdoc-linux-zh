# Check the CD/DVD for defects

Testing the CD/DVD takes a few minutes but can save you much aggravation if the installation fails or you run into problems after installing Ubuntu due to bad media. Whether you burned your own CD/DVD, purchased it, or are using the disk included with this, it is a good idea to verify that the contents of the CD/DVD is correct.

tip

With the menu screen or one of the CD menus displayed, use the ARROW keys to highlight **CD disc for Defects** and press **RETURN**. Checking the CD/DVD takes a few minutes—Ubuntu keeps you updated of its progress. When Ubuntu finishes checking the CD/DVD, it displays the result of its testing. Press **RETURN** to reboot the session.

From the Welcome screen, click **Install Ubuntu 10.04** to install Ubuntu on the hard disk; continue with the Where are you screen as described on page 59.
