```
$ cat sa.ldif
dn: ou=employees,dc=sobell,dc=com
changetype: add
objectClass:organizationalUnit
ou: employees
```

The following command modifies the LDAP directory based on the sa.ldif file. The ldif filename extension is commonly used but not required for files LDIF

```
$ ldapmodify -xD cn=admin,dc=sobell,dc=com -w popine -f sa.ldif
adding new entry "ou=employees,dc=sobell,dc=com"
```

With this object class in place, you can add employees to the LDAP directory. The following file adds an employee:

```
$ cat sa2.ldif
dn: Samuel Smith,ou=employees,dc=sobell,dc=com
changetype: add
cn: Samuel Smith
cn: smith
objectClass: inetOrgPerson
mail: sls@example.com
givenName: Samuel
surname: Smith
displayName: Samuel L Smith
telephoneNumber: 999 999 9999
honephone: 000 000 0000
initials: SLS
```

The following command uses -W to call ldapmodify to prompt for the LDAP administrator password. Specifying a password in response to a prompt instead of on the command line can improve security by not making the password visible to a user running ps.
