# /etc/fstab: MOUNTS DIRECTORY HIERARCHIES AUTOMATICALLY

The /etc/fstab (page 510) lists directory hierarchies that the system mounts automatically as it comes. You can use the options discussed in the preceding sections on the command line or in the fstab file.

The following line shows fstab mounts from dog: /grape/gc1 filesystem on the /grape/gc1 mount point:

```
grape:/gc1  grape.gc1  nfs  rsize=8192,wsize=8192  0 0
```

A mount point should be an empty, local directory. (Files in a mount point are hidden when a directory hierarchy is mounted on it.) The type of filesystem mounted using NFS is always nws, regardless of its type on your local system. You can increase the rsize and wsize options to improve performance. Refer to "Improving Performance" on page 780.

The next example shows fstab mounts from dog:

```
dog:/export  /dog.export  nfs  timeout=50,hard  0 0
```

Because the local system connects to dog over a slow connection, timeout is increased to 5 seconds (5-tenths of a second). Refer to "Timeouts" on page 780. In addition, hard is to make sure NFS keeps to communicate with the server after a major timeout. Refer to "hard/soft" on page 780.
