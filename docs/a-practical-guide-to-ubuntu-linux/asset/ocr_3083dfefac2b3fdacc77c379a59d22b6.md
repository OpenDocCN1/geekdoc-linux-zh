# GLOSSARY

# 1171

scroll

To move lines on a terminal or window up and down or left and right.

scrollbar

A widget (page 1180) found in graphical user interfaces that controls (scrolls) which part of a document is visible in the window. A window can have a horizontal scrollbar, a vertical scrollbar (more common), or both.

server

A powerful centralized computer (or program) designed to provide information to clients (smaller computers or programs) on request.

session

The lifetime of a process. For a desktop, it is the desktop session manager. For a character-based terminal, it is the user's login shell. In KDE, it session may also be the sequence of events when you start using a program, such as an editor, and when you finish.

setgid

When you execute a file that has setgid (set group id) permission, the executing file takes the privileges of the file it belongs to. The utility shows setgid permission as an s in the group's executable position. See also setuid.

setuid

When you execute a file that has setuid (set user id) permission, the executing file takes the privileges of the owner of the file. For example, if you run a setuid program that removes all the files in a directory, you can remove files in any of the file owner's directories, even if you do not have permission to do so. When the program is run by root, you can remove files in any directory that a user working with root privileges can remove. The ls shows setuid permission as an s in the user's executable position. See also setgid.

sexillion

In the British system, 10⁶. In the American system, this number is named undecillion. See also large number (page 1156).

SHA1

Secure Hash Algorithm 1. The SHA family is a set of cryptographic hash (page 1151) algorithms that were designed by the National Security Agency (NSA). The second member of this family is SHA1, which is MD5 (page 1159). See also cryptography on page 1143.

share

A filesystem hierarchy that is shared with another system using SMB (page 1172). Also Windows share (page 1181).

shared network topology

A network, such as Ethernet, in which each packet may be seen by systems other than its destination system. Shared means shared by all users.

shell

A Linux system command processor. The three major shells are the Bourne Again Shell (page 1138), the TC Shell (page 1176), and the Z Shell (page 1182).

shell function

A series of commands that the shell stores for execution at a later time. Shell functions are like shell scripts but run more quickly because they are stored in the computer's memory rather than in files. Also, a shell function is run in the environment of that that it calls (unlike a shell script, which is typically run in a subshell).
