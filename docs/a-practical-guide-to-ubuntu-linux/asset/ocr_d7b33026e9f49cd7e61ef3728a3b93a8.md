The named.conf file has four clauses: an Options clause, two View clauses, and a Logging clause. The Options clause specifies the zone files that are located in the /etc/bind directory. The View clauses specify the characteristics and zones that a resolver depends on the resolver's address. One zone is for use the LAN/local users; the other is used by Internet/public users. The Logging clause sets the misc2.log file for default messages.

There are several ways to specify which clients see a view. The following named.conf file uses match-clients statements:

```
$ /etc/bind/named.conf
options
    directory "/etc/bind";
    //end options
```

```
view "local" IN {
    // start local view
match-clients { 127.0.0.1; 192.168.0.0/24};
    recursion YES;
```

```
zone "zach.net" IN {
    type master;
    file "local.net";
    notify YES;
```

```
zone "0.168.192.in-addr.arpa" IN {
    type master;
    file "named.local";
    notify YES;
```

```
zone "." IN {
    type hint;
    file "named.ca";
```
