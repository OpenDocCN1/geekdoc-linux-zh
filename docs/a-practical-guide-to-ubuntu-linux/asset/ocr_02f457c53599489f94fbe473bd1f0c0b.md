This program copies /usr/share/dict/words to standard output. A pipe (l; page 170) is then used to send the output through head (page 166), which displays the first four lines of the file (the first line is blank).

```
$ cat file2.pl
open (my $infile, "/usr/share/dict/words") or die "Cannot open dictionary: $!\n"
while ($line = $infile) {
    print $line;
}
```

# $ perl file2.pl | head -4

+   * A
* A's
* AOL

> The $! variable holds the last system error. In a numeric context, it holds the system error number; in a string context, it holds the system error string. If the words file is not present on the system, file2.pl displays the following message:

> Cannot open dictionary: No file or directory

> If you do not read permission for the file, the program displays the message:

> Cannot open dictionary: Permission denied

Displaying the value of $ gives the user more information about what went wrong than simply saying that the program could not open the file.

# Always check for error when opening a file

When a Perl program attempts to open a file, the program does not display an error unless unless open returns an error. In file2.pl, the operator in the open statement causes Perl to execute die (page 1059) if open fails. The die statement sends the message Cannot open the dictionary followed by the system error to standard error and terminates the program.

@ARGV The @ARGV array holds the arguments from the command line Perl was called with. When you call the program with a list of filenames, it displays the first line of each file. If the program cannot read a file, die (page 1059) sends an error message to standard error and quits. The foreach structure loops through the command-line arguments, as represented by @ARGV, assigning each argument to Filename. The foreach block starts with an open statement. Perl executes the statement preceding the or operator (or) or, if, Perl executes the statement following the or operator (die). The result is that either opens the file named by Filename and assigns IN as its handle, or if it cannot open that file, executes the die statement and quits. The print statement displays the name of the file followed by a colon and the first line of the file. When it accepts Sline = <IN> as an argument to print, Perl displays the value of Sline following the assignment. After reading a line from a file, the program closes the file.
