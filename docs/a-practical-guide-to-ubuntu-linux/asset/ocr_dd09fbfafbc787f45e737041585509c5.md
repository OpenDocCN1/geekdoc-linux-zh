# 588 CHAPTER 15 BUILDING A KERNEL

Listing installed Each time update-grub runs, it searches for kernel files. If a kernel file is longer present, it will no longer include a menu entry for that kernel. Similarly, if a new kernel file is present, it will include a menu entry for that kernel. You can remove a kernel's menu entry by removing the kernel package, which removes the kernel files.

The command uname -r displays the name of the kernel the system is running. and list the following commands display the name of the kernel the system is running and list the installed kernel packages. See page 535 for more information about the dpkg --list option.

```
$ uname -r
2.6.32-22-generic
```

```
$ dpkg list "linux-image*generic"
Desired=Auto/Unknown/Install/Remove/Purge/Hold
Status=Not-Installed/Config-Files/Failed/Half-inst/try-wait/Tig-pend
| Err=7
```

| Name | Version | Description |
|---|---|---|
| 11 linux-image-2.6.32-21-generic | 2.6.32-21 | Kernel image for version 2.6.32 on x86/x86_64 |
| 11 linux-image-2.6.32-22-generic | 2.6.32-22 | Kernel image for version 2.6.32 on x86/x86_64 |
| 11 linux-image-generic | 2.6.32.22 | Generic Kernel image

aptitude removes The easiest way to remove a kernel is to use Main: System Administration+Computer Janitor. You can also use the aptitude remove command. Substitute the name of the kernel you want to remove for the one in the following example. As above, the dpkg command truncates the name of the kernel package in the column labeled Name and displays three extra characters in the column labeled Version. This following command removes the first kernel package listed by the previous dpkg command:

```
$ sudo aptitude remove linux-image-2.6.32-19-generic
Reading package lists... Done
Building dependency tree
Reading state information... Done
Reading extended state information
Initializing package states... Done
The following packages will be REMOVED:
linux-image-2.6.32-19-generic
...
nRemoving linux-image-2.6.32-19-generic ...
Examining /etc/kernel/prerm.d.
Running postrm hook script /usr/sbin/update-grub.
Generating grub.cfg
Found linux image: /boot/vmlinuz-2.6.32.11+drm33.21271202298
Found linux image: /boot/vmlinuz-2.6.32-21-generic
Found initrd image: /boot/initrd.img-2.6.32-21-generic
Found memtest86+: /boot/memtest86+.bin
done
```

The lines starting with Generating grub.cfg are displayed by update-grub, which is run by the deb post script (page 533). It is good practice to keep at least one known-good kernel in addition to the one the system is running. See page 520 for more information on the aptitude remove command.
