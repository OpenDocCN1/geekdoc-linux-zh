# RUNNING the ftp and sftp FTP Clients 693

```
ftp > !mkdir memos.hold
ftp > lcd memos.hold
Local directory now /home/sam/memos.hold
ftp >
```

Sam uses the ftp mget (multiple get) command followed by the asterisk (*) wildcard to copy all files from the remote memos to the memos directory on the local system. If ftp prompts for the first file, Sam realizes that he forgot to turn off the prompts, he responds with n and presses CONTROL-C to stop copying files in response to the second prompt. The server checks whether he wants to continue with his mget command.

Next Sam gives the ftp prompt command, which toggles the prompt active (turns off if it is off and turns on if it is off). Now when he gives a mget * ftp copies the files without prompting. After getting the desired files, Sam gives a quit command to close the connection with the server, exit from ftp, and return to the local shell prompt.

A Linux system running ftp can exchange files with any of the many systems that support FTP. Many sites offer archives of free information on an FTP server, although for many it is just an alternative to an easier-to-access Web site (see, for example, ftp://ftp.ibilio.org/pub/Linux and http://www.ibilio.org/pub/Linux). Most browsers can connect to and download files from FTP servers.

The ftp utility makes no assumptions about filesystem nomenclature or structure because you use ftp to exchange files with non-UNIX/Linux systems (which may use different naming conventions).
