When Linux Torvalds introduced Linux and for a long time-after, Linux did not have a graphical user interface (GUI): It ran on character-based terminals only, using a command-line interface (CLI), also referred to as a textual interface. All the tools ran from a command line. Today the Linux GUI is important but many people—especially system administrators—run many more command-line utilities than their GUI counterparts. Command-line utilities are often faster, more powerful, or sometimes there is no GUI counterpart to a textual utility; some people prefer the hands-feeling of the command line.

When you work with a command-line interface, you are working with a shell (Shell 7, 9, and 27). Before you start with a shell, it is important to understand something about the characters that are special to the shell, so this chapter starts with a discussion of special characters. The chapter describes five basic utilities: ls, cat, rm, less, and hostname. It continues by describing several other file manipulation utilities as well as utilities that display who is logged in; that communicate with other users; that print, compress, decompress files; and that pack and unpack files.
