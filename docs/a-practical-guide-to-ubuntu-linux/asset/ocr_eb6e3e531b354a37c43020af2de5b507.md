In the following, more realistic example, the file zachcat.jpg contains a computer graphics image:

```
$ ls -l
-rw-r--r-- 1 sam sam 33287 2010-03-01 22:40 zachcat.jpg
```

The bzip2 utility can reduce the size of the file by only 28 percent because the image is already in a compressed format:

```
$ bzip2 -v zach.jpg
zachcat.jpg: 1.3911, 5.749 bits/byte, 28.13% saved, 33287 in, 23922 out.
```

```
$ ls -l
-rw-r--r-- 1 sam 23922 2010-03-01 22:40 zachcat.jpg.bz2
```

Refer to the bzip2 manual, www.bzip.org, and the Bzip2 mini-HOWTO (see page 142 for instructions on obtaining this document) for more information.

# bunzip2 and bzcat: DECOMPRESS A FILE

You can use the bunzip2 utility to restore a file that has been compressed with bzip2:

```
$ bunzip2 letter_e.bz
$ ls -l
-rw-r--r-- 1 sam 584000 2010-03-01 22:31 letter_e
$ bzip2 zachcat.jpg.bz2
$ ls -l
-rw-r--r-- 1 sam 33287 2010-03-01 22:40 zachcat.jpg
```

The bzcat utility displays a file that has been compressed with bzip2. The equivalent of cat for .bz files, bzcat decompresses the compressed data and displays the decompressed data. Like cat, bzcat does not change the source file. The pipe in the following example redirects the output of bzcat instead of being displayed on the screen it becomes the first two lines of the file:

```
$ bzcat letter_e.bz | head -2
eeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee
eeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee
```

After is run, the contents of letter_e.bz are unchanged; the file is still stored on the disk in compressed format.

bzip2recover The bzip2recover utility supports lost data from media errors. The command bzip2recover followed by the name of the compressed, corrupted file from which you want to try to recover data.

# gzip: COMPRESSES A FILE

gzip and zcat The gzip (GNU) utility is older and less efficient than bzip2. Its flags and operation are very similar to those of bzip2. A file compressed by gzip is a .gz extension. Linux manual pages in gzip format to save disk space; likewise, those you download from the Internet are frequently in gzip format. Use gzip, gunzip, and zcat as you would use bzip2, bunzip2, and bzcat, respectively.
Refer to the gzip info page for more information.
