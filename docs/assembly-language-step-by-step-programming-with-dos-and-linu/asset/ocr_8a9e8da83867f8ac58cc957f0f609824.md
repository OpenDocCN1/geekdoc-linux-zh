For example, the value of the first column is the number base raised to the 1 minus, or zero, power. Since any number raised to the zero power is one, the first column in any number base always has the value of one and is called the units column. The second column has the value of the number base raised to the 2 minus, or first power, which is the value of the number itself. In octal this is 8; in decimal, 10; in Martian base fooby, fooby.
