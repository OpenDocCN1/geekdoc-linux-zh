# Logical NOT (One's Complement)

# Flags affected:

O D I T S Z A P C OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
<none> IF: Interrupt flag ZF: Zero flag CF: Carry flag

# Logical forms:

+   - NOT r8
- NOT m8
- NOT r16
- NOT m16
- NOT r32 386+
- NOT m32 386+

# Examples:

+   - NOT CL
- NOT DX
- NOT EBX
- NOT WORD [SI+5]

# Notes:

NOT inverts each individual bit within the operand separately. That is, every bit that was 1 became 0, and every bit that 0 becomes 1. This is the “logical NOT” or “one’s complement” operation. See the NEG instruction for the negation, or two’s complement, operation.
After execution of NOT, the value FFH would become 0; the value AAH would become 55H.
You must use a size specify (BYTE, WORD, DWORD) with memory data!
