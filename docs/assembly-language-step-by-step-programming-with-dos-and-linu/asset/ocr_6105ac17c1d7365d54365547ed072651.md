# JECZ Jump If ECX =

# Flags affected:

O D I T S A P C OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
<none> IF: Interrupt flag ZF: Zero flag CF: Carry flag

# Legal forms:

JECZ <short displacement> 386+

# Examples:

JECZ AllDone ;Legal AllDone must be within 127 bytes;

# Notes:

This instruction operates identically to JECXZ, except that the register tested is ECX, and not CX.
JECZ is often used to bypass the ECX = 0 condition when using the LOOP instruction. Because LOOP decrements ECX before testing for ECX = 0, if you enter a loop governed by LOOP with ECX = 0, you will end up iterating the loop 2,147,483,648 times, hence JECXZ.
