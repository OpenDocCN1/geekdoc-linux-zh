# Searching for Text

Much of the power of electronic text editing lies in its ability to search for a particular character pattern in a text file. Furthermore, once found, it's a logical extension of the search concept to replace the found text string with a different text string. For example, if you decide to change the name of a variable to avoid conflict with another identifier in a program, you might wish to have the text editor locate every instance of the old variable name in a program and replace each with the new variable name.

NASM-IDE's editor can both search and search/replace operations with great ease—such easy makes page numbering unnecessary. If you wish to work on the part of a program that contains a particular procedure, all you need to do is search for that procedure's name and you will move the cursor right to the spot you want:

Ctrl-Q/F will find a given text.
