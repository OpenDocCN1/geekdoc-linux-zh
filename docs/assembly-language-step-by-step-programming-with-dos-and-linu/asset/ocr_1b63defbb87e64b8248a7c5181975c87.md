The key is to go back to SHOWCHAR and find out what ScnWidth and LinesDown might have thought that these were variables in memory, defined with the DW operator. Instead, they're something I touched on only briefly at the end of Chapter 10: equates. Equates are defined with the EQ operator, and if you find yourself confused by the differences between EQ and DW, don't despair. It's an easy enough thing to do.

One road to understanding harkens to the Pascal language. What is the difference between a variable and a simple constant? A variable is located at one and only one particular place in memory. A simple constant, on the other hand, is a value dropped into the program anywhere it is used and exists at no particular place in memory. Simple constants are used mostly in expressions calculated by the compiler during compilation.

It's the same thing here. The DW and DB operators define and set aside areas for storage of data. A DW exists somewhere at address and only exists in one place. The EQ, by contrast, is a symbol you define mostly for the assembler's use. It sets aside no memory and has no particular address. Consider this line from SHOWCHAR:

```
LinesDown EQ 4 ; Number of lines down to start ASCII table
```

The value defined as LinesDown exists at no single place in the SHOWCHAR program. It allocates no storage. It's actually a notation in the assembler's symbol table, telling the assembler to substitute the value 4 for the symbol LinesDown, anywhere it encounters the symbol LinesDown. The same is true for the equates of ScrWidth and LineLen.

When the assembler equates in a program, it performs a textual substitution of the values assigned to the symbol defined in the equate. The symbol is dumped, and the value is dropped in. Then assembly continues, using the substituted values rather than the symbols. In a very real sense, the assembler is pausing to alter the source code it processes an equate, then picks up its task again. This is exactly what happens when the assembler processes a macro, by the way.
