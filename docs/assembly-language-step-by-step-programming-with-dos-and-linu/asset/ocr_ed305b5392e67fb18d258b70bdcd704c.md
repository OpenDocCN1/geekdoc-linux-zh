# SUB Arithmetic Subtraction

Flags affected:

O D I T Z A P C OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
* * * * * IF: Interrupt flag ZF: Zero flag CF: Carry flag

Legal forms:

```
SUB r8,r8
SUB m8,r8
SUB r8,m8
SUB r16,r16
SUB m16,r16
SUB r16,m16
SUB r32,r32 386+
SUB m32,r32 386+
SUB r32,m32 386+
SUB r8,i8
SUB m8,i8
SUB r16,i16
SUB m16,i16
SUB r32,i32 386+
SUB m32,i32 386+
SUB r16,i18
SUB m16,i18
SUB r32,i18 386+
SUB m32,i18 386+
SUB AL,i18
SUB AX,i16
SUB EAX,i32 386+
```

Examples:

```
SUB BX, DI
SUB AX, 0FFFFF ;Uses single-byte-byte opcode
SUB AL, 42H ;Uses single-byte-byte opcode
SUB BP, 17H
SUB ECX, DWORD [ESI+5]
SUB EAX, 17
SUB WORD [BX+SI+Inset],5
SUB WORD [ES:BX],0B00H
```

Notes:

SUB performs a subtraction without borrow, the source is subtracted from the destination, and the result replaces the destination. If the result is negative, the Carry flag is set. Multiple-precision subtraction can be performed by following SUB with SBB (Subtract with Borrow) which takes the Carry flag into account as a borrow.
