AND is the way to go. We set up a bit mask in which the bits that we want to inspect and test are set to 1, the bits we wish to ignore are set to 0. To mask out bits but bits 4 and 5, we must set up a mask in which bits 4 and 5 are set to 1, with all other bits at 0. This mask in binary is 00110000B, or 30H.(To verify it, count the bits from the right-hand end of the binary number, starting with 0). This bit mask is then ANDed against the value in question.
