3. When the offset is specified in BP, the assumed segment register is SS.

4. For string instruction LODS, the assumed segment is DS and the
assumed offset is SI. This may not be overridden!

5. For string instructions STOS and SCAS, the assumed segment is ES
and the assumed offset is DI. This may not be overridden!

6. For string instruction MOVS, the source must be pointed to by DS:SI and
the destination must be pointed to by ES:DI. This may not be overridden!
