# Stringing Up 393

```
inc AL          ; Bump the character value up by 1
dec BL          ; Decrement the line counter by one
loopnz DoChar  ; Go back & do another char BL goes to 0
```

The work here (putting a character/attribute pair into the video buffer) is done by STOSW. Once again, STOSW is working solid, without REP. Without REP to pull the loop inside the CPU, you have to set the loop up yourself.

Keep in mind what happens each STOSW fires. The character in AX is copied to ES:DI and DI is incremented by 2. At the other end of the loop, the LOOPNZ instruction decreases CX by 1 and closes the loop.

During register setup, we loaded CX with the number of characters we wanted to display—in this case, 256. Each STOSW fires, it places another character on the screen, and there is one fewer character to display. CX acts as the master counter, keeping track of when we finally display the last remaining character. When CX goes to zero, we've displayed the full ASCII character and the job is done.

# Jumping When CX Goes to 0

Hence the instruction JXZ. This is a special branching instruction created specifically to help with loops like this. Back in Chapter 10, I explained how it's possible to branch using one of the variations of the JMP instruction, based on the state of one of the machine flags. Earlier in this chapter, I explained the LOOP instruction, which is a special-purpose JMP instruction, one combined with an implied DEC instruction. JXZ is yet another variety of JMP instruction, but one that doesn't watch any of the flags or decrement any registers. Instead, JXZ watches the CX register. When it sees that CX has just gone to zero, it jumps to the specified label. If CX is still nonzero, execution falls through to the next instruction in line.

In the case of the inner loop shown previously, JXZ branches to the “close up shop” code when it sees that CX has finally gone to 0. This is how the SHOWCHAR program terminates.

Most of the other JMP instructions have partners that branch when the governing flag is not true. That is, JC (Jump on Carry) branches when the Carry flag equals 1. Its partner, JNC (Jump on Not Carry), jumps if the Carry flag is not 1. However, JXZ is a loner. There is no JXNZ instruction, so don't go looking for one in the instruction reference!
