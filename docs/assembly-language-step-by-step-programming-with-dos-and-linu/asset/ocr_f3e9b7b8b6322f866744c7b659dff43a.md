the two lines on the source code listing suggests that stacktop: beyond the block of memory set aside by RESB, that's not the case. the stacktop: label resolves to the offset of the last byte in that block of 64 bytes.

You load the address represented by the stacktop: label into SP when the program begins, typically right after you set up the segment registers:

```
mov sp,stacktop      ; Point SP to the top of the stack
```

After that's set up, you have valid values in both SS and SP, and you can begin using the stack.

# Pushing Data

You can place data onto the stack in numerous ways, but the most straightforward way involves a trio of related machine instructions, PUSH, PUSH, and PUSHA. The three are similar in how they work, and differ as to they push onto the stack. PUSH pushes the Flags register onto the stack. PUSHA pushes all 16-bit register or memory value that is specified by you in your source code, like:

```
PUSH      ; Push the Flags register
PUSHA     ; Push AX, CX, DX, BX, BP, SI, and DI, in order, all at once
PUSHAD    ; Push EAX, ECX, EDX, EBX, ESP, ESI, EDI, and EDI, all at once
PUSH AX    ; Push the AX register
PUSH [BX] ; Push the word stored in memory at DS:BX
PUSH DI    ; Push the DI register
PUSH ES    ; Push the ES register
```

Note that PUSH takes no operands. You'll generate an assembler error if you try to hand it an operand; PUSH pushes the flags and that's all it is capable of doing.

PUSH and PUSH work this way: First SP is decremented by one word (two bytes) so it points to an empty area of the stack segment that is two bytes long. Whenever it is to be pushed onto the stack is written to memory in the stack segment at the offset address in SP. Voila! The data is safe on the stack, and SP has crawled closer to SS. We call the word of memory pointed to by SP the top of the stack.

PUSHA works the same way, except that it pushes 16-bit registers at once, using 16 bytes of stack space at one sweep. One to remember is that PUSHA is a newer instruction that doesn't exist on the 8086 and 8088. It works with the 286.
