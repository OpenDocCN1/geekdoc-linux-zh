# Columns and Carries

With all the single-column additions committed (more or less) to memory, you can tackle multicolumn addition. It works pretty much the same way it does with decimal. Add each column starting from the right, and carry into the next column anytime a single column’s sum exceeds 0FH.

For example:

```
1   1
2 F 3 1 A DH
+ 9 6 B A 0 7H
C 5 E B B 4H
```
