cuted. The stack pointer is incremented by two bytes and moves from SS. DX now contains a copy of the contents of CX. In effect, CX was pushed onto the stack, and then immediately popped off DX.

That’s a roundabout way to copy the value of CX into DX. MOV DX,CX is lots faster and more straightforward. However, MOV will not operate on the Flags register. If you want to load a copy of Flags into a register, you must first push the Flags register onto the stack with PUSH, then pop the flags off the stack into the register of your choice with POP. Getting the Flags register into BX is done like this:

```
PUSH ; Push the flags register onto the stack...
POP BX ; ...and pop it immediately into BX
```

# Storage for the Short Term

The stack should be considered a place to stash things for the short term. Items stored on the stack have no names, and in general must be taken off the stack in the reverse order that they were put on. Last in, first out, LIFO!

One excellent use of the stack allows the all-too-few registers to multiply duty. If you need a register to temporarily hold some value to be operated on by the CPU and all the registers are in use, push one of the busy registers onto the stack. Its value will remain safe on the stack while you use the register for other things. When you’re finished using the register, pop its old value off the stack—and you’ve gained the advantages of an additional register without really having one. (The cost of course, is the time you spend moving that register’s value onto and off the stack. It’s not something you want to do in the middle of an often-repeated loop!)
