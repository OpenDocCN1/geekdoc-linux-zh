# ASSEMBLY LANGUAGE STEP-BY-STEP

Adding one to something or subtracting one from something are actions that happen a lot in computer programming. If you're counting the number of times a program is executing a loop, or counting by in table, or doing something that advances or retreats count at a time, INC or DEC can be very quick ways to make the actual addition or subtraction.

Both INC and DEC take only one operand. An error will be flagged by DEBUG by your assembler if you try to use INC or DEC with two operands, or without any operands.

Try by using the Assemble command and the Trace command under DEBUG. Assemble this short program, display the registers after entering it, and then trace through it:

```
MOV AX, FFFF
MOV BX,002F
DEC BX
INC AX
```
