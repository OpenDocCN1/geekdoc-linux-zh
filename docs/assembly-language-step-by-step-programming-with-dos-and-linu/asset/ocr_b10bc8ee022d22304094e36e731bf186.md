# Dividing and Conquering 297

; Created date : 9/12/1999
; Last update : 9/12/1999
; Author : Jeff Dentmann
; Description : A simple example of a DOS EXE file programmed for
real mode segmented model, using NASM 0.98 and ALINK.
This program demonstrates how separately-assembled
modules sharing both code and data are linked into a
single executable module.

```
[BITS 16] ; Set 16 bit code generation
-----------------------
; BEGIN CODE SEGMENT
-----------------------

; Note that the following items are external to EAT4.ASM, and must
; be linked from the external file VIDLIB.OBJ. Assemble VIDLIB.OBJ.
; first to VIDLIB.OBJ before attempting the link.

EXTERN GotoXY,Write,Writeln,Clr

SEGMENT SETUP
```

In real mode segmented, a program uses three segments, and it must
set up the addresses in the three corresponding segment registers. This
is as what the ASSUME directive has a name in MASM; we ASSUME nothing in NASM!
Each of the three segments has a name (here, code, data, and stack) and
these names are identifiers indicating segment addresses. It is the
propriate segment address that is moved into each segment register.
Note that you can't move an address directly into a segment register;
you must first move the address into a general purpose register. Also
note that we don't do anything with CS; the ..start: label tells the
linker where the code segment begins.

```
..start: ; This is where program execution begins:
mov ax, data ; Move address of data segment into AX
mov ds, ax ; Copy address from AX into DS
mov ax, stack ; Move address of stack segment into AX
mov ss, ax ; Copy address from AX into SS

mov sp, stacktop ; Point SP to the top of the stack

call ClrScr ; Clear the display

word [TextPos], 0914H ; 0914H = X @ 20, Y @ 9

mov DX,[TextPos] ; TextPos contains X,Y position values
call GotoXY ; Position cursor
mov DX,Eatl ; Load offset of Eatl string into DX
```
