# Loading Files into the Editor

When you invoke NASM-IDE and it begins running, it loads either the file named on the command line when you invoked it (as I described and showed you earlier) or else the last file it worked on, as recorded in a configuration file called NASMIDE.INI. (You can inspect this file, which is maintained by NASM-IDE, and don't alter it yourself!)

Individual lines within an edit file are limited to 254 characters. Loading-ing a file with longer lines will cause the editor to insert hyphens at the 254-character point. You'll get an error box if you try to type past the 254-character point on any line.
