# Saving Your Work

It's very important to keep in mind what is happening while you edit text files with the editor. You are editing entirely within memory. Nothing goes out to disk while you are actually doing the edit. You can work on a file for hours, and one power failure or deg tripping over your PC's power cord will throw it all away. You must develop the discipline of saving your work every so often.

You can save your work by going to the menu bar, pulling down the File menu, and selecting the Save item. The easiest way to execute a Save command from within the editor is with the Save shortcut, F2.

F2 saves your work file.

Press F2 early and often. Everything depends on it.
