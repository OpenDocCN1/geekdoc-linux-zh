define pseudoinructions give a name, size, and a value to a data item.
The reserves only give a name and a size. Here are some examples:

```
rowcount dd 6
fileop    db 'w',
timesg    db 'Hey, what time is it? It's %s*,10,0
```

```
timediff resd 1 ; Reserve 1 integer (4 bytes) for time difference
timistr resb 40 ; Reserve 40 bytes for time string
tmcopy     resd 9 ; Reserve 9 integer fields for struct tm
```

The first group are defines. The ones you'll most often are DD (define double) and DB (define byte). The DB pseudoinruction is unique in that it allows you to define character arrays easily, and it is used for string constants. For more advanced work, NASM provides you with DW (define word) for 16-bit quantities, DQ (define quad word) for 64-bit quantities, and DT (define ten-byte) for 80-bit quantities. These larger types are used for floating-point arithmetic, which I won't be covering in this book.

The second group are reserves. They all begin with "RES," followed by the code that indicates the size of the item to be reserved. NASM defines RESB, RESW, RESD, RESQ, and REST for bytes, words, doubles, quads, and 10-bytes. The reserves allow you to allocate arrays of any type, by specifying an integer constant after the pseudoinstruction. RESB 40 allocates 40 bytes, and RESD 9 allocates 9 doubles (32-bit quantities) all in a contiguous area.

# Making a Copy of club's tm Struct with MOVSDS

It's sometimes handy to be able to keep a separate copy of a tm struct, especially if you're working with several date/time values at once. So, after you use localtime to fill the library's hidden tm structure with date/time values, you can copy that structure to a structure allocated in the [bss] section of your program.

Doing such a copy is a straightforward use of the REP MOVSDS (Repeat Move String Double) instruction. MOVSDS is an almost magical thing: once you set pointers to the data area you want to copy, and the place you want to copy it to, you store the size of the area in ECX and REP MOVSDS do the rest. In one operation it will copy an entire buffer from one place in memory to another.
