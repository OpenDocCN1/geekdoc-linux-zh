Another one of these fossilized characters will eventually cause you
some trouble: the end-of-file (EOF) marker character. Unlike EOL, EOF
is a single character, ASCII character 26, sometimes written as Ctrl+Z
because you will generate the EOF character by holding the control key
d and pressing the Z key.
