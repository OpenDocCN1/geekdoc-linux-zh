When DEBUG loads a file from disk, it places the number of bytes in the file in the CX register. CX is a general-purpose register, but it is often used to contain such count values and is therefore called the count register.

Notice that the value of CX is 13H—just the number DEBUG reported when it wrote the altered SAM.TXT out to disk in response to the W command. If we change the value in CX, we change the number of bytes DEBUG will write to disk.

So let's fix SAM.TXT. In changing the word "man" to "moose" we wrote over two characters: the period at the end of the sentence and the CR character portion of the last line's EOL marker. We could start at address 012H and enter a period character (2EH—use your ASCII table!) followed by a CR character (0DH). In doing so, however we would overwrite the LF character, which is just as bad or worse.

Unlike a text editor, DEBUG will not just over the values to the right of the point where you wish to insert new values. DEBUG has no insert mode. You have to enter all three characters: The period, the CR, and the LF.
