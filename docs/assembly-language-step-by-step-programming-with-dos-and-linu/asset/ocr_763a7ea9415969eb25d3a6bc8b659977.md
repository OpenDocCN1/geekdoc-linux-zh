If the value in AL is to be adjusted, it indicates that there was a carry in the addition, and thus AH is incremented. Also, the Carry flag CF is set to 1, as is the Auxiliary flag AF. Again, if the low nibble of AL contained a valid BCD digit when AAA was executed, AH is not incremented, and the two Carry flags are cleared (forced to 0) rather than.

AAA facilitates base 10 (decimal) addition on the low nibble of AL. After AL is adjusted by AAA, the low nibble contains a valid BCD digit and the high nibble is 0. (But note well that this will be true only if the addition that preceded AAA was executed on two valid BCD operands! And ensuring that those operands are your responsibility, not the CPU’s!)

This allows us to add ASCII digits such as ‘1’ and ‘2’ using the ADD instruction. Ruler does this immediately after the STOS instruction:

```
add AL, '1'      ; Bump the character value in AL up by 1
aaa               ; Adjust AX to make this a BCD correction
```

If prior to the addition contents of AL’s low nibble were 9, adding ‘1’ would make the value 0AH, which is not legal BCD. AAA would then adjust AL by adding 6 to AL and clearing the high nibble. Adding 6 to 0A would give 10, so the high nibble is cleared the new value in AL would be 00. Also, AH would have been incremented by 1.

In Ruler we are not adding multiple columns but instead simply rolling over a count in a single column and displaying the number in that column to the screen. Therefore, we just ignore the incremented value in AH and AL alone.

# Adjusting AAA’s Adjustments

There is one problem: AAA clears the high nibble to 0. This means that adding ‘1’ and ‘1’ doesn’t equal ‘2’, the displayable digit. Instead, AL becomes 02, which in ASCII is the dark ‘smiley face’ character. Make AL a displayable ASCII digit again, we have to add 30H to AL. This is easy to: Just add ‘0’ to AL, which has a numeric value of 30H. So, adding ‘0’ takes 02H back to 32H, which is the numeric equivalent of the ASCII digit character ‘2’. This is the reason for the AL/0’ instruction that immediately follows AAA.
