# Characters Out

Enough warm-up—it's time to start writing programs! Actually, we've already been through a complete and assemble-able program called BOILER.ASM. However, if you assemble BOILER.ASM and run it, you won't see anything. It takes no real action and doesn't display any output. Making an "Eat at Joe's" program out of it requires that we make a C library function call to display text on the screen. This isn't particularly difficult, and it's good practice in learning the conventions for making C library calls from assembly. I explained the C conventions in some detail in an earlier section of this chapter, and now we'll actually put them to work. Consider the following program, which is built on the BOILER.name foundation I showed you earlier:

```
; Source name : EATLINUX.ASM
; Executable name : EATLINUX
; Version : 1.0
; Created date : 11/12/1999
; Last update : 11/22/1999
; Author : Jeff Duntemann
; Description : A simple program in assembly for Linux, using NASM 0.98,
; demonstrating the use of the puts C library routine to display text.
```

```
; Build using these commands:
; nasm -f elf eatlinux.asm
; gcc eatlinux.o eatlinux
;
```

```
[SECTION .text] ; Section containing code
```

```
extern puts ; Required so linker can find entry point
global main
```

```
main:
push ebp ; Set up stack frame for debugger
mov ebp,esp
push ebx ; Program must preserve ebp, ebx, esi, &edi
push esi
push edi
;; Everything before this is boilerplate; use it for all ordinary apps!
```

```
push dword eatmsg ; Push a 32-bit pointer to the message on the stack
call puts ; Call the clib function for displaying strings
add esp, 4 ; Clean stack by adjusting esp back 4 bytes
n;; Everything after this is boilerplate; use it for all ordinary apps!
pop edi ; Restore saved registers
```
