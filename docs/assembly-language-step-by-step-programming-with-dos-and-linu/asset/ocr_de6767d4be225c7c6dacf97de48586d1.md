For most programs you may write while you're getting your bearings in Linux assembly, you'll be entering simple integers, and scanc is very good at that. You pass scanc the name of a numeric variable in which to store the entered value and a formatting code what that value will take on data entry. The scanc function will take the characters typed by the user and convert them to the integer value that characters represent. That is, scanc will take the two ASCII characters "4" and "2" successively and convert them to the integer value 42 after the user presses Enter.

What about a prompt, instructing the user what to type? Well, many newcomers get the idea that you can combine the prompt with the format code in a single string handled by scanf-but that won't work. It seems like it should-hey, after all, you can combine formatting codes with the base string being displayed printf. And in scanf, you can theoretically use a base string containing formatting codes... but the user would then have to type the prompt as well as the numeric data

So, in actual use, the only string used by scanc is a string containing the formatting codes. If you want a prompt, you must display the prompt before calling scanf, using printf. To keep the prompt and the data entry on the same line, make sure you don't have a newline called out at the end of your prompt string!

The scanc function automatically takes character input from standard input. You don't have to pass it the file handle stdin, as with gets. (There is a C library routine fscanf which you do have to pass a file handle, but for integer entry, there's no hazard in using scanc.)

Here's how to use the scanc routine:

+   1. Make sure you have declared extern scanc along with your external declarations at the top of the [.text] section.

+   2. Declare a memory variable of the type to hold the numeric data read and converted by scanc. My examples here will be for integer data, so you would create a variable with either the DD directive or the RESD directive. Obviously, if you're going to keep several rate values, you'll need to declare one variable per value entered.
