# The Instruction Pointer

Another type of register lives inside the x86 CPUs. The instruction pointer (usually IP) is in a class by itself. In radical contrast to the gang of general-purpose registers, IP is a specialist par excellence—more of a specialist than even the segment registers. It can do only one thing: it contains the offset address of the next machine instruction to be executed in the current code segment.
