
# Software Interrupt

Flags affected:
O D I T S Z A P C OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
* IF: Interrupt flag ZF: Zero flag CF: Carry flag

# Legal forms:

- INT3 NASM-specific shorthand for INT 3
- INT i8

# Examples:

- INT3 ; NASM requires this to generate an INT 3 instruction
- INT 10H

# Notes:

INT triggers a software interrupt to one of 256 vectors in the first 1,024 bytes of memory. The operand specifies which vector, from 0 to 255. When an interrupt is called, the Flags register is pushed on the stack with the return address. The IF flag is cleared, prevents further interrupts (either hardware or software) from being recognized until IF is set again. TF is also cleared.

A special form of the instruction calling Interrupt 3 with a single-byte instruction. Debuggers use INT 3 to set breakpoints in code by replacing an instruction with the single-byte opcode for calling Interrupt 3. NASM does not recognize this, and if you want to use INT 3 for some reason (and that form isn't of much use unless you're writing a debugger), you must use a special mnemonic INT3 rather than INT 3. This is advanced stuff; be careful.

Virtually all your applications of INT will use the other form, which takes an 8-bit immediate numeric value.

Always return from a interrupt service routine with the IRET. IRET restores the flags that were pushed onto the stack by INT, and in doing so it allows further interrupts.

```
r8 = AL AH BH CL CH DL DH          r16 = AX BX CX DX BP SI DI
sr = CS DS SS ES FS GS               r32 = EAX EBX ECX EDX ESP ESI EDI
m8 = 8-bit memory data               m16 = 16-bit memory data
m32 = 32-bit memory data             i8 = 8-bit immediate data
i16 = 16-bit immediate data         i32 = 32-bit immediate data
d8 = 8-bit signed displacement      d16 = 16-bit signed displacement
d32 = 32-bit unsigned displacement
```

# IRET Return from Interrupt

Flags affected:

```
* D I T S Z A P C OF: Overflow flag TF: Trap flag AF: Aux carry
* F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
* * * * * * * * IP: Interrupt flag ZF: Zero flag CF: Carry flag
```

# Legal forms:

```
IRET
```

# Examples:

```
IRET
```

# Notes:

IRET must be used to exit from interrupt service routines called through INT or interrupt hardware such as serial ports and the like. IRET pops the return address from the top of the stack into CS and IP, and then pops the next word from the stack into the Flags register. All flags are affected.

If the interrupt was triggered by hardware, there may be additional steps to be taken to prepare the hardware for another interrupt before IRET is executed. Consult your hardware-documentation.

When using NASM, the actual opcode generated for IRET depends on the setting of the BITS setting, and governs whether a 16-bit return or 32-bit return is generated.

```
r8 = AL AH BH CH DL DH      r16 = AX BX CX DX BP SP ESI DI
sr = CD DS SS ES FS GS        r32 = EAX EBX ECX EDX EBP ESP ESI EDI
m8 = 8-bit memory data       m16 = 16-bit memory data
m32 = 32-bit memory data     i8 = 8-bit immediate data
i16 = 16-bit immediate data i32 = 32-bit immediate data
d8 = 8-bit signed displacement d16 = 16-bit signed displacement
d32 = 32-bit unsigned displacement
```

# Examples:

- JB HalfSplit ;Jumps if CF=1

# Notes:

By default these instructions make a short jump (127 bytes or 128 bytes back) if s condition is true, or fall through if the condition is not true. The conditions all involve flags, and the flags in-question are given to the right of the mnemonic and description.

The mnemonics incorporating "above" or "below" are for use after signed comparisons, the mnemonics incorporating "less" or "greater" are for use after signed comparisons. "Equal" and "Zero" may be used after unsigned or signed comparisons.

NASM allows use of the segmentwide form by inserting the NEAR keyword after the instruction mnemonic. In real mode this allows the use of a 16-bit signed displacement, and in 32-bit protected mode this allows the use of a 32-bit signed displacement. Use of NEAR is only supported with 386 and newer CPUs.

# JCZX Jump If CX = 0

Flags affected:

O D T S Z A P OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
<none> IF: Interrupt flag ZF: Zero flag CF: Carry flag

Large forms:

JCZX <short displacement>

Examples:

JCZX AllDone ;Legal AllDone must be within 127 bytes;

Notes:

Many instructions use CX as a count, JCZX allows you to jump if CX is 0. The jump may be a short jump (127 bytes or 128 bytes back) if CX is 0 at the time the instruction is executed. If CX is any other value, execution falls through to the next instruction. See Jump on Condition instructions.

JCZX is often used to bypass the CX = 0 condition when using LOOP instruction. Because LOOP decrements CX before testing for CX = 0, if you enter a loop governed by LOOP with CX = 0, you will end iterating the loop 65,536 times, hence JCZX.

```
r8 = AL AH BH CH CL DL DH      r16 = AX BX CX DX BP SI DI
sr = CS DS SS ES FS GS                r32 = EAX EBX ECX EDX ESP EDI
m8 = 8-bit memory data               m16 = 16-bit memory data
m32 = 32-bit memory data             i8 = 8-bit immediate data
i16 = 16-bit immediate data         i32 = 32-bit immediate data
d8 = 8-bit signed displacement      d16 = 16-bit signed displacement
d32 = 32-bit unsigned displacement
```

# JECZ Jump If ECX =

# Flags affected:

O D I T S A P OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
<none> IF: Interrupt flag ZF: Zero flag CF: Carry flag

# Legal forms:

JECZ <short displacement> 386+

# Examples:

JECZ AllDone ;Legal AllDone must be within 127 bytes;

# Notes:

This instruction operates identically to JECXZ, except that the register tested is ECX, and not CX. JECZ is often used to bypass the ECX = 0 condition when using the LOOP instruction. Because LOOP decrements ECX before testing for ECX = 0, if you enter a loop governed by LOOP with ECX = 0, you will end up iterating the loop 2,147,483,648 times, hence JECXZ.

```
r8 = AL AH BL BH CH CL DL DH      r16 = AX BX CX DX BP SP SI DI
sr = CS DS SS ES FS GS                r32 = EAX EBX ECX EDX ESP ESI EDI
m8 = 8-bit memory data               m16 = 16-bit memory data
m32 = 32-bit memory data             i8 = 8-bit immediate data
i16 = 16-bit immediate data         i32 = 32-bit immediate data
d8 = 8-bit signed displacement      d16 = 16-bit signed displacement
d32 = 32-bit unsigned displacement
```
