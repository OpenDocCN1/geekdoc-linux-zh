# LOOPZ/LOOP Loop While CX/ECX > 0 and ZF = 1

# Flags affected:

O D I T Z A P C OF: Overflow flag TF: Trap flag AF: Aux carry
F F F F F F F DF: Direction flag SF: Sign flag PF: Parity flag
<none> IF: Interrupt flag ZF: Zero flag CF: Carry flag

# Legal forms:

LOOPZ d8
LOOP d8

# Examples:

LOOPZ SenseOnshots
LOOP CRCGenerate

# Notes:

LOOPZ and LOOP are synonyms and generate identical opcodes. Like LOOP, they use either CX or EC depending on the BITS set and hence the mode. LOOPZ/LOOP decrements CX and jumps to the location specified in the target operand if CX is not 0 and the Zero flag ZF is 1. Otherwise, execution falls through to the next instruction.

What this means that the loop is pretty controlled by ZF. If ZF remains 1, the loop is looped until CX is decremented to 0. But as soon as ZF is cleared to 0, the loop terminates. Think of it as "While Zero Flag."

Keep in mind that LOOPZ does not affect affect ZF. Some instruction within the loop (typically one of the string instructions) must do something to affect ZF to terminate the loop before CX/EC counts down to 0.

```
r8 = AL BH BL CL CH DL DH             r16 = AX CX DX BP SP SI DI
sr = CS DS MS ES FS GS                r32 = EAX ECX EDX EBP ESP ESI EDI
m8 = 8-bit memory data                 m16 = 16-bit memory data
m32 = 32-bit memory data               i8 = 8-bit immediate data
i16 = 16-bit immediate data           i32 = 32-bit immediate data
d8 = 8-bit signed displacement        d16 = 16-bit signed displacement
d32 = 32-bit unsigned displacement
```
