### Working with the Linux File System

Fedora uses a *file system*, or layout of hierarchical directories similar to that used by other UNIX variants (such as Mac OS 8). Nearly all Linux distributions use a similar directory structure, and Linux distribution vendors have generally agreed on the naming and location of critical Linux files and directories.

> **NOTE**
> The effort to build a consensus regarding the Linux directory structure began in 1993 with the Filesystem Hierarchy Standard (FHS), a draft proposal that addressed not only Linux issues, but also those of other operating systems, such as BSD. Red Hat has stated that it is committed to staying compliant with the FHS, which specifies the location and names of files and directories. Fedora uses the current 2.3 standard.
