# NOTE

If you frequently use VoIP applications such as GNOMEMeeting, you will tire of repetitively typing in long IP addresses to make connections. To avoid this hassle, you can use a “gatekeeper”\ — similar in purpose to a DNS server— to translate names into IP addresses. OpenH323 Gatekeeper is one such popular gatekeeper application. It is not provided with Fedora, but you can obtain it from http://www.gnug.org/.
