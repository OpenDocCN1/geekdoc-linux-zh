# **Red Hat®
Fedora™ 5
UNLEASHED**

Red Hat® Fedora™ 5 Unleashed presents comprehensive coverage of Fedora 5—the open-community version of Red Hat Linux, the most popular Linux distribution in the world.

This book provides detailed information on installing, using, and administering Fedora. You'll learn how to set up a workstation or a server, and you'll find complete details on Fedora's easy-to-use desktop and productivity software.

Red Hat® Fedora™ 5 Unleashed includes a range of coverage: From the software you need every day for work, such as the OpenOffice.org productivity suite, to how to configure your Linux desktop to run smoothly using multiple printers, shell scripts, and more.

For the hardcore Linux enthusiast, there is complete coverage of the X Window system, Linux programming, web server administration, and network administration.

Paul Hudson is a professional developer and full-time journalist for Future Publishing. His articles have appeared in Mac Format, PC Answers, PC Format, PC Plus, and Linux Format.

Andrew Hudson is a regular freelance contributor to Linux Format magazine, the UK's largest Linux magazine. His particular area of expertise is Fedora Core and the Red Hat Enterprise platform.
