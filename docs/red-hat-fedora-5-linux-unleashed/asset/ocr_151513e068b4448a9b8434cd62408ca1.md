The network file previously supported a FORWARD_IPV4 value, which determined whether the host forwarded IP packets (usually “yes” for routers). This setting is now saved in `/etc/sysctl1.conf` as a `net.ipv4_ip_forward` setting, which can be modified if the forwarding changes are required. See the sysctl1.conf man page for more information.
