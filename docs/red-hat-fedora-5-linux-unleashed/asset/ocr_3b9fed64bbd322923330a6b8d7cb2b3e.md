If directory permissions in the FTP repository are set correctly, the pub directory should be the only directory that shows any files under it. To verify this, change directories to etc and list the contents:

ftp> cd etc
 250 CWD command successful.
 ftp> ls
 200 PORT command successful.
 150 Opening ASCII mode data connection for directory listing.
 total 0
 226 Transfer complete.

By setting the permissions to execute only on the directories bin, lib, and etc, a system administrator can restrict users from seeing any files in those directories. Good security dictates that remote users are denied information about a system because any information could aid in hacking attempts.
