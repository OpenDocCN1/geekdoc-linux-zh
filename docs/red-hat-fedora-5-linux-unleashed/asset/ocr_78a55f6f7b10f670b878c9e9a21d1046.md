# Creating a CUPS Printer Entry

This section provides a short example of creating a Linux printer entry using CUPS's web-based interface: Use the CUPS web interface to create a printer and device queue type (such as local, remote, serial port, or Internet); then you enter a device uniform resource identifier (URI), such as lpd://192.168.2.35:11lp, which represents the IP address of a remote UNIX print server, and the name of the remote print queue on the server. You also need to specify the model or make of printer and its driver. A Printers page link allows you to print a test page, stop the printing service, manage the local print queue, modify the printer entry, or add another printer.

In the Admin page, click the Add Printer button and then enter a printer name in the Name field (such as lp), a physical location of the printer in the Location field, and a short note about the printer (such as its type) in the Description field.
