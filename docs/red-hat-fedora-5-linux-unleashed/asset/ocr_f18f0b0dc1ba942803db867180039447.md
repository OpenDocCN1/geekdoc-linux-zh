NetworkManager can handle WEP and WPA encryption. You are advised to use WPA encryption as it is the stronger of the two.

NetworkManager can also connect to Cisco VPN connections, using the `vpnc` software. Install this using `yum` and you will be able to specify connection settings as appropriate, or if you have access to a pre-defined configuration `l.pcf` file you can import it directly into NetworkManager.

# RELATED FEDORA AND LINUX COMMANDS

You will use these commands when performing post-installation configuration tasks:

+   * `apm` —Views or uses power management settings and commands
+   * `cardctl` —Controls PCMCIA slots and services
+   * `cdcd2wav` —Extracts audio files from audio CDs
+   * `cdparanoia` —Extracts audio files from audio CDs
+   * `cdrecord` —Gets SCSI device information and burns CD-ROMs
+   * `chkconfig` —Controls services at each Linux runlevel
+   * `dmesg` —Views information reported by the Linux kernel
+   * `insmod` —Loads a kernel module into memory
+   * `system-config-network` —Fedora’s graphical X client used to detect and configure a modem when configuring a dialup Internet connection
+   * `kppp` —KDE’s X PPP connection utility can detect and use a modem
+   * `lsmod` —Views loaded kernel modules
+   * `mouseconfig` —Configures a pointing device for Linux
+   * `ntsysv` —Controls services started when booting Linux
+   * `system-config-date` —Fedora’s graphical date and time client
+   * `system-config-display` —Fedora’s graphical X configuration client
+   * `system-config-soundcard` —Fedora’s graphical sound card configuration tool
+   * `system-config-keyboard` —Fedora’s graphical keyboard map configuration tool
+   * `system-config-mouse` —Fedora’s graphical pointer configuration tool
+   * `sensors` —Gets the system’s power, fan speed, and CPU temperatures
+   * `setserial` —Configures a serial port from the command line
+   * `sndconfig` —Configures a sound card for Fedora from the console
