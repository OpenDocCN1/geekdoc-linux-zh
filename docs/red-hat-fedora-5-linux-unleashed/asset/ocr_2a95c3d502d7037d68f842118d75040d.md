# Internet Relay Chat

Internet Relay Chat (IRC) is a popular form and forum of communication for many Red Hat Linux developers and users because it allows an interactive, real-time exchange of information and ideas. To use IRC, you must have an IRC client and the address of a network and server hosting the desired that channel for your discussions.

You can use the irc.freenode.net IRC server, or one listed at http://www.freenode.net/ to chat with other Fedora Project users. Two current channels are

+   - #fedora channel—General chat about Fedora
+   - #fedora-devel—Hangout for a number of The Fedora Project developers
