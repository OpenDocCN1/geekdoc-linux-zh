# Finding Information for Advanced Configurations

The information presented in this chapter should be enough to get most people up and running with their ISP. However, both kernel PPP and user PPP are extremely complex, and this chapter cannot cover all the options available. If you need to do more advanced configuration, both kernel PPP and user PPP have detailed man pages that describe all the options available. The kernel PPP man page can be accessed with man pppd, and the user PPP man page can be accessed with man ppp. In addition, sample configuration files are located in /usr/share/examples/ppp.
