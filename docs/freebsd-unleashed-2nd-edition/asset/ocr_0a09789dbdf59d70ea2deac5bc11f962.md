# What's on the CD-ROM

Disc 1 of the FreeBSD 5.0 distribution includes many packages that enhance the base FreeBSD kernel. The list that follows is based on the actual category that you can choose during the FreeBSD 5.0 installation and a brief description of what each category means.

+   | category | description |
+   |---|---|
+   | afterstep | Ported software that supports the AfterStep Window Manager |
+   | archivers | Archiving and unarchiving utilities and software |
+   | astro | Astronomy-related applications |
+   | audio | Software and utilities for sound cards—you may need a supported card for these programs to work |
+   | converters | Software and utilities to convert formats |
+   | databases | Database software |
+   | devel | Libraries and utilities for software development |
+   | editors | Text editors |
+   | emulators | Run software from other OSes with these utilities |
+   | ftp | FTP clients and servers |
+   | games | Amusements and diversions |
+   | gnome | Gnome Desktop Environment components |
+   | graphics | Libraries and utilities for graphics |
+   | ipv6 | Software and utilities for IPv6 |
+   | irc | Software and utilities for Internet Relay Chat |
+   | kde | Software and utilities for the K Desktop Environment |
+   | lang | Computer language support |
+   | linux | Linux applications and utilities that can be run under binary compatibility mode |
+   | mail | Software and utilities for electronic mail |
+   | math | Math-related software |
+   | misc | Software and utilities that don't fit in the other categories |
+   | net | Network-related utilities |
+   | news | Software for USENET News |
+   | perl5 | Perl 5 utilities and modules |
+   | print | Printing-related software and utilities |
+   | python | Python language support |
+   | ruby | Ruby language support |
+   | security | Software and utilities related to system security |
+   | shells | Replacement shell environments |
+   | sysutils | System utilities |
+   | tcl83 | TCL 8.3 and software dependent on it |
+   | textproc | Software and utilities that handle text processing |
+   | windowmaker | Windowmaker support packages |
+   | www | Clients and servers for web pages |
+   | x11 | Utilities for the X Window System |
+   | x11-clocks | Clocks for the X Window System |
+   | x11-fm | File managers for the X Window System |
+   | x11-fonts | Fonts for the X Window System |
+   | x11-servers | Servers for the X Window System |
+   | x11-toolkits | Development toolkits for the X Window System |
+   | x11-wm | Window managers for the X Window System |
