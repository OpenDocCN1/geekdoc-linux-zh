# Using ee (Easy Editor)

ee (Easy Editor) is installed by default along with FreeBSD. As its name indicates, the Easy Editor is a basic text editor that is designed to be easier to work with than some other traditional Unix text editors.

ee can be invoked either by simply typing **ee** at the command line or by typing **ee** followed by the name of a file you wish to edit. Figure 6.1 shows a sample ee session with a blank document.
