# Configuring FreeBSD 5.0

To configure FreeBSD for a default gateway, add the following line to the `/etc/rc.conf` file:

```
defaultrouter="64.41.131.162"
```

Of course, you will need to replace the IP address in the preceding example with the IP address of the gateway interface on the FreeBSD system that is serving as a gateway.
The change will not take effect until you have rebooted the system.
