# FIGURE 33.2 SWAT, the Samba Web Administration Tool.

SWAT comes with the Samba port and allows you to configure Samba graphically through a Web browser interface. This graphical configuration capability simplifies the process of managing the `smb.conf` file and reduces the risk of errors. As a Web application, however, the security risks associated with SWAT are significant. SWAT authenticates users against the system user database in `/etc/master.passwd`; authentication passwords are sent in clear text over the network from your client machine to the Samba server you want to configure. Unless you're configuring Samba from the local machine (localhost, using X-Windows), this presents a security risk. The risk can be managed a number of ways, but it's still not foolproof.
