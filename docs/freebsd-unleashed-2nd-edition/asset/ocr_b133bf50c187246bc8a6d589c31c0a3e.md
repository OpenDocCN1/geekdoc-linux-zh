Below this block are the “optional” lines—items that are part of the GENERIC kernel by default. Although these lines don’t have to be present in order for the kernel to be valid, it just wouldn’t be a very useful kernel without them. These include the block of useful kernel options shown in Listing 16.2 (a FreeBSD 5.0 kernel is shown).
