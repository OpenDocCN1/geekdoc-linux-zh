After you select the network device you want to configure, you are asked if you want to try the IPv6 configuration of the interface. Unless you are sure your network has an IPv6 server on it that is set up to send you configuration information, you should select No.

The next question asks you the same thing about the DHCP configuration of the interface. If your network has a DHCP server on it, FreeBSD will attempt to contact that server and obtain its network information. If your network does not have a DHCP server, you should select No.

The next screen allows you to enter the information about your network. This will be covered in much more detail in Chapters 21, “Networking with FreeBSD,” and 22, “Configuring Basic Networking Services,” but here are a few guidelines to get you started.
