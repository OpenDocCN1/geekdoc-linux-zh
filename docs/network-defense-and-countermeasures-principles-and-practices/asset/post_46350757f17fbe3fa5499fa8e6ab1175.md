## Conducting the Initial Assessment

Disaster recovery, access rights, and appropriate policies are topics that are often overlooked by those new to security. To keep it simple and easy to remember, the stages of assessing a system’s security can be separated into the “Six Ps”:

- Patch
- Ports
- Protect
- Policies
- Probe
- Physical

The first three are discussed in this section. The fifth—probe—is discussed in the next section, and policies are covered in Chapter 11, “Security Policies.” You should note that these Six Ps are the invention of this book’s author (just as the numerical grading system), and are not yet standards in the security industry. They are provided here as a framework for approaching system security.

## Patches

Patching a system is perhaps the most fundamental part of security. Therefore, when assessing any system’s security, you should check to see whether a procedure is in place to govern the updating of all patches. And you should also, of course, check to see that the machines actually have current patches and updates. A written policy is essential, but when performing a security audit, you need to ensure that those policies are actually being followed.

As you are, operating system and application vendors occasionally disclose security flaws in their products and release patches to correct these flaws. Unfortunately, it is not uncommon to find organizations in which patches have not been applied late as 30 days or more after their release.

## Applying Patches

Applying patches means that the operating system, database management systems, development tools, Internet browsers, and so on are all checked for patches. In a Microsoft environment this should be easy because the Microsoft website has a utility that scans for any required patches to the browser, operating system, or office products. It is a very basic tenant to ensure that all patches are up-to-date. This should be one of your first tasks when assessing a system. Regardless of the operating system or application vendor, you should be able to go to its website and find information regarding how to download and install everything.

## CHAPTER 12 Assessing System Security

Once you have ensured all patches are up to date, the next step is to set up a system to automatically patch. There are also automated solutions that will patch your network. Manually patching machines can be quite cumbersome, and in larger networks, simply impractical. These solutions scan your systems at preset times:

- Windows Update: For systems running Windows, you can set up Windows to automatically patch your system. Recent versions of Windows have this automatically. If your system is older, simply go to https://support.microsoft.com/en-us/help/12373/windows-update-faq and follow the instructions to keep your system updated. This is free. This approach does have a few shortcomings, the first being that it will only update Windows and not any other applications. The second drawback is that it does not provide any way to check patches on a test machine before deploying them to the entire network.

- HFNetChkPro: This product is available from https://www.petri.co/hfnetchk_pro. It automatically administers and manages patches, including rebooting the patched machines. It is sold on a seat license, with five seats going for about $200 and 100 seats selling for about $2,100.

- ZENWorks Patch Management: This product is available from Microfocus at https://www.microfocus.com/products/zenworks/patch-management/

- McAfee ePolicy Orchestrator: This product (https://www.mcafee.com/us/products/epo-orchestrator) is both interesting and popular. It handles the automated patching of your system, and includes a number of other features. One interesting feature is that it monitors the network for any devices that are connected to the network that are not set up via ePolicy Orchestrator. This prevents “rogue” machines. In larger organizations people setting up their own machines and servers can be a significant risk. ePolicy Orchestrator also monitors other aspects of your network defense, including antivirus and firewall software.

Other patch management software solutions are available. These four are provided to give you an example of the solutions available and the price range you can expect to pay for them. A simple Internet search using any major search engine should give you more options than you might want to consider.
