It should be noted that all of these tasks can be done without Norton. You can set your browser
security settings, and you can scan your machine for vulnerabilities (using free tools
downloaded from the Internet, some of which will be discussed in Chapter 12, "Assessing System
Security"). However, with Norton you can accomplish all of this via a much simpler interface. This is
particularly appealing to novice users. It should also be stressed that, unlike advanced fire-
walls, Norton’s firewall can block outgoing traffic as well.

As of the 2016 version of the Norton Firewall, it adds some additional features that are more like an
incursion detection system. It will notify you of any port scans, suspicious traffic, or unusual connection
attempts. It also support rules, like any firewall. You can learn more about the Norton firewall
at ftp:http://ftp.symantec.com/public/english_us_canada/products/norton_internet_security/2015/manuals/
IShelp.pdf.

- Norton Firewall has several extra features, such as the ability to scan your system for
