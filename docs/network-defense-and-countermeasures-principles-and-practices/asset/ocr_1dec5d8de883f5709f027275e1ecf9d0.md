# Understanding Denial of Service Attacks

The first type of attack to examine is the denial of service (DoS). Recall from Chapter 1 that a denial of service attack is any attack that aims to deprive legitimate users of the use of the target system. This class of attack does not actually attempt to infiltrate a system or to obtain sensitive information. simply aims to prevent legitimate users from accessing a given system. This type of attack is one of the most common categories of attack. Many experts feel it is so common that most forms of service attacks are fairly easy to execute. The ease with which these can be executed means even attackers with minimal technical skills can successfully perform a denial of service.

The concept underlying the denial of service attack is based on the fact that device has operational limits. This fact applies to all devices, not just computers. For example, bridges are designed to hold up to a certain limit, aircraft planes on how far they can travel without refueling, and automobiles can only accelerate to a certain point. All of these various devices share a common trait: They have limitations to their capacity to perform work. Computers are not different from these, or any other machine; they, too, have limits. Any computer system, web server, or network can only handle a finite load

How a workload (and its limits) differs from one machine to another. A workload for a computer system might be defined in a number of different ways, including by the number of simultaneous users, the size of files, the speed of data transmission, and the amount of data stored. Any of these limits will stop the system from responding. For example, if you flood a web server with more requests than it can process, it will be overloaded and no longer be able to respond to further requests. This reality underpins the DoS attack. Simply overload the system with requests, and it will no longer be able to respond to legitimate users attempting to access the web server.

# DoS in Action

The concept of a denial of services attack is simple; however, most principles are easier to grasp if one can see a concrete example. In this case you need a safe way to simulate a DoS attack within a classroom or laboratory setting. One simple way to illustrate a DoS attack, especially in a classroom setting, involves the use of the ping command with certain parameters. (Recall that in chapter 1 `ping /h` or `ping /` will show you all the options for the `ping command`). The first step is to set up a web server running on a computer that will be used as the target for this attack. You can use any operating system and any web server (such as Microsoft Internet Information Services or Apache HTTP Server). Apache is a free download from www.apache.org. Microsoft Windows 10 comes with Internet Information Services, so you should have no trouble purposefully use a low-capacity machine. An older machine, perhaps an older laptop, would be ideal. You would want to pick a machine that is easy to overload. In essence you are looking for the exact opposite of what you look for when setting up a web server.
