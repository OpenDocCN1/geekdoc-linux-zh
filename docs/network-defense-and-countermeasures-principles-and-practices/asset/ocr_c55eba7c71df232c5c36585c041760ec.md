# Introduction

Protecting the system's parameters and subnets by firewalls, proxy servers (or NAT-enabled machines), intrusion-detection systems, honeypots, and other devices is only one part of securing a network. Even installing antivirus software and anti-spyware does not complete a network's security. To achieve a more secure network, you must perform operating system hardening. This is the process of properly configuring each machine, and specially servers, for the optimum security settings. The word optimum than maximum is used for a reason. Maximum security is the least used. Optimum security strikes a balance between ease of use and security.

In this chapter you will learn how to properly configure Windows 7, Windows 8/8.1, Windows 10, Linux, and various web browsers. Secure configuring the operating system and its software is a critical step in system security that is frequently ignored. Even naive security administrators often think installing a firewall or antivirus software, but many fail to harden the individual machines against attacks. Discovering the presence of vulnerabilities allows you to close “open” ports and further restrict “input/output” operations. All of these techniques and procedures are in the over-arching area of Risk Management Systems and Information Assurance.
