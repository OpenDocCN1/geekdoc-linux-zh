# # SPAP

Shiva Password Authentication Protocol (SPAP) is a proprietary version of PAP. Most experts consider SPAP somewhat more secure than PAP because the username and password are both encrypted when they are sent, unlike with PAP. Figure 7-5 illustrates this protocol.

![](bbox=[0.118, 0.486, 0.621, 0.633])

SPAP encrypts passwords, someone capturing authentication packets will not be able to read the SPAP password. However, SPAP is still susceptible to playback attacks (that is, a person records the exchange and plays the message back to fraudulent access). Playback attacks are possible because SPAP always uses the same reversible encryption method to send the passwords over the wire.

# # Kerberos

Kerberos is one of the most well-known network authentication protocols. It was developed at MIT and its name stems from the triple-headed dog that guards the gates to Hades.
