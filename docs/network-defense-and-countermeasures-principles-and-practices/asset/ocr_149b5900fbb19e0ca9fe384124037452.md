This particular Trojan horse is a classic backdoor Trojan. Within the Trojan horse util-linux distribution, the program /bin/login was altered. The changes included code to send e-mail to the Trojan horse creator that contained the host name and logon information of users logging in. The distributors of the legitimate util-linux package updated their site with a new version; however, it is impossible to determine how many systems installed the Trojan version or how many systems were compromised as a result.

# Portal of Doom

This is an old, but a classic example. This Trojan horse is also a backdoor administration tool. It gives the remote user a great deal of control over the infected system. The actions remote users can take, if they get control of your system via Portal of Doom, but include are not limited to:

+   - Opening and closing the CD tray
- Shutting down the system
- Opening files or programs
- Accessing drives
- Changing the password
- Logging keystrokes
- Taking screenshots

Portal of Doom is similar to Back Orifice and NetBus. It is easy to use and has a graphical user interface, as you can see in Figure 10-3.
