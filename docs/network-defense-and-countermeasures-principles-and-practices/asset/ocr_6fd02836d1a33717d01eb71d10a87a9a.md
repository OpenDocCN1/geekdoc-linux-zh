You XOR the two values together, and store the resulting bits:

Drive 1 = 10101010

Drive 2 = 00001111

XOR = 10100101

The value 1010101 gets stored as parity bits. Now at some later time, drive 2 fails and the data is lost. All you need to do is XOR the parity bits with the remaining drive, and you will get back the original bits:

+   - Parity bits 10100101
- Drive 1 10101010
- Result is 00001111

So you get back the missing data. This is how the parity bits in RAID 3, 4, 5, and 6 work.

Although RAID and backup strategies are the fundamental issues of fault tolerance, any backup system provides additional fault tolerance. This can include uninterruptible power supplies, backup generators, and redundant Internet connections.
