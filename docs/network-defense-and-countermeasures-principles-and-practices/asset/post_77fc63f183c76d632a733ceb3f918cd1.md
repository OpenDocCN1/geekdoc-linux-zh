### Introduction
The first two chapters of this book discussed threats to network security and ways to defend against those threats. This and the following two chapters will address security devices. One of the most fundamental devices used to implement network security is the firewall. This is a key part of any security architecture. In fact, other systems such as the proxy server, intrusion prevention systems (IPS), and intrusion detection systems (IDS) work in conjunction with the firewall and are to some extent dependent upon it.

Most people have a general idea of what a firewall is. In this chapter we will examine firewalls in detail so you will have a deeper understanding of them. We will also look at some firewall products.

This chapter will explore the basics of how firewalls work to provide a basis for evaluating which firewall is most appropriate in a given situation.
