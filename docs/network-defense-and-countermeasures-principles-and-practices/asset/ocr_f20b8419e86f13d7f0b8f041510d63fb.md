# A1 - Verified Protection

This level includes everything in B3 with the addition of formal methods and proof of integrity of TCB. The biggest difference between A-rated and B-rated operating systems lies in the development. For A-rated systems the Orange Book carefully delineates specific controls that must be in place during the development of the system and testing standards that must be adhered to. This basically means that an A-rated system has every aspect of its security carefully verified during its development. Doing this requires a great deal of effort and expense. You will note that the only two A1 systems we list are for military use.

You can actually find here A1-certified systems:

+   - Boeing MLS LAN: This is a highly secure and specialized network operating system.
- Honeywell SCOMP (Secure Communications Processor): This is a highly secure and specialized network operating system.

# The Orange Book in Your Organization

Many IT professionals select operating systems based on one of three factors:

+   - Cost
- What they are familiar with
- What has the most software available for it

This means that in many businesses you will see Windows on the desktop and Windows, Linux, or Unix servers. However, as security becomes a greater concern, perhaps other criteria should be considered, at least for servers. Note that Windows Systems are C2-rated systems. That means that a Windows 2000 or Windows 2003 server is also rated C2. For many businesses this is enough.

However, you may wish to consider a more secure solution, at for your most critical servers. Even a C2 or B1-rated system generally suffices. This would probably make some version of Unix (though it is thought that Microsoft will eventually release a more secure server version, perhaps with a B1 or better rating). You could still use Windows for less critical servers such as web servers. But use the more secure Unix version for your major servers that contain data such as credit card data.

There has been a great deal of talk in the Linux community about someone making a much more secure version of this open source operating system specifically for use in highly secure settings. So far, to the best of this author's knowledge, that product has not been released. However, given the history of the open source software community, it seems only a matter of time.
