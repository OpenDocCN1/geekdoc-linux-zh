
# ipconfig

The first thing you want to get is information about your own system. To accomplish this factfinding mission, you must get a command prompt. In Windows, you can do this by going to the Start menu, selecting All Programs, and then choosing Accessories. You can also go to Start, run and type cmd. In Windows 10 you can go to Search and type cmd. You can now type in ipconfig. (You could use the same command in Unix or Linux by typing in ifconfig from the shell). After typing in ipconfig (ifconfig in Linux), you would see something like Figure 1-1.

![](img/b9022ea8d49ef539d37d0ec09f73f71c_32_0.png)

Figure 1-1 ipconfig

This command gives you some information about your connection to a network (or to the Internet). Most importantly you find out your own IP address. The command also has the IP address for your default gateway, which is your connection to the outside world. Running the ipconfig command is a first step in determining your system's network configuration. This means that commands, including ipconfig, have a number of parameters, or flags, that can be passed to the commands to make the computer behave in certain way. You can find out what these commands are by typing in the command, followed by a space, and then typing in hyphen question mark: - ?

As you can see, you might use a number of options to find different details about your computer's configuration. The most commonly used would probably be ipconfig/all, shown in Figure 1-2.

## ping

Another common command used is ping. ping is used to send a packet, or echo packet, to a machine to find whether it is reachable and how long the packet takes to reach the machine. This useful diagnostic tool can be employed in elementary hacking techniques. Figure 1-3 shows the command.

```
ping www.phpbb.com.au (192.168.1.178) with 32 bytes of data:
Reply from 192.168.1.178: bytes=32 time=1ms TTL=64
Reply from 192.168.1.178: bytes=32 time=1ms TTL=64
Reply from 192.168.1.178: bytes=32 time=1ms TTL=64
Reply from 192.168.1.178: bytes=32 time=1ms TTL=64

Ping statistics for 192.168.1.178:
    Packets Sent: 4, Received: 4, Lost (0% loss),
    Minimum = 1ms, Maximum = 1ms, Average = 1ms
```

FIGURE 1-3 ping

This figure tells you that a 32-byte echo packet was sent to the destination and returned. The ttl means “time to live.” That time unit is how intermediary steps, hops, the packet should take to the destination before giving up. Remember that the Internet is a vast conglomerate of connected networks. Your packet probably won't go straight to its destination. It will have to take several hops to get there. As with ipconfig, you can type in ping - to find out various ways you can refine your ping.

## tracerert

The next command we will examine in this chapter is tracerert. This command is a sort of “ping deluxe.” tracerert not only tells you whether the packet got there and how long it took, but it also tells you all the intermediate hops. (This command can be seen in Figure 1-4).

## tracerert

Another common command used is ping. ping is used to send a packet, or echo packet, to a machine to find whether it is reachable and how long the packet takes to reach the machine. | Layer | Description | Protocols |
| --- | --- | --- |
| Application | This layer interfaces directly to applications and performs common application services for the application processes. | POP, SMTP, DNS, FTP, Telnet |
| Presentation | The presentation layer relieves the application layer of concern regarding syntactic differences in data representation within the end-user systems. | Network Data Representation (NDR), Lightweight Presentation Protocol (LPP) |
| Session | The session layer provides for managing the dialogue between end-user application processes. | NetBIOS |
| Transport | This layer provides end-to-end communication control. | TCP, UDP |
| Network | This layer routes the information in the network. | IP, ARP, ICMP |
| Data link | This layer provides the logical organization of data bits transmitted on a particular medium. The data link layer is divided into two subarrays: the Media Access Control (MAC) and the Logical Link Control (LLC). | SLIP, PPP |
| Physical | This layer describes the physical properties of various communications media, as well as the electrical properties and interpretation of the exchanged signals. In other words, the physical layer is the actual NIC, Ethernet cable, and so forth. | IEEE 1394, DSL, ISDN |
