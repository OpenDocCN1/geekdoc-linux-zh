# Shedun

Shedun is a specific type of malware that was first discovered in 2015 and targets Android systems. The attack vector of this Trojan is to repack legitimate Android applications such as Facebook or the game Crush, but to include adware with them. The goal is to get the adware onto the target system, inundate the user with ads.

# Brain Test

Brain Test is another Android Trojan horse that was also discovered in 2015. It appears as an IQ test application. However, it is far more malicious than Shedun. It does not deliver adware, but instead installs a rootkit on the target system.

# FinFisher

This product is interesting because it was developed by a private company, but exclusively for law enforcement agencies. It can spread in many ways, but relevant to this chapter, it can appear as a software update. However, what it ultimately installs on the target system is spyware. This was designed for law enforcement agencies, presumably with a valid warrant, to use on suspects' computers. However, the entire suite of FinFisher products was released by WikiLeaks in 2011 and has been found on numerous computers that time.

# NetBus

The NetBus Trojan is quite similar to Back Orifice. A NetBus worm tries to infect machines with the NetBus Trojan. This tool is a remote administration tool (often called a RAT), much like Back Orifice. NetBus, however, operates only on port 20034. It gives the remote user control of the infected machine, as if he were sitting at the keyboard and had all administrative rights. The NetBus administration screen is shown in Figure 10-2. You can see that the intruder can accomplish a variety of high-level tasks on the infected machine.
