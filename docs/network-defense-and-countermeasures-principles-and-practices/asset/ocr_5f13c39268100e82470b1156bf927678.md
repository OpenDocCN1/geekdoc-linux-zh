# Equipment Security

Physical security begins with controlling access to the building and key rooms within the building. At the most basic level it includes a locked door on the server room. In addition to that you also have some way of controlling who has access to that room. A highly recommended approach is a swipe card or password key entry system that records who enters the room and when. You should also consider the room itself. It should not have a window, or if it does it should be a reinforced window and someone outside should not be easily view inside the room. The room should also be fireproof, because a fire in the server room would be a significant disaster.

The server room is obviously a key item to secure, but it is not the only item. If routers or switches are distributed in the building, they must be in locations that are not easily accessible by unauthorized personnel. Locked closets make a good location for these items. Locking down workstations so they are secured to the desk is also a common practice. This makes the theft of computers much more difficult.

Essentially any device that is itself valuable or contains data that is valuable must be physically secured. Equipping mobile business phones with the ability to remotely wipe them is also common practice. That if they become stolen or lost, the administrator can remotely wipe all data on phone.

# Securing Building Access

After you have secured the equipment you must also control access to the building itself. A common method is to have a locked door or turn that requires an employee ID to enter. A sign-in sheet is also a good way to track who enters and exits your office. The level of effort put into physical security of the building will vary depending on the organization's security needs.

A man trap is an often-used security mechanism in high-security environments. A man trap consists of two doors with a short hallway between them. The second door cannot open until the first door is closed. This prevents tailgating, which is the process of an unauthorized person following an authorized person through a secure door. This can be further enhanced by having each door use a different authentication method. Perhaps the first door requires a key and the second requires a passcode. This two-factor authentication system would be difficult for an intruder to circumvent.

Other methods of securing building include the external areas of a building. For example, a parking lot can be designed so that a person must turn every 50 feet or so to exit. This prevents a thief or intruder from "speeding away" and makes it more likely that someone will be able to note their license plate, or that police might arrive before they escape.

Fences are also important. Having some level of fencing is essential. High-security environments might use a tall fence, even topped with concertina wire. This might not be appropriate for many organizations, but even a decorative hedge provides some level of barrier to slow down intruders.
