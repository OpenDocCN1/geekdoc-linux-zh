Security professionals and security-savvy network administrators frequently use the same tools to inspect their systems that hackers try to break into them. Using the tools of hackers to try to crack an encryption method is a practical and straightforward way of testing data security.

# Cracking Passwords

Although not exactly same as breaking encrypted transmissions, cracking passwords is similar to it. If someone is able to successfully crack a password, particularly the administrator password, then other security measures are rendered irrelevant.

# John the Ripper

John the Ripper is a password cracker with both network administrators and hackers. You can download it for free from www.openwall.com/john/

This product is perfectly command line–based and has no Windows interface. It enables the user to select text files for word lists to attempt cracking a password. Although John the Ripper is less convenient to use of its command-line interface, it has been around for a long time and is well regarded by the security and hacking communities. Interestingly, a tool is available at www.openwall.com/passwdq/ ensures your passwords cannot easily be cracked by John the Ripper.

John the Ripper works with password files rather than attempting to crack live passwords on a given system. Passwords are usually encrypted and in a file on the operating system. Hackers frequently try to get that file off of a machine and download it to their own system so they can crack it at all. They might look for discarded media in your dumpster to find old backup tapes that might contain passwords. Each operating system stores that in a file in a different place:

+   - In Linux, it is /etc/passwd.
- In Windows 95, it is in a .pwl file.
- In Windows 2000 and beyond, it is in a hidden .sam file.

After you have downloaded John the Ripper, you can run it by typing in (at command line) the word john followed by the file you want to try to crack:

```
john password
```

To make it use a wordlist with rules only, type:

```
john -wordfile:/usr/dict/words -rules password
```
