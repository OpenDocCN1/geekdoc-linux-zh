# Introduction

Chapter 4 Firewall Practical Applications

A full discussion of IDS is beyond the scope of this section. However, this section provides an overview of how these work. IDS have become much more widely used in the last years. IDS is designed to alert the administrator that suspicious activity has taken place.

# Understanding Concepts

To explore this, we must first review how networks function. Historically, when IDS were first developed, hubs were used. Switches are used rather than hubs. With a hub, after a packet has travelled from its source network to the destination network, it finally arrives at the segment where the target is located. All the computers on that segment can see the packet, but because the destination address does not match the address of their network card, they ignore the packet.

At some point, individuals realized that if they chose not to ignore packets not destined for their network card, they could see all the traffic on the network segment. In other words, the packet sniffer was born.

# Preemptive Blocking

Preemptive blocking, sometimes called banishment vigilance, seeks to prevent intrusions before they occur. This is done by noting any signs of impending threats and then blocking the user or IP address from which these signs originate. Examples of this technique include attempting to detect the early footprinting stages of an impending intrusion, blocking the IP or user that is the source of the footprinting activity. If you find that a particular IP address is the source of frequent port scans and other scans of your system, you would block that IP address at the firewall.
