# Restrict Null Session Access Over Named Pipes

The null session access over named pipes registry setting should be changed for much the same reason as the preceding null session registry setting. Restricting such access helps prevent unauthorized access over the network. To restrict null session access over named pipes and shared directories, edit the registry and delete values, as shown in Table 8-5.

Key Path: HKLM\SYSTEM\CurrentControlSet\Services\LanmanServer
Action: Delete all values

# Restrict Anonymous Access

The anonymous access registry setting allows anonymous users to list domain user names and enumerate names. It should be shut off. The possible settings for this key:

+   - 0—Allow anonymous users
- 1—Restrict anonymous users
- 2—Allow users with explicit anonymous permissions

Key Path: HKLM\SYSTEM\CurrentControlSet\Control\Lsa
Action: Set Value = 2
