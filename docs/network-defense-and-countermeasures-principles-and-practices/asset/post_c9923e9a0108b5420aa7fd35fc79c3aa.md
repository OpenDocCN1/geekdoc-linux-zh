
It is a simple matter to check whether your computer is infected with NetBus. Simply go to command prompt and telnet with one of the following commands. If you get a response, you are probably infected. Use of the Loop back command:

telnet 127.0.0.1 12345
telnet 127.0.0.1 12346

If you are infected, removal is best accomplished via the registry by following these steps:

1. Using regedit find the key HKEY_LOCAL_MACHINE\Software\Windows\CurrentVersion\RunServices
2. Delete the key 666
3. Reboot the computer
4. Delete the file EXE in the Windows directory

### FlashBack
The FlashBack Trojan was first discovered in 2011. Though that is a bit dated, it should be noted that this Trojan specifically affected computers running Mac OS. The infection came from redirecting the user to a site that had an applet containing an exploit that caused the malware to be downloaded.

### Zeus
This Trojan was very active in 2014 to 2016 and is still found as of writing. It is notable because it is based on components of the older Trojan. Secondly, it is interesting because it set up an encrypted-to-peer botnet allowing the perpetrator to control infected computers.

### Linux Trojan
It is common to find proponents of non-Microsoft systems noting the security of their systems. It is true that there are certain features in many products that favor usability over security. However, it has been contention of some security experts that they have a smaller share of the market and are therefore less targets to the creators of malware. As these operating systems become more popular, we will see more attacks focused on them. In fact, Trojan horses have aimed specifically at Linux. There are a number of utilities available for Linux. Most ship with Linux distributions, but it is common for users to download updates from the Internet. The Trojan includes essential utilities for Linux systems. A Trojan horse was placed in the file .tar.gz on at least one server between January 22, 1999, and January 24, 1999. This Trojan could have been distributed to FTP sites. It is impossible to tell how many users downloaded it.

## Against Trojan Horses, Spyware, and Malware
The age of this Trojan horse should tell you that threats to Linux are nothing new. This particular Trojan horse is a classic backdoor. Within the Trojan distribution, the program /bin/login was altered. The changes included code to send e-mail to the Trojan creator that contained the host name and logon information of users logging in; however, it is impossible to determine how many systems installed the Trojan.

### Portal of Doom
This is an old but classic example. This Trojan horse is also a backdoor tool. It gives the remote user a great deal of control over the infected system but are not limited to:

- Opening and closing the CD tray
- Shutting down the system
- Opening files or programs
- Accessing drives
- Changing the password
- Logging keystrokes
- Taking screenshots

Portal of Doom is similar to Backifice and NetBus. It is easy to use and has a graphical user interface, as you can see in Figure 10-3.

You can manually remove this Trojan horse with the following steps:

2. Use the task manager to shut down the process for lsjs.exe. If you cannot shut it down, then reboot the machine. Now that you have altered the registry, the lsjs.exe program will not start again.
3. Delete the file lsjs.exe from the Windows directory.

### Symptoms of a Trojan Horse
It is difficult to determine whether your system is the victim of a Trojan horse. There are a number of symptoms that might indicate that you have a Trojan horse. Assuming, of course that you or another legitimate user are not making these changes, symptoms include:

- Browser page changing
- Any change to passwords, usernames, accounts, etc.
- Any changes to screen savers, mouse settings, backgrounds, etc.
- Any device seeming to work on its own

Any of these changes are symptoms of a Trojan horse and indicate your system is probably infected.

### So Many Trojan Horses?
Why do we see so many Trojan horses? I actually wonder why we don't see more. A variety of tools are available on the Internet, for free, that allow one to create a Trojan horse. One simple example is ELTeWrap, shown in Figure 10-4, which you can download for free after searching on Google. It is a simple command-line tool that is remarkably easy to use:

1. Open a command window.
2. Navigate to the folder you put ELTeWrap in.
3. Make sure two programs are in the folder (one carrier program and the other program you want to attach).
4. Type in the filename you want to run that is visible.
5. Type in the operation:
   a. Pack only
   b. Pack and execute, visible, asynchronously
   c. Pack and execute, hidden, asynchronously
   d. Pack and execute, visible, synchronously
   e. Pack and execute, hidden, synchronously
   f. Execute only, visible, asynchronously
   g. Execute only, hidden, asynchronously
   h. Execute only, visible, synchronously
   i. Execute only, hidden, synchronously
6. Go to the command line.
7. Type in the second file (the item you are surreptitiously installing).
8. Type in the operation.
9. When you're done with the files, press Enter.
