When selecting a tool, keep in mind that there are two methods for acquiring data from a phone or other device: logical and physical. It is important to understand how these methods work and the differences between them, make sure the tool you select supports the type of extraction you wish to perform.

# Logical Acquisition

Logical imaging refers to copying the active file system from the device into another file. Using this method, the data from the actual device is recovered and later be analyzed. Logical techniques are often the first type of examination forensics analysts will because they are easier to execute. In many cases they will provide sufficient data for the case. But they might not be enough in all cases. Physical techniques can provide more data. The reason examiners don't always use physical acquisition is that it is more difficult and takes considerably more time. Fortunately, many of the mobile forensics tools support logical acquisition also provide a reporting mechanism.

In many cases, the tool will execute a logical acquisition of the device, and with this information, it will export files into a graphical user interface (GUI) or report. The problem with some of these tools is that the examiner can see the reported data, but cannot view the source of data. It is preferable if an acquisition tool not only reports the data that was found but also allows the investigator to view the raw files from which it was derived.
