# Using Security Resources

As you read this book and when you move into the professional world, you will have frequent need for additional security resources. This section highlights a few of the most important ones and those you may find useful now.

+   - CERT (www.cert.org/). CERT stands for Computer Emergency Response Team, a group sponsored by Carnegie-Mell University. CERT was the first computer incident-response team and is still one of the most respected in the industry. Anyone interested in network security should visit the site routinely. On the website is a wealth of documentation, including guidelines for security policies, cutting-edge security research, security alerts, and more.

+   - Microsoft Security TechCenter (https://technet.microsoft.com/en-us/security). This site is particularly useful because many computers run Microsoft operating systems. This site is a portal to all Microsoft security information, tools, and updates. Users of Microsoft software should visit this site regularly.

+   - F-Secure Corporation (www.f-secure.com/). This site is, among other things, a repository for detailed information on virus outbreaks. You will find notifications and detailed information about specific viruses. This information includes how the virus spreads, ways to recognize the virus, and specific tools for cleaning an infected system of a particular virus.

+   - F-Secure Labs (www.f-secure.com/en/labs_global/home).

+   - SANS Institute (www.sans.org/). This site provides detailed documentation on virtually every aspect of computer security. The SANS Institute also sponsors a number of security research projects and publishes information about those projects on its website.
