Because many distributed DoS attacks depend on "unwitting" computers being used like, one way to reduce such attacks is to protect your computer against virus/worm attacks and Trojan horses. # Defending Against Buffer Overflow Attacks

Virus, DoS, and Trojan horse attacks are probably the most common ways to attack a system, but they are not the only methods of attack available. Another way of attacking a system is called a buffer overflow (or buffer overrun) attack. Some experts argue that the buffer overflow occurs often, if not more often, the DoS attack, but this is less true now than it was a few years ago. A buffer overflow attack is designed to put more data in a buffer than the buffer was designed to hold. However, recall that at least one used a buffer overflow to infect targeted machines. This means that although this might be less than once it was, it is still a real threat.

Any program that communicates with the Internet or a private network must receive some data. Data is stored, at least temporarily, in a space called a buffer. If the programmer who wrote the application was careful, the buffer will truncate or reject any information that the buffer has limit. Given the number of applications that might be running on a target system and the number of buffers in each application, the chance of having at least one buffer that was not written properly is significant enough to cause any prudent system administrator some concern. A moderately skilled in programming can write a program that purposefully writes more data into the buffer than it can hold.
