# NMAP

Perhaps the most popular pop scanner in the hacking and security community is the free tool Nmap (https://nmap.org/). There is a Windows version of it with a GUI that can be downloaded from nmap.org/download.html. You can use Nmap from the command line and learn all the various commands and flags. But using the GUI, it is just point and click. This is shown in figure 12-18.
