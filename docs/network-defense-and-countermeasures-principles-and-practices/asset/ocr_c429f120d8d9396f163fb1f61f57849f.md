Hackers call this type of attack cracking, which means intruding onto a system without permission, with malevolent intent. Any attack designed to breach security, either via some operating system or by other means, can be classified as cracking. As you progress through this book you will encounter a few methods for intruding on a system. In many cases, if not most, the idea is to exploit some software to gain access to the target system.

Using security flaws is not the only method for intruding into a system. In fact, some methods can be technologically much easier to execute. For example, one completely not technologically based method for breaching a system's security is social engineering, which, as the name implies, relies more on human nature than technology. This was the type of attack that the famous hacker Kevin Mitnick often used. Social engineering uses artist techniques to get users to offer up the information needed to access to a target system. This method is much simpler. The perpetrator obtains preliminary information about that organization, such as the name of its system administrator, and it to gain additional information from the system's users. For example, he might call someone in accounting and claim to be one of the company's technical support personnel. The intruder could use the system administrator's name to validate that. He could then ask various questions to learn additional details about the system's specifications. A savvy intruder might even get a person to provide a username and password. As you can see, this method is based on how well the intruder can manipulate people and has little to do with computer skills.

Social engineering and exploiting software flaws are not the only methods of executing an intrusion attack. The growing popularity of wireless networks gives rise to new kinds of attacks. The most obvious and dangerous activity is war-driving. This type of attack is an offshoot of war-dialing. With war-dialing, a hacker sets up a computer to call phone numbers in sequence until another computer answers to try and gain entry to its system. War-driving, using the same concept, is applied to locating vulnerable wireless networks. Many people forget that their wireless network signal extends as much as 100 feet (that, walls). # Denial of Service

The third category of attacks is blocking attacks, an example of the denial of service attack (DoS). In this attack, the attacker does not actually access the system, but rather simply blocks access to system from legitimate users. In the words of the CERT (Computer Emergency Response Team) Coordination Center (the first computer security incident response team), “A denial-of-service” attack is characterized by an explicit attempt by attackers to prevent legitimate users of a service from using that service.” One-used blocking method is flooding the targeted system with many false connection requests that it cannot respond to legitimate requests. DoS is an extremely common method, second only to malware.
