Note: This exercise requires you to use an open source honeypot. One such free solution can be found at www.honeypotproject.org, but free to use any honeypot you like. In fact, if possible, it is best to test out multiple solutions in order to compare results.

+   2. Configure it according to the vendor documentation.

+   3. Have one student(s) as a hacker attacking the honeypot.

+   4. The other student(s) should use the honeypot to detect intrusion.
