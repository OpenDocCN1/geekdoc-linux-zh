# Hank 的 Linux





这本书献给我的女儿，Josie。
因为她太棒了。


这是一个关于一个叫汉克的人的故事。
他遇到了麻烦，电脑屏幕一片空白。

他按下每一个按钮，不停地点击鼠标。
沮丧又愤怒，他甚至尝试踢它一脚。

但毫无作用。他的电脑坏了。
他需要一些帮助，找一个他信任的人。

汉克迅速起身，走向他的电话。
他必须给朋友打电话，汉克希望斯坦利在家。

电话响了，响了，响了，响了。
这时前门传来一声巨大的响声。

汉克放下电话，冲向门口。
“谁在那儿？”汉克焦急地询问。

“是我，斯坦利！”斯坦利说，“我来帮你了！”
“我们会修好你的电脑。不要害怕！”

“但怎么修？”汉克问，“它甚至无法启动！”
“Windows 起不来，我已经等了这么久！”

“别担心，我的朋友，”斯坦利宣布。
“我们将安装 Linux，现在让我们准备起来！”

“Linux？那是什么？”汉克一脸困惑地问。
“这听起来不像我用过的任何东西。”

“它能让你的电脑发挥出全部潜能！”
斯坦利宣布，“而且 Linux 是自由的！”

“它有趣，它快速，而且为了共享而构建。”
“它是由人们创造的，那些在乎它的人们！”

“听起来很棒，”汉克说，“但我该如何开始？”
斯坦利笑了笑说：“那部分我来帮你。”

“首先要做的是选择你的发行版（Distro）。”
“Linux 有各种风味，就像曲奇面团一样。”

“我可以拥有巧克力 Linux 吗？”汉克兴奋地问。
斯坦利笑了。“不，汉克，并非如此。”

“没有两种 Linux 是完全相同的。”
“我会告诉你我最喜欢的，我会告诉你它们的名字。”

“有古老的 Slackware，从一开始就在那里。”
“使用 Slackware，你的电脑永远不需要重启。”

“听起来太棒了！”汉克说，“我就用那个！”
“慢着！”斯坦利说，“还有很多可供选择的！”

“但为什么停在那？让我们深入探索吧！”
“Linux From Scratch，你会成为真正的专业人士！”

“如果你热爱编译，那么还有 Gentoo……”
“它确实很酷，但可能需要花 quite a while（很长时间）。”

“或者你可以用 Sabayon。选它准没错。”
“它有点像戴了顶漂亮蓝色帽子的 Gentoo。”

“我不明白，”汉克哭丧着脸说。
“我只想让它能工作，我想要简单点。”

斯坦利思考了一会儿，想出了一个计划。
“我们会为你找一个发行版，让你甚至不需要查 `man` 手册。”

“SUSE 很简单，让你感觉像个巫师。”
“它很棒，它是绿色的，还配有一只蜥蜴。”

“当然，如果你不喜欢绿色，还有 Ubuntu。”
“它是棕色的，它是橙色的，中间还夹着紫色。”

“Mint 就是 Ubuntu，除非它不是的时候。”
“我听说街上的很多人非常喜欢它。”

“Elementary 很有趣，它确实有格调。”
“它漂亮且精致，一定会让你微笑。”

“如果你喜欢大红帽子，Fedora 很酷。”
“而这当然完全没有问题。”

“然后是 Puppy 和 CrunchBang，它们的名字读起来就很有趣。”
“你可能想试试它们！你可能想留下来！”

“快停下来！”汉克兴奋地说。
“我要全部尝试！我要尝试每一个字节！”

“我要试 SUSE，试 Mint，试 Puppy 和 Gentoo！”
“我要试 Slackware，试 CrunchBang，Fedora 和 Ubuntu！”

“然后是 Debian，Puppy 和 Linux from Scratch！”
“接着是 Elementary，Sabayon 和 Arch！”

“很高兴能帮到你！”斯坦利随之唱道。
“让我们点披萨吧！安装派对时间到！”
