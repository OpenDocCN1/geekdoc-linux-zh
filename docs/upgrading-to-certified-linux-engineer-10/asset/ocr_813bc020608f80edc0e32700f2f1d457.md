# Use Syslog Daemon syslog-ng



The file /etc/sysconfig/syslog contains general parameters applicable to syslog-ng as well as syslog.

Parameters set in this file include switches passed to syslogged or syslog-ng, kernel log level, parameters for klogd, and which syslog daemon is to be used.

```
## Type: string
## Default: ""
## Config: ""
## ServiceRestart: syslog
#
# if not empty: parameters for syslogd
# for example SYSLOG_PARAMS="-r -s my.dom.ain"
SYSLOG_PARAMS="" 
```

```
## Type: string
## Default: ""
## Config: ""
## ServiceRestart: syslog
#
# if not empty: parameters for klogd
# for example SYSLOG_PARAMS="-x" to avoid (duplicate) symbol resolution
KLOGD_PARAMS="-x" 
```

```
## Type: list(syslog,syslog-ng)
## Default: syslog
## Config: syslog-ng
## Command: /sbin/rcsyslog restart
## PreSaveCommand: /sbin/rcsyslog stop
#
# The name of the syslog daemon used as syslog service: "syslogd", "syslog-ng"
SYSLOG_DAEMON="syslog-ng" 
```
