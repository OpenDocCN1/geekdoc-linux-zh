| 2. Activate LDAP Authentication | If you use the LDAP directory for user authentication, you can change the user's password by using the `ldappasswd` command.

If you configure the LDAP client with the YaST module, the PAM module `pam_ldap.so` is activated for all kinds of authentication in the file `/etc/security/pam_unix2.conf`.

If you configure the LDAP client manually, you can activate the LDAP authentication only for selected services.

To do this, use the PAM module `pam_ldap.so` (included in the package `pam_ldap`) is used. Add the module corresponding to the service to the PAM configuration file in `/etc/pam.d`. |
