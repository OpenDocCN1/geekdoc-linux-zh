| 3. Use a Virus Scanner for Email | AVMailGate is an antivirus email filter from H+BEDV Datentechnik GmbH.

AVMailGate can update the virus definition file and the engine itself.

AVMailGate is composed of two kinds of processes:

- av gated. The smtpd receiver that stores incoming email in the input queue.
- avgatefwd. Virus scanning function and SMTP forwarder and sendmail invoker.

Both processes can be configured by editing the file `/etc/avmailgate.conf.`

AMaViSd-new consists of

- The daemon.
- Optional helper programs that are only needed in setup between the message transfer agent (MTA).
- One or more content checkers: virus scanners such as SpamAssassin.

The email server sends all incoming and outgoing email to AMaViS d.

The emails will be extracted by AMaViS d-new and tested with a virus scanner. |
