# Summary

| Objective | Summary |
|---|---|
| 1. Improve Application Security with AppArmor | AppArmor imposes limits on processes based on rules set in profiles.

Even if compromised, programs are limited in what they are allowed to read, write, and execute. This even holds true for programs running with root permissions. |
| 2. Create and Manage AppArmor Profiles | There are YaST modules as well as command line tools to create and manage AppArmor profiles.

The main YaST modules are the Add Profile Wizard, and the Update Profile Wizard.

The corresponding command line tools are autodep, genprof, and logprof.

Profiles are text files located in /etc/apparmor.d/ and can be maintained with any text editor. |
