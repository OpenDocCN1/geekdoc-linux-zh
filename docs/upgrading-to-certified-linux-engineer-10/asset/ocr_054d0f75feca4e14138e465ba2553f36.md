|---|---|
| 3. Replicate OpenLDAP Servers | The slapd on the master server can be configured to write a replication logfile.

On the master server you also have to specify the name(s) of the slave server.

On the master you specify a DN to used by the master to access the slave. This DN must also be specified on the slave server and must have permission to write to the database.

**slapacat** is used to generate an LDIF output based on the contents of a slapd database. |
