## 目标 2 配置安全设置

YaST 提供一个本地安全模块，可让您为 SUSE Linux Enterprise Server 配置以下本地安全设置：

- 密码设置
- 启动配置
- 登录设置
- 用户创建设置
- 文件权限

您可以从三个预设的安全级别中选择（或修改），或创建自己的自定义安全设置，以满足您企业安全策略和程序的要求。

您可以通过从 YaST 控制中心选择“安全和用户 > 本地安全”，或在终端窗口中输入 `yast2 security`（以 root 身份），访问安全设置模块。
