+   - **$notify_virus_recips_templ.** Specify a text file if you do not want to notify the recipients of an email that contained a virus.
+   - **$notify_spam_sender_templ.** Specify a text file if you do not want to notify the sender of an email that contained spam.
+   - **$notify_spam_admin_templ.** Specify a text file if you do not want to notify the administrator if a spam email is detected.
