| 2. Understand Recent Match of iptables | The recent match can be used to dynamically create a list of IP addresses and create rules regarding those IP addresses.

| 3. Log to a Remote Host | Logging to a log host prevents manipulation of log files after an intrusion.
The information in log files is only useful if someone sees it and acts accordingly.
Several programs, like logcheck, logsurfer, or custom scripts exist to help find relevant log entries. |
