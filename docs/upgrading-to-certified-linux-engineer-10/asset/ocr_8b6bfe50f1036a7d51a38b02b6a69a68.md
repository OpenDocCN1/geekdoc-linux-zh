| 5. Use the GNOME File Manager (Nautilus) | GNOME provides its own file manager (called Nautilus).

Normally Nautilus shows the content of the user's home directory after starting.

The right frame is called **Side Panel**.

At the top of the side panel there is a menu where you can select the content of the side panel. |
| 6. Search for Files | The GNOME Search Tool allows you to search for information such as file size, date, or file owner.

Further settings can be made when you open the menu under **Select more options**. Select a search rule from the pulldown menu **Available options**. |
| 7. Access the Command Line Interface From the Desktop | You can start a terminal emulation from your GNOME desktop by selecting Gnome Terminal (shown in the following picture) or X Terminal from the main menu. |
