| 1. Understand SMTP Communication | The following SMTP commands must be implemented in an SMTP server to provide SMTP communication:
- HELO
- MAIL FROM:
- RCPT TO:
- DATA
- RSET
- NOOP
- QUIT |

| Objective | Summary |
|---|---|
| 2. Manage Spam | **spamassassin** (and **spamc**) expect their input from STDIN.

If you want to use SpamAssassin with your Postfix configuration, the easiest way is to use Procmail.

Spam can be filtered from the mail client or in a further Procmail configuration (~/.procmailrc).

You can use **telnet** to test your configuration. You also can send a spam email directly using the **sendmail** command. |
