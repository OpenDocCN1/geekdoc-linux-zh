# Objective 4 Monitor AppArmor

There are two ways to monitor AppArmor:

+   - Security Event Report
+   - Security Event Notification

# Security Event Report

The YaST module to configure and view AppArmor security event reports can be launched by starting YaST and selecting Novel AppArmor > AppArmor Reports. It can also be launched directly from a console window as root by entering yast2 SD_Report.

The dialog that opens up shows when security event reports are generated.

![](bbox=[0.05, 0.5, 0.95, 0.85])

By default these are created once a day at midnight.
