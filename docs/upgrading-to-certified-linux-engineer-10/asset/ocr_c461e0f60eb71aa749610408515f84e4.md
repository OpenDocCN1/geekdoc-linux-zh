| 2. Configure LVM with Command Line Tools | To initialize a partition for LVM, use the tool **pvcreate**.

**pvscan** shows the physical volumes and their use.

The tool **pvmove** is used to move data from one physical volume to another.

The tool **vgcreate** is used to create a new volume group.

To add further physical volumes to the group, use **vgexpand**.

Removing unused physical volumes is done with **vgreduce** after shifting data from the physical volume scheduled for removal to other physical volumes using pvmove.

**vgremove** removes a volume group, providing there are no logical volumes in the group.

To create a logical volume, use **lvcreate**.

**lvscan** is used to view the logical volumes.

**lvextend** is used to increase the size of a logical volume.

Before you use **lvreduce** to reduce the size of a logical volume, you have to reduce the size of the file system. |
