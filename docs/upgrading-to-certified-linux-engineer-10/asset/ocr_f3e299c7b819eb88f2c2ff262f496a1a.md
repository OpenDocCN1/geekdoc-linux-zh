# Summary

| Objective | Summary |
|---|---|
| 1. Create a Key for Zone Transfer | Generate the key by using the `dnssec-keygen` command.

The *.key file contains a DNS KEY record that can be included in a zone file using the include statement.

The *.private file contains algorithm specific fields. For security reasons, this file does not have general read permission.

This key has to be included in the configuration file /etc/named.conf on both the master server and the slave server. |
| 2. Configure Dynamic DNS | You can to modify the resource records of BIND dynamically and without editing and reloading files.

Dynamic DNS can also be used by external services like DHCP.

To manipulate the DNS records dynamically, use the `nsupdate` command. |
