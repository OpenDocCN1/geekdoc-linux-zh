On the root drive, Linux can use special directories as *mount points*. Mount points are directories in the virtual directory where you can assign additional storage devices. Linux causes files and directories to appear within these mount point directories, even though they are physically stored on a different drive.

System files are often physically stored on the root drive. User files are typically stored on a separate drive or drives, as shown in Figure 3.3.

The *Linux* filesystem structure originally evolved from the *UNIX* file structure. In a *Linux* filesystem, common directory names are used for common functions. Table 3.1 lists some common *Linux* virtual top-level directory names and their contents.

The */usr* directory deserves some special attention, because it is a secondary directory grouping, containing read-only files that are shareable. It often contains user commands, source code files, games, and so on. Here is an example of the */usr* directory on a *Rocky 9 Linux* system:

