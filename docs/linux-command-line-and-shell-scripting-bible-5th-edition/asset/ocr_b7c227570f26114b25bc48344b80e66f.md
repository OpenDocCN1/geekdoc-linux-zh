practice to use the `$S` variable as the seed value. This special variable represents the process ID (PID) of the shell and should be unique for each instance the shell runs.

# **Defining the variable type**

A feature in the ksh93 shell that's not available in the Bash shell is the `typeset` command. This command allows you to set attributes for variables and functions. One of the attributes you can set is the data type that the variable uses. Table 25.3 lists the parameters used with the `typeset` command.

# TABLE 25.3 **The typeset Command Parameters**

| Parameter | Description |
| :--- | :--- |
| `-A` | Makes the variable an associative array. |
| `-b` | Indicates that the variable can contain any number of data bytes. |
| `-En` | Makes the variable a double-precision floating-point number with *n* significant figures. |
| `-Fn` | Makes the variable a double-precision floating-point number with *n* decimal places. |
| `-f` | Assigns a name for a function. |
| `-In` | Makes the variable an integer value with a base of *n*. |
| `-i` | Converts all uppercase characters to lowercase. |
| `-L` | Removes leading blanks and left-justifies the text. |
| `-n` | Declares the variable to be a reference to another variable. |
| `-r` | Makes the variable read-only. |
| `-R` | Adds leading blanks to right-justify the text. |
| `-u` | Converts all lowercase characters to uppercase. |
| `-x` | Marks the variable for automatic exporting. |
| `-Z` | Right-justifies and fills with leading zeros. |

The `typeset` command is a great way to convert numbers between different bases:

```
$ typeset -12 a
$ typeset -18 b
$ typeset -116 c
$ a=100
$ b=100
$ c=100
$ echo $a $b $c
2#1100100 8#144 16#64
$
```
