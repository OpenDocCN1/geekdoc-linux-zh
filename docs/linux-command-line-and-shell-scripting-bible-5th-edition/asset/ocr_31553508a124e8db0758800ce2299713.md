# Part IV: Working with Alternative Shells

The *tcsb* shell also contains special tests for files and directories. These tests take this form:

- *op* *file*

where *op* is a one-character operation that defines the type of file operation to test. Table 24.5 shows the file test operators available in *tcsb*.

TABLE 24.5 The tcsb File Test Operators

| Operator | Description | 
|---|---|
| r | Read access |
| w | Write access |
| x | Executable |
| X | Contained within the path or a built-in command |
| e | The file exists |
| o | The owner of the file |
| z | Has zero size |
| s | Has non-zero size |
| f | Plain file |
| d | Directory |
| l | Symlink |


This provides an easy way to test the status of files in your shell scripts:

```
$ cat test6
#!/bin/tcsb
# testing for the $HOME directory and a file

if ( -d $HOME ) then
	echo "The HOME directory exists"
endif
if ( -f $HOME/test ) then
	echo "The test file exists"
else
	echo "The test file doesn't exist"
endif
$ ./test6
The HOME directory exists
The test file doesn't exist
$ touch $HOME/test
$ ./test6
The HOME directory exists
The test file exists
$
```

Using the file test operators, you can easily determine the status of files before trying to use them in your scripts.
