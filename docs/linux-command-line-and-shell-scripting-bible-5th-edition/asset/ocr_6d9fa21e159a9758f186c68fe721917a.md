```
$ ./${\textbf{badtest2}}
${\text{The result is 22}}
${\text{temp is larger}}
$
```

Because the $temp variable was used in the function, its value is compromised in the script, producing a result that you may not have intended. There’s an easy way to solve this problem in your functions, as shown in the next section.

# Local variables

Instead of using global variables in functions, any variables that the function uses internally can be declared as local variables. To do that, simply add the local keyword in front of the variable declaration:

```
${\text{local temp}}$
```

You can also use the local keyword in an assignment statement while assigning a value to the variable:

```
${\text{local temp=}${[\S value + 5]}}$
```

The local keyword ensures that the variable is limited to only within the function. If a variable with the same name appears outside the function in the script, the shell keeps the two variable values separate. That means you can easily keep your function variables separate from your script variables and share only the ones you want to share:

```
$ ${\text{cat test9}}
${#!{/bin/bash}}
# ${\text{demonstrating the local keyword}}

${\text{function func1}}${
}
	normal local temp=${[\S value + 5]}
	normal result=${[\S temp * 2]}
${}

temp=${[4]}
value=${[6]}

${\text{func1}}
${\text{echo}}${"The result is ${[\S result]"}}
${\text{if}}${[}{[\S temp -gt ${[\S value]}]}$
	normal then
	normal echo${"temp is larger"}
	normal else
	normal echo${"temp is smaller"}
${\text{fi}}
$
$ ./${\text{test9}}
${\text{The result is 22}}
${\text{temp is smaller}}
$
```
