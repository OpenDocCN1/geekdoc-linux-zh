> **WARNING**
> 
> The /tmp directory is called temporary because the Linux operating system will automatically delete files stored there. While different Linux systems use different rules for how long temporary files are kept, at a minimum, each time the system is rebooted, it cleans out the /tmp directory. Don't count on any files you create in the /tmp directory to be there after your script runs!

# ### Creating a temporary directory

The -d option tells the `mktemp` command to create a temporary directory instead of a file. You can then use that directory for whatever purposes you need, such as creating additional temporary files:
