# Built-in commands

The tcsh shell contains a host of built-in commands available both on the command line and in shell scripts. Table 24.4 describes the available commands.

# TABLE 24.4 The tcsh Shell Built-in Commands


| Command | Description |
| :---- | :---- |
| @ | Displays or sets shell variables. |
| alias | Assigns an alias name to a command. |
| alloc | Displays the dynamic memory status. |
| bg | Places the current or specified job in background mode. |
| bindkey | Displays or sets editor commands to keyboard keys. |
| builtins | Displays the names of all built-in commands. |
| cd | Changes to the home directory, or to the specified directory. |
|.chdir | The same as the cd command. |
| complete | Displays or manages command completion strings. |
| dirs | Displays or saves the current directory stack. |
| echo | Displays a string to STDOUT. |
| echotc | Performs a terminal command on STDOUT. |
| eval | Treats the supplied string as input to the shell executes the commands. |
| exec | Executes the supplied command in place of the current shell. |
| exit | Terminates the current shell process. |
| fg | Continues the specified job in foreground mode. |
| filetest | Applies a specified test to the specified file. |
| glob | Similar to echo, except doesn't recognize escape characters, and words are delimited with null characters. |
| hashstat | Displays statistics on command-line hash table hits. |
| history | Displays and manages the command history file. |
| hup | Runs specified command and exits if a hangup signal is received. |
| jobs | Displays any active jobs. |
| kill | Sends the specified signal to the specified process ID (PID). |
| limit | Limits the specified resource so as to not take more than the specified resource (CPU time, file space, memory size, and others). |
| log | Displays the contents of the watch shell variable and reports on each user. |
| login | Terminates the shell and replaces it with the /bin/login process. |
| logout | Terminates the shell. |
