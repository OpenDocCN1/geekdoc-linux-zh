| Name | Shortcut Key | Description |
| :--- | :--- | :--- |
| Monitor for Activity | Ctrl+Shift+A | Toggles on/off a special message when activity starts occurring in the tab session |
| Monitor for Process Finishing | None | Toggles on/off a special message when the current process finishes and returns a command prompt |
| Read-only | None | Toggles on/off the terminal session accepting keyboard strokes; does not enable/disable keyboard shortcuts |
| Allow Mouse Tracking | None | Toggles on/off the ability to follow the mouse pointer in the window |
| Enlarge Font | Ctrl++ | Enlarges the font size in the window incrementally |
| Reset Font Size | Ctrl+Alt+0 | Returns the font size to default |
| Shrink Font | Ctrl+- | Reduces the font size in the window incrementally |
| Set Encoding | None | Selects the character set used to send and display characters |
| Clear Scrollback | None | Removes the text in the current session's scrollback buffer |
| Clear Scrollback and Reset | Ctrl+Shift+K | Removes the text in the current session's scrollback buffer and resets the terminal window |
| Full Screen Mode | F11 | Toggles on/off the terminal window filling the entire monitor display area |

The Monitor for Silence option is used for indicating tab silence. Tab silence occurs when no new text appears in the current tab session for about seven seconds. This allows you to switch to another tab while waiting for application's output to stop.

> **Tip**
> The Konsolle application provides a simple menu when you right-click in the active session area. Several menu items are available in this easy-to-access menu.

The Bookmarks menu options provide a way to manage bookmarks set in the Konsolle window, as listed in Table 2.12. A bookmark enables you to save your active session's directory location and then easily return there in either the same session or a new session.
