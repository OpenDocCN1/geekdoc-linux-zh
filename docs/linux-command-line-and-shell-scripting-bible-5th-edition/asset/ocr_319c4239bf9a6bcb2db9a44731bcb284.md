Configure Notifications allows you to associate specific events that can occur within a session with different actions, such as playing a sound. When one of the events occurs, the defined action (or actions) is taken.

To start learning Linux command-line commands, you need access to a CLI. In the world of graphical interfaces, this can sometimes be challenging. This chapter discussed various interfaces you should consider to get to the Linux command line.

First, this chapter discussed the difference between accessing the CLI via a virtual console terminal (a terminal outside the GUI) and a graphical terminal emulation package (a terminal inside the GUI). The chapter briefly looked at the basic differences between these two access methods.

Next, it explored in detail accessing the CLI via a virtual console terminal, including specifics on how to change console terminal configuration options such as background color.
