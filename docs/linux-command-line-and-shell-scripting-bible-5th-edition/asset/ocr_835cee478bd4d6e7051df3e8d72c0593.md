The zsh shell is no slouch when it comes to providing built-in commands! You should recognize most of these commands from their Bash counterparts. The most important features of the zsh shell built-in commands are modules.

# Add-in modules

There’s a long list of modules that provide additional built-in commands for the zsh shell, and the list continues to grow as resourceful programmers create new modules. Table 23.5 shows the currently available modules at the time of this writing.

# TABLE 23.5 The zsh Modules

|Module|Description|
|---|---|
|zsh/attr|Commands to manipulate extended attributes|
|zsh/cap|POSIX capability commands|
|zsh/clone|Commands to clone a running shell to another terminal|

|zsh/complete|Command line completion commands|
