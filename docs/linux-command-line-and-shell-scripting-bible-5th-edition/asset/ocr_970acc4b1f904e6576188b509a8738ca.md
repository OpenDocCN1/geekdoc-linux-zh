After retrieving the input, the switch statement compares the text to each case statement. If none matches, it uses the default statement (if provided).

# ## Summary

This chapter discussed the features found in the C shell. While the C shell is not overly popular in the Linux world, you may still run into it, so it’s a good idea to know how it differs from the Bash shell.

The most popular C shell implementation is the tsh shell. While the tsh shell is usually not the default shell in Linux, it’s usually available as an installation file. This allows you to write and test scripts used in a UNIX environment that uses the C shell.

The C shell uses two types of variables—shell variables and environment variables. Shell variables are lowercase and contain system information and settings commonly used in the C shell. The environment variables are mostly used for compatibility with Bourne and Bash shell scripts, and they maintain simple values such as the path and shell name.

To set shell variables you must use the `set` statement. The C shell allows you use assign mathematical operations to variables, but you must use the `set` statement `alias`, the `at` symbol (@). Using this symbol, you can write mathematical equations using standard math symbols and parentheses.

To set environment variables you must use the `setenv` statement.
