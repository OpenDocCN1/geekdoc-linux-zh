# **The GNU parted command**

The `GNU parted` program provides yet another command-line interface (CLI) for working with drive partitions. Unlike the `fdisk` and `gdisk` programs, the commands within this utility are more word-like:

```
$ sudo parted
GNU Parted 3.5
Using /dev/sda
Welcome to GNU Parted! Type 'help' to view a list of commands.

(parted) print
Model: ATA VBOX HARDDISK (scsi)
Disk /dev/sda: 21.5GB
Sector size (logical/physical): 512B/512B
Partition Table: msdos
Disk Flags: 

 Number  Start   End     Size    Type     File system  Flags
     1     1049kB  1075MB  1074MB  primary  ext4         boot
     2     1075MB  21.5GB  20.4GB  primary              lvm

(parted) quit
$
```

One of the selling features of the `parted` program is that it allows you to modify existing partition sizes so you can easily shrink or grow partitions on the drive.
