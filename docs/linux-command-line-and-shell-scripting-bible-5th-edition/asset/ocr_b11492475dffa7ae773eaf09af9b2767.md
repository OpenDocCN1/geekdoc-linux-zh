# Installing the tcs h Shell

The tcs h shell is available in the repository for most Linux distributions, so installing it is as easy as using the appropriate installation tool. For example, in Ubuntu, use the apt command:


Once you have the tcs h package installed, to get to the tcs h shell command prompt, just type the tcs h command:

```
rich@ubuntu2404:~$ tcs h
ubuntu2404:->
```

You can use the c hsh command to set the default login shell for a user to the tcs h shell:

```
rich@ubuntu2404:~$ sudo chsh -s /bin/tcs h test1
rich@ubuntu2404:~$ 
```
