# Part I: The Linux Command Line

The touch command is useful for creating empty files and for changing the access or modification times on an existing file. You also learned about using the cp command to copy existing files from one location to another. You walked through the process of linking files instead of copying them, providing an easy way to have the same file in two locations without making a separate copy. The ln command provides this linking ability.

Next, you learned how to rename files (called moving) in Linux using the mv command and saw how to delete files (called removing) using the rm command. You also saw how to perform the same tasks with directories, using the mkdir and rmdir commands.

Finally, this chapter closed with a discussion on viewing the contents of files. The cat, more, and less commands provide easy methods for viewing the entire contents of a file, whereas the tail and head commands are great for peeking inside a file to just see a small portion of it.

The next chapter continues the discussion on Bash shell commands. You'll look at more advanced administrator commands that come in handy as you administer your Linux system.
