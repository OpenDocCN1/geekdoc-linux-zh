# # Renaming files

In the Linux world, renaming files is called *moving files*. The `mv` command is available to move both files and directories to another location or a new name:

```
$ ls -li f*11
1414976 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 fall
1415004 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 fell1
1415005 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 fill1
1415011 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 full1
$
$ mv fall fz11
$
$ ls -li f*11
1415004 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 fell1
1415005 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 fill1
1415011 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 full1
1414976 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 fz11
$
```

Notice that moving the file changed the name from *fall* to *fz11*, but it kept the same inode number and timestamp value. This is because `mv` affects only a file's name.

You can also use `mv` to change a file's location:

```
$ ls -li /home/christine/fz11
1414976 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12 /home/christine/fz11
$
$ ls -li /home/christine/NewDocuments/fz11
ls: cannot access `/home/christine/NewDocuments/
fz11': No such file or directory
$
$ mv /home/christine/fall /home/christine/NewDocuments/
$
$ ls -li /home/christine/NewDocuments/fz11
1414976 -rw-rw-r---. 1 christine christine 0 Feb 29 16:12
/home/christine/NewDocuments/fz11
$
$ ls -li /home/christine/fz11
ls: cannot access `/home/christine/fz11': No such file or directory
$
```

The preceding example moved the `fz11` file from `/home/christine` to `/home/
christine/NewDocuments` using the `mv` command. Again, there were no changes to the
file's inode number or timestamp value.

> **Tip**
> 
> As with the `cp` command, you can use the `-i` option on the `mv` command. Thus, you are asked before the command attempts to overwrite any preexisting files.
