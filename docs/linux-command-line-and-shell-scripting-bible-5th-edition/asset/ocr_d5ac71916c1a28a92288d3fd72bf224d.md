# TABLE 2.12 **The Bookmarks Menu**

| Name | Shortcut Key | Description |
|---|---|---|
| Add Bookmark | Ctrl+Shift+B | Creates a new bookmark at the current directory location |
| Bookmark Tabs as Folder | None | Creates a new bookmark for all current terminal tab sessions |
| New Bookmark Folder | None | Creates a new bookmark storage folder |

The Plugins menu allows you to enable or disable plugin features installed in Konsolo. By default there are two plugins installed:

+   - **Show Quick Commands:** Opens a panel where you can add and manage shortcuts for frequently used commands.
+   - **Show SSH Manager:** Opens a panel where you can manage SSH connections.

The Settings menu allows you to customize and manage your profiles. The options are listed in Table 2.13. Profiles allow a user to automate the running of commands, set up the session's appearance, configure the scrollback buffer, and so on. Also, within the Settings menu, you can add a little more functionality to your shell sessions.

# TABLE 2.13 **The Settings Menu**

| Name | Shortcut | Key Description |
|---|---|---|
| Create New Profile | None | Opens the Edit Profile window to provide profile configuration options |
| Switch Profile | None | Applies to the current tab a selected profile |
| Manage Profiles | None | Opens the Manage Profiles window to provide profile management options |
| Window Color Scheme | None | Allows you to select from a list of preset color schemes |
| Show Menubar | Ctrl+Shift+M | Toggles on/off menu bar display |
| Toolbars Shown | None | Displays a list of the current toolbars where you can enable/disable individual toolbars |
| Configure Language | None | Allows you to set the language character set to use for the Konsolo session |
| Configure Keyboard Shortcuts | None | Creates Konsolo command keyboard shortcuts |
| Configure Toolbars | None | Allows you to customize the toolbars in your Konsolo session |
| Configure Notifications | None | Creates custom Konsolo notifications |
| Configure Konsolo | Ctrl+Shift+, | Configures many Konsolo features |
