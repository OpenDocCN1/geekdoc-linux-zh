Konsolle provides an excellent method for tracking what function is taking place in each tab session. Using the Rename Tab option, you can name a tab to match its current task. This helps in tracking which open tab session is performing what job.

> **NOTE**
> Konsolle also utilizes a scrollback buffer for retaining a history of previously entered commands.
