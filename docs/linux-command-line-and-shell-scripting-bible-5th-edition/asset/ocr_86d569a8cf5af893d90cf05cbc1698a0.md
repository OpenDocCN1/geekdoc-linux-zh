# ## Chapter 2: Getting to the Shell

TABLE 2.7 The Terminal Menu

| Name | Description |
| :--- | :--- |
| Set Title... | Changes the title that appears at the top of the tab |
| Read-Only | Toggles on/off the terminal session accepting keyboard strokes; it does not enable/disable keyboard shortcuts |
| Reset | Sends the reset terminal session control code |
| Reset and Clear | Sends the reset terminal session control code and clears terminal session screen |
| 80x24 | Adjusts the current terminal window size to 80 columns wide by 24 rows high |
| 80x43 | Changes the current terminal window size to 80 columns wide by 43 rows high |
| 132x24 | Adjusts the current terminal window size to 132 columns wide by 24 rows high |
| 132x43 | Changes the current terminal window size to 132 columns wide by 43 rows high |

The Tabs menu provides items for controlling the location of the tabs and selecting which tab is active, as listed in Table 2.8. This menu displays *only* when you have more than one tab session open.

TABLE 2.8 The Tabs Menu

| Name | Shortcut Key | Description |
| :--- | :--- | :--- |
| Previous Tab | Ctrl+Page Up | Makes the previous tab in the list active |
| Next Tab | Ctrl+Page Down | Makes the next tab in the list active |
| Move Terminal Left | Shift+Ctrl+Page Up | Shuffles the current tab in front of the previous tab |
| Move Terminal Right | Shift+Ctrl+Page Down | Shuffles the current tab in front of the next tab |
| Detach Terminal | None | Removes the tab and starts a new GNOME Terminal window using this tab session |

Finally, the Help menu contains two menu options:

+   1. **Contents** provides a full GNOME Terminal manual so that you can research individual GNOME Terminal items and features.
+   2. **About** shows you the current GNOME Terminal application version that's running.

*Besides the GNOME terminal emulator package, another commonly used package is Konsole. In many ways, Konsole is similar to GNOME Terminal. However, enough differences exist to warrant its own section.*
