
The `if`-`then` statement uses the `continue` command to stop processing the commands inside the loop but continue the outer loop:

```
if [ $a -gt 2 ] && [ $a -lt 4 ]
then
    continue 2
fi
```

Notice in the script output that the iteration for the value `3` doesn't process any inner loop statements because the `continue` command stopped the processing, but it continues with the outer loop processing.

# Processing the Output of a Loop

Finally, you can either pipe or redirect the output of a loop within your shell script. You do this by adding the processing command to the end of the `done` command:

```
for file in /home/rich/*
do
    if [ -d "${file}" ]
    then
        echo "${file} is a directory"
    elif
        echo "${file} is a file"
    fi
done > output.txt
```

Instead of displaying the results on the monitor, the shell redirects the results of the `for` command to the `output.txt` file.

Consider the following example of redirecting the output of a `for` command to a file:

```
$ cat test23
#!/bin/bash
# redirecting the `for` output to a file

for (( a = 1; a < 10; a++ ))
do
    echo "The number is $a"
done > test23.txt
```
