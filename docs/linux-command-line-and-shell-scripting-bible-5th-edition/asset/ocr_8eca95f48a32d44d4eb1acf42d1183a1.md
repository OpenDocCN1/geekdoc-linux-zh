# Chapter 24: The tcsh Shell

|

Command
Description

|

ds -F
Displays files using the ls command and the -F parameter, identifying file types with special characters.
|

nice
Sets the scheduling priority of the shell, or the specified command.
|

nohup
Runs the command and ignores hangup signals.
|

notify
Notifies the user when status of the specified job(s) change(s).
|

onintr
Sets the shell action when it receives an interrupt.
|

popd
Pops the directory stack and returns to the new top directory.
|

printenv
Displays the names and values of environment variables.
|

pushd
Exchanges the top two elements of the directory stack.
|

rehash
Recomputes the command hash table.
|

repeat
Executes the specified command a specified number of times.
|

sched
Displays or manages the scheduled event list.
|

set
Displays or manages shell variables.
|

setenv
Displays or manages environment variables.
|

settc
Sets the specified terminal capability feature to the specified value.
|

setty
Sets the TTY modes that are not allowed to change.
|

shift
Shifts the positional parameters one position.
|

source
Reads and executes commands from the specified file.
|

stop
Stops the specified job or process executing in background mode.
|

suspend
Immediately stops the shell process using the SIGSTOP signal.
|

telltc
Displays the values of all terminal capabilities.
|

time
Executes the specified command and displays a time summary.
|

umask
Sets the default permissions for new files and directories.
|

unalias
Removes all aliases that match the specified pattern.
|

uncomplete
Removes all completions that match the specified pattern.
|

unhash
Disables the use of the hash table to find executable programs.
|

ulimit
Removes the resource restriction on a resource.
|

unset
Removes all shell variables whose names match the specified pattern.
|

unsetenv
Removes all environment variables whose names match the specified pattern.
|

wait
Waits for all background jobs to complete.
|

where
Displays all known instances of the specified command, including aliases.
|

which
Displays the command the shell will execute after matching the specified pattern.
