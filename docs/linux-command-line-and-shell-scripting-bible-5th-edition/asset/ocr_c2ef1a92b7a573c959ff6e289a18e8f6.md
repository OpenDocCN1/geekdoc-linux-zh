# Structured commands

The ksh93 shell implements all of the structured commands you’re familiar with in the Bash shell:

+   if-then-else statements
+   for loops (including the C-style)
+   while loops
+   until loops
+   select statements
+   case statements

Each of these structured commands uses the same format as the Bourne shell (and thus the Bash shell), so I won’t cover these in detail. However, the ksh93 shell provides a simpler method for specifying mathematical operations in the if-then statement and the while/ until loops. The following sections take a closer look at these features.

# The if-then-else statement

The if statement uses the same format as for the Bash shell (see Chapter 12, “Using Structured Commands”). The basic format of the if statement is as follows:

```
if command then
    statements1
else
    statements2
fi
```

Just as with the Bash shell, the ksh93 shell if statement executes the command provided, and if it returns a zero exit status, it proceeds to execute the first set of statements. Otherwise, it executes the second set of statements.

The ksh93 shell also supports the elif statement, allowing you to chain if statements together:

```
if command1 then
    statements1
elif command2 then
    statements2
fi
```
