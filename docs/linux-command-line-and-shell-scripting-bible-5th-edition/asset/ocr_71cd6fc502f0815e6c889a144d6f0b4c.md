# FIGURE 18.2

Using the `msgbox` widget in the `dialog` command.

![](bbox=[0.34, 0.18, 0.72, 0.4])

Here’s an example of using the `yesno` widget:

```
$ dialog --title "Please answer" --yesno "Is this thing on?" 10 20
$ echo $?
1
$ 
```

This code produces the widget shown in Figure 18.3.

# FIGURE 18.3

Using the `yesno` widget in the `dialog` command.

![](bbox=[0.33, 0.61, 0.72, 0.83])

The exit status of the `dialog` command is set depending on which button the user selects. If the No button is clicked, the exit status is 1, and if the Yes button is clicked, the exit status is 0.
