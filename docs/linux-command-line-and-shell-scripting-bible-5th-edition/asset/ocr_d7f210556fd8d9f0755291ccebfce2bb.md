# Part III: Advanced Shell Scripting

By combining characters and special characters, you can define a pattern to match almost any type of data. You can then use `sed` or `gawk` to filter specific data from a larger data stream or to validate data received from data entry applications.

The next chapter digs deeper into using `sed` to perform advanced text manipulation. Lots of advanced features are available in `sed` that make it useful for handling large data streams and filtering out just what you need.
