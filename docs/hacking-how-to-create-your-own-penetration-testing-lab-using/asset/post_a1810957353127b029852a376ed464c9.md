
# Install Guest Additions

So your VM can use USB devices and other system tools, you need to install VBox Guest Additions into the Kali VM. (Make sure you have updated like above before starting this). There are no optional steps, so make sure you can do them successfully before moving on.

To check for Linux headers, you are looking for the current linux-headers that end in -kali-all-amd64. The version will change over time.

![](img/5481504809e843668406e46c502c72ab_39_0.png)

This will generate a list (if updated correctly) when you type in `apt-cache search header | grep -i linux`. Look for the one ending in -kali-all-amd64.

![](img/5481504809e843668406e46c502c72ab_39_1.png)

![](img/5481504809e843668406e46c502c72ab_39_2.png)

Install Linux headers. At the time of writing, it went to 4.5, but this does change, so type in the version you see when you do `apt-cache search header | grep -I linux` and install with **apt-get install linux-headers-4.5.0-kali-all-amd64**.

When that finishes (just in case), run **apt-get update && apt-get upgrade -y** (there might be nothing to update, but it is good to check), then in the terminal type **reboot**.

Log back into Kali, click Devices, click Insert Guest Additions CD image.

![](img/5481504809e843668406e46c502c72ab_40_0.png)

You should see a graphic of a CD and an option to run. When you click run, it will fail.

![](img/5481504809e843668406e46c502c72ab_40_1.png)

![](img/5481504809e843668406e46c502c72ab_41_0.png)

Just click OK.

Then go back to your terminal, navigate to the media you just mounted. Type in `cd /media/cdrom0`, then type `ls` so you can verify the file `VBoxLinuxAdditions.run`.

![](img/5481504809e843668406e46c502c72ab_41_1.png)

You want to copy this file to your desktop in order to get it to run. Type in `cp VBoxLinuxAdditions.run /root/Desktop` (you must remember this is case-sensitive).

![](img/5481504809e843668406e46c502c72ab_42_0.png)

![](img/5481504809e843668406e46c502c72ab_42_1.png)

![](img/5481504809e843668406e46c502c72ab_42_2.png)

Navigate back to root and type in `cd Desktop` (remember the caps), then `ls` to verify you see it. Now run the file by typing `./VBoxLinuxAdditions.run` (you can copy & paste).

![](img/5481504809e843668406e46c502c72ab_43_0.png)

Your Kali VM is ready to use, ENJOY!
