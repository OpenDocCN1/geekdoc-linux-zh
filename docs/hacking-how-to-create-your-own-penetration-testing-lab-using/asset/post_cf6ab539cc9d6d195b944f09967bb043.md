## Tweak your Kali VM

There are a few final steps and your Kali VM will be ready to go. Let's go to the “Terminal” and verify and change some settings.

![](img/5481504809e843668406e46c502c72ab_35_0.png)

To launch the terminal: press the icon under iceweasel, it looks like a command prompt, and when it opens you see this screen. This is where we are going to verify some settings.

Change the NetworkManager.conf file settings from “false” to “true”.

![](img/5481504809e843668406e46c502c72ab_36_0.png)

We want to get to the directory that contains the NetworkManager.conf file - from the prompt, change your directory with cd /etc/NetworkManager (case sensitive) your prompt should change to that directory.

![](img/5481504809e843668406e46c502c72ab_36_1.png)

Once there type in ls and confirm. You will see the “NetworkManager.conf file” (Seen here in white). We then want to edit this file. We are going to use nano (a text editor for this) In the same directory type in nano NetworkManager.conf and press enter (case sensitive)

![](img/5481504809e843668406e46c502c72ab_36_2.png)

Where it says “managed=false” change to “managed=true”. Then hit Ctrl+O and hit enter to save then Ctrl+X to exit the editor and return to the terminal and see if you can ping google.com

Check your source file for the correct repositories for Kali updates and upgrades to the current files can be found here <http://docs.kali.org/general-use/kali-linux-sources-list-repositories> You need all lines of this to match in your source file to avoid duplicates. I just cleaned mine out and pasted the ones in that link in. Let’s check or clean out the file

```
root@kali:~# cd /etc/apt
root@kali:/etc/apt# ls
apt.conf.d   preferences.d  sources.list-
listchanges.conf  sources.list  sources.list.d
root@kali:/etc/apt#
```

Navigate to cd /etc/apt directory and do an ls to check for the sources.list file again we are going to use nano to check out this file by typing nano sources.list

In this case I took the lines in the link and pasted them into the file and cleaned out the rest. **NOTE: *they do change it now and then*** so you need to check Kali docs at docs.kali.org

![](img/5481504809e843668406e46c502c72ab_37_0.png)

If they match you are good to go, if not cut and paste into your nano session again Ctrl+O and press enter to save and Ctrl+X to exit.

Time to get updates and/or upgrades. Once we have connectivity and repositories in the source file it’s time to check for updates.

![](img/5481504809e843668406e46c502c72ab_37_1.png)

Type in apt-get update && apt-get upgrade -y (the -y is answering yes to things that want to install without prompting you to answer for each one)

![](img/5481504809e843668406e46c502c72ab_38_0.png)

Once the updates start, be patient big files sometimes look like your system is locked and the first time you do this it can take a while. (You should consider doing this fairly often as there are often updates) When completed, you may see notices, the ones that begin with “W” are only warnings and not a problem. However, if you start seeing ones that begin with “E” and text, read them /check connectivity/ check the source file again. With the new rolling updates, you will also want to run **apt-get dist-upgrade** and this can take a while. Reboot Kali and do the **apt-get update && apt-get upgrade** -y again to be sure you have everything.
