The ioctl number encodes the major device number, the type of the ioctl, the command, and the type of the parameter. This ioctl number is usually created by a macro call (_IO, _IOR, _IOW or _IOW — depending on the type) in a header file. This header file should then be #include'd ioctl's by the programs which use ioctl (so they can generate the appropriate ioctl's) and the kernel module (so it can understand it). In the example below, the header file is chardev.h and the program which uses it is ioctl.c.

If you want to use ioctl in your kernel modules, it is best to receive an official ioctl assignment, if you accidentally get somebody else's ioctl's, or if they get yours, you'll know something is wrong. For more information, consult the kernel source tree at 'Documentation/ioctl-number.txt'.
