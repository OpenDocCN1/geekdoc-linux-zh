# 前言

无论你是终端用户、系统管理员，还是两者兼顾，这本书都通过逐步示例解释了如何充分利用 Fedora Core 或 Red Hat Enterprise Linux。在 28 章中，这本书将带你从安装 Linux 到理解其工作原理以及设置服务器。

## 读者

本书为各种读者设计。它不需要你有编程经验，但具备通用计算机经验会有帮助。这本书适用于：

- 使用 Linux 课程的学生。
- 想要安装和运行 Linux 的家庭用户。
- 在工作中使用 Linux 的人士。
- 需要 Linux 及其可用工具的系统管理员。
- 研究 Linux 系统的计算机科学学生。
- 需要了解 Linux 编程环境的程序员。
- 想要获得 Linux 基础的技术主管。

## 益处

《Red Hat Linux 实战指南：Fedora Core 和 Red Hat Enterprise Linux，第三版》让你对 Linux 的许多方面有广泛的了解，从安装 Red Hat Linux 到使用和定制。无论你的背景如何，这本书都能提供所需的知识。在未来的几年里，这本书将是宝贵的参考书。

## 重叠

如果你读过《Linux 命令、编辑器和 Shell 脚本》，你会发现这本书与你正在读的这一本之间存在重叠。第一章以及关于工具、文件系统、编程工具和正则表达式的章节在书中非常相似，关于 Bourne Again（`bash`）的章节也是如此。

书中包含但《Linux 命令、编辑器和 Shell 脚本》中没有的章节包括第 2 和 3 章（安装）、第 4 和 8 章（Red Hat Linux 和 GUI）、第 10 章（网络）、第四部分（系统管理）和第五部分（服务器）的所有章节，以及附录 C（安全）。

## 本书包含一张 Fedora Core 5 DVD

《Red Hat Linux 实战指南，第三版》包含了一个你可以使用它来安装或升级 Fedora Core 5 的 DVD。第 2 章帮助你准备安装 Fedora Core。第 3 章提供了从此 DVD 安装 Fedora Core 的逐步说明。

## 本版更新了什么？

《Red Hat® Linux 实用指南》第三版涵盖了 Fedora Core 5 和 Red Hat Linux 第 4 版本。自本书第二版以来，这些产品发生的所有大小变化都已整合到说明和示例中。以下列表列出了书中变化最大部分内容的细节。

- 访问控制列表（ACLs）：一种安全功能，比传统的 Linux 权限提供更细粒度的控制，决定哪些用户可以访问目录和文件。
- SELinux（安全增强型 Linux）：一种安全功能，通过强制安全策略来限制用户或程序可以的操作。
- `bash`（再次在第 7、9 和 28 章）：这些章节经过了重组和改写，提供了更清晰的解释和更好的示例，说明了 `bash` 如何从命令行到日常使用以及作为编写脚本的编程语言来工作。
- `yum`（46）：一个保持 Fedora Core 系统更新的程序。该工具从互联网上的仓库下载软件。它可以升级现有软件并安装新软件。你可以手动运行，也可以让它每晚自动运行。
- `yum`（48）：一个图形化软件包管理工具。`yum` 与 `yum` 类似，不同之处在于它是针对软件包组工作的。例如，你可以使用 `yum` 用一个命令下载并安装整个 KDE 桌面环境。
- `parted`（65）：一个用于报告和操作硬盘分区的命令行工具。

## GNU-Linux 连接

操作系统是负责调度任务、分配存储以及处理外设设备（如打印机、磁盘驱动器、屏幕和鼠标）接口的底层软件。操作系统有两个主要部分：内核和系统程序。内核为所有运行程序分配内存、磁盘空间和 CPU 周期。系统程序执行高级任务，通常在客户端/服务器关系中担任服务器。Linux 是 Torvalds 在 1991 年向世界介绍的内核名称，此以来许多人一直在致力于增强其安全性。

## Linux 的历史

本节介绍了 GNU 和 Linux 之间的一些背景知识。

## 回到 1983

Richard Stallman (`www.stallman.org`) 宣布了 GNU 项目，旨在创建一个包含内核和系统程序的操作系统，并提交了《GNU宣言》，开头如下：

> 措辞很粗率。我的意图是任何人都不需要为使用 GNU 系统而支付费用。但这些词汇并没有说明这一点，人们经常将其解读为 GNU 公司应该一直以极低或免费的价格分发。这从未是我的初衷；后来在宣言中提到了公司为了利润提供发行服务的可能性。

## 为什么我必须使用 GNU

到目前为止，斯尔曼（Stallman）继续说道：我认为黄金法则要求如果我喜欢一个程序，我必须将其分享给其他喜欢它的人。软件销售者想要分化用户并让他们听从，让每个用户同意不与他人分享。我拒绝以这种方式破坏与其他用户的团结。我无法在良心上允许签署保密协议或软件许可协议。多年来，我在人工智能实验室工作，以抵制这种倾向和其他不友好的行为，但最终他们还是做得太过分了：我无法留在一个违背我的意愿去做这些事情的机构中。

为了让我能够不失尊地继续使用计算机，我决定汇集足够的自由软件，以便我能够在不需要任何非软件的情况下生存。我已经从人工智能实验室辞职，以剥夺麻省理工学院任何阻止我使用 GNU 的法律理由。

## 下一个场景，1991

GNU 项目已朝着其目标迈进。除了内核之外，GNU 操作系统的目标已经完成。理查德·斯尔曼后来写道：

> 在 20 世纪 90 年代初，我们完成了除了内核以外的整个系统（我们也在开发一个内核，即 GNU Hurd,[3]，它运行在 Mach[4] 之上）。这个内核比我们预想的要困难得多，我们仍在努力完成它。[5]
>
> 很多情况一样，当林斯·托瓦尔斯（Linux Torvalds）完成内核后，他的朋友们寻找自由软件，结果发现无缘无故地，构建类 UNIX 系统所需的一切都已经就绪了。
>
> 我们发现的 GNU 系统并非偶然。可用的自由软件[6] 之所以能构成一个完整的系统，是因为 GNU 项目自 1984 年以来一直致力于开发这样一个系统。《GNU 宣言》设定了开发一个名为 GNU 的自由类 Unix 系统的目标。《GNU 项目的最初公告》也概述了 GNU 系统的的一些原始计划。当 Linux 出现时，[GNU] 系统已几乎完成。[7]

## 代码是自由的

自由的传统可以追溯到 UNIX 以名义成本发布给大学的日子，这促进了它的移植性和成功。当 UNIX 商业化，制造商将源代码视为专利时，它实际上变得不可用了，这种传统也就消失了。UNIX 商业版本的另一个问题与其复杂性。随着每个制造商针对特定架构对 UNIX 进行调整，它变得越来越不利于移植，并且对于教学和实验来说太笨了。

## MINIX

两个教授为了教学目的创建了他们精简版的 UNIX 仿制品：道格·康纳（Doug Comer）创建了 XINU (`www.cs.purdue.edu/research/xinu.html`)，安德鲁·丹宁鲍（Andrew Tanenbaum）创建了 MINIX (`www.cs.vu.nl/~ast/minix.html`)。林斯·托瓦尔斯（Linus Torvalds）创建 Linux 是为了应对 MINIX 的缺点。每当在简单和效率之间做出选择时，丹宁鲍都会选择简单（以便使用 MINIX 教学），这意味着系统缺乏许多人们想要的功能。Linux 则方向相反。

你可以通过互联网免费获取 Linux（第 35 页）。你也可以通过购买较高价格软件包中的代码获取 GNU 软件基金会 (`www.fsf.org`)，你还可以购买 Linux 的商业版本（称为发行版），例如红帽 Linux，它们包含了安装脚本、软件和源码。

## GPL

Linux 和 GNU 软件根据 GNU 通用公共许可证 (GPL, `www.gnu.org/licenses/gpl.html`) 的条款分发。GPL 规定你有权根据协议复制、修改和分发代码。当你重新分发代码时，你必须与代码一起分发相同的许可证，使代码和许可证不可分割。如果你从一个受 GPL 保护的会计程序获取了一些代码，然后修改这些代码并重新分发该程序的可执行版本，你也必须分发修改后的源码和 GPL 协议。由于这种安排与普通的版权作品相反（它赋予了权利而不是限制权利），因此它被称为“左向许可”（copyleft）。（本段不是对 GPL 的法律解释；在这里仅仅是为了让你对它的运作方式有一个大致的了解。当你想要使用它时，请参考 GPL 本身。）

## 玩得！

Linux 的两个词是“Have Fun!（玩得开心！）”。这两个词出现在提示符和文档中。UNIX Linux 文化浸淫在幽默中，这种幽默贯穿整个系统。例如，`less` 用名为 `less` 的改进工具替换了 UNIX 的分页命名系统。查看 PostScript 文档的工具命名为 `ghostscript`，它是 `vi` 编辑器的几个替代品之一。带有英特尔处理器的机器外部贴有“Intel Inside”标志，而一些 Linux 机器贴着“Linux Inside”标志。托瓦尔斯本人一直穿着一件印有“Linux Inside”字样的 T 恤。

## 内核

GNU “操作系统”运行在 FreeBSD (`www.freeBSD.org`) 和 NetBSD (`www.netbsd.org`) 内核之上，具有完全的 Linux 二进制兼容性；运行在 Hurd 预览版和 Darwin (`developer.apple.com/opensource`) 之上则没有任何兼容性。

## Linux 有什么之处？

多年来，Linux 已经成为一种强大且创新的力量。它的流行正在超过其先驱者。尽管它在许多方面模仿 UNIX，但该操作系统在几个方面与 UNIX 不同：内核独立于 BSD 和 System V 实现，Linux 的持续开发是通过全球范围内许多人的共同努力完成的，而且 Linux 让商务和个人用户触手可及。通过互联网，今天的熟练程序员向操作系统提交添加和改进，Linux 托瓦尔斯、GNU 或其他软件。

## 应用

Linux 提供了丰富的应用程序，既有免费的商业的，以及各种工具：图形、文字处理、网络、安全、管理、Web 服务器等许多。大型公司最近看到了支持 Linux 的益处，现在有了全职程序员，其工作是设计和编写内核、GNU、KDE 或运行在 Linux 上的软件。例如，IBM (`www.ibm.com/linux`) 是 Linux 的主要支持者。Linux 越来越符合 POSIX 标准，某些发行版符合该标准。（更多信息请参阅标准页。）这些发展意味着 Linux 正在变得主流，并作为其他流行操作系统的吸引替代方案受到尊重。

## 外设

Linux 吸引用户的另一个方面是支持的外设范围极其广泛，以及对新外设的支持速度。Linux 通常支持外设接口卡，特别是专利显卡在支持方面滞后，因为制造商没有及时或根本不发布驱动的规范或源码。

## 软件

对用户来说，重要的是可用软件不仅有源码（需要编译），还有易于安装和即插即用的预编译二进制文件。这些包括自由软件。例如，`Netscape` 从开始就可以在 Linux 上可用，并在商业供应商提供之前就包含了 Java 支持。现在它的兄弟软件 `Mozilla/Thunder-bird/Firefox` 也是一个可行的浏览器、邮件客户端和新闻阅读器，并执行许多其他功能。

## 平台

Linux 不仅用于基于 Intel 的平台：它已经移植并运行在 Power PC 上，包括 Apple 计算机 (`ppclinux`)、康睿尔（原数字设备公司）的 Alpha 机器、MIPS 机器、摩托罗拉 68K 机器、各种 64 位系统以及 IBM 的 S/390。Linux 也不仅用于单处理器机器：从 2.0 版本开始，它就可以多处理器系统 (SMP) 上运行。它包含一个 O(1) 调度器，这极大地提高了 SMP 系统的可扩展性。

## 模拟器

Linux 支持名为模拟器的程序，这些程序运行为其他操作系统设计的代码。通过使用模拟器，你可以在 Linux 下运行某些 DOS、Windows 和 Macintosh 程序。`Wine` (`[www.winehg.com](http://www.winehg.com)`) 是基于 X Window 系统和 UNIX/Linux 的 Windows API 开源实现；`QEMU` (`[fabrice.bellard.free.fr/qemu](http://fabrice.bellard.free.fr/qemu)`) 是一个仅限 CPU 的模拟器，可以在非 x86 Linux 系统上执行 x86 Linux 二进制文件。

## Xen

Xen 创建于剑桥大学，现在由开源社区开发，是一种开源虚拟机监控器 (VMM)。VMM 允许多个虚拟机 (VM，每个运行一个操作系统实例）运行在单台机器上。Xen 引入了虚拟机，使得其中一个崩溃不会影响其他任何一个。此外，与原生运行每个操作系统相比，Xen 引入了极微的性能开销。

通过虚拟机，你可以在单台机器上尝试操作系统和应用程序的最新版本，而无需担心基础（稳定）系统。你可以在单台机器上设置并测试系统网络。Xen 提供了一个沙箱区域（系统区域），你可以在其中工作，而不必担心工作的结果或需要清理的需求。

Fedora Core 5 包含了 Xen。本书不包含 Xen 的安装或使用。请参阅 `[fedoraproject.org/wiki/FedoraXenQuickstartFC5](http://fedoraproject.org/wiki/FedoraXenQuickstartFC5)` 获取安装说明。

有关 Xen 的更多信息，请参考 `[wiki.xensource.com/xenwiki](http://wiki.xensource.com/xenwiki)` 和位于 `[www.cl.cam.ac.uk/Research/SRG/nets/xen](http://www.cl.cam.ac.uk/Research/SRG/nets/xen)` 的 Xen 主页。

## 为什么 Linux 受硬件公司和开发者欢迎

计算机行业的两个趋势为 UNIX 和 Linux 的流行奠定了基础。首先，硬件技术的进步对一种能够利用可用硬件能力的操作系统产生了需求。在 20 世纪 70 年代中期，微机开始在许多应用中挑战大型主机，微机可以以更廉的价格执行相同的功能。最近，64 位处理器芯片、充足且廉价的内存以及价格更低的磁盘存储，使得硬件公司能够在台式电脑上安装多用户操作系统。

## 专有操作系统

其次，随着硬件成本的不断下降，硬件制造商已无法负担开发和支持专有操作系统的费用。专有操作系统由硬件制造商编写并拥有（例如，DEC/Compa 拥有 VMS）。今天的制造商需要一种可以轻松适配到其机器的通用操作系统。

## 通用操作系统

通用操作系统是在制造硬件的公司之外编写的，并出售（UNIX、Windows）或赠送（Linux）给制造商。Linux 是一种通用操作系统，因为它运行在不同制造商生产的不同类型的硬件上。当然，如果制造商可以支付开发费用并避免单位成本（他们每卖出一份 Windows 拷贝都要向微软付费），制造商的处境会好得多。反过来，软件开发者需要保持其产品价格；他们无法负担将产品转换为在许多不同的专有操作系统运行。与硬件制造商一样，软件开发者也需要通用操作系统。

尽管 UNIX 系统曾作为通用操作系统满足了硬件公司和研究人员的需求，但随着时间的推移，由于每个制造商增加对特殊功能的支持并引入新的软件库和实用程序，它变得越来越专有。

Linux 的出现是为了同时满足这两种需求。它是一种利用可用硬件能力的通用操作系统。

## Linux 是可移植的

可移植操作系统是指可以在许多机器上运行的操作系统。Linux 操作系统的 95% 以上是用 C 语言编写的，而 C 是可移植的，因为它是用高级的、与机器无关的语言编写的。（C 编译器是用 C 语言编写的）

由于具有可移植性，它可以适配（移植）到不同的机器并满足特殊需求。例如，Linux 被用于嵌入式计算机，如手机、PDA 以及许多电视顶部的机盒中的计算机。文件结构充分利用了大型硬盘。同样重要的是，Linux 最初被设计为一种多用户操作系统，而不是在事后才修改为服务多个用户。在许多用户之间共享计算机能力并赋予他们共享数据和程序的能力是该系统的核心特性。

由于具有适应性并利用了可用硬件，Linux 运行在许多不同的基于微处理器的系统以及主机上。微处理器硬件的普及驱动了 Linux 的发展；这些计算机正变得越来越快。随着 C 语言的出现，程序员不再需要求助于汇编语言来获得运行良好的代码（尽管汇编器生成的代码比高级语言更高效）。这让喜欢拥有一致环境的系统管理员受益。

## 标准

来自整个行业公司的个人共同开发了 POSIX（可环境可移植操作系统接口）标准，该标准很大程度上基于 UNIX V 定义 (SVID)。这些努力是由美国政府推动的，它需要一个标准的计算环境。现在这些标准获得了认可，软件开发者能够在所有标准的 UNIX 版本上开发应用程序。

## C 语言语言

Ken Thompson 在 1969 年用 PDP-7 汇编语言编写了 UNIX 系统。汇编语言是依赖机器的：用汇编语言编写的程序只能在一个机器上，或者最多在一个机器族上。原始的 UNIX 系统无法轻松移植到其他机器。

为了让 UNIX 可移植，Thompson 从 BCPL 语言开发了 B 语言，这是一种机器无关的语言。Dennis Ritchie 通过 B 开发了 C，并与 Thompson 在 1973 年用 C 重写了 UNIX。修订后的操作系统可以更容易移植到其他机器上运行。

该开发标志着 C 语言的开始。它的起源揭示了它成为如此强大工具的许多原因。C 可用于编写机器无关的程序。设计程序可移植的程序员可以轻松迁移到任何带有 C 的计算机。C 也被设计为编译成高效的代码。

C 是一种很好的系统语言。你可以用 C 编写编译器或操作系统。它是高度结构化的，但不是一种高级语言。C 允许程序员操作位和字节，这在编写操作系统时是必要的。它还具有高级结构，允许高效的模块化编程。
