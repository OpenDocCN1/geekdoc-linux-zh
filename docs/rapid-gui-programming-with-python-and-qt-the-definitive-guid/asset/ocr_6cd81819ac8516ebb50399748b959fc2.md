Table 12.2 Selected QGraphicsltem Methods #1 | Syntax | Description |
|---|---|
| g.boundingRect() | Returns QGraphicsltem g's bounding QRectf; subclasses should reimplement this |
| g.collidesWith(Path(pp)) | Returns True if QGraphicsltem g collides with QPainter-Path pp |
| g.collidingItems() | Returns a (possibly empty) list of the QGraphicsItems that QGraphicsltem g collides with |
| g.contains(pt) | Returns True if QGraphicsltem g contains QPointF pt |
| g.isObscured() | Returns True if QGraphicsltem g is obscured by its colliding items, providing their z values are larger |
| g.isSelected() | Returns True if QGraphicsltem g is selected |
| g.itemChange(c, v) | Does nothing; subclasses can reimplement this method to detect changes—for example, in selected status or position. Do not call QGraphicsltem. setPos() directly or indirectly in this method. |
| g.moveBy(dx, dy) | Moves QGraphicsltem g by float dx horizontally and by float dy vertically in scene coordinates |
| g.paint(p, o) | Does nothing; subclasses should reimplement this to draw themselves on QPainter p and with the option QStyleOptionQGraphicsltem o; painting is done in local logical coordinates, by default centered at (0,0) |
| g.pos() | Returns QGraphicsltem g's position as a QPointF. If g is a child of another QGraphicsltem, the point is in terms of the parent item's local logical coordinates; otherwise, it is in terms of scene coordinates. |
| g.resetMatrix() | Resets QGraphicsltem g's transformation matrix to the identity matrix; for PyQt 4.3, use resetTrans-form() instead |
| g.rotate(a) | Rotates QGraphicsltem g by float a° |
| g.scale(x, y) | Scales QGraphicsltem g horizontally by float x and vertically by float y; 1.0 is unscaled, 0.5 is half size, and 3.0 is three times the size |
| g.scene() | Returns QGraphicsltem g's QGrapicsScene, or None if it has not been added to a scene |
| g.sceneBounding-Rect() | Returns QGraphicsltem g's bounding QRectf in scene coordinates—this accounts for transformations |
| g.setCursor(c) | Sets g's cursor to c, a QCursor or a Qt. CursorShape |
| g.setEnabled(b) | Sets g to be enabled or disabled depending on b |
| g.setFocus() | Gives the keyboard focus to QGraphicsltem g |
| g.setFlag(f) | Sets the given QGrapicsltem. ItemFlag f on g |
