```
<file alias="editmenu.html">help/editmenu_fr.html</file>
<file alias="filemenu.html">help/filemenu_fr.html</file>
<file alias="index.html">help/index_fr.html</file>
</resource>
```

A resource file can have any number of <resources> tags, although up until now we have only ever used one. If the current locale is “en_US”, the main help file will be ./index.html; but if the locale is “fr_CA” or “fr” or any other “fr_*”, when we seek to access file :/index.html in code, the file we will actually get is :/index_fr.html.
