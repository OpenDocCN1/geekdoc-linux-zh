Now we iterate over the movie data, writing each movie’s data to the data stream. The data’s format is illustrated in Figure 8.3. The QDataStream class overloads the << operator for many PyQt classes, including, for example, QString, QDate, and QImage, so we must use a C++-like streaming syntax to write our data. The << operator writes its right operand to the data stream as its left operand. It can be applied repeatedly to the same stream, since it returns the stream it is applied to, but for integers, we must use the writeIntn() and writeUIntn() methods.
