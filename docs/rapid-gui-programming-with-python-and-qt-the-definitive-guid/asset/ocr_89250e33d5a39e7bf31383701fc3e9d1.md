# **Table 3.3** Selected Collection Special Methods

| Method | Syntax | Description |
| :--- | :--- | :--- |
| `__contains__(self, x)` | `x in y` | Returns True if x is in sequence y or if x is a key in dict y. This method is also used for not in. |
| `__len__ (self)` | `len(y)` | Returns the number of items in y |
| `__getitem__ (self, k)` | `y[k]` | Returns the k-th item of sequence y or the value for key k in dict y |
| `__setitem__ (self, k, v)` | `y[k] = v` | Sets the k-th item of sequence y or the value for key k in dict y, to v |
| `__delitem__ (self, k)` | `del y[k]` | Deletes the k-th item of sequence y or the item with key k in dict y |
| `__iter__(self)` | `for x in y: pass` | Returns an iterator into collection y |
