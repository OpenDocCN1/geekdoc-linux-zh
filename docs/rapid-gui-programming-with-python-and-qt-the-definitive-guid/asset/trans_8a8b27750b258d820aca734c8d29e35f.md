> *来自真实应用的真实世界代码*

开源技术已彻底改变了计算机世界。许多大型项目已在全球投入生产使用，例如 Apache、MySQL 和 Postgres，程序员们使用包括 Perl、Python 和 PHP 在内的多种语言编写应用程序。这些技术被应用于许多不同的系统，范围从专有系统、Linux 系统、传统 UNIX 系统到大型机。

**普雷西斯·霍尔开源软件开发系列**旨在为您带来这些开源技术的精髓。您不仅将学习如何在项目中使用它们，还将*从它们中学习*。通过查看来自真实应用的真实代码，您将学习全球开源开发者的最佳实践。
