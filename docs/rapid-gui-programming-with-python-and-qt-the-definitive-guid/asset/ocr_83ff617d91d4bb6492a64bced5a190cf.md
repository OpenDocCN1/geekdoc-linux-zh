If you want to run the examples that are shown in the book or you want to see the model answers to the exercises, you can unzip the pyqtbook.zip file available from http://www.qt-academy.org/pyqtbook.html.

Now that all the pieces are at hand, we can perform the installation. The order of installation is important, and is different from the downloading order. (You needed to download PyQt first, to make sure you got the right versions of Python and Qt; but for installing you must start with the C++ compiler, and finish by installing PyQt.) We will assume that the versions are those mentioned earlier, but obviously use whichever versions you downloaded and adjust accordingly.
