Although it is possible to drag layouts onto the form and then drag widgets
onto the layouts, the best practice is to drag all the widgets and spacers onto the
form, and then repeatedly select some widgets and spacers and apply layouts
to them. The one situation where it makes sense to add widgets to an existing
layout is if we want to drag widgets into gaps—for example, into empty cells in
a grid layout.
