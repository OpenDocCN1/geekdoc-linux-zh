system that matches the pixels in the widget's area, and a logical coordinate system. By default, the logical coordinate system is set to exactly match the physical coordinate system.

In fact, the physical coordinates are not necessarily pixels since they depend on the underlying paint device. This can be a $Q\text{GLPixelBuffer}$ (for 2D and 3D painting), a QImage, a QPicture, a QPixmap, a $\text{QPainter}$ (in which case the coordinates are points, $\frac{1}{96}"$), a $\text{QSvgGenerator}$ (introduced with Qt 4.3), or a QWidget.

In PyQt terminology the physical coordinate system is called the “viewport”, and confusingly, the logical coordinate system is called the “window”.

![](bbox=[0.2, 0.34, 0.85, 0.48])

*Figure 11.4 The viewport and window coordinate systems*

In Figure 11.4, we have a physical widget size of $800 \times 600$. By calling setWindow(−60, −60, 120, 120) we can create a “window” with a top-left coordinate of $(−60, −60)$, a width of 120, a height of 120, and centered at point $(0, 0)$. The window's coordinate system is a logical coordinate system that $\text{QPainter}$ automatically maps to the underlying physical device. After the $\text{setWindow}()$ call, all our painting takes place using the logical (window) coordinate system.

In this case, the widget is rectangular, but our window has the same width and height. This means that the items we paint will be stretched out horizontally, since coordinates in the y-axis will be scaled by $\text{QPainter}$ in the ratio 120:600 (1.5), whereas those in the x-axis will be scaled in the ratio 120:800 (1:$\frac{5}{6}$).

For most widgets, a rectangular region works perfectly well, but in some cases—if for example, we really want our logical window to be square—we can change the viewport so that we operate on only a proportion of the widget's area.

```
side = min(self.width(), self.height())

painter.setViewport(((self.width() - side) / 2,
self.height() - side) / 2, side, side)
```

This code, executed inside a widget's paintEvent(), changes the widget's viewport to be the largest centered square region that will fit. In the example earlier, this will produce a viewport of $600 \times 600$ pixels with no top or bottom margins, but with a 100-pixel margin on the left and on the right. The window will now be an exact square, and the aspect ratio of anything we paint in it will be preserved.
