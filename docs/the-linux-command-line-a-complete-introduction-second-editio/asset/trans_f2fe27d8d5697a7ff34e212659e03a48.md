

## 直接将数据移入移出设备

我们通常认为计算机上的数据是按文件组织的，但也可以将数据视为“原始”形式。例如，如果我们查看一个磁盘驱动器，会发现它由大量数据“块”组成，操作系统将其视为目录和文件。然而，如果我们将磁盘驱动器视为简单的大量数据块集合，就能执行有用的任务，例如克隆设备。

`dd` 程序执行此任务。它将数据块从一个位置复制到另一个位置。它使用独特的语法（出于历史原因），通常这样使用：

```
dd if=input_file of=output_file [bs=block_size [count=blocks]]
```

### 警告

> `dd` 命令非常强大。尽管其名称源自“数据定义”，但它有时被称为“destroy disk”（销毁磁盘），因为用户经常输错 `if` 或 `of` 指定。按下回车键之前，务必仔细核对输入和输出指定！

假设我们有两支相同大小的 USB 闪存盘，并且想将第一块盘完全复制到第二块盘。如果我们将两块盘都连接到计算机，并且它们分别被分配为设备 `/dev/sdb` 和 `/dev/sdc`，我们就可以用以下命令将第一块盘上的所有内容复制到第二块盘：

```
dd if=/dev/sdb of=/dev/sdc
```

或者，如果只有第一块设备连接到计算机，我们可以将它的内容复制到一个普通文件中以便稍后恢复或复制。

```
dd if=/dev/sdb of=flash_drive.img
```

## 创建 CD-ROM 映像

刻录可记录 CD-ROM（CD-R 或 CD-RW）包括两个步骤。

1. 构建一个 ISO 映像文件，该文件是 CD-ROM 的精确文件系统映像
2. 将映像文件写入 CD-ROM 介质

### 创建 CD-ROM 的映像拷贝

如果我们想为现有的 CD-ROM 制作 ISO 映像，可以使用 `dd` 读取 CD-ROM 上的所有数据块并将其复制到本地文件。假设我们有一张 Ubuntu CD，并且想制作一个稍后可用于制作更多拷贝的 ISO 文件。插入光盘并确定其设备名称（我们假设为 `/dev/cdrom`）后，我们可以这样制作 ISO 文件：

```
dd if=/dev/cdrom of=ubuntu.iso
```

此技术对数据 DVD 也适用，但对音频 CD 不适用，因为音频 CD 不使用文件系统存储。对于音频 CD，请查看 `cdrdao` 命令。

### 从文件集合创建映像

要创建包含目录内容的 ISO 映像文件，我们使用 `genisoimage` 程序。为此，我们首先创建一个包含要包含在映像中的所有文件的目录，然后执行 `genisoimage` 命令来创建映像文件。例如，如果我们创建了一个名为 `~/cd-rom-files` 的目录并在其中填入了 CD-ROM 的文件，我们就可以用以下命令创建名为 `cd-rom.iso` 的映像文件：

```
genisoimage -o cd-rom.iso -R -J ~/cd-rom-files
```

`-R` 选项为 Rock Ridge 扩展添加元数据，这允许使用长文件名和 POSIX 风格的文件权限。同样，`-J` 选项启用 Joliet 扩展，这允许 Windows 使用长文件名。

### 换个名字也是程序……

如果你查看创建和刻录光学介质如 CD-ROM 和 DVD 的在线教程，你会经常遇到两个名为 `mkisofs` 和 `cdrecord` 的程序。这些程序是 Jörg Schilling 编写的名为 `cdrtools` 的流行软件包的一部分。2006 年夏季，Schilling 先生对 `cdrtools` 软件包的一部分进行了许可变更，在许多 Linux 社区人士看来，这与 GNU GPL 存在许可不兼容。因此，`cdrtools` 项目的一个分支被启动，现在其中包含名为 `wodim` 和 `genisoimage` 的 `cdrecord` 和 `mkisofs` 的替代程序。

### 写入 CD-ROM 映像

在我们有了映像文件后，就可以将其刻录到光学介质上。我们将在下面各节中讨论的大多数命令都可应用于可记录 CD-ROM 和 DVD 介质。

### 直接挂载 ISO 映像

我们可以使用一个技巧在 ISO 映像仍在硬盘上时将其挂载，并将其视为已在光学介质上。通过向 `mount` 添加 `-o loop` 选项（以及所需的 `-t iso9660` 文件系统类型），我们可以将映像文件作为设备挂载并将其附加到文件系统树中。

```
mkdir /mnt/iso_image
mount -t iso9660 -o loop image.iso /mnt/iso_image
```
