
将当前目录更改为DIR。默认的DIR是`HOME` shell变量的值。

变量CDPATH定义了包含DIR的目录的搜索路径。CDPATH中不同的目录名用冒号（`:`）分隔。空目录名等同于当前目录。如果DIR以斜杠（`/`）开头，则不使用CDPATH。

如果未找到该目录，并且shell选项`cdable_vars`已设置，则该词被认为是变量名。如果该变量有值，则其值用作DIR。

**选项：**

- `-L` 强制跟随符号链接：在处理`..`实例之后，解析DIR中的符号链接
- `-P` 使用物理目录结构而不跟随符号链接：在处理`..`实例之前，解析DIR中的符号链接
- `-e` 如果提供了`-P`选项，并且当前工作目录无法成功确定，则退出并返回非零状态
- `-@` 在支持的系统上，将具有扩展属性的文件呈现为包含文件属性的目录

默认行为是跟随符号链接，就像指定了`-L`一样。`..`的处理方式是移除紧邻的前一个路径名组件，直到遇到斜杠或DIR的开头。

**退出状态：**

如果目录已更改，并且在使用`-P`时`$PWD`成功设置，则返回0；否则返回非零。

> **关于符号的说明：**当方括号出现在命令语法描述中时，它们表示可选项。竖线字符表示互斥项。以上面的cd命令为例：

```
cd [-L|[-P[-e]]] [dir]
```

这种表示法说明cd命令后面可以可选地跟一个`-L`或一个`-P`，此外，如果指定了`-P`选项，则还可以包含`-e`选项，后面再跟可选的参数dir。

虽然cd命令的help输出简洁准确，但它绝不是教程式的，而且我们可以看到，它似乎还提到了很多我们还没讨论过的东西！别担心。我们很快就会讲到。

## --help—显示用法信息

许多可执行程序支持`--help`选项，它会显示命令支持的语法和选项的描述。例如：

```
[me@linuxbox ~]$ mkdir --help
Usage: mkdir [OPTION] DIRECTORY...
Create the DIRECTORY(ies), if they do not already exist.

    -Z, --context=CONTEXT (SELinux) set security context to CONTEXT
Mandatory arguments to long options are mandatory for short options too.
    -m, --mode=MODE      set file mode (as in chmod), not a=rwx - umask
    -p, --parents        no error if existing, make parent directories as needed
    -v, --verbose        print a message for each created directory
        --help           display this help and exit
        --version        output version information and exit
Report bugs to <bug-coreutils@gnu.org>.
```

有些程序不支持`--help`选项，但你还是可以试试。通常它会产生一条错误消息，而这条消息会揭示相同的用法信息。

## man—显示程序的手册页

大多数用于命令行操作的可执行程序都提供一份正式的文档，称为手册或man页面。一个名为man的特殊分页程序用于查看它们。用法如下：

```
ioctl
sfdisk (8)      - partition table manipulator for Linux
sgdisk (8)      - Command-line GUID partition table (GPT)
manipulator fo..
```

输出中每一行的第一个字段是man页面的名称，第二个字段显示分区/章节。注意，带`-k`选项的man命令执行的功能与apropos相同。

## whatis—显示man页面的一行描述

whatis程序显示与指定关键字匹配的man页面的名称和一行描述。

```
[me@linuxbox ~]$ whatis ls
ls              (1)  - list directory contents
```

## 所有man页面中最“残酷”的一页

正如我们所见，Linux和其他类Unix系统附带的man页面是作为参考文档而非教程使用的。许多man页面很难读，但我认为最难的奖项非bash的man页面莫属。在我为这本书做研究时，我仔细审阅了bash的man页面，以确保我涵盖了它的大部分主题。打印出来有80多页，内容极其密集，其结构对新用户来说完全没有章法。

另一方面，它非常准确、简洁，而且极其完整。所以，如果你有胆量，就去看看吧，并期待有一天你能读懂它，而且一切都能说得通。

## info—显示程序的info条目

GNU项目为它们的程序提供了一种替代man页面的方式，称为info。info手册通过一个阅读器程序来显示。
