

| Directory | Comments |
|---|---|
| / | 根目录，一切由此开始。 |
| /bin | 包含系统启动和运行所必需的二进制文件（程序）。 |
| /boot | 包含 Linux 内核、初始 RAM 磁盘镜像（启动时所需的驱动程序）以及引导加载程序。值得关注的文件包括 /boot/grub/grub.conf 或 menu.lst，用于配置引导加载程序，以及 /boot/vmlinuz（或类似文件），即 Linux 内核。 |
| /dev | 这是一个特殊目录，包含设备节点。“一切皆文件”也适用于设备。这里是内核维护其所理解的所有设备列表的地方。 |
| /etc | /etc 目录包含所有系统范围的配置文件。它还包含在启动时启动各个系统服务的 shell 脚本集合。此目录中的所有内容都应为可读文本。虽然 /etc 中的所有内容都很有趣，但以下是一些经典之作：/etc/crontab，定义自动化作业运行时间的文件；/etc/fstab，存储设备及其关联挂载点的表；以及 /etc/passwd，用户账户列表。 |
| /home | 在正常配置中，每个用户在 /home 中都有一个目录。普通用户只能在其主目录中写入文件。这种限制可以保护系统免受用户误操作的影响。 |
| /lib | 包含核心系统程序使用的共享库文件。这些类似于 Windows 中的动态链接库（DLL）。 |
| */lost+found* | 每个使用 Linux 文件系统（如 ext3）格式化的分区或设备都会有此目录。它用于在文件系统损坏事件部分恢复时使用。除非系统发生了严重问题，否则此目录将保持为空。 |
| */media* | 在现代 Linux 系统上，*/media* 目录将包含可移动媒体的挂载点，例如 USB 驱动器、CD-ROM 等，这些媒体在插入时会自动挂载。 |
| */mnt* | 在旧版 Linux 系统上，*/mnt* 目录包含手动挂载的可移动设备的挂载点。 |
| */opt* | */opt* 目录用于安装“可选”软件。这主要用于存放可能安装在系统上的商业软件产品。 |
| */proc* | */proc* 目录很特殊。它不是以存储在硬盘上的文件为意义的真正文件系统，而是一个由 Linux 内核维护的虚拟文件系统。其包含的“文件”是窥视内核本身的窗口。这些文件可读，会让你了解内核如何看待你的计算机。 |
| */root* | 这是 root 账户的主目录。 |
| */sbin* | 此目录包含“系统”二进制文件。这些是执行关键系统任务的程序，通常保留给超级用户。 |
| */tmp* | */tmp* 目录用于存储各种程序创建的临时、短暂文件。某些配置会在系统每次重启时清空此目录。 |
| /usr | /usr 目录树可能是 Linux 系统上最大的目录树。它包含普通用户使用的所有程序和支持文件。 |
| /usr/bin | /usr/bin 包含由你的 Linux 发行版安装的可执行程序。这个目录包含数千个程序是很常见的。 |
| /usr/lib | /usr/bin 中程序的共享库。 |
| /usr/local | /usr/local 树是安装那些未包含在发行版中但 intended 用于系统范围使用的程序的位置。从源代码编译的程序通常安装在 /usr/local/bin 中。在新安装的 Linux 系统上，此树存在，但直到系统管理员放入内容之前将保持为空。 |
| /usr/sbin | 包含更多系统管理程序。 |
| /usr/share | /usr/share 包含 /usr/bin 中程序使用的所有共享数据。这包括默认配置文件、图标、屏幕背景、声音文件等。 |
| /usr/share/doc | 系统上安装的大多数软件包都会包含某种文档。在 /usr/share/doc 中，我们会找到按软件包组织的文档文件。 |
| /var | 除了 /tmp 和 /home，我们迄今为止查看的目录相对静态；即其内容不会改变。/var 目录树是存储可能发生变化的数据的位置。各种数据库、spool 文件、用户邮件等都位于此处。 |
| /var/log | /var/log 包含日志文件，即各种系统活动的记录。这些很重要，应不时进行监控。最有用的有 /var/log/messages 和 /var/log/syslog。请注意，出于安全原因，在某些系统上，你必须为超级用户才能查看日志文件。 |
