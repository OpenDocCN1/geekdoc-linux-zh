postgres@jesse-desktop:/home/dspace$ exit

After you exit you will return to Dspace user mode.

# Here create Database dspace as user Dspace.

```
dspace@jesse-desktop:~$ createdb -U dspace -E UNICODE dspace
```

now make some changes in postgres configuration file.
Open the configuration file with this command.

```
dspace@jesse-desktop:~$ sudo gedit /etc/postgresql/8.4/main/pg_hba.conf
```

(add this line **host dspace dspace 127.0.0.1 255.255.255.255 md5**)

In case of postgresQL latest versions
Replace “ident sameuser” by “trust”
