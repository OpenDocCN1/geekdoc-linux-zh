Then you are just one step away from the success, my friend.

We just need to copy the webapps files, which will provide us the web interface of dspace. Those files need to be copied in tomcat directory.

Give these commands one by one to copy dspace JSPUI, XMLUI and OAI files to tomcat webapps folder.

```
dspace@jesse-desktop:~$ cp -r /home/dspace/webapps/jspui /home/dspace/apache-tomcat-6.0.18/webapps/
```

```
dspace@jesse-desktop:~$ cp -r /home/dspace/webapps/xmlui /home/dspace/apache-tomcat-6.0.18/webapps/
```

```
dspace@jesse-desktop:~$ cp -r /home/dspace/webapps/oai /home/dspace/apache-tomcat-6.0.18/webapps/
```
