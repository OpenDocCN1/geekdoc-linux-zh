It is almost done now. We just need to compile and create webapps folder for Dspace directory.

Open the terminal window and give the following command for **running the maven**

```
sh
dspace@jesse-desktop:~$ cd home/dspace/dspace-1.5.2-src-release/dspace
dspace@jesse-desktop:~/dspace-1.5.2-src-release/dspace$ mvn package
```

(this may take some time because this command will download and install all the required maven packages.)

After waiting so long, it should show you this screen, and it will make a target folder in your home/dspace/dspace-1.5.2-src-release/dspace directory.

![](img/81cd45265ffdc1888ff0c46976f30c4c_17_0.png)

it means, Maven package has been compiled successfully. Now time to make webapps in dspace. First move to Dspace target folder and then dspace build.dir, which was made while compilation of mvn package.

Go to terminal window and run this command to move to dspace build directory in target folder.

```
sh
dspace@jesse-desktop:~$ cd /home/dspace/dspace-1.5.2-src-release/dspace/target/dspace-1.5.2-build.dir/
```

now run **ANT FRESH_INSTALL** give the following command in terminal window.

```
sh
dspace@jesse-desktop:~/dspace-1.5.2-src-release/dspace/target/dspace-1.5.2-build.dir$ ant fresh_install
```

If it shows Build Successful like this .

![](img/81cd45265ffdc1888ff0c46976f30c4c_18_0.png)

Then you are just one step away from the success, my friend.

We just need to copy the webapps files, which will provide us the web interface of dspace. Those files need to be copied in tomcat directory.

Give these commands one by one to copy dspace JSPUI, XMLUI and OAI files to tomcat webapps folder.

```
dspace@jesse-desktop:~$ cp -r /home/dspace/webapps/jspui /home/dspace/apache-tomcat-6.0.18/webapps/
```

```
dspace@jesse-desktop:~$ cp -r /home/dspace/webapps/xmlui /home/dspace/apache-tomcat-6.0.18/webapps/
```

```
dspace@jesse-desktop:~$ cp -r /home/dspace/webapps/oai /home/dspace/apache-tomcat-6.0.18/webapps/
```

![](img/81cd45265ffdc1888ff0c46976f30c4c_19_0.png)

now **Start your Webserver Tomcat** by giving this command

```
dspace@jesse-desktop:~/home/dspace/apache-tomcat-6.0.18/bin/startup.sh
```

It will give you the following output on the screen and the webserver will start.

![](img/81cd45265ffdc1888ff0c46976f30c4c_20_0.png)

Ok now ..... say HALLELUJAH...!!!

and open your web browser and browse any of this URL

http://localhost:8080/ispui

http://localhost:8080/xmlui

![](img/81cd45265ffdc1888ff0c46976f30c4c_21_0.png)

Thank the LORD first and then say ...Oh yes...!! It works!

Finally create an administrator account to monitor and administrate the repository site:

Give this command in terminal window.

```
$ home/dspace/bin/create-administrator
```

It will prompt you for some additional information. Like user name email id password etc.

![](img/81cd45265ffdc1888ff0c46976f30c4c_22_0.png)

But be careful while giving your administrator password, coz terminal window will show it on the screen.

After this you're done.

This is Dspace Administrator URL

http://localhost:8080/ispui/password-login

You can login on Dspace using your Email id and password which you have provided while creating administrator, and create community, Collection, and can upload contents.
