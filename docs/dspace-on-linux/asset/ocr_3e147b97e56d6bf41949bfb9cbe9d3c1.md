Now all the files will be in folder source-file, from here you will need to extract those tar files into /home/dspace.

This can be done by giving this command.

```
dspace@jesse-desktop:~$ tar -zxvf /home/dspace/source-files/dspace-1.5.2-src-release.tar.gz -C /home/dspace/
```

This command will untar all the files in dspace source file into /home/dspace folder, and you will see this stuff running on your terminal screen.
