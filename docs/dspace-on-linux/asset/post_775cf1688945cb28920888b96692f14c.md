
## Me vs. Dspace

### Prerequisites software we need.

- Java Development Kit
- Apache Tomcat
- Apache Maven
- Apache Ant
- PostgresSQL
- .M2

JDK can be downloaded from [http://java.sun.com/javase/downloads/widget/jdk6.jsp](http://java.sun.com/javase/downloads/widget/jdk6.jsp)

Apache Tomcat from [http://tomcat.apache.org/download-60.cgi](http://tomcat.apache.org/download-60.cgi)

Apache Maven [http://maven.apache.org/download.html](http://maven.apache.org/download.html)

PostgreSQL

Apache Ant [http://ant.apache.org/bindownload.cgi](http://ant.apache.org/bindownload.cgi)

First of all we need to Download and Install PostgreSQL and Maven2 with help of some Package Manager or any Software installer, which is an inbuilt tool in Linux Operating system (you must have an INTERNET connection on your pc). This tool will Search your required software from worldwide Linux repository, and will download and Install it for you. Isn't Kool..?!?!. Let's Start...

![](img/81cd45265ffdc1888ff0c46976f30c4c_0_0.png)

Provide your user password if it asks. Package manager will start.

![](img/81cd45265ffdc1888ff0c46976f30c4c_1_0.png)

Make a quick search of postgresSQL it will now search the software from entire Linux repository and will give you a list of all the available softwares matching your search keyword, right click on your required software and click on “Mark for Installation”.

![](img/81cd45265ffdc1888ff0c46976f30c4c_2_0.png)

Then click on Apply button. This will begin to download that software and after download is complete, its installation will start automatically. Just like this.

![](img/81cd45265ffdc1888ff0c46976f30c4c_2_1.png)

Now next job is to install Maven2 (the same way) from this tool. Search for Maven2, right click on it and mark it for installation. System will automatically download and install it for you.

![](img/81cd45265ffdc1888ff0c46976f30c4c_3_0.png)

Ok now PostgresSQL and Maven2 are installed on your PC. Next you'll need to create Dspace user on your PC by following command.

```
jess@jess-desktop:~$ sudo adduser dspace
```

![](img/81cd45265ffdc1888ff0c46976f30c4c_4_0.png)

Here, after this command it will ask you for some other information like password, Full name, give password and full name and leave all the other things blank. Press Y at last and it’s done.

Now you can logoff from your current user or administrator and Logon Dspace.

![](img/81cd45265ffdc1888ff0c46976f30c4c_5_0.png)

Now after Logging in to Dspace, open the Terminal window there and make a folder named “Source-files”, using the following command.

```
dspace@jesse-desktop:~$ mkdir source-files
```

now you can download all the required prerequisite software and all the source files in this folder, or if you have already downloaded the files, just move those files in this folder by giving this command.

```
dspace@jesse-desktop:~$ mv /home/dspace/Downloads/hspace-1.5.2-src-release.tar.gz /home/dspace/source-files/
```

(move all the files one by one using the same command with different file names.)

![](img/81cd45265ffdc1888ff0c46976f30c4c_6_0.png)

Now all the files will be in folder source-file, from here you will need to extract those tar files into /home/dspace.

This can be done by giving this command.

```
dspace@jesse-desktop:~$ tar -zxvf /home/dspace/source-files/dspace-1.5.2-src-release.tar.gz -C /home/dspace/
```

This command will untar all the files in dspace source file into /home/dspace folder, and you will see this stuff running on your terminal screen.

![](img/81cd45265ffdc1888ff0c46976f30c4c_7_0.png)

Now Extract other source files also by giving same command but change the source file name in each command .. like .

```
dspace@jesse-desktop:~$ tar -zxvf /home/dspace/source-files/apache-ant-1.7.1-bin.tar.gz -C /home/dspace/
```

```
dspace@jesse-desktop:~$ tar -zxvf /home/dspace/source-files/apache-maven-2.1.0-bin.tar.gz -C /home/dspace/
```

```
dspace@jesse-desktop:~$ tar -zxvf /home/dspace/source-files/apache-tomcat-6.0.18.tar.gz -C /home/dspace/
```

```
dspace@jesse-desktop:~$ tar -zxvf /home/dspace/source-files/jdk-6u18-linux-i586.bin /home/dspace/
```

```
dspace@jesse-desktop:~$ mv /home/dspace/source-files/jdk-6u18-linux-i586.bin /home/dspace/
```

Then change the permissions of that bin file, so that you will be able to execute that. Give this command in terminal.

```
dspace@jesse-desktop:~$ chmod 777 jdk-6u18-linux-i586.bin
```

now install the JDK file with the following command

```
dspace@jesse-desktop:~$ jdk-6u18-linux-i586.bin
```

This command will execute the JDK binary file and it will show the EULA, press enter to scroll up the screen text.

![](img/81cd45265ffdc1888ff0c46976f30c4c_8_0.png)

Press Y at the end of this License agreement, then it will start extracting the files, if the processing stops at this screen .... this means , your Java Development Kit is installed.

![](img/81cd45265ffdc1888ff0c46976f30c4c_9_0.png)

Now give following command to see the list of Directories and programs installed in your Home/dspace folder.

```
dspace@jesse-desktop:~$ ls -l
```

and this will show some files as follows ..

- apache-ant-1.7.1
- apache-maven-2.1.0
- apache-tomcat-6.0.18
- dspace-1.5.2-src-release
- jdk1.6.0_18

![](img/81cd45265ffdc1888ff0c46976f30c4c_10_0.png)

Now set the environmental variables for these files in your Linux operating system, It can be done by this method.

```
dspace@jesse-desktop:~$ sudo gedit .bashrc
```

This command will open an editable .bashrc file of your dspace user. In this file copy the following line at the bottom

```
JAVA_HOME=/home/dspace/jdk1.6.0_18
ANT_HOME=/home/dspace/apache-ant-1.7.1
CATALINA_HOME=/home/dspace/apache-tomcat-6.0.18
MVN_HOME=/home/dspace/apache-maven-2.1.0
PATH=$JAVA_HOME/bin:$ANT_HOME/bin:$CATALINA_HOME/bin:$MVN_HOME/bin:$PATH
export PATH JAVA_HOME ANT_HOME CATALINA_HOME MVN_HOME
```

![](img/81cd45265ffdc1888ff0c46976f30c4c_11_0.png)

Save and close that file.

This part is done. Now our next step is to create the Database for postgres SQL server. Here we start.

### Start your postgresSQL service with following command

```
dspace@jesse-desktop:~$ sudo /etc/init.d/postgresql-8.4 restart
```

then switch to postgres user.

```
dspace@jesse-desktop:~$ sudo su postgres
```

You will get user prompt like this

![](img/81cd45265ffdc1888ff0c46976f30c4c_12_0.png)

Now create the DATABASE with this command .

```
postgres@jesse-desktop:/home/dspace$ createuser -U postgres -d -A -P dspace
```

(it will ask for password give dspace(you can choose your own password , but don't forget to enter it in dspace.cfg file :-) as password it will ask whether this new role will be able to create new roles say "no" )

![](img/81cd45265ffdc1888ff0c46976f30c4c_13_0.png)

```
postgres@jesse-desktop:/home/dspace$ exit
```

After you exit you will return to Dspace user mode.

### Here create Database dspace as user Dspace.

```
dspace@jesse-desktop:~$ createdb -U dspace -E UNICODE dspace
```

now make some changes in postgres configuration file. Open the configuration file with this command.

```
dspace@jesse-desktop:~$ sudo gedit /etc/postgresql/8.4/main/pg_hba.conf
```

(add this line **host dspace dspace 127.0.0.1 255.255.255.255 md5**)

In case of postgresQL latest versions Replace “ident sameuser” by “trust”

![](img/81cd45265ffdc1888ff0c46976f30c4c_14_0.png)

Save and exit

now run one more command

```
dspace@jesse-desktop:~$ sudo gedit /etc/postgresql/8.4/main/postgresql.conf
```

uncomment the line **listen localhost** by just deleting # in the beginning.

![](img/81cd45265ffdc1888ff0c46976f30c4c_15_0.png)

save and exit

Now edit the space.cfg file: this is the very important file because many more configurations are to be done in this file.

```
dspace@jesse-desktop:~$ cd /home/dspace/dspace-1.5.2-src-release/dspace/config/
dspace@jesse-desktop:~/dspace-1.5.2-src-release/dspace/config$ sudo gedit dspace.cfg
```

Here in this file the path for webapps folder is defined. And you need to change the path to /home/dspace.

dspace.dir = /dspace
dspace.dir = /home/dspace (if you wrong path here it will not create the webapp folder in /home/dspace)
