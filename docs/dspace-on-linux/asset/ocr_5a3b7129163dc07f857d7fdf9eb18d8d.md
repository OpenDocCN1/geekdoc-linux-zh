Open the terminal window and give the following command for **running the maven**

```
```sh
dspace@jesse-desktop:~$ cd home/dspace/dspace-1.5.2-src-release/dspace
dspace@jesse-desktop:~/dspace-1.5.2-src-release/dspace$ mvn package
```
```

(this may take some time because this command will download and install all the required maven packages.)

After waiting so long, it should show you this screen, and it will make a target folder in your home/dspace/dspace-1.5.2-src-release/dspace directory.

![](bbox=[0.09, 0.28, 0.91, 0.69])

it means, Maven package has been compiled successfully. Now time to make webapps in dspace. First move to Dspace target folder and then dspace build.dir, which was made while compilation of mvn package.

Go to terminal window and run this command to move to dspace build directory in target folder.

```
```sh
dspace@jesse-desktop:~$ cd /home/dspace/dspace-1.5.2-src-release/dspace/target/dspace-1.5.2-build.dir/
```
```

now run **ANT FRESH_INSTALL**
give the following command in terminal window.

```
```sh
dspace@jesse-desktop:~/dspace-1.5.2-src-release/dspace/target/dspace-1.5.2-build.dir$ ant fresh_install
```
