
# Linux Mint 18：初学者指南

作者：William Rowley

## 引言

世界上绝大多数人已经转向使用 Linux 而不是常见的 Windows 操作系统。这是因为他们已经意识到 Linux 是多么强大，以及使用 Linux 可以成就很多目标。当被称为“Linux 极客”时，人们也会感到自豪。Linux 有多种发行版，每种发行版都是为了特定的领域而设计的。

Linux Mint 是可选的 Linux 发行版之一，基于 Ubuntu 和 Debian 开发。你可以使用这个 Linux 发行版完成许多任务。本书是一份关于如何使用 Linux Mint 的指南，并已更新至 Linux Mint 18.0。阅读愉快！

## 第 1 章 什么是 Linux Mint？

Linux Mint 是全球数百万用户使用的常用 Linux 发行版之一。该 Linux 发行版提供完整的多媒体支持，并且易于使用。它是开源的，这意味着用户可以下载它并对其进行一些定制以满足自己的需求。Linux Mint 的开发是社区驱动的，这意味着用户能够对其使用 Linux Mint 的体验提供反馈，以改进它。

Linux Mint 的开发基于 Ubuntu 和 Debian，并配备了最优秀的软件包（多达 30,000 个）以及最好的包管理器。Linux Mint 的第一个版本于 2006 年作为 Linux Mint 1.0 发布，这是一个测试版本。随后，发布了 Linux Mint 2.0，它使用 Ubuntu 作为代码库。

2010 年，发布了基于 Debian 的 Linux Mint 版本。这个版本的 Linux Mint 不受限于 Ubuntu 软件包。

## 第 2 章 Linux Mint 的安装

可以免费下载 Linux Mint 操作系统。它将以 ISO 文件的形式下载，你可以将其刻录到 DVD 中。LiveDVD 是启动的，并包含一个功能完整的操作系统，你可以在不更改电脑的情况下对其进行尝试。建议你先尝试 LiveDVD，如果你喜欢你看到的内容，再安装 Linux Mint。你可能需要的所有工具（包括分区工具）都将可用。

您可以选择“启动 Linux Mint”然后按下回车键。实时系统将启动，您将看到它的屏幕。几分钟后，实时系统将准备就绪，并显示桌面。

请注意，此时 Linux Mint 尚未安装到您的计算机上，它仅在从 DVD 运行。然而，一旦您将其安装到计算机上，它将与您现在从 DVD 运行的完全相同。此外，您应该知道，从 DVD 运行系统会比安装在电脑上慢。这背后的原因是数据必须从 DVD 读取，而不是从速度较快的硬盘中读取。

点击桌面上的“安装 Linux Mint”图标。安装程序随后将会出现。此外，多阅读一下发布说明也对您大有益，这样您就可以了解更多功能，以及如何处理可能出现的任何问题。

选择您需要的语言，然后点击“继续”。系统将显示一个询问您是否需要安装第三方软件的界面。这指的是那些并非完全开源但具有某些许可限制的软件。如果您需要使用这些软件，只需勾选该框然后点击“继续”。

## 第 3 章 - Linux Mint 桌面

桌面是操作系统的一部分，负责显示您在桌面上看到的元素。这些包括壁纸、面板、菜单、控制中心等。

### Cinnamon 桌面

Cinnamon Linux Mint 使用“Cinnamon”桌面，该桌面非常强大且直观。

### 桌面设置

桌面是一个允许您更改您主要使用的 Cinnamon 桌面的菜单。

要启动它，点击屏幕左下角的“菜单”，选择“系统设置”，然后点击“桌面”。

Linux Mint 自带默认的 Cinnamon 菜单。如果您需要启动菜单，点击屏幕左下角的“菜单”按钮或按下 `CTRL+SUPER_L`。键盘上的 SUPER_L 指左 Windows 键。

### “位置”菜单

一旦您选择“位置”部分，将向您显示五个项目。这些项目将为您提供对 Cinnamon 桌面某些位置的快捷访问。

它是显示您计算机中存储卷的项。如果您挂载了计算机中的所有分区，并将“桌面设置”设置为在桌面上显示“挂载卷”，那么您就不需要经常访问这些位置了。然而，对于那些选择不在此桌面上显示挂载卷的用户，或者需要挂载以前未挂载的分区的用户，您将必须访问此位置，因为它对您很有用。

“主目录”位置是对您证明非常有用的位置之一。

对于过去使用 Cinnamon 桌面的用户，您可能习惯了点击桌面上的“主目录”图标。当您打开了太多窗口导致桌面消失时，菜单将帮助您能够快速访问“主目录”。

如果你将某些数据放在此文件夹中，它也将被添加到桌面上。你也可以通过将文件拖到桌面来实现相同的操作。“网络”位置负责向你显示共享设备、域以及其他计算机，以及你计算机上可用的工作组。“废弃篓”位置负责保留已删除的文件。

在文件上点击右键后，你将获得两个选项，即“删除”和“移动到废弃篓”。如果你选择“删除”，该文件将被永久删除；但如果你选择“移动到废弃篓”，该文件将简单移动到“废弃篓”处，你可以从菜单访问它。如果你需要恢复文件，可以将其拖放到你需要的地方。如果你需要永久删除废弃篓中的所有项目，你必须选择“清空废弃篓”，这些文件将被永久删除。

### “系统”菜单

该菜单为我们提供了许多系统选项。它们能够帮助我们快速访问系统最核心的功能。未经授权的用户无法访问这些内容，因为访问这些内容需要密码。

“软件管理器”按钮将打开 Linux Mint 软件管理器。它是 Linux Mint 中安装软件的最佳程序。为了让你获得系统权限，系统将要求你提供密码。

“软件包管理器”按钮将打开一个名为“Synaptic”的应用程序。该软件包负责管理已安装在计算机上的程序，以及存储库中提供的程序。

“系统设置”按钮打开 Cinnamon 控制中心。该程序允许我们配置 Cinnamon 桌面的每一个方面以及整个计算机。让我们讨论一下此控制中心中包含的项目。

“终端”按钮打开一个名为“终端”的应用程序，它允许用户使用键盘输入命令。对于习惯 Windows 系统的用户来说，这可能有一点复杂，因为它的命令提示符没有进步多少。Linux Mint 终端非常强大，一旦习惯了，它会变得轻而易举。值得你了解，在 Linux Mint 图形化桌面上运行的任何命令都必须通过终端。一个很好的例子是当你点击桌面上的图标时。在这种情况下，Cinnamon 被指示向终端传递一些文本信息。通过一个命令，终端就可以帮助你完成很多工作，而无需通过打开多个窗口来实现相同的目标。

“锁定屏幕”按钮用于锁定你的屏幕。解锁时，系统会提示你输入密码。当你点击“注销”按钮时，会弹出一个允许你注销或切换用户的窗口。

“退出”按钮将启动一个对话框，允许你选择所需的选项。“挂起”选项会将会话保存到内存中，计算机将进入睡眠状态直到你按下按键。“休眠”选项会将会话保存到硬盘中，计算机将关机。“重启”选项将重启计算机。“关机”选项将关闭计算机。

## 第 4 章- 软件管理

### 包管理

对于第一次使用 Linux Mint 的用户，你可能不知道如何将软件组织成一个“包”。在安全和访问便利性方面，这是一个非常好的功能。

Linux Mint 的设计使得任何连接的硬件都会被自动检测，并且所有驱动程序都会自动安装。它还让 Linux Mint 用户能够完成大多数任务，而无需寻找任何第三方软件。Linux Mint 的安装版还带有一个功能完整的办公套件、一个高质量且专业的图像编辑解决方案、IRC 和 IM 客户端、几个媒体播放器、一个磁盘刻录机以及许多实用配件。这些都是免费软件！

当你从第三方网站寻找要在 Linux 系统上使用的软件时，会遇到很多问题。首先，你很难知道该软件是否经过测试，以及是否已被证明与你的操作系统兼容。此外，很难知道该软件是否能与系统中的其他软件兼容并按你预期的方式运行。该软件还可能来自未知的开发者，你不确定该软件是否会损坏你的计算机。

你可能会从不同的供应商下载并安装多个不同的程序。然而，这样做的问题在于，你的系统将缺乏一种管理结构。此外，你最好能制定一个计划，说明如何确保你下载到系统中的软件部分能够保持更新。有时，你可能会对某个程序感到厌倦。你将如何摆脱该程序呢？有些软件程序在安装后不提供移除选项，即使它们可能随之附带，程序也不会从系统中完全删除。这意味着在你电脑上运行了该程序的安装程序后，它获取了你电脑的一些控制权，更忘了该程序是由陌生人编写的。



在这种情况下，以这种方式分发的软件就变成了静态的。这意味着你必须先下载程序本身，然后是运行它所需的数据库。该程序的开发者现在意识到了你系统上安装的软件和库。这意味着，为了确保你在你的系统上成功运行该程序，他们必须向你提供程序本身以及数据库。下载本身将非常大，而且每当你需要更新它时，你都必须更新程序本身以及其余库。这也是分开进行的，而不是一次性完成。这意味着通过分发静态软件，会产生重复工作。

虽然可以通过图形化用户界面进行操作，但随着时间的推移，你会发现终端的力量，以及它如何让操作变得简单快速。有时，你可能会发现自己无法访问某个特定应用程序的软件包。

与软件管理器（Software Manager）的区别在于，它允许通过获取合适的软件包来安装应用程序。这不需要从 APT 和 Synaptic 访问的仓库（软件包数据库），也可以从互联网上的其他地方获取。

软件管理器主要有两个用途：

- 1. 如果你不习惯使用 APT 或 Synaptic。
- 2. 如果你需要安装的应用程序无法通过 APT 或 Synaptic 获取。

### 移除应用程序

APT 是我们删除应用程序的简单方法之一。此外，这是命令行操作，正如你将看到的，它让我们的工作变得非常方便。记得我们在系统中安装了 Opera 浏览器吗？让我们尝试通过 APT 移除它。打开菜单，然后点击“终端”。在终端中输入以下命令：

```
apt remove opera
```

再次，在使用 APT 之前，请确保你已关闭了 Synaptic。因为 Synaptic 正在后台使用 APT，你将无法同时使用两者。

执行上述命令后，Opera 将从你的系统中卸载。

### Synaptic

Synaptic 也可以用于卸载软件包。让我们演示如何实现这一点。

首先打开菜单并点击“软件包管理器（Package Manager）”。点击“搜索”按钮并输入“Opera”。你可以在提供的列表中找到对应之前安装的 Opera 浏览器的选项，勾选“标记为移除（Mark for Removal）”，然后点击“应用（Apply）”。

### 更新系统和应用程序

在你计算机上的软件包有了新版本后，可以进行更新。更新可以安全更新的形式应用于操作系统，或者你可能需要更新 Firefox 浏览器。

Linux Mint 系统由软件包组成，可以通过更新这些软件包来完成更新。一旦完成，旧软件包将被新软件包替换。

在 Linux Mint 中，有很多方法可以更新软件包，但我们建议只使用一种。APT 可以通过使用命令 `apt upgrade` 来升级系统，但这并不推荐。这样做的问题在于，系统中的所有需要升级的部分都将升级了。

你应该注意，系统的某些部分是最新的，而其他部分不是。在考虑升级内核时，如果你执行此操作，可能会导致网卡以及如 VirtualBox 和 VMware 等其他应用程序出现问题。

## 更新管理器

更新管理器（Update Manager）是 Linux Mint 自带的一个工具。它负责向用户提供有关更新的信息，并允许用户指定更新的安全性。这意味着它可以保护你免受安全漏洞的影响。

如果鼠标悬停在上方，你会被告知系统是否是最新的，以及有多少可用更新。

### 欢迎使用更新管理器

此工具为你的操作系统提供软件和安全更新。请选择更新策略：

- **不要弄坏我的电脑 (Don't break my computer!)** 推荐新手。仅选择已知安全不影响系统关键部分的更新。不要显示可能损害系统稳定性的更新。
- **优化稳定性和 (Optimize stability and security)** 推荐大多数用户。仅选择已知安全不影响系统关键部分的更新。同时也显示内核更新。
- **始终更新一切 (Always update everything)** 推荐经验丰富的用户。选择所有可用更新。保持我的电脑完全最新。如果出现回归问题，我会修复它。

一旦你点击图标，更新管理器将打开，第一次它会要求你选择更新策略。你应该阅读可用选项并选择最适合你的一个。

大多数 Linux Mint 用户希望软件保持最新，他们喜欢使用第二个选项。然而，对于那些需要计算机工作并获取所有所需更新的人，你应该选择第一个选项。

你将看到更新界面。系统还会询问你是否需要切换到本地镜像进行更新。全球范围内有很多组织帮助 Linux Mint 分发更新，以便用户在使用 Linux Mint 时获得最佳体验。为了获得最快的更新，最好选择离你最近的镜像。如果你不需要使用本地镜像，可以在“编辑-设置（Edit-Preferences）”下方更改。

更新管理器将向你显示可用更新。界面非常易用。对于软件包的每个更新，你都可以读取日志（changelog），它描述了开发者所做的更改。如果 Linux Mint 对更新有警告，你也会看到同样的内容。你还可以查看计算机上的现有版本以及你应该更新到的版本。还会显示一个符号，标明它是安全更新还是软件包更新。

分配给软件包更新的稳定性级别也会显示。每个软件包更新通常会带来一些改进或修复安全问题，但有时会出现 bug。Linux Mint 还会为每个软件包分配稳定性级别，并告知用户应用更新后有多安全。

你可以点击列并按状态、稳定性级别、版本或包名进行排序。“清除”和“全选”按钮可用于选择或取消选择所有更新。

级别 1 和级别 2 的更新都是无风险的，这意味着你可以直接应用它们。级别 3 更新预期是“安全的”，你应该确保已在更新列表中检查了它们。当你遇到任何关于级别 3 更新的问题时，最好通知 Linux Mint 开发团队，以便该更新被设为级别 4 或级别 5，从而阻止他人将其作为级别 3 更新应用。

一个很好的例子是，当所有级别都被设置为“可见”时，但只有级别 1 和级别 2 被标记为“安全”的。在这种情况下，列表中将看到许多更新，但更新管理器会告诉您您的系统是最新状态。

“选项（Options）”选项卡为您提供了许多选择，您可以借此更改更新管理器的设置。您还会在“选项”下找到“包含需要安装新软件包或卸载已安装软件包的更新”选项，这将允许您指定是否允许更新管理器安装某些新的依赖项。在使用此选项时务必小心，因为尽管它可能帮助您安装某些新的依赖项，但也可能会移除您已经安装的依赖项。

“自动刷新（Auto-Refresh）”选项卡将帮助您定义更新管理器检查更新的频率。在“忽略的包（Ignored packages）”选项卡中，您可以定义不需要接收更新的包。该处支持使用“*”和“?”。

# 第 5 章 技巧与窍门

在 Linux Mint 中，有一种方法可以让人们更轻松地执行最简单的任务。这将帮助您节省时间。

让我们讨论一下 Linux Mint 中一些可以帮助您实现此目标的技巧。

## 复制与粘贴

在大多数情况下，Linux Mint 用户必须选择需要复制的文本然后对其点击右键。其他人也通过点击“编辑（Edit）”菜单来这样做。这非常耗时。您可以仅通过使用鼠标来复制并粘贴您想要的文本。在这种情况下，鼠标的左键负责复制文本，而中键将负责粘贴文本。这非常简单且节省时间！

为了演示这一点，请打开文本编辑器、LibreOffice Writer 或任何您喜欢的、允许输入文本的应用程序。在其中输入几句子。使用鼠标左键选择您刚刚输入的一些文本。大多数人通过点击“编辑”菜单然后点击“复制”。其他人也喜欢使用某些组合键，例如“CTRL + COPY”。Linux 让它变得更简单。通过选择文本，您就已经复制了它。由于您已经选择了文本，它已经被复制并保存在“鼠标缓冲区”中，您不需要按下任何其他键。

点击文档的其他部分以将光标放置在那个位置。点击鼠标中键。如果您的鼠标有滚轮，只需在点击时按压滚轮即可；而对于那些只有两个按钮的鼠标，请同时点击右键和左键。您会发现刚刚复制的文本被粘贴了。

如果您习惯了这种操作，在 Linux Mint 中复制和粘贴文本对您来说将变得简单。这适用于其他的 Linux 发行版。

请您注意，鼠标使用的缓冲区与 Cinnamon 桌面使用的缓冲区是不相同的。这意味着您可以使用鼠标复制某些文本，然后使用 `CTRL +C` 复制另一个文本，或通过使用“编辑”菜单。这意味着您将复制两个不同的项目，而粘贴它们的方式将取决于您复制的方式。

## 笔记

在 Linux Mint 中，人们有多种方法可以记录笔记。大家在运行电脑时喜欢记录笔记。Linux Mint 自带了一个适用于此类任务的工具，被称为 Tomboy。

该工具非常易用，在您点击它后将加载您的笔记。如果您需要记录新笔记，只需点击“新建笔记（Create New Note）”。这将打开一个笔记。一旦您更改了标题，您也可以更改它的名称。您可以在笔记中编写任何需要的内容然后将其关闭。通过 Tomboy，您可以访问刚刚编写的内容。您不需要保存笔记，甚至可以重启电脑也不会影响笔记。笔记会在您输入时立即保存。

如果您已经完成了笔记并确定不再需要它，可以点击“删除（Delete）”按钮将其删除。如果您在正在创建的笔记中写了特定笔记的标题，那么点击该链接后将打开第二个笔记。Tomboy 还允许您在创建笔记时使用某些格式功能。这些功能包括搜索功能、同步以及将笔记导出为 HTML、PDF 等。这就是在 Linux Mint 中记录笔记的方法。

Linux Mint 是 Linux 的发行版之一。它基于 Ubuntu 和 Debian。通过 Linux Mint，人们可以做很多事情。现在，您应该对使用 Linux Mint 的各个方面了如。Linux Mint 终端可以帮助您更轻松、更快速地完成大多数任务。一个很好的例子是当您执行系统升级时。您可以使用一个简单的命令来完成，而不是使用 GUI 手动更新系统的每个组件。对于 Linux Mint 初学者来说，使用命令行可能看起来有点复杂，但对您来说开始练习是有好处的。涉及到 Linux Mint 的更新时，它们被分类在级别 1 到级别 5 之间。人们必须指定系统处于“安全”的级别。如果违反了这一点，您将收到有关可用更新的通知，并获得升级到该级别的选项。
