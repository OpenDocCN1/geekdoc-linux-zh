## 引言

如果你是一个初学者，可能在好奇 `Linux` 是什么？让我来提供一些基础知识。`Linux` 是一个操作系统，就像 `Windows` 和 `MacOS` 一样，但具有更高的安全性、稳定性和可定制性。你知道吗？它是完全免费的并且是开源的（这意味着源代码没有被隐藏或加密）。

`Linux` 是一个由专业人士为专业人士专门开发的操作系统。与 `Windows` 和 `macOS` 相比，它提供的创意软件要少得多。你找不到 `Linux` 版本的 `Photoshop`，因为 `Adobe` 认为 `Linux` 不是开发者用来创建他们产品的平台。

那么，你可能会好奇谁在用 `Linux` 作为日常工作机器？

`Linux` 可能不是一个创意型操作系统，但绝对是开发者、程序员、白帽和非白帽黑客、数据库系统管理员和系统管理员的首选。`Linux` 是复杂的，而且绝对有学习曲线。`Linux` 爱好者应该意识到命令的重要性，特别是要深入深入理解 `Shell` 编程，以便使用 `Linux` 内核实现他们想要的目标。

你被 `Linux` 的各种可能性感到无所措了吗？不要担心，我们在这里帮助你，通过简单的解释和指令向你介绍 `Linux`。欢迎来到本书的第一个模块，你将在这里获得对 `Linux` 生态系统的简单介绍和详细的逐步安装指南。让我们开始吧！

# Linux 与开源软件

`Linux` 是一个免费且开源的 `Unix` 类操作系统。该操作系统的内核由 `Linus Torvalds` 于 1991 年首次发布。之后，随着用户空间应用程序的加入，它变成了 `Linux` 操作系统。

严格来说，`Linux` 使用的是操作系统内核。“`Linux` 内核”这一术语通常用来表达这一点。`Linux` 经常被指的是基于 `Linux` 内核的完整操作系统，包含了 `GUI` 组件和许多其他实用程序。

`GNU` 通用公共许可证（通常称为 `GNU GPL` 或 `GPL`）是一种广泛使用的自由软件许可协议。它最初由 `Richard Stallman` 为 `GNU` 项目编写，`GPL` 为自由软件给出了定义。任何源自 `GPL` 软件的产品都必须在 `GPL` 许可证下发布，并公开源代码。

`Linux` 是自由软件和开源软件开发中最著名的案例。只要遵循 `GNU GPL`，任何个人和组织都可以自由使用 `Linux` 的底层源代码，并自由修改和分发。随着 `Linux` 操作系统的快速发展，`Linux` 上的各种集成开源软件和工具也得到了应用和普及。因此，`Linux` 也成为了开源软件的代名词。`红帽`是著名的 `Linux` 操作系统之一，将其工具出售给寻找数据库管理系统的企业。

# Linux 在服务器领域的发展

随着全球开源软件影响日益增大，服务器操作系统在服务器操作系统市场结构中占据了越来越多的份额，并已形成大规模市场应用的局面，并保持着快速增长，特别是在政府、金融、农业、交通和电信等关键领域。根据权威部门的统计，`Linux` 目前在服务器领域占据了 75% 的市场份额。同时，考虑到 `Linux` 的快速增长以及各国相关政策的支持，`Linux` 服务器产品必将影响更大的服务器市场，并以强劲的势头成为服务器操作系统领域的骨干。

# LINUX 在桌面领域的发展

近年来，特别是在技术市场，`Linux` 桌面操作系统的发展趋势非常迅速。由本地系统软件厂商推出的 `Linux` 桌面操作系统，如获胜的 `红旗 Linux` `Red Flag Linux`、`深度 Linux` `Deepin Linux`，已在政府、企业、`OEM` 等领域广泛使用。

此外，`SUSE` 和 `Ubuntu` 也发布了基于 `Linux` 的桌面系统，尤其是 `Ubuntu Linux`，它积累了大量的社区用户。然而，从系统的整体功能和性能来看，`Linux` 桌面系统与 `Windows` 系列之间仍然存在一定差距，主要体现在易用性、系统管理、软硬件兼容性以及软件丰富性方面。`macOS` 在设计师、电影创意专业人士以及作家中也广受欢迎。`Linux` 则有其明确的目标并很好地服务于这一目标。其他操作系统也是如此。作为一名黑客，理解 `Linux` 的重要性是至关重要的，因为使用 `Windows` 和 `Mac` 软件可能很难破解任何系统。

在下一节中，我们将通过一组示例来讨论 `Linux` 在各个领域的发展。请随我们一起！

# LINUX 在移动嵌入式领域的发展

`Linux` 的低成本、强大的定制功能和良好的移植性使得 `Linux` 被广泛应用于嵌入式系统。目前，`Linux` 已广泛用于手机、平板电脑、路由器、电视和电子游戏机中。广泛用于移动设备上的 `Android` 操作系统是基于 `Linux` 内核创建的。目前，`Android` 已成为全球最流行的智能手机操作系统，超过了备受瞩目的 `iOS` 系统。根据 2015 年权威部门的最新统计，`Android` 操作系统的全球市场份额已达到 84.6%。

此外，`思科`在网络防火墙和路由器中使用了定制的 `Linux`，`AWS` 云端也开发了基于 `Linux` 的操作系统，可以在手机、平板电脑和网络电视上使用。常见的数字录像机、舞台灯光控制系统正逐渐采用定制版本的 `Linux` 来实现，这一切都归功于 `Linux` 和开源的力量。`Linux` 绝不会灭绝，它将迅速遍布每一个角落。

# LINUX 在云计算/大数据领域的发展

互联网行业的快速发展促进了云计算和大数据行业的形成和快速发展。作为一个基于开源软件的平台，`Linux` 占据了云计算和数据的核心优势。

根据 `Linux` 基金基金的研究，86% 的企业已使用 `Linux` 操作系统来构建云计算和大数据平台。目前，`Linux` 已开始取代 `UNIX` 成为最流行的云计算和大数据平台操作系统。

在下一章中，我们将提供不同 `Linux` 发行版的细节，帮助读者选择他们喜的操作系统。选择一个 `Linux` 发行版总是一项具有挑战性的任务。为了了解什么最适合你，我们建议尝试不同的发行版来找到你真正喜欢的。

`Linux` 发行版非常多，没有人能给出准确的数字，但有一点是：`Linux` 变得越来越流行。面对这么多 `Linux` 发行版，计划从其他系统切换到 `Linux` 系统的初学者可能会感到困惑。即使是忠实的 `Linux` 用户也没有精力去逐一尝试。因此，在初学者学习 `Linux` 之前，他们需要一个明确的方向。选择一个适合自己的 `Linux` 系统非常重要。接下来的章节将对 `Linux` 发行版进行分类介绍。

## 第二章

## 选择 Linux 发行版

上一章很好地介绍了 `Linux` 作为一种操作系统的重要性和设计理念。目前有许多 `Linux` 发行版，选择那一个完美的发行版可能是一项艰巨的任务。即使是专业人士也难以持续维护或使用某一个发行版。正如我们所，使用完美支持你偏好的 `Linux` 发行版是最好的方法。可能存在流行的版本，但在你知道自己想要什么之前，它们不会让你满意。

这里是一些常见的 `Linux` 发行版：

- `Red Hat Linux` `红帽`

`Red Hat Linux` 是红帽发布的最早个人版本 `Linux`。其 1.0 版本于 1994 年 11 月 3 日发布。虽然它的历史没有其他著名的 `Linux` 发行版长，但它比许多新的 `Linux` 发行版要长得多。

自 `Red Hat 9.0` 发布以来，`Red Hat` 不再开发桌面 `Linux` 发行版。`Red Hat Linux` 已停止开发并将精力集中在服务器版本的开发上，即 `Red Hat Enterprise Linux` 版本。2004 年 4 月 30 日，`Red Hat` 正式停止了对 `Red Hat 9.0` 版本的支持，标志着桌面版 `Red Hat Linux` 的正式结束。原始桌面 `Red Hat Linux` 发行版与开源社区的 `Fedora` 合并成为 `Fedora Core` 发行版。

`Red Hat` 目前分为两个系列：由 `Red Hat` 提供付费技术支持和更新 `Red Hat Enterprise Linux`，以及由社区开发的免费 `Fedora Core`。

我们向谁推荐这个？

对于所有有服务器管理需求的优秀企业，没有比 `Red Hat Linux` 更好的发行了。

- `Fedora Core`

`Fedora Core` `FC` 被 `Red Hat` 定位为新技术的测试平台，许多新技术将在 `FC` 中进行测试。如果这些新技术趋稳定，`Red Hat` 将考虑将这些软件加入 `Red Hat Linux`。

`Fedora Core 1` 于 2003 年底发布，`FC` 定位面向桌面用户。`FC` 提供最新的软件包，且版本周期非常短，只有 6 个月。由于版本更新频繁，性能和稳定性无法保证，通常不建议在服务器上使用 `Fedora Core`。

对于用户来说，`Fedora` 是一个具有完整功能和快速更新的免费操作系统。因此，对于个人应用（如开发和体验新功能），你可以选择这个发行版本。

- `Kali Linux`

作为一名黑客，你需要意识到存在一个专门为黑客设计的完美 `Linux` 发行版。在此之前，它被称为 `Blacktrack`，由许多志愿者维护。`Kali Linux` 的优势在于在同一个操作系统中为黑客和法取证专家提供必不可少的工具。

虽然现在 `Kali` 确实面临 `Parrot Linux` 的竞争（这是另一个著名的 `Linux`），但我们仍然建议初学者使用 `Kali Linux` 开启他们的黑客生涯。`Kali Linux` 免费下载并完全支持所有开源政策。如果你想认真对待黑客技术，那么通过使用 `Kali` 作为你的主操作系统显然是明智之举。

- `CentOS`

`CentOS` 的全称是“社区企业操作系统”。它根据开源规范从 `RHEL` 发布的源代码编译而得。由于 `RHEL` 是商业产品，所有的 `Red Hat` 标志必须更改为自己的 `CentOS` 标志，这导致了 `CentOS` 操作系统的诞生。

两者之间的区别在于 `CentOS` 不包含闭源软件。因此，`CentOS` 不仅可以免费使用，还能享受 `CentOS` 提供的长期免费升级和更新服务。这是一个巨大的优势。

`CentOS` 是基于 `RHEL` 源码构建的。它的版本号由部分组成：主版本和次版本。主版本和次版本分别对应 `RHEL` 的版本和更新包。例如，`CentOS 6.5` 是基于 `RHEL 6` 的第 5 次更新。

但从 `RHEL7` 开始，`CentOS` 的命名格式发生了发生了变化。主版本仍然对应 `RHEL` 的主版本，次版本取决于 `RHEL` 更新包的发布日期。2014 年，`CentOS` 宣布与 `Red Hat` 合作，但 `CentOS` 将继续在一个新的委员会下运行，不受 `RHEL` 的影响。这一策略表明 `CentOS` 的后续开发将获得 `Red Hat` 的强支持。

- `SUSE Linux`

`SUSE` 是德国最著名的 `Linux` 发行版并享有良好声誉，但现在的命运相当坎坷。2003 年 11 月 4 日，`Novell` 宣布收购 `SUSE`。收购成功完成后，`Novell` 正式将 `SUSE` 命名为 `SUSE Linux`。`Novell` 对 `SUSE` 的收购加速了 `SUSE Linux` 的发展，并将免费的 `SUSE` 变成了 `openSUSE` 社区项目。

但在2010 年，`Attachmate` 收购了 `Novell`。收购后，`SUSE` 的开发被阻塞。仅仅三年后，`SUSE` 再次更换了所有者。幸运的是，`SUSE` 正式宣布开源是 `SUSE` 开发的基础，并将继续对开源做出贡献。`SUSE` 仍将充分支持 `openSUSE`。

尽管 `SUSE` 经过了多次所有变更，但这并不影响它的专业性。根据不完全统计，`SUSE Linux` 现在占据了欧洲 `Linux` 市场近 80% 的份额，大多数关键应用程序都是在 `SUSE Linux` 下构建的。

- `Ubuntu`

`Ubuntu` 是一种基于桌面应用程序的 `Linux` 操作系统。它基于 `Debian GNU/Linux`，旨在为普通用户提供一个由自由软件构建的、最新且稳定的操作系统。`Ubuntu` 拥有巨大的社区力量，用户可以轻松从社区获得帮助。

在使用这个 `Ubuntu`，`Linux mint` 也是基于此开发的，我们将在书中主要使用它来讨论各种概念。

上述章节主要介绍了常见的 `Linux` 发行版。事实上，有许多 `Linux` 发行版。更常见的 `Debian GNU/Linux`、`Mandriva`、`Gentoo`、`Slackware`、`Knoppix`、`MEPIS` 和 `Xandros`，以及 `红旗 Linux`、`深度社区` 和 `麒麟 Linux` 等，本文将不再作介绍。事实上，观察各种 `Linux` 发行版，`Linux` 发行版无非这两个方面的发展：一个是服务器市场，另一个是桌面市场。

### 最后，根据用途我们的建议是什么？

以 `Ubuntu Linux` 为代表的 `Linux` 发行版走的是桌面市场路线。尽管它们给用户带来了很多惊喜并且更新迅速，但 `Linux` 桌面市场的发展并不乐观，因为桌面市场有像 `Windows` 这样强力的竞争对手。目前，`Ubuntu Linux` 也开始在企业服务器市场展现其实力。

以红帽为代表的 `Linux` 发行版现在主要面向企业级 `Linux` 服务器市场，专注于企业版 `Linux` 的开发，而其他发行版则侧于 `Linux` 服务器市场。这两个大 `Linux` 发行版厂商现在都采取了 `Linux` 服务器市场的路线，这表明 `Linux` 作为企业服务器具有巨大的开发前景。根据权威部门的统计，`Linux` 在服务器市场的份额逐年上升。

事实上，`Linux` 的许多应用程序都是针对 `Linux` 服务器的，而本书的描述主要针对服务器环境下的各种 `Linux` 应用。作为一名黑客，你需要了解企业如何使用 `Linux` 来使其场景运行起来。即使是从像 `Kali Linux` 这样的桌面系统攻破目标，你也需要完全了解构建和维护这些服务器的 `Linux` 服务器的功能。我们都知道，所有敏感信息和我们绝对需要的信息都存储在服务器中。

### 初学者的首选是什么？ - LinuxMint

在学习了几个 `Linux` 发行版后，我们发现了为什么选择 `Linux Mint` 作为初学者入门学习对象。`Linux Mint` 现在拥有庞大的用户网络，80% 的网络 `Linux` 资源基于 `Ubuntu` 发行版。如果你在学习过程中遇到任何问题，可以轻松在互联网上搜索解决方案。

`Linux Mint` 版本可以轻松获得。

你可以从 `Linux Mint` 官网或 `163` 开源、`SOHU` 开源、云源站点下载各种版本的 `Mint` 安装媒体。如果这是你第一次接触 `Linux`，建议安装 `Fedora Core`。`Fedora Core` 易于安装，具有良好的硬件支持，并且界面精美。你也可以体验 `Linux` 的最新特性。如果你对 `Linux` 有了一了解并需要深入学习，建议使用 `CentOS` 发行系统。

`Linux Mint` 拥有广泛的应用，并且具有典型性和代表性。

现在基本上所有互联网公司的后端服务器都使用 `Linux Mint` 作为操作系统。可以认为，学习了 `Linux Mint` 后，不仅可以快速融入企业工作环境，还可以类此类推，快速掌握其他类似的发行版。同时，周围学习 `Linux` 的用户通常基于 `Mint`，这样沟通起来很方便，学习中的问题也更容易解决。

在通过 `Linux mint` 熟练掌握 `Linux` 后，作为黑客，你可以安装 `Kali Linux` 来扩展你的专业知识，并使用其中提供的大量工具来破解系统。

### 桌面平台首选是什么？ - Ubuntu Linux

提到 `Linux` 桌面市场，`Ubuntu Linux` 占据了桌面 `Linux` 的近半数。`Ubuntu Linux` 是最流行的 `Linux` 桌面，拥有漂亮、简单且精美的界面。如果你想在 `Linux` 下享受娱乐休闲，`Ubuntu Linux` 绝对是首选。

`Ubuntu` 的安装非常友好，只需按照提示逐步操作即可。`Ubuntu` 被认为是硬件支持最好、最全面的 `Linux` 发行版之一。许多在其他发行版或默认配置无法使用的硬件在 `Ubuntu` 上可以轻松安装使用。因此，用户可以像安装 `Windows` 一样安装 `Ubuntu`，并享受 `Ubuntu Linux` 的乐趣。

### 企业应用的首选是什么？ - RHEL/CentOS 系列

企业级应用追求可靠性和稳定性，这要求构建应用的系统平台具有高可靠性和稳定性。企业级 `Linux` 发行版可以解决这个问题。

`RHEL` 和 `CentOS` 这两个 `Linux` 发行版区别不大。区别在于 `RHEL` 是一个商业 `Linux` 发行版。如果你想使用 `RHEL` 版本，需要购买商业授权和咨询服务。红帽提供系统技术支持并提供免费系统升级。

## 第六章 LINUX 中的分区

分区是在计算机上执行 Linux 安装时必须的非常基础的步骤。即使您安装 Windows 系统也需要分区。虽然 Windows 提供图形化界面，但 Linux 的分区机制可能不同，某些 Linux 发行版甚至不提供 Gparted 这样的图形化安装程序。跟随操作详细了解分区方案和安装步骤。

## 分区命名方案

这些数字分区命名方案。

- `/dev`: 这是存储所有设备文件的目录。

- `hd` 和 `sd`: 它们是分区名的前两个字母，代表分区所在的设备类型，其中 `hd` 代表 IDE 硬盘，`sd` 代表 SCSI 硬盘。

- `a`: 它是分区名的第三个字母，表示分区位于哪个设备。

例如，`/dev/hda` 代表第一块 IDE 硬盘，`/dev/sdb` 代表第二块 SCSI 硬盘，`/dev/sdd` 代表第四块 SCSI 硬盘，以此类推。

- `+ 2`: 这些数字分区。

Linux 下的前 4 个分区（主分区或扩展分区）用数字 1 ~ 4 表示，逻辑分区从 5 开始，以此类推。

例如，`/dev/hda2` 代表第一块 IDE 硬盘的第二个主分区或扩展分区，`/dev/sdb3` 代表第二块 SCSI 硬盘的第三个主分区或扩展分区，`/dev/sdc6` 代表第三块 SCSI 硬盘的第二个逻辑分区。

### 双系统 Windows + LINUX 硬盘分区方案

很多从 Windows 切换过来的初学者喜欢在电脑上安装双系统。这在技术术语中也称为双启动。这种方法对于 Linux 初学者来说更加危险，可能会导致硬盘数据丢失。因此，有必要讨论如何安全、有效地安装 Linux + Windows 共存的双系统。

首先，应该理解 Linux 和 Windows 是两个完全不同的系统，因此 Linux 和 Windows 的文件系统之间也是不兼容的。如果你想安装 Linux，必须从硬盘中“专用”出一个分区给 Linux，这种专用并不是清空某个盘器符下的数据，而是从 Windows 中完全删除磁盘。

例如，如果我想给 Linux 系统分配 G 盘空间，我需要在 Windows 的磁盘管理中完全删除 D 盘。空间取决于安装包的大小。通常，10GB 的空间就能满足需求。

整理好 Linux 所需的空间后，下一步是重启系统，将 BIOS 设置为光驱启动，将 Linux CD 放入光驱，然后进入系统安装界面。

注意：

安装双系统时，最好先安装 Windows 系统，然后再安装 Linux，因为每次安装 Windows 时，系统启动文件都会被修改。如果你反过来安装双系统，Linux 可能无法启动，你可能需要修复系统启动文件。

此外，在安装 GRUB 引导加载程序时，引导将从 Windows 切换到 Linux。在将来情况下，如果由于某种原因你选择了删除 Linux，那么 Grub 将损坏，你可能无法进入你的 Windows 系统。

这是初学者在处理双启动系统时遇到的最常见的问题之一。要排除引导加载器问题，我们建议检查制造商的论坛。

### 系统安装设置

前一章节为 Linux 爱好者了解不同的流程提供了一个良好的开始，这有助于理解 Linux 是什么。在本章中，我们将讨论 Linux 安装过程中常用的不同系统安装设置。请继续阅读！

#### 系统安装设置

- 1) 现在进入磁盘分区阶段。在所示的界面中，点击“安装目标”（INSTALLATION DESTINATION）进入磁盘分区阶段。你可以看到有一个大小为 100GB 的硬盘 `sda`。显示的大小将根据你的磁盘大小而定。

在分区之前，有一些关于 Linux 分区的必要说明。

Linux 系统下的必要分区是根分区（root partition，标记为 `/`）和交换分区（swap partition，标记为 swap）。交换分区等于 Windows 中的虚拟内存概念，即在内存与硬盘之间交换数据。关于交换分区的大小，许多来源指出它至少是物理内存的两倍，事实并非如此。

基本原则是：如果内存较小（根据经验，物理内存小于 4GB），通常将交换分区的大小设置为内存的两倍。如果物理内存大于 4GB 但小于 16GB，可以将交换分区的大小设置为与物理内存相等。如果内存大小超过 16GB，可以将交换分区设置为 0。虽然交换分区可以设置为 0，但并不建议这样做，因为设置特定大小的交换分区仍然具有的一定的效果。

虽然 Linux 默认只需要划分根分区和交换分区即可完成系统安装，但并不推荐这样做，因为如果只划分了根分区，当根分区损坏且数据存储在根分区中时，系统可能无法启动。数据也可能丢失，这非常不。因此，建议为独立的应用程序分配独立的分区，这样即使某个分区被破坏，也不会影响其他分区的数据，并可以尽力减少系统崩溃造成的损失。

安装系统时，建议独立分配以下分区：

- `/boot`：存储系统启动信息和内核信息。
- `/usr`：存储系统应用软件的安装信息。
- `/var`：存储系统日志信息。

关于每个分区的含义，请参考下一章获取更详细的。

根分区包含 Linux 系统所有的目录。如果安装系统时只分配了根分区，上述的 `/boot`、`/usr` 和 `/var` 都将包含在根分区，这意味着分区将占用根分区的空间。如果你单独划分了 `/boot`、`/usr` 等，这些分区将不再占用根分区的空间。

了解了一些基础分区知识后，开始下方的磁盘分区。

- 2) 在所示界面中，首先选择 100GB 的 `sda` 磁盘，然后在左下角会有两个分区选项。第一个是“自动分区”（Automatically configure partitioning），意味着自动分区。第二个是“我将配置分区”（I will configure partitioning），意味着手动分区。

如果你不熟悉分区，可以默认选择“自动”。然而，从学习的角度考虑，建议选择手动分区，即使你是新手，选择手动分区也有助于理解和掌握系统分区。在此选择手动分区。选择后，点击左上角的“完成”按钮进入界面。

- 3) 选择手动分区后，你还需要选择分区方案。你可以从左侧面板的下拉菜单中选择分区方案。可用的方案包括标准分区（Standard Partition）、Btrfs、LVM 和 LVM 精简配置（LVM Thin Provisioning）。

其中，标准分区可用于各种文件系统或交换空间（swap），是一种常用的分区方案。Btrfs 是下一代 Linux 文件系统，被 Oracle、Red Hat、Intel 和 Suse 等公司和社区使用。

LVM 是一种逻辑管理分区方案。创建 LVM 分区时，会自动生成 LVM 逻辑卷，可以通过 LVM 灵活使用物理磁盘并提高磁盘性能。使用 LVM 精简配置，你可以动态创建并分配存储池，然后自由地管理磁盘空间。LVM 精简配置是 LVM 的升级版本。

事实上，还有一种 RAID 分区方案。当有两个或多个磁盘时，会出现 RAID 分区方案。这是一种软件 RAID，可以为服务器提供高级存储功能和数据冗余安全。

在此处选择“标准分区”方案。添加分区有两个步骤。首先，你需要创建一个挂载点。点击左下角的“+”按钮来创建挂载点。

- 4) 首先创建一个根分区，并将根分区空间设置尽可能大，因为如果根分区空间满了，系统可能会停止响应，运行在系统上的应用程序可能会异常。由于 `/boot` 和 `/usr` 等分区已经分开，根分区 20GB 的空间是足够的。

事实上，分区大小设置与磁盘大小有关。如果磁盘足够大，确保系统充足而不浪费空间是磁盘分区的标准。

挂载点（Mount point）可以通过点击下拉列表选择，也可以手动填写。所需容量（Desired Capacity）如 20GB 可以直接填写“20G”，500MB 可以填写“500M”，以此此类推。设置完成后，点击“添加挂载点”按钮完成挂载点的添加。

- 5) 挂载点创建成功后，将进入界面。点击左侧面板中的挂载点，你可以在右侧面板进行各种修改，例如：编辑挂载点、修改分区大小、选择设备类型、选择文件系统类型、用于自定义的标签选项，以及对相应分区进行加密或重新格式化。

对于文件系统选择，默认是 xfs，但共有七种类型：swap、vfat、BIOS boot、ext2、ext3、ext4 和 xfs。其中，ext2、ext3 和 ext4 是 Linux 系统上的主流文件系统；在 RHEL/CentOS 7.x 之前的版本中，默认采用 ext 系列文件系统。VFAT 文件系统对应 Windows 上的 FAT 文件系统，而 swap 是 Linux 上的交换分区。BIOS boot 主要用于系统启动设备，是一个非常小的分区，而 xfs 系统是一种出现在 RHEL/CentOS 7.x 上的高性能文件系统。

“标签（Label）”选项是对应磁盘分区的标签，通过它可以快速识别分区。标签选项可以填写内容，也可以不填写，默认留白。

一旦建立了挂载点，对应的磁盘 ID 就会固定。例如，与分区对应的磁盘 ID 为 `/dev/sda1`。除非删除分区并重新建立，否则这个“sda1”是修改的。

所有设置修改完成后，点击界面中的“Update Settings（更新设置）”按钮完成磁盘分区的编辑。

- 6) 点击所示界面左下角的“+”按钮继续创建 `/boot` 挂载点。之后，在 Mount Point（挂载点）下拉列表中选择“boot”，并在 Desired Capacity（所需容量）输入框中选择输入的大小为“500M”。

`/boot` 分区不需要太大，因为它只用于存储一些系统启动信息和内核信息。点击 Add（添加）挂载按钮，即可创建 `/boot` 挂载点。

- 7) 然后创建一个 swap 类型的挂载点。在 Mount 下拉列表中选择 swap，然后在 Desired Capacity 输入框中输入大小，此处指定 4096M。

注意这是“swap（交换）”，而不是“root（根）”。

- 8) 然后分别创建 `/usr` 和 `/var` 分区。创建方法与 `/boot` 分区基本相同，但分区大小不同。

如果安装了应用软件，可以增大 `/usr` 分区。建议 `/var` 分区设得大一些，因为系统运行一段时间后会产生大量日志。

- 9) 在创建完系统所需的分区后，如果空间足够，还可以创建一个根分区来存储你的数据。在这里创建根分区。注意每个分区都是在 root 下创建的。

为了确保 Linux 使用所有磁盘空间，将剩余空间分配给根分区。具体操作是在输入框中输入 Mount Point，并留空 Desired Capacity。

- 10) 此时分区工作已基本完成，将显示已完成的分区。如需删除分区，可以点击界面左下角的“-”按钮。完成所有设置后。

- 11) 在所示界面中显示了所有与磁盘相关的操作，包括创建、调整大小或删除分区。你可以查看所有更改。如果需要修改分区，点击 Cancel（取消）按钮返回分区界面。要确认更改操作，点击 Done（完成）按钮。

到此为止，已经介绍了分区的所有基本操作。现在我们将进入网络配置。

# U 盘安装过程

如今大多数 PC 和服务器已不再配备 CD-ROM 驱动器，而是被 USB 接口设备取代。同时，USB 3.0 规范已广泛普及，U 盘的数据传输速度可以达到每秒千比特。根据您的需求，市场上上有从 2GB 到 2TB 不等的数十种产品。



由于这种安装程序的出现，现在有越来越多基于 USB 接口的应用程序，如 USB 键盘、USB 鼠标、USB 光驱等。在安装系统时，虽然可以使用 USB 光驱进行安装，但目前 USB 光驱的成本相对较高，而通过 U 盘安装系统不仅成本低，而且快速方便。在大规模系统安装中，通过 U 盘已成为主流程序。

通过 U 盘安装 Linux 系统的基本步骤如下：

1) 首先，需要一个大约 8GB 的 U 盘。容量越大越好。如今 Linux Mint 的完整 ISO 镜像文件大小已达到 7GB。在决定制作 USB 安装介质之前，请务必确认文件大小。

2) 从开源网站 (`http://mirrors.163.com`) 下载 Linux Mint 的 ISO 文件。或者您可以直接访问 Linux Mint 官方网站选择您偏好的磁盘镜像进行安装。

3) 从互联网下载一个 U 盘刻录工具。常用的 U 盘刻录工具包括 UltraISO、USBWriter 和 Rufus。这里推荐使用 USBWriter，因为它易于使用，且可以一步刻录磁盘镜像文件。虽然 UltraISO 也可以将 ISO 镜像刻录到 U 盘，但刻录的 U 盘在安装和启动过程中有时会出现问题。如果您使用 Windows 系统制作安装介质，我们强烈建议您使用 Rufus 来刻录 U 盘，因为它更方便且是推荐的做法。

4) `USBWriter` 是一个开源工具，可以从 `http://sourceforge.net/projects/usbwriter/` 下载。它是一个专门用于 Linux 系统的 U 盘刻录工具。

它的工作原理是将 U 盘分为两个分区：一个 FAT32 分区（大小仅几 MB）用于安装启动程序，另一个 Linux 分区用于存储系统安装包。

有时会出现一个已知问题：

使用 `USBWriter` 刻录后，U 盘的容量会自动变小。这是因为只能看到一个 FAT32 分区，另一个 Linux 分区在 Windows 下是不可见的。但不用担心，很容易将 U 盘恢复到原始大小。从互联网下载 `Diskius` 工具即可将 U 盘恢复到原始大小。

5) 使用 `USBWriter` 将下载的 ISO 镜像文件刻录到 U 盘。首先选择 ISO 镜像文件的位置，并指定需要刻录的 U 盘（例如选择一个 16GB 的 U 盘）。选中后点击“写入（Write）”按钮开始刻录过程。

将 ISO 文件刻录到 U 盘后，U 盘上之前的所有数据将丢失，刻录前请备份 U 盘中的数据。

6) U 盘刻录过程相对快，通常需要 10 到 30 分钟。如果刻录过程中没有错误，则刻录基本上就成功了。U 盘刻录完成后，将提示刻录成功。

7) U 盘刻录成功后，你需要重新插入 U 盘。此时，在 Windows 磁盘管理器中，你可以看到 16GB 的 U 盘大小变成了约 6MB。

8) U 盘刻录成功后，将 U 盘插入服务器的 USB 接口，然后进入 BIOS 设置从 USB 设备启动，然后重启系统进入提供更多选项的界面。

9) 接下来的安装过程与我们之前介绍的光驱安装方法完全相同，因此将不再重复介绍。但需要注意的是磁盘分区阶段，你会看到两个磁盘。

在完成（U 盘刻录）后，U 盘就就绪了，你可以用它在任何电脑上安装 Linux。

# 第一章

## 在 Linux 中安装软件和软件包

与所有操作系统一样，安装软件也是 Linux 的一个必用用例。Linux 使用了组织良好的包管理系统，并在操作正确的情况下，以一种更完美的方式安装软件。初次处理 Linux 软件的安装和更新时，可能会感到有些复杂，但随着时间的推移，你会发现 Linux 的安装哲学是非常有条理且易于的。作为一名黑客，理解并找到简单的软件安装方法至关重要，以防破坏系统。即使你是在使用 Live USB 进行黑客攻击，理解 Linux 中包的安装工作原理也是至关重要的。

为了帮助你理解这些概念，我们在本章中提供了各种用例和示例。请跟随我们一起！

### 它与 Windows 有何不同？

与 Linux 相比，Windows 的安装程序可能看起来很直观，但事实并非如此。Windows 安装文件巨大，因为它们创建了一个沙箱来包含软件在不同实例调用的所有 API。这导致安装文件变大，并可能在以后引起延迟问题。

然而，Linux 使用不同的方法来安装文件。它使用紧密封装且独立的软件包，并由它们自己的实例进行更新。这有时可能会引起问题，但大多数时候它运行得非常完美。

### 如何在 Linux Mint 中安装软件？

众所，Mint 是一个基于 Debian 的轻量级系统，甚至可以在低端系统上运行。不同的 Linux 发行版使用不同的包管理器。例如，Arch Linux 作为一个开发者喜爱的 Linux 发行版，使用 `Pacman` 来安装软件。

所有基于 Debian 的系统基本上都使用 `apt` 来安装软件。`Apt` 是一个简单的包管理器，它紧密集成了所有组件，并使用脚本文件中提供的指令将它们安装到 Linux 中。

#### 它是如何工作的？

当调用一个软件时，首先下载第一个脚本文件，然后包管理器将分析系统正常运行所需的所有组件。如果系统已经安装了某个组件，它将跳过到下一个进行下载。在安装所有组件后，软件将在几秒钟被打包并安装到 Linux 系统中。

这是一个命令：

```
apt-get install python
// 这将 Python 下载到 Linux 系统中
```

### 如何搜索软件包？

`Apt` 几乎提供了 Linux 爱好者和开发者青睐的所有著名软件包。然而，由于兼容性原因，有很多第三方软件包可能无法使用。

如果你正尝试下载一个软件包，且你不确定该软件包是否存在于包管理器中，你可以使用搜索命令来找到它。如果你没有针对包名得到任何准确的结果，那么显而易见 apt 不支持你的软件包。

这是一个命令：

```
root@server : apt-cache search Python4
// 这将搜索 apt 仓库并在命令行中显示“no results”
```

为了获得更准确的结果，请使用 apt 仓库的网页版本，那里所有可用软件包甚至根据类别进行了排序。

如果你正在使用 Arch Linux，`Pacman` 也提供了搜索选项，在下载和安装软件包之前进行检查。

### 如何删除软件？

从操作系统中删除软件与将软件安装到系统中同样重要。

你可能会疑惑，为什么删除一个对你的 Linux 系统没有造成任何损害的软件是重要的？但请听专家的建议，因为过时的空闲软件可能会与新安装的软件发生冲突。

如果 Linux 系统中存在潜在冲突，可能会导致整个操作系统崩溃。删除不需要的软件可以提高系统性能，并帮助用户将那些浪费的内存资源分配给更有价值的事物。

伦理黑客也应该理解如何删除软件，因为当他们检测到攻击者为了劫持系统而插入任何木马或爬虫时，他们应该能够尽快从系统中清除痕迹。某些高风险木马在你不手动找到并结束其进程之前是不会删除的。如果黑客使用潜在危险的方法来实现软件，那么删除软件将非常困难。

现在，我们将学习使用像 `apt` 这样的包管理器来删除软件。

是一些命令：

```
apt-get remove python
// 这将删除 python
```

对于黑客来说，许多自动化某些任务的脚本通常是由黑客上传给社区的。许多键盘记录工具和监控工具也是由开源社区上传的。

如果你是一个初学者，并尝试使用代码来实现你的攻击技术，那么将该仓库克隆到你的 Linux 系统中是合情逻辑的。要实现这一点，请使用下文提到的命令。

```bash
root@server : apt-get install git

// 这会在你的 Linux 系统中安装支持 git 的系统
root@server : git clone https://github.com/enterurlhere

// 这会将你所需的仓库克隆到 Linux 系统
```

至此，我们已经完成了关于在 Linux 中使用包管理器安装、更新和删除软件的简要介绍。你也可以在必要的权限后，使用可执行的 `.deb` 文件在 Linux 中安装软件。在下一章节中，我们将学习进程管理，这被认为是对于使用 Kali Linux 进行攻击的黑客来说是一项必备技能。请跟上节奏！

# 第二章

## Linux 中的进程管理

在深入理解安装哲学和 Linux 用途之后，你现在已经准备好进入一个新的 Linux 领域，这可以帮助你作为黑客激发更多重大的思考。Linux 使用进程来维护并让所有组件与 Linux 内核进行交互。如果没有进程在运行，那么我们可以肯定地说 Linux 系统已经关机。作为一名黑客，理解进程、操纵它们并在必要时结束它们是一项受幸运的技能。在本章中，我们不仅提供关于 Linux 进程的基础知识，还将提供可以帮助你更具体地理解 Linux 基础的示例。请跟上节奏！

### 什么是进程？

进程是 Linux 程序运行的内容。它们代表了软件/命令行工具正在与 Linux 内核等系统资源交互，以完成它应该做的事情。Linux 中运行的每个软件都有一个进程，如果手动结束该进程，软件将停止工作。

作为一名黑客，当你访问系统时，你很容易被 Linux 系统中运行的防病毒进程监控到。为了让它们停止向系统管理员发送日志，你可能需要手动结束它们的进程。

虽然像使用 Windows 任务管理器那样结束进程看起来很简单，但如果操作不当，可能会导致严重的后果。你需要具备实践经验并对进程管理有良好的理论理解，才能实现你的愿望。

在接下来的章节中，你将学习一些查找和管理进程的技巧，以及根据你的方便自动管理它们的方法。

### 如何查看进程？

每当 Linux 系统启动时，某些进程会自动开始打开。每当你打开终端或网络浏览器时，相应的进程就会被打开。当你关闭某些进程时，部分进程会自动关闭，而其他将在后台运行并消耗你的系统资源。

这里是查看进程的命令：

```bash
root@server : ps
// 这显示 Linux 系统中运行的所有进程
```

这里是示例输出：

```
PID
45637
// 这些数字是进程的标识符
```

如果你想对特定进程进行任何更改，那么你应该记录下进程号。输出信息将显示其他信息，如进程名称、时间和以及它正在使用的命令类型。如果你是从终端打开的进程，那么 bash 命令将出现在输出信息中。

注意：

查找进程有时是一项艰巨的任务，因为你需要从几十个正在运行的进程中进行搜索。在更改进程状态之前，请务必确保你是信心的。如果你以任何方式终止了运行 Linux 系统的系统进程，可能会停止响应，直到下次重启。

### 如何显示额外信息？

通常使用 `ps` 命令，你只能获得基本信息。你可以使用 `aux` 命令显示有关进程的额外信息。让我们通过示例检查。

```bash
root@server : ps aux
// 这打印出描述关于进程大量信息的输出
```

这里是示例输出：

```
PID - 2134 %CPU -2.3%MEM - 32% Start Time - 22:34
// 它显示了额外信息，例如它消耗的内存和 CPU 功率。它还显示了启动时间以便于估计进程名称
```

`aux` 命令还描述了启动进程的实例。这对于法医调查人员至关重要，因为他们可以使用此程序轻松地追踪攻击的源点。

### 如何过滤进程？

想象你正在寻找一个你急需停止的进程，但由于输出屏幕上显示了许多其他进程，很难找到它。如果你很聪明，你会找到一种过滤所需进程的方法，而不是手动遍历所有进程来寻找你想要的。

如果你想表现得聪明，Linux 为你提供了。Linux 专门提供了使用 `grep` 命令过滤进程的功能。这里有一个供你理解的示例。

```bash
root@server : burp suite
// 首先使用默认命令启动一个进程或你喜欢的任何软件
root@server : ps aux | grep burpsuite
```

```bash
// 现在使用此命令过滤掉通过使用 "burp suite" 命令启动的进程
```

这将显示类似于我们之前展示的输出，其中包含了理解该进程所需的所有信息。

### 如何找到问题进程？

在描述贪婪进程之前，我们应该谈论一个这些来变得非常流行的场景，特别是在 Windows 系统中。

如今许多垃圾邮件发送者和黑客在安装到你系统的应用程序中包含了挖矿程序。当你自愿或出于其他原因安装它时，你的计算机将变得非常慢，且无法正常运行。

### 为什么会发生这种情况？

因为挖矿程序强制使用所有系统资源并在后台运行。普通用户无法观察它，因为它是隐藏的。只有能够访问终端的专业人士才能判断操作系统是否存在恶意软件。作为系统管理员，你应该意识到杀死贪婪进程。

### 如何找到高资源进程？

要找到高资源进程，你只需要作为 root 用户输入以下命令。

```bash
root@server : top
// 这将显示分配了最大资源的信息
```

如果你觉得这些高资源进程中的任何一个对你的系统都是不必要的，你可以用 `kill` 命令结束它们，我们将在接下来的章节中讨论。

### 如何在 Linux 中设置优先级？

在一个运行大量进程的 Linux 系统中，作为道德黑客或系统管理员，始终建议使用 `nice` 命令为进程设置优先级。

### 为什么要设置优先级？

如果你是一个个人用户，那么设置优先级看起来并不智能，因为你拥有所需的所有资源。但想象如果你在企业并使用 Linux 维护的其他用户的资源，那么为你自己使用所有系统资源是不可能的。如果你这样做，你的系统管理员可能会发现并暂时阻止你的访问。

许多新手黑客破解系统后一次性攻击所有资源，通知系统管理员并关闭对系统的访问。如果你是一个聪明的黑客，你会仔细地设置进程优先级而不引起过多注意，当你获得所有所需的敏感信息时，结束进程并删除所有日志，这样就不会给法医调查人员留下任何足迹。

### nice 命令到底是做什么的？

`nice` 是一个 Linux 工具命令，开发用于根据其重要性给进程打分。优先级数字可以自定义，但它们通常范围在 -19 到 +19 之间。在这里，0 是中性范围，而 -19 用于确定最弱的偏好进程，+19 用于确定最偏好的进程。

```bash
root@server: nice -n 5 /bin/terminal
// 这是一个优先级为 5 的进程
root@server: nice -n 10 /bin/game
```

```
// 这是一个优先级为 -10 的进程
```

因此，当系统资源下降时，优先级为 -10 的进程将自动结束。任何情况下，低优先级进程都不应该占用系统。系统管理员通常会花费大量时间为系统中的完美进程进行优先级排序。如果你是一个黑客，你也应该学习如何进行排序，以便在尝试窃取信息的同时有效管理资源。

你可以随时使用 `renice` 命令更改进程的优先级顺序。

```
root@server: renice 13 7732
// 在这里将进程 ID 7732 的优先级更改为 13
```

在下一节中，我们将讨论如何杀死进程。学习杀死进程对于黑客来说是一项备受推崇的技能，因为他们经常需要关闭管理员使用的入侵检测系统。

### 如何杀死进程？

某些进程通常被称为“僵尸进程”，因为即使它们在系统中处于冻结或卡住状态，也会消耗大量资源。如果你运行了任何不值其所占资源之价值的进程，那么不计代价地杀死它们是一个明智的选择。

这里有一个命令：

```
root@server : kill -1 3638
// 这个 -1 表示在先杀死进程后应将其重启
root@server : kill -9 3638
// 这个 -9 表示该进程需要立即终止
```

在本章的最后一节中，我们将讨论进程调度。

### 如何调度进程？

在任何操作系统或计算机操作管理系统中，进程调度都是一项必须掌握的重要技能。调度不仅可以减少工作量，还能帮助你理解如何智能地使用资源。

例如，你可以安排仅在从网络浏览器下载文件后才启动杀病毒进程。

在 Linux 中，使用 `at` 工具来调度进程。

这里有一个命令：

```
root@server : at 9:00pm
// 这将启动 at 命令实用程序，它可以用于调度进程
root@server : at > /root/users/startscript
// 在上述时间，提到的脚本将作为进程启动
```

通过使用调度功能，黑客即使在失去访问权限也可以运行远程程序。你可以将程序与 metasploit 漏洞脚本绑定，使它们在几秒钟将信息发送到你的手机或服务器。

### 接下来做什么？

至此，我们已经完成了对进程管理的简要且完整的介绍。在下一章中，我们将结合大量示例讨论 Linux 文件管理。让我们开始吧！

# 第三章

## Linux 中的文件管理

在上一章中，我们一致地讨论了进程管理对黑客的重要性。如果你在认真地使用 Linux 进行黑客活动，你应该具备足够关于 Linux 文件管理和目录权限的信息。

许多新黑客在获得访问权限后，由于缺乏文件和目录权限而无法获取所需信息。Kali Linux 使用复杂的目录结构和目录管理哲学来应对普通 Linux 发行版可能面临的漏洞。在本章中，我们将通过具体的示例讨论许多此类场景。请跟上！

### Linux 中的用户和组是什么？

每个操作系统都使用“用户”概念来确定谁在使用什么。例如，Windows 使用一些某些名为“管理员”的复杂账户来访问系统文件。如果你不是管理员，就没有机会访问对黑客重要的 C 程序和系统文件。

同样，Linux 使用了更复杂的用户管理系统，以便更方便的访问和高级安全功能。

- 用户 - 用户是指可以访问系统特定区域的个人。
- 组 - 组是用户组合，可以共同访问特定的资源。

现在我们将更详细地讨论 Linux 中不同类型的用户。

1) 首先，你需要了解 Linux 系统的头部。也就是说，它是所有人中最强大的一个。它通常被称为 `root 用户`。`root 用户`是最强大的，可以在系统中做任何事情。他可以随所欲添加或删除用户和组。通常，root 权限被授予企业的系统管理员。作为黑客，你的主要格言应该是获得 root 权限，因为有了它你可以做任何你想做的事。

2) 接下来就很简单了。普通用户是指没有 root 权限的用户。他们可以访问什么完全由 root 用户决定。如果有一家服务公司，开发者将仅获得代码资源，而管理员工将仅获得管理文件。每家企业都有自己的方法来决定用户应该访问什么。

### 如何授予权限？



Linux 管理员通常使用权限来控制用户与系统文件及目录的交互。通常有三种权限，即：读（read）、写（write）和执行（execute）。

### A) 读取 (read)

这是仅读取文件的权限。你不能对其进行任何修改或删除。这些权限通常授予企业的入门用户。在 Linux 命令术语中，它表示为“`r`”。

### B) 写 (write)

这种权限允许用户写入文件。写入意味着修改文件内容。然而，写入文件后，不能保证你能够执行新写入的文件。例如，git 分支的贡献者被授予了仓库中文件的写入权限，但只有在被 git 分支管理员接受后才能执行。在 Linux 命令术语中，它表示为“`w`”。

### C) 执行 (Execute)

这是 root 用户拥有的高级权限。如果用户获得了权限，他不仅可以读写文件，还可以执行它们来更改系统文件和目录。当黑客试图攻击系统时，他通常期望获得执行权限。然而，请记住，有时 root 管理员只提供权限而不给予读和写权限。根据 Linux 命令术语，它表示为“`x`”。

至此，我们完成了对权限的简要介绍。在下一节中，我们将讨论如何从命令行为用户授予权限。

## 如何授予用户权限？

当你向用户授予权限时，他就可以错误地与文件或目录交互。

`chown` 命令用于在 Linux 中为用户授予权限。

这里有一个命令：

```
root@server : chown sample /home
```

在上述命令中，“`chown`”是告诉 Linux 内核提供权限的默认命令。“`sample`”代表用户名称，而“`/home/pictures`”是被授予的目录。

## 如何授予组权限？

就像 root 用户为个人用户分配权限一样，他也可以为组分配。

`chgroup` 命令是 Linux 中用于为特定组分配权限的命令。在企业中，创建和管理组是绝对必要的。在进行项目时，分配权限可以解决很多问题。

这里有一个命令：

```
root@server : chgroup hackers /home
```

在上述命令中，`chgroup` 是允许组分配权限的默认标识符。`hackers` 是组名，而 `/home` 是被授予的目录。

### ISP 能够追踪什么？

这听起来可能很可怕，但事实是你的 ISP 会将你访问过的每一个网站都记录在他们的系统日志中。一些不道德的 ISP 甚至试图将这些数据卖给跨国公司，这些公司需要创建机器学习算法来进一步针对你的兴趣，甚至可以改变你的政治观点。

那么，我们应该做什么来停止被政府和 ISP 追踪呢？许多网络爱好者和关注隐私的工程师与这个问题斗争了多年。在花费了数百小时的研究后，一组网络专家创建了被称为 TOR 网络的东西。

在首先理解 TOR 之前，我们需要通过一个例子来讨论 IP 地址是如何被追踪我们的。

### IP 地址如何追踪我们？

明确来说，IP 地址就像是你的设备（如手机/路由器，有时甚至是无线连接）的收地址盒。

例如，假设你给朋友发送了一条 WhatsApp 消息。当你点击发送按钮时，消息内容将以数据包的形式发送到最近的路由器。数据包包含源地址信息，并包含目的地址。网络数据包的传输就像发送到特定地址的邮件。当目的地接收到消息状态后，消息平台中的消息状态将会改变。

通常，一个正常的网络数据包在到达目的地之前会在 20 个数据包之间跳跃（hop）。对于普通用户来说，这一切在几秒钟内完成，甚至并不重要。但对于黑客和安全爱好者来说，这些数据包可以提供大量的未加密信息。ISP 和政府的追踪也可以通过这些网络数据包的帮助获取大量敏感信息。

### 如何找到数据包的传输路径？

Linux 提供了一个特殊的命令来帮助你理解数据包的传输路径。它被称为路由追踪（trace route）命令命令。

```
root@server : traceroute yahoo.com
```

这将显示你提供的 URL 地址的路由追踪。它将显示到达目的地所需的跳跃次数，并提供网络数据包的大小。

TOR 网络通过中间人接收并发送数据，这些数据是加密的，无法被追踪。虽然 TOR 不提供完全的匿名性，我们在暗网中可以找到 `.onion` 网站，那里充满了非法活动。

在下一节中，我们将讨论代理服务器，它是另一种隐藏身份以防止政府/ISP 追踪的方法。

### 什么是代理服务器？

用通俗的话说，代理是作为源和目的之间的中间人。它们是中间节点，允许来自源和目的的所有流量通过它们通过。

如果你好奇代理服务器是如何工作的，请遵循这个简单的解释。

假设你想用网络浏览器访问一个网站。在这种情况下，你的 IP 地址被称为主机地址，你要访问的网站的 IP 地址被称为目的地址。当你使用网络浏览器向该网站发送请求时，你的 ISP 会记录这些请求。

然而，现在假设当你向网站发送请求时，而不是直接访问网站，所有流量将首先发送到代理服务器。当流量到达代理服务器时，前往目的地的流量将更改其 IP 地址。在这种情况下，由于存在中间节点，很难追踪流量的来源。同样，目标网站也将响应发送给数据（即代理），现在代理会将数据发送到源地址。

### 有哪些缺点？

就像所有的解决方案一样，匿名代理也有一些缺点。最重要的一点是，由于涉及到接收并为你发送数据的中间人，速度将显著降低。

此外，代理绝对不是完全安全的。虽然它们在访问被封的网站或涉及黑客程序的活动方面可能是安全的，但你不应该完全依赖它们。特别是使用免费代理时。经验丰富的黑客使用如 Sock5 等安全的代理。如果你做了一些琐碎的事情，并且有搜查令搜查代理日志，那么由于法律执法部门的压力，代理提供商可能会提供你的详情。

# 第五章

## LINUX 中的日志系统

在上一个章节中，我们讨论了在互联网上保持安全和匿名的方法。作为一个黑客，隐藏在黑暗中并获取敏感信息通常是你的主准则。作为同类的安全爱好者，我建议你对 Linux 发行版中不同的日志系统保持良好的掌握，以帮助你理解你尝试访问的系统中到底发生了什么。此外，删除可能泄露你身份的敏感日志文件也是黑客需要掌握的一项任务。为了帮助你理解组成日志文件的不同日志系统守护进程（daemons），我们通过大量的示例介绍了本章。跟随操作！

### 什么是日志文件？

日志文件是关于操作系统中发生的所有重要事件的信息。像 Windows 和 macOS 等传统操作系统除非你有特殊的管理员权限，否则无法访问日志文件。Linux 提供了系统中存在的所有错误和警告的详细信息。某些日志文件即使没有 root 权限也可以访问。然而，所有创建的日志文件只有在你拥有 root 权限的情况下才能被修改或删除。

### 日志如何帮助黑客？

想象日志文件通往目的地（你的 IP 地址/其他敏感信息）的路径。每当新用户访问系统时，Linux 系统会自动注册其所有信息，并在程序之后才会建立连接。这一安全功能对于黑客来说可能是一场噩梦，因为取证爱好者可以提取所有信息/代理地址并进行进一步调查。

为了确保你每次访问系统时都不会被追踪，你应该前往日志位置并永久删除它们。管理员可以发现日志文件缺失，但永远不知道是谁干的。删除日志文件会引起怀疑，但不会有确认。

### 日志如何帮助系统管理员？

系统管理员和数据库专家经常在职业生活中对不同的 Linux 系统进行故障排除。一些管理员使用远程解决问题。为了让管理员理解问题是什么，他需要对日志文件的确定访问权限。日志文件将帮助他们理解问题所在。如果没有日志文件，手动检查问题所在之处将是一项艰巨的任务。

日志是如何创建的？

Linux 中的日志文件通常使用名为 `syslogd` 的特定守护进程创建。

但是，什么是守护进程（daemon）？

守护进程是一种在系统重启时自动启动的系统服务。它们是无论安装了什么软件都会运行的首批进程。它们被称为默认系统进程。`syslogd` 是一个为运行中的每个事件创建日志文件的特定系统进程。

此外，重要的是记住每个 Linux 发行版都有它自己的方式创建日志文件。例如，Debian 系统使用 'syslog' 创建日志文件。其他操作系统如 Arch 和 Redhat 根据用例使用不同的日志系统。日志系统的选择取决于使用的发行版。Debian 系统是 Linux 世界的窗口，因此轻量级且可以作为日常驱动。这就是为什么 Debian 使用简单的日志系统如 'rsyslog' 的原因。

复杂的操作系统如用于服务器管理的 Red Linux 在日志方面需要许多额外因素，因为它们经常用于故障排除。

### 如何理解和分析日志文件？

在本节中，我们将提供一个简单的程序来分析 Debian 系统中 syslog 守护进程创建的日志文件。你唯一需要的准备工作是安装你喜欢的文本编辑器来读取日志文件。

安装文本编辑器后，进入终端并输入以下命令。

```
root@server : locate rsyslog own
```

此默认命令搜索 Linux 系统中的所有文件。确保你已经使用 `su` 命令获得了 root 权限，这样命令将搜索所有系统文件。几秒钟后输出信息将显示日志文件所在的所有位置。

例如：

```
/etc/ home/example.rsyslog
```

这就是我们通过上述命令找到的文件格式。选择要分析的日志文件后，前往该位置并使用你喜欢的文本编辑器打开它。

现在，你将看到每当使用 `rsyslog` 守护进程创建日志文件时存在的默认代码。不要编辑任何内容，直接进入日志末尾，你会发现一个标题为“RULES”的区域，如下所示。

格式如下：

Cron, daemon, kern 和 user。也可以通过在它们之间使用逗号来使用其中任何一个。

#### b) priority（优先级）

这是一个标识符，说明使用正在运行的守护进程创建什么类型的日志文件。有不同的优先级操作，例如根据你的喜创建调试文件、错误文件或警报文件。

# 什么是面向对象对象和类？

### 通用的什么是 Shell（壳）？

Linux 使用硬件设备等系统资源与软件内核进行交互，以确保所有功能都能完美运行。Linux 内核是复杂的，并为几乎每个创建的驱动程序提供用例。用户与内核之间的所有通信都在称为 shell 的命令行环境中进行。

在 Linux 中，shell 就像是用户和操作系统之间的一座交叉桥。你输入的任何内容都会被发送到 Linux 内核。然而，请记住，Linux 内核只对它认为正确的 shell 命令做出响应。它不会执行任何可能关闭系统或完全抹除系统的恶意破坏性命令。如果你拥有 root 权限并在 shell 环境下执行命令，请务必小心，因为任何错误的命令都可能严重搞乱你的系统。

### Shell 的优势是什么？

你可能经常听过 shell，并应该困惑为什么它们在 Linux 系统中如此特殊。它们在系统管理员（Sysadmins）和黑客之间的流行，是因为它们不像占用大量资源的 GUI 应用程序和安装程序那样产生非常少的杂乱。你可能觉得在日常普通 PC 时这并不重要，因为维护服务器和数据库并不断监控它们不崩溃是一项微不足道的任务。

这正是 shell 以其极低的系统占用大显身手的地方。它用非常少的代码和时间执行复杂的任务。此外，应该记住 shell 可以同时运行在 Linux 和 UNIX 操作系统上。由于 macOS 是基于 UNIX 构建的，因此你可以在上面运行所有的 Linux shell 代码。对于 Windows，还有其他沙箱替代方案可以在 Windows 内部创建 shell 环境。

shell 的一些著名示例包括 Korn shell、C shell 和 Bourne-again shell (`Bash`)。在本章的下一节中，我们将通过几个示例讨论 bash shell 的基础。

### 如何编写一个简单的 Bash 脚本？

如前所述，Bash 脚本可以用于与内核进行交互。它像一个解释器一样执行所编写的 shell 代码。Bash 和其他 shell 解释器的区别在于，它有自己的内置命令，这使得执行过程变得简单且耗时更短。

I) 首先，我们将讨论以 Shebang (`#!`) 符号开头的行。如果一个文本文件以 Shebang 命令开头，那么直接意味着该文件正在请求 Linux 内核查找可以作为解释器运行此程序的系统文件。

这里，提供了 `/bin/bash` 作为解释器位置。所以现在 Linux 知道上述文本文件需要作为 Bourne-again shell 运行。

- iii) 第三行紧跟在 `#` 之后被称为注释（comment）。注释通常由程序员用来让其他人理解他们写了什么。然而，重要的是，注释中写的所有内容都将被 bash 解释器忽略，以节省编译时间和系统资源。

### 如何运行 Bash 脚本

Linux 尊重用户隐私，并对运行可能损害系统的程序（如 bash 脚本）有严格限制。即使你是文件的所有者，如果没有某些调整，你被允许运行 bash 程序，这些调整将确认你已经意识到如果搞乱任何系统文件可能发生的风险。但这正是我们这些黑客要做的，不是吗？承担风险，搞乱系统并修复它们。



在这里，`./` 表示只在当前目录下搜索指定的文件。这是一个良好的习惯，它减少了搜索时间，因此被所有 Linux 系统管理员建议在终端中运行 Bourne-again shell。

### 什么是内置命令？

内置命令是在安装软件或 shell 接口时自带的命令。例如，当我们安装一个 Python 解释器时，可以在 shell 中运行 `py` 命令。换句话说，`py` 是因为安装了 Python 而自带的内置命令。

同样，bash 也带有这些命令，由于它们在与内核资源通信方面的效率很高，其中一些命令被 Linux 操作系统广泛使用。

### I) echo

我们已经讨论过这个命令，并在我们的某些程序中也使用了它。Echo 命令就像编程语言中的 `print` 命令。它所做的只是在屏幕上显示输出。它可以通过 `$` 符号获取变量或函数实例。

这是一个示例：

```
Echo “This can display output on computer screen"
```

# 输出:

This can display output on computer screen

#### ii) cd

这是由 bash 开发的著名 Linux 命令之一。它的作用是更改用户在终端中的目录。在执行操作时，你可能需要更改目录，因为某些程序只会在当前目录中运行。

这是一个示例：

```
Cd /bin/home
```

在 shell 接口中执行上述命令后，你将进入该特定目录。你现在可以使用 `ls` 来检查当前目录下的所有文件。

#### iii) pwd

请记住你也可以使用 `pwd` 命令查找你所在当前目录的信息。

这是一个命令：

```
root@ server : pwd
```

这将提供关于你所处目录的一系列信息，以及文件数量和目录位置。

#### iv) 进程管理命令

我们都知道在 Linux 中一切都作为进程运行。有后台进程和前台进程，它们可以提高可用系统配置的准确性。Bash 有一些内置命令可以帮助用户更好地组织可用进程或刚创建的进程。

#### A) bg

这个内置命令让你尝试启动的软件或进程在后台运行，而不是在前台并消耗系统资源。

这是一个示例：

```
root@server : bg vmware
// This starts the software in background
```

作为一名黑客，你需要意识到哪些软件正在后台运行，因为防病毒软件是以后台进程运行的。此外，当你向目标系统植入漏洞时，你需要确保它不会被系统管理员发现。

#### B) exec

这是一个内置的 bash 命令，将软件作为新进程启动。有时即使在软件或工具已经打开的情况下，你也可以使用此命令打开该软件的新实例。

这是一个命令：

```
root@server : exec vmware config
// This starts the config file of Vmware software as a new process
```

你可以通过以下命令确认是否创建了新进程：

```
root@server : pid
```

使用 `grep` 命令在此处检查 `vmware`，查看是否有两个进程同时运行。

#### C) wait

通常情况下，进程会自动启动，并在系统资源允许时结束。有时进程甚至会卡住，并在它们需要之前就结束。有时，你可以使用 `wait` 命令强制让软件等待进程完成。

这是一个示例：

```
root@server : wait vmware
```

#### V) umask

这个内置命令用于更改已存在的默认权限。我们通常可以使用 `chmod` 来赋予可执行权限，但 `umask` 要复杂得多，可以在需要时执行复杂的更改。

这是一个命令：

```
root@server : umask 777 bash.sh
// This makes the files as executable even though by default it has just read and write permissions.
```

#### Vi) 变量的内置命令

变量是编程语言用于指向计算机内存地址的内存位置。它们简单且对于脚本的高效运行是必要的。Bash 提供了两个简单的命令来调整它们的属性。

#### A) read-only

这是一个命令：



```
readonly first
```

#### B) export

同样，当你在计算机程序或脚本文件中创建变量或函数时，它们无法被其他文件使用。在其他文件中使用这些组件唯一的方法是使用可用的 `export` 命令。

这是一个命令：

```
export first
```

### 脚本文件的编写格式要求有哪些？

首先，脚本文件的第一行需要 shebang (`#!`) 符号，它用于指定脚本的解释器，例如 `#!/bin/bash`、`#!/bin/sh`、`#!/usr/bin/env python`。

这一行由 `#` 注释，因此它不会作为命令执行，但计算机通过这一注释信息知道应该使用哪个解释器来解释整个脚本文件中所有有效代码（在此例中解释器是 `/bin/bash`）。

其次，脚本文件使用 `#` 或 `<<` 符号来实现单行或多行注释。需要理解的是，注释的关键字或代码不会被执行，注释是给人类看的！

通过阅读注释，我们可以快速理解脚本文件的功能、版本和作者联系信息。核心功能是解释脚本文件或代码块的功能。最后，最重要的内容是代码部分。

通常情况下，一行代码就是一个命令，脚本文件中所有有效代码命令都是从上到下执行的。

让我们编写第一个脚本文件，并看看脚本文件的组成。

```
#!/bin/bash
<< COMMENT

> 这是一个注释
( 大多是多行的)
为 Linux Hackers 编写
COMMENT
### 现在我们将展示一个 echo 命令
echo "This is an example program"
```

注意，`<<` 符号后面的关键字可以是任何字符串，但在结束注释时必须使用相同的关键字。如果你从 `<< ABC` 开始注释，那么在结束注释信息时也必须使用 `ABC`（字母大小写敏感）。

在本章的下一节中，我们将简要讨论 shell 或确切说是任何脚本文件的各种执行模式。

### 脚本文件的各种执行模式

写完脚本文件后，下一步是执行它。执行脚本文件有多种方法，包括需要执行权限的、不需要权限的、打开子进程的以及不打开子进程的。我们将通过示例解释这些每种情况。

- 1) 如果脚本文件本身没有执行权限

在这种情况下，无法直接执行默认脚本，但可以使用 `bash` 或 `sh` 等解释器将脚本文件作为参数（读取脚本文件的内容）来执行脚本。

以下是命令：

```
root@server : ./sample.sh
// 将显示错误，因为没有权限
root@server : bash sample.sh
root@server : sh sample.sh
 其他 其他执行方式但不会报错
```

从上述三个命令的输出信息中，我们可以看到在没有执行权限的情况下执行当前目录下的 `sample.sh` 脚本时，会出现错误信息；而使用 `bash` 和 `sh` 作为参数执行 `sample.sh` 脚本，将显示正确的输出信息 "This is a sample"。

- 2) 如果脚本文件具有执行权限

可以通过 `chmod` 命令为脚本文件分配执行权限。一旦脚本文件拥有执行权限，就可以使用绝对路径或相对路径执行它。

以下示例假设脚本文件的绝对路径为 `/root/sample.sh`，执行脚本的效果如下。

以下是命令：

```
root@server : chmod +x sample.sh
// 这将赋予执行权限
root@server : ./sample.sh
// 将显示输出且不会报错
```

- 3) 如何打开子进程进行执行

关于决定是否打开子进程，我们首先需要理解什么是子进程。通常，我们可以通过 `ptree` 命令查看进程树来理解进程之间的关系。

以下是命令：

```
root@sample : pstree
```

从上述命令输出中，我们可以看到计算机启动的第一个进程是 `systemd`，在该进程下启动了 N 个子进程，例如 `NetworkManager`、`atd`、`chronyd` 和 `sshd`，它们都是 `systemd` 的子进程。在 `sshd` 进程下，有两个 `sshd` 子进程。在这两个 `sshd` 子进程下，启动了 `bash` 解释器子进程，并在其中一个 `bash` 进程执行了 `pstree` 命令。

你的系统可能有其他不同的子进程。你只需要使用 `ptree` 命令进行验证。正如我们刚刚所说的，无论是直接执行脚本还是使用 `bash` 或 `sh` 等解释器执行，都会启动子进程。

下面的示例通过脚本文件演示了效果。

首先，打开命令行终端，在终端中编写脚本文件并执行它。然后打开另一个命令行终端，在该终端中通过 `ptree` 命令观察进程树。

以下是命令：

```
// sleep.sh
#!/bin/bash
Sleep 5000
root@server :chmod +x sleep.sh
root@server :./sleep.sh
root@server : pstree
```

从输出可以看出，`bash` 终端下打开了一个子进程脚本文件，并通过脚本执行了 `sleep` 命令。回到第一个终端，使用 `Ctrl+C` 终止之前的脚本文件，然后再次使用 `bash` 命令执行。

```
root@server : bash sleep.sh
```

最后，在第二个终端上运行 `ptree` 命令以观察结果。结果相似，在 `bash` 进程下打开了一个子进程。

- 4) 不带子进程的执行模式

接下来，让我们看看无子进程的执行模式。

与之前的实验类似，我们需要打开两个命令行终端。首先打开第一个终端，这次使用 `source` 或 `.` (点) 命令执行脚本文件。

```
root@server : .sleep
root@server : bash sleep
root@server : source sleep.sh
```

这里有一种使用各种高级 shell 输出技术显示经典“hello world”的方法。


### 2) 使用 printf 命令扩展知识并创建脚本菜单。

在 Linux 系统中，除了 `echo` 命令，你也可以使用 `printf` 命令来实现相同的效果。

功能描述：

`printf` 命令可以打印格式化数据。

`printf` 命令的语法格式如下：

```
printf "details"
```

注意：通用 `printf` 命令的参数是需要作为输出的内容。常用的格式字符串和函数描述如所示，以便你更好地理解你正在处理的内容。在下一节中，我们将通过应用案例进一步扩展我们的知识。

#### 应用案例：

该命令的格式 `%8d` 将打印宽度设置为 8，并以右对齐的方式显示整数 `64`。

```
root@server : printf "%8d" 64
// 输出将为 64，宽度为 8
```

注意，该命令的输出信息 64 前面有五个空格。5 个空格 + 3 个数字合共 8 个字符宽。如果你需要左对齐，可以使用 `%-8d` 来实现效果，例如下面的命令。

```
root@server : printf "%-8d" 44
```

注意，`printf` 命令输出信息后，默认不换行。如果你需要换行，可以使用 `\n` 命令。

为了更好地观察左右对齐效果，以下示例将打印两个符号来确定位置。

```
root@server : printf " |%-11d \n" 64
```

左对齐输出 64，输出内容占用 11 个字符宽，占用 2 个字符宽，后面跟着 8 个空格。

默认 `printf` 命令输出后不会换行，但可以使用 `\n` 命令符号在输出后换行。

这显示了 10 的八进制值，从八进制 12 转换为十进制正好是 10。`x11` 代表十六进制 11，`printf` 命令将十六进制 11 转换为十进制整数输出 `17`。`01` 代表八进制 11，`printf` 命令将八进制 11 转换为十进制整数输出 `9`。

```
root@server : printf "%d \n" 17.011
```

当使用 `\d` 打印大整数时，系统提示超出范围，且可以打印的最大数字是 927983298。

下一节中，我们将讨论使用目前流行的 `read` 命令来获取可用信息。

有时在 Linux 系统中，我们需要完成一项复杂的任务，但某个命令可能无法完成该任务。此时，我们需要将两个或多个命令结合在一起来完成此类任务。

正如 Linux 文档所述，类似于输送水的管道，Linux 系统的管道可以将命令 1 的输出结果（数据）存储到管道中，然后让命令 2 从管道中读取数据并进一步处理。

在下一节中，我们将讨论关于向可用函数提供输出和输入的高级能力。

#### a) who

`who` 命令可以帮助我们检查哪些账户在什么时候登录了计算机。然而，当计算机上有大量的登录信息时，手动记录登录次数是不方便的。

Linux 系统中的 `wc` 命令可以统计行数，但 `wc` 命令需要数据。如果你提供几行数据，该命令会自动统计数据的行数。我们可以使用管道将 `who` 和 `wc` 命令结合。

```
root@server : who
```

#### b) ss

另一个例子是 `ss` 命令可以查看 Linux 系统所有服务监听的端口列表。然而，`ss` 命令本身没有灵活的过滤功能，而 `grep` 命令具有强大且灵活的过滤功能，因此这两个命令可以通过管道结合使用。显然，有很多数据没有经过 `grep` 命令的过滤，这不够清晰。

在 `ss` 命令将其输出数据存储到管道后，`grep` 命令再次从管道中读取数据，并过滤出包含 `sshd` 的许多数据，最终的输出结果只有两行数据。

```
root@server : ss
```

通过这种方式，我们可以更简单、更清晰地看到我们需要的数据。某些命令是特殊的，例如我们之前使用的 `passwd` 命令，它用于修改系统账户密码，但该命令默认只能从键盘读取密码。

如果你想让命令从管道中读取数据并将其作为密码，你需要使用 `--stdin` 选项。所示，`echo` 命令默认会在屏幕上显示输出结果。在建立管道后，`echo` 命令可以将输出的 `123456` 存储在管道中，而 `passwd` 则可以从管道中读取 `123456` 来修改系统账户 'sample' 的密码。

## 第三章：在 Shell 中重定向输入和输出

在上一章中，我们对 Shell 脚本中输入输出语句的重要性及其实现进行了很好的介绍。在本章中，我们将通过大量的示例讨论高级专家细节，例如输入输出语句的重定向。请继续阅读！

### 为什么重定向在 Shell 中很重要？

在大多数系统中，输出信息通常默认显示在屏幕上，而标准输入信息通过键盘获取。

然而，在编写脚本时，我们不能或不想让某些命令的输出信息显示在屏幕上（当执行脚本时，大量的输出信息会让用户感到困惑）。它还消耗了比需要的系统资源。

此时由于这个原因，最好将输出信息临时写入文件，然后在以后需要时读取文件并提取所需的信息。默认的标准输入信息也存在类似的问题。当我们使用 `mail` 命令在 Linux 系统发送邮件时，程序需要读取邮件的文本。

默认情况下，来自键盘的输入数据被用文本，会导致脚本进入交互模式，因为读取键盘信息需要手动输入。

例如，如果此时可以更改默认输入模式，不再从键盘读取数据，而是从预先准备的文件读取数据，这样邮件程序就可以在需要时自动读取文件内容并自动发送邮件，而无需手动交互。通过这样，脚本的自动化效果将带来更好的体验。

### Linux 系统中的输出

在 Linux 中，输出可以分为标准输出和标准错误输出。标准输出的文件描述符是 `1`，标准错误输出的文件描述符是 `2`。而输入文件描述符为 `0`。

如果你想更改输出信息的方向，可以使用 `>` 或 `>>` 符号将输出信息重定向到文件。使用 `1>` 将标准输出信息重定向到文件（`1` 可以省略不写，默认值为 `1`），或使用 `2>>` 将错误输出信息重定向到文件。

使用 `>>` 符号将输出信息重定向到文件。如果文件不存在，系统会自动创建文件。如果文件已存在，系统会将输出信息追加到文件原始信息的末尾。

在接下来的示例中，`echo` 命令本会在屏幕上显示数据，但使用了重定向，输出信息可以导出到文件中。

```
root@server : echo "This is a sample" > sample.txt
// 这将文件导出到名为 sample 的文本文件中
```

之前的 `echo` 命令不会给出错误信息。然而，当使用 `ls` 命令时，最终输出信息根据文件是否存在被分为标准输出和错误输出。此时，如果我们只使用 `>` 或 `>>`，我们就无法将错误信息重定向并导出到文件中。

这里我们需要使用 `2>` 或 `2>>` 来重定向错误输出。

如果我们想将标准输出和错误输出都重定向到同一个文件，可以使用 `2>&1`。例如，`ls /root > file 2>&1` 将标准输出和错误输出都重定向到 `file`。

如果我们想将标准输出重定向到一个文件，将错误输出重定向到另一个文件，可以使用 `>` 和 `2>`。例如，`ls /root > file1 2> file2` 将标准输出重定向到 `file1`，错误输出重定向到 `file2`。

如果我们想将输出追加到文件，可以使用 `>>` 和 `>>1`。例如，`ls /root >> file 2>>1` 将标准输出和错误输出都追加到 `file`。

如果我们想丢弃命令的输出，可以将其重定向到 `/dev/null`。例如，`ls /root > /dev/null` 将丢弃标准输出，而 `ls /root 2> /dev/null` 将丢弃错误输出。

提前进行，好吗？

你可以使用 `<<` 符号来实现相同的效果。这样，脚本就可以独立运行，而不依赖于邮件内容文件。使用 `<<` 符号将数据内容重定向到上一个命令作为该命令的输入。

```bash
root@server : mail -s warning << EOF
```

`<<` 符号（也称为 Here Document）意味着你需要的内容在这里。让我们来看一个例子，`cat` 通过 Here Document 读取数据，并通过输出重定向将数据导出到文件。

以下是该脚本：

```bash
#!/bin/bash
Mail -s error
这是我们想要发送的内容
<< fax.txt
### 在输入重定向后结束程序
```

在 Linux 系统中，`fdisk` 命令通常用于划分磁盘分区，但该命令是交互式的，现在我们需要编写脚本来实现自动分区、自动格式化、自动挂载分区等。为了解决这个问题，也可以使用 Here Document。让我们来编写这样一个自动分区脚本。

警告：

此脚本将删除磁盘上的所有数据，所有数据将丢失！

以下是该脚本：

```bash
#!/bin/bash
mkfs.xfs /dev/sdb
### 这用于格式化
```

为了提高编写脚本时代码的可读性，通常需要对代码添加额外的缩进。然而，当使用 `<<` 将数据导入程序时，如果内容中有缩进，它将连同缩进内容一起传递给程序。

此时，Tab 键仅起缩进作用，我们不希望将其传递给程序。如有必要，可以使用 `<<-` 符号重定向输入，这样系统将忽略 `EOF` 之前的所有数据内容和 Tab 键。这样，只有 Tab 键可以被忽略，如果 Here Document 的主体内容是用空格缩进的，它将无效。

```bash
cat << EOF
```

## 第四章

## SHELL 脚本编写中的不同引号

编程语言经常使用引号来显示程序中的行结束，或用于确定编程语言的缩进原则。在 Shell 中，我们也使用不同类型的引号来提高程序的效率。在本章中，我们将通过示例描述其中一些用法。请跟随学习！

### 各种引号的正确使用姿势

1) 单引号和双引号

在编写脚本时，我们经常需要引号。Shell 支持各种引号，例如 `"`（双引号）、`''`（单引号）、`` ` ``（反引号）和 `\`（转义符号）。

以下是一些命令：

```bash
root@server : touch x y z
### 这是没有使用引号的
root@server : touch "x y z"
### 这是使用了引号
```

### 在什么情况下会使用这么多符号？

让我们来看几个案例。从这里可以看出，双引号的作用是引用一个整体，计算机会将引号内的所有内容视为一个整体。如果不使用双引号，就会创建三个不同的文件。当以后需要删除文件时，会发生类似的问题。因此，我们需要使用第一个命令而不是第二个命令，因为它们是独立的文件。

```bash
root@server : rm -rf x y z
### 这将删除创建的所有三个文件
root@server : rm y z
# 这将显示错误
```

此外，我们应该分析这里有多少个文件？文件名到底是什么？

```bash
root@server : " x y z"
```

因为这里没有使用双引号，系统理解为需要删除 X、Y 和 Z 三三个文件，但实际上系统中只有一个名为“x y z”的文件，空格也是文件名的一部分。

在下一节中，我们将进一步讨论在实际中如何删除文件。

### 如何删除文件？

文件通常可以通过双引号成功删除。在 Linux 系统中，除了双引号外，单引号也可以引用一个整体。同时，单引号还有另一个功能，即特殊符号可以被屏蔽（特殊符号的特殊含义可以屏蔽并转换为字符表面的名称）。

```bash
root@server : echo #
root@server : echo '####'
```

上述两个命令没有特殊符号，因此使用双引号或单引号的效果相同。然而，当存在特殊符号时，单引号和双引号不能互换，如上面解释的示例所示。

在第一个 Shell 中，`#` 符号具有特殊含义，是一个注释符号。

`#` 符号及其内容将被程序解释为注释而不会被执行。此命令原本想在屏幕上输出一个 `#` 符号，但实际输出结果是空行。

如果我们想输出这个 `#` 符号，可以像第二个命令那样使用单引号来屏蔽 `#` 符号的特殊含义。除了 Shell 之外，`$` 具有提取变量值的特殊含义，当我们需要使用它时，使用双引号。

```bash
root@server : echo $$
root@server : echo '$$'
```

### 2) 命令替换

最后，我们将解释命令替换（反引号）。它也是一种命令替换替换，会将命令替换为命令的输出结果。让我们来看下面的示例。

```bash
root@server : ping -c2 $(url)
```

反引号通常用于封装命令，以便将其输出作为参数使用。然而，它们也有一些缺陷，例如难以阅读且不支持嵌套。为了解决这些问题，我们使用 `$()` 语法。

在定义变量时，变量名只能使用字母（包括大小写）、数字和下划线（_）的组合。并且不能以数字开头。此外，在工作中定义变量名时，最好使用易于理解的单词。记住不要使用随机字符来命名变量。不规则的变量名会使脚本的可读性变得糟糕。

需要注意的是，定义变量时，等号两边不应该有空格。

#### 变量命名提示：

当你需要读取变量值时，需要在变量名之前添加美元符号 `$`。如果变量名与其他非变量字符混合，则需要用 `{}` 隔开。最后，如果你需要取消一个变量，可以使用 `unset` 命令将其删除。

示例：

```
root@server : test=567
root@server : $test
```

输出

```
567
```

此时，你需要使用 `$` 将变量名与其他字符隔开。

虽然这三个命令没有使用 `$` 将变量名与其他字符隔开，但最终的返回值不是空的。由于 Shell 变量名只能由字母、数字和下划线组成，无法包含特殊符号（如横线、冒号、空格等），因此系统不会将特殊符号视为变量名的一部分，但会理解为变量名后面跟着的是与变量名无关的其他字符串。

让我们来看一个简单的变量使用案例。

在下一节中，我们将分析一个脚本来深入理解这些变量带来的复杂性。

#### 脚本案例分析如下：

```bash
#!/bin/bash
localip=$(ifconfig | grep -eth0)
mem=$(uptime | grep -m)
cpu=$(uptime | grep -u)
echo " The IP address is $localip"
echo " The memory that cpu offers $mem"
echo " The cpu name is $cpu"
```

此脚本中定义了三个变量，它们都是命令的返回结果，因此变量值在每次执行脚本时可能会发生。然而，无论变量值如何变化，脚本都能在最后正常输出这些变量值。

第一个变量 `localip` 存储本地 `eth0` 网卡的 IP 地址。这里假设系统中存在 `eth0` 网卡且已配置了 IP 地址。

第二个变量 `mem` 存储本地内存的剩余容量。

第三个变量 `cpu` 存储本地 CPU 在 15 分钟内的平均负载。语句中使用了 `tr` 和 `cut` 命令来获取这三个变量值，并在 `tr -s` 之后加了一个空格，这用于将管道传输的数据中多个连续的空格合并为一个空格。

如果在 `-s` 选项后使用引号来引用其他字符，效果是相同的，可以将多个特定的字符合并为一个字符。使用 `cut` 命令可以帮助我们获取特定的数据列（通过 `-f` 选项指定要获取的列数），并使用 `-d` 选项设置列的分隔符字符。

#### 系统变量

上面介绍了用户定义变量，接下来我们介绍系统预设变量。系统预设变量顾名名，是系统已经预设好的变量，无需用户自行定义即可直接使用。

系统默认变量基本上使用大写字母或某些特殊符号作为变量名。

预设变量可以细分为环境变量、位置变量、预定义变量和用户定义变量。

在编写脚本时，我们可以在适当的地方应用合适的变量，因此在这里不再详述。通过编写脚本案例并调用这些系统预设变量来检查执行效果。

### 为什么系统变量是必要的？

虽然自定义变量可以帮助我们创建程序来定义需要做什么，但后者可以帮助我们创建使用系统环境变量的程序。系统变量用于内存磁盘值、根分区，有时用于关于时间、内存大小等数值的细微系统细节。

以下是一些经常使用的最重要的系统变量。

- a) UID

这是一个系统变量，用于显示当前正在使用系统的用户 ID。如果作为 root 系统使用，则将显示默认值。

- B) PWD

这是一个系统变量，用于为 Linux 中的各种文件和网络系统创建密码。例如，我们可以使用 `umask` 命令为文件系统创建密码。

- C) RANDOM

这是一个系统变量，利用随机机制按我们的意愿输出。我们可以显示数字、文本文件，有时甚至是随机路径。你只需要在 Shell 程序中调用 `RANDOM` 变量即可。

- D) PATH

这是一个系统变量，用于讨论我们正在使用的当前路径。我们也可以选择路径地址并使用 `echo` 命令显示它们以供进一步参考。

- E) LANG

这是一个系统变量，可以打印以不同语言的所有系统命令。例如，你可以使用 `FR` 将所有用英语编写的系统命令替换为法国法语。当你需要将 Shell 程序发布到不以英语作为主要语言的国家时，特别推荐使用这些系统变量。

### Shell 编程中的操作符

在上一章中，我们讨论了过滤，并提供了示例来帮助理解 Linux 中如何通过 `grep` 命令实现过滤工作。现在，我们需要在这些命令中使用操作符来进一步提高 Shell 代码的质量。

### 什么是操作符？

我们都知道数学运算，如加、减、乘、除，这些操作在编程语言中广泛用于算术计算以及编写搜索算法等其他编程场景。即使在 Shell 编程中，我们也可以使用操作符来提高代码质量。

#### 各种算术操作

Shell 支持各种算术操作。

你可以使用 `$((expression))` 和 `let expression` 来执行整数算术操作。注意，这些命令无法执行小数运算。使用 `bc` 命令来执行小数运算。

下面，根据上述操作符号并在结合特定命令时，通过 `$(())` 和 `$[]` 演示了实际操作的效果，两者都支持变量的计算。

以下是命令：

```
root@server : echo $(( 2 +4))
// 结果是 6
```

接下来，我们将通过内置命令 `let` 学习这种算术操作用例。注意，当使用 `let` 命令进行计算时，操作结果默认不会作为输出给出。通常，需要将操作结果赋值给变量，并通过变量查看结果。

此外，当使用 `let` 命令计算变量时，不需要在变量名之前添加 `$` 符号。

最后，注意当使用 `++x` 或 `-x` 操作时，`x++` 和 `xxx` 的结果是不同的，`x-` 和 `-x` 的结果也是不同的。`x++` 指调用 x 并给 x 加 1，`++x` 指先给 x 加 1 再调用 x。`x-` 是先调用 x 然后从 x 减 1，而 `x--` 是先从 x 减 1 然后。

Bash 仅对整数支持四种运算，不支持小数运算。如果我们需要对任意精度的小数进行操作，甚至在脚本中编写计算函数，可以使用 `bc` 计算器来实现。

### 什么是哈希 (HASH)？

“Hash”允许 Bash 记录已执行命令的 `PATH` 并将其保存在内存哈希表中，这样下次执行该命令时，就不需要通过路径变量搜索命令路径了，这通常会提高效率。

但有时程序的路径会发生变化，因为 Hash 记录的存在会导致命令执行失败。可以看出之前执行的外部命令具有特定的记录信息，而 `hits` 代表命中次数，即系统通过读取哈希表定位命令路径的次数。

```
root@server : hash sample.txt
```

通常情况下上述情况没有问题。但是，如果我们把 `ip` 命令从 `/usr/bin/` 目录移动到 `/bin/` 目录，系统仍会根据哈希表中记录的位置执行命令，导致找不到 `ip` 程序。

```
root@server : hash -d
root@server : hash -r
```

我们可以使用 `hash -d` 删除特定的记录，使用 `hash -r` 清除整个哈希表，或者使用 `set +h` 直接禁用哈希表。这些方法可以解决类似的问题。Hash 通过设置 `histexpand` 属性支持使用感叹号调用。

```
root@server : histexpand
```

历史命令，`yum` 可以直接调用历史中的最后一个命令。默认情况下，当我们使用重定向符号如 `>>` 时，文件会被覆盖，这可能导致数据丢失。


### 在虚拟机中安装 KALI LINUX

这就是使用虚拟机的原因。它们不仅易于安装，还能提供很多功能。在虚拟机中安装 Kali Linux 之前，让我们了解一下虚拟机。

### 什么是虚拟机？

虚拟机是功能完备的操作系统但在沙箱中运行，而不是直接与硬件通信。虽然与原生硬件性能相比，它们的功能可能较少，但它们仍然非常快速且易用。它们提供了传统方式无法实现的功能。

### 什么是最好的虚拟机软件？

虚拟机软件并不多。其中，Virtual box 和 VMware 广受推荐。在本书中我们将使用 Virtual box，因为它易于使用而且是开源软件。加分项！

### 推荐黑客使用虚拟机吗？

虚拟机指的是具有完整硬件系统功能的完整计算机系统，它由软件模拟并在完全隔离的环境中运行。作为一名黑客，没有什么可以像虚拟机那样对系统文件进行实验。黑客在学习系统如何构建的同时会不断破坏东西。如果你破坏了原生的宿主机系统，可能会给你带来头疼，而且通常不建议这样做。你既能破坏东西又能不破坏任何工作文件的唯一方法就是使用虚拟机客机操作系统。

虚拟机会生成现有操作系统的全新镜像。如今，Linux 发行版开发人员通常都会发布虚拟机文件。它具有与真实操作系统完全相同的功能。进入虚拟机后，所有操作都可以在这个全新的独立系统中自由进行。

### 使用虚拟机技术的优势是什么？

几乎所有企业都使用虚拟化技术来维护其服务和服务。例如，著名的企业软件 Docker 也使用虚拟化技术来提供其服务。在本节中，我们将详细讨论虚拟机的优势。

#### 它降低成本

如果你想在没有虚拟机的计算机上安装 Linux 和 Windows 系统，有两种方法。一种是安装多个硬盘，每个配合操作系统使用。这种方法的缺点是成本较高。

第二种方法是在一个硬盘上安装双系统。这种方法的缺点是安全性不够，因为系统盘的 MBR（主引导记录）是操作系统的必经之路，而 Windows 更加具有主导性。

每次重新安装系统时，几个安装的系统可能会同时崩溃。使用虚拟机软件既省钱又安全。因此，对于新手来说，通过虚拟机学习 Linux 是再不过不过了。

#### 安全且方便

在虚拟机上安装好 Linux 系统后，你不需要担心格式化硬盘。你甚至可以随心所欲地设置和更改虚拟系统的设置。你可以格式化虚拟硬盘，也可以使用 VirtualBox 的高级功能对虚拟系统硬盘进行重新分区。

由于虚拟机软件运行在真实系统上，对虚拟机系统进行的任何操作实际上都是对软件进行的操作。它还可以轻松地使用硬盘或 U 盘导入到其他 Linux 或 Windows 系统中。它非常方便，而且通过加密选项为你提供了大量的隐私保护。对于黑客来说，这确实是一个福音。

#### 简单高效

虚拟机模拟的 Linux 系统与真实的 Linux 系统完全相同。现在，各公司的专用 Linux 服务器通常不会允许新手操作，而测试用的 Linux 服务器通常比较稀缺。如果你在电脑上安装一个虚拟 Linux 系统，你可以随心所欲地学习和测试，不受任何环境的影响。

### 虚拟机运行环境和硬件要求

#### 1. 运行环境

流行的虚拟机软件包括 VMware 和 VirtualBox，它们都有 Windows 和 Linux 版本，也可以用于 macOS 操作系统。

也就是说，它们可以安装在 Windows 和 Linux 平台上：Windows、Linux、UNIX 等可以在 Windows 平台下虚拟化。同样，Windows、Linux、UNIX 等电脑也可以在 Linux 平台上虚拟化。但请记住，根据 Apple 的 EULA（用户许可协议），你只能在苹果硬件上虚拟化 macOS。

注意：

运行虚拟机软件的操作系统称为主机操作系统（Host OS），运行虚拟机中的操作系统称为虚拟机操作系统（Guest OS）。

#### 2. 硬件要求

虚拟机软件将两个或多个计算机的任务整合到一个计算机中。因此，对硬件的要求较高，主要涉及内存、硬盘和 CPU。

内存必须足够大，因为每个虚拟机都会占用一定量的内存资源，内存总量等于每个虚拟系统内存之和。幸运的是现在内存非常便宜，所以这不是问题。同样，硬盘空间也会被每个虚拟机占用。CPU 现在已经发展到多核阶段，硬盘价格也不应该是问题。

## VIRTUAL BOX 的安装与使用

### 1. VirtualBox 软件概述

VirtualBox 是一款开源虚拟机软件。它最初由德国 Innotek 公司开发，由 Sun Microsystems 生成的软件使用 Qt 编写。在 Sun 被 Oracle 收购后，正式更名为 Oracle VirtualBox。

VirtualBox 可以被认为是最强大的虚拟机软件。它不仅功能丰富，而且性能卓越且易于使用。它可以虚拟化 Windows、Mac OS X、Linux、OpenBSD、Solaris、IBM OS2 甚至其他操作系统。

VirtualBox 不仅开源的，还具有许多优势。本模块将介绍如何使用 VirtualBox 等虚拟机软件来学习 Kali Linux 操作系统。

VirtualBox 的主要功能如下：

- 它支持 64 位客户端操作系统，即使主机使用 32 位的 CPU。
- 它支持虚拟硬盘快照。
- VirtualBox 支持在主机和客户端之间共享剪贴板。但记住需要安装客户端驱动。
- 它支持在主机和客户端之间建立共享文件夹，但需要安装客户端驱动。
- 它可以虚拟化 Windows、Mac OS X、Linux、OpenBSD、Solaris、IBM OS2 甚至其他操作系统。

### 2. VirtualBox 安装

VirtualBox 的官方网站是 `https://www.virtualbox.org`。读者可以在这里下载稳定版本的 VirtualBox。

### 3. 创建虚拟机

虚拟机软件安装好后，双击桌面上的 VirtualBox 图标启动应用程序并创建虚拟机。

具体步骤如下：

- 1) 按 `CTRL+N` 键新建虚拟机，弹出“新建虚拟机”窗口。在这里填写名称、类型和系统版本。虚拟机名称为“Kali Linux”，类型为“Linux”，版本为“Linux (64位)”。选择合适的选项后点击“下一步”。
- 2) 配置虚拟机内存大小。应给予 2GB 以获得更好的性能。为虚拟机配置“4096MB”，点击“下一步”。
- 3) 添加虚拟硬盘，在这里选择“现在创建虚拟硬盘”按钮，然后点击“创建”。
- 4) 设置虚拟硬盘文件类型。在这里选择“VDI (VirtualBox 映像)”按钮，点击“下一步”。如果你使用的是 VMware 则应选择 `.vmdk` 文件格式。
- 5) 设置虚拟硬盘空间分配方法。这是存储虚拟机所有内容的地方。根据情况选择“动态分配”或“固定大小”。为了获得最佳性能，选择“动态分配”按钮并点击“下一步”。
- 6) 设置虚拟硬盘文件的位置和大小。在这里选择文件位置为“F:\files\KaliLinux.vdi”（你可能不同），虚拟硬盘大小为“100GB”，点击“创建”完成虚拟硬盘创建。
- 7) 虚拟机打开且虚拟硬盘创建完成后，虚拟机已创建。这是 VirtualBox 的整个控制管理界面。点击左侧的虚拟机名称可以查看该虚拟机的配置属性。
- 8) 在 VirtualBox 控制管理界面中，你可以创建、管理和启动虚拟机。首先选择左侧的虚拟机名称，然后点击“设置”按钮设置虚拟机，关于系统的具体设置。

- 4) 虚拟机上的 Linux 安装方法

在虚拟机上安装 Linux 有两种常用方法：CD-ROM 安装法和 ISO 镜像文件安装法。

- 1) 光驱驱动器安装方法

在“Oracle VirtualBox 管理器”界面中，选择需要安装的虚拟机，点击“设置”按钮进入虚拟机设置界面，然后选择“存储”选项。



点击“存储”选项后，右侧会出现一个 IDE 控制器和一个 SATA 控制器。SATA 控制器下是虚拟机的虚拟磁盘设备，而默认的 IDE 控制器为空并显示“无磁盘”。点击“无磁盘”选项，右侧将出现 IDE 控制器的属性设置。点击“属性”下方的 CD 图标。将出现所有可用设备，包括物理设备和虚拟设备。这里的物理设备“F:”是物理主机的 CD-ROM 驱动器。选择它后，点击“确定”按钮。使用物理 CD-ROM 安装系统。

最后，点击“Oracle VirtualBox 管理器”界面上的“启动”图标启动虚拟机。VirtualBox 将自动读取物理机的 CD 并进入 Linux 启动安装界面。

### 2) ISO 文件安装方法

ISO 文件是一种 CD 镜像文件。刻录软件可以直接将 ISO 刻录成可安装的系统。由于 ISO 文件直接在硬盘上运行，数据传输速度非常快。CD 安装方法简单，但由于普通 CD-ROM 驱动器的传输速度较慢，安装过程也相对缓慢。

因此，建议在虚拟机上通过 ISO 文件安装系统。

### 1) 与 CD-ROM 安装法类似，在“ISO VirtualBox 管理器”界面中选择要安装的虚拟机，然后点击“设置”图标进入虚拟机设置界面。然后选择“存储”选项，点击“选择磁盘”按钮并指定物理机上相应的 ISO 文件。最后点击“确定”按钮完成 ISO 镜像文件的加载。

### 2) 点击“Oracle VirtualBox 管理器”界面上的“启动”图标启动虚拟机。VirtualBox 将自动读取 ISO 文件并引导进入 Linux 安装界面。

### 3) 有时虚拟机无法从 CD-ROM 驱动器或 ISO 文件启动，你可能需要修改虚拟机的启动顺序。虚拟机启动后，快速按下键盘上的 `F12` 键进入虚拟机启动顺序配置界面。

### 4) 虚拟机的默认启动顺序是硬盘、软盘驱动器、光驱和网络。如果你想从光驱启动，直接在界面按 `c` 键即可进入 CD 启动。其他操作类似。

### 5) VirtualBox 虚拟机启动后，将进入一个新的虚拟计算机控制台。进入新计算机控制台时，会遇到虚拟机与物理机之间切换键盘鼠标的问题。

### 6) 默认切换键是右 `Ctrl` 键，即当虚拟机独占键盘鼠标时，按下右 `Ctrl` 键退出独占模式，再次按下右 `Ctrl` 即可进入独占模式。此右 `Ctrl` 键也称为热键。

### 7) 主机键（Host key）与其他键的组合可以实现虚拟机上的快捷操作。例如，`Host+Del` 组合键代表键盘上的 `Ctrl+Alt+Del` 组合，`Host+R` 代表重启虚拟机，`Host+H` 组合键代表正常关闭虚拟机，等等。

## 黑客哲学

在上一一个章节中，我们已经在虚拟机中安装了 `Kali Linux`，现在我们准备好对其进行实验，学习一些黑客知识，并进行被认为对于道德黑客是必要的实实介绍。

### 什么是黑客？

由于流行文化中对黑客的持续性错误介绍，这个问题可能看起来很随意。从 90 年代的电影、书籍和漫画中，黑客被描绘成试图破坏系统和击垮互联网的阴暗人物。

但，这正确吗？或者黑客真的如他们所代表的那样吗？我的意思是，确实有一些坏人留在暗网中，并为愿意剥削的人廉价出售盗取的信用卡信息。

但在硬币的另一面，还有成千上万的道德黑客，他们努力工作，保护复杂的网络系统免受某些试图破解系统的恶作分子的攻击。

黑客行为（Hacking）是一门计算机学习，人们在尝试破坏系统。虽然破坏似乎是一件坏事，但他们实际上是在帮助我们理解开发软件、操作系统和应用程序时可能出现的漏洞。

早期，黑客技术是一种同时需要硬件和软件访问的技能。但现在，随着互联网和网络架构的出现，任何东西都可以仅通过电脑借助少量软件被黑入。

### 对黑客来说，Linux 是什么？

所有著名的黑客都强烈建议新手（他们也称为脚本小子 `script kiddies`）停止使用 Windows 或 macOS 进行黑客攻击。Windows 和 macOS 不仅对黑客来说是非常糟糕的操作系统，而且在攻击和破解系统时还可能损害你的安全。

`Linux` 是一个高度安全的内核级系统，预装了网络监控工具和其他命令行实用程序，可以帮助你监控流量。

### 什么是黑客程序？

黑客使用不同的协议来破解系统。还记得几年前摧毁许多行业的勒索软件吗？它利用了 Windows 中的未知漏洞进行剥削。

有才华的黑客在攻击之前总是会对目标进行彻底研究。新手在这个阶段会通过同时攻击多个目标来浪费系统资源。

### 有多少类型的黑客？

技术领域通常将黑客分为三类。其中最重要的是道德黑客，他们通过渗透测试技能和漏洞检测来帮助保护系统。

以下是对每种类型黑客的简要描述：

#### 1) 黑客（Black hackers）

这类黑客为了个人利益而进行黑客活动。他们带有动机利用系统并窃取数据。根据最新统计，黑客每年从互联网上盗取超过 20 亿美元。更多科技公司担心黑客，并投入巨额资金开发入侵检测系统。如果你学习这本书是为了成为黑帽黑客，我们警告你那里并不容易。

#### 2) 白帽黑客（White hackers）

这类黑客是为了保护系统而进行黑客活动。几乎所有的安全研究人员都属于这一类。不仅是黑客，法医专家和逆向工程师也属于这一类。白帽黑客在知识和速度上与黑帽黑客一样成熟。白帽黑客相对于黑帽黑客拥有的唯一优势是他们拥有良好的信息。

#### 3) 灰帽黑客

如果黑客落在其他两者之间，我们可以简单地称其为灰帽黑客。为政府或大学工作的黑客属于这一类。

### 接下来做什么？

要成为黑客，你需要对目标研究有良好的思维。在下一章中，我们将讨论不同的网络工具以提高你的侦察知识。我们还建议通过阅读不同的博客来更详细地学习黑客和网络安全。如果你对道德黑客攻击感兴趣，也可以尝试参与漏洞赏金（bug bounty hunting）。

## KALI LINUX 中的工作工具

在本书的之前的模块中，我们讨论了黑客哲学以及 `Kali Linux` 的介绍。虽然 `Kali Linux` 是掌握和利用工具的极佳途径，但我们也需要关注其中一些监控工具。网络是互联网通信的骨干，对于每个程序员来说，理解其基础知识是必修的。

`Linux` 为开发者提供了许多实用工具来调试和评估服务器程序。熟练的网络程序员会在开发服务器程序的整个过程中不断使用这些工具中的一个一个来监控服务器的行为。

其中一些工具对于黑客来说是常见的。

本章将讨论一些常用的工具：`tcpdump`, `nc`, `trace`, `lsof`, `netstat`, `vmstat`, `ifstat` 和 `mpstat`。这些工具支持许多选项，但我们的讨论限于最常用且实用的部分。此外，请记住，我们仅提供了供您理解工具能力的重要命令。为了进一步了解和实验该工具，我们首先建议您：

### TCPDUMP

`Tcpdump` 是一个经典的网络包捕获工具。即使在今天，我们也有像 `Wireshark` 这样更容易使用和掌握的抓包工具，但 `tcpdump` 仍然是网络程序员必不可少的的工具。`tcpdump` 为用户提供了大量选项来过滤数据包或自定义输出格式。

在学习更多 `tcpdump` 之前，我们建议您先理解网络包的本质以及如何使用 `Wireshark` 等工具进行追踪。如果您是一个高效的黑客，学习一些网络嗅探以从收集的数据中获取敏感信息也是重要的。

我们在本章中引入了许多不同的黑客工具，现在我们总结了常用选项并带有示例，以便您更好地理解这个工具可以完成的奇功能。

在 4.0 及之前的版本中，默认捕获长度为 68 字节。这对于 IP、TCP 和 UDP 等协议足够了，但对于 DNS 和 NFS 等协议，68 字节通常无法容纳完整的数据包。

例如，当我们抓取 DNS 包时，我们使用 `-s` 选项（测试机上的 `tcpdump` 版本为 4.0）。

```
root@server : tcpdump -s 192.132.112.11
```

然而，在 4.0 之后的版本中，默认捕获长度被更改为 65535 字节，因此我们不需要担心捕获长度了。`-s`，TCP 段的序列号以绝对值显示，而不是相对值。`-w`，将 `tcpdump` 的输出重定向到特殊格式的文件。而 `-r` 将从文件中读取包信息并显示出来。

除了使用选项外，`tcpdump` 还支持使用表达式来过滤过滤包。`tcpdump` 表达式的操作数分为三类型：类型（type）、方向（direction）和协议（protocol）。本节将依次介绍这些。类型将解释紧随其后的参数的含义。`tcpdump` 支持的所有类型包括 `host`（主机）、`net`（网络）和 `portrange`（端口范围）。

它们分别指定主机名（或 IP 地址）、CIDR 方法表示的网络地址、端口号和端口范围。例如，要抓取整个 `1.2.7.0/255.253.231.0` 网络上的数据包，可以使用以下命令。

```
root@server : $ tcpdump net 1.2.7.0/13
```

在这里，`src` 指定数据包的发送者，`dst` 指定数据包的目的地。

例如，要抓取进入端口 `13111` 的包，可以使用以下命令：

```
root@server : $ tcpdump dstport 13111
```

例如，要抓取所有的互联网控制消息协议（ICMP），可以使用以下命令。

```
root@server : $ tcpdump ICMP
```

你可以将其用于其他几种协议，如 `SMTP`、`FTP` 等。

当然，我们也可以使用逻辑运算符来组织上述操作数以创建更复杂的表达式。`tcpdump` 支持的逻辑运算符与编程语言中的完全相同，包括 `(&&, or (||), not (!))`。

例如，要抓取主机 `-laptop` 和非源主机交换的 IP 数据包，可以使用以下命令。

```
root@server : $ tcpdump IP host
```

如果表达式很复杂，可以使用括号将它们分组。然而，在使用括号时，我们要么使用反斜杠 "\" 进行转义，要么将其包含在单引号 "'" 中，以避免被 shell 解析。

例如，要抓取来自主机 `8.0.2.4` 且目标端口为 `3369` 或 `12` 的包，可以使用以下命令。

```
root@server : $ tcpdump src 8.0.2.4 and (dstport 3369 or 12)
```

此外，`tcpdump` 还允许直接使用包中的某些协议字段来过滤包。例如，要仅提取 TCP 同步段，可以使用以下命令。

```
root@server : $ tcpdump TCP [13]&2!=0
```

因为 TCP 头部第 14 字节的第二位是同步标志，所以我们可以从数据中获取大量信息。最后，`tcpdump` 的特定输出格式不仅与协议有关，还与其他协议有关。我们讨论了 IP、TCP、ICMP、DNS 的 `tcpdump` 输出格式。对于其他协议的 `tcpdump` 输出格式，请参考相关手册。到此，我们完成了对这种流行的监控工具的简要介绍。在下一节中，我们将讨论 `lsof`，另一个流行的监控工具。

### LSOF

`lsof`（list open file）是一个列出系统打开的文件的工具。通过它，我们可以知道哪些进程打开了文件。该选项的用法如下：

```
$ lsof [-4|-6] [protocol] [@hostname | ipaddr] [:service | port]
```

其中 `4` 代表 IPv4 协议，`6` 代表 IPv6 协议。`Protocol` 指定传输层协议，可以是 `TCP` 或 `UDP`。`Hostname` 指定主机，`ipaddr` 指定 IP 地址。`Service` 指定服务名，`Port` 指定端口号。例如，要显示连接主机 `192.168.1.108` 的 socket 文件描述，可以使用命令。

```
root@server : lsof -i192.168.1.108:22
```

如果 `-i` 选项没有指定参数，`lsof` 命令将显示所有文件描述。`-u` 显示由指定用户启动的进程，`-c` 显示由指定命令启动的进程。例如，要查看 `websrv` 打开的文件描述，可以使用以下命令。

```
root@server : $ lsof -c websrv
```

要显示指定进程打开的文件描述使用 `-p`。它只显示目标进程的 PID。我们可以直接文件名作为 `lsof` 命令的参数来查看哪些进程打开了文件。从列表中可以看到测试机上的程序文件和动态库存储在设备 `"8,3"` 中。其中，“`8`” 表示 SCSI 硬盘，“`3`” 表示该硬盘上的第三个分区，名为 `sda3`。

对应于 `websrv` 程序的标准输入、标准输出和标准错误的设备是 `"136,3"`。其中，“`136`” 表示这是一个伪终端，“`3`” 表示它是第三个伪终端，即 `./dev/pts/3`。

对于 FIFO 类型文件（如管道和 socket），此文件将显示内核引用文件的地址或其 inode 节点。如果文件显示为 `"Ot"` 或 `"Ox"`，则意味着它是一个偏移值，否则意味着它是一个大小。对字符设备或 FIFO 类型文件定义文件大小是没有意义的，因此该文件将显示偏移值。对于 socket，它显示协议类型，如 `"TCP"`。`Name` 显示文件的名称。如果我们使用 `telnet` 命令连接到 `websrv` 服务器，当我们再次执行 `lsof` 命令时，以下行将被添加到其输出中。

```
websrv63466shuang5gu IPv4 442880tcp localhost: 13579-> localhost: 48215
(ESTABLISHED).
```

此输出表示服务器已打开一个值为 `5` 的 IPv4 类型 socket，且处于已建立（established）状态。与该 socket对应的连接本地套接地址为 `(127.0.0.1, 13579)`，远程套接地址为 `(127.0.0.1, 48215)`。

虽然 `lsof` 不具备像 `tcpdump` 那样的高级功能，但它仍然实现了其设计初衷。在本章的下一节中，我们将详细介绍 `netcat`。请继续阅读下去！

### NC(NETCAT)

`netcat` 命令短小、高效且强大，被称为“瑞士军刀”之誉。它主要用于快速建立网络连接。我们可以让它作为服务器，监听某个端口并接收客户端连接，因此它可以调试客户端程序。我们也可以让它作为客户端，发起对服务器的连接并接收数据，因此它可以调试服务器程序，这有点像 `telnet` 程序。

`nc` 命令默认使用的传输层协议是 `TCP` 协议。

- `-w`，如果 `nc` 客户端在指定时间内没有检测到任何输入，则退出。
- `-x`，指定 `nc` 客户端与代理服务器之间通信时使用的通信协议。目前，`nc` 支持的代理协议包括 `"4"socks v.4`）、`"5"socks v.5`）和 `"connect"`（https 代理）。`nc` 默认使用的代理协议是 `SOCKS v.5`。
- `-x`，指定目标代理服务器的 IP 地址和端口号。

例如，要从源笔记本连接到 `squid` 代理服务器并通过它访问 `www.google.com` 的 Web 服务，可以使用以下命令。

```
root@server: $ nc -x source: 1080 -x Connect www.google.com 80 -z, 并扫描目标机器上的一个或多个服务是否开启（端口扫描）。
```

例如，要扫描 `ernst-laptop` 机器上端口号在 20 到 50 之间的服务，可以使用以下命令。

```
root@server: $nc -z source 20-50.
```

例如，我们可以使用以下方法连接到 `websrv` 服务器并向其发送数据。

```
root@server :$nc -C 127.0.0.1 13579 (服务器监听端口 13579)
http://localhost/a.htmlHTTP/1.1 (回车)
```

它将提供在该服务器上未找到请求文件的提示。在这里我们使用 `-C` 选项，这样每当我们按下键向服务器发送一行数据时，`nc` 客户端程序都会向服务器发送一个额外的 `<CR> <LF>`，这正是 `websrv` 预期的 HTTP 行终止符。

在发送第三行数据后，我们收到了服务器的响应，这与我们的预期完全一致。服务器没有找到请求资源文件 `a.html`。因此，`nc` 命令是一个方便且快速的测试工具，通过它我们可以快速发现服务器的逻辑错误。

在本章的下一节中，我们将讨论 `strace` 工具，它可以方便地帮助我们跟踪数据包的路径。请继续阅读下去！

### STRACE

`Strace` 是测试服务器性能的重要工具。它跟踪程序运行期间接收到的系统调用和信号，并将系统名称、参数、返回值和信号名称输出到标准输出或指定的文件。

格式为：

```
[qualifier=][!value1,value2]..
```

限定符（qualifier）可以是 `trace`, `abbrevi`, `verbose`, `raw`, `signal`, `read` 和 `write` 之一，默认是 `trace`。值（Value）是用于进一步限制所跟踪系统调用的符号或数值值。它的两个特殊值是 `all` 和 `none`，分别意味着跟踪限定符指定类型的所有系统调用，以及不跟踪任何此类类型的系统调用。

例如，`-e read=3, 5` 表示输出从文件描述符 `3` 和 `5` 读取的所有数据。

- `-o`，将 `strace` 的输出写入指定的文件。`strace` 命令的每行输出包含这些字段：系统名称、参数和返回值。

例如，以下示例：

```
root@server: $ strace /dev/null open("/dev/null", O_RDONLY | O_FILE) = 3.
```

此行输出表示程序 `"cat/dev/null"` 在运行期间执行了 `open` 系统调用。

`Open` 以只读方式打开了大文件 `/dev/null`，然后返回一个值为 `3` 的文件描述符。需要注意的是，此示例命令将输出大量内容，在这里我们省略了很多次要信息。在随后的示例中，我们只显示与主题相关的内容。

当系统调用发生错误时，`strace` 命令将输出错误标识和描述，如下例所示。

```
root@server : $ strace /foo/bar open("/foo/bar", O_RDONLY | O_FILE) = -1
```

这将输出显示为 `ENO (no such file or directory)`。



`strace` 命令对不同参数类型有不同的输出模式，例如，对于 C 风格字符串，我们将根据其参数获得不同的输出。这有助于我们使用 `strace` 实用工具动态地监控数据。

默认最大输出长度为 32 字节，过长的 `strace` 将用 "..." 省略。

例如，`ls -l` 命令将读取 `/etc/passwd` 文件：

```
root@server : $ strace -read(4, "root: x: 0: root:root:/bin/bash \n" ..., 4096) = 2342.
```

需要注意的是，文件名不被 `strace` 视为 C 风格字符串。对于结构体，`strace` 将用 "{}" 输出结构体的每个字段，并用 "," 分隔每个字段。对于字段较多的结构，`strace` 将用 "..." 省略部分输出。

例如：

```
root@server : $ strace /dev/null lstat64 ("/dev/null",{mode = S_IFCHR|0666, rdev = makedev(1,3),...) = 0
```

上面的 `strace` 输出显示 `trace` 的第一个参数是 `stat` 结构类型的输出参数（指针）。`strace` 只显示了结构参数的两个字段：`mode` 和 `rdev`。应该指出，当系统调用失败时，输出参数将显示为传入之前的值。

对于位参数（例如信号类型 `sigset`），`strace` 将把集合中所有置为 1 的位输出在 "[ ]" 中，并用空格分隔每个项目。

假设程序中有以下代码：

```c
sigaddset(&set,SIGUSR1);sigprocmask(SIGBLOCK, &set,NULL);
```

那么针对该程序的 `strace` 命令将输出以下内容：

```
rt sigprocmask (SIGBLOCK, [SIGUSR1], NULL, 8) = 0.
```

关于其他参数类型的输出模式，请参考 `strace` 的手动页，我们在此不再重复。

对于程序接收到的信号，`strace` 将输出信号的值及其描述。例如，我们在一个终端上运行 "`sleep 100`" 命令，然后在另一个终端使用 `strace` 命令跟踪该进程，然后使用 "`Ctrl+C`" 终止 "`sleep 100`" 进程以观察 `strace` 的输出。

具体操作如下：

```
root@server : $ sleep 100 $ ps -EF | grep sleep
```

操作如下：

```
root@server : $ ./websrv 127.0.0.1 13579 $ ps -EF | grep websrv
```

接下来，使用该方法发起对服务器的连接并发送 HTTP 请求。因此，此事件表示客户端连接正在到来，所以 `websrv` 服务器对监听的 `socket` 执行了 `accept` 调用，`accept` 返回一个新的值为 5 的连接 `socket`。

然后，服务器清除新 `socket` 上的错误，设置其 `REUSEADDR` 属性，然后在 `epoll` 事件表中的 `socket` 上注册注册 `EPOLLRDHUP` 和 `EPOLET` 事件，最后将新 `socket` 设置为非阻塞。

`wait` 调用检测到文件描述符上的事件，这表明工作线程正确处理了客户端请求并准备好了发送的数据，因此主线程开始执行 `write` 系统调用并响应客户端。

最后，服务器从 `epoll` 事件表中移除文件描述符 5 的所有注册事件并关闭文件描述符。因此，`trace` 命令使我们能够清晰地看到每个系统调用的时机和相关参数的值，这比使用 `gdb` 调试要方便。

到此，我们已经对 `strace` 命令 `string` 了简短而复杂的介绍。我们建议你仔细阅读。虽然理解网络包在 `strace` 中重要性的方法有多种，但我们还应该使用如 `netstat` 等其他工具来进一步提升我们作为黑客对网络监控工具的影响力。

## NETSTAT

`Netstat` 是一个强大的网络信息统计工具。它可以打印本地网卡接口上的所有连接、路由表信息和网卡接口信息。对于本书，我们主要使用上述功能中的第一种，即显示 TCP 连接及其状态信息。

毕竟，对于路由表信息和网卡（NIC）接口信息，我们可以使用 `route` 和 `ifconfig` 命令获取更丰富的输出内容。

接下来，我们运行 `websrv` 服务器并执行 `telnet` 命令向其发起连接请求。

```bash
root@server : $./websrv 127.0.0.1 13579 & $ telnet 127.0.0.1 13579
```

然后执行命令来检查连接状态。

```bash
netstat -nat | grep 127.0.0.1:13579
```

结果如下：

```
proto recv-q send-q local address foreign address state
TCP 0 0 127.0.0.1:13579 0.0.0.0:
```

在上述输出中，第1行表示本地 `socket` 地址 `127.0.0.1:13579` 处于 `LISTEN` 监听状态，等待任何远程 `socket`（由 `0.0.0.0:` 表示）向其发起连接。第2行表示服务器与远程地址 `127.0.0.1:48220` 建立了连接。

第三行仅从客户端的角度反复输出由第二行信息所指示的连接，因为我们正在同一台机器上运行服务器程序 (`websrv`) 和客户端程序 (`telnet`)。在服务器端程序的开发过程中，我们必须确保每个连接在任何时刻都处于我们期望的状态。因此，我们应该学会使用 `netstat` 命令。

我们可以使用 `netstat` 命令显示关于不同网络服务器、其流量包和其他重要的大量信息。在下一节中，我们将讨论另一种名为 `vmstat` 的基础网络工具。请继续！

## VMSTAT

`Vmstat` 是 `virtual memory statistics`（虚拟内存统计）的缩写，它可以实时输出系统各种资源的使用情况，例如进程信息、内存使用、CPU 使用率和 I/O 使用率。

默认情况下，`vmstat` 的输出非常丰富。

看示例：

```bash
root@server : $vmstat 5 3
#### 每5秒输出一次结果。
```

注意，第一行的输出是自系统启动以来的平均结果，而下一行的输出是采样间隔内的平均结果。

如果这两个值变化频繁，说明内存不足。`io` 是块设备的使用信息，单位是 `block/s`；`bi` 表示从块设备读取块的速率；`bo` 表示向块设备写入块的速率；`in` 表示每秒中断数，`cs` 表示每秒上下文切换（进程切换）的次数次。

然而，我们可以使用 `iostat` 命令获取更多关于磁盘使用情况的信息，也可以使用 `mpstat` 获取更多关于 CPU 使用率的信息。`vmstat` 命令主要用于检查系统内存的使用情况。

许多黑客利用此工具了解内存资源，并临时停止那些消耗高内存的程序。在执行暴力破解等任务时，我们需要理解这些可以减轻系统负载的工具的重要性。在下一节中，我们将详细介绍 `ifstat` 网络工具。请继续！

## IFSTAT

`Ifstat` 是 `interface statistics`（接口统计）的缩写，是一个简单的流量监控工具。

例如，我们在测试机上执行以下命令：

```bash
root@server : $ifstat-a 2 5
#### 每2秒输出一次结果。
```

`ifstat` 的输出显示了每个 NIC 接口接收和发送数据的速率（单位为 KB/s）。因此，使用 `ifstat` 命令可以粗略估计服务器在每个阶段的总入出流量。

在本章的后续节，我们将讨论 `mpstat`，这是一种黑客分析不同处理器统计数据的常用网络工具。请继续！

## MPSTAT

`Mpstat` 是 `multi-processor statistics`（多处理器统计）的缩写，它可以实时监控多处理器系统中每个 CPU 的使用情况。`mpstat` 命令和 `iostat` 命令通常集成在 `sysstat` 软件包中，可以通过安装 `sysstat` 获取。

`mpstat` 命令的典型用法如下（`mpstat` 的选项并不多，此处不做专门介绍）：

```bash
mpstat [-p { all }] [interval [count]]
```

选项 `p` 指定要监控的 CPU 编号（0 ~ CPU 数量 -1），其值 "all" 表示监控所有 CPU。

`interval` 参数是采样间隔（单位为秒），即每隔一个间隔输出一次统计信息。`count` 参数是采样次数，即 `mpstat` 总共输出 `count` 次统计信息，并最终输出这 `count` 次采样结果的平均值。

与 `vmstat` 命令类似，`mpstat` 命令的第一个输出结果是自系统启动以来的平均结果，而接下来的（第 `count` 次）输出结果是采样间隔内的平均结果。

例如，我们在测试机上执行以下命令：

```bash
root@server : $mpstat -P ALL 5 2
#### 每5秒输出一次结果。
```

每次采样的输出包含三部分信息，每部分包含以下字段：CPU，“0”表示第一个 CPU 的数据，“1”表示第二个 CPU 的数据，“all”表示两个 CPU 的平均值。

`%usr` 表示除了具有 `nice` 值的进程外，系统其他进程在用户空间运行的时间占比例。

`%nice` 表示具有负 `nice` 值的进程在用户空间运行的时间占比例。

`%sys` 表示系统所有进程在内核空间运行的时间占比例，但不包括由硬件和软件中断消耗的 CPU 时间。

`%iowait` 表示 CPU 等待磁盘操作的时间占比例。`%ir` 表示处理硬件中断的 CPU 时间占比例。

`%soft` 表示处理软件中断的 CPU 时间占总 CPU 时间的比例。

`%steal` 表示一个物理 CPU 可能包含一对虚拟机 CPU，它们由虚拟机管理器管理。当虚拟机管理器处理一个虚拟机 CPU 时，另一个虚拟机 CPU 必须等待其处理完成后才能运行。这种等待时间被称为窃时。该字段表示窃时占总 CPU 时间的比例。

`%guest` 表示运行虚拟机 CPU 的时间占总 CPU 时间的比例。

`%idle` 表示系统空闲时间占总 CPU 时间的比例。在所有输出字段中，我们最关注 `%user`、`%sys` 和 `%idle`。

它们基本上反映了代码中业务逻辑代码和系统调用的比例，以及系统能够承受的负载。显然，在上面的输出中，执行系统调用消耗的 CPU 时间比执行用户业务逻辑更多。这是因为我们运行了此机器上介绍的压力测试工具，它不断执行 `recv/send` 系统调用来收发数据。

在模块的下一章中，我们将详细讨论不同的 Kali Linux 工具。请继续！

`KALI LINUX` 预装了 350 多种黑客工具。所有工具都提供了不同的用场景，可以帮助黑客伪造网络数据，甚至可以对其进行监控以备未来取证。

在本章中，我们将讨论 Kali Linux 中可用的一些重要工具以及它们的功能。请坐好，尽情探索黑客的不同分支吧。

## 阶段 1 - 侦察工具

如前所述，在破解和攻击系统之前，你首先需要获取关于目标的大量信息。例如，了解目标使用的服务器架构可以帮助你发现该特定服务器架构的漏洞。

但是，你到底是如何获取目标信息的呢？

为了解释这一点，我们首先需要解释黑客的工作原理。黑客不仅是聪明的极客，还是出色的交际者，他们试图从使用目标的用户的普通对话中获取信息。

如果一个黑客想要攻击银行服务器，他会说服几名银行员工并试图收集有关服务器的信息。虽然这看起来很有风险，但只需安装监控软件就能帮助他们获得所需的所有资源和信息。

出于这个原因，我们将这一黑客分支分为两类：一种是社交工程攻击，另一类是挖掘价值信息。

### A) 社交工程攻击

这些是黑客针对目标用户、员工和系统管理员的攻击。一种著名的攻击手段是创建一个钓鱼页面，让目标输入其用户名和密码。在获取凭据后，他们利用这些权限访问 `root` 级别。

这类攻击有许多工具可用。有不同的命令行程序可以创建社交网络网站的虚假钓鱼页面。

### B) 挖掘价值信息

关于目标的大量信息通常可以在开放世界中找到。几次智能 Google 搜索就能为你提供大量关于目标的信息。通过电子邮件联系系统管理员也是获取某些敏感信息的好方法。

然而，黑客在这一黑客步骤中使用的最重要的工具是 `nmap`。`nmap` 是一个开源工具，用于扫描可用的开放端口并输出与目标相关的大量信息。

如果操作得当，你可以通过不同的自动化命令找到服务器架构和目标使用的操作系统。然而，请记住，网络安全研究人员多年积累了大量经验，并开发了多样的入侵检测系统，以应对来自试图扫描开放端口的新手的请求。

如果你是一个经验丰富的黑客，你唯一做的就是不要引起系统管理员的注意，以免你的 IP 地址或 MAC 地址被永久封禁。

这里有一些命令：

```
root@sample : nmap
// 这显示菜单
root@ sample : nmap www.google.com
// 这扫描此地址的开放端口
root@sample : nmap -V 192.32.222.12
// 这对输入地址发送开放端口检测请求
```

`Nmap` 在了解其他高级内容（如 `ping` 时间和防火墙的存在）方面也非常高效。如果存在防火墙，你可以找到开放的漏洞并利用它们。

在扫描并发现潜在漏洞后，你可以进入黑客攻击的下一个阶段。即利用（Exploitation）。

## 2) 利用工具

如果你不知道如何攻击和利用系统，攻击系统还有什么乐趣呢？

在发现漏洞后，黑客通常会插入木马或蠕虫来为他们完成肮脏工作。现在许多黑客在不同系统中实施比特币货币挖矿来赚快钱。但他们是如何做到的呢？

经验丰富的黑客会编写自己的利用软件，而中级黑客则使用 `Metasploit` 等 Kali Linux 工具。

### 什么是 Metasploit？

`Metasploit` 是最流行的利用工具，可以用于跟踪用户或将木马绑定到图像或 PDF 文件中。当目标点击被 `metas-loot` 修改的文件时，我们就可以跟踪并利用他们。

这里有一些命令：

```
root@server : metasploit
// 这将启动 msf 控制台
root@server : metasf bind.jpg
// 使用图片文件绑定木马
```

`Metasploit` 还可以用于生成安卓文件进行利用。你还可以使用 `metasploit` 破解服务器。然而，请记住，在没有硬件访问的情况下你无法破解安卓设备。

## 阶段 3 - 监控工具

在之前的阶段中，我们使用了 Kali Linux 工具进行扫描和利用。在本节中，我们将学习如 `Wireshark` 等监控工具，以理解可能发生的黑客攻击。

### 什么是监控？

网络数据以包的形式传输。数据包如果没有加密，就可以被伪造，并被黑客用于窃取信息。`Wireshark` 是一种用于分析异常流量的工具。它提供一个显示每个数据包的面板。

像 `Wireshark` 这样的工具可以帮助黑客通过伪造数据包进行监控。`Wireshark` 是最受欢迎的包分析软件之一。它提供一个显示每个数据包头部信息的面板。

- 以下是使用 `Wireshark` 的一些技巧：

1) 始终确保你了解尝试监控的目标主机地址。

2) 使用 `net stat` 和 `ping` 等工具分析网络流量，并有效地捕捉数据包。

3) 理解加密和非加密网络包的区别。如果你强制解密加密包，请确保你理解 `HTTP` 协议等复杂内容。

`Wireshark` 为网络管理员提供付费功能。在专业版中你可以使用捕获的信息自动报告，而在社区版中你需要手动制作。

### 字典攻击工具

黑客需要处理许多复杂的问题，他们最感兴趣的是窃取密码和电子邮件地址等敏感信息。获取大量密码和账户唯一方法是使用字典攻击，技术上称为暴力破解。

Kali Linux 提供了 `Hydra` 和 `Jack the Ripper` 等工具来破解网站和数据库。一些破解者还利用 SQL 注入破解数据库以获取敏感信息。

#### A) Hydra

`Hydra` 是 Kali Linux 中的字典攻击工具。使用 `Hydra`，你只需要提供 URL 页面和一个由冒号分隔用户名和密码的文本文件。

所有成功的登录都将打印在日志文件中，并用于登录网站。

这里有一些命令：

```
root@server : hydra www.google.com/login user.txt
// 这将使用文本中的信息攻击登录页面
```

#### B) Jack the Ripper

`Jack the Ripper` 是同类型的工具，可用于破解登录页面。虽然 `Hydra` 只能暴力破解静态登录页面，但此工具可以帮助你动态破解登录页面。

也就是说，你可以根据正在的结果自定义暴力破解。例如，如果登录页面出现“未找到服务器”错误，`Jack the Ripper` 将自动更换代理服务器，以缓解入侵检测系统执行的代理封禁。

这是一条命令：

```
root@server : jtr -w pass.txt www.sampleurl.com -p proxy.txt
```

这里的 `w` 代表携带用户名和密码的字典列表，而 `proxy.txt` 包含不同代理服务器的信息，如果它们是存活的，会被引擎随机使用。

我们将最后讨论的一组工具是关于无线工具的。我们都知道，世界正在发生快速变化，网络以太网现在不再是网络中传输信息的唯一方式。无线网络包括 `wifi` 热点、手机手机、笔记本电脑甚至智能手表。

这里涉及到大量的隐私问题，即使网络协议中一个微小的漏洞也可能被窃取大量敏感信息。这就是为什么你需要定期更新系统的原因。

以下是一些重要的工具：

#### A) aircrack-ng

这是一个著名的网络工具，可用于暴力破解所有可用的 `Wpa/wp2` 网络。它还可以自动发现 `WPS` 网络中的漏洞。你们只需要使用 `net stat` 命令找到无线网络的地址，并将其插入到工具中进行自动破解即可。

以下是相关命令：

```
root@server : aircrack-ng 192.23.11.234 text.txt
```

#### B) Airdump



Airdump 是一种网络监控工具，其工作与上述工具相同，但提供了更多选项和自定义功能。Airodump 甚至提供了虚造的钓鱼页面，通过社会工程攻击从目标用户处获取信息。

到此，我们完成了对 Kali Linux 工具集的简要介绍。在模块的下一个章节中，我们将介绍不同的网络监控工具，这些工具可以帮助分析网络并破解它们。让我们开始吧！

# 第五章

## 用于渗透测试的 BURPSITE

在之前的章节中，我们讨论了网络监控工具，这些工具可以帮助我们理解目标系统中存在的不同网络模块。虽然网络破解在几年前是一种很流行的破解程序，但随着互联网和 Web 应用的普及，我们现在处于仅通过浏览器就能被窃取的边缘。

### 什么是 Web 应用？

Web 应用是运行在浏览器中的软件，只需通过 URL 即可访问。例如，`we.gmail.com` 就是一个 Web 应用，可以向全球任何拥有电子邮件地址的人发送邮件。

对于经验丰富的程序员来说，在 Web 应用中寻找漏洞是非常的。为了寻找这些漏洞，他们使用像 `Burp suite` 这样的软件。`Burp suite` 是目前最流行的 Web 应用漏洞扫描软件。它提供社区版和专业版。社区版免费且不提供自动扫描功能，而专业版则以低廉的价格出售，并提供目标的自动爬取和扫描功能，同时为企业提供文档支持。`Burp suite` 还有一个插件商店，包含大量免费和付费的插件，让 Web 应用渗透测试员的生活变得简单得多。

## 如何使用 BURPSUITE？

要安装 `Burp suite`，请前往官方网站并在使用 `chmod` 命令授权后进行安装。

如果你正在使用 Kali Linux，那么你很幸运，因为 `burp` 社区版已经预装在这个破解发行版中了。从开始菜单中的“Web application”菜单栏打开 `Burp suite`。

打开 `Burp suite` 后，按照以下指令操作：

- 1) 使用代理选项（proxy options），在 `Firefox` 和 `burp suite` 中将 `127.0.0.1` 作为主机地址。通过此操作，所有来自浏览器的 HTTP 请求都将发送到 `Burp suite`。
- 2) 你还可以使用来自 `port swigger` 安全网站的证书运行 HTTPS 协议请求。
- 3) 接收请求后，你需要输入“Accept（接受）”或“Reject（拒绝）”将其发送 `Burp` 监控。你也可以输入 URL 让 `Burp` 爬取整个网站。然而，在扫描网站时要现实な，因为你不会通过扫描器得到令人惊叹的结果。要发现漏洞，你需要更深层次的挖掘和大量的测试。
- 4) `Burp suite` 还有其他界面，如 `Burp suite intruder`、`Burp suite comparer`，用于自动化暴力破解和分析 cookie 信息。
- 5) `Burp suite` 还提供了一个文档面板，你可以在那里为你发现的漏洞编写 POC（证明）。

在下一节中，我们将提供如何使用 `Burp suite` 中提供的 `Burp intruder` 选项破解在线网页密码的详细说明。我们希望你仔细遵循练习，以理解如何破解你喜欢的任何网站账户。这有时很棘，但如果操作正确，你可以获得丰硕的成果。

`Burp intruder` 是 `Burp suite` 软件中的一个重要组件。使用 `intruder`，你可以单独发送请求，并使用可用字典和选项对其暴力破解。`Intruder` 可以发送 GET 和 POST 请求，并可以轻松用于分析结果。

使用 `intruder`，安全分析师通常可以了解入侵检测系统的性能。许多其他 Web 渗透漏洞，如 XSS 和 CSRF 攻击也可以使用 `Burp intruder` 组件进行检测。

### 如何使用它？

第一步：

找到你想要破解的网页。可以是支持 HTTP 或 HTTPS 的网站。如果你不确定网站施加的攻击限制，我们建议你尝试专门为 Web 应用渗透测试员练习开发的示例测试网站。

第二步：

开启 `burp` 拦截代理（intercept proxy）并进入该网页。几秒钟后，你将在 `Burp` 界面中收到一个请求。只需查看它并接受所有出现的请求。如果你拒绝了任何请求，有时网页可能无法正常打开。因此，确保网页已出现在 `Burp site` 菜单中。

第三步：

现在仔细观察 `burp inspector` 获得的所有请求。在这些请求中找到带有“POST”标识符的请求。通常，所有请求都带有“GET”标识符，因为它们正在向服务器请求某些信息。而登录页面和其他敏感框使用“POST”标识符，因为它们正在向服务器发送信息。

第四步：

找到你想要暴力破解的登录表单后，会出现一个菜单。在 `Burp` 菜单中点击“Send to intruder（发送到 intruder）”。现在你可以进入 `intruder` 界面查看该页面已准备好执行（字典）攻击。

第五步：

现在，使用底部框中出现的 HTML 代码选择参数。在这里选择“login（登录）”和“password（密码）”框以便于攻击。选择选项菜单后，选择你想使用的字典类型。

从数字到常用密码，有几十种选项供你考虑。你也可以在 `Burp suite` 的专业版中上传自定义字典列表。不要忘记选择你想执行的暴力破解攻击类型。我通常使用“pitchfork（叉叉模式）”，因为它简单快捷。

第六步：

现在点击 `start（开始）`，几秒钟内请求将开始涌入你的结果屏幕。暴力破解后仔细观察结果。所有带有“404”错误的结果都是坏结果。如果你收到任何成功消息，它们可能就是良好的结果。交叉检查良好的结果并对攻击场景编写一份文档。

到此，我们已经提供了关于 `Burp suite` 的清晰指令以及各种重要信息。
