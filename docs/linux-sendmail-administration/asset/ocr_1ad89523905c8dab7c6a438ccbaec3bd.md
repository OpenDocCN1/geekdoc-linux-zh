# Closing the Holes

The most important thing you can do to improve the security of your system against network-based attacks is to install security updates as soon as they become available. To update the software, you must know what software needs to be updated and where to find it. Security advisories and vulnerability reports sometimes offer fixes.

Unfortunately, the fix is not always included in a vulnerability report, and you may need to look for Sendmail and fixes yourself. The Linux vendor's Web site and www.sendmail.org are good place to look for fixes. Many Linux vendors provide security fixes for their distributions

> TIP The Linux vendor is a good place to get fixes because you can confidence that the fixes do not contain malicious code. It is important to know where your patches come from. Get your fixes from a reliable source. Otherwise you risk opening another hole.
