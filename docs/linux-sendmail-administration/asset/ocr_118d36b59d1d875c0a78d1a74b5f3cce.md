# The cf Directory Structure

m4 is a general-purpose processor. It has a wide variety of uses and is not specifically intended for Sendmail configuration. m4 macros have been built by the people who maintain Sendmail in order to allow us to create a Sendmail configuration with m4.

The Sendmail distribution contains the m4 source files needed to build the sendmail.cf. These source files are found in the cf directory located under the top directory created by the Sendmail distribution tar file. The top directory created by the file has a name based on the Sendmail distribution's version number. The format of this directory name is sendmail-version, where version is the version number. Thus the file for Sendmail 8.11.0 creates a directory named sendmail-8.11.0, and the configuration files for it are found in sendmail-8.11.0/cf. All of this, relative to the directory in which we restored the file. In Chapter 3, we restored the file in /usr/local/src, so the complete path to the configuration files on our sample system is /usr/local/src/sendmail-8.11.0/cf. A listing of that directory shows 10 entries.

```
[craig]$ ls /usr/local/src/sendmail-8.11.0/cf
```

README cf domain feature hack m4 mailer ostype siteconfig
The cf directory contains a README file and nine subdirectories. The README file provides useful documentation on the m4 language and what language is used to build sendmail.cf. Always check this file for the latest changes and the newest features.
