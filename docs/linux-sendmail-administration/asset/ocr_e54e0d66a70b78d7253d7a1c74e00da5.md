Debug level 35.9 is more interesting than 37.1 because it shows variables changing. But if debug level 37.1 is more useful than 35.9. While variables can be individually checked with the $v command syntax, there is no address test command for examining an individual option. To see the options that are set and the values that they are to run. If the problem you're having with your configuration is related to an option setting, this is a good way to check it on. For a complex test, I sometimes print out a hard copy of the 37.1 output and keep it on as a reference while I run the tests that I have planned for the configuration.

The six debug levels in this chapter are the ones I use and the ones I find useful in address test mode. There are huge number of debug options, as Appendix B makes clear. Few are of interest to a system administrator and even fewer have any impact on address test mode. Most debug levels the debug information through the syslog daemon process. Setting debugging can cause your logs to grow at an enormous rate. Use caution when playing with debug modes.
