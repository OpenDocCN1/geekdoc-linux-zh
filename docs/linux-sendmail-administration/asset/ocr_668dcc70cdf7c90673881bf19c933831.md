--IAB01301.964... contains three different Content-Type: headers, each of which I marked in bold to make easier to find. The first one identifies this as a message of multipart. It is in fact a message composed of three distinct parts. The subtype of this multipart message is report. (The subtype report was not defined in RFC 2046; it was added later.) Two parameters are also defined on the first Content-Type: header. The report-type argument tells us this is a delivery-status report. The boundary argument defines the line that is used to separate each part in this multipart message. The boundary lines are also in bold to make easier to find in the listing.
