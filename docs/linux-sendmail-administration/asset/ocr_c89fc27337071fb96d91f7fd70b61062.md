# Chapter 10 Testing Sendmail

detail seen when the sendmail command is run with the -bt option is equivalent to debug level 21.1. However, from the point of view of the system administrator, the category and level numbers are insignificant. In reality, debug levels are simply arbitrary numbers, a few of which produce useful information.

A few debug levels category 0, the category that prints information about the Sendmail version, are useful. We saw an example of debug level 0.1 in Chapter 6. Two other debug 0 levels that I sometimes use are 0.4 and 0.10. Listing 10.5 shows the information printed by debug level 0.10.

Debug level 0.10 was used in Listing 10.15 because debug levels are cumulative with a category. The display generated by 0.10 contains the information that 0.1 and 0.4 would show and makes it possible for us to display all three debug levels with one listing. Level 0.1 displays the version number, the Sendmail compiler options, and the system identity. Debug level 0.4 displays the same three fields plus the addresses derived from the network interfaces. The names and addresses are listed under the headings “canonical name” and “UUCP nodename.” Level 0.10 prints all of the information
