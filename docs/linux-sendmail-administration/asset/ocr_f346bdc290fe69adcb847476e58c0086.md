# Using the -bv Option

The -bv option processes a delivery address through Sendmail to determine whether or not the address is deliverable. If it is deliverable, the mail delivery triple for the address is displayed. If it is not deliverable, the specific problem with the address is printed as an error message. Listing 10.1 shows a different -bv tests.

+   10.1 The -bv Option in Action

```
[root]# sendmail -bv sara@hawk.forbirds.org
sara@hawk.forbirds.org... deliverable: mailer esmtp,
host hawk.forbirds.org... delivery , user sara@hawk.forbirds.org
[root]# sendmail -bv craig
craig... deliverable: mailer local, user craig
[root]# sendmail -bv joe
joe... User unknown
[root]# sendmail -bv MAILER-DAEMON
craig... deliverable: mailer local, user craig
[root]# sendmail -bv -ccentient-only.cf
craig... deliverable: mailer relay, host wen.forbirds.org
user craig@wren.forbirds.org
[root]# sendmail -bv -ccentient-only.cf joe
joe... deliverable: mailer relay, host wen.forbirds.org,
user joe@wren.forbirds.org
```

The first example in Listing 10.1 shows -bv is being used to process the external address sara@hawk.forbirds.org. Sendmail responds by echoing back the address and displaying the mailer/host/user triple that will be used to deliver to that address. External addresses are not really verified, beyond determining that they are in the correct format. The primary of interest when processing a remote address with -bv is to find out what mailer is used to deliver the mail. Knowing the mailer can be useful information for later debugging, as you'll see when we cover the -bt option. The mailer should be the one you expect based on your configuration.

The next three examples process local addresses. For a couple of reasons, the output is more interesting than the output for remote addresses. First, sara@hawk.forbirds.org does not mean that there really is a sara account on hawk. It just means that the local system will send the mail to hawk for delivery. The successful test of sara means that the local system will send for hawk using the esmtp mailer. But the test of craig literally means that the local system has an account named craig to which it will deliver. Likewise, the error message returned for the test of joe tells us that there is no joe account or alias on the local system.
