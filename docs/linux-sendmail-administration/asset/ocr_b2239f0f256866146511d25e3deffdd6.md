The example shows the m4 command format used to build a sendmail.cf file. The path../m4/cf.m4 is the path to the m4 source tree required to build a sendmail.cf file. This must be specified on the m4 command line if it is not included in the macro configuration with an include command. Notice that the pathname is a relative pathname starting with ../ Older versions of m4 actually required a relative path. Changing to the /cf directory was not a convenience; it was a necessary part of running m4 with the correct source path. The GNU m4 program built with Linux can accept an absolute pathname for this argument, which means the macro configuration file can be stored anywhere. Red Hat takes advantage of this when installing Sendmail via RPM. RPM places a copy of the Red Hat configuration file in /etc/mail and includes an absolute pathname to cf.m4 inside the macro configuration file.

The second command-line argument is the name of the new macro configuration file, test.mc. m4 reads the source files ../m4/cf.m4 and test.mc, and it outputs the test file. The output generated by the m4 command is in the correct format for a sendmail.cf file.
