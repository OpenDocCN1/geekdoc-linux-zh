Creating your own blackhole server is one technique that Sendmail provides for you to do. Another is to define access controls in the access database.

# Using the access Database

The Sendmail access database defines e-sources with e-addresses, domain names, and IP network numbers with the action that Sendmail should take when it receives mail from the specified source. Earlier we use to enable relaying. An even more powerful use for the access database is a tool to block mail from or to known spammers. For example:

```
spammer@isp.com REJECT
wespamu.com REJECT
172.18 REJECT
```

These access database entries tell Sendmail to reject any mail from the e-mail address spammer@isp.com, from any host in the domain wespamu.com, and from any computer whose IP address belongs to network 172.18. Each entry in the database begins with the source of the mail followed by a keyword that tells Sendmail what action to take. Chapter 6 describes all of the valid keywords and the actions they cause.
