# Sendmail Aliases

Sendmail aliases perform important functions that are an essential part of creating a server. Mail aliases do the following:

+   **Specify nicknames for individual users.** Nicknames can be used to direct mail aliased to special names, such as postmaster or root, to the real users who do those jobs. When in conjunction with the domain MX records covered earlier, aliases can be used to create a standard e-mail address for a domain.
- **Forward mail to other hosts.** Sendmail aliases automatically forward mail to the host address included as part of the recipient address.
- **Defining mail lists.** An alias with multiple recipients is a mailing list.

Mail aliases are defined in the aliases file, which is the database Sendmail uses to determine where to deliver inbound mail. An process through the aliases is called aliasing. It is a multi-step process

+   1. First, Sendmail determines whether or not the address is a local address. Only mail addressed to the local system is processed through the aliases database. Mail is considered be addressed to the local system when the recipient address has no host part—i.e., no @hostname or the host in the part of the address is either the name of the server itself or one that it recognizes as a local host alias. Local host aliases are not the same as aliases. Aliases are usernames defined in the aliases database. Local host aliases are defined in the local-host-names file. If Sendmail decides the mail is addressed to the local system, aliasing continues. Otherwise, the mail is processed for relaying. Relaying is described in the next section).
2. Next, the username from the recipient address is used as the key for an aliases lookup. If the database does not return a value for the lookup, the mail is delivered to the recipient address.
3. If the aliases database returns a value for the lookup, the value becomes the new database key.
4. Another lookup is done using the key. If no value is returned for the lookup, the mail is delivered to the address that was used the last key. If a value is returned, Sendmail goes back to step 3. Sendmail can loop through steps 3 and 4 up to ten times, because aliases can point to other aliases and can be nested up to ten levels deep.
5. Sendmail loops through steps 3 and 4 and the maximum number of times without resolving the aliases, it returns an error and does not deliver the mail.
