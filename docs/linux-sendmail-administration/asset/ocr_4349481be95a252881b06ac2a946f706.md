# Appendix A m4 Macro Command Reference

conFEBINDIR Defines the directory where executables for FEATURE(`local_icmp`) and FEATURE(`smsh`) are stored. The default directory is /usr/libexec.

conFEIGHT_BIT_HANDLING Defines how eight-bit data is handled. Defaults to pass8, which passes eight-bit data to the server. [EightBitMode]

conERROR_MESSAGE Points to a file containing a message that is prepended to error messages. [ErrorHandler]

conERROR_MODE Defines how errors are handled. To print. [ErrorMode]

conFALLBACK_MX Defines a backup MX host. [FallbackMXHost]

conFORWARD_PATH Defines places to search for forward files. Defaults to $z/forward.sw=$/forward. [ForwardPath]

conFROM_HEADER Defines The header format. Defaults to $x$x $<$g$.

conFROM_LINE Defines the format of the Unix line. Defaults to $g $d. [UnixFromLine]

conHOSTS_FILE Defines the path to the hostname file. Defaults to /etc/hosts. [HostsFile]

conHOST_STATUS_DIRECTORY Defines the directory in which host status is saved. [HostStatusDirectory]

configure_DOTS Tells Sendmail to ignore dots in incoming messages. This option defaults to false, meaning that a line containing only dot signals the end of a message. [IgnoreDots]

conFLAP_DEFAULT_SPEC Defines the defaults used for LDAP databases unless overridden by a K command for an individual map. [LDAPDefaultSpec]

conLOCAL_MAILER Defines the mailer for local connections. Defaults to local.

conLOG_LEVEL Defines the level of detail for the log file. Defaults to 9. [LogLevel]

conMAILER_NAME Defines the sender name used on error messages. Defaults to MAILER-DAEMON. [$n]

conMATCH_GECOS If set to, Sendmail matches the e-mail username to the GECOS field. This match is not done if this is not set. [MatchGECOS]

conMAX_ALIAS_RECURSION Aliases can refer to other aliases. Sets the maximum depth that alias references can be nested. The default is 10. [MaxAliasRecursion]

conMAX_DAEMON_CHILDREN Refuses requests when this number of connection is reached. By default, connections are never refused. [MaxDaemonChildren]
