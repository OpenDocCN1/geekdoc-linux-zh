All of the scripts that can be controlled by tksys are listed on the left-hand side of the screen. On the right are the services that are started and stopped for runlevels 2, 3, 4, and 5. To disable a service for a specific runlevel, simply highlight the service in the Start list for that runlevel and click the Remove button. For example, remove Sendmail from runlevel 5, which is traditionally used as the runlevel for dedicated X Windows workstations, click sendmail1 in the Start list under runlevel 5 and click Remove. After that, Sendmail will no longer start when the system boots up runlevel 5.

To Add a runlevel, highlight sendmail in the Available list and click Add. You'll be asked to select a runlevel. An example might be runlevel 3, which is traditionally the default runlevel for multiuser users. Select the runlevel and click Done. You're asked to select a script number. The default, is 80 for the sendmail script. Click Add and the script is added to the start-up. The next time the system reboots under runlevel 3, Sendmail will be started.

> TIP Of course you don't want to reboot your system just to run the sendmail start-up script. Use the Execute button to run the sendmail script immediately.

tksys has a couple of nice features. First, it come bundled with different versions of Linux. It runs just as well on Caldera as it does on Red Hat, and it runs just as well as under Red Hat 6 as it does under Red Hat 7. Second, a clone of tksys called ntsys runs in text mode and doesn't require X Windows. A dedicated tksys that runs in text mode. In that case, you will want a tool like ntsys.

# Enabling Sendmail with ntsys

ntsys is even easier to use because it doesn't bother you with lots of questions about runlevels. It allows the current runlevel as a default unless it run with the --level1 argument. ntsys presents you with a list of services that can be automatically started at boot time. One of these is Sendmail. The start-up script for every item in the list that has an asterisk next to it will be run during the next boot. Use the arrow keys to scroll down to the sendmail entry in the list and use the space bar to deselect sendmail. When the settings are just what you want, tab over to the OK button and press Enter.
