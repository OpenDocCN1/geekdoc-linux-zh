# The m4 Directory

The last subdirectory of cf is the m4 directory. This directory contains the m4 macro definitions and the sendmail.cf skeleton code needed to build sendmail.cf configuration file. Remember that m4 is not a language designed to build Sendmail configurations. It is a general-purpose macro language. The commands you use to build a Sendmail configuration are macros defined by the Sendmail developers. The directory that contains the definitions of those macro commands. The cf/m4 directory contains only four files.

```
[craig]$ ls m4
cf.m4 cfhead.m4 proto.m4 version.m4
```
