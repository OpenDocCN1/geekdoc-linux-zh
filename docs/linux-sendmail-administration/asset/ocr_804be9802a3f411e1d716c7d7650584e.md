Next we edit file. First I edited the macro configuration file, redhat811.mc, changing the DOMAIN command to load foobirds.m4 instead of generic.m4. Then I moved the CONF_USER_ID parameter to the new OSTYPE file because I consider the user ID and group ID setting specific to Red Hat Linux. I deleted the two undefined because they serve no purpose. I also deleted CONFAUTO_REBUILD because it is a deprecated option.

I considered moving CONFTO_CONNECT to the OSTYPE file because it is designed to handle the default TCP timeout settings by the Linux operating system. I decided to delete it because I had no TCP timeout problems and did not anticipate any. Likewise I considered moving CONFRY_NULL_LIST to the DOMAIN file because MX records are handled. I decided to delete the option instead because it causes Sendmail to handle MX records in a non-standard way. Unless I must break a brazil to get things running, I don't want to.

I deleted the CONFDONT_PROBE_INTERFACES option because it causes Sendmail to include all of the server's interfaces as of class w. The CONFDFONT_PROBE_INTERFACES option is primarily useful on laptop systems where PCMCIA may be added or removed from a running system. Since I'm not running on a server on a laptop, I don't need this option. For the same reason, I deleted the accept_unresolvable_domains feature from the configuration, which is primarily used on laptops. I have good DNS service and therefore should not use that feature.

Some lines required no decision. PROCMAIL_MAILER_PATH and local_procmail are already in the DOMAIN file. However, the confMAX_HEADERS_LENGTH option that came from the generic.m4 file seemed unnecessary to me, so I deleted it from the new DOMAIN file. I also deleted the ifdef conditional from the OSTYPE file to set PROCMAIL_MAILER_PATH unconditionally.

I moved ALIAS_FILE, STATUS_FILE, and smsh to the OSTYPE file because file locations and mailer options are usually stored there. I deleted the UUCP_MAIL setting because the configuration does not define any UUCP mailers. I used CONFUSERDB_SPEC, always_add_domain, access_db, and blacklist_recipients to the new DOMAIN file because I decided to put all domain, masquerading, and anti-spam configuration in that file.
