# 374 Appendix A m4 Macro Command Reference

confTO_FILEOPEN Sets the maximum time to wait for a file to open. Defaults to 60s. [Timeout.fileopen]

confTO_HELO Sets the maximum time to wait for a HELO or EHLO response. Defaults to 5m. [Timeout.helo]

confTO_HOSTSTATUS Sets the timer for stale host status information. Defaults to 30m. [Timeout.hoststatus]

confTO_CONNECT Sets the maximum time to wait for the very first connect attempt to a host. [Timeout.connect]

confTO_IDENT Sets the maximum time to wait for an ident query response. Defaults to 30s. [Timeout.ident]

confTO_INITIAL Sets the maximum time to wait for the initial connect response. Defaults to 5m. [Timeout.initial]

confTO_MAIL Sets the maximum time to wait for a MAIL command response. Defaults to 10m. [Timeout.mail]

confTO_MISC Sets the maximum time to wait for other SMTP command responses. Defaults to 2m. [Timeout.misc]

confTO_QUEUERTURN_NONURGENT Sets the “Undeliverable mail” timeout for priority messages. [Timeout.queuerturn.nonurgent]

confTO_QUEUERTURN_NORMAL Sets the “Undeliverable mail” timeout for normal priority messages. [Timeout.queuerturn.normal]

confTO_QUEUERTURN_URGENT Sets the “Undeliverable mail” timeout for urgent priority messages. [Timeout.queuerturn.urgent]

confTO_QUEUEARN Sets the time until a message is returned from the queue as undelivered. Defaults to 5d. [Timeout.queueurn]

confTO_QUEUEARN_NONURGENT Sets the time until a “still queued” warning is sent for low priority messages. [Timeout.queuearn.non-urgent]

confTO_QUEUEARN_NORMAL Sets the time until a “still queued” warning is sent for normal priority messages. [Timeout.queuearn.normal]

confTO_QUEUEARN_URGENT Sets the time until a “still queued” warning is sent for urgent priority messages. [Timeout.queuearn.urgent]

confTO_QUEUEWARN Sets the time until a “still queued” warning is sent about a message. Defaults to 4h. [Timeout.queuewarn]

confTO_QUIT Sets the maximum time to wait for a QUIT command response. Defaults to 2m. [Timeout.quit]

confTO_RCPT Sets the maximum time to wait for a RCPT command response. Defaults to 1h. [Timeout.rcpt]
