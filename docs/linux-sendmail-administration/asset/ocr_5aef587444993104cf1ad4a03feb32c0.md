# Appendix A m4 Macro Command Reference

confBLANK_SUB Defines the character used to replace unquoted blank characters in e-mail addresses. [B1ankSub]

confCACERT identifies a file containing a cryptographic certificate from a certificate authority. [CACERTFile]

confCACERT_PATH Defines the path to the directory that contains the cryptographic certificates. [CACERTPath]

confCF_VERSION Sets the Sendmail version number. [SZ]

confCHECKPOINT_INTERVAL Sets the maximum number of queued items processed before Sendmail checkpoints the queue. Default is 10. [CheckpointInterval]

confCHECK_ALIASES Looks up every alias during the aliases database. Default is false. [CheckAliases]

confFLIENT_CERT identifies the file containing the cryptographic certificate Sendmail uses when it acts as a client. [ClientFile]

confFLIENT_KEY identifies the file containing the private key associated with the certificate used when Sendmail acts as a client. [ClientKey]

confFLIENT_OPTIONS defines the port options for outbound SMTP client connections. [ClientPortOptions]

confCOLON_ON_ADDR Tells Sendmail to treat colons as regular characters in addresses. Default is false. [ColonInAddr]

confCONNECTION_RATE_THROTTLE Sets the maximum number of connections per second. [ConnectionRateThrottle]

confCONNECT_ONLY_TO defines limited connectivity. Only needed when Sendmail is tested by the developers. This is not used in production environments. [ConnectOnlyTo]

confCONTROL_SOCKET_NAME defines a socket for managing the Sendmail daemon. [ControlSocketName]

confEXPENSIVE Tells Sendmail to hold mail bound for mailers who have the e flag set in the next queue run. Defaults to false. [HoldExpensive]

confCOPY_ERRORS_TO Sets the email address that receives copies of error messages. [Postmaster]

confFR_FILE points to the file that lists the hosts for this server will relay mail. Defaults to /etc/mail/relay-domains. [$R]

confCT_FILE defines the file of trusted usernames. Defaults to /etc/mail/trusted-users. [$t]

confW_FILE points to the file of local host aliases. Defaults to /etc/mail/local-host-names. [$w]
