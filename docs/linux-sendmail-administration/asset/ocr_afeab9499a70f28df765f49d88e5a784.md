# Creating an Anti-Spam Database

The format of the entries in the access database is the easy part. Deciding exactly what to put in the database is harder. There are organizations on the Internet that collect information about spammers that might help you build an anti-spam database. A few sites to start with are maps.vix.com, spam.abuse.net/, and www.mids.org/nospam. These sites are a starting point for locating information about known spammers.

Of course, in addition to extracting data from online lists of spammers, you can enter your own entries directly into the access database using your favorite editor. I find this the simplest method, and the most flexible for responding to the problems of my individual users.

If you have Windows tools, you can use linuxnuxconf to build the access database. Figure 11.1 shows an anti-spam filter being created with 1nuxconf.
