Mail definitions take up a substantial portion of the Sendmail configuration file. Each mail definition provides the instructions that Sendmail needs to properly prepares a message for a given mailer. This includes the commands that are used to process sender addresses and recipient addresses for the mailer. There are also flags associated with each mailer. The flags define optional processing required by the mailer and identify the message headers needed for the mailer. The number and type of headers from mailer to mail.

The Sendmail configuration contains several mailers. Sendmail must select the correct mailer to deliver a piece of mail.

# Determining the Delivery Triple

When Sendmail receives a piece of mail from an MUA, it determines what mailer will deliver the mail. Sendmail determines this from the delivery address included in the mail. It does this by literally converting the delivery address into a *delivery triple*. A delivery triple consists up to three values:

+   * the recipient's e-mail address
* the name of the server to which the mail will be sent
* the internal name of the mailer that will deliver the mail to the server

You can see the delivery triple that is produced for any delivery address by running the sendmail command with the -bv option and the address you wanted. Listing 2.1 shows the output of sendmail -bv for two different addresses.

# 2.1 Determining the Delivery Triple

```
[craig]$ sendmail -bv ed@xy.com
ed@xy.com... deliverable: mailer smtp, host xy.com, user ed@xy.com
[craig]$ sendmail -bv craig
craig... deliverable: mailer local, user craig
```

The first line in Listing 2.1 is a command that asks Sendmail to evaluate the delivery address@xy.com. Sendmail responds that the address is deliverable—which in this case means only that it is properly formatted, the copy of Sendmail running on your server does not have any knowledge of whether or not the host can actually deliver mail to this address. The delivery triple for the address is also displayed. The name of the internal mailer that Sendmail will use to transport mail to this address is esmtp, which is the default name for the extended SMTP mailer. The host to which Sendmail will transfer the mail is named_xy.com, and the e-mail address that the mail will be delivered to is ed@xy.com.
