accept_unresolvable_domains This tells Sendmail to accept mail from a source if the domain name of the source cannot be resolved by DNS. By default, Sendmail takes the hostname in the MAIL: header and asks DNS to map that name back to an address before it accept incoming mail. This option overrides default behavior.

Allowing mail from unsolvable domains is a security problem, but this feature is necessary for systems that do not have full-time DNS service. Systems are laptops that be disconnected from the network or systems behind a firewall that are not given DNS access. The Red Hat configuration includes this feature because Red Hat must create a configuration with the widest range of systems. If you have full-time DNS service for your network—and you—should remove this feature from your configuration.

The mailer installed by MAILER(procmail) is used only if you configure entries in the mailertable to use it.
