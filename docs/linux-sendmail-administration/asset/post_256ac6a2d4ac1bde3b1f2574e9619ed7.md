
# Appendix A m4 Macro Command Reference

confBLANK_SUB Defines the character used to replace unquoted blank characters in e-mail addresses. [BBlankSub]

confCACERT identifies a file containing a cryptographic certificate from a certificate authority. [CACERTFile]

confCACERT_PATH Defines the path to the directory that contains the cryptographic certificates. [CACERTPath]

confCF_VERSION Sets the Sendmail version number. [SZ]

confCHECKPOINT_INTERVAL Sets the maximum number of queued items processed before Sendmail checkpoints the queue. Default is 10. [CheckpointInterval]

confCHECK_ALIASES Looks up every alias during the aliases database. Default is false. [CheckAliases]

confCLIENT_CERT identifies the file containing the cryptographic certificate Sendmail uses when it acts as a client. [ClientFile]

confCLIENT_KEY identifies the file containing the private key associated with the certificate used when Sendmail acts as a client. [ClientKey]

confCLIENT_OPTIONS defines the port options for outbound SMTP client connections. [ClientPortOptions]

confCOLON_ON_ADDR Tells Sendmail to treat colons as regular characters in addresses. Default is false. [ColonInAddr]

confCONNECTION_RATE_THROTTLE Sets the maximum number of connections per second. [ConnectionRateThrottle]

confCONNECT_ONLY_TO defines limited connectivity. Only needed when Sendmail is tested by the developers. This is not used in production environments. [ConnectOnlyTo]

confCONTROL_SOCKET_NAME defines a socket for managing the Sendmail daemon. [ControlSocketName]

confEXPENSIVE Tells Sendmail to hold mail bound for mailers who have the e flag set in the next queue run. Defaults to false. [HoldExpensive]

confCOPY_ERRORS_TO Sets the email address that receives copies of error messages. [Postmaster]

confREL_FILE points to the file that lists the hosts for this server will relay mail. Defaults to /etc/mail/relay-domains. [$R]

confCT_FILE defines the file of trusted usernames. Defaults to /etc/mail/trusted-users. [$t]

confW_FILE points to the file of local host aliases. Defaults to /etc/mail/local-host-names. [$w]

# Complete Command Reference 369

confDEAD_LETTER_DROP Defines the file that failed messages that could not be returned to the sender or to the postmaster are saved. [DeadLetterDrop]

confDAEMON_OPTIONS Sets options for the Sendmail daemon. [DaemonPortOptions]

confDEF_AUTH_INFO Identifies the file that contains the authentication information for outbound connections. [DefaultAuthInfo]

confDEF_CHAR_SET Defines the default character set for unlabeled-8-bit MIME data. [DefaultCharSet]

confDEF_USER_ID Defines the user and group ID used by Sendmail. Defaults to 1:1. [DefaultUser]

confDELIVERY_MODE Sets the default delivery mode. Defaults to background. [DeliveryMode]

confDF_BUFFER_SIZE Defines the maximum amount of buffer memory that will be used before a disk file is used. [DataBufferSize]

confDH_PARAMETERS Identifies the file that contains the DH parameters for DSA/DH digital signature algorithm. [DHParameters]

confDIAL_DELAY Sets the dial used before retrying a "dial on" connection. 0 means "don't retry". Defaults to 0s. [DialDelay]

confDOMAIN_NAME Defines the system's hostname. [$j]

confBLAME_SENDMAIL Tells Sendmail not to perform security checks if set. By default, the checks are performed. Don't use this option. It is a threat to the security of your server. [DontBlameSendmail]

confDONT_EXP_NAMES Tells Sendmail not to convert nicknames to canonical names if true. Defaults to false. False means "do convert". [DontExpNames]

confDONT_INIT_GROUPS If true, disables the initgroups routine. Defaults to false. False means "the initgroups routine". [DontInitGroups]

confDONT_PROBE_INTERFACES Tells Sendmail not to automatically accept the addresses of your server's network interfaces as valid addresses if set to true. Defaults to false. [DontProbeInterface]

confDONT_PRUNE_ROUTES Tells Sendmail not to prune route-addresses to the minimum possible. Defaults to false, meaning that Sendmail will prune routes. [DontPruneRoutes]

confDOUBLE_BOUNCE_ADDRESS When errors occur while sending an error message, this option tells Sendmail the address to which to send the second error message. [DoubleBounceAddress]

# Appendix A m4 Macro Reference

confDIR Defines the directory where executables are stored. [Dir]

confERROR_MESSAGE Sets the error message header. Defaults to false. [ErrorMessage]

confERROR_MODE Defines how errors are handled. Defaults to 0. [ErrorMode]

confFALLBACK_MX Defines the backup MX host. [FallbackMx]

confFORWARD_PATH Defines the path to the forward file. [ForwardPath]

confEIGHT_BIT_HANDLING Defines how eight-bit data is handled. [EightBitHandling]

confIGNORE_DOTS Tells Sendmail to ignore dots. [IgnoreDots]

confLDAP_DEFAULT_SPEC Defines the defaults used for LDAP. [LdapDefaultSpec]

confLOCAL_MAIL Defines the mailer for local connections. [Local]

confLOG_LEVEL Defines the level of detail for log. [LogLevel]

confMAILER_NAME Defines the sender name used on error messages. [MailerName]

confMATCH_GECOS If set, Sendmail matches the e-mail username to the GECOS field. This match is not done if not. [MatchGecos]

confMAX_ALIAS_RECURSION Aliases can refer to other aliases. Sets the maximum depth alias can be nested. The default is 10. [MaxAliasRecursion]

confMAX_DAEMON_CHILDREN Refuses requests when this number of connection is reached. By default, connections are never refused. [MaxDaemonChildren]

confMAX_HEADERS_LENGTH Defines the maximum length of the sum of all headers. [MaxHeadersLength]

confMAX_HOP Defines the counter used to determine mail loops. Defaults to 25. [MaxHopCount]

confMAX_MESSAGE_SIZE Sets the maximum size for a message the server will accept. By default, no limit is set. [MaxMessageSize]

confMAX_MIME_HEADER_LENGTH Defines the maximum length of MIME headers. [MaxMimeHeaderLength]

confMAX_QUEUE_RUN_SIZE Defines the maximum number of entries in a single queue. Defaults to 0, which means everything in the. [MaxQueueRunSize]

confMAX_RCPTS_PER_MESSAGE Defines the maximum number of recipients for a piece of mail. [MaxRecipientsPerMessage]

confI_CACHE_SIZE Sets the number of open connections that can be cached. Defaults to 2. [ConnectionCacheSize]

confI_CACHE_TIMEOUT Sets the amount of inactive open connections are held in the cache. Defaults to 5m. [ConnectionCacheTimeout]

confME_TOO True to send a copy of the mail to the sender. Default is false. [MeTo]

confMIME_FORMAT_ERRORS True to send MIME-encapsulated error messages. The default is true. [SendMimeErrors]

confMIN_FREE_BLOCKS Sets the minimum number of blocks that must be available on the disk to accept mail. Defaults to 100. [MinFreeBlocks]

confMIN_QUEUE_AGE Sets the minimum time a job must be queued. Defaults to 0. [MinQueueAge]

confMUST_QUOTE_CHARS Adds characters to the list of characters that must be quoted when they are in the user's full name ($). The characters @;:![] are always quoted. By default and ' ' are added to the list. [MustQuoteChars]

confNO_RCPT_ACTION Defines handling for mail with no recipient headers.

- Do nothing
- add-to Add a To: header
- add-app way-to Add an Apparently-To: header
- add-bcc Add a Bcc: header
- add-to-undisclosed Add a To: undisclosed-recipients header
