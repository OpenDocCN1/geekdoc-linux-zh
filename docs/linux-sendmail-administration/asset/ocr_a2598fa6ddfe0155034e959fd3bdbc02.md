In addition to the verbose option, the sendmail command in Listing 1.2 is invoked with the -t option accepts the mail message directly from the keyboard. In Listing 1.2, the user types in To: address, From: address, a Subject: line, and a one-line message. The user input is terminated by Ctrl+D. Everything else in Listing 1.2 is displayed by Sendmail.

Three of the lines displayed are informational messages from Sendmail. The first line displays the reply: the delivery address craig@wren, the remote server name wen.foobirds.org, and the inbound mailer name esmtp. You'll hear much about the delivery triple later on. The other two lines created by Sendmail appear near the bottom of Listing 1.2. The first of these two lines displays the message used used to send the message, which is NAA01047 in the example. The second line informs us that Sendmail is ready to close connection.

Most of the output displayed by >>> is the SMTP protocol interaction. Every line that begins with a command sent from the local system to the remote system. Every line that begins with a response code is a response from the remote system. Only six commands are used to send the message:

EHLO is the hello command. It is different from the one shown in Table 1.1 because this is the extended hello by Extended SMTP, which is covered later in this chapter.

MAIL From: This is the From: address. Addresses in the SMTP protocol exchange are changed to envelope addresses and are distinct from the header addresses sent as part of the message data, although header addresses and envelope addresses usually contain the same values. You'll hear more about different address types when we discuss address rewriting and testing in Chapter 8, “Understanding Rules."

RCP To: This is the To: address. It is also an envelope address.

DATA The DATA command marks the beginning of the message.

+   - The Dot (.) is used to mark the end of the message.

QUIT The QUIT closes the session.
