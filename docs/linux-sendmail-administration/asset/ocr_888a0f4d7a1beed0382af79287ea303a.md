The template uses a literal + plus the values from $2 (@imaginary.com) as the key. The database returns david@lion.mammals.org as the value for that key—just what you would expect from the cat of virtuertable.

The second test demonstrates the use of arguments. It passes the address jim@other.org to DBTest and gets jim@local.org in response. The key @other.org matches the value @1.local.org. The $1 is the argument, so $1 is rewritten to jim, and the final value returned by the rule is jim@local.org.

The final test illustrates the use of the default value. The third test passes the address info@patient-rights.org. A quick look at the cat of virtuertable shows that info@patient-rights.org is a valid key and when sara@hawk.foobirds.org shows the value assigned to that key. But DBTest does not return the value sara@hawk.foobirds.org. Here's why. info@patient-rights.org matches the pattern $@$. The template uses $2, which in this case is @patient-delivery.org, as the key. @patient-rights.org is missing the string info before the @ which is a key not found in this database. The database returns the value defined as the default, or if no default is defined. In this case, if no default were defined the value returned would be @patient-rights.org. However, a default was defined as: $102, so the value returned is info@patient-rights.org—the original address. Using a default is particularly important in a database like virtuertable, which uses different keys, is normally searched by a series of related rules that try all of the keys. If DBTest contained another rule that used the input address as the key, info@patient-rights.org would return sara@hawk.foobirds.org.

The virtuertable used in the examples takes an input address as the key and returns a different address as the value, in most cases. However, two of the virtuertable start with the word error and do not appear to be e-mail addresses. They aren't. They are a special type of rewrite rule used in ruleset 0 (ruleset parse).

# Special Ruleset 0 Rewrite Rules

There is a special rewrite syntax that is used in ruleset 0. Ruleet 0 defines the triple (mailer, host, recipient) that specifies the mail delivery program, the recipient host, and the recipient user. The special template syntax to use this is:

```
$# mailer $ host $: user
```
