List 10.11 an excerpt from the middle of a long sendmail -bt run. The first line shows us the contents of a variable. $m asks for the values stored in variable m is. From Chapter 9 we know that m contains the masked value. When it is empty, masking is turned off. The first /try test processes the address craig@wren.foobirds.org as a header sender address. The output of the final ruleset shows that the address is not masked. We then store the value foobirds in variable m using the command .Dfoobirds.org, where .D is the command, m is the variable name, and foobirds is the value. A second /try test with the address craig@wren.foobirds.org returns the masked address craig@foobirds.org. We changed the Sendmail configuration and observed the impact of the change in real time.
