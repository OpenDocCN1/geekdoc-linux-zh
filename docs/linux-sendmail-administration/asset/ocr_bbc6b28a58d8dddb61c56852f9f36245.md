+   - divert is set to 0 to direct the stream to the output file—e.g., sendmail.cf. If the divert(-1) command is used at the start of a large comment, divert(0) is used at the end of the command to redirect the stream to the output file.

The dn1 command is also used to control the output stream. The dn1 command accepts no arguments. Its two basic functions are determined by its position on the command line:

+   - If the dn1 command occurs at the end of a line, after another m4 command, it is used to clean up unwanted blank lines from the output file. For example, on the line OSTYPE(linux)dn1 ensures that any extraneous output generated after the linux OSTYPE macro expands not get written to the sendmail.cf.

+   - If the dn1 command occurs at the beginning of the line, it is treated as a comment. For example, the line dn1 define the domain is a comment. If the sample line did not begin with dn1, m4 would interpret “define” and “domain” as m4 commands. Messy! Always start each comment with dn1, unless it is a large comment bracketed by divert commands.

The divert and dn1 commands direct m4 output but they do not define or generate the output data. The other m4 commands are used to generate the actual configuration file.

# The Basic Commands

In terms, there are two types of files used to build an m4 configuration. One of these is the macro configuration file, which is traditionally identified by the .m4 extension. The macro configuration file is the input file for the m4 command, and its name appears on the m4 command line. The other files are m4 source files that are referenced by the macro configuration file. Traditionally, m4 source files are given the file extension .m4. Almost all m4 commands from Table 4.1 can appear in either type of file, although three of the commands are generally found only in the macro configuration file:

OSTYPE The OSTYPE macro is required, and it is always found in the macro configuration file. The OSTYPE command loads an m4 source file that defines system-specific information. The file and directory paths, mailnames, and system-specific major arguments are the kind of information generally found in OSTYPE file. The Sendmail source distribution provides more than 40 predefined operating system macro files, and you can create your own for a specific Linux distribution if you like.(We discuss this option when we evaluate the vendor-supplied macro configuration files in the next chapter.) The only argument passed to the OSTYPE command is the name of the m4 source file that contains the system-specific information. Here is the command that processes the linux.m4 OSTYPE source file:

```
OSTYPE(linux)
```
