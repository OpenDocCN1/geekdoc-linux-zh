# Use Sendmail to Block Spam 313

rulesets allow you to process the addresses and headers from incoming mail. Sendmail provides two anti-spam rulesets for your personal rules. These are:

Local_check_relay This is a ruleset where you can define rules for handling mail that is being relayed.

Local_check_rcpt This is a ruleset where you can define rules to process mail based on the recipient address.

Local_check_mail This is a ruleset where you can define rules to process mail based on the sender address.

Assume that you have been receiving mail that is trying to masquerade as local by using a From: address that contains only a username. Further, assume that you have configured your mail server so the From: address of mail always includes the hostname. You use Local_check_mail: to check the sender address as shown in Listing 11.4.

# Listing 11.4 A Simple Anti-Spam Ruleset

```
Slocal_check_host
# Check for user@host
R$ @ $+
	$ \$OK
R$ $ $$Error: 550 Invalid the ruleset
```

The first line in Listing 11.4 is an S command that defines the name of the ruleset Local_check_mail. The first R command matches the incoming address against the pattern $+ @ $+$, which looks for one or more tokens (+), a literal at-sign (@), and one or more tokens. In any address of the form of user@host this pattern matches. The formation says that if the address matches the pattern, the exit ruleset ($) and the mail name #OK to calling the ruleset. The mail name #OK is a phony user to indicate that the address is valid.

The second R command matches every address that failed to match the first. For all of these addresses the rule returns the mail name $$Error and the text of an error message. The $$Error mail is a special that returns the mail to the sender along with an error message. An alternative to this would have been the $$dcard mail that silently discards the mail. Most administrators prefer to return an error message.

> NOTE The ruleset in Listing 11.4 is just a teaching example, which was designed to be easily explained and reasonably focus addresses and the various valid address formats.
