The directory contains files for more than 40 operating systems. Solaris, BSD, Linux—are all here and identified by name. In fact, there are many more operating system definitions in the /cf/cf directory. One thing that I find slightly surprising is that there are at least as different AIX 3 as AIX 4, yet different Linux distributions create OSTYYPE files. It doesn't matter. You can start with the standard Linux OSTYYPE and do all of your customization in the configuration file you build in the cf/cf directory.

# The mailier directory

In addition to an OSTYPE command, every usable server configuration must have at least one MAILER command. MAILER contains process files from the cf/mailer directory. Each file in the mailier directory contains the definition of a set of mailers. Listing 4.5 shows the mailier definitions defined with Sendmail 8.11.

# Listing 4.5 The Contents of the cf/mailer directory

```
[craig]$ ls -l mailier
cyrus.m4 local.m4 phquery.m4 procmail.m4 smtp.m4 uucp.m4
fax.m4 mail11.m4 pop.m4 qpage.m4 usenet.m4
4
```

The directory contains definitions for 11 different sets of mailers, all of which are described in this text. In this chapter, we use only the two most basic sets of mailers: local1.m4 for local mail delivery and smtp.m4 for SMTP mail delivery.
