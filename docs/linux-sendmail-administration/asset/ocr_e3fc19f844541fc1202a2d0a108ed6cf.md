happythings.com. The following two lines in the virtuertable would route mail to the
correct employee regardless of the domain to which it was addressed:

```
@funstuff.com               %1stuffycorporation.com
@happythings.com         %1stuffycorporation.com
```

The last line in Listing 6.10 shows that the +detail value in the +detail syntax can be
passed to the outbound address as Mail sent to sales+info@thatplace.com would be deliv-
ered to info@newplace.com and mail sent to +detail sent to sales+orders@thatplace.com would be deliv-
ered orders@newplace.com. Notice that the use of +detail syntax must be indicated
the first field of the virtuertable by placing +before in the virtual
address domain. Use of e-mail addresses enough without using the +detail
syntax. For this reason, the syntax is rarely used unless you have a program that-
automatically generates this syntax for the user. It is covered here the sake of completeness,
but you will probably not use it in your configuration.

Before the virtuertable can be used by Sendmail, it must be turned into a has data-
base using makedmap. Listing 6.11 shows a successful build and test of the virtuertable
database.
