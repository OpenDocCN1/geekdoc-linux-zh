# Table 8.2 Rulesets Found in the Mailer Declarations Section (continued)

| Name | Number | Description |
|---|---|---|
| HdrFromSMTP | 31 | Rewrites the header sender address. |
| MasqRelay | 71 | Handles masquerading for the relay mailer. |

| EnvTol | 20 | Rewrites the envelope recipient for the local mailer. |

| AddDomain | 50 | Adds the local domain for the always_add_domain feature. |

Most of these rules deal with rewriting sender and recipient addresses in the envelope and the header. That's to be expected. After all, the S and R parameters of the mailer command (M) identifies the ruleset used to rewrite sender addresses and recipient addresses for a specific mailer. It is only natural that these rulesets are included in the Mailer Definitions section of the sendmail.cf file.

Listing 8.1 shows two of these rulesets: EnvTol and HdrFromL. Each ruleset starts with an S command, and when the next S command is encountered. Therefore, the EnvTol contains only one rule, while the HdrFromL rules contains four rules.

# Listing 8.1 Two Simple Rulesets

```
#
# Envelope recipient writing
#
EnvTol=20
R$ < $@ $: $      strip host part

#
# Header sender rewriting
#
SHdrFromL=30
R<$> $n               errors to mailer-daemon
R < $@ $:n               temporarily bypass Sun bogosity
R$+ $:>AddDomain $1      add local domain if needed
R$ $:>MasqHdr $1      do masquerading
```
