# The local-host-names File

In Chapter 5, both the generic Linux configuration and the Red Hat configuration contain the FEATURE(use_cw_file) command. That feature reads the /etc/mail/local-host-names file and adds the hostnames listed there to the hostnames and addresses defined in class w. Listing 5.4 in Chapter 5 shows that, by default, class w contains the special name localhost, 127.0.0.1, and the system's IP addresses, full domain names, and unqualified hostnames. Anything you put in local-host-names is added to these default values.

The system checks w to decide or not it should accept inbound mail for local delivery. The Sendmail server only accepts mail for local delivery that is addressed to the server. Yet many systems might use the Sendmail server as a mailbox to collect and hold their mail. If the mail that the server should collect and hold is literally to another system, the name of that system needs to be added to class w. The other system's hostname is treated by Sendmail as if it were an alias for names. Mail addressed to systems listed in class w is accepted as if it were addressed to the server. An example will make this clear.

Assume that robin.foobirds.org is a PC that uses the wren.foobirds.org as a mailbox to collect and hold mail. An MX record is placed in the DNS server that directs robin's mail to wren. Listing 6.3 shows what happens when logon on bear.mammals.org sends mail to robin on logon on bear.mammals.
