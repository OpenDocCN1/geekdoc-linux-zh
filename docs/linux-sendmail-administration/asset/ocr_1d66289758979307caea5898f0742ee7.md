# Options

A large number of Sendmail options are set inside of the sendmail.cf file. Chapter 7 describes the Options section of the sendmail.cf file and provides several examples of the options. The complete list of options is shown below.

AliasFile=[type:]path, [type]:path... Specifies the location of the aliases file(s). path is the pathname of the aliases file. type is the aliases database type. Valid types are implicit, hash, dbm, stab (internal symbol table), or nis. The selected database must be compiled into Sendmail on your system. type defaults to implicit.

AliasWait=timeout Defines the amount of Sendmail waits for @: entry to appear in the aliases database during start-up. The @: signals the end of the aliases database. If @: is not found, it means the database is being rebuilt. The timeout expires while @: being detected, Sendmail automatically rebuilds the database if AutoRebuildIdAliases is set, otherwise it issues a warning message and continues on.

AuthMechanisms=list Lists the supported authentication mechanisms.

AuthOptions Lists the options supported by the SMTP auth command.

AllowBogusHELO Tells Sendmail to accept illegal HELO SMTP commands that dont not contain a hostname. Breaking the protocol rules is not a good idea.

AutoRebuildIdAliases Causes Sendmail to automatically rebuild the aliases database when necessary. The preferred method is to rebuild the aliases database with an explicit aliases command.

BlankSub= Uses c as the blank substitution character to replace unquoted spaces in the addresses. The default is to replace spaces with dots (.).

CACERTFile=filename Identifies the file that contains the certificate of a authority.

CACERTPath=path Defines the path to the directory that contains the certificates of various certificate authorities.

CheckAliases Tells Sendmail to check the delivery address for each alias is valid when rebuilding the aliases database. Normally, this check is not done. Adding this check slows the database build substantially.

CheckpointInterval=n Causes Sendmail to checkpoint the queue after every n items are processed to simplify recovery if your system crashes during queue processing. The default is 10.

ClassFactor=factor factor is the multiplier for messages with a higher value in the Priority: defaults to 1800.
