Whenever new virtual domains are added to the file, send Sendmail the SIGHUP signal to make sure it reads the new values and loads them into class (VirthHost).

> TIP Both the VIRTUSER_DOMAIN and VIRTUSER_DOMAIN_FILE macros require changing and rebuilding the sample configuration. Because we already had the local-host-names file in our configuration, it would be easier to add the virtual domains to that file. It works just well because Sendmail checks both w and class (VirthHost) when processing virtual domains.
