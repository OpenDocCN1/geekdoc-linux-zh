You can also learn the PID by displaying the sendmail.pid file:

```
[root]# head -1 /var/run/sendmail.pid
542
```

Combining the last command with kill, you can send a signal directly to Sendmail. For example, to restart Sendmail you could enter the following command:

```
kill -HUP head -1 /var/run/sendmail.pid
```

The head -1 /var/run/sendmail.pid command that is enclosed in single quotes is processed by the shell first. On our few Linux system, the first line of the sendmail.pid file contains the PID 542. That is combined with the shell and processed as kill -HUP 542.

Signals, boot scripts, and everything else in this section has assumed that you have Sendmail already installed in your system. In the next section, we look at how to install Sendmail if you don't have it or if you want to upgrade to the latest release.

# Installing Sendmail

Sendmail is delivered with every major Linux distribution, and it is normally installed as part of the initial Linux installation. If it is not installed at that time, it can easily be added later using one of the package-management systems available for Linux.
