The =M command displays all of the mailers in the current Sendmail configuration. All of the fields displayed by =M are the fields in the "Mailer Definitions" section of Chapter 7, The Sendmail.cf File." But there are a couple of interesting things displayed by the =M command that cannot be found by simply searching the sendmail.cf file. First, you will notice that each mailer has an identifying number as a name. Second, and, there are two mailers that do not appear in the sendmail.cf file:

+   *file The *file mailer is an internal mailer used to send the contents of a mail message to a file.
*include The *include mailer is an internal mailer that attaches the mail message to a :include list.
