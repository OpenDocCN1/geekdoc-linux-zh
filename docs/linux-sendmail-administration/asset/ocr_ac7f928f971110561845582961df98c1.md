address, but it's not exactly what you want. You want to hide the hostname in outbound e-mail by using user@foobirds.org. Sendmail calls hiding the real hostname “masquerading.” Chapter 9, “Special m4 Configurations,” provides much more coverage on masquerading, but for now all we need to know is that we want to masquerade as foobirds.org.

To create the new configuration, you need to understand the purpose of the macro variable, found in the Local Info section of the sendmail.cf file. The comment for the D command that sets M says "who I masquerade as." Checking Listing 7.1, you find that no value is assigned to macro M, which means masquerading is not being used. To replace the name of the local host in outbound mail of the domain, set M to the domain name, as shown below.

+   # who I masquerade as (null for no masquerading)
Dmobirds.org

Given value for M, parrot rewrites the sender addresses on outbound mail
user@Foobirds.org.

After setting a value for the M macro in the test.cf file, run a test to see if it works. Running Sendmail with the test configuration does not affect the Sendmail daemon that was started by the boot script. A separate instantiation of Sendmail is used for the test.

# Testing Your New Configuration

To test the new configuration, run the sendmail command with the -bt option. Sendmail displays a welcome message and waits for you to enter an address. The details of testing Sendmail of the -bt syntax are covered in Chapter 10, “Testing Sendmail.” For now, all you need to know is that we want to see if the header address is properly rewritten to masquerade the hostname as the domain name when we send outbound SMTP mail. /tryflags command lets request header address processing and the /try command lets us process the sender address for the smtp mailer. First, test the existing configuration to see how the address is processed by the default configuration:

```
[root]# sendmail -bt
ADDRESS TEST MODE (ruleset 3 NOT automatically invoked)
nEnter <ruleset> <address>
> /tryflags HS
> /try smtp craig
Trying header sender address craig for mailer smtp
```
