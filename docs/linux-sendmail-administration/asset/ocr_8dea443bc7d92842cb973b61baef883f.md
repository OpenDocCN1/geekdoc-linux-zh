In Listing 11.2, the administrator of wen used grep to check that the sendmail.cf file is already configured to read the relay-domains into class R. If it wasn't, a configuration file using either the confFR_FILE option or the RELAY_DOMAIN_FILE macro, would be needed before the relay-domains would be effective. After configuring the relay-domains, the administrator passes Sendmail a SIGHUP signal to make sure it reads the new configuration. After the reload, wen relays mail for any system in the mammals domain, including ox.mammals.org, as the final test clearly shows.

The first two values illustrate that individual hosts can be granted relay privileges either by specifying the host's fully qualified name or by specifying the host IP address.
