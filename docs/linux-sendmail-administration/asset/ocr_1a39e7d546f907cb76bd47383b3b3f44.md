For example: From the discussion of the MAILER(smtp) command in Chapter 5, you know that Sendmail sends out SMTP using the smtp mailer and that there are other mailers available to handle SMTP in special ways. One of these is the smtp mailer that is designed to sign-eight MIME data that cannot understand Extended SMTP. If the domain cluelesscollege.edu used such a mail server, you could put the following entry into the mailertable to handle the mail:

```
.cluelesscollege.edu    smtp8:0ldserver.cluelesscollege.edu
```

A mailtable contains two fields. The first is the key. It contains the portion of the delivery address. It can contain either the full name of the host—e.g., emma.cluelesscollege.edu—or the domain name. To specify a domain name, start the name with a dot, as in the example below. If a domain name is used, it matches every host in the domain.

The second field in the entry is the value returned for the key. It normally contains the name of the server to which the mail should be sent and handle the mail of the server to which. Optionally, a username can be specified with the server address in the user@server. Additionally, the mailer that is specified by the internal error mailer. If the error message is used, the value following the mailer name is an error message instead of a server name. Here is an example of each of these alternatives:

```
.cluelesscollege.edu    smtp8:0ldserver.cluelesscollege.edu
booby.foobirds.org      smtp:postmaster@wren.foobirds.org
dodo.foobirds.org        error:no host is extinct
```

Normally, mail passing through the mailertable is sent to the user to which it is addressed. For example, mail@emma.cluelesscollege.edu is sent through the smtp mailer to the server oldserver.cluelesscollege.edu. Adding a username to the second field, however, changes this normal behavior and causes Sendmail to mail to the individual instead of a mail server. For example, mail sent to any user at booby.foobirds.org is sent to postmaster@wren.foobirds.org. There, the mail is handled manually. Finally, mail handled by the mailertable does not have to be delivered at all. Instead, an error message can be returned to the sender. Any mail sent to dodo.foobirds.org returns the error message “This host is extinct” to the sender. The error message is constructed exactly as it is for the virtertable, using either the Sendmail error condition keywords or the DSN error codes.
