# In Sum

A Sendmail configuration is not built from scratch. Start from one of the sample files that is provided as part of the Sendmail source code distribution or start with the configuration that comes from your distribution vendor. Read and understand the vendor's configuration before modifying it to create your own. Don't assume the vendor's configuration is right for you. A vendor often makes compromises to create a configuration that runs on a wide variety of systems. Focus on the configuration you create on those capabilities you actually need.

Starting from a sample configuration can simplify the creation of your configuration, the sample configurations carry their own level of complexity. Some, like generic-linux.mc, are reasonably simple, but may not provide the features you need. Others, like redhat.mc, are more complex than necessary. The way to attack the complexity of the sample configuration files is one line at a time. Even with a reference, as this book, you get a general idea of what each line does. Using fewer than 30 lines. Discard those that are clearly unnecessary for your configuration. Research the others in more detail to select those that you want to keep.

The analysis of the configurations in this chapter has shown that Sendmail relies heavily on database files to route mail, convert addresses, and control spam. In the next chapter, we look at the databases used by Sendmail and describe how you can use those databases to configure your system.
