Masquerading and databases are one way to rewrite addresses, but they are not the only way. Addresses can be directly rewritten using custom rewrite rules. m4 provides several macros for inserting rewrite rules and their supporting configuration variables into the `sendmail.cf` file. In addition to the various techniques for rewriting addresses, which usually apply to servers that are handling their own mail, we looked at the m4 configuration options that are used to create a mail relay client. m4 provides ten different relay options. Understand this, and you have mastered 99 percent of relay client configuration.
