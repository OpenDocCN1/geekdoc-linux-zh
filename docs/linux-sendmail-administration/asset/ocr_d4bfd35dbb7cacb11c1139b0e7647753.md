# The Sendmail-cf RPM Files

In this chapter, the cf directory and its subdirectories are described as part of the Sendmail source code distribution. These same files, however, are available as part of an RPM installation. In Chapter 3, we installed the RPM version of the cf directory. It was the RPM package identified as sendmail-cf-8.11.0-1386. It contains all of the files that are described in this chapter. The only difference is the location of the files. To find out where the files are stored, run an rpm query and ask for a file list:

```
```rpm -q -l sendmail-cf ```
```

On our sample Red Hat system, this command shows that the cf directory is named /usr/lib/sendmail-cf. A listing of /usr/lib/sendmail-cf shows you the following:

```
```craig$ ls /usr/lib/sendmail-cf ```
```

```
README domain feature hack mailer otype sh siteconfig
```

If, you're using an RPM installation, /usr/lib/sendmail-cf is equivalent to cf in these discussions. The same README and the nine subdirectories appear in /usr/lib/sendmail-cf on an RPM installation as appear in cf on a source installation. Everything covered in this chapter applies regardless of how you have installed Sendmail 8.11.
