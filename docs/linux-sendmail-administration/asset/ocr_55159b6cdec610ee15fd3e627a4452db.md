The rulesets shown in Figure 8.1 and described in the list above are automatically called by Sendmail, but that doesn't mean they necessarily exist in your configuration. Two good examples of these are ruleset 1 (sender) and ruleset 2 (recipient). By default, these rulesets are empty and thus not defined in the sendmail.cf file for Sendmail 8.11. (We'll see in Chapter 9, "Special m Configurations," that you can define your own rewrite rules for rulesets 1 and 2, if needed). The fact that these rulesets are not defined in the sendmail.cf file does not cause Sendmail any problems. It simply calls them and goes on to the next ruleset when they are not found.

# More Rulesets

The six rulesets described so far are only those directly called by Sendmail. There are many rulesets defined in the sendmail.cf file. For example, the sendmail.cf file created by the redhat.mc macro configuration has 47 rulesets. Other rulesets provide additional address processing.
