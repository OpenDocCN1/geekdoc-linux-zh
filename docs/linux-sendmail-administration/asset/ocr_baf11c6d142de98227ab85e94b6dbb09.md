The mailq command starts Listing 10.7 has two command-line arguments: -qScraig and -qR@goat.mammals.org. These arguments select queued mail that is from the sender address craig (-qScraig) and addressed to anyone on the host (-qR@goat.mammals.org). In this example, a partial recipient address is specified. A full address or any part of address can be used to match sender or recipient addresses.
