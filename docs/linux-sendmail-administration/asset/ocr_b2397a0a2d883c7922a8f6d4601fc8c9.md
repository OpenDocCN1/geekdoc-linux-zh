# Appendix C Sendmail Variables, Options, and Flags

Table C.4 Possible Settings for the DontBlameSendmail Option (continued)

| Keyword | What It Tells Sendmail |
|---|---||
| GroupWritableAliasFile | Accept the aliases file if it is group-writeable. |
| GroupWritableDirPathSafe | Accept all group-writeable directories as "safe". |
| GroupWritableForwardFileSafe | Accept a . forward file if it is group-writeable. |
| GroupWritableIncludeFileSafe | Accept :include: files even if they are group-writeable. |
| HelpInUnsafeDirPath | Accept the help file if it is in an unsafe directory. |
| IncludeFileInUnsafeDirPath | Accept :include: files even if they are unsafe directories. |
| IncludeFileInUnsafeDirSafe | Accept program and file references from an :include: file even if it is in an unsafe directory. |
| IncludeFileIngroupWritableDirPath | Accept an :include: file even if is in a group-writeable directory. |
| InsufficientEntropy | Use STARTTLS if the random generator for SSL is inadequate. |
| LinkedAliasInWritableDir | Accept an aliases that is a link in a writeable directory. |
| LinkedClassInWritableDir | Load class values from files that are links in writeable directories. |
| LinkedForwardFileInWritableDir | Accept . forward files that are in writeable directories. |
