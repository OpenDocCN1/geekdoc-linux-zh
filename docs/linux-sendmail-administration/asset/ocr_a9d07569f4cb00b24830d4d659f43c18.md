The precedence of the relays defined by these parameters is from the most specific to the least specific. If both the UUCP_RELAY and the SMART_HOST relay are defined, the UUCP_RELAY is used for outgoing UUCP mail even though the SMART_HOST relay is defined as handling "all" outgoing mail. If you define both LOCAL_RELAY and MAIL_HUB, use the FEATURE (sticky)host to handle the LOCAL_RELAY handle all local addresses that do not have a host part, and MATL_HUB handle all local addresses that have a host part. If stickyhost is not specified and both relays are defined, the LOCAL_RELAY is ignored and MAIL_HUB handles all local addresses.

In addition to the defines shown in Table A.4, macros that relate to masquerading and relaying also appear in the DOMAIN source file. These macros are:

+   * LOCAL_USER (usernames) This defines defines usernames that should not be relayed even if LOCAL_RELAY or MAIL_HUB are defined. This command is the same as adding usernames to class L in the sendmail.cf file.

+   * RELAY_DOMAIN(otherhost.domain) This macro identifies a host for which mail should be relayed. The host identified in manner is added to class R.

+   * RELAY_DOMAIN_FILE(filename) This macro identifies a file that contains a list of hosts for which mail should be relayed. This macro loads R from the specified file.

+   * MASQUERADE_AS(host.domain) This macro converts the host portion of the sender address on outgoing mail to the specified name. Sender addresses that have no hostname or have a hostname found in the w class are has the same effect as the M macro in the sendmail.cf file. Examples of MASQUERADE_AS and variable M in Chapter 9.

+   * MASQUERADE_DOMAIN(otherhost.domain) This macro converts the host portion of the sender address on outgoing mail to the domain name defined by the MASQUERADE_AS command, if the host portion of the sender address matches the value defined there. This command must be used in conjunction with MASQUERADE_AS. Its effect is the same as adding hostname to class M in the sendmail.cf file. Chapter 9.

+   * MASQUERADE_DOMAIN_FILE(filename) This macro loads M hostnames from the specified file. Its effect is the same as using the Fm1filename command in the sendmail.cf file.

+   * MASQUERADE_EXCEPTION(host.domain) This macro defines a host that is not masqueraded, even if it belongs to a domain that is being masqueraded. This allows you to enlace an entire domain with the MASQUERADE_DOMAIN macro and then exempt a few hosts that should be exposed to the outside world.
