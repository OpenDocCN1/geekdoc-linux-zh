# 302 Chapter 11 Stopping Spam

Windows clients that can't run their own Sendmail program. Blocking relaying at the server causes the client to get an error. For example, a client running Netscape Messenger would get a pop-up box saying “An error occurred while sending mail. The mail server responded: Relay denied. Please check the message recipients and try again. There is nothing wrong with the recipients. What is wrong is that the user configured the “Outgoing mail SMTP server” with the name of your server, and your server is running the default Sendmail configuration, which denies relaying.

To create a server, you must allow some level of relaying. The Sendmail feature that relaxes relay restrictions just enough to get the job done. Don't overdo it, or you will open the door to spam. There are several relay features from which you can choose.

Class R can be used to extend relaying services to specific clients. As described in Chapter 6, there are three ways to store hostnames in class R. Individual values can be stored in class using the RELAY_DOMAIN macro. A file can be loaded into Class using either the confR_FILE option or the RELAY_DOMAIN_FILE macro. The “Relay-domains File” section of Chapter 6 for more information about these commands.
