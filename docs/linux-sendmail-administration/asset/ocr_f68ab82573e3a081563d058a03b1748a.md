# Listing 3.2 The Sendmail Link for Runlevel 3

```
[craig]$ cd /etc/rc/rc3.d
[craig]$ ls -l S80sendmail -> ../init/sendmail
lrwxrxr-x 1 root 18 Dec 26 1999 S80sendmail
```

To enable or disable the sendmail start-up script for a specific runlevel, simply add or remove the symbolic link in thatlevel's directory. In itself this would be simple enough, Linux systems make it easier by providing tools to manage the runlevel directories.
