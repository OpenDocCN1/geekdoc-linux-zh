## Options

A large number of Sendmail options are set inside of the sendmail.cf file. Chapter 7 describes the Options section of the sendmail.cf file and provides several examples of the options. The complete list of options is shown below.

- AliasFile=[type:]path Specifies the location of the aliases file(s).
- AuthMechanisms=list Lists the supported authentication mechanisms.
- AuthOptions Lists the options supported by the SMTP auth command.
- AllowBogusHELO Tells Sendmail to accept illegal HELO SMTP commands that dont not contain a hostname.
- AutoRebuildAliases Causes Sendmail to automatically rebuild the aliases database when necessary.
- BlankSub=c Uses c as the blank substitution character to replace unquoted spaces in the addresses.
- CACERTFile=filename Identifies the file that contains the certificate of a authority.
- CACERTPath=path Defines the path to the directory that contains the certificates of various certificate authorities.
- CheckAliases Tells Sendmail to check the delivery address for each alias is valid when rebuilding the aliases database.
- CheckpointInterval=n Causes Sendmail to checkpoint the queue after every n items are processed.
- ClassFactor=factor factor is the multiplier for messages with a higher value in the Priority.
- AliasWait=timeout Defines the amount Sendmail waits for @: entry to appear in the aliases database during start-up.
