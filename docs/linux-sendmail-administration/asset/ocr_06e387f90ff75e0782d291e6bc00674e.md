Another level of aliasing occurs after the recipient is processed through the aliases data-
base. The aliases database defines mail forwarding for the entire system. The .forward
file, which can be created in any user's home directory, defines mail forwarding for an
individual user. Sendmail identifies the user to whom the mail will be delivered, or
looks for a .forward file in the user's home directory. If the .forward file is found, the
mail is forwarded to the e-mail address contained in that file. If the file is not found or
empty, the mail is delivered directly to the user's account.

The Sendmail terms “forwarding” and “relaying” are often used interchangeably, but
there a slight difference. Referring to the act of transferring to another host
mail that was originally addressed to the local host. For example, if mail addressed to
norm the local host is sent to normane@hawk.foobirds.org as a result of aliasing, you
would say the mail has been forwarded to hawk.foobirds.org. Relaying, which is
next topic, is subtly different.

# Mail Relaying

Relaying occurs when mail is transferred toward its destination and neither the source
or the destination address of the mail is the address of the local system. For example: If
a server named wen.foobirds.org receives mail from ibis.foobirds.org that is
addressed to craig@wrotebook.com and re-sends that mail to the host
wrotebook.com, is acting as a mail relay.

At one time mail relaying was the default configuration for Sendmail systems, but no
more. Spammers use unsuspecting mail servers to relay their spam in order to hide the
true origin of the nuisance mail. Now the default configuration is to relay no mail at all.

By default, Sendmail does not relay mail. A server accepts mail addressed to the server
itself or any of its local hostname aliases. It rejects all other mail. To enable relaying,
specific names of the hosts or domains that are allowed to relay mail must be pro-
vided to Sendmail. The hostnames of relay clients can be provided in the relay-domains
file or through the access database. Both of these files are covered in Chapter 6.
