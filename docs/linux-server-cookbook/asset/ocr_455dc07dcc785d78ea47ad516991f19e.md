The command **ansible-playbook** includes the options **--list-hosts** and **--list-tasks**, which are useful to see which hosts are going to be used and the tasks defined in the **Playbook**. [Figure 12.22](Figure 12.22) shows an example output:

```
agonzalez@ansible:~/playbooks$ ansible-playbook --list-hosts playbook1.yaml

playbook: playbook1.yaml

 play #1 (linux): Configure Linux systems  TAGS: []
  pattern: ['linux']
  hosts (2):
    ubuntu
    rhel
```

The option **--list-tasks** can be seen in [figure 12.23](figure 12.23):

agonzalez@ansible:~/playbooks$ ansible-playbook --list-tasks playbook1.yaml

playbook: playbook1.yaml

 play #1 (linux): Configure Linux systems  TAGS: []
  tasks:
