+   * **Names**: The name of the container. If a name is not specified during the execution, an auto-generated one is assigned.

It is possible to interact with a container after creating it. This is useful for troubleshooting. The options used for this purpose are as follows:

+   * **-tty (-t)**: Allocate a pseudo-TTY
+   * **-interactive (-i)**: Keeps **standard input (STDIN)** open.

The *hostname* of the pod is assigned to the auto-generated ID for the pod. It is possible to specify the *hostname* for the pod with the option **-\--hostname (-h)**. Exiting a container by writing the command *exit* in the shell, the *container* will be stopped after the session is closed. To disconnect from the *container* without stopping it, it is required to press the combination *Ctrl-L-P* followed by *Ctrl-Q*.
