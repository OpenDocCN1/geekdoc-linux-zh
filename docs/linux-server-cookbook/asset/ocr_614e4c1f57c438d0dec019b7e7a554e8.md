Other useful statements available in a Dockerfile are described in table 13.2:

| Statement | Description |
| :--- | :--- |
| LABLE | Adds metadata to an image. Information such as the maintainer, the software version, or any other information. |
| ADD | Adds files to the image. The differences with COPY are two: <br>• If a directory is specified, only the content is copied and not the parent directory. <br>• If the file to be added is a compressed file, it will be automatically uncompressed |
| ENTRYPOINT | By default, containers are used to execute the commands specified using /bin/sh. With this statement, it is possible to change this behavior, specifying other commands as an entry. |
| VOLUME | Specifies the volumes to be created to have persistant storage. |
| USER | Specifies the user to be used to execute the commands specified in the Dockerfile. |
