To access the logs generated by the container, the command **docker** and the argument **logs** are required. It is possible to specify the name of the *container* or the *ID* in long format (64 characters) or short format (12 characters). *Figure 13.10* shows the logs from the previous *container*:

```
```
root@ubuntu:~# docker logs testconsole
root@e67b41d7cc70:~# cat /etc/debian_version
11.5
root@ubuntu:~#
```
```
