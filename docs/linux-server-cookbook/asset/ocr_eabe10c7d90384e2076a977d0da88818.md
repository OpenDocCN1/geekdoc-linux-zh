# ## Collections

From version 2.10 of Ansible, a new distribution format for the content was introduced. A collection can include Playbooks, Roles, Modules, and Plugins. The main goal is to reduce the number of modules in the core of Ansible and be more flexible with the new distribution of the content. Collections have the format of namespace_name.collection_name. The directory structure is the following:

```
ansible_collections/
└── namespace_name
    └── collection_name
├── docs/
├── galaxy.yml
├── meta/
│   └── runtime.yml
├── plugins/
│   ├── modules/
│   │   └── module1.py
│   ├── inventory/
│   └── .../
├── README.md
├── roles/
│   ├── role1/
│   ├── role2/
│   └── .../
└── playbooks/
```
