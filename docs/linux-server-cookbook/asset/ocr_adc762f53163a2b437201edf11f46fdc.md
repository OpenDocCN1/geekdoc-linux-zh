# # Flavors

To run a *Virtual Machine*, it is required to specify the resources required. For that, a *flavor* is specified during the creation. A *flavor* contains how many *virtual CPUs*, memory, and disk the *Virtual Machine* will have associated. *Figure 16.9* shows the creation of a flavor named **m1.small**:

```
[stack@client ~]$ openstack flavor create m1.small --ram 2048 --disk 20 --vcpus 1
```
