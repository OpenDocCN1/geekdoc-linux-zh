

## Relax-and-Recover (ReaR)

该软件是一个开源的*裸机*灾难恢复解决方案。它易于安装、配置和使用，用于恢复系统。此解决方案会生成一份随时可用的系统副本。它支持多种启动介质（*ISO、PXE、USB 或 eSATA*）和多种网络协议（*nfs、cifs、ftp 或 http*），以及各种备份策略（*Symantec Netbackup、EMC Networker* 等）。

生成的文件可以包含在另一个**备份**解决方案中，例如**Bacula**，以便在需要时使用。**恢复**是一个两步过程：挂载启动介质以及从中央服务器或存储设备传输数据。

使用**ReaR**的最大优势之一是该解决方案使用系统工具来执行**备份**。以下示例使用中央*NFS*存储来保存数据和*ISO*镜像以供使用。安装只需从软件仓库安装**rear**软件包即可。安装后，需要配置的文件是 */etc/rear/local.conf*，如下所示（以**Red Hat Enterprise Linux**系统为例）：

```bash
yum install -y rear
cat >/etc/rear/local.conf <<EOF
OUTPUT=ISO
BACKUP=NETFS
BACKUP_URL="nfs://ubuntu/storage"
EOF
```

**ReaR** 解决方案提供了 **rear** 命令以执行不同的操作。参数 **mkbackup** 将初始化**备份**过程，在上面的示例中，它将生成一个*ISO*镜像，并将数据复制到用于**恢复**过程中的使用。命令 **rear mkbackup -v** 的示例输出如下：
