The physical network is connected to a subnet with the address 10.0.0.0/24. Figure 16.13 shows an example of the creation of the subnet attached to the previous network created.

```
[stack@client ~]$ openstack subnet create subexternal --no-dhcp \ > --network external --subnet-range 10.0.0.0/24 \ > --allocation-pool start=10.0.0.220,end=10.0.0.230 \ > --gateway 10.0.0.1 --dns-nameserver 8.8.8.8
```
