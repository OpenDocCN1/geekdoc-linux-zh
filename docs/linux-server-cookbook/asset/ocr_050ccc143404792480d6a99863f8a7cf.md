# ## SUSE Linux enterprise server and openSUSE

SLES distribution is developed by SUSE, a German-based multinational open-source software company. It uses RPM as the package management system. Installation images can be found on the following website: [https://www.suse.com/download/sles/](https://www.suse.com/download/sles/)

SUSE offers two non-commercial versions of SLES called Leap and Tumbleweed, managed by the project openSUSE. The second one, Tumbleweed, is a rolling release with more updated software.
