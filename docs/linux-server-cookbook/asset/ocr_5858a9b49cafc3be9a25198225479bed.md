used to create file-sharing servers on Linux. Samba project offers client tools to access servers, either to access files or printers. Version 3, released in the year 2003, was able to join **Active Directory** as a member. New versions of Samba (4.x) support the latest SMB protocols and includes the modern features offered by the protocol. Some of these features are as follows:

+   * NetBIOS over TCP/IP
+   * WINS server (also known as NetBIOS name server)
+   * Security account manager
+   * Local security authority
+   * NTLM (NT Lan manager)
