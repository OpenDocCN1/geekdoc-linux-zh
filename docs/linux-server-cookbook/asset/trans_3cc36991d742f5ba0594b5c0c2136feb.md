## 服务介绍

Linux 服务（或有时称为 **守护进程**）是在后台运行以执行某些任务或等待某些事件的应用程序或一组应用程序。有些服务可以执行某些应用程序，当它们完成时，服务就会停止。例如，配置系统网络的服务就是这种情况。其他服务则持续运行，等待提供某些资源；例如，**SSH** 服务正等待用户连接并提供登录服务器的可能性。

大多数 Linux 发行版使用名为 **systemd** 的服务管理器，它是历史悠久且广受欢迎的 **SysV init** 守护进程的替代品。当 Linux 发行版启动时，执行的第一项进程是 **systemd**，它将负责启动系统中已启用并在启动时启用的其他服务。

**Systemd** 是一整套应用程序，旨在统一不同 *Linux 发行版* 中的服务配置和行为。管理服务的主要命令是 `systemctl`，常用操作描述如表 4.26 所示：

| 操作 | 描述 |
| :--- | :--- |
| list-units | 列出系统中可用的 *单元*（服务、挂载点、设备和套接字）。 |
| status | 检查指定 *单元* 的状态。 |
| show | 显示指定 *单元* 的属性。 |
| start | 启动指定的 *单元*。 |
| stop | 停止指定的 *单元*。 |
| reload | 指定的 *单元* 将重新加载配置。 |
| restart | 停止并启动指定的 *单元*。 |
| enable | 启用指定的 *单元*，使其在系统启动时启动。 |
| disable | 禁用指定的 *单元*，使其在系统启动时不启动。 |

### 结论

管理用户和组是 Linux 管理员和管理系统的常规用户的主要任务之一。Linux 提供了易于使用的工具来执行所有与用户和组相关的任务，例如创建、查询、修改或删除。

在操作 Linux 发行版时需要的其他重要知识是了解如何在系统中安装和管理软件。理解包格式、软件仓库以及可用工具是配置系统、安装新软件并在其上安装新服务的必要技能。服务通常是后台运行的应用程序，执行某些任务或为普通用户提供某些服务。

### 关键事实

- 用户和组信息存储在纯文本文件中。
- 密码经过加密，并保存在仅管理员可访问的文件中。
- Linux 发行版提供了多种工具来操作用户和组。
- 发行版的包格式有助于新软件的安装过程并更新系统。
- 软件仓库保存软件和库，使其可以从系统中访问，并且系统工具可以安装软件。
- 服务是后台运行的进程，执行某些操作或等待提供功能。
