# Check network services available

As described in *Chapter 7, Network Configuration*, it is possible to use the command *ss* to list the different services running in the system where the application is executed.

The file */etc/services* contain a list of the popular services and the ports, with the protocol (*tcp* or *udp*) used. For example, in the following excerpt, it shows the definition for the services *SSH, DNS (domain)*, and *DHCP (bootps/bootpc)*:

```
ssh         22/tcp    # SSH Remote Login Protocol
domain      53/tcp    # Domain Name Server
domain      53/udp
bootps      67/udp
bootpc      68/udp
```

To detect the network services available in one host or in the network, the utility *nmap* is the most popular for Linux systems. This utility is used to scan the ports available in one system or a subnet. Specifying an IP, it will scan for the known ports searching for the port opens. *Figure 9.24* shows a simple scan output:

