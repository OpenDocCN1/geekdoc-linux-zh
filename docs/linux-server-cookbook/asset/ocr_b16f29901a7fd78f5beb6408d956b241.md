During the installation of the SSH server, it generates private and public keys, which are located inside of the directory /etc/ssh/. These keys use different cryptography algorithms. The name of the files have the format ssh_host_ALGORITHM_key and ssh_host_ALGORITHM_key.pub:

+   *   **ECDA:** stands for **Elliptic Curve Digital Signature Algorithm**, which uses elliptic-curve cryptography.
+   *   **Ed255190:** EDSA stands for **Edwards-curve Digital Signature Algorithm**, and Ed25519 is a signature scheme using SHA-512 and Curve25519.
