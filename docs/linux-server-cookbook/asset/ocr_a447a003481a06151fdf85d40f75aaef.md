# Command whoami

The command whoami provides a simple output: the name of the current user. This command does not accept options or arguments. This command is usually used inside scripts, where a typical use case is to ensure that an administrative user (root) is not running a script for security reasons. The following figure is an example of the output for this command:

```
agonzalez@ubuntu:~$ whoami
agonzalez
```
