

恢复过程是否将在同一系统中进行（如果可能的话），或者在系统中进行，这一点定义很重要。

- **恢复速度要求：** 从**备份**中恢复数据可能需要更长的时间，具体取决于所使用的策略。因此，计划应包括可接受的从副本恢复文件和服务的时间。
- **恢复程序：** 包含在**备份**中的每个系统、服务或元素都应关联一个**恢复**程序，以防数据丢失。
- **恢复测试计划：** 没有定期恢复测试的**备份**无法确保**恢复**程序是正确的。

总的**恢复**目标由以下两个术语定义：

- **恢复时间目标 (RTO)：** 为了避免不可接受的后果，恢复服务中断的最大持续时间。例如，对于非关键环境，可以是数小时或数天；对于关键环境，可以以分钟为单位指定。
- **恢复点目标 (RPO)：** 由于事故导致数据丢失的最大目标时间段。

重要的是要指出，分布式存储解决方案（如 Ceph）、高可用性系统或镜像技术（如 RAID）并不是备份解决方案，它们不能替代保护数据的适当策略。如今，随着容器和云采用的普及，确保数据受到保护的策略已经演变。本书中涵盖的不同概念，如自动化、微服务、基础设施即代码和 DevOps，有助于将需求纳入备份，这是服务使用者唯一使用的数据。在现代基础设施上重建环境是一项快速且容易的任务，但备份和恢复对数据的重要性仍然非常重要。

在以下情况下可能需要恢复任务：

- 从本地副本快速恢复：例如，如果自动化正在部署服务的新配置且该配置无效，则可以恢复之前的版本。
- **从备份解决方案恢复文件**：数据丢失可能由人为错误、应用程序行为异常、外部攻击或硬件损坏（如磁盘问题）引起。
- **恢复完整系统**：这可能包括恢复虚拟机或物理系统。现代**备份**解决方案允许对运行中的系统进行快照，并可以在同一系统或新系统中恢复它。

## 备份的存储介质

首先，企业**备份**存储在物理磁带上，其中单个文件包含在副本中。**恢复**过程需要找到存放待恢复数据的正确磁带，然后将其从那里复制到系统。更现代的解决方案基于*磁带库*（也称为*磁带机器人*），其中包含多个磁带，并自动挂载所需的磁带以执行**备份**或**恢复**。**虚拟磁带库**（VTL）模拟*磁带库*，其后端是一个常规存储系统，如硬盘。使用磁带的最大优势之一，即使是在今天，是可以在异地（原始数据所在的以外的位置）轻松存储它们。

磁带作为**备份**存储介质的流行一直持续到 21 世纪第一个十年。硬盘成本的降低和**云存储**的引入，以及不同的工作方法，如**DevOps**，减少了企业中使用磁带。**网络存储**解决方案，如*NFS*、*iSCSI*和*NAS*，用于存储**备份**数据。尽管如此，在另一个位置（例如不同的*数据中心*）保留一份与原始数据分离的副本仍然很重要。

现代环境使用**对象存储**来存储数据，包括**备份**数据。公共云提供经济实惠的存储来存储*对象*。**对象存储系统**将非结构化数据放置于常规文件系统之外。要存储的*对象*（文件）不能被修改，只能用版本替换。一些可用的选项如下：

- **Amazon Web Services (AWS)** 提供一种称为 **Amazon S3 Glacier** 的廉价归档和备份解决方案。
- **Microsoft Azure** 提供 **Azure 归档存储** 服务。
- **Google Cloud** 提供用于归档和备份的 **云存储** 解决方案。
- 私有云 **OpenStack** 提供解决方案 **Swift**。
- 软件定义存储解决方案 **Ceph** 有一个名为 **Rados Gateway (RGW)** 的组件，用于提供**对象存储**服务。

## 备份类型

主要有以下三种**备份**类型：

- **完全备份**：它包含所有要复制的数据。这并不意味着整个系统都会被复制；而是意味着指定要复制的所有数据都将包含在执行的**备份**中。主要优势和劣势如下：
  - **优势**：因为包含所有数据，所以恢复时间很快。
  - **劣势**：所需空间很大，并且每次执行的**备份**都需要全部空间。例如，如果要保存的数据是 1 TB，并且需要 30 个不同的**备份**，总大小将是 30 TB。
- **增量备份**：仅传输自上次执行的**备份**以来更改的数据。此操作减少了所需空间。主要优势和劣势如下：
  - **优势**：执行**增量备份**所需的 空间和时间大幅减少。
  - **劣势**：**恢复**需要更多时间，因为需要遍历多个已执行的**备份**。
- **差异备份**：此方法仅传输上次**完全备份**与执行**备份**时刻之间的差异。主要优势和劣势如下：
  - **优势**：**恢复**过程比**增量**备份需要更少的引用；它只需要**完全备份**和特定的**差异备份**。
  - **劣势**：副本的大小比**增量**备份大。
