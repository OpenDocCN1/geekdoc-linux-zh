# Use of basic first CLI commands

As observed previously, the Linux console and the prompt are showing every moment—in which directory and the system the user is working on. Linux distributions offer some commands to provide more information, such as the full directory where the user is located or obtain the current time and date for the system.

# Command pwd

The command *pwd* (print working *directory*) shows the absolute current directory where the user is located. The prompt usually shows the relative directory. This command, even having some options, is generally used without any option or argument. Working with several directories with the same name can be problematic and cause unexpected errors. The command *pwd* helps to ensure that the task will be executed in the desired directory.
