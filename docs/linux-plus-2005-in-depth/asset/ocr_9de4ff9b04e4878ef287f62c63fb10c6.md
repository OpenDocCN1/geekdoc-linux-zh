Although less common than GNOME and KDE, the **Xfce desktop environment** (Figure 9-14) is another desktop environment that is used on many Linux systems. Xfce ships with a small set of easy-to–use tools and consumes less hardware resources than KDE or GNOME. As a result, Xfce is typically run on Linux servers that do not have many hardware resources available.

> NOTE
> 
> To learn more about the Xfce desktop, you can visit the Internet at http://www.xfce.org.
