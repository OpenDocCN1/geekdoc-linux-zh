Recall that the first process started by the Linux kernel is the init daemon, which has a PID of 1 and a PPID of 0 referring to the kernel itself. The init daemon then starts most other daemons, including those that allow for user logins. After you log in to the system, the login program starts a BASH shell. The BASH shell then interprets user commands and starts all user processes. Thus, each process on the Linux system can be traced back to the init daemon by examining the series of PPIDs, as shown in Figure 10-2.
