`ps` 命令有几十种选项可用于显示进程及其属性；本节中列出的选项是最常用的，并在表 10-1 中进行了总结。

### 表 10-1 `ps` 命令的常用选项
| 选项 | 说明 |
| :--- | :--- |
| -e | 显示在终端上运行的所有进程，以及不在终端上运行的进程（守护进程） |

你可能会遇到在执行过程中发生错误并持续占用系统资源的进程。这些进程被称为**流氓进程**，并出现在由 `top` 命令生成的列表顶部。`top` 命令也可用于更改进程优先级或终止进程；因此，你一旦识别出流氓进程，就可以立即通过 `top` 命令终止它们。进程优先级和终止进程将在本章后续部分讨论。
