+   • **XFree86**—A common implementation of X Windows used in Linux distributions.
+   • **xvfb**—A program used to fine-tune the vsync and hsync video card settings for use in X Windows.
+   • **zcat command**—A command used to view the contents of an archive created with compress or *gzip* to Standard Output.
+   • **Zip disk**—A removable information storage unit similar to a floppy disk that can store much more information than floppy disks and which is used in *Zip* drives.
+   • **zless command**—A command used to view the contents of an archive created with compress or *gzip* to Standard Output in a page-by-page fashion.
+   • **zmore command**—A command used to view the contents of an archive created with compress or *gzip* to Standard Output in a page-by-page fashion.
+   • **zombie process**—A process that has finished executing, but whose parent has not yet released its PID; it still retains a spot in the kernel's process table.
+   • **zone**—A portion of the Domain Name Space that is administered by one or more DNS servers.
+   • **zone transfer**—The process of copying resource records for a zone from a master to a slave DNS server.
