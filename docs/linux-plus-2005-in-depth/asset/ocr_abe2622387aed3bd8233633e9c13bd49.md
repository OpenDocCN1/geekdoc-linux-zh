# Listing Files

Linux hosts a variety of commands, which can be used to display files and their types in various directories on hard drive partitions. By far, the most common method for displaying files is to use the ls command. Following is an example of a file listing in the root user's home directory:

```
[root@server1 root]# pwd
/root
[root@server1 root]# ls
current  myprogram  project   project12  project2  project4
Desktop  myscript  project1  project13  project3  project5
[root@server1 root]#
```
