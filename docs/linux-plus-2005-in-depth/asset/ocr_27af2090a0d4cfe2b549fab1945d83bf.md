# ## Downloading Files Using FTP

The most common method for transferring files across the Internet is by using the File Transfer Protocol, as discussed in Chapter 1, “Introduction to Linux.” Most Web browsers have a built-in FTP utility that allows you to enter a FQDN in the form of `ftp://ftp.sampledomain.com` and view publicly available files and directories on a remote computer using the Web browser screen, as depicted in Figure 14-12.

![](bbox=[0.13, 0.27, 0.28, 0.31])

> You can also use `ftp://IP_address` to connect to a public FTP server without using name resolution.

![](bbox=[0.17, 0.39, 0.78, 0.7])

**FIGURE 14-12** *Using a Web browser FTP client*

Using the mouse to click a file displayed in Figure 14-12 results in a dialog box that allows you to save the file to the appropriate location on a local filesystem.

Alternatively, you can specify the host name or IP address of a computer running the FTP service as an argument to the `ftp utility` to open a connection that allows the transfer of files to and from that computer.
