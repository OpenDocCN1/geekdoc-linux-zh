# Specifying the Installation Type

Next, the installation attempts to detect any previous installations of Red Hat Linux on your hard disks. If a previous version of Red Hat is detected by the installation, you are prompted to either upgrade the previous installation of Red Hat Linux that exists on the hard drive or perform a fresh installation. Typically, you only perform an upgrade if there are data or configurations on the previous installation of Red Hat Linux that are difficult to re-create or back up.
