## Linux 目录结构

使用 Linux 操作系统的基础是了解 Linux 如何在硬盘上存储文件。典型的 Linux 系统可能在硬盘上拥有成千上万的数据文件和程序文件；因此，需要一个结构来组织这些文件，以便更容易地找到和操作数据以及运行程序。回顾前一章的内容，Linux 使用逻辑目录树将文件组织到不同的目录（也称为文件夹）中。当用户在某个**目录**中存储文件时，它们会物理存储在一台计算机内部硬盘的某个分区上的文件系统中。大多数人熟悉图 4-1 中所示的 Windows 操作系统目录树结构；硬盘分区上的每个文件系统都由一个驱动器字母（如 C: 或 D:）引用，并拥有一个根目录（由 \ 字符指示），其中包含共同形成层次树状的子目录。

在目录树中正确描述目录很重要；文件或目录的**绝对路径名**是从根目录开始的特定文件或目录的完整路径名。根据图 4-1，color 目录的绝对路径名是 C:\windows\color，而 sue 目录的绝对路径名是 D:\home\sue。换句话说，我们将 C:\windows\color 称为 C: 驱动器根目录下 windows 目录下的 color 目录。类似地，我们将 D:\home\sue 称为 D 驱动器根目录下 home 目录下的 sue 目录。

Linux 使用类似的目录结构；然而，没有驱动器字母。只有一个根（使用 / 字符表示），而硬盘分区上的不同文件系统被挂载到这个目录树的不同目录中，使得文件系统对用户是透明的。与图 4-1 中所示的 Windows 示例目录树等效的 Linux 示例目录树如图 4-2 所示。

根据图 4-2，color 目录的绝对路径名是 /windows/color，而 sue 目录的绝对路径名是 /home/sue。换句话说，我们将 /windows/color 目录称为系统根（/ 字符）下 /windows 目录下的 color 目录。类似地，我们将 /home/sue 目录称为系统根下 home 目录下的 sue 目录。

### 更改目录

当用户登录到他的 Linux 系统时，他会被放置在他的**主目录**中，这是每个用户存储个人文件的独特位置。普通用户通常拥有一个位于 /home 目录之下、以其用户账户命名的主目录，例如 /home/sue。然而，root 用户在系统根目录（/root）下拥有一个名为 root 的主目录，如图 4-2 所示。你可以通过观察 shell 提示符末尾的名称或在命令行提示符下输入**pwd（print working directory，打印当前工作目录）命令**并按 Enter 键来确认你当前所在的系统目录。如果你以 root 用户身份登录，终端屏幕上将显示以下输出：

```
[root@server1 root]# pwd
/root

[root@server1 root]#
```

但是，如果你以用户 sue 身份登录，你会看到以下输出：

```
[sue@server1 sue]$ pwd
/home/sue

[sue@server1 sue]$
```

要更改目录，你可以发出带有指定目标目录参数的**cd（change directory，更改目录）命令**。如果你不指定目标目录，cd 命令只是将你返回到你的主目录：

```
[root@server1 root]# cd /home/mary
[root@server1 mary]# pwd
/home/mary
```

```
[root@server1 mary]$ cd /etc 
[root@server1 etc]$ pwd 
/etc 
[root@server1 etc]$ cd 
[root@server1 root]$ pwd 
/root 
[root@server1 root]$_ 
```

`~`**元字符**也可以用于指代当前用户的主目录。或者，你还可以在 `~` 元字符末尾附加一个用户名，使用该元字符来指定另一个用户的主目录：

```
[root@server1 root]$ cd ~mary 
[root@server1 mary]$ pwd 
/home/mary 
[root@server1 mary]$ cd ~ 
[root@server1 root]$ pwd 
/root 
[root@server1 root]$_ 
```

在之前讨论的许多示例中，`cd` 命令后指定的参数是目录的绝对路径名，这意味着系统拥有查找目标目录所需的所有信息，因为路径名从系统根（/）开始。然而，在大多数 Linux 命令中，你还可以使用相对路径名代替绝对路径名以减少输入。**相对路径名**是目标文件或目录相对于你在树中当前目录的路径名。要指定你当前目录下的一个目录，只需通过名称引用该目录（不要以 / 字符开始路径名）。要引用树中更接近根的一个目录（也称为父目录），只需使用两个点（..）。下面展示了一个使用相对路径名在目录树中移动的示例：

```
[root@server1 root]$ cd /home/mary 
[root@server1 mary]$ pwd 
/home/mary 
[root@server1 mary]$ cd .. 
[root@server1 home]$ pwd 
/home 
[root@server1 home]$ cd mary 
[root@server1 mary]$ pwd 
/home/mary 
[root@server1 mary]$_ 
```

在上面的示例中，我们使用 ".." 向上移动一个父目录，然后使用单词 "mary" 来指定相对于我们在树中当前位置的 mary**子目录**；但是，你也可以在目录树中上下移动多层：

```
[root@server1 root]# cd /home/mary
[root@server1 mary]$ pwd
/home/mary
[root@server1 mary]$ cd ../..
[root@server1 /]$ pwd
/
[root@server1 /]$ cd home/mary
[root@server1 mary]$ pwd
/home/mary
[root@server1 mary]$
```

你也可以使用一个点（.）来指代当前目录。虽然在使用 cd 命令时这并不方便，但你将在本书后面使用一个点。

虽然当指定某个文件或目录的位置时，使用绝对路径名作为命令的参数很直接，但如果当前目录距离根目录较远，相对路径名可以为你节省大量输入并减少出错的可能性。例如，假设当前目录是 /home/sue/projects/acme/plans，你需要将其更改为 /home/sue/projects/acme 目录。使用绝对路径名，你需要输入 cd /home/sue/projects/acme；然而，使用相对路径名，你只需要输入 cd .. 就能完成同样的任务，因为 /home/sue/projects/acme 目录是目录树中当前位置的一个父目录之上。

在输入命令参数的路径名时节省时间的另一种方法是使用 BASH shell 的 Tab 补全功能。为此，输入目录中足够独特的字母，然后按 Tab 键，让 BASH shell 找到正在指定的目标文件或目录并填入适当的信息。如果有多个可能的匹配项，Tab 补全功能会通过蜂鸣声警告你；在此蜂鸣声后再次按 Tab 键，将向你列出可能的文件或目录。

观察图 4-2 中的目录结构。要使用 Tab 补全功能将当前目录更改为 /home/sue，你只需输入 cd /h 然后按 Tab 键。这将终端屏幕上的前几个字符更改为显示 cd /home/（BASH shell 能够填入适当的信息，因为 /home 目录是 / 目录下以字母 "h" 开头的唯一目录）。然后，你可以向命令添加一个 s 字符，使命令行显示 cd /home/s/，并再次按 Tab 键让 shell 填入剩余的字母。这会导致终端屏幕上显示命令 cd /home/sue/（sue 目录是 /home 目录下以 s 字符开头的唯一目录）。此时，你可以按 Enter 键执行命令并将当前目录更改为 /home/sue。
