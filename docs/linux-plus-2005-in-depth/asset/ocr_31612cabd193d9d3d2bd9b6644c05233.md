Although the sar command displays CPU statistics by default, you can display different statistics by specifying options to the sar command. Table 13-2 lists common options used with the sar command.

# **Table 13-2 Common options to the sar command**

| Option | Description |
|:---|:---|
|-A | Displays the most information; this option is equivalent to all options |
|-b | Displays I/O statistics |
|-B | Displays swap statistics |
|-c | Displays the number of processes created per second |
|-d | Displays Input/Output statistics for each block device on the system |
|-i FILENAME | Displays information from the specified file; these files typically reside in the /var/log/sa directory |
|-n FULL | Reports full network statistics; network monitoring is discussed in Chapter 14 |
|-o FILENAME | Saves the output to a file in binary format |
