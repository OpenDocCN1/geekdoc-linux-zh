# # Automating Linux Installations

Some organizations deploy several Linux servers and workstations that require the same con- figuration. For these organizations, it is time-consuming to answer all of the installation ques- tions on a computer-by-computer basis. Instead, these organizations often use **disk imaging software** to duplicate the hard disk contents from one computer to the next, or use an auto- mated installation script to automate each installation.
