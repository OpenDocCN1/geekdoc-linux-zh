# **NOTE**

Any line in a kickstart file that starts with a # symbol is a comment line and is ignored by the installation program.

To use the kickstart file shown previously, simply format a floppy disk with the ext2 file system and copy the ks.cfg file to it. When you start the installation by booting the computer from an installation CD-ROM, DVD, installation startup CD-ROM, or bootable USB flash memory drive, you receive an initial Red Hat Fedora welcome screen and boot: prompt, as shown earlier in Figure 7-7. Instead of pressing Enter at this prompt, type the command `linux ks=floppy:/ks.cfg` and press Enter. This forces the installation program to look for configuration information in the ks.cfg file on the floppy.

The firstboot wizard is not run following a kickstart installation.
