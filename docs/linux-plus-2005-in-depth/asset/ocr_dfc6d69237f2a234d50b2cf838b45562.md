**Table 4-7 Key combinations commonly used at the command mode (Continued)**

| Function | Description |
|---|---|
| :r date | Reads the output of the date command into the document under the current line |
| :r filename | Reads the contents of the text file called filename into the document under the current line |
| :set all | Displays all vi environment settings |
| :set ...... | Sets a vi environment setting to a certain value |
| :s/the/THE/g | Searches for the regular expression "the" and replaces each occurence globally throughout the current line with the word “THE” |
| :1,$ s/the/THE/g | Searches for the regular expression "the" and replaces each occurence globally from line 1 to the end of the document with the word “THE” |
