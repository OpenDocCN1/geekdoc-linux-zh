Notice from the preceding output that a README and configure file exist and that the configure file is executable. To execute this file without using the PATH variable, you can enter the following command:

```
```
[root@server1 rdesktop-1.3.1]# ./configure
rdesktop build configuration script

X Window System:
  includes    /usr/X11R6/include
  libraries   /usr/X11R6/lib

OpenSSL:
  includes    /usr/include
  libraries   /usr/lib

Sound support enabled: Open Sound System

configure complete - now run make
[root@server1 rdesktop-1.3.1]# _
```
```
