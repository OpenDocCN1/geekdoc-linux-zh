TIP

You can also insert a spreadsheet file into your current spreadsheet using the Insert Sheet dialog. Select from the From File option. Then use the Browse button to locate the Calc file that you want to insert into the current spreadsheet.

# Delete Sheet

With the sheet that you want to open in the Calc window, select Edit, Sheet, Delete. You are asked whether you want to permanently delete the sheet; select Yes. The sheet is removed.
