# Open Bookmarks Manager

From the Firefox window, select Bookmarks, Manage Bookmarks. The Bookmarks Manager opens.

# Move Bookmark

Expand the Bookmark Toolbar folder to view the "ready-made" folders provided by Firefox. To move a bookmark from the main folder to one of the toolbar folders (or from any folder to another folder), drag the book-mark to the new location.
