The next time you log on to the iFolder server on our NLD system (using the iFolder client) synchronization takes place. However, there will be a con-lict because the file you deleted using the web client is not on the server; it is in your local iFolder. Instead of just deleting the file, the file in question is placed in your conflict bin. This allows you to review the file and decide whether it should be deleted from the local iFolder on your NLD system.
