# Change Accessibility Settings

If you do not want to configure keyboard accessibility settings, you can skip this step. Double-click the Accessibility icon to open the Accessibility dialog. On the Basic tab, select Enable Keyboard Accessibility Features (to enable accessibility). You can then enable sticky keys (helper keys as Alt and Ctrl that only have to be tapped rather than held down when used for shortcuts) and repeat keys (for a set key before it repeats) on this tab.
