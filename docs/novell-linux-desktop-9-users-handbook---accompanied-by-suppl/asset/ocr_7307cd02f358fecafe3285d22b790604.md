# 98 Use the AutoPilot to Create a Document

One of the easiest ways to create a new document and have Writer walk you through the various steps of creating that document is to use the AutoPilot. The AutoPilot allows you to create “specialty” documents such as agendas, memos, and reports. The AutoPilot walks you through each step as you create the document.
