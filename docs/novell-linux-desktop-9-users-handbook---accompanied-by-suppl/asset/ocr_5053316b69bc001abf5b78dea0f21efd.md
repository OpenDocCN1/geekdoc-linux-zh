# Mark Package for Installation

The results of your search will appear in the Red Carpet window. If you want to mark a package for installation, select a package in the Search Results list. Then select the Mark for Installation button. The package is added to the Pending Actions list.

At this point you can redefine your search parameters and do a new search. Add any packages you want to install to the Pending Actions list.
