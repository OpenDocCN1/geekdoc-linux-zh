# Key Terms

Applet—A software tool that requires minimal system resources and is designed to be launched from within another application. Applets typically do not provide access to the computer's hard drive. NLD provides number of applets, such as the Volume Control applet and the Resolution Switcher.

Boot—The process where a computer system is initialized, and an operating system is loaded.

Character style—A collection of saved character formatting attributes to use format words in a document.

CUPS—Short for Common Print System, CUPS provides the set of print drivers and the printing architecture that make it easy to configure printers and format from Linux (such as NLD) and UNIX systems.

Dependency—A necessary software module for a program to run on the Linux system. Linux applications and applets require other software modules and files to be installed before the application or applet run.

Distribution—A particular flavor or version of Linux that has been packed using the Linux source code and other open source software applications.

Groupware—Client communication software that allows collaboration with other users and is designed to connect to a communication server product.

Paragraph style—A collection of both character and paragraph formatting attributes that have been saved under a style name.

Patch—a patch is a software update to a particular system or software file that resolves issues or tightens security.

POP3 server—The server that acts as the post office and holds your email until you download them to your computer using email client.

Proxy server—Proxy servers are used to provide service for networked computers that connect to the Internet. The proxy sits between your network and the Internet and handles outgoing and incoming information that is passed between the internal network and the Internet. The only proxy is really 'visible' to computers outside the internal network, which protects your computer and others on the internal network from external attacks.

Range—A group of adjacent and contiguous cells. Ranges are used in formulas and to compute the results. You can also select a range of cells for formatting.

Refresh rate—The frequency of times that monitor is redrawn in a second. Refresh rates are measured in Hz (hertz). For example, an 80Hz refresh rate would translate to the screen being refreshed 80 times per second.

Root—The root account is the administrative account for a Linux system. It has many rights and capabilities compared to the typical user account in NLD.

RPM—An archived, compressed, and compiled software application, or file. RPM files for RedHat Package Manager.

SAMBA—An open source protocol that provides the bridge that allows Linux systems such as NLD to talk to computers running Microsoft Windows (SMB). This means Linux systems can share files and printers transparent.

SMTP server—the server that accepts your email when you send an email. The SMTP server passes the email to its final destination.

Theme—Settings that allow the look of program and utility windows including the frame and controls. Themes also control the look of desktop and panel icons.

Virtual desktop—a separate workspace that can be used to run applications. Each workspace uses the GNOME desktop, but each workspace is a discrete operating space, which allows you to keep the actual desktop (within each virtual desktop) less crowded (with applications).

X Window System—the graphical display system used by many Linux implementations including NLD.

XML—XML or extensible Markup Language is a markup language that allows for the creation of extended tags (a tag language like HTML). It provides a universal file format that can be embraced by many types of applications.
