# Open Save As Dialog

If you would rather save the file for later consideration (instead of open-ing it immediately), select the drop-down arrow to the right of the attach- icon. Then select Save As.

# Save Attachment

In the Save As dialog box browse for a folder to save the file in. You can change the filename if needed. Then select Save. The file is saved to the selected folder.

TIP

To browse for other folders in the Save As dialog box, select the Browse for OtherFolders link.

# Read, Sort, and Search Your Email

To read a message all you have to do is select that message and then view it in the Preview pane. Sometimes, however, you may find it difficult to find a par-ticular message. Evolution makes it easy for you to sort messages by date, subject, or any of the informational columns shown above the message list (in any mail folder such as the Inbox). You can also quickly search for a message using the Search toolbar.

# Read Message

Select a message in the Inbox or any folder to view that message in the Preview pane.

# Sort Email

Email is sorted by date (this is the default). To sort the mail in the cur-rent folder (such as the Inbox) by one of the other mail columns, select the heading of that column as Subject. The mail is sorted alphabeti-ally in ascending order by subject. If you want to sort descending (or unsort the messages) by a particular column, right-click on that column and select Sort Descending
