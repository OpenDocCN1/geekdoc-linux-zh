# Use the ps Command

To view currently running processes, type ps at the command line and press Enter. The number of processes listed depends on what you are running on the NLD desktop before initiating the ps command. Note that a pid or id is supplied for each running process (process really being synonymous with program). You would use the pid with the kill command to terminate an errant process.

After you have worked with some of the system commands, you can close the terminal window. Type exit and then press Enter to return to the NLD desktop.
