# CHAPTER 4: Modifying the NLD Desktop

# Set Timings
You can set timings for how long the screensaver should run before the screen is blanked and how often the screensavers should be cycled if you chose to use the Random Screen Saver mode. Set the Blank After and Cycle time settings as needed. If you also want to lock the screen and require your password to reenter the system, select the Lock Screen After check box and set a timing (for the Lock Screen tool). After completing the settings in the Screensaver Preferences dialog box, close the dialog box.

TIP
 you want to set Display Power Management for a compliant monitor (such as the timing for the monitor when it goes into standby), select the Advanced tab of the Screensaver Preferences dialog box. The Advanced tab also provides settings for image manipulation where you can set up a screensaver to use image files that you have stored in a folder.

# Use the Lock Screen
The screen can be locked by setting a timing in the Screensaver Preferences dialog box when you configure your screensaver. In cases where you want to lock the screen when you are ready to step away from your computer, you can use the Lock Screen command on the System menu. After you have locked the screen, the screensaver starts after a short period provided to unlock the screen using your password.

# Lock Screen
Select the System menu and then select Lock Screen. The XScreenSaver lock dialog appears. You can now go about your business and step away from your computer.
