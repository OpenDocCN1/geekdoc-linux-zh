You can also quickly create a vFolder based on a selected message. Select Tools, Create Virtual Folder From Message, and then select one of the choices on the submenu as **vFolder on Subject**. This opens a new Virtual Folder dialog box (the Add Rule dialog).You then set the criteria and folders to be filtered as need-ed to create the vFolder.
