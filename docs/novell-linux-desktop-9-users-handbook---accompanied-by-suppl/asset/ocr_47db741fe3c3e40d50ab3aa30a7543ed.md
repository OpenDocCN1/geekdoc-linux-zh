# 49 Delete Files

# Open Folder Containing File

In the Nautilus window locate the folder that contains the file or files, you want to delete. Then open the folder.

# Select and Delete File

Select the file you want to delete. If you want to select multiple files, select the first file and then hold down the Ctrl key as you select subsequent files. Press the **Delete** key. The file or files will be removed and placed in the trash.

TIP

To select all the files in a folder, from the Nautilus menu, select **Edit, Select All Files**. You can also use the mouse to drag a selection area around files in the Nautilus window to select them.

# Empty the Trash

Right-click on the **Trash** icon and select **Empty Trash**. In the warning dialog box that appears, select **Empty** to remove the file from your system.
