# Novell Linux Desktop 9
User's Handbook

Get More Done with Novell Linux Desktop

This official Novell Press book is your complete guide to installing and using\Novell's exciting new Linux operating system–Novell Linux Desktop.

Novell Linux Desktop is the powerful new operating system that
combines the power and stability of SUSE Linux with leading open-source
productivity applications such as Novell Evolution and the OpenOffice.org
productivity suite. Novell Linux Desktop also provides a user-friendly
interface in the form of GNOME or KDE desktop.

User Handbook is designed to be a complete
reference for taking advantage of all the features and software provided
by Novell Linux Desktop. For the end user, this book walks
the ins and outs of the Novell Linux Desktop graphical
interface and provides in-depth coverage for a number of the software
applications that are part of the Novell Linux installation.

This book is packed with detailed reference information–everything
from overviews of how to navigate Novell Linux Desktop, manage
files, and use Linux productivity tools to working with clients and
personal information management software as Novell Evolution.

Inside You'll Find Just What You Need to...

+   * Learn Novell Linux Desktop, update it, and keep it running
* Learn to manage files from the Nautilus file manager and the
Linux command line
* Learn the ins and the outs of the GNOME desktop
* Browse the World Wide Web with the Mozilla Firefox Web Browser
* Work with OpenOffice.org applications such as Writer, Calc, and
Impress and create documents, spreadsheets, and presentations
* Manage your email, contacts, calendar, and tasks with Novell Evolution
* Access your files from any workstation using Novell iFolder
* Configure and use hardware devices and peripherals such as printers
and USB drives
