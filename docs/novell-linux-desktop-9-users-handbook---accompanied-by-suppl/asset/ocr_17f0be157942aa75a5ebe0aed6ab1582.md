# 56 About Backing Up and Restoring Files

When the concept of backing up and restoring data is discussed, we typically think of a single GUI program or command-line utility that allows us to back up files to some sort of compressed format and then, if disaster strikes, restore them to a computer. System administrators deal with fairly sophisticated hardware and software to back up files and can often be heard discussing such things as incremental and full backups. But I'm basically looking at the backup of important files that you create on the computer: your letters, databases, and spreadsheets.

NLD provides both a System Backup and a Restore System utility. You can back up important system files (it can be done automatically without even choosing) and then, if there is a problem, you can use the Restore System utility. This type of backup protects programs and system files. Both of these utilities must be run by root because you cannot open YaST without the root password.

NLD provides administrative utilities to back up the system.
