The best way to navigate a multipage document is with the Navigator. It allows you to quickly jump to a particular object in a document such as a heading, frame, table, or graphic. It also provides a page spinner box-that allows you you to move quickly to any page in the document. The Navigator is opened using the Navigator button on the Function bar.

TIP

You can also open the Navigator by selecting the Navigator button on the vertical scrollbar, which also provides Next Page and Previous Page buttons.
