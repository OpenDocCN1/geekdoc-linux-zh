# 10 Change the System Date and Time Settings

+   1 View Month

To view the current date in the context of the current month, select the Clock (showing the current date and time on the top panel). To close the month view, select the Clock a second time.

+   2 Open Clock Preferences

Right-click on the date and then select Preferences from the shortcut menu that appears. This opens the Clock Preferences dialog.

+   3 Change Clock Preferences

Select the Clock Type drop-down box to select either a 12, 24 hour, UNIX time (the seconds that have elapsed since January 1, 1970; this is used primarily by developers), or Internet time (a universal reference used all over the world) for the clock. To show seconds on the clock, select the Show Seconds check box. To change the clock to UTC (Universal Coordinated Time or Greenwich Mean Time), select the UTC check box. When you have completed editing the preferences, click Close.

+   4 Change Date and Time Settings

Right-click on the date and time and then select Adjust Date and Time from the shortcut menu. The Run as Root dialog box appears.

+   5 Enter the Root Password

Type the root password in the Password box and then click OK. The YaST window opens the Clock and Time Zone Configuration.

+   6 Edit Date and Time Settings in YaST

In the Region select your region. The appropriate region. To change the date or time, select the Change Time or Date button. The Change System Date and Time dialog opens. Enter the correct time in the Current Time boxes and enters the correct date in the Current Date boxes (the correct format for each entry is provided). After entering the time and date information, click Apply. This returns you to YaST. If you want to change the hardware clock setting to local (the default is UTC), click the Hardware Clock Set To-drop-down box and select Local Time. After changing the clock settings in YaST, click Accept. YaST writes a new configuration file and then closes, returning you to the NLD desktop.
