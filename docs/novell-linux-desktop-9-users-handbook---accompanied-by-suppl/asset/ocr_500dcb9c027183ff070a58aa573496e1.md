# 103 Create a Paragraph Style

You can create your own styles, which are added to the Stylist for easy access. Styles can quickly be created by formatting text or paragraphs and then creating a new style based on the current formatting of selected text or paragraphs.

Paragraph styles, which are often the most useful style to create, can contain both font attributes and paragraph attributes such as alignment. So, you can create your own heading styles or special paragraph styles and then apply them as needed.
