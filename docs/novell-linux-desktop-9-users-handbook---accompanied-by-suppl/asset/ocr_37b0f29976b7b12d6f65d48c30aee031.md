# TIP

When you use some functions such as the AVERAGE function, you may want to decrease the number of decimal places shown in the functions results so that only “whole”numbers are represented. Use the Number Format: Delete Decimal Place button on the Object bar to reduce the number of decimal places shown in the function's results.

# TIP

If the results of your function show as ####, this means that the column width can't accommodate the results of the function. Widen the column as needed to view the function results.
