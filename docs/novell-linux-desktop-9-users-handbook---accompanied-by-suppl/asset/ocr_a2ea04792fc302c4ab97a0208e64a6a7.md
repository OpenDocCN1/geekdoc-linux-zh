TIP

You can use the Back and Forward buttons as needed when you are browsing the Web. To see a list of sites that you can go back (or forward) to, click the drop-list button next to the Back or Forward buttons. You can also select the Go button to view a list of recently visited sites. Select a site in the list to go to that site.
