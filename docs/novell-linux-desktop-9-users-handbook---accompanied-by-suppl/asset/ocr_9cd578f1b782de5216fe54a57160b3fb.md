# Enter Text

Click in a cell that will contain text. Type the text. After you have completed entering the text, press Enter. The text is placed in the cell, and the cell selector moves to the next cell down. Enter other text as needed. Notice that text is aligned in the cells.

# TIP

You can also enter typed text in a cell by pressing an arrow key. This moves you to another cell in the direction of the arrow key.
