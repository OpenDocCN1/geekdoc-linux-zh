# Select Page Format

You may want to add information in the header or footer of the pages of your sheet printout. This allows you to add page numbers, the date, and other repeating information on each page. You can also add borders and backgrounds to the pages of your printout.

Select the Page Format button on the Page Preview Object bar. The Page Style dialog box opens.
