# CHAPTER 3: Working on the NLD Desktop

# TIP

To view the desktop without closing a maximized application window, click on the Minimize button in that window. The application can be restored to the desktop by clicking its icon on the bottom panel of the desktop.

# 8 Use the Menu System

You can access the application and other tools provided by NLD using the menus that reside in the top panel of the desktop. The Programs menu divides the installed applications into categories such as Accessories, Graphics, and Other. Selecting a particular category provides a list of applications in that category. For example, the Accessories submenu provides access to tools such as the Calculator, Dictionary, and File Manager. The Office submenu provides access to the OpenOffice org suite, which includes Write, Calc, and Impress.

The System menu provides access to personal and administrative settings. It also allows you to quickly search for a file and provides you with the ability to log off the system.
