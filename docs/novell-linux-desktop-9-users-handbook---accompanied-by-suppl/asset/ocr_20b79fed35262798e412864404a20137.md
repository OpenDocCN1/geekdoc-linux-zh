The boot loader provides options for how you want the system to boot.

![](bbox=[0.115, 0.131, 0.882, 0.433])

NLD communicates with the computer's memory and other hardware components as it prepares the system for use. As these events take place, the kernel writes to the screen, so you will actually see messages related to hard-initializations and other boot events.

The NLD boot process is displayed as messages on the screen.
