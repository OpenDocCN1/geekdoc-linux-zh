# Open Search Window

Select the System menu and then select Search for Files. The Search for Files window opens.

# Enter Search Name and Path

In the Name Contains box, enter all or part of the filename (wildcards such as * are not necessary). In the Look In Folder box, type the path for the folder you search. You can also locate the folder; click the Browse button.
