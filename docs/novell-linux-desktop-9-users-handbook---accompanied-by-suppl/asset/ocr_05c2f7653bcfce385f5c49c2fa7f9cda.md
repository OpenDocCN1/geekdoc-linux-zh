# 121 Insert and Delete Columns

# Select Column or Columns

Select the column or columns where you want to insert new columns. Click the column heading to select a column or drag to select multiple columns. The number of columns that you select dictates how many are inserted.

# Insert Columns

Select Insert, Columns. The new column or columns are inserted into the sheet. The selected column or columns are pushed to the right.
