# 42 Change Session Settings

The Session Options tab also provides you with the ability to create sessions and save them under a particular name. This feature would be extremely useful if there was a quick and easy way to switch between the sessions or easily load them at startup. You do have ability to load your last session at startup (which is the default option on the Logon Manager). A command-line tool, gnome-session, can be used to load a particular session at startup, but you would have to load NLD from a command line or special script. The GNOME documentation (http://www.gnome.org) promises some sort of session switcher utility in future versions of GNOME.
