# Enter URL for Tab Window

Enter a URL for the new tab window in the address box (and then press Enter), or use the Go button to select a site from your list of recently visited sites. You can also select a site from your Bookmarks list. The selected site opens in the tab window.

# TIP

To open your history list and select a site from the historyry (to open in the tab window), press Ctrl+H (or select History on the Go list). The History pane appears on the left side of the browser window. Click a site in the history to open that site.
