### 3 Download Headers

In the Download Headers for Group dialog box new headers will be downloaded (meaning the titles of recent posts). If you want to download a greater (or fewer) number of posts, select the Download Headers option and use the drop-down list to specify a number. Then select Execute.

### 4 View Message and Threads

To view a post, select the post in the upper pane of the list. To view threads (responses) to the post, double-click the expand button to the left of the post. The contents of the currently selected post appear in the bottom pane of the window.

### 5 Post Message

To post a message as a follow-up to the currently selected post, select the Followup Newsgroup icon (the second button from the left). If you want to post a new message (not related to the current post), select the Post to Newsgroup button (the first button on the toolbar). In either case a new window opens.

Enter the text for your post in the message area of the window. If you are creating a new post (not related to the current post) enter a subject for the post. After entering the information, select the Send button, and the post will be sent. It may take some time (depending on the server) for your post to appear.

After you have finished browsing groups and posting your own messages, select the Close button to close the window.

TIP

As you browse through the various groups, you will find groups you want to access often. Right-click the group in the list and select Subscribe. The group is marked with a subscribe icon. You can quickly find your subscribed groups in the list. Select the All Groups drop-down list and select subscribed. Only subscribed groups appear in the list.

## About Internet Communication Tools

Internet offers other communication tools that you can use. These tools include an Internet Relay client, a videoconencing client, and an FTP client.

Internet Relay Chat (IRC) is the grandfather (or grandmother if you prefer) of chat platforms. Users log on to IRC channels which are discussion groups that allow real-time conversations between participants. IRC provides channels for many subjects and is actually a good place to gather information about computers, gardening, or just anything else. However, like Usenet, some channels will definitely make you blush and you may want to avoid them (which you may have to decide).

To use IRC (select Internet and then IRC Client), you connect to a network. After you are connected to a network, you can select a channel and participate in chat on that channel. The IRC client allows you to participate in IRC chats.

# NOTE

IRC channels are moderated by the owner of that channel (the person who originated it). They have the ability to knock users out of the channel for inappropriate behavior.

Another Internet tool provided is the videoconferencing software. This software allows you to voice and videoconference over the Internet using a microphone and an optional USB webcam (or other camera).

GnomeMeeting provides the ability to communicate via text, voice, or video over the Internet. In terms of voice communication, connect a microphone to your system and then run the GnomeMeeting Configuration, which runs the first time you start GnomeMeeting or can be started from the Edit menu.

In terms of configuring GnomeMeeting for videoconencing, USB webcams can be a problem because many manufacturers of these small cameras don't provide support for the Linux platform. You can attempt to use the Configuration to get your video camera running. If it does not work, you need to do some research on the Web, and you may be able to get GnomeMeeting up and running with your webcam or other video camera. Start your research at www.gnomemeeting.org.

Another tool that you may need in certain circumstances is gFTP. FTP or File Transfer Protocol is the protocol used to download and upload files on the Internet. Web browsers such as Firefox have FTP capabilities built in, so for most of the time you do not necessarily need an FTP client. However, if you need to access an FTP server that requires a username and a password to download or upload files, you will need an FTP client such as gFTP.

The gFTP client allows you to access FTP sites that require a username and password.

![](img/6e85ebc4ce06a64c82109523b6018ba_231_0.png)

To use gFTP (select Programs, Internet, More, and then FTP Client), you need to know the URL for the FTP site (typically ftp://sitename.com) and your username and password. All three of these items are entered in the gFTP window. You can then connect to the site and view the folders and files available on the site. The gFTP site provides a number of bookmarked FTP sites that you can explore using gFTP (select a site from the Bookmarks menu).
