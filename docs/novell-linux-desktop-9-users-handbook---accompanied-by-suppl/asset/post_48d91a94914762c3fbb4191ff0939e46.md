# Installing Novell Linux Desktop

You may need to change your BIOS settings to boot directly from the DVD drive. If you are not sure if can boot from a DVD, you should start or reboot your computer and go into the BIOS setup utility. Pressing the DEL (Delete) or the F2 key usually accesses this utility while the computer is starting up. Once in the BIOS setup utility, look for a boot priority option. If your computer is capable of booting from a DVD, your DVD drive has a higher boot priority than your hard drive(s) to enable booting from a DVD.

Once you have determined that can boot from the DVD, start or reboot your machine with the disc in your DVD drive. After a few moments, you should see the installation routine.
