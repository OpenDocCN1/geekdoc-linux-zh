When you open the Browse window with the Browse button, you are provided
icons for the desktop, your home folder, and your removable media drives. To add
a location to the Browse window, right-click in the right pane of the window and
select Open Location from the shortcut menu. You can type in the path. The eas-
way to see all the available folders is to type a slash (/) for the root and all theolders contained in the file system appear. Click on the one you want to add. You can
now use this location as the start for your search.

# Show More Search Options

To access more search options, select the Show More Options switch in
the Search for Files window.

# Enter Additional Search Options

Select the Available Options drop-down list and select one of the
options listed:

+   - Contains the Text—Enter any text contained in the file.
- Date Modified Less Than—Enter the number of days that the mod-
ification date must be less than.
- Date Modified More Than—Enter the number of days that the
modification date must be greater.
- Size At Least—Enter the “least” file size in kilobytes.
- Size At Most—Enter the “most” file size in kilobytes.
- File Is Empty—Looks for empty files (you will use this rarely
because anything you create in an application is essentially “not
empty”).
- Owned By User—Enter the user who owns the file.
- Owned By Group—Enter the group that owns the file.
- Owner Is Unrecognized—Allows you to search for files where the
cannot be recognized by the system.
- Name Does Not Contain—Enter a character string not contained in
the filename. This allows you to “rule out” certain files that would
contain the character in the name.
- Name Matches Regular Expression—Regular expressions are special
search strings that you can create using a text editor. Using regular
expressions is certainly an advanced way to search but requires a
fair amount of knowledge to create.
