# 1 Access Open Dialog

From any of the OpenOffice.org application windows, select File, Open. The Open dialog box appears.

TIP

You can quickly open a file using the Open File button on the Function bar.

# 2 Select File

Use the icons provided (double-click to open a folder or location in the left pane) to locate the file that you want to open and then select the file in the file list.

TIP

The Open dialog browses for all document types. If you want to browse for only one file type, such as text documents or spreadsheets, select the File Type drop-down list type and select one of the file types provided. This filters the file list by that file type.
