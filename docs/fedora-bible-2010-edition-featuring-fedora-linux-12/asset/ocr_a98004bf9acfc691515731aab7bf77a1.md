# # Summary

With the rise of the Internet, security has become a critical issue for nearly all computer users. Properly using passwords, securely configuring network services, and monitoring log files are critical ways of keeping your computer secure. Using encryption keys, you can help verify the authenticity of those you communicate with, as well as make the data you transmit more secure. By following the recommendations in this chapter, you can begin to learn the techniques and tools that are available for keeping your Fedora systems secure.
