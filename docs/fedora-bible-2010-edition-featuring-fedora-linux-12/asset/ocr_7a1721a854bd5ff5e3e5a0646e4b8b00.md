While most of this chapter focuses on using and administering a MySQL database from the command line, some graphical tools are available for working with MySQL databases. ```
# yum install mysql-administrator
```
```

If you are familiar with MySQL, you can go ahead and use MySQL Administrator to connect to your MySQL database (assuming it is already running). If MySQL is new to you, I recommend you run through the procedures in this chapter to become familiar with how MySQL works and how to use it from the command line.

To launch MySQL Administrator, type **mysql-administrator**. If your MySQL database server is running, as described later in this chapter, enter the server hostname (such as **localhost**), user name (such as **root**), and password. The MySQL Administrator window appears, as shown in Figure 23-1.
