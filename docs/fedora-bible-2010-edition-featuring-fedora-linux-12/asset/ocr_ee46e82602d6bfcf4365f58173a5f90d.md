The libvirt site (http://libvirt.org/storage.html) describes storage device choices. The choices include:

+   - **raw** — A raw disk image is the default type created by virt-manager. Although it doesn’t make the most efficient use of disk space, it is a format that is easy to export to other formats so it can be used by other virtualization software.

+   - **bochs** — A disk image format used by Bochs, a portable x86 emulator.

+   - **cloop** — A loopback disk image format that can work with compressed CD images.

+   - **cow** — A disk image format used with User Mode Linux. Once the only image format used by QEMU that was growable, it is now mostly supported for compatibility with older versions.
