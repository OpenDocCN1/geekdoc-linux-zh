# TextMaker

TextMaker is another popular commerical word processing package for Linux (http://www.softmaker.com/english/tm1_en.htm). # Displaying PDF Files with Adobe Acrobat Reader

The Portable Document Format (PDF) provides a way of storing documents as they would appear in print. With Adobe Acrobat Reader, you can view PDF files in a very friendly way. Adobe Acrobat makes it easy to move around within a PDF file. A PDF file may include hyperlinks, a table of contents, graphics, and a variety of type fonts.

PDF files are used extensively on the Internet as a means to exchange documents. Traditionally, the PDF format has been considered more secure than other formats such as Microsoft Word, although there have been PDF security issues as well. In addition, as a read-only document format, PDF files serve better than Word documents when an organization wants to distribute documents.

Download the most recent version of Adobe Acrobat Reader from Adobe.com at get.adobe.com/reader/. As of this writing, the most recent version is 9.1.2. See http://www.adobe.com/products/reader/dlm/firefox_steps.html for instructions on how to install the Adobe PDF Reader plug-in for Firefox.

Acrobat Reader comes as a .bin file, a binary executable. You need to change permissions on this file and then execute the file as the root user:

```
# chmod u+x AdbeRdr9.1.2-1_i486linux_enu.bin
# ./AdbeRdr9.1.2-1_i486linux_enu.bin
```

After you install Adobe Acrobat Reader, type the following command to start the program:

```
$ acroread
```

You can also Select Adobe Reader from the Applications→Office menu on the desktop.
