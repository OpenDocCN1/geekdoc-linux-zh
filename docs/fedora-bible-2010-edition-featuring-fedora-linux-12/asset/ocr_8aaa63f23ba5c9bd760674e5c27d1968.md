# Accessing an LDAP Address Book from Thunderbird

With your LDAP address book configured and running, you should be able to use it to get e-mail addresses from any e-mail client that supports LDAP directories. Assuming your LDAP directory is up and running, the following example shows how to use Thunderbird (which is available with Fedora) to search your LDAP directory for e-mail addresses.

+   1. In Thunderbird, click the Address Book button.

+   2. In the Address Book window, select File \to New \to LDAP Directory. From the Thunderbird Directory Server Properties dialogthat appears, enter at least the following information on the General tab:

+   - **Name** — The name that identifies the server on your LDAP Servers list.
+   - **Hostname** — The name or IP address of the computer hosting the LDAP content.
+   - **Base DN** — Indicates the point in the LDAP directory to begin searching. You can select Find to have Thunderbird check your LDAP server for the Search base. In the example used throughout this chapter, `dc=linuxtoys,dc=net` is the search base.
+   - **Port** — Enter an IP address for the LDAP server. The port number is 389 by default.
