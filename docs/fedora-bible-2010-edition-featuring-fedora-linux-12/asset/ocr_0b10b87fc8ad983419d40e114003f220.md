# Checking the status of shared directories

The smbstatus command enables you to view who is currently using Samba shared resources offered from your Linux system. The following is an example of the output from smbstatus:

![](bbox=[0.13, 0.21, 0.78, 0.5])

This output shows that from your Linux Samba server, the myhome service (which is a share of /home/chris/files directory) is currently open by the computer named bookeer. PID 25833 is the process number of the smbd daemon on the Linux server that is handling the service. The file that is open is the /home/chris/files/.b.swap file, which happens to be opened by a vi command. It has read/write access.

# Using Samba from Nautilus

To connect to a Samba share from Nautilus, use the Open Location box by clicking File → Open Location. Then type smb: into your Nautilus file manager Open Location box.
