+   *   **dmg** — A Mac disk image format.

+   *   **iso** — A disk image format used with CDs and DVDs.

+   *   **qcow** — The QEMU version 1 disk image format. This has largely been replaced by qcow2. Images in this format are still substantially smaller than raw images. With a qcow image, you can store snapshots of the image's history. The image can also be compressed (using zlib compression) and encrypted (using AES encryption).

+   *   **qcow2** — The QEMU version 2 disk image format. Offers the same features as qcow, plus smaller images.

+   *   **vmdk** — A disk image format used with VMware.

+   *   **vpc** — A VirtualPC disk image format.

The qcow2 image format is popular because it only takes up as much space as the guest operating system consumes, up to the maximum amount allocated. So, with many guests installed, you can make much more efficient use of your disk space.

Choose the image Name, Format, Max Capacity, and Allocation and select Create Volume. The new volume appears in the Host Details window under the Volumes Heading.

A pop-up window asks for the location of your install media (CD, DVD, ISO image, Web server, FTP server, or PXE server).
