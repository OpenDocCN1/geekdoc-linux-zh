# xxii  Preface

+   * **Fedora 12 Desktop Live/Install CD** — Before you install Fedora, you can try out a desktop-oriented live version of Fedora 12 by booting the CD that comes with this book. For this edition, we use the GNOME live CD (there is also a KDE live CD available for download). While that CD is running, you can use it to prepare your computer for a permanent installation. The contents of that CD can also be installed directly to your hard disk.

+   * **Productivity, productivity, productivity** — Much of this book has been changed, sometimes subtly, to focus on getting you up-to-speed and productive as quickly as possible. Some of the older features are gone, replaced by newer features. In addition, the goal is to cover enough to get you started and then point you in the right direction should you need more information.

+   * **Virtualization** — Virtualization, the ability to run other operating systems on top of your Fedora system, forms a major focus for Fedora 12. This release adds lots of changes and improvements across the board relating to virtualization, from improved performance with large memory virtualizations to virtual storage management. We added a new chapter to focus on virtualization issues (Chapter 25).

+   * **GNOME 2.28 Desktop** — Although primarily a release focusing on software usability improvements, GNOME 2.28 includes some new features for supporting Bluetooth wireless devices, as well as a nice focus on improving the usability of all the GNOME applications. There have also been improvements to the Cheese photo editor, the time-tracker applet that helps you keep track of time spent on projects, and the Empathy instant messaging client.

+   * **KDE 4.3 Desktop** — The KDE desktop includes a new desktop theme called Air, along with improved integration with Fedora branding, menus, and overall concepts. Several new applets were added to the relatively new Plasma desktop included with KDE. In addition, KDE offers improved notifications and job management. (KDE is not on the CD that comes with this book, but you can install it from the DVD.)

+   * **Improved security** — Using the PolicyKit, applications can run without root privileges while gaining enhanced permissions only for selected operations. This contrasts with the less secure traditional method of granting all of an application super user privileges.

+   * **Better Webcam support** — With the rise of small notebooks, webcams have become standard hardware on many portable devices. Fedora 12 improves upon earlier efforts to support many more webcams under Linux, and provide better support to those that were only marginally supported in the past.

+   * **Command line help, including installing applications** — The “command not found” feature of PackageKit provides help when you misspell the names of Linux commands, and even offers to install missing commands.

In addition to new features just described, procedures throughout the book have been tested and corrected to match changes that have occurred to Fedora 12 software in this version.
