# Summary

By providing centralized file servers, an organization can efficiently share information and applications with people within the organization, with customers, or with anyone around the world. Several different technologies are available in Fedora to enable you to make your Linux computer a file server.

The Network File System (NFS) protocol was one of the first file server technologies available. It is particularly well suited for sharing file systems among Fedora and other Linux/UNIX systems. NFS uses standard `mount` and `umount` commands to connect file systems to the directory structures of client computers.

The Samba software package that comes with Fedora contains protocols and utilities for sharing files and printers among Windows, UNIX and Linux operating systems. It uses SMB and CIFS protocols that are included with all Microsoft Windows systems, and therefore provides a convenient method of sharing resources on LANs containing many Windows systems.
