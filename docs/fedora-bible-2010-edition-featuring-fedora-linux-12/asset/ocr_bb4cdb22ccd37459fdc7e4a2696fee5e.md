# # Using the Moblin Desktop

The Moblin desktop provides a specialized desktop aimed at users of systems sporting small screens and limited resources, such as netbooks.

By default, Moblin takes over the entire screen and tries to show just one application at a time. Remember this is intended for systems with small screens and limited RAM and processing power. Figure 3-17 shows the default Moblin desktop screen, including an overview of tasks, should you set up.

To use Moblin, you need to install the Moblin desktop packages (`yum install @moblin-desktop`). To launch this desktop, you can either select Moblin from the Sessions box on the KDE login screen or use the switchdesk feature (described earlier in this chapter) to make Moblin your default desktop.
