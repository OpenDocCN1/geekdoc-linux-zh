With the `-h` option, `rpm` chugs out 50 hash marks (#) until the package is done installing. As you can see, when everything goes well, installing with `rpm` is quite simple. Some problems can occur, however. Here are a couple of them:

+   * **Package dependencies errors** — If the package you are installing requires an additional package for it to work properly, you will see an error noting the missing components. You should get and install the packages containing those components before trying your package again. (You can override the failure with install options described previously, but I don't recommend that because your package may not work without the dependent package.)
