+   4. Select Internet Protocol Version 4 and click Properties.

+   5. On the General tab, make sure the Obtain an IP Address Automatically button is selected.

# Windows (95, 98, 2000, or XP)

+   1. From most older Windows operating systems (Windows 95, 98, and 2000), you open the Network window from the Control Panel (Start \u2192 Settings \u2192 Control Panel). For Windows XP systems, select Start \u2192 Control Panel \u2192 Network and Internet Connections \u2192 Network Connections, and then select your Local Area Connection and choose Properties.

+   2. From the Configuration tab (or General tab in Windows XP), click the TCP/IP interface associated with your Ethernet card (something like TCP/IP \u2192 3Com EtherLink III).

+   3. Click Properties. The Properties window appears.

+   4. Click the IP Address tab (or General tab in Windows XP) and then select the Obtain an IP Address Automatically check box.

+   5. Click OK and reboot the computer so the client can use the new IP address.

# Fedora

While you are initially installing Linux, click Configure using DHCP on the Network Configuration screen. Your network client should automatically pick up its IP address from your DHCP server when it starts up.

To set up DHCP after installation using the Network Manager, follow these steps:

+   1. Right-click on the Network Manager icon in the GNOME panel.

+   2. Select Edit Connections.

+   3. Highlight “System eth0” and press the Edit… button.

+   4. Select the IPv4 Settings tab.

+   5. Select “Automatic (DHCP)” from the Method drop-down box.

+   6. Click Apply and then click Close.

+   7. Click on the Network Manager icon and select System eth0 to reconnect.

Additionally, there is a traditional tool commonly used on Fedora servers that you can use instead of using the Network Manager. To set up DHCP after installation using the traditional Network Configuration tool, follow these steps:

+   1. Open the Network Configuration window (select System \u2192 Administration \u2192 Network or run the system-config-network command).

+   2. From the Network Configuration window:

+   a. Click the Devices tab (on by default).
