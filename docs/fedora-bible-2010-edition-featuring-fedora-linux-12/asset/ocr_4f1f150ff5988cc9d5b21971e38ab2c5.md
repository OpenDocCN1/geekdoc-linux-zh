The `options` definition lies at the beginning of the named.conf file and identifies the `/var/named` directory as the location where the zone files reside. The `acl` lines define the `mylan` access-control list, which consists of host computers on the 10.0.0.0 local private network and the localhost (127/8). (See Chapter 14 for information on the form of IP addresses, CIDR, and netmasks.) You use this definition in the `0.0.10.in-addr.arpa` zone to enable only users on the LAN to perform reverse lookups of names of computers on the LAN.

The `controls` section indicates that the rndc command (used to start, stop, and otherwise change the named service) can only be run from the localhost. The `include` statement at the end of the file indicates where the rndc key is. The rndc command is called by the named startup script (`service` named start), so you rarely need to use the rndc command directly.
