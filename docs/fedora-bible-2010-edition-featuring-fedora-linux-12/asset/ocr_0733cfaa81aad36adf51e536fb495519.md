Chapter 2 describes installation using the included media, as well as methods of launching installation if you don't have a bootable DVD or CD drive: Once the install is started, you need either an extra hard disk partition or another computer (that can be reached over the network) that has packages or images of the Fedora distribution on it.

Not every piece of PC hardware works with Fedora. While there is no official hardware compatibility list as there is for Red Hat Enterprise Linux (available at `https://hardware.redhat.com`), overall hardware support should be improved in Fedora 12. In fact, wireless LAN cards, FireWire devices, and some other components have seen improved support in recent versions of Fedora.

There are versions of Fedora available for other computer architectures as well. If you have a Power PC or X86 64-bit computer, you can download official install and live CDs and DVDs from the Fedora project (`http://fedoraproject.org/get-fedora.html`).

# Fedora Bible 2010 Edition Improvements

*Fedora Bible 2010 Edition* represents the continuing development of *Red Hat Linux Bible*, which first published in 1999. About every six months since Red Hat Linux 6.1, we followed new versions of Red Hat Linux or Fedora with updates of this book.

Red Hat, Inc. split its Red Hat Linux development efforts into two tracks: the Fedora Project and the Red Hat Enterprise Linux (RHEL) product. This book now covers the fast-moving Fedora Linux. By learning the features in Fedora 12, you will also be preparing yourself for future releases of RHEL.

The foundation for Fedora, RHEL, and this book rests on the tradition begun with Red Hat Linux. The enhancements included in this edition reflect that foundation, plus some bold new cutting-edge Linux technology.

This edition covers a wide range of features in Fedora 12. The following list describes features that are new to this book since the previous edition:

+   - **Fedora 12 Official Install DVD** — We provide Fedora 12 on DVD with this edition. This is the exact DVD produced by the Fedora project, offering a wide range of desktop, workstation, and server software.
