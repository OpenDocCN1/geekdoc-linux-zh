Now, when you use programs such as $\mathit{1ftp}$, $\mathit{ssh}$, or other TCP/IP utilities, you can use any hostname that is identified on your local computer, exists in your search path domain, or can be resolved from the public Internet DNS servers. (Strictly speaking, you don't have to set up your /etc/hosts file. You could use IP addresses as arguments to TCP/IP commands, but names are easier to work with.)

# Adding Windows computers to your LAN

It is likely that you have other types of computers on your LAN in addition to those running Linux systems (at least for a few more years). If a DHCP server is available on your LAN (or if you have configured one yourself as described in Chapter 22), Windows and most other computer systems can simply start up and begin using the network. In cases where your network card is not properly detected, or you want to set static IP addresses, you need to do some extra configuration.
