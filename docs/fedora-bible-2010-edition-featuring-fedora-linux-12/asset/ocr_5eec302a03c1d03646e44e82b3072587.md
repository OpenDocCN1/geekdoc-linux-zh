Sections in the output from dig include a question section and an authority section. The results show name server assignments and addresses associated with the domain you're querying about. (To query a specific DNS *server*, use `dig @server yourdomain.com.`) The `nslookup` command is another tool you can use to look up domain information. In the following example, `nslookup` looks up the server that is resolving `ftp.yourdomain.com`:

```
```
# nslookup -sil ftp.yourdomain.com
Server:		123.45.67.89
Address:		123.45.67.89#53

Name:	ftp.yourdomain.com
Address:	123.45.67.3
```
```

The output from the `nslookup` command includes the name of the computer fulfilling the request and its IP address, along with the name and address of the computer you're asking for. (The `-sil` option prevents a message that `nslookup` might show be removed from Fedora.) Try `nslookup` with an IP address (such as `10.0.0.1`) to make sure reverse lookup works. You can also consider using `dig` instead of `nslookup`.
