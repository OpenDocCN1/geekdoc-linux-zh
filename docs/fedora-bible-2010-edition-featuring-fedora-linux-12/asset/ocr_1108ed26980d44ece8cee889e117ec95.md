The **id** field is a unique identifier, one to four alphanumeric characters in length, that represents a particular action to take during system startup. The **runlevels** field contains a list of run levels in which the command will be run. Common run levels are 0, 1, 2, 3, 4, 5, and 6 (s and S represent single-user mode, which is equivalent to 1). Run levels 7, 8, and 9 can also be used as the special run levels associated with the on-demand action (a, b, and c, which are equivalent to A, B, and C). The next field represents the type of action to be taken by **init** (valid actions and the results of those actions are listed in Table 11-3), and the last field is the actual command that is to be executed.
