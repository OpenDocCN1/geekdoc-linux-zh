# Launching applications

Instead of the default top panel used in the GNOME desktop, KDE provides a small F (for Fedora) menu on the bottom left of the screen. From this menu, you can select **Applications** and then browse through the menus under **Applications**. These menus are similar by default, but not exactly the same as the GNOME menus. Figure 3-10 shows the **Applications** menus.

Using the menus in Figure 3-10, you can select any of the tabs on the bottom to change the available choices.

+   - The **Favorites** tab lists items you’re likely to use most often.
+   - The **Applications** tab shows a hierarchy of menus based on categories such as Office and Utilities from which you can launch applications.
+   - The **Computer** tab provides shortcuts to directories, network file servers, as well as system information.
