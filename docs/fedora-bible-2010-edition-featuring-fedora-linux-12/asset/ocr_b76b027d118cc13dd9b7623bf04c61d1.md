Here is an example of a cdlabelgen command line that you can use to generate a CD label file in PostScript format. (Type it all on one line or use backslashes, as shown here, to put it on multiple lines.)

```
```bash
cdlabelgen -c "Grunge is Gone" -s "Yep HipHop" \\
-i "If You Feed Me$Sockin Years$City Road$Platinum and Copper$Fly Fly \\
Fly$Beat Man Spins$What A Headache$Stayin Put Feelin$Dreame Do Go \\
Blue$Usa$Wildest Schemes" -o yeah.ps
```
```

In this example, the title of the CD is indicated by -c "Grunge is Gone" and the artist by the -s "Yep HipHop" option. The tracks are entered after the -i option, with each line separated by a $ sign. The output file is sent to the file yeah.ps with the -o option. To view and print the results, you can use the evince command as follows:

```
```bash
$ evince yeah.ps
```
```

The results of this example are shown in Figure 7-9.

You will probably want to edit the command and re-run evince a few times to get the CD label correct. When you are ready to print the label (assuming you have a printer configured for your computer), click Print All to print the label.
