## Table 20-1: Dynamic Shared Object (DSO) Modules

| Module | Description |
|---|---|

| mod_dnssd | Adds ZeroConf support to Apache. |
| mod_dumpio | Lets you log all input received by or sent from Apache. Because this can involve a lot of data, it is used mostly for debugging purposes. |

## Including module-specific configuration files

The following line causes Apache to load configuration files from the /etc/httpd/conf.d/ directory. This directory contains configuration files associated with specific modules.

```
Include conf.d/*.conf
```
