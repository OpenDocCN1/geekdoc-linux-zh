# # Monitoring Server Activities

An Apache Web server is a tempting target for someone with a desire to hijack a computer for bad purposes. This usually occurs because the server is placed on the public Internet to service client requests. Because of the open nature of the Internet, it’s likely that if you do not secure your Web server correctly, you will become a target for an attack.
