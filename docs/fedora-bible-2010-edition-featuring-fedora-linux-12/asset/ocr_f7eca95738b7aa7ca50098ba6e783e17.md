+   6. Save slapd.conf. Save your changes to the slapd.conf file and close it.

+   7. Check slapd.conf. Check for syntax errors in your slapd.conf file by running the slappatest command, as follows:

```
```
# slappatest -u
config file testing succeeded
```
```

If something was wrong with the syntax of the file (for example, if you omitted a quotation mark or misplaced a comma), the message would say slappatest: bad configuration file instead. Try to correct the problem and check the file again. Later, when the databases are created, you can run slappatest again (without the -u option) to make sure that slapd.conf points to existing, properly configured databases.

At this point, you can try starting the OpenLDAP service.

# ## Creating an Encrypted Password

To create an encrypted password for the administrator of the OpenLDAP database, use the slappasswd command. You can create the password using Crypt, SSHA, SMD5, MD5, or SHA encryption. Here's an example of creating a password for OpenLDAP using MD5 encryption:

```
```
# slappasswd -h {md5} > /tmp/myslap
New password: ********
Re-enter new password: ********
# cat /tmp/myslap
{MD5}uBoM+LOQg5GHJj2Z4NLu9a==
```
```

Enter a password (twice) to create an encrypted MD5 password. This example directs the encrypted password into the /tmp/myslap file; you can read into the slapd.conf file later. In this example, I had you cat the file so you could see what the encrypted password looks like. Your password will be different. Here's what the rootpw line will look like with an encrypted rather than a clear-text password:

```
```
rootpw {MD5}uBoM+LOQg5GHJj2Z4NLu9a==
```
```
