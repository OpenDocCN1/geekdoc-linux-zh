To modify the device represented by a piece of hardware, click the Devices tab, highlight the device, and click Edit on the toolbar. The utility displays a window appropriate to the device you are editing. For example, if you are working with an Ethernet NIC, system-config-network displays the Ethernet Device window (Figure 17-8).

From this window, you can set up the device to use DHCP or manually specify the necessary IP addresses. The Hardware Device tab allows you to associate the device with a piece of hardware and specify a MAC address (page 1092). When you are finished making changes, click OK, click the Devices tab, highlight the new device, and click Menu bar: File Save. Click Activate on the toolbar to activate the device if necessary.
