
以下命令使用 `find` 在根目录为当前工作目录的目录树中定位名为 **README** 的文件。此文件列表是 `find` 的标准输出，并成为 `ls` 的参数列表。

```
$ ls -l $(find . -name README -print)
```

下一行命令展示了旧的 `\`command\`` 语法：

```
$ ls -1 `find . -name README -print`
```
新语法的一个优点是它避免了旧语法中关于令牌处理、引号处理以及转义反引号的晦涩规则。新语法的另一个优点是它可以嵌套，而旧语法则不能。例如，你可以使用以下命令生成所有大小超过 ./README 的 **README** 文件的详细列表：

```
$ ls -l $(find . -name README -size +$(cat ./README | wc -c) -print)
```
在执行此命令之前，先执行一个 `set -x` 命令（第 900 页），以查看 bash 如何展开它。如果没有 README 文件，你只会得到 `ls -l` 的输出。有关使用命令替换的其他脚本，请参见第 896、915 和 945 页。

## $(( 与 $(

> **提示：** 符号 `$((` 构成一个独立的令牌。它引入的是一个算术表达式，而不是命令替换。因此，如果你想使用带括号的原生子 shell（第 293 页）在 `$( )` 内，必须在 `$(` 和下一个 `(` 之间插入一个空格。

## 单词分割

参数和变量展开、命令替换以及算术展开的结果是单词分割的候选项。bash 使用 `IFS`（第 309 页）中的每个字符作为可能的分隔符，将这些候选项分割为单词或令牌。如果 `IFS` 未设置，bash 使用其默认值（空格-制表符-换行符）。如果 `IFS` 为空，bash 不分割单词。

## 路径名展开

路径名展开（第 243 页），也称为*文件名生成*或*通配符匹配*，是解释模糊文件引用并替换为相应文件名列表的过程。除非设置了 `glob`（第 341 页），否则当 shell 遇到模糊文件引用——即包含任一引用字符 `\*?[]|` 的令牌时——shell 会执行此功能。如果 bash 无法找到任何匹配指定模式的文件，包含模糊文件引用的令牌将保持原样。Shell 不会删除该令牌或将其替换为空字符串，而是将其原样传递给程序（参见第 341 页的 `noglob`）。

在以下示例的第一个 `echo` 命令中，shell 展开模糊文件引用 `tmp*` 并将三个令牌（`tmp1`、`tmp2` 和 `tmp3`）传递给 `echo`。`echo` 内置命令显示 shell 传递的三个文件名。在 `rm` 删除这三个 `tmp*` 文件后，shell 尝试展开时找不到匹配 `tmp*` 的文件名。因此，它将未展开的字符串传递给 `echo` 内置命令，该命令显示其接收到的字符串。

```
$ ls
tmp1 tmp2 tmp3
$ echo tmp*
tmp1 tmp2 tmp3
$ rm tmp*
$ echo tmp*
tmp*
```
在路径名开头或在路径名中紧跟斜杠（`/`）后的点必须显式匹配，除非你设置了 `dotglob`（第 340 页）。选项 `nocaseglob`（第 341 页）使模糊文件引用在匹配文件名时忽略大小写。

> 在参数周围使用双引号会使 shell 抑制路径名扩展和其他所有扩展，但参数和变量扩展除外。在参数周围使用单引号会抑制所有类型的扩展。以下示例中的第二个 `echo` 命令显示变量 `$alex` 位于双引号之间，双引号允许变量扩展。结果，shell 将该变量展开为其值：`sonar`。由于第三个 `echo` 命令使用单引号，因此不会发生此展开。由于单引号和双引号都不允许路径名扩展，最后两个命令显示未展开的参数 `tmp*`。

```
$ echo tmp* $alex
tmp1 tmp2 tmp3 sonar
$ echo "tmp* $alex"
tmp* sonar
$ echo 'tmp* $alex'
tmp* $alex
```
shell 区分变量的值和变量的引用，如果模糊文件引用出现在变量的值中，则不进行展开。因此，你可以给变量赋值一个包含特殊字符（例如星号（`*`））的值。

> 在下一个示例中，工作目录有三个文件名以 `letter` 开头的文件。当你将值 `letter*` 分配给变量 `var` 时，shell 不会对模糊文件引用进行扩展，因为它出现在变量的值中（在变量的赋值语句中）。字符串 `letter*` 周围没有引号；仅上下文就阻止了扩展。赋值后，`set` 内置命令（借助 `grep`）显示 `var` 的值为 `letter*`。

三个 `echo` 命令演示了三个级别的扩展。当 `$var` 用单引号引用时，shell 不执行任何扩展，并将字符字符串 `$var` 传递给 `echo`，`echo` 则显示该字符串。当你使用双引号时，shell 仅执行变量扩展，并用 `var` 变量的值替换其名称，前面带有美元符号。由于双引号会抑制路径名扩展，因此此命令不会执行路径名扩展。在最后一个命令中，shell 没有引号限制，在执行变量替换之后、将参数传递给 `echo` 之前执行路径名展开。

```
$ ls letter* 
letter1 letter2 letter3 
$ var='letter*' 
$ set | grep var 
var='letter*'
$ echo '$var'
$var
$ echo "$var"
letter*
$ echo $var
letter1 letter2 letter3
```

## 进程替换

Bourne Again Shell 的一个特殊功能是能够用进程替换文件名参数。语法为 `<command>` 的参数会导致执行 *command* 并将输出写入命名管道（FIFO）。shell 将该参数替换为管道的名称。如果该参数随后在处理过程中被用作输入文件的名称，则读取 *command* 的输出。类似地，语法为 `>command` 的参数被替换为 *command* 作为标准输入读取的管道的名称。

以下示例使用 *sort*（第 155 页）的 **-m**（合并，仅在输入文件已排序时才正确工作）选项，将两个单词列表合并为一个列表。每个单词列表由一个管道生成，该管道从文件中提取匹配模式的单词并对该列表中的单词进行排序。

```
$ sort -m -f <(grep "[^A-Z][^A-Z]" memol | sort) <(grep "[^A-Z][^A-Z]" memo2 | sort)
```

## 章节总结

Shell 既是命令解释器，也是编程语言。作为命令解释器，shell 执行你响应其提示而输入的命令。作为编程语言，shell 执行来自称为 shell 脚本的文件的命令。当你启动 shell 时，它通常运行一个或多个启动文件。

假设包含 shell 脚本的文件位于当前工作目录中，从命令行执行该 shell 脚本有三种基本方法。

- 输入包含该脚本的文件名的简单文件名。
- 输入相对路径名，包括以 `./` 开头的简单文件名。
- 输入 `bash` 后跟文件名。

方法 1 要求当前工作目录位于 `PATH` 变量中。方法 1 和方法 2 要求你对包含脚本的文件具有执行权限和读取权限。方法 3 要求你对包含脚本的文件具有读取权限。

## 作业控制

一个作业是一个或多个通过管道连接的命令。你可以使用 `fg` 内置命令将后台运行的作业转到前台。你可以使用 `bg` 内置命令将前台作业放到后台，前提是你先按暂停键（通常是 CONTROL-Z）挂起该作业。使用 `jobs` 内置命令查看哪些作业正在运行或处于挂起状态。

## 变量

Shell 允许你定义变量。你可以通过给变量赋值来声明并初始化变量；你可以使用 `unset` 移除变量声明。除非使用 `export` 内置命令导出变量使其对子进程可用，否则变量在进程内是局部的。你声明的变量称为用户创建的变量。Shell 还定义了关键字变量。在 shell 脚本中，你可以操作调用该脚本时使用的命令行（位置）参数。

## 进程

每个进程都有唯一的标识（PID）号，并且是单个 Linux 命令的执行。当你给出一个命令时，shell 会 fork 一个新的（子）进程来执行该命令，除非该命令是 shell 内置的（第 247 页）。当子进程正在运行时，shell 处于称为睡眠的状态。通过以 ampersand（`&`）结束命令行，你可以在后台运行子进程并绕过睡眠状态，使得在你按下 RETURN 后 shell 提示符立即返回。shell 脚本中的每个命令都会 fork 一个单独的进程，这些进程中的每一个又可能会 fork 其他进程。当一个进程终止时，它会向其父进程返回其退出状态。退出状态为零表示成功，非零表示失败。

## 历史

历史机制是从 C shell 改编的功能，它维护最近发出的命令行（也称为事件）列表，提供了一种快速重新执行之前命令的方法。有几种处理历史列表的方法；最简单的一种是使用命令行编辑器。

## 命令行编辑器

在使用交互式 Bourne Again Shell 时，你可以使用 Bourne Again Shell 的两种命令行编辑器之一（`vi(m)` 或 `emacs`）编辑你的命令行和历史文件中的命令。当你使用 `vi(m)` 命令行编辑器时，你从输入模式开始，这与通常进入 `vi(m)` 的方式不同。你可以在命令模式和输入模式之间切换。`emacs` 编辑器没有模式，通过识别控制字符作为命令来区分命令和编辑器输入。

## 别名

别名是 shell 将其转换为另一个名称或（复杂）命令的名称。别名允许你通过用字符串替换简单命令的第一个令牌来定义新命令。
