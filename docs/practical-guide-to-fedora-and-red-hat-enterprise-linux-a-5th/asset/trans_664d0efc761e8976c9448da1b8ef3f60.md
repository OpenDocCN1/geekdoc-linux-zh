总之，**桌面**目录与其他任何目录类似，只是 GNOME 会在桌面（每个工作区）上显示其内容。这就像桌面是一个巨大的、普通的“桌面文件浏览器”窗口。因为 **桌面**目录始终被显示，所以您可以对其进行操作。在 GUI 中，若要显示和与其他任何目录的内容进行操作，您必须使用诸如 Nautilus 之类的实用程序。

## 选择对象

可以在文件浏览器窗口或桌面上使用相同的技术来选择一个或多个对象。单击一次对象即可将其选中；GNOME 会突出显示该对象。按住 CTRL 键的同时单击其他对象，以选择更多对象。通过先突出显示第一个对象，然后按住 SHIFT 键并单击最后一个对象，您可以选择一组相邻的对象；GNOME 会突出显示您单击的两个对象之间的所有对象。或者，您可以使用鼠标指针拖出一个框，将一组对象框选起来。

若要尝试这些技术，请打开一个显示主文件夹的文件浏览器窗口。选中几个对象，右键单击，然后选择“复制”。现在将鼠标指针移动到桌面的空白区域，右键单击，并选择“粘贴”。这样，您就从主文件夹中选中了所选对象并将其复制到了桌面上。您可以拖动和放置对象来移动它们，但无法将 **桌面**文件夹拖放到其自身之上。

## 清空回收站

选择 **文件浏览器菜单栏：编辑 > 移到回收站** 会将选中的（突出显示的）对象移动到 **回收站**目录。由于回收站中的文件会占用硬盘空间（与任何文件一样），定期删除它们是个好主意。所有文件浏览器窗口都允许您通过选择 **文件浏览器菜单栏：文件 > 清空回收站** 来永久删除 **回收站**目录中的所有文件。要查看回收站中的文件，请单击底部面板右端的回收站图标（图 4–2，第 92 页）。Nautilus 会显示 **回收站文件浏览器** 窗口。从 **回收站**图标上下文菜单中选择 **清空回收站**，即可永久删除回收站中的所有文件。（如果回收站中没有文件，则不会出现此选项。）或者，您可以打开 **回收站**目录，右键单击一个对象，并选择 **永久删除** 以仅移除该对象（文件）。您可以像操作其他文件夹一样，将文件拖放至回收站或从回收站拖出。

# 更新小部件

在连接到互联网的系统上，Fedora/RHEL 最初被设置为自动搜索软件更新并在有可用更新时通知您。GNOME 在有可用更新时，会将更新小部件（图 4-12）放置在顶部面板的右侧。单击此对象会打开“软件更新”窗口（图 4-12）。您也可以通过选择 主菜单：系统 → 管理 → 软件更新 (FEDORA) 或 主菜单：应用程序 → 系统工具 → 软件更新器 (RHEL)，或者在终端模拟器或“运行应用程序”窗口（ALT-F2）中输入命令 `gpk-update-viewer` (FEDORA) 或 `pup` (RHEL) 来打开此窗口。

![](img/f28adb66a7398a382f0505e0ba74a872_145_0.png)

图 4-12 更新小部件和软件更新窗口

当“软件更新”窗口打开时，它会显示信息 **正在检查更新**；稍后它会显示可用更新的数量。如果没有可用更新，窗口会显示信息 **所有软件均为最新版本**。如果有可用更新，请单击 **安装更新**。在下载和安装软件包时，“软件更新”窗口会显示消息和进度条。完成后，“软件更新”窗口会关闭。如果更新要求您重新启动系统或重启某个程序，顶部面板上会出现一个对象。准备好时，单击此对象并采取所需操作。有关更多信息，请参阅第 122 页的“更新、安装和删除软件包”。

# 更改外观（主题）

Linux 桌面最令人兴奋的一个方面是它提供的灵活性，允许您更改其外观。您不仅可以更改背景，还可以更改窗口边框（包括标题栏）、图标、应用程序使用的按钮等。若要查看您可以实现的一些示例，请访问 art.gnome.org。

在 **GUI** 中，*主题* 是一种反复出现的模式和整体外观，（理想情况下）赏心悦目且易于理解和使用。您可以在多个层面操作桌面主题。第一种也是最简单的选择是保持现状。Fedora 附带一个外观精美的名为 Fedora 的主题；RHEL 使用 Clearlooks。如果您对更改桌面的外观不感兴趣，请继续阅读下一节。

下一个选择几乎同样简单，即选择 Fedora/RHEL 附带的替代主题之一。您还可以修改这些主题，更改背景、字体或界面。此外，您可以从互联网上的许多站点下载主题，并以相同的方式对其进行更改。

下一个层级是定制主题，这会改变主题的外观——例如，更改主题使用的图标。在更高级的层级上，您可以设计和编写自己的主题。有关更多信息，请参阅 art.gnome.org 上的教程。

**外观首选项窗口 (FEDORA)**

更改桌面外观的关键是“外观首选项”窗口。通过选择 **主菜单：系统首选项 > 外观** 或右键单击根窗口（工作区上的任何空白区域）并选择 **更改桌面背景** 来显示此窗口。“外观首选项”窗口有三个选项卡：

- **主题** 选项卡（图 4-13）允许您选择多种主题之一。单击一个主题，工作区会立即反映使用该主题的效果。Fedora 是默认的 Fedora 主题；选择此主题可使工作区看起来像安装系统时的样子。RHEL 使用 Clearlooks。选择主题后，如果您满意此选择，可以单击 **关闭**；或者单击其他选项卡以修改主题。

![](img/f28adb66a7398a382f0505e0ba74a872_146_0.png)

图 4-13 外观首选项窗口，主题选项卡

- **背景** 选项卡允许您指定桌面背景的壁纸或颜色。若要指定壁纸，请单击“壁纸”框架中的某个样本，或单击 **添加** 并选择一个文件（例如您想用作壁纸的图片）。（单击 **添加** 会显示“添加壁纸”窗口；有关使用此窗口选择文件的说明，请参阅第 103 页的“浏览/保存窗口”。）然后选择您希望 GNOME 用于应用壁纸的风格。例如，缩放会使您选择的图片适配工作区。
  - 您还可以为背景指定颜色：纯色或两种颜色之间的渐变。若要使用颜色，您必须先从“壁纸”框架中选择 **无桌面背景**：让鼠标指针悬停在“壁纸”框架中显示的每个壁纸上，直到找到一个显示工具提示 **无桌面背景** 的壁纸。选择该（非）壁纸。（最初，此壁纸的图标出现在壁纸图标区域的左上角。）接下来，从标记为 **颜色** 的下拉列表中选择 **纯色**，并单击此列表右侧的彩色方块。GNOME 会显示“选择颜色”窗口。从圆环中单击您喜欢的颜色，并通过拖动三角形内的小圆点来调整颜色。完成后单击 **确定**。您选择的颜色将成为桌面的背景颜色。有关“选择颜色”窗口的更多信息，请参阅第 273 页。
- **字体** 选项卡（图 8-8，第 272 页）允许您指定 GNOME 在桌面不同位置使用的字体。您还可以更改 GNOME 渲染字体的方式（第 272 页）。

您在“背景”和“字体”选项卡中所做的更改将适用于您选择的任何主题，包括您定制的主题。在“外观首选项”窗口选项卡中完成更改后，您可以单击 **关闭** 以使用您修改后的主题，或者返回“主题”选项卡以定制主题。

从“外观首选项”窗口的“主题”选项卡中，选择您想要定制的主题，或继续处理上一节中修改的主题。单击 **定制** 以打开“定制主题”窗口。浏览此窗口中的每个选项卡；选择条目并观察每个选择如何改变工作区。并非所有选项卡都适用于所有主题。当您对结果满意时，单击 **关闭**。

定制主题后，其名称为“Custom”。当您定制另一个主题时，这些更改将覆盖“Custom”主题。因此，最好通过单击 **另存为** 并为主题指定唯一名称来保存定制的主题。保存主题后，它出现在“主题”选项卡的主题列表中。

_RHEL_ RHEL 使用“主题首选项”和“桌面背景首选项”窗口代替“外观首选项”窗口。“主题首选项”窗口代替 Fedora 的“主题”选项卡，“桌面背景首选项”窗口代替 Fedora 的“背景”选项卡。
