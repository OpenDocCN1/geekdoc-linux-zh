# Table 12-1 Filesystems (continued)

| Filesystem | Features |
| :--- | :--- |
| **ext4** | An extension of the **ext3** filesystem. See ext4.wiki.kernel.org for more information. |
| **GFS** | Global Filesystem. GFS is a journaling, clustering filesystem. It enables a cluster of Linux servers to share a common storage pool. |
| **hfs** | Hierarchical Filesystem: used by older Macintosh systems. Newer Macintosh systems use **hfs+**. |
| **hpfs** | High-Performance Filesystem: the native filesystem for IBM's OS/2. |
| **iso9660** | The standard filesystem for CD-ROMs. |
| **minix** | Very similar to Linux, the filesystem of a small operating system that was written for educational purposes by Andrew S. Tanenbaum (www.minix3.org). |
| **msdos** | The filesystem used by DOS and subsequent Microsoft operating systems. Do not use **msdos** for mounting Windows filesystems; it does not read VFAT attributes. |
| **ncpfs** | Novell NetWare NCP Protocol Filesystem: used to mount remote filesystems under NetWare. |
| **nfs** | Network Filesystem. Developed by Sun Microsystems, this protocol allows a computer to access remote files over a network as if they were local (page 727). |
| **ntfs** | NT Filesystem: the native filesystem of Windows NT. |
| **proc** | An interface to several Linux kernel *data structures* (page 1078) that behaves like a filesystem (page 478). |
| **qnx4** | QNX 4 operating system filesystem. |
| **reiserfs** | A journaling (page 1089) filesystem, based on balanced-tree algorithms. See **ext3** for more on journaling filesystems. |
| **romfs** | A dumb, readonly filesystem used mainly for *RAM disks* (page 1102) during installation. |
| **smbfs** | Samba Filesystem (page 749). |
| **software RAID** | RAID implemented in software. Refer to “RAID Filesystem” on page 494. |
| **sysv** | System V UNIX filesystem. |
| **ufs** | Default filesystem under Sun’s Solaris operating system and other UNIXs. |
| **umsdos** | A full-feature UNIX-like filesystem that runs on top of a DOS FAT filesystem. |
| **vfat** | Developed by Microsoft, a standard that allows long filenames on FAT partitions. |
| **xfs** | SGI’s journaled filesystem (ported from Irix). |
