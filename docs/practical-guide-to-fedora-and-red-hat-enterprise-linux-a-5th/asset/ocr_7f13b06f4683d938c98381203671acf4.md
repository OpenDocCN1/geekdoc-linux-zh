# SPECIAL CHARACTERS

Table 9-6 lists most of the characters that are special to the bash shell.

Table 9-6 Shell special characters

| Character | Use |
| NEWLINE | Initiates execution of a command (page 290) |
| ; | Separates commands (page 290) |
| ( ) | Groups commands (page 293) for execution by a subshell or identifies a function (page 335) |
| & | Executes a command in the background (pages 241 and 292) |
| \| | Sends standard output of preceding command to standard input of following command (pipe; page 292) |
| > | Redirects standard output (page 232) |
| >> | Appends standard output (page 236) |
| < | Redirects standard input (page 234) |
| << | Here document (page 919) |
| * | Any string of zero or more characters in an ambiguous file reference (page 244) |
| ? | Any single character in an ambiguous file reference (page 243) |
| \\ | Quotes the following character (page 148) |
| ' | Quotes a string, preventing all substitution (page 148) |
| " | Quotes a string, allowing only variable and command substitution (pages 148 and 301) |
| `...` | Performs command substitution (page 348) |
| [ ] | Character class in an ambiguous file reference (page 245) |
| $ | References a variable (page 299) |
| . (dot builtin) | Executes a command (only at the beginning of a line, page 283) |
| # | Begins a comment (page 289) |
| { } | Used to surround the contents of a function (page 335) |
| : (null builtin) | Returns true (page 945) |
| && (Boolean AND) | Executes command on right only if command on left succeeds (returns a zero exit status; page 956) |
| \|\| (Boolean OR) | Executes command on right only if command on left fails (returns a nonzero exit status; page 956) |
| ! (Boolean NOT) | Reverses exit status of a command |
| $( ) | Performs command substitution (preferred form; page 348) |
| [ ] | Evaluates an arithmetic expression (page 346) |
