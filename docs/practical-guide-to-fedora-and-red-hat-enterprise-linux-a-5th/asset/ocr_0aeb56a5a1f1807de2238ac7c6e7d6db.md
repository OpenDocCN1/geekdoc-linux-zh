# ## FINDING LINUX-RELATED INFORMATION

Fedora/RHEL comes with reference pages stored online. You can read these documents by using the **info** (page 127) or **man** (page 125) utilities. You can read **man** and **info** pages to get more information about specific topics while reading this book or to determine which features are available with Linux. You can search for topics using **apropos** (see page 167 or give the command **man** **apropos**).
