# ## Notes

Unlike Oracle, when you create a user, MySQL does not automatically create a database. Under MySQL, users and databases are not as rigidly bound as they are under Oracle.

MySQL has a separate set of users from Linux users. As installed, the name of the MySQL administrator is **root**. Because the MySQL **root** user is not the same as the Linux **root** user, it can have a different password.

# # JUMPSTART: Setting Up MySQL

**You must assign a password to the MySQL user named root**

> The examples in this section will not work unless you use **mysql_secure_installation** to assign a password to the MySQL user named **root**. See the following instructions.

MySQL is installed with test databases, an anonymous user, and no password for the MySQL user named **root**. For a more secure setup, remove the anonymous user and assign a password to MySQL **root**. The **mysql_secure_installation** utility asks a series of questions that allows you to assign a password to the MySQL user named **root** and perform other housekeeping tasks.
