To turn off the Nautilus Spatial view and turn on File Browser windows:

+   1.  Select **Main menu: Places->Home folder**. Nautilus opens a window that displays a Spatial view of the contents of your home folder (also called your home directory; page 192). It appears similar to the left side of Figure 4-7.

+   2.  From the menubar of the new window, select **Edit->Preferences**. Nautilus displays the File Management Preferences window.

+   3.  Click the tab labeled **Behavior**. See Figure 4-8.

+   4.  Click the check box labeled **Alvays open in browser windows**. A tick will appear in the check box.

+   5.  Click the button labeled **Close** at the lower-right corner of the File Management Preferences window to close the window.

+   6.  Click the **x** at the upper-right corner of the home folder window to close the window.

After following these steps, Nautilus will always display File Browser windows as shown in this book.
