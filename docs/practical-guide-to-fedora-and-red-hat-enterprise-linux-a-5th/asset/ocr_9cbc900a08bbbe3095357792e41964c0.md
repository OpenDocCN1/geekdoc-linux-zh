# ## FINDING THE INSTALLATION MANUAL

The definitive resource for instructions on how to install Fedora/RHEL is the Installation Guide for the release you are installing and the platform you are installing it on. You can view or download installation guides at the following sites:

+   * **FEDORA** Go to docs.fedoraproject.org and select from the various formats and languages under Installation Guide.
+   * **RHEL** Go to www.redhat.com/docs/manuals/enterprise. Additional installation, setup, and troubleshooting resources are available from Red Hat at www.redhat.com/apps/support. You can also search for a keyword or words using the box labeled Search at the upper-right corner of most Red Hat Web pages.
