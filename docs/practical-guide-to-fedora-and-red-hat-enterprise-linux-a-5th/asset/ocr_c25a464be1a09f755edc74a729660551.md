# USING BITTORRENT TO DOWNLOAD A CD/DVD ISO IMAGE FILE

When you use a Web browser to download a file, the browser contacts a Web (HTTP) or FTP server and downloads the file from that server. If too many people download files from a server at the same time, the downloads become slower.

BitTorrent efficiently distributes large amounts of static data, such as ISO image files. Unlike using a browser to download a file from a single server, BitTorrent dis- tributes the functions of a server over its clients. As each client downloads a file, it becomes a server for the parts of the file it has downloaded. To use BitTorrent, you must download a small file called a torrent (or have a Web browser do it for you). This file, which holds information that allows clients to communicate with one another, has a filename extension of .torrent. As more people use a torrent to down- load a file at the same time, the downloads become faster.

Because BitTorrent is available for Windows, Mac OS X, and Linux, you can down- load and burn a Fedora CD/DVD under any of these operating systems. To download a torrent, point a browser at fedoraproject.org/get-fedora or torrent.fedora- project.org and click the filename of the torrent you want to download.
