
## foreach/for

Perl 的 **foreach** 和 **for** 关键字是同义词；你可以在任何上下文中将一个替换为另一个。这些结构是复合语句，具有两种语法。一些程序员使用 **foreach** 配合一种语法，使用 **for** 配合另一种语法，尽管这样做并没有必要。本书使用 **foreach** 配合这两种语法。

### **foreach：** 语法 1

**foreach** 结构的第一种语法类似于 shell 的 **for**...**in** 结构（第 901 页）：

```perl
foreach[for] $var (list) {...}
```

其中 *list* 是表达式或变量的列表。Perl 为 *list* 中的每个项目 **执行一次** 语句块，在每次迭代中依次将 *list* 中某一项的值分配给 *var*，从第一项开始。如果你未指定 *var*，Perl 会将值分配给 `$_` 变量（第 999 页）。

下面的程序演示了一个简单的 **foreach** 结构。在循环的第一次遍历中，Perl 将字符串 **Mo** 分配给变量 **$item**，然后 say 语句显示该变量的值后跟一个换行符（NEWLINE）。在循环的第二和第三次遍历中，**$item** 分别被分配值 **Larry** 和 **Curly**。当列表中不再有项目时，Perl 继续执行位于 **foreach** 结构之后的语句。在这种情况下，程序终止。如果该程序报告 say 不可用，请参见第 981 页关于 `use feature 'say'` 的内容。

```perl
$ cat foreach.pl
foreach $item ("Mo", "Larry", "Curly") {
    say "$item says hello.";
}
```

```bash
$ perl foreach.pl
Mo says hello.
Larry says hello.
Curly says hello.
```

使用 `$_`（第 999 页），你可以将程序编写如下：

```perl
$ cat foreacha.pl
foreach ("Mo", "Larry", "Curly") {
    say "$_ says hello.";
}
```

以下是使用数组的程序：

```perl
$ cat foreachb.pl
@stooges = ("Mo", "Larry", "Curly");
foreach (@stooges) {
    say "$_ says hello.";
}
```

以下是使用 foreach 后缀语法的程序：

```perl
$ cat foreachc.pl
@stooges = ("Mo", "Larry", "Curly");
say "$_ says hello." foreach @stooges;
```

循环变量（前述示例中的 $item 和 $_）引用括号内列表中的元素。当你修改循环变量时，你实际上是在修改列表中的元素。uc 函数返回其参数的全大写版本。下一个示例表明，修改循环变量 $stooge 会修改 @stooges 数组：

```perl
$ cat foreachd.pl
@stooges = ("Mo", "Larry", "Curly");
foreach $stooge (@stooges) {
    $stooge = uc $stooge;
    say "$stooge says hello.";
}
say "@stooges[1] is uppercase";
```

```bash
$ perl foreachd.pl
MO says hello.
LARRY says hello.
CURLY says hello.
LARRY is uppercase
```

参见第 1003 页关于遍历命令行参数的示例。

## last 和 next

Perl 的 last 和 next 语句允许你中断循环；它们类似于 Bourne Again Shell 的 break 和 continue 语句（第 910 页）。last 语句将控制权转移到循环结构控制的语句块之后的语句，从而终止循环的执行。next 语句将控制权转移到语句块的末尾，继续以下一次迭代执行循环。

在下面的程序中，if 结构测试 $item 是否等于字符串 two；如果是，该结构执行 next 命令，跳过 say 语句并继续循环的下一次迭代。如果你将 next 替换为 last，Perl 将从循环中退出，并且不会显示 three。如果该程序报告 say 不可用，请参见第 981 页关于 `use feature 'say'` 的内容。

```perl
$ cat foreachl.pl
foreach $item ("one", "two", "three") {
    if ($item eq "two") {
        next;
    }
    say "$item";
}
```

```bash
$ perl foreachl.pl
one
three
```

### **foreach：** 语法 2

**foreach** 结构的第二种语法类似于 C 语言的 **for** 结构：

```perl
foreach|for (expr1; expr2; expr3) [...]
```

*expr1* 初始化 foreach 循环；Perl 在执行语句块之前，只对 *expr1* 求值一次。*expr2* 是终止条件；Perl 在每次遍历语句块之前对其进行求值，如果 *expr2* 的求值结果为 **true**，则执行语句块。Perl 在每次遍历语句块之后对 *expr3* 求值——它通常递增 *expr2* 中变量的一部分。

在下一个示例中，**foreach2.pl** 程序提示输入三个数字；显示第一个数字；重复地将该数字加上第二个数字，显示每个结果，直到结果将大于第三个数字；然后退出。关于魔术文件句柄（**< >**）的讨论，请参见第 1000 页。

```perl
$ cat ./foreach2.pl
#!/usr/bin/perl -w

print "Enter starting number: ";
$start = <>;

print "Enter ending number: ";
$end = <>;

print "Enter increment: ";
$incr = <>;

if ($start >= $end || $incr < 1) {
    die ("The starting number must be less than the ending number\n",
        "and the increment must be greater than zero.\n");
}

foreach ($count = $start+0; $count <= $end; $count += $incr) {
    say "$count";
}
```

```bash
$ ./foreach2.pl
Enter starting number: 2
Enter ending number: 10
Enter increment: 3
2
5
8
```

在提示输入三个数字之后，上述程序测试起始数字是否大于或等于结束数字，或者增量是否小于 1。|| 是布尔 OR 运算符；**if** 后括号内的表达式，如果该运算符之前的表达式或之后的表达式任何一个求值结果为 *true*，则该表达式的求值结果即为 *true*。

**foreach** 语句开始将 **$start+0** 的值分配给 **$count**。在字符串 **$start** 上加上 0（零）强制 Perl 在数值上下文中工作，在分配时去除尾部的换行符（NEWLINE）。如果没有这个修复，程序会在显示的第一个数字后显示一个额外的换行符。

## while/until

**while**（第 904 页）和 **until**（第 908 页）控制结构是复合语句，它们使用以下语法实现条件循环：

```perl
while (expr) {...}
until (expr) {...}
```

这些结构仅在终止条件的含义上有所不同。**while** 结构在 *expr* 求值结果为 *true* 时反复执行语句块；**until** 在 *expr* 求值结果为 *true*（即 *expr* 保持 *false*）时继续执行。

以下示例演示了一种在仍有输入时读取和处理输入的技术。尽管该示例显示输入来自用户（标准输入），但该技术对于来自文件的输入（参见第 1002 页的示例）同样有效。用户在一行中单独输入 CTRL-D 来指示文件结尾。

在此示例中，*expr* 是 **$line = <>**。该语句使用魔术文件句柄（<>；第 1000 页）从标准输入读取一行，并将其读取的字符串分配给 **$line** 变量。只要读取到数据，该语句的求值结果即为 *true*。当到达文件结尾时，该语句的求值结果为 *false*。**while** 循环只要有数据可读，就继续执行语句块（在此示例中，仅有一条语句）。

```perl
$ cat while1.pl
#!/usr/bin/perl -w
$count = 0;
while ($line = <>) {
    print ++$count, ".  $line";
}
print "\n$count lines entered.\n";
```

```bash
$ ./while1.pl
Good Morning.
1. Good Morning.
Today is Monday.
2. Today is Monday.
^D
2 lines entered.
```

在前面的示例中，$count 跟踪用户输入的行数。将 ++ 自增运算符放在变量之前（++$count；称为前置自增运算符），会在 Perl 评估该变量之前对其进行自增。或者，你可以将 $count 初始化为 1，并使用 $count++（后置自增）对其进行自增，但那样的话，在最终的 print 语句中 $count 将比输入的行数多 1。

`$_` 变量跟踪程序读取的输入行数。使用 `$_`，你可以重写前面的示例如下：

```perl
$ cat while1a.pl
#!/usr/bin/perl -w
while ($line = <> ) {
    print $_, ". $line";
}
print "\n$_. lines entered.\n";
```

通过利用 `$_` 变量，通常可以简化 Perl 代码。你可以在 Perl 程序中的许多地方使用 `$_`——将 `$_` 视为“它”，即你所做操作的对象。它是许多操作的默认操作数。例如，以下代码段使用 $line 变量处理一行。它读取一行到 $line 中，使用 chomp（第 1001 页）从 $line 中去除尾部的换行符（NEWLINE），并检查正则表达式是否匹配 $line。

```perl
while (my $line = <>) {
    chomp $line;
    if ($line =~ /regex/) ...
}
```

你可以使用 `$_` 替换 $line 来重写此代码：

```perl
while (my $_ = <>) {
    chomp $_;
    if ($_ =~ /regex/) ...
}
```

由于在这些实例中 `$_` 都是默认操作数，你也可以完全省略 `$_`：

```perl
while (<>) {       # read into $_
    chomp;              # chomp $_
    if (/regex/) ...    # if $_ matches regex
}
```
