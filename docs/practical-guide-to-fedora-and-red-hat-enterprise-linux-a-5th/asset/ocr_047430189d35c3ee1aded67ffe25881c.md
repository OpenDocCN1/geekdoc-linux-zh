Finally \texttt{lnks} uses the \texttt{find} utility to search for files having inode numbers that match \texttt{\$inode}:

```
```
# Find and print the files with that inode number
echo "\$lnks: using find to search for linkss..." \$2\$2
find "\$directory" -xdev -inum \$inode -print
```
```

The \texttt{find} utility searches for files that meet the criteria specified by its arguments, beginning its search with the directory specified by its first argument (\texttt{\$directory}) and searching all subdirectories. The remaining arguments specify that the file-names of files having inodes matching \texttt{\$inode} should be sent to standard output. Because files in different filesystems can have the same inode number and not be linked, \texttt{find} must search only directories in the same filesystem as \texttt{\$directory}. The \texttt{-xdev} argument prevents \texttt{find} from searching directories on other filesystems. Refer to page 212 for more information about filesystems and links.

The \texttt{echo} command preceding the \texttt{find} command in \texttt{lnks}, which tells the user that \texttt{find} is running, is included because \texttt{find} frequently takes a long time to run. Because \texttt{lnks} does not include a final \texttt{exit} statement, the exit status of \texttt{lnks} is that of the last command it runs, \texttt{find}.

# DEBUGGING SHELL SCRIPTS

When you are writing a script such as \texttt{lnks}, it is easy to make mistakes. You can use the shell's \texttt{-x} option to help debug a script. This option causes the shell to display each command before it runs the command. Tracing a script's execution in this way can give you information about where a problem lies.

You can run \texttt{lnks} as in the previous example and cause the shell to display each command before it is executed. Either set the \texttt{-x} option for the current shell (\texttt{set -x}) so that all scripts display commands as they are run or use the \texttt{-x} option to affect only the shell that is running the script called by the command line.

```
```

+ '[' -d letter ']'
+ file=letter
+ '[' 2 -eq 1 ']'
+ '[' -d /home ']'
+ directory=/home
+ '[' '1' -f letter ']'
...
