# WINDOWS

In a workspace, a *window* is a region that runs, or is controlled by, a particular program (Figure 4-17). Because you can control the look and feel of windows—even the buttons they display—your windows may not look like the ones shown in this book. Each window in a workspace has a Window List applet (page 113) on the Bottom panel.

**Titlebar** A titlebar (Figures 4-17 and 4-18) appears at the top of most windows and controls the window it is attached to. You can change the appearance and function of a titlebar, but it will usually have at least the functionality of the buttons shown in Figure 4-18.
