# Keyword Variables: A Summary

Table 9-5 lists the *bash* keyword variables.

Table 9-5 bash keyword variables

| Variable | Value |
| :--- | :--- |
| BASH_ENV | The pathname of the startup file for noninteractive shells (page 282) |
| CDPATH | The cd search path (page 311) |
| COLUMNS | The width of the display used by select (page 917) |
| FCEDIT | The name of the editor that fc uses by default (page 319) |
| HISTFILE | The pathname of the file that holds the history list (default: ~/.bash_history; page 316) |
| HISTFILESIZE | The maximum number of entries saved in HISTFILE (default: 500; page 316) |
| HISTSIZE | The maximum number of entries saved in the history list (default: 500; page 316) |
| HOME | The pathname of the user's home directory (page 305); used as the default argument for cd and in title expansion (page 193) |
| IFS | Internal Field Separator (page 309); used for word splitting (page 349) |
| INPUTRC | The pathname of the Readline startup file (default: ~/.inputrc; page 329) |
| LANG | The locale category when that category is not specifically set with an LC_ variable |
| LC_ | A group of variables that specify locale categories including LC_COLLATE, LC_CTYPE, LC_MESSAGES, and LC_NUMERIC; use the locale builtin to display a complete list with values |
| LINES | The height of the display used by select (page 917) |
| MAIL | The pathname of the file that holds a user's mail (page 307) |
| MAILCHECK | How often, in seconds, bash checks for mail (page 307) |
| MAILPATH | A colon-separated list of file pathnames that bash checks for mail in (page 307) |
| PATH | A colon-separated list of directory pathnames that bash looks for commands in (page 306) |
| PROMPT_COMMAND | A command that bash executes just before it displays the primary prompt |
| PS1 | Prompt String 1; the primary prompt (default: "$\$"; page 307) |
| PS2 | Prompt String 2; the secondary prompt (default: "> "; page 309) |
| PS3 | The prompt issued by select (page 917) |
| PS4 | The bash debugging symbol (page 900) |
| REPLY | Holds the line that read accepts (page 938); also used by select (page 917) |
