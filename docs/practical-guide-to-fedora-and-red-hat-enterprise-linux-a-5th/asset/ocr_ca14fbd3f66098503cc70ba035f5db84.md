# OpenSSH: Secure Network Communication

OpenSSH is a suite of secure network connectivity tools that replaces telnet, rcp, rsh/rshd, rlogin/rlogind, and ftp/ftpd. Unlike the tools it replaces, OpenSSH tools encrypt all traffic, including passwords. In this way they thwart malicious users who would eavesdrop, hijack connections, and steal passwords. This chapter covers the following OpenSSH tools:

+   1. `scp`—Copies files to/from another system
+   2. `sftp`—Copies files to/from other systems (a secure replacement for ftp)
+   3. `ssh`—Runs a command on or logs in on another system
+   4. `sshd`—The OpenSSH daemon (runs on the server)
+   5. `ssh-keygen`—Creates RSA or DSA host/user authentication keys
