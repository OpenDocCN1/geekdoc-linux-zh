GNOME provides tooltips (page 110), a context-sensitive Help system, and the Help Browser discussed on page 125.

# ## FINDING HELP LOCALLY

The /usr/src/linux/Documentation (present only if you install the kernel source code, as explained in Chapter 15) and /usr/share/doc directories often contain more detailed and different information about a utility than man or info provides. Frequently this information is meant for people who will be compiling and modifying the utility, not just using it. These directories hold thousands of files, each containing information on a separate topic.

# ## USING THE INTERNET TO GET HELP

The Internet provides many helpful sites related to Linux. Aside from sites that offer various forms of documentation, you can enter an error message from a program you are having a problem with in a search engine such as Google (www.google.com), or its Linux-specific version at www.google.com/linux). Enclose the error message within double quotation marks to improve the quality of the results. The search will likely yield a post concerning your problem and suggestions about how to solve it.
