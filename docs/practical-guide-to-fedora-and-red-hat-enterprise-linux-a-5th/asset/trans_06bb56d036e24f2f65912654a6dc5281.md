
## 术语表

**异步事件** 指不会规律性地或与另一事件同步发生的事件。Linux 系统的信号是异步的；它们可以在任何时间发生，因为它们可以由各种非规律性事件触发。

**附件** 附加在电子邮件中，但不是电子邮件消息本身组成部分的文件。附件通常由邮件程序调用的程序（包括你的互联网浏览器）打开，因此你可能没有意识到它们并不是电子邮件消息的固有部分。

**身份验证** 对个人或进程身份的验证。在通信系统中，身份验证用于确认消息确实来自其声称的来源。Linux 系统中的身份验证方法包括 /etc/passwd 和 /etc/shadow 文件、LDAP、Kerberos 5 以及 SMB 身份验证。

**自动挂载** 一种从远程主机按需挂载目录的方式，无需将其硬编码配置到 /etc/fstab 中。也称为自动挂载（automounting）。

**避免遮挡** 指面板等对象，通常不应被窗口等其他对象覆盖。

**后门** 系统设计者或维护者故意保留的安全漏洞。创建此类漏洞的动机并不总是出于恶意；例如，某些操作系统出厂时就带有特权的账户，旨在供现场服务技术人员或供应商的维护程序员使用。

肯·汤普森（Ken Thompson）在 1983 年 ACM 图灵奖演讲中揭示，早期 UNIX 版本中存在一个后门，这可能是有史以来最狡猾的安全漏洞。C 编译器中包含代码，能够识别 login 命令何时被重新编译，并插入一段代码来识别汤普森选择的一个密码，从而让他无论是否为其创建了账户都能进入系统。

通常，这种后门可以通过从编译器源代码中移除它并重新编译编译器来消除。但为了重新编译编译器，你必须使用该编译器，因此汤普森安排编译器能够*识别它正在编译自身的一个版本*。它会向重新编译的编译器中插入代码，以便在重新编译的 login 中插入允许汤普森进入的代码，并且，当然，还有识别自身并在下一次循环中重做整个过程的代码。完成这一次操作后，他便能够使用原始源代码重新编译编译器；该漏洞在不可见的情况下自我延续，保留后门并保持激活状态，但在源代码中却没有任何*陷阱*。

有时也被称为*虫洞*（wormhole）。也称*陷阱门*（trap door）。

**后台进程** 不在前台运行的进程。作为后台进程，也被称为*分离进程*（detached process），由以安培符号（&）结尾的命令行启动。你不必等待后台进程运行完毕再向 shell 输入其他命令。如果你拥有作业控制权限，可以将后台进程移至前台，反之亦然。

**基名** 文件的名称。与路径名不同，基名不提及包含该文件的任何目录（因此不包含任何斜杠 [*/]）。例如，**hosts** 是 */etc/hosts* 的基名。

**波特率** 通信信道每秒所能传输的最大信息容量，单位为符号（状态转换或电平转换）/秒。只有在无帧或停止位的二电平调制下，波特率才与比特率（bits per second）一致。符号是通信信道的唯一状态，接收方可以将其与其他所有可能的状态区分开来。例如，在直接数字连接中，它可能是线上的两个电压电之一，或者也可能是载波的相位或频率。

波特率常被错误地用作比特率（bits per second）的同义词。

**波特率** 传输状态。通常用于测量终端或调制解调器的速度。常见的波特率范围为 110 到 38,400 波特。参见*波特率*（baud）。

**伯克利 UNIX** UNIX 操作系统的两个主要版本之一。伯克利 UNIX 由加州大学伯克利分校的计算机系统研究组开发，通常被称为 **BSD**（伯克利软件发行版）。

**BIND** 伯克利互联网域名（Berkeley Internet Name Domain）。由加州大学伯克利分校开发并分发的一种 **DNS**（见第 1079 页）服务器实现。

**BIOS** 基本输入/输出系统。在 PC 上，基于 **EEPROM**（见第 1081 页）的系统软件，提供对 peripheral 设备的最低层接口，并控制 **引导**（见第 1072 页）过程的第一阶段，该过程用于加载操作系统。BIOS 可以存储在不同类型的存储器中。存储器必须是非易失性的，以便在系统关闭时仍能记住系统设置。也称为 **BIOS ROM**。

**比特** 计算机能处理的最小信息单位。*比特* 是一个二进制数字：要么是 1，要么是 0（**开** 或 **关**）。

**位深** 等同于*色彩深度*（见第 1075 页）。

**位图显示器** 一种图形显示设备，屏幕上每个像素都由底层的零和一表示来控制。

**空白字符** 指 **空格** 或 **制表符** 字符，也称为*空白*（见第 1115 页）。在某些上下文中，**换行符** 被视为空白字符。

**块** 磁盘或磁带的一个区段（通常长度为 1,024 字节，但在某些系统上可能更短或更长），在一次操作中写入。

**块设备** 磁盘或磁带驱动器。块设备以字符块的形式存储信息。块设备由块设备文件（块特殊文件）表示。与*字符设备*（见第 1074 页）相对。

**块号** 磁盘和磁带的*块* 编号，以便 Linux 可以跟踪设备上的数据。
