# PRINTING WITH CUPS

A *printing system* handles the tasks involved in first getting a print job from an application (or the command line) through the appropriate *filters* (page 1082) and into a queue for a suitable printer and then getting it printed. While handling a job, a printing system can keep track of billing information so the proper accounts can be charged for printer use. When a printer fails, the printing system can redirect jobs to other, similar printers.
