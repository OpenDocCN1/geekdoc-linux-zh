## 使用 ANACONDA

Anaconda 在每个安装屏幕的右下角显示一个标有“Next”的按钮，在大多数屏幕上，其旁边还有一个标有“Back”的按钮。当您完成安装屏幕上的输入后，单击“Next”或按 F12；在文本安装中，按 TAB 键直到“Next”按钮高亮显示，然后按 RETURN 键。选择“Back”可返回到上一个屏幕。
