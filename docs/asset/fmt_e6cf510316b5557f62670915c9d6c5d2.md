最后一步是配置 `LILO` 使你的新内核可用。这是一个默认的 `/etc/lilo.conf`（带有 DOS 启动分区），其中包含一个为你新内核准备的 `image=` 部分。
```
boot=/dev/hda

linear
default=linux

label=linux221k
read-only
root=/dev/hda2
image=/boot/vmlinuz-2.2.16-22
label=linux
read-only
root=/dev/hda2
other=/dev/hda1
label=dos
```
# 实验答案 383

新的 `image=` 部分采用了粗体/斜体。请注意，我们获取了之前的 `image=` 部分，复制它并更改了 `image` 文件名，以匹配我们安装到 `/boot` 中的内核镜像。

`LILO` 将启动 `label` 与 `default=` 指令匹配的内核。注意，我们让它指向旧内核（以防我们的新内核中出现任何错误）。

另外注意，我们没有删除旧内核。不要太急于删除旧内核。你的新配置可能不可靠，在启动新内核后的几天甚至几周内，你可能还没有察觉问题。在必要时，始终保留一个可以启动的安全内核。

21. 使用命令安装你的新 `LILO` 更新：
```bash
# lilo -v -v
```
