
# KDE 进程和系统监控工具

从“进程列表”视图（通过窗口左上部分的选项卡选择）选择一个进程，并点击屏幕左下角的“更多信息”，即可在显示器底部显示该进程的详细信息。你可以从下拉的“视图”列表中选择三种视图来过滤显示：`All Processes`、`My Processes`，你拥有的进程或`Active Processes`，所有活跃的进程。

在显示器顶部的“编辑”命令下选择“隐藏进程”，可以显示任何隐藏进程（内核未启用普通监控工具可见的进程）。选择任何进程并使用“结束进程”将其杀死。

可以通过选择“编辑”、“更改优先级”对进程重新调整优先级（re-nice）。菜单栏中的“视图”选择还提供了内存映射。在“资源监控”选项卡中，你可以查看代表 CPU 和内存使用的移动图表（见图 8.9）。

KDE 提供了多个进程和系统监控客户端。通过右键点击任务栏并遵循菜单操作，可以将 KDE 图形化客户端集成到桌面任务栏中。

**图 8.9** 系统监控器的图表视图。它显示了 CPU 使用率、内存/交换分区率以及磁盘使用率。要查看此内容，请选择“资源监控”选项卡。

这些 KDE 监控客户端包括：

- `kdf`—系统文件表的图形化界面，显示空闲空间并允许你使用指针设备挂载和卸载文件系统。
- `ksysguard`—另一个面板小组件，以动画图表的形式提供 CPU 负载和内存使用信息。

```
redhat-config-packages—Fedora Core GUI 软件包管理器。

nice—以指定的优先级运行程序。

rpm—RPM 软件包管理器。

ps—显示所有运行进程的列表。

top—显示并管理运行中的进程。

pmbuild—构建 RPM 源包和二进制包。

uptime—告知自上次重启以来的时间和平均负载。

vmstat—提供虚拟内存统计数据。

kill—停止进程。
```
