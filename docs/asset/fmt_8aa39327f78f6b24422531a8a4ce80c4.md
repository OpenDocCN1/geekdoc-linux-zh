
# 数组

Shell 支持一维数组。元素的数量是 1024。当定义数组时，维度自动被设置为 1024。一维数组包含连接在一起的元素序列。元素可以是任何内容，你可以使用数组创建二维和三维数组。但这超出了本书的范围。

# 加载数组

数组有两种加载方式。你可以使用 `set -A` 命令定义并加载数组，也可以逐个加载元素。这里显示了这些技术：

```bash
set -A MY_ARRAY alpha beta gamma

X=0 # 初始化计数器为零

for ELEMENT in alpha beta gamma
do
  MY_ARRAY[$X]=$ELEMENT
  (( X + 1 ))
done
```

通过 0 而不是 1 来引用第一个数组元素。访问元素使用以下语法：

```bash
echo ${MY_ARRAY[0]} # 显示第一个元素
echo ${MY_ARRAY[1]} # 显示第二个元素
echo ${MY_ARRAY[2]} # 显示第三个元素
echo ${MY_ARRAY[*]} # 显示所有元素
echo ${MY_ARRAY[@]} # 显示元素的总数
```

# 测试字符串

Shell 脚本中最困难的任务之一是从命令行测试用户输入。使用正则表达式来定义字符串的 1-25 将解决问题。


## 第一部分 Shell 脚本基础

```bash
# set -x # 取消注释以调试此脚本
# set -n # 取消注释以验证语法。
# 注意：恢复注释后脚本将执行！

############
# 定义函数 ############################

test_string () {
# 此函数测试字符字符串
# 必须有一个参数 ($1)
if [[ $# != 1 ]]
then
    # 这是一个编程错误
    print "错误: 需要一个参数"
    return 1
fi

# 将 arg1 赋值给变量
STRING=$1

# 字符串测试开始
case $STRING in
  ([0-9]+).([0-9]+).([0-9]+).([0-9]+))
    # 测试 IP 地址 - 有效无效
    # 分离 "IP" 地址的整数部分
    # 并确保没有部分大于 255
    # 或者它是无效的 IP 地址。
    for i in $( $STRING | awk -F . '{print $1, $2, $3, $4}')
    do
      if (( i > 255 ))
      then
        INVALID=TRUE
      fi
    done
    case $INVALID in
      TRUE)
        print '无效的 IP 地址'
        ;;
      FALSE)
        print '合的 IP 地址'
        ;;
    esac
    ;;
  ([-0-1]))
    # 仅测试 0-1
    print '二进制或正整数'
    ;;
  ([-0-7]))
    # 仅测试 0-7
    print '八进制或正整数'
    ;;
  ([-0-9]))
    # 检查整数
    print '整数'
    ;;
  ([-0-9]))
    # 检查负整数
    print '负整数'
    ;;
  ([-0-9][.0-9]))
    # 检查正浮点数
    print '正浮点数'
    ;;
  ([-0-9][:][0-9]))
    # 检查带有 + 前缀的正浮点数
    print '正浮点数'
    ;;
  +(-([0-9][:][0-9]))
    # 检查负浮点数
    print '负浮点数'
    ;;
  ([.-0-9]))
    # 检查负浮点数
    print '负浮点数'
    ;;
  ([.+0-9]))
    # 检查正浮点数
    print '正浮点数'
    ;;
  ([-a-f]))
    # 测试十六进制或全小写字符
    print '十六进制或全小写'
    ;;
  ([-a-f][:][0-9]))
    # 测试十六进制或全小写字母数字
    print '十六进制或全小写字母数字'
    ;;
  ([-A-F]))
    # 测试十六进制或全大写字符
    print '十六进制或全大写'
    ;;
  ([-A-F][:][0-9]))
    # 测试十六进制或全大写字母数字
    print '十六进制或全大写字母数字'
    ;;
  *)
    print '无效格式'
    ;;
esac
}
```
