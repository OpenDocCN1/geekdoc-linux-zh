
**证明。** 假设在有向图 `$D$` 中，互不相交的 `u-v` 路径集合中 `u-v` 路径的最大数量为 `k`，且 `$D$` 中 `u-v` 顶点分隔集 `S` 的顶点最小数量为 `ℓ`。由于每条 `u-v` 路径都包含 `S` 中的一个顶点，且 `S` 中没有顶点位于多于一条这样的路径上，因此 `k ≤ ℓ`。剩下的工作是证明 `ℓ ≤ k`。

通过将有向图 `$D$` 中的每个顶点 `t ≠ u, v` 替换为两个新顶点 `t'` 和 `t''` 以及弧 `(t', t'')`，构造一个新的有向图 `$D'$`。假设有向图 `$D$` 中的两个顶点 `x` 和 `y` 均不是 `u` 或 `v`，即 `x, y ∉ {u, v}`。如果 `(x, y)` 是 `$D$` 中的弧，则 `(x, y)` 被替换为 `(x', y'')`。如果 `(u, x)` 是 `$D$` 中的弧，则 `(u, x)` 被替换为 `(u, x')`。如果 `(x, u)` 是 `$D$` 中的弧，则 `(x, u)` 被替换为 `(x'', u)`。如果 `(x, v)` 是 `$D$` 中的弧，则 `(x, v)` 被替换为 `(x'', v)`；而如果 `(v, x)` 是 `$D$` 中的弧，则 `(v, x)` 被替换为 `(v, x')`。下表总结了这一过程。

对于 `x, y ∈ V(D)` 且 `{x, y} ∩ {u, v} = ∅`，

| `D` 中的弧 | 被替换为 | `D'` 中的弧 |
|---|---|---|
| `(x, y)` | | `(x', y'')` |
| `(u, x)` | | `(u, x')` |
| `(x, u)` | | `(x'', u)` |
| `(x, v)` | | `(x'', v)` |
| `(v, x)` | | `(v, x')` |

图 8.11 所示的有向图 `$D$` 展示了该过程。

假设 `k'` 是有向图 `$D'$` 中两两弧不相交的 `u-v` 路径的最大数量，且 `ℓ` 是 `$D'$` 中 `u-v` 弧分隔集中弧的最小数量。根据定理 8.10，`ℓ = k'`。我们将证明 `ℓ ≤ ℓ'` 且 `k' ≤ k`，从而得到所需的不等式 `ℓ ≤ k`。

设 `A` 是 `$D'$` 中的一个 `u-v` 弧分隔集，且 `|A| = ℓ'`。因此，`A` 不包含任何形如 `(z,u)` 或 `(v,z)` 的弧，其中 `z ≠ u,v`。每个弧 `a ∈ A` 的形式要么为

`a = (u,x')`，`a = (x',x'')`，`a = (y',x')` 或 `a = (x',v)`

其中某些顶点 `x,y ∈ V(D) \ {u,v}`。无论弧 `a` 是什么，将弧 `a` 中涉及的顶点 `x` 记为 `w_a`。此外，令

`W = {w_a : a ∈ A}`，使得 `W ⊆ V(D) \ {u,v}`

且 `|W| ≤ |A| = ℓ'`。由于 `A` 是 `$D'$` 中的一个 `u-v` 弧分隔集，因此集合 `W` 是 `$D$` 中的一个 `u-v` 顶点分隔集。因此，`ℓ ≤ |W| ≤ ℓ'`，从而 `ℓ ≤ ℓ'`。

接下来，设 `P1', P2', …, Pk'` 是 `$D'$` 中 `k'` 条两两弧不相交的 `u-v` 路径。那么每条路径 `Pi'` `1 ≤ i ≤ k` 的形式为

`Pi' = (u,x1',x1'',x2',x2'', …, xr',xr'',v)`

并对应生成路径

`Pi = (u,x1,x2, …, xr,v)`。

根据有向图 `$D'$` 的构造方式以及 `P1', P2', …, Pk'` 两两弧不相交的事实，可得 `P1, P2, …, Pk` 是 `$D$` 中互不相交的 `u-v` 路径。因此，`k ≥ k'`。故 `ℓ ≤ ℓ' = k' ≤ k`，从而 `ℓ ≤ k`。

为了说明定理 8.11 的证明过程，考虑图 8.12 中的有向图 `$D$`。我们寻找 `$D$` 中互不相交的 `u-v` 路径的最大数量。虽然在这种情况下这相当容易做到，但我们构造了定理 8.11 证明中描述的有向图 `$D'$`，并确定 `$D'$` 中两两弧不相交的 `u-v` 路径的最大数量。这个数量是 2，且其中两条路径为

`P1' = (u,w',w'',z',z'',v)` 和 `P2' = (u,y',y'',x',x'',v)`。

正如定理 8.11 的证明中所描述的那样，这对应生成了路径

`P1 = (u,w,z,v)` 和 `P2 = (u,y,x,v)`，

它们构成了 `$D$` 中互不相交的 `u-v` 路径的一个最大集合。
