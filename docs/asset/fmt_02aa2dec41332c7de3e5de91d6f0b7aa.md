
此命令列出所有文件，过滤出`.txt`文件，然后只显示前5个结果。

## 生成命令行

有时你会发现自己需要在你的`Linux`服务器上执行某种非常频繁的操作。例如，假设你想删除目录树中属于特定用户的所有文件。对于大型目录树，这项任务可能是令人望而生畏的！

通常的文件删除命令`rm`（在第4章中有详细描述）没有提供搜索并删除符合特定标准的文件的选项。一个可以搜索的命令是`find`（同样在第4章中有详细描述）。该命令会显示所有符合你提供的标准的文件。如果你能将`find`的输出组合成一系列使用`rm`的命令行，那么任务就解决了。这正是`xargs`命令的用途所在。

`xargs`命令从它的标准输入构建命令。该命令的基本语法如下：

```
xargs [options] [command [initial-arguments]]
```

`command`是你想执行的命令，`initial-arguments`是你想传递给命令的参数列表。`options`是`xargs`选项；它们不会传递给命令。当你运行`xargs`时，它会为传递给标准输入的每个单词运行一次命令，并将该单词添加到命令的参数列表。如果你想向命令传递多个选项，可以将这些选项包含在引号内以保护它们。

例如，考虑删除属于特定用户的几个文件的任务。你可以通过将`find`的输出传给`xargs`，然后由`xargs`调用`rm`：

```bash
find / -user Christine | xargs -d "\n" rm
```

此命令的第一部分（`find / -user Christine`）在目录树（`/`）及其子目录下查找所有属于用户`Christine`的文件。该列表随后被传给`xargs`，`xargs`会将每个输入值添加到其各自的`rm`命令中。如果你正在遍历整个目录树，可能会出现问题；如果文件名包含空格，你需要超级用户权限，因为`xargs`默认同时使用空格和换行符作为项目分隔符。`-d "\n"`选项告诉`xargs`只使用换行符作为分隔符，从而在当前语境下避免了这个问题。（`find`命令用换行符分隔每个找到的文件名。）

在使用超级用户权限执行`rm`命令时，务必格外小心。当你将要删除的文件传递给`rm`命令时尤其如此。你可能会在无意中删除错误的文件。

在许多方面，与`xargs`类似的工具是反引号（``），它是大多数键盘上数字1键左侧的字符。反引号与单引号（''）不同，单引号位于大多数键盘上分号（;）的右侧。

反引号内的文本被视为单独命令，其结果会被替换到命令行中。例如，要删除那些用户文件，你可以输入以下命令：

```bash
rm `find ./ -user Christine`
```

反引号方案在某些情况下运行良好，但在更复杂的情况下会失效。原因是反引号包含的命令的输出会被传递给其前面的命令，就好像它在`shell`中直接输入过的一样。相比之下，当你使用`xargs`时，它会为每个输入项目运行一次你指定的命令（在这些示例中为`rm`）。此外，你无法向反引号传递诸如`-d "\n"`的选项。因此，这两个示例在很多情况下效果相同，但并非在所有情况下都是如此。

> 反引号的使用正在逐渐减少，因为反引号经常与单引号混淆。在某些`shell`中，你可以使用`$()`代替它。例如，前一个示例中使用的反引号可以更改为`rm $(find . / -user Christine)`

此命令工作效果同样好，而且更容易阅读和理解。

## 文件合并命令

第一类文本过滤命令是用于将两个或多个文件合并为一个文件的命令。该类别中三个重要的命令是`cat`、`join`和`paste`，它们根据文件中的字段或按行合并将文件连接到末尾。

### 使用 cat 合并文件

`cat`命令的名字是`concatenate`（连接）的缩写，该工具正是执行此功能：它将任意数量的文件连接到末尾并将结果发送到标准输出。通过将`cat`与输出重定向相结合，你可以快速将两个文件合并为一个：

```bash
$ cat first.txt second.txt > combined.txt
$ cat first.txt
Data from first file.
$
```

```bash
$ cat second.txt
Data from second file.
$
```

```bash
$ cat combined.txt
Data from first file.
Data from second file.
$
```

虽然`cat`正式上是一个合并文件的工具，但它也常用于向标准输出显示短文件的内容。如果你只输入一个文件名作为选项，`cat`会显示该文件。这是查看短文件的极佳方法；但对于长文件，最好使用全功能的分页器命令，如`more`或`less`。

你可以添加选项让`cat`在合并文件时对文件进行细微修改：

#### 显示行尾

如果你想查看行结束的位置，添加`-E`或`--show-ends`选项。结果是在每行的末尾显示一个美元符号（$）。

#### 编号

`-n`或`--number`选项在行的开头添加行号。`-b`或`--number-nonblank`选项类似，但它只对包含文本的行编号。

#### 压缩空行

`-s`或`--squeeze-blank`选项将一组空行压缩为一行。

#### 显示特殊字符

`-T`或`--show-tabs`选项将制表符显示为`^I`。`-v`或`--show-nonprinting`选项使用脱字符（^）和`M-`表示显示控制和其他特殊字符。

`tac`命令与`cat`类似，但它反转了输出行的顺序：

```bash
$ cat combined.txt
Data from first file.
Data from second file.
$
$ tac combined.txt
Data from second file.
Data from first file.
$
```

### 按字段连接文件

`join`命令通过匹配指定字段合并两个文件。然而，你可以使用`-t`选项指定另一个字符作为分隔符。例如，要连接两个以冒号而非空格分隔的文件，输入`join -t : file1 file2`。

默认情况下，`join`使用第一个字段作为匹配字段。你可以通过`-1`或`-2`选项指定第一个或第二个文件的字段。例如，`join -3 -2 cameras.txt lenses.txt`将`cameras.txt`中的第三字段和`lenses.txt`中的第二个字段连接起来。`-o FORMAT`为输出文件提供了更复杂的规范。你可以查询`man join`页面获取更多详情。

列表 1.1：包含数字的文件

- `Christine | 555-2397 | listed`
- `Christine | 555-516 | listed`
- `Jones | 555-729 | listed`
- `Samuel | 555-9871 | unlisted`

列表 1.2：包含状态的文件

- `555-2397 | unlisted`
- `555-516 | listed`
- `555-729 | listed`
- `555-9871 | unlisted`

`join`命令可以用于一组数据处理工具的核心。但它本身非常局限。它要求两个文件具有相同的行顺序。（可以使用`sort`命令来确保这一点。）

### 使用 paste 合并行

`paste`命令按行合并文件，并用制表符分隔每个文件的行，如下例所示（使用了列表1.1和1.2）：

```bash
$ paste listing1.txt listing1.2txt
555-2397 Beckett, Barry	555-2397 unlisted
555-516 Carter, Gertrude	555-516 listed
555-729 Jones, Theresa	555-729 listed
555-9871 Orwell, Samuel	555-9871 unlisted
```

你可以使用`paste`来合并那些没有适用于`join`使用的字段键的文件数据。当然，为了产生意义，文件的行数必须完全等同。或者，你可以将`paste`作为创建文本数据双列输出的快速方法；但如果第一列的行长度不完全均匀，第二列的对齐可能并不精确。
