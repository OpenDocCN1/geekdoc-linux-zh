自旋锁与互斥锁类似，但它们内部实现为创建临界区的最快方法，主要用于在多处理器系统上运行线程的场景。自旋锁 API 用的接口与互斥锁相似，但自旋锁没有关联属性。需要注意的是，在 Linux 下，自旋锁会持续检查自旋锁的值以获取目标值。虽然它比互斥锁更快，但代价是消耗更多的 CPU 资源。

要查看自旋锁如何在应用程序中被使用，请参阅列表 6.20。对比图 6.9 和图 6.10 将帮助你直观地了解互斥锁和自旋锁之间的区别。

最后一种同步方法我们将讨论的是屏障。屏障是一个检查点，可以用于多个线程，除非所有线程都到达了屏障，否则没有线程通过。屏障的工作原理是有一个计数器，计数器的每个值代表一个需要到达屏障的线程。每当此处计数就会减一。当计数最终变为零时，所有线程就可以通过屏障。列表 6.21 使用 `TThread` 派生类演示了如何使用屏障允许线程在特定时间到达应用程序的某一点。
