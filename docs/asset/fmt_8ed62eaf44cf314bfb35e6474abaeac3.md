### 引言

Linux 是最流行的操作系统之一。它的开发由 Linus Torvalds 于 1991 年开始。该操作系统的灵感源于 Unix，Unix 是另一个由 AT&T 实验室在 20 世纪 70 年代开发的操作系统。Unix 专是为小型计算机而设计的。在当时，“小型”计算机指的是不需要一整个带空调的大厅且花费低于百万美元的机器。后来，它们被认为是两个人就能抬起来的机器。在当时，廉价的 Unix 系统无法出现在办公室电脑等设备上，而这些设备倾向于基于 x86 平台。因此，当时还是学生的 Linux 开始实现一种运行在该平台上的类 Unix 操作系统。

### 发行版

Linux 发行版是一个软件包，由一个 Linux 内核和一组由公司或用户社区维护的应用程序组成。发行版的目标是针对特定的用途或用户群优化内核以及运行在操作系统上的应用程序。发行版通常包含用于软件安装和系统管理的特定发行版工具。这就是为什么某些发行版主要用于桌面环境，因为它们需要易于使用；而另一些发行版则主要用于服务器，以便尽可能高效地利用可用资源。

分类发行版的另一种方法是参考它们所属的发行族。Debian 发行族的发行版使用 `dpkg` 包管理器来管理运行在操作系统上的软件。可以使用包管理器安装的包由发行版社区的志愿者维护。维护者使用 `.deb` 软件包格式来指定软件如何在操作系统上安装以及默认如何进行配置。与发行版类似，“包”是软件以及相应的配置和文档的集合，这使得用户能够更容易安装、更新和使用软件。

Debian GNU/Linux 发行版是 Debian 族中最大的发行版。Debian GNU/Linux 项目由 Ian Murdock 于 1993 年启动。今天有数以千计的志愿者致力于该项目。Debian GNU/Linux 旨在提供一个非常可靠的操作系统。它还促进了 Stallman 的愿景，即尊重用户运行、研究、分发和改进软件的自由。这就是为什么它默认不提供任何专有软件。

Ubuntu 是另一个值得的基于 Debian 的发行版。Ubuntu 由 Mark Shuttleworth 及其团队于 2004 年创建，使命是为 Linux 桌面环境带来易用性并降低专业服务的成本。该发行版每六个月计划发布一次版本，每 2 年发布一次长期支持版本。

Red Hat 是由同名软件公司开发和维护的 Linux 发行版，该公司已于 2019 年被 IBM 收购。Red Hat Linux 发行版始于 1994 年，并在 2003 年更名为 Red Hat Enterprise Linux（通常称为 RHEL）。它作为一种可靠的企业级解决方案提供给公司，由 Red Hat 支持，并附带了简化在专业服务器环境中使用 Linux 的软件。其某些组件需要付费订阅或许可。CentOS 项目使用 Red Hat Enterprise Linux 的免费可用源代码并将其编译成完全免费提供的发行版，但作为回报，它不提供商业支持。

RHEL 和 CentOS 都针对服务器环境的使用进行了优化。Fedora 项目成立于 2003 年，创建了一种旨在面向桌面电脑的 Linux 发行版。红帽（Red Hat）发起并一直维护着 Fedora 发行版。Fedora 非常具有前瞻性，能够迅速采用新技术，有时被认为是未来可能引入 RHEL 的新技术的测试场。所有红帽发行版都使用 `rpm` 软件包格式。

SUSE 公司于 1992 年成立于德国，最初是一家 Unix 服务提供商。SUSE Linux 的第一个版本于 1994 年发布。多年来，SUSE Linux 以其 YaST 配置工具而广为人知。该工具允许管理员安装和配置软件及硬件，设置服务器和网络。与 RHEL 类似，SUSE 也发布了 Linux 企业版服务器（Linux Enterprise Server），这是其商业版本。该版本的发布频率较低，适用于企业和生产部署。它既可以作为服务器，也可以作为桌面环境部署，并配有特定用途的软件包。2004 年，SUSE 发布了 openSUSE 项目，为开发者和用户提供了测试和进一步开发系统的机会。openSUSE 发行版可免费下载。

多年来，业界开发了许多独立发行版。其中一些基于红帽或 Ubuntu，旨在改进系统或硬件的特定属性。还有基于特定功能构建的发行版，例如 Qubes（一个非常安全的环境）或 Kali Linux（提供一个利用软件漏洞的环境，主要供渗透测试人员使用）。最近，一些非常微小的 Linux 发行版被设计为专门运行 Docker 等 Linux 容器。还有专门为嵌入式系统组件甚至智能设备构建的发行版。

嵌入式系统是计算机硬件和软件的结合，旨在在更大的系统中实现特定功能。它们通常是其他设备的一部分，帮助控制这些设备。嵌入式系统用于汽车、医疗甚至军事领域。由于其应用广泛，人们开发了多种基于 Linux 内核的操作系统用于嵌入式系统。许多智能设备运行着基于 Linux 内核的系统。

因此，随嵌入式系统的是嵌入式软件。这种软件的目的是访问硬件并使其可用。Linux 相比任何专有嵌入式软件的主要优势包括跨厂商平台兼容性、开发性、支持以及无许可费用。两个最流行的嵌入式软件项目是 Android（主要用于各种厂商的手机）和 Raspbian（主要用于树莓派）。
