## 探索 Red Hat 软件包 (RPM)

`Red Hat` 软件包管理器是一个用于安装、升级和删除软件包的强大管理器。例如，`Mandriva` 等 `Linux` 发行版使用 `RPM`。`RPM` 允许您跟踪已安装的软件包。`RPM` 具有以下优势：

- 通过单个命令安装软件包。
- 提供在系统之间传输软件包的方便方法。
- 自动处理依赖关系。`RPM` 包含以下信息表1：

| 符号 | 描述 |
| :--- | :--- |
| `rpm -qa` | 让您查看已安装的软件包 |
| `rpm grep` | 列出包含特定单词的软件包 |
| `rpm -ivh filename` | 安装软件包 |
| `rpm -Uvh filename` | 升级已安装软件包 |
| `rpm -e` | 让您卸载软件包 |

您可以使用 `rpm -qa` 命令查看系统中已安装的软件包。执行以下步骤：

- 1. 点击 应用程序→工具→终端（图 `Fig.Linux-39`）。
- 2. 终端窗口出现。您需要进入 `root` 模式。
- 3. 输入 `root` 密码并按回车键（图 `Fig.Linux-40`）。
- 4. 在命令行中输入 `qa` 命令列出已安装的软件包（图 `Fig.Linux-41`）。
- 5. 按回车键显示已安装的软件包（图 `Fig.Linux-42`）。
