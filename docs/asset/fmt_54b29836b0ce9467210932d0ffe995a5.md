# shararchive

`/shar/vi` n: [Unix 和 Unet; `/bin/sh` archive] 一组文件的扁平化表示，其独特属性是可以通过存储在标准的 Unix shell 中来“反扁平化”（还原原始文件）；因此，shararchive 可以分发到运行中的 Unix 系统上，但需要特殊的软件包支持。shararchives 的趣味之处在于，它们通常是由 shell 脚本创建的；因此，产生归档的脚本本身是产生自解压脚本的脚本，而这些脚本本身可能又包含脚本。（shararchives 的缺点是它们是木马攻击的理想视图，而且对于不运行 Unix 的接收者来说，没有简单的 um–sharchiving 程序可用；shararchives 还可以利用任意的强大功能）。shararchives 通常也根据生成它的最常用程序的名称被称为“shar 文件”。源自 Jargon Dictionary http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# shared secret

许多人共享相同密码或查询的想法。共享密钥被广泛使用是因为它们很简单：只需要给出一个密码即可。另一方面，密钥共享得越广泛，被泄露的可能性就越大。事实上，许多人认为两个人之间共享秘密是极其危险的，正确的解决方案是使用公钥分发随机生成的密钥，该密钥仅对特定消息有效。例如：DVD 电影使用随机生成的密钥加密。然后，该密钥使用数百个密钥进行多次加密。每个 DVD 播放器都拥有一个密钥并将其嵌入设备中，从而允许播放器解密电影。（假设如果其中一个密钥泄露，可以在不触犯该密钥的情况下生成未来的电影，从而导致基于该密钥的播放器过时）。然而，并没有良好的方法来保护这些密钥，尽管它们存储在硬件中。1999 年，欧洲的学生们能够破解了其中一个密钥（Xing 软件 DVD），并证明其使用了 40 位加密，破解软件播放器中的一个密钥就允许进行已知明文攻击）。源自 Hacking-Lexicon http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
