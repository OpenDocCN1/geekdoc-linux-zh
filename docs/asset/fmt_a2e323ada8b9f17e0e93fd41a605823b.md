## `Pine`

`Pine` 是一个基于菜单的电子邮件程序。在 Unix 提示符下输入 `pine` 运行该程序。第一次调用 `Pine` 时，你会看到以下屏幕。

```
| PINE 3.87 MAIN MENU Folder: (CLOSED) 0 Messages |
欢迎使用 Pine... 一个用于网络新闻和电子邮件的程序。Pine 提供了： |
|- 使用简单的用户界面访问本地和远程邮件文件夹 |
|- 通过 MIME 标准发送文档、图形等（附件） |
| Pine 中的命令：屏幕上的最后两行告诉你当前情况下可用的命令。通常命令比两行能显示的多，因此使用 TAB 键查看其他可用命令。“O”是可选的；在使用命令前不需要命令可见（除非 Pine 使用功能键模式；此时需要 F2。）。） |
| PINE 配置：Pine 将在你的主目录下创建一个默认配置文件 `.pinerc`。你可以编辑此文件以选择各种选项。它还会创建一个“mail”子目录用于你的保存邮件文件夹。请从主菜单输入 "?" 以获取帮助。 |
| PINE 是华盛顿大学的商标。 |

输入任意字符继续：
```

从这里开始，你将看到 Pine 主菜单界面：

```
| PINE 3.87 | 主菜单 | 文件夹: INBOX 8 条消息 |
|---|---|---|
| ? | 帮助 | 使用 Pine 获取帮助 |
| C | 撰写邮件 | 编写并发送消息 |
| I | 文件夹索引 | 查看当前文件夹中的消息 |
| L | 文件夹列表 | 选择文件夹进行查看 |
| A | 地址簿 | 更新地址簿 |
| S | 设置 | 配置或更新 Pine |
| Q | 退出 | 退出 Pine 程序 |

[文件夹 "INBOX" 已打开，留有 8 条消息]
P P PrevCmd R RelNotes
O OTHER CMDS L[ListFldrs] N NextCmd K BLock
```

此屏幕在程序运行过程中处可见。在屏幕顶部，`pine` 将显示程序版本号，随后显示你当前操作的菜单选项。屏幕右上角是当前文件夹以及其中存储的消息数量。屏幕中间是此菜单的选项，底部列出了单字母命令。

### 发送邮件

- 在 `pine` 的主菜单中按 C 撰写消息。
- 在 `To:` 字段输入名称。
- (你可以使用在地址簿中设置的昵称)
- 按 `<tab>` 移动到下一步，根据需要填写其他字段（尤其是主题字段）。
- 按 `<tab>` 移动到笔记正文。
- 输入笔记文本。
- 按 X (`control-X`) 发送，然后按 Y 确认。

### 编辑你的笔记

- 单词在输入时会自动换行。
- 要插入字母、单词或句子，请移动到你想要插入的位置并输入。
- 退格键（Backspace）将删除字母。
- 空格会根据需要（在输入时）在笔记中添加空格。
- 使用 `^J` (`control-J`) 在编辑后对文本进行重新对齐。
- 按 `^T` (`control-T`) 进行拼写检查。

### 查看收到的邮件

- 在 `pine` 主菜单中按 L 列出可用文件夹。
- 按 `<tab>` 移动到 `inbox`，按 `<return>` 选择。
- 使用 `<tab>` 移动到你想要阅读的消息，按 V 查看笔记。
- 完成该笔记后，按 `<tab>` 或 N 查看下一条笔记。
- 阅读完邮件后，按 M 查看主菜单。

### 回复收到的邮件

- 在查看笔记时按 R（代表回复）。
- 在开始回复时，对提示响应 Y，则可以包含笔记的原始文本。
- 输入你对笔记的回复，按 `^X` (`control-X`) 发送笔记。

### 管理你的邮件

- 你可以从主菜单按 I 查看当前文件夹中的笔记。
- 你可以从主菜单按 L 列出并切换到其他文件夹。
- 你可以按 D 删除笔记。
- 你可以按 U 恢复已删除的笔记。
- 在阅读笔记时，你可以按 S 保存它们。
- 系统将提示你将消息保存到 `saved-messages`文件夹中。
- 该消息将被标记为从收件箱中删除。

### 创建/编辑地址簿

- 从主菜单按 A 进入 `Pine` 的地址簿选项。
- 按 A 向地址簿添加名称。
- 按照提示输入其全名（姓，名）。
- 输入一个在 `Pine` 中使用的昵称。
- 输入你的电子邮箱地址。
- 要编辑字段，使用方向键或 `tab` 并按 E。
- 你可以按 D 删除一个昵称。

## `Elm`

`Elm` 是一个基于菜单的电子邮件程序。要运行该程序，请在 Unix 提示符中输入 `elm`。第一次调用 `elm` 时，你将看到以下消息：

> 注意：此版本的 `ELM` 需要在你的主目录下使用 `.elm` 目录来存储你的 `elmrc` 和别名文件。我是否应该为你创建 `.elm` 目录并进行设置 (y/n/q)？ n

在提示处输入 Y 来设置 `elm`。随后将显示：

> 太棒了！我现在就去处理。
> 注意：
> `ELM` 需要使用一个目录来存储你的邮件文件夹。我是否应该为你创建 `/showme/cctrman/Mail` 目录 (y/n/q)？ y

在提示处输入 Y 继续设置 `elm`。完成后，它将为你显示 `elm` 主屏幕：

> 邮箱箱为 '/usr/spool/mail/cctrman' 有 0 条消息 [ELM 2.4 PL23]

你可以通过按下第一个字母使用以下任何命令；d)删除或 u)恢复邮件，m)发送消息，r)回复或 f)转发邮件，q)退出。要阅读消息，请按 `<return>`。j = 向下移动，k = 向上移动，? = 帮助。

命令：

### 发送邮件

- 从主界面按 m。
- 当系统询问 'Send the message to:' 时，输入电子地址（你可以使用用别名设置的昵称）。
- 当系统询问 'Subject of message:' 时，输入主题。
- 当询问 'Copies to:' 时，你可以包含将接收此邮件 副本的人员的电子地址或昵称。默认值是不发送副本。
- `Elm` 将调用其默认编辑器（通常是 `vi`）。输入你的消息，并以 `:wq` 结尾。
- 按 s 发送。

## 创建和修改 UNIX 磁盘文件

`SHOWME` 上流行的三个编辑器是：`pico`、`vi` 和 `x`。`Pico` 对初学者最简单，`x` 几乎与 `MIZZOU1 CMS XEDIT` 相同，而 `vi` 是 Unix 标准。

### `Pico` 编辑器参考

`Pico` 是一个简单的显示文本编辑器。命令显示在屏幕底部，通过按 `^g` (`Control-G`) 提供上下文相关的帮助。在输入字符时，它们会立即插入到文本中。使用控制键组合输入编辑命令。要开始编辑新文件，请从 `SHOWME` 提示符输入 `pico`。屏幕看起来应该像：

```
PICO 2.1                               New Buffer

^G 获取帮助    ^O 写出 ^R 读取文件 ^Y 上一页 ^K 剪切文本    ^C 当前位置

^X 退出        ^J 对齐   ^W 查找 ^V 下一页 ^U 粘贴
```
