
# 第 8 章：使用 Firefox 浏览网页

在 3.0 之前的 Firefox 版本中，任何人都可以从各自的网站下载并安装任何加载项、扩展程序或主题。在 Firefox 3.0 中，某些主题和扩展程序只有在您于 Mozilla 加载项网站（`https://addons.mozilla.org/en-US/firefox/`）注册后才可用。一方面，这很麻烦，而且不会帮助加速 Firefox 的采用；另一方面，对于 Mozilla 基金会的扩展程序/主题开发者来说，知道有多少人在使用 Firefox 以及他们实际上在使用哪些扩展程序和主题是有用的。

您可能在遇到需要您执行操作的扩展程序或主题之前不想注册，但时间没过多久。您可以通过点击任何页面右上角的“注册”链接在加载项网站注册，或者直接访问 `https://addons.mozilla.org/en-US/firefox/users/register`。在输入您的电子邮件地址、密码和少量的个人信息后，您将通过电子邮件收到确认消息。当您收到此消息时，点击消息中的链接确认您的注册即可。

注册后，Firefox 还会显示一个提供保存您的登录/密码信息的横幅。即使您通常不愿意在浏览器中保存登录/密码，在 Firefox 中保存这个似乎也无害（除非这是您到处使用的同一个密码，这通常不是个好主意）。

注册并确认账户后，您可以随时点击任何页面右上角的“登录”链接登录加载项网站。这有助于确保您可以下载并安装适用于您的 Firefox 版本的扩展程序或主题。

## 查看已安装的 Firefox 加载项、主题和角色

Firefox 用于主题/角色、扩展程序和加载项的单一对话框让您可以轻松查看 Firefox 中当前安装了哪些内容、哪些加载项当前处于启用状态以及当前正在使用哪种主题。虽然可以同时启用多个扩展程序，但一次只能使用一个主题。

要查看您正在使用的 Firefox 版本中当前安装的加载项，请从“工具”菜单中选择“加载项”命令。这将显示加载项对话框。点击“扩展程序”图标显示图 8-20 所示的窗格，该面板显示所有当前安装的扩展程序列表。此列表最初几乎是空的，但我们将在下一节解决这个问题。

**图 8-20 Firefox 中的加载项对话框**

![](img/c20d2eef7a2778ee7a3a4ec5714c4d3c_346_0.png)

> **注意：** 如果您最近安装了扩展程序或主题，将看到一个标识已安装加载项数量的黄色横幅。可以通过点击右侧的按钮关闭此横幅。

如果扩展程序处于激活状态，将显示“禁用”按钮，允许您禁用它。如果扩展程序的任何部分可以配置，将显示“偏好设置”按钮，允许您自定义扩展程序。如果禁用的扩展程序与您的版本兼容，将显示“启用”按钮。

要查看您正在使用的版本中当前安装的主题，请从“工具”菜单中选择“加载项”命令。这将显示加载项对话框。点击“主题”图标显示图 8-21 所示的面板，该面板显示所有当前安装的主题列表。与扩展程序列表一样，此列表最初几乎是空的，但我们将在下一节也解决这个问题。

**图 8-21 主题列表**

![](img/c20d2eef7a2778ee7a3a4ec5714c4d3c_347_0.png)

## 添加 Firefox 加载项、主题和角色

向 Firefox 中添加新的加载项和主题/角色很容易，因为 Firefox 会自动为您下载并安装它们——但弄清楚您最喜欢哪些很难，因为选择太多。

> **注意：** 角色在 Firefox 3.6 中实际上取代了主题，提供了一个更轻量的更改浏览器外观的模型，同时为工具栏和导航栏添加了酷的装饰。然而，在本节的其余部分，我将简单地将其称为主题，因为按钮、图标和菜单命令仍然是这样说的。

要添加扩展程序或主题，首先从“工具”菜单中选择“加载项”命令。这将显示加载项对话框，该对话框最初检索并显示尚未在您的系统上安装的推荐加载项列表，如图 8-22 所示。

![](img/c20d2eef7a2778ee7a3a4ec5714c4d3c_348_0.png)

一旦此对话框显示，您可以点击“添加到 Firefox”按钮立即安装选定的加载项，或者您可以使用对话框右上角的任何链接来浏览可用的扩展（“浏览所有插件”），或浏览由 Ubuntu 人员推荐的扩展程序列表（“获取 Ubuntu 扩展”）。首先，让我们探索来自 Mozilla Firefox 扩展程序网站提供的海量扩展程序。点击“浏览所有插件”链接将打开一个新的 Firefox 标签页，连接到 Mozilla 项目的 Firefox 总部，并显示当前所有可用扩展的页面，如图 8-23 所示。

Firefox 扩展程序页面左侧的“类别”菜单将可用的扩展程序组织为若干主题，这使得能够更容易找到与你想在 Firefox 中完成的特定任务相关的扩展程序。这些类别既包含扩展，也包含主题，尽管我稍后会讨论一个单独的“主题”类别。

![](img/c20d2eef7a2778ee7a3a4ec5714c4d3c_349_0.png)

此时，你可以继续在 Mozilla 站点浏览其他主题和扩展程序，并安装任何其他看起来有趣的程序。如果你正在安装多个扩展或主题，可以推迟重启 Firefox，直到你下载并安装了它们全部。

> **提示：** Firefox 可用的扩展程序非常多，人们很想同时下载并安装大量的扩展，看看你喜欢哪一个。我建议你控制自己，一次只安装一或两个，原因如下：首先，某些扩展程序可能与其他产生冲突，这会导致 Firefox 出现问题。其次，如果你安装了太多扩展程序，很难判断是哪一个导致了 Firefox 的哪些变化。如果你想在多台机器上安装相同的扩展集，这可能会变得困难，因为你可能会浪费时间安装你不需要或需要的扩展程序。

这些扩展程序中的某些是针对 Ubuntu 特有的（例如 Firefox Launchpad 插件，如果你正在进行开发或监控错误；如果你是意大利 Ubuntu 社区成员或通常说意大利语），而大多数是通用的（例如 Firefox 上的 AdBlock，或者如果你是开发者，Web 工具栏）。点击列表中的任何扩展程序都会在该页面的下方部分显示关于该扩展程序的摘要信息。

在安装新的并重启后，你可以为你已安装的许多扩展程序配置偏好设置。某些扩展程序（例如帮助阻止网页广告的 AdBlock 扩展）在启动时会自动显示“偏好设置”对话框，以便你提供必需的配置信息，如图 8-28 所示。
