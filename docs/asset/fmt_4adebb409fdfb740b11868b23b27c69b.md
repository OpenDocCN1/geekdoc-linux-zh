
# 内联编辑选项

通常情况下，你只需从终端设备输入每行命令并跟随一个换行符（Return或换行）。然而，如果激活了 `emacs`、`gmacs` 或 `vi` 选项，你可以编辑命令行。若要进入这些模式中的一种，你必须设置相应的选项。每当 `VISUAL` 或 `EDITOR` 变量被赋值以编辑选项名称结尾的值时，就会自动选择一个编辑选项。

编辑功能要求你的终端接受 Return 为不带换行符的 Return，并且空格可能会覆盖屏幕上的当前字符。编辑模式实现了你正在通过一个窗口查看当前行的概念。如果定义了 `COLUMNS`，则窗口宽度为该值；否则为 80 个字符。如果窗口宽度太小，无法显示提示符且为输入留出至少 8 列，则提示符将从窗口末尾截断。如果行长度大于宽度减二，则会在窗口末尾显示一个标记。光标移动并到达窗口边界；窗口将围绕光标居中。如果行延伸到窗口右侧，标记为 `>`；如果行延伸到左侧，标记为 `<`；如果行延伸到窗口的两侧，则标记为 `*`。每个编辑模式下的搜索命令提供了访问历史文件的接口。只匹配字符串，不匹配模式，在字符串开头加 `^` 限制匹配从行的第一个字符开始。

## emacs 编辑模式

你通过启用 `emacs` 或 `gmacs` 选项进入 emacs 编辑模式。这两种模式之间的区别在于它们处理 `^T` 的方式。若要编辑，将光标移动到需要修正点，然后根据需要插入或删除字符或单词。所有的编辑命令都是控制字符或转义序列。控制字符的表示法是脱字符 `^` 后跟控制字符。

例如，`^F` 是 Control-F 的表示法。通过按住 Control 键并输入 `f` 进入此键序列。不要按 Shift 键。（符号 `^` 表示 Delete 键。）

## ksh, rksh

转义序列的表示法是 `M-` 后跟一个字符。例如，通过按下 Escape (ASCII 033) 后按 `f` 来输入 `M-f`（读作 Meta f）。`M-F` 是 Escape 后按 Shift（大写 F）的键的表示法。所有编辑命令都可以在行的任何位置操作（而不是在开头）。

注意 — 除非另有说明，否则不要为编辑命令按下 Return 或换行键。

- `^F` 光标向右（右）移动一个字符。
- `M-f` 光标向前移动一个单词。emacs 编辑器认为单词是由仅由字母、数字和下划线组成的字符字符串。
- `^B` 光标向后（左）移动一个字符。
- `M-b` 光标向后移动一个单词。
- `^A` 光标移动到行首。
- `^E` 光标移动到行尾。
- `]char` 光标向前移动到当前行中的字符 `char`。
- `M-char` 光标向后移动到当前行中的字符 `char`。
- `^X` 交换光标和标记。
- `erase` 删除之前的字符。用户定义的删除字符（通常为 "H" 或 `#`）由 `stty(1)` 命令定义。
- `^D` 删除当前字符。
- `M-d` 删除当前单词。
- `M-H` (Meta-backspace) 删除上一个单词。
- `M-h` 删除上一个单词。
- `M-?` (Meta-Delete) 删除上一个单词（如果你的中断字符是 `?` (Delete，默认)，此命令无效）。
- `^T` 在 emacs 模式下将光标与下一个字符交换位置。
- `^C` 在 emacs 模式下交换前两个字符的位置。
- `M-C` 将当前字符大大写。
- `M-l` 将当前单词改为小写。
- `^K` 从光标删除到行尾。如果前面有一个数值参数且其值小于当前光标位置，则从给定位置删除到光标。如果前面有一个数值参数且其值大于当前位置，则从光标删除到给定光标位置。
- `^W` 从光标杀死到标记。
- `M-p` 将光标到标记的区域推入栈中。

### kill

删除当前整行。如果你连续输入两个 kill 字符，从那时起所有的 kill 字符都会插入一个换行符（在使用纸终端时有用）。用户定义的 kill 字符（通常为 `^G` 或 `#`）由 `stty(1)` 命令定义。

- `^Y` 从行恢复上一次删除的项。（将项 取回行）。
- `^L` 换行并打印当前行。
- `^@` (空字符) 设置标记。
- `M-space` (Meta-space) 设置标记。
- `J` (换行) 执行当前行。
- `M` (Return) 执行当前行。
- `eof` 处理文件结束字符（通常为 `^D`），仅当当前行也是文件结束时作为文件结束。

- `M-_` 等同于 `M-.`。
- `M-*` 在单词末尾添加星号并尝试文件名扩展。通过通过替换所有匹配带星号单词的文件的最长公共前缀来完成文件名扩展。如果匹配唯一，如果是目录则添加 `/`，如果不是文件则添加空格。
- `M=` 列出匹配带星号单词的文件。
- `^U` 将下一个命令的参数乘以 4。
- `\` 转义下一个字符。你可以在命令行或搜索字符串中使用它进入删除、杀死和中断（通常为 `?`）字符。\ 移除下一个字符的编辑功能（如果有）。
- `^V` 显示 shell 版本。
- `M-#` 在行首插入 `#` 并执行。此命令还会在历史文件中插入注释。

## vi 编辑模式

`vi` 有输入模式和控制模式。最初，当你输入命令时，你处于输入模式。若要编辑，按下 Escape (033) 进入控制模式，将光标移动到需要修正点，然后根据需要插入或删除字符或单词。
在大多数系统上，最初启用规范处理，如果速度大于 1200 波且包含任何控制字符，或者自提示符出现以来已超过一秒，则再次显示命令。Escape 字符终止剩余部分的规范处理，随后你可以修改命令行。这种方案结合了规范处理的优点和原始模式的预读显示。

如果还设置了 `raw` 选项，终端始终禁用规范处理。这种模式对于不支持替代换行终止符的系统是隐式的，对某些终端可能帮助。

### vi 输入编辑命令

默认编辑器处于输入模式。

- `erase` 删除字符。用户定义的删除字符（通常为 `^H` 或 `#`）由 `stty(1)` 命令定义。
- `^W` 删除空白分隔的单词。
- `^D` 终止 shell。

## ksh, rksh

`^` 转义下一个字符。在命令行或搜索字符串中，如果字符前面跟上一个 `^`，你就可以输入编辑字符以及删除或杀死字符。`^` 会移除下一个字符的编辑功能（如果有的话）。

`\` 转义下一个删除或杀死字符。

### vi 移动编辑命令

以下命令可移动光标。

- `[count]l` 将光标向前（右）移动一个字符。
- `[count]w` 将光标向前移动一个字母数字单词。
- `[count]W` 将光标移动到空白后下一个单词的开头。
- `[count]e` 将光标移动到单词末尾。
- `[count]E` 将光标移动到当前空白分隔单词的末尾。
- `[count]h` 将光标向后（左）移动一个字符。
- `[count]b` 将光标向移动一个单词。
- `[count]B` 将光标移动到上一个空白单词。
- `[count]|` 将光标移动到第 count 列。
- `[count]fc` 在当前行中查找下一个字符 c。
- `[count]Fc` 在当前行中查找上一个字符 c。
- `[count]tc` 等同于 f 后紧跟 h。
- `[count]Tc` 等同于 F 后紧跟 1。
- `[count];` 重复 count 次上一次的单字符查找命令（f, F, t, 或 T）。
- `[count],0` 反向重复 count 次上一次的单字符查找命令。
- `^` 将光标移动到行首第一个非空白字符。
- `$` 将光标移动到行尾。
- `%` 移动到匹配的 ( ), { }, [, 或 ]。如果光标不在上述任何字符上，则首先在行剩余部分搜索上述字符之一的首次出现。

### vi 搜索编辑命令

使用这些命令访问你的命令历史。

- `[count]k` 获取上一个命令。每次输入 k，都会向回溯访问上一个命令。
- `[count]-j` 获取下一个命令。每次输入 j，都会向后后访问下一个命令。
- `[count]+` 等同于 j。
- `[count]G` 获取命令计数。默认值是最近的一条历史命令。
- `/string` 在历史中向后搜索包含 string 的之前的命令。按回车或换行符结束字符串。如果字符串前面有 `^`，则匹配的行必须以 string 开头。如果 string 为空，则使用上一个字符串。
- `?string` 与 `/` 相同，但是向后搜索。
- `n` 搜索上一次 `/` 或 `?` 命令模式的下一个匹配项。
- `N` 搜索上一次 `/` 或 `?` 命令模式的下一个匹配项，但方向反向。在历史中搜索之前的 `/` 命令输入的字符串。

### vi 文本修改编辑命令

使用这些命令修改行。

- `a` 进入输入模式并在当前字符后输入文本。
- `A` 在行尾追加文本。等同于 `$a`。
- `[count]cmotion` 删除从当前字符到 motion 将光标移动到的字符之间的所有字符，并进入输入模式。如果 motion 是 c，则删除整行并进入输入模式。
- `c` 删除从当前字符到行尾并进入输入模式。等同于 `cs`。
- `[count]s` 删除当前字符并进入输入模式。
- `S` 删除整行并进入输入模式。等同于 `cc`。
- `[count]dmotion` 删除从当前字符到 d 将光标移动到的字符之间的所有字符。如果 motion 是 d，则删除整行。
- `d` 删除从当前字符到行尾。等同于 `d`。
- `i` 进入输入模式并在当前字符前插入文本。
- `I` 在行首前插入文本。等同于 `0i`。
- `[count]P` 将上一次文本修改放在光标前。
- `[count]p` 将上一次文本修改放在光标后。
- `R` 进入输入模式，并以覆盖方式用你输入的字符替换屏幕上的字符。
- `[count]rc` 将当前光标处开始的 count 个字符替换为 c，并移动光标。
- `[count]x` 删除当前字符。
- `[count]X` 删除前一个字符。
- `[count].` 重复上一次的文本修改命令。
- `[count]I` 反转当前光标位置开始的 count 个字符的大小大小写，并移动光标。
- `[count]_` 追加上一次命令的第 count 个单词并进入输入模式。如果省略 count，则使用上一个单词。
- `*` 在当前单词后附加一个星号 (*) 并尝试生成文件名。如果没有找到匹配项，则响铃。否则，将单词替换为匹配模式并进入输入模式。
- `\` 通过将当前单词替换为所有匹配（带星号后缀）的文件名的最长公共前缀来执行文件名补全。如果匹配是唯一的，如果是目录则添加 /，如果不是目录则添加空格。

### vi 其他编辑命令

- `Y` 复制当前字符到 motion 将光标移动到的字符处，并将其放入删除缓冲区。保持文本和光标不变。
- `Y` 从当前位置到行尾复制内容。等同于 `y$`。
- `u` 撤销行上的上一次文本修改命令。
- `U` 撤销行上的所有文本修改命令。
- `[count]v` 在 `VISUAL` 指定的编辑器中打开该行。如果未定义 `VISUAL`，则使用 `/vi`。

## 命令历史

从终端输入的命令保存在历史文件中。`HISTSIZE` 变量决定了保存的命令数量。默认值为 128。如果未设置 `HISTFILE` 或该文件可写，`ksh` 使用 `$HOME/.sh_history` 来存储历史。shell 可以访问使用相同 `HISTFILE` 的所有 shell 的历史。使用特殊命令 `fc` 来列出或编辑历史中分配给它的部分内容。你可以指定单个命令或命令范围。如果你没有为 `fc` 指定一个编辑器，则使用变量 `FCEDIT` 的默认值。如果 `FCEDIT` 未定义，则使用 `/bin/ed` 作为编辑器。在离开编辑器时，打印并重新执行编辑后的命令。使用编辑器名称 `-` 可以跳过编辑阶段并重新执行。在这种情况下，你可以使用 `old=new` 形式的替换参数来修改命令。例如，如果别名为 `fc -`，输入 `bad=good` 将重新执行以字母 c 开头的最新命令，并将字符串 bad 替换为字符串 good。

如果你为一个单词定义了别名，每个命令的第一个单词将被替换为别名的文本。别名由任意字符组成，但不包括元字符、引用字符、参数和替换字符以及 `=`。替换字符串可以包含任何有效的 shell 脚本，包括上述元字符。替换后的文本中每个命令的第一个单词（正在被替换的除外）将被检查别名。如果别名值的最后一个字符是空格，则也会对后续别名进行别名替换。你可以使用别名重新定义特殊的内置命令，但不能使用它们来重新定义保留字。

使用 `alias` 命令创建、列出和导出别名。使用 `unalias` 命令删除它们。导出的别名对于通过名称调用的脚本有效，但对于单独的 shell 实例必须重新初始化。为了防止递归别名中的无限循环，如果 shell 当前没有处理同名的别名，则将该单词替换为别名值；否则不替换。

别名是在读取脚本时执行的，而不是执行时。因此，为了别名生效，别名的定义必须在引用该别名的命令之前执行。别名经常用作全路径名的简写。

## 别名

如果你为一个单词定义了别名，每个命令的第一个单词将被替换为别名的文本。别名由任意字符组成，但不包括元字符、引用字符、参数和替换字符以及 `=`。替换字符串可以包含任何有效的 shell 脚本，包括上述元字符。替换后的文本中每个命令的第一个单词（正在被替换的除外）将被检查别名。如果别名值的最后一个字符是空格，则也会对后续别名进行别名替换。你可以使用别名重新定义特殊的内置命令，但不能使用它们来重新定义保留字。

使用 `alias` 命令创建、列出和导出别名。使用 `unalias` 命令删除它们。导出的别名对于通过名称调用的脚本有效，但对于单独的 shell 实例必须重新初始化。为了防止递归别名中的无限循环，如果 shell 当前没有处理同名的别名，则将该单词替换为别名值；否则不替换。

## 跟踪别名

跟踪别名（tracked alias）机制允许别名的值被自动设置为对应命令的全路径名。这些别名被称为跟踪别名。跟踪别名的值在第一次查找对应命令时定义，并在每次重置 `PATH` 变量时被定义为未定义。这些别名将保持跟踪状态，以便随后的引用能够重新定义其值。有几个跟踪别名被被编译到 shell 中。`set` 命令的 `-h` 选项会将每个被引用的命令名变为跟踪别名。以下导出的别名会被编译（并构建）到 shell 中，你可以对它们进行取消（unset）或重新定义。
```
