
- `-l` `limit` 指定输出设备的最大 own，以 512 字节块为单位。默认情况下，如果输出文件是目录或可挂载设备，`pkgmk` 使用 `def(1M)` 命令动态计算输出设备上的可用空间。此选项通常配合 `pkgtrans(1)` 使用以创建数据流格式的包。

- `-o` 如果包已存在，则覆盖该实例实例。

- `-p` `pstamp` 用 `pstamp` 覆盖 `pkginfo(4)` 文件中的生产标记定义。

- `-r` `root-path` 忽略 `prototype(4)` 文件中的目标路径。相反，使用指定的 `root-path` 并附加源路径名来定位源机器上的对象。

- `-v` `version` 用 `version` 覆盖 `pkginfo(4)` 文件中提供的版本信息。

`variable=value`

将指定的变量置于打包环境中。（变量规范的定义请参见 `prototype(4)`。）

### 操作数

- `pkginst` 按实例标识的包。实例可以是包的缩写，也可以特定的实例（例如 `inst.1` 或 `inst.2`）。你可以通过 `inst.*` 请求包的所有实例。

星号字符 (`*`) 对 shell 来说是特殊字符，可能需要进行转义。在 C shell 中，你必须用单引号 (`''`) 包围 `*`，或在它前面加上反斜杠 (`\`)。

## `pkgparam` — 显示包参数值

## 选项

## `pkgproto` — 生成用于 `pkgmk` 命令输入的原型文件条目

## 描述

`pkgproto` 命令扫描指定的路径并生成可以作为 `pkgmk(1)` 命令输入的 `prototype` 文件条目。如果在命令行上没有指定路径，则假设标准输入为路径列表。如果命令行列出的路径是目录，则将搜索该目录的内容。

## `pkgproto 1019`

默认情况下，`pkgproto` 为遇到的任何符号链接创建符号链接条目（`ftime=s`）。当使用 `-i` 选项时，`pkgproto` 为符号链接创建文件项（`ftime=f`）。您必须编辑 `prototype(4)` 文件来分配此类类型 `v`（易变的）、`e`（可编辑的）或 `x`（独占目录）。`pkgproto` 会检测已链接的文件。如果链接了多个文件，则遇到的第一个路径是链接的源。

默认情况下，`pkgproto` 将原型条目打印到标准输出中。然而，您应该将输出保存到文件中（命名为 `Prototype` 或 `prototype`），以作为 `pkgmk(1)` 命令的输入。

## 选项

- `-i` 忽略符号链接并将路径记录为 `ftype=f`（文件）或 `ftype=s`（符号链接）。
- `-c` `class` 将所有路径的类映射到 `class`。

### 操作数

- `path1` 对象所在的路径名称。
- `path2` 在输出中应替换 `path1` 的路径名称。

## 示例

以下示例展示了 `pkgproto` 的用法以及产生输出的部分列表。

```
castle$ pkgproto /bin=bin /usr/bin=usrbin /etc=etc

f none bin/sed=/bin/sh 0755 bin daemon

f none bin/sh=/bin/sh bin bin

f none bin/sort=/bin/sort 0755 bin bin

f none usrbin/sdb=/usr/bin/sdb 0775 bin bin

f none usrbin/shl=/usr/shl 4755 bin bin

d none etc/master.d 0755 root daemon

f none etc/master.d/kernel=/master.d/kernel 0644 root daemon

d none etc/rc=/etc/rc 0744 root daemon
```

```
castle$ find -type d -print | pkgproto

d none / 755 root root

d none /bin 755 bin bin

d none /usr 755 root root

d none /usr/bin 775 bin bin

d none /etc 755 root root

d none /tmp 777 root root

castle$
```
