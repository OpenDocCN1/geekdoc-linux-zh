# 前言

《黑客与渗透测试人员的 Linux 基础》是一本实操型的教程书籍，它向你教授 Linux 基础知识，并强调伦理黑客和渗透测试。本书采用 Kali Linux 发行版，教授读者如何使用 Linux 命令和软件包对系统和网络进行安全测试。

书中涵盖了文本处理、网络管理、所有权与权限、BASH 脚本、代理服务器、VPN 和无线网络。本书将帮助你准备 Web 应用程序黑客攻击和伦理实践，通过教你如何使用 Linux 命令并开始像黑客一样思考，构建你自己的黑客工具包。每一章都包含了实操练习和实际示例，以强化所涵盖的概念。

对于任何对伦理黑客和渗透测试职业感兴趣的人来说，这本书都是必读。通过强调伦理黑客实践，你不仅将学习如何攻击，还将学习如何负责任且合法地进行。本书将为你提供所需的技能和知识，在网络安全领域产生积极影响，同时保持伦理和专业素养。无论你是初学者还是经验丰富的黑客，这本书都将帮你磨练技能，成为一名熟练且合伦理的 Linux 黑客。
