
# 窗口函数

多个客户端可以在同一个窗口上进行选择。它们的事件是分开维护的。当生成事件时，会报告给所有客户端。然而，一次只有一个客户端可以选择 `SubstructureRedirectMask`、`ResizeRedirectMask` 和 `ButtonMask`。如果客户端尝试选择其中任何一个事件掩码，而另一个客户端已选择了一个，则会导致 `BadAccess` 错误。只有一个`-do-propagate-mask`用于。

`XChangeAttributes` 可能会产生 `BadAccess`, `BadColor`, `BadMatch`, `BadPixmap`, `BadValue` 和 `BadWindow`。

要将窗口的背景设置为指定的像素，使用 `XSetWindowBackground`。

```
XSetWindowBackground(display, w, background);
```

`display` 指定与 X 服务器的连接。

`w` 指定指定的窗口。

`background` 指定用于背景的像素。

要将窗口的背景设置为指定的 pixmap，使用 `XSetWindowBackgroundPixmap`。

```
XSetWindowBackgroundPixmap(display, w, background_pixmap);
```

`display` 指定与 X 服务器的连接。

`w` 指定指定的窗口。

`background_pixmap` 指定 pixmap、`ParentRelative` 或 `None`。

`XSetWindowBackgroundPixmap` 函数将窗口的背景设置为指定的 pixmap。如果没有后续的显式引用，pixmap 可以被立即释放。如果指定 `ParentRelative`，则使用父窗口的背景 pixmap；在根窗口上恢复默认背景。如果你尝试更改 `InputOnly` 窗口的背景，会导致错误。如果背景设置为 `None`，则窗口没有。

`XSetWindowBackgroundPixmap` 可能会产生 `BadMatch`, `BadPixmap` 和 `BadWindow` 错误。

要将窗口的边框设置为指定的像素，使用 `XSetWindowBorder`。

```
XSetWindowBorder(display, w, border_pixel);
```

`display` 指定与 X 服务器的连接。

`w` 指定指定的窗口。

`border_pixel` 指定调色中的项。

`XSetWindowBorder` 将窗口的边框设置为指定的像素值。如果你尝试对 `InputOnly` 窗口执行此操作，会导致 `BadMatch` 错误。

`XSetWindowBorder` 可能会产生 `BadMatch` 和 `BadWindow` 错误。

要更改并重绘窗口的边框瓷砖，使用 `XSetWindowBorderPixmap`。

```
XSetWindowBorderPixmap(display, w, border_pixmap);
```

`display` 指定与 X 服务器的连接。

`w` 指定指定的窗口。

`border_pixmap` 指定 pixmap 或 `CopyFromParent`。

`XSetWindowBorderPixmap` 函数将窗口的边框 pixmap 设置为指定的 pixmap。如果没有后续引用，pixmap 可以被立即释放。如果指定 `CopyFromParent`，则使用父窗口的边框 pixmap。如果你尝试对 `InputOnly` 窗口执行此操作，会导致 `BadMatch` 错误。

`XSetWindowBorderPixmap` 可能会产生 `BadMatch`, `BadPixmap` 和 `BadWindow` 错误。

要设置窗口的调色，使用 `XSetWindowColormap`。

```
XSetWindowColormap(display, w, colormap);
```

`display` 指定与 X 服务器的连接。

`w` 指定指定的窗口。

`colormap` 指定颜色表（`Colormap`）。

`XSetWindowColormap` 函数为指定的窗口设置指定的颜色表。颜色表必须与窗口具有相同的视觉类型，否则将导致 `BadMatch` 错误。

`XSetWindowColormap` 可能会产生 `BadColor`、`BadMatch` 和 `BadWindow` 错误。

要定义窗口中使用的哪种光标，请使用 `XDefineCursor`。

```
XDefineCursor(display, cursor);
```

- `display` 指定与 X 服务器的连接。

- `w` 指定指定的窗口。

- `cursor` 指定要显示的光标或 `None`。

如果设置了光标，当指针在窗口内时将使用该光标。如果光标为 `None`，则等同于 `XUndefineCursor`。

`XDefineCursor` 可能会产生 `BadCursor` 和 `BadWindow` 错误。

要取消给定窗口的光标定义，请使用 `XUndefineCursor`。

```
XUndefineCursor(display, w);
```

- `display` 指定与 X 服务器的连接。

- `w` 指定指定的窗口。

`XUndefineCursor` 函数会撤销该窗口之前的 `XUndefineCursor` 效果。当指针在窗口内时，现在将使用父窗口的光标。在根窗口上，将恢复默认光标。

`XUndefineCursor` 可能会产生 `BadWindow` 错误。

# 第 4 章 窗口信息函数

在将显示器连接 X 服务器并创建窗口后，你可以使用 Xlib 窗口信息函数来：

- 获取窗口信息

- 转换屏幕坐标

- 操作属性列表

- 获取并更改窗口属性

- 操作选择集

## 获取窗口信息

Xlib 提供了许多函数，可以使用它们获取窗口树信息、窗口当前属性、窗口当前几何形状或当前指针坐标。由于这些函数被窗口管理器频繁使用，它们会返回一个状态来指示窗口仍然存在。

要获取给定窗口的父窗口、子窗口列表和数量，请使用 `XQueryTree`。

```
Status XQueryTree(display, w, root_return, parent_return, children_return, nchildren_return);
```

`display` 指定与 X 服务器的连接。

`w` 指定你想获取其子窗口列表、根窗口、父窗口和子窗口数量的窗口。

`root_return` 返回根窗口。

`parent_return` 返回父窗口。

`children_return` 返回子窗口列表。

`nchildren_return` 返回子窗口的数量。

`XQueryTree` 函数返回指定窗口的根 ID、指向子窗口列表的指针（无子窗口时为 `NULL`）以及列表中子窗口的数量。子窗口按当前的堆叠顺序列出，从最底部（第一个）到最顶部（最后一个）。`XQueryTree` 在失败时返回零，成功时返回非零。当不再需要非 `NULL` 子窗口时，请使用 `XFree` 释放它。

`XQueryTree` 可能会产生 `BadWindow` 错误。

要获取给定窗口的当前属性，请使用 `XGetWindowAttributes`。

```
Status XGetWindowAttributes(display, w, window_attributes_return);
```

`display` 指定与 X 服务器的连接。

`w` 指定你想获取其当前属性的窗口。

`window_attributes_return` 在 `XWindowAttributes` 结构中返回指定的窗口属性。

`XGetWindowAttributes` 函数将指定窗口的当前属性返回到 `XWindowAttributes` 结构中。
