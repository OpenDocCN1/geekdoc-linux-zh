# 在开始之前
如果以随意的方式学习，`Linux` 可能成为一个巨大且令人敬畏的话题。因此，当你开始学习 `Linux` 时，请记住书中每一章都是建立在前章基础上的。为了确保对核心 `Linux` 概念有深入理解，请按顺序阅读章节。你应该参加当地的 `Linux` 用户组 (`LUG`)，并在互联网上寻找网站、常见、`HOWTO` 和新闻组，以扩展你对 `Linux` 的知识。
