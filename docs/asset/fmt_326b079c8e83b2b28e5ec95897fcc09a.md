# `limit`, `ulimit`, `unlimit` — 设置或获取可用系统资源的限制

## 摘要

```
/usr/bin/ulimit [-f] [blocks]

sh
ulimit [-HS][a | cdfnstv]
ulimit [-HS] [c | d | f | n | s | t | v] limit

csh
limit [-h] [resource]
unlimit [-h] [resource]

sh
ulimit [-HSacdfnstv] [limit]
```

## 描述

`/usr/bin/ulimit`

`ulimit` 命令设置或报告 shell 及其子进程写入的文件大小写入限制（任何大小的文件均可读取）。只有具有适当权限的进程才能增加限制。

### Bourne Shell

Bourne shell 内置函数 `ulimit` 用于打印或设置硬限制或软资源限制。这些限制在 `getrlimit(2)` 中描述。

如果你指定了 `ulimit`，`ulimit` 会打印指定的限制。你可以一次打印任意数量的限制。`-a` 选项打印所有限制，如下所示：

```bash
$ ulimit -a
time(seconds) unlimited
file(blocks) unlimited
data(kbytes) unlimited
stack(kbytes) 8192
coreump(blocks) unlimited
ofiles(descriptors) 64
memory(kbytes) unlimited
$
```

如果存在 `limit`，`ulimit` 将指定的限制设置为 `limit`。字符串 `unlimit` 请求最大的有效限制。你一次只能对一种资源设置限制。任何用户都可以将软限制设置为硬限制以下的任何值。任何用户都可以降低硬限制。只有超级用户才能调高硬限制；参见 `su(1)`。

`-H` 选项指定硬限制。`-S` 选项指定软限制。如果两个选项都没有指定，`ulimit` 会同时设置两个限制并打印软限制。

以下选项指定要打印或设置哪个对象的限制。如果你未指定任何选项，则将打印或设置文件大小限制。

- `-c` 最大转储文件大小（以 512 字节块计数）。
- `-d` 数据段或堆的最大大小（以 KB 为单位）。
- `-f` 最大文件大小（以 512 字节块计数）。
- `-n` 最大文件描述符。
- `-s` 最大栈大小（以 KB 为单位）。
- `-t` 最大 CPU 时间（以秒为单位）。
- `-v` 最大虚拟内存（以 KB 为单位）。

```
time(seconds) unlimited
file(blocks) 100
data(kbytes) 523256
stack(kbytes) 512
coredump(blocks) 200
ofiles(descriptors) 64
memory(kbytes) unlimited
castle%
```

# `line` — 读取单行

### 概要

`/usr/bin/line`

## 描述

`line` 命令从标准输入复制一行（包含换行符在内）并将其写入标准输出。它在文件结束时返回退出状态 1，并且始终至少打印一个换行符。它通常用于 shell 脚本中以从用户的终端读取内容。

## 示例

当你调用 `line` 命令时，它会进入换行符并等待你输入一行。当你按下回车键时，该行将回显到标准输出，例所示。

```
castle% line
This is a line
This is a line
castle%
```

## 退出状态

- `0` 成功完成。
- `>0` 输入结束。
