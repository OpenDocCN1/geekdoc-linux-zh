
当找到此类条目时，`tip` 会相应设置连接速度。如果未找到此类条目，`tip` 将 `-speed-entry` 解释为系统名，导致错误消息。

如果你省略了 `-speed-entry`，`tip` 使用 `tip0` 条目来设置连接速度。

# tip

## 使用

输入的字符通常直接传输到远程系统（远程也会进行回显）。

每当 `tip` 提示输入参数时（例如在设置文件期间），你可以使用标准的删除和杀死字符来编辑输入行。对提示输入空行或进行中断将取消对话并返回远程系统。

# 命令

作为行第一个字符的 `(-)` 被视为逃逸信号，指示 `tip` 执行某些操作。`tip` 识别以下序列：

+ `~D` 掉连接并退出（你可能仍在远程系统登录）。
+ `~c [name]` 切换目录目录。（不带参数时切换到主目录）。
+ `~!` 切换到本地系统上的交互式 `shell`。（退出 `shell` 后返回 `tip`）。
+ `~->` 将文件从本地复制到远程。
+ `~<` 从远程复制到本地。
+ `~p [from]` 将文件发送到运行 Unix 系统的远程主机。当你使用 `put` 命令时，远程系统运行命令 `cat >`，`tip` 将文件发送给它。如果你未指定目标文件，则使用文件名。此命令实际上是 `->` 命令的 Unix 系统特定版本。
+ `~t [from]` 从运行 Unix 系统的远程主机获取文件。与 `put` 命令一样，如果你未指定目标，则默认为文件名。远程主机执行命令字符串 `cat from`；通过 `echo ^A` 将文件发送给 `tip`。
+ `~|` 将远程命令的输出通过管道传输到本地进程。`shell` 处理发送给本地系统的命令字符串。
+ `~C` 将程序连接到远程系统。`shell` 处理发送给程序的命令字符串。程序继承的文件描述符 `0` 作为远程行输入，`1` 作为远程行输出，`2` 作为标准错误。
+ `~$` 将本地进程的输出通过管道传输到远程主机。`shell` 处理发送给本地系统的命令字符串。
+ `~#n` 向远程系统发送 `BREAK`。
+ `~s` 设置变量（见下文讨论）。

# 提示

- `~Z` 停止 `tip`（仅在支持作业控制的 `shell`（如 `C shell`）等）下运行时可用）。
- `~Y` 仅停止 `tip` 的“本地侧”（仅在支持作业控制的 `shell`（如 `C shell`）等）下运行时可用）；让 `tip` 的“远程侧”继续运行，即显示远程主机输出的那一侧。
- `~` 获取波浪号转义字符（tilde escapes）的摘要。

复制文件需要远程主机执行某些操作。当您使用 `->` 或 `~` 转义字符发送文件时，`tip` 会提示文件名（要传输或接收的文件）以及如果文件是从远程系统传输的，则要发送到远程系统的命令。在 `tip` 传输期间，屏幕上会持续显示传输的行数。你可以通过中断中止传输。

# 自动拨号单元

你可以使用 `tip` 通过多个自动拨号单元 `ACU` 拨打远程系统。当远程系统描述包含提供的能力 `cu`、`AC` 类型 `at` 和电话号码 `pn` 时。通常情况下，`tip` 在拨号时会显示详细信息。

取决于用于建立连接的自动拨号器类型，远程主机在连接时可能会收到垃圾字符。你不应假设在外国主机上输入的第一个字符就是呈现给它的字符。建议的做法是在建立连接后立即输入杀死字符（大多数 UNIX 系统使用 `@` 或 `Control-U` 作为初始杀死字符）。

`tip` 目前支持 `Ventel MD-212+` 和兼容 `Hayes` 的调制调器。

当 `tip` 初始化一个兼容 `Hayes` 的调制调器进行拨号时，它会将调制调器设置为自动应答。通常，在对话完成后，`tip` 会释放 `DTR`，挂起调制调器。

大多数调制调器都可以配置为当 `DTR` 释放时，它们重新初始化为预设状态。你可以使用此功能重置调制调器并禁用自动应答。

此外，可以使用 `Hayes` 命令设置电话号码，以便在拨号之前配置调制调器。例如，使用类似 `pn=S0=DT5551212` 设置 `/etc/remote` 中的所有电话号码。`S0` 会禁用自动应答。

# 远程主机描述

远程主机的描述通常位于系统级文件 `/etc/remote` 中。然而，你可以通过定义和导出 `REMOTE` `shell` 变量来维护个人的描述文件（以及电话号码）。远程文件必须对 `tip` 可读，但你可以维护一个仅你可读的描述电话号码的辅助文件。除非定义并导出 `shell` 变量 `PHONES`，否则该辅助文件为 `/etc/phones`。电话号码文件包含以下格式的行：`system-name phone-number`。

为系统找到的每个电话号码都会被尝试，直到建立连接或达到文件结束符 `EOF`。电话号码由 `0123456789-*` 组成，其中 `=` 和 `*` 表示等待第二个拨号音（取决于 `ACU`）。

# tip 内部变量

`tip` 维护了一组在正常操作中使用的变量。某些变量对普通用户是只读的（`root` 允许更改任何感兴趣的内容）。你可以使用 `~` 转义字符显示和设置变量。变量的语法参考了 `vi(1)` 和 `mail(1)`。向 `~` 转义字符提供所有参数将显示所有你可以读取的变量。或者，你可以通过在末尾附加 `?` 来请求显示特定变量。例如，`-s` 转义字符显示当前字符。

变量可以是数字 `num`、字符串 `str`、字符 `char` 或布尔值 `bool`。你通过指定它们的名称来设置布尔变量。你可以通过在名称前加 `!` 来重置它们。通过在后面添加 `=` 并设置值来设置其他类型的变量。整个赋值不能包含任何空格。你可以使用单个 `set` 命令来查询以及多个变量。

可以通过在家目录下的 `.tipprc` 文件中运行 `set` 命令（不带 `-s` 前缀）来初始化变量。`-v` 选项会显示带有 `#` 号的 `.tipprc` 文件。

最后，你必须完全指定变量名或使用缩写。以下列表详细列出了这些已知变量：

- `autify` `bool` 在脚本会话时取消不可打印字符；缩写为 `be`。如果存在 `nb` 能力，则初始将 `beautify` 设置为 `off`；否则，初始将 `beautify` 设置为 `on`。
- `baudrate` `num` 建立连接的速率；缩写为 `ba`。如果你在命令行上指定了波特率，则初始将 `baudrate` 设置为指定值；否则，如果存在 `br` 能力，则初始将 `baudrate` 设置为该能力的值；否则，将 `baudrate` 设置为 `300` 波。一旦 `tip` 启动，只有超级用户可以更改 `baudrate`。
- `beautify` `bool`
- `dialimeout` `num` 拨号电话号码时等待建立连接的时间（秒）；缩写为 `di`。初始将 `dialimeout` 设置为 `60` 秒。只有超级用户可以更改此值。
- `disconnect` `str` 设置到远程主机以断开其连接的字符串；缩写为 `di`。如果存在 `di` 能力，初始将 `disconnect` 设置为该能力的值；否则，将 `disconnect` 设置为空值。
- `echocheck` `bool` 与远程主机同步；如果存在 `ec` 能力，则初始将 `echocheck` 设置为 `on`；否则，将 `echocheck` 设置为 `off`。
- `eof` `str` 表示结束的字符串；缩写为 `oe`。如果存在 `oe` 能力，初始将 `eof` 设置为该能力的值；否则，将 `eof` 设置为空。
- `escape` `char` 远程主机上表示行结束的字符；缩写为 `pr`。如果存在 `pr` 能力，初始将 `escape` 设置为该能力的值；否则，将 `escape` 设置为空。
- `exceptions` `str` 应该被丢弃的字符集；缩写为 `ex`。如果存在 `ex` 能力，初始将 `exceptions` 设置为该能力的值；否则，设置为空。
- `force` `char` 强制传输的字符；缩写为 `fo`。如果存在 `fo` 能力，初始将 `force` 设置为 `\377`（禁用）。否则，将 `force` 设置为 `\377`（禁用）。
- `framesize` `num` 文件之间缓冲区的数据量（字节）；缩写为 `fs`。如果存在 `fs` 能力，初始将 `framesize` 设置为该能力的值；否则，将 `framesize` 设置为 `1024`。
- `halfduplex` `bool` 半双工模式；缩写为 `hd`。如果存在 `hd` 能力，初始将 `halfduplex` 设置为 `on`；否则，初始将 `halfduplex` 设置为 `off`。
- `hardwareflow` `bool` 控制；缩写为 `hf`。如果存在 `hf` 能力，初始将 `hardwareflow` 设置为 `on`；否则，初始将 `hardwareflow` 设置为 `off`。
- `host` `str` 你连接的主机名称；缩写为 `ho`。通过命令行或环境变量设置 `host`。
- `localecho` `bool` `halfduplex` 的同义词；缩写为 `le`。
- `log` `str` 用于记录拨出信息的文件。初始将 `log` 设置为 `/var/adm/aculog`。超级用户检查。
- `parity` `str` 与远程主机通信时生成和检查的校验和；缩写为 `par`。可能的值为：
    - `none` 输入时不检查校验和，输出时将校验位设置为 `0`。
    - `one` 输入时不检查校验和，输出时将校验位设置为 `1`。
    - `even` 输入检查偶校验和，输出生成偶校验和。
    - `odd` 输入检查奇校验和，输出生成奇校验和。如果存在 `pa` 能力，初始将 `parity` 设置为该能力的值；否则，将 `parity` 设置为 `none`。
- `phones` 用于查找号码的文件。如果设置了环境变量 `PHONES`，将 `phones` 设置为 `PHONES` 的值；否则，将 `phones` 设置为 `/etc/phones`。你不能在 `tip` 内部更改 `phones` 的值。
- `prompt` `char` 远程主机上行结束的字符；缩写为 `pr`。数据传输期间使用此值进行同步。文件传输期间的行数基于接收到的此字符。如果存在能力，初始将 `prompt` 设置为该能力的值；否则，将 `prompt` 设置为空。
- `raise` `bool` 大写模式；缩写为 `ra`。当启用此模式时，将所有小字母转换为大写后传输到远程系统。如果存在 `ra` 能力，初始将 `raise` 设置为 `om`；否则，初始将 `raise` 设置为 `off`。
- `raisechar` `char` 用于切换大写模式的输入字符；缩写为 `rc`。如果存在 `rc` 能力，初始将 `raisechar` 设置为该能力的值；否则，将 `raisechar` 设置为 `\377`（禁用）。
- `rawftp` `bool` 文件传输期间发送所有字符；不过滤不可打印字符，并且不转换转换为 `\r`。缩写为 `raw`。如果存在 `rw` 能力，初始将 `rawftp` 设置为 `on`；否则，初始将 `rawftp` 设置为 `off`。
- `timeout` `num` 等待响应的时间（秒）。如果存在能力，初始将 `timeout` 设置为该能力的值；否则，将 `timeout` 设置为 `60` 秒。
- `record` `str` 用于记录会话脚本的文件名；缩写为 `rec`。如果存在 `re` 能力，初始时将 `record` 设置为该能力的值；否则，将 `record` 设置为 `tip`。
- `remote` 用于查找远程系统描述的文件。如果设置了环境变量 `REMOTE`，则将 `remote` 设置为 `/etc/remote`。你无法在 `tip` 内部更改 `remote` 的值。
- `script` `bool` 会话脚本模式；缩写为 `sc`。当 `script` 开启时，将远程系统传输的所有内容都记录在 `record` 字段指定的脚本文件中。如果开启了美化开关（beauty switch），则仅在脚本文件中包含可打印的 ASCII 字符（即 `040` 到 `0177` 之间的字符）。使用变量 `exceptions` 来指示是正常美化规则异常的字符。如果存在 `sc` 能力，初始时将 `script` 设置为 `on`；否则，初始将 `script` 设置为 `off`。
- `tabexpand` `bool` 在文件传输期间将 Tab 扩展为空格字符；缩写为 `tab`。当 `tabexpand` 开启时，将每个 Tab 扩展为八个空格字符。如果存在 `tb` 能力，初始时将 `tabexpand` 设置为 `on`；否则，初始将 `tabexpand` 设置为 `off`。
- `tandem` `bool` 使用 `XON/XOFF` 流控制来限制远程主机发送数据的速率；缩写为 `ta`。如果存在 `nt` 能力，初始时将 `tandem` 设置为 `off`；否则，初始将 `tandem` 设置为 `on`。
- `verbose` `bool` 详细模式，缩写为 `verb`。当启用详细模式时，会在拨号期间打印消息，显示文件传输操作过程中当前的传输行数等信息。如果存在 `v` 能力，初始时将 `verbose` 设置为 `off`；否则，初始将 `verbose` 设置为 `on`。
- `SHELL` `str` 用于 `~` 命令的 `shell` 名称；默认值为 `/bin/sh`；否则，从环境变量中取值。
- `HOME` `str` 用于 `~` 命令的家目录；从环境变量获取默认值。
