## 收集有关系统的信息

当你使用 `sha1` 工具处理文件时，`sha1` 会根据文件生成一个数字。如果该数字与 `SHA1SUMS` 中的对应数字匹配，则下载的文件是正确的。你可以从终端模拟器运行以下命令：

```
$ grep desc-i386 SHA1SUMS ; shasum ubuntu-10.04-desktop-i386.iso
```
