
```bash
$ env
...
VENDOR=intel
MACHTYPE=i386
HOSTTYPE=i386-linux
HOST=thinkpad.home.org
```

另一方面，`bash`可能会提供这些变量或同名但定义略有不同的变量，例如

```bash
$ env
...
HOSTTYPE=i386
HOSTNAME=thinkpad.home.org
```

虽然shebang行的行为未由POSIX定义，但在使用shell编写脚本时，其用法的变体可能很有帮助。例如，如`wish`手册页中所述，你可以使用shell来帮助执行shell脚本中调用的程序，而无需硬编码程序的路径名。`wish`命令是一个窗口化Tool Command Language（`tcl`）解释器，可用于编写图形客户端。避免使用特定程序的路径名可以提高shell脚本的可移植性，因为并非每个UNIX或Linux系统中的程序都在同一位置。

例如，如果你想使用`wish`命令，你最初的冲动可能是写下

```bash
#!/usr/local/bin/wish
```

虽然这在许多其他操作系统上有效，但在Linux下该脚本会失败，因为`wish`位于`/usr/bin`目录下。然而，如果你这样编写命令行，

```bash
#!/bin/sh
exec wish "$0"
```

脚本将始终找到正确的二进制文件。

## 在Shell脚本中使用变量

在编写Linux shell脚本时，你会用到三种类型的变量：

- `环境变量`——它们是系统环境的一部分，你可以在shell程序中使用它们。可以定义新变量，其中一些变量（如`PATH`）也可以在shell程序内被修改。
- `内置变量`——这些变量（例如在命令中使用的选项，被shell解释为*位置参数*）由Linux提供。与环境变量不同，你不能修改它们。
- `用户变量`——由你在编写shell脚本时定义。你可以在shell程序中随意使用和修改它们。

Shell编程与其他编程语言的一个主要区别在于，在shell编程中，变量没有*类型*——也就是说，你不需要指定变量是数字还是字符串等。

## 给变量赋值

假设你想使用一个名为`1count`的变量来统计shell程序中循环的迭代次数。你可以按如下方式声明并初始化该变量：

| 命令 | 环境 |
| :--- | :--- |
| `1count=0` | `pdksh`和`bash` |
| `set 1count=0` | `tcsh` |

> **注意**
>
> 在`pdksh`和`bash`中，必须确保等号（`=`）前后没有空格。

要在变量中存储字符串，可以使用以下方法：

| 命令 | 环境 |
| :--- | :--- |
| `myname=Sanjiv` | `pdksh`和`bash` |
| `set myname=Sanjiv` | `tcsh` |

如果字符串没有包含空格，请使用上述变量形式。如果字符串包含嵌入的空格，可以按如下方式进行赋值：

| 命令 | 环境 |
| :--- | :--- |
| `myname="Sanjiv Guha"` | `pdksh`和`bash` |
| `set myname="Sanjiv Guha"` | `tcsh` |

## 访问变量值

你可以通过在变量名前添加`$`（美元符号）来访问变量的值。也就是说，如果变量名是`var`，你可以通过使用`$var`来访问该变量。

如果你想将`var`的值赋给变量`1count`，可以按如下方式操作：

| 命令 | 环境 |
| :--- | :--- |
| `1count=$var` | `pdksh`和`bash` |
| `set 1count=$var` | `tcsh` |

## 位置参数

可以从命令行或另一个shell脚本向你的shell程序传递选项。

这些选项由Linux作为*位置参数*提供给shell程序，它们具有系统提供的特殊名称。第一个参数存储在一个名为`1`（数字1）的变量中，可以在程序中使用`$1`访问。第二个参数存储在一个名为`2`的变量中，可以在程序中使用`$2`访问，依此类推。在调用shell程序时，可以省略一个或多个较高编号的位置参数。

在开发更高级的shell程序时，理解如何使用这些位置参数以及如何访问和使用从命令行获取的变量是必要的。

## 位置参数的简单示例

例如，如果一个shell程序`mypgm`期望有两个参数——例如名字和姓氏——你可以只用一个参数（名字）来调用该shell程序。然而，你不能用第二个参数（姓氏）单独调用它。

这里有一个名为`mypgm1`的shell程序，它只接受一个参数（一个名字）并将其显示在屏幕上：

```bash
#!/bin/sh
#Name display program
if [ $# -eq 0 ]
then
    echo "Name not provided"
else
    echo "Your name is $1"
fi
```

如果你按以下方式执行`mypgm1`，

```bash
$ bash mypgm1
```

你会得到以下输出：

```text
Name not provided
```

然而，如果你按以下方式执行mypm，

```bash
& bash mypm Sanjiv
```

你会得到以下输出：

```text
Your name is Sanjiv
```

Shell程序mypm还说明了shell编程的另一个方面：Linux内核提供给shell的内置变量。在mypm中，内置变量`$#`提供了传递给shell程序的位置参数的数量。本章的下一个主要部分将介绍更多关于处理内置变量的知识。

### 使用位置参数从命令行访问和获取变量

如果你需要使用带有管道命令且需要复杂参数的命令行，在脚本中使用位置参数可能会很有帮助。如果命令不常使用，包含位置参数的shell程序可能更方便。例如，如果你使用Fedora系统并连接了一个语音调制解调器作为应答机，你可以编写一个脚本来发出命令以检索和播放语音消息。以下行将一个保存的声音文件（`.rm`或voice-phone格式）转换并将结果管道传输到系统的音频设备：

```bash
#!/bin/sh
# play voice message in /var/spool/voice/incoming
rmtoopvf /var/spool/voice/incoming/$1 | pvfspeed -s 8000 | \
pvftobasic >/dev/audio
```

然后，可以使用此脚本（也许命名为`pmm`）轻松播放语音消息：

```bash
$ pmm name_of_message
```

包含位置参数的shell脚本通常用于自动化例行的琐碎任务，例如系统日志报告生成、文件系统检查、用户资源核算、打印机使用核算以及其他系统、网络或安全管理任务。
