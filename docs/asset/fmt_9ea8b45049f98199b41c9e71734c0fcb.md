
将自 epoch 来的秒数时间转换为 UTC 协调世界时间（又称格林威治时间）。此函数返回一个具有以下属性的 `struct_time` 对象：

| 属性 | 取值 |
| --- | --- |
| tm_year | 四位数值，例如 1998 |
| tm_mon | 1-12 |
| tm_mday | 1-31 |
| tm_hour | 0-23 |
| tm_min | 0-59 |
| tm_sec | 0-61 |
| tm_wday | 0-6 (0=周一) |
| tm_yday | 1-366 |
| tm_isdst | -1, 0, 1 |

如果夏令时（DST）生效则 `tm_isdst` 属性为 1；否则为 0；如果没有可用信息则为 -1。如果省略 `secs` 或为 `None`，则使用当前时间。为了向后兼容，返回的 `struct_time` 对象行为类似于包含 9 个元素的元组，其顺序与上述出的值相同。

### `localtime([secs])`

返回一个与 `gmtime()` 类似的 `struct_time` 对象，但对应于本地区域。如果 `secs` 省略或为 `None`，则使用当前时间。

### `mktime()`

此函数接收一个表示本地时区时间的 `struct_time` 对象（格式与 `localtime()` 返回的格式相同），并返回一个自 epoch 来的秒数的浮点数。如果输入值不是有效时间，将抛出 `OverflowError`。

### `sleep(secs)`

让当前进程睡眠 `secs` 秒。`secs` 是一个浮点数。

### `strftime(format [, tm])`

将由 `gmtime()` 或 `localtime()` 返回的 `struct_time tm` 转换为字符串（为了向后兼容，`tm` 也可以是一个表示值）。`format` 是一个其中嵌入了以下格式代码的字符串：

| 指令 | 含义 |
| --- | --- |
| %a | 语言区域缩写的星期名称 |
| %A | 语言区域完整的星期名称 |
| %b | 语言区域缩写的月份名称 |
| %B | 语言区域完整的月份名称 |
| %c | 语言区域适当的日期和时间表示 |
| %d | 十进制表示的几几 [01-31] |
| %H | 十进制表示的小时（24小时制）[00-23] |

| 指令 | 含义 |
| --- | --- |
| %I | 十进制表示的小时（12小时制）[01-12] |
| %j | 十进制表示的一年中的 [001-366] |
| %m | 十进制表示的月份 [01-12] |
| %M | 十进制表示的分钟 [00-59] |
| %p | 语言区域对应的 AM 或 PM |
| %S | 十进制表示的秒 [00-61] |
| %U | 一年中的周数 [00-53]（周日为第一天） |
| %w | 十进制表示的星期 [0-6]（0 = 周日） |
| %W | 一年中的周数（周一为第一天） |
| %x | 语言区域适当的日期表示 |
| %X | 语言区域适当的时间表示 |
| %y | 十进制表示的无世纪年份 [00-99] |
| %Y | 十进制表示的带世纪年份 |
| %Z | 时区名称（如果不存在时区则为空字符） |
| %% | 字符 % |

格式代码可以包含与在字符串上使用的 `%` 操作符相同方式的宽度和精度。如果任何字段超出范围，将抛出 `ValueError`。如果省略 `tuple`，则使用对应于当前的时间。

### `strptime(string, format)`

解析表示时间的字符串并返回由 `localtime()` 或 `gm()` 返回的 `struct_time` 对象。该格式使用与 `strftime()` 相同的参数，默认值为 `'%a %b %d %H:%M:%S %Y'`。这是 `ctime()` 函数产生的格式。如果字符串未解析，将抛出 `ValueError`。

### `time()`

返回以 UTC（协调世界时间）自 epoch 来的秒数表示当前时间。

### `tzset()`

根据 UNIX 上 `TZ` 环境变量的值重置时区设置。例如：

```
os.environ['TZ'] = 'US/Mountain'
time.tzset()
```

```
os.environ['TZ'] = 'CST+06CD,M4.1,M10.5.0'
time.tzset()
```

### 注意事项

- 当接受两位年份时，它们将根据 POSIX X/Open 标准转换为四位年份，其中值 69-99 映射到 1969-1999，值 00-68 映射到 2000-2068。
- 时间函数的精度远小于表示时间的单位可能暗示的精度。例如，操作系统每秒可能只更新时间 50–100 次。

### `winreg`

`winreg` 模块提供了 Windows 注册表的低级接口。`winreg` 在 Python 2 中被称为 `_winreg`。

#### `CloseKey(key)`

关闭已打开的键。

#### `ConnectRegistry(computer_name, key)`

返回指向另一个计算机的注册表句柄。如果 `computer_name` 为 `None`，则使用本地注册表。以下列表显示 HKEY*:

* `HKEY_CLASSES_ROOT`
* `HKEY_CURRENT_CONFIG`
* `HKEY_CURRENT_USER`
* `HKEY_DYN_DATA`
* `HKEY_LOCAL_MACHINE`
* `HKEY_PERFORMANCE_DATA`
* `HKEY_USERS`

#### `CreateKey(key, sub_key)`

创建或打开键并返回句柄。`key` 是打开的键或预定义的 HKEY_* 常量。`sub_key` 是标识要创建子键的字符串。

#### `DeleteKey(key, sub_key)`

删除子键。`key` 是打开的键或预定义的 HKEY_* 常量。`sub_key` 不得包含子键；否则将抛出 `Error`。

#### `SetValue(key, value)`

从注册键中删除命名值。`key` 是打开的键或预定义的 HKEY_* 常量。`value` 是包含要删除值的名称字符串。

#### `EnumKey(key, index)`

根据索引返回子键名称。`key` 是打开的键或预定义的 HKEY_* 常量。`index` 是要检索的整数。如果索引超出范围，将抛出 `EnvironmentError`。

#### `EnumValue(key, index)`

返回键的值。`key` 是打开的键或预定义的 HKEY_* 常量。`index` 是要检索的整数。该函数返回一个元组 `(name, data, type)`，其中 `name` 是值，`data` 是持有值的对象，`type` 是指定数据类型的整数。以下是定义的类型代码：

| 代码 | 描述 |
| --- | --- |
| REG_BINARY | 二进制数据 |
| REG_DWORD | 32 位数字 |
| REG_DWORD_LITTLE_ENDIAN | 小端 32 位数字 |
| REG_DWORD_BIG_ENDIAN | 大端格式的 32 位数字 |
| REG_EXPAND_SZ | 带有未展开环境变量引用的空终止字符串 |
| REG_LINK | Unicode 符号链接 |
| REG_MULTI_SZ | 空终止字符串的序列 |
| REG_NONE | 无定义的值类型 |
| REG_RESOURCE_LIST | 设备驱动资源列表 |
| REG_SZ | 空终止字符串 |

#### `ExpandEnvironmentStrings(#)`

展开字符串 `s` 中形式为 `%name%` 的环境变量。

#### `FlushKey(Key)`

将属性写入注册表，强制更改到磁盘。只有当应用程序绝对要求注册表数据存储在磁盘上才调用此函数。它在写入之前不返回。正常情况下没有需要使用此函数。

#### `RegLoadKey(key, sub_key, filename)`

创建一个子键并将注册信息从文件加载其中。`key` 是打开的键或预定义的 HKEY_* 常量。`sub_key` 是标识要加载子键的字符串。`filename` 是从文件中加载数据的文件名。该文件的内容必须是

通过 `SaveKey()` 函数创建，且调用进程必须具有 `SE_RESTORE_PRIVILEGE` 才能工作。如果键是由 `ConnectRegistry()` 返回的，文件名应该是相对于远程计算机的路径。
