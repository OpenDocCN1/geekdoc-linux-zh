# 8.33. Bison-3.8.2

Bison 软件包包含一个解析器生成器。

估计构建时间：2.3 SBU

所需磁盘空间：62 MB

## 8.33.1. 安装 Bison

为编译准备 Bison：

```
./configure --prefix=usr --docdir=usr/share/doc/bison-3.8.2
```

编译软件包：

```
make
```

要测试结果（约 5.5 SBU），执行：

```
make check
```

安装软件包：

```
make install
```

## 8.33.2. Bison 内容

- 安装的程序：`bison` 和 `yacc`
- 安装的库：`liby.a`
- 安装的目录：`/usr/share/bison`

# 描述

`bison` 根据一系列规则生成一个分析文本文件结构的程序；Bison 是 Yacc（另一个编译器生成器）的替代品

`yacc` `bison` 的封装器，用于那些仍然调用 `yacc` 而不是 `bison` 的程序；它带 `-y` 参数调用 `bison`

`lib` Yacc 库，包含与 Yacc 兼容的 `yyerror` 和 `main` 函数的实现；此库通常用不大，但 POSIX 要求它

# 8.34. Grep-3.11

Grep 软件包包含用于搜索文件内容的程序。

估计构建时间：0.4 SBU

所需磁盘空间：39 MB

## 8.34.1. 安装 Grep

首先，删除关于使用 grep egrep 的警告，该警告会导致某些软件包的测试失败：

```
sed -i "s/echo/#echo/" src/egrep.sh
```

为编译准备 Grep：

```
./configure --prefix=/usr
```

编译软件包：

```
make
```

要测试结果，执行：

```
make check
```

安装软件包：

```
make install
```

## 8.34.2. Grep 内容

- 安装的程序：`egrep`, `grep`

# 描述

`grep` 输出匹配扩展正则表达式的行。已过时，请使用 `grep -E`

`egrep` 输出匹配固定字符串的行。已过时，请使用 `grep -F`

`grep` 输出匹配基本正则表达式的行
