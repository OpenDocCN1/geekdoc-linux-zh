## netcat

## netude

用于 tcpdump 追踪文件的显示和编辑器。它是一个基于 GUI 的工具，允许你对 tcpdump 追踪文件中的包进行详细更改，目前它可以执行以下操作：
- 设置 IP、TCP 和 UDP 包中每个字段的值。ICMP 功能将很快完成。
- 在追踪文件中复制、移动和删除数据包。
- 分段和重组 IP 包。
- Netude 与 tcpdump 进程通信以更新熟悉的 tcp。这意味着你对本地版本 tcpdump 进行的任何更改都会反映在 Netude 中。
