## vi 中的搜索和替换

vi 中有许多搜索和替换功能。表 10-6 总结了 vi 中一些常用的搜索和替换功能。

### 表 10-6 vi 中的搜索和替换

| 命令 | 搜索和替换动作 |
| --- | --- |
| `/text` | 在文件中向前搜索 `text`。 |
| `?text` | 在文件中向后搜索 `text`。 |
| `n` | 按原始搜索相同的方向重复搜索。 |
| `N` | 按原始搜索的反方向重复搜索。 |
| `ftext` | 在当前行向前搜索 `text`。 |
| `Ftext` | 在当前行向后搜索 `text`。 |
| `ttext` | 在当前行向前搜索 `text`，并在 `text` 字符之前的一个字符处停止。 |
| `Ttext` | 在当前行向后搜索 `text`，直到 `text` 之后的字符。 |
| `:set ic` | 搜索时忽略大小写。 |
| `:set noic` | 使搜索区分大小写。 |
| `:s/oldtext/newtext` | 用 `newtext` 替换 `oldtext`。 |
| `:m,ns/oldtext/newtext` | 在第 `m` 到 `n` 行中用 `newtext` 替换 `oldtext`。 |
| `&` | 重复上一个 `:s` 命令。 |
| `:g/text1/s/text2/text3` | 找到包含 `text1` 的行，将 `text2` 替换为 `text3`。 |
| `:g/text/command` | 在所有包含 `text` 的行上运行 `command`。 |
| `:v/text/command` | 在所有不包含 `text` 的行上运行 `command`。 |

### 搜索示例

`wisdom` 文件内容：

```text
无为而为；
无为而治。
视小为大
并视少为多。
在困难尚未
容易时面对；
通过一系列小行动
完成伟大任务。
```

`"wisdom" 8 行，189 个字符`

- 输入 `/many` 向前搜索 `many`。
- 输入 `/text` 向前搜索 `text`，按 `n` 继续向前搜索。
- 输入 `?text` 向后搜索 `text`，按 `N` 向反方向重复搜索。
