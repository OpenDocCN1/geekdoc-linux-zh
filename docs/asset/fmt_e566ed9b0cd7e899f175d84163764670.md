## 自认证文件系统
`SFS` 是一种安全的、具有完全去中心化控制的全局文件系统。它从本地主机导出的 `NFS` 共享，并将其安全地传输到其他主机；`NFS` 服务不需要暴露在网上。`SFS` 的特点是密钥管理和授权分离的文件系统，具有与密钥分发的密钥撤销功能。`SFS` 需要 `NFSv3` 支持；Linux 内核版本 2.2.18、2.4.0 或更高（早期版本需要打补丁）。`SFS` 主页位于：`http://fs.Net` Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index`
