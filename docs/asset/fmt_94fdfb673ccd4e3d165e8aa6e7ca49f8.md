# `mrt`

多线程路由工具包 (BGP4+/BGP/RIP/RIPng/2) `MRT` 是一组路由和网络性能测量工具，BGP4+/BGP/RIP/RIPng/2 软件（包括 DVMRP 和 PIM-DM）使用了新颖路由架构设计方法，并结合了并行进程、多进程支持和硬件等功能。软件面向对象的模块化设计确保了实验路由协议和域间策略算法的快速添加和原型设计。您可以使用 `MRT` 和库来：

- 作为 IPv6 或 IPv4 网络连接的骨干路由软件。同时处理路由配置、路由策略和 RIB 维护等任务，并分配分析路由抖动统计数据
- 生成互联网路由的实时图形地图
- 捕获 BGP 会话并实时监控
- 记录并重放事件序列，例如路由失败 来自 Debian 3.0r0 APT

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# `MRTRG`

多路由器流量图表 来自 VERA

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

多路由器流量图表 Multi Router Traffic Grapher 是一种主要用于监控网络链路流量负载（通过使用 SNMP）的工具。`MRTRG` 生成包含 PNG 图像的 HTML 页面提供流量的实时表示。`MRTRG` 通常生成每日、每周和每年图表。除了 SNMP 监控外，`MRTRG` 还可以根据任何应用程序生成图表，允许对任何需要监控的内容生成图表（例如 CPU 和内存使用率、网页访问量等）。为了更快地收集数据，`MRTRG` 还可以连接到 `RRDtool`。更多信息请参阅 `http://www.ee.ethz.ch/~oetiker/webtools/`。`mrt-contrib` 包包含了用于形成 `mrt` 包一部分的贡献脚本和配置文件。来自 Debian 3.0r0 APT

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
