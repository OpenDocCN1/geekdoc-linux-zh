### isdnorefile
ISDN 配置文件传输。如果你想在具有特殊配置系统的 ISDN 线上发送/接收文件，请使用此包。据信在德国以外未使用（且不多）来自 Debian 3.0rt0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### isdnlog
ISDN 连接记录器记录所有 ISDN 连接，并可以计算通话费用。如果有足够的数据，它可以为特定的通话推荐合适的 ISDN 运营商。对于按离散单元计费的国家，它可以在下一个单元开始前断开线路来自 Debian 3.0rt0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### ISDNUP
ISDN 用户部分（ISDN, GSM, 移动系统），“ISDN-UP”来自 VERA http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### isdnutils
大多数 ISDN 相关包和工具。注意，对于外部 ISDN 适配器，你不需要此包或任何相关包。这仅适用于内部 ISDN 适配器。选择此包将选择最常用的命令。当前 isdnutils 版本被拆分为可选包，以便更容易精调安装内容；几乎不需要所有内容。无法自动选择所需内容。这是一个用于升级和升级的过渡包，它选择了你需要的最重要的包。升级后，此包可以安全删除。此包选择的包有：
- 基于 isdnutils 的 ISDN 工具集
- isdnpd 用于同步 PPP 的 ISDN 网络
- isdnlog 用于记录通话（以及更多）
- isdnutils–tools 用于 X ISDN 程序的工具（目前只有 xdnload 和 xmondis）
- boxserver ISDN 自动答机，服务器系统需要它们
- isdnvoxel 自动答机，isdndoc–用于提供详尽文档（基础文档包含在每个包中）；未被选择（尽管建议默认）：isnorefile 使用特殊配置协议通过 ISDN 传输文件；用于普通 ppp 守护程序的 pppcapi 插件，使用 CAPI 与 ISDN 通信。

isdnserver ISDN 自动应答机，客户端 (vbox) 来自 Debian 3.0r0 APT

## isdnutils-tools
使用 X 的 ISDN 实用程序是 ISDN 的图形化工具，包括 xmonsidn 和 xlsdnload。它们以各自的方式提供了 ISDN 线路的视觉指示，因此例如在有连接时变得一目了然。这些工具已从主 isdnn 包中分离出来，如果你不运行 X 但需要 ISDN，就不需要不必要地包含 X 库。来自 Debian 3.0r0 APT http://www.tdlp.org/LDP/Linux–Dictionary/html/index.html

## isdnboxserver
ISDN 自动应答机，客户端/服务器，你的设备就是你的应答机！消息可以远程记录，并自动发送电子邮件。此包是用于安装软件客户端（你用它听消息）和服务器（你用它记录消息）部分的助手。来自 Debian 3.0r0 APT
http://www.tdlp.org/LDP/Linux–Dictionary/html/index.html

## isdnboxclient
ISDN 自动应答机，客户端，你的设备就是你的应答机！消息可以远程记录，并自动发送电子邮件。这是软件的客户端部分，你可以用它听消息。消息记录在带有服务器部分（isdnboxserver）的服务器上；该系统可能在其他地方，只要它可以连接到网络即可。来自 Debian 3.0r0 APT http://www.tdlp.org/LDP/Linux–Dictionary/html/index.html

## isdnboxserver
ISDN 自动应答机，服务器，你的设备就是你的应答机！可以可以远程访问并自动发送电子邮件。这是软件的服务器部分。它需要安装在带有 ISDN 卡的系统上。要听录制的消息，你需要在某处安装客户端包 (isdnboxclient)，不一定在同一系统上。来自 Debian 3.0r0 APT http://www.tdlp.org/LDP/Linux–Dictionary/html/index.html
