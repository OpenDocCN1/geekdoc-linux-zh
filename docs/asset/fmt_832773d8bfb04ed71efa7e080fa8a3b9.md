
我们之所以说“几乎所有”，是因为运行 `make maintainer-clean` 命令不应删除 `configure`，即使 `configure` 可以使用 `Makefile` 中的规则重新生成。更通地说，`make maintainer-clean` 不应删除任何为了运行 `configure` 并开始构建程序所必须存在。这是唯一的例外；`maintainer-clean` 会删除其他所有可以重建的内容。

`maintainer-clean` 目标旨在供软件包的维护者使用，而非普通用户。你可能需要特殊工具来重建 `make maintainer-clean` 删除的某些文件。由于这些文件通常包含在发行包中，我们并不介意让它们难以重建。如果你发现需要再次解压整个发行包，请不要怪我们。

为了帮助用户意识到这一点，特殊 `maintainer-clean` 目标的命令以这两条开头：

> echo 此命令旨在供维护者使用；
> echo 它将删除可能需要特殊工具才能重建的文件。

## installdirs

添加一个名为 `installdirs` 的目标来创建安装文件的目录及其父目录是有用的。有一个名为 `mkinstldirs` 的脚本非常方便；你可以在 Texinfo 包中找到它。你可以使用如下规则：

```
# 确保所有安装目录（例如 $(bindir)）
# 通过创建它们来确保存在。
installdirs: mkinstldirs

$(srcdir)/mkinstldirs $(bindir) $(datadir) \
  $(libdir) $(infodir) \
  $(mandir)
```

或者，如果你希望支持 `DIR`：

```
# 确保所有安装目录（例如 $(bindir)）
# 通过创建它们来确保存在。
installdirs: mkinstldirs

$(srcdir)/mkinstldirs \
  $(DESTDIR)$(bindir) $(DESTDIR)$(datadir) \
  $(DESTDIR)$(libdir) $(DESTDIR)$(infodir) \
  $(DESTDIR)$(mandir)
```

此规则不应修改编译所在的目录。它只负责创建安装目录。

## 14.6 安装命令分类

在编写 `install` 目标时，必须将所有命令分为三类：普通命令、安装前命令和安装后命令。

普通命令将文件移动到正确的位置并设置模式。它们不能修改除所属软件包之外的任何文件。

安装前命令和安装后命令可能会修改其他文件；特别是它们可以编辑全局配置文件或数据数据库。

安装前命令通常在普通命令之前执行，安装后命令通常在普通命令之后运行。

### 144

### GNU make

已安装。这是一个安装后命令，因为它需要在安装软件包的 Info 文件的普通命令之后执行。

大多数程序都不需要预安装命令，但我们保留了这一功能以备不时之需。

要将 `install` 规则中的命令分类为这三类，请在它们之间插入类别行。类别行指定了后续命令所属的类别。

类别行由一个制表符、对特殊 Make 变量的引用以及末尾可选的注释组成。你可以使用三个变量，每个对应一个类别；变量名指定了类别。在普通执行中，类别行是无操作（no-op），因为这三个 Make 变量通常在最后定义（你不应该在 Makefile 中定义它们）。

这里是三个可能的类别行，每行都带有一个解释含义的注释：

```
$(PRE_INSTALL)   # 后续为预安装命令。
$(POST_INSTALL)  # 后续为安装后命令。
$(NORMAL_INSTALL) # 后续为普通命令。
```

如果你不在 `install` 规则的开头使用类别行，则在第一个类别行出现之前，所有命令都将被归类为普通。如果你不任何类别行，则所有命令都归类为普通。

这些是卸载的类别行：

```
$(PRE_UNINSTALL)   # 后续为预卸载命令。
$(POST_UNINSTALL)  # 后续为卸载后命令。
$(NORMAL_UNINSTALL) # 后续为普通命令。
```

通常，预卸载命令用于删除 Info 目录中的条目。

如果 `install` 或 `uninstall` 目标具有作为安装子程序的依赖项，你应该每个依赖项的命令以类别行开头，并且主目标的命令也以类别行开头。这样，无论实际运行了哪个依赖项，都能确保每个命令都放置在正确的类别中。

预安装和安装后命令不应运行以下以外的任何程序：

```
[ basename bash cat chgrp chmod chown cp dd diff echo
grep expand false fgrep getopt grep gunzip gzip
hostname install-info kill ldconfig ls msum
mkdir mkfifo mkdn mv prentv pwd rmdir sed sort tee
test true uname xargs yes
```

## 第 14 章：Makefile 约定

但安装二进制包确实需要执行预安装和安装后命令。

构建二进制包的程序通过提取预安装和安装后命令来实现。这里是提取预安装命令的一种方法：

```
make -n install -o all \
    PRE_INSTALL=pre-install \
    POST_INSTALL=post-install \
    NORMAL_INSTALL=normal-install \
| awk -f pre-install.awk
```

其中文件 `pre-install.awk` 可能包含如下：

```
$0 ~ /^\[ \t]*(normal_install|post_install)[ \t]*$/ {on = 0}
{print $0}
$0 ~ /^\t[ \t]*pre_install[ \t]*$/ {on = 1}
```

生成的预安装命令文件将作为 shell 脚本执行安装二进制包的一部分。
