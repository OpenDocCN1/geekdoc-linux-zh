## 搜索与替换

vi 具有根据搜索移动光标到特定位置的能力。它可以在单行或整个文件上执行此操作。它还可以在无需或需要确认的情况下执行文本替换。

## 行内搜索

`f` 命令搜索一行并将光标移动到指定字符的下一个出现处。例如，`fa` 命令会将光标移动到当前行内字符 `a` 的下一个位置。在行内执行字符搜索后，可以通过输入分号 `;` 重复搜索。

## 搜索整个文件

要将光标移动到单词或短语的下一个出现处，可以使用 `/` 命令。这与我们之前在 `:` 命令中学习的原理相同。当你输入 `/` 命令时，屏幕底部会出现 `/`。输入要搜索的单词或短语，然后按回车。光标将移动到包含搜索字符串的下一个位置。可以使用 `n` 使用上一次的搜索字符串重复。例如：

```
The quick brown fox jumps over the lazy dog. It was cool.

Line 2
Line 3
Line 4
Line 5
```

将光标置于文件的第一行。输入以下内容并回车：

```
/Line
```

光标将移动到第 2 行。接下来，输入 `n`，光标将移动到第 3 行。
重复 `n` 命令将光标向下移动文件，直到没有匹配项。
虽然到为止我们只使用了单词和短语作为搜索模式，但 vi 允许我们使用正则表达式，这是一种复杂文本模式的强大方法。我们将在第 19 章详细介绍正则表达式。

## 全局搜索与替换

vi 使用命令在行范围或整个文件上执行搜索替换操作（在 vi 中称为替换）。要将整个文件的单词 `line` 更改为 `line`，我们使用以下命令：

```
:s/Line/Line/g
```

## 保存我们的工作

和 vi 的其他功能一样，有几种不同的方法可以保存编辑的文件。我们已经涵盖了 `:w` 命令，但其他的可能也有帮助。在普通模式下，输入 `zz` 会保存文件并退出。同样，命令模式下将 `:w` 和 `:q` 命令合并为一个命令。`:iw` 命令还可以指定可选的文件名。例如，如果我们正在编辑 `foo.txt` 并想要保存一个名为 `fool.txt` 的版本，我们将输入：

```
:iw foo.txt
```

此命令会将文件保存为新名称，但不会更改我们正在编辑的文件。继续编辑时，我们仍然编辑 `foo.txt`。

## Bash 也支持 vi

在第 8 章中，我们查看了编辑命令行内容的各种方法。bash 使用的特定命令并不是随机的，它们的灵感来自 emacs 编辑器。这是 bash 的默认设置，但 bash 也支持 vi 风格的命令行编辑。可以通过以下命令开启：

```
me@linuxbox~$ set -o vi
```

完成后，我们就可以使用学过的 vi 风格命令了。试试吧。在提示符输入以下示例：

```
me@linuxbox~$ the quick brown fox jumps over the lazy dog
```

我们可以以前一样使用方向键移动光标，并普通方式输入字符。因为我们启动了一个新的命令行，编辑器处于插入模式，行为就像 vi 一样。要进入酷的功能，我们需要切换到普通模式。按 `ESC` 退出插入模式。在 vim 中，移动、剪切和粘贴操作像编辑文本文件一样工作。将 bash 设置为 vi 风格的命令行编辑是强化键盘技能的好方法，并减少了我们需要记忆的编辑命令。为了使其永久，我们可以在 `.bashrc` 中添加 `set -o vi` 命令。返回 emacs 风格编辑模式，输入此命令：

```
me@linuxbox~$ set -o emacs
```

该功能有很多在线教程，但请注意大多数使用的是传统的 vi 模式名称（command, insert 和 ex），而不是 vim 的名称。
