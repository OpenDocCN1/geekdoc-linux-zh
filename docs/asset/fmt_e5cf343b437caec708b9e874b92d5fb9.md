### 3.3.3 确保不接受安全的 ICMP 重定向（自动化）

**配置适用性：**
- 级别 1 - 服务器
- 级别 1 - 工作站

**描述：**
安全的 ICMP 重定向与 ICMP 重定向相同，区别在于它们来自默认网关列表。假设这些网关对你的系统来说是已知的，并且它们很可能是安全的。

**原理：**
即使是已知的网关也可能被攻击，此措施可以保护系统免受可能受攻击的网关更新路由表。

**设置：**
- `net.ipv4.conf.default.secure_redirects = 0`
- `net.ipv4.conf.all.secure_redirects = 0`

**审计：**
运行以下脚本进行验证：
- `net.ipv4.conf.default.secure_redirects = 0`

### 3.3.4 确保记录可疑数据包（自动化）

**策略适用性：**

- 级别 1 - 服务器
- 级别 1 - 工作站

**描述：**

启用此功能后，系统将带有不可路由源地址的数据包记录到内核日志中。

**原理：**

通过设置以下参数启用此功能并记录这些数据包：

- `net.ipv4.conf.all.log_martians = 1`
- `net.ipv4.conf.default.log_martians = 1`

允许管理员调查攻击者是否可能向其系统发送伪造数据包。

#### 审计

运行以下脚本检查：

- `net.ipv4.conf.all_log_martians = 1`
- `net.ipv4.conf.default.log_martians = 1`

#!/usr/bin/env bash

{
  output="" output2=""
  listfile="net.ipv4.conf.all_log_martians=1"
  net.ipv4.conf.default.log_martians=1
  searchloc="/run/sysctl.d/*.conf /etc/sysctl.d/*.conf /usr/local/sysctl.d/*.conf /usr/lib/sysctl.d/*.conf /lib/sysctl.d/*.conf /etc/sysctl.conf /etc/default/ufw && awk -F '^\s*IPT_SYSCTL=' '{print $2}' /etc/default/ufw"
  KPC() {
    krp=$(sysctl $1_kpname | awk -F '=' '{print $2}' xargs)
    listfile="$(grep -Psl "^\h=$1_kpname=\h*$1_kpvalue(.*)?" $1_searchloc)
    listfile="$(grep -s "\s$1_kpname " $1_searchloc | grep -Pv "\h=$1_kpname\b\h" | awk -F '=' '{print $1}')"
    if [ "$1_kpvalue" ]; then
      output="$output\n - $1_kpname is set to $1_kpvalue" in the running configuration"
    else
      output2="$output2\n - $1_kpname is set to $1_krp" in the running configuration"
    fi
    if [ -n "$1_listfile" ]; then
      output="$output\n - $1_kpname is set to $1_kpvalue" in $1_listfile"
    else
      output2="$output2\n - $1_kpname set to $1_kpvalue" is not set in a kernel configuration file"
    fi
    if [ -n "$1_listfile" ] && [ "$1_output2" != "$1_output2\n - $1_kpname is set incorrectly in $1_listfile" ]; then
      :
    fi
    for kpe in $1_listfile; do
      kpname=$(awk -F '=' <<< "$1_kpe")
      kpvalue=$(awk -F '=' <<< "$1_kpe")
    done
  }
  KPC
  if [ -z "$1_output2" ]; then
    echo -e "\n- Audit Result:\n ** PASS\n$output\n"

      echo -e "\n- Audit Result:\n ** FAIL\n - Reason($2) for audit failure:\n$output2\n"
