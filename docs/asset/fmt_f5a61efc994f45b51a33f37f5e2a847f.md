## ipmasq

安全地初始化 IP 伪装/防火墙。该包包含用于作为防火墙的 IP 伪装脚本。IP 伪装允许整个网络通过在另一个网络上的一个地址连接到另一个网络（互联网）。IP 伪装在其他平台上通常被称为 NAT（网络地址转换）。默认情况下，此包将系统配置为基础防火墙，具有反欺骗和路由保护。这是一个非常灵活的框架，你可以覆盖任何规则。它还允许在 ping 启用或禁用链路时控制是否重新解释规则。此包应安装在防火墙主机上，而不是防火墙后的主机上。IP 伪装需要内核编译了伪装支持（请参见特定内核的文档）。来自 Debian 3.0r

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# IPng

下一代 IP：IP 的新版本，旨在作为 IPv4 的演进步骤。它是 IPv4 的自然增量。IPng 是 IP 的一个新版本，设计用于作为 IPv4 的演进步骤。它是 IPv4 的自然增量。它可以作为软件升级程序安装在网络设备上，并与当前的 IPv4 兼容。IPng 设计用于在高性能网络（如 ATM）上良好运行，同时在低带宽网络（如无线网络）上仍然保持高效。此外，它为近期可能需要的新互联网功能提供了一个平台。来自 Linux Guide @FirstLinux `http://www.ldp.org/LDP/Linux~Dictionary/html/index.html`
