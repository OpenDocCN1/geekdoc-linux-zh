# 9.3.2 DIRB

`DIRB`²⁴³ 是一种 Web 内容扫描器，它使用字典列表通过向服务器发送请求来查找目录和页面。即使主索引页缺失，`DIRB` 也能识别 Web 服务器上有效的页面。

默认情况下，`DIRB` 会识别服务器上的目录，但也可以进行自定义以搜索特定目录，使用自定义字典、在每个请求中使用 `set cookie` 或标头等。
