
我们创建了一个名为 `ps1_old` 的新变量并将 `PS1` 的值赋值给它。我们可以通过 `echo` 命令验证字符串是否已成功复制。

```
me@linuxbox ~]$ echo ps1_old\n\u \ h \$
```

我们可以在终端会话期间任何时候通过反转过程恢复原始提示符。

```
me@linuxbox ~]$ PS1="$ps1_old"
```

现在我们已经准备好继续了，让我们看看如果提示符为空会发生什么。

```
me@linuxbox ~]$ PS1=
```

如果我们不对提示符字符串分配任何内容，我们什么都没有。完全没有提示符！提示符仍然在那里，但不显示任何内容，正如我们要求这样做的那样。因为这样看起来有些不习惯，我们将将其替换为极简的提示符。

```
PS1="\ \$ 
```

这样好多了。现在我们可以看到自己在做什么了。注意双引号内的末尾空格。这在显示提示符时提供了美元符号和光标之间的空格。

让我们在提示符中添加一个蜂铃（bell）。

```
$ PS1="\[a\]\$ "
```

现在每次显示提示符时我们都会听到“哔”的一，尽管某些系统禁用了这个“功能”。这可能会很烦恼，但如果我们执行执行运行时间很长的命令时需要通知，这可能很有用。我们注意到包含了 `\[` 和 `\` 序列。由于 ASCII 蜂铃 (a) 不会“打印”，也就是说它不会移动光标，因此我们需要告诉 bash，这样它才能正确确定提示符的长度。

接下来，让我们尝试创建一个带有主机名和时间信息的交互性提示符。

```
$ PS1=\a h \$ 
17:33 linux $
```

如果我们需要跟踪执行某些任务的时间，在提示符中添加时间将很有用。最后，我们将创建一个与原始提示符类似的新提示符。

```
17:37 linuxbox PS1="\u0h \W\$
me@linuxbox ~$
```

尝试表 13-1 中列出的其他序列，看看你能否设计出一个出色的新提示符。

## 添加颜色

大多数仿真器程序对某些非打印字符做出响应，以控制字符属性（如颜色、文本和可怕的闪烁文本）以及光标位置。我们稍后会介绍光标位置，但首先我们来看颜色。

## 终端混乱

在古代，当终端连接到远程计算机时，有多个竞争的终端品牌，它们的工作方式各不相同。它们有不同的键盘，而且解释控制信息的方式也各异。Unix 和类 Unix 系统有两个复杂的子系统来处理终端控制行为（称为 `termcap` 和 `terminfo`）。如果你在终端仿真器设置的最深处查看，你可能会发现一个关于终端仿真类型的设置。

为了让终端拥有一种某种通用语言，美国标准协会（ANSI）开发了一套标准字符来控制视频终端。旧时代的 DOS 用户会记得 `ANSI.SYS` 文件，它是用于启用这些代码解释的。

字符颜色通过在要显示的字符流中嵌入终端仿真器的 ANSI 转义码来控制。控制代码不会在显示器上“打印”；而是被终端解释为一条指令。正如我们在表 13-1 中所示，`\` 和 `]` 序列用于封装非打印字符。ANSI 转义码以八进制 `033`（由 ESC 键生成的代码）开头，后跟一个可选属性，然后是一个指令。例如，将文本设置为普通（属性 = 0）的代码如下：

```
\033[0m
```

### 表 13-2：设置文本颜色的转义序列

| 序列 | 文本颜色 | 序列 | 文本颜色 |
|---|---|---|---|
| `\033[0;30m` | 黑色 | `\033[1;30m` |  |
| `\033[0;31m` | 红色 | `\033[1;31m` | 浅红色 |
| `\033[0;32m` | 绿色 | `\033[1;32m` | 浅绿色 |
| `\033[0;33m` | 棕色 | `\033[1;33m` | 黄色 |
| `\033[0;34m` | 蓝色 | `\033[1;34m` | 浅蓝色 |
| `\033[0;35m` | 紫色 | `\033[1;35m` | 浅紫色 |
| `\033[0;36m` | 青色 | `\033[1;36m` | 浅青 |
| `\033[0;37m` | 灰色 | `\033[1;37m` | 白色 |

让我们尝试制作一个提示符（在这里显示为灰色）。我们在开头插入转义码。

```
me@linuxbox ~$ PS1="\033[0;31m\u@h
me@linuxbox ~$
```

这有效了，但注意提示符之后输入的所有文本都将以红色显示。为了修复这个问题，我们在提示符末尾添加另一个转义码，告诉终端仿真器返回之前的颜色。

```
me@linuxbox ~$ PS1="\033[0;31m\u@h\$\033[0m"
me@linuxbox ~$
```

这样好多了！还可以使用表 13-3 中列出的代码设置背景颜色。背景颜色不支持粗体属性。

### 表 13-3：背景颜色的转义序列

| 序列 | 背景颜色 | 序列 | 背景颜色 |
|---|---|---|---|
| `\033[0;40m` | 黑色 | `\033[0;44m` | 蓝色 |
| `\033[0;41m` | 红色 | `\033[0;45m` | 紫色 |
| `\033[0;42m` | 绿色 | `\033[0;46m` | 青色 |
| `\033[0;43m` | 棕色 | `\033[0;47m` | 浅灰色 |

我们可以通过对第一个代码进行简单的更改来创建一个红色背景的提示符。

```
me@linuxbox ~$ PS1="\033[0;41m\u@h\$\033[0m"
me@linuxbox ~$
```

## 移动光标

转义码可以用于定位光标。这通常用于在屏幕的不同位置提供时或其他类型的信息，例如每次绘制提示符时在顶角。表 13-4 列出了定位光标的转义码。

### 表 13-4：光标移动

| 转义码 | 操作 |
|---|---|
| `\033[1;cH` | 将光标移动到第 1 行 c 列 |
| `\033[nA` | 将光标向上移动 n 行 |
| `\033[nB` | 将光标向下移动 n 行 |
| `\033[nC` | 将光标向前移动 n 个字符 |
| `\033[nD` | 将光标向后移动 n 行 |
| `\033[2J` | 清空屏幕并将光标移动到左上角（第 0 行 0 列） |
| `\033[K` | 从光标位置清除到当前行末尾 |
| `\033[s` | 存储当前光标位置 |
| `\033[u` | 回收存储的光标位置 |

使用表 13-4 中的代码，我们将构造一个提示符，每次显示提示符时在屏幕顶部绘制一条红条，其中包含一个时钟（黄色文本渲染）。提示符的代码是这个看起来很复杂的字符串：

```
PS1="\033[0m\033[0;41m\033[K\033[1;33m\033[u\]\033[0m\u@h$"
```

### 表 13-5：复杂提示符字符串的拆解

| 序列 | 操作 |
|---|---|
| `\[` | 开始非打印字符序列。此此目的是允许 bash 正确计算可见提示符的大小。如果没有准确的计算，命令行编辑功能无法正确定位光标。 |
| `\033[s` | 存储光标位置。这是在屏幕顶部绘制完条和时钟后返回提示符位置所需的。请注意某些终端仿真器不识别此代码。 |
| `\033[0;H` | 将光标移动到左上角，即第 0 行 0 列。 |
| `\033[0;41m` | 设置背景颜色为红色。 |
| `\033[K` | 从当前光标位置（左上角）清除到行末尾。由于背景现在是红色，所以整行被清除了颜色，创建了我们的条条。 |
| `\033[1;33m` | 将文本颜色设置为黄色。 |
| `\t` | 显示当前时间。虽然这是一个“打印”元素，但我们仍然将其包含提示符的非打印部分，因为我们在计算显示的真实大小时不会计算到时钟。 |
| `\033[0m` | 关闭文本。这同时影响文本和背景。 |
| `\033[u` | 恢复之前保存的光标位置。 |
| `\0334<@h\$` | 结束非打印字符序列。 |

## 保存提示符

显然，我们不想总是输入这些长字符串，所以我们想要存储我们的提示符。我们可以通过将其添加到 `.bashrc` 来使提示符持久化。为此，请在文件中添加以下两行：

```
PS1="\033[0;0H\033[0;41m\033[1;33m\t\033[0m\033[u\]<@h\$ " 
export PS1
```

## 总结

信不信由，涉及 shell 函数和脚本的提示符还有很多可以做的，我们在这里还没有涵盖，但这是一个很好的开始。并不是每个人都有足够的兴趣更改提示符，因为默认提示符通常是可以满意的。但对于我们这些喜欢钻研的人来说，shell 提供了许多闲闲乐趣的机会。
