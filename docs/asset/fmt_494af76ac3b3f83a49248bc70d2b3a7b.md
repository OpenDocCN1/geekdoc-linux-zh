### flex

快速词法分析器（或 `flex`）是一个使用用户提供的正则表达式集合来生成词法分析器的工具。生成的应用程序随后可以用于将输入文件从字符序列分词为标记序列。生成的应用程序实际上只不过是从正则表达式集推导出的有限状态自动机。

```
<rules>
%%
<user code>
```

| name | definition |

| :--- | :--- |

| pattern | action |
