
# World Wide Web

`World Wide Web`（或简称为 `Web`）是一个在（错误地）引用“互联网”时使用的术语，它有两层含义：第一，泛指可以使用 `Gopher`、`FTP`、`telnet`、`USENET`、`WAIS` 和其他工具访问的资源。第二，（`HTTP` 服务器），通常被称为“`Web` 服务器”，即为浏览器提供页面的服务器。来自 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## www-mysql

一个用于 `MySQL` 数据库的 `WWW` 接口 `ww-mysql` 是 `MySQL` 的 `Web` 接口。`SQL` 命令可以嵌入到网页中；这些命令由 `ww-mysql` 在服务器上执行，并将结果发送到浏览器。来自 `Debian 3.0r0` `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## www-pgsql

一个用于 `PostgreSQL` 的 `WWW` 接口 `ww-pgsql` 是 `PostgreSQL` 的 `Web` 接口。`SQL` 命令可以嵌入到网页中；这些命令由 `ww-pgsql` 在服务器上执行，并将结果发送到浏览器。来自 `Debian 3.0r0` `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## wwwconfig-common

`Debian` web 配置。一个为需要 `apache` 和数据库的某些包提供的通用包。来自 `Debian 3.0r0` `http://www.tld.org/LDP/Linux-Dictionary/html`

## woffle

`World Web Explorer` 是一个具有特殊功能的简单拨号代理服务器，可以在不连接的情况下浏览 页面。

* 在线 - 稍后查看的页面缓存。
* 条件获取，仅获取更改过的页面。
* 修改页面，例如移除 `BLINK` 标签或窗口。
* 离线 - 用于下载的页面。
* 浏览器或命令行选择的页面。
* 关于页面显示日期的可选信息。缓存页面可以使用搜索引擎搜索。来自 `Debian 3.0r0` `http://www.tld.org/LDP/Linux-Dictionary/html`

## xxwin2-headers

`xxWindowsC++` GUI 工具包（头文件）`xxWindows` 是一个在多个平台上提供 GUI（图形界面）和其他设施的 `C++` 类。`2.2` 版本支持 `GTK+`、`Motif` 和 `MS Windows`。此包提供了使用 `xxWindows` 工具包所需的常用头文件。来自 `Debian 3.0r0` `APT` `http://www.tld.org/LDP/Linux-Dictionary/html`

## wyg

## WYSIWYG

形容词。描述“所见即所得”的界面；是 `WYSIWYG` 的变体。点击式界面入门容易，但缺乏深度；它们经常会让习惯于命令式界面的用户感到沮丧。当这种情况发生时，沮丧的用户就面临 `WYSIWYG` 问题。`WYSIWYG` 主要用于：编辑器、文字处理器和文档格式程序。例如，`WYSIWYG` “桌面出版”程序在创建包含大量字体和图形的小型文档（尤其是事报和幻灯片）方面具有明显优势。然而，在排版书籍稿时，规模改变了任务的性质；人们很快就会遇到 `WYSIWYG` 的局限性，命令行驱动的战斗性 `TeX` 或 `Unix` 的强大灵活性不再是理想选择，而是必须。对比 `YAFIGI`。来自术语字典 `http://www.tld.org/LDP/Linux-Dictionary/html`

## WYSIWYG

`wiz/ee-wig/` 形容词。[追溯自 1970 年左右菲利普·威尔逊在剧中的角色“Geraldine”] 描述一种“所见即所得”（What You See Is What You Get）的用户界面，与之相对的是使用较模糊且不会产生视觉反馈的命令的界面。在支持多种字体或图形的环境中，真正的 `WYSIWYG` 是一个难以实现的理想；该术语有多种变体来表达现实世界中的体现，包括 `WYAW`（所见即几乎是所所得）和 `WYSIMOLWYG`（所见即大致是所所得）。这些词都可能带有轻微的贬义，因为它们通常被用来指代针对非程序员的傻化用户友好界面；一个黑客拥有最早的 `WYSIWYG` 编辑器之一，用 `WYSIWYG` 替换（实际上最初是叠加）已经进入了《牛津英语字典》（`OED`），尽管目前还是小写形式。--`ESR` 源自《术语字典》

另一方面，`WYSIAYG`。基于命令的 `TECO`。另见 `WIMP` 环境。[足够奇怪的，`WYSIWYG`]`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## wzip

有损压缩与去噪。`wzip` 程序是 `LOSSY` 数据压缩的预处理器。它将一组 `ascii` 浮点数转换为一组小整数，准备好使用 `gzip` 等工具进行有效压缩。该程序还可用于对测量数据进行有效但耗时的去噪。`wzip` 最初是为处理 `EDX--`线扫描数据而编写的。来自 `Debian 3.0r` `APT` `http://www.tld.org/LDP/linux-Dictionary/html/index.html`

## X Toolkit

`X Toolkit` (`libXt`) 是一个一直随 `X` 一起的库。与今天的标准相比，它是非常粗糙的。它不具备 `3D`（阴影）小部件，尽管它是随 `X` 附带。优秀的 `Motif` 是一个 `X Toolkit` 应用，它实际上被用于制作演示中的图表。`Motif` (`libM`) 是一个现代、全功能的小部件库，已成为行业标准。`Motif` 是昂贵的专有库。`Tk`（读作 `tee–key`）是一个主要用于 `Tcl` 脚本语言的库。它可能是第一个平台无关的库（运行在 `Windows`、`IX UNIX`、`Apple Mac` 上）。然而，它运行缓慢且功能有限（正在不断改进）。`Tk` 和 `Motif` 看起来都不优雅。`1996` 年左右，我们看到许多不同许可证、扩展和图表的小部件库涌现，`xforms` 浮现在脑海。那时我开始编写窗口编程小部件。当时`UNIX` 缺乏一种高效、多用途、免费且优雅的小部件库。这种局面一直存在并阻碍了自由软件的发展。源自 `Ruite–Users–Guide`

`http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`
