### 主 DNS

# 第 4 章：获取 Red Hat Linux

Linux 和 Windows 文件系统之间的另一个主要区别是，Linux 要求你显式挂载文件系统，而 Windows 则是自动完成的。显式挂载文件系统并没有听起来那么麻烦。Red Hat Linux 安装了工具，可以在需要时自动检测并挂载文件系统。例如，默认的 Red Hat Linux 配置会在你向驱动器插入 DVD 或 CD-ROM 时自动挂载。
