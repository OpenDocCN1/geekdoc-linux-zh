
```
readonly first
```

#### B) export

什么是 Shell 脚本文件？

在赋予脚本文件必要的执行权限（通常称为 root 权限）并运行脚本文件后，计算机将从上到下执行脚本文件中的命令。运行时，它可以根据指令查看其他 shell 文件或程序。Shell 文件是定义工作操作的一种简单且推荐的方法。

与在命令行手动执行系统命令相比，脚本文件的优点是一旦编写，脚本中的所有命令都可以自动完成（效率更高）。而且，同一个脚本文件可以反复调用和执行，避免了不必要的手动重复输入。

以下是命令：

```
root@server : vim sample.sh
// 这将会创建一个 shell 文件
```

### 脚本文件的编写格式要求有哪些？

首先，脚本文件的第一行需要 shebang (`#!`) 符号，它用于指定脚本的解释器，例如 `#!/bin/bash`、`#!/bin/sh`、`#!/usr/bin/env python`。

这一行由 `#` 注释，因此它不会作为命令执行，但计算机通过这一注释信息知道应该使用哪个解释器来解释整个脚本文件中所有有效代码（在此例中解释器是 `/bin/bash`）。

其次，脚本文件使用 `#` 或 `<<` 符号来实现单行或多行注释。需要理解的是，注释的关键字或代码不会被执行，注释是给人类看的！

通过阅读注释，我们可以快速理解脚本文件的功能、版本和作者联系信息。核心功能是解释脚本文件或代码块的功能。最后，最重要的内容是代码部分。

通常情况下，一行代码就是一个命令，脚本文件中所有有效代码命令都是从上到下执行的。

让我们编写第一个脚本文件，并看看脚本文件的组成。

```
#!/bin/bash
<< COMMENT

> 这是一个注释
( 大多是多行的)
为 Linux Hackers 编写
COMMENT
### 现在我们将展示一个 echo 命令
echo "This is an example program"
```

注意，`<<` 符号后面的关键字可以是任何字符串，但在结束注释时必须使用相同的关键字。如果你从 `<< ABC` 开始注释，那么在结束注释信息时也必须使用 `ABC`（字母大小写敏感）。

在本章的下一节中，我们将简要讨论 shell 或确切说是任何脚本文件的各种执行模式。

### 脚本文件的各种执行模式

写完脚本文件后，下一步是执行它。执行脚本文件有多种方法，包括需要执行权限的、不需要权限的、打开子进程的以及不打开子进程的。我们将通过示例解释这些每种情况。

- 1) 如果脚本文件本身没有执行权限

在这种情况下，无法直接执行默认脚本，但可以使用 `bash` 或 `sh` 等解释器将脚本文件作为参数（读取脚本文件的内容）来执行脚本。

以下是命令：

```
root@server : ./sample.sh
// 将显示错误，因为没有权限
root@server : bash sample.sh
root@server : sh sample.sh
 其他 其他执行方式但不会报错
```

从上述三个命令的输出信息中，我们可以看到在没有执行权限的情况下执行当前目录下的 `sample.sh` 脚本时，会出现错误信息；而使用 `bash` 和 `sh` 作为参数执行 `sample.sh` 脚本，将显示正确的输出信息 "This is a sample"。

- 2) 如果脚本文件具有执行权限

可以通过 `chmod` 命令为脚本文件分配执行权限。一旦脚本文件拥有执行权限，就可以使用绝对路径或相对路径执行它。

以下示例假设脚本文件的绝对路径为 `/root/sample.sh`，执行脚本的效果如下。

以下是命令：

```
root@server : chmod +x sample.sh
// 这将赋予执行权限
root@server : ./sample.sh
// 将显示输出且不会报错
```

- 3) 如何打开子进程进行执行

关于决定是否打开子进程，我们首先需要理解什么是子进程。通常，我们可以通过 `ptree` 命令查看进程树来理解进程之间的关系。

以下是命令：

```
root@sample : pstree
```

从上述命令输出中，我们可以看到计算机启动的第一个进程是 `systemd`，在该进程下启动了 N 个子进程，例如 `NetworkManager`、`atd`、`chronyd` 和 `sshd`，它们都是 `systemd` 的子进程。在 `sshd` 进程下，有两个 `sshd` 子进程。在这两个 `sshd` 子进程下，启动了 `bash` 解释器子进程，并在其中一个 `bash` 进程执行了 `pstree` 命令。

你的系统可能有其他不同的子进程。你只需要使用 `ptree` 命令进行验证。正如我们刚刚所说的，无论是直接执行脚本还是使用 `bash` 或 `sh` 等解释器执行，都会启动子进程。

下面的示例通过脚本文件演示了效果。

首先，打开命令行终端，在终端中编写脚本文件并执行它。然后打开另一个命令行终端，在该终端中通过 `ptree` 命令观察进程树。

以下是命令：

```
// sleep.sh
#!/bin/bash
Sleep 5000
root@server :chmod +x sleep.sh
root@server :./sleep.sh
root@server : pstree
```

从输出可以看出，`bash` 终端下打开了一个子进程脚本文件，并通过脚本执行了 `sleep` 命令。回到第一个终端，使用 `Ctrl+C` 终止之前的脚本文件，然后再次使用 `bash` 命令执行。

```
root@server : bash sleep.sh
```

最后，在第二个终端上运行 `ptree` 命令以观察结果。结果相似，在 `bash` 进程下打开了一个子进程。

- 4) 不带子进程的执行模式

接下来，让我们看看无子进程的执行模式。

与之前的实验类似，我们需要打开两个命令行终端。首先打开第一个终端，这次使用 `source` 或 `.` (点) 命令执行脚本文件。

```
root@server : .sleep
root@server : bash sleep
root@server : source sleep.sh
```

## 如何在脚本文件中实现数据的输入输出？

在 Linux 系统中，`echo` 命令和 `printf` 命令都可以实现程序所需的信息输出功能。让我们分别查看这两个命令的应用案例。

- 1) 首先，我们将使用 `echo` 命令创建一个脚本文件菜单。

命令功能描述：

`echo` 命令主要用于显示字符串信息。

`echo` 命令的语法如下：

```
echo "This is the 1st sentence"
echo "This is the 2nd sentence"
echo "This is the 3rd sentence"
```

从上面的脚本文件可以看出，`echo` 命令可以输出任何字符串消息。可以使用多个 `echo` 命令输出多条消息，或者可以使用一个 `echo` 命令连同引号输出多条消息。然而，输出信息通常是默认的黑色字体，并且无法居中显示。

当我们需要醒目地显示信息以引起用户的注意时，输出可能会略显单调。`echo` 命令支持 `-e` 选项，它允许 `echo` 命令识别 `\t` 之后转义符号的含义。

```
root@server : echo "u"
```

在这些额外的命令中，`\033` 或 `\e` 后面可以终端代码，可以定义字体颜色、背景颜色、光标定位等。所有这些额外信息都可以根据你的方便，使用 `echo` 命令增强消息显示的效果。

### 示例应用案例：

这里有一种使用各种高级 shell 输出技术显示经典“hello world”的方法。

由于没有 `-e` 选项且不支持字符 `\`，屏幕将直接输出原始内容 `\`。在本例中，我们将输出 hello，然后使用 Tab 缩进，最后输出 world，然后确保最终结果将显示为“hello world"。

在另一种方法中，我们可以输出 hello，然后将光标向左移动一个字符，然后输出 world。原始字母 `e` 通常会被新字母 `o` 替换，因此最终输出结果仍将显示为“hello world”。

以下是命令：

```
root@server : echo -e "hello\fworld"
```

```
root@server : echo -e "hello\tworld"
```

注意：

`-e` 选项与后面要输出的内容之间至少有一个空格。与上面的情况类似，向左移动 2 个字符，最终输出将显示为“hello world”。

```
root@server : echo -e "hello\bo world"
```

我们还可以输出 hello，即我们换行时光标留在原始位置（即字母 `o` 后面的位置），然后输出 world。我们将实现**粗体**显示 OK。`\033` 或 `\e` 后面可以跟随不同的代码来设置不同的终端属性。

```
root@server : echo -e "hello \bo world"
```

`1m` 用于终端以粗体显示字符字符串，后面的 `OK` 是要显示的字符字符串内容，最后 `\033[0m` 是为了在输出粗体 OK 后关闭终端属性设置。

如果属性设置最后没有用 `0m` 关闭，那么终端中的所有字符串都将以粗体显示。执行以下命令后，你会发现终端中输出的所有字符串除 OK 之外都将以粗体显示。

这里有一个命令：

```
root@server : echo -e "w 0m"
// 这用指定的选项显示
```
