## 12.1 数值比较

本章围绕以下程序演示：

```c
#include <stdio.h>

void f_signed(int a, int b)
{
    if (a>b)
        printf("a>b\n");
    if (a==b)
        printf("a==b\n");
    if (a<b)
        printf("a<b\n");
}

void f_unsigned(unsigned int a, unsigned int b)
{
    if (a>b)
        printf("a>b\n");
    if (a==b)
        printf("a==b\n");
    if (a<b)
        printf("a<b\n");
}

int main()
{
    f_signed(1, 2);
    f_unsigned(1, 2);
    return 0;
}
```

### 12.1.1 x86 在关闭优化选项时，使用MSVC编译源程序，得到`f_signed()`函数。

第一个条件跳转是`JLE`，“*Jump if Less or Equal*”。如果上一条`CMP`指令的操作第一个表达式小于（不大于）第二个表达式，`JLE`将跳转到指令标识的地址；如果不满足条件，则运行一条指令，例如程序调用`printf()`函数。第二个条件跳转是`JNE`，“*Jump if Not Equal*”。如果`CMP`的两个操作数不等，则跳转。

第三个条件跳转是`JGE`，“*Jump if Greater or Equal*”。`CMP`的第一个表达式大于等于第二个表达式（不小于），则跳转。这段程序，如果三个跳转条件都不满足，将调用`printf()`函数；除非特殊情况，这种情况不会发生。

在我们观察`f_unsigned()` 函数的汇编。`f_unsigned()`函数和`f_signed()`函数相同。它们的区别体现在条件跳转上：`f_unsigned()`函数使用的跳转是`JBE`和`JAE`，而`f_signed()`函数使用的跳转则是`JLE`和`GE`。使用`GCC`编译上述程序，可以得到`f_unsigned()`的汇编：
