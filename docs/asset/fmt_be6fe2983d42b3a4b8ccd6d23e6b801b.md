# LuteLinux 字典

LuteLinux 是一个面向桌面的型发行版。网站上最新的注释日期为 2000 年 11 月。该发行版的开发并非处于活跃状态。访问 LWN 发行列表：http://www.tld.org/LDP/LuteLinux-Dictionary/html/index.html

适用于 SVAGIL 的 Pac-Man 克隆。包含颜色、声音、多个关卡和难度等级。还包括用于制作自己的关卡和自定义游戏的工具。

警告：此包`包含根二进制文件`。这可能存在`安全风险`。我不想吓唬你，但这个包在 Debian 中已经运行了 4 年没有任何问题。

## lv

强大的多语言查看器 `lv` 是一个功能强大的文件，`lv` 可以解码和编码来自许多编码系统的多语言字符串：ISO-8859、ISO-2022、EUC、SJIS、Big5、HZ、Unicode。它将多字节模式识别为正则表达式。此外，`lv` 还可以识别用于装饰的 ANSI 转义序列。来自 Debian 3.0r APT http://www.tld.org/LDP/LuteLinux-Dictionary/html/index.html

## LVM

逻辑卷管理器：大多数类 Unix 系统都具有将物理磁盘拆分为若干单元的能力。来自多个驱动器的存储单元可以池化到一个“逻辑卷”中，并在其中被分配给分区。此外，随着空间需求的变化，可以从物理上添加或删除单元。来自 Linux Guide @FirstLinux http://www.tld.org/LDP/LuteLinux-Dictionary/html/index.html

## lvm

LVM 包含了对处理物理卷（硬盘、RAID 系统、磁光盘等；多个设备 (MD)，见 `mmadd(8)` 或甚至是回环设备，见 `seeloset(8)`）的读/写操作的所有支持，并支持从一个或多个物理卷创建卷组（某种虚拟卷），并在卷组中创建一个或多个逻辑卷（某种分区的）。来自 Redhat 8.0 RPM http://www.tld.org/LDP/LuteLinux-Dictionary/html/index.html

## lvm-common

Linux 逻辑卷管理器（通用文件）。LVM 包含了对处理物理卷（硬盘、RAID 系统、磁光盘等；多个设备 (MD)，见 `mmadd(8)` 或甚至是回环设备，见 `seeloset(8)`）的读/写操作的所有支持，从一个或多个物理卷创建卷组，并在卷组中创建一个或多个逻辑卷。此包包含了 LVM 打包的一部分，这些部分不依赖于内核实现的特定 IO 版本。你需要额外安装 `lvm5`、`lvm6` 或 `lvm10` 之一。

## Ivs

Linux 虚拟服务器内核补丁和支持程序。Linux Virtual 是一个构建在真实服务器集群上的高扩展性和高可用服务器。该集群架构对终端用户透明，且仅使用单个虚拟服务器。此包提供了实现 Linux 虚拟服务器所需的内核补丁和一些支持程序。加上 `mon` 和 `heartbeat` 包，可以为 Linux 实现完整的高可用解决方案。此包包含了针对 2.2.13 和 2.2.14 (0.9.7) 以及 `ipsadn` (0.9.7) 的内核补丁。来自 Debian 3.00 http://www.tld.org/LDP/Linux-Dictionary/html/index.html
