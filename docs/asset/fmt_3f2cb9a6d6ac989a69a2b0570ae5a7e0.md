
15. 选择软件包。选择你想要安装在系统上的包。使用 GRP 软件包来使用预编译的二进制文件。这将加快安装过程。点击“前进 (Forward)”创建账户或查看“服务 (Services)”屏幕。

16. 选择服务。开启将在启动时运行的服务。点击“前进 (Forward)”进入“其他设置 (Other Settings)”屏幕。

17. 选择设置。选择与显示管理器、键映射以及你感兴趣的其他相关的设置。你还可以选择将 BIOS 时钟设置为 UTC 时间。点击“前进 (Forward)”继续进入“用户 (Users)”屏幕。

18. 分配 root 密码。输入你的 root 密码并重复。选择“添加用户到账户”来创建一个普通用户。点击“前进 (Forward)”查看“检查 (Review)”屏幕。

19. 检查选项。仔细检查你选择的选项。点击“保存 (Save)”保存设置以便将来安装。这是你在擦除磁盘并安装软件包之前的最后机会！选择“安装 (Install)”重新格式化硬盘并安装 Gentoo。安装过程将花费很长时间才能完成。事实上，它可能需要非常长时间！

20. 完成安装。看到“安装完成 (Install Complete)”消息后关闭安装程序。

21. 退出并重启。选择注销，然后选择重启电脑。移除光盘 CD 并重启新安装的 Gentoo 系统。

此时，你可以使用 `emerge` 命令向你已安装的 Gentoo 系统添加额外的软件包。请参阅本章稍后的“使用 Emerge 获取软件 (Getting Software with Emerge)”章节。

# 从最小 CD 开始安装 Gentoo

以下是使用本章描述的最小化安装程序安装 Gentoo 的最低计算机配置要求：

- 1GB 硬盘空间
- 64MB 内存
- 一个 486 处理器（或更高）
- 300MB 总内存（内存和交换分区总和）

如果你有一个 CD，请考虑预编译软件包，因为整个编译过程可能需要很长时间。

使用附录 A 中描述的随书 CD。有了这张 CD，以下是在你的电脑上安装 Gentoo 的方法：

- 1. 插入 CD。将 CD 插入电脑的 CD 或 DVD 驱动器中。
- 2. 重启。重启你的电脑。
- 3. 启动 CD。在启动提示符处，按回车键。（如果你无法启动安装介质，按 F1 或 F2 查看可能帮助你的其他安装选项。）

Gentoo 应该检测你的电脑硬件，启动安装过程并显示启动提示符。

# 第三部分 选择和安装 Linux 发行版

## 4. 设置日期

输入 `date` 命令以确保日期和时间正确。如果需要更改，使用 `date` 命令（选项）来更改它们。例如，要将日期设置为 2007 年 6 月 15 日上午 8:15，输入：

```
# date 0615008152007
```

## 5. 加载模块

如果某些硬件没有被自动检测到，你可能需要加载访问该硬件所需的模块。使用 `modprobe` 命令并带上你想要加载的模块名称。例如，要加载 Orinoco 无线局域网网的模块，你可以输入：

```
# modprobe orinoco
```

搜索“Linux”和未检测到的硬件名称以找到相应的模块。

![](img/fa18693414a802b12c8add5f8c4be910_425_0.png)

## 6. 配置网络

输入 `ifconfig eth0` 查看到第一块以太卡的连接是否已启动。然后尝试 ping 互联网上的一个计算机以确保你可以访问外部（例如，`ping google.org`）。如果你无法获取 DHCP 服务器来自动连接互联网，可以通过输入以下命令手动设置 Internet 连接：

```
# net-setup eth0
```

参考第 8 章安装过程中的网络配置信息，帮助你回答关于手动设置 Internet 连接的问题。

## 7. 分区硬盘

对你的硬盘进行分区以为 Gentoo 安装做准备。Gentoo 建议创建一个 64MB 的启动卷（ext2 文件系统）、一个大小是内存两倍的交换分区，以及一个大的根（/）分区（ReiserFS 文件系统）。通过运行你的第一个硬盘名称命令来启动 `fdisk`（对于第一个 IDE 或 SCSI 硬盘使用 `/dev/hda` 或 `/dev/sda`）。然后输入 `h` 显示磁盘列表。（有关如何使用 `fdisk` 分区硬盘的信息，请参阅第 7 章。）

![](img/fa18693414a802b12c8add5f8c4be910_425_1.png)

重新分区磁盘会破坏硬盘上的数据。在开始此操作之前请备份任何数据。确保不要删除或更改任何你想要保留数据的分区。

```
# fdisk /dev/hda
```

## 8. 创建文件系统

要在分区上创建适当的文件系统，请使用 `mk2fs` 和 `mkswap` 命令。例如，对于 IDE 驱动器，第一个分区是启动分区（`/dev/hda1`），第二个是交换分区（`/dev/hda2`），第三个是根分区（`/dev/hda3`），你可以输入内容：

```
# mk2fs /dev/hda1
# mkswap /dev/hda2
# mk2fs /dev/hda3
```

## 9. 开启

使用 `swapon` 命令开启交换分区。例如（`/hda2` 为交换分区），输入：

```
# swapon /hda2
```

# 运行 Gentoo Linux

## 10. 挂载根（/）分区

你需要临时挂载根（/）分区以开始安装 Gentoo。在示例中（根位于 `/hda3`），输入：

```
# mount /hda3 /mnt/gentoo
```

## 11. 挂载 /boot 分区

接下来，挂载启动分区以便从中安装文件：

```
# mkdir /mnt/gentoo/boot
# mount /hda1 /mnt/gentoo/boot
```

## 12. 获取 stage 包

假设你有 Gentoo 安装 CD，你需要下载 stage 包。在硬盘上创建一个目录并使用 `wget` 等工具复制它：如果你使用的是 CD，那里已经有了 stage 包。与其下载，请跳转到下一步，并从 `/cdrom/stages/` 提取 `stage1*.bz2`。

```
# mkdir /mnt/gentoo/tmp
# cd /mnt/gentoo/tmp
# wget -c http://gentoo.org/releases/x86/2006/stage1-x86-2006.bz2
```

`wget` 命令跨多行显示，应在一行内输入（第一行末尾的斜杠与下一行的“stages”之间没有空格）。如果下载在中间停止，可以在相同目录下再次运行该命令恢复。

## 13. 提取 stage 包

使用以下命令：

```
# cd /mnt/gentoo
tar -xvjf tmp/stage1-*.bz
```

一旦解压，你就可以删除 stage 包了。

## 14. 选择镜像站点

使用 `mirrorselect` 命令搜索下载所需文件的 Gentoo 镜像。运行以下命令选择一个高效镜像并将其添加到 `make.conf` 文件中（测试超过15 个服务器需要一段时间）：

```
# mirrorselect -s -o | grep GENTOO_MIRORS >> /mnt/gentoo/etc/make.conf
```

如果在后续执行 `emerge` 命令时看到未找到下载站点，可能需要在 `make.conf` 文件中添加其他镜像站点。

## 15. 挂载文件系统

按照如下方式挂载 /proc 文件系统：

```
# mount -t proc /mnt/gentoo/proc
```

## 16. 更改根目录

使用 `chroot` 命令将 `/mnt/gentoo` 更改为根目录，首先复制 `resolv.conf` 文件以便从那里可以使用：

```
# cp /etc/resolv.conf /mnt/gentoo/etc/resolv.conf
```

输入以下命令将最新的包信息安装到 `/usr/portage` 目录：

```
# emerge --sync
```

## 18. 更新环境

按照如下方式读取环境变量：

```
# env-update; source /etc/profile
```

## 19. 修改 make.conf

使用 nano 文本修改构建 Gentoo 系统的 `make.conf` 文件，因为这是此时可用的编辑器。方法如下：

```
# nano -w /etc/make.conf
```

（使用 nano 的 `-w` 选项使配置行不换行。更多 nano 选项，请输入 `nano --help`。）如果你不知道修改什么，请参考 `/etc/make.conf.example` 文件以获取在继续之前可能更改的设置信息。如果你不知道电脑使用的是什么处理器，输入 `/proc/cpuinfo`。
