# 解析命令行以获取有效数字

为了开始提取过程，我们使用之前初始化的两个变量：`COUNT` 和 `MAX_COUNT`。`COUNT` 变量在 `while` 循环处理期间会增加，而 `MAX_COUNT` 已初始化为 # 的值，它指定用户提供的命令行参数总数。`while` 循环一直运行直到 `COUNT` 大于或等于 `MAX_COUNT`。

在 `while` 循环内部，`COUNT` 加1，因此在第一次循环迭代时等于 1，因为它被初始化为 0。接下来是 `TOKEN` 变量。在整个循环执行过程中，`TOKEN` 始终指向 `$1` 参数。使用 `TOKEN` 所指向的 `$1` 参数的当前值作为 `case` 语句，我们测试 `$TOKEN` 是否指向一个已知值。命令行上的当前值是 `-s` 和 `-S` 开关，它们用于定义浮点算术的精度（如果给了精度的话），以及 `SCALE` 的整数值。精度的值只有两种选择：

- `-s` (精度整数)
- `-S` (精度整数)

注意这些是命令行唯一可能的精度值（我们也允许大写的 `-S`），我们可以在 `case` 语句中轻松地测试此条件。记得我提到过 `$TOKEN` 变量始终指向 `$1` 位置参数吗？为了将其他位置参数移动到 `$1` 位置，我们使用 `shift` 命令。单单的 `shift` 命令会将 `$2` 位置参数移动到 `$1` 位置。如果你想将 `$3` 位置参数移动到 `$1` 位置怎么办？我们有两种选择：连续使用两个 `shift` 命令，或者为 `shift` 命令添加一个整数作为参数。以下命令都会将 `$3` 位置参数移动到 `$1` 位置。

```bash
shift; shift
```

或者

```bash
shift 2
```

注意在第一个命令中，你可能会想知道之前的 `$1`（在此情况下是 `$2`）位置参数值发生了什么。嗯，任何从 `$1` 位置移出的内容都会丢弃！但这正是我们想要的结果。

如果 `$1` 位置的值参数仅为 `-s` 或 `-S` 开关，我们就移动两个位置。我们这样做是因为我们知道 `-s` 或 `-S` 开关之后有一个整数值，那是定义精度的整数开关参数。另一方面，如果用户没有在开关和开关参数之间留空格，我们就只移动了一个位置。假设用户在命令行输入了以下命令之一：

```bash
[root:yogi]@scripts# float_multiply.ksh -s 4 8.09838 2048 65536 42.632
```

或者

```bash
[root:yogi]@scripts# float_multiply.ksh -s4 8.09838 2048 65536 42.632
```
