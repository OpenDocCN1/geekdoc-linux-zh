# authorization (授权)

在最初，授权的概念验证了某人访问某些权利。例如，你被授权从我的 Web 服务器读取文件，但我没有授权你更改内容。授权的第一阶段通常是身份验证。在决定一个个人被允许做什么之前，你必须首先确定他们是谁。在某些情况下，授权是从身份验证识别出来的，而不是允许任何人登录。来自 Hacking-Lexicon

# autoconf (自动配置)

GNU 的工具用于配置源码和 Makefile。使用 `Autoconf`，程序员可以创建可移植且可配置的软件包，因为构建软件包的人被允许指定各种配置选项。如果你正在开发软件并希望它创建配置源码的脚本，就应该安装 `Autoconf`。你还需要安装 GNU `m4` 软件包。请注意，终端用户在使用 `Autoconf` 生成的脚本配置软件时，不需要 `Autoconf` 软件包；`Autoconf` 仅用于脚本的生成，而不是其使用。
