桌面应用程序为你提供了几个选项，可以简化对 Windows 服务的访问。我喜欢的有以下几个：

如果运行的 Windows 终端服务是 Windows XP 或更高版本的 Windows，那么一个在上一节未列出的非常有用的选项是 `-r` 选项，它允许你将 Linux 系统直接映射到你的 Windows 终端服务连接中。当你想要将本地打印队列映射到 Windows 终端会话中的虚拟打印机，或者当你想要将本地驱动器映射到终端会话时，这特别有用。这些的语法分别为 `-r printer:local-queue-name` 和 `-r share-name=/device/path`。例如，要将 PRN1 挂载到本地打印机 SuperScript-660i，你可以在执行 `rdesktop` 命令时在命令行中添加 `-r printer:SuperScript-660i`。图 15.12 显示了你的本地打印队列是如何出现在 Windows 打印对话框中的。

### 用于终端服务器连接的 `tsclient`

如果你出于某些原因不喜欢 `rdesktop`，Ubuntu 在默认安装包中还提供了另一个 Windows 终端服务器客户端。这就是 `tsclient`（终端服务客户端）应用程序（可在 gnomepro.com/tsclient 获取）。`tsclient` 应用程序是一个以 GNOME 为中心的终端服务器客户端，它提供了一些优化，并允许你将终端服务器连接的信息保存到文件中，你可以快速轻松地重新加载它，而无需在每次想连接时都手动指定所有设置。虽然 Ubuntu 的最新版本 `tsclient` 始终可以从仓库获取，但你可以从客户端 SourceForge 项目网站 http://sourceforge.net/projects/ts-client 获取其他基于 GNOME 系统的最新源代码和程序包。

要使用 `tsclient` 应用程序，选择 应用程序（Applications）➪互联网（Internet）➪终端服务器客户端（Terminal Server Client），如图 15.13 所示。输入你想连接的终端服务器名称并点击连接（Connect），标准的终端服务器登录界面会在新的 `tsclient` 窗口中显示，如图 15.14 所示。你正常登录即可。

### 其他远程连接软件

如果不是作为默认 Ubuntu Linux 安装的一部分提供，另一种连接到远程系统的流行软件是 NoMachine NX 的免费版本，被称为 `FreeNX`。这是 NoMachine NX（www.nomachine.com）的免费、GPL 实现。NX 开发了一种压缩技术，大幅减小了 X 窗口通信的大小，并通过缓存和通用协议添加了其他性能改进。Linux 的客户端应用程序包含在 `FreeNX` 软件包中——Windows、Mac OS X 和 Solaris 的客户端可以从 NoMachine 网站免费下载。NX 服务器版本之间的主要区别在于功能（以及，当然，还有成本）。`FreeNX` 提供了商业版 NX 服务器用于远程连接的所有核心功能，但未包含商业版 NX 服务器提供的 SMB 和打印（CUPS）支持。如果你已经是 VNC 的粉丝了，NX 绝对值得你一看，因为它具有卓越的压缩和性能改进，而且因为它内生使用 SSH 进行安全通信。`FreeNX` 实际上等同于 VNC，并且支持 Linux 终端服务器、Citrix 元数据和标准的 XDM 连接。然而，它不是任何官方 Ubuntu 仓库的一部分，因此如果你遇到任何问题，将无法从他们那里获得支持。（尽管如此，你可能需要同情。）

## 总结

在网络和邮件出现之前的时代（你可能不记得了），你需要向另一台计算机拷贝文件。这通常涉及将文件写入可移动介质（如软盘），将该软盘带到另一个系统，然后从软盘拷贝文件——“肉体网络”简直是无法比拟的！现在网络几乎无处不在，大多数家庭都有自己的网络，电子文件传输是必要的。正如你预期的，有许多方法可以传输或拷贝文件，从点点传输到对等传输。在点点传输中，你显式地从一个系统拷贝到另一个系统，并且你知道主机的地址或身份。在对等文件共享系统中，显然有人在共享文件，但通常不知道文件是从哪些系统获取或发送到哪些系统。本章讨论了流行的点点文件传输到你的 Ubuntu 系统。在“Ubuntu 上的对等共享”的第二节中，讨论了在你的 Ubuntu 系统上安装和使用的各种对等解决方案。本章以通过不同的 SSH 连接让其他系统安全访问你的文件而结束。音乐服务器吗？
