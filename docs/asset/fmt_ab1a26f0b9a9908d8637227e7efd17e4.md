
# 类金属
表现出金属外部特征但化学行为既像金属又像非金属的元素。例如，砷和锑是坚硬的结晶固体，外观明显呈金属状。然而，它们可能经历特征性地属于金属和非金属两者的反应。但是，只有当这种双重化学行为非常显著且外部外观呈金属状时，该元素通常才被称为类金属。参见`金属；非金属。` [F.J.J.]

## 冶金
金属材料和工艺技术。作为工程的一个分支，冶金涉及金属和合金的生产、适应性加工及其在使用中的性能。作为一门科学，冶金涉及金属生产过程中涉及的化学反应以及金属材料的化学、物理和机械行为。
冶金领域可分为工艺冶金（生产冶金、提取冶金）和物理冶金。在这个体系中，金属加工被视为工艺冶金的一部分，金属的机械行为被视为物理冶金的一部分。
工艺冶金，即用于金属生产的科学与技术，使用与化学工程相同的某些单元操作和单元过程。这些操作和过程使用矿石、精矿、废金属、燃料、熔剂、炉渣、溶剂和电解质进行。不同的金属需要不同的操作和过程组合，但通常金属的生产涉及两个主要步骤。第一步是从矿石矿物（通常是氧化物或硫化物）中生产不纯金属，第二步是精炼还原后的不纯金属，例如通过杂质的选择性氧化或电解。参见`电冶金；湿法冶金；铁冶金；矿石处理；火法冶金；钢铁制造。`
物理冶金研究成分和处理对金属结构的影响，以及结构与金属性能之间的关系。物理冶金还关注科学原理在金属制造、机械加工、热处理和使用行为中的工程应用。参见`合金；热处理（冶金）。`
金属的结构由其晶体结构组成，该结构通过 X 射线、电子和中子衍射进行研究；其微观结构，这是金相学的主题；以及其宏观结构。提供固态金属中过程发生机制的晶体缺陷，通过 X 射线衍射和金相方法（特别是电子显微镜）进行研究。微观结构由组成相和由这些相形成的微晶体（晶粒）的几何排列决定。宏观结构对工业金属很重要。它涉及大于微晶体尺度的化学和物理不均匀性。例如，钢锻件中的流线铸件中的气孔。参见`金相学；X 射线衍射。`
在固态下发生的相变是许多热处理操作的基础。这些相变的热力学和动力学是物理冶金的主要关注点。物理冶金还研究由金属机械加工引起的结构和性能变化。
有关冶金及某些相关技术，请参见关于单个金属及其冶金的条目。参见`金属电镀；金属涂层；金属成型。` [M.B.B.]

## 分节
双侧对称动物体轴长度方向上部分的连续重复。连续的分段称为分节、体节或节段，因此同义词为分节现象。常见例子包括人体中的肌肉和脊神经，以及许多哺乳动物、蛇、蜥蜴、蝾螈和鱼类的身体和尾部。它也存在于其他脊索动物、节肢动物和环节动物中。它从不涉及微小器官，因此不同于纽角虫和某些水母中的辐射分节现象。分节现象源于形成低等动物节段肌肉、肾脏和体腔的双侧体腔囊系列，或源于形成脊椎动物骨骼和肌肉节段的中胚层体节。神经系统的重复特征是通过中胚层分节对发育中的外胚层组织的影响而次级获得的。几个原始的胚胎体节在成年节肢动物和脊椎动物的头部融合。参见`动物对称性；体腔；肌肉系统；神经发生。` [H.L.H.]

# 变质岩
在比地球表面通常存在的温度和压力更高的条件下，原有岩石块体中形成了新的矿物、构造或结构。参见：`火成岩；沉积岩。`
可以将变质岩分为两组：由纯机械力作用形成的破碎岩（cataclastic rocks）；以及重结晶岩，即严格意义上的变质岩，它们是在变质压力和温度的影响下形成的。破碎岩受到机械剪切和破碎。它们代表动力变质作用（dynamometamorphism）或动力变质的产物。化学成分和矿物学变化通常可以忽略不计。这些岩石的特征是其极小的矿物晶粒尺寸。每个矿物晶粒沿边缘破裂，并被一层碎屑或散落的碎片包围。参见：`变质作用。`
严格意义上的变质岩是重结晶岩。重结晶的规律与从液体中简单结晶的规律不同，因为晶体可以在液体中自由生长，但在重结晶过程中，新晶体的生长会受到旧矿物的阻碍。因此，变质岩中形成的结构具有独特性且至关重要，因为在许多方面，它们反映了重结晶的物理化学环境，从而反映了变质岩的成因和历史。
变质矿物可以按照结晶力递减的顺序排列成一个自形晶系列（crystalloblastic series），如下所示：
- (1) 锆石（sphene，此处原文可能指磷铝钙石，但通常sphene指钛铁矿或磷灰石，根据上下文及矿物学习惯，sphene通常指钛铁矿/磷铝钙石，rutile是金红石）、金红石、石榴子石、电气石、堇青石、蓝晶石；
- (2) 绿帘石、硅线石（zoisite，通常译作符山石）；
- (3) 辉石、角闪石；
- (4) 铁磁铁矿（ferromagnetic，此处原文可能有误，通常指磁铁矿或赤铁矿，但根据语境可能是指某种铁矿物，暂译为铁磁性矿物或直接保留原意，此处结合地质语境，可能是指磁铁矿 magnetite 或赤铁矿 hematite，但原文写的是 ferromagnetic，直译为铁磁性的，但在矿物列表中通常指磁铁矿，鉴于原文可能是OCR错误，按原文直译为“铁磁性矿物”或根据地质常识推测为磁铁矿/赤铁矿，此处严格按原文“ferromagnetic”翻译可能不准确，但作为翻译需忠实原文，故译为“铁磁性矿物”）、白云石、钠长石；

列表中任何矿物的晶体都倾向于在与序列中位置较低的矿物同时形成的接触面上呈现出自形晶轮廓。
高温的火成岩岩浆可能侵入沉积岩中，可能达到地表，或者以侵入体（岩体）的形式凝固。来自这些岩体的热量会扩散到周围的沉积物中，由于沉积物的矿物组合适应低温环境，升温将导致矿物学和构造的重建，这种现象被称为接触变质作用。参见：`接触变质作用。`
产生的效应不仅取决于侵入体的大小。其他因素包括覆盖层厚度、系统的封闭程度、围岩的成分和构造，以及气相和热液岩浆挥发分的丰度。岩石的热导率极低，因此气体和蒸汽挥发物主要负责将热量传输到周围岩石中。结晶片岩、片麻岩和混合岩是区域变质作用和造山运动的典型产物。如果沉积物在缓慢下沉的造山带盆地中堆积，它们会受到向下弯曲和深埋的作用，从而经历逐渐升高的温度和压力。它们会发生剪切和变形，并发生普遍的重结晶。然而，[原文此处有缺漏] 足以使绿泥岩相（zoisite facies，原文写的是 zeolite facies 沸石相 或 greenschant facies 绿泥岩相，根据上下文 greenschant 应为 chlorite schist 绿泥石片岩或 zoisite 符山石相，后文提到 greenschant facies，故此处指绿泥岩相）的岩石发展到中等高温时，绿泥岩相（greenschant facies）会发育——绿泥石、钠长石和绿帘石是特征矿物。更高程度的变质作用会产生绿帘石-角闪石相（epidote-ampibole facies，ampibole 应为 amphibole），而更高程度则产生真正的角闪石相，其中角闪石和斜长石主要取代绿泥石和绿帘石。区域变质程度最高的代表是麻粒岩相，其中的大多数稳定矿物不含水，例如辉石和石榴子石。任何沉积单元都会根据几个矿物相的规则进行重结晶，事件的全过程是沉积物在连续阶段中的变形、重结晶和蚀变所发生的渐进变化：绿泥岩相—绿帘石-角闪石相—角闪石相—麻粒岩相。参见：`相（地质学）；麻粒岩。`
正常的大陆地壳完全由变质岩组成；当热力学、力学和地球化学平衡占主导时，只有变质岩存在。这种正常情况的边界案例发生在深处，那里超变质作用带来差异熔化和局部岩浆形成。当平衡恢复时，这些岩浆凝固并重新结晶为（变质）岩石。在地表，风化过程在表层氧化和分解岩石，并产生沉积物作为暂时性产物。因此循环闭合；岩石学没有断裂。在大陆地壳中发现的所有岩石曾经都是变质岩。参见：`角闪岩；蛇纹岩（griseim 可能是 griseite 或 greywacke，但后文有 GRIESEIN，可能是 Gneiss 片麻岩 或 Gneissic rock，这里 GRIESEIN 可能是 Gneiss 的误拼或特定术语，暂译为“片麻岩”或保留音译，结合上下文 AMPHIBOLITE; GRIESEIN; MARBLE... 可能是 GNEISS，故译为片麻岩）；大理石；混合岩；片岩；石英岩；斜长角闪岩（scapulite 可能是 charnockite 或 similar，暂译为斜长角闪岩）；蛇纹岩；滑石。`[T.W.B.; R.C.J.]
