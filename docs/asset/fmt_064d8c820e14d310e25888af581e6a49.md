### 在 Pidgin 中组织好友

随着你积累了更多的 IM 联系人，你的好友列表窗口将填满，你必须不断向下滚动才能找到某个你不记得名字的人。如上一节提到的，你可以使用好友列表中的组来组织你的联系人。当你只有几个好友时，这通常感觉是大此小用，但一旦你有了几个，你就会希望从一开始就将他们组织成组。幸运的是，你可以组织现有好友分组，几乎和最初定义他们时将他们添加到组一样容易。

默认情况下，Pidgin 提供了以下组供你组织好友：

- 好友（Buddies）
- 同事（Co-workers）
- 家人（Family）
- 朋友（Friends）
- 最近好友（Recent Buddies）

要分组好友所在的组，右键点击该好友，选择`Move To`菜单项，并选择你想将其移动的组。

你可以通过选择`Buddies -> Add Group`命令创建自定义组，这将显示一个你可以定义新组名称的对话框。你也可以通过右键点击现有组名称并选择`Rename`命令来命名。

### 在 Pidgin 中查看好友

默认情况下，Pidgin 只显示在线的好友，这在添加好友时看不到他们的名字可能会令人困惑。你可以通过两种方式更改离线好友的显示方式：

- 通过选择`Buddies -> Show`并选择线下。这将显示你所有的好友，无论他们是在线还是离线。离线好友将显示为灰色项目，下方带有“离线”字样。如果你使用该好友的默认图标，标准的绿色（在线）图标在他们离线时会被中间带有“x”的圆取代。
- 通过右键点击好友窗口中的特定好友名称，从显示的上下文菜单中选择“显示”。此好友将出现在好友列表中，无论他们的状态或是否显示离线好友。

使用`Buddies -> Show Offline Buddies`命令在你确定是否已将某人添加为好友或重新组织联系人时也方便。选择此命令将允许你看到到为止定义的所有好友，并让你如上一节所述将现有好友移动到其他组。

### 记录你的对话

### 退出 Pidgin

如本节早期提到的，启动 Pidgin 时，它会在面板的通知/系统托区域创建一个图标。关闭好友列表窗口后，Pidgin 仍在运行，你可以随时通过单击面板上的 Pidgin 图标重新显示好友列表窗口。选择`Buddies -> Quit`实际上会终止 Pidgin。如果你尝试从应用程序菜单重启 Pidgin，Pidgin 仍在运行的事实会导致轻微故障。
