
# 你预期的那样工作，请确保你已明确在下面启用了它。

# 这应该更改为你设置 `DocumentRoot` 的值。

```apache
<Directory "/var/www/html">
```

# 这也可能是 `"None"`、`"All"` 或 `"Indexes"` 的任何组合，`"Includes"`、`"FollowSymLinks"`、`"ExecCGI"` 或 `"MultiViews"`。

# 请注意，`"MultiViews"` 必须被*明确*命名——`"Options All"` 不会给你这个选项。

```apache
    Options Indexes Includes FollowSymLinks
```

# 这控制目录中的 `.htaccess` 文件可以覆盖哪些选项。也可以是 `"All"` 或 `"Options"`、`"FileInfo"` 的任何组合，`"AuthConfig"` 和 `"Limit"`

```apache
    AllowOverride None
```

# 控制谁可以从此服务器获取内容。

```apache
    Order allow,deny
    Allow from all
</Directory>
```

# `UserDir`：如果收到 `~user` 请求，则附加到用户主目录的目录名称。

```apache
UserDir public_html
```

# 控制对 `UserDir` 目录的访问。以下是一个这些目录限制为只读的网站示例。

```apache
#<Directory /home/*/public_html>
#    AllowOverride FileInfo AuthConfig Limit
#    Options MultiViews Indexes SymLinksIfOwnerMatch IncludesNoExec
#    <Limit GET POST OPTIONS PROPFIND>
#        Order allow,deny
#        Allow from all
#    </Limit>
#    <Limit PUT DELETE PATCH PROPPATCH MKCOL COPY MOVE LOCK UNLOCK>
#        Order deny,allow
#        Deny from all
#    </Limit>
#</Directory>
```

# `DirectoryIndex`：用作预编写 HTML 目录索引的文件或文件名称。用空格分隔多个条目。

```apache
DirectoryIndex index.html index.htm index.shtml index.cgi
```

# `AccessFileName`：要在每个目录中查找的访问控制信息文件的名称。

```apache
AccessFileName .htaccess
```

# 以下几行防止 `.htaccess` 文件被 Web 客户端查看。由于 `.htaccess` 文件通常包含授权信息，出于安全原因禁止访问。如果你希望 Web 访问者查看 `.htaccess` 文件的内容，请注释掉这些行。如果你更改了上面的 `AccessFileName` 指令，请确保在此处进行相应的更改。此外，人们倾向于使用诸如 `.htpasswd` 之类的名称作为密码文件，因此这也将保护它们。

```apache
<Files ~ "^\\.ht>"

    Order allow,deny
    Deny from all

</Files>
```

# `CacheNegotiatedDocs`：默认情况下，Apache 在每个基于内容协商的文档上发送 `"Pragma: no-cache"`。这是要求代理服务器不要缓存该文档。取消注释以下行会禁用此行为，并允许代理服务器缓存文档。

# `CacheNegotiatedDocs`

# `UseCanonicalName`：（1.3 新增）当此设置开启时，每当 Apache 需要构建自引用 URL（指向响应来源服务器的 URL）时，它将使用 `ServerName` 和 `Port` 形成“规范”名称。当此设置关闭时，Apache 将尽可能使用客户端提供的主机名:端口。这也影响 CGI 脚本中的 `SERVER_NAME` 和 `SERVER_PORT`。

```apache
UseCanonicalName On
```

# `TypesConfig` 描述了 `mime.types` 文件（或等效文件）的位置。

```apache
TypesConfig /etc/mime.types
```

# `DefaultType` 是服务器在无法通过其他方式（例如文件名扩展名）确定文档类型时使用的默认 MIME 类型。如果你的服务器主要包含文本或 HTML 文档，`"text/plain"` 是一个合适的值。如果你的内容大多是二进制的，例如应用程序或图像，你可能希望使用 `"application/octet-stream"` 来阻止浏览器将二进制文件作为文本显示。

```apache
DefaultType text/plain
```

# `mod_mime_magic` 模块允许服务器使用文件本身内容的各种提示来确定其类型。`MIMEMagicFile` 指令告诉模块提示定义的位置。

# `mod_mime_magic` 不是默认服务器的一部分（你必须使用 `LoadModule` 添加 [参见“全局环境”部分中的 DSO 段落]，或者重新编译服务器并将 `mod_mime_magic` 作为配置的一部分包含进来），因此它被包含在 `<IfModule>` 容器中。这意味着只有当模块是服务器的一部分时，才会处理 `MIMEMagicFile` 指令。

```apache
<IfModule mod_mime_magic.c>
    MIMEMagicFile share/magic
</IfModule>
```

# `HostnameLookups`：记录客户端的名称或仅记录其 IP 地址 例如，`www.apache.org`（开）或 `204.62.129.132`（关）。默认为关，因为如果人们必须有意开启此功能，这对整个网络来说会更好，因为启用它意味着每个客户端请求都会导致至少一次向名称服务器发出的查找请求。

```apache
HostnameLookups Off
```

# `ErrorLog`：错误日志文件的位置。如果你在 `<VirtualHost>` 容器内未指定 `ErrorLog` 指令，与该虚拟主机相关的错误消息将记录在此处。如果你*确实*为 `<VirtualHost>` 容器定义了错误日志文件，该主机的错误将记录在那里而不是这里。

```apache
ErrorLog /var/log/httpd/error_log
```

# `LogLevel`：控制记录到 `error_log` 的消息数量。可能的值包括：`debug`, `info`, `notice`, `warn`, `error`, `crit`, `alert`, `emerg`。

```apache
LogLevel warn
```

# 以下指令为使用 `CustomLog` 指令定义了一些格式昵称（见下文）。

```apache
LogFormat "%h %l %u %t "%r" "%s" %b "%{Referer}i" "%{User-Agent}i"
```
