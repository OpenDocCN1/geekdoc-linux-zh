# KWord 的文字处理（及更多）

早在在 OpenOffice.org 成为 Linux 企鹅吉祥物 Tux 眼中的灵光一点之前，Linux 用户就需要以图形化方式创建文档了。多年来，为 GNOME 和 KDE 桌面环境开发了一系列高质量的业务/办公应用，包括每个环境的套件。对于 GNOME，GNOME Office 办公件（http://libre.gnome.org/gnomeOffice）是一组松散耦合的业务/办公应用，包含了如 Abi Word 文字处理器、Gnumeric 电子表格（在第 17 节讨论）以及其他几个应用。所谓的松散耦合是指 GNOME Office 中的程序之间实际上几乎没有交互或数据共享——它更像是一个碎片化的组织，而不是一个集成套件。

在 KDE 方面，情况完全不同。KDE 的 KOffice 是一组紧耦合的业务/办公应用，可以在需要的地方方便地共享数据。KOffice 包含了如 K 电子表格（在第 17 节讨论）、KPresenter 演示程序（也在第 X 节讨论，你猜对了，也是第 7 节讨论过）、其他几个以及本节的套件——KWord 文字处理应用。（关于 KOffice 的更多信息，请访问其网站`www.koffice.org`）。

KWord 是一个强大的文字处理应用，具有有趣的功能，例如支持布局设计。传统的文字处理应用（如 Microsoft Word、Corel WordPerfect、OpenOffice.org Writer 等）在您创建新文档时会提供一个空白页。输入文本后，随着你写得越来越多，文本会自然地从一页流到下一页。你可以更改文本宽度和页边距，并让文本环绕图形流动，你的文档由从开始到结束的单一连续文本组成。而布局导向型应用，如 QuarkXPress、Adobe InDesign、FrameMaker、PageMaker、Scribus（在下一节讨论）和 KWord 使用了一种灵活得多的机制，被称为“帧”（frames），以便对文档中的文本、插图、表格和其他部分提供非常详细的控制。帧是创建在文档页面上的矩形区域，任何文档元素都可以位于其中。在 KWord 中，帧可以组合为“帧集”（framesets），即一组包含相关内容的帧。文本在帧集的帧之间流动使得创建多列文档变得容易，或者创建像标准报纸那样的“本文从第 N 页继续”（你还记得吧？）。当你在 KWord 中创建文档时，你会看到一个空白页，可以在上面开始输入文本，就像任何其他文字处理器一样。你可以在此空白页上输入文本，还可以绘制帧，定义文本在帧集中的流动方式以及后续页面中文本如何从一个帧流到另一个帧，等等。帧为创建视觉上吸引且设计良好的文档提供了一个强大的模型，而 KWord 在 Linux 文字处理器中独一无二，因为它同时支持帧和标准的页面导向型文字处理。
