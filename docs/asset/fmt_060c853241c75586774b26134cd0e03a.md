
`items[i] = x * x`  # 原地修改 `items`

```python
square(a)  # 变为 [1, 4, 9, 16, 25]
```

改变其输入值的函数被认为具有副作用，它们会改变程序其他部分的状态。通常情况下，这是一种最好避免的编程风格，因为随着程序规模和复杂性的增加，此类函数可能会成为微妙编程错误的来源（例如，从阅读函数无法看出该函数是否具有副作用）。

## 作用域规则

每次函数被调用时，都会创建一个新的命名空间。在函数内部创建的变量是局部的。当函数返回时，该命名空间就会被销毁。如果变量在这些作用域中未找到，它将搜索全局作用域，最后是内置命名空间。

命名空间的一个特殊之处在于，在函数内部为变量赋值会创建一个局部变量，即使全局作用域中存在相同的名称。要修改全局变量，必须使用 `global` 语句。例如，考虑以下：

```python
a = 42

def foo():
    a = 13

# a 仍然是 42
```

如果你使用 `global` 语句，就可以修改全局变量：

```python
a = 42

def foo():
    global a
    a = 13

# 现在 a 是 13
```

Python 支持嵌套函数。这里有一个示例：

```python
def countdown(start):
    n = start
    def display():
        print('T-minus %d' % n)
    while n > 0:
        display()
        n -= 1
```

嵌套函数的变量是通过词法作用域绑定的。也就是说，名称的解析是通过首先检查局部作用域，然后是外层函数定义的作用域（从内部到外部）。如果未找到变量，它将搜索全局命名空间，最后是内置命名空间。

Python 2 只允许在最内层作用域（局部变量）和全局命名空间（使用 `global`）中重新赋值变量。因此，内部函数无法重新赋值外层函数中定义的局部变量。例如，此代码无法运行：

```python
def countdown(start):
    n = start
    def display():
        print('T-minus %d' % n)
        def decrement():
            n -= 1  # 在 Python 2 中失败
    while n > 0:
        display()
        decrement()
```

在 Python 2 中，你可以通过将想要更改的值放在列表或字典来绕过这个问题。在 Python 3 中，你可以如下声明 `n` 为 `nonlocal`：

`nonlocal` 声明不会将名称绑定到当前调用栈更深处任意函数中定义的局部变量（即动态作用域）。所以，如果你是从 Perl 学习 Python 的，`nonlocal` 等同于声明局部变量。

如果在局部变量被赋值之前使用了它，将抛出 `UnboundLocalError` 异常。这里是一个说明这种情况可能发生场景的示例：

```
i = 0

def foo():
    i = i + 1  # 导致 UnboundLocalError
    print(i)
```

在这个函数中，变量 `i` 被定义为局部变量（因为它在函数内部被赋值了，且没有 `global` 语句）。然而，赋值语句 `i = i + 1` 试图在 `i` 第一次赋值之前读取它的值。尽管在这个示例中有一个全局变量 `i`，但在这里并没有用它来提供值。变量是由局部或全局定义决定的，不能在函数中间突然改变作用域。例如，在前面的代码中，并不是表达式 `i + 1` 中的 `i` 指向全局变量 `i`，而 `print(i)` 中的 `i` 指向的是上一个语句创建的局部变量。

## 作为对象的函数与闭包

函数在 Python 中是一等对象。这意味着它们可以作为参数传递给其他函数，放入数据结构中，并作为函数的返回结果。这里是一个接受另一个函数作为输入并调用它的函数示例：

```python
# foo.py
def callf(func):
    return func()
```

这是一个使用上述函数的示例：

```python
>>> import foo
>>> def helloworld():
...     return 'Hello World'
>>> foo.callf(helloworld)  # 将函数作为参数传递
'Hello World'
>>>
```

当函数被当作数据处理时，它隐式地携带了与定义定义环境相关的信息。这影响了函数中自由变量是如何绑定的。例如，考虑这个版本的 `foo.py`，它现在包含了一个变量定义：

```python
# foo.py
x = 42

def callf(func):
    return func()
```

现在，观察这个示例的行为：

```python
>>> import foo
>>> x = 37
>>> def helloworld():
...     return "Hello World. x is %d" % x
>>> foo.callf(helloworld)  # 将函数作为参数传递
'Hello World. x is 37'
>>>
```

在这个示例中，注意 `helloworld()` 函数使用了在 `helloworld()` 定义时环境中定义的 `x` 的值。因此，尽管 `foo.py` 中以及 `helloworld()` 实际调用的地方也定义了 `x`，但在 `helloworld()` 执行时使用的并不是那个 `x` 值。

当构成函数的语句与它们执行的环境打包时，生成的对象被称为**闭包**（`closure`）。上一个示例的行为是因为所有函数都有一个 `__globals__` 属性，该属性对应于函数定义所在的全局命名空间。对于上一个示例，你会得到以下内容：

```python
helloworld.globals = {
  'builtins': <module 'builtin' (built-in)>,
  'helloworld': <function helloworld at 0x7bb30>,
  'x': 37, 'name': '__main__': '__doc__': None,
  'foo': <module 'foo' from 'foo.py'>
}
```

使用嵌套函数时，闭包会捕内部函数执行所需的整个环境。这里有一个示例：

```python
import foo
def bar():
  x = 13
def helloworld():
  return 'Hello World. x is %d' % x
foo.call(helloworld)  # 返回 'Hello World, x is 13'
```

如果你想基于懒加载或延迟执行的概念编写代码，闭包和嵌套函数将特别有用。这里是另一个示例：

```python
from urllib import urlopen
# from urllib request urlopen (Python 3)
def page(url):
  def get():
    return urlopen(url).read()
  return get
```

在这个示例中，`page` 函数并没有立即执行 `urlopen(url)`，而是返回了 `get` 函数。只有当生成的 `get` 函数被调用时，才会执行网络请求。这种延迟执行机制正是闭包的强大之处。

在这种情况下，装饰器按照列出的顺序应用。其结果与以下代码相同：

```python
def grok(x):
    pass
grok = foo(bar(spam(grok)))
```

装饰器也可以接受参数。这里有一个示例：

```python
@eventhandler('BUTTON')
def handle_button(msg):
    ...

@eventhandler('RESET')
def handle_reset(msg):
    ...
```

```python
def handle_button(msg):
temp = eventhandler('BUTTON') # 使用提供的参数调用装饰器
handle_button = temp(handle_button) # 调用装饰器返回的函数
```
