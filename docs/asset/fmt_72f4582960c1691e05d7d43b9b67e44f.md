
一个描述波或场中激发的术语，暗示该激发具有基本粒子性质，如能量或质量、动量和角动量。通常，对于任何经过量子化处理的方程（包括已经用量子力学处理的二次量子化系统），都会导致激发的粒子解释，这些激发被称为场的量子。历史上，该术语最初应用于不可分割的电磁或光能量，通常称为光子。光子，或电磁场的量子，是一种无质量粒子，最好通过量子化麦克斯韦方程组来解释。类似地，电子可以被称为狄拉克场的量子，这是通过狄拉克方程的二次量子化得出的，这也预测了正电子作为该场的另一种量子的存在，其质量相同但电荷与电子相反。以类似的方式，引力场方程的量子化暗示了引力子的存在。π 介子或 π 介子在理论上被预测为核力场的量子。另一个量子是量子化晶格振动，即声子，可以解释为量子化的声波，因为它像声音在空气中传播一样，以相同的方式穿过量子固体或流体，或穿过核物质。

将量子用作形容词（量子力学，量子电动力学）意味着特定主题应根据为量子化系统制定的现代规则进行处理。参见`基本粒子`；`引力子`；`麦克斯韦方程`；`介子`；`光子`；`量子电动力学`；`量子场论`；`量子力学`。

## 量子声学

研究量子力学定律对声波传播和吸收影响的学科。在物理科学发展的现阶段，量子力学是物理现象最基础的理论。然而，对于日常世界中的许多应用，经典力学提供了足够精确的自然描述。量子声学指的是在结果只能用量子理论来理解的情况下进行声学实验。作为一种总体趋势，在高频声波实验中或在较低温度下进行的声学实验中，量子效应变得更加重要。参见`非相对论量子理论`；`量子热力学`。

### 声波与光子

为了理解声波的量子特性，考虑光量子理论的起源是有价值的。十九世纪后期的实验表明，将经典电磁理论与统计力学定律相结合，无法解释加热表面发射的光谱。为了使理论与实验相符，马克斯·普朗克在 1900 年提出光波的量子是量子化的。这意味着只有某些特定的波能量值是允许的。这些允许值由以下方程给出：

$$E = n h \omega$$

其中 $h$ 是普朗克常数除以 $2 \pi$，$\omega$ 是光波的角频率，$n$ 是整数。该公式的现代解释用称为光子的基本量子来描述这种能量。每个光子具有能量 $h \omega$，波由 $n$ 个光子组成。后来意识到，这种相同的能量量子化也应适用于声波。声波能量的量子化单位被称为声子。参见`热辐射`；`光`；`声子`；`光子`。

### 光电效应

最早证实光由光子组成的实验之一是光电效应。在该效应中，光理论的能量被用于从金属表面击出电子。只有当光的频率足够高时，光子才有足够的能量将电子从金属中击出。因此，检测这一阈值频率是能量量子化的有力证据。类似的实验已经用

### 声子-声子相互作用

固体中的声波在传播过程中会因各种物理过程而衰减。在许多材料中，最重要的机制与固体中的杂质或缺陷有关，例如裂纹、晶界或位错。即使声波通过不含缺陷的完美晶体传播，发现仍然存在可测量的衰减。在没有自由电子的绝缘晶体中，这种衰减是由于声波与固体中原子的随机热振动之间的相互作用造成的。这些构成固体热能并同样被量子化的随机振动被称为热声子。声波的衰减可归因于与热声子的碰撞，其中部分声子声子被散射出声束。这种机制被称为声子-声子散射。参见 晶体缺陷；晶格振动；声音吸收。

在线性弹性固体中，弹性应力与应变严格成正比，这种现象称为胡克定律。如果胡克定律成立，一个波的存在不影响另一个波的传播，因此声子之间没有相互作用。声子-声子散射发生是因为真实固体总是表现出对线性弹性行为的一定偏差。这种非线性称为非谐性，因为胡克定律被称为线性声学。

即使温度非常低且热声子数量极少，非谐性仍可导致声波衰减。这是因为声子可以自发衰变为频率较低的声子。这种衰减发生的速率与声波频率的五次方成正比，因此衰减仅对频率非常高的声波重要。如果声子数量足够大，在某些情况下，部分衰变声子的数量可能会大量积累。这个过程称为参量放大。参见 参量放大器。 [H.I.M.a]

## 量子反常

当某个量根据经典物理的动力学规则消失，但在用量子规则时获得有限值时产生的现象。例如，某些实体的经典泊松括号可能消失；然而相应的量子对易子可能非零——这是对易子反常。或者，某些物质流的流动可能因经典运动方程而满足连续性方程，表明流动是守恒的；但在量子化后，连续性方程可能失效，且在该量子理论中流动可能不再守恒——这是反常散度（或该电流）。由于泊松括号和量子对易子的形式以及电流连续性方程的出现与理论的对称性和（或）守恒定律有关，量子反常起到破坏某些对称性和摧毁经典模型某些守恒定律的作用。这种对称性的破坏并非由动力学方程中显式的对称性破坏项驱动——而是量子化程序本身违反了经典对称性。这一现象的数学原因是，涉及有限自由度数量的经典动力学通常导致在无限维向量空间（希尔伯特空间）上的量子理论，而这种“无穷”产生了新奇效应：参见 正则变换；守恒定律（物理学）；连续性方程；希尔伯特空间；非相对论量子理论；对称性定律（物理学）。

这些现象在量子场论中具有重要的物理意义，特别是应用于基本粒子物理时，其中无限维希尔伯特空间作为对称性破坏的主要来源。量子反常也在量子场论应用的其他物理学分支中发挥作用，包括凝聚态物理、超弦理论和弯曲时空中的运动。参见 基本粒子；量子场论；时空；超弦理论；超弦对称性破缺。 [R.Ij]

## 量子化学

化学的一个分支，研究量子力学在化学问题中的应用。更具体地说，它关注分子的电子结构。自 1960 年代发展起来的方法使量子化学家能够获得非相对论薛定谔方程的可靠近似解。主导量子化学领域的方法是哈特里-福克或自洽场近似。参见 哈特里运动方程；量子力学。

对于闭壳层分子，哈特里-福克波函数的形式由方程 (1) 给出，其中 `A(n!)` 是反对称化器

```
Ψ_HF = A(n! φ_1(1) φ_2(2) … φ_n(n))                                                                 (1)
```

对于 `n` 个电子，其作用的效果是将轨道乘积转化为一个斯莱特行列式。`φ` 是自旋轨道，是空间轨道与单电子自旋函数 `α` 或 `β` 的乘积。对于任何给定的分子体系，形式 (1) 的波函数有无穷多个，但哈特里-福克波函数是轨道 `φ` 经过变分以获得最低可能能量（方程 (2)）的那一个。

```
E = ∫ Ψ * H_HF Ψ d r d τ                                                                 (2)
```

由于单行列式波函数的能量 `E` 形式简单，由此得到的哈特里-福克能量相对容易处理 [方程 (3)]。

```
E_HF = Σ_i f(i|i) + 1/2 Σ_{i≠j}[f(i|j) - (j|i)]       (3)
```

为了精确求解哈特里-福克方程，轨道 `φ` 必须在解析基函数的完备集合中展开，或者必须获得严格的数值（即制表的）轨道。前者对于多于两个电子的系统从实际角度来看是不可能的，后者仅对原子和少数双原子分子实现。因此，放弃了对多原子分子精确求解哈特里-福克方程。相反，采用一个不完整（但合理的）解析基函数集合，并求解在方程 (2) 给出的最低能量下形式 (1) 波函数的最佳变分集合。这种波函数被称为具有自洽场（SCF）质量。那么对于非常大的基函数集合，将由此产生的 SCF 波函数称为近哈特里-福克是合理的。

对于大型化学体系，在从头计算理论研究只能使用最小基函数集合（MBS）。“大型”包括具有 100 个或更多电子的分子体系。所有从头计算方法对化学的最大影响在于结构预测领域。从头计算几何结构预测最令人鼓舞的方面是它们的可靠性。基本上所有分子结构似乎都能在哈特里-福克理论水平上得到可靠预测。更令人鼓舞的是，使用仅
