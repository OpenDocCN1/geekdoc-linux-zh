
# 黑曜石

一种火山玻璃，通常具有含水矿物成分，由粘稠熔岩的快速冷却形成。由于富含微小的、未结晶的晶体生长物（微晶），其颜色为纯黑色，这些微晶使玻璃在不透明，除了薄边缘外。氧化铁灰尘可能会产生红色或棕色的包裹体。

黑曜石通常形成于熔岩流的上部。著名的产地包括怀俄明州黄石公园的黑曜石崖、冰岛的赫尔达山以及意大利海岸附近的利帕里群岛。参见：火成岩；火山玻璃。[OCA]

## 掩星

一个天体在视线方向上被另一个天体暂时遮挡而导致的视消失现象。通常，它指的是被月球掩食的恒星，但也适用于被大行星或小行星掩食的恒星、小行星之间的相互掩食、木星掩食其伽利略卫星等。由于历史原因，一些掩食被称为日食，例如日食。掩食严格来说指的是视线被遮挡，而不是在阴影中消失。参见：日食。

几个世纪以来对恒星月球掩食的观测研究，已被用于改进月球运动理论，并有助于检测地球自转的不规则性。以这些知识为基础，月球掩食现在在研究月球形状方面具有更重要的意义。参见：地球自转和轨道运动；月球。

掩食被用于研究那些无法看到其圆盘的天体的大小和形状。在这种情况下，如果预测一颗行星将通过一颗恒星的临时半径内，而未发生掩食，则设定一个上限。正是通过这种方式确定了冥王星体积很小的事实。参见：冥王星。

观测技术的应用为小行星提供了非常精确的轮廓。然而，成功的观测仍然相当罕见。该方法也被用于寻找疑似的双星小行星。参见：小行星。

在具有大气层的行星掩食恒星期间，对几种不同波长的光进行高速光度探测观测，将揭示大气层的成分、结构和动力学信息。1977年，天王星的非常薄且暗淡的环在被发现时是偶然得到的，当时在准备观测天王星掩食某颗恒星的校准观测期间，这些环掩食了该恒星。现在，为了寻找更多的环并确定已知环的精细结构，此类观测通常从地面和太空常规进行。参见：木星；海王星；太阳系；天王星。[AD.F]

## 海洋

占据地球表面近四分之三的相互连接的咸水主体的主要组成部分之一。地球是太阳系中唯一一个表面覆盖着大量水分的行星。在地表或相对容易获取的地下供应中发现的约14亿立方千米的水中，超过97%位于海洋中。参见：海洋学。

海洋以及连接它们的海域覆盖了地球表面约73%的面积，平均深度为海平面以下3729米（12,234英尺）。超过70%的海洋位于3000至6000米（10,000至20,000英尺）的深度之间。只有不到0.2%的海洋深度达到7000米（23,000英尺）。

海洋是寒冷且咸的。约50%的海洋温度在0至2°C（32至36°F）之间，盐度在34.0至35.0之间。作为一个高度近似的值，盐度34相当于每千克海水中含有34克盐。温度高于几摄氏度的海水局限于海洋相对较薄的表层。参见：海水。

海洋盐度主要受降水、河流径流和海面水分蒸发平衡的控制。最高盐度出现在主要蒸发盆地，这些地区降雨量或河流径流量很少，例如红海。最低盐度出现在主要河口附近，例如亚马逊河。参见：红海。

人类已知的大多数元素都已被发现溶解在海水中，那些未被发现的元素也被认为存在。然而，除少数几种外，它们的存在量都非常少。氯化钠占溶解盐类的约85%，另外四种离子（硫酸根、镁、钙和钾）使总含量超过99.3%。离子比率从一个海洋到另一个海洋，以及每个海洋的顶部到底部都惊人地恒定。

海洋不断将多余的热量（暖水）从热带向两极输送，并将较冷的水送回热带。这种将多余热量从低纬度（南纬40度以南）向高纬度（北纬40度以北）转移的过程，由海洋和大气大致平均分担。海洋热量交换过程中的重要部分是由主要洋流完成的，如“命名”洋流，包括墨西哥湾流、巴西洋流、加利福尼亚洋流和黑潮。这些洋流主要由风力驱动，且不同海洋盆地之间的模式相当相似。参见：墨西哥湾流；黑潮。

## 海洋环流

海洋的广义环流。该术语通常被理解为包括大型、近乎稳态的特征，例如 [墨西哥湾流](https://example.org/gulf_stream)，以及季节性变化但年复一年持续存在的洋流系统，例如美国西海岸西北部的 [戴维森流](https://example.org/davidson_current) 和印度洋的赤道洋流。许多海洋运动具有一个月或两个月的周期和几百公里的水平尺度——这是一种极低频的湍流，统称为 [涡旋](https://example.org/eddies)。高能运动也集中在局地惯性周期（30°纬度时为24小时）以及与潮汐相关的周期（主要是日潮和半日潮）附近。参见 [潮汐](https://example.org/tide)。对于洋流，正如对于波浪一样，最大的单一驱动力是风。此外，海洋在低纬度地区吸收热量，在高纬度地区释放热量。对密度分布的这种综合影响与大规模风驱动环流耦合在一起。一些次表面流动是由表层水因冷却或高蒸发率而密度增大下沉引起的。参见 [海洋波浪](https://example.org/ocean_waves)。

除了西部边界洋流和 [南极绕极流](https://example.org/antarctic_circumpolar_current) 之外，一般向西的表面洋流主要限制在海洋上部 330–660 英尺（100–200 米）范围内。然而，中纬度反气旋涡在平均意义上在 3300 英尺（1000 米）以下仍保持连贯。开阔海洋表面洋流的平均速度通常保持在 0.4 节（20 cm/s）以下。例外情况见于西部边界洋流（如墨西哥湾流）和三大洋的 [赤道洋流](https://example.org/equatorial_currents)，它们的速度均为 2–4 节（1–2 m/s）。

深层环流部分源于风应力，部分源于由热量、盐度和水量收支维持的内部压力力。这两组力都依赖于人为影响。除了科里奥利力和摩擦力外，海底地形对水流路径具有决定性影响。边缘海的深层环流在很大程度上取决于该地区的气候，无论是干旱还是湿润。在干旱气候的影响下，蒸发量大于降水量。因此，边缘海充满了相对咸且密度较高的水。其海平面低于邻近海洋。此类型的例子包括 [地中海](https://example.org/mediterranean_sea)、[红海](https://example.org/red_sea) 和 [波斯湾](https://example.org/persian_gulf)。湿润气候下边缘海的深层环流表现出不同的模式。海平面高于邻近海洋。因此，密度较低、相应盐度较低的表层水流向外，而密度较高的、相对咸的海洋水流入并进入边缘海。这种环流的例子包括拥有浅层的 [达尔瑟河](https://example.org/darsser_river) 和 [德雷戈亚姆河](https://example.org/drejogam_river) 的 [波罗的海](https://example.org/baltic_sea)， [挪威](https://example.org/norway) 和 [格陵兰](https://example.org/greenland) 峡湾，以及通过 [博斯普鲁斯海峡](https://example.org/bosphorus_strait) 入口的 [黑海](https://example.org/black_sea)。参见 [黑海](https://example.org/black_sea)；[峡湾](https://example.org/fjord)；[地中海](https://example.org/mediterranean_sea)。
