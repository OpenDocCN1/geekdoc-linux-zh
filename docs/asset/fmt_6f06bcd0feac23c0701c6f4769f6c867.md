# bstophedron

一种 t/kl 文本阅读器，以 bstophedron 格式化行（一种每行交替的阅读/写作风格）。与传统的从左到右的读写风格不同，bstophedron 不需要每当到达行尾时都让眼睛（或手）回到页边距。在 bstophedron 中，水平位置不会改变；只需向下到下一行继续即可。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index`
