# 使用 Kali Linux 进行渗透测试

现在指示攻击器仅修改每个请求的密码值。在开始攻击之前，让我们为攻击器提供一个字典。由于正确密码是 "password"，我们可以从 Kali 的 rockyou 字典获取前 10 个值。

```bash
kali@kali~$ cat /usr/share/wordlists/rockyou.txt | head
123456
12345
12345
12345678
password
iloveyou
princess
1234567
rockyou
12345678
abc123
```
