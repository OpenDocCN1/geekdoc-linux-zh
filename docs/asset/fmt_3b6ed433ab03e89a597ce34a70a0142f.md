### 72 MandelBreak:

```
; CX=迭代次数

xchg ax,cx

; AX=迭代次数. 写入到VGA缓冲区

stosb

; stosb也递增DI，现在DI指向缓冲区的下一个点
; 这是一个无限循环

jmp FillLoop
```

这个程序的算法是：

- 切换到分辨率为`320×200×256`的图形模式。`320×200=64000(xF00)`。像素都是单字节，所以缓冲区大小就是`xF00`。
- 图形区域的地址存储在`ES`寄存器里，所以`ES`寄存器的值必须是`xFFFF`。至少用4个字节（`PUSH 0xFFFF`）。程序段前缀（PSP）位于此处，启动时的初始值是`0xFFFE`。
- 该程序的运行平台是`MS-DOS`，而且没有内存保护，这种方式不会崩溃。整个程序只有16字节。
- 像素处理使用两个循环：一个遍历像素、另一个循环遍历坐标。在`VGA`缓冲区里通过坐标定位像素，双循环必须通过乘法找到。此，图像中心点`[100,99]`。
- 确正缩放：`BX=BX/64`。转换坐标时（除法）用的`SAR`指令（符号右移），而不是`SH`指令。
- 简化溢出检测算法。常规方法是坐标，作者三次检测了溢出问题：两个减法操作和一次加法的溢出后再次运行的`SAR`指令（相当于64）设置了像素度。灰色的跨度越大，对比越高，图像越清晰；对比越低，图像越模糊。
- 这个程序采用的是无限循环，不能正常退出。如果要终止或进行交互，那么程序还需要。此外，这个程序的优化技巧：
  使用单字的`DX`清空，`“XOR DX, DX”`占用2字节；`MOV DX,0`占用3字节。
  使用单字的`AX`，`“CHG AX, CX”`完成操作。毕竟不再使用`AX`，交换造成任何问题。因为程序没有对`DI`进行初始化，`DI`保持`[0,xFFFF]`之间。
