
这个程序告诉你的计算机在循环内部执行三次指令。最后一行将`$counter`变量的值增加1。只要`$counter`的值小于4，循环就会继续运行；一旦`$counter`的值达到4，循环就会结束。

你可以通过更改`while`循环的条件值（`$counter -lt 4`）来控制计算机在循环内执行指令的次数。

假设你希望程序执行指令十次。将数值4更改为11。将数值更改为11意味着只要`$counter`的值小于11，`while`循环就会继续。

#### 使用嵌套循环

```bash
let flag=1
while [ "$flag" -lt 4 ]
do
for friend in Bob Mary Sue
echo "Hello $friend ."
done
let flag=$flag + 1
done
```

简而言之，该程序在屏幕上问候Bob、Mary和Sue三次。程序中有两个循环：`while`循环和`for in`循环。`while`循环运行三次。内层循环，即嵌套的`for in`循环，在`while`循环每一轮运行时向每位朋友显示问候语。
