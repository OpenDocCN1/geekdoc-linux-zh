### 文件与目录的操作

让我们学习如何对目录应用权限。

#### 在目录上应用权限

你可以为目录分配权限。你可以为目录分配三种类型的权限：读取、写入和执行。读取权限显示目录中可用文件的列表，写入权限允许你更改文件内容，执行权限允许你访问目录中的文件。当你创建一个目录时，由于你是该目录的所有者，你拥有读取、写入和执行权限。除了已经提到的权限类型外，你还可以在目录上应用其他权限，如设置组标识 (SGID) 和粘滞位。

以下是你可以应用于目录的三种权限类型：

- `r`: 允许你查看目录中的文件列表。
- `w`: 允许你更改目录的内容。
- `x`: 允许你访问目录中的文件。

你可以通过 `ls -l` 命令查看你正在工作的目录的权限。假设你想查看某个目录的权限，在终端输入 `ls -l` 命令并按回车。终端将显示如下输出：

```bash
root@localhost:~$ ls -l
total
drwxr-xr-x 2 root root 4096 May 12 10:00 test
-rw-r--r-- 1 root root 0 May 12 10:05 file1
-rw-r--r-- 1 root root 0 May 12 10:06 file2
```

#### 设置目录的组 ID (SGID)

组 ID (GID) 是一种用于分配权限的唯一标识。你可以通过 `chmod +s` 命令对目录应用 SGID。这允许在该目录创建的文件继承父目录的组。

执行以下步骤设置 SGID：

1. 输入 `chmod +s` 后跟目录名称。
2. 按下 `ENTER` 键。
3. 输入 `ls -l` 并按 `ENTER` 键。

#### 在目录上应用粘滞位

粘滞位是一种特殊权限，除非用户是文件的所有者或 `root` 用户，否则无法删除目录中的文件。这为共享目录提供了安全性。

执行以下步骤应用粘滞位：

1. 输入 `chmod +t` 后跟目录名称。
2. 按下 `ENTER` 键。
3. 输入 `ls` 并按 `ENTER` 键查看权限中的粘滞位。

### 应用 Umask 设置

Umask 设置用于确定新创建的文件和目录的默认权限。默认情况下，`umask` 通常为 `022`，这意味着文件权限为 `644`，目录权限为 `755`。

执行以下步骤设置 `umask`：
