# IP 伪装 (IP-Masquerading)

Linux 中的网络功能类似于许多商用网络和网络路由器中的一到多 `NAT`（网络地址转换）。`IP` 伪装允许连接到此设备（通过 `PPP`、`以太网`等）的其他“内部”计算机访问互联网。即使这些内部机器没有正式分配的 IP 地址，Linux `IP` 伪装也能实现此功能。来自 Linux Guide @FirstLinux

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# ip2host

在日志中将 IP 转换为域名，是 Apache Web 服务器 `resolvepl` 脚本的替代方案。`ip2host` 的设计是强制并行处理 `DNS`，但通过通信来减少延迟响应的影响。这使得速度提升了约 10 倍，并随着 `DNS` 值的增加而性能下降。来自 Debian 3.0r0

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# IP 欺骗 (IP spoofing)

`IP` 欺骗是一种由多个组件组成的复杂攻击。它是一种安全漏洞，通过欺骗处于信任关系中的计算机让你认为你是 `true` 身份。关于这一点有一篇详尽的论文，以及 `Phrack` 杂志的第七、八期。来自 Linux Guide @FirstLinux

## IPChains

用于创建规则控制特定机器或网络进出访问的程序和技术。用于配置 Linux 内核中的防火墙规则。`Ipchains` 在 2.4 内核中已被 `iptables` 取代。来自 Redhat-9–Glossary

## ipcheck

通过 `Dyndn.org` 注册动态 `IP`。动态 `DNS` 服务允许你将动态 `IP` 别名为静态主机名，使你更方便地从互联网的各个位置访问。这是一个使用 `NIC V2.0` 协议注册动态 `IP` 的 Python 脚本。该脚本非常易用，并支持多种确定外部 `IP` 的方法（解析本地机器上的接口、基于 `IP` 的检测、支持 Linux, Xnex, Graytrack, Netapy, HawkingTech, Watchguard, Cayman, Zylxel, SMC, Compaq, UPlus, DL Link 和 Cisco 系统）。它还支持 `dynfind` 离线模式。从 1.4.1 版本开始，`ipcheck` 使用默认值，并在发生超时时回退到 `http`。来自 Debian 3.0.0 `APT`
`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
