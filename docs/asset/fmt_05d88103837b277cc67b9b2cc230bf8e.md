
`while` 循环重复命令。`while` 循环以关键字 `while` 开始，后面跟着一个在括号内的表达式。循环的结束由关键字 `end` 指定。
`while` 循环可以很容易与 `switch` 结构结合来驱动菜单。在下一个示例中，注意菜单中包含一个退出选项，它将把 `again` 的值设置为 `no` 并停止循环。

## lschoicew

```bash
set again = yes

while ($again == yes)

  echo "1. List Sizes"

  echo "2. List All File Information"

  echo "3. List C Files"

  echo "4. Quit"

  echo -n "Please enter choice: "

  set choice = $<

  switch ($choice)

    case 1:

      ls -s

      break

    case 2:

      ls -l

      break

    case 3:

      ls *.c

      break

    case 4:

      set again = no

      echo Good-bye

      break

    default:

      echo Invalid Option

  end

end
```

## TCSH 配置 101

## TCSH 配置

TCSH shell 允许你使用 shell 配置变量和特性来配置自己的 shell。你可以使用 `set` 命令开启或关闭某些特性。TCSH shell 还有用于登录、注销以及每次进入 TCSH shell 时的配置文件。

## TCSH Shell 特

TCSH shell 具有若干功能，允许你控制不同 shell 操作的工作方式。TCSH shell 的功能包含了 PDKSH shell 中的功能以及许多其特有的功能。例如，TCSH shell 有一个 `noclobber` 选项，用于防止重定向覆盖文件。最常用的功能包括 `echo`、`noclobber`、`ignoreeof` 和 `noglob`。TCSH shell 功能通过定义和取消与该功能相关的变量来开启或关闭。每个功能都有一个对应的变量；例如，`noclobber` 功能通过使用 `set` 命令定义变量来开启，通过 `unset` 命令取消变量来关闭。要开启 `noclobber` 功能，你执行命令 `set noclobber`。要关闭它，使用命令 `unset noclobber`。

`set feature-variable`
`unset feature-variable`

这些变量有时也被称为 `toggles`（开关），因为它们被用于开启和关闭功能。

## echo

设置 `echo` 会启用一项功能，在执行命令前显示它。命令 `set echo` 开启 echo 功能，而命令 `unset echo` 将其关闭。

## ignoreeof

设置 `ignoreeof` 会启用一项功能，防止用户通过 CTRL-D 注销用户 shell。它被设计用于防止意外注销。当此功能关闭时，你可以通过按下 CTRL-D 注销。然而，CTRL-D 也用于结束直接输入标准输入的用户输入。它经常用于 `mail` 程序或像 `cat` 这样的工具。在这些情况下，你很容易多输入一个 CTRL-D 并导致意外注销。ignoreeof 特性可以防止此类意外注销。当它被设置时，你必须使用 `logout` 命令显式注销：

- `set ignoreeof`
- `^D`

使用 logout 进行注销

## noclobber

设置 noclobber 会启用一项功能，保护现有文件免受重定向输出的影响。有了 noclobber 特性下，如果你将输出重定向到一个已经存在的文件，该文件将不会被标准输出覆盖；原始文件将被保留。在某些情况下，你可能会使用已经给现有文件指定的名称作为重定向输出的文件名。noclobber 特性可以防止你无小心覆盖原始文件：

- `set noclobber`
- `cat preface > myfile`

myfile: file exists
有时你可能想用重定向输出覆盖一个文件。在这种情况下，你可以在重定向操作符后面放置一个感叹号。这将覆盖 noclobber 特性，用标准输出替换文件内容：

- `cat preface >! myfile`

## nogglob

设置 noglob 会启用一项功能，禁用用户 shell 中的特殊字符。`*`、`?`、`[`、`]` 和 `~` 将不再扩展为匹配的文件。这项功能很有帮助，因为某种原因，你的文件名中包含了特殊字符。在下一个示例中，用户需要引用一个以 `?` 字符结尾的文件：`answers?`。首先，用户使用 `noglob` 选项关闭特殊字符。现在命令行上的问号被视为文件名的一部分，而不是特殊字符，用户就可以引用 `answers?` 文件。

- `set noglob`
- `ls answers?`
`answers?`

## 106 TCSH 配置

结合 BASH 和 ZSH shell 中 `MAIL` 和 `MAIL-PATH` 变量的功能。

在下一个示例中，`mail` 变量设置为每 20 分钟（1200 秒）检查一次邮件，并检查 `/usr/mail/chris` 中的邮箱文件。赋值给 `mail` 的数组第一个值是 1200，数组中的第二个值是要检查的邮箱文件路径名。

> set mail ( 1200 /usr/mail/chris /home/mail/chris )
