### 5.5.1. 安装 Glibc

首先，为符合 LSB 兼容性创建一个符号链接。此外，对于 x86_64，创建一个动态库正常运行所需的兼容性符号链接：

```
case ($name -m in)
  i686) ln -svf ld-linux.so.2 $LFS/lib/ld-lsb.so
  ;;
  x86_64) ln -svf ld-linux.so.2 $LFS/lib/ld-lsb.so
  ;;
esac
```
