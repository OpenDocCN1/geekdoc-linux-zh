### 更改 KDE 壁纸、主题、窗口装饰和颜色

寻找与 KDE 外观相关内容的最佳地点，自然就是 `http://www.kde-look.org`。在 `kde-look` 上，您可以找到图标、壁纸、主题、启动画面以及您需要的一切。您仍然可以在其他地方寻找图标和主题，但 `kde-look` 拥有最大的收藏，并且是下载主题最安全的地方，以确保您不会下载到异常损坏的文件。

今天我们要从网站获取一个桌面壁纸。KDE 自带了许多不错的主题，所以我们将使用其中的两个用于样式和窗口装饰。

1. 启动 Web 浏览器并前往 `kde-look.org`。
2. 在壁纸类别下，导航找到适合您当前屏幕分辨率且您喜欢的壁纸。如果您不知道当前的屏幕分辨率，请在控制中心的 `外围设备 > 显示` 下查找。将您的壁纸保存到计算机上，放在您能找到的地方，或者创建一个文件夹，例如 `/home/[username]/MyLook/`。我选择了一个名为 `Spot the Fish` 的壁纸。
3. 打开 KDE 控制中心并进入 `外观与感觉` 部分。
4. 首先选择 `背景`。在右侧的内容区域中，您应该看到两个轮廓分明的区域：`背景` 和 `选项`。在 `背景` 中，`图片` 选项应该已经被选中。使用文件图标浏览您的新壁纸图像。我的位于 `/home/susan/MyLook/2992-pinguin-1024.jpg`。如果您选择的壁纸图像尺寸适合您的分辨率，只需单击 `应用` 即可完成。如果您有一个尺寸奇怪的图像，请使用 `位置` 下拉列表选择按比例缩放、居中或居中自动适应。您可以尝试每种设置后单击 `应用`，然后查看壁纸，看看您最喜欢哪一种。
5. 在控制中心的 `外观与感觉` 部分，接下来前往 `样式`。有三个选项卡。在 `样式` 选项卡上，使用 `组件样式` 部分中的下拉列表选择您喜欢的样式主题。选项卡的整个下半部分会为您预览每种样式。我将使用 `Thememdk`。当您做出决定后，单击 `应用`。`效果和杂项` 选项卡具有视觉效果功能，例如透明度和可拆卸菜单。一些效果对您的计算机处理器负担较重，因此在看到它们是否过度降低计算机性能之前，不要启用太多效果。
6. 前往控制中心 `外观与感觉` 列表中的 `窗口装饰` 部分。在 `窗口装饰` 选项卡上，使用下拉列表选择您喜欢的那一个。下方会为您预览。完成后单击 `应用`。我将使用 `Glow` 主题。
7. 最后，您可以更改颜色以匹配。前往 `控制中心 > 外观与感觉 > 颜色`。您可以从 `颜色方案` 选择框中选择预定义的方案，或者使用 `组件颜色` 下拉列表选择每种组件类型，然后在下方选择颜色来创建自己的方案。您还可以更改 `对比度`。保存自定义方案是个好主意，这样如果您尝试一些更改后，就不必重新创建它。使用 `颜色方案` 选择框下方的 `保存方案` 按钮。我打算将我的命名为 `Hoofooglers`。完成后单击 `应用`。
8. 关闭控制中心，欣赏您的创作。

您可以从 `kde-look.org` 下载新的 KDE 样式主题和窗口装饰主题。如果下载主题，请注意该主题页面上的安装说明。安装新主题类似于从源代码安装软件。您需要打开终端并遵循该主题的安装说明。确保您下载的主题适用于您的 KDE 版本。如果您不确定您的 KDE 版本号，请打开控制中心，不要单击或突出显示任何内容，在右侧内容区域查找“KDE 版本”旁边的数字。

## GNOME 控制中心

| 程序信息 | | |
| :--- | :--- | :--- |
| Fedora/GNOME 菜单 | *偏好设置 > 控制中心* 或桌面上的 `从这里开始` 图标 | |
| Mandrake/KDE 菜单 | *应用程序 > 系统 > 配置 > GNOME > GNOME 控制中心* | |
| 终端命令 | *gnome-control-center* | |

GNOME 实际上并没有一个控制中心。我认为他们开始将偏好设置模块的集合称为控制中心，是因为 KDE 是这么称呼的。名称 aside，GNOME 控制中心是 `Nautilus` 文件管理器中图标的一种视图（参见图 4.3）。除了主菜单和终端命令访问外，您可以以文件浏览模式打开 `Nautilus` 并在地址栏中输入 `preferences:///` 以访问控制中心图标视图。当然，Mandrake 和 Fedora 在 GNOME 控制中心中有一些差异。大多数差异在于使用的图标和附加在每个模块上的标签。

### 图 4.3

GNOME 控制中心视图包含主菜单上 *偏好设置* 菜单中找到的大多数项目。

![](img/f2b5f4073f00f9ec5546d9acb9cc6448_147_0.png)

由于 GNOME 控制中心仅由一组图标组成，您可以双击任何图标以访问该偏好设置模块的对话框。如果您想快速访问单个模块，可以从主菜单下 `偏好设置` 中的子菜单中选择它。其中一个主题选项不在控制中心。您可以在主菜单下的 `系统设置 > 登录屏幕` 中找到更改 `GDM`（登录管理器）主题的相关偏好设置。尽管 KDE 控制中心包含一些可被视为系统管理任务的项目，但 GNOME 控制中心仅包含个人偏好设置。GNOME 将所有系统管理任务保留在主菜单下的 `系统设置` 和 `系统工具` 中。让我们看看 Fedora 中的 GNOME 控制中心。

### 辅助功能

主菜单中的 `辅助功能` 选项是一个子菜单，因此在这里它通过打开两个额外模块图标的新图标视图来充当子菜单。辅助功能模块是残障用户调整键盘和鼠标选项以方便访问的地方。一些键盘设置会在 `键盘和鼠标` 模块中重复出现。在 `辅助技术偏好设置` 对话框中，您会找到屏幕阅读器、放大镜和屏幕键盘的选项。

### 更多偏好设置

`更多偏好设置` 图标是另一个指针，它会打开包含其他五个图标的新图标视图。其中大多数选项是高级的、无需更改，或可以在其他地方访问。

### 关于我自己

如果您在安装过程中被要求提供姓名时不知道自己的名字，您有机会再次正确回答这个问题。如果您知道自己的电话号码和电子邮件信息，就可以获得额外加分。这些信息对于完成操作并不重要。请将 `登录 Shell` 选项保持设置为 `/bin/bash`。

### CD 和 DVD

此模块是 GNOME 的一个出色补充。您可以设置当不同类型的 CD 和 DVD 放入驱动器时自动执行的操作。没错，GNOME 是从 Apple 那里借鉴了这个想法，但拥有它仍然很好。在决定更改之前，请先尝试默认设置。

## 控制中心

我无法告诉你控制中心图标为什么会出现在控制中心中。因为控制中心视图只是“首选项”下主菜单项的副本，这个图标就混进了视图里。你可以整天点击它，但这个图标除了打开你已打开的窗口外，什么都不会做。

## 桌面背景

`桌面背景` 模块是添加裸体农场动物照片——或者你喜欢的任何东西——到桌面的地方。选项很简单：选择一张图片，设置样式，并挑选一种颜色。

## 文件类型和程序

当你在文件管理器 `Nautilus` 中双击文档、媒体文件、归档文件或图像时，默认应用程序会尝试启动。如果你不喜欢 `Nautilus` 针对特定文件类型使用的默认程序，你可以在这里更改它。你还可以添加未定义的文件类型，并为没有关联应用程序的文件类型设置应用程序。该模块在每次发布中都越来越好，但“文件类型和程序”仍然是那些你需要谨慎处理的偏好设置之一。如果你为特定文件类型设置了应用程序，之后又改变了主意，解除关联可能会令人沮丧。

## 字体

`字体` 首选项对话框是让你的桌面完全个性化的另一种方式。你可以更改应用程序、桌面图标、窗口标题和 `GNOME 终端` 使用的默认字体。

## 键盘

你可以在 `键盘` 模块中更改键盘速度设置和区域布局。此对话框中一个非常酷的新功能是“打字休息”选项卡。如果你是一个经常忘记休息、活动一下、让眼睛休息并预防腕管综合症的人，请使用 `打字休息` 选项来强制执行休息。

## 键盘快捷键

你知道键盘快捷键是什么。GNOME 已经为你设置了许多键盘快捷键，但你可以在此处调整它们。请注意不要使用会干扰应用程序正在使用的键盘快捷键。还要确保你不会设置那些在你做其他工作时太容易触发的键盘快捷键。例如，`Enter` 键就是一个糟糕的键盘快捷键选择。
