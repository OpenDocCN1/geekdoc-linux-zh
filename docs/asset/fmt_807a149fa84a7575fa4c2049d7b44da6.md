## 热门 UNIX 变体的覆盖范围

根据业内专家、应用开发、顾问和系统管理员的建议，我们提供了多种 UNIX 变体的信息。我们将变体分为两类：主要和次要。这并不是对变体质量或能力的评价，而是基于其市场渗透率（流行程度）。我们认为 AIX、HP-UX、Solaris 和 SVR4 是主要的，而 BSD、IRIX、Linux 和 SunOS 是市场上的次要玩家。还有其他变体；如果它们变得更加流行，下一版可能会涵盖它们。

您可以通过旁边的图标来识别哪些内容是针对特定变体的讨论：

- AIX (主要)：IBM 的版本，运行在 RS/6000 系列 RISC 系统和大型机。已售出了超过 50 万台 RS/6000 系统！

- BSD [次要] 此版本在市场上的存在度较低。虽然许多变体可以追溯到 BSD，但作为一种产品，它并不流行。

- HP-UX [主要] 惠尔士-派克（HP）的版本，在市场中具有很强的硬件存在度，并拥有良好的未来增长路径。

- IRIX [次要] 虽然硅图形（SGI）的机器在图形处理方面非常出色，但它们在业务环境中尚未获得广泛认可。

- Linux [次要] 虽然这是一个非常优秀且免费的变体，但它在市场上的商业存在很少（可能是因为企业不希望在没有可以在出现问题时起诉的供应商的情况下运行其关键任务应用程序）。详细信息请参阅《Linux Linux Unleashed》系列书籍（Red Hat 和 Slackware）。

- Solaris [主要] 太阳能微系统公司（Sun Microsystems）的版本，在市场中具有很强的硬件存在度，并拥有良好的未来增长路径。

- SunOs [次要] 很大程度上已被 Solaris 安装版所取代。这是一个很好的变体，但公司很难同时支持两个版本的 UNIX。

- SVR4 [主要] 此版本在市场中具有很强的存在度。此外，许多变体可以追溯到 System V Release 4。

## 系统管理员版是如何组织的

第一卷 *UNIX Unleashed, Systems Administrator Edition* 包含三个部分。主要重点是引导你开始使用 UNIX，处理 Shell 以及管理系统。

第一部分，UNIX 简介，旨在引导你开始使用 UNIX。它提供了关于 UNIX 组织、查找文件的信息。

第二部分，UNIX Shell 提供了关于如何选择和使用 Shell 的信息。最流行的 Shell：Bourne、Bourne Again (`BASH`)、Korn 和 C 均有它们之间的比较。

第三部分，系统管理引导你开始并持续。该部分涵盖的重要主题包括启动和停止 UNIX、用户管理、文件系统和磁盘管理、配置内核（系统核心）、网络系统、使用计费、邮件管理、新闻（Usenet）、UUCP（仍在使用的早期方法）、FTP（文件传输协议），最后是备份和恢复文件。

## 互联网版是如何组织的

第二卷 *UNIX Unleashed, Internet Edition* 包含七部分。主要重点是编程（GUI、应用程序语言和互联网）、文本格式（涉及将命令嵌入文本并进行处理）、安全（高级系统管理）、为互联网开发、引导你开始使用 UNIX、处理 Shell、源码控制和配置管理以及不同 UNIX 版本的常见问题（FAQ）。

第一部分，图形用户界面提供了关于使用和编写 GUI 应用的信息。当操作系统是 UNIX 时，GUI 是 X 窗口系统。

第二部分编程介绍了 UNIX 环境中最流行的程序开发工具。最重要的部分是进入你的程序（使用 vi 和 emacs 编辑）。涵盖了 awk、Perl、C 和 C++ 编程语言。Awk 和 Perl 是用于快速程序开发的解释语言。C 是由 Kernighan 和 Ritchie 开发的编译语言；UNIX 使用这种语言编写。C++ 是 C 语言的增强，支持对象编程。本部分的最后一个章节讨论了 `make` 工具，它提供了一种基于规则控制程序编译的方法。

第三部分文本格式化与打印涵盖了 UNIX 环境中支持文档开发、格式化和打印的工具。这些工具是开发 UNIX 的原始理由。格式程序 `nroff` 和 `troff`、标准宏包以及许多其他文档准备工具均已涵盖。此外，还讨论了开发自己的文本格式化宏。

涵盖了可用的工具以及有用的组织。

第五部分“UNIX 与互联网”介绍了用于万维网以及通过电子邮件传输二进制文件（MIME）的工具。书中介绍了网页页面定义语言 HTML，以及如何使用 shell 脚本语言、Perl 和 C/C++ 开发 CGI（[在 Web 服务器上运行并处理来自网页数据的数据的通用网关接口程序]）程序的方法。书中在关于 HTTP（超文本传输协议）和监控服务器活动的章节中提供了管理性信息。

第六部分“版本控制”涵盖了 UNIX 提供的工具，用于在创建不同版本（及修订版）时对你的源代码进行控制。这三个主要工具是 RCS、CVS 和 SCCS。

第七部分“常见问题解答”顾其实思义，提供了关于各种 UNIX 变体的最常见问题的解答。书中用独立章节涵盖了 AIX、BSD、HP-UX、Linux、Solaris、SVR4 和 IRIX。
