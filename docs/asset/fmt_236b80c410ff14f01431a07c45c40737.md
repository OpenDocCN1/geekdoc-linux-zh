# 疾病

一种发生在亚细胞水平的有害反应集合，由某种损伤刺激引起，通常表现为受影响生物的结构或功能改变。随着理解的深入和敏感探针的开发，现在已经清楚，疾病的基本原因基于细胞内的生物化学和生物物理反应。这些反应现在正被分类，其机制正在缓慢地被理解。

术语“稳态”指生物体的功能平衡以及维持该平衡的过程。有一系列被认为是正常的反应。如果细胞被推向在这些限度之外做出反应，正常结构或功能可能会增加、减少或丧失。这种变化可能是可逆的或不可逆的。如果是不可逆的，细胞可能会死亡。因此，亚细胞变化可能反映在改变的组织状态、器官中，并进而影响生物体，导致描述为疾病的状态。参见 `HOMEOSTASIS（稳态）`。

病变是疾病的化学和结构表现。疾病过程的主观表现，如虚弱、疼痛和疲劳，称为症状。客观可测量的表现，如体温、血压和呼吸速率的变化，称为体征或身体发现。身体器官、组织或体液或其排泄产物的化学或细胞组成的变化称为实验室发现。诊断是通过综合这些来源的信息，在患者病史的光照下评估，并与已知的体征和症状模式进行比较，从而确定病理过程的性质。在常用用法中，“疾病”一词指可归因于个体中由影响身体或其部分的因子产生的改变反应所导致的一组特定体征和症状。

病因学是研究疾病过程原因或原因的学科。虽然一种疾病可能有一个主要的病因因子，但越来越明显的是，有几个因素参与疾病过程的启动。个体的易感性是一个始终存在的变量。病因因子可以方便地分为两类（见表）。一组由内源性（内部的；体内的）因子组成，可能起源于遗传物质的错误。另一类病因因子是外源性（环境的）。这些占大多数疾病反应的原因。外源性因子包括物理、化学和生物因子。

发病机制是指细胞，从而身体，对病因因子做出反应的机制。它涉及生物化学和生理反应，反映在超微结构、显微或大体解剖病变中。细胞对损伤的反应方式数量有限。反应的性质受因子性质、剂量、入口门户、暴露时间以及许多宿主因素（如年龄、性别、营养状态和物种和个体易感性）的修改。

# 疾病生态学

宿主的行为和生态学与病原体生物学之间的相互作用，以及疾病对种群的影响。

`阈值定理。` 为了使疾病传播，平均而言，它必须在当前宿主死亡或康复之前成功传播给一个新宿主。这一观察结果是流行病学中最重要的思想——阈值定理的核心。阈值定理指出，如果易感宿主的密度低于某个临界值，那么疾病的传播平均而言不会足够快以导致感染个体数量的增加。换句话说，如果疾病的再生数量（reproductive rate）大于1，就会发生流行病，再生数量被定义为感染个体平均产生的新感染数。人类免疫规划基于将流行病学阈值定理应用于公共卫生；具体来说，如果一个种群中足够多的个体接种疫苗，那么易感个体的密度将降低到足以防止流行病的水平。参见“流行病学”；“疫苗接种”。

一般来说，疾病的再生数量与其传染性和个体具有传染性的持续时间成正比。因此，极度致命且过快杀死宿主的疾病可能需要极高的宿主密度才能传播。并非所有疾病都像阈值定理假设的那样简单地表现，最显著的例外是性传播疾病。由于生物体主动寻求繁殖，性传播疾病在宿主之间传播的速率通常对宿主密度的依赖性较小。

`种群效应。` 许多动物种群的循环被认为是由疾病驱动的。例如，欧洲卷叶蛾幼虫的波动据推测是由感染并杀死该物种幼虫的病毒驱动的。英格兰北部红松鸡的循环也被认为由疾病驱动，在这种情况下是由寄生线虫驱动的。只有当红松鸡携带沉重的蠕虫负担时才会看到影响，这些影响表现为繁殖成功率降低或冬季死亡率升高。这个例子突出了疾病的一个共同特征：它们的影响可能只有在宿主受到其他压力（如严冬和饥饿）同时侵袭时才变得明显。

新疾病引入野生种群已造成自然生态系统的巨大破坏。例如，1980年代牛瘟病毒引入非洲水牛和野生动物种群后，这些种群遭到毁灭性打击。近年来，非洲野生偶蹄目动物之所以恢复，是因为大规模的疫苗接种计划消除了主要宿主——家畜中的牛瘟。但牛瘟在野生偶蹄目动物中流行病的后果远远超出了偶蹄目动物种群本身。例如，牛瘟流行病之后，人类昏睡病（睡眠症）发病率上升，因为传播昏睡病的采采蝇出现了猎物动物（采采蝇的正常宿主）短缺，并越来越多地转向人类觅食。
