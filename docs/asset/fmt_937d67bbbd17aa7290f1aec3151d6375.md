
这必然只是对`Kubernetes`的高层概述，省略了系统的许多细节和功能。我们略过了自动扩展（包括`Pod`和组成集群的节点）、`Cron Job`（按计划启动容器）、`Ingress`（`HTTP`负载均衡、重写和`SSL`卸载）、`RBAC`（基于角色的访问控制）、网络策略（防火墙）等等。`Kubernetes`极其灵活且极其强大：对于任何新的`IT`基础设施，它必须是一个有力的竞争者。

## 防止恶意软件

**乔尼·比德韦尔（Jonni Bidwell）** 不确定恶意软件是否比他更能破坏他的电脑，但他真的不想去证实这一点……

`![](img/3f314b57ad3c8b08d25e5d1ab47de56d_81_0.png)`

- `Linux`不是恶意软件的滋生地！“其用户基数很小，意味着没人有兴趣攻击它。从网络随机下载并运行内容的文化并不存在。它更安全。生态系统的碎片性对它有利的地方在于，使得针对特定发行版变得困难，”他们大声说道。

遗憾的是，这些都不是事实。`Linux`服务器运行着互联网的大部分，还有数十亿台`Android`手机，以及基于`Arm`和`MIPS`的路由器和`IoT`设备。而且人们总是运行诸如`curl... | sudo bash`这样的命令——这是许多流行程序推荐的安装方法。因此，`Linux`自满的时候已经过去，我们需要长密码、勤勉的`ossec`以及受迷惑的技术编辑的偏执抱怨的时刻已经到来。不过别担心，我们准备了对影响你的`Linux`主机的威胁及其缓解措施的综合调查。

> **恶意软件的范围**
>
> “通过你的网络摄像头或麦克风来监视你的软件怎么样？”

任何使用过`Windows XP`的人都知道广告软件（`adware`）和缠人软件（`nagware`）有多烦人。但更令人担忧的是收集电子邮件地址、密码或加密你文件的恶意软件。如果那没吓到你，那么通过你的网络摄像头和麦克风来监视你的软件怎么样？还有窃取你所有辛苦赚来的加密货币（或者如果你还相信那回事的话，是真实金钱）的恶意软件怎么样？这些威胁都非常真实，但我们会看到，一些简单的步骤（使用密码管理器、保持软件最新、不打开可疑文件、小心你访问的网站）将在很大程度上保护你。

我们将查看恶意软件如何得逞、它是如何被发现的以及攻击者的动机是什么。网络是一个危险的地方，我们越来越多地看到，无论运行在什么平台上，`Web`浏览器都可能被攻破。因此，我们将深入探讨如何保护你的浏览器。我们还将深入`Linux`反病毒（小而世界）领域。

## `Linux`上的恶意软件

在桌面`Linux`上运行确实使你是少数派，但恶意软件在针对你的操作系统时并不歧视。

“`Linux`不会得病毒”这一阶段性的说法曾经很常见。现在依然如此，由该操作系统的粉丝甚至是发行版制造商（见右文 [`manjaro.org`](https://manjaro.org)）。不幸的是，这种说法从来都不完全真实，而现在它比以往任何时候都更具误导性。当`Linux`还只是林纳斯眼中的一点星光时，`UNIX`系统上就已经存在蠕虫、`rootkit`和各种其他恶意程序。它们使用的许多技术在`Linux`平台成熟后得到了适配。

就桌面`Linux`而言，情况还算清晰：报告的攻击少得多，已知恶意软件菌株的列表远短于`Windows`机器。考虑到桌面`Linux`的市场份额（大约在百分之二左右），这是合理的——攻击者更倾向于攻击大众正在使用的东西。2006年“`Mac`不会得病毒”系列电视广告声称“`Mac`不会得病毒”。自那以后，其桌面市场份额增长到大约百分之十，威胁数量也随之成比例增加。尽管苹果公司对软件安装采取了围墙花园式的做法。

如今，关于反病毒软件在`Windows`上是否有帮助的观点分歧，并不是因为它没有做它声称做的事情，而是因为有时（由于编程不佳）它会暴露系统给新的、潜在更危险的攻击。安全大师`Tavis Ormandy`，`Google Project Zero`安全团队的一部分，对此威胁特别直言不讳。以最高权限级别运行的程序，正如反病毒扫描系统文件或特权内存所要求的，需要无懈可击。如果这些有漏洞，那么系统也有漏洞，可能比没有运行此类反病毒时更严重。

通常你不需要依赖一个有漏洞的程序来利用系统：一个有漏洞的用户就足够了。编写一个程序来加密所有用户文件，记录/注入击键（至少在`X`中——见 [`github.com/CoolerVoid/Rootstealer`](https://github.com/CoolerVoid/Rootstealer)），启动`FTP`服务器（使机器文件对世界开放），甚至如果该用户具有`root`权限并且可以被骗输入密码时擦除所有本地存储——所有这些都很简单。技巧在于找到一个足够天真的用户来运行它。同样，对潜在灾难的了解，精心制作的钓鱼邮件可以欺骗他们访问一个可以从其中吞噬密码的假网站，打开一个有毒的`PDF`，甚至只是运行一个恶意可执行文件——只要它没被邮件提供商或目标邮件客户端阻止。人类有一个坏习惯，当事情似乎来自他们认识的人时，他们会相信，因此很容易看到这些事情如何级联并变成大规模爆发。

### 我们 ♥ 统计

`Thycotic Black Hat 2018`黑客调查报告 `[1]` 指出，近 60% 的黑客认为社会工程学是攻破网络最快的方式。使用恶意软件（6%）和应用漏洞（20%）的可能性要小得多。得益于松散的安全实践和/或黑客的智慧，相当规模的密码转储（`password dumps`）公开可用。你可以通过访问 `Hunt` [`Have I Been Pwned`](https://havelbeenpwned.com) 来检查你的任何电子邮件地址是否与这些转储相关联。几年前加入的旧论坛的密码可能对黑客没什么用，但如果那个论坛账户可以与你的身份相关联（通过电子邮件地址、用户名或其他），并且你在那个论坛之外重用了那个密码或其简单变体，情况就不同了。调查发现，密码重用是黑客利用最多的行为（50%），公共 `Wi-Fi` 使用和中毒 `USB` 驱动器并列第二，各占约 20%。

### 保护你的浏览器

网络浏览器本身已经变成了操作系统，而现代网络则是一片丛林。

在 `Linux` 上，路过式下载（`Drive-by downloads`）相当罕见，公平地说，它们在 `Windows` 上也越来越少了。过去那种 `reputable` 程序在安装程序中偷偷捆绑“可选”附加功能的日子也一去不复返了，例如浏览器搜索栏或无法关闭的弹窗广告。但这并不是自满的理由。

当这类东西出现在 `Linux` 上时，通常是以浏览器扩展的形式出现，且往往是用户在不知情的情况下安装的。毕竟，那些巡逻 `Chrome` 商店和 `Firefox` 扩展页面的神谕般的人类和机器学习机器人并不能捕捉到所有问题。通常情况下，这些扩展很容易从“附加组件”（`Firefox`）或“扩展”（`Chrome`/`Chromium`）设置中卸载。`Chromium` 的最新版本可以记录所有扩展活动；只需使用以下命令启动即可：

```
$ chromium --enable-extension-activity-logging
```

然后转到扩展页面，点击你想调查的扩展的“详细信息”，向下滚动至“查看活动日志”。如果你不喜欢看到的内容，请禁用或删除该扩展。

- `Firefox` 的多账户容器是一项非常值得付出的努力，它是一项出色的扩展。与 `Docker` 等类似，其理念是将工作流程隔离，在此情况下通过颜色编码的浏览器标签页来实现。例如，你可以在一个域名中进行所有的社交媒体活动，而在另一个域名中进行研究和实际工作。它们还提供了方便的功能，允许使用两组不同的凭证登录同一网站——如果你管理多个 `Gmail` 或 `Twitter` 账户，这会非常有用。`Facebook` 拥有一个专门的容器（<http://bit.ly/Ixj25lfbook>），确保其跟踪 `Cookie` 无法知道我们在该容器之外的身份。

`Firefox` 容器更多地解决的是隐私问题而非恶意软件问题（我们不敢诋毁 `Facebook` 称其为恶意软件），但并非不可能存在某些高级恶意软件，利用用户登录到高知名度或高价值网站这一事实。有关我们批准的其他扩展，请参见后文方框中的内容。
