
### NR 和 NF 变量

`NR` 和 `NF` 是 `awk` 的预定义变量，分别意味着输入记录数（Number of input Record）和输入记录中的字段数（Number of Fields）。在示例中，`NR` 随着输入记录的改变而改变，而 `NF` 是恒定的。下表显示了此类内置 `awk` 变量的列表。

| `awk` 变量 | 含义 |
|---|---|
| `FILENAME` | 当前输入文件的名称 |
| `RS` | 输入记录分隔符（默认是换行） |
| `OFS` | 输出字段分隔符字符串（默认为空） |
| `ORS` | 输出记录分隔符字符串（默认是换行） |
| `NF` | 输入记录数 |
| `NR` | 输入记录中的字段数 |
| `OFMT` | 数字的输出格式 |
| `FS` | 字段分隔符（默认为空格和制表符） |

### 使用 awk 进行算术运算

你可以按照如下方式轻松地使用 `awk` 进行算术运算：

```awk
$ cat > math
{
  print $1 " + " $2 " = " $1+$2
  print $1 " - " $2 " = " $1-$2
  print $1 " / " $2 " = " $1/$2
  print $1 " x " $2 " = " $1*$2
  print $1 " mod " $2 " = " $1%2
}
```

按照如下方式运行：

```awk
$ awk -f math
20 + 3 = 23
20 - 3 = 17
20 / 3 = 6.66667
20 x 3 = 60
20 mod 3 = 2
(按 Ctrl + D 终止)
```

在上面的程序中，`$1 " + " $2 " = " $1+$2` 语句用于加法运算。在这里，`$1 + $2` 意味着加上第二个字段。你同样可以进行 `-`（减法）、`*`（乘法）、`/`（除法）、`%`（取模求余数）。
