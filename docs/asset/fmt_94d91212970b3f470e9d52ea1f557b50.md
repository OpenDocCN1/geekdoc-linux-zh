# 安全 RHEL 7

因此，在 `x86` 上，你会在重启之前通过执行以下命令尝试同步磁盘：

`<Alt><SysRq>s`

`<Alt><SysRq>b`

或者，如果你仍然可以访问终端，可以通过发送字符到 `/proc/sysrq-trigger` 来相同的操作：

```bash
echo s > /proc/sysrq-trigger
```
