最后要考虑的是曝光，它由三个因素控制：快门速度、光圈和 ISO 速率。快门速度顾名思义就是：快门保持开启的时间。这时间可以从千分之一秒到几秒不等，进入相机的光量与快门速度成正比。

接下来是光圈，镜头的视野，它由光圈叶片控制。这就是所谓的 f 值（光圈数），它可能从 1/2.0 到 1/4、1/5、1/8、1/11 以及 1/16 不等。简而言之，光圈越小，上述序列中的每个 f 值越大，这代表进入的光量减少了一半。（详见下文）

ISO 是感光度。它是测量照射在相机电路上的光量。范围可能从 100 到几千不等，但 HQ 摄像头最高为 800。

## 平衡术

由于会有多个影响曝光的因素，因此会有某些组合可以提供正确的曝光。例如，如果你用 1/60、f/8 和 ISO 100 拍摄曝光，那么用 1/120 秒、f/5.6 和 ISO 100，或者 1/240 秒、f/4 和 ISO 200 也是正确的。然而，这些组合并不完全相同，因为它们以各种方式影响照片质量。

快门速度是最明显的因素。快门越慢，如果你在快门开启时移动了相机或场景中的某个物体，就越容易出现模糊。如果不使用三脚架，模糊的概率会很高；或者如果你拍摄静态场景，你需要 1/60 秒或更快的快门，使用长焦镜头时需要更快。模糊会变形画面中的任何物体。

## f 值详解

理解原理比死记硬背更容易。因为 f 值解释了光圈的测量方法，所以它是浅显易懂的。这里是你需要知道的。

f 值的写法看起来可能很奇怪。其实非常简单。f/4 的光圈意味着镜头的直径（经过快门缩小后）是焦距除以 4。因此，对于 HQ 摄像头的 16mm 镜头，在 f/4 时直径为 4mm。当然，这恰恰解释了为什么大 f 值意味着小光圈，反之亦然。进入的光量取决于其面积，而面积与直径成正比，我们现在可以看到，在 f/8 时允许的光量，与光量减半的 f 值序列的关系看起来很奇怪：f/1.4、f/2、f/2.8、f/4、f/5.6、f/8、f/11、f/16。

事实上，f 值是直径与焦距的比值。为了获得相同的光圈，镜头的直径必须大于广角镜头。通过对比，6mm 镜头的 f 值（f/1）略大于 16mm 镜头（后者）。

## 官方镜头

在两个官方镜头中，6mm 采用的是 C 接口，而 16mm 采用的是 CS 接口。幸运的是，两者具有相同的螺纹，因此可以将其中任何一个适配到 HQ Camera。然而，由于 C 口和 CS 口对焦到传感器的距离与镜头不同，如果你使用 C 口镜头，则必须使用相机随附的适配器。在使用 16mm 镜头时需要使用适配器，否则在使用 6mm 镜头时将无法正确对焦。

在安装 HQ Camera 镜头之前，你可能会发现练习使用镜头说明很有用。从 16mm 镜头开始是最直观的。你会看到两个环，每个环上都有指螺螺钉。与普通的单反相机等相机（你会经常更改光圈和焦点）不同，这些镜头是用于 CCTV 的，因此你需要锁定环以防止意外调整。除非你将其用于某些无人值守的应用，否则请在松开两个指螺的情况下使用 16mm 镜头，这并不困难。

或者更短地说，在近焦和远焦功能上，另一个控制环上标记有从 f/4 到 f/16 的光圈。要查看它是如何工作的，请取下前后镜盖，然后在握住镜头时尝试旋转光圈环。你会看到光圈的打开和关闭。

你可能认为 6mm 镜头的运作方式与预想的不一样。具体来说，对焦并不是一个可以独立旋转的环。相反，它是通过螺丝旋入相机的移动来实现的。要旋转镜头，实际上是拧紧或松开镜头。要进行调整，请拧紧光圈环上的焦点（通过 OPEN 和 CLOSE 移动）或松开对焦环。
