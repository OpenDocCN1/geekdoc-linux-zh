### Kali Pi 和 Mana-Toolkit

在本节中，我们将介绍 Kali Pi 上的 Mana 脚本。正如我们在上一节中看到的，它创建了一个功能完备的热点供目标连接，并执行带有 SSL 剥离的中间人攻击。这意味着我们将获得他们访问的任何网站的副本或输入的任何凭据，即使他们使用的是 HTTPS。为了使此操作成功，我让 Pi 通过网口连接到互联网，并使用我的 TP-Link USB Wi-Fi 适配器作为 Mana 的恶意接入点。

#### 重要目录：

- Mana 程序目录：`/usr/share/mana-toolkit`
- Mana 配置设置：`/etc/mana-toolkit/hostapd-mana.conf`
- Mana 启动脚本：`/usr/share/lib/mana-toolkit/run-mana`
- Mana 捕获流量与日志：`/var/lib/mana-toolkit`

#### 运行 Mana

在 Kali Pi 终端中输入以下命令：

```bash
cd /usr/share/mana-toolkit
cd run-mana
```

在该目录下，你将找到多个可以运行的脚本：

```

fireman-view.sh      start-noupstream-all.sh
start-nat-full.sh    start-noupstream-eap.sh
start-nat-simple.sh start-noupstream-only.sh
```

请查看手册以获取每个脚本功能的完整描述。正如我们在上一章中所做的那样，我们将运行 `start-nat-full.sh`。该脚本会创建一个 Wi-Fi 访问点，对任何连接它的客户端执行 SSL 剥离（尝试将 HTTPS 降级为 HTTP）和中间人攻击。它会捕获任何凭据并将其存储在日志文件夹中。启动：
