
- 如果某些文件缺失或看起来损坏，您应该重新安装该包或卸载它。

- 在某个时刻，您可能会看到一个不认识的文件。要找出哪个包拥有它，请输入以下命令：

```
rpm -qf /usr/bin/view
```

输出将类似于：`gv-3.5.8-1`

- 假设在使用 `/usr/bin/paste` 时遇到问题，并想验证该文件的包，但不知道哪个包拥有它。在这种情况下，只需输入以下命令：

```
rpm -Vf /usr/bin/paste
```

相应的包将被验证。
