## 辉钼矿

一种具有 $\mathrm{MoS}_2$ 组成的矿物。辉钼矿是钼的主要矿石。它在六方晶系中结晶，但晶体稀有，当发现时呈六方板状。它常见于鳞片状或片状团块中。该矿物具有油腻感。硬度为 1.5（莫氏硬度），比重为 4.7。光泽为金属光泽，颜色为铅灰色。辉钼矿和石墨长期以来因它们几乎相同的物理性质而被混淆。它们可以通过在纸上的条痕来区分，石墨为黑色，辉钼矿为绿色。辉钼矿已被用作润滑剂。

辉钼矿出现在挪威、瑞典、澳大利亚、英国、中国和墨西哥的各种地方。在美国，辉钼矿在许多地方都有少量发现，但最重要的产地是科罗拉多州的克莱马克斯。[C.S.Hu:J]

## 钼

一种化学元素，Mo，原子序数 42，原子量 95.94，位于元素周期表中第三族过渡元素，包括铬（原子序数 24）和钨（原子序数 74）。研究揭示，它是应用最广泛的化学元素之一，不仅应用于冶金，还应用于油漆、颜料和染料；陶瓷；电镀；工业催化剂；工业润滑剂；以及有机金属化学。钼是土壤和农业肥料中必不可少的微量元素。发现钼原子在酶（氧化酶和还原酶）中执行关键功能，特别引人注目的是其在氮酶中的作用，氮酶被豆科植物中的细菌用来将空气中的惰性氮 ($\mathrm{N}_2$) 转化为生物可用的氨 ($\mathrm{NH}_4$)。参见：固氮；元素周期表。

钼广泛分布于地壳中，在岩石圈中的重量浓度为每百万分 1.5，在海水中约为每十亿分 1.0。它至少存在于 13 种矿物中，主要以硫化物（辉钼矿 $[\mathrm{MoS}_2]$）或钼酸盐形式存在（例如，钼铅矿 ($\mathrm{PbMoO}_4$) 和镁钼酸盐 ($\mathrm{MgMoO}_4$)）。

尽管钼在原子量和原子序数上更接近铬，但其化学行为通常与钨非常相似，后者具有几乎相同的原子半径。（这是由于所谓的镧系收缩，即在钼和钨之间的周期中，原子 57 到 71 的原子半径减小。）参见：铬；镧系收缩；钨。

钼原子含有六个价电子 $[4d^5 5s^1]$，它们以极大的多样性用于形成化合物和配合物，其中电子构型从 $d^{10}$（氧化态 $+6$ 中 0 个电子）到 $d^0$（$-2$ 氧化态中 8 个电子，注：原文此处描述可能有误，$d^0$ 在 $-2$ 价态对于 Mo 来说是不寻常的，通常 Mo 最低价态是 -2 吗？Mo 常见价态 +6, +5, +4, +3, +2。Mo 可以形成二茂金属配合物。原文说 "8 electrons in -2 oxidation state"，如果 Mo 是 -2 价，其电子排布可能是 $d^8$? 不，Mo 原子序 42。

让我们仔细检查原文："electronic configurations vary from $d^{10}$ (0 electrons in oxidation state $+6$) to $d^0$ (8 electrons in $-2$ oxidation state $-2$)"。

这句话本身在化学上可能有些混乱或非常规。

$d^{10}$ 意味着 d 轨道全满，通常对应于 0 价或 +6 价（如果 4d 全满，5s 5p 空？）。

对于 Mo(VI)，通常认为是 $d^0$。

对于 Mo(0)，是 $d^6$? (如果是八配位)

Mo(0) 通常 $d^6$?

让我们看原文的逻辑：

"d^{10} (0 electrons in oxidation state +6)" -> 这暗示 +6 价时 d 轨道有 10 个电子？这不对。+6 价通常失去 6 个电子，Mo 是 42 号，失去 5s1 4d5 6个电子，变成 $d^0$。

所以原文 "d^{10} (0 electrons in oxidation state +6)" 这里的 "0 electrons" 可能指的是参与成键的电子？或者原文有误。

"to d^0 (8 electrons in -2 oxidation state -2)" -> -2 价时 $d^8$?

鉴于这是翻译，我必须忠实于原文的文字，即使原文有科学错误。

翻译策略：

"d^{10}$（氧化态 $+6$ 中 0 个电子）到 $d^0$（$-2$ 氧化态中 8 个电子，注：原文此处重复了 -2，且描述存疑，但保留原文意思）。

实际上，原文 "8 electrons in -2 oxidation state -2" 中的 "-2" 重复了。

翻译为：

“...从 $d^{10}$（氧化态 $+6$ 中 0 个电子）到 $d^0$（$-2$ 氧化态中 8 个电子）。”

这看起来像原文的错误，但翻译应保留。

$+6$ 态是优选的，但 $-2, +3, +4, +5, +6$ 的所有态都是已知的。态通常以各种氧化数 $(+4$ 到 $+6)$ 存在，并包括聚合物配合物和金属-金属键，在金属簇中其金属核心含有两个到六个金属原子。钼与氧形成大量化合物。低价钼，例如 $\mathrm{Mo(CO)}_6$ 和 $\mathrm{Mo}_3$，具有非常丰富的有机金属化学，包括作为钼金属表面的模型而被研究的簇，这些模型催化用于工业合成和石油精炼的有机反应。钼原子改变氧化态、配位数和配位几何形状以及在簇中形成金属-金属键的能力部分解释了含 Mo 原子的工业催化剂和生物酶的数量，这些 Mo 原子位于催化的活性位点。参见：化学键；配位化学；电子构型。

钼是一种高熔点的银灰色金属，即使在高温下也很强，坚硬且耐腐蚀（见表）。它还表现出高导电性、高弹性模量、高热导率和低膨胀系数。其主要用途是合金钢，例如作为工具钢（$\leq 10\%$ 钼）、不锈钢和装甲板。铸铁中添加多达 3% 的钼以增加强度。铁、钴和镍基合金中可以添加多达 30% 的钼，设计用于严酷的高温耐腐蚀应用。它可用于灯泡灯丝，并在电子电路中有许多应用。参见：合金；铁合金；不锈钢。
