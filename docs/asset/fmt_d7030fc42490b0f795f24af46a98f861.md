
## 描述

`/etc/passwd` 是用户账户信息的本地源。密码文件可以与其他密码源配合使用，包括 NIS 映射 `passwd.byname`、`passwd.bygid` 以及 NIS+ 表 `passwd`。程序使用 `getpwnam(3)` 例行程序来访问这些信息。

每个 `passwd` 条目都是单行，格式如下：

```
username:password:uid:gid:gcos-field:home-dir:login-shell
```

`username`
