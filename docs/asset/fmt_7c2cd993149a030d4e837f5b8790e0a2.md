
```python
>>> a = "Your name is {name} and your age is {age}"

>>> a.format("Mike", age=40)

'Your name is Mike and your age is 40'

>>>
```

在特殊格式字符串中，`{item}` 还可以包含索引和属性查找。占位符 `{item[n]}`（`n` 为数字）对 `item[key]` 执行序列查找（其中 `key` 是非数字字符串），则返回 `item["key"]` 的字典查找。占位符 `{item.attr}` 指向 `item` 的属性。关于 `format()` 的更多细节可以可以在第 4 章的“字符串格式化”部分。

## range() 对象

`may`可以取负值，在这种情况下，索引将从字符串末尾开始计算。

`s.translate()` 方法用于执行高级字符替换，速度快于剥离字符串中的所有字符。作为参数，它接受一个翻译表，其中包含原始字符串中字符到字符的一一一映射。对于 8 位字符串，翻译表是一个 256 个字符的字符串。对于 Unicode，翻译表可以是任何序列 `s`，其中 `s[n]` 返回一个整数字符码或与值为 `n` 的 Unicode 字符对应的 Unicode 字符。

`s.encode()` 和 `s.decode()` 方法用于在字符串数据与指定的编码之间转换。作为输入，它们接受编码名称，如 `'ascii'`、`'utf-8'` 或 `'utf-16'`。这些方法通常用于将 Unicode 字符串转换为用于 I/O 操作的数据编码，并在第 9 章“输入与输出”中进一步描述。在 Python 3 中，`encode()` 仅适用于字符串，而 `decode()` 仅适用于 `bytes` 数据类型。

`s.format()` 方法用于执行字符串格式化。作为参数，它接受位置参数和关键字参数的任何组合。`s` 中由 `{item}` 表示的占位符会被相应的字符串替换。位置参数可以使用 `{0}` 和 `{key}` 等占位符引用。关键字参数使用带有名称的占位符如 `{name}`。例如：

```python
>>> a = "Your name is {name} and your age is {age}"

>>> a.format("Mike", age=40)

'Your name is Mike and your age is 40'

>>>
```
