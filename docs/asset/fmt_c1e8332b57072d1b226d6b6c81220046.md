## 2.6.5 用户身份验证

如果在之前的安装步骤中已成功配置了网络访问，您现在有两种不同的方式来管理系统上的用户账户。

### 本地用户管理

使用此方法，用户是在本地（即已安装的机器）上管理的。这是独立工作站的典型解决方案。

### 使用 NIS 或 LDAP 进行用户管理

此方法主要用于组织内部，以部门为单位管理工作站。整个部门的用户管理在中央主机或名称服务器上进行，这使得创建本地账户变得不再必要。事实上，选择这种方法可能是因为本地账户是不不可取的。

如果满足所有要求，YaST 将打开一个对话框，在其中选择用户管理方法。如图 2.16 所示。如果您没有必要的网络连接，请创建本地用户账户。

## 2.6.7 创建本地用户账户

在本地创建用户账户时，任何与用户账户相关的数据（名称、登录名、密码等）都存储并管理在此主机上。Linux 是一个允许多个用户同时在系统上工作的操作系统。每个用户都需要一个用户账户来登录系统。通过使用用户账户，系统的安全性大大提高。普通用户无法更改或删除系统运行所需的文件。同样，特定用户的个人数据不能被其他用户修改、查看或篡改。每个用户都可以设置自己的工作环境，并在重新登录时发现该环境保持原样。

![](img/705a076b108ea96be0c0695efb5556ce_59_0.png)

可以使用图 2.18 所示的对话框创建用户账户。在输入名和姓后，指定用户名（登录名）。如果您想不起合适的用户名，请点击“建议”（Suggestion）让系统自动生成一个。

最后，为用户输入密码。重新输入以进行确认（确保您没有不小心输入其他内容）。用户名告诉系统谁是用户，而密码则用于验证此身份。

## 注意事项

> 请记住您的用户名和密码，因为您每次登录系统时都需要它们。

为了提供有效的安全性，密码长度应在五到八个字符之间。密码的最大长度为 128 个字符。然而，如果没有加载特殊的安全模块，仅使用前八个字符来区分密码。密码区分大小写。不允许使用变音符号（umlauts）等特殊字符。允许其他特殊字符（7 位 ASCII）和数字 0 到 9。

本地用户有两个：

- 通过电子邮件接收系统消息：勾选此框将发送系统服务创建的用户消息。这些消息通常只发送给 root（系统管理员）。此选项对于经常使用的用户账户有用，因为强烈建议仅在特殊情况下以 root 身份登录。
- 自动登录：此选项仅在使用 KDE 作为桌面时可用。它会在系统启动时自动登录当前用户。这对于仅由一人操作的计算机非常有用。

> 注意
> 使用自动登录启动时不进行身份验证。对于包含敏感数据或他人可以使用的系统，不要勾选此选项。

## 3.2 自动修复

此方法最适用于修复原因不明的损坏系统。选择此项将开始对已安装系统进行广泛分析，由于测试和检查数量巨大，这将需要一些时间。程序的进度将在屏幕底部通过两个进度条显示。上方进度条显示当前正在运行的测试进度。下方进度条显示分析过程的整体进度。日志窗口允许上方跟踪当前运行的活动及其测试结果。见下页的图 3.2。每次运行都会执行以下主要测试。这些测试又包含许多单独的子测试。

- 所有硬盘的分区表：检查所有检测到的硬盘的分区表的有效性和一致性。
- 交换分区：检测、测试已安装系统的交换分区，并在适用时提供激活建议。为了提高系统修复速度，应当接受该建议。
- 文件系统：对所有检测到的文件系统进行特定于文件系统的检查。
- 文件 `/etc/fstab` 中的条目：检查文件中条目的完整性和一致性。挂载所有有效分区。
- 启动加载程序配置：检查已安装系统的启动加载程序配置（GRUB 或 LILO）的完整性和一致性。检查启动设备和根设备，并检查 initrd 模块的可用性。
- 软件包数据库：检查是否存在运行最小化安装所需的所有包。虽然可以选择也分析基础软件包，但由于其数量巨大，这需要花费很长时间。

每当遇到错误时，程序停止并打开对话框提供详细信息和可能的解决方案。无法描述所有这些情况。请仔细阅读屏幕上的通知，并从列表选项选择所需的操作。在有疑问的情况下，也可以拒绝建议的修复操作。在这种情况下，系统将保持不变，且在没有提示用户的情况下不会执行任何修复。

## 3.3 用户定义修复

前节介绍的自动修复会分分类地执行所有测试。这在系统损坏程度未知时很有用。然而，如果你已经知道系统的哪个部分受影响，可以缩小应用测试的范围。选择“用户定义”将显示测试运行列表，所有测试最初都被标记为执行。测试的总范围与自动修复相同。如果你已经知道哪里没有损坏，可以取消标记相应的测试。点击“继续”将启动一个范围较窄的测试程序，其运行时间可能会显著缩短。

并不是所有测试组都可以单独适用。对 fstab 条目的分析始终取决于对文件系统的检查，包括现有的交换分区。YaST 通过选择最少必要的测试运行来自动满足此类依赖关系。

## 3.4 专家工具

如果你熟悉 SUSE LINUX 并且已经清楚地知道你的系统中需要修复的内容，请通过选择“专家工具”直接应用修复系统所需的工具。
