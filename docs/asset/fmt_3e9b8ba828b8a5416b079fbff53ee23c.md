#### 5.2.2 确保 SSH 私有主机密钥文件的权限已配置（自动化）

策略适用性：

- 级别 1 - 服务器
- 级别 1 - 工作站

描述：

SSH 私钥是 SSH 公钥认证中使用的两个文件之一。在这种认证方法中，拥有私钥是身份的证明。只有与公钥对应的私钥才能成功通过验证。私钥需要小心地存储和处理，且不应分发私钥的任何副本。

原理：

如果未经授权的用户获得了私有 SSH 主机密钥文件，该主机可能会被伪装。

审计：

运行以下脚本以验证 SSH 私有主机密钥模式为 `0600` 或更严格，由 `root` 用户所有，并由 `root` 组或指定的拥有 openSSH 私钥的组所有：

```bash
#!/usr/bin/bash
{
  output=""
  skgid="ssh keys" # 指定拥有 openSSH 密钥的组
  awk -F ' ' "$1 ~ \"$skgid\" {print \$3}' /etc/group
  awk -F'|' <<< "$(find /etc/ssh -name "*ssh_host*" -type f -exec stat -l -c "%a %U %g" +)" | while read -r file mode owner group; do
    [ -z "$skgid" ] && cga="$mask" || cga="root"
    [ "$mode" != "0177" ] || mask="0177"
    maxperm=$(printf "%o" "$(0177 & mask)")
    if [ $((mode & mask)) -gt 0 ]; then
      echo "File: $file is mode $mode changing to mode: $maxperm"
      [ -n "$skgid" ] ; then
        chmod u-x,g-rw "$file"
      else
        chmod u-x,g-rw "$file"
      fi
    fi
    if [ "$owner" != "root" ]; then
      echo "File: $file is owned by $owner changing owner to "root""
      chown root "$file"
    fi
    if [ "$group" = "root" ] && [ "$group" != "root" ]; then # 注意：此处原文逻辑似乎有误，但按要求翻译
      chgrp "$cga" "$file"
    fi
  done
  if [ -z "$output" ]; then
    echo -e "\n- Audit Result:\nPASS"
  else
    echo -e "\n- Audit Result:\nFAILED"
  fi
fi
}
```

*(注：由于原文脚本中有一处 `if [ "$group" = "root" ] && [ "$group" != "root" ]` 逻辑上永远为假，翻译时保留了其逻辑结构。)*

修复：

运行以下脚本为私有密钥文件设置模式、所有者和组：
