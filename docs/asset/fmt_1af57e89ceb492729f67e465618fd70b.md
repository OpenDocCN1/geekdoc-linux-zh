# 关于作者

William Shotts 是 Media Cybernetics LLC 前技术服务副总裁。现已退休，他于1978年获得第一台电脑时开启了他的计算职业。从那时起，他一直担任教师、摄影师、程序员以及技术经理，管理着由技术支持专家、软件质量保证测试人员、系统管理员和技术作家组成的多元化团队。他获得锡拉库大学工业设计学士学位。自1996年以来一直是 Linux 用户和倡导者，也是 LinuxCommand.org 的创始人。

# 关于技术评审

Mitch Frazier 是一位在美森电气工作的程序员，主要从事 C 语言嵌入式系统编程。他偶尔也使用 Golang、Python、Tcl、JavaScript 编写代码。他曾在《Linux Journal》担任技术编辑和系统管理员。
