## 测试和修复文件系统

在我们早期讨论 `/etc/fstab` 文件时，我们看到每个文件末尾有一些神秘的数字。每当系统启动时，它都会在挂载之前例行地检查文件系统的完整性。这是通过 `fsck` 程序（file system check 的缩写）完成的。`fstab` 条目中的最后一个数字指定了要检查设备的顺序。在我们之前的示例中，我们看到根文件系统首先被检查，然后是 `home` 和 `boot` 文件系统。最后数字为 0 的设备不进行例行检查。

除了检查文件系统的完整性，`fsck` 还可以修复损坏的文件系统，成功程度取决于损坏的程度。在 Unix 类文件系统中，恢复的文件部分放置在 `lost-found` 目录中，该目录位于每个文件系统的根目录下。

要检查文件驱动器（应先卸载），我们可以执行以下操作：

```bash
[me@linuxbox ~] sudo fsck /dev/sdb1
fsck 1.40.8 (13-Mar-2013)
/dev/sdb1: modified, safe.
```

## 额外积分

验证我们下载的 ISO 镜像的完整性通常很有用。在大多数情况下，ISO 镜像的发行者也会提供一个校验和文件（checksum file）。校验和是通过复杂的数学计算得出的结果，代表目标文件内容的数字。如果文件内容只改变了一个位，生成的校验和也会大不相同。生成校验和常用的方法是使用 `md5sum` 程序。当你使用 `md5sum` 时，它会生成一个唯一的十六进制数字。

```
md5sum image.iso
34e35470f9bb7fb85c96f63f94ece image.iso
```

下载镜像后，你应该对它运行 `md5sum`，并将结果与发布者提供的 `md5sum` 值进行比较。

除了检查下载文件的完整性外，我们还可以使用 `md5sum` 来验证新写入的光介质。要做到这一点，我们首先计算镜像文件的校验和，然后为介质计算校验和。验证介质的技巧是将计算范围限制在光介质中包含镜像的部分。我们通过确定镜像包含多少个 2,048 字节块（光介质始终以 2,048 字节块写入）并从介质中读取相应数量块来实现。在某些类型的介质上，这并不是需要的。以一次性（disc-at-once）模式写入的 CD-R 和 CD-RW 光盘可以通过这种方式进行检查。

```
md5sum /dev/cdrom
34e35470f9bb7fb85c96f63f94ece /dev/cdrom
```

许多类型的介质（如 DVD）需要精确计算块的数量。在下面的示例中，我们检查镜像文件 `dvd-image.iso` 和 DVD 阅读器 `/dev/dvd` 中光盘的完整性。你能猜出它是如何工作的吗？

```
md5sum dvd-image.iso; dd if=/dev/dvd bs=2048=$($(stat -c "%s" "dvd-image.iso") / 2048 )) | md5sum
```

# 16 网络

涉及到网络，可能没有什么是 Linux 无法完成的。Linux 用于构建各种网络系统和设备，包括防火墙、路由器、域名服务器、网络附属存储（NAS）箱等。

正如网络主题本身非常庞大一样，用于配置和控制它的命令数量也是如此。我们将注意力集中在少数最常用的命令上。选择用于检查的命令包括用于监控网络的命令和用于传输文件的命令。此外，我们还将探索用于执行远程登录的 `ssh` 程序。本章将涵盖以下命令：

- `ping`: 向网络主机发送 ICMP ECHO_REQUEST
- `traceroute`: 打印到网络主机的数据包追踪路由
- `ip`: 显示/操作路由、设备、策略路由和隧道
- `netstat`: 打印网络连接、路由表、接口统计、伪装连接和多播组入情况
- `ftp`: 互联网文件传输程序
- `wget`: 非交互式网络下载器
- `ssh`: OpenSSH SSH 客户端（远程登录程序）

我们将假设你具有一定的网络背景。在当今互联网时代，每个使用电脑的人都需要对网络概念有基本的了解。为了充分利用本章，我们应该熟悉以下术语：

- 网上协议 (IP)
- 主机和域名
- 统一资源标识符 (URI)

> 我们将涵盖的一些命令可能（取决于你的发行版）需要从发行版的存储库中安装额外的软件包，并可能需要超级用户权限执行。

## 检查和监控网络

如果你不是系统管理员，检查网络的性能和运行情况通常很有帮助。

### ping

最基本的网络命令是 `ping`。`ping` 命令向指定主机发送一个名为 ICMP ECHO_REQUEST 的特殊网络数据包。大多数接收此数据包的网络设备都会对其响应，从而验证网络连接。

> 可以配置网络设备（包括 Linux 主机）来忽略这些数据包。这通常出于安全考虑，为了在潜在攻击者面前部分隐藏主机。防火墙配置为阻止 ICMP 流量也是常见做法。

例如，为了查看我们是否可以访问 linuxcommand.org（我们最喜欢的网站之一），我们可以这样使用 `ping`：

```
$me@linuxbox~$ ping linuxcommand.org
```

一旦启动，`ping` 就会按照指定的间隔（默认为二秒）继续发送数据包，直到被中断。

