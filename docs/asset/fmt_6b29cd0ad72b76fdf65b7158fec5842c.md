## `pclose` 是必须的

当你完成对 `popen` 创建的连接的操作，使用 `pclose` 而不是 `fclose`。进程需要等待，否则它会变成僵尸。`pclose` 会调用 `wait`。

## 11.4.2 编写 `popen`：使用 `fdopen`

`popen` 如何工作的，我们如何编写它？`popen` 运行一个程序并返回该程序标准输入或标准输出的连接。

我们需要一个新进程来运行程序，因此我们使用 `fork`。我们需要与该进程建立一个连接，因此我们使用 `pipe`。我们需要将一个文件描述符转换为缓冲流，因此我们使用 `fdopen`。最后，我们需要能够在该进程中运行任何 shell 命令，我们使用 `exec`，但我们要执行什么呢？唯一能运行任何 shell 命令的程序是 shell 本身：`/bin/sh`。方便的是，`sh` 支持 `-c` 选项，告诉 shell 运行命令并退出。例如：

## 11.4 `popen`: 让进程像文件

```c
FILE *fdopen(), *fp;               /* fdopen 创建一个 fd 流 */
int parent_end, child_end;         /* 管道的 */

if (*mode == 'r') {                /* 确定方向 */
    parent_end = READ;
    child_end = WRITE;
} else if (*mode == 'w') {
    parent_end = WRITE;
    child_end = READ;
} else return NULL;

if (pipe(pfp) == -1) {             /* 获取管道 */
    return NULL;
}

if ((pid = fork()) == -1) {        /* 以及一个进程 */
    close(pfp[0]);
    close(pfp[1]);
    /* 释放管道 */
    return NULL;
}

/* -------------------------------------- */
/* 父进程代码在此 */
/* 需要关闭一端并 fdopen 另一端 */

if (pid > 0) {
    if (close(pfp[child_end]) == -1) {   /* -1 */
        return NULL;
    }
    return fdopen(pfp[parent_end], mode); /* 相同的模式 */
}

/* -------------------------------------- */
/* 子进程代码在此 */
/* 需要重定向 stdin 或 stdout 然后执行 cmd */

if (close(pfp[parent_end]) == -1) {      /* 关闭另一端 */
    exit(1);                             /* 不要返回 */
}

if (dup(pfp[child_end], child_end) == -1) { /* -1 */
    exit(1);
}

if (close(pfp[child_end]) == -1) {        /* 完成这一个 */
    exit(1);
}

execl("/bin/sh", "sh", "-c", command, NULL); /* 全部准备好运行 cmd */
exit(1);
```
