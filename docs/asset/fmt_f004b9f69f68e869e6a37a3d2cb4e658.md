## 8.3.2 控制应用程序服务器

WebSphere Application Server 包含多个命令行工具，用于启动、停止和监控 WebSphere Application Server 进程和节点。这些工具在本地服务器和节点上运行，无法在远程服务器或节点上操作。在前面的节中，您已经学会使用 `wsadmin` 工具作为命令行工具安装应用程序。现在我们将展示如何在没有管理员控制台的情况下启动和停止应用程序服务器。
