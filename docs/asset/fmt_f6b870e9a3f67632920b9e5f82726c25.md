
# 第 08 章 / 模式匹配

## 字符类（Character Classes）
字符类用于匹配特定类型的字符。方括号用于创建字符类。例如，你可以使用 `m/[0123456789]/` 匹配任何数字。这匹配 0 到 9 范围内的单个字符。你可以在本章节后的“字符类”部分找到更多关于字符类的信息。

## 符号字符类（Symbolic Character Classes）
有几个字符类的使用非常频繁，以至于它们拥有符号表示。点元字符 (`.`) 代表一个特殊的字符类，匹配除换行符以外的所有字符。其余的是 `\d`、`\D`、`\s`、`\S`、`\w` 和 `\W`。这些在前面的表 8.7 中提到，并在本章节后的“字符类”部分进行了讨论。

`\s` 此符号匹配任何空格、制表符或换行符。等同于 `[\t \n]`。
`\S` 此符号匹配任何非空白字符。它等同于 `[^\s]`。
`\d` 此符号匹配任何数字。等同于 `[0-9]`。
`\D` 此符号匹配任何非数字字符。等同于 `[^0-9]`。

你可以在其他字符类中使用这些符号，但不能作为范围的端点。例如，你可以执行以下操作：

```
$_ = "\tAAA";
print "matched" if m/[\d\s]/;
```

显示为：

```
matched
```

因为 `$_` 的值包含制表符。

> 出现在定义字符类的方括号内部的元字符是以其字面意思使用的。它们失去了它们的元特殊含义。这在起初可能会有点让人困惑。事实上，在评估模式时，我倾向于忘记这一点。

> 我认为，关于正则表达式的大多数困惑在于，模式中的每个字符都可能有几种可能的含义。脱字符符号可以是锚点，也可以用于取反字符类。因此，在给任何给定的模式字符或符号分配意义之前，确定它处于哪种语文中是至关重要的。

## 锚点（Anchors）
脱字符 (`^`) 和美元符号 (`$`) 元字符用于将模式锚定在搜索字符串的开头和结尾。除非使用了分支元字符，否则字符总是模式中的第一个字符。例如，`m/^one/;` 仅当搜索字符串以序列 `one` 开头时才匹配。美元符号作为锚点时，始终是模式中的最后一个字符。例如，`m/(last|end)$/;` 仅当搜索字符串以序列 `last` 或字符序列 `end` 结尾时才匹配。`\A` 和 `\Z` 元序列也用作字符串开头和结尾的锚点。

## 量词（Quantifiers）
有几个元字符专门用于控制匹配字符的数量。例如，`m/a{5}/` 表示在返回真结果之前必须找到五个字符。`*`、`+` 和 `?` 元字符以及大括号都用作量词。请参见本章节后的“量词”部分获取更多信息。

Perl 提供了几种不同的量词，允许你指定在匹配成功之前给定组件必须出现多少次。它们在你预先不知道需要匹配多少字符时使用。表 8.8 列出了可以使用的不同量词。

### 表 8.8 六种类型的量词

| 量词 | 描述 |
|---|---|
| * | 组件必须出现 0 次或多次。 |
| + | 组件必须出现一次或多次。 |
| ? | 组件必须出现 0 次或一次。 |
| {n} | 组件必须出现 `$n$` 次。 |
| {n,} | 组件必须至少出现 `$n$` 次。 |
| {n,m} | 组件必须至少出现 `$n$` 次且超过 `$m$` 次。 |

如果你需要匹配一个长度未知的单词，你需要使用 `+` 量词，因为长度为 0 的单词是没有意义的。所以，匹配语句可能像这样：

```
m/^\w+/;
```

此模式匹配 `OOO` 和 `AAAAA`，但不匹配 `""` 或 `BBB`。为了考虑到可能在或不在字符串开头的领先空白，你需要按照以下方式将星号 (`*`) 量词与 `\s` 符号字符类结合使用：

```
m/\s*\w+/;
```

## 模式内存（Pattern Memory）
括号用于将匹配的内容存储到缓冲区中以便以后回溯。我喜欢将此视为模式内存的一种。某些程序员称之为反向引用（back-references）。当你使用 `m/(fish|fowl)/;` 匹配字符串并找到后，变量 `$1` 将持有 `fish` 或 `fowl`，取决于匹配了哪一个序列。请参见本章节后的“模式内存”部分获取更多信息。

## 单词边界（Word Boundaries）
`\b` 元序列匹配空格与单词第一个字符之间的边界，或者单词最后一个字符与空格之间的边界。如果字符串没有领先或尾随空格，`\b` 匹配字符串的开头。例如，`m/\bfoo/;` 即使单词周围没有空格也能匹配 `foo`。它匹配 `$foo` 是因为美元符号不被视为单词字符。语句 `m/foo\b/;` 匹配 `foo` 但不匹配 `foobar`；语句 `m/\bwiz/;` 匹配 `wizard` 但不匹配 `geewiz`。请参见本章节后的“字符类”部分获取更多关于单词边界的信息。

`\B` 元片段匹配单词边界以外的所有位置。

## 引用元字符（Quoting Metacharacters）
你可以通过将元字符包含在 `\Q.\E` 序列中进行字面匹配。这可以让你避免使用反斜杠来转义所有元字符，并使你的代码更容易读。

## 扩展语法（Extended Syntax）
`(...)` 序列允许你使用正则表达式语法的扩展版本。不同的选项在本章节后的“示例：扩展语法”部分进行了讨论。
