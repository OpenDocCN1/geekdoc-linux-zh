
### 步骤 2
但是，你也可以在代码行的末尾添加注释，以更好地描述正在发生的事情：

```cpp
cout << "Hello, world!\n"; //This line outputs the words "Hello, world". The \n denotes a new line.
```

请注意，你不需要在注释末尾加分号。这是因为注释是被编译器忽略的代码行。

![](img/d501697c83491ed0bb4b382b0d28ef0a_130_1.png)

### 步骤 3
使用正斜杠和星号可以注释多行代码：

```cpp
/* This comment can
 * cover several lines
 * without the need to add more slashes */
```

切记要用相反的星号和正斜杠结束块注释。

![](img/d501697c83491ed0bb4b382b0d28ef0a_130_2.png)

### 步骤 4
注释时要小心，特别是块注释。很容易忘记添加闭合的星号和正斜杠，从而导致位于注释块内的代码失效。

![](img/d501697c83491ed0bb4b382b0d28ef0a_130_3.png)

### 步骤 5
显然，如果你尝试编译并执行代码，它会报错，抱怨缺少花括号 `}` 来结束代码块。如果你犯过几次这种错误，回去修正会很耗时。幸运的是，Geany 的颜色编码有助于区分注释和代码。

![](img/d501697c83491ed0bb4b382b0d28ef0a_130_4.png)

### 步骤 6
对于块注释，在 C++ 中良好的实践是在注释块的每一新行添加一个星号。这也有助于你记得在继续编写代码之前关闭注释块：

```cpp
/* This comment can
 * cover several lines
 * without the need to add more slashes */
```

幸运的是，Geany 会自动完成这一点，但在使用其他 IDE 时要注意这一点。

![](img/d501697c83491ed0bb4b382b0d28ef0a_130_5.png)

# 变量

在 C++ 中使用变量与在 Python 中略有不同。在 Python 中，你只需声明 'a' 等于 10，变量就会被赋值。然而，在 C++ 中，变量必须先声明其类型才能被使用。

## 变量的声明

你可以通过代码中的语句来声明 C++ 变量。有几种不同类型的变量可以声明。以下是具体操作方法。

### 步骤 1
打开一个新的空白 C++ 文件，输入常规的代码头：

```cpp
#include <iostream>
using namespace std;

int main()
{
}
```

![](img/d501697c83491ed0bb4b382b0d28ef0a_131_0.png)

### 步骤 2
从简单开始，创建两个变量 `a` 和 `b`，一个赋值为 10，另一个为 5。你可以使用数据类型 `int` 来声明这些变量。在花括号内输入：

```cpp
int a;
int b;

a = 10;
b = 5;
```

![](img/d501697c83491ed0bb4b382b0d28ef0a_131_1.png)

### 步骤 3
你可以编译并运行代码，但除了将值 10 和 5 存储到整数 `a` 和 `b` 中，它不会做太多事。忽略关于变量已设置但未使用的警告，代码仍然可以工作。为了输出变量的内容，添加：

```cpp
cout << a;
cout << "\n";
cout << b;
```

`cout << "\n";` 部分仅在 10 和 5 的输出之间插入一个新行。

![](img/d501697c83491ed0bb4b382b0d28ef0a_131_2.png)

### 步骤 4
当然，你可以声明一个新变量，命名为 `result`，并输出简单的算术运算：

```cpp
int result;
result = a + b;
cout << result;
```

按照截图将上述代码插入到代码中。

![](img/d501697c83491ed0bb4b382b0d28ef0a_131_3.png)

## 步骤 5

你可以在声明变量的同时为其赋值。你之前输入的代码看起来可能像这样。反之：

```cpp
int a = 10;
int b = 5;
int result = a + b;

cout << result;
```

![](img/d501697c83491ed0bb4b382b0d28ef0a_132_0.png)

## 步骤 6

就 C++ 而言，你在使用声明变量的同时为其赋值时，也可以使用以下写法：

```cpp
int a (10);
int b (5);
```

然后，从 C++11 标准开始，可以使用花括号：

```cpp
int result = {a+b};
```

![](img/d501697c83491ed0bb4b382b0d28ef0a_132_1.png)

## 步骤 7

你可以创建全局变量，这些变量是在任何函数外部声明的，并且可以在整个代码中的任何函数内使用。你目前所使用的都是局部变量：即在函数内部使用的变量。例如：

```cpp
#include <iostream>
using namespace std;
int StartLives = 3;

int main()
{
    StartLives = StartLives - 1;
    cout << StartLives;
}
```

![](img/d501697c83491ed0bb4b382b0d28ef0a_132_2.png)

## 步骤 8

上一步创建了变量 `StartLives`，它是一个全局变量。例如在游戏中，玩家的生命值会根据其表现好坏而增减。当玩家重新开始游戏时，`StartLives` 会恢复到其默认状态。在这里，我们将生命值设为 3，然后减去 1，剩下 2 条命。

![](img/d501697c83491ed0bb4b382b0d28ef0a_132_3.png)

## 步骤 9

现代 C++ 编译器比大多数程序员给予其的赞誉要智能得多。虽然我们可以为变量声明许多不同的数据类型，但你可以直接使用 `auto` 特性：

```cpp
#include <iostream>
using namespace std;
auto pi = 3.141593;

int main()
{
    double area, radius = 1.5;
    area = pi * radius * radius;
    cout << area;
}
```

![](img/d501697c83491ed0bb4b382b0d28ef0a_132_4.png)

## 步骤 10

尽管我们在步骤 3 中提到忽略警告，但警告和错误之间存在区别。在这种情况下，它只是一个简单的警告。新的数据类型 `double` 意味着双精度浮点值，这使得代码更加精确。结果应该是 7.06858。基本上，你可以处理警告，但不能处理错误。

![](img/d501697c83491ed0bb4b382b0d28ef0a_132_5.png)

## 数据类型

如前所述，变量存储信息，程序员随后可以调用这些信息进行操作（如有需要）。变量仅仅是保留的内存位置，存储程序员根据所使用的数据类型分配的值。

### 数据的价值

C++ 为程序员提供了许多不同的数据类型，例如整数、浮点数、布尔值、字符等。普遍认为有七种基本数据类型，通常称为“原始内置类型”；但是，如果代码中出现需求，你可以创建自己的数据类型。

| 类型 | 命令 |
| :--- | :--- |
| 整数 | int |
| 浮点数 | float |
| 字符 | char |
| 布尔值 | bool |
| 双精度浮点数 | double |
| 宽字符 | wchar_t |
| 无值 | void |

这些基本类型也可以使用以下修饰符进行扩展：长整型 `Long`、短整型 `Short`、有符号 `Signed` 和无符号 `Unsigned`。基本上，这意味着修饰符可以扩展每种数据类型的最小值和最大值范围。例如，`int` 数据类型的默认值范围是 -2147483648 到 2147483647，这是一个相当不错的范围，你会同意的。

现在，如果你使用其中一种修饰符，范围会改变：

- 无符号 int `Unsigned int` = 0 到 4294967295
- 有符号 int `Signed int` = -2147483648 到 2147483647
- 短整型 `Short int` = -32768 到 32767
- 无符号短整型 `Unsigned Short int` = 0 到 65,535
- 有符号短整型 `Signed Short int` = -32768 到 32767
- 长整型 `Long int` = -2147483647 到 2147483647
