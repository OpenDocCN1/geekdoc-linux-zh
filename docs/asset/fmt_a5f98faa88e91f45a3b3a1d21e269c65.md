
## mount 命令

`mount` 命令列出挂载的文件系统。文件系统使用逻辑块设备名称标识，如下列表所示：

```
15. /isa/asy@1,3f8" 0 asy

16. /isa/fdc1,3f0" 0 fdc

17. /isa/fdc1,3f0/fd@0,1" 1 fd

18. /isa/fdc1,3f0/fd@0,0" 0 fd

19. /options@" 0 options

20. /objmgr@" 0 objmgr

21. /pseudo@" 0 pseudo
```
