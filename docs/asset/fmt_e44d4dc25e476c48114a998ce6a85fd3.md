
你渲染的立面看起来会有些单调。你可以添加喷泉、汽车、周围物体和人物为图像注入生命。在渲染中增加景观、人物和汽车被称为“环境”（`entourage`）。你稍后可以在图像编辑程序中为静态图像添加环境（见第7章），或者你可以在模型中包含树和人物与建筑一同渲染。

# 渲染阴影研究

使用`VIZ`动画工具的另一个好方法是创建阴影研究。在某些情况下，项目可能需要建筑的阴影研究，以确保其阴影不会影响附近的景观特征或另一栋建筑。你可能还需要创建阴影研究来分析建筑的热增益和能量消耗。`Daylight System`工具结合动画工具可以快速完成此类任务。

在下面的章节中，你将学习如何使用动画功能创建随时间变化的影子静态图和动画。

## 调整正北

第11章向你展示了如何将日光系统（`Daylight System`）放入场景中。我们将不再重复这些指令，而是使用一个已经为你放置好日光系统的文件。`Shadowstudy.max`文件在场景中放置了一个日光系统，太阳位置设置为`2008`年`9`月`21`日下午`2`点，地点位于法国巴黎。目前尚未对正北进行调整，因此你需要相对于建筑正确对准太阳方向。对于这栋别墅，正北实际上位于顶部视图（`Top viewport`）的左下角。你可以改变指南针的方向，从而改变项目场地的正北方向。

1. 打开`Shadowstudy.max`文件。
2. 点击主工具栏中的“按名称选择”（`Select by Name`），从列表中选择`[Daylight01]`。
3. 点击命令面板中的“运动”（`Motion`）选项卡，如有必要，关闭控制参数（`Control Parameters`）展开组顶部的“手动覆盖”（`Manual Override`）设置。此选项可以锁定和解锁控制参数设置。
4. 滚动到控制参数展开组的“站点”（`Site`）组。
5. 将“北方向”（`North Direction`）设置改为`225`。你会看到指南针和阳光方向的方向和位置发生变化，以反映新的方向。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_708_0.png)

“北方向”设置将值解释为顺时针方向的角度，因此若要让正北直接指向正`X`轴方向，应输入`90`。北方向输入框不接受负值，所以要让正北指向顶部视图的左下角，你需要输入`225`。

现在让我们为阴影研究设置一些时间。假设你想查看从`6`点开始、每隔`3`小时的阴影。你可能需要在`6`点之前设置第一个小时，以防你想创建一个光照的动画研究。

1. 选中`Daylight01`系统，将控制参数展开组中“时间”（`Time`）组的“小时”（`Hours`）参数设置为`3`。
2. 点击“自动关键帧”（`Auto Key`）按钮将其关闭。
3. 将时间滑块移动到第`70`帧并将“小时”改为`21`。注意，所有与时间相关的数值框都会变为红色，显示它们已设置了关键帧。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_708_1.png)

4. 关闭自动关键帧模式。

现在你有一段时间范围，可以用它来生成单幅或两秒的动画，显示`2008`年`9`月`21`日阴影在地面上的移动。在创建研究渲染图之前，你还需要调整一个细节。

## 将 IES 太阳更改为标准光

你可能在第11章中记得，日光系统使用的是`IES`太阳，这是一种光度光。这种光在不配合辐射度渲染器（`radiosity renderer`）使用时会产生粗糙的阴影。当你使用默认阴影渲染器时，希望将日光系统从`IES`太阳改为定向光（`directed light`），以获得平滑均匀的阴影。

1. 点击“修改器”（`Modifier`）选项卡。
2. 在日光参数（`Daylight Parameters`）展开组中，将阳光（`Sunlight`）下拉列表中的`IES`太阳更改为“标准”（`Standard`）。

| 日光参数 | |
|---|---|
| 阳光 | 激活 (Active) |
| 标准 | |

3. 你不需要天光（`Skylight`）选项，因此在日光参数展开组中关闭天光的“激活”选项。

## 在视口中更改相机尺寸

如果你的相机比希望的尺寸大，可以使用偏好设置（`Preference Settings`）对话框中视口选项卡中的非缩放对象大小（`Non-scaling Object Size`）选项来更改它们的尺寸。这将更改所有相机的大小以及所有其他非缩放对象，例如灯光图标和组装头组件（`Assembly Head gizmos`）。

## 创建漫游

相机应位于地面上方`16`英尺处，这样它就处于二楼的高度。然而，你无法移动相机，因为它的位置现在由它被指定的跟随路径的位置控制。你移动的是路径。

1. 在路径控制（`Path Control`）部分，点击选取路径（`Pick Path`）按钮；然后选择你在第`1`步中绘制的`Walkthroughpath`形状。相机移动到指定路径上的顶点。
2. 在路径控制（`Path Control`）部分，将视角高度（`Eye Level`）值设置为`16'`；然后勾选移动路径到视线（`Move Path to Eye`）选项。路径和相机的高度会发生变化。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_713_0.png)

## 调整相机朝向

漫游（`Walkthrough`）将路径约束（`Path Constraint`）设置为决定相机位置的控制器，它是基于沿路径的百分比。当应用路径约束时，相机会随着路径的移动而移动，其朝向会转向路径的方向。路径约束控制对象的位置，默认情况下，相机的朝向遵循路径。你可以选择对其朝向设置关键帧，以便在任何时间点自定义你所看到的视图。

1. 将时间滑块从第`0`帧拖到第`600`帧。观察`WalkthroughCamera`如何遵循它所约束的路径移动，并在第`600`帧到达线条的终点。
2. 在`Camera.View3DFR`视口中点击右键以激活它。在漫游视图（`Walkthrough View`）对话框的相机部分，将视口设置为相机（`Set Viewport to the Camera`）。`Walkthrough_Cam01`视图现在占据视口。

## 使用多路径

使用路径约束（`Path Constraint`）控制器，你可以为对象分配多个形状作为跟随的路径。当选择多个形状时，每个形状都会被赋予一个权重，该权重决定了它们对对象运动的影响力。例如，如果将弧线和直线都分配为相机（或任何其他对象）移动的路径，其中弧线的权重为`10`而直线的权重为`2`，则对象将无法完美地遵循任何一条路径。它将以比直线五倍的程度遵循弧线，创建出一条有些扁平的轨迹。如果交换权重，轨迹将非常直，但带有一个凸起，表示弧线的影响较小。

1. 在视口中选择相机，然后点击命令面板的运动（`Motion`）选项卡。确保`PRS`参数（`PRS Parameters`）展开栏底部选中了位置（`Position`），并向下滚动到路径参数（`Path Parameters`）展开栏。

该展开栏中有几个重要的选项，定义了分配给路径约束的对象的运动。默认勾选的跟随（`Follow`）选项决定了相机是否改变朝向以匹配路径的切线方向，而银行（`Bank`）选项允许对象在通过路径弯路段时倾斜。如果受约束的对象遵循垂直循环路径（如过山车），你需要勾选允许倒置（`Allow Upside Down`），否则对象将在循环的顶点瞬间翻转。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_714_0.png)

2. 你可以使用旋转关键帧来定义相机的朝向，并覆盖由跟随选项设置的朝向。将时间滑块拖到第`100`帧（相机进入曲线之前），直到路径末端。
