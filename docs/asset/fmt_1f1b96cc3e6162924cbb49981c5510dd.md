### Web 服务器

Web 服务器是一种应用程序（有时被认为是一个计算机），作为你的网络浏览器和互联网之间的接口。在基础层，它翻译来自浏览器的请求（通常是 HTTP 请求的形式），将请求定向到包含你尝试访问内容的适当服务器机器，并将其送回你的网络浏览器，以便你可以在浏览器中显示。你可以在 UNIX 市场上找到开源和基于许可的 Web 服务器。
