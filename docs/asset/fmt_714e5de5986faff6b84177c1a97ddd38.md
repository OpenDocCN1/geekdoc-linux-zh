## .csh 中的别名

别名（`alias`）是为常用命令定义的简写。你可以使用别名来简化输入。在 `.csh` 文件中定义别名。你可以使用 `alias` 命令查看当前定义的别名。你可以使用 `alias -d` 命令删除别名。

```csh
alias ls 'ls -F'
alias ll 'ls -la'
alias cd 'cd -P'
```

这些别名存储在 `.csh` 文件中，这样每次启动 Shell 会话时都会加载。你可以通过文本编辑器修改该文件。修改完别名后，通常需要运行 `source .csh` 使更改立即生效。
