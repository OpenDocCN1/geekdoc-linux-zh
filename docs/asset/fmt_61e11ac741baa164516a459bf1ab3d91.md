## 最小权限原则 (least privilege, concept of)

使用 root 权限运行的用户所犯的错误比普通用户的破坏性大得多。当你操作计算机时，特别是当你以系统管理员身份工作时，请使用最小权限执行任何任务。如果可以使用普通用户身份执行任务，请那样执行。如果你必须使用 root 权限工作，请尽可能以普通用户身份操作，通过登录 root 或使用 `su` 或 `sudo` 命令以 root 权限运行，尽可能完成必须由 root 权限完成的任务，并尽快切换回普通用户。

## multicast (组播)

组播数据包有一个源地址和多个目的地。在组播中，源主机在特殊地址注册以传输数据。目标主机在同一地址注册以接收数据。与基于局域网的广播（第 1026 页）不同，组播流量设计为基于订阅机制跨越路由网络工作。组播通过仅传输一次数据包来减少网络流量，由路径末端的路由器根据多个接收者的需要对其进行拆分。

## network segment (网段)
