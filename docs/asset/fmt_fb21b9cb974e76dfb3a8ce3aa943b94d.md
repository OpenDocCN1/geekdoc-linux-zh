## Lpc 打印控制命令

Linux 使用 System `lpc`（行打印控制）来控制打印机和打印队列，就像 System Unix 一样。该服务的优点是你可以独立地控制队列和打印机。我们对 Linux 队列和打印感兴趣的主要命令包括表 16.3 中列出的 `lpc` 命令选项。

如表 16.3 所示，控制的粒度非常出色，在创建 shell 脚本时提供了选项。要一次性控制所有的打印和排队，你实际上不需要 shell 脚本。以下两个命令可以同时启动和停止所有打印队列的打印和排队。

```
lpc down all             # 禁止所有打印和排队
```

```
lpc up all               # 启用所有打印和排队
```

### 表 16.3 Lpc 命令选项

| LPC 命令 | 命令结果 |
| --- | --- |
| `disable (printer[@host] | all)` | 禁用排队 |
| `stop (printer[@host] | all)` | 禁用打印 |
| `down (printer[@host] | all)` | 禁用打印和排队 |
| `enable (printer[@host] | all)` | 启用排队 |
| `start (printer[@host] | all)` | 启用打印 |
| `up (printer[@host] | all)` | 启用打印和排队 |

### 脚本实现细节

`while` 循环。查看下一条命令行，了解我们如何直接加载数组 `pqstat`，其包含每行前三个字段的数组元素。

```
lpc status all | tail +2 | while read pqstat[1] pqstat[2] pqstat[3] junk
```

我只需要输出中的前三个字段，注意 `while` 语句中 `read` 的第四个变量是 `junk`。`junk` 变量是一个通用变量，用于将输出中的任何剩余字符串捕获到一个单一变量中。你必须处理这些剩余文本，如果你忽略了用于捕获行尾剩余字符的变量，你将在下一次迭代中将这些字符作为字符串读取！这种错误会产生某些难以发现和排错的奇怪输出。

注意 `lpc status all` 命令的输出，打印机显示队列已禁用（disabled），这是第三个字段。处理这两个状态字段的最简单方法是使用两个 `case` 语句，每个语句针对一个字段进行标记。查看列表 16.8 中的完整脚本代码，我们将在最后介绍这种技术。

### 打印队列管理：让打印机持续打印

```
do
  # 首先检查每个打印机的打印状态
  case $(pqstat[2]) in
    disabled)
      # 打印已禁用 - 输出状态并重启打印
      echo "$(pqstat[1]) Printing is $(pqstat[2])" | \
        tee -a $LOGFILE
      lpc start $(pqstat[1]) | tee -a $LOGFILE
      ((($? == 0)) && echo "$(pqstat[1]) Printing Restarted " | \
        tee -a $LOGFILE
      ;;
    enabled|*) # 无操作 - 什么都不做
      ;;
  esac
  # 接下来检查每个打印机的队列状态
  case $(pqstat[3]) in
    disabled)
      echo "$(pqstat[1]) Queueing is $(pqstat[3])" | \
        tee -a $LOGFILE
      lpc enable $(pqstat[1]) | tee -a $LOGFILE
      ((($? == 0)) && echo "$(pqstat[1]) Queueing Restarted " | \
        tee -a $LOGFILE
      ;;
    enabled|*) # 无操作 - 什么都不做
      ;;
  esac
done
```

**列表 16.8** `print_UP_Linux.ksh` 脚本。（续）

我们在列表 16.8 的脚本开头定义了 `$LOGFILE`。注意在日志文件定义之后，后面的命令会检查日志文件是否存在。如果 `$LOGFILE` 不存在，测试的结果将是一个非零返回码。我们使用逻辑或（由双管道符 `||` 指定）来执行随后的命令，以创建一个长度为零的 `$LOGFILE`，因为如果测试结果为非零，说明该文件不存在。

接下来，我们使用 `while` 循环在每次循环迭代中加载 `pqstat` 数组，在我们的用例中，迭代是针对单个打印机的循环。这意味着我们在每次循环迭代中都会加载一个带有新数据的一维数组（Korn shell 只能使用一维数组）。再次，注意在 `while` 语句中作为最后一个变量的 `junk` 变量。这个额外的变量是必要的，可以将剩余文本捕获到单一变量中。

加载数组后，我们继续使用两个 `case` 语句来测试每个打印队列的打印和队列状态。注意，我们在 `case` 语句中直接使用数组元素，如下：

```
case $(pqstat[2]) in
```

我们在 `case` 语句的打印队列数组元素中使用了相同的技术。数组元素只有两种可能的结果：`enabled` 和 `disabled`。我们关心的唯一结果是任何 `disabled` 值。如果收到任何 `disabled` 值，我们尝试在打印机上重新打印或启用队列。注意，在两个 `case` 语句中的第二个选项都包含了 `enabled` 和通过通配符 `*` 指定的任何其他内容，如下：

```
enabled|*
```

本可以使用通配符覆盖所有内容，但对于脚本阅读者来说，在 `case` 语句中看到实际的预期结果比看到一个通用的星号更清晰。
