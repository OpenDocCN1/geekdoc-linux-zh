# 6.2.6 互联网协议选项

IPv4 中的 IP 选项是奇怪的东西。它们具有很高的价值，但由于（二十多年来）它们一直相对少用，大多数路由器在慢路径中处理它们。慢路径是处理特殊情况的代码，包含比所谓的快速路径处理更多的检查。事实上，当路由器通过硬件解决方案来解决问题时，他们是将设计投入昂贵的硅片，因此他们将选项减少到零。然而，由于主机需求，我们需要处理它们。松散和严格源路由以及记录选项如果它们将非常有用
