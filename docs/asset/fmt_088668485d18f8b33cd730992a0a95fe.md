# 组织培养

**组织培养** 在受控环境中培养细胞或高等植物的生物学分支。当细胞附着在固体基质（如玻璃或赛胶）上或提供复杂的营养培养基时即可进行。现在所有培养也采用悬浮。组织培养用于研究、形态、遗传机制、辐射生物学以及研究和活性。见微生物方法（MICROOLOGICAL METHODS）。(TTP)

# 滴定

所有的钛金属均由四氯钛（`TiCl4`）生产，这是在氧化钛颜料的氯化过程中产生的中间化合物。该过程涉及氯化；二氧化钛在流化床反应器中与氯气（`Cl2`）和碳（`C`）反应形成四氯钛。为了生产合金，会采用进一步的还原过程来去除污染钛的其他金属。

在滴定法中，重点是滴定溶液中的离子与电荷相反的离子结合。这种结合可能涉及许多物种，其中某些可能是离子的。结合可能导致沉淀或配合物的形成。沉淀-配合物。

将净化的四氯钛溶解成液态加入反应容器中。在某些情况下，四氯钛与镁（`Mg`）或钠（`Na`）反应形成金属海绵，这由氧气或氮气产生的多孔细胞形式，在氩气氛围下进行。

在氧化滴定中，使用氧化剂来确定被氧化的物质，因此作为还原剂。氧化还原滴定。

# 按终点分类。

确定终点的准确性是滴定法中的一个至关重要的因素。由于其简单性和多功能性，化学指示剂非常常见，特别是在酸碱滴定中。

指示剂。酸碱指示剂是一种弱酸或弱碱，当它从分子形式转变为共轭形式时会改变颜色。这些指示剂用量非常小，因此只需要少量的指示剂。酸性指示剂的工作范围或颜色变化取决于发生氢离子浓度变化的 pH 值。现有的指示剂具有不同范围，以覆盖滴定过程中可能遇到的整个氢离子范围。参见酸碱指示剂。

滴定。一种本质上是体积的定量分析。在高精度滴定法中，滴剂溶液从滴定管中排出，其体积方面是间接的。通常使用标准溶液（即含有已知浓度物质 (X) 的溶液）作为滴剂，它将与待测物反应。反应持续到达到终点。

理想的滴定等于一种不存在过量 X 或 Y 的反应。如果已知 X 和 Y 反应的化学计量比或精确比例，就可以计算出溶液中 Y 的量。参见体积分析。

化学法滴定。在普通滴定中，化学反应可以分为三大大类：酸碱、中和和氧化还原。酸碱滴定涉及碱对酸的中和，或反之。

纯钛是柔软、白色且极其耐用的。然而，通过适当添加其他金属，碱可以变成具有独特特性的工程材料，包括高强度、耐性和耐久性。合金添加的质量和数量决定了方法，在某种程度上，常见合金包括铝、氮、碳、钒、铁、镍和锡。参见合金；钛冶金术。

然而，该过程是非特异性的；在硝酸和盐酸混合物的滴定中，可以通过额外的测量来确定总酸度。源自某种来源的盐和极弱酸可以像碱一样被滴定。

# 电位滴定。

通过由缓冲溶液形成的电极测量 pH。电极系统的选择影响了哪些电位法可以应用于组合滴定和氧化还原滴定。现代电位法使用选择性电极大大改进了结果。参见电位计；选择性电极。

电导滴定。当发现电导终点时，电导总结是成功的。在电导滴定中，溶液中所有离子和分子物种表现出一种电导：测量稀释溶液的电导率并随体积绘制图。氢离子和氢氧离子比任何其他离子更具载性。参见电导。

分光滴定。光谱仪是一种光学设备，仅探测紫外、红外或可见光谱范围内极窄波长范围内的辐射。吸光度是定量的，并与在该波长吸收光的物质浓度有关。可见范围内的滴定是最常见的。参见分光法。

安培滴定。使用滴液电极或合适的微电极，可以找到在溶剂中施加的电动势（emf）范围内，电流与一个或两个反应的浓度成正比。

双安培滴定是一种密切相关的技术。在两个相同的电极之间施加一个小电流。这种不涉及液接面的布置，在非水滴定中（例如使用有机滴剂）是有效的。

极谱分析。

恒温或焓滴定。化学反应涉及热量的释放。如果将其中一种用作滴定的基础，温度会下降，并在滴定持续直到达到终点时保持不变。如果终点消失，恒温滴定适用于所有类型的反应。参见温度计。

非水滴定。这被用于执行在水中没有终点的滴定。与所有反应类别的适用原理不同，碱的应用远超过其他类型。溶剂为溶剂或盐混合物的非水滴定也是可能的。

自动滴定。在通常重复执行的常规工作中可以实现自动化。另一种方法是停止滴定并滴剂。另一种方法是在终点或接近终点处自动产生。使用终点控制输液设备，使用带有电磁控制阀的普通滴定管。
