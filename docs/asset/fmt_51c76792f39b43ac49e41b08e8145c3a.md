## Description

`awk` 命令 是一个简单的语言，非常用于计算和模式匹配。

`audiorecord` 将音频数据从音频设备复制到命名的音频文件中（如果没有指定文件名，则复制到标准输出）。如果你未指定文件且标准输出是 TTY，则命令行上指定的音量、平衡、监听音量、端口和音频格式设置将生效，程序退出。

默认情况下，单声道音频数据以 8 kHz 录制并以 `ulaw` 格式编码。如果音频设备支持额外的配置，你可以使用 `-c`、`-s` 和 `-e` 选项来指定数据格式。输出文件开头有一个音频头，该头用于识别文件中编码的数据格式。

录制立即开始，并持续到收到 `SIGINT` 信号（例如 Control-C）。如果你指定了 `-t` 选项，`audiorecord` 将指定时间到后停止。

如果音频设备不可用（即另一个进程当前具有读取权限），`audiorecord` 将打印错误信息并立即退出。
