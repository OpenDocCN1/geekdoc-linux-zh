
程序的运行实例被称为“进程”。如果你屏幕上显示了两个终端窗口，那么你可能运行了两次同一个终端程序——你有两个终端进程。每个终端窗口可能都在运行一个 `shell`（外壳）；每个 `shell` 都是另一个进程。当你从 `shell` 调用一个命令时，相应的程序会在新进程中执行；当进程完成后，`shell` 进程会恢复执行。

高级程序员经常在单个应用程序中使用多个协作进程，以使应用程序能够同时完成多项工作，增加应用程序的健壮性，并利用已有的程序。

本章描述的大多数进程操作函数与其它 UNIX 系统上的函数相似。大多数函数在 `<stdio.h>` 头文件中声明；请检查每个函数的 `man` 页面（手册页）以确保正确。

### 3.1 查看进程

即使你坐在电脑前，也有进程在运行。每个执行中的程序都使用一个或多个进程。让我们先看看你计算机上已经运行的进程。

#### 3.1.1 进程 ID (PID)

Linux 系统中的每个进程都通过其唯一的进程 ID（process ID，有时称为 `pid`）来标识。进程 ID 是 16 位数字，由 Linux 在创建新进程时按顺序分配。

每个进程都有一个父进程（第 3.4.3 节“僵尸进程”描述的特殊 `init` 进程除外）。因此，你可以将 Linux 系统上的进程想象成树状结构排列，以 `init` 进程为根节点。父进程 ID（或 `ppid`）仅仅是父进程的进程 ID。

在 C 或 C++ 程序中引用进程 ID 时，请使用 `pid_t` 类型别名，它定义在 `<sys/types.h>` 中。程序可以通过 `getpid()` 系统调用获取其运行环境的进程 ID，并可以通过 `getppid()` 系统调用获取其父进程的进程 ID。例如，列表 3.1 中的程序打印了它的进程 ID 及其父进程的进程 ID。

列表 3.1 (`print-pid.c`) 打印进程 ID

```c
#include <stdio.h>
#include <unistd.h>

int main ()
{
    printf("The process ID is %d\n", (int) getpid());
    printf("The parent process ID is %d\n", (int) getppid());
    return 0;
}
```

注意，如果你多次调用此程序，报告的进程 ID 将是不同的，因为每次调用都在新进程中进行。然而，如果你总是从同一个 `shell` 调用它，那么父进程 ID（即 `shell` 进程的进程 ID）就是相同的。

#### 3.1.2 查看活动进程

`ps` 命令显示在你的系统上运行的进程。GNU/Linux 版本的 `ps` 有很多选项，因为它尝试兼容其它 UNIX 变体中的 `ps` 版本。这些选项控制列出哪些进程以及显示每个进程的哪些信息。

默认情况下，`ps` 显示由调用该命令的终端或终端窗口控制的进程。例如：

```bash
% ps
PID TTY           TIME CMD
21693 pts/8      00:00:00 bash
```

### 3.2 创建进程

创建新进程有两种常用技术。第一种相对简单，但应谨慎使用，因为它效率低下且存在安全风险。第二种技术更复杂，但提供了更大的灵活性、速度和安全性。

#### 3.2.1 使用 system

标准库中的函数提供了一种从程序内部执行命令的简单方法，就像在 `shell` 中输入命令一样。事实上，`system` 创建了一个运行 `/bin/sh` 的子进程，并将命令交给该 `shell`。例如，列表 3.2 中的程序调用 `ls` 命令来显示根目录的内容，就像你在 `shell` 中输入了 `ls -1`。

列表 3.2 `system.c` 使用 `system` 调用

```c
#include <stdlib.h>

int main() {
    int return_value;
    return_value = system("ls -1 /");
    return return_value;
}
```

`system` 函数返回 `shell` 命令的退出状态。如果 `shell` 无法运行，`system` 返回 127；如果发生其他错误，`system` 返回 -1。

由于 `system` 函数使用 `shell` 调用你的命令，因此受到系统 `shell` 特性、限制和安全缺陷的影响。无法依赖特定版本的 Bourne `shell` 的可用性。在许多 UNIX 系统上，`/bin/sh` 是指向另一个 `shell` 的符号链接。例如，在大多数 GNU/Linux 系统上，`/bin/sh` 指向 `bash`（Bourne-Again SHell），不同的 GNU/Linux 发行版使用不同版本的 `bash`。使用 `system` 函数调用程序，例如，可能会产生不同的结果

#### 3.2.2 使用 fork 和 exec

DOS 和 Windows API 包含 `spawn` 函数族。这些函数将要运行程序的名称作为参数并创建该程序的新实例。Linux 不包含在一个步骤内完成所有操作的单一函数。相反，Linux 提供了一个函数 `fork`，它创建一个与父进程完全相同的子进程。Linux 提供了另一组函数，即 `exec` 族，它们会使特定进程停止作为一个进程的实例，转而变为另一个程序的实例。要产生一个新进程，你首先使用 `fork` 创建当前进程的副本。然后，你使用 `exec` 将其中一个进程转换为你所启动的程序的实例。

##### 调用 fork

当一个程序调用 `fork` 时，会创建一个复制的进程，即子进程。父进程从调用 `fork` 的点继续执行该程序。子进程则从相同的位置开始执行相同的程序。

那么，这两个进程之间有什么区别呢？首先，子进程是一个新进程，因此它有一个新的 ID（PID），与其父进程的 ID 不同。程序区分自己是处于父进程还是子进程的一种方法是调用 `fork`；`fork` 函数会向父进程和子进程返回返回值——一个进程“进入”了 `fork` 调用，而有两个进程“出来”，且返回了不同的值。父进程中的返回值是进程 ID，而子进程中的返回值是 0。因为任何进程的进程 ID 都不为 0，这使得程序很容易判断自己是作为父进程还是子进程运行。

列表 3.3 是使用 `fork` 复制程序进程的示例。请注意，`if` 语句的第一块块只在父进程中执行，而 `else` 分句在子进程中执行。

列表 3.3 (`fork.c`) 使用 `fork` 复制程序的进程

```c
#include <stdio.h>
#include <sys/types.h>
#include <unistd.h>

int main ()
{
    pid_t child_pid;

    printf("the main program process ID is %d\n", (int) getpid());

    child_pid = fork();
    if (child_pid != 0) {
        printf("this is the parent process, with id %d\n", (int) getpid());
        printf("the child's process ID is %d\n", (int) child_pid);
    }
    else
        printf("this is the child process, with id %d\n", (int) getpid());

    return 0;
}
```

##### 使用 exec 族

`exec` 函数用另一个程序替换掉进程中运行的程序。当一个程序调用 `exec` 函数时，该进程会立即停止执行，并从头开始执行新程序，前提是 `exec` 调用没有遇到错误。

在 `exec` 族中，这些函数在功能和调用方式上略有不同。

- 名称中包含 `p` 的函数（`execvp` 和 `execclp`）接受一个程序名，并在当前执行路径中按名称查找该程序；不包含 `p` 的函数必须是要执行的程序的完整路径。
- 名称中包含 `v` 的函数（`execv`、`execve` 和 `execvp`）接受一个以 `NULL` 结尾的字符串指针数组，作为新程序的参数列表。名称中包含 `l` 的函数（`execl`、`exepl` 和 `exle`）使用 C 语言的可变参数（variargs）机制来接受参数列表。
- 名称中包含 `i` 的函数（`execve` 和 `exle`）接受一个额外的参数，即环境变量数组。该参数应该是一个以 `NULL` 结尾的字符字符串指针数组。每个字符字符串的格式应为 `"VARIABLE=value"`。

由于 `exec` 会用另一个程序替换调用它的程序，除非发生错误，否则它不会返回。

传递给程序的参数列表类似于你从 `shell` 运行程序时指定的命令行参数。它们通过 `main` 函数的 `argc` 和 `argv` 参数可用。请记住，当程序被 `shell` 调用时，`shell` 会将参数列表的第一个元素 `argv[0]` 设置为程序的名称。
