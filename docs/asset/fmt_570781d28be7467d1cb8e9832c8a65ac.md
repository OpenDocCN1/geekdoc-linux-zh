上下文相关菜单的内容是特定于应用程序，这意味着你无法直接对其进行自定义。但是，可以通过安装额外的应用程序、小部件，或在 Firefox 或 Nautilus 等可扩展应用程序中通过安装扩展或插件来添加功能，从而提供相关的菜单项，并对这些菜单进行自定义。

## 自定义菜单

GNOME 为你提供了两种自定义基础 GNOME 菜单内容的方法。“应用程序”菜单底部的第一个项目让你方便地将新应用程序添加到“应用程序”菜单中定义的现有部分，如果这些应用程序尚未于系统中，它甚至会安装这些应用程序。“辅助工具”菜单中的 Alacarte 菜单编辑器可以方便地向任何标准 GNOME 菜单中添加你自己的组、快捷方式或应用程序条目，但它不会替你安装任何东西。接下来的两个部分将解释如何使用这些应用程序。

### 将应用程序添加到“应用程序”菜单

“应用程序”菜单底部的“添加/删除”项会显示 `gnome-all-applications` 窗口的对话框，如图 5.6 所示。

![](img/e88880e40d650bfe19d5b6927bd86568_143_0.png)

添加到你的 Ubuntu 系统的应用程序

“添加/删除应用程序”窗口的内容如下：

- **软件分类列表：** 列出“添加/删除”程序知道的所有预定义软件类型。
- **应用程序窗格：** 列出当前选择分类中所有可用应用程序。
- **搜索字段：** 如果你不确定某个应用程序属于哪个分类，此字段允许你通过名称搜索特定应用程序。
- **额外应用程序复选框：** 勾选此框将在“应用程序”窗口中包含未受 Canonical, Ltd 官方支持、但在 Ubuntu 仓库的用户支持的 *Universe* 部分可用的应用程序。有关 Ubuntu 仓库以及软件在其中如何分类的更多信息，请参见第 11 章“其他办公软件：表格和演示文稿”。
- **允许专有应用程序复选框：** 与“额外应用程序”复选框类似，勾选此框会将“应用程序”窗口中在复制、使用、重新发或增强方面某些限制的应用程序，因此不符合 Ubuntu/Debian 的开源软件定义。这些软件可用 Ubuntu 仓库的 *Multiverse* 部分。有关 Ubuntu 仓库以及软件在其中如何分类的更多信息，请参见第 11 章。
- **应用程序描述窗格：** 显示任何当前选择软件软件包的描述。
- **按钮：** 执行以下各种操作：
    - **帮助：** 为 `gnome-app-install` 应用程序显示详细的在线帮助。
    - **高级：** 启动功能 Synaptic 软件包管理器应用程序，该程序提供了超越 `gnome-app-install` 应用程序提供的功能。

![](img/e88880e40d650bfe19d5b6927bd86568_144_0.png)

- **应用：** 根据你的选择更新“应用程序”菜单，安装任何必要的软件并返回 `gnome-app-install` 应用程序。
- **取消：** 退出应用程序，不对“应用程序”菜单进行任何待处理更改。
- **确定：** 对“应用程序”菜单进行任何待处理更改，然后退出。

假设，假设你想将 Gnumeric 应用程序添加到你的办公菜单，请执行以下操作：

1. 从“应用程序”菜单中选择“添加/删除”项。
2. 在软件分类列表中选择“办公”分类。
3. 在应用程序窗格中浏览 Gnumeric，或在搜索字段中输入 `gnumeric`。
4. 勾选 Gnumeric 应用程序条目左侧的复选框。
5. 点击“应用”安装 Gnumeric 并返回 `gnome-app-install` 应用程序。
6. 在权限对话框中输入密码并按回车。`gnome-app-install` 应用程序会自动检索并安装请求的软件及其所需的任何包。如果你请求的软件包与现有软件冲突，对话框将识别冲突并提供移除冲突包的选项。

### 向任何菜单添加项目

要添加你自己的菜单或为特定应用程序创建自定义菜单项，你需要使用“应用程序”辅助工具子菜单中的菜单编辑器，它可以方便地向任何 GNOME 菜单添加几乎任何内容，包括自定义子菜单。

假设你想创建一个名为“收藏”的子菜单并开始向其中添加条目。要这样做，以 `emacs` 为例，请执行以下操作：

1. 选择 `应用程序→辅助工具→Alacarte 菜单编辑器` 启动菜单编辑器。此菜单编辑器对话框由两个主要窗格组成——左侧的菜单分类面板和右上显示当前选择菜单内容的内容窗格。
2. 如果打开此对话框时“应用程序”菜单是展开的且/或未选择菜单，请选择左侧菜单分类面板中的“应用程序”条目，并点击名称左侧的箭头以折叠该菜单的条目列表。菜单编辑器看起来应该像图 5.7 所示的对话框。

你会注意到菜单分类面板列出了许多当前未在系统中显示的菜单。这是因为它们在右侧的内容窗格中未被标记为“可见”。
