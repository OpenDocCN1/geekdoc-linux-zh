## 时空

一个用于描述相对论视角下物理宇宙概念的术语。它也被称为闵可斯基空间。在牛顿物理学中，空间和时间被认为是独立的实体。

爱因斯坦证明，如果两个观测者使用相同的观测方法但处于相对运动中，他们对事件的同步性、彼此之间的距离，因此不可避免地对不同运动方式的钟表速率以及测量长度和比例产生分歧。不同观测者和不同参考系的钟钟和空间长度与同一事实无关。

根据洛伦兹变换，两个事件的时间间隔和空间与执行测量的运动速度函数相关。然而，存在一个新的不变量，即这两个量的乘积。它被称为不变时空间隔，或固有时空间隔，由公式 `(Eq. 1)` 定义：

```
s^2 = c^2t^2 - x^2
```

两个事件之间的距离以及真空中的光速。对于不同的观测者，`$T$` 和 `$r$` 分别不同但具有相同的值。在事件 `(Eq. 1)` 中，除了 `c` 之外没有是不变的的，`t` 和 `r` 可以被由公式 `(2)` 定义的 `τ` 替换。如果从起点发送信号，其中一个事件发生的位置将到达另一个事件的位置。

```
s^2 = c^2τ^2 - x^2
```

## 航天器结构

![](img/b16805e6127c92641547ee45e5728f7f_2079_0.png)

需要屏蔽宇宙辐射。辐射在 10-20 年期间对任务结构的影响并不严重。空间中结构的耐用性是长寿命设计的一个主要关注点。根据现有数据，水分子、热量、紫外线以及质子和电子辐射的协同效应会降低聚合物的机械、物理和光学性能。

空间中的极端温度和封闭环境通过多种技术进行控制。被动控制通过表面涂层和材料实现，这些材料可以控制从航天器到太空以及反向的辐射传输。由于太阳辐射强度随距离太阳距离而变化，行星任务需要对吸收和发射表面属性进行调整。内部电子设备或其他产生的热量必须在热平衡设计中进行控制。其他使用的技术还包括主动加热器、热冷却器和热管。

航天器设计中考虑了热梯度，特别是当航天器持续面对太阳时。在某些情况下，必须使用隔热毯来保护航天器免受极端环境影响。

航天器结构通常要求轻量化和刚性，因此需要选择低密度和高模量密度比的高模量钛铍合金。这些金属难以制造，因此应用受到限制。最常用的材料铝、镁和复合材料被用作基础航天器材料。它们更容易制造，价格便宜，且质量通常适用于空间环境。在需要热或磁隔离的航天器结构中使用塑料复合材料。

## 空间阶段与设计考量

空间阶段涉及持续到再入之前的剧烈载荷。在此阶段，进入轨道的结构必须承受这些载荷。设计考量包括结构完整性、热胀以及振動和声载荷的最小化。

航天器控制系统会在整个结构中施加负载。在零重力环境中，每个方向的变化都会产生应力。结构的完整性是一个至关重要的设计原则。一个重要的材料属性是断裂韧性。参见材料在应变条件下的缺口敏感性。这种明显的脆性会导致关键接头的过早失效。

陨粒相对于航天器具有极高的能量速度（高达 22,500 ft/s 或 6 km/s）。轨道碎片还包括由太空活动产生的颗粒，它们会损坏航天器。长轨道航天器的碰撞是不可避免的。此类碰撞的最坏影响包括聚合物的降解、高压箱和栖息舱活动罩的侵蚀。这些结构设计中的一个基本参数是减轻辐射影响。

对低重量、高刚性和低热膨胀（精密点）的再入要求促使航天器结构使用复合材料。再入热由大气摩擦产生，这种热由车辆前方空气的压缩提供支撑。使用的材料必须确保内部航天器结构免受进入体所经历极端温度的影响。

再入阶段。地球的大气密度较薄，这对于降低飞行速度是必要的。进入位置由进入大气的物体决定。

大气层。当车辆进入地球大气层时，具有大量的能量。某些航天器被设计为在高海拔进入，但另一些可能设计为在外层高度进入。结构设计至关重要。

再入会导致极端热和摩擦，必须通过使用高温陶瓷或烧蚀材料来耗散。航天器覆盖有热保护，允许飞行器在表面达到 1200 °F (650 °C) 时保持冷却，并对其前缘进行保护。

卫星再入。进入大气层在下降过程中形成火焰层。通常，卫星大部分或全部在到达表面之前被烧毁，但也有例外，例如 2001 年 3 月 22 日俄罗斯“和平号”空间站的再入。

在某些应用中，利用气动力升力的车辆比气动升力弹道体具有若干优势 `(1)`：

(1) 使用升力允许更平缓的下降，减少对车辆和乘客的减速力。
(2) 车辆的机动能力使其命中特定目标或着陆点具有更高的精度。
(3) 给定下降的引导系统的灵活性可以到达更广泛的区域。
(4) 更大的灵活性是因为气动力升力可以随速度进行调整。

火花后，火焰从火花塞流出，在正常燃烧下逐渐燃烧整个燃料包。燃烧气体加热并膨胀，导致燃烧室压力和温度增加。火焰前可能会升至自燃温度。如果火焰前太快，燃烧气体可能会点燃并爆炸。
