
# 如何获取 IBM Redbooks

你可以通过以下网站订购纸质版 Redbooks，也可以在该网站查看、下载或搜索 Redbooks：`ibm.com/redbooks`

你还可以从该网站下载额外的材料（代码示例或软盘/CD-ROM 镜像）。

## IBM Redbooks 集合

Redbooks 也可以以 CD-ROM 的形式提供。点击 Redbooks 网站上的 CD-ROMs 按钮可以获取所有提供的 CD-ROM 信息以及更新和格式。
