# HTML（超文本标记语言）

一组用于标记文档部分内容的约，，以便在通过一个名为解析器（`parser`）的程序访问时，每个部分都以一种独特的格式显示。`HTML` 是一种用于改善万维网（World Wide Web）文档外观的标记语言，而访问这些文档的程序是 Web 浏览器。`SGML`（标准通用标记语言）的一系列功能允许作者插入超链接，点击后会显示另一个 HTML 文档。编写 HTML 的过程称为编写（authoring）。你可以使用某些 HTML 编辑器作为 HTML 助手通过编辑纯文本文档来编写 HTML。此外，还有提供 HTML 编辑功能的插件，例如 `Bluefish`。与文字处理的格式代码不同，HTML 代码（称为标签）并不指定文档每个部分的角色，例如标题、副标题或正文文本。解析器决定了如何格式化文本。来自 QUEDIC

http://www.tdlp.org/LDP/Linux–Dictionary/html/index.html
