# 关于作者

`Doug Lowe` 写过大量计算机类书籍，包括 35 多本“傻呆哥”系列书籍，其中包括《傻呆哥网络指南》、《傻呆哥 Java 全方位桌面参考书》、《傻呆哥 PowerPoint 2003 指南》以及《傻呆哥 Word 2003 全方位桌面参考书》。他住在加利福尼亚州阳光的弗雷斯诺，那里的座右铭是“和他的妻子 Lucy 以及三个强迫症女儿，她们在圣诞节会挂上数千盏灯”。去年，他实际上在后院建造了一艘海盗船。
