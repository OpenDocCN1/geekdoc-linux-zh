
```python
def assert_call(*args, **kwargs):
    for (name, check), value in zip(args_check, args):
        if check: assert(value, "%s %s" % (name, check.__doc__))
    for name, check in args_check[len(args)]:
        if check: assert(kwargs[name], "%s %s" % (name, check.__doc__))
    result = func(*args, **kwargs)
    assert return_check(result), "%s" % return_check.__doc__"
    return result

return assert_call
```

# 仅关键字参数 (Keyword-Only Arguments)

函数可以指定关键字参数。这通过在第一个星参数之后定义参数来实现。例如：

```python
def foo(x, *args, strict=False):
    statements
```

在调用此函数时，`strict` 参数只能作为关键字指定。

例如：

```python
a = foo(1,strict=True)
```

任何额外的位置参数将被放入 `args` 中，而不会用于设置 `strict` 的值。如果你不想接受可数量参数但想要仅关键字参数，请在参数列表中使用单独的 `*`。例如：

```python
def foo(x, *, strict=False):
    statements
```

这是一个用法示例：

```
foo(1,True)      # 失败。TypeError: foo() takes 1 positional argument
foo(1,strict=True) # OK
```

# 链式异常 (Chained Exceptions)

异常现在可以链在一起。`from` 关键字用于显式链接异常。例如：

```python
try:
    statements
except ValueError as e:
    raise SyntaxError("Couldn't parse configuration") from e
```

当抛出 `SyntaxError` 时，回溯信息将显示：

```

  File "stdin", line 2, in <module>

```

上述异常是后续异常的直接原因：

```
Traceback (most recent call last):
  File "stdin", line 4, in <module>
SyntaxError: Couldn't parse configuration
```

对于隐式链，异常实例的 `__context__` 属性包含对之前异常的引用。异常链的一个微妙示例涉及在异常处理器内部抛出的异常。例如：

```python
def error(msg):
    print(m)  # 注意：此处故意错误的（m 未定义）

    statements
```

在处理上述异常期间，发生了另一个异常：

# 高级元类 (Advanced Metaclasses)

在 Python 2 中，你可以定义更改类行为的元类。实现的一个微妙方面是，元类执行的处理器是在类体执行后才进行的。也就是说，解释器执行整个类体并创建一个字典。一旦填充了字典，字典就会传递给元类构造函数（在类体执行后）。

在 Python 3 中，元类还可以在类体执行之前额外提取额外工作。这是通过在元类中定义一个特殊的类方法 `__prepare__(cls, name, bases, **kwargs)` 来实现的。该方法必须返回一个字典作为

result。这个字典是在类定义体执行时被获取的。这里有一个概述了基本步骤的示例：

```python
class MyMeta(type):
    @classmethod
    def __prepare__(cls, name, bases, **kwargs):
        print("preparing", name, bases, kwargs)
        return {}

    def __new__(cls, name, bases, classdict):
        print("creating", name, bases, classdict)
        return type.__new__(cls, name, bases, classdict)
```

Python 3 使用了替代语法来指定元类（metaclass）。例如，要定义一个使用 `MyMeta` 的类，你可以使用以下代码：

```python
class Foo(metaclass=MyMeta):
    """准备定义方法"""
    def __init__(self):
        pass
    def bar(self):
        pass
    print("Defining methods")
```

如果你运行以下代码，你将看到下面的输出，展示了执行流：

```
Foo() {}
About to define methods
Defining methods
creating Foo ({__module__': '__main__',
    '__bar__': '<function bar at 0x3845d0',
    '__init__': '<function __init__ at 0x3845d8>}
```

元类的 `__prepare__` 方法的额外参数是从类语句列表中的关键字参数传递而来的。例如，类 `Foo(metaclass=MyMeta, spam=2, blah="Hello")` 将关键字参数 `spam` 和 `blah` 传递给 `MyMeta.__prepare__`。这种约定可以用于向元类传递任意配置信息。
