
`delete` 函数是一个内置函数，用于从计算机内存中删除数组元素。例如，要删除一个元素，可以使用 `delete name[1]` 命令。

**警告：** 在你从内存中删除一个元素后，它就消失了，且不会回来！如果不确定，请保留它。

尽管技术在进步，内存不再是曾经认为的那种珍贵资源，但在编写程序时，清理自己仍然是一个好习惯。想想支票打印程序。两百名字不会填满内存。然而，如果你的程序控制人员活动、开具支票和存根、添加和删除员工并绘制销售图表，最好将每个文件更新到磁盘并移除不再使用的数组。这样读取过时数据的概率更小。它还消耗更少的内存，并尽可能减少了使用旧数据数组执行新任务的概率。清理可以很容易完成：

```awk
END {i=totalemps
 while(i>0) {
 delete name[i]
 delete data[i]
 i-- }
 }
```

Nawk++ 创建了另一个用于模拟多维数组的内置变量。“高级概念”章节中讨论了更多关于它的内容。它被称为 `SUBSEP`，默认值为 `"\034"`。要向 awk 中添加此变量，只需在你的程序中使用该名称即可：

```awk
BEGIN { SUBSEP = "\034" }
```

记住，在 awk 中，数组下标是以字符串存储的。由于每个列表都包含一个名称及其相关的数字，你可以匹配名称和匹配文件。

### 算术

尽管 awk 主要是用来用于模式匹配的语言，因此文本和字符串比数学和数字更容易进入脑海，但 awk 也拥有一套很好的数学工具。在本节中，我首先展示基础知识，然后讨论 awk 内置的数学函数。

### 运算符

Awk 支持常用的数学运算。表达式 `x^y` 是 `x` 的 `y` 次幂，即 `x` 的 `y` 次方。`%` 运算符在 awk 中计算余数：`x%y` 是 `x` 除以 `y` 的余数，结果取决于机器。所有数学运算使用浮点数，无论以何种格式表示，数字都是等价的，因此 `100 = 1.00e+02`。

awk 中的数学运算符由四个基本函数组成：`+`（加法）、`-`（减法）、`/`（除法）和 `*`（乘法），加上用于指数和余数的 `^` 和 `%`。正如你在最近销售中看到的，字段可以用于算术运算。如果在月中，我的老板要求一份一份最新的每月总额列表，我不需要为被丢弃的数字而恐慌；我只需要打印一个新的列表。我的第一次尝试似乎足够了。（参见列表 4.2。）

**列表 4.2. 打印五月份的销售总额。**

```awk
BEGIN {OFS="\t"}
```

awk 中有两种打印形式：`print` 语句和 `printf` 语句。到目前为止，我一直使用 `print` 语句。它是一个备选方案。`print` 语句有两种形式：带括号和不带括号的。因此，`print $0` 与 `print($0)` 是相同的。在 awk 的简写中，语句 `print` 本身等同于 `print $0`。正如之前的示例所示，使用 `print ""` 语句可以打印一个空行。请使用你偏好的格式。

**注意：** `print()` 不是合法的简写；它会产生语法错误。

只有当 `print` 语句涉及关系运算符时，Nawk 才需要使用括号。对于一个简单的例子，考虑 `file1`：

```
$cat file1
1 10
3 8
5 6
7 4
9 2
10 0
```

命令行

```bash
$ nawk 'BEGIN {FS="\t"}; {print($1>$2)}' file1
```

在显示器上显示：

```
0
0
0
1
1
1
```

由于 `0` 表示假，`1` 表示真，上述结果可能是你所预期的，但大多数编程语言不会直接打印关系式的结果。Nawk 和 C 会。

**注意：** 打印关系表达式的值需要 nawk 或更高版本。在 awk 中尝试上面的示例会导致语法错误。

Nawk 使用 `print` 和 `printf` 打印关系式的结果。然而，当涉及关系时，`print` 和 `printf` 都要求使用括号，以区分表示大于的 `>` 和表示重定向的 `>`。

## `printf` 语句

当需要格式化输出时使用 `printf`。它非常类似于 C 语言的 `printf`。与 print 语句一样，它有两种形式：带括号和不带括号的。两者均可以使用，但在使用关系运算符时必须使用括号。

`printf format-specifier, variable1,variable2, variable3,..variablen`
`printf(format-specifier, variable1,variable2, variable3,..variablen)`

`printf` 始终需要格式说明符。它包含了任何字面文本以及你想要打印的任何变量的特定格式。格式说明符始终以 `%` 开头。可以出现三个修饰符的任意组合：`-`、数字和 `*.number*`。`-` 表示变量应在其字段内左对齐。数字表示字段的总宽度应为该数字（如果数字以 `0` 开头，`%-05` 意味着变量宽度为 `5` 并根据需要用 `0` 填充）。最后一个修饰符是 `.*number*`，其含义取决于变量的类型，该数字表示字符串的最大宽度，或者小数点右侧的位数。在零或多个修饰符之后，显示格式以一个表示要显示的变量类型的单字符结束。

**提示：** 数字可以作为字符显示，非数字字符串可以作为数字显示（经过转换）。使用 `printf`，万事皆通！

记住，格式说明符有一个字符串值，正因为如此，它必须始终被包含在双引号（`"`）中，无论它是字面量字符串如：

`printf("This is an example of a string in the display format.")`

还是组合：

`printf("This is the %d example", occurrence)`

或者仅仅是一个变量：

`printf("%d", occurrence)`

**注意：** POSIX awk 规范（因此 gawk）支持动态字段宽度和精度修饰符，就像 ANSI C 的 `printf()` 程序一样。要使用此功能，请在实际显示修饰符处放置一个 `*`，值将从格式字符串后面的参数列表中替换。awk 还是 nawk 均没有此功能。

表 4.5 显示了决定 awk 变量打印方式的格式说明符，还有用于修改格式说明符行为的格式修饰符。

**表 4.5. awk 中的格式说明符。**

| 格式 | 含义 |
| :--- | :--- |
| `%c` | 一个 ASCII 字符。 |
| `%d` | 十进制（整数，不涉及小数点）。 |
| `%i` | 与 `%d` 相同（记住 `i` 代表 integer）。 |
| `%e` | 科学计数法下的浮点数（`1.00000E+01`）。 |
| `%f` | 浮点数（`10001010.434`）。 |
| `%g` | awk 在 `%e` 和 `%f` 显示格式之间进行选择；选择产生较短字符串的一个。不打印无效的零。 |
| `%o` | 无符号八进制（八位）数。 |
| `%s` | 字符串。 |
| `%x` | 无符号十六进制（十六位）数。 |
| `%X` | 与 `%x` 相同，但字母大大写而非小写。 |

**注意：** 如果用于 `%c` 的参数是数值，则它被视为字符并打印。否则，假设参数是字符串，仅打印该字符串的第一个字符。
