你刚刚在 VIZ 中创建了第一个对象，在此过程中，你看到对象的尺寸反映在参数展开列表中。一旦创建了对象，你就可以通过以下练习继续修改参数：

1. 在参数（Parameters）展开列表中找到宽度（`Width`）输入框，并多次点击右侧的箭头。这样的箭头被称为数值调节器（spinners），它们允许你图形化地调整关联输入框的值。注意，随着宽度框中值的增加，视口中的盒子开始变宽。

| 参数 | |
| --- | --- |
| 长度 | 53.259 |
| 宽度 | 76.961 |
| 高度 | 20.299 |

2. 指向宽度调节器的箭头点击并按住鼠标左键。注意按住鼠标时宽度继续增长。当你按住鼠标向前或向后移动时，值的变化率会加快。

3. 右键点击调节器。宽度缩小到 0。右键点击任何调节器都会将其值改为可能的最低值（在本例中为 0）。

4. 从宽度调节器向上拖动鼠标。宽度增加。点击并拖动，宽度再次缩小。

5. 点击并拖动宽度调节器直到光标到达屏幕顶部。继续向上移动鼠标。注意光标出现在屏幕底部。这种调节器的操作允许你在不受区域限制的情况下滚动。

## 撤销调节器更改

在调整调节器时，可以通过按住左键右键鼠标来立即撤销所做的任何更改。这允许你在工作时快速尝试调节器设置。

你刚刚学会了如何使用调节器更改对象的参数。现在我们来看看在输入框中输入值的绝对方法：

1. 双击参数展开列表中的长度（`Length`）输入框并输入 60。注意盒子的长度发生了变化，长度值变为 `50.0"`，这是 60 英寸的等价表示。注意，表示英寸时不需要输入符号（`"`）。然而，在输入英尺测量值时需要输入引号（`'`）。这是由于你在本章之前的设置对话框中选择了英寸（Inches）作为默认单位。

2. 按 `Tab` 键。注意宽度值现在被选中。

| 参数 | |
| --- | --- |
| 长度 | 50.0 |
| 宽度 | 125.961 |
| 高度 | 20.299 |

3. 为宽度输入 `60'` 并按 `Tab`。高度值被选中。

4. 再次输入 `5'`。盒子现在是一个 60 英寸的正方形。

## 使用立方创建方法

你也可以通过选择创建方法（Creation Method）展开列表中的立方（Cube）按钮创建一个立方。

如果有一系列相关的输入框（例如上一个练习中的长度、宽度和高度框），`Tab` 键允许你在下一个值之间切换。你会发现整个 Autodesk VIZ 2008 中数字输入框和调节器非常常见。

## 设置调节器变化率

如果你在按住 `Ctrl` 键时移动调节器，值的变化率会增加。如果你按住 `Shift` 键，变化率会降低。

你刚刚学会了如何使用调节器更改对象的参数。现在我们来看看在输入框中输入值的绝对方法。（注：文本似乎有跳转或合并，请遵循逻辑流阅读）。

### 选择和移动对象

VIZ 的工具非常简单：

1. 点击主工具栏上的选择对象（Select Object）工具。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_47_0.png)

2. 将光标放在盒子上。它会变成加号。

3. 如果盒子未被选中，点击盒子。会出现一个名为移动变换轴（Move Transform gizmo）的图形，显示了盒子相对于视口的 `X`、`Y`、`Z` 取向。盒子的角上也会出现选择框。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_48_0.png)

4. 将光标放在移动变换轴的蓝色 `Z` 轴柄上；蓝色箭头代表 `Z` 轴。注意 `Z` 轴变为黄色，`Y` 轴标签恢复红色。

5. 将光标放在 `XY` 平面柄上，即连接 `X` 和 `Y` 轴柄的正方形。注意 `XY` 平面柄变为黄色。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_48_2.png)

6. 点击并拖动蓝色的 `Z` 轴箭头。现在，移动被限制在 `Z` 轴上，即远离或靠近网格。你可以猜想到，点击并拖动绿色的 `Y` 轴箭头会限制 `Y` 轴上的移动。

## 上一个变换的轴将用黄色高亮

黄色高亮的轴是上一次使用的轴约束。例如，如果你在 `Y` 方向上对对象进行变换，下次你开始变换对象时，`Y` 轴将高亮显示。

如果你点击的对象位于坐标箭头以外的位置，但仍位于对象上，你可以在当前的轴限制或平面限制内自由移动该对象。请注意，对象的坐标值显示在绘图工具正下方的状态栏中。

### 限制运动

“约束”（Constraints）工具栏中的工具可以限制对象在 `X`、`Y` 或 `Z` 轴上的运动。例如，要限制 `X` 轴上的运动，请点击“选择并移动”（Select and Move）工具，然后点击约束工具栏中的 `X` 工具。所选对象的运动将受限制在 `X` 轴上。在 VIZ 的早期版本中，这是允许运动的唯一方法。

约束工具栏提供的另一个重要功能是选择默认的自由移动平面。在前面的练习第 5 步中，你能够在 `XY` 平面内自由移动盒子，但你被限制在该平面内。约束工具栏允许你选择受限制的默认平面。“限制到 XY 平面”（Restrict to XY Plane）是一个浮动选项，你可以通过选择三个选项之一来选择想要限制运动的平面。`XY` 平面对于你几乎所有的工作都适用；偶尔你可能想使用其他选项，因此了解这个工具是有好的。你也可以通过简单拖拽变换手柄（Transform gizmo）的相关部分来访问这些约束平面——这非常有用。

如果你倾向于使用快捷键而不是工具，`F5`、`F6` 和 `F7` 键分别切换 `X`、`Y` 和 `Z` 轴约束。反复按下 `F8` 可以在 `XY`、`YZ` 和 `XZ` 平面约束之间循环。

最后，一个与变换工具相关的工具是“选择锁定切换”（Selection Lock Toggle）。
