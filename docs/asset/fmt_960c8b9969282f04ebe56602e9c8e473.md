
## 7.2 进程项

- `stat` 包含了大量关于进程的状态和统计信息。这些数据与 `status` 条目提供的数据相同，但以原始数值格式呈现，且全部在同一行。这种格式难以阅读，但可能更适合解析程序。
- 如果你想在程序中使用 `stat`，请查看 `proc` 手册页，它通过调用 `man 5 proc` 来描述其内容。
- `statm` 包含了关于进程使用内存的信息。`statm` 条目的描述在第 7.2.6 节“进程内存统计”中。
- `status` 包含了大量关于进程的状态和统计信息，格式化后便于人类理解。第 7.2.7 节“进程统计”包含了对 `status` 条目的描述。
- `cstat` 仅在 SMP Linux 内核上出现。它包含了按 CPU 分类的进程时间（用户态和内核态）。

出于安全考虑，某些条目的权限被设置为只有拥有该进程的用户（或超级用户）才能访问它们。

### 7.2.1 `/proc/self`

`/proc` 文件系统中的一个条目使得通过 `/proc` 查找其进程的信息变得简单。`/proc/self` 是一个指向与当前进程对应的 `/proc` 目录的符号链接。`/proc/self` 链接的目标取决于哪个进程在查看它；每个进程都将自己的进程目录作为链接的目标。

例如，列表 7.2 中的程序读取 `/proc/self` 链接的目标来确定其 ID。调用在第 3 章“进程”、在第 3.1.1 节“进程 ID”中描述的 `getpid` 函数是实现相同功能的更简单的方法。该程序使用了第 8.11 节“readlink: 读取符号链接”中描述的系统调用来提取符号链接的目标。

列表 7.2 `get-pid.c` 从 `/proc/self` 获取进程 ID

```c
#include <stdio.h>
#include <sys/types.h>
#include <unistd.h>

/*
 返回调用进程的 ID，是根据
 /proc/self 符号链接确定的。 */

pid_t get_pid_from_proc_self ()
{
    char target[32];
    int pid;
    /* 读取符号链接的目标。 */
    readlink("/proc/self", target, sizeof(target));
```

列表 7.2 继续

```c
/* 目标是一个以进程 ID 命名的目录。 */
sscanf(target, "%d", &pid);
return (pid_t) pid;
}

int main () {
    printf("/proc/self reports process id %d\n",
        (int) get_pid_from_proc_self ());
    printf("getpid() reports process id %d\n", (int) getpid ());
    return 0;
}
```

### 7.2.2 进程参数列表

`cmdline` 条目包含参数列表（参见第 2 章“编写良好的 GNU/Linux 软件”，第 2.1.1 节“参数列表”）。参数以单个字符字符串的形式呈现，参数用 NUL 分隔。大多数函数期望整个字符串以单个 NUL 结尾，并且不会处理嵌入在字符串中的 NUL，因此你必须妥善处理这些内容。

#### NUL 与 NULL

NUL 是整数值为 0 的字符。它与 NULL 不同，NULL 是一个值为 0 的指针。

在 C 语言中，字符字符串通常以 NUL 字符结束。例如，字符字符串 `"Hello, world!"` 占用 14 字节，因为感叹号后面有一个隐式的 NUL 表示字符串的结束。

相反，NULL 是一个指针值，它永远不会对应于程序中的真实内存地址。

在 C 和 C++ 中，NUL 被表示为常量 `'0'` 或 `(char)0`。NUL 的定义随操作系统而异；在 Linux 上，它在 C 中被定义为 `((void*)0)`，在 C++ 中简单地定义为 `0`。

在 2.1.1 节中，我们展示了列表 21 中打印 `cmdline` 的程序。使用 `/proc` 文件系统，我们可以实现一个打印另一个进程参数的程序。列表 7.3 就是这样一个程序；它打印指定进程 ID 进程的参数列表。由于 `cmdline` 内容中可能有多个 NUL 而不是仅在结尾有一个，我们无法使用 `strlen` 来确定字符串长度。`strlen` 只是计数到遇到第一个 NUL 为止。相反，我们通过 `read` 获取 `cmdline` 的长度，`read` 返回读取的字节数。

列表 7.3 `print-arg-list.c` 打印运行中进程的参数列表

```c
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <unistd.h>

/* 打印给定 PID 进程的参数列表，每个参数占一行。 */
void print_process_arg_list(pid_t pid) {
   int fd;
   char filename[24];
   char arg_list[1024];
   size_t length;
   char* next_arg;

   /* 生成该进程的 cmdline 名称。 */
   sprintf(filename, "/proc/%d/cmdline", (int) pid);
   /* 使用 read 确定 cmdline 的长度，read 返回读取的字节数。 */
}
```

### 7.2.5 进程文件描述符

`fd` 是一个子目录，其中包含了进程打开的文件描述符的条目。每个条目都是指向在该描述符上打开的文件或设备的符号链接。你可以对这些符号链接进行写入或读取；等同于写入或读取目标进程中对应的文件或设备。`fd` 子目录中的条目以文件描述符数字命名。

这里有一个你可以尝试在 `/proc` 的 `fd` 条目上实用的小技巧。打开一个新窗口，并通过 `ps` 找到运行中进程的进程 ID。

```bash
% ps
PID TTY           TIME CMD
1261 pts/4       00:00:00 bash
2455 pts/4       00:00:00 ps
```

在这种情况下，shell `bash` 运行在进程 1261 中。现在打开第二个窗口，查看进程的 `fd` 子目录的内容。

```bash
% ls -l /proc/1261/fd
total 0
lrwx------ 1 samuel samuel 64 Jan 30 01:02 0 -> /dev/pts/4
lrwx------ 1 samuel samuel 64 Jan 30 01:02 1 -> /dev/pts/4
lrwx------ 1 samuel samuel 64 Jan 30 01:02 2 -> /dev/pts/4
```

记得我们在第 2.1.4 节“标准 I/O”中提到过，文件描述符 0、1 和 2 分别初始化为输入、输出和错误。因此，通过向 `/proc/1261/fd/1` 写入，你可以向 shell 进程中的 `stdout` 设备写入——在这种情况下是第一个窗口中的伪 TTY。在第二个窗口中，尝试向文件写入消息：

```bash
% echo 'Hello, world.' >> /proc/1261/fd/1
```

文本出现在第一个窗口中。

```c
size_t get_executable_path(char* buffer, size_t len)
{
  char* path_end;
  /* Read the target of /proc/self/exe. */
  if (readlink("/proc/self/exe", buffer, len) <= 0)
    return -1;

  /* Find the last occurrence of a forward slash, the path separator. */
  path_end = strchr(buffer, '/');
  if (path_end == NULL)
    return -1;

  /* Advance to the character last slash. */
  ++path_end;
  /* Obtain the directory containing the program by truncating
     path after the last slash. */
  path_end = '\0';
  /* The length of the path is the number of characters up through
     last slash. */
  return (size_t)(path_end - buffer);
}

int main () {
  char path[PATH_MAX];
  get_executable_path(path, sizeof(path));
  printf("this program is in the directory %s\n", path);
  return 0;
}
```
