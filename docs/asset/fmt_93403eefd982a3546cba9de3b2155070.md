
# Linux 串口教程

```
C-Kermit set modem type usr ; 选择调制解调器类型
C-Kermit set line /dev/ttyS3 ; 选择通信设备
C-Kermit speed 11500 ; 设置拨号速度
C-Kermitdial765421 ; 拨号
Device=/dev/ttyS3, modem=usr, speed=11500
连接完成。<BEEP
连接到 /dev/ttyS3，速度 11500
义字符是 Ctrl-\ (ASCII 28, FS)
输入义字符后接 C 返回，
或后接 ? 查看其他选项。

Welcome to ...
login:
```

参见串口程序如果需要帮助。当你的 Linux 系统启动时，只有 `ttyS(0-3)` 配置了默认的中断 4 和 3。因此，如果你有其他板提供的串口，或者 `ttyS(0-3)` 有非标准中断，你必须使用 `setserial` 配置这些串口。完整列表请参阅主页。

## 5.3 调制解调器配置

对于仅拨出，你可以按照你的想法配置调制解调器。如果你打算在拨入时使用调制解调器，你必须以你意愿的方式配置 `getty`。然而，大多数调制解调器在 `getty` 运行到串口时会自动设置速度。这样 `getty` 在 115,000 速度下工作。对于这些调制解调器支持的设置，请参阅调制解调器说明。

## 5.4 硬件流控

如果你的调制解调器支持硬件流控（`RTS/CTS`），我强烈建议使用它。这对于支持数据压缩的调制解调器尤为重要。首先，你必须在串口本身上启用 `RTS/CTS` 流控。最好在启动时完成，例如在 `/etc/rc.d/rc.local` 或 `/etc/rc.d/rc.serial` 中。确保这些文件由主 `rc.sysinit` 执行！对于你想启用流控的每个串口，你需要执行以下操作：

```
stty crtscts < /dev/ttyS3
```

如果未启用，你还必须在调制解调器上启用 `RTS/CTS` 流控。你的通信程序可能会启用它。如果需要，请参阅调制解调器说明，然后如果调制解调器支持存储配置，请保存配置。

## 6 如何用 getty_ps 用我的调制解调器拨入拨出

让你的调制解调器正确拨出。如果你还没有阅读这一节，现在就去！它包含了非常重要的设置信息。如果你只想用调制解调器拨出，则不需要阅读这一节。

### 6.1 拨入拨出调制解调器配置

对于拨入和拨出使用，你必须以某种方式设置调制解调器（再次使用调制解调器上的 `AT` 命令）：

```
E1 回显开启

Q0 报告代码

V1 详细模式开启

S=0 从不回答 (ugty 通过 WAITFOR 选项处理此)
```

如果你没有正确设置这些，配置文件中的 `INIT` 字符串可能会失败，导致整个过程混乱。但关于配置文件的更多信息见下文……

```
&C1 DCD 连接后开启

&S0 DSR 始终开启

DTR 开启/关闭重置调制解调器（取决于制造商-RTFM）
```

这些在调制解调器启动和结束时影响它。

如果你的调制解调器不支持存储配置，可以通过配置文件中的 `INIT` 字符串设置这些。见下文。某些调制解调器带有影响寄存器设置的 DIP 开关。确保这些也设置正确。

我开始收集了针对不同类型调制解调器的设置方案。目前，我只有其中几个，如果你愿意向我发送你正在使用的配置，请尽管发送！你可以在 `http://ftp.cc.gatech.edu/pub/people/gregh/modem-configs` 获取它们。

注意：为了让我的 US Courier V.34 调制调器在 DTR 下降时正确重置，我必须设置 D2 和 S13=1（这设置了寄存器 S13 的第 0 位）。这已在 USR Sportster V.34 调制调器上确认有效。

注意：某些 Supra 调制调器对 DCD 的处理方式与其他调制调器不同。如果你正在使用 Supra，尝试设置 `&C0` 而不是 `&C1`。你必须设置 `&D2` 以正确处理 DTR。

## 6.2 安装 getty_ps

从 `sunsite.unc.edu/pub/Linux/system/serial` 获取最新版本。特别是，如果你想使用高速度（57600 和 115200 波特），你必须获取 2.0.7j 或更高版本。你还必须拥有 `libc` 5.x 或更高版本。

默认情况下，`getty_ps` 将配置为符合 Linux FSTND（文件系统标准），这意味着二进制执行文件将位于 `/sbin`，配置文件将命名为 `/etc/config.[ugetty].ttyN`。这在文档中并没有明确说明！它还会期望锁文件位于 `/var/lock`。请确保你有 `/var/lock` 目录。

如果你不使用 FSTND 标准，二进制执行文件将进入 `/etc`，配置文件将进入 `/etc/default/[ugetty].ttyS`，锁文件将存放在 `/usr/spool/uuc`。如果你在使用 UOCP，我建议使用这种方法，因为如果你将锁文件移动到它所在的位置，UOCP 将出现问题。

`getty_ps` 还可以使用 `syslog` 来记录消息。如果你还没有运行它，请参阅 `syslog(1)` 和 `syslog.conf(5)` 的帮助页来设置 `syslog`。消息使用优先级 `LOG_AUTH` 记录日志，错误使用 `LOG_ERR`，调试使用 `LOG_DEBUG`。如果你不想使用 `syslog`，可以编辑 `getty_ps` 源文件中的 `tune.h`，以用日志文件代替消息，默认为 `/var/adm/getty.log`。

决定你是否需要 FSTND 标准和 `syslog` 功能。你也可以选择两者的结合。编辑 `Makefile`、`tune.h` 和 `config.h` 以反映你的决定。然后按照软件包随附的说明进行编译和安装。

从现在起，所有对 `getty` 的引用将指向 `getty_ps`。对 `ugetty` 的引用将指向 `getty_ps` 软件包自带的 `ugetty`。这些指令不适用于 `mgetty` 或 `aty`。

## 7. ugetty

### 7.1 设置 ugetty

确保你为调制调器所在的串口端口准备了一个输出和一个输入设备。如果你的调制调器在 `ttyS3` 上，你需要 `/dev/cua3` 和 `/dev/ttyS3` 设备。如果你没有正确的设备，请查看“在 /dev 中创建设备”章节了解如何创建设备，并创建这些设备。如果你希望能够使用你的调制调器拨打出号，且 `ugetty` 正在监听端口等待登录，请使用 `/dev/cuaN` 设备代替 `/dev/ttyN` 设备 [如果软件在编写时为了避免使用它，就不需要 `cua` 了]。

`ugetty` 会进行重要的锁文件检查。更新 `/etc/getdefs` 以包含你的调制调器条目。编辑完 `/etc/getdefs` 后，可以通过观察端口的操作来验证语法是否正确：

```
linux# -c /etc/getdefs
```

### 现代调制调器

如果你有一个带有数据压缩功能的 9600 bps 或更快的调制调器，你可以将串口串口锁定在一种速度上。例如：

```
# 115200 固定速度

F115200# B115200 CS8 # B115200 SANE -ISTRIP HUPCL ##S @L@B login:

#F115200
```

如果你将调制调器设置了 `RTS/CTS` 硬件流控，你可以在条目中添加 `CRTSCTS`：

```
# 115200 带有硬件流控的固定速度

F115200# B115200 CS8 CRTSCTS # B115200 SANE -ISTRIP HUPCL CRTSCTS ##S @L@B login:#F115200
```

### 旧慢速调制调器

如果你有一个慢调制调器（低于 9600 bps），那么不需要为单一速度使用单行，而是需要几行来尝试多种速度。注意，这些行通过行尾的“单词”连接在一起，例如 `#38400`。每个条目之间需要空行。

# Linux 串口 HOWTO

```
# 调制调器条目

115200# B115200 CS8 # B115200 SANE -ISTRIP HUPCL @@S @L @B login: #57600

57600# B57600 CS8 # B57600 SANE -ISTRIP HUPCL @@S @L @B login: #38400

38400# B38400 CS8 # B38400 SANE -ISTRIP HUPCL @@S @L @B login: #19200

2400# B2400 CS8 # B2400 SANE -ISTRIP HUPCL @@S @L @B login: #115200
```

### 登录横 (Banner)

如果你愿意，可以让 `uugetty` 在登录 banner 中打印有趣的内容。在我的示例中，包含了系统名称、串口和当前比特率。你可以添加其他内容：

```
@B 当前比特率。

@D 当前日期，MM/DD/YY。
```
