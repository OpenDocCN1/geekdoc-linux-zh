# FreeBSD 6 UNASHED

- 安装最新版本的 FreeBSD
- 配置操作系统
- 配置 X Window 系统
- 设置 FreeBSD 上的服务，包括电子邮件和 FTP 服务器
- 安装可以与 Microsoft Windows 客户端共享文件的 FreeBSD 服务器
- 深入了解网络安全
- 配置 FreeBSD 上的 SQL 数据库
- 监控性能
- 在你的系统中安装额外软件并配置 DHCP
