现在使用 `echo` 语句提供 `ed` 命令。为了确保无无，我在插入我的新内容到第 1 行之前设置了一个地址：

```
echo "1"

<Files ".user.ini">
<IfModule mod_authz_core.c>
Require all denied
</IfModule>
<IfModule mod_authz_core.c>

</IfModule>

w" | ed $x
done
```

```bash
ed $x <<EOE
1
i
# Wordfence WAF
<Files ".user.ini">
<IfModule mod_authz_core.c>

</IfModule>
<IfModule mod_authz_core.c>
Order deny,allow
Deny from all
</IfModule>
</Files>

.
w
q
EOE
```
