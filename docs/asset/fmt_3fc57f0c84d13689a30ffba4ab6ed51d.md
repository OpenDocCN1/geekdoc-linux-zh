# 第 5 章 Shell 脚本编程概念

shell 使用特殊参数来执行特定任务，例如位置参数的数量、脚本名称、shell 的 PID 或命令的状态。特殊参数无法由你赋值。你只能通过特殊符号引用它们的内容。特殊符号扩展为实际值。

| 表 5-3 shell 使用的特殊参数的描述 |

| 特殊参数 | 描述 |

| `@` | 扩展为从 1 开始的位置参数 |

| `#` | 扩展为位置参数的数量 |

| `?` | 扩展为之前执行命令的状态 |

| `$` | 扩展为 shell 的 PID |

| `!` | 扩展为之前执行的进程 |
