# Tar

`tar` 软件包包含 `tar` 和 `rmt` 程序。

### 描述
### tar
`tar` 是一种归档程序，用于从名为 `tarfile` 的归档文件中存储和提取文件。

### rmt
`rmt` 是远程转储和恢复程序使用的程序，通过进程间通信连接操作磁带驱动器。

# Textutils
目录

`Textutils` 软件包包含 `cat`, `cksum`, `comm`, `split`, `cut`, `expand`, `fmt`, `fold`, `head`, `md5sum`, `nl`, `od`, `paste`, `pr`, `ptx`, `sort`, `split`, `tac`, `tail`, `tr`, `tsort`, `expand`, `uniq` 和 `wc` 程序。

### 描述
### cat
`cat` 将文件或标准输入连接到标准输出。

### cksum
`cksum` 打印每个指定文件的 CRC 校验和和字节数。

### comm
`comm` 按行比较两个排序后的文件。

### csplit
`csplit` 将按模式分隔的文件部分输出到文件 `xx01`, `xx02`, ... 中，并将每个部分的字节数输出到标准输出。

### cut
`cut` 将指定文件中选定的行部分打印到标准输出。

### expand
`expand` 将文件中的制表符转换为空格，写入标准输出。

### fmt
`fmt` 重新格式化指定文件中的每个段落，写入标准输出。

### fold
`fold` 对每个指定文件中的输入行进行折叠，写入标准输出。

### head
`head` 将每个指定文件的前 `xx` 行打印到标准输出，默认 `10` 行。

### join
`join` 根据公共字段连接两个文件中的行。

### md5sum
`md5sum` 打印或检查 MD5 校验和。

### nl
`nl` 将每个指定文件写入标准输出，并添加行号。

### od
`od` 将指定文件的无歧义表示写入标准输出，默认为八进制字节。

### paste
`paste` 写入由顺序对应的行组成的行。

### pr
`pr` 以格式化页面打印文件。

### ptx
`ptx` 处理文件以便打印机输出。

### sort
`sort` 对文本行进行排序。

### split
`split` 将文件分成若干部分。

### tac
`tac` 反转每个文件的行。

### tail
`tail` 打印每个文件的最后部分。

### tr
`tr` 翻译或删除字符。

### tsort
`tsort` 对文本进行排序。

### uniq
`uniq` 过滤重复行。

### wc
`wc` 统计字节、单词和行数。
