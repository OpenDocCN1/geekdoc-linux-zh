| `~r` | 按文件名读取文件并将其内容添加到你的消息中。 |
| `~<` | 按文件名读取文件（使用重定向运算符）并将其内容添加到你的消息中。 |
| `~<!` | 执行指定的命令并将其内容放入你的消息中。 |
| `~v` | 调用视觉编辑器、`vi` 编辑器或使用 `VISUAL` 变量的值。 |
| `-w 文件名` | 将当前编写的消息写入指定的文件中。 |
