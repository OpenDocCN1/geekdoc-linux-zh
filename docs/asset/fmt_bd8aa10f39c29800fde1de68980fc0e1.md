
# Alias
默认情况下，Apache 仅提供单个 `DocumentRoot` 文件夹下的文件。`Alias` 选项类似于 IIS 中的虚拟目录，允许 Web 路径以 Web 服务器上任何所需的目录开始。在这种情况下，我们将 `/test` 映射到目录 `/usr/share/doc/jsp/test`，这里正是 Mono 项目的 ASP.NET 示例的安装位置。

# AddMonoApplications
如前所述，Web 应用程序实际上运行在另一个名为 XSP 的独立服务器上。`mod_mono` 模块在需要该服务器时会自动启动。因为 XSP 是一个独立的程序，它并并不知道我们刚刚创建的 `/test` 和 `/usr/share/doc/jsp/test` 之间的别名。因此，我们通过由 `mod_mono` 模块提供的 `AddMonoApplications` 选项再次为 XSP 提供这些信息并传递给它。在我们的示例中，`AddMonoApplications` 只接受两个参数。第一个参数是本文讨论的重点，应设置为默认值。第二个应设置为 `/test:/usr/share/doc/jsp/test`，以便告诉 XSP 对 `/test` 文件夹中内容的请求实际上指向 `/usr/share/doc/jsp/test` 中的内容。

# Location
`Location` 选项是一个容器，用于包含引用特定子目录的额外选项。`Location` 选项以 `<Location` 开头，随后是子目录名 `/test>`。后面是适用于 `/test` 的选项，并以 `</Location>` 结束。

# SetHandler
默认情况下，Apache 将按照其通常规则交付 `/test` 虚拟目录中的内容。ASP.NET 页面将作为普通的 HTML 下载，而不会执行 ASP.NET 代码。`SetHandler` 选项此处包含在 `<Location /test>` 容器中，指定了负责交付 `/test` 内容“内容处理器”。在这种情况下，我们希望使用 `mono_mono` 模块接管并通过 XSP 正确交付 ASP.NET 页面。

按照以下步骤配置 `linux1.corp.com` 的 Apache 服务器以支持 `/test` 虚拟目录中的 ASP.NET 页面：

1. 将以下行添加到你的 `/etc/httpd/conf/httpd.conf` 文件的末尾：

```
LoadModule mono_modules modules/mod_mono.so
Alias "/test /usr/share/doc/jsp/test"
AddMonoApplications default "/test:/usr/share/doc/jsp/test"
<Location /test>
SetHandler mono
</Location>
```

2. 重启支持 mono 的 Web 服务器

```
service httpd restart
```

如果你收到错误信息，请确保你确实已经按照之前介绍的步骤安装了 Mono RPM 包。

访问 `http://1inserv1.corp.com/test/` 查看结果。可以随意点击图 10.5 所示的任何示例。

# 使用 JASP 测试示例 ASP 应用程序

但它有效吗？让我们通过创建一个“Hello World” ASP 页面来寻找答案。虽然这不是一本编程书籍，但对我们正在看的内容进行简要说明会有帮助。

ASP 类似于微软的 .NET ASP 系统，它通过在 HTML 页面中寻找 `<` 和 `>` 标记之间的内容来识别 ASP 代码。ASP 最重要的功能之一是生成当前发送给用户的 HTML 页面部分内容。这允许页面的部分包含动态检索的信息，例如数据库查询的结果。

当我们把以下

```
response.write("<h1>ASP Test Page</h1>")
```

放在 `<` 和 `>` 之间，并给页面命名以 `.asp` 结尾的文件时，JASP 引擎将识别该代码，并在每次网页浏览器访问该页面时执行它，引号内的 HTML 将作为页面的一部分发送到浏览器中。网页浏览器永远看不到代码。浏览器只看得看到它生成的 HTML。

由于该页面的部分 HTML 代码是由 ASP 代码生成的，除非 JASP 引擎正在运行，否则该页面在网页浏览器中将显示为空白。请按照以下步骤创建并查看测试 ASP 页面：

1. 使用你偏好的文本编辑器，在 `linserv1.corp.com` 上创建 `/var/www/html/test.asp` 文件。
2. 在文件中放置以下内容：

```html
<head>
<title>JASP Test Page</title>
</head>
<body>
% response.write("<h1>ASP Test Page</h1>") %%
</body>
</html>
```

3. 在你的网页浏览器中访问以下 URL：

`http://linserv1.corp.com/test.asp`
