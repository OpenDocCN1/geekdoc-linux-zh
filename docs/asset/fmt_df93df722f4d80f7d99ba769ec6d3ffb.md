# 古物石学

植物以多种方式被保存，保存过程中涉及物理和化学过程的各种结合。要演变成化石，必须连续发生独特的过程来保存叶片。第一个过程涉及靠近沉积物聚集的场所，而叶片的快速埋藏确保了它不会被磨损或破坏。快速埋藏对于确保微生物的生物活动破坏植物材料至关重要。

叶片部分保存在细粒的粉砂和砂中，这些沉积物代表了古代沉积的层。这些沉积物通常产生极佳的化石，因为微小的粒径保护了脆弱部分免受损坏。保存的化石质量取决于其他化石是否会被保存或被侵蚀。例如，沉积在粘土或页岩中的沉积物随着时间的推移可能成为系统，或因河流系统切入含化石岩石而被侵蚀。

植物化石广泛应用于各个地质领域：植物生物学、古物石学和生物地理学。在古物石学中，可以追溯过去植物群的地质记录。植物化石为从古生时代早期到用于食物和庇护的复杂多细胞开花植物的植物演化知识提供了巨大的推动。在生物地层学中，一些植物巨化石以及花粉和孢子被用于岩石计时。植物化石在重建过去的陆地环境方面也具有价值。参考 古物石学；地层学。

古海洋学是关于沉积、生物学、化学和沉积模式的海洋研究。信息来源主要是深海盆地，可以通过搜索海洋古物石学或海洋沉积学来找到。它与地球物理学、海洋化学和数学建模也有强有联系。地球化学化石用于重建地理（大陆位置、洋壳的水平运动）、气候（任何海底部分的整体沉降）和年代（海底的放射性、磁性模式和同位素），沉积成分（碳酸盐、石油和微量元素等各种成分的组成）。这些信息被用于沉积序列，结合地球化学提供了关于碳和营养循环动态的见解。数学建模引入了强定量元素。它与地质学和古物石学共同发展。参考 气候；地球物理学；古物石学；沉积学。

陆地沉积物的研究本身一样古老。它的区别在于对从海洋（尤其是深海）回收的沉积物的研究，以及由输送者（输送流和上升流）开发的概念，这些概念调节了沉积预算、营养循环、古生物地理学和海洋历史。早期研究是对美国“卡里俄号”（1956年）船在北大西洋采集的岩芯进行的。这些沉积层现在通常被称为海因里希层（Heinrich layers）；据说它们来自最后冰川时代冰川碎的偶尔涌入。参考 地质学。

通过全球深海探险（1947-1969）系统性地获取岩芯，可以比较主要洋盆之间的气候速率，获取的科研岩芯长可达15米（50英尺），记录可达50,000至10亿年。许多基础古海洋学概念是由分析这些岩芯的生物学家建立的，包括更新世冰川-间冰期趋势的作用、北大深层水的循环供应、晚第四纪的周期性本质，以及生物地理边界的大尺度位移。参考 气候；古物石学。

### 古气候学

浮游植物、微浮游植物以及行动虫在白垩纪末消失。尽管如章鱼、鹦鹉螺等少数物种生存了下来，生物在始新世直到第三纪之前发生了高度多样化。参考 生物学。

化石指示物通过其分布（古生物地理）提供了关于气候的信息，后者通常是地质记录中较窄的耐受性部分。另一个信息来自古气候模式和稳定同位素地球化学。

在陆地上，哺乳动物在白垩纪末期间多样化，包括鳄鱼和鳄鱼在扩张并继续繁衍。这一时期的真哺乳动物是原始且体较小的。随着澳大利亚大陆变得孤立，有袋类等动物被隔离。参考 哺乳动物；古物石学。

气候和冰体积的变化难以区分，因为地质记录对于长期气候变化和冰盖历史的研究有限。参考 地质学；化石。

古气候学。古代时期的气候特别是地表植被和土壤类型。在古代世界，古气候学家必须依赖地质学（如沉积学和古物石学）以及地球化学、大气化学和海洋物理。对古代气候系统的理解提供了预测其未来行为的能力。参考 气候。

# 古生代 1599

现代生态学的实验性方法和直接测量法（这些是现代生态学的组成部分）在古生物学中通常是无法实现的。例如，化石组合的信息失真和丢失很少与现生生物群落一致。古代生态环境的程度尚不确定。证据的缺乏可以通过这一事实得到弥补：古生态学发生在跨越巨大时间尺度，而这是现代科学无法利用的，且可能与环境模式有关。

更重要的是，必须记录气候变化的总体模式；古生物学依赖于对在塑造演化中起着明确作用的环境趋势的识别和解释。

古生物学的目标之一包括：重建古代环境、从化石中推断古代生物的模型、识别反复出现的古代生物群、重建群落及其相互作用，以及生态系统中大型且长期变化模式的规模。

为了理解古代生命，必须满足某些参数，例如温度、盐度、氧气水平、营养盐浓度和水化学。在深层次上，古生态学通过现代实验的发展与生态学领域直接相互作用。

## 沉积系统与策略

解释古代生物的生活模式（通过化石）是一项多学科交叉的方法。虽然生活模式无法通过完整的古生物学定义，但古生物学家通常可以推断行为类型、代谢和活动程度的总体趋势。

化石记录包含了过去群落或古生物群落的偏倚遗骸。古生物群落通常被认为是化石物种的联合体。多元分析被用于发现反复出现的化石群落。

古生物群落在时间上不是静态的实体，而是随着时间尺度的经历独立的变化，例如演替和演化。由于这些变化发生在非常短的时间尺度上（从几十年到几个世纪），因此短期变化很少被采样到。跨越数千年的群落结构长期变化尚未得到真正的验证。这些变化是真正的群落响应，涉及迁徙、灭绝或向不同地点的转移。

## 生态成功

生物在不稳定的环境中演化。在真空状态下，生物之间随时间产生相互作用具有巨大可能性。这种捕食作用强度的增加可能对演化变化产生重要影响。
