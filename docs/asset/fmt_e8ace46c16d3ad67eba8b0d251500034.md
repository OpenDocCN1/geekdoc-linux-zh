
`httpd stream tcp nowait httpd /usr/local/apache/conf/httpd.conf`

此示例中的`httpd`二进制文件和`httpd.conf`配置文件的路径假定您已使用默认设置从源代码安装了Apache。此条目表示，每次`inetd`收到`HTTPD`连接时，都应使用指定的`httpd.conf`文件启动`httpd`。

此外，您必须指定传入`HTTPD`连接将使用的端口。这是在`/etc/services`文件中指定的。该文件必须具有以下条目，以支持标准端口80上的`HTTPD`：

```
httpd 80/tcp httpd
```

创建这些条目后，应使用以下命令重启`inetd`：

```
# /etc/rc.d/init.d/inet stop
# /etc/rc.d/init.d/inet start
```

或者，您可以通过向`inetd`发送`SIGHUP`信号来强制其重新加载配置文件：

```
# kill -1 `cat /var/run/inetd.pid`
```

> **提示**
> 如果您通过`inetd`运行Apache，则不希望它包含在用于启动的`rc`脚本中。检查您的启动脚本，确保您没有在启动时启动`httpd`。有关`rc`启动脚本的详细信息，请参阅第4章“启动和关闭”。
