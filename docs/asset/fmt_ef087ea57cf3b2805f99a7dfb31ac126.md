
# XChangeGC

`XChangeGC` 函数更改指定 GC 中由 `valuemask` 指定的组件。参数包含要设置的值。这些值和限制与 `XCreateGC` 相同。更改裁剪掩码（`clip-mask`）会覆盖之前的 `XSetClipRectangles` 请求。更改虚线偏移（`dash-offset`）或虚线列表（`dash-list`）会覆盖上下文之前的 `XSetDashes` 请求。验证和更改组件的顺序取决于服务器。如果产生错误，部分组件可能已经被更改。

`XChangeGC` 可能会生成 `BadAlloc`, `BadFont`, `BadGC`, `BadMatch`, `BadPixmap` 和 `BadValue` 错误。

要获取给定 GC 的组件，使用 `XGetGCValues`。

```
Status XGetGCValues(display, gc, valuemask, values_return);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。
- `valuemask` 指定要在 `values_return` 参数中返回 GC 中的哪些组件。此参数是零或多个有效 GC 组件掩码位的按位或运算的结果。
- `values_return` 在指定的 `GCValues` 结构中返回 GC 值。

`XGetGCValues` 函数返回指定 GC 中由 `valuemask` 指定的组件。如果值包含有效的 GC 掩码位（`GCFunction`, `GCPlaneMask`, `GCForeground`, `GCBackground`, `GCLineWidth`, `GCLineStyle`, `GCCapStyle`, `GCJoinStyle`, `GCFillStyle`, `GCFillRule`, `GCT`, `GCStipple`, `GCClipTextStyle`, `GCClipTypeOrigin`, `GCFont`, `GCSubwindowMode`, `GGraphicsExposures`, `GCClipOrigin`, `GCOffsetYOrigin`, `GCDashOffset`, `or GCMode`）且没有发生错误，`XGetGCValues` 将在 `values` 中设置的组件并返回非零状态。否则，它返回零状态。注意不能请求裁剪掩码和虚线列表（在 `valuemask` 中分别由 `GCClipMask` 和 `GCDashList` 表示）。注意，如果组件从未被客户端显式设置过，则 `GCFont`, `GCTitle` 和 `GCStipple` 将返回一个无效的资源 ID（其一个或多个最高位被置为 1）。

要释放 GC，使用 `XFreeGC`。

```
XFreeGC(display, gc);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。

`XFreeGC` 函数销毁指定的 GC 以及所有关联存储。

`XFreeGC` 可能会产生 `BadRequest`。

要获取 GC 的上下文，使用 `XFromGC`。

```
GCContext XFromGC(gc);
```

- `gc` 指定你想要资源 ID 的 GC。

Xlib 通常推迟发送到服务器的组件，直到实际调用它。在某些情况下，客户端可能需要强制发送。要强制更改 GC 组件，使用 `XFlushGC`。

```
void XFlushGC(display, gc);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。

## 使用图形上下文程序

本节讨论了如何设置：

- 前景、背景、平面掩码、函数组件
- 线属性和虚线组件
- 填充样式和填充规则组件
- 填充瓦样式组件
- 字体组件
- 裁剪区域组件
- 弧模式、子窗口模式和图形暴露组件

### 设置前景、背景、函数或平面掩码

要设置给定 GC 的前景、背景、平面掩码和函数组件，使用 `XSetState`。

```
XSetState(display, gc, foreground, background, function, plane_mask);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。
- `foreground` 指定要为 GC 设置的前景。
- `background` 指定要为 GC 设置的背景。
- `function` 指定要为 GC 设置的函数。
- `plane_mask` 指定平面掩码。

`XSetState` 可能会生成 `BadAlloc`, `BadGC` 和 `BadValue` 错误。

要设置给定 GC 的前景，使用 `XSetForeground`。

```
XSetForeground(display, gc, foreground);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。
- `foreground` 指定要为 GC 设置的前景。

`XSetForeground` 可能会生成 `BadAlloc` 和 `BadGC` 错误。

要设置给定 GC 的背景，使用 `XSetBackground`。

```
XSetBackground(display, gc, background);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。
- `background` 指定要为 GC 设置的背景。

`XSetBackground` 可能会生成 `BadAlloc` 和 `BadGC` 错误。

要设置给定 GC 中的显示函数，使用 `XSetFunction`。

```
XSetFunction(display, gc, function);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定要为指定的 GC 设置的函数。

`XSetFunction` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

要设置 GC 的平面掩码，请使用 `XSetPlaneMask`。

```
XSetPlaneMask(display, gc, plane_mask);
```

- `display` 指定到 X 服务器的连接。
- `gc` 指定 GC。
- `plane_mask` 指定平面掩码。

`XSetPlaneMask` 可能会产生 `BadAlloc` 和 `BadGC` 错误。

### 设置线属性和虚线

要设置 GC 的线条绘制组件，请使用 `XSetLineAttributes`。

```
XSetLineAttributes(display, gc, line_width, line_style, cap_style, join_style);
```

- `display` 指定到 X 服务器的连接。
- `gc` 指定 GC。
- `line_width` 指定要为指定的指定的 GC 设置的线宽。
- `line_style` 指定要为指定的 GC 设置的线样式。你可以传递 `LineSolid`、`LineOffDash` 或 `LineDoubleDash`。
- `cap_style` 指定要为指定的 GC 设置的线样式和线帽样式。你可以传递 `CapNotLast`、`CapBatt`、`CapRound` 或 `CapProjecting`。
- `join_style` 指定要为指定的 GC 设置的连接样式。你可以传递 `JoinMiter`、`JoinRound` 或 `JoinBevel`。

`XSetLineAttributes` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

要为给定 GC 的虚线设置偏移量和虚线列表，请使用 `XSetDashes`。

```
XSetDashes(display, gc, dash_offset, dash_list[], n);
```

- `display` 指定到 X 服务器的连接。
- `gc` 指定 GC。
- `dash_offset` 指定要为指定的 GC 设置的虚线样的相位。
- `dash_list` 指定要为指定的 GC 设置的虚线样式的虚线列表。
- `n` 指定 `dash_list` 中的元素数量。

`XSetDashes` 函数设置指定 GC 中虚线的偏移量和虚线列表属性。指定的虚线列表中必须至少有一个元素，否则将产生 `BadValue` 错误。`dash list` 的初始元素和交替元素（第二个、第四个等）是偶数虚线，其他是奇数虚线。每个元素指定以像素为单位的虚线长度。所有元素必须为非零，否则将产生 `BadValue` 错误。指定奇数长度列表等同于指定相同的连接自身以生成偶数长度列表。

`dash-offset` 定义了模式的相位，指定在任何图形请求中实际上从 `dash-list` 模式的多少像素处开始。虚线在结合连接样式的路径元素中是连续的，但在每组连接线之间会重置为 `dash-offset`。

虚线的测量单位可能是针对普通坐标系的。理想情况下，虚线长度是沿着水平线和垂直线的斜率测量的。如果不符合语义，建议长度沿线条的主轴测量。主轴定义为相对于 x 轴角度为 -45 度和 +43 度或在 x 轴 135 度到 225 度之间的线条轴。对于其他线条，主轴为 y 轴。

`XSetDashes` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

### 设置填充样式和填充规则

要设置给定 GC 的填充样式，请使用 `XSetFillStyle`。

```
XSetFillStyle(display, gc, fill_style);
```

- `display` 指定到 X 服务器的连接。
- `gc` 指定 GC。
- `fill_style` 指定要为指定的 GC 设置的填充样式。你可以传递 `FillSolid`、`FillTiled`、`FilledStippled` 或 `FillOpaqueStippled`。
