# 碘

碘是一种非金属，化学符号为 `I`，原子序数 53，是天然存在的卤素。在正常条件下，碘是一种黑色的挥发性固体；其名称根据其气味命名。

矿物质元素缺乏会导致甲状肿，即甲状腺体肿大。

碘的化学性质与其他卤素不同，这归因于原子通过电负性获取电子以形成碘离子 `I⁻` 或形成共价键；也归因于它形成许多有机化合物的灵活性。

主要工业在摄影领域使用碘，它是胶片光乳剂的组分；碘类化合物则用于食品加工和染色。

## 卤素元素：周期

碘的性质受共价键相对电负性和原子尺寸的调节。碘原子较大的尺寸降低了卤素离子的晶格能和溶剂化能，同时增加了范德华力在碘化合物中的重要性；碘的一些性质列在表中。

一个原子或一组原子带有电性荷。带电的离子称为阳离子和阴离子。当中性原子获得电子时，它就变成阴离子；例如，钠元素（`Na`）与氯（`Cl`）的反应导致电子从 `Na` 转移，形成 `Na⁺` 阳离子和 `Cl⁻` 阴离子，它们形成盐。

碘呈黄色，但在高浓度和海水中碘的积累下，某些品种的海藻可以富集该元素。以碘化钙的形式，碘存在于中国以及加利福尼亚州和墨西哥岸售鱼类的细胞中。

碘也可以与多原子离子形成化合物。例如，铵离子 `[NH₄]⁺` 由一个氮原子和四个氢原子组成，并带有正电荷。（注意：原文说 `NH₄⁺` 为负电荷，这是一个错误）。

碘的稳定同位素是 `¹³I`（57 质质子）。其他 22 个同位素（质量在 119 到 135 之间）具有放射性。碘³ 被广泛用作放射性示踪剂和甲状腺研究。

碘是双原子的；在固体、液态和气态下，它在空气或真空中低温下（0°C 或 312°F 以下）发生升华。

碘的晶体结构表明分子间作用力较弱。碘在非极性液体中的溶解大得多，溶液的颜色表明 `I₂` 分子与其溶剂相关。

阴离子和阳离子结合形成称为盐的材料，命名方法为阳离子名称后加阴离子名称。对于多原子离子和硝酸根盐，分子式为 `NH₄₃`，名称为硝酸铵。对于单原子离子，阳离子名称与元素相同，阴离子名称以 -ide 结尾。例如，盐 `NaCl` 称为氯化钠。

碘的命名源自其气味。

碘在水中的溶解度并不高，这与其直接结合的其他卤素不同。

重要的例外包括惰性气体、碳和一些贵金属。碘的有机衍生物用于医学。无机形式的化合物，大多数是电正性元素，以及含氧的化合物。

# 离子交换

离子可以从与含有固定电荷离子的系统的平衡中分离。离子由于其在自由基基质中的位置而被固定。对固定位点具有较高亲和力的溶液离子与固定离子交换，并保持在固定位点附近。同时，溶液中富集了原本位于固定位点的离子。

## 离子推进

离子交换是用于识别和定量分析广泛环境、生物和工业样品中离子浓度的主要分析方法之一。

离子注入是一种在低温下将离子置于固体中的技术。它用于许多应用，例如识别半导体的电学性能以及合金、金属和刻盘的机械或化学性能。另请参：电子；半导体。

河流中的天然水绝不是纯净的；它含有钙盐和镁盐，这些盐会形成水垢并在管道和水箱中留下沉积物。通过通过树脂或土壤中的阳离子交换（在这种情况下，移动阳离子是钠）来软化水。

该过程使用了宽范围的离子能量和剂量。对于能量从 1 keV 到 10 keV 的离子，其渗透深度在 5 到 50 纳米之间。这需要极高的离子能量。因此，离子注入是一种表面改性技术，不适用于改变固体的整个整体性质。离子剂量取决于具体的应用需求。

许多工业和实验室工艺需要盐量极低的纯水。这可以通过水通过氢离子形式的阳离子交换床和氢氧化根形式的阴离子交换床来实现。

工业废水混合物中的毒性离子如 `(Hg²⁺)`、`(Pb²⁺)`、`(Cd²⁺)`、`CO₃²⁻` 和 `[Fe(CN)6]³⁻` 通过离子交换去除。

离子交换用于回收水中的贵金属，如 `(Au³⁺)`、`(Pt⁴⁺)` 和 `(Ag⁺)`。离子交换经常用于清除环境中含有放射性元素和其他元素的水。

离子注入在半导体行业中广泛应用。硅集成电路的制造通常需要许多步具有不同能量和剂量的离子注入。

离子交换用于实验室分离和纯化，以及为实验室研究准备大量的材料。离子交换通常与色谱法结合以分离化合物。现代色谱技术采用具有小颗粒尺寸和快速质量传递特性的离子交换，并在压力下运行。

离子注入用于改变金属和合金的表面性能。它还被用于提高材料的耐磨性、疲劳寿命、耐腐性和化学性。如果通过高温处理延长射，可以将金属或复合材料的寿命延长 80 倍或更多。

生物技术研究需要高效的方法来纯化医药、农业和食品工业中蛋白质和核酸。离子交换广泛用于材料的分离和纯化。这些技术包括去除无机盐、消除内毒素和毒素、去除宿主蛋白和核酸 (`DNA`)，以及去除密切相关的蛋白变体。

离子推进产生高速带电粒子束。通常，正离子由附着在飞天器上的网栅产生的电场产生并加速。由于正离子从推器排出会在飞天器和推器上留下大量的负电荷，必须同时排出电子以保持系统中性。电子以非常高的能量加速，这种能量远低于其他推器或化学火箭。

膜是一类阻隔离子并能够选择性允许离子通过其自身的膜。合成系统包括阳离子交换膜和阴离子交换膜。

离子推进系统的三个主要部分是离子源、加速器和燃料储箱，因此动力单元。

电源可以是核反应堆或太阳能电力系统。在热法中，能量通过聚变或裂变反应释放。太阳辐射可以通过光伏电池（太阳能电池）或通过太阳热交换器转换为电。另请参：太阳。

离子交换膜通常由薄膜层（可能是聚合物）组成，以具有官能团。使用的示例包括聚苯烯、聚乙烯、聚丙烯和氟化聚合物。连接在聚合物上的离子基包括硫酸根—`(SO₄⁻)`、羧酸根—`(COO⁻)`、铵根—`(NH₃⁺)`、磷酸根—`(PO₃²⁻)`。

## 离子注入

利用加速离子渗透固体。注入的离子可用于改变固体材料表面组成、结构或性能。这种表面改性取决于离子种类和能量。深度可以通过调整离子能量和使用的离子类型来控制。注入到固体中的离子总数由离子通量和持续时间决定。

已研究的离子推器使用了氙、汞以及如铯等元素。离子推进已用于早期任务；此外，由于对汞的毒性考虑，现在所有的太空任务中都使用氙。

离子推器装置包含三个功能元件：提供电场以加速离子并将其形成良好聚焦光束的加速器；以及中和器或电子发射器，用于在排气束排出后中和其电荷量。

正离子通过强电场吸引、通过接触大于排斥器电位的功函数吸引，或通过电子轰击阴极吸引，后者似乎是最可能的。
