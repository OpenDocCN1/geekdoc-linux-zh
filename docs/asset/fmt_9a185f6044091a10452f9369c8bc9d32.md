## `tput` 命令的其他选项

我们用过的唯一 `tput` 命令选项是 `tput smso`，它用于开启高亮。`tput` 命令还有许多其他选项可以控制终端显示。在我们的示例中，我们不仅对文本进行了高亮，还对每个字符周围的区块进行了高亮。我们还可以通过其他选项高亮文本部分、双倍整个文本、下划线——例如，我们可以对粗体文本加下划线。`tput` 命令非常好玩。命令选项的简列表如表 15.1 所示。

| 表格 15.1 `tput` 命令的选项 |
|---|---|
| `tput bell` | 响蜂声 |
| `tput blink` | 开启闪烁模式 |
| `tput bold` | 开启双倍强度（比反转视频亮得多） |
| `tput civis` | 关闭光标（使光标不可见） |
| `tput cnorm` | 使光标恢复正常 |
| `tput cr` | 向终端发送回车符 |
| `tput cvis` | 使光标非常亮 |
| `tput dim` | 开启半强度模式 |
| `tput ed` | 清除到显示末尾 |
| `tput el` | 清除到行末尾 |
| `tput flash` | 发送可见的蜂声（适合给朋友发个闪光） |
| `tput invis` | 开启不可见文本模式 |
| `tput prot` | 开启保护模式 |
| `tput rc` | 恢复上次保存的光标位置（由 `tput sc` 设定） |
| `tput rev` | 开始反转视频模式（非常亮！） |
