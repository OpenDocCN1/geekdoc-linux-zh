## 在 /etc/system 文件中启用或禁用 SCSI 选项

系统可能拥有多个 SCSI 驱动器，有大有小。最近 SCSI 驱动器支持 16 位（或宽 SCSI）通信，而旧的驱动器不支持。

由于旧的、低速驱动器不支持宽 SCSI 配置，如果你需要向支持宽驱动器的新系统中添加驱动器，则需要对内核进行修改以使系统能够启动。不符合标准的修改会将所有 SCSI 端口以异步模式运行。这种较慢模式会完全锁定所有的 SCSI 数据传输信号，并确保 SCSI 总线末端扩展存储模块（Extended Storage Module）的可靠运行。在异步模式下，你可以可靠地在快速 SCSI 端口上运行包含快速驱动器和非标准设备的 Sun 配置。

> 注意 — 较慢的数据速率适用于系统中所有的 SCSI 端口。某些应用程序可能会因为数据速率变慢而运行得更慢。

下表了 SCSI 十六进制字节，每个选项占用 1 位。

`bit=1` 表示启用该选项；`bit=0` 表示禁用该选项。

| SCSI 选项 | 将对应位设置为 1 的值 |
|---|---|
| 断开/重连 (Disconnect/reconnect) | `0x008` (bit3=1，从 bit 0 开始) |
| 链接命令 (Linked commands) | `0x010` (bit4=1) |
| 同步传输 (Synchronous transfer) | `0x020` (bit5=1) |
| 奇校验 (Parity) | `0x040` (bit6=1) |
| 标记队列 (Tagged queuing) | `0x080` (bit7=1) |
| 快速 SCSI (Fast scsi) | `0x100` (bit8=1，如果从 1 开始则为 bit 9) |
| 宽 SCSI (Wide scsi) | `0x200` (bit9=1) |

作为 root 用户，检查当前的选项设置：

```
#adb -k
physmem 1f0d
```
