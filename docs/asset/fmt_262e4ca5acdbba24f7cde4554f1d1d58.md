# ex

`ex` 是指向 `vim` 编辑器的符号链接。在此模式下，`vim` 编辑器会模拟 `ex` 编辑器。

# fc

`fc` 命令用于编辑历史文件。传递给它的参数（如果有的话）可以用于从历史文件中选择一段命令范围。

# jmacs

# joe

`joe` 是一个递归缩写，遵循 GNU 传统，代表 Joe's own editor。它是一个非常小（160k）且运行极快的全屏编辑器；`joe` 是 `VI` 的流行替代方案。
