
# getpwnam

## 语法

```pascal
function getpwnam(Name: PChar): PPasswordRecord;
```

## 描述

`getpwnam` 函数在已知用户名时返回一个指向 `/etc/passwd` 文件中该用户的指针。该函数将以 `TPasswordRecord` 的形式返回 `/etc/passwd` 文件中的信息。

```pascal
type
  passwd = record
    pw_name: PChar;      // 用户名
    pw_password: PChar;  // 密码
    pw_uid: _uid_t;      // 用户 ID
    pw_gid: _gid_t;      // 组 ID
    pw_gecos: PChar;     // 真实姓名
    pw_dir: PChar;       // 目录
    pw_shell: PChar;     // Shell 程序
  end;
  TPasswordRecord = passwd;
  PPasswordRecord = ^passwd;
```

## 参数

- **Name**: 以空字符结尾的用户名字符串。

## 返回值

如果在 `/etc/passwd` 文件中找到了传入的用户名，函数将返回一个代表该用户的 `TPasswordRecord` 指针。如果未找到该用户名，或在使用函数时发生错误，则函数将返回 `nil`。

## 参见

`getpwid`, `getpw`, `getpwuid`

## 示例

列表 4.38 - 使用 `getpwnam` 函数

```pascal
procedure TfrmUsers.FindByName;
var
  usr: PPasswordRecord;
  strUserName: string;
begin
  mmSearchResults.Clear;
  strUserName := edSearchValue.Text;
  usr := getpwnam(PChar(strUserName));
  if usr = nil then
    mmSearchResults.Add('未找到该用户')
  else
  begin
    mmSearchResults.Add('User ID: ' + IntToStr(usr^.pw_uid));
    mmSearchResults.Add('User Name: ' + usr^.pw_name);
    mmSearchResults.Add('User Password: ' + usr^.pw_password);
    mmSearchResults.Add('Group ID: ' + IntToStr(usr^.pw_gid));
    mmSearchResults.Add('User Directory: ' + usr^.pw_dir);
    mmSearchResults.Add('User Shell: ' + usr^.pw_shell);
  end;
end;
```

# getpwuid

## 语法

```pascal
function getpwuid(uid: __uid_t): PPasswordRecord;
```

## 描述

`getpwuid` 函数在已知用户 ID 时返回 `/etc/passwd` 文件中的特定用户详细信息。该函数将以 `TPasswordRecord` 指针的形式返回用户信息。

```pascal
type
  passwd = record
    pw_name: PChar;      // 用户名
    pw_password: PChar;  // 密码
    pw_uid: _uid_t;      // 用户 ID
    pw_gid: _gid_t;      // 组 ID
    pw_gecos: PChar;     // 真实姓名
    pw_dir: PChar;       // 目录
    pw_shell: PChar;     // Shell 程序
  end;
  TPasswordRecord = passwd;
  PPasswordRecord = ^passwd;
```

## 参数

- **uid**: 与 `/etc/passwd` 文件中的记录匹配的整数值。

## 返回值

如果传入的 `uid` 参数是有效的，函数将返回一个代表该用户的 `TPasswordRecord` 指针。如果 `uid` 参数不代表有效用户，或在使用函数时发生错误，则函数将返回 `nil`。

## 参见

`getpwent`, `endpwent`, `getpwuid`, `getpwnam`

## 示例

列表 4.39 - 使用 `getpwuid` 函数

```pascal
procedure TfrmUsers.FindByUID;
var
  usr: PPasswordRecord;
begin
  usr := getpwuid(StrToInt(edSearchValue.Text));
  mmSearchResults.Lines.Clear;
  if usr = nil then
    mmSearchResults.Add('未找到该 ID 用户')
  else
  begin
    mmSearchResults.Add('User ID: ' + IntToStr(usr^.pw_uid));
    mmSearchResults.Add('User Name: ' + usr^.pw_name);
    mmSearchResults.Add('User Password: ' + usr^.pw_password);
    mmSearchResults.Add('Group ID: ' + IntToStr(usr^.pw_gid));
    mmSearchResults.Add('User Directory: ' + usr^.pw_dir);
    mmSearchResults.Add('User Shell: ' + usr^.pw_shell);
  end;
end;
```

# group_member

## 语法

```pascal
function group_member(groupID: __gid_t): Integer;
```

## 描述

此函数确定当前进程是否在 `groupID` 参数指定的组中。此函数可用于确定特定文件、目录或资源的权限。

## 参数

- **GroupID**: 要检查的组 ID，以查看进程是否在该组内。

## 返回值

如果进程在组内，函数返回 `1`。如果进程不在组内，函数返回 `0`。

## 另请参阅

`getgroups`, `getgrent`

## 示例

列表 4.40 - 使用 `group_member` 函数

```pascal
procedure TfrmLinuxGroups.ReadInGroups;
var
  grp: PGroup;
  DoProcessHavePermissionsOfGroup: Boolean;
  intIndex: Integer;
begin
  // 从系统读取组列表并检查当前进程所属的组
  grp := getgrent;
  while grp <> nil do
  begin
    // 显示关于该组的信息
    intIndex := cbGroups.Items.Add(grp^.gr_name);
    DoProcessHavePermissionsOfGroup := group_member(grp^.gr_gid) = 1;
    clbGroups.Checked[intIndex] := DoProcessHavePermissionsOfGroup;

    grp := getgrent;
  end;
end;
```

# putenv

## 语法

```pascal
function putenv(Str: PChar): Integer;
```

## 描述

`putenv` 函数在当前环境中设置一个环境变量名/值对。

此函数仅涉及当前进程以及任何使用 `fork` 或 `exec` 函数从应用程序中创建的子进程。

## 参数

- **Str**: 设置形式为 `name=value` 格式的环境变量字符串。如果环境中存在同名的环境变量，它将被更改为新值。如果 `Str` 参数持有 `name` 形式的键值，则该环境变量将被删除。

## 返回值

如果成功，函数返回 `0`；如果在 `name=value` 的情况下未写入环境变量或在 `name` 的情况下未删除环境变量，则返回 `-1`。

## 另请参阅

`getenv`, `setenv`, `clearenv`, `__secure_getenv`

## 示例

列表 4.41 - 使用 `putenv` 函数

```pascal
procedure TForm1.ButtonClick(Sender: TObject);
begin
  // 存储环境变量值并创建一个可以使用该设置值的子进程
  if putenv('SimpleDBBappSettings=/root/dblocation.ini') = 0 then
  begin
    if fork = 0 then
    begin
      // 在子进程中
      RunChildActions;
      Exit;
    end;
  end
  else
  begin
    MessageDlg('The settings file could not be set.', mtInformation, [mbOK], 0);
  end;
end;
```

# setegid

## 语法

```pascal
function setegid(GroupID: __gid_t): Integer;
```

## 描述

`setegid` 函数设置调用进程的有效组 ID。这更改了进程的访问级别，因此在访问应用程序内的文件时，进程将考虑新有效组的权限。

## 参数

- **GroupID**: 将用作进程有效组 ID 的新组 ID。

## 返回值

函数成功时返回 `0`。如果函数失败，则返回 `-1`。

## 另请参阅

`seteuid`

## 示例

列表 4.42 - 使用 `setegid` 函数

```pascal
procedure TfrmLinuxGroups.btnSetEffectiveGroupClick(Sender: TObject);
var
  groupID: Integer;
begin
  // 从复选框获取组 ID
  if clbGroups.ItemIndex = -1 then
    Exit;
  groupID := Integer(clbGroups.Items.Objects[clbGroups.ItemIndex]);

  // 设置新的有效组 ID
  setegid(groupID);

  // 刷新用户
  RefreshGroupMembershipDisplay;
end;
```

# setenv

## 语法

```pascal
function setenv(Name: PChar; const Value: PChar; Replace: Integer): Integer;
```

## 描述

`setenv` 函数在当前环境中设置一个环境变量名/值对。此函数仅涉及当前进程以及任何使用 `fork` 或 `exec` 函数从应用程序中创建的子进程。

## 参数

- **Name**: 指向环境变量名的指针。
- **Value**: 指向包含要设置的环境变量值的字符串的指针。
- **Replace**: 仅当环境变量指向已存在的环境变量时才使用，并决定该环境变量是否应被覆盖。当 `Replace` 为非零值时，同名的环境变量存在并将被新值替换。当它为 `0` 时，则不会对环境进行任何更改。

## 返回值

函数成功时返回 `0`，如果环境变量未写入，则返回 `-1`。

## 另请参阅

`getenv`, `clearenv`, `secure_getenv`

## 示例

列表 4.43 - 使用 `setenv` 函数

```pascal
procedure TForm1.ButtonClick(Sender: TObject);
begin
  // 存储环境变量值并创建一个可以使用该设置值的子进程
  if setenv('SimpleDBBappSettings', '/root/dblocation.ini', 1) = 0 then
  begin
    if fork = 0 then
    begin
      // 在子进程中
      RunChildActions;
      Exit;
    end;
  end
  else
  begin
    MessageDlg('The settings file could not be set.', mtInformation, [mbOK], 0);
  end;
end;
```

# seteuid

## 语法

```pascal
function seteuid(UID: __uid_t): Integer;
```

## 描述

此函数将应用程序的有效用户 ID 设置为 `UID` 参数指定的用户。此函数只能由超级用户执行。函数可以将用户名转换为 UID 并冒充该用户。

## 参数

- **UID**: 进程将作为有效用户 ID 的用户。

## 返回值

如果函数成功，则返回 `0`；否则，返回 `-1` 并由 `errno` 决定结果。

## 另请参阅

`getuid`, `getgid`

## 示例

列表 4.44 - 使用 `seteuid` 函数

```pascal
procedure TfrmLinuxGroups.ReadInUsers;
var
  usr: PPasswordRecord;
begin
  // 从系统读取用户列表
  setpwent;
  usr := getpwent;
  while usr <> nil do
  begin
    // 显示关于用户的信息
    clUsers.Items.AddObject(usr^.pw_name, TObject(usr^.pw_uid));
    usr := getpwent;
  end;
  endpwent;

  RefreshDisplay;
end;

procedure TfrmLinuxGroups.RefreshDisplay;
begin
  lblEffectiveUserID.Caption := UserIDUserName(getuid());
end;

procedure TfrmLinuxGroups.btnSetEffectiveClick(Sender: TObject);
var
  intUserID: Integer;
begin
  // 从列表框获取用户 ID
  if clUsers.ItemIndex = -1 then
    Exit;
  intUserID := Integer(clUsers.Items.Objects[clUsers.ItemIndex]);

  // 设置新的有效用户
  if seteuid(intUserID) = -1 then
    MessageBox('You cannot set the effective user ID. It is possible that the current process''s permissions do not allow this.', mtWarning, [mbOK], 0);

  // 刷新用户
  RefreshDisplay;
end;
```

# setgid

## 语法

```pascal
function setgid(GroupID: __gid_t): Integer;
```

## 描述

`setgid` 函数用于将进程的有效组更改为 `GroupID` 参数指定的组。当由超级用户账户执行此命令时，实际组 ID 也将被设置为 `GroupID` 参数指定的组。

## 参数

- **GroupID**: 将用作新有效组 ID 的 ID。

## 返回值

成功时，函数返回 `0`。如果函数失败，则返回 `-1`。此函数产生错误的结果通常是因为进程没有足够的权限成功更改进程的组。通常只有以 root 运行的进程具有这些权限。

## 另请参阅

`setuid`, `seteuid`, `getuid`, `getgid`, `getegid`, `geteuid`

## 示例

列表 4.45 - 使用 `setgid` 函数

```pascal
procedure TfrmLinuxGroups.btnSetEffectiveGroupClick(Sender: TObject);
var
  intGroupID: Integer;
begin
  // 从 CheckListBox 中获取组 ID
  if clbGroups.ItemIndex = -1 then
    Exit;
  intGroupID := Integer(clbGroups.Items.Objects[clbGroups.ItemIndex]);

  // 现在设置有效组 ID
  setgid(intGroupID);

  // 刷新用户
  RefreshGroupMembershipDisplay;
end;
```
