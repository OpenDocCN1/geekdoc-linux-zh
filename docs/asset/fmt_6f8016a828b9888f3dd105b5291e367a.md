## tcpdump
`tcpdump`是一个监控网络流量的命令行工具。`tcpdump`可以在特定接口上捕获并显示包头。它可以在所有接口上捕获数据。出自 Redhat 8 http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcpflow
TCP 流量记录器。该程序捕获在网络上传输的数据（TCP 连接），并以某种方式存储。与像 `tcpdump` 这样的显示包程序不同，`tcpflow`会重组数据并将其存储在单独的文件。`tcpflow`理解重传和乱序交付。然而，它目前不支持分包（对于包含分包的流量）。`tcpflow`基于 LBL 库，并支持 `tcpdump` 所支持的丰富表达式。出自 Debian 3.0 http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcpquota
一个拨号/监控包。`TcpQuota`监控并限制在线时间（拨号）。该程序适用于那些拥有作为互联网网关的本地网络的用户。该包限制来自服务器或主机的用户。网关/防火墙内部的用户必须运行 `openhost` 命令，并根据花费的时间对用户名进行扣费。出自 Debian 3.0 http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcpreplay
以任意速度回放 `tcpdump` 文件的工具。`Tcpreplay`的目标是通过回放网络流量来测试 NIDS 的性能。`Tcpreplay`允许控制回放速度，并可以回放任意 `tcpdump`。由于人工生成的流量并不执行 NIDS 执行的应用程序/协议，也不会产生生产网络中出现的真实异常（非对称路由、流量突发、分片、重传等），`tcpreplay`允许精确回放网络上看到的流量。出自 Debian 3.0 http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcpslice
提取片段或拼接。`tcpslice`是一个用于提取使用 `tcpdump -l -w` 生成的包跟踪文件部分的程序。它也可以用于拼接此类文件。出自 Debian 3.0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## tcpspy
入站和出站 TCP/IP 连接。`tcpspy`是一个记录入站和出站 TCP/IP 连接信息的分析器。它用 C 语言编写，不像 `tcpdump` 那样使用 libpcap 函数。通过过滤器选择要记录的连接，表达式与 `tcpdump` 使用。记录的信息包括：用户名、地址和端口、远程地址和端口，可选的可执行文件。目前仅支持 IPv4 协议。出自 Debian 3.0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## tcpstat
网络接口统计报告工具。`tcpstat`报告网络接口统计信息，类似于用于系统统计的 `nmstat`。`tcpstat`通过监控特定接口或通过从文件中读取之前保存的 `tcpdump` 数据来获取信息。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## tcptraceroute
一种使用 TCP 数据包的 `traceroute` 实现。更传统的 `traceroute(8)` 发送 TTL（生存时间）为 1 的其他 UDP 或 ICMP ECHO 数据包，并不断增加 TTL 直到到达目的地。通过追踪沿途中生成 ICMP “时间超时（time exceeded）”消息的网关，来确定数据包到达目的地的路径。问题在于互联网上防火墙的广泛使用，`traceroute(8)` 发出的许多数据包被过滤，导致无法完全追踪到目的地的路径。然而，在许多情况下，这些防火墙会允许进入防火墙后监听连接的特定主机的入站 TCP 数据包。通过发送 TCP SYN 数据包而不是 ICMP ECHO 数据包，`tcaceroute` 能够绕过最常见的防火墙。来自 Debian 3.0r0 http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcputils
用于 shell 脚本 TCP 编程的工具。这是一个便于在 shell 脚本中 TCP 编程的脚本集合。还有一个小型库可以更容易创建 TCP/IP socket。此版本包含的程序有：
- `mini-inet` – 小型 TCP/IP 连接
- `patcher debugger` – TCP/IP 连接绑定
- `tcpconnect` – 通用 TCP/IP 客户端
- `tclisten` - 通用 TCP/IP 服务器
- `getname` – 获取连接的/IP 对端的名称
来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcpwrappers
作为客户端与要运行的服务器之间的中介，提供一种过滤“封装器（wrapper）”，允许根据主机或网络地址允许或拒绝连接。来自 Linux @FirstLinux http://www.tldp.org/LDP/Linux-Dictionary/index.html

## tcp_wrappers
`tcp_wrappers`软件包提供了小型守护进程，用于监控和过滤针对 stay、finger、FTP、telnet、login、rsh、ssh、talk 以及其他服务的入站请求。如果您需要过滤入站服务的工具，请安装 `tcp_wrappers` 程序。来自 Redhat 8.0 RPM http://www.tldp.org/LDP/Linux-Dictionary/index.html

## TCSEC (国防部可信计算机系统评估标准，CSC-STD-001–83，DoD 5200.228-53)
美国国防部在 20 世纪 80 年代初创建的一种正式学术信息安全规范。`TCSEC`分四个部分：A、B、C 和 D，其中“A”描述了安全性最高的系统和不可信系统。这些每个部分进一步细分为“类（classes）”。微软为 Windows NT 获得了“C2”认证。这是政府认证符合防御 2 级的系统。对比：`TCSEC`设计是围绕“受信员工访问本地系统”的概念设计的。它并不是为如今的开放互联网设计的。黑客并不从 `TCSEC`的角度考虑安全性。`TCSEC`并不处理黑客带来的威胁。这意味着，在尝试防止黑客攻击你的电子商务网站时，`TCSEC`是无关紧的。然而，它在保护内部系统免受内部人员侵害方面极其有用。记住，最大的威胁来自你自己的员工，网络犯罪分子因滥用被赋予的信任而被定罪。来自 Hacking-Lexicon http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## tcsh
`Tcsh`是 `csh`（即 C Shell）的增强版且功能完全的版本。`Tcsh`是一种命令语言解释器，既可以作为交互式登录 shell，也可以作为脚本命令处理器。`Tcsh`包含命令行编辑器、可编程单词补全、拼写检查、历史机制、作业控制和类 C 语言语法。来自 Redhat 8.0 RPM http://www.tld.org/LDP/linux-dictionary/html/index.html
