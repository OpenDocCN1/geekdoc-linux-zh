# F.4. 批量复制

如果您出版文档的印刷副本（或通常有印刷封面的介质中的副本）数量超过 100 份，且文档的许可通知要求封底文本，则你必须将副本装在封内，清晰且合法地承载所有这些封底文本：封面上的封面文本和封底上的封底文本。两个封面都必须清晰易读地标明您是副本的出版者。封面必须包含完整标题，且标题中的所有单词均显著且可见。您可以在封面上额外添加其他材料。只要您保留文档并满足这些条件，将更改限于封面的复制在其他方面可以被视为原样复制。

如果任一封面所需的文本体量太大而无法清晰容纳，您应该将列出的前面的文本（根据需要提供若干）放在实际封面上，并将其余部分继续在相邻页面上。

如果您出版或分发超过 100 份文档的不透明副本，则你必须在每份不透明副本旁附带一份机器可读的透明副本，或者在每份不透明副本说明一个计算机网络位置，通用网络用户可以使用公共标准网络协议从中下载未添加额外材料的文档透明副本。如果您使用后一种方案，在开始大量分发不透明副本时，可以采取合理的审慎步骤，以确保该透明副本在您最后一次向公众分发（直接或通过您的代理人或零售商）该版本副本后至少一年内在该位置仍然可访问。

建议（但不是要求）您在重新分发大量副本之前，联系文档作者，给他们一个机会为您提供文档的更新版本。
