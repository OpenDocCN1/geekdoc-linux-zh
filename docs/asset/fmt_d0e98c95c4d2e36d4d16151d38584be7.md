# znew

描述：将 `compress` 文件（`.Z` 文件）转换为 `gzip` 使用格式（`.gz` 文件）。如果未指定文件，则处理标准输入。

语法

```
znew [-f9K] [file.Z ...]
```

重要标志和选项

- `-9`：使用最好、最慢的压缩方法。
- `-f`：即使已存在 `.gz` 文件也强制压缩。
- `-K`：如果 `.Z` 文件比新的 `.gz` 文件小，则保留 `.Z` 文件。
- `-t`：在删除原始 `.Z` 文件之前测试新的 `.gz` 文件。
