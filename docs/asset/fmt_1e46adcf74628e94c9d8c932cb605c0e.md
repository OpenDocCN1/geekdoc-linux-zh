## 集合类型

集合是唯一元素的无序集合。与序列不同，集合没有索引或切片操作。它们也类似于字典，因为它们没有与对象关联的键值对。放入集合的元素必须是可变的。有两种不同的类型：可变的集合（`set`）和不可变的冻结集合（`frozenset`）。这两种集合都使用一对内置函数创建：

```python
s = set([1,5,10])

f = frozenset({'a', 'hello'})
```

`set()` 和 `frozenset()` 都会通过遍历提供的参数来填充集合。两种集合都提供了表 3.7 列出的方法。

| 项目 | 描述 |
| --- | --- |
| `len(s)` | 返回 `s` 中元素的数量。 |
| `s.copy()` | 创建 `s` 的副本。 |
| `s.difference(t)` | 集合差。返回 `s` 中存在但不在 `t` 中的所有元素。 |
| `s.intersection(t)` | 交集。返回 `s` 和 `t` 中共同的所有元素。 |
| `s.isdisjoint(t)` | 如果 `s` 和 `t` 没有共同元素，则返回 `True`。 |
| `s.issubset(t)` | 如果 `s` 是 `t` 的子集，则返回 `True`。 |
| `s.issuperset(t)` | 如果 `s` 是 `t` 的超集，则返回 `True`。 |
| `s.symmetric_difference(t)` | 对称差。返回在 `s` 或 `t` 中但不在两者共同中的所有元素。 |
| `s.union(t)` | 并集。返回 `s` 或 `t` 中的所有元素。 |

## 可调用类型

可调用类型表示支持调用操作的对象。具有此属性的对象有多种，包括用户定义函数、内置函数、实例方法和类。

## 用户定义函数

用户定义函数是在模块级使用 `def` 语句或 `lambda` 运算符创建的可调用对象。这里是一个示例：

```python
def foo(x,y):
    return x + y
```

```python
bar = lambda x,y: x + y
```
