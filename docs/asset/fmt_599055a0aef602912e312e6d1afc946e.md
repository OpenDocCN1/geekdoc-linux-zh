## 滑率（电力）

一种用于定义电耦合器和感应机性能的数值。在电耦合器中，滑率简单来说是两个旋转部件速度之差。在感应电机中，同步速度与转子速度之差。

当感应电机的绕组连接到合适的电压时，它们会在定子中建立磁场。该磁场的速度称为同步速度，由公式 (1) 或 (2) 给出：

$$\omega_s = \frac{4f}{p}$$

$$n_s = \frac{120}{p} \text{ rev/min}$$

其中 `f` 是频率，`p` 是电机的极数。极数由定子的设计决定。如果定子连接到交流电压，只有当磁通随线圈时间变化时，磁场才能在线圈中感应出电流。转子以与定子相同的速度移动越快，其磁链就越少。如果转子以同步速度旋转，则不会感应电流。滑率可能是定子和转子速度之间的差。

### 感应机

滑率的大小用每分钟或每秒转圈数的两个速度之差表示。感应电机的滑率最常见的定义是同步速度的分数，如公式 (2) 或 (3) 或 (4)。这里 `n` 是每分钟转圈数：

$$s = \frac{n_s - n}{n_s}$$

$$\omega = \frac{\omega_s - \omega}{\omega_s}$$

或 `ω` 是每秒弧度的速度，`s` 是滑率，或每单位的滑移量。感应电机的典型满载滑率范围在 0.02 到 0.05 之间，取决于转子设计。滑率以同步速度的百分比表示，而不是单位。如果感应电机的驱动速度比同步速度快，感应电流将为负，电机将作为发电机运行，将能量反馈电源电路。
