表对象的访问权限在第五行显示。该表有四列：`cname`、`name`、`addr` 和 `comment`。每列都有其访问权限、名称和属性。在示例中，列已授予额外的权限，所有者和组具有修改和删除权限。

如果你具有读取权限，可以使用 `niscat` 命令显示表的值。在下一个示例中，`auto_master.org_dir` Map有四个条目。

castle$ niscat auto_master.org_dir

auto_master

hosts

castle$
```
