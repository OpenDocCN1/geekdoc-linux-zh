- `<HTML>`：定义 HTML 文档的开始。
- `</HTML>`：结束`<HTML>`标签。
- `<HEAD>`：设置文档的头部。
- `</HEAD>`：结束`<HEAD>`标签。
- `<TITLE>`：创建文档标题。在查看页面时，标题显示在浏览器的标题栏中，并用书签的标签。
- `</TITLE>`：结束`<TITLE>`标签。
- `<BODY BGCOLOR="#FFFFFF">`：设置背景颜色。在这种情况下，背景为白色，未链接的链接为蓝色。
