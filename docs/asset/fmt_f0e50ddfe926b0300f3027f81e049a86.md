# 第 26 章 使用 CoreCENTRAL 通讯录保持联系

CoreCENTRAL 程序的第三组成部分是通讯录。在这里，你可以将所有朋友、同事和伙伴的联系信息汇总并整理到一个易于使用的界面中。在本章中，你将学习如何：

- 将地址添加到通讯录中
- 更新地址信息
- 在通讯录中查找地址
- 创建并管理多个通讯录

## 创建地址

今天结交了新朋友吗？从公司网站获取了新客户吗？那么，你需要将她的地址信息添加到通讯录中。

1. 点击“创建新地址条目”（Create a new address entry）按钮。“新建”（New）对话框将出现。

![](img/33d9b1681e3609bc590f82347ae3a699_367_0.png)

2. 点击“人员”（Person）。人员将被选中。

3. 点击“确定”（OK）。“新建”对话框将关闭，“人员属性”对话框将打开。

![](img/33d9b1681e3609bc590f82347ae3a699_367_1.png)

![](img/33d9b1681e3609bc590f82347ae3a699_368_0.png)

4. 在相应的框中输入所有可用信息。

5. 点击“人员”（Personal）选项卡。“人员”选项卡将置前。

![](img/33d9b1681e3609bc590f82347ae3a699_368_1.png)

6. 在相应的框中输入所有可用信息。

7. 点击“确定”（OK）。“人员属性”对话框将关闭，地址将被添加到通讯录。

## 编辑地址

美国人一生会搬三次。这意味着你需要定期编辑通讯录条目。

1. 点击一个地址条目。该条目将被选中。

2. 点击“编辑地址条目”（Edit an address entry）按钮。该条目的属性对话框将出现。

![](img/33d9b1681e3609bc590f82347ae3a699_369_0.png)

3. 在条目框中输入任何新或额外的信息。

4. 点击“确定”（OK）。条目属性对话框将关闭，通讯录中的条目将更新。

![](img/33d9b1681e3609bc590f82347ae3a699_369_1.png)

## 导入地址

4. 导航到适当的文件。该文件将被选中。

![](img/33d9b1681e3609bc590f82347ae3a699_371_0.png)

5. 点击“打开”（Open）。导入对话框将关闭，ASCII 分隔符设置（ASCII Delimiter Setup）框将打开。

![](img/33d9b1681e3609bc590f82347ae3a699_371_1.png)

6. 确认字段和记录分隔符的设置。大多数 ASCII 版本的联系信息使用逗号作为字段分隔符，换行作为记录分隔符。

7. 点击“确定”（OK）。ASCII 分隔符设置框将关闭，字段映射（Field Mapping）对话框将打开。

8. 点击“已导入”（Imported）列中的某行。该行将被选中。

9. 点击“通讯录”（Address Book）列中的匹配行。该匹配行将被选中。

10. 点击“已映射”（To Mapped）按钮。关系将出现在“已映射”（Mapped）列中。

11. 重复步骤 8-10，直到完成所有必要的映射。

![](img/33d9b1681e3609bc590f82347ae3a699_372_0.png)

12. 点击“确定”（OK）。当出现“导入成功！”（Imported Successfully！）消息时，地址将导入通讯录。

![](img/33d9b1681e3609bc590f82347ae3a699_372_1.png)

13. 点击“确定”（OK）。过程将完成。

## 搜索地址

当你的通讯录中有大量地址时，你需要一种方法快速找到它们。在通讯录中进行搜索是轻而易举的。

![](img/33d9b1681e3609bc590f82347ae3a699_373_0.png)

1. 点击“搜索指定文本”（Search for specified text），对话框将出现。

![](img/33d9b1681e3609bc590f82347ae3a699_373_1.png)

2. 输入要查找的名称。

3. 点击“立即查找”（Find Now）。查找对话框将展开并列出地址条目。

4. 双击条目。该条目的属性（Properties）对话框将出现，供你阅读或编辑。

![](img/33d9b1681e3609bc590f82347ae3a699_374_0.png)

![](img/33d9b1681e3609bc590f82347ae3a699_374_1.png)

## 创建新通讯录

在你的通讯录中有若干条目后，你可能想通过将它们存放在不同的通讯录中来组织它们。要做到这一点，你需要创建一个通讯录。

![](img/33d9b1681e3609bc590f82347ae3a699_374_2.png)

1. 点击“创建新通讯录”（Create a new address book）按钮。新通讯录（New Address Book）对话框将出现。

![](img/33d9b1681e3609bc590f82347ae3a699_374_3.png)

2. 点击 CoreCENTRAL。CoreCENTRAL 将被选中。

![](img/33d9b1681e3609bc590f82347ae3a699_374_4.png)

3. 点击“确定”（OK）。新通讯录对话框将关闭，新通讯录属性对话框将打开。

![](img/33d9b1681e3609bc590f82347ae3a699_374_5.png)

4. 在“名称”（Name）框中输入通讯录名称。

5. 点击“确定”（OK）。新通讯录属性对话框将关闭，通讯录将出现。

![](img/33d9b1681e3609bc590f82347ae3a699_375_0.png)

## 管理通讯录

创建新通讯录后，你可以轻松地将条目移动进去以便组织。

1. 点击通讯录条目。该条目将被选中。

2. 点击“剪切”（Cut）按钮。条目将从通讯录中剪切。

3. 点击目标通讯录。通讯录将打开。

![](img/33d9b1681e3609bc590f82347ae3a699_375_1.png)

4. 点击“粘贴”（Paste）按钮。条目将被放入通讯录。

![](img/33d9b1681e3609bc590f82347ae3a699_376_0.png)
