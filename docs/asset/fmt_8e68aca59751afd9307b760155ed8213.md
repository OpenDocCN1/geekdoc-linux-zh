# 安装后是否重启？

安装 Solaris 软件后，必须重启系统。你可以选择让系统自动重启，或者如果你想在重启之前运行脚本或进行其他自定义，也可以选择手动重启系统。你可以通过 `reboot(IM)` 命令手动重启系统。
