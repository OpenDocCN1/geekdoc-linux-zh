### ttloop

一个小型子程序，用于刷新网络输出缓冲区，从网络获取数据，并将其通过 telnet 状态机处理。如果 pty 输入缓冲区过于拥挤，我们也通过丢弃其数据来刷新它。

```c
void
 ttloop()
 {
 if (nfrontp-nbackp) {
 netflush();
 }
 ncc = read(net, netibuf, sizeof netibuf);
 if (ncc < 0) {
 exit(1);
 } else if (ncc == 0) {
 exit(1);
 }

 netip = netibuf;
 telrcv(); /* 状态机 */
 if (ncc > 0) {
 pfrontp = pbackp = ptyobuf;
 telrcv();
 }
 }
```
