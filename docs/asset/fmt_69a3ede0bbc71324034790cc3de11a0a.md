
# 进化计算 (Evolutionary computation)

**进化计算 (Evolutionary computation)**是一个多学科科学领域，关注模拟进化方面以解决现实问题。许多生物以及人类通过选择和突变表现出复杂的优化。达尔文的“压力”理论描述了进化解决问题的能力。进化是生物学的通用力量，但作为工程原理，其中群体中的个体经历随机变异（突变和重组）。

# 蒸发器 (An evaporator)

**蒸发器 (An evaporator)** 是用于从溶液中蒸发溶剂的设备。价值产品是固体或浓缩溶液。如果是固体，必须利用蒸发热将其变为固体中的悬浮液，否则该设备必须作为干燥机使用。蒸发器可能由几个组件组成，但如果这些组件中的任何一个故障，过程就会受到损害。当价值产品是溶液时，蒸发器有时被称为蒸馏器，有时被正确标记，例如锅炉用水蒸发器。

![](img/b16805e6127c92641547ee45e5728f7f_866_0.png)

蒸发器用于化学工业。例如，通过在蒸发器中蒸发盐水来制造盐。盐以盐水悬浮液的形式收集。物料被泵到过滤器中，从那里回收固体，并将液体部分返回蒸发。蒸发器广泛应用于食品工业，也作为一种减少体积以限制能量和储存成本的方法。

水的蒸发需要大量的热量来传递溶质。传递这种热量的设备装置是蒸发器最大的元素，也是许多

# 专家系统

一种能够利用专家的推理程序以产生必要的控制行动的智能系统。专家系统寻求引入系统设计、实际操作和异常恢复程序（通常由工程师执行）。人工智能领域的技术用于获取和表示知识并生成控制决策。专家系统基于知识，通常被称为基于知识的系统。使用专家系统的优点之一是其处理信息的固有能力。然而，这些系统可能像专家一样是通用、模糊的，并且缺乏学习、推理和引发新知识的灵活性。它们可以通过经验学习新知识并改进性能。

另一个主要问题涉及过剩能量核回到稳定性的衰变模式。任何来自稳定值的衰变都是发射一个或多个质子的过程，一个质子变成另一个（具有中子数的同位素），或未结合核。这些极限分别定义了质子线和中子线（丰图中远离稳定性区域的线）。

专家系统中存在的组件组件数据库、推理引擎、用户界面以及这些组件之间的接口。

这些深入的问题为物质的结构和衰变模式提供了重要见解，使得测试和扩展原子核理论模型成为可能。这些见解不仅适用于稳定性区域附近的原子核。

专家系统的核心是知识（或知识库），它包含特定领域的知识。该知识包含领域特定的事实和规则（或框架），用于解决该领域的问题。

## 知识工程的通用类别

| 类别 | 解决的问题 |
| --- | --- |
| 解释 | 从传感器数据中推断情况 |
| 控制 | 推断给定情况的质量 |
| 数据采集 | 推断缺失信息 |
| 设计 | 在约束下配置对象 |
| 决策 | 比较观察结果以规划漏洞 |
| 维护 | 维护的处方性需求 |
| 调试 | 向患者解释处方治疗方案 |
| 指导 | 调试和修复学生的知识 |
| 控制 | 系统的交互、预测和修复 |

用户将搜索过程交给程序化编写的策略和算法；通过推理机制（通常以逻辑形式存在）来解决问题、得出结论并激活最终控制。

控制算法是执行最终控制动作的工具，通常可以进行调整。

用户界面允许用户通过知识库、源编辑与系统进行交互，并执行许多其他任务。

专家系统以及构建具有专门问题解决知识的人机系统的方法。这种专业知识已经出现了几十年，并显著减少了独立领域问题解决理论的出现。事实上，新的原则和技术构成了知识工程的基础。

专业知识包含特定领域、对问题的理解，并且解决其中某些问题需要公共知识和私有知识。公共知识包括发表的事实和理论，这些内容包含在领域的教科书和参考文献中。但专业知识通常不仅需要公共知识。私有知识包含了在发表文献中未发现的内容。这些知识由大量的规则或启发算法组成。启发算法使专家能够做出决策、识别问题并处理错误或不完整的数据。此类知识的阐明和再现是知识工程的目标。

该领域的研究人员提出了他们强调基于知识的方法而非以前的表示和关联方法的几个原因。首先，基于知识系统的灵活性允许更复杂的解决方案。其次，许多重要任务（如计划、学习、医学诊断、基因工程和军事分析）是在复杂的社会或物理背景下进行的，这需要精确的描述和严谨性。
