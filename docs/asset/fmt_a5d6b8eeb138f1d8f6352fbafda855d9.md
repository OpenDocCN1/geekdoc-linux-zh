| Linux Kernel Archives | `www.kernel.org` |

较小的开源包和项目很少有用于托管开发的网站。相反，它们被列在开源仓库网站上，也称为开源归档，其中包含成千上万可下载的软件包。通常，这些网站提供多个不同的 Linux 发行版，方便地避免了访问发行版网站来获取其中之一。有很多仓库网站，表 C-5 列出了其中的示例。
