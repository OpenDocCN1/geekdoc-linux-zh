
```python
import os
try:
    from httplib import HTTPConnection  # Python 2
except ImportError:
    from http.client import HTTPConnection  # Python 3

BOUNDARY = "$Python-Element$"
CRLF = "\r\n"

def upload(addr, url, formfields, filefields):
    # 创建表单字段
    formsections = []
    for name in formfields:
        section = [
            --'+BOUNDARY,
            'Content-disposition: form-data; name="%s" % name,
            '',
            formfields[name]
        ]
        formsections.append(CRLF.join(section)+CRLF)

    # 收集所有上传的文件信息
    fileinfo = [(os.path.getsize(filename), filename) for name, filename in filefields.items()]

    # 为每个文件创建 HTTP头部
    filesize = 0
    fileheaders = []
    for filesize, formname, filename in fileinfo:
        headers = [
            --'+BOUNDARY,
            'Content-disposition: form-data; name="%s"; filename="%s" \',
            (formname, filename),
            'Content-length: %d' % filesize,
        ]
        fileheaders.append(CRLF.join(headers)+CRLF)
        filesize += filesize

    # 结束标记
    closing = "--'+BOUNDARY--\r\n"

    # 确定整个请求的长度
    content_size = (sum(len(f) for f in formsections) + sum(len(f) for f in fileheaders) + len(closing)

    # 上传
    conn = HTTPConnection(addr)
conn.putrequest("POST", url)
conn.putheader("Content-type", 'multipart/form-data; boundary=%s' % BOUNDARY)
conn.putheader("Content-length", str(content_size))
conn.endheaders()
```

```python
# 发送所有表单部分
for s in formsections:

for head,filename in zip(fileheaders,filefields.values()):

    f = open(filename, 'rb')
    while True:
        chunk = f.read(16384)
        if not chunk: break
        conn.send(chunk)

r = conn.response()
respondedata = r.read()
conn.close()
```


# `http.server` (`BaseHTTPRequestHandler`, `CGIHTTPServer`, `SimpleHTTPServer`)

`http.server` 模块提供了用于实现 HTTP 服务器的各种类。在 Python 2 中，该模块的内容被分在三个库模块中：`BaseHTTPRequestHandler`、`CGIHTTPServer` 和 `SimpleHTTPServer`。

## `HTTPServer`

以下类实现了一个基本的 HTTP 服务器。在 Python 2 中，它位于 `BaseHTTPRequestHandler` 模块中。

```python
HTTPServer(server_address, request_handler)
```

创建一个新的 `HTTPServer` 对象。`server_address` 是服务器将监听的 (主机, 端口) 元组。`request_handler` 是一个派自 `BaseHTTPRequestHandler` 的处理器类，将在后文中进行描述。

`HTTPServer` 直接继承自 `socketserver` 模块中的 `TCPServer`。因此，如果你想以任何方式自定义 HTTP 服务器的操作，你可以通过继承服务器运行的方式来实现。以下是定义一个只接受来自特定子网连接的多线程 HTTP 服务器的方法：

```python
from http.server import HTTPServer # Python 3
from socketserver import ThreadingMixIn
except ImportError:
    from BaseHTTPServer import HTTPServer # Python 2
    from SocketServer import ThreadingMixIn
class MyHTTPServer(ThreadingMixIn, HTTPServer):
    def __init__(self, addr, subnet):
        HTTPServer.__init__(self, addr, handlerclass)
        self.subnet = subnet
    def verify_request(self, request, client_address):
        host, port = client_address
        if not host.startswith(self.subnet):
            return False
        return HTTPServer.verify_request(self, request, client_address)
```

### `SimpleRequestHandler` 和 `CGIRequestHandler`

如果你想快速搭建一个简单的独立 Web 服务器，可以使用两个 Web 处理器类。这些类独立于任何像 Apache 的第三方 Web 服务器运行。
