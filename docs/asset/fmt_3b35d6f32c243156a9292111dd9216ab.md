
大多数守护进程是在启动序列的最后自动创建的。在某些情况下，进程是由 `init` 进程（进程 #1）创建的。在其他情况下，进程是由自终止的父进程创建的，导致守护进程变成孤儿进程。正如你可能从在本章之前的讨论中所记得的，所有孤儿都会被 `init` 进程收养。因此，无论如何，大多数守护进程最终都会成为进程 #1 的子进程。出于这个原因，守护进程的一个定义是：任何没有控制终端、且父进程 ID 为 #1 的后台进程。

如果你使用的是 Linux 系统，请花点查看 `/etc/rc.d/init.d` 目录。在这里发现大量的脚本，每个脚本都用于启动、停止或重启特定的守护进程。

- `vi -R file`: 以只读模式启动 vi，编辑指定文件
- `view file`: 以只读模式启动 vi，编辑指定文件
- `vim file`: 启动 Vim，编辑指定文件。
- `vim -C file`: 在兼容模式下启动 vi

## 退出

- `q!`: 不保存数据退出
- `ZZ`: 保存数据并退出
- `wq`: 保存数据并退出
- `x`: 保存数据并退出

## 故障后恢复

- `vi -r`: 显示可以恢复的文件名
- `vi -r file`: 启动 vi，恢复指定文件

## 修正按键

- `<Backspace>`/`<Delete>`: 删除输入的最后一个字符
- `^W`: 删除输入的最后一个单词
- `^X/U`: 擦除整行

## 控制显示

- `^L`: 刷新当前屏幕
- `:set number`: 显示内部行号
- `:set nonumber`: 不显示内部行号

# 移动缓冲区

- `^F`: 向下移动一屏
- `^B`: 向上移动一屏
- `^D`: 向下移动一屏
- `^U`: 向上移动一屏

# 搜索模式

- `/regex`: 向前搜索指定表达式
- `?regex`: 向后搜索指定表达式
- `n`: 重复上次搜索，相同方向
- `N`: 重复上次搜索，相反方向

# 字符

- `i`: 进入插入模式：在光标前插入
- `a`: 进入插入模式：在光标后插入
- `I`: 进入插入模式：在行首插入
- `A`: 进入插入模式：在行尾插入
- `oo`: 进入插入模式：在当前行下方
- `0`: 进入插入模式：在当前行上方
- `<Escape>`: 离开插入模式，回到命令模式

# 修改

- `r`: 替换 1 个字符 `不进入插入模式`
- `R`: 覆盖替换
- `s`: 替换 1 个字符并插入
- `C`: 从光标到行尾替换插入
- `cc`: 替换整行
- `S`: 替换整行
- `cmove`: 从光标到移动位置替换
- `~`: 切换字母大小写

# 替换

- `/:pattern/replace/`: 替换当前行
- `/:lines/pattern/replace/`: 替换指定行
- `/:line_lines/pattern/replace/`: 替换指定范围
- `:%s/pattern/replace/`: 替换所有行

在命令结束时，使用 `c` 确认，使用 `g` 全局替换所有匹配项。要指定行号，可以使用实际数字、`.` `点` 表示当前行或 `$` `美元符号` 表示缓冲区最后一行。数字 `1` 表示缓冲区的第一行。

# 行号

- `nG`: 跳转到第 n 行
- `IG`: 跳转到缓冲区第一行
- `gg`: 跳转到缓冲区第一行
- `G`: 跳转到缓冲区最后一行
- `map g 1G`: 定义宏使 g 等同于 1G
- `zn`: 跳转到行 n
- `:1G`: 跳转到第一行

- `i`: 进入插入模式：在光标前插入
- `a`: 进入插入模式：在光标后插入
- `I`: 进入插入模式：在行首插入
- `A`: 进入插入模式：在行尾插入
- `oo`: 进入插入模式：在当前行下方

## 删除：常用组合

- `dw` 删除 1 个单词
- `dnw` 删除 n 个单词
- `dnW` 删除 n 个单词 `忽略标点符号`
- `db` 向后删除 1 个单词
- `dn)` 删除 n 句子
- `}` 删除 n 个段落
- `dG` 从当前行删除到编辑缓冲区末尾
- `dgg` 从当前行删除到编辑缓冲区开头
- `d1G` 从当前行删除到编辑缓冲区开头

## 复制上次删除的内容

- `p` 复制剪贴板；插入到光标之后/下方
- `P` 复制剪贴板；插入到光标之前/上方
- `xp` 交换两个字符
- 深度交换两个单词 `第一个单词的左侧`
- `ddp` 交换两行
- `"1Pu_u_u...` 连续撤销一个删除操作

## 复制与移动行

- `zlinecot` 复制指定行；插入到目标行下方
- `zline_linecolarget` 复制指定范围；插入到目标行下方
- `zlinarget` 移动指定行；插入到目标行下方
- `zline_linarget` 移动指定范围；插入到目标行下方

## 取回 `Yank`

- `ymove` 从光标取回到移动位置
- `yy` 取回当前整行

## 取回：常用组合

- `yw` 取回 1 个单词
- `ynw` 取回 n 个单词
- `ynW` 取回 n 个单词 `忽略标点符号`
- `yb` 向后取回 1 个单词
- `yn)` 取回 n 句子
- `}` 取回 n 个段落
- `yG` 从当前行取回到编辑缓冲区末尾
- `ygg` 从当前行取回到编辑缓冲区开头
- `y1G` 从当前行取回到编辑缓冲区开头

## 执行 Shell 命令

- `=command` vi，执行指定的 shell 命令
- `=!!` vi，执行上一次 shell 命令
- `:sh` vi，启动一个 shell
- `:!!csh` vi，启动一个新的 C-Shell

## 将数据读入编辑缓冲区

- `=file` 在指定行之后插入文件内容
- `:file` 在当前行之后插入文件内容
- `:!command` 在指定行之后插入命令输出
- `:r command` 在当前行之后插入命令输出
- `:r pattern` 插入以指定模式开头的单词

## 使用 Shell 命令处理数据

- `n!command` 在 n 行上执行命令
- `!move command` 从光标到移动位置执行命令
- `!move fmt` 格式化从光标到移动位置的行

## 写入数据

- `=w` 将数据写入原始文件
- `:w file` 将数据写入指定文件
- `:w>> file` 将数据追加到指定文件

## 在编辑时更改文件

- `=e` 编辑指定的文件
- `:e! file` 编辑指定的文件，跳过自动检查

## 缩写

- `=ab` 设置长字符串，将短字符串设为长字符串的缩写；显示当前缩写
- `:ab`
- `:una` 取消缩写短字符串
