3. 使用`touch`命令创建一个新文件。该文件的默认权限是什么？

根据指定的`UMASK`，默认权限将分配给新创建的文件。在这台机器上，`UMASK`未被修改，这会导致所有者具有读写权限，用户组只有读权限，而其他人没有权限。执行此任务的命令如下所示，同时也如图 1.103 所示。

```bash
touch newfile

ls -l
```
