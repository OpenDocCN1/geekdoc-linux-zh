
# Linux 词典

## IDE

参见集成设备电子（IDE）。来自 Redhat-9–Gloss

用于 IDE 硬盘的 S.M.A.R.T. 状态检查工具，对具备 SMART（自我监控、分析和报告技术）的 IDE 设备执行各种非破坏性测试。SMART 通过监控设备的不同属性（ID）提供近故障预测。你的 BIOS 和硬件需要支持 SMART 来使用此设备。来自 Debian 3.0r APT

### IDE（国际数据加密算法 International Data Encryption Algorithm）

IDEA 是一种对称分组算法。它在用于 PGP 时非常流行，但由于商业许可问题，它并非无处不在。争议：IDEA 是少数受专利保护的（广泛使用的）密码之一；商业使用需要许可。误解：该名称暗示 IDEA 是官方标准——事实并非如此。然而，它被广泛使用，并且许多标准中的一个选项。应用：PGP 来自 Hacking–Lexicon

由雪杰和 James L. 开发。它使用 128 位密钥。由瑞士公司 "Ascom-Tech" 持有。

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## ident2

高级守护进程 `ident2` 是一个高级、可配置的 ident 守护进程。你可以将其设置为撒谎、或者不接收任何响应，并且它是按用户配置的（例如，如果用户在使用 IRC，则使用 ~daemon/ident 配置；如果用户在使用 IRC，则使用 ~kind/ident）。管理员可以指定他们想要或不要返回类型。来自 Debian 3.0r

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## ident/auth

UNIX 上的 ident（也称为 auth）用于识别 TCP 连接的所有者。auth 最初被引入是作为某种身份验证机制。现在，它最常用作一种记录谁在做什么活动的方式：当你连接到基于 UNIX 的邮件服务器时，它通常会尝试通过 ident 端口 113 向你建立反连接。目标仅仅是记录哪个用户正在测试访问服务器。来自 Hacking–Lexicon
