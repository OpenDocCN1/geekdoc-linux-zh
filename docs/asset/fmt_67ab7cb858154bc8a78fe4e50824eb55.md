## 第87章 Oracle 的 MS 文件

在解决问题时，如果理解已经是，那么你总会有循。

> 精确法则

Oracle 的 MS 文件是一种含有错误信息和相应编号的二进制文件。本章将你共同研究它的格式，尝试解读其中的原始数据。Oracle RDBMS 提供专门的文本格式的错误信息，并不是每个 MS 文件都有对应的文本格式错误文件，都需要将二进制文件和信息进行转换。过滤`Oracle.MSG`日志后，文件开头的内容如下：
