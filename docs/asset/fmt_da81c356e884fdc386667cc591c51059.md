
# 第 10 章 文件操作

新特性！

`合并变换（Merge Transforms）` 将源对象的变换控制器合并到当前场景中。在外部引用对象到场景之前，必须先选择合并变换选项。

`合并材质（Merge Materials）` 将外部引用（XRef）记录中的材质合并到当前文件中。

`合并操器（Merge Manipulators）` 允许你决定是否对操器具有本地控制权。勾选时，应用到 `XRef` 对象的任何操器都将合并到场景中。取消勾选时，无法更改来自 `XRef` 的操器。

`修改器（Modifiers）` 控制来自 `XRef` 文件的修改器的处理方式。当其设置为 `XRef` 时，修改器包含在 `XRef` 文件中且无法更改。`合并（Merge）` 意味着分配给 `XRef` 对象的修改器可以更改，但不会反映回 `XRef` 中。`忽略（Ignore）` 意味着忽略来自 `XRef` 文件的修改器。

一旦导入了 `XRef` 对象，你就可以使用工具对其编辑。如果你使用命令面板中的“修改（Modify）”选项卡修改 `XRef` 对象：在选中 `XRef` 对象的情况下，“修改”选项卡允许你控制 `XRef` 代理对象的行为和显示方式。“修改”选项卡中的选项与 `XRef` 对象对话框中的 `XRef` 区域对应。

## 使用 XRefs 和资产浏览器布置家具

使用 `XRefs`，你可以开始为来自别墅模型的家具创建一个场景设置。在本节中，你将使用椅子以及来自 `Sybase` 的其他家具来创建设置。在布置家具的过程中，你将有机会探索使用 `XRefs` 的另一种方法。这次，你将使用 `XRef` 场景通过合并命令和资产浏览器临时将别墅模型与一个新的家具文件合并到一起。资产浏览器（`Asset Browser`）是一个帮助你从一个 `VIZ` 文件将几何体导入到另一个文件的工具。它通过提供一种无缝的方式访问你个人电脑、网络和互联网数据，来帮助你管理项目。

让我们先查看如何使用合并命令导入 `VIZ` 文件数据。

1. 选择 `文件（File） ⮥ 重置（Reset）` 以创建一个新文件，并将新文件重置为 `VIZ` 的默认设置。
2. 显示重置警告消息。点击 `是（Yes）`。
3. 选择 `文件（File） ⮥ 合并（Merge）`。合并对话框。这是一个典型的 `Windows` 对话框。
4. 找到并打开你刚刚创建的 `MyCouch01.max` 文件。出现合并对话框（见图 10.6）。

## 重置单位

在早早重置场景后，你可以将单位更改为“美国标准英尺（带十进制的英寸）”（`US Standard Feet w/Decimal Inches`）。

1. 选择 `文件（File） ➤ 合并（Merge）`。
2. 在合并对话框中，找到并选择 `Mybigchair.max`，然后点击 `打开（Open）`。
3. 在合并对话框中，点击 `[Bigchair01]`，然后点击 `确定（OK）`。这次你看到一个对话框，警告当前场景中存在重复材质，如图 10.8 所示。

在此时，你有四个选项：

- 你可以通过在对话框顶部附近的输入框中输入新名称并点击“重命名合并材质”（`Rename Merged Material`）按钮来重命名合并的重复材质。这将保持合并的材质和当前场景中的材质均为唯一材质。
- 你可以使用“合并材质”（`Use Merged Material`）用合并文件的材质替换当前文件中的材质。

## 使用外部文件替换对象

你刚刚看到如何使用合并命令导入场景的一部分。另一个命令叫做“替换（`Replace`）”，与合并相似，但它允许你替换当前场景中同名的对象。由于你不想替换沙发的背部，你必须更改沙发背的对象。

1. 打开 `MyFurniture.max` 文件。
2. 选择 `Couch01`；然后选择 `打开（Open）`。
3. 点击名为 `ChamferBox02` 的对象。按需要按下键盘上的 `H` 键。
4. 在命令面板的“修改”选项卡中，更改对象 `ChamferBox02` 和 `Couchback01` 的名称。
5. 选择 `组（Group） ▷ 关闭（Close）`。

现在你准备好用你修改过的椅子替换椅子背了：

1. 选择 `文件（File） ▷ 替换（Replace）`。
2. 在替换对话框中，找到并选择 `Mybigchair.max`，然后点击 `打开（Open）`。出现替换对话框，如图 10。
3. 选择 `ChamferBox02`，然后点击 `确定（OK）`。椅子背。
4. 点击 `是（Yes）`。椅子背将被用你在 `Mybigchair.max` 文件中修改过的椅子替换，如图 10.10 所示。
5. 保存 `MyFurniture.max` 文件。

注意，背在原始椅子和椅子的实例副本中都被替换了。如果你制作的是副本而不是实例副本，那么只有原始椅子背会被替换。这证明实例副本会与原始对象一起被替换。

# 视口中材质显示错误

在使用 `XREfs` 和 `替换（Replace）` 选项时，材料在 `平滑+高光（Smooth + Highlights）` 渲染视口中并不总能正确显示。要强制 `VIZ` 重新评估材料，请在材质编辑器（`Material Editor`）中选择它们，关闭视口中的 `显示贴（Show Map）`，然后再次开启。材料应该就能正常显示。
