
如果你管理着一堆 Windows 机器，`AIO System Rescue Kit`可以帮助你保持它们的良好状态。

`ALT Linux Rescue`在自定义方面也没有提供太多。它拥有的少数辅助功能之一是法证模式（`forensic-mode`）启动选项，该选项启动发行版时不激活交换分区或挂载任何分区。还有几个脚本会自动挂载连接的磁盘并修复主引导记录中的任何问题，这非常方便。

使`UBCD`从竞争中脱颖而出的是其自定义启动菜单。该发行版没有图形桌面，而是启动到一个布局非常合理的菜单。自定义的文本菜单帮助你引导至解决你问题的相关实用程序。菜单逻辑排列，各个条目包含有用的信息，帮助你识别它们。

相比之下，`AIO System Rescue Toolkit`拥有许多`CLI`工具，但为了便于访问，它在桌面上为所有工具提供了快捷方式。除了`Live`环境，你还可以在`Windows`内部启动该发行版的`CD/USB`，通过自定义界面访问其所有`Windows`特定的修复和救援工具。

| `SystemRescueCd` | 3/10 |
| `ALT Linux Rescue` | 7/10 |
| `Ultimate Boot CD` | 9/10 |
| `MorpheusArch` | 5/10 |

新用户尤其会欣赏`UBCD`的自定义启动菜单。

### 易用性

用户体验如何？

对于打包了专业工具的发行版，要让我们信服，需要的不仅仅是各部分的总和。在发行版中塞入大量工具会对经验丰富的用户有所帮助，但对于试图救援无法启动的机器的普通桌面用户来说，帮助有限。

正因如此，易用性成为本`Roundup`中此类专业发行版的关键因素。请记住，易用性不仅仅是美观的界面；拥有有关如何使用手头工具的相关信息与选择正确的工具同样重要。

最后，仅仅因为一个发行版无论用户经验水平如何都易于使用，并不意味着它比专为经验丰富的用户设计的发行版功能更弱。

### System Rescue Toolkit 8/10

该发行版的独特之处在于它拥有几种用户模式。你可以将`ISO`传输到`CD`或`USB`，并将其作为常规`Live`磁盘使用，该磁盘启动到经过调整的`LXDE`桌面。桌面上有所有应用程序的图标（包括命令行版本），这对初次使用的用户非常有帮助。

除了`Live`环境，你还可以在`Windows`内部运行该发行版。在这种情况下，它会启动一个自定义修复实用程序，列出其存储库中所有可用的工具，帮助你修复损坏的`Windows`安装。

该自定义应用有多个选项卡，每个选项卡包含特定领域的应用，如硬件、软件、网络等。对于熟悉故障排除的人来说，该自定义应用操作直观；还有一个非常实用的`AutoFix`工具，可以帮助新手修复`Windows`安装中的许多常见问题。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_41_0.png)

### ALT Linux Rescue 5/10

与`Roundup`中的其他发行版不同，`ALT Linux Rescue`直接启动到`shell`，完全缺少图形桌面。这显然表明它是为经验丰富的用户设计的，这些用户不仅熟悉捆绑的工具，还知道需要哪些工具来修复影响系统的问题。

除了前面提到的几个脚本，没有其他便利功能。除了常规启动选项，该发行版还有几个其他选项。有上述的法证模式，它最小化与计算机磁盘的交互，帮助你进行系统法证调查。

另一种启动选项旨在救援无头机器。它自动为机器分配`IP`地址，生成随机`root`密码，并启动`SSH`服务器以帮助你远程访问机器。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_41_1.png)

### 帮助与支持

当你需要协助时。

`MorpheusArch`是本`Roundup`中没有提供任何自身帮助信息的两个发行版之一。

你可以在`LinDag`的`GitHub`页面上找到简短的图解指南，但没有论坛或邮件列表可供寻求协助，因此该发行版仅适用于希望在其`Arch`基础上使用捆绑恢复工具的人。

`ALT Linux Rescue`在这方面也没好多少，它只在`ALT Linux`网站上有一个页面，列出了发行版的功能和一些主要实用程序。主要的`ALT Linux`发行版有俄语论坛和邮件列表，但`Rescue`版本没有任何官方支持渠道。

相比之下，`AIO System Rescue Toolkit`有一个详细的常见问题解答（`FAQ`），列出了所有工具以及几个视频，帮助你熟悉该发行版。没有论坛，但开发者在网站上创建了一个页面，用户可以在此提问。

`SystemRescueCd`的网站托管了快速入门指南以及基本和高级使用的详细说明。还有针对经验丰富用户的指南，例如如何制作自定义版本以及如何从无法启动的`Windows`计算机备份数据。

拥有教程版块`wiki`和详细的`FAQ`（旨在让用户熟悉该发行版），`UBCD`在这方面远远超过其竞争对手。然而，教程版块只是指向从论坛版块整理出的一系列用户贡献的教程列表，因此它可能还可以更友好一些。`Wiki`列出了发行版中的所有工具，以及关于其功能的有用备注。

`SystemRescueCd`和`UBCD`是仅有的两个积极在论坛版块上解决用户查询的发行版。

## MorpheusArch 3/10

与其他几款维修和救援发行版相比，`MorpheusArch`的吸引力较为有限。它主要宣传包含`TestDisk`和`PhotoRec`等实用工具，这些工具可以帮助用户恢复误删的文件。该发行版启动后会进入一个锁定的`LXQt`桌面，而项目网站上没有提及默认密码（`arch`），这是一个严重的疏漏。

`LXQt`桌面包含少量应用程序，包括`Firefox`、`Zenmap`和`LFTP`。桌面没有提供任何关于如何继续操作的指示，这有点令人困惑。发行版内部甚至项目网站上缺乏入门文档也无助于改善这种情况。

`MorpheusArch`项目的一个亮点是辅助工具`LinDiag`。然而，它并未包含在发行版中，你需要手动拉取它，这一点再次没有明确说明。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_42_0.png)

## SystemRescueCd 7/10

该发行版的早期版本拥有一个综合的启动菜单，包含十多个启动选项。在最新的基于`Arch`的版本中，这些选项已被移除，只剩下两个。

有一个选项可以将整个系统复制到`RAM`中，默认选项会将系统启动到控制台，其中列出了配置键盘布局和启动图形环境的命令。

该发行版使用`X`桌面，其菜单中包含了一些必备的生产力应用，包括网络浏览器、`VNC`查看器、密码管理器以及一些对开发人员友好的工具。

发行版中的大多数救援工具是基于命令行的，与`MorpheusArch`一样，该发行版没有提供任何指针来帮助用户入门。其网站是其救命稻草，里面充满了各种详细的文档，帮助首次用户使用该发行版。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_42_1.png)

## Ultimate Boot CD 9/10

与这里的其他发行版不同，`UBCD`的独特之处在于它直接启动到其自定义的基于文本的菜单。该菜单根据工具影响的计算机部分，将打包的实用工具分为不同类别，例如`HDD`、外围设备、系统等。

进入某个类别即可查看单个工具的项目列表。一些类别，如`HDD`，会进一步细分为不同的任务，如启动管理、数据恢复、磁盘克隆和磁盘擦除等。

当你浏览某个类别中的每个工具时，菜单会显示有关该工具的简短但有用的信息。尽管菜单是基于文本的，但清晰的分类和有用的描述意味着没有经验的用户可以轻松导航和使用该发行版。结合项目网站上的有用信息，`UBCD`是一个极佳的选择。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_42_2.png)

## 安全与隐私功能

除了维修和救援，它们还能做什么？

虽然这些发行版的主要目的是救援损坏的计算机，但许多发行版还配备了一整套工具，以帮助保护你的系统安全并防止隐私泄露。这是因为安全问题导致计算机崩溃的情况并不少见。偶尔，你可能还需要在恢复系统之前对安装进行清理（`sanitise`），以确保与其交互的网络中其他机器的健康状态。

`MorpheusArch`拥有`nmap`工具来探索网络，你可以通过`LinDiag`脚本使用它。该发行版还有几个实用工具，可以从设备中清除文件系统签名并设置硬盘参数。

`AIO System Rescue Toolkit`也包含`nwipe`，以帮助安全地清除文件。`ALT Linux Rescue`包含工具来安全删除文件并调查安全漏洞。该发行版设计用于多种场景，但不幸的是，确保隐私并不是其中之一。
