
# 基于记录的数据库模型

在基于记录的模型中，数据库由若干类型固定格式的记录组成。每个记录具有固定的一组字段。最广泛接受的三种基于记录的数据模型是关系模型、网状模型和层次模型。后两者曾经被广泛使用，但如今重要性逐渐下降。关系模型则被非常广泛地使用。基于关系模型的数据库被称为关系数据库。

关系模型使用一组表（称为关系）来表示数据以及这些数据之间的关系。每个表有多个列，每列都有一个唯一的名称。表的每一行称为一个元组，每一列表示该元组中某个属性的值。

数据库的大小可以差异很大，从个人数据库的几兆字节（megabytes），到大型公司数据库的吉字节（gigabytes，1 吉字节等于 1,000 兆字节）甚至太字节（terabytes，1 太字节等于 1,000 吉字节）。

数据库中的信息存储在一个能够容纳大量数据的非易失性介质上；最常用的此类介质是磁盘。磁盘比主存能存储显著更多的数据，并且每单位数据的成本要低得多。

为了提高关键任务系统中的可靠性，磁盘可以被组织为一种泛称的独立磁盘冗余阵列（`RAID`）。在 `RAID` 系统中，数据在多个磁盘之间以一定的冗余度（例如复制）进行组织。即使 `RAID` 系统中的某个磁盘损坏并丢失数据，丢失的数据也可以从 `RAID` 系统中的其他磁盘重建。参见`计算机存储技术`。

在逻辑上，关系数据库中的数据被组织为一组关系，每个关系由一组记录组成。这是呈现给数据库用户的视图。底层磁盘上的实现（对用户隐藏）由一组文件组成。每个文件由一组固定大小的磁盘存储单元组成，称为块。数据库中的记录一次存储一个块，该块与一个或多个文件相关联。通常，一个文件仅包含来自一个关系的记录，但出于性能原因，也使用了文件包含来自多个关系的记录的组织方式。

在关系数据库中检索所需记录的一种方式是对相应的关系执行扫描；扫描会从关系中逐条获取所有记录。

使用扫描从大型关系中访问所需记录可能非常昂贵。索引是允许更高效访问记录的数据结构。索引建立在一个或多个关系属性之上；这些属性构成了搜索键。给定每个搜索键属性的值，可以使用索引结构快速检索具有指定搜索键值的记录。索引还可以支持其他操作，例如检索搜索键值落在指定值范围内的所有记录。

数据库模式由用数据定义语言表达的一组定义指定。数据定义语言语句的执行结果是一组存储在名为数据字典的特殊文件中的信息。数据字典包含元数据，即关于数据的数据。在数据库系统中实际读取或修改数据之前，会参考此文件。数据定义语言还用于指定存储结构和访问方法。

数据操作是检索、插入、删除和修改存储在数据库中的信息。数据操作语言使用户能够以适当的数据模型组织的方式访问或操纵数据。数据操作语言基本上有两种类型：

- 过程式数据操作语言要求用户指定需要哪些数据以及如何获取这些数据；
- 非过程式数据操作语言要求用户只指定需要哪些数据，而不指定如何获取这些数据。

查询是请求检索信息的语句。用于执行此信息检索的数据操作语言的查询被称为查询语言。虽然在技术上不准确，但将查询语言和数据操作语言同义使用的做法很常见。

数据库语言支持数据定义和数据操作功能。虽然已提出并实现了许多数据库语言，但 `SQL` 已成为大多数关系数据库系统支持的标准语言。基于面向对象模型的数据库也支持与 `SQL` 类似的声明式查询语言。

`SQL` 提供了完整的数据定义语言，包括创建具有指定属性类型的关系的能力，以及对数据定义完整性约束的能力。

通过示例查询（`QBE`）是一种用于指定查询的图形化语言。由于它对非专家用户来说比 `SQL` 简单得多，因此广泛用于个人数据库系统中。

表单界面呈现一个看起来像表单的屏幕视图，其中包含供用户填写的字段。表单系统中的某些字段可能会自动填充。报表生成器允许定义报表格式，并包含从数据库获取数据的查询；查询的结果以格式化的形式显示在报表中。这些工具提供了一种构建数据库界面的新语言，通常被称为第四代语言（`4GLs`）。参见`人机交互`。

通常，对数据库的多个操作构成单个逻辑工作单元，称为事务。事务的一个例子是从一个账户向另一个账户转账。数据库中的事务反映商业世界中相应的交易。

传统上，数据库系统被设计用于支持商业数据，主要由结构化字母数字数据组成。近年来，数据库系统增加了对多种非传统数据类型的支持，如文本文档、图像、地图和其他空间数据。目标是使数据库成为通用服务器，可以存储所有类型的数据。而不是将所有这些数据类型的支持添加到核心数据库中，供应商提供与数据库集成的附加包来提供此类功能。 [H.FKo; A.Si.; S.Su.]

## 椰枣

椰枣是椰枣树（`Phoenix dactylifera`）的果实，这是最古老的栽培树种作物之一。它为中东和北非的许多人群提供主食，并且因其饲料、纤维和遮蔽功能而备受重视。

椰枣树属于棕榈科。`Phoenix` 属与其他棕榈物种的区别在于它产生萌蘖、柱状圆形树干、羽状叶以及特征明显的沟槽种子。椰枣树是单子叶植物，只有一个芽或生长点。椰枣树干也缺乏通常在双子叶果树中发现的形成层生长层，这对真正的次生生长非常重要。

椰枣树是雌雄异株的：雄性棕榈产生雄花，雌性棕榈产生雌花。雄花和雌花簇都被保护性的叶鞘包裹。蜜蜂和昆虫会去雄性花朵，但不会去雌性花朵。椰枣树依赖于人工授粉。对于商业椰枣生产，必须每个季节收集雄花的花粉，并手动将其应用于雌花序。风媒传粉会导致坐果率低，且果实不能正常成熟。一棵雄性树可以为 30–40 棵雌性树提供足够的花粉。由于果壁内层肉质，椰枣果实被归类为浆果，例如番茄。参见`ARECALES`（露兜树科）；`FRUIT`（果实）；`TREE`（树木）。

## 测年方法

用于按时间顺序排列事件，并确定历史、地质学、古生物学、考古学、古人类学和天文学中事件数值年龄的相对和定量技术。相对技术可以确定事件的先后顺序，而定量技术可以对事件的年龄进行数值估算。大多数数值技术基于天然放射性核素的衰变，少数基于随时间变化的化学变化，另一些则基于地球轨道的变化。一旦校准，某些相对技术也可以对年龄进行数值估算。参见`ARCHAEOLOGY`（考古学）；`ASTRONOMY`（天文学）；`GEOLOGY`（地质学）；`RADIOISOTOPES`（放射性同位素）。

### 相对测年

相对测年方法依赖于对自然界物理过程如何留下可排序记录的理解。一旦事件记录被排序，每个事件相对于其他每个事件是更老还是更年轻便是已知的。在大多数情况下，记录包含在地质背景中，如地层序列；在其他情况下，记录可能包含在单个化石中，或体现在天体在时空中的排列中。最重要的相对测年方法是地层测年和古地磁测年。其他相对测年方法包括古地磁测年、树木年轮测年和火山灰地层测年。参见`DENDROCHRONOLOGY`（树木年轮学）；`PALEOMAGNETISM`（古地磁学）；`SEQUENCE STRATIGRAPHY`（序列地层学）；`STRATIGRAPHY`（地层学）。

### 化学与同位素测年

几种化学过程缓慢发生，产生地质学感兴趣的时间尺度的变化；其中包括黑曜石的水合，以及L-型氨基酸向D-型氨基酸的转化（外消旋作用或差向异构作用）。年龄测定需要测量过程的速率常数，了解被研究物质的温度历史，以及（特别是对于氨基酸外消旋作用）了解物质的化学环境。参见`AMINO ACID DATING`（氨基酸测年法）；`OBSIDIAN RACEMIZATION`（黑曜石外消旋作用）。

与化学方法不同（化学方法的变化既取决于时间又取决于环境条件），基于放射性衰变的同位素方法仅取决于时间。母体核素可能通过简单衰变单步衰减为一个稳定的子体[例如，铷衰变为锶加上一个β粒子（`$^{87}$Rb → $^{87}$Sr + $\beta$`）]；通过不同过程分支衰变为两个子体[例如，钾捕获一个电子形成氩，或失去一个β粒子形成钙（`$^{40}$K → $e^{-}$ + $^{40}$Ar`，`$^{40}$K → $^{40}$Ca + $\beta$`）]；通过一系列步骤（链式衰变）衰减为一个稳定的子体；或通过裂变分解为两个大小不等的碎片。在所有情况下，母体原子数量减少，子体原子数量增加，因此对于每种方法，都有一个对年龄敏感的子体/母体同位素比随时间增加。许多不同的同位素已被用于测量地质和考古材料的年龄。例如，下表列出了母体同位素、它们的半衰期以及产生的子体产物。参见`GEORONTOLOGY`（地质年代学）；`HALF-LIFE`（半衰期）。
