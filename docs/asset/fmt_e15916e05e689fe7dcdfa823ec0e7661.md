# 倾斜对象

当您倾斜 或斜向 所选对象时，您是在水平或垂直方向上对其进行倾斜。结果可以使对象看起来在远离观众，这为特别是二维对象赋予了深度感。您可以倾斜多边形和贝塞尔曲线。如果您想要倾斜的对象既不是这些者，程序将询问您是否想将其转换为曲线或多边形。
