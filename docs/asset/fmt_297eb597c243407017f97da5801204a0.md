## 先决条件

要使用本书，你只需要一个可以运行的 Linux 安装。你可以通过两种方式获取它：

**在（不那么旧的）电脑上安装 Linux。** 你选择哪种发行版并不重要，尽管今天大多数人从 `Ubuntu`、`Fedora` 或 `OpenSUSE` 开始。如果不确定，请先尝试 `Ubuntu`。取决于你的硬件，安装现代 Linux 发行版可能极其简单，也可能极其困难。我建议使用一台几年前的台式电脑，至少拥有 2GB 内存和 6GB 硬盘空间。尽可能避免笔记本电脑和无线网络，因为这些通常更难运行。

**使用“现场启动 CD”或 USB 闪盘。** 许多 Linux 发行版的酷之处之一是可以直接从 CD-ROM 或 USB 驱动器运行它们，而无需安装。只需进入 BIOS 设置，将计算机设置为从 CD-ROM 驱动器或 USB 设备启动并重启。使用这种方法是在安装之前测试计算机 Linux 兼容性的很好的方法。缺点是与在硬盘上安装 Linux 相比，速度可能会慢。`Ubuntu` 和 `Fedora`（以及其他版本）都有现场版本。

无论你如何安装 Linux，你都需要偶尔拥有超级用户（即管理员）权限来执行书中的课程。

在你完成了可以运行的安装后，就可以开始阅读并配合你自己的电脑进行操作：书中的大部分内容都是“实践性的”，所以请坐下来开始打字吧！

## 为什么我不叫它为“GNU/LINUX”

在某些领域，将 Linux 操作系统称为“GNU/Linux 操作系统”是政治正确的。“Linux”这个词的问题在于，没有完全正确的命名方式，因为它在一个庞大的、分布式的开发过程中，是由许多不同的人编写的。从技术上说，Linux 是操作系统内核的。当然，内核非常重要，因为它让操作系统运行起来，但仅靠它不足以形成一个完整的操作系统。

理查德·斯托曼（Richard Stallman）是自由软件运动的天才哲学家，他创立了自由软件基金会，建立了 GNU 项目，编写了第一版本的 GNU C 编译器 (`gcc`)，创建了 GNU 通用公共许可证 (`GPL`) 等。他坚持要求你称其为“GNU/Linux”，以正确反映 GNU 项目的贡献。虽然 GNU 项目基于 Linux 内核，且该项目的贡献非常值得认可，但将它们放在名称中对所有做出重大贡献的人来说是不公平的。此外，我认为“Linux/GNU”在技术上更准确，因为内核首先启动，一切都运行在内核之上。

在流行用法中，Linux 指内核以及典型发行版中找到的所有其他自由和开源软件，即整个 Linux 生态系统，似乎倾向于像 DOS、Windows、macOS、Solaris、Irix 和 AIX 这样的单单词名称。我选择了使用流行的格式。如果你更倾向于使用“GNU/Linux”，请在阅读本书时进行心理上的查找替换。我不介意。

# 第一部分：学习 Shell

## 什么是 Shell？

当我们谈论命令行时，我们实际上是指 shell。shell 是一个程序，接收键盘命令并将其传递给操作系统执行。几乎所有的 Linux 发行版都提供一个来自 GNU 项目的名为 `bash` 的 shell 程序。这个名字是 bourne-again shell 的简称，引用了 `bash` 是由 Steve Bourne 编写的原始 Unix shell 程序 `sh` 的增强替代品这一事实。

### 终端模拟器

在使用图形用户界面 (GUI) 时，我们需要另一个称为终端模拟器的程序来与 shell 交互。如果我们查看桌面菜单，可能会发现一个。KDE 使用 `konsole`，而 GNOME 使用 `gnome-terminal`，尽管它在你的菜单上可能简单地称为 `Terminal`。Linux 有许多其他终端模拟器可用，但它们基本上都在做相同的事情：赋予我们访问 shell 的权限。你可能会根据某个终端模拟器的功能多少寡而对其中某一个产生偏好。

### 你的第一次击键

那么让我们让我们开始吧。启动终端模拟器。一旦它出现，我们应该看到类似这样的：

```
linuxuxbox~$
```

这是一个 shell 提示符，每当 shell 准备好接受输入时它就会出现。虽然外观可能根据发行版而异，但它通常包含你的用户名@主机名，后面跟着当前工作目录（稍后会介绍）和一个美元符号。

如果提示符的最后一个字符是井号 (`#`) 而不是美元符号，则终端会话具有超级用户权限。这意味着我们以 `root` 用户身份登录，或者我们选择了一个提供超级用户权限的终端模拟器。

假设目前一切正常，让我们尝试输入。在提示符处输入一些乱码，例如：

```
linuxuxbox~$ kaekjfaij
```

因为这个命令没有意义，shell 告诉了我们这一点并给了我们另一个机会。

```
bash: kaekjfaij: command not found
linuxuxbox~$
```

### 命令历史

如果我们按下上方向键，将看到之前输入的命令 `kaekjfaij` 重新出现在提示符后面。这被称为命令历史。大多数 Linux 发行版默认记录最后 1000 条命令。按下下方向键，之前的命令就会消失。

### 光标移动

再次按下上方向键即可之前的之前的命令。如果我们尝试左和右方向键，我们会发现可以将光标放置在命令行的任何位置。这使得编辑命令变得简单。

### 关于鼠标和焦点的几句话

虽然 shell（壳）完全依赖键盘，但你也可以在终端模拟器上使用鼠标。X Window 系统（运行 GUI 的底层引擎）内置的一种机制支持快速复制粘贴技术。如果你通过按住鼠标左键并在文本上拖动鼠标（或双击某个单词）来选中某些文本，它就会复制到由 X 维护的缓冲区中。按下鼠标键会将文本粘贴到光标所在的位置。尝试一下吧。

不要在终端窗口中使用 `CTRL-C` 和 `CTRL-V` 来执行复制和粘贴。它们不起作用的。这些控制代码对 shell 来说有不同的含义，并且在微软 Windows 发布很多年前就已经被分配了。
