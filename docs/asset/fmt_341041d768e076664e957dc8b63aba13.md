# 创建 socket

在用户可以对 TCP/IP 栈执行任何操作之前，它通过调用 socket API 函数创建一个新的 socket。这些函数是通用的，不一定与 TCP/IP 关联，因此在调用任何代码之前发生了很多事情。socket 可以为 TCP/IP以外的许多协议类型创建。本节将描述当执行系统调用 `socket` 时，在内核内部发生了什么。
