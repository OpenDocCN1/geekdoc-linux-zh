# 调整文件系统

可能会出现这种情况：你想更改在最初创建文件系统时设置的一些参数。也许你想要更改 `minfree` 值以便在大硬盘驱动器上释放连续的磁盘空间。使用 `tunfs` 命令，你可以修改以下文件系统参数：

- - `maxcontig`
- `rotdelay`
- `maxbgpg`
- `minfree`
- `optimization`

`tunfs` 可以在几秒钟内破坏文件系统。

请参见表 7.1 的这些选项的描述。

`tunfs` 的语法如下：

```
tunfs [ -a <maxcontig> ] [ -d <rotdelay> ] [ -e <maxbgpg> ] [ -m <minfree> ] [ -o <value> ] special/filesystem
```
