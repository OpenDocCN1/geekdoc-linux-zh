
`GNOME` (GNU Network Object Model Environment) 是一组用户友好的应用程序和桌面工具，与 Windows 系统的管理器配合使用。`GNOME` 在目的和范围上与 `KDE` 类似，但 `GNOME` 完全基于自由软件。`gnome-core` 软件包包含了安装 `GNOME` 所需的基础程序和库。`GNOME` 为 `gnome` 桌面提供了核心图标和库。来自 `Mandrake 9.0 RPM`

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
