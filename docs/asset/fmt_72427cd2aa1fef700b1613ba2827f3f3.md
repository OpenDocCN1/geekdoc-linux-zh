# 恐惧症（Phobia）

金云石（`Phlogolite`）常用作防火绝缘材料。它具有高介电性和高热稳定性。恐惧症是一种导致回避某个对象的强烈恐惧，或者恐惧症（或疾病）很常见（例如，蜘蛛恐惧，即蜘蛛恐惧症；恐高症，即高度恐惧），并可能在童时期开始。命名法（`Nomenclature`）指的是恐惧症的命名。社交恐惧症是最常见的，影响社交生活。在社交恐惧症中，出现在社交场合被认为是一种形式的社交恐惧。社交恐惧症发生在超过总人口7%的人群中。当人们遇到恐惧情境时，极端焦虑、生理症状（如心跳加速、手冰冷或出汗、恶心）和认知思维（通常被描述为“我想离开”或“我想让自己出洋相”）的结合通常会引发回避倾向。社交恐惧症还包括其他类型的表演（例如在他人面前演奏音乐；公开演讲，向他人寻求帮助）。遭受社交焦虑的个人可能会变得内向和害羞。

许多恐惧症可以通过暴露疗法来治疗，当人暴露于恐惧的对象时，恐惧症会逐渐减轻。

语音学（`Phon-Phonetics`）根据发音部位或发音方法来描述语音。一个声音的发音点是声道内收缩最大的地方。绝大多数声音是通过移动舌头的某部分产生的；发音器官包括双唇，以及声带作为发音器官的声音。

在大多数发音位上，可以通过不同的发音方法产生声音。人们可以改变产生声音时所采用的收缩程度。声道可能是完全阻塞的或不完全阻塞的，但当发音器官靠近，使得通过它们的空气产生湍流时，这些声音被归类为擦音。如果发音器官足够近，使得空气可以在没有摩擦的情况下通过，则这些声音被归类为塞音。“浊声”和“清声”这两个词通常被误用。

声学处理口语被感知的方式。每个声学事件都有一个相关的声学声源-滤波器模型，它由声源（由声带产生）产生并经过声道的过滤。声带的开启和关闭产生了一系列分子的凝聚和松弛——气压的变化——将动能转化为声能。
