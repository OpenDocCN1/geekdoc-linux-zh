
虽然所有应用程序都是跨平台的，但 `WPS Writer` 的 Linux 版并没有得到与其 Microsoft 版同等的关注。这就是为什么你可能会在官方文档中找到某些问题的解决方案，但这些解决方案并不适用于 Linux 版。例如，官方帮助会告诉你如何使用邮件合并功能，但该功能在 Linux 上甚至不可用。

`OnlyOffice` 网站上的文档不多，除了涵盖安装和基本使用的说明外，你不会找到更多信息，但你可以在程序内部找到更多有用的信息。根据你运行的应用程序，点击“文件 > 帮助”会显示一个分类列表，如果你正在寻找特定内容，还有一个搜索栏。

相比之下，`Caligra` 的文档不存在。从程序内部启动手册会将你带到不存在的 KDE 手册页面。当你最终设法在 KDE Userbase 上找到一些文档时，它只列出了几个孤立的功能。幸运的是，你可以在官方论坛版块上利用用户社区获取建议和帮助。

`LibreOffice` 拥有详细的用户指南，可以从每个组件应用程序内部访问。除了其详尽的文档指南外，该项目还有一个名为 Ask LibreOffice 的问答网站。

## `LibreOffice` 10/10

这是最全面的套件之一，每个组件应用程序都拥有详细的文档，用户可以直接在应用程序内访问。

随着 6.0 版本的发布，该项目还引入了类似 *Microsoft Office* 的功能区界面，但它默认并未启用。不过，如果你喜欢功能区界面，`WPS Office` 的实现效果相当令人愉悦，但遗憾的是，*`LibreOffice`* 在这方面的表现却并非如此。

尽管使用简单，但我们对 *`LibreOffice`* 唯一的抱怨是它渲染大多数 `docx` 文件的效果非常糟糕。另一个常见的抱怨是它是一个资源占用大户，如果你正在运行一台配置较低、仅拥有约 2GB 内存的机器，那么选择其替代品可能会更合适。

但它通过提供数百种增强其功能扩展来弥补了这些不足，而在这一点上，*`LibreOffice`* 是无可匹敌的。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_116_0.png)

## `OnlyOffice` 8/10

在本次评测中，我们测试的是 *`OnlyOffice Desktop Editors`*，这是该办公套件的离线版本。此版本不提供诸如协作等许多实用功能。如果你想体验完整的功能集合，可以尝试各种云安装服务，它们均提供 30 天的免费试用。虽然这些云版本可能适合企业用户，甚至家庭办公（SoHo）环境，但对于家庭用户来说，它们价格昂贵且操作繁琐。

与其他拥有独立应用程序的套件不同，*`OnlyOffice`* 采用单一界面设计。你可以随时决定是处理演示文稿、电子表格还是文档，或者同时处理这三者，它们将在界面内的独立标签页中打开。

不过，对于基本家庭用户而言，*`Only Office`* 提供了你从最常见的三种生产力应用程序中期待的大部分常用功能。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_116_1.png)

## `WPS Office` 7/10

*`Only Office`* 和 *`WPS Office`* 仅提供电子表格、文字处理和演示程序，而其他套件还提供绘图应用程序或数据库管理工具。在这两者中，我们更喜欢 *`OnlyOffice`*，因为相比之下该项目更加成熟，而 `WPS Office` 能发布 Linux 版本已属幸运。

由于负责 Linux 版本的团队规模很小，我们不确定该项目在未来是否还能持续。此外，目前尚不清楚它何时（如果有的话）会引入其一些最佳功能，例如目前仅限于 Windows 版本的协作功能。

缺乏对 `ODF` 的支持也是一个令人失望之处，这可能会劝退许多开源纯粹主义者。但它的功能区实现令人印象深刻，我们甚至认为 *`LibreOffice`* 可以从 *`WPS Office`* 在这方面吸取经验。

## 其他工具

### 这些程序还能实现什么其他功能？

文字处理器、电子表格和演示文稿应用程序是办公套件中三个最常用的工具。我们为本次*汇总*选择的每个套件都提供其他应用程序。

*`Google Docs’ Forms`* 可用于快速创建一些最常见的表单，例如联系表、活动回复（RSVP）和派对邀请。模板提供了大量跨许多不同类别的常用选项，例如*个人、文字*（求职申请、活动反馈）和*教育*（评估、工作表）。你还可以使用 *`Google Drawings`* 创建流程图和思维导图，但不能用于艺术创作。

*`Calligra`* 提供了 *`Karbon`*，这是一个矢量图形绘制应用程序，但该工具已不再维护。如果你有兴趣使用图形化应用程序来构建数据库，可以尝试 *`Kexi. Calligra Plan`* 是一个项目管理工具，可用于管理即使是中等规模的项目。

与 *`Calligra’s Kexi, LibreOffice Base`* 一样，这是一个图形化数据库管理应用程序，类似于 *`Microsoft Access`*。`Base` 提供各种向导，帮助新手或甚至经验丰富的用户创建表、查询、表单和报告。它还包含预定义的表定义，用于跟踪资产、客户、销售订单和发票，以简化快速部署。它原生支持大多数广泛使用的数据库引擎，例如 *`MySQL、MS Access、PostgreSQL`* 和 *`Oracle`*。相比之下，*`Calligra’s Kexi`* 不支持 `MS Access`，且开发程度不如 *`Base`*。

与其他工具不同，*`WPS Office`* 和 *`OnlyOffice`* 仅具备三个基本组件，目前尚无消息称它们是否会提供绘图或数据库应用程序。

## 协作

当你需要分担工作量时，有哪些选择？

在线办公套件受欢迎的一个重要因素在于，它们允许多个用户协作并同时处理同一文档。虽然离线办公套件正在赶上，但这仍然是在线办公套件（如 `Google Docs`）主导的领域。

`Google Docs` 支持在 `Google` 文档、`Google` 表格、`Google` 幻灯片和 `Google` 绘图工具上进行实时的逐字符协作。当多人同时在同一文档上工作时，他们都能查看彼此所做的更改。这些协作选项与共享选项配合使用，可以设置文件的访问级别，从而让你控制谁可以查看和编辑你的文件。同样，与其他功能一样，你可以使用另一个 `Google` 服务 `Google` 群组，通过单击一次即可与一群人共享文档。

`LibreOffice Calc` 允许多个用户共享文档，并拥有同时写入权限。假设每个用户都在“工具”>“选项”下的 `LibreOffice` 用户数据页面上添加了姓名，那么跟踪不同用户所做的贡献将变得相当容易。

`Calligra Suite` 尚未实现类似功能，而且没有任何关于未来版本将引入此功能的说法。由于该项目的网站没有未来版本的路线图，因此无法预测何时（如果有的话）会引入此功能。

使用 `OnlyOffice` 时，你会收到视觉提示，告知你的协作者正在编辑的内容，并且你可以与他们交谈以讨论想法。但此功能在离线编辑器中不可用，你必须使用云功能才能访问它。
