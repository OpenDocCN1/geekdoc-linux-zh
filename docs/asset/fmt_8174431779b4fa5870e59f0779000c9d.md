# 23 Web 编程

Python 在构建网站时被广泛使用，并在其能力范围内承担着多种角色。首先，Python 脚本通常是简单生成一组静态 HTML 页面并由 Web 服务器交付的有用方法。例如，可以使用一个脚本来获取原始内容，并用你通常在网站上看到的额外功能（导航栏、侧边栏、广告、样式表）对其进行装饰。这主要只是文件处理和文本处理的问题——这些主题已经在书的其他章节中涵盖。

其次，Python 脚本用于生成动态内容。例如，一个网站可以使用 Apache 等标准 Web 服务器运行，但会使用 Python 脚本来动态处理各种请求。Python 的使用与表单处理特别相关。例如，一个 HTML 页面可能包含这样的表单：

```html

<FORM ACTION='/cgi-bin/subscribe.py' METHOD='GET'>

Your name: <INPUT type='text' name='name' size='30'>

Your email address: <INPUT type='text' name='email' size='30'>

<INPUT type='Submit' name='submit-button' value='Subscribe'>

</form>

```

在表单内部，有一个属性名为 `subscribe.py` 的 Python 脚本，它会在表单提交时在服务器上执行。

另一个涉及动态内容生成的常见场景是 AJAX（异步 JavaScript）。通过 AJAX，JavaScript 事件与页面上的 HTML 元素关联。例如，当鼠标悬停在元素上时，可能会执行 JavaScript 函数并向 Web 服务器发送 HTTP 请求，该请求会被处理（可能由 Python 脚本处理）。当收到相应的响应时，另一个 JavaScript 函数将执行以处理响应数据并显示结果。结果有很多返回方式。例如，服务器可以以纯文本、XML、JSON 或任何其他格式返回数据。有一个示例 HTML 文档说明如何实现一个悬停弹出鼠标，当移动到所选元素上时，会弹出一个窗口。

  var request = new XMLHttpRequest();

    if (request.readyState == 4 && request.status == 200) {

        popupcontent.innerHTML = request.responseText;

        popupbox.style.left = hoveritem.offsetLeft+10;

        popupbox.style.top = hoveritem.offsetTop+20;

        popup.style.visibility = "Visible";

  popup.style.visibility = "Hidden";
