## 相关的 Ubuntu 和 Linux 命令

以下命令帮助您管理打印服务：

- `accept`: 通过命令行控制打印作业对 CUPS 服务的访问
- `cancel`: 从命令行取消打印作业
- `cancel`: 命令行控制打印队列
- `disable`: 从命令行控制打印
- `enable`: 命令行控制 CUPS 打印机
- `lp`: 命令行控制打印机和打印服务
- `lpc`: 在控制台上显示打印机和打印服务的状态
- `lppq`: 在控制台上查看打印队列（悬待处理的打印作业）
- `lprm`: 通过命令行从打印机队列中删除打印作业
- `lpstat`: 显示打印机和服务器状态
- `system-config-printer`: Ubuntu 的图形化打印机配置工具
