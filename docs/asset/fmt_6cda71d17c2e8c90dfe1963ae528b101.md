
# load_policy

`load_policy [-qi]`

## NAME

`load_policy` - 将新的 SELinux 策略加载到内核

## DESCRIPTION

`policy` 将安装的策略文件加载到内核。现有的策略值在策略重载时会被保留，而不是重置为策略文件中的默认值。

## OPTIONS

`-q` 抑制警告消息。
`-i` 初始化加载。仅在首次加载时使用（通常由 `initfs` 调用）。

## EXIT STATUS

`0` 成功
`1` 参数无效
`2` 策略失败
`3` 请求初始化
