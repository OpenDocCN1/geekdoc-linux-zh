# shorewall

Shoreline 防墙 (`shorewall`)。Shoreline 防墙 (`shorewall`) 是一个用于扫描 NFS 服务器以显示共享/给谁的工具。此命令有两种基本形式：`showmount` 显示哪些机器登录到 NFS 服务器，`showmount -e` 显示哪些目录。此命令使用了 `rpc` 协议（`rpc` 程序 `100005`）。在大多数系统中，命令不需要验证，这意味着任何人都可以运行它们。无参数的命令等同于 `MOUNTPROG_DUMP` 程序，而 `-e` 选项等同于 `MOUNTEXPORT`。

# SHTTP (安全超文本传输协议)

世界维网超文本传输协议 (HTTP) 的扩展，支持 Web 上的安全商业交易。安全 HTTP 通过两种方式提供这种支持：向供应商确保尝试购买其商品的客户确实是其所声称的身份（身份验证），并加密敏感信息（如信用卡号），防止其在传输过程中被截获。安全 HTTP 由 Enterprise Integration Technology (EIT) 和国家超级计算机应用中心 (NCSA) 开发，随后由 Terisa 进行商业化开发。Netscape 开发了一种通信安全技术——套接层 (SSL) 协议。这两个协议不兼容，曾导致一段时间没有出现任何被广泛接受的安全协议。1995 年初，Netscape 大力注资了 Terisa Systems，并宣布将整合安全 HTTP 和 SSL，为 Web 社区提供一种可用于任何具备安全能力浏览器的单一安全协议。源自 QUEDIC

# shutdown

关闭系统。源自 http://www.tld.org/LDP/Linux-Dictionary/html/index.html

关闭系统。所有已登录的用户都会收到系统即将关闭的通知，并且 `login(1)` 将被阻塞。可以立即关闭系统，也可以在延迟后关闭。所有进程首先会通过 `SIGTERM` 信号通知系统即将关闭。这为 `vi(1)` 等程序留出了时间保存正在编辑的文件，为新闻程序提供了正常退出的机会。`Shutdown` 通过向进程信号请求其取消运行级别（`runlevel`）来完成工作。级别 `0` 用于停止系统，级别 `6` 用于重启系统，级别 `1` 用于将系统处于可以执行管理任务的状态。来自 Linux Guide @FirstLinux
