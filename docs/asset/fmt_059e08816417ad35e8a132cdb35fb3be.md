# `IndexIgnore` 是一组目录索引应该忽略且不包含在列表中的文件名。允许使用 Shell 风格的通配符

```
IndexIgnore ??* - # HEADER README RCS CVS *,v *t
```

# `AddEncoding` 允许某些浏览器（Mosaic/X 2.1+）动态解压缩信息。注意：并非所有浏览器都支持此功能。尽管名称相似，以下 `Add` 指令与上述 `FancyIndexing` 定制指令完全无关。

```
AddEncoding x-compress Z
AddEncoding x-gzip gz
```

# `AddLanguage` 允许你指定文档的语言。你可以使用内容协商为浏览器提供其可以理解的语言的文件。注意，后缀不必与语言关键词相同 --- 那些拥有有波兰语文档的站点（其网络标准语言代码为 `pl`）可能希望使用 "`AddLanguage .po`" 以避免与 `perl` 脚本的常用后缀产生歧义。

```
AddLanguage .en
AddLanguage fr .fr
AddLanguage de .de
AddLanguage da .da
AddLanguage el .el
AddLanguage it .it
```

# `LanguagePriority` 允许在内容协商发生冲突时给某些语言优先级。只需按偏好程度从高到低列出语言即可。

```
LanguagePriority en fr de
```

# `AddType` 允许你在无需实际编辑 `mime.types` 的情况下调整它，或将某些文件设置为特定类型。例如，`PHP3` （非 Apache 分发包含 - 访问 `http://www.php.net`）我们通常使用：

```
AddType application/x-httpd-php3 .php3
AddType application/x-httpd-php3-source .phps
```
