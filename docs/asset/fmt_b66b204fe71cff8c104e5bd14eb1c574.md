上述规则的另一种编写方式如行所示：

```
/bin/ls -> +pinugtsdrbamcmMSH-1 (Rename="OS Utilities", severity=100);
```

第一种方法更好，因为它可以将许多文件和目录归类到一个规则下。例如，下代码中列出的所有工具都属于同一策略：

```
SEC_CRIT = +pinugtsdrbamcmMSH-
(Rename="OS Utilities", severity=100)
{
/bin/ls -> $(SEC_CRIT);
/bin/login -> $(SEC_CRIT);
}
```
