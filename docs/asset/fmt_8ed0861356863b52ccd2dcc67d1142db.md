
无论如何，似乎如果我们按 HR 进行分层，我们就得到了得分（runs）与 BB 之间的二元分布。同样，如果我们按 BB 进行分层，我们就得到了 HR 与得分之间的二元正态分布近似。

## 19.2.2 多元回归

为每个分层计算回归线是常见的。我们本质上是在拟合如下直线：

> `E(R | BB = x_1, HR = x_2) = β₀ + β₁(x_2)x_1 + β₂(x_1)x_2`

其中对于 `$x_1$` 的斜率随 `$x_2$` 的不同值而变化，反之亦然。但是否有更简单的方法？

如果考虑到随机变异，分层中的斜率似乎并没有发生太大。如果这些斜率相同，则意味着 `β₁(x_2)` 和 `β₂(x_1)` 是常数。反过来意味着，给定 HR 和 BB 的得分期望可以写成：

> `E(R | BB = x_1, HR = x_2) = β₀ + β₁x₁ + β₂x₂`

该模型表明，如果 HR 数固定在 `$x_2$`，我们观察到得分与 BB 之间存在线性关系，截距为 `β₀ + β₂x2`。我们的探索性数据分析支持了这一点。模型还表明，随着 HR 数量的增加，截距线性增长并由 `β₁x₁` 良好确定。

在这种称为多元回归的分析中，你经常听到人们说 BB 斜率 `β₁` 经过了 HR 效应调整。如果模型是正确的，混杂已经得到了考虑。我们如何从数据中估计 `β₁` 和 `β₂`？通过此，我们学习线性模型和最小二估计。

## 19.3 最小二估计

我们已经描述了数据是如何二元正态的，然后条件期望遵循回归线。条件期望并不是额外的假设，而是一个推导结果。然而，在实践中，我们需要显式地写出一个使用线性模型描述两个或多个变量之间关系的模型。

我们注意到，“线性”并非仅指直线，而是指条件期望是已知数量的线性组合。在数学中，当我们将每个变量乘以一个常数然后相加时，我们就得到了变量的线性组合。`3x - 4y + 5z` 是 `x, y` 和 `z` 的线性组合。我们也可以添加一个常数，`2 + 3x - 4y + 5z` 同样是 `x, y` 和 `z` 的线性组合。

所以 `β₀ + β₁x₁ + β₂x₂` 是 `$x_1$` 和 `$x_2$` 的线性组合。最简单的线性模型是常数 `β₀`；第二简单的是线性 `β₀ + β₁x₁`。如果我们用加尔顿的数据预测 `$x_2$`，我们将观测到的身高标记为 `x₁, ..., xₙ`，那么预测 `n` 个儿子高度的模型即为：

> `$Y_i = β₀ + β₁x_i + ε_i, i = 1, ..., N$`.

### 19.3. 最小二估计

在这里 `x_i` 是父亲的身高，由于条件的限制，它是固定的（不是随机的），而 `Y_i` 是我们想要预测的随机儿子身高。我们进一步假设 `ε_i` 相互独立，期望值为 0，且标准差（称之为 `σ`）不依赖于 `i`。

在上述模型中，我们知道 `x_i`，但为了有一个用的预测模型，我们需要 `β₀` 和 `β₁`。我们从数据中估计这些值。一旦完成，我们就可以预测任何父亲身高 `x` 对应的儿子身高。我们将在下一节展示如何操作。

注意，如果进一步假设 `ε` 服从正态分布，该模型正是我们通过假设二元数据推导出的那个。一个细微的区别是，在我们的种方法中，我们假设数据是二元正态并推导出线性模型，而不是假设模型。在实践中，线性模型通常被直接假设而不假设正态性：`ε` 的分布并未指定。尽管如此，如果你的数据是二元正态的，上述线性模型就成立。如果你的数据不是二元正态的，你需要其他方法来证明该模型的合理性。

#### 19.3.1 解读线性模型

线性模型受欢迎的原因之一是它们具有可解释性。在加尔顿的数据中，我们可以这样解释数据：由于遗传基因的影响，父亲身高 `x` 每增加一个，儿子的身高就增加 `β₁`。因为并不是身高为 `x` 的父亲身高都相等，我们需要项 `ε` 来解释剩余的变异。这种剩余变异包含了母亲的遗传影响、环境因素和生物学随机性。

由于我们写了上述模型，截距 `β₀` 不怎么解释，因为它是没有父亲的儿子的预测身高。由于回归的影响，预测值会比 0 大。为了让斜率参数更具可解释性，我们可以稍微重写模型：

> `$Y_i = β₀ + β₁(x_i - \bar{x}) + ε_i, i = 1, ..., N$`

其中 `\bar{x}=1/N\sum_{i=1}^N x_i` 是 `x` 的平均值。在这种情况下 `β₀` 代表平均父亲的儿子身高。

#### 19.3.2 最小二估计 (LSE)

为了使线性模型有用，我们需要估计未知的 `β`。科学上的标准方法是找到使拟合模型与数据距离最小的值。以下是最小二 (LS) 方，我们将在本章看到：

> `$RSS = \sum_{i=1}^N (y_i - (β₀ + x₁x_2)$`

这个量被称为残差平方和 (RSS)。一旦有了 RSS，我们将调用最小二估计 (LSE) 并将其标记为 `β₀` 和 `β₁`。让我们用之前的数据集演示：

```r
library(HistData)

set.seed(123)

galton_height <- data("HistData") %>%

  filter(gender == "male") %>%

  group_by(family) %>%

  sample_n(1) %>%

  select(father, childHeight) %>%

  rename(son = childHeight)

rss <- function(beta0, beta1, data) {

  resid <- data$son - (beta0+beta1*data$father)

  return(sum(resid^2))

}
```

对于任何数值对，我们都会得到 RSS。当我们将 `β₀` 固定在 25 时，这里是 RSS 关于 `β₁` 的函数：

```r
beta1 <- seq(0, 1, len=row(galton_height))

results <- data.frame(beta1 = beta1,

  rss = sapply(beta1, rss, beta0 = 25))

ggplot(aes(beta1, rss)) + geom_line(aes(beta1, rss))
```

我们可以看到 `β₁` 在 0.65 附近有一个明显的最小值。然而，这个 `β₁` 最小值对应的 `β₀=25` 是任意选取的。我们不知道 `(25, 0.65)` 是否是使所有组合方程最小的。在这种情况下，尝试法是无效的。相反，我们使用微积分：求导数，将它们置为 0 并求解 `β₁`。当然，如果我们有很多参数，这些方程会变得复杂。但 R 中有函数为我们完成这些计算。我们将学习这些。要学习背后的数学原理，可以咨询线性模型的书籍。
