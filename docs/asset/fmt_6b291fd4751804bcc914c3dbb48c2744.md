## 项目 14C：图标（创建）

gThumb 非常像 iPhoto 的功能之一是我妈妈在运行 Linux 后询问的第一件事之一就是如何创建图标。你在第 7 章已经学习过处理图标，但由于我已经介绍了许多工具，现在可能是个好机会。

### 14C-1：使用现有图标作为图标

你可以使用任何图像作为图标的基础，但获取图标最简单的方法是使用系统图标。这种想法唯一的问题是大多数系统图标是 48x48 像素，而图标是 36x36 像素。如果你不想让图标看起来异常巨大且不协调，最好进行调整大小。

正如上一节所述，gThumb 对于调整大小非常有帮助。对于这个项目，我们将使用 `gnome-tiger` 图标，选择上方的下拉菜单并导航到 `/usr/share/pixmaps`。在那里选择“以列表查看”，然后双击它，接着进入“图像”菜单并“调整大小”。这将弹出缩放窗口（如图 14-8 所示），你可以在其中将宽度改为 36 像素（只要勾选了“保持比例”，高度会自动变化）。完成后，点击“缩放”。

现在你需要将新调整大小的图标保存到主目录，同时保留原始文件。要执行此操作，进入“文件”菜单并选择“另存为”，这将弹出保存窗口。将文件保存为主目录下的 `gnome-tiger-emblem.png`。你可以通过点击“保存到文件夹”字样旁边的下拉菜单按钮并导航到主目录来实现。完成后，点击“保存”。

### 14C-2：将新调整大小的图像添加到图标集合

一旦你有了尺寸合适的图像，现在就可以将其添加到系统的图标集合中了。要执行此操作，进入“编辑”菜单并选择“背景和图标”。当“背景和图标”窗口打开时，点击左侧的“图标”按钮，然后点击窗口底部的“添加新图标”按钮。这将弹出一个小的创建新图标窗口（如图 14-9 所示）。

在该窗口中，首先为你的图标命名。由于图像是老虎，我给它命名为 *Kitten Stuff*，但如果你愿意，也可以起其他名字。只需在“关键词”框中输入名称即可。

## 使用 GIMP 玩转艺术

Windows 和 Mac 世界可能有 Photoshop，但 Linux 世界有 GIMP。可以说，GIMP 的功能可能没有 Photoshop 那么强大，但它是一个很有竞争力的竞争者，这可能解释了为什么它被移植到了 Mac 和 Windows 上。GIMP 允许你创建位图图形，更重要的是，还可以修饰或完全修改图像文件。通过 GIMP，你可以消除数字照片中的红眼，用气刷涂掉不需要的阴影（甚至是面部瑕疵），查看画布纹理，将照片转换为油画，甚至在各处添加几粒辣椒——而且带有投影阴影（见图 14-11）。运行 GIMP，请进入**应用程序**（Applications）菜单，并选择**图形 > GIMP 图像编辑器**（Graphics > GIMP Image Editor）。

图 14-11：在 GIMP 中处理数字图像

## 使用 GIMP 调整图像大小和转换文件格式

与 gThumb 一样，GIMP 也是一个调整图像大小的方便工具。只需右键点击在 GIMP 中打开的图像并在弹出菜单中选择**图像 > 缩放图像**（Image > Scale Image）即可完成。这将弹出“缩放”窗口，你可以在其中设置图像的新尺寸。

GIMP 也是将图像从一种格式转换为另一种绝佳工具。例如，你可以转换位图 (`.bmp`) 文件并将其保存为 (`.png`) 文件，或者 JPEG (`.jpg`) 等。虽然也可以用 gThumb 完成此操作，但 GIMP 拥有广泛的文件格式，甚至允许你将图像文件保存为压缩文件，这使其成为真正的文件转换之王。

要执行文件转换，只需右键点击在 GIMP 内部打开的图像，然后在弹出菜单中选择**文件 > 另存为**（File > Save As）。如果你愿意，也可以从**文件**（File）菜单进行相同选择。无论何种方式，都会出现“保存图像”窗口。在该窗口中，你可以通过将顶部“名称”框中的原始文件扩展名替换为目标格式的扩展名来指定新文件格式。如果你不确定可用格式，点击“选择文件类型（按扩展名）”（Select File Type (By Extension））左的小箭头，然后从下方面板中的选项进行选择。要保存正在的工作，请使用 GIMP 原生的 `XCF` 格式，以便你以后继续处理图像。
