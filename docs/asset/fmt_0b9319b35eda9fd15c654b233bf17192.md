`open source` 名词。[常用；也可作形容词]；“开源”术语由 Mozilla 在 1998 年 3 月创造，用于描述在保证免费使用、修改和重新分发权利的许可下分发的源代码软件。其意图是通过避免“自由软件”一词的负面含义，帮助从事软件的黑客进入主流。关于这些策略及其后果的讨论，请参见开源倡议（Open Source Initiative）。来自术语词典（Jargon Dictionary）`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

`source` 由 Mozilla 在 1998 年 3 月创造的术语，用于描述在保证免费使用、修改和重新分发权利的许可下分发的源代码软件。其意图是通过避免“自由软件”一词的负面含义，帮助从事软件的黑客进入主流。来自《Linux 指南》（Linux Guide）@FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

Open Source Software 开源软件是指其编译代码对用户可见的软件，以便他们读取、修改并构建包含更改的新软件版本。有许多类型的开源软件，主要区别在于允许（或必须）重新分发（修改后的）副本的许可。来自 Matisse `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
