
`diffs [-C][-I][-c date-time][--rsid] -r sid diff-options (/usr/xpg4/bin/sccs)`

将用于编辑的文件检出工作副本与 SCCS 历史中的某个版本进行比较（差异比较）。默认使用最近的提交版本。`diff` 子命令接受 `diff` 相同的选项。

任何 `-r`, `-c`, `-i`, `-x`, 和 `-t` 选项都会传递给 `get` 命令。任何 `-i`, `-s`, `-e`, `-f`, `-h`, 和 `-b` 选项都会传递给 `diff` 命令。`-c` 选项将作为 `-ac` 传递给 `diff`。`-I` 选项将作为 `-i` 传递给 `diff`。

`-c date-time (/usr/ccs/bin/sccs)`

`-c date time | -c date-time (/usr/xpg4/bin/sccs)`

使用指定日期之前检查的最新版本进行比较。`date-time` 的格式为 `yy[[dd[hh[[mm[ss]]]]]]`。省略的部分默认为最大值；即，`-c7502` 等同于 `-c75022832599`。

`-rsid (/usr/ccs/bin/sccs)`

`-r sid | -rsid (/usr/xpg4/bin/sccs)`

使用与指定 delta 对应的版本进行比较。

### edit

检索用于编辑的文件版本。提取一个可写的文件版本；在历史文件所在的 SCCS 子目录中创建一个 `p.file`，以便其他人员无法提交或检出。以未展开的形式检索 ID 关键字。`.edit` 接受 `get` 相同的选项。ID 关键字列表及其定义请参见 `sccs-get(1)`。

### enter

与 `edit` 类似，但省略了最后的 `sccs`。如果你在初始化历史文件后立即执行 `sccs edit`，可以使用此子命令。

### fix -rsid (/usr/ccs/bin/sccs)

`fix -r sid | -rsid (/usr/xpg4/bin/sccs)`

修订一个（叶节点）delta。从 SCCS 历史中删除该 delta，在目录中留下当前版本的工作副本。此子命令用于合并不需要审计记录的微更新或修订 delta 注释。你必须在 `fix` 后跟随 `-r` 选项指定要删除的 `sid` delta。指定的 delta 必须是该分支中最近的（叶节点）delta。使用 `fix` 要小心，因为它不会留下差异的审计轨迹（尽管历史文件中保留了之前的注释）。

# sccs

# 1157

`info [-b][-u[username]] (/usr/ccs/bin/sccs)`

`info [-b][-u [username]] [-U] (/usr/xpg4/bin/sccs)`

- 显示正在编辑的文件列表，包括检出的版本号、要提交的版本号、持有锁的用户名称，以及文件检出的日期和时间。
- `-b` 忽略分支。
- `-u[username] (/usr/ccs/bin/sccs)`
- `-u [username] -U (usr/xpg4/bin/sccs)`

仅列出由你检出的文件。当你指定 `uselist` 时，仅列出你检出的文件。对于 `/usr/xpg4/bin/sccs`，`-U` 选项启用为 `-u` 当前用户。

`print` 打印每个命名文件的完整历史。使用 `sccs prs -e` 后紧接 `sccs get -p -m`。

`prs [-el][-c date-time][-rsid] (/usr/ccs/bin/sccs)`

`prs [-el][-c date-time][-r sid |rsid] (/usr/xpg4/bin/sccs)`

浏览（显示）delta 表或 `sccs` 文件的其他部分。`sccs-prs(1)`。
- `-e` 显示比 `-r` 指定的更早的所有 delta 的 delta 表信息（若未指定，则显示所有 delta）。
- `-l` 显示由 `-c` 或 `-r` 指定之后并包含的所有 delta 信息。
- `-c date-time (/usr/ccs/bin/sccs)`
- `-c date-time |` 指定指定日期和时间之前提交的最新 delta。`date-time` 参数格式为 `yy[[mm[[ss]]]]`.
- `-rsid (/usr/ccs/bin/sccs)`
- `-r sid |-rsid (/usr/xpg4/bin/sccs)`

通过 `sid` 指定特定的 delta。

`prt [-y]` 显示 delta 表，但省略 MR 字段（关于该字段的更多信息参见 `sccs-file(4)`）。参见 `sccs-prt(1)`。
- `-y` 显示最近的 delta 表项。每个文件参数对应单行输出；这种格式便于在管道中配合 `awk(1)` 或 `sed(1)` 使用。

# SCCS

# 1158

`rmdel -rsid (/usr/ccs/bin/sccs)`

`rmdel -r sid (/usr/x4/bin/sccs)`

从历史文件中删除指定的 delta。该 delta 必须是该分支中最近的（叶节点）delta。参见 `sccs-rmdel(1)`。

`sact` 显示 SCCS 文件的编辑活动。参见 `sccs-sact(1)`。

`ccsdiff -r old-sid -r new-sid`

使用 `diff` 比较两个 `sid` 对应的版本。参见 `ccsdiff(1)`。

`tell [-b][-u[username]] (/usr/ccs/bin/sccs)`

`tell [-b][-u[username]] | -U (/usr/xpg4/bin/sccs)`

显示当前检出的文件列表，每行一个。
- `-b` 忽略分支。
- `-u[username] (/usr/ccs/bin/sccs)`
- `-u [username] | -U (/usr/xpg4/bin/sccs)`

仅列出你检出的文件。当你指定 `username` 时，仅列出该用户检出的文件。对于 `/usr/xpg4/bin/sccs`，`-U` 选项等同于 `-u` 当前用户。

撤销上次编辑或 `-e`，并将工作副本恢复到之前的状态。`unget` 自检出以来所有的更改。参见 `sccs-unget(1)`。

`val` 历史文件。参见 `val(1)`。

`what` 显示二进制（对象）或文本文件中展开的 ID 字符串。参见 `what(1)`。

## 示例

以下示例检出一个文件，进行编辑，然后再次提交。

```
castle% sccs edit program.c
1.1
new delta 1.2
castle% vi program.c
your editing session
castle% sccs edit program.c
comments
1.2
3 inserted
2 deleted
12 unchanged
```

以下示例定义了根路径。

```
castle% sccs -d/src/include stdio.h
/usr/ccs/bin/src/include/SCCS/stdio.h
```

以下示例重定义了私有目录。

```
castle% sccs -private include/stdio.h
/usr/ccs/bin/private
```

以下示例为名为 `program.c` 的源文件初始化历史文件，创建 SCCS 子目录，然后使用 `sccs create` 创建历史文件。

```
castle% mkdir SCCS
castle% sccs create program.c
program.c:
1.1
14 lines
```

验证工作副本后，可以删除以逗号开头的备份文件，如下所示。

```
castle% diff program.c ,program.c
castle% rm ,program.c
```

以下两个示例从另一个目录检索文件到当前目录。

```
castle% sccs get /src/sccs/cc.cc
castle% sccs -p/src/sccs/
```

以下示例检出当前目录 SCCS 下的文件。

```
castle% sccs edit SCCS
```

以下示例提交所有当前检出的文件。

```
castle% sccs delta `sccs tell -u`
```

# 1160

`PROJECTDIR`

指定 SCCS 用于历史文件的绝对路径名（以斜杠开头）。如果 `PROJECTDIR` 不以斜杠开头，则将其视为用户名，并在用户家目录的 `src` 子目录中搜索历史文件。如果 SCCS 找到了该目录，则使用它。否则，使用该值作为相对路径。
