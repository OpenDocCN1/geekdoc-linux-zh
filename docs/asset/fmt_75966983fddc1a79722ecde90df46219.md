
# 第 10 章. 升级 Linux 及其他应用程序

请注意，目前内核开发有两个“流”——其中一个流被认为是“稳定”发布版，而另一个流被认为是“开发”发布版。对于像 Internet 服务器这样的关键任务应用程序，强烈建议你使用稳定版并远离开发内核。

这两个流之间的区别在于，在开发内核中，会定期引入新的但未经测试的硬件驱动程序、文件系统和其他“前沿”开发成果。这些内核仅供黑客使用——那些不介意在内核 bug 现出丑陋面目时重启系统的人。

稳定内核只在经过彻底测试后才会引入新功能和驱动程序。该流中的次要版本还起到清理任何发现并纠正的剩余漏洞。

这两个流使用的版本号编号方式不同，有助于区分它们。内核的版本号第二个数字是偶数，例如 `2.0.35`、`2.0.36`、`2.2.4`，而开发内核的版本号第二个数字是奇数，例如 `2.1.120`、`2.1.121`、`2.3.0`。

最新的稳定内核始终会在 `/ftp/redhat.com/redhat/updates/` FTP 站点以源码或预编译二进制格式提供。下载适用于你的版本和平台的所需内核包，例如，你需要导航到 `"/6.1/138"`。

> 注意：除非绝对必要，否则我真的建议避免 tar 包，如果可以的话坚持使用 RPM。

更糟糕的是，无意中覆盖了现有文件。

一旦 tar 包（tarball）安装到相应的目录，你几乎肯定会在新安装的文件中找到一个 `README` 或 `INSTALL` 文件，其中包含有关如何准备软件软件包以供使用的进一步说明。你可能需要输入类似于下面示例的命令：

```
./configure
make
make install
```

上述命令将配置软件，以确保你的系统具有必要的功能和库来成功编译该软件包，将所有源文件编译为可执行的二进制文件，然后将二进制文件和任何支持文件安装到适当的位置。当然，你需要遵循的实际步骤可能会随不同的软件包而异，因此你应该仔细阅读每份文档。

再次，除非绝对必要，我真的建议避免使用 tar 包，如果可以的话坚持使用 RPM。

## 10.3. 保持系统更新的策略

你偶尔会听到来自各种来源的 Linux 内核或用户应用程序的重大升级。这些来源可能是杂志、新闻组、网页等。

Linux 管理员应该——不，是**必须**关注的最好的单一在线资源可能就是 `http://freshmeat.net/` 网站。该网站包含了对新的开源应用程序和项目的描述、文档以及其他 Linux 社区感兴趣的公告。

另一个跟踪新应用程序公告的资源是通过 `comp.os.linux.announce` 新闻组。该新闻组包含了适用于 Linux 的新应用程序、某些内核或应用程序升级、网页等帖子。这是一个受管理（moderated）的新组，因此具有较高的“信噪比”。

然而，并非所有的产品升级公告都会发布在 `comp.os.linux.announce`。因此，访问你正在使用的应用程序的网页或 FTP 站点可能也是一个非常好的主意。

## 10.4. Linux 内核升级

偶尔升级你的 Linux 内核可能是明智的。这将允许你在新功能和错误修复出现时跟上它们的节奏。或者，也许你可能正在新型或特殊硬件上运行 Linux，或者希望启用某些需要自定义内核的特性。

本节将描述新内核的升级和定制。这并不像你想象的那么困难！

新内核版本的公告可以通过多种来源获取，包括 `comp.os.linux.announce` 新闻组，以及 `http://freshmeat.net/` 和 `http://slashdot.org/` 网站。

## 10.5. 升级 Red Hat 标准内核

升级内核最简单的方法是使用 Red Hat 提供的标准包。这种方法非常简单且几乎没有风险。只需以 root 身份执行以下命令序列：

```
rpm -Uvh kernel-2.0.36
cd /boot
```

记下 `ls` 命令显示的内核名称。现在，使用编辑器编辑 `/etc/lilo.conf`，并将 `image=` 行指向新内核。完成后，执行 `/sbin/lilo`。如果 LILO 报告错误，请检查 `boot/` 目录的文件。

> 注意：不要忘记这一步！

在更新引导加载器信息后，你应该可以使用新内核关闭系统（见 6.7 节）。

## 10.6. 构建自定义内核

如果你在特殊硬件上运行 Linux，或者希望使用标准内核不支持的特性，又或者你希望减少内核占用以更好地利用系统内存，你可能需要构建自己的自定义内核。

升级内核涉及配置模块、编译内核，最后安装内核。随后是系统重启（祝好运！）。所有这些都记录在内核自带的 `README` 文件中。此外可以在 `Documentation/` 目录中找到。其中一个特别有用的文件是 `Configure.help`，它包含了可用编译选项和模块的详细信息。
