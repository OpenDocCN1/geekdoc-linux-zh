# 引言

我想给你们讲一个故事。不，不是关于在 1991 年 `Linus Torvalds` 如何编写出 Linux 内核第一个版本的故事。你可以在很多 Linux 书中读到那个故事。我也不打算给你们讲在几年前，Richard Stallman 如何启动 `GNU` 项目以创建一个自由的 Unix 类操作系统的故事。那也是一个重要的故事，但大多数其他 Linux 书也都包含了它。

不，我想给你们讲的是关于你如何重新夺回对电脑的控制权的故事。

当我 20 世纪 70 年代后期作为一名大学生开始接触计算机工作时，一场革命正在发生。微处理器的发明让像你这样的普通人实际上拥有计算机成为可能。对于许多人来说，很难想象在只有大企业和政府运行所有计算机时，世界是什么样子的。只能说，那时候你什么也做不了。

今天，世界已大不相同。计算机无处不在，从微小的手表到巨大的数据中心，再到其间一切。除了无处不在的计算机，我们还拥有无处不在的网络将它们连接在一起。这创造了一个奇妙的个人赋能和创作自由的新时代，在过去的几十年里发生了一些事情。一些公司一直在对世界上大多数计算机实施控制，并决定你对它们可以做什么和不能做什么。坦率地说，世界各地的人都在为此行动。他们正在通过编写自己的软件来维护对计算机的控制权。他们正在构建 Linux。

许多人在提到 Linux 时会“自由”，但我认为大多数人并不知道这种自由意味着什么。自由是决定你的计算机做什么的权力，而拥有这种自由的唯一方法是知道你的计算机正在做什么。自由没有任何秘密的计算机，只要你足够用心寻找，一切都是可感知的。

## 为什么要使用命令行？

你是否注意到在电影里，当“超级黑客”——你懂的，那个能在 30 秒内闯入极其安全的军事计算机的家伙——坐在电脑前时，他从未碰过鼠标？因为电影制作者意识到，作为人类，本能知道从计算机上获取任何内容的唯一方法是通过键盘打字？

如今的大多数计算机用户都熟悉*用户界面（GUI）*，并被供应商和评论家告诉，*命令行界面（CLI）*是过去的一种可怕事物。这很遗憾，因为一个良好的命令行界面是与计算机通信的一种极具表现力的方式，正如文字之于人类一样。人们说“图形化界面让任务变得简单，而命令行界面让任务变得困难”，这在今天仍然非常真实。

由于 Linux 是模仿 Unix 操作系统族的建模的，它与 Unix 共享了相同的命令行工具传统。Unix 在 20 世纪 80 年代初脱颖而出（尽管它在十年前就被首次开发），在图形化界面被广泛采用之前，因此它开发了广泛的命令行界面。事实上，Linux 早期采用者选择它而不是 `Windows NT` 的最有力理由之一，就是那个强大的命令行界面，它让“困难的任务变得可能”。

## 本书关于什么

这本书是关于在 Linux 命令行中“生活”的宽泛概述。与某些集中于单一程序（如 shell 程序 `bash`）的书不同，这本书将尝试传达如何在更广泛的意义上与命令行界面相处。这一切是如何运作的？它能做什么？使用它的最好方法是什么？

**这不是一本关于 Linux 系统管理的书。** 任何对命令行的严肃讨论不可避免地会导致系统管理的话题，这本书仅触及了少数管理问题。然而，它将通过提供命令行使用的坚实基础为读者的额外学习做准备，而命令行是任何严肃系统管理任务的必备工具。

**本书以 Linux 为中心。** 许多其他书籍试图通过包含其他平台（如通用 Unix 和 macOS）来扩大它们的吸引力。这样做时，它们“稀释”了内容，只介绍通用主题。相反，本书仅涵盖现代的 Linux 发行版。95% 的内容对其他 Unix 类系统的用户是有用的，但这本书是高度针对现代 Linux 命令命令行。

## 谁应该读这本书

这本书是给从其他平台迁移的新用户的。大多数像你这样是某个版本 `Microsoft Windows` 的“高级用户”。也许你的老板告诉过你要管理一台 Linux，或者你正在进入单板计算机（`SBC`，如树莓派）这一令人兴奋的新世界。你可能只是一个厌倦了所有安全问题并想尝试 Linux 的桌面用户。这没关系。这里欢迎这里所有人。
