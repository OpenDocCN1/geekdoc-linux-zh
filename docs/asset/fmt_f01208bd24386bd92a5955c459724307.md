# 免费软件

Solaris 8 版本包含以下免费工具和类库：

- `bash`——兼容 shell 的语言解释器。
- `bzip2`——块排序压缩器。
- `patch`——将补丁应用于原始文件。
- `gzip`——GNU 压缩命令。
- `less`——类似于 more 的分页器。
- `libz`——也称为 zlib，一个执行压缩的类库，遵循 RFC 1950。
- `mkisofs`——使用 iso 格式构建 iso 文件系统。
- `rpmcpio`——将 RPM 格式（Red Hat 包管理器）转换为 cpio 归档。
- `tcsh`——具有文件补全和命令行编辑功能的 shell。
- `zip`——文件打包命令。
- `zsh`——作为交互式 shell 和脚本处理器的解释器。
