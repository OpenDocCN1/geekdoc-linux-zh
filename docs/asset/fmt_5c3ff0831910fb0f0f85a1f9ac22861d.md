
# Zope 产品 (Zope Products)
Zope 产品是用 Python 编写的发行版，可以安装在 Zope 服务器上。安装产品后，可以在 Zope 服务器上创建具有该产品实现的功能的对象。

# Zope 版本 (Zope Versions)
Zope 版本允许你在不同版本的项目上进行工作，而不会在开发过程中影响该产品的运行版本。
