### 10.2.2 将 time_t 转换为分解时间

`gmtime()`和`localtime()`函数将`time_t`值转换为分解时间（broken-down time）。分解时间被放置在返回的静态分配结构中。

```c
#include <time.h>

struct tm *gmtime(const time_t *time);

struct tm *localtime(const time_t *time);
```

返回指向静态分配的分解时间结构的指针，出错时返回`NULL`

`gmtime()`函数将日历时间转换为对应UTC的分解时间（字母源自格林威治时间）。相比之下，`localtime()`考虑时区和夏令时设置，返回对应系统本地时间的分解时间。这些函数的重入版本提供了`gmtime_r()`和`localtime_r()`。这些函数返回的`tm`结构包含了分解为部分的日期时间。该结构的格式如下：

```c
struct tm {
  int tm_sec;    /* 秒 (0-60) */
  int tm_min;    /* 分钟 (0-59) */
  int tm_hour;   /* 小时 (0-23) */
  int tm_mday;   /* 日 (1-31) */
  int tm_mon;    /* 月 (0-11) */
  int tm_year;   /* 自 1900 年起的年份 */
  int tm_wday;   /* 星期 (0-6) */
  int tm_yday;   /* 一年中的第 (0-365) */
  int tm_dst;    /* 夏令时标志
    > 0: 夏令时生效
    = 0: 夏令时未生效
    < 0: 夏令时不可用
};
```

`mktime()`在执行翻译时使用时区设置。此外，夏令时设置可能不被使用，取决于输入`isdst`字段的值：

`mktime()`函数将以本地时间表示的分解时间转换为`time_t`值，并作为结果返回。这些字段中的第一个`long int tm_toff`包含时间位于UTC东部的秒数。第二个字段`const char *tm_zone`是缩写名称（例如中欧夏令时的CEST）。SUSv3未指定这些字段中的任何一个，它们仅出现在少数派生版本中。

```c
#include <time.h>

time_t mktime(struct tm *timeptr);
```

返回与`timeptr`对应的自Epoch纪以来的秒数

未成功或出错时返回`(time_t) -1`

`mktime()`函数可能会修改`timeptr`指向的结构。此外，它并不要求结构的其他字段限制在所描述的范围内。至少，它确保`tm_wday`和`tm_yday`字段被设置为与其他输入字段对应的值。对于每个值超出范围的字段，`mktime()`都会调整字段的值使其在范围内，并对其他字段进行相应调整。所有调整都在`mktime()`计算返回的`time_t`值之前完成。

例如，如果输入`sec`字段为123，那么在返回时，该字段的值将变为3，`tm_min`字段将在原有值的基础上加2。（如果此加法导致`tm_min`溢出，则`tm_min`值将通过调整，`tm_hour`字段将增加，依此类推。）这些调整甚至适用于负字段值。例如，为`tm_sec`指定-1意味着上一分钟的第59秒。此功能非常有用，因为它允许我们对分解时间值进行日期和时间算术运算。

190 第10章

`mktime()`执行翻译时使用时区设置。此外，夏令时设置可能不被使用，取决于输入`isdst`字段的值：

- 如果`tm_isdst`为0，将其视为标准时间（即忽略夏令时，即使在一年中的该时期生效）。
- 如果`tm_isdst`大于0，将其视为夏令时（即假定夏令时生效，即使在一年中的该时期通常不）。
- 如果`tm_isdst`小于0，尝试确定一年中的该时期是否生效夏令时。这通常是我们希望的设置。

在完成时（无论初始`tm_isdst`设置如何），如果给定日期夏令时生效，`mktime()`将`tm_isdst`字段设置为一个正值；如果不生效，则设置为0。

## 2.2.3 在分解时间与可打印格式之间进行转换
