
# Easy Diffusion

```ini
[Desktop Entry]
Name=Easy Diffusion
Comment=Easy Diffusion
Exec=./Downloads/easy-diffusion/start.sh
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

要保存更改，点击“保存”按钮，或通过“文件”选择“保存”，或者点击 `≡` 图标选择“另存”。完成后，退出编辑器。

请确保 `Exec=` 路径正确指向 Easy Diffusion 可执行文件在系统中的位置。

```bash
./start_linux.sh

```

后一个命令用于更新上述软件。

# oobabooga (Text Generation GUI)

`oobabooga (Text Generation GUI)` `.desktop` 快捷方式通过 GUI 创建：

要为 `oobabooga (Text Generation GUI)` 创建桌面快捷方式，请打开终端并输入以下命令：

```bash
cd /usr/share/applications
sudo gedit oobabooga1.desktop
```

接下来，使用以下内容更新 `oobabooga1.desktop` 文件：

```ini
[Desktop Entry]
Name=oobabooga (Text Generation GUI)
Comment=oobabooga (Text Generation GUI)
Exec=./Downloads/text-generation-webui-main/update_linux.sh
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

保存你的更改。

请确保 `Exec=` 路径正确指向你系统上 `oobabooga (Text Generation GUI)` 可执行文件的位置。

## Upscayl

访问 Upscayl 官方网站 `https://www.upscayl.org/` 获取所有关于 Upscayl 的信息。

### 通过软件管理器安装 DEB/FLATPAK 软件包

- 打开软件管理器并搜索 `Upscayl`。
- 点击 `Upscayl`，然后点击源选择框。
- 选择系统包 (`System Package`) 或 `Flatpak` 并点击安装。

### 通过 Snap Store 安装 Snap 软件包

- 在 `Snap Store` 中搜索 `Upscail`。
- 点击 `Upscail`，然后点击源选择框。
- 选择 `Snap` 下的最新/稳定版本并点击安装。

### 通过终端通过 Snap 安装 Upscail

输入此命令：

```bash
sudo snap install upscail
```

### 通过终端通过 Flatpak 安装 Upscail

输入此命令：

```bash
flatpak install flathub org.upscail.Upscail
```
