
将文件名的时间改为当前时间。如果文件不存在，则创建一个空文件。你可以使用 `touch -t 20020131759` 修改日期。每个文件都有三个时间值：

- 最后访问时间 (`atime`)
- 最后修改时间 (`mtime`)
- 最后更改时间 (`ctime`)

`touch` 将前两个和最后一个改为当前时间。它们可以使用 `stat` 命令读取（所谓的 inode）。

```
stat filename
```

打印关于文件的通用信息（所谓的 inode）。

```
strings filename
```

```
od -c filename
```

## `wc`

`wc`（单词计数）打印文件的行数、单词数和字节数。

示例：

```
dir | wc
cat myfile | wc
wc myfile
```

## `cksum`

为文件名计算 CRC（循环冗余校验）以验证其完整性。

## `md5sum`

为文件名计算 `md5` 校验和（128 位）以验证其完整性。

## `mkpasswd`

`mkpasswd -l 10` 创建一个长度为 10 字符、难以猜测的随机密码。

```

```

在公共字段上连接两个文件的行。`join` 类似于数据库操作“连接表”，但它作用于文本表。默认在第一个表的第一个字段上连接，默认分隔符是空白。要调整数据，我使用通过 `man join` 找到的选项。
例如，如果 `file1` 的内容为：

+   1 Barbara
2 Peter
3 Stan
4 Marie

而 `file2` 的内容为：

+   2 Dog
4 Car

生成的 `file3` 将是：

+   2 Peter Dog

```
gpg
```

"Gnu Privacy Guard"—`PGP`（"Pretty Good Privacy"）的免费替代品。`gpg` 比 `PGP` 更安全且不使用专利算法，`gpg` 主要用于对你的电子邮件签名以及检查他人的签名。你也可以用它来加密/解密消息。
`http://www.gpg.org` 包含了所有细节，包括一份易读且详细的手册。

要开始，一对密钥：私钥和公钥。私钥用于对我的消息签名。你发出的公钥其他人可以用它验证我的签名。[也可以使用公钥来加密消息，以便使用我的私钥进行读取。] 我使用以下命令生成了密钥对：

```
gpg --gen-key
```

我的密钥存储在目录中（用我在生成密钥期间提供的密码加密）。要以纯文本形式列出我的公钥，我使用：

```
gpg --armor --export my email address > public_key.stan
```

这创建了一个包含类似内容的 `public_key.stan` 文件，如下：

```
-----BEGIN PGP PUBLIC KEY BLOCK----
```
