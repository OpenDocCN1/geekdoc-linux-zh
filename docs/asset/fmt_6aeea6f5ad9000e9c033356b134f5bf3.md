# exit

```

# 第三部分：库函数

```

## 描述

`exp()` 函数返回 `$e$`（自然对数的底）的 `$x$` 次方值。

- `pow()` 函数可能返回以下错误：
  - `EDOM`: 参数 `$x$` 为负数且 `$y$` 不是整数值。这将导致复数。
