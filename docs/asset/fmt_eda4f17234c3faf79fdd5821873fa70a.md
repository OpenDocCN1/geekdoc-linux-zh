## D.3 标准错误函数

我们定义了一组在全文处理错误状况的函数。使用这些错误函数的目的是让我们用一行 C 代码编写错误处理，例如：

```c
if(error)
    err_sys(printf any number of arguments);
```

而不是：

```c
if(error) {
    char buff[];
    snprintf(buff, sizeof(buff), printf any number of arguments);
    perror(buff);
    exit (1);
}
```
