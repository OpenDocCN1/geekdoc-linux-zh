## 逻辑卷脚本

在查看连接到系统的物理磁盘后，查看一些逻辑卷的摘要信息（包括分配给逻辑卷的物理磁盘）将会非常有帮助。以下名为 `audlysum.sh` 的脚本提供了系统上逻辑卷的简要总结。

```
#!/usr/bin/ksh
USAGE=Usage: [-d]
VOLORDER='y'      # 默认按逻辑卷排序
                   - n = 按磁盘排序

while (( $# > 0 ));
do
    case "$1" in
        -d) VOLORDER='n'
           ;;
        *) echo未识别 option: "$1"
           echo $USAGE
           exit 1 ;;
    esac
    shift
done

if [ "$VOLORDER" = "y" ];  # 根据命令行选项确定排序顺序
then
    FISH=sort
else
    FISH=cat
fi

# 用于使输出对齐更好的宽度指定符
# LVINFO = LV + USE + 6
# DISINFO = HW + ID + 8
typeset -L28 LVINFO
typeset -L18 LV
typeset -L20 DISINFO
typeset -L10 ID
typeset -L12 HW
typeset -R9 SZ
typeset -R4 USE FREE

ioscan -f|grep - disk -e ext_bus|awk '{print "$1" "$2" "$3"}'|while read LINE
do set $LINE
Ty="$1"
```
