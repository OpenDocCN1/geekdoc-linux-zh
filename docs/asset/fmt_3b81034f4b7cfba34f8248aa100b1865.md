```bash
$ log2timeline -f pcap -z UTC jackr-challenge.pcap -w pcap.body
```

数据生成后，你可以轻松地合并与每个主机相关的时间线，并开始调查中针对特定主机的初步组件：

```bash
$ cat ENG*.REG/ENG*.body >> ENG_all

```
