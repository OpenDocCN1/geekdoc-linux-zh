
### copy-on-write（写时复制）
一种技术，维护对公共对象的多个引用，直到该对象被修改（写入）为止。在对象被写入之前，会创建一个副本；修改是在副本上进行的，而不是原始对象上。在虚拟内存管理中，写时复制是内核用于管理多个进程共享页的常用方案。映射共享页的所有页表项均被设置为：对该页的首次引用会导致页错误。当处理页错误时，发生故障的页将被替换为一个私有副本，该副本是可写的。

### core file（核心转储文件）
系统向进程传递某些信号时创建的文件（名为 core）。该文件包含了信号发生时进程状态的记录。该记录包括进程虚拟地址空间的内容，在大多数系统中，还包括用户结构（user structure）。

### CPU（中央处理器）
参见 central processing（中央处理），意外的系统故障。

### crash（崩溃）
机器崩溃时机器状态的记录。该记录通常写入次级存储器上被认为是安全的地方，以便能够被保存直到信息被恢复为止。

### CRT（阴极射线管）
参见 cathode tube（阴极管）。

### current working directory（当前工作目录）
进程解释相对路径名的起始目录。进程的当前工作目录通过 `chdir` 或 `fchdir` 磁盘系统设置。

### cylinder（柱面）
磁盘上从磁头组件的一个位置可以访问的磁道。

### cylinder group（柱面组）
在文件系统中，磁盘驱动器上为了局部化信息而分组在一起的一组柱面。也就是说，文件系统按柱面组为基础分配索引块（blocks）。

### daemon（守护进程）
一个提供系统相关服务的长存进程。有在内核模式下执行的守护进程（例如 `pagedaemon`），也有在用户模式下执行的守护进程（例如 `routing daemon`）。旧英语术语 `daemon` 意为“被神化的生物”，区别于意为“恶魔”的术语 demon。

### DARPA（美国高级研究计划署）
美国国防的一个机构，负责研究。

### datagram（数据报）
一种可能不可靠的通信的套接字类型。

### data segment（数据段）
进程地址空间中被初始化的部分的段，在数据被修改时使用。另参见 `text segment`（文本段）。

### decapsulation（解封装）
在网络通信中移除消息的最外头部。封装（encapsulation）的反向过程。

### demand paging（按需分页）
一种内存管理技术，内存被分为页并根据需要提供。另参见 pure demand paging（纯按需分页）。

### demon（恶魔）
参见 daemon。

### descriptor（描述符）
创建文件或套接字时由系统分配的整数。描述符可以通过 `dup` 和 `fctl` 系统调用进行复制。

### descriptor table（描述符表）
每个进程持有 I/O 对象的表。I/O 描述符是该表的索引。

### device（设备）
在 UNIX 中，连接到 CPU 的外设。

### device driver（设备驱动程序）
内核的一部分，支持访问外设设备的模块。

### device flags（设备标志）
在系统配置文件指定并传递给设备驱动程序。设备驱动程序中使用这些标志。终端设备驱动程序使用这些标志指示哪些终端应忽略控制信号。

### device number（设备号）
在块设备或字符设备类中唯一标识设备的数字。设备号由两部分组成：主设备号（major number）和小设备号（minor number）。

### device special（特殊设备）
进程通过其访问机器设备的文件。例如，带带通过此类文件访问。

### directed broadcast（定向广播）
在一个发送者未直接连接的网络上进行广播的消息。

### direct memory access (DMA)（直接内存访问）
一种外设无需 CPU 协助即可访问主内存的机制。DMA 通常用于在主内存和外设之间传输连续块。

### directory（目录）
在 UNIX 中，一种特殊文件类型，包含指向其他文件的条目。按照约定，目录至少包含两个条目：`(.)` 和 `..`。`(.)` 指向目录本身；`..` 指向父目录。

### directory entry（目录项）
目录文件中由变长记录结构表示条目。每个结构包含一个表示文件名的 ASCII 字符串、为字符串提供的空间字节数、条目提供的空间字节数、条目引用的文件类型以及与文件名关联的 inode 号。按照约定，inode 编号为 0 的目录被视为未分配，条目占用的空间可用。

### dirty（脏的）
在计算机系统中，系统通常跟踪对象是否被修改——是否为“脏”，因为它在重用对象占用的空间之前需要保存对象的内容。例如，在文件系统中，文件缓存中的缓冲区如果内容被修改，则它是脏的。脏缓冲区在重用之前写回磁盘。

### disk partition（磁盘分区）
磁盘驱动器上的连续区域，用作交换区或存放文件系统。

### distributed program（分布式程序）
一个被划分到多个进程中的程序，可能跨越多台机器。

# 术语表

DMA *参见内存访问。*

双间接块 *参见间接块。*

有效 GID *参见有效组标识符。*

有效组标识符 (effective GID) groups 数组中的第一个条。有效 UID连同 groups 数组中的其他 GID，被文件系统用于检查组访问权限。在执行设置组标识符（set-group-identifier）程序时设置有效 GID。另参见组标识符；真实组标识符；保存组标识符。

有效 UID *参见有效用户标识符。*

有效用户标识符 (effective UID) 系统用于检查许多用户权限的 UID。例如，文件系统使用 UID 来检查文件的所有者访问权限。在执行设置用户标识符（set-user-identifier）程序时设置有效 UID。另参见用户标识符；真实标识符；保存用户标识符。

电梯排序算法 设备驱动程序用于移动磁头磁盘 I/O 请求的算法。该算法根据柱号将请求按循环升序顺序进行排序。该名称源于该算法对请求排序的方式类似于高效处理电梯请求的方式。

模拟 emulate 4.4BSD 的许多部分可以模拟硬件供应商提供的 UNIX 操作系统的系统接口。例如，HP300 版本的4.4BSD 可以运行为 HP-UX 编译的二进制文件。

解封装 decapsulation。

封装 encapsulation 在网络通信中，创建一个消息的过程，其中包含了一个现有的消息数据。协议通常通过构建一个前导协议头来封装消息，该头标明原始消息将被视为数据。这是解封装的反过程。

删除字符 erase character 终端处理器在运行于规范模式（canonical mode）时，识别为“删除输入行中的最后一个字符”的字符。每个终端会话可以有不同的删除字符，并且可以通过 `tsetattr` 调用随时更改该字符。终端处理器在非规范模式的终端上不识别删除字符。另参见删除字符；杀死字符。

errno C 程序中的全局变量，保存有一个指示系统调用失败原因的错误代码。存放在 errno 中的值由内核在标准返回寄存器返回；由 C 运行时库中的代码从该返回寄存器移动到 errno。

错误消息缓冲区 *参见消息缓冲区。*

驱逐通知 eviction notice 从服务器到客户端的回调消息，通知客户端其对象租约即将终止。租约的终止通常是因为另一个客户端想要修改该租约所代表的对象。另参见回调；租约。

缺页率 fault rate 产生页异常的频率。对于引用字符串，缺页率定义为与时间无关，计算方法为页异常数除以引用字符串的长度。

取页策略 fetch policy 需求分页虚拟内存管理系统在处理页异常时使用的策略。取页策略的主要区别在于它们处理数据的方式。

FIFO 在文件系统中，一种可用于进程间通信的文件类型。一个进程写入 FIFO 的数据将由另一个进程按照发送的顺序进行读取。该名称指的是数据是以“先进先出”的方式进行转换的。

文件 file 文件系统中的一种对象，被视为字节的线性数组。文件至少有一个名称，并且在所有名称被删除之前它都会一直存在。

句柄 handle 由 NFS 服务器创建并传回给 NFS 客户端的全局唯一令牌。客户端可以使用句柄来引用服务器上关联的文件。在首次打开文件时创建句柄；在引用已打开文件的后续操作（如读和写）中将其传递给服务器。

文件名 filename 用于命名普通文件、文件或目录的 ASCII 字符字符串。文件名中的字符不能包含空字符 (0) 或斜杠 ('/') 的 ASCII 码。

文件偏移量 file offset 与打开的文件描述符相关的偏移量。文件描述符的偏移通过 `lseek` 系统调用显式设置，或作为读写系统调用的结果隐式设置。

文件结构 file structure 内核用于持有引用一个或多个文件描述符的文件的数据结构。但在大多数情况下，当打开的描述符通过 `dup` 和 `dup2` 系统调用复制、跨 `fork` 系统调用继承，或通过进程间通信设施在消息中接收时使用。
