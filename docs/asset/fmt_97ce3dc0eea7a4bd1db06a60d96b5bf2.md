## 用于动画的沉浸式环境

使用光绘（matte painting）的局限性之一是，如果相机移动一点，幻觉就会破坏。特别是相机旋转时，你会察觉到背景的平面感，因为环境位图不会随着场景的其他部分一起旋转。

在相机移动的动画中，你必须设计沉浸式环境，使背景保持真实。实现这一点的一种方法是使用抽象背景，无论相机如何旋转，它看起来都一样。另一种复杂的方法是实际上用一个巨大的天穹（skydome）来建模环境，它包裹了场景的其他部分。你将在这里学习创建可以在动画场景中使用的沉浸式环境，但在第 13 章之前你将暂不深入主题。

## 创建可构建的背景

在显示建筑室外飞行的动画中，背景可以是从顶部到底部的简单渐变。这种背景看起来不会是静态的，因为当相机移动时，背景中的物体定义了一个参考点。

1. 继续上一个练习或按下`Savoy9.max`。

2. 选择`Rendering Environment`或按键盘上的`8`键。打开`Environment and Effects`对话框。

3. 点击`Map #23 (SUNSET90.jpg)`来更改映射类型。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_493_0.png)

4. 打开`Material/Map Browser`。从列表中选择`Gradient`，并注意对话框左上角的样本。它显示了从顶部黑色到白色白色灰度渐变。

5. 点击`OK`选择`Gradient`映射。

你已经将背景切换为渐变映射，但你会想要为渐变添加一些颜色：

1. 点击主工具栏上的`Material Editor`打开它（如果尚未打开）。

2. 如果你的`Material Editor`仅显示插槽，使用右侧的滑条查看对话框下方第三行的样本插槽。

3. 点击右下角未使用的插槽选中它；然后点击`Material`按钮。

4. 在`Material/Map Browser`中，点击`Browse`组中的`Scene`单选按钮，然后双击显示`Map #24 (Environment)`的列表。插槽显示了渐变。

一旦插槽中有了渐变，就可以开始调整它的参数：

1. 关闭`Material/Map Browser`。

2. 在`Material Editor`中，滚动到`Gradient`卷叠并点击标记为`Color #1`的颜色块。

| Gradient Parameters | |
|---|---|
| Color #1 | None |
| Color #2 | None |
| Color #3 | None |

3. 在`Color Selector`对话框中，将`Hue`设置为`155`，`Saturation (Sat)`设置为`219`，`Value`设置为`100`。

## 使用纹理映射和半球天空

渐变背景提供了晴朗天空的幻觉，但如果你想添加一些云朵怎么办？你可以通过在模型上方添加穹顶并分配一个使用云天位图的纹理映射来模拟云天。以下是操作方法：首先添加半球对象：

1. 右键点击`Top`视口，然后点击`VIZ`窗口右角的`Zoom Extents`工具。

2. 在命令面板的`command`标签中，点击`Geometry`按钮并选择`Sphere`。

3. 在`Top`视口中，从建筑中心点击并拖动球，如图 9.19 所示。使球延伸到平面，半径为`1060`英尺。

## 图 9.19

创建一个半径为`1060`英尺的球。

![](img/74f26f3c74f826f3c74f8_495_0.png)

4. 右键点击`Front`视口，点击`Zoom Extents`按钮。

5. 在命令面板中，将球的`Hemisphere`参数改为`0.7`。大部分球将消失，留下顶部位置。将球名称从`Sphere01`改为`Skydome`，以便跟踪其功能。

6. 移动`Hemisphere`，使其基座位于地面平面下方，如图 9.20 所示。

当你调整`Hemisphere`参数时，`VIZ`会展平球的底部并在区域放置表面。你需要将平坦球的底部放在地面平面下方，以便球的平坦表面出现在你的相机视图中。另一个选项是将对象转换为`editable poly`，然后删除形成底部的面。

现在你的模型上方有一个穹顶，它将成为天空。球通常旨在从外部查看，因此当`VIZ`创建球时，法线向外。在这种情况下，你希望从内部查看球，因此你需要反转法线方向：

1. 选中`Editable poly`，点击`Modify`标签。

2. 在修改器堆中右键点击`Sphere`，然后转换为`Editable Poly`。

3. 点击`Selection`卷叠中的`Element`按钮。
