### expand 和 unexpand

`expand` 和 `unexpand`

`expand` 过滤器将制表符转换为空格。它通常用于管道中。

`unexpand` 将空格转换为制表符。这与 `expand` 的效果相反。

### cut

`cut`
一个用于从文件中提取字段的工具。它类似于 `awk` 中的 `print $N` 命令，但功能更有限。在脚本中使用 `cut` 可能比使用 `awk` 更简单。特别是 `-d`（分隔符）和 `-f`（字段指定符）选项非常重要。

使用 `cut` 获取挂载的文件列表：

```bash
cut -d ' ' -f1,2 /etc/mtab
```

使用 `cut` 显示操作系统和内核版本：

```bash
uname -a | cut -d" " -f1,3,11,12
```

使用 `cut` 从邮件文件夹中提取标头：

```bash
bash$ grep '^Subject:' read-messages | cut -c10-80

n:: Linux suitable for mission-critical apps?
MAKE MILLIONS WORKING AT HOME!!!
Spam complaint
Re: Spam complaint
```

使用 `cut` 解析文件：

```bash
# 列出 /etc/passwd 中的所有用户。

FILENAME=/etc/passwd

for user in $(cut -d: -f1 $FILENAME)
do
    echo $user
done
```

> 感谢 Oleg Philon 建议此方法。
> `cut -d: -f2,3 filename` 等同于 `awk -F: '{ print $2, $3 }'`

#### 换行符作为分隔符

甚至可以指定换行符作为分隔符。技巧是实际上在命令序列中嵌入一个换行符（RETURN）。

```bash
bash$ cut -d$'\n' -f3,7,19 testfile

This is line 3 of testfile.
This is line 7 of testfile.
This is line 19 of testfile.
```

### paste

`paste`
将不同文件合并为单个多列文件的工具。与 `cut` 结合，可创建系统日志文件。

```bash
bash$ cat items

alphabet blocks
building blocks
cables

bash$ cat prices

$1.00/dozen
$2.50 ea.
$3.75

bash$ paste items prices

alphabet blocks $1.00/dozen
building blocks $2.50 ea.
cables $3.75
```

### 计算文件中间的行数

```bash
var=$($(head -n m $filename | tail -n n)

# filename = 文件名
# m = 从行开始到块结束的
# n = 设置给变量的行数（从块末尾修剪）
```

`tail` 的新实现废弃了旧的 `tail -LINES filename` 用法。标准的 `tail -n LINES filename` 是正确的。

### grep

一个使用正则表达式的多功能搜索工具。它最初是受推崇的行编辑器 `g/re/p` 的命令/过滤器（全局 - 正则表达式 - 打印）。

```bash
grep pattern [file...]
```

在文件(们)中搜索 `pattern` 的出现情况，`pattern` 可以是字文本也可以是正则表达式。

```bash
bash$ grep "[rst]system.* osinfo.txt

The GPL 规定了 Linux 操作系统的发行。
```

如果没有指定文件，`grep` 从标准输入读取，就像在管道中一样。

```bash
bash$ ps ax | grep clock

765 ttl S 0:00 xclock
901 pts/1 S 0:00 grep clock
```

*   `-i` 选项导致不区分大小写的搜索。
*   `-w` 选项仅匹配整个单词。
*   `-l` 选项仅列出找到匹配的文件，但不列出匹配的行。
*   `-r`（递归）选项在当前工作目录及其所有子目录中搜索文件。
*   `-n` 选项列出匹配的行以及行号。

```bash
bash$ grep -n Linux osinfo.txt

2:This is a file containing information about Linux.
6:The GPL governs the distribution of the Linux operating system.
```

`-v`（或 `--invert-match`）选项过滤掉匹配项。

```bash
grep pattern1 *.txt | grep -v pattern2

# 匹配所有 *.txt 文件中包含 "pattern1" 的行
# 但不包含 "pattern2"
```

`-c` 选项提供匹配项的数字计数，而不是实际列出匹配项。

```bash
grep -c txt *.sgml # ("*.sgml" 文件中 "txt" 出现的次数)
```

计数非空项：

```bash
# grep -cz .
#   dot
# 意味着计数 (-c) 零分隔 (-z) 匹配 "." 的项
# 即非空项（至少包含 1 个字符）。

printf 'a\nb\nc\n' | grep -cz . 3
printf 'a\nb\nc\n' | grep -cz $ 5
printf 'a\nb\nc\n' | grep -cz '$' 5
printf 'a\nb\nc\n' | grep -c '$' 9

# 默认情况下，换行符 (\n) 分隔要匹配的项。
# 注意 -z 选项是 GNU "grep" 特有的。
```

感谢，S.C.

`--color`（或 `--colour`）选项用颜色标记匹配的字符串（在控制台或 `xterm` 窗口中）。由于 `grep` 会打印包含匹配模式的每一整行，这让你确切看到正在匹配的是什么。另请参见 `-o` 选项，它只显示行(们)的匹配部分。

#### 示例 16-1. 从存储的电子邮件消息的行中打印内容

```bash
#!/bin/bash
# from.sh
# 模拟 Solaris、BSD 等系统中常用的 'from' 工具
# 回显你邮件目录中所有消息的 "From" 头部行

MAILDDIR=/mail/* # 变量没有加引号。为什么？

# 也许检查 $MAILDDIR 是否存在 [ -d $MAILDDIR ] ; .

GREP_OPTS="-H -5 --color" # 显示文件，加上额外的上下文行
# 并用颜色显示 "From"。

TARGET="From" # 行首的 "From"。

for file in $MAILDDIR # 变量没有加引号。
do
    grep $GREP_OPTS "$TARGET" "$file"
    # 再次，不要给这个变量加引号。
    echo
done

exit $?
```

> 你可能希望此脚本的输出管道到 `more`
> 或将其重定向到文件 . . .

当用一个目标文件调用时，`grep` 指定哪个文件包含匹配项。

```bash
bash$ grep Linux osinfo.txt misc.txt

osinfo.txt:This is a file containing information about Linux.
osinfo.txt:The GPL governs the distribution of the Linux operating system.
misc.txt:The Linux operating system is steadily gaining in popularity.
```

要强制 `grep` 在仅搜索一个目标文件时仅显示文件名，只需提供 `/dev/null` 作为第二个文件。

```bash
$ grep Linux osinfo.txt /dev/null

osinfo.txt:This is a file containing information about Linux.
osinfo.txt:The GPL governs the distribution of the Linux operating system.
```

如果存在匹配，`grep` 返回退出状态 0，这使得在脚本中非常有用，特别是结合使用 `-q` 选项抑制输出时。

```bash
SUCCESS=0 # 如果 grep 成功
```

#### 示例 16-2. 字典查找脚本

```bash
#!/bin/bash
# dict-lookup.sh

# 此脚本用于在 1913 版韦伯士字典中查找定义。
# 这本公共领域字典可以从多个网站下载，包括
# 古腾堡项目 (http://www.gutenberg.org/ebooks/247)。

# 在使用此脚本之前，请将其从 DOS 格式转换为 UNIX 格式（行尾保留 LF）。
# 将文件存储为纯文本、未压缩的 ASCII 格式。
# 在下方设置 DEFAULT_DICTFILE 变量为路径/文件名。

E_BADARGS=85

MAXCONTEXTLINES=50 # 显示的最大行数。

DEFAULT_DICTFILE="/usr/share/dict/webster1913-dict.txt"
# 默认字典文件名。
# 根据需要修改此项。

# 注意：
# 1913 版韦伯士字典的这一特定版本
# 每个条目都以大写字母开头
# （其余字符为小写）。
# 只有条目的“第一行”是这样开头的
# 搜索算法正是这样工作的。

if [[ -z "$1" ]]; then
    echo "Usage: basename $0 Word-to-define [dictionary-file]"
    echo
    echo "Note: Word to look up must start with an uppercase letter,"
    echo "the rest of the word lowercase."
    echo "------------------------------------------------"
    echo "Examples: Abandon, Dictionary, Marking, etc."
    exit $E_BADARGS
fi

if [ -z "$2" ]; then
    dictfile=$DEFAULT_DICTFILE
else
    dictfile="$2"
fi

Definition=$(grep -A $MAXCONTEXTLINES "$1" "" "$dictfile")
    # 格式为 "Word..." 的定义

# 而且，是的，“grep" 的速度足够搜索
# 即使是非常大的文本文件。

# 现在，截取出定义块。

echo "$Definition" | \
sed -n '/^\[A-Z\]/p' \
# 从输出的第一行开始打印
# 到下一个条目的第一行。
sed '$d' | sed '$d'
# 删除输出的最后两行
# （空行和下一个条目的第一行）。

exit $?

# 练习题：
# 1) 修改脚本以接受任何类型的字母输入
# （大写、小写、混合大小写），并将其转换为
# 可处理的格式。
# 2) 将脚本转换为 GUI 应用程序，
# 使用类似 'dialog' 或 'zenity' 的工具
# 脚本将不再从命令行
# 获取其参数。
# 3) 修改脚本以解析其他可用的
# 公共字典，例如美国人口普查局地名索引。
```

> 参见示例 A-41，获取在大文件上进行快速 `fgrep` 查找的示例。

### agrep (近似 grep)

`agrep` 扩展了 `grep` 的功能用于近似匹配。搜索字符串与匹配结果之间存在指定数量的差异。此工具不是 Linux 核心发行版的一部分。

> 要搜索压缩文件，请使用 `zgrep`、`zegrep` 或 `zfgrep`。这些也适用于非压缩文件，尽管比纯 `grep`、`egrep`、`fgrep` 慢。它们对于搜索混合了部分压缩和未压缩的文件集非常方便。

要搜索 `bzipped` 文件，请使用 `bgrep`。

### look

该命令的工作原理类似于 `grep`，但会对“字典”（一个排序后的列表）进行查找。默认情况下，`look` 在 `/usr/dict/words` 中搜索匹配，也可以指定不同的字典文件。

#### 示例 16-20. 检查列表中单词的有效性

```bash
#!/bin/bash
# lookup: 对数据文件中的每个单词进行字典查找。

file=words.data # 从其中读取测试单词的数据文件。

echo
echo "Testing file $file"
echo

while [ "$word" != "end" ]; do
    # 数据文件中的最后一个单词。
    read word # 从数据文件读取，因为循环末尾有重定向。
    look $word > /dev/null # 不需要显示字典文件中的行。
    # 在文件 /usr/share/dict/words 中搜索单词
    # （通常是 linux.words 的软链接）？
    # look 命令的退出状态。

    if [ "$?" -eq 0 ]; then
        echo "$word" 是有效的。
    else
        echo "$word" 是无效的。
    fi
done <"$file" # 重定向 stdin 到 $file，因此读取内容来自该文件。

echo
exit 0
```

> 下方的代码将不会执行，因为上面有 "exit" 命令。
> Stephane Chazelas 提了以下更简洁的替代方案：

```bash
while read word && [[ "$word" != "end" ]]; do
    if look "$word" > /dev/null; then
        echo "$word" 是有效的。
    else
        echo "$word" 是无效的。
    fi
done <"$file"
exit 0
```

### sed

`sed`

### awk

`awk`
非交互式“流编辑器”，允许在批量处理中使用许多 `awk` 命令。它在 shell 脚本中有许多用途。

### wc

`wc`
编程的文件提取器和格式化工具，用于处理和提取结构化文本文件的字段（列）。其语法与 C 语言相似。

对文件或 I/O 流给出“单词计数”：

```bash
bash $ wc /usr/share/doc/sed-4.1.2/README
13 70 447 README
[13 行 70 个单词 447 个字符]
```

*   `wc -l` 只显示行数。
*   `wc -c` 只显示字节数。
*   `wc -m` 只显示字符数。
*   `wc -L` 只显示最长行的长度。

### 文件重命名示例

```bash
if [ "$fname" != "$sn" ]  # 仅重命名尚未转换为小写的文件。
then
    mv $fname $sn
fi
done
exit 
```

```bash
# 此行以下代码将由于 "exit" 而不会执行。
# 如需运行它们，请删除上行的脚本。
# 上述脚本不适用于包含空格或换行符的文件。
# Stephanie Chazelas 建议采用以下替代方案：

for filename in *  # 没有必要使用 basename，
do
    n=$(echo "$filename" | tr '[:upper:]' '[:lower:]')
    # 因为它不会返回任何包含 "/" 的文件
    # POSIX 集合符号。
    # 加上斜杠是为了防止末尾的换行符被
    # 命令替换移除。
    # 变量替换：
    n=${n%/} # 从文件名中移除上面添加的末尾斜杠。
    [ "$filename" == "$n" ] || mv "$filename" "$n" # 检查文件名是否已经是小写。
done
exit 0
```
