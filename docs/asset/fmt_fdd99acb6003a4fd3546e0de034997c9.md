# 链反应（物理学）

重原子核发生分裂（称为核裂变）后会释放出一代中子。该过程释放出 200 MeV (3.2 × 10⁻¹ J) 的能量，形式为包括两个或三个中子的粒子。其中一部分这一代中子被裂变物种（`$^{235}$U`、`$^{238}$U`、`$^{239}$Pu`）捕获，从而引发下一代的裂变。

主要由钙质生物和微生物的遗骸组成。大多数海洋生物生活在海洋和近岸水域，如球石藻（藻类）和浮游生物（原生动物）。可能存在较大的化石，但含量较少。钙质类生物的主体骨骼遗骸沉积在深度小于 40 米（或 13,000 英尺）的海床上（碳酸盐在更深的水层沉积会减缓）。典型的沉积速率在数百万年间变化。该地层的形成还取决于粘土等稀释材料的沉积。

# 蓝铜矿

蓝铜矿的化学成分为 `$CuSO_{4}\cdot5H_{2}O$`。蓝铜矿呈蓝绿色晶体状。它是高度无水的。莫氏硬度为 2.5 到 5，比密度为 2.8。它溶于水且味道味酸，但质脆。它在空气中会脱水变成白色粉末。尽管它在某些地区存在，但通常不是重要的天然矿石来源。其存在在美国西部已有见证记录。

这种颜色和成分纯度的独特组合，被许多早期时期用于在板上书写。蓝铜矿还用于水泥颜料、肥料、磨料剂以及化妆品中。

# 碧玉石

玉石是石英（二氧化硅）的一种细颗粒变体。其纤维结构由隐晶质结构组成。根据颜色可分为不同的亚种；某些自古以来就被珍视为宝石材料，如红玉髓（深红色至珊瑚色）、橙玉髓（橙红色至棕红色）和碧玺石（苹果绿）。

玉石呈现圆形、微晶体或葡萄状的表面，是结节状玛瑙的主要成分。其莫氏硬度为 6.5–7。比密度为 2.57–2.6。

大多数玉石由汇集到表面的细微层组成。玛瑙是玉石的一种常见且重要的变体，具有颜色和透明度不一的条纹。在某些情况下，玛瑙的种类根据材料形成时的空腔形状呈弯曲和同心状。参考玛瑙（AGATE）。

# 方解石

方解石是一种在热液系统（217°F 或 107°C）中结晶的白色矿物。晶体细小且稀有，通常具有高光泽和美丽的色泽。最常见的是，这种矿物呈细粒块状，具有金属光泽和浅灰色，与铜发生改变时产生。它发现于硫化铜的氧化。

# 黄铁矿

黄铁矿是一种采铜矿物 `$CuFeS_{2}$`。晶体细小呈块状，具有黄褐色的金属光泽和不定的色调。莫氏硬度为 3.5 到 4.0。

黄铁矿是最主要的铜矿石。它发现于许多国家（比格姆矿，智利；科罗拉多州；德国；英国；匈牙利；法国；萨克森州；俄罗斯；里约；内华达州；阿拉斯加州；田纳西州，美国西南）。

# 粉笔

广义上指任何软、脆或风化的细粒石灰岩；然而，该术语主要局限于深海（生物源）石灰岩。它通常是细粒、浅色的碳酸盐石灰岩。

# 变岩

变岩指的是非洲和马达加斯加属于变色科的所有 80 种中小型蜥类。变色龙（Anoles）属于另一个蜥类科，变色蜥科。

变岩也是物种种类最多的，是一个典型的例子。变色龙是树栖的。变色龙具有变色能力。变色龙的四肢适应了树栖生活。变色龙的眼睛很大。变色龙的变色可以独立移动很远距离。变色龙的舌很长，用于捕食昆虫。变色龙是卵繁殖的。变色龙在巢中产卵。

# 钙质变岩（Chalk）

广义上指任何软、脆或风化的细粒石灰岩；然而，该术语主要局限于深海（生物源）石灰岩。它通常是细粒、浅色的碳酸盐石灰岩。
