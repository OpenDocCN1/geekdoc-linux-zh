
> 警告
请记住，在添加新用户账户时，在启动 `useradd` 命令之前，该账户所属的主组和辅助组必须存在。此外，如果一个组是某个用户账户的主组，则无法删除它。

# passwd 命令

此命令主要用于更改用户密码。任何用户都可以更改自己的密码，但只有 `root` 用户可以更改任何用户的密码。

根据所使用的 `passwd` 选项，你可以控制密码过期的特定方面：

- `-d`
删除用户账户的密码（从而设置为空密码，使其成为无密码账户）。

- `-e`
强制用户账户更改密码。

- `-l`
锁定用户账户（加密后的密码前会有一个感叹号）。

- `-u`
解锁用户账户（移除感叹号）。

## -S

输出特定账户的密码状态信息。

这些选项仅供 `root` 使用。要查看完整的选项列表，请参考手册页（`man pages`）。

## 引导练习答案

1. 对于以下每个条目，指出它所指向的文件：

- `developer:x:1010:frank,grace,dave`: `/etc/group`
- `root:x:0:0:root:/bin/bash`: `/etc/passwd`
- `henry:1$.AbCdEfGh123456789A1b2C3d4.:18015:20:90:5:30::`: `/etc/shadow`
- `henry:x:1000:1000:User Henry:/home/henry:/bin/bash`: `/etc/passwd`
- `staff:!:dave:carol,emma`: `/etc/group`

2. 观察以下输出回答接七个问题：

- `carol` 的用户 ID (`UID`) 和组 ID (`GID`) 是多少？`UID` 是 1051，`GID` 是 1051。
- `dave` 和 `henry` 设置了什么 shell？`dave` 使用 `/bin/bash`，`henry` 使用 `/bin/tcs`。
- `henry` 的主组名称是什么？组名是 `web_developer`。
- `web_developer` 组的成员有哪些？成员是 `grace` 和 `christian`。都不是组管理员。
- 哪个用户无法登录系统？`henry` 账户被锁定（`shadow` 中有一个感叹号）。
- 哪个用户下次登录系统时应该更改密码？`shadow` 第三字段（最后修改日期）为0，所以是 `dave`。
- `carol` 更改密码需要经过多少天？60 天。

## 探索练习答案

1. 以 `root` 身份运行 `useradd -m dave` 命令添加新用户账户。该命令执行了哪些操作？该命令向系统用户列表中添加名为 `dave` 的新用户。创建了 `dave` 的主目录（默认是 `/home/dave`），并将 `skeleton` 目录中的文件和目录复制到主目录。最后，创建了一个与用户账户同名的组。

2. 现在你已经创建了 `dave` 账户，该用户可以登录系统吗？

不可以，因为 `dave` 账户被锁定了（查看 `/shadow` 中的感叹号）。

```
# cat /etc/shadow | grep dave

dave!:18015:0:99997:::
```

如果你为 `dave` 设置密码，账户将解锁。你可以使用 `passwd` 命令来实现。

```
# passwd dave

Changing password for user dave.

New UNIX password:

Retype new UNIX password:

passwd: all authentication tokens updated successfully.
```

3. `dave` 的用户 ID (`UID`)、`组 ID` (`GID`) 以及 `dave` 组的所有成员。

```
# cat /etc/passwd | grep dave

dave:x:1019::/home/dave:/bin/sh

# cat /etc/group | grep 1019

dave:x:1019:
```

`dave` 的 `UID` 和 `GID` 分别为 1015 和 1019（分别是 `/etc/passwd` 中的第三和第四字段），`dave` 组没有成员（`/etc/group` 中的第四字段为空）。

4. 创建 `sys_admin`、`web_admin` 和 `db_admin` 组，并识别它们的组 ID (`GID`)。

```
# groupadd sys_admin

# groupadd web_admin

# groupadd db_admin
```

5. 添加一个 UID 为 1035 的新用户 `carol`，并将 `sys_admin` 设置为主组，`web_admin` 和 `db_admin` 设置为其辅助组。

```
# useradd -u 1035 -g sys_admin -G web_admin,db_admin carol
```

6. 删除你之前创建的 `dave` 和 `carol` 用户账户以及 `sys_admin`、`web_admin` 和 `db_admin` 组。

```
# userdel dave

# userdel carol

# groupdel sys_admin

# groupdel web_admin

# groupdel db_admin
```
