## `ld.so`

动态加载器。每个使用共享库的二进制文件都有 3KB 的启动代码，用于查找和加载共享库。现在这些代码被放在一个共享库 `/lib/ld.so` 中，所有二进制文件都可以查找它，这节省了磁盘空间，并且更容易升级。

源自 Linux Guide @FirstLinux

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## `LDAP`

目录服务，`LDAP`（轻量级目录访问协议）被电子邮件程序（Microsoft, Netscape, Aurora 等）用于在公司数据库中查找姓名，并找到他们的电子邮件地址、电话号码以及管理员决定放在那里的其他信息。关键点：大多数 LDAP 服务器几乎或没有身份验证。查找 LDAP 服务器并下载其内容是黑客攻击侦察阶段的一个重要步骤。关键点：`LDAP` 虽然非常轻量，但仍然相当复杂。存在许多实现和部署漏洞可以被利用来入侵服务器。

源自 Hacking-Lexicon

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## `LDAP`

`LDAP` 代表轻量级目录访问协议。正如其名所示，它是一种用于目录服务的轻量级客户端-服务器协议，特别是基于 X.500 的目录服务。`LDAP` 运行在 TCP/IP 或其他面向连接的传输服务之上。`LDAP` 在 RFC2251 中定义。

“轻量级访问协议 (v3)。目录类似于数据库，但倾向于包含更多描述性的、基于属性的信息。目录中的信息读取次数远大于写入次数。目录的写入是为了对高大量的查找或搜索操作提供快速响应。它们可能具有复制信息的能力，以增加可用性和可靠性，同时缩短时间。当信息被复制时，副本之间临时的不一致可能是可以接受的，因为它们最终会同步。提供目录服务有许多方法。不同的方法允许在目录存储不同类型的信息，对信息的如何引用、查询和更新有不同要求，对如何保护其免受未经授权的访问有不同要求。某些目录服务是本地的，为受限的上下文提供服务（例如单机上的 finger 服务）。其他服务是全局的，为更广泛的上下文提供服务。

LDAP–Linux–HOWTO

http://www.tld.org/LDP/Linux-Dictionary/index.html

## `ldap2dns`

基于 LDAP 的 DNS 管理系统。`ldap2dns` 是一个直接从 LDAP 目录创建 DNS（域名服务）记录的程序。它应该被用于主服务器替换辅助服务器。`ldap2dns` 减少了所有的管理开销：不再需要编辑文件，不再需要编辑区域。在使用 ldapdns 后，管理员只需访问 LDAP 目录。`ldap2dns` 设计用于使用 bind 包中的 ASCII 数据文件，但也可用于写入名称引用的 .db 文件。

源自 Debian 3.0 APT
