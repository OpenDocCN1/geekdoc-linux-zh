
# 指数函数
指数函数是形式为 `$f(x) = a^x$` 的函数，其中 `$a$` 是数系中的常数。这些函数的图像有两种基数类型：`$0 < a < 1$` 的图（见图 3a）和 `$a > 1$` 的图（见图 3b）。

指数函数在描述增长率与现有数量成比例的情况下非常重要。指数函数可以描述的情况包括：利息计算、放射性衰变和人口增长。

# 对数函数
代数中另一个重要的函数是对数函数。对数是指数函数的反函数，通过交换 `$x$` 和 `$y$` 的角色来实现。

```
$y = \log_ax \iff a^y = x$ (5)
```

# 方程
方程 `$x^2 = 2$` 在有理数集中无解，在实数有两个解（`$x = \sqrt{2}$` 和 `$x = -\sqrt{2}$`），在复数域有四个解。

# 函数
一些最基础的方程涉及一个变量。当两个变量变化时，例如一个可以用另一个表示（例如 `$y$` 使得对于每个 `$x$` 的值只有一个 `$y$` 的值），则这种关系被描述为函数，它可能是多项式，也可能不是。
