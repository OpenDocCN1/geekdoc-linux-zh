
# vi 命令参考

## 文件操作

| vi 命令 | 功能 |
| :--- | :--- |
| `:w` | 保存文件并保持编辑模式 |
| `:w` | 在 Windows 中为另存为... |
| `:w!` | 覆盖现有文件 |
| `:n1,n2w` | 将 n1 到 n2 行写入文件 |
| `:n1,n2w` | 将 n1 到 n2 行追加到文件 |
| `:.w` | 将当前行写入文件 |
| `:$w` | 将最后一行写入文件 |
| `:x` | 保存文件并退出编辑模式 |
| `:wq` | 如上 |
| `:q` | 当文件无任何更改时退出编辑模式 |
| `:q!` | 放弃更改后退出编辑模式 |

## 编辑多个文件

你可以使用 `:e`, `:n`, `:rew`，除非设置了 `autowrite`。

| vi 命令 | 功能 |
| :--- | :--- |
| `:e` | 编辑当前文件 |
| `:e!` | 如上，但放弃对当前文件的更改 |
| `:e#` | 编辑最后编辑的文件 |
| `[Ctrl-^]` | 返回最近编辑的文件 |
| `:n` | 编辑下一个文件（在使用多个文件名时） |
| `:set autowrite` | 切换文件时自动写入当前文件 |
| `:rew` | 回到第一个文件（在使用多个文件名时） |
| `:r` | 在当前行下方读取文件 |

## 多窗口 (vim)

| vim 命令 | 功能 |
| :--- | :--- |
| `:sp` | 将当前窗口分为二 |
| `:new` | 打开一个新的空白窗口 |
| `[Ctrl-w][Ctrl-w]` | 在窗口间切换 |
| `:on` | 使当前窗口成为唯一窗口 |
| `:q` | 退出当前窗口 |
| `:qa` | 退出所有窗口 |
| `:xa` | 保存并退出所有窗口 |
| `[Ctrl-w] +` | 增大窗口大小 |
| `[Ctrl-w] -` | 减小窗口大小 |

## 搜索和重复

vi 对字符串和正则表达式使用相同的搜索和重复技术。它还使用单独的键序列在行内搜索字符。

| vi 命令 | 功能 |
| :--- | :--- |
| `/pat` | 向前搜索字符串 pat |
| `/pat` | 如上，但 pat 是正则表达式 |
| `?pat` | 向后搜索字符串 pat |
| `?pat` | 如上，但 pat 是正则表达式 |
| `n` | 在相同方向重复字符串搜索 |
| `N` | 在反向方向重复字符串搜索 |
| `n` | 在相同方向重复正则表达式搜索 |
| `N` | 在反向方向重复正则表达式搜索 |
| `:set wrapscan` / `:set ws` | 通过移动到文件另一端继续模式搜索 |
| `:set ignorecase` / `:set ic` | 搜索时忽略大小写 |
| `:set magic` | 保留正则表达式字符的含义 |
| `fc` | 向前搜索字符 c |
| `Fc` | 向后搜索字符 c |
| `;` | 重复上一次字符搜索 |
| `,` | 重复上一次反向字符搜索 |

## 替换

| vi 命令 | 功能 |
| :--- | :--- |
| `:1,$s/s1/s2/g` | 全局替换字符串 s1 为 s2 |
| `:1,$s/s1/s2/g` | 如上，但 s1 是正则表达式 |
| `:1,$s/s1/s2/gc` | 交互替换 |
| `:1,$s/s1/s2/gc` | 如上，但 s1 是正则表达式 |
| `:s` | 在当前行重复上一次替换（仅限 vim） |

| vi 命令 | 功能 |
| :--- | :--- |
| `ma` | 设置标记 a |
| `'a` | 跳到标记 a |

## 重做与撤销 (Redoing and Undoing)

| vi 命令 | 功能 |
| :--- | :--- |
| `.` | 重复上一次命令 |
| `u` | 撤销上一次编辑命令 |
| `[Ctrl-r]` | 重做上次撤销（仅 vim） |
| `U` | 撤销当前行的所有更改 |
| `"4p` | 从缓冲区恢复第四次删除的完整行 |

## 文本缩写 (Abbreviating Text)

| vi 命令 | 功能 |
| :--- | :--- |
| `:ab stg name` | 将 name 缩写为 stg (也可以放在 `~/.exrc` 中) |
| `:ab` | 列出所有缩写 |
| `:unab stg` | 移除缩写 stg |

## 宏与键位映射 (Macros and Key Mapping)

| vi 命令 | 功能 |
| :--- | :--- |
| `qm` ... `q` | 定义名为 m 的宏 (输入命令序列，然后按 `q` 结束) |
| `@m` | 运行上次定义的名为 m 的宏 |
| `:map key commands` | 将键映射到命令 (也可以放在 `~/.exrc` 中) |
| `:map! key commands` | 在输入模式下将键映射到命令 (也可以放在 `~/.exrc` 中) |
| `:map` | 显示所有命令模式映射 |
| `:map!` | 显示所有输入模式映射 |
| `:unmap key` | 移除命令模式的键映射 |
| `:unmap! key` | 移除输入模式的键映射 |

## 与 UNIX 的接口 (Interface To UNIX)

只有在启用作业控制的 shell 中才能用 `[Ctrl-z]` 挂起编辑器。

| 命令 | 功能 |
| :--- | :--- |
| `:!cmd` | 运行 UNIX 命令 cmd |
| `:%!` | 将当前文件作为 shell 或 perl 脚本执行 |
| `:r !cmd` | 读取命令 cmd 的输出 |
| `:r !head -n 3 foo` | 在当前行下方读取 foo 的前三行 |
| `:sh` | 退出到 UNIX shell |
| `[Ctrl-z]` | 挂起编辑器 |
| `:make %` | 编译当前编辑的 C 程序 |
| `:!javac %` | 编译当前编辑的 Java 程序 |

| `:set ro` | 切换到只读模式 |

# 附录 E：正则表达式超集 (The Regular Expression Superset)

vi/vim 和 emacs 编辑器使用正则表达式来过滤 grep、egrep、sed、awk 和 perl。遗憾的是，这些命令使用该集合的不同子集，许多人并不确定某个命令识别哪些元字符，哪些不识别。文中提供了示例以方便理解。

## 基础正则表达式 (Basic Regular Expressions)

| 符号 | vi | emacs | grep | sed | egrep | awk | perl | vim | grep | sed | gawk | 匹配 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| `*` | | | | | | | | | | | | 上一个字符的零次或多次 |
| `9*` | | | | | | | | | | | | 空或 g, 99, 999 等 |
| `99*` | | | | | | | | | | | | 9, 99, 999 等 |
| `.` | | | | | | | | | | | | 单个字符 |
| `.*` | | | | | | | | | | | | 空或任意数量的字符 |
| `[abc]` | | | | | | | | | | | | a 或 b 或 c |
| `[1-3]` | | | | | | | | | | | | 1 到 3 之间的数字 |
| `[^Z]` | | | | | | | | | | | | Z 以外的任何字符 |
| `[^a-zA-Z]` | | | | | | | | | | | | 非字母字符 |
| `^DM` | | | | | | | | | | | | 行首的 DM |
| `bash$` | | | | | | | | | | | | 行尾的 bash |

## 扩展正则表达式 (Extended Regular Expressions)

| 符号 | vi | emacs | grep | sed | egrep | awk | perl | vim | gawk | 匹配 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| `+` | | | | | | | | | | 上一个字符的一次或多次 |
| `g+` | | | | | | | | | | 至少一个 g |
| `g\+` | | | | | | | | | | 同上 |
| `?` | | | | | | | | | | 上一个字符的零次或一次 |
| `g?` | | | | | | | | | | 空或 g |
| `g\?` | | | | | | | | | | 同上 |
| `GIF` | | | | | | | | | | JPEG 的 GIF |
| `GIF\|JPEG` | | | | | | | | | | 同上 |
| `wood(cock\|house)` | | | | | | | | | | woodcock 或 woodhouse |
| `wood(cock\|house)` | | | | | | | | | | 同上 |
| `\<pat` | | | | | | | | | | 行首的模式 |
| `pat\>` | | | | | | | | | | 行尾的模式 |

## 间隔与标记正则表达式 (Interval and Tagged Regular Expressions)

这些是高级正则表达式。egrep、awk 和 perl 也接受，但会忽略前面的括号 `)`。gawk 同样如此。

| 符号 | vi | emacs | grep | egrep | awk | perl | vim | gawk | 匹配 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| `\(m\)` | | | | | | | | | | 上一个字符的 m 次 |
| `\{m\}` | | | | | | | | | | 同上 |
| `^.\{m\}` | | | | | | | | | | 行首的 m 次上一个字符 |
| `^.\{m,\}` | | | | | | | | | | 行首至少 m 次任意字符 |
| `\{m,n\}` | | | | | | | | | | 上一个字符的 m 到 n 次 |
| `\(exp\)` | | | | | | | | | | 同上并附加标记 |
| `(exp)` | | | | | | | | | | 同上，但也使用 1, 2 等。 |
