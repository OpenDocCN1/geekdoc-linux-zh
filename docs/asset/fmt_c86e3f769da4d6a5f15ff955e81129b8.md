
- `Omni[36]` — 这是 IBM 的一个自由软件项目，旨在将其过去 OS/2 时期的打印机驱动知识转化为适用于 Linux/UNIX 的现代、模块化、通用驱动架构（目前仍处于测试版阶段）。目前支持 437 种型号。
- `HPLJS[37]` — 这是 HP 的一个自由软件项目，旨在为其自身产品系列提供支持（非常成熟，大多数情况下打印效果完美并提供真正的照片级质量）。目前支持 369 种型号。
- `Gimp-Print[38]` — 这是一个自由软件项目，由 Michael Sweet（也是 CUPS 的主要开发人员）发起，现由 Robert Krawitz 主导，该项目达到了惊人的照片打印质量水平（许多 Epson 用户甚至宣称其质量优于 Epson 为 Microsoft 平台提供的厂商驱动）。目前支持 522 种型号。

### 21.13.1.7 论坛、下载、教程、操作指南（也适用于 Mac OS X 和商业 UNIX）

如今，`Linuxprinting.org` 是下载打印机驱动程序的一站式商店。

查找打印机信息和教程[39]，或在其热门论坛[40]中解决打印问题。

该论坛不仅面向 GNU/Linux 用户，商业 UNIX 系统管理员[41]也会访问那里，而相对较新的 Mac OS X 论坛[42]在短短几周内就成为了访问频率最高的论坛之一。

`Linuxprinting.org` 和围绕 `Ghostscript` 的 `Foomatic` 驱动程序封装器现在是所有重要发行版打印的标准工具链。

它们底层大多也使用 `CUPS`。

尽管近年来大部分打印机数据都是由 Kampetper 添加的，但也来自 SuSE、Red Hat、Connectiva、Debian 以及其他厂商工程师的许多额外贡献。

厂商中立性是 `Foomatic` 项目的重要目标。

`Mandrake` 和 `Connectiva` 已合并，现在称为 `Mandriva`。

> Mandrakesoft 的 Till Kampetper 利用业余时间为维护 `Linuxprinting.org` 和 `Foomatic` 做出了卓越的工作。因此，如果您经常使用它们，请给他发一封电子邮件以表达您的感激之情。

### 21.13.1.8 Foomatic 数据库生成的 PPD

`Foomatic` 数据库本身就是一个天才般的创造。

它不仅保存打印机和驱动程序信息，而且其组织方式使其能够基于内部 XML 数据集即时生成 PPD 文件。

虽然这些 PPD 是根据 Adobe 规范建模的，但 `Linuxprinting.org`/`Foomatic-PPDs` 通常并不驱动 PostScript 打印机。

它们用于描述你在 Epson Stylus 喷墨打印机、HP Photosmart 或其他任何打印机上能玩出的所有花样。

主要的诀窍在于增加了一行 PPD 规范未曾设想的内容，以 `*cupsFilter` 关键字开头。
