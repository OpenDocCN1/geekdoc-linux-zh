# Shortcuts:

| `ctrl+c` | 终止当前命令 |
| `ctrl+z` | 停止当前命令（进入后台） |
| `ctrl+d` | 退出当前会话 |
| `ctrl+w` | 删除当前行中的一个单词 |
| `ctrl+u` | 删除整行 |
| `ctrl+r` | 输入以调出最近的命令 |
