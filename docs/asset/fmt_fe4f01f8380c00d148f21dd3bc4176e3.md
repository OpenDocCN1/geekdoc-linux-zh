
### Domain Name
域名用于识别计算机属于特定的组织。域名在本质上是层次化的，层次结构中的每一层都用点（读作“dot”）与其他层分隔。例如，Foo 公司的财务部可能会使用域名 `finance.foo.com.`。

### Driver
参见 Device Driver。

### 双引导 (Dual Boot)

将计算机系统配置为启动多个操作系统的行为。这个名字有些误导性，因为可以启动比“双”字暗示的两个更多的操作系统。

#### EIDE

增强集成驱动器电子（Enhanced Integrated Drive Electronics）的缩写，它是 IDE 接口标准的新版本，也是 IDE 设备特定实现的另一个术语。EIDE 使更大更快的磁盘驱动器成为可能；今天大多数系统都使用 EIDE。

#### Errata

错误列表。Errata 是拉丁语，意为“哎呀”。当发现软件有 Bug 时，通常会修复软件并作为错误列表发布。Red Hat Linux 也不例外；我们有一个错误列表网页 `http://www.redhat.com/errata`。

#### Extended Partition (扩展分区)

包含其他分区的磁盘驱动器分段。参见 Partition（分区）。

#### FAQ

常见问题解答（Frequently Asked Questions）的缩写。Linux 信息通常以问答形式的 FAQ 呈现。

#### fdisk

`fdisk` 是一种用于在磁盘上创建、删除或修改分区的实用程序。

#### Filesystem

文件系统是存储在磁盘驱动器上存储信息的方法。不同的操作系统通常使用不同的文件系统，使得在两个操作系统之间共享磁盘驱动器的内容变得困难。然而，Linux 支持多个文件系统，例如可以读写专门用于 Windows 的分区。

#### Floppy (软盘)

一个带有历史色彩的术语，指可拆卸卡盒中的小型质存储设备，旨在兼容设备中进行读写。参见“diskette”。

#### Formatting (格式化)

在磁盘驱动器上写入文件系统的行为。

#### FQDN

全限定域名（Fully Qualified Domain Name）的缩写。FQDN 是包含计算机主机名和相关域名的类可读名称。例如，给定主机名为“foo”，域名为“bar.com”，则 FQDN 为“foo.bar.com”。

#### FTP

文件传输协议（File Transfer Protocol）的缩写。正如其名，允许从一个系统到另一个拷贝文件。

#### Gateway (网关)

在网络术语中，连接一个或多个计算机与其他网络的设备。可以是专用硬件（如路由器），也可以作为网关的通用计算机系统。

#### Geometry (几何结构)

指磁盘驱动器时，磁盘内部组织的物理特征。注意磁盘可能会报告与其“物理几何结构”不同的“逻辑几何结构”。参见 Cylinder（磁柱）、Head（头）。

#### GID

组 ID（Group ID）的缩写。Red Hat Linux 各部分识别用户在组中身份的手段。GID 是数值的，尽管类可读名称存储在 `/etc/group` 中。

#### Group (组)

为某些用户类分配权限的方式。例如，所有参与 Project X 的用户都可以加入 xproj 组。系统资源（如磁盘空间）可以配置为仅允许 xproj 成员访问。

#### Hard Disk (硬硬盘)

硬硬盘包含快速旋转的磁介（盘状）。微小的头悬浮在每个磁盘的表面，并在磁盘旋转时对其进行写入和读取。

#### Head (头)

指磁盘驱动器时，磁盘驱动器内部读写头的数量。例如，磁盘驱动器中的每个盘片通常有两个头——每个表面一个，尽管一个表面可能未被使用。参见 Geometry。

#### Hostname (主机名)

主机名是用于识别特定计算机系统的类读字符串。

#### I18n

参见 Internationalization（国际化）。

#### IDE

集成驱动器电子（Integrated Drive Electronics）的缩写，它是用于将磁盘驱动器和 CD-ROM 驱动器连接到计算机系统的标准接口。参见“EIDE”和“ATAPI”。

#### Intel

生产 PC 最常用微器的公司。这些处理器包括 80386、80486、Pentium Pro 和 Pentium II。

#### Internationalization (国际化)

设计和编写可以容易配置为以多种语言与用户交互的程序的实践。由于起始字母“i”和结尾“n”之间的字母数量，通常被称为“i18n”。

#### IP Address (IP 地址)

IP 地址是在 TCP/IP 网络上识别单个计算机系统（严格准确地说是这些计算机系统的网络接口）的方法。所有 IP 地址由四个数字块组成，每个范围从 0 到 253，并用点分隔。

#### Kernel (内核)

操作系统的核心部分，操作系统的其余部分在此基础上。

## 术语表

### 库 (Library)
在论及计算机时，指的是执行程序通常所需的操作的例程集合。库可以是共享的，这意味着库例程存在于与使用它的程序分离的文件中。库也可以被“静态链接”到程序中，这意味着该程序所需的库例程副本被物理地附加到程序中。此类静态链接的二进制文件在执行时不需要任何库文件。与库链接的程序在未安装所需库的情况下，将无法执行。

### LILO
一种用于基于 Intel 兼容处理器的 Linux 系统的常用自引导装载程序。

### 林纳斯·托瓦尔斯 (Linus Torvalds)
在其大学学生期间于 1991 年创建了 Linux。

### Linuxconf
一个由 Jacques Gelinas 编写的多功能系统配置程序。Linuxconf 通过几种不同的用户界面提供了一种基于菜单的系统配置方法。

### Linux
一种最初由林纳斯（Linus Torvalds）开发的、功能完备、健壮且免费获取的操作系统。

### 逻辑分区 (Logical Partition)
存在于扩展分区中的分区。参见“分区 (partition)”和扩展分区。

### 主引导记录 (Master Boot Record)
主引导记录 (MBR) 是磁盘驱动器存储空间的一个区域，用于保存启动个人计算机自引导过程开始所需的信息。

### MBR
参见“主引导记录 (Master Boot Record)”。

### 内存 (Memory)
在论及计算机时，内存（泛指）是指任何可以存储数据供检索的硬件。在此背景下，内存通常特指 RAM。

### MIL
一种用于基于 Alpha 处理器的 Linux 系统的常用自引导装载程序。

### 模块 (Module)
在 Linux 中，模块是执行系统级函数的例程集合，并可以根据需要从运行的内核中动态加载和卸载。模块通常包含设备驱动程序，它们与内核版本紧密绑定；从一个内核版本构建的大多数模块无法在运行另一个内核的系统上正常加载。

### 挂载点 (Mount Point)
文件系统在挂载后可以访问的目录。

### 挂载 (Mount)
使文件系统对系统用户变得可访问的行为。

### 名称服务器 (Nameserver)
在 TCP/IP 网络术语中，名称服务器是一种计算机，可以将人类可读名称（如“foo.car.com”）翻译为数字地址（如“10.0.2.14”）。

### 网络掩码 (Netmask)
网络掩码是一组由点隔开的四个数字块。每个数字表示为八位二进制数的十进制等值，这意味着每个数字可以取 0（所有位清零）到 255（所有位置1）之间的任何值。每个 IP 地址由两部分组成（网络地址和主机号）。网络掩码用于确定这两个部分的大小。网络掩码中被置1位的位置被认为代表预留给网络地址的空间，而被清零的位被认为代表预留给主机号的空间。

### NFS
网络文件系统（Network File System）的缩写，NFS 是一种让远程系统上的文件系统在本地系统中可访问的方法。从用户的角度来看，NFS 挂载的文件系统与直接连接的磁盘没有区别。

### 操作系统 (Operating System)
控制计算机各种资源的软件集合。

### 软件包 (Packages)
包含软件的文件，并以特定格式编写，该格式允许软件易于安装和卸载。

### PAM
可插认证模块（Pluggable Authentication Modules）的缩写。PAM 是一种控制 Red Hat Linux 访问的认证系统。

### 分区 (Partition)
磁盘驱动器存储空间的一个片段，可以像磁盘驱动器一样被访问。

### 分区表 (Partition Table)
分区表是磁盘驱动器存储空间的一个区域，用于定义该磁盘驱动器上的分区。

### 分区类型 (Partition Type)
分区包含一个字段，用于定义分区将包含的文件系统类型。分区类型实际上是一个数字，尽管许多时候通过名称引用分区。例如，“Linux 原生”分区类型是 82。注意，此数字是十六进制的。

### PC 卡 (PC Card)
参见 PCMCIA。
