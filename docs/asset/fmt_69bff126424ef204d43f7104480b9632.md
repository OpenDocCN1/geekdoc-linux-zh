
# 伪色彩曝光控制 (Pseudo Color Exposure Control)

伪色彩仅用于分析来自辐射解决方案的光照数据。对于受益于此类仿真生成的真实世界数据的灯光设计师来说，这种分析可能是无价之宝。该界面与其他曝光控制算法非常不同，因为其目的也完全不同。

| | 伪色彩曝光控制 | |
|---|---|---|
| **显示类型 (Display Type)** | **显示范围 (Display Range)** | |
| | 数量照度 (Quantity Illuminance) | 最小值 (`Min.`): `0.0 lx` |
| | 样式 (Style) | 最大值 (`Max.`): `80.0 lx` |
| | 比例尺 (Scale) | 坎拉 (`cd`) |
| | 物理比例尺 (Physical Scale) | `1500.0` |

# 亮度与照度 (LUMINANCE AND ILLUMINANCE)

亮度是人眼感知的表面明暗程度。照度是单位时间内单位面积接收的光通量，它是掉落在表面上的光能量。

## 亮度与照度（Luminance and Illuminance）

有一个专门针对灯光工程师和设计师的工具，与伪色彩控制配合使用，称为光照分析（`Lighting Analysis`）。让我们开启伪色彩时查看场景照照度数据，如图 11.35 所示：

1.  在选择 渲染（`Rendering`） > 环境（`Environment`）时，开启光照分析（`Lighting Analysis`）。
2.  你的光标显示吸管器符号。在显示伪色彩的场景中点击并拖动。
3.  切换到前视口并选择灯罩（`Hood`）对象。放大灯罩与 `Arm02` 相交的区域。

**图 11.35**

# 组装关节灯具 (Assembling an Articulated Luminaire)

在本节中，你将学习如何创建一个连接光源线条界面参数的组装。这种组装结构在 `VIZ` 中被称为灯具。

你将学习运动学（`Kinematics`）的基础，以便连接台灯的关节。运动学是关节运动的研究，你将通过台灯模型学习正向运动学和反向运动学的区别。完成后，你将拥有一个可以快速放入工作场景并以友好方式调整的灯具。

# 变换中心点 (Transforming Pivot Points)

你首先通过调整示例模型的中心点，为在层级中连接其关节做好准备。这些对象（底座外）每一个都有两个部分汇的关节。每个部分的中心点必须与该对象的旋转轴重合。

1.  从 `Sybex` 网站打开 `Luminaire01.max` 文件。场景如图 11.37 所示。
2.  检查这个简单灯模型的部件。按下键盘上的 `H` 打开选择对象对话框。这盏灯有五个部分：`Arm01`、`Arm02`、`Base`、`Hood` 和 `Swivel`（旋转）。选择每个对象并在屏幕上识别它。
3.  切换到前视口并选择灯罩（`Hood`）对象。放大灯罩与 `Arm02` 相交的区域。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_586_0.png)

![](img/7e143440dd5a0ed9683d4f26f3c074f8_586_1.png)

**图 11.37**

光照分析数值数据

![](img/7e143440dd5a0ed9683d4f26f3c074f8_587_0.png)

4.  点击命令面板的“层级”（`Hierarchy`）选项卡。点击“轴心”（`Pivot`）按钮，并在移动/旋转/缩放点组中开启“仅影响轴心”（`Affect Pivot Only`）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_587_1.png)

## 将光源与灯具对接

你可能会注意到已经建模了一个灯泡几何体以适应台灯的灯罩。接下来你将添加光源：

1.  点击命令面板的“创建”（`Create`）选项卡并选择“灯光”（`Lights`）类别按钮。从下拉列表中选择“光度”（`Photometric`），并在“对象类型”（`Object Type`）展开栏中点击“目标点”（`Target Point`）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_588_0.png)

2.  在顶视图（`Top viewport`）中拖出一个目标点，无需考虑其位置或其目标点的位置。
3.  在顶视图和前视图中，将该点本身移动到灯泡内部。
4.  右键点击顶视图以激活它；然后选择 `Point01.Target` 并按下 `Alt+A` 调用“对齐”（`Align`）命令。
5.  不要尝试直接对齐对象，而是选择“选取对象”（`Pick Object`）对话框（该框与“选择对象”对话框几乎相同），从列表中选择 `Point01`。
6.  在“对齐选择”（`Align Selection`）框中，勾选 `X` 位置和 `Y` 位置，并取消勾选 `Z` 位置。在“当前”（`Current`）和“目标”（`Target`）单选按钮中选择“中心”（`Center`），以将目标直接对齐到其下方，如图 11.38 所示。完成后点击确定 接受更改并关闭对话框。
7.  选择 `Point01` 并切换到命令面板的“修改”（`Modify`）选项卡。
8.  在“强度/颜色/分布”（`Intensity/Color/Distribution`）展开栏中，展开“分布”下拉列表并将分布更改为“聚光灯”（`Spotlight`）。将灯泡颜色设置为“卤素”（`Halogen`）。
9.  将强度更改为 `3,000` 坎拉（`candelas`），点击“倍数”（`Multiplier`）复选框激活此功能。`100%` 即 `3,000` 坎拉的 `100%`。

## 图视图 (SCHEMATIC VIEW)

图视图是为复杂的角色动画设计的，从 `3ds Max` 引入 `VIZ`。对图视图的全面探索超本书的范围。

图视图提供了“连接已选”（`Connect`）和“取消链接已选”（`Unlink Selected`）工具，允许你设置层级结构，使得一个对象（父级）的变换根据父级轴心点影响其他对象（子级）。你可以按照你正在链接的模型结构来排列节点，这为你想要制作动画的运动学链提供了视觉参考。

1.  点击主工具栏上的“图视图（打开）”按钮。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_589_1.png)

2.  点击图视图工具栏上的“连接”（`Connect`）按钮，如图 11.39 所示。
3.  点击 `Point01` 节点，在图视图中拖动一条链接到 `Hood` 节点。当你拖动时，光标将变为“连接”图标，并有一条“橡皮筋”连接你的光标和 `Point01` 节点。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_590_0.png)

> **注意**：在图视图中拖动节点时，始终从子节点拖动到父节点。在灯的案例中，你希望 `Hood` 的变换传递给 `Point01`。

4.  通过在两个节点之间拖动链接，连接 `Point01.Target` 与 `Hood`。现在称 `Hood` 是点光源及其目标的父级（`Point01` 和 `Point01.Target` 是该家族中的兄弟节点）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_590_1.png)

5.  继续在图视图中建立关系，将 `Hood` 链接到 `Arm02`。然后连接 `Arm02` 到 `Arm01`。`Arm01` 应该链接到 `Swivel`（旋转关节），最后 `Swivel` 应该是 `Base`（底座）的子级。完成后，你的层级结构应该像图 11.40。注意整个家族都由 `Base` 的子级组成。设计如此，以便你通过 `Base` 移动整个模型。
