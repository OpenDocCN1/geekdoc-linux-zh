# pr — 打印文件

### 概要

```
/usr/bin/pt+page [-column] [-adFmrt] -e[char] [gap] [-header] -i[char][gap] [-1 lines] -n[char][width] -o offset [-s[char]] [-w width] [-fp][file...]

/xpg4/bin/pr [+page] [-column] [-adFmrt] -e[char] [gap] [-h header] -i[char][gap] [-1 lines] -n[char][width] -o offset [-s[char]] [-w width] [-fp][file...]
```

## 描述

`pr` 命令是一个打印和分页过滤器。如果你指定了多个输入文件，每个文件将被读取、格式化并写入标准输出。默认情况下，输入被分为 66 行一页，每页具有：如果标准输出与终端关联，诊断消息将延迟到 `pr` 命令处理完成。如果你指定了多列输出选项，文本列宽度相等；无法放入文本列的输入行将被截断。默认情况下，文本列之间至少有一个空格字符分隔。

## 选项

在接后的选项描述中，`column`、`lines`、`offset`、`page` 和 `width` 是正十整数；`gap` 是非负整数。某些参数是可选的，某些参数不能作为与前一个选项字母分开的参数指定。特别是 `-s` 选项要求将选项字母与其参数保持在一起，而

`options -e, -i, -n` 要求如果这两个参数都存在，则必须与选项字母连用。

`/usr/bin/pr` 和 `/usr/xpg4/bin/pr` 均支持以下选项：

- `+page` 从格式化后的输入的第 `page` 页开始输出。
- `-column` 产生按 `column` 列排列的多列输出（默认值为 1），并按照从输入文件中接收到文本的顺序按列顺序向下写入每一列。不要与 `-m` 一起使用此选项。假设 `-e` 和 `-i` 选项用于多列文本输出。文本列是否具有相同的顶点对齐尚未指定，但文本列的长度永远不会达到页面的长度（见 `-l` 选项）。与 `-t` 配合时，使用最少行数写入输出。
- `-a` 修改 `-column` 选项的效果，使列按轮询顺序跨越页面进行填充（例如，当 `column` 为 2 时，第一行位于第 1 列，第二行位于第 2 列，第三行是第 1 列的第二行，依此类推）。
- `-d` 产生双倍间距输出；在输入中的每个换行符之后追加一个额外的换行符。
- `-e[char] [gap]` 将每个输入的 Tab 字符扩展到由公式 `n*gap+1` 指定的下一个列位置，其中 `n` 是大于 0 的整数。如果省略 `gap` 或其为 0，则默认为 8。将输入中的所有 Tab 字符扩展为相应数量的空格字符。如果指定了任何非数字 `char`，则使用其作为输入 Tab 字符。
- `-f` 使用换页符作为新页，而不是使用默认的系列换行符行为。如果标准输出关联到终端，则在开始第一页之前暂停。
- `-h header` 使用字符串 `header` 替换文件操作数的页眉内容。
- `-l lines` 覆盖默认的 66 行，并将页面重置为 `lines` 行。如果 `lines` 不大于头部和页尾深度（以行计）之和，则抑制头部和页尾，且如果 `-t` 选项生效。
- `-m` 合并文件。格式化标准输出，将由 `file` 指定的每个文件的行并排写入具有相等固定列位置宽度的文本列中。实现方式支持合并至少九个文件。

```
-n[char] [width]
```

提供宽度 `width` 数字行号（`width` 默认为 5）。该数字占据默认输出中每个文本列或 `-m` 输出中每行的前 `width` 列位置。如果你指定了 `char`（任何非数字字符），则将其附加到行号之后以与随后的内容分离（`char` 默认为 Tab 字符）。

将每行偏移 `offset` 个空格。如果你未指定 `-o` 选项，默认偏移量为 0。所占的空间是输出行之外的额外（见 `-w` 选项）。

如果标准输出定向到终端，则在开始每一页之前暂停（向标准错误写入一个 ALERT 字符并等待在 `/dev/tty` 上被读取）。

在打开文件失败时不写入诊断报告。

使用单个字符 `char` 分隔文本列，而不是相应数量的空格字符（`char` 默认为 Tab 字符）。

不写入通常为每页提供的 5 行页眉或 5 行页尾。在每个文件的最后一行后停止写入，不留空到页末尾。

仅对多列文本输出设置行宽为 `width` 列位置。如果你未指定 `-w` 选项并指定了 `-s` 选项，默认宽度为 72。如果你未指定 `-w` 选项并指定了 `-s` 选项，默认宽度为 512。对于单列输出，输入行不会被截断。

## /usr/bin/pr

以下选项仅由 `/usr/bin/pr` 支持。

- `-` 折叠输入文件的行。在多列模式下（带有 `-a` 或 `-m` 选项）使用时，折叠行以适应当前列的宽度；否则，折叠以适应当前行宽（80 列）。
- `-i` 在输出中，当一个或多个相邻空格达到列位置 `n*gap+1`、`2*gap+1`、`3*gap+1` 等时，将空格替换为 Tab 字符。如果 `gap` 为 0 或被省略，则在每八个列位置设置默认 Tab。如果你指定了任何非数字字符 `char`，则使用其作为 Tab 字符。

## /usr/xpg4/bin/pr

以下选项仅由 `/usr/xpg4/bin/pr` 支持。

- `-f` 使用换页符作为新页，而不是使用系列换行符的默认行为。

## pr 1047

`-i [char] [gap]`

在输出中，每当两个或多个相邻空格字符达到列位置 `n*gap+1`、`2*gap+1`、`3*gap+1` 等时，将多个空格字符替换为 Tab 字符。如果 `gap` 为 0 或被省略，则在每八个列位置设置默认 Tab。如果指定了任何非数字字符 `char`，使用其作为输出 Tab 字符。

## 操作数 (Operands)

`file`
要写入的文件路径名。如果你未指定操作数，或操作数为为 `-`，则使用标准输入。
