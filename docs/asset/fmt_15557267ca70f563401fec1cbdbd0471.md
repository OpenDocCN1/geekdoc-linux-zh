## 前言

本 IBM 红书讨论了 UNIX 到 UNIX 的跨平台数据共享和用户/系统管理。本红书还演示了 AIX 和 Linux 操作系统之间的相似之处。

本红书旨在帮助拥有 AIX 系统的 IT 专家了解如何在 Linux 环境中集成并优化 AIX 系统，并与其共享资源。我们将描述重点放在以下领域：

- 用户管理
  - 身份识别与验证
  - 集中用户管理
  - 单点登录
- 网络
  - 网络服务
  - Sendmail
  - NFS
- 数据共享
  - Samba 文件和打印服务器
  - 文件系统和数据归档
  - 打印共享
- 系统管理
  - 安全
  - 系统管理应用
  - 用于 IBM eServer pSeries 和 RS/6000 的 Linux
