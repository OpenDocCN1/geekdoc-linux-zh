
## psstoedit
用于编辑矢量图形内容的 PostScript 和 PDF 文件。`psstoedit` 将 PostScript 和 PDF 文件转换为各种可编辑的矢量图形，包括 `tfig`, `xpdf`, `graphics`, `gformat`, `idraw`, `MetaPost`, `GNU Meta`, `PIC`, `Contour` 和展化的 PostScript。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html

## pstotext
从 PostScript 和 PDF 文件中提取文本，`pstotext` 从 PostScript 或 PDF（便携文档格式）中提取（ISO 8859-1 字符）集。因此，`pstotext` 类似于 ghostscript 自带的 `ps2ascii` 程序。`pstotext` 的输出优于 `ps2ascii`。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html

## psutils

## 基础 ASCII pTeX 文件
ASCII pTeX 是一种日本 TeX 分发版。与 `ptex–bin` 一起使用，你就拥有了一个完整的安装。包括：`platex` 来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## ASCII pTeX 二进制文件
这是 ASCII pTeX，一种日本 TeX 分发版。pTeX 系统的所有二进制文件。你至少需要配合使用 `ptex–base`。包括：`platex` 来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## 构建 ASCII pTeX 的支持文件
此包包含晚期 TeX 工具栏的片段（将存放在 `/usr/src`）。由于 ASCII pTeX 是作为 TeX 源码的一组额外文件提供的，当你已经有 `ptex–bin` 时，不需要安装此包。还包含一个用于提取大 tar 包的小脚本。你不需要安装此包即可拥有运行 pTeX 系统。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
