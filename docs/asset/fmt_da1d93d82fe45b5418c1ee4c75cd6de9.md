
# Kandy
KDE 的手机程序。目前 Kandy 大多是一个具有存储命令及其参数的一些功能的终端程序，但也有简单的 GUI 访问手机，并将手机保存到 KDE 通讯录中。Kandy 针对集成 (GSM) 模块的手机。源自 Debian 3.0r APT

http://www.tld.org/LDP/Linux–Dictionary/html/index.html

# kannel
WAP 和 SMS 网关。Kannel 是一个连接 Wap（无线应用协议）到互联网的网关。它还是一个 SMS 网关，为 GSM 提供基于 SMS 的服务。源自 Debian 3.0r APT

http://www.tld.org/LDP/Linux–Dictionary/html/index.html

# kapptemplate
创建开发 KDE 应用的框架。KappTemplate 是一个脚本，将创建开发各种 KDE 应用所需的框架。它还负责代码，提供代码骨架和典型代码的示例。此包是 KDE 开发工具包的一部分。源自 Debian 3.0r APT

# kaptain
命令行程序的图形化前端（KDE 版本）。Kaptain 是一个基于上下文无关文法的图形化前端 (KDE)。程序 captain 控制一个包含生成文本语法规则的文件。它根据语法构建对话框并根据用户的设置生成文本。如果你不需要，还有该包的 Qt 版本 (captain)。
