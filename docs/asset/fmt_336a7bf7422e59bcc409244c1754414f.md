### 关于文件的一切

Linux 与 Unix 不同，它将一切都视为文件。换句话说，硬盘等设备的名称是其驱动程序的文件地址。例如，`/dev/hda` 是第一个 IDE 硬盘的名称，`/dev/sdb` 是第二个 SCSI 硬盘的名称。

由于 Linux 不使用字母来指定每个驱动器，它简单地将它们插入树结构中。例如，`/dev/hda1` 可能挂载在 `/`，`/dev/hda2` 挂载在 `/home`。这意味着 `/home` 目录中的所有文件都位于分区 `/dev/hda2` 上，而其余都在 `/dev/hda1` 上。分区或驱动器挂载的目录被称为挂载点（mount point）。

字母指的是分区所在的设备。例如，IDE 驱动器被命名为 `hda`、`hdb`、`hdc` 等。SCSI 驱动器被称为 `sda`、`sdb`、`sdc` 等。`hd` 代表硬盘（hard drive），`sd` 代表 SCSI 驱动器。

通常情况下，你的目录结构中至少需要一个根分区和一个交换空间。因此，你应该设置最少类型的磁盘空间：一个从根目录开始的 Linux 文件系统和一个交换空间。

数字指定分区。Linux 仅支持四个分区，但其中一个可以是扩展分区。数字 1、2、3 和 4 表示分区；逻辑分区从 5 开始。`/dev/hdb3` 是第二个 IDE 硬盘上第三个分区的名称。在 SCSI 世界中，`/dev/sdc6` 是第三块硬盘上第二个逻辑分区的名称。

最好为你的用户文件设置一个独立的分区（通常是 `/home` 目录），为你的 Linux 设置多个分区更好。

Linux 文件系统由一个或多个挂载的分区组成。

使用 `cdisk`，你可以看到所有分区。你可能想要删除一个或多个分区，或者将它们划分为更小的 Linux 分区。

### 内核位置限制

- 如果你没有 IDE 驱动器但有 SCSI 驱动器，根分区必须位于 ID 0 或 ID 1 上；其他 SCSI ID 无法工作。
- 你的 Linux 内核必须位于 1023 磁道以下。这是因为 BIOS 无法“看到”磁盘上第 1023 磁道之后的内容。Linux 的主要引导过程被称为 `LILO`，它的功能依赖于 BIOS；如果 Linux 内核超过了 1023 磁道，`LILO` 将无法找到它并启动引导过程。

在 IDE 驱动器上，1023 磁道通常在 512MB 标记以下；对于 SCSI 驱动器，它通常在 1GB 以下。确保内核位于 0 到 1023 磁道之间最简单的方法是在进行磁盘分区时使用 `fdisk` 程序指定此范围。较新版本的 BIOS 支持逻辑块寻址（LBA），因此它们可能不受此限制。
