## 水文学

研究地球的水：其发生、循环和分布，及其化学和物理性质；以及它们与环境（包括与生物的关系）的反应。参见[陆地水](https://example.org/terrestrial_water)。

液态和固态的水覆盖了地球地壳的大部分地区。通过一个由重力和太阳辐射能驱动的复杂过程，水蒸气、液态和固态水在大气、海洋和地壳之间进行着无休止的交换。这被称为水文循环。水在空气和海洋中循环，也在陆地表面和地下流动。地球上的水分布是不均匀的。大气、海洋和陆地中存在一般的循环模式，但区域特征非常不规则，细节上看似随机。因此，虽然因果关系是整个过程的基础，但人们认为重要的随机因素会影响局部水文事件。参见[大气环流](https://example.org/atmospheric_general_circulation)。

尽管公认了水文循环的全球联系，但水文学传统上将其直接关注点局限于由陆地物理边界限定的循环部分的详细研究；因此，它通常排除了对海洋（这是海洋学研究的对象）和大气（这是气象学研究的对象）的专门研究。然而，对人为引起的环境影响的关注日益增加，突显了水文循环在全球物质、热量和能量传输与预算中的关键作用。水文学已被认可为关注局部、区域和全球尺度过程的一门科学。这种增强地位加强了其与气象学、气候学和海洋学的联系。参见[气候学](https://example.org/climatology)；[气象学](https://example.org/meteorology)；[海洋学](https://example.org/oceanography)。

水文研究进行多种现场测量。其中包括：

- 降水的量和强度；
- 以雪和冰形式储存的水量及其随时间的变化；
- 河流的流量；
- 入渗土壤的速率和水量，以及土壤水分的运动；
- 井的出水量及其水位变化作为地下水储存的指标；
- 地表水和地下水中化学元素、化合物和生物组分的浓度；
- 由雪、湖泊、河流、土壤和植被通过蒸发和蒸腾转移到大气中的水量；以及
- 从陆地流失并由河流输送的沉积物。

此外，水文学还关注水文循环中所有物理和生物组分的现象和机制研究，目的是充分理解它们，从而允许进行定量预测和预报。现场调查和测量不仅提供评估每个组分行为详情的数据，允许以定量术语进行公式化，而且提供整个系统历史表现的记录。因此，水文预报和预测有两个主要载体：一组基本过程，其运算可以用数学术语表达，链接形成确定性模型，允许在给定条件下预测水文事件；以及一组测量水文变量（如降水或径流）的记录或时间序列，可以通过统计方法分析以建立随机模型，允许对水文事件的未来可能性进行推断。参见[地下水文学](https://example.org/ground-water_hydrology)；[水圈](https://example.org/hydrosphere)。 [Ma.Ma.]

## 水解

水分子分解分子的化学反应。应用于有机分子的水解可以看作是酯化和酰胺形成等反应的逆反应。展示了酯[反应(1)]和酰胺[反应(2)]的水解。其他可发生水解的有机化合物类别包括缩醛、缩酮、醛卤化物、缩酮和肽。虽然总的水解反应[如反应(1)和(2)]看似涉及水分子（H₂O）的加成，但该反应实际上更复杂。有几个反应步骤；例如，与质子 [H⁺，酸催化水解] 或氢氧根离子 [OH⁻，碱催化水解] 形成络合物，随后消除这些离子以得到总方程。水解反应在生物系统中经常遇到。这些反应的速率受酶（生物催化剂）如酯酶和肽酶的作用而大大加快。参见[酶](https://example.org/enzyme)；[氢离子](https://example.org/hydrogen_ion)。

`CH3COOC6H5 + H2O -> CH3COOH + C6H5OH (1)`

乙酸苯酯    乙酸  苯酚

`CH3CONH2 + H2O -> CH3COOH + NH3 (2)`

乙酰胺     乙酸  氨

在无机化学中，水解也称为水合（aquation），代表一类涉及金属配位复合物的反应，其中一个配位配体被 H₂O 或 OH⁻ 取代。水解是被称为配体取代反应的一类反应的特殊情况[反应(3)，其中 M 是金属，L 和 X 是配体，Y 是取代配体（水解反应中的 H₂O）]。参见[配位化合物](https://example.org/coordination_complexes)；[配体](https://example.org/ligand)。 [F.H.]

`MLm + Y -> LM + X (3)`

## 水解过程

有机和无机化学中的反应，其中水与另一种化合物发生双重分解，氢去往一个组分，羟基去往另一个组分，如反应(1)-(3)所示。虽然“水解”一词意味着被水分解，但水单独引起有效水解的情况很少见，通常需要高温和高压。参见[水解](https://example.org/hydrolysis)。水解反应可以分类如下：

- (1) 仅用水的水解；
- (2) 用稀酸或浓酸的水解；

`XY + H2O -> HY + XOH (1)`

`KCN + H2O -> HCN + KOH (2)`

`C6H13 O + H2O -> C6H13 OH + NaOH (3)`

### 稀碱或浓碱水解；高温下碱熔融水解，水用量极少或无。

在有机化学领域，“水解”一词的适用范围已扩展至涵盖大量向水中加入碱或酸的反应。碱水解过程的一个例子是酯的水解（反应(4)），

$$\mathrm{CH_3COOC_2H_5 + NaOH \rightarrow CH_3COONa + C_2H_5OH}\tag{4}$$

生成醇。酸性条件过程的一个例子是在磷酸存在下烯烃水解生成醇（反应(5)）。酸或碱的加入即使不引发反应，也能加速此类反应。

$$\mathrm{C_2H_4 + H_2O} \xrightarrow[\mathrm{phos.\ acid}]{\mathrm{H_3PO_4}}\mathrm{C_2H_5OH}\tag{5}$$

也许最古老且产量最大的水解技术涉及肥皂制造。第一步中，硬脂酸甘油酯（一种脂肪）与水水解生成硬脂酸和甘油。第二步中，硬脂酸与烧碱中和生成肥皂（硬脂酸钠）和水。参见 **脂肪** 和 **油**。

水解过程占据了巨大的产品产量。通过盐酸处理将淀粉（如玉米淀粉）转化为麦芽糖和葡萄糖（糖浆）是一个主要行业。同样，从燕麦壳或其他谷物副产品（如玉米芯、稻壳或棉籽壳）的戊聚糖中生产硫酸木浆是另一个商业化水解过程。[D.L.H]

## 湿法冶金

通过水溶液发挥主导作用的过程，从矿石中提取和回收金属的方法。湿法冶金涉及两个不同的过程：通过被称为浸出的操作将矿石中的金属组分溶解；以及从溶液中回收金属，通常是在适当的溶液纯化或浓缩步骤之后，或两者兼有。湿法冶金的范围非常广泛，不仅延伸到矿石处理，还包括金属精矿、金属废料和循环材料以及冶金过程中的中间产品的处理。湿法冶金进入了几乎所有有色金属和类金属（如硒和碲）的生产。湿法冶金和火法冶金过程相辅相成。参见 **浸出**，**火法冶金**。

湿法冶金在铝、铜、镍、钴、锌、金、银、铂、硒、碲、钨、钼、铀、锆以及其他金属的生产中扮演着重要角色。参见 **冶金**。[W.C.Co]

## 水文气象学

研究大气中水分的出现、运动及其状态变化的学科。该术语在更严格的意义上也被使用，特别是被水文学家用来指大气与大陆表面之间水分交换的研究。这包括 **降水** 和直接冷凝过程，以及来自自然表面的蒸发和蒸腾。对于特定地点或地理区域，降水随面积和时间变化的统计特性受到相当大的重视。

水在大气中主要以水蒸气或气态形式存在。每平方单位面积的水量平均值往往随海拔和纬度的增加而减少，并且随季节和地表类型强烈变化。可降水的水量（即可降水量），指从地球表面延伸至大气外层极限的空气柱中所含的单位面积水蒸气质量，从大陆极地空气中的接近零到非常湿润的热带空气中的约 6 g/m² 不等。
