
RAID 通过将两个或多个磁盘组合为一个逻辑设备来工作。RAID 有几层：
- `RAID 0`（条带化）将两个或多个磁盘组合为一个逻辑设备，不提供任何冗余。它通常结合 `RAID 1` 或 `RAID 5` 使用。
- `RAID 0+1` 称为 `RAID 10`。
- `RAID 0+5` 称为 `RAID 5`。
- `RAID 1`（镜像）结合两个具有相同数据的磁盘，其中一个专门用于校验。如果任何磁盘故障，整个逻辑设备仍然可用，但性能会下降。由于性能原因，它并不常用。
- `RAID 5` 结合三个或多个磁盘，并将校验分布在各个磁盘上。功能与 `RAID 4` 类似，性能更好。

尝试访问 `http://linux/softraid.htm` 获取更多信息。`RHEL` 有在初始操作系统安装过程中设置软件 RAID 的选项。简单的步骤在 `http://www.redhat.com/docs/manuals/linux/RHEL/7.2/custom-guide/software-raid.htm` 中概述。在 `RHEL` 安装期间，在“分区驱动”：

1. 创建类型为“软件 RAID”的新分区。你无法为单个分区指定挂载点——你可以指定每个分区的大小，使其变为“可增长的”，或强制将其作为主分区。
2. 点击磁盘屏幕上的“创建 RAID”按钮。
3. 在此处对话框中：输入 RAID 数组的挂载点、RAID 数组的分区类型、RAID 类型（你可以从 `RAID 0`、`1` 和 `5` 中选择）、RAID 成员（你创建的）以及备用数量（用于 `RAID 1` 或 `5`）。“备用”是 RAID 故障时将自动使用的分区。你应该为每个备用分区至少创建一个“RAID 类型”分区。
4. 点击“确定”，如果你的 RAID 数组显示正确，请检查“驱动摘要”。

注意：如果你为 `/boot` 创建 RAID 分区，选择 RAID 级别 1，它必须使用前两个驱动之一（`IDE` 优先，`SCSI` 次之）。如果你在为 `/` 创建 RAID 分区，选择 RAID 级别 1，它必须使用前两个驱动之一（`IDE` 优先，`SCSI` 次之）。

### 8.5.2 使用 `MySQL` 设置数据库

第一步。为 `MySQL` 设置 `root` 密码。如果没有 `root` 密码，任何人都可以从本地以 `root` 权限登录你的 `MySQL` 数据库，如果你打算保留任何可用的数据，这可能是不利的。

```
mysqladmin --user=root password my_root_password
```

如果你想为特定用户（包括 `root`）创建一个密码，请使用以下语法（在这种情况下，用户的密码从 "my_root_password" 更改为 "MY NEW root_password"）：

```
mysqladmin --user=root password=my_root_password 'My New root_password'
```

第二步。创建一个用于操作的数据库。这通常是你实际安装 `MySQL` 的原因。

```
mysqladmin --user=root password=my_root_password create_database
```

第三步。登录 `MySQL`

```
mysql --user=root -pmy_root_password
```

一旦登录，你应该看到类似这样的显示：

```
Welcome to the MySQL monitor. Commands end with : \
Your connection to the server version: 2.23.56
Type 'help' or 'h' for help. Type \c to clear the buffer.
mysql>
```

最后的 "mysql" 代表提示符。

第四步。创建一个可以在 "my database" 中读写数据表的用户。为了实现这一点，我以 `root` 权限登录 `MySQL` 后使用了 `GRANT` 命令。

```
mysql> GRANT SELECT,INSERT,UPDATE,DELETE,CREATE,DROP,ALTER
-> ON my_database.* TO 'peter';
-> IDENTIFIED BY 'password';
```

注意，`MySQL` 只有在命令以分号结束时才会处理该命令。输入后，你将获得类似下面的输出：

```
Query OK, 0 rows affected (0.00 sec)
mysql>
```

退出 `MySQL` 只需输入：

```
mysql> exit
```

现在你可以用新用户账户登录 `MySQL` 并开始构建你的新数据库。

```
mysql --user=peter --password='peter_password' my_database
```

第五步。在 `my_database` 中创建一个表。使用 `CREATE TABLE` 命令来添加一个表。语法如下：

```
CREATE TABLE [table_name] ([column name] [column type] [DEFAULT value],...)
```

我的命令看起来像这样：要修改你创建的表，请使用 `ALTER TABLE` 命令。要向表中添加一个名为 "height"、类型为 `REAL` 且默认值为 `NULL` 的列，我使用以下命令：

```
CREATE TABLE table_name (person TEXT "", age INTEGER 0);
ALTER TABLE table_name ADD COLUMN (height REAL NULL);
```

第六步。向表中填充值。注意，当你输入值时，它们的顺序必须与列的顺序一致。使用 "NULL" 表示空值。

```
mysql> INSERT INTO my_table VALUES('Bill',20,184);
```

你也可以从一个 `ASCII` 制表符分隔的文件填充表。为了做到这一点，你必须在登录时向 `MySQL` 传递选项 `--local-infile`，然后调用 `LOAD DATA` 命令。

```
mysql --local-infile --user=peter --password='peter.password' my_database
mysql> LOAD LOCAL INFILE "my_data_filename" INTO TABLE my_table;
```
