# msgfmt — 从消息文件创建消息对象

### 概要

`/usr/bin/msgfmt [-v] [-o output-file] filename.po...`

## 描述

`msgfmt` 从可移植对象文件（`filename.po`）创建消息对象文件，而不会更改可移植对象文件。

`.po` 文件包含由系统命令或应用程序显示给用户的消息。你可以编辑 `.po` 文件并用系统支持的任何语言重写其中的消息。

你可以使用 `xgettext()` 命令从脚本或程序创建 `.po` 文件。

`msgfmt` 根据当前 `LC_TYPE` 语言区域类别的设置将数据解释为字符。

> 注意 — `msgfmt` 还是任何 `anygettext()` 例程均未对消息的总长度设置限制。然而，`*.po` 文件中的每一行受限于 `MAX_INPUT` (512) 字节。

在 C 语言环境下安装消息目录是没有意义的，因为为了效率，它们会被忽略。

# 可移植对象文件

所有 `.po` 文件的格式都是相同的。每个 `.po` 文件包含一个或多行，每行以哈希标记 (`#`) 开头并以换行符结束。所有注释都被忽略。语句的格式为：

`directive value`

每个指令从行首开始，并通过空白（一个或多个空格或制表符）与值分隔。`value` 由一个或多个由空白分隔的引用字符串组成。可以使用以下任何类型的指令：

`domain domainname`
`msgid message_identifier`
`msgstr message_string`

`domain` 指令的行为受所用选项的影响。参阅第 838 页的“选项”部分以了解指定 `-o` 选项时的行为。

+ * 将从每个 `.po` 文件从开始到第一个 `domain` 指令的所有 `msgids` 放入一个默认消息对象文件 `messages.mo` 中。
+ - 当 `msgfmt` 在 `.po` 文件中遇到 `domain domainname` 指令时，将下一个 `domain` 指令之前的所有 `msgids` 放入消息对象文件 `domainname.mo` 中。
+ - 在每个 `domain` 的作用范围内定义重复的 `msgids`。也就是说，只有当相同的 `domain` 中存在相同的 `msgid` 时，该 `msgid` 才被视为重复。
+ - 忽略重复的 `msgids`。
+ - `msgid` 指令指定与其后续指令关联的 `msgid` 标识符的值。`message_identifier` 字符串标识了在检索时使用的目标字符串。每个包含 `msgid` 指令的语句必须紧跟一个包含 `msgstr` 指令的语句。
+ - 这里的
+ - 消息字符串可以包含转义序列：`\n`（换行）、`\v`（垂直制表符）、`\r`（回车）、`\f`（分页）、`\\`（反斜杠）、`\"`（双引号）、`\dd`（八进制模式）和 `\xDD`（十六进制模式）。

## 选项

+ -v 列出重复的消息标识符。消息字符串不会被重新定义。
+ -o `output-file` 指定输出文件名为 `output-file`。忽略 `.po` 文件中的所有 `domain` 指令和重复的 `msgids`。

## 示例

在以下示例中，`module1.po` 和 `module2.po` 是可移植消息对象文件。

```
cat module1.po

# default domain "messages.mo"

msgid "msg 1"

msgstr "msg 1 translation"

#ndomain "help_domain"

msgid "help 2"

msgstr "help 2 translation"

#ndomain "error_domain"

msgid "error 3"

msgstr "error 3 translation"

cat module2.po

# default domain "messages.mo"
```

```
msgid "mesg 4"

msgstr "mesg 4 translation"

#

domain "error_domain"

msgid "error 5"

msgstr "error 5 translation"

#

domain "error_domain"

msgid "window 6"

msgstr "window 6 translation"
```

# mt — 磁带控制

### 概要

`/usr/bin/mt [-f tapename] command... [count]`

## 描述

`mt` 向磁带驱动器发送命令。

# Bug

并非所有设备都支持所有选项。某些选项取决于硬件。参阅设备手册。不支持异操作。

## 选项

`-f tapename` 指定磁带设备。

## 参数

+ `count` 请求的操作执行的次数。默认情况下，`mt` 执行一次命令；你可以指定多次操作。
+ `command` 可以发送到磁带驱动器的可用命令。
* `eom` 到磁带上记录材料的末尾。适用于向已写入的磁带追加文件。
* `rewind` 回带磁带并在适当的情况下通过卸载磁带使驱动器离线。驱动器循环所有磁带。
* `status` 打印磁带的状态信息。
* `retention` 完全回带磁带，然后向前绕带直到开头，以消除磁带张力。
* `reserve` 允许磁带驱动器在关闭设备后保持保留状态。必须显式释放。
* `release` 重新建立释放的默认行为。
* `forceres` 破坏其他主机持有的磁带保留，然后保留磁带驱动器。此命令只有超级用户才能执行。
* `erase` 擦除整个磁带。擦除磁带可能需要很长时间，取决于设备和/或磁带。详情参阅设备手册。

如果在以下命令中指定了 `count`，则忽略 `count` 并执行一次命令。

* `eof` 在磁带当前位置写入 `count` EOF 标记。
* `fsf` 越过 EOF 标记。将磁带移动到第一个块。
* `fsr` 向移动记录。
* `bsf` 越过 EOF 标记。将磁带移动到 EOF 标记的磁带起始侧。
* `bsr` 回退计数记录。
* `nbsf` 回退计数文件。将磁带移动到第一个块。
* `asf` 绝对空间计数文件。这等同于回带后执行一次 `fsf`。
