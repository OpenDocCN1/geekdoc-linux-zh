## 日期和时区

设置时间信息通常在安装时完成。之后，可以使用 NTP（网络时间协议）客户端保持最新状态。大多数 Linux 系统默认运行 `ntpd`：

```
debbry->> ps -ef | grep ntpd
tp      24678      1 0 2002 ?     00:00:33 ntpd -U ntp
```

你可以运行 `ntpdate` 来设置时间，通过 `ntpdate` 可以访问服务器。当你使用 `ntpdate` 调整时间，`ntpd` 进程不会运行。使用服务器作为命令的参数：

```
root@box:-# ntpdate 10.2.5.200
26 Oct 14:35:42 ntpdate[20364] adjust time server 10.2.5.200 offset -0.008049 sec
```

请参阅你的手册和 NTP 软件包附带的文档。大多数桌面管理器都包含设置系统时间的工具，前提是你拥有系统管理员账户权限。

为了正确设置时间，你可以利用 `date` 或 `timezone` 命令。时区信息通常在机器安装期间设置。许多系统都有特定于发行版的工具来配置它，请查看你的系统文档。

## 语言

如果你更希望用荷兰语或法语获取系统消息，你可能需要设置 `LANG` 和 `LANGUAGE` 环境变量，为所需的语言启用本地化支持，并最终启用与该语言字符规范相关的字体。

对于大多数图形化登录界面（如 `gdm` 或 `kdm`），你可以在登录前配置这些语言设置。

请注意，在某些系统上，现在的默认值是 `en_US.UTF-8`。这并不是问题，因为以此作为默认的系统也会附带所有支持该编码的程序。因此，你可以编辑系统上的所有文件，`cut` 也能正常工作等等。

当你连接到不支持此编码的旧系统，或者在只支持 1 字节字符的系统上打开 UTF-8 编码的文件时，问题就会出现。`recode` 工具可能在将文件从一个字符集转换为另一个时很有用。阅读 `man` 手册以概述功能和用法。另一种解决方案可能是通过设置 `LANG` 变量临时使用另一种编码定义：

```
debbry->> acread /var/tmp/51434s.pdf
Warning: charset "UTF-8" not supported, using "ISO88859-1"
Aborted
```

```
debbry->> set | grep UTF
LANG=en_US.UTF-8
```

deby->> export LANG=en_US

deby->> acroread /var/tmp/51434s.pdf

<--new window opens-->

# 安装新软件

## 通用

大多数人看到安装 Linux 后有一台可以运行和使用的计算机感到惊讶；大多数发行版都对视频卡、网卡、显示器和其他外部提供了充分的支持，通常不需要安装额外的驱动程序。此外，办公套件、浏览器、电子邮件和其他网络客户端等常用工具也包含在主发行版中。尽管如此，安装程序可能无法满足你的需求。

如果你就是找不到你需要的东西，也许它没有安装在你的系统上。可能是你拥有所需的软件，但它没有按照预期工作。请记住，Linux 发展非常快，软件每天都在改进。不要浪费时间去排查可能已经解决的问题。

你可以随时更新系统或添加软件包。大多数软件都是以包的形式提供的。额外的软件可以在安装光盘或互联网上找到。你所 Linux 发行版的网站是寻找额外软件以及关于如何在你的类型 Linux 上安装它的说明的好地方，请参见附录 A，“从现在开始去哪里？”。始终阅读新软件附带的文档，以及软件包可能包含的任何安装指南。所有软件都带有一个 `README` 文件，强烈建议阅读。

## RPM 软件包

### 什么是 RPM？

RPM，即 RedHat 软件包管理器，是一个强大的软件包管理器，你可以用它来安装、更新和删除软件包。它允许你搜索软件包并跟踪每个软件包包含的文件。系统内置了功能，以便你可以验证从互联网下载的软件包的真实性。高级用户可以使用 RPM 构建自己的软件包。

一个 RPM 软件包由文件归档和用于安装和删除归档文件的元数据组成。元数据包括辅助程序脚本、文件属性以及关于软件包的描述性信息。软件包有两种类型：二进制包，用于封装要安装的软件；以及源包，包含产生二进制包所需的源码和配方。

许多其他发行版也支持 RPM 软件包，包括流行的 RedHat Enterprise Linux、Mandriva（原 Mandrake）、Fedora Core 和 SuSE Linux。在阅读关于 RPM 的建议之后，你可能想要阅读。
