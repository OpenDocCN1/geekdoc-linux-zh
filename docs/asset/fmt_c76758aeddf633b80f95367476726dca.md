## subprocess

`subprocess` 模块包含了函数和对象，这些元素将创建进程、控制输入输出以及处理返回码的任务泛化。该模块将功能集中在许多其他模块中，如 `os`、`popen2` 和 `commands`。

### `Popen(args, **parms)`

作为子进程执行一个新命令，并返回一个表示新进程的 `Popen` 对象。命令在 `args` 中指定，形式可以是字符串（例如 `'ls -1'`）或字符串列表（例如 `['ls', '-1']`）。`parms` 代表一组关键字参数集合，这些参数可用于控制子进程的各种属性。引入了以下关键字参数：

| 关键字 | 描述 |
| --- | --- |
| `bufsize` | 指定缓冲行为，其中0 表示不缓冲，1 表示行缓冲，负值指定系统默认值，正值指定近似的缓冲区大小。默认为0 |
| `close_fds` | 如果为 True，则在执行子进程之前关闭除 0、1 和 2 之外的所有文件描述符。默认值为 False。 |
| `creation_flags` | 指定 Windows 上的进程创建标志。目前唯一可标志是 CREATE_NEW_CONSOLE。默认值为 0 |
| `cwd` | 命令执行的目录。在执行之前，子进程的当前目录将更改为 `cwd`。默认值为 None，即使用父进程的当前目录 |
| `env` | 新进程的环境变量字典。默认值为 None，即使用父进程的环境变量 |
| `executable` | 指定要使用的可执行程序的名称。如果程序名已包含在 `args` 中，则很少需要此参数。如果已给定了 `shell`，则此参数指定要使用的 shell 名称。默认值为 None |
| `preexec_fn` | 指定一个在执行命令之前在子进程中调用的函数。该函数不应接受任何参数 |
| `shell` | 如果为 True，则使用类似于 `os.system()` 函数的 UNIX shell 执行命令。默认 shell 为 `/bin/sh`，但也可以通过设置 `executable` 来更改它。`shell` 的默认值为 None。 |
| `startupinfo` | 提供在 Windows 上创建进程时使用的启动标志。默认值为 None。可能的值包括 START_USENOWINDOW 和 START_USESTDHANDLERS。 |
| `stderr` | 表示子进程中用于 stderr 的对象。可以是通过 `open()` 创建的文件对象、整数文件描述符，或特殊值 `PIPE`（表示应创建一个新管道）。默认值为 None。 |
| `stdin` | 表示子进程中用于 stdin 的对象。可以被设置为与 `stderr` 相同的值。默认值为 None。 |
| `stdout` | 表示子进程中用于 stdout 的对象。可以被设置为与 `stderr` 相同的值。默认值为 None。 |
| `universal_newlines` | 如果为 True，则代表 `stdin`、`stdout` 和 `stderr` 的文件将以文本模式打开，并启用通用换行符模式。完整描述请参阅 `open()` 函数。 |

### `call(args, **parms)`

此函数与 `Popen()` 完全相同，不同之处在于执行命令并返回其状态码（即它不返回 `Popen` 对象）。如果你只想执行命令而不关心捕获其输出或通过其他方式控制它，则此函数非常有用。参数的含义与 `Popen()` 相同。

### `check_call(args, **parms)`

与 `call()` 相同，但如果退出码不为零，则会抛出 `CalledProcessError` 异常。该异常将退出码存储在其 `returncode` 属性中。

`Popen()` 返回的 `Popen` 对象具有多种属性，可用于子进程交互。

### `p.communicate([input])`

通过向进程的标准输入发送 `input` 提供的数据与进程进行通信。一旦发送了数据，该方法将等待进程，同时收集从 `stdout` 和 `stderr` 接收到的输出。返回一个元组 `(stdout, stderr)`，其中 `stdout` 和 `stderr` 是字符串。如果没有向子进程发送数据，则 `input` 被设置为 `None`（默认值）。

### `p.kill()`

通过在 UNIX 上发送 `SIGKILL` 信号或在 Windows 上调用 `p.terminate()` 方法来杀掉子进程。

### `p.poll()`

检查 `p` 是否已终止。如果是，则返回子进程的退出码。否则，返回 `None`。

### `p.send_signal(signal)`

向子进程发送信号。`signal` 是在 `signal` 模块定义的信号值。在 Windows 上，唯一支持的信号是 `SIGTERM`。

### `p.terminate()`

通过在 UNIX 上发送 `SIGTERM` 信号或在 Windows 上调用 Win32 API `TerminateProcess` 函数来终止子进程。

### `p.wait()`

等待 `p` 终止并返回退出码。

### `p.pid`

子进程的进程 ID。

### `p.returncode`

进程的数值返回码。如果为 `None`，则进程尚未终止。如果是负数，则表示进程被信号终止（UNIX）。

### `p.stdin`, `p.stdout`, `p.stderr`

每当 I/O 流作为管道打开时，这三个属性都会被设置为打开的文件（例如在 `Popen()` 中将 `stdout` 设置为 `PIPE`）。提供这些文件对象是为了让管道连接到其他子进程。如果没有使用管道，这些属性将设置为 `None`。

## 示例

```python
# 执行命令并获取输出

import subprocess

p = subprocess.Popen(['ls', '-l'], stdout=subprocess.PIPE, stderr=subprocess.PIPE)

stdout, stderr = p.communicate()

print(stdout.decode())
```

```python
# 使用 call 获取返回码

import subprocess

return_code = subprocess.call(['ls', '-l'])

if return_code == 0:
    print("Success")
```

```python
# 使用 check_call，它会在命令失败时抛出异常

import subprocess

try:
    subprocess.check_call(['ls', '/nonexistent_directory'])
except subprocess.CalledProcessError as e:
    print(f"Command failed with return code {e.returncode}")
```
