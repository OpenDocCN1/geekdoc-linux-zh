## 开启/关闭 SSA 识别灯

在任何利用 IBM 串行存储架构 (SSA) 磁盘子系统的系统中，你都会理解在数百个不同卷卷组的磁盘中找到特定的故障磁盘是多么困难。SSA 识别的其他需求包括找到连接到特定系统的所有驱动器。你可能只想看到运行在特定卷组或特定磁盘组上的驱动器。在本章中，我们将处理所有这些识别领域。

在识别系统硬件组件时，你通常有一套用于此功能的工具。本章将集中在 AIX 系统上。本章介绍的脚本仅适用于 AIX，但经过少量修改，它可以运行在利用 SSA 子系统的其他 Unix 变体上。我坚持使用 AIX，是因为该脚本有一个查询卷组的选项，而并非所有系统都支持。

## 语法

一如既常，我们需要从完成任务的命令开始。对于 SSA 子系统，我们关注两个与 hdisk 相关的命令。第一个命令 `ssaxlate` 将 `hdisk#` 转换为 `pdisk`，反之亦然。我们使用的第二个命令是 `ssidentify`，它需要一个 pdisk。该命令用于开启和关闭 SSA 磁盘识别。我们希望脚本识别 hdisk 格式或 pdisk 格式。

### 将 hdisk 转换为 pdisk

```
# ssaxlate -1 hdisk43
```
pdisk41

在这个示例中，`hdisk43` 转换为 `pdisk41`。这告诉我 hdisk 到 pdisk 的偏移量为 2，我不得不假设 `hdisk0` 和 `hdisk1` 都是 SCSI 磁盘，而 `hdisk3` 到 `hdisk43` 都是 SSA 磁盘。事实总是如此。这取决于 AIX 配置管理器最初发现磁盘的方式，但我的假设是合理的。我们可以通过在 `ssaxlate` 命令中指定 `pdisk41` 来轻松地转换为 hdisk43。

下一步是实际上开启 `hdisk43` 的识别灯，我们已将其转换为 `pdisk41`。`ssidentify` 命令要求以 pdisk 表示磁盘，因此我们需要在该命令中使用 `pdisk41`。

### 识别 SSA 磁盘

```
# ssidentify -1 pdisk41 -y
```

`ssidentify` 命令将返回成功或失败的返回码，但不返回文本。如果返回码为 0，则命令执行成功。如果返回码不零，则命令由于某种原因失败，并将信息发送到标准错误（即文件描述符 2）。我们关心的仅仅是返回码是否为 0。

## 控制函数

我们从 `all_defined_pdisks` 函数开始进入开启关闭识别灯的真实世界，它是本章 SSA 识别函数中最简单的一个。目标是获取系统中每个 SSA 磁盘的列表，并使用 pdisk# 按顺序开启或关闭控制识别灯。要要理解这个函数，你需要理解名为 `lsdev` 的命令以及我们用于提取 pdisk 信息的开关。`lsdev` 命令用于显示系统中的设备及其特征。`-C` 关告诉 `lsdev` 命令仅查看当前定义的设备。`-c` 关用于指定特定的设备类；在我们例中设备是 pdisk。因此我们的 `lsdev` 命令语句如下：

```
# lsdev -Cc pdisk
```
