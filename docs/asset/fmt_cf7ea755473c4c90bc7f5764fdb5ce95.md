# 再生（生物学）

动物恢复其丢失身体部位的方式。身体可以经历伤口愈合、组织修复和许多活动。系统中的大多数再生涉及通过一系列事件替换复杂结构或器官的主要部分，从而产生一个完美复制缺失部分的结构。

最为人知且研究最充分的再生例子是后生再生（epimorphosis），在整个动物界中通过增殖细胞的爆发直接复制丢失的结构。对再生系统的研究提供了有关动物发育机制的信息，以及控制结构发育（如脊椎动物）中模式形成的因素。

哺乳动物、鸟类和爬行动物不像两栖动物和鱼类那样具有再生复杂的能力，但在器官部分移除后仍形成组织并修复。例如，如果切除肝，剩余细胞将生长以补偿丢失的组织并恢复器官的正常功能。肝脏再生的过程涉及触发肝细胞（cell cells）的生长，这些细胞在正常肝脏中通常处于静止状态。这些细胞的增殖及其不同的分化导致了丢失肝质量的恢复和充足的肝功能。

在所有脊椎动物中，两栖动物具有最强大的再生能力。某些物种不仅能够再生肢体，还能再生器官部分、下颌、肠道和心脏。截肢的完全再生发生在�蟾和青期间。原生动物和多细胞生物（包括海绵和虫）在许多例子中显示出人的适应性。生物的再生能力与其繁殖能力密切相关，最常见的是分裂或出芽。再生的形式通常与某些无性繁殖相似。例如，如果完全纤毛聚虫在细胞间分裂和分裂，将发育。如果单个生物的碎片包含完整的遗传材料和原始纤毛细胞的一部分，会导致再生过程。

大多数动物（如地蚓）在移除后可以轻易再生其节；某些物种可以从少数细胞再生整个器官。像虫一样，环节动物可以通过横向分裂繁殖。动物再生和碎片化的能力非常显著，特别是考虑到这些动物的复杂性。

当地蚓被切成两部分时，后部可以再生几节。在某些物种中，后部再生前节的能力受限或不存在。在移除神经系统组件的物种中，缺乏再生的神经影响，可能由某些物质的分泌介导。

壳类动物（如海星）再生缺失手臂的能力是众为人知的。将手臂切成几段，每段形成一个新的有机体，这种现象利用了每段中至少某些全能细胞的存在。身体再生是海胆对损伤的再生反应。当海星受伤时，它会受到刺激并透过体壁破裂排出自身。该分区随后开始再生各个部分，从手指开始。参见 `ECHNODERIA`（棘皮动物）。

三叉动物（tripla）成员中扩散的再生能力有限。在这些具有发达骨骼且无无性繁殖的复杂动物中，再生与蜕皮过程密切相关。参见 `TETRAPOD`（四足动物）；`FEEDBACK`（反馈）；`BIOMENTAL`（生物心理）。
