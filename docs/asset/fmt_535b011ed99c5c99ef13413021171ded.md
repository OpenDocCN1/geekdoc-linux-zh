
## less 命令

- `Ctrl-d` 或 `d` 向后移动半屏（默认 11 行）。如果前面有数字，则向前移动指定的行数。新数字将被注册为后续所有 `d` 或 `u` 命令的新默认值。
- `g` 默认跳转到文件开头。如果前面有数字，文件将定位到数字指定的行。
- `G` 默认跳转到文件末尾。如果前面有数字，文件将定位到数字指定的行。
- `p` 或 `%` 默认跳转到文件开头。如果前面是 0 到 100 之间的数字，则定位到文件指定的百分比。
- `Ctrl-p` 或 `Ctrl-k` 或 `Ctrl-y` 或 `k` 向后移动 1 行。如果前面有数字，则向后移动指定的行数。
- `Ctrl-u` 或 `u` 向后移动半屏（默认 11 行）。如果前面有数字，则向后移动指定的行数。新数字将被注册为后续所有 `d` 或 `u` 命令的新默认值。
- `Ctrl-l` 或 `Ctrl-r` 或 `r` 重新绘制当前屏幕。
- 小写字母用小写字母标记位置供以后使用。
- `- 小写字母` 使用 `m` 子命令跳转到用小写字母标记的位置。如果后面跟着 `^`（脱字符），`less` 显示文件开头。如果后面跟着 `$`（美元符号），`less` 显示文件末尾。
- `- 数字/模式` 将文件定位到文件中指定的模式出现处。你可以使用以下特殊字符来指示特殊操作：
  - `o!` 搜索不包含指定模式的行。
  - `*` 如果搜索多个文件。
  - `@` 搜索包含模式的行。
  - `n` 搜索模式的下一个出现。
  - `N` 搜索模式的上一个出现。
  - `/` 向前搜索模式。
  - `?` 向后搜索模式。
  - `s` 搜索模式。
  - `c` 退出搜索。
  - `h` 显示帮助。
  - `q` 退出。

## tail

```
tail +27 file1
This is the line 28
This is the line 29
This is the line 30
```

在此示例中，显示从文件顶部的第 28 行开始。如果你想从文件的指定位置而不是行位置开始，可以使用 `-c` 标志，如下所示：

```
tail -c +500 file1
the line 27
This is the line 28
This is the line 29
This is the line 30
```

在此示例中，显示从文件顶部的第 500 个字节开始。如果你想指定一个绝对行号来开始显示文件，可以使用如下所示命令中的 `-n` 标志：

```
tail -n -5 file1
This is the line 26
This is the line 27
This is the line 28
This is the line 29
This is the line 30
```

在此示例中，显示从文件底部的倒数第 5 行。如果你想以反序显示文件的行，请在以下命令中使用 `-r` 标志：

```
tail -r -n -5 file1
This is the line 30
This is the line 29
This is the line 28
This is the line 27
This is the line 26
```

在此示例中，最后 5 行按反序显示，最后一行在最后。

## head

`head` 命令在标准输出上显示文件。`head` 命令从文件顶部开始，并从文件开头显示指定数量的字节或行。默认情况下，`head` 显示 10 行。

以下是可与 `head` 命令使用的标志：

- `-c number`：显示从文件顶部开始的字节数。
- `-n number`：显示从文件顶部开始行数。

数字可以不带任何符号，也可以以 `-` 开头，两者含义相同。

示例：假设我们有一个文件，其内容与 `tail` 命令中显示的相同。

如果你想从顶部开始显示指定数量的行，请使用如下命令中的 `-n` 标志：

```
head -3 file1
This is the line 1
This is the line 2
This is the line 3
```

在此示例中，显示了 `file1` 的前三行。如果你想从文件顶部显示前指定数量的字节，请使用如下命令中的 `-c` 标志：

```
head -c 29 file1
This is the line 1
This is the th
```

在此示例中，显示了 `file1` 的前 29 个字节。

## wc

```
wc
```

`wc` 命令统计指定文件中字节数、单词数和行数。一个单词是一组连接在一起的字符，由空格或换行符分隔。

以下是可与 `wc` 命令使用的标志列表：

- `-l`：仅统计文件的行数。
- `-w`：仅统计文件的单词数。
- `-c`：仅统计文件的字节数。

你可以使用多个文件名作为 `wc` 命令的参数。

示例：如果你想知道 `file1` 中的字节数、单词数和行数，请执行以下命令：

```
wc file1
25 125 491 file1
```

此示例显示 `file1` 有 25 行、125 个单词和 491 个字节。如果你只想找到文件的单词数，请在如下命令中使用 `-w` 标志：

```
wc -w file1
125 file1
```

如果你想获取 `file1` 和 `file2` 的单词数，请执行以下命令：

```
wc -w file1 file2
125 file1
463 file2
588 total
```

注意，如果你使用多个文件，输出中将额外获得一行，显示所有文件的总计。

## read

```
read
```

`read` 命令用于 shell 脚本，用于从文件中读取每个字段并将其赋值给 shell 变量。字段是由空格或换行符分隔的字节字符串。如果读取的字段数少于变量数，则剩余字段将不会赋值。

以下是可与 `read` 命令使用的标志列表：

- `-r`：将反斜杠 `\` 视为输入记录的一部分，而不是控制字符。

示例：如果你想启动一段 shell 代码，从文件中读取名字和姓氏并打印它们：

```
while read -r lname fname
do
    echo "$lname,$fname"
done < namefile
```

## od

`od` 命令可以以指定的格式显示文件的内容。通常，此命令用于查看可执行文件或其他非文本文件，大多数 UNIX 命令无法处理这些文件。你也可以指定从文件的何处开始显示的偏移量。

以下是可与 `od` 命令使用的标志列表：

- `-d`：将输出作为有符号十进制数。
- `-i`：将输出作为无符号十进制数。
- `-f`：将输出作为浮点数。
- `-b`：将输出作为八进制值。
- `-h`：将输出作为十六进制值。
- `-c`：将输出作为 ASCII 字符。

你可以在文件名之后指定显示的字节偏移量。如果偏移量以 `0x` 开头，则该偏移量被解释为十六进制。如果偏移量以 `0` 开头，则被解释为八进制。偏移量可以带有后缀 `b` 表示字节，`k` 表示千字节（1024 字节），`m` 表示兆字节（1024 字节）。

示例：要显示文件内容，请执行以下：

```
od file | more
000000 00737 000007 031147 104407 000000 000000 000000 000000
000020 00110 010007 00413 000001 000002 024250 000001 056674
000040 00012 030504 000001 052320 000000 010000 000000 000000
000060 00001 055020 000004 000002 000004 000004 000007 000005
```

这以十进制格式显示文件。如果你想以十六进制格式显示文件，请在如下命令中使用 `-h` 标志（注：此处原文可能为误，通常为 `-x`）：

这是第 2 行

这是第 3 行

这是第 4 行

这是第 5 行

这是第 6 行

这是第 7 行

:

在这个示例中，显示的行数是 7 行。另一方面，如果你想像下面的命令那样，通过数字 `a +`（加号）从第 7 行开始显示：

```
pg +7 file1
```

如果你想用个性化的提示符替换默认的 `:`（冒号）提示符，请使用如下命令中的 `-p` 标志：

```
pg +7 -s -p "Enter Sub-command -> " file1
这是第 1 行
这是第 2 行
这是第 3 行
这是第 4 行
这是第 5 行
这是第 6 行
这是第 7 行
Enter Sub-command ->
```

在这个示例中，默认提示符已被 `Enter Sub-command ->` 替换。如果你想从出现第 5 行的行开始打开文件，请执行以下命令：

```
pg +"line 5" file1
```

## tee

如果你想执行一个命令，并将其输出重定向到标准输出之外的多个文件，请使用 `tee` 命令。`tee` 命令接受来自标准输入的输入，因此可以将另一个命令管道给 `tee` 命令。

以下是可以配合 `tee` 命令使用的可选标志：

- `-a` 将添加到指定文件的末尾。`tee` 命令的默认行为是覆盖指定的文件。

示例：如果你想使用 `cat` 命令对 `file1` 进行显示并在屏幕上，但你想为 `file2` 创建一个副本，可以使用如下 `tee` 命令：

```
cat file1 | tee file2 | more
```

如果你想将 `file1` 追加到已存在的 `file2` 的末尾，请使用如下命令中的 `-a` 标志：

```
cat file1 | tee -a file2 | more
```

## vi

`vi` 命令可用于全屏模式编辑文件。如果没有提供文件名，UNIX 会创建一个没有名的空工作文件。如果提供了文件名且文件不存在，则会创建一个指定指定的空工作文件。在保存更改之前，`vi` 命令不会修改现有文件。

> 注意：`vi` 命令在编辑时不会锁定文件。因此，可能多个用户同时编辑它。最后保存的文件版本将是保留的版本。

以下是可以在 `vi` 命令中使用的一些标志列表：

- `-c sub-command` 在将指定文件放入编辑模式之前执行指定的子命令。
- `-r filename` 恢复指定的文件名。
- `-R` 以只读选项将指定文件放入编辑模式，使得对任何修改都无法保存。
- `-number` 设置编辑窗口为具有指定行数的大小。

以下是 `vi` 编辑器的模式列表：

- 命令模式（command mode）是进入 `vi` 时的默认模式。在此模式下，你可以输入各种子命令来操作行，例如删除行、粘贴行、移动到不同的单词、移动到不同的行等。
- 文本输入模式（text input mode）是你可以修改行中的文本或输入新行的模式。你可以通过在命令模式下使用命令 `a`、`i` 或 `c` 进入此模式。按 `Escape` 键返回命令模式。
- 命令输入模式（command entry mode）是可以输入需要额外参数的特定子命令的模式。其中子命令是 `w` 子命令（需要文件名）或 `/` 子命令（需要输入模式）。你可以使用 `Escape` 键返回命令模式。

以下是在命令模式下用于在行内移动的子命令快速参考：

- `h` 将光标移动到同一行内的上一个字符。
- `l` 将光标向右移动到同一行内的下一个字符。
- `j` 将光标向下移动到同一列的下一行。
- `k` 将光标向上移动到同一列的上一行。
- `w` 将光标移动到同一行内下一个小单词的开头。
- `W` 将光标移动到同一行内下一个大单词的开头。
- `b` 将光标移动到同一行内上一个小单词的开头。
- `B` 将光标移动到同一行内上一个大单词的开头。
- `e` 将光标移动到同一行内下一个小单词的结尾。
- `E` 将光标移动到同一行内上一个大单词的结尾。
- `fc` 移动到同一行内的下一个字符 `c`。
- `Fc` 移动到同一行内的上一个字符 `c`。
- `tc` 将光标移动到同一行内下一个字符 `c` 之前的一列。
- `Tc` 将光标移动到同一行内上一个字符 `c` 之后的一列。
- `number|` 将光标移动到指定的列数。

以下是在命令模式下用于跨行移动的子命令快速参考：

- `+` 或 `Enter` 将光标移动到下一行的第一个非空字符。
- `{` 将光标移动到上一行的第一个非空字符。
- `0` 将光标移动到行首。
- `$` 将光标移动到行尾。
- `H` 将光标移动到当前行的第一个非空字符。
- `L` 将光标移动到当前行的最后一个非空字符。
- `M` 将光标移动到行的中间。

以下是在命令模式下用于在行内移动的子命令快速参考：

`line:` 

- `:w` 将更改保存到原始文件。
- `:w filename` 如果文件 `filename` 不存在，则将更改保存到指定的 `filename`。如果你尝试使用此子命令保存已存在的文件，将收到错误。
- `!w filename` 如果文件 `filename` 已经存在，则将更改保存到指定的 `filename`。

以下是如果你在调用 `vi` 时指定了多个文件，可用于不同文件之间切换的子命令快速参考：

- `:n` 开始编辑 `vi` 启动时指定的指定文件列表中的下一个文件。
- `:n filenames` 指定一个新的要编辑的文件列表。

以下是用于在当前文件和交替文件（alternate file）之间切换的子命令快速参考：

- `:e` 调用 `vi filename` 并使其成为交替文件。
- `:e` 重新加载当前文件。如果当前文件有更改，则这些更改将被丢弃。
- `:e + filename` 调用 `vi` 并传入 `filename`，但从文件末尾而不是从开始开始编辑。
- `:e + number filename` 调用 `vi` 并传入 `filename`，并从指定的行号开始编辑。
- `:e #` 开始编辑交替文件。

以下是用于从其他源向当前文件添加新行的子命令快速参考：

- `:r filename` 读取完整的 `filename` 并将其添加到当前行之后。
- `:r !command` 执行指定的命令并将输出添加到当前行之后。

以下是一些杂杂子命令的快速参考：

- `Ctrl-g` 获取当前正在编辑的文件信息。
- `:sh` 启动可以在其中执行命令的 shell。你可以使用 `exit` 命令或 `Ctrl-d` 返回。
- `!command` 执行上一次的 `:!command`。
- `!!` 重新执行上一次的 `:!command`。
- `:q` 退出 `vi`。如果你尝试使用此子命令退出且对文件进行了修改，UNIX 将不允许你退出。
- `:q!` 无论对文件做出了任何更改，都退出 `vi`。
- `:wq` 将更改保存到原始文件并退出 `vi`。

你可以使用一个名为 `.exrc` 的特殊文件，在其中你可以指定 `vi` 子命令。若要在会话中使用这些子命令，请在命令前加加一个冒号 `:`。其中一些子命令如下：

- `Ab abb` 缩写为 `abb`。
- `unab` 关闭缩写。
- `map m seq` 将一组 `vi` 命令映射到某个字符或按键。

## 文件内容搜索命令

我们已经看到可以使用 `find` 在目录中搜索文件名。若要在在一个或多个文件中搜索特定模式，请使用 `grep` 系列命令。`grep` 命令在指定文件中搜索字符串并将输出显示到标准输出。

```
grep
```

`egrep` 命令是 `grep` 命令的扩展版本。该命令在一个或多个文件中搜索指定的模式，并将输出显示到标准输出。该模式可以是一个正则表达式，你可以在其中指定特殊字符以使其具有特殊含义，这些特殊字符如下：

- `.` 匹配任意字符。
- `*` 匹配星号之前的一个或多个单字符。
- `^` 匹配行首的正则表达式。
- `$` 匹配行尾的正则表达式。
- `+` 匹配前一个正则表达式的次或多次出现。
- `?` 匹配前一个正则表达式的零次或一次次出现。
- `[` 匹配括号内指定的任何字符。

以下是可配合 `grep` 命令使用的标志（flags）列表：

- `-b` 在每个找到的行开头显示块号。
- `-c` 显示找到模式的行数，而不显示行内容。
- `-f filename` 指定一个包含要匹配模式的文件名。
- `-h` 如果搜索了多个文件，则抑制显示中的文件名。
- `-i` 搜索时忽略大小写。
- `-l` 列出匹配模式的文件名。
- `-n` 显示找到模式的行号。
- `-q` 静默模式，不输出内容。
- `-s` 如果发生错误则抑制错误。
- `-v` 显示不匹配模式的行。
- `-w` 以单词形式搜索。
- `-x` 精确匹配整行。

`egrep` 命令是 `grep` 命令的扩展版本。该命令在一个或多个文件中搜索指定的模式，并将输出显示到标准输出。由于某些特殊功能，该模式可以是一个正则表达式，你可以在其中指定特殊字符以使其具有特殊含义，这些特殊字符如下：

- `+` 匹配前一个正则表达式的次或多次出现。
- `?` 匹配前一个正则表达式的零次或一次次出现。
- `|` 如果你想要找到两个模式中的任意一个，你可以使用竖线（管道）来分隔这两个模式。
- `( )` 使用左括号和右括号对模式进行分组。

假设我们有一个文件 `l`，其内容如下，使用以下命令查看包含模式的行，显示的如下：

```
filel
***** This is a dummy file
programmers
end users
```

Believe it or not, grep series of commands are used by pros and novices alike

***** THIS IS DUMMY FILE

```

如果你想找到所有 `dummy` 的出现，使用以下命令：

```
egrep dummy filel
***** This is a dummy file
```

如果你想在忽略大小写的情况下找到所有 `dummy` 的出现，使用以下命令：

```
egrep -i dummy filel
***** This is a dummy file
***** THIS IS DUMMY FILE
```

如果你想显示包含模式的行的相对行号，使用以下命令：

```
egrep -i -n dummy filel
1:***** This is a dummy file
8:***** THIS IS DUMMY FILE
```

如果你想知道出现指定模式的行数，使用以下命令：
