
你可以如下所示创建未成对的标签，例如 `<BR>`、`<HR>` 和 `<P>`：

```perl
print $cgi->p;
```

### 成对的 HTML 标签

其他标签（如 `<I>` 和 `<B>`）是成对的。你可以这样创建它们：

```perl
print $cgi->i("Here is some text to be italicized.");
```

你甚至可以如下在标签内嵌套标签：

```perl
print $cgi->i("Here is some", print $cgi->b("bold text"), "to be italicized");
```

### 某些需要避免的陷阱

尽管你可以通过同名的小写函数调用使用你预期的任何 HTML 标签，但在某些情况下，它们会与当前命名空间中的其他方法冲突。

例如，你可能想要创建一个 `<TR>` 标签，但 `tr()` 在 Perl 中作为字符翻译器存在。因此，你可以使用 `TR()` 来生成 `<TR>` 标签。此外，你通过 `PARAM()` 方法创建 `<PARAM>` 标签，因为 `param()` 是 CGI 模块本身的方法。

## HTML 填充表单

请记住，创建表单的方法返回必要的 HTML 标记文本，以便让浏览器显示你想要的内容。从方法中获取字符串后，你仍然需要打印这些字符串。此外，你为表单指定的默认值仅在程序首次调用时有效。如果你通过查询字符串传递了任何值，程序将使用它们，即使这些值是空的。

如果你需要，可以使用 `param()` 方法专门设置字段的值。（你可能想使用此方法来忽略查询字符串中可能存在的内容，并将其设置为你想要的另一个值。）如果你想强制程序对给定的字段使用其默认值，可以通过 `-override` 参数来实现。

因此，这段 CGI

```perl
print $cgi->textfield(-name => 'browser',
-default => 'Mozilla');
```

在第一次调用时，它会在浏览器的文本字段中使用中使用 `Mozilla` 这个值。然而，如果查询字符串包含 `browser=InternetExploder`，则文本字段将改用此值。

为了防止这种情况的发生，你可以将你的 CGI 改为如下所示：

```perl
print $cgi->textfield( -name => 'browser',
-default => 'Mozilla',
-override => 1);
```

现在，文本字段始终具有 `Mozilla` 的默认值，无论查询字符串中的值是什么。

如果你想强制页面上所有字段都使用默认值，而不需要专门告诉每个字段去覆盖查询字符串中的值，你可以使用 `defaults()` 方法创建一个默认按钮，或者你可以构造你的程序，使其从不将查询字符串传回给自己。

虽然你可以在一个页面上放置多个表单，但同时跟踪多个表单并不容易。

传递给表单元素的文本会经过转义。因此，你可以使用 `<my@email.addr>` 等而不必担心它会被某种方式发送到浏览器，浏览器会认为你只是发送了一个奇怪的标签。如果你需要关闭此功能（以便你可以使用特殊的 HTML 字符，如 `&copy; ([])`），你可以通过这种方式实现：

```perl
$cgi->autoEscape(undef);
```

要重新开启该功能，请尝试：

```perl
$cgi->autoEscape('yes');
```

要创建 `<ISINDEX>` 标签，你可以如下所示使用 `isindex()` 方法：

```perl
isindex($action);
```

### 开始和结束表单

`startform()` 和 `endform()` 方法用于开始和结束表单，如下所示：

```perl
print $cgi->startform($method, $action, $encoding);
print $cgi->endform;
```

有两种编码类型：

- `application/x-form-urlencoded`：这是向服务器提交数据的标准方式。
- `multipart/form-data`：你可以使用 Netscape 2.0 引入的这种新编码选项来发送大文件。如果你不使用浏览器的文件功能，不需要使用此方法。此外，你可以通过传递 `-name` 和 `-onSubmit` 参数在表单中使用 JavaScript。（在提交前验证表单数据是此很好的用途。）允许提交的 JavaScript 按钮应该返回真值，假值则取消提交。

未选择编码，用户选择上传的文件名是可用的，但其内容不可用。

请记住，你可以使用 `query()` 方法获取文件名。方便的是，返回的文件名也是一个文件句柄（file handle）。因此，你可以使用如下代码读取用户上传的文件内容：

```
$uploaded_file = $cgi->param('uploaded_file');
 while(<$uploaded_file>) {
 print;
 }
```

不过，二进制数据并不喜欢这种 `while` 循环。事实上，如果 `you` 想要将用户上传的文件保存到某个地方（例如用户正在上传一幅新汽车的 JPEG 图像），可以使用像下面的代码来实现：

```
 open(NEWFILE, ">>/some/path/to/a/file") || die "Cannot open NEWFILE: $!\n";
 while($bytesread=read($uploaded_file, $buffer, 1024)) {
 print NEWFILE $buffer;
 }
 close NEWFILE;
```

## 弹出菜单

你可以使用 `popup_menu()` 方法创建一个菜单。`-name` 是菜单的名称（必填），`-values` 是一个包含菜单列表项的数组引用。你可以传递一个匿名数组，或者一个数组的引用，例如 `menu_items`（必填）。`-default` 是默认菜单选项的名称（可选）。`-labels` 允许你传递一个关联数组引用，为用户看到的菜单项标签命名。如果未指定，用户将看到来自 `-values` 的值（可选）。

```
print $cgi->popup_menu( -name =>'menu_name',
 -values=>\['one', 'two', 'three'],
 -default =>'three',
 -labels =>{'one'=>'first','two'=>'second',
 'three'=>'third'});
```

### 滚动列表

创建滚动列表的方法是 `scrolling_list()`：

```
print $cgi->scrolling_list( -name=>'list_name',
 -values=>\['one', 'two', 'three'],
 -default=>\['one', 'three'],
 -size=>4,
 -multiple=>'true',
 -labels=>\%labels);
```

`-name` 和 `-values` 与弹出菜单中的相同。所有其他参数都是可选的。`-default` 是默认选中的项目列表（或单个项目）。`-size` 是列表的显示大小。`-multiple` 当设置为 `true` 时，允许选择多个项。否则，一次只能选择一个项目。`-labels` 与弹出菜单中的相同。

## 复选框

你使用 `checkbox()` 方法创建独立的复选框。如果你有一组在逻辑上相互关联的复选框，可以使用 `checkbox_group()`。

```
print $cgi->checkbox( -name=>'checkbox_name',
 -checked=>'checked',
 -value=>'ON',
 -label=>'Check me!');
```

`-name` 是一个包含复选框名称的参数；它是唯一的必填参数。复选框的名称也会用作复选框旁的可读标签，除非 `-label` 另有指定。如果默认要选中，则将 `-checked` 设置为 `checked`。`-value` 指定了复选框被选中时的值。`-label` 指定了复选框旁边显示的内容。

## 复选框组

这里显示的 `checkbox_group()` 是你用于创建多个在逻辑上相互关联、且其行为可以受其他框影响的复选框的方法。

```
print $cgi->checkbox_group( -name=>'group_name',
 -values=>\['uno', 'dos', 'tres'],
 -default=>'dos',
 -linebreak=>'true',
 -labels=>\%labels);
```
