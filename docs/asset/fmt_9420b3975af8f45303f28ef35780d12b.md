## partition (分区/划分)

POP3 和 IMAP4 代理服务器。`id` 允许用户连接到无内容的 POP3 或 IMAP4 服务器，该服务器将重定向到其真实的 POP3 或 IMAP4 服务器。这使得域的邮件检索可以根据每个用户分布在多个后端服务器上。这也可以用作映射来确定 POSIX 正则表达式、GDBM、MySQL、PostgreSQL 和 LDAP 库的服务器，这些库有助于分布。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## partition-ldap (ldap 分区)

允许访问基于 LDAP 的 pop 映射的库。通过类似于 glibc 中 NSS 的方式通过共享库允许任意数据库访问。此包允许从 LDAP存储用户数据库。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## partition-mysql (MySQL 分区)

允许访问基于 MySQL 的 pop 映射的库。通过类似于 glibc 中 NSS 的方式通过共享库允许任意数据库访问。此包允许将用户数据库存储在 MySQL 数据库中。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## partition-postgresql (PostgreSQL 分区)

允许访问基于 PostgreSQL 的 pop 映射的库。通过类似于 glibc 中 NSS 的方式通过共享库允许任意数据库访问。此包允许将用户数据库存储在 PostgreSQL 中。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## perforate (穿孔)

用于节省空间的工具。`gpu` 通过在写入文件时使用 `seek` 并跳过不分配磁盘块来删除包含 0 填充空洞的文件，从而节省磁盘空间。遗憾的是，它不再工作了。因此，现在没有程序可以在现有文件中创建空洞。有一些脚本可以帮助清理硬盘（查找重复和/或未使用的文件）。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## perimeter-network (边界网络)

在受保护网络和外部网络之间添加的网络，以提供额外的安全层。边界网络有时被称为 DMZ。来自 Linux Guide @FirstLinux `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## peripheral component interconnect (PCI) (外部件互连接)

计算机系统的总线为计算机系统与其外设设备之间提供高速连接，允许在单个系统中连接多达七个外设设备。来自 Redhat–9–Glossary `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## perl

Larry Wall 开发的实用提取和报告语言。一种解释型脚本语言，被某些人称为“Unix 的瑞士军刀电锯”。Perl 针对扫描文本文件和系统管理进行了优化。它内置了正则表达式匹配和替换，具有一种可以提高 sed 脚本并发性的数据流机制，并且可以通过可以与 C 库接口的模块进行扩展。来自 Debian 3.0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## perl

Perl 是一种高级编程语言，源于 sed、awk 和 shell 脚本编写。Perl 擅长处理进程和文件，而且特别擅长处理文本。Perl 的特点是实用和高效。虽然它被用于执行许多不同的任务，但 Perl 最常见的应用（以及它擅长的）可能是系统管理工具和 Web 编程。网上大部分 CGI 脚本是用 Perl 编写的。你需要在系统中安装 `perl` 包，以便你的系统能够处理 Perl 脚本。你需要 `perl-base` 来拥有完整的 perl。Mandrake 9.0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## PERL

PERL 是一种流行的脚本语言。Perl 之所以流行是因为它可以运行在所有平台（UNIX、Windows 等）。它可以解析文本文件并生成报告。它很容易学习。它使用一个大型工具库来工作。它可以轻松地集成到 Web 服务器中用于 CGI。它是开源的。关键点：PERL v5 引入了“污染”输入的概念，未经预处理的内容不能传递给操作系统。这是一个极其实用的功能，解决了 CGI 脚本中的大多数输入验证问题。关键点：将 Perl 可执行文件直接放在 CGI-bin 目录下。

## persgen

构建和分析 SGML 文类型的工具。`dtd2html` 生成一组 HTML 文档，列出 SGML 类型定义 (DTD) 中每个元素的组件和特性。`dtd` 显示两个 DTD 之间的差异。`ddtree` 显示 SGML 元素的层级结构（ASCII）。`ddtree` 是一个用于研究 DTD 的交互式程序。`persist` 剥离文件的标记，并将实体引用转换为 ASCII 字符。
