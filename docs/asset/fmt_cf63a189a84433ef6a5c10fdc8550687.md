如列表 17.1 所示，`ftp` 命令需要与用户交互以将文件从远程机器传输到本地机器。我们如何自动化这个交互过程呢？如果你学习过其他章节，就会知道答案是一个 `document`（文档）。文档是一种编码技术，允许我们把所有所需的交互式命令放在两个 `labels`（标签）之间。让我们来看列表 17.2 使用这种自动化技术编写简单 `ftp` 传输的示例。

```bash
#!/bin/ksh

#
# SCRIPT: tst_ftp.ksh
## AUTHOR: Randy Michael
# DATE: 6/12/2002
# REV: 1.1.A
# PLATFRM: Not platform dependent
```
