## 如何使用选项

选项（option）是一种命令类型。当你想要执行标准函数的变体时，就会指定一个选项。选项的语法可能根据命令有所不同，但大多数选项以连字符（-）开头。

### 5.3 使用命令

示例：配合命令使用选项

列出当前目录下的文件或目录。

+ 1 输入小写字母 "ls"。

```bash
root@server /root]# ls
```

+ 2 按空格键。

```bash
root@server /root]# ls
```

+ 3 输入 "-a"。

```bash
root@server /root]# ls -a
```

+ 4 按回车。显示命令结果（在当前目录中）。

```bash
root@server /root]# ls -al
.bash_logout
.bash_history
.bash_profile
.bashrc
.shrc
```
