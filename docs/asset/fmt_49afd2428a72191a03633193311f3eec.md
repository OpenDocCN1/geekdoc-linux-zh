
- 如果在不带下标的情况下引用数组变量，则引用的值为数组的第一个元素：

  `$ print $planets`

  Mercury

- 数组变量不能导出。

- 可以使用特殊表达式 `${#name[*]}` 或 `${#name[@]}` 获取数组中非空元素的个数。例如，

```
$ print There are ${planets[*]} planets: ${planets[*]}
There are 5 planets: Mercury Venus Earth Uranus Pluto
```

- 你必须使用大括号语法来引用数组元素。如果没有大括号，Korn shell 将以 Bourne shell 的相同方式解释表达式。例如，

```
$ print The known planets are ${planets[*]
The known planets are Mercury[*]
$ print The second planet from the Sun is $planets[2]
The second planet from the sun is Mercury[2]
```

## 数组变量

数组变量是具有多个值的变量。数组变量对于管理字符串列表非常有帮助，因为你可以无需借助字符串分割技术即可处理列表中的单个元素。

你可以通过赋值语句一次性为数组分配值。例如，

```
$ planets[1]=Mercury
$ planets[2]=Venus
$ planets[3]=Earth
$ print ${planets[2]}
Venus
```

Shell 支持通用语法 `name[script]` 来引用数组元素。下标支持 0 到 511 范围内的整数，或者编写一个具有所需元素编号值的变量表达式。元素从 0 开始。数组中的第一个元素是 `${name[0]}`。

你可以使用 `set -A` 命令通过一条语句设置多个数组元素。例如，前面的代码可以重写为：

```
$ set -A planets Mercury Venus Earth
$ print ${planets[2]}
Venus
```

你还可以使用特殊符号 `${name[*]}` 或 `${name[@]}` 来替换数组的元素。

```
$ set -A planets Mercury Venus Earth
$ planets[5]=Pluto
$ planets[7]=Uranus
$ print The known planets are: ${planets[*]}
The known planets are: Mercury Venus Earth Uranus Pluto
```

使用数组变量时你应该记住以下几点：

Korn shell 自动定义了一个等同于 `typeset -i` 的整数别名 `integer`：

```
alias integer="typeset -i"
```

你可以使用该别名让你的整数定义更具可读性，如下所示所示：

```
integer x y
read x y
let sum=x+y
print $sum
```

`typeset` 的第二次用法（用于为变量设置格式选项）主要适用于希望生成格式化输出的 shell 脚本编写者。格式选项 `-L`、`-R`、`-LZ` 和 `-RZ` 也用于生成文件名。假设你想创建一系列以四位数字结尾的文件。通过使用 `typedef` 语句：

```
typeset -Z4 suffix
```

你可以使用如下代码轻松生成所需的文件名：

```
typeset -Z4 suffix=0
while ...
  let suffix=suffix+1
  print samplefile.$suffix
done
```

Korn shell 会将 `$suffix` 的值在四个字符字段内自动右对齐，并用零填充数字至四位。因此，它会生成系列文件名 `samplefile.0001`、`samplefile.0002` 等。

使用 `let` 执行算术计算。`let` 语句是 shell 支持算术运算的第二个主要元素，其语法非常简单：

```
let expr
```

对于 `expr`，你编写一个由项和运算符组成的表达式。项是一个变量或字面量——例如 `3` 或 `512`。字面量假设是以 10 进制编写的。你可以通过使用 `radix#number` 格式指定任何进制，其中 `radix` 是基数，`number` 是值。对于大于 10 的进制，数字由字符 0 到 9 以及 A 到 Z 组成。例如，在进制 16（十六进制）中，数字为 0 到 9 以及 A 到 F。

shell 还支持使用括号进行表达式分组。括号内的表达式在评估其外部的任何项之前会作为一个单元求求。括号用于覆盖运算符的正常优先级。

表 11.13 中的运算符按优先级从高到低列出。shell 对算术运算符使用常规优先级，这你从 C 语言语言或普通计算器中已知。由于这些规则，表达式 `a+b*y` 会先计算 `b*y`，然后将结果加到 `a`，就像表达式被写成 `a+(b*y)` 一样。通过括号，你可以改变计算顺序。例如，`(a+b)*y` 将通过先加 a 和 b，然后将和乘以 y 来计算。

`let` 命令是一个内置命令。像任何命令一样，它会设置一个退出值。如果计算的最后一个或唯一的表达式的值非零，则 `let` 命令的值为 0。如果唯一的表达式求值为 0，则 `let` 命令的退出值为 0。

该解决方案的关键元素是使用 `let` 语句来计算和。它将计算出的结果存储在一个名为 `sum` 的新变量中，稍后可以引用。

你可能认为使用处理程序（handler）是在键盘上执行简单算术问题的更简单的方法，我对此倾向于同意你的观点。在键盘输入上，更有效的方法实际上是直接使用 `expr` 命令。例如：

```bash
$ expr 4 + 9
```

`expr` 在键盘输入上实现了求和，但在 shell 脚本内部它的作用有限，因为 `expr` 计算的结果无法直接获取以供使用。

现在考虑这个计数器控制循环的示例：

```bash
integer i=0
while (( i<5 ))
do
  i=i+1
  print $i
done
```

这个小程序简单地打印从 1 到 5 的数字。注意这里使用了赋值语句而不是 `let` 命令来增加 `i`。这之所以能通，是因为变量 `i` 之前被声明为整数。该示例在键盘输入上运行良好。请试一下。

为了一个更实用的示例，请考虑以下内容：

```bash
$ typeset -i16 hex
$ hex=125
$ print $hex
16#7d
```

在这里，变量 `hex` 被声明为整数并以 16 进制表示。第二行给 `hex` 变量分配了一个普通的数值，第三行将其打印出来。通常情况下，`typeset` 命令中 `16` 的效果是明显的：`hex` 的值以十六进制（基16）法显示。反向操作——从十六进制转换为十进制——同样简单：

```bash
$ integer n
$ n=16#7d
$ print $((n))
125
```

在键盘输入上，在你声明了 `hex` 和 `n` 变量后，它们将保持长期有效。你可以反复使用它们在十六进制和十进制之间转换。

```bash
$ hex=4096; print $hex
16#1000
$ n=16#1000; print $((n))
4096
```

# Shell 编程

尽管 Korn shell 特性的主要动力是提高键盘输入效率，但 Korn shell 也为编写 shell 脚本提供了许多便利，这使得 Korn shell 成为一个吸引人的程序开发环境。本节回顾了适用于 shell 脚本编写的 Korn 扩展。当然，Bourne shell 的所有编程结构均可用，因此第 9 章的内容同样适用于 Korn shell，且此处不再重复。

对编写 shell 脚本有用的 Korn 扩展是条件表达式，它们增强了以下内容的灵活性：

- `if`、`while` 和 `until` 语句

- 数组、整数变量、扩展变量表达式和算术表达式

- 一个新的 `select` 语句，用于构建提示菜单，用户可以从中选择选项

- 对函数的扩展支持，包括自动加载函数（autoload functions）

- 命令表达式 `$(())` 的增强形式，它比反引号形式更易使用

- 使用操作符 `|&` 对与处理进行通信的扩展支持

如果你打算编写将由许多人使用的 shell 脚本，那么将此内容放在脚本的第一行是明智的：

```bash
#!/bin/ksh
```

这告诉 shell 该脚本实际上应该在何种 shell 下运行。例如，在 C shell 下运行 Korn shell 脚本，无论你如何尝试都是行不通的！

本章早前的“变量”部分讨论了 Korn shell 的扩展变量支持，包括数组变量、整数变量、变量引用表达式和算术表达式。其他新功能将在后续章节中解释。

# 条件表达式

`if`、`while` 和 `until` 语句支持两种新类型的表达式。`(( ))` 双括号运算符计算算术表达式，允许你执行复杂的算术测试。结果为零被视为真，非零结果被视为假。你也可以像写 `if`、`while` 或 `until` 那样编写扩展条件表达式。条件测试表达式具有如下通用格式：

```bash
[[ conditional-exp ]]
```

其中 `conditional-exp` 是表 11.14 所示的任意形式。

注意，条件表达式的形式与 `test` 或 `[ ]` 表达式相似。Korn shell 对 `test` 和 `[ ]` 表达式的支持与 Bourne shell 完全相同。`[[ ]]` 表达式提供了扩展功能，同时没有牺牲与 Bourne shell 的兼容性。

| 表达式 | Bourne Shell | 为真时的条件 |

| --- | --- | --- |

| -r file | Yes | 文件存在。 |

| -w file | Yes | 文件存在且启用了写权限。即使设置了写权限或其位于挂载为只读的文件系统中，该文件也可能是不可写的。 |

| -x file | Yes | 文件存在且设置了执行权限。该文件可能不可执行。目录通常设置了执行标志。 |

| -f file | Yes | 文件存在且是一个普通文件。 |

| -d file | Yes | 文件存在且是一个目录。 |

| -c file | Yes | 文件存在且是一个字符特殊文件。 |

| -b file | Yes | 文件存在且是一个块特殊文件。 |

| -p file | Yes | 文件存在且是一个命名管道。 |

| -u file | Yes | 文件设置了用户 ID 位 (Set User ID)。 |

| -g file | Yes | 文件设置了组 ID 位 (Set Group ID)。 |
