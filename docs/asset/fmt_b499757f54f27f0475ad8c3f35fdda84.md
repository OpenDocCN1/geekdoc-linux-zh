# 配置 iptables

首先，让我们来看 `iptables` 的语法。

```
Syntax: iptables [options] [chain] -j [target]
```

选项：

- `-A` `chain` 向链末尾追加
- `-D` `chain` 从链中删除
- `-I` `chain` 向链中插入
- `-L` `chain` 列出所有规则
- `-p` `proto` 使用指定的协议
- `-m` `match` 匹配扩展表达式
- `-s` `address` 定义源地址
- `-d` `address` 定义目的地址

链：

- `INPUT` 进入系统的数据包
- `OUTPUT` 离开系统的数据包
- `FORWARD` 在网络之间转发的数据包

目标：

- `ACCEPT` 允许数据包
- `DROP` 丢弃数据包
- `REJECT` 拒绝数据包

首先，请注意这些是最常用的目标。

当你定义规则时，需要考虑几个因素：方向、协议、动作和目标。
