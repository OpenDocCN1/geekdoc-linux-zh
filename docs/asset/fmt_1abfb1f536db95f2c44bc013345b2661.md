
在开孔之前，确保你位于两根墙柱之间。检查电源插座以确定正确的高度，使开口匹配。此外，确保对面墙上没有电源插座。你可能会切到某些线路，因为布线有时会在同一高度横跨墙面。为了避免这种情况，勾勒出要切割的区域。使用小刀或美工刀切割墙板。注意不要让刀尖伸进墙内太深。一旦开好孔并确定安全，你可以使用小锯或更大的刀清理切割边缘。

## 网络布线

为了将设备连接到网络，我们需要在设备之间使用某种介质，以便数据包从一个设备传输到另一个设备。这就是网络布线的用武之地。你可以使用不同类型的电缆来连接网络，但在今天现代硬件条件下，我们倾向于使用的只有两种类型。

直通以太网线有两种标准的布线方案。它们分别是 `T568A` 或 `T568B`，其中 `T568B` 是美国更常用的布线方案。两者唯一的区别是绿色对和橙色对的引脚位置对换了。任何一种方案在你的网络上都能正常工作，但除非你想遇到通信问题，否则不要混合使用。是否使用所有四对线取决于电缆的类别。例如，旧的 `10/100Mbps` 电缆仅使用两对，而 `1Gbps` 电缆将使用所有四对线，以便同时传输和接收。

有些人喜欢自己动手制作电缆，以便确定精确的长度。这是一个相当繁琐的过程，除非你非常精通，而且你还需要用电缆测试仪测试每一根制作的电缆，以确保其工作正常。

### 交叉线

交叉线用于连接类似的设备，例如交换机到交换机、路由器到路由器，或路由器直接连接到主机。这些电缆的外观和手感相同，但布线方案是它们不同之处。它们被称为交叉线，是因为八根线中的四根线在一端的布线方式与另一端相反。

如果你留了心，可能会发现交叉线基本上就是一端使用 `T568A` 布线方案、另一端使用 `T568B` 布线方案的电缆。

为了方便记忆，这里有一张表，列出了你在什么情况下使用直通线对比交叉线。

### 回环线（Rollover Cables）

我要提到的最后一种电缆被称为回环线，也称为空调制解调线（`null modem cable`）。这些电缆用于将 PC 连接到交换机或路由器的控制端口，以便在无法通过通常的网络端口连接时执行管理功能。

回环线一端的引脚定义在另一端是反转的。一端是 `RJ45` 连接，另一端是 `DB9` 连接。`RJ45` 连接插入交换机或路由器的管理端口，而 `DB9` 将连接到计算机的串口。大多数新电脑已不再有串口了，因此你除了回环线外还需要一个 USB 转串口适配器。一些高端交换机现在带有用于管理的微 USB 端口，因此你实际上可以使用 USB 线连接，甚至可以使用智能手机！

现在你已经知道什么是以太网线以及它是如何布线的，我想花一点时间讨论一下以太网线的类别。在 `Cat5e` 之前有一些变体，之后也有一些，这里是以太网线标准及其最大速率能力的快速摘要。

- 第3类（`Category 3`） – `10Mbps` 和 `16Mhz` 频率
- 第4类（`Category 4`） – `16Mbps` 和 `20Mhz` 频率
- 第5类（`Category 5`） – `100Mbps` 和 `100Mhz` 频率
- 第5e 类（`Category 5e`） – `1Gbps` 和 `100Mhz` 频率
- 第6 类（`Category 6`） – `1Gbps` 和 `250Mhz` 频率
- 第6a 类（`Category 6a`） – `10Gbps` 和 `500Mhz` 频率
- 第7 类（`Category 7`） – `100Gbps` 和 `600Mhz` 频率

这些高速（如 `1Gbps` 及以上）是通过使用四对线而非仅用两对，以及增加线芯每厘米的扭转次数来实现的。`Cat6` 及以上的电缆还有尼龙骨（`nylon spline`），这有助于消除串扰，串扰是来自一个电路对另一个电路的干扰。另一种类型的以太网线称为屏蔽双绞（`STP`），它在电线周围包裹了保护屏蔽层以进一步防止干扰问题。`STP` 电缆更贵且更难处理，因为由于屏蔽层的存在它们不够灵活。当电缆没有屏蔽层时，它被称为非屏蔽双绞线或 `UTP` 电缆。

**提示**

`99%` 的情况下，你所使用的以太网线类型会打印在电缆本身的护套上。你可能只需要看几英尺就能找到它。

通常情况下，以太网线的长度限制为 `100` 米（约 `300` 英尺），之后信号开始衰减并需要再生才能继续传输。集线器和交换机等设备会再生信号，这样你可以再传输 `100` 米而无需再次再生。

### 802.11i

`802.11` 无线连接标准的设计旨在取代早期的有线等效协议。`802.11i` 也称为强壮安全网络（`Robust Security Network`）。`802.11i` 通过 `RADIUS` 等多种协议提供认证。`802.11i` 还支持 `CCMP` 加密。值得，`802.11i` 允许在不更换硬件的情况下升级有线等效协议。

### 认证

Wi-Fi 安全联盟（`WPA2`）认证其符合 `802.11i`。通过由中央机构管理开发，一致性和质量可能得到保证。此外，拥有一个协调的中心点对于增强安全性是必要的，可以确保只有意良好的实体参与开发。

### 临时密钥完整性协议

`TKIP` 指的是对于 WLAN `802.11i` 标准不可或缺的加密协议，它的设计旨在提供比有线等效协议更安全的加密。在应用中，`TKIP` 由一组算法组成，这些算法作为有线等效协议的封装，允许旧局域网设备在无需更换硬件的情况下升级。`TKIP` 通过利用早期的有线等效协议工作。`TKIP` 通过增加四个额外算法增强稳健性：

- 密文消息完整性检查：它是一种向量序列机制，使用哈希算法而不是有线等效协议的明文传输。哈希意味着数据已加密并赋予一个唯一值，可以通过检查该值来确认传输期间是否有修改。
- 逐包密钥混合函数：通过混合加密密钥，恶意用户破坏数据完整性变得越来越困难，因为破解加密所需的计算能力变得几乎不可不可及。
- 重新密钥技术：通过为每固定数量的传输数据包创建新密钥，攻击者很难在截获的数据中建立共同模式，这增强了无线连接的安全性。

相比之下，`TKIP` 对于升级最初配备有线等效协议的设备的安全性至关重要，但它无法解决有线局域网连接面临的所有安全问题，并且对于敏感的政府和企业数据传输来说可能不够高效或可靠。高级加密标准（`AES`）在 `802.11i` 标准中与 `TKIP` 一起被规定。`AES` 提供了更高程度的安全性并被推荐。

政府使用，但需要升级硬件才能实施。由于大多数组织正在更换旧的无线接入器和支持无线功能的设备，高级加密标准（`AES`）有望成为无线连接安全的标准加密方法。

带计数模式密码分组链消息认证码协议（`CCMP`）。

作为一种加密标准，带计数模式的密码分组链消息认证码协议是 `802.11i` 无线连接标准不可或缺的一部分，特别是实现 `WiMax` 技术的连接。

`CCMP` 算法基于美国联邦政府的高级加密标准。可以认为该标准旨在为无线连接提供最高程度的数据加密。

与 `TKIP` 等类似技术相比，`CCMP` 协议提供了更高的安全性。特别是，带计数模式的密码分组链消息认证码协议部署了 `128` 位密钥以及 `48` 位初始化向量，这降低了对重放攻击的脆弱性。具体而言，计数模式组件提供了数据隐私性。另一方面，密码分组链消息认证码元素提供了数据完整性和验证。与 `CCMP` 协议的临时密钥完整性协议（`TKIP`）相比，增加的隐私性和安全性在大多数情况下需要额外的处理能力来处理，这需要升级硬件。

### 网络扫描

网络扫描是一种用于识别计算机网络上活动主机的过程，可用于安全评估或进行攻击。端口扫描和 `ping` 扫描（`ping sweeps`）等方法提供了如 `IP` 地址到互联网上活动主机的映射等信息。此外，网络扫描至关重要，因为它能够让攻击者通过返回未映射到活动主机的 `IP` 协议地址数据来假设可行地址。扫描是入侵者或攻击者收集情报的一个组件。在扫描期间，入侵者可以获得有关连接或网络上可见的实际 `IP` 地址、每台计算机上运行的服务、操作系统以及系统架构的数据。网络扫描具有以下目的：

- 识别目标主机上运行的可用 `TCP` 和 `UDP` 网络服务
- 通过监控 `IP` 响应确定使用的操作系统类型
- 评估目标主机的 `TCP` 序列
- 识别目标主机与用户之间的过滤系统
