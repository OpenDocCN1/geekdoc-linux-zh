
- `binary`—以二进制形式下载任何指定的文件。在下载大多数压缩的 Linux 文件之前，你必须使用此命令。
- `bye`—关闭任何打开的连接并退出 `ftp` 程序。
- `cd`—切换目录，例如：

```
> cd ..
```
- `close`—关闭当前连接。
- `get`—从当前目录下载特定文件到你的当前目录，例如：

```
> get killbarney.tgz
```
- `is`—列出当前目录下的文件或目录。
- `mget`—一个一个匹配指定模式的多个文件，例如：

```
> mget kill*.tgz
```
- `open`—打开到指定主机的连接，例如：

```
> open ftp.mcp.com
```

例如，要交互式运行 `ftp` 命令，你只需要输入：

