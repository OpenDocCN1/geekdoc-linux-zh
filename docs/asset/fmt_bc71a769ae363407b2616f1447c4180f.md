
## 描述

`whois` 为标识符搜索互联网目录条目，标识符可以是名称（如 `Smith`）或句柄（如 `SRI-NIC`）。

标识符前的以下字符可以修改搜索：

- `-` 强制仅进行名称搜索。
- `!` 强制仅进行句柄搜索。
- `.` 搜索组或组织实体。该组的完整成员列表将随记录一起显示。

当然，你可以使用感叹号和星号，或者句号和星号组合。

## 选项

- `-n host` 指定要搜索的主机名。

### 操作数

- `identifier` 指定要在互联网目录中搜索的名称（如 `Smith`）或句柄（如 `SRI-NIC`）。

## 示例

以下命令查找名称或句柄 `Smith`。
```
caste% whois Smith
```

以下命令仅查找句柄 `SRI-NIC`。
```
caste% whois !SRI-NIC
```

以下命令仅查找名称 `John Smith`。
```
caste% whois .Smith, John
```

在名称或句柄参数后添加 `...` 将匹配从该点开始的任何内容；例如，`ZU...` 会匹配 `ZUL`、`ZUM` 等。

关于以下属性的描述请参见 `attributes(5)`：

| 属性类型 | 属性值 |
|---|---|
| 可用 | `SUNWcsu` |

# write — 写入另一个用户

### 概要

`/usr/bin/write user [terminal]`

## 描述

你可以使用 `write` 命令向单个用户的终端发送消息。当使用如 `CDE` 或 `OpenWindows` 这样的窗口系统时，每个窗口被视为一个独立的日志。如果用户登录了多次，消息将定向到控制台窗口。

`write` 命令从标准输入读取行并将其写入另一个用户的终端。当首次调用时，它向用户写入以下消息：

`Message from sender-login-id (sending-terminal) [date]...`

当 `write` 成功完成后，接收者可以通过输入以下命令进行回复
```
write sender-login-id [terminal]
```

建议使用 `write` 的协议如下：当你第一次向另一个用户写信息时，等待他回复后再开始发送。每个人都应该在消息结束时加上明显的信号（例如，`o` 表示结束），以便对方知道何时回复。当对话结束时，建议使用信号（`oo` 表示结束并退出）。

你也可以通过以下语法使用 `write` 命令重定向文件消息：
```
write username < filename
```

### 操作数

- `user` 接收消息的用户名。此操作数必须是 `who(1)` 命令返回的格式。
- `terminal` 与 `who` 命令提供的相同的终端标识。

## 环境变量

参见 `environ(5)` 关于影响 `write` 执行的环境变量：`LC_TYPE`、`LC_MESSAGES` 和 `NLPATH`。

## 状态

- `0`: 完成。
- `>0`: 目标用户未登录或目标用户拒绝写入权限。

## 文件

- `/var/adm/utmp`: `write` 用户和账户信息。
- `/usr/bin/sh`: Bourne shell 执行文件。

## 属性

关于以下属性的描述请参见 `attributes(5)`：

| 属性类型 | 属性值 |
|---|---|
| 可用 | `CSI` |
|  | `SUNWcsu Enabled` |

## 诊断

```
user is not logged on
```
你尝试写入的用户未登录。

```
Permission denied
```
你尝试写入的用户拒绝了该权限（通过 `mesg` 设置）。

```
Warning: cannot respond, set mesg -y
```
你的终端设置为 `mesg n`，接收者无法向你回复。

```
Can no longer write to user
```
在你开始写入后，接收者拒绝了权限（`mesg n`）。

# xargs — 构建参数列表并调用命令

### 概要
```
/usr/bin/xargs [-t][-p][-e[eofstr]][-E eofstr] [-I replstr]
[-i [replstr]][-L [number]][-n number] [-x]
[-s size] [command [argument...]]
```

## 描述

`xargs` 命令是一个 shell 编程工具，它允许你使用一个命令的输出来定义另一个命令的参数。`xargs` 命令会构建一个命令行，该命令行由指定的命令和参数操作数组成，随后紧跟从标准输入中顺序读取的参数，直到达到选项指定的长度和数量限制为止。然后，`xargs` 命令会调用所构建的命令行并等待其完成。此序列将重复，直到在标准输入上检测到文件结束（EOF）条件，或者构建的命令行的调用返回退出状态 `255`。

使用引号的空白字符、未转义的空白字符或换行符将标准输入中的参数隔开。你可以通过双引号将零或多个非双引号(`"`)和非换行符的字符括起来。你可以通过单引号将零或多个非单引号(`'`)和非换行符的字符括起来。你可以通过在斜杠（`\`）前面对任何未引号的字符进行转义。命令执行一次或多次，直到达到文件结束。如果命令尝试从其标准输入读取内容，结果将未定义。

生成的命令行长度是命令名称和每个参数被视为字符串时的字节大小之和，其中每个字符串都包含包含空空字节终止符。`xargs` 命令限制了命令行长度，以便在调用命令时，所调用的参数和环境列表不超过 `[ARG_MAX]-2048` 字节。在这一限制范围内，如果你既没有指定 `-n` 也没有指定 `-s` 选项，则默认命令行长度至少为 `[LINE_MAX]`。

## 选项

- `-eofstr` 使用 `eofstr` 作为逻辑文件结束字符串。如果你使用 `-n` 或 `-E`，则假设逻辑 EOF 字符串为下划线 (`_`)。输出 `-eofstr` 选项参数时，将禁用逻辑功能并字面处理下划线。读取标准输入直到遇到文件结束或逻辑 EOF 字符串。
- `-E eofstr` 指定一个逻辑文件结束字符串来替换下划线。读取标准输入直到遇到文件结束或逻辑 EOF 字符串。
- `-i replstr` 等同于 `-i replstr`。如果你省略选项参数，则假设 `replstr` 为 `()`。
- `-I replstr` 为标准输入中的每一行执行命令，将整行视为单个参数，并将其插入到 `replstr` 每次出现的位置参数中。你可以在参数中使用最多五个参数，其中包含一个或多个 `replstr`。忽略每行开头的任何空白字符。构建的参数不能大于 `255` 字节。选项 `-x` 和 `-i` 选项互斥；最后一个指定的将生效。
- `-n number` 如果省略了 `number`，则默认为 `1`。强制开启 `-x` 选项。等同于 `-L number`。
- `-L number` 为标准输入中的每 `number` 个非空行执行命令。命令的最后一次调用剩余的行数少于 `number`。除非行的最后一个字符是空白字符，否则认为行在第一个换行符结束；尾随字符指示连接到下一个非空行（包含该行）。`TL`、`1` 和 `-n` 选项互斥；最后一个指定的将生效。
- `-n number` 调用命令，尽可能多使用标准输入参数，最多使用 `number`（一个正十进制整数）个参数。在以下情况下将使用的参数较少：
    - 累积的命令行长度超过了 `-s` 选项指定的尺寸（如果没有 `-s` 选项，则为 `{LINE_MAX}`）。
    - 最后一次迭代剩余的操作数少于 `number` 但大于 `0`。

在每次调用时提示是否执行命令。开启跟踪模式 (`-t`) 可将要执行的命令实例写入标准错误，随后紧跟一个指向标准输出的提示符。从 `/dev/tty` 读取的肯定答复（取决于用户的本地设置）将执行命令；否则，跳过该特定的命令调用。

调用命令，尽可能多使用标准输入参数，并产生一个小于 `size`（一个正十进制整数）字节的命令行。在以下情况下将使用的参数较少：
    - 参数总数超过了 `-n` 选项指定的数量。
    - 总行数超过了 `-L` 选项指定的数量。
    - 在累积到 `size` 之前在标准输入上遇到了文件结束。

在满足指定限制的情况下，支持至少 `(LINE_MAX)` 的尺寸。你可以给出大于实现支持或超过指定限制的值；`xargs` 在限制范围内使用其支持的最大值。启用模式 (`-t`) 将每行命令行写入标准错误。

### 操作数

要调用的命令名称，使用 `PATH` 搜索路径；如果省略了命令，默认为 `echo`。

## 使用

输入被解析为行；空白字符用于隔开参数。如果使用 `xargs` 来打包如 `find` 或 `ls` 等命令的输出，如果文件名包含任何空白字符，可能会产生意外结果。你可以通过使用 `find` 将任何字符串转换为 `xargs` 解析的引用形式来解决此问题。

> 注意 — `xargs` 的引用规则与 `shell` 不同。由于应用程序依赖于当前的规则，因此未未保持一致。

## 示例

以下示例将目录 `$1` 中的所有文件移动到目录 `$2`，并在执行前打印每个 `mv` 命令。
```
ls $1 | xargs -I {} -t mov $1/ $2/
```
