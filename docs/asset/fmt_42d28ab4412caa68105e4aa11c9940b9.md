光学棱镜：一种简单的组件，由玻璃等折射性透明材料制成，并由两个或多个成角的表面面边界，用于实现光的方向旋转、反转或将光色散为其包含的光色。当光进入棱镜后，在离开棱镜之前会经过多次折射。

棱镜可以根据其功能进行分类。某些棱镜（如鸽子镜）可用于旋转和改变其手性。双远镜中的图像反转就是一个典型应用。某些棱镜利用内反射现象来偏转光，例如直棱镜和双目相机中使用的棱镜。在光学楔中，它可以用于改变光方向，也可以在各种应用中用角反射装置。

棱镜的一个重要应用是偏转光。当光从棱镜的一个面进入时，会发生折射。折射率取决于波长，因此光以不同的角度折射并色散成光谱。蓝光的弯曲程度比红光大。当光到达棱镜边缘时，会再次发生折射，根据棱角，入射偏角可以增加或抵消。

# 光脉冲

光脉冲用于传输信息或记录频率事件的时间顺序。最简单的例子是摄影闪光灯。随后早期摄影师发现，当点燃时，短促的光脉冲非常强烈。随后是长尾光，例如氙气被短促的闪光脉冲激发。产生短光脉冲的一个绝佳例子是激光。

激光是产生高强度、持续时间和能量的短光脉冲最常见且有效的方法。参见：激光；光谱学；摄影。

皮秒脉冲（10⁻¹² s）可以通过机械调制恒定光源（如灯或空腔谐振器）产生。这可以通过将光源替换为高质量空腔来实现。更短的脉冲（10⁻¹² s）或飞秒脉冲（10⁻¹⁵ s）是使用称为调Q锁的技术产生的。锁模器件集成在激光空腔结构中，并将脉冲转换为输出。锁模器件通常由外部脉冲产生。参见：信号通信；纤维。

持续时间为皮秒（1 ps = 10⁻¹² s）或飞秒（1 fs = 10⁻¹⁵ s）的光脉冲是通过一种称为模式锁的通用原理产生的，其中激光的几个频率模式被瞬间重建并叠加，从而在激光器处形成短持续时间脉冲。
