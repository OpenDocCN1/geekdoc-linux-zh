
# pSeries 服务器系列

## `pSeries 640`

`pSeries 640` 是一款机架式服务器，专为电子商务和电信应用中的高密度服务器集群设计。此外，`p640` 中使用的 1-4 路 `POWER3-II` 微处理器为许多 `HPC`（高性能计算）应用提供了所需的浮点能力。`pSeries 640` 符合 `NEBS Level 3` 标准，适用于电信和恶劣环境。

## `pSeries 650`

`pSeries 650` 是 IBM 最受欢迎的中端服务器。这台 2-8 路机架式系统提供 1.2 GHz 或 1.45 GHz `POWER4+` 处理器、`LPAR` 支持，并具有连接最多 `IBM 7311-D10` 或 `IBM 7311-D20` I/O 扩展机箱的能力。对于 `pSeries` 中端线顶端的 `p650`，IBM 为增长需要此类扩展的客户提供了向 `p690` 的型号转换。
