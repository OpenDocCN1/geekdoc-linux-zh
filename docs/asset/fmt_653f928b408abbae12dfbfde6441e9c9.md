
# 炎症反应

炎症反应的早期阶段是定型的：一系列发生在具有高度多样性组织中的事件，但其特征是充血、水肿和细胞成分附着在血液中。白细胞通过小血管的内皮细胞迁移。随后的炎症过程由诸等因素决定。

局部炎症，对损伤的局部反应，涉及小血管、其中循环的细胞和结缔组织。
