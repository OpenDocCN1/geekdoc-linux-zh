
### 从字符设备子菜单启用 PTY 支持

从字符设备 (Character) 子菜单通过选择“使用的最大 PTY 数量 (0-2048)”来启用 PTY 支持。系统默认有 256 个 PTY。每次登录都需要单个 PTY。

如果您预计会有超过 256 个并发登录的会话，请设置一个 256 到 2048 之间的值。每个 PTY 至少使用 4 KB 内存。确保您有足够的内存来满足并发登录会话的数量。

## SMP 实时时钟支持

如果您使用多个 CPU（启用了对称处理支持），请启用增强型时钟 (RTC)，以便以 SMP 兼容的方式进行设置。要启用 RTC，请从字符设备 (Character devices) 子菜单启用增强型时钟选项。

## 数据包过滤 (防火墙) 选项

您可以在内核中配置许多其他选项，到目前为止讨论的选项应该是为您的系统构建精简自定义内核的良好开始。保存您创建的配置，并按照后续章节中讨论的内容编译内核。

## 编译内核

编译配置好的内核需要检查源码依赖项，然后编译内核镜像。源码依赖检查可确保用于您选择的功能的所有源文件都是可用的。镜像过程编译源代码并为内核和模块构建二进制文件。

### 检查源码依赖项

在编译内核之前，您需要确保所有源码依赖项状态良好。为此，您可以以 root 身份从 `/usr/src/linux` 运行 `make`。此命令

* 执行依赖项检查
* 为镜像编译准备源码

> 如果您收到上述命令的任何错误信息，可能是源码完整性问题。在这种情况下，您必须下载一份新的内核源码并从头开始配置。在运行此命令后，您就准备好编译内核及其模块了。

### 编译镜像和模块

内核编译涉及构建镜像（二进制）文件

* 内核本身
* 必要的内核模块

后续章节将解释如何编译内核镜像和模块。

### 编译内核镜像

要创建内核镜像文件，请以 root 身份从 `/usr/src/linux` 运行 `make bImage` 命令。根据处理器速度，编译时间从几分钟不等。在具有 384MB 内存的 Pentium III 系统上，编译不到五分钟。一旦 `make bImage` 命令完成，特定架构的目录下就会创建一个名为 `bImage` 的内核镜像。例如，x86 系统的新内核 `bImage` 文件位于 `/usr/src/linux/arch/i86/boot`。

### 编译并安装模块

在内核配置的过程中，您至少设置了一个功能作为内核模块，因此您需要编译并安装模块。使用以下命令编译并安装内核模块。

- `make modules`
- `make modules_install`

> 如果您正在编译当前系统上运行的相同版本的内核，请先备份 `/lib/modules/x.y.z` 模块（其中 `x.y.z` 是内核版本号）。您可以简单地运行 `cp -r /lib/modules/x.y.z /lib/modules/x.y.z.current`（通过将 `x.y.z` 替换为相应的版本号）创建当前模块备份。命令完成后，所有新模块将安装在 `/lib` 中的一个新的子目录下。

## 启动新内核

在启动新内核之前，必须先安装它。这是一个非常重要的一步。您必须非常小心，以便在新内核出现问题时仍然启动旧内核。现在您可以安装新内核并配置 LILO 启动任意内核。

### 安装新内核

Linux 内核保存在 `/boot` 目录。如果您打开 `/etc/lilo.conf` 文件并寻找类似 `image=/path/to/kernel` 的行，您会看到类似 `image=/boot/vmlinux-x.y.z` 的内容（其中 `x.y.z` 是版本号）。使用 `cp /usr/src/linux/arch/i86/boot/bzImage /boot/vmlinux-x.y.z` 拷贝新内核（不要忘记将 `x.y.z` 替换为版本号）。例如，安装新的 2.4.1 内核的命令是

```
cp /usr/src/linux/arch/i386/boot/bzImage /boot/vmlinux-2.4.1
```

### 配置 LILO

LILO 是引导程序，在启动新内核之前必须对其配置。按照如下方式编辑 LILO 配置文件 `/etc/lilo.conf`：

1. 复制定义当前镜像及其设置的 lilo 部分。例如，列表 2-1 显示了一个带有单个内核定义的示例文件。目前目前，lilo 启动标记为 linux 的内核（因为设置了 `default=linux`）。

Listing 2-1: `/etc/lilo.conf`

```
boot=/dev/sda
map=/boot/vmlinux-2.4.0
prompt
timeout=50
message=linux
default=linux
image=/boot/vmlinux-2.4.0
label=linux
read-only
root=/dev/sda
```

2. 在 `/etc/lilo.conf` 的末尾附加以下行：

```
boot=/dev/sda
map=/boot/vmlinux-2.4.1
prompt
timeout=50
message=linux
default=linux2
image=/boot/vmlinux-2.4.1
label=linux2
read-only
root=/dev/sda
```

3. 将镜像路径更改为新内核。例如，将 `/usr/src/linux/arch/i86/boot/bzImage` 改为 `/boot/vmlinux-2.4.1`。

Listing 2-2: `/etc/lilo.conf` (更新后)

```
boot=/dev/sda
map=/boot/vmlinux-2.4.1
prompt
timeout=50
message=linux
default=linux2
image=/boot/vmlinux-2.4.1
label=linux2
read-only
root=/dev/sda
```

4. 将标签改为 `linux2`。

5. 运行 `/sbin/lilo` 使用更新后的 `/etc/lilo.conf` 重新配置 lilo。永远不要从远程尝试新内核。始终从控制台重启系统。

### 重启新内核

安装新内核后，按照以下步骤进行首次重启：

- 使用 `/sbin/shutdown -r now` 命令从控制台重启系统。在重启过程中，你会看到 lilo 提示符。
- 在 lilo 提示符处输入 `linux2`。

默认的 `linux` 会加载旧内核。通过与新内核关联的新标签 `linux2`，您的系统尝试加载新内核。假设一切顺利，它应该正常启动并显示登录提示符。

1. 在登录提示符处，从控制台以 root 身份登录。
2. 登录后，重新运行 `uname -a` 命令，它应该显示内核版本号以及其他信息。

这是一个示例输出：

```
Linux rhat.nitec.com 2.4.1 #2 SMP Wed Feb 14 17:14:02 PST
2001 1686 unknown
```

我将版本号加了粗体。`#2` 反映了内核构建此内核的次数。

# 第一部分：系统性能

## 1. 确定整个系统的文件句柄数量

要查找文件句柄的数量，请运行 `cat /proc/sys/fs/file-max` 命令。你应该看到一个类似 4096 或 8192 的数字。

## 2. 要增加文件句柄数

要增加文件句柄数（通常称为文件描述符），请在你的 `/etc/rc.d/local` 脚本中添加以下行（将 `nnn` 替换为你需要的句柄数）：

```bash
echo nnnn > /proc/sys/fs/file-max
```

以下行将系统级文件句柄总数设置为 10240 (10K)：

```bash
echo 10240 > /proc/sys/fs/file-max
```

### 启动大量线程

使用大量线程将达到系统的并发进程能力。要设置每个进程的文件句柄限制，请遵循以下步骤：

1. 编辑 `/etc/security/limits.conf` 文件并添加以下行：

```text
* soft nofile 1024
* hard nofile 8192
```

前面的代码将文件句柄限制设置为 8192。

2. 确保 `/etc/pam.d/system-auth` 包含如下所示的行：

```bash
session required /lib/security/pam_limits.so
```
