# 850 乙醇

生物在处理特定情况时所具有的先天倾向。

对世界的感知为思想和行动提供了基础。生态学的一项基本公理是：每个生物的大脑连接着基因决定的动作模式，这些模式反过来控制着发育大脑等神经结构的遗传程序。因素表明，可以通过经验回忆起修改动作模式的需求。动作模式由大脑控制，虽是先天的但受控，且在不同物种之间往往不同。固定模式的概念对于理解由大脑产生的各种行为模式的表达至关重要，这些模式是每个有机发育的神经单元。这些模式中的每一种都由单一刺激触发，但其可选范围虽然有限，但足以通过经验进行调整来改变。仔细研究发现，模式中动作的灵活性大于构建复杂动作的模式本身。因此，在由于物种结构和生活方式决定的动作模式要求存在差异的物种中，神经系统可能具有某些灵活性。动物学家通过实验发现，在受限环境中，动作和模式的自然发育程度受到限制，每种动物都必须学习如何将它们组合成适应性的序列。

关于学习的现代研究，洛伦兹在实验中发现一只小鸭可以通过对他产生印记来执行复杂的行为。在此过程中，它们可能关注自己的想法。学习在生命早期的关键期发生非常快。学习受到遗传偏好的高度关注，以遵循具有特定亲和力和特定物种特定会合线索的模式-物体，并学习什么是最用的。学习中天性（遗传倾向）与后天（环境影响）之间的相互作用在印记中表现得非常清楚，其存在的特异性表明，它不是为了学习物种知识，而是为了学习对每个个体有利的事物，并在适当的时间与同类交配。

印记有许多形式。所谓的印记（确保小鸭和鹅子只跟随父母）与性印记是不同的，后者会影响成年后的许多选择；而前者发生在生命中更晚的阶段。类印记过程也塑造了行为偏好的发展以及在各种情况下使用这些偏好的能力。

对印记的各种早期研究倾向于反驳大脑对学习贡献的“白板”观点，动物行为学强调需要理解所研究物种的生物学各个方面，以应对个体生存和社会生活的许多复杂性。尽管今天人们正在探索大脑如何作为个体学习来应对社会和环境问题。参见：通讯；行为遗传学；本能行为。[P.]
