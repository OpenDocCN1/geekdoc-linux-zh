## 13 避免 GPIO 故障

树莓派倾向于让扩展引脚排变得非常拥挤，这给廉价处理器的制造商带来了问题。建议通过一组定义来处理引脚与功能之间的映射关系。我们选择的是带有短引脚的树莓派——40 引版本，这需要将某些物理引脚映射到逻辑 GPIO 编号。

```cpp
int blockCounter=0;
int rowCounter=0;
while(1) {
  if (blockCounter==16) {
    blockCounter=0;
  }
  if (rowCounter==0) {
    blockCounter=0;
    rowCounter++;
  } else {
    blockCounter++;
    rowCounter++;
  }
```
