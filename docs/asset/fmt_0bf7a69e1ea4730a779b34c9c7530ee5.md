### id
一个 UNIX 命令，用于识别执行命令的用户，包括 UID、GID、组和关联名称。关键点：这是黑客攻入内存后在系统上运行的第一条命令。黑客将远程破坏运行在 root 账户下的服务、为该服务设置的账户（例如名为 'majority' 的主要服务）或用户账户。黑客希望他们立即获得了 root 权限。如果没有，黑客将不得不运行本地漏洞来提升权限。黑客可能执行的其他命令是 `id`。示例：在我的结果之一上以 root 运行 `id`：`uid=0(root) gid=0(root) groups=0(root),1(bin),2(daemon),3(sys),4(cmd),6(disk),10(wheel),1(floppy)` 来自 Lexicon

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### id3
一个 ID3 标签编辑器（ID3 Tag Editor），这是一个可以列出、修改或删除文件来自 ID3 标签的命令行程序。ID3 标签是流媒体文件的时代。你可以在标签中存储艺术家、标题、专辑和类型，以及 2 字符的注释。来自 Debian 3.0r0

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### id3ed
另一个 `id3` 标签编辑器命令行程序，允许你在 `mp3` 文件上添加/编辑/删除 `id3` 标签。它通过文件名运行，以交互式地更改标签。像其他 `id3` 标签编辑器一样，它仍然可以在脚本中方便使用。来自 Debian 3.0r

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### id3ren
`id3` 标签和重命名工具，通过读取文件末尾包含歌曲名的 `id3` 标签来批量重命名 `mpeg` 文件。用于 `id3` 标签的命令行编辑器。在需要从脚本编辑 `id3` 标签时强烈推荐。也可用于读取 `id3` 标签。在需要从脚本编辑 `id3` 标签时强烈推荐。来自 Debian 3.0r APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
