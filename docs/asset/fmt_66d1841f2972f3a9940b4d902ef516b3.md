### 在 Kubernetes 上部署应用

让我们将之前用 docker-compose 使用的 WordPress 应用部署到我们的 Kubernetes 集群中。我们将创建两个命名空间（namespace），并将 MySQL 部署到其中一个，将 WordPress 部署到另一个中。然后，我们将打开本地端口以便我们访问 WordPress。

### MySQL

首先创建一个名为 `mysql.yaml` 的文件并传入以下内容：

`mattias@hrb:~/kubernetes$ cat mysql.yaml`

```yaml
apiVersion: v1

kind: Service

metadata:

  name: mysql

  namespace: mysql

labels:

  app: wordpress

spec:

  ports:

  - port: 3306

  selector:

    app: mysql

---

apiVersion: apps/v1

kind: Deployment

metadata:

  name: mysql

  namespace: mysql

labels:

  app: mysql

spec:

  selector:

    matchLabels:

      app: mysql

  strategy:

    type: Recreate

  template:

    metadata:

      labels:

        app: mysql

    spec:

      containers:

      - image: mysql:5.7

        args: ["--default-authentication-plugin=mysql_native_password"]

        name: mysql

        env:

        - name: MYSQL_ROOT_PASSWORD

          value: "myrootpassword"

        - name: MYSQL_DATABASE

          value: wordpress

        - name: MYSQL_USER

          value: wordpress

        - name: MYSQL_PASSWORD

          value: password

        ports:

        - containerPort: 3306

          name: mysql
```

你可以将命名空间视为一个独立的文件夹，将我们在 Kubernetes 中运行的内容隔离开。现在，我们将如下所示创建一个命名空间来存放我们的部署：

```
mattias@hrb:~/kubernetes$ kubectl create namespace mysql
namespace/mysql created
```

命名空间已创建。现在，我们可以将 YAML 应用到 Kubernetes，如所示：

```
mattias@hrb:~/kubernetes$ kubectl apply -f mysql.yaml
service/mysql created
deployment.apps/mysql created
```
