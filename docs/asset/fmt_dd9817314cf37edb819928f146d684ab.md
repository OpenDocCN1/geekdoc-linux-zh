## 为什么卸载设备很重要

如果你查看 `free` 命令的输出（该命令显示内存使用统计数据），你会看到一个名为 `buffers`（缓冲区）的统计数据。计算机系统的设计旨在尽可能运行。系统速度的障碍之一是慢设备。打印机就是一个很好的例子。即使是最快的打印机，按计算机的标准也极其缓慢。如果计算机必须停下来等待打印机完成一页的打印，它的速度将非常慢。在 PC 的早期时代（多任务处理之前），这是一个真正的问题。如果你正在处理电子表格或文本文档，每当您打印时，计算机就会停止并变得不可用。计算机会以打印机接受的速度将数据发送到打印机，但速度非常慢，因为打印机打印得并不快。这个问题通过打印机缓冲区（printer buffer）的出现得到了解决，这是一种包含一些 RAM 的设备，位于计算机和打印机之间。有了打印机缓冲区后，计算机将打印机输出发送到缓冲区，数据会被快速存储在快速 RAM 中，这样计算机就可以无需等待继续工作。与此同时，打印机缓冲区会以打印机可以接受的速度从缓冲区内存中缓慢拉取数据。

不要让偶尔向设备写入或从设备读取数据的操作阻碍系统速度。操作系统在实际需要与较慢设备交互之前，会尽可能长时间存储已读取并准备写入存储设备的数据。例如，在 Linux 系统上，你会注意到内存随着使用时间的推移似乎被占得满了。这并不意味着 Linux 正在“使用”内存；而是意味着 Linux 正在利用所有可用内存进行尽可能的缓冲。

这种缓冲允许向存储设备写入数据变得非常快，因为写入物理设备的操作被推迟到了以后。在此期间，目标设备的数据在内存中堆积。有时，操作系统会将这些数据写入物理设备。

卸载（Unmounting）设备意味着将所有剩余数据写入设备，以便安全地移除。如果在此未先卸载的情况下移除设备，可能会导致所有数据未完成传输。在某些情况下，这些数据可能包含目录更新，会导致文件系统损坏，这是计算机上发生的最糟糕的事情之一。

## 确定设备名称

有时确定设备名称很容易。在过去，设备总是位于相同的位置并没有变化。当像 Unix 这样的系统开发时，“更改磁盘驱动器”涉及到从计算机上拔掉设备。近年来，典型的桌面硬件配置已变得动态化，Linux 也变得比它的祖先更灵活。

在前面的章节示例中，我们利用了现代桌面 Linux “自动”挂载设备的功能，然后确定名称。但如果我们是在管理服务器或其他不发生自动挂载的环境中，该如何处理呢？

首先，让我们看看设备名称。如果我们列出 `/dev` 的内容（所有设备所在地），我们可以看到有很多设备。

```
me@linuxbox ~$ ls /dev
```

此列表的内容显示了一些命名模式。

表 15-2 概述了这些模式。
