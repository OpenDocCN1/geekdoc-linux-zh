我们可以看到，轨道越大，稳定子越小。事实上，在每种情况下 `#(Orb(x)) × #(Stab(x)) = 8`，而 8 是群 `S(\square)` 中元素的个数。这不是巧合，而是一个在群作用的所有情况下都成立的重要结果。

### 定理 12.4

**轨道-稳定子定理**

如果群 `G` 作用于集合 `X`，则对于每个 `x ∈ X`，

$$\#(Orb(x)) \times \#(Stab(x)) = \#(G). \qquad (12.1)$$

**证明**

由引理 12.3 可知，`Stab(x)` 是 `G` 的子群。因此方程 12.1 类似于我们在拉格朗日定理（定理 11.6）证明中出现的方程，即：

$$k \times \#(H) = \#(G), \qquad (12.2)$$

其中 `k` 是 `H` 的不同左陪集的数量。

比较方程 12.1 和 12.2，我们看到要证明方程 12.1，只需证明

$$\#(Orb(x)) = \text{$Stab(x)$ 的不同陪集数量}。$$

因此，我们需要证明 `Orb(x)` 的元素与 `Stab(x)` 的陪集之间存在一一对应。现在，`Orb(x) = {g \triangleright x : g ∈ G}`，且 `Stab(x)` 的陪集集合为 `{gStab(x) : g ∈ G}`。我们现在如下建立这些集合之间所需的一一对应：

对于 `g1, g2 ∈ G`，我们有：

$$g1 \triangleright x = g2 \triangleright x \Leftrightarrow g2^{-1}g1 \triangleright x = x,$$

根据练习 12.2.3A 的结果，

$$\Leftrightarrow g2^{-1}g1 ∈ Stab(x),$$

根据 `Stab(x)` 的定义，

$$\Leftrightarrow g1Stab(x) = g2Stab(x),$$

根据引理 11.4。

这建立了所需的对应关系，从而完成了定理 12.4 的证明。我们可以立即得出以下推论。

### 推论 12.5

设 `G` 为作用于集合 `X` 的有限群。则每个轨道中的元素个数是 `G` 的阶的因数。

特别地，在群对自身进行共轭作用的群作用情况下，每个轨道中的元素个数（在此语境下也称为*共轭类*）是群中元素个数的因数。这在分析群的结构时是一个非常有用的结果。

现在我们看到，可以很容易地从轨道-稳定子定理推导出以下结果，它给出了轨道数量的公式。

### 定理 12.6

轨道计数定理

设 `G` 为作用于集合 `X` 的有限群。则不同轨道的数量为

$$\frac{1}{\#(G)} \sum_{x ∈ X} \#(\text{Stab}(x)).$$

### 证明

假设有 `k` 个不同的轨道，`Orb(y1)`，`Orb(y2)`，...，`Orb(yk)`。对于 `1 ≤ r ≤ k` 且对于每个 `x ∈ Orb(yr)`，`Orb(x) = Orb(yr)`。因此，根据轨道-稳定子定理，

$$\#(\text{Stab}(x)) = \frac{\#(G)}{\#(\text{Orb}(x))} = \frac{\#(G)}{\#(\text{Orb}(yr))}.$$

因此

$$\sum_{x ∈ Orb(yr)} \#(\text{Stab}(x)) = \sum_{x ∈ Orb(yr)} \frac{\#(G)}{\#(\text{Orb}(yr))} \qquad (12.3)$$

在方程 12.3 中，等号右边的和式中每一项具有相同的值，且该和式中项数为 `#(Orb(yr))`。因此，由方程 12.3 我们得出

$$\sum_{x ∈ Orb(yr)} \#(\text{Stab}(x)) = \#(\text{Orb}(yr)) \times \frac{\#(G)}{\#(\text{Orb}(yr))} = \#(G).$$

因此，由于 `X = ⋃_{r=1}^{k} Orb(yr)`，且对于 `1 ≤ r ≤ s ≤ k`，集合 `Orb(yr)` 和 `Orb(ys)` 互不相交，

$$\sum_{x ∈ X} \#(\text{Stab}(x)) = \sum_{r=1}^{k} \left( \sum_{x ∈ Orb(yr)} \#(\text{Stab}(x)) \right) = \sum_{r=1}^{k} \#(G) = k \#(G).$$

由此可得

$$k = \frac{1}{\#(G)} \sum_{x ∈ X} \#(\text{Stab}(x)).$$

- 12.4.1A 我们说群 `(G, •)` 中的两个元素 `x`、`y` **交换**，如果 `x • y = y • x`；如果一个群的所有元素对都交换，则称该群为**交换**群。

  群的**中心**，记作 `Z(G)`，定义为群中所有与群中每个元素都交换的元素组成的集合。也就是说，`Z(G) = {g ∈ G : 对所有 x ∈ G,  gx = xg}`。显然，对于任何群 `G`，都有 `e_G ∈ Z(G)`。正三角形对称群（如表 11.3 所示）的例子表明，可能存在 `Z(G) = {e}`。本练习的目的是证明：如果 `(#)(G)` 是一个质数 `p` 的幂，那么 `Z(G)` 中至少有 `p` 个元素。

  a. 证明 `Z(G)` 是 `G` 的一个子群。

  b. 证明 `g ∈ Z(G) ⇔` `g` 的共轭类是 `{g}`，即 `g` 与自身共轭。
