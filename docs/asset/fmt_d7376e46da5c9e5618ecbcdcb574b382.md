# 3.3.6 确保忽略虚假的 ICMP 响应（自动化）

配置适用性：

- 等级 1 - 服务器
- 等级 1 - 工作站

描述：

设置 `icmp_ignore_bogus_error_responses = 1` 可以防止内核记录来自广播重帧的虚假响应（不符合 `RFC-1122` 的响应），防止文件系统被无用的日志消息填满。

原理：

某些路由器（以及某些攻击者）会发送违反 `RFC-1122` 的响应，并试图用许多无用的错误消息来满日志文件系统。

# 审计

运行以下脚本以验证 `icmp_ignore_bogus_error_responses = 1`：

```bash

{

  l1_searchpath=$(/run/sysctl.d/*.conf /etc/sysctl.d/*.conf /usr/local/sysctl.d/*.conf /usr/lib/sysctl.d/*.conf /lib/sysctl.d/*.conf /etc/sysctl.conf $(grep -f /etc/sysctl.ufw) | awk -F /\s*IPT_SYSCTL=/ (print $2)' /etc/sysctl.ufw))
  KPC() {
    l_krp=$(sysctl "$l1_kpname" | awk -F '$(print $2)' | xargs)
    l1_outfile=$(grep -Psl "^\\h$l1_kpname\\h=$l1_kpvalue\\b\\.*)?$" "^\\h$l1_kpname\\h*" | grep -Pv "^\\h$l1_kpvalue\\h")
    if [ "$l1_kpname" ]; then
      output=$output n - \$l1_kpname" is set to \$l1_kpvalue" in
      running configuration"
    else
      l_output2=$1_output - \$l1_kpname" is set to \$l1_kpvalue" in the

    fi
    if [ -n "$l1_outfile" && $1_output2="\$l1_kpname" is set
```

```bash
#!/usr/bin/env bash
{
  l_output="" output2=""
  l_parselist=net.ipv4.icmp_ignore_bogus_error_responses=1
  l_searchloc="/run/sysctld/*.conf /etc/sysctld/*.conf
  /usr/local/lib/sysctld/*.conf /usr/lib/sysctld/*.conf /lib/sysctld/*.conf
  /etc/sysctl.conf $(cat -f /etc/default/ufw | awk -F '/^\s*IPT_SYSCTL=/ {print $2}' /etc/default/ufw)
  l1_kpfile="/etc/sysctld/60-net.ipv4_icmp_ignore_bogus_error_responses.conf"
  KPI() {
    # comment out parameter(s) in kernel file
    l1_file=$(grep -s "\\$1 kpname" l_searchloc | grep -v "\\h=\h$1value" | awk -F '{print $1}')
    for l1_bkpf in $l1_file; do
      echo "Commenting out \$1 kpname\n in \$1_bkpf"
      sed -i "s/\\$1 kpname/*/" "\$1_bkpf"
    done
    # Set parameter in a kernel file
    if grep -psq "\\$1 kpname=\h$1value\b\h*(.*)?$" \$searchloc; then
      echo -e "\n Setting \$1 kpname\n to \$1value\n in \$1_outfile"
      echo "$1 kpname = $1value" >> "\$1_outfile"
    fi
    # Set parameter in a kernel
    l1_krp=$(sysctl \$1 | awk -F '{print $2}')
    if [ "\l1_krp" != "\$1value" ]; then
      echo -e "\n Updating \$1 kpname\n to \$1value\n in the active
      kernel\n"
      sysctl -w \$1
    fi
    for l1_kpe in $l1_list; do
      l1_kpname=$(awk -F '{print $1}')
      l1_kpvalue=$(awk -F '{print $2}')
    done
}
```

## 3.3.9 确保不接受 IPv6 路由器公告（自动化）

配置适用性：

- 等级 1 - 服务器
- 等级 1 - 工作站

描述：

此设置禁系统接受 `IPv6` 路由器公告的能力。

原理：

建议系统不要接受路由器公告，因为系统可能会被欺骗将流量路由到受攻击的机器。在系统内部设置静态路由（通常是到信任路由器的单一默认路由）可以保护系统免受恶意路由的影响。

设置：

- `net.ipv6.conf.all.accept_ra = 0`
- `net.ipv6.conf.default.accept_ra = 0`

禁用了系统接受 `IPv6` 路由器公告的能力。
