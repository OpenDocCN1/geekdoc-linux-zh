
## 在 SELinux 和 AppArmor 之间选择

`SELinux` 和 `AppArmor` 之间的选择取决于你的 Linux 发行版和安全需求。某些发行版默认带有 `SELinux`，而另一些则使用 `AppArmor`。在决定使用哪种 MAC 系统时，请考虑熟悉程度、社区支持和特定策略需求等因素。

总之，`SELinux` 和 `AppArmor` 是通过执行强制访问控制来增强 Linux 安全性的重要工具。理解它们的差异和功能允许你根据特定的安全需求，对实施何种 MAC 系统做出明智决策。

## 7.5. 安全启动与内核加固

加固启动过程和 Linux 内核对于保护系统免受各种威胁和攻击至关重要。在本节中，我们将探索安全启动（`Secure Boot`）——一种确保启动过程完整性的技术，以及增强 Linux 内核特性的加固技术。

## 安全启动

安全启动是现代计算机上的 `UEFI`（统一可扩展固件接口）固件提供的一种功能。它有助于防止在系统启动期间加载未经授权或恶意的启动加载程序和操作系统。安全启动通过在允许启动加载程序和内核组件运行之前验证其数字签名来实现。

以下是安全启动的关键组件：

- `UEFI` 固件：安全启动依赖 `UEFI` 固件来存储和管理数字密钥和证书。
- 平台密钥 (`PK`)：安全启动中最高级别的信任，`PK` 是用于签名 `KEK` 数据库的加密密钥。
- 密钥交换密钥 (`KEK`)：`KEK` 用于签名签名数据库 (`db`) 和禁止签名数据库 (`dbx`)。
- 签名数据库 (`db`)：该数据库包含受信任的密钥和证书，用于验证启动加载程序和内核。
- 禁止签名数据库 (`dbx`)：它包含已知恶意软件或未经授权组件的密钥或证书，这些组件不应被加载。
- `Shim` 启动加载程序：`Shim` 是一个用微软密钥签名的预加载器，允许它在启用安全启动的 `UEFI` 系统上运行。`Shim` 随后验证并加载 `GRUB2` 启动加载程序，然后由其加载 Linux 内核。

启用安全启动可确保只有签名的启动加载程序和内核允许运行，保护系统免受启动期间的启动加载攻击和 `rootkit` 攻击。

## 内核加固

内核加固涉及实施各种安全措施，使 Linux 内核对攻击和漏洞更具韧性。一些关键的内核加固技术包括：

- 地址空间布局随机化 (`ASLR`)：`ASLR` 随机化内核使用的内存地址，使攻击者更难预测内核函数和数据结构的位置。
- 内核页表隔离 (`KPTI`)：`KPTI`（称为 `Meltdown` 缓解）将内核和用户空间页表分离，防止用户空间应用程序访问内核内存。
- 控制流完整性 (`CFI`)：`CFI` 限制内核的控制流，以防止执行未经授权的代码。
- `Seccomp` (安全计算模式)：`Seccomp` 允许限制从用户空间程序发起的系统调用，减少攻击面。
- 内核模块签名：强制对内核模块进行签名，确保只有受信任且签名的模块才能加载到内核。
- 使用内核安全模块：`AppArmor`、`SELinux` 和 `Smack` 等内核安全模块可以通过执行强制访问控制和限制策略来增强内核安全性。
- 定期更新内核：保持内核使用安全补丁和更新到最新对于维护安全性至关重要。

内核加固措施可以显著降低内核级漏洞的风险。总之，安全启动和内核加固是 Linux 安全性的基本组成部分。安全启动保护启动过程，确保加载签名的组件，而内核加固技术则加强了内核本身的安全性。实施这些措施可以帮助缓解各种威胁并增强系统的整体安全性。

# 第 8 章：脚本与自动化

## 8.1. Bash 脚本简介

`Bash`（`Bourne-Again Shell`）脚本是一项强大且重要的技能。它允许你自动化任务、创建脚本并在 Linux 环境中执行操作。在本节中，我们将向你介绍 `Bash` 脚本的基础知识，从基础开始。

### 什么是 Bash？

`Bash` 是一种命令行 shell 和脚本语言，提供了与 Linux 系统交互的接口。它是大多数 Linux 发行版的默认 shell，由于其灵活性和扩展性而被广泛使用。

### 为什么使用 Bash 脚本？

`Bash` 脚本具有许多优势：

- **自动化**：你可以自动化重复任务，使系统管理更高效。
- **自定义**：`Bash` 脚本允许你根据需求创建自定义解决方案。
- **移植性**：`Bash` 脚本在 Linux 系统间具有移植性，确保你的自动化在不同发行版上都能运行。
- **集成**：你可以将 `Bash` 脚本与其他工具和实用程序集成。
- **故障排除**：`Bash` 脚本有助于对过程进行故障排除和调试。

## 开始学习 Bash 脚本

要开始编写 `Bash` 脚本，你需要像 `Vim`、`Nano` 或 `VSCode` 这样的文本编辑器。这是一个简单的 `Bash` 脚本示例，显示“Hello, World!”消息：

```bash
#!/bin/bash

# 这是一个 Bash 脚本

echo "Hello, World!"
```

让我们拆解这个脚本：

- `#!/bin/bash`：这一行被称为 shebang (`#!`)，指定要使用的解释器（在本例为 `Bash`）。
- `# 这是一个 Bash 脚本`：`Bash` 中的注释以 `#` 符号开头，用于文档说明。
- `echo "Hello, World!"`：此命令在终端打印“Hello, World!”。

## 运行 Bash 脚本

1. 使用 `chmod` 命令使你的脚本具有可执行权限：

```bash
chmod +x script.sh
```

2. 运行脚本：

```bash
./script.sh
```

## Bash 中的变量

你可以使用变量在 `Bash` 脚本中存储和处理数据。这里是一个示例：

```bash
#!/bin/bash

name="John"

echo "Hello, $name!"
```

在这个脚本中，我们定义了一个变量名并在 `echo` 命令中使用它。

## 用户输入

你可以使用 `read` 命令在 `Bash` 脚本中获取用户输入：

```bash
#!/bin/bash

echo "What’s your name?"

read name

echo "Hello, $name!"
```

此脚本会提示用户输入名称，然后显示问候语。

## 条件语句

`Bash` 支持 `if`、`elif` 和 `else` 等条件语句，用于脚本中的决策：

```bash
#!/bin/bash

read -p "Enter a number: " num

if [ $num -gt 10 ]; then
    echo "The number is greater than 10."
else
    echo "The number is not greater than 10."
fi
```

此脚本检查数字是否大于 10 并提供相应的输出。

## 循环

你可以使用 `for` 和 `while` 循环来处理重复任务：

```bash
#!/bin/bash

for i in {1..5}; do
    echo "Count: $i"
done
```

此脚本打印从 1 到 5 的数字。

## 函数

函数允许你对代码模块化：

```bash
#!/bin/bash

function greet() {
    echo "Hello, $1!"
}

greet "Alice"
greet "Bob"
```

在这个脚本中，我们定义了一个 `greet` 函数，它接受一个参数并显示问候语。

### 结论

`Bash` 脚本是一种多功能工具，能够让你实现任务自动化并自定义 Linux 体验。在本节中，我们涵盖了 `Bash` 脚本的基础知识，包括脚本结构、变量、用户输入、条件语句、循环和函数。有了这些基础知识，你可以开始创建自己的 `Bash` 脚本来简化你的 Linux 工作流。

## 8.2. 使用 Shell 脚本自动化任务

`Shell` 脚本是 Linux 环境中自动化任务的有效工具。在本节中，我们将深入探索 `Shell` 脚本的世界，并探索如何创建可以自动化系统上各种过程的脚本。

### 理解脚本执行

当你运行 `Shell` 脚本时，`Shell` 解释器（例如 `Bash`）会按顺序从脚本文件中读取并执行命令。要执行 `Shell` 脚本，你需要使用 `chmod` 命令赋予其执行权限，然后运行它。

例如，如果你有一个名为 `myscript.sh` 的 `Shell` 脚本，你可以通过以下命令赋予其执行权限：

```bash
chmod +x myscript.sh
```

然后执行它：

```bash
./myscript.sh
```

### 向脚本传递参数

你可以向 `Shell` 脚本传递参数，使其更加灵活和通用。特殊变量 `$1`、`$2` 等代表传递给脚本的参数。

这是一个接受两个参数并打印它们的脚本示例：

```bash
#!/bin/bash

echo "First argument: $1"
echo "Second argument: $2"
```
