### `ncpfs`
使用 Netserver 资源的工具。此包包含从 Netserver 挂载卷的实用。还包括一些小工具如 `nprint`，它在 PrintNet 队列上打印并提供 Net Print 队列。`ccfs–2.0.12` 及以上替换了 `netcpfs`。此包兼容 2.0.x、2.1.x、2.2.x、2.3.x 和 2.4 内核。此外，`ncpfs–2.0.12` 及以上支持 Netware 目录。

来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ncps`
控制台进程杀器 `ncpcs` 是一个受 `gGPS` 启发的控制台进程破坏器和杀死器。它可以根据各种标准对进程进行排序，并以树状视图显示。它比 GNU 交互工具中的 `gitps` 更强大。来自 Debian 3.0r0 APT
