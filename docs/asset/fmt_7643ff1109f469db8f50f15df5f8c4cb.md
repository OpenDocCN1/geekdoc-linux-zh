
默认情况下使用系统通知。使用此模块可以确定在发生问题、执行任务或发生需要立即注意的事件时，系统应如何通知您。

在对话框的上部，选择要为其配置系统通知的应用程序。一旦您选择了一个程序，该程序可以发送给用户的所有事件都会列在下方的窗口中。在“操作”对话框中确定每种通知的通知类型。

系统通知对话框的标准视图仅提供“播放声音”复选框的激活，用于听觉通知。点击“更多选项”可以访问其他操作模式。您可以将通知记录到文件中、执行程序或在弹出窗口中显示消息。在对话框下部的“快速控制”下，可以全局地激活或禁用所有程序的操作。

### 5.2.4 外观与主题

此项目包含您桌面外观的所有精细调整选项。

### 屏幕保护

用于选择和配置屏幕保护程序的模块由三部分组成。从左侧列表中选择合适的屏幕保护程序。右侧的预览显示所选程序的样式。使用“设置”和“测试”在运行的系统中测试屏幕保护程序并进行配置。

自动启动屏幕保护：为了让屏幕保护程序自动激活，请设置屏幕保护程序后应激活的时间（分钟）。

### 停止屏幕保护需要密码

屏幕保护程序可以锁定您的工作站并在释放时需要密码。

### 优先级

使用滑块设置屏幕保护程序相对于其他进程的优先级。如果您使用产生高处理器负载的复杂图形屏幕保护程序，请提高优先级以获得流畅的显示质量。在这种情况下，其他进程的优先级将相应降低。然而，如果您经常在做其他事情时让机器运行，则应避免运行高优先级的复杂屏幕保护程序。

### 颜色

使用此模块管理和编辑桌面的颜色方案。从许多现有方案中选择一个。预览窗口以定义的颜色显示所有桌面元素。要更改一个或多个组件的颜色，请从“组件颜色”下的下拉菜单中选择组件名称，并点击颜色条在颜色编辑器中选择合适的颜色。最后，调整对比度设置并以您喜欢的名称保存修改后的方案。若要全局应用此方案，请激活“将颜色应用于非 KDE 应用程序”。

### 窗口装饰

从“常规”选项卡下的列表中为您的应用程序窗口选择装饰样式。点击“应用”测试所选样式。若要定位或移动标题栏的单个元素，请激活“使用自定义标题按钮位置”并在“按钮”选项卡下重新排列元素。如果所选样式有额外的配置选项，可以在“配置”选项卡下访问这些选项。

### 背景

为您的桌面确定背景。默认情况下，您的修改将应用于所有虚拟桌面。若要为各个虚拟桌面单独配置背景，请取消勾选“共同背景”。配置的效果可以在对话框右上角的预览中看到。

可以在“背景”选项卡下选择背景颜色。若要修改颜色分量，点击“颜色 1”或“颜色 2”旁颜色条打开颜色编辑器。在此处，根据需要更改颜色设置，或使用吸管工具从任何桌面元素、加载的图像或网页中采用颜色。在“模式”下选择特殊渐变。

若要使用图像作为一个或多个背景的背景，请激活“单壁纸”。然后选择缩放模式或壁纸在桌面上的位置，并使用下拉菜单或“浏览...”按钮指定合适的壁纸。或者，也可以从文件管理器（见第 150 页第 5.3 节）或桌面将图像文件拖放到预览图像上。为了壁纸的多样性，请激活“多个壁纸”并使用“设置多个...”继续后续配置。

“高级”选项卡包含一些通常不需要修改的特殊设置。

### 字体

在此可以配置桌面上使用的所有字体和字体属性。点击“选择...”，然后在打开的对话框中指定您的设置。默认情况下，所有字体都启用了抗锯齿。若要禁用或自定义抗锯齿，请选择相应的复选框。

> 注意
>
> 抗锯齿的更改仅适用于新启动的程序。已打开的程序不受影响。

### 样式

在此处，为所有组件（图形界面元素）选择样式。窗口下半部分显示所有当前设置的预览。使用“效果”配置各种透明类型（如果该样式支持）。

## 5.2.5 区域与辅助功能

### 国家/区域与语言

此模块中的设置仅适用于 KDE 应用程序，如 `OpenOffice.org` 等可能单独配置。使用下拉菜单从列表中选择所需的国家，例如美国，但点击“添加语言”选择该语言并将其添加到列表。若要删除语言，请在列表中标记它并点击“删除语言”。

数字 使用比“区域”下所选国家默认不同的数字设置

时间与日期 在此处输入时间格式、日期格式、短日期格式以及每周的第一天。如果您点击标题栏中的“?”符号，然后相应的菜单项，将显示详细说明。

其他选项卡具有默认纸张格式和单位的设置。在美国系统上，默认纸张格式为“美国信”，使用的是制制。

### 键盘快捷键

此模块由多个选项卡组成。使用“快捷方案”选项卡选择现有布局或创建新的布局方案。“修饰键”选项卡提供了键盘上可用特殊键的概述。

您的系统提供了针对特定任务的预定义快捷键并按方案组织。使用“快捷方案”选项卡管理系统上的所有快捷键。默认提供以下方案：

- Windows 方案（带 Win 键）
- Mac 方案
- KDE 默认三修饰键
- KDE 默认四修饰键
- Windows 方案（不带 Win 键）
- Unix 方案

若要更改系统使用的方案，请从列表中选择一个方案并将其全局应用（“全局快捷键”、“快捷序列”和“应用程序快捷键”），或为单独的操作分配快捷键并将其保存为自定义方案。

若要为操作创建快捷快捷或修改现有快捷键，请选择相应区域的选项卡（例如“全局快捷键”）并点击操作（例如“显示任务管理器”）。对话框下部的“所选操作快捷键”部分将被激活。

现有方案受写保护，允许随时恢复默认值。通过点击右上角的“保存...”并为您的自定义方案命名来保存您的所有修改。新方案将列在选择菜单中。

## 注意

在“应用快捷键”下，你只能配置所有应用程序通用的标准快捷键。特定程序的快捷键必须在程序内部通过“设置”->“配置快捷键”进行配置。

# 辅助功能

此模块中的设置帮助听力障碍或运动障碍用户访问系统。该模块包含“蜂铃”和“键盘”选项卡。

听觉蜂铃：系统蜂铃可以通过可见或可听的形式通知用户。默认设置为“使用系统蜂铃”的听觉变体。要配置特定声音，激活“使用自定义蜂铃”并使用“浏览...”从列表中选择声音。

视觉蜂铃：若要以视觉方式传递蜂铃，请激活“使用视觉蜂铃”。如果不进行其他修改，当系统蜂铃响时，默认会激活“反转屏幕”。视觉蜂铃的持续时间可以通过滑块进行调整。除了反转外，还可以设置屏幕闪烁。通过激活“闪烁屏幕”并点击颜色条在颜色编辑器中选择合适的颜色来实现。

粘滞键：某些快捷键需要在输入快捷键的第二部分时按住某个键（如 `Alt`、`Ctrl` 和 `Shift`）。如果使用粘滞键，即使这些键只被按了一次，系统也会认为它们持续按下。

慢键：在这里，可以确定当按键时系统延迟在屏幕上输出字符的时间和程度。通过滑块调整的时间间隔越长，按键越长就不会触发相应字符的重复输出。

跳跳键：如果你激活了此选项，如果滑块选择的间隔已过去，连续按两次键将被解释为两个字符。如果不小心按了两次，则会被忽略。

# 5.3 作为文件器的 Konqueror

`Konqueror` 是一个统一的 浏览器、文件管理器、文档查看器和图像查看器。以下章节涵盖了使用 `Konqueror` 进行文件管理。点击面板中的房屋图标启动 `Konqueror`，随后将显示你的主目录内容。

文件管理器窗口由顶部的菜单栏、工具栏和位置栏组成。窗口下部垂直分为导航面板和主窗口，主窗口显示内容。

## 5.3.1 Konqueror 菜单

位置：使用“位置”菜单打开额外的 `Konqueror` 窗口。如果你点击“新窗口”，你的主目录将在新窗口中显示。“重复窗口”会生成一个内容相同的第二个窗口。你还可以通过电子邮件发送文件或链接（使用浏览器功能）。如果你点击这些菜单项之一，将打开 `KMail` 编写器。指定收件人并编写文本。根据所选项目，文件将作为附件附加或链接将显示在电子邮件正文中。你也可以从此菜单直接打印。

**编辑**：“编辑”下的大多数项目只有在你在主窗口中选择对象时才会变为激活。提供标准的编辑功能。“粉碎”功能会永久删除数据。可以创建新的目录和文件，或更改文件属性（如文件权限）。为用户、组或所有用户授予或拒绝读取、写入和执行权限。在主窗口中，可以通过将鼠标指针移动到文件上并按住左鼠标键，或使用“编辑”菜单中的选择功能来选择一个或多个文件。

**视图**：使用“视图”菜单更改视图。如果目录非常满，文本视图或树状视图可能更高效。如果你查看 HTML 页面，请激活“使用索引”。使用“锁定到当前位置”停止动画图像，使用“解锁视图”恢复动画。“图标大小”、“排序”、“预览”、“显示隐藏文件”和“文件夹图标反映内容”控制主窗口中显示的图标。还使用此菜单为背景选择颜色或图像。

**前往**：“前往”菜单包含导航功能。然而，你可以在工具栏中更快速地访问这些功能。此菜单下有一个有趣的功能：最近查看的目录列表，可以对其进行选择和显示。

**书签**：书签可以是 Internet 地址 (`URL`)，也可以指向主机上特定文件或目录的路径。如果你选择“添加书签”，位置栏当前的内容将保存为书签。要访问该位置，只需点击此书签。出于实用性考虑，请将书签安排在文件夹中。SUSE 文件夹已存在。“编辑书签”会打开书签编辑器，以执行删除书签、重命名书签和将书签从一个移动到另一个等任务。
