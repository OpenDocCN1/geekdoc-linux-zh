# gemdprox

# genesis

通用模拟器 GENESIS 是一个通用复杂平台，旨在支持神经系统的仿真，从单个神经元的复杂模型到通过抽象概念的大网络仿真。GENESIS 为加州理工学院（Caltech）和马萨诸塞州伍兹霍尔生物实验室的神经仿真实验室课程提供了基础。目前大多数 GENESIS 应用都实现了生物系统的真实仿真。虽然该软件也可以模拟更抽象的网络，但其他模拟器更适合反向传播和连接主义建模。来自 Debian 3.0r0 APT

# geneweb

带有 Genew 接口的家谱软件允许你跟踪祖先数据。它是一个维护家族历史数据集的强大系统。它支持 Linux 字典-GEDCOM 系统的数据存储，既可以作为存档家谱数据的主要系统，也可以作为网络服务（通过 CGI 接口）发布你的数据供他人使用。Genew 正在活跃使用和开发，因此其功能不断改进。它具有大多数现有产品不具备的功能，如变体计算、关系计算以及其他统计分析工具。来自 Debian 3.0r0 APT
