
### 4.2 文件特性

UNIX 文件描述中的第一个字符表示文件类型。

该字符描述的文件类型包括：

| 字符 | 描述 |
| :--- | :--- |
| d | 目录文件 |
| b | 块类型特殊文件 |
| c | 字符类型特殊文件 |
| l | 符号链接 |
| s | 套接字 |
| - | 普通文件 |

普通文件包含任何 ASCII 或二进制信息。目录文件是当前目录子目录的指针。用户通常只通过删除目录文件来操作它们，从而移除子目录。接下来的九个字符 `(rwxr--r--)` 定义了文件的*权限*。每个文件都有三个级别的权限：所有者、组和其他和其他用户，分别由第一、第二和第三组三个字符组定义。与 Open-VMS 不同，UNIX 没有第四个权限级别来定义对本地系统管理员的访问权限，管理员始终对 UNIX 文件具有完全访问权限。每级权限允许三种类型的访问：读取 `r`、写入 `w` 和执行 `x`。与 OpenVMS 不同，UNIX 不区分写入和删除。因此，一个你可以写入的 UNIX 文件也可以被删除。然而，你应该注意，与 OpenVMS 一样，UNIX 要求对包含文件的目录具有写入权限，并且文件本身具有适当的权限。

我们示例中的第二个条目 `1` 表示该文件拥有的链接数。*链接*是文件与目录之间或目录与目录之间的连接。文件至少对其所在的目录文件有一个链接。例如，文件规范 `/tmp/test1` 表示文件 `test1` 与目录文件 `/tmp` 有一个链接。同样，一个目录文件至少有两个链接：一个指向该目录中的所有文件，另一个指向其父目录文件。

我们示例中的接下来两个条目 `danny` 和 `staff` 表示文件的所有者以及文件所属的组。你可以以类似于 OpenVMS ACL 中访问控制项 `ACE` 的方式使用组。用户可能属于多个组，例如根据部门或工作功能。你可以分配文件的组权限，以只允许适当组的成员进行访问。

如果一个用户属于多个组，而文件只能属于一个组，那么该用户创建的文件属于哪个组？答案可以在 `/etc/passwd` 和 `/etc/group` 文件找到。`/etc/group` 文件包含与每个组名关联数字组标识符。`/etc/passwd` 文件为每个用户包含一个组标识符和一个唯一的用户标识符，无论该用户属于多少组。因此，UNIX 在创建文件时会将与用户唯一组标识符关联的组名分配给文件。文件所有者可以使用 `chgrp` 或 `chown` 命令轻松更改文件的组所有权。

下面的示例显示了 `/etc/passwd` 文件中用户 `danny` 的一条记录；记录内部的字段由冒号分隔。

UNIX 示例：
```
% more /etc/passwd
julia:x:9GeD4S9Hktztl:102:49:Julia Rose,523BB:/home/julia:/bin/csh
%more /etc/group
staff:*:49:julia,danny,fred,george
```

### 4.3 确定当前目录

`pwd` 命令用于确定当前目录。C shell 还提供了 `dirs` 命令，它可以显示一个名为“栈”的目录层次列表，其中当前工作目录位于顶部。

### 4.4 切换目录：`cd`

`cd` 命令用于更改当前工作目录。

OpenVMS
格式：
```
$ SET DEFAULT device-name[directory]
```
示例：
```
$ SET DEFAULT DUA2:[USER]
```

UNIX
示例：
```
% cd directory2/
% cd /user
% cd . ./user
% cd
% cd -nathan
```

C shell 通过 shell 变量 `cdpath` 扩展了 `cd` 的用法。

### 4.5 创建目录：`mkdir`

UNIX 命令 `mkdir` 用于创建目录。

OpenVMS
格式：
```
$ CREATE/DIRECTORY [/ *QUALIFIER *{S]} - *directory-spec[*.... *]*
```

UNIX
```
% mkdir *directory
% mkdir test
% mkdir /user/tmp/test
```

在第一个示例中，`mkdir test` 演示了在当前工作目录下创建一个子目录 `test`。在第二个示例中，`mkdir /user/tmp/test` 使用绝对路径创建一个子目录 `test`。

`mkdir -p` 命令将创建任何所需的中间目录。

### 4.6 删除目录：`rmdir` 和 `rm -r`

UNIX 提供了两个命令来删除目录：`rmdir` 和 `rm -r`。`rmdir` 只有在目录不包含任何文件时才会删除目录。`rm -r` 会删除目录中的所有内容。

OpenVMS
格式：
```
$ DELETE [/ *QUALIFIER {S}] *directory*
```

UNIX
```
% rmdir *directory
% rmdir /usr/user/tmp
% rm -r [*option {s}] directory *
% rm -r /usr/user/tmp
```

### 4.7 查找文件：`find`

`find` 命令提供了在目录树中定位文件的功能。

```
% find *pathname_list criterion *action *
% find / -name ourfile -print
/userl/bin/ourfile
/user3/progs/ourfile
```

### 4.8 显示文件：`cat` 和 `more`

用于显示文件最常用的 UNIX 命令是 `cat` 和 `more`。`od` 以各种格式转储文件。`head` 命令显示文件的开头。`tail` 命令显示文件的结尾。

### 4.9 分页查看文件：`less`

`less` 命令用于显示文件内容。`less` 比 `more` 更健壮。

#### UNIX
格式：
```
% less [options] *file*
```

示例：
```
% less -V myfile.dat
```

### 4.10 复制文件：`cp`

UNIX 命令 `cp` 将一个文件复制到另一个文件。

#### OpenVMS
格式：
```
$ COPY [ /QUALIFIER (S) ] *input-file-output-file*
```

#### UNIX
```
% cp [options] input_file output_file
```

示例：
```
% alias cp 'cp -i' # C shell
$ alias cp:'cp -i' # Korn shell
```

### 4.11 重命名文件：`mv`

UNIX 命令 `mv` 的功能与 OpenVMS 的 `RENAME` 命令相同。

#### OpenVMS
格式：
```
$ RENAME [ /QUALIFIER (S) ] *input-file-output-file*
```

#### UNIX
```
% mv [options] input_file output_file
```

示例：
```
% mv file1 file2
% mv -i file1 file2
% mv -f file1 file2
```

### 4.12 删除文件：`rm`

第 4.6 节讨论了使用 `rm -r` 移除目录及其内容。你也可以使用 `rm` 删除文件。

#### OpenVMS
格式：
```
$ DELETE [ /QUALIFIER (S) ] *file-spec [ .... ] *
```

#### UNIX
```
% rm [options] file*
% rm file1
% rm -i file1 file2
% rm /usr/file1
```

### 4.13 总结

UNIX
`cp` 复制文件
`mv` 移动或重命名
`rm` 删除文件
`ls` 列出目录
`chmod` 更改权限
`find` 搜索文件
`alias` 设置别名
`pwd` 显示当前目录

OpenVMS
`COPY` 复制文件
`RENAME` 重命名文件
`DELETE` 删除文件
`DIRECTORY` 列出目录
`SETLEVEL` 更改权限
`SEARCH` 搜索文件
`alias` 设置别名
`pwd` 显示当前目录

### 5.1 行模式编辑：`ex`

`ex` 编辑器使用当前行作为默认行。`ex` 编辑器使用一个或两个字符来指定命令。`w` 命令将整个文件写回磁盘。点 `.` 表示当前行。美元符号 `$` 表示文件的最后一行。

#### ex 命令总结

| ex Command | EDT 等效命令 | ex 含义 |
| :--- | :--- | :--- |
| `a` | `CHANGE` | 在当前行之后追加行 |
| `c` | `DELETE` | 修改指定的行 |
| `d` | `ALL` | 删除指定的行 |
| `e` | `INSERT` | 设置编辑缓冲区包含指定的文件并覆盖原始内容 |
| `w` | | 将编辑缓冲区的内容写入文件 |

### 5.1.1 显示行

```
% ex myfile.dat
59 lines, 1971 characters
: 5 p
: 5,10
: 1,$
```

### 5.1.2 插入、追加和删除

```
: i
This is one new line
: a
This is one new line
```

### 5.1.3 搜索与替换

```
: /string/
: ?string?
: s/string1/string2/
```

### 5.1.4 剪切与粘贴

```
: -3,.m$
:10,20 co 30
```

### 5.1.5 外部文件处理

```
:1:10 w newfile
:r myfile.dat
:e myfile.dat
```

### 5.1.6 恢复编辑会话

```
% ex -r myfile
```

### 5.2 UNIX 屏幕编辑器：`vi`

命令 `vi file1 [...]` 启动 `vi` 会话。

#### 5.2.1 入门

当你打开一个文件进行编辑时，`vi` 从命令模式开始。

#### 5.2.2 光标移动

`CTRL-F` 向前滚动一屏幕
`CTRL-B` 向后滚动一屏幕
`w` 向前移动单词
`b` 向后移动单词
`$` 移动到行尾

#### 5.2.3 操作命令

`dd` 删除当前行。

#### 5.2.4 在 `vi` 中调用 `ex`

在命令模式下输入冒号时，屏幕底部会出现冒号提示符，用户可以输入 `ex` 命令。

### 5.3 UNIX 屏幕编辑器：`Emacs`

启动编辑会话的命令是 `emacs file`。

#### 5.3.1 入门

使用 `emacs -u herb` 加载用户初始化文件。

#### 5.3.2 Emacs 命令

`Emacs` 将 Escape 键识别为 META 键，文档将其表示为 `M-`。

#### 光标移动

| Emacs 命令 | 含义 |
| :--- | :--- |
| `<CTRL>-E` | 移动到行尾 |
| `<CTRL>-A` | 移动到行首 |
| `<CTRL>-V` | 向前滚动文件一屏 |

#### 5.3.3 标记文本

`<CTRL>-SPACE` 在光标位置设置标记。

#### 5.3.4 操作命令

`<CTRL>-Y` 命令用于将临时缓冲区的内容贴回当前光标位置。

#### 5.3.5 文件操作

```
<CTRL>-X <CTRL>-S 保存缓冲区
<CTRL>-X <CTRL>-F 查找并读取文件
```

#### 5.3.6 窗口操作

```
<CTRL>-x 2 垂直拆分窗口
<CTRL>-x o 移动到另一个窗口
```

#### 5.3.7 错误恢复与编辑会话恢复

使用 `<CTRL>-G` 可以取消任何正在进行的 Emacs 命令。

`recover-file` 命令用于恢复并继续编辑因计算机崩溃或网络中断而中断的文件。
