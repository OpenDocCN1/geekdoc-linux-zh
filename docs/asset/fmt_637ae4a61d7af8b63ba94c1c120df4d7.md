# 输出 TCP/UDP 报文
##################################################################

```
$IPT -N OUT
$IPT -A OUT -p tcp -j FLAGS
$IPT -A OUT -s ! $sIP -j LDORP
$IPT -A OUT -m state --state ESTABLISHED,RELATED -j ACCEPT
```

此防火墙配置为默认阻止出站连接。
要允许出站连接，请取消以下注释：

```
$IPT -A OUT -j ACCEPT
```
