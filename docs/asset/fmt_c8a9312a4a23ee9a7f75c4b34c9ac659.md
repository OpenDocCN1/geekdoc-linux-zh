FFD 修改器提供三种类型：`$2 \times 2 \times 2$`、`$3 \times 3 \times 3$` 和 `$4 \times 4 \times 4$`。每个类型在对象周围放置一个不同的框。例如，FFD `$2 \times 2 \times 2$` 修改器会放置一个在每个角都有控制点的框。

# FFD (Box)

FFD (Box) 修改器的功能与之前的 FFD 修改器相似，但增加了控制控制点数量的能力。使用 FFD (Box)，你不局限于 `$2 \times 2 \times 2$`、`$3 \times 3 \times 3$` 或 `$4 \times 4 \times 4$`。FFD (Box) 修改器在对象周围放置一个框，如图 B.6 所示。

# FFD (Cyl)

与 FFD (Box) 修改器类似，FFD (Cyl) 在对象周围放置圆柱形晶格。你可以控制控制点的数量。

# FILLET/CHAMFER

Fillet/Chamfer（圆角/倒角）允许将直线顶点转换为圆角或角。它适用于连接线段的顶点。要使用它，选择形状并应用 Fillet/Chamfer 修改器。顶点面板会自动打开，允许选择顶点。

# HSDS

HSDS 代表层级表面划分。HSDS 修改器对对象的表面进行划分，而不将其转换为网格。

# LATHE

Lathe（旋转）用于以圆形方式将 2D 形状旋转到第三维。VIZ 形状、NURBS 曲线和从 CAD 程序导入的形状都可以进行旋转。Lathe 修改器具有封端选项，这会关闭旋转形状开始和结束处的开口。

# Lattice

Lattice（晶格）修改器允许将形状的线段转换为支撑架，并将顶点转换为关节。这种效果类似于将网格转换为线框，但将线框表示为可渲染的几何体（见图 B.7）。测地圆是使用晶格球的一个良好建筑示例。

# LS MESH

此修改器精炼 Lightscape 网格（从 Lightscape 导入）。此修改器设计用于与 Lightscape 和 LS Colors 修改器配合使用。

# MapSCALAR

当你希望材质贴图相对于对象的比例保持不变时，应用此修改器的 OSM 版本。对象的比例也会影响关联贴图的比例。使用 WSM 版本将关联贴图的比例锁定到世界空间。

# MATERIAL (材质)

当你对对象应用 Multi / Sub-Object 材质时，需要在对象的选面上分配一个材质 ID，以便将子材质与选面相关联（参见第 8 章查看 Multi / Sub-Object 材质）。Material 修改器允许你执行此操作。

## 修改器 | 897

材质（Material）修改器不需要用于可编辑网格或可编辑多边形。它旨在用于其他不提供网格级编辑访问权限的对象。对于这些对象，你需要先应用网格选择（Mesh Select）修改器来选择网格面。然后你可以应用材质修改器来分配材质 ID。

# MATERIALByELEMENT

MaterialByElement 修改器将多/子对象（Multi/Sub-Object）材质的不同材质应用到对象的不同元素。这是随机进行的。

# MESHSMOTH

MeshSmooth（网格平滑）的作用正如其名：它平滑网格，使锐利的角变得圆润。它通过增加网格的复杂度来实现这一点。可以使用类似于 NURBS 控制点（CVs）的方式对平滑后的形状进行编辑（关于 NURBS 控制点的更多信息请参见附录 C）。MeshSmooth 与本附录后述的 TurboSmooth 修改器类似。

# MIRROR

Mirror（镜像）的功能与 VIZ 主菜单中的镜像工具类似。镜像工具在克隆（Clone）选项指示时会创建一个第二个对象，而镜像修改器则使用复制（Copy）选项创建第二组几何体，这两个几何体都是同一个对象的元素。由于它是一个修改器，你可以作为对象栈的一部分来控制镜像效果。

# MULTires

MultiRes 修改器与 Optimize（优化）修改器类似，增加了一个按百分比或顶点数量来指定简化程度的选项。更强大的 MultiRes 通常已经取代了 Optimize，用于网格简化操作。

# NOISE

Noise（噪声）修改器重新定位对象的顶点以模拟不平整的表面。你可以调整噪声的强度来创建一个相对平滑的表面或山地地形。Noise 的效果取决于对象的分段。

# NORMAL

当你在 VIZ 中创建几何体时，几何体的法线是向外的，你无法控制它们的方向。你可以通过折叠栈并将几何体还原为编辑网格来获得对 VIZ 体法线的控制。遗憾的是，一旦这样做，几何体就会失去参数化功能。Normal（法线）修改器允许你在不放弃参数函数的情况下控制几何体的法线。

# NORMALIZE SPLINE

Normalize Spline（样条规范化）修改器在样条上放置额外的控制点。控制点以等间隔分布。这在需要恒定速度的运动路径样条使用时非常有用。

# OPTIMIZE

Optimize（优化）修改器在保持可接受细节水平的同时简化对象的几何体。这提供了更快的渲染时间和更少的内存占用优点。此修改器已被 MultiRes 修改器有效取代。

# PATCHDEFORM

PatchDeform（补丁变形）允许你根据补丁（Patch）对象的形状变形对象。补丁对象是通过编辑其顶点形成平滑曲面的对象。例如，你可以创建一个平面，然后将平面转换为可编辑补丁。然后编辑可编辑补丁的顶点，将平面塑成你需要的任何形状的平滑曲面。此类表面可以使用 PatchDeform 修改器来变形其他对象。另见此修改器的 WSM 版本。

对象在变形时保持在当前位置。

# PATHDEFORM

PathDeform（路径变形）修改器的工作方式与 PatchDeform 修改器类似，但使用的是样条或 NURBS 曲线而不是补丁对象。例如，你可以用它沿样条路径变形对象。例如文字弯曲以适应圆柱或球体的形状。使用此修改器时，对象不会随路径移动。另见 WSM 版本。

# PRESERVE

Preserve（保留）修改器允许你“清理”在顶点子对象级上编辑过的网格。当通过移动顶点编辑网格时，生成的形状看起来很粗糙。Preserve 修改器将帮助平滑那种粗糙的外观。

要使用 Preserve 修改器，必须先对要修改的对象进行复制。对副本的顶点进行更改，然后在顶点子对象级保持激活状态时应用 Preserve 修改器。使用 Preserve 修改器的 Pick Original（选取原始对象）按钮选择你复制的原始对象。然后可以使用其他的 Preserve 控件来调整网格。

# PUSH

如果你需要创建膨胀或收缩的外观，可以使用 Push（推）。Push 修改器从对象的中心推或拉动对象的顶点。

# RELAX

Relax（放松）类似于 Push，但它不是从对象中心向外推顶点，而是软化对象的角边缘，或通常让对象的形状变得更平滑，表面变化不那么明显。

# RENDERABLE SPLINE

此修改器允许设置样条对象的渲染参数，包括通过 AutoCAD 导入或文件链接（见第 17 章）引入 VIZ 的参数。

# RIPPLE

Ripple（波纹）修改器修改对象以产生波状表面。你可以控制波纹的振幅、相位和衰减。

# SHELL

Shell（壳）修改器通过挤出表面来创建壳状体积。

# SKEW

Skew（倾斜）修改器会倾斜对象，如图 B.9 所示。你可以控制倾斜的方向和强度。

# SLICE

Slice（切片）允许你定义一个切割对象的平面。Slice 影响对象有两种方式。最明显的一种是分割单个对象。

# SMOOTH

Smooth（平滑）修改器对表面应用平滑处理。尽管你通常可以在子对象级对可编辑网格应用平滑。

# SPHERIFY

Spherify（球化）修改器允许将对象扭曲为球形。它提供了一个参数，允许你控制畸变的程度。

# SQUEEZE

Squeeze（挤）允许你沿 Z 轴移动对象的顶点。靠近中心点的顶点比边缘的顶点更远。例如，如果对盒子应用 Squeeze，中心处的顶点会被推开。
