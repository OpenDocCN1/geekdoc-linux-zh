## vrflash
工具将内核和 rootmods 刷入 Agenda VR。Agenda VR 是一种运行 Linux 的手持电脑。`VRflash` 通过串口线与 Agenda 的启动监控器（PMON）通信，在设备上安装新软件。内核和根镜像可以通过这种方式更新。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## vrfy
验证电子邮件地址。“`vrfy'`” 是一个验证电子邮件和邮件列表的工具。在简单格式下，它检查地址“user@domain”，查询“domain”的 MX 主，并在主 MX 主（可选所有）上发送 SMTP 命令 VRFY，或者在不存在 MX 时在“domain”上发送。“domain”指的是“localhost”。更复杂的功能包括递归扩展转发循环、*可以在本地执行的语法检查或完整的 RFC822 地址检查、* 各种选项可以打印许多形式的详细输出。有明显的局限性（主要是由于某些主机上的 VRFY 实现松散），但除此之外它运行得很好。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## vrms
虚拟理查·斯托曼 `vrms` 程序将分析 Debian GNU/Linux 系统上当前安装的软件包，并报告所有当前安装的非自由软件包。未来的 `vrms` 版本包含一个选项，显示 RMS 等人的公开文章，解释为什么每个已安装的非自由软件包对自由软件社区某些人造成了重大问题。该功能尚未包含。

## vrrpd
虚拟路由器冗余协议（Virtual Router Redundancy Protocol）用户用例实现包，提供了 rfc2338 中 VRRPv2 的实现。它运行在 Linux 内核的用户态中（以 root 身份运行）。VRRP 用于在 Debian 中设置高可用服务，使得两台机器可以使用相同的（虚拟）IP 地址，该地址在发生故障转移时传输。需要启用某些内核功能（请阅读常见问题解答）。来自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
