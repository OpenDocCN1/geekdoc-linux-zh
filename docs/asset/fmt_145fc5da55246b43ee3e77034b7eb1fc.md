
- `Activity streams`：一种基于 `JSON` 的格式，用于编码活动和事件元数据，如“喜欢”帖子

- `WebSub`：前身为 `PubSubHubbub` (`PuSH`)，一种用于流、源等的实时通知协议

- `Saloon`：一种消息交换协议，用于统一对帖子和文章的评论。提供单个评论线程，其中引用的源在不同地方被参考。之所以这样称呼，是因为沙龙里的马会逆水游泳（`saloon swim upstream`，双关语，`saloon` 也指西部牛仔酒馆）。

- `WebFinger`：一种用于通过 `URI` 标识的实体的发现协议。这些可能是人，在这种情况下，该协议在功能上（但在结构上完全不）类似于 `ARPANET` 的 `Finger` 协议。

`OStatus` 设计的许多部分已被现代替代方案所取代：`OStatus` 原生不支持私有帖子，这意味着支持私有帖子的平台（如 `Mastodon`）必须使用额外属性来联邦化私信，而且没有保证其他平台会尊重这些属性。

但不要担心，因为从 1.6 版本（2017 年 9 月发布）开始，`Mastodon` 实现了新的、更灵活的 `ActivityPub` 协议。现在我们知道了当时不知道的事情，它有效地提供了分布式社交网络所需的一切。此外，它足够可扩展，能够提供未来所需的功能，并且已经用于比微博客多得多的用途——例如，它是 `PeerTube` 的核心。在此期间，`Mastodon` 将支持 `OStatus` 作为后备，直到 2.0 版本发布。对于这些协议的更详细分析和梳理，我们建议研究 `JB Crawford` 的优秀文章，可以在以下地址找到：`https://lwn.net/Articles/741218`。

### 实例 Mastodon

如果你想运行一个 `Mastodon` 实例，让其他人（甚至只有你自己）可以连接，你需要一台服务器来运行它。这可能是一台在你地下室运行的树莓派，或者一个 `VPS`（你可以租用一台小的，每月低至 5 美元），或者是任何东西。它应该 24/7 可访问，所以在你每晚关机或经常运行资源密集型游戏的家用电脑上运行它可能是个坏主意。此外，如果你选择在家运行 `Mastodon`，你需要配置路由器将流量转发到服务器，使用 `NAT`（针对 `IPv4` 地址）或通过防火墙设置例外（大多数家用路由器，理由充分，会阻止所有传入的 `IPv6` 连接尝试）。具体做法取决于所使用的光猫/路由器。你还需要为你的服务器设置一个域名（没有人喜欢通过 `IP` 地址访问这些服务），你可以使用商业注册商或免费服务（如 `DuckDNS`，它发行形如 `example.duckdns.org` 的子域名）来实现。新域名（以 `.social`、`.xyz`、`.rocks` 或其他所谓后缀结尾的域名）在 `Mastodon` 实例中很受欢迎。如果你只是在测试，可以使用虚构的域名名称，并在 `/etc/hosts` 中放置一条条目。

与许多 `Web` 应用程序一样，你无法在发行版的软件包仓库中找到 `Mastodon`，最好直接从源代码安装。设置好一切是一个漫长的过程。我们需要设置 `Node.js`、`Ruby` 和一个 `PostgreSQL` 数据库以及 `Web` 服务器（及相关证书）。你可能更喜欢使用 `Docker` 镜像。预构建的镜像可在 `https://hub.docker.com/r/tootsuite/mastodon` 获取，它们可以按原样使用或根据你的需求进行定制。在 `Heroku` 和 `Scalify` 上也有现成的付费服务。请阅读 `https://github.com/tootsuite/documentation#running-mastodon` 以研究可用的选项。我们现在将详细介绍独立安装过程，该过程基于 `Ubuntu 18.04` 服务器，但除了少数外观上的差异外，其他发行版上的过程是相似的，如果你使用的是桌面版 `Ubuntu`，过程则完全相同。

首先，在较新的安装环境中（基于 `18.04.1` 点发布的版本），需要启用 `Multiverse` 和 `Restricted` 仓库：

```bash
$ sudo add-apt-repository multiverse
$ sudo add-apt-repository restricted
```

我们还需要添加 `node.js` 和 `Yarn` 仓库，这使用了一种略显不雅但不可否认的便捷做法：将 `curl` 的输出通过管道传递给 `bash`：

```bash
$ curl -sL https://deb.nodesource.com/setup_8.x | sudo bash -
$ curl -sS https://dl.yarnpkg.com/debian/pubkey.gpg | sudo apt-key add -
$ echo "deb https://dl.yarnpkg.com/debian/ stable main" | sudo tee /etc/apt/sources.list.d/yarn.list
$ sudo apt update
```

现在我们可以安装依赖项了，依赖项很多（你可能想从之前链接的 `Tootsuite` `GitHub` 页面复制并粘贴此命令 – 只需跟随 `Standalone Installation` 链接即可）：

```bash
$ sudo apt -y install imagemagick ffmpeg libpq-dev libvips-dev libssl1.1-dev file git-core \
libprotobuf-dev protobuf-compiler pkg-config nodejs gcc autoconf build-essential libssl-dev \
libyaml-dev libreadline6-dev zlib1g-dev libncurses5-dev libffi-dev libgdbm5 libgdbm-dev \
nginx redis-server redis-tools postgresql postgresql-contrib certbot yarn libidn11-dev libicu-dev
```

接下来，我们将设置一个 `Mastodon` 用户并构建 `Ruby` 环境，步骤如下：

```bash
$ sudo adduser mastodon
$ su - mastodon
$ git clone https://github.com/rbenv/rbenv.git ~/.rbenv
$ cd ~/.rbenv && src/configure && make -C src
$ echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
$ echo 'eval "$(rbenv init -)"' >> ~/.bashrc
```

### 社交网络的开源探索

我们在这里专注于 `Mastodon`，但还有各种其他开源的、去中心化的流行社交媒体平台替代品。`PeerTube` 是一个使用 `WebTorrent` 技术来减轻服务器负担的视频共享平台（同样，任何人都可以托管服务器，且服务器之间可以联合）。当用户观看视频时，他们也会将其分享给其他用户，为热门视频创造了一种正向反馈循环。

对于静态图片，以及那些寻找 `Instagram` 或 `Flickr` 之外归宿的人，这里有 `Pixelfed` (`https://pixelfed.org`)。与 `Mastodon` 类似，你可以托管自己的 `Pixelfed` 实例并与其他实例联合，比如你在 `https://pixelfed.social` 可以找到的那个实例。对于更偏向 `Facebook` 而非 `Twitter` 类型的去中心化社交网络，你应该关注 `Diaspora*` (`https://diasporafoundation.org`)。实例被称为“`pods`”，而 `pods` 可以基于地理位置、兴趣、酷炫的域名或受欢迎程度。对于拿不定主意的人，`The Federation` (`https://the-federation.info`) 收集了不仅限于 `diaspora*` `pods` 的自愿统计数据，还包括本文提到的所有网络以及更多网络的实例数据。联邦制模糊了传统的边界，因此许多这些网络可以互相通信，无论是通过交叉发帖工具还是通过 `ActivityPub` 原生实现。

我们需要重启 `shell` 以应用这些环境变更，然后安装 `ruby-build` 并安装所需的 `Ruby` 版本：

```bash
$ exec bash
$ git clone https://github.com/rbenv/ruby-build.git ~/rbenv/plugins/ruby-build
$ rbenv install 2.5.1
$ rbenv global 2.5.1
```
