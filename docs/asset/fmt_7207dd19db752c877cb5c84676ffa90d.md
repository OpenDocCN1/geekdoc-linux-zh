## vi 内置编辑器

要编辑历史列表，请转到命令行并按 `Esc` 键。然后，如果要在历史列表中向上滚动，请按 `K` 键；要向下移动，请按 `J` 键，就像标准的 vi 移动键一样。找到要编辑的命令后，使用 vi 中用于向左和向右移动、删除、插入和更改文本的标准键。（参见表 9.13。）完成编辑后，按回车键。该命令将被执行并添加到历史列表的底部。如果要添加或插入文本，请使用任何插入命令（`i`、`e`、`o`、`O` 等）。请记住，vi 有两种模式：命令模式和插入模式。实际键入文本时，你始终处于插入模式。要返回命令模式，请按 `Esc` 键。

### 表 9.13 vi 命令

| 命令 | 功能 |
|---|---|
| 在历史文件中移动 | |
| `Esc K` 或 `+` | 在历史列表中向上移动 |
| `Esc J` 或 `-` | 在历史列表中向下移动 |
| `G` | 移动到历史文件中的第一行 |
| `5G` | 移动到历史文件中的第五个命令 |
| `/string` | 在历史文件中向上搜索 |
| `?` | 在历史文件中向下搜索字符串 |

### 表 9.13 vi 命令（续）

| 命令 | 功能 |
|---|---|
| 在行内移动 | |
| `h` | 在行内向左移动 |
| `l` | 在行内向右移动 |
| `b` | 向后移动一个单词 |
| `e` 或 `w` | 向前移动一个单词 |
| `^` 或 `0` | 移动到行首第一个字符 |
| `$` | 移动到行尾 |
| 使用 vi 编辑 | |
| `a A` | 追加文本 |
| `i I` | 插入文本 |
| `dd dw x` | 将文本删除到缓冲区（行、单词或字符） |
| `cc C` | 更改文本 |
| `u U` | 撤销 |
| `yy Y` | 复制（将一行复制到缓冲区） |
| `p P` | 将复制或删除的行放到当前行下方或上方 |
| `r R` | 替换行中的一个字母或任意数量的文本 |

## emacs 内置编辑器

如果你使用的是 emacs 内置编辑器，与 vi 一样，从命令行开始。要通过历史文件向上移动，请按 `^P`。要向下移动，请按 `^N`。使用 emacs 编辑命令更改或纠正文本，然后按回车键，该命令将被重新执行。参见表 9.14。

### 表 9.14 emacs 命令

| 命令 | 功能 |
|---|---|
| `Ctrl-P` | 在历史文件中向上移动 |
| `Ctrl-N` | 在历史文件中向下移动 |
| `Esc <` | 移动到历史文件的第一行 |
| `Esc >` | 移动到历史文件的最后一行 |
| `Ctrl-B` | 向后移动一个字符 |

| `Esc <` | 移动到历史文件第一行 |

## 绑定键

`bindkey` 内置命令列出所有标准键绑定，包括 emacs 和 vi 的键绑定。键绑定分为四组：标准键绑定、替代键绑定、多字符键绑定和箭头键绑定。`bindkey` 命令还允许您更改键的当前绑定。

### 示例 9.81

```
1 > bindkey

Standard key bindings

"^B" -> is undefined

"^A" -> beginning-of-line

"^B" -> backward-char

"^C" -> tty-sigintr

"^D" -> list-or-eof

"^E" -> end-of-line

"^F" -> forward-char

"^L" -> clear-screen

"^M" -> newline

...

Alternative key bindings

"^B" -> is undefined

"^A" -> beginning-of-line

"^B" -> is undefined

"^C" -> tty-sigintr

"^D" -> list-choices

"^E" -> end-of-line

"^F" -> is undefined

...

Multi-character bindings

"^["A" -> up-history

"^["B" -> down-history

"^["C" -> forward-char

"^["D" -> backward-char

"^["OA" -> up-history

"^["OB" -> down-history

...

Arrow key bindings

down -> down-history

up -> up-history

left -> backward-char

right -> forward-char
```

`bindkey` 的 `-l` 选项列出编辑器命令及其作用。参见示例 9.84。

### 示例 9.84

```
> bindkey -l

backward-char

  Move back a character

backward-delete-char

  Delete the character behind cursor
```
