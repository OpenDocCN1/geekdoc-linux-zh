# 生物学模型

生物学考虑促成了某些胜者为王模型的产生（Elias and Grossberg, 1975）。我们描述了一个满足李雅普夫函数属性的模型；它是有下界的，并且当方程 $dE/dt = -\sum(\partial E/\partial\zeta_i)^2$ 指定的动力学随时间增加而减小。可以看到 $\zeta$ 被限制为正值。因此系统收敛于 $\zeta$ 的最小值。
