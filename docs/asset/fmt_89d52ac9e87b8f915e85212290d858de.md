# 守恒定律（物理学）

守恒定律是描述在孤立系统中，特定物理量的总数值随时间保持不变的原则。守恒定律在物理学基础及其应用中都占据着极其重要的地位。

## 在经典力学中的体现

力学中有三大守恒定律：动量守恒，通常简称为**动量守恒**；**角动量守恒**；以及**能量守恒**。

质点的动量，或简称**动量**，等于其质量与速度的乘积。它是一个矢量物理量。一个由多个质点组成的系统的总动量，仅仅是各质点分别考虑的动量之和。动量守恒定律指出，该总动量不随时间变化。参见[动量守恒](https://example.org/conservation_of_momentum)；[动量](https://example.org/momentum)。

质点的**角动量**则更为复杂。它由位置矢量和动量矢量的叉积（向量积）定义。角动量守恒定律指出，孤立系统的总角动量不随时间变化。参见[角动量](https://example.org/angular_momentum)。

**能量守恒**可能是所有定律中最重要的一个。能量是一个标量物理量，有两种形式：动能和势能。质点的动能定义为其质量与速度平方乘积的一半。势能通常被松散地定义为做功的能力。总能量是动能和势能之和，根据守恒定律，在孤立系统中，总能量不随时间变化。

通过考虑两个碰撞物体间的问题，可以体会到应用能量守恒定律时的本质困难。一般而言，物体碰撞后的运动速度比碰撞前更慢。这种现象似乎违反了能量守恒定律，直到人们意识到涉及的物体可能由更小的粒子组成。它们的随机微观运动需要消耗动能，从而剥夺了直接观测到的宏观物体的相干大尺度运动所具有的能量。十九世纪物理学最伟大的成就之一，就是认识到宏观物体内部的微观运动可以与感知的热属性对应。参见[能量守恒](https://example.org/conservation_of_energy)；[能量](https://example.org/energy)；[物质动理论](https://example.org/kinetic_theory_of_matter)。

## 在现代物理学中的作用

随着物理学的发展，伟大的守恒定律在形式和内容上同样经历了演变，但从未停止作为重要的指导原则。

为了描述电磁现象，必须超越点粒子的概念，假设充满整个空间的连续电场和磁场的存在。为了获得有效的守恒定律，必须将能量、动量和角动量赋予电磁场。参见[电磁辐射](https://example.org/electromagnetic_radiation)；[麦克斯韦方程组](https://example.org/maxwells_equations)；[坡印廷矢量](https://example.org/poyntings_vector)。

在狭义相对论中，能量和动量不是独立的概念。爱因斯坦发现了狭义相对论或许最重要的推论，即**质能等价性**，这是基于守恒定律得出的结果。“**质量守恒定律**”被理解为能量守恒的一个近似推论。参见[质量守恒](https://example.org/conservation_of_mass)；[相对论](https://example.org/relativity)。

对称性与守恒定律之间建立了一种卓越、优美且极具成果的联系。因此，**动量守恒定律**被理解为空间均匀性的结果，**能量守恒**被理解为时间均匀性的结果，**角动量守恒**被理解为空间各向同性的结果，而**能量守恒**也被视为时间均匀性的结果。参见[对称性定律（物理学）](https://example.org/symmetry_laws_physics)。

广义相对论（现代引力理论）的发展，要求关注守恒定律的一个根本问题：这些定律指的是“孤立系统”，但并不清楚是否有任何系统真正是孤立的。对于长程作用力并在宇宙尺度上累积的引力而言，这是一个尤为尖锐的问题。事实证明，物理定律的对称性实际上比守恒定律本身更为根本，因为即使守恒定律严格来说失效时，对称性仍然有效。

在量子理论中，伟大的守恒定律在非常强的意义上仍然有效。通常，量子力学的形式体系不允许预测单个实验的结果，只能预测不同可能结果的相对概率。因此，人们可能会认为守恒定律仅在平均意义上有效。然而，在每一个实验中，能量、动量和角动量都是守恒的。参见[量子力学](https://example.org/quantum_mechanics)；[量子测量理论](https://example.org/quantum_theory_of_measurement)。

## 粒子类型的守恒定律

还有另一类重要的守恒定律，它们与粒子的运动无关，而与粒子的类型有关。其中在实践上或许最重要的一条定律是**化学元素守恒**。从现代观点来看，这一原理源于这样一个事实：化学变化中涉及的能量微小，不足以破坏原子深处的原子核。它不是一条绝对定律，因为某些原子核会自发衰变，而在能量足够高时，该定律会被显著违背。参见[放射性](https://example.org/radioactivity)。

粒子物理学中有几条守恒定律具有类似的性质：它们是有用的，即使它们不精确，因为尽管已知的过程会违背它们，但这些过程要么异常缓慢，要么需要极高的能量。参见[基本粒子](https://example.org/elementary_particle)。

# 能量守恒

能量守恒原理指出，能量不能被创造或消灭，尽管它可以从一个形式转换为另一个形式。因此，在任何孤立或封闭系统中，所有形式能量的总和保持不变。系统的能量可以在许多不同形式之间相互转换——化学能、电能、磁能、热能、化学能、核能等——随着时间推移，其可用性趋于降低；但在小实验误差的范围内，在任何能够确保能量未以做功或热量的形式进入或离开系统的情形中，均未观察到总能量发生变化。对于既通过做功和热量获得能量又失去能量的系统（如许多运行中的机器），能量原理断言，净能量增益等于系统内能的总变化。参见[热力学原理](https://example.org/thermodynamic_principles)。

能量守恒原理有许多种表述方式，具体取决于预期的应用。特别值得关注的是该原理的一种特殊形式，即**机械能守恒原理**，它指出任何以任何方式相互连接的物体系统的机械能是守恒的，前提是系统不受任何摩擦力作用，包括在物体碰撞过程中可能产生的内部摩擦。

J. P. 焦耳和其他人证明了热和功的等价性，他们表明，尽管对于每一台运行中的机器，在克服摩擦力所做的功之后，总会出现一定数量的热量。实验通常是这样安排的：产生的热量被给定数量的水吸收，观察到给定量的机械能支出总是在水中产生相同的温度升高。由此产生的机械能与热量之间的数值关系称为**焦耳当量**，也称为**热的机械当量**。

鉴于狭义相对论中**质能等价**原理，经典能量守恒原理必须被视为**质能守恒**原理的一个特例。然而，这一更普遍的原理并不一定仅在处理某些核现象或涉及与光速相当的速度（$1.86 \times 10^8$ m/s 或 $3 \times 10^8$ m/s）时才需要引入。

# 质量守恒

认为质量，或物质，既不能被创造也不能被毁灭的观念。根据质量守恒，改变物质属性的反应或相互作用不会改变其总质量；例如，当木炭燃烧时，所有燃烧产物（如灰烬、烟灰和气体）的质量等于木炭的原始质量及其反应所用的氧气质量。

阿尔伯特·爱因斯坦的**狭义相对论**，已通过实验验证，表明当物体拥有的能量变化时，物体的质量也会随之变化。除亚原子现象外，这种质量变化太小而无法检测到。此外，物质可以被创造，例如通过光子（电磁能量量子）物质化形成电子-正电子对；或者物质可以被摧毁，通过这对基本粒子的湮灭产生一对光子。参见[电子-正电子对产生](https://example.org/electron_positron_pair_production)；[相对论](https://example.org/relativity)。
