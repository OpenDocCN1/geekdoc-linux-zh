
如果你尝试打开需要用户名和密码，系统会在新窗口中提示这些信息（图 6-8）。注意，在这种情况下，你需要的用户名和密码是你尝试连接的机器的，而不是你在 Ubuntu 中使用的（除非用户名和/或密码恰好相同）。你就可以像处理硬盘上的文件夹一样，在该共享之间复制文件。

在某些情况下，特别是当尝试访问运行 OS X 的 Mac 上的共享时，双击方法可能无效。尽管 Nautilus 窗口中显示了该机器的图标，你仍然无法访问该机器的共享。在这种情况下，双击你尝试访问的机器图标，然后点击一次（打开一个空窗口），进入菜单（`Menu`）并选择“位置”（`Location`）。位置栏中会出现一个文本框（如图 6-5 所示），其中已经填充了你尝试访问的机器的位置。

在该位置之后，添加一个正斜杠（`/`），然后是目标机器上的用户名。例如，如果目标机器名为 `cowboys`，用户名是 `metowyou`，则位置为 `smb://cowboys/metowyou`。如果你知道该文件夹的路径，也可以将其缩小到网络中的特定文件夹，只需添加你已经输入的路径即可，例如添加 `smb://cowboys/metowyou/Documents`。

该路径的头部代表服务器消息块（server message block），但为了方便起见（或许可能更容易记忆），你可以将其视为 Samba 的缩写，Samba 是基于 Unix 的系统（如 Linux 和 Mac OS）用于与 Windows 网络交互的软件。

一旦你进入了已连接的网络机器上想要浏览的文件夹，使用 Nautilus 的书签功能标记该打开的共享窗口可能是个好主意。之后，你可以通过在 Nautilus 书签菜单中选择共享名称，轻松地访问该共享。如果由我来称赞的话，这真的很酷。

# Nautilus 作为 FTP 客户端

Nautilus 不仅允许浏览和挂载本地网络上的共享，还可以作为一个 FTP 客户端，例如当你想更改远程服务器上网站的文件时。要执行此操作，转到“连接服务器”窗口（文件 `File` ► 连接服务器 `Connect to Server`），然后在服务类型中选择 FTP（登录）。输入由你的网站托管商提供的信息，并点击“连接”按钮。桌面和侧边栏将出现一个 FTP 网络图标。双击该图标，在提示时输入你的密码（针对该账户的密码——而不是你 Ubuntu 系统的密码，除非两者恰好相同），然后你就可以查看并添加你那里的文件了。

# Nautilus 中的文件和文件夹权限

在探索 Ubuntu 世界的过程中，你会发现会遇到以某种方式锁定的文件或文件夹，无论是取决于你能够读取它们、编辑它们，还是两者兼有。这些可读性和可更改性状态被称为“权限”（`permissions`）。

现在你可能会（合理地）怀疑这些权限机制有什么意义，为了帮助你理解，我将给你一些它的用处例子。假设你有一些不想让配偶或孩子看到的文件——例如，一些糟糕的诗或一份圣诞购物清单。通过拒绝对文件或包含这些文件的文件夹的读取权限，没有人能够偷看，除非他们擅长更改权限，并且拥有更改这些文件或文件夹权限的必要权限。

另一个例子是，想象你有一个工作了小时并终于完成的文件。为了缓解你可能以某种方式意外将其丢废桶的恐惧，你可以拒绝写入权限。通过这样做，在不更改权限的情况下，你无法对该文件进行任何操作。事实上，如果你尝试将该文件移动到回收箱，甚至移动到另一个文件夹，你将收到一个“无法执行”的消息，如图 6-9 所示。

# 在 Nautilus 中更改文件和文件夹权限

若要在 Nautilus 中更改文件或文件夹权限，只需右键点击文件夹，并在弹出菜单中选择“属性”（`Properties`）。打开属性窗口后，点击“权限”（`Permissions`）选项卡，查看所有者是谁以及他们被允许做什么。你可能会觉得这些权限机制有点困惑，但它其实很简单：

- 读取（`Read`）：查看的权限
- 写入（`Write`）：更改的权限
- 执行（`Execute`）：运行程序的权限

通常情况下，你不需要担心为他人设置权限，但如果需要，你可以更改所有者和组设置。

## 读取 CD 和 DVD

在 Ubuntu 中处理 CD 和 DVD 非常简单，因为一切都是自动的。要读取带有数据的 CD 或 DVD（而不是音乐或视频），将光盘放入驱动器，桌面上会自动出现一个 CD 或 DVD 图标（它们看起来一样）。显示磁盘内容的 Nautilus 窗口也会出现，你可以使用标准的拖放程序将文件从 CD 或 DVD 复制到硬盘。

当你想要移除 CD 或 DVD 时，只需关闭其 Nautilus 窗口，右键点击桌面图标，并在弹出菜单中选择“弹出”（`Eject`）。磁盘就会弹出。

## 刻录 CD 和 DVD

在 GNOME 中刻录 CD 和 DVD 非常简单。你只需要将一张空白的 CD-R（可刻录 CD）或 DVD（Ubuntu 支持 DVD-RW、DVD-R 和 DVD-RW）放入驱动器中，并确保选择了驱动器支持的介质格式，然后会弹窗询问你想对磁盘做什么。点击“刻录数据 CD”（`Burn Data CD`）按钮，或者在空白 DVD 的情况下点击“制作 DVD”（`Make DVD`）按钮。Nautilus 的 CD/DVD 创建器窗口随后将会出现，你可能发现它看起来与其他 Nautilus 窗口非常相似，区别在于位置栏下方有一条横带以及一个“写入磁盘”按钮（图 6-12）。

## CD/DVD 刻录器 - 文件浏览器

![](img/ba6b82a7869bba748202d57c97336dca_111_0.png)

**图 6-12：打开 Nautilus CD/DVD 刻录器窗口，文件已准备好刻录到磁盘**

一旦打开 CD/DVD 刻录器窗口，将想要刻录到磁盘的文件其实是非常简单的拖放操作。只需打开一个新的 Nautilus 窗口，将想要刻录的文件拖到 CD/DVD 刻录器窗口上。如果你更倾向于使用典型的 Windows 风格操作，可以通过单击每个文件来选择要传输到磁盘的文件，同时按住 `CTRL` 键进行多项选择。如果你想选择多个连续文件，可以点击组中的第一个文件，按下 `SHIFT` 键，然后点击组中的最后一个文件，系统会自动选择中间的所有文件。释放 `CTRL` 或 `SHIFT` 键，右键点击任何高亮显示的文件，并在弹出菜单中选择**复制**。之后，回到 CD/DVD 刻录器窗口，右键点击任何空白区域，然后在菜单中选择**粘贴**。

值得一提的是，你复制到 CD/DVD 刻录器的文件实际上并没有被复制。相反，你在刻录器窗口中看到的本质上是原始位置文件的别名。如果你在将 CD/DVD 刻录器窗口的内容刻录到磁盘之前从原始位置移动了其中一个文件，该文件将自动从窗口中消失，并在你最终执行刻录步骤时不会被刻录。这并不是问题，但值得注意。

一旦你复制了所有想要刻录到磁盘的文件，点击**写入磁盘**（`Write to Disc`）按钮，随后会弹一个窗口（如图 6-13 所示），它会告诉你你选择了多少兆字节的文件要写入磁盘。在这个窗口中，你可以为磁盘命名，并调整磁盘刻录的速度（速度越慢 = 出错机会越少），不过你也可以接受默认设置。

### 图 6-13：在刻录 CD 或 DVD 之前的设置选项

当你准备好刻录磁盘时，点击写入（`Write`）按钮，CD / DVD 刻录器就会开始工作。在某些情况下，会出现一个警告窗口，提示某些文件的命名可能不符合 Windows 兼容性。如果遇到此类窗口，只需点击确定，除非你打算将文件传输到系统，如果是那样，你最好在开始实际刻录之前根据 Windows 命名规范重命名文件。特别要避免特殊字符和变音（如变音符号和重音），并且不要使用以下字符：`/` `:` `?` `*` `"` `<` `>` `|`

一旦刻录开始，其进度将在新窗口中显示，当磁盘完成后，系统会询问你接下来想做什么。假设你今天只用一次磁盘刻录，点击弹出（`Eject`），然后点击关闭（`Close`）。

如果你好奇，你在 Linux 中刻录的磁盘在其他操作系统中是可以读取的。

## 处理 CD-RW 磁盘

CD-RW 磁盘与 CD-R 磁盘几乎相同，只是它们可以被擦除并再次写入。它们也比 CD-R 磁盘贵得多，而且通常不支持更高的刻录速度。
