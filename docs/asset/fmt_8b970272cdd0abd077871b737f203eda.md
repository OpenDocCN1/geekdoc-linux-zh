
氚，`T` 及其同位素氢 `H` 处于几乎完全相同的条件下。巨大的区别是氚的性质与氢不同，如表所示。化学上它的行为相似，但由于质量较大，它的许多反应比氢慢得多。

氚原子也被称为质子（protiumgen），由两个质子和两个中子组成。

# Triton 是 ³H 的原子

氚是氢已知唯一的放射性原子。氚是由氘 (`³H + n → ³He`) 通过 β 衰变为 `e⁻` 产生的，半衰期为 12.3 年。在产生 `³H` 的过程中释放了约 20 `MeV` 的能量。氚也用于核轰击实验。参见核聚变（`NUCLEAR FUSION`）。

# 三目是一类小型开花植物，

被子植物（Angiosperms），双子叶植物，木兰目。该目包含两个科，三目科（`Trituraceae`）有七属，二十种花头大，叶片从中等长度到长且尖。花瓣许多，螺旋形排列且多轮生。雄蕊许多，合蕊序或花冠合蕊序，子房离生且发育良好。它们主要生长在旧世界的热带地区，以及植物园中。参见百合目（`ALISENALES`）、木兰目（`MAGNOLIALES`）、被子植物（`MAGNOLYPHYTA`）。`[A.C.J.]`

# 夹竹目是一类开花植物，

被子植物（Angiosperms），双子叶植物。该目包含两个科，夹竹科（`Trochodendraceae`）和四角科（`Tetraaceae`）。每个科只有一个具有极大美丽和观赏价值的物种，因为它位于双子叶植物基部和岛屿上。夹竹（`Trochododendron`）是更大的群体，具有更原始的开花植物（具有木质部）。花瓣退化严重，萼片略微融合

有些叶片呈梨形，颜色各种 a.Bryan（B. Patella, a. mollusc, C. Polyargus, an. Asterias）（参考 F. Storer 等人的《普通动物学》，44, MacGregor-1970）。

外部具有隐蔽的颜色（a tria）和两个附属须。前萼和后萼齿以及子房经常存在。消化道完整且功能正常；具有对的肾器和排泄管；肌肉和神经纤维、器官和心脏。肠很长，幼虫沿着许多分叉发育，指示了这些族群的进化关系并代表了。参见百合目（`ALISENALES`）、`BRAACHIOIDA`、`BRYOIDA`、`MOLLICA`、`POLYARGUS`、`TETEROIDA`。

# 火鸟目是一种小型鸟类，仅包含

蜂鸟科（`Trogonidae`），在全球范围内分布三个种。蜂鸟是松鸦大小的鸟，头大，尾巴从中等长度到长且尖。喙短且钩。雄性羽毛为绿色，雌性为褐色或灰色。羽毛有亮红色、黄色或橙色。尽管颜色鲜艳，这些鸟在栖息时并不显眼。蜂鸟的腿很短，尾巴长，第一趾和第二趾之间有额外的羽毛。它们的飞行快速、起伏且嘈杂；栖息时缓慢且安静。它们的饮食包括果实和小虫，它们在树外的空气中捕食。

`[J.W.B.]`

# 位于拉格朗日的特洛伊行星

太阳-木星系统的拉格朗稳定点。正如 `Lagrange` 在 1772 年所示，两个点位于行星，另外三个点位于通过系统中两个最大质量体的直线上。1906 年，马克斯·沃尔夫（`Max Wolf`）发现了一个位于木星拉格朗点的小行星。空间中更多行星的发现导致人们根据荷马的《伊利亚特》中的特洛伊战争命名这些行星。

# 大气散射

太阳在北极圈以北的地平线上角为 47°，在摩羯回归线处在其上方 43°。北回归线是被称为热带的赤道区的北部边界，热带位于北回归线和南回归线之间。见纬度和经度：地理；科学。`[H.]`

# 摩羯回归线

位于赤道以南约 23°25'（23° 45'）的纬线。它以织户座星座（`Capricorn`）命名，其原因是某种尚不完全清楚的天文学文学原因。

在它绕太阳公转的过程中，其地轴相对于黄道面倾斜 23°½'，南回归线标志着天顶区的南部边界。在这一天发生夏至，此时太阳位于地平线上 90°。

南回归线是赤道区的南部边界，赤道位于北回归线和南回归线之间。见气象地理；北回归线。`[H.]`

# 热带气象

对纬度南北各 30° 区域大气结构和气候的研究。

热带涉及对流、辐合、离散、信风、飓风和厄尔尼诺南方涛动。低纬度地区从太阳获得的能量多于损失到太空的辐射能量。高纬度地区相反，极地风主导信风。

大部分情况下，热带地区（岛屿）每天的变化很小。天气变化仅在严重事件中发生。热带风暴是各半球的特征。南纬 5° 到北纬 5° 之间的赤道带很少没有飓风，信风从东向向西吹出。地球表面的陆地较小，夏冬差异也较小。事实上，对于印度北部的陆地，经验人士夏季温度为 18°C 至 28°C（64°F 至 82°F），而 7 月温度保持在 22°C（72°F）。陆地上大区域的日夜温差也很大，夏季（64°F 或 18°C）或冬季（14°F 或 -8°C）。

北半球南纬 5° 到北纬 20° 之间发现稳定地风被称为信风。南半球纬度地区也有信风。这些风的强度为 5-10 节（2.5-5 m/s）。它们是气旋的赤道边界。海洋上的风向很大。见风。

飓风也发生在热带，印度洋和南太平洋也有热带气旋。如果热带风暴的风超过 65 节（33 m/s），它就会变成飓风。飓风通常在赤道 5° 纬以南北的低压（气旋）上方形成。见飓风。

赤道辐合带通常位于纬度 5° 到 10° 之间。它们通常面向西和东，包含每天降水量在 10 到 50 毫米的云。两个半球的信风都向这个降水系统输送水分。见云；物理；降水（气象）。

快速移动的洋流被称为急流，是热带环流的重要元素。其速度超过 30 节（15 m/s），分布于热带的几个地区。见大气环流；急流。

季风从亚洲沿岸向内陆吹，，延伸到经验人士称为季风的陆地地区。季风由冷海洋和暖陆地之间的热力差异驱动。见季风。

每 2-6 年，赤道东部太平洋的海表温度升高 5-9°F（3-5°C）。这种现象被称为厄尔尼诺，是厄尔尼诺-南方涛动的一部分。

另一个极端情况被称为拉尼娜。已知它会影响全球范围的天气。见厄尔尼诺；海洋学。

# 对流层顶

对流层与平流层之间的边界。对流层顶定义为温度递减（度）小于 8°F（每公里 2°C）的高度。在低纬地区，对流层高度为 12-18 km（40-60 km），在中纬度和极地地区，对流层较低，位于海平面 6-12 km（20-40 km）。在热带和极地对流层交汇处可能会出现著名的“标记对流层顶”。见平流层。

# 对流层散射

从表面到高度 6-10 km（20-30 km）的大气低层，平流层的基底部。它包含了大气总质量的五之四。

平均而言，温度在该层随高度增加降低，递减率为每英里 18°F（每公里 6.5°C）。在近地低层发生高逆温。明显的水气和云大多局限于低层。这里是由对流、辐射和表面摩擦引起的所有重要过程和天气变化。见云；物理；天气。

# 对流层散射

用于平流层底部不规则层对无线电波折射的术语；在对流层以上很少或没有发生。对流层散射提供了非常有用的通信，但也可能对频率业务和调频广播引起干扰。高频通信和微波信号通过它进行远距离对点传输。典型的对流层散射发生在 200-500 m（600 ft）以上的地球上方。在某些情况下，500 m（800 ft）发生高频散射。

# 卡车

一种运载货物或货物的车辆，卡车在许多方面与汽车相似，但通常具有加强的底盘、悬挂、变速箱、驱动轴和货床。然而，许多不同类型的卡车。见汽车；系统。

卡车根据总重（gtw）额定，即车辆和载荷的总重。分为轻型、中型或重型。尽管热带地区（岛屿）每天的变化很小，天气变化仅在严重事件中发生。热带风暴是各半球的特征。南纬 5° 到北纬 5° 之间的赤道带很少没有飓风，信风从东向西吹出。地球表面的陆地较小，夏冬差异也较小。事实上，对于印度北部的陆地，经验人士夏季温度为 18°C 至 28°C（64°F 至 82°F），而 7 月温度保持在 22°C（72°F）。陆地上大区域的日夜温差也很大，夏季（64°F 或 18°C）或冬季（14°F 或 -8°C）。
