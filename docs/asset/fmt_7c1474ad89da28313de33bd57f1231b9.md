# 让我们看看输出行：

# `000000` 是起始偏移量：为零：

# 下一个数字是偏移量：字节2 是 `137 012`

# 后的数字是八进制：`137 040 011 012 137 012`

# 例如，一个空格可以表示为八进制的 `\040`。

# `137` 是下划线：

# `040` 是空格。

# 数字用于显示记录的开始和结束。

# `011` 是制表符 `(\t)`。

# `012` 是换行符 `(\n)`。

# `037` 第二次出现的是下划线。

# 行尾的 `012` 是换行符，

# 它是 `'echo'` 自动放置在那里的。

# `0006` 表示你目前为止打印了多少字节。

# 你可能在问：“既然我都知道了，那又怎么了？”

# 这意味着默认的 `IFS` 有三个值：空格、制表符和换行符。
