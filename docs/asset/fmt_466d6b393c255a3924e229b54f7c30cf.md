
# 2154 超导器件

超导体是在氮气温度下通过新型超导技术制造的。超导器件可以方便地分为两类：薄膜器件和利用二型超导体制成的零电阻材料的大型器件。

超导器件。各种薄膜器件的性能比其非超导对应物更高。20 世纪60 年初对超导性的预测和发现为开发灵敏磁性探测器提供了新的机会。

基于 `SQUID` 的探测器现在基于采用半导体行业光刻技术的硅片，已经有了多种选择。这些器件在 42 K 或更低的温度下工作（4.2-152 K），这正是常大气压下液氦的温度。

高温超导体的发现使得 `SQUID` 能够在液氮（77 K）中运行，这使其比液氦更易获得，同时也使其制造变得更加容易，能够使用更简单、更紧凑的器件。新型超导体，如 `YBaCuO3` (`YBCO`)，已以薄膜形式开发到实际应用的水平，并已有若干器件可用。密集的材料研究导致了高温 `SQUID` 的成功，这些器件是在两个 `YBCO` 晶粒之间的界面形成的。

这些细晶粒边界是通过在基底上沉积薄膜并使两层薄膜在其上生长制成的。这是通过控制晶体的取向，或通过基底上的阶梯边缘来实现的。

## 超导量子干涉器件类型

两种超导量子干涉器件 (`SQUID`) 类型：直流 `dc SQUID` 和射频 `rf SQUID`。`dc SQUID` 带有直流偏置电流，由两个串联的约瑟夫森结组成。磁力计在器件上施加磁场时测量 `SQUID` 的电流（或电压 `V-I`），这会诱导磁通环路产生周期为 `Φ0` 的振荡；`Φ0 = 2h × 2.07 × 10^-15 Wb`，其中 `h` 是普朗克常数，`e` 是电子电荷。然后，`SQUID` 在磁通量上几乎是周期性的。

`rf SQUID` 几乎在磁锁环中运行。施加的通量在 `rf` 回中产生相应的电流，然后产生被放大器检测到的输出电压。在反馈电路中，输出电压被反馈到施加的通量以保持恒定通量。见 `EFFECT: SQUID`。

存在许多集成到超导环中的约瑟夫森结的传感器。例如，磁力计通过将超导磁通环耦合到变压器制造。施加在采样环上的磁场会在变压器中产生持久电流，从而在 `SQUID` 中产生磁通。

例如地球物理学，在磁电测法中。见 `GEOPHYS EXPL: MAGNETOMETER`。

低温 `SQUID` 用于测量极低温度下样品的磁灵敏度。另一个应用是用于人脑研究的高灵敏电压表。高温 `SQUID` 用作核和核四极矩的超声波探测器，并作为引力波探测器。最近的工作显示 `SQUID` 已经从聚集在一起的单量子片捕捉到了磁体的图像。

见 `HALL: MAGNETIC SENSITIVITY; RESONANCE (NMR); THERMOELECTRIC:`。

`SQUID` 最实用的应用领域包括生物物理学、地球物理学和人脑医学研究。在这些研究中，磁力计或梯度计被放置在磁屏蔽房间内的人体附近。`SQUID` 记录的波动磁信号耦合到电极。这两种技术已用于指出癫痫的起源，并确定大脑返回肿瘤信号的功能。见 `BIOMAGNETICS`。

对于……而言，最灵敏的探测器是超导量子干涉器件 (`SQUID`) 结。约瑟夫森结在只有一个电流通过它时，是超导的。电压-电流特性在 `2V/e` 处显示出电压的急剧变化，`SQUID` 偏置在该设定附近，此处特性具有高度非线性，并用于测量磁场。

这些混合器在高达几吉赫的频率下非常有用。无线电天文学中获取重要信息的接收器，例如，气球载或在水蒸气大气层运行的高空地面望远镜。

高温超导体的出现使研究人员开发了被动和微波滤波器，利用了这些氮气温度下制造的导体材料极低的电阻。薄膜 `YBCO` 线圈的改进了 `SQUID` 的信噪比。见 `RESONANCE (NMR): FILTER`。

超导线圈用于大型应用。当需要强磁场时，超导磁体提供的场仅为等效刚性磁体的 5-10%。在异常配置和较小总体积内实现的相对高磁场降低了昂贵构造的成本。见 `MOIST:`。

`钛铌` (`NbTi`) 已广泛用于大型应用，随后是 `A15` 线圈，包括锡铌 (`Nb,Sn`)、铝铌 (`Nb-Al`)、锗 (`Nb-Ge`) 和镓钒 (`V,Ca`)。在高温陶瓷超导体出现之前，铌保持着最高温度（23 K – 45 K）的记录。见 `A15 phases`。

# 超导性 2155

高温超导体已取得显著进展。已找到在 20 K (41 K) 下运行的新材料。电流的载流能力有限。要在大型应用中使用这些材料，仍需大量的开发。

`Nb-Ti` 超导体被广泛使用。医院和诊所的大多数 `MRI` 机器都集成了超导磁体。见 `MEDICAL`。
