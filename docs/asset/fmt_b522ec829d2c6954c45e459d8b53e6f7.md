# 质量识别

气体速度与声速进行比较。该比值称为马赫数（`M`），由公式(5)定义。

```
M = \frac{V}{a} (5)
```

利用马赫数可以描述不同的流态：

- `M < 1` 亚音流
- `M = 1` 声速流
- `0.9 < M < 1.1` 跨声流
- `M > 1` 超音速流
- `M > 5` 高超速流

高速飞行器根据马赫数进行分类。见 SOUND（声学）。流体可以分为内部流和外部流。内部流指的是受管道、飞机或导弹限制的气体。外部流通常以激波和波波的方向为特征，这些波会在管道内壁和内部流中发生反射。通过逐一忽略这些影响，可以更简单地描述内部流的基本特征。

边界层是外部流关注的重点。在内部流中，如果除了一维方法假设外没有建立其他关系，分析压缩性的影响更为困难。参见 Anderson, *现代气体动力学导论 (Modern Introduction to Gas Dynamics)*, McGraw-Hill。

稀薄流是气体动力学的一个分支，处理在分子自由程与流场特征尺寸相当的情况下的气体流动。稀薄流发生在密度极低的情况下，例如真空系统或高空飞行，也发生在颗粒径较大的情况下，例如悬浮在大气中的极小颗粒。

无量纲数描述了稀薄程度。如果定义为平均自由程 `λ` 与流场特征尺寸 `L` 的比值大于某个值，则该流被认为是稀薄流。根据情况不同，`L` 可能很大（例如管道直径），也很小（例如波长、亚微级颗粒直径、高空火箭的长度，或边界层或激波的厚度）。平均自由程 `λ` 是分子在与其他分子碰撞之前移动的平均距离，它等于公式(6)定义的平均自由程，其中 `R` 是常数，`T` 是

# 气体与气田

“气田”（field gas）一词指的是由一个或多个油储层为主的地理区域。这种具有商业价值的气体主要是甲烷，含有少量的乙烷、丙烷、丁烷，有时含有二氧化碳、氢气和氮气杂质，当气体渗透由多孔岩石组成的地下储层时产生。储层中的气体可能是游离的，也可能是随油的。

美国约三分之一的气体产量来自没有油（仅有液态烃类）接触的储层。储层中的气体是非关联的。气体从气体与油有大量接触的储层中产生。油田（OIL AND GAS FIELD）；石油（PETROLEUM）；石油地质学（PETROLEUM GEOLOGY）；石油储层（PETROLEUM RESERVOIR）。[T.D.]。

# 气炉

气体炉内的封闭装置燃烧。家用供暖系统拥有气炉。有些气炉以产生水的气体为燃料。其他装置根据可用性使用气体作为加热或冷却的燃料。某些炉炉使用天然气、煤气高炉油燃料以及丙烷和丁烷等液化气。燃料：气体（GAS）；炉炉（FURNACE）；蒸汽发生炉（STEAM-GENERATING FURNACE）。[R.H.]。

# 气体温度计。温度测量法。

带有气体温度计的管。温度计法是在基本物理参数——温度在 3 K 到 900 K (-454 到 116 °F) 范围内测量信息的方法。

原则上，气体温度计利用理想气体状态公式(1)作为物质的属性。体积 n 是

```
PV = nRT (1)
```

的摩尔数，`R` 是气体常数，`T` 是热力学温度；参考开尔文热力学温度的理想定义——水的三点。水的三点在实验室实践中定义为精确的百分之一，其值为 273.16 K (0 C 或 32.18 °F)。确定温度需要对气体属性进行两次测量。一次测量是在气体处于水点温度时进行的；第二组是在三点温度下建立的。可以通过公式(1)通过 `n = (PV)/(RT)` 来评估温度，这几组属性具有相同的值。

等容气体温度计是最常用的气体温度计法。这个名称有时会被误解，因为没有气体气泡显示

```
T = \frac{PV}{nR} (2)
```
