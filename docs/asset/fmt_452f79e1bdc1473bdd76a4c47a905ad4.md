## SUSE LINUX 常见问题

本节提供了常见问题的解答。

### 1. 我是唯一使用这台电脑的人。为什么我总是需要登录？

Linux 是一个多用户系统。需要用户名和密码，以便 Linux 知道是谁在操作它。只有以 root 身份登录才能对系统进行更改（安装软件或更改配置）。日常使用时，请创建一个普通用户。这可以防止意外损坏安装。

### 2. 我在哪里可以找到 PDF 或 HTML 格式的 SUSE 手册？

我们的手册在 CD 中可用。PDF 文件或 HTML 版本位于 `suselinux-adminguide_en` 和 `suselinux-userguide_en` 包中。在已安装的系统中，进入目录 `/usr/share/doc/packages/suselinux-adminguide_en/` 或 `/usr/share/doc/packages/suselinux-userguide_en/`。

### 3. 我可以在哪里获取更多关于 SUSE LINUX 的信息？

关于 SUSE LINUX 安装和特性的大部分信息都在手册中。应用程序文档位于 `/usr/share/doc/packages/`，而 HowTos 位于 `/usr/share/doc/howto/en/`。可以使用命令读取这些文件：

```
less /usr/share/doc/howto/en/DOS-to-Linux-HOWTO.txt.gz
```

按 Q 退出命令。

### 4. 我可以在哪里获得特殊提示或帮助？

在 Konqueror 中，输入路径 `/usr/share/doc/sdb/en/html/index.html` 以查看我们的支持数据库，其中包含有用信息。如果此路径不存在，请安装 `sdb` 和 `sdb_en` 包。在互联网上，最新版本位于 http://sdb.suse.de/en/sdb/html/

### 5. 我该如何在 KDE 中输入命令？

点击面板中带有 shell 图标的屏幕以启动 Bash shell。从主菜单中选择备用终端。要运行单个命令，按 `Alt` + `F2` 然后输入命令。

### 6. 我在 KDE 中找不到许多程序。

你可以通过在终端窗口中输入程序名称并按 `Enter` 来启动所有程序。

### 7. 什么是镜像（mirror）？为什么我不应该从 ftp.suse.com 获取这些内容？

由于有许多用户同时需要从服务器获取内容，其容量很快就会达到限制。因此，还有许多包含 SUSE 服务器副本的 FTP 服务器。这些服务器被称为镜像。选择一个离你近（同一国家）的镜像以加速下载。镜像列表可以在 http://www.suse.de/en/support/download/ftp/ 找到。

### 8. 我找不到 .exe 文件。应用程序在哪里？

在 Linux 中，可执行文件通常没有文件扩展名。许多程序位于 `/usr/bin` 和 `/usr/X11R/bin`。

### 9. 我该如何识别可执行文件？

命令 `ls -l` 会以绿色返回 `/usr/bin/` 目录下的所有可执行文件。也可以通过第一列中的 x 来识别它们。

```
-rwxr-xr-x 1 root 64412 Jul 23 15:23 /usr/bin/ftp
```

### 10. 我想删除 Linux。这是如何操作的？

使用 `fdisk` 删除 Linux 分区。你可能需要在 Linux 中运行 `fdisk`。之后，从 MS-DOS 盘启动并在 DOS 或 Windows 中运行 `fdisk/MBR`。

### 11. 我如何访问我的 CD？

首先用 `mount` 命令挂载 CD。有关此命令的信息可以见第 397 页的 25.3.1 节。

### 12. 我无法将 CD 从驱动器中取出。我现在该怎么办？

首先，用 `mount` 命令卸载 CD。关于此点的更多信息可以见第 398 页的 25.3.1 节。在 KDE 中，只需右键点击 CD-ROM 图标并选择“卸载驱动器”（Unmount Drive）。如果你的电脑上正在运行 YaST，请退出。

### 13. 我如何查看 Linux 中的可用空间？

使用 `df -hT` 命令。

### 14. 我可以在 Linux 中复制和粘贴吗？

在终端窗口输入 `tail -f /var/log/messages`。以该用户创建一个普通用户。然后使用 `su` 切换到 root 用户。然而，使用 `ssh` 程序更安全。

### 15. 我需要担心 Linux 中的病毒吗？

在 Linux 中已经发现了一些病毒。如果不激活它们，病毒可能会造成严重损害。然而，你应该备份重要数据和配置。

### 16. 我需要自己编译内核吗？

不需要，这通常是不必要的。由于内核变得非常大，在配置时有数百种选项。强烈建议没有经验的用户不要这样做。SUSE 不对自定义编译内核提供任何支持。

### 17. 我可以在哪里查看系统消息？

在终端窗口输入 `tail -f /var/log/messages`。相关的有趣程序还有 `top`、`procinfo` 和 `xiew`。使用 `less /var/log/boot.msg` 查看启动消息。

### 18. 我无法通过 telnet 登录我的电脑。总是提示登录错误

你可能正在尝试以 root 身份登录。出于安全考虑，默认情况下是不可能的。使用 YaST 设置一个普通用户账户。用该用户登录。

### 19. 我如何在 Linux 中连接互联网？

第 154 页的 5.4.1 节提供了有关此的信息。

### 20. 我在 SUSE LINUX 中发现了一个错误。我应该向谁报告？

首先，确定这是否是程序本身的错误，还是操作错误或配置设置错误。还要阅读 `/usr/share/doc/packages/` 和 `/usr/share/doc/howto` 中的文档。该错误可能已经被发现。在支持数据库 http://sdb.suse.de/en/sdb/html/ 中检查。如果确实是错误，请电子邮件向 feedback@suse.de 发送描述。

### 23. 我的硬件受支持吗？

最好参考 http://hardwaredb.suse.de 或 http://cdb.suse.de 中的组件数据库。运行 `less /usr/share/doc/howto/en/Hardware-HOWTO.gz` 也可以提供一些信息。

### 24. 如何对硬盘进行碎片？

Linux 拥有智能文件系统。这种文件系统使得碎片整理变得多余，因为它防止了碎片的产生。你的分区使用率不应超过百分之九十。使用 `df -h` 查看已用和可用硬盘空间的信息。

### 25. 什么是分区？

分区是将硬盘划分为较小的区域。对于默认配置，SUSE LINUX 至少需要两个分区（一个用于 Linux 本身，一个用于虚拟内存的交换分区）。

### 26. Linux 需要多大的空间？

这取决于你想要安装多少个以及哪些软件包。带有办公应用程序的标准安装大约需要 1 GB。如果你还想为自己的数据留出空间，建议使用 2 GB。如果只是安装所有内容，根据版本不同需要 3–6 GB。

### 27. 我需要 Linux 需要更多空间。如何添加另一块硬盘？

为了提供更多空间，可以随时将新的硬盘或其部分（分区）集成到你的 Linux 系统中。例如，如果发现 `/opt` 需要更多空间，可以将一个额外的硬盘分区挂载到该目录。按照以下步骤操作：

- (a) 按照制造商的说明安装硬盘，然后启动 Linux。
- (b) 以 root 用户身份登录。
- (c) 使用 `fdisk` 对新硬盘进行分区。更多信息，请通过 `man fdisk` 参考 `fdisk` 的手册页。
- (d) 使用 `mke2fs /dev/hdb1` 格式分区。
- (e) 输入以下命令：

```
cd /opt
mkdir /opt2
mount /dev/hdb1 /opt2
cp -avx /opt2
```

彻底检查以查看所有数据是否已复制。
之后，移动旧目录并添加新目录——一个空挂载点：

```
mv /opt /opt.old
mdir /opt
```
