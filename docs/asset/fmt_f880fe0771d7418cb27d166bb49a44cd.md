# dis — 对象反汇编器

## 描述
`dis` 命令生成一个文件的汇装语言列表，列表包括汇装语句以及这些语句的八进制表示。

## 选项
选项由反汇编器解释。你可以按任何顺序指定。

+   `-C` 在反汇中显示解密 C++ 符号名
+   `-d sec` 反汇编命名节为数据，打印从节开始的偏移量。
+   `-D sec` 反汇编命名节为数据，打印数据的实际地址。
+   `-F function` 在每个用户指定的文件中指定的命名函数。你可以在命令行上多次指定 `-F` 选项。
+   `l string` 通过字符串反汇存档文件。例如，你就会命令 `dis -l x -l z` 来反汇 `libx.a` 和 `libz.a`，假设它们在 `LIB-DIR` 中。
+   `-L` 启动符号表中 C 语言标签的查找，供后续写入标准输出。
+   `-o` 以八进制打印数字。默认是十六进制。
+   `-t sec` 反汇编命名节为文本。
+   `-V` 在标准错误上打印正在执行的反汇编器版本号。

在控制跳转指令执行完相对位移后，计算出的地址是控制跳转到目标扇区内的地址。第一列显示函数名，如果对象文件包含符号表，则后面后跟 `()`。

### 操作数
`file` 对象文件或对象文件归档（参见 `ar(1)`）的路径名。

## 环境变量
参阅 `environ(5)` 以了解以下影响 `dis` 执行的环境变量描述：`LC_TYPE`、`LC_MESSAGES` 和 `NLPATH`。

`LIBDIR` 使用此路径来搜索库。如果该变量包含空值或未设置，则在 `/usr/lib` 下搜索库。

## 退出状态
- `0` 成功完成。
- `>` 发生发生错误。

## 文件
`/usr/lib` 默认的 `LIBDIR`。

## dos2unix — 将文本文件从 DOS 格式转换为 ISO 格式

### 概要
```
/usr/bin/dos2unix [-ascii][-iso] [-7] originalfile convertedfile
```

## 描述
`dos2unix` 将 DOS 扩展字符集中的字符转换为对应的 ISO 标准字符。

你可以从 DOS 或 SunOS 调用此命令。然而，文件名必须符合调用该命令时环境的规范。

如果 `originalfile` 和 `convertedfile` 是同一个文件，`dos2unix` 将转换后重写原文件。

## 选项
- `-ascii` 移除换行符并将 DOS 格式文本文件中的文件结束符转换为符合 SunOS 要求的格式。
- `-iso` 将 DOS 扩展字符集中的字符转换为对应的 ISO 标准字符（默认值）。
- `-7` 将 8 位 DOS 图形字符转换为 7 位字符。

## 属性
参阅 `attributes(5)` 以了解以下属性的描述：

| 属性类型 | 属性值 |
| --- | --- |
| 可用性 | SUNW |

## 参见
`unix2(1)`, `attributes(5)`

## download — 下载主机本地 PostScript 字体

### 概要
`/usr/bin/lp/postscript/download [-f][-p printer] [-m name] [-H directory][file...]`
`/usr/bin/bin/download`

## 描述
`download` 将主机本地字体添加到标准输出中。如果未指定文件，则使用默认字体。文件应该由 `stoff` 准备好。`eqn` 和 `pic` 预处理器在使用 `troff` 之前需要知道分辨率。如果是你的系统中安装的版本，请对 `eqn` 使用 `-r720` 选项，对 `pic` 使用 `-t720`。`dpost` 不假设任何分辨率。`x res` 命令设置了使用的分辨率。PostScript 头部负责设置适当的坐标系。输出`/lib/font/devpost/DESC.out` 定义了二进制字体文件中使用的分辨率。通过 `postreverse(1)` 处理 `dpost` 的输出应产生一个最小标准的 PostScript 文件。虽然 `dpost` 可以处理为任何设备格式化的字体，但仿真是昂贵的，并且会增加打印时间和输出大小。尚未尝试实现 `stoff` 支持的所有设备的字符集或字体。缺失的字符被空格替换，无法识别的字体通常默认为 Times 字体（即 R、I, B 或 BI）。`x res` 命令必须在第一个 `x init` 命令之前调用，且输入文件应该为相同的输出设备准备好。注意 — 使用 `-T` 选项是不建议的。其唯一目的是允许使用其他 PostScript 字体和设备描述文件，它们可能使用了不同的分辨率、字符集或字体。

## 选项
- `-f` 强制扫描每个。
- `-p printer` 检查列表。
- `-m name` 使用名称。
- `-H directory` 使用目录。

## 示例
通过执行以下命令，你可以下载字体：

```
castle% download -m myprinter
```
