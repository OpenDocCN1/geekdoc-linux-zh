
> 注意：如果你使用 `csh`，环境变量会自动在 `csh` 变量之间进行复制。这些包括 `HOME`、`TERM` 和 `PATH`，`csh` 将它们分别保存在 `home`、`term` 和 `path` 变量中。

你只需要给它赋一个值，就可以创建一个新的环境变量。如果你给一个现有变量赋值，旧值会被覆盖。设置环境变量的一个困难点在于它们依赖于你正在使用的 shell。要了解如何设置环境变量，请查看第二部分中关于你正在使用的 shell 的详细信息。

为了让你的 shell 能够正确显示输出，环境变量 `TERM` 需要有一个合理的值。这个变量名源于终端用作显示器的时代（在 PC 和图形显示器普及之前）。不同的终端支持不同的输出控制。UNIX 系统有许多它们所支持的终端类型。这些类型并不是标准的，因此你需要从你的支持人员处了解应该使用哪种终端类型。如果你使用 PC 连接到 UNIX 系统，你正在运行终端模拟器模式。这些工具具有模拟多种类型终端的能力。重要点是确保你的模拟器和你的 `TERM` 变量相同（或兼容）。首先通过输入 `echo $TERM` 查看你的 `TERM` 变量设置 own什么。参考你的终端模拟器手册并向你的系统管理员寻求以确保设置正确。

> 提示：许多终端模拟器（包括微软 Windows“终端”程序）支持“VT100”或 ANSI 标准终端控制序列。对于这类终端模拟器，尝试将 `TERM` 设置为 `vt100` 或 `ansi`。

## 使用 Shell 启动文件

环境变量来自哪里？系统为你设置了各种环境变量。而且在登录过程中，通常还会使用其他变量。你可能在不知情的情况下就在这样做。登录时发生的启动过程会被触发。这个 shell 会自动在的一两个特殊位置查找启动信息。这些位置中的一个就在你的家目录中。家目录中的启动信息存储在特殊文件中。你使用的具体文件取决于该文件的命名。当 shell 启动时，它会检查此文件并执行所有指定的动作。常见的动作之一是给环境变量赋值。这种动作被称为初始化或设置变量。

在用户的 shell 启动文件中经常设置的一个环境变量是 `PATH` 变量（或小写的 `path`），shell 应该在系统中的该变量处查找命令的位置。你输入的每个命令在物理上都是你系统上的一个文件。同一个命令名可能位于不同的地方（并在执行时可能具有相同或不同的行为）。假设你有一个名为 `my_program` 的程序存储在你的家目录下，而你在提示符处有一个名为 `my_program` 的程序。shell 需要知道在哪里找到 `my_program` 的存储位置。shell 查看 `PATH` 变量中的目录，并将列表作为有序的目录搜索列表。第一个包含 `my_program` 的目录将停止搜索，并由 shell 执行。由于单个目录内的所有文件必须是唯一的，这为寻找可执行文件（命令）提供了一种直接且且的方法。

你希望 `$HOME` 位于 `PATH` 目录列表的开头，而你可能希望你朋友的二进制目录放在最后，或者完全不列出。这样当你输入 `my_program` 时，执行的是你的程序而不是对方的。在 shell 启动文件中，除了设置环境变量外，你还可以进行各种类型的操作。如果你愿意，可以添加一个 `echo` 命令来打印一条问候语或提醒你做某些事。shell 启动文件中配置的一个项目是你的字符设置（见本章的“在系统上工作”部分）。这些启动文件对于你这个 shell 用户来说是强大的工具，可以自动控制 shell 的行为。shell 启动文件在第二部分“寻找 Shell”中会有更详细的介绍。

> 提示：在你的 HOME 中创建一个 `bin` 目录并存储可执行文件是一个好主。将 `$HOME/bin` 包含在路径中。

## 使用 rc 文件配置

启动时读取文件的想法不仅用于 shell。事实上，许多程序都有包含用户可以修改的信息的特殊文件。根据这些文件的命名惯例，大多数此类文件被称为 `rc` 文件。这些文件以字母 `rc` 结尾。一些常见的文件包括 `.xrc`、`.mailrc` 和 `.cshrc`。这些都是“点文件”，即以点（`.`）开头。以点开头的意义是它们在普通的目录列表运行时不会显示。如果你想看到这些文件，请使用 `ls -a`。`.xrc` 用于 vi 编辑器（Unix 版）。`.mailrc` 用于邮件。`.cshrc` 用于 `csh`。

## 管理你的密码

登录期间，系统会提示输入密码。如果你忘记了，可以使用 `passwd` 命令进行更改。这里有一些需要考虑的点：

- 它应该是容易记忆的。
- 它应该包含至少一个非字母字符。
- 长度应该是合理的。
- 定期更改它。
- 不要把它写下来。

当你考虑好想要什么密码后，可以更改它。输入 `passwd`。首先会提示你输入密码。输入你的旧密码并按回车。接下来，会提示你输入新密码。最后的确认有助于避免在打字错误时更改密码。如果两次密码输入不一致，则不会进行更改。旧密码仍然有效。

## 在系统上工作

键盘上的大多数键都很直观。如果你按下 `S`，屏幕上会出现一个字符。如果你按住 `Shift` 再按 `S` ，屏幕上会出现一个大写的 S (S)。除了字母和数字，还有符号，例如百分号 (%) 和逗号 (,)。还有一些 UNIX 和系统特定的字符需要定义，你应该熟悉它们。它们可以帮助你更有效地管理工作和打字。这类字符通被称为控制字符。这个名称源于使用它们的方式。首先找到 Control 键——你的键盘上应该有一个或多个。它可能标记为 Ctrl 或 Control 的某种缩写。这个键用法类似于 Shift 键。你按下它但不要松开。在按下 Control 键的同时，输入另一个键，通常是字母表中的字母。如果你在按住 Control 键时按下 Q 键，被称为 Control+Q，通常写为 `^Q`（脱字符符号位于数字 6 上方，后面跟着字母）。

> 注意：当你看到 `^Q` 时，并不意味着要同时按住 Control 和 Shift 再按 Q。你只需要按住 Control 键并按下 Q 即可。

UNIX 使用这些控制键来执行各种键盘操作。它们可能非常有用。困难的之处在于，不同系统对这些操作的默认 Control（控制）键设置不同。因此，你首先应该查出你当前的设置，然后根据需要进行更改。要查看你当前的设置，请使用 `stty` 命令。在命令提示符处输入 `stty -a` 并查看结果。请参考下一个该命令的输出示例。

```
$ stty -a
speed 28800 baud; line = 0; susp <undef>; dsusp <undef>
rows = 44; columns = 120
intr = ^C; quit = ^\; erase = ^H; kill = ^X; switch <undef>
eof = ^D; eol = ^M; time = 0; stop = ^S; start = ^Q
-parennb -parenn cs8 -cstop -hputcl -clclial -lolbrcs
-ignbrk inlr -ignar -parmark -inpelf -itrip -inlncr icrnl -iuclc
ixon -ixof -iof -ctxon -iengak
ig ican ieocten -xcaseo echo echoe -echolon -noflsh
opost -olcul onrner -oncrl -ofill -ofdel -topost tab 3
```

参考上述 `stty` 输出示例，查找包含 `erase` 和 `eof` 单词的章节。每个单词都对应一个字符键。找到你 `stty` 输出中的对应部分。在阅读后续主题时请记住它。

## Erase（删除键）

查看 `stty` 输出中的 `erase`。在我的系统中，该词对应的是 `^H`（读作 Control+H），这意味着通过输入 `^H` 可以退格删除上一次输入的字符。`erase` 是你修正错误的方法。请查看你的 `stty -a` 输出，因为你的系统配置可能与此示例不同。在你的系统上尝试一下。首先，输入一个想要删除的字符，例如 A。尝试使用你的 Control、Backspace（退格）或 Delete（删除）键来配合 Erase 功能。如果一切正常，你的光标应该退格到 A 上方，而你下一个想要的键应该是 B。输入一组正确的键序列，例如 `<Return>`，确保该字符确实生效了。如果你收到类似 "A^Hdate found" 的消息，说明 Erase 不起作用。要让它生效，选择你与 Erase 关联的键，并插入（以下内容代表你所选择的退格键）：

```
$ stty '^H'
$
```

现在，尝试输入数据命令并删除 `dA` 中的 `d`，将其替换为 `a`。

> 注意：根据你显示器的不同，删除字符可能不会真的让字符消失。相反，它可能会重新定位光标，以便下一次按键覆盖这些字符。

Erase 键是最常用的控制键之一，因为输入本身很困难。因此，键盘上有一个或多个适用于这项工作的特殊键。寻找标记为 "Delete" 或 "Backspace" 的键。其中通常一个作为删除键使用。尝试输入字符并观察按下 Backspace 或 Delete 时会发生什么。通常 Backspace 键被设置为 `^H`，所以，如果你的 erase 配置为 `^H`，那么 Backspace 应该会工作。

## Kill（杀死键）

Kill 控制字符与 Erase 字符类似，因为它允许你退回输入错误。Erase 是一次删除一个字符，而 Kill 则会一直退格到提示符处。因此，如果你正在输入一个非常长的命令，并在快结束时发现忘记先执行某个其他命令，可以通过输入与 Kill 关联的控制字符来重新开始。如果你看不到你的 Kill 设置为何什么，请重新执行 `stty` 命令。记住你的系统配置可能与此输出不同。现在，尝试输入几个字符后跟上你的 Kill 控制字符，看看会发生什么。所有字符都将被删除，你的光标将回到提示符。

## Stop and Start（停止与开始）

两个常用的字符是 Stop 和 Start。它们的正常值分别为 `^S` 和 `^Q`。Stop 允许你暂停屏幕上正在发生的情况，而 Start 允许在停止后恢复活动。如果文本正在你的屏幕上滚动供你阅读，这非常有用。Stop 控制字符将无限暂停滚动，这样你可以从心阅读。你可以在下次登录时尝试这样做，当时“今日消息”（Message of the Day）正在滚动显示（参见本章较前的“登录”部分）。记住要做好准备并保持迅速，因为那些文本滚动得非常快。要停止滚动，别忘记输入你的 Start 控制字符来继续滚动。

> 注意：在普通的 GUI 和高高速连接下，Stop 和 Start 对输出的控制非常差。这是因为输出速度太快，在你输入 Stop 字符之前，整个屏幕可能已经刷过去了。

## eof

eof 控制字符用于信号输入的结束。`eof` 字母源于 end of file（文件末尾）。eof 控制字符的正常值是 `^D`，但务必使用 `stty` 命令验证这一点。你可以在本章较前的“重定向输入和输出”部分看到 `eof` 是如何使用的。

这里我们不会介绍另外几个控制字符。你应该查阅你系统文档中的 `stty` 命令来获取信息。或者更好，阅读这里将向你展示如何在 UNIX 帮助中查找有关命令的信息。

## Online Help（在线帮助）

最重要的事情之一就是如何获取帮助。`man` 命令对于不熟悉 UNIX 的用户非常有非常有选项：该选项是 `-k`，用于查找所有与……相关的命令。例如，如果你想找到关于打印的信息，可以输入 `man -k`。`man` 命令会在一个特殊的数据库（即 whatis 数据库）中搜索包含该单词的命令和描述。在搜索期间，如果发现了任何包含 print（如 printing），它将显示在你的屏幕上。结果是所有与 print 相关的命令列表。你可以使用 `man` 命令查找其中任何或所有命令的详情。由于整套 man 条目完全在线，它占据了大量的磁盘空间。有些人使用的减少磁盘空间需求的选项是将 man 条目存储在所有人可以通过网络访问的机器上。由于这种情况，man 条目可能并不存储在预期的目录中。为了让 man 命令显示条目存储的位置，你可以设置 `MANPATH` 变量（参见本章较前的“设置和查看环境变量”部分）。

## UNIX 手册页

每个 UNIX 系统都带有一套打印文档。大多数 UNIX 系统管理员都会配置他们的系统，让其用户可以使用这些信息。它们通常被称为“man pages（手册页）”，因为它们通过 `man` 命令访问。本节将在稍后部分讨论 `man` 命令。如果你的系统上没有手册页，请咨询你的系统管理员。

## 手册页结构

手册页分为八部分。它们的组织方式如下：

- 1. **Commands（命令）** 此部分提供有关用户级命令的信息，如 `ps` 和 `ls`。
- 2. **UNIX System Calls（UNIX 系统调用）** 此部分提供与 UNIX 操作系统接口的库调用，例如打开文件和执行程序文件。这些通常由 C 程序员访问。
- 3. **Libraries（库）** 此部分包含随系统运行的库程序。每个系统附带的一个示例库是数学库（math library），包含诸如绝对值的 `fabs` 等函数。与系统调用部分一样，这与程序员有关。
- 4. **File Formats（文件格式）** 此部分包含有关系统文件格式的信息，如 `init`、`group` 和 `passwd`。这对于系统管理员很有用。
- 5. **File Formats（文件格式）** 此部分包含各种系统特性的信息。例如，这里有一个手册页用于显示完整的 ASCII 字符集（`ascii`）。
- 6. **Games（游戏）** 此部分通常包含随系统自带游戏的说明。
- 7. **Device Drivers（设备驱动）** 此部分包含有关 UNIX 设备驱动的信息，如 `scsi` 和 `floppy`。这些通常与实现设备驱动以及系统管理员有关。
- 8. **System Maintenance（系统维护）** 此部分包含对系统管理员有用的命令信息，例如如何格式化磁盘。

起初，知道要搜索哪个部分可能会令人困惑。然而，经过一些练习，你应该能够识别出适当的部分。事实上，某些 `man` 页选项允许你在进行搜索时跨越多个部分。

## man 命令

`man` 命令允许你通过指定关键词在在线手册中查找信息。你可以通过以下方式使用它：

- -k 列出所有单行摘要中包含关键词的条目。
- -m 根据指定的关键词显示所有单行描述。
- -f 显示指定关键词的完整手册页条目。
- -n [章节号] 仅在下述指定的章节内搜索指定的关键词。

调用 `man` 命令最简单的方法是在不带任何选项的情况下指定关键词。例如，如果你想获得更多关于 `finger` 命令的信息，请执行 `man finger`。在运行 HP-UX 版本 UNIX 的 HP 系统上，你的输出显示如下：
