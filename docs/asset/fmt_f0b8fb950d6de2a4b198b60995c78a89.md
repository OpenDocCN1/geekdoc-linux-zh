
# OpenVPN 服务器配置

``` 
port 1194

proto udp

dev tun

ca /etc/openvpn/easy-rsa/keys/ca.crt

cert /etc/openvpn/easy-rsa/keys/server.crt

key /etc/openvpn/easy-rsa/keys/server.key

dh /etc/openvpn/easy-rsa/keys/dh2048.pem

server 10.8.0.0 255.255.255.0
```

``` 
ifconfig-pool-persist ipp.txt

push "redirect-option-gateway def1 bypass-dhcp"

push "dhcp-option DNS 8.8.8.8"

push "dhcp-option DNS 8.8.4.4"

keepalive 10 120

cipher AES-256-CBC

comp-lzo

user nobody

group nogroup

persist-key

persist-tun

status openvpn-status.log

verb 3
```

上述配置用于在端口 `1194` 上使用 `UDP` 协议的基础 OpenVPN 服务器，带有 `TUN` 设备和 `AES-256-CBC` 加密。请注意这是一个基础示例，你可能需要根据需求自定义设置。

## 安全 VPN 连接

- 启用端口转发：端口转发可以帮助确保传入的 VPN 流量引导至正确的服务器。您可以在路由器或防火墙上启用端口转发。
- 启用 VPN 杀手开关（Kill Switch）：VPN 杀手开关项功能，当 VPN 连接丢失时会自动断开设备与互联网的连接。这有助于防止设备意外连接到不安全的网络。
- 启用 DNS 泄露保护：DNS 泄露保护可以帮助防止设备意外向 VPN 隧道之外发送 DNS 请求。这有助于保护您的隐私并防止位置泄露。
- 保持 OpenVPN 服务器为最新版本：OpenVPN 发布更新以修复漏洞并添加新功能。保持 OpenVPN 服务器软件为最新版本对于防止新的安全威胁并确保软件运行运行至关重要。
- 确保服务器和客户端更新最新的安全补丁：保持服务器和客户端使用最新的安全补丁是确保 VPN 连接安全的重要方面。这有助于防止各种漏洞和其他安全威胁。
- 定期监控 VPN 服务器日志：定期监控 VPN 服务器日志有助于检测任何可疑活动或未经授权的访问尝试。

## 管理 VPN 用户账户

管理 VPN 用户账户是安全和维护 VPN 服务器的重要方面。以下是关于如何详细管理 VPN 用户账户的逐步指南：

- 创建用户账户：管理 VPN 用户账户的第一步是创建账户。可以使用命令行或基于 Web 的界面完成。例如，使用命令行创建用户账户，可以使用命令 `sudo add <username>`。
- 分配用户权限：创建用户账户后，您需要为每个用户分配适当的权限。这可以通过创建不同的组并将用户分配到这些组来实现。例如，您可以为管理员创建一个组，为普通用户创建一个组，为访客创建一个组。
- 创建并分发客户端证书：为了验证 VPN 客户端，您需要创建并分发客户端证书。这可以使用 `openvpn-pki` 工具完成。例如，要创建客户端证书，可以使用命令：

```
sudo openvpn-pki --gen-req --days 3650 <clientname>
```
