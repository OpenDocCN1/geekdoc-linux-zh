
# 空间的算术化

空间的算术化导致了 `n` 维空间（欧几里得空间和其他空间）的纯数学创造，对于任意整数维度 `n`，通过将其点一般地定义为实数的 `n` 元组 `(x¹, …, xⁿ)` 并给出这些点之间各种几何关系的适当定义。这种应用中最著名的是相对论理论中的四维空间，但事实上，多维几何在此之前已经在物理学中发挥作用。如果一个力学系统涉及 `M` 个质点，实际上习惯于引入维度为 `n = 3M` 的空间，其点是系统的状态，即任意时刻点处的坐标 `n` 元组 `{x_m¹, x_m², x_m³}`，其中 `m = 1, …, M`。此外，如果系统中存在约束，则拉格朗日-哈密顿理论通过使用系统的自由参数而不是原始的 `n` 个坐标本身，实质上减少了空间的维度。自由参数的使用从力学系统扩展到了物理学和化学中的其他系统，所有所谓的状态方程都以此为依托。最后，在量子理论中，系统的状态具有无限多个坐标，表示它的无限维空间是一个希尔伯特空间。也部分受希尔伯特空间的影响，数学家们对一般意义上的无限维空间产生了浓厚的兴趣。它们正在被深入研究，数学的很大一部分正被纳入这些新的参考框架中。

空间的算术化也反映在图表使用的不断扩展中。参见 `代数`；`向量微积分`；`几何学`；`拓扑学`。

## 基质隔离

一种使分子在低温下保持以供光谱研究的技术。该方法特别适用于在固体惰性环境中保存反应性物种。难以捉摸的分子碎片，如作为控制反应中化学转化重要工业中间体的假设自由基、在极高温度下与固体处于平衡的高温分子，以及在等离子体放电或高能辐射中产生的分子离子，都可以通过吸收（红外、可见光和紫外）、电子-核共振以及激光光谱技术进行检查。

基质隔离实验的实验装置在设计时考虑了分子瞬态的产生方法和进行光谱分析的方法。插图显示了用于吸收光谱测量的真空容器的横截面。基质样品通过喷涂线引入；氩是最广泛使用的基质气体，尽管氖、氪、氙和氮气也被使用。反应性物种可以通过多种方式产生：通过石英窗口对被困的前驱体分子进行汞蒸气光解；从加热器中的克努森细胞中蒸发；从克努森细胞中蒸发的原子与通过喷涂线沉积的分子发生化学反应；以及来自通过管子流动的放电激发原子的辐射对沉积在喷涂线上的分子进行真空紫外光解。对于激光激发研究，样品沉积在一个倾斜的铜楔上，该铜楔被激光束掠过，然后由摄谱仪检查以大约 90° 发射或散射的光。在电子自旋共振研究中，样品被限制在一根蓝宝石杆内，该杆可以放入必要的波导管和磁体中。

## 矩阵理论

研究矩阵及其性质，以及可以用矩阵表示的向量空间上的线性变换。

矩阵是一个数字的矩形阵列，出现在矩阵中的数字被称为元素。例如，由方程 `(1)` 给出的 `A` 是一个 `2 × 3` 矩阵；也就是说，它有 `2` 行和 `3` 列。矩阵第 `$i$` 行第 `$j$` 列的元素由 `$a_{ij}$` 表示。例如，在矩阵 `$A$` 中，`$a_{12}$` 是 `4`，`$a_{12}$` 是 `2`。（注：原文此处 `$a_{12}$` 重复且数值描述可能存在笔误，译文忠实于原文字面意思）

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_0.png)

一般情况下，如果 `$X$` 是一个 `$m×n$` 矩阵，`$Y$` 是一个 `$n×q$` 矩阵，那么乘积 `$P=XY$` 是一个 `$m×q$` 矩阵，其第 `$i$` 行第 `$j$` 列的元素由方程 `(2)` 给出，其中 `$i=1,⋯,m$` 且 `$j=1,⋯,q$`。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_1.png)

为了定义乘积矩阵 `$P$`，`$X$` 的列数必须与 `$Y$` 的行数相同。一般情况下，`$XY$` 和 `$YX$` 不必是相同的矩阵；也就是说，矩阵乘法不一定满足交换律。矩阵 `$X$` 乘以一个 `$n×n$` 矩阵（该矩阵在第 `$i$` 行第 `$i$` 列为 `1`，其中 `$i=1,⋯,n$`，其余位置为 `0`），不会改变矩阵 `$X$`。最后，两个矩阵的乘积的所有元素都可以是 `0`，而其中一个因子并不满足这种情况。

平面中的向量可以相加，并可以由常数乘法（缩放）。例如，如果向量 `$u$` 和 `$v$` 以及数字 `$c$` 由方程 `(3)` 给出，则 `$u+v$` 由方程 `(4)` 给出，`$c=u$`（注：原文如此，可能是 `$cu$`）由方程 `(5)` 给出。

存在许多由向量加法和标量乘法满足的简单公理。一组向量 `$V$` 与满足这些规则的一组数字 `$F$` 一起被称为 `$F$` 上的向量空间。数字集合 `$F$` 是一个域。这意味着 `$F$` 具有许多与有理数（分数）、实数（小数）或复数相关联的性质。有许多重要的数学系统满足向量空间的公理。一些例子包括平面几何的二维空间、立体几何的三维空间，以及系数取自 `$F$` 的多项式。参见 `域论（数学）`；`线性代数`。

如果 `$V$` 和 `$W$` 是 `$F$` 上的向量空间，则从 `$V$` 到 `$W$` 的线性变换 `$T$` 是一个函数，它将 `$V$` 中的每个向量 `$u$` 分配给 `$W$` 中唯一的向量 `$w$`，如方程 `(6)` 所示。此外，如果 `$u$` 和 `$v$` 是

`$V$` 中的任意向量，`$c$` 和 `$d$` 是 `$F$` 中的任意标量，则 `$T$` 满足方程 `(7)`。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_5.png)

向量空间 `$V$` 的基是 `$V$` 中向量 `$v_1,⋯,v_n$` 的一个有序序列，使得 `$V$` 中的任何向量 `$u$` 只能以方程 `(8)` 的方式唯一写出（对于适当的标量 `$c_1,⋯,c_n$`）。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_6.png)

一旦分别选定了 `$V$` 和 `$W$` 的基 `$v_1,⋯,v_n$` 和 `$w_1,⋯,w_m$`，从 `$V$` 到 `$W$` 的任何线性变换 `$T$` 都可以由方程 `(9)` 在 `$m×n$` 矩阵 `$A$` 的元素方面完整且唯一地描述。换句话说，每个 `$Tv_i$` 作为

`$W$` 中的向量，可以唯一地表示为基 `$w_1,⋯,w_m$` 的标量倍数之和。标量 `$a_{1i},⋯,a_{ni}$` 是 `$A$` 第 `$j$` 列的元素。这一观察结果是根本性的，因为它表明线性变换的研究与矩阵的研究范围一致。

关于线性变换有许多重要的问题已经被广泛研究。特别是：

- 1. 给定 `$W$` 中的 `$u$`，确定 `$V$` 中所有满足 `$T$` 方程 `(10)` 的向量 `$v$`（如果存在）的问题。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_8.png)

- 2. 如果 `$V=W$`，确定满足 `$T$` 方程 `(11)` 的所有标量 `$\lambda$` 和非零向量 `$u$` 的问题。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_9.png)

当 `$v$` 在 `$V$` 上变化时，所有获得的向量 `$Tv$` 的集合称为 `$T$` 的像（范围）。`$T$` 的像总是一个向量空间。因此，上述第一个问题等同于确定线性变换 `$T$` 的像。一旦选定了 `$V$` 和 `$W$` 的基，可以看出方程 `(10)` 等价于求解方程 `(12)` 形式的线性方程组以确定数字 `$x_1,⋯,x_n$`。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1348_10.png)

寻找满足方程 `(11)` 的数字 `$a$`（原文如此，通常指 `$\lambda$`）和向量 `$u$` 被称为特征值问题；方程 `(11)` 中的数字 `$\lambda$` 被称为 `$T$` 的特征值，而方程 `(11)` 中对应的向量 `$u$` 被称为 `$T$` 的特征向量。方程 `(11)` 导致一个类似方程 `(12)` 的方程组，但 `$m=n$` 且每个 `$b_i$` 必须被替换为 `$\lambda x_i$`，其中 `$i=1,⋯,n$`。此外，特征值 `$\lambda$` 和 `$x_1,⋯,x_n$` 都必须确定。由于方程 `(10)` 和 `(11)` 在应用数学许多领域的重要性，已经开发出了处理它们的专用计算机程序。参见 `本征函数`；`本征值（量子力学）`。
