# 它们从哪里来？

我不认为媒体和评论人士指出 FOSS（开源软件）中存在漏洞。当他们指出时，暗示这是 FOSS 的问题，而不仅仅是闭源。

开源（以及部分自由软件）的区别在于，代码暴露给许多人，并且在问题发生时可以进行补丁。闭源代码（或使用开源组件的代码）无法由生产闭源产品的公司进行修改以获取补丁，因此闭源公司实际上在为该软件生产产品。

媒体和评论人士正在暗示这些是“开源”问题，事实并非如此。

让我们保持诚实。
