为编译准备 Kmod：

```
./configure --prefix=/usr \
--bindir=/bin \
--sysconfdir=/etc \
--with-rootlibdir=/lib \

```

配置选项（configure options）的含义：

- `--with-xz`, `--with-zlib`: 这些选项允许 Kmod 处理压缩的内核模块。

```
make
```

该软件包未附带可以在 L chroot 环境下运行的测试套件。至少少需要 `git` 程序，且有若干测试在 git 仓库外无法运行。
