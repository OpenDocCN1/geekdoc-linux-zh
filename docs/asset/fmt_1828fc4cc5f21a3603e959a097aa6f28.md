### 格式化输出

Linux 提供了多个工具来格式化文件内容或另一命令的输出。这些命令是 `coreutils` 软件包的一部分，该软件包在 Linux 发行版中默认安装。表 5.18 展示了一些常用命令及其描述：

| 命令 | 描述 |
| :--- | :--- |
| `nl` | 为文件的行编号 |
| `sort` | 对文本文件的行进行排序 |
| `tac` | 以反序显示指定文件 |
| `tr` | 转换或删除字符 |
| `sed` | 过滤和转换文本 |
| `rev` | 逐字符反转行 |
| `wc` | 统计单词和行数 |
| `fmt` | 简单的最优文本格式化程序 |
| `uniq` | 省略或报告重复行 |
| `join` | 基于公共字段连接两个文件的行 |
| `paste` | 合并文件的行 |
| `shuf` | 生成随机排列 |
