# 函数

使用函数关键字 `function` 来定义函数。别名在函数被读取并存储在内部时会被解析。函数像命令一样执行，参数作为位置参数传递。

函数在调用者的相同进程中执行，并与函数共享所有文件和当前工作目录。调用者捕获的陷阱（traps）在函数内部会被重置为默认操作。未捕获或忽略的陷阱条件将终止函数并将条件传递给调用者。

# 函数定义命令

函数是一个自定义名称，用作简单命令。函数定义的格式如下：

```
fname()[io-redirect...]
```

函数定义由两个运算符组成：`()`。因此，在 `fname` 和 `)` 之间混合空白字符是允许但不必要的。实现为函数和变量维护了独立的命名空间。

当你声明函数时，对复合命令或 `io-redirect` 的文本不进行扩展；每次调用函数时都会执行扩展。同样，`io-redirect` 重定向和复合命令内的任何变量赋值是在函数执行期间执行的。

执行函数时，它具有内置命令描述的语法错误和变量赋值属性。当指定为简单命令时执行复合命令。操作数作为位置参数传递给函数。

调用函数时，它有自己的命名空间。复合命令执行期间的位置参数以及特殊参数 `#` 变为反映操作数。特殊参数 `i` 保持不变。函数完成后，位置参数和特殊参数 `#` 将恢复到执行函数之前的值。如果在复合命令中执行了特殊内置命令 `return`，函数将完成并从调用后的下一个命令继续。

函数定义的退出状态如果定义成功则为 0，否则大于 0。函数调用的退出状态是函数中执行的最后一个命令的退出状态。

以下示例展示了如何在允许简单命令的地方使用函数定义：

```
# 如果变量 i 等于 "yes"，
# 定义函数 foo 输出 -1
#
[$i = yes] && foo() {
ls -1
}
```

# 特殊命令

以下简单命令在 shell 进程中执行。允许输入/输出重定向。另有说明的情况下，输出写入文件描述符 1，如果没有语法错误，退出状态为 0。

以一个或两个星号 `*` 为前的命令将以以下方式进行特殊处理：

- 命令前的变量赋值列表在命令完成后仍然有效。
- I/O 重定向在变量赋值之后处理。
- 包含它们的错误的脚本将终止。

- 跟随在带有 `**` 命令后的单词，如果其格式为变量赋值，则将按照与变量赋值相同的规则进行扩展。这意味着会在等号后执行波号替换，且不执行单词拆分和文件名生成。

- `* [arg...]`
  仅扩展参数。

- `* file [arg...]`
  读取整个文件，然后执行命令。在当前 shell 环境中执行命令。使用 `PATH` 指定的路径查找包含该文件的目录。如果你指定了任何参数，它们将成为位置参数。否则，位置参数保持不变。退出状态为上一个执行的命令的状态。

- `*** alias [-tx] [name=value]...`
  带有参数时，以 `name=value` 的形式在标准输出上打印别名列表。为每个给定的值的名称定义一个别名。值末尾的空格会检查下一个单词是否进行别名替换。使用 `-t` 选项设置并列出别名。被跟踪的别名的值对应给定名称的完整名称。当名称被重置时，值变为未定义，但别名仍被跟踪。在不使用 `-t` 选项的情况下，对于别名的每个名称和值，使用 `-x` 选项进行设置或通过名称调用。如果指定了一个名称但未为该名称定义别名，则退出状态为非零。

```bash
bg [%#job...]
```
仅支持作业控制的系统。将每个作业放入后台。如果你未指定作业，则将当前作业放入后台。请参见第 599 页的“作业控制”获取作业格式的描述。

- `* break [n]`
  退出被包含的 for、while、until 或 select 循环（如果有）。如果你指定了 `n`，则跳出 `n` 级。

- `* continue [n]`
  继续被包含的 for、while、until 或 select 循环的下次迭代。如果你指定了 `n`，则从第 `n` 个包含的循环处恢复。
