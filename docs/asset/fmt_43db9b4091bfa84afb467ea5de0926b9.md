## uptime — 显示系统运行时间

### 概要

`/usr/bin/uptime`

## 描述

`uptime` 命令打印当前时间、系统运行时长，以及过去 1、5 和 15 分钟运行队列中的平均作业数。本质上讲，它是 `w(1)` 命令的第一行。

> 注意 — 你可以使用 `who -b` 命令显示系统上次启动的时间。

## 示例

以下示例显示了 `uptime` 的输出。

```
castle$ uptime

10:47am up 27 day(s), 50 mins, 1 user, load average: 0.18, 0.26, 0.20

castle$
```
