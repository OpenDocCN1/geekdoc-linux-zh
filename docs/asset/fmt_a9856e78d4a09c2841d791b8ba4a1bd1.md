
## 描述

`postmd` 过滤器从文件中读取一系列浮点数，将其转换为 `postmd` 图像，并将结果写入标准输出。在典型应用中，数字可能是按行优先顺序写的矩阵元素。如果你未指定文件或 `-` 是文件之一，则读取标准输入。

### 注意事项

可以的最大矩阵取决于区间和灰色列表、打印机分辨率以及纸张大小。对于使用 300 dpi 打印机在 8.5x11 英寸纸张上的双元素区间列表（即五个区域），600x600 的矩阵是一个乐观的上限。
不建议在灰色列表中使用白色（即 255）。它不会显示在 `postmd` 在图像下方显示的图例和柱状图中。

### 选项

- `-b num` 使用 `num` 字节模式打包输出文件中的位掩。值 0 关闭输出文件的所有打包。默认情况下，`num` 为 6。
- `-c num` 每页打印 `num` 份。默认情况下只打印一份。
- `-d dimen` 将所有文件的矩阵维度设置为 `dimen`。你可以以行或乘以列的形式给出 `dimen` 字符串。如果你省略了列，则将其设置为行。默认情况下，`postmd` 假设每个矩阵都是正方形，并将行和列数设置为每个输入文件元素数量的平方根。
- `-g list` 使用 `list`（一个 0 到 255 之间的整数逗号或空格分隔字符串）为 `-i` 选项选择的实线区域分配 PostScript 灰色。255 对应白色，0对应黑色。`postmd` 过滤器分配一种默认灰色，不包含白色（即 255），并随着区域沿实线从左向右移动而变得越来越深。
- `-i list` 使用由逗号、空格或斜杠（`/`）分隔的 N 个浮点数，将实线划分为 2N+1 个区域。请按数值从到到大的顺序指定该列表。这些分界点用于将从输入文件中读取的浮点数映射为灰度整数，这些整数由 `postmd` 自动分配，或通过使用 `-g` 选项任意选择。默认列表为 `-1, 0, 1`，它将实线划分为七个区域。
- `-m num` 按因子 `num` 放大每个逻辑页面。围绕原点进行等比例缩放，原点默认位于每个页面的中心。默认放大倍数为 1。
- `-n num` 在每张纸上打印 `num` 个逻辑页面，其中 `num` 可以是任何正整数。默认情况下，`num` 设置为 1。
- `-o list` 打印逗号分隔列表中给出的页码页面。该列表包含若干 N 个数字和范围 N1-N2。缺失 N1 表示最低页码，缺失 N2 表示最高页码。页范围是逻辑页的表达式，而不是物理纸张。例如，如果你在一张纸上打印两个逻辑页面并指定范围为 4，则会打印两张包含四个页面布局的纸张。如果你在请求每张纸打印两个逻辑页面时指定范围为 3-4，则只会打印第 3 和第 4 页布局，它们将出现在一张物理纸张上。
- `-p mode` 以 `p`（竖向）或 `l`（横向）模式打印文件。`mode` 的第一个字符是有效的。默认模式为竖向。
- `-w window` 使用窗口（由逗号或空格分隔的四个正整数列表），从从每个输入行中选择一个子矩阵的左上角和右下角。行和列索引从左上角开始为 1，输入文件中的数字假设是按行序写入的。默认情况下，显示整个矩阵。
- `-x num` 沿正 x 轴平 `num` 英寸。默认坐标系将原点固定在页面中心，x 向右，y 向上。正数 `num` 将所有内容向右移动。默认偏移为 0 英寸。
- `-y num` 沿正 y 轴平 `num` 英寸。正数 `num` 将所有内容向上移动。默认偏移为 0。

每个逻辑页面仅显示一个矩阵，且每个输入文件必须包含恰好一个矩阵的完整描述。矩阵元素是每个输入文件中按行序排列的浮点数。空白字符（包括换行符）不用于确定矩阵维度。默认情况下，`postmd` 假设每个矩阵都是正方形，并将输入文件中元素数量的平方根设置为行数和列数。在命令行上使用 `-d` 选项提供默认维度将覆盖此默认行为，在这种情况下，维度适用于所有输入文件。

你可以为每个输入文件提供一个可选的头部（header），用于设置矩阵维度、实线划分、灰度映射以及进入矩阵的窗口。头部由关键字/值对组成，每对对单独占一行。它从每个输入文件的第一行开始，在第一个无法识别的字符串处结束，该字符串应是第一个矩阵元素。在头部中设置的值仅对当前输入文件有效。可识别的头部关键字为 `dimension`、`interval`、`grayscale` 和 `window`。紧随在每个关键字后的值字符串的语法与 `-d`、`-i`、`-g` 和 `-w` 选项所接受的格式并行。

### 示例

假设文件初始包含 20 x 50 矩阵中的 1,000 个数字。你可以通过完成步骤产生完全相同的输出。首先，执行以下命令。

```
$ postmd -d20x50 -i"-100 100" -g0,128,254,128,0 file
```

接下来，在文件之前加上以下头部。

```
dimension 20x50

interval -100.0 .100e+3

grayscale 0 128 254 128 0
```

然后，执行以下命令。

```
$ postmd file
```

区间列表将实线划分为五个区域，而灰度列表将小于 -100 或大于 100 的数字映射为 0（即黑色），等于 -100 或 100 的数字映射为 128（即 50% 黑色），而 -100 到 100 之间的数字映射为 254（即近白色）。

# postplot — 用于 plot(1) 的 PostScript 翻译器

### 概要

```
/usr/lib/lp/postplot [-c num] [-f name] [-m num] [-n num] [-o list] [-p mode] [-w num] [-x num] [-y num] [filename...]

/usr/lib/lp/postscript/postplot
```

## 描述

`postplot` 过滤器将 `plot(1)` 图形名称转换为 PostScript 并将其写入标准输出。如果你没有指定文件名或 `-` 是输入文件之一，则读取标准输入。注意——默认行宽对于打印(1)来说太小。

## 选项

- `-c num` 打印每页的 `num` 份。默认情况下，只打印一份。
- `-f name` 使用字体打印文本。你可以使用任何 PostScript 字体，尽管只有使用等宽字体才能获得最佳结果。默认字体是 Courier。
- `-m num` 按因子 `num` 放大每个逻辑页面。围绕原点进行等比例缩放，原点位于每个页面的中心。默认放大倍数为 1.0。
- `-n num` 在每张纸上打印 `num` 个逻辑页面，其中 `num` 可以是任何正整数。默认情况下，`num` 设置为 1。
- `-o list` 打印逗号分隔列表中给出的页码页面。该列表包含数字 N1–N2。缺失 N1 表示最低页码，缺失 N2 表示最高页码。
- `-p mode` 以 `p`（竖向）或 `l`（横向）模式打印文件名。`mode` 的第一个字符是有效的。默认模式为竖向。
- `-w num` 将用于图形的宽度设置为 `num` 点，其中一个点约为 1/72 英寸。默认情况下，`num` 设置为 0，强制线条宽度为一个像素。
- `-x num` 沿正 x 轴平移 `num` 英寸。默认坐标系将原点固定在页面中心，x 向右，y 向上。正数 `num` 将所有内容向右移动。默认偏移为 0。
- `-y num` 沿正 y 轴平移 `num` 英寸。正数 `num` 将所有内容向上移动。默认偏移为 0。
