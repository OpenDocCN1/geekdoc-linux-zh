
由此可知 `ℓ ≤ n/2 - 2`，且存在至少两个与 `u` 相邻但不位于 `P` 上的顶点。由于 `P` 是所有顶点都不位于 `C` 上的最长路径，由此推知，`C` 上至少有两个与 `u` 相邻的顶点，且至少有两个从 `v` 可达（即与 `v` 相邻，弧方向指向 `v`? 不，原文是 "adjacent from v"，在有向图中通常指 `(v, w)` 这样的弧存在，即 `v` 指向 `w`，或者 `w` 指向 `v`？根据上下文 "adjacent from v" 通常意味着存在从 `v` 出发的弧到该顶点，即 `v` 的出邻居）位于 `C` 上的顶点。

*注：原文 "adjacent from v" 在此处语境下，结合后面 "vertices ... that are adjacent from v which lie on C"，通常指存在弧 `(v, x)`。*

令 `a` 表示 `C` 上与 `u` 相邻的顶点数量。因此，`a ≥ 2`。对于 `C` 上每个与 `u` 相邻的顶点 `x`，紧随 `x` 之后的 `ℓ + 1` 个顶点不能从 `v` 相邻（即不存在从 `v` 到这些顶点的弧，或者根据 "adjacent from v" 的定义，这里指 `v` 的出邻居集合中不包含这些顶点？不，原文逻辑是：如果 `x` 后面紧接的某个顶点 `y` 满足 "adjacent from v"（即存在弧 `v → y` 或 `y → v`？），那么就会形成长度超过 `k` 的圈。通常 "adjacent from v" 在有向图语境中若未指定方向，可能指存在弧连接。但在圈论证明中，通常指 `v` 的出邻居或入邻居。根据 "adjacent from v" 的短语，更可能是指存在从 `v` 出发的弧，即 `v` 的出邻居。如果 `C` 上存在从 `v` 相邻的顶点（即 `v` 的出邻居在 `C` 上），则必须存在一个顶点

`C` 上与 `u` 相邻的 `y`，使得 `y` 在 `C` 上紧随其后的 `ℓ + 1` 个顶点均不与 `u` 相邻，也不从 `v` 相邻。

对于 `C` 上每个与 `y` 不同且与 `u` 相邻的 `a - 1` 个顶点，紧随其后的顶点不能从 `v` 相邻。因此，`C` 上至少有 `(a - 1) + (ℓ + 1) = a + ℓ` 个顶点不从 `v` 相邻，否则 `D` 中会出现一个长度超过 `k` 的圈。由于 `P` 是 `D` 中不含 `C` 中任何顶点的最长路径，因此与 `u` 相邻的每个顶点要么在 `C` 上，要么在 `P` 上。

由于 `iu ≥ n/2`，且 `D` 中能与 `u` 相邻的顶点仅属于 `C` 或 `P`，因此得出 `a + ℓ ≥ n/2`。从而，`v` 最多与 `(n - 1) - (a + ℓ) ≤ (n - 1) - n/2 = n/2 - 1` 个顶点相邻，这产生了矛盾。

## 7.4 锦标赛

有一些体育赛事（团队或个人）要求每两个队之间恰好各比赛一次。这被称为循环赛（round robin tournament）。男子足球自 1900 年起便是夏季奥运会的比赛项目。来自 16 个国家的队伍参赛，分为四个小组，每组 4 支队伍。每个小组内进行循环赛，每个小组的前两名队伍晋级争夺奥运奖牌。当 32 个国家参赛并分为 8 个小组（每组 4 队）的足球世界杯争夺战中也采用这种赛制。

循环赛自然地产生了一类有向图，我们之前已经提及过。回顾一下，**锦标赛（tournament）** 是完全图的一种定向。因此，锦标赛可以被定义为一个有向图，对于每对不同的顶点 `u, v`，恰好存在 `(u, v)` 和 `(v, u)` 中一条弧。那么，锦标赛 `T` 建模的是一个不允许平局的循环赛。`T` 的顶点是循环赛中的队伍，如果队伍 `u` 击败队伍 `v`，则 `(u, v)` 是 `T` 中的一条弧。

![](img/598a6ae3fd44120830ada34717906f29_182_0.png)

图 7.11 展示了两个 3 阶锦标赛。事实上，这就是仅有的两个 3 阶锦标赛。非同构锦标赛的数量随着阶数的增加而急剧增长。例如，只有一个 1 阶锦标赛和一个 2 阶锦标赛。正如我们刚刚观察到的，图 7.11 中的锦标赛 `T1` 和 `T2` 是仅有的两个 3 阶锦标赛。有 4 个 4 阶锦标赛，12 个 5 阶锦标赛，56 个 6 阶锦标赛，以及超过 1540 亿个 12 阶锦标赛。

### 传递锦标赛

如果对于 `T` 中的弧 `(u,v)` 和 `(v,w)`，则 `(u,w)` 也是 `T` 中的弧，则锦标赛 `T` 是**传递的**。图 7.11 中的锦标赛 `T2` 是传递的，而 `T1` 不是。以下结果给出了传递锦标赛的一个基本性质。**无圈有向图**是指不含任何圈的有向图。

**定理 7.12** 锦标赛是传递的当且仅当它是无圈的。

**证明.** 设 `T` 是一个无圈锦标赛，假设 `(u,v)` 和 `(v,w)` 是 `T` 的弧。由于 `T` 是无圈的，`(w,u)∉E(T)`。因此，`(u,w)∈E(T)` 且 `T` 是传递的。

反之，假设 `T` 是一个传递锦标赛，并假设 `T` 包含一个圈，设为 `C=(v1,v2,…,vk,v1)`，其中 `k≥3`。由于 `(v1,v2)` 和 `(v2,v3)` 是传递锦标赛 `T` 的弧，可知 `(v1,v3)` 也是 `T` 的弧。由于 `(v1,v3)` 和 `(v3,v4)` 是弧，如果 `k≥4`，则 `(v1,v4)` 是弧。类似地，`(v1,v5)`，`(v1,v6),…,(v1,vk)` 都是 `T` 的弧。然而，这与 `(vk,v1)` 是 `T` 的弧这一事实相矛盾。因此，`T` 是无圈的。

假设 `n` 阶锦标赛 `T` 的顶点集为 `V(T)={v1,v2,…,vn}`，表示 `n` 个队伍 `v1,v2,…,vn` 之间的循环赛。如果队伍 `vi` 击败队伍 `vj`，则 `(vi,vj)` 是 `T` 的一条弧。队伍 `vi` 的获胜次数是 `vi` 的出度。因此，锦标赛中顶点 `vi` 的出度也被称为 `vi` 的**得分**。如果存在一个 `n` 阶锦标赛 `T`，其顶点可以标记为 `v1, v2,…,vn`，使得对于 `i=1,2,…,n` 有 `od vi = si`，则非负整数序列 `s1,s2,…,sn` 被称为锦标赛的**得分序列**。

图 7.12 展示了 `n= 3, 4, 5` 时的传递锦标赛。每个传递锦标赛的得分序列都有一个有趣的性质。以下结果精确描述了哪些序列是传递锦标赛的得分序列。

![](img/598a6ae3fd44120830ada34717906f29_184_0.png)

**定理 7.13** 由 `n` 个非负整数组成的非递减序列 `π` 是 `n` 阶传递锦标赛的得分序列，当且仅当 `π` 是序列 `0,1,…,n-1`。

**证明.** 首先，我们证明 `π:0,1,…,n-1` 是 `n` 阶传递锦标赛的得分序列。设 `T` 是顶点集为 `V(T)={v1, v2,…,vn}` 且弧集为 `E(T)={(vi, vj): 1 ≤ i<j ≤ n}` 的锦标赛。我们声称 `T` 是传递的。设 `(vi, vj)` 和 `(vj, vk)` 是 `T` 的弧。则 `i<j<k`。由于 `i<k`，`(vi, vk)` 是 `T` 的弧，因此 `T` 是传递的。对于 `1 ≤ i ≤ n`，`od vi = n-i`。因此，`T` 的一个得分序列是 `π: 0,1,…,n-1`。
