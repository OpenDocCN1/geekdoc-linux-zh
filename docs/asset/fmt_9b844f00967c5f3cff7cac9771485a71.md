在此代码中，`Account`类允许一组`AccountObserver`对象通过在余额变化时接收更新来监控`Account`实例。为了实现这一点，每个`Account`都保留一个观察者集合，而`AccountObserver`保留一个指向账户引用。每个类都定义了`__del__()`来尝试某些清理（如取消注册等）。然而，这无效。相反，这些类创建了引用循环，引用计数永远不会降为0，垃圾回收器（`gc`模块）也不会清理它，导致永久的内存泄漏。

修复示例所示问题的方法是让其中一个类为另一个创建一个弱引用（weak reference）。弱引用是一种在不增加对象引用计数的情况下创建引用的方法。要使用弱引用，你必须添加额外的功能来检查被引用的对象是否存在。这是一个修改后的观察者类示例：

```python
import weakref
class AccountObserver(object):
    def __init__(self, account):
        self.accountref = weakref.ref(account) # 创建一个弱引用
        self.account.register(self)
```

最后，类通过特殊属性`__bases__`连接到它们的基类，该属性是基类的元组。这种底层结构是所有获取、设置和删除对象属性操作的基础。

用户定义的类可以实现自己的`__slots__`。这是一个示例：

```python
class Circle(self):
    def __init__(self,radius):
        self.radius = radius
    def __getattr__(self,name):
        if name == 'area':
            return math.pi*self.radius
        elif name == 'perimeter':
            return 2*math.pi*self.radius
        else:
            raise TypeError('%s' % name)
    def __setattr__(self,name,value):
        if name in ['area','perimeter']:
            raise TypeError('%s is read-only' % name)
        object.__setattr__(self,value)
```

`__slots__`的使用也会破坏预期实例具有`__dict__`的代码。尽管不适用于用户代码，库和其他支持对象的工具可能会查看`__dict__`。

## 运算符重载

通过向类添加第3章描述的特殊方法的实现，可以让用户定义的对象与Python内置运算符配合。例如，如果你想向Python添加一种新类型的数字，你可以定义一个类，其中定义了如`__add__()`等特殊方法来处理标准运算符。

下面的示例展示了如何通过定义一个实现部分标准运算符的类来实现这种工作。

> 注意
> 因为Python已经提供了复数类型，此类仅用于说明之目的。

```python
class Complex(object):
    def __init__(self,real,imag=0):
        self.real = float(real)
        self.imag = float(imag)
    def __repr__(self):
        return "Complex(%s,%s)" % (self.real, self.imag)
    def __str__(self):
        return "%s+%sjj" % (self.real, self.imag)
    # + other
    def __add__(self, other):
        return Complex(self.real + other.real, self.imag + other.imag)
    # - other
    def __sub__(self, other):
        return Complex(self.real - other.real, self.imag - other.imag)
```
