### 3.5.3.2 配置 IPv4 iptables

`Iptables` 用于在 Linux 内核中设置、维护和检查 IP 数据包过滤规则。可能会定义多个不同的表。每个表包含若干个内置链（`chains`），也可能包含用户定义的链。

每个链都是可以匹配一组数据包的规则列表。每条规则规定了对匹配的数据包要执行什么操作。这被称为“目标”（`target`），它可以跳转到同一表中的用户定义链。

注意：本节泛泛假设了一个空的 `IPTables` 防火墙规则集（通过使用 `iptables -F` 清空规则建立）。修复步骤仅影响运行中的系统，您还需要配置您的防火墙配置以确保在启动时生效。直接在远程连接上配置运行中的系统通常会导致被锁定在系统之外。建议准备一个已知的配置并在启动时运行，并在脚本中配置整个防火墙结构，然后在保存到启动项之前运行并测试。以下脚本将实现本节的防火墙规则，并从任何地方开放 22(ssh) 端口：

```bash
#!/bin/bash

# 清空 iptables 规则
iptables -F

# 确保默认防火墙策略
iptables -P INPUT DROP
iptables -P OUTPUT DROP
iptables -P FORWARD DROP

# 确保回环流量已配置
iptables -A INPUT -i lo -j ACCEPT
iptables -A OUTPUT -o lo -j ACCEPT
iptables -A INPUT -s 127.0.0.08 -j DROP

# 确保出站和已建立连接已配置
iptables -A OUTPUT -p tcp -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A OUTPUT -p udp -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A OUTPUT -p icmp -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A INPUT -p tcp -m state --state NEW,ESTABLISHED -j ACCEPT
iptables -A INPUT -p udp -m state --state ESTABLISHED -j ACCEPT
iptables -A INPUT -p icmp -m state --state ESTABLISHED -j ACCEPT

# 入站 ssh (tcp 端口 22) 连接
iptables -A INPUT -p tcp --dport 22 -m state --state NEW -j ACCEPT
```

## 3.5.3.2.4 确保为所有开放端口确存在 iptables 防火墙规则

（自动化）

配置适用性：

- Level 1 - 服务器
- Level 1 - 工作站

描述：

在非环回地址上开放的任何端口都需要防火墙规则来管理流量。

注意：

- 在通过网络连接时更改防火墙设置可能会导致被排除在系统之外。
- 修复将仅影响运行中的系统防火墙，请确保在您的防火墙管理中配置默认策略，以便在启动时同样生效。


CIS 控制措施：
