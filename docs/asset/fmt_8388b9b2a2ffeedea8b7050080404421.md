# 可移植性文档格式 (PDF)

一种将文档对象（包括文本）渲染为图像的格式，使得发送格式化文档成为可能，并让它们在读者显示器上或以预期的方式出现。来自 Redhat–9 Glossary `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# 门户 (Portal)

作为营销术语使用，描述一个人们使用 Web 时是或意图成为第一个访问的网站。通常，“门户”拥有一个工具目录、搜索引擎或两者兼备。门户网站还可能提供电子邮件和业务，以吸引人们将该网站作为访问 Web 的主要“入口点”（因此称为“门户”）。来自 Mathis `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# portmapper

`portmapper` 是一个安全工具，防止通过 `portmapper` 盗取 `NIS(YP)`、`NFS` 以及其他敏感信息。`portmapper` 管理 `RPC` 连接，这些连接被 `NFS` 和 `NIS` 协议使用。在任何作为使用 `RPC` 协议服务器的机器上都应该安装 `portmap` 包。来自 Redhat 8.0 RPM `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

`portmap`

`RPC portmapper` 是一个服务器，将 `RPC`（远程过程调用）程序号转换为 `DARPA` 端口号。它必须运行才能进行 `RPC` 调用。使用 `RPC` 的服务有 `NFS` 和 `NIS`。来自 Debian 3.0r apt `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

`portmapper (rpcbind)`

在 `UNIX RPC` 协议中，`portmapper` 负责确定特定的 `RPC` 服务正在使用哪个端口号。`RPC` 程序被分配一个已知的“`RPC` 程序号”而不是已知端口。在 `RPC` 套件中，唯一被分配“已知”端口的程序是 `portmapper`。其余程序在启动时随机分配端口号，并告诉 `portmapper` 它们使用的端口。例如，`rpc.mount RPC` 程序被分配已知端口号 `10000`。当它启动时，它可能会获得端口号 `635`。它向本地 `portmapper`（同一台机器上）注册并给它 `[10000,635]` 组合。当客户端请求联系 `portmapper` 时，`portmapper` 回复当前点；然后客户端程序继续在正确的点与 `RPC mount` 通信。理论上，你必须访问目标机器上的 `111` 端口才能到达任何 `RPC` 服务。因此，第一个访问 `111` 端口的管理员认为这可以保护他们免受容易发现 `RPC` 服务，但仍然可以搜寻它们。使用 `nmap`，入侵者可以先进行扫描以找到开放的 `RPC` 端口。来自 Hacking-Lexicon `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# Linux 词典

可以运行在 `PHP` 支持的任何操作系统上。`Postaci` 同样独立于数据库。它可以处理 `MySQL`、`Microsoft SQL`、`Sybase` 和 `PostgreSQL`。它使用非常复杂的数据库来处理 `POP3` 文件夹状态。`Postaci` 是一个土耳其单词，意为“邮递员”。源自 Debian 3.0r0 `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

### postal

`SMTP` 基准测试 – 这个疯狂的程序会启动指定数量的进程，向轮账户发送大量数据作为垃圾邮件。它发送的邮件中带有 `X-Post` 报头，如果有人使用它，则很容易通过代理进行获取。源自 Debian 3.0r0 `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

### poster

利用 `PostScript` 页面制作大尺寸海报。`PostScript` 取一个单页 `PostScript` 文件并将其缩放为指定的大小。它可以将生成的图像平铺到多个页面，这些页面可以拼接在一起形成大海报。`PostScript` 将 `EPS` 视为其输入格式；也能理解 `PostScript` 的形式。源自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

### postfix

一种高性能邮件传输代理。`Postfix` 是 Wiener 的邮件传输代理，最初作为广泛使用的 `Sendmail` 程序的替代方案出现。`Postfix` 尝试做到快速、易于管理，同时保持足够的兼容性以防扰乱现有用户。它的外部带有某种发送的风格，但内部完全不同。此包不支持 `SASL`。如需 `SASL` 支持，请安装 `postfix-tls`。源自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

### postfix

`Postfix` 是一个邮件传输代理 (`MTA`)，支持 `LDAP`、`SMTP` 认证 (`SASL`)、`TLS` 并且并在群发环境中运行。`Postfix` 是 Wiener 的邮件服务器，最初作为广泛使用的 `Sendmail` 程序的替代方案出现。`Postfix` 尝试做到快速、易于管理，同时保持足够的兼容性以防扰乱现有用户。它的外部看起来有些像发送器，但内部完全不同。该软件曾名为 `Vmailer`。它由 IBM Server Club 于 1998 年发布。从那时起它一直沿用 `Postfix`。此 rpm 支持 `LDAP`、`SMTP` 认证 (`cyrus-sasl`) 和 `TLS`。如果你也需要 `MySQL`，请重新构建 `srm --- mysql`。源自 Mandrake 9.0 RPM `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

### PostgreSQL

运行在 `BSD Linux` 上的免费服务器。源自 Route–Users–Guide `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

### postgresql

对象关系 `SQL` 数据库，源自 `POSTGRES`。`PostgreSQL` 是一个对象关系数据库，支持部分 `SQL` 标准。它处于持续开发中，且发布的版本实现了更多 `SQL` 标准，其程度比许多商业数据库更有可能。它还支持面向对象的特征。与 `MySQL` 相比，`PostgreSQL` 更完整——最重要的是，`PostgreSQL` 支持所有表上的事务，这对于数据库的多用户使用和引用完整性至关重要，而这对于可靠的数据库同样至关重要。缺点是它的速度可能会慢一些，尽管每个版本都能看到效率的提高。更多信息请参见 `<http://OpenACS.org/why-not-mysql.html>`。此包提供了后端功能；你需要 `postgres-client` 或其他前端才能访问它们。如果你想用它验证远程连接，则需要一个 `ident-server`。源自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`
