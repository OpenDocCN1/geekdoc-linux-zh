
## 描述

`dump` 命令将每个对象文件参数的选定部分导出到标准输出。`dump` 命令最适用于脚本。建议使用 `elfdump(1)` 命令获取更易读的输出。

## 选项

`dump` 命令接受对象文件及其归档。它根据下列的一个或多个选项处理每个文件参数。

- `-a` 导出归档成员的头部。
- `-c` 导出字符串表。
- `-C` 导出解码后的 C++ 符号名称。
- `-D` 导出调试信息。
- `-F` 导出每个文件头部。
- `-g` 导出归档符号表中的全局符号。
- `-h` 导出节头部。
- `-l` 导出行号信息。
- `-L` 如果可用，导出动态链接信息和静态共享库信息。
- `-o` 导出每个程序执行头部。
- `-r` 导出重定位信息。
- `-s` 以十六进制形式导出节内容。
- `-t` 导出符号表条目。
- `-T index`
  `-T index1, index2`
  `-T` 仅导出由索引定义的索引符号表条目，或由 `index1, index2` 定义的范围范围。
- `-V` 打印版本信息。

### 修饰符

你可以使用以下修饰符来修改上方列出的选项的功能。

| 修饰符 | 描述 |
|---|---|
| `-d number` | `-d number1, number2` |

转储第 `number1` 和 `number2` 个节号。从 `number1` 开始到 `number2` 结束的节范围。你可以将此修饰符与 `-h`、`-s` 和 `-r` 一起使用。当将 `-d` 与 `-h` 或 `-s` 使用时，将参数视为节或节范围的编号。当将 `-d` 与 `-r` 使用时，将参数视为重定位所应用的的节或节范围的编号。例如，要打印与 `.text` 关联的所有重定位，请将节号指定为 `-d` 的参数。如果 `text` 是文件中的第 2 节，`dump -d 2` 将打印所有关联条目。要打印特定的重定位节，请使用 `dump -s -n name` 进行原始数据输出，或使用 `dump -sv -n name` 进行解释性输出。

仅转储与命名实体相关的信息。你可以将此修饰符与 `-h`、`-s` 和 `-t` 一起使用。当将 `-n` 与 `-h` 或 `s` 使用时，将参数视为节名。当将 `-n` 与 `t` 或 `-r` 使用时，将参数视为符号名。例如，`dump -t -n .text` 转储与名为 `.text` 的符号关联的符号条目，而 `dump -h -n` 则转储 `.text` 节的节表头信息。

抑制表头的打印。

以符号表示而非数值形式转储信息。你可以将此修饰符与以下选项使用：

- `-a` (日期, 用户, ID 组)。
- `-f` (类, 数据, 类型, 机器, 版本, 标志)。
- `-h` (类型, 标志)。
- `-o` (类型)。
- `-r` (名称, 类型, 在可能的情况下解释节内容)。
- `-s` (类型, 绑定)。
- `-t` (值)。
- `-L` (值)。

当将 `-v` 与 `s`（注：此处原文可能有误，应为 `-s`）配合使用时，所有可以被解释的节（如字符串表或符号表）都会被解释。例如，`dump -sv -n .symtab filename...` 产生与 `dump -tv filename...` 相同的格式化输出，但 `dump -s -n .symtab filename...` 以十六进制打印原始数据。在没有额外修饰符的情况下，`dump -sv filename...` 转储文件中的所有节，解释所有可以解释的内容并将其余部分（如 `.text` 或 `.data`）作为原始数据转储。

## 输出格式

`dump` 命令尝试以有意义的方式格式化其转储的信息，根据需要将某些信息以字符、十六进制、八进制或十进制表示打印。
