
# 流料斗与流动

扩张流料斗是通过在漏斗料斗底部连接一个质量流料斗形成的。其出口通常比漏斗流料斗所需的给料器小。质量流料斗应将通道扩大到足以防止旋转的尺寸。

漏斗流比质量流料斗更容易导致固体软塌，且需要更大的出口来保证可靠流动。这些料斗还会导致静止区域产生分层。除非出口设计为防止分层，否则清理漏斗流料斗是非常困难的。

## 流体液压与耦合器
流体液压；流体耦合器由一个位于进口轴（或驱动轴）上的叶轮和一个位于受动轴上的转子组成。这两个流体（见插图）叶轮和转子是叶片；叶轮充当泵，转子作为涡轮。基本上，叶轮从其轴线处提取流体，在该处，径向速度分量较低，而切向速度分量较高。这导致了动能的增加。流体质量从叶轮获得能量，并以低速度离开。

## 可压缩性与马赫数
所有流体都是微可压缩的，也就是说，它们的密度随着压力增加而增加。然而，在许多流动中，可以忽略压缩性。压缩性的一个重要因素是马赫数，即速度与流体速度之比。对于亚速流，`Ma < 1`；对于超音速流，`Ma > 1`。本质上是不可压缩流 `Ma < 0.3`；对于低于 250 m/s 的空气速度，许多流动被视为不可压缩流。可压缩流；马赫数。

由不平衡力和应力引起的流体运动。只要施加不平衡力，运动就会发生。例如，从高处倒水时，在口缘处速度很快，在接近处速度中等，在容器底部速度较低。重力的作用是，即，倾斜的容器决定了速率，只要有水且容器保持满溢状态。

## 流体力学基础
流体力学 流体力学是一门关注作用在流体（液体和气体）上的力以及流体对流体施加的力的工程科学。它与固体力学不同，因为流体不抗衡剪切；它们会连续变形。在弹性固体中，应力和变形与施加的应力成正比，而流体没有剪切模量。在大多数情况下，流体中的变形速率（相对于固体中的变形量）与施加的应力成正比。

流体可以是液体或气体。蒸气密度取决于其自身的相，例如水蒸气。如果水蒸发，重要的变量是供应速率。

流体流动；牛顿定律。

气体具有分子间作用力并膨胀以填充任何容器。空气压力是地球的大气。气体是可压缩的；密度随压力变化。恒温下的压力决定气体密度。

许多经验或工程重要物质以流体态存在。这包括液体（和水）、气体（和气态），以及用于工业和家庭过程的其它液体。大多数常用的流体在正常条件下使用。

液体具有力并倾向于保持恒定的体积。在容器中，液体占据自身的体积，并形成一个与任何接触它的流体压力相同的表面。液体几乎是不可压缩的，密度几乎恒定。密度随温度的变化仅为 0.005%。

流体力学将流体视为连续体，忽略了它实际上由单个分子组成的这一事实，而这些分子实际上在运动和碰撞。对于所有尺寸远大于原子或分子平均自由程的流动，连续假设都是有效的。

作用在流体上的力会导致流动和法应力的变形（类似于固体中），但遵循的是流体在某一点将没有剪切应力和均匀变形的原则。这是流体力学的基本原理：流体运动以平衡流体的重量。

流体力学可以应用于所有尺寸的流动，从小管道到广阔海洋。在高海拔，空气密度变化很大，在地球表面的最上层，原子的平均自由程增加到极端长度。

当流体流动时，它会产生剪切，并通过分子动量传递产生力和剪切。这种运动的动量传递速率称为粘度，它与流体流动中的速度梯度成正比。

流体力学是许多学科的基础，包括航空航天、化学、环境、机械和工程，以及地质学、气象学和考古学。我们不仅限于作用于容器的流体研究；在管道和流道中；在河流、湖泊和海洋中污染物的分布。

线性速度流动的常见流体是具有恒定粘度的流体。更复杂的流体，如膏、、漆和浆体，是非牛顿流体或表现出非线性行为，需要更复杂的理论来解释它们的行为。见牛顿定律。

流体粘度。[V.C. L.]

所有流体（无论是否为牛顿流）的一个共同特征是它们在边界处不滑移。无论流体运动有多快，固体表面的速度都等于表面速度。这种边界效应正是流体速度在边界处等于固体速度的原因。无滑移条件意味着当流体在固体表面流动时会形成剪切层或边界层。边界层流理论非常完善，解释了许多涉及粘性流动的效应。
