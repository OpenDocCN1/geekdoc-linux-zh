
## 映射 IP 对应的端口

映射 IP 对应的端口。这对于建立你网络配置的安全性**非常有用**，因为你可以在 `RH7.0` 的 `"Linux PowerTools"` 光盘中看到方便的 GUI 前端端口映射，此外 `nmap` 还可以进行操作系统“指纹识别”。通常，人们（以及你的 `ISP`）可以检测到他们的计算机端口被扫描（他们将其视为攻击前的探测），如果发现可能会抱怨——而你自己的命令使用 `nmap` 只能看到（命令会发送给他们）。我怎么知道这一点？

## 网络分析工具

### `ethereal`

（以 `root` 身份，在 `Xterminal` 中）网络分析器——查看通过电脑的网络流量。包含在 `RH7.0` `"Linux PowerTools"` 光盘中。在某些情况下使用 `ethereal` 可能是不符合道德的，在工作场所未经授权使用可能被视为过错行为。

### `tcpdump`

```
tcpdump -i ppp0 -a
```

（以 `root` 身份）以 `ASCII` 和十六进制打印通过第一个拨号接口 (`ppp0`) 的所有网络流量。`tcpdump` 是一个原始 `root` 工具，可以用于构建更具“自定义”的工具来监听/你需要的内容。

## 6.19 与音乐相关的命令

### 音频 CD 操作

```
cdplay play 1
```

播放音频 CD 上的轨道。使用 `cdplay play` 播放整张 CD。足够时使用 `cdplay stop`。

### `eject`

```
eject
```

获得一个免费的杯架 :))).（弹出 CD ROM）。此命令默认指向 CDROM，但也可以通过指定挂载点或设备来弹出其他可移动介质。例如，你可以从并行口（外部）zip 磁盘弹出 zip 磁盘（以 `root` 身份 `eject /dev/sda4`）。当我按下 CDROM 上的按钮介质未弹出时，我经常使用 `eject`（以 `root` 身份）。

### 波形文件处理

```
play .file.wav
```

播放波形文件。

```
rec my_file.wav
```

从我的麦克风录制波形文件。

### MP3 处理

```
mp123 my_file.mp3
```

播放 mp3 文件。

```
mp123 - my_file.wav my_file.mp3
```

从 mp3 音频 CD 创建波形音频。如果你想从 mp3 写入音频 CD，你必须先将 mp3 转换为 `*.wav` 格式。不要对转换速度慢感到惊讶——解压 mp3 非常消耗 CPU 资源。

### GUI MP3 播放器

```
xmms &
```

（在终端中）好用的 GUI mp3 播放器。

```
freeamp &
```

（在终端中）另一个 GUI mp3 播放器。

### MP3 编码

```
lame input_output_file
```

MP3 编码器。你可能需要自己下载并安装（标准 Linux 发行版由于对 mp3 压缩技术的专利存在分歧，未提供该软件）。

### 下载与共享

```
knapster
```

（在终端中）启动程序下载他人使用的 mp3 文件——用于下载。你也可以分享你的 mp3。非常酷，只要它还能持续——`nutella` 和 `FreeNet` 将让...

### 音频 CD 提取

```
cdparamania -B 8 "1-"
```

（CD 阅读器）读取音频 CD 的内容并将其保存到当前目录下的 wav 文件中，每个轨道一个文件。`"1-"` 意味着“从第 1 轨道到最后一个”。`-B` 强制将每个轨道存入单独的文件。

### 刻录工具

```
grip
```

（在终端中）一个用于刻录（Rip）的 GUI（参见上一个命令）。

### MIDI 播放

```
playmidi my_file
```

播放文件。`my.file` 将在屏幕上显示文本。

### 音频转换

```
sox audio another_file
```

从任何音频格式转换（但不包括 mp3）。查看 `man` 手获取支持的音频格式列表（有很多），`sox` 允许为你的文件添加特殊特效。

### 其他终端播放器

```
3d
```

（在终端中）CD 播放器。

```
midi
```

（在终端中）MIDI 播放器。

```
kix
```

（在终端中）卡拉OK 播放器。

```
studio
```

（在终端中）混音器——编辑文件等。在 `RH7.x` 的 `PowerTools` 光盘上可用。

```
extrace
```

（在终端中）声音视觉化。

### 文本转语音

```
tts my_file
```

读出 `my_file.txt` 的内容。`"festival"` 是一种合成器，可以为 `RedHat` `7.0` `"PowerTools"` 光盘命名。要从命令行输出某些内容，你需要启动 `"festival"`，然后在相应的命令（`"scheme"`）语言解释器中，在本例中（加粗表示提示符）：

```
festival
```

## 6.20 与图形相关的命令

### Postscript 查看

```
hostview my_file.ps
```

（在终端中）显示一个 postscript（或 pdf）文件。

### PDF 查看

```
xpdf my_file
```

（在终端中）查看 pdf 文件。对于查看 pdf，我们可以从菜单选择：

```
acroread my_file.pdf
```

从 `http://www.adobe.com/products/acrobat/read` 下载。

### 图像缩放

```
convert -geometry 800x68 my_picture.gif out_sample.gif
```

缩放图片到 `60x80` 像素。查看几行关于如何转换不同图形格式的示例。

### 图像动画

```
animate -delay 65 pic1 pic2 pic3
```

按顺序显示两个或多个图片。示例中，文件名为 `pic1`、`pic2` 和 `pic3`，图片之间的延迟为 `0.06`，整个演示序列每 `5` 秒重复一次。

### 图像合并

```
combine pic1 pic2 combined_mic.gif
```

将两个或多个图像合并为另一个图像。你可以示例为每张图像添加 logo。

### 图像拼贴

```
montage -geometry 800x600+0+0 my_picture montage.miff
```

创建一个 `my_picture`。有些使用方法是针对艺术家的，`gimp` 中有你可以捕捉的。使用右键获取 `gimp` 菜单，学习使用图层。以 `gimp` 格式 `.xcf` 保存你的文件以保留未来的编辑）然后将其平化并保存为 `png` 或其他。

### 位图编辑

```
xpaint
```

（在终端中）简单的位图映射类型。

### 矢量绘图

```
xfig
```

（在终端中）一个绘图程序。用于制作简单的草图或图表。

```
dia
```

（在终端中）一个使用构建组件绘图的工具。

### 图像查看与处理

```
display my_picture
```

（在终端中）仅用于查看图片。你也可以从菜单选择查看图像、旋转、更改颜色、应用某些特效，`display` 是 `ImageMagick` 软件包的一部分，下面描述了几个其他工具。

### 图像信息

```
identify -verbose my_file
```

给我图像文件的描述：格式、类型、类、像素大小、颜色数、大小（字节）。

### Postscript 转换

```
ps2ps my_file. new_file
```
