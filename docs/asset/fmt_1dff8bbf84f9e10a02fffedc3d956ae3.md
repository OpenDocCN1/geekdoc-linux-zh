# pwgen

自动密码生成 (Automatic Password generation) 生成随机、无意义的密码。这些密码包含小写字母或大小写混合以及数字。大写字母和数字的放置方式便于记忆单词。来自 [Debian 3.0r APT](http://www.tldp.org/LDP/Linux-Dictionary/html/index.html)

# pwm

带框架的轻量级窗口管理器。`PWM` 是一个用于 X11 的相当轻量级的窗口管理器，其独特功能是多个客户端窗口可以附加到同一个框架上。这一功能有助于大量术语的窗口组织。来自 [Debian 3.0r APT](http://www.tldp.org/LDP/Linux-Dictionary/html/index.html)

# pxfonts

用于 TX Pen 的帕拉廷风格字体 (Palatino-likes fonts) 包含：

1. 使用 Adobe Palatino（或 URPalladio）的虚拟文本字体，并在 OT1、TI1 和 TS1 中包含一些经过修改的额外字体。
2. 使用 Adobe Helvetica（或 UR NimbusSans）的虚拟文本无衬线字体，以及 OT1、TI1、TS1 和 LY1 编码中的额外符号（在 TX 分发版中）。
3. OT1、TI1、TS1 和 LY1 编码中的等宽打字机字体（在 TX 字体中）。
4. 使用 Adobe Palatino（或 URPalladio）的数学字母，带有经过调整的间距。
5. 与 Computer Modern 字体（CMSY、CMMI、CMEX 和 CMR 中的希腊字母）对应的所有符号字体。
6. 与 AMS 字体（MSAM 和 MSBM）对应的所有符号字体。
7. 各种符号的额外字体来自 [Debian 3.0r0 APT](http://www.tldp.org/LDP/Linux-Dictionary/html/index.html)
