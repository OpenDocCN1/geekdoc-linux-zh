
# 细胞能量代谢与离子传输

线粒体中三羧酸循环反应中的氧化过程已知与三磷酸腺苷（`ATP`）的合成相耦合，`ATP`由二磷酸腺苷（`ADP`）和无机正磷酸盐（`Pi`）通过称为电子传递链或电子传递系统的酶和细胞色素系统形成。该系统将电子从三羧酸循环的有机分子中通过脱氢作用移除，从线粒体膜的一侧传输到电子结合进入水（由两个氢离子和一个氧原子形成）的另一侧位点。电子从有机基底中相对较高的电势水平流向水中较低电势水平的流动，实际上构成了负电荷电流，有人提出这种流动驱动质子在相反方向流动，作为正电荷电流。这种质子流反过来又被提议为驱动合成`ATP`的力量，对于通过细胞传递系统的每两个电子，合成三个`ATP`分子。实际上，这是细胞发电厂的机械装置。

`Na/K/ATPase`泵随后提供了一个例子，说明质子泵如何在`ATP`水解和细胞工作过程之间转移能量。作为泵基础的酶已知通过磷酸磷脂结合到质膜的脂质双分子层上，并且仅在结合时功能。`Na+`、`K+`、`H+`和`ATP`与酶活性位点的结合可能具有别构效应，改变酶分子的形状，激活`ATP`的水解，并打开`Na+`和`K+`交换的途径。[B.T.S.]

传输过程涉及植物对无机离子的吸收和释放，以及植物体内离子的分布，从而决定了植物的离子关系。离子必须穿过细胞壁和细胞外部的脂质-蛋白质质膜。细胞内分布和区室化由细胞内其他膜上的传输决定。最重要的是将细胞液泡与细胞质分开的液泡膜（`tonoplast`）。

在组织内，相邻细胞连续的细胞壁为离子传输形成了一条质外体途径。质外体途径由细胞质提供，通过穿过细胞壁的小通道（胞间连丝，直径约40纳米）从一个细胞延伸到另一个细胞。较长距离的传输在器官（根、芽、叶、果实）中很重要，这些器官由不同类型的组织组成，并且在整株植物中也很重要。木质部和韧皮部作为长距离传输的途径。根部从土壤中吸收离子，并必须供应其他植物器官。根和芽在无机阴离子和有机基质方面的营养状况在整株植物离子关系的调节中起着巨大作用。植物激素影响传输机制；它们在特定组织中产生，通过传输途径分布，然后发挥信号功能。参见：韧皮部；植物激素；植物组织系统；木质部。

木质部的管道系统在其成熟传导状态下由死细胞（管胞、导管元素）的行组成，其横壁有孔或完全去除。木质部中长距离传输的驱动力很大程度上是被动的。传输是由蒸腾作用引起的，即植物地上部分水分的散失，由从土壤到根、叶和大气的水势梯度驱动。驱动木质部中树皮上升的通常小得多的成分是渗透根压，这是由于泵机制使根部木质部中的离子浓缩，水被动跟随。简而言之，木质部可以被视为从根到芽的离子长距离传输途径，而韧皮部则是从光合作用的源叶到植物中各种库的代谢物传输途径。韧皮部的（长距离）传输途径是筛管，这是一种具有多孔横壁（筛板）的管道系统，但与木质部导管不同，它具有活的细胞质。在源和库区域分别通过筛管的主动装载和卸载建立的浓度和压力梯度是传输的驱动力。参见：植物，盐生环境。[U.L.]

# 离子晶体

一类晶体，其中晶格位点上的占据者是带电离子，主要通过静电相互作用结合在一起。这种结合被称为离子结合。经验上，离子晶体以强吸收红外辐射、高温下良好的离子导电性为特征，

以及晶体容易解理的晶面的存在。参见[晶体结构](https://example.org/crystal_structure)。

强电正性和强电负性元素的化合物形成**离子晶体**，例如碱金属卤化物、其他单价金属卤化物，以及碱土金属卤化物、氧化物和硫化物。如果晶体中的某些离子是复杂离子，如金属碳酸盐、金属硝酸盐和铵盐，也可以归类为离子晶体。

作为晶体类型，离子晶体应区别于其他类型，如分子晶体、共价晶体或金属。按照定义，理想的离子晶体最接近的是碱金属卤化物（见插图）。其他通常被归类为离子的晶体，其结合力并非纯离子性的，而是包含了一定程度的共价键混合。因此，**离子晶体**这一术语指的是一种理想化模型，真实晶体在不同程度上符合这一模型，并且存在具有不止一种晶体类型特征的晶体。参见[化学键合](https://example.org/chemical_bonding)。

离子晶体，尤其是碱金属卤化物，在固体物理的发展中发挥了非常突出的作用。它们相对容易制成较大的、相当纯净的单晶，适合进行精确且可重复的实验研究。此外，由于它们结构简单，且离子间由理解透彻的库仑力结合，因此也相对容易进行理论处理。这与金属和共价晶体（由更复杂的力结合）以及分子晶体（结构复杂或难以制得单晶）形成对比。由于易于获取且是已知最简单的固体之一，它们已成为理论与实验之间频繁且有益的交汇点。离子晶体的这些特点也使其成为研究晶体缺陷的理想宿主晶体：即人为引入的杂质、空位、间隙原子和色心。参见[色心](https://example.org/color_centers)；[晶体缺陷](https://example.org/crystal_defects)。[B.G.D.]

大多数离子晶体具有较大的带隙，因此通常是很好的电子绝缘体。然而，这些晶体中的电传导是通过离子的运动发生的。点缺陷的存在，即晶体点阵中理想有序性的偏离，促进了这种运动，从而产生电荷的传输。在除点缺陷外完美晶格中，所有晶格位置均被占据，离子无法移动。许多所谓的普通离子晶体在室温下的电导率约为 $10^{-10}$ (ohm $\cdot$ cm)$^{-1}$ 或更低。然而，一种相对较少的被称为**超离子导体**或**快速离子导体**的离子材料，其电导率数量级为 $10^{-2}$ 到 $10^{-3}$ ($\Omega$-m)$^{-1}$，表现出类似液体的行为。在这些晶体中，通常只有一种离子物种具有迁移性，其扩散系数和迁移率达到了通常在液体中才能观测到的数值。由于其高离子电导率以及选择性传输离子物种的能力，超离子导体已成功地作为固体电解质应用于许多领域。参见[扩散](https://example.org/diffusion)；[固态电池](https://example.org/solid-state_battery)。[T.M.G.u.]

## 离子平衡

在化学反应中，至少有一种离子物种产生、消耗或从一种介质转移到另一种介质的平衡。

可能存在的各种离子平衡类型包括：

- 未电离物质的溶解，例如氯化氢（气体）溶解在水中（一种电离溶剂），反应(1)–(3)；
- 晶体在水中的溶解，例如固体氯化银的解离，反应(4)；
- 强酸的解离，例如硝酸 `HNO3` 溶解于水时发生解离，如反应(5)所示；
- 离子在水中的解离，例如硫酸氢根离子 `HSO4-` 在水中解离，如反应(6)所示；
- 以及水本身的解离，由反应(7)表示。

## 电离

电子从原子、分子或离子中移除的过程。这对于气体和液体中的电传导具有基本重要性。在最简单的情况下，电离可以看作是从由中性原子组成的初始状态过渡到由正离子和自由电子组成的最终状态。在更复杂的情况下，分子可能转化为被分离开的重正离子和重负离子。[G.H.M.]

## 电离室

一种通过测量电离辐射与合适的气体、液体或固体相互作用释放的电荷量来探测电离辐射的仪器。
