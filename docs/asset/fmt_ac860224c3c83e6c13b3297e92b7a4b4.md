# split — 将文件切分为片段

### 概要

```
/usr/bin/split [-linecount | linecount] [-suffixlength] [file]
/usr/bin/split -b size [file]
```

## 描述

`split` 命令读取文件并将其写入一组带有 `suffix` 后缀的文件，每个输出文件包含 `linecount` 行。输出文件的文件名按字母顺序排列。如果未指定 `suffix`，则使用 `aa`。

## 选项

- `linecount` 指定每个片段的行数。默认为 10。
- `suffixlength` 指定后缀长度。如果未指定，则默认为 6。
- `-b size` 按字节大小切分。

## 参数

- `file` 要切分的文件路径。

# srchtxt — 显示数据库的内容，或在数据库中搜索字符串

### 概要

```
/usr/bin/srchtxt [-s][-1 locale] [-m myfile,...][text]
```

## 描述

使用 `srchtxt` 命令显示消息数据库中的所有字符串，或在消息数据库中搜索字符串（see `gs(1)`）。这些数据库是位于 `/usr/lib/locale/locale/LC_MESSAGES` 的文件（see `setlocale(3)`），除非通过 `-m` 指定的文件包含 `/`。目录 `locale` 是语言名称。如果你没有指定 `-1` 选项，访问的文件由环境变量 `LC_MESSAGES` 决定。如果 `LC_MESSAGES` 未设置，则访问的文件取决于环境变量 `LANG`。如果未设置，则访问 `/usr/lib/locale/LC_MESSAGES`。

如果你没有指定 `text` 参数，则显示所有的文本字符串。

如果你指定 `-s` 选项，显示的文本将以消息序列号开头。序列号包含在角括号中：`<myfile:msgnum>`。

- `myfile` 文本出现的文件名。
- `msgnum` 文本出现的序列号。格式见 `gettext(1)` 和 `gettext(3C)`。

## 选项

- `-s` 抑制打印正在显示的消息序列号。
- `-1 locale` 访问 `/usr/lib/locale/locale/LC_MESSAGES` 目录下的文件。如果你也指定 `-m myfile`，对于包含 `/` 的消息将忽略 locale。
- `-m myfile` 访问由一个或多个 `myfile` 指定的文件。如果 `myfile` 包含字符，则被解释为路径名；否则假设在上述目录中。指定多个 `myfile` 时用逗号分隔。
- `text` 搜索由 `text` 指定字符串，并显示每个匹配项。`text` 可以采用正则表达式的形式；见 `regexp(5)`。
