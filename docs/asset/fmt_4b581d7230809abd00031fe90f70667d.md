## 116 | Linux 命令精通

通常，这个值在所有 Linux 发行版中均为 `022`。当你创建一个文件或目录时，默认权限将根据 `umask` 如下：

- 目录：`rwx-xr-x` (755)
- 文件：`rw-r--r--` (644)

要更改 `umask` 值，我们使用 `umask <new_value>` 命令。

让我们解释一下 `umask` 的含义：如果 `umask` 值为 `022`，那么将每个数字映射到三位数数字（二进制）。例如 `022`，我们用权限代码写为 `"rw-rw-"` 和 `"rwx"`。
