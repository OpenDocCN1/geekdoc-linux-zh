
指定与 X 服务器的连接。

- `display`：指定源窗口或 `None`。
- `src_w`：指定目标窗口或 `None`。
- `dest_w`
- `src_x`
- `src_y`
- `src_width`
- `src_height`：指定源窗口中的一个矩形。
- `dest_x`
- `dest_y`：指定目标窗口内的 `x` 和 `y` 坐标。

如果 `dest_w` 为 `None`，`XWarpPointer` 根据相对于指针当前位置的偏移 (`dest_x`, `dest_y`) 移动指针。如果 `dest_w` 是一个窗口，`XWarpPointer` 将指针移动到相对于 `dest_w` 原点的偏移 (`dest_x`, `dest_y`)。然而，如果 `src_w` 是一个窗口，则只有当窗口 `src_w` 包含指针且 `src_w` 的指定矩形包含指针时，移动才会发生。

`src_x` 和 `src_y` 坐标相对于 `src_w` 的原点。如果 `src_height` 为零，它将被替换为 `src_w` 的当前高度减去 `src_y`。如果 `src_width` 为零，它将被替换为 `src_w` 的当前宽度减去 `src_x`。

很少需要调用此函数。指针通常应该留给用户操作。如果你调用了此函数，它产生的事件就像用户瞬间将指针从一个位置移动到另一个位置一样。注意，你不能使用 `XWarpPointer` 将指针移动到屏幕外。

`XWarpPointer` 可以产生 `BadValueError`。

## 控制输入焦点

Xlib 提供了函数，你可以用来更改键盘控制、获取自动重复键、开启或关闭键盘自动重复、响铃、获取指针按钮或键盘映射，以及获取键盘的位向量。

本节讨论了铃声、键行为等用户偏好选项。许多选项的默认值取决于服务器。并非所有实现都能控制这些参数。

根据 `focus` 参数，会发生以下情况：

- 如果 `focus` 为 `None`，`Xlib` 提供了这些函数来设置和获取输入焦点。

设置输入焦点，使用 `XInputFocus`。

```
XInputFocus(display, focus, revert_to, time);
```

- `display`：指定与 X 服务器的连接。
- `focus`：指定窗口、`PointerRoot` 或 `None`。
- `revert_to`：指定当窗口变得不可见时的焦点回复。你可以传递 `RevertToParent`、`RevertToPointerRoot` 或 `RevertToNone`。
- `time`：指定时间戳或 `CurrentTime`。

`XInputFocus` 函数更改焦点和最后更改时间。如果指定的时间早于当前的最后更改时间，则不设置最后更改时间。如果 `focus` 是窗口，它在调用 `XInputFocus` 时必须可见，否则如果焦点后来变得不可见，将导致 `BadMatch` 错误。如果 `focus` 是 `PointerRoot`，则忽略 `revert_to` 参数。

获取当前的输入焦点，使用 `GetInputFocus`。

```
XGetInputFocus(display, focus_return, revert_to);
```

- `display`：指定与 X 服务器的连接。
- `focus_return`：返回窗口、`PointerRoot` 或 `None`。
- `revert_to`：返回当前的焦点状态（`RevertToParent`、`RevertToPointerRoot` 或 `RevertToNone`）。

`GetInputFocus` 函数返回焦点窗口和当前的焦点状态。

`XInputFocus` 可以产生 `BadMatch`、`BadValue` 和 `BadWindow` 错误。

# 输入设备函数

```c
int bell_duration;
int led;
int led_mode;
int key;
int auto_repeat_mode;
/* LedModeOn, LedModeOff */
/* AutoRepeatModeOff, AutoRepeatModeOn,
   AutoRepeatModeDefault */
) XKeyboardControl;
```

`key_click_percent` 成员设置按键点击的音量，范围从 0（关闭）到 100（响亮），如果支持。设置为 -1 可重置为默认值。其他负值将产生 `BadValue` 错误。

`bell_percent` 成员设置铃声的音量，范围从 0（关闭）到 100（响亮），如果支持。设置为 -1 可重置为默认值。`bell_pitch` 成员设置铃声的音调（以 Hz 指定），如果支持。设置为 -1 可重置为默认值。其他负值产生 `BadValue` 错误。`bell_duration` 成员设置以毫秒为单位的铃声时长；如果支持。设置为 -1 可重置为默认值。其他负值产生 `BadValue` 错误。

如果同时指定了 `led` 和 `key` 成员，则在支持的情况下更改 LED 的状态。`led` 成员可以设置为 `LedModeOn` 或 `LedModeOff`。如果只指定了 `led_mode`，则在支持的情况下更改所有 LED 的状态。最多支持从 1 开始编号的 32 个 LED。未定义 LED 的标准解释。如果在未指定 `led_mode` 的情况下指定它，将导致 `BadMatch` 错误。

如果同时指定了 `auto_repeat_mode` 和 `key` 成员，则在支持的情况下更改该键的自动重复模式（根据 `AutoRepeatModeOn`、`AutoRepeatModeOff` 或 `AutoRepeatModeDefault`）。如果只指定了 `auto_repeat_mode`，则在支持的情况下更改整个键盘的全局自动重复模式，且不影响按键设置。每个键都有一个决定是否自动重复的独立模式。每个未指定 `auto_repeat_mode` 的按键将返回 `BadMatch` 错误以及该模式的默认设置。此外，应该启用或不启用全局自动重复模式作为该模式的默认设置。当全局模式为 `AutoRepeatModeOn` 时，键应遵循其个人的自动重复模式。当全局模式为 `AutoRepeatModeOff` 时，没有任何键应该自动重复。自动重复的键会在 `KeyPress` 和 `KeyRelease` 事件之间交替。当键被用作修饰键时，无论其自动重复设置如何，该键都不应自动重复。

连接到控制台但未直接连接在键盘上的铃声生成器被视为键盘的一部分。验证和更改控制项的顺序。如果产生错误，部分控制项可能已经被更改。

```c
XChangeKeyboardControl(display, value_mask, values);
```

- `display`：指定与 X 服务器的连接。
- `value_mask`：指定要更改的控制项。此掩码是控制位的按位或结果。
- `values`：为掩码中每个置为 1 的位指定一个值。

`XKeyboardControl` 函数控制由 `XKeyboardControl` 结构定义的键盘特性。值掩码（`value_mask`）指定要更改的值。

`XKeyboardControl` 可以产生 `BadMatch` 和 `BadValue` 错误。

要获取键盘的当前值，请使用 `XGetKeyboardControl`。

```
XGetKeyboardControl(display, values_return);
```

- `display` 指定与 X 服务器的连接。
- `values_return` 在指定的 `XKeyboardState` 结构中返回当前的键盘控制。

`XGetKeyboardControl` 函数将键盘的当前值返回到 `XKeyboardState` 结构。

```c
typedef struct {
    int key_click_percent;
    int bell_percent;
    unsigned int bell_pitch, bell_duration;
    unsigned long led_mask;
    int global_auto_repeat;
    char auto_repeats[32];
} XKeyboardState;
```

对于 LED，`led_mask` 的最低有效位指示 LED 1，`led_mask` 中每个置为 1 的位都指示一个 `AutoRepeatModeOn` 或 `AutoRepeatModeOff`。自动重复（`auto_repeats`）是一个位向量。每个置为 1 的位表示相应的按键启用了自动重复。该向量表示为 32 字节。第 N 字节（从 0 开始）包含按键 8N 到 8N+7 的位，其中字节中的最低有效位代表按键 8N。

要开启自动重复，请使用 `XAutoRepeatOn`。

```c
XAutoRepeatOn(display);
```

- `display` 指定与 X 服务器的连接。

`XAutoRepeatOn` 为指定的显示器开启键盘自动重复。

要关闭键盘自动重复，请使用 `XAutoRepeatOff`。

```
XAutoRepeatOff(display);
```

- `display` 指定与 X 服务器的连接。

`XAutoRepeatOff` 关闭指定显示器上键盘的自动重复。

要响铃声，请使用 `XBell`。
