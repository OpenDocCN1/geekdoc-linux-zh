# 邮件服务器类型说明

您的 ISP 或电子邮件提供商可能为您提供 POP3（有时称为 POP）或 IMAP 服务器的选择，您更倾向于哪一个？

如果你在服务器上有大量的存储空间（例如 Gmail 的 7GB 限制），IMAP 是最佳选择。
