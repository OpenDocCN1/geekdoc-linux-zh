
# 生长

大量无机物是形成骨骼和其他支持结构所必需的。在脊椎动物和无脊椎动物中，以硅形式存在的二氧化硅、以碳酸盐形式存在的碳以及以磷酸盐形式存在的磷都极其重要。钠、钾、钙和镁的盐类是体液的基本组成部分。它们贡献于体液的渗透性质，并提供了细胞、组织和器官能够正常功能的环境。一些微量元素，在原生质中仅以微量存在，对生长是必需的。许多可能参与酶和酶辅因子的形成和作用。参见ENZYME（酶）；OSMOREGULATORY MECHANISMS（渗透调节机制）。

动物用作生长原料的有机化合物是碳水化合物、蛋白质和脂肪，或其分解产物。碳水化合物似乎并非必不可少；实验动物可以在完全没有碳水化合物的情况下生长。就其本身而言，脂肪可能也不是必不可少的，尽管某些动物需要某些不饱和脂肪酸来维持生长。然而，在生长过程中，碳水化合物和脂肪是主要的能量来源。参见CARBOHYDRATE（碳水化合物）；LIPID（脂质）。

蛋白质代表生命组织的主要有机成分，是生长最重要的原料。在生长过程中，储存在卵中或作为食物从外部提供的蛋白质被消化为其组成的氨基酸。然后，这些氨基酸重新合成为活细胞的胞质。生物体合成的蛋白质具有特定的特征，这取决于它们所含氨基酸的种类和数量；因此，并非所有蛋白质都同等支持生长。不能诱导生长的蛋白质缺乏一种或多种必需氨基酸（生物体需要但不能自身合成的氨基酸）。参见AMINO ACIDS（氨基酸）；NUTRITION（营养）；PROTEIN（蛋白质）。

除了用于合成主要胞质系统的物质外，动物体还需要某些辅助物质才能生长。其中一些现在被称为维生素。参见VITAMIN（维生素）。

脊椎动物的生长受到由垂体前叶产生的特定生长激素的影响。甲状腺、肾上腺皮质的分泌物，以及在某些情况下性腺的分泌物也影响生长，但可能没有那么直接。各种节肢动物的生长受激素作用的控制。蜕皮，是昆虫和甲壳类动物生长前必不可少的环节，受激素控制。参见ENDOCRINE SYSTEM (INVERTEBRATE)（内分泌系统（无脊椎动物））；ENDOCRINE SYSTEM (VERTEBRATE)（内分泌系统（脊椎动物））。

生长不仅决定动物的大小，还决定其形状和形态。只要动物在所有维度上以相同速率生长，其身体比例就不会改变。然而，当某些方向的生长速率与其他方向不同，或当生长生物体中的一个或多个部分比其他部分发展得更快或更慢时，形态就会发生渐进变化。这种相对生长被称为异速生长。参见HETEROGENY（异形性），或HETEROXENY（异形发育）。

身体比例变化引起的形态变化在人类发展中体现得淋漓尽致。在胎儿生命的第二个月，头部和颈部占胎儿总体积的近一半；出生时，头部的相对大小仅为身体的32%；成熟时则为10%。相反，在同样这三个阶段，腿部分别占身体总体积的2%、16%和29%。在此期间，躯干的相对大小保持恒定，约为身体体积的50%。显然，在胎儿第二个月后的产前发育过程中，头部的生长相对于腿部来说较小，而腿部的生长相对于整体身体来说较大。

许多因素参与生长的调节，有些是内在的，有些是环境的。一个重要的因素是生物体细胞的组织学分化；随着分化的进行，生长速率下降。遗传在确定生长的极限和速率方面很重要。高个子父母生高个子孩子，玩赏型斗牛犬和獒的后代生长到具有特征性的尺寸。激素影响也影响生长，营养水平、温度和拥挤程度等环境因素也是如此。在大多数鱼类中，生长成熟时停止，但在某些鱼类中，生长终身持续。当达到成虫阶段时完全停止生长主要发生在陆生动物中。[E.J.B.]

## 动物界

五大生物界之一：动物界、植物界、真菌界、原生生物界和原核生物界。动物是多细胞的真核生物，它们将食物摄入体内，并由囊胚胚胎发育而来。动物物种被组织成根据比较发育模式、身体结构、行为、生物化学途径、营养模式和祖先定义的动物门。参见ANIMAL SYSTEMATICS（动物系统学）。

传统上，动物被分为无脊椎动物（没有脊柱）和脊椎动物（有脊柱）。脊椎动物包括哺乳动物、两栖动物、爬行动物、鸟类和鱼类。所有其他动物门的成员，占所有动物物种的98%以上，是无脊椎动物。虽然无脊椎动物没有骨头，但它们通过从精致的玻璃状骨针到坚韧的环和杆再到静水压的结构来实现物理支持。仅节肢动物门就包含超过100万种已知物种。如果热带物种得到更好的描述，节肢动物可能包括多达1000万个现存物种。参见AMPHIBIA（两栖纲）；AVES（鸟纲）；CHONDRICHTHYES（软骨鱼类）；CHORDATA（脊索动物门）；MAMMALIA（哺乳纲）；OSTEOICHTHYES（硬骨鱼类）；REPTILIA（爬行纲）。[KV.S]

## 动物形态发生学

动物形态和图案的形成。动物具有复杂的形状和结构模式，这些模式在每一代的胚胎发育过程中都能被忠实地复制。形态发生学通过从单个细胞（即受精卵或合子）生成 progressively 更复杂的结构而发生。合子不断分裂，形成多细胞胚胎，胚胎内的细胞群在识别为组织和器官的精确空间模式中进行结构和功能的特化（分化）。

细胞分化涉及细胞核脱氧核糖核酸（DNA）中基因的差异表达，这些基因编码决定每种细胞类型结构和功能的蛋白质合成。在卵裂过程中，细胞核均等分裂，使得胚胎中的所有细胞都获得合子细胞核 DNA 中包含的全套基因。然而，胚胎不同区域的细胞含有组成不同的细胞质。细胞的细胞质组成控制着胚胎每个区域哪些基因将被表达，从而产生模式化的分化。最初，不同的细胞类型产生是因为细胞占据了独特的位置；有些细胞位于合子早期分裂产生的细胞群内部，而其他细胞则位于外部。这样产生的细胞类型亚群之间的相互作用进一步改变了区域细胞质组成，导致新的基因表达模式。通过许多这样的相互作用，动物身体中大约 200 种不同的细胞类型逐渐在适当的空间模式中显现出来。参见 细胞分化；脱氧核糖核酸（DNA）；基因作用。

动物的结构模式及其部分表现出极性；即，它们沿一个或多个轴显示结构差异。在许多动物中，胚胎的总体极性在卵子发生和受精到第一次卵裂之间的时期确立。例如，随着两栖类卵子在卵巢中生长，其后半部充满卵黄，而其前半部的皮质细胞质中沉积有深色色素。这两个极之间的界限定义了未来胚胎的前后轴。参见 受精；发生；卵子。

背腹轴垂直于前后轴发育，并由受精事件启动的合子细胞质重组建立。此轴可以在任何包含前后轴的平面内形成。其实际形成的平面由精子进入卵子的子午线决定。受精后发生细胞质重组。随着重卵黄在重力作用下流动，抬高的一侧形成一条富含卵黄的细胞质舌，该侧出现一个新的灰色新月形，其背中线与前后轴倾斜所在的平面重合。由精子进入建立的背腹轴在第一次卵裂前不久确定。

两栖类卵子裂期间形成两个主要的细胞层：大的、富含卵黄的内胚层细胞，以及较小的、有色的外胚层细胞，包括由灰色新月形区域形成的细胞。

在原肠前期中胚层阶段，当胚胎由数千个细胞组成时，内胚层细胞和灰色新月形细胞之间发生诱导相互作用，导致后者成为中胚层细胞。在胚胎发育过程中，这三种细胞类型重新排列形成三个同心层，外胚层在外，内胚层在内，中胚层在中间。外胚层发育成皮肤表皮和神经系统，内胚层发育成消化道器官，中胚层发育成肌肉、骨骼、心脏、肾脏和结缔组织。参见 囊胚形成；原肠形成；胚层。

在原肠形成之前，外胚层和内胚层的预期器官区域尚未确定。然而，在这些条件下，中胚层器官区域具有高度的自我组织能力。外胚层和内胚层的器官区域在原肠形成期间及之后由中胚层器官的诱导作用确定。例如，背侧中胚层通常内陷并沿背中线伸展，在那里分化为脊索和躯干肌肉。覆盖背侧中胚层的外胚层分化为中枢神经系统。参见 命运图（胚胎学）。

一旦诱导发生，器官区域本身可以从未确定的组织中诱导额外的器官。例如，眼睛的中胚层和虹膜由从 forebrain 长出的囊泡发育而来。该囊泡诱导头外胚层形成晶状体，然后晶状体诱导头外胚层形成角膜以完成眼睛。通过这样的诱导相互作用级联反应，身体所有器官都定型。参见 胚胎诱导。

一旦确定，器官区域构成一个发育系统，称为形态发生场，它指定器官内细胞分化的详细模式。细胞按照其在场内的相对位置规定的模式分化。普遍认为，分级分子信号或线索是这种位置信息的基础。假设信号源是一组定义场限制的边界细胞。因此，场内的所有细胞都从同一组边界细胞中获得其位置信息。

大多数场在其指定的模式开始分化后变得不活跃；然后移除或交换细胞后形成正常器官的能力丧失。然而，在某些动物中，某些器官的场可以通过部分的缺失而重新激活，即使在成体中也是如此。缺失的部分随后通过称为再生的过程重新发育。参见 再生（生物学）。

不同类型的细胞分泌蛋白质分子和与碳水化合物结合的蛋白质，构成特定类型和模式的细胞外基质。基质稳定组织和器官结构，引导迁移细胞到达其适当位置，并且是细胞相互作用发生的介质。细胞相互作用发生在细胞表面，其分子组成因细胞类型而异，使它们能够相互识别。这些差异反映在不同种类细胞之间以及细胞与不同种类细胞外基质之间粘附性的不同程度中。差异性粘附性是细胞迁移、聚集和重排的基础属性，因此在创建细胞-细胞和细胞-基质相互作用的条件方面很重要。参见 细胞粘附。

复杂图案和形状发育的另一个重要机制是器官及其部分的差异性生长。一旦胚胎器官区域开始发育，差异性生长就显而易见了。在发育早期，器官的生长速率由内在因素控制。在发育后期，包括出生后生活，器官生长主要受内分泌腺细胞分泌的激素控制。
