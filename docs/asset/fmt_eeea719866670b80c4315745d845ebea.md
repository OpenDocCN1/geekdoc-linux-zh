
你可能会反驳说，其他操作系统也有很多免费应用程序，但嘿，让我们面对现实吧——这些程序在功能方面往往是有限的。稍微好一点的程序大多是共享软件，而大多数共享软件在某些方面受到限制，或者除非你付钱，否则你只能使用很短时间。当然，它们的成本相对较低，但 25 美元和 35 美元最终加起来也是一笔不小的钱。还有一个问题是，这些程序中的一些在你不知情的情况下会安装后门、键盘记录器，或让你的系统陷入突然的广告软件丛林。最后，至少根据我的经验，大多数此类程序并不值其要求的价格。我发现的唯一值得购买的共享软件是 Lemke Software 的 GraphicConverter 和 Plask 的 Comic Life，都是用于 Mac 的。

## 仅仅是为了金钱吗？

虽然我的观点对普通用户很重要，但这无疑不是投身 Linux 世界的唯一原因；正如我之前提到的，Linux 以其稳定性著称。尝试在一个月内重启你现在的系统，看看会发生什么。众话 Linux 可以在不重启且性能不下降的情况下运行一年。凭借其多语言能力，Linux 也是语言学生或多语言环境用户的完美选择。

此外，Linux 是无限可定制的：你可以让你的系统看起来和运行起来像你想要的那样，而不会被向导搞死。还有大多数 Linux 发行版附带的应用程序。除了种类繁多之外，许多非常符合行业标准，例如 Evolution 和 GIMP，它们是 Linux 世界之外人士羡慕的来源。

最后，随着微软新 Windows 系统的出现及其对硬件的高苛要求（特别是如果你想利用其最受推崇的功能），你可能会发现你现在的机器正处于过时的快速车道。将其转换为 Linux 机器将确保再有几年的工作寿命。毕竟，过早让良好的硬件闲置是太可惜了。

## Linux 真的准备好用于桌面端了吗？

尽管 Linux 近年来取得了进展，但这个问题仍然频繁出现，这本身就说明了问题。但考虑一下：当你在你现在的 Windows 系统上安装一个程序并收到错误消息说程序由于缺少某些 DLL 文件而无法运行，或者当你连接了一台硬件却无法让它运行运行时，没有人会询问那个操作系统是否为桌面端准备好了。

根据我的经验，我没有理由怀疑 Linux 已经准备好了。Linux 有自己的怪癖，但其他任何操作系统也是如此。如果我母亲（她几乎不是电脑专家）都能使用她的 Linux 系统完成她需要的工作并让自己娱乐到半夜（甚至把整个系统都搞崩溃了），那么我想说你也会没问题的。
