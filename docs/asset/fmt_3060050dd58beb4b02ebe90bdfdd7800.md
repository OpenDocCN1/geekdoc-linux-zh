## 15.4 `device_struct`

`device_struct` 数据结构用于注册字符设备和块设备；它们持有设备名称以及可以用于该设备的文件操作操作集。`chrdevs` 和 `blkdevs` 向量中的每个有效成员分别代表一个字符设备或块设备。

```c
struct device_struct {
    const char *name;
    struct file_operations * fops;
};
```
