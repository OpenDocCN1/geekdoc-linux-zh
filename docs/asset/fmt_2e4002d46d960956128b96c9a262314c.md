`Host` 字段是用户连接的位置。数据库将根据您的用户名以及连接时的 IP 地址或主机名允许您连接。此信息将与列表进行匹配，通过比较主机名、用户名和密码判断是否允许连接。主机可以是完整的主机名或 IP 地址，例如 `test.machine.com` 或 `1.2.3.4`。也可以使用通配符（以 `%` 表示），允许更广泛的范围，并允许你在指定整个局域网或域名时进行精确；例如 `%.machine.com` 或 `1.2.3.%`

一旦你进入 `mysql` 提示符，你就处于数据库命令层级，可以执行 SQL 命令。在这里我们将执行 `GRANT` 语句创建一个管理员和一个用户账户：

```
mysql> GRANT ALL PRIVILEGES ON *.* TO dba@localhost
IDENTIFIED BY 'dbappassword' WITH GRANT OPTION;
mysql> GRANT ALL PRIVILEGES ON *.* TO dba@"
IDENTIFIED BY 'dbappassword' WITH GRANT OPTION;
```

这将允许我们的新用户 `dba` 在本地或从远程任何地方连接，并使用数据库的所有权限。新用户的密码现在是 `dbappassword`。我们现在可以使用 `GRANT` 命令添加另一个权限较少的本地用户：

```
MySQL> GRANT SELECT, INSERT ON *.* TO testuser@localhost
IDENTIFIED BY 'testuserpassword'
```

该用户现在可以使用密码 `testuserpassword` 从本地机器连接，并可以在表上运行 `SELECT` 和 `INSERT` 操作。如果你精通 SQL，可以跳过 `GRANT` 手动将数据插入到用户表中。我们现在可以使用 `INSERT` 命令直接操作此表，前述的 `dba` 账户示例所示：

```
mysql> INSERT INTO user
VALUES('localhost','dba',PASSWORD('dbappassword'),
'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y')
mysql> INSERT INTO user VALUES('%','dba',PASSWORD('dbappassword'),
'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y', 'y')
mysql> INSERT INTO user
VALUES('localhost','testuser',PASSWORD('tsetuserpassword')),
'N','Y','N','N','N','N','N','N','N','N','N','N','N')
mys> FLUSH PRIVILEGES;
```
