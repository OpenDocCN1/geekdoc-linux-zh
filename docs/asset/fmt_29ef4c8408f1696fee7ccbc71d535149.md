## 可靠且健壮

我知道这些术语听起来像是炒作，但在你稍微折腾一下 Ubuntu 之后，你就会理解它们的含义了。把东西弄得乱七八糟它们也能立刻弹回来——这对于往往擅长搞砸事情的初学者来说非常重要。没有什么比一个动不动就崩溃、用得小心翼翼的系统更让新用户望而却了。

## 面向桌面用户

许多 Linux 发行版虽然在桌面领域非常出色，但它们针对的是极客和开发者，用大量你可能永远用不到的垃圾占用了宝贵的磁盘空间。Ubuntu 的目的是从雷德蒙（微软）手中夺取桌面市场份额，因此普通终端用户的需求始终被在内。结果是，Ubuntu 的 GNOME 环境对于普通桌面用户来说是一个非常舒适的地方。

## 硬件兼容性

好了，背景闲话说够了；该让程序运行起来了。如果你还没有在机器上安装 Linux 并且不知道是否可以，那么相对来说，Ubuntu 可以运行在你目前拥有的绝多数机器上。当然，这个说法有一个主要的限制：在实际运行起来之前，你永远不知道。你的机器中有许多细小的部件，很难说每个部分是否都能与你的安装协作工作。暂时忽略这些细小部件，还有显卡、声芯片、网卡、显示器等等，它们都需要被考虑在内。

## 开始尝试

如果你打算买一台新机器来运行 Ubuntu，那么稍微担心并先检查一下是完全合理的，但如果你打算在现有的机器上安装，我建议直接上手。毕竟，你第一次尝试并不真的需要安装任何东西。毕竟，这本书里这里就有一张 Live CD，所以你只需要把 CD 放入驱动器，启动机器，然后砰、砰、砰的一声，一或两分钟内就能运行起来了。一切都会变得……嗯，你的担心结束了，你可以在准备好并就绪时继续安装系统。这是 Ubuntu 的优势之一——不仅所有基本内容都包含在单张 CD 中（与四个或更多其他发行版相比），而且这张 CD 既是现场运行环境，又是安装程序！没有比这更方便的了

## 当需要研究时

如果 Live CD 无法工作，你可以搜索网络，看看是否能识别出你的硬件难题中的某个部分导致了你的问题。（或者如果你正在寻找可以安装 Ubuntu 的机器，你可以搜索受 Linux 支持的硬件。）当然，你可以这样做，但你需要知道你拥有什么型号的硬件。如果你想发现任何有价值的信息，至少应该知道主板、中央处理器 (`CPU`)、显示器和显卡。识别你的 `CPU` 和显示器应该是容易的，但主板和显卡可能需要稍微查找。

如果你没有说明这些设备制造和型号的文档，你可以从 Windows 中获取需要的信息：进入 Windows 控制面板，双击“系统”，然后点击窗口中的“硬件”选项卡。一旦进入“硬件”选项卡，点击“设备管理器”按钮，在那里能找到关于系统组件的信息相当有限，因此你可能想尝试使用共享软件应用程序，如 `HWiFO` (`www.hwinfo.com`) 或 `Sandra` (`www.softaware.net`) 来获取更多有用的细节，例如主板规格或你当前设置支持的视频模式（见第 1-2 节 `Sandra`）。

![图 1-2：在 Windows 中使用 Sandra 查找你的硬件详情]

`HWiFO` 和 `Sandra` 都应该给你提供关于主板所需的信息，但如果没有提供（或者你不想麻烦它们），你随时可以打开电脑机箱查看主板。你不需要担心损坏任何东西，因为你不需要触摸任何东西——所以别碰。你可能需要手电筒照亮它，但名称和数字应该印在某个地方，在主板中间或边缘。例如，我的在主板中间写得很清楚：`AOpen MX46-533V`。这是你应该寻找的。一旦你有了所有信息，你可以通过在 Google 上输入你的主板名称加上 Ubuntu 单词，或者在 Ubuntu 论坛或邮件列表中发布问题。这些列表在本书的末尾提供。

## 硬件要求

需要注意的是，你必须满足一些硬件要求：

- 任何带有 `i86` 处理器的计算机，这几乎涵盖了绝大多数 PC
- 约 10GB 的磁盘空间
- 至少 128MB 内存，尽管如果你有这样的机器，越高越好
- 至少 256MB 内存以确保功能运行
- 为了让运行顺畅，至少 384MB 内存

## 给 Mac 用户的混合消息

那些拥有 PowerPC Mac 的用户可能知道，之前的 Ubuntu 版本提供 PowerPC 版本。遗憾的是，从 Feisty Fawn（我在这里正在写的这一个）开始，情况不再如此了。这意味着如果你是 PowerPC Mac，你将不得不使用旧版本的 Ubuntu 发布之一，或者等待非官方的、社区支持的 PowerPC 版 Feisty Fawn (`http://cdimage.ubuntu.com/ports`)。当然，如果你正在使用新的 Intel 芯片的 Mac，你就很幸运了，因为随书附带的光盘可以在你的 Mac 上运行。

## Ubuntu 术语

值得注意的是，在处理 Ubuntu 时，你不可避免会遇到很多奇怪的短语，特别是在网上搜索信息时。特别地，我指的是四个不协调的短语：Warty Warty、Hoary Hedgehog、Breezy Badger、Dapper Drake 和 Edge。这些自 2004 年首次出现以来，每个 Ubuntu 发布版本的不常代号。对你来说最重要的是当前版本（书中附带光盘上的版本）：Feisty Fawn。

你可能还会遇到其他几种 Ubuntu 变体。这些是 `Kubuntu`（基于 KDE 的 Ubuntu 版本）、`Edubuntu`（专为教室设计的 Ubuntu 特别版本）以及 `Xubuntu`（基于 XFCE 桌面面的轻量级 Ubuntu 版本）。
