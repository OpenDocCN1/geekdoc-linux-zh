# diff — 显示两个文本文件之间的逐行差异

## 摘要

```
/usr/bin/diff [-bitw] [-c | -e | -f | -h | -n] file1 file2
/usr/bin/diff [-bitw] [-C number] file1 file2
/usr/bin/diff [-bitw] [-D string] file1 file2
/usr/bin/diff [-bitw] [-c | -e | -f | -h | -n][-1][-r][-s][-S name] file1 file2
```

## 描述

`diff` 命令按行比较 `file1` 和 `file2` 的内容，并生成两个文件之间所有差异行的完整索引，以及它们的行号。它还会报告为了使文件匹配而必须修改的内容。如果文件相同，则不产生任何输出。

以下示例展示了两个简单文件的 `diff` 输出。

```
castle$ diff kookaburra kookaburra2
4c4
< Gay your life must be.
---
> Glad your life must be.
castle$ 
```

`diff` 输出的每一部分都以一个代码开头，指示后续行所指的差异类型。在上例中，差异被标记为代码 `4c4`。该代码告诉你第一个文件的第 4 行和第二个文件的第 4 行之间存在更改 (`c`)。仅包含第一个文件中文本的行以 `<` 开头。仅包含第二个文件中内容的行以 `>` 开头。虚线分隔引用文件不同部分的输出内容。

正常输出包含以下形式的行：

```
n1 a n3, n4
n1, n2 d n3
n1, n2 c n3, n4
```

其中 `n1` 和 `n2` 代表 `file1` 中的行，`n3` 和 `n4` 代表 `file2` 中的行。`a` (append) 代码表示在第一个文件的该行之后添加了一行。`d` (delete) 代码表示在一个文件中找到但在另一个文件中未找到的行。`c` (change) 代码表示两个文件之间存在更改。

这些行类似于将 `file1` 转换为 `file2` 的 `ed(1)` 或 `vi(1)` 命令。通过将 `d` 交换为 `a` 并反向读取，你可以将 `file2` 转换为 `file1`。与 `ed` 一样，相同的对（当 `n1=n2` 或 `n3=n4` 时）被简写为单个数字。

在这些每一行之后，是第一个文件中受影响的所有行（并以 `<` 标记），然后是第二个文件中受影响的所有行（并以 `>` 标记）。

> 注意 — 根据 `-e` 或 `-f` 选项生成的编辑脚本原生创建由单个句点（`.`）组成的行。

文件末尾缺少换行符表示目标文件的最后一行没有换行符。如果行不同，它们会被标记并输出，尽管输出看起来它们是相同的。

## 选项

- `-b` 忽略行尾空格（空格和制表符），并将其他空白字符串视为等效。
- `-i` 忽略字母大小写；例如，比较 `A` 等于 `a`。
- `-E` 扩展输出行中的制表字符。正常输出或 `-c` 输出会在每行前添加字符，这些字符可能会不利于原始源行的缩进，并使输出行难以理解。此选项保留原始源的缩进。
- `-B` 忽略所有空白（空格和制表符），并将所有其他空白字符串视为等效；例如，`if ( a == b )` 等于 `if (a==b)`。

- `-C` 生成三行上下文列表。使用此选项时，输出格式会略微修改：输出从涉及的文件及其创建日期开始，每个更改之间都由一条包含十二个星号的行分隔。从 `file1` 中删除的行标记为 `-`；添加到 `file2` 的行标记为 `+`。从一个文件到另一个文件更改的行在两个文件中均标记为 `!`。

# diff3 — 三路差异文件比较

### 概要

```
/usr/bin/diff3 [-eEX3] filename1 filename2 filename3
```

## 描述

`diff3` 比较文件的三个版本，并用以下代码标记不不同的文本范围：

```
==== 所有文件均不同。
====1 filename1 不同。
====2 filename2 不同。
====3 filename3 不同。
```

在将给定文件的某个范围转换为某些其他内容时，更改的类型通过以下方式之一进行指示：

`f : n1` 文本将追加在文件 `f` 的第 `n1` 行之后，其中 `f = 1, 2, 或 3`。

`f : n1, n2 c` 在范围 `n1` 到第 `n2` 行之间更改文本。如果 `n1 = n2`，则范围可以缩写为 `n1`。
