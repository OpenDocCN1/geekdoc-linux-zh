# 射电望远镜

射电望远镜一种用于搜索和探测来自各个方向的射频功率的仪器。它由三个部分组成：收集和聚焦入射辐射的反射面；放大和处理收集信号的电子设备；从地面观测，射电望远镜的波长必须短于100 米 (英尺)，因为大气吸收；且长于0.04 米 (毫米)，因为水蒸气 (`H2O`) 和 `CO2` 等吸收了高频噪声。

## 基本原理

射电望远镜的基本原理是探测该波长的辐射。入射波（无线电波或光波）被抛物面拦截并反射到焦点。反射面的形状决定了无线电波“到达”焦点的位置；因此，从点到焦点的长度对于天线上的所有点必须完全相同。这种限制通过抛物面天线满足，尽管曲面也是可能的；大多数现代射电望远镜具有这种形状（见 TELES）。

一旦波被收集并聚集在焦点处，它们就会被大大放大。微弱的射频（rf）信号首先在焦点处放大1000倍，然后转换为较低频率，然后从焦点传输到望远镜控制大楼。随后通过各种方法研究许多方式对信号进行检测和显示。

不同类型的天体发射射频辐射，可以通过无线电天文学家进行研究，以确定无线电观测者是否需要合适的发射机和接收设备。两个通用的天文学考虑因素决定了所需的仪器：首先是无线电分辨率，以便研究无线源的细节；其次，接收器应该对宇宙射线发射的微弱信号极其敏感。

## 角分辨率

最终的角分辨率通过长基线干涉技术（`VLBI`）实现，该技术利用了间隔数千英里的多个望远镜。数据在每个望远镜处获取并录制在录像带上。然后在数据上加上时间标记。数据记录后，对分离望远镜的信号进行相关处理；以便对同一时间的时间标记和数据进行比较和分析。`VLBI`技术已实现微角秒级的分辨率。

## 放射性沉降

当放射性物质由于核释放装置或事故进入空气时，污染的云团最终沉积在地球表面。来自云团的表面物质及其随后的沉积物被称为放射性沉降。

放射性物质由不稳定的原子组成，如伽马射线、β粒子或α粒子。这些发射出的射线和粒子是它们在原子核中产生的原因。如果这些射线和随后的电离能量被生物系统吸收，可能会引起关注。参见α粒子；β粒子；伽马射线；放射性。

天线之间可能的传输路径。

**（不稳定的）原子核的放射性束。** 在核物理实验室中，具有产生不稳定原子核束的能力，这些原子核可能会衰变，或者利用它们来诱发反应并检测衰变。放射性束对于研究恒星效应（如新新星、超新星和X射线）特别有用。这些爆炸是宇宙中最耗昂的现象之一，在产生大量能量的同时合成了构成世界的元素。这些壮观的效应发生是由反应驱动的，在这些反应中，原子核（质子和中子）被重元素的放射性同位素捕获并形成新元素。

铀和钚的裂变产生了70多种不同的元素；每个原子都可能有几种不同的同位素。产物的形式是元素的同位素，它们通常具有放射性。例如，裂变同位素90(Sr)的半衰期为28年，另一种半衰期为50天。在几十年中，所有这些放射性同位素都会发射不同能量的β粒子。其他同位素如铯-137(Cs)的半衰期为30年，碘-131(I)的半衰期为8天。参见碘；铯；同位素。

产生放射性束的一种方法是同位素分离机（`ISOL`）技术。加速器轰击稳定靶材，产生少量的放射性同位素。这些原子通过各种技术（包括热扩散）输送到离子源，在其中被电离（或添加电子以赋予电荷）。然后，这些束与其他同位素分离，并由第二个加速器用于核物理实验。`ISOL`方法产生高质量、高强度的放射性束；其缺点是从产生靶材和初级束产生的放射性束很少，且具有短寿命同位素的束难以处理。

# 放射性矿物

放射性矿物，含有铀（U）或钍（Th）作为其化学组成的基本成分。例如二氧化铀（`UO2`）或二氧化��（`Th2`）。铀中存在放射性矿物，并作为相似尺寸和变化的矿物的替代品。铀或钍元素中约有200种矿物，也对此有描述。这些矿物在铀和钍矿石中发现，其中许多相的描述较差，其细粒变体如铀的沥青矿、钍矿和铁铀矿是铀的主要矿物。
