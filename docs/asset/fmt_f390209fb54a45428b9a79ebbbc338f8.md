# 4.7 Arcnet

状态：已支持，驱动程序名称：`arcnet` (`arc-rimi`, `com90xx`, `com20020`)

鉴于以太网的低成本和更好的性能，大多数地方可能会免费赠送 Arcnet 硬件，导致许多家庭系统配备 Arcnet。

Arcnet 的优势是所有网卡具有相同的接口，因此一个驱动程序适用于所有人。它具有内置的错误处理机制，据称永远不会丢失数据包。（这对 UDP 流量非常好！）注意 `arc` 驱动使用 `arc0` 作为名称，而不是以太网设备常用的 `eth0`。

标准内核中包含了用于设置跳线、通用提示以及发送错误报告邮件地址的信息文件。

据称该驱动同样也支持 100Mbs ARCnet 网卡！
