# 在 VIZ 中链接导出的文件

现在`DWG`文件已经创建，你可以将其链接到`VIZ`场景中。操作如下：

1. 打开或重置`VIZ`。
2. 点击文件(`File`) > 文件链接管理器(`File Link Manager`)。
3. 在附加(`Attach`)选项卡中，点击文件(`File`)按钮，导航到保存导出的`DWG`文件的位置并选择它。如果你没有完成之前的练习，请选择`Shop-rvt-30View-[3D].dwg`文件。
4. 返回文件链接管理器，从预设(`Preset`)下拉列表中选择`Revit`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_868_0.png)

5. 点击预设(`Presets`)选项卡并点击修改(`Modify`)按钮。
6. 在打开的文件链接设置对话框中，点击高级(`Advanced`)选项卡，并确保勾选“使用场景材质定义(`Use Scene Material Definitions`)”和“重新加载时使用场景材质分配(`Use Scene Material Assignments On Reload`)”选项；然后点击保存(`Save`)。
7. 点击文件链接管理器附加选项卡上的附加此文件(`Attach This File`)按钮。系统会处理处理，然后商店出现在视口中。
8. 关闭文件链接管理器。
9. 缩放场景，然后点击快速渲染(`Quick Render`)按钮。如图 17.45 所示，在`Revit`中分配的材质已导入到`VIZ`。
10. 要查看分配的材质，打开材质编辑器(`Material Editor`)，选择一个采样球，然后点击获取材质(`Get Material`)。
11. 在材质/贴图浏览器(`Material/Map Browser`)中，在浏览来源(`Browse From`)部分选择场景(`Scene`)。浏览器将变为显示现在位于`VIZ`中的所有`Revit`材质（见图 17.46）。

正如你在这个练习中所看到的，`Revit`文件是通过将其导出为`AutoCAD`文件并导入或链接到`VIZ`来纳入`VIZ`场景的。为了保持高效的工作流，对`Revit`文件的更改应导出到`AutoCAD`，覆盖现有的链接文件。这样，`Revit`文件中的任何更改在重新加载链接文件时都会反映在`VIZ`中。
