# Tcl/Tk

`Tcl` (发音为 "`tk`") 是一种脚本语言。易学且强大。`Tcl/Tk` 的工具包用于创建图形用户界面 (`GUI`)。`Tcl/Tk` 通常认为比 C 代码少 10 倍。`Tcl/Tk` 是一个快速开发环境。`Tcl/Tk` 如何使用 `://www.tldp.org/Dictionary/index.html`
