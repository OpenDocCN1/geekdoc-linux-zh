## 7.3 主调度器

`schedule()` 函数是 Linux 内核的核心。它在许多地方调用，当进程放弃 CPU 时。由于大部分这些操作由调度器维护，因此这里是介绍它的位置。系统调用可能会调用 `schedule()`，但它们通常通过调用 `sleep()`（第 4.5 节）来实现。调度器的其余在后续章节将详细介绍这些情况。

主调度器的概述如下：

- 7.3.1 检查异常；
- 7.3.2 调度准备工作；
- 7.3.3 选择下一个进程；
- 7.3.4 调度决策；
- 7.3.5 上下文切换
