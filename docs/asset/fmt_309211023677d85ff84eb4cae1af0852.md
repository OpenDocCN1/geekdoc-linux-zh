## 4.3.3 我如何设置 cron？

Cron（一种在夜间执行后台工作的进程）在 RedHat 系统上默认配置好了。你不需要对它做任何操作，除非你想添加某些定期执行的任务，或者想更改 `cron` 执行任务的时间。请注意，`cron` 对于你的系统长期正常运行可能至关重要。其他任务包括：

- 重建使用 `locate` 命令搜索文件时使用的文件数据库，
- 清理 `/tmp` 目录，
- 重建手册页（manual pages），
- “轮转”日志文件，即删除旧日志文件，重命名中间日志并创建新日志。
- 执行某些其他检查，添加你最近复制到系统的字体。

因此，在晚上关闭你的 Linux 机器可能不是一个好主意，因为 `cron` 永远没有机会执行它的工作。如果你在晚上要关闭电脑，可能需要查看 `cron` 设置执行任务的情况，例如查看 `/etc/crontab`：

```bash
cat /etc/crontab
# run-parts
01 * * * * root-parts run-parts /etc/cron.hourly
02 4 * * * root-parts run-parts /etc/cron.daily
22 4 1 * * root-parts run-parts /etc/cron.weekly
42 4 1 * * root-parts run-parts /etc/cron.monthly
```

它可能包含类似的内容：

你可以看到 `cron` 任务有四类：每小时、每天、每周和每月执行。你可以修改这些任务或添加你自己的类别。以下是它的工作原理。

时间设置中的列分别是：分钟（0-59）、小时（0-23）、日期（1-31）、星期（0-6，周日到周六）。`*` 表示“任何有效值”。

因此，在示例设置中，每小时的任务在每次电脑时钟显示“0 点和 1 分”时执行，这每小时发生一次，即在整点后一分钟。每天的任务在每次时钟显示凌晨 4 点 2 分时执行，每天发生一次。每周任务在周日凌晨 4 点 22 分执行。每月任务在每月第一天的凌晨 4 点 42 分执行。每行的最后项是包含要执行命令的脚本文件的目录。

如果你想让任务在中午执行而不是凌晨 4 点，请将 `4` 改为 `12`。`cron` 每分钟都会唤醒一次并检查 `/etc/crontab` 是否发生变化；修改更改后无需重启。

如果你想向 `crontab` 中添加内容，请将运行任务的脚本（或该脚本的链接）放在 `/etc/cron.hourly`、`cron.daily`、`/etc/cron.weekly` 和 `/etc/cron.monthly` 目录下。

这里是 `/etc/crontab` 中的一个示例，它会导致任务每周执行三次：

```bash
22 4 * 1 * root /path/to/script
```

## 4.4 什么是提示符（prompt）？

提示符是 shell 准备好接受命令时显示的文本。你可以通过设置 `PS1` 变量来自定义提示符。可以使用以下特殊代码：

- `\u`: 用户名
- `\h`: 主机名
- `\W`: 当前目录（短名）
- `\w`: 当前目录（全路径）
- `\t`: 时间（24 小时制）
- `\T`: 时间（12 小时制）
- `\D`: 日期（YYYY-MM-DD）
- `\l`: 历史记录数
- `\s`: 当前 shell 名称

例如，将提示符设置为显示用户名和主机名：

```bash
PS1="\u@\h: "
```

这将显示类似 `user@hostname:~$` 的提示符。你还可以添加颜色来让提示符更可见：

```bash
PS1="\[\e[0;32m\]\u@\h\[\e[0m\]:\[\e[0;34m\]\w\[\e[0m\]\$$ "
```

这将用绿色显示用户名和主机名，用蓝色显示目录。
