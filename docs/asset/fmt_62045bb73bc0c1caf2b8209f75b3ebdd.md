## 引言

本书旨在为 Linux 上的程序员提供参考。它涵盖了 Linux 中使用的三个主要 shell 的命令、语法和运算符：Bourne Again shell (BASH)、TCSH shell 和 Z shell。它们都是其对应的 Unix shell 的增强版本。BASH shell 是 Bourne shell 的高级版本，包含了为 Unix Korn shell 和 C shells 开发的大多数高级功能。TCSH 是 C shell 的增强版本，该版本初衷是为 BSD 版本的 Unix 开发的。Z shell 是 Unix Korn shell 的增强版本。

此外，本书还涵盖了编程工具，包括编译器、库、调试器和项目管理器。书中详细讨论了 Linux 上广泛使用的 GNU C 编译器，以及可用的不同类型的库：静态库、动态库和共享库。介绍了 `gdb` 调试器和 `make` 实用程序，用于管理复杂编程项目的版本控制系统 (RCS)。

本书还研究了软件发行工具。`autoconf` 和 `configure` 可以在任何 Linux 系统上自动编译源代码。Redhat 包管理器 (rpm) 自动安装软件包，将所有适当的库和配置文件放置在正确的目录中。书中甚至对开发在线手册的 `man` 宏也进行了研究。

书末尾的三个附录包含了 Perl、Tcl/Tk 和 TeX/LaTeX 命令列表。尽管这些是跨平台的编程语言和工具，但它们在 Linux 系统上被广泛用于创建自定义的 Linux 应用程序。

## BASH Shell 编程

BASH shell 具有类似于编程语言的能力，允许你结合 shell 变量、控制结构、表达式和 Linux 命令来创建复杂的 shell 程序。shell 程序通过某种方式组合 Linux 命令以执行特定任务。Linux shell 为你提供了许多用于创建 shell 程序的编程工具。你还可以定义变量并为它们赋值。你还可以在脚本文件中定义变量，并在脚本执行时让用户交互式地输入值。还有循环和条件控制结构，可以重复 Linux 命令或对你想要执行的命令做出判断。你还可以构建执行算术或比较操作的表达式。所有这些编程工具的操作方式与其他编程语言中的类似。

通常，组成 shell 程序的指令被输入脚本文件中，然后可以执行。你可以使用任何标准编辑器创建此脚本文件。要运行 shell 程序，你需要执行它的脚本文件。

![](img/3db93a7d263e3b589612548bc59abfdb_18_0.png)

shell 脚本是一个包含 Linux 命令的文本文件，你可以使用任何标准编辑器输入它。然后你可以通过文件名作为任何 `sh` 或 dot 命令 (`.`) 的参数来执行文件中的命令。随后，shell 将会读取并执行脚本中的命令。你还可以将脚本文件设为可执行，并在命令行中直接使用它的名称，就像使用任何命令的名字一样。
