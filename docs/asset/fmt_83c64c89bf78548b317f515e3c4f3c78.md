# Tomcat Apache 插件

第 8 章引入了 Apache 的开源 Web 服务器 Tomcat。在 true 章节的练习中，你安装并测试了 Tomcat。Tomcat 产品包含一个基础的 HTTP 服务器。对于生产环境，应该将 Tomcat 作为插件添加到 Apache 服务器中。你可以从 Apache 的 Jakarta 项目网站 (`http://jakarta.apache.org`) 下载插件。获取适用于你版本 Tomcat 的下载链接（注意，4.0 及更高版本使用了本节课程中未涵盖的插件策略），然后按照 `/bin/linux/i386/` 路径获取 `mod_jk.so`。

`mod_jk.so` 模块允许 Apache 与 Tomcat 通信。你需要使用以下命令将其移动到 `/etc/httpd/libexec/` 目录：

```
mv <download-dir>/mod_jk.so /etc/httpd/libexec/mod_jk.so
```

注意，你可能需要创建 `libexec` 目录。此外，注意 `mod_jk.so` 有 ANSI 版本和非 ANSI 版本供下载。最后，通过在 Apache 的 `/etc/httpd/conf/httpd.conf` 文件末尾添加此行来包含 Tomcat 所需的项：

```
Include /etc/httpd/conf/mod_jk.conf
```
