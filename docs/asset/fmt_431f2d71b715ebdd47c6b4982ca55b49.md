## 充分利用海龟

是时候让这些海龟派上用场了。让我们创建一个绘制正方形的函数，这将用于在游戏中创建方形（和矩形），作为墙壁：

```python
def square(x, y):
    path.up()
    path.goto(x, y)
    path.down()
    path.begin_fill()
    for count in range(4):
        path.forward(20)
        path.left(90)
    path.end_fill()
```

我们还需要几个函数来计算数学问题。

尽管吃豆人是一个相对简单的游戏，但仍然涉及一些物理元素，主要在于碰撞检测，并确保我们的吃豆人不会穿过墙壁走出游戏世界。

```python
def offset(point):
    x = (floor(point.x, 20) + 200) / 20
    y = (180 - floor(point.y, 20)) / 20
    index = int(x + y * 20)
    return index
```

这将返回偏移量。我们还需要检查移动是否有效：

```python
def valid(point):
    index = offset(point)
    if tiles[index] == 0:
        return False
    index = offset(point + 10)
    if tiles[index] == 0:
        return False
    return point.x % 20 == 0 or point.y % 20 == 0
```

def world():

当然，我们可以根据需要更改颜色，但一开始我们使用的是 1980 版吃豆人的传统黑色和蓝色环境。最后那个颜色（`path.dot`）分配给我们路径上的小圆点。你会注意到我们利用了之前设置好的`square`函数。

def move():
