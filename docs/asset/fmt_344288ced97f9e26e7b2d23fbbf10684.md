
数据库是底层应用程序之一。数据库“记录”的概念早于计算机中的“文件”。如今，大多数关于数据库的讨论都围绕着 SQL（结构化查询语言）展开。SQL 是一种特殊的语言，你可以用它来编码语句，例如“所有名字名为 Robert 的人”。实际的 SQL 语句看起来像：`SELECT * FROM everyone else name equals "Robert"`。关键点在于：SQL 接近编程的特性意味着它容易受到困扰其他脚本语言的相同漏洞。例如，针对数据库的一种频繁攻击是向数据字段中插入元数据。例如，一个使用 `PERL` 的报告系统，它从数据库中提取数据。我可以创建一个名为 "`mail'`" 的银行账户，这样当你运行月底报告时，它就会把密码字段发送给我。在 1999 年和 2000 年初，成千上万的微软 Web 服务器被破解，是因为数据库程序通过 SQL 查询提交了命令行语句，而默认脚本在服务器的默认安装中留下了这些查询。源自 Hacking-Lexicon

# datagram (数据报)

在协议中，数据报是一个独立的传输单元。它们被称为“不可靠数据报”，因为无法保证它们一定到达目的地。这需要某些高层协议或应用程序来验证数据报是否到达目的地。流媒体（音频/视频/语音）在传输过程中丢失几个数据包并无重要时，通常会使用数据报。源自 Hacking-Lexicon
