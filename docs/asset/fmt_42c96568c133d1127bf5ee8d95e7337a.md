
通过本章的介绍，我们学习了 Linux 目录结构。我们了解了各个目录的作用，并学习了符号链接和硬链接。这些知识对于熟练使用 Linux 系统至关重要。

## 表 4-3：通配符示例

| 模式 | 匹配项 |
| --- | --- |
| `*` | 所有文件 |
| `g*` | 任何以 g 开头的文件 |
| `b*.txt` | 任何以 b 开头、中间任意字符 .txt 结尾的文件 |
| `Data???` | 任何以 Data 开头后跟三个三个字符的文件 |
| `[abc]*` | 任何以 a、b 或 c 开头的文件 |
| `BACKUP.[0-9][0-9]` | 任何以 BACKUP 开头后跟两个两个数字的文件 |
| `[[:upper:]]*` | 任何大写字母开头的文件 |
| `[[:digit:]]*` | 任何非数字开头的文件 |
| `*[:lower:]123]` | 任何以小写字母或数字 1,2,3 结尾的文件 |

## 通配符在 GUI 中同样有效

通配符之所以非常有价值，不仅是因为它们在命令行被频繁使用，还因为某些图形文件管理器也支持它们。

- 在 `Nautilus`（`GNOME` 的文件管理器）中，你可以使用 `编辑 ► 选择模式`（`Edit ► Select Pattern`）菜单项选择文件。输入带有通配符的文件选择模式，当前查看目录下的文件将被高亮。
- 在某些版本的 `Dolphin` 和 `Konqueror`（`KDE` 的文件管理器）中，你可以直接在位置栏输入通配符。例如，如果你想查看 `/usr/bin/` 目录下所有以小写字母 u 开头的文件，在位置栏输入 `/usr/bin/u*`，它将显示结果。

许多最初在命令行界面中的想法也进入了图形界面。这是让 Linux 桌面变得强大原因之一。

通配符可以用于任何接受文件名作为参数的命令，但我们将在第 7 章中详细讨论。

> 如果你来自其他 Unix 类环境，或者读过关于此主题的其他书籍，你可能遇到过 `[A-Z]` 和 `[a-z]` 字符范围表示法。这些是传统的 Unix 表示法，在旧版本的 Linux 中也有效。它们仍然可以工作，但你必须小心使用，因为除非正确配置，否则它们不会产生预期的结果。目前，你应该避免使用它们，而是改用字符范围。

## mkdir—创建目录

`mkdir` 命令用于创建目录。它的工作方式如下：

```
mkdir directory...
```

注意，当命令描述中的参数后面跟着三个点时（如上例所示），意味着该参数是可以重复的。因此，以下命令：

```
mkdir dir1
```

将创建一个名为 `dir1` 的单个目录。而下条命令：

```
mkdir dir1 dir2 dir3
```

将创建三个名为 `dir1`、`dir2` 和 `dir3` 的目录。

## cp—复制文件和目录

`cp` 命令复制文件或目录。它可以有两种不同的用法。如下所示：

```
cp item1 item2
```

将单个文件或目录 `item1` 复制到文件或目录 `item2`。此命令：

```
cp item... directory
```

将多个项目（文件或目录）复制到目录中。

### 有用的选项和示例

表 4-4 描述了 `cp` 的一些常用选项（短选项和等效的长选项）。

## 表 4-4：cp 选项

| 选项 | 含义 |
| --- | --- |
| `-a`, `--archive` | 复制文件和目录及其所有属性，包括所有和权限。通常，复制将使用执行复制用户的默认属性。我们将在第 9 章中查看文件权限。 |
| `-i`, `--interactive` | 在覆盖现有文件之前，提示用户进行确认。如果未指定此选项，`cp` 将静默地（意味着没有警告）覆盖文件。 |
| `-r`, `--recursive` | 递归复制目录及其内容。在复制目录时需要此选项（或 `-R` 选项）。 |
| `-u`, `--update` | 从一个目录复制文件到另一个目录时，仅复制目标目录中不存在或比现有文件较新的文件。这这在复制大量文件时非常有用，因为它跳过了不需要复制的文件。 |
| `-v`, `--verbose` | 在执行复制时显示信息性消息。 |

表 4-5 提供了这些常用选项的一些示例。

## 表 4-5：cp 示例

| 命令 | 结果 |
| --- | --- |
| `cp file1 file2` | 将 `file1` 复制到 `file2`。如果 `file2` 存在，则用 `file1` 的内容覆盖它。如果 `file2` 不存在，则创建它。 |
| `cp -i file1 file2` | 与上一个命令相同，不同在于如果 `file2` 存在，在覆盖之前会提示用户。 |
| `cp file1 file2 dir1` | 将 `file1` 和 `file2` 复制到目录 `dir1`。目录 `dir1` 必须已经存在。 |
| `cp dir1/* dir2` | 使用通配符，将 `dir1` 中的所有文件复制到 `dir2`。目录2 必须已经存在。 |
| `cp -r dir1 dir2` | 将目录 `dir1` 的内容复制到目录 `dir2`。如果 `dir2` 不存在，则创建它，之后的内容将与目录 `dir1` 相同。如果目录 `dir2` 已存在，目录 `dir1`（及其内容）将被复制到 `dir2`。 |

## mv—移动和重命名文件

`mv` 命令执行文件移动和文件重命名，取决于如何使用。无论何种情况，操作后原始文件名都不存在。`mv` 的用法与 `cp` 非常相似，如下所示：

```
mv item1 item2
```

将 `item1` 移动或重命名为 `item2`。`mv` 与 `cp` 共享许多选项，如下所示：

```
mv item... directory
```

将多个项目移动到目录。

## rm—删除文件和目录

`rm` 命令用于删除文件和目录，如下所示：

```
rm item...
```

其中 `item` 是一个或多个文件。

### 有用的选项和示例

表 4-8 描述了 `rm` 的一些常用选项。

| 选项 | 含义 |
| --- | --- |
| `-i`, `--interactive` | 在删除现有文件之前，提示用户进行确认。如果未指定此选项，`rm` 将删除文件。 |
| `-r`, `--recursive` | 递归删除目录。这意味着如果被删除的目录有子目录，将删除它们。删除目录时需要指定此选项。 |
| `-f`, `--force` | 忽略不存在的文件且提示。这将覆盖交互选项。 |
| `-v`, `--verbose` | 在执行删除时显示信息性消息。 |

## 小心使用 rm！

像 Linux 这样的 Unix 类操作系统没有“撤销”命令。一旦你用 `rm` 除了东西，它就消失了。Linux 假设你是聪明的，知道自己在做什么。在使用通配符时要格外小心。考虑这个经典示例。假设你想删除目录中的所有 HTML 文件。要这样做，输入：

```
rm *.html
```

这是正确的，但如果你认为在 `*` 和 `.html` 之间加了一个空格，像这样：

```
rm * .html
```

`rm` 命令将删除目录中的所有文件，然后报错没有名为 `.html` 的文件。有一个实用的技巧：每当你用 `rm` 使用通配符时（除了仔细检查输入之外），先用 `1s` 测试通配符。这将让你看到将要删除的文件。然后按向上键调回命令并将 `1s` 替换为 `rm`。
