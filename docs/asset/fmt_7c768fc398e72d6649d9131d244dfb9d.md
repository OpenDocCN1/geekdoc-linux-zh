
## 第 18 章：系统管理命令

### atrm: 删除已计划的任务

示例：

```
root> atrm 25
```

(`atrm 25`: 删除编号为 25 的计划作业。)

### ps: 显示当前进程状态

示例：

```
root> ps -f
```

(`ps -f`: 显示当前进程的完整信息。)

示例：

```
root> ps -u username
```

(`ps -u`: 显示用户当前的进程。)

### w: 显示谁登录以及正在做什么

示例：

```
root> w -s username
```

(`-s`: 显示用户的摘要信息。)

### uptime: 显示系统运行时间

示例：

```
root> uptime
```

(`uptime`: 显示系统已运行时间。)

### top: 查看最活跃的或指定的进程

示例：

```
root> top
```

(`top`: 显示系统上运行的所有进程)

### crontab: 创建在指定时间运行的作业

示例：

```
root> crontab -e
```

(`-e`: 编辑 `crontab` 文件，在表中添加一个 `crontab` 作业)

### 总结

- `job`: 显示所有作业的状态
- `fg`: 在前台运行暂停的任务
- `bg`: 在后台运行暂停的任务
- `kill`: 通过编号杀死作业或通过 `pid` 杀死进程
- `at`: 在指定时间调度作业
- `atq`: 显示已计划的作业
- `atrm`: 删除已计划的任务
- `ps`: 显示当前进程状态
- `w`: 显示谁登录以及正在做什么
- `uptime`: 显示系统运行时间
- `top`: 查看最活跃的进程
- `crontab`: 创建在指定时间运行的作业

### 示例：网络诊断命令

#### nslookup

> > `root> nslookup myexample.com`

(返回 `IP` 地址，例如 `75.126.166.2XX`)

(`nslookup`: 手动查询 `DNS` 服务器。)

(`DNS`（域名系统）协议允许你从名称服务器获取给定主机名的 `IP` 地址。此过程被称为域名解析。)

### 总结

- `host`: 显示远程主机名和 `IP` 地址
- `ifconfig`: 显示本地网络配置
- `ping`: 发送数据包以测试远程主机是否可达
- `ssh`: 安全地连接到远程计算机
- `ftp`: 通过“文件传输协议”传输文件
- `mesg`: 启用或禁用消息传递功能
- `write`: 向其他用户写入消息
- `open`: 连接到 `ftp` 服务器
- `mail`: 在本地和范围内发送及接收邮件。

# 第 19 章：脚本命令

### echo: 显示文本

`echo`: 显示文本。

示例：

```
root> STR="Hello World!"
root> echo $STR
```

(`echo`: 显示文本。输出是 “Hello World!”)

### echo -e: 使用转义序列显示文本

示例：

```
root> STR="Hello World!"
root> echo -e "\n$STR\n"
```

(`echo -e`: 使用 `\n` 显示文本。 `\n` 意味着换行。)

输出是：

Hello World!

### expr: 执行数学计算

示例：

```
user> expr 20 + 80
```

(输出是 “100”)

示例：

```
user> expr 21/7
```

(输出是 “3”)

示例：

```
user> expr 9 ">" 6
```

(输出是 “1”， 1 表示真)

示例：

```
user> expr 9 "<" 6
```

(输出是 "0"，0 表示假)

### #!/bin/bash: 放在 bash shell 脚本的第一行

示例：

```bash
#!/bin/bash
if...then...else...fi
```

(`#!/bin/bash`: 始终放在 `bash` shell 脚本的第一行)

### 总结

- `echo`: 显示文本。
- `expr`: 执行数学计算。
- `#!/bin/bash`: 始终放在 `bash` shell 脚本的第一行

# 第 20 章：系统命令

### df: 显示文件系统的磁盘占用

`df`: 显示文件系统的磁盘占用

示例：

```
root> df -h
```

(`df`: 显示文件系统的磁盘占用)
(`-h`: 使输出易于理解)

### mount: 使设备对文件系统可用

示例：

```
root> mount /cdrom
```

(`mount`: 使 `cd-rom` 对文件系统可用。)

### umount: 使设备对文件系统失效

示例：

```
root> umount /dev/hda1
```

(`umount`: 使 `hda1` 对文件系统失效)
(`hda1`: 一个硬盘分区)

### fsck: 检查并修复文件系统

示例：

```
root> fsck
```

(`fsck`: 检查并修复文件系统。)

### init n: 将系统切换到运行级别 n

示例：

```
root@user-linux: ~ # init 5
```

(`init 5`: 将系统切换到运行级别 5)

### who -r: 显示当前运行级别

示例：

```
root@user-linux: ~ # who -r
```

(`who -r`: 显示当前运行级别。)

### free: 显示空闲内存

示例：

```
root@user-linux: ~ # free -m
```

(`free`: 显示空闲内存)
(`-m`: 以 `MB` 为单位显示空闲内存)

### du: 显示文件或目录的磁盘占用

示例：

```
root@user-linux: ~ # du -b myfile.txt
```

(`du`: 显示文件或目录的磁盘占用。)
(`-b`: 统计其占用的字节数。)

### export: 设置环境变量

示例：

```
root@user-linux: ~ # export newvar=8
```

(`echo $newvar`. 输出是 8)

### printenv: 列出环境变量的名称和值

示例：

```
root@user-linux: ~ # printenv
```

(`printenv`: 列出环境变量的名称和值)

### unset: 移除环境变量

示例：

```
root@user-linux: ~ # unset var
```

(`unset var`: 移除环境变量 `var`。)

### clear: 清除屏幕

示例：

```
user>clear
```

(`clear`: 清除屏幕。)

### exit: 退出 shell 或注销。

示例：

```
user>exit
```

(`exit`: 退出 `shell` 或注销。)

### shutdown -h +n: 系统将在 n 分后关闭！

示例：

```
root@user-linux: ~ # shutdown -h +5
```

(`shutdown -h +5`: 系统将在 5 分后关闭!)
(`-h`: 停止系统)
(`+n`: 在 `n` 秒后)

### 总结

- `df`: 显示文件系统的磁盘占用
- `mount`: 使设备对文件系统可用
- `umount`: 使设备对文件系统失效
- `fsck`: 检查并修复文件系统
- `init n`: 将系统切换到运行级别 `n`
- `who -r`: 显示当前运行级别
- `free`: 显示空闲内存
- `du`: 显示文件或目录的磁盘占用
- `export`: 设置环境变量
- `printenv`: 列出环境变量的名称和值
- `unset`: 移除环境变量
- `clear`: 清除屏幕
- `exit`: 退出 `shell` 或注销。
- `shutdown -h +n`: 系统将在 `n` 分后关闭！
