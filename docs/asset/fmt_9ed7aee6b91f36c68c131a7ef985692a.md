
# 使用 StarImpress 模板构建报告

在这个示例中，你将使用 `StarImpress` 模板构建一份报告。该报告是为虚拟的 Tomco 定制木工公司年度员工会议准备的，该公司使用特殊木材和手工制品根据要求制作橱，每个柜子都满足客户的需求。作为公司的总裁，你想与员工分享过去一年的事件。

1. 使用 `文件 > 从模板新建`（`File > New From Template`）打开文档模板屏幕。
2. 在左侧窗口中选择 `演示文稿`（`Presentations`）类别。右侧窗口会出现演示文稿模板列表。选择 `员工大会`（`Staff Assembly`）并点击确定。（见图 28-1。）

**图 28-1：** 从文档模板屏幕选择模板

3. `StarImpress` 打开“员工大会”模板。你现在可以选择并用你想要共享的具体信息替换通用的文本模板。
4. 标题灯片在顶部。点击标题栏并将其替换为正确的文本：`Tomcat 年度员工会议`。
5. 点击屏幕底部的 `议程`（`Agenda`）标签页。出现议程灯片。使用此幻灯片提供整个员工会议的议程，而不仅仅是这次演示的程。点击文本区域并输入议程：`9:00 开场白，10:15 头脑风暴，12:00 午餐。`
6. 点击屏幕底部的 `概述`（`Overview`）标签页。打开了第三张灯片。使用此幻灯片简要概述全年的业务，并与去年进行比较。点击项目列表选择它，并替换每个项目的文本：`收入增长 37%，建筑师推荐减少 8%，木材成本增加了三分之一。`
7. 点击屏幕底部的 `成就`（`Achievement`）灯片。打开了第四张灯片。在这张灯片上，解释公司销售和利润达到新水平的领域。点击项目列表选择它，并替换每个项目的文本，如图 28-2 所示。
8. 点击屏幕底部的 `公司`（`Company`）标签页。打开了第五张灯片。因为 Tomcat 的几名员工是新来的，使用此幻灯片解释公司的管理结构。点击项目列表选择它，并替换每个项目的文本：`总裁，Tom Bartram；副总裁，Steve Mitchell；人力资源协调员，Susan Wills；营销经理，Vicki Gonzalez。`
9. 点击屏幕底部的主要问题（`Main Issues`）标签页。打开了第六张灯片。指出年度会议涵盖的主要概念以及 Tomcat 在明年面临的关注问题。点击项目列表选择它，并替换每个项目的文本：`员工满意度，产品质量，提高客户满意度。`

![](img/fadd96433567128670f1068748d632f5_472_0.png)

10. 点击屏幕底部的主要目标（`Main Goals`）标签页。打开了第七张灯片。在这张灯片上，描述过去一年的销售和生产目标。点击项目列表选择它，并替换每个项目的文本：增加重复业务，在面向家庭的杂志上登广告，提高高峰期间的生产。

**图 28-2：** 在“成就”灯片中解释公司的成功之处。

11. 点击屏幕底部的 `结果`（`Results`）标签页。打开了第八张灯片。在这里显示 Tomco 是否达到了去年的目标。点击项目列表选择它，并替换每个项目的文本，如图 28-3 所示。
12. 点击屏幕底部的 `周转率与利润`（`Turnover & Profit`）标签页。打开了第九张灯片。使用此幻灯片解释年度员工流转率并显示利润率。插入一个表格以图表形式显示。（点击项目列表将其替换为表格。）
13. 点击屏幕底部的主要支出（`Main Expenses`）标签页。打开了第十张灯片。使用饼图说明过去一年的主要支出及其占总支出的比例。点击项目列表将其替换为饼图。使用 `插入图表`（`Insert Chart`）在幻灯片中放置基础图表，然后点击条形，如图 28-4 所示。

![](img/fadd96433567128670f1068748d632f5_473_0.png)

**图 28-3：** 结果灯片上的 Tomco 目标。

**图 28-4：** Tomco 支出的饼图。

14. 点击屏幕底部的 `市场研究`（`Market Research`）标签页。打开了第十一张灯片。使用此灯片解释当前市场并指出你今年的目标市场。点击项目列表选择它，并替换每个项目的文本：旧房装修人员，电视购物节目，公寓室内装饰师。
15. 点击屏幕底部的 `未来目标`（`Future Goals`）标签页。打开了第十二张灯片。在这张灯片上，展示未来的目标。点击项目列表选择它，并替换每个项目的文本：保持低流转率，增加媒体报道，降低商店成本。
16. 最后，点击屏幕底部的 `总结`（`Summary`）标签页。打开了第十三张灯片。在这里你可以回顾报告的要点。点击项目列表选择它，并替换每个项目的文本。
17. 当你完成每个灯片后，使用 `幻灯片放映`（`Slide Show`）查看演示。

## 创建书籍提案

演示软件的常见用途是构建销售提案。使用幻灯片演示来支持口头报告可以让观众通过两个渠道获取信息：听觉和视觉。这增加了他们记住你所说内容的概率，增加了他们成功的机会。

在这个示例中，你将创建一个提案布局，因为没有任何模板或自动制作选项可以在不经过大量修改的情况下适应提案。你将为一位想要描写意大利美食和葡萄酒的记者制作此提案。这个主题可能太大了，因此作者决定关注拉齐奥省（包括罗马）的美食和葡萄酒。该演示将作为幻灯片放映。

1. 从桌面开始，使用 `文件 > 新建 > 模板`。文档模板窗口打开。
2. 在左侧窗口中选择 `演示布局`（`Presentation Layouts`）。右侧窗口出现模板列表。选择 `欧洲`（`Europe`）。点击确定。
3. 修改幻灯片窗口出现。选择一张带有标题和文本的灯片。点击确定。
4. 幻灯片出现在蓝色背景上，带有欧洲的轮廓图。点击标题栏，输入演示类型。使用工具栏中的按钮使文本居中并设置书名为斜体，如图 28-5 所示。
5. 点击主文本框。输入作者姓名：`John Ippolit`。增大字体大小并居中。点击名字中间，按住鼠标按钮并拖动名字，直到它处于美的位置。如果框超幻灯片边缘请不要担心。点击幻灯片外部并检查你的修改是否可以接受。
