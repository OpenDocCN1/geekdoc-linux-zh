# 启动和停止服务的机制

要切换运行级别，`init` 会以运行级别作为参数调用脚本 `/etc/init.d/rc`。该脚本检查相应的运行级别目录 `/etc/init.d/rc.d/`，并根据该目录中的链接启动和停止服务。

对于每个运行级别，`/etc/init.d/` 下都有相应的子目录。对于运行级别 1，它是 `/etc/init.d/rc1.d/`；对于运行级别 2，它是 `/etc/init.d/rc2.d/`，以此此类推。
