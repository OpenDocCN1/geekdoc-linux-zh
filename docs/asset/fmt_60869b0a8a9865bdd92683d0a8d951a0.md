
# 水黾类

水黾类广泛分布在世界温暖国家。美国最著名的是*Zoapter hubardus*，分布范围从宾夕法尼亚州到佛罗里达州，再到堪萨斯州和墨西哥。已知仅25种，且全部属于水黾科（Zoapteridae）大属。

# 石松叶目

石松叶目（Zosterophyllida）是一种灭绝的石松植物纲，由原始叶类植物组成，这些植物从泥盆纪开始开始繁盛，并在晚泥盆纪达到一个较短的巅峰，当时它们在生态上非常重要，是陆地植物群的一部分。

石松叶目由约18属组成，尽管这些物种中很少能从其解体的结构中完全重建。所有属都表现出退化的生殖器官和直立轴，轴通常分枝密集。它们的特征是配子体成熟阶段早，随后产生具有多细胞和简单结构的血管化肾形孢孢子。

最原始的蕨类植物总类是石松藻属（Zosterophyllum）。*Glinifolia*和其他石松叶类具有其他蕨类植物不具备的特征，成功地在泛滥平原和海岸边缘生存下来，但到泥盆纪结束时，更复杂的石松叶类已几乎灭绝。

# 接合孢目 2421

接合孢目（Zygematales）。一种大型绿藻（绿藻门）的特征是缺乏鞭毛。性生殖通过接合管中变形配子的融合来实现，从而产生世代交替周期。生物学和结构上的特征表明，接合孢目与藻藻纲比藻藻纲更近。接合孢目的成员主要局限于淡水和亚空气栖息地。它们基本上被归类在该纲的根部。接合菌类在全球分布，尽管很少遇到；它们可能是特定宿主的成员。参见真核生物；真菌；接合菌门。

接合菌亚（Zygomycina）通过性性和无性策略进行区分。性接合孢产生于两个配子的融合。无性生殖可能是孢子子形成（包含一个到多个、始终不运动的分生子）。各种方法与孢子的形成有关。无性生殖比性生殖更常见；许多物种和某些目中的性生殖未知。其他是腐生的、寄生的或专性共生的特别是在节肢动物中。有两个纲（接合菌纲和毛丝菌纲），但不确定它们是亲缘关系还是通过趋同进化变得相似。

接合菌纲（Zygomycetes）是一个陆生真菌纲，包括广霉。性生殖的形成是通过孢子囊内的内生孢子形成，或多孢子囊、酵母细胞或节肢体。这些真菌以吸器（具有吸收营养的结构）出现在动物和植物（包括人类）的身体或根部，或作为腐生，特别是在土壤或粪中。某些物种是内生或菌根。

成熟的孢子结构是干燥的并通过空气传播，或是潮湿的并通过动物或昆虫的直接接触或在其粪便中传播。水滴可能会传播孢子或完好的产孢结构。

分类基于感染模式、接合孢的形态（如果形成的话）、性生殖的类型、孢子梗的分枝模式和隔膜形态。接合菌目前被归在几个目中：接合孢目、内生目、食虫目、干燥孢目、球菌目、里克塞尔菌目、毛菌目和食孢目。
