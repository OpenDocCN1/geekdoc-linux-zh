
# 线虫纲目概述

线虫纲的一个目，其口囊通常呈漏斗状且角质层较薄；然而，在某些科中，口囊宽敞且角质层厚，并装备有可伸缩的齿。Amphids 的形态从简单的螺旋形到圆形不等。通常，头部感觉器的第二和第三轮是合并的，但在某些分类单元中，由四根明显刚毛组成的第三轮是独立的。正常的分布模式常常被众多颈刚毛所扰乱。近圆柱形的食道有时在后部膨胀。角质层可能是光滑的，也可能具有环纹或装饰。当环纹明显时，体刚毛可能较长，并排列成四至八纵行。雌生殖腺呈伸展状，为单个或成对。有三个单胃线虫总科：Limnomoidae 和 Siphonolaimidae 主要是海洋型；各群组的摄食习性未知。Mohnystereidae 是自由生活的线虫，存在于所有环境中，从海水到淡水和土壤；摄食习性未知。参见 [线形动物门](https://example.org/nematoda)。

## 猴

灵长类中的一种适应性或进化等级，由现代三个类人猿超科中的两个超科的成员代表。新世界阔鼻猴（Ateloidea）和旧世界狭鼻类（Cercopithecoidea）可能在从共同祖先分离后（也许是 4000 万年前）独立达到了猴的适应水平。“猴”这一术语并不指示分类学或系统发育上的亲缘关系；卷尾猴总科最近的亲属不是蜘蛛猴，而是旧世界猿类和人类。Ateloidea 包含两个科，而现存的 Cercopithecidae 今天被认为仅包含一个科，有两个亚科。类人猿总科的现代分类如下：

- 下目 Anthropoidea
    - 亚目 Platyrrhini
        - 超科 Ateloidea（新世界或阔鼻猴）
            - 科 Atelidae
                - 亚科 Atelinae（吼猴和蜘蛛猴）
                - 亚科 Pitheciinae（绢毛猴、狐猴和 titi 猴）
            - 科 Cebidae
                - 亚科 Cebinae（僧帽猴和松鼠猴）
                - 亚科 Callithricinae（狨猴和柮猴）
                - 亚科 Brasilinae（灭绝的早期 Ateloids）
    - 亚目 Catarrhini（旧世界类人猿）
        - 下下目 Eucatarrhini（现代狭鼻类）
            - 超科 Hominoidea（长臂猿、大型猿类和人类）
            - 超科 Cercopithecoidea
                - 科 Cercopithecidae（旧世界或狭鼻猴）
                    - 亚科 Cercopithecinae（颊囊猴：猕猴、狒狒、长尾猴和西番猴）
                    - 亚科 Colobinae（叶食性：叶猴和疣猴）
                    - 亚科 Victoriapithecinae（灭绝的早期卷尾猴）
        - 下下目 Ecatarrhini（原始狭鼻类）
            - 科 Pliopithecidae（晚期原始狭鼻类）
            - 科 Propliopithecidae（早期原始狭鼻类）
    - 亚目 Paracatarrhini（灭绝的早期类人猿）
        - 科 Parapithecidae（灭绝的埃及猴）
        - 科 Oligopithecidae（灭绝的原始类人猿）

由于极大的多样性以及与猿类的比较，很难对猴作为一个群体进行特征描述。猴和猿与类人猿等级（prosimian grade）的对比在于，它们通常是大的、昼行性的、群居动物。猴与猿的区别在于它们有尾巴、脑容量较小、四足行进的直腰姿态（pronograde posture）以及通常较长的脸部。它们通常比猿小，但大型猴比长臂猿重。像几乎所有的灵长类动物一样，猴是五指（趾）型，且大多数情况下指尖是指甲而非爪子。它们具有胸前乳腺和发达的视觉。猴主要以素食为主，栖息于热带和亚热带的森林地区

## 单胺氧化酶

存在于线粒体外膜上的两种酶之一，可降解生物胺，因此负责在神经元突触处破坏传递物质。神经细胞在受到刺激时，会将神经递质释放到突触中。神经元随后必须处理这种神经递质以停止信号，否则新的信号无法通过。这是通过三种机制之一实现的：扩散；重新摄取到突触前区域；以及被包括单胺氧化酶在内的一系列酶降解。参见**突触传递**。

单胺氧化酶抑制剂是阻断细胞内胺类递质降解的药物；然而，并非它们的所有效应都可以直接归因于单胺氧化酶抑制，因为已经描述了许多不同的神经元效应。单胺氧化酶抑制最显著的后果是细胞内单胺浓度的迅速增加。此外，脑中5-羟色胺水平的升高程度超过去甲肾上腺素和多巴胺。在这些胺浓度升高后，发生次级适应性后果，包括通过明显的反馈机制减少胺合成，这在去甲肾上腺素系统中表现得最为清楚。参见**神经生物学**；**去甲肾上腺素能系统**；**5-羟色胺**。

已鉴定出两种类型的单胺氧化酶。它们分别被命名为A型和B型，因其具有不同的底物特异性而有所区别。A型优先使去甲肾上腺素、皮质多巴胺和5-羟色胺脱氨，并可选择性地被氯吉线抑制。B型降解苯乙胺、多巴胺和苄胺，并对左旋二羟苯乙胺（Deprenyl）或帕吉林（Pargyline）的抑制敏感。常用的单胺氧化酶抑制剂是非选择性抑制剂，同时影响A型和B型。人体中75%的单胺氧化酶是B型。

单胺氧化酶抑制剂在医学上用于控制高血压以及治疗抑郁症和其他障碍。其他精神疾病，如强迫症、贪食症、躯体形式疼痛障碍、恐慌症和分裂症，据报道偶尔对单胺氧化酶抑制剂的治疗有反应。也有证据表明，所谓“非典型抑郁症”的患者更倾向于对单胺氧化酶抑制剂产生反应。参见**情感障碍**；**高血压**。**[M.A.E.]**

## 单殖类

属于苔藓植物中叶苔亚目的一个目，仅包含一个属（单殖目）。配子体是所有叶苔中最大的之一；其叶状体除散在的油细胞外，由同质细胞组成。假根光滑，且既有单壁细胞也有薄壁细胞。性器官成群分布但不凸起；雄器沉入腔体中并成组形成藏卵器，而颈器则被苞片包围成组。非常长而粗壮的孢丝显著地将孢子囊抬高，孢子囊通过一条裂缝进行孢子散出。孢子母细胞中的分裂方式在叶苔亚目中是独特的。参见**苔藓植物门**；**叶苔亚目**。**[H.C.]**

## 单克隆抗体

结合特定靶分子（抗原）上特定部位（抗原表位）的抗体蛋白。针对感染或异物免疫接种，免疫系统会产生许多不同的抗体，结合到外源蛋白上。这个多克隆抗体池中的单个抗体结合到靶分子上特定的表位上。分离出多克隆抗体池中的单个抗体，将允许对仅靶向单个表位的高特异性分子实体进行生物化学和生物学表征。认识到这种特异性的治疗潜力，推动了研究开发方法来分离并持续产生单一谱系抗体（即单克隆抗体，mAb）的方法。

1974年，W. Kohler 和 C. Milstein 开发了单克隆抗体的生成过程。在他们的方法中，单个B细胞（产生具有单一特异性但寿命有限的抗体的B淋巴细胞）与髓瘤细胞（B细胞肿瘤细胞，可在培养中无限生长）融合，生成杂交瘤细胞。这种杂交瘤保留了两个亲本细胞的可取特性，能够产生具有特定特异性的抗体，并可在培养中无限生长。
