
# `Pteridosperms（种子蕨）`
一组已灭绝的种子植物，其特征是产生裸种（naked seeds）的雌性叶。种子蕨的发现是对植物进化研究的重要贡献，因为它证明了一群如今已灭绝的维管植物的存在。虽然种子蕨的最终起源可能在原裸子植物目（progymnosperm order）`Aneurophytales`（非维管植物目）中，但该群体最好的证据来自下石炭统（密西西比期）及更年轻的沉积物中。一些种子蕨被重建为具有粗壮茎的树木，而大多数可能是支持巨大蕨状叶片的藤蔓或木质藤本。种子蕨包括古生代的六个目（`Calamopityales`, `Buxtoxylonales`, `Lyginopteridales`, `Medullosales`, `Callipteridales`, `Glossopteridales`）和中生代岩石中发现的三个目（`Peltaspermales`, `Cystospermales`, `Caytoniales`）。参见`CAYTONIALES`；`古植物学`。[TIN.T]

# `Pterobranchia（羽鳃纲）`
一组小型固着生活的半索动物（hemichordates），可能是群居的（`Rhabdopleura`）、伪群居的（`Cephalodiscus`）或独居的（`Atubaria`）。每个个体，即虫体（zooid），生活在原索（protosome）分泌的非几丁质管内，`Atubaria`除外；虫体的聚集称为共株（coenecnum），形状可变。原索，或口盾（oral shield），呈盘状，在腹侧封闭口部，并分泌管壁。原索在第一对臂的基部具有对称的极。中索（mesosome），或领部（collar），具有前腹侧的口和一对到九对背侧具纤毛的羽状臂，用于收集小型生物作为食物。中体腔延伸至两臂和触手。末索（metasome）分为一个小的圆柱形躯干和一个细长的腹侧柄，其末端可能是自由的。躯干包含U形的消化道，咽具有一对鳃，`Rhabdopleura`除外。胃是肠道的囊状扩张，管状肠道背侧弯曲并在臂后方通过背中侧肛门开口。神经系统非常简单，缺乏神经索。口部憩室是中空的，具有肠层膜心室和中央窦。肾小球发育不良，循环系统比肠鳃类（enteropneusts）更简单。参见`半索动物门`。[J.Ben.]

# `Pteropsida（蕨类植物总目）`
一大群维管植物，其特征是茎中的全环异型叶隙（panchyomorphous leaf gaps in the stele），以及被认为起源于遥远的过去为分枝茎系统的叶片。一些植物学家将`Pteropsida`视为一个自然类群，承认其为纲、亚纲或部门。另一些则将其视为由石松类祖先（rhynophyte ancestry）经历某些相似变化而来的植物的人为集合。`Pteropsida`的各个组成部分在此被视为三个独立的部门，名为`Magnoliophyta`（木兰植物门），`Pinophyta`（松植物门）和`Polypodiophyta`（蕨植物门）。参见`木兰植物门`；`松植物门`；`蕨植物门`。[A.Cn]

# `Pterosaurs（翼龙）`
中生代的“有翼爬行动物”，构成与恐龙（Dinosaurs）最接近的主要群体，并与其共享许多特征。它们的共同祖先是一种小型、双足、敏捷的类似 `Scelidosaurus`（`Scelerronuchus`）的鸟蜥类，拥有大而轻质的头骨、短小的身体、长的后肢以及具有四个长跗骨的趾行足。翼龙继承了所有这些特征，并进一步进化出飞行能力。翼龙拥有内部由长、细、可能是胶原质的硬化纤维支撑并由前肢支起的皮肤翅膀，前肢包括一根大大延长的第四指（前三指保持较小）。它们的大脑很大且类似鸟类。它们的骨壁是所有四足动物中最薄的。参见`Ornithischia（鸟臀目）`；`Saurischia（蜥臀目）`。最早的翼龙已知于晚三叠世，大约是第一只恐龙出现的时间：包括 `Eudimorphodon`（双型齿龙），`Peteinosaurus`（彼得诺龙）和 `Preondactylus`（原始翼指龙），均发现于意大利的海洋岩层中。翼指龙类（Pterodactyloids，“翅指”）是晚侏罗纪和白垩纪翼龙的一个亚群，取代了早期翼龙。该群体中最著名的成员包括小型的 `Pterodactylus`（翼指龙）和翼展达 7 米（23 英尺）的 `Pteranodon`（无齿翼龙）（见插图）。

# `Pterygota（有翅亚纲）`
昆虫纲的两个亚纲中较大的一个。所有高等昆虫在成虫阶段都有翅或源自有翅祖先；也就是说，如果无翅，那是次生的。原始有翅类构成原翅类（Palapterigota）部；蜉蝣、蜻蜓和豆娘属于此类。其他所有有翅类构成新翅类（Neoptera）部。最原始的新翅类具有外翅发育，如蚱蜢、真蝽等，而更特化的新翅类具有内翅发育，如蝴蝶、蛾、甲虫、胡蜂等。参见`无翅亚纲（APTERYGOTA）`；`内翅类（ENDOPTERYGOTA）`；`外翅类（EXOPTERYGOTA）`；`昆虫纲（INSECTA）`。[EMC.]

# `Pychodactylaria（指触目）`
动物界六辐射珊瑚动物门（Coelenterata）下石珊瑚动物亚门（anthozoans）的一个目。这一群独居海葵已知仅有北极和南极的 `Pychodactylus` 和 `Dactylanthus` 两个属。参见`石珊瑚动物亚门（ANTHOZOA）`；`六辐射珊瑚动物门（COELENTERATA）`。[C.H.]

# 公共卫生
社会组织的旨在保护、促进和恢复人民健康的努力。它是科学、技能和信念的结合，旨在通过集体或社会行动维持和改善健康。公共卫生的项目、服务和机构强调疾病预防以及整体人口的卫生需求。额外的目标包括减少

## 人口中的疾病、过早死亡、残疾和不适的数量。

公共卫生的基础科学包括流行病学和生命统计，它们用于衡量健康状况并评估人口的健康趋势。流行病学也是一种强大的研究方法，用于确定多种疾病的病因并计算患病或死亡的风险。许多科学，包括毒理学和微生物学，被应用于检测、监测和纠正环境中的物理、化学和生物危害。这些应用正被用来应对对全球环境恶化的担忧。自认识到懒惰、孤独、人格类型以及对烟草的依赖等因素会导致过早死亡和慢性残疾疾病的风险增加以来，社会和行为科学在公共卫生中变得日益重要。参见[流行病学](https://www.example.com/epidemiology)。

在大多数工业国家，公共卫生服务在国家级、区域级和地方级进行组织。国家级公共卫生服务通常负责制定、监测和维持健康标准，促进健康，收集和汇编国家健康统计，并支持和开展对公共卫生具有重要意义的疾病研究。区域级（例如，州级）公共卫生服务主要处理重大的卫生保护活动，如确保安全的供水和食品供应；它们可能还运营早期疾病筛查计划，并负责特定群体（如慢性精神病患者）的医疗保健。地方公共卫生服务（在城镇、州级城市和部分农村社区）开展多种个人公共卫生服务，如免疫诊所、健康教育、对母亲和新生儿的家庭监测与建议，以及对老年人和长期卧床患者等脆弱群体的个人护理。地方卫生服务还调查和控制流行病和其他传染病，如性传播疾病。

国家级公共卫生服务相互沟通，以控制具有国际重要性的疾病，并在世界卫生组织（WHO）的 auspices 下开展全球合作。虽然世界卫生组织的许多工作集中在发展中国家，但它也参与了控制重大流行病的全球努力，并制定了关于有害环境和职业接触的标准。

# 滑轮
一种带有平面、冠形或槽形轮缘的轮子，用于配合平皮带、V形皮带或绳索，以传递运动和能量。用于V形皮带和绳索驱动的滑轮表面带有凹槽，通常称为皮带轮（sheaves）。由绳索、滑轮和滑轮组组合而成，旨在获得机械优势（例如提升负载）的系统被称为滑轮组。参见[皮带传动](https://www.example.com/belt_drive)，[滑轮组](https://www.example.com/block_and_tackle)。

用于平皮带的滑轮由铸铁、轧制钢、木材和纸制成。特定的滑轮设计必须基于对耐冲击能力、导热性以及耐腐蚀环境等能力的考量。滑轮表面必须足够光滑以最小化皮带磨损；同时，皮带与滑轮表面之间必须有足够的摩擦力来承载负载。

两种常见的V形皮带滑轮是压制钢滑轮和铸铁滑轮。压制钢滑轮适用于单带驱动。对于多带驱动，或者在需要飞轮效应而导致滑轮质量较高的单带驱动中，使用铸铁滑轮。[J.R.Z.]
