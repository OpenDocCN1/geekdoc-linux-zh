`-e` 不打印邮件。如果用户有邮件，则返回状态 `0`；否则返回状态 `1`。

`-p` 打印所有消息，而不提示方式。

# 调试

以下命令行参数提供邮件调试信息。

`-x debug-level`

创建一个包含调试信息的跟踪文件。

`-x` 选项会创建一个名为 `/tmp/MLDBGprocess_id` 的文件，该文件包含与 `mail` 处理当前消息有关的调试信息。`debug-level` 的绝对值控制调试信息的详细程度。`0` 表示不进行调试。如果 `debug-level` 大于 `0`，只有当 `mail` 在处理消息时遇到某些问题时，才会保留调试文件。通过 `-x` 指定的 `debug-level` 会覆盖 `/etc/mail/mailcfg` 中对 `DEBUG` 的任何指定。如果小于 `0`，则始终保留调试文件。`-x` 选项提供的信息非常晦涩，可能仅对系统管理员有用。

# 递送通知

`mail` 提供了提供了多种形式的通知，包括头文件中的以下行之一：

+   `- Transport-Options: [/options]`
- `Default-Options: [/options]`
- `To: 收件者 [/options]`

其中 `/options` 可以是以下一个或多个项：

+   `/delivery` 通知发送者消息已成功递送到收件者的信箱。
-/nodelivery 不通知发送者成功递送。
-/ignore 不通知发送者递送失败。
-/return 如果邮件递送失败，则通知发送者。将失败的消息返回给发送者。
-/report 与 `/return` 相同，但不返回原始消息。

默认值是 `/nodelivery/return`。如果你使用了冲突的选项，将识别第一个，并忽略稍后的任何冲突术语。

# 注意事项

由于“递送通知”部分描述的头行而产生的解释和后续采取的操作，仅当此版本的 `mail` 安装在发生递送（或失败）的系统上时才会发生。早版本的 `mail` 可能不支持任何类型的递送通知。某些条件会导致无法删除锁文件。

# mailcompat — 为 Solaris Mailbox 提供兼容性

格式

`/usr/bin/mailcompat`

描述

`mailcompat` 命令为 Solaris box 格式提供了 4.x 兼容性。你通常运行 `mailcompat` 是为了当你的邮件服务器是 Solaris 时，能够在运行 4.x 的工作站上读取邮件。

启用 `mailcompat` 会在你家目录下的现有的 `.forward` 文件中创建一个条目。如果 `.forward` 文件不存在，`mailcompat` 会创建它。禁用 `mailcompat` 会从 `.forward` 文件中删除该条目，如果这是唯一的条目，则删除整个文件。

要执行 `mailcompat`，请登录 Solaris 邮件服务器并在命令行输入 `mailcompat`。回答程序提供的查询。

用法

查看 `largefile(5)` 以了解 `mailcompat` 在遇到大于或等于 `2 Gbytes(**31 bytes)` 文件时的行为描述。

示例

以下示例启用了 `mailcompat` 功能并显示 `.forward` 文件的内容。

`castle% mailcompat`

此程序可将您的邮件存储为可以使用基于 SunOS 4.X 的邮件读取器读取的格式。

# mailstats — 打印 sendmail 统计信息

# 摘要

```
usr/bin/mailstats [-c configfile] [-f statisticsfile]
```

## 描述

`mailstats` 命令打印 `mail(1M)` 程序对邮件使用的统计信息。如果存在 mail 的 S 选项则收集这些统计信息。默认统计文件为 `etc/mail.st`。`mailstats` 命令首先打印统计文件的创建时间和最后修改时间。然后为配置文件中指定的每个 mailer 打印一个表格。第一列是 mailer 编号，随后是该 mailer 发送的消息总数。接下来的两列引用自 mail 接收的消息数量，最后两列引用 mail 发送的消息。显示消息数量及其总大小（以 1024 字节为单位）。如果没有任何 mailer 发送或接收消息，则不打印数字。

你可能需要在 `/var/spool/cron/crontabs/root` 中添加条目以初始化统计文件。将 `/dev/null` 复制到统计文件中或对其进行截断以重置计数器。

## 选项

`-c configfile` 指定 `sendmail` 配置文件。

`-f statisticsfile` 指定统计文件。
