# 远程管理木马 (RAT)

一种运行后可为机器提供远程管理的木马。`RAT` 是一种程序，其隐藏意图是远程控制机器。特别是，当程序运行并将其安装为隐藏后台服务时，它就不再经典意义上的木马，现在更多被认为是一个 rootkit（根内核程序）。示例：Office, NetBus, SubServer, Hack'ack。木马：远程管理木马不是病毒。普通大众使用病毒来指代黑客可能使用的任何恶意程序。通常情况下，使用正确的词是徒劳的，但在这种情况下，这种区别是重要的。你是意外感染病毒的，而病毒很少对你的主机做任何事情。相反，当黑客试图用远程管理木马感染你的系统时，该黑客是在针对你个人进行攻击。Windows 机器上的远程管理木马感染变得像病毒一样频繁。一种常见的媒介是文件和打印共享，当用户无意中将他们的系统向全世界开放时。如果黑客拥有硬盘访问权限，他/她可以将木马放在名为“启动”文件夹的位置。然后木将在用户登录时运行。另一种常见的媒介是黑客直接将木马通过电子邮件发送给用户，并带有某些社会工程手段说服他违背直觉去运行它。`http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`
