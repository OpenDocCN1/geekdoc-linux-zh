## 使用 traceroute 进行故障排除

与 `ping` 几乎同样重要的工具是 `traceroute`。该程序映射了 IP 数据包到达目的地所经过的路径。一个数据包在途中可能会通过许多网络设备（通常是网关）。对于互联网来说尤其如此，因为它是由一个接一个网关组成的。当汽车从纽约开到芝加哥时，它会经过几个城镇（将它们想象成网关）。

以下是在网站（`www.debian.org`）上使用 `traceroute` 的示例：

