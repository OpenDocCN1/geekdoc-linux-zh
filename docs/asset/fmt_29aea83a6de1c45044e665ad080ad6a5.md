
在星系的活动核心（具有强光学发射线和非热连续谱的星系）中，X 射线发射通常比正常星系高出几个数量级。在大多数情况下，发射来自星系核心，且基于变异性以及在当前观测极限下缺乏结构（几角秒），必须限制在一个相对较小的区域内。许多天体物理学家认为星系核心是巨大黑洞的位置，至少是太阳质量的 $10^9$–$10^{11}$ 倍，并且来自这些天体的辐射是由于下坠物质释放的引力能。X 射线光度等性质的广泛范围可能反映了黑洞的大小以及下坠物质的可用性。类星体可能代表这种现象的极端情况。许多可观测性质不仅取决于核黑洞的大小，还取决于观测者的视角。参见 QUASAR（类星体）。

星系团是由数百至数千个单个星系组成的引力束缚系统。人们发现此类星系团中星系之间的空间包含热的（大约 $10^7$–$10^9$ K）稀薄气体，该气体在 X 射线中发光，其质量等于（或超过）可见星系的质量。参见 ASTROPHYSICS, HIGH-ENERGY（高能天体物理）；GALAXY, EXTERNAL（河外星系）。

## X 射线晶体学

通过 X 射线衍射技术研究晶体结构。关于 X 射线衍射的实验方面，参见 X-RAY DIFFRACTION（X 射线衍射）。

在结构上，晶体是原子、原子团或分子在空间中的三维周期性排列。如果这种周期性模式延伸贯穿给定的材料样品，则称之为单晶。如果知道构成称为晶胞的三维周期性图案中所有原子的位置，则可以确定任何给定晶体的精确结构。晶体中原子的非常紧密且周期性的排列使其能够作为 X 射线的衍射光栅。参见 CRYSTALLOGRAPHY（晶体学）。

# X射线衍射

**X射线衍射** 指X射线被物质散射时，由于干涉效应导致不同方向上强度发生变化的现象。X射线衍射是固态化学最重要的工具之一，因为它提供了一种强大且易得的方法来确定物质中的原子排列。X射线衍射方法基于以下事实：波长约为1纳米的X射线可以轻易获得，而这一数量级恰好与原子尺寸相当。当X射线束照射到物质上时，所有原子都会产生散射的X射线。这些散射波从样品中的所有原子向四面八方球形扩散，来自不同原子的散射辐射产生的干涉效应使得散射辐射的强度在各个方向上呈现出极大值和极小值。参见[衍射](DIFFRACTION)。

**用途。** X射线衍射的一些用途包括：

- (1) 区分晶体材料和非晶态材料；
- (2) 确定晶体材料的结构（晶轴、晶胞的大小和形状、晶胞中原子的位置）；
- (3) 确定原子内部以及整个晶胞内的电子分布；
- (4) 确定单晶的取向；
- (5) 确定多晶材料的织构；
- (6) 识别晶相并测量相对比例；
- (7) 测量固溶度的极限，并确定相图；
- (8) 测量应变和小晶粒尺寸；
- (9) 测量晶体中各种类型的无序性、非规整性和缺陷；以及
- (10) 确定非晶固体和液体的径向分布函数。

**技术。** 下文讨论了用于研究晶体物质、气体和液体的技术。

**劳厄法。** 劳厄图案使用由工作在35–50 kV的X射线管产生的连续光谱提供的多色X射线。不同的衍射束具有不同的波长，其方向仅由具有米勒指数 *hkl* 的一组晶面的取向决定。透射劳厄图案曾被用于结构测定，但其许多缺点使其实际上已变得过时。另一方面，背反射劳厄图案在晶体取向的研究中仍被大量使用。

**转晶法。** 最初的转晶法应用于布拉格衍射仪中。一束足够单色的光束，其波长约为1 Å，通过狭缝系统进行准直，然后如**图1**所示，照射到单晶的一个大的延伸面上。布拉格衍射仪被广泛用于获取与晶体表面平行的晶面的积分强度的定量测量。将测量室设置在正确的2θ角，并配备足够宽的狭缝，以便所有从晶体反射的辐射都能进入并被测量。晶体以恒定的角速度通过布拉格定律位置旋转，测量在此过程中电离室接收到的总衍射能量。测量室设置在峰值两侧进行的类似读数提供了背景校正。

**气体。** 气体和液体被发现会产生X射线衍射图案，其特征是一个或多个光晕或干涉环，通常有些漫射。这些衍射图案与玻璃和非晶固体的类似，是由干涉效应引起的，这些效应既取决于每个原子或分子的电子分布，也取决于它们在系统中的相对位置。

对于单原子气体，产生散射强度分布的显著干涉效应仅由每个原子核周围的电子分布产生。这些产生所谓相干强度的干涉效应是由于原子不同部分中电子散射的个体波的干涉结果。原子的电子分布用特征性的原子散射因子来描述，该因子定义为原子散射的合振幅与自由电子在相同条件下散射的振幅之比。

**液体。** 与稀薄气体和晶体固体不同，无法从衍射数据中推导出液体结构的明确、详细的描述。尽管如此，液体的衍射研究仍提供了非常有用的信息。通常，实验结果不是通过与计算各种模型得到的理论分布进行比较，而是以径向分布函数的形式提供，该函数指定了系统中任何参考原子或电子的密度随径向距离的变化，而无需对结构做出任何先验假设。从径向分布函数中可以得出：

- (1) 结构中发生频率最高的平均原子间距离，对应于第一、第二以及可能的第三近邻的位置；
- (2) 距离的分布；以及
- (3) 每个原子间距离的平均配位数。

但强度会降低两到三个数量级。其他替代方案包括放射性源和同步辐射。

另一种方法用于电子显微镜和电子探针中，它将电子束直接照射在样品上，在电子轰击下，每种元素产生其自身的X射线光谱，就像在X射线管中一样。参见[电子显微镜](ELECTRON MICROSCOPE)。

检测器的输出信号被送入分析仪，光子计数存储在与这些光子能量相关的内存位置（通常使用1024–8192个通道）。这也允许在阴极射线管屏幕上视觉观察累积的光谱和同时计数过程。分析仪通常配备光标标记，以轻松识别光谱中的峰值。计算机存储器可用于存储光谱计数，从而提供对计算机例程的有效访问，以进行进一步的数据评估。

电子探针广泛用于小区域的元素分析。使用1微米（或更小）的电子束，X射线光谱通过聚焦（弯曲）晶体衍射仪或能量色散固体探测器进行分析。通常使用两到三个光谱区域来覆盖三个不同的光谱区域。可以检测到轻至铍、硼和碳的轻元素。该方法的一个重要应用是具有几立方微米空间分辨率的点对点分析。通过移动样品来确定元素分布，可以制作任何元素的X-Y图。参见[电子探针显微分析](ELECTRON-PROBE MICROANALYSIS)。 [W.P.; M.Man.]

# X射线荧光分析

一种用于固态或液态材料化学成分分析的非破坏性物理方法。样品被光子或具有足够能量的带电粒子辐照，使其元素发射（荧光）其特征X射线线光谱。检测系统允许确定发射线的能量及其强度。通过其谱线能量或波长识别样品中的元素用于定性分析，而强度与其浓度相关用于定量分析。计算机在该领域得到广泛应用，既用于自动化数据收集，也用于将X射线数据转化为重量百分比和原子百分比化学成分或与面积相关的膜质量。参见[荧光](FLUORESCENCE)。

待分析的材料可以是固体、粉末、液体或薄箔和薄膜。晶体状态通常不影响分析，化学键状态也不影响分析，但对于非常轻的元素除外。所有原子序数大于12的元素都可以在0.1到100 wt %的浓度范围内进行常规分析。对于原子序数较低（4–11）的元素或更低浓度的分析，以及微量分析，需要特殊技术。每种元素所需的分析计数时间从几秒到几分钟不等，具体取决于样品特性和所需精度，但对于微量分析和薄膜，时间可能会长得多。结果与湿化学和其他分析方法的良好一致。对于大多数无机材料，该方法通常是破坏性的，因为适当制备的样品在分析过程中不会发生改变。

产生X射线光谱用于荧光分析的两种一般方法是光子激发和带电粒子激发。最常见的方法是将样品暴露于标准X射线管发出的强光谱中。这有时通过使用X射线管外的二次靶材（或单色器）来激发荧光来修改。这具有选择最接近待分析元素吸收边的最有效能量，并减少或不激发其他干扰元素的优点。
