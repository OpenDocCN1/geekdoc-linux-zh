
## 描述

Korn Shell
`print`内置函数是 Korn Shell 用于显示 `arg` 的机制。在没有选项或使用 `-` 或 `--` 时，参数将按照 `echo(1)` 描述的方式打印到标准输出。。除非输出文件未打开写入，否则退出状态为 0。

## 选项

- `-n` 抑制输出中的换行符。
- `-R` 忽略 `echo` 的转义约定。`-R` 打印除 `-n` 以外的所有参数。
- `-p` 将参数写入通过 `|` 的管道。
- `-s` 将参数写入历史文件而不是标准输出。
- `-u [n]` 使用 `n` 参数指定放置输出的文件描述符。默认为 1。

## printenv — 显示当前环境变量

### 概要

`/usr/ucb/printenv [variable]`

## 描述

使用 `printenv` 命令打印环境中的变量。如果指定了变量，则只打印其值。

## 示例

以下示例显示 `EDITOR` 环境变量的值。
```
castle% printenv EDITOR
/usr/dt/bin/vi
castle%
```

## 属性

有关以下属性的描述，请参见 `attributes(5)`：

| 属性类型 | 属性值 |
|---|---|
| 可用性 | SUNcpu |

`csh(1)`, `echo(1)`, `sh(1)`, `stty(1)`, `tset(1)`, `attributes(5)`, `environ(5)`

## 诊断

如果指定的变量未定义，`printenv` 返回退出状态 1。

## printf — 格式化输出

### 概要

`/usr/bin/printf format [argument...]`

## 描述

`printf` 命令将格式化操作数写入标准输出。参数操作数根据 `format` 操作数进行格式化。

### 操作数

`format` 是用于写入剩余操作数的格式字符串。参见 `formats(5)` 手页，但有以下例外：

- 在转换规范以外的任何上下文中，将格式字符串中的空格字符视为输出的普通字符。
- 将格式字符串中的 delta 视为 delta 字符而不是空格字符。
- 除了转义序列 `\\`, `\a`, `\b`, `\f`, `\n`, `\r`, `\t`, `\v` 以及 `\ddd`（其中 `ddd` 是一个到三位的进制数），写入由进制数指定的字节。
- 不在转换规范的输出前后留空格。如果参数操作数无法完全转换为相应转换规范的内部值，则向标准错误写入诊断消息，不要以状态 0 退出，继续处理剩余操作数，并将检测到错误时的值写入标准输出。
- 不在转换规范的输出前后留空格。如果字符序列以 `*` 开头但不是有效的转换规范，则行为未定义。反斜杠后跟任何其他序列的解释未定义。支持以下反斜杠序列：
- 将 `formats(5)` 手页中列出的转义序列 `\\`, `\a`, `\b`, `\f`, `\n`, `\r`, `\t`, `\v` 转换为它们代表的字符。
- 将 `\ddd`（其中 `ddd` 是一个到三位的进制数）转换为由进制数指定的字节。
- 写入 `\c` 并忽略字符串中的任何剩余字符。
从转换后的字符串写入字节，直到达到指定的精度数。如果省略精度，则视为无限，从而将所有字节写入字符串末尾。

## 使用

注意，`printf` 命令与其作为基础的 `printf(3S)` 函数一样，在使用 `%c` 转换规范或在 `%b` 或 `%s` 转换规范中指定精度时，对于处理多字节字符没有特殊规定。应用程序程序员在字符集中存在多字节字符时，使用这些功能时应非常谨慎。

如果参数操作数没有被完全用于 `c s` 转换，或者字符串操作数的第一个或第二个字符被用于获取字符的数值值，则不被视为错误。

## 示例

以下示例会提醒用户，然后打印并读取一系列提示。

```
printf "\aPlease fill in the following: \nName: "\nread name

printf "Phone number: "\nread phone
```

以下示例从文件中读取一个正确和错误答案的列表，正确地计算百分比并将其打印出来。数字右对齐，并由单个制表符分隔。百分比保留一位小数的精度。

```
while read wrong;

percent=$(echo scale=1;($right*100)/($right+$wrong) | bc

printf "%%2d right\%2d wrong\t(%%s)\n"

done < database_file

printf " $wrong percent
```

## 命令

```
printf "%5d%4d\n" 1 21 321 4321 54321
```

产生

```
   1 21

321432

54321 0
```

注意，格式操作数被使用了三次以打印所有给字符串，并且 `printf` 提供了一个 0 来满足最后一个 `%4d` 转换规范。

当产生数值输出时如果检测到转换错误，`printf` 命令会通知用户；因此，在 32 位位补码整数的实现上，当指定 `%d` 为格式操作数时，可以预期以下结果：

| 标准参数 | 输出 | 诊断输出 |
| :--- | :--- | :--- |
| 5a | 5 | printf: 5a not completely converted |
| 9999999999 | 2147483647 | printf: 9999999999: Results too large |
| -9999999999 | -2147483648 | printf: -9999999999: Results too large |

* 无符号

| 标准参数 | 输出 | 诊断输出 |
| :--- | :--- | :--- |
| ABC | 0 | printf: ABC expected numeric value |

注意，标准输出上显示的值是预期函数 `strtol(3)` 的返回值。`%u` 与 `strtol(3)` 之间存在类似的对应关系，`%e`, `%f`, `%g` 与 `strtod(3)` 之间也存在。

在使用 ISO/IEC 646:1991 标准作为底层字符集的 locale 中，命令 `printf("%d\n" 3 +3 -3 '\"+3" "-3")` 产生：

- -3 常量 3 的数值值。
- -3 常量 3 的数值值。
- -3 常量 -3 的数值值。
- -51 ISO/IEC 646:1991 标准代码集中字符 3 的数值值。
- -43 ISO/IEC 646:1991 标准代码集中字符 + 的数值值。
- -45 ISO/IEC 646:1991 标准代码集中字符 - 的数值值。

> 注意 — 在具有多字节字符的 locale 中，字符的值旨在是该字符的等效 `wchar_t` 表示的值。

如果操作数无法完全转换为适用于相应转换规范的内部值，则会将诊断消息写入标准错误，并让命令返回 0 退出状态，继续处理任何剩余的操作数，并将检测到错误时累积的值写入标准输出。

## 环境变量

请参阅 `environ(5)` 了解以下影响 `printf` 执行的环境变量描述：`LC_COLLATE`, `LC_CTYPE`, `LC_MESSAGES`, `LC_TIME`, `TZ` 和 `NLPATH`。

## 退出状态

- 0 成功完成。
- >0 发生错误。
