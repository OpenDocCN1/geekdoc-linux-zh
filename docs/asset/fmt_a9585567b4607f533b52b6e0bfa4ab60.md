# 1676 形态发生目 (Phytomostoida)

是指形态发生群体。鸟类和哺乳动物等群体都是形态性的，它们与其他脊椎动物之间关系密切。然而，其他传统群体（如爬行动物）被描述为非形态性的（所谓的“小群”，即成员与彼此之间的关系比与其他物种的关系更紧密的群体），它们构建了化石的形态并揭示了它们的独特性。对灵长类进行仔细控制的研究表明，在功能灭绝物种的形态、习性和偏好方面具有巨大的前景。自1970年以来，行为医学、骨科、放射学和神经科学的先进技术和概念帮助在灵长类学中建立了一个新范式。

基于形态的分类被称为分类学。分类对于理解生物的分布和演化也至关重要。了解哪些生物之间相互相关，有助于传记者描述它们之间的关系，并重构群体及其行为的空间历史。分类学分类。

### 分子生物学。遗传密码解码后分子生物学的爆发帮助人类学家测试人类与类人之间的倾向，以及其他个体个体之间以及与其他人的关系。当物种在早期阶段分裂时，某些“分子钟”被证明特别有用。假设时钟以早期速率变化并给出一个著名的分化日期，就可以计算出一个物种自另一个物种分离以来的时间。参见分子人类学。

正则海胆序，如海胆目（`Echinidea`），其特征是不完全的水管、由一个或多个外壳组成的钙质软体（出现于侏罗纪），以及具有可移动齿的强力灯笼。它们出现在侏罗纪，可能是并系的。从化石中知的现存两个群体是日本北部直径为30至40 mm（10–15英寸）的`Stomunculus`，以及印度-太平洋沿岸岩石岸的常见居民。它们是食碎性的。参见海胆总目（`ECHOINOIDEA`）。

### 灵长类行为。尽管根根于比较行为，但进化灵长类学对体人类学也很重要。这些领域对早期研究领域贡献良多。野外研究的目标是预测其栖息灵长类的行为、习性和社会结构。由于与人类有密切的遗传关系，黑猩已成为早期人类社会最流行的模型。它们行为的各个方面为人类行为提供了不同的模型。

### 体质人类学。涉及人类和灵长类演化、人类行为的生物学基础以及人类变异意义意义标题。有些人将该领域称为人类学，以与其他生物学划清。体质人类学很大程度上是美国和英国的发明；在许多其他国家，体质人类学家是唯一研究史前人类行为方面的人类学家。

### 人类变异。“变异”一词在人类学中被广泛使用，因为族的概念非常敏感。它带有许多负面内涵。相反，研究人员应该研究变异的基因序列和生物学。这些基因型和表型信息将根据每个环境的历史和环境力量进行解释。参见人类变异。

### 古物学。通过化石、人工制品和墓葬地对人类演化进行多学科研究。古物学家组织探险并指导发掘，以发现化石，然后对这些遗骸进行分析和重建。这包括解剖描述、与物种的比较以及在系统发育中的定位。参见海洋化石（`FOSSIL MARINES`）。

### 骨骼生物学。骨骼生物学有助于反映灵长类学的功能方法，并用于确定尺寸和形状（连续测量），使我们能够记录古代种的局部历史。

古物学在人类和灵长类解剖方面提供了更多细节，以及利用标本来排序和解释它们的历史。除了解剖描述外，还需要对遗骸的意义进行检查，并在可能的情况下进行统计学显著性测试。由于许多化石的碎片性，主要问题之一是将这些发现与之前描述的物种联系起来，或者分别代表新的物种。
