
定义在 `ctypes.util` 中。返回与库名称对应的路径名。`name` 是不带后缀的库名，例如 `'libc'`、`'libm'` 等 `/usr/lib/libc.so.6`。此函数的行为取决于系统，并取决于共享库的底层配置和环境（例如 `LD_LIBRARY_PATH` 的设置和其他参数）。如果找不到库，则返回 `None`。

# 外部函数

由 `CDLL()` 类创建的共享库实例作为底层 C 库的代理。要访问库的内容，只需使用属性查找（运算符）。例如：

# 嵌入 Python 解释器

```python
>>> import ctypes
>>> libc = ctypes.CDLL("/usr/lib/libc.dylib")
>>> libc.rand()
16807
>>> libc.atoi("12345")
12345
>>>
```

在这个示例中，`libc.rand()` 和 `libc.atoi` 等操作直接调用加载的 C 库中的函数。

`ctypes` 假设所有函数都接受 `int` 或 `char *` 类型的参数并返回 `int` 类型的值。因此，尽管之前的调用“成功”了，但对其他 C 库函数的调用并没有按预期方式工作。例如：

```python
>>> libc.atoi("34.5")
-1073746168
>>>
```

为了解决这个问题，可以通过以下属性设置任何外部函数的类型签名和处理：

- `func.argtypes`: 一个 `ctypes` 数据类型的元组（此处有描述），描述 `func` 的输入参数。
- `func.restype`: 描述 `func` 返回值的 `ctypes` 数据类型。返回 `void` 的函数使用 `None`。
- `func.errcheck`: 一个 Python 可调用对象，接受三个参数（`result`, `func`, `args`），其中 `result` 是外部函数返回的值，`func` 是外部函数本身的引用，`args` 是输入参数的元组。该函数在外部函数调用后被调用，可执行错误检查和其他操作。

这里是 `atof()` 函数接口的示例，如上一个示例所示：

```python
>>> libc.atoi.restype=ctypes.c_double
>>> libc.atoi("34.5")
34.5
>>>
```

`ctypes.c_double` 是预定义数据类型的引用。下一节将描述这些数据类型。

# 替代类型构造方法

所有 `ctypes` 类型（如 `c_int`、`POINTER` 和 `for_`）都具有一些类方法，用于从内存地址和其他对象创建类型的实例。

```
ty.from_buffer(source, offset)
```

创建一个 cypes 类型 `ty` 的实例，该实例与 `source` 共享相同的内存。`source` 必须是任何支持可写缓冲区接口的其他对象（例如 `bytearray`、`array` 模块中的对象、`mmap`），`offset` 是从缓冲区开始使用的字节数。

```
ty.from_buffer_copy(source [, offset])
```

与 `ty.from_buffer()` 相同，区别是会创建内存副本，且 `source` 可以是只读的。

```
ty.from_address(address)
```

从指定的整数原始内存地址 `address` 创建 cypes 类型 `ty` 的实例。

```
ty.from_param(obj)
```

从 Python 对象 `obj` 创建 cypes 类型 `ty` 的实例。只有当传递的 `obj` 可以被适配相应的类型时，此方法才有效。例如，Python 整数可以转换为 `c_int` 实例。

```
ty.in_dll(library, name)
```

从共享库中的符号创建 cypes 类型 `ty` 的实例。`library` 是由 `CDLL` 类创建的对象的加载库名称。`name` 是符号的名称。此方法可以用于为库中的全局变量封装 cypes 包装器。

下面的示例展示了如何为库 `libexample.so` 中的全局变量 `int status` 创建引用。

```
libexample = ctypes.CDLL("libexample.so")
status = ctypes.c_int.in_dll(libexample, "status")
```

# 工具函数

`ctypes` 定义了以下工具函数：

`addressof(cobj)`

返回作为整数形式的 `cobj` 内存地址。`cobj` 必须是 `ctypes` 类型的实例。

`alignment(ctype_or_obj)`

返回 `ctypes` 类型或对象的对齐要求。`ctype_or_obj` 必须是 `ctypes` 类型或某个类型的实例。

`cast(cobj, ctypes)`

将 `ctypes` 对象 `cobj` 转换为 `ctypes` 中的一种新类型。这仅适用于指针，因此 `cobj` 必须是指针或数组，且 `ctypes` 必须是指针。

`create_string_buffer(init, size)`

创建一个作为 `c_char` 类型数组的可变字符缓冲区。`init` 是整数或表示初始内容的字符串。`size` 是可选参数，当 `init` 为字符串时指定要使用的大小。默认情况下，`size` 被设为大于 `init` 中的字符数。Unicode 字符串使用默认编码编码为字节。

`create_unicode_buffer(init [, size])`

与 `create_string_buffer()` 相同，区别是创建了一个类型为 `c_wchar` 的 `ctypes` 数组。

`get_errno()`

返回 `ctypes` 拷贝的 `errno` 的当前值。

`get_last_error()`

返回 Windows 上 `ctypes` 拷贝的 `LastError` 的当前值。
