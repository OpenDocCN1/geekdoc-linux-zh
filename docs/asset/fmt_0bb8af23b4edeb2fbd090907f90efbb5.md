## 创建新文件系统

假设我们想将闪盘格式化为 Linux 原生文件系统，而不是现在的 FAT3 系统。这涉及到两个步骤：

1. （可选）如果现有布局不符合要求，创建一个新的分区。
2. 在驱动器上创建一个空文件系统。

> **警告** 在接下来的练习中，我们将格式化闪盘。请使用您熟悉的驱动器，因为它将被删除！再次强调，务必指定系统中正确的设备名称，而不是文中显示的。不遵守此警告可能会导致格式化（即删除您的驱动器！）！

## 使用 fdisk 操作分区

`fdisk` 是许多可用程序（包括命令行和图形界面）之一，允许我们在非常底层与磁盘设备（如硬盘和闪盘）直接交互。通过此工具，我们可以在设备上编辑、删除和创建分区。为了操作我们的闪盘，必须首先卸载（如果需要），然后按照如下方式调用 `fdisk` 程序：

```
@melinux~$ sudo umount /dev/sdb1
@melinux~$ sudo fdisk /dev/sdb
```

注意我们必须以整个设备指定设备，通过分区编号。程序启动后，我们将看到以下提示：
