## 配置 IP 地址和路由

在网络用于内部或外部通信之前，必须配置 IP 地址和路由。在这里，我们将向你展示如何进行 IP 地址和路由配置，以便你迅速让你的网络与彼此以及外部世界通信。

### 配置 IP 地址

IP 地址是分配给网络上每个设备的唯一标识符，允许它们进行通信。

### 配置 IP 地址

在这里，我们将向你展示如何配置 IP 地址和路由进行导航，以便你迅速让你的网络与彼此以及外部世界通信。

### 静态 IP

分配静态 IP。以下是配置静态 IP 的示例：

```
$ ip addr add 192.168.1.10/24 dev eth0
```

### 删除静态 IP

删除静态 IP 地址的示例：

```
$ ip addr del 192.168.1.10/24 dev eth0
```

### 删除 IP 地址

删除删除 IP 地址的示例：

```
$ ip addr del 192.168.1.10/24 dev eth0
```

### 修改 IP 地址

修改 IP 地址的示例：

```
$ ip addr add 192.168.1.11/24 dev eth0 && ip addr del 192.168.1.10/24 dev eth0
```

### 添加默认路由

添加默认路由的示例：

```
$ ip route add default via 192.168.1.1
```

### 删除默认路由

删除默认路由的示例：

```
$ ip route del default
```

### 添加静态路由

添加静态路由的示例：

```
$ ip route add 192.168.2.0/24 via 192.168.1.1
```

### 删除静态路由

删除静态路由的示例：

```
$ ip route del 192.168.2.0/24
```

### 查看路由表

查看路由表的示例：

```
$ ip route show
```

### 配置路由

在 YAML 中配置路由的示例：

```yaml
network:
  version: 2
  ethernets:
    eth0:
        addresses:
          - 192.168.1.10/24
        routes:
          - to: default
            via: 192.168.1.1
```

}

启动并启用 Keepalived：

```
$ sudo systemctl start keepalived
```

```
$ sudo systemctl enable keepalived
```

## 实现持久化配置

使用 `netplan` 确保配置在重启后依然有效，例如：

```yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 10.1.1.1/24
      gateway4: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
      routes:
        - to: 10.1.2.0/24
          via: 10.1.1.254
```

```
$ sudo netplan apply
```

IP 地址和路由的正确配置创建了强大的网络架构，允许 AlphaProject 高效地进行内部和外部通信。网络响应变化和维护高可用性的能力取决于你对路由策略的理解和实现。
