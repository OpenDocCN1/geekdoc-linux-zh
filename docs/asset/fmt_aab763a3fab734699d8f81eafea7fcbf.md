# teapop-mysql

强大且符合 RFC 标准的 POP3 服务器。Teapop 是一个 POP–3 服务器（符合 `RFC1939` 和 `RFC2249`）：

- 虚拟主机（“YOP”）
- 灵活身份验证（可以从 `mysql`、`PostgreSQL`、`htpasswd` 文件、系统密码数据库... 获取用户名/密码；LDAP 将推出）
- APOK
- `mbox` 和 `Maildir` 风格的池
- 使用 X-UILED处理器
- 忽略 UW-IMAP 控制邮件
- 从 indent 或独立模式运行
- 如果你懂操作，有各种可能的 POP–before–SMTP 方法

此包中的二进制文件包含对 `mysql` 数据库验证的支持。如果你完全不需要验证，请使用 `teapop` 包；如果你需要使用 PostgreSQL 数据库验证，请使用 `teapop–pgsql` 包。源自 Debian 3.0r APT

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# teapot-pgsql

强大且符合 RFC 标准的 POP3 服务器。Teapot 是一个 POP–3 服务器（符合 `RFC1939` 和 `RFC2240`），支持：

- 虚拟主机（“VPOP”）
- 灵活身份验证（可以从 `mysql`、`PostgreSQL`、`htpassword` 文件、系统密码数据库 获取用户名/密码；LDAP 将推出）
- APOP
- `mysql` 和 `Maildir` 风格的池
- 使用 X-UIDL 头
- 忽略 UW–IMAP mboxes
- 从内部或独立模式运行
- 如果你懂操作，有各种 BEFORE–SMTP 方法

此二进制文件包含对 PostgreSQL 数据库验证的支持。如果你不需要数据库验证，请使用 `teapot` 包；如果你需要使用数据库验证，请使用 `teapot–pgsql` 包。源自 Debian 3.0r

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
