
# 美洲间海的洋流
美洲间海的洋流主要受墨西哥湾流系统支配。表层水通过小安的列斯群岛的通道流入该海，并在较小程度上通过古巴和海地之间的向风海峡以及波多黎各和安圭拉之间的阿内加达海峡流入。这些流入的水形成加勒比海流，向西北流入墨西哥湾，通过尤卡坦海峡。参见：海洋环流。
来自南美洲几条河流（特别是奥里诺科河和亚马逊河）的径流漂移穿过美洲间海，并将物质携带至距三角洲数千公里之外。巨大的三角洲受到人为活动的强烈影响，但它们仍然是丰富渔场和密集社区的来源。由于该海潮汐范围小，大多数三角洲是波浪主导的地质特征。参见：三角洲；地震；海洋渔业；板块构造；潮汐。G.A.Mo.

## 内含子
在分裂基因中，这部分包含在核糖核酸 (`RNA`) 转录物中，但在 `RNA` 处理过程中从转录物内部去除并迅速降解。分裂基因是指其信使 `RNA` (`mRNAs`) 或结构 `RNA` 中出现的部分（称为外显子）在基因中不连续，而是由不编码 `RNA` 成熟过程中幸存部分的脱氧核糖核酸 (`DNA`) 序列隔开的基因。大多数真核基因和少数原核基因是分裂的。这些不仅包括大量不同的蛋白质编码基因，还包括编码酵母和青蛙等多样化真核生物转运 `RNA` (`tRNAs`) 的基因，以及编码某些原生生物核糖体结构 `RNA` 的基因。内含子也存在于低等真核生物的线粒体基因和某些叶绿体基因中。参见：外显子。
基因中内含子的数量变化很大，从结构 `RNA` 基因的 1 个到胶原蛋白的 50 多个。内含子的长度、位置和组成在基因之间也有很大差异。然而，一般而言，不同生物同源基因的大小和位置——而非 `DNA` 序列——是可比的。这意味着内含子在真核生物进化的早期阶段就在基因中确立，虽然其核苷酸序列不是非常重要，但其存在、位置和大小具有意义。
关于内含子的角色和进化的推测主要基于蛋白质结构域和由间隔内含子定义的基因外显子之间观察到的相关性。例如，酶酒精脱氢酶 (`ADH`) 有两个结构域，一部分结合酒精，另一部分结合酶辅因子烟酰胺腺嘌呤二核苷酸 (`NAD`)。`ADH` 基因有一个内含子，清晰地分隔编码每个结构域的核苷酸序列，像这样的基因序列排列并不罕见。有人提出，内含子之所以在真核生物基因（以及在细菌中有限程度）中确立，是因为它们促进了编码不同功能单元的基因部分的遗传洗牌或重排，从而创造出具有新属性组合的新基因。内含子允许遗传重组发生在编码单元之间而非内部，从而提供了一种通过功能子单元或构建模块的整体重排而非实际的蛋白质编码 `DNA` 序列的偶然重组来进行遗传进化的手段。参见：基因；遗传密码；重组（遗传学）。PMMRJ.

## 入侵生态学
研究由人类将物种从一个地区或大陆转移到另一个地区或大陆后的建立、扩散和生态影响的学科。生物入侵作为一种基本研究的工具，用于研究种群的生态学和进化以及新的生物相互作用，以及作为与生物多样性保护相关的保护问题，已引起关注。非本地（也称为异源、外来或非本土）物种的入侵是负责管理和保护自然及人工生态系统的严肃问题。参见：生态学；种群生态学。
生态学家对引入物种和入侵物种进行了区分，前者指在任何自然栖息地之外生长的任何物种，包括栽培或驯化生物，后者指在野外建立自由生活种群的那部分引入物种。根据一些研究的估计，绝大多数引入物种（约 90%）不会变成入侵物种。虽然某些问题入侵者，如斑马贻贝 (`Dreissena polymorpha`)，会造成巨大的经济和生态成本，但其他引入物种通常被认为是有利的补充，例如大多数主要粮食作物。
有意引入植物主要由园艺业推动，以满足公众对新景观的需求。然而，植物也因农业、林业和土壤侵蚀控制而被引入。有意引入动物包括为运动狩猎或捕鱼引入的游猎物种。与这些例子不同，有意引入也可以包括那些不一定旨在形成自我维持种群的物种，例如由水族馆或宠物贸易推广的物种。
偶然引入的物种是“搭便车者”。船舶压载水是一个主要媒介，最初是携带陆地无脊椎动物和植物种子或根状的土壤形式，更近则是携带外来港口浮游生物幼虫的压载水形式。虽然许多物种以这种或类似方式被引入，但搭便车者是那些绕过进口和检疫措施的 unwanted 寄生虫。例如，许多非本地农业杂草已随受污染的种子批被进口。
某些类型的栖息地似乎比其他地方有更多已建立的非本地物种。必须确定使一个场所易于入侵的特征。例如，岛屿对入侵特别脆弱，岛屿通常起始时常住物种较少，因此推测较简单的系统对入侵者的生物抗性较低。也就是说，引入物种不太可能遇到能够排除它的常住竞争者、捕食者或病原体。生物抗性的概念也与复杂性赋予自然系统稳定性的概念一致。参见：入侵生态学。
关于可入侵性的第二个概括是，具有高水平人为扰动的生态系统，如农田或路边，似乎更易被入侵。这些场所开放空间的周转增加可能为新物种的建立提供更多机会。另一种解释是，许多适应欧洲人为栖息地的物种只是随着人类在新地方重建这些栖息地而随后到来。这些物种在利用人类扰动方面自然地比本地物种具有优势。生态系统管理提倡者的最后一个建议是，扰动（在此背景下包括自然扰动制度的破坏，例如火灾抑制）
削弱生态系统的固有抵抗力，并促进物种入侵。
入侵物种可能产生多种不同类型的影响。首先，它们会影响本地生物性状的和行为（例如，导致与其相遇的本地物种在饮食、体型或形状上发生转变）。其次，影响可能发生在种群层面，要么通过改变本地种群的丰度，要么通过改变其遗传组成。入侵物种与近缘本地物种之间的杂交可能导致渐渗和遗传污染。当本地物种基因组的独特部分被淹没时，最终结果可能是该本地物种在事实上的灭绝。第三，影响可能发生在群落生态层面。当个别种群因入侵物种的竞争或捕食而减少甚至灭绝时，结果是受侵染区域总体生物多样性的下降。最后，入侵者不仅影响其他物种，还会影响生态系统的物理特征。
决定哪些物种影响最大的两个主要因素是丰度和特殊特性。达到极高密度的入侵者会压倒所有其他生物体。其他物种则具有特殊的性状，导致其影响与其数量不成比例地巨大。
鉴于非本地物种在经济和保护方面的重要性，入侵生态学的大量研究集中于入侵物种的预防、根除和控制，以及控制后的场地恢复。研究强调了早期检测和根除问题物种的重要性。生物防治被吹捧为除草剂和杀虫剂的环境友好型替代方案。参见“ALIEN ECOLOGY”（外来生态学）；“ECOLOGICAL COMMUNITIES”（生态群落）；“ECOLOGICAL SUCCESSION”（生态演替）；“SPECIATION”（物种形成）；“SPECIES CONCEPT”（物种概念）。

## 库存控制
管理货物订购和储存的时机及数量的过程，以便能够以满意且经济的方式满足需求。库存是等待被使用以应对预期需求的累积商品。库存控制策略是关注针对每种不同类型的物品“何时”和“订购多少”这两个问题的替代方案的利弊权衡的决策规则。
持有库存的可能原因包括：
- 对未来需求量的不确定性；
- 对供货提前期持续时间的不确定性，从而对生产持续性提供更大保障；
- 利用在制品库存作为对冲某些为其他机器供料的机器故障的措施；
- 对商品未来价格的投机。
持有库存的其他一些重要好处包括：
- 降低订货成本和生产准备成本（随着订单规模变大，这些成本发生的频率降低，进而产生较高的库存）；
- 大批量订购的价格折扣；
- 运输规模经济；
- 维持稳定的生产率和劳动力水平，否则这些指标可能因季节性需求波动而过分波动。
持有库存的好处必须与持有库存的成本进行比较。持有成本包括以下要素：
- 被库存占用的资金的成本；
- 拥有或租用仓库或其他存储空间的成本；
- 物料搬运设备和人工成本；
- 潜在的过时、盗窃和损耗成本；
- 对库存征收的财产税；
- 以及安装和运行库存控制策略的成本。
库存按其年度成本列示时，往往表现出类似于帕累托定律和分布的相似性。产品线的很小一部分可能占库存总预算的很大比例（它们被称为 A 类物品）。
连续审查法和固定间隔法是库存控制系统的两种不同运作模式。前者意味着每次从库存中提取物品时都会更新记录。当库存水平降至称为再订货点的临界水平时，就会发出补充订单。在固定间隔策略下，不需要知道每个时间点的库存状态。审查是定期进行的。
未来需求的不确定性在库存成本中起着主要作用。这就是为什么能够更准确预测未来需求可以大幅降低企业的库存支出的原因。反之，使用无效的预测方法会导致所需物品过度短缺和不必要物品的高水平。
物料需求计划（`MRP`）系统（利用计算机文件和数据处理设备的生产-库存调度软件）正得到广泛应用。`MRP` 系统尚未利用数学库存理论。它们承认多阶段制造中相关需求的含义（其中包括不规则的生产需求）。通过整合物料清单、最终产品的既定生产需求和库存记录文件，`MRP` 系统生成部件、分总装和最终产品的完整生产-库存日程表，同时考虑提前期要求。`MRP` 已被证明是制造商的有用工具，尤其是在总装作业中。

## 逆散射理论
一种旨在从散射场知识中确定散射物体或相互作用势能理论的逆向问题。这是与直接散射理论相反的问题，在直接散射理论中，散射振幅是由包括势能在内的运动方程确定的。运动方程通常是非线性（算子值）散射问题。参见“SCATTERING OBJECTS (ATOMS AND MOLECULES)”（散射物体（原子和分子））；“SCATTERING EXPERIMENTS (NUCLEI)”（散射实验（原子核））。
逆散射理论分为两种类型：
- （1）纯逆问题，当数据由完整的、无噪声的散射振幅信息组成时；
- 以及（2）应用逆问题，当给出不完整且受噪声破坏的数据时。
