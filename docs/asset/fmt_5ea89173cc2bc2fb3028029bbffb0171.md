
## 描述
`install` 命令最常用于 `makefiles`（参见 `make(1S)`），用于将文件安装到特定位置或在文件系统中创建目录。每个文件都通过复制到相应的目录来安装。`.install` 不使用特殊权限将文件从一个地方复制到另一个地方。

这意味着：
- 你必须拥有读取要安装的权限权限。
- 你必须拥有复制到目标目录的权限。
- 如果你想使用 `-m` 选项，你必须拥有更改最终复制文件模式的权限。
- 如果你想用 `-u` 或 `-g` 选项指定安装文件的所有者，你必须是超级用户。如果你不是超级用户，则安装的文件将归你所有，无论原始文件的所有者是谁。

如果你没有指定选项或目录（`dirx ...`），`install` 会一组默认目录（`/bin`, `/usr/bin`, `/etc`, `/lib` 和 `/usr/lib`，按顺序排列）中搜索与 `file` 同名的文件。当它找到第一个匹配项时，`install` 会发出消息说明它正在覆盖该文件并继续操作。如果未找到文件，程序将说明这一点并退出。

## 手册页语法

### 命令语法
除非另有说明，手册页概要中描述的命令接受以下格式：

`name [-option...][cmdarg...]`

其中
- `-option` 或 `cmdarg` 不是必需的。
- 表示 `option` 或 `cmdarg` 的多次出现。
- 指定可执行文件的名称。
- 表示相互依赖的选项和参数，以便包含的内容被视为一个单元。
- 始终由连字符 `noargletter...` 或 `argletter{...}` 引导。单个字母代表无参数的选项。注意你可以在一个连字符后分组多个 `noargletter`（参见规则 5）。
- 单个字母代表需要参数的选项。
- 参数（字符字符串）要满足先前的 `argletter`。`argletter` 之后的 `optargs` 组必须用逗号或制表符和字符进行分隔（参见规则 8）。
- `-` 指定路径名（或其他命令参数），其不以连字符 `-` 或连字符本身开头，这表示标准输入。

### 命令语法标准
并非所有当前命令都遵循这些命令语法规则，但所有新命令都遵守。所有的 shell 过程都应该使用 `getopts(1)` 解析位置参数并检查合法选项。`getopts` 支持规则3-10。其他规则的执行必须由命令本身完成。

- 命令名称（上述 `name`）长度必须在二到九个字符之间。
- 命令名称只能包含小写字母和数字。
- 选项名称（上述 `option`）长度必须为单个字符。
- 所有选项都必须由连字符 `-` 前导。
- 无参数的选项可以分组在一个连字符 `-` 之后。
- 选项后的第一个选项参数（上述 `optarg`）必须由制表符或空格字符前导。

## 诊断

在终止时，每个命令返回两个字节的状态，一个由系统提供并指示终止原因，另一个（在“正常”终止的情况下）由程序提供 [参见 `wait(3B)` 和 `exit(2)`]。前者字节在正常终止时为 0；后者通常为 0 表示执行成功，非零则表示存在问题，如错误参数、坏数据或不可访问的数据。它被通俗称为“退出代码”、“退出状态”或“返回代码”，且仅在涉及特殊约定时进行描述。在本书中，每个命令的“退出状态”描述了命令终止时返回的值。
