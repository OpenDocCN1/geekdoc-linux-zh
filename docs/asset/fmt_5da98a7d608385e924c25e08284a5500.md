## elif

```
if Linux command
then
    commands
elif Linux command
then
    commands
else
    commands
fi
```

`elif` 结构允许你嵌套 `if-then-else` 操作。`elif` 结构代表 "else if"。通过 `elif`，你可以在几个替代方案之间进行选择。第一个替代方案由 `if` 结构指定，随后是其他替代方案，每个方案由其自己的结构指定。最后一个 `elif` 结构的替代方案由 `else` 指定。如果第一个 `if` 结构的测试（一个 Linux 命令）失败，控制将传递到下一个 `elif` 结构并执行其测试。如果再次失败，控制将传递到下一个 `elif` 并检查其测试。此过程一直持续直到某个测试为真。这时将执行该 `elif` 的命令，并将控制跳出 `if` 结构，执行 `fi` 关键字之后的下一个命令。

如果设置了 `CSH_JUNKIE_PAREN` 选项，你可以使用 C 程序格式，用括号表示测试表达式，用大括号表示循环体。不需要 `then` 或 `fi` 关键字。如果表达式由单个条件表达式组成，则可以省略周围的括号。

```
if ( ) {
  elif ( ) {
  ... else {
  }
}
```

## exec

```
exec [[-] [arguments]]
```

`exec` 执行一个命令并替换当前 shell。不会创建新进程。你可以为命令指定参数。如果 `exec` 的第一个参数是 `-`，shell 会在传递给命令的零位参数中放置一个横杠。如果 `exec` 没有参数，则任何重定向将在当前 shell 中生效，并返回 0 作为退出状态。

## fc

```
fc [-e name] [-nlrdDfEm] [old=new ...] [first[last]]
fc -ARWI [filename]
```

`fc` 通过第一个和最后一个事件引用从历史列表中选择一个范围的命令。第一个和最后一个事件的引用可以指定为数字或字符串。你可以使用负数偏移到当前历史事件数。你还可以指定对所选命令执行的替换（`old=new`）。使用 `-l` 选项，结果命令将显示在标准输出中。使用 `-m` 选项，参数被视为模式，只有匹配模式的事件会被显示。如果没有这些选项，则将在包含这些历史事件的文件上调用编辑器。通过 `-e` 选项，你可以指定使用的编辑器。如果 `ename = "*"`, 则不调用编辑器。如果未指定第一个事件，它将被设置为 `-1`（最近的事件），或者在使用 `-l` 选项时设置为 `-16`。

## 130 Z-Shell 命令

在括号内。列表中的每个值都被赋值给 `foreach` 结构中的变量。与 `while` 结构一样，`foreach` 结构也是一个循环。每次循环时，列表中的下一个值会被赋值给该变量。当到达列表末尾时，循环停止。像 `while` 循环一样，`foreach` 循环的主体以关键字 `end` 结束。

在 `mylist` 脚本中，接下来的示例中，用户简单地输出每个项目的项目列表以及今天的日期。项目列表构成了 `foreach` 循环读取的值列表。每个项目被连续赋值给变量 `grocery`。

### mylist

```
#\set tdate='+%D'

foreach grocery ( milk cookies apples cheese ) 

echo "$grocery" $tdate

end
```

```
$ mylist

milk 05/23/99

cookies 05/23/99

apples 05/23/99

cheese 05/23/99

$
```

`foreach` 循环常用于管理文件。在 `foreach` 结构中，你可以在模式中使用 shell 特殊字符来生成文件名列表，作为你的值列表使用。生成的文件名列表成为 `foreach` 结构所引用的列表。星号 `*` 可以生成所有文件和目录的列表。`*.c` 列出扩展名为 `.c` 的文件，这些通常是 C 源。接下来的示例对每个文件进行备份，并将备份放在名为 `sourcebak` 的目录中。模式 `*.c` 生成 `foreach` 结构操作的文件名列表。

### cbackup

```
#

foreach backfile (*.c )

cp $backfile sourcebak/$backfile

echo $backfile

end
```

```
$ backup

io.c

lib.c

main.c
```
