
"O*" 转换接受两个参数 (`converter`, `addr`) 并使用函数将 `PyObject` 转换为 C 数据类型。`converter` 是指向函数的指针，其原型类型为 `converter(PyObject *obj, void *addr)`，其中 `obj` 是传递的 Python 对象，`addr` 是在 `PyArg_ParseTuple` 中作为第二个参数提供的地址。`PyArg_ParseTuple(args, converter())` 在成功时应返回 1，失败时返回 0。发生错误，`converter` 还应该抛出异常。这种转换可用于将 Python 对象映射到 C 结构中。例如，这里是我们之前代码中 `distance()` 包装器的可能实现：

```c
/* 将元组转换为 Point 结构。 */
int convert_point(PyObject *obj, void *addr) {
Point *p = (Point *)addr;
return PyArg_ParseTuple(obj,"ii",&p->X, &p->y);
}
PyObject *py_distance(PyObject *self, PyObject *args) {
Point p1, p2;
double result;
if (!PyArg_ParseTuple(args,"O&O*",
    convert_point, &p1, convert_point, &p2)) {
    return NULL;
}
result = distance(p1,p2);
return Py_BuildValue("d",result);
}
```

## 602 第 26 章 扩展

"e#"、"u#"、"w#" 和 "w#" 的转换与 "s#" 系列代码一样，它们只接受实现缓冲区接口的对象。"tb" 要求缓冲区是可读的。"w#" 代码要求缓冲区既可读又可写。支持可写缓冲器的 Python 对象被假定为是可变的。因此，C 扩展覆盖或修改缓冲区内容是合法的。

# 向模块添加值

在扩展模块的初始化函数，通常会添加常量并支持其他值。可以使用以下函数来实现此操作：

```c
int PyModule_AddObject(PyObject *module, const char *name, PyObject *value)
```

向模块添加一个新值。`name` 是该值的名称，`value` 是包含该值的 Python 对象。你可以使用 `PyBuildValue()` 来构建它。

```c
int PyModule_AddIntConstant(PyObject *module, const char *name, long value)
```

向模块添加一个整数值。

```c
void PyModule_AddStringConstant(PyObject *module, const char *name, const char *value)
```

向模块添加一个字符串值。`value` 必须是一个空终止字符串。

```c
void PyModule_AddIntMacro(PyObject *module, macro)
```

以整数的形式向模块添加一个宏值。`macro` 必须是预处理器宏的名称。

```c
void PyModule_AddStringMacro(PyObject *module, macro)
```

以字符串的形式向模块添加一个宏值。

# 错误处理
