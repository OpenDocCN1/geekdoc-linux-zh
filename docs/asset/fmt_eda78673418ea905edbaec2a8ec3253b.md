
与整数值完全相等的数值值通过等效于调用 `sprintf` 函数转换为字符串，其中使用 `%d` 作为 `fmt` 参数，并将该数值作为第一个且唯一的参数进行转换。任何其他数值值通过等效于调用 `sprintf` 函数转换为字符串，其中将变量 `CONVFMT` 的值作为 `fmt` 参数，并将该数值作为第一个且唯一的参数进行转换。

## nawk 855

在以下情况下，字符串被视为数值字符串：

- 忽略任何前后的空白字符。
- 如果第一个未忽略的字符是 `+` 或 `-`，则忽略该字符。
- 如果剩余的非忽略字符在词法上被识别为 `NUMBER` 令牌，则该字符串被视为数值字符串。
- 如果在上述步骤中忽略了 `-` 字符，则数值字符串的数值为识别出的 `NUMBER` 令牌数值的取反；否则，该数值字符串的数值为识别出的 `NUMBER` 令牌的数值。字符串是否为数值字符串仅与本节中使用该术语的上下文有关。

当表达式在布尔上下文中使用时，如果它具有数值值，则将 `0` 视为 `false`，任何其他值均视为 `true`。否则，空字符串值被视为 `false`，任何其他值均视为 `true`。布尔上下文指以下之一：
- 条件表达式操作的第一个子表达式。
- 被逻辑非、逻辑与或逻辑或操作的表达式。
- `for` 语句的第二个表达式。
- `if` 语句的表达式。
- `while` 或 `do...while` 语句中 `while` 子句的表达式。
- 用模式使用的表达式（如整体程序结构所示）。

`nawk` 语言支持存储数字或字符串的数组。数组不需要声明。下标或元素标识符是字符串，它们是动态变化的，提供了一种关联数组的能力。你可以将数组名后跟方括号内的下标作为 `lvalue` 和表达式使用，如语法中所描述的那样。不带下标的数组名仅用于以下上下文：

- 函数定义或函数调用中的参数。
- 任何使用关键字 `in` 后的 `NAME` 令牌。

有效的索引由一个或多个用逗号分隔的表达式组成，类似于某些编程语言中多维数组的索引方式。由于 `nawk` 数组实际上是一维的，`nawk` 通过将逗号分隔的列表转换为单个字符串，每个表达式的字符串值通过 `SUBSEP` 变量的值连接起来。因此，以下两种数组索引操作是等效的：

```
var[expr1,expr2,...exprn]
```

```
var[expr1 SUBSEP expr2... SUBSEP exprn]
```

## 856

`in` 操作必须包含多维索引。`in` 运算符测试数组元素是否存在，如果元素不存在，则不会创建它。对不存在的元素的任何引用都会创建它。

## 变量与特殊变量

你可以通过引用在 `awk` 程序中使用变量。除了函数参数外，变量不需要显式声明。未初始化的变量和数组元素的数值值均为 `0`，值为空字符串。

字段变量由 `$` 后跟数值表达式指定。字段编号评估为非负整数以外的结果定义。在此上下文中，不需要将未初始化的变量或字符串值转换为数值。通过给它们赋值来创建新字段。对不存在字段的引用（即 `$NF`）会产生空字符串。然而，给不存在的字段赋值（例如 `$(NF+2) = 5`）会增加 `NF` 的值，为中间字段创建空字符串，并使用 `IFS` 的值重新计算 `$0` 的值。创建的每个字段变量具有字符串值。当当前区域的小数点字符更改为点时，字符串被视为数值字符串；字段变量也具有其数值。`nawk` 设置了以下特殊变量：

- `ARGC`：`ARGV` 数组中的元素。
- `ARGV`：命令行参数数组，编号从 `0` 到 `ARGC-1`。

你可以修改或添加 `ARGV` 中的参数。你可以更改 `ARGC`。当每个输入文件结束时，`nawk` 将 `ARGV` 中直到当前 `ARGC-1` 值的下一个非空元素视为下一个输入文件的名称。将 `ARGV` 的某个元素设置为空意味着它不作为输入文件。名称表示标准输入。如果参数匹配文件参数的格式，则该参数被视为赋值操作，而不是文件参数。

```

```
