### 创建 `/etc/fstab` 文件

为了让某些程序能够确定默认挂载分区的位置，使用了 `/etc/fstab` 文件。创建一个新文件 `/etc/fstab` 并包含以下内容：

```
# Begin /etc/fstab
/dev/<LFS-partition designation> / ext2 defaults 1 1
/dev/<swap-partition designation> swap swap defaults 0 0
none /proc proc defaults 0 0
```

将 `<LFS–partition designation>` 和 `<swap–partition designation>` 替换为相应的设备（在我的情况下是 `/dev/hda5` 和 `/dev/hda6`）。

# 第 8 章 设置基础网络

# 引言

本章将设置基础网络。虽然你可能没有连接网络，Linux 软件也会使用网络功能。我们将至少安装本地回环设备和适用情况的网卡。此外，还将创建正确的启动脚本，以便在启动期间启用网络。

### 创建网络启动脚本
创建 `/etc/init.d/localnet` 启动脚本

创建一个新文件 `/etc/init.d/localnet`，其中包含以下内容：

```sh
#!/bin/sh
# Begin /etc/init.d/localnet
source /etc/init.d/functions
source /etc/sysconfig/network
case "$1" in
    start)
        echo -n "正在启动环回接口..."
        /sbin/ifconfig lo 127.0.0.1
        evaluate_retval
        echo -n "正在设置主机..."
        /bin/hostname $HOSTNAME
        evaluate_retval
        ;;
    stop)
        echo -n "正在停用环回接口..."
        /sbin/ifconfig lo down
        evaluate_retval
        ;;
    *)
        echo "Usage: $0 {start|stop}"
        exit 1
esac
# End /etc/init.d/localnet
```

## 设置权限和符号链接

运行以下命令来设置适当的文件权限并创建必要的符号链接：

```bash
root:~# cd /etc/init.d
root:init.d# chmod 754 localnet
root:init.d# cd ../rcS.d
root:rcS.d# ln -s ../init.d/localnet S03localnet
```

## 创建 `/etc/sysconfig/network` 文件

运行以下命令创建一个新文件 `/etc/sysconfig/network`，并将主机名写入其中：

```bash
root:~# echo "HOSTNAME=lfs" > /etc/sysconfig/network
```

将 `"lfs"` 替换为你想要给计算机起的名称。请注意，你不应该在此处输入 FQDN（完全限定域名名）。该信息稍将放入 `/etc/hosts` 文件中。

## 创建 `/etc/hosts` 文件

如果你想配置网卡，你必须为用于 `/etc/hosts` 文件的 IP 地址、FQDN 和可能的别名（aliases）做出决定。例如：

```
<my-IP> myhost.mydomain.org aliases
```

确保 IP 地址在私有网络 IP 地址范围内。有效范围是：
- 类网络（Class Networks）
- A 类 `10.0.0.0`
- B 类 `172.16.0.0` 到 `172.31.0.0`
- C 类 `192.168.0.0` 到 `192.168.255.0`

一个有效的 IP 地址可以是 `192.168.1.1`。此 IP 的一个有效 FQDN 可以是 `.linuxfromscratch`

如果你不使用网卡，你仍然需要构造一个 FQDN。这对于像 Sendmail 等程序的正常运行是必要的（事实上；当 Sendmail 确定 FQDN 时将无法运行）。

如果你不配置网卡，请创建一个新文件 `/etc/hosts` 并包含以下内容：

```bash
# Begin /etc/hosts (无网络版本)
127.0.0.1 www.mydomain.com <value of HOSTNAME> localhost
# End /etc/hosts (无网络版本)
```

如果你不配置网卡，请创建一个新文件 `/etc/hosts` 并包含以下内容：

```bash
# Begin /etc/hosts (网卡版本)
127.0.0.1 localhost.localdomain localhost
192.168.1.1 www.mydomain.org <value of HOSTNAME>
# End /etc/hosts (网卡版本)
```

当然，你可以根据自己的喜好修改 `192.168.1.1` 和 `www.mydomain.org`（或者如果网络/系统管理员分配了 IP 地址并计划将此机器连接到网络时相应修改）。

本节仅适用于你要配置网卡的情况。如果不配置，请跳过本节。

创建一个新文件 `/etc/init.d/ethnet`，包含以下内容：

```sh
#!/bin/sh
# Begin /etc/init.d/ethnet
source /etc/init.d/functions
source /etc/sysconfig/network
case "$1" in
start)
  echo -n "正在启动 eth0 接口..."
  /sbin/ifconfig eth0 $IP broadcast $BROADCAST netmask $NETMASK
  evaluate_retval
  ;;
stop)
  echo -n "正在停用 eth0 接口..."
  /sbin/ifconfig eth0 down
  evaluate_retval
  ;;
*)
  echo "Usage: $0 [start|stop]"
  exit 1
  ;;
esac
# End /etc/init.d/ethnet
```

## 编辑 `/etc/sysconfig/network` 文件

编辑 `/etc/sysconfig/network` 文件并向其中添加以下行。不要删除 `HOSTNAME=` 行。

```bash
IP=192.168.1.1
NETMASK=255.255.255.0
BROADCAST=192.168.1.255
```
