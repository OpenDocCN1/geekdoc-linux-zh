## Usenet

如本章开头提到的，Usenet 新闻组用于在互联网上交换新闻、信息、数据和辩论。理想情况下，新闻组名称按层级结构组织以便于访问，但在实践中，某个小组可能会在该组织结构之外创建并繁荣发展。正式结构中的组名从通用到具体组织，并用点分隔。例如，`comp.os.linux.announce` 用于与 Linux 操作系统相关的公告，属于更广泛的主题 computer（计算机）。

以下是其他一些广泛的主题：

- News：关于 Usenet 的信息。
- Talk：当前议题和辩论。
- Soc：社会问题、文化。
- Rec：游戏、爱好、运动、艺术。
- Sci：科学主题。
- Alt：任何内容；最初是一个“备用（alternate）”层级结构。

文章和消息被发布到新闻服务器（仅处理新闻组数据的计算机）并传输到其他新闻服务器，供世界上任何人阅读。产生后续反馈的帖子被称为“线程”，就像对话的“线索”一样。带有严厉谴责内容的文章被称为“帧”。

每个新闻组都有自己的特点和行为准则，这些准则可能未明确说明。有些小组非常正式，另一些则非正式且随意。有些小组允许在不受审查的情况下进行批评和修正；另一些则不允许。如果一个小组经过审核，这意味着由一个人或一群人在消息发布前批准进入的消息，以保持主题不偏离且语气文明。否则，新闻组的方向、内容和语气将受到任何参与者的影响。

## 概述

KDE 提供了许多用于浏览网络的工具。在第 3 章中，你学习了如何将 Konqueror 作为文件管理器。在本章中，主题是将 Konqueror 作为网页浏览器，以及使用 Netscape 和 Opera 等其他浏览器。重点是利用 Konqueror 提供的许多自定义选项，以便让浏览器满足你的需求和偏好。在本章末尾，你将看到关于如何使用文字处理程序和 Quanta Pulse 创建你自己的网页的讨论。

在深入学习网页浏览、快捷键、书签等内容之前，让我们了解一些你应该知道的基本术语，以便有效使用网络并理解本章的其余内容。如果你是浏览高手，请直接跳到下一节“详细了解 Konqueror”。

- **Internet**：一个去中心化的全球网络，连接了数百万台计算机，用于交换数据、信息、新闻、观点等。
- **网页**：World Wide Web 的缩写，一种支持特殊格式文档的互联网服务器系统。
- **网页浏览器**：一种在你的计算机上显示网页的软件应用程序。
- **网站**：Web 上一个由个人、团体、公司或组织所有并管理的场所。它可能包含单个网页或许多文件、图形和其他信息，且通常与相关主题有关。
- **URI**：统一资源标识符，Web 上所有类型名称和地址的通用术语。
- **URL**：统一资源定位符，Web 上网页的具体地址。
- **IP 地址**：分配给每个计算机的标识代码。
- **域**：一组计算机。
- **HTML**：超文本标记语言，创建文档的常用语言。
- **网络**：一组机器。
- **在线**：计算机连接时的状态。
- **协议**：传输数据的约定标准方法。

## 导航基础

通过在位置栏中输入网站的 URL 或地址（例如 `http://`）并按回车键开始导航。注意，当你移动到新页面时，位置栏上方的左箭头变为激活。这是“后退”按钮，点击它可以返回上一个页面。

网页浏览器的强大功能之一是通过使用超链接关联相关材料。超链接是特殊格式的单词和图像（图像映射），点击后会自动将浏览器带到另一个页面。你通常可以识别超链接，因为它们默认带有下划线，并且通常以不同色的字体显示。你也可以通过将鼠标指针悬停在链接和图像上来识别；如果箭头变成了手，它就是一个链接。

有时会在新的浏览器窗口中打开，但通常你的主 Konqueror 会跟随链接，导致原始页面丢失。你通常可以使用后退箭头返回上一个页面，但这可能需要很长时间。此外，有时你只能回退几次，而有时你可能同时看到两个页面。在这种情况下，你会希望在浏览器的新实例中打开链接，或者将鼠标指针悬停在链接上并右键点击--从弹出的菜单中点击“新窗口”。这将启动一个跟随链接的新浏览器实例。

> **提示**：`ALT+F2` 运行的妙之处仍在。它的工作原理与 Konqueror 的地址栏非常相似，通过启动 Konqueror 并显示你输入的任何 URL 的网页。

如果你停止了页面加载，或者页面没有正常加载，你可以点击“重新加载”按钮重试。重新加载页面可能仍然无法正常显示；这可能是由于 HTML 编写不当、图像链接损坏或网络拥堵导致的。

## 搜索万维网
