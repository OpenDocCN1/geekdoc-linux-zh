# 安装 Ldso

安装 Ldso

运行以下命令安装 Ldso：

```
root:ld.so-1.9.9# cd util
root:util# make lddconfig
root:util# cp ldd /bin
root:util# cp lddconfig /sbin
root:util# cd ../
root:man# cp ldd.1 /usr/share/man/man1
root:man# cp *.8 /usr/share/man/man8
root:man# rm /usr/bin/ldd
root:man# hash -r
```

"`-r`" 命令用于让 `bash` 忘记之前执行过的命令的位置。如果你之前执行过 `ldd`，`bash` 期望在 `/usr/bin` 中找到它。由于我们将其移动到了 `/bin`，因此需要清除缓存，以便在你想要执行它时 `bash` 能在 `/bin` 中找到它。

你可能注意到我们没有对该软件包使用编译器优化。原由于是覆盖 `CFLAGS` 变量会导致编译问题。你必须编辑 `Config.mk` 文件并为 `CFLAGS` 变量添加适当的值，然后编译该包。如果你想这样做，随你的意。不过我不认为这值得麻烦。`ld` 和 `ldd` 程序通常很少使用。
