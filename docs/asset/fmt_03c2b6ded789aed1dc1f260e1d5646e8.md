
| `value = d[key]` | 从数据库获取数据 |
| `del d[key]` | 数据库条目 |
| `d.close()` | 关闭数据库 |
| `key in d` | 测试键是否存在 |
| `d.sync()` | 将所有更改写入数据库 |

特定的实现可能会添加额外功能（详情请参阅相应的模块参考）。DBM 风格模块的一个问题是并非每个模块都安装在每个平台上。例如，如果你在 Windows 上使用 Python，`dbm` 和 `gbm` 模块通常不可用。但如果你在 Unix 上使用 Python，`dbm` 和 `gbm` 模块通常是用的。

# shelve 模块

`shelve` 模块通过“shelf”对象为持久化对象提供支持。它的行为类似于字典，但它包含的对象存储在磁盘上。然而，与这些模块不同，shelf 中的值并不限制为字符串。使用 `shelve.open()` 函数创建一个 shelf。

```python
open(filename, flag='c', protocol {, writeback=})
```

Shelf 打开一个文件。如果文件不存在，则创建它。`filename` 是数据库文件且不应包含后缀。`flag` 的含义与章节介绍相同，为 'r'、'w'、'c' 或 'n'。如果数据库不存在，则创建。`protocol` 指定存储在数据库中的 pickle。`writeback` 控制数据库的缓存行为。如果为 `True`，所有条目缓存在内存中，仅在 shelf 关闭时写入。默认值为 `False`。

这是一个在字典对象之上实现 shelf 功能的类。当使用它时，返回的 shelf 将被 pickle 并存储在底层字典中。两者 `protocol` 和 `writeback` 的含义与 `shelve.open()` 相同。shelf 使用 `anydbm` 来选择合适的 DBM 模块。在标准 Python 安装中，它很可能是依赖 Berkeley DB 库的 `dbhash`。

## bz2

`bz2` 模块用于根据 bzip2 压缩算法读写数据。

```python
BZ2File(filename , mode , buffering [, compresslevel=1]])
```

打开一个 bz2 文件 `filename`，并返回一个类文件对象。`mode` 为 'r' 表示读取或 'w' 表示写入。通过指定模式 'u' 还可以支持通用换行符。`buffering` 以字节指定缓冲区大小，默认值为 0（无缓冲）。`compresslevel` 是 1 到 9 之间的数字。值 9（默认值）提供最高级别的压缩，但消耗的处理器时间最多。返回的对象支持所有常见的文件操作，包括 `close()`、`read()`、`readline()`、`readlines()`、`seek()`、`tell()`、`write()` 和 `writelines()`。

```python
BZ2Compress([compresslevel])
```

创建一个压缩器对象，可按顺序压缩一系列数据块。`compresslevel` 指定压缩级别，为 1 到 9 之间的数字（默认值）。

`BZ2Compress` 的实例 `c` 具有以下两个方法：

```python
c.compress(data)
```

向压缩器对象 `c` 输入新字符串。如果可能，返回压缩后的数据字符串。由于压缩涉及数据块，返回的字符串可能不包含所有数据，并可能包含来自之前调用 `compress()` 的压缩数据。在提供所有输入数据后，应使用 `flush()` 方法返回压缩器中存储的任何剩余数据。

```python
c.flush()
```

刷新内部缓冲区并返回包含所有剩余数据压缩版本的字符串。在此操作之后，不应再对对象执行任何 `compress()` 调用。

`BZ2Decompressor()`

创建一个解压缩器对象。`BZ2Decompressor` 的实例 `d` 仅支持一个方法：

```python
d.decompress(data)
```

给定字符串 `data` 中的数据块压缩数据，此方法返回解压后的数据。由于数据是分块的，返回的字符串可能包含不包含 `data` 中提供的所有内容的压缩版本。重复调用此方法将继续解压缩块，直到在输入中找到流结束标记。如果之后尝试解压缩数据，将抛出 `EOFError`。

`compress(data, compresslevel)`

返回字符串 `data` 中提供的数据压缩版本。`compresslevel` 是 1 到 9 之间的数字（默认值）。

`decompress(data)`

返回一个包含字符串 `data` 中解压数据的字符串。

## filecmp

`filecmp` 模块提供了以下函数，用于比较文件和目录：

`cmp(file1, file2, shallow)`

比较文件 `file1` 和 `file2`，如果它们相等则返回 True，否则返回 False。默认情况下，由 `os.stat()` 返回具有相同属性的文件被认为是等等的。如果指定 `shallow` 参数为 `False`，则比较两个文件的计数以确定等等性。

`cmpfiles(dir1, dir2, common, [shallow])`

比较目录 `dir1` 和 `dir2` 中列表 `common` 里的文件内容，返回一个包含文件名列表（`match`, `mismatch`, `errors`）的元组。`match` 列出两个目录中都存在的文件，`mismatch` 列出不匹配的文件，`errors` 列出由于某些原因无法比较的文件。`shallow` 参数的含义与 `cmp()` 相同。

`dircmp(dir1, dir2, ignore, [hide])`

创建一个比较对象，用于对目录 `dir1` 和 `dir2` 执行各种操作。`ignore` 是要忽略的文件名列表，默认值为 `['.RCS','CVS','tags']`。`hide` 是要隐藏的文件名列表，在 UNIX 上默认为 `[os.curdir, os.pardir]`。

`dircmp()` 返回的目录对象 `d` 具有以下方法和属性

```python
d.report()
```

比较目录 `dir1` 和 `dir2` 并报告打印到 `sys.stdout`。

```python
d.report_partial_closure()
```

比较 `dir1`、`dir2` 以及共同的直接子目录。结果打印到 `sys.stdout`。

```python
d.report_full_closure()
```

递归地比较 `dir1`、`dir2` 以及所有子目录。结果打印到 `sys.stdout`。

```python
d.left_list
```

列出 `dir1` 中的文件和子目录。内容由 `hide` 和 `ignore` 过滤。

```python
d.right_list
```

列出 `dir2` 中的文件和子目录。内容由 `hide` 和 `ignore` 过滤。

```python
d.common
```

列出 `dir1` 和 `dir2` 中都有的文件和子目录。

```python
d.left_only
```

列出仅在 `dir1` 中的文件和子目录。

```python
d.right_only
```

列出仅在 `dir2` 中的文件和子目录。

```python
d.common_dirs
```

列出子目录。

## shutil

`shutil` 模块用于执行高级文件操作，如复制、删除和重命名。该模块中的函数应仅适用于适当的文件和目录。特别，它们不适用于文件系统上的特殊类型文件，如命名管道、块设备等。此外，请注意这些函数并不总是能处理高级文件元数据（例如，资源叉、创建者代码等）。

`copy(src, dst)`

将文件 `src` 复制到文件或目录 `dst`，并保留文件权限。`src` 和 `dst` 均为字符串。

`copy2(src, dst)`

与 `copy()` 类似，也会复制访问时间和修改时间。

`copyfile(src, dst)`

将 `src` 的内容复制到 `dst`。`src` 和 `dst` 均为字符串。
