# 引言

人们为什么选择使用 GNU/Linux？有些人选择它是因为他们想声明，一旦你拥有了它，就可以做你想的事。有些人想提高自己的计算技能并学习新东西。其他人使用 GNU/Linux 是因为大多数 GNU/Linux发行版是免费的！无论你选择 GNU/Linux 的理由是什么，选择 Ubuntu发行版都是你能做的明智的决定之一。
