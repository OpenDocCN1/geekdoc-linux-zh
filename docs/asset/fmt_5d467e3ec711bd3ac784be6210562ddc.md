
每次登录时，`login`程序都会运行。此程序使用存储在`/etc/passwd`文件中的数据实际开始你的登录会话，该文件包含有关每个系统用户的一行信息。`/etc/passwd`文件包含你的用户名、你的密码（加密形式）、你的主目录和你的默认`shell`。有关`/etc/passwd`文件的更多信息，请参阅第5章。

`login`程序在你在`login:`提示符下输入用户名后运行。它执行以下功能：

- 显示`Password:`提示符（如果你有密码）。
- 验证你输入的用户名和密码是否与`/etc/passwd`文件中包含的内容一致。
- 为`shell`环境分配默认值。
- 开始运行`shell`进程。
- 运行系统登录脚本和你的个人登录脚本。有关更多信息，请参阅第7.6节。

### 7.5.2 环境变量

你的`shell`环境为你定义和维护一个独特的工作环境。你工作环境的大多数特征由环境变量定义。

环境变量由名称和值组成。例如，你的登录目录的环境变量名为`HOME`，其值在你登录时自动定义。

一些环境变量由`login`程序设置，一些可以在适合你的`shell`的登录脚本中定义。例如，如果你使用C shell，环境变量通常会在`.cshrc`登录脚本中设置。有关登录脚本的更多信息，请参阅第7.6节。

表7-5列出了可被所有操作系统`shell`使用的选定环境变量。这些变量的大多数值在登录过程中设置，然后传递给你在会话期间创建的每个进程。

#### 表7–5：选定的Shell环境变量

| 环境变量 | 描述 |
|---|---|
| `HOME` | 指定你的登录目录的名称，即登录完成后成为当前工作目录的目录。`cd`命令使用`HOME`的值作为其默认值。登录程序设置此变量，且不能由个人用户更改。 |
| `LOGNAME` | 指定你的登录名。 |
| `MAIL` | 指定邮件系统用于检测新邮件到达的文件路径名。登录程序根据你的用户名设置此变量。 |

你也可以创建自己的环境变量。例如，一些系统为用户提供了不止一个邮件程序。假设你的系统上同时有`mail`和`mh`，并且每个都有自己的路径名。因此，你可以为每个邮件程序的路径名定义一个变量。

有关特定于每个操作系统`shell`的环境变量的更多信息，请参阅第8章。有关操作系统`shell`环境变量的完整列表，请参阅`sh(1b)`、`sh(1p)`、`csh(1)`和`ksh(1)`参考页。

### 7.5.3 Shell变量

`Shell`变量仅对你的当前`shell`有效，且不会传递给子`shell`。因此，它们只能在定义它们的`shell`中使用。换句话说，它们可以被视为局部变量。

`Shell`变量可以通过成为环境变量在当前`shell`之外访问。有关环境变量的更多信息，请参阅第7.7.1节。

你也可以创建自己的`shell`变量。例如，一些邮件程序使用`PAGER`变量来定义显示邮件的程序。假设你的邮件程序是`mailx`。你可以将`PAGER`变量定义为使用`more`程序来显示你的邮件。

有关如何设置`shell`变量的信息，请参阅第7.7.1节。

### 7.6 登录脚本与你的环境

登录脚本是一个包含设置用户环境的命令的文件。有两种登录脚本：

- 特定`shell`的所有用户的系统登录脚本：这些脚本为所有用户创建默认环境，并由你的系统管理员维护。Bourne、Korn和POSIX `shell`使用名为`/etc/profile`的系统登录脚本。C `shell`使用名为`/etc/csh.login`的脚本。有关系统登录脚本的路径名，请参阅表7-6。登录时，此文件中的命令会首先执行。
- 默认登录目录中的本地登录脚本：这些脚本让你定制环境，你维护相应的文件。例如，你可以更改默认搜索路径或`shell`提示符。如果你的默认`shell`（参见第7.3节）是Bourne、Korn或POSIX `shell`，则登录脚本文件称为`.profile`。C `shell`使用名为`.login`的文件。本地登录脚本在系统登录脚本之后执行。

如果C `shell`是你的默认`shell`，你的环境还可以通过`.cshrc`文件进一步定制。它在登录时执行（在`.login`之前）以及每次生成子`shell`时执行。`.cshrc`文件是C `shell`自动使变量对子`shell`可用的机制。

启动时，Korn和POSIX `shell`还会执行`ENV`环境变量指向的任何文件。此变量通常在`.profile`文件中设置，并设置为另一个文件，通常位于`$HOME`目录中。一些用户更喜欢将此文件称为`.kshrc`或`.envfile`。要使用此类文件，请在你的`.profile`文件中放置如下一行：

```
ENV=~/.kshrc
```

此类文件通常包含`shell`变量、别名定义和函数定义。在本文件的其余部分中，该文件将被称为`.kshrc`。
