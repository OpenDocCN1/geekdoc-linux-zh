## 章节总结

- 大多数 Linux 软件采用 Red Hat Package Manager（RPM）格式。SLES 在 `/var/lib/rpm` 目录维护维护所有 RPM 安装软件的数据库，并每天将该数据库备份到 `/var/adm/backup/rpmdb` 目录。

- 您可以在终端中使用 **rpm** 命令，或在桌面环境中使用 YaST 来安装、删除和查找有关 RPM 软件包的信息。
