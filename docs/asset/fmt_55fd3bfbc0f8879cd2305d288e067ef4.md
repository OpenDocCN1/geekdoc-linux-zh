# 调整图像位置

如果屏幕未能将图像正确居中，你可以编辑 `Modes` 数字。在拉伸或缩小图像之前，请确保图像已居中。你所做的任何调整将在重启 X 服务器后生效。

### 居中图像

`Pixels Displayed` 数字必须与所需的物理值匹配。`Sync Start` 和 `Sync End` 数字必须同时以相同的量增加或减少（以向左或向右；向上或向下），并保持在 `Displayed` 和 `Total` 的范围内。

- 图像太右：要调整太右的图像，等量增加 `Horizontal Sync Start` 和 `Horizontal Sync End` 值。

- 图像太左：要调整太左的图像，等量减少 `Horizontal Sync Start` 和 `Horizontal Sync End` 值。例如，要调整太靠左的图像，可以从向两个水平计时数字（`Sync Start` 和 `Sync End`）增加 8 开始。确保 `Sync End` 数字不会超过 `Horizontal Total` 数字。

- 图像太低：要调整太靠下的图像，等量减少 `Vertical Sync Start` 和 `Vertical Sync End` 值。

- 图像太高：要调整太靠上的图像，等量增加 `Vertical Sync Start` 和 `Vertical Sync End` 值。例如，要调整太靠上的图像，可以从向两个垂直计时数字（`Sync Start` 和 `Sync End`）增加 8 开始。确保 `Sync End` 数字不会超过 `Vertical Total` 数字。

### 拉伸或缩小图像

`Pixels Displayed` 数字必须与所需的物理屏幕分辨率匹配。通过增加或减少 `Total` 值来拉伸或缩小图像。此外，为了居中位置，`Sync Start` 和 `Sync End` 数字必须根据变化的 `Total` 值的一半等量增加或减少。例如，如果 `Horizontal Total` 增加了 10，则你对 `Horizontal Sync Start` 和 `Horizontal Sync End` 各增加 5。

- 图像水平太窄：要拉伸水平太窄的图像（两侧出现额外空间），增加 `Horizontal Sync Start` 和 `End` 值。总计增加 `x`，然后对 `Horizontal Sync Start` 和 `Horizontal Sync End` 各增加 `x` 的一半。

- 图像垂直太窄：要拉伸垂直太窄的图像（顶部和底部出现额外空间），增加 `Vertical Sync Start` 和 `End` 值。增加数量 `x`，然后向垂直同步起始（`Vertical Sync Start`）和垂直同步结束（`Vertical Sync End`）值中各加上 `x` 的一半。

- 图像水平过宽：要缩小水平过宽的图像（图像超出了左右边缘），请将水平总宽度（`Horizontal Total`）减少 `x`，然后从水平同步起始（`Horizontal Sync Start`）和结束（`Sync End`）值中各减去 `x` 的一半。

- 图像垂直过高：要缩小垂直过高的图像（图像超出了上下边缘），请将垂直总高度（`Vertical Total`）减少 `x`，然后从垂直同步起始（`Vertical Sync Start`）和垂直同步结束（`Vertical Sync End`）值中各减去 `x` 的一半。

# Metro X 配置文件

扩展配置位于`/usr/lib/Metro/X11/Extensions`。大多数扩展都是动态加载的；也就是说，如果需要，它们会自动加载，无需额外的手动配置。“开启”的扩展在服务器启动时加载且永不卸载。标记为`DYN`的扩展在 X 客户端调用`XQueryExtension`请求时按需加载。这些扩展可以通过`XListExtensions`或`xdpyinfo`显示。标记为`OFF`的扩展不被使用，也不会通过`XListExtensions`或`xdpyinfo`显示。

# 注意事项

- 多缓冲（`Multi-Buffering`）和双缓冲（`DOUBLE-BUFFER`）无法动态加载。它们必须被设置为`ON`或`OFF`。

- `GLX` (OpenGL) 可以动态加载，但 `GLX` 取决于 `DOUBLE-BUFFER` 是否为`ON`。因此，要使用 `GLX`，请将 `DOUBLE-BUFFER` 设置为`ON`并将 `GLX` 设置为`DYN`。

- `X3D-PEX` (`PEX`) 可以动态加载，但 `X3D-PEX` 取决于多缓冲是否为`ON`。因此，要使用 `X3D-PEX`，请将多缓冲设置为`ON`并将 `X3D-PEX` 设置为`DYN`。

### D.3.1 如何让我的 SB16 上的 IDE CD-ROM 工作？

Creative Labs 的套件默认将 IDE 接口设置为第三个 IDE 端口（我记记得是 IDE2）。这在 Linux 下将无法工作，因为内核只识别两个 IDE 端口。你需要做的是移动卡上的跳线帽以将其配置为 IDE（次要 IDE 端口）。我不确定是否需要在 DOS 下进行某些更改，但你的手册应该对这提供帮助（它仍然可以工作，但你可能需要编辑一两个文件）。
