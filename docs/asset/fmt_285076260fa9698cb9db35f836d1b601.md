## 重定向标准错误

重定向标准错误缺乏专用重定向操作符的便利性。要重定向标准错误，我们必须引用它的文件描述符。程序可以在任意几个文件流上产生输出。虽然我们一直把这前三个文件流称为标准输入、输出和错误，但 shell 在内部将它们引用为文件描述符 `0`、`1` 和 `2`。shell 提供了一种使用文件描述符编号重定向文件的表示法。由于标准错误等同于文件描述符编号，我们可以使用这种符号重定向标准错误：

```
[melinuxbox ~]$ ls -1 /bin/usr 2>ls-error.txt
```

文件描述符 `2` 放在重定向操作符之前，以便将标准错误重定向到文件 `ls-error.txt`。

## 将标准输出和标准错误重定向到同一个文件

在某些情况下，我们可能希望将所有输出捕到一个文件中。为了这样做，我们必须同时重定向标准输出和标准错误。这有两种实现方法。这里显示的是传统方法，适用于旧版本的 shell：

```
[melinuxbox ~]$ ls -1 /bin/usr > ls-output.txt 2>&1
```

使用这种方法，我们执行了两次重定向。首先我们将标准输出重定向到文件 `ls-output.txt`，然后使用 `2>&1` 符号将文件描述符 `2`（标准错误）重定向到文件描述符 `1`（标准输出）。

bash 的最新版本提供了另一种更简洁的方法来执行这种组合重定向，如下所示：

```
me@linuxbox ~$ ls -1 /bin/usr & ls-output.txt
```

在这个示例中，我们使用符号 `&` 将标准输出和标准错误都重定向到文件 `ts-output.txt`。你也可以像这样将标准输出流和标准错误流追加到单个文件中：

```
me@linuxbox ~$ ls -1 /bin/usr &> ls-output.txt
```

## 丢弃不需要的输出

有时“沉默是金的”，我们不需要命令的输出；我们只是想把它丢弃。这对于错误和状态消息尤为如此。系统提供了一种将输出重定向到特殊文件 `/dev/null` 的方法。这个文件是一个被称为“位桶”（bit bucket）的系统设备，它接受输入但不对其进行任何处理。要抑制命令的错误消息，我们可以这样做：

```
me@linuxbox ~$ ls -1 /bin/usr 2> /dev/null
```

## 重定向标准输入

到为止，我们还没有遇到任何使用标准输入的命令（实际上我们遇到过了，但稍后我们会揭晓这个惊喜），所以我们需要介绍一个。

## cat: 合并文件

`cat` 命令读取一个或多个文件并将它们复制到标准输出，如下：

```
cat filename
```

在大多数情况下，你可以将 `cat` 类比为 DOS 中的 `TYPE` 命令。你可以用它来不分页地显示文件。例如，以下命令将显示 `ls-output.txt` 文件的内容：

```
$me@linuxbox~$ cat ls-output.txt
```

`cat` 通常用于显示短文本文件。由于 `cat` 可以接受多个文件作为参数，它也可以用于合并文件。假设我们下载了一个被分成多个部分的大文件（多媒体文件通常通过 Usenet 分分），我们想将它们重新合并。如果文件命名为：

```
movie.mpg.001 movie.mpg.002 ... movie.mpg.099
```

我们可以使用此命令将它们重新合并：

```
cat movie.mpg.* > movie.mpg
```

由于通配符总是按排序顺序展开，因此参数将以正确的顺序排列。这些都很好，但这与标准输入有什么关系呢？目前还没有，但让我们尝试点别的。如果我们不带任何参数输入 `cat` 会发生什么？

```
$me@linuxbox~$ cat
```

什么都没有发生；它就那样停在那里，像死机了一样。看起来可能是那样，但它实际上正是它应该做的。如果没有给 `cat` 任何参数，它会从标准输入读取，而标准输入默认连接到键盘，它正在等待我们输入内容！尝试添加以下文本并按回车：

```
$me@linuxbox~$ cat
The quick brown fox jumped over the lazy dog.
```

接下来，输入 CTRL-D（即按住 CTRL 键并按 D）告诉 `cat` 它已经到达标准输入的文件末尾（EOF）。

```
$me@linuxbox~$ cat
The quick brown fox jumped over the lazy dog.
The quick brown fox jumped over the lazy dog.
```

在没有文件名参数的情况下，`cat` 将标准输入复制到输出，所以我们看到那行文本重复了。我们可以利用这种行为来创建短文本文件。假设我们想创建一个名为 `lazy_dog.txt` 的文件，其中包含 "the quick brown fox jumped over the lazy dog" 的文本。

```
$me@linuxbox~$ cat > lazy_dog.txt
```

接下来，输入 CTRL-D（即按住 CTRL 键并按 D）告诉 `cat` 它已经到达标准输入的文件末尾。使用这种技术，我们可以检查任何命令的输出。

## 管道

管道通常用于对数据进行复杂操作。通常情况下，以这种方式使用的命令被称为过滤器（filters）。过滤器接收输入，以某种方式对其更改，然后输出。

## > 和 | 的区别

初看起来，可能很难理解管道操作符 `|` 执行的重定向与重定向操作符 `>` 的区别。简单来说，重定向操作符将命令与文件连接，而管道操作符将一个命令的输出与第二个命令的输入连接。

## uniq: 报告或忽略重复行

`uniq` 命令通常配合 `sort` 使用。`uniq` 接受来自标准输入或单个文件名参数的排序数据列表（详情请阅 `uniq` 手页），并默认删除列表中的任何重复项。
