## 共享对象 API 函数

### `dladdr` (LibC.pas)

```
function dladdr(
  Handle: Pointer;
  var Info: TDLInfo;
): Integer;
```

**Description**

`dladdr` 函数返回有关共享对象句柄的信息。有关共享对象的信息通过 `TDLInfo` 结构体返回。

**Parameters**

- `Handle`: 使用 `dlopen` 函数打开的共享对象的引用句值。
- `Info`: `TDLInfo` 类型的变量。

**返回值**

该函数返回函数在共享库中的位置。虽然结果的数据类型是指针，但它应该被强制转换为与导出函数之参数和调用约定完全匹配的存储过程或函数类型。

**另需参考**

`dlopen`, `dlclose`, `dlerror`, `dlsym`

---

### `dlclose` (LibC.pas)

```
function dlclose(
  Handle: Pointer;
): Integer;
```

**Description**

此函数关闭之前使用 `dlopen` 函数打开的共享对象。它会减少共享库的引用计数，当没有应用程序引用该共享对象时，该共享对象将从内存中移除。

可选地，当共享对象从内存中移除时，会调用一个名为 `_fini` 的函数。通常，此函数被用作释放在对象共享对象过程中可能分配的任何资源的方法。

**Parameters**

- `Handle`: 使用 `dlopen` 函数打开库时返回的引用值。确保该对象本身确实引用了一个共享对象。如果不是，错误将无法被正确处理并可能导致核心转储（core dump）。

**返回值**

该函数返回共享对象被释放后的引用计数。

**另需参考**

`dlopen`, `dlsym`, `dlerror`, `dladdr`

**示例**

参见代码举例 8.10 - 动态加载共享对象的代码。

### `dlerror` (LibC.pas)

```
function dlerror: PChar;
```

**Description**

此函数用于测试在使用任何一个动态共享库函数时是否发生了任何问题。返回的消息对于日志记录和确定发生的问题很有用。一旦调用了此消息，该消息就会被清除。因此，连续调用两次此方法会导致清除错误消息。

**返回值**

如果在使用任何共享对象调用（如 `dlopen`、`dlclose` 或 `dlsym`）时发生错误，返回值是一个指向字符串的指针，该字符串包含有关发生情况的详细信息。由于在使用 `dlsym` 函数时拼错函数名而可能返回的结果示例：

```
/lib/SimpleMathCalls.so.1.0.0: undefined symbol: $SimpleAction
```

相反，如果没有发生错误，函数简单返回 `nil`。

**另需参考**

`dlopen`, `dlclose`, `dlsym`, `dladdr`

**示例**

参见代码举例 8.10 - 动态加载共享对象的代码。

### `dlopen` (LibC.pas)

```
function dlopen(
  Filename: PChar;
  Flag: Integer
): Pointer;
```

**Description**

此函数打开一个共享对象，该对象包含一组函数并返回库的引用。在使用共享对象中的任何函数或存储过程之前，必须调用此函数。

如果打开的共享对象有一个名为 "init" 的程序且尚未加载到内存中，则将调用此函数。对于用 Delphi 编写的共享对象，init 函数会自动导出，作为库源代码中 `begin` 和 `end` 之间的代码。

**Parameters**

- `Filename`: 共享对象的文件名或链接到共享对象的文件的文件名。`Filename` 可以共享对象文件的绝对路径，也可以仅文件名。当它只包含文件名时，Linux API 将在 `/lib/`、`/usr/lib/` 以及位于 `/etc/ld.so.cache` 的缓存文件中查找共享对象。为文件名传递 `nil` 将使库在其自己的进程中搜索。
- `Flag`: 指库函数应该如何加载。如果使用常量 `RTLD_NOW`，共享对象中的函数将立即加载到内存中。如果使用常量 `RTLD_LAZY`，则在第一次调用该库中的某个函数时才会打开库函数。

**返回值**

如果无法加载共享对象，函数返回 `nil`，可以通过调用 `dlerror` 函数找到有关错误的信息。如果函数成功，则返回一个共享库。

**另需参考**

`dlclose`, `dlsym`, `dlerror`, `dladdr`

**示例**

参见代码举例 8.10 - 动态加载共享对象的代码。
