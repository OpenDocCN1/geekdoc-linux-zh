
在示例的启动屏幕上，我们看到了文本“Running in Vi compatible mode.”（以 Vi 兼容模式运行）。这意味着 vim 的运行模式接近 vim 的正常行为，而不是其增强的行为。在本章中，我们希望以增强的行为运行 vim。要做到这一点，我们有几种选择。尝试运行 `vim` 而不是 `vi`。如果有效，考虑在你的 `.bashrc` 文件中添加 `alias vi='vim'`。或者，使用此命令向你的 vim 配置文件添加一行：

```
echo "set noc" >> ~/.vimrc
```

不同的 Linux 发行版以不同的方式对 vim 进行封装。某些发行版默认安装精简版的 vim，只支持有限的 vim 功能。在执行后续课程时，你可能会遇到功能缺失的情况。如果是如此，请安装完整版本的 vim。

就像我们之前学习 nano 一样，要学习的是如何退出。要退出，输入以下命令（注意冒号字符是命令的一部分）：

```
:q
```

shell 提示符将会返回。如果由于某种原因 vi 不会退出（通常是因为我们修改了尚未保存的文件），我们可以在命令后添加一个感叹号来告诉 vi 我们确实是想要执行该操作。

`:q!`

如果你在 vi 中“迷路”了，尝试双击两次 `ESC` 键来找回方向。

让我们再次启动 vi，这次向它传递一个不存在的文件名。我们就是这样通过以下命令创建一个新文件的：

```bash
[me@linuxbox ~]$ rm -f foo.txt
[me@linuxbox ~]$ vi foo.txt
```

如果一切顺利，我们应该看到类似这样的屏幕：

前面的波浪字符 (`~`) 表示该行没有文本。这表明我们有一个空文件。先不要输入任何内容！

关于 vi 需要学习的第二个重点（在学习如何退出之后）是 vi 是一个模态编辑器。当 vi 启动时，它处于命令模式。在这种模式下，几乎每个键都是一个命令，因此如果我们开始输入文字，vi 基本上会疯掉并搞一团乱。

## 进入插入模式

为了向文件中添加一些文本，我们必须首先进入插入模式。为此，我们按下 `i` 键。之后，如果 vim 以其标准的增强模式运行，我们将在屏幕底部看到以下内容（这在 vi 兼容模式下不会出现）：

```
-- INSERT --
```

现在我们可以输入一些文本。尝试一下：

The quick brown fox jumped over the lazy dog.

要退出插入模式并返回命令模式，按下 `ESC` 键。

## 保存我们的工作

要保存我们刚刚对文件进行的修改，我们必须在命令模式下输入一个 ex 命令。通过按下 `:` 键可以轻松实现。执行后，屏幕底部会出现一个冒号。

要写入我们修改后的文件，我们在冒号后输入 `w` 然后按回车。

```
:w
```

文件将被写入硬盘，我们会在屏幕底部看到一条确认消息，如下：

```
"foo.txt" [New] 1L, 46C written
```

> 如果你阅读 vim 文档，你会发现（令人困惑的是）命令模式被称为普通模式（normal mode），而 ex 命令被称为命令模式（command mode）。请小心。

## 移动光标

在命令模式下，vi 提供了大量的移动命令，其中一些是与其他编辑器共有的。表 12-1 列出了子集。

### 表 12-1：光标移动键

| 键 | 移动光标的操作 |
|---|---|
| `l` 或右箭头 | 向右移动一个字符。 |
| `h` 或左箭头 | 向左移动一个字符。 |
| `j` 或下箭头 | 向下移动一行。 |

### 表 12-1：光标移动键（续）

| 键 | 移动光标 |
|---|---|
| `k` 或上箭头 | 向上移动一行。 |
| `0` (零) | 到当前行的开头。 |
| `^` | 到当前行的第一个非空白字符。 |
| `$` | 到当前行的末尾。 |
| `w` | 到下一个单词或标点符号的开头。 |
| `W` | 到下一个单词的开头，忽略标点符号。 |
| `b` | 到上一个单词或标点符号的开头。 |
| `B` | 到上一个单词的开头，忽略标点符号。 |
| `CTRL-F` 或 `PAGE DOWN` | 向下一页。 |
| `CTRL-B` 或 `PAGE UP` | 向上一页。 |
| `数字+G` | 到某一行。例如，`1g` 移动到文件的第一行。 |
| `G` | 到文件的最后一行。 |

为什么使用 `h`、`j`、`k`、`l` 键来移动光标呢？在最初编写 vi 时，并不是所有的视频终端都有方向键，熟练的打字员可以使用普通的键盘键移动光标，而无需将手指离开键盘。

vi 中的许多命令都可以以一个数字作为前缀，例如表 12-1 列出的 `G` 命令。通过在命令前加一个数字，我们可以指定执行命令的次数。例如，命令 `5j` 会导致 vi 光标向下移动五行。

## 基础编辑

大多数编辑由几个基本操作组成，例如插入文本、删除文本以及通过剪切和粘贴移动文本，vi 无疑以其独特的方式支持所有这些操作。vi 还提供了有限形式的撤销（undo）。如果我们在命令模式下按下 `u` 键，vi 将撤销你所做的更改。在我们尝试一些基础编辑命令时，这会非常有用。

## 删除文本

正如预期的，vi 提供了多种删除文本的方法，所有方法都包含两个按键。首先，`x` 命令将删除光标位置的字符。`x` 前可以加一个数字，指定要删除多少个字符。`d` 命令更通用。像 `x` 一样，它的前面也可以加一个数字来指定执行删除的次数。此外，`d` 总是跟着一个控制删除范围的移动命令。表 12-3 提供了一些示例。
