中止文件传输

要中止文件传输，请使用终端键（通常为 `Ctrl-C`）。

发送传输将立即停止。`ftp` 通过先向远程服务器发送 `ftp` 协议命令来停止传入（接收）传输，然后丢弃任何后续接收的数据。完成此操作的速度取决于远程服务器对 `ABOR` 处理的支持。如果远程服务器不支持 `ABOR`，传输可能会继续完成或被手动杀死。

文件命名约定

作为参数指定的文件将根据以下规则处理：

- 如果指定了文件名，则按其使用。
- 如果未指定文件名，`ftp` 将 `local-file` 名称（根据任何 `trans` 或 `nmap` 设置处理）分配给 `remote-file` 名称。
- 如果 `get` 或 `met` 命令的目标文件已存在同名文件，则在名称后附加 `.1`。如果生成的名称与另一个现有文件匹配，则在原始名称后附加 `.2`。如果此过程持续到 `.99`，则会打印错误信息且不进行传输。`ftp` 会报告唯一文件名。
- `runique` 不影响从 shell 命令生成的本地文件（见下文）。其默认值为关闭。
- 远程服务器报告唯一名称。默认情况下，`sunique` 为关闭。
