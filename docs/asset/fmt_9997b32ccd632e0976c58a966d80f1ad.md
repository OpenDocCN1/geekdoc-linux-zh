# 鳕鱼配土豆

# 极佳的鯪鱼

取鯪鱼（或任何易翻滚的鱼），切成片并晾干，在每片鱼上撒上胡椒、盐和一撮混合香料，将每片鱼紧紧卷起，紧密地放入盘中以防松散。取等量的醋和啤酒；若不喜欢用黄油，则用醋加一些黑胡椒，并撒上大量的干混合香草和盐。淋在鱼上，在顶部放上一块黄油，在中火烤箱中（中型派盘）烤1 小时15 分钟。

# 鱼保存法

这种鱼可以廉价购买大量，并用此方法保存几周。准备等量的温热醋和水，以你认为足够覆盖莳萝的量为准，并留出损耗；每夸升汁水加入一小匙混合香料，再加入四个小洋葱、一小束捣碎的百香、半个柠檬的薄皮和胡椒；如果用塔香草醋效果更好。洗净小鯱鱼，去去尾和鱼头，铺在深盘中。将汁水淋在鱼上，盖上一张大纸，在凉的烤箱中烘烤2至3 小时；根据需要烹饪。放凉后备用，需要时取出。
