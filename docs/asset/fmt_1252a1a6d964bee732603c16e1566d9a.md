### 关于模式的解释注释：
```
# ^[0-9]{3}\-[0-9]{2}\-[0-9]{4}$
# 123456789_123456789_123456789_12
# 在第一个位置，'^' 意味着“开头”。
# 在第 32 个位置，'$' 意味着“数据结束”。
# 第 2 到第 9 位：[0-9]{7}
# 我们正在寻找 3 个数字。
# 以下模式具有相同的作用：
# [0-9]{3}[0-9]{9}
# 第 10 到第 12 位：\-
```

# '\-' 意味着“查找一个字面上的连字符，例如 [0-9]”。

# (连字符后面的问号意味着连字符是否存在是不确定的；

# 如果找到了连字符，没关系；如果没找到，也是可以的。)

```
```
# 第 13 到第 20 位：[0-9](2)

# '[0-9](2) 意味着“查找两个数字”。

# 以下模式等效于：[0-9][0-9]
```
```
# 第 21 到第 23 位：\-?

# '\-' 意味着“查找一个字面上的连字符”。

# 连字符后面的问号意味着连字符是否存在是不确定的。
```

# 第 24 到第 31 位：[0-9]{4}

# '[0-9]{4} 意味着“查找 4 个数字”。
```
