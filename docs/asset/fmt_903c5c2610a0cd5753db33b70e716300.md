由于潜在的专利纠纷，大多数分发者花了很长时间才整合Mono，但它现在运行良好。更此外，Mono同时支持C#和Visual Basic，以及完整的.NET 1.0和1.1框架（以及2.0框架的大部分），使其易于学习和高效使用。

曾有人担心Mono可能会消失。在2011年5月初，Unity收购了带有SU Linux发行版的Novell。Novell曾领导Mono项目。Unity在收购后做的第一件事之一取消了Mono项目。他们解雇了所有的Mono开发者，大约30人。

2011年5月16日，Mono的首席开发者Miguel de Icaza宣布了一了一名为Xamarin的新公司（http://x.com）。该新公司的创建是为了继续开发Mono并构建Mono应用。2011年7月18日，SUSE宣布已将知识产权协议和永久许可扩展到Xamarin，以便继续使用和开发Mono平台以及使用Mono的。

没有人知道Mono的未来如何，但我们知道它尚未放弃。Mono和一些用Mono编写的程序默认安装在Ubuntu 12.04中，但在本版章节定稿时，12.10的计划尚不确定。

可以确定，Mono将继续在Ubuntu仓库中可用，无论它默认是否安装。你可以从`http://mono-project.com/`了解更多关于Mono。要在Ubuntu上使用，你需要在常用的编辑器中编写程序并安装`mono-devel`包。

## Ruby

在Ruby中，一切都是对象。每个对象都有其自己的属性和方法。你可以使用闭包（在Ruby中称为块）。你不需要声明变量，并且只有单继承。Ruby通过编写C来扩展。Ruby受到Lisp、Perl、Python和Smalltalk等不同方式的影响，最初设计用于系统管理。大多数程序员倾向于结合名为Rails的框架使用Ruby。这个框架紧密遵循DRY原则：“不要重复自己”。所有的信息都存储在一个地方。Ruby on Rails运行在Apache或Nginx等Web服务器上并使用Gems (rubygems.org)进行扩展。要在Ubuntu上使用Ruby，你需要在常用的编辑器中编写程序。为了运行它们，你可以从Ubuntu仓库安装`ruby`解释器。因为Ruby经常变化，官方文档建议不要使用发行版，而是直接从Ruby网站下载最新版本。

# Android简介

在进一步介绍Android软件开发的细节之前，对Android架构进行更详细的介绍是合适的。我们的描述从硬件开始，并在此基础上层层地构建。

# 硬件

虽然已经证明可以在其他平台上运行Android，但主要的平台是ARM。ARM处理器是32位的精简指令集计算机（RISC）处理器。与其他RISC处理器一样，它们为速度而设计，其理念是更简单的处理器指令集可以产生更高的效率和吞吐量。ARM处理器还针对低功耗设计，使其成为移动和嵌入式设备的理想选择。事实上，ARM是这些市场中的主导处理器。

# Linux内核

在Android栈中运行的第一层软件是定制的Linux内核。大多数定制以功能增强或优化的形式出现，以帮助Android和Linux更高效地协同工作。最初，Google特意提交了代码，但某些功能被主线Linux内核开发者拒绝纳入标准的Linux内核中。这意味着，为了保留其所需的代码定制，Google必须创建一个Linux内核的分支（fork），这在内核发布的许可下是允许的。第21章“内核与模块管理”提供了Linux内核的介绍。

# 库

在内核之上运行着一套软件库。这些库被Android的高层组件使用，并提供给开发者在使用Android软件开发包（SDK）编写Android应用时使用，SDK将在本章后面讨论。这些库包括标准C库的一个版本（libs）、用于许多流行媒体格式录制和播放的库、图形和网络浏览器引擎、字体渲染等。

# Android运行时

应用程序层（下文描述）中Android的某些高层组件直接与上述库交互。应用程序层的其他部分则通过Android运行时与库交互。Android软件主要用Java编写，使用Google开发的和特定的Java库。这些软件运行在Android运行时上，它由一些运行在名为Dalvik的特殊虚拟机之上的额外核心库组成。核心库提供了Java的大部分功能。Dalvik执行执行即时编译（JIT）并针对移动设备进行了优化。

# 应用程序框架

应用程序框架（Application Framework）是一组有用的系统和服务，顶级应用程序可以调用它们。这些服务提供了访问系统信息、使用设备硬件、创建通知等标准化方法。它们与Android中包含的核心应用程序使用的是同一套服务，终端用户创建的应用程序可以与Android提供的相同的外观、感觉和交互风格。

# 应用程序

Android自带了一套核心应用程序。这些包括网络浏览器、短信程序、联系人管理程序、日历、电子邮件客户端等。如前文所述，Android软件是用Java编写的。
