网络时间协议 – 一种构建在 TCP/IP 之上的协议，通过参考原子钟以及互联网上的其他时钟来确保准确的本地时间计时。该协议能够在长时间的时间内以毫秒级同步分布式时钟。来自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`。

网络时间协议 (NTP) 用于将计算机时间与参考时间源同步。`ntp` 软件包包含守护进程，这些守护进程将通过 NTP 协议和 NTP 服务器将您的计算机时间同步到协调世界时 (UTC)。`ntp` 软件包包括 `ntdate`（用于通过网络从远程机器获取日期时间）和 `ntpd`（一个持续调整时间的守护进程）。如果您需要通过网络保持系统时间同步，请安装 `ntp` 软件包。来自 RedHat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`。

用于参考时钟的 NTP v4。此版本的 `ntp` 守护进程包含了用于各种无线电钟和其他用于创建参考时钟的设备驱动程序。如果您没有无线电钟，请使用 `ntp-simple` 软件包，因为它消耗的内存更少！如果您打算构建一个高质量的第 1 层时钟，请查看 Ulrich Wind 为 Linux 内核编写的 PPSkit，它位于 `linux/daemons/ntp` 目录下。来自 Debian 3.0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
