我们唯一可以处理的退出信号是 `kill -9` 信号，因为你无法捕获 `kill -9`。如果你想在 `trap` 语句列表中添加更多内容，还有更多的退出信号，但我认为最常用的已经列出。

此脚本中执行的最后一个命令是 `exit`，因为在任何情况下必须执行 `cleanup_exit` 函数。如果 `exit` 不是最后一个命令，用户将返回到命令提示符，而没有任何日志记录。这种行为的原因是脚本的执行实际上是原始 shell 的一个 fork（ fork）。因此，当脚本命令停止执行时， fork 进程中的一个 shell 会终止，而不是原始 shell。这最后的退出会注销原始 shell。你可能希望将此位于 `cleanup_exit` 函数中的最后一个 `exit` 替换为 `logout`，这将确保用户注销系统。
