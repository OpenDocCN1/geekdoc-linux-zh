附带的 CD 包含示例源码，以及 Linux API、Kylix 开放版和 Kylix 2 测试版的源码。这些组织在以下目录中：

```
gunzip TomesOfKylixSource.tar.gz
tar -xf TomesOfKylixSource.tar
```
