
使用分号、换行符或右括号终止语句。空的 `expression-list` 代表整行输入。表达式根据需要取布尔或数值，并使用运算符 `+`、`-`、`*`、 `/`、`%`、`^`、`=` 以及连接（由空格表示）构建。表达式中还可以用运算符 `++`、`--`、`+=`、`-=`、`*=`、 `/=`、`=`、`>=`、`<=`、`==`、`!=` 和 `?`。

变量可以是标量、数组元素（表示为 `x[i]`）和字段。变量初始化为空字符串或 `0`。数组下标可以是任何字符串，但必须是数字；这种语法允许一种关联内存的形式。字符串常量用引号（`""`）引起，内部识别常见的转义字符。

`print` 语句在标准输出上格式化其参数，如果存在 `?expression` 则在文件中，如果存在 `|cmd` 则在管道中。`print` 语句产生的输出由输出记录分隔符决定，每个参数之间用当前输出字段分隔符分隔。`printf` 语句根据 `fmt` 描述的格式格式化表达式列表（参见 `printf(3)`）。

## 内置函数

### 算术函数

- `cos(x)` 返回 `x` 的余弦，其中 `x` 为弧度。
- `sin(x)` 返回 `x` 的正弦，其中 `x` 为弧度。
- `exp(x)` 返回 `x` 的指数函数。
- `log(x)` 返回 `x` 的自然对数。
- `sqrt(x)` 返回 `x` 的平方根。
- `int(x)` 将参数截断为整数。如果 `nx>0`，则向 0 截断。

### 字符串函数

- `index(s, t)` 返回字符串 `s` 中字符串 `t` 首次出现的位置，如果没有出现则返回 0。
- `int(s)` 将 `s` 截断为整数。如果没有指定 `s`，则使用 `$0`。
- `length(s)` 返回作为字符串处理的参数长度，如果没有参数则返回整行的长度。
- `match(s, re)` 返回正则表达式在字符串 `s` 中出现的位置，如果没有出现则返回 0。
- `split(s, a, fs)` 将字符串 `s` 拆分为数组元素 `a[1]`、`a[2]`、`a[n]` 并返回 `n`。分离通过正则表达式 `fs` 或在未给出 `fs` 的情况下使用字段分隔符 `FS` 完成。
- `printf(fmt, expr, expr...)` 根据 `fmt` 给出的 `printf` 格式格式化表达式并返回生成的字符串。
- `substr(s, m, n)` 返回 `s` 中从位置 `m` 开始的长度为 `n` 的子字符串。

### 输入/输出函数

`getline` 将 `$0` 设置为当前输入文件的下一个输入记录。`getline` 输入成功返回 1，文件结束返回 0，错误返回 -1。

# basename, dirname

## basename, dirname — 提取路径名的部分

### 概要

```
/usr/bin/basename string [suffix]
/usr/xpg4/bin/basename string [suffix] dirname string
```

### 描述

你可以使用 `basename` 命令从文件名中剔除路径。例如，如果你有一个包含完整路径的环境变量，你可能只想提取文件名而不包含完整路径。这通常用于 shell 过程中的替换标记（`` ``）内部。

- `/usr/bin/basename`

  后缀是在 `expr(1)` 手册页上定义的模式。

- `/usr/xpg4/bin/basename`

  `/usr/xpg4/bin/basename` 是 `/usr/bin/basename` 命令的 POSIX 兼容版本。参见 `standards(5)`。

后缀是一个字符串，对其包含的任何字符均不具有特殊含义。

相反，你可以使用 `dirname` 命令剔除文件名，并返回字符串中除路径最后一层之外的所有目录路径。

### 示例

以下示例首先显示了 `EDITOR` 环境变量的完整路径。然后，它使用 `basename` 命令显示编辑器的名称，使用 `dirname` 命令显示不带文件名的路径。

```
castle% env | grep EDITOR
EDITOR=/usr/dt/bin/dtpad
castle% basename $EDITOR
ddtpad
castle% dirname $EDITOR
/usr/dt/bin
castle%
```

### 环境变量

参见 `environ(5)` 获取影响 `basename` 和 `dirname` 执行的以下环境变量的描述：`LC_CTYPE`、`LC_MESSAGES` 和 `NLSPATH`。
