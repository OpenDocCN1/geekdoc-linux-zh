## 卤代烃
一种其中一个或多个原子被卤素取代的脂肪族化合物。

卤代烃是指一个原子被卤素（氟 (`F`)、氯 (`Cl`)、溴 (`Br`) 或碘 (`I`)）取代的化合物。例如，溴化物（乙溴 `CH3CH2Br`）。已制备了许多烷卤醚；这些卤化物是反应活性的中间体，而不是产物。

烷卤醚是制备许多其他取代化合物的原料。带有孤对电子的取代卤化物是重氮盐。

卤素与苯环或芳香环结合的化合物通过亲电取代形成，使用 `FeCl3` 或 `FeBr3` 等路易斯催化剂增强环的活性。

在烷卤醚中，每个卤原子通过与母分子的简单亲核取代被氢取代。由于原子尺寸很小，空间位阻最小。这些化合物在化学上是惰性的，具有与其他任何有机化合物不同的性质。

烃类包含碳和氢的组合以满足碳的需求。氢氟烃也被称为 `HF`。它们不含氯，这些化合物对臭氧层消耗没有贡献。

全氟烃仅含碳和氟。它们通过前缀 `fluoro-` 命名。

许多含有两个或更多卤原子的化合物具有特殊性。甲烷 (`CH4`) 可以被多个卤素取代，产生如 `CH3Cl`、`CH2Cl2` 和 `CHCl3` 等化合物。

甲烷的氯化导致单氯、三氯和四氯产物的混合物。可以通过调整反应物的比例来控制其量。氯氯通过这种氯化过程以及甲醇与 `HCl` 的反应产生。二氯甲烷是主要产物，主要用作溶剂或聚化学中的试剂。甲酸甲是甲醛的高度毒性异构体。

氯代液体产物用于工业化学。

氯氟烃是甲烷和乙烷，所有氢原子均被氯和氟的组合所取代。氯氟烃被称为 `CFCs`。它们曾与氨和溶剂一起用制冷设备中的无毒、不可燃制冷剂。其他化合物用于满足喷雾、空调和推进剂的需求。

哈密顿方程可以由拉格朗日方程导出。系统的坐标 `$q_j$` (`$j = 1, 2, ..., f$`) 以及系统的动力学描述由拉格朗量 `$L(q, dq, t)$` 给出，其中 `$q$` 是所有坐标，`$dq$` 是它们的时间导数。拉格朗日方程由方程 (1) 给出。与 `$q$` 共轭动量

```
d L / d q_j = p_j (1)
```

```
p_j = d L / d dq_j (2)
```

哈密顿量 `$H$` 由方程 (3) 导出。哈密顿正则方程为方程 (4)。

```
H = \sum p_j dq_j - L(q, dq, t) (3)
```

```
dH / d dq_j = p_j (4)
```
