
# 850 描述

`awk` 命令是一种完整的编程语言，对于计算和模式匹配非常有用。`awk` 的名称是由该语言的三个位开发者姓氏的首字母组成的缩写：Aho、Weiner 和 Kernighan。`nawk` (new awk) 命令是 `awk` 的极大增强和优化版本。

`/usr/bin/nawk` 和 `/usr/xpg4/bin/awk` 使用 `nawk` 编程语言执行程序，该语言专门用于处理文本数据。一个 `nawk` 程序是模式和相应动作的序列。你必须用单引号 (`''`) 将指定程序的字符串括起来以防止其被 shell 解释。你可以在命令行中通过 `program` 指定模式-动作语句的序列，或者通过 `-f profile` 选项指定一个或多个文件。当读取的输入匹配模式时，将执行与模式关联的动作。

输入被解释为记录（records）的序列。默认情况下，记录是一行，但你可以通过内置变量 `RS` 更改此默认值。输入的每条记录都会与程序中的每个模式进行匹配。对于每个匹配的模式，都会执行相关的动作。

`nawk` 命令将每个输入记录解释为字段（fields）的序列，默认情况下，字段是非空字符的字符串。你可以使用内置变量 `FS` 或 `-F ERE` 选项更改默认的空白字符字段分隔符（空格和制表符）。`nawk` 命令将记录的第一个字段识别为 `$1`，第二个识别为 `$2`，以此此类推。符号 `$0` 指代整个记录。

## 注意

`nawk` 是 `awk` 的增强版本，提供了以前版本不具备的功能。

### 选项

- `-F ERE` 使用正则表达式定义输入分隔符。
- `-f profile` 指定包含 `awk` 程序的文件。你可以多次指定此选项。
- `-v assignment` 赋值格式为 `var=value`，其中 `var` 是变量名。如果有多个实例，以最后一个为准。

# awk

## 输入文件

`awk` 程序的输入文件可以来自以下源：

* 通过修改 `awk` 变量 `ARGV` 和 `ARGC` 的任何文件操作或等效操作。
* 在无任何文件操作时的标准输入。
* `getline` 函数的文本文件参数。无论 `RS` 是否设置为换行符以外的值，对于这些文件，实现支持直到 `LINE_MAX` 字节的指定终止符并支持更长的记录。
* 包含 `awk` 程序的 `-f profile` 选项的文件参数。
* 当未指定文件操作或文件操作为 `-` 时的标准输入。

## 扩展描述

`awk` 程序由以下形式的对组成：

```
pattern { action }
```

你可以省略模式或动作，包括包含它们的括号字符。用分号或换行分隔模式-动作语句。

缺失模式匹配任何输入记录，缺失动作等同于将匹配的输入记录写入标准输出的动作。

`awk` 程序的执行如下：

1. 按出现顺序执行所有 `BEGIN` 模式关联的动作。
2. 处理每个文件操作（如果没有指定文件则处理标准输入），从文件中读取数据直到遇到记录分隔符（默认为换行符）。
3. 使用当前的 `FS` 值将当前记录拆分为字段，按出现顺序评估程序中的每个模式，并执行与每个匹配模式相关的动作。
4. 匹配模式的动作在评估后续模式之前执行。
5. 按出现顺序执行所有 `END` 模式关联的动作。

## awk 中的表达式

表达式描述了模式和动作中的计算。下表按优先级从高到低列出了有效的表达式操作。

### awk 853

在语法形式歧义的表达式求值中，高优先级运算符先于低优先级运算符求值。在表中，`expr`、`expr1`、`expr2` 和 `expr3` 表示任何表达式，而 `lvalue` 表示任何可以赋值的实体（即赋值运算符的左侧部分）。

| 语法 | 名称 | 结果类型 | 结合性 |
|---|---|---|---|
| `( expr )` | 分组 | `expr` 的类型 | N/A |
| `$expr` | 字段引用 | 字符串 | N/A |
| `++ lvalue` | 前置增量 | 数值 | N/A |
| `-- lvalue` | 前置减 | 数值 | N/A |
| `lvalue ++` | 后置增量 | 数值 | N/A |
| `lvalue --` | 后置减 | 数值 | N/A |
| `expr ^ expr` | 幂 | 数值 | 右结合 |
| `! expr` | 逻辑非 | 数值 | N/A |
| `+ expr` | 一元加 | 数值 | N/A |
| `- expr` | 一元负 | 数值 | N/A |
| `expr * expr` | 乘法 | 数值 | 左结合 |
| `expr / expr` | 除法 | 数值 | 左结合 |
| `expr % expr` | 取模 | 数值 | 左结合 |
| `expr + expr` | 加法 | 数值 | 左结合 |
| `expr - expr` | 减法 | 数值 | 左结合 |
| `expr expr` | 字符串拼接 | 字符串 | 左结合 |
| `expr < expr` | 小于 | 数值 | 无 |
| `expr <= expr` | 小于等于 | 数值 | 无 |
| `expr != expr` | 不等于 | 数值 | 无 |
| `expr == expr` | 等于 | 数值 | 无 |
| `expr > expr` | 大于 | 数值 | 无 |
| `expr >= expr` | 大于等于 | 数值 | 无 |

### 854

| 语法 | 名称 | 结果类型 | 结合性 |
|---|---|---|---|
| `expr ~ expr` | ERE 匹配 | 数值 | 无 |
| `expr !~ expr` | ERE 不匹配 | 数值 | 无 |
| `expr in ( index ) in array` | 多维数组成员检查 | 数值 | 左结合 |
| `expr && expr` | 逻辑与 | 数值 | 左结合 |
| `expr || expr` | 逻辑或 | 数值 | 左结合 |
| `expr1 ? expr2 : expr3` | 条件表达式 | 所选内容的类型 | 右结合 |
| `lvalue ^= expr` | 幂赋值 | 数值 | 右结合 |
| `lvalue %= expr` | 取模赋值 | 数值 | 右结合 |
| `lvalue *= expr` | 乘法赋值 | 数值 | 右结合 |
| `lvalue /= expr` | 除法赋值 | 数值 | 右结合 |
| `lvalue += expr` | 加法赋值 | 数值 | 右结合 |
| `lvalue -= expr` | 减法赋值 | 数值 | 右结合 |
| `lvalue = expr` | 赋值 | `expr` 的类型 | 右结合 |

每个表达式都有一个字符串值、一个数值值或两者都有。除非特定上下文另有说明，表达式的值会被隐式转换为其使用所需的类型。字符串值通过等效于以下调用转换为数值值：

```
setlocale(LC_NUMERIC, "*");

numeric_value = atof(string_value);
```
