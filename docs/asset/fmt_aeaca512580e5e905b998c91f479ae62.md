
黏膜表面在呼吸道、胃肠道和泌尿生殖道中也提供了机械屏障。这些表面沐浴在具有抗菌活性的分泌物中。在呼吸道中，机械清洁通过咳嗽和黏液纤毛运动完成。鼻窦、中耳、支气管树和肺部的反复感染发生在纤毛运动受损的个体中。这些感染通常由*肺炎链球菌*（原文误写为 Staphylococcus pneumoniae，结合上下文及常见病原体，此处保留原文译名逻辑但需指出学名对应关系，若严格翻译原文应为“肺炎葡萄球菌”，但根据医学常识及后文 Neisseria 等，原文可能指 Streptococcus pneumoniae 或 Staphylococcus 属。此处严格按原文翻译学名：*Staphylococcus pneumoniae* 和 *H. influenzae*（流感嗜血杆菌），即更具毒力的化脓性鼻咽喉部微生物。注意：原文此处学名拼写可能有误，Staphylococcus 为葡萄球菌，Pneumoniae 通常指肺炎球菌 Streptococcus。作为翻译员，我将直译原文提供的学名，并保留斜体。） *Staphylococcus pneumoniae* 和 *Haemophilus influenzae*，即鼻咽喉部发现的更具毒力的化脓性微生物。纤毛运动的缺陷也会导致吸烟者和大量饮酒者发生细菌性呼吸道感染。参见**葡萄球菌属**。

一旦皮肤和黏膜的自然屏障被突破，下一个主要的防御线是多形核白细胞。拥有这些吞噬细胞功能障碍的个体，其固有微生态菌引起的严重感染发病率会增高。

补体系统是身体消除入侵微生物的另一种非特异性机制。补体蛋白与网状内皮系统的器官（脾脏、肝脏和骨髓）协同作用，在从血液中清除包膜细菌方面起着关键作用。脾切除个体以及因镰状细胞病导致脾脏无功能的个体，其由*肺炎链球菌*（*S. pneumoniae*）、*流感嗜血杆菌*（*H. influenzae*）、*脑膜炎奈瑟菌*（*Neisseria meningitidis*）以及最近被认定的异常微生物引起的暴发性感染发病率增高。参见**补体**。

# 微斜长石

三斜晶系钾长石，`KAlSi₃O₈`，通常含有百分之几的钠长石（`Ab = NaAlSi₃O₈`），以固溶体形式存在。其硬度为 6；比重为 2.56；平均折射率为 1.52；颜色为白色（绿色品种称为亚马逊石或亚马逊石）。微斜长石见于某些较高程度的区域变质岩中，但在伟晶岩、花岗岩及相关深成火成岩中更为常见。在后者中，它常以微斜长石斑晶的形式出现，包含出溶的低钠长石共生体。参见**长石；透长石**。

# 微型计算机

微型计算机是一种数字计算机，其中央处理单元由微处理器（单片半导体集成电路芯片）组成。曾经，微型计算机的功能不如大型计算机强大，但现在的微型计算机功能已与几年前的迷你计算机和超迷你计算机相当。这 partly 归因于每一代微处理器处理能力的不断提升，以及芯片中增加了大型计算机的功能特性，如浮点运算、计算机硬件、内存管理和多处理器支持。参见**集成电路；微处理器；多处理**。

微处理器是推动个人计算机和工作站增长的核心技术。当今微处理器的功能与功耗降低相结合，创造了一类新的微型计算机：手持设备。其中一些设备实际上是通用微型计算机。它们拥有液晶显示（LCD）屏幕，并使用可运行多种通用应用程序的操作系统。许多其他设备服务于固定目的，例如提供显示屏以接收基于文本的寻呼信息的电话，以及利用卫星定位信号绘制车辆位置的汽车导航系统。参见**液晶；移动无线电；无线电寻呼系统；卫星导航系统**。

微处理器作为微型计算机的中央处理单元（CPU），执行执行程序所需的所有操作（见图）。

存储器子系统使用半导体随机存取存储器（RAM）来临时存储数据或程序。存储器子系统还可以包含一个小的高速二级内存缓存，通过将经常使用的数据对象或程序代码段存储在一个高速 RAM 中来提高系统性能。

图形子系统由在彩色监视器或 LCD 屏幕上显示信息的硬件组成；图形内存缓冲区存储屏幕上显示的图像，数模转换器（DACs）生成在模拟监视器上创建图像的信号，可能还有专门用于加速二维或三维图形绘制的硬件。（由于 LCD 屏幕是数字设备，图形子系统直接将数据发送到屏幕，而不是通过 DAC。）参见**数模转换器**。

存储子系统使用内部硬盘驱动器或可移动介质来持久存储数据。

通信子系统由高速调制解调器或连接计算机到网络所需的电子部件组成。

微型计算机软件是使微型计算机变得有用的逻辑。软件由程序组成，程序是指令集，指导微型计算机通过一系列任务。启动（引导）例程初始化 ROM，初始化所有设备，加载操作系统软件并启动它。所有微型计算机都使用操作系统，该操作系统提供基本服务，如输入、简单的文件操作以及程序的启动或终止。过去，操作系统曾是个人计算机和工作站之间的主要区别之一，但今天的个人计算机操作系统也提供高级服务，如多任务处理、网络处理和虚拟内存。所有微型计算机都利用位图图形显示来支持窗口操作系统。参见**操作系统；软件**。

# 微透析采样

微透析采样是一种对体内基本任何组织或流体区间的细胞外间隙进行采样的方法。可以进行长时间的连续采样，对实验动物的干扰最小。微透析提供了一条采样细胞外液的途径，而无需移除液体；并在不添加液体的情况下给予化合物。所得样品干净，适合直接分析。

微透析采样通过在感兴趣的部位植入短段的空心纤维透析膜来进行。纤维用采样溶液（灌流液）缓慢灌流，其离子组成和 pH 值与被采样组织的细胞外液紧密匹配。细胞外液中的低分子量化合物扩散进入纤维，并被扫入收集瓶中进行后续分析。该系统类似于一个人工血管，可以输送化合物并去除产生的代谢物。参见**透析；膜分离**。

微透析是一个扩散控制的过程。通过探头的灌流率通常在 0.5 到 5.0 µL/min 的范围内。在此流速下，透析膜上没有净液体流动。物质传输的驱动力是细胞外液与探针内液体之间的浓度梯度。参见**扩散；传输过程**。

微透析采样最大的应用领域是在神经科学中。微透析探针可以植入清醒动物的特定脑区，以便将神经化学活动与行为联系起来。大多数研究集中在确定多巴胺或其他单胺类神经递质上。参见**神经生物学**。

微透析探针已被植入实验动物和人类的皮肤，以确定经皮药物递送系统从角质层递送药物的情况。使用微透析研究了向肿瘤递送抗癌药物。参见**药物递送系统；药理学**。

微透析采样也用于研究体内化合物的代谢。肝脏和肾脏等代谢器官已通过微透析采样进行研究。此外，通过微透析采样胆道，可以从单只实验动物中获得完整的代谢谱。这种方法极大地减少了评估新药物代谢所需的实验动物数量。[C.E.Lu]

# 微机电系统（MEMS）

微机电系统是将微机械与微电子耦合的系统。这类系统也被称为微型系统（Microsystems），将微机械与微电子耦合也称为微电子学。微机械指主要涉及具有亚毫米尺寸和相应微米级或更小公差机械部件的微机械设计和制造。MEMS 所涵盖的系统类型代表了对执行信号和信息处理功能与机械世界之间作用的传感器的需求。这种对多个工程领域的耦合导致了一个高度跨学科的领域，相应地影响着生物学和医学、电信、汽车工程和国防等几乎所有科学与技术分支。最终，实现一种“智能”MEMS 可能针对某些应用进行设计，将信息处理任务与传感任务集成，产生能够自主感知并相应反应于环境的设备。参见**换能器**。

MEMS 背后的驱动因素包括，由于器件尺寸减小，对封装形状约束的独立性更高。此外，由于批处理制造方案（如用于集成电路处理的那些方案，它们构成了 MEMS 制造的基础），可重复的制造工艺优势以及经济优势也可以随之而来。然而，在决定集成方法是否有益时，许多技术和制造上的权衡都会发挥作用。在某些情况下，效用最大的器件设计基于混合方法，即机械处理和电子处理在最终封装步骤之前是分离的。MEMS 解决的传感需求衍生出两大类器件：输入换能器或微型传感器，以及输出换能器或微型执行器。参见**集成电路**。
