## 6.9 IPv6 版本

在很大程度上，IPv6 代码是基于 IPv4 代码的，因此我们只需要关注它的不同之处。IPv6 既更复杂更简单。例如，它的自动配置意味着许多相关的协议都不再需要。另一方面，这意味着内置功能更加复杂。

### 6.9.1 IPv6 头部定义

```c

/* IPv6 固定头部 */

struct ipv6hdr {
    if defined(__LITTLE_ENDIAN_BITFIELD)
        __u8 priority:4,
        __u8 version:4;
    elif defined(__BIG_ENDIAN_BITFIELD)
        __u8 version:4,
        __u8 priority:4;
    else
#error "Please fix <asm/byteorder.h>"
    __u8 flow_lbl[3];
    __u16 payload_len;
```
