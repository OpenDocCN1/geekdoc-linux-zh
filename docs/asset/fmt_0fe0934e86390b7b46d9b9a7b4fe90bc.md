## 1.1 从根本上说，为什么要用 Linux？

如果你真正热爱计算机，Linux 就是你梦想中的操作系统。它比世界上任何其他操作系统都要趣。Linux 是计算机爱好者的乐堂。

Linux 之所以具有革命性，是因为它是`开源软件`（`Open Software`）。我们的科学技术得益于信息的免费获取、同行评审，以及拾取、修改或扩展想法的能力。开源软件是将科学方法应用于软件开发领域的实现。Linux 许可带来的拾取、修改和扩展的自由，提供了一个承诺：在 Linux 许可下的软件开发将像科学的发展一样持续下去。

马匹的制造、玻璃吹制或测量曾是严守的秘密。得益于少数人对技术诀分享，科学技术在 500 年前发生了爆炸式增长。为什么在印刷时代之前科学技术相对停滞不前？“商业秘密”式的增长模式有其局限性：开发会持续，直到学习速度等于遗忘速度。将技术诀转移到公共领域（在纸面上）将平衡位置推到了更高的水平，经过 500 年的剧烈发展，我们仍未实现这一目标。

如果你感兴趣，我可以展示借用化学平衡领域的方程，以更正式的方式描述这一点。核心点是印刷增加了受众群体，并允许信息跨越空间和时间。

在印刷早期，许多敢于分享的人因为泄露“商业秘密”而被暗杀。Linux 就像是古登堡写字时所处的计算机时代。希望这次不会发生暗杀（-）。Linux 确实会与那些声称拥有信息“所有权”的人发生激烈冲突，他们正试图夺回失去的 500 年。。

开源对计算机安全也有影响。想象一架基于秘密“科学法则”制造的飞机，根据未经审查的设计建造，其内部结构除了制造商外，无人可以检查。你会相信这架独特的、完全专有的、显然是由聪明且资金充足的营销人员在地下室建造的飞机，会比一架在成千上万与制造商秘密计算机程序无关的批判性工程师和爱好者监督下公开建造的飞机更安全吗？开源 Linux 特别适合任务关键型应用——它的安全性和力量基于稳健的解决方案，这些解决方案不受任何限制地经过审查并不断改进。

## 1.2 Linux 适合我吗？

只有你自己才能回答这个问题。Linux 是一个成熟、强大、安全且极其多功能的类 Unix 操作系统。强大和多功能伴随着代价——你可能需要具备计算机知识来设置和维护 Linux。如果操作系统和应用程序设置得当，Linux 是一个相对易用的操作系统。所以，如果你为你的母亲设置一个图形账户并在 GUI 桌面面上选择图标/菜单，你母亲就能使用 Linux。Linux 是安全的，所以无论你母亲如何努力，她都不会损坏系统——除非使用锤子！

Linux 与 `MS Windows` 有很大不同，因此不要认为如果你能玩转 Windows，那么 Linux 也会轻而易举。你可能需要学习。另一方面，如果你来自 `UNIX` 背景，Linux 对你来说会很直观。如果你对计算机并不了解多，或者你并不喜欢它们，那么 Linux 管理可能非常适合你。如果你不了解自己的硬件，Linux 的安装可能是一个挑战。

## Linux 有哪些好处？

Linux 可以带给你：

- 在你廉价的 PC 硬件上提供一个现代、稳定、多用户、多任务的环境，或者在软件上几乎没有（几乎大部分）资金成本。Linux 是一个丰富且强大的框架——不要把它看作一个“人的”操作系统。开箱即用的 Linux 具有不输配备了 5000 美元软件插件的 `Windows NT` 的能力，更加稳定，且相同任务所需的硬件更少。

- 标准 Linux 非常标准——它本质上是一个符合 `POSIX` 标准的 `UNIX`（是的，Linux 属于 UNIX，因为“UNIX”是`开放集团`（`The Open Group`）的注册商标）。Linux 包含了与 UNIX 相关的所有工具和实用程序，甚至超过许多商业实现。

- 无与伦比的计算能力、可移植性、灵活性和定制性。Linux 最近（1999 年）在基准测试中创建了超级计算机。Linux 在基于网络的 PC 上受欢迎，但在许多其他硬件平台上运行良好（`Debian` 表达了这种理念：“Linux，通用操作系统。”Linux 可以被定制以执行几乎任何计算任务。

- 高级图形用户界面。Linux 提供标准的网络透明窗口系统，并带有窗口管理器（通常是 `KDE` 或 `GNOME`，但也提供其他）。图形桌面可以制作得像 `MS Windows`（或者你喜欢的任何图形界面）。

- 数十种优秀的通用桌面应用程序。这些包括一系列免费的电子邮件程序、文字处理器、电子表格、位图和矢量图形编辑器、文件管理器、音频 CD 刻录机、一些游戏、打字教程等，复杂的平台。

- 千万免费的应用、工具及更多。“小即美”符合 Linux 哲学。微小的 Linux 工具通常协同工作执行更复杂的任务。全球研究人员开发的数百种专门应用（天文学、信息技术、化学、物理、工程、语言学、生物学……）。在许多领域，Linux 是世界上“唯一的”操作系统，发现你的天文学家运行什么，但如果你想要力量，它是历史以来最好的软件。

- 许多顶级商业程序，包括所有主流数据库（例如 `Oracle`，但不是`微软`的）。其中许多（大部分）针对个人使用免费提供。

- 一个真正的学习平台。如果你是一个家长，你应该感到高兴你的女儿/儿子 Linux 将学到有持久的价值。如果你是一个老师，你应该把安装 Linux 视为你的学校。“在一个奇怪的世界，教育工作者需要被说服分享信息比隐瞒信息是件好事”（`http://edge-op.org/grouch/factuals.html`）。如果你能提供教育而非培训，你就会选择 Linux。理解得越，你的计算机部门在教学中使用 Linux 的机会就越大。例如，在 Linux 下，你可以立即修改并编译为
