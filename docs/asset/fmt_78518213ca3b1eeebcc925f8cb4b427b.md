该头文件定义了这些每一个函数。
你可以像如下所示初始化结构体：

```c
#ifdef HAVE_NET_DEVICE_OPS

static struct net_device_ops ops = {

ndo_open = my_open,

ndo_stop = my_close,

ndo_start_xmit = stub_start_xmit,

};

#endif
```

然后在你的设置例程中，将该结构体放入 `net_device` 结构体，如下：

```c
struct net_device *dev;

#ifdef HAVE_NET_DEVICE_OPS

dev->dev_ops = &ops;

#else

dev->open = my_open,

dev->stop = my_close,

dev->hard_start_xmit = stub_start_xmit;

#endif
```
