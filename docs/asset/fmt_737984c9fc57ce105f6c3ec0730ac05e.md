
记住，`ed` 是按行工作的。第 1 行不匹配我们的正则，所以它报错了。你必须使用搜索（手动或自动）来定位替换。

替换允许你程序化地纠正错误。考虑我们单词列表中的一个条目。

*18

theeeeeen

“Theeeeee”不是一个单词。显然当有人输入“then”时，`e` 键卡住了。我们可以使用替换来修复它。在这里，我将任何两个或多个 `e` 组成的字符串替换为单个 `e`。

`*s/e\{2,\}/e/`

现在检查该行。

then

如果我提前知道我想打印结果，可以在替换的末尾添加 `p` 命令。我们将介绍在替换末尾起的几个特定命令。

`*s/e\{2,\}/e/p`

如果转义所有大括号让你感到苦恼，你可以选择更简单的重复替换的方法。`s` 命令会重复上一次替换。

```
*s/ee/e/p
theeeee
*s
theeee
*s
theeen
*s
theen
*s
then
*s
?
no match
```

你可能会注意到替换只影响一个匹配项。考虑这样的一行。

```
*19
wXXhXXaXtXX XXisXX this?XX
```

我不知道那些 `XX` 块是怎么进那里的，但它们必须消失。你可以尝试将其中一个字符串替换为空。

```
*s/XX//p
whXXhaXtXX XXisXX this?XX
```

替换引擎执行了你对它要求的最少工作。它匹配 `w` 和 `h` 之间的第一个 `XX`，将其拔出。你可以通过提供数字参数来告诉它提取哪一个匹配项。我将第七个 `XX` 替换为空。

```
*s/XX//7p
wXXhaXtXX XXisXX this?
```

替换在这方面具有可疑的人性化。

对现有行进行微调是有用的。这种替换的问题在于你必须计数。它也让重复替换变得不那么有用。要重复上一次替换，再次按 `s` 即可。

```
*s/XX//p
whaXXTT XXisXX this?
*s
whaXXTT XXisXX this?
...
*s
what is this?
```

我可以在 `s` 后面加上一个数字，只对行中的特定匹配项重复替换。

使用 `g`（全局）修符消除所有匹配项要简单得多。它告诉 `ed` 对当前行的每一个匹配项执行替换。我还会添加 `p` 修符来打印结果。

```
*s/XX//gp
what is this?
```

问题解决了。

## 结合搜索与替换

必须找到包含你想替换文本的行会剥夺 `ed` 的乐趣。与你的温和不同，`ed` 可以结合搜索和替换。在搜索之后给出你的替换，表示“如果匹配此项，则执行此替换”。

我们的示例尝试找到单词“there”并将其替换为“then”。搜索非常直观：`g/there/`。就像在 shell 中一样，反斜杠意味着“延续下一行”。然后我给出所需的替换。

```
*g/there/ \ \
ss/there/then/
test there
thereafter
4 theremin
```

`ed` 打印匹配搜索的行。但现在看这些行。

```
*5p
test then
*7p
thenafter
*10p
4 thenmin
```

替换成功！`ed` 将这种组合搜索与替换（或者用年轻人的话说，搜索和替换）视为单个命令，所以你可以用 `\` 将其反转。我确实是做了，因为这是一个草稿示例。但你可以在脚本中使用它来更新登录脚本、更新指向迁移服务器的链接或任何其他繁琐的任务。我们将在第 111 章看到一些示例。

反斜杠将此操作分成两行是不必须的。如果你把它们都放在一行，`ed` 就不会显示匹配搜索的行。

```
*g/there/ s/there/then/\
```

你可以在一个命令中拥有多个替换，但每个替换必须出现在单独的行，并用反斜杠分隔。

```
*g/there/ s/there/then/\
s/t/T/n
```

- 7 Test then

10 4 Thenmin

这把“then”换成了“there”，并将每行的第一个 `T` 大写。

虽然你可以在替换中使用明显无关的正则，但其中一个替换的失败会终止后续所有的替换。请仔细安排你的替换。

现在你已经看到了了复杂的形式，让我们稍微简化一下。当你想要对正在搜索的正则执行替换时，可以使用 `%` 地址来对所有可用行执行替换。

`*%s/there/Then/`

注意，这与上面更复杂的替换并不完全相同；第 5 行将“test”大写，而不是“then”。完整版本要灵活得多，所以我们将重点关注它。

## 子表达式与反向引用

子表达式是正则表达式的一部分。使用子表达式将一行拆分成若干块，如“我们关注之前的所有内容、我们关注的内容、以及之后的所有内容”。子表达式用括号标记，例如 `([a-zA-Z0-9])`。与大括号类似，你必须转义括号，以告诉 `ed` 你正在将它们用于子表达式。否则，`ed` 会查找字面上的括号字符。在引入子表达式时，我们将跳过反斜杠。

为了让 `ed` 记住整行，子表达式必须匹配包含字符串的整行。点和通配符在这里非常有用。虽然 `/the/` 匹配包含字符串“the”的行，但记住整行需要使用 `.*`：任意多个字符、我们真正想要的、然后任意多个字符。将正则表达式括在括号中让 `ed` 将其视为子表达式：`/(.*)`

反向引用允许你引用子表达式匹配的字面文本。你可以在搜索中使用反向引用，但它们大量出现在替换中。`ed` 按你定义的顺序调用子表达式。你的第一个子表达式是第一个引用，第二个是第二个，以此此类推。用反斜杠和数字指示反向引用，如 `\1`、`\2` 等。

我们的示例正则 `/(.*)` 告诉 Ed 记住一个子表达式。只有一个反向引用 `\1`。

如何使用子表达式和反向引用？你可能想搜索包含起始和结束引号的所有行。人类是非常一致的，所以这些字符串使用单引号或双引号。我定义了一个包含两种引号的字符类 `['"]`。该类包含括号以声明它是子表达式：`(['"])`。在我们之后可以是任何数量的字符，直到下一次出现与子表达式匹配的内容：`.*`。我们在子表达式中找到的任何字符都是我们的第一个反向引用，或 `\1`。将所有内容组合成正则 `(['\).*\1`。我想在搜索命令中使用它，所以我需要转义括号以告诉 `ed` 这是一个子表达式：`\(['\\].*\1`。使用 `g` 命令打印匹配此正则的行。

```
*g/['\\].*\1
'bleeeeeep'
unconscious 'people'
```

*g/the/\s\(.*\)/HIT-\1/p

the HIT-

their HIT-their

...

第一行对我们的目标正则表达式进行搜索，选择包含“the”的行。命令被分为两行，因此 `ed` 会打印匹配的行。第二行执行替换，添加字符串 `HIT-`，然后添加 `\1` 反向引用来调用第一个也是唯一的子表达式。我在末尾添加了 `p` 以在替换后打印结果，显示替换前后的效果。每个匹配字符串都具有所需的前缀。

假设你想对“the”进行不区分大小的匹配，而且你不仅想记住匹配到的内容，还想将内存分为“之前”、“匹配”和“之后”部分。每个部分都需要自己的括号，给你类似于 `/(.*)([[T] [hH] [eE]) (.*)`。

这个正则表达式有三个子表达式，因此你将使用 `\1`、`\2` 和 `\3` 对它们进行反向引用。

如何使用它？可能你想在匹配项周围加上 `HERE->` 和 `<<<HERE>`。你的替换需要第一个子表达式，然后添加 `HERE->`，第二个子表达式，` <-HERE` 以及最后一个子表达式。

第一行（搜索）将我们的替换置于匹配不区分大小的“the”的行。第二行使用带有子表达式的正则表达式将该行分成若干部分，然后使用反向引用执行替换并将行拼接在一起。使用这需要用反斜杠转义所有的括号，这说明了为什么我在创建正则表达式时跳过了反斜杠。

### 多次替换

你使用正则表达式搜索来定位替换，但这并不意味着你必须在替换中使用该正则表达式。`ed` 允许在搜索后堆叠多次替换，从而允许复杂的数据转换。

## Ed 精通

```
*g/the/t. \
s/\./=g
*,n
1 the
2 ===
3 but then
4 ====
5 their
6 ====
7 Them
8 there
9 ====
```
