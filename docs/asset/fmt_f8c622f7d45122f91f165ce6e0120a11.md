# mailx, mail, Mail 769

来自 `alias` 命令的格式，该命令接受空格分隔的列表。

**注意** — 转发地址必须有效，否则邮件将退回。例如，如果你的新地址尚未列在 NIS `aliases` 列表中，你无法通过转发到新地址来将邮件重定向到新主机。

## Commands

普通命令的形式为 `[command][message-list][arguments]`

在输入模式下，命令通过转义字符波浪线 (`~`) 识别，不视为命令的行被视为消息输入。如果你在命令模式下未指定命令，则认为下一个。以下是 `mailx` 命令的完整列表。

```
!shell-command
```

转义到 `shell`。注意，在 `shell-command` 有效的地方，并不总是允许参数。建议进行实验。

```
# comment 空命令（注释）。在 mailrc 文件中很有用。
= 输出当前消息编号。
? 打印命令摘要。
```

```
alias name...
group alias name...
```

为给定的名称声明别名。当使用 `alias` 作为收件者时，会进行替换。此命令在 `mailrc` 文件中很有用。如果不带参数，则显示已定义的别名列表。

```
alternates name...
```

为你的登录名声明备用名称列表。在回复消息时，从回复的收件人列表中删除这些名称。如果不带参数，则打印当前的备用名称列表。另见第 779 页的“Internal Variables”。

```
cd [directory] chdir [directory]
```

更改目录。如果你未指定目录，则使用 `$HOME`。

```
copy [file]
copy [message-list] file
```

将消息复制到文件，但不将消息标记为已保存。否则，等同于 `save` 命令。

- `*` `%` 是当前邮箱箱。
- `%user` 是用户的邮箱箱。
- `#` 是上一个邮件文件。
- `&` 是当前的 `mbox`。
- `+file` 是文件夹目录中的命名文件（列在 `folder` 变量中）。

如果不带参数，则打印当前邮件文件的名称以及包含的消息数量和字符数。

`folders` 打印由 `folder` 变量设置的目录中的文件名（见第 779 页的“Internal Variables”）。

`Followup [message]`

回复消息，并将回复记录在文件中，文件名源自消息的作者。如果设置了 `record` 变量，则覆盖它。如果设置了 `replyall` 变量，则反转 `Followup` 和 `followup` 操作。另见 `followup`、`Save` 和 `Copy` 命令，以及第 799 页“Internal Variables”中的 `outfolder` 和第 766 页的“Starting Mail”。

`followup [message-list]`

回复 `message-list` 中的第一条消息，将消息发送给 `message-list` 中每条消息的作者。取第一条消息的主题，并将回复记录在文件中，文件名源自第一条消息的作者。如果设置了 `replyall` 变量，则反转 `followup` 操作。另见 `Followup`、`Save` 和 `Copy` 命令，以及第 799 页“Internal Variables”中的 `outfolder` 和第 766 页的“Starting Mail”。

`from [message-list]`

为指定的消息打印标头摘要。如果你未指定消息，则打印当前消息的标头摘要。

`group alias name... alias alias name...`

为给定的名称声明别名。当 `alias` 用作收件者时，名称会进行替换。在 `mailrc` 文件中很有用。

`headers [message]`

打印包含指定消息的标头页。`screen` 变量设置每页标头的数量（见第 779 页的“Internal Variables”）。另见 `z` 命令。

`help` 打印命令摘要。

`hold [message-list]`

`preserve [message-list]`

在邮箱箱中保留指定的消息。

```
if s | r | t
mail-commands
else
mail-commands
endif
```

条件执行，如果程序处于发送模式，`s` 将执行随后的 `mail-commands` 直到 `else` 或 `endif`。`r` 仅在接收模式下执行 `mail-commands`。`t` 仅当 `mailx` 从终端运行时运行时执行 `mail-commands`。在 `mailrc` 文件中很有用。

```
ignore [header-field...]
discard [header-field...]
```

在屏幕上显示消息时，抑制对指定标头字段（`header-field`）的打印。要忽略的标头字段示例包括 `Status` 和 `Cc`。在保存消息时，包含所有字段。`More`、`Page`、`Print` 和 `Type` 命令会覆盖此命令。如果你未指定标头，则打印当前正在忽略的标头字段列表。另见 `discard` 和 `unignore` 命令。

合并在你读取系统邮箱箱期间到达的消息。将新消息添加到当前邮件会话中的邮件列表中。此命令不会提交会话期间的更改，也不会对之前的消息进行重新编号。
