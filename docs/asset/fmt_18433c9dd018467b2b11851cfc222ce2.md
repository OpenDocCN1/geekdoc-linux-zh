`longopts`结构体指针指向选项结构项的数组。选项结构体由四个成员组成：

```c
struct option {
    const char *name;   /* 长选项名称 */
    int has_arg;        /* 如果有参数则为真 */
    int flag;           /* NULL 或指向 int 的指针 */
    int val;            /* 要返回/赋值的值 */
};
```
