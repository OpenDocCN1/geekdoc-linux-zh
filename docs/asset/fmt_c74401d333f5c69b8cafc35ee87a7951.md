# 地震学
研究由自然或人工源引起的地球内部震动。在20 世纪 60 年代初板块构造被接受且其基础得到确认期间，直到地震学的后期（特别是地震成像），它为在地球地幔和地核结构方面取得的进展提供了关键的观测证据。

在具有特定形状波函数且带有传播波的弹性波方程的解称为行波。行波的一个重要特性是它们的因果性；即在能量首次到达之前，波没有振幅。整个地震波场可以通过叠加所有可能的行波来构建。

地震是一个能量转换过程，在这个过程中，极短的时间内（通常持续不到一分钟，且小于 1-10 秒）将势能转化为动能。地震波通过地球传播，并通过内部摩擦转化为热量。机械功是指，震源释放的大量势能可以转化为功。5 级地震和 50 公里的距离足够大，可以在地震波消散到现代探测水平以下之前被观测到。

射线理论或全波理论为在所有方向和波运动（包括向外的法向射线）中弹性波传播提供了实用的理论分析基础。射线理论使得通过简单的几何练习即可预测某些运动学量，如射线传播时间和距离。射线理论可以应用于具有均匀分层的地球模型；这对于地震学的大多数问题都是一个非常有用的方法，并可以扩展到全球研究。

地震图由被称为地震计的仪器记录，地震计在波经过过下方时感应地面的位置（或水压）。随时间变化的地面运动记录为地震图，可以以模拟或数字形式记录。计算机技术的进步使得地震图的模拟记录变得容易实现，这使得定性分析变得更加可行。

地球对地震扰动的响应由完美弹性体中扰动的运动方程描述。该方程无论源类型如何都成立，并与控制流体声音传播的弹性波方程有关。对于各向同性弹性固体，存在两个描述膨胀波（纯体积变化）和剪切波（无体积变化，无散）传播的方程。这些波分别以 $p$ 和 $s$ 的速度传播。这些速度也被称为初级（P）速度和次级（S）速度，波被称为 P 波和 S 波。P 波总是比 S 波快。在地球中，速度范围可以从未固结沉积物中的几百米到核地幔边界上方的 13.7 km/s（8.2 英里/秒）。地震速度 $v$ 的范围从每秒数百米（流体、地壳、外核）到核地幔边界的约 13 km/s。

P 波仅引起体积变化，而没有其他畸变。S 波没有引起体积变化的位移，但材料中的直角会发生畸变。爆炸是扰动的高效产生器，会产生压缩波和剪切波。由于机械稳定性，波先于剪切波到达。

压缩波和剪切波存在于由自由边界限制的弹性体中。对于这些区域，以 $p$ 或 $s$ 速度传播的地震波称为体波。如果弹性体由自由表面或边界限制，就会产生能量波。能量在表面附近传播，被边界或表面反射或折射。这有两种类型。瑞利波同时产生压缩和剪切运动，因此只需要边界的存在。勒夫波是纯剪切位移，可以在从自由表面向深弹性属性的变化中传播。两者都比体波慢。
