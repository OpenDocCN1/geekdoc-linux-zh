`long ExtendedMaxSizeRequest(display);`

`display` 指定到 X 服务器的连接。

如果指定的显示不支持扩展长度协议编码，`ExtendedMaxSizeRequest` 函数返回 0；否则，它返回服务器使用扩展长度编码的最大请求大小（以 4 字节为单位）。Xlib 函数 `XDrawLines`、`XDrawArcs`、`XFillPolygon`、`XChangeProperty`、`XSetClipRectangles` 和 `XSetRegion` 将根据需要使用服务器支持的扩展长度编码。在其他 Xlib 函数（例如 `XDrawPoints`、`XDrawRectangles`、`XDrawSegments`、`XFillArcs`、`XFillRectangles`、`XPutImage`）中使用扩展长度编码是被允许但不是必须；Xlib 实现可以选择将数据拆分为多个所需的请求。

```
long XMaxRequestSize(display);
```

`display` 指定到 X 服务器的连接。

`XMaxRequestSize` 返回服务器在不使用扩展长度协议编码支持的最大请求大小（以 4 字节为单位）。除非服务器支持扩展编码，否则发送到服务器的协议请求不能大于此。协议保证大小不超过 4096 个单元（16384 字节）。Xlib 会根据需要将以下函数的数据自动批处理为多个协议请求：`XDrawPoints`、`XDrawRectangles`、`XDrawSegments`、`XFillArcs`、`XFillRectangles` 和 `XPutImage`。
