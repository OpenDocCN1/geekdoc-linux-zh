
在这里，`404` 是状态代码，`Not Found` 是原因短语。在典型的 Web 客户端上，Web 浏览器将在浏览器窗口中显示 `Not Found` 短语。最新的 `HTTP 1.1` 规范提供了五种不同类别的状态代码；这些类别在以下部分中进行讨论。

## 信息性状态代码 (100–199)

这种类型状态代码的目的是让客户端知道服务器正在处理请求。这些状态代码仅是信息性的；客户端无需对其中任何一项采取行动。请注意，`HTTP 1.0` 未定义 `1xx` 状态代码，因此不得向 `HTTP 1.0` 客户端发送 `1xx` 状态代码。当前定义的 `1xx` 状态代码如下：

- `100 Continue` — 服务器发送此代码以告知客户端它已准备好接收请求的其余部分。
- `101 Switching Protocol` — 当服务器愿意将应用协议切换为客户端提供的 `Upgrade` 请求头部中指定的协议时，服务器会发送此代码。仅当新协议比现有协议具有优势时才应进行切换。例如，客户端可能请求服务器使用比当前正在使用的新版 `HTTP` 协议。在这种情况下，服务器应尽可能进行切换。

## 客户端请求成功 (200–299)

返回的 `200–299` 范围内的状态代码表示客户端的请求已被成功接收和接受。当前定义的 `2xx` 状态代码如下：

- `200 OK` — 服务器成功处理了请求，且请求的文档已附带。
- `201 Created` — 服务器成功创建了一个新的 `URL`，该 `URL` 在 `Location` 头部中指定。
- `202 Accepted` — 请求已被接受处理，但服务器尚未完成处理。
- `203 Non-Authoritative Information` — 响应头部中的元信息并非源自服务器；它是从另一台服务器复制的。
- `204 No Content` — 请求已完成，但无需发送新信息。客户端应继续显示当前文档。
- `205 Reset Content` — 客户端应重置当前文档。当 `HTML` 表单需要重置以清除所有输入字段的现有值时，这非常有用。
- `206 Partial Content` — 服务器已满足对资源的分部分 `GET` 请求。此代码用于响应 `Range` 请求。服务器发送 `Content-Range` 头部以指示附带的数据段。

## 请求重定向 (300–399)

`300–399` 范围内的状态代码被发送给客户端，以告知其需要执行进一步的操作来完成请求。当前定义的 `3xx` 状态代码如下：

- `300 Multiple Choices` — 请求的资源对应于一组文档。服务器可以发送关于每个文档的信息，包括其特定位置和内容协商信息，以便客户端可以选择其中一个。
- `301 Moved Permanently` — 请求的资源在服务器上不存在。发送 `Location` 头部将客户端重定向到新 `URL`。客户端将所有未来的请求指向新 `URL`。
- `302 Found` — 请求的资源已临时移动。服务器发送 `Location` 头部，将客户端重定向到新 `URL`。客户端在后续请求中继续使用旧的 `URI`。
- `303 See Other` — 请求的资源位于由 `Location` 头指示的其他位置，客户端应使用 `GET` 方法获取该资源。
- `304 Not Modified` — 服务器使用此代码响应 `If-Modified-Since` 请求头。这表明自指定日期以来，请求的文档未被修改，客户端应使用其缓存副本。
- `305 Use Proxy` — 客户端应使用由 `Location` 头指定的代理来获取请求的资源。
- `307 Temporary Redirect` — 请求的资源被临时重定向到其他位置。服务器发送 `Location` 头，将客户端重定向到新 `URL`。客户端在后续请求中继续使用旧的 `URI`。

## 客户端请求不完整（400–499）

`400–499` 范围内的状态码用于指示客户端请求不完整，需要更多信息来完成资源请求。当前定义的 `4xx` 状态码如下：

- `400 Bad Request` — 服务器检测到客户端请求中存在语法错误。
- `401 Unauthorized` — 请求需要用户身份验证。服务器发送 `WWW-Authenticate` 头，以指示请求资源的身份验证类型和域。
- `402 Payment Required` — 此代码保留供将来使用。
- `403 Forbidden` — 禁止访问请求的资源。客户端不应重复该请求。
- `404 Not Found` — 请求的文档在服务器上不存在。
- `405 Method Not Allowed` — 客户端使用的请求方法不可接受。服务器发送 `Allow` 头，说明访问请求资源时可接受的方法。
- `406 Not Acceptable` — 根据服务器接收到的 `Accept` 头，请求的资源不可用客户端可接受的格式。如果请求不是 `HEAD` 请求，服务器可以发送 `Content-Language`、`Content-Encoding` 和 `Content-Type` 头，以指示可用的格式。
- `407 Proxy Authentication Required` — 对代理服务器的未授权访问请求。客户端必须首先与代理进行身份验证。服务器发送 `Proxy-Authenticate` 头，指示请求资源的身份验证方案和域。
- `408 Request Timeout` — 客户端未能在服务器使用的请求超时时间内完成其请求。但是，客户端可以重复该请求。
- `409 Conflict` — 客户端请求与其他请求发生冲突。服务器可以随状态码添加有关冲突类型的信息。
- `410 Gone` — 请求的资源已从服务器永久删除。
- `411 Length Required` — 客户端必须在请求中提供 `Content-Length` 头。
- `412 Precondition Failed` — 当客户端发送带有 个或多个 `If...` 头的请求时，如果这些头中指定的条件中有一个或多个为假，服务器使用此代码进行指示。
- `413 Request Entity Too Large` — 由于消息体过大，服务器拒绝处理该请求。服务器可以关闭连接，以阻止客户端继续发送请求。
- `414 Request-URI Too Long` — 由于指定的 `URI` 过长，服务器拒绝处理该请求。
- `415 Unsupported Media Type` — 由于不支持消息体的格式，服务器拒绝处理该请求。
- `417 Expectation Failed` — 服务器未能满足 `Expect` 请求头的要求。

## 服务器错误（500–599）

当服务器遇到错误且无法处理请求时，会返回 `500–599` 范围内的状态码。当前定义的 `5xx` 状态码如下：

- `500 Internal Server Error` — 服务器配置设置或外部程序导致错误。
- `501 Not Implemented` — 服务器不支持处理请求所需的功能。
- `502 Bad Gateway` — 服务器从上游服务器或代理接收到了无效响应。
- `503 Service Unavailable` — 服务暂时不可用。服务器可以发送 `Retry-After` 头，以指示服务何时可能再次可用。
- `504 Gateway Timeout` — 网关或代理已超时。
- `505 HTTP Version Not Supported` — 客户端使用的 `HTTP` 版本不受支持。

正则表达式通常由普通字符和特殊字符组成，以创建模式。该模式用于匹配一个或多个子字符串，或匹配整个字符串。例如：

```
([a-z]+)\.([a-z])\.([a-z])+
```

这是一个匹配 `www.idgbooks.com`、`www.apache.org` 等的正则表达式。正则表达式中使用的特殊字符通常称为元字符。表 B-1 展示了常用的元字符。

| 元字符 | 用途 |
| :--- | :--- |
| `.` | 匹配任何字符（换行符除外） |

| `\b` | 匹配单词边界 |
| `x?` | 匹配 0 或 1 个 `x`，其中 `x` 是任何正则表达式 |
| `x*` | 匹配 0 个或多个 `x` |
| `x+` | 匹配 1 个或多个 `x` |
| `foo\|bar` | 匹配 `foo` 或 `bar` 之一 |
| `[abc]` | 匹配集合 `abc` 中的任意字符 |
| `[A-Z]` | 匹配范围 `A` 到 `Z` 中的任意字符。 |
| `[^xyz]` | 匹配集合 `xyz` 中不存在的任意单个字符 |

如果需要在正则表达式中将元字符作为普通字符使用，可以使用 `\metachar` 格式来取消特殊含义。一个例子是 `\$`，它是一个普通的美元符号字符。表 B-2 展示了正则表达式中使用的标准量词。

| 量词 | 含义 |
| :--- | :--- |
| `*` | 匹配 0 次或多次 |
| `+` | 匹配 1 次或多次 |
| `?` | 匹配 1 次或 0 次 |
| `{n}` | 恰好匹配 `n` 次 |
| `{n,}` | 至少匹配 `n` 次 |
| `{n, m}` | 至少匹配 `n` 次但不超过 `m` 次 |

`\|` 字符被视为 `OR`（或）运算符。一对圆括号 `()` 允许您定义正则表达式中用于搜索匹配字符串的区域。一对方括号 `[ ]` 创建字符类或范围。
