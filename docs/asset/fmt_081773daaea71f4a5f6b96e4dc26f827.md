此程序与大多数 GUI 程序一样，大量使用将指针作为参数传递给函数。在程序程序中，你使用 GNOME 函数创建部件，并设置在某些事件发生时要调用的函数。这些函数被称为回调函数。所有的事件处理都由 `gtk_main` 函数处理，因此你不需要担心事件是如何处理的。你所做的就是设置好回调来等待它们。

以下是此程序中使用的所有 GNOME 函数的简要描述：

- `gnome_init`: 接收命令行参数、参数计数、应用程序 ID 和应用程序版本，并初始化 GNOME 库。
- `gnome_app_new`: 创建一个新的应用程序窗口，并返回其指针。接受应用程序 ID 和窗口标题作为参数。
- `gtk_button_new_with_label`: 创建一个新按钮并返回其指针。接受一个参数 - 按钮中的文本。
- `gnome_app_set_contents`: 接收 gnome 应用程序窗口的指针以及任何你想要的部件（在本例中为按钮），并使该部件成为应用程序窗口的内容。
- `gtk_widget_show`: 必须在每个创建部件（应用程序窗口、按钮、文本输入框等）上调用此函数，以便它们可见。然而，为了让指定的部件可见，其所有的父级也必须是可见的。
- `gtk_signal_connect`: 这是连接部件和其信号处理回调函数的函数。该函数接受部件指针、信号名称、回调函数和一个额外数据指针。在此应用程序中，每当给定事件被触发时，回调函数就会被调用，并传入产生信号的部件和额外数据指针。在此应用程序中，我们不使用额外数据指针，因此将其设置为 `NULL`（即 0）。
- `gtk_main`: 此函数导致 GNOME 进入其主循环。为了使编程更方便，GNOME 为我们处理程序的主循环。GNOME 会检查事件并在事件发生时调用相应的回调函数。此函数将继续处理事件，直到调用 `gtk_main_quit`。
