
`ln` (link) 命令用于创建一个链接文件，以启动或激活位于另一个文件夹中的文件。当你尝试激活一个深埋在硬盘某处子文件夹的子文件夹的子文件夹中的文件时，这个工具非常有用。该命令经常配合 `-s` (symbolic，符号) 标志使用，它提供的功能与你在 Windows 中熟知的快捷方式或 Mac 别名本质上相同。

使用 `ln` 命令最简单的方法是先使用 `cd` 命令将终端的位置更改到你想放置链接的文件夹。你可以在命令行中输入 `ln` 命令，后面跟着你想要链接的文件路径。例如，假设你想在主文件夹中为你关于自传的 `myLife.sxw` 的 OpenOffice.Writer 文件创建一个链接。该文件深埋在主文件夹深处的一层嵌套子文件夹中：`/home/username/Document/personal/self/autobiography/myLife.sxw`。要创建链接，你需要打开一个新的终端窗口，输入以下命令并按回车：

```
ln -s Document/personal/self/autobiography/myLife.sxw
```

一旦完成，链接将以图标的形式出现在你的主文件夹中，外观与原始文件一致，但带有一个箭头以表示这是一个链接。

## $ tar

在第 6 章中，你学习了创建和提取归档（或 tar 包），但你知道也可以通过命令行创建和提取 tar 包吗？`tar` 命令就是你实现这一操作的关键。

要创建一个归档，你只需输入 `tar -cvf`，后面跟着你想为 tar 包指定的名称，然后是你想要归档的文件夹或文件的名称。例如，假设你想为 `photos` 文件夹创建一个归档，并将其命名为 `pics4pals`。在这种情况下，你将输入以下命令然后按回车：

```
tar -cvf pics4pals.tar photos
```

正如你所注意到的，你的字符串中 `tar` 命令后面有一些标志。`c` 告诉 `tar` 程序创建一个归档。`v` 告诉程序显示详细过程。`f` 告诉程序指定文件名。

## Project 8C: 使用 Briscola 进行命令练习复习

如果你想强化在上一个项目中用过的技能，为什么不玩玩 Briscola 呢——这是一种简单但非常传统的意大利牌牌（见图 8-12）。与作为 Python 脚本的 `pyWings` 不同，`Briscola` 是另一种风格的脚本，用 Tcl 语言编写，并使用名为 Tk 的工具来创建其图形界面。

![](img/ba6b82a7869bba748202d57c97336dca_165_0.png)

图 8-12：Briscola

### 8C-1: 获取 Briscola

你正准备好“安装” `Briscola`，但在那之前，你必须先获取它。你可以通过访问项目主页 `www.rigacci.org/comp/software` 并以传统方式下载来获取 `Briscola`，但由于我们正在学习命令，让我们用新命令 `wget` 来获取 `Briscola` 吧。

要这样做，只需打开终端窗口，输入以下命令字符串，然后按回车键：

```
wget http://www.rigacci.org/comp/software/briscola/briscola-4.1.tar.gz
```

在终端窗口中，你会看到 `wget` 正在连接存储 `Briscola` 的网站并下载文件。完成后，你将在你的主目录中找到 `Briscola` 的 tar 包。

### 8C-2: 解压 Briscola tar 包并重命名 Briscola 文件夹

解压 `Briscola` tar 包的过程与解压 `pyWings` 基本相同；然而，`Briscola` 已经封装在自己的文件夹中，所以你不需要为它创建一个特殊的文件夹。

我相信你现在已经知道怎么做了，我会再说一遍。打开终端窗口，输入以下命令，并按回车键：

```
tar -xzvf briscola*.gz
```

一个名为 `Briscola-4.1` 的新文件夹现在出现在你的主目录中，里面包含了所有的 `Briscola` 文件。为了方便以后处理，我们将文件夹名称缩短为简单的 `Briscola`。我们已经知道如何通过右键方法做到，但这次让我们通过命令行来完成。要这样做，你可能很惊讶惊讶，你需要使用 `mv` 命令，后面跟着你要更改的文件名，然后是文件的新名称。

输入以下命令并按回车键尝试一下：

```
mv briscola-4.1 briscola
```
