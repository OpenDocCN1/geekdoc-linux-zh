## C 语言解释器 Cli

一种类 C 语言解释器，是一个可编译的、开放的系统，用于开发使用 C 语法的程序。如果程序经过编译且语法正确，则会立即生成命令行。代码为虚拟机生成。虚拟机是框架的一部分。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

基于简单规范文件的命令行生成器，为函数 `Cmdline *parseCmdline(int argc, char **argv)` 生成 C 代码，该函数解析典型 C 程序的命令行并返回类型为 `Cmdline` 的结构体结果。除了 `parseCmdline()` 之外还生成了函数 `void use()`，且命令行解析器包含明显的错误。使用 `cli` 的原因之一是自动生成 `use()` 函数，该函数与程序实际理解的选项始终同步。此外，`cli` 会创建一个手册页。来自 Debian 3.0r0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## Common LISP 接口管理器 (CLOS)

`"C"` 语言集成生产系统 `CLISP` 6.0 是一个由 NASA 使用 ANSI C 编写的、类操作系统的前向携带生产系统。`CLISP` 推理引擎包含真值维护、动态规则激活和可自定义的冲突解决策略。`CLISP`（包括运行时）可以很容易地嵌入到其他应用程序中。`CLOOL`（`CLISP` 面对象语言）直接与推理引擎集成。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

GNU `CLISP` 是一种 Common Lisp 的实现，是一种高级、通用的编程语言。GNU `CLISP` 是由卡尔斯鲁厄大学的 Bruno Haiele 和德国慕尼黑的 Michael Stoll 实现的。它主要支持 ANSI 标准描述的 Lisp。它可以运行在微型计算机（OS/2, Windows NT/2000, Windows 95/98, Amiga 500–4000, Accord RISC PC）以及 Unix 工作站（Linux, SysVR, Sun, Delta Alpha, HP-UX, BoS, NextStep, AIX, 等）上，仅需 2 MB RAM。用户界面提供德语、英语、法语、西班牙语和荷兰语。GNU `CLISP` 包含解释器、编译器、`CLOS` 的子集、外语言接口和套接接口。通过 `CLX` 和 `Garnet` 提供 X11 接口。来自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/html.index`
