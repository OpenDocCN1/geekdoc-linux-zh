# 1998 虫漆

虫漆需要一种或多种装饰。浮凸是通过绘图在壳体上形成图案。硬币通过一种过程在壳体上留下压痕，这种过程是至关重要的，最好是在线圈的两个面之间。通过一对锋利工具的切削作用分离材料，类似于剪刀的作用。

旋压工艺通过芯轴或使用轮子形成旋转。有两种方法：传统旋压和剪切旋压。传统旋压过程涉及通过芯轴旋转材料，壳体的厚度几乎或没有变化。剪切旋压涉及以这种方式去除材料，使得原始块的直径保持不变，但厚度按所需量减少。这两种方法都能产生各种形状的壳体（弯形、曲线形，以及通过在圆柱形芯轴上进行管旋压制成的管状），具有良好的光度和改进的性能。

# 船舶设计

船舶设计涉及将需求转化为设计以及建造船舶所需的技术细节。造船是一项昂贵的任务，但需要许多其他技能。这些技能包括海洋工程、结构设计和生产工程。船舶生产过程是迭代的，在开发期间被分为几个阶段。通常，用户需求规定了新船必须执行的任务以及如速度、燃料续航能力和载量等参数。目标是为预期用户设计一艘船。船舶设计过程涉及许多权衡，以实现用户所定的所需的容量和使用范围。
