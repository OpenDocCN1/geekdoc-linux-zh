
有时错误不是致命的，特别是在命令行脚本存在 `-prefix` 前缀或使用 `-k` 命令行选项的情况下。致命错误以字符串 `***` 为前缀。

错误消息均以程序名称（通常为 `'make'`）为开头，或者如果在 `Makefile` 中发现错误，则以包含问题的文件名和行号为开头。

在下表中，省略了这些常见前缀：

- `'[foo] Error NN'`
- `'[foo] signal description`

这些错误并不是真正的 `make` 错误。它们意味着 `make` 作为命令脚本的一部分调用的程序返回了非 0 的错误代码（`'Error NN'`），`make` 将其解释为失败，或者它以其他异常方式退出（带有某种类型的信号）。参见第 5.4 节 `[命令错误]`，第 44 页。

如果消息没有附加 `***`，则子进程失败了，但 `Makefile` 中的规则带有特殊字符 `-` 的前缀，因此 `make` 忽略了该错误。

- `'missing separator. Stop.'`
- `'missing separator (did you mean TAB instead of 8 spaces?). Stop.'`

这意味着 `make` 无法理解它刚刚读取的命令的任何内容。`GNU make` 寻找各种分隔符（`:`, `,`, `=`, `TAB` 字符等）来帮助判断它是哪种命令行。这意味着它没有找到有效的分隔符。

出现此消息的这种常见原因之一是你（或你那“热心过头”的编辑器，许多 MS-Windows 编辑器都是如此）尝试使用缩进而不是 `TAB` 字符。在这种情况下，`make` 将使用上述错误格式。记住，命令行脚本中的每一行必须以 `TAB` 字符开头。空格不计入。参见第 4.1 节 `[语法]`，第 19 页。

- `'commands commence first target. Stop.'`
- `'missing rule before commands. Stop.'`

这意味着 `Makefile` 中的第一项似乎是命令脚本的一部分：它以 `TAB` 字符开头，并且看起来不是合法的 `make` 命令（例如变量赋值）。命令行脚本必须与目标相关。

第二种格式如果行具有分号作为第一个非空白字符；`make` 将其解释为你遗漏了“目标:”部分。参见第 4.1 节 `[语法]`，第 19 页。

`‘No rule to make target ‘xxx’.`

`‘No rule to make target ‘xxx’, needed by ‘yyy’`

这意味着 `make` 决定需要构建目标，但它没有找到任何指令。

如果消息没有附加 `***`，则子进程失败了，但 `Makefile` 中的规则带有特殊字符 `-` 的前缀，所以 `make` 忽略了错误。

- `'missing separator. Stop.'`
- `'missing separator (did you mean TAB instead of 8 spaces?). Stop.’`

情况下，子进程将生成此警告消息并按顺序继续构建。

## 附录 C 复杂的 Makefile 示例

这是 `GNU tar` 程序的 `makefile`。这是一个中等复杂的 `makefile`。

由于它是第一个目标，默认目标是 `'all'`。这个 `makefile` 的一个有趣特性是 `'testpad.h'` 是由 `testpad` 程序自动创建的源文件，该程序本身是从 `'testpad.c'` 编译的。

如果你输入 `'make'` 或 `'make all'`，那么 `make` 会创建 `'tar'` 可执行文件、提供远程磁带访问的 `'rmt'` 进程以及 `'tar.info'` Info 文件。

如果你输入 `'make install'`，`make` 不仅会创建相同的 `'tar'`、`'rmt'` 和 `'tar.info'` 文件，还会安装它们。

如果你输入 `'make clean'`，`make` 会删除 `'.o'` 文件，以及 `'tar'`、`'rmt'`、`'testpad'`、`'testpad.h'` 和 `'core'` 文件。

如果你输入 `'make distclean'`，`make` 不仅会删除与 `'make clean'` 相同的文件，还会删除 `'TAGS'`、`'Makefile'` 和 `'config.status'` 文件。（尽管显而易见，但此 `makefile`（以及 `'config.status'`）是由用户使用 `configure` 程序生成的，该程序在 `tar` 分发中提供但在此处未显示。）

如果你输入 `'make realclean'`，`make` 会删除与 `'make distclean'` 相同的文件，还会删除从 `'tar.texinfo'` 生成的 Info 文件。

此外，还有创建发行包的 `shar` 和 `dist` 目标。
