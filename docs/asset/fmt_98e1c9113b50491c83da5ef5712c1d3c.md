# 关于作者

Dee-Ann LeBlanc 是 RHCE（Linux 认证工程师），她是一位作家、开发者、记者，专门从事 Linux 技术。虽然这些专业领域看起来很分散，但实际上相辅相成，能够让她看到人们在现实世界中如何使用 Linux 以及他们需要什么。她是 Linux Journal 的编辑，Wiley.com 的编辑，并编写了许多关于 Linux 的书籍。
