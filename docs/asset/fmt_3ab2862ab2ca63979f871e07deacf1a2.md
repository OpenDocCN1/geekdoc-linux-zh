
## 初学者社区（Beginner Community）

一个托管了“绝对初学者谈话”（Absolute Beginner Talk）论坛的论坛板块，它提供了一个任何人都可以就计算机、Linux、Unix 和 Ubuntu 提问题的论坛。如果你一直担心问题可能太基础而不敢提问，那么这个论坛就是为你准备的！

## 当前版本论坛（Current Version Forum）

一组专门支持当前 Ubuntu 版本和相关项目发布版（本书编写时为 6.06 LTS）用户的论坛。该论坛区域细分为以下几个关注领域：

### 通用支持（General Support）

针对当前 Ubuntu、Kubuntu、Edubuntu 或 Xubuntu 发布版本的系列论坛。这些论坛分为桌面支持、64 位处理器支持、安装或升级帮助、Macintosh/Apple/PPC 用户以及 Sun SPARC 用户论坛。

### 硬件帮助（Hardware Help）

针对 Ubuntu Linux 无法检测或支持硬件问题的系列论坛。该论坛区域托管有关网络、视频和音频、笔记本支持和无线支持主题的子论坛。

### 支持与资源（Support & Resources）

针对各种通用主题的系列论坛。该论坛区域分为以下关注领域：

#### 教程、技巧与窍门（HOWTOs, Tips & Tricks）

讨论通用、KDE 和 GNOME 定制的论坛。

#### 游戏（Gaming）

讨论 Linux 游戏的论坛。

#### 第三方项目（Third-Party Projects）

针对非 Canonical 赞助的第三方项目的系列论坛。

#### Ubuntu 中心（Ubuntu Center）

各种通用主题的系列论坛。该论坛区域分为以下关注领域：

- **教程、技巧与窍门：** 讨论通用、KDE 和 GNOME 定制的论坛。
- **游戏：** 讨论 Linux 游戏的论坛。
- **第三方项目：** 针对非 Canonical 赞助的第三方项目的系列论坛。
- **Ubuntu 中心：** 各种通用主题的系列论坛。
