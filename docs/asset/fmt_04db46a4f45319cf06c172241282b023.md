## 另一个选项：`a2ps`

`a2ps` 程序（在大多数发行版的存储库中可用）很有趣。从它的名字可以推断出，它是一个格式转换程序，而且不仅如此。它的名字原意是“ASCII 转 PostScript”，用于准备文本文件以在 PostScript 打印机上打印。多年来，该程序的功能不断增强，现在它意味着“任何格式转 PostScript”。虽然它的名字暗示它是一个格式转换程序，但它实际上是一个打印程序。它将默认输出发送到系统的默认打印机，而不是标准输出。程序的默认行为是“精排打印器”，意味着它会改进输出的外观。我们可以使用该程序在桌面上创建一个 PostScript 文件。

```bash
[melinuxbox] $ ls /usr/bin | pr -t | a2ps -o ~/Desktop/ls.ps -L 66
stdin (plain): 11 pages on 6 sheets
[Total: 11 pages on 6 sheets] saved into the file /home/me/Desktop/ls.ps'
```

在这里，我们通过 `pr` 处理流，使用 `-t` 选项（省略页眉和页脚），然后通过 `a2ps`，指定输出文件（`-o` 选项）和每页 66 行（`-l` 选项）以匹配 `pr` 的输出分页。如果我们使用适当的文件查看器查看结果，将在图 22-1 中看到输出。

图 22-1：查看 `a2ps` 输出

## 监控和控制打印作业

CUPS 提供了两个用于终止打印作业并从打印队列中删除它们的程序。一个是 Berkeley 风格（`lpr`），另一个是 System V 风格（`cancel`）。它们在支持的选项上略有不同，但基本相同。以之前的打印作业为例，我们可以停止并删除该作业：

```bash
[me@linuxbox]$ $ cancel 603
[me@linuxbox]$ $ lpq
printer is ready
no entries
```

每个命令都有删除属于特定用户、特定打印机和多个作业编号的选项。各自的 `man` 页面包含所有详细信息。

## `Lpq`—显示队列状态

使用 `lpq` 程序来查看打印机状态。这允许我们查看队列的状态及其包含的打印作业。这里是系统默认打印机的空队列示例：

```
printer is ready
no entries
```

如果不指定打印机（使用 `-P` 选项），将显示系统默认打印机。如果我们向打印机发送一个作业然后查看队列；我们将看到它。

```
[me@linuxbox ~]$ ls *.txt | pr -3 | lpq
request id is printer-603 (1 file(s))
[me@linuxbox ~]$ lpq
printer is ready
```
