## 复制切片

`copy()` 函数将源参数（一个切片）中的元素复制到第一个参数中，第一个参数也必须存在数据。以下代码展示了使用 `copy()` 如何非常复杂。

```go
$ make(map[string]int)

map["Mon"] = 0

map["Tue"] = 1
```

上一个示例定义了一个连接字符串到整数的 map。你可以按照如下方式向 map 添加两个元素：

```go
slice := []int{1, 2, 3}

newSlice := []int{-1, -2, 3, 4, 5}

copy(anotherSlice, newSlice)

copy(anotherSlice, slice)
```
