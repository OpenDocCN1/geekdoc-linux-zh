# 控制器 (SCSI)

仔细选择 SCSI 控制器非常重要。许多廉价的 SCSI 控制器设计用于驱动光驱而非其他任何设备。低端 SCSI 控制器并不比 IDE 好。在购买 SCSI 卡之前，请查看 SCSI HOWTO 并参考性能数据。
