# kerberos — Kerberos 安全系统简介

## 描述

Kerberos 系统验证网络环境中的单个用户。在向 Kerberos 验证身份后，你可以使用 NFS 等网络服务的 kerberos 认证选项。此外，在某些环境中，你可以使用网络命令如 `login(1)`、`rcp(1)` 和 `rsh(1)`，而无需在 `.hosts` 文件中有条目。有关你站点 Kerberos 支持更多信息，请咨询你的系统管理员。

在使用 Kerberos 之前，你必须在 Kerberos 数据库中注册为用户。你可以使用 `kinit(1)` 查看你的状态。该命令提示你登录 Kerberos 系统，`kinit` 会提示用户名和密码。输入你的用户名和密码。命令将登录你且不给出消息，说明你已经注册了。

如果你输入用户名且 `kinit` 回复以下消息，说明你尚未注册为 Kerberos 用户。请咨询你的系统管理员。

Principal unknown (kerberos)

一个 Kerberos 名称包含三部分：

- 主体名称（principal name），通常是用户或服务的名称。
- 实例（instance），对于用户来说通常为空。某些用户（如 root 或 admin）可能拥有特权实例。对于服务，实例是运行该服务的系统名称；也就是说，在系统 ABC 上运行的 NFS 服务可能与运行在系统 XYZ 上运行的 NFS 服务不同。
- 域（realm），通常是网络的域名。域通过 @ 符号与实例隔开。例如：

```
billz@lcs.edu
root@athena.edu
admin@athena.edu
```

当你使用 Kerberos 进行身份验证时，通常使用格式 `principal@realm`。

> 注意 — 当你将 `kdestroy` 放在 `.logout` 文件中时，注销后代表你执行的操作将失败。

### 缺陷

Kerberos 不进行转发。换句话说，如果你使用 `login` 登录远程主机，Kerberos 会明文通过网络发送你的密码。

# keylogin — 使用 keyserv 解密并存储密钥

## 用法

`/usr/bin/keylogin [-r]`

## 描述

`keylogin` 命令是安全 RPC 命令集的一部分。在使用 `keylogin` 之前，系统管理员必须使用 `newkey(1M)`、`nisaadded(1M)` 或 `nsclient(1M)` 命令生成公钥和密钥。每个用户都有唯一的公钥和密钥。该密钥可以在 `/etc/publickey` 文件（参见 `publickey(4)`）或用户家目录域中的 NIS 映射 `publickey.byname` 中找到。此类域及其查找顺序在 `/etc/nsswitch.conf` 文件中指定（参见 `nsswitch.conf(4)`）。

`keylogin` 命令会提示输入密码并使用它解密用户的密钥。一旦解密，该密钥将由本地密钥进程 `keyserv(1M)` 存储。该存储的密钥将在向...发布请求时使用。

## Options

- `-r`

更新 `/etc/.rootkey` 文件。该文件持有超级用户的未加密机密。只有超级用户可以使用此选项。以超级用户运行的进程可以发出认证请求，而无需管理员显式地以超级用户身份运行 `keylogin`（参见 `keyserv(1)`）。

当公钥数据库中的主机条 way且文件中存储的实际密钥对过期时，管理员应使用 `-r` 选项。`/etc/.rootkey` 文件的权限允许超级用户读写，但系统上的其他用户无法访问。

如果系统配置了多个身份验证机制，`/etc/.rootkey` 文件将存储每个机密。

## keylogout — 使用 keyserv 删除存储的机密

### Synopsis

`/usr/bin/keylogout [-f]`

## Description

`keylogout` 命令是安全 RPC 命令集的一部分。

`keylogout` 删除由密钥服务器进程 `keyserv(1)` 存储的密钥。

对密钥的进一步访问将被撤销；然而当前的会话密钥可能保持有效，直到它们过期或刷新。

当你删除由 `keyserv` 存储的密钥时，任何需要安全 RPC 服务的后台作业或 `at(1)` 任务都会失败。由于系统中只保留一份密钥，因此在 `.logout` 文件中调用此命令并非好主，因为它会影响同一台机器上的其他会话。

## Options

- `-f` 强制 `keylogout` 删除超级用户的机密。默认情况下，不允许超级用户执行 `keylogout`，因为这将破坏所有由超级用户启动的 RPC 服务（如 NFS）。
