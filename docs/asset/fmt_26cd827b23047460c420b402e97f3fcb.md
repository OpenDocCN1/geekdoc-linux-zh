## acpid

用于 ACPI 现代计算机的工具，支持高级配置和电源接口 (ACPI)，允许在系统上进行智能电源管理并查询电池和配置状态。此包包含 acpid，它是使 Linux ACPI 支持完全功能所需的用户态守护进程。使用它需要较新的内核 (>=2.4.7)。可以通过包含 /acpid.sourceforge.net 上的补丁或使用未打补丁的内核来实现。来自 Debian 3.0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
