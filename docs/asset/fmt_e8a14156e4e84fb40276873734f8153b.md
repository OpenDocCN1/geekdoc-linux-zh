# 讨论

在线算法在搜索阶段的行为尚不为人知。信息几何将搜索描绘为由立方约束分隔的黎曼流形系。这为所有在线算法提供了实质性的保证。在线梯度可以克服随机选择过程引入的噪声。统计力学方法为这些主题带来了新的见解。结果可能是极大提高在线学习的先驱。
