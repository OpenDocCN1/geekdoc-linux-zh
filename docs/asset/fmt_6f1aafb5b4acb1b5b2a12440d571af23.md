
`stty` 命令为当前标准输入设备设置某些终端 I/O 选项；不带参数时，它会报告某些选项的设置。

在本节中，如果字符前面有一个脱字符符号（^），则该选项的值为相应的控制字符（例如，^h 是 Control-H；Control-H 等同于退格键）。序列 ^ 意味着该选项为空值。

关于“通过本地模式进行控制模式”下列模式的详细信息，请见 `termio(7I)`。关于“硬件流控制模式”和“时钟模式”下列模式的详细信息，请见 `termio(7I)`。

“组合模式”节中描述的操作通过前面节中描述的选项实现。注意，许多选项组合可能没有意义，但程序不会进行性检查。硬件流控制和时钟模式选项可能不受所有硬件接口支持。

## 选项

- `-a` 向标准输出写入终端的所有选项设置。
- `-g` 以可以作为另一个 `stty` 命令参数的格式报告当前设置。如果底层驱动程序支持，则输出 termios 类型的输出；否则，输出 termio 类型的输出。

### 操作数

#### 控制模式

- `-parenb` 启用（禁用）校验位生成和检测。
- `-parext` `-parext` 启用（禁用）标记和空格校验的扩展校验位生成和检测。
- `-parodd` `-parodd` 选择奇数（偶数）校验位，或者如果启用了 `parext` 时选择标记（空格）校验位。
- `-cs5` `cs6` `cs7` 字符大小（见 `termio(7I)`）。
- `-0` 立即挂断线路。

#### 本地模式

- `echoe` `-echoe`

回（或不回）`ERASE` 字符作为“退格-空格-退格”字符串。请注意，这种模式在许多 CRT 终端上会删除被删除的字符；但它不会跟踪列位置，因此对于转义字符、制表符（Tabs）和退格键可能会导致混乱。

- `echok` `-echok`

在 `KILL` 字符后回（或不回）换行（NL）。

- `lfkc` `-lfkc`

与 `echok` `-echok` 相同；已废。

- `echonl` `-echonl`

回（或不回）换行（NL）。

- `noflsh` `-noflsh`

禁用（启用）在 `INTR`、`QUIT` 或 `SUSP` 后的刷新。

- `ststrap` `-ststrap`

禁用（启用）对同步行上超过 79 个字符的行进行截断。

- `topstop` `-topstop`

当后台进程写入终端时发送（或不发送）`SIGTTO`。

- `echoctl` `-echoctl`

回（或不回）控制字符为 `^char`；删除为 `^?`。

- `echoprt` `-echoprt`

在字符被删除时回（或不回）该删除字符。

- `echoke` `-echoke`

在行杀死时用 BS-SP-BS 删除（或不 BS-SP-BS 删除）整行。

- `flush` `-flush`

输出（或不是）被刷新。

- `pendin` `-pendin`

在下次读取或输入字符时重输（或不重输）等待处理的输入。

- `iexten` `-iexten`

启用（禁用）当前未被 `icanon`、`isig`、`ixon` 或 `ifoff` 控制的特殊控制字符：`VEOLZ`、`VSWTCH`、`VPREPRINT`、`DISCARD`、`VDSUSP`、`VWERASE` 和 `VLNEXT`。

- `stflush` `-stflush`

在同步行上，在每次 `write(2)` 后启用（禁用）刷新。

- `stappl` `-stappl`

在同步行上使用应用模式（或使用行模式）。

## 硬件流控模式

- `rtsxoff` `-rtsxoff`

在输入时启用（禁用）RTS 硬件流控。

- `ctsxoff` `-ctxon`

在输入时启用（禁用）CTS 硬件流控。

- `dtrxoff` `-dtrxoff`

在输入时启用（禁用）DTR 硬件流控。

- `cxon` `-cdxon`

在输入时启用（禁用）CD 硬件流控。

- 在输入时启用（禁用）等时硬件流控。

## 时钟模式

- `xctset` 从发送信号元素定时（DCE 源）引脚、CCITT V.24 电路114、EIA-232-D 引脚15 获取传输时钟。
- `xcrset` 从接收信号元素定时（DCE 源）引脚、CCITT V.24 电路115、EIA-232-D 引脚17 获取传输时钟。
- `rcibrg` 从内部波特发生器获取接收时钟。
- `rctset` 从发送信号元素定时（DCE 源）引脚、CCITT V.24 电路114、EIA-232-D 引脚15 获取接收时钟。
- `rcserset` 从接收信号元素定时（DCE 源）引脚、CCITT V.24 电路115、EIA-232-D 引脚17 获取接收时钟。
- `tsetcrff` 未提供发送信号元素时钟。
- `tsetctbrg` 在发送信号元素定时（DTE 源）引脚、CCITT V.24 电路113、EIA-232-D 引脚24 上输出接收波特发生器。
- `tsetctset` 在发送信号元素定时（DTE 源）引脚、CCITT V.24 电路113、EIA-232-D 引脚24 上输出发送信号元素定时（DCE 源）。
- `tsetcrbr` 在发送信号元素定时（DTE 源）引脚、CCITT V.24 电路113、EIA-232-D 引脚24 上输出接收信号元素定时（DCE 源）。

- `rsetcoeff` 未提供接收信号波特-元素定时时钟。
- `rsetcrbrg` 在接收信号元素定时（DTE 源）引脚、CCITT V.24 电路128、无 EIA-232-D 引脚上输出波特发生器。
- `rsetctbrg` 在接收信号元素定时（DTE 源）引脚、CCITT V.24 电路128、无 EIA-232-D 引脚上输出传输波特发生器。
- `rsetctset` 在接收信号元素定时（DTE 源）引脚、CCITT V.24 电路128、无 EIA-232-D 引脚上输出发送信号元素定时（DCE 源）。
- `rsetcrser` 在接收信号元素定时（DTE 源）引脚、CCITT V.24 电路128、无 EIA-232-D 引脚上输出接收信号元素定时（DCE 源）。

## 控制字符赋值

```
control-character c
```

将控制字符设置为 c，其中控制字符-is 为 ctab, discard, dsup, eol, eol2, erase, kill, lnext, quit, reprint, stop, susp, swtch, erase（ctab 与 stipple 使用）；参见 `termio(7)`
