
# 第 14 章 客户端间通信函数

《客户端间通信规范》（以下简称 ICCCM）详细说明了 X 联盟批准的用于客户端间通信的规范。这些规范确保了客户端在选择选择、剪贴板缓冲区和共享资源方面的对等协作，以及客户端与窗口管理器、会话管理器之间的协作。更多信息请参阅《客户端间通信手册》。

Xlib 提供了许多符合 ICCCM 标准的标准属性和编程接口。其中某些属性的预定义原子在 `<X11/Xatom.h>` 头文件中定义，为了避免与用户符号冲突，它们的 `#define` 名称均带有 `XA_` 前缀。关于原子和属性的更多信息，请参见第 4.3 节。

Xlib 的选择和剪贴板缓冲区机制提供了通过客户端应用程序之间相互通信的主要编程接口（见第 4.5 节和 16.6 节）。本章讨论的函数提供了客户端应用程序与窗口管理器、会话管理器通信以及共享标准调色板的主要编程接口。

与窗口管理器和会话管理器通信时特别感兴趣的标准属性有：

| 名称 | 类型 | 格式描述 |
| --- | --- | --- |
| `WM_CLASS` | `STRING` | 8 由应用程序设置，允许窗口管理器和会话管理器从资源数据库获取应用程序的资源。 |
| `WM_CLIENT_MACHINE` | `TEXT` | 运行客户端程序的机器字符串名称。 |
| `WM_COLORMAP_WINDOW` | `WINDOWS` | 32 可能需要与其顶层窗口使用不同调色板的窗口 ID 列表。 |
| `WM_COMMAND` | `TEXT` | 用于调用应用程序的由空分隔的命令和参数。 |
| `WM_HINTS` | `WM_HINTS` | 客户端为窗口管理器设置的额外提示。该属性的 C 类型为 `XWHints`。 |
| `WM_ICON_NAME` | `TEXT` | 图标使用的名称。 |
| `WM_ICON_SIZE` | `WM_ICON_SIZE` | 32 窗口管理器可以在根窗口上设置此属性，以指定其支持的图标。该属性的 C 类型为 `XiconSize`。 |
| `WM_NAME` | `TEXT` | 应用程序的名称。 |
| `WM_NORMAL_HINTS` | `WM_NORMAL_HINTS` | 窗口在正常状态下的尺寸提示。该属性的 C 类型为 `XSizeHints`。 |
| `WM_PROTOCOLS` | `ATOM` | 32 客户端愿意参与的原子列表。 |
| `WM_STATE` | `ATOM` | 32 窗口正常的状态。 |
| `WM_TRANSIENT_FOR` | `WINDOW` | 窗口所属的窗口。 |

本章剩余部分讨论：

- 客户端到窗口管理器
- 客户端到会话管理器
- 标准调色板

### 操作顶层窗口

Xlib 提供了用于更改顶层窗口（根窗口的子窗口）可见或尺寸的函数。注意窗口管理器忽略子窗口。

要标识顶层窗口，请使用 `IconifyWindow`。

```c
Status IconifyWindow(display, w);
```

| 参数 | 描述 |
| --- | --- |
| `display` | X 服务器的连接。 |
| `w` | 窗口。 |
| `screen_number` | 主机屏幕编号。 |

`XIconify` 函数映射指定的窗口并向指定的根生成合成的 `UnmapNotify`。窗口管理器可以选择接收此消息并将其视为更改窗口状态为撤销的请求。当窗口处于撤销状态时，其正常表示和图标表示均不可见。如果成功发送 `UnmapNotify` 事件，则返回非零状态；否则返回零状态。

要请求撤销顶层窗口，使用 `WithdrawWindow(display, w, screen_number);`

```c
Status WithdrawWindow(display, w, screen_number);
```

| 参数 | 描述 |
| --- | --- |
| `display` | 服务器的连接。 |
| `w` | 窗口。 |
| `screen_number` | 主机屏幕编号。 |

要请求重配置顶层窗口，使用 `ReconfigureWMWindow(display, w, screen_number, value_mask);`

```c
Status ReconfigureWMWindow(display, w, screen_number, value_mask);
```

| 参数 | 描述 |
| --- | --- |
| `display` | X 服务器的连接。 |
| `w` | 窗口。 |
| `screen_number` | 主机屏幕编号。 |
| `value_mask` | 指定使用 `values` 结构中的信息设置值。 |
| `values` | `XWindowChanges` 结构。 |

`XReconfigureWMWindow` 函数向指定的顶层窗口发出 `ConfigureRequest`。如果堆叠模式激活且请求因 `BadMatch` 错误失败，则会被 Xlib 捕获并向指定窗口根发送包含配置参数的合成 `ConfigureRequestEvent`。窗口管理器可以选择接收此事件并将其视为重配置指示窗口的请求。如果请求或事件成功发送，则返回非零状态；否则，返回零状态。

`XReconfigureWMWindow` 可以产生 `BadValue` 和 `BadWindow` 错误。

### 字符串列表

许多文本属性允许多种类型和格式。由于存储在这些属性中的数据不是简单的空终止字符串，因此使用 `XTextProperty` 结构来描述文本的编码、类型、长度及其值。`XTextProperty` 结构包含：

```c
typedef struct {
    unsigned char *value; /* property data */
    Atom encoding; /* type of property */
    int format; /* 8, 16, or 32 */
    unsigned long items; /* value 中的项数 */
} XTextProperty;
```

Xlib 提供了用于本地化文本或转换为客户端间通信约定编码的函数。此外，还提供了用于将字符字符串指针列表转换为 `STRING` 编码的文本属性的函数。

本地化文本函数返回一个有符号整数状态，其中 `Success` 编码为零，特定的错误条件编码为负数，部分覆盖则返回不可转换字符的数量。

```c
#define XNoMemory -1
#define XLocalSupported -2
#define XConverterNotFound -3
```

```c
typedef enum {
    XStringStyle, /* STRING STYLE */
    XCompoundTextStyle, /* COMPOUND_TEXT */
    XTextStyle, /* 所有者编码中的文本（当前本地化） */
    XStdICTextStyle /* STRING，否则 COMPOUND_TEXT */
} XCCEncodingStyle;
```

要将文本字符串列表转换为 `XTextProperty` 结构，请使用 `XmbListToTextProperty` 或 `XwcListToTextProperty`。

```c
int XmbListToTextProperty(display, list, count, style, text_prop_return);
int XwcListToTextProperty(display, list, count, style, text_prop_return);
```
