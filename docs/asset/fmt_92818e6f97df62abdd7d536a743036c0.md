# 5

## 完善系统功能

轻松地下载、安装和更新程序

![](img/ba6b82a7869bba748202d57c97336dca_86_0.png)

Ubuntu 最方便的功能之一就是它配备了非常简单易用的应用程序安装机制。这种机制背后的引擎（广义上）被称为“高级软件包工具”（Advanced Package Tool，简称 APT），它允许你轻松地下载、安装、更新和删除封装在 DEB 归档（或软件包）中的软件。

APT 是一种非常不容易出错的程序安装方法；什么都不会丢失，因为它会自动下载并安装运行该应用程序所需的任何文件。对于大多数 Linux 用户来说，寻找这些被称为“依赖项”（dependencies）的文件是一个巨大的头疼问题。寻找并安装这个文件或那个文件，以及这些文件本身所拥有的任何依赖项的痛苦过程，导致了缺失依赖问题被称为“依赖地狱”（dependency hell）。而 APT 让这几乎成为了过去式。

APT 有一点让一些人（尤其是初学者）认为可能是问题，那就是是一个命令行驱动的应用程序。这意味着你通过命令行终端（Terminal）中的命令进行控制。通常，Ubuntu 为 APT 两个不同的图形化界面，允许你跳过命令行并让一切变得尽可能简单。

### 项目 5A：通过 Synaptic 安装应用程序

正如我提到的，Ubuntu 自带了两个 APT 的图形化界面：更简单但可能认为更具吸引力的 GNOME App Install；以及处理应用程序工作的主力——Synaptic。因为 Synaptic 是这两个应用程序中功能最全的，而且 GNOME App Install 也利用它来处理设置任务，我们将从 Synaptic 开始。

要查看 Synaptic，请进入系统菜单，选择“管理（Administration） > Synaptic 软件包管理器”。由于 APT 在你受保护的系统区域安装内容（该主题将在第 6 章详细介绍），在 Synaptic 实际出现之前，系统会在单独窗口中提示你输入密码。该密码是你常用的用户密码（其他 Linux 发行版的用户注意），所以很容易记住。在提示时输入你的密码并点击“继续（Continue）”。如图 5-1 所示，Synaptic 就会出现。

![](img/ba6b82a7869bba748202d57c97336dca_87_0.png)

图 5-1：Synaptic 软件包管理器

虽然 Synaptic 的界面初看起来非常简单，但它是一个非常强大的程序。它不仅允许你搜索、下载和安装应用程序，还允许你找到并安装那些不显眼但同样重要的库和支持文件，这些文件可能是为了配合 Ubuntu 自带的其他程序（如 MP3 支持），或你通过其他方式安装的程序。你还可以使用 Synaptic 查找其他内容，如字体、外语言本地化文件和常用工具，并在有可用更新时更新你在系统中安装的软件。

当然，如果你不知道在找什么，可以通过窗口左下角的“部分（Sections）”按钮通过 Synaptic 浏览软件包，在上方面板中选择感兴趣的类别，然后点击右上面板中特定软件包的名称，随后下方面板将显示该软件包的描述。

### 5A-1：通过 Synaptic 添加 APT 仓库

需要知道，APT（因此包括 Synaptic 和 GNOME App Install）搜索、下载和安装的软件包位于一组特定的仓库（repositories）中。这些仓库本质上是包含大量应用程序和支持文件的在线服务器，并且是针对你的特定系统而存储的。你系统最初自带的所有文件，包括系统（内核）本身以及可用的更新，都存储在那里。

Ubuntu 默认只激活了主程序和更新仓库，但真正的应用程序金库位于所谓的“宇宙（universe）”和“多宇宙（multiverse）”仓库。这些仓库包含了由 Ubuntu 社区准备并维护但未经 Ubuntu 官方支持的软件。为了获得良好的 Synaptic 体验（并跟上书中后续的项目），你需要确保 universe 和 multiverse 仓库已激活。

要这样做，请进入 Synaptic 设置（Settings），选择“仓库（Repositories）”。当“软件源（Software Sources）”窗口出现，你将看到所有当前激活的仓库（图 5-2）。检查四个框是否已勾选。如果其中任何一个框没有勾选，那么……勾选它们吧。你可以忽略“源代码（Source code）旁边的最后一个框。完成所有操作后，点击“关闭（Close）”按钮。

会出现一个新窗口，告诉你必须点击“重新加载（Reload）”按钮使更改生效。点击该窗口中的“关闭”按钮，然后按照刚才的指示在 Synaptic 主窗口中点击“重新加载”按钮。

Synaptic 将开始从你刚刚添加到其软件包数据库的每个仓库下载软件包列表。像图 5-3 所示的窗口将显示下载进度，并在进程完成后消失。会有很短一段时间，Synaptic 主窗口中的所有面板都会变成灰色，但不要担心；这只是暂时的。

![](img/ba6b82a7869bba748202d57c97336dca_89_0.png)

图 5-2：Synaptic 的仓库列表

图 5-3：Synaptic 中的下载进度

### 添加新仓库

你不需要现在就做，但事实上，知道你可以向 Synaptic 添加外部仓库是值得的。要添加仓库，只需遵循以下步骤：

1. 进入“设置（Settings）”菜单，选择“仓库（Repositories）”。

2. 在“软件源（Software Sources）”窗口中，点击“第三方软件（Third-Party Software）”标签。

3. 进入该标签后，点击“添加（Add）”按钮。

4. 会出现另一个窗口。在文本框中输入你要添加的仓库的 APT 行。所有仓库的格式将遵循如下所示：

```
deb http://example.com/repoisty main
```

5. 完成后，点击该窗口中的“添加”按钮。新仓库就像 universe 和 multiverse 仓库一样，只需通过取消勾选其条目旁边的框即可禁用。

### 5A-2：安装 Monkey Bubble

让我们通过安装一个名为 Monkey Bubble 的游戏来开始使用 Synaptic，看看它是如何工作的。你将要做的基本上是你用于通过 Synaptic 搜索和安装任何软件包的标准方法，因此这是一个值得记忆的过程。以下是步骤：

1. 在 Synaptic 主窗口中，点击“搜索（Search）”按钮。

2. 会出现一个“查找（Find）”窗口。确保“查找范围（Look In）”菜单中选择了“描述（Description）”和“名称（Name）”（以提供更宽松的搜索），在搜索框中输入 `monkey`，然后点击“搜索”按钮。

3. 一段时间后，右上面板将出现列表。找到 `monkey-bubble` 并点击它进行选中。该文件的描述将出现在右下面板。

4. 右键点击该条目，在弹出的菜单中选择“标记为安装（Mark for Installation）”。

5. 现在现在准备好操作了，只需点击 Synaptic 主窗口中的“应用（Apply）”按钮，随后会弹出另一个窗口（摘要/Summary），告知你将将安装什么、将更改什么以及哪些将保持不变（图 5-4）。

![](img/ba6b82a7869bba748202d57c97336dca_90_0.png)

图 5-4：Synaptic 让你知道将安装哪些额外的软件包

6. 点击该摘要窗口中的“应用”，随后 Synaptic 将开始安装过程，并在单独窗口中向你显示进度（实际上与你在图 5-3 中看到的进度窗口相似）。

7. 安装完成后，将出现一个类似图 5-5 所示的新窗口提示你。点击该最终窗口中的“关闭（Close）”，然后等待 Synaptic 退出暂时的灰色状态，这标志着安装过程结束。
