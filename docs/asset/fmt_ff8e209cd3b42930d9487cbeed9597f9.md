```
if [ $var -eq 5 ]

    break

done

```

当满足 `if-then` 条件时，`while` 循环执行了 `break` 命令并终止。

### 跳出内层循环

当你处理多个循环时，`break` 命令会自动终止你正在处理的最内层循环：

```bash
$ cat test19
#!/bin/bash
# breaking out of an inner loop
for (( a = 1; a < 4; a++ ))
do
    echo "Outer loop: $a"
    for (( b = 1; b < 100; b++ ))
    do
        if [ $b -eq 5 ]
        then
            break
        fi
        echo "Inner loop: $b"
    done
done
$ ./test19
Outer loop: 1
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
Outer loop: 2
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
Outer loop: 3
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
```

内层循环中的 `for` 语句指定一直迭代到变量 `b` 等于 100。然而，如果内层循环中的 `if-then` 语句指定变量 `b` 的值等于 5，则执行 `break` 命令。注意，尽管内层循环通过 `break` 命令终止了，但外层循环仍按照指定继续工作。

### 跳出外层循环

有时你处于内层循环中但需要停止外层循环。`break` 命令包含一个命令参数值：

`break n`

其中 `n` 表示要跳出的循环层级。默认情况下，`n` 为 1，表示跳出当前循环。如果你将 `n` 设置为值2，`break` 命令将停止下一级的外层循环：

```bash
$ cat test20
#!/bin/bash
# breaking out of an outer loop
for (( a = 1; a < 4; a++ ))
do
    echo "Outer loop: $a"
    for (( b = 1; b < 100; b++ ))
do
        if [ $b -gt 4 ]
        then
            break 2
        fi
        echo "Inner loop: $b"
    done
done
$ ./test20
Outer loop: 1
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
```

现在当 shell 执行 `break` 命令时，外层循环停止了。

## `continue` 命令

`continue` 命令是一种提前停止处理循环内部命令的方法，但不会完全终止循环。这允许你在循环中设置条件，使得 shell 在某些情况下不执行命令。这里有一个在循环中使用 `continue` 命令的简单示例：

```bash
$ cat test21
#!/bin/bash
# using the continue command
for (( var = 1; var < 15; var++ ))
do
    if [ $var -gt 5 ] && [ $var -lt 10 ]
    then
        echo "Iteration number: $var"
    fi
done
$ ./test21
Iteration number: 1
Iteration number: 2
Iteration number: 3
Iteration number: 4
Iteration number: 5
Iteration number: 10
Iteration number: 11
Iteration number: 12
Iteration number: 13
Iteration number: 14
$
```

当满足 `if-then` 语句的条件（值大于5且小于10）时，shell 执行 `continue` 命令，这跳过循环中的剩余命令，但保持循环继续。如果 `if-then` 条件不再满足，则恢复正常。

你可以在 `while` 和 `until` 循环中使用 `continue` 命令，但操作时要极度小心。记住，当 shell 执行 `continue` 命令时，它会跳过剩余的命令。如果你在这些条件之一中增加测试条件变量，就会发生糟糕的事情：

```bash
$ cat badtest3
#!/bin/bash
# improperly using the continue command in a while loop
var=0
while echo "while iteration: $var"
  [ $var -lt 15 ]
do
  if [ $var -gt 5 ] && [ $var -lt 10 ]
  then
    continue
  fi
  echo " Inside iteration number: $var"
  var=$[$var + 1] 
done
$ ./badtest3 | more

  Inside iteration number: 3

  Inside iteration number: 5
while iteration: 6

  Inside iteration number: 6
while iteration: 6
  Inside iteration number: 6

  Inside iteration number: 6
```
