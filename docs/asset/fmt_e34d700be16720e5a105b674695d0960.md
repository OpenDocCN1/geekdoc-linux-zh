
```
du /var/log
4     /var/log/httpd
4     /var/log/news/OLD
8     /var/log/news
4     /var/log/vbox
4     /var/log/samba
4     /var/log/sa
120   /var/log
```

每个目录名前面都有一个数字。该数字表示该目录使用的磁盘空间大小（以千字节为单位）。因此，`/var/log`目录整体使用了120K的磁盘空间，而`/var/log/old`子目录使用了4K。如果你只想查看某个目录（包括该目录中包含的所有文件和子目录）使用的总磁盘空间，请使用如下所示的`-s`选项：

```
du -s /var/log
120   /var/log
```

注意，`-s`选项使`du`仅打印`/var/log`目录的汇总信息。

> `-h`选项既适用于`du`也适用于`df`。

## 故障排除

如果某个命令未按预期工作，可能是因为执行的命令是Bash内置命令，而不是普通的Linux程序。例如，有两个可用的`pwd`命令：Bash的`pwd`命令和程序`/bin/pwd`。如果你不想使用Bash内置命令，必须输入命令的完整路径名，例如`/bin/pwd`。如果`ps`命令的输出在屏幕上滚动得太快以至于无法阅读，你可以将其输出重定向到文件（`ps ax > ps.out`），或者通过`more`命令管道传输其输出（`ps ax | more`）。

如果`df`或`du`命令的输出看起来不正确，请尝试以root用户身份执行它们。某些目录或它们包含的文件普通用户无法读取。

## 使用 ed 和 vi 进行文本编辑

所有UNIX系统，包括Linux，都自带两个文本模式文本编辑器：

- `ed`，一个面向行的文本编辑器
- `vi`，一个支持早期名为`ex`的编辑器命令集的全屏幕文本编辑器

虽然图形文本编辑器易于使用，但`ed`和`vi`可能比其他更图形的文本编辑器更难理解。你应该学习`ed`和`vi`的基本编辑命令，因为有时这两个可能是唯一可用的编辑器。例如，当你遇到系统问题且Linux拒绝从硬盘引导时，你可能需要从软盘引导。在这种情况下，你必须使用`ed`编辑器来编辑系统文件，因为该编辑器足够小，可以装入软盘。正如下面两部分所演示的，学习`ed`和`vi`的基本文本编辑命令并不难。

### 使用 ed

`ed`文本编辑器使用*缓冲区*工作——这是一个内存存储区域，实际文本在此处驻留，直到你明确将文本保存到文件。通常，你只有在引导极简版本的Linux（例如从引导软盘）且系统不支持全屏模式时才需要使用`ed`。在所有其他情况下，你可以使用`vi`编辑器，它在文本模式全屏下工作。

如你将在以下使用`ed`编辑器的示例中看到，你在命令模式或文本输入模式下工作，定义如下：

- *命令*模式是默认模式。在此模式下，你输入的任何内容都被解释为命令。`ed`文本编辑器有一个简单的命令集，其中每个命令由一个或多个字符组成。
- *文本输入*模式允许你将文本输入到缓冲区。你可以使用命令`a`（追加）、`c`（更改）或`i`（插入）进入输入模式。在输入几行文本后，你可以在单独的一行上输入一个句点（`.`）来退出输入模式。

为了练习编辑文件，请使用以下命令将`/etc/fstab`文件复制到你的主目录：

```
cd
cp /etc/fstab .
```

现在你的主目录中应该有一个名为`fstab`的文件。输入以下命令以开始使用`ed`编辑文件：

```
ed -p: fstab
608
:
```

此示例使用`-p`（*prompt*，提示符）选项将提示符设置为冒号字符（:`），然后打开当前目录中的`fstab`文件进行编辑，该目录应该是你的主目录。`ed`编辑器打开文件，报告文件中的字符数（690），显示提示符（:`），然后等待命令输入。

使用`ed`进行编辑时，您可能会发现使用`-p`选项开启提示字符很有帮助。没有提示符时，很难判断`ed`是处于输入模式还是命令模式。

当`ed`打开文件进行编辑后，当前行是文件的最后一行。*当前行*是指`ed`对其应用您命令的那一行。要查看当前行号，请使用`.`命令：

```
:.
8
```

此输出告诉您`fstab`文件有八行。（您的系统上的`/etc/fstab`文件可能具有不同行数的行数，在这种情况下，您将看到不同的数字。）
