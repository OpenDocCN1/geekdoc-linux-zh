对非线性规划的综述考虑了这些问题的理论和实践方面。理论问题包括代数和几何约束的研究，以及凸性以及保证解的存在和唯一性的条件。

一般的非线性规划问题可以表述为在满足某些约束的所有 $x$ 上最小线性二次目标函数 $f(x)$。约束具有一般的非线性形式和不等式。在数学上，当 $x = (x_1, x_2, \dots, x_k)$ 时，我们定义变量：

```
minimize f(x) subject to
g_i(x) \geq 0, i = 1, 2, \dots, m
h_j(x) = 0, j = 1, 2, \dots, p
```

其中 $f(x)$ 是目标函数，$g_i(x)$ 是不等式约束，$h_j(x)$ 是等式约束。这种公式对于最大化 $-f(x)$ 的问题通用，且 $g_i(x) \geq 0$ 是求解非线性规划问题的约束。

由于非线性方程无法以线性形式求解，必须使用迭代法。一组接近方法或迭代将在指定的条件下导致解。牛顿法（`Newton method`）是其中一种，也是许多求解非线性规划方法的基础。

### 非正弦波

非正弦波是指不是简单正弦波的电压。包含非线性元件（如二极管、铁芯电感器和晶体管）的电路会产生正弦电压和电流。当这些是时间的重复函数时，它们被称为振荡。振荡可能包含在一个周期内不同波段的不同谐波。一个周期对应两个电周期，并涵盖了第二个波形重复其形状的时间间隔 $T$，以此此类推。

这些电波由常数项（平均值或直流功率）偏置，加上一系列相对于基频 $f_0$ 的谐波，如果基频存在，则其周期为 $T = 1/f_0$。那么二谐波频率 $f_2$ 在 $T$ 范围内将有两个周期。

上述项序列也称为傅里叶级数，可以表示为函数 $y(t)$ 的形式，在基频周期内绘制图时，其形状为

$y(t) = B_0 + C_1\sin(f_0t + \phi_1) + C_2\sin(2f_0t + \phi_2) + \dots = \sum_{n=1}^{\infty} C_n\sin(nf_0t + \phi_n)$

即非正弦波。基频频率为 $\omega_0 = 2\pi f_0$，$C_1$ 是基振幅。$C_n$ 是频率为 $nf_0$ 的谐波振幅，$\phi_n$ 为它们的相位。基频相对于选定时间间隔的相位角为 $\phi_1$，$\phi_n$ 是谐波的相位角。更多详情见。
