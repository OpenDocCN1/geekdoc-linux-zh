## sysV-make — 维护、更新和重新生成程序

用法

`/usr/lib/svr4.make [-f makefile][-eiknapqrst] [names]`

描述

`sysV-make` 命令是 System Vset 的原生 `make` 版本。如果设置环境变量 `USE_SVR4_MAKE`，则 `make` 命令将调用此版本的 `make`。

`make` 允许程序员维护、更新和重新生成一组计算机程序。`make` 执行 `makefile` 中的命令以更新一个或多个目标名称(`names`)（通常是程序）。如果你不指定 `-f` 选项，则 `make` 将按顺序尝试 `makefile`、`Makefile` 以及源码控制系统 (SCCS) 文件 `s.make`。如果 `makefile` 是一个横杠 (`-`)，则从标准输入读取。你可以指定多个 `-f makefile` 参数对。

只有当目标的依赖项比目标更新新时，`make` 才会更新该目标。目标的所有先决文件都会递归地添加到目标列表中。缺失的文件被视为已过时。你可以在 `makefile` 中包含以下列表中的指令来扩展目标。这些指令在 `makefile` 中的用法如下：

- `DEFAULT`: 如果必须制作某个文件，但没有显式命令或相关的内置规则，则使用与 `name .DEFAULT`（如果存在）相关联的命令。
- `IGNORE`: 与 `-i` 选项相同。
- `PRECIOUS`: 当按下退出或中断时，不要删除 `.PRECIOUS` 条目中的依赖项。
- `SILENT`: 与 `-s` 选项相同。
