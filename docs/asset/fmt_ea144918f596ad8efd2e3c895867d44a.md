
## 描述

`ex` 是编辑器家族（`ex`, `edit`, `vi`）的根。`ex` 是 `ed(1)` 的子集，最显著的扩展是显示编辑功能。显示编辑是 `ex` 的重点。

如果你有一个 CRT 终端，你可能想使用显示编辑器；在这种情况下，使用 `vi(1)`，它是一个专注于 `ex` 显示编辑部分的命令。

如果你已经使用了 `ed`，你会发现除了可以使用所有的 `ed` 命令外，`ex` 还有许多在 CRT 终端上有用的功能。智能终端和高速终端使用 `vi` 非常愉快。通常，`ex` 编辑器比 `ed` 使用更多的终端能力。

## 选项

- `-s` 抑制所有交互式用户反馈。此选项在处理编辑器脚本时非常有用。注意，如果你使用命令行 `-s` 选项，文件输入/输出错误将不会打印文件名。
- `+command` `c` 通过执行指定的编辑器命令开始编辑（通常是搜索或定位命令）。
- `-C` 模拟 `C` 命令。`C` 命令类似于 `x` 命令，不同之处在于它假设读取的所有文本都经过了加密。
- `-1` 准备为编辑 LSP 程序做准备。
- `-L` 列出所有作为编辑器或系统崩溃结果保存的文件名。
- `-R` 设置只读标志，以防止意外覆盖文件。
- `-r file` 在编辑器或系统崩溃后编辑文件。（恢复崩溃时缓冲区中文件的版本。）注意，当你在加载文件时看到“文件太大，无法用 -r 选项恢复”的消息时，表示你已成功保存并编辑了该文件。然而，如果编辑器会话丢失，你无法通过 -r 选项恢复文件。
- `-t tag` 编辑包含标签的文件，并将编辑器定位到其定义处。
- `-V` 使用 `vi` 启动显示编辑。你只需输入 `vi` 命令即可实现相同效果。
- `-V` 当通过标准输入读取 `ex` 命令时，将输入回到标准错误。这个详细选项对于在 shell 脚本中处理 `ex` 命令非常有用。
- `-wn` 将默认窗口大小设置为 `n`。此选项在通过低速线路使用编辑器时非常有用。
- `-x` 模拟 `x` 命令并提示加密密钥。该密钥使用 `crypt` 命令的算法对文本进行加密和解密。`x` 命令通过合理推断来判断读取的文本是否加密。临时缓冲区文件也会加密，使用的是用于 `-x` 选项的密钥的转换版本。

注意 — 尽管以下选项仍被支持，但它们在文档中已被遵循命令语法标准的后续选项所替换（参见 `intro(1)`）。该选项已被 `-s` 替换；未跟选项参数的 `-r` 选项已被 `-L` 替换；`+command` 已被 `-c command` 替换。

```
/usr/xpg4/bin/ex
```

如果你同时指定了 `-t tag` 和 `-c command` 选项，将先处理 `-t tag`。也就是说，先通过 `-t` 选择包含标签的文件，然后执行命令。
