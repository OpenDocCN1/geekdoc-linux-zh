
# 窗口信息函数

## 原子名称函数

如果所有名称都返回了原子，此函数返回非零状态；否则返回零。

`XInternAtom` 可以产生 `BadAlloc` 和 `BadValue` 错误。

要为给定的原子标识符返回名称，请使用 `XGetAtomName`。

### XGetAtomName

```c
char *XGetAtomName(display, atom);
```

`display` 指定与 X 服务器的连接。  
`atom` 指定想要返回的属性名称对应的原子。

`XGetAtomName` 函数返回与指定原子关联的名称。返回的数据如果是拉丁可移植字符编码（Latin Portable Character Encoding），则返回的字符串为主机可移植字符编码；否则，结果取决于实现。要释放该字符串，请调用 `XFree`。

`XGetAtomName` 可以产生 `BadAlloc` 错误。

要为一组原子标识符返回名称，请使用 `XGetAtomAtoms`。

### XGetAtomAtoms

```c
Status XGetAtomAtoms(display, atoms, count, names_return);
```

`display` 指定与 X 服务器的连接。

参数说明：

- `atoms`：指定原子数组。
- `count`：指定数组中原子的数量。
- `names_return`：返回原子名称。

`XGetAtomNames` 函数返回与指定原子关联的名称。名称存储在调用者提供的 `names_return` 中。调用此函数等同于依次为每个原子调用 `XGetAtomName`，此函数最大限度地减少了客户端与 X 服务器之间的往返协议交换次数。

如果所有原子都返回了名称，此函数返回非零状态；否则返回零。

`XGetAtomNames` 可以产生 `BadAtom` 错误。

## 获取和更改窗口属性

你可以为每个窗口附加一个属性列表。每个属性都有一个名称、类型和一个值（参见第 4.3 节）。该值是 8 位、16 位或 32 位数量的数组，其解释留给客户端决定。`char` 类型用于表示 8 位数量，`short` 类型用于表示 16 位数量，`long` 类型用于表示 32 位数量。

Xlib 提供了你可以使用的函数，用以获取、更改、更新或交换窗口属性。此外，Xlib 还提供了其他用于客户端通信的实用函数（第 14 章）。

要获取给定窗口属性的类型、格式和值，请使用 `XGetWindowProperty`。

### XGetWindowProperty

```c
int XGetWindowProperty(display, w, property, long_offset, long_length, delete, req_type, actual_type_return, return, actual_format_return, nitems_return, bytes_after_return, prop_return);
```

- `display`：指定与 X 服务器的连接。
- `w`：获取窗口。
- `property`：指定属性名称。
- `long_offset`：指定指定属性中（32 位数量）要检索数据的数据偏移量。
- `long_length`：指定要检索的数据按 32 位倍计算的长度。
- `delete`：指定一个布尔值，决定是否删除该属性。
- `req_type`：指定与属性类型或 `AnyPropertyType` 关联的原子标识符。
- `actual_type_return`：返回定义属性实际类型的原子标识符。
- `actual_format_return`：返回属性的实际格式。
- `nitems_return`：返回 `prop_return` 数据中存储的 8 位、16 位或 32 位项的实际数量。
- `bytes_after_return`：如果执行了部分读取，则返回读取该属性剩余的字节数。
- `prop_return`：返回指定格式的数据。

`XGetWindowProperty` 函数返回属性的实际类型；属性的实际格式；传输的 8 位、16 位或 32 位项的数量；读取该属性时剩余的字节数；以及指向实际返回数据的指针。`XGetWindowProperty` 设置返回参数如下：

- 如果指定的窗口不存在指定的属性，`XGetWindowProperty` 向 `actual_type_return` 返回 `None`，向 `actual_format_return` 返回值。
- 如果指定的属性存在但与类型不匹配，`XGetWindowProperty` 向 `actual_type_return` 返回 `None`，向 `actual_format_return` 返回值。
- 如果指定的属性存在且类型匹配，`XGetWindowProperty` 向 `actual_type_return` 返回实际类型，向 `actual_format_return` 返回实际格式，向 `nitems_return` 返回数量，向 `bytes_after_return` 返回剩余字节数，向 `prop_return` 返回数据。

`XGetWindowProperty` 可以产生 `BadAlloc` 错误。

### XListProperties

要获取窗口的属性列表，请使用 `XListProperties`。

```c
Atom *XListProperties(display, w, num_prop_return);
```

`display` 指定与 X 服务器的连接。  
`w` 指定想要获取属性列表的窗口。  
`num_prop_return` 返回数组的长度。

`XListProperties` 函数返回一个指向该窗口定义的原子数组的指针，如果没有找到属性，则返回 `NULL`。要释放此函数分配的内存，请使用 `XFree`。

`XListProperties` 可以产生 `BadWindow` 错误。

要更改给定窗口的属性，请使用 `XChangeProperty`。

### XChangeProperty

```c
XChangeProperty(display, w, property, type, format, mode, data, elements);
```

`display` 指定与 X 服务器的连接。  
`w` 指定想要更改属性的窗口。  
`property` 指定属性名称。  
`type` 指定属性的类型。  
`format` 指定数据应被视为 8 位、16 位或 32 位数量的列表。  
`mode` 指定操作模式。  
`data` 指定属性数据。  
`elements` 指定指定数据格式的元素数量。

- 如果模式为 `PropModePrepend` 或 `PropModeAppend`，`XChangeProperty` 分别将指定的数据插入到现有数据的开头或现有数据的末尾。类型和格式必须与现有属性值匹配，否则将产生 `BadMatch` 错误。如果属性未定义，则将其视为具有正确类型和格式且数据长度为零的。

如果指定的格式为 8，属性数据必须是一个 `char` 数组。如果指定的格式为 16，属性数据必须是一个 `short` 数组。如果指定的格式为 32，属性数据必须是一个 `long` 数组。

属性的生命周期不与存储客户端绑定。属性将一直存在，直到被显式删除、窗口被销毁或服务器重置。关于连接到 X 关闭时会发生什么，请参见第 2.6 节。属性的最大大小是有定义的，并且可以动态取决于服务器可用内存量。（如果空间不足，将发生 `BadAlloc` 错误。）

`XChangeProperty` 可以产生 `BadAlloc`、`BadAtom`、`BadMatch` 和 `BadWindow` 错误。

### XRotateWindowProperties

要旋转窗口属性列表，请使用 `XRotateWindowProperties`。

```c
XRotateWindowProperties(display, w, properties[], num_prop, npositions);
```

`display` 指定到 X 服务器的连接。  
`w` 指定窗口。  
`properties` 指定要旋转的属性数组。  
`num_prop` 指定属性数组的长度。  
`npositions` 指定旋转的次数。

`XRotateWindowProperties` 函数允许你旋转窗口上的属性，并导致 X 服务器生成 `PropertyNotify` 事件。如果 `properties` 数组中的属性名称被视为从 0 开始编号，且列表中有 `num_prop` 个名称，则与属性名 (i) 关联的值对于所有从 0 到 N-1 的 i 均变为 N。其效果是围绕属性名称的环形结构对属性进行位置上的旋转（正数位置向右旋转，负数 `npositions` 向左旋转）。如果 `npositions` 不为 0，X 服务器将按照属性在数组中列出的顺序为每个属性生成一个 `PropertyNotify` 事件。如果一个原子在列表中出现多次，或者该窗口上没有定义该名称的属性，将产生 `BadMatch` 或 `BadAlloc` 错误，属性不会发生更改。

`XRotateWindowProperties` 可以产生 `BadAtom`、`BadMatch` 和 `BadWindow` 错误。

### XDeleteProperty

要删除给定窗口上的属性，请使用 `XDeleteProperty`。

```c
XDeleteProperty(display, w, property);
```

`display` 指定到 X 服务器的连接。  
`w` 指定你想要删除属性的窗口。
