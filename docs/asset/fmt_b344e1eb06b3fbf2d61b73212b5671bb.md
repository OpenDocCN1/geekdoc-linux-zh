
命令可以单独执行，例如 `ls`。当你指定一个选项（通常以短横线 `-` 开头）时，命令的行为会有所不同，例如 `ls -a`。同一个选项字符在另一个命令中可能有不同的含义。GNU 程序支持以两个短横线 `--` 开头的长选项，如 `ls --all`。某些命令没有选项。

命令的参数是对你想让命令生效的对象的指定。例如 `ls /etc`，其中目录 `/etc` 就是该命令的参数。这表示你想查看该目录的内容，而不是通过仅输入 `ls` 并按 `回车` 获取默认的当前目录内容。某些命令需要参数，而某些参数是可选的。

你可以通过检查该命令的在线帮助来确认它是否接受参数以及哪些参数是有效的，参见“获取帮助 (Getting help)”章节。

在 Linux 中，与 UNIX 一样，目录使用斜杠 分隔，这与网页地址（URL）使用的相同。我们稍后会深入讨论目录结构。

涉及目录时，`.` 和 `..` 有特殊含义。我们将在练习和下一章尝试了解这些内容。

尽量避免登录或使用系统管理员账户 `root`。除了你的正常工作外，其他任务（包括检查系统、收集信息等）可以使用没有任何特殊权限的普通用户账户执行。如果需要（例如在创建新用户或安装新软件时），获取 root 权限的首选方法是切换用户 ID，参见“路径 (The path)”章节的示例。

书中的几乎所有命令都可以在没有管理员权限的情况下执行。在大多数情况下，当非特权用户发布命令或启动程序时，如果需要 root 权限，系统将警告你或提示输入 root 密码。完成后，请立即离开具有权限的应用程序或会话。

阅读文档应该是你的本能。特别是在刚阶段，阅读系统文档、基本命令手册、HOWTO 等非常重要。由于文档量极其巨大，不可能包含所有相关文档。本书将尝试引导你找到每个主题最合适的文档，以培养阅读 man 页的习惯。

## 使用 Bash 特性

几个关键组合键允许你使用 GNU shell（Bash）更轻松、更快速地完成任务。Bash 是任何 Linux 系统的默认 shell，参见“外壳 (The shell)”章节。以下是常用的常用功能列表；强烈建议你养成使用这些功能的习惯，以便从一开始就充分利用你的 Linux 特性。

### 表 2.2. Bash 中的按键组合

| 按键或组合键 | 功能 |
| --- | --- |
| Ctrl+A | 将光标移动到命令行的开头。 |
| Ctrl+C | 结束正在运行的程序并返回提示符，参见第 4 章“进程 (Processes)”。 |
| Ctrl+D | 退出当前 shell 会话，等于 exit 或 logout。 |
| Ctrl+E | 将光标移动到命令行的末尾。 |
| Ctrl+H | 生成退格符字符。 |
| Ctrl+L | 清除当前终端。 |
| Ctrl+R | 搜索命令历史，参见“grep 命令 (The grep command)”章节。 |
| Ctrl+Z | 暂停程序，参见第 4 章“进程 (Processes)”。 |
| 左箭头和右箭头 | 在命令行上向左或向右移动光标，以便在开头和结尾的其他位置插入字符。 |
| 上箭头和下箭头 | 浏览历史。跳转到你想重复的行，如有必要时编辑细节，然后按回车节省时间。 |
| Shift+Page 和 Shift+PageDown | 浏览终端缓冲区（查看滚出屏幕的文本）。 |
| Tab | 命令或补全：当有多种可能选择时，系统将通过音频或视觉蜂铃发出信号，或者如果有许多选择，则会询问你是否想查看所有选项。 |
| Tab Tab | 显示文件或命令的可能选项。 |

此表的最后两项可能需要额外的解释。例如，如果你想进入 `directory_with_a_very_long_name` 目录，你不需要输入那个非常长的名字。你只需要在命令行中输入 `cd dir`，然后按 Tab 键，如果没有其他以相同字符开头的文件，shell 就会为你补全名称。当然，如果没有其他以“d”开头的项，你可能只需要输入 `cd d` 然后按 Tab。如果有多个文件以相同的字符开头，shell 会向你发出信号，此时你可以短时间内连续按两次 Tab，shell 就会呈现你拥有的选择：

```
your_prompt> cd st
starthere stuff stuffit
```

在示例中，如果你在前两个字符后输入 "u" 并再次按 Tab，将不再有其他可能性。man 会显示选项，直到你到达结尾：

```
your_prompt> cd st
starthere
```

或者，如果文件名没有歧义，shell 会补全它。当你再次按 Tab 时，man 会显示选项：

```
ls
dev
```

这同样适用于命令补全。

## 获取帮助 (Getting help)

### 警告 (Be warned)

GNU/Linux 变得自给自足。许多新手害怕 man 页（手册），因为它们信息量过大。然而，它们的结构良好，正如示例所示：

```
username@your ~ man
```

### man 页 (The man pages)

阅读文档应该是你的本能。特别是在刚阶段，阅读系统文档、基本命令手册、HOWTO 等非常重要。由于文档量极其巨大，不可能包含所有相关文档。本书将尝试引导你找到每个主题最合适的文档，以培养阅读 man 页的习惯。

#### NAME

`man` - 格式化并显示在线页面

`manpath` - 确定搜索路径

#### SYNOPSIS

```
man [-acdfHTW] [--path] [-m system] [-C configfile] [-M path] [-P page] [-S section_list] [section] name
```

#### DESCRIPTION

`man` 格式化并显示在线页面。如果你指定了 section，`man` 只会在该部分查找 name。如果 `man` 包含斜杠，`man` 会将其解释为文件规范，因此你可以执行 `man /foo.5` 或 `man /cd/bar.1`。

有关 `man` 查找页文件的说明，见下文。

#### OPTIONS

```
-C configfile
lines 1-27
```

使用空格键翻到下一页。可以使用 b 键返回上一页。当你到达结尾时，`man` 通常会退出并返回提示符。如果你在到达结尾之前离开 man 页，或者查看器在结尾没有自动退出，请输入 q。

#### 分页器 (Pagers)

操作 `man` 的可用组合键取决于我们使用的分页器。大多数发行版使用 less 来查看和滚动。参见 less 章节获取更多关于分页器的信息。

每个 man 页都包含几个章节细节，正如我们在 man 页示例所示：第一行包含你正在阅读的命令名称，以及该 man 页所在的章节 ID。页面按章节排序。命令可能会有多个页面。

- 提供了该命令更详细的描述。
- 列出了选项及其描述。选项通常可以组合使用。如果不能组合，本节将说明相关情况。
- 环境描述了影响该命令行为的 shell 变量（并非所有命令都有此项）。
- 提供了该命令的特定章节。
- `SEE ALSO` 部分提供了对其他页面的引用。括号内是查找该命令的 man page（帮助页）章节。丰富的用户通常使用 `/` 命令后跟搜索字符串 `SEE` 并按 `Enter` 来切换到 `SEE ALSO` 部分。
- 通常还有关于已知错误（异常）的信息，以及发现新错误 时的报告地址。
- 可能还包含作者和版权信息。

某些命令有多个页面。例如，`passwd` 命令在第 1 节有一个 man 页，在第 5 节有另一个。默认情况下显示编号最小的 man 页。如果你想查看默认之外的其他章节，可以在 man 命令后指定它：

```
man 5 password
```

如果你想查看关于某个命令的所有页面，请对 `man` 使用 `-a` 参数：

```
man -a password
```

这样，当你到达第一页末尾并再次按下 `SPACE` 时，将显示下一个章节的 man 页。

## 更多信息

### Info 页面

除了 man 页之外，你还可以使用 `info` 命令阅读关于命令的 Info 页。这些页面通常包含更新的信息，且使用起来稍微简单。某些命令的 man 页会引用 Info 页。

在终端窗口中输入 `info info` 开始使用：

```
File: info.info, Node: Top, Next: Getting Started, Up: (dir)
**********************************
```

Info 是你现在正在使用的一个程序，用于阅读计算机程序的文档。GNU 项目以 Info 格式分发大部分在线手册，因此你需要一个“Info 阅读器”来阅读这些手册。你现在使用的正是其中一个程序。
