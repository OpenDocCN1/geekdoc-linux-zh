- 内核 `Kernel`
  内核是 Linux 操作系统的核心部分，直接与硬件交互。它负责 Linux 系统的所有主要活动。

- 系统库 `System Library`
  系统库是特殊的程序，应用程序通过它们访问内核的功能。

- 系统工具 `System Utility`
  系统工具程序负责执行特定的任务。
