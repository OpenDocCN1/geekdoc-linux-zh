# Linux 操作系统

主板可能还拥有一个或多个扩展槽。扩展槽允许用户添加特殊的电路板作为扩展卡，以支持自定义、遗留和非标准的显卡。扩展卡还支持 RAID，以及用于串行和并行连接的特殊遗留接口。

系统级芯片（SoC）配置通过将处理器、系统内存、SSD 和控制外设的硬件封装成单个集成电路封装，实现了比主板配置在功耗、性能、空间和可靠性方面的优势。SoC 配置所支持的外设受限于封装组件的种类。因此，SoC 配置倾向于为特定用途而开发。手机、平板电脑和其他便携设备通常基于 SoC 技术。

某些系统集成了外设。笔记本电脑类似于工作站，集成了显示器、键盘和鼠标外设。一体机（All-In-One systems）类似于笔记本电脑，需要鼠标和键盘外设。主板或 SoC 控制器通常与适用于特定用途的集成外设一起。

# 驱动程序和设备文件

到目前为止，本课程介绍了关于处理器、内存、分区、格式化和外设的信息。如果要求普通用户处理系统中每个设备的特定细节，将导致这些系统无法使用。同样，软件开发人员将需要为他们支持的每个新设备或修改过的设备修改代码。

“处理细节”问题的解决方案是由设备驱动程序提供的。设备驱动程序接受一组标准请求，然后将这些请求转换为相应的设备控制活动。设备驱动程序允许您和您运行的应用程序从 `/home/*/stuff` 读取文件，而而不必担心文件是在硬盘、固态内存 棒、加密存储还是其他设备上。

设备文件位于 `/dev` 目录中，用于识别设备、设备访问和支持的驱动程序。在带有 SCSI 或 SATA 存储设备的现代系统中，规范文件名以前缀 `sd` 开头。前缀后面是一个字母（如 `a` 或 `b`），表示物理设备中的一个分区。因此，`/dev/sda3` 将第一个存储设备中的第 3 分区。每种类型的设备文件都有适用于该设备的命名约定。虽然涵盖所有可能的命名约定超出了本课程的范围，但请记住，这些约定对于使系统管理成为可能关重要。
