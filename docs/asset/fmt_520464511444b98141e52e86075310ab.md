# 为 Linux 客户端启用 Exchange 的 Pop 和 IMAP 访问

并不是每个环境都有独立的 Linux 邮件服务器供 Linux 客户端使用。在某些情况下，你可能希望允许 Linux 或非 Windows 客户端直接在 Exchange 服务器上检查邮件。通过开启 Exchange 服务器对 POP 和 IMAP 的支持轻松实现这一点。尽管这没有让 Linux 客户端获得运行 Outlook 时的完整协作功能，但对于读取电子邮件来说效果良好。

我们将通过 Exchange 服务器的命令行命令来启用 POP 和 IMAP 支持。使用命令提示符，输入：

```
sc config pop3svc start=auto
sc config imapsvc start=auto
sc start pop3
sc start imap4
```

注意，等号后面没有空格。Windows 将这些协议称为 POP3 和 IMAP4，以将它们与旧版本的 POP 和 IMAP 区分来。
