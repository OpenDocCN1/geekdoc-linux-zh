
`environ` 字典包含以下 WSGI 特定的值：

- `wsgi.version`：表示 WSGI 版本（例如 `(1,0)`）。
- `wsgi.scheme`：表示方案（`'http'` 或 `'https'`）。
- `wsgi.input`：输入的文件类对象。
- `wsgi.errors`：以文本模式打开的文件对象。
- `wsgi.multithread`：布尔值，如果应用程序是多线程。
- `wsgi.multiprocess`：布尔值，如果应用程序是多进程。
- `wsgi.run_once`：布尔值，如果应用程序在进程生命周期内只运行一次。

# WSGI 规范

`start_response` 参数是一个用于启动响应的可调用对象。`headers` 是一个元组列表，每个元组 `(name, value)` 对应一个 HTTP 头部。

响应的数据或主体由 Web应用程序作为一个产生字符串的迭代器返回。如果应用程序需要进行任何 UTF-8 编码，它必须自己处理。

这是一个读取字段并产生某些输出的 WSGI应用程序示例：

```python
import cgi

def subscribe_app(environ, start_response):
    fields = cgi.FieldStorage(environ['wsgi.input'])
    environ=environ
    name = fields.get("name")
    email = fields.get("email")
    # 各种处理
    status = "200 OK"
    headers = [['Content-type','text/plain']]
    start_response(status, headers)
    response = [
        'Hi %s. Thank you for subscribing.' % name,
        'You should expect a response soon.' % email
    ]
    return [line.encode('utf-8') for line in response]
```

## wsgiref 包

`wsgiref` 包提供了 WSGI 标准的参考实现，允许应用程序在独立服务器中进行测试，或作为普通的 CGI 脚本执行。

## wsgiref.simple_server

`wsgiref.simple_server` 模块实现了一个简单的独立 HTTP 服务器，用于运行简单的 WSGI 应用程序。有两个感兴趣的函数：

### make_server(host, port, app)

创建一个在指定的主机名 `host` 和端口号 `port` 上接受连接的 HTTP 服务器。`app` 是一个实现 WSGI 应用程序的函数或可调用对象。要运行该服务器，请使用 `s.server_forever()`，其中 `s` 是返回的服务器实例。

### demo_app(environ, start_response)

这是一个 WSGI 应用程序，返回包含“Hello World”消息的页面。它可以作为 `make_server()` 的 `app` 参数来验证服务器是否工作正常。

以下是一个运行简单 WSGI 服务器的示例：

```python
def my_app(environ, start_response):
    # Some application
    start_response("200 OK", [('Content-type', 'text/plain')])
    return ["Hello World"]

if __name__ == '__main__':
    from wsgiref.simple_server import make_server
    serv = make_server('', 8080, my_app)
    serv.server_forever()
```

## wsgiref.handlers

`wsgiref.handlers` 模块包含用于设置 WSGI 环境的处理器对象，以便应用程序可以在任何 Web 服务器中运行（例如 Apache 下的 CGI 脚本）。这里有几个不同的对象。

### CGIHandler()

创建一个在 CGI 环境中运行的 WSGI 处理器对象。该处理器从 `cgi` 库描述的标准环境变量和 I/O 流中收集信息。

### BaseCGIHandler(stdin, stdout, stderr, environ, {multithread, multiprocessing})

创建一个在 CGI 环境中运行的 WSGI 处理器，在该环境中，标准的 I/O 流和环境变量可能以不同的方式设置。`stdin`、`stdout` 和 `stderr` 指定用于 I/O 流的文件对象。`environ` 是环境变量字典，预期始终包含标准的 CGI 环境变量。`multithread` 和 `multiprocessing` 是布尔标志，用于设置 `wsgi.multithread` 和 `wsgi.multiprocessing` 环境变量。默认情况下，`multithread` 为 `True`，`multiprocessing` 为 `False`。

### SimpleHandler(stdin, stdout, stderr, environ, multithread, multiprocess)

创建一个与 `BaseCGIHandler` 相似的 WSGI 处理器，但它允许底层应用程序直接访问 `stdin`、`stdout`、`stderr` 和 `environ`。与 `BaseCGIHandler` 的不同的是，后者提供了处理某些功能的额外逻辑（例如在 `BaseCGIHandler` 中，响应码会被转换为 Status 头）。

所有这些处理器都有一个 `run(app)` 方法，用于在处理器内运行 WSGI 应用程序。这是一个作为传统 CGI 脚本运行的 WSGI 应用程序示例：

```python
#!/usr/bin/env python
def my_app(environ, start_response):
    # Some application
    start_response('200 OK', [('Content-type', 'text/plain')])
    return ['Hello World']
```

```python
from wsgiref.handlers import CGIHandler
hand = CGIHandler()
hand.run(my_app)
```

## wsgiref.validate

`wsgiref.validate` 模块有一个函数，可以将 WSGI 应用程序包装在一个验证包装器中，以确保应用程序和服务器都按照标准运行。

### validator(app)

创建一个新的 WSGI 应用程序，该应用包装了 WSGI 应用程序 `app`。新应用程序的工作方式与 `app` 相同，但增加了额外的检查以确保应用程序和服务器遵循 WSGI 标准。任何验证结果都会以 `AssertionError` 异常的形式出。

以下是使用 `validator` 的示例：

```python
def my_app(environ, start_response):
    # Some application
    start_response('200 OK', [('Content-type', 'text/plain')])
    return ['Hello World']
```

```python
if __name__ == '__main__':
    from wsgiref.simple_server import make_server
    from wsgiref.validate import validator
```
