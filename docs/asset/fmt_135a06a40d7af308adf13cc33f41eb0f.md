## pof: 被动式操作系统指纹识别

## amap: 应用版本检测

有时，你可能会遇到无法通过端口号或即时响应轻松识别的服务。`amap` 会向特定服务发送多次查询和探测，然后分析结果（包括返回的横幅），以识别特定端口上实际运行的应用程序或服务。某些选项允许你最小化并行尝试，或者通过大量尝试真正给系统施压，这可能会提供不同的信息。你也可以使用 `-1` 选项查询一次服务，并在报告第一个匹配的横幅后返回。在图 3.16 中，使用 `amap` 用来发现 OpenSSH 服务器和 DNS 服务器。这些扫描使用的选项包括：调用映射 `-A`、打印收到的任何 ASCII 横幅 `-b`、不将关闭且无响应的端口标记为已识别或已报告 `-q`，以及使用 UDP 端口 `-u`。
