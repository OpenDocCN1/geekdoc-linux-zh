
`new(hashname)`

创建一个新的摘要对象。`hashname` 是一个字符串，例如 `'md5'` 或 `'sha256'`，指定要使用的哈希算法名称。哈希名称可以是之前的任何一种哈希算法，也可以是 OpenSSL 库暴露的哈希算法（取决于安装情况）。

# hmac

`hmac` 模块提供了对 HMAC（密钥哈希的消息身份验证）的支持，该算法在 RFC-2104 中描述。HMAC 是一种基于 MD5 和 SHA1 等加密哈希函数构建的消息身份验证机制。

```
new(key [, msg [, digest]])
```

创建一个新的 HMAC 对象。在这里，`key` 是包含哈希起始密钥的字节字符串，`msg` 包含要处理的数据，`digest` 是用于加密哈希的摘要构造函数。默认情况下，`digest` 为 `hashlib.md5`。

通常，初始密钥值使用加密强随机数生成器随机确定。

HMAC 对象 `h` 具有以下方法：

```
h.update(msg)
```

将字符串 `msg` 添加到 HMAC 对象中。

```
h.digest()
```

返回到为止处理的所有数据的摘要，并返回一个包含摘要值的字节字符串。字符串的长度取决于底层的哈希函数。对于 MD5，长度为 16 个字符；对于 SHA-1，为 20 个字符。

```
h.hexdigest()
```

以十六进制字符串形式返回摘要。

```
h.copy()
```

制作 HMAC 对象的副本。

## 示例

`hmac` 的主要用途是验证消息。要实现这一点，使用密钥和消息创建一个 HMAC 对象，然后将摘要与预期值进行比较。这是一个示例：

```python
import hmac
import hashlib

key = b"secret"
msg = b"Hello World"
h = hmac.new(key, msg, hashlib.md5)
if h.hexdigest() == "83359617777777777777777777777777":
    print("Authenticated")
else:
    print("Not authenticated")
```

# HTMLParser

Python 3 中，此模块名为 `html.parser`。`HTMLParser` 定义了一个用于解析 HTML 和 XHTML 文档的类。要使用此模块，定义一个继承自 `HTMLParser` 的类并重写相应的方法。

```
HTMLParser()
```

这是一个创建解析器的基类。初始化不需要任何参数。

`HTMLParser` 实例 `h` 具有以下方法：

```
h.close()
```

关闭解析器并强制处理任何未解析的数据。该方法在所有 HTML 数据输入解析器后调用。

```
h.feed(data)
```

向解析器提供数据。这些数据会被立即解析。然而，如果数据是不完整的（例如以 HTML 元素结尾），不完整的部分将被缓冲并在下次调用 `feed` 提供更多数据时进行解析。

```
h.getpos()
```

返回当前的行号和该行中的字符偏移量，格式为元组 `(line, offset)`。

```
h.get_starttag_text(tag)
```

返回最近打开的标签对应的文本。

```
h.handle_charref(name)
```

当遇到如 `'&#ref;'` 的字符引用时，会调用此处理器。`name` 是包含引用名称的字符串。例如，在解析 `'&#229;'` 时，`name` 将设置为 `'229'`。

```
h.handle_comment(data)
```

当遇到注释时，调用此处理器。`data` 是包含注释文本的字符串。例如，在解析注释 `'<!--comment-->'` 时，`data` 将包含文本 `'comment'`。

```
h.handle_data(data)
```

调用此处理器以处理出现在标签之间的数据。`data` 是包含文本的字符串。

```
h.handle_decl(decl)
```

调用此处理器以处理如 `'<!DOCTYPE HTML...>'` 的声明。`decl` 是包含声明文本的字符串，不包括开头的 `<!` 和结尾的 `>`。

```
h.handle_endtag(tag)
```

每当遇到结束标签时，都会调用此处理程序。`tag` 是转换为小写的标签名。例如，如果标签为 `'</BODY>'`，则 `tag` 为字符串 `'body'`。

```
h.handle_entityref(name)
```

调用此处理程序来处理实体引用，如 `&name;`。`name` 是包含引用名称的字符串。例如，如果解析 `&lt;`，`name` 将设置为 `'lt'`。

```
h.handle_pi(data)
```

调用此处理程序来处理处理指令，如 `?processing instruction>;`。`data` 是一个包含处理指令文本的字符串，包括开头的 `?` 或结尾的 `!`。当对 XHTML 风格的 `?...?` 指令进行调用时，最后一个 `?` 将包含在 `data` 中。

```
h.handle_starttag(tag, attrs)
```

此处理程序处理 XHTML 风格的空标签，如 `<tag name="value">.../>`。`tag` 是一个包含标签名称的字符串，`attrs` 是一个列表，其中 `name` 是转换为小写的属性名，`value` 是属性值。在提取值时，引号和实体会被替换。例如，如果解析 `href='http://www.foo.com/'`，`tag` 为 `'a'`，`attrs` 为 `{'href', 'http://www.foo.com/'}]`。如果在类中未定义，此方法的默认实现会调用 `starttag()` 和 `handle_endtag()`。

```
h.handle_starttag(tag, attrs)
```

此处理程序处理起始标签 `<tag name="value">..>`。`tag` 和 `attrs` 的含义与 `handle_starttag()` 中的 `tags` 相同。

```
h.reset()
```

重置解析器，丢弃任何未处理的数据。提供以下异常：

```
HTMLParserError
```

由于解析错误而引发的异常。该异常有三个属性：`msg` 属性包含描述错误的消息，`lineno` 属性是错误发生的行号，`offset` 属性是该行中的字符位置。

## 示例

以下示例使用 `urllib` 包获取一个 HTML 文档，并打印用 `<a href="......">` 指定的链接：

```python
# printlinks.py
try:
    from HTMLParser import HTMLParser
    from urllib import urlopen
except ImportError:
    from html.parser import HTMLParser
```

```python
from urllib.request import urlopen
import sys

class PrintLinks(HTMLParser):
    def handle_starttag(self, tag, attrs):
        if tag == 'a':
            for name, value in attrs:
                if name == 'href':
                    print(value)

p = PrintLinks()
u = urlopen(sys.argv[1])
data = u.read()
charset = u.info().getparam('charset') # Python 2
#charset = u.info().get_content_charset() # Python 3
p.feed(data.decode(charset))
p.close()
```

在示例中，必须注意使用 `urllib` 获取的任何 HTML 文档都以字符串形式返回。为了对其进行解析，必须根据文档字符集编码将其解码为文本。示例展示了如何在 Python 2 和 Python 3 中实现这一点。

### 注意

`HTMLParser` 的解析能力往往相当有限。事实上，对于非常复杂或格式不正确的 HTML，解析器可能会崩溃。用户还会发现该模块的层次较低，实用性一般。如果你正在编写必须从 HTML 页面爬取数据的程序，请考虑 Beautiful Soup 软件包 (`http://pypi.python.org/pypi/BeautifulSoup`)。

# json

`json` 模块用于序列化和反序列化使用 JavaScript 对象表示（JSON）表示的对象。关于 JSON 的更多信息可以访问 `http://json.org`，但该格式实际上 JavaScript 语法的子集。顺便说，它与 Python 表示列表和字典的语法几乎相同。例如，JSON 数组写为 `[value1, value2, ...]`，JSON 对象写为 `{name:value, name:value, ...}`。
