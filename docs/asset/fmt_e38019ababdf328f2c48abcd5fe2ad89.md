基于 Web 的 IMAP 邮件程序。一组实现基于 IMAP 的网络邮箱系统的 PHP3 脚本。假设你在支持 IMAP 的服务器上有一个账户，理论上你可以在任何可以访问的地方通过安装的 IMAP 检查你的邮件。IMAP 并不要求在你安装它的机器上运行 IMAP 服务器，除非你打算将当前机器用于其 IMAP 连接。如果你是连接到远程服务器，则不需要 IMAP。如果你想使用地址簿、偏好等扩展功能，IMAP 需要一个数据库。它目前使用 PHPlib 作为数据库接口，只要 PHPlib 支持你选择的数据库。此包设计用于支持 PostgreSQL 和 MySQL 连接。来自 Debian 3.0r APT

# impress

无需浏览器的所见即所得（WYSIWYG）出版与演示。Impress 是一个为 Linux 设计的视化布局程序。它允许你使用完全缩放的图形创建演示文稿和 Postscript文档，类似于 Macromedia Freehand、Corel、Adobe Illustrator 等程序。它与 Gimp、Adobe Photoshop 和 J's PaintShop Pro 等位图图形包不同，因为它具有可以在画布上操作的图形对象，而不仅仅是油漆层。更多信息请访问：http://www.nlug.org/~ccox/impress/index.html

来自 Debian 3.0r0 APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index
