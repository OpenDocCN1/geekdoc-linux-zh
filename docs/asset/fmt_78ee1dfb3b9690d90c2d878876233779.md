# 大小转换

`bash` 提供了四种参数扩展和两个 `declare` 命令选项来支持字符串的大写/小写转换。

那么，大小转换有什么用？除了显而易见的审美价值外，它在编程中也起着重要作用。让我们考虑数据库查询的情况。假设用户在输入框中输入了一个字符串，我们要在数据库中查找该字符串。用户可能会输入全大写、全小写或两者的组合。我们显然不希望在数据库中填充所有可能的大写和小写拼写组合。该怎么办？

解决此问题的常用方法是对用户输入进行归一化。也就是说，在尝试数据库查询之前，将其转换为标准形式。我们可以通过将用户输入中的所有字符转换为小写或大写来实现，并确保数据库条目也同样归一化。

`declare` 命令可将字符串归一化为大写或小写。使用 `declare`，我们可以强制变量无论赋值了什么值，始终包含期望的格式。

```bash
#!/bin/bash

# ul-declare: 通过 declare 演示大小转换

declare -u upper

declare -l lower

if [[ $1 ]]; then

  upper="$1"

  lower="$1"

  echo "$upper"

  echo "$lower"

fi
```

在前面的脚本中，我们使用 `declare` 创建了两个变量 `upper` 和 `lower`。我们将第一个命令行参数（位置参数 1）的值赋值给每个变量并将其显示在屏幕上。

```bash
@linuxbox$ ul-declare aBbc

ABC

abc
```

如所见，命令行参数 `aBc` 已经过归一化。除了 `declare` 之外，还有四种参数扩展可以执行大/小写转换，如表 34-1 所示。

## 表 34-1：大小转换参数扩展

| 格式 | 结果 |
| --- | --- |
| `$(parameter,,pattern)` | 将 *parameter* 的值扩展为全小写。*pattern* 是可选的 shell 模式，将限制哪些字符（例如 `[A-F]`）会被转换。有关模式的完整描述请参阅 man page |
| `$(parameter,pattern)` | 扩展 *parameter* 的值，仅将第一个字符改为小写。 |
| `$(parameter^^pattern)` | 将 *parameter* 的值扩展为全大写字母。 |
| `$(parameter^pattern)` | 扩展 *parameter* 的值，仅将第一个字符改为大写（大化）。 |

以下是一个演示这些扩展的脚本：

```bash
#!/bin/bash

# ul-param: 通过参数扩展演示大小转换

if [[ "$1" ]]; then

  echo "${1,,}"

  echo "${1,}"

  echo "${1^^}"

  echo "${1^}"

fi
```

以下是脚本的运行情况：

```bash
[me@1nuxbox~$ ul-param aBc]

abc

aBc

ABC

abC
```

我们再次处理第一个命令行参数并输出参数扩展支持的四种变体。虽然此脚本使用了第一个位置参数，但参数可以是任何字符串、变量或字符串表达式。

## 位运算 (Bit Operations)

有一类运算符以一种特殊的方式处理数字。这些运算符在位级别上工作。它们被用于某些低级任务，通常涉及设置或读取位标志（bit flags）（详见表 34-5）。

### 表 34-5：位运算符

| 运算符 | 描述 (Description) |
| --- | --- |
| ~ | 按位取反。反转数字中的所有位。 |

| & | 按位与。对两个数字的所有位执行 AND 运算。 |
| | | 按位或。对两个数字的所有位执行 OR 运算。 |
| ^ | 按位异或。对两个数字的所有位执行异或（exclusive OR）运算。 |
