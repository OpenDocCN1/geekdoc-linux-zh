
# 从底层开始编程 [x86 汇编,Linux,GFDL]

此书不是一本参考书，而是一本入门书。因此，它本身并不适合学习如何进行专业的 x86 汇编语言编程，因为为了让学习过程更加顺畅，书中省略了一些细节。本书的目的是帮助学生理解汇编语言和计算机编程的工作原理，而不是作为该主题的参考。关于特定处理器的参考信息可以通过联系制造它的公司获得。

如需获取本书的电子版，请访问网站：

`http://savannah.nongu.org/projects/pgubook/` 该网站包含了根据 GNU 自由文档许可证定义的下载本书透明副本的说明。

# 第1章 引言

## 欢迎编程

我热爱编程。我享受不仅是写出一个运行良好的程序，而且要写得有格调。编程就像诗歌。它传递信息，不仅给计算机，还给那些修改和使用你程序的人。通过程序，你根据自己的规则构建了自己的世界。你根据自己对问题和解决方案的理解来创造你的世界。高明的程序员用程序创造出清晰、简洁的世界，就像诗歌或散文一样。

最伟大的程序员之一唐纳德·高纳（Donald Knuth）将编程描述为不是告诉计算机如何做什么，而是告诉人他们应该如何指示计算机去做某事。关键点在于，程序是给人读的，而不仅仅是计算机读。在你转向其他项目很久之后，你的程序仍会被他人修改和更新。因此，编程与其说是与计算机交流，不如说是与后继者交流。程序员既是问题解决者，又是诗人，还是指令员。你的目标是解决眼下的问题，在保持平衡和品味的同时完成，并将你的解决方案教给未来的程序员。我希望这本书至少能教你一些“诗意”，并让计算变得令人兴奋。

大多数编程入门书都让我感到无比沮丧。读完它们后，你仍然会问“计算机到底是如何工作的？”，却得不到答案。它们往往倾向于跳过那些困难但很重要的话题。我会带你通过这些困难的问题，因为通通精精编程的唯一途径。我的目标是带你从对编程一无所知到理解如何像程序员一样思考、编写和学习。你不会知道一切，但你将拥有万物如何关联的背景知识。在书结束时，你应该能够做到：

- 理解程序如何工作以及如何与其他程序相互作用
- 阅读他人的程序并学习它们是如何工作的
- 快速学习新的编程语言
- 快速学习计算机科学中的高级概念

我不会教你一切。计算机科学是一个巨大的领域，尤其是当你将理论与计算机编程实践相结合时。然而，我会尝试让你打好基础，以便你之后可以轻松地去你想去的任何地方。

教学编程（尤其是汇编语言）存在某种“鸡生蛋蛋的问题的问题。要学的东西很多——几乎多到无法一次性学完，但每一部分都依赖其他所有部分。因此，在学习编程时，你必须对自己和计算机保持耐心。如果你第一次没懂，请重读。如果你还是不懂，有时最好的办法是先相信它，以后回来。通常在接触更多编程后，这些想法会变得更有意义。不要气馁。这是一段漫长的攀登，但值得的。

每个章节末尾都有三组复习题。第一组很大程度上是背诵——它们检查你是否能复述本章学到的内容。第二组包含应用题——它们检查你是否能应用所学知识来解决问题。最后一组是看你是否有能力拓宽眼界。有些问题在书的后面可能没有答案，但它们给了你一些思考的方向。另一些问题需要你查找外部资源来发现答案。还有一些问题要求你只需分析选项并解释最佳解决方案。许多问题没有对错之分，但这并不意味着它们不重要。学习编程中涉及的问题、学习如何寻找答案以及学习如何前瞻性思考都是程序员工作的重要组成部分。

如果你有无法解决的问题，这本书有一个邮件列表，读者可以在那里进行讨论并就他们阅读的内容寻求帮助。地址是 `pgubook-readers@nongnu.org`。该邮件列表向任何类型的问题或关于本书的此类讨论开放。你可以通过访问 `http://mail.nongnu.org/mailman/listinfo/pgubook-readers` 订阅此列表。

# 你的工具

本书教授针对 `x86` 处理器和 `GNU/Linux` 操作系统的汇编语言。因此，我们提供的所有示例都将使用 `GNU/Linux` 标准 `GCC` 工具集。如果你不熟悉 `GNU/Linux` 和 `GCC` 工具集，稍后将对它们进行描述。如果你是 Linux 新手，你应该查看位于 `http://tute.sourceforge.net/` 的指南。我打算向你展示更多的是关于如何在特定平台上使用特定工具集进行通用编程，但将其中一种标准化会让任务变得容易得多。

那些 Linux 新手应该尝试加入他们当地的 `GNU/Linux` 用户组。小组成员对新手来说非常有帮助，他们会帮助你从安装 Linux 到学习如何高效地使用它的方方面。

`Linux`/`Linux` 组可以在 `http://www.linux.org/groups/` 找到。小组成员对新手来说非常有帮助，他们会帮助你从安装 Linux 到学习如何高效地使用它的方方面。

通过“`GNU/Linux` 发行版”，指的是 `x86` `Linux` 机器的。内核负责处理。你只需要知道如何使用像 `pico`、`emacs` 或 `vi` 这样的编辑器。
