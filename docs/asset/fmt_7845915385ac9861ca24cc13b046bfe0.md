### ~user

在 Unix 上，可以使用波浪号（`~`）后跟登录名来引用主目录。例如，在我的电脑上运行 `ls ~rob` 将列出 `~home/rob` 中的所有文件。关键点：Web 服务器通常允许通过这种方式访问用户目录。例如是 http://www.robertraham.com/~rob。关键点：互联网上的一个巨大漏洞是人们会无意中地泄露信息。例如，`.bash_history` 文件是用户目录中的一个隐藏文件，包含了他们输入到 shell 中的所有命令的完整文本（假设他们的 shell 是 bash，这是 Linux 上最流行的 shell）。来自 Hacking–Lexicon

### a2ps

GNU `a2ps`“任何内容到 PostScript”转换器和打印机——`a2ps` 将文件转换为 PostScript 用于打印或查看。它使用很好的默认设置，通常每个物理页面显示两页，周围页边带有有用信息（页码、打印日期、文件或名称标题）、行符号替换，以及针对多种编程语言的漂亮打印。从历史上看，`a2ps` 起初是一个文本到 PostScript 的转换器，但令人惊喜的是，它能够处理任何类型的文件，它可以处理手册、dvi 文件、textinfo 等……`a2ps` 最显著的特征包括：

- 各种编码（所有拉丁字母）
- 各种字体（原子字体下载），
- 各种媒体，
- 各种打印机接口，
- 各种输出样式，
- 各种编程语言，
- 各种辅助应用程序，
- 各种语言。来自 Debian 3.0r0 A2ps

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
