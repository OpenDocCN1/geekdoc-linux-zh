# 间层化合物

晶体或聚合物晶体由主体层组成，其中嵌入了客体分子以容纳主体。该结构的特征是沿着（0到3）方向晶格强度较高，且键不受间层反应的影响。各向异性三维晶格（包括许多氧化物和沸石）包含大型的多重客体通道。层型二维晶格（石墨和粘土）在嵌入客体分子时会膨胀。主体层通常是可逆间层主体，其中乙炔在间层反应中绕其轴发生协同反应，形成由客体原子产生的化合物。基于客体的（往返和多维）间层家族包括60碳纳米管的间层，其水簇之间具有强烈的内部结合。这些簇表现得类氢分子，提供了足够的空间来容纳主要客体的其他成员。在许多材料中，客体原子的性质可能会变化，它们并非真正的化合物。

间层化合物的应用来自于间层反应的结果。最为人知的例子是水。硅酸盐片之间的水间层形成了湿粘土，而在干燥过程中排出水分则产生一种耐用的材料。某些间层化合物是离子导体，因此被用于充电电池电解质锂离子燃料电池。电池的工作原理是电极充电放电时两层电极之间的间层作用：钒（三维）和石墨（二维）。沸石含有金属原子，具有足够大的孔隙以……

## 波的干涉

每当两个频率或波长相同的波组合时，就会形成一个振幅等于干涉波振幅之和的波。干涉波可以是电磁波、声波、水波或任何物理方向的波。

干涉最显著的特征是同相波和反相波之间的区别。如果两幅波是反相的，它们可以相互抵消，产生的振幅为零。这最接近于相消干涉（`destructive interference`）。

在相长干涉（`constructive interference`）中，波产生的振幅远大于源中的任意一个。在这种情况下，无法通过相反抵消来消除噪声。
