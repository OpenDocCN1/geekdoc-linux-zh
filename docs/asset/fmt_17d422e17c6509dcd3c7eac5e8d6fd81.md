# 使用 GUI 配置无线网卡

在之前以太网接口的图形化设置期间，可以使用所示的 GUI 配置远程系统网卡。在这种情况下，不要选择“有线”选项卡，而在网络连接交换框中选择“无线”选项卡。

从此选项卡选择“添加”按钮，这将显示标题为“更改无线关联 1”的交换框（假设这是主远程连接）。

此对话框有四个选项卡，用于启用远程网卡的设置。此对话框包含用于配置框架远程网卡的各种设置。

## 关联名称

关联名称设置默认为“远程关联”，后是正在配置的连接数量，在此情况下为无线关联。

- 此名称可以更改为更有意义的内容，例如客户远程关联。

## 自动关联复选框

当勾选“自动关联”复选框时，系统将在 PC 启动且无需客户端介入的情况下尝试连接远程系统。如之前描述 DHCP 所示，这对于大多数 Linux 客户端可能很有帮助。但对于渗透分析来说，这通常不是最佳选择。如果不勾选此复选框，系统将在 PC 启动时不会尝试连接远程系统。

## 服务集标识

服务集标识（SSID）是用于识别远程系统的名称。与 SSID 不同，每个通道将有一个唯一的 BSSID。

## get MAC 地址

`get`设备 MAC 地址字段用于将此配置绑定到远程连接器。这在 PC 有多个远程连接器时非常有用。下拉列表将填充远程连接器的 MAC 地址。为您的连接器选择正确的 MAC 地址。

## 密码和密钥

如果在掉落时选择了 WEP 或 WPA 个人模式作为安全技术，请在密文/密钥字段中输入安全密钥。勾选“显示密码/密钥”复选框以确认所使用的密钥已正确输入。在不需要显示密码的情况下，请保持未勾选复选框。某些框架使用密码或密钥转换策略。如果是，请通过选择正确的列表为每个列表输入密码或密钥，然后为该文件输入正确的密钥或安全密钥。

系统可能具有开放系统框架或共享密钥验证。在共享密钥验证中，路由器会向尝试连接的 PC 发送测试即时消息。连接的 PC 随后使用 WEP 密钥对内容进行加密，并将编码内容返回给路由器。

如果连接 PC 使用的加密密钥提供了正确的加密字符串，路由器随后将允许连接。开放框架验证同样允许 PC 在没有此测试和响应安排的情况下进行连接，这取决于 PC 使用了正确的 SSID。在这两种情况下，当使用 WEP 密钥验证通道时，通信通道即完成。虽然共享密钥验证看起来更安全，但实际上更不安全，因为测试消息和编码内容响应是以明文发送的，允许任何监控远程通道的人截获测试和响应。由于 WEP 密钥被用于加密测试，截获测试和响应可以导致 WEP 密钥被破解。

## Web 服务器

Kali Linux 包含一个易于设置的 Apache Web 服务器。拥有一个可以有效配置的 Web 服务器对于入口点分析师来说是一个巨大的优势。例如，利用此管理功能，可以创建复制互联网上现有页面的网站。这些目标网站随后可以被用于向目标系统上的客户端投放恶意代码。它们将利用社交工程策略，如钓鱼，包括组装促进辅助通道的收集服务器、处理回调以及提供指向恶意程序的指令。HTTP 管理功能在入口测试中有许多不同的用途。

### 使用 GUI 启动、停止或重启 Apache 服务器

使用 GUI 是启动、停止或重启/重置 Web 管理最简单的方法。要执行此操作，从 Kali 屏幕顶部栏中选择“应用程序”(`Applications`)。从下拉菜单选择 Kali Linux，这将显示一个子菜单。从该菜单选择“系统管理”(`System Administrations`)，这将显示另一个菜单；在弹出菜单上选择“HTTP”选项。这将显示启动、停止和重启 Apache 管理的选项。

当使用菜单选择一个选项时，一个指令 shell 将启动并显示服务器的状况。当 Apache 服务器启动或重启时，将显示 Kali Linux 的默认设置。

你可能会看到错误，“Couldn't reliably decide the server's fully qualified domain name, using 127.0.0.1 for ServerName。”此错误目前不会引起任何问题，因为 Web 服务器将根据框架的 IP 地址在系统上可访问。要解决此错误，修改 `/etc/apache2/` 中的 `apache2.conf` 记录，在文档末尾的 ServerName 之后添加要使用的服务器名称，然后按如下操作保存记录。

`ServerName localhost`

当 Apache 服务器启动或重启后，可以通过在浏览器中输入 PC 的 IP 地址来访问默认站点。Kali Linux 发行版包含了 IceWeasel 浏览器，可以通过点击顶部栏上的 IceWeasel 图标（一个被白色鼬包围的蓝色地球仪）来访问。

### 在命令提示符中启动、停止和重启 Apache

可以使用命令 `/etc/init.d/apache2` 加上上述操作（`stop`, `start`, 或 `restart`）来有效地启动、停止和重启 Apache HTTP 服务器。使用命令行带来的效果与 GUI 相同。

```
/etc/init.d/apache2 start
```

```
/etc/init.d/apache2 stop
```

```
/etc/init.d/apache2 restart
```
