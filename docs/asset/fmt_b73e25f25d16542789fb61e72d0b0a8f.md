
# 椰子纤维

一种天然纤维，也称为椰壳纤维，是从椰子（*Cocos nucifera*）的果壳中获得的。椰子纤维最突出的特性是其抗腐烂能力。例如，椰子纤维门垫可以在户外风吹雨打多年。椰子纤维在植物纤维中的强度处于中等水平，但其断裂伸长率大于任何韧皮纤维或硬质纤维。超过95%的椰子纤维出口来自斯里兰卡和印度；泰国、坦桑尼亚、墨西哥、菲律宾、马来西亚、肯尼亚和特立尼达和多巴哥也有少量出口。

椰子纤维主要有三种类型——纱线纤维、刷丝纤维和床垫纤维。只有最细和最长的纤维适合纺成纱线。它从未成熟果实的果壳中获得，是主要的经济作物而非副产品。刷丝纤维和大部分床垫纤维来自成熟果实，是椰仁生产的副产品。椰子纤维的颜色从浅黄褐色到深棕色不等。刷丝根据长度分类，并根据长度、硬度、颜色和清洁度分级。对于任何用途，长而干净的纤维和浅色都是可取的，硬度对于刷丝是可取的，但对于纱线则是不利的。

在发达国家，纱线纤维主要用于垫子；例如，在美国，其最著名的用途是浅棕色簇绒门垫。在亚洲，它广泛用于绳索和细绳，并在当地用于手工制作的袋子。刷丝纤维的主要用途一直是制刷，但市场已经萎缩，现在大多数刷丝纤维用于软垫填充。床垫纤维主要用于弹簧床垫，尽管它也被用作绝缘材料。参见：椰子；天然纤维。 [E.G.N.]

# 焦炭

由炼焦煤干馏（破坏性蒸馏）后留下的连贯、多孔、碳质残渣。它主要以碳为主要成分，并含有矿物质和残留挥发分。从非炼焦煤，如次烟煤、泥煤或无烟煤碳化获得的残渣通常称为木炭。焦炭主要在化学回收焦炉中生产，但也有一小部分在非回收的蜂窝形或其他类型的焦炉中生产。焦炭主要用作高炉中的燃料还原剂，同时它也用于支撑炉料。

## 作为冶金作业的燃料

作为冶金作业的燃料，焦炭提供铁矿石还原所需的热量以及气体。它还用于其他还原工艺、铸造冲天炉和家庭供暖。

煤在隔绝空气的条件下加热时形成焦炭。在 660–930°F (350–500°C) 的温度范围内加热时，煤软化并融合成固体块。加热过程中达到的软化程度在很大程度上决定了所产生焦炭的特性。为了生产具有预期特性的焦炭，在装入焦炉之前，会将两种或更多种类的煤进行混合。除了混合煤的类型外，焦炉内的炭化条件也会影响所产生焦炭的特性。炉温是其中最重要的因素，并对焦炭的尺寸和强度产生显著影响。一般而言，对于给定的煤种，随着炭化温度的降低，焦炭的尺寸和抗碎强度会增加。

在冶金作业中，人们关心的焦炭重要特性包括其化学成分（如水分、挥发分、灰分和硫含量）以及物理特性（如尺寸、强度和密度）。水分和挥发分含量是炉操作方式和冷却方式的函数，而灰分和硫含量则取决于装入煤的组成。参见**木炭**；**煤**；**干馏**。

# 焦化（石油）

在石油工业中，将原油中不可蒸馏的馏分（残渣）转化为低沸点产物和焦炭的工艺。由于存在使催化剂中毒的金属和氮组分，焦化常被优先于催化裂化使用。参见**裂化**。

焦化装置的液体产物，经过市售加氢脱硫技术的净化后，可以提供大量低硫液体燃料（硫含量低于 0.2 wt%）。该工艺的另一个主要应用是将重质低价值原油升级为较轻的产物。

石油焦主要用作燃料，或在煅烧后用于碳电极。产生焦炭的原料控制了焦炭的特性，尤其是硫、氮和金属含量。浓缩效应倾向于将大部分硫、氮和金属沉积在焦炭中。硫含量超过约 2.5% 且钒含量超过 200 ppm 的焦炭主要用作；在环境法规允许的情况下，用作燃料或燃料添加剂。非燃料用途的焦炭特性包括低硫、低金属、低灰分以及可定义物理结构。参见**石油产品**。

# 可乐果

一种树木，*Cola acuminata*，属于玉蕊科（Sterculiaceae），原产于热带非洲。其果实为星状荚果，内含八粒硬种子，即商品可乐果。这些坚果是热带非洲许多地区重要的咀嚼物。其咖啡因含量是咖啡的两倍。坚果还含有精油和一种苷类物质——可乐豆苷（kolanin），这是一种心脏兴奋剂。可乐果与可可提取物结合，用于制造饮料**可口可乐**。如今，可乐果在安哥拉、牙买加、巴西、印度和热带亚洲其他地区都有种植。参见**古柯**；**Malales**。

# 秋水仙素

从秋水仙（*Colchicum autumnale*，又称秋季番红花）的种子荚、球茎和鳞茎中提取的主要生物碱。自中世纪以来，人们就知道使用秋水仙植物来缓解痛风疼痛，尽管秋水仙素是一种毒性极强的物质，它仍然是治疗痛风的标准药物。秋水仙素的一个重要特性是它能在细胞分裂发生前中断有丝分裂周期。这种效应导致多倍体细胞的形成，这对植物育种具有价值。参见**生物碱**；**百合科**；**有丝分裂**；**多倍体**。

# 耐寒性（植物）

温带地区植物在零度以下温度下存活的能力。这一特性是决定本地植物物种地理分布以及许多重要农学和园艺作物种植北界的主要因素。此外，霜冻伤害是导致作物损失的主要原因，表现为早秋霜冻、深冬低温或晚春霜冻。在全球不同地区，耐寒性问题都是农民关注的问题。因此，开发具有改进耐寒性的栽培植物品种一直是长期关注的问题。

在植物界中，低温耐受性存在广泛多样性——从土豆等草本植物较低的耐寒水平，到小麦和黑麦等冬一年生植物中等的耐寒水平，再到像黑刺槐、红雪松和山茱萸等耐寒落叶乔木和灌木，后者可以承受液氮温度。在给定物种内，耐寒性的范围可以相当大。在特定植物体内，不同组织和器官的耐寒性也存在广泛差异。例如，根对零度以下温度的耐受性远低于嫩枝；花芽比叶芽更敏感。

给定物种的耐寒性是一种固有的遗传性状，需要特定的环境信号才能表达。随着秋季日照缩短和夜间气温降低，温带植物进入休眠状态并增强其耐寒性。这个过程被称为**冷驯化**。在春季，日照延长和气温升高导致植物恢复生长和发育，并相应地降低耐寒性。耐寒性可能受辐射、温度、光周期、降水和植物发育阶段的影响，不同物种、品种或种内生态型具有不同的最适条件。各种环境信号用于协调植物发育与环境。这种协调经过数百年演化而来，栽培物种中任何打破这种协调的因素都可能导致霜冻伤害。

温度是提高植物耐冻能力的关键环境参数。低温（高于冰点）有助于秋季耐寒性的增加，而温暖气温则是春季耐寒性降低的原因。通常认为，大多数植物在气温逐渐降至 50°F (10°C) 以下时进行驯化。然而，在驯化过程中，气温的逐步下降极其重要。耐寒性的形成可能需要 4 到 6 周。

光周期是影响冷驯化的第二个主要因素，但这仅适用于那些在生长停止或休眠诱导（真正的生理休息期）方面对光周期有响应的物种。在其他物种中，光仅在提供冷驯化过程所需的光合储备方面重要。在某些情况下（例如，萌发的种子），已经存在足够的能量储备，驯化可以在黑暗中进行。参见**光周期现象**。

# 科尔曼石

硼酸盐矿物组中较为常见的一种矿物（一种羟基水合钙硼酸盐，化学式为Ca[BO₃(OH)₄(H₂O)₄]（Ca = 钙，B = 硼，O = 氧，OH = 羟基，H₂O = 水））。

科尔曼石呈白色至灰色，条痕为白色，透明至半透明，具有玻璃光泽。它以短而高度改形的棱柱状晶体形式出现，或以块状或粒状集合体的形式出现。它在一个方向上具有完全解理，平行于其晶格的片状结构。科尔曼石在莫氏硬度标度上的硬度为4–4.5，比重为2.42。参见[硬度标度](HARDNESS SCALES)。

科尔曼石通常出现在第三纪的湖泊蒸发岩沉积物中。它由初级硼酸盐矿物（如土莱石，NaCa[BO₃(OH)₄(H₂O)₃]（Na = 钠））通过热成岩作用形成。参见[硼砂矿物](BORAX MINERALS)；[成岩作用](DIAGENESIS)；[盐湖](SALT LAKES)。

科尔曼石是硼的主要来源之一，与硼砂和土莱石一起，在加利福尼亚州、内华达州、土耳其和阿根廷被大量开采。硼被广泛用于各种工业产品：肥皂和洗衣粉、玻璃和陶瓷、特种合金，以及许多产品中的填料。参见[硼](BORON)。

# 头足纲

头足纲的一个亚纲，出现在古生代中期（早泥盆世），据信是从菊石类演化而来。在五个化石头足类目中，箭石类因其化石外壳（被称为“闪电箭”）而引人注目。所有这类形式都在中生代末期，即6500万年前灭绝了。在白垩纪晚期到侏罗纪晚期演化出的现存四个目代表了今天所有现生的头足类动物，除了鹦鹉螺（亚纲Nautiloidea）。

头足类的特征包括：内部由几丁质或钙质构成的外壳；口周有8–10个附肢（当存在8个腕和2个触腕时，其内侧布满吸盘或钩爪）；一对鳃；高度发达的眼睛；融合成的管状漏斗；墨囊（在某些物种中消失）；色素细胞；以及身体上的鳍（在某些章鱼中消失）。

现生的头足类包括：

- 目Sepioida（乌贼，如*Sepia*；短尾鱿鱼，*Spirula*）

- 目Teuthioida（鱿鱼——近海的小型鱿鱼，如*Loligo*；远洋的大型鱿鱼，如*Ommastrephus*）

- 目Vampyromorphoidea（黑色的深海吸血鬼鱿鱼）

- 目Octopoda（章鱼、纸鸟章鱼、深海贝足章鱼，或卷腕章鱼）
