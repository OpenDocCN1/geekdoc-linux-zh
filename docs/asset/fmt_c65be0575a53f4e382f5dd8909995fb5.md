
动物和人类应该进行经济设计这一观念源于常识，但也得到了许多观察结果的支持。血管结构确保血液流动分布具有最小的能量损失。骨骼结构根据应力分布呈图案化排列，并在定量上适应总应力。通过训练，运动员可以具体调整其肌肉和心血管系统的结构以适应更高的功能需求，而当训练停止时，这些修改很快会逆转。

超适应结构理论假设结构设计对功能容量进行了理想适应。然而，这几乎是一个不合理的假设，因为复杂系统的优秀工程设计需要一定的冗余度作为安全系数，以应对功能性能的不完善和变化的边界条件。通过使用超适应结构的概念，可以检测到这种偏离理想化经济设计的现象。[E.R.W.]

# 交感神经系统

自主神经系统中负责非自主性操作有机体以应对紧急情况的组成部分。参见[自主神经系统](https://example.org/autonomic_nervous_system)。

交感神经系统在哺乳动物中理解得最为透彻。它由两条神经元链组成，从脊髓的胸椎和腰椎区域延伸到内脏和血管。第一神经元或节前神经元的胞体位于脊髓，并发送其轴突与节后交感神经元形成突触，该节后交感神经元位于平行于脊髓的交感神经节链中，或位于滋养消化道内脏的大型血管基部的交感神经节中。节后轴突比节前轴突长，并延伸到内脏或血管的腺体或平滑肌。感觉内脏神经纤维支配血管和内脏，并将感觉信息传递到脊髓，从而提供内脏反射（见插图）。参见[神经系统（脊椎动物）](https://example.org/nervous_system_vertebrate)；[副交感神经系统](https://example.org/parasympathetic_nervous_system)。 [D.B.W.]

# 共鸣振动

由以相同频率振动的邻近系统提供的能量，使机械或声学系统在其共振频率上发生驱动。例子包括由扬声器发出的声音引起的墙板振动，随着电机速度增加机器部件在特定频率下的振动，以及使用音叉下的调谐空气共振器来增强木琴的声学输出。增加振动系统的阻尼会减小其共鸣振动的振幅，但同时也扩大其参与共鸣振动的频率带宽。参见[共振（声学 и 机械学）](https://example.org/resonance_acoustics_and_mechanics)；[振动](https://example.org/vibration)。 [I.E.K]

# 原肢纲

多足动物亚门中的一个纲。原肢动物与盲蛛目类似，是微小的、淡色的、类似蜈蚣的生物，栖息于潮湿的土壤或在碎片下生活；一般来说，它们生活在任何有足够水分以防止水分过度损失的地方。它们在原始触角型和同形型方面与盲蛛目和倍足纲相似。它们每个大颚，像多足动物的一样，都有一个可动的齿瓣；同时，它们的两对颚足比单一颚足的多足动物和盲蛛目更让人想起有颚类和低等昆虫。

该纲包括三个科，被归入其中的物种不超过 60 种。[I.E.G]

# 合弓纲

一个已灭绝的爬行纲亚类，通常特征在于位于眶后骨和鳞骨连接处下方的颞孔，即所谓的下颞孔。然而，在高级形式中，眶后-鳞骨桥缺失。哺乳动物在三叠纪时期从这组爬行动物中进化而来。参见[爬行纲](https://example.org/reptilia)。

合弓纲最早出现在地质记录中的晚石炭世。它们在晚古生代和早中生代繁盛，但在三叠纪末期左右灭绝。在这段时间内，它们在陆地上经历了广泛的适应性辐射，并对水生栖息地进行了小规模的入侵。这次辐射有两个主要阶段：一个是早期的由似哺乳爬行动物（Pelycosaurs）完成的，另一个是后期的（晚二叠世和三叠纪）由合弓目（Therapsids）完成的。参见[盘龙目](https://example.org/pelicosauria)；[爬行纲](https://example.org/reptilia)；[合弓目](https://example.org/therapsida)。 [J.C.O]

# 突触传递

一个神经细胞（神经元）通过与其功能耦合的解剖学相邻神经元相互影响其活动的生理机制。大脑功能依赖于神经细胞彼此之间以及它们所支配的腺细胞和肌细胞之间的相互作用。这些相互作用发生在细胞之间被称为突触的特定接触部位。突触是神经系统中最小且最基本的信息处理单位。通过神经元之间不同的突触连接模式，在发育过程中构建了突触回路，以执行神经系统的不同功能操作。参见[神经元](https://example.org/neuron)。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_2190_0.png)

**突触类型。** (a) 电突触，显示突触前和突触后细胞的质膜通过缝隙连接相连。(b) 化学突触，显示由突触前细胞释放的神经递质扩散穿过突触间隙并结合到突触后膜上的受体。

最简单的突触类型是电突触（见插图），它由两个细胞之间异常紧密的接触区域组成，该区域充满了跨越两个膜及其之间间隙的通道。电突触也称为缝隙连接。两个细胞之间的电学和代谢通信是通过缝隙连接组分建立的。包括钙离子、pH 值、膜电位、神经递质和磷酸化酶在内的一系列影响因素，可能作用于通道以调节其在一个方向（整流）或两个方向的电导。

电突触存在于整个动物界。在脊椎动物中，它们在鱼类的中枢神经系统以及哺乳动物大脑的某些神经核团中数量众多，在这些区域快速传递和活动同步化至关重要。电突触也在大脑中互连胶质细胞。参见[生物电突触和离子电流](https://example.org/bioelectrical_synaptics_and_ionic_currents)；[细胞膜通透性](https://example.org/cell_membrane_permeability)。

神经细胞之间最普遍的突触类型是化学突触（见插图）。在化学突触处，神经递质从突触前细胞释放，扩散穿过突触间隙，并结合到突触后细胞上的受体。化学突触仅存在于神经细胞之间，或神经细胞与其所支配的腺细胞和肌细胞之间。神经肌肉接头，即运动神经元的轴突末梢与肌纤维之间的接头，是一种原型的化学突触。该突触由三个基本要素组成：含有突触小泡的突触前结构（在这种情况下，是运动神经元轴突末梢），终板（细胞间特化的接触部位）；以及突触后细胞。

# Synbranchiformes（弓鳍鱼目）

一个鳗形鱼类目，与真正的鳗鱼不同，其上前颌骨以独立的骨骼形式存在。小型的口裂在胸部常相互融合。鳃发育不良，在某些物种中，部分呼吸通过高度血管化的口咽囊完成。没有鳍棘或胸鳍，若中鳍发育，则是连续的。若存在腹鳍，则很小且位于喉部。身体可能裸露或有鳞片。没有鱼鳔。该群体没有化石记录，被分为 2 亚目、3 科、7 属和 12 种。这些蛇形鱼类栖息于热带美洲、澳大利亚、亚洲东部和东南部、东印度群岛以及热带非洲的沼泽、洞穴以及流速缓慢的淡水和咸淡水中。参见 **ACTINOPTERYGII（辐鳍鱼类）**。

# Synchrotron radiation（同步辐射）

相对论性带电粒子在磁场或电场中弯曲时发射的电磁辐射。随着电子存储环的发展，具有日益增高的通量、亮度和相干功率水平的辐射，已成为生物学、化学和物理学的广泛基础和Applied研究，以及医学和技术应用的研究工具。参见 ELECTROMAGNETIC RADIATION（电磁辐射）；PARTICLE ACCELERATOR（粒子加速器）；RELATIVISTIC ELECTRODYNAMICS（相对论电动力学）。

电子存储环提供电磁波谱中从红外到可见光、近紫外、真空紫外、软 X 射线和硬 X 射线部分的辐射（延伸至 100 keV 及以上）。可用于实验的通量 [光子/秒，单位带宽]、亮度（或辉度）[通量/(单位源尺寸，单位立体角)] 以及相干功率（对成像应用重要，且与亮度成正比），特别是在真空紫外、软 X 射线和硬 X 射线波段，比其他来源高出几个数量级。

这种辐射具有许多特性（天然准直、高强度和亮度、宽光谱带宽、高偏振度、脉冲时间结构、小源尺寸和高真空环境），使其成为实验科学和技术中各种应用的理想选择。当高能物理学家在 1950 年代开始运行电子同步加速器时，紫外和 X 射线波段的强同步辐射源变得可用。尽管同步加速器产生大量辐射，但其循环特性导致每个循环中脉冲间的强度变化以及光谱和源形状的变化。相比之下，自 1960 年代为对撞机实验开发的电子-正电子存储环提供了恒定的光谱和更好的稳定性。在同步加速器和存储环上都建造了光束线，以允许这些机器的弯曲磁体产生的辐射离开环形真空系统并到达实验站。在大多数情况下，研究计划是以寄生方式进行的，次要于高能物理计划。

*劳伦斯伯克利国家实验室 1.5-GeV 高级光源源的布局，这是一种低能第三代同步辐射源。指示了光束线上实验站的应用。*

自 1980 年左右以来，几个国家已完成全专用存储环源。它们被称为第二代设施，以区别于为高能物理研究建造的第一代环。
