# 关于作者

`Jon McFarland` 住在俄亥俄州克利夫兰。他在一家开发公司管理设计部门，在那里他使用 `AutoCAD` 和 `VIZ` 创建拟建建筑的视觉图。他编写了五本书，并在大学教授 `VIZ`、`AutoCAD` 和 `3ds Max` 课程。
