### sted
`Small/Stupid Text editor`，是 `Small/Stupid`（由你选择）`Text Editor` 的缩写，是一个小型和/或文本编辑器。所以它没做什么事情。你可以编辑文件、加载和保存它们。它有很多许多你可能会觉得很恼的局限性。它在 `xterm` 中运行并不良好。来自 Debian 3.0r APT http://www.tldp.org/LDP/Linux–Dictionary/html/index.html

### sted2
一个快速的 MIDI 编辑器。`Sted2` 是一个用于 `Unix/X1` 平台的开源 MIDI 编辑器。最初由已故的 Takayuki “TURBO” Todo 为 SHARP X6800 个人工作站编写，现在已移植到 GNU/Linux，并可以在内核和 X 上完美运行。`Sted2` 最具特点的特征是它的输入方法。`Sted2` 支持“步进”输入，让你能够极快地输入 MIDI。还支持通过 `/dev/midi` 进行实时录制。来自 Debian 3.0r http://www.tldp.org/LDP/Linux–Dictionary/html/index.html

# 隐术 (stegano, TRANSEC)

在密码学中，隐术不仅指的是混淆（加密）数据，还隐藏其存在的事实。在通信中，`stegano` 描述的是尝试进行通信这一事实。历史：在古代，信使会被剃光头，然后在皮肤上纹上信息。头发重新长出来后，信使被派遣出去。接收者再次剃光信使的头以获取信息。来自 Hacking-Lexicon

http://www.tldp.org/LDP/Linux–Dictionary/html/index.html

# steghide

一种隐术工具程序，将文件的位隐藏在另一个文件的某些最低有效位中，使得数据文件的存在不可见且无法被证明。`Steghide` 设计为可移植和可配置的，具有在 `bmp`、`wav` 和文件中隐藏数据、鱼鳞算法加密、密码到密钥的 MD5 哈希值以及容器数据中隐藏位点的伪随机分布等特性。来自 Debian 3.0rt APT

http://www.tldp.org/LDP/Linux–Dictionary/html/index.html
