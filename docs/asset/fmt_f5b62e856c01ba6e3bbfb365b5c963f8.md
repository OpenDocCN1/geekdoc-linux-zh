就像 `HOME` 变量一样，`PWD`（打印工作目录）变量对用户环境至关重要，不应被更改。`PWD` 存储用户在目录中的位置。它受 `cd` 命令以及其他命令（例如需要确定当前目录时的 `pwd`）的影响。以下输出演示了它是如何工作的：

```bash
[rootserver ~]# pwd

/root
[rootserver ~]# cd /etc
[rootserver ~]# pwd
/etc
[rootserver ~]# echo $PWD
/etc
```
