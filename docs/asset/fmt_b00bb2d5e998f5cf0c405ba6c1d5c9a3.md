# gnome-lokkit

基础交互配置工具（GNOME 界面）。`gnome-lokkit` 软件包包含一个实用程序，尝试为普通 Linux 用户提供防火墙。用户无需手动配置防火墙规则，`gnome-lokkit` 会询问几个简单的问题并为你编写规则集。它并非设计用于配置活跃的防火墙。为了保持简单易懂，它只处理复杂的拨号用户和电缆调制解调器设置。它不会复杂的防火墙配置，也不是专业防火墙设计者的助手。主页：http://www.gnome.org/apps/lokkit.html 源自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html
