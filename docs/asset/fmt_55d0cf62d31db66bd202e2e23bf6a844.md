磁盘分区

### 理解分区表、类型和挂载点

Linux 中的分区是将存储设备（如硬盘或 SSD）划分为多个逻辑单元（分区）的过程。每个分区都可以使用不同的文件系统进行格式化，并挂载到文件系统层次结构中的不同位置。

以下是与 Linux 磁盘分区的一些基本概念：

- **分区表**：分区表是一种用于存储设备上分区信息的数据结构。Linux 中常用的分区表格式是主引导记录 `MBR` 和 GUID 分区表 `GPT`。`MBR` 限制最多四个分区，或者三个主分区和一个扩展分区。`GPT` 则允许更大数量的分区，并包含分区表的备份以增加可靠性。
- **分区类型**：存储设备上的每个分区都可以分配一个特定的分区类型，用于指示分区的用途。某些分区类型包括主分区、扩展分区和逻辑分区。
- **文件系统**：文件系统是在存储设备上组织和存储文件的方式。Linux 中使用的文件系统包括 `ext2`、`ext3`、`ext4`、`xfs`、`btrfs` 等。
- **挂载点**：挂载点是文件系统层次结构中分区挂载并供使用的位置。例如，根分区通常挂载在 `/`，而家目录分区通常挂载在 `/home`。

## 修改分区

`Parted` 命令与 `fdisk` 类似，也可以用于在存储设备上创建、删除和修改分区。例如，要在 `/dev/sda` 上创建一个大小为 100GB 的分区，可以使用以下命令：

```
sudo parted /dev/sda mkpart primary ext4 0 100G
```

## 挂载分区

`mount` 命令用于挂载分区并使其可使用。例如，将 `/dev/sda1` 挂载到 `/mnt`，可以使用以下命令：

```
sudo mount /dev/sda1 /mnt
```

## 卸载分区

`umount`：此命令用于卸载分区使其不可用。例如，要卸载挂载在 `/mnt` 的分区，可以使用以下命令：

```
sudo umount /mnt
```

需要注意的是，磁盘分区是一项敏感的任务，因为它涉及修改存储设备的结构，如果处理不当，可能会导致严重后果。

以下是磁盘分区被认为敏感任务的一些原因：

- **数据丢失**：如果错误地创建、删除或修改分区，可能会导致存储设备上的数据丢失。如果不小心删除了分区，或者在现有分区上创建了新分区，就会发生这种情况。
- **文件系统损坏**：如果错误地创建或修改文件系统，它可能会损坏并导致数据丢失或使存储设备无法访问。
- **启动失败**：如果错误地修改了分区表或引导程序，可能会导致系统无法启动。
- **磁盘故障**：在某些情况下，磁盘分区可能会对存储设备造成物理损坏，导致数据完全丢失或完全无法使用该设备。

这就是为什么在分区之前备份数据非常重要，同时，在使用分区命令时要非常小心，并在使用之前理解它们的工作原理。此外，在应用于生产系统之前，在非关键系统上测试分区过程是一个良好的做法。

## 文件系统操作

Linux 中的文件系统是在存储设备（如硬盘或 SSD）上组织和存储文件的方式。它负责管理存储设备上文件、目录和元数据的结构。Linux 中常用的文件系统包括 `ext2`、`ext3`、`ext4`、`xfs`、`btrfs` 等。每个文件系统都有自己的特性、优缺点，不同的文件系统适用于不同的用例。

黑客围绕文件系统的任务包括：

- **文件系统分析**：黑客可能会分析文件系统以识别敏感文件、隐藏目录和其他用于获取未经授权访问或或其他数据的信息。
- **文件系统枚举**：黑客可以使用各种命令和工具枚举文件系统的内容，例如列出所有文件和目录，并识别权限和所有权。
- **文件系统操作**：黑客可以使用各种命令和工具操纵文件系统的内容，例如创建、删除或修改文件和目录，以及更改文件权限和所有权。
- **文件系统挂载**：黑客可以使用各种命令和工具挂载文件系统，例如在法医分析的情况下，或访问通常无法访问的文件系统文件。
- **文件系统加密**：黑客可以使用 `LUKS` 等工具加密文件系统，以保护文件免受未经授权的访问。
- **文件系统取证**：黑客可以使用各种工具和技术对文件系统进行法医分析，例如恢复删除的文件、识别文件系统痕迹以及分析文件系统元数据。

## 创建文件系统

`Mkfs` 命令用于在分区上创建文件系统。例如，要在 `/dev/sda1` 上创建一个 `ext4` 文件系统，可以使用以下命令：

```
sudo mkfs.ext4 /dev/sda1
```
