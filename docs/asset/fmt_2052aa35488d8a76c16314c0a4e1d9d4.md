## 创建启动脚本

首先，让我们在 `rc` 目录下创建一个名为 `mysql` 的新脚本。进入 `/etc/rc.d/init.d` 并创建 `mysql` 文件。在这里我们将为所有脚本设置环境。通过以下内容告诉系统使用哪个 shell 来执行 `execute` 脚本：

```
#!/bin/sh
```

接下来，我们设置路径和目录名称：

```
PATH=/sbin:/usr/sbin:/bin:/usr/bin

basedir=/my/path/mysql

pid_file=/my/path/mysql/var/mysqld.pid

mysql_daemon_user=mysql
```

然后，我们设置脚本的启动部分。这将切换到之前指定的 `mysql` 目录；确保 `safe_mysqld` 程序存在，然后执行它，并指定之前定义的用户和 `pid-file`。`pid file` 包含进程 ID，可以在脚本的后半部分停止该进程。

```
mode=$1
```

```
cd $basedir
case "$mode" in

'start')

  #启动守护进程
  if test -x bin/safe_mysqld
  then
    # 启动数据库
    bin/safe_mysqld --user=$mysql_daemon_user --pid-file=$pid_file &
  else
    echo "Can't execute $basedir/bin/safe_mysqld"
  fi
fi
;;
```

最后一部分将使用之前生成的 `pid` 文件停止数据库。

```
'stop')

  # 使用 pid 文件停止守护进程
  if test -f "$pid_file"
  then
```

```
mysqldpid=`cat $pid_file`
echo "Stopping database with pid $mysqld_pid"
kill $mysqld_pid
else
echo "Cannot find $pid_file."
fi
;;
```

最后，我们提供了一些语法规范并退出：

```
+   * # # 用法
echo "usage: $0 start|stop"
exit 1
;;
esac
```

再次，这应该被放置在 `/etc/rc.d/init.d/mysql`。为了确保它在开机时执行执行，需要在每个运行级别 `run-level` 目录中创建一个符号链接，以启动和停止它。
在 `rc0.d`、`rc1.d` 和 `rc6.d` 目录下执行此命令：

```
shell$ ln -s ../init.d/mysql K90mysql
```

在 `rc2.d`、`rc3.d`、`rc4.d` 和 `rc5.d` 目录下执行此命令：

```
shell$ ln -s ../init.d/mysql S90mysql
```

这应该会在启动时启动数据库服务器，并在服务器重启/关机阶段关闭。这发生在不同的运行级别；这就是为什么根据运行级别需要在每个级别的目录中链接脚本。
了解运行级别对于管理目的非常重要；有关运行级别的更多信息，请查看您的 Linux 发行版文档。与其他数据库相关的应用程序也可以在这里启动。

# 性能

可以通过编译器进行一些优化来提高 MySQL 的性能。通过使用 `-static` 标志，你可以获得可能的数据库。此外，使用 UNIX sockets 而不是网络连接也会提高性能。

不同的硬件配置也有帮助。通过将数据库存储在多个磁盘上，等待磁头移动和寻道的时间就会减少，因为有多个磁盘在工作，而不是一个磁盘成为瓶颈。这被称为条带 `striping`。对于更大规模的条带，使用独立磁盘冗余阵列 `RAID` 将给你带来最佳结果。
使用符号链接也有帮助，通过对发行版中其他磁盘上的目录创建链接。删除交换文件也有帮助，因为操作系统可能会通过驱动器头将程序从内存交换出而减慢数据库访问。
MySQL 守护进程本身也可以进行调。有很多变量可以调优以提高性能。这些可以使用 `mysqldadmin` 工具进行设置。

```
shell ./mysqldadmin variables
```
