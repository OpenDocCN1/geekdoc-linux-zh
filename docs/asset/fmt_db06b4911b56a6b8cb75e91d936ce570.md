## 结论

共享目录和打印机一直是文件和打印服务器中配套使用的。就像从 Windows 服务器共享目录和打印机一样，你也可以在配置了 Samba 的 Linux 上这样做。

Red Hat Linux 包含了两种用于安装打印机的不同服务：CUPS 和 LPD。CUPS 是 Red Hat Linux 的默认选择。
