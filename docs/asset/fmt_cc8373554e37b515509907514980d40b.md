### WINE

WINE 按照其递归的 Linux 风格代表 WINE Is Not an Emulator（WINE 不是一个模拟器）。我认为他们选择这些词只是为了能拼出某个单词，因为它确实是一个模拟器。它模拟 Windows 的所有版本。我觉得他们应该叫它 Winux。

而且你可以用它在 KDE 下无缝运行 Windows 应用程序，如图 32.1 所示。
