## HP-UX 交换空间

HP-UX 操作系统执行交换，如 `swapinfo` 命令所示。要检查交换空间的统计，使用 `swapinfo -tm` 命令。`-t` 为输出添加一行，`-m` 选项指定输出单位为 MB，而不是默认的 KB。正如我之前提到的，HP-UX 在生成虚拟内存统计方面做得最好，因此我们只需要需要的输出是可用交换空间的百分比。在继续之前，让我们看看正在处理的命令输出，如 6.6 所示。

## 第 6 章

我们可以将读取命令的输出管道到 `while read` 循环中。当然，`while read` 循环只会运行一次迭代。最简单的技术是管道到 `while` 循环。以下命令将带我们：

```bash
swapinfo -tm | grep dev | while read junk SW_TOTAL SW_USED \
    SW_FREE_PERCENT_USED junk2
```

在上一个语句的 `while read` 部分，注意我们如何分配了名为 `junk` 和 `junk2` 的字段。第一个字段由 `junk` 变量指定的 `dev`，我们对保存这个字段不感兴趣，因此给它赋值为 `junk`。最后一个变量 `junk2` 是输出行中剩余任何内容的通用捕获器；具体来说，“928768 - 1 /dev/dsk/c0t60”会被作为一个整体整体赋值给变量 `junk2`。这是 `while read` 语句中非常重要的一部分，因为你必须考虑到某行数据中的所有内容。我漏掉了 `junk2` 变量；当我们需要的唯一行数据是 24% 时，`PERCENT_USED` 变量将指向数据“24 928768 - 1 /dev/dsk/c0t60”。`junk2` 变量捕获行中所有剩余数据并将其赋值给 `junk2`。这引出了另一个点。如果你想捕获行数据并赋值给单个变量，可以使用以下语法：

```bash
while read DATA_LINE 
do
    PARSE $DATA_LINE DATA HERE
done < $DATA_FILE
```

使用这种语法，所有数据都由单个变量 `DATA_LINE` 捕获，并且数据按照其在命令输出中的形式分成字段。

回到我们之前的 `swapinfo` 语句，我们将感兴趣的数据存储在以下变量中：

- `SW_TOTAL`. 系统上可用的交换空间总量，以 MB 为单位。
- `SW_USED`. 当前正在使用的交换空间（MB）。
- `SW_FREE`. 当前空闲的交换空间（MB）。
- `PERCENT_USED`. 已用总交换空间的百分比。

我们需要的输出中唯一的部分是当前空闲的交换交换空间百分比。这是一个简单的计算，因为我们已经有了 `$PERCENT_USED`。为了进行计算，我们需要移除 `$PERCENT_USED` 变量中的百分比符号 `%`。以下语句一步完成了移除百分比符号并进行计算：

```bash
((PERCENT_FREE = 100 - $(echo $PERCENT_USED | cut -d% -f1)))
```

在前面的数学语句中，我们使用命令替换通过 `cut` 命令移除 `$PERCENT_USED` 变量中的百分比符号，并将 100% 减 24% 赋值给变量 `PERCENT_FREE`。在语句的 `cut` 部分，我们通过 `-d%` 将 `%` 定义为分隔符或字段分隔符，然后使用 `-f1` 符号提取第一个字段（在本例中为 24）。一旦命令替换完成，我们就得到了下面的数学语句：

```bash
{{PERCENT_FREE = 100 - 24}}
```
