## trap

`trap` 命令允许你指定一个在 shell 接收到特定特定值的信号时应执行的命令。其语法如图 5.15 所示。这里有一个使用 `trap` 控制结构的脚本示例：

```
$ cat trap.sh ...列出脚本。
trap 'echo Control-C; exit 1' 2
while true
do
echo infinite loop
sleep 2
done
$ trap.sh ...执行脚本。
infinite loop
Control-C
infinite loop
Control-C
infinite loop
```
