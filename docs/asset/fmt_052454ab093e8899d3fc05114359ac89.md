
由数学归纳法原理，对于每个正整数 `k`，`a_{ij}^{(k)}` 是 `G` 中不同的长度为 `k` 的 `v_i-v_j` 途径的数量。$\blacksquare$

在给出一个例子来说明定理 2.2 之前，我们做几点观察。设 `G` 是阶数为 `n` 的图，其中 `V(G)={v_1,v_2,…,v_n}` 且 `A^k=[a_{ij}^{(k)}]`，其中 `A` 是 `G` 的邻接矩阵。根据定理 2.2，`a_{ij}^{(k)}` 给出了 `G` 中不同的长度为 `k` 的 `v_i-v_j` 途径的数量。由于长度为 2 的 `v_i-v_i` 途径是 `(v_i,v_t,v_i)`，其中 `v_t` 是与 `v_i` 相邻的某个顶点，因此对于 `G` 中的每个顶点 `v_i`，都有 `a_{ii}^{(2)}=deg(v_i)`。当 `i≠j` 时，`a_{ij}^{(2)}` 是 `G` 中不同的长度为 2 的 `v_i-v_j` 路的数量。再次根据定理 2.2，`a_{ij}^{(3)}` 给出了 `G` 中不同的长度为 3 的 `v_i-v_j` 途径的数量。由于长度为 3 的 `v_i-v_j` 途径是 `(v_i,v_s,v_t,v_j)`，其中 `v_s` 和 `v_t` 是相邻顶点，且都与 `v_i` 相邻，因此 `v_i` 必须属于一个三角形。不仅 `(v_i,v_s,v_t,v_j)` 是 `G` 中长度为 3 的 `v_i-v_j` 途径，`(v_i,v_t,v_s,v_j)` 也是（不同的）`G` 中长度为 3 的 `v_i-v_j` 途径。因此，`a_{ii}^{(3)}` 是包含 `v_i` 的 `G` 中三角形数量的两倍。

作为一个例子，考虑图 2.3 中具有邻接矩阵 `A` 的图 `G`。我们可以通过观察 `A^2` 中的 `(i,i)` 元素（`1≤i≤4`）是 `deg v_i`，且 `A^2` 中的 `(i,j)` 元素（`i≠j`）是不同长度为 2 的 `v_i-v_j` 路的数量，从而无需进行矩阵乘法即可计算 `A^2`。现在我们转向 `A^3`。由于 `G` 中不同的长度为 3 的 `v_1-v_3` 途径是

### 闭迹与圈

图 `G` 中一条不重复经过任何边的非平凡闭游走被称为 `G` 中的**闭迹**（或**回路**）。例如，`C = (u, w, x, y, w, v, u)` 是图 2.1 中图 `G` 的一个闭迹。除了该闭迹中 `u` 的必要重复外，`w` 也被重复了。这是可以接受的，因为 `C` 中没有边被重复。一个形如：

> `C = (v = v_0, v_1, …, v_k = v)`,  \tag{2.4}

且 `k≥2`，其中顶点 `v_i, 0≤i≤k-1` 互不相同的闭迹，是 `G` 中的一个**圈**。因此，`C' = (u, v, y, x, w, u)` 是图 2.1 中图 `G` 的一个长度为 5 的圈。与第 1 章中提到的被称为圈的图类 `C_k, k≥3` 类似，(2.4) 中的圈 `C` 被称为 *k*-圈。再次强调，3-圈被称为**三角形**。偶数长度的圈是**偶圈**，奇数长度的圈是**奇圈**。

由路径 `(v_1, v_2, …, v_k)` 或圈 `(v_1, v_2, …, v_k, v_1), k≥3` 中的边诱导出的子图，分别被称为**路径**或**圈**。因此，路径和圈有多种解释——它们是图中顶点之间的一种行进方式，是图中的子图，也是图的一类。迹（trails）和闭迹（circuits）也是如此。图 2.1 中图 `G` 前文描述的路径 `P'` 和圈 `C'` 对应于图 2.4 所示的子图。我们在 1.1 节中看到，阶为 `n` 的路径或圈分别记为 `P_n` 和 `C_n`。

![](img/598a6ae3fd44120830ada34717906f29_54_0.png)

图 2.4：图中的一条路径和一个圈

图 `G`（包含圈）中最小圈的长度是 `G` 的**围长**（girth），记为 `g(G)`，最长圈的长度是 `G` 的**周长**（circumference），记为 `c(G)`。因此，当 `n≥3` 时，`g(K_n)=3` 且 `c(K_n)=n`；而当 `2≤s≤t` 时，`g(K_{s,t})=4` 且 `c(K_{s,t})=2s`。彼得森图的围长为 5，周长为 9（我们将在第 6 章中看到）。

### 连通性

图 `G` 中的两个顶点 `u` 和 `v` 是**连通的**，如果 `G` 包含一条 `u-v` 路径。如果 `G` 中任意两个顶点都是连通的，则图 `G` 本身是**连通的**。根据定理 2.1，如果对于 `G` 中的任意两个顶点 `u` 和 `v`，`G` 都包含一条 `u-v` 游走，则图 `G` 是连通的。不连通的图 `G` 称为**非连通图**。图 2.5 中的图 `F` 是连通的，因为对于 `F` 中的任意两个顶点 `u` 和 `v`，`F` 都包含一条 `u-v` 路径（以及一条 `u-v` 游走）。另一方面，图 `H` 是非连通的，例如，`H` 中不包含任何 `y_1-y_5` 路径。

![](img/598a6ae3fd44120830ada34717906f29_54_1.png)

图 2.5：一个连通图和一个非连通图

图 `G` 的一个连通子图 `H` 被称为 `G` 的一个**连通分量**（component），如果 `H` 不是 `G` 的任何连通子图的真子图。因此，`G` 的每个连通分量都是 `G` 的一个诱导子图。图 `G` 中连通分量的数量记为 `k(G)`。因此，`G` 是连通的当且仅当 `k(G)=1`。对于图 2.5 中图 `H` 的顶点集 `S_1={y_1,y_2,y_3,y_4}` 和 `S_2={y_5,y_6,y_7}`，诱导子图 `H[S_1]` 和 `H[S_2]` 是 `H` 的（唯一的）连通分量。因此，`k(H)=2`。

我们介绍的所有熟悉的图类都是连通的。这包括路径 `P_n`、圈 `C_n`、完全二部图 `K_{n,n}`、超立方体 `Q_n` 和完全图 `K_n`。由于完全图 `K_n` 是连通的，所以每个顶点度数为 `n-1` 的任意阶为 `n` 的图都是连通的。这说明了我们将经常遇到的一个事实。假设完全图 `K_n` 具有某个性质（在本例中，它是连通的）。因此，如果阶为 `n` 的图 `G` 的每个顶点度数足够高，则 `G` 也具有此性质。由于图 2.6 中阶为 `n=2k` 的非连通图 `H=2K_k` 是 `(k-1)`-正则的，显然 `k-1=(n-2)/2` 对于保证阶为 `n` 的图 `G` 的连通性来说，其顶点度数并不是足够大。然而，数值 `(n-2)/2` 接近具有此性质。在证明这一点之前（在推论 2.4 中），我们首先呈现一个更普遍的结果。
