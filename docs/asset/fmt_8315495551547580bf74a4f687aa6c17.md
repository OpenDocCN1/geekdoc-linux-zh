# isync (同步工具)
同步本地 maildir 与远程 IMAP4 邮箱。一个命令行应用程序，将本地 maildir 格式的邮箱与远程 IMAP4 邮箱进行同步，适用于 IMAP 离线模式。可以维护多个远程 IMAP4 邮箱副本，并同步标志位。特性：获取新邮件的快速方法 *（端口 993） * TLS/SSL 连接 * 支持用于机密性的 STARTTLS (RFC2595) * 支持命名空间 NAMESPACE (RFC2342) * 支持用于认证的 CRAM-MD5 (RFC2045) -来自 Debian 3.0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
