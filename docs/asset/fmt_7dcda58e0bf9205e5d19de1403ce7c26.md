
用于多读器的“小兄弟”数据库。此包由一组小工具组成，从多个源收集邮件地址，并将这些地址提供给扩展查询功能。支持以下模块：

- `m_finger` (搜索 `finger(1)` 命令)
- `m_inmail` (扫描传入的地址)
- `m_password` (搜索 XP 密码数据库)
- `m_yppasswd` (搜索 YP 数据库)
- `m_get` (搜索配置的数据库)
- `m_pp2`, `m_gpg` (搜索你的 GPG 或 Gnu 密钥环)
- `m_fish` (查找 Fido 节点列表)
- `m_abook` (搜索地址簿)
- `m_addr_email` (使用地址簿程序中的 addr-email)
- `m_mutials` (搜索别名)
- `m_pine` (搜索 Pine 数据库)
- `m_palm` (搜索你的 Palm 数据库；需要 `libpalm-perl` 包）
- `m_gnomecard` (搜索 GnomeCard 数据库)
- `m_bbdb` (搜索你的 BBDB 数据库)
- `m_ldap` (查询任何 LDAP 服务器) 源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# lbproxy

低带宽 X (LBX) 代理。利用低带宽 X (LBX) 的应用程序必须连接到 `lbproxy`。这些应用程序不需要 LBX，只需像普通的 X 服务器一样连接到 `lbproxy`。`lbproxy` 接收客户端，在单个连接上进行复用，并对 X 协议进行各种优化，使其在低带宽/高延迟连接下更快。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
