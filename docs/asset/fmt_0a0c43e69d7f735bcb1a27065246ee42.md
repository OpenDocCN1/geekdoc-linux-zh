## 7.2.6 进程内存统计

`stat` 条目包含七个用空格分隔的数字。每个数字都是进程在特定类别中使用的内存页计数。类别按出现的顺序列在这里：

- 进程总大小
- 驻留在物理内存中的进程大小
- 与其它进程共享的内存——至少一个（如共享库或未被触碰的页）
- 进程的大小——已加载执行代码
- 映射到此进程的共享库大小
- 进程用于栈的内存大小
- 脏页数量——被程序修改的内存页

## 7.2.7 进程统计

`status` 条目包含了关于进程的各种信息，并便于人类阅读。这些信息中包括进程 ID 和父进程 ID、真实和有效用户 ID、内存使用，以及指定信号捕获、忽略和阻塞的位掩码。

## 7.3 硬件信息

`/proc` 文件系统中的其他几个条目提供了有关硬件的信息。虽然这些条目通常令系统配置员感兴趣，但有时对应用程序程序员也有用。我们在这里介绍一些实用的条目。

### 7.3.1 CPU 信息

如前所述，`proc/cpuinfo` 包含了关于运行 Linux 系统的 CPU 信息。`Processor` 字段列出处理器数量；对于单处理器系统，该值为 0。`Vendor`、`CPU Family`、`Model` 和 `Stepping` 字段允许你确定 CPU 的精确型号和修订。`Flags` 字段显示设置了哪些 CPU 标志，指示该 CPU 可的功能。例如，`mmx` 表示扩展 MMX 指令。

从 `/proc/cpuinfo` 返回的大部分信息来自 x86 汇编。这是程序获取 CPU 信息的低级机制。对于 `/proc/cpuinfo`，请参考 IA-32 Architecture Developer's Manual, Volume 2: Instruction Set。最后一个元素 `bogomips` 是 Linux 特有的值。它是处理器在紧凑循环中速度的测量值，因此是整体速度的一个较差指标。

### 7.3.2 设备信息

`/proc/devices` 列出了系统可用块设备的主设备。设备类型和设备编号请见第 6 章“设备”。

### 7.3.3 PCI 总线信息

`/proc/pci` 文件列出了连接 PCI 总线的设备总结。这些 PCI 扩展卡可能包括集成在主板上的设备以及 AGP 显卡。列表包括设备类型；设备和厂商 ID（如果可用）；设备提供的功能信息；以及设备使用的 PCI 资源。

### 7.3.4 串口信息

`/proc/tty/driver/serial` 文件列出了串口的配置和统计数据。串口从 0 开始编号。也可以使用 `setserial` 命令获取串口的配置信息。然而，`proc/tty/driver/serial` 显示了关于每个串口中断数的额外统计。

- 关于 MMX 指令的文档请参考 IA-32 Architecture Developer's Manual，关于如何在 GNU/Linux 程序中使用这些和其他特殊汇编指令的信息，请参考本书的第 9 章“内联汇编”。
- 注意在 DOS 和 Windows 下，串口从 1 开始编号，因此 COM1 对应 Linux 下的串口 0。

`/tty/driver/serial` 中的这一行可能描述串口 1（在 Windows 下为 COM2）：

- `1: 16550A port:2f8 irq:9600 tx:11 rx:0`

这表示串口由 16550A 型 UART 运行，使用 I/O 端口 0x28 和 IRQ 3 进行通信，运行速度为 9600 波特。该串口将有 11 个发送中断和 0 个接收中断。

关于串口设备的信息请见第 6.4 节“硬件设备”。

## 7.4 内核信息

`/proc` 中的许多条目都提供了有关运行内核配置和状态的信息。这些条目中的一些位于 `/proc` 的顶层，另一些位于 `/proc/sys/kernel` 下。

### 7.4.1 版本信息

`/proc/version` 文件包含一个长字符串，描述内核的发布版本和构建版本。它还包含了关于内核如何构建的信息：编译它的的用户、编译它的机器、编译日期以及使用的版本——例如：

```bash
%cat /proc/version
Linux version 2.2.14-5.0 (root@pretty.devel.redhat.com) (gcc version egcs-2.9.16-10968534/Linux (egcs-1.1.2 release)) #1 Tue Mar 7 21:07 EST 2000
```

这表示系统正在运行 2.2.14 版本的 Linux 内核，该内核是用 EGCS 1.1.2 编译的。（EGCS，实验性 GNU 系统，是当前 GCC 项目的前身。）

此输出中最重要的条目（操作系统名称、内核名称和修订版本）也存在于单独的 proc 条目中。它们分别是 `/proc/sys/kernel/ostype`、`proc/sys/kernel/osrelease` 和 `/proc/sys/kernel/version`。

```bash
%cat /proc/sys/kernel/ostype
Linux
%cat /proc/sys/kernel/osrelease
2.2.14-5.0
%cat /proc/sys/kernel/version
#1 Tue Mar 7 21:07 EST 2000
```

### 7.4.2 主机名和域名

`/proc/sys/kernel/hostname` 和 `/proc/sys/kernel/domainname` 条目分别包含计算机的主机名和域名。这些信息与第 8.15 节描述的 `uname` 系统调用返回的信息相同。

## 7.5 驱动器、挂载点与文件系统

### 7.4.3 /proc/meminfo 内存使用

`/proc/meminfo` 条目包含了有关系统内存使用的信息。信息同时针对物理内存和交换分区（`swap space`）。前三行以字节（`bytes`）显示内存总量；但后续行以千字节（`kilobytes`）总结这些信息——例如：

```bash
$ cat /proc/meminfo
| total: used: free: shared: cached: |
| Mem: 52044728 51961868 10084352 82612224 18977280 82108416 |
| Swap: 271302768 4403328 227389440 |
| MemTotal: 51728 kB |
| MemFree: 9848 kB |
| MemShared: 80676 kB |
| Buffers: 10728 kB |
| Cached: 80184 kB |
| BigTotal: 0 kB |
| BigFree: 0 kB |
| SwapTotal: 265032 kB |
| SwapFree: 222060 kB |
```

这显示了 512MB 的物理内存，其中约 9MB 为空，以及 258MB 的交换分区，其中 216MB 为空。在对应物理内存的行中，还提供了另外三个值：

- `Shared` 列显示系统当前分配的总共享内存（参见第 5.1 节，“共享内存”）。
- `Buffers` 列显示 Linux 为块设备缓冲区（`block device buffers`）分配的内存。这些缓冲区被设备驱动程序，用于存储从磁盘读取或写入的数据块。
- `Cached` 列显示 Linux 分配给页缓存（`page cache`）的内存。这部分内存用于缓存对映射文件的访问。

你可以使用 `free` 命令来显示相同的内存信息。

## 7.5 驱动器、挂载点与文件系统

`/proc/filesystems` 同样包含了系统中存在的磁盘驱动器以及从这些驱动器上挂载的文件信息。

### 7.5.1 文件系统

`/proc/filesystems` 条目显示了内核已的文件系统类型。请注意此列表并不是完整的：文件系统可以作为内核模块动态加载和卸载。`/proc/filesystems` 的内容仅列出静态链接到内核或当前加载的文件系统类型。其他文件系统类型可能以模块形式存在于系统中，但尚未被加载。

### 7.5.2 驱动器与分区

`/proc` 文件系统包含了连接到 IDE 控制器和 SCSI 控制器的设备信息（如果系统包含这些设备）。

在典型系统中，`/proc/ide` 子目录可能包含 `ide0` 和 `ide1` 两个子目录中的一个或两个，它们分别对应于连接到系统的物理设备的主、从 IDE 控制器。这些目录包含进一步的子目录。如果 Linux 没有识别到任何连接的设备，则控制器或设备目录可能不存在。对应四个 IDE 设备的完整路径如表 7.1 所示。

- `model` 包含设备的型号识别字符串。
- `media` 包含设备的介质类型。可能的值有 `disk`（磁盘）、`tape`（磁带）、`cdrom`（光驱）、`floppy`（软盘）和 `UNKNOWN`（未知）。

## 7.6 系统统计

`/proc` 中的两个条目包含有用的系统统计信息。`/proc/loadavg` 文件包含有关系统的信息——前三个数字代表实际运行的活动任务数——这是过去 1、5 和 15 分钟的平均值。下一个条目显示当前可运行任务的瞬时数量——即当前被调度运行而非在系统中阻塞的进程——最后一个条目是最近运行的进程的进程 ID。

# Linux 系统调用

到目前为止，我们介绍了许多你的程序可以调用的函数，用于执行与系统相关的功能，例如解析命令行选项、操作进程和映射内存。如果你深入研究其原理，你会发现这些函数根据其实现方式可以分为两类。

- **库函数**（`library function`）是存在于你的程序外部库中的普通函数。我们到目前为止介绍的大多数库函数都在标准 C 库（`*standard C library*`）中；例如，`getopt_long` 和 `mktemp` 就是由 C 库提供的函数。

对库函数的调用就像任何其他函数调用一样。参数被放在处理器寄存器或栈上，执行流被转移到函数代码的起点，该代码通常位于加载的共享库中。
