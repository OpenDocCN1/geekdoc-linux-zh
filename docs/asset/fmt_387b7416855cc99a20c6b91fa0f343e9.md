# 第 15 节：系统管理实用工具

## 概述

本节介绍两个对商用 Unix 系统非常实用的系统管理工具：

- `SMIT`：AIX 的系统管理界面工具
- `SAM`：HP-UX 的系统管理管理器

`SMIT` 和 `SAM` 是菜单驱动的应用程序，可用于简化复杂的任务，如管理硬件、软件、用户/组等。虽然可以在命令行上执行 `SMIT` 或 `SAM` 中的每项任务，但在这些实用工具中执行相同任务通常要容易和快捷得多。它们还通过确保请求的任务以正确的参数执行，从而提供了一层额外的防错保护。

## 本节涵盖的命令：

| 命令 | 用途 |
|---|---|
| `sam` | HP-UX 系统管理管理器 |
| `smit` | AIX 系统管理界面工具 |
