- `module` `mod_mmap` 用于提高性能
- `module` `mod_auth` 用于密码验证。
- `module` `mod_sel` 用于加密和安全交易。
- `module` `mod_php` 用于提高 php 页面加载速度。
- `module` `mod_perl` 比脚本提供更好的安全性和性能。
- 禁用 `include`
- 禁用 `status`
- 禁用 `userdir`
- 禁用 `negotiation`
- 禁用 `autobindex`
- 禁用 `asis`
- 禁用 `imap`
- 禁用 `env`
- 禁用 `actions`

```
<Location /perl-status>

  Deny from all
