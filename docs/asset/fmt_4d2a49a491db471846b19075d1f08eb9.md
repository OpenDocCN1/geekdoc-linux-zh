
`char *XGetDefault(display, program, option);`

`display`
指定到 X 服务的连接。

`program`
指定用于 Xlib 默认值的程序名（通常是主程序的 `argv(0)`）。

`option`
指定选项名称。

`XGetDefault` 返回 `resource_prop` 的值，其中 `prog` 是去除了目录前缀的参数，且 `option` 必须是单个组件。请注意，`XGetDefault` 无法同时使用多个资源。类 "Name" 用于资源查找。如果该程序没有指定的 `option`，则 `XGetDefault` 返回 `NULL`。`XGetDefault` 返回的字符串由 Xlib 所有，客户端不应对其修改或释放。

如果已用 `XrmDatabase` 设置了数据库，则使用该数据库进行查找。否则，将创建一个数据库并设置在显示中（类似于调用 `XrmDatabase`）。`XGetDefault` 使用屏幕0根窗口上 `RESOURCE_MANAGER` 属性的资源。如果不存在该属性，则使用用户主目录下的资源文件。在符合 POSIX 的系统中，该文件是 "`HOME/.Xdefaults`" 。加载默认值后，`XGetDefault` 会合并由 `ENVIRONMENT` 指定的额外默认值。如果定义了 `ENVIRONMENT`，它包含额外资源名的完整路径。如果未定义 `ENVIRONMENT`，`XGetDefault` 将查找 "`$HOME/.Xdefaults-name`" ，其中 name 指定运行应用程序的机器名称。

## X Version 10 兼容性函数

你可以使用 X Version 10 兼容函数来：

- 绘制并填充多边形和曲线
- 将用户数据与值关联

### 绘制和填充多边形和曲线

Xlib 提供了用于绘制或填充任意多边形或曲线的函数。这些函数是为了兼容 X Version 10 而提供的，并且没有服务器支持。也就是说，它们调用其他 Xlib 函数，而不是直接调用服务器。因此，如果你有直线要绘制，使用 `XDrawLines` 或 `XDrawSegments` 会快得多。

这里讨论的函数提供了 X 10 函数 `XDraw`、`XDrawFilled`、`XDrawPatterned`、`XDrawDashed` 和 `XDrawiled` 的所有功能。在 X 11 新绘制函数的情况下，它们尽可能保持兼容。但需要注意的是，`VertexLastPoint` 不再被支持。此外，返回的错误与 X 10 下的相反。你使用的图形上下文会影响你是否能获得虚线。如果线条连接并包含了图形的闭，则将正确连接。X 10 中的 `XAppendVertex` 和 `XClearVertex` 也不被支持。要实现 X Version 10 `XDraw`、`XDrawDashed` 和 `XDrawPatterned` 的效果，请使用 `XDraw`。

```c
#include <X11/X10.h>

Status XDraw(display, d, gc, vlist, vcount);
```

`display` 指定到 X 服务的连接。
`d` 指定可绘制区域（drawable）。
`gc` 指定图形上下文（GC）。
`vlist` 指定指向顶点列表的指针，指示要绘制的内容。
`vcount` 指定 `vlist` 中的顶点数量。

`XDraw` 函数绘制任意多边形或曲线。绘制的图形由指定的顶点列表 (`vlist`) 定义。点根据标志结构中的指定用线条连接。`<X11/X10.h>` 中定义的每个 `Vertex` 是一个包含以下成员的结构：

```c
typedef struct {
  short x, y;
  unsigned short flags;
} Vertex;
```

`x` 和 `y` 成员是顶点坐标，相对于可绘制区域的右上角（如果 `VertexRelative` 为 0）或上一个顶点（如果 `VertexRelative` 为 1）。`<X11/X10.h>` 中定义的 `flags` 如下：

| 标记 | 值 | 说明 |
| :--- | :--- | :--- |
| VertexRelative | 0x0001 | 否则绝对值 |
| VertexDontDraw | 0x0002 | 否则绘制 |
| VertexCurved | 0x0004 | 否则直线 |
| VertexStartClosed | 0x0008 | 否则否 |
| VertexEndClosed | 0x0010 | 否则否 |

- 如果未设置 `VertexRelative`，坐标是绝对的（即相对于可绘制区域）。第一个顶点必须是绝对值。
- 如果 `VertexDontDraw` 为 1，则不从上一个顶点到此处绘制线条或曲线。这类似于拿起笔移动到另一个地方。
- 如果 `VertexCurved` 为 1，则使用样条算法从上一个顶点通过此点到下一个顶点绘制平滑曲线。如果上一个顶点和下一个顶点都是（无论是显中显式还是通过闭合曲线的定义），将 `VertexCurved` 设置为 1 是意义的。
- `VertexDont` 位和 `VertexCurved` 位可以同时为 1。如果你想定义平滑曲线的前一个点，但直到此点之前不开始实际曲线，这非常有用。
- 如果 `VertexStartClosed` 为 1，该点标记为闭合曲线的开始。该点必须被一个坐标相同的顶点（`VertexEndClosed` 为 1）跟随。这些点之间通过样条算法形成循环。该函数使用 GC 组件：function、plane-mask、line-width、line-style、cap-style、join-style、fill-style、subwindow-mode、clip-x-origin、clip-y-origin、clip-mask。它还使用这些模式相关的组件：foreground、background、tile、stipple、tile-stipple-x-origin、tile-stipple-y-origin、dash-offset。

要实现 X Version 10 `XDrawFilled` 的效果，使用 `XDrawFilled`：

```c
Status XDrawFilled(display, d, gc, vlist, vcount);
```

`display` 指定到 X 服务的连接。
`d` 指定可绘制区域。
`gc` 指定图形上下文。
`vlist` 指定指向顶点列表的指针，指示要绘制的内容。
`vcount` 指定 `vlist` 中的顶点数量。

`XDrawFilled` 函数绘制任意多边形或曲线并填充它们。这使用了 GC 组件：function、plane-mask、line-width、line-style、cap-style、join-style、fill-style、subwindow-mode、clip-x-origin、clip-y-origin、clip-mask。它还使用了这些模式相关的组件：foreground、background、tile、stipple、tile-stipple-x-origin、tile-stipple-y-origin、dash-offset、dash-list、fill-style 和 fill-rule。

### 将用户数据与值关联

这些函数已被上下文管理函数（见第16.10节）取代。经常需要与资源 ID 关联任意信息。Xlib 提供了你可以用于此类关联的 `AssocTable` 函数。应用程序通常需要在事件到达时方便地引用所有者数据结构。`AssocTable` 系统为用户提供了一种与资源（位图、字体、窗口等）关联数据结构的方法。

`AssocTable` 可用于 X 资源分类。例如，用户可能有三四个窗口，每个窗口都有不同的属性。可以通过将每个 X 窗口 ID 关联到自定义窗口数据结构指针来实现。在使用 `AssocTable` 时应遵循以下指南：

- 所有 XID 都相对于指定的显示器。
- 由于关联机制使用的哈希方案，应遵循以下确定 `AssocTable` 大小的规则：如果表格大小（哈希系统的桶数）是 2 的幂，且每个桶中的 XID 数量不超过 8 个，则关联和查找将更高效。

要从给定的 `XAssocTable` 获取数据，请使用 `XLookupUpAssoc`。

```c
char *XLookupUpAssoc(display, table, x_id);
```

`display` 指定与 X 服务的器的连接。

`table` 指定关联表（assoc table）。

`x_id` 指定 X 资源 ID。

`XLookupUpAssoc` 函数通过其 XID 检索存储在 `XAssocTable` 中的数据。如果在表中找到了适当匹配的 XID，则 `XLookupUpAssoc` 将返回与之关联的数据。如果从表中未找到 xid，则返回 `NULL`。

要从给定的 `XAssocTable` 中删除条目，请使用 `XDeleteAssoc`。

```c
XDeleteAssoc(display, table, x_id);
```
