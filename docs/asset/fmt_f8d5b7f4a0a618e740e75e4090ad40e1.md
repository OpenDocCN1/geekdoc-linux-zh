# 14.8 远程计算

除了 `telnet` 和 `ftp` 命令外，UNIX 还提供了另一组命令，包括 `scp`、`rsh` 和 `login`，它们的作用类似于 `telnet`。表 14.11 列出了这些命令，接下来的章节将解释如何使用这些命令。

## 表 14.11 r 命令列表

| 命令 | 操作 |
|---|---|
| `rcp` | 远程复制程序 |
| `rsh` | 远程 shell 程序 |
| `login` | 远程登录程序 |

## 14.8.1 远程访问命令：rcp

你可以使用 `rcp` 命令在系统之间复制文件。它的用法和作用类似于 `cp`，但你是在从其他系统复制文件。其基本语法与 `cp` 相同：

```
rcp source-file destination-file
```

然而，源文件或目标文件要么是远程文件名 `hostname:path`，要么是本地文件名。例如，以下命令将 `unix3.university.edu` 上的远程文件 `/usr/home/student/report` 复制到你的本地目录。

```
$ rcp unix3.university.edu:/usr/home/student/report .
```

以下命令将本地文件 `report` 复制到 `unix3.university.edu` 系统上的目录：

```
$ rcp report unix3.university.edu:/usr/home/student .
```

- 冒号 (`:`) 将远程主机名与文件名分隔。
- 你也可以将文件从一个系统复制到另一个远程系统。
- 你必须在远程主机和本地系统上拥有有效的账户和相同的用户名。

## 14.8.2 远程访问命令：rsh

你可以使用 `rsh` 命令在远程主机上运行 shell，以执行你在命令行中传递的命令。例如，以下命令序列将登录到名为 `unix3.university.edu` 的远程系统，并使用远程主机上的 shell 执行 `whoami` 命令。

```
$ rsh unix3.university.edu "whoami"
```

```
$ rsh unix3.university.edu
$ exit
```
