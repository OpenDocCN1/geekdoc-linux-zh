
这个问题应该被考虑，**“知识产权”**与基本正义、体面和常识的概念相冲突。似乎不诚实的企业试图施加模糊的**“许可”**来无限地榨取，同时又不提供任何新价值。在某些情况下，它正成为一些大公司试图对普通人（以及初创企业）征税的工具。`Linux` 是这种不健康趋势的回答，是一个基于尊重现有代码同时提供价值的回答。`Linux` 与那些想要在提供价值的同时榨钱的人产生了冲突。我不认为 `Linux` 的 `IP` 存在根本性问题，但确实存在利益冲突，从而导致对 `Linux` 的攻击。

总结，`Linux` 许可基于对当前版权法的尊重。据我们所知，`Linux` 没有**“知识产权”**侵权。它采取了最勤勉的实践来确保免受此类侵权影响。然而，由于源代码开发的革命性本质，`Linux` 正在受到模糊 `IP` 索赔的攻击，并被一些付费的

### 给犹豫不决者（Linux 的好处）

如果发生了最坏的情况，知识产权变得如此限制以阻碍 `Linux` 和开源软件的进步，我预计将是法律发生崩溃。这是因为政治家们似乎忘记了知识产权并非真实存在（杰斐逊知道这一点），它被设立是为了进一步的发展和共同利益。`Linux` 的诞生源于对过去方法所产软件的质量和成本的真实挫败，而这种挫败是无法通过赤裸政治后果来遏制的。

### 1.19 Linux 其他等

如果你不喜欢 `Linux`，就不要使用它。使用 `Linux` 并不是在帮任何忙。`GNU/Linux` 是免费且强大的软件，但只属于那些喜欢或需要它的人。有其他的操作系统供你选择，它们可能更符合你的需求。虽然大多数 `Linux` 用户喜欢增长并欢迎新用户，但有些人对此并不非常开心，因为**“这里和商业可能会产生我们创造的那个黑客天堂。”**因此，你使用 `Linux` 并不是在帮任何忙。

在这种背景下，总结一下 `Linux` 的优缺点可能是值得的：`Linux` 由它的粉丝所有（你的所有权伴随着你对粉丝俱乐部的免费订阅），绝对强大且功能丰富，高度灵活，取决于你想成为什么样（带有复杂的），不考虑硬件成本，任何网络功能皆可了解，需要一名计算机管理员，一些优秀的桌面应用程序在所有平台上仍是商业产品（例如电子表格和文字处理），许多优秀的终端用户应用程序作为操作系统的**“标准”**免费提供，图形用户界面非常漂亮，但没有苹果或微软提供的那么精细。`Linux` 具有高度标准（`POSIX` `UNIX`），一直使用开放文件格式，数千个程序可免费下载（尽管在易用性和质量价值上有所不同）。最重要的是，`Linux` 是令人享受的！

# 安装 LINUX 前准备

`Knoppix` 的特点在于它是一个**“现场发发行版”**，即它可以从 `CD` 启动而无需安装。这对于尝试 `Linux` 来说极佳（如果你喜欢它，也可以在硬盘上安装 `Knoppix`）。它也是一个完美的灾难恢复工具（在 `CD` 上运行是安全的，因为没有恶意程序可以对你的电脑做任何事情，而且对于需要事后分析的本地存储来说，它是非侵入性的）。`Knoppix` 也有助于你在嵌入式系统上进行 `Linux` 工作：你只需将 `Knoppix` 插入 `CD` 驱动器，可能并在 `USB` 接口插入外部存储设备（用于个人存储），就可以准备好在环境中工作了。完成后，带上你的芯片回家。你还可以挂载你拥有的本地资源。这很有趣。

`Gentoo` 有一些非常忠实的支持者。在 `Gentoo` 中（传闻，我从未用过），它有一套从源码进行编译/升级的系统（需要本地编译）。长时间的编译可能会浪费时间，但它们确实需要时间。生成的执行程序是针对你的硬件定制的，因此它们比更标准的**“始终预编译好的”**（二进制）发行版更快或体积更小。

`Core` 是另一个 `Linux` 发行版，显然面向于精美（且昂贵）的配置。`Core` 办公套件包括：`Wordperfect` 文字、`QuattroPro` 表格、`Core Presentations` 演示、数据库 `CoreDraw` 画画师……`Core Linux` 基于 `Debian`。它看起来很有前景，但不清楚 `Core` 与微软之间是什么关系（如果它是收了微软的钱才放弃它的话）。`Core Linux` 现在已经死灭了，我永远不会向任何人推荐它，因为它是一条死胡同。提到它的唯一理由是 `Core Linux` 从未获得过过多的关注，你可能仍然会听过它。这像是一个悲伤的故事，特别是对 `Calenda` 来说。

`Caldera` 也是另一个著名的发行版。据说它在企业用户中很受欢迎，拥有花哨（且昂贵）的配置工具以及其他企业机构。2000 年，`Caldera` 收购了 `SCO`（`UNIX` 的原始商标），这在我看来让它更加**“企业化”**。`Caldera` 似乎并不太关心家庭 `Linux` 用户，所以我从未考虑过将它用于家庭使用。在 2003 年初，`Caldera`（表现为 `SCO`）被不同的、可能更有利润的业务模式迅速驱逐（**“我将绝对避开任何带有 SCO 或 Caldera 名称的物品，因为我不喜欢为了支付 139 美元来获得在单处理器计算机上运行 Linux 的权利或被使用的想法。Caldera/SCO Linux 发行版没有未来。”**）

还有一些**“特殊用途”**发行版，例如 `Linux` 的**“实时”**版本，如果你处于自动化、机器人技术、高速采集（等）领域，它们可能很有用；非常小的发行版（如果你喜欢从单张软盘运行 `Linux` 的想法，这对于系统安全或恢复可能有用）；用于嵌入式系统的 `Linux`（如果你想将 `Linux` 定定义为**“特殊用途”**设备，这对于下一代音响、`MP3` 播放器、掌上电脑或手机手机可能很好）；并行计算和集群系统（如果你计划做气象预报——这可能很棒）或者至少是核爆炸模拟 `(:p)`，这里的差异会更大，但这些发行版并不是为了**“通用用途”**设计的。作为一个新手，你可能不想从其中任何一个开始，尽管你可能会被它们诱惑。（它们确实喜欢 `Linux` 的强大和可见性——`Linux` 运行在玩具上，甚至是手表上，以及目前世界上最先进系统的计算机集群上。）

你需要的发行版显然取决于你拥有的硬件平台。这意味着对于包含 `Intel 386` 处理器、或 `Intel 486`、`Intel Pentium`、`Intel 586`、`Intel 686`、`Cyrix`、或 `K6`、`AMD` 等的 `PC` 硬件，你需要一个名为**“Intel”**或**“386 x86”**的二进制发行版。`[除非你准备好从自己编译的 Linux 源码开始，这对于新手来说并不典型 :--)]` 这是因为对于其他硬件平台也有二进制发行版：`PowerPC`、`Alpha`、`Apple`、`IBM` 主机、`Intel StrongARM`、`Transmeta`，以及可能更密集的——你不会为你的 `PC` 兼容机获得这些二进制文件；它们显然无法在内部有**“Intel”**或**“AMD”**处理器的 `PC` 机器上运行。如果你没有 `Intel` 硬件，你可能想在互联网上查找谁支持它（`Debian` 除外），以查看最奇特的那些。你需要获取**“Debian ARM”**、**“Debian Motorola 680x0”**、**“Debian PowerPC”**或**“Debian SPARC”**。

简而言之，虽然没有与多个 `Linux` 发行版混淆，但有理由选择不同的商店。这应该被视为 `Linux` 的一种优势而非弱点。`Linux` 正在填充所有的应用程序和硬件平台。缺点是，如果你计划让你的业务依赖 `Linux`，有些**“奇特”**的发行版需要避开。

本指南专注于 `(Intel)` 平台的 `Redhat` 和 `Mandrake`。许多答案适用于其他发行版或平台，但我们没有尝试过它们。
