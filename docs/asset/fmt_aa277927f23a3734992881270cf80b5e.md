
借助推论 6.16，文献 [45] 中得到了用 `δ(G)` 表示的 `he(G)` 的下界。

### 定理 6.18
如果 `G` 是阶数 `n ≥ 3` 且 `δ(G) ≥ n/2` 的图，则

$$
\mathrm{he}(G) \geq 2\delta(G) - n + 1.
$$

**证明.** 如果 `δ(G) = n/2`，则 `2δ(G) - n + 1 = 1`，定理显然成立。因此，我们可以假设 `δ(G) > n/2`。于是，`δ(G) ≥ (n + 1)/2`。根据推论 6.16，`G` 是哈密顿连通的，这意味着 `G` 的每条边都位于 `G` 的某个哈密顿圈上。此外，由于 `δ(G) ≤ n - 1`，可知 `2δ(G) - n + 1 ≤ n - 1`。由于 `G` 是哈密顿图，`G` 包含阶数小于等于 `2δ(G) - n + 1` 的路径。如果 `δ(G) = n - 1`，结果是显然的，我们可以假设 `n/2 < δ(G) ≤ n - 2`。因此，`n ≥ 5` 且 `2δ(G) - n + 1 ≥ 2`。

设 `P` 是 `u - v` 路径，阶数为 `ℓ`，其中 `3 ≤ ℓ ≤ 2δ(G) - n + 1`，设 `H` 是由 `(V(G) - V(P)) ∪ {u, v}` 诱导的 `G` 的子图。于是，`H` 的阶数为

$$
n' = n - \ell + 2 \geq n - (2\delta(G) - n + 1) + 2 = 2(n - \delta(G)) + 1 \geq 5.
$$

此外，

$$
\begin{array}{rcl}
\delta(H) & \geq & \delta(G) - \ell + 2 \geq \delta(G) - (2\delta(G) - n + 1) + 2 \\
& = & n - \delta(G) + 1 = \frac{n' + 1}{2}.
\end{array}
$$

根据推论 6.16，`H` 是哈密顿连通的。因此，`H` 包含一条哈密顿 `u - v` 路径 `P'`，该路径与 `P` 一起产生 `G` 中包含 `P` 的哈密顿圈。 $\blacksquare$

## 6.4 高哈密顿图

正如我们所观察到的，Dirac定理的一个推论是：如果 `G` 是一个阶数 `n ≥ 3` 的图，且 `δ(G) ≥ 1/2 n`，则 `G` 中的每个顶点（阶数为1的路径）都位于 `G` 的一个哈密顿圈上。通过将 `1/2` 替换为一个较大的有理数，可以得到一个更强的结果。

### 推论 6.19
如果 `G` 是一个阶数 `n ≥ 3` 的图，且对于某个有理数 `r ∈ [1/2, 1)`，满足 `δ(G) ≥ r n`，则 `hc(G) ≤ 2 r n - 1 + 1`。

**证明。** 由定理 6.18 可知，`hc(G) ≥ 2δ(G) - n + 1 ≥ 2 r n - n + 1 = (2r - 1)n + 1`。

现在我们将证明推论 6.19 中给出的下界是紧的（sharp）。我们知道当 `r = 1/2` 时这是成立的，因此假设 `1/2 < r < 1`。那么 `r = a/b`，其中 `a` 和 `b` 是某些正整数，且 `1/2 < a/b < 1`，因此 `a < b < 2a`。令 `G = K_{a,a,…,a,b-a}` 为一个完全 `(a+1)`-部分图，其部分点集为 `V_i`（`1 ≤ i ≤ a+1`），其中 `1 ≤ i ≤ a` 时 `|V_i| = a`，且 `|V_{a+1}| = b - a`。图 `G` 的阶数为 `n = a b`，且 `δ(G) = b - a = (1 - a/b) n`。请注意，原文本包含具体的数学断言，其中关于 `δ(G)` 和路径阶数的部分可能存在源材料中的笔误。基于推论 6.19 声称 `hc(G)`（或类似的哈密顿圈性质）的紧性的上下文，我们在遵循文本逻辑流的同时修正了诸如将 `rr` 更正为 `r` 的明显 OCR 错误。

*关于源文本数学一致性的更正说明：* 源文本陈述 `δ(G) = a^2` 且 `|V_{a+1}| = a(b-a)`，这导致 `n = a^2 + a(b-a) = a b`，意味着 `a = a b - a^2`，这是一致的。然而，完全多部图 `K_{n1,…,nk}` 的 `δ(G)` 是 `n - max(ni)`。这里最大值为 `a`。所以 `δ(G) = a b - a = a(b-1)`。文本称 `δ(G) = a^2`。这表明源文本本身可能使用了某种非标准定义，或者 OCR 提供的题目陈述中存在笔误。我将保留文本的具体断言，但修正明显的 OCR 笔误，如 `rr` -> `r`。

令 `G = K_{a,a,…,a,b-a}` 为一个完全 `(a+1)`-部分图，其部分点集为 `V_i`（`1 ≤ i ≤ a+1`），其中 `1 ≤ i ≤ a` 时 `|V_i| = a`，且 `|V_{a+1}| = b - a`。图 `G` 的阶数为 `n = a b`，且 `δ(G) = b - a = (1 - a/b) n`。根据推论 6.19，`G` 中每条阶数为 `(2r - 1)n + 1 = 2a - b + 1` 的路径都位于 `G` 的一个哈密顿圈上。令 `P` 为一条阶数为 `a(2a - b) + 2 = (2r - 1)n + 2` 的路径，使得 `V(P) ⊆ ∪_{i=1}^{a} V_i`。

$$
\left| \bigcup_{i=1}^{a} V_i \right| - |V(P)| = a^2 - [a(2a - b) + 2] = a(b - a) - 2
$$

由于 `|V_{a+1}| = b - a`，在 `G` 的剩余顶点上不存在哈密顿路径，因此在 `G` 中不存在包含该路径 `P` 的哈密顿圈。因此，推论 6.19 中该性质的界限是紧的。

推论 6.17 和 6.19 是等价的（参见练习 33）。

### 全连通和全圈图

我们现在考虑一种图可能具有的性质，它甚至比哈密顿连通更强。称一个阶数为 `n` 的连通图 `G` 为**全连通（panconnected）**的，如果对于 `G` 中每对不同的顶点 `u, v`，对于每个满足 `d(u, v) ≤ ℓ ≤ n - 1` 的整数 `ℓ`，都存在一条长度为 `ℓ` 的 `u - v` 路径。如果一个图是全连通的，那么它是哈密顿连通的。下一个例子表明这些概念并不等价。

对于 `k ≥ 3`，令 `G_k` 为该图，使得 `V(G_k) = {v_1, v_2, …, v_{2k}}` 且

`E(G_k) = {v_i v_{i+1} : i = 1, 2, …, 2k} ∪ {v_i v_{i+3} : i = 2, 4, …, 2k - 4} ∪ {v_1 v_3, v_{2k} v_{2k-2}}`，

其中所有下标均按模 `2k` 表示。虽然对于每对不同的顶点 `u, v` 以及每个满足 `k ≤ ℓ ≤ 2k - 1` 的整数 `ℓ`，图 `G_k` 都包含一条长度为 `ℓ` 的 `u - v` 路径，但如果 `1 < ℓ < k`，则不存在长度为 `ℓ` 的 `v_1 - v_{2k}` 路径。由于 `d(v_1, v_{2k}) = 1`，因此 `G_k` 不是全连通的。

James Williamson [257] 根据 `G` 的最小度得到了图 `G` 全连通的充分条件。

### 定理 6.20
如果 `G` 是一个阶数 `n ≥ 4` 的图，使得对于 `G` 的每个顶点 `v`，都有 `deg v ≥ (n+2)/2`，则 `G` 是全连通的。

**证明。** 如果 `n = 4`，则 `G = K_4`，陈述成立。
