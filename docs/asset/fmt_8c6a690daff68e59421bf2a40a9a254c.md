
从系统中删除软件包，包括配置文件。

# 自动移除软件包

```bash
sudo apt autoremove
```

从系统中移除未使用的软件包及其依赖项。

# 列出已安装软件包

```bash
sudo apt list
```

列出系统中安装软件包。

# 添加存储库

```bash
sudo add-apt-repository repository
```

将存储库添加到 `sources.list.d` 文件夹。

# 移除存储库

```bash
sudo add-apt-repository -r repository
```

从 `sources.list` 文件夹移除存储库。

# 编辑源文件

```bash
sudo apt edit-sources
```

用默认文本编辑器打开 `sources.list` 文件。

# 修复依赖

```bash
sudo apt install -f
```

通过安装缺失或冲突的软件包尝试修复任何损坏的 `apt` 依赖。

# 获取软件包源码

```bash
sudo apt source package
```

从存储库下载软件包的源码。

# 升级系统

```bash
sudo do-release-upgrade
```

启动发行版升级并将操作系统移动到较新版本。

# 清理软件包

```bash
sudo apt clean
```

清理本地软件包缓存，重点是移除不再需要的 `.deb` 文件。

# 自动清理软件包

```bash
sudo apt autoclean
```

对本地软件包缓存进行自动清理，从而移除任何不再需要的 `.deb` 文件，且全程无需确认。

# 锁定 Apt 软件包

```bash
sudo apt mark-hold package
```

锁定软件包，使其在运行 `sudo apt upgrade` 命令时停止被更新。

# 解锁 Apt 软件包

```bash
sudo apt mark-unhold package
```

取消软件包锁定，从而允许其通过 `sudo apt upgrade` 进行更新。

# 显示已锁定的软件包

```bash
sudo apt-mark showhold
```

显示系统中所有已锁定或固定的软件包。

# 软件包验证

```bash
sudo apt-key verify
```

验证软件包存储库密钥的完整性并对其进行身份验证。

## Flatpak

# 安装 Flatpak

```bash
flatpak install flatpak
```

从远程仓库安装 `flatpak`。

# 列出已安装的 Flatpak

```bash
flatpak list
```

列出系统中已安装的 `flatpak`。

# 更新 Flatpak

```bash
flatpak update
```

将所有已安装的 `flatpak` 升级到最新的可用版本。

# 运行 Flatpak

```bash
flatpak run flatpak
```

运行已安装的 `flatpak` 应用。

# 卸载 Flatpak

```bash
flatpak uninstall flatpak
```

从系统中移除已安装的 `flatpak`。

# Flatpak 远程仓库列表

```bash
flatpak remote-list
```

列出已添加到系统的 `flatpak` 远程仓库。

# 添加 Flatpak 远程仓库

```bash
flatpak remote-add --if-not-exists name url
```

向系统添加 `flatpak` 远程仓库。

# Flatpak 远程仓库

```bash
flatpak remote-delete name
```

删除 `flatpak` 远程仓库。

## Snap

# 安装 Snap

```bash
sudo snap install
```

从 `snap craft` 数据库安装 `snap` 应用程序。

# 列出已安装的 Snaps

```bash
sudo snap list
```

列出系统中已安装的 `snaps`。

# 更新 Snaps

```bash
sudo snap refresh
```

将所有 `snaps` 升级到最新的可用版本。

# 运行 Snap

```bash
snap run snap
```

运行已安装的 `snap`。

# 删除 Snap

```bash
sudo snap remove snap
```

从系统中移除已安装的 `snap`。

# 搜索 Snaps

```bash
sudo snap find snap
```

在 `snapcraft` 数据库中搜索任何匹配搜索词的 `snaps`。

# 列出 Snap 信息

```bash
sudo snap info snap
```

提供有关系统中已安装 `snap` 的详细信息，例如安装版本、发布者、许可证和描述。

# 查看 Snap 连接

```bash
sudo snap connections snap
```

查看由已安装 `snap` 创建的连接。

# chown

# 更改文件所有权

```bash
sudo chown user filename
```

将文件或文件夹的所有权更改为命令中指定的用户。

# 递归更改所有权

```bash
sudo chown -R user filename
```

递归地将文件或文件夹的所有者更改为命令中指定的用户。

# 指定组更改所有权

```bash
sudo chown user:group filename
```

更改与文件或文件夹关联的用户组。

# 在抑制错误消息的情况下更改所有权

```bash
sudo chown -f user filename
```

更改文件或文件夹的所有权，如果操作未成功则抑制错误消息。

# 带详情更改所有权

```bash
sudo chown -v user filename
```

更改文件或文件夹的所有权，同时提供处理过程的各种详细信息。

# 带确认更改所有权

```bash
sudo chown -i user filename
```

更改文件或文件夹的所有权时请求确认。

# 保留时间戳更改所有权

```bash
sudo chown --preserve-timestamps user filename
```

在保留时间戳的同时更改文件所有权。

# chmod

# 更改文件权限

```bash
sudo chmod permissions filename
```

更改文件或文件夹的权限。

# 递归更改权限

```bash
sudo chmod -R permissions filename
```

递归地更改文件或文件夹的权限。

# 数字更改权限

```bash
sudo chmod numbers filename
```

根据数字更改文件或文件夹的权限，例如 `755`，以便所有者可以执行该文件。

# 递归更改数字权限

```bash
sudo chmod -R numbers filename
```

使用数字递归地更改文件或文件夹的权限。

# 带详情更改权限

```bash
sudo chmod -v permissions filename
```

更改文件或文件夹的权限，并显示有关更改的信息。

# 带确认更改权限

```bash
sudo chmod -i permissions filename
```

在更改文件或文件夹权限时请求确认。

# 通过引用文件更改权限

```bash
sudo chmod --reference=reference-file filename
```

更改文件或文件夹的权限以匹配引用文件的权限。

# dpkg

# 安装 .deb 软件包

```bash
sudo dpkg -i file.deb
```

安装 `.deb` 文件。

# 移除已安装的 .deb 软件包

```bash
sudo dpkg -r filename
```

从系统中移除已安装的软件包。

# 移除带文件的 .deb 软件包

```bash
sudo dpkg -P filename
```

从系统中移除已安装的软件包，包括配置文件。

# 列出已安装的软件包

```bash
sudo dpkg -l
```

列出系统中安装的所有软件包及其版本和描述信息。

# 列出软件包安装的文件

```bash
sudo dpkg -L package
```

列出系统中特定软件包安装的所有文件。

# 检查软件包依赖

```bash
sudo dpkg -l packagename.deb
```

检查并列出 `.deb` 软件包的依赖关系。

# 重新配置已安装软件包

```bash
sudo dpkg-reconfigure packagename
```

重新配置已安装的软件包。
