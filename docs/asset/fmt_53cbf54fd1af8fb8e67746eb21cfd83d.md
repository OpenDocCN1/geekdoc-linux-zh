
张量方程是将一种类型的张量等于另一种相同类型张量的方程。引力场方程通常涉及度规张量。黎曼张量 `$R^\alpha_{\beta\nu}$` 完全描述了空间的几何结构。如果它是零，空间就是平坦的；如果不是，空间就是弯曲的。在收缩场中，对 `$\alpha = \beta$` 黎曼张量求和，爱因斯坦场方程设置为：

```
R_{\mu\nu} = 0  (真空)  (6)
```

场方程是一组关于具有十个独立分量的四对称张量 `$R_{\mu\nu}$` 的十个二阶偏微分方程；需要求解度规 `$g_{\mu\nu}$`，它定义了弯曲空间的几何结构。该空间的曲率对应于引场的内在属性。因此，弯曲空间中的机械力概念被广义相对论的概念取代。

在非空空间中，必须修改场方程以包含代表空间物质或能量内容的动量张量。修改后的方程为公式(7)，其中 `$T_{\mu\nu}$` 是引源。

```
G_{\mu\nu} = -8π/c^4 T_{\mu\nu}  (非空空间) (7)
```

等于 `6.67 × 10^{-11} m^3 kg^{-1} s^{-2}$`。`$G_{\mu\nu}$` 张量代表空间的几何，右侧的 `$T_{\mu\nu}$` 代表空间的质量或能量内容。

### 宇宙常数
爱因斯坦在1916年以公式(7)的形式给出了场方程。在这里可以通过在另一侧添加另一个项来推广，他将其称为宇宙常项，`$\Lambda g_{\mu\nu}$`。更通用的场方程为：(8)。

```
G_{\mu\nu} + \Lambda g_{\mu\nu} = -8π/c^4 T_{\mu\nu} (8)
```

常量 `$\Lambda$` 被称为宇宙常数。爱因斯坦在1917使用宇宙常数是为了使宇宙模型保持静态，因为他相信宇宙是静态的。1929年根据遥远星系的发现观测到宇宙正在膨胀。爱因斯坦放弃了宇宙常项。然而，由于广义相对论与宇宙量子理论有关，对宇宙常数的兴趣仍然存在，且此后的观测表明该常数可能存在。

## 1892 磁阻电机

继电器 - 一种电磁或固态器件，通过输入的变化来转动或控制连接到输出端的其他设备。它们被广泛应用于工业的各个场合中，例如交换机、数字计算机、电机序列系统和自动化系统。高度复杂的继电器用于保护电路免受过量反向电动势的影响，并控制电力的产生和分配。在家庭中，继电器用于冰箱、空调、洗碗机和热泵。继电器通常与电控装置配合使用，有许多类型，例如气动和液压。它们可以通过机械方式直接操作和输出，或者反之亦然。

对于磁场 `$H$` 中任何长度为 `$l$` 的闭合路径，`$H d\alpha$` 的积分是该路径的磁动势，如公式 (1) 所示，其中 `$\alpha$` 是

```
mmf = \int H d\alpha (1)
```

```
mmf = \int H d\alpha = NI (2)
```

## 可靠性、可用性与可维护性

可靠性是指工程系统（从客户角度看）在指定的环境和运行条件下，在其寿命内执行其预期功能的概率。可维护性是指系统在给定时间内保持运行状态或返回特定状态的概率。可用性是在特定时刻和需要时运行状态满意的概率。可靠性理论对于理解系统的可靠性、可用性和维护性至关重要。参见可靠性。

### 可靠性 - 基本设计参数

可靠性是一个基本设计参数，必须纳入系统设计中。它是系统的固有特性；就像功率额定或产品服务的质量一样，可靠性是一种面向时间的质量特征。可靠性是客户与系统有效性满意度（包括可靠性和可维护性）之间的关系。参见可维护性；可靠性。

为了分析和测量系统的可维护性，可以使用系统的数学模型，显示所有组件、子系统和整个系统之间的功能关系。功能的可靠性就是其组件的可靠性。可靠性模型可以由可靠性框图或因果链组成，包含所有设备故障和分布的细节，以及备件和维修策略的说明。对系统的每种模式进行应用可靠性分析。

### 可维护性
衡量故障后设备恢复到指定状态的容易和快速程度。它是设备设计和可用性的特性，取决于所需的技能水平以及进行维护的环境。可维护性表示为项目在给定时间内保持运行或恢复到特定状态的概率。

**多光谱图像。** 多光谱扫描通过传感器（而非通过摄影）记录电磁谱中几个可见光和近红外波段的光谱反射率。

在卫星应用中，光学传感由一组范围从 0.2 到 1.1 微米的传感器阵列提供。当不同频段的光学传感器在与卫星飞行方向平行的平面上扫描通过地形时，它们接收来自地面的图像。

每个光谱波段通过分类元素或像素进行区分，并在模拟或数字磁带上记录单独的反射率。每个像素都可以实时电子化传输到接收站，或者存储在卫星的磁带上直到飞过基站。当接收到信号时，它几乎会瞬间处理成等同于传统航空照片的虚拟图像。
