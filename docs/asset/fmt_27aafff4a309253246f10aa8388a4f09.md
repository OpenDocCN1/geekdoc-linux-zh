SaaS 是通过提供对虚拟机的访问来共享云服务器资源，这些虚拟机实际上是作为主机上的客户运行的多个操作系统，它们通过一个被称为 `hypervisor`（虚拟机监控器）的重要软件进行连接。`hypervisor`负责通过隔离和管理主机上的可用资源给这些客户，从而使这些客户操作系统能够运行。这就是我们说的虚拟化。在 IaaS 模型中，你只需为你基础设施所使用的部分资源付费。

另一方面，PaaS 在技术和概念上都建立在 IaaS 模型之上。在 PaaS 中，用户访问的不是虚拟机，而是一个平台，可以在平台上部署和运行他们的应用程序。这里的目标是减轻处理系统管理和操作系统更新的负担。Heroku 是一个常见的 SaaS 示例，可以在那里运行程序代码而无需担心底层容器和虚拟机。

最后，SaaS 是你通常支付订阅费用以便使用软件而不担心其他任何事情的模型。Dropbox 和 Salesforce 是 SaaS 的两个示例。

大多数这些服务通过 Web 浏览器访问。

## 使用互联网时的隐私问题

Web 浏览器是任何桌面电脑上的一项基础软件，但某些人仍然缺乏安全使用它的知识。虽然有越来越多的服务通过浏览器访问，但通过浏览器执行几乎所有操作都会被各方跟踪和分析。保护互联网服务的安全并防止跟踪是使用互联网的一个重要方面。

## Cookie 追踪

假设你浏览了一个电子商务网站，选择了一个你想要的产品并将其放入购物车。但在最后一刻，你决定再考虑一下，并多想一会儿是否需要它。一段时间后，你开始在网上各处看到同一个产品的广告。当你点击这些广告时，会被立即发送到该商店的页面页面，购物车仍在那里等待你查看。你是否曾想过他们是如何做到的？他们如何在另一个网页上向你展示正确的广告？这些问题的答案就是 Cookie 追踪。

Cookies 是网站保存在你的计算机上的小文件，用于存储和检索对你的导航有用的某些信息。它们已经存在多年，是客户端存储存储数据的最老的方法之一。其中一个很好的例子是唯一的购物车 ID。这样，如果你在几天后回到同一个网站，商店就可以记住你上次访问时放入购物车的产品，并节省你寻找它们的时间。

这通常是可以接受的，因为网站为你提供了有用的功能而没有向第三方共享任何数据。但当你在其他网页浏览时显示给你的广告又是呢？这就是广告网络发挥作用的地方。

但他们如何知道向你展示什么产品呢？他们通常通过也保存一个 Cookie

来自你访问或在电子商务网站上搜索特定产品时所看到的广告。通过这种方式，网络能够在任何有广告的地方检索有关该 cookie 的信息，并将其与你感兴趣的产品建立联系。这通常是互联网上追踪某人的最常见方法之一。我们提供的示例利用电子商务平台让这一切变得更具象，但社交媒体平台通过其“点赞”或“分享”按钮以及社交登录实现了同样的功能。

你可以消除这一点的一种方法是不允许第三方网站在你的浏览器中存储 cookie。这样，只有你访问的某个网站可以存储它们的 cookie。但请注意，如果你这样做，某些“合法”功能可能无法正常工作，因为现在许多网站都依赖第三方服务来运行。因此，你可以在浏览器的扩展库中寻找 cookie 管理器，以便对存储在机器上的 cookie 进行精细化控制。

## 请勿追踪 (DNT)

另一个常见的误解与一种名为 DNT 的浏览器配置有关。DNT 是“Do Not Track”（请勿追踪）的缩写，可以在任何当前浏览器上开启。与隐私模式类似，并不难找到那些认为只要开启了此配置就不会被追踪的人。遗憾的是，事实并不总是如此。目前，DNT 只是你告诉你访问的网站，你不希望他们追踪你的一种方式。但事实上，决定是否尊重你的选择的是网站本身。换句话说，DNT 是一种退出网站追踪的机制，但这种选择并无保证。

从技术上讲，这是通过简单地在 HTTP 请求协议标头中发送一个额外的标记来实现的（在向 Web 服务器请求数据时发送 DNT）。如果你想了解更多关于这个主题的信息，网站 https://allaboutnt.com 是一个很好的起点。

## “隐私”窗口

你可能注意到了上面标题中的引号。这是因为这些窗口并没有人们想象中那么私密。它们可能有所不同，但根据你正在使用的浏览器，它们可以被称为“隐私模式”（private mode）、“无痕模式”（incognito）或“匿名”（anonymous）标签页。

在 Firefox 中，你可以通过按下 `Ctrl` + `Shift` + `P` 键轻松使用它。在 Chrome 中，只需按下 `Ctrl` + `Shift` + `N`。它的实际上是打开一个全新的会话，它不会共享你标准个人配置中的任何配置或数据。当你关闭隐私窗口时，浏览器会自动删除由该会话产生的所有数据，在使用的计算机上不留任何痕迹。这意味着没有任何个人数据（如历史记录、密码或 cookie）存储在该计算机上。

因此，许多人误解了这一点，认为他们可以在互联网上匿名浏览，这并不完全真实。隐私模式或无痕模式的作用是避免我们所说的 cookie 追踪。当你访问一个网站时，它可以在你的计算机上存储一个小型文件，该文件可能包含一个用于追踪你的 ID。除非你配置浏览器不接受第三方 cookie，否则广告网络或其他公司可以存储并检索该 ID，并实际上跨网站追踪你的浏览。由于存储在隐私模式会话中的 cookie 在你关闭会话后就会被删除，这些信息就会丢失。

此外，网站和互联网上的其他同仍然可以使用其他技术来追踪你。因此，隐私模式为你提供了一定程度的匿名性，但在你正在使用的计算机上它是完全私密的。如果你从公共计算机（如机场或酒店）访问你的账户或银行网站，你绝对应该使用浏览器的隐私模式进行访问。在其他情况下，可能会有好处，但你应该准确知道你正在规避什么，哪些是无效的。每当你使用公共可访问计算机时，请意识到可能存在恶意软件或键盘记录器等其他安全威胁。在此类计算机上输入个人信息（包括用户名和密码）或下载、复制机密数据时，请务必小心。

## 选择正确的密码

任何用户面临的最困难的情况之一，就是为他们使用的服务选择一个安全的密码。你以前听过你不应该使用像 `qw`、`123456` 或 `654321` 这样的常用组合，也不要使用易猜的数字，如你（或亲属）的生日或邮政编码。原因是这些都是显而易见的组合，而第一次尝试就会邀请入侵者获取你账户的权限。

创建安全密码有已知的技术。其中最著名的方法之一是编造一个让你想起该服务的句子，并选取每个单词的首字母。假设我想为 Facebook 创建一个良好的密码。在这种情况下，我可以构思一句如 "I would be happy if I had hundred like Mike" 这样的句子。取每个单词的首字母，最终生成的密码将是 `Iwbi1Ha100fIM`。这产生了一个 15 个字符的密码，它足够长，难以被破解，同时又容易记忆（只要我还能记住那个句子以及提取密码的“算法”）。

现如今，句子通常比许多服务的密码更容易记忆，而且我们使用它们的频率各不相同，这最终会导致我们在需要时很难记住所有的句子。那么我们能做什么呢？你可能会说，在这种情况下最明智的做法是创建一个良好的密码并在相似的服务上重复使用它们，对吧？

遗憾的是，这也不是一个好主意。你也听过你不应该在不同服务之间重复使用密码。问题在于，如果一个服务被攻破，你所有的账户都会受到损害。密码管理器是一种软件，它以加密格式存储你所有的用户名。这样，你只需要记住一个主密码，因为管理器将保管所有的密码。

# TLS

传输层安全协议（TLS）是一种通过密码学技术为网络连接提供安全性的协议。TLS 是安全套接层（SSL）的继任者，SSL 已由于多个缺陷被弃用。TLS 经过几次演进以适应自身并变得更加安全，因此其当前版本是 1.3。它通过利用所谓的对称加密和公钥加密来同时提供隐私性和真实性。换句话说，这意味着在使用的过程中，你可以确保没有人在该会话期间能够窃听或篡改你与该服务器的通信。

这里最重要的教训是识别一个网站是否是信赖的。你应该寻找浏览器地址栏上的“锁”形符号。如果你愿意，可以点击它来检查在 HTTPS 协议中起着重要作用的证书。

TLS 用于 HTTPS 协议（基于 TLS 的 HTTP），以便使其能够通过 网发送敏感数据（如你的信用卡号）。解释 TLS 的工作原理超出了本文的范畴，但你可以在维基百科上找到更多信息。

# 使用 GnuPG 进行文件和电子邮件加密

有很多用于保护电子邮件的工具，但其中最重要的工具无疑是 GnuPG。GnuPG 代表 GNU Privacy Guard，它是 OpenPGP 的开源实现，是经过 RFC 4880 的国际标准。

GnuPG 可用于签名、加密和解密文本、电子邮件、文件、目录甚至磁盘分区。它与公钥加密配合工作并广泛可用。简而言之，GnuPG 创建了一个包含你的公钥和私钥的文件对。如名称所示，公钥可以提供给任何人，而私钥需要保持保密。人们将使用你的公钥来加密数据，只有你的私钥可以进行解密。

你也可以使用你的私钥对任何文件或电子邮件进行签名，并可以使用相应的公钥进行验证。这种数字签名等同于现实世界的签名。只要你是唯一拥有自己私钥的人，接收方就可以确定它是由你编写。通过利用密码学哈希功能，GnuPG 还会保证签名后没有发生任何更改；内容的任何更改都会使签名失效。

GnuPG 是一个非常强大的工具，在某种程度上它也是一个复杂的工具。你可以在它的网站和 Archlinux wiki 上找到更多信息（Archlinux wiki 是一个非常好的信息源，即使你不使用 Archlinux）。

# 磁盘加密

保护数据的一种良好方法是加密你的整个磁盘或分区。有很多开源软件可以用来实现这种目的。它们的工作原理以及它们提供的加密水平也有显著差异。目前有两种基本方法：堆栈加密和块设备加密。

堆栈文件系统解决方案实现在现有文件系统之上。当使用这种方法时，文件和目录在存储到文件系统之前会被加密，在读取它们之后会被解密。这意味着文件以加密的形式存储在主机文件系统中（这意味着它们的内容，通常还包括它们的文件/文件夹名称被替换为看似随机的数据），但除此之外，它们仍然像没有加密时一样存在存在于文件系统中，作为普通文件、符号链接、硬链接等。

另一方面，块设备加密发生在文件系统层之下，使得写入块设备的所有内容都被加密。如果你在块离线状态下查看它，它看起来像是一大段随机数据，在先进行解密之前，你甚至无法判断那里是什么种类型的文件系统。这意味着你无法判断什么是文件或目录；不知道它们有多大以及什么类型的数据；元数据、目录结构和权限也被加密了。

这两种方法都有自己的优缺点。在所有可用选项中，你应该查看 `dm-crypt`，它是 Linux 系统块加密的事实标准，因为它是内核原生的。它可以与 `LUKS`（Linux 统一密钥设置）扩展一起使用，`LUKS` 是一个实现了用于各种工具的平台无关标准的规范。

如果你需要一种堆栈方法，你应该查看 `EncFS`，它可能是 Linux 上保护数据最简单的方法，因为它的实现不需要 root 权限，并且可以在不修改的情况下在现有文件系统上运行。

最后，如果你需要在各种平台上访问数据，请查看 `Veracrypt`。它是 TrueCrypt 的继任者，允许创建加密媒体和文件，这些文件可以用于 Linux 也可以用于 macOS 和 Windows。
