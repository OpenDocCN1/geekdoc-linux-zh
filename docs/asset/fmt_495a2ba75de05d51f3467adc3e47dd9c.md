### xsri

`xsri` 程序允许在根窗口显示文本、段落和图像，因此用户可以更改登录界面的 `XDM` 样式和/或 X 背景。如果您想更改登录和/或 X 背景，请安装 `xsri`。它也用于显示默认背景（Red Hat）。来自 RedHat 8.0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index`

### starfish

X 壁纸生成器。`starfish` 根据数学函数提供的随机数生成彩色、平铺的图像。它不使用源图像，因此可以无限地生成图像而不会耗尽材料。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index`

### xstcmap

### xsu

允许用户以 root 身份运行命令，并提示密码。`xsu` 是 Gnome 中命令 `su -- username -c command` 的接口。当用户执行 `xsu` 时，系统会提示输入命令、用户名和密码。如果用户输入不正确，`xsu` 将以输入的用户身份执行命令。因此，如果用户输入错误，命令将以 root 身份执行。还可以通过在 `xsu` 命令行使用 `[-u,--username]` 和 `[--c,--command]` 参数重新用户名和命令。这在示例 gnome 面板中使用 `xsu` 时非常有用。Gnome Xsu 2.0 使用标准二进制文件获取 root 权限。任何安全问题应得到解决。所有 `xsu` 版本的安全性都很差。在 `xsu` 0.1.0 中，引入了使用管道创建非 Gnome SUID 应用程序。这已被来自 'login' 包的 GNU 应用程序特殊类型管道取代。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index`

### sysinfo

以图形形式显示某些内核参数。此客户端类似于 `top`、`free` 和 `x` 的结合，值以水平条的形式显示。显示的值为：CPU 负载、CPU 空闲率和交换分区大小。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index`

### xt-catalog

为 XSLT 处理器 `XT` 提供目录支持和封装。此包提供了一个简单的端到端接口，用于 XL 样式表处理源文件。SGML 目录支持由修改后的 `XT` 命令行驱动程序类版本提供。还包含一个用于通用 `XT` 用的封装脚本。此包适用于处理 DocBook XML 源文件。Norman Walsh <ndw@walsh.com>: 主页: `http://www.arnetext.com/Tank/XML_Resources/Issue_3/body_issue_theme.html`。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

## xtail

类似于 `tail -f`，用于被截断的文件和目录，`xtail` 监控文件的增长。它就像对一组文件运行 `tail -f`。它会检测文件是否被截断，并从从头开始监控。当你指定一个目录时，它会监控该目录下的所有文件。当新文件被创建（开始监控）或旧文件被删除（停止监控）时，它会通知你。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

## xtalk

BSD `talk` 是 X 窗口系统客户端程序。`xtalk` 是一个视觉通信程序，可以将文件从你的终端复制到另一个用户的终端。这是用 Python 编写的 X 窗口系统版本。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

## xtartan

显示 `xtartan` 的程序在 X 窗口或根窗口中显示 `xtartan`（格纹）。它可以为 WWW 页面编写图像。程序包含了超过 240 种格纹的库，你也可以添加自己的。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`
