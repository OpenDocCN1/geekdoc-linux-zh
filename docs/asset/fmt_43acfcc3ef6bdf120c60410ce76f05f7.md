### asterisk
开源程路交换 (PBX) 是一种开源程路交换 (PBX) 和电话开发平台，它可以取代传统的 PBX，并作为开发自定义电话应用的平台，用于通过 CGI 和 Web 服务器向任何能够通过 Web 服务器传递动态内容的人通过电话传递动态内容。Asterisk 使用 BRI、POTS 和 IP 电话客户端通过星际间协议（例如，电话或更多）与各种硬件通信。有关更多信息和受支持硬件的当前列表，请参见 http://www.asteriskpbx.com。源自 Debian 3.0r

### atari-fdisk-cross
用于 Atari（运行在非 Atari 设备上）的磁盘分区编辑器。该 `fdisk` 工具允许你创建和编辑以 Atari 格式分区的磁盘的分区表。它支持 Atari 格式的 AHDI 5.0 和 ICD 变体。它是一个交互式工具，具有与 PC `fdisk` 相似的菜单界面，并支持 PC `fdisk` 的大多数选项。来自 Debian 3.0r0 APT

http://www.tldp.org/LDP/Linux-Dictionary/html/index

### atari800
用于 sgalib/Curs 的 Atari 模拟器。这是一个可以使用 SVGALIB 或普通 curs 的 Atari 模拟器。它支持 Atari 800、800XL、130XE 和 5200 系统。由于版权原因，该软件包不包含 Atari 操作系统 ROM。你必须从旧的 Atari 计算机上拷贝，或者查看 README.Def 获取其他获取方法。来自 Debian 3.0r0 APT

### aterm
Afterstep XVT - 一个用于 Window 系统的 VT102 模拟器。Atem 是基于 rxvt 2.4 的彩色 vt102 终端模拟器，具有快速透明等某些功能，作为不需要 Tektron 4014 仿真和工具包风格可配置性等用户的 xterm 替代品。因此，aterm 使用的空间较少——这对于运行许多会话的机器来说是一个显著优势。它是为 Afterstep 窗口管理器设计的，但不绑定于任何库，可以在任何地方使用。来自 Debian 3.0r0 APT

http://www.tldp.org/LDP/Linux-Dictionary/index.html
