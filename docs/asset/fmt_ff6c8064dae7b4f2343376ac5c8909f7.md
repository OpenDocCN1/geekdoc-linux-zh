```
R$* < @ $* : $* $1 < @2

R$* @ $* $1 @2 让它们全部相同。

## 规则集 96 - 规则集的后半部分

```
S96

# 处理本地名称的特殊情况
R$* < @ $* $1 < @2 完全没有 @ 符号
R$* < @ .m $* $1 < @2 域名
R$* < @ $+] $* $1 < @2 $3 标记 a.b.d
R$* < @ @ $* $0 < @2 $3 自定义字面量

# 在表中查找域名
RS* < @ $+ $* $:1 < @ (domable $2 $)

# 传递给名称以进行规范化
pass to name to make canonical

# 处理带加号的用户，以便别名能够正常工作
R$+ + *          $$local $0 $\$&h: $1
R$+ + $*          $$local $0 $2: $1 + *

# 在前面添加一个空的“转发主机”
RS$ - < > $1

# 将未识别的本地用户发送到中继主机
#RC < > + $*      $: < L . $(user $1 $) + $2
#RC < > $+      $: < L . $(user $1 $)      查找用户
#RC $* < > $*    $: < $2 $3               找到；去除 L
#RC $* . > $+    $: < $1 $2               去除多余的点

# 处理带加号的本地名称
RC < > + $* $$local $0 $2: $1

# 检查我们是否有中继主机或集纽
RC < > $+      $: < $RH $1               尝试集纽
RC < > $+      $: < $RH $1               尝试中继
RC < > $+      $:0 $1                    没有，放弃
RC - : $+ > $++    $:0 $95 $1 $2 $3 < > $2
RC < > $+      $:0 $95 $1 $2 < > $1
```

## 规则集 95 - 将邮件发送器:主机语法规范化为三部分

```
S95

## 规则集 93 - 将标头名称转换为伪装形式

```
S93
RS=E < @LOCAL*> $0 $1 < @Sj . 留作暴露
RS=E < @S=M . $0 $1 < @S2 . .
RS=E < @S=w . $0 $1 < @S2 . .
RS* < @S-M > $* $: $1 < @S2 . @SM > $3 转换伪装域名
RS* < @S=w > $* $: $1 < @S2 . @SM > $3
RS* < @LOCAL*> > $* $: $1 < @Sj . @SM > $2
RS* < @S+ > $* $0 $1 < @S2 > $3 $SM 为空
RS* < @S+ > @S+ > $* $0 $1 < @S2 > . 4 $SM 不为空
```
