如果以此为基础创建一个 shell 脚本（它只是系列你可能直接输入到 shell 的命令，都整齐地保在一个文件中），那就太好了。一个 shell 脚本可以显示每个文件的第一行和最后一行，并去掉中间部分。条目如下：

```
echo filename=

head -5 filename; tail -5 filename
```

我将结合 `vi` 中的 `!` 命令和 `awk` 命令来实现此：

```
awk "{ print \"echo \"$0;\"$4 bytes... tail $8\" }"
```
