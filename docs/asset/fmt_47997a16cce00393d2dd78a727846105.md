# 增强你的网络防御技能

如我们之前看到的，你可以使用上一个命令末的 `>> {file_name}` 选项将结果导出到 `.txt` 文件，以便发送给服务器所有者（尽快获取漏洞）。此外，将文件导出为 `.txt` 文件作为审计证据是非常好的。

使用网络映射主工具 – `Nmap` 245

5. 一旦安装完成，运行该脚本非常简单：

```
nmap -sV --script vulcan/scipag_vulcan/vulscan.nse

scanme.nmap.org
```
