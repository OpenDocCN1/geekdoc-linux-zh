# 有用文件

```perl
# 去掉用户提供的值末尾的回车符
# Perl 的处理非常字面化
chomp($firstname); chop($lastname);
chomp($address1); chop($address2);
chomp($citystatezip); chop($phoneno);
```

```perl
# split 根据第一个参数将内容 
# 分成数组。城市、州、邮政编码之间的逗号
# 让我们能够通过拆分成一个包含
# [城市][] 州 邮编 的数组来提取城市
@splitaddress = split(/,/$citystatezip);
$city = $splitaddress[0];
```

```perl
# 现在我们需要分离州和邮政编码 - 使用空格
# 注意它前面有一个空格，所以
# 结果是 [][][州][邮编]
@msplitaddress = split(/,/$splitaddress[1]);
$state = $msplitaddress[1]; zip = $msplitaddress[2];
```

```perl
# 在空字符串上拆分名字，以创建一个字母
# 数组。通过名字的第一个字符和
# 姓氏的全部来构建潜在的用户名。
# 在 Perl 中，点号 (.) 是连接操作符。
@nameletters = split(/,/$firstname);
$userid = $nameletters[0] . $lastname;
```

```perl
# 将 userid 转换为全小写
$userid =~ tr/[A-Z]/[a-z]/;
```
