
# 频闪镜

一种通过使运动物体间歇可见，从而产生其静止的光学错觉来观察运动物体的仪器。频闪镜可以通过用明亮的光脉冲照射物体，或在观察者和物体之间施加间歇快门来工作。

频闪镜用于测量机械部件或系统的旋转速度或振动频率。与其他仪器相比，它们的优点是加载或干扰正在测试的设备。借助频闪镜，可以在实际运行条件下观察机械设备。寄生振荡、缺陷和高速度下的不期望变形容易检测到。

闪光式频闪镜使用气体放电管来提供持续时间极短的明亮光源。根据所需的光输出量，管子可以从霓虹辉光管到能够产生数十万坎德拉闪光且持续时间仅为几百万分之一秒的特殊频闪灯管不等。参见[霓虹辉光管](https://example.org/neon_glow_lamp)；[蒸气灯](https://example.org/vapor_lamp)。[A.R.E.]

## 频闪摄影

频闪或“strobe”摄影通常指由电气放电产生的光脉冲拍摄的单一和多次曝光照片。最初，该术语指使用频闪装置作为快门拍摄的多次曝光照片。现代频闪摄影的一个基本特征是短曝光时间，通常比机械快门能获得的时间短得多。

使用频闪光的高速摄影已被证明是工程和科学中观察快速运动的最强大研究工具之一。同样，在非填充闪光灯中产生光脉冲的电气系统对影棚、抓拍和新闻摄影具有极大效用。参见[摄影](https://example.org/photography)；[频闪镜](https://example.org/stroboscope)。[H.E.E.]

# 叠层石

碳酸盐岩（石灰岩和白云岩）中的层状微生物结构。叠层石是地球上至少25亿年前的生命宏观证据，并且它们目前仍在海水中形成。在海洋无脊椎动物出现前的15亿年地球历史中，叠层石是最明显的生命证据，并在其余地质记录中零星出现。在密苏里州和非洲，叠层石礁含有大量的铅、锌或铜；在蒙大拿州、新墨西哥和阿曼，叠层石存在于油气储层中。对地质学家来说，叠层石的形状是其环境条件的有用指示，而在缺乏无脊椎动物化石的最古老沉积岩中，层状构造的形态和微观结构变化可能具有年龄诊断意义。参见[白云石](https://example.org/dolomite)；[石灰岩](https://example.org/limestone)；[礁](https://example.org/reef)。

在露头中，叠层石通过其特征性的向上凸起的层状结构容易识别。单个新月形的层状结构通常厚约一毫米，聚集在一起产生巨大范围的形状和尺寸。

构成现代叠层石的微小丝状蓝藻（蓝绿藻）以及与已知最古老叠层石相关的类似物种，被认为是地球上最成功的生物之一。巴哈马和澳大利亚西部的活叠层石具有记录微生物席间歇性捕获和粘结沉积物颗粒的层状结构。在现代海洋中，叠层石几乎仅在排除或威慑食草无脊椎动物和鱼类破坏微生物席并抑制竞争性藻类定殖的极端海洋条件下发育。参见[藻类](https://example.org/algae)；[蓝藻](https://example.org/cyanobacteria)。[R.G.I.]

# 叠层海绵目

一个已灭绝的目，因其与硬骨海绵纲的密切相似性而被认为是海绵。一般认为，叠层海绵最早出现在中奥陶世初期，在泥盆纪末期灭绝。叠层海绵全球分布，通常与层状石灰岩和化石礁相关。

叠层海绵骨骼称为共骨层，它从一层称为外骨骼层（perthescale）的不规则杆和板开始发育。大多数共骨层是半球形的，或厚的层状或透镜状结构。然而，一些叠层海绵薄而不规则波动，其他则是圆柱形、锥形、分枝或吻合的。参见[硬骨海绵纲](https://example.org/sclerospongiae)。[J.S.H.J]

# 强相互作用

一种基本物理相互作用，作用于强子对之间。强子包括核子（即中子和质子）；奇异重子，如 lambda ($\Lambda$) 和 sigma ($\Sigma$)；介子，如 pion ($\pi$) 和 rho ($\rho$)；以及奇异介子，kaon ($K$)。这种相互作用的性质主要通过观察强子对的碰撞来确定。由此发现，这种相互作用具有约 $10^{-15}$ m（$10^{-13}$ in.）的短程性，并在这个范围内是远占主导的力，远大于其次的电磁相互作用。强相互作用守恒宇称，并且是时间反演不变的。参见[重子](https://example.org/baryon)；[强子](https://example.org/hadron)；[介子](https://example.org/meson)；[核子](https://example.org/nucleon)；[宇称（量子力学）](https://example.org/parity_quantum_mechanics)；[奇异粒子](https://example.org/strange_particle)；[对称定律（物理学）](https://example.org/symmetry_laws_physics)；[时间反演不变性](https://example.org/time_reversal_invariance)。

# 鞭虫目

鞭虫目是一纲线虫，其头部区域可能带有三个或六个唇状结构，或者唇状结构可能被放射状冠所取代。鞭虫线虫是寄生性的。该目包含八个总科：Stronguloidea（强线虫总科）、Diphanocephaloidea（双头线虫总科）、Anisostomatoidea（异口线虫总科）、Trichostrongyloidea（毛圆线虫总科）、Metastrotongyloidea（后旋毛线虫总科）、Cosmocercoides（宇宙尾线虫总科）、Oxyuroidea（尖尾线虫总科）和 Heterakoidea（异线虫总科）。

`Strongyloidea（毛圆线虫总科）`。毛圆线虫总科包含爬行动物、鸟类和哺乳动物的重要寄生虫。早期幼虫阶段可能是自由生活的微虫形，但成虫总是寄生的。有三种物种是马匹的重要寄生虫：`Strongylus vulgaris`（普通马毛圆线虫）、`S. equinus`（马毛圆线虫）和 `S. edentatus`（无齿马毛圆线虫）。这三种虫经历直接生活史，即感染是通过摄取受污染的食物获得的。

`Trichostrongyloidea（毛圆线虫总科）`。Trichostrongyloides 包括除鱼类外所有脊椎动物的寡口式寄生虫。它们通常是肠道寄生虫，但有些在肺中发现。该物种是绵羊、牛和山羊的重要寄生虫。雌虫在肠道中产卵，卵随粪便排出。在有氧环境中，卵在几天内孵化。当幼虫被合适的宿主吞食时，它们失去保护鞘，并通过第四个幼虫阶段在肠道中发育至成虫，此时它们可能进入黏膜。在胃肠道外不发生迁移。

`Metastrotongyloidea（后旋毛线虫总科）`。后旋毛线虫总科包括陆地和海洋哺乳动物的寡口式寄生虫，常见于呼吸道。在其生活史中，它们利用中间宿主和转续宿主，其中包括各种无脊椎动物，如蚯蚓和软体动物。两个重要的物种是 `Metastrotongylus spir`（猪肺线虫）和 `Anacystrotongylus cantercanus`（啮齿类肺线虫）。
