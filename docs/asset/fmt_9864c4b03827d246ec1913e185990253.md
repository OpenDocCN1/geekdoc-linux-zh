
# 使用多个字体集绘制文本

要在绘制区域中使用多个字体集绘制文本，我们使用 `XmbDrawText` 或 `XwcDrawText`。

```c
void XmbDrawText(display, d, gc, x, y, items, nitems);
void XwcDrawText(display, d, gc, x, y, items, nitems);
```

- `display` 指定 X 服务器。
- `d` 指定可绘制区域（drawable）。
- `gc` 指定 GC。
- `x` `y` 指定 x 和 y 坐标。
- `items` 指定文本数组。
- `nitems` 指定文本项的数量。

`XmbDrawText` 和 `XwcDrawText` 使用为指定字体集加载的字体，返回指定文本每个字符的文本尺寸。`ink_array_return` 和 `logical_array_return` 的每个后续元素被设置为后续字符的绘制度量，相对于提供的文本字符串中字符串和每个字符的绘制起点。

填充矩形是对于相同的文本和 `XFontSet`，`XmbTextExtents` 和 `XwcTextExtents` 返回给 `overall_logical_return` 的矩形。

# 使用单个字体集绘制文本

要在绘制区域中使用单个字体集绘制文本，我们使用 `XmbDrawString` 或 `XwcDrawString`。

```c
void XmbDrawString(display, d, font_set, gc, x, y, string, num_bytes);
void XwcDrawString(display, d, font_set, gc, x, y, string, num_wchars);
```

- `display` 指定 X 服务器。
- `d` 指定可绘制区域。
- `font_set` 指定字体集。
- `gc` 指定 GC。
- `x` `y` 指定 x 和 y 坐标。
- `string` 指定字符字符串。
- `num_bytes` 指定字符串参数中的字节数。
- `num_wchars` 指定字符串参数中的字符数。

`XmbDrawString` 和 `XwcDrawString` 函数使用前景像素绘制指定文本。当 `XFontSet` 缺少字符时，每个不可用字符使用 `XCreateFontSet` 返回的默认值绘制。对于无效码点，其行为未定义。

# 使用单个字体集绘制图像

要在指定的绘制区域中使用单个字体集绘制图像，使用 `XmbDrawImageString` 或 `XwcDrawImageString`。

```c
void XmbDrawImageString(display, d, font_set, gc, x, y, string, num_bytes);
void XwcDrawImageString(display, d, font_set, gc, x, y, string, num_chars);
```
