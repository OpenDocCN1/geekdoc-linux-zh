## ACL

`ACL` 语句允许你指定哪些主机允许执行某些操作。你可以指定一个 IP 地址列表，然后指定它们允许执行的操作。

```text
acl {
    name {
        address-list;
        operation-list;
    }
}
```

## LOGGING

`logging` 语句允许你指定服务器应该记录哪些信息。你可以指定日志的通道、严重程度目的地。`logging` 语句的语法如下：

```
logging {
    channel name {
        severity level;
        print-time yes or no;
        print-category yes or no;
        print-severity yes or no;
    }
}
```
