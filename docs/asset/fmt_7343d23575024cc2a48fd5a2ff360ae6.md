
KFloppy 是 KDE 的软磁盘格式程序。从主菜单或从命令行使用命令 `kfloppy` 启动程序。KFloppy 会打开一个对话框（见图 5.6），在其中可以指定若干设置。在“软磁盘驱动器”下，选择主设备或辅助设备（前提您的机器有两个软磁盘驱动器）。大小的默认设置为“3.5英寸1.44 MB”，这是最常用的软磁盘类型。文件系统的设置非常重要。在 Linux 格式 ext2 和 MS-DOS 之间进行选择。如果您选择 MS-DOS，将能够在 Windows 机器上读写该软磁盘。

在中间，选择“快速格式”或“完全格式”。快速格式化程序会重写文件系统并删除所有数据。完全格式化程序会重写所有轨道和扇区，并能够检测并标记坏道。标记为坏道的扇区将不会用于写入数据。选择“验证完整性”可以在完成后对格式进行检查和验证。如果您激活了“卷标”，可以在下方的输入字段中为软磁盘指定名称。

![](img/705a076b108ea96be0c0695efb5556ce_179_0.png)

在完成所有设置后，点击“格式化”。您将收到警告，提示磁盘上的所有数据将丢失，并要求确认。如果在格式化过程中发生任何问题，KFloppy 会通知您，包括关于任何坏道的信息。

点击“帮助”访问提供 KFloppy 手册的短菜单。此外，可以使用它向 KFloppy 开发者发送错误报告或其他问题。选择“关于 KFloppy”可以访问有关版本、作者、翻译和许可证的信息。“关于 KDE”提供有关 KDE 的信息以及 KDE 开发者的网页。点击“退出”退出 KFloppy。

## 5.4.8 桌面共享

桌面共享允许您通过网络共享您的桌面。要使用此功能，您需要一个服务器和一个客户端。服务器使用 VNC 协议捕捉屏幕，客户端连接进行查看和控制。

要启动服务器，请在系统设置中启用“桌面共享”。可以设置密码以确保安全。客户端通过输入服务器的 IP 地址进行连接。

配置连接，使用“设置” -> “Internet与网络”。

## 5.4.9 KSnapshot：截屏

使用 KSnapshot 截取屏幕或特定应用程序。从主菜单或从命令行使用命令 `ksnapshot` 启动程序。Snapshot 对话框由两部分组成（见 5.9）。上半部分（当前截图）包含当前屏幕的预览以及三个用于创建和保存的按钮。在窗口下半部分确定更多选项。

要截图，使用“截图延迟”确定点击“新建截图”之前的秒数。如果激活了“仅捕取指针所在的窗口”，则只截取指针所在的窗口。要保存截图，点击“保存截图...”并在后续对话框中为图像指定目录和文件名。使用“打印截图...”打印截图。

## 5.4.11 与朋友聊天：Kopete

Kopete 是一款在线即时通讯应用程序，允许连接到互联网的多个伙伴互相聊天。Kopete 目前支持所有常见的即时通讯协议，如 ICQ、MSN、Yahoo、SMS、Jabber 和 IRC。

### 配置 Kopete

通过输入您的个人用户数据配置 Kopete。点击“设置” -> “配置 Kopete”。“连接”显示所有当前可用协议。勾选所需的连接类型即可激活。

在“账户”（Accounts）中，输入您的用户数据。在使用此类服务之前，您必须先在提供即时消息服务的供应商处注册。点击“新建”（New）打开配置助手，该助手可以协助您完成用户资料。

下一步列出了可用的消息服务。选择您已注册的服务并点击“继续”（Continue）。在下一步中，输入从消息服务注册时获得的用户数据。这通常包括昵称或电子邮件地址以及您选择的密码。点击“完成”（Finish）完成消息软件的配置。

![](img/705a076b108ea96be0c0695efb5556ce_184_0.png)

图 5.11：Kopete 配置面板

配置对话框中的下一项是“外观”（Appearance）。它影响 Kopete 的显示方式。“表情符号”（Emoticons）标签页提供了各种类型表情的选择。

“聊天窗口”（Chat window）和“颜色与字体”（Colors & Fonts）标签页提供了调整与其他参与者通信的聊天窗口外观的能力。可以在相应提供者的经典主题之间选择，也可以根据个人喜好调整字体或颜色创建自定义主题。

### 添加联系人

为了与参与者聊天，必须添加联系人。如果您已经在其他电脑上创建了账户，这些数据将被导入并自动添加到您的联系人列表中。要手动创建联系人条目，请点击“文件”（File）->“添加联系人”（Add contact）。

会自动出现一个新助手将引导您直到完成。但请注意，您必须在线才能将联系人添加到列表中。

### 添加组

通过“文件”（File）->“创建新组”（Create New Group）访问此功能。为组命名并点击“确定”（OK）确认。联系人列表中将出现一个新的文件夹，用于存储所需的联系人。您可以将联系人拖入所需的文件夹中。这允许对联系人进行分组以便更好地查看。

### 使用 Kopete

为了能够与其他参与者聊天，必须建立与的连接。完成后，点击“文件”（File）->“连接”（Connection）->“连接全部”（Connect All），即可在 Kopete 与所选的消息服务之间建立连接。

主应用程序窗口包含联系人列表。当您点击标记为在线的联系人时，会打开一个包含各种选项的菜单。向该人员发送消息或开始聊天。聊天允许邀请其他参与者进行实时讨论。当聊天会者离开房间时，与所有其他参与者的连接将关闭。

可以通过即时消息软件右键点击用户并点击其名称方便地传输文件。在这里可以找到许多选项，如“删除联系人”（Delete Contact）、显示用户信息”（Show User Information）、锁定用户”（Block User）和“发送文件”（Send File）。点击“发送文件”将打开选择所需文件的对话框。确认“确定”（OK）将向接收用户发送对话框，询问其是否接受文件。如果他接受，文件将传输。
