# 在防火墙处记录数据包

如之前讨论的，`Ipables -l` 选项允许你记录匹配的数据包。你可以将 `-I` 插入到任何规则中，只要你不中断特定的选项。例如，以下命令记录所有被拒绝的 TCP 数据包：

```
ipchains -I input -i eth0 -p tcp -s 0.0.0.0/0 -y -l -j REJECT
```
