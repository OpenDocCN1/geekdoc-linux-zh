# 向场景中添加植物

植物和树可以为场景增添生命和色彩，还可以作为结构尺寸和场景地理位置的视觉线索。`VIZ` 提供了两种创建植物和树的方法：`Foliage AEC`（AEC 植物被）对象和 `EASYnat` 树插件。这两类树都是完全参数化的，具有确定高度、跨度、密度等的控件。

## 创建植物被

植物和树由成千上万的元素组成，包括树干、树枝和叶子。手动创建这些元素会消耗大量时间。以前计算机图形是通过拍摄真实的树然后将其应用的，这对于远景是可以接受的。`VIZ` 提供了可以快速填充场景的参数化对象。以下是使用 `EASYnat` 插件的方法：

- 继续上一个练习或打开 `Condo.max` 文件。

- 在透视视图中，在创建 `AEC Foliage`（植物被）对象之前放大到该区域。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_285_0.png)

# 使用 `EASYnat` 插件创建树

随 `VIZ` 2008 提供的（可在 `http://www.bionatics.com` 获取）是 `Bionatics EASYnat` 插件的 2.5 版本，用于创建参数化的树和植物。`EASYnat` 的功能与 `VIZ` 原生的 `Foliage` 对象相似，但以不同的方式处理树。与其完全依赖几何体来制作植物，`EASYnat` 植物还可以使用映射到多边形对象的带有漫射和透明度的贴图来显示叶子和花朵。这保持了低多边形数量且渲染速度快，同时显示高质量的植物。可以使用多种方法创建 `EASYnat` 植物：近景使用全几何体；中景使用多个看板面；以及使用交叉看板树来填充背景低多边形树森林。

`EASYnat` 插件和下一节讨论的 `RPC` 插件都可以在 `VIZ` 2008 安装光盘的合作伙伴页面找到。

## 创建 `EASYnat` 植物
