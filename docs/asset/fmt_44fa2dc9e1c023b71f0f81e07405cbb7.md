| `unsigned long int` | 4 字节 | 0 到 4,294,967,295 |

## `ios` 类的 `open_mode` 常量

| 常量 | 标准 | 效果 |
| :--- | :--- | :--- |
| `app` | | 下次写操作将新信息添加到文件末尾。 |
| `ate` | | 打开时定位到文件末尾。“ate” 代表“at end”（在末尾）。 |
| `binary` | | 以二进制（非文本）模式打开文件。 |
| `in` | | 用于输入（读取）打开文件。 |
| `nocreate` | | 如果文件不存在，则不创建新文件。 |
| `noreplace` | | 如果文件已存在，则不覆盖文件。 |
| `out` | | 用于输出（写入）打开文件。 |
| `trunc` | | 打开并截断现有文件。写入其中的新信息将替换文件的当前内容。 |
