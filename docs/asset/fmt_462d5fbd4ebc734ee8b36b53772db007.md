# jde

用于 Emacs 或 Eacs 的 Java 开发环境。Java 开发环境 (JDE) 是一个 Emacs 列表包，使 Emacs 与第三方 Java 开发工具接口，例如由 Java 开发工具包 (JDK) 提供的工具。结果是一个集成开发环境 (JDE)，可与许多商业 Java IDE 。功能包括：

- 具有语法高亮和自动缩进的源代码编辑
- 编译时可从错误信息自动跳转到源代码中的响应行
- 在交互式 (comint) emacs 缓冲区运行 Java 命令
- 集成调试功能，具有交互式调试命令，并在单步执行代码时自动定位文件/行
- 使用选定的浏览器浏览 JDK 文
- 使用 Emacs tags 或树形 speedbar 浏览您的源代码
- 轻松且无限自定义 来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# jdresolve

`apacheeresolve` 的快速替代方案，用于解析主机名中的 IP 地址。为了减少解析大批量地址的时间，`jdresolve` 向 DNS 服务器开启许多并发连接，并在内存中保留大量文本行。这些行可以包含任何内容，因为 IP 地址是左侧的第一个字段。大多数 HTTP 和 FTP 日志文件的格式均如此。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# jed

面向程序员的编辑器（文本模式）`Jed` 提供：

- 类似于 C 语言的可扩展性
- 完全自定义
- 能够在 Jed 浏览器中从文件中读取 GNU info
- 多种编程模式（带有语法高亮）可供：Pascal, Perl, C, C++, FORTRAN, TeX, HTML, SH, IDL, DCL, NROFF, PostScript, Basic
- 支持以 AUC 风格编辑 TeX 文件（支持 BibTeX）
- 矩形剪切/粘贴
- 正表达式
- 增量搜索
- 跨文件搜索替换
- 多个窗口
- 多个缓冲区
- 模式
- 目录编辑器 (ired)
- 邮件
- 以及更多。来自 Debian 3.0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
