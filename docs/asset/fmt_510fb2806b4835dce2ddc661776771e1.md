
# perspic

一种文本索引和词搜索工具。Perspic 用于研究不经常变化（或不变化）的文档，例如文献、具有历史意义的古代文献等。Perspic 构建原始文本文件的完全索引和压缩版本。词搜索结果按行摘要。选择某一行将打开关于该单词的全文。其他功能还包括单词定义、派生词扫描以及带有附带属性的引文选择。源自 Debian 3.0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

# peruser

用于 Usenet 新闻离线阅读和编写的套件。Peruser 是几个小程序的组合，用于启用 Usenet 新闻的离线阅读和编写。Peruser 还可以通过邮件回复，并将其交给本地的 `sendmail`。顶层应用程序的文件名为 "`ncollections`"，但你可以在 shell 提示符处输入 "`ncollections`" 或 "`peruser`" 来启动 News Peruser，或者从窗口管理器菜单中选择它。源自 Debian 3.0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`
