#### 注意：每天检查核心储有两个原因：
# 1. `'core'` 文件通常占用大量磁盘空间。
# 2. 当应用程序（来自供应商如 ORACLE，
# 或是自开发的程序如你的工资系统）
# 崩溃时，稍后分析核心储可以获取详细信息。
# （问题可能是空间不足、电源波动
# 或应用程序错误）
# 设置一个每天自动运行的 cron 任务是个好主意；如果发现核心储，脚本可以向
# 相关人员发送电子邮件。（参见：`'core.txt'`）

# 由于此类任务由 `user=root` 执行，
# 某些命令（如 `'strings'` 命令）使用了
# 完整路径而不是简单的命令（在许多系统中，
# root 的 PATH 被故意限制得很小）。

# 记住……
# 许多服务器设置设置不允许 ROOT 发送电子邮件。
# 如果是 root（cron 任务）提交任务，我们发布
# 命令并让用户向适当的用户发送警报。
