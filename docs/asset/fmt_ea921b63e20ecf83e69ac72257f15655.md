### 2.9 我可以在同一台电脑上同时安装 MS Windows 和 Linux 吗？

是的，可以。许多 Linux 用户使用双系统。这通常通过在一个硬盘分区上安装 MS Windows，在另一个分区上安装 Linux 来实现。Linux 附带一个名为 GRUB 的引导管理器（某些其他发行版可能包含另一个名为 LILO 的引导管理器）。你在启动时选择的引导管理器将决定你启动哪种操作系统。先安装 MS Windows，只有在 MS 安装后才安装 Linux，否则将禁用你对 Linux 的访问。如果你准备了 Linux 启动软盘但需要重新安装 MS-Windows，无疑会禁用你对 Linux 的访问，你必须从软盘启动然后运行命令列表才能回来。最好是使用 MS Windows 95，因为它对 Linux 的干扰并不复杂，而且完全没有冲突。安装 MS Windows 的版本无疑会给你的双系统系统带来麻烦（显然是故意的），它甚至会坚持使用它自己的引导管理器，那无疑会拒绝运行 Linux。尽管它是一个迷人的单体结构，可以持续干扰另一个操作系统，但人们可能需要从中学习。

来自 Linux，你将能够读取和写入 Windows 驱动器分区，因此基于 Linux 的程序是无缝的。你还能够使用基于 MS Windows 的资源：音频文件、背景、图片、字体等（首先检查这是否违反了你的许可协议，微笑。对于那些不从微软运行的产品，它可能违反了。对于我的 Linux 电脑，我可以证明无论在什么地方都没有盗版软件：）

MS Windows 不感知你的电脑上存在 Linux——它只会认为：

* 存在一个引导管理器
* 硬盘上存在非 Microsoft 分区。

MS Windows 在正常运行期间不会干扰它们（但在安装、硬磁盘重新分区期间会弄得很糟，两者都不行）

### 2.10 我该如何对硬盘进行分区？

在安装之前，你可能真的想知道硬盘是什么。担心的是你可能会在无意中删除你的 MS Windows 分区——你是想为双系统准备独立的分区。这意味着 MS 在一个分区，Linux 在另一个独立分区上。你通常不会将 Linux 安装在 MS 分配的分区的可用空间上。在 MS Windows 分区安装 Linux 是可能的，但不建议这样做。如果你删除了硬盘上的分区，该分区上的所有内容都会丢失。

如果你计划双系统（在同一台电脑上使用 Linux 和 Windows），使用你的 DOS/Win FDISK 创建 MS Windows 分区。留出硬盘的一部分（一半）未分区供 Linux。你将在 RedHat（或 Mandrake 或其他）安装期间创建并格式化 Linux 分区。Linux 会识别硬盘上的空闲（未分区）空间并使用它创建非微软格式的分区。

将 MS Windows 分区设为“主”且“可启动”。在安装之前，安装、配置并测试你的 MS Windows。如果你计划只运行 Linux（不双系统），你只需要一个干净的硬盘（无分区）作为开始。

只有一个 Linux 分区是可能的（如果双系统，则为 MS Windows 留一个）。但是拥有更多的分区更好，这样你可以将用户数据与操作系统的其他部分分开。这样，一旦出现问题，或者你必须格式化或重新安装操作系统，你

在许多计算机（486）上设置分区时，另一个考虑因素是：许多 BIOS 有一个限制，即分区不能超出第一块硬盘的第 1024 磁道区。为了避免这一限制，请设置第一个（可启动的）分区，使其在第 1023 磁道之前结束（这使得该分区的大小约为 512 MB，对于 /root 分区来说足够了）。一旦安装了 Linux，BIOS 的限制就不再重要了，因为 Linux 处理硬件管理，你可以将分区扩展到磁道 1023 之外。

在安装和使用 Linux 时，你的驱动器显示为具有以下名称的设备：hda-第一个 IDE 硬盘（代表“hard a”，即第一个 IDE 接口上的主设备），hdb-第二个 IDE 硬盘（第一个 IDE 接口上的从设备），hdc-第三个 IDE 硬盘（即第二个 IDE 接口上的主设备），hdd-第四个 IDE 硬盘（即第二个 IDE 接口上的从设备）。这些数字在物理设备上的含义是：“hda1”是第一块 IDE 硬盘（hd a）的第一个分区，“hda2”是第一块硬盘的第二个分区，“hda3”是第一块硬盘的第三个分区，“hda4”是第一块硬盘的第四个分区。“hdb1”是第二块硬盘的第一个分区（如果 CD-ROM 是你第一个 IDE 接口上的从设备，则为“hdb”）。“hdc1”——第三块硬盘的第一个分区。SCSI 硬盘具有类似的名称，并以字母“sd”开头（“SCSI drive”，即 SCSI 硬盘）。例如，“sda4”意味着第一个 SCSI id 设备。如果你在并行口上连接了外部 zip 驱动器，它在 SCSI 挂载环境中将显示为“sdz”（zip 驱动器）。

作为参考，这里是 Linux 分区类型（文件系统）的简要总结及短描述。将其包含在 Linux 手册页中：fs 和 man（带有我在 /usr/src/fs 源代码文件中添加的一些内容）。带有下划线的文件系统是你更有可能使用的。其他文件系统（下文未列出）作为 Unix 操作系统可用、压缩等……第一个在 Linux 上运行的文件系统。它具有若干特点：64GB 分区大小限制、短文件名、单个时间戳，并且对于软盘和 RAM 磁盘仍然有用。

- ext 是 minix 文件系统的扩展。它已被第二代扩展文件系统 (ext2) 完全取代，并最终将从内核中移除。
- ext2 是 Linux 用于固定式磁盘以及可移动媒体的高性能文件系统。第二扩展文件系统被设计为扩展文件系统 (ext) 的扩展，ext2 在（速度和 CPU 使用率方面）提供了 Linux 支持的文件系统中的最佳性能。简而言之，ext2 是主要的（默认的、典型的）Linux 文件系统。
- ext3 是带有日志功能（journaling）的 ext2 文件系统的扩展。它与 ext2 向上和向后兼容。这意味着 ext2 可以在不重新格式化或丢失数据的情况下转换为 ext3（只需挂载即可）。ext3 也可以转换为 ext2，同样不会丢失数据。我从 2001 年 10 月以来一直频繁使用 ext3——它简单且无需手动干预。它作为安装项包含在。
- ixfs 设计为不再接受频繁使用的释放操作。强烈建议你使用此文件系统。它提供了基础功能而没有过度复杂。该文件系统被 DOS、Unix 和某些 OS/2 计算机使用。msdos 文件长度不再超过 8 个字符加上扩展名。
- umdos 是 Linux 使用的扩展 dos 文件系统。它为文件名、UID/GID、POSIX 以及命名管道等特殊文件增加了容量。
