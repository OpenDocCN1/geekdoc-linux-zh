### 斜三角形的解法。
如果三角形的任何一个角都不是直角，则该三角形为斜三角形。为了解此类三角形，有四种情况需要考虑：
- 给定一条边和两个角；
- 给定两条边和其中一条边的对角；
- 给定两条边和它们的夹角；以及
- 给定三条边。

在以下讨论中，边标记为 `a`、`b` 和 `c`；这些边的对角分别为 `α`、`β` 和 `γ`；对应的顶点为 `A`、`B` 和 `C`（图 3）。

### 无穷级数表示。
根据定义 `n = 1, 2, 3, \cdots`，正弦和余弦函数可以用两个无穷级数表示，即公式 (17) 和 (18)。这些级数对所有 `x` 收敛。因此，要找出 sin `x` 或 cos `x` 的值，只需使用级数中所需的项数以确保所需的精度即可。[M.S.u.]

$$\sin x = \sum _ { k = 0 } ^ { \infty } (- 1 ) ^ { k } \frac { x ^ { 2 k + 1 } } { ( 2 k + 1 ) ! } = x - \frac { x ^ { 3 } } { 3 ! } + \frac { x ^ { 5 } } { 5 ! } - \cdots ( 1 7 )$$

$$\cos x = \sum _ { k = 0 } ^ { \infty } (- 1 ) ^ { k } \frac { x ^ { 2 k } } { ( 2 k ) ! } = 1 - \frac { x ^ { 2 } } { 2 ! } + \frac { x ^ { 4 } } { 4 ! } - \cdots ( 1 8 )$$

# 三叶虫纲

它们的现存最近亲缘类群是蛛形纲，包括蜘蛛、螨类和鲎类（`Xiphosura`）。约 3000 个已描述的属使三叶虫成为最多样化且最著名的化石类群之一。物种多样性在晚寒武纪达到峰值，随后大致持续下降，直到晚泥盆纪大灭绝。只有四个科延续到密西西比纪，且只有一个属延续到该纲在二叠纪的灭绝。

它们在大多数寒武纪海洋环境中的优势对于该纪的生物地层对比至关重要。参见 节肢动物门；寒武纪；螯肢亚门；泥盆纪；标准化石；二叠纪。

三叶虫在化石记录中通常以其外骨骼的矿化部分为代表，作为尸体或蜕壳残留物。矿化外骨骼主要局限于背部（见插图），向下弯曲形成类似边缘的双层边缘，以及一块位于头部中央区域下方的单一矿化腹板，即 `hypostome`（口下板）。矿化外骨骼由低镁方解石和少量有机物质组成。大部分腹面外骨骼，包括附肢，均未矿化。

大多数三叶虫是底栖碎屑食性或食腐动物，生活在沉积物-水界面或该界面下方的浅层掘处。有些显然是肉食性的，其附肢带有尖刺和向下延伸的突起。这些类群的形态以及广泛的地理和生态分布范围表明它们是活跃的游泳者。在它们的演化历史中，三叶虫适应了所有海洋环境，从浅层高能量海岸带到深海无氧栖息地。[D.D.E., J.AdJ.]

### 三重态
当分子的总自旋角动量量子数 `S` 等于 1 时，分子所处的电子态。三重态是有机化学中重要的中间体。除了通过光化学激发技术可获得的大量三重态分子外，许多分子处于稳定的三重态基态，例如氧气分子。参见**原子自旋与光谱**；**分子结构与光谱**；**自旋（量子力学）**。[N.J.T.]

只要分子拥有两个电子，且这两个电子在轨道上未配对且自旋未配对，就可能产生三重态。当分子吸收可见光或紫外光的光子时，电子的轨道未配对现象就会发生。通过这种光吸收直接形成三重态是一个非常不可能发生的过程，因为这要求电子的轨道和自旋必须同时改变。因此，吸收光线通常形成的是单重态。然而，这种单重态的寿命往往足够长，允许两个电子中之一的自旋翻转，从而产生三重态。参见**分子轨道理论**。

# 三裂科（Triplidia）

一种线虫目，其头部角质层简单且未双层化；没有头盔状结构。身体角质层光滑或有时表面有环状纹理。头部感觉器遵循典型模式，其中一圈环绕口部，第二圈通常由第二圈和第三圈组合而成。假瓣状输入管开口不显著或呈横向椭圆形。口腔多变，为简单型、塌陷型、漏斗形或圆柱形，且带有或没有武装。在大多数分类单元中，口腔周围被食道组织包围；即完全为食道型。当口腔扩张时，几丁质部和食道部均清晰可见。食道为圆柱圆锥形。食道腺体开口位于神经环之前。雄性通常有三个辅助器官，在某些分类单元中更多。一个控制杆伴随阳茎刺。尾部腺体通常存在。两个三裂总科是**三瓣科（Tripylidae）**和**铁线科（Ironoidae）**。**三裂科（Triplida）**特征性的发达角质环纹仅在其他 Enopida 中可见。这些线虫通常见于淡水或非常潮湿的土壤；然而，有些生活在咸水和海洋生境中。肠道内容物表明其食物主要由小型微型动物组成，通常包括线虫和轮虫。**铁线总科（Ironoida）**包含物种（据推测为肉食性），出现在淡水土壤生境中。参见**线虫动物门（NEMATA）**。[A.R.M.]
