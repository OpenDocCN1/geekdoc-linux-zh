
移除该文件后，您可以再次启动 DB2 安装程序。

问：当我输入 `db2start` 命令来启动我的实例数据库管理器时，我收到了 SQL10007N 消息“-1393” 无法检索。错误代码：“1”。

答：DB2 无法察觉到该实例的存在。当你输入 `db2start` 命令时，DB2 将尝试启动默认实例。默认实例由 `DB2INSTANCE` 环境变量确定的，该变量由 DB2 安装程序在安装期间设置。此错误最常见的情况是当你使用不带 `–` 参数的 `su` 命令登录系统时，正如本章之前讨论的那样。如果你收到此错误，请输入 `export DB2INSTANCE=db2inst1` 命令（或者，如果你希望默认实例是 `db2inst1` 以外的其他实例，请指定该实例）。

问：我在配置 DB2 客户端与 DB2 服务器通信时，使用了你说的可以使用的默认值（`dbcdb2inst1` 和 `50000`）。连接失败了！我查阅了“客户端到服务器故障排除”部分，并正确输入了所有命令。发生了什么？

答：这可能有很多原因；然而，它可能与 `sclename` 和端口号有关。你是否在此机器机器上安装过之前的版本的 DB2？本章的说明假设这台机器上没有安装过旧版本的 DB2，并且默认服务名和端口号是可用的。如果该机器上安装过 DB2 并已删除，请检查 `/etc/services` 文件并查看 `dbcdb2inst1` 是否映射到 `50000`。也许当你删除 DB2 时，你忘记了清理 `/etc/services` 文件，导致该服务名或端口号无法供 DB2 安装程序使用。你在安装期间是否更改了任何默认设置？

# 简介介绍

MySQL 是一个复杂的数据库，但安装并没有你想象的那么复杂。在开始之前做出一些决定，整个过程将会非常顺利。然而，在开始之前，你应该拥有一台 Linux 机器以及大量的磁盘空间。机器应留有 30–40 MB 的空闲空间用于安装。内存也是一个关键因素——数据库可用的内存越多越好。通常，64 兆字节就足够。

MySQL 有多种发行版，每种都有其优缺点。包括二进制发行版、RPM（用于 RedHat Linux 的包管理器）安装和源码发行版。二进制和 RPM 发发版最容易设置，并让你在几分钟内运行。源码发行版的安装和设置需要更多时间，但它们最强大，允许用户进行调优以发挥最大的潜力。源码发行版还允许你生成针对特定平台优化的数据库。

每个发行版也有不同的开发阶段；某些是前沿发行版，仅供那些想要尝试新功能即使可能会更频繁崩溃的用户。稳定版本（推荐初学者使用）包含所有主要功能，并且完全可靠且经过良好测试。后期版本适用于那些从旧版本升级或落后于稳定版本的用户；这些用于历史目的。对于任何支持应用程序的数据库类型，都应该使用稳定版本。

这些发行版的安装（特别是二进制和 RPM 发发版）将在后续介绍，并且不需要花费很长时间。这些非常容易安装，并让你开始利用 MySQL 的力量。源码发行版需要更多几个步骤，但这些步骤并不复杂，且会有详细解释。一旦完成了一个源码发行版，你就可以应对大多数其他开源发行版。

安装完成后，下一步是确保数据库的安全。确保只有

授权用户可以访问数据库；数据库安全是一项非常重要的步骤。根据你的应用程序，应该认真对待数据库安全，特别是在数据非常敏感（如信用卡号）的电子商务应用程序中。每个用户都应被设置密码。系统还将根据用户对数据库的预期使用类型向其授予某些权限。如果用户只需要读取表，则可以在不赋予用户在数据库上执行任何命令权限的情况下实现。用户和权限是防止数据库被未经授权访问和使用的重要方法。

数据库应该始终保持可用。安装自定义脚本以确保数据库始终运行，将保持数据库在线并持续运行，将停机时间减少到最低。还有其他工具可以提供有关数据库的关键信息及其运行情况，以及工具可以确保数据库管理成为一项简单的任务，允许管理员执行 DBA 的所有常见任务。此外还有其他方法可以提高 MySQL 安装的性能，通过使用 MySQL 数据库的性能属性、对你的发行版进行更多优化编译以及使用不同的硬件设置。所有这些步骤将允许你为应用程序设置一个强大的数据库。

# 安装

在安装 MySQL 之前，你必须先在三个版本中做出决定。推荐的是稳定版本，标记为 3.22.X。该版本经过了充分的测试，没有任何未经测试的功能，已准备好投入生产，推荐初次用户使用。开发版本 3.23.X 面向为改进 MySQL 做贡献的开发者，包含许多未经测试的新功能。该版本不建议在生产环境中使用。最后一个版本 3.21.X 是一个弃用的版本。它主要为之前的用户提供了一种升级到该版本的方法，而功能上不会发生任何重大变化。这更像是一个历史版本，不供使用。

选择好版本后，必须在二进制（binary）、RPM 和源码（source）发行版之间做出决定。二进制发行版已经为你的平台进行了编译。你所需要做的只是安装它并决定文件的位置。缺点是你必须找到适用于你所在平台的相应二进制文件。并不是所有平台都为每个版本保持最新状态。

RPM 发行版适用于使用 RedHat Linux 发行版的用户。它类似于已经编译好的二进制文件，甚至会为你设置好系统环境。最后一个选项是源码发行版。该发行版允许最大程度的自定义，带有更多文档和示例，并且可以针对速度进行优化。二进制文件可能需要 root 权限，RPM 发行版必须以 root 用户身份安装。二进制文件和 RPM 都是特定平台的。源码发行版高度可定制，不特定于平台，可以由任何用户运行，由于这些原因，它优于其他两种发行版。

在安装的下部分，你需要找到 MySQL 发行版。最好从镜像站（mirror）获取发行版，即从官方网站复制最新文件到自身位置的站点。你可以找到一个离你近的镜像站，根据镜像站的远近，可能会缩短你的下载时间。镜像还有助于分流官方网站的流量，保护带宽。镜像站列表可以在 http://www.mysql.com/mirrors.html 找到。

当然，如果你找不到合适的镜像站，也可以从官方网站下载发行版。官方地址为 http://www.mysql.com/download.html。
