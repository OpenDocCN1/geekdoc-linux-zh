### 审计 UNIX 和 Linux

每个 UNIX 发行版和版本都以自己的方式记录日志，并存储在特定文件中。然而，大多数 UNIX 和 Linux 系统支持丰富的日志功能并共享许多特性。

### 表 A.2 常见的 `syslog` 设施

| 设施 | 描述 |
|---|---|
| `Auth` | 授权 |
| `Cron` | 计划任务 |
| `Daemon` | 守护进程 |
| `Kernel` | 内核 |
| `local` | 本地 |
| `Lpr` | 打印 |
| `Mark` | 标记 |
| `Mail` | 电子邮件 |
| `Syslog` | 系统日志 |
