
从操作系统基础开始，《Linux Essentials》第 2 版解释了 Linux 的属性和原理，并展示了如何在工作场所管理这一开源操作系统。课程按任务组织，每章都包含练习和复习题，以巩固你的知识。

## 学习这些 Linux 基础知识——以及更多：

- 发行版类型和开源应用程序
- 关于自由、许可、操作和导航的所有知识
- 使用常用的 Linux 程序
- 命令行导航
- 数据的搜索、提取和归档
- 将命令转换为脚本
- 创建用户类型、用户和组
- 管理网络连接
