## 水龙目 (Hydrochariales)

一种开花植物，属于单子叶植物（被子植物）中的藻目亚。该目仅包含水藻科（Hydrocharaceae），其一个亚目的特征是不子子具有盘状胎座。该科的植物如藻华（Vallisneria），被称为草带或鳗草，它们不是草，而是属于水藻科。

ALIFER：开花的。(A.C.)

## 加氢裂解 (Hydrocracking)

一种高压工艺，生产高油烷汽油或喷气燃料。它通过两个主要反应产生：向过于复杂且沉重的裂解分子中加入氢。该过程是将油在高压（每平方英寸1000–2500 psi 或 7–17 兆帕）和中等温度（350–750 °F 或 177–400 °C）下与酸催化剂和金属催化剂接触时进行。可以直接或通过随后的催化精炼等步骤生产高油烷汽油；也可以使用其他催化剂制造燃料。

该工艺通常用作升级，以转化裂解油。裂解油含有芳烃并会导致催化剂失效，而在加氢裂解中可以很容易处理，因为缺乏焦结前体且高压减少了催化剂结垢。

加氢裂解的产物由饱和或芳香化合物组成；未发现烯烃。在市场上，石蜡产生高油烷值。生产的汽油在催化精炼后具有良好的性能，产生高芳香汽油，并含有铅添加剂以及甲烷、乙烷和丙烷等不如汽油理想的成分。

加氢裂解工艺正用于其他领域，特别是在润滑油精炼中，将重芳烃和高沸残留转化为沸燃料。

CROINING：加氢裂解。(C.P.)

## 流体力学 (Hydrodynamics)

研究基于质量、动量和能量的物理守恒定律。这些定律的数学可以用积分形式或微分形式表示。积分形式适用于大规模分析且效果很好，而微分形式始终有用，特别是对于工程应用。从主要意义上说，第一形式对任何问题都有用，但只有在小规模或特殊情况下才能获得解。大多数问题的求解通过数值技术获得，而这些技术受流体复杂性的限制。
