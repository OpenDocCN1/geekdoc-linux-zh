安培，`R` 以欧姆（电导）测量。欧姆定律定义了材料对电流子流提供的电阻。电阻是金属的一种属性，电载流子在其中移动，受到局部晶格结构中原子、空位和位错碰撞的阻碍。载流子将能量转化为热，因此在导体中产生焦耳热。金属的电阻随温度升高而增加。

# 电阻

均匀金属立方体对立方体相反面的均匀密度电流所提供的电电阻。也称为比电阻，是材料的固有（但细微）属性。它通常通过测量具有长度和均匀截面积的样品电电阻来确定，根据方程，其中 `ρ` 是电阻，`A` 是截面积，`l` 是长度。因此，在方程中，电阻以欧姆表示，样品尺寸以米表示。

```
R = \rho l / A
```
