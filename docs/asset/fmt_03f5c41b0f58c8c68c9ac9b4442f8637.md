
# 甲醇

任何材料中的碳都可以转化为甲醇。天然气常被选作原料，如果将天然气转化为甲醇，而不是直接管道输送或将天然气转化为液化天然气并在其低温下储存和运输，其能量传递成本可能低得多。参见[液化天然气](https://example.org/LIQUEFIED_NATURAL_GAS)；[甲烷](https://example.org/METHANE)；[天然气](https://example.org/NATURAL_GAS)。

甲醇是最通用且最便宜的液体燃料。它比汽油不易燃；意外火灾可以用水扑灭，而不是像易燃液体那样蔓延。燃烧时，它既不产生颗粒物（烟灰）也不产生硫氧化物，且产生的氮氧化物数量更少比任何其他燃料都高。当从天然气或固体酒精中生产时，甲醇总是可以被视为纯的，但它更可能被视为天然替代气体（SNG），且仅有少量的能量损失。即使使用昂贵的化学级甲醇用于具有相对微小变化的汽车中，这些车辆的里程成本也比使用汽油作为燃料时更低。参见METHANOL。[D.O.O.]

## 酒精依赖症

持续或过量使用酒精（乙醇）并伴随病理结果。酒精依赖症的特点是持续或周期性的醉酒，尽管消耗模式差异巨大。首次入住酒精依赖症治疗中心的个体通常每天消耗约3至4盎司（80至100克）纯酒精，相当于约七到九杯啤酒或葡萄酒。研究表明，这些人群中酗酒问题始于每天约2盎司（60克），即每天四到五杯酒，并且这些酒是迅速连续饮用的，导致每周有三天或更多天醉酒。这些水平的酒精摄入量者也有高于平均水平的风险发展为酒精性肝硬化。然而，这些水平不应被视为绝对值，因为它们可能因体重和其他因素在不同个体之间有很大差异。

肝脏负责约80%的酒精代谢。在肝脏中，酒精首先被氧化为乙醛，然后转化为乙酸，乙酸在许多组织中被代谢，包括大脑、心脏和肌肉。一个体重150磅（68公斤）的人每小时代谢约0.4盎司（10克）纯酒精（相当于约1盎司蒸馏饮品[含酒精饮料]），并且每天摄入8至10盎司（190至240毫升）纯酒精后，血液通常含有酒精，相当于每天1300至1600卡路里。一些含酒精饮料含有微量的必需营养素。这些卡路里被称为“空卡路里”。许多酒精依赖症患者出现营养不良，因为其热量摄入的重要组成部分是酒精。酒精还损害某些必需营养素的吸收和代谢。在存在酒精的情况下，肝脏消耗的氧气中约80%用于酒精的代谢；因此，肝脏通常氧化的其他物质，如脂肪，未被代谢，导致肝脏脂肪堆积。参见LIVER；MALNUTRITION。

与严重酒精摄入相关的症状和后果也差异巨大；也就是说，在某些个体中可能只存在少数症状。这些可能包括身体依赖性的发展，表现为身体不适或过度兴奋（震颤或发抖）的状态，该状态可通过持续饮酒而减轻；对酒精作用的耐受性发展，导致个体增加饮酒量；醉酒时发生事故；断片，特征为醉酒时失去事件记忆；工作问题，包括解雇；朋友和亲属关系的丧失；婚姻问题，包括离婚；财务损失，包括破产或持续失业；医疗问题，包括胃溃疡、胰腺炎、肝病和脑萎缩。最后一种通常与认知缺陷相关，如无法理解相对简单的指令或记住一系列数字。参见COGNITION。

酒精性肝病以两种状况为特征：肝脏无法排毒各种物质并产生必需产物；以及肝脏血流阻力增加。酒精性肝病和肝硬化在美国和加拿大排名在前10大死亡原因之列。参见CIRRHOSIS。

几乎无一例外，寻求早期治疗其酒精问题的个体有很好的康复概率。上述呈现的问题数量越少，预后越好。早期识别酒精依赖症以及由家庭、朋友、雇主或医生早期识别问题饮酒变得非常重要。干预类型差异很大，从自我监测技术到密集的门诊和住院计划再到酗酒者互诫协会（AA）团体。

有充分证据表明，酒精依赖倾向可能源于家庭，由于环境、文化和遗传影响。一项瑞典研究证明，美国的同卵双胞胎比异卵双胞胎更有可能有共同的酒精问题。在一项美丹研究中，显示酗酒父母的子女比非酗酒父母的子女更有可能发展出酒精依赖症（18%），而非酗酒父母的子女（4%），但两组儿童在出生后6个月内均被非酗酒者收养。参见BEHAVIOR GENETICS；BEHAVIORAL TOXICOLOGY。[V.I.]

用于酒精康复的药物治疗已获得更广泛的接受。接受最多研究关注的特定药物治疗利用纳洛酮和二硫仑。其他有前途的药理干预是乙酰氨基酚和丁丙诺啡。纳洛酮是一种阿片受体拮抗剂，阻断大脑内源性阿片类药物的作用。来自动物研究的研究表明，酒精激活内源性阿片系统，因此可能有助于产生酒精消费的愉悦效果。因此，纳洛酮可能减少人们所消费酒精的强化作用，并降低其饮酒动力。二硫仑是一种导致乙醛脱氢酶抑制的药物，导致血液中乙醛水平增加。乙醛的升高产生恶心、呕吐、心动过速、呼吸困难和血压变化导致低血压。综合可能功能在于减少与兴奋性神经递质如N-甲基-D-天冬氨酸等相关的酒精诱导的欣快，并对阿片受体具有一些阻断作用。丁丙诺啡，一种非苯二氮卓类抗焦虑剂，可能减少与延长酒精戒断综合征相关的焦虑症状，从而降低酒精复发的潜力。这两种药物都需要进一步调查以确定其作为酒精依赖症治疗药物疗法的有效性。[S.Mar]

酒精药理学作用的精确机制尚不明确。酒精在低剂量时可作为兴奋剂，在高剂量时可作为抑制剂。即使在非常低的剂量下，酒精也会损害嗅觉和味觉的敏感度。此外，低剂量已知会改变运动协调能力和时间空间感知，这是驾驶汽车的重要方面。在0.05%水平时已可见某些效果。中等剂量会减弱痛觉敏感度。在某些个体中，酒精已知会减少自我意识感并抑制恐惧和焦虑，这些效果可能与酒精诱导的社交性相关。这些效果无疑作为使用含酒精饮料的心理强化因素。

## 藻珊瑚亚纲（Alcyonaria）

硬珊瑚纲（Anthozoa）的一个亚纲。这些刺胞动物通常为群体生活，多为固着性且栖息于潮间带，部分种类生活在极深海域。普通的息肉，即**自养水螅体（autozooid）**，具有八根可运动、可收缩、中空且呈羽状分支的触手。存在八组完整的**肠膜（mesenteries）**，其中背部或**非沟侧（asulcal）**的一对发育最完善，并承载最大、具丰富纤毛的外胚层丝状结构。其余肠膜承载具有许多腺细胞的内胚层丝状结构。纵向**缩肌**在其腹侧或**沟侧（sulcal）**表面发达。口球（stomodome）或咽部，其沟侧边缘具单一**口唇（siphonoglyph）**，由具纤毛的腺上皮覆盖。每个息肉的**胃腔（gastrovascular cavity）**通过复杂的管道系统或**管系（solenae）**相互连通。这些管道贯穿群体的**骨针中胶层（mesogloea）**或**共同组织（coenenchyme）**。骨骼由外胚层细胞分泌的角质物质沉积而成，或由分泌不同形状钙质骨针或骨板的**外胚层骨原细胞（scleroblasts）**形成。肌肉系统发育不特别完善。

息肉的口端称为**水螅体（anthocodium）**。基部，即**水螅柄（anthostole）**，嵌入含有大量变形虫样细胞和骨原细胞的共同组织中。

藻珊瑚亚纲的特征是具有高度发达的口唇，用于在群体中循环水流。藻珊瑚亚纲动物为雌雄异体或雌雄同体。性腺在内胚层肠膜丝中成熟。雌性息肉通过无性生殖从管系系统或亲代体壁上出芽形成。*Pennatulae*（海笔属）和其他一些种类具有**二型性（dimorphic）**。**管水螅体（siphonozooid）**比自养水螅体小。它没有触手，或触手退化且通常不育。参见：硬珊瑚纲（ANTHOZOA）；刺胞动物门（COELENTERATA）。[K.A.]
