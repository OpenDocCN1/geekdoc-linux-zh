### 标准式游戏

在玩家在游戏中选择策略后，他们并没有实际玩游戏。相反，结果是由所选策略或裁判决定的，然后由裁判执行他们的记录条目和他们本会移动的动作。这种直观的想法导致了游戏的收益矩阵。

至于在那一刻，由于游戏中没有动作，而是由于对于玩家 1, 2, ..., $n$，存在由 $s_1, s_2, ..., s_n$ 构成的纯策略，游戏的结果恰好以一种方式确定并产生一个结果。游戏是。令 `P1(s1, ..., sn)` 为玩家 1 玩游戏的收益。

在引入游戏的影响之前……

如果游戏中有动作，一组纯策略（每个玩家一个）将决定游戏的唯一结果。所有可能的策略必须互斥，且与它们的发生相关的动作收益是相关联的。因此，在这种情况下，我们令 `P1(s1, ..., sn)` 为……的预期收益。

## 游戏分类

如果每个可能的 $n$ 元策略 $s_1, s_2, ..., s_n$ 的所有玩家收益之和为零，则该游戏被称为零和游戏，即公式 (1) 成立：

`P1(s1, ..., sn) + P2(s1, ..., sn) + ... + Pn(s1, ..., sn) = 0`

对于某些纯策略游戏，其和不为零，被称为非零和游戏。如果每个玩家在每个动作做出时都知道，则游戏在极端情况下具有完美信息。如果每个玩家知道对方做了什么（但不知道自己做了什么），由于玩家的记忆在两个……之间划分，具有完美记忆。游戏论在经济学、社会学和政治科学等领域的应用导致了许多零和游戏。

### 非零和游戏

游戏论的大部分处理一个玩家的收益恰等于另一个玩家损失的游戏。当两个或多个玩家参与冲突局面时，游戏的……特征是联盟在一起以最大化总收益。具有联盟的游戏被称为合作游戏。在非合作游戏中，每个玩家只关心自己的收益。在这样的游戏的平衡点，一组混合策略 `s1, ..., sn`，使得公式 (2) 成立：

`P(s1, ..., sn) = Pi(s1, ..., sn)`

对于 `i = 1, …, n`，这意味着没有玩家可以通过改变策略来保持自己的收益。如果任何玩家改变策略而其他人保持固定，收益将得到提高。

### 简单游戏

零和游戏的一个重要类别是简单游戏。在这些游戏中，每个玩家都可以赢得、输掉或阻止。联盟可能是一个阻止联盟形成的玩家集合。如果联盟中的玩家不强制他们的策略，则联盟是阻止的。

### 连续游戏

在游戏的正式术语中，如果允许玩家从策略范围内选择，且收益允许是两个变量的函数，结果被称为连续游戏。
