# 脱氧核糖核酸 (DNA)

DNA是所有生物中存在的分子，使用核糖酸（RNA）的病毒除外。包含生物所有遗传信息的DNA集合被称为基因组。DNA主要存在细胞核中，但在真核细胞中部分位于线粒体和叶绿体。DNA也存在于称为质粒的自主细胞器中。参阅：核（NUCLEUS）。

# 剥蚀

所有导致地表降低的风化和侵蚀过程。剥蚀（Denudation）是指沉积物在沉积盆中积累完成后的过程。参阅：沉积过程与环境（DEPOSITIONAL PROCESS AND ENVIRONMENTS）；侵蚀（EROSION）；风化过程（WEATHERING PROCESS）。

自19世纪中期以来，记录陆地地区重新处理的沉积物和通量的现代记录被用于估计剥蚀速率。这些速率通常以地表降低速率表示，单位为毫米/年（mm/yr）。

近年来，开发出了允许定义地质尺度剥蚀速率的方法。发明沉积和地层记录以及定义大陆过程中的剥蚀的尝试，在很大程度上受益于沉积过程调查、提取和建模的改进。在陆地表面，基于岩石分布的剥蚀估算通过使用数字地形模型和绝对测年技术来实现。等效估算显示，我们喜马拉雅山保持着快速的基岩剥蚀速率（高达15 mm/yr）。

# 脱氧核糖核酸 (DNA)

与胸腺嘧啶形成两个氢键，胞嘧啶与鸟嘌呤形成三个氢键。这两对碱基保持相同的几何结构，使得DNA无论碱基对的具体序列如何，都能保持其结构。脱氧核糖（DEOXYRIBOSE）；嘌呤（PURINE）；嘧啶（PYRIMIDINE）

**结构。** DNA由两条链组成，它们相互缠绕形成双螺旋。链之间通过碱基配对结合在一起，并呈反平行结构。如果其中一条链的方向是5'到3'方向，另一条链的方向将是3'到5'方向。DNA的结构最早由J. D. Watson和F. H. Crick提出。DNA最常见的形式是B型，它是右旋的。DNA的其他形式包括A型（右旋）和Z型（窄且左旋）。

为了生命的生长，DNA中的遗传信息必须（1）从代传递，并（2）表达到细胞。参阅：遗传密码（GENETIC CODE）。

**复制。** 每条链都会复制。复制产物是保守的，意味着母本链和新生链。DNA复制非常准确。突变率约为每代1000个核苷酸，或10^9个碱基对。这种低错误率归于复制过程的高准确性和修复错配的途径。参阅：突变（MUTATION）。

**转录。** 在转录过程中，DNA作为RNA的模板。RNA是一种单链分子，含有核糖，并用尿嘧啶代替胸腺嘧啶。DNA链分离，一条单链被用合成RNA的模板。遗传信息直接从DNA转录为RNA。当RNA合成时，DNA恢复双链结构。参阅：突变（MUTATION）。

**遗传变异。** 不同生物的DNA含量序列存在大量差异。由于碱基配对，腺嘌呤与胸腺嘧啶、胞嘧啶与鸟嘌呤的比例在不同生物中从25%到75%不等。物种间的DNA含量也有很大差异。简单真核生物的基因组只有几个碱基对，而复杂真核生物的基因组拥有数十亿个碱基对。这种变异反映了更复杂生物基因数量的增加。每个变异也体现在不编码蛋白质的DNA中（称为内含子）。在大多数真核生物中，编码蛋白质的DNA序列（称为外显子）是不连续的，它们之间内含子。初始转录本由RNA聚合酶合成，然后通过剪接将外显子连接。RNA随后经过处理去除内含子，产生信使RNA（mRNA），随后翻译成蛋白质。参阅：蛋白质（PROTEIN）；核糖体（RIBOSOME）。

DNA在修饰碱基存在的情况下合成，这会导致掺入特定碱基后合成终止。这些方法现在可以被调整，从而确定生物整个基因组的DNA序列。目前，细菌和真菌基因组、小鼠和大基因组以及人类序列中含基因组部分的完整序列已确定。见人类基因组计划。[M.C.W.]

在细胞中，游基因组DNA必须高度压缩才能适应。例如，整个人类基因组的总长度约为3米（10微米）。这段DNA必须进入一个直径为10微米的细胞核。这种还原在真核生物中通过称为染色质的核蛋白结构中的多级压缩实现的。第一层涉及将20个碱基对的DNA折叠在一个称为核小体的核心上。核小体像线上的珠子一样连接在一起（见图3），形成直径10纳米的结构，并进一步缠绕成20-30纳米的纤维。30纳米的纤维通过蛋白质支架进一步缠绕并组织成环状。这种支架组织了有丝分裂期间中期染色体的复杂形状。见核小体（NUCLEOSOME）。

在原核生物中，DNA减少了DNA结合蛋白（如聚合酶和其他对转录和复制至关重要的因子）的可及性。因此作为转录的普遍抑制物。见核小体（NucleOSOME）。[L.C.L.]

电子显微镜显示腺病毒颗粒（直径70纳米；0.1微米 =100纳米）和腺病毒（20纳米）。

与其他一样，腺病毒具有脱氧核糖酸（DNA）核心。然而，尽管其生长依赖它，但其基因组似乎与“螺旋”无关。它的遗传内容及其结构都比腺病毒小，且蛋白质外壳与腺病毒完全不同。这些颗粒具有二十面体对称。双链DNA被发现存在腺病毒内部，以正链或互补链的形式存在于颗粒中。提取后，发现DNA形成了一个螺旋结构。
