
## 丛书编辑 Bruce Perens

是一位开源布道者、开发人员和顾问，他的软件是大多数商业嵌入式 Linux 产品的重要组成部分。他是 Linux 标准基（Linux Standard Base）、开源倡议（Open Source Initiative）和软件公共利益组织（Software in the Public Interest）的创始人或联合创始人。作为 Debian GNU/Linux 项目负责人，他在将该系统带上美国两次航天飞机飞行任务中发挥了重要作用。
