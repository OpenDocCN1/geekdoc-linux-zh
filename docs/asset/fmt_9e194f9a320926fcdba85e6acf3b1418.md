
`zmore` 是一个过滤器，允许在软拷贝终端上一次一屏地检查压缩或纯文本文件。`zmore` 可处理用 `compress`、`pack` 或 `gzip` 压缩的文件，也可处理未压缩的文件。如果文件不存在，`zmore` 会查找添加了 `.gz`、`.z` 或 `.Z` 后缀的同名文件。行为类似于 `more` 命令，一次打印一屏。

- 用于编辑命令行的内置命令行编辑器（emacs 或 vi）

- 只读变量
- 更好的缺陷报告工具

- 波浪号、花括号和参数展开
- 用于自定义按键序列的键绑定
- 高级模式匹配
- 数组
