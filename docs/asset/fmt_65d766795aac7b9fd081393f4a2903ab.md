# M

本地通用多用户服务器 Mserv 是一款音乐服务器，旨在在许多方面比大多数用于播放 mp3 的系统表现得更好：

- 支持使用标准 TCP 协议的任何类型客户端
- 在磁盘数据库中存储 mp3 信息（比特率、时长、名称、作者、流派、制作日期、最后日期）
- 用户提供的评分信息（优、差、中、好、来源等）
- 完善的队列系统（曲目、专辑、随机专辑等）
- 随机播放会根据人们在线创建的想要听的歌曲来选择歌曲的评分。
- 搜索功能、状态信息、统计数据等。
- 用户管理功能、四级用户、加密密码。
- Talker 趣味通信（说话、表情等）。
- 播放、下一首、停止、重复、音量、低音、均衡。
- 在线和离线曲目信息编辑。
- 高级过滤功能（例如 ‘john-super’、‘good’、‘year=1990’、‘duration=180’、‘genre=pop’、‘john=goodfriendunheard’）。
- 内置 talent 客户端（见手册）。
- 库接口，无需编写 TCP 代码。
- 带有用于交互的命令行服务器以及用于 Web 控制该服务器的 Web 客户端。
- 使用外部解析器输出，已知支持 mppeg321、mppeg123 和 freep - 这可以用于广播输出或支持其他播放器。附带适用于 mppeg123 兼容播放器的合适的解析器，可以提高低容量处理器的体验。更多信息请访问 http://www.mserv.org 来自 Debian 3.00 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
