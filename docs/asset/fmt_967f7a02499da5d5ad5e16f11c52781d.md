# fake IP 地址接管工具

Fake 是一种工具，通过在主机机上启动第二个接口并使用免费 ARP 来来实现 IP 地址的接管。设计用于局域网上的备份服务器。来自 Debian 3.0r0 APT

## FAQ

/F–A–Q/ 或 /fak/ n. [Usenet] 1. 常见问题。2. 一种积累知识的百科，定期发布在高流量新闻组中，试图防止此类问题的出现。有些人更倾向于使用“FAQ 列表”或 /FAQL/faql/，将 FAQ 留给含义 1。这个词汇表是此类知识集合的良好范例，或者它太大了，无法在 # 字符后发布 FAQ。例如：“NULL 的正确类型是什么？”和“# 的那个幽默的名字叫什么？”都是常见问题。若干处 FAQ 指向了此。来自术语字典 (Jargon Dictionary)

`http://www.tld.org/LDP/Linux–Dictionary/html/index.html`

## faqomatic

在线界面 CGI。使用 CGI 创建基于 Web 的 FAQ。它保留有关访问的累计统计数据。高度可定制，可以仅允许你选择的人更新 FAQ，或者根据你的需求允许任何人更改。它还会生成页面缓存，设计使得大多数数据访问将通过 Web 服务器提供，而没有 CGI 的开销。如果你想生成统计数据，请安装 lib-perl。来自 Debian 3.0r0

`http://www.tldp.org/LDP/Linux–Dictionary/index.html`
