## 第7章 系统调用的跟踪工具

### 71.1 `strace`/`dtruss`

Linux 内核提供了一款非常有用的调试工具，它可以跟踪某个进程调用的系统调用（以及该进程收到的信号）[1]。这款工具就是 `strace`。它属于命令行工具，在使用时，我们可以希望跟踪的应用程序直接指定命令参数。例如：

```
# strace -h
```
