`acct`

### 概要

`/usr/bin/acct [-abfhkmqrtv] [-C sec] [-e time] [-E time] [-g group] [-H factor] [-I chars] [-l line] [-n pattern] [-o output-file] [-O sec] [-s time] [-T time] [-u user] [filename...]`

## 描述

`acct` 是用于构建会计系统的工具套之一。使用 `acct` 命令搜索由 `acct(4)` 创建的会计文件并将标准输入或 `/var/adm/pacct` 写入标准输出。每条记录代表一个进程的执行。输出显示 COMMAND, USER, TTY, START TIME, END TIME, REAL (SEC), CPU (SEC), MEAN SIZE (K)，以及可选的 F (fork())/exec 标记：STAT（系统退出状态），HOG FACTOR, KCORE MIN, CPU FACTOR, CHARS TRNSFD 和 BLOCKS READ（总读写块）。用超级用户权限执行命令时，命令名前加上 (#)。当进程与已知终端关联时，TTY 字段将显示 ?。

# 22

当你不指定名称且标准输入与终端或 `/dev/null` 关联时（例如在 shell 中使用 & 时），读取 `/var/adm/pacct`。任何文件参数按其顺序读取。每个文件通常正向读取，即按进程完成时间的时间顺序排列。文件 `/var/adm/pacct` 通常是正在检查检查的文件；繁忙的系统可能需要此类文件，其中所有当前文件都在 `/var/adm/pacct` 中找到。`acct` 仅报告已终止的进程。对于活动进程使用 `ps(1)`。

## 选项

- `a` 显示所选进程的一些平均统计数据。在输出记录后打印统计数据。

- `b` 回读，优先显示最新命令。当读取标准输入时，此选项无效。

- `f` 在输出中打印 fork()/exec 标记和系统退出列。以八进制显示数值输出。

- `h` 代替内存大小，显示进程在执行期间消耗可用 CPU 时间的比例。此 hog 因子计算为 (总 CPU 时间)/(通过时间)。

- `i` 在输出中打印包含 I/O 计数的列。

- `k` 代替内存大小，显示总 kcore 分钟。

- `m` 显示平均核心大小（默认）。

- `q` 不打印任何输出记录，像 `-a` 选项一样打印平均统计数据。

- `r` 显示 CPU 因子（用户时间/(系统时间+用户时间)）。

- `t` 显示独立的系统和用户 CPU 时间。

- `v` 排除总 CPU 时间（系统时间+用户时间）超过 `sec` 秒的列。

- `e time` 显示在时间或之前存在的进程。

- `E time` 显示在时间或之前结束的进程。对 `-S` 和 `-E` 使用相同的时间，显示在该时间存在的进程。

- `group` 显示仅属于某个组的进程。你可以通过组 ID 或组名指定该组。

- `H factor` 显示仅超过 `factor` 的进程，其中 `factor` 是上述选项 `-h` 中解释的 hog 因子。

- `I chars` 显示仅传输字符超过 `chars` 给出的截止数字的进程。

- `line` 显示仅属于终端 `/dev/term/line` 的进程。

## `acctcom` 23

- `-n pattern` 显示仅匹配模式的命令，模式可以是正则表达式（如 `regcmp(3)`），其中 `+` 表示一次或多次出现。

- `-o output-file` 将选定的进程记录按输入数据格式复制到 `output-file`；抑制打印到标准输出。

- `-O sec` 仅显示 CPU 系统时间超过 `sec` 秒的进程。

- `-s time` 显示在给定时间或之后存在的进程，格式为 `hr[min;sec]`。

- `-u user` 仅显示属于特定用户的进程。你可以指定用户 ID、转换为用户 ID 的名称、`#`（指定仅以超级用户权限执行的进程）或 `?`（指定与未知用户 ID 相关的进程）。
