# gzip 实用

GNU zip (`gzip`) 实用使用了 Lempel-Ziv 算法 (`LZ77`)，该算法与 `compress` 实用使用的算法略有不同。通常，该算法为 `gzip` 提供的平均压缩率为 60% 到 70%。
