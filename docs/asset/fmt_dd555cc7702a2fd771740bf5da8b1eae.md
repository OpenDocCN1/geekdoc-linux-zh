## 告别鼠标

《Linux 命令行》带你从第一次击键一直到使用最新版本的 bash（最流行的 Linux Shell）编写完整的程序。

这部全球畅销书的第二版包含了 bash 4.x 功能的内容，例如新的重定向操作符和扩展。更新后的脚本部分讨论了现代、健壮的脚本实践以及避免常见类型错误的方法。

与第一版一样，你将学习持久的命令行技能，如文件导航、环境配置、命令链以及使用正则表达式进行模式匹配。

通过书中简短易于理解的章节，你将学习如何：

- 创建和删除文件、目录和符号链接
- 管理你的系统，从网络和包安装到进程管理
- 使用标准输入输出、重定向和管道
- 使用 vi（最流行的文本编辑器）编辑文件
- 编写脚本自动处理常见的任务
- 使用 cut、paste、grep、patch 和 sed 切割和处理文本

一旦你克服了最初的“命令行冲击”（shell shock），你会发现命令行是与计算机通信的一种自然且富有表现力的方式。
