
## 集合运算

- `X` ∪ `Y`, `X` + `Y`
  集合 `X` 和 `Y` 的并集
- `X` ∩ `Y`, `X` · `Y`
  集合 `X` 和 `Y` 的交集
- `+`, `-`, ∪
  集合 `X` 和 `Y` 的对称差
- ∪`X`ᵢ, ∩`X`ᵢ
  所有集合 `X` 的并集
- ∅, ∅
  空集，零集
- `X`′, `C`₂ `X`
  集合 `X` 的补集
- `X` − `Y`, `X` `Y`
  集合 `X` 和 `Y` 的差
- `A(P)(x)`, `{x: P(x)}`, `{x: P(x)}`
  具有性质 `P` 的所有 `x` 的集合
- `(x, y, z)`, `(x, y, z)`
  元素 `x`, `y`, `z` 的有序集；需与例如 `{x, y, z}` 区分
- `{x, y, z}`
  无序集，其元素为 `x`, `y`, `z`，且无其他元素
- `{a₁, a₂, … , aₖ}`; `{b₁, b₂, … , bₖ*}`, `{c₁, c₂, … , cₖ*}`
  成员为 `aᵢ` 的集合，其中 `i` 是从 1 到 `n` 的任意整数
- `{a₁, a₂, … }`, `{b₁, b₂, … , bₖ*}`, `{c₁, c₂, … , cₖ*}`
  成员为 `aᵢ` 的集合，其中 `i` 是任意正整数
- `X` × `Y`
  笛卡尔积，满足 `x` ∈ `X`, `y` ∈ `Y` 的所有 `(x, y)` 的集合

## 数学符号与记号

- `$A$`：元素为 `$a_i$` 的集合，其中 `$i \in I$`
- `x(y), R(x, y)`：关系
- `~, ≡, ≠`：等价关系，例如，同余
- `≷, ▷, ◁, ≻, ⪯`：传递关系，例如，数值序
- `f: X → Y, X × Y, f: Y ← X`：函数、映射、变换
- `f^{-1}`：逆映射
- `g ∘ f`：复合函数：`(g ∘ f)(x) = g(f(x))`
- `f(X)`：`X` 在 `f` 下的像
- `f^{-1}(X)`：逆像集，原像
- `1 → 1`，one-one：读作“一一对应”
- `△`：图示：当 `φ ∘ f = g ∘ ψ` 时，图示是交换的
- `Y/X, Y/Z`：偏函数，函数 `f` 到集合 `A` 的限制
- `f|_A`：集合 `A` 的基数
- `X, card X, #X`：可数无穷
- `ℵ₀, ℵ₁`：连续统的势
- `c, 𝔠, 2^{ℵ₀}`：正整数集的序型
- `ω`：整数
- `ℤ`：读作“可数”
- a.e., `d.p.`：几乎处处，几乎必然
- ess sup：本身上确界
- Space：连续函数空间
- `C⁰, Cᵏ([a, b], ℂ)`：具有连续 `k` 阶导数的函数类（在 `[a, b]` 上）
- `ℓ_p, L_p`：与 `C¹` 相同
- `L_p, ℓ_p`：函数的 Lipschitz 空间
- `L¹, L², L²[a, b]`：绝对 `p` 次方可积函数空间（在 `[a, b]` 上）
- `L^∞`：与 `L¹` 相同
- `C([a, b]), (C, p)`：Cesaro 可和性

## 特殊函数

- `Γ`：`π` 的整数部分
- `⎡ n k ⎤`：二项式系数 `n!/(n-k)!`
- `⎧ n k ⎫`：勒让德符号
- `!^x`：指数函数
- `e^x`，exp `x`：双曲函数
- `sinh x`，`cosh x`，`tanh x`：雅可比椭圆函数
- `sn x`，`cn x`，`dn x`：韦伯斯特拉斯椭圆函数
- `Γ(x)`：伽马函数
- `J(x)`：贝塞尔函数
- `λ_x(x)`：集合 `X` 的特征函数：若 `x ∈ X` 则 `λ_X(x) = 1`，否则 `λ_X(x) = 0`
- `Δ`：符号函数：`sgn x = 0`，而当 `x ≠ 0` 时 `sgn x = x/|x|`
- `δ(x)`：狄拉克 δ 函数

## 数，数值函数

- 1, 4, 1.4, 1'4：读作“一又十分之四”
- `[1](2)(10)100`：读作“从 1 到 20 间隔为 1，从 20 到 100 间隔为 10”
- const：常数
- `A ≥slant 0`：数 `A` 非负，或矩阵 `A` 正定，或矩阵 `A` 的元素非负
- `x | y`：读作“`x` 整除 `y`”
- `x ≡ y (mod p)`：读作“`x` 模 `p` 同余于 `y`”
- `a₀ + 1/(a₁ + 1/(a₂ + ⋯))`, `a₀ + 1/a₁ + 1/a₂ + ⋯`：连分数
- `[a, b]`：闭区间
- `[a, b]`：半开区间（右端开）
- `[a, b)`：开区间
- `[a, ∞) [∞, -∞]`：左端闭、右端无界的区间
- `(-∞, ∞) [a, -∞]`：所有实数的集合
- `max_X {f(x), max {f(x) | x ∈ X}`：当 `x` 属于集合 `X` 时 `f(x)` 的最大值
- `min`：最小值
- `sup, I.u.b.`：上确界，最小上界
- `inf, g.l.b.`：下确界，最大下界
- `lim_{x → a} f(x) = b, lim_{x → ∞} f(x) = b`：`b` 是 `f(x)` 当 `x` 趋近于 `a` 时的极限
- `f(x) → b` as `x → a`
- `lim_{x → ∞} f(x), lim_{x → ∞} f(x), f(a -)`：`f(x)` 当 `x` 从左侧趋近于 `a` 时的极限
- `lim sup`：上极限
- `liminf`：下极限
- `I.u.b.`：平均极限
- `L.L.`
- `z = x + iy = re^{iθ}`, `z = ξ + iη`：复变量
- `ū = u + iv = āb̄`：复共轭
- `ℜ`：实部
- `ℑ̅`：虚部
- `arg`：辐角
- `Δ(x, y), D(x, y)`：雅可比行列式，函数行列式
- `Δ(x, y), Δ'x, y)`：雅可比行列式，函数行列式
- `∫`：积分（例如，函数 `f` 在集合 `E` 上关于测度 `μ` 的勒贝格积分）
- `f(n) → log n` as `n → ∞`：当 `n → ∞` 时 `log n` 趋近于 `∞`
- `f(n) → log n` as `n → ∞`：当 `n → ∞` 时 `f(n) log n` 趋近于零
- `f(n) ∼ b, f(x) ↑ b`：`f(x)` 增加，趋近于极限 `b`
- `f(n) ∼ b, f(x) ↓ b`：`f(x)` 减少，趋近于极限 `b`
