
```c
#include <sys/types.h>
#include <sys/socket.h>

int sendto(int s, const void *msg, int len, unsigned flags, const struct sockaddr *to, int tolen);
```

`flags`:

- `MSG_OOB` 处理带外数据。
- `MSG_DONTROUTE` 绕过路由。
- `MSG_DONTWAIT` 写入时不阻塞等待。
- `MSG_NOSIGNAL` 不抛出 `SIGPIPE`。

### `fcntl(2)` 使用 `F_SETOWN`

```c
#include <unistd.h>
#include <fcntl.h>

int fcntl(int fd, int cmd, long arg);
```

`cmd` 值 `F_SETOWN` 允许建立套接字的所有权，以 `arg` 中给出的进程 ID 为准。

### `ioctl(2)` 测试标记

```c
#include <sys/ioctl.h>
int z;   /* 状态 */
int s;   /* 套接字 */
int flag; /* 在标记处时为真 */

z = ioctl(s, SIOCGETMARK, &flag);
if ( z == -1 )
    abort();           /* 错误 */
if ( flag != 0 )
    puts("At Mark");
else
    puts("Not at mark.");
```
