## ssl 关键字参数

| 参数 | 描述 |
| :--- | :--- |
| server_side | 布尔标志，指示 socket 是作为服务器 (True) 还是客户端 (False) 运行。默认值 own False。 |
| keyfile | 用于识别连接本地侧的密钥文件。这应该是一个 PEM 格式的文件。 |
| certfile | 用于识别连接本地侧的证书文件。这应该是一个 PEM 格式的文件。 |
| cert_reqs | 指定是否需要连接另一端提供证书以及是否对其进行验证。`CERT_NONE` 表示忽略证书；`CERT_OPTIONAL` 表示不需要证书但如果提供了将进行验证；`CERT_REQUIRED` 表示需要证书并进行验证。如果提供了证书，则必须提供 `ca_certs` 参数。 |
| ca_certs | 用于验证的证书颁发机构证书文件路径。 |
| ssl_version | 使用的 SSL 协议版本。可能值为 `PROTOCOL_TLS1`、`PROTOCOL_SSLv2`、`PROTOCOL_SSLv3`，默认协议为 `PROTOCOL_SSLv3`。 |
| do_handshake_on_connect | 布尔标志，指定连接时是否自动执行 SSL 握手。默认值为 True。 |
| suppress_ragged_eof | 指定 `read()` 是否处理连接的意外 EOF。如果为 `True`（默认），则指示一个正常的 EOF。如果为 `False`，则抛出异常。 |

`s.getpeercert([binary_form])`

返回连接另一端的证书，如果没有证书，则返回 `None`。如果存在证书但未通过验证，则返回一个空字典。如果收到了一个通过验证的证书，则返回一个包含键 'subject' 和 'notAfter' 键的字典。如果 `binary_form` 为 `True`，则以 DER 编码的字节序列形式返回证书。

`s.read(nbytes)`

读取最多 `nbytes` 字节的数据并返回。如果省略了 `nbytes`，则返回最多 1,024 字节的数据。

`s.write(data)`

写入字符串数据。返回写入的字节数。

`s.unwrap()`

关闭 SSL 连接并返回底层的套接字对象，可以在该对象上进行进一步的加密通信。

该模块还定义了以下实用函数：

`cert_time_to_seconds(timestring)`

将证书中使用的格式的字符串时间 `timestring` 转换为浮点数，与 `time.time()` 函数兼容。

`DER_to_PEM_CERT(derbytes)`

给定一个包含 DER 编码证书的 `derbytes`，返回 PEM 编码的字符串版本证书。

`PEM_to_DER_cert(pemstring)`

给定一个包含 PEM 编码字符串版本证书的 `pemstring`，返回 DER 编码的字节版本证书。

`get_server_certificate(addr, ssl_version [, ca_certs])`

检索 SSL 服务器的证书并以 PEM 编码的证书形式返回。`addr` 是一个（主机名, 端口）的地址。`ssl_version` 是 SSL 版本号，`ca_certs` 是如 `wrap_socket()` 函数中描述的证书机构证书文件名。

`RAND_status()`

如果 SSL 层认为伪随机数生成器已用随机数种子，则返回 `True` 或 `False`。

`RAND_egd(path)`

从熵收集守护进程读取 256 字节的随机数并添加到伪随机数生成器中。`path` 是守护进程的 UNIX 域套接字名称。

`RAND_add(bytes, entropy)`

将字符串字节 `bytes` 添加到伪随机数生成器中。`entropy` 是一个非负浮点数，表示熵的下限。

## 示例

以下示例展示了如何使用此模块打开 SSL 客户端连接：

```python
import socket, ssl

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

ssl_s = ssl.wrap_socket(s)

ssl_s.connect(('gmail.google.com',443))

print(ssl_s.ciphers())

#发送请求
ssl_s.write(b"GET / HTTP/1.0\r\n\r\n")

# 获取响应
while True:
    data = ssl_s.read()
    if not data:
        break
    print(data)

ssl_s.close()
```

这是一个 SSL 安全时间服务器的示例：

```python
import socket, ssl

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR,1)
s.bind(('',12345))
s.listen(5)
while True:
    client, addr = s.accept()      # 获取连接
    print("Connection from", addr)
    client_ssl = ssl.wrap_socket(client,
                                server_side=True,
                                 certfile="timecert.pem")
    client_ssl.send(b"HTTP/1.0 200 OK\r\n")
    client_ssl.send(b"Connection: Close\r\n")
    client_ssl.send(b"Content-Type: text/plain\r\n")
    resp = "time:" + str(time.time()) + "\r\n"
    client_ssl.send(resp.encode('latin-1'))
    client_ssl.close()
client.close()
```
