
# 删除 `.desktop` 文件

访问 `.desktop` 规范 `https://specifications.freedesktop.org/desktop-entry-spec/desktop-entry-spec-latest.html` 了解所有 `.desktop` 相关信息。

## 通过命令行删除 `.desktop` 文件

在终端中执行以下命令：

```bash
cd /usr/share/applications
```

```bash
dir
```

[`Dir` 列出目录下所有的文件和文件夹。]

```bash
sudo cp uget-gtk.desktop uget-gtkdesktop
```

[将 `uget` `.desktop` 文件备份]

```bash
sudo rm -r uget-gtk.desktop
```

[删除 `uget` `.desktop` 文件.]

```bash
sudo update-desktop-database
```

[更新 `.desktop` 应用程序数据库。]

# 电源设置

## 通过 GUI 调整电源设置

通过图形用户界面调整电源设置，请从应用程序菜单中打开“设置”。接下来，导航到“电源”部分。在这里，你将找到“屏幕休屏”选项；选择它并设置为“5 分钟”。之后，寻找“自动挂起”功能并通过选择“关闭”选项将其关闭。此过程非常直观，可确保您的电源设置高效地按照您的喜好进行配置，而无需过于复杂的指令或冗余步骤。

## GNOME 扩展

`GNOME Shell` 扩展由第三方开发，通过允许如窗口管理微调或应用启动修改等自定义功能来增强 `GNOME` 界面。你可以在专门的网站上找到并管理这些扩展，它们带有唯一的标识符 (`uuid`) 以确保安全安装。虽然它们提供了从细微到重大的界面变化的多样化功能增强，但用户应当谨慎操作；因为扩展与操作系统深度集成，可能会导致系统问题或安全风险。尽管如此，它们在提供下载之前会经过严格的安全性审查，以确保创新与安全之间的平衡。

`GNOME Shell` 扩展管理器（`Extension Manager`）简化了 `GNOME` 扩展的安装和管理。该工具允许用户直接从 `extensions.gnome.org` 网站浏览、安装、删除、启用或禁用扩展，无需网络浏览器。它在 `Ubuntu` `21.10` 及更高版本上特别有用，因为那里默认的 `Firefox` 由于其 `Snap` 格式无法安装扩展。从 `GNOME` `43` 开始，它支持应用内更新，并能够管理已安装的扩展（包括系统扩展），提供了一种精简体验。它通过 `Flathub` 以 `Flatpak` 包的形式，是增强 `GNOME` 桌面环境的必备工具。

`GNOME Shell` 集成 `Chrome` 扩展和 `Firefox` 载程序促进了 `GNOME` 桌面环境与相应浏览器之间的无缝交互。它们允许用户直接从浏览器安装、管理和应用 `GNOME Shell` 扩展，而无需使用终端或其他工具。这种集成简化了 `GNOME` 桌面体验的自定义和增强，使其对于偏于使用图形界面而非命令行操作的用户来说更加易用。

`User Themes` 扩展为 `Linux Mint` `21` 上的 `GNOME` 桌面环境设计，允许用户自定义 `GNOME Shell` 的外观。默认情况下，`GNOME Tweaks` 无法更改 `GNOME Shell` 主题。安装此扩展后克服了这一限制，直接在环境中提供了更多的个性化选项。

`ArcMenu` 是一款顶级的 `GNOME Shell` 扩展，提供从简单到奇特的各种布局的传统应用菜单体验。它具有内置的 `GNOME` 搜索、快速系统快捷键访问，以及时尚的视觉更新（如可调整的搜索框圆半径）。最新版本包含了错误修复和改进，例如为类别和应用程序设置独立的图标大小，以及 `Windows 11` 风格的电源按钮子菜单。

`Dash to Panel` 是一款多功能的 `Gnome Shell` 扩展，它能将 `Dash` 转换为统一的主面板，合并应用启动器和系统托盘，提供类似于 `KDE Plasma` 和 `Windows 7+` 的精简体验。它消除了对独立 `dock` 的需求，可以轻松访问运行中和收藏的应用。它具有高度定制性，允许用户调整面板的外观、行为和功能，包括运行指示、窗口预览和智能功能。如自定义运行指示、悬停实时预览、启动应用程序的键盘快捷键以及多显示器支持等功能增强了易用性，让您的工作空间更加个性化且高效。

`Desktop Icons (NG)` 是 `GNOME Shell` 的一项增强，作为官方 `Desktop Icons` 扩展的修订版本。它引入了诸如直观的跨桌面、应用程序和 `Nautilus` 窗口的拖放功能，以及针对多个文件的通用“用...打开”选项。它确保图标在悬停或点击时显示完整全称（即使名称过长也是如此），并在高强度的桌面活动下保持合成器的稳定性。

`Tray Icons: Reloaded` 是一项 `GNOME Shell` 扩展，通过将托盘图标返回顶部面板来重振您的桌面，并丰富了新功能。它引入了带有“三点”图标的溢出模式、可自定义的托盘位置、图标限制和大小。用户可以精调图标颜色饱和度、对比度和亮度，以及可调整的托盘、图标边距和内边。

# `GNOME Shell Extension Manager`

访问 `GNOME Shell Extension Manager` 官方网站 `https://github.com/mattjakeman/extension-manager` 获取有关 `GNOME Shell Extension Manager` 的所有信息。

通过软件管理器安装 `DEB`/`FLATPAK` 程序包：

- 打开软件管理器并搜索 `GNOME Shell Extension Manager`。
- 点击 `GNOME Shell Extension Manager`，然后点击源选择框。
- 选择系统包 (`System Package`) 或 `Flatpak` 并点击安装。

在终端中通过 `APT` 安装 `GNOME Shell Extension Manager`：

输入这些命令：

```bash
sudo apt update
sudo apt install gnome-shell-extension-manager
```

在终端中通过 `Flatpak` 安装 `GNOME Shell Extension Manager`：

输入此命令：

```bash
flatpak install flathub com.mattjakeman.ExtensionManager
```
