# 458 尝试 sed

这正是 `sed` 旨在创建的任务。与标准（交互式）编辑器不同，流编辑器通过遍历文件并根据规则进行更改。这种情况下规则是将 219 更改为 260。这并不简单，如果你使用命令：

```
sed /219/260/
```

结果并不是你想要的：

1218:Cottrell:Marketing:260.555.5555:123 Main Street
