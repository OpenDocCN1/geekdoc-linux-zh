# 变星

亮度发生变化的恒星，通常是由其他物理过程引起的。在恒星的生命期间，亮度的变化发生在早期或后期，由于不稳定性以及由恒星演化和性质引起的变性。取决于恒星的类型，变性可以提供关于其大小、质量、温度、光谱类型和离地球距离的信息。已知超过31,000颗恒星是变星。

长周期变星是银河系中所有变星中最丰富的。它们是红色的、低温的或光谱分类为M、R或C的碳星超巨星。长周期变星是离开主序并处于演化后期的恒星。

变星可分为两类：内变星和外变星。外变星是指由于一颗恒星被另一颗恒星遮挡（食双星除外）或表面具有类似黑子的点的恒星旋转而导致亮度变化的恒星。

长周期变星的演化是造父变（天座），它为周期范围在250个等值及更多的长周期变星命名。造父变星的周期在100到1000天之间。它们是周期性的，可能比其他星亮或更远。

内变星是指亮度由于恒星内部或表面的现象而变化的恒星。它们分为两类：脉动型和爆发型。

红变星和巨变星通常表现出黄化效应，变化周期较短，小于2天。不表现出任何亮度规律的非脉动变星称为不规则变星。

脉动变星。恒星或其外层的脉动（收缩和扩张）导致亮度的变化。许多变星的周期范围在1到2个等值之间。造父变星在其变化周期和相对等值之间显示出重要的相关性，周期越长的星越亮。由于它们亮度很高，可以用于测量到星系的距离，并确定宇宙的尺度。

爆发变星。这些是在寿命中经历过一次或多次爆发（质量抛射）的恒星。最壮观的恒星爆炸类型是超新星，恒星的亮度突然增加数千年，然后原恒星逐渐暗，总亮度失去原始亮度。巨大的爆炸由于恒星的引力塌缩引起，核反应释放了大量的能量，从而产生足够的能量吹散核心周围的层。或者，爆炸可能发生在双星系统中，当白矮星接收来自另一个组件过多的物质时发生爆炸。

一组变星，处女座W，发现于球形星团和银河系中心，比造父变星更蓝（温度更高）且更老（II族星）。它们的周期从1到20天不等，没有周期-光度关系。它们有时根据经典的I型造父变称为II型造父变星。

# 变分法（物理）

变分法在量子力学计算中也起着重要作用。对于计算由微分方程产生的函数所需的量，使用使输入在附近微小变化时泛函保持平稳的公式总是具有巨大的优势。
