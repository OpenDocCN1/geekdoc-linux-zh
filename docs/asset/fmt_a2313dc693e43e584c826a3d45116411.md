钙骨素——一种激素，由哺乳动物甲状腺的旁滤细胞或 C 细胞产生，在调节钙和磷酸末端支中具有重要性。

钙骨素与甲旁腺激素共同作用，产生于甲状腺的所有形式中，并调节血钙水平。其主要功能是通过抑制骨吸收来保护骨骼免受钙过度流失的后果。这在磷酸和骨骼的钙化过程中产生钙，因为如果没有骨吸收，骨矿物质的各种成分将以骨吸收物质的形式释放到血液中。参见：钙代谢；甲旁状腺；甲旁状腺激素。

钙骨素在某些情况下还会导致尿液排出磷酸，但目前尚不确定这是激素对肾脏的直接作用，还是切除甲状腺后血钙水平下降的间接结果。参见：磷酸代谢；甲状腺。

# 潮汐

潮位计的记录影响了相邻位点。层层叠叠的波浪被测量中的一个阻尼孔所衰减。良好的记录高度经过平均处理，以确定每日较高（或唯一）潮的平均值（24.84小时）、所有高潮、所有低潮以及较罕见的（或唯一的）低潮。平均长度为19年，它平均了整个月交点周期和梅影周期内的所有潮汐（*梅影周期是19个月球年的周期，即月球在每月的相同日期出现的周期。但只有19年的平均值在测量能力、气象观测、工程和法律方面具有重要意义。*）。

潮位基准是相等的。重力变化、沉积状况、垂直洋流、潮汐特性、海水密度差异以及海平面（在任何时间和位置）都不会影响从根本上定义的潮汐。参见地理测量学（GEODESY）。

潮汐能通过利用海岸的升降获得。海洋盆地用大坝围成，使得利用海洋与盆地之间的水位差发电。填充或排空盆地的震荡水流被用于驱动涡轮，从而驱动发电机。

潮汐沉积物是由潮下流和潮上流中的潮汐过程沉积的各种成分组成的。沿中海岸产生涨潮流和落潮流，它们在高波和低波之间推进和退缩，并运行于潮下环境。这些水流携带了沉积输运的物质。

平坦潮滩（包括潮上带和潮间带）是潮汐环境中广为人知的。在这些区域存在非陆地潮滩和非潮汐滩涂，前者通常形成潮汐。

非陆地潮汐沉积物由低潮、中潮和高潮（潮下）部分组成。这每部分都由不同的沉积过程形成，具有特征纹理和沉积结构。在潮滩上，细颗粒沉积物从高潮线附近的地下积累，而较粗的沙子通过底床运移沉积。这些分层床和沙层是在交替的底质推移和沉积条件下沉积的（见插图）。

非陆地潮滩不接收陆地海岸沉积物。积累在这些潮滩上的沉积物由盆地内的有机颗粒组成。主要生活在水面下的各种生物在其生命周期中形成碳酸钙，并在硬性工作后分解产生碎屑；粘土、粉土和砂粒。
