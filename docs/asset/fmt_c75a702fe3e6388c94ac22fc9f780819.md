
# 13 章：文件系统管理

`where`

- `block-special-file` 是系统所在特殊文件的名称，例如 IDE 驱动器上第一个分区的块设备名，如 `/dev/hda1`。
- `mount-loc` 是文件系统将被挂载的目录。如果该目录位于用于交换的分区上，使用 `swap` 作为 `mount-loc`。
- `type` 是分区的类型。对于原生 Linux 文件系统，`type` 为 `ext2`。
- `opts` 是用于列出选项的字段，以逗号分隔。选项可能包括以下任意项：

### `rw`
允许对文件进行读取和写入（读写模式）。

### `ro`
允许对文件进行读取（只读模式）。

### `dev`
将此文件系统中的特殊文件视为特殊文件。

### `nodev`
将此文件系统中的特殊文件视为文件名。

### `exec`
允许从该文件系统执行二进制文件。

### `noexec`
防止从该文件系统执行二进制文件。这对于包含所有数据的文件系统非常有用，可以防止系统破解者引入程序，或防止人们尝试执行本应运行在不同系统（如 MS-DOS）上的程序。

### `auto`
允许通过 `mount` 命令的 `-a` 选项挂载文件系统。

### `nouser`
禁止非超级用户挂载文件系统。

### `async`
异步向文件系统写入数据。系统速度更快，但如果发生故障可能会丢失数据。

### `sync`
同步向文件系统写入数据。

### `suid`
允许 `suid`（设置用户 ID）访问模式（默认值）。
