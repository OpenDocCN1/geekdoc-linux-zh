
# nischown — 修改 NIS+ 对象的所有者

## 概要

```
/usr/bin/nischown [-aLP] owner name...
```

## 描述

使用 `nischown` 命令将按名称指定的 NIS+ 对象或条目的所有者更改为 `owner`。使用索引名称指定条目（见 `mismatch(1)`）。如果 `owner` 不是完全限定的 NIS+ 主体名（见 `nisadcred(1)`），将附加默认域（见 `nisdefaults(1)`）。
更改对象所有者的唯一限制是你必须拥有该对象的修改权限。

> 注意 — 如果你是当前对象的所有者并更改了所有权，除非对新对象具有修改权限，否则你可能无法重新获得所有。

NIS+ 服务器在进行修改之前会检查名称的有效性。如果主 NIS+ 服务器未运行，`nischown` 命令将失败。

## 选项

- `-A` 修改连接路径中所有表中匹配 `name` 中指定搜索标准的条目。此选项蕴含了 `-P` 选项。
- `-f` 强制执行操作，如果不成功则静默失败。
- `-L` 跟踪链接并更改链接对象或内部条目的所有者，而非链接本身的所有者。
- `-P` 跟踪命名表内的连接路径。此选项仅当 `name` 为索引名称或你指定了 `-L` 选项且命名对象是指向条目的链接时有效。

## 示例

以下两个示例展示了如何将对象的所有者更改另一个域的主体（principal），以及如何将其更改为本地域主体。

```
castle% nischown bob.remote.domain object
castle% nischown skippy object
```

以下示例展示了如何更改 `passwd` 表中条目的所有者。

```
castle% nischown bob.remote.domain '[uid=99],passwd.org_dir'
```

以下示例展示了如何更改指向链接的对象或条目。

```
castle% nischown -L skippy linkname
```

## 环境变量

`NIS_PATH` 如果此变量已设置且 NIS+ 名称不是完全限定的，则搜索每个指定的目录，直到找到对象为止（见 `nisdefaults(1)`）。

# nischttl — 修改 NIS+ 对象的生存时间（TTL）值

### 概要

`nischttl [-aFLpP] time name...`

## 描述

使用 `nischttl` 命令将 `name` 指定的 NIS+ 对象或条目的生存时间值（ttl）更改为 `time`。使用索引名称指定条目（见 `nismatch(1)`）。

生存时间值被对象缓存用于设置缓存内对象的过期时间。当对象被读取到缓存时，该值将加到当前时间（秒），从而得到缓存对象过期的时间。只要当前时间早于计算出的过期时间，就可以从缓存中返回对象。当到达过期时间时，对象将从缓存中刷新。

你可以以秒指定生存时间，也可以以“天、小时、分钟、秒”的格式指定。后者格式使用后缀字母 `d`、`h`、`m` 或 `s` 来识别时间单位。

如果主 NIS+ 服务器未运行，则该命令将执行失败。

> 注意：设置高 `ttl` 值允许对象在缓存中留存更长时间并可以提高性能。然而，当对象发生变化时，在坏情况下，此属性中的秒数对所有客户端可见。将 `ttl` 值设为 0 则完全不缓存该对象。

高 `ttl` 值是一周，低值小于一分钟。密码条目的 `ttl` 值应为 12 小时左右（轻松允许每天更改一次密码），RPC 表中的条目可以具有几周的 `ttl` 值（这些信息实际上是不经常改变的）。在此实现中，只有目录对象和组对象被缓存。

## 选项

- `-A` 修改拼接路径中所有匹配 `name` 中指定搜索准的表。此选项隐含了 `-P` 选项。
- `-f` 强制执行操作，如果未成功则静默失败。
- `-L` 遵循链接并更改所链接对象或条目的生存时间，而不是链接本身的生存时间。
- `-P` 遵循命名表内的拼接路径。此选项仅当其中一个名称是索引名称，或者你也指定了 `-L` 选项且该命名对象是指向条目的链接时才有意义。

## 示例

以下示例使用第二种格式以及“天、小时、分钟、秒”格式更改对象的 `ttl`。第二个对象的 `ttl` 被设置为 1 天 12 小时。

```
castle% nischttl 184000 object
castle% nischttl 1d12h object
```

以下示例更改密码条目对应对象的 `ttl`。

```
castle% nischttl 1h30m [uid=99],passwd.org_dir
```

接下来的两个示例更改由链接指向的对象或条目的 `ttl`，以及 `hobbies` 表中所有条目的 `ttl`。

```
castle% nischttl -L 12h linkname
castle% nischttl 3600 '[], hobbies'
```

# nisdefaults — 显示 NIS+ 默认值

### 概要

`/usr/bin/nisdefaults [-adghprstv]`

## 描述

使用 `nisdefaults` 命令打印调用 NIS+ 本地名称函数返回的默认值（见 `nis_local_names(3N)`）。当未指定任何选项时，所有默认值都以详细格式打印。指定选项后，仅显示对应选项的信息。

## 选项

- `-a` 以简洁格式打印所有默认值。
- `-d` 打印默认域。
- `-g` 打印默认组。
- `-h` 打印默认主机名。
- `-p` 打印默认主体名。
- `-r` 打印创建对象时的默认访问权限。
- `-s` 打印默认搜索路径。
- `-t` 打印默认生存时间。
- `-v` 以详细格式打印默认值。

## 示例

以下示例打印在 `castle` 机器上 `foo.bar` 的默认值。

```
castle% nisdefaults
主体名：castle.bar
域名：foo.bar
主机名：castle
组名：
访问权限：-----cdr---r---
生存时间：12:00:00
搜索路径：foo.bar
```

以下示例为 shell 脚本设置默认域。

```bash
DOMAIN=`nisdefaults -d`
```

以下示例以详细格式打印生存时间。

```
castle% nisdefaults -tv
生存时间：12:00:00
```

以下示例以简洁格式打印生存时间。

```
castle% nisdefaults -t
43200
```
