### 下载照片

以下步骤描述了如何从数字相机下载照片。

1. 使用电缆将数字相机连接到电脑，并打开相机以准备接收数据。
2. 如果你的相机没有被识别到，请运行 `usbview` 命令。
3. 如果你的相机没有被识别到，请检查 `/etc/fstab` 文件，你的条目可能如下：

```
/dev/usb0 /mnt/camera auto 0 0
```

4. 如果你的相机没有被识别到，请创建 `/mnt/camera` 目录。
5. 完成后，卸载相机：

```
# umount /mnt/camera
```
