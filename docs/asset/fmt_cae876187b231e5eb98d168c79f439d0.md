## lwm

轻量级窗口管理器 (Lightweight Window Manager) 是一个用于 X 的窗口管理器，它不会干扰你的视线。没有图标、没有按钮栏、没有 dock、没有菜单、什么：如果你想要这些，其他程序可以提供。它不提供可配置性；如果你想要，可以使用不同的管理器；一个在你空间和内存的这种习惯中运行你操作系统的管理器。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lxdoom

Doom 的移植版，一个 3D 游戏，由 id Software 在 1993 年发布。`Lxdoom` 是一个在 Linux 或 Free86 上运行的 Doom 版本。此包包含了控制台二进制文件。要实际运行 Doom，你需要 `lxdoom-x11` 或 `lxdoom-svga`。可以增强你的游戏体验。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lxdoom-ndsvery

`Lxdoom` 的音效。`Lxdoom` 中的音效由独立的服务器播放。这种服务器不需要运行 Doom，它取决于 `ndsvery` 和 `musserv` 的是否存在。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lxdoom-svga

用于 `Lxdoom` 的 SVGALIB。此包包含了 svg 二进制文件。注意，这可能存在安全风险。只有 `ndsvery` 和 `lxmusserv` 可以增强你的游戏体验。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lxdoom-x11

用于 `Lxdoom` 的 X 二进制文件。此包包含了 X 界面。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lxmusserv

Doom 和 Heretic 的 Linux 音乐服务器。Doom 移植版使用端口播放来自主游戏二进制文件的音乐。如果你想在这些经典的 3D 射击游戏中听音乐，请安装此包。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lxr

Linux 交叉引用 (Linux Cross-Reference) 是超文本交叉引用工具的测试应用程序。项目的主要目标是为较大的代码库创建一个通用的交叉引用工具。该项目基于 Web 技术，代码选择从所有可用的浏览器中进行。在服务器端，任何具有 cgi 脚本能力的 Unix Web 服务器都可以胜任。索引的主要功能是可以轻松跳转到任何全局标识符的定义。事实上，对全局标识符的所有引用都已索引。快速访问函数声明、数据（类型）定义和预处理器宏使得浏览变得更加方便。在开发和调试期间，概述更改函数或类型定义会影响哪些代码区域也应该帮助。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## lynx

`Lynx` 是一个基于文本的 Web 浏览器。`Lynx` 不显示任何图像，但支持框架、表格和大多数 HTML 标签。`Lynx` 与图形化浏览器相比的优势是速度；`Lynx` 启动和退出，并能快速切换网页。来自 Redhat 8.0 RPM `http://www.tdp.org/LDP/Linux-Dictionary/html/index.html`

## lynx

文本模式 `Lynx` 浏览器是一个功能全面的 World Web (WWW) 客户端，用于运行光标地址字符单元显示（例如 vt100 终端、运行在 PC 或 Mac 上的 vt100 模拟器，或任何“面向 curses”的显示器）。它将显示包含指向本地系统文件的链接超文本标记语言 (HTML) 文档，以及位于运行 Gopher、HTTP、FTP、WAIS 和 NNTP 服务器的远程服务器的文件。来自 Debian 3.0r0 APT `http://www.tdp.org/LDP/Linux-Dictionary/html/index.html`

## lynx-cur

支持 SLS 的文本模式 WWW 浏览器（开发版本）。`Lynx` 是一个为运行光标地址字符单元显示设备的用户功能全面的 Wide Web (WWW) 客户端。它非常快速且易于使用。它将显示包含指向本地系统文件的链接 HTML 文档，以及位于运行 Gopher、HTTP、FTP、WAIS 和 NNTP 服务器的远程服务器的文件。此版本的 `Lynx` 提供了通过 HTTP 使用 SSL 安全访问网站 (HTTPS) 以及通过 NNTP 使用 SSL 安全访问新闻服务器 (SNEWS) 的能力。SSL 被透明处理，允许用户通过相同的接口通过安全和标准传输访问网站和新闻。来自 Debian 3.0r0 APT `http://www.tdp.org/LDP/Linux-Dictionary/html/index.html`

## lynx-cur-wrapper

`lynx-cur` 的包装器将为 `lynx` 提供所有基本设置，主要针对使用 `LANG` 环境变量的用户，因此用户除了设置合适的 `LANG` 外什么都不需要做。来自 Debian 3.0r0 APT `http://www.tdp.org/LDP/Linux-Dictionary/html/index.html`
