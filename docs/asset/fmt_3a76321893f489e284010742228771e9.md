# 配置 FreeS/WAN

在你将 FreeS/WAN 编译到 Linux 内核并确认 IPSec、KLIPS 和 Pluto 正在运行后，你就准备好配置该程序了。任何 IPSec 实现都要求你在每个隧道端点的网关或主机上测试 IP 网络。其原因是，除非底层有一个功能正常的 IP 网络，否则 IPSec 将无法工作。
