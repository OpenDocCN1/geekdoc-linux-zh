# 为 Linux 安全 Tripwire

## 安全问题

确保运行的系统完整性未被破坏至关重要。为了获得基准数据库，你应该从干净的安装和原始介质生成操作系统和应用程序。此外，建议删除名为 `"twcfg.txt"` 的 Tripwire 配置文件的文本副本，防止任何人创建第二个或备用的配置。

要删除 Tripwire 配置文件的文本副本，使用以下命令：

```
[root@deep /# rm -f /usr/bin/twcfg.txt
```
