# 调试级别

在大型复杂项目中，你比简单的开启 DEBUG 有更多的控制权。你可以定义调试级别，并决定使用哪些宏以及移除哪些。

要定义一个级别，只需在 `#define DEBUG` 语句后跟一个数字。虽然你可以定义任意数量的级别，但常见的系统有：HIGH、MEDIUM、LOW。列表 21.7 展示了如何使用列表 21.5 中的 `String` 和 `Animal` 类来实现。
