
# 术语表

### 别名 Shell
用于缩写命令行的机制（对比 OpenMS 的构造 `--`）。

### 参数列表 Shell
从命令行中传递给命令的单词列表。

### ASCII
美国信息交换标准代码：一种字符编码方案。

### 后台作业
不从终端输入的作业。

### bash
Bourne-Again shell。一种在 Linux 上常见的 shell 程序，基于 `sh`。

### Baud
比特率；一种描述数据传输速度的单位。

![](img/e259ba2750941fa3d146eda78c65e89d_501_0.png)

### 位桶
文件 `/dev/null` 的名称。写入此处的字符会被“丢弃”；从此处读取字符会立即导致 EOF。

### 位图
屏幕映射，使得每个像素在物理内存中有表示。

### 断点
在源代码中设置的点，使调试器在执行时停止。

### BSD
Berkeley Software Distribution，源自加州大学伯克利分校的 UNIX 版本。

### 内置命令
代码位于 shell 内部的；shell 不会派生进程来执行该命令。

### 守护进程
一种以用户透明的方式执行某些系统管理功能的系统生成进程。

### 调试
修正程序或过程中的错误。

### 分离作业
在用户注销后继续继续处理的作业。

531

### 设备 (Device)
物理设备。

### 目录 (Directory)
一个包含其他文件或目录名的 UNIX 文件。

### 目录层次结构 (Directory hierarchy)
UNIX 文件系统中目录的排列方式。

根目录位于目录层次结构的顶端，包含指向所有文件系统的指针，从而指向系统上的所有目录。

### 目录栈 (Directory stack)
用于存储稍后回溯目录的数据结构。

### 磁盘分区 (Disk partition)
挂载文件系统的磁盘部分。

### 环境 (Environment)
描述 用户终端会话的特征集。这些特征包括打开的文件、用户和组标识、进程标识以及环境变量。

### 环境变量 (Environment variable)
自动导出到后续程序的变量。环境变量通过 `setenv` 命令定义。

### EOF
文件结束符，表示文件结束的字符，通常为 `<CTRL>D`。

### 以太网 (Ethernet)
局域网标准，提供了 ISO/OSI（国际标准组织/开放系统体系）七层参考模型中的低两层。

### 事件 (Event)
存储在历史列表中的过去命令。

### 可执行镜像 (Executable image)
位于物理内存中的可执行文件。

### 扩展 (Extension)
路径名中 `.`（点）之后的部分。也称为文件扩展名。

### 字段分隔符 (Field separator)
用于分隔记录中字段的一个或多个字符；默认位一个或多个空格。

### fifo
一种旨在持续使用的文件，其中先进入文件的字节字节将成为先从该文件中读取的第一个字节（先进先出）。

### 文件 (File)
存储在唯一路径名下的字节流。

### 文件与设备独立性 (File and device independence)
在命令中等价使用文件名和设备名；例如，`who > out` 且 `who >/dev/lp`。

### 文件描述符 (File descriptor)
UNIX 分配给打开文件的数字。

### 文件名 (Filename)
用于引用文件的字符集。任何字符都是合法的，但最好选择字母数字字符集、点和下划线。BSD 文件名可包含多达 255 个字符。

### 文件名扩展 (Filename expansion)
根据以下规则匹配指定目录中的文件名：`*` 匹配包括空在内的任何字符序列；`?` 匹配任何单个字符；`[]` 界定字符集；`[n-m]` 匹配从 n 到 m（包含）的字符范围；`;@` 匹配主目录；`{}` 界定公共路径名中的不同部分（另见 `globbing`）。

### 文件系统 (File system)
从根目录开始挂载在磁盘分区中的文件分级排列。

### 过滤器 (Filter)
从标准输入读取、处理并将其写入标准输出的程序。过滤器通常用于管道。

### 浮点加速器 (Floating point accelerator)
专门设计的硬件，用于增强对浮点数据类型执行数学运算的速度。

![](img/e259ba2750941fa3d146eda78c65e89d_504_0.png)

### 前台作业 (Foreground job)
在外 shell 接受更多命令之前必须完成或中断的任务；从终端接收输入的作业。

### 派生 (Fork)
通过复制调用进程（父进程）来创建新进程的系统例程。

### 通配符匹配 (Globbing)
使用元字符的文件名扩展。

### 组 ID (Group ID)
指定用户所属组的数字标识。该数字对应于 `/etc/group` 文件中的条目。

### GUI
一种与用户交互的方法，用鼠标和图形补充或取代传统的键盘输入和文本（图形用户界面）。

### 硬链接 (Hard link)
在同一文件系统中将相同的文件内容与两个或多个文件名关联。硬链接不能跨文件系统；符号链接（也称为软链接）可以。

### 头文件/目录 (Header)
包含文件名的目录。

### 历史列表 (History list)
之前执行过的命令列表。

### 主目录 (Home directory)
用户的默认工作目录，指定在 `/etc/passwd` 文件中。

### 主机 (Host)
网络上的计算机（对比 OpenVMS 节点）。

### 主机名 (Host name)
分给主机的名称（对比 OpenVMS 节点名）。

### 节点 (Inode)
用于在物理设备上定位数据的指针。

534

### 输入 (Input)
命令或用户程序读取的数据。

### 中断 (Interrupt)
一种通常由键盘产生的信号，导致当前执行的进程终止，除非进程采取特殊操作来处理该信号。

### 中断处理程序 (Interrupt handler)
接收到中断后执行的一组语句。

### 作业 (Job)
由一个或多个进程组成的任务，由 shell 分配作业号，并在前台或后台执行。

### 作业控制 (Job control)
shell 控制多个作业的能力。

### 作业号 (Job number)
在 shell 会话中唯一标识一个作业的数字。

### 作业栈 (Job stack)
由 shell 维护的作业队列。

### 作业状态 (Job states)
作业的当前状态。（（另见 `Suspended Job`、`Terminated Job` 和 `Detached Job`）。

### ksh
`/bin/ksh`，即 Korn shell 程序的缩写。

### 链接 (Link)
目录中的一个条目（即文件名），指向已存在的文件。硬链接不能跨文件系统；符号链接（也称为软链接）可以。

### 链接加载器 (Link loader)
将程序的所有独立模块组合以创建可执行文件的软件。

### 锁 (Lock)
一个文件的存在会阻止某些功能的使用（例如访问公共数据库、打印设备或设施）。

![](img/e259ba2750941fa3d146eda78c65e89d_506_0.png)

### 登录名 (Login name)
分配给用户的（对比 OpenVMS 用户）。

### 元字符 (Metacharacter)
具有特殊含义的字符（例如 `>` 表示输出重定向）。

### 修饰 (Modifier)
见 `Variable modifier`。

### 多处理器 (Multiprocessor)
共享物理内存的多个处理器。

### 网络竞争 (Network contention)
多个数据包同时访问网络。

### NFS
网络文件系统（Network File System），由 Systems, Inc. 开发的一种网络协议，允许像访问本地计算机一样访问远程计算机的文件（对比 OpenVMS 集群）。

### NIS
一种分布式命名服务，允许参与的主机共享一组管理和网络文件。

### 目标文件 (Object files)
作为编译结果产生的目标代码文件。

### 目标库 (Object library)
包含目标文件的库。

### 选项 (Option)
修改命令执行。

### 输出 (Output)
命令或用户程序产生的数据。

### 数据包 (Packet)
一单元数据和其他信息，例如本地主机地址、远程主机地址，通过网络发送。
