`XParseGeometry` 函数返回一个位掩码，指示字符串中实际发现了哪些值（宽度、高度、xoffset 和 yoffset）以及 x 和 y 值是否已更新。按照习惯， -0 不等于 +0，因为用户需要能够表示 - 位置（相对于右边缘或底部边缘定位窗口）。对于找到的每个值，对应的参数都会被更新。对于未找到的值，则保持不变。这些位由 `XValue`, `YValue`, `WidthValue`, `HeightValue`, `XNegative` 或 `YNegative` 表示并定义在 `<X11/XUtil.h>` 中。每当其中一个值被定义或一个符号被设置时，这些位就会被设置。

- `def_geom` 指定应用程序的默认几何结构或 NULL。
- `bwidth` 指定边框宽度。
- `hints` 指定窗口在正常状态下的尺寸提示。

`XWMGeometry` 函数结合了用户指定的任何几何信息（使用 `XParseGeometry` 使用的格式）和调用程序的尺寸提示（通常是存储在 `WM_NORMAL_HINTS` 中的那些），并返回描述窗口的位置、尺寸和重力（`NorthGravity`, `NorthEastGravity`, `SouthEastGravity` 或 `SouthGravity`）。如果 `XHints` 中未设置基础尺寸，则如果设置了将使用最小尺寸。否则，假设基础尺寸为零。如果提示结构中没有设置最小尺寸，则使用基础尺寸。掩码（来自用户通过 `XParseGeometry` 返回）描述了用户规范中的哪些值，以及位置坐标是否相对于右边缘和底部边缘，返回一个区域。请注意，这些坐标已经在 `x_return` 和 `y_return` 值中考虑过了。

# 操作区域

区域是像素位置的任意集合。Xlib 提供了操作区域的函数。透明类型 `Region` 定义在 `<Xlib/Xutil.h>` 中。Xlib 提供了你可以用于操作区域的函数。本节讨论了如何：

- 创建、复制或销毁区域
- 移动或缩小区域
- 对区域进行计算
- 确定区域是否为空或相等
- 在区域中定位点或矩形

## 创建、复制或销毁区域

创建一个新区域，请使用 `XCreateRegion`。

```
Region XCreateRegion();
```

从多边形生成区域，请使用 `XPolygon`。

```
Region XPolygon(points[], n, fill_rule);
```

`points` 是一个数组。
`n` 指定多边形中点的数量。
`fill_rule` 指定填充规则。你可以传递 `EvenOdd` 或 `WindingRule`。

要设置 GC 的裁剪掩码，请使用 `XSetRegion`。

```
XSetRegion(display, gc, r);
```

`display` 指定与 X 服务的连接。
`gc` 指定 GC。
`r` 指定要设置为掩码的区域。

释放与区域关联的存储空间，请使用 `XDestroyRegion`。

```
XDestroyRegion(r);
```

`r` 指定要释放存储空间的区域。

## 移动或缩小区域

按指定量移动区域，请使用 `XOffsetRegion`。

```
XOffsetRegion(r, dx, dy);
```

`r` 指定区域。
`dx` 和 `dy` 指定你想移动区域的 x 和 y 偏移量。

按指定量缩小区域，请使用 `XShrinkRegion`。

```
XShrinkRegion(r, dx, dy);
```

`r` 指定区域。
`dx` 和 `dy` 指定你想缩小区域的 x 和 y 偏移量。正值缩小区域尺寸，负值扩展区域。

## 对区域进行计算

生成区域的最小矩形，请使用 `XClipBox`。

```
XClipBox(r, rect_return);
```

`r` 指定区域。
`rect_return` 返回最小矩形。

计算两个区域的交集，使用 `XIntersectRegion`。

```
XIntersectRegion(sra, srb, dr_return);
```

`sra` 指定第一个区域。
`srb` 指定第二个区域。
`dr_return` 返回结果区域。

计算两个区域的并集，使用 `XUnionRegion`。

```
XUnionRegion(sra, srb, dr_return);
```

`sra` 指定第一个区域。
`srb` 指定第二个区域。
`dr_return` 返回结果区域。

创建一个源区域和矩形的并集，使用 `XUnionRectWithRegion`。

```
XUnionRectWithRegion(rectangle, src_region, dest_region_return);
```

`rectangle` 指定矩形。
`src_region` 指定要使用的源区域。
`dest_region_return` 返回目标区域。

减去两个区域，使用 `XSubtractRegion`。

```
XSubtractRegion(sra, srb, dr_return);
```

`sra` 指定第一个区域。
`srb` 指定第二个区域。
`dr_return` 返回结果区域。

计算两个区域并集与交集之间的差异，使用 `XXorRegion`。

```
XXorRegion(sra, srb, dr_return);
```

`sra` 指定第一个区域。
`srb` 指定第二个区域。
`dr_return` 返回结果区域。

## 确定区域是否为空或相等

要确定指定的区域是否为空，请使用 `XEmptyRegion`。

```
Bool XEmptyRegion(r);
```

- `r` 指定区域。

如果区域为空，`XEmptyRegion` 函数返回 `True`。

要要确定两个区域是否具有相同的偏移、大小和形状，请使用 `XEqualRegion`。

```
Bool XEqualRegion(r1, r2);
```

- `r1` 指定两个区域。
- `r2`

如果两个区域具有相同的偏移、大小和形状，`XEqualRegion` 函数返回 `True`。

## 在区域内定位点或矩形

要确定点是否位于指定的区域内，请使用 `XPointInRegion`。

```
Bool XPointInRegion(r, x, y);
```

- `r` 指定区域。
- `x`
- `y` 指定定义点的 x 和 y 坐标。

如果点 `(x, y)` 包含在区域 `r` 中，`XPointInRegion` 函数返回 `True`。

要确定一个区域是否在另一个区域内部，请使用 `XRectInRegion`。

```
int XRectInRegion(r, x, y, width, height);
```

- `r` 指定区域。
- `x`
- `y` 指定定义矩形左上角坐标的 x 和 y 坐标。
- `width`
- `height` 指定定义矩形的宽度高度。

如果矩形完全在指定区域内，`XRectInRegion` 函数返回 `RectangleIn`；如果矩形在指定区域外，返回 `RectangleOut`；如果矩形部分在指定区域内，返回 `RectanglePart`。

## 使用剪贴板缓冲区 (Cut Buffers)

Xlib 提供了操作剪贴板缓冲区的函数，这是一种非常简单的剪切粘贴客户端间通信形式。选择（Selections）是在客户端（见第 4.5 节）之间交换数据的更强大且实用的机制，通常应该使用选择代替剪贴板缓冲区。

剪贴板缓冲区实现为显示器第一个根窗口的属性。缓冲区只能包含 `STRING` 编码的文本。Xlib 在取取或存储时不会更改编码。提供了 8 个缓冲区，可以作为环形缓冲区或显式缓冲区（编号 0 到 7）进行访问。

要在剪贴板缓冲区 0 中存储数据，请使用 `XStoreBytes`。

```
XStoreBytes(display, bytes, nbytes);
```
