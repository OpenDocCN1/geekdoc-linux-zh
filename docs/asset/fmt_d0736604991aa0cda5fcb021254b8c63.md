要修改 `/etc/httpd/conf/httpd.conf` 文件，你需要用编辑器打开文件并为安全服务器添加 `VirtualHost` 配置：

```apache
<VirtualHost 192.168.0.215

    DocumentRoot /var/www/html

    ServerName smartdeveloper.com

</VirtualHost>
```
