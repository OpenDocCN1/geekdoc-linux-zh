
# 程序 Sample

## 源类型
`CLLE`

## 说明
输出队列监控处理器，向用户发送通知消息

## 参数
- `&Job` 输入打印文件作业名
- `&User` 输入打印文件用户
- `&JobNbr` 输入打印文件作业号
- `&SpFName` 输入打印文件名
- `&SplNbr` 输入打印文件号
- `&OutQName` 输入输出队列 OutQ 名称
- `&OutQLib` 输入输出队列 OutQ 库

```
Pgm (
  &Job
  &User
  &JobNbr
  &SpFName
  &SplNbr
  &OutQName
  &OutQLib
)
```

## 变量声明

```
Dcl &Job *Char ( 10 )
Dcl &User *Char ( 10 )
Dcl &JobNbr *Char ( 6 )
Dcl &SpFName *Char ( 10 )
Dcl &SplNbr *Dec ( 4 )
Dcl &OutQName *Char ( 10 )
Dcl &OutQLib *Char ( 10 )
```
