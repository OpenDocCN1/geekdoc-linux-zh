## 你愿意做 Code Club 的志愿者吗？

`Code Club` 是一个全国性的志愿者网络，为 9-11 岁的儿童提供志愿者领导的课后编程俱乐部。

我们需要精通计算机编程的人担任志愿者，每周在当地的小学、图书馆或社区中心运营一小时。

我们为志愿者创建了教学项目，我们制作的项目旨在通过向孩子们展示如何制作电脑游戏、动画和网站来教他们编程。

加入我们吧，让我们教下一代编写代码！

访问 `www.codeclub.org.uk` 了解更多信息
