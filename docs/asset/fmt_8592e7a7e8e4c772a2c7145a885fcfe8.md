## 频率计数器

对于一个没有质量跨越边界的闭合系统，在可逆等温过程中可以完成的功由级数方程给出。

```
$W_{rev} = -\Delta A = -\Delta(E - TS) = -(\Delta E - T\Delta S)$
```

`T` 代表向环境释放的热量。如果过程是可逆的，`$\Delta S < 0$`，对环境所做的实际功小于系统的内能。`(-\Delta A - T\Delta S)` 可以被视为自由能，即在不可逆过程中可以转换成功的最大机械能。这就是“自由能”名称的由来。

在它们之间；因此，随着物体与地球之间距离的增加，物体的加速度减小。当物体从无限远距离自由落体到地球表面时，获得的最终速度由下式给出，其中 R 是地球的半径：

```
$v_f = \sqrt{2gR}$
```

[2] 其数值为 11.2 km/s 或 7 英里/秒。

即“逃逸速度”，上升物体克服地球引力所需的速度。由于作用与反作用力的结果，水平抛出或水平投射的物体 `v` 无论方向如何，其减速速率与自由落体物体相同。

在足够的高度，投射物从水平方向落下的速率，与地球表面同一高度的（如果是卫星）落下的速率相同。

> 弹道学；引力。

熵的增加伴随着自由能的减少。方程 (1) 显示“自由能”的减少与熵的增加成正比。化学热力学。

```
$\Delta A = -\Delta H + T\Delta S = W_{rev} - P\Delta V$
```

这些自由能都是热力学系统状态的不可逆函数。对于化学变化，平衡标准独立于完成该变化的路径。

在恒温和恒压的恒定系统中定义的过程的可逆性、不可逆性和平衡标准，可以自然地用化学势来表示。对于恒温恒压下的不可逆过程，`$\Delta G < 0$`；如果环境不是系统的一部分，那么 `$\Delta G$` 必须为负或零。对于可逆过程，`$\Delta G = 0$`。

自由能在给定的温度和压力下的平衡态下降至最低值。由于自由能是通过改变温度和体积可以获得的最大功，它是热力学中最重要的物理量。

> 熵；化学力学。

在引力作用下向地心加速的自由落体运动。从地球表面附近自由落体的物体，以约 9.8 m/s² 或 32 ft/s² 的加速度获得速度。

自由基是指任何仅包含一个未对电子的分子。某些包含多个一个未对电子的分子（例如，氧气）不被认为是自由基，因为它们的活性没有自由基那么高。它们可能具有高活性（如甲基自由基），也可以是稳定的实体（氮氧化物物种）。

自由基可分为三类：无机自由基（例如 OH、NO、Cl 和 O₃）和有机自由基（例如 CH₃、CH₂CH₄ 和 CH₅）。此类自由基通常涉及工业和热过程。自由基还已知能引发链反应和结合反应。

通常情况下，自由基是通过化学键断裂产生两个自由基形成的，每个自由基都有一个未对电子。由此产生的自由基可能会参与进一步的反应或结合形成原始自由基。

如果下落物体在任何方向上都没有初速度，在没有其他力存在的情况下，它将自由落体。如果存在其他力，可能会改变下落的方向和速率；尽管运动结果是向上运动，物体也可以被认为是在“下落”。

```
$v = \sqrt{2gt}$
```

对于非常大的距离，重力加速度不能再视为常数。根据牛顿引力定律，任何两个物体之间的力与距离的平方成反比。

## 波频（波数）

频率计数器是一种用于测量输入信号频率的电子仪器。频率计数器常用于实验室、现场和终端用户应用的各种设备。频率计数器最常见的应用是振荡器的表征和振荡。频率计数器还用于时钟。

频率计数器有几类。基本频率计数器是提供频率测量的双通道仪器。

> 波频；波；波数。

## 934 频率分频器

计数器是基本频率计数器的一种示例，用于测量 40 GHz 及以上的微波频率。

三种主要架构是常规计数、倒数计数和连续计数。连续计数器是最简单且最好的，但它的灵活性最低。常规计数器使用简单的寄存器在 1 次测量时间内计算输入信号的每个周期。

倒数计数是最常见的架构。它比计数提供了更好的灵活性。主门由用户设置，并决定了进行测量的名义时间（通常为几秒）。

连续计数基于倒数技术，但使用高速数字计数器连续采样频率，可以通过数字处理将 1 秒测量内的分辨率提高到高达 12 位。
