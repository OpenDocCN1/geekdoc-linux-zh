
```c
typedef struct {                    /* 窗口位置 */
    int x, y;                              /* 窗口的宽度和高度 */
    int width, height;                     /* 窗口边框 */
    int border_width;                     /* 窗口深度 */
    int depth;                             /* 深度 */
    Visual *visual;                        /* 关联的视觉结构 */
    Window root;                          /* 包含窗口的屏幕根窗口 */
    int class;                             /* InputOutput, InputOnly */
    int bit_gravity;                      /* 位重力值之一 */
    int win_gravity;                      /* 窗口重力值之一 */
    int backing_store;                     /* 映射时有用。始终为 Always */
    unsigned long backing_planes;         /* 恢复平面时使用的值 */
    unsigned long backing_pixel;          /* 布尔值，位是否应该被保存？ */
    Bool save_under;                      /* 布尔值，与窗口关联的颜色表 */
    Colormap map;                        /* 布尔值，当前安装的颜色表 */
    Bool map_installed;                   /* 是否映射、是否可见、是否可视的 */
    int map_state;
    long all_event_mask;                  /* 所有人都感兴趣的事件集**/
    long do_not_propagate_mask;           /* 不应传播的事件集 */
    Bool override_redirect;               /* 布尔值，覆盖重定向的值 */
    Screen *screen;                        /* 指向正确屏幕的反向指针 */
} XWindowAttributes;
```

`x` 和 `y` 成员设置为相对于窗口原点的左上外角。`width` 和 `height` 成员设置为窗口的内部尺寸，不包括边框。`border_width` 成员设置为像素为单位的窗口边框。`depth` 成员设置为窗口深度（即对象的每个像素位数）。`visual` 成员指向屏幕关联的视觉结构指针。`root` 成员设置为包含窗口的屏幕根窗口。`class` 成员设置为窗口类，可以是 `InputOutput` 或 `InputOnly`。

`bit_gravity` 成员设置为窗口的位重力，可以是以下值之一：

- `ForgetGravity`
- `NorthWestGravity`
- `NorthGravity`
- `NorthEastGravity`
- `SouthGravity`
- `SouthWestGravity`
- `SouthGravity`
- `WestGravity`
- `StaticGravity`

有关重力的更多信息，请参见第 3.23 节。

`win_gravity` 成员设置为窗口的窗口重力，可以是以下值之一：

- `UnmapGravity`
- `NorthWestGravity`
- `NorthGravity`
- `NorthEastGravity`
- `SouthGravity`
- `SouthWestGravity`
- `SouthGravity`
- `EastGravity`
- `WestGravity`
- `StaticGravity`

`backing_store` 成员指示服务器如何维护窗口内容，可以是 `WhenMapped`、`Always` 或 `NotUseful`。`backing_planes` 成员设置（位为 1）指示哪些平面持有必须在备份存储中保留的动态数据。`backing_pixel` 成员指示在未设置备份平面时使用的值。

`save_under` 成员设置为 `True` 或 `False`。`map` 成员设置为指定窗口的颜色表，可以是映射 ID 或 `None`。`map_installed` 成员指示颜色表是否已安装，可以是 `True` 或 `False`。`map_state` 成员指示窗口状态，可以是 `Unmapped`、`Unviewable` 或如果窗口已映射但某些祖先节点未映射则是 `IsViewable`。

`all_event_mask` 成员设置为所有客户端在窗口上选择的事件掩码并集。`event_mask` 成员设置为查询客户端选择的所有事件掩码的并集。`do_not_propagate_mask` 成员设置为不应传播的事件集的并集。

`override_redirect` 成员指示窗口是否覆盖了结构控制功能，可以是 `True` 或 `False`。如果为 `True`，窗口管理器客户端应忽略该窗口。

`screen` 成员设置为一个屏幕指针，提供指向正确屏幕的反向指针。这使得无需遍历匹配的根窗口字段即可获取屏幕信息。

`XCreateWindowAttributes` 可能会产生 `BadDrawable`、`drawable` 错误。

## 窗口信息

要获取图形的当前几何形状，请使用 `XGetGeometry`。

```c
Status XGetGeometry(display, d, root_return, x_return, y_return, width_return, height_return, border_return, depth_return);
```

`display` 指定与 X 服务器的连接。

`d` 指定图形，可以是窗口或位图。

`root_return` 返回根窗口。

`x_return`

`y_return`

返回定义可图区域位置的 x 和 y 坐标。对于窗口，这些坐标指定相对于其父窗口原点的左上外角。对于位图（pixmaps），这些坐标始终为 0。

`width_return`

返回可图区域的尺寸（宽度和高度）。对于窗口，这些尺寸指定内部大小，不包括边框。

`height_return`

返回以像素为单位的边框宽度。如果可图区域是位图，则返回 0。

`border_width_return`

返回可图区域的深度（像素比特）。

`depth_return`

`XGetGeometry` 函数返回根窗口和可图区域的当前几何结构。可图区域的几何结构包括 x 和 y 坐标、高度、边框宽度深度。这些在参数列表中描述。解析类为 `isOnly` 的窗口是合法的。

`XGetGeometry` 可能会产生 `BadDrawableError`。

## 翻译屏幕坐标

应用程序有时需要从一个窗口的坐标空间到另一个坐标空间进行坐标变换，或者确定指针所在的窗口层深度。`XTranslateCoordinates` 和 `XPointer` 通过请求 X 服务器执行这些操作来满足这些需求（避免任何竞态条件）。

要将一个窗口中的坐标翻译到另一个窗口的坐标空间，请使用 `XTranslateCoordinates`。

```c
Bool XTranslateCoordinates(display, src_w, dest_w, src_x, src_y, dest_x_return, dest_y_return, child_return);
```

- `display`: 指定与 X 服务器的连接。
- `src_w`: 指定源窗口。
- `dest_w`: 指定目标窗口。
- `src_x`: 指定源窗口内的 x 和 y 坐标。
- `dest_x_return`: 返回目标窗口内的 x 和 y 坐标。
- `child_return`: 如果坐标包含在目标窗口的映射子窗口中，则返回子窗口。

如果 `XTranslateCoordinates` 返回 `True`，它返回相对于源窗口原点的 src 这种坐标，并将这些坐标作为相对于目标窗口原点的 `dest_x` 和 `dest_y` 返回。如果 `XTranslateCoordinates` 返回 `False`，则 `src_w` 和 `dest` 在不同的屏幕上，且 `dest_x` 和 `dest_y` 返回 0。如果坐标在 `dest_w` 的映射子窗口中，则返回给 `child_return`。否则，`child_return` 被置为 `None`。

`XTranslateCoordinates` 可能会产生 `BadWindow`。

要获取指针的屏幕坐标或确定相对于指定窗口的指针坐标，请使用 `XQueryPointer`。
