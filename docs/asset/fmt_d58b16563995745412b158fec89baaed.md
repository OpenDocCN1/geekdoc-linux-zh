# 234 第四部分：书呆子的复仇

```
$TTL 86400

@ IN SOA @ root.localhost (

	1 : serial

28800 ; refresh

7200 ; retry

604800 ; expire

86400 ; ttl

)

@ IN NS localhost.

@ IN A 127.0.1
```

分号（`;`）表示注释。分号后的所有字符都被视为注释，不会影响 DNS 配置文件的操作。

- 3. 通过“文件:另存为”保存配置。
