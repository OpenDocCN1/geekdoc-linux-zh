与许多关注如何使用 Linux 的书籍不同，《Unix 哲学》探讨了‘属于 Linux 的思维方式’以及为什么 Linux 是这一个功能极其强大的操作系统的优越实现。

本书是对一部计算机科学经典著作的修订和扩展。每一章都针对 Linux 内容进行了彻底更新。

《Linux 与 Unix 哲学》恰好处于关于迭代设计和项目管理的“软性”文本与“操作类”技术文本之间。到目前为止，无论 Unix 领域还是 Linux 领域，还没有人过这一主题的书。《Linux 与 Unix 哲学》涵盖了与第一版相同的内容，同时也提出了关于 Linux 和开源的新观点。

- 哲学原则的简明列表使其成为方便的快速参考工具
- 轶事案例为读者增添了人性化的色彩
- 对话式的风格使其读起来轻松且愉快

Mike Ganzarc 是佐治亚州亚特兰大的一位应用程序和编程顾问。利用 Linux、Unix 和 Java 工具，他的团队为金融服务行业开发了获奖的解决方案。作为 Unix 应用设计专家，Mike 多十年来一直是 Unix 方法的倡导者。作为诞生 X 窗口系统的团队成员，他开创了在纽罕布什州纳什亚的数字设备公司工程小组运行的现代窗口器的可用性概念。Mike 领导了将 Unix 命令和工具移植到 64 位 Alpha 处理器。他的第一本书《Unix 哲学》（Digital Press, 1995）在全球范围内售出了超过 15,000 册。
