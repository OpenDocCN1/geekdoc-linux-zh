
```bash
[root@deep #] openssh-1.2.3]# make
[root@deep #] openssh-1.2.3]# make install
[root@deep #] openssh-1.2.3]# make host-key
[root@deep #] openssh-1.2.3]# install -m644 contrib/redhat/sshd_pam /etc/pam.d/
```

`make`命令将所有源文件编译成可执行的二进制文件，`make install`将将二进制文件和任何支持文件安装到相应的位置。`make host-key`命令将生成主机密钥，最后`install`命令将为RedHat Linux安装PAM支持，它比流行的ssh-1.2包功能更强大。

"`/etc/ssh/sshd_config`"文件是OpenSSH的全局配置文件，允许您设置修改客户端程序的选项。这些文件包含键值对，每行一个，关键字不区分大小写。这里是配置您的"`ssh`"以实现安全的关键字；完整列表或特殊要求可以参考`ssh (1)`页。

## 安全软件（网络服务） | 第 1 章

```bash
ListenAddress 192.168.1.1
HostKey /etc/ssh/ssh_host_key
ServerKeyBits 1024
LoginGraceTime 600
KeyRegenerationInterval 3600
PermitRootLogin no
IgnoreHosts yes
IgnoreUserKnownHosts yes
StrictModes yes
X11Forwarding no
Permitit yes
SyslogFacility AUTH
LogLevel INFO
RostsAuthentication no
RostsRSAAuthentication no
RSAAuthentication yes
PasswordAuthentication yes
PermitEmptyPasswords no
AllowUsers admin
```

这告诉`sshd_config`为此特定配置设置以下内容：

- 端口 22

"`Port`"选项指定`sshd`守护进程监听入站连接的端口号。

默认端口为 22。

`ListenAddress 192.168.1.1`

"`ListenAddress`"选项指定`ssh`服务服务器套字绑定的网络接口IP地址。默认值为"`0.0.0.0`"；为了提高安全性，你可以指定必要的地址以限制可能的连接范围。

`HostKey /etc/ssh/ssh_host_key`

"`HostKey`"选项指定私钥所在的位置。

`ServerKeyBits 1024`

"`ServerKeyBits`"选项指定服务器密钥中使用的位数。这些位在守护进程启动生成RSA密钥时使用。

`LoginGraceTime 600`

"`LoginGraceTime`"选项指定用户在发送连接请求后，如果未成功登录，断开连接前等待的秒数。

`KeyRegenerationInterval 3600`

"`KeyRegenerationInterval`"选项指定服务器在自动重新生成密钥之前等待的秒数。这是一项防止捕获会话被解密的安全功能。

`PermitRootLogin no`

"`PermitRootLogin`"选项指定root用户是否可以登录`ssh`。永远不要对此选项设置"`yes`"。

`IgnoreHosts yes`

"`IgnoreHosts`"选项指定在认证时是否应使用hosts或shosts文件。出于安全考虑，建议**不要**使用hosts或shosts文件进行认证。

`IgnoreUserKnownHosts`

"`IgnoreUserKnownHosts`"选项指定`ssh`守护进程在进行Rhosts RSA认证期间是否忽略用户的"`HOME/.ssh/known_hosts`"文件。

`StrictModes`

"`StrictModes`"选项指定`ssh`在登录前是否应检查用户其主目录和rhosts文件的权限。此选项必须设置为"`yes`"，因为用户可能会意外地将目录或文件设为全局可写。

`X11Forwarding`

"`X11Forwarding`"指定服务器上是否应该启用X11转发。由于我们设置的服务器没有安装GUI，我们可以安全地将其关闭。

`PrintMold`

"`PrintMold`"选项指定当用户交互式登录时，`ssh`守护进程是否应该打印`/etc/motd`文件的内容`/etc/motd`文件被称为“当日消息”（message of the day）。

`SyslogFacility`

"`SyslogFacility`"选项指定记录`sshd`日志时使用的设施（facility）。该设施指定产生消息的子系统——在本例中为AUTH。

`LogLevel`

"`LogLevel`"选项指定记录`sshd`日志时使用的级别。INFO是一个很好的选择。其他可能性请参见`sshd`页面。

`RostsAuthentication`

"`RostsAuthentication`"选项指定`sshd`是否可以尝试使用基于rhosts的认证。由于这种认证不安全，你不应该使用此选项。

`RostsRSAAuthentication`

"`RostsRSAAuthentication`"选项指定是否尝试在RSA主机认证下进行rhosts认证。

`RSAAuthentication`

"`RSAAuthentication`"选项指定是否尝试RSA认证。为了提高会话的安全性，此选项必须设置为"`yes`"。RSA使用通过`ssh-keygen`工具创建的公私密钥对进行认证。

`PasswordAuthentication`

"`PasswordAuthentication`"选项指定我们是否应该使用基于密码的认证。为了强安全性，此选项必须始终设置为"`yes`"。

`PermitEmptyPasswords`

"`PermitEmptyPasswords`"选项指定服务器是否允许使用空密码登录账户。如果你打算使用"`scp`"工具在网络上进行自动备份，必须将其设置为"`option`"或"`yes`"。

`AllowUsers`

"`AllowUsers`"选项指定并控制哪些用户可以访问`ssh`服务。可以指定多个用户，用空格隔开。
