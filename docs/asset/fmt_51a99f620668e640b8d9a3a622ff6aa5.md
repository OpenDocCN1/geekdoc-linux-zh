
# 命令

## ls

`ls` 将列出目录和文件。语法：
`ls [options] filename`。

## 选项

- `-1` 长列出文件和目录。使用此选项命令将显示以下类型的信息：文件类型、权限、链接数、所有者、组、文件大小、文件修改时间、文件名。
- `-a` 显示所有文件（包括隐藏文件）
- `-i` 显示节点号。
- `-A` 显示所有文件但不包括 `.` 和 `..`

### 通配符示例

```
$ ls ab*       /*以 ab 开头*/
$ ls ?ab       /*以单个字符开头*/
$ ls [abc]*    /*第一个字母必须是 [] 中给出的任意一个*/
$ ls ![abc]*   /*不以 abc 开头*/
$ ls [a-d][c-m][2-9]?? /*列出所有第一个字母为 a 到 d，第二个字母为 c 到 m，第三个字母为 2 到 9 且两个任意字符的文件*/
$ ls *.txt     /*列出所有扩展名为 txt 的文件*/
```

### 文件类型

| 文件类型 | 含义 |
| :--- | :--- |
| `-` | 普通文件 |
| `d` | 目录文件 |
| `b` | 块设备文件 |
| `c` | 字符设备文件 |
| `p` | 命名管道 |
| `l` | 符号链接 |
| `s` | 套接字 |
| `m` | 共享内存文件 |

# UNIX 与 SHELL 编程

## 文件权限

文件权限分为三类：

| 权限 | 权重 |
| :--- | :--- |
| 读取 (r) | 4 |
| 写入 (w) | 2 |
| 执行 (x) | 1 |

一个文件由 `rwxrwxrwx` 组成，其中前三个 `rwx` 分别代表所有者、组所有者，最后三个代表其他用户。

更改文件权限 → 文件权限可以由文件所有者或超级用户（root）更改，不能由其他用户更改。

### chmod（文件模式）

通过此命令我们可以更改文件的权限。

语法：`$ chmod [WHO] [+/-/=] [Permission] <Filename>`

- `WHO` 表示：`u` → 代表用户，`g` → 代表组，`o` → 代表其他用户
- `+` → 添加权限，`-` → 移除权限，`=` ⇒ 设置指定的权限并移除所有其他权限（如果存在）。

```
$ chmod 777 <name> /*这将更改文件的所有权限*/
```

## 创建目录

使用 `mkdir` 命令创建目录。语法：`$ mkdir <Directory name>`

### 选项

- `-m` 设置权限模式。
- `-v` 为每个创建的目录打印一条消息。
- `-p` 创建父目录。

## cat 命令

创建/显示/追加文件

```
$ cat f1           /*如果 f1 是已存在的文件，则覆盖 f1 的内容*/
$ cat >> f1        /*如果 f1 不存在，则创建它，并向 f1 追加内容*/
$ cat f1           /*打开文件 f1，如果不存在则报告错误*/
$ cat f1 > f2      /*如果 f2 存在，则将文件复制到 f2 并覆盖其内容*/
$ cat f1 >> f2     /*如果 f2 不存在则创建它，并将 f1 的内容追加到 f2 中*/
$ cat a*           /*错误（尝试创建一个文件 a*）*/
$ cat > a\*        /*将创建文件 a* */
```

## 删除文件和目录

### 普通文件

```
$ rm <name>        /*删除一个普通文件 */
$ rm a*            /*删除所有以 a 开头的文件 */
$ rm a\*           /*删除名为 a* 的文件 */
```

### 目录文件

```
$ rm -r <directoryname>  /*删除非空目录 */
$ rmdir <directoryname>  /*仅在目录为空时删除 */
```

## 日期命令

`date` 命令以多种格式打印当前日期和时间。它也被系统管理员用于设置系统时间。

```
$ date
Day_of_week Month Date Time IST Year /*默认打印格式 */
```

### 选项

| 名称 | 描述 | 名称 | 描述 |
| :--- | :--- | :--- | :--- |
| `%a` | 本地缩写星期名 | `%l` | 小时 (1.......12) |
| `%A` | 完整星期名 | `%m` | 月份 (01.......12) |
| `%b` | 缩写月份名称 | `%M` | 分钟 (00.......59) |
| `%B` | 完整月份名称 | `%n` | 新行 |
| `%c` | 本地日期和时间 | `%N` | 纳秒 |
| `%C` | 世纪 | `%p` | AM 或 PM 标识 |
| `%d` | 月中的天数 | `%P` | am 或 pm 标识 |
| `%D` | 日期 (MM/DD/YY) | `%r` | 12小时时间 |
| `%e` | 填充空格的天数 | `%R` | 24小时时间 |
| `%F` | 等同于 %Y-%m-%d | `%t` | 水平制表符 |
| `%g` | 对应 %V 周的两位年份 | `%U` | 以周日为第一天的周数 |
| `%G` | 对应 %V 周数的四位年份 | `%u` | 星期 (1.......7) |
| `%h` | 缩写月份名称 | `%V` | 以周一为第一天的周数 |
| `%H` | 小时 (00,...23) | `%w` | 星期 (0.......6) |
| `%I` | 小时 (01,...12) | `%x` | 本地日期 |
| `%j` | 一年的天数 | `%X` | 本地时间 |
| `%k` | 小时 (0,...23) | `%y` | 年份后两位 |
| `%Y` | 年份 (4位数) | | |

## UNIX 命令

### cal

显示日历

```
$ cal          /*显示当前月的日历*/
```

#### 选项

- `-1` -> 显示单月
- `-3` -> 显示上个月/本月/下个月
- `-s` -> 以星期日为第一天
- `-m` -> 以星期一为第一天
- `-j` -> 显示儒略日期
- `-y` -> 显示整年日历

### clear

清除终端屏幕。

### tty

打印连接到标准输入的终端设备文件名。

```
$ tty          // 它打印 /dev/tty01
```

#### 选项

- `-s` 仅在退出状态时不打印任何内容。

## bc 计算器

`bc` 是一种支持任意精度并交互式执行语句的语言。`bc` 开始按照命令行上列出的所有文件的顺序处理代码。在处理完所有文件后，`bc` 从标准输入读取。

### 语法

`bc [OPTION] files`

### 选项

- `-h` → 打印用法并退出
- `-i` → 强制交互模式
- `-l` → 定义标准数学库
- `-w` → 提供 POSIX 权限的警告
- `-q`（静默）不打印名称
- `-v` → 打印版本号并退出

### 变量

- `ibase` → 设置输入基数，默认为 10
- `obase` → 设置输出基数，默认为 10
- `scale` → 小数点后的数字位数
- `last` → （扩展）是一个变量，其值为最后打印的数字

### 注释

```
/* bc 注释 */
# 单行注释
```

### 变量与表达式

简单变量就是一个“名称”。数组通过 `name[expr]` 指定。

- `-expr` → 表达式的负值
- `++var` → 变量加一
- `--var` → 变量减一
- `var++` / `var--` → 后缀自增/自减
- `expr + expr` → 表达式之和
- `*, /, ^, -, %` → 乘、除、幂、减、取模
- `var = expr` → 赋值

### 关系表达式

`<`, `>`, `<=`, `>=`, `==`, `!=`

### 布尔表达式

`&&`, `||`, `!`

### 优先级（从低到高）

1. `||` → 运算符左结合
2. `&&` → 运算符左结合
3. 关系运算符 → 左结合
4. 赋值运算符 → 右结合
5. `+`, `-` → 运算符左结合
6. `*`, `/`, `%` → 运算符左结合
7. `^` → 运算符右结合
8. 一元运算符 → 不结合
9. `++`, `--` → 运算符不结合

### 标准函数

- `length(expression)` → 返回长度
- `read()` → 从标准输入读取数字
- `scale(expression)` → 该函数的值是表达式中小数点后的数字位数
- `sqrt(expression)` → 表达式的平方根
- `print (list)` → 提供另一种输出方法

### 语句

- `[语句列表]` → 它允许将多个语句组合在一起执行（用分号或换行分隔）。
- `if ( expression ) statement1 [else statement2]`
- `while (expression) statement`
- `for (exp1; exp2; exp3) { statement }`
- `break` / `continue`
- `halt` → 这是一个已执行的语句，仅在执行时导致 `bc` 处理器退出。
- `return(expression)`

### 函数定义

```
define name(parameters) {
    auto auto_list
    statement_list
}
```

### 调用

`call → name(parameters)`

示例：
```
define f(n) {
    return(2*n);
}
```

### 数组

数组在参数定义中通过 `name[expr]` 指定。
