
# 化学感受

在多细胞生物中，单细胞和复杂的多细胞感觉器官既用于维持体液稳态（内感受器），也用于监测外部环境（外感受器）。研究最深入的内感受器可能是高等脊椎动物的颈动脉体化学感受器，它们监测动脉血中氧气、二氧化碳和氢离子的水平。研究最深入的外感受器是与味觉和嗅觉相关的感受器。在多细胞生物中，内部通讯也通过化学手段实现。因此，激素和神经控制都涉及细胞对控制化学信使（分别为激素和神经递质）受体的反应。参见：颈动脉体；化学感觉；嗅觉；感觉器官；味觉；舌头。

化学感受背后的基本机制是化学刺激与细胞外膜上受体分子的相互作用。这些分子据信是蛋白质，由于其三维形状和化学性质，它们将具有与仅有选择性的一组化学物质相互作用的正确的空间位置和结合“契合度”（这与酶对多种底物具有特异性是同样的基本机制）。化学刺激与受体分子之间的相互作用最终导致膜通道的结构变化。净结果通常是膜对特定离子的导电性（通透性）发生变化，这既改变了细胞内部的化学成分，也改变了跨细胞膜的电荷分布。在单细胞生物中，这可能足以建立膜电流，从而引发如纤毛运动增加或减少等反应。在多细胞生物中，这通常导致激素释放速率的变化或神经元的刺激。参见：细胞膜。

所有化学感受器的基本特征是特异性（它们将对其产生反应的化学物质）、敏感度（对给定化学刺激的反应幅度）以及感知范围（感受器能够区分的最小或最大刺激水平）。特异性是受体细胞膜中发现的蛋白质类型的结果。每个细胞将具有不同受体分子的镶嵌体，每个受体分子将对不同的分子表现出不同的兴奋性或抑制性反应组合。在兴奋性反应中，有阳离子净流入细胞（去极化）；对于抑制性反应，有阴离子净流入细胞（超极化）。刺激越强——即化学物质越多——受影响的受体越多，导电性变化越大，膜电流越大。在具有神经系统的动物中，主要感觉细胞导电性的这些变化可导致两种事件之一。在某些受体中，如果电流是兴奋性的且幅度足够大，动作电位将在神经元的尖峰起始区产生。其他受体则通过释放作用于二级神经元的神经递质来响应，该神经元具有兴奋性，因此可以产生动作电位。参见：生物电位和离子流。

化学感受器的敏感度既反映了启动受体细胞膜电位变化或放电所需的化学底物量，也反映了化学刺激水平发生任何变化时电位或放电的变化。膜导电性或放电频率的变化程度存在实际限制。因此，对于更敏感的细胞，在反应达到最大导电性或放电速率并饱和之前，它们能够提供有关任何特定化学物质浓度变化信息的范围更小。

在动物中，某些化学感受器的响应性可被其他神经输入增强或衰减。这些影响来自中枢神经系统传入的纤维、邻近的感受器，甚至是化学感受器自身感觉轴突的回返分支。净效果是（1）提高感受器的敏锐度（兴奋性输入使受体细胞的膜电位更接近阈值，需要更少的化学刺激即可引起反应）；或（2）扩展感受器响应性的范围（抑制性输入降低受体细胞的膜电位，需要更多的化学刺激才能使其更接近阈值）。例如，当大多数动物处于饥饿状态时，其化学敏感度会大大增强。

任何给定的化学感受器细胞都可以拥有任何受体蛋白的组合，每种蛋白都可能对不同的化学分子做出反应。因此，化学感受器细胞不表现出对单一化学物质的特异性统一性，而是表现出对各种化学物质组的反应谱。动物能够区分如此众多、复杂、天然化学刺激的能力，源于其中枢神经系统“识别”大量细胞群放电模式的能力。感觉质量不依赖于特定细胞或细胞群的激活，而依赖于具有重叠反应谱的细胞之间的相互作用。

尽管所有生物体中化学感受的基础机制是共同的，但在多分子化学感受器官的设计上存在巨大的多样性，特别是在动物中。大多数这些器官的复杂结构反映了过滤和放大化学信号的适应性。因此，许多昆虫的触角，以及灌溉敏感腔体（如鱼类的嗅球和哺乳动物的鼻腔），增加了化学感受器细胞与环境的接触。同时，它们还允许减少化学刺激物与化学感受器细胞之间的扩散延迟，从而提高敏锐度。就过滤而言，它们可能起到将湍流或分散的刺激转化为更容易解释的时间模式的作用。在各种生物中观察到的这种结构适应性的程度，往往反映了化学感受对该生物的重要性，而这在很大程度上反映了生物体生活的栖息地。参见：化学生态学。[W.M.]

# 恒化器

一种用于连续培养微生物或植物细胞的装置（见图）。细胞生长所需的营养物质通过泵连续供应到培养瓶，泵连接到一个培养基储库。瓶中的细胞在这些营养物质上连续生长。残留的营养物质和细胞以相同的速率通过溢流从瓶（发酵罐）中移除，从而维持发酵罐中培养液的恒定体积。

恒化器培养的一个重要特征是稀释率，定义为一小时提供的营养培养基体积除以细胞体积。在恒化器培养期间，会建立一个平衡（稳态），此时细胞的生长速率等于稀释率。稀释率越高，允许生物体生长的速度越快。超过给定的稀释率后，细胞将无法再更快生长，培养物将从发酵罐中被冲出。因此，恒化器提供了研究生物体在选定生长速率下特性的机会。参见：发酵。

## 恒化器原理

注入发酵罐的营养培养基中除了一种生长限制营养物质外，其余所有生长因子均过量。发酵罐中细胞（生物量）的浓度取决于培养基进料中生长限制营养物质的浓度。当生长限制营养物质进入发酵罐后，几乎会被完全消耗，因此培养物和流出液中仅残留微量该物质。起初，由于接种在生长容器中的细胞数量较少，即使是生长限制营养物质也处于过量状态。因此，微生物能以超过其移除速率的速率生长。这种细胞生长导致生长限制营养物质的水平下降，逐渐使微生物的比生长速率降低。一旦比生长速率与细胞因稀释而被移除的速率达到平衡，系统便建立起稳态，此时细胞密度和生长限制营养物质的浓度均保持恒定。因此，恒化器是一种能够在恒定生理状态下几乎无限期培养微生物的工具。

为了实现稳态，除稀释速率和培养体积外的其他参数必须保持恒定（例如温度和pH值）。发酵罐经过搅拌以提供均一的悬浮液，使培养物中的所有单个细胞都能立即接触到生长限制营养物质，并在使用好氧培养时实现发酵罐内空气（氧气）的最佳分布。

实验室恒化器的培养液体积通常为0.5至10.5升（0.5至1.0升），但工业连续培养可涉及高达343,000加仑（1,300立方米）的体积，用于微生物生物量的连续生产。

由于当营养物质保持生长限制状态时，培养物中的营养物质浓度极低，因此恒化器可用于在剧毒营养物质上培养微生物。恒化器可用于筛选对生长限制营养物质具有更高亲和力的突变体，或者在混合种群中，筛选出对生长限制和培养条件适应最佳的物种。恒化器在微生物的生理学、生态学和遗传学等领域具有重要用途。参见：细菌遗传学；细菌生理学与代谢；微生物学。[J.G.L]

# 化学地层学

化学地层学是地层学和地球化学的一个分支学科，涉及通过使用痕量元素浓度、分子化石以及岩石组分中可测量的特定同位素比值，对海洋沉积物和沉积岩进行对比和定年。化学地层学中使用的同位素可分为三类：放射性成因同位素（锶、钕、锇）、放射性同位素（放射性碳、铀、钍、铅）和稳定同位素（氧、碳、硫）。痕量元素浓度（即镍、铜、钼和钒等金属）以及某些有机分子（称为生物标志物或生物标志分子）也应用于化学地层学。参见：定年方法；岩石年龄测定。

放射性成因同位素是由母体同位素通过放射性衰变形成稳定的子体同位素而产生的。这些同位素在地层学中的应用基于溶解在海水中的元素同位素组成的自然周期，这些周期记录在沉积岩中。参见：同位素；放射性同位素。

氢、碳、氮、氧和硫等元素由于原子质量不同，物理和生物过程会对这些同位素进行区分，从而决定了它们的同位素分布。这些同位素在地层学中的应用也得益于海水同位素组成的周期，但海洋矿物中的同位素比值还取决于水温和矿物形成过程。参见：海水。

某些可与特定来源相关联的有机分子（称为生物标志物）在地层学中变得非常有用。生物标志物的沉积分布反映了有机物质的生物来源和输入（如来自藻类、细菌和维管高等植物），以及沉积环境。

某些痕量金属，如镍、铜、钒、镁、铁、铀和钼，在富含有机物的沉积物中根据有机碳的含量而富集。尽管控制其富集的过程复杂，但它们通常形成于缺氧环境（如黑海）或全球海洋缺氧事件期间，届时整个海洋盆地变得缺氧，导致许多生物死亡；因此，海洋沉积物中保存了更多的有机碳。单个地层单位的痕量金属组成可作为地层标志物或“指纹”。参见：地球化学；海洋沉积物；地层学；铀。[B.L.L, D.J.DP]

# 化学分类学

在分类学研究中应用生物化学。生物体产生多种天然产物，含量各异，且负责这些化合物合成的生物合成途径往往因分类群的不同而异。这些化合物及其生物合成途径的分布与基于形态等传统标准现有的分类安排非常吻合。在某些情况下，化学数据与现有假设相矛盾，这促使人们重新审视该问题；或者更积极地说，当其他形式的数据区分度不足时，化学数据提供了更确定的信息。参见：动物系统学。

现代化学分类学家通常将天然产物分为两大类：

- 小分子：即分子量小于或等于1000的化合物，如生物碱、萜类化合物、氨基酸、脂肪酸、类黄酮色素和其他酚类化合物、芥子油以及简单碳水化合物。
- 大分子：即分子量超过1000的化合物（通常为聚合物），包括复杂多糖、蛋白质以及生命的基础——脱氧核糖核酸（DNA）。

植物的粗提物可以通过使用一种或多种色谱技术，包括纸色谱、薄层色谱、气相色谱或高压液相色谱，分离成其各个组分，特别是在小分子的情况下。所得的色谱图提供了特定化合物类别下植物物种的可视化显示或特征“指纹”。

分离后的单个斑点可以进一步纯化，然后 subjected 于一种或多种光谱学技术，如紫外光谱、红外光谱、核磁共振或质谱（或两者兼有），这可能提供关于化合物结构的信息。因此，为了分类目的，可以跨物种比较化合物的视觉图案和结构知识。参见：光谱学。
