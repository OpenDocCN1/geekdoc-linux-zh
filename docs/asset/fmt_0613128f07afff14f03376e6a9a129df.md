# 颜色

颜色也通过标准方法定义，例如基于三个值的颜色规范。这些值将构成`X`、`G`和`B`角的有效身份。由于当时对1931年CIE色度图了解较少，色彩印象（CIE系统）在当时被采纳为一种用于预测异色色的相关系统（CIE色度系统）。这种视觉系统允许通过`X`、`Y`和`Z`坐标来表现颜色，从而可以基于光场的计算预测颜色效应。

## 颜色（量子）

一个被认为使强相互作用元素结合在一起的夸克所携带的假设性量子数。颜色与光学颜色无关。

被认为构成强相互作用粒子的夸克具有一个单位 `h`（普朗克）的自旋。根据量子力学的基本理论，它们遵循费米-狄拉克统计并必须遵守泡利不相容原理。没有两个夸克具有相同的量子态。排除原理

然而，在制造重子时，有必要对粒子进行可视化。例如，该粒子由三个夸克组成，这三个必须处于完全相同的状态。O. W. Greenberg 为夸克的发现提出了本质解决方案。1964 年，他建议三种类型的夸克（`u`、`d` 和 `s`）具有三种不同的内部属性，这种属性后来被称为“颜色”。那么该原理可以表述为：重子中的夸克不会具有相同的颜色数。如果它们在其他所有方面都相同，它们将会有不同。

## 原子元素与原子跃迁的影响

原子跃迁在相反的光谱中产生吸收带。此类谱带存在于碱卤化物、地球氟化物或金属中。这是在广泛系统中发现的普遍现象。吸收是由辐射或激发、添加杂质或某些取代基引起的，或者是由它们自身引起的。一个广为人知的例子是碱卤化物（如氯化物）中的 `F` 中心。该名称来源于德语词 "Far"，意思是中心在可见光谱的蓝端产生一个光吸收带；晶体在光下呈现黄色。如 `F` 中心和 `V` 中心等色心的存在导致了在紫外线区域出现吸收带（U 带）。在这种情况下，并未形成 `F` 中心。然而，氢的结合极大地增加了 X 射线照射产生的 `F` 中心的形成，使得 U 中心以高效率转换为 `F` 中心。

## 颜色

颜色是一种部分吸收辐射的元素，通常被称为吸收滤片。吸收对于波长（或颜色）具有选择性，限制了被吸收的光所传输的颜色。

滤光片不吸收所有颜色。它们用于摄影、光学仪器和成像设备，以控制光的光谱组成。

滤光片为了最大性能而制造，细胞中的液体溶液用于颜色的灵活性，或者玻璃上的明胶用于经济和灵活性。滤光片的性能通常良好，但它们被胶在玻璃板之间以获得更大的稳定性和耐用性。

滤光片根据其光谱类型分类：短波、长波通过或带通；漫散或陡截止；单色或转换。短通允许所有到指定波长的光通过。长波通过滤片漏光严重且不易产生。每一块玻璃在紫外线或光谱的褪色部分都不通过光。

滤光片分为尖锐和漫散，带通边缘的尖锐度不同。单色滤片是非常窄的带通滤片。转换滤片将一种光源的光谱变为另一种的光谱，从光浴到太阳的颜色。电磁辐射的吸收；颜色；太阳。[W.L. Woo]
