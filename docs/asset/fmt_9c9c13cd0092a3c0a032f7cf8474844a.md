# Linux 词典

用于 Java(tm) CUP 的 LALR 解析器生成器是实用解析器构造器（Constructor of Useful Parsers），这是一个从简单的 LALR 规范生成解析器的系统。它与广泛使用的程序 YACC 起相同作用，且 CUP 用 Java 编写，使用包括嵌入 Java 代码在内的规范，并产生以导入形式的解析器。来自 Debian 3.0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

cups

通用 Unix 打印系统（Common Unix Printing System）为 UNIX(tm) 操作系统提供了一个可移植的打印层。它由 Easy Software Product 开发，旨在为所有 UNIX 厂商和用户推广标准的解决方案。CUPS 提供了 System V 和 Berkeley 界面。这是 CUPS 服务器的主包（即连接到网络打印机或使用主机作为网络打印机的机器）。它也可以用于 CUPS 客户端，这样它们只需从其他 CUPS 服务器获取广播的打印机信息，并通过 `/etc/cups/client.conf` 分配给特定的 CUPS 服务器。来自 Mandrake 9.0 RPM `http://www.tdlp.org/LDP-Linux-Dictionary/index.html`

cupsys

通用 Unix 打印系统(tm) – 通用 Unix 打印系统（或 CUPS(tm)）是一种打印系统，是 lpd 等类似程序的通用替代方案。它使用互联网打印协议 (IPP)，并拥有处理各种文档类型的自己的驱动模型。此包提供了 CUPS 调度程序/守护进程以及相关文件。“Common Unix Printing System”和“CUPS”是 Easy Software Products（www.easysw.com）的商标，并指制作这些内容的原始源包。来自 Debian 3.0 APT `http://www.tdlp.org/LDP-Linux-Dictionary/index.html`

curator

将图像目录转换为静态网页。Curator 是一个强大的脚本，允许用户生成网页画廊，旨在在网络上显示摄影图像，或用于 CD-ROM 展示和存档。它生成静态页面——用户无需配置或运行脚本。该脚本支持许多格式、分级目录、缩略图生成以及带有所有属性的逐图像描述，以及跨多个目录的图像“轨迹”。模板包含嵌入 Python 的 HTML。此脚本需要较版本的 Python 解释器和 ImageMagick 工具。上游地址：`http://curator.sourceforge.net` 来自 Debian 3.0r `http://www.tdlp.org/LDP-Linux-Dictionary/index.html`

curl

从 FTP 或 HTTP 获取文件，curl 是一个客户端，用于从服务器处理数据。它支持 SSL、代理和恢复。该包提供了各种协议的工具集。来自 Debian 3.0r `http://www.tdlp.org/LDP-Linux-Dictionary/index.html`

cursel
