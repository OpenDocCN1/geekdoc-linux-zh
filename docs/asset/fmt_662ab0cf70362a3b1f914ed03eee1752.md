**Listing 27-27** 使用选项 2，Dirvish 执行特定备份。当我们运行单个备份时，脚本首先确保库中有一个 `default.conf` 文件。如果找到了 `default.conf` 文件，我们使用以下语法执行备份：

```bash
/usr/local/sbin/dirvish -vault $SHN
```
其中 `$SHN` 是要备份的库名。
