### 使用终端仿真器

有经验的`Linux`用户最常使用的方法之一是`Terminal Emulator`界面。这是一种通过输入完整命令来调用`GUI`和非`GUI`应用程序的界面。终端仿真器中的界面完全基于字符且非图形化。当你从终端调用`GUI`程序时，操作系统会为调用的程序打开一个独立的`GUI`窗口。

> 由于在终端仿真器中完成的所有工作都需要基于字符的命令输入，因此终端仿真器也被称为命令行接口（或`CLI`）。它也通常简称为终端。

存在许多终端仿真器，例如`gnome-terminal`和`xterm`。在这本书中，我们将大量使用`Red Hat Linux`自带的`gnome-terminal`仿真器。要调用这个特定的终端仿真器，你可以打开一个运行程序... 窗口（按`Alt-F2`），并输入名称`gnome-terminal`；或者选择`Main Menu | System Tools | Terminal`。

这样调用`gnome-terminal`后，你会得到一个类似于下图所示的终端窗口。现在你可以开始输入想要执行的程序名称。在这个截图中，你可以看到我们使用选项`-al`执行了程序`ls`以显示当前目录中的所有文件：

![](img/b852150740856958b10aff9e8c9d2adc_61_0.png)

### CLI 的优缺点

使用`CLI`相比`GUI`有优势，但也有缺点：

- 在此界面中执行程序时，你需要知道它们的名称。与显示可用选项的`GUI`菜单界面不同，`CLI`不提供这种便捷的即查即用功能。

然而，`GUI`通常受限于显示屏上的可用空间。即使通过菜单进行了合理的组织，也很难让操作系统的每个程序都触手可及，而过多的菜单层级会使访问特定程序变得更加繁琐。相比之下，使用`CLI`可以访问所有可用的程序。

最终，`CLI`提供了力量和灵活性，使你能够更完整地控制计算机，如果你执行大量类似的任务，它有可能比使用`GUI`提高你的生产力。存在一个学习曲线——主要与学习程序名称和适当参数有关——但这种努力通常会有回报。为了给你正确的方向，这里有两个便捷的工具，将帮助你开始使用`CLI`应用程序。

### 学习如何使用程序

要了解有关命令的更多信息，你可以使用`man`命令，它会为你提供该命令的`Program Manual`。例如，如果你想更多地了解`vim`编辑器，可以在命令行输入以下内容：

```
$ man vim
```

这将显示以下输出：

![](img/b852150740856958b10aff9e8c9d2adc_63_0.png)

要查看此文档的下一页，请按空格键；实际上，你可以使用箭头键在文档中上下导航。要退出手册（并返回到命令行提示符），请按`q`。

事实上，手册分为许多部分；有些关键词有多个条目，在这种情况下，你可能需要指定正确的部分。例如，第 1 部分涵盖用户命令，因此以下内容将为你提供描述`passwd`命令的手册页：

```
$ man 1 passwd
```

相比之下，第 5 部分涵盖文件格式，因此下一个命令将为你提供描述`/etc/passwd`文件的手册页：

```
$ man 5 passwd
```

要快速浏览手册中所有章节，请尝试以下命令，其中`$N`是你感兴趣的章节编号：

```
$ man N intro
```

### 关闭计算机

您最迫切的需求之一是弄清楚在完成后如何关闭机器，或者因某种原因需要重启它。此外，当您完成工作后，可能需要注销桌面，以便其他用户可以登录计算机并开展工作。

注销和关机选项均由`Main Menu | Log Out`选项控制。

如果您选择`Log Out`，当前桌面会话将终止，并显示登录屏幕——允许您或该机器的其他用户登录并使用桌面。`Shut Down`和`Reboot Computer`选项不言自明——它们允许您关闭机器或重启它。

> 这些是推荐的关闭和重启机器选项，以确保数据安全并保证操作系统在未来可靠运行。

注意对话框顶部的`Save Current Settings`复选框。对于这些选项中的每一个，如果您选择此复选框，`Linux`将在注销您之前保存桌面设置。此选项的主要优点是，桌面会记录正在运行的应用程序，并且下次登录时，它将尝试重新启动这些应用程序。

##### 文件系统

对于从非`Unix`基础操作系统（例如任何`Microsoft Windows`操作系统）迁移过来的用户，`Linux`对文件、目录、磁盘驱动器及其他设备的组织方式需要一点时间来适应。作为`Unix`的一个变种，`Red Hat Linux`以`Unix`的方式组织文件——使用一个庞大的`Directory Hierarchy`。在本节中，我们将研究文件系统层次结构以及如何在工作中使用文件系统；我们将在第 7 章中进一步详细研究文件系统。

### 文件系统层次结构

在`Linux`操作系统中，每个文件、目录和设备都是庞大层次结构的一部分。此层次结构中最顶层的成员是`Root Directory`，用符号`/`表示。给定目录的子目录由父目录和子目录名称的连接表示。例如：

- 根目录下有一个名为`usr`的子目录，我们用`/usr`表达式表示该子目录的完整路径
- `usr`目录下一个名为`local`的子目录可以用`/usr/local`表达式表示

这种简单的目录层次结构可以用下面的树状图表示：

![](img/b852150740856958b10aff9e8c9d2adc_66_0.png)
