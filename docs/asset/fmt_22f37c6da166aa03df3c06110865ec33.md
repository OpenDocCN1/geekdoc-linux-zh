## 启动

启动 WordPerfect 时，一个小矩形窗口，即程序窗口，会出现在屏幕上（图 1）。您使用程序窗口所做的任何更改都会影响 WordPerfect 中创建的所有文档。

文档窗口是屏幕上创建文档的区域（图 1）。您使用文档窗口所做的任何更改仅影响您正在处理的当前文档。文档窗口中您实际处理文档文本的部分称为工作区。

您可以同时打开多达 100 个文档窗口（取决于计算机的内存大小）。当显示多个文档窗口时，标题栏高亮的窗口为活动窗口。如果您在文档窗口中输入或更改任何内容，则更改的是活动文档。首次启动 WordPerfect 时，会出现一个新文档窗口，准备好进行输入。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_44_0.png)

### 菜单项和桌面快捷方式

在 Gnome 或 K 主菜单中添加一个项目或在桌面上添加快捷方式后，启动 WordPerfect 变得快速而简单。

#### 将菜单项放在 Gnome 主菜单上：

1. 从 Gnome 主菜单上的 Settings 弹出菜单中选择 Menu editor（图 2）。GNOME 菜单编辑器对话框将打开，并在树视图窗口中选择了 User Menus（图 3）。
2. 在菜单栏上，单击 New Item 在 User Menus 下添加新的菜单项。
3. 在 Basic 选项卡页面上，在 Name 文本框中输入 WordPerfect（图 4）。
4. 在 Command 文本框中输入 WordPerfect 安装位置的完整路径名加上启动 WordPerfect 的命令。在图 4 中，已输入 `/usr/wp/wpbin/` `./wp`。
5. 单击 Icon 按钮选择合适的图标。
6. 单击保存。
7. 通过单击关闭按钮关闭 GNOME 菜单编辑器对话框。WordPerfect 菜单项将出现在 Gnome 主菜单上（图 5）。
