
# 机翼颤振

在无激波的平滑流动中，飞机机翼或其操纵面的流-弹性不稳定称为经典颤振。飞行试验表明，对于固定的攻角，翼型的升力随马赫数增加而增加。此升力在临界马赫数达到最大值，然后急剧下降，无论飞行速度多高都不会再增加。这种下降是由于流动分离或激波形成。这两种流动机制中的任何一种都可能导致翼型失速或损坏。在这种情况下，翼型被称为失速颤振或激波失速，取决于流动过程。参见[激波](https://example.org/shock_wave)。

当流动从飞机机翼上分离时，机翼后方的流动是湍流且随机的。因此，飞机的尾部受到机翼湍流尾迹的随机激励。随机振荡的机翼和尾部可能会失去稳定性。这种动态气动弹性不稳定被称为拍击颤振，因为振荡是随机的。参见[边界层流动](https://example.org/boundary_layer_flow)；[湍流](https://example.org/turbulent_flow)；[尾迹流](https://example.org/wake_flow)。

# 圆柱阵列的振动

在流致振动的话题中，圆柱形结构起着非常重要和关键的作用。例如，飞机机身、导弹和火箭的细长体，工业烟囱、输电电缆、电话线、石油管道、反应堆燃料棒、热交换器管和海洋结构的主体，以及血管主要由圆柱形结构组成。这些结构在操作时，受到非定常流体力作用，容易振动。根据来流与圆柱轴入射角，这种振动可分为顺流引起或横流引起振动。失速和拍击颤振，称为流弹性不稳定，包括流体阻尼控制和流体刚度控制的不稳定，以及涡脱落，在流致振动期间都可能发生。（S.S.C. WWU.）

# 流量测量

测定通过管道、导管或明渠的流体（液体、蒸气或气体）的数量。流量可以表示为体积流量率（如升/秒、加仑/分钟、立方米/秒、立方英尺/分钟）、质量流量率（如千克/秒、磅/小时），或总体积或质量流量（给定时间段内的积分流量率）。

流量测量虽然已有数百年历史，但在工业时代已成为一门科学。这是因为需要受控的工艺流量、更严格的核算方法、更高效的运营，以及意识到过程工业中大多数加热、冷却和物料运输都是流体形式，其流量率易于用阀门或变速泵控制。参见[过程控制](https://example.org/process_control)。

测量通过多种手段完成，取决于涉及的量、流量和流体类型。

许多工业过程流量测量由两种设备组成：一种主要设备，与流体紧密接触并产生信号；和一种次要设备，将此信号转换为运动或次要信号，用于指示、记录、控制或累积流量。其他设备通过流动流体与直接或间接接触流体流的测量设备的相互作用，直接指示或累积流量。参见[计量孔板](https://example.org/metering_orifice)；[皮托管](https://example.org/pitot_tube)；[文丘里管](https://example.org/venturi_tube)。(M.B. L.FE.)

# 固体流动

陶瓷粉、塑料颗粒和矿石等颗粒固体以独立颗粒形式在重力作用下流动，颗粒相互接触，其间的空隙充有气体，通常是空气。

颗粒固体是固-气两相系统。它们是可压缩的；其堆密度在流动过程中变化。由于在此过程中颗粒体积变化很小，主要受影响的是空隙的大小。空隙大小的变化可导致气体压力变化，并在流动的固体中产生气压梯度，从而倾向于降低重力排出率。当固体由大颗粒组成，即其渗透性高，且所需流量率低时，气压梯度不显著；气相可以被忽略，固体可被视为单一相、仅固体系统。

料仓（筒仓、料斗）通常由一个垂直圆柱体和一个收敛料斗组成。从流动的角度来看，有三种类型的料仓：质量流、漏斗流和扩展流。当料斗壁足够陡峭且光滑，使得当抽出任何固体时，所有固体都能流动，没有停滞区域时，就会发生质量流。导致质量流的料斗斜率和摩擦角范围如下图所示。除非满足此处所示的质量流条件，否则将发生漏斗流。

在漏斗流料斗中，固体物料通过停滞物料内部形成的通道流向出口。该通道的直径近似于有效出口的最大尺寸。随着通道内固体物料层位的下降，物料层会从停滞物料堆的顶部脱落并落入通道中。对于具有凝聚性的固体物料，这种不规则的行为是有害的，因为下落的物料在撞击时会发生压实，从而增加了物料在料斗中形成稳定拱桥并导致流动完全停止的可能性。通道，特别是狭窄且高速的通道，可能会完全排空，形成所谓的“鼠洞”现象，然后充入料斗的粉末会通过该通道冲出。在漏斗流料斗中以高速流动的粉末可能由于在料斗中停留时间较短而保持流化状态，并在流出料斗时冲出。在这些条件下，通常使用旋转阀门来容纳物料，但由于流向阀门的流动不规则，无法确保均匀的流量。

与质量流料斗相比，漏斗流料斗更容易导致具有凝聚性的固体物料形成拱桥，因此它们需要更大的出口才能保证可靠的流动。这些料斗还会导致固体物料的分级，因此不适用于在停滞区域中会随时间降解的固体物料。漏斗流料斗的清理往往不确定，因为停滞区域内的固体物料可能会压实和结饼。

扩展流料斗是通过在漏斗流料斗的底部连接一个质量流料斗形成的。与漏斗流料斗相比，其出口通常只需要较小的给料机。质量流料斗应将流动通道扩展到足够的尺寸，以防止鼠洞现象的发生。[A.W.Je.; J.W.Ca.]

# 花

高等植物的性器官总称，包括产生生殖细胞的部件以及紧密相连的吸引和保护部位（图 1）。本文使用的“花”一词，如往常一样，局限于被子植物，即种子封闭且具有独特生殖过程——双受精的植物。在其最常见的形式中，花由四种同心排列的单位组成。绿色的萼片（统称为萼）位于最外层，其次是花瓣（花冠），然后是承载花粉的单位（雄蕊，雄蕊群），最后是中央位置结种子的单位（心皮，雌蕊群）。这就是前文讨论过的“完全”花；但这只是几乎令人眼花的众多花形式中的一种。根据物种不同，一种或多种单位可能缺失或难以识别，并且在某些被子植物类群中，进化修饰如此之大，以至于花簇（花序）看起来像是一朵单独的花。

## 花多样性

大多数植物学名词都是描述性的，植物学家必须拥有大量的这类术语来识别绝大多数花卉。以下示例仅是其中的一小部分。例如，在紫花忍冬（purple loesetree）中，与萼片交替排列的额外附属物系列被称为副萼。具有宽阔末端区域和狭窄基部区域的花瓣被称为具有瓣片和爪；紫薇（crape myrtle）就有这样的花瓣。术语“花被”（perianth）涵盖了萼和花冠，避免了区分两者的需要，这对于像郁金香这样的花特别有用，其花被部分有两个系列，但在大小、形状和颜色上相似。这种未分化花被的成员称为花被片。然而，当花被只有一个系列的部分时，即使它们像花瓣一样，习惯上也被称为花被片，例如风信子（windflower）。

雄蕊通常由一个细长的花丝组成，顶端是一个四裂的花药，每个裂片中包含一个不育囊。一种或多种雄蕊群的部分可能是不育的退化体，称为雄蕊化结构（staminodes）：毛地黄花朵有四个可育雄蕊和一个雄蕊化结构。雌蕊化结构（Carpellode）是用于指代发育不完全的雌蕊群单位的相应术语。

如果心皮是分离的（木兰、黑莓），雌蕊群即为离生雌蕊（apocarpical）；如果它们联合（郁金香、罂粟），则为合生雌蕊（syncarpic）。或者，雌蕊群可能仅由一个心皮组成（豆类、樱桃）。单个心皮或合生雌蕊群通常可以分成三个区域：顶端的、接受花粉的柱头；基部肿胀的、包裹未发育种子（胚珠）的子房；以及两者之间收缩的、细长的花柱。雌蕊群可以是上部离生、下部合生的，也就是说，可以在一个子房上拥有分离的花柱和柱头（酢浆草属的木酢浆草）。

前面提到的每朵花都具有上位子房：花被和雄蕊群在其下方分叉（下位花）。如果花被和雄蕊群从子房顶端分叉，子房即为下位子房，花则为上位花（苹果、香蕉、南瓜）。如果子房位于杯状结构内的上位位置，且其他花部分从杯口边缘分叉，则为周位花（樱桃）。如果合生子房仅有一个心室（梅、梨），则为单心室合生子房（unicarpical）；如果隔膜将其分为多个心室，多心室子房的胚珠通常附着在隔膜相交的角上；这是中轴胎座，胎座是胚珠附着的区域。胚珠还有其他附着方式——顶生、基生、侧生或在游离的中轴胎座上——每一类都具有一定的植物类群特征（图 2）。

术语“苞片”可应用于与一朵或多朵花相关但并非花的一部分的任何叶状部分。花的苞片通常很小，甚至像鳞片，但花楸属（flowering dogwood）在每簇花下方都有四个像花瓣一样大的苞片。花茎上花部分附着的宽端是花托。同一个术语不太一致地用于指承载许多单独小花（florets）组成复合花（如蒲公英或向日葵）的宽基部。

## 两性生殖
