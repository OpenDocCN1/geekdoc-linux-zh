## fmt—一个简单的文本格式化工具

`fmt` 程序也可以格式化文本，它还可以接受文件或标准输入，并对文本流进行段落格式化。基本上，它会填充并合并文本中的行，同时保留空行和缩进。

为了演示这一点，我们需要一些文本。让我们从 `fmt` 的帮助页中提取一些。

`fmt` 读取指定的 `FILE` 参数（如果没有提供，则从标准输入读取），并写入到标准输出。

默认情况下，空行、单词之间的空格和缩进会在输出中保留；具有不同缩进的连续输入行不会合并；制表符在输入时展开，在输出时引入。

`fmt` 倾向于在句子末尾断行，并尽量避免在句子第一个单词之前或最后一个单词之前断行。“句子断句”被定义为段落的结束，或者以 `\?` 结尾的单词，后跟两个空格或行尾，并忽略任何中间的括号或引号。像 Tex 一样，`fmt` 在选择行之前会进入“段落”模式；该算法是 Donald E. Knuth 和 Michael F. Plass 在《Breaking Paragraphs Into Lines》（发表于 *Software--Practice & Experience* 11, 11 (1981年11月), 1119-1184）中提供的算法变体。

我们将这段文本复制到文本编辑器并将文件保存为 `fmt-info.txt`。现在，假设我们想重新格式化这段文本以适应 50 个字符的宽度。我们可以通过 `fmt` 配合 `-w` 选项处理文件来实现。

```bash
me@linuxbox ~$ fmt -w 50 fmt-info.txt | head
  'fmt' reads from the specified FILE arguments
  (or input if
  none given), and writes to standard output.
```

### 表 21-3：fmt 选项

| 选项 | 说明 |
|---|---|
| `-c` | 在页边距模式下运行。这保留了段落前两行的缩进。后续行与第二行的缩进对齐。 |

| `-s` | 单行拆分模式。在此模式下，行仅会被拆分以适应指定的列宽。短行不会合并以填满行。这种模式在格式化如代码等不需要合并的文本时非常有用。 |
| `-u` | 对文本执行统一的传统的“打字机样式”格式化。这意味着单词之间有一个空格，句子之间有两个空格。这种模式用于两端对齐，即通过填充空格来强制使左右边距对齐的文本。 |
