## Web 浏览器：Mozilla, Konqueror, Galeon 和 Lynx

## 你的 CD-R/W 驱动器设置（可选部分）

- 所有设置都必须完成。新的发行版（例如 RedHat 8.0）可能不需要设置。

- 检查你的启动文件是否包含一个内核参数，告知你拥有 ide-scsi 驱动器的信息：`"hdb=ide-scsi"`。如果需要，将其添加到文件 `/etc/locilo.conf`。
`"hdb=ide-scsi"` 选项应该位于 `/boot/grub/grub.conf` 中（取决于你的系统使用哪个引导加载程序）：

```
append="hdb=ide-scsi" #（/etc/locilo.conf，在 Linux "image" 部分末尾）
kernel /boot/vmlinuz-2.4.7-10 root=/dev/sda6 hdb=ide-scsi #（对于 /boot/grub/grub.conf）
```

如果你的刻录机不是 `"hdb"`（第一个 IDE 接口上的第二个驱动器），请调整上述行。这使得你的 IDE-ATAPI CD-W(R) 在你的 Linux 系统中被视为 SCSI 设备。（它并不是真正的 SCSI 设备，是一个 IDE 设备，只是假装成 SCSI。）在更改 `etc/lio.conf` 后运行。Grub 不需要重新运行。

- 如果 `/dev/` 目录下不存在 loop，请添加它。这不是强制性的，但如果你计划制作自己的 CD，这是一个很好的功能。loop 设备将允许你挂载 CD 镜像文件（如果是文件系统）以检查内容。在安装 Linux RedHat 后，我的硬盘上不存在 loop 设备，所以我使用以下命令创建它：

```
cd /dev
```

确保使用以下命令将相应的模块加载到内核：

```
insmod
```

如果需要，将这两行位于 `/etc/rc.d/rc.local` 文件末尾，以便在启动时自动加载所需的内核模块：

```
sbin/insmod ide-scsi
sbin/insmod loop
```

分别用于 SCSI 模拟 IDE 驱动器和支持 loop 设备。

- 检查或修改设备 `/dev/cdrom` 使其指向正确的设备，最可能是：

```
ls -l /dev/cdrom
ls -s /dev/scdb /dev/cdrom [如果需要]
```

你可能需要这样做，因为 `"dev/cdrom"` 指向了一个 IDE 设备（可能是 `/dev/hdb`），但现在你的刻录 CD-R 将在 SCSI 模拟下运行。
你可能想让 `dev/cdwriter` 指向 `dev/cdrom`，尽管在 CD 驱动器系统上这不是必须的：

```
ls -s /dev/cdwriter /dev/cdrom
```

- 重启以使 `etc/lio.conf` 的更改生效。检查 CD-R(W) 是否仍能正常读取。
检查是否安装了 `cdrecord`，例如：

```
cdrecord -scan
```

如果没有安装，请从你喜欢的 Linux 软件仓库下载 `"cdrecord"` 程序（例如，`http://direct.linuxberg.com/`）。然后安装源码、编译、安装程序。

- 音频 CD（Audio CDs）不包含文件系统，它们存储的是“原始数据”。这意味着你无法挂载音频 CD。此外，每个音轨都是单独写入的，就像它们是 CD 上不同的“分区”一样。

要从音频 CD 中读取音轨并将其写入硬盘上的文件（典型格式为 `.raw` 或 `.wav`），你需要一个“CD 刻录机（cd ripper）”。一个流行的 CD 刻录软件是 `"cdparanoia"`。如果没有安装 `cdparanoia`，请下载它。从源码安装的步骤如下（在输入以下行时，我使用了自动补全 Tab 键快捷键）：

```
cd ~/local

tar -xvf /path/to_which_downloaded/cdparanoia-III-alpha9.6.src.tgz

ls

cd cdparanoia-III-alpha9.6

./configure

make

make install
```

要从音频 CD 刻录第一个音轨，我可以使用：

```
cdparanoia 1
```

这会将 CD 中的第一个音轨放入当前目录下的波文件 `"cdda.wav"` 中。

要将音频 CD 的第 1 到 2 个音轨刻录到“原始”文件格式，可以使用：

```
cdparanoia -p 8 "1-2"
```

选项 `-B` 表示使用“批量”模式，因此每个音轨会被放入一个单独的文件，`-p` 选项指定以原始格式输出。文件命名为 `track1.cdraw` 和 `track2.cdraw`。

要从音频 CD 刻录所有音轨，每个音轨保存到单独的 `.wav` 文件中，同时强制以 4 倍速运行，可以使用：

```
cdparanoia -s 4 -8 "1-"
```
