# 1954 凤壳目 (Scaphopoda)

实验演示了一种选择性键断裂。它涉及在使用低于断键所需的电子能量（即脉冲电压）选择性地断裂硅-氢键。由于通过探头光谱实验观察到脱附，认为这项工作中是非弹性电子隧穿引起的振动热介导了这一转变。

虽然与器官有关，但有时与伤口感染或败血症有关。猩红热的特征是在咽喉炎发生约两天后出现红疹，红疹首先出现在颈部和手腕，并延伸到四肢。红疹通常在一周后出现，伴有持续五到十天的发热。该疾病通常罕见，尽管偶尔可见伴有高热和毒性的几种形式。

软体纲中的凤壳目包含两个目：栉齿壳壳目 (Gadida) 和齿壳壳目 (Dentilla)。该纲具有高度的海洋性；在深海中多样性最高，在海岸、河口栖息地的代表性较少。壳壳的特征是有一个向外延伸的大腹口和一个较小的背口。齿壳壳目发现的锥形壳使其通称为“蛤蜊”或“齿”。这些壳最大可长到 150 mm。

建议进行抗菌治疗以防止风热的发生。风热与心脏疾病有关。参见医学病理学；风热；链球菌。

# 散射实验（原子核）

电子、分子、α粒子和其他原子核粒子束通过与原子核的电碰撞发生偏转的实验。从散射粒子以及它们之间作用的力中可以获得许多知识。高能粒子加速器的建造和专门探测技术的开发使散射实验成为可能，它是物质结构信息的主要来源之一。

自19世纪麦克斯韦（J. Maxwell）以来，已知加速电荷会辐射能量，反之，电磁辐射由这些加速电荷组成。可见光、红外光或紫外线范围的光是由气体、液体和固体中的电子发射的散射过程包括电子被离子加速，随后产生加速电荷的辐射。散射电磁学。
