
`s=$months`

`a = p * ((1 + i) ^ n) / (((1 + i) ^ n) - 1)`

`print a, "\n"`

`EOF`

```

在上一章中，我们查看了 shell 如何处理字符串和数字。到目前为止我们过的数据类型在计算机科学领域被称为*标量变量*（scalar variables）；即它们是包含单个值的变量。

在本章中，我们将学习另一种数据结构，称为*数组*（array），它存储多个值。数组是几乎每种编程语言的特性。shell 也支持数组，尽管方式相当有限。尽管如此，它们对于解决某些类型的编程问题仍然有用。

## 什么是数组？

数组是同时持有多个值的变量。数组像表格一样组织。让我们以电子表格为例。电子表格就像一个*二维数组*。它既有行也有列，其中的单元格根据其行和列地址定位。数组拥有单元格，被称为*元素*（elements），每个元素包含数据。单个数组通过称为*索引*（index）或下标的地址访问。

大多数编程语言支持多维数组。电子表格是一个两个维度（宽度和高度）的多维数组示例。许多语言支持任意维数的数组，尽管二维和三维数组可能是最常用的。

*bash* 中的数组局限于单维。我们可以将其视为只有单列的电子表格。即使有这种限制，它们也有许多应用。数组的支持首次出现在 *bash 第 2 版本*中。原始的 Unix shell（*sh*）完全不支持数组。

## 创建数组

数组变量的命名方式与其他 bash 变量相同，并在被访问时自动创建。以下是一个示例：

```
me@linuxux ~$ j a[1]=foo

me@linuxux ~$ j echo ${a[1]}
```

我们看到了数组元素赋值和访问的示例。在第一个命令中，数组的元素 1 被赋值为值 `foo`。第二个命令显示了元素 1 的存储值。在第二个命令中使用大括号是为了防止 shell 对数组元素的名称尝试路径名扩展。

也可以使用 `declare` 命令创建数组。

```
me@linuxux ~$ declare -a a
```

使用 `-a` 选项，这个 `declare` 示例创建了数组。

## 为数组分配值

值可以通过两种方式之一进行赋值。简单值可以使用以下语法赋值，其中 `name` 是数组名称，`subscript` 是大于或等于 0 的整数（或算术表达式）：

```
name[subscript]=value
```

注意，数组的第一个元素的下标是 0，而不是 1。`value` 是分配给数组元素的字符串或整数。

可以使用以下语法分配多个值，其中 `name` 是数组名称，多个 `value` 占位符按顺序被分配给数组的元素，从元素 0 开始：

```
name=(value1 value2 ...)
```

例如，如果我们想为数组 `days` 分配星期的缩写，可以这样做：

```
me@linuxux ~$ days=(Sun Mon Tue Wed Thu Fri Sat)
```

也可以通过为每个值指定下标来向特定元素赋值。

```
me@linuxux ~$ days[0]=Sun [1]=Mon [2]=Tue [3]=Wed [4]=Thu [5]=Fri [6]=Sat
```

## 访问数组元素

数组有什么用呢？就像许多数据管理任务可以使用电子表格程序完成一样，许多编程任务可以使用数组完成。

让我们考虑一个简单的数据收集和展示示例。我们将构建一个脚本来检查指定目录下文件的修改时间。根据这些数据，我们的脚本将输出一个表格，显示文件在一天中哪个小时最后被修改。这种脚本可以确定系统何时最活跃。这个名为 `hours` 的脚本产生如下：

```
Hour Files | Hour Files
00 0 | 12 11
01 1 | 13 7
02 0 | 14 1
03 0 | 15 7
04 1 | 16 6
05 1 | 17 5
06 6 | 18 4
07 3 | 19 4
08 1 | 20 1
09 14 | 21 0
10 2 | 22 0
11 5 | 23 0
```

文件文件 = 80

我们执行 `hours` 程序，指定当前目录为目标。它产生一个表格，显示每天的每个小时（0-23）有多少文件最后被修改。生成此结果的代码如下：

```bash
#!/bin/bash

# hours: 按修改时间统计文件的脚本

usage() {
  echo "usage: ${0#*/} directory" >&2
}

# 检查参数是否为目录
if [ ! -d "$1" ]; then
  usage
  exit 1
fi

# 初始化数组
hours=

# i 是循环变量
for i in {0..23}; do
  # 收集数据
  hours[$i]=$(find "$1" -maxdepth 1 -type f -newermt "$i" | wc -l)
done

# 显示数据
echo -e "Hour Files\tHour Files"
for i in {0..11}; do
  printf "%02d %d\t%02d %d\n" "$i" "${hours[$i]}" "$((i+12))" "${hours[$((i+12))]}"
done

# 总文件数
count=0
for val in "${hours[@]}"; do
  count=$((count + val))
done

echo "Total files = $count"
```

由于 bash 允许数组在下标赋值中包含“空隙”，有时确定哪些元素实际上存在是有很有用的。这可以通过以下形式的参数扩展来完成，其中 `array` 是数组变量名：

```
${array[*]}
n${array[@]}
```

与其他使用 `*` 和 `&` 的扩展一样，用引号括起来的 `&` 最有用，因为它会被展开为独立的单词。

```
[me@linuxbox ~]$ foo[2]=a[6]=c
[me@linuxbox ~]$ foo for i in "${foo[@]}"; do echo $i;
```

a
b
c

```
[me@linuxbox ~]$ foo for i in "${foo[@]}"; do echo $i;
```

2
4
6

```
[me@linuxbox ~]$ declare -a foo
[me@linuxbox ~]$ read -a foo <<< "0th 1st 2nd 3rd 4th"
[me@linuxbox ~]$ foo for i in "${foo[@]}"; do echo $i;

## 向数组末尾添加元素

如果我们需要向数组末尾追加值，知道数组中的元素个数是没有帮助，因为 `*` 和 `@` 符号返回的值并没有告诉我们数组的最大索引。幸运的是，shell 为我们提供了解决方案。通过使用 `+=` 赋值运算符，我们可以自动将值追加到数组末尾。在这里，我们为数组 `foo` 分配了三个值，然后添加更多：

```
[me@linuxbox ~]$ foo=(a b c)
[me@linuxbox ~]$ echo $i${foo[@]}
```

a b c

```
[me@linuxbox ~]$ foo+=(d e)
[me@linuxbox ~]$ echo $i${foo[@]}
```

a b c d e f

## 将文件读取到数组

最新版本的 bash 包含一个名为 `mapfile` 的新内置命令，它可以直接将标准输入读取到索引数组中。它的语法如下：

```
mapfile -options array
```

`mapfile` 命令具有一些有趣的选项，其中一些在表 35-1 中。

### 表 35-1：mapfile 选项

| 选项 | 说明 |
| --- | --- |
| -d delim | 使用 delim 替代换行符终止行。 |
| -n count | 只读取 count 行。 |
| -O origin | 从索引 origin 开始分配数组元素而不是索引 0。 |
| -s count | 跳过文件开头的行。 |
| -t | 修剪每行末尾的终止符。 |

为了演示 `mapfile` 的用法，我们将创建一个产生随机短语的短脚本。这些作为传统密码非常有用，因为它们很长且容易记忆，只要你知道如何拼写。

```bash
#!/bin/bash

# array-mapfile  mapfile 内 builtin
```

以下脚本使用了 `/usr/share/dict/words` 并过滤掉了撇号和大写写字母。

```bash
DICTIONARY=/usr/share/dict/words
WORDLIST=/wordlist.txt
declare -a words

# 创建过滤后的单词列表
grep -v '\ < "$DICTIONARY"' | grep -v "[[[:upper:]]]" | shuf > "$WORDLIST"

# 将 WORDLIST 读取到数组
mapfile -t -n 32767 words < "$WORDLIST"

# 创建四个单词密码语
while [[ -z $REPLY ]]; do
  echo "${words[$RANDOM]}"
  echo "${words[$RANDOM]}"
  echo "${words[$RANDOM]}"
  read -p "Enter to continue, q to quit > " REPLY
done
```

我们使用 `shuffle` 命令打乱单词列表以获得良好的随机顺序。接下来，我们将前 32,767 个单词加载到文件数组中。为什么是 32,767？因为我们将使用 `RANDOM` 变量从数组中选择随机元素，每引用一次 `RANDOM` 变量，它都会返回一个 0 到 32,767 之间的随机整数。

```

```

在这里我们看到了输出。每次按下回车键，脚本都会显示四个随机单词。

## 切片数组

我们可以使用一种参数扩展来从数组中提取一组连续元素，称为“切片”。这会产生原始数组所需切片的数组元素，如下所示：

```
[me@linuxbox ~]$ arr=$(echo 1st 2nd 3rd 4th)
[me@linuxbox ~]$ echo "${arr[@]:2:3}"
2nd 3rd 4th
```

在这个示例中，我们创建了一个包含五个元素的数组。接下来，我们从索引 2 开始提取数组中的三个元素。通过指定负索引，我们从数组的末尾而不是开始计数。在下一个示例中，我们提取了数组的最后两个元素。注意负号前面需要一个空格。

```
[me@linuxbox ~]$ echo "${arr[@]:-2:2}"
3rd 4th
```

我们也可以轻松创建一个包含切片元素的数组。

```bash
[me@linuxbox ~]$ arr2="${arr[@]:2:3}"
[me@linuxbox ~]$ echo "${arr2[@]}"
2nd 3rd 4th
```

在这里我们创建了数组 `arr2` 并用来自 `arr` 的元素填充了它。

电子表格经常需要对列数据进行排序。shell 没有直接的方法，但通过少量代码就可以实现。

```bash
#!/bin/bash

# array-sort 排序数组
a=(f e d c)
echo "Original array: ${a[@]}"
a_sorted=$(for i in "${a[@]}"; do echo "$i"; done | sort)
echo "Sorted array: ${a_sorted]}"
```

执行时，脚本产生：

```
[me@linuxbox ~]$ array-sort
Original array: f e d c
Sorted array: a c d f
```

脚本通过将原始数组 (a) 的内容复制到第二个数组 (a_sorted) 来工作。这种基本技术可以对数组进行许多操作。

## 删除数组

要删除数组，使用 `unset` 命令：

```
[me@linuxbox ~]$ foo=(a b c d)
[me@linuxbox ~]$ echo "${foo[@]}"
a b c d
[me@linuxbox ~]$ unset foo
[me@linuxbox ~]$ echo "${foo[@]}"
```

`unset` 也可以用于删除单个数组元素：

```bash
[me@linuxbox ~]$ foo=(a b c d f)
[me@linuxbox ~]$ echo "${foo[@]}"
a b c d f
[me@linuxbox ~]$ unset 'foo[2]'
[me@linuxbox ~]$ echo "${foo[@]}"
a b d f
```

在这个示例中，我们删除了数组下标为 2 的元素。记住，数组从零开始！注意数组元素必须加引号以防止 shell 执行路径展开。

有趣的是，给数组赋值空值不会清空它的内容。

```
[me@linuxbox ~]$ foo=(a b c d f)
[me@linuxbox ~]$ foo=
[me@linuxbox ~]$ echo "${foo[@]}"
a b c d f
```

对不带下标的数组引用指向数组的零元素。

```
[me@linuxbox ~]$ foo=(a b c d f)
[me@linuxbox ~]$ echo "${foo[0]}"
a
[me@linuxbox ~]$ foo=
[me@linuxbox ~]$ echo "${foo[0]}"
b c d f
```

### 关联数组

bash 4.0 及更高版本支持关联数组。关联数组使用字符串而不是整数作为下标，类似于字典或哈希表的键值对。这种能力允许管理数据的新方法。例如，我们可以创建一个名为 `colors` 的数组并使用颜色名称作为索引。

```bash
declare -A colors
colors["red"]="#ff0000"
colors["green"]="#00ff00"
colors["blue"]="#0000ff"
```

与通过引用创建的索引数组不同，关联数组必须使用 `declare` 命令的 `-A` 选项显式创建。关联数组元素的访问方式相同。

```
echo ${colors["blue"]}
```

可以使用关联数组的键值对特性执行查找任务。关联数组允许我们直接访问所需数据，而无需使用索引数组顺序搜索。接下来，我们将 `/usr/bin` 目录下所有文件名及其相应的大小读取数组，然后根据用户输入进行查找：

```bash
#!/bin/bash

# array-lookup 使用关联数组演示查找
declare -A cmds
```

```bash
# 填充命令和文件大小
cd /usr/bin || exit 1
echo "Loading commands..."
for i in .*; do
  cmds["$i"]=$(stat -c "%s" "$i")
done
echo "${cmds[@]} commands loaded"

# 执行查找
while true; do
  read -rp "Enter command (empty to quit) -> " REPLY
  [[ -z $REPLY ]] && break
  if [[ -x $REPLY ]]; then
    echo "${cmds[$REPLY]} bytes"
  else
    echo "No such command '$REPLY'."
  fi
done
```

当我们运行程序时，得到如下：

```
[me@linuxbox ~]$ ./array-lookup
Loading commands...
2329 commands loaded
Enter command (empty to quit) -> ls
ls 138216 bytes
Enter command (empty to quit) -> cp
cp 141832 bytes
Enter command (empty to quit) -> mv
mv 137752 bytes
```
