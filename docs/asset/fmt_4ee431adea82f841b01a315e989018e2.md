## 程序注释 (Program Comments)

所以，你会有这样的想法在代码中写一些注释。这些注释很重要，因为它们允许你在代码中留下一条小信息，以便以后阅读的人能够很好地查看代码是如何运行的，并对你试图实现的目标提供“参考”。此外，在代码行中留下笔记是提醒自己代码可能出错的好方法。通过在代码中放置注释，你正在更有可能知道你在哪里成功了，或者哪里出了错。

这些注释可以根据你的意愿变得简单，也可以复杂。如果只需要一两个单词就能帮助其他用户，有些人只会写这么多；但在其他情况下，你可能需要结合更多几行内容，以确保一切正常运行，并让其他人理解代码内部正在发生什么。

在这种语言中，你只需要使用 `//` 符号来表示你正在编写注释。你可以将其写得尽可能长，只需确保在注释结束时跳到下一行，这样程序就知道该重新开始读取了。

程序在遇到 `//` 之后就会停止读取，这不会影响程序的运行方式。其他查看代码的程序员会看到你编写的注释，但当程序执行时，这些注释会被跳过。你可以在程序中添加任意数量的注释，但尽量保持适度，因为过多的注释可能会阻塞代码，使其变得难以阅读和理解。

程序注释基本上是代码内部的语句。这些语句（或注释）的作用是帮助使用你代码的人理解每个函数的作用。所有的编程语言都允许某种类型的注释，但它们并不允许所有种类的注释。最常用的是单行注释，这是所有编程语言都允许的。这些注释是简单的解释性行，用简单的句子告诉下一个读者其目的。

还有多行注释。这是极少数编程语言允许的类型。C++ 就是其中寥寥语言之一。有时你需要一个更复杂的解释，并且需要跨越多行。这在 C++ 中是可以实现的。

当你使用单行注释时，你会看到它在代码中用 `//` 写出，并且可以延伸到行尾。
示例如下：

```
{
  cout << "that's great" >> //prints that's great
  return 0
}
```

最终输出将是 "that's great" 而没有其他任何内容。编译器会忽略注释，这样你可以让其他程序员了解代码的用途，或者你需要对代码进行什么操作。

然而，如果你试图就某些代码寻求帮助，你应该使用多行注释，以便能够轻松地利用你复杂的代码。多行注释被 `/* */` 符号包围。这样打出来看起来像像表情符号。例如

```
/* I need help making the puppet dance*/ 是一个注释。然而，这仍然是一个单行注释。更好的例子是

/* I need help making the puppet dance
*All he does at this point is sway from side to side */
```

这就是多行注释。如你所见，当你开始新行时，应该在开头放置星号，以指示程序你仍在编写注释，并且下一行确实是空白。编译时，它将忽略注释并只显示你想让它显示的内容。

虽然你可以混合使用注释样式，但在掌握一切之前，最好将它们分开。

## 数组

数组是 C++ 中的一种数据结构，能够存储基本类型相同的元素且具有固定大小。基本上它们是同类型变量的集合。与其使用单独变量，你会声明一个这样的变量数组（例如数字）。为了做到这一点，你使用 0 到 99 的数字，并通过数组的索引访问每一个数字。

数组将是连续的内存位置。最低的始终是第一个元素，而最高的将是最后一个元素。

### 数组初始化

你可以逐个初始化数组，也可以使用单条语句。示例：

```cpp
double balance[5]={1000.0, 2.0, 3.4, 17.0, 50.0};
```

括号内找到的数量不能高于你所使用的元素数量。这意味着当你的数组标题只指定了五个元素时，你不能提供六组数字。然而，如果你不指定大小，就会创建一个大小恰合适的数组。你可以按照如下方式输入：

```cpp
double balance [] {1000.0, 2.0, 3.4, 17.0, 50.0};
```

现在你已经知道如何编写数组了，是时候将它放入实际程序中了。这个程序比之前的稍微高级一点，包含更多元素。你可以在 `www.compileonline.com` 上查找这些元素。你会被引导到许多教程，甚至有一个 `PDF` 文件供你下载。

## 循环类型

循环类型用于你想获取某类型代码并反复执行它的任何时候。这些语句将一个接一个执行。循环语句将更容易按照你所需的次数执行这些语句。

有四种类型的循环。这些循环处理不同的需求。

### While 循环

只要满足特定条件，`While` 循环就会继续重复。它会一直测试条件直到条件不再成立。

```cpp
while (condition)

{

    statement;

}
```

### For 循环

此循环执行固定次数。它使用初始化、条件和递增。

```cpp
for (init; condition; increment)

{

    statement;

}
```

### Do-while 循环

`Do...while` 循环与 `while` 类似，但在测试条件之前至少执行一次代码。

```cpp
do

{

    statement;

} while (condition);
```
