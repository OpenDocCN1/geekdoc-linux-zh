
# 风能

风的动能及其转化为能量类型：热能、机械能或电能。世纪以来，风能已应用于各种领域。

据估计大气中的总功率约为 3.6 × 10³³ W，这是一个中等风力涡轮机可利用的数量级。这种能量中只有一小部分被提取出来，每天最多 6000 瓦。根据所谓的贝茨极限（Betz limit），从风中可以提取出 55% 的功率。然而，实际提取 5% 到 45% 的可用功率是非常重要的。因为风能随风速的立方增加，因此找到高风速区域以布置风力涡轮机至关重要。参见 WIND。

大多数研究是关于风发电的。风能是一种再生资源，具有巨大的潜力但也有局限性。风速测量存在环境问题，且只能位于易于到达或靠近高压输电线的地方。这些高风地区通常偏远或难以进入。此外，风能随风速随时间变化而变化，电力生产必须遵循需求。由于风能具有间歇性，它可能不能作为唯一的发电源。电能的储存困难且昂贵，因此必须与其他形式的发电或中性存储结合使用。风能结合热发电是一种可以用于储能的方法，而压缩空气存储是另一种选择。参见 ELECTRIC POWER GENERATION；ELECTRIC STORAGE。[F.S.]

用于发电的最常见风力涡轮机类型是水平轴的，轴上安装有两个或更多叶片。对于水平轴机器，叶片垂直于风旋转，这导致了高效率。叶片形状的设计使用了与相同的空气动力学理论。参见 PROLLER TURBINE。[G.TH.]

由风的方向和速度作用在地球表面的单位面积切向力。气体的侵蚀和对表面的压力分布。风应力决定了地球与大气之间的动量传递，并作用于大气层底部一公里内风向的变化。该力作用于地球表面和相邻的空气层。参见 METEOLOGY。

低大气层内的应力是由地面附近的风与上方一公里移动较大的空气之间的剪切强度引起的。这里的湍流区域被认为具有延伸几百米的不同特征。

风作用于单位面积的且与风向也垂直的力被称为动力力（dynamic）。为了产生应力，风在迎风面和背风面之间产生压力差，当风速很高时，这代表了巨大的力。参见 WIND。

以每平方厘米因或每平方米厘米为单位不适合代表跨越几公里的未区域的平均阻，因此最好表示随时间的平均风速和海面附近的平均风（例如，在海平面以上 10 米处）。

阻力系数也是水平和垂直环流中的重要量，因为它与风速有关，风速产生波浪、洋流以及为云和风暴提供能量的大气湍流。表面阻力系数取决于风场以及空气边界层中的湍流结构。涉及的机制不足以对其进行计算。参见 ATMOSPHERIC GENERAL CIRCULATION；MARITIME METEOROLOGY；OCEAN CIRCULATION；OCEAN WAVES.

# 机翼

机翼面积的物理特性包括：在平面或视图中测量的从左翼到右翼的跨度、展弦比、锥度比以及翼型的厚度比。展弦比是跨度与弦长的比值。弦长是从前缘到后缘的距离。在最简单的情况下，弦长沿跨度变化，在根部最大。锥度比是弦长与根部弦长的比值。翼型是相对于迎来气流定义并垂直于机翼表面的平面截面形状。厚度比是翼型最大厚度与弦长的比值，并随上表面和下表面曲率的不同而变化，上下表面之间的中线是弯曲的。这种曲率是由机翼特性引起的，它会影响效率，必须仔细选择。参见 飞机设计（AIRCRAFT DESIGN）；翼型（AERFOIL）。

存在一个特定的迎角，可以用最小的阻力产生升力。机翼的选择旨在任何任何所需的迎角和高度范围内最大化升力。当然，起降场面积在区域选择中至关重要。较大的面积允许更平稳的飞行，配合更短的起降距离是理想的。

机翼的设计必须能够防止失速。气流保持附着直到机翼分离导致升力突然丧失和阻力剧增的迎角被称为失速，这通常是需要避免的情况。机翼的设计是为了推迟失速并尽可能减少对机翼外缘可能的影响。这是通过仔细地改变翼型截面和跨度来实现的。

飞行控制通过改变升力的幅和方向，以及改变发动机提供的推力或功率来控制。飞行的一个重要方面是控制相对于迎来气流的迎角。这通过改变升舵（通常位于水平轴上的控制面）的角度来调整。高度通过将升舵设置为零位来调整，这通过设定发动机来控制。参见 升舵（ELEVATOR）。

飞行方向通过倾角控制。当翼水平且合力向左或向右时，副翼必须直线飞行。副翼是机翼外部分的后缘襟，向相反方向偏转。当副翼由于偏转而倾斜或滚转时，副翼会将升力推向偏转的一侧。这导致飞机绕其纵轴滚转和偏航。使用方向舵可以转动飞机，方向舵将使飞机转向所需的航向，这项工作是在没有副作用的情况下完成的。参见 方向舵（RUD）。

高速飞机使用扰流板（特别是代替襟翼），仅在单侧释放升力以使飞机滚转。扰流板用于减少升力并增加阻力率。扰流板还用于快速减少升并将重量压在刹车轮上，从而大大提高有效性。

# 野香蕉

一种植物（Musa textostperma），也称为野生香蕉、亚洲梨、山羊蕉，属于香蕉科。这是一种叶状水果，通常像苹果一样食用。有人认为起源于非洲或东南亚，但有更多证据源于非洲。然而，在新几内亚高地的植物将水果引入了西方。

大约1890年至1900年间，香蕉被引入热带地区。

这种植物的许多部分可食用，是蛋白质的丰富来源。种子、荚和叶可以用于沙拉。种子和蔬菜还用于提取油。这种油用于许多东南亚食物的烹饪，如豆腐、肉和面粉。香蕉果可以作为食品产品或用于育种市场。

许多昆虫和害虫通过锈菌或或瘤菌（由Sphaeromyces perforora引起）对果实造成破坏。

> (T.N.R.)

植物的纤维通常用于横截和时尚。它的直径或质量足够坚固。杆由几条细小的扭曲或缠绕纤维制成，但如果用于结构或在结构中，可以用于拉力（如悬索桥），或作为框架的延伸。金属丝大大增加了其抗拉强度。因此，小直径金属丝组成的电缆比单个更强且更灵活。

> [F.H.R.]

# 沃尔夫-瑞埃星

一种高温高亮度恒星，以其强烈且快速的风风为特征。这些恒星发出的极其明亮且离散的原子发射带，由于法国天文学家沃尔夫（Wolf）和乔治·瑞埃（Georges Rayet）于1867年在巴黎天文台通过视觉光谱法发现而得到了极大促进。天文学。

沃尔夫-瑞埃现象是大质量恒星（质量约为太阳的20-100倍）在行星质量阶段中高级演化中的一个典型阶段。大质量恒星核心的首次聚变过程涉及氦转化为碳-氮-氧（CNO）循环，在此过程中，以消耗初始氢、碳和氧为代价产生碳和氮。

当这种恒风变得强大时，沃尔夫-瑞埃星将暴露其内部，其光谱由各种电离阶段的氦和氮的多普勒增宽线主。随后，当发生第二次聚变反应时，氦转化为碳和氧，此时存在氦、碳和氧。可能会出现富碳的沃尔夫-瑞埃星（WC），之后，所有其他阶段都非常快，以至于恒星暴露。此时，人们认为沃尔夫-瑞埃星将爆炸，导致大多数情况下坍缩为黑洞。参见黑洞；多普勒效应；核合成；行星星云；超新星。

[A.F.M.]

在隐藏表面的风之下，大质量的沃尔夫-瑞埃星的表面强度从10,000到500,000埃耳（10到50太阳单位），亮度为太阳的$10^5$到$10^6$倍。它们的质量损失速度通常是太阳风的$10^4$倍，范围从3000到30000 g/s。它们的寿命如此短而非常罕见（银河系中仅有200到500年，估计总数为1000-20000个），所有大质量恒星可能在其相对较短的寿命末期经历沃尔夫-瑞埃阶段。

见风；恒星演化。

[E.C.T.C.]

# 钨矿

钨矿是一种矿物成分 (Fe,Mn)WO4，是钨和钨矿之间的中间体。

钨矿在变质岩和热液脉中呈短带状出现，是钨矿物最重要的来源。钨矿的主要产地位于美国西部地区；主要产地在加利福尼亚、德国北部和科罗拉州。见胡贝尔（HUBERN）。

[E.C.T.C.]

# 沃尔aston石

沃尔aston石是一种含有 CaCO3 的矿物成分。它是常见的，或者呈解理状的坚韧聚集体。

莫氏硬度上的硬度；比重为2.8–3.5。在解理面上光泽为珍珠光或无色；颜色为白色至浅灰色。

沃尔aston石在大块中出现在德国黑森林；法国布列塔尼；墨西哥奇瓦华州；以及纽约州威尔伯，在那里它作为陶瓷材料被发现。见硅（SILIC）。

[E.C.A.H.]

# 极鼬
