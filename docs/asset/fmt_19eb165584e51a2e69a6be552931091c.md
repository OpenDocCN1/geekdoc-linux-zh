# tar — 创建卷归并添加或提取文件

### 概要

```
/usr/bin/tar[bBeEfFhklinqFqwX[0-7]][block][tarfile] [exclude-file]...
  -I include-file -C directory file | file] ...
/usr/bin/tar r [bBeEfFhklinqnw [0-7]][block]
  -I include-file -C directory file | file] ...
/usr/bin/tar t [BefFhklinqnw [0-7]][tarfile] [exclude-file]
  -I include-file -tarfile
/usr/bin/tar u [bBeEfFhklinqqX[0-7]][block][tarfile] file...
tar x [BefFhklinmnopqwX[0-7]][tarfile] [exclude-file:...]
```

## Description

使用 `tar` 命令将文件和目录子树拷贝到单个卷带中。`tar` 命令的优点是它在大多数 UNIX 操作系统上可用，并且在公共领域很容易获得。`tar` 命令的缺点是 `tar` 不感知文件系统边界，全路径长度不能超过 255 个字符，它不拷贝空目录或特殊文件（如设备文件），并且不能用于创建多个卷带卷。

`tar` 命令在名为 `tarfile` 的单个文件中对文件进行归档和解压。`tarfile` 通常是一个磁带，但也可以是任何文件。你通过 `key` 参数控制 `tar`，该参数是一个包含恰好一个函数的字符字符串——`-c`（创建）、`r`（替换）、`t`（列表）、`u`（更新）或 `x`（提取）——以及零或多个函数修饰符（字母或数字）。`key` 字符串不包含特殊字符。函数修饰符参数在命令行中的列出顺序与其相应的函数修饰符在 `key` 字符串中出现的顺序相同。

`-I include-file`、`-C directory` 和 `file` 参数指定要归档或提取的文件或目录。在所有情况下，目录名称的出现指的是该目录的文件和（递归）子目录。大括号 `{}` 内出现的参数表示你必须指定这些参数之一。

## Notes

你无法访问文件的第 `n` 次出现。

卷带错误的处理方式并不优雅。
