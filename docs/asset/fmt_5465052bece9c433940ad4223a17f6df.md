
# 第 5 章

## 符号链接与文件操作

`ln`: 在`file1`和`file2`之间创建链接

`ln -s`: 在两个文件之间创建符号链接

### 示例：

```
user> ln -s dir1/file1.txt dir2/file2.txt
```

`ln -s`: 在`file1`和`file2`之间创建符号链接

`-s`: 符号链接允许给定文件同时出现在多个位置或多个名称下。例如，符号链接可以链接到目录。

`readlink`: 显示符号链接的目标

### 示例：

```
user> readlink dir2/file2.txt
```

输出: `dir1/file1.txt`

`lpr`: 将文件发送到打印机

### 示例：

```
user> lpr myfile.txt
```

已将`myfile.txt`发送到打印机。

`lpq`: 显示打印队列。

### 示例：

```
user> lpq
```

显示当前打印队列状态。

## 总结

`su`: 将普通用户切换为`root`超级用户

`loginname`: 显示登录名

`exit`: 退出`shell`

`whoami`: 显示当前用户名

`hostname`: 显示当前主机名

`sudo`: 允许具有适当权限的用户以另一个用户（如超级用户）的身份执行命令

# 第 6 章

## 查看文件命令

`cat`: 查看文件内容

`less`: 分页查看文件

`tail`: 查看文件末尾

`head`: 查看文件开头

### 示例：

```
user> cat myfile.txt
```

`cat`: 显示`myfile.txt`内容。

### 示例：

```
user> less myfile.txt
```

`less`: 分页查看`myfile.txt`。

### 示例：

```
user> tail myfile.txt
```

`tail`: 查看`myfile.txt`的最后`10`行。

### 示例：

```
user> head myfile.txt
```

`head`: 查看`myfile.txt`的前`10`行。

`cp`: 复制文件

`mv`: 移动文件

`mv`: 重命名文件

`rm`: 删除文件

`rm -ri`: 删除非空目录

`vi`: 打开编辑器并编辑文件

`find`: 查找文件

`wc`: 显示文件的字数

`file`: 估算文件类型

`ln`: 在文件之间创建链接

`ln -s`: 为文件创建符号链接

`readlink`: 显示符号链接的目标

`lpr`: 将文件发送到打印机

`lpq`: 显示打印队列。

### 示例：

```
root> vi myfile.txt
```

`vi`: 使用`vi`编辑打开`myfile.txt`

`tr`: 转换文件文本

### 示例：

```
root> echo apple | tr "apple" "banana"
```

输出: `banana`

## `tee`: 将标准输出写入文件

### 示例：

```
Root> sort file1.txt | tee file2.txt
```

排序`file1.txt`并写入`file2.txt`

## 总结

- `cat`: 显示文件内容
- `cat | less`: 分页显示文件内容
- `cat | more`: 逐屏显示文件内容
- `head`: 显示文件的头部内容
- `tail`: 显示文件的尾内容
- `aspell`: 对文件进行拼写检查
- `cut`: 显示文本文件的指定列
- `paste`: 合并两个文件的内容并显示
- `sort`: 按字母顺序显示文本行
- `stat`: 显示文件或目录的属性
- `wc`: 显示文件的单词数
- `file`: 测试文件类型
- `touch`: 创建文件或更改文件时间戳
- `l`: 显示文件每行的行号
- `vi`: 使用`vi`编辑器或创建文本文件
- `tr`: 转换文件文本
- `tee`: 将标准输出写入文件

# 第 7 章

## 比较文件命令

`diff`: 显示两个文件之间的差异

`cmp`: 按字节比较两个文件

`comm`: 按行比较两个文件

`md5sum`: 创建`md5`校验和数字

`cksum`: 创建`crc`校验码

### `diff`: 显示两个文件之间的差异

#### 示例：

```
user> diff myfile1.txt myfile2.txt
```

`diff`: 显示两个文件之间的差异。

### `cmp`: 按字节比较两个文件

#### 示例：

```
user> cmp myfile1.txt myfile2.txt
```

`cmp`: 按字节比较两个文件。

### `comm`: 按行比较两个文件

#### 示例：

```
user> comm myfile1.txt myfile2.txt
```

`comm`: 按行比较两个文件。

### `md5sum`: 创建 md5 校验和数字

#### 示例：

```
user> md5sum myfile1.txt
```

输出: `f7tkgu5orj1jf8kelc2os95nd57jf8r myfile1.txt`

### `cksum`: 创建 crc 校验码

#### 示例：

```
user> chsum myfile2.txt
```

输出: `4658791048 19 myfile2.txt`

## 总结

- `diff`: 显示两个文件之间的差异
- `cmp`: 按字节比较两个文件
- `comm`: 按行比较两个文件
- `md5sum`: 创建`md5`校验和数字
- `cksum`: 创建`crc`校验码

# 第 8 章

## 文本匹配命令

`grep`: 显示所有包含指定字符串的行

`egrep`: 显示所有包含指定字符串的行

`uniq`: 显示文件中唯一的行

`find`: 在指定目录中查找文件

`look`: 显示匹配给定前缀的单词

### `grep`: 显示所有包含指定字符串的行

#### 示例：

```
user> grep good myfile.txt
```

`grep`: 显示所有包含“`good`”字符串的行。

### `egrep`: 显示所有包含指定字符串的行

#### 示例：

```
user> egrep excellent myfile.txt
```

`egrep`: 显示所有包含“`excellent`”字符串的行。

### `uniq`: 显示文件中唯一的行

#### 示例：

```
user> uniq myfile.txt
```

`uniq`: 显示`myfile.txt`中唯一的行。

### `find`: 在指定目录中查找文件

#### 示例：

```
user> find /mydir --type f myfile.txt -print
```

`find`: 在目录中查找文件。
`-type f`: 指定文件
`-print`: 打印

### `look`: 显示匹配给定前缀的单词

#### 示例：

```
User> look ab
```

输出: `aba, abb, abc, abd...`

## 总结

- `grep`: 显示所有包含指定字符串的行
- `egrep`: 显示所有包含指定字符串的行
- `uniq`: 显示文件中唯一的行
- `find`: 在指定目录中查找文件
- `look`: 显示匹配给定前缀的单词
