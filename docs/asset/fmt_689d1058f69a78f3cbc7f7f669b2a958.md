```
numericExpression1-numericExpression2
```

你可以将减号与其他数值运算符结合使用执行复杂的数学计算。你可以在同一个表达式中进行加、减、乘、除运算，但必须注意优先级。优先级控制计算的顺序。例如，ActionScript 在执行加减法之前会执行乘除法。关于优先级的解释，请参见第 110 页。
