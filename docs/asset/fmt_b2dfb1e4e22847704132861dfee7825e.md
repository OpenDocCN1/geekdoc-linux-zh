
作为替代方案，可以使用数字代码。代码的四个数字是由 4、2 和 1 的和组成的——二进制掩码的十进制结果。第一个数字设置用户 ID (`SUID`) (`4`)、设置组 ID (`2`) 和粘滞位 (`1`)。第二个数字定义文件所有者的权限。第三个数字定义组成员的权限，最后一个数字设置所有其他用户的权限。读取权限设置为 `4`，写入权限设置为 `2`，执行文件的权限设置为 `1`。文件的所有者通常会得到 `7` —— 所有权限之和。

`gzip [parameters] file(s)`

该程序使用复杂的算法压缩文件内容。以这种方式压缩的文件赋予 `.gz` 扩展名，并在使用前需要解压缩。要压缩多个文件甚至整个目录，请使用 `tar` 命令。

- `-d` 解压缩打包的 `gzip` 文件使其恢复原始大小并可以正常处理（类似于 `gunzip` 命令）

`tar` 选项归档文件(s) `tar` 命令将一个或多个文件放入归档中。压缩是可选的。`tar` 是一个非常复杂的命令，提供了许多选项。最常用的选项有：

- `-f` 将输出写入文件，而不是像通常那样输出到屏幕上
- `-c` 创建一个新的 `tar` 归档
- `-r` 向现有归档添加文件
- `-t` 输出归档的内容
- `-u` 添加文件，但仅当这些文件比归档中已包含的文件更新时才添加
- `-x` 从归档中解包文件（提取）
- `-z` 使用 `gzip` 对生成的归档进行压缩
- `-v` 列出已处理的文件

`tar` 创建的归档文件以 `.tar` 结尾。如果 `tar` 归档也使用了 `gzip` 压缩，结尾为 `.tgz` 或 `.tar.gz`。如果使用 `bzip2` 压缩，结尾为 `.tar.bz2`。可以在第 385 页的第 25.1.8 节找到应用示例。

`locate` 查找模式(s) `locate` 命令可以找到指定文件所在的目录。如果需要，可以使用通配符指定文件名。该程序运行非常快，因为它使用专门为此目的创建的数据库（而不是遍历整个文件系统）。然而，这一事实导致了一个主要的缺点：`locate` 无法找到在上次更新后创建的任何文件。可以通过 root 使用 `updateddb` 生成数据库。

`updateddb [options]` 此命令使用 `locate` 更新数据库。要包含所有现有目录中的文件，请以 root 身份运行该程序。在命令末尾添加符号 `&` 将其放在后台运行也是有意义的，这样你就可以立即在同一命令行上继续工作 (`updateddb &`)。

`find [options]` 使用 `find` 在给定目录中搜索文件。第一个参数指定开始搜索的目录。选项 `-name` 后面必须跟一个搜索字符串，该字符串也可以包含通配符。与使用数据库的 `locate` 不同，`find` 会扫描实际目录。

# 访问文件内容的命令

`cat [option(s)] file(s)` `cat` 命令显示文件内容，将条目打印到屏幕上且不中断。

- `-n` 在左侧边距对输出进行编号

`less [option(s)] file(s)` 此命令可用于浏览指定文件的内容。使用 `(PgUp)` 和 `(PgDn)` 向上向下滚动半页，或使用 `(Space)` 向滚动一页。使用 `(Home)` 和 `(End)` 跳到文件的开头或结尾。按 `Q` 退出程序。

`grep [option(s)] search filename` `grep` 命令在指定文件中查找特定的搜索字符串。如果找到了搜索字符串，该命令将显示该搜索字符串所在的行以及文件名。

- `-i` 忽略大小写
- `-l` 仅显示相应的文件，但不显示文本行
- `-n` 此外显示找到匹配的行号
- `-L` 仅出未出现搜索字符串的文件

`diff [option(s)] file1file2` `diff` 命令比较任意两个文件的内容。程序产生的输出列出了所有不匹配的行。这经常被程序员使用，他们只需要发送程序的更改，而不是整个源代码。

- `-q` 仅报告两个文件是否存在差异

# 文件系统

`mount [option(s)] [device] mountpoint` 此命令可将任何数据媒体（如硬盘、CD-ROM 驱动器和其他驱动器）挂载到 Linux 文件系统的目录上。

- `-r` 挂载为只读
- `-t filesystem` 指定文件系统。最常见的用于 Linux 硬盘的 `ext2`，Windows 文件系统的 `msdos`, `vfat` 以及用于 CD 的 `iso9660`。

对于 `/etc/fstab` 文件未定义的硬盘，还必须指定设备类型。在这种情况下，只有 root 可以挂载它。如果文件系统也应由其他用户挂载，则需要特殊处理。`umount [option(s)] mountpoint` 此命令从文件系统卸载挂载的介质。为了防止数据丢失，应始终使用此程序关闭系统。

# 系统信息

`df [option(s)] [directory]` `df` 命令显示文件系统磁盘空间。在不带任何选项的情况下，它显示目录的磁盘空间。

- `-H` 以人类可读格式显示，在指定目录时，显示显示的的。
- `-t` 类型 指定文件系统

`du [option(s)] [path]` `du` 命令显示路径及其子目录占用的磁盘空间。

- `-a` 显示单个文件
- `-h` 以人类可读的形式显示
- `-s` 仅显示总和

`free [options]` `free` 命令显示内存和交换空间的使用情况。

- `-b` 以字节为单位
- `-k` 以字节为单位
- `-m` 以兆字节为单位

`date [option(s)]` `date` 命令显示当前系统时间。以 root 运行时，它可以更改时间。

# 进程

`top [options(s)]` `top` 提供当前运行进程的快速概述。按 `H` 访问页面。

`ps [option(s)] [process ID]` `ps` 在不带任何选项的情况下，显示进程的详细列表。

`kill [option(s)] process ID` `kill` 命令通过进程 ID 终止程序。在大多数情况下，可以使用以下参数来停止程序：

- `-9` 使用 `KILL` 信号而不是 `TERM` 信号

`killall [options] processname` 此命令与 `kill` 类似，但使用进程名（而不是进程 ID）作为参数，杀死所有同名的进程。

# 网络

`ping [option(s)] host|IP address` `ping` 命令是测试 TCP/IP 网络功能标准工具。它向目标主机发送一个小数据包并请求立即回复。如果有效，`ping` 会显示该消息，表明网络链接基本正常。

- `-c number` 指定要发送的数据包总数并在发送后结束。默认不设置迭代。
- `-f` 泛洪 `ping`：尽可能地发送数据包。这是 root 常用的测试网络手段。
- `-i value` 指定两个数据包之间的间隔（秒）。默认：1 秒。

`lookup` 域名系统将域名解析为 IP 地址。使用此工具向信息服务器（DNS 服务器）发送查询。

`telnet [option(s)] host or IP address` `Telnet` 实际上是一种允许你在网络上操作远程主机的协议。`telnet` 也是一个 Linux 程序名，它使用该协议操作远程计算机。

> 注意不要在第三方可以窃听的网络上使用 `telnet`。特别是在互联网上，请使用加密传输方法（如 `ssh`），以避免密码被恶意使用的风险（参见 `ssh` 的手册）。

# 杂项

`passwd [option(s)] username` 用户可以随时使用命令更改自己的密码。管理员 root 可以用来更改系统上任何用户的密码。

`su [option(s)] username` `su` 命令可以在运行的会话中以不同的用户名登录。在不指定用户名的情况下使用时，将提示输入 root 密码。指定用户名和相应的密码以使用相应用户的环境。root 不需要密码，因为 root 有权假设任何用户的身份。

`reboot [option(s)]` 与 `halt` 命令相同，但系统会执行立即重启。

`clear` 此命令清理控制台的可视区域。它没有相关选项。

## 25.4 vi 编辑器

操作 `vi` 编辑器需要一些练习。对于许多人来说，它是首选的编辑器，部分原因因为它适用于任何类 UNIX 类的操作系统，并包含在默认的 Linux 系统中。此外，如果其他方法都无效，`vi` 的简短指令应该让你能够使用 `vi` 编辑各种配置文件和其他类型的文件。

`vi` 提供了三种运行模式。在命令模式下，按键被解释为命令元素。在插入模式下，所有按键都被解释为文本输入。末行模式用于更复杂的命令，这些命令在最后一行中输入。

命令模式下下最重要的命令是：

### 表 25.2：vi 编辑器的简单命令

| 命令 | 说明 |
| :--- | :--- |
| `:` | 切换到末行模式。 |
| `i` | 切换到插入模式（字符出现在当前光标位置）。 |
| `a` | 切换到插入模式（字符出现在当前光标位置之后）。 |
| `A` | 切换到插入模式（字符在行末尾添加）。 |
| `ESC` | 切换到命令模式（覆盖旧文本）。 |
| `r` | 切换到插入模式并覆盖每个字符。 |
| `s` | 切换到插入模式（行的剩余部分被新文本替换）。 |
| `o` | 切换到插入模式（在当前行之后插入一个新行）。 |
