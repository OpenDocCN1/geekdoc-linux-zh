
# 听力保护器

耳塞保护器最常见的用途是保护听力免受过度噪音伤害；因此“听力保护器”是最合适的术语。用于构建听力保护装置的材料方面的进步，使用户的衰减和舒适度都显著提高。使用听力保护器可以预防暂时性（听觉疲劳）和永久性噪音引起的听力损失，实际上还可以增强人在过度噪音环境中听力的能力。参见 HEARING (HUMAN)（人类听力）。 [D.C.Ma]

# 耳机

早期智人由东北部非洲的这些先民演化而来。在接下来的5万年里，他们的活动范围随着全球气候周期的变化而扩张和收缩，有时包括地中海近东地区及北非的部分地区。因此，早期智人及其生物学特征和生活方式，最初相对于晚期古老人类并没有多少优势。参见`尼安德特人`。

早期智人在生物学上与现代人类相同，他们融入其中时很难被区分出来。他们与现代人的主要区别在于其体格倾向于健壮且擅长运动。这些人群通常身材高大，男性平均身高为175–180厘米（5英尺10英寸），女性为160–165厘米（5英尺4英寸）。由于拥有高大的身材和肌肉发达，他们的大脑相对较大，平均约为1500 cm³（90 in³），而近期人类的平均值通常约为1350 cm³（80 in³）。然而，当他们的大脑尺寸相对于估算的体重进行缩放时，他们的大脑与现生人类的大脑大小相对一致。

早期智人是成功的狩猎采集者，占据了旧大陆大部分宜居地区。他们依靠狩猎中小型动物（有选择地猎捕羚羊、鹿、山羊以及偶尔的野马和牛）以及采集野生植物、鱼类和贝类为食。他们作为狩猎采集者的高效性部分归因于其技术。他们开发了复杂的石器技术，制造长刀片，这些刀片成为带有可更换切割边缘和尖端的工具的毛坯。他们还率先将粘土烧制成陶器，并使用多种技术制作随身袋。然而，他们能够有效地以狩猎采集为生，取决于他们对环境的广泛知识。这些知识通过已知的首批复杂符号系统传播，该系统由多种几何标记系统和首批具象艺术组成。他们也是首位普遍佩戴饰物的人类，因此得以改变个人的社会形象，暗示着比先前已知的更复杂的社会角色。虽然这些行为进步与早期智人有关，但其中大多数出现在约5万年前之后，因此与现代人类的扩散有关。参见`化石人类`。 [E.T.]

一类能量换能器，能够接收或转换声波，并非常紧密地重传该声音的特征。其功能由`振膜`实现，并通过磁吸引力、静电吸引力或压电效应（某些晶体物质对电荷的响应而发生的膨胀或收缩）来完成。耳机系统包括带有振膜及磁通、静电或直接电荷布置的驱动元件，加上外壳、一个或多个声学腔体及声孔、声学阻尼和绝缘，以及将驱动器耦合到人耳的某种装置。连接前级放大器与驱动器的电线（这可能已整合到耳机系统中），在现代系统中可作为复杂电路工作，为立体声的两个通道中的每一个，将部分电流馈送至每只耳朵。两个耳机（每个可能包含两个驱动器）的时间延迟和能量比可以适当地调整，使听者产生一种错觉，即声源不在“头内”，而是在空间的三个平面上适当地外部化。下面描述了各种类型的耳机。参见`换能器`。

磁式类型是一种永久磁化的振膜，由交流电激励的电磁铁使其向内和向外移动。动圈耳机实际上是小型动圈扬声器。在某些类型中，由声源供电的小型线圈粘合在膜状振膜上。线圈中的交流电驱动振膜朝向和远离外壳后部的永磁体。在另一种构型中，线圈相对较大，仅在边缘处附着在振膜上。微型磁式耳机的输出端可紧密地放入耳道内的塑料橄榄形塞中。这些小耳机广泛用于小型收音机、大功率助听器、电视评论员、商务转录设备以及许多其他通信场合。参见`助听器`。

如果将振膜的质量减至最小，效率会提高。静电耳机利用一层薄（0.25–1.2微米）的金属化塑料薄膜，辅助单元在其上放置大的恒定静电荷。振膜的运动由施加在两侧穿孔金属网板上的音频信号控制。该组件安装在一个相对较大的腔体中，并通过圆形软垫与头部耦合。此类耳机轻便舒适，具有出色的频率响应和瞬态失真特性。

动圈-静电（或正驱动）耳机的振膜是一片永久极化的氟碳薄膜。因此，消除了需要额外的极化电压源这一静电耳机固有的缺陷。参见`电换能器`。

某些晶体物质在施加交流电压时会膨胀和收缩。在某些压电耳机中，晶体元件在机械上耦合到一个小锥体（直径约2.5厘米）的中心。此类耳机可以轻便且廉价，对于语音通信可能可以接受。参见`压电效应`。

任何对真实声学事件的单声道录音，当通过一只耳朵的耳机回放时，听起来会在“头内”。即使是两个通道向两只耳朵耳机的立体声录音，虽然提供了运动的错觉，但仍然没有被听者外部化定位。如果对左声道信号的一部分进行时间延迟并也施加到右耳机（当然，右声道到左耳机也如此），并且如果在“直接”与“间接”声源（如反射墙）之间的声能密度比之间实现电阻比，则证明了外部化。如果通过频率滤波器将人工头立体声录音的右声道信号馈送到左耳机（左声道馈送到右耳机），模拟在头对录音情况下两个耳机在不同频率下的差异化声学效果，则外部化也会得到改善。已构建了结合这些时间延迟和比例的立体声耳机系统。因此，耳机下的鼓膜呈现由实际房间中的扬声器或其他声源产生的精确声学条件，此类耳机系统极大地推进了声音外部化和声学真实感这一重要的心理声学特征。参见`扬声器`；`麦克风`；`声音重放系统`；`立体声`。 [J.D.H.]

# 地球

太阳系的第三颗行星，也是最大的内行星（或类地行星）。太阳是一颗平均大小、中年的恒星，位于银河系某条旋臂的外缘附近。据目前所知，地球在太阳系中是唯一的拥有生命的行星。太阳系之外是否存在生命尚不可知。参见`星系，宇宙`；`银河系`；`行星`；`太阳系`；`恒星`；`太阳`；`宇宙`。

地球有一个天然卫星，即月球。除此之外，地球在太空中的最近邻居是金星，它距离太阳约108 × 10⁶ km（67 × 10⁶ mi），以及火星，距离太阳约220 × 10⁶ km（141 × 10⁶ mi）。地球距离太阳约150 × 10⁶ km（93 × 10⁶ mi）。参见`火星，水星`[行星]；`月球`；`金星`。

地球绕太阳公转一周需要365天5小时48分46秒；轨道定义了年长。日的长度由地球自转周期决定

其自转轴。一年不是整数的天数这一事实影响了历法的发展。参见`历法`。

地球每天绕其自转轴旋转一次。自转轴与赤道垂直，而赤道与地球绕太阳公转的轨道平面之间成约 23.5° 的倾角。当地球在轨道上运动时，自转北轴，即地理北极，指向北极星（勾陈四）的方向，使其成为北极星或极星。赤道相对于轨道平面倾斜的一个结果是，地球的不同部分在一年中接收到的阳光量不同：这是季节变化的主要原因。参见`赤道`；`极地`；`旋转运动`。

地球是一个扁球体。平均赤道半径为 6378.139 千米（3963.37 英里），极半径为 6356.779 千米（3950.10 英里），两者之差为 21.360 千米（13.27 英里）。地球的质量为 5.976 x 10²⁷ 克（0.2108 x 10²² 盎司），它是固体地球（5.974 x 10²⁷ 克，0.2107 x 10²² 盎司）、海洋（1.4 x 10¹⁹ 克，0.049 x 10¹⁵ 盎司）和大气层（5.1 x 10¹⁸ 克，0.18 x 10¹⁴ 盎司）质量总和。地球的平均密度为 5.518 克/立方厘米，这大约是地表常见岩石密度的两倍，表明地球内部比地表更致密。地震研究证实地球在成分和力学性质上都是分层结构的（参见图示）。参见`大气层`；`密度`；`地球内部`；`海洋学`；`地震学`。

最深层的成分层是地核，它分为固态的内核和液态的外核。内核和外核具有相同的成分，被认为由镍铁合金加上少量轻元素（如硫和硅）组成。在外核熔融金属中流动的电流被认为是地球磁场的起源。在地核之上是地幔，根据从金伯利岩管道中从地幔深处带出的稀有岩石样本的密度以及其他证据，认为地幔由硅酸盐矿物组成，特别是橄榄石和辉石。主要由橄榄石和辉石组成的岩石被称为橄榄岩。参见`橄榄石`；`橄榄岩`；`辉石`；`硅酸盐矿物`。

在地幔之上是地壳，在地壳和地幔之间有一个显著的地震不连续面，称为莫霍洛维奇不连续面，简称莫霍面。地壳分为两种，这两种地壳的密度都比下面的橄榄岩质地幔小，且成分不同。在海洋下方，地壳的成分是玄武岩质的，厚度约为 8 千米（5 英里）。大陆下方的地壳成分是花岗岩质的，平均厚度为 35 千米（21.7 英里），但范围可达 80 千米（49.7 英里），如青藏高原下方。海洋地壳在地质年代上是年轻的，因为它通过板块构造过程不断被创建和破坏。目前尚未发现年龄超过约 180 x 10⁶ 年的海洋地壳。大陆地壳比海洋地壳古老得多。在加拿大发现有 4 x 10⁹ 年历史的大陆岩石，而这些岩石的高度变形表明其有着漫长而多事的历史。参见`地壳`；`花岗岩`；`莫霍面（莫霍洛维奇不连续面）`；`板块构造`。

固体地球表面的高程呈双峰分布。如果将海洋中的水去除，将会明显看出大陆地势较高（平均海拔高于海平面 840 米或 2755 英尺），而海底地势较低（平均海拔低于海平面 3800 米或 12,464 英尺）。这种高程差异源于刚性的岩石圈漂浮在薄弱的软流圈之上，且海洋岩石圈（即由海洋地壳覆盖的岩石圈）的密度大于大陆岩石圈的密度。
