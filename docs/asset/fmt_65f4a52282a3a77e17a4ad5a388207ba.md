
在这里，我们看到该表达式匹配数字的形式，但并不匹配包含非数字字符的数字。这个表达式并不完美，因为它仍然允许区号周围出现不匹配的括号，但它将执行第一阶段的验证。

# 匹配元素零次或多次

与 `?` 元字符一样，`*` 也用于表示可选项目；但与 `?` 不同，它可以出现任意次数，而不仅仅是一次。假设我们想查看一个字符串是否是一个句子；也就是说，它以大写字母开头，包含任意数量的大写和小写字母，并以句号结束。为了匹配这种（粗略的）句子定义，我们可以使用这样的正则表达式：

```regex
([[:upper:]][[:upper:][[:lower:]]* )*\.
```

该表达式由三个项目组成：一个包含 `[:upper:]` 和 `[:lower:]` 字符类以及一个空格的括号表达式，以及用反斜杠转义的句号。第二个元素后面跟着 `*` 元字符，这样句子开头的大写字母以及后续任意数量的字母和空格就可以随其后并保持匹配。

我们看到这个表达式不匹配行 `a b 9`，因为它包含非字母字符；它也不匹配 `abc d`，因为有多个空格分隔了字符 `c` 和 `d`。

# 匹配元素指定的次数

`{ }` 元字符用于指定所需匹配的最小和最大数量。可以通过四种方式指定，如表 19-3 所示。

Table 19-3: 指定匹配次数

| 指定符 | 含义 |
| :--- | :--- |
| {n} | 如果前一个元素恰好出现 n 次，则匹配 |
| {n,m} | 如果前一个元素出现 n 到 m 次之间，则匹配 |
| {n,} | 如果前一个元素出现 n 次或更多，则匹配 |
| {,m} | 如果前一个元素出现 0 次到 m 次，则匹配 |

# 量词 Quantifiers

扩展正则表达式支持多种方式来指定元素匹配的次数，如接下来的章节所示。

## ? 匹配元素零次或一次

这个量词实际上意味着“使该元素成为可选的”。假设我们想要检查电话号码的有效性，并认为如果号码符合以下两种形式之一（`n` 是数字）则，它是有效的：

- `(nnn) nnn-nnnnn`
- `nnn nnn-nnnnn`

我们可以构建这样一个正则表达式：

```regex
^([0-9]-[0-9])? [0-9]-[0-9]-[0-9]-[0-9]-[0-9]-[0-9]$
```

在这些指示中，我们在括号字符后面跟着问号，表示它们将被匹配零次或一次。同样，由于括号在 ERE 中通常是元字符，我们在它们前面加上反斜杠，以使它们被视为字面量。让我们试一下。

```bash
[me@linuxbox] $ echo "555 123-4567" | grep -E '^\([0-9]-[0-9])\)? [0-9]-[0-9]-[0-9]-[0-9]-[0-9]-[0-9]$'
555 123-4567
[me@linuxbox] $ echo "555 123-4567" | grep -E '^\([0-9]-[0-9])\)? [0-9]-[0-9]-[0-9]-[0-9]-[0-9]-[0-9]$'
555 123-4567
[me@linuxbox] $ echo "AAA 123-4567" | grep -E '^\([0-9]-[0-9])\)? [0-9]-[0-9]-[0-9]-[0-9]-[0-9]-[0-9]$'
~
```

在这里，我们看到该表达式匹配数字的形式，但并不匹配包含非数字字符的数字。这个表达式并不完美，因为它仍然允许区号周围出现不匹配的括号，但它将执行第一阶段的验证。

## 交替 Alternation

这是一个非常直观的示例，我们将输出通过给 `grep` 并查看结果。当发生匹配时，我们看到打印出来的结果；当没有匹配项时，我们看不到任何结果。

```bash
[me@linuxbox ~]$ echo "AAA" | grep AAA
AAA
[me@linuxbox ~]$ echo "BBB" | grep AAA
[me@linuxbox ~]$
```

现在我们将添加交替，它由竖线 `|` 元字符表示。

```bash
[me@linuxbox ~]$ echo "AAA" | grep -E 'AAA|BBB'
AAA
[me@linuxbox ~]$ echo "BBB" | grep -E 'AAA|BBB'
BBB
[me@linuxbox ~]$ echo "CCC" | grep -E 'AAA|BBB'
[me@linuxbox ~]$
```

在这里，我们使用了正则表达式 `'AAA|BBB'`，它的意思是“匹配字符串 AAA 或字符串 BBB”。注意，这是一个扩展功能，我们为 `grep` 添加了 `-E` 选项，并且我们将正则表达式括在引号中，以防止 `shell` 将竖线元字符解释为管道操作符。交替不限于两个选择。

```bash
[me@linuxbox ~]$ echo "AAA" | grep -E 'AAA|BBB|CCC'
```

要将交替与正则表达式的其他元素结合，我们使用 `()` 来分隔交替。

```bash
[me@linuxbox ~]$ grep -Eh '^(bz|gz|zip)*' dirlist*.txt
```

该表达式将匹配我们列表中以 `bz`、`gz` 或 `zip` 开头的文件。如果我们省略了括号，这个正则表达式的含义将变为匹配任何以 `bz` 开头、或包含 `gz` 或包含 `zip` 的文件名：

```bash
[me@linuxbox ~]$ grep -Eh '^bz|gz|zip\*' dirlist*.txt
```
