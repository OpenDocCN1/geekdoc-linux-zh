# uustat — uucp 状态查询与作业控制

### 概要


## 描述

`uustat` 在以下三个领域运行：

- 显示或取消之前指定的 `uucp` 命令的具体状态。
- 提供远程系统性能信息，例如平均传输率或平均队列时间。
- 提供指向其他系统的 `uucp` 连接的常规状态、远程系统特定状态和用户特定状态。

> 注意 — 在用户发出 `uucp` 请求后，如果传输的文件被移动、删除或在发出 `uucp` 请求时未复制到池化目录 `-C` 选项，`uustat` 将报告文件大小为 `-99999`。由于找不到要传输的文件，该作业最终失败。

`uuto`, `uupick` — 公共UNIX到UNIX 系统文件复制

### 概要

```
/usr/bin/uuto [-mp] source-file...destination

/usr/bin/uupick [-system]
```

## 描述

`uuto`
`uuto` 将 `source-file` 发送到 `destination`。`uuto` 使用 `uucp(1)` 发送文件；允许本地系统控制文件访问。`source-file` 名称是系统上的路径。目标格式为：
`system[!system] ... !user`

其中 `system` 取自 `uucp` 已知的系统列表。`user` 是指定系统上的某人。
指定的文件被发送到系统上的 `PUBDIR`，其中 `PUBDIR` 是 `uucp` 源定义的公共目录。默认情况下，该目录是 `/var/spool/upublic`。具体来说，文件被发送到 `PUBDIR/receive/user/mysystem/files`。

接收者通过 `mail(1)` 通知文件的到达。

> 注意 — 发以点的文件，例如 `.profile`，必须包含点。例如，以下文件名是正确的：

```
.profile.prof* .profile?
```

以下文件名是错误的：

```
*prof* ?profile
```

# uupick

`uupick` 接受或拒绝传输给用户的文件。具体来说，`uupick` 在 `PUBDIR` 中搜索目标为用户的文件。发现的每个条目，文件或目录，在标准输出上打印以下消息：

```
from system sysname: [file file-name][dir dirname] ?
```
