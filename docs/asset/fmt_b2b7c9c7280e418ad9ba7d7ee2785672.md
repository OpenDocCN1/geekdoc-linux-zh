
你可能会注意到，当 `VIZ` 自动保存场景时，系统停顿的时间比通常要长。这是因为辐射解决方案会大幅增加 `.max` 文件的大小。例如，你在本章开始打开的 `Savoye11.max` 文件大约只有 `700KB`。如果你现在保存该文件，你会发现它的大小超过了 `180MB`。`VIZ` 的自动备份（`Auto Backup`）功能在每个备份周期中必须保存这么多数据。

你可能已经注意到，在更改细化迭代和过滤选项后，你不需要重置场景的辐射解决方案。这是因为这些更改不会影响场景中的光能。

## 控制单个对象的辐射网格大小

当你之前的练习中包含辐射网格选项时，`VIZ` 是全局范围内应用网格大小的——即应用于所有选用于辐射解决方案的对象。如果需要，你可以为单个对象设置网格大小。要执行此操作，请遵循以下步骤：

1. 选择你想要设置的对象。
2. 右键点击对象；然后从四角菜单的变换组中选择属性（`Properties`）。
3. 在对象属性对话框中，选择高级光照（`Adv. Lighting`）选项卡。
4. 在对象细分属性组中，关闭全局细分设置（`Global Subdivision Settings`）选项。你会看到细分（`Subdivision`）、自适应细分（`Adaptive Subdivision`）选项以及网格设置（`Mesh Settings`）组中的所有选项从灰色变为黑色，表示它们可用。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_556_0.png)

5. 将最小和最大网格尺寸（`Min and Max Meshing Size`）选项设置为你想要的值，并确保勾选细分（`Subdivision`）选项。
6. 点击确定保存设置并关闭对象属性对话框。

然后你可以重置辐射解决方案并开始一个新的。选中的对象将细分为步骤 5 中指定的尺寸单元格，而所有其他对象将使用全局设置。

## 使用细分修改器

另一种控制单个对象辐射网格大小的方法是应用细分（`Subdivide`）修改器。与“对象属性”对话框相比，这种方法的优点之一是在计算辐射解决方案之前，你可以在视口中看到视觉反馈。这种增加的视觉反馈至关重要，因为你不想花费时间计算解决方案，结果却发现网格大小不是你预期的。要尝试这种方法，请采取以下步骤：

1. 选择你想要细分的对象。
2. 应用细分（`Subdivide`）修改器。你会在命令面板的修改（`Modify`）选项卡上看到它的参数卷。
3. 右键点击视口名称打开快捷菜单，并切换到线框（`Wireframe`）或显示边界（`Edged Faces`）显示模式。
4. 调整细分修改器的尺寸（`Size`）参数，以交互式细分选中的对象。

| 参数 | 说明 |
|---|---|
| 尺寸: `1.0` | |
| 更新 (`Update`) | |
| 自动 (`Automatic`) | |
| 渲染 (`Render`) | |
| 手动 (`Manual`) | |
| 现在显示细分 (`Update Now Display Subdivision`) | |

尺寸越小，辐射网格越复杂。曲率较大的区域也会获得更多的细分。细分修改器的算法根据你设置的最大尺寸参数自动定义对象是否会添加辐射网格，如图 11.10 中的茶壶所示。

## 创建完成的渲染

到目前为止，你一直在处理完善图像和进行调整的过程，直到你对空间有了相当相当好的表示。在很多情况下，你可能会发现通过你目前所学到的过程获得的结果已经足够好了。但如果你真的想获得最好的渲染效果，可以再采取几个步骤，从而大幅改进你的最终渲染输出。

你在第 7 章中接触了快速渲染（`Quick Render`）工具。在本节中，你将更深入地了解通过“渲染场景”框控制输出的一些方法。尝试以下练习以良好了解：

1. 确保你的相机处于激活状态；然后点击工具栏上的渲染场景（`Render Scene`）按钮。显示场景对话框，如图 11.11 所示。

## 创建最终渲染图

* **选项组（`Options Group`）**：此组提供了对特殊效果和渲染工具的控制。其中某些选项与用于视频的动画文件有关，而其他一些则控制渲染器的通用效果。
* **高级光照组（`Advanced Lighting Group`）**：在选项组下方，你会看到高级光照组，它可以让你一键开启或关闭辐射光（`radiance`）。
