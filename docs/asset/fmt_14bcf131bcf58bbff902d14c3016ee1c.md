### wpp

### wrap around
vi. （也写作 'wraparound' 缩写 'wrap around' 1[techspec]）1. 计数器的动作，在达到最大值后从零或“最小无穷大”（infinity）重新开始并继续增加，这是因为程序设计是如此运行的，或者是由于溢出（例如汽车里程表从 0 重新开始）。2. 通过维持稳定的唤醒周期，逐渐且持续地改变远于 24 小时的时长（28 小时），例如每周生活六天（或者，同样地，以 10 微赫兹的速度睡眠）。这也被称为相位环（phase-wrapping）。来自 argon 字典 http://www.tldp.org/LDP/Linux–Dictionary/html/index.html

### write-only code
n. 一种类似“只读内存”的代码。代码极其晦涩、复杂或结构不良，以至于除了作者以外的任何人无法修改甚至无法理解，甚至作者本人也无法。这是一件坏事。来自 argon 字典 http://www.tldp.org/LDP/Linux–Dictionary/html/index.html

### write-only language
n. 一种语法（或语义上）变得密集且怪异的语言，导致任何相当规模的推理自动变成只写代码。这是一种偶尔应用于 APL、INTERCAL 和 TERCO 的别号。

### write-only memory
n. “只读内存”的反义词。在计算中，只写内存是一种可以写入但不可读取的内存。这通常用于安全。在某些情况下，只写内存用于存储用户不应访问的信息。例如，只写内存可存储密码。在任何情况下，只写内存都是保护敏感信息的工具。来自 argon 字典 http://www.tldp.org/LDP/Linux–Dictionary/html/index.html
