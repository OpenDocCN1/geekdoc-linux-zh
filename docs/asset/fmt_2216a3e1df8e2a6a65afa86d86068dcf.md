
# Concurrent Computer 的 RedLinux
Concurrent Computer 的 RedLinux 不是一个微发行版，而是某种程度上功能齐全的实时发行版。它是一个行业标准的、符合 POSIX 的实时 Linux 版本，基于 Red Hat Linux。RedLinux 具有高 I/O 吞吐量、对外部事件快速响应以及优化的进程通信。1.3 版本于 2003 年 5 月 22 日发布。一种特殊用途发行版。源自 LWN 分发列表 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# Redice–Linux
RedSonic 的 RED 是一个实时 Linux 内核，旨在支持任务关键应用并为系统提供服务质量。源自 LWN 分发列表 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# redir
TCP 连接可以在其下运行也可以单独运行（在这种情况下它可以处理多个连接）。它构建整洁，不限于命令行模式，体积小巧。支持 FTP 重定向并支持基于 IP 地址的跨防火墙重定向。不需要防火墙工具包。`med/tcp` 和 "`redir`" 的功能允许你在没有 telnet/ftp 网关的情况下完成所有需要。（假设你正在运行 IP 伪装。）源自 Debian 3.0r3 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# redirection
从输出以外源接收或向标准输出以外的目的发送。使用 `<` 进行输入重定向，使用 `>` 进行输出重定向。源自 Linux Guide@FirstLinux http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# Redirection Symbol
> 字符用于将输出发送到文本文件。例如，将目录列表发送到名为 output.txt 文件。重复该命令将用新数据替换文件内容。（另请参见追加符号和管道符号。）源自 I-gloss http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

在单个计算机系统中使用两个或多个驱动器，可以提供更好的磁盘性能、错误恢复和容错性。源自 Redhat–9–Glossary http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# regexp
`/regexp/` n. [Unix]: 'regex' 或 'reg-expr' 1. `regular expression`（正则表达式）的常用书面和口语缩写，指 Unix 工具（如 `grep(1)`, `sed(1)` 和 `awk(1)`）中使用的通配符模式。这些惯用法与下文描述的相似，但不仅限于此。对于本字典而言，只需注意 regexps 也允许使用 `^` 使用补补字符集，可以使用 `[^A-Za-z]` 指定任何非字母字符。2. 一种广名的 C 语言正则表达式处理可移植程序名称，由重用了 Henry Spencer <henry@zoo.toronto.edu> 代码编写。源自术语字典（Jargon Dictionary） http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# register distancing（寄存器缓冲）
n. 许多处理器架构面临通用寄存器严重不足的问题。这对于编译器编写者来说尤其是一个问题，因为生成的代码需要地方来存储表达式评估等内容的临时值。某些具有此类问题的设计（如 Intel x86）拥有少量特殊用途寄存器，可以挤入寄存器，提供缓存集以避免对处理器状态产生副作用；当使用特殊寄存器持有中间值时，需要细致的操作，在特殊寄存器的功能（和值）再次需要之前，保存并恢复该寄存器的值。源自术语字典（Jargon Dictionary） http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# regular expression（正则表达式）
一组符号，包括文本和元字符，用于搜索第一个文本。最常见的组件是点（`.`），匹配一个字符；星号（`*`），匹配任意数量的字符；以及中括号 `[string]`，它列出一组要匹配的字符。来自 Linux Guide @FirstLinux http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# Regular Expressions（正则表达式）
正则表达式是一个形成模板的字符序列，用于在文本中搜索字符串 [单词、短语或任何字符序列 ]。换句话说，它是一种搜索模式。为了直观理解何时需要这样做，请考虑有一个姓名和电话号码列表的例子。如果你想找到一个第二个数字是 3 且以 8 结尾的电话号码，正则表达式提供了这种搜索方法。考虑需要向许多人发送电子邮件的情况，将“Dear”替换为他们自己的名字以使信件更具个性化。正则表达式允许此类搜索和替换。来自 Route-Users-Guide http://www.tldp.org/LDP/Linux-Dictionary/index.html

# reiserfs-utils
`reiserfs-utils` 软件包包含许多工具，用于创建、检查和纠正 ReiserFS 系统中的任何不一致之处，包括 `reiserfs`（修复不一致性）、`mkreiserfs`（将分区初始化为空的 ReiserFS 文件系统）、`debugreiser`（检查文件系统的内部结构、手动修复损坏的文件系统，或为 reiserfs 创建测试用例）以及其他 ReiserFS 工具。如果你想在你的任何分区上使用 ReiserFS，则应该安装 `reiserfs-utils`。来自 ReiserFS 8.0 RPM http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# reisersprogs
用于 ReiserFS 的用户级工具。此软件包包含创建、检查和调试 ReiserFS 系统的工具。注意：2.4 之前的 Linux 版本本身不支持 ReiserFS。这些工具仅在 Linux 2.4 中或当你的内核在构建时应用了 ReiserFS 补丁时才有用。该补丁可以在此处找到。来自 Linux 字典 http://www.tld.org/LDP/Linux-Dictionary/index.html
