## 5. 使用 Java CGI 类。

目前支持三个类：`CGI`、`Email` 和 `HTML`。它们用于测试服务器。

### 5.1 CGI

#### 5.1.1 类语法

```
public class CGI
```

#### 5.1.2 类描述

`CGI` 类持有环境变量。该类位于 Orbits 包。

#### 5.1.3 成员摘要

- `CGI()`：构造构造函数。
- `getNames()`：获取名称列表。
- `getValue()`：通过名称获取值。

#### 5.1.4 参见 `CGI.Test`。

#### 5.1.5 `CGI()`

目的是构造包含可用 CGI 数据的对象。

语法

```
public CGI
```

描述：构造 `CGI` 对象时，所有可用的 CGI 信息都会吸取到本地存储中。

#### 5.1.6 `getNames()`

目的是列出定义的名称。

语法

```
public Enumeration getKeys ()
```

描述：提供具有对应值的完整名称列表。

返回所有名称的枚举（`Enumeration`）。

#### 5.1.7 `getValue()`

目的是检索与指定名称关联的值。

语法

```
public String getValue ( String name )
```

描述：此方法提供了从 HTML 表单发送的名称和值之间的对应关系。

参数

`name`：选择值的键。

返回包含该值的字符串。

### 5.3 Email

#### 5.3.1 类语法

```
public class Email extends Text
```

#### 5.3.2 类描述

消息通过 `Text` 类的 `add()` 方法以及此类类添加的电子邮件特定方法来构建。完成后，消息将发送到其目的地。

该类位于 "Orbits.net" 程序包中。

#### 5.3.3 成员摘要

```
Email()             // 构造函数。
send()               // 发送电子邮件消息。
sendTo()             // 为消息添加目的地。
subject()           // 设置消息的主题（Subject:）。
```

#### 5.3.4 参见

`Email.Test`, `Text`。

#### 5.3.5 `Email()`

##### 目的

构造一个将包含电子邮件消息的对象。

##### 语法

```
public Email()
```

##### 描述

设置一个空消息，由 `Email` 方法完成内容。

##### 参见

`Text`。

#### 5.3.6 `send()`

##### 目的

发送电子邮件消息。

##### 语法

```
public void send ()
```

##### 描述

对消息进行格式化并发送。如果没有设置目标地址，则不执行任何操作。

#### 5.3.7 `sendTo()`

##### 目的

为此消息添加目的地。

##### 语法

```
public String sendTo ( String address )
```

##### 描述

将地址添加到此方法的目的地列表中。电子邮件消息可以拥有的目的地数量没有限制。我确信，如果你构建的列表足够大，可能会超过邮件传输代理（Mail Transport Agent）可以接受的参数列表大小或消耗你的内存。

##### 参数

| 参数 | 描述 |
| :--- | :--- |
| `address` | 发送此消息的目的。 |

#### 5.3.8 `subject()`

##### 目的

设置此消息的主题。

##### 语法

```
public void subject ( String subject )
```

##### 描述

此方法设置电子邮件主题行（Subject:）的文本。如果调用多次，将使用最后一次设置的主题。

##### 参数

| 参数 | 描述 |
| :--- | :--- |
| `subject` | 此消息主题行（Subject:）的文本。 |
