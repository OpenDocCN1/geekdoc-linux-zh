电话号码可能列为 `(410) 555-1214`、`(410)5551214`、`4105551214`、`410 1212-555-1214`。为了让这个文件具有可读性，我想将所有这些电话号码重写为最后一种形式。

```
sed 's/\([0-9]\{3\}\) \([0-9]\{3\}\)-\([0-9]\{4\}\)/\1-\2-\3/g' -i numbers.txt
```
