
### iii. `p_3(n)` = [ \(\frac{1}{12}n^2 + \frac{1}{2}n + 1\) ]。

### 证明

- i. 这是显而易见的，因为 `n` 分为至多一个部分的分区只有一个，即 `n` 本身。

- ii. `n` 分为至多两个部分的分区如图 6.4 所示。我们需要分别考虑 `n` 为偶数的情况（设 `n` = 2`q`，其中 `q` 为某个整数）和 `n` 为奇数的情况（设 `n` = 2`r` + 1，其中 `r` 为整数）。

  - 我们可以看到，当 `n` = 2`q` 时，`p_2(n)` = `q` + 1 = \(\frac{1}{2}\)`n` + 1；当 `n` = 2`r` + 1 时，`p_2(n)` = `r` + 1 = \(\frac{1}{2}\)`n` + \(\frac{1}{2}\)。由于这些值都是整数，因此公式 `p_2(n)` = [ \(\frac{1}{2}n\) ] + 1 在这两种情况下都成立。

- iii. 仔细分析 `n` = 1, 2, 3, 4, 5, 6, 7, 8, . . . 的情况，会得出以下建议：

  - `p_3(n)` = \(\frac{1}{12}\)(`n`\(^2\) + 6`n` + `t`)，其中 `t` = 5, 8, 9, 8, 5, 12，具体取决于 `n` ≡ 1, 2, 3, 4, 5, 0 (mod 6)。 (6.5)

我们使用数学归纳法证明方程 6.5。

*基础步.* 我们假设你可以通过直接计算确认方程 6.5 在 $n = 1, 2, 3, 4, 5, 6$ 时成立（参见习题 6.2.1A）。

*归纳步.* 我们假设 $n \ge 6$ 且方程 6.5 对所有正整数 $k < n$ 成立。使用定理 6.2 两次，我们得到 `p_3(n)` = `p_2(n)` + `p_3(n-3)` = `p_2(n)` + `p_2(n-3)` + `p_3(n-6)`。因此，根据 (ii)，`p_3(n)` = [\frac{1}{2}n+1] + [\frac{1}{2}(n-3)+1] + `p_3(n-6)`。现在，可以证明 [\frac{1}{2}n+1] + [\frac{1}{2}(n-3)+1] = `n`（请你在习题 6.2.6A 中检查这一点），因此，利用归纳假设，

`p_3(n)` = `n` + \frac{1}{12}((`n`-6)^2 + 6(`n`-6) + `t`) = \frac{1}{12}(`n`^2 + 6`n` + `t`)，其中 `t` = 5, 8, 9, 8, 5, 12，具体取决于 `n`-6 ≡ 1, 2, 3, 4, 5, 0 (mod 6)。由于 `n` ≡ `n`-6 (mod 6)，因此结果对 `n` 也成立。

这就完成了通过数学归纳法证明方程 6.5 对所有正整数 `n` 成立的证明。

我们现在需要证明 (iii) 中给出的公式是正确的。为此，我们首先注意到如果 `n` = 6`m` + `r`，则 \frac{1}{12}(`n`^2 + 6`n` + `t`) = 3`m`^2 + `m``r` + 3`m` + \frac{1}{12}`r`^2 + \frac{1}{2}`r` + \frac{1}{12}`t`，而 [\frac{1}{12}`n`^2 + \frac{1}{2}`n` + 1] = [\frac{1}{12}3`m`^2 + `m``r` + 3`m` + \frac{1}{12}`r`^2 + \frac{1}{2}`r` + 1] = 3`m`^2 + `m``r` + 3`m` + [\frac{1}{12}`r`^2 + \frac{1}{2}`r` + 1]，因为 3`m`^2 + `m``r` + 3`m` 是整数。所以我们只需要检查 \frac{1}{12}`r`^2 + \frac{1}{2}`r` + \frac{1}{12}`t` ≡ [\frac{1}{12}`r`^2 + \frac{1}{2}`r` + 1] 在 (`r``t`) = (1,5), (2,8), (3,9), (4,8), (5,5) 和 (6,12) 这些情况下的成立。这一点很容易做到。
