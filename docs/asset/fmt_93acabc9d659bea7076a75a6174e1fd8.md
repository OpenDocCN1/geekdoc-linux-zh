# WinLinux

WinLinux 2001 的设计和构建旨在成为最易用的 Linux 系统。它的安装和配置任务直接在 Windows 上使用图形化工具完成。目前已提供 WinLinux 2003。来自 LWN 分发列表

# WinSlack

WinSlack 是一个带有 KDE 和 Star Office 的基础 Linux 安装版。它不需要登录，并为你提供一个与其它领先 PC GUI 类似的桌面环境，它将内核编译到 CD-ROM 和软盘中，且软盘会自动挂载和卸载。你还可以从桌面格式化软盘。退出 X 会话后，机器将关机。它主要基于 Slackware 7.1 并经过了一些修改。来自 LWN 分发列表

`http://www.tldp.org/LDP/Linux-Dictionary/index.html`

# Wintel

n. 微软 Windows 加上英特尔 - 20 世纪 90 年代桌面计算的默契联盟。现在（1999 年）可能正处于来自 Linux 压力的边缘：参见 Intel。来自 George 字典
