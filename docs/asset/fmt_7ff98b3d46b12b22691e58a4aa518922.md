# setfacl — 修改文件或文件的访问控制列表 (ACL)

# 语法

/usr/bin/setfacl [-r] -s acl-entries file...

## 描述

访问控制列表 (ACL) 是标准 UNIX 权限的扩展。ACL 信息单独存储并与每个文件关联。`setfacl` 用于设置、添加、修改和删除 ACL 条。对于指定的每个文件，`setfacl` 要么替换其整个 ACL（包括目录的默认 ACL），要么添加、修改或删除一个或 ACL 条（包括默认条）。

在文件上设置 ACL 也会修改文件的权限位。用户目修改文件所有者权限位。如果你没有指定掩码条目，组目修改文件组所有者权限位。如果你指定

如果你使用 `chmod(1)` 命令更改带有 ACL 条目的文件的组所有者权限，则组所有者权限和 ACL 掩码都将更改新权限。请注意，新的 ACL 掩码权限可能会更改对文件具有 ACL 条目的其他用户和组的有效权限。

目录可以包含 ACL 条目。如果你在包含 ACL 条目的目录中创建一个文件，新创建的文件权限将根据 `umask(1)`、默认 ACL 条目和创建时请求的权限的交集生成。如果为特定用户（或用户）指定了默认 ACL，则文件将按常规方式创建；否则，仅根据上述交集初始化模式位。默认 ACL 应被认为可以授予的最大裁量访问权限。
