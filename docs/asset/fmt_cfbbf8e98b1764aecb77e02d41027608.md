
# 结肠

结肠是从盲肠延伸到直肠的肠道部分；在某些哺乳动物中，它可能通过回盲瓣与小肠分隔开。它也被称为大肠。结肠通常分为升结肠、横结肠和降结肠部分。在人类中，第四个部分——乙状结肠——在草食动物中较长，在肉食动物中较短，在人类中长度约为 4 到 6 英尺（1.2 到 1.8 米）。结肠不分泌消化酶。许多消化过程（例如纤维素的所有分解）都是由细菌完成的，其中 `Escherichia coli`（大肠杆菌）最为常见。在消化过程中添加到食物中的大部分液体在结肠中被重新吸收到体内。所有的消化作用、水分吸收等在食物材料离开结肠进入直肠之前完成。参见 [DIGESTIVE SYSTEM](https://www.example.org/digestive_system)。[W.J.B.]

# 颜色

颜色是视觉感知的一个方面，使人类观察者能够区分两个具有相同大小、形状和持续时间的无结构光场之间的差异。虽然亮度差异被发现与色调差异几乎同样容易区分，但“颜色”一词通常局限于在等亮度条件下仍能感知到的一类差异。这些差异取决于两个光场光谱组成的物理差异，通常表现为观察者看到的色调或饱和度差异。

颜色辨别之所以可能，是因为人眼包含三类锥体光感受器，它们所含的光合色素和神经连接各不相同。其中两类，R 锥体和 G 锥体，对可见光谱中 380 到 700 纳米的所有波长都敏感。（如果有足够的能量，更长或更短的波长也可能有效。）R 锥体在约 570 纳米处敏感度最高，G 锥体在约 540 纳米处敏感度最高。R/G 锥体敏感度比值在 465 纳米处达到最小，对于比该波长更短或更长的波长，比值单调增加。该比值与强度无关，颜色的红-绿变化维度是用该比值编码的。B 锥体的敏感度峰值在约 440 处，对于长于 540 纳米的波长，B 锥体不会被显著激发。蓝色和黄蓝色的感知取决于 B 锥体的激发水平相对于 R 和 G 锥体的激发水平。只要两个足够不同以可区分的波长，就不能在三类锥体中产生相等的激发，因此两个波长不能引起相同的感官体验。

不同的复杂光谱分布通常（但并不总是）看起来不同。适当比例的短、中、长波长光，如果相加混合，例如可以精确地像含有所有波长相等能量的光一样激发 R、G 和 B 锥体。因此，这两个刺激看起来相同。这是物理上不同的刺激在主观上相同的极端例子，被称为彩色同色异谱体。相加混合可以通过光学叠加、频率过高以至于视觉系统无法跟踪的快速交替，或者（如在彩色电视中）通过并置极其细小的元素来实现，这些元素组成精细到超出视觉敏锐度极限的场结构。参见 [EYE (VERTEBRATE)](https://www.example.org/eye)；[LIGHT](https://www.example.org/light)。

虽然颜色通常通过参考标准样本来定义，但三色视觉的性质允许用三个值来规范它们。理想情况下，这些值可能是 R、G 和 B 锥体的相对激发量。由于 1931 年对锥体作用光谱了解甚少，国际照明委员会（CIE）当时采用了一种不同但相关的同色异谱体预测系统（CIE 色度制系统）。这个广泛使用的系统允许指定三刺激值 X、Y 和 Z，它们关于颜色匹配的预测与基于锥体作用光谱的计算几乎相同。如果对于场 1 和场 2，X1 = X2，Y1 = Y2，且 Z1 = Z2，则称这两个刺激匹配（因此具有相同的颜色），无论它们在物理上是相同的（同构的）还是不同的（同色异谱的）。

颜色通常在一个称为 CIE 色度图的二维图表中规范，该图表展示了独立于亮度的三刺激值之间的关系。在这个平面中，按照惯例，它被绘制为 x 的函数，其中 $y = Y/(X + Y + Z)$ 和 $x = X/(X + Y + Z)$。[值 $z = Z/(X + Y + Z)$ 也等于 $1 - (x + y)$，因此不包含额外信息。] 这样的图表在插图中展示，其中连续光谱色的轨迹由最外轮廓表示。所有非光谱色都包含在由该边界和一条从红色到紫色的直线定义的区域内。图表还显示了 25 个区域的辨别数据，这些数据绘制为椭圆，并以实际尺寸的 10 倍表示。一个辨别单位是椭圆中心到其周界距离的十分之一。已经制定了用于向 CIE 图表其他区域进行插值的预测方案。

色度图确实具有一些非常便利的性质。其中最主要的事实是颜色的相加混合位于连接混合颜色的色度之间的直线上。虽然有时方便通过色度图来可视化颜色

，但重要的是要意识到这不是一个心理学颜色图。相反，色度图陈述的是同色异谱颜色匹配的结果，意思是图表上的给定点代表所有在色度坐标 x, y 处绘制的同色异谱体的轨迹。然而，这并不指定颜色的外观，因为颜色的外观可以通过预先使眼睛暴露于有色光（色觉适应）或在现实生活的复杂感觉中通过附近或相邻区域存在的其他颜色（颜色对比和同化）而显著改变。尽管如此，在限制范围内，颜色外观由此改变的同色异谱体仍然匹配。

对于在黑暗环境中呈现的简单、直接注视且无结构的光场，颜色的色度坐标与引发的颜色感觉之间存在一致的关系。因此，色度图的区域通常由颜色名称表示，如插图所示。

虽然 CIE 系统在实践中工作得相当好，但存在重要的局限性。正常的人类观察者对他们的颜色匹配并不完全一致，主要是因为光合色素前的惰性色素对光的不同吸收。对于色差色度，个体差异要大得多，而且该系统整体上不适合那些色觉异常的人群（占人口的 4%，主要是男性）。该系统仅适用于中间范围的亮度，低于此范围时，杆体（夜间视觉受体）开始起作用，高于此范围时，视觉色素的光漂白会显著改变锥体的吸收光谱。参见 [COLOR VISION](https://www.example.org/color_vision)。[R.Mo.]

# 颜色（量子力学）

一个术语，用于指代夸克所携带的一个假设量子数，这些夸克被认为是组成强相互作用基本粒子的成分。它与颜色这个词在普通视觉用法中没有任何关系。

被认为是组成强相互作用粒子的夸克具有 h（普朗克常数）的一个半单位的自旋角动量。根据相对论与量子力学结合的一个基本定理，它们因此必须遵守费米-狄拉克统计，并受泡利不相容原理的约束。在特定系统中，任何两个夸克都不能具有完全相同的量子数。参见 [EXCLUSION PRINCIPLE](https://www.example.org/exclusion_principle)；[FERMI-DIRAC STATISTICS](https://www.example.org/fermi_dirac_statistics)。

然而，在组成重子时，似乎经常需要违反这一原理。例如，$\Omega^-$ 粒子由三个奇异夸克组成，并且这三个夸克都必须处于完全相同的状态。O. W. Greenberg 负责了这个悖论解决方案的基本思想。1964 年，他提出每种夸克类型（u, d, 和 s）有三种品种，在所有可测量特性上相同，但在一种附加属性上不同，这种属性后来被称为颜色。这样就可以满足不相容原理，夸克可以保持为费米子，因为重子中的夸克将不会具有相同的量子数。即使它们在其他方面相同，它们在颜色上也会不同。参见 [BARYON](https://www.example.org/baryon)；[ELEMENTARY PARTICLE](https://www.example.org/elementary_particle)；[MESON](https://www.example.org/meson)；[QUARKS](https://www.example.org/quarks)。[Tap.]

# 色心

产生光学吸收带的各种原子和电子缺陷，存在于原本透明的晶体中，如碱金属卤化物、碱土金属氟化物或金属氧化物。它们是发现于广泛材料中的一般现象。色心由伽马射线或 x 射线产生，通过添加杂质或过量成分，有时通过电解产生。一个众所周知的例子是碱金属卤化物（如氯化钠，NaCl）中的 F 心。F 心的名称来自德语单词 `Farbe`，意为颜色。NaCl 中的 F 心在可见光谱的蓝端产生光学吸收带；因此，有色晶体在透射光下呈黄色。另一方面，具有 F 心的 KCl 呈品红色，KBr 呈蓝色。参见 [CRYSTAL](https://www.example.org/crystal)。

色心已被研究了许多年。由详细实验工作指导的理论研究产生了对特定色心的深入理解。出现色心的晶体倾向于对光和微波透明。因此，可以进行的实验包括光学光谱、发光和拉曼散射、磁圆二色性、磁共振和电子自旋共振。色心在辐射剂量计中有实际应用；已提出使用色心在高密度存储器件中，并由含有色心的晶体制造了可调激光器。

插图展示了在液氮温度（81 K）下将晶体暴露于强穿透 x 射线后，在溴化钾中产生的色心引起的吸收带。辐照产生了几条显著的吸收带。F 带出现在 600 纳米处，所谓的 U 带出现在紫外区。

F 带和 U 带等色带是由于分散在整个晶格中的缺陷对光的吸收而产生的。这种吸收是由色心处的电子跃迁引起的。另一方面，分散在光学介质中的胶体颗粒（每个由许多原子组成）也会产生色带。在这种情况下，如果颗粒足够大，光的消光是由于光的散射和光的吸收共同作用。胶体金负责某些类型红宝石玻璃的颜色。胶体也可以在碱金属卤化物晶体中形成——例如，在对含有过量碱金属的加色晶体进行热处理期间。
