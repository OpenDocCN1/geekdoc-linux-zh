
### 输入上下文重置

`ic`: 指定输入上下文。

当 `XNMRResetState` 被设置为 `XIMInitialState` 时，输入上下文恢复到初始状态；当 `XNMRResetState` 被设置为 `XIMPreserveState` 时，则保留当前输入状态。在这两种情况下，该上下文上的待处理输入都会被删除。输入法需要清除预设区域并相应地更新状态。调用 `XmbResetIC` 或 `XwcResetIC` 不改变焦点。

`XmbResetIC` 的返回值是其当前预设字符串的多字节字符串形式。如果没有绘制或对用户的预设文本，则过程必须返回非 `NULL` 字符串。如果没有可见的预设文本，这些过程返回非 `NULL` 字符串还是 `NULL` 取决于输入法的实现。

客户端应调用 `XFree` 来释放返回的字符串。

要获取与输入上下文关联的输入法，使用 `XIMFic`。

```
XIM XIMOFIC(ic);
```

`ic`: 指定输入上下文。

`XIMOFIC` 函数返回与指定的输入上下文关联的输入法。

### 设置和读取 XIC 值

`Xlib` 分提供了两个用于设置和读取 `XIC` 值的函数，分别是 `XSetICValues` 和 `XGetICValues`。这两个函数都具有变长列表。在参数列表中，`XIC` 值的名称必须使用可字符集字符串表示。

要设置 `XIC` 值，使用 `XSetICValues`。

```
char *XSetICValues(ic);
```

`ic`: 指定输入上下文。
... 指定用于 `XIC` 值的变长列表。

如果没有发生错误，`XSetValues` 函数返回 `NULL`；否则，它返回无法设置的第一个参数的名称。由于以下原因可能无法设置参数：

- 参数是只读的（例如 `XNFilterEvents`）。
- 参数名称不被识别。
- 发生了依赖于实现的错误。

要设置的每个值必须是适当的数据，与参数语义强制的数据类型匹配。

`XSetValues` 可以产生 `BadAtom`、`BadColor`、`BadCursor`、`BadPixmap` 和 `BadWindow` 错误。

要获取 `XIC` 值，使用 `XGetICValues`。

```
char *XGetICValues(ic)
```
