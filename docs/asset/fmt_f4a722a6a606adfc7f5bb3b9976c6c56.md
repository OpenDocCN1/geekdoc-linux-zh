## 第 12.3 节：云存储与 Linux

云存储在现代计算中起着至关重要的作用，提供了扩展、可靠且具有成本效益的数据解决方案。在 Linux 系统中集成云存储对于管理数据至关重要。在本节中，我们将探索如何使用 Amazon S3、Azure Blob Storage 和 Google Cloud Storage (GCS) 等云存储解决方案。

### Amazon S3

Simple Storage Service (S3) 是一种流行的对象存储服务，提供高持久性、可扩展性和可用性。要在 Linux 系统上与 Amazon S3 交互，你可以使用 AWS 命令行界面 (CLI) 或软件开发包 (SDKs)。以下是一些常见操作：

#### 安装 AWS CLI

你可以在 Linux 上安装 AWS CLI 以交互 Amazon S3。在 Debian 系发行版上，使用：

```bash
sudo apt-get install awscli
```

在 Red Hat 系发行版上，使用：

```bash
sudo yum install aws-cli
```

#### 配置 AWS CLI

安装后，使用你的访问密钥和密钥配置 AWS CLI：

```bash
aws configure
```

#### 上传文件到 S3

要将文件上传到 S3 桶，请使用 `aws s3 cp` 命令：

```bash
aws s3 cp local-file.txt s3://your-bucket/
```

#### 从 S3 下载文件

要从 S3 下载文件到你的 Linux 系统，请使用：

```bash
aws s3 cp s3://your-bucket/remote-file.txt local-copy.txt
```

### Azure Blob Storage

Azure Blob Storage 是微软的对象存储服务。你可以在 Linux 上使用 Azure CLI 或各种编程语言的 Azure SDK 与 Azure Blob Storage 交互。以下是常见操作的方法：

#### 安装 Azure CLI

要在 Linux 上安装 Azure CLI，请按照官方网上适用于你发行版的说明。

#### 配置 Azure CLI

登录你的 Azure 账户：

```bash
az login
```

# 上传 Blob

使用 `az storage blob upload` 命令将本地文件上传到 Azure Blob Storage 容器：

```
az storage blob upload --type block-blob --account-name your-storage-account --account-key your-storage-key --container-name your-container-name remote-file.txt --type file-path
```

# 下载 Blob

要从 Azure Blob Storage 下载 blob，请使用 `az storage blob download` 命令：

```bash
az storage blob download --type block-blob --account-name your-storage-account --account-key your-storage-key --container-name your-container-name remote-file.txt --type file-path
```

# Google Cloud Storage (GCS)

Google Cloud Storage (GCS) 是 Google 的对象存储服务。你可以在 Linux 上使用 Google Cloud SDK 或客户端库与 GCS 交互。以下是执行常见任务的常见方法：

# 安装 Google Cloud SDK

按照 Google Cloud 网站提供的说明在 Linux 上安装 Google Cloud SDK。

# 配置 Google Cloud SDK

运行以下命令来配置 Google Cloud SDK：

```bash
gcloud init
```

# 上传对象

要向 GCS 上传对象，请使用 `gsutil cp` 命令：

```bash
gsutil cp local-file.txt gs://your-bucket/
```

# 下载对象

从 GCS 下载对象到你的 Linux 系统，请使用：

```bash
gsutil cp gs://your-bucket/remote-file.txt local-copy.txt
```
