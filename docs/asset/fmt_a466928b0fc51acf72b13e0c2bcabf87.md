## 4.4.6 IDE DMA 模式

通过此模块激活或禁用 IDE 磁盘的 DMA 模式。此模块对 SCSI 设备没有影响。DMA 模式可以大幅提高性能和数据传输速度。

在安装期间，当前的 SUSE 内核会自动为硬盘激活 DMA，而不是光驱器，因为默认激活所有驱动器会导致问题。如果你想为驱动器激活。

> 注意
>
> DMA（直接内存访问）意味着数据可以直接传输到 RAM，而跳过处理器控制。

## 4.4.9 扫描仪

# 未检测到扫描仪

只有支持的扫描仪可以自动检测。连接到另一个网络节点的扫描仪将无法检测。手动配置区分了三种类型的扫描仪：USB 扫描仪、SCSI 扫描仪和网络扫描仪。

- USB 扫描仪：指定厂商和型号。`YaST` 将会尝试加载 USB 模块。如果您的扫描仪非常新，模块可能不会自动加载。在这种情况下，继续进入一个对话框，在其中手动加载 USB 模块。更多信息请参阅 `YaST` 文本。
- SCSI 扫描仪：指定设备（如 `/dev/sg0`）。在系统运行时不应连接或断开 SCSI 扫描仪。请关闭系统。
- 网络扫描仪：输入 IP 地址或主机名。

您可以使用连接到网络中主机并配置为网络扫描仪的扫描仪。要配置网络扫描仪，请参阅支持数据库文章 [Linux 中的扫描](http://sdb.suse.de/en/，关键词：scanner)。在选择网络扫描仪时，输入扫描仪所连接的主机主机名或 IP 地址。

如果未检测到您的扫描仪，则该设备可能不支持。然而，有时受支持的扫描仪未被检测到。如果是如此，请继续手动选择扫描仪。如果您能在厂商和型号列表中识别出您的扫描仪，请选择它。否则，选择“取消”。关于适用于 Linux 的扫描仪信息，可以在 http://cdb.suse.de/index.php?LANG=en、http://sdb.suse.de/en/ 以及 http://www.mostang.sane 获取。

## 注意事项

仅在您完全确定时才手动分配扫描仪。选择错误可能会损坏您的硬件。

# 故障排除

您的扫描仪可能未被检测到，原因可能是以下之一：

- 扫描仪不支持。检查 http://sdb.suse.de/en/ 获取 Linux 兼容设备列表。
- 您的 SCSI 控制器未正确安装。
- 你的 SCSI 端口存在终端问题。
- 您的 SCSI 线太长。
- 您的扫描仪具有 Linux 不的 SCSI 光控制器。
- 您的扫描仪故障。

## 4.4.10 声音

启动声音配置工具时，`YaST` 会尝试自动检测您的声卡。配置一个或多个声卡。要使用多个声卡，请从选择一个要配置的声卡开始。按“配置”进入“设置”对话框。“编辑”将打开一个可以在其中编辑以前配置的声卡的对话框。“完成”将保存当前设置并完成声音配置。如果 `YaST` 无法自动检测您的声卡，请在“声音配置”中点击“添加声卡”，打开一个可以在其中选择声卡和模块的对话框。

## 设置

使用“快速自动设置”，您无需经过任何进一步的配置步骤，且不进行声音测试。声卡将自动配置。使用“普通设置”，您有机会调整输出音量并播放测试音。使用“选项”，可以手动自定义声卡选项。

通过点击相应的复选框来设置您的摇杆。在随后的出现的对话框中选择摇杆类型并点击“下一步”。当您在 `YaST` 控制中心中点击“摇杆”时，会出现相同的对话框。

## 声卡音量

在此测试屏幕中测试您的声音配置。使用 `+` 和 `-` 调整音量。从约百分之十开始以避免损坏扬声器或听力。当您按下“测试”时，应该能听到测试音。如果您听不到任何声音，请增加音量。按“继续”完成声音配置。音量设置将被保存。

## 声音配置

使用“删除”移除声卡。已配置声卡的现有条目将在 `/etc/modules.conf` 文件中被停用。点击“选项”打开一个对话框，可以在其中手动自定义声音模块选项。在“音量”中，配置每个声卡输入和输出的单独设置。“下一步”将保存新值，“上一步”将恢复默认配置。在“添加声卡...”下，配置额外的声卡。如果 `YaST` 检测到另一个声卡，将继续到“配置声卡”。如果 `YaST` 未检测到声卡，将自动重定向到“手动选择声卡”。

如果您创建了 CreativeBlaster Live 或 AWE 声卡，使用“安装声音字体”从原始 SoundBl 驱动光盘（CD）中将 SF2 字体自动复制到您的硬盘。声音字体将保存在目录 `/usr/share/sfbank/` 中。

使用“启动 ALSA”在启动机器时启用或禁用 ALSA 的启动。要播放 MIDI 文件，请激活“启动选择器”。这样，支持选择器所需的模块将随 ALSA 模块一起加载。

点击“完成”时，所有已安装声卡的音量和配置将被保存。混合器设置保存到文件 `/etc/asound.conf`，ALSA 配置数据附加在文件 `/etc/modules.conf` 的末尾。

## 配置声卡

如果检测到多个声卡，请在“自动识别列表...”下选择您偏好的声卡。点击“下一步”继续进入“设置”。如果声卡未被自动检测，点击“从列表中选择”，并点击“下一步”进入“手动选择声卡”。

## 手动选择声卡

如果声卡未被自动检测，将显示一个声卡驱动程序和模型列表供您选择。通过“所有”，可以查看支持的显卡完整列表。

所需信息请参阅您的声卡文档。ALSA 支持的声卡及其相应声音模块的参考列表位于 `/usr/share/doc/packages/alsa/cards.txt`。在做出选择后，点击“下一步”返回“设置”。

## 4.4.11 电视和广播显卡

启动并初始化此 `YaST` 模块后，将出现“电视和广播显卡”对话框。如果您的显卡被自动检测，它将位于列表顶部。在这种情况下，用鼠标选中该行并选择“配置”。如果您的显卡未被检测，选择“其他（未识别）”。按“配置”在厂商和型号列表中选择您的显卡。

如果您已经配置了电视或广播显卡，使用“更改”修改现有配置。在这种情况下，对话框显示所有已配置的显卡。选择一个显卡并从“编辑”开始。

在自动硬件检测期间，`YaST` 会尝试为您的显卡分配正确的调谐器。如果您不确定，只需保持“默认（已识别）”设置并检查是否有效。如果您无法看到所有频道，可能是由于调谐器类型检测失败。在这种情况下，点击“选择调谐器”并在列表中正确的调谐器。

如果您熟悉技术细节，可以使用专家对话框为电视或广播显卡指定设置。在此对话框中选择内核模块及其参数。还要检查电视显卡驱动程序的所有参数。选择相应的参数并在参数行输入新值。通过“应用”确认新值，或通过“重置”恢复默认值。
