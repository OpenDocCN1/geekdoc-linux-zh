# HP-UX 操作系统

本节重点关注特定操作系统的问题，这些问题的解决方案可能显而易见。

## 如何确定 CD-ROM 驱动器的设备名称，以便将其添加到 `/etc/checklist` 文件中进行挂载？我正在使用一台运行 9.04 的 HP9000 机器。

最好的办法是进入 disks and filesystems 部分下的 `SAM` 来设置你的 CD-ROM。`SAM` 不仅具有易于使用的优点，还能处理所有遗留工作，例如在 `/etc/checklist` 文件中创建条目。

进入 filesystem，然后选择 `Actions|Create a New Filesystem`，然后选择 `non-lvm filesystem`。会弹出一个列表，显示系统上配置的磁盘，其中一个就是你的 CD-ROM。现在填写所需的字段。你必须已经创建了一个目录来挂载文件系统；`/cdrom` 通常是使用的目录名。

## 我该如何扩展根卷组？

嗯，这并不容易，但可以做到，尽管有些间接。

关于这个问题有两种观点：从头开始重新构建系统，或者将子目录及其内容移动到其他已挂载的文件系统。

如果你选择重新构建系统，你实际上可以考虑在另一组磁盘上构建新系统，并在同一台服务器或工作站上提供两个操作系统供选择。

基本上，你需要做的是定义指向新根磁盘的主启动路径，向该磁盘上安装操作系统，并修改某些系统文件（如 `/etc/fstab`），使其指向原始文件系统（当然，除了根 `filesystem` 之外）。我说的听起来比实际上简单得多，但这个过程在 HP 手册中有非常详细的记录。

如果你决定将易变目录（`/usr`, `/opt`, `/var` 以及其他用户创建的文件系统）移动到其他文件系统，如果你没有额外的磁盘空间，这可能是一个不主主意。只有在你尚未设置与根目录分离的常规易变文件系统，或者根文件系统中的一两个目录异常大时，你才能这样做。

在这里，你想做以下两件事之一：你可以创建不同的文件系统并从原始目录创建链接；或者你可以将原始目录中的所有内容移动到临时位置，递归删除原始目录中的所有内容，创建一个具有适当空间的逻辑卷，从该目录挂载文件系统，并将所有内容从临时位置移回来。这必须在单用户模式下进行。

如果你选择后一种方法，请务必小心；某些文件和目录可能不会很好配合，系统可能会变得混乱。特别要小心设备驱动周围的内容。系统崩溃（system panic）可并不好看。

此外，就像任何类型的操作系统手术一样：**务必先进行完整备份！！！** 这被称为“保命”步骤。

无论你选择哪种，都要制定一个清晰的计划，记录一切，并在考虑给病人任何麻醉之前快速过一遍。

## 有办法方法可以在 10.10 系统上将 CDFS 文件名从全大写改为小写吗？

没有。你必须使用 `pfs` 子系统而不是默认的 `CDFS` 子系统来挂载 CD。这将允许你使用小写字母。

## 我计划从 9.04 升级到 10.01。直接进行全新的安装会更容易吗？

升级并没有那么糟糕。事实上，进行升级是更好的，因为它提供了过渡链接，允许你继续使用来自 9.04 的旧路径，并保留 `/etc/hosts`、`/etc/passwd` 等重要内容。

由于从 9.04 升级到 10.01 实际上是从基于 BSD 的 UNIX 升级到基于 System V 的 UNIX，许多命令移动以符合 System V 标准。例如，所有的 `lvm` 命令都从 `/etc` 移动到 `/usr/sbin`。此外，升级将保留你的站点特定信息，并提供分析工具帮助你转换可能有的任何自定义脚本。`snoop` 工具用于识别升级时可能出现的错误，这将帮助你避免在完全搞乱系统的情况下遇到中止状态。一如既往：**先进行完整备份！！！**

## 我如何让 Windows 95 客户端在我的 HP-UX 机器上使用 NFS？

通常，NFS 服务器提供基本的文件共享能力（`nfsd`），以及通过 `mountd` 建立连接。在基本形式下，它用于所有 UNIX 机器之间，这些机器使用用户名和用户 ID 进行多用户认证。当用户登录 NFS 机器时，她正在使用其原生认证来获取用户 ID。然后她可以使用该用户 ID 访问文件。这意味着两个系统对用户有相同的视图。由于情况是如此，安全认证由 NFS 服务器执行。文件系统的访问控制在主机级别通过将文件系统导出到各个工作站来完成。一旦导出，NFS 客户端可以显式选择挂载这些文件系统中的任何或全部。要启用使用不同认证系统的异构操作系统之间的文件共享，请使用 PCNFS 实用。此时 NFS 客户端被认为是不安全的，认证被推迟到 NFS 服务器或另一个委托主机。PCNFS 在服务器端处理此过程。NFS 客户端通过向 PCNFS 服务器转发用户名和密码来启动文件系统挂载。然后验证用户名和密码，并代表 NFS 客户端获取相应的 UNIX ID。一旦建立挂载，原始的 NFS 服务器将处理请求。此外，PCNFSD 还可以提供额外的锁定和打印机共享功能。

在 HP-UX 9.x 中启动 PCNFS：
编辑 `/etc/netnfsrc` 文件并将行
`PCNFS_SERVER=0`
更改为
`PCNFS_SERVER=1`

在 HP-UX 10.x 中启动 PCNFS：
编辑 `/etc/rc.config.d/nfsconf` 文件并将行
`PCNFS_SERVER=0`
更改为
`PCNFS_SERVER=1`

在两个系统中，你都必须重启服务器以启用 PCNFS。

## 如何让 `swinstall` 在 CD-ROM 光盘上运行？

首先，你必须将 CD-ROM 挂载为文件系统。在根目录下创建一个目录（通常为 `/CDROM`），并使用 `SAM` 将 CD-ROM 挂载到该目录。然后进入 `swinstall` 窗口中，将软件仓库指定为 `/CDROM`。现在你就可以选择要安装的软件了（当然，在你输入代码字之后）。

## 如何增加文件系统上的 inode 数量？

如果你正在使用 VxFS 文件系统，它是动态更改的。如果你使用的是 HFS（标准版），你将不得不使用 `newfs` 或 `mkfs` 来重新构建文件系统。遗憾的是，这将破坏该文件系统上的所有文件。

你可以使用 `newfs` 或 `mkfs` 的 `-i` 来更改 inode 的数量。

但你应该记住，当你增加 inode 数量时，会失去用于文件的磁盘空间。

## 我可以创建超过 14 个字符的文件名吗？

如果你还没有长文件名，可以使用 `/etc/convertfs` 实用程序转换为长文件名。然而，这是一条单行道。一旦做出更改，你就无法恢复。

要检查长文件名是否存在，请执行以下操作：

`tunefs -v /dev/rdsk/(disk driver) |grep magic`

你将得到类似下面的输出：

`magic 95014 clean FS_OK time Tue Mar 23 14:13:01 1993`

如果第二个字段中的数字是 95014，则该文件系统已安装长文件名支持。如果数字等于 11954，则系统设置为短文件名。

然后也可以在每个目录上使用 `getconf` 命令，如下：

`getconf NAME_MAX (directory)`

## 我如何知道我的系统中加载了哪些产品？

你可以检查 `/etc/filesets` 目录。在那里，你会为每个已加载的文件集找到文件，该文件总结了文件集中的内容。多个工具都会使用该目录，例如 `/etc/update`、`/etc/updist`、`/etc/netdistd` 和 `/etc/rmfn` 用于卸载和加载软件。

在 HP-UX 10.x 上有一个工具可以执行此操作。只需使用 `swlist` 命令即可。

## 从 HP-UX 系统安全删除软件的最佳方法是什么？

在 HP-UX 9.x 上，`/etc/rmfn` 命令将干净地删除 HP 软件。在 HP-UX 10.x 系统上，该工具是 `swremove`。

## 为什么 `/usr/mail` 中的邮件文件所有者是守护进程而不是接收者？

邮件投递代理 `/bin/rmail` 需要能够对这些文件执行 `chown(2)`。如果你删除了 `CHOWN` 权限，它无法做到（参见 `setprivgrp(1)`建议移除 `CHOWN` 以防止磁盘配额欺骗）。

为了绕过这个问题，由于 `/bin/rmail` 运行 `setgid` 到 `mail` 组，你可以通过在 `/etc/privgroup` 中插入 `mail CHOWN` 行来仅向 `mail` 组授予 `CHOWN` 权限。更改将在下次重启时生效，或者如果你执行命令 `setprivgrp -f /etc/privgroup` 则立即生效。

## 我应该担心只拥有双用户许可 吗？

关于 HP-UX 许可，有几个基本点需要记住：

- G 系列 700 和系列 800 用户现在的计算方式相同。
- G 显示控制台计为一个用户。
- G 每个 ASCII 终端都计为一个用户，无论它是如何连接的。
- LAN 连接计为一个用户。

ASCII 终端：

要记住的简单规则是，任何已登录的 ASCII 终端都算一个用户。

ASCII 终端连接有几种不同形式：

- 通过串口终端复用器直接连接。
- 通过数据终端集中器 (DTCs) 或终端服务器连接。
- 以终端仿真模式运行的个人电脑 (PC)，无论它是通过串口线还是局域网 (LAN) 连接的。

X 终端和工作站：

当客户从 HP 或其他供应商处购买 X 终端或工作站时，HP 承认该客户也买了一个单份的 UNIX 使用许可。

因此，客户有权通过 X 终端或工作站通过 LAN 无限次登录到系列 700 或系列 800。这些登录可以通过 X 终端窗口（`hpterm` 和 `xterm`）、`telnet`、`rlogin` 或其他手段。

使用 X 终端仿真软件（如 XView）的 PC 每个都等同于一个 X 终端。这是因为当 PC 运行 X 服务器软件时，它本质上变成了一个 X 终端。因此，当 PC 运行 X 终端仿真器时，该 PC 有权无限次登录 HP-UX 系统。

### 清理 `/tmp` 和 `/usr/tmp` 目录有什么好的建议？

这里有两个可以从 `cron` 运行的脚本：

```
#!/bin/sh

DAYS=7

find /tmp /usr/tmp -depth -hidden -fsonly hfs -atime +$DAYS -exec rm -rf {} \;
```

`-depth` 选项确保在删除目录之前先删除其内容；使用 `-fsonly hfs`是因为我偶尔会在那里挂载 NFS 目录，在本地机器上进行清理效果更好；使用 `-hidden` 是以防由于某种原因那里出现了 CD-光盘文件系统（CDFS）。

另一种处理方法是：

```
#!/bin/sh

DAYS=7

DIRS="/tmp /usr/tmp"

find $DIRS -type d -atime +$DAYS -exec rm -rf {} \;
find $DIRS ! -type d -atime +$DAYS -exec rm -f {} \;
```
