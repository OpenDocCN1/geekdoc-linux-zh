# 肌电图

检测并记录肌肉纤维产生的电活动。体内运动控制的功能单元是运动单位，它们由脑干或脊髓中的运动神经元、它们的轴突以及每个运动神经元提供的十到数百个肌肉纤维组成。运动单位在其运动神经元的大小和性质、轴突的大小和传导速度、神经肌肉接头的形态以及每个运动神经元供应的肌肉纤维的结构和生理性质方面各不相同。

起源于单个运动神经元并响应中枢神经系统各种指令信号的冲动传导至该单位的远端，通常导致该单位中的所有肌肉纤维放电。由单位中所有肌肉纤维或多或少同步放电产生的电活动可以通过皮肤表面的记录电极或插入肌肉的针头检测到。这种电位反映了整个运动单位产生的电活动。

影响运动神经元的疾病有时伴随轴突的自发放电。此外，运动轴突的变性可能使一些肌肉纤维失去其正常神经支配；其中一些会自发放电。这种单个肌肉纤维的放电称为纤颤，可通过插入肌肉的针电极轻松检测到，用于诊断目的。

肌电图也可用于研究原发性肌肉疾病，如肌营养不良症，以及各种其他影响肌肉纤维而非运动神经元或其轴突的代谢性、炎症性和先天性肌病。参见 生物电位和离子流；电诊断。[WFEB]

# 电动势（emf）

衡量电能源强度的一种度量。该术语常被简称为 emf。它不是通常机械意义上的力（因此有时被称为电动电压），而是一个描述驱动电流通过电路机制的描述性术语。在直流 I（以安培测量）通过电阻 R（以欧姆测量）的简单情况下，欧姆定律指出电阻两端将有 V=IR（以伏特测量）的电压降（或电势差）。（使此电流流动需要一个电动势也以伏特测量的电源）E。更一般地，基尔霍夫电压定律指出，沿电路中任何闭合路径的电源 E 之和等于电压降之和。这等价于陈述：闭合电路中的总电动势等于电场强度沿该电路的线积分。参见 电流；电场；电阻；欧姆定律。

电动势可以是稳态（直流），如电池那样；也可以是时变的，如充电电容器通过电阻放电那样。电动势可以由多种物理、化学和生物过程产生。其中一些更重要 的是：

- 电化学反应，如用于直流（dc）电池中，其中电动势源于电解质和电极之间的反应。参见 电池；电化学；电动势（电池）。
- 电磁感应，其中电动势源于穿过电路的磁通量的变化。这应用于交流旋转发电机和变压器，为电力供应行业提供基础。参见 交流发电机；电磁感应；法拉第感应定律；变压器。
- 热电效应，其中电路不同部分之间的温度差产生电动势。主要用途是通过热电偶测量温度；有一些应用用于发电。参见 热电偶；热电发电机；热电效应。
- 光电效应，其中半导体中光（或更一般地，电磁辐射）的吸收产生电动势。这广泛用于科学研究中的辐射探测器，并且越来越多地用于从太阳辐射中发电。参见 光伏效应；辐射计；太阳能电池。
- 压电效应，其中对某些类型晶体施加机械应力产生电动势。在声音记录、超声以及各类测量传感器中有应用。参见 交流电路理论；直流电路理论；直流电机；基尔霍夫电路定律；麦克风；压电效应；传感器；超声。[A.EBaJ]

# 电子

一种基本粒子，是普通物质中带有负电的组成成分。电子是已知最轻的具有电荷的粒子。其静止质量为 me=9.1 × 10⁻³¹ kg，约为质子或中子质量的 1/1836，它们分别是普通物质中带正电和中性的组成成分。电子于 1895 年由 J. J. 汤姆逊以阴极射线的形式发现，是第一个被识别的基本粒子。参见 电荷；基本粒子；核结构。

电子的电荷为 e=4.8 × 10⁻¹⁰ 静电库仑。按照惯例，电子的电荷符号为负，而带等量电荷的质子的电荷符号为正。这是一个不幸的惯例，因为导体中电子的流动方向与传统电流方向相反。

电子在放射性衰变（作为 β 射线）以及许多其他衰变过程中发射；例如，所有介子的最终衰变产物都是电子、中微子和光子，介子的电荷由电子带走。电子本身是完全稳定的。电子构成了普通物质的主要部分：原子的体积几乎全部被围绕原子核的电子云占据，而原子核仅占原子体积的约 10⁻¹³。普通物质的化学性质由电子云决定。参见 β 粒子；介子；放射性。

电子服从费米-狄拉克统计，因此常被称为费米子。物质的一个主要属性——不可渗透性——源于电子作为费米子服从泡利不相容原理这一事实；如果最轻的带电粒子是玻色子，即服从玻色-爱因斯坦统计的粒子，世界将完全不同。参见 玻色-爱因斯坦统计；不相容原理；费米-狄拉克统计；正电子。[C.J.G]

### 磁矩

电子由于其 (1) 绕母体原子核的轨道运动和 (2) 绕自身轴的旋转而具有磁性质。磁物质的特性最好通过1和2相关的**磁偶极矩**来描述，这是载流电路的经典类比。电子自旋磁偶极矩可以被认为源于电荷（即电流）绕电子轴的循环；但与轨道磁偶极矩相比，这一力矩的经典类比意义要小得多。构成固体的原子中电子的磁矩产生了固体的宏观磁性。

**自旋**。电子的一种属性，使其产生绕电子内部某一轴的角动量。自旋是电子永久且基本的属性之一。电子的自旋及其相关的磁偶极矩均由 G. E. Uhlenbeck 和 S. Goudsmit 在 1925 年提出，作为解释许多观测效应的必要条件，其中包括所谓的反常塞曼效应、碱金属原子光谱中双峰（紧密排列的双线）的存在，以及 X 射线光谱的某些特征。参见**自旋（量子力学）**。
