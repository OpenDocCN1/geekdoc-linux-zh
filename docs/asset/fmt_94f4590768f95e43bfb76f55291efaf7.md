## 9.10.2 接收和处理 ARP 数据包

在`linux/net/ipv4/arp.c`文件中实现的函数`arp_recv`在ARP数据包到达支持ARP的以太网或接口时被调用。

```c
int arp_recv(struct sk_buff *skb, struct net_dev *dev, struct packet_type *pt)
    struct arphdr *arp;
```

首先，确保传入的数据包长度足够以容纳ARP头部。如果不是，我们释放数据包并退出。

```c
if (!skb_may_pack(skb, (sizeof(struct arphdr) + 
    (2 * dev->addr_len) +
    (2 * sizeof(u32))))
    goto freeskb;
```

在此函数中，我们确保接收数据包的接口使用了ARP协议，并且该数据包不是环回包。

```c
if (arp->hr_len != dev->addr_len ||
dev->flags & IFF_NOARP ||
skb->pkt_type == PACKET_OTHEROTHER ||
skb->pkt_type == PACKET_LOOPBACK ||
arp->pl_len != 4)
    goto freeskb;
```

接下来，我们确保传入的数据包不是共享的。如果另一个协议接收了该包并正在修改它，就会出现这种情况。这种情况不太可能，但可能。

```c
if ((skb == skb_share_check(skb, GFP_ATOMIC)) == NULL)
    goto out_of_mem;
```

如果一切正常，我们通过网络调用`arp_process`。

```c
return NF_HOOK(NF_ARP, NF_ARP_IN, skb, dev, NULL, arp_process);
freeskb:
    free_skb(skb);
out_of_mem:
    return 0;
```
