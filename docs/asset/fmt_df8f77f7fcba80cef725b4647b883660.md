
# Linux (版本 1.6) | 主题 5：安全与文件权限

`Another_Directory` `picture.jpg` `text.txt`

但每个文件都有更多可用信息，包括类型、大小、所有权等。要查看这些信息，必须要求 `ls` 显示“长格式”列表，即使用 `-l` 参数：

```bash
$ ls -l

total 536

drwxrxr-x 2 carol carol 4096 Dec 10 15:57 Another_Directory

--rw-r--r-- 1 carol carol 539663 Dec 10 10:43 picture.jpg

--rw-r--r-- 1 carol carol 1881 Dec 10 15:57 text.txt
```

输出的每一列都有含义：

- 列表的第一列显示文件类型和权限。

例如，`drwxrwxr-x`：

- 第一个字符 `d` 表示文件类型。
- 接下来的三个字符 `rwx` 表示文件所有者的权限，也称为用户（user）或 `u`。
- 接下来的三个字符 `rwx` 表示文件组的权限，也称为组（group）或 `g`。
- 最后三个字符 `r-x` 表示其他人的权限，也称为其他人（others）或 `o`。
- 第二列表示指向该文件的硬链接数。对于目录，这意味着子目录的数量 `(. )` 和父目录的数量 `(..)`。
- 第三列和第四列显示所有权信息：分别是拥有文件的用户和组。
- 第五列显示文件大小（单位为字节）。
- 第六列显示精确的日期时间。
- 第七列显示名称。

如果你希望以“人类可读”格式查看大小，添加 `-h` 参数。小于 1 MB 的显示 K，小于 1 GB 的显示 M，小于 1 TB 的显示 G。

`/etc/passwd` 和 `/etc/group` 文件是全局可读的且出于安全原因进行了加密。当使用影子密码时，你可以在这些文件的第二个字段看到一个 `x`，因为用户和组的加密密码存储在 `/etc/shadow` 和 `/etc/gshadow` 中，这些文件只有 `root` 用户可以读取，在某些系统中，所有用户可能都属于 `shadow` 组。

## 本节超出范围的内容

### b (块设备)

此文件代表一个虚拟或物理设备，通常是磁盘或其他类型的存储设备。例如，系统中的第一个硬盘可能由 `/dev/sda` 表示。

### c (字符设备)

此文件代表一个虚拟或物理设备。终端（如 `/dev/tty0` 上的主终端）和串口是字符设备的常见示例。

### s (套接字)

套接字充当两个程序之间传递信息的“管道”。

> 警告 除非你清楚自己在做什么，否则请勿更改块设备、字符设备或套接字的任何权限。这可能会导致你的系统无法工作！

## 理解权限

在 `ls -l` 的输出中，文件权限紧跟在文件类型之后，以三组三个字符的形式显示，顺序为 `r`、`w` 和 `x`。以下是它们的含义。请记住，短横线 `-` 表示缺少某种特定权限。

### 文件的权限

#### r
代表读取（read），其八进制值为 4（别担心，我们稍后会讨论八进制）。这意味着具有打开文件并读取其内容的权限。

#### w
代表写入（write），其八进制值为 2。这意味着具有编辑或删除文件的权限。

#### x
代表执行（execute），其八进制值为 1。这意味着该文件可以作为执行文件或脚本运行。

因此，例如，权限为 `rw-` 的文件可以读取和写入，但不能执行。

### 目录的权限

#### r
代表读取（read），其八进制值为 4。这意味着具有读取目录内容（如文件名）的权限。但并不意味着具有读取文件本身的权限。

#### w
代表写入（write），其八进制值为 2。这意味着具有在目录中创建或删除文件、更改其名称、权限和所有者的权限。如果用户对目录具有写入权限，则该用户可以更改目录中任何文件的权限，即使用户对该文件没有权限，或者该文件属于另一个用户。

#### x
代表执行（execute），其八进制值为 1。这意味着具有进入目录的权限，而不是列出其文件的权限（这需要 `r` 权限）。

关于目录的最后一点听起来可能有点困惑。让我们假设，你有一个名为 `Another_Directory` 的目录，权限如下：

```bash
$ ls -ld Another_Directory/
--xr-xr-x 2 carol 4.0K Dec 20 18:46 Another_Directory
```

同样假设在该目录内你有一个名为 `hello.sh` 的 脚本，权限如下：

```bash
-rwxr-xr-x 1 carol 33 Dec 20 18:46 hello.sh
```

如果你是该用户并尝试列出 `Another_Directory` 的内容，你将收到错误信息，因为你对该目录没有读取权限：

```bash
$ ls -l Another_Directory/
ls: cannot open directory 'Another_Directory/': Permission denied
```

然而，用户 `carol` 拥有执行权限，这意味着只要她对相应文件拥有正确的权限，就可以进入目录。在这个例子中，用户对 `.sh` 脚本拥有完全权限，因此她可以运行脚本，即使她没有读取过包含该脚本的目录。只需要完整的文件名。

```bash
$ sh Another_Directory/hello.sh
```

## 你好，LPI 世界！

正如我们之前提到的，权限是按顺序指定的：首先是文件的所有者，然后是所有组，最后是其他用户。每当有人尝试对文件执行操作时，都会以相同的方式检查权限。首先，系统检查当前用户是否拥有该文件。否则，它会检查当前用户是否属于该文件的所有组。如果是这样，它会检查当前用户是否是其他用户。这意味着如果当前用户是文件的所有者，则权限是有效的。

## 修改权限

`chmod` 命令用于修改文件的权限，并接受至少两个参数：第一个描述要更改的权限，第二个指向目标的文件或目录。然而，权限可以用两种不同的方式描述，即“模式”。

第一种被称为*符号模式*（symbolic mode），提供了细粒度的控制，允许你添加或撤销单一权限，而不影响其他权限。另一种模式被称为*数字模式*（numeric mode），更容易记忆，并且当你一次性设置所有权限值时更快。这两种模式将产生相同的结果。例如，以下命令：

```bash
$ chmod ug+rw-x,o-rwx text.txt
```

和

```bash
$ chmod 660 text.txt
```

将产生相同的输出，即权限设置为：

```bash
-rw-rw---- 1 carol carol 765 Dec 20 21:25 text.txt
```

现在，让我们了解每种模式的工作原理。

### 符号模式

在符号模式中描述要更改的权限时，第一个字符（字符）指示你要更改的对象：用户（`u`）、组（`g`）或其他用户（`o`）。下一个字符是执行执行的操作：
- `+` 添加权限
- `-` 移除权限
- `=` 设置权限

最后，模式指定受影响的类别：
- `u` 所有者
- `g` 组
- `o` 其他
- `a` 所有

例如，`chmod u+w file.txt` 为所有者添加写入权限。

### 数字模式

在数字模式中，权限以不同的方式指定：作为三位数字值，使用八进制表示法（八进制系统）。

每个权限都有对应的值，并按以下顺序指定：首先是读取（`r`），值为 4；然后是写入（`w`），值为 2；最后是执行（`x`），用 1 表示。如果没有权限，则使用零（`0`）。因此，`rwx` 权限为 7 (`4+2+1`)，而 `r-x` 为 5 (`4+0+1`)。

权限集中的三个数字，第一个数字代表用户（`u`）的权限，第二个代表组（`g`）的权限，第三个代表其他用户（`o`）的权限。如果我们想将权限设置为 `rw------`，八进制值为：

```bash
$ chmod 660 text.txt
$ ls -l text.txt
-rw-rw---- 1 carol 765 Dec 20 21:25 text.txt
```

除此之外，数字模式下的语法与符号模式相同，第一个参数表示你想要更改的权限，第二个参数指向你将对其进行更改的文件或目录。

**提示** 如果权限值是奇数，那么该文件显然是可执行的！

应该使用哪种语法？如果你想将权限更改为特定值（例如 640 (`rw-r--`)），则建议使用数字模式。

如果你只想翻转某个特定的值，而无乎文件的当前权限，那么符号模式会更有用。例如，我只需要使用 `chmod +x script.sh` 就可以为用户添加执行权限，而无需考虑（甚至触碰）组和其他用户的当前权限。

## 修改文件所有权

`chown` 命令用于修改文件或目录的所有者。语法非常简单：

```bash
chown username:groupname filename
```

例如，让我们检查一个名为 `text.txt` 的文件：

```bash
$ ls -l text.txt
-rw-rw---- 1 carol 1881 Dec 10 15:57 text.txt
```
