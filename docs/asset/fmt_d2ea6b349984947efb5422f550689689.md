## 9.10 符号解析

这就是 `ld.so` 输出所引的链接映射。让我们看看列表中的第二个地址：

```
(gdb) x/s 0x40013580

```

下一个 `link_map` 值是另一个库：

```
(gdb) x/5x 0x400137f8
0x400137f8: 0x40016000 0x400137e0 0x400c246c 0x400139e8
0x40013808:
(gdb) x/s 0x400137e0:
"/usr/lib/libstdc++.so"
```

同时注意每个 `link map` 结构体中的第四个值 (`l_next`) 指向 `link map` 结构体。`l_prev` 指向上一个结构体。这里既有链表，也有指向这些函数的指针数组。

加载库列表由运行时链接器使用，用于跟踪进程已加载的库。
