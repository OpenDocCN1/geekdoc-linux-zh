
### if elsif else 阶梯语句
用户可以在此处从多个备选项中进行选择。`if` 语句按照列出的顺序执行。当满足一个 `if` 条件时，执行与该条件相关的语句，并跳过阶梯的其余部分。如果没有满足条件，则使用最后一个 `else` 表达式。

## 语法：

```perl
if(condition1)
{
    # 如果 condition1 为真，将执行代码。
}

elsif(condition2)
{
    # 如果 condition2 为真，则执行代码
}

elsif(condition3)
{
    # 如果 condition3 为真，则执行代码
}

...

else
{
    # 如果所有条件都为假，则执行代码
}
```

    printf "c 是 20\n";

}

else
{
    printf("c 不存在\n");
}

### unless 语句
如果条件为假，则将执行语句。在布尔上下文中，数字 `0`、空字符串 `""`、字符 `"0"`、空列表 `()` 和 `undef` 都是假的，而所有其他值均为真。

## 语法：

```perl
unless(boolean_expression)
{
    # 如果给定的条件为假，则执行
}
```

`Unless` 语句。

## 示例：

```perl

# unless 语句的程序

$c = 20;

{
    # 如果条件为假，则
    # 打印以下内容
    printf("c 不等于 20\n");
}
```

### unless else 语句
当布尔表达式为真时，`except` 后面跟着一个可选的 `else` 语句。

## 语法：

```perl
unless(booleanexpression)
{
    # 如果给定的条件为假，则执行
}

else
{
    # 如果给定的条件为真，则执行
}
```

### unless elsif 语句
`unless` 和可选的 `elsif` 可以跟在 `else` 语句之后。`unless` 语句允许我们通过 `else` 语句来测试多个条件。

## 语法：

```perl
unless(condition1)
{
    # 当 condition1 为真时执行
}

elsif(condition2)
{
    # 当 condition2 为真时执行
}

else
{
    # 当 condition 真
}
```

## 条件已验证
当我们希望循环至少执行一次时，我们使用 `do..while` 循环。由于条件是在执行循环后才验证的，因此它也被退出控制循环。

## 语法:

```
do {
    # statements Executed
} while(condition);
```

## 示例:

```perl
# program to illustrate
# do..while Loop

$c = 20;

# do..While loop

do {
    print "$c ";
    $c = $c - 1;
} while ($c > 0);
```

## until 循环
`while` 循环的反向是 `until` 循环。它接受括号中的一个条件，并且只在条件为假时运行。它本质上是重复一条指令或一系列指令，直到该条件为假（`FALSE`）。它也是一种入口控制循环，这意味着会先测试条件，然后执行块内的一系列指令。

## 语法:

```
until (condition)
{
    # Statements executed
}
```

## 示例:

```perl
# program to illustrate until Loop

$c = 20;

# until loop

until ($c < 1)
{
    print "$c ";
    $c = $c - 1;
}
```

## 嵌套循环
嵌套循环是指包含另一个循环内部的循环。`Perl` 编程支持嵌套循环。上述列出的所有循环都可以嵌套。
多个嵌套循环的 `Perl` 语法：

- 嵌套 `for` 循环

```
for (init statement; condition; increment/decrement )
{
    for (init statement; condition; increment/decrement )
    {
        # Code Executed
    }
}
```

- 嵌套 `variable_1 (@array_1)` 
```
foreach variable_2 (@array_2)
{
    # Code Executed
}
```

- 嵌套 `while` 循环

```
while (condition)
{
    while (condition)
    {
        # Code Executed
    }
}
```

- 嵌套 `do...while` 循环

```
do{
    do{
        # Code Executed
    }while(condition);
} while(condition);
```

- 嵌套 `until` 循环

```
until (condition) {
    until (condition)
    {
        # Code Executed
    }
}
```

## 示例:

```perl
# program to illustrate
# nested while Loop

$c = 5;

$d = 0;

# outer while loop

while ($c < 7)
{
    $d = 0;
    
    # inner while loop
    
    while ( $d < 7 )
    {
        print "value of c = $c, d = $d\n";
        $d = $d + 1;
    }
    
    $c = $c + 1;
    print "Value of c = $c\n";
}
```
