## ZSH-Shell 配置

Z shell 有多种初始化文件、许多配置变量以及各种 shell 选项。初始化文件与 BASH 和 TCSH shell 中的文件相似，其中一个被称为 `.zhenv`。shell 配置变量也与 BASH 和 TCSH shell 中的非常相似。Z shell 拥有一系列广泛的选项来配置你 shell 的许多方面。

### ZSH 初始化文件

系统首先读取系统 `/etc/zshenv` Z-shell 初始化文件中的命令（带有 `-f` 或 `NO_RCS` 选项时将跳过所有其他初始化文件）。然后读取用户的 `.zhenv` 文件。此文件和其他用户初始化文件（见下列表）可以位于用户的家目录，也可以位于分配给 `ZDOTDIR` 的目录。如果启动的 shell 是登录 shell，则读取 `/etc/zprofile` 文件，然后是用户的 `.profile` 文件。如果该 shell 还是交互式的，则会读取 `/etc/zshrc` 文件以及用户的 `.zshrc` 文件。如果该 shell 随后是登录 shell，则读取 `/etc/zlogin` 和用户的 `.zlogin` 文件。

```
$ZDOTDIR/.zshenv
$ZDOTDIR/.zprofile
$ZDOTDIR/.zshrc
$ZDOTDIR/.zlogin
$ZDOTDIR/.zlogout
/tmp/zsh*
/etc/zshenv
/etc/zprofile
/etc/zshrc
/etc/zlogin
```

### Shell 配置变量

可以使用以下配置变量来应用不同的设置，例如 shell 提示符或历史文件：

| 变量 | 描述 |
|---|---|
| `ARGVO` | 如果导出，其值将用作外部命令的 `argv[0]`。 |
| `BAUD` | 当前连接的波特率。 |
| `cdpath` (`CDPATH`) | 目录数组（用冒号分隔的列表），指定 `cd` 命令的搜索路径。 |
| `COLUMNS` | 此终端会话的列数。 |
| `DIRSTACKSIZE` | 目录列表的最大 size。 |
| `FCEDIT` | 内置命令 `fc` 的默认编辑器。 |
| `ignore` (`FIGNORE`) | 包含数组（用冒号分隔的列表），包含在自动补全期间要被忽略的文件后缀名。 |
| `fpath` (`FPATH`) | 目录数组（用冒号分隔的列表），指定函数定义的搜索路径。 |
| `HISTCHARS` | shell 的历史记录和词法分析机制使用的三个字符。第一个字符表示历史替换的开始（默认为 `!`）。第二个字符表示快速历史替换的开始（默认为 `^`）。第三个字符是注释字符（默认为 `#`）。 |
| `HISTFILE` | 保存历史记录的文件。 |
| `HISTSIZE` | 历史列表的最大 size。 |
| `HOME` | `cd` 命令的默认参数。 |
| `IFS` | 内部字段分隔符。默认是空格、制表符和换行符。 |
| `KEYTIMEOUT` | shell 等待另一个键按下的时间，以百秒为单位。 |
| `LINES` | 此终端会话的行数。 |
| `MAIL` | 如果设置了此参数且未设置 `mailpath`，shell 将在指定文件中查找邮件。默认是用户的系统邮箱。 |
| `MAILCHECK` | 检查新邮件的间隔（单位为秒）。 |
| `mailpath` (`MAILPATH`) | 检查邮件的目录数组（用冒号分隔的列表）。 |
| `NULLCMD` | 当命令为空时使用的命令。 |
| `PROMPT` | 匹配提示符的模式（主提示符）。 |
| `PROMPT2` | 匹配失败时的提示符。 |
| `PROMPT3` | 匹配多个结果时的提示符。 |
| `PROMPT4` | 匹配特定条件时的提示符。 |
| `READCMD` | 读取输入时使用的命令。 |
| `SAVEHIST` | 是否将历史记录写入文件。 |
| `TMOUT` | 如果非零，则在指定的秒数后退出。 |
| `TMPPREFIX` | 临时文件的前缀。 |
| `WORDCHARS` | 用于定义单词的字符。 |
| `ZDOTDIR` | 用于查找初始化文件的目录。 |

### ZSH-Shell 配置 151

| 选项 | 功能 |
| --- | --- |
| `CSH_JUNKIE_QUOTES` | 如果带引号的表达式运行到行末尾则报错；防止带引号的表达式包含未转义的换行符。 |
| `CSH_NULL_GLOB` | 如果用于文件名生成的模式没有没有匹配项，则从参数列表中删除该模式；除非命令中的所有模式均无匹配项，否则不报告错误。（覆盖 `NULL_GLOB`。） |
| `ERR_EXIT` (`-e`) | 如果命令的退出状态为非零，则执行已设置的 `ZERR` 陷获（trap）并退出。（在运行初始化脚本时禁用）。 |
| `EXTENDED_GLOB` | 将 `#`、`~` 和 `^` 字符视为文件名生成等模式的一部分。 |
| `EXTENDED_HISTORY` | 将起始和结束时间戳保存到历史记录文件（history file）中。 |
| `GLOB_DOTS` (`-4`) | 显式匹配文件名时，不需要文件名以点（`.`）开头。 |
| `GLOB_SUBST` | 使由变量替换和命令替换产生的任何字符都符合文件名生成的条件。 |
| `HIST_IGNORE_DUPS` (`-h`) | 如果命令行记录与上一个事件重复，则不将其存入历史列表。 |
| `HIST_IGNORE_SPACE` (`-g`) | 如果行中的任何命令以空格开头，则不将该命令行存入历史列表。 |
| `HIST_LIT` (`-j`) | 在编辑器中使用历史行的字面量版本。 |
| `HIST_NO_STORE` | 调用 `history` 命令时，不将其自身保存到历史记录中。 |
| `HIST_VERIFY` | 不立即执行带有历史替换的行；先将该行重新加载到编辑缓冲区。 |
| `IGNORE_BRACES` (`-I`) | 不执行大括号扩展（brace expansion）。 |
| `IGNORE_EOF` (`-7`) | 遇到文件结束（EOF）字符时不退出。 |
| `INTERACTIVE` (`-i`) | 交互式 shell。 |
