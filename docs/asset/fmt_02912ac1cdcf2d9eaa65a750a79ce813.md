
VIZ 最后评估对象的属性（properties）。属性包括对象的名称、颜色、图层分配、显示、渲染、阴影投射和运动模糊等。例如，尽管对象在创建时就获取了默认颜色和名称，但 VIZ 会最后评估它的名称和颜色。

总结对象数据流，VIZ 按照以下顺序查看对象数据：

1. 主对象
2. 修改器
3. 变换
4. 属性

对象数据流的影响起初并不明显，但在使用 VIZ 时请在心中记住这个概念。它将帮助你理解程序的行为，并让你对你的模型有更好的控制。

# 创建共享属性的克隆

修改器堆在允许你将对象塑成所需的形状方面起着重要作用，但你可以更进一步，让修改器影响多个对象而不仅仅是一个。在第 1 章中，你学习了如何复制对象，但在这里我们将学习实例化（instancing）。

当你对对象进行实例化时，你正在原始对象和副本之间建立链接。你对主对象所做的任何更改将反映在所有实例上。这是创建许多相同对象（如窗户、柱子或树）的非常强大的工具。

# 创建实例

要创建实例，首先从工具栏选择“实例化”（Instance）工具。然后，点击你想实例化的对象，并在视图中你想要放置实例的地方点击。该实例现在将与主对象链接。

如果你修改了主对象，所有实例将相应更改。然而，如果你想在不影响其他实例的情况下修改一个实例，必须先使用“变为唯一”（Make Unique）工具。这将断开链接并将实例转换为普通副本。

# 修改实例

一旦你创建了实例，就可以通过修改器堆来修改它们。例如，如果你更改了主对象的颜色，所有实例也会更改颜色。这对于保持模型模型的一致性很有用。

如果你只需要更改一个实例，可以使用之前描述的“变为唯一”工具。这将允许你修改特定对象的属性而不影响其他实例。

# 设置撤销次数

默认情况下，你可以使用撤销功能撤销多达 `20` 步。你也可以设置 VIZ 允许的撤销步数。要设置步数，请选择 `Customize` > `Preferences`。在首好设置对话框中选择“常规 (General)”选项卡，然后将“场景撤销选项 (Scene Undo Options)”设置为所需的值。保留更多的撤销步骤会消耗更多内存。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_114_0.png)

`Use Pivot Point Center` 将变换中心放置在选中对象的轴点。如果选择了多个对象，每个对象将围绕其自身的对象空间进行变换。

`Use Selection Center` 将变换中心放置在所选对象的中心。这与轴点中心的区别在于，所有对象都围绕一个共同点移动、缩放或旋转，而不是围绕各自的独立轴点。

`Use Transform Center` 将变换中心放置在世界坐标系的原点。或者，如果你正在使用网格，变换中心将位于用户网格的原点。此选项结合用户网格使用，用于相对于模型中的特定位置移动、缩放或旋转单个对象或一组对象。

# 在修改器栈中添加变换

`XForm` 修改器允许你从修改器栈对对象进行缩放和旋转。这种方法的优点是允许你在无需单独选择对象的情况下将变换工具应用于克隆对象。它还有效果是将变换工具应用于数据流中的特定位置。通常，变换在修改器之后求值，但你可以使用 `XForm` 修改器在修改器栈中插入变换。

# 使克隆对象唯一化

在某个时刻，你可能决定将一个克隆对象转换为唯一对象，使其不再与其他克隆对象联合反应。你可以使用“变为唯一性 (Make Unique)”工具来实现。

- 1. 点击“选择对象”工具，选择最左侧的实例克隆。
- 2. 确保命令面板中选中了“修改 (Modify)”选项卡，并且修改器栈中高亮了 `Taper` 修改器。
- 3. 点击修改器栈下方工具栏上的“变为唯一性”按钮。选中的窗口现在是一个独立对象，不再与其他克隆连接。
