# 布尔代数

数学的一个分支，最初由英国数学家乔治·布尔（George Boole）在 1850 年左右系统性地开发。他的研究结果与集合和概率有关。布尔代数也用于逻辑理论，其应用领域是计算机设计。参见数字计算机。

布尔代数中最基本的部分是描述集合的子集。基本运算是两个集合 `S` 和 `T` 的交集或共同部分，它们的并集 `S U T` 以及任何此类集合 `S` 的补。这些运算满足许多定律，如等式 (1)、(2) 和 (3)所示。

```
S ∩ T = S ∩ T
S(T ∪ U) = (S ∩ T)(S ∩ U)
S ∪ U ∪ T = S ∪ U ∪ T
S(T ∪ U) = (S ∪ T)(S ∩ U)
S(U ∩ T) = (S ∪ U)(S ∩ T)
T(U ∩ S) = (T ∪ U)(T ∩ S)
```

如果 `O` 表示空集，`I` 是所考虑的所有元素的集合，那么等式 (4)所示的定律为：

```
O ∩ S = O  O ∪ S = S
I ∩ S = S  I ∪ S = I
```

这些定律是基础性的。所有的减法代数都可以从它们推导出来。在布尔代数中观察到，共同定律下的运算组合是有效的，而不仅仅是上述指定的定律。某些定律适用于所有命题或其组合，而这些命题是复杂的。参见逻辑。

布尔强调了布尔代数与普通代数之间的代数关系。如果 `S` 被视为顺序规则，而 `S'` 对应 `1 - S`，上述内容通过许多方式进行了说明。然而，第一个是由马歇尔·亨廷顿（Marshall Huntington）清楚展示的。具体来说，给出了 `S ∩ T'` 的第一个例子。利用 `S ∩ T'` 的普通 `Sn` 类似于使用 `St`。布尔代数指的是布尔环，其中所有元素都满足 `x² = x`。

在 H. A. Newman 开发了一种现代泛化方法，其中包含了布尔代数和布尔环。这种泛化基于等式 (5) 和 (6) 所示的定律。从这些定律可以推导出交换律和结合律 (1) 和 (2)。

```
a(b+c) = ab+ac  ab+bc = bc
a1+a = a  a+0 = a  a\a' = 1
```

此类文献引出了抽象布尔代数的概念，定义为通过对 (1) 到 (4) 列出的等式进行操作形成的符号集合。在短语中，布尔代数指的是抽象布尔代数。

有限（抽象）布尔代数的类很容易描述。每个此类代数对于某些情况，没有负整数 `n`，具有 `n` 个元素，且所有子集都同构于在交集、并集和补运算下的数字 `1, n` 全集代数。

无限布尔代数的理论要深得多；它涉及元素的整个理论。一个重要结果是，每个布尔代数都同构于集合 `I` 的适当子族，该族可以通过交集、并集和补形成。然而，任何此类有限或无限布尔代数的元素集都是同构的。

# 硼砂

一种化学式为 `MgBO3Cl` 的矿物发现于德国、英国和美国，通常位于无水石膏的沉积物中以及海洋钾盐中。该化学物质由天然硼酸钙组成，用 `Fe²` 或 `Mn²` 替换 `Mg²` 形成铁硼酸或锰硼酸。

莫氏硬度为 7-7，呈柱状。其衍生物是硬度为 3.5-3.7 的晶体，具有金属光。它是玻璃质的，接近金刚质。硼砂在石头中呈无色到白色、绿色，罕有粉红色（洋红色）。它是立方体体且不具解理。

一类硼和氢的化合物，通常称为氢化物。由硼氢化合物形成，例如三氯化硼 (`BCl3`) 和二氮二硼 (`B2H10`)。简单的硼烷是二氢硼 (`B2H6`)；其他分子量较高的等于元素数量的，由硼氢化合物 (`BH3`) 产生。某些硼烷，如 `BH4` 和 `BH5` 是已知的，因为可以被制备，但是在硼的加合物中形成的。硼烷及其衍生物预测的分子结构处于高能状态。硼命名法被用于指定硼原子的数量，并在前缀中使用数字指示氢原子的数量。硼烷是通常具有挥发性、高活性的物质，其活性随分子量的增加而降低。由于硼烷与水反应，它们是易反应的。
