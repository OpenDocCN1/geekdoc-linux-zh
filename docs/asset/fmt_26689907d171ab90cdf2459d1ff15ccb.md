## Kermit

一种异步通信协议，使得通过电话系统无错误传输程序文件变得更容易。它由哥伦比亚大学开发并归入公共领域，被学术机构使用。与 XMODEM 不同，Kermit 可以在每字节 7 位的大型机系统上实现。参见通信协议。来自 QUID `http://www.ldp.org/LDP/Linux–Dictionary/html/index.html`

在操作系统中，内核的核心部分位于内存中并执行最基本的操作系统任务，例如处理输入/输出操作和管理内部内存。来自 QUID `http://www.ldp.org/LDP/Linux–Dictionary/html/index.html`

## kernel

操作系统的一部分，实现了与硬件的接口和资源共享。`http://www.ldp.org/LDP/Linux–Dictionary/html/index.html`

## Kernel (内核)

操作系统的核心，所有其他组件都依赖于它。内核管理低级硬件交互和资源共享，包括内存分配、输入/输出和安全。来自 I-less `http://www.ldp.org/LDP/Linux–Dictionary/html/index.html`

## kernel

操作系统的核心。内核对所有事务具有完全的控制权。当你的计算机崩溃时，意味着内核崩溃了。如果只有一个程序崩溃，系统的其余部分将继续运行，内核本身并没有崩溃。内核的设计旨在协调系统的不同组件，例如驱动器、网络、键盘和运行中的程序。关键点：内核运行是为了安全，防止一个程序入侵同一系统上的其他程序。除了旧的 Mac 和 Windows 之外，所有系统都不提供这种级别的安全性。关键点：“Linux”一词实际上指的就是内核。我们在 Linux 发行版中看到的实际上是内核加上构建在其之上的一系列 UNIX 类应用程序。对比：你的软件有两种运行方式。内核模式在内核上下文中运行，不仅包括内核还包括驱动程序。用户模式是软件运行的环境。关键在于，当你运行在内核模式时，你可以访问系统且无人能阻止你。然而，当你运行在用户模式（未未登录 root）时，内核对你的活动没有安全限制。这意味着如果你攻破了一个普通的 HTTP 服务器，你可能实际上无法破解整个机器。然而，较新版本的 Linux 出于性能考虑将某些内容放入内核。此类服务中被利用的漏洞将导致整个机器被攻破。来自 Hacking–Linux `http://www.ldp.org/LDP/Linux–Dictionary/html/index.html`

## kernel

操作系统的基础部分，处理资源管理、进程控制和输入/输出 `I/O` 支持。来自 Linux Guide @FirstLinux `http://www.ldp.org/LDP/Linux–Dictionary/html/index.html`

## K

内核软件包包含 Linux 内核 `vmlinux`，它是 Red Hat 操作系统的核心。内核处理操作系统的基本功能：内存分配、进程分配、设备输入和输出等。来自 Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## Kernel headers (内核头文件)

头文件定义了构建大多数程序所需的结构和限制。重新编译内核也需要头文件。来自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## kernel-source (内核源码)

`kernel-source` 软件包包含内核的源代码。构建大多数 C 程序需要这些源文件，因为它们依赖于源码中定义的常量。源码也可以用于构建针对你的硬件进行调优的自定义内核。来自 Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## key (密钥)

在加密中，加密/解密所需的值通常是一个数字或短字符串。对比：人们混淆密钥和密码之间的区别。密钥是一个很大的数字，而密码是一系列字母（可能还有数字和标点符号）。由于加密仅使用密钥，密码通常通过适当函数转换为数字。对比：密钥有两种类型：对称密钥用于加密和解密是相同的；非对称对，其中一个密钥用于加密，另一个用于解密。对比：网络浏览器中 40 位和 128 位加密的区别问题。答案是破解加密和读取明文最明显的方法是尝试所有密钥。40 位密钥有一万亿 `1,000,000,000` 种组合。含义：平均人只需要几周就能尝试所有组合。如果你的计算机可以跨线嗅探任何消息，浏览器应该管理它。密钥长度每增加一位，破解时间将增加一倍。因此，如果破解一个 40 位密钥需要一周，那么破解一个 128 位密钥将需要是 40 位密钥的 `$2^{88}$` 倍（即 309,485,221,345,781 倍）。示例：下表显示了 2000 年左右破解密钥的难度。

| 难度 | 计算机 |
| :--- | :--- |
| 硬币和铅笔谜题（周日） | 16 |
| 桌面电脑 | 56 |
| 自定义硬件 | 64 |
| 十万台机器 | 80 |
| 政府机构（NSA, CIA） | 128 |
| 当前时间不可破解 | 256 |
