## 隔离特定服务

作为一个任何优秀的端口扫描器，扫描特定端口的能力至关重要。确定网络上所有系统是否具有一组标准服务或特定功能的方法是针对特定端口扫描网络。例如，假设我们想确定 216.155.202.0 网络上的所有系统是否支持某种 SNMP 代理。由于 SNMP 可能存在安全漏洞，根据配置，应该扫描网络以检测支持该协议的情况。命令为：

```
# nmap -p 161 -sU -o results 216.155.202/24
```
