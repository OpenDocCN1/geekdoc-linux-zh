### dgipsip
使用互联网 GPS 信号纠正 GPS 位置，这是一项将已知位置的修正因子应用到 GPS 信号中的技术。这可以显著减少 GPS 位置的不确定性。通常，修正信号是使用卫星接收台获取的：`dgipsip` 允许你通过 TCP/IP 接收 GPS 信号，并将其发送到连接到串口的 GPS 设备。来自 Debian 3.0r0 apt `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### dhcpclient
DHCP（动态主机配置协议）是一种允许 IP 网络上的单个设备从 DHCP 服务器获取其自身的网络信息（IP 地址、子网掩码、广播地址等）。DHCP 的总目的是更方便地管理大型网络。在你的网络上使用 DHCP，安装 DHCP 服务器（或中继代理），并使用 DHCP 客户端守护进程。`dhcpclient` 包提供了 ISC DHCP 客户端守护进程。来自 Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
