
- 第一个计算机防火墙是一个具有两个不同网络连接的非路由主机。一个网络连接到互联网，另一个连接到私有局域网。要访问私有网络，你必须登录防火墙（`Unix`）服务器。然后你使用系统资源访问互联网。例如，你可以使用 `X-windows` 在防火墙系统上运行 `Netscape` 浏览器，并将显示在你的工作站上。由于浏览器在上面运行，它可以访问两个网络。这种双宿主系统（具有两个网络连接的系统）的设置如果你**信任所有**用户，那是非常棒的。你可以简单地设置一个 `Linux` 系统，并给每个需要访问互联网的人提供一个账户。在这种设置下，只有私有网络上的计算机知道外部世界的任何信息，那就是防火墙。没有人可以将文件下载到防火墙，然后从防火墙下载到你的工作站。

大注：99% 的入侵始于获取对被攻击系统的层级访问。由于这个原因，我不推荐这种防火墙。它也非常有局限性。`Firewall-HOWTO` `http://www.tdp.org/LDP/Linux-Dictionary/html/index.html`

## wall (墙)

防火墙旨在防止火灾蔓延的结构。建筑防火墙由砖墙组成，完全划分了建筑的区域。在汽车中，防火墙是隔离开引擎和客舱的金属墙。互联网防火墙旨在通过拒绝所有互联网访问来保护你的局域网成员免受追溯。

## Flat address space (扁平地址空间)

一种组织计算机内存的方法，操作系统可以无限制地分配部分内存。扁平地址空间的对面是 `MS–DOS` 和 `Microsoft Windows 3.1` 的分段内存架构，它将内存分为 64K 的区域（称为段）。分页内存空间设计更高效，因为处理器不需要将每个内存地址映射到 64K 段，但这种设计要求使用 32 位内存地址。采用 32 位内存地址的 `Microsoft Windows 95` 为你的应用程序创建了扁平地址空间。来自 `QUEDIC` `http://www.ldp.org/LDP/Linux-Dictionary/index.html`
