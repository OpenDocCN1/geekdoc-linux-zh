## 18.4.6 DMA 环形缓冲区初始化

再次从以太网驱动程序的示例（cs 18.5, 行 401–411），我们看到 Rx 描述符在模块初始化时被初始化。这是一个类型为 `etrax_eth_desc`、长度为 `NR_OF_RX_DESC` 的 `RxList` 数组。这些描述符管理接收网络数据包的 DMA 存储。我们看到数组的连续元素通过每个数组 `desc` 字段（类型为 `etrax_dma_desc`）的 `next` 字段连接在一起。我们初始化大小为 `MAX_MEDIA_DATA_SIZE` 的每个缓冲区 `skb`。为接收 DMA 描述符初始化网络缓冲区，因为接收到的帧直接 DMA 到缓冲区中。

这种安排使得 `RxList` 数组看起来像环形链表。我们需要做的最后一步是初始化设备的 `MyNextRxDesc`、`MyLastRxDesc` 和 `MyPrevRxDesc`（cs 18.7）。`MyNextRxDesc` 指向中断处理程序读取下一帧的描述符，这意味着它指向下一个接收到尚未从设备 DMA 队列中取出处理的数据包。`MyLastRxDesc` 是 DMA 环形缓冲区中的最后一个描述符。该描述符的 `d_eol` 控制位始终被设置为（`myLastRxDesc<-desc.ctrl`）。`MyPrevRxDesc`指向最后一个处理的描述符，将其标记为环形缓冲区的结束。最后，初始化 Rx 描述符后，它将如图 18.11 所示。
