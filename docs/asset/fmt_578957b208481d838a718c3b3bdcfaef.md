```bash
if (( len > max_len )); then

  max_word="$1"
fi
echo "$1: '$max_word' ($max_len characters)"
```

在这个示例中，我们寻找文件中找到的最长的字符串。当在命令行上给出一个或多个文件名时，该程序使用 `strings` 程序（包含在 GNU binutils 软件包中）在每个文件中生成可读的文本“单词”列表。`for` 循环处理每个单词，并确定当前单词是否为为止发现的最长单词。当循环完成后，将显示最长的单词。

这里需要注意的一点是，与我们通常的做法不同，我们没有将命令替换 `$1` 包在双引号中。这是因为我们实际上希望通过单词拆分（word splitting）来获取我们的列表。如果我们给命令替换加上了引号，它将只会产生一个包含文件中所有字符串的单个单词。这并不是我们想要找的结果。

如果省略了 `for` 命令中可选的 `in`，它将默认处理位置参数。我们将修改最长单词的脚本来使用这种方法：

```bash
#!/bin/bash
# longest-word2: find longest string in a file
for i; do
  if [[ -r "$i" ]]; then
    max_word=
    max_len=0
    for j in $(strings "$i"); do
      len=$(echo -n "$j" | wc -c)
      if (( len > max_len )); then
        max_len="$len"
        max_word="$j"
      fi
    done
    echo "$i: '$max_word' ($max_len characters)"
  fi
done
```

我们可以看到，我们已经将最外层的循环改为使用 `in` 代替 `while`。通过省略 `for` 命令中的单词列表，而是使用了位置参数。在循环内部，变量 `i` 之前的实例已更改为变量 `j`。同时也消除了 `shift` 的使用。

### 为什么用 i?

你可能注意到在之前的每个 `for` 循环示例中都选择了变量 `i`。为什么呢？实际上没有特殊原因，只是传统如此。在 `for` 中使用的变量可以是任何有效变量，`i` 是最常见的，其次是 `j` 和 `k`。

这种传统的起源于 Fortran 编程语言。在 Fortran 中，以 i, j, k 和 m 字母开头的未声明变量会自动类型为整型，而以任何其他字母开头的变量则类型为实数型（带小数部分的数字）。这种行为导致程序员使用 i, j, 和 k 作为循环变量，因为当需要临时变量（循环变量通常就是临时变量）时，使用它们更少占用资源。

它还导致了以下基于 Fortran 的神秘主义：“上帝是真实的，除非声明为整数。”

### —C\013 语言形式

最近版本的 `bash` 添加了命令语法的第二种形式，类似于在 C 编程语言中找到的形式。许多其他语言也支持这种形式。

```bash
for (( expression1; expression2; expression3 )); do
  commands
done
```

这里的 expression1、expression2 和 expression3 是算术表达式，而 commands 是在循环的每次迭代中要执行的命令。
从行为上说此，这种形式等同于以下结构：

```bash
(( expression1 ))
while (( expression2 )); do
  commands
  (( expression3 ))
done
```

expression1 用于初始化循环条件，expression2 用于确定循环何时结束，而 expression3 在循环的每次迭代结束时执行。
这是一个典型的应用：

```bash
#!/bin/bash
# simple_counter: demo of C style for command
for (( i=0; i<5; i=i+1 )); do
  echo $i
done
```

当执行时，它会产生以下输出：

```
me@linuxbox ~]$simple_counter
0
1
2
3
4
```

在这个示例中，expression1 将变量 `i` 初始化为值 0，expression2 允许只要 `i` 的值小于 5 循环就会继续，而 expression3 在每次循环重复时将 `i` 的值加 1。

C 风格的 `for` 在任何需要数值序列时都很有用。我们接下来的两个章节中看到它的几种应用。

## 总结

有了我们对 `for` 命令的了解，我们现在将对 `sys_info_page` 脚本进行最后的改进。目前，`report_home_space` 函数看起来如下：

接下来，我们将重写它，为每个用户的主目录提供更多细节，并包含每个目录中的文件和子目录的总数。

```bash
report_home_space () {
  local format="%8s%10s%8s\n"
  local i dir_list total_files total_dirs total_size user_name
  if [ "$(id -u)" -eq 0 ]; then
    dir_list="/home/*"
    user_name="All Users"
  else
    dir_list="$HOME"
    user_name="$USER"
  fi
  for i in $dir_list; do
    if [ -d "$i" ]; then
      total_files=$(find "$i" -maxdepth 1 -type f | wc -l)
      total_dirs=$(find "$i" -maxdepth 1 -type d | wc -l)
      total_size=$(du -sh "$i" | cut -f1)
      printf "$format" "$user_name" "$total_files" "$total_dirs" "$total_size"
    fi
  done
}
```

## 参数扩展

虽然参数扩展在第7章提到过，但我们没有详细介绍，因为那时关注的是未设置变量。然而，shell提供了许多形式。参数扩展允许我们在变量转换为字符串之前对其转换。

## 简单参数

参数扩展的最简单形式体现在变量的普通用法中。这是一个示例：

这变为变量 a 所包含的内容。简单参数也可以用大括号包围。

这对于扩展没有影响，但当变量与其他文本相邻时，这是必要的，否则可能会混淆 shell。在这个示例中，我们尝试通过在变量名后附加字符串 _file 来创建一个文件名：

```bash
a="foo"
echo "$a_file"
```

如果我们执行这一系列命令，结果将为空，因为 shell 将尝试扩展名为 a_file 的变量而不是 a。这个问题可以通过给“真正的”变量名加上大括号来解决。

```bash
a="foo"
echo "${a}_file
```

## 管理空变量的扩展

几种参数扩展用于处理不存在和空的变量。这些扩展对于处理位置参数和为参数分配默认值非常方便。第一个为未设置参数提供默认值。

${parameter:-word}

如果参数未设置（即不存在）或为空，此扩展的结果为 word 值。如果参数未设置，扩展的结果为参数的值：

```bash
foo=""
echo ${foo:-substitute value if unset}
```

```bash
foo="bar"
echo ${foo:-substitute value if unset}
```

如果 `parameter` 未设置或为空，此扩展的结果为 `word` 的值。此外，`word` 的值会被赋值给 `parameter`。如果 `parameter` 不为空，则扩展的结果为 `parameter` 的值。

```
me@linux -j foo=
me@linux -j echo $(foo:="default value if unset")
default value if unset
me@linux -j echo $foo
default value if unset
me@linux -j foo-bar
me@linux -j echo $(foo:="default value if unset")
bar
me@linux -j echo $foo
bar
```

## 注意

位置参数和其他特殊参数不能通过这种方式赋值。

如果所需的参数未设置或为空，此扩展将终止脚本。
${parameter:word}

如果 `parameter` 未设置或为空，此扩展会导致脚本带错误退出，`word` 的内容会被发送到标准错误输出。如果 `parameter` 不为空，则扩展的结果为 `parameter` 的值。

```
me@linux -j foo=
me@linux -j echo $(foo:"parameter is empty")
bash: foo: parameter is empty
me@linux -j echo $?
1
me@linux -j foo=bar
me@linux -j echo $(foo:"parameter is empty")
bar
me@linux -j echo $?
```

此扩展为非空参数替换值。
$(parameter:+word)

如果 `parameter` 未设置或为空，此扩展的结果为空空。如果 `parameter` 不为空，则用 `word` 的值替换 `parameter`；但 `parameter` 的值不会改变。

```
me@linux -j foo=
me@linux -j echo $(foo:+"substitute value if set")
```

```
me@linux -j foo=bar
```

```
$me@linux - echo ${foo:+"substitute value if set"}
substitute value if set
```
