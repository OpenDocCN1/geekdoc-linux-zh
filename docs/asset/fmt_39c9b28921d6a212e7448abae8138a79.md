### X-writer software

X-CD 是一个完整的 X 刻录软件，是 cdtools-0.93 的继任者。它是一个类似 cdwrite 0.98 等程序的前端。

- 基于 GTK 界面，而不是 TLK/TK
- 支持大多数数据/混合模式/音频-CD（实时刻录）
- 重新录音频-CD（实时刻录）
- 创建你自己的音频-CD（支持一次性刻录）
- 支持 SCSI/ATAPI/并行刻录机
- 不同的国际语言
- CDB 查询和 CD 文本
- 运行在大多数 Unix 操作系统上（主要平台：Linux 和 Solaris）

来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

### xclip

X 选择区域（Selections）的命令行接口，这是一个设计用于任何具有 X11 实现的系统上的命令行工具。它提供了从命令行访问 X 选择区域（“剪贴板”）的接口。它可以从文件中读取数据并将其放入 X 选择区域中以便粘贴到其他应用程序中。xclip 还可以将 X 选择区域打印到 stdout，然后将其重定向到文件或其他程序。来自 Debian 3.0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html.index`
