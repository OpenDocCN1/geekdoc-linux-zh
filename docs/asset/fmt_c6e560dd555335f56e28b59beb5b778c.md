
进入`/path/to/xxx`目录，找到`xxx.json`。

`)| sendmail -t`

```
sendmail
```
的`-t`标志告诉程序为目标电子邮件地址直接发送消息本身。反引号的内容永远不会出现在命令行的视线中，因为在`sendmail`队列系统中它被解释为无效的电子邮件地址（然后安全地存入日志文件）。

另一个安全机制要求从Web浏览器到服务器的信息必须编码；例如，反引号实际上会以`%60`发送到服务器（并交给CGI脚本），这完全可以被shell脚本安全地处理而无任何危险。

本章中所有CGI脚本的一个共同特征是，它们对编码字符串的解码很少：空格在传输时被编码为`+`，因此将它们切换回空格是安全的。电子邮件地址中的`@`字符被发送为`$40`，因此它也同样被安全地转换了回来。除了这些之外，清洗后的字符串可以安全地扫描是否存在`%`，如果遇到则生成错误。这在脚本`#72《处理联系表单》`中使用的代码中强调了这一点。

最终，高度复杂的网站将使用比shell更健壮、更强大的工具，但凭借书中的许多解决方案，一个20到30行的脚本通常就足以验证一个想法、证明一个概念，或以快速、可移植且合理的方式解决简单问题。

# 70 记录 Web 事件

基于shell的CGI脚本的一个酷炫用法是使用包装器（wrapper）来记录事件。假设我想在我的网页上放置一个Yahoo!搜索框，但我不想直接将查询内容发送给Yahoo!，而是想记录它们，以建立一个关于人们从我的站点看到了什么的数据库。

首先，关于HTML和CGI：网页上的输入框是在表单（forms）内部创建的，表单通过发送表单`action`属性的值来处理用户信息。任何网页上的Yahoo!查询框都可以简化为以下内容：

```html
<form method="get" action="http://search.yahoo.com/bin/search">
Search Yahoo:
<input type="text" name="p">
```

No Starch Press, Copyright © 2004 by Dave Taylor

```html
<input type="submit" value="search">
</form>
```

然而，我们并不是直接将搜索模式交给Yahoo!，而是给它提供一个运行在我们自己服务器上的脚本，该脚本将记录该模式并将查询重定向到Yahoo!服务器。表单的变化仅发生在一个微小的地方：`action`字段变成了本地脚本，而不是直接调用Yahoo!。

```html
<!-- 如果脚本放置在 /cgi-bin/ 或其他位置，调整 action 值 -->
<form method="get" action="log-yahoo-search.cgi">
```

`log-yahoo-search.cgi`脚本非常简单，正如你将看到的那样。

## 代码

```sh
#!/bin/sh
```

```sh
# log-yahoo-search - 给定一个搜索请求，记录模式，然后
# 将序列传递给真实的 Yahoo! 搜索系统。
# 确保目录路径和列为 'logfile' 的文件对 nobody 用户
# 或任何你作为 Web 服务器 uid 的用户是可写的。
logfile=/var/www/wicked/scripts/searchlog.txt
```

```sh
if [ ! -f $logfile ]; then
touch logfile
chmod a+rw $logfile
fi
```

```sh
if [ -w $logfile ]; then
echo "$(date): \$QUERY_STRING" | sed 's/p=\//g;s/+/g' >>$logfile
echo "Location: http://yahoo.com/bin/search\$QUERY_STRING"
echo ""
fi
```

```sh
exit 0
```

## 工作原理

脚本中最显著的元素与Web服务器和Web客户端如何通信有关。输入到搜索框中的信息作为`QUERY_STRING`发送到服务器，它通过将空格替换为`+`号并将其他非字母数字字符替换为适当的字符序列进行编码。然后，当记录搜索模式时，所有的`+`号都会安全且简单地转换回空格，但其他情况下搜索模式不会被解码，以确保用户不会尝试任何棘手的破解手段。（更多细节请参见本章的引言。）

一旦记录，网页浏览器将通过`location:`HTTP头部值重定向到实际Yahoo!搜索页面。请注意，只需追加`?$QUERY_STRING`就足以将搜索模式（无论其简单还是复杂）传递到其最终目的地。

此脚本产生的日志文件中每个查询字符串前都有当前日期和时间，该数据文件不仅显示了搜索内容，还可以按一天的时间、星期、月份等进行分析。在繁忙的站点上，这个脚本可以使用大量信息！
