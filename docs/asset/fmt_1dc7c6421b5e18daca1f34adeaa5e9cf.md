
# 指定颜色温度和光强

光分布对照明方案的质量有很大影响，但颜色也起着重要作用。VIZ 让你可以控制灯光的色温度，或者你可以从一组预定义的颜色解决方案中选择。你可以在`强度/颜色/分布`（`Intensity / Color/Distribution`）展开节的`颜色`（`Color`）组找到该选项。

例如，一个典型的 100 瓦白炽灯将产生 1,750 流明。当你查看灯具规格时，还会发现以坎拉（或 `cd`）为单位额定功率的灯光。测量强度的第三种方法是勒克斯，它考虑了与光源的距离。

这三个不同的单位表示了光强的不同方面。流明表示光源的总强度。坎拉表示到某点的光强，而不是整体光输出。勒克斯测量距离光源特定距离的区域内的强度。

你可以从灯具制造商处获得强度规格，许多网站提供各种类型灯光的通用强度值。表 11.2 列出了一些较常见的光强。你可以为任何光度灯具在`强度/颜色/分布`（`Intensity/Color/Distribution`）展开节中指定光强参数。

# 指定线性和面积尺寸

两种灯类型，线性和面积，超出了单点。由于这种原因，线性和面积灯具有允许您设置的。当你选择线性灯时，你会在命令面板中看到一个名为 `Linear Parameters` 的展开节。同样，面积灯提供了允许您设置长度和宽度的。对于面积灯，你需要一个。除了这些设置，你将注意到与这些灯相关的。例如，如果你有一个靠近面积灯的室内场景，你应该指定一个面积投影。你可以从 `Modes` 下拉列表中选择一个。

# 理解动态范围

你已经在 VIZ 中尝试了一些动态范围，即使你没有意识到自己在做调整。在`环境和效果`（`Environment and Effects`）对话框中，你使用了 `Brightness` 来控制。

| 对数曝光控制参数 |
| :--- |
| 亮度 (`Brightness`): 25.0 | 颜色校正 (`Color Correction`): |
| 对比度 (`Contrast`): 10.0 | 去饱和低水平 |
| 中调 (`Mid Tones`): 1.0 | 影响间接 |
| 物理缩放 (`Physical Scale`): 1500.0 | 室外日光 |

要理解动态范围，考虑传统的摄影很有帮助。相机的快门速度和镜头的光圈用于控制快门开启期间到达胶片的光量。在晴亮的阳光下，快门速度将非常快，以捕捉图像而不过度曝光。相反，摄影师在黄昏时可能需要使用三脚架，因为曝光时间必须足够长才能曝光胶片。为了让胶片适应真实世界的巨大动态范围，开发了许多方法。

我们的眼睛瞳孔会收缩，许多其他机制控制进入视网膜的光量。人类可以区分比我们感知的最亮光还要亮十亿倍的光。我们感知可见光的宽动态范围，但这仍然是电磁光谱中的一个窄范围。

电脑显示器显示的白色只比黑色亮 100 倍。因此，显示器的动态范围非常有限。当我们根据真实光度光源进行辐射测量模拟时，光数据涵盖了适用于人类感知的宽动态范围。遗憾的是，我们必须将这些数据显示在能力有限的电脑显示器上，丢失了大量信息。为了补偿，我们在 VIZ 中使用曝光控制将巨大的光数据与显示器能够显示的有限动态范围匹配。

正如你将在第 12 章中学习到的，`HDRIs`（高动态范围图像）是一种存储具有更多代表光强度范围图像的方法。`HDR` 中的所有数据无法一次显示在显示器上，因为这将超过显示器的狭窄动态范围。然而，`HDRI` 数据可以在辐射测量模拟中更准确地使用，并可以重复用在烛光场景和日光场景中。

曝光控制是 VIZ 穿过可见光大动态范围的方式，并将其映射到显示器可以显示的内容。VIZ 中有多种曝光控制算法供选择。让我们探索一下选项。

按下键盘上的 8 或选择 `渲染`（`Rendering`） ➤ `环境`（`Environment`），并展开`曝光控制`（`Exposure Control`）面板中的下拉列表，以探索各种曝光控制算法。

`自动曝光控制` (`Automatic Exposure Control`) 正如其所示，该算法对图像进行原子采样并构建直方图，以为渲染图像提供合理的色彩分离。它擅长显示静态图中的极暗光照以及低动态范围的场景。在动画中绝不应使用自动曝光控制，因为每一帧都会有不同的直方图，导致运动闪烁。

# 曝光控制与 MENTAL RAY

自动曝光控制不适用于 `mental ray`（详见第 12 章）。

`对数曝光控制` (`Logarithmic Exposure Control`) 这是你的通用型曝光控制算法，适用于静态图和动画。它最适合具有高动态范围的场景（图像中既有非常亮的区域也有非常暗的区域）。曝光控制将来自辐射解决方案（具有高动态范围）的数据映射到显示器上的 `RGB` 值（动态范围有限）。图 11.34 显示了对数曝光控制参数面板。以下是它的控制项：

`亮度、对比度和中间色调` (`Brightness, Contrast, and Mid Tones`) 这些是主要控制项，可以在视口中提供视觉反馈，而无需渲染或重新计算辐射解决方案。

`物理比例尺` (`Physical Scale`) 使用此参数为标准灯具指定物理比例尺。通常在辐射渲染中你会使用光度光源，但如果你有使用标准灯具的遗留场景，则提供了此功能。单位是坎拉（`candelas`）。将值设置为场景中最亮的光源，以为你的辐射解决方案提供真实性基础。

# 物理比例尺参数

每个标准灯具的`倍数`（`Multiplier`）参数都会乘以`物理比例尺`（`Physical Scale`），以得到坎拉为单位的光强。光度光源不受物理比例尺参数的影响。

`色彩校正` (`Color Correction`) 你放入颜色色块的颜色在渲染时将是纯白色。当勾选此参数时，所有其他颜色都会发生偏移以补偿。如果需要，色彩校正可以消除来自灯具的色偏。

`降低低级饱和` (`Desaturate Low Levels`) 此功能模拟了眼睛在昏暗光照条件下从锥细胞视觉切换到杆细胞视觉的过程。你看到非常暗的区域没有任何颜色（去饱和），因为你用眼睛中的杆细胞感知这些光照信息，而只有强度能感知到它。这种功能在场景照度低于 50 `lux` 的昏暗区域非常明显。

`仅影响间接` (`Affect Indirect Only`) 如果你在辐射渲染中使用标准灯具，请开启此项。勾选此项后，将覆盖`物理比例尺`参数，灯具的渲染方式类似于扫描线渲染。这有助于比例尺渲染和辐射渲染之间的比较。

`室外日光` (`Exterior Daylight`) 勾选`日光曝光`（`Daylight Exposure`）以补偿户外场景的极端强度。你可以像通常一样调整`亮度`、`对比度`和`中间色调`，但所有内容移动了几个数量级，以防止过度曝光。
