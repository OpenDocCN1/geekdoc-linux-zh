
| help | 解析选项时打印帮助。仅当你想通过比标准 `-h` 或 `--help` 不同的选项显示帮助时才需要此。 |

| version | 打印传递给 `OptionParser()` 的版本号（如果有）。仅当你想使用比标准 `-v` 或 `--version` 不同的选项显示版本信息时。 |

| 关键字参数 | 说明 |
|---|---|
| `callback_args` | 提供给通过 `callback` 参数指定的调用函数的可选位置参数。 |
| `callback_kwargs` | 提供给通过 `callback` 参数指定的调用函数的可选关键字参数。 |
| `choices` | 字符串列表，指定所有可能的选项值。用于选项具有有限值集的情况（例如 `['small', 'medium', 'large']`）。 |
| `const` | 存储在 `store_const` 动作中的的常量值。 |
| `default` | 如果未提供，则设置选项的默认值。默认情况下，默认值为 `None`。 |
| `dest` | 设置在解析期间存储选项值的属性名称。该名称派自选项名称本身。 |
| `help` | 此特定选项的帮助文本。如果不提供，该选项将列在帮助信息中但不带描述。可以使用特殊值 `optparse.SUPPRESS_HELP` 来隐藏选项。特殊值 'default' 的替换部分指定了打印帮助信息时使用的选项参数名称。 |
| `nargs` | 为期望参数的动作指定选项参数的数量。默认值为 1。如果使用大于 1 的数字，参数将被收集到一个元组中，并在处理参数时使用。 |
| `type` | 指定参数的类型。有效类型为 'string','int','long','choice','float' 和'complex'。 |

`p.disable_interspersed_args()`

不允许简单选项与位置参数混合。例如，如果 `-x` 和 `-y` 是不带参数的选项，则参数不能出现在任何参数之前（例如 `prog -x y arg1 arg2 arg3`）。

`p.enable_interspersed_args()`

允许选项与位置参数混合。例如，如果 `-x` 和 `-y` 是不带参数的简单选项，它们可以与参数混合，如 `prog -x arg1 arg2 -y arg3` 所示。这是默认行为。

`p.parse_args(arglist)`

解析命令行选项并返回一个元组 `(options, args)`，其中 `options` 是一个包含所有选项值的对象，而 `args` 是所有剩余位置参数的列表。`options` 对象将所有数据存储在与选项名称匹配的属性中。例如，选项 `--output` 的值将存储在 `output` 中。属性名称可以通过之前描述的 `dest` 参数设置。默认情况下，参数从 `sys.argv[1:]` 获取。然而，也可以作为可选参数 `arglist` 提供不同的参数源。

`p.set_defaults(dest=value, ... dest=value)`

设置特定选项目的地的默认值。你只需提供指定要设置目的地的关键字参数即可。参数名称应与之前声明的 `add_option()` 中使用 `dest` 参数指定的名称匹配。

`p.set_usage(usage)`

更改 `--help` 选项产生的文本中显示的用法。

# 示例

```python
# foo.py
import optparse
p = optparse.OptionParser()

# 一个简单的选项，不带参数
p.add_option("-t", action="store_true", dest="tracing")

# 一个接受字符串参数的选项
p.add_option("-o", "--outfile", action="store", type="string", dest="outfile")

# 需要整数参数的选项
p.add_option("-d", "--debuglevel", action="store", type="int", dest="debug")

# 具有几个选择的选项
p.add_option("--speed", action="store", type="choice", dest="speed",
             choices=["slow","fast","ludicrous"])

# 接受多个参数的选项
p.add_option("--coord", action="store_const", type="int", dest="coord", nargs=2)

# 一组控制共同目的地的选项
p.add_option("--novice", action="store_const", const="novice", dest="mode")
p.add_option("--guru", action="store_const", const="guru", dest="mode")

# 为各种选项目的地设置默认值
p.set_defaults(tracing=False,
              speed="fast",
              coord=(0,0),
              mode="novice")

# 解析参数
opt, args = p.parse_args()

# 打印选项值
print("tracing ", opt.tracing)
print("outfile ", opt.outfile)
print("debug ", opt.debug)
print("speed ", opt.speed)
print("coord ", opt.coord)
print("mode ", opt.mode)

# 打印剩余参数
print("args ", args)
```

## setpgrp()

通过调用系统调用 `setpgrp()` 或 `setpgrp(0, 0)` 创建一个新的进程组，取决于实现了哪一个版本（如果有）。返回新进程组的 ID (UNIX)。

## setpgid(pid, pgrp)

将进程 `pid` 分配到进程组 `pgrp`。如果 `pid` 等于 `pgrp`，该进程成为一个新的进程组组。如果 `pid` 不等于 `pgrp`，该进程加入现有组。如果 `pid` 为 0，则使用调用进程的 ID。如果 `pgrp` 为 0，则由 `pid` 指定进程创建一个进程组组 (UNIX)。

## setreuid(uid, eid)

设置调用进程的真实和有效用户 ID (UNIX)。

## setregid(rgid, egid)

设置调用进程的真实和有效组 ID (UNIX)。

## setsid()

创建一个会话并返回新创建会话 ID。会话通常与终端设备以及启动它们的进程的作业控制相关 (UNIX)。

## setuid(uid)

设置当前进程的用户 ID。此函数具有特权，通常仅由以 root 运行的进程执行 (UNIX)。

## strerror(code)

返回与整数错误码对应的错误消息 (UNIX 和 `errno` 模块为这些错误码定义了符号名称)。

## umask(mask)

设置当前的数值 umask 并返回之前的 umask。umask 用于清除进程创建的文件的权限位 (UNIX 和 Windows)。

## uname()

返回一个字符串元组 `(sysname, nodename, release, version, machine)`，用于标识系统类型 (UNIX)。

## unsetenv(name)

取消设置环境变量 `name`。
