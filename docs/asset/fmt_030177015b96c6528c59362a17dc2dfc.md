
# 生物化学遗传学

生物化学遗传学始于对遗传代谢病的研究。这些是身体化学性疾病，其中小分子，如糖或氨基酸，因为负责其代谢分解的酶缺乏而在体液中积累。这种分子缺陷是编码该酶的基因突变的结果。根据积累分子的性质不同，它负责导致高度特异性的疾病模式。随着认识到类似的遗传缺陷酶会干扰非常大分子（如粘多糖和脑组织中复杂脂质等显著成分）的分解，生物化学遗传学领域得以扩展。由此产生的贮积病表现出形态和身体结构的极端改变以及神经退行性疾病。

大多数代谢遗传病是以常染色体隐性方式遗传的。在这些家庭中，每个亲本在一个染色体上携带一个突变基因，在另一个染色体上携带正常基因。其中大多数突变都很罕见。在遗传多样性较高的群体中，大多数受累个体在同一基因中携带两个不同的突变。某些代谢病由X染色体上的基因编码。其中大多数疾病是完全隐性的，因此所有受累个体都是男性，而携带该基因的女性在临床上表现为正常。由线粒体基因组中突变引起的疾病是以非显性方式遗传的，因为线粒体DNA仅从母亲遗传。携带突变的个体是异质二倍体；也就是说，每个个体都携带混合的线粒体种群，其中一些含有突变，另一些没有。

苯丙酮尿症（PKU）是一种原型生物化学遗传病。它是一种常染色体隐性遗传病，在许多家庭中已证实的突变，当同时存在于两个染色体上的基因时，会导致催化苯丙氨酸代谢第一步的酶活性缺陷。这导致苯丙氨酸积累以及可识别的临床疾病，其最显著的特征是严重的智力发育迟缓。参见苯丙酮尿症。

由线粒体DNA突变引起的疾病直到20世纪90年代才被认为具有此类性质。它们是由点突变、缺失和其他重排引起的。大多数这类疾病在化学上表现为血液或脑脊液中乳酸浓度升高。许多疾病被称为线粒体肌病（肌肉疾病），因为骨骼肌病或心肌病是其特征。[W.L.N.v.]

# 人类基因组计划

一项有组织的国际科学事业，旨在确定人类遗传物质脱氧核糖核酸（DNA）的完整结构并理解其功能。参见人类遗传学。

## 历史

人类基因组计划（HGP）的想法最初产生于20世纪80年代中期。几个科学小组召开会议讨论其可行性，并发表了各种报告。最有影响力的报告是由国家研究委员会（NRC）美国国家科学院。它提出了一项详细的科学策略，说服了许多科学家相信该项目是可行的。1990年10月1日被宣布为人类基因组计划（HGP）在美国正式启动的时间；此时重大资金已经到位，各研究小组也已开始着手工作。英国、法国、日本和德国对HGP做出了重大贡献，其他许多国家也做出了较小的贡献。各国之间的协调是非正式的，主要依赖科学家之间的合作，但事实证明这种协调非常有效。

## 科学策略

首先，通过遗传图谱将标记放置在染色体上，即观察标记在家庭中的遗传方式。其次，由重叠的DNA克隆片段创建物理图谱。第三，确定每个片段的序列，并通过计算机将序列排列，直到获得沿整个染色体的连续序列。第二步和第三步可以颠倒，或并行执行。当对片段进行测序时，重叠末端的序列可用于帮助确定片段的顺序。如果在片段图谱制作之前完成测序，则此过程被称为全基因组鸟枪法测序。参见 [脱氧核糖核酸（DNA）；基因]。

由于人类基因组如此庞大（人类DNA由约30亿个核苷酸首尾相连成线性阵列组成），有必要将任务分解成可管理的块（见图示）。

## 模式生物

整体策略的一个重要组成部分是在HGP中包含对模式生物的研究。原因有二：
1. 更简单的生物提供了很好的练习材料。
2. 模式生物与人类之间的比较能产生非常有价值的科学信息。

HGP最初采用五种模式生物进行DNA测序：细菌*大肠杆菌*、酵母*酿酒酵母*、线虫*秀丽隐杆线虫*、果蝇*果蝇*，以及实验用小鼠*小鼠*。小鼠基因组的复杂性与人基因组相当，但小鼠的优势在于可以对其进行育种，并进行那些在人类身上无法开展的其他实验。

## 发现

关于人类基因组，基因数量可能是最常见的问题。最先被测序的两条人类染色体，即22号和21号染色体，证实了一些有趣的观察结果。尽管这两条染色体的长度大致相同，但22号染色体上的基因数量却是21号染色体的两倍多。基于在22号和21号染色体上发现的基因数量进行外推，估计整个人类基因组包含约36,000个基因。这是一个相当大的意外，因为之前的估计是80,000到100,000个基因。对全人类基因组草图的初步检查证实，基因数量远低于先前认为的水平。这并不一定意味着人类基因组的复杂性较低，因为许多基因可以通过在翻译成蛋白质组成成分时对其外显子（基因编码蛋白质的区域）进行可变剪接，从而产生多种蛋白质。参见 [染色体；遗传密码]。

人类基因组序列的另一迷人特征在于由重复序列元件组成的大比例；21号染色体中有40%和22号染色体中有42%由重复序列组成，而22号染色体主要由重复序列构成。这些重复序列中任何一个的功能目前尚不清楚，但阐明它们在基因组中的分布可能有助于揭示其功能。

另一个有趣的统计量是碱基组成，即DNA中鸟嘌呤-胞嘧啶（GC）碱基对相对于腺嘌呤-胸腺嘧啶（AT）碱基对的百分比。22号染色体的GC含量为48%，而21号染色体为41%，全基因组的平均水平为42%。同样，其意义目前尚不清楚，但较高的GC含量似乎与较高的基因密度相关。

最初在对21号和22号染色体进行时所进行的分析类型已被扩展到整个人类序列。然而，全面理解将需要数十年的时间才能实现。

## 未来研究

随着生物体完整基因组的可用，可以研究基因如何开启和关闭，以及基因之间如何相互作用。还必须了解不同基因的作用及其如何影响人类健康。因此，目前大量工作致力于研究基因表达调控，并为序列添加有关功能的有用生物学注释（标注）。另一个关键挑战是理解DNA功能如何随DNA序列的差异而变化。每个独特的人都有其独特的DNA序列，无论种族起源如何，都与其他任何人相差约0.1%。然而，这种微小的差异会影响特征，如人类的外观以及他们容易患哪些疾病。这些差异也为了解人类物种的进化和全球人口历史迁移模式提供了线索。参见 [分子生物学；核酸]。[FCA; ELos]

# 人机系统

由人类和机器组成的复杂系统。人机系统工程是对此类系统的分析、建模和设计。它在三个一般方面区别于更广泛的人因学领域，以及与人类-计算机交互、工程心理学和社会技术系统理论相关的领域。首先，人机系统工程侧重于大型、复杂、动态的控制系统，这些系统通常是部分自动化的（例如驾驶飞机、监控核电站或监管柔性制造系统）。其次，人机系统工程师建立人机交互的定量或计算模型，作为分析工具和设计框架。最后，人机系统工程师在自然环境中或高保真模拟环境中研究人类的问题解决能力。参见 [人类-计算机交互；人因工程]。

因此，人机系统工程专注于设计联合技术与人类系统所带来的独特挑战。从历史上看，它源于关于控制论、控制工程、信息和通信理论以及工程心理学的研究。随后，专注于认知人机系统的研究人员（其中人类工作主要是认知而非手工的）也将他们的专业领域称为认知工程或系统工程。参见 [控制论；信息论]。

人机系统的四个主要方面，按大致的历史顺序排列，分别是人类作为手动控制器系统的、人类作为监督控制器系统的、人类与人工智能系统的交互，以及复杂系统中的人类团队。这种普遍演变与计算机和自动化技术的进步有关。随着这种技术的日益复杂和复杂化，人类的角色从直接手动控制转变为对物理过程的监督控制，再转变为对智能系统的监督，最后，随着对复杂系统社会和组织方面的日益重视，转变为复杂环境中的团队协作。

*航空业*是一个例子，其中所有这些发展都曾发生。早期在飞机系统中的工作侧重于飞行员表现的手动控制模式。随着自动化水平的提高，飞行员转向更具监督性的角色，其中诸如规划和编程飞行管理计算机等任务成为主要的工作形式。参见 [飞机仪表；自动驾驶仪；飞行控制]。[PM.J]

# 人类变异

试图描述和解释人们彼此差异的方式，构成了人类学中一个传统上核心的研究问题。这也提供了人类通过强加模式来解释世界以及科学的社会功能的一个经典例证。

最早提出人类物种实际上可以分为少数几个自然群体的人是法国旅行家和医生弗朗索瓦·伯尼耶（Francois Bernier），时间为1684年。他建议将人类物种分为欧洲、北非和印度的人群；近东；撒哈拉以南非洲的人群；东亚人；斯堪的纳维亚的拉普人（萨米人）；以及南部非洲的霍顿托特人（科伊人）。这种系统的表观自然性如此强大，以至于生物分类学的父亲卡尔·林奈（Carolus Linnaeus）在十八世纪正式将其纳入他的*自然系统*中。在这里，四种语言成为了四种正式指定的人类亚种的冠名归属地：红色的美洲人、黄色的亚洲人、白色的欧洲人和黑色的非洲人。后续研究试图微调分类，观察到许多复杂人群的显著身体特征，但仍然未能质疑确实存在少数几个基本类型的人需要被识别和分类这一基本假设。参见 [分类学]。

直到遗传数据的出现，种族范式才开始受到严重质疑。研究表明，人类物种中绝大部分的遗传差异发生在当地种群内部和之间；大陆区域之间的差异仅占总额的约6%。因此，发现种族（大陆）差异在数量上是微不足道的。

遗传变异似乎以两种主要方式呈现模式。普遍的多态性，如ABO血型，构成了可检测遗传变异的大多数，其中大多数种群包含大多数等位基因。私有多态性构成了人类变异的另一组成部分，其中特定变体主要在世界某个受限区域被发现。即便如此，它也只以低频率被发现。参见 [基因；人类遗传学]。
