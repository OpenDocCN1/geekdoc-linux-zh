- `/bin`

一个包含可执行程序的目录，大部分程序存储在二进制文件中。大多数程序位于 `/directories` 和 `/usr/bin` 中；然而，用户经常将额外的程序保存在私有目录中，如 `/home/user/bin`。源自 Linux Guide @FirstLinux

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

- `/dev`

在 UNIX 上，这是一个可以写入的虚拟文件。写入该文件的数据会被丢弃。它类似于 Windows 上的 NUL 文件。在获取 root 权限时，入侵者经常会将日志重定向到 `/dev`。例如，命令 `-s /dev/bash_history` 将导致系统停止记录行为。文化：在俗语中，与黑洞的意思相同。典型用法：如果你不喜欢，请将你的意见指向 `/dev/null`。源自 Hacking–Lexicon

http://www.tldp.org/LDP/linux–Dictionary/html/index.html

- `/etc`

Unix 上存放大部分配置的目录。它大致比比 Windows 注册表。特别值得关注的是 `/etc/passwd` 文件，它存储了所有密码。关键点：如果入侵者可以从该目录读取文件，他们就可以很容易地利用这些信息攻击该机器。源自 Hacking–Lexicon

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
