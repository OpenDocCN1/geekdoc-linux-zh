## 调试常见问题

本小节描述了 Samba 可能会出现问题，并建议了如何修复它们。

### 连接被拒绝 (CONNECTION REFUSED)

如果您看到消息：`connect error: Connection refused`

那么 Samba 可执行文件不可用。请确保 Samba 进程正在运行；输入命令 `ps -ax | grep smbd`。如果您没有看到 `smbd` 进程，请切换到超级用户 `root` 并输入以下命令：

```

```

现在，再次尝试 `smbclient`。

### 服务器异常 (UNFRIENDLY SERVER)

如果您看到这样的错误消息：

```
Session request failed (0,0) with myname=EXAMPLEGROUP
destname=EXAMPLEHOST
Unspecified error 0x0
Your server software is being unfriendly
```

说明您正尝试通过 `inetd` 运行 Samba，而 `inetd` 无法运行文件 `/etc/inetd.conf` 中指定的两个 Samba 程序之一。这通常是由于 Samba 安装不当导致的。确保 `smb.conf` 文件安装在 `/etc` 目录下。确保 Samba 可执行文件安装在文件 `/etc/inetd.conf` 中指定的目录中。例如，如果 `inetd.conf` 中 Samba 的条目如下：

```
netbios-ssn stream tcp nowait root /usr/local/samba/smbd smbd
netbios-ns dgram up wait root /usr/local/samba/bin/nmbd nmbd -Gmygroup
```

那么确保可执行程序 `smbd` 和 `nmbd` 位于 `/usr/local/samba` 目录。

### 用户账户错误 (BAD USER ACCOUNT)

如果您看到类似于 `Bad password` 的错误消息，说明您访问 Linux 系统的访客账户定义不正确。请确保全局资源中访客账户定义定义的账户确实存在。此外，请确保它没有设置密码。

如果 Samba 编译处理密码的方式与您的系统不同，也会发生此错误。如果您的系统使用影子密码 (shadow passwords)，则 Samba 必须编译为使用它们。而如果您的系统不使用密码，则 Samba 必须不编译为使用密码。如果您使用默认的 SuSE 密码设置，这不应该是一个问题。

### I: SET IP ADDRESS 选项

`-I` 选项设置你想要连接的主机 SMB 服务器的 IP 地址。它接受一个参数：点分表示法的主机 IP 地址。例如，该命令

```
smbclient -L loki -I 192.168.1.5
```

请求列出服务器 `loki` 上的资源，并使用 IP 地址 `192.168.1.5` 作为 `loki` 的 IP 地址。

如果你不使用 `-I` 选项，而是简单通过 NetBIOS 名称识别 Windows 机器，`smbclient` 将尝试通过广播一个标识身份自身的请求来定位该 Windows 机器。请注意，如果你为想要查询的 SMB 服务器资源主机输入了错误的 IP 地址（即名称和 IP 地址未指向同一个主机），`smbclient` 将显示错误消息并退出。

如果由于某种原因，你的 `smbclient` 无法将 Windows 机器解析为其 IP 地址，你应该使用此选项。

### U: SET THE USER Name 选项

`-U` 选项允许你指定操作 SMB 资源的用户名。此选项接受一个参数，即用户登录到你正在查询的 SMB 服务器主机时使用的登录标识符。

如果你愿意，可以将密码附加在登录标识符后面。密码必须通过单个字符 `%` 与名称隔开，且没有空格。例如，以用户 `fred` 的身份（密码为 `password`）查询 Windows 机器，使用以下选项：

```
-U fred%password
```

如果你在 `%` 字符后没有设置密码，`smbclient` 将空字符串作为密码。你可以使用此选项来处理不需要密码的资源。

如果你不使用 `-U` 选项，`smbclient` 将使用环境变量 `USER` 的值作为查询 SMB 服务器的用户名，并提示输入密码。显然，这种默认方式仅适用于主机识别用户的登录标识符和密码的情况。

## 命令

你可以使用许多命令来操作资源。如果你曾经用过 `ftp`（在第 7 章描述），大多数命令对你来说应该是熟悉的。以下列表列出了最常见的命令。

- `cd [directory]` – 切换到文件共享内的目录。如果你在不带参数的情况下 `cd`，`smbclient` 会打印你当前所在的目录名称。`smbclient` 在其提示符中包含你正在操作的目录名称。
- `del [pattern]` – 删除当前目录中所有匹配模式的文件。模式可以包括字母和通配符 `*` 和 `?`。例如，该命令

```
del a*
```

删除当前目录中所有以字母 `a` 开头的文件。

请注意与 Linux shell 的一个区别：通配符 `?` 匹配任何单个字符，或者不匹配任何字符。因此，如果当前目录包含文件 `foo.bar`，则命令

```
del foo*
```

将同时删除这两者，而在 Linux shell 下，只有 `foo.bar` 会被删除。

- `dir [pattern]` – 列出所有匹配模式的文件。模式可以包括通配符 `*` 和 `?`。如果你不提供模式，此命令将列出目录中的所有文件。
- `get remotefile [linuxfile]` – 将文件资源上的 `remotefile` 复制到你 Linux 工作站的本地目录中。如果给定了可选参数 `linuxfile`，则 `remotefile` 在你的机器上被重命名为 `linuxfile`。请注意，此命令从远程主机检索一个且仅一个文件。要检索多个文件，请使用命令 `mget`。
- `lcd [localdirectory]` – 将当前本地目录从你 Linux 机器上的目录切换到 `localdirectory`。从远程主机检索的文件将写入新的当前目录中。如果你在不带参数的情况下使用此命令，`smbclient` 会打印你的 Linux 目录的名称。
- `mget pattern` – 从远程主机复制多个文件。要复制的文件必须匹配模式，模式可以包括通配符 `*` 和 `?`。例如，要从 Windows 共享将所有 C 源文件复制到 Linux 机器，你将使用命令 `mget *.c`。
- `mkdir directory` – 在远程主机创建一个目录。新目录将在你当前所在的远程目录中创建。请注意，你创建新目录的能力取决于远程主机授予你的权限。如果你在你操作的目录中没有写权限。
- `mput pattern` – 向远程主机复制多个文件。要复制的文件必须匹配模式，模式可以包括通配符 `*` 和 `?`。例如，要将所有 C 源文件复制到 Windows 共享，你将使用命令 `mput *.c`。
- `print filename` – 在你连接的资源上打印 `filename`。如果你想从标准输入打印，请使用 `print -`。
- `printmode [text|graphics]` – 将打印模式设置为文本或图形。
- `prompt` – 切换 `smbclient` 是否在通过 `mget` 或 `mput` 命令复制文件之前请求你的许可。
- `put localfile [remotefile]` – 将 Linux 工作站当前目录下的 `localfile` 复制到远程主机。默认情况下，`localfile` 在远程主机上保留其名称；但 `put` 的可选第二个参数会将名称更改为 `remotefile`。
- `queue` – 显示你连接的资源打印队列的信息。对于打印队列中的每个作业，`smbclient` 会显示作业的标识符、名称和状态。
- `quit` – 关闭与 Windows 机器的交互式连接并退出 `smbclient`。
- `recurse` – 切换 `mget` 和 `mput` 命令的递归。当开启递归时，`mget` 和 `mput` 会搜索匹配给定模式的文件，不仅在当前目录中，还在当前目录下的所有目录中。例如，在开启递归的情况下，命令

```
mget *
```

将远程主机共享上的每个文件复制到 Linux 机器的当前目录中。

- `rmdir directory` – 从 Windows 机器上删除目录。如果目录包含任何文件，此命令将失败。
- `? [command]` – 调用交互式帮助。命令 `?` 打印 `smbclient` 识别的所有命令列表。命令 `? command` 打印给定命令的摘要；例如，命令

```
? mget
```

显示以下内容：

```
HELP mget:
<mask> get all the matching files
```

## 在 Windows 机器上打印

在第 7 章中我们讨论了在 Linux 下打印。简单回顾一下，你可以调用 `lpr` 命令打印文件。`lpr` 接收你提供的文件并将其复制到暂存目录中。它从 `/etc/printcap` 读取你想要打印该文件的打印机信息，并使用这些信息格式化文件并发送到你想要打印该文件的打印机。

我们在第 7 章的讨论仅限于如何将作业发送到其他 Linux 工作站打印。你也可以使用 `lpr` 格式化并发送作业到 Windows 机器上打印。然而，在这里，我们不使用 `printcap` 的 `rm` 指令（该指令会转发到另一台 Linux 工作站上的打印守护进程），而是编写一个使用 `smbclient` 将作业发送到 SMB 打印机服务的脚本。

设置这样的打印服务需要两个步骤：

## 第 15 章：Samba 和 SMBFS

1. 编写一个脚本，根据要打印的打印机类型对文件进行格式化，然后调用 `smbclient` 将文件转发到 Windows 上的打印机资源。
2. 修改文件 `/etc/printcap`，定义一个使用该脚本处理并分发文件的打印机。

这看起来可能很复杂，但实际上比初看起来简单得多。我们将逐一讨论步骤。

### 编写脚本

你需要编写的脚本需要从标准输入读取文本，进行处理（如果有必要），然后调用 `smbclient` 将文本分发到 Windows 打印资源。以下是此类脚本的最简单形式：

```
#!/bin/sh

/usr/bin/smbclient //winbox/winprinter -U fred%password -c "print - "
```

该命令调用 `smbclient` 与 Windows 机器 `winbox` 上的资源 `winprinter` 交互。`-U` 选项设置 Windows 用户的用户名和密码，文件将以该用户名打印——在此情况下，用户为 `fred`。（请注意，这与实际打印文件的 Linux 工作站上的用户不需要相同。）最后，`-c` 选项调用 `smbclient` 的 `print` 命令来打印文本；参数 `-` 告诉 `print` 从标准输入读取文本。

如果你愿意，可以修改此脚本以便在打印的同时格式化文本。例如，假设 Windows 机器上的打印机是一台 PostScript 打印机。你可以使用 `a2ps`（ASCII 到 PostScript）命令对文件进行某些格式化，在这种情况下，你的脚本将如下：

```
#!/bin/sh

/usr/bin/a2ps -o - | /usr/bin/smbclient //winbox/winprinter \
-U fred%password -c "print -"
```

- `-o -` 告诉 `a2ps` 将输出写入标准输出；管道符 (`|`) 将 `a2ps` 的输出传递到 `smbclient` 的标准输入。（如果你对这些术语不熟悉，不要担心——这是标准的 UNIX/Linux 术语。）

一旦准备好脚本，你应该切换到超级用户 `root` 并恰当地更改脚本的所有权和权限。例如，如果你将脚本命名为 `smbscript`，应使用以下命令设置其权限：

```
chmod 700 smbscript
chown lp smbscript
```

这些命令意味着只有控制打印机守护进程的 `lp` 用户才能读取或执行 `smbscript`。这很重要，因为脚本中嵌入了密码。

最后，你应该将脚本移动到存放所有格式化脚本的目录中。我们建议使用 `/usr/local/lib`，但也可以使用你喜好的目录。

### 修改 /ETC/PRINCAP

一旦编写并测试了脚本，你就必须在 `/etc/printcap` 文件中添加条目。该条目将定义一个使用你的脚本格式化文件并将其分发到 Windows 机器打印的打印机。以下是此类条目的简单示例：

```
winprinter:\
:mx#0:\
:of=/usr/local/lib/smbscript:\
:lp=/dev/null:\
:sd=/var/spool/winprinter:\
:lf=/var/log/lpd-err:
```

该条目很简单，但包含了以下指令：

- `sh` - 禁止打印突发性头文件（burst header）。
- `mx` - 设置可打印文件的最大大小。0 表示无限制。
- `of` - 输出过滤器。这指定了用于过滤该打印机打印文本的脚本名称。如你所示，它被设置为你在上一节中准备的脚本的完整路径名。
- `lp` - 行打印机设备。在这里设置为 `/dev/null`，因为你不会在物理设备上打印——而是你的脚本将打印到另一台机器上的打印机。
- `sd` - 池化目录：存放打印排队文件的目录名称。每个打印机都应该有自己的池化目录。如果该目录尚不存在，你应该创建它。
- `lf` - 日志文件。行打印机守护进程写入错误信息的文件名。

就此全部。一旦设置完成，Linux 工作站上想要在连接到 Windows 机器的打印机上打印文件文本的用户只需使用以下命令：

```
lpr -Pwinprinter mytext
```

行打印机守护进程将对文件进行排队，然后对其进行格式化并分发到 Windows 机器进行打印。请注意，一旦你设置了这个打印机定义，它不仅供坐在你 Linux 工作站前的用户使用。如果你设置了 Samba 让内网内的用户可以使用打印机资源，那么该打印机定义对内网中的任何用户都可用。因此，Samba 为你提供了一个主打印池的良好方法，它可以识别并可以将文件分发到连接到内网任何机器的任何打印机。
