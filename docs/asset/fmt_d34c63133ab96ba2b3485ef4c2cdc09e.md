
## 338 了解电子邮件

电子邮件消息的地址是某个主机（主机只是在线计算机的雅称）上的一个用户名。这意味着，如果 John Doe 使用用户名 `jdoe` 登录，电子邮件的收件地址就是 `jdoe`。唯一能够唯一标识收件者的信息是收件者系统的完全限定域名名（FQDN）。因此，如果 John Doe 的系统命名为 `some-place.com`，他的完整电子邮箱地址就变为 `jdoe@someplace.com`。基于此，互联网上的任何人都可以向 John Doe 发送电子邮件。

## MUA 和 MTA 如何工作

有两种类型的邮件软件。

- 邮件用户代理（MUA）是邮件读取器的雅称 —— 它是你用来读取邮件、撰写回复和撰写新消息的客户端。通常情况下，邮件用户代理使用 POP3 或 IMAP 协议从邮件服务器检索消息。POP3 是邮局协议第 3 版，而 IMAP 是互联网信息组访问协议第 4 版。Fedora Core 自带了如 Thunderbird、Mozilla 和 Evolution 等邮件用户代理。
- 邮件传输代理（MTA）是发送和接收邮件消息文本的邮件传输器的雅称。用于邮件传输的具体方法取决于底层网络。在 TCP/IP 网络中，邮件传输代理使用简单邮件传输协议（SMTP）传递邮件。Fedora Core 包含了 `send`，这是一个用于 TCP/IP 网络的强大且流行的邮件传输代理。

图 1 显示了在 Alice 向 Bob 发送电子邮件消息后，MUAs 和 MTAs 是如何协同工作的。

图 1 中的场景是大多数人的典型情况。Alice 和 Bob 都通过 ISP（互联网服务提供商）连接互联网，并通过他们的 ISP 获取和发送电子邮件。当 Alice 输入消息并发送时，她的邮件用户代理（MUA）使用简单邮件传输协议（SMTP）将消息发送给其 ISP 的邮件传输代理（MTA）。然后，发送方 MTA 使用 SMTP 将该消息发送到接收方 MTA —— Bob 的 MTA。当 Bob 连接互联网时，他的 MUA 使用 POP3（或 IMAP4）协议从其 ISP 的 MTA 下载消息。这就是邮件在互联网上移动的方式 —— 从发送 MUA 到发送 MTA，再到接收 MTA，最后接收 MUA。

## 邮件消息增强

邮件消息以前是纯文本的（现在大多数仍然如此），但今天许多消息包含远不止两种类型。今天邮件的两个新功能是：

- **附件**：现在的许多消息包含附件文件，可以是从文档到图片的任何内容。收件人可以将附件保存到磁盘上，或直接从邮件读取器打开。不幸的是，附件是黑客试图将病毒和蠕虫引入你电脑的途径之一。
- **HTML**：邮件消息可以是 HTML（超文本标记语言），用于布局网页的语言。当你在功能良好的邮件读取器上阅读 HTML 消息时，消息将以全盛的状态出现，带有漂亮的字体和嵌入图形。

虽然 HTML 消息很漂亮，但当你使用基于文本的邮件读取器时，它们显示异常。在文本邮件读取器中，HTML 消息显示为一堆乱码。

## 使用 Evolution

设置向导引导完成以下操作：

1. 在身份界面输入你的姓名和电子邮件地址并点击下一步。
2. 设置接收选项并点击下一步：选择邮件下载类型 POP 或 IMAP。然后提供服务器名称。
3. 提供更多关于接收的信息 —— 检查邮件的频率以及是否将邮件留在服务器上 —— 然后点击下一步。
4. 设置发送选项并点击下一步：选择服务器类型为 SMTP。输入服务器名称，如 `smtp.comcast.net`。
5. 指定是否希望将此电子邮件账户作为默认账户，并如果需要，给此账户一个描述性名称；点击下一步。
6. 通过地图设置时区；点击下一步。
7. 点击应用完成 Evolution 设置。

完成设置后，Evolution 将打开其主窗口。

## 使用 Mozilla Mail

Mozilla Mail 是随 Mozilla — Netscape Communicator 附带的邮件新闻阅读器。

要使用 Mozilla Mail，首先运行 Mozilla 浏览器。点击面板上的 Mozilla 图标，将打开 Mozilla Web 窗口。要访问 Mozilla Mail 和新闻阅读器，请从菜单中选择“窗口 > 邮件和新闻组”。

账户向导将引导你完成以下步骤：

- 输入你的身份信息——你的姓名和完整电子邮件地址，然后点击“下一步”。
- 提供 ISP 邮件服务器的信息——协议类型（POP 或 IMAP）以及入/出站服务器名称——并点击“下一步”。
- 输入 ISP 给你的用户名；点击“下一步”。
- 输入你想要用于标识此账户的名称，并点击“下一步”。

### 发现万维网

标准的 Web 文档格式是超文本标记语言（HTML），交换 Web 文档的标准协议是超文本传输协议（HTTP）。

Web 服务器提供 HTML HTTP 请求的软件。Web 浏览器是实际上从 Web 服务器下载 HTML 文档并进行图形化显示的客户端软件。

### Web 服务器与 Web 浏览器

Web 服务器提供 Web 页面，而 Web 浏览器则下载并将其显示给用户。

在典型场景下，用户坐在连接到互联网的电脑前并运行 Web 浏览器。当用户点击链接或在 Web 浏览器中输入 URL 时，浏览器连接到 Web 服务器并向服务器请求文档。

### Fedora Core 中的 Web 浏览

Fedora Core 自带了 Mozilla Web 浏览器。Mozilla 是 Netscape Communicator 的开源版本。

Fedora Core 还包含了其他几个 Web 浏览器：

从 GNOME 桌面，你可以通过两种方式启动 Mozilla：

- 从 GNOME 中选择菜单 → Internet：Mozilla Web 浏览器。

### 更改你的主页

主页是你启动 Mozilla 时它加载的页面。

从 Mozilla 菜单中选择“编辑：偏好”。偏好窗口将会出现。你可以使用主页的 URL，下方是“使用当前页面”按钮。

### 创建网页

基础的 HTML 文件结构：

```
<html>
<head>
<title>My Home Page</title>
</head>
<body>
</body>
</html>
```

HTML 标签包含在角括号 `<>` 中，且一对标签——一个起始标签和一个结束标签——格式如下 `</>`。

- `<html> ... </html>` 标签表示该文档是一个 HTML 文档。
- `<head> ... </head>` 标签包含页头信息。
- `<body> ... </body>` 标签包含整个 HTML 文档。

### 使用 Mozilla Composer 编写网页

Mozilla Composer 是一个图形化工具，不需要了解 HTML 就可以创建网页。

从 Mozilla 菜单中选择“窗口 > Composer”。

你可以插入图像：
1. 收集你想要使用的图像文件。
2. 将光标置于你想放置图像的地方；然后从组件中心选择“插入::图像”。
3. 点击“选择文件”按钮，并在“选择图像”对话框中选择图像文件。
4. 为图像输入备用文本。
5. 点击“确定”。

### 理解新闻组

新闻组从 Usenet 起源，现在已迁移到互联网。现在使用网络新闻传输协议 `NNTP` 代替 UUCP 来传输新闻。

新闻组被组织成层级。新闻组名称显示了层级结构。
