
# 启动您的第一台虚拟机

启动您的第一台虚拟机最简单的方法之一，就是使用 Oracle 的 `VirtualBox`。这是一款免费（采用 GPL2 许可协议）的软件，适用于 Windows、macOS 和 Linux。Mac 和 Windows 用户应从 `https://virtualbox.org` 下载，而 Linux 用户应使用以下命令安装：

```bash
sudo apt install virtualbox
```

它在所有平台上的外观和操作方式相同，因此无论您的操作系统是什么（或者您想虚拟化的操作系统是什么），都可以利用我们对面提到的实用六步指南。如果您不知道该尝试哪个发行版，不妨从 `LXF0VD` 中拷贝 Solus 或 OpenMandriva 的 ISO 文件？如果您想让 `VirtualBox` 直接从光盘使用这些文件，速度会非常慢。

如果您发现卡在全屏模式下，请按下 `Right Ctrl+F` 返回窗口模式。如果您发现鼠标光标被困在来宾窗口中，只需按下 `Right Ctrl` 键即可逃逸。如今大多数 Linux 发行版都支持无缝鼠标集成，因此后者不应该发生——在来宾系统中将鼠标移出屏幕边缘应该会释放控制权回到宿主机。

## VirtualBox 优化技巧

启动虚拟机很简单，但让我们看看 `VirtualBox` 提供的一些选项，让您的虚拟生活像真实生活一样流畅。首先，如果您将虚拟磁盘镜像存储在传统机械硬盘上，I/O 密集型工作负载会非常缓慢，您可能会注意到在执行期间有大量磁盘活动。对于此类任务，事实上如果您敢运行 Windows 虚拟机，将镜像存储在 SSD 上会让您的体验显著 提升。

如果您没有 SSD，或者 SSD 空间不足，您可以通过为虚拟机启用主机 I/O 缓存来获得额外性能。从左侧列中选择您的虚拟机，点击工具栏上的“设置”按钮，选择磁盘镜像（VDI 文件，而不是光盘），并勾选该选项。您还可以在此处更改呈现给虚拟机的控制器类型，但一般来说，默认设置（光驱连接的 IDE 控制器为 PIIX4，SATA 控制器为 AHCI）的支持更好。`VirtualBox 6.1` 于一月发布，引入了对 virtio 存储的实验性支持，这意味着 `VirtualBox` 不必浪费 CPU 周期来模拟磁盘控制器。这至少应该能在 Linux 发行版上良好工作，但需要在 Windows 虚拟机中添加驱动程序。当我们了解 `QEMU` 时，会在下一页讨论 virtio 的细节。

人们最常想做的就是提高图形性能。`VirtualBox` 中新的默认图形控制器（VMSVGA，实际上是借自 VMware）应该能很好地满足 Linux 来宾系统。如果您手头有较旧的 `VirtualBox` 虚拟机，您可能希望更新它们以使用新控制器。虚拟 Windows 可能在使用 `VBoxSVGA` 驱动时表现更好。如今没有理由使用旧的 VBoxSVGA 驱动，除非您正在运行或试图虚拟化非常古老的发行版。

您可以在虚拟机设置对话框的“显示”部分找到图形控制器选项。默认的视频内存分配仅为 16MB，这对于在 1080p 以下分辨率测试 Linux 发行版来说已经足够，但对于更严肃的工作，您希望增加这一数值。前述虚拟 SVGA 设备模拟了足够的显卡功能，以暴露基本的 OpenGL 原语和一些 2D 加速能力——但您可能会注意到还有一个 3D 加速 的选项框。

如果使用此功能，宿主机的所有 OpenGL 功能都将在来宾系统中可用。名称有点令人困惑，因为许多看起来非常二维的桌面效果依赖于 3D 扩展。例如，`VirtualBox` 下的 Linux Mint 会告诉您它正在使用软件渲染，直到勾选 3D 选项框。

设置桥接网络，使您的来宾系统作为局域网上的独立主机出现非常容易，所有这些其他网络配置也是如此。

## 打开 VIRTUALBOX！

### 1. 准备就绪

按对面所述下载 `VirtualBox` 并启动它。默认情况下，新虚拟机存储在主目录中，因此请确保这里有一些活动空间——否则您需要手动指定不同的位置。一个初始大小为 5GB 的桌面 Linux 安装很容易增长到 10GB。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_70_0.png)

### 2. 创建您的虚拟机

点击 `VirtualBox` 工具栏中的“新建”按钮。我们将使用从 `LXFDVD` 拷贝的 Solus ISO——尽管您可以自由选择任何您喜欢的发行版。给您的虚拟机命名，将机器类型设置为 Linux，版本设置为相应的选项。这里的 32/64 位选择很重要。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_70_1.png)

### 3. 分配内存

为虚拟机分配多少内存取决于您如何使用它以及主机机器有多少 RAM。现代桌面和应用程序（如 Web 浏览器）会轻松消耗 2GB，而启动到控制台所需很少。如果您为虚拟机分配过多的内存，主机性能会受到影响。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_70_2.png)

### 4. 处理存储

我们需要为虚拟机提供一些存储空间。现代 Linux 发行版在安装到少于 10GB 空间的位置时往往比较挑剔，如果您有多余空间，多分配一些是个明智的想法。选择“立即创建虚拟硬盘”（除非您只是想运行一个 Live 发行版）以开始流程。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_70_3.png)

### 5. 调整存储

选择默认的 VDI 存储。这些文件可以是固定大小的，也可以是动态大小的（直至给定最大值）。动态存储显然更灵活，如今您不太可能注意到增加的 I/O 开销，所以请选择动态存储。您可以通过右侧的小图标指定文件位置。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_70_4.png)

### 6. 起飞！

您需要一个 ISO 镜像来启动您的机器。转到“设置 > 存储”并选择光驱。点击右侧的光盘下拉菜单并选择“选择虚拟光盘文件”（原文如此）。定位您的 ISO 文件，点击“确定”，然后点击绿色的启动箭头。各就位，发射！

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_70_5.png)

## QEMU 和 KVM

利用 Linux 的强大功能，在命令行深入探索并构建您自己的虚拟机。

`VirtualBox` 当然很好，但还有其他选择。有些人不喜欢使用 Oracle 软件，而且过去来宾扩展（用于启用图形加速和共享剪贴板的功能）并非自由许可，意味着它们无法被发行版捆绑，必须单独安装。

这种情况不再存在，大多数发行版现在都附带所需的主机和来宾模块——但偶尔，主机和来宾模块会不匹配（例如，如果来宾发行版包含比主机运行版本更旧的模块），则必须手动安装。这些可以在所有平台上，通过在一个运行中的虚拟机中选择“设备”菜单中的“安装来宾增强功能”来安装。会插入一张虚拟 CD，您会找到一个用于构建和安装模块的 Linux 脚本，以及 Windows 和 Mac 可执行文件。

总之，我们离题了：我们本应讨论 `VirtualBox` 的替代品，而不是提供有用的建议。所以，这里有免费（但非开源）的 `VMware Workstation Player`，它对于在桌面上运行单台机器来说很不错，从用户角度看，其工作原理与 `VirtualBox` 非常相似。然而，虚拟化革命的发生并非因为人们可以在另一个笨拙的桌面操作系统中窗口化运行笨拙的桌面操作系统，而是因为强大的服务器可以托管多个虚拟机——节省资源、提高可移植性，总体上让事情变得更美好。`Workstation Pro` 是 `VMware` 的商业产品，当然还有 `Hyper-V`、`Xen` 和其他革命性改变基础设施管理的专有工具。其中一个结果是便宜 `VPS`（虚拟专用服务器）的兴起，来自 `Digital Ocean` 和 `OVH` 等提供商。这是了解远程服务器管理的好方法。

Linux 进行虚拟化的方式是一个双城记：`KVM` 和 `QEMU`。`KVM` 是 `hypervisor` 部分，使内核能够访问 `CPU` 的虚拟化功能；`QEMU` 是与之通信并模拟虚拟硬件的用户空间实用程序。`KVM` 已移植到许多架构，如今在 `Arm`、`IBM s/390` 大型机和 `MIPS` 上运行。`QEMU` 是一个模拟器，我们已经谈过模拟和虚拟化是两回事——但我们稍后会看到 `QEMU` 需要做的实际模拟量可以减少到几乎为零。

`QEMU` 是一个命令行事务，但作为 Linux 爱好者或新兴的 CLI 战士，我们不会让它成为障碍。安装 `QEMU` 只需：

```bash
sudo apt install qemu
```
