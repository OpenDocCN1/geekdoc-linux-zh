
## Frost

Frost 是一个 Freeten 独立的应用程序，作为一个前端。它让在 Freeten 网络上的浏览更类似于浏览 Usenet 新闻组。下载地址：

`http://jtcfrost.sourceforge.net`

运行 Freeten 后，你可以选择同时运行 Frost 以从 Freeten 网络下载插入内容。这并非强制性的，但非常有帮助。运行 Freeten，然后运行 Frost，等待大约一小时让 Frost 找到一些小组，然后点击顶部面板上的地球按钮来订阅小组。这些小组都在讨论着世界上方方面面的话题。其中一些小组相当死气，几乎没有任何讨论，而另一些则异常活跃。

### Frost 小贴士

- 1.) 如果你在 Frost 中开始下载某些东西，请在 Frost 中完成它
- 2.) 像 Usenet 一样，不要在版块上挑事。这会让你进入用户的“忽略”列表，从以后他们将再看不到来自你昵称的任何消息。
- 3.) 永远不要向 Frost 版块上的任何人透露你的节点引用（node reference），因为它可能被用于定位你。
- 4.) 将下载天数倒退设置为 60（或你想要的任何长度）。只需注意如果你选择非常大的天数，检索所有消息可能需要几天时间。
- 5.) 在选项/偏好选项卡中，你可以调整设置，忽略昵称下关联少于四条消息用户的评论。这对于消除版块上的垃圾信息非常有效。

# 第 6 章 - Truecrypt

如果我们花费了这么多精力制定安全选项以确保我们的在线足迹不落入坏人之手，却对我们的线下足迹闭而不谈，那是愚蠢的。简单来说，你应该谨慎对待你的线下习惯，就像谨慎对待你的在线人格一样。

假设你正在你喜爱的咖啡馆里。你坐在咖啡香浓郁的角落，用笔记本电脑喝着冰咖啡，必须去去趟洗手间。只需要一分钟左右，对吧？当你进去时，坐在隔壁桌的人决定向你的笔记本电脑插入 USB 密钥，并向你的机器上传一个键盘记录器病毒。这个键盘记录器的尺寸小得离谱，大多数用户都无法察觉到。它甚至可以伪装成窗口服务，看起来和任何其他 `svchost` 进程一样，同时截取你的屏幕截图，记录你当天剩余时间内输入的所有内容，并将其发送给安装病毒的任何人。如果你知道这件事，你会有点担心的。

然而，大多数人并没有意识到他们在公共场所让自己容易受到此类攻击。一些专家将此称为“恶女仆攻击”（evil maid attack），源于这样一个场景：你住在酒店，短暂地走到外面片刻，这时有人进入并对你正在运行的机器拥有物理访问权限。他们现在可以访问你浏览器存储的每个 cookie，以及你用过的任何信用卡号、朋友可能的电话号码/电子邮件等。如何防止这种情况？

首先，为了防止身份盗用，你需要认真考虑全盘加密。这远没有你想象的那么复杂。加密你的启动驱动器简单得离谱，而且不需要你支付任何费用，并可能让你免于数月的头疼。

你有几种加密应用程序供你选择：付费程序，如 `PGP`、`Drivecrypt` 和 `Phonecrypt`，以及流行的免费版本 `PGP` 和 `Truecrypt`。它们之间存在细微差别，但免费版和付费版共同具备的点是：在没有密码的情况下，它们都能阻止启动。

`Truecrypt` 是免费的，它通过创建 256 AES 密钥来实现这一点。你安装应用程序，选择要加密的驱动器，选择你的密码。简单。

这对你有什么好处？嗯，当下一次偷你笔记本电脑的人尝试启动硬盘时，没有密码他将无计可做。他会看到一个密码字段，如果输入不正确，硬盘就会停止。密码如果足够长，足以抵御几乎任何暴力破解攻击，即使是国家安全局（NSA）。只需确保使用易于记忆但足够长的密码：15 位，包含大小写字母和两个数字。

`Truecrypt` 如何？它被认为是不可破解的，即使使用暴力破解法破解一个中等长度的密码也需要数亿。所有情况下，绝对的薄弱环节是你。如果你足够不幸中中了键盘记录器，它们可以获取你的密码。然而，如果你保持操作系统、防病毒软件和反恶意软件程序的更新，这种情况相当少见。另一个薄弱环节是你的密码。你会惊讶于有多少人在密码中使用了自己的个人信息。这样做可能会让密码更容易记忆，但也更容易被破解。在密码中每增加一个位，破解此类密码的计算需求就会翻倍。

`Dricrypt` 是另一个加密程序，但它不是开源的，也不是免费的。我使用这个程序八年了，不得不说如果预算有限，请选择 `Truecrypt`，因为它具有许多 `Truecrypt` 的功能，且免费。`Dricrypt` 有一个“`bootauth`”选项，是启动授权的缩写。安装过程与 `Truecrypt` 类似，尽管启动密码界面略有不同。你启动硬盘，然后输入密码启动操作系统。`Truecrypt` 也有这一功能。

如前所述，它不是开源的。这意味着它无法被公共部门（即：安全用户）研究，以确定是否被植入了任何后门。

...法庭指控。然而，你可以给他们你诱饵系统的密码。在没有键盘记录器（keylogger）的情况下，他们无法知道你是否隐瞒了一个隐藏的操作系统。

`Truecrypt` 和 `Drivecrypt` 不会就隐藏文件的存在提供任何提示或泄露任何数据。挂载此类文件的唯一方法是知道密码，而你通过此类选项创建了两个密码：一个用于诱饵，另一个用于隐藏容器/操作系统。

`Truecrypt` 和 `Drivecrypt` 还支持使用加密容器文件，点击该文件时，它会像 `DaemonTools` 或 `Nero` 等挂载程序挂载 iso 镜像一样挂载。在挂载之前，程序会要求你输入密码。如果密码错误，容器将完全不会挂载。这可能非常困难，因为你有许多可以向政府或任何类型的起诉机构隐藏的私密物品，例如医疗记录、税务记录、学校成绩单、业务信函等。

给 `Truecrypt`/`Drivecrypt` 用户的一些提示：

- 1.) 如果你有火线接口（firewire port），请将其禁用，因为它可以被用来泄露加密密钥。
- 2.) 在过边关站时，永远不要在笔记本电脑上留下任何挂载容器，除非你想让容器中的私密信息与守卫共享。
- 3.) 永远不要让你的电脑长时间处于开启且无人看管的状态（如公共 wifi 热点、咖啡馆、图书馆、大学教室等）。当攻击者（或其他任何人）物理接触你的机器时，所有的安全性都会化为乌有。在这种情况下，`Truecrypt` 或 `Drivecrypt` 都无法保护你的数据，因为攻击者可以安装键盘记录器记录你的击键。

### 缩略图（Thumbnails）

如果你拥有任何犯罪性快照（文件、`Wikileak` 照片、线人文件），请在稍后删除文件夹中的图像，但请注意影子副本（shadow copy）仍然存在。在 Windows XP 中（是的，仍有大量用户固守着这个系统），jpeg 的缩略图存储在图像位置的每个文件夹中。因此，如果你有一个名为“政府办公室快照”（government office snapshots）的文件夹，你将在文件夹设置中开启任何图片（jpegs、位图等）的缩略图，并且会出现一个隐藏的 `thumbs.db` 文件，它会显示该图片的微型版本。因此，即使你删除了 jpegs，这个隐藏文件仍然会向任何人暴露原始文件夹的内容。查看或禁用此隐藏文件的唯一方法是进入“工具 – 选项 – 查看”，并将选项设置为“显示隐藏的文件和文件夹”。

在完成此操作之前，每个包含图片的文件夹都会存储图片的微型快照，除非禁用此功能。Windows 7 是与 Windows XP 完全不同的文件系统。它不是将缩略图缓存存储在图片所在的文件夹中，而是存储在中心位置（`%userprofile%\AppData\Local\Microsoft\Windows\Explorer`）。

我发现直接在 Windows 7 中保留缩略图选项要好得多，因为图像加载相当快，不需要缓存来加速。还有其他文件，如文本、音频等，如果你不采取措施安全地删除文件，它们也面临被发现的风险。然而，这并不意味着已经从回收站中删除了。当你从回收站中删除任何项目时，这只是告诉操作系统之前被该文件占用的空间可以再次写入。在空间被其他程序再次覆盖之前，它不会永久删除该文件。

政府机构拥有可以删除文件的程序。绕过此限制的方法是使用各种程序安全地删除文件，例如 `Cleaner`。该应用也有一个有趣的擦除实用程序，它可以擦除硬盘上之前删除的任何内容的空闲空间。你甚至可以在操作系统运行时进行此操作。

不用说，如果你有一个 2TB 的硬盘，且只使用了 20%，剩余 80% 为“空闲空间”，那么完成擦除过程需要几个小时，取决于硬盘的速度以及你正在运行的其他程序。除非你告诉它，否则它不会碰到系统中已存在的任何安装程序，即使如此，只有空闲空间会被分配用于使用。

### 交换文件（Swap file）

简要讨论一下大多数操作系统使用的“交换”文件。这意味着在 PC 高负载使用期间，你的系统内存可能会不足，此时操作系统将使用硬盘作为临时 RAM 存储设备。这就是所谓的“交换文件”，它可以提高计算机运行速度。对于怀有不轨胎的人来说，这个交换文件可能是一个真正的数据金矿。文本文件、视频缩略图和 Word 文档片段可能存在此，足以打印出你过去的一个相当不错的快照。甚至出现过仅凭缩略图碎片就在法庭上被定罪的案例。你可以通过控制面板，系统和安全 – 系统 – 高级 – 性能 – 设置 – 高级 – 内存并点击“更改”来禁用 Windows 使用的交换文件。选择“无分页文件”。重启。
