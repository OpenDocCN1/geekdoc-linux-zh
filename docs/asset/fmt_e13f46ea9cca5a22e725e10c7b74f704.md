
$\phi$ 的旋度有两个重要的性质。`Grad` $\phi$ 是一个垂直于表面 `(x, y, z)` 的法向量，它在平面的每一点都是恒常的。此外，`grad` $\phi$ 产生一个旋度为零的场，且线积分与路径无关。斯托克斯定理（`Theorem of Stokes`）指出式 `(16)` 成立，其中 `'I'` 是表面 `S` 的边界。

由式 `(9)` 定义的 `del` 算子（`nabla`）在向量积分的发展中起着重要作用。对于式 `(10)` 的向量场：

```
$$\begin{aligned} \nabla \mathbf{v} &= \mathbf{i}\frac{\partial v_x}{\partial x} +\mathbf{j}\frac{\partial v_y}{\partial y} +\mathbf{k}\frac{\partial v_z}{\partial z} (9) \end{aligned}$$
```

$\mathbf{v}$ 的散度由 `(11)` 定义。旋度的散度为：

```
$$\begin{aligned} \mathbf{div} \mathbf{v} &= \frac{\partial v_x}{\partial x} + \frac{\partial v_y}{\partial y} + \frac{\partial v_z}{\partial z} (11) \end{aligned}$$
```

通过使用 `del` 算子，我们可以得到式 `(12)` 的值。$\mathbf{v}$ 的旋度在以下条件下是 ($\mathbf{v}$) 的旋度：它是表面的反射，...因此 $\mathbf{v}$ 的旋度是一个向量场。

如果一个向量场 $\mathbf{F}$ 定义在表面 `S` 外部，那么 `(13)` 代表 $\mathbf{F}$ 穿过表面 `S` 的总通量：

```
$$\begin{aligned} \int_S \mathbf{F} \cdot d\mathbf{S} &= \int_V (\nabla \cdot \mathbf{F}) \ d\mathbf{V} (14) \end{aligned}$$
```

卡尔拉的形成是因为地下 2-3 公里（2-4 英里）岩浆房岩浆被抽取，导致顶部的塌陷。岩浆的抽取要么通过相对爆炸性的喷发发生（如火山屑岩腔的情况），要么通过构造塌陷发生，并形成卡尔拉。

高斯散度定理指出，当区域 `R` 由 `S` 边界时，式 `(14)` 成立，正如高斯定理（`GAUSS' THEOREM`）所述。

爆炸形成的喷发可能持续几天或几年（地质意义上），深处的熔融岩浆中产生火山屑物质。岩浆在喷发柱中破碎成微小碎片，上升到大气层几英里高。这是喷发的第一也是最具爆炸性的阶段，就像覆盖喷口周围区域的岩流一样。卡尔拉可以在喷发塌陷时形成，此时爆炸性较小。

向量的线积分描述如下：设 `G` 为一条曲线，设 $\mathbf{F}$ 为在 `A` 点切于 `G` 的向量场，起始和结束于 `G` 的点。式 `(15)` 中的标量积分被称为线积分：

```
$$\begin{aligned} \int_A^B \mathbf{F} \cdot d\mathbf{r} &= (15) \end{aligned}$$
```
