
# 第 7 章 · 性能分析技术

## 内存传输

系统从一个位置复制内存块到另一个位置的速度有多快？人们可能会认为这种操作独立于操作系统。如果有差异，我们希望了解这些差异。由于我们寻找的是最佳性能，编译将采用完全优化。我们的内存到内存拷贝程序称为 `memxfer.cpp`。程序的主循环如下：

```c
for(i = 0; i < cnt; i++) {
    printf("%s %d %-18.18s\n", proname, cnt, methods[method]);
    tstart();
    if(freelag == 1) {
        p1 = (char *)Malloc(size);
        p2 = (char *)Malloc(size);
    }
    switch(method) {
        case 0:
            (void)memcpy(p1, p2, size);
            break;
        case 1:
            p = p1;
            q = p2;
            for(j = 0; j < size; j++)
                *p++ = *q++;
            break;
        case 2:
            sp = (short *)p1;
            sq = (short *)p2;
            for(j = 0; j < size; j += sizeof(short))
                *sp++ = *sq++;
            break;
        case 3:
            ip = (int *)p1;
            iq = (int *)p2;
            for(j = 0; j < size; j += sizeof(int))
                *ip++ = *iq++;
            break;
        case 4:
            lp = (long *)p1;
            lg = (long *)p2;
            for(j = 0; j < size; j += sizeof(long))
                *lp++ = *lg++;
            break;
        case 5:
            llp = (int64 *)p1;
            llq = (int64 *)p2;
            for(j = 0; j < size; j += sizeof(int64))
                *llp++ = *llq++;
            break;
        case 6: // partially unwound loop.
            dp = (double *)p1;
            dq = (double *)p2;
            for(j = 0; j < size; j += 4*sizeof(double)) {
                *dp++ = *dq++;
                *dp++ = *dq++;
                *dp++ = *dq++;
                *dp++ = *dq++;
            }
            break;
    }
    if(freeflag == 1) {
        free(p1);
        free(p2);
    }
    tend();
    t = tval();
    if(t == 0.0) {
        t = .01;
        printf("%8.2f seconds %8.2f MB/s\n", t, (double)size/t/1000000.);
    }
}
```

`memxfer` 的调用方式如下：

用法: `memxfer [-f] size cnt [-cnt] [method]`
`-f` 标志设置为对 "cnt" 次进行 `malloc` 和 `free`。

methods：
- 0: "memcpy (默认)"
- 1: "char *"
- 2: "short *"
- 3: "int *"
- 4: "long *"
- 5: "int64 *"
- 6: "double *"

例如，以下命令将分配 64 KB 内存并执行八次每次 64 KB 的内存拷贝，使用默认方法 `memcpy`：
`memxfer 65536 8 -`
