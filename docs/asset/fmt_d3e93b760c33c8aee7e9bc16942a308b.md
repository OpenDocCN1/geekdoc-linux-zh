## 相机映射 (CAMERA MAP)

与附录之前解释的 `Camera Map (WSM)` 修改器类似，有时你可能希望对象在设计存在的同时保持不可见。例如，假设你有一张显示车库的背景图像，你想创建一个汽车进入车库的幻象。你可以创建一个与背景车库开口形状相似的简单箱体，然后使用 `Camera Map` 修改器将对象混合到背景中。完成后，你可以让汽车驶入箱体。最终效果是，在最终动画中汽车似乎驶进了背景图像中的车库。这允许你保持几何形状简单，同时具有显示相当细节的动画。

`Camera Map` 修改器对对象应用平面 `UVW` 贴图，并与指定的相机对齐。贴图通常与背景相同，产生隐藏对象的幻觉。由于对象可以投射和接收阴影，你可以创建不同的效果。例如，如果你使用 `Camera Match` 将设计匹配到建筑现场的照片，你可以使用 `Camera Map` 修改器在背景上包含阴影。

当没有相机运动时，该修改器的对象空间版本是更好的选择。（见本附录后后的“材质”部分。）

## 封孔 (CAP HOLES)

某些编辑会在网格中留下开口。例如，你可能使用 `Slice` 将对象切分为两半。每个部分在切片平面处都有开口。`Cap Holes` 可用于封闭这些开口。

在 `VIZ` 中，洞是一个具有尖锐面的边缘闭合环路。`Cap Holes` 适用于平面孔，但也适用于非参数化孔。`Cap Holes` 与 `STL` 修改器配合使用时是一个非常有用的工具；如果你在 `STL`（立体固化）检查中发现网格存在问题，使用 `Cap Holes` 可能会修复这些问题。

## 截面 (CROSSSECTION)

`CrossSection` 修改器是一个连接样线形成表面的强大工具。（如果你使用 `AutoCAD`，可以将 `CrossSection` 视为 `Edgesurf` 命令。）该修改器被称为截面，是因为你可以绘制对象的截面并连接它们形成表面。

与 `Surface` 修改器配合使用时，`CrossSection` 允许通过两个或多个 3D 样线定义表面边缘。首先绘制样线；然后使用 `Modify` 卡上的连接选项将它们合并为单个对象。然后应用 `CrossSection` 修改器，它连接样线的顶点。最后使用 `Surface` 修改器在样线上进行“皮肤”（见图 B.3）。

# 修改器 (MODIFIERS)

## 89

## DELETEPATCH

你可以将 `DeletePatch` 修改器视为工具，允许你在 `Patch` 对象中尝试删除操作。由于它是一个修改器，它可以放置在修改器堆栈的任何位置。它的工作原理与 `DeleteMesh` 修改器（在上一节介绍）类似。由于 `DeletePatch` 是一个修改器，你可以通过从修改器堆栈中移除 `DeletePatch` 来恢复被删除的项目。

## DELETESPLINE

`DeleteSpline` 与 `DeleteMesh` 类似，但它作用于样条（`splines`）而非网格。子对象选择限于限于顶点、线段和样条。

## DISP APPROX

`Disp Approx`（位移贴近似）修改器允许你通过材质通道对对象应用位移贴。该修改器的教程可以在第 15 章找到。

## DISPLACE

`Place` 修改器允许你直接对对象应用位移贴，而无需通过材质来实现。这与 `DispApprox` 修改器类似，但不需要任何材质。

## EDIT MESH

与 `Edit Spline` 修改器一样，`Edit Mesh` 看起来似乎有些多余，因为它复制了可编辑网格（`editable meshes`）的参数。然而，`Edit Mesh` 在编辑网格方面提供了极大的灵活性，允许你在修改器堆栈中的任何位置进行编辑。你可以实验网格的变化，保持其他可能因网格编辑而发生改变的修改器和参数，或者编辑多个网格对象。`Edit Mesh` 修改器使用的内存比简单的 `Edit Mesh` 对象要多。因此，除非你真的需要它提供的灵活性，否则请避免使用它。

## EDIT PATCH

`Edit Patch` 修改器允许你像编辑可编辑 `Patch` 对象一样编辑对象（有关可编辑 `Patch` 对象的更多信息，请参见附录 C）。`Edit Patch` 修改器消耗大量的 `RAM`，因为它可能为了执行其功能而在 `RAM` 中创建所选几何体的副本。尽管如此，`Edit Patch` 适用于那些想要尝试选项，或必须放置先前的修改器和参数选项的情况。

## EDIT POLY

`Edit Poly` 是另一个修改器，允许你像编辑简单几何对象（在此情况下为可编辑多形体对象）一样编辑对象。使用 `Edit Poly` 可以控制所有的可编辑多形体工具，而无需实际上将网格转换为可编辑多形体。仅使用此修改器测试工具，然后转换对象或折叠修改器堆栈以保存编辑并减少文件大小和 `RAM` 使用。由于其工具集更丰富，`Edit Poly` 通常优于 `Edit Mesh`。

## EDIT SPLINE

`Edit Spline` 修改器似乎有些多余，因为它复制了样条对象（`Spline objects`）的参数，尽管有一些限制。`Edit Spline` 在编辑样条方面提供了灵活性，允许你在修改器堆栈中的任何位置进行编辑。例如，你可以使用 `Edit Spline` 测试样条编辑。由于它是一个修改器，你可以通过从修改器堆栈中删除它来轻松放弃使用 `Edit Spline` 所所的更改——这是使用样条的基本参数时无法实现的。`Edit Spline` 也用于通过对一组对象应用单个 `Edit Spline` 修改器来同时对多个形状应用更改。你可能还想保留其他会因形状基本参数更改而受影响的修改器。

### 考虑 EDIT SPLINE 修改器的内存使用

`Edit Spline` 修改器使用的内存比简单的可编辑样条对象多得多。因此，除非你需要它提供的灵活性，否则请尽量避免使用此修改器。

## EXTRUDE

`Extrude`（挤出）用于以线性方式将 2D 形状扩展到第三维。`VIZ` 形状、`NURBS` 曲线和从 `CAD` 程序导入的形状都可以进行挤出。`Extrude` 修改器提供了封端（`cap ends`）的选项，这会关闭挤出的闭合形状顶部底部形成的开口。你还可以选择由 `Extrude` 创建的网格类型。

## FACE EXTRUDE

`Face Extrude`（面挤出）修改器允许你仅挤出网格的选面。你必须首先在对象的子对象级上选择面。然后你可以应用 `Face Extrude` 修改器来影响选面。虽然你可以在可编辑网格或可编辑多形体的子对象级使用 `Extrude` 选项，但 `Face Extrude` 修改器使用的资源更少，并提供了额外的选项，例如比例（`Scale`）和从中心挤出（`Extrude from Center`）。你可以通过这些选项实现倒角效果。选择修改器必须放置在 `Extrude` 下，并向上传递子对象选择。

## FFD (2×2, 3×3×3, 4×4×4)

自由形式变形（`FFD`）修改器允许你通过控制点拉伸和拉对象来以通用方式变形对象。当你应用 `FFD` 修改器时，选择对象周围会出现一个晶格框（`lattice box`）。你可以使用框上的控制点来推或拉对象的形状（见图 B.5）。晶格框是一种工具（`gizmo`），不代表实际几何体。
