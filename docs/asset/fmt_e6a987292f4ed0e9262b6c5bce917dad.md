
## 图像编辑软件

图像编辑软件通过裁剪、修饰和色彩调整来处理数字照片。它包括矢量、位图和 3D 工具，用于增强或从零开始创建图像。它主要用于 2D 编辑，支持如调整图像大小和应用滤镜以调整图像属性或添加效果的任务，同时也方便了格式转换。

`GIMP`（或 `GNU` 图像操纵程序）是一款用于照片编辑、图像合成等功能的免费工具。它提供了诸如绘画工具、图层支持以及带有完整 `Alpha` 通道支持的高处理功能。`GIMP` 可以通过插件和脚本进行扩展，运行在多种平台上，并支持许多文件格式。它非常适合简单任务和复杂的图像编辑需求。

`Blender` 是一款免费的开源 3D 创建套件，用于建模、动画、特效和视频编辑。它是跨平台的，运行在 `Linux`、`macOS` 和 `Windows` 上，专为专业人士和爱好者设计。凭借全的工具集，`Blender` 支持从游戏资产到电影的各种媒体制作。其由 `OpenGL` 驱动的界面确保了跨设备的一致体验，其活跃的社区也提供了详尽的支持和学习资料。`Blender` 强调在创作数字艺术时，艺术技能与技术知识同样重要。

`Pinta` 是一款开源的跨平台图像编辑器，类似于 `Paint.NET`，但具有更广泛的适用性以及比微软画图更丰富的功能。它为位图图像编辑提供了一个简单而强大的工具箱，包括绘图工具、滤镜、色彩调整，并支持多个图层以进行复杂编辑。它以易用性为设计目标，拥有无限的撤销历史、多语言支持以及可以容纳浮动和停靠窗口的可定制工作区。`Pinta` 在简单性与强大的图像编辑能力之间的平衡脱颖而出，成为寻求易用且功能强大的图像编辑解决方案用户的首选。

`Krita` 是一款面向数字艺术家和动画师的多功能、免费开源图形编辑器，支持在 `Linux`、`Windows` 和 `macOS` 等多个平台上提供 2D 动画和艺术创作工具。它具有 `OpenGL` 加速的画布、带有 100 多种预载笔刷的高级笔刷引擎、非破坏性图层、矢量支持以及带有面板和面板的可定制界面，以适应任何工作流。`Krita` 还包含了用于流畅笔触的笔刷稳定器、用于漫画的内置矢量工具以及用于共享或导入笔刷的资源管理器，使其成为在数字艺术项目中寻求灵活和精度的创作者的强大工具。

`Inkscape` 是一款多功能免费开源矢量图形编辑器，运行在包括 `Windows`、`macOS` 和 `Unix` 类系统在多个平台上。得益于其矢量方法，它擅长创建清晰、可扩展的插图（如卡通、标志和图表），且不受像素限制。`Inkscape` 支持 `SVG` 作为主要格式，处理广泛的文件类型。它的工具允许使用形状、文本、颜色和渐变进行复杂设计，同时还提供了直接从位图源转换并编辑图像为矢量艺术的功能。

`Darktable` 是一款免费的开源摄影应用和 `Raw` 显影工具，专注于非破坏性后期处理。它优化了工作流，能够在各种平台上高效处理大量图像。通过实时调整、`GPU` 加速和对许多图像格式的支持等功能，它通过色彩校正、特效和组织模块增强图像编辑。`Darktable` 支持非破坏性编辑、`ICC` 配置文件以及用于自定义的 `Lua` 脚本。其 `UI` 包含了轻型台（`lighttable`）和暗室（`darkroom`）模式以便于导航和编辑，此外还有快照和地图视图用于全面的感光图像管理。

`Tux Paint` 是一款专为 3 到 12 岁儿童设计的免费开源绘图软件。它由 `Bill Kendrick` 于 2002 年创建，是专有教育程序的一种具有吸引力的替代品，提供了一个充满趣味效果和绘图工具的简单界面，以激发孩子的创造力。它支持 `Windows`、`macOS` 和 `Android` 等多个平台，使其在全球范围内得以普及。在吉祥物 `Tux` 的引导下，孩子们可以通过各种工具和效果探索艺术，而教师和家长可以使用额外内容自定义体验。`Tux Paint` 是在教育环境中培养计算机素养和艺术技能的理想选择，因其易用性和包容性设计而广受赞誉。

### Pinta

访问 `Pinta` 官方网站 https://www.pinta-project.com/ 了解关于 `Pinta` 的所有信息。

通过软件管理器安装 `DEB/FLATPAK` 软件包：

* 打开软件管理器并搜索 `Pinta`。
* 点击 `Pinta`，然后点击源选择框。
* 选择系统软件包或 `Flatpak` 并点击安装。

在终端中通过 `APT` 安装 `Pinta`：

只需输入以下命令：

```bash
sudo apt update
```

```bash
sudo apt install pinta
```

通过 `Snap Store` 安装 `Snap` 软件包：

* 在 `Snap Store` 中查找 `Pinta`。
* 点击 `Pinta`，然后点击源选择框。
* 选择 `Snap` 下的最新/稳定版本并点击安装。

在终端中通过 `Snap` 安装 `Pinta`：

输入此命令：

```bash
sudo snap install pinta
```

在终端中通过 `Flatpak` 安装 `Pinta`：

输入此命令：

```bash
flatpak install flathub com.github.PintaProject.Pinta
```
