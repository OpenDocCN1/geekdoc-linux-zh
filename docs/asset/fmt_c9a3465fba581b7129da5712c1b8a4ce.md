
```
tar -cvf etc.tar /etc
```

如果你想用 Gzip 压缩归档，请添加 `z` 选项：

```bash
tar -cvzf etc.tar.gz /etc
```

如果你想用 bzip2 压缩归档，请添加 `j` 选项：

```bash
tar -cvjf etc.tar.bz2 /etc
```

如果归档的大小超过了磁带的容量，你将需要添加 `-M` 选项。这将允许 `tar` 跨越多个磁带。

```bash
tar -cvfM etc.tar /etc
```

当任务完成后，你可以使用 `mt` 回退磁带：

```bash
mt -f /dev/sto eof
```
