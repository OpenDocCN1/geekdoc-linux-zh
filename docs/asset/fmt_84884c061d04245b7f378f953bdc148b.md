**第 1 步** 任何你想让用户输入程序的内容都必须存储在系统内存的某处，以便检索和使用。因此，任何输入必须首先声明为一个变量，以便供用户使用。从创建一个包含头文件的 C++ 文件开始。

## 第 8 步

虽然 `cin` 适用于大多数输入任务，但它有一个局限性。它总是将空格视为单词边界而非多个单词。然而，获取 `cin` 作为第一个参数并将变量作为第二个：

```cpp

    cout << "Your sentence is: " << name << " long.\n";
}
```
