
不会影响调用者的 shell 变量。注意——shell 函数与调用 shell 共享 `OPTIND`。使用 `getopts` 解析参数的函数通常会在进入时保存 `OPTIND` 的值，以便为调用 shell 更改 `OPTIND`。

## Examples

以下示例脚本解析并显示其参数。

```
aflag=

bflag=

while getopts ab: name

do

  case $name in

    a) aflag=1

    b) bflag=1

       bval="$OPTARG";

    ?) printf "Usage: %s: [-a] [-b value] args\n" "$0"

  exit 2;

  esac

done

if [ -z "$aflag" ]; then

    printf "Option -a specified\n"

fi

if [ -z "$bflag" ]; then

    printf "Option -b %s specified\n" "$bval"

fi

shift $((OPTIND - 1))

printf "Remaining arguments are: %s\n" "$*"
```

## gettext — 从消息数据库检索文本字符串

### 概览

```
/usr/bin/gettext [textdomain] msgid
```

## 描述

`gettext` 从由 `msgfmt(1)` 生成的消息对象检索与字符串 `msgid` 对应的翻译后的文本字符串。消息对象的名称源于可选参数 `textdomain`（如果存在）；否则源于环境变量 `TEXTDOMAIN`。如果你没有指定域（domain）或无法找到相应的字符串，`gettext` 将打印 `msgid`。

通常情况下，`gettext` 在 `/usr/lib/locale/lang/LC_MESSAGES` 中查找其消息对象，其中 `lang` 是本地区域名称。如果存在 `TEXTDOMAININIR` 变量，则将替换路径中的 `lang` 部分。

此命令解释诸如 `\t`（制表符）之类的转义序列。使用 `\` 打印反斜杠。要单独占一行输出消息，可以在 `msgid` 的末尾添加 `\n`，或者配合 `printf(1)` 使用此命令。

> 注意 — 此命令是库函数 `gettext(3)` 的 shell 等效实现。

## 环境变量

`LANG` 指定本地区域名称。
`LC_MESSAGES` 指定消息本地区域，如果存在，则覆盖消息的 `LANG` 设置。
`TEXTDOMAIN` 指定域名，它与不带 `.mo` 后缀的消息对象文件名相同。
`TEXTDOMAINDIR` 指定消息数据库的路径，如果存在，则使用它代替 `/usr/lib/locale`。
