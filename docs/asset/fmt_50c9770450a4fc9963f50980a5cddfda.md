
比喻和间接语言具有暗示的力量，因为它们没有做出可以被反驳的陈述。它们不会在观众脑海中引起矛盾的思想，从而履行了暗示的基本要求之一。通过在间接或比喻语言中暗示结论，往往能强有力地主张。

注意，在接下来，布莱恩先生并没有说麦金利先生将会失败。他以一种更有效的方式暗示了这一点：

麦金利先生在圣路易斯被提名，其平台主张维持金本位，直到通过国际协议将其改为双金属货币制。麦金利先生是共和党最受欢迎的人，三个月前，共和党每一个人都预言他将当选。为什么今天不是呢？为什么，那个曾经乐于认为自己看起来像拿破仑的人，今天在想起自己是在滑铁卢战役纪念日被提名的时，却在发抖？不仅如此，当他倾听时，他能越来越清晰地听到海浪拍打在圣赫勒拿孤独岸边的声音。

如果卡莱莱说：“虚伪的人找不到宗教，”他的话既不会是那样有力量，也不可能像他在这些引人注目的话语中的暗示那样被长久记住：

一个虚伪的人找到了宗教？为什么，一个虚伪的人造不起砖房！如果他不真正地了解并遵循砂浆、烧粘土以及他所作用的其他材料的特性，他造的就不是房子，而是一堆垃圾。它无法立足十二世纪来容纳一亿八十万；它会立即倒塌。人必须顺应规律，真正与自然以及事物的真理交流，否则自然将回答他：不，绝不绝！

观察韦伯斯特在这里描绘的画面如何比任何单纯的断言都更加强调和更有力：

先生，我不知道别人感受如何，但对我自己来说，当我看到我的母校像凯撒在元老院一样，被那些反复一刺又一刺的人包围时，我宁愿让这只手转过来对我说：“还有你也是，我的儿子！”

## 第二十三章

236 从两个方面来看：建立论证，拆解论证；也就是说，你不仅必须检查你论证结构的稳定性，使其既能支持你想要探究的命题，又稳固到无法被对手推翻，你还必须敏锐地察觉论证中的缺陷，以便拆解那些反对你者的较弱的论点。

我们可以仅泛泛地考虑论证，将细微的技术讨论留给如乔治·P·贝克的《论证的原理》和乔治·雅各布·霍约奥克的《公共演讲与辩论》等优秀著作。任何优秀的大学修辞学著作也能对这一主题提供帮助，特别是约翰·富兰克林·比德和亚当斯·谢尔曼·希尔的作品。敦促学生熟悉这些文本中的至少一种。

接下来的系列问题希望能起到三重目的：一是无论如何使用证明方法，都提供证明的形式建议；二是帮助演讲者测试其论点的强度；三是演讲者能够以敏锐且公正的立场攻击对手的论点。

### 论点的测试

#### 一、 讨论的问题

1. *是否表述清晰？*
    - (_a_) 陈述中的术语对每位争论者是否含义相同？（例如，“绅士”一词的含义可能无法达成共识。）
    - (_b_) 目的是否可能引起混乱？
2. *是否表述公正？*
    - (_a_) 是否包含了足够的内容？
    - (_b_) 是否包含了过多的内容？
    - (_c_) 表述是否带有陷阱？
3. *这是一个可供辩论的问题吗？*
4. *整个问题的关键点是什么？*
5. *从属点有哪些？*

#### 二、 证据

1. *关于事实的证人*
    - (_a_) 每个证人都是中立的吗？他与争议话题是什么关系？
    - (_b_) 他的心理能力健全吗？
    - (_c_) 他在道德上可信吗？
    - (_d_) 他是否有可能事实？他是目击者吗？
    - (_e_) 他是自愿的证人吗？
    - (_f_) 他的证言是否被反驳？
    - (_g_) 他的证言是否得到证实？
    - (_h_) 他的证言是否与众常事实或一般原则相悖？
    - (_i_) 它可能发生吗？
2. 被引为证据的权威
    - (_a_) 该权威是否被广泛认可？
    - (_b_) 什么使他成为权威？
    - (_c_) 他对本案的利益是中立的吗？
    - (_d_) 他是否明确且清晰地陈述了他的意见？
    - (_e_) 所引用的非个人权威（书籍等）是否可靠且无偏见？
3. 作为证据引出的事实
    - (_a_) 它们的数量足以构成证明吗？
    - (_b_) 它们的性质是否足够重要？
    - (_c_) 它们是否符合逻辑？
    - (_d_) 它们是相互和谐还是相互矛盾？
    - (_e_) 它们是被承认、怀疑还是争议的？
4. 作为证据引出的原则
    - (_a_) 它们是公理吗？
    - (_b_) 它们是普遍经验的真理吗？
    - (_c_) 它们是特殊经验的真理吗？
    - (_d_) 它们是通过实验得出的真理吗？此类实验是特殊的还是普遍的？实验是否具有权威性和结论性？

#### 三、 推理过程

1. 归纳法
    - (_a_) 事实是否足够多，以支持接受概括具有结论性？
    - (_b_) 事实仅在将此解释作为结论来考虑时才一致吗？
    - (_c_) 你是否忽略了任何矛盾的事实？
    - (_d_) 当接受这一推理为真时，矛盾的事实是否得到了充分解释？
    - (_e_) 是否已证明所有对立立场相对来说都是站不住脚？
    - (_f_) 你是否将单纯的意见视为了事实？
2. 演绎法
    - (_a_) 该法律或一般原则是建立公认的吗？
    - (_b_) 该法律或原则是否清晰地包含了你想从中推导出的事实，还是说你牵强了推理？
    - (_c_) 该法律或原则的重要性是否足以支持如此重要的推理？
    - (_d_) 能否证明该演绎推导得过头？
3. 平行案例
    - (_a_) 案例在足够的点上是平行的，以支持推导出相似的因果关系的结论吗？
    - (_b_) 案例在争议的关键点上是平行的吗？
    - (_c_) 平行性是否被牵强了？
    - (_d_) 是否没有其他指向更强反向结论的平行案例？
4. 推论
    - (_a_) 前提条件是否足以使指控变得可能？（例如，被告的性格和机会。）
    - (_b_) 指向推理的迹象是否足够清晰或充足，以支持将其作为事实接受？
    - (_c_) 迹象是累积的且相互一致的吗？
    - (_d_) 迹象可以被指向相反的结论吗？
5. 三段法
    - (_a_) 三段法中是否省略了任何步骤？（例如在省略三段法 *enthymeme* 中。）如果是，请通过补全三段法来测试此类情况。
    - (_b_) 你是否犯了陈述一个并不成立结论的错误？（不当结论 *non sequitur*。）
    - (_c_) 你的三段法可以被归为荒谬吗？（归谬法 *reductio ad absurdum*。）
