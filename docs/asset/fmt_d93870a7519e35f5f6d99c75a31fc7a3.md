## 验证安装

现在你已经成功安装了 DB2，应该通过访问安装期间创建的示例数据库（称为 `SAMPLE`）中的数据来验证安装。要验证安装并访问 `SAMPLE` 数据库中的数据，请执行以下步骤：

- 1. 以 DB2 安装程序在安装期间创建的实例的所有者（`instance-owner`）身份登录系统。对于我们的示例，输入以下命令：

```bash
su - db2inst1
```

> 提示 如果你使用此方法登录系统验证安装，你必须像上例所示带有 – 参数地输入此命令。如果你作为 `su db2inst1` 输入此命令，将收到错误，因为 DB2 将无法正确读取 DB2 配置。

- 2. 使用 `db2start` 命令启动数据库管理器。要访问位于实例中的数据库，该实例必须启动并运行。如果你还记得，我们选择了让此实例自动启动；输入此命令后，你应该收到以下消息：

SQL1026N The database manager is already active.

> 提示 如果你收到 SQL1007N 消息 “1393 could not be retrieved. Reason Code: “1” 错误，不要担心！DB2 并不知道默认实例是什么。如果你的 DB2 配置文件在登录时没有执行，就会发生。对于此示例，如果你收到此错误，请输入 `export DBINSTANCE=db2inst1` 命令。

- 3. 输入以下命令连接到 `SAMPLE` 数据库：

```bash
db2 connect to sample
```

你应该收到以下输出：

```
Database Connection Information

Database server = DB2/LINUX 6.1.0

SQL authorization ID = DB2INST1
```

本地数据库别名 = SAMPLE

- 4. 输入命令选择 staff 表中属于部门 20 的所有员工列表：

```bash
db2 "select * from staff where dept = 20"
```

注意 你必须确保命令带有双引号（""），以确保 Linux 不将星号（*）误认为操作系统命令。如果你执行带有在操作系统上可能具有特殊含义的字符的 DB2 命令，你应该用引号将命令内容括起来，所示。

你应该收到以下输出：

| ID | NAME | DEPT | JOB | YEARS | SALARY | COMM |
|---|---|---|---|---|---|---|
| 10 | Sanders | | Mgr | 7 | 18357.50 | |
| 20 | Pernal | 20 | Sales | | 18171.25 | 612.45 |
| 80 | James | 20 | Clerk | | 13504.60 | 128.20 |
| 190 | Sneider | 20 | Clerk | 8 | 14252.75 | 126.50 |

- 5. 输入命令重置数据库连接：

```bash
db2 connect reset
```
