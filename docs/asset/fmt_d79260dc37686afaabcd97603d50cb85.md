`ps -el` 长列表中的字段描述如上，它们共同指示进程当前的状态。

- `F`: 标志位，用于历史目的。
- `S`: 进程的状态，由以下字母之一表示：
    - `O`: 正在处理器上运行。
    - `S`: 睡眠状态；等待 I/O 事件完成。
    - `R`: 准备就绪状态。
    - `I`: 空闲状态；进程正在创建。
    - `Z`: 僵尸状态。进程已终止且父进程正在等待，但该进程仍留在进程表中。
    - `T`: 停止状态；正在跟踪进程。

- `X`: 等待更多内存。
- `UID`: 进程所有者的 ID。
- `PID`: 进程 ID。
- `PPID`: 父进程 ID。
- `C`: CPU 使用率（即进程使用的 CPU 时间百分比估算值）。
- `CLS`: 调度类。仅在使用 `-c` 选项时打印。
- `PRI`: 调度优先级。数字越大优先级越低。
- `NI`: 影响进程调度优先级的数值。进程 nice 表示降低其优先级使其不使用过多 CPU 时间。
- `ADDR`: 进程的内存地址。
- `SZ`: 进程所需的虚拟内存。此数字表示进程对系统内存的需求。
- `WCHAN`: 进程睡眠的事件地址。如果此列为空，则进程正在运行。
- `TTY`: 进程（或其父进程）启动的终端，或问号表示没有控制终端（通常表示系统进程）。
- `TIME`: 进程启动以来使用的 CPU 时间总量。
- `COMD`: 生成进程的命令。

`ps -f` 报告中的字段如下：

- `UID`: 进程所有者的 ID。
- `PID`: 进程 ID。
- `PPID`: 父进程 ID。
- `C`: CPU 使用率（即进程使用的 CPU 时间百分比估算值）。
- `STIME`: 进程启动时间，格式为时、分、秒。在执行 `ps` 命令前超过 24 小时的进程以月和日显示。
- `TTY`: 进程（或其父进程）启动的终端，或问号表示没有控制终端（通常表示系统进程）。
- `TIME`: 进程启动以来使用的 CPU 时间总量。
- `COMD`: 生成进程的命令。

指定 `-j` 选项时，会打印额外的列：

- `PGID`: 进程组 ID。
- `SID`: 会话领导者的进程 ID。

指定 `-L` 选项时，会打印额外的列：

- `LWP`: 报告的轻量级进程的 lwp ID。
- `NLWP`: 如果也指定 `-f` 选项，进程中 lwp 的数量。

使用 `-L` 选项时，进程中的每个 lwp 打印一行，`STIME` 和 `TIME` 字段显示 lwp 的值而不是进程的值。传统的单线程进程包含一个 lwp。已退出有父进程但未被等待的进程标记为 `<defunct>`（僵尸进程）。

## 创建自定义报告

你可以使用 `-o` 选项创建自定义报告，只显示你感兴趣的信息列。你通过提供一个你所需的列列表作为单个参数来指定格式。名称必须是逗号分隔的列表，或者是用空格或逗号分隔的引号列表，如下示例所示。

```
castle% ps -o "user pcpu nice args"

USER %NI COMMAND

winsor 0.0 20 /bin/csh

castle% ps -o user,pcpu,nice,args

USER %CPU NI COMMAND

winsor 0.0 20 /bin/csh

castle%
```

每个变量都有默认头部。你可以通过在 `-o` 选项中附加等号和头部的新文本来覆盖默认头部。报告按照命令行上指定的顺序写入字段，并以列的形式安排输出。字段的宽度由系统选择，至少与头部等宽。如果头部文本为空（如通过 `-o=` 指定），则至少与默认头部等宽。如果所有头部文本字段为空，则不显示头部行。
