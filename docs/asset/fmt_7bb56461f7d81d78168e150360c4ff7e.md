
# VMS（引号表示小写）

你也可以指定负选项来覆盖默认值。在不希望的选项前加上一个或多个连字符。例如，如果你不喜欢汇总行，可以指定 `-1-t` 或 `--tl` 选项。第一个连字符是标准的切换字符，但第二个也被解释为负号。这种连字符的双重用途可能看起来有点别扭，但它是直观的。在第一个连字符之后，任何其他连字符都表示负选项。这种语法与 UNIX `nice(1)` 命令的行为一致。

## 缺陷

与 `unzip` 一样，`zipinfo -M`（more）选项在处理屏幕输出方面过于简单。它无法检测长行的换行，并可能在它们被读取之前就滚动到了屏幕顶部。`zipinfo` 应该检测并处理每次换行，将其视为额外打印的一行，这需要同时知道屏幕的宽度和高度。此外，`zipinfo` 应该在所有系统上检测真实的屏幕几何结构。

多种列表格式没有必要那么复杂，可以进行简化。（这并不是说它们会被简化。）

## 示例

以下示例显示了 `085XDOCS` ZIP 压缩包完整内容的短格式列表，包含头行和汇总行。

```
castle zipinfo 085XDOCS

Archive: 085XDOCS.ZIP 106272 bytes 4 files

-rw-a-- 2.0 fat 76800 t- defn 18-Aug-98 21:55 085X01.DOC

-rw-a-- 2.0 fat 67072 b- defn 22-Aug-98 01:39 085X02.DOC

-rw-a-- 2.0 fat 95232 t- defn 31-Aug-98 20:29 085X02.DOC

-rw-a-- 2.0 fat 63488 t- defn 4-Oct-98 20:24 085X04.DOC

4 files, 302592 bytes uncompressed, 105858 bytes compressed: 65.0%

castle$
```

以下示例显示了基础的长格式列表（非详细模式），包含头行和汇总行。

```
castle zipinfo -1 085XDOCS

Archive: 085XDOCS.ZIP 106272 bytes 4 files

-rw-a-- 2.0 fat 28048 defn 18-Aug-98 21:55 085X01.DOC

-rw-a-- 2.0 fat 24492 b- defn 22-Aug-98 01:39 085X02.DOC

-rw-a-- 2.0 fat 30592 t- defn 31-Aug-98 20:29 085X02.DOC

-rw-a-- 2.0 fat 63488 t- defn 4-Oct-98 20:24 085X04.DOC

4 files, 302592 bytes uncompressed, 105858 bytes compressed: 65.0%

castle$
```

### zipinfo 1535

以下示例列出了不带头部和尾部的压缩包内容。

```
castle zipinfo -t 085XDOCS

-rw-a-- 2.0 fat 76800 t- defN 18-Aug-98 21:55 085X01.DOC

-rw-a-- 2.0 fat 67072 b- defN 22-Aug-98 01:39 085X02.DOC

-rw-a-- 2.0 fat 95232 t- defN 31-Aug-98 20:29 085X02.DOC

-rw-a-- 2.0 fat 63488 t- defN 4-Oct-98 20:24 085X04.DOC

castle$
```

以下示例使用不同的语法产生与上方相同的结果。如果 shell 会扩展 `*`，则需要反斜杠。或者，你可以将 `*` 放在双引号内。

```
castle zipinfo 085XDOCS "*"

-rw-a-- 2.0 fat 76800 t- defN 18-Aug-98 21:55 085X01.DOC

-rw-a-- 2.0 fat 67072 b- defN 22-Aug-98 01:39 085X02.DOC

-rw-a-- 2.0 fat 95232 t- defN 31-Aug-98 20:29 085X02.DOC

-rw-a-- 2.0 fat 63488 t- defN 4-Oct-98 20:24 085X04.DOC

castle$
```

以下示例使用 `ZIPINFO` 环境变量关闭汇总行。

```
castle setenv ZIPINFO --t

castle zipinfo -t 085XDOCS

Archive: 085XDOCS.zip 106272 bytes 4 files

-rw-a-- 2.0 fat 76800 t- defN 18-Aug-98 21:55 085X01.DOC

-rw-a-- 2.0 fat 67072 b- defN 22-Aug-98 01:39 085X02.DOC

-rw-a-- 2.0 fat 95232 t- defN 31-Aug-98 20:29 085X02.DOC

-rw-a-- 2.0 fat 63488 t- defN 4-Oct-98 20:24 085X04.DOC

castle$
```

以下示例显示了当环境变量设置为关闭汇总行时，如何显示文件格式列表。注意，你必须指定 `-s` 选项，因为 `-t` 选项本身意味着只打印汇总行：

```
castle setenv ZIPINFO --

castle zipinfo -st 085XDOCS

4 files, 302592 bytes uncompressed, 105858 bytes compressed: 65.0%

Archive: 085XDOCS.zip 106272 bytes 4 files

-rw-a-- 2.0 fat 76800 t- defN 18-Aug-98 21:55 085X01.DOC

-rw-a-- 2.0 fat 67072 b- defN 22-Aug-98 01:39 085X02.DOC

-rw-a-- 2.0 fat 95232 t- defN 31-Aug-98 20:29 085X02.DOC

-rw-a-- 2.0 fat 63488 t- defN 4-Oct-98 20:24 085X04.DOC

4 files, 302592 bytes uncompressed, 105858 bytes compressed: 65.0%

castle$
```

`-s` 选项像 `-m` 和 `-1` 一样，默认包含头部和汇总，除非你另有指定。由于环境变量指定了汇总行，且该设置的优先级高于 `-s` 的默认行为，你必须使用显式的 `-t` 选项来生成完整列表。由于没有关于头的说明，因此 `-s` 选项足够了。

### zipinfo 1536

以下示例以中等格式列出单个文件的信息。

```
castle zipinfo -m 085XDOCS 085X01.DOC

-rw-a-- 2.0 fat 76800-1.64% defN 18-Aug-98 21:55 085X01.DOC

castle
```

当你使用任何选项指定单个文件时，`zipinfo` 只显示关于请求文件的单行信息，无论头部和汇总行的默认设置如何。你可以向命令添加 `t` 或 `h` 选项。

以下示例使用详细选项并将输出通过管道 `more` 显示关于压缩包的第一屏信息。

```
castle zipinfo -v 085XDOCS | more

Archive: 085XDOCS.zip 106272 bytes 4 files
```

中心目录结束记录：

```
实际记录的记录偏移量：106250 (0001F0Ah)

预期的记录偏移量：106250 (0001F0Ah)

（基于中心目录的长度和预期偏移量）
```

此 zip 文件构成单部分存档的唯一磁盘；其中心目录包含 4 个条目。中心目录长度为 226 (0000E2h) 字节，其相对于 zip 文件开始位置的预期字节偏移量为 106024 (00019E28h)。

没有 zip 包注释。

中心目录条目 #0：

```
085X01.DOC
```
