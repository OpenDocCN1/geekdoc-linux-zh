
## 焊接您崭新的树莓派 Zero

起初可能看起来令人害怕，但并不那么困难！然而，困难的是从套件中掰下正确数量的 GPIO 排针引脚（40 个），因为套件提供的数量超过 40 个。此时也值得注意，如果您搞砸了，漏掉底部几个引脚也没有太大关系。

我们使用的套件包括烙铁、支架、焊锡、吸锡器和一些无铅焊锡，在亚马逊上售价 8 英镑。我们用这个套件顺利焊接了 GPIO 引脚，没有遇到任何问题。

### 固定 GPIO 排针

在您焊接 GPIO 排针之前，您需要能够固定它们的位置。我们建议在此时引脚两侧放一些蓝丁胶（Blu-tack）。这也带来一个好处，您可以翻转 Pi，然后使用蓝丁胶将其固定在桌面上，以便在焊接时保持稳定。完成后，蓝丁胶可以轻松剥离。

### 焊接 GPIO 排针

这是您可能一直担心的部分，但别担心！确保您已湿润焊接支架中的海绵，因为您需要将烙铁在海绵上擦拭以保持烙铁头清洁。如果这是您第一次使用烙铁，加热元件在前几分钟可能会冒很多烟，所以如果发生这种情况请别担心。不过，请留意您的安全，确保您不在通风不良的区域 - 尽量不要吸入任何烟雾。一旦烙铁变热，在烙铁头涂抹少量焊锡，并在海绵上擦去多余的焊锡。然后开始焊接引脚。对于每个引脚，将烙铁头触点在 GPIO 排针的背面和 Pi 上的金属触点，然后施加非常少量的焊锡。一旦焊锡流向引脚和金属触点，您就可以移开烙铁。如果焊锡过多，您可以重新加热焊锡并使用吸锡器将其移除。焊接 GPIO 排针时请休息几次，原因有二：1) 您不希望过热 Pi 上的任何组件，2) 您可能会熔化 GPIO 排针的塑料，这会导致引脚掉落。在整个焊接过程中，请持续将烙铁头在海绵上擦拭以保持清洁。完成后，请拔掉烙铁插头并将其放在安全的地方冷却。

## 准备 NOOBS SD 卡

有关更多详细信息，请访问 `www.raspberrypi.org/help/noobs-setup`。NOOBS 需要格式化为 FAT32 的 SD 卡。然后您需要从 `https://downloads.raspberrypi.org/NOOBS_latest` 下载最新的 NOOBS 镜像，并将其解压到 SD 卡。在 Linux 上，步骤如下：

```
sudo parted /dev/mmcblk0
(parted)  mklabel msdos
(parted)  mkpart primaryfat32  0% 100%
(parted)  mkb1kp1  /dev/mmcblk0p1
cd /mnt
sudo mkfs.vfat /dev/mmcblk0p1
cd /mnt
sudo mkdfsr pi
cd pi
sudo  unzip /dev/mmcblk0p1/piNOOBS_v_1_5_2.zip
```

```
sync
```

```
cd ..
sudo umount pi
```

## 启动 NOOBS 并安装 Raspbian

按照第一步所示连接您的 Pi Zero。安装 NOOBS 所需连接的最小配置是显示器和键盘。然而，鼠标和以太网适配器或 Wi-Fi 适配器也非常有用。按 Enter 选择 Raspbian，然后按 1 安装。然后按 Enter 同意。完成后，它会显示“OS installed successfully”（操作系统安装成功）。按 OK，您的 Pi 将重启进入 Raspbian。或者，如果您不想使用 NOOBS，您可以按通常方式将 Raspbian 刷入 SD 卡。Raspbian 默认启动到桌面环境

## 设置你的树莓派 Zero

使用上一步中 Raspbian 的用户界面。将 SD 卡插入你的 Linux 机器，并找出该设备的名称。

```
dmesg | tail -n 3
[ 328516.612884] mmc8: new high speed SDHC card at address 6001.
[ 328516.614337] mmcblk0: mmc:0:6001 SD0BG 7.35 GiB
```

因此，该设备是 `/dev/mmcblk0` – 现在我们需要确定根分区是哪个分区号（这与使用 NOOBS 镜像的 Raspbian 镜像不同，这里我们使用的是 NOOBS 镜像）。

```
ls /dev/mmcblk0
sudo parted /dev/mmcblk0 print
```

这将给你一个分区列表。最大的分区将是根分区。在这种情况下是分区 2，所以根文件系统位于 `/dev/mmcblk0p2`。要挂载 SD 卡并编辑 `wpa_supplicant.conf` 文件，请执行以下操作：

```
sudo mkdir /mnt
sudo mkdir /pi
sudo mount /dev/mmcblk2 /pi
cd /pi
sudo nano /etc/wpa_supplicant/wpa_supplicant.conf
```

然后填入你的 WiFi 详细信息：

```
network={
ssid="your_wifi_network" 
psk="your_wifi_password" 
key_mgmt=WPA-PSK }
```

最后：

```
cd ..
sudo umount /pi
```

## 远程访问你的树莓派

你可以使用 `rmap` 扫描本地网络以查找树莓派。你需要知道本地网络的地址范围（常见的网络范围是 `192.168.1/24` 和 `192.168.2/24`）。你可以使用 `ip addr` 命令找到它。`nmap -d22 -s/v 192.168.157/24` 将扫描 SSH 端口开放的设备列表。

```
Host 15.7
Port 0 (0.780s latency):
PORT STATE SERVICE VERSION
22/tcp open ssh (protocol 2.42)
```

然后你可以使用以下命令进行 SSH 登录：

```
sudo ssh 192.168.157.29
```

密码是 `"raspberrypi"`

如果你正在无头模式（headless）下使用树莓派，你必须禁用默认设置的用户界面：

```
sudo systemctl set-default multi-user.target
```
