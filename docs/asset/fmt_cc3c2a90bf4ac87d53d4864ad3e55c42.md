
我未曾料到我会面临这样的处境。Linux newfound 的流行不仅给我，也给整个虚拟社区带来了一些艰难的时期。事实上，当开源代码在1998年引起世界关注时，一个大辩论是关于名称本身的。在此之前，我们将在GPL等许可证下共享软件的现象称为“自由软件”，并通常称之为“自由软件运动”。这个术语根源自由软件基金会，由理查德·斯托曼（Richard Stallman）于1985年创立，旨在推广如GNU这样他发起的自由Unix项目。突然之间，像埃里克·雷蒙德（Eric Raymond）这样的传教士发现记者们感到困惑。单词“自由”是指免费吗？是指无限制的“自由”吗？是指自由的“自由”吗？结果是，代表Apache向记者解释的布莱恩·贝尔亨德（Brian Behlendorf）也遇到了类似的挫败感。经过数周非公开的电子邮件交流（我并未参与，只是被抄送，因为我对政治方面不感兴趣），达成共识：我们将使用“开放”而非“自由”。因此，自由软件运动变成了开源运动——对于喜欢将其视为一种运动的人来说，我想它确实如此。然而，自由软件基金会仍然叫自由软件基金会，而理查德·斯托曼仍然是其背后的心理大师。

作为该运动实际领导者之一，我越来越受欢迎。在Transmeta，每次我的电话响起——那些天电话响个不停——都意味着两件事之一：要么记者想采访我，要么会议组织者希望我演讲。为了传播开源和Linux的理念，我觉得有义务做这两件事。把一个害羞的数学天才放到一个大众事业的迎宾微笑电路中，你就创造了一个民间英雄。忘掉埃里克·雷蒙德说的我比许多骇客看起来不那么怪僻吧。我的魅力（或者你们想怎么称呼它）的一大部分在于我不是比尔·盖茨。

记者们似乎很喜欢这一事实：当盖茨住在一个高科技湖畔豪宅时，我却在新居住地——一个位于无聊的圣克拉拉、拥有糟糕管道的三室联排别墅中——被女儿的玩具绊倒。我开着一辆无聊的庞蒂亚克汽车。我亲自接电话。谁不爱我？

随着Linux被视为微软的真正威胁——在微软遭遇反垄断困境时，它确实需要至少拥有真正威胁的外观——媒体跳上每一个发展动态，好像他们在报道第三次世界大战。有人泄露了“万圣节文件”，这是微软的一份内部备忘录，显示该公司担心Linux。很快，史蒂夫·鲍尔默（Steve Ballmer）被引述说：“是的，我很担心。”事实是，即使微软通过夸大Windows NT受到的Linux竞争而获益，现实情况是竞争只会变得更加激烈。

我不*需要*站在讲台上说微软的坏话。有什么意义呢？事件自然会发展，并且它们朝着有利于Linux的方向发展。记者们喜欢这一切。低声细语（像狐狸一样）的David对抗垄断、心术不正的Goliath。而且，既然我要完全坦白，我实际上很喜欢向记者谈论这一切。我喜欢把记者称为人渣，但我发现大多数采访都是有趣的。记者们通常对我们的故事感兴趣——谁会不支持弱者的呢？

一旦他们看够了“摧毁微软的阿摩巴”剧情（注：出于全面披露的目的，这句话已经过微软产品进行拼写检查），记者们想要理解开源的概念。这条信息的传达所花费的时间越来越少，因为人们现在可以看到其实际应用的例子。接下来令他们惊讶的是Linux的管理。他们无法理解，当平均三十人的公司通常退化成类似牲口圈混乱的状态时，人类历史上最大的协作项目如何能如此有效地管理。

有人创造了“仁慈的独裁者”这个短语来形容我如何管理这一切。第一次听到这个术语时，我只想到某个阳光国家的将军留着黑色的胡子，向饥饿的大众分发香蕉。我不知道我是否对“仁慈的独裁者”的形象感到自在。我控制Linux内核，这是一切的基础，因为到目前为止，与Linux相关的每个人都更信任我多于信任其他人。我管理拥有数十万开发者的项目的方法，与我当年在卧室里编写代码时是一样的：我不主动委派，而是等待人们站出来自愿接管事物。这始于我剥离了我认为不太有趣的职责，比如用户级代码。人们站出来并提议接管子系统。所有事情都通过这些子系统的维护者过滤到我这里。

面对不同种类的事情，我通常都会接受这两种方案，看看哪种会被实际使用。有时两者都会被采用，但最终走向不同的发展路径。有一次，两个人之间爆发了激烈的竞争，他们坚持提交互相冲突的代码补丁。我拒绝接受任何一方的补丁，直到其中一位开发者失去兴趣为止。如果所罗门王经营一家托儿所，他大概也会用这种方式处理事情。

仁慈的独裁者？不，我只是懒惰。我试图通过不做决定、让事情自然发生来进行管理。只有在这些自然发生的时刻，你才能得到最好的结果。

我的这种管理方式登上了头条新闻。

但这里的讽刺意味在于，尽管我的 Linux 管理风格（如果那能称为风格的话）在媒体上获得了高度评价，但在我在 Transmeta 公司短暂担任经理期间，我无疑是个失败者。在某一刻，公司决定让我管理一个开发团队。我搞砸了。任何进过我那堆杂物般的办公室的人都知道，我毫无章法。我在管理每周的进度会议、绩效评估和待办事项方面都遇到了困难。三个月后，情况变得很明显：尽管记者们称赞我管理 Linux 的方式，但我的管理风格对 Transmeta 并没有起到任何帮助作用。

与此同时，媒体不断抨击另一个问题：碎片化。那些关注过 Unix 坎坷且不幸历史的人，都知道 Unix 供应商之间无休止的争吵。1998 年，这个问题反复出现：历史会在 Linux 世界重演吗？我的回答始终是：虽然 Linux 供应商之间确实存在争吵，但这不会导致像 Unix 那样长期存在的碎片化问题，Unix 因此始终只是个“差一点就成功”的存在。Unix 的问题在于，竞争的供应商们浪费了数年时间来实现类似的功能，仅仅是因为他们无法访问相同的源代码基础。独立开发相同的功能不仅让 Unix 损失了数年时间，还导致了血腥的内斗。当然，我会告诉媒体，Linux 供应商不会定期举行定期的聚会（Love-Ins，此处指非正式的社交活动或庆祝会）。但是，Linux 社区内部将比 Unix 社区拥有更少的碎片化，因为即使是关系不好的 Linux 供应商也能看到相同的源代码基础，并能复用彼此的工作。源代码是一个任何人都可以从中汲取资源的宝库。

随着记者们开始更多地理解这些概念，我越发喜欢与他们见面。（与我少年时期在赫尔辛基记忆中的记者不同，1990 年代在美国的大部分记者都比较冷静理智。）我特别享受与他们辩论的机会。

但演讲完全是另一回事。我并不是你们所说的天生表演型人格。请记住：我那个童年几乎很少离开卧室的人。我连写演讲稿都不太擅长，所以我总是等到活动前一晚才开始准备。

不知怎的，这似乎并不重要。通常，当我走上讲台时，人们甚至会在我开口之前起立鼓掌。我不想听起来像是不懂得感恩，但我一直觉得这种场面很尴尬。无论你说什么听起来都像是错的，甚至是我标准的开场白“谢谢，现在请坐下”也不例外。如果有建议，我很乐意听取。

但并非所有的电话都来自记者或会议组织者。有一天晚上，我在家和 Tove 待在一起。我们正给孩子们读书。电话响了。

我接起来：“托瓦兹。”

“呃。你是那个 Linux 的家伙吗？”

“是的。”

两秒钟沉默。挂断。

另一晚，拉斯维加斯的一个家伙给我家打电话，试图说服我加盟某个 Linux T 恤生意。

显而易见的解决方案是申请一个不公开的电话号码。刚搬到加利福尼亚时，我没 bother（麻烦）去做这件事，因为那比拥有公开号码更贵。后来我学到了这么吝啬的代价，现在我已经取消了号码的公开登记。有一次，在我取消登记之前，David 弄丢了我的家庭号码，于是查了号码查询台。他询问我的号码，提供号码的话务员惊讶得不得了，说道：“他也登记了？身家千万的人？”

但是不，并没有千万。拥有数百万 Linux 用户，没错。但绝不是林纳斯身家千万美元。而那也完全没问题。

大多数日子，我醒来时都会觉得自己是这世上最幸运的家伙。我不记得 1999 年 8 月 11 日星期三是不是其中之一，但它应该是。

那天是 Linux World 大会和贸易展的第二天，该活动正在圣何塞会议中心举行。SuSE 的首席执行官 Dirk Hohndel 从德国专程赶来参加贸易展，他当晚睡在我们家庭客房的客床上。我认识他好多年了。他是老牌 XFree86 团队的一员，负责 Linux 的图形界面部分。他也是 Daniela 的教父。我醒后，给 Tove 和 Dirk 做了卡布奇诺，读了《圣何塞水星新闻》上除了体育版和分类广告以外的所有内容——就像我平时做的那样——然后我们坐进丰田 RAV4，开始了前往圣何塞市中心的十英里路程。

我记得我握了很多手。

这天 Red Hat 即将上市。这家公司早在几年前就给了我股票期权，最近才给我寄来了一些文件，但我从未费心去看过。它就躺在我电脑附近的一堆文件里。我记得我真的希望 Red Hat 能表现出色。这不仅仅是因为我对这些期权感到兴奋——我并没有完全意识到它们意味着什么。我因为另一个原因而极其兴奋。在许多方面，IPO（首次公开募股）的成功将是对 Linux 的验证。所以那天早上我有点紧张，但我不止一个人这样。市场几周以来表现不佳，人们不禁怀疑 Red Hat 是否还能完成其 IPO。

“流动性事件”确实发生了。我们在会议现场得知，Red Hat 的首次公开发行价格为 15 美元。或者是 18 美元？我不记得了。重要的是，它第一天的收盘价达到了 35 美元。虽然没有打破纪录，但也还不错。
