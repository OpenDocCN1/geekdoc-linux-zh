仓鼠（Hamster）是仓鼠科（Cricidae）14 种物种的通称。这些物种的自然分布范围是亚洲，但与在欧洲常见的仓鼠（Cricetus）一样著名。

普通仓鼠是一种独居动物，拥有有趣且会嚎叫的洞穴。洞穴并不深，超过 2 米（m），由一个大室室和放射状的侧隧道组成，如用于进食、居住和排泄。所谓的室室用于繁殖。仓鼠进入它的洞穴，入口处会封堵，并且钻得非常深，几乎很少被看到。参见仓鼠（`HAMSTER`）。

金仓鼠（Mesocricetus）被广泛用作实验动物，特别是在行为的生理方面。

长角水蚤目（Haplopoda）是一种肉食甲壳动物目，曾被归入水蚤目（Cladocera）。其中一种物种淡水长角水虾（Lapthoda indica）长约 9 毫米（1 厘米），通过巨大的触角和刚毛在大多数淡水栖息地中缓慢移动。具有六对节段，足性胸肢。其运动是一种类似于桡足类（copepod）的游泳。

病原卵携带在幼囊中，在发育过程中会受精并矿化。卵缩小成一个小囊，不再提供下一个。

水绵虫（Lepodora）广泛发现大型湖泊和海洋的浮游生物中。

> (G.F.)

多壳海绵目（Haplosceria）是海绵纲（Demospiae）的一种海绵目，其骨架由单纤维或连接成海绵骨架组成。多纤海绵（Mericlid sponges）由许多纤维融合在一起组成。

多壳海绵在某些不存在，但在大陆架的浅水和深水区特别丰富。某些占据的深度达。

如果一个问题的确定方法可以通过如下解决：如果系统的构型在时间 $t_1$ 和 $t_2$ 时由 $q(t_1)$ 和 $q(t_2)$ 给出，则需要找到从初始构型到最终构型的轨迹。哈密顿原理与几何学家解决曲面上两点之间寻找曲线最短路径的问题非常相似。两点之间的几何距离是两点之间 $ds$ 与它们的坐标 $dq$ 的积分，如方程 (1) 所示。两点之间的路径和指定的点

```
(ds)^2 = \sum dq_j dq_j (2)
```

```
D = \int ds (3)
```

给定这些点，方程 (2) 中的积分被发现最小值。哈密顿定义了一个特征函数 $\Phi$，类似于 $D$，

```
\Phi = \int L(q, t) dt (4)
```
