
控制自动 IPv6 隧道。

默认：`no`

`IPV6_DEFAULTGW=<IPv6 地址[%接口]>`

（可选）通过指定的网关添加默认路由。可以指定接口：对于链路本地地址是必需的

`IPV6_DEFAULTDEV=<接口>`

（可选）通过指定的接口在不指定下一跳的情况下添加默认路由。类型的

接口将测试这是否允许

`IPV6_RADVD_PIDFILE=<pid-file>` (可选)

用于控制 `radvd` 的 PID 文件位置

### /etc/sysconfig/rawdevices

此用于设置原始设备到块设备的映射。其格式如下：

`<rawdev> <major> <minor>`

`<rawdev> <blockdev>`

例如：

```
/dev/raw/raw1 /dev/sda1
/dev/raw/raw2 8 5
```

### /etc/sysconfig/saslauthd

由 `saslauthd` init 脚本（`cyrus-sasl` 包的一部分）使用，用于控制启动时将哪些参数传递给 `saslauthd`；对此文件进行的更改在重启 `saslauthd` 之前不会生效

`MECH=shadow`

控制 `saslauthd` 在检查用户密码时 咨询哪个数据源；运行 '`saslauthd -a`' 可 查看可用认证 机制的完整列表

`SOCKETDIR=/var/run/saslauthd`

控制 `saslauthd` 将在哪个目录下 创建其监听套接字；对此值的任何更改 都需要在客户端配置文件进行相应的更改

### /etc/sysconfig/i18n

- `LANG=`

设置所有类别的本地化，可以是任何两个字母的 ISO 语言代码

`LC_CTYPE=`

用于字符分类和 转换的本地数据配置

`LC_COLLATE=`

用于字符串排序（排序顺序）的本地数据配置

`LC_MESSAGES=`

用于 yes 和 no 消息翻译的本地数据配置

`LC_NUMERIC=`

用于非货币数值数据的本地数据配置

`LC_MONETARY=`

用于货币数据的本地数据配置

`LC_TIME=`

用于日期和时间的本地数据配置

`LC_ALL=`

覆盖所有内容的本地数据配置

`LANGUAGE=`

可以是一个由冒号分隔的 ISO 语言代码列表

`LANGUAGE=`

可以是一个由单引号分隔的 ISO 语言代码列表
