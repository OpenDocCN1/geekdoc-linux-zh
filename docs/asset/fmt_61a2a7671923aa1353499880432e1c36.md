## InterBase

  - 垃圾回收

  - 扫描无效数据结构

- 管理软件激活证书

  - 在产品未来版本中将被替换的 API 调用

  - 待处理的数据库关闭

  - 在不同 InterBase 版本产生不同结果的 SQL 表达式

- 支持 SQL 分隔标识符；即由双引号分隔的数据库对象名称

- 方言（dialects）概念，允许用户使用新功能，例如分隔标识符、大精确数值以及 SQL DATE、TIME 和 TIMESTAMP 数据类型，这些功能与旧版本的 InterBase 不兼容
