
请注意，`vparmodify` 的 `-a` 选项会根据当前 CPU 数量相对地更改 CPU 数量。在我们的案例中，当前的 CPU 数量为 1，使用 `-a cpu:1` 会在当前数量 1 的基础上增加 1 个 CPU，结果变成 2 个 CPU。使用 `vparmodify` 的 `-d` 选项移除处理器时，也是如此。以下示例展示了运行 `vparstatus` 以查看这两个 CPU，使用 `vparmodify` 将 CPU 数量改回 1（这也是相对于当前 CPU 数量而言的，当前数量为 2），以及运行 `vparstatus` 以确认该更改已生效：

