
通过`opendir()`打开的目录结构在处理目录完成后需要关闭。要关闭目录结构，使用`closedir()`系统调用，它关闭指向`DIR`对象指针所引的目录流。从`closedir()`成功返回后，指向`DIR`对象的指针不再有效。如果`closedir()`成功，它返回0；否则，返回-1。`closedir()`的原型如下。

```c
int closedir(DIR *dirp);
```

## The `readdir()` 系统调用

`readdir()`函数读取由`DIR`对象指向的目录的内容，它包含特定目录内所有目录条目的有序序列。`readdir()`函数返回一个指向目录流中当前位置目录目的结构指针，并将目录流移动到下一个条目。该目录结构被称为`dirent`。`dirent`中包含当前路径的成员是`char d_name[]`，这是一个以空字符终止的字符串。

当`readdir()`到达目录流的末尾时，将返回空指针。如果在最近一次调用`opendir()`之后目录中删除了或添加了文件，`readdir()`将该文件返回一个“未知”条目。`readdir()`的原型如下。

```c
struct dirent *readdir(DIR *dirp);
```
