
- `/home/downloads`
- `/home/local/mp3`
- `/usr/local/dos_data`

原因如下。

- `/usr/local` 是为了应对任何 Linux 升级。将其放在单独的分区上很好，因为我可以重新格式化其他分区而不影响存储在 `/usr/local` 中的本地内容。我肯定希望它的类型是 `ext2`、`ext3` 或可能是 `ext4`。
- `/home` 包含用户数据。显然，这些数据最值得被照顾。它显然应该能够任何升级。哇，显然我想把它放在单独的分区上。类型通常是 `ext2`、`ext3` 或 `ext4`。
- `/usr/local/mp3` 是非标准的 Linux 目录。我可以把 MP3（音乐）文件放在那里。这些文件通常很大。
- `/usr/local/dos_data` 另一个非标准目录。如果我使用双系统，我会考虑将硬盘的一个额外分区设置为 `DOS FAT32` 或类似的格式，以便在 MS Windows 和 Linux 之间共享文件（双向）。我会配置所有基于 Windows 的程序使用此“驱动器”作为所有用户生成文件的默认位置。我可以在此位置放置 `mp3s`、`cds` 和其他目录。这种方法的缺点是——MS Windows 可能会在重装时搞乱这个分区。

1. 对新硬盘进行分区。例如，如果我的硬盘是第二个 IDE 接口的从设备（也许是“第四个”IDE 硬盘），我可以使用：

```
cfdisk /dev/hdd
```

或者更老旧（标准）的工具：

```
fdisk /dev/hdd
```

如果你的硬盘不是 `hdd`，请根据需要调整命令。

- `hda` -- 第一个 ide 主设备（整个磁盘）
- `hdb` -- 第一个 ide 从设备
- `hdc` -- 第二个 ide 主设备
- `hdd` -- 第二个 ide 从设备
- `sda` -- 第一个 scsi（整个磁盘）
- `sdb` -- 第二个 scsi（整个磁盘）
- `sdp` -- 第六 scsi（整个磁盘）

对于其他磁盘，请咨询 `/usr/src/Linux/Documentation/devices.txt`。大多数情况下，我会将 Linux 分区的类型设为 `ext3` ("Linux")。分区可能很复杂——如果你从未这样做过，请阅读 `fdisk` 和 `cfdisk`。删除带有所有数据的分区非常容易。请务必确认你正在操作哪一个！

`fdisk` 或 `cfdisk` 在我写入新的分区布局之前，不会对硬盘进行任何更改。或者如果我犯了错误，可以随时退出而不写入。只有在完全完成后，我才会将布局写入硬盘。

2. 格式化每个分区。例如，为了格式化第一个分区并进行坏块检查 (`-c`)，我会执行：

```
mkfs -c ext2 /dev/hdd1
```

3. 测试新分区。手动挂载新分区（挂载目录必须存在且为空）。向每个分区拷贝大量文件。查看/编辑随机文件的副本。删除所有内容。

4. 拷贝数据。可选——仅当你只想从旧分区移动数据到新分区时。要进入单用户模式 (`init 3`)，手动挂载新分区。将数据从旧分区拷贝到新分区。小心旧数据，如果你犯了错误，你可能不想丢失它，所以我不会删除它——我会恰当地重命名顶层目录。

```
cp -R /usr/local/ /mnt/hdd1
```

```
mv /usr/local/ /usr.local.backup_2001-04-24
```

5. 编辑文件 `/etc/fstab`。修改它以反映你的新文件系统布局。然而，根据需要插入新分区或修改任何旧的挂载点。例如，如果将 `/usr/local` 移动到自己的分区，我需要添加这样的一行：

```
/dev/sda1 /usr/local ext2 defaults 1 2
```

6. 重启并测试。另一种方法是卸载并挂载新的挂载点。例如：

```
mount /usr/local
```

```
mount -a
```

硬重启可能是对新布局更严谨的测试。

7. 删除旧数据。几天后，当我有信心一切运行良好时，删除旧数据（例如目录 `/usr/local.backup` 的 `2001-04-22`）。

## 5.2.13 交换空间 (Swap space)

交换空间是计算机物理内存的扩展。你可能在初始 RedHat 安装期间创建了一个交换分区。你可以使用以下命令验证系统上可用的交换空间大小：

```bash
cat /proc/meminfo
```

通常建议是，应该拥有：至少 4 MB 交换空间，对于仅运行命令行的系统至少需要 32 MB 总内存（物理+交换），对于运行 X-windows 的系统至少需要 64 MB 总内存（物理+交换），且交换空间至少是物理内存的 1.5 倍。

## 5.3 使用控制台

前几个控制台是基于文本的（CLI，“命令行”）并命名为 `tty1`-`tty6`（历史名称，“tty”代表电字机）。随后的控制台是图形化的（GUI）。你可以通过网络远程连接到 Linux 服务器。连接后，你可以让程序在服务器上运行并将显示到你的本地控制台。这对于区分控制台是在本地运行还是远程运行非常有帮助。

全屏控制台本身就是终端。在 GUI 下，你还可以按需创建“从”伪终端（在窗口中）–它们被称为 `pts0`、`pts1`

## 5.3.2 如何为 X-server 设置显卡、显示器和鼠标？

这应该在你的 Linux 初始安装期间设置，除非你跳过了该步骤。如果现在要设置，你可以尝试以 root 身份运行这些文本模式配置器之一（需要 root 权限）：

```
Xconfig
XF86setup
xconf
```

在 RedHat 下，你也可以运行 `setup` 命令（以 root 身份）并从那里访问 `config`。

要在 Linux 下设置 X-windows，你可能需要了解你的硬件信息。你可能需要清理一下显示器，以查看它支持哪些同步频率（垂直和水平）。计算机启动时的信息可能会提供关于显卡类型和显存大小的线索。此外，运行以下命令也会提供有用信息：

```
lspci
```

阅读下方的手册以了解鼠标类型。下次你可能需要一个鼠标，一个 3 键的“Linux 就绪”罗技或类似产品（Linux 利用所有三个按钮）。一个标准的鼠标（无论是否是仿制品）总是有意义的——我绝不会使用特殊的鼠标，因为它们需要驱动程序，否则就会成为安装或功能上的障碍。

在测试 X-server 时，如果屏幕变空、显示全屏或显然没有按预期运行，使用 `ctrl-<alt-B>Backspace` 杀死它并重新检查你的显示器同步频率。运行过高的频率会对你的显示器造成损坏。

如果你真的遇到了问题，请在了解系统工作原理后再进行微调，例如使用 `vga` X 第一种分辨率（`640x480` 像素，`16` 或 `26` 色），或者借助 X 下提供的一些更好用的设置工具。

设置好 X 后，你可以使用以下命令手动启动它：

```
startx
```

`&` 符号让你的命令在后台运行，这样你的文本就不会被阻塞。你也可以使用：`init`，它会将你的系统切换到运行级别 5，这意味着“图形用户界面运行级别”。若要在系统重启时自动（或根据你的选择）启动 X，请阅读接下来的几段。

## 5.3.3 我可以拥有 GUI 提示吗？

为了在系统启动时自动启动 X-server 并显示图形登录提示，你必须以 root 身份修改 `/etc/inittab` 文件中的一个字符。该文件指定了如下内容：

```
id:3:default
```

将其改为

```
id:5:default
```

这会将默认运行级别设置为 5，即 X-Windows。运行级别的含义在示例 `/etc/inittab` 中解释：

- `0` 停机（不要将 `inittab` 设置为此项）
- `1` 单用户模式
- `2` 多用户模式，不带 NFS（如果你没有网络，则与 `3` 相同）
- `3` 全多用户模式
- `4` 未使用
- `5` X11
- `6` 重启（不要将 `inittab` 设置为此项）

你可以从命令行更改运行级别。例如，此命令（必须以 root 身份执行）：

```
init 6
```

若要找到我当前处于什么运行级别，我使用 `runlevel` 命令。
