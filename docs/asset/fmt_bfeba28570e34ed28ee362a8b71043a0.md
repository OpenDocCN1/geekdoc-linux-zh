
# find 命令示例

## 按名称查找

- 在 `/tmp` 目录下查找以 `.txt` 结尾的文件

```
find -name "*.txt"
```

- 在当前目录下查找名字以大字母开头的文件

```
find -name "[A-Z]*"
```

- 在 `/etc` 下查找以 `.bak` 结尾的文件

```
find -name "*.bak"
```

- 在当前目录下查找以 `file` 开头（忽略后缀）的文件

```
find -name "file*" -type d
```

## 例 4-70 按所有者或者用户组查找

- 在 `/home` 下查找用户 `user01` 的文件

```
find -user user01
```

- 在 `/home` 下查找 UID 大于 1001 的文件

```
find -uid +1001
```

- 在 `/var` 下查找用户组 `apache` 的文件

```
find -group apache
```

- 在 `/home` 下查找组 ID 为 1000 且以大字母或数字开头的文件

```
find -gid 1000 -name "[A-Z0-9]*"
```

## 例 4-71 按文件类型查找

- 在当前目录下查找所有目录

```
find . -type d
```

- 在当前目录下查找非目录的文件

```
find . -type f
```

- 在 `/dev` 下查找块设备和字符设备

```
find /dev -type b -o -type c
```

## 例 4-72 按文件大小查找

- 在当前工作目录下查找大于 100 字节的文件

```
find . -size +100
```

- 在当前工作目录下查找小于 1k 的文件

```
find . -size -1k
```

## 任务 4 管理文件

- 查找大小大于 900M 且名为 `a` 的文件

```
find -size +900M -name a
```

- 查找大小小于 100MB 的文件

```
find -size -100M
```

- 在当前目录下查找空文件

```
find -empty
```

## 示例 5: 文件访问权限查找

- 在当前目录下查找所有权限为 755 的文件

```
find -perm 755
```

- 在用户目录下查找权限只有 644（可读）、用户读写、其他不可读的文件

```
find -perm rwx,o=-
```

## 示例 6: 文件时间属性查找

- 在当前目录下查找 5 分钟内创建、15 分钟内访问过的文件

```
find -atime +0 -atime -15
```

- 在当前目录下查找 1 天前创建、2 天内访问过的文件

```
find -atime +1 -atime -2
```

- 在当前目录下查找 10 分钟前创建、15 分钟内属性/内容发生改变的文件

```
find -cmmin +0 -cmmin -15
```

- 在当前目录下查找 1 天前创建、2 天内属性/内容发生显著改变的文件

```
find -ctime +1 -ctime -2
```

- 在当前目录下查找 5 分钟前创建、15 分钟内内容修改的文件

```
find -mmin +0 -mmin -15
```

- 在当前目录下查找 1 天前创建、2 天内内容发生改变的文件

```
find -mtime +1 -mtime -2
```

- 在当前目录下查找修改时间比 `tmp.txt` 最近的文件

```
find /home -newer tmp.txt
```

> **注意**
>
> - `atime`: 文件最后访问的时间
> - `mtime`: 文件内容最后修改的时间
> - `ctime`: 文件状态最后改变的时间（包括所有者、权限或链接设置）
>
> 在本章中提到的时间（timestamp）指的是 `mtime`。

## 示例 7: 按硬连接数或者索引查找

- 在所有目录下查找连接数大于 2 且索引节点为 5 的文件

```
find -links +2 -inum 5
```

## 示例 8: 关于 find 命令的动作

- 在当前目录下查找名为 `tools` 的对象并列出完整路径

```
find -name tools
```

- 在当前目录下查找大于 3M 的文件

```
find -size +3M -type f
```

- 在当前目录下查找名为 `tools` 的文件复制到 `/test/`

```
find -name tools -exec cp {} /test/ \;
```

- 在当前目录下查找大小为 0 的文件并输出到 `result.txt`

```
find -size 0 > result.txt
```

- 在当前目录下查找以 `.tar` 结尾的文件并删除

```
find -name "*.tar" -exec rm {} \;
```

## 示例 9: 关于 find 命令逻辑运算符

- 在用户目录下查找名为 `.tmp` 或 `.bak` 结尾的文件

```
find -name "*.tmp" -o -name "*.bak"
```

- 在目录下查找名字为数字的目录

```
find -name '[0-9]*' -type d
```

- 在当前目录下查找类型为字符且名为 `.tmp` 结尾的文件

```
find . -name "*.tmp" -type c
```

> **注意**
>
> - `find` 命令可以使用运算符：
>   - `-a` 表示与
>   - `-o` 表示或
>   - `!` 表示非
> - 使用多个条件时，这些条件用括号括起来，还要用斜杠 `\` 来转义。

# locate 命令

## 用法

```
locate [选项] 模式
```

## 功能

在一个预建立的系统数据库 `/var/lib/mlocate/mlocate.db` 中查找全名匹配的文件。`locate` 的查找比 `find` 快得多，因为 `locate` 并不是查找文件系统而是查找数据库。由于这个原因 `locate` 的查找是不实时的，新创建的文件可能找不到或被删除的文件找到。

## 表 4-20 locate 命令的常用选项

| 选项 | 说明 |
| --- | --- |
| `-A` | 查找时匹配所有列出的模式 |
| `-b` | 查找时只匹配文件名而非路径在内的全名 |
| `-c` | 显示匹配文件个数 |
| `-i` | 查找时忽略大小写 |
| `-e` | 显示真实存在的文件（而非数据库中已经删除的文件） |
| `-S` | 显示所有数据库并列出收集的统计信息 |
| `-q` | 不显示错误信息 |

## 示例 1：简单查找

查找全名中包含 `/bin/ls` 的文件：

- `locate /bin/ls`
- `locate /usr/ls`
- `locate /usr/lsattr`
- `locate /usr/lsblk`

> **注意**
>
> - `locate` 命令对包括路径内的文件进行全名匹配，而不仅针对文件名。
> - `locate` 命令查找的范围是全局，即整个文件系统。

## 示例 2：使用选项 -A 查找

查找文件全名同时包含 `/bin/ls` 和 `md` 的文件：

- `locate -A /bin/ls md`
- `locate /usr/ismd`

## 示例 3：使用选项 -b 查找

查找文件名（而非路径）中包含 `stun` 的文件：

- `locate -b stun`
- `locate -b /etc/selinux/targeted/active/modules/100/stunnel`
- `locate -b /usr/stunbdc`

如果不使用选项 `-b` 则会匹配包含路径的前缀：

```
locate stun
/etc/selinux/targeted/active/modules/100/stunnel
/etc/selinux/targeted/active/modules/100/stun/cil
/etc/selinux/targeted/active/modules/100/stun/hll
/usr/stunbdc
```

> **注意**
>
> - `locate` 使用的数据库默认是 `/var/lib/mlocate/mlocate.db`。
> - `mlocate.db` 数据库是使用 `updatedb` 命令创建和更新，一般作为一个定时任务按日运行。
> - 可以执行 `updatedb` 立即更新 `mlocate.db` 数据库。

# 4.3.9 知识点 压缩相关命令

## 1. tar 命令

### 用法

```
tar [选项] 归档文件
```

### 功能

`tar` 命令最初将文件打包到磁带上，现在都用它来实现备份特定分区或目录或者文件。使用 `tar` 命令可以归档多个文件。

### tar 命令的常用选项

| 选项 | 说明 |
| --- | --- |
| `-A` | 合并两个归档 |
| `-c` | 创建一个新的归档 |
| `--delete` | 在归档文件中删除 |
| `-r` | 向归档文件追加 |
| `-t` | 列出归档中的文件 |
| `-u` | 更新归档文件 |
| `-X` | 指定排除文件 |
| `-f` | 指定归档文件 |
| `-Z` | 使用 gzip 压缩 |
| `-j` | 使用 bzip2 压缩 |
| `-v` | 显示过程 |

### 例 1: 创建一个归档文件

创建一个归档文件 `myarchive.tar`，将 `/etc` `/root/cfg` 包进去：

```
tar -cvf myarchive.tar /etc /root/cfg
```

> **注意**
>
> - 归档文件的扩展名 `.tar` 不是必须的，但是一般约定俗成加上，以告诉用户这个文件是一个归档文件。
> - `-f` 选项必须紧跟归档文件名。
