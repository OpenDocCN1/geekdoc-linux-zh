## `shift`

```
shift [n]
```

如果提供了参数 `n`，`shift` 重命名位置参数，使得参数 `n+1` 变为 `$1`，`n+2` 变为 `$2`，依此类推。参数 `n` 及以下参数将被取消。如果 `n` 为 `0`，则不更改参数。如果没有参数，假设 `n` 为 `1`。参数必须是非负数，除非 `n` 小于 `0` 或大于位置参数的数量，否则 `shift` 返回 `0`。

## `test`

```
test value -option value
test string-string
```

通常，你可能需要执行一个比较两个值的测试。Linux 有一个名为 `test` 的命令，可以执行这种对值的值的比较。`test` 命令会比较两个值，如果比较成功，则返回状态码 `0`。

通过 `test` 命令，你可以比较整数或字符串，甚至可以执行逻辑操作。该命令由关键字 `test` 组成，后面跟着要进行比较的值，并由一个指定正在进行什么比较的选项（`option`）隔开。该选项可以被看作操作符，但像其他选项一样，它带有减号和字母代码。例如，`-eq` 是表示相等性比较的选项。然而，有两个字符串操作实际上使用的是操作符而不是选项。当你比较两个字符串是否相等时，你使用等号 (`=`)。对于不相等，你使用 `!=`。

在接下来的示例中，用户比较两个整数以查看它们是否相等。在这种情况下，你需要使用相等性选项 `-eq`。通过检查 `test` 命令的退出状态来确定测试操作的结果。shell 特殊变量 `$?` 存储了最近执行的 Linux 命令的退出状态。

```bash
$ num=5
$ test $num -eq 10
$ echo $?
```

除了使用关键字 `test` 来执行测试命令外，你还可以使用括号。命令 `$greeting="hi"` 可以写为：

```bash
$ [ $greeting="hi" ]
```

同样，`test` 命令 `test $num -eq 10` 可以写为：

```bash
$ [ $num -eq 10 ]
```

## `trap`

```bash
trap [-1] [argument] [sigspec]
```

指定此处列出的作为参数的某个命令在 shell 接收到由 `sigspec` 指定的系统信号时将被读取并执行。该信号可以是定义在 `<signal.h>` 中的信号名称，也可以是信号数字。如果 `sigspec` 是 `EXIT` (`0`)，则在退出 shell 时执行命令 `argument`。如果由于没有为该信号列出命令参数，则该信号将被重置。

单独使用 `trap` 命令且不带任何参数时，会显示与每个信号数字关联的命令列表。使用 `-l` 选项，它会显示信号名称列表及其对应的数字。参数 `--` 禁用后续参数的选项检查。在进入 shell 时被忽略的信号无法被 `trap`（捕获）或重置。被捕获的信号在创建子进程时会被重置为它们的原始值。如果 `trap` 名称或数字无效，则 `trap` 返回假。
