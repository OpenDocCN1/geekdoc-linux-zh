# 清屏 (clear)

你可以显示单个文件或目录的校验和、文件列表的校验和，或目录下所有文件的校验和。以下示例显示了当前工作目录下所有目录和文件的校验和。

## 用法概要 (Synopsis)

`/usr/bin/clear`

## 描述 (Description)

`clear` 命令用于清除屏幕。它通过查询终端数据库（`terminfo`）来重置屏幕状态。

# 比较 — 比较两个文件 (Compare Files)

## 用法概要 (Synopsis)

`/usr/bin/cmp [options] file1 [file2]`

## 描述 (Description)

`cmp` 命令比较两个文件。如果文件相同，则不输出任何内容；如果文件不同，它会输出第一个不同字节的字节和行号。

## 选项 (Options)

- `-l` 以十进制格式显示差异字节
- `-s` 静默模式

## 操作操作数 (Operands)

- `file1` 第一个文件
- `file2` 第二个文件（如果省略，则与 `file1` 相同）

# 说明

`col` 接受的输入格式与 `nroff` 使用 `-T37` 或 `-Tlp` 选项产生的输出匹配。如果 `col` 输出的最终设备可以解释半行移动的，请使用 `-T37`（以及 `col` 的 `-f` 选项）。否则，使用 `-Tlp`。

`col` 回溯不能超过 128 行或每行处理超过 800 个字符。会导致越过文档第一行的局部垂直移动将被忽略。因此，第一行不能包含任何上标。

## 选项

- `-b` 假设正在使用的输出设备不支持退格。在这种情况下，如果两个或多个字符要出现在同一个位置，则只输出最后一个。
- `-f` 向前传输半换行符 (`Esc-9`)，但不反转行移动。通常，半行输入移动将在下一行完整行显示。
- `-p` `Esc-7`。
- `-x` `Esc-8`。

## 示例

以下示例通过 `tbl` 和 `nroff` 运行文件，然后通过 `col` 和 `more` 过滤并在屏幕上显示输出。

```
castle$ tbl file | nroff | col | more
```

以下示例通过 `col` 来自 VDT 的 `nroff` 输出。

```
castle$ nroff -cm -oR8 -W79 document | col
```
