
如果任何文件已经存在，`filesync` 将请求确认。源和目标之间的区别是相对任意的（在 `-o` 和 `-f` 的用法外）。

## 环境变量

- `FILESYNC` 指定打包规则和基准文件的默认位置。默认值为 `$HOME`。将附加 `.packingrules` 和 `.filesync-base` 后缀。
- `LC_MESSAGES` 决定诊断和信息消息呈现方式。在 C 区域中，消息将以程序中的默认形式呈现（大多数情况下为美国英语）。

## 退出状态

通常，如果所有文件都是最新的，或者所有文件都已成功对齐，`filesync` 以状态 `0` 退出。然而，如果你指定了 `-n` 选项或发生任何错误，退出状态为以下内容的逻辑或（OR）：

- `0` 无冲突，全部已更新。
- `1` 部分可解决的冲突。
- `2` 部分需要手动解决的冲突。
- `4` 某些指定的文件不存在。
- `8` 某些文件权限不足。
- `16` 访问打包规则或基准文件出错。
- `32` 参数无效。
- `64` 无法访问指定的源或目标目录（或两者）。
- `128` 其他杂项失败。

### 操作数

- `path` 目录层次结构中起始点的名称。
- `expression` 解释第一个以 `-` 开头、或以 `!` 或 `(` 开头的参数，并将所有随后的参数解释为一个由以下主操作数和运算符组成的表达式。在描述中，每当使用 `n` 作为主操作数时，将其解释为十进制整数，前面可选的加号 `+` 或减号 `-` 符号，如下：

  `+n` 大于 `n`。
  `n` 正好等于 `n`。
  `-n` 小于 `n`。

### 表达式

- `-atime n` 如果文件在 `n` 天前被访问过，则为真。`path` 中目录的访问时间由 `find` 本身更改。
- `-cpio device` 始终为真；以 cpio 格式（5120 字节记录）将当前文件写入设备 `device`。
- `-ctime n` 如果文件的状态在 `n` 天前被更改过，则为真。
- `-depth` 始终为真；遍历目录层次结构，使得目录中的所有条目在目录本身之前被处理。当 `find` 配合 `cpio(1)` 传输没有写权限目录包含的文件时，此选项非常有用。
- `-exec command` 如果执行的命令返回退出值为 `0`，则为真。你必须用转义的分号 `;` 结束命令。命令参数 `{}` 会被替换为当前路径名。
- `-follow` 始终为真；跟随符号链接。在跟随符号链接时，`find` 会跟踪已访问的目录以便检测无限循环。例如，如果符号链接指向祖先目录，就会发生此类循环。不要将此表达式与 `-l` 表达式配合使用。
- `-fst type` 如果所属的文件系统类型为 `type`，则为真。
- `-group gname` 如果文件属于组 `gname`，则为真。如果 `gname` 是数字且未出现在 `/etc/group` 文件中，则被视为组 ID。
- `-inum n` 如果文件的 inode 节点为 `n`，则为真。
- `-links n` 如果文件有 `n` 个硬链接，则为真。
- `-local` 如果文件系统类型不是 `/etc/dfs/ftypes` 文件中定义的远程文件系统类型。如果不存在 `/etc/dfs/ftypes` 文件，则使用 `nfs` 作为默认远程文件系统类型。
- `-ls` 始终为真；打印当前路径名及其相关的统计信息：

  - Inode 号。
  - 以 KB 为单位的大小（1024 字节）。
  - 保护模式。
  - 硬链接数。
  - 用户。
  - 组。
  - 以字节为单位的大小。
  - 修改时间。

  如果文件是特殊文件，大小字段包含主、设备号。
  如果文件是符号链接，则通过 `->` 打印链接文件的路径。格式与 `ls -g` 相同（见 `ls(1)`）。格式在内部完成，不执行 `ls` 程序。
- `-mount` 始终为真；将搜索限制在包含指定目录的文件系统中。不列出到其他文件系统的挂载点。
- `-mtime n` 如果文件的数据在 `n` 天前被修改过，则为真。
- `-name pattern` 如果 `pattern` 当前文件名，则为真。你可以使用普通文件名生成字符（见 `sh(1)`）。在模式中使用反斜杠 `\` 作为转义字符。从 shell 调用 `find` 时，对模式进行转义或加引号。
- `-ncpio device` 始终为真；以 cpio -c 格式（5120 字节记录）将当前文件写入设备 `device`。
- `-newer file` 如果当前文件比参数文件修改得更晚，则为真。
- `-nogroup` 如果文件属于 `/etc/group` 文件之外的组，则为真。
- `-nouser` 如果文件属于 `/etc/passwd` 文件之外的用户，则为真。
- `-ok command`

  与 `-exec` 类似，但会先带问号打印生成的命令行，并且仅在用户输入 `y` 响应时才执行。
- `-perm [-]mode`

  `mode` 参数代表文件模式位。其格式与 `chmod(1)` 中描述的符号模式操作相同，并按以下方式解释。首先，假设一个所有文件模式位都已清零的模板。对于运算符符号：

  `+` 在模板中设置相应的模式位。
  `-` 清除相应的位。
  `=` 设置相应的模式位，而不忽略进程文件创建掩码的内容。

  你不能在模式的第一个字符使用 `-` 符号；此限制是为了避免与可选的前导横线产生歧义。
  由于初始模式所有位均为关闭，因此任何符号模式都不需要作为第一个字符。

  如果省略横号，当文件权限完全匹配结果模板的值时，主操作结果为真。

  否则，如果 `mode` 以横号开头，当结果模板中的所有位在文件权限位中都已设置时，主操作结果为真。
- `-perm [-]on`

  如果文件权限标记完全匹配八进制数字 `onum`（见 `chmod(1)`），则为真。如果 `onum` 以横号 `-` 开头，则只比较 `onum` 中设置的位与文件权限标记，如果匹配则表达式为真。
- `-print`

  始终为真；打印当前路径名。
- `-prune`

  始终为真。不要检查匹配模式下方目录结构中的任何目录或文件。
- `-size onum[c]`

  如果文件为 `onum` 块（每块 512 字节），则为真。如果在 `onum` 后跟随 `c`，则大小为字节。
- `-type c`

  如果文件类型为 `c`，则为真，其中 `c` 为 `b`（块设备文件）、`c`（字符设备文件）、`d`（目录）、`l`（符号链接）、`p`（管道）、`s`（套接字）或 `f`（普通文件）。
- `-user oname` 如果文件属于用户 `oname`，则为真。如果 `oname` 是数字且未出现在 `/etc/passwd` 文件中，则被视为用户 ID。
- `-xdev`

  如果文件系统与路径同一设备，则为真。

## 复合表达式

你可以使用列出的运算符组合主操作数，优先级顺序如下：

`(expression)` - 括号对 shell 有特殊含义，必须转义。

`! expression` 主操作数的否定（`!` 是单元运算符）。

`expression [-a] expression` 主操作数的连接（两个主操作数并列表示逻辑与）。

`expression -o expression` 主操作数的或（`-o` 是或运算符）。

注意 — 当你将 `find` 与 `cpio` 使用，或者反之使用 `-L` 选项时，会得到意外的结果。

如果没有表达式，则使用 `-print`。否则，如果给出的表达式不包含 `-exec`、`-ok` 或 `-print` 操作数，则给出的表达式实际上被替换为：`-print`。

`-user`、`-group` 和 `-newer` 主操作数分别评估各自的参数。

## 示例

以下命令等效。它们都会输出当前目录的整个目录树。

```
castle find .
castle find . -print
```

以下示例从根目录 `/` 搜索并列出系统中所有文件。

```
castle find / -name core -print
/export/home/winsor/core
/files/winsor/bookgames/src/xblackjack/core
```

以下示例搜索当前目录并静默删除所有 core 文件。

```
castle pwd
/export/home/winsor
castle ls core
core
castle find . -name core -exec rm {} \
castle ls core
core: No such file or directory
```

如果你想看到被删除的文件列表，请按如下示例所示在命令行中添加 `-print` 选项。

```
castle find -name core -exec rm {} \ -print
```

以下示例递归打印所有权限模式匹配用户读、写、执行权限，以及组和其他读、执行权限的文件。

```
castle find . -perm u+rwx,g=rx,o=rx
./dt
.dt/sessions
.dt/sessions/current
.dt/sessions/current.old
.dt/types
.dt/types/fp_dynamic
.dt/tmp
.dt/sessionlogs
```
