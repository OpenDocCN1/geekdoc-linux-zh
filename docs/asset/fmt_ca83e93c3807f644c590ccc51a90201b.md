## 5-13 实用程序

### 获取用户和系统信息

你也可以使用 `finger` 显示一个用户的用户名。例如，在一个有一个名为 Helen Simpson 的用户的系统中，你可能知道 Helen 的姓是 Simpson，但可能猜不到她的用户名是 `hls`。`finger` 实用程序并不敏感，可以使用 Helen 的名或姓来搜索关于 Helen 的信息。以下命令可以找到你寻找的信息，以及其他名字为 Helen 或 Simpson 的用户的信息：

```
$ finger HELEN

Login: hls
```

```
$ finger simpson

Login: hls
```
