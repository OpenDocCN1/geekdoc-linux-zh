
### 13.7.2 在 Windows 中安装 FTK

#### FTK 的前提条件

FTK 安装有两种不同的设置（配置选项）：

- 单台机器：FTK + 数据库
- 两台机器：在独立机器上的 FTK + 数据库

以下截图显示了带有 PostgreSQL 数据库的 FTK 通用规格

| 软件 | 规格 |
|---|---|
| 操作系统 | Server 2008 R2 / Windows 7 (64-位) |
| 处理器 | Intel i7, 双四核或 AMD 等效处理器 |
| 内存 | 32 GB（或更多） |
| OS / 应用程序 | 带 64MB 缓存的 7200 RPM 驱动器或 SSD |
