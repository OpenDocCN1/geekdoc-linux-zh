## integrit (完整性)

### Linux 词典

像 `Tripwire` 这样的文件完整性校验程序可以帮助你确定入侵者是否修改了你的系统。如果没有使用完整性检查，系统管理员将无法知道用于调查系统的程序是否为木马。通过创建一个包含系统最核心部分快照的数据库，你可以将数据库存放在安全的地方，稍后可以使用它来确保没有人对你的系统进行非法修改。完整性功能的特点是：内存占用小、在配置文件中有针对路径的规则、支持 XML 或人类可读输出，以及支持同步检查和更新。源自 Debian 3.0r APT

信息安全的一个领域，是关注哪些消息/信息是“正确”的且未被对手更改或篡改的领域。例如：我们在个人支票上写金额时，同时用数字和文字写下。这可以防止他人更改金额，例如在数字中多加一位，从而从你那里索要 1000 美元而非授权的 100 美元。我们将加密哈希值作为文档指纹和检测文档变更的方法。最流行的哈希是 SHA-1 和 MD5。针对信息修改、插入、删除的关键完整性检查。对比：完整性（integrity）和真实性（authenticity）这两个词被泛用来指代相同的意思。在其他情况下，它们有不同的含义（特别是在法律领域）。“完整性”通常是指防止已发送的消息被恶意篡改，而“真实性”还意味着对消息发送者进行某些验证以防止伪造。另一种看待完整性的角度是系统完整性。关注点是维护计算机本身的完整性，而不是跨线传输的消息。在这种语境下，目标是防止文件被修改或程序被安装到系统中。系统完整性的重点之一是使用 tripwire，通过维护所有文件的哈希表来检查系统的完整性，并检测哪些文件发生了变化。另见：完整性通常与机密性、认证和不可否认性等其他概念相关。源自 Hacking-Linux

## 交互式登录（网络登录）

Microsoft Windows 有两种登录机器的方式。交互式登录是你本地登录（坐在控制台前），而网络登录是通过网络远程连接文件服务器的过程。通常，两种登录在输入一次用户名/密码后同时发生，用户通常感知不到两者的区别。网络登录可以由管理员禁用。这防止了人们窃取密码并远程管理机器。这使得物理安全变得更容易。

### Linux 词典

对比：Unix 具有类似的概念。本地登录通过“控制台”进行。Windows 和 Unix 都通过一个用户账户远程登录到 root/管理员。源自 Hacking-Linux
