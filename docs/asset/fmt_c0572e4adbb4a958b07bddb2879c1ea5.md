
# Vi 编辑器基础

## Vi 的两种模式

Vi 有两种模式：

- **命令模式** —— 允许你执行管理任务，如保存文件、执行命令、移动光标、剪切（选取）和粘贴行或单词，以及查找和替换。在此模式下，输入的任何内容——即使是单个字符——都被解释为命令。
- **插入模式** —— 允许你向文件中插入文本。在此模式下输入的所有内容都将被解释为输入。

Vi 从命令模式启动。要输入文本，你必须进入插入模式。如何进入那里？简单来说，还有其他进入插入模式的方法，它们将在本章稍后的部分描述。要退出插入模式，按 `Esc` 键，这将让你回到命令模式。

> 如果你不确定自己处于哪种模式，按两次 `Esc` 键，你就会进入命令模式。事实上，为了安全起见，你可以一直按两次 `Esc` 来进入命令模式。

## 启动 Vi 与界面说明

无论你启动 Vi ——无论是通过现有文件名还是新文件名——你都从命令模式开始。

### 新文件界面

你会注意到光标后的每行上都有一个波浪号 (`~`)。波浪号表示一个未使用的行（没有换行符或任何形式的文本）。如果某行没有以波浪号开头且看起来是空白的，则存在一个空格、制表符、换行符或其他不可见字符。大多数版本的 Vi 提供的信息并不多（某些版本会提供关于下一步该做什么的极简信息或指导）；唯一的信息在屏幕底部的状态行，它显示了文件名和光标位置。像 Unix 中的许多事物一样，提供的信息可能随系统而异。你的 Vi 实现可能包含更多或更少的信息。

### 常见错误处理

- 如果你在尝试用 Vi 打开文件时收到“拒绝访问”错误或只读指示，说明该文件具有你无法访问的保护限制，或者你以只读模式启动了 Vi。
- 非文本文件（如二进制文件）可能会给 Vi 中的用户带来问题，例如显示垃圾内容——即不可读的输出。如果你遇到具有意外结果的文件（例如不可读的文件），只需输入 `:q` 即可退出文件而不对文件进行任何修改。

## 在文件内移动

要在不影响文本的情况下在文件内移动，你必须处于命令模式（按两次 `Esc`）。最基础的移动是字符到字符。

### 基础字符移动命令

| 命令 | 结果 |
| --- | --- |
| `k` | 向上一行 |
| `j` | 向下一行 |
| `h` | 向左移动一个字符 |
| `l` | 向右移动一个字符 |

> 你可以使用键盘上的标准方向键在文件中移动，但建议使用表中所指定的键，因为方向键在所有平台上并不都工作。

### 数字前缀与重复执行

如果你想在文件内移动超过一个字符或行，可以在按下移动键之前输入想要移动的次数。例如，如果你想在文件中向下移动 10 行，输入 `10j`（在命令模式下），你的光标将从当前行向下移动 10 行。

假设有以下行：
> The quick brown fox jumped over the lazy dog.

- 如果光标位于句中的第一个 `T` 上，且你输入 `10l`，光标将向右移动 10 个字符（包括空格）。
- 如果光标在 `f` 上且你输入 `6h`，光标将向左移动 6 个字符。

> 由于 Vi 是区分大小写敏感的，因此在使用命令时需要注意大小写。

### 进阶移动命令

| 命令 | 说明 |
| --- | --- |
| `0` | 光标移动到行首 |
| `$` | 光标移动到行尾 |
| `w` | 光标移动到下一个单词（单词由空格、制表符或标点符号隔开） |
| `b` | 光标移动到上一个单词 |
| `^` | 光标移动到行首非空白字符（句子以标点符号开头） |
| `Ctrl+F` | 向下翻页 |
| `Ctrl+B` | 向上翻页 |
| `G` | 光标移动到文件的末尾（你可以使用数字来跳转，例如 `4G` 会移动到第 4 行） |
| `:数字` | 冒号后跟数字跳转到行（例如 `:4` 会移动到第 4 行） |
