
服务器将查找文件：
`/home/username/public_html/foo.html`

在上述示例中，`home/username/`是用户的主目录（注意用户主目录的默认路径可能不同）。
确保用户主目录的权限设置正确。主目录必须设置为`0711`。用户的`public_html`目录必须设置读取 (`r`) 和执行 (`x`) 位（`0755`也可以）。在用户`public_html`目录中提供的文件必须设置为`0644`。

## 10.5.31. DirectoryIndex

`DirectoryIndex`是用户通过在目录名称后指定斜杠 (`/`) 请求目录索引时，服务器提供的默认页面。
当用户请求页面`http://example/this_directory/`时，他们将获得存在的`IndexError`页面或服务器生成的目录列表。`DirectoryIndex`是`index.html`和`index.html`类型映射。服务器尝试寻找这些文件中的任何一个，并返回找到的第一个。如果没有找到任何这些文件，且该目录设置了`Options Indexes`，服务器将生成并返回HTML格式的目录子目录和文件列表，除非目录列表功能已关闭。

## 10.52. AccessFileName

`AccessFileName`指定了服务器在每个目录下应用于访问控制信息的文件名。默认值为`.htaccess`。

在`AccessFileName`指令之后，有一组`Files`标签将对任何以`.ht`开头的文件应用访问控制。出于安全考虑，这些指令会拒绝Web访问任何`.htaccess`文件（或其他以`.ht`开头的文件）。

## 10.533. CacheNegotiatedDocs

默认情况下，Web服务器会请求代理服务器不要缓存任何基于内容协商的文档（即可能随时间变化，或由于请求者的输入而改变的文档）。如果将`CacheNegotiatedDocs`设置为`on`，将禁用此功能并允许代理服务器缓存文档。

## 10.534. TypesConfig

`TypesConfig`指定了设置默认MIME类型映射列表（文件扩展名到内容类型）的文件。默认的`TypesConfig`文件为`/etc/mime.types`。相对于`/etc/mime.types`，添加MIME类型映射推荐的方法是使用`AddType`指令。

有关`AddType`的信息，请参阅第10.5.58节`AddType`。

## 10.535. DefaultType

`DefaultType`为Web服务器无法确定MIME类型的文档设置一个默认类型。默认值为`text/plain`。

## 10.536. IfModule

`<IfModule>`和`</IfModule>`标签创建一个条件容器，只有在指定的模块加载时它才被激活。包含在`IfModule`标签内的指令将在两种条件之一被处理：如果起始`<IfModule>`标签中包含的模块已加载，则处理指令；或者，如果在模块名称之前出现感叹号`[!`，则只有在`<IfModule>`标签指定的模块未加载时，才处理指令。

有关Apache HTTP Server模块的信息，请参阅第10.7节“添加模块”。

## 10.537. HostnameLookups

`HostnameLookups`可以设置为`on`、`off`或`double`。如果将`HostnameLookups`设置为`on`，服务器会自动为每个连接解析IP地址。解析IP地址意味着服务器与DNS服务器建立一个或多个连接，这增加了处理开销。如果将`HostnameLookups`设置为`double`，服务器将执行双反向DNS解析，产生更多的处理开销。

为了节省服务器资源，`HostnameLookups`默认设置为`off`。

如果服务器日志文件中需要主机名，请考虑在滚动Web服务器日志文件时更高效、批量地进行DNS查找。

# 第10章 Apache HTTP Server

## 10.5.38. ErrorLog

`ErrorLog`指定记录服务器错误的文件。默认情况下，此指令设置为`/var/log/httpd/error_log`。

## 10.5.39. LogLevel

`LogLevel`设置错误日志中错误信息的详细程度。`LogLevel`可以设置为（从最不详细到最详细）`emerg`、`alert`、`crit`、`error`、`warn`、`notice`、`info`或`debug`。默认`LogLevel`为`warn`。

## 10.5.40. LogFormat

`LogFormat`指令配置虚拟Web服务器日志文件的格式。实际的`LogFormat`取决于`CustomLog`指令中给出的设置（参见第10.5.41节`CustomLog`）。

当`CustomLog`指令设置为`combined`时，可用选项如下：

- `%h`（远程主机的IP地址或主机名）
列出请求客户端的IP地址。如果`HostnameLookups`设置为`on`，除非无法从DNS获取主机名，否则将记录客户端主机名。

- `%l` (`rfc931`)
不使用。日志文件中的该字段显示连字符 `[-]`。

- `%u`（身份验证用户）
如果需要身份验证，则列出记录的用户名。通常不使用此，因此日志文件中的该字段显示连字符 `[-]`。

- `%t`（日期）
列出请求的日期和时间。

- `%r`（请求字符串）
列出完全来自浏览器或客户端传来的请求字符串。

- `%s`（状态）
列出返回给客户端主机的HTTP状态码。

- `%b`（字节）
列出文档的大小。

- `%(Referer)i`（引用者）
列出将客户端主机引用到Web服务器的网页URL。

- `%(User-Agent)i`（用户代理）
列出发出请求的Web浏览器类型。

## 10.5.41. CustomLog

`CustomLog`识别日志文件和日志格式。默认情况下，日志记录在`/var/log/httpd/access_log`文件。

默认的`CustomLog`格式为`combined`。以下展示了组合日志文件格式：

| remote | rfc931 | user | date | "request" | status | bytes | referrer | user-agent |
|---|---|---|---|---|---|---|---|---|

## 10.5.42. ServerSignature

`ServerSignature`指令向任何服务器生成的文档添加包含Apache HTTP服务器版本和`ServerName`的行，例如发送给客户端的错误消息。`ServerSignature`默认设置为`on`。

也可以将其设置为`off`或`EMail`。`EMail`在自动生成的响应的签名行中添加一个`mailto:ServerAdmin`HTML标签。

## 10.5.43. Alias

`Alias`指令允许访问`DocumentRoot`目录之外的目录。任何以别名结尾的URL都会自动解析为别名路径。默认情况下，`icons`目录的别名已被Web服务器访问，但该目录不在`DocumentRoot`中。

## 10.5.44. ScriptAlias

`ScriptAlias`指令允许`DocumentRoot`目录之外的目录被访问。任何以别名结尾的URL都会自动解析为别名路径。默认情况下，`icons`目录的别名已被Web服务器访问，但该目录不在`DocumentRoot`中。 (注：此处原文似乎存在重复或错误，已按逻辑翻译)

## 10.5.45. Redirect

当使用`Redirect`时，它可以将文件映射到新的URL。格式如下：

```
Redirect /old-path http://<current-domain>/<file-name>
```
