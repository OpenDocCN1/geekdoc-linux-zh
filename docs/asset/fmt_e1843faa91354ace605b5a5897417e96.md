# 引导磁盘 (boot disk)

一种包含足够操作系统（如 Linux）的磁盘，用于启动计算机并从命令行运行基本程序。如果系统由于某种原因导致无法启动，则可能需要它。引导磁盘可用于分区和格式化硬盘、恢复主引导记录（`MBR`）或复制特定文件等。出自 I-gloss http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# 引导扇区 (boot sector)

IBM 计算机引导硬盘或软盘上的第一个轨道（第 0 轨道）。在启动过程中，只读存储器（`ROM`）告诉计算机读取该轨道的第一个块并加载找到的任何程序。如果发现了文件系统，它会引导计算机加载 MS-DOS。出自 QECURID

# 引导扇区（引导根） (boot root)

自引导程序所在驱动器的第一个扇区。当微病毒出现时，引导扇区病毒是最常见的体。它们通过软盘传播。当用户在计算机重启时将软盘留在驱动器中，它会从软盘启动。这将运行病毒，病毒随后感染硬盘上的引导扇区。任何进一步插入系统的软盘都会被病毒感染。应对措施：我曾在一家执行严苛反病毒程序的公司工作（所有桌面都安装反病毒，定期擦除），从未能从引导扇区病毒中完全释放；有一种病毒从未在公司内被根除。我个人的政策是断开机器的软驱，并在剩余机器上禁用软驱启动。出自 Hacking-Lexicon

http://www.tld.org/LDP/Linux-Dictionary/html/index.html
