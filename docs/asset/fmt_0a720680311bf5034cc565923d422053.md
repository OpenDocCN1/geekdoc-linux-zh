## 定理 15.16

每个偶环都是 2-可选的。

**证明.** 我们已经知道 `$C_4$` 是 2-可选的。设 `$C_n$` 是一个 `$n$`-环，其中 `$n \ge 6$` 为偶数。假设 `$C_n = (v_1, v_2, \ldots, v_n, v_1)$`。设给出了 `$C_n$` 的顶点大小为 2 的颜色列表集合 `$\mathfrak{L} = \{L(v_i) : 1 \leq i \leq n\}$`。我们证明 `$C_n$` 是 `$\mathfrak{L}$`-列表可着色的。我们考虑两种情况。

### 情况 1.

所有颜色列表都相同，例如对于 `$1 \leq i \leq n$`，`$L(v_i) = \{1,2\}$`。如果我们给奇数 `$i$` 的 `$v_i$` 分配颜色 1，给偶数 `$i$` 的 `$v_i$` 分配颜色 2，那么 `$C_n$` 是 `$\mathfrak{L}$`-列表可着色的。

### 情况 2.

`$\mathfrak{L}$` 中的颜色列表并非都相同。那么 `$G$` 中存在相邻顶点 `$v_i$` 和 `$v_{i+1}$` 使得 `$L(v_i) \neq L(v_{i+1})$`。因此，存在颜色 `$a \in L(v_{i+1}) - L(v_i)$`。图 `$C_n - v_i$` 是一个阶为 `$n-1$` 的路径。设 `$\mathfrak{L}' = \{L(v) : v \in V(C_n - v_i)\}$`。根据定理 15.14，存在 `$C_n - v_i$` 的 `$\mathfrak{L}'$`-列表着色 `$c'$`，使得 `$c'(v_{i+1}) = a$`。设 `$b \in L(v_i)$` 使得 `$b \neq c'(v_{i-1})$`。那么由

```
c(v) = \begin{cases} b & \text{若 } v = v_i \\ c'(v) & \text{若 } v \neq v_i \end{cases}
```

定义的着色 `$c$` 是 `$G$` 的 `$\mathfrak{L}$`-列表着色。
