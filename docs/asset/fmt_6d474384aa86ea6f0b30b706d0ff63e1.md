### 其他考虑

多年来，许多基于`Arch`的发行版来来往往，但有些经受住了时间的考验，新的也定期出现。发行版通常会添加非自由软件以改善用户体验，但`Parabola`和较新的`Hyperbola`走向了另一个极端。这两个发行版不仅以诅咒命名，都是`FSF`认可的，并使用`Linux-libre`内核。`Hyperbola`从`Debian`获得灵感，使用较旧但久经考验的内核。`Arch`可能已停止支持`32`位，但`Arch Linux 32`发行版依然活跃且健康。

`Arch-Xference`和`Anarchy Linux`，两者都是`Xfce`风格，值得一试。`Chakra Linux`是一款`KDE`发行版，去年给我们留下了深刻印象，但自那以后未再更新。那些想要比`ArchLabs`更轻量的用户应查看`ArchBang`，它受现已停止维护的`CrunchBang`启发。以曲折的方式，这也启发了`ArchLabs`。

## Linux 用户使用 BSD

`Aaron Peters`在一个熟悉又陌生的领域探索，深入`FreeBSD`，这是`Linux`的开源表亲...

如果你正在阅读这篇文章，那么你对自由软件至少有一点点兴趣。也许这仅限于`Linux`，但自由开源软件（`FOSS`）社区比那更广阔。有许多软件项目运行在其他操作系统上，还有各种开源的`Un*x`克隆。

`BSD`操作系统家族是一个重要例子，代表了最早真正摆脱传统`Unix`代码遗留的系统之一，可以被视为如今我们所知`Linux`的叔叔。最初的一个系统，伯克利软件分发版（`BSD`），经历了许多版本（本身就是一本书），由不同的项目和厂商开发。今天的`BSD`系统家族包括`NetBSD`、`OpenBSD`和`TrueOS`。其中，`FreeBSD`被认为是最“通用”的，也是有争议的流行度最高的。值得注意的是，`Apple`使用`FreeBSD`代码作为`Darwin`项目的基础，这是一个后来成为`Mac OS X`（现在是`macOS`）的操作系统。

如果你正在寻找一个安装后即可立即投入生产的桌面系统，有更好的选择（参见侧边栏了解`BSD`家族的其他成员）。但本文旨在作为一个学习练习，看看这个有点`Unix`风格的小恶魔表现如何。`FreeBSD`通过比其他面向桌面的系统（无论是`Linux`还是`BSD`）更亲自动手提供了这种学习机会。然而，作者确实有一个目标——能够从零开始安装到一个完整的“生产力系统”，包括`GUI`界面和配套工具。但在这个过程中，我们的目标既要看什么相同，也要看什么不同。

正如我们在开源社区所知，多样性是数字生活的调味料。因此，我们有责任探索这个`BSD`系统，看看到底怎么回事。

为什么要使用`FreeBSD`？也许更好的问题是“为什么不使用`FreeBSD`？”正如我们将看到的，`FreeBSD`与`Linux`拥有相同的`Unix`根源，我们可以期待我们的技能能很好地迁移过来。哦，当然会有一些细微差异，但`shell`就是`shell`，`FreeBSD`中的`ls`命令确实会列出当前目录的内容。

但总是能从不同的做事方式中学到东西，`FreeBSD`出色的领域包括：

- 作为服务器。`FreeBSD`驱动了互联网上一些最基本服务，也用于构成其基础设施的一些网络硬件。

- 安全性。作为服务器操作系统的起源，使`FreeBSD`包含了许多独特的安全功能，如访问控制列表（`ACL`）、强大的防火墙选择，以及用于运行虚拟化操作系统的监狱（`jails`）。

- 遵循文档。在许多现代`Linux`发行版中，安装是简单的点点点过程。相比之下，`FreeBSD`来自一个你必须真正阅读文档、理解它并密切跟随的时代。

- 关注编译源代码。`Ports`系统为那些并非职业软件工程师的人提供了编译软件的绝佳入门介绍。

为了乐趣使用`FreeBSD`。用它来学习，并在社区中传播它——毕竟我们是一家人。安装`FreeBSD`的方式与`Linux`类似，你需要获取某种安装介质，然后从该介质启动机器。安装过程中的主要区别有三点。首先，安装程序是基于文本的。其次，安装程序不提供返回上一屏幕的选项。最后，安装期间包含软件的方式相当独特。

在这种语境下，“包含”软件并不意味着实际安装它。但安装程序确实提供了添加`FreeBSD Ports`集合的选项。`Ports`相当于`Linux`软件包仓库，只是它们用于构建软件包而不是安装。

暂时来说，如果你安装过`Linux`发行版，你会轻松通过基于文本的安装程序屏幕：

- 首先是几个环境屏幕：键盘映射选择，为机器选择主机名。

- 选择“发行版”。如上所述，确保包含`Ports`。将这些视为软件集合，而不是对基于`Linux`的操作系统的俚语。

- 磁盘分区。第一个选项将在传统的`UFS`和较新的`ZFS`文件系统之间选择。对于测试，`UFS`即可。你会被提供通常的手动分区或接管整个磁盘。你还将选择几种不同的分区方案。

- 安装程序将开始将发行版解压缩到你的驱动器上。别走开，这不会花太长时间。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_24_0.png)

最后，是一些快速的系统配置，包括设置`root`用户、网络、时区、日期/时间、服务（默认选择`SSH`）、安全选项和用户账户。

有一些子步骤，这看起来可能像我们略过了安装过程。但诚实地说，如果你做过`Linux`安装，你不会有任何麻烦。对于我们中那些达到一定年纪的人来说，步骤`2`甚至可能带回编写`Slackware`软盘套件的温馨回忆。

## 认识 BSD 恶魔般的家族

`FreeBSD`与`Linux`相似，拥有一个扩展的其他系统家族。现在`BSD`世界中有相当多的不同选择。以下是其中一些最受欢迎的：

- `FreeBSD` ([www.freebsd.org](www.freebsd.org)) 最初首先是服务器操作系统（就像大多数类`Unix`系统一样），但现在定位为“多面手”系统，如果你愿意付出努力，正如我们将要介绍的。

- `NetBSD` ([www.netbsd.org](www.netbsd.org)) 是另一个通用操作系统，专注于尽可能运行多种不同设备，这意味着你同样可以很容易地在桌面、服务器，或`2004`年左右取代`NEC MobilePro 790`上的`Windows CE`中找到它。

- `OpenBSD` ([www.openbsd.org](www.openbsd.org)) 其声望在于安全性，所有软件包都在源代码级别经过严格的审计。

- `TrueOS` ([www.trueos.org](www.trueos.org))，最初称为`PC-BSD`，这是一个对`FreeBSD`的桌面友好型重混，预配置了图形化安装器和预安装的应用程序包等便利功能。

- `DragonFlyBSD` ([www.dragonflybsd.org](www.dragonflybsd.org)) 从`FreeBSD`分支而来，为高性能应用程序提供精心调整的系统。

- `GhostBSD` ([www.ghostbsd.org](www.ghostbsd.org)) 技术上是`FreeBSD`的孙辈，因为它基于`TrueOS`构建。正如`Linux`发行版站在巨人的肩膀上一样，这旨在提供比其父级更简单的体验，专注于`MATE`和`Xfce`等更轻量的桌面。
