- 1. 选择“文件向导”（File Wizards），根据你正在创建的文档类型选择相应的向导。Writer 提供了创建信件、事实、议程、演示文稿和网页的向导。在本示例中，我将选择“信件向导”。Writer 将使用它创建一个新的信件文档，并显示第一个 Writer 对话框，如图 16-13 所示。

# 创建和使用模板

正如本章早些部分提到的，Writer 自带了一系列优秀的默认文档类型（称为模板），并提供了向导帮助你使用它们，甚至根据文档类型创建新模板。上一节描述了如何创建自己的样式以精调你在文档中使用的设置。这非常方便，但它只会修改与特定文档相关的样式——创建该文档的模板不会获取这些新样式，这使得你很难与其他分享你的样式见解。这也让复用这些样式变得困难，除非你通过复制带有新样式的现有文档来创建每个新文档，然后替换其内容。这种情况下，这是一件非常痛苦的事，最坏的情况下是完全没有效率。正确的解决方案是轻松创建和管理你自己的文档模板。你可以通过从更新后的模板启动新文档来复用你的样式，并只需通过向其他用户提供模板副本来共享你的 Writer 向导。

创建新模板的过程最初与手动创建新文档（不使用向导）相同。主要区别在于你不需要添加内容（仅需设计新样式的代表性元素），并且将新文档保存为模板而不是文档。继续下文！

要创建一个新模板，请执行以下操作：

- 1. 从任何 Writer 窗口中选择文件 -> 新建模板和文档，以显示图 16-20 所示的对话框。
