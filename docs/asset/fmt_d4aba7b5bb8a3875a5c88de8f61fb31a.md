
用于运输二氧化碳的化合物具有四个原子，因此这些植物被称为 `C4` 植物。固定三碳化合物并产生三碳化合物的植物被称为 `C3` 植物。大多数植物都是 `C3` 植物。

# 光球

光球的表面是覆盖在重金属之上的气体层，深度为 8,604 英里（13,900 公里）；除非我们考虑太阳的直径和约 5800 K（10500 F）的平均温度。来自光球的辐射占了地球能量通量的大半。
对流胞将光球上方的蓝色区域（热区）连接起来，这些区域被深色颗粒（冷区）包围。一个典型的颗粒直径约为 600 英里（1000 公里）。对颗粒水平和垂直运动的测量表明存在中等对流流。参见 `[SLK]`。

# 光合作用

含有叶绿素或细菌叶绿素的细胞利用无机材料制造有机化合物（初级碳水化合物）。这一过程需要光形式的能量。在植物细胞中，光合作用涉及水（`H2O`）氧化为氧分子，并释放到环境中。
相比之下，细菌光合作用不涉及 `H2O` 的氧化，而是使用其他供体，如 `H2S`。本文将重点关注植物的光合作用。参见生物物学与代谢叶绿素植物研究。
光合作用色素吸收的能量，特别是叶绿素或细菌叶绿素色素，被高效地转化为储存的化学能。光合作用的两个方面——有机物质的转化和光能向化学能的转化——使其成为地球上生命的根本过程；它是所有生命物质和所有生命能量的终极来源。

## 光合作用反应

烟酰酸磷酰物（`NADPH`）作为 `CO2` 还原固定为有机分子的电子来源。这些分子除了一贯以葡萄糖等碳水化合物或聚合物的形式存在外，还作为氮化合物的基础。此外，将 `CO2` 同化为有机分子的反应被称为光合反应，这些反应可能不在黑暗中发生，而在光下发生——与光反应相反。

### C3 光合作用
`C3` 光合作用的关键细节详见图 1。三个分子 `CO2` 与三个分子核酮糖二磷酸在反应中结合，形成酶结合的三碳化合物。这些化合物被水解为六分子三碳化合物，然后通过六分子 `ATP` 磷酸化，释放 `ADP` 以通过光反应进行光合作用。所得物通过光反应中形成的 `NADPH` 还原，形成三碳磷酸甘油醛（`PGAL`）。一个分子 `PGAL` 可与另一个三碳化合物二羟丙酮磷酸结合，后者由部分 `PGAL` 重新组装（需要卡尔文循环的第二次“循环”）以形成六碳糖。另外五个 `PGAL` 分子通过一系列反应可以与 `CO2` 结合以再次启动循环。循环两次“转”的产物六碳糖发生在植物的叶绿体中（由二碳糖葡萄糖和果糖组成）——

### C4 光合作用
`C3` 循环可能是 `CO2` 同化的唯一途径，尽管在某些植物（如玉米、甘蔗和高粱）中，它被叶片中异常的光合组织（克兰兹结构）所取代。在这些植物中，存在名为 `C4`-二酸途径的额外 `CO2` 途径（图 2）。`CO2` 固定形成四碳酸苹果酸，然后还原为天氨酸或以酸的形式运输。四碳酸移动到束细胞，在那里通过 `C3` 循环释放 `CO2`，产生的三碳化合物移回叶肉并可以进行羧化。`C4` 光合作用根据束细胞中的四碳酸分为三种：
- `NADP-ME` 型：`NADP+ + 苹果酸 → 草草酸 + NADPH`
- `NAD-ME` 型：`NAD+ + 苹果酸 → 草草酸 + NADH`
- `PCK` 型：`磷酸烯醇丙酮 + ATP → 草草乙酸`

在干旱和沙漠条件下，由于水分短缺，水分流失严重并迅速导致脱水。通过在白天关闭气孔可以保持水分，但会阻止在晚上发生的 `CO2` 固定。在景肉科、大戟科和其他科中，独立演化出了 `CAM` 代谢策略，其中 `CO2` 的分离是时间上而非空间上的。`PEP` 被 `PEP` 固定。

### 光探测器

在减少光合作用下，光合作用的速率可以被高达 50%。由于光合作用为植物生长提供了必要的物质，光合作用抑制会导致生长减缓并最终死亡（同化）。
光合作用是一个复杂的多阶段过程。主要阶段包括：(1) 初级光化学过程，其中光被吸收并转化为某些富能中间体形式的化学能；以及 (2) 酶催化（即非光化学）反应，通过这种反应将这些中间体转化为最终产物和游糖。
自养植物的细胞内二氧化碳由核酮糖磷酸羧基加氧酶固定。许多植物可以通过在夜间吸收二氧化碳并在光合作用期间释放来实现。这些植物被归类为景肉植物酸代谢（`CAM`）。其他植物，如玉米（`CAM`），在白天通过一种缓慢积累的机制吸收二氧化碳，并在晚上释放。
实验表明，植物可以在卡尔文循环（`C3` 或 `PS I` 反应）将二氧化碳转化为糖，而光依赖反应（`PS II`）则发生在类囊体中。

用于运输二氧化碳的化合物具有四个原子，因此这些植物被称为 `C4` 植物。固定三碳化合物并产生三碳化合物的植物被称为 `C3` 植物。大多数植物都是 `C3` 植物。

光伏是含有一种或多种碱金属（钠、钾、铯、锑或银）的半导体。半导体导带中含有过量的自由电子，这增强了表面的光电效应。使用半导体材料——砷化镓（`GaAs`）或砷化铟（`InGaAs`）来实现伏。这些材料在环境温度下运行高效。这种暗电流即使在黑暗中也存在并随温度指数级增加。在 60 °C (333 K) 时可达到 `$10^{-5}$ A/cm²`。
