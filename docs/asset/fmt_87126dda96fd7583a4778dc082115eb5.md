
```python
c["session"] = "/"
c["domain"] = "foo.bar.com"
c["expires"] = "18-Feb-2001 15:00:00 GMT"
```

要将 cookie 数据输出为一组 HTTP 头部，使用 `c.output(method)`。

```python
print(c.output())
# 生成两行输出
# Set-Cookie: session=8273612; expires=...; path=/;...
# Set-Cookie: user=beazley
```

当服务器向 HTTP 服务器发回 cookie 时，它被编码为键=值对的字符串，例如 `"session=8273612; user=beazley"`。`expires`、`path` 和 `domain` 等可选属性不会被返回。该 cookie 字符串可以被解析为 `SimpleCookie` 对象。`http.cookie` 通过提供一个特殊的字典类对象简化了生成 cookie 值的任务，该对象存储并管理 cookie 值，被称为 marshals。每个 marshal 都有一个名称、一个值以及一组包含提供给浏览器的元数据的属性 `[expires, path, comment, domain, max-age, secure, version, httponly]`。名称是一个简单的标识符，因为 `"name"` 不同于 `"expires"` 或 `"path"` 等元数据名称之一。值是一个短字符串。要创建一个 cookie，只需像这样创建：

```python
c = SimpleCookie()
```

`smtplib` 模块提供了一个底层 SMTP 客户端接口，可以使用 RFC 821 和 RFC 1869 描述的 SMTP 协议发送邮件。该模块包含许多低级函数和方法，在在线文档中有详细说明。然而，以下内容涵盖了该模块最实用的部分：

## urllib 包

`urllib` 包提供了一个高级接口，用于编写需要与 HTTP 服务器、FTP 服务器和本地文件交互的客户端。应用程序可以包括从网页抓取数据、自动化、代理、网络爬虫等。这是一个高度配置的库模块，因此不会列出每一个细节。相反，本文描述了该包最常用的用途。

在 Python 2 中，`urllib` 的功能分布在几个不同的库模块中，包括 `urllib`、`urllib2`、`urlparse` 和 `robotparser`。在 Python 3 中，所有这些功能已整合并重组到 `urllib` 包。

## urllib.request

`urllib.request` 模块提供了打开和从 URL 获取数据的函数和类。在 Python 2 中，此功能位于 `urllib2` 模块中。该模块最常用的用途是通过 HTTP 从 Web 服务器获取数据。对于此示例，这段代码显示了获取网页的最简单方法：

```python
try:
    from urllib.request import urlopen  # Python 3
except ImportError:
    from urllib2 import urlopen  # Python 2
```

与现实世界的服务器交互时会许多复杂性。例如，你可能需要担心代理服务器、身份验证、cookies、用户代理等方面问题。所有这些都得到了支持，但代码更加复杂。

## urlopen() 和 Requests

执行请求最直接的方法是使用 `urlopen()` 函数。

`urlopen(url, data, [timeout])`

`urlopen` 返回一个类文件对象，可用于读取返回的数据。`url` 可以是字符串或稍后描述的 `Request` 类的实例。`data` 是一个包含要上传到服务器的数据 URL 编码字符串。如果提供了该参数，则使用 HTTP POST 方法而不是默认的 `'GET'`。数据使用诸如 `urllib.parse.urlencode` 的函数生成。`timeout` 是内部用于所有阻塞操作的可选超时时间。

由 `urlopen()` 返回的文件对象 `u` 支持以下方法：

| 方法 | 说明 |
| :--- | :--- |
| `u.read([bytes])` | 将字节作为字节字符串读取。 |
