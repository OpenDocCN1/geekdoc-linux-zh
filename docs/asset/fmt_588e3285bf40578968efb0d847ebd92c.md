# 第 1 章：KALI LINUX 简要历史

如果您曾经尝试过检查系统漏洞或破解网络中的 Wi-Fi 密码，那么您可能已经熟悉 Kali Linux。它是一个专注于安全的 Linux 版本，提供了许多有助于我们黑客攻击自己网络以发现弱点并防止其他黑客试图进入您系统的工具。

最初，这套系统是出于 Kali 主要开发者 Mati Aharoni 的必要性而创建的。在进行专业安全工作时，这位开发者发现他需要想出许多安全工具，而不必在客户的系统上安装大量软件和其他内容。于是，他转向 Linux，看看他能够一站式做什么来应对这个问题。

这种发行版的理念包含了一堆出于必要性而诞生的安全工具。Aharoni 在与客户进行安全接触时面临着一个困境。他不允许在接触中携带任何硬件，而且通常你只能使用现场电脑，前提是你不能进入硬盘或以任何方式修改它们。

这是一个相当标准的程序。这些公司希望从他们的电脑中获得最大的安全性，并希望确保没有黑客能够入侵。但他们不希望太多东西被更改或修改

他们的系统。你必须保持谨慎，并确保发现所有漏洞。

在 Aharoni 花了一些时间思考这个问题之后，他意识到这些工作条件看似不可能实现，但他只需进行若干调整并添加一些工具即可满足这些条件。所有这些工具都可以添加到现有的可启动 Live Linux CD 中。这使得每个人都能更轻松地按照自己的意愿使用该系统，而不会遇到任何问题。

一旦创建完成，就可以将光盘（在我们的情况下则是可启动 USB 驱动器）带入到作业区域，在你希望工作的任何计算机上启动这些内容，然后直接在 RAM 中操作，这样不会对硬盘或其他部分造成任何影响。完成工作后，你可以选择重新使用该驱动器，或者销毁可启动驱动器，在需要另一种使用场景时再次下载即可。

随着时间推移，情况会发生变化，Linux 带来了新的下载包和更新。Kali Linux 的整体诞生源于一种认知：是时候将过去八年构建 Linux 安全发行版的经验应用到一张全新的画布上，并加以发挥了。原始的 Linux 形式是处理黑客活动及应对随之而来的各种复杂部分的绝佳方式。但随后，Kali Linux 帮助打磨了这一切，并投入时间来深入实践，从而取得了一些优异的成果。

这意味着，针对原始的 Linux 黑客操作，我们需要回顾并拆除此前构建的所有内容，并以全新的起点开始。这一过程对于参与此项目的开发人员来说既令人恐惧又令人解脱，因为他们必须放下某些整体发行版相关的包袱，而这并不容易。但另一方面，这也给了他们重新构建，甚至扩展当前系统以创造更好成果的机会。

一旦 Kali Linux 开发人员做出了这些艰难的决定，他们发现下一步需要处理的是引入一些真正懂行的人参与到该系统中。这正是他们引入了一位来自 Debian 的新开发人员，该人员帮助他们从零开始构建新的开发基础设施。这一协助对项目非常有益，确保了 Kali Linux 尽可能成功。

Kali 附带的一个目标是为大量特殊硬件提供操作系统镜像，主要是基于 ARM 的硬件。这将包括使用所需的一切，包括 Android TV 设备、平板电脑、树莓派（Raspberry Pi）等等。我们将使用的每一种硬件都具有独特的属性。

例如，MK808 配备双核 CPU 和惊人的 1GB RAM，同时保持中等尺寸 USB 加密狗的形态。想象一下！这是一台强大且高效的便携式黑客计算机，电池供电，可以装在你的口袋里。想想这对你的整个黑客和安全系统有多么棒。

因此，我们需要决定要针对哪种类型的硬件。这取决于几件事。可用性是主要障碍。在处理安全评估时，我们将尝试识别以有趣方式使用的有趣硬件，如果找到这样的硬件，就有可能构建 Kali 以配合其工作。然而，目前 Kali 支持的硬件种类繁多，且这个列表每个月都在不断增长。

关于 Kali Linux 最大的担忧之一是 BackTrack 到 Kali 的转变，这最终导致我们进行了品牌重塑。在作为安全社区主要力量多年之后，BackTrack 是众所周知的。如果我们突然改变这一点，对于部分用户来说可能会显得混乱和困惑，他们不确定该如何处理以及如何让人们接受这一变化。

好消息是，许多不同的程序总是不断进行品牌重塑。这很难做到，有时可能做得不够好。但有时他们必须这样做。在某些情况下，品牌重塑确实具有挑战性，但参与将其品牌更改为 Kali 的开发人员认为这段时间是值得的。

使用 Kali Linux 系统有很多不同的选择和优势，花时间来学习如何根据自己的某些需求操作它是值得的。使用 Kali Linux 的首要优势是它是免费的。尽管使用该系统无需支付任何费用，但它将附带一套先进的工具，以满足你保持系统安全完好的所有需求。正如 Linux 操作系统是开源的，Kali 也可供你终身免费使用。这是吸引许多开发人员使用它来满足部分安全需求的因素之一。

另一个优势是它将遵循文件系统层次结构标准。这在安全领域至关重要。所有遵循被称为 FHS 标准的系统，都将允许用户找到支持文件、二进制文件以及他们成功所需的所有库。对你而言，这意味着你不必手动寻找任何需要的工具，因为你可以将命令名称输入到 root 终端中，系统就会为你找到它。

你还可以使用数百种渗透工具。我们将稍后讨论你可以使用此程序进行的渗透测试，但确保没有人能进入你的系统并造成问题非常有帮助。Kali Linux 上提供超过 600 种渗透测试工具，旨在帮助网络安全团队更轻松地了解其网络的安全状况。

这些工具将包括许多收集网络信息所需的基本工具、分析工具，甚至报告工具。Kali Linux 整合如此多此类工具的原因是确保没有任何事情是听天由命的。
