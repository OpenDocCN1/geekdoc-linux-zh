
## 姬蜂

中型至大型昆虫（黄蜂）的通用名称，包含25,000个物种，属于姬蜂科（膜翅目）；与姬蜂总科（`Ichneumonoidea`）中的小蜂总科（`Braconidae`，另有15,000个物种）共同构成姬蜂总科。大多数姬蜂体型纤细，具有细长的丝状触角，可自由转动的头部，以及永久伸出的产卵器。姬蜂分布全球，在茂密的植被区域如林地边缘、树篱和次生植被中最为丰富，常在林地树冠层或林下枯落物中被发现。姬蜂在春季和秋季最常见，因为这些黄蜂会避开炎热干燥的天气。参见 膜翅目；昆虫纲。

姬蜂科的所有成员在幼虫阶段均为寄生性。它们攻击多种多样的昆虫，通常是甲虫、蝴蝶、蛾、蝇和其他膜翅目的幼虫阶段。由于其许多宿主昆虫被视为森林和农作物的害虫，姬蜂在生物防治中有益且重要。参见 昆虫学；经济昆虫学。`[S.B.V]`

## 鱼龙

中生代爬行动物的一个亚纲，由高度特化的水生鱼龙目组成。鱼龙化石已知自下三叠世至白垩纪末期。它们的体型与现存的 dolphins 相似。高等鱼龙具有纺锤形躯干、狭窄的尾柄和宽高比较高的月牙形尾鳍。这种体型配置与现代游速最快的鲨鱼及金枪鱼、剑鱼等硬骨鱼非常接近。参见 爬行纲。`[R.T.C]`

## 鸟龙目

一个小型的会飞的带牙的化石鸟类目，年代可追溯至白垩纪，仅包含北美洲的鸟龙科。将鸟龙目与黄昏鸟目一起置于鸟亚纲中，仅基于它们共有的牙齿特征；这种亲缘关系仍需更多证据支持。参见 黄昏鸟目；鸟亚纲。

最初的`Ichthyornis`（鱼鸟）发现于堪萨斯州的尼奥布拉拉白垩层，但近期的发现已将其分布范围扩展至北美洲大部分地区以及早白垩世。`Ichthyornis`在白垩纪晚期消失，可能是由于该时期覆盖北美洲中部大部分地区的广阔内陆海的消失。

参见 鸟纲。

## 鱼石螈

在晚泥盆世（4亿–3.5亿年前 [见插图]）由肉鳍鱼类祖先演化而来的四足脊椎动物（基干四足类）。`Ichthyostega`（鱼石螈）是第一个被描述的泥盆世四足类，于20世纪30年代在东格陵兰发现。在许多年里，它是唯一已知来自关节骨骼化石的“鱼类-四足类过渡”代表。随后，同一层位发现的第二个属`Acanthostega`（棘鱼螈）被更完整地描述，而在20世纪90年代，在世界其他地方发现了泥盆世四足类动物属。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1134_0.png)

与其他早期四足类动物一样，`Ichthyostega`（鱼石螈）的头骨由一个外部颅骨（头骨顶）组成，其内部包含一个容纳脑的独立骨盒（脑颅）。脑颅显示出一些极不寻常的特征，尤其是在耳部区域，这些特征难以解释，且与其他早期四足类动物相似的特征不符。

颅后骨骼显示出一些原始特征和高度特化特征。尾部像鱼类一样有一圈鳍条，这些特征在所有其他已知的早期四足类中均已消失，除了`棘鱼螈`。支撑脊髓的神经棘通过发达的关节面（关节突）相互连接。肋骨是厚实且重叠的板状结构，围绕身体形成紧身胸衣，赋予其刚性。

巨大的肩带承载着大型且结构复杂的肱骨，该肱骨与肩关节在垂直于身体的位置连接。巨大的胸廓仅通过韧带和肌肉附着于脊柱，没有像现代四足类动物那样涉及骨关节面。股骨长度似乎约为肱骨的一半，后肢呈桨状，胫骨、腓骨和踝骨都宽大且扁平。脚部有七个脚趾，似乎被皮肤形成的蹼包裹。参见 两栖纲；迷齿类。

`[J.A.Cla.]`

## 火成岩

由熔融物质凝固而成的岩石。根据形成条件不同，它们可能由晶体、玻璃或两者组成。它们来源的熔融物质称为岩浆；当喷出地表时，通常被称为熔岩。高温岩浆的凝固是对热量损失的响应。在深处形成的岩浆倾向于上升。它通常穿过地壳，溢出到地球表面或海底，形成火山岩或喷出岩。在地表快速冷却时，会形成细粒或玻璃质岩石。

当岩浆无法到达地表时，它会通过上覆岩石保温而更缓慢地冷却；从而形成较粗的质地。由此产生的火成岩相对于相邻岩石表现为侵入岩。一般来说，深部形成（深成）的岩石显示最粗的质地。在浅层形成的（浅成）火成岩显示出介于火山岩和深成岩类型之间的特征。参见 岩浆；侵入体；火山；火山学。

质地指的是均匀聚集体内部岩石组分之间的相互关系。它取决于结晶质和非结晶质（玻璃质）物质的相对含量，以及组分的大小、形状和排列方式。岩石质地具有重要意义；它们有助于揭示岩石成因问题，并告知关于岩石形成条件和环境的大量信息。

火成岩的分类方案众多。使用三种主要的分类方法。

- 宏观方案基于手标本的外观或放大镜（硬透镜）下的观察。这些方案在野外岩石研究中很有用。
- 微观方案（主要是矿物学的）用于需要更详细信息的实验室研究。
- 化学方案非常有用，但应用范围更有限。岩石的矿物成分和质地通常比总体化学分析更能揭示岩石的起源。火成岩在化学、矿物、质地和结构上表现出巨大的变化，几乎没有自然界限。

深成岩存在于大型侵入体（岩基、岩颈和其他大型侵入体）中。它们在极大深度形成，常被称为深成岩。它们由缓慢冷却的大型岩浆体生成。

火山岩作为熔岩流或火山碎屑岩（火山灰和较粗碎屑物质的混合堆积）形成。它们快速凝固，逸出挥发物形成的膨胀气泡经常产生高度多孔的岩石。

浅成岩表现出介于火山岩和深成岩类型之间的特征。它们与火山岩的不同之处在于它们是侵入性的，且通常不含玻璃质和多孔结构。它们与深成岩的不同之处在于它们存在于小规模的岩体（脉岩和岩床）或浅层形成的大规模岩体（岩盖）中，并且具有因较快速冷却而形成的特征质地。参见 长英岩；玄武岩；长石；霞石；辉石；花岗岩；花岗闪长岩；斜长石；辉长岩；辉石；石英；流纹岩；正长岩；粗安岩。

火成岩形成矿物可归为原生或次生。原生矿物是直接由岩浆结晶形成的。次生矿物可能在岩石凝固后的任何时间形成。主要原生矿物种类相对较少，可归为浅色（酸性）或深色（基性）品种。酸性是长石质矿物（长石和霞石）和二氧化硅（石英、方英石和鳞石英）的记忆术语。基性是镁铁矿物（黑云母、角闪石、辉石和橄榄石）的记忆术语。酸性矿物主要由二氧化硅、氧化铝和碱组成。基性矿物富含铁、镁和钙。

次生矿物包括在岩石凝固后添加物质形成的矿物，或由岩石中已存在矿物蚀变形成的矿物。某些矿物变得或多或少重组的蚀变现象非常普遍。由主要原生矿物衍生的常见蚀变产物如下。

| 原生矿物 | 次生矿物 |
| :--- | :--- |
| 石英 | 不蚀变 |
| 钾长石 | 高岭石，绢云母 |
| 斜长石 | 高岭石，绢云母（伊利石），绿帘石，硬柱石，方解石 |
| 霞石 | 方钠石，方解石，钠沸石 |
| 白长石 | 霞石和钾长石 |
| 方钠石 | 方解石，方钠石 |
| 黑云母 | 绿泥石，钛铁矿，绿帘石，金红石，氧化铁 |
| 普通角闪石 | 透闪石，黑云母，绿泥石，绿帘石，方解石 |
| 斜方辉石 | 蛇纹石，透闪石，滑石 |
| 单斜辉石 | 普通角闪石，透闪石，黑云母，绿泥石，绿帘石，蛇纹石 |
| 橄榄石 | 蛇纹岩，磁铁矿，滑石，菱镁矿 |

参见 岩石学。

## 集块岩（凝灰岩）

一种由一股或多股贴地流动的炽热火山碎屑或颗粒形成的火山碎屑岩沉积物，本质上与火山碎屑流沉积物、火山灰流凝灰岩、洪水凝灰岩或焊凝灰岩同义。

集块岩通常在喷发性火山喷发过程中产生，并与世界上大多数火山系统有关。其大小差异巨大（喷发物质体积在 `10^{-3}` 到 `10^{3}` `km^{3}` 之间变化），且其化学成分涵盖了岩浆岩常见的整个范围（从玄武质到流纹质）。集块岩可以呈现任何形态和尺寸，但大多数沉积物呈板状形状，覆盖数万平方公里。

集块岩沉积物的特征是由火山灰（晶体和玻璃屑）和浮石组成的分选不良的集合体。在较大的沉积物中，浮石碎片可能被压扁和拉伸，形成卵形至透镜状形状，定义了沉积物在就位后或就位期间的压实和焊接。参见 `IGNEOUS ROCKS`（岩浆岩）；`PUMICE`（浮石）；`PYROCLASTIC ROCKS`（火山碎屑岩）；`TUFF`（凝灰岩）；`VOLCANIC GLASS`（火山玻璃）；`VOLCANO`（火山）。

## 点火系统

内燃机中引发燃料与气缸内空气之间化学反应的系统，其通过产生火花来实现充能。多缸内燃机的点火系统具有三个基本功能：

- (1) 产生足够能量的火花，以点燃每个气缸内的燃料-空气混合物；
- (2) 控制点火时刻以获得最佳效率，使气缸压力在活塞达到压缩行程顶部后不久达到最大值；以及
- (3) 选择正确被点火的缸。

在感应点火系统中，有三种可能的控制类型：真空-机械式、电子火花式或全电子发动机式。在火花放电之前，电能以感应方式存储在初级线圈中。通往初级线圈绕组的电流由点火模块根据点火时刻触发信号进行通断控制。电流关闭的时刻标志着火花事件的开始。精确的点火时刻计划是许多发动机变量的复杂函数，例如燃料-空气成分、发动机每分钟转数 (`rpm`)、温度、气缸压力、废气再循环率、爆震倾向以及发动机设计。

点火线圈在闭合（电流接通）期间存储电能，并在闭合结束时作为变压器工作，将初级中存储的低电压、大电流能量转换为次级中的高电压、小电流能量。分电器通过定位转子使其面对连接到某个火花塞的端子来选择被点火的火花塞。所选的火花塞取决于气缸点火顺序，而点火顺序又取决于发动机设计。分电器由凸轮轴以发动机转速的一半驱动。参见 `SPARK PLUG`（火花塞）。
