## `Text` 控件

`Text` 控件允许用户输入文本。该文本可以是多行的，并且 `Text` 控件提供了完整的文本编辑功能。如果你确定你只需要让用户进行单行输入，可以指定 `TextField` 控件。这仅仅是 `Text` 控件的缩减版本。除非显式说明，否则两者的资源是相同的。这些包括：

- `XmNvalue`: 一个字符字符串，就像 C 语言中一样。这与 Motif 1.1 或旧版本不同，在旧版本中该值是一个复合字符串。如果你使用的是 Motif 1.2 或更高版本，它将是 C 字符串。
- `XmNmarginHeight` 和 `XmNmarginWidth`: 控件边界与文本之间的像素数。默认值为 5 像素。
- `XmNmaxLength`: 这设置 `XmNvalue` 资源中字符数量的限制。
- `XmNcolumns`: 每行的字符数。
- `XmNcursorPosition`: 从文本文件开始到光标位置的字符数。
- `XmNeditable`: 一个布尔值，如果设置为 `TRUE`，将允许用户插入文本。

此控件的回调函数为：

- `XmNactivateCallback`: 当用户按下 Return 键时调用。
- `XmNfocusCallback`: 当控件接收到指针焦点时调用。
- `XmNlosingFocusCallback`: 当控件失去指针焦点时调用。

针对此控件有几个方便函数：

- `XmTextGetString(Widget w)` 返回一个 C 字符串 (`char *`)。
- `XmTextSetString(Widget w, char *s)` 为控件设置字符串。
- `XmTextSetEditable(Widget w, Boolean trueOrFalse)` 设置控件的可编辑字符串。
- `XmTextInsert(Widget w, XmTextPosition pos, char *s)`: 在由 `pos` 定义的位置设置文本。此 `XmTextPosition` 是一个不透明的项，定义了文本数组中的索引。
- `XmTextShowPosition(Widget w, XmTextPosition p)`: 滚动以显示位置 `p` 处的剩余字符串。
- `XmTextReplace(Widget w, XmTextPosition from, XmTextPosition to, char *s)`: 将从位置 `from`（包含）开始到位置 `to` 的字符串替换为字符串 `s` 中的字符。
- `XmTextRemove(Widget w)`: 清除字符串中的文本。
- `XmTextCopy(Widget w, Time t)`: 将当前选文本复制到 Motif 剪贴板。`Time t` 值源于最近的 `XEvent`（通常在回调中），剪贴板用它获取最新的记录。
- `XmTextCut(Widget w, Time t)`: 与 `XmTextCopy` 类似，但会从文本缓冲区移除被选文本。
- `XmTextPaste(Widget w)`: 将 Motif 剪贴板的内容粘贴到当前光标（插入）位置的文本区域。
- `XmTextClearSelection(Widget w, XmTextPosition p, XmTextPosition q, Time t)` 选择从位置 `p` 到位置 `q` 的文本。

## 按钮

按钮在点击式的世界中无处不在。特殊的变体包括*单选按钮 (radiobuttons)* 和*复选按钮 (checkbuttons)*；但最重要的是*推按钮 (pushbuttons)*。

### `PushButton`

`XmPushButton` 可能是 Motif 中最常用的控件。列表 2.1 和 2.2 显示了该类的基本用法。当推按钮区域的被按下时，按钮将进入“按下 (armed)”状态。按钮的颜色会改变以反映这种状态。这种颜色可以通过 `XmNarmColor` 设置。当 `XmNfillOnArm` 资源设置为 `TRUE` 时，会显示此颜色。

**提示:** 如果推按钮的 `XmNarmcolor` 似乎不起作用，尝试将 `XmNfillOnArm` 资源设置为 `TRUE`。

推按钮的回调函数为：

- `XmNarmCallback`: 当推按钮按下时调用。
- `XmNactivateCallback`: 当按钮处于按下状态时，在控件区域释放按钮时调用。如果释放按钮时指针在控件外部，则不会调用此函数。
- `XmNdisarmCallback`: 当按钮处于按下状态时，指针在控件区域外释放按钮时调用。

**提示:** 如果一个控件注册了多个函数的回调函数，则所有函数都会被调用，但不一定是按照它们注册的顺序执行。不要依赖在其他系统上保持相同的顺序。如果你想在回调期间按特定顺序执行多个函数，请将它们封装在一个函数中。在列表 2.2 中，你看到了如何使用 `XtAddCallback` 为推按钮添加回调函数，相同的方法也可用于为其他动作调用其他函数，例如 `XmdisarmCallback`。
