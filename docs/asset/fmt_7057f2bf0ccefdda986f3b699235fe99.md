# xupopuyoyo

一种类似于俄罗斯方块的游戏，带有彩色方块。`Xupopuyoyo` 是一种类俄罗斯方块的益智游戏，你的目标是匹配四个相同颜色的“色块”。每次匹配都会获得积分，还会向你的对手投掷石头，这些石头非常难以处理且难以清除。同时多次匹配可以获得更多分数，并导致向对手投掷更多石头（令他们沮丧）。第一个让屏幕填满 `xupopoyo` 的人输了。支持单机模式、人战 AI、人战人以及 AI 战 AI 和网络游戏。来自 Debian 3.0r APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# xuzzles

适用于 X 的谜题集。包含以下谜题：

- 旋转 3D 谜题：`rubrik`, `pyraminx`, `xctot`, `xkweb`, `xmino`, `xmall`
- 滑块游戏：`xetubes`, `xtria`, `hexagons`, `xepan`
- 组合：`xmlin` 使用 `xmpuzzles` 解释谜题，它们尝试在 `app-details` 中安装相同的文件。在覆盖 `xmuuzzles` 安装或与之安装时，配合 `--force-overwrite` 可以安全使用。来自 Debian 3.0r APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# xpvm

用于 PVM XVM 的图形化控制台和显示器。它为 PVM 命令和信息提供了图形界面，并带有多个动画窗口用于监控并行 PVM 程序的执行情况，协助调试和性能调优提供任务间交互的信息。关于 XVPM 的各种功能及其操作方法，请参考相应的在线弹出帮助信息。来自 Debian 3.0r APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# xpw

可怜的文字处理器 EGON。Siege Office 的文字处理器部分，同时也包含 STAG，Siege Office 使用 Office OND 拖放协议。读取在线内容需要 WWW 浏览器。使用 `postscript` 进行文档处理。它可以读取和写入 RTF 和 HTML doc 文件，以便与其他著名的文字处理器协同操作。在 `cdoc` 的帮助下也可以读取 doc 文件。来自 Debian 3.0r APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# xqf
