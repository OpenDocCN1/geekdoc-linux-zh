
## Set up dictionary mapping argument names to values

```python
args = {}

for arg in arglist:
    (key, value) = arg.split('=')
    args[key] = value

# Print time, as before, but with a bit of extra advice
print_time(output)

output.write(
    "Time for a pizza. I'll have the %s and a swig of %s\n" %
    (args['pizza'], args['drink']))
```
