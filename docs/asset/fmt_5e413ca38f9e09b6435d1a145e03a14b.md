# Web Application Platforms

# 冷聚变

Allaire 的 Cold Fusion 是另外一种易于学习和使用的专有产品；尽管它目前仅支持 Windows NT，但 Allaire 最近已开始转换为各种 UNIX 变体，包括 HP-UX、Solaris 和 Linux。Cold Fusion 使用自定义 HTML 标签与标准 HTML 混合来构建自定义的、数据库驱动的页面。你可以在 `http://www.allaire.com` 找到更多信息。

## Java Server Pages (JSP)

Sun 的 Java Server Pages 也是 Web 应用程序平台的新新成员，但它提供了 Sun Java 语言的强大功能。尽管它既复杂又功能丰富，但如果你的组织正在标准化使用 Java 和 CORBA，那么它是一个极佳的选择。JSP 适用于任何提供 Java 解释器的平台，包括 Linux、UNIX 和 Windows NT。更多信息请访问 `http://www.sun.com`。

## Zope

Zope 是一个出色的开源 Web 应用程序平台，它将分级面向对象的数据库与内置模块以及基于 Web 的开发环境整合在一起。它拥有连接到主流数据库引擎的模块，并提供了传统关系型数据库和面向对象数据库的所有优势，以及 PHP 的许多优势。它还提供了一种向下继承方案和内置的权限策略。与大多数开源项目一样，它的开发进展非常快，绝对值得尝试。作为一个具有集成安全模型的复杂全功能产品，它的运行不像 PHP 那么快。你可以在 `http://www.zope.org` 找到更多信息。

## 脚本语言

有很多开源脚本语言，例如 Perl、Python 和 TCL，它们提供了脚本化能力。其中许多语言可以集成到 Apache 和其他 Web 服务器中，从而避免了使用 CGI 时出现的安全和性能问题。这些语言是 Web 开发的极佳选择，特别是当你已经精通它们时。你可以访问以下任何一个网站获取更多信息：`http://www.perl.com`、`http://www.python.org` 和 `http://www.tcl.com`。

## PHP

PHP 是一种非常受欢迎的开源脚本语言，旨在与 ASP 和 JSP 直接竞争。它提供了针对 IMAP、POP3、LDAP、XML、PDF、PostScript、FTP、WebDAV、Oracle、MySQL、mSQL、Informix、PostgreSQL、Sybase 以及数不尽数据库引擎的模块。它运行在 Linux、UNIX 和 Windows NT 上。由于 PHP 是免费提供的、带有源码且与 RedHat Linux 集成的，我们将针对 MySQL 数据库引擎开发使用 PHP 构建的应用。根据 Netcraft 的数据，PHP 驱动着超过百万个 Web 服务器并且增长非常快。更多信息请访问 `http://www.php.net`。

## Apache

到目前为止最流行的 Web 服务器平台是 Apache (`http://www.apache.org`)，根据 Netcraft 的数据，其市场份额约占 60%。微软的 IIS 紧随其后，市场份额为 22%。Apache 提供了优异的性能，尽管性能并不是它唯一的优势。它有丰富的插件和模块可用；它极其稳定并提供了良好的安全性；它运行在所有流行的操作系统上；它具有很强的扩展性；而且它是免费开源的。

Apache 基于 NCSA Web 服务器。Apache 的开发者对 NCSA Web 服务器的开发速度感到不满，发布了他们自己的补丁版本，即“Patchy Web Server”。在之后的多年里，Apache 已经发展成为健壮且支持良好的平台。安全漏洞在几小时内就能被修复，因为每个人都有源代码并可以贡献。PHP 和 Perl 以及大多数其他开源语言和平台，都可以作为插件模块提供给 Apache。虽然 PHP 可以在其他 Web 服务器上运行，但我们将讨论作为 Apache 模块运行 PHP，因为通过 CGI 运行它涉及其他安全限制。

## PHP、MySQL 和 Apache：安装示例应用程序

此应用程序适用于被编译为 Apache 模块（`mod_php`）或 CGI 模块的 PHP。要验证 PHP 是否已正确安装在 Web 服务器上，请在 Web 浏览器中输入以下内容，并在文档根目录（`DocumentRoot`）中保存为 `test.php3`：

```
<?php
phpinfo();
?>
```

当访问 `http://webserver/test.php3` 时，你应该能看到一个巨大的信息页面，列出了所有的 PHP 安装信息。在扩展（extensions）部分下，确认是否加载了 MySQL 扩展。如果没有加载，你将需要编译 MySQL 扩展（请参考 MySQL 文档）。

要创建数据库架构，需要创建一个数据库并加载数据库转储。如果你的数据库尚未创建，请选择数据库并输入以下命令：

```
servername:~$ mysql -u username -p
Enter password:
Welcome to the MySQL monitor. Commands end with ; or \g.
Your MySQL connection id is 106270 to server version: 3.22.27
Type 'help' for help.mysql> CREATE DATABASE shopcart
```

使用以下命令将转储文件导入到 MySQL：

```
servername:~$ mysql -u username -p shopcart < shopcart.sql
```

最后，编辑 `index.php3`（见附录 A）中的 `init_db_variables()` 函数，使其与你的数据库服务器名称、用户名、密码和数据库名称匹配。访问 `http://webserver/` 并确保购物车显示无误。如果你看到的是目录列表或“权限被拒绝（Permission Denied）”，你可能需要在 Apache 的 `httpd.conf` 中的 `DirectoryListing` 中添加 `index.php3`。或者，你也可以创建一个 HTTP 响应页面 `index.html`，它会将浏览器立即跳转到 `index.php3`。
