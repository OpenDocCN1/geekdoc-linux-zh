我们的个人电脑运行需要操作系统。在办公室里，或使用相对廉价的台式电脑时，使用的操作系统可能是微软的 Windows。内容创作者、作家和图形艺术家更倾向于使用苹果电脑，因为它们配备了以创意为中心的 OSX 操作系统。Windows 和 OSX 这两个操作系统已经主导了消费市场多年。然而，存在另一种在易用性、定制性、安全性和价格方面表现卓越的替代操作系统。基于相对不为人知的 Linux 内核的操作系统必须在所有这些领域都达到并超过这些标准，但它仍然是一个许多人甚至没有听过的冷门选项。

Linux 本身并不是一个操作系统。它是一个内核，或者说是操作系统的“核心”。就像 Windows NT 是 Windows 7 的内核一样，Linux 是 Ubuntu、Debian、Arch、Fedora 等“发行版”的内核。

但是，会有人放弃 Windows 的熟悉感而选择一个从未听过的计算环境吗？Linux 不仅在资金上是免费的，而且它兼容大量的设备。旧电脑，特别是那些已经无法运行的电脑，可以通过 Linux 操作系统焕发新生，使其运行得如新的一样。

# Linux 历史

20 世纪初 90 年代初，林斯·托瓦尔斯（Linus Torvalds）是芬兰的一名学生。当时的计算机通常运行在 DOS 或 UNIX 上，这两个操作系统在当时都是专有的且难以使用。托瓦尔斯试图作为一个业余项目（基于 UNIX）创建自己的操作系统，但该项目迅速成长并吸引了更多开发者。内核不断演变，直到它变得可移植（可以在各种系统上使用）并且完全可以用于计算。内核并不是操作系统，尽管 Linux 与 GNU 核心实用程序相结合，创建了一个类似于操作系统的计算环境。

然后，第三方组织获取了基础 Linux 产品，并为其添加了他们自己的高级软件和功能，从而创建了 Linux“发行版”。直到今天，Linux 仍然是一个免费的业余项目，因此内核不断收到托瓦尔斯和社区的更新和修订。在整个 2000 年代，许多其他第三方看到了 Linux 环境的实用性，并开始将其整合到他们的生产环境和企业中。今天，Linux 以因其在服务器和商业环境中被广泛使用而闻名，并拥有小规模的专用桌面用户。面向未来，内核已经达到了永远不会消失流行程度。大公司青睐 Linux 的优势和实用性，因此内核和各种发行版将一直作为最好的替代操作系统存在。

# Linux 的好处

为了比较 Linux 作为计算机选择的有多大，我们将将其与更熟悉的现代操作系统进行比较。

首先，Linux 是免费的。GNU 的背景将 Linux 置于一种“免费和开源”的心态中，随 Linux 发送的大部分（不是全部）软件都是免费的。免费和开源（FOSS）指的是两点：软件在资金上是免费的，而且源代码也是透明的。FOSS 与专有软件的区别在于，FOSS 的一切都是开放的，在使用它时不涉及隐藏的间谍软件、费用或陷阱。软件通常更安全，因为任何人都可以对公开的源代码做出贡献并使其变得更好。由于 Linux 以及你可以为它下载的大部分软件，它对于预算有限的小企业或个人来说是一个极佳的操作系统。通过不收费显然没有牺牲质量，因为 Linux 项目及其各种发行版是社区驱动的，并通过捐赠获得资金。与 Windows 的成本相比，光操作系统通常就需要几百美元。Microsoft Office 是一个受欢迎的文档编写套件，但 Linux 中也存在这些程序的替代方案，它们在质量上绝对可以与大品牌产品媲美。

PC 所有者最大的抱怨可能是病毒。Windows 电脑特别容易受到病毒侵害，即使是防病毒软件公司一直在追赶最新的威胁。只需访问一个恶意网站通常就足够感染计算机，许多用户选择 Mac 电脑是因为与恶意软件相关的事件发生频率要低得多。基于 Linux 的操作系统与 Mac 相似之处在于病毒几乎不存在。这种增强的安全性使得任何关心隐私、安全或可靠性的人都必须切换到 Linux。

Linux 在公司和政府机构中非常受欢迎。这就是为什么高功率服务器和关键设备在运行 Linux 操作系统时，运行得明显更好。该操作系统也以可靠性和稳定性闻名。虽然 Windows 电脑需要定期重启和维护来“刷新”并防止其运行变慢，但 Linux 服务器可以运行几个月甚至几年而无需重启。IT 专业人员由于其声誉不可避免地选择 Linux 作为网络的骨干。其闻名的稳定性在桌面平台也适用于消费者，而且对我们来说绝对有用。

也许使用 Linux 最大的好处是速度。低系统要求意味着在 Windows 上通常很慢的电脑将变得敏捷快速。对变慢感到沮丧的用户会更换操作系统以获得更快速的体验。此外，Linux 可以安装在旧电脑上以重焕活力。因此，尽管旧笔记本对于最新版本的 Windows 可能已经过时，但可能有一个 Linux 发行版可以再榨出几年的寿命。

定制化是技术领域中追求的功能。Windows，尤其是 OSX，由于担心普通用户会破坏它，限制了你对操作系统可以做的操作。Linux 并非如此，因为它鼓励编辑和更改操作系统的视觉效果和功能。当然，这并非必须，而且大多数 Linux 发行版的默认配置非常稳定，很难无意破坏。但对于那些热爱越狱、改装和玩弄电脑的人来说，Linux 可以促进创意的一面，并为好奇的黑客提供在其他系统中无法使用的的工具。

最后，Linux 兼容大量的设备。Linux 可以运行在几乎任何架构上，这意味着它可以安装在手机、台式机、笔记本电脑、服务器、游戏机和“智能”设备上。爱好者们仅仅因为他们可以，就乐于在小众、旧或奇特的设备上安装 Linux。

安装 Linux 有多种方式，例如将操作系统镜像刻录到光盘、写入 USB 闪盘、在线订购 Live CD、格式化 SD 卡，以及通过 Virtual Box 尝试运行。尽管如此，你不能仅仅安装“Linux”就获得一个可用的操作系统。因为 Linux 只是一个内核，你还需要其他提供图形界面、互联网访问等的软件。如前所述，Linux 存在不同的“发行版”（distributions）。发行版是包含预装程序并具有独特风格和重点的 Linux 版本。发行版提取了 Linux 核心，并将其转化为一个适合日常使用的完整操作系统。

Linux 发行版的数量多得惊人。某些版本具有特定用途，例如用于黑客的 Kali Linux、用于教育的 Sugar Linux，以及用于自定义的 Arch Linux。另一些则更通用，例如 Ubuntu 和 Debian。要充分发挥安装 Linux 的优势，你需要了解不同的发行版，并选择哪种最适合你。阅读以下章节将了解一些最受欢迎的发行版的用途。
