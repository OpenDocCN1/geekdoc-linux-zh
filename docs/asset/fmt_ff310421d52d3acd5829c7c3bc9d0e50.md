
# SoftMaker Office

访问 SoftMaker Office 官方网站 `https://www.freeoffice.com/en/` 了解关于 SoftMaker Office 的所有信息。

通过软件管理器获取 DEB/FLATPAK 软件包：

1. 打开软件管理器并搜索 SoftMaker Office。
2. 点击 SoftMaker Office，然后点击源选择框。
3. 选择系统软件包或 Flatpak 并点击安装。

通过 GUI 使用 `.deb` 安装 SoftMaker Office：

1. 导航至发布页面：`https://www.freeoffice.com/en/download/applications`
2. 点击 `Deb` 下载 SoftMaker Office
3. 前往 `~/Downloads`
4. 双击 `softmaker-freeoffice-2021_1068_amd64.de`

# Thunderbird

Thunderbird（火鸟）是一款免费开源的邮件、新闻订阅、聊天和日历客户端，它倡导开放标准以确保通信自由。它易于使用、可定制，由志愿者和付费员工共同开发，并由用户捐助资金。Thunderbird 由社区选举的委员会治理，旨在为封闭平台提供安全、私密的替代方案，促进去中心化的开放标准通信。它致力于提高效率，并提供一个管理信息的扩展平台。

## 访问官方网站

访问 Thunderbird 官方网站 `https://www.thunderbird.net/en-GB/` 了解关于 Thunderbird 的所有信息。

## 通过软件管理器获取 DEB/FLATPAK 软件包

1. 打开软件管理器并搜索 Thunderbird。
2. 点击 Thunderbird，然后点击源选择框。
3. 选择系统软件包或 Flatpak 并点击安装。

## 在终端中通过 APT 安装 Thunderbird

只需输入以下命令：

```bash
sudo apt update
sudo apt install thunderbird
```

## 通过 Snap Store 获取 Snap 软件包

1. 在 Snap Store 中查找 Thunderbird。
2. 点击 Thunderbird，然后点击源选择框。
3. 选择 Snap 下的最新/稳定版本并点击安装。

## 在终端中通过 Snap 安装 Thunderbird

输入此命令：

```bash
sudo snap install thunderbird
```

## 在终端中通过 Flatpak 安装 Thunderbird

输入此命令：

```bash
flatpak install flathub org.mozilla.Thunderbird
```
