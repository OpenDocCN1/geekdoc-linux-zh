`find` 程序通常用于搜索文件和目录，但不带任何选项时，它将向你显示当前目录下所有文件、目录和子目录的列表。

列出目录内容时，`-t` 和 `-r` 选项非常有用。它们按时间排序（`-t`）并反转排序（`-r`）。在这种情况下，最新的文件将位于输出底部。

## 创建文件

通常，文件是通过存储在文件中的程序创建的。一个空文件可以使用 `touch` 命令创建。如果你对现有文件运行 `touch`，文件内容不会改变，但文件的修改时间将被更新。

运行以下命令创建一些用于通配符练习的文件：

```
$ touch globs/question1 globs/question2 globs/question3 globs/question4 globs/question5 globs/question6 globs/question7 globs/question8
```

`question4`

现在让我们验证 `globs` 目录中的所有文件是否存在：

```
$ cd globs
$ ls
question1 question2 question3 question4 question5 question6 question7 question8
```

这种方法并不特定于 `echo`，它可以与任何命令配合。

## 重命名文件

文件被移动和重命名-使用 `mv` 命令移动和重命名文件。

将你的工作目录设置到移动目录：

```
$ cd ~/linux_essentials-2.4/moving
```

创建一些文件进行练习。到此时，你应该已经熟悉这些命令了：

```
$ touch file1 file2
$ echo file3 > file3
$ echo file4 > file4
$ ls
file1 file2 file3 file4
```

假设 `file22` 是一个类型并应该是 `file2`。使用 `mv` 命令修复它。重命名文件时，第一个参数是当前名称，第二个是新名称：

```
$ mv file22 file2
$ ls
file1 file2 file3 file4
```

使用 `mv` 命令要小心。如果你将一个文件重命名为现有文件的名称，它将覆盖后者。让我们用 `file3` 和 `file4` 测试这一点：

```
$ cat file3
file3
$ cat file4
file4
$ mv file4 file3
$ cat file3
file4
```

## 移动文件

使用 `mv` 命令可以将文件从一个目录移动到另一个目录。

创建几个目录用于移动：

```bash
$ cd ~/linux_essentials-2.4/
$ mkdir dir1 dir2
$ ls
dir1 dir2 file1 file2 file3 file5
```

将 `file1` 移动到 `dir1`：

```bash
$ mv file1 dir1
$ ls
dir1 dir2 file2 file3 file5
$ ls dir1
file1
```

注意 `mv` 的最后一个参数是目标目录。每当 `mv` 的最后一个参数是一个目录，文件就会移动到其中。在一个 `mv` 命令中可以指定多个文件：

```bash
$ mv file2 file3 dir2
$ ls
dir1 dir2 file5
$ ls dir2
file2 file3
```

也可以使用 `mv` 来移动和重命名目录。将 `dir1` 重命名为 `dir3`：

```bash
$ ls
dir1 dir2 file5
$ ls dir1
file1
$ mv dir1 dir3
$ ls
dir2 dir3 file5
$ ls dir3
file1
```

# 删除文件和目录

`rm` 命令可以删除文件和目录，而 `rmdir` 命令只能删除目录。让我们通过删除 `file5` 来清理移动过的目录：

```bash
$ cd ~/linux_essentials-2.4/
$ ls
dir2 dir3 file5
$ rmdir file5
rmdir: failed to remove 'file5': Not a directory
$ rm file5
$ ls
dir2 dir3
```

默认情况下，`rmdir` 只能删除空目录，因此我们必须使用 `rm` 来删除普通文件。尝试删除正在删除目录：

```bash
$ cd ~/linux_essentials-2.4/
$ ls
copying creating deleting globs moving
$ rmdir deleting
rmdir: failed to remove 'deleting': Directory not empty
$ ls -d deleting
total 0
drwxr-xr-x. 2 emma Mar 26 14:58 directories
drwxr-xr-x. 2 emma Mar 26 14:58 files
```

默认情况下，`rmdir` 拒绝删除非空目录。使用 `rmdir` 删除 `deleting` 目录下的一个空子目录：

```bash
$ ls -a deleting/files
..
$ rdir deleting/files
$ ls -l deleting
directories
```

删除大量文件或包含许多子目录的深层目录结构似乎很麻烦，但实际上非常简单。默认情况下，`rm` 只作用普通文件。`-r` 选项用于覆盖此行为。小心，`rm -r` 是一个极佳的“自残武器”！当你使用 `-r` 选项时，`rm` 不仅删除任何目录，还会删除该目录内的所有内容，包括子目录及其内容。亲自看看 `rm -r` 是如何工作的：

```bash
$ ls
copying deleting globs moving
$ rm deleting
rm: cannot remove 'deleting': Is a directory
$ ls -l deleting
total 0
drwxwxr-x. 2 emma 6 Mar 26 14:58 directories
$ rm -r deleting
$ ls
copying creating globs moving
```

注意 `deleting` 消失了，尽管它不是空的？像 `mv` 一样，`rm` 有一个 `-i` 选项可以在执行任何操作前进行提示。使用 `rm -ri` 删除移动部分中不再需要的目录：

```bash
$ cd ~/linux_essentials-2.4/
$ ls
copying creating deleting globs moving
$ rmdir deleting
rmdir: failed to remove 'deleting': Directory not empty
$ ls -d deleting
total 0
drwxr-xr-x. 2 emma Mar 26 14:58 directories
drwxr-xr-x. 2 emma Mar 26 14:58 files
```

# 复制文件和目录

`cp` 命令用于复制文件和目录。将几个文件复制到 `copying` 目录：

```bash
$ cd ~/linux_essentials-2.4/copying
$ ls
directories files
$ cp /etc/nswitch.conf files/nswitch.conf
$ cp /etc/issue /etc/hostname
```

如果最后一个参数是目录，`cp` 会在其中创建一个副本。像 `mv` 一样，可以同时指定多个文件。如果两个操作数存在，`cp` 会覆盖第一个。

```bash
$ cd ~/linux_essentials-2.4/copying
$ ls
directories files
$ cp /etc/nswitch.conf files/nswitch.conf
$ cp /etc/issue /etc/hostname
```
