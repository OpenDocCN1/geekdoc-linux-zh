RPC (远程过程调用)

一种 Unix 网络协议，RPC 允许一台机器上的程序在另一台机器上执行“过程”调用。它的优点可以将程序分成部分，每个部分在单独的机器上运行。过程调用被映射，这样程序员就不需要担心细节。对比：旧版本的 RPC 是 Sun RPC，许多协议（如 NFS）都在使用。较新的 DCE RPC 被微软用于其服务。DCE 版本比 Sun 的变体复杂得多，但许多子集更简单。在 1999 年（2000 年初），针对 Sun RPC 的攻击席卷了连接到网络的机器。默认 RPC 服务，许多 Linux 机器也通过 RPC 服务被破解。几乎所有这些攻击都是通过缓冲区溢出实现的。例如：某些 RPC 服务器是远程的，允许客户端查找服务器。NFS 是所有服务中最为人知的。当一个 Unix 系统与另一个 Unix 系统共享文件系统时，你可以断它们正在使用 NFS。“NFS” 意味着特定的协议 “NFS”，但也整个协议套，如 “mount”、“statd” 和 “lockd”。`rpc.mount` NFS 套件中的 “mount”子协议用于客户端连接到文件服务。它是 UNIX 中名为 “mount” 的命令，用于连接远程文件系统，但也软盘、CD-ROM 驱动器或其他硬盘。漏洞：在 1998/1998 年期间，Linux 实现中的缓冲区溢出导致了广泛的渗透。`showmount` 监控文件状态；Linux 和 Solaris 版本的漏洞导致了 1998 年至 2001 年的广泛利用。来自 Hacking-Lexicon `http://www.ldp.org/LDP/linux-Dictionary/index.html`
