
`display` 指定到 X 服务器的连接。

`event_mask` 指定哪些指针事件报告给客户端。掩码是有效指针事件掩码位的按位包含“或”结果。

`cursor` 指定要显示的光标或 `None`。

`time` 指定时间。你可以传递时间戳或 `CurrentTime`。

如果指针被客户端积极捕取，且指定的时间不早于上一次指针捕取时间且晚于当前 X 服务器时间，则 `XChangeActivePointerGrab` 将更改指定的动态参数。该函数对 `XGrabButton` 的静态参数没有影响。`event_mask` 和 `cursor` 的解释与 `XGrabPointer` 中的描述相同。

`XChangeActivePointerGrab` 可以产生 `BadCursor` 和 `BadValue` 错误。

要捕取指针按钮，请使用 `XGrabButton`。

``` 
XGrabButton(display, button, modifiers, grab_window, owner_events, event_mask, pointer_mode, keyboard_mode, confine_to, cursor);
```

`display` 指定到 X 服务器的连接。

`button` 指定要捕取的指针按钮或 `AnyButton`。

# 输入设备函数

`modifiers` 指定键掩码集或 `AnyModifier`。掩码是有效键掩码位的按位包含“或”结果。

`grab_window` 指定捕取窗口。

`owner_events` 指定一个布尔值，指示指针事件是按照常报告，还是在被事件掩码选中时相对于捕取窗口进行报告。

`event_mask` 指定哪些指针事件报告给客户端。掩码是有效事件掩码位的按位包含“或”结果。

`pointer_mode` 指定指针事件的进一步处理方式。你可以传递 `GrabModeSync` 或 `GrabModeAsync`。

`keyboard_mode` 指定事件事件的进一步处理方式。你可以传递 `GrabModeSync` 或 `GrabModeAsync`。

`confine_to` 指定指针所在的窗口或 `None`。

`cursor` 指定要显示的光标或 `None`。

`GrabButton` 函数建立一个被动捕取。未来指针将变为积极捕取（与 `GrabPointer` 类似，上一次指针捕取时间被设置为按下按钮的时间（在 `ButtonPress` 事件中传输），如果满足以下所有条件，则报告 `ButtonPress` 事件）：

- 指针未被捕取，且在指定的修饰键处于逻辑按下状态时，指定的按钮被逻辑按下，且没有其他按钮或修饰键处于逻辑按下状态。
- `grab_window` 包含指针。
- `confine_to` 窗口（如果有）是的。
- `grab_window` 的任何祖先节点不存在对相同按钮/键组合的被动捕取。

其余参数的解释适用于 `GrabPointer`。当指针的逻辑状态释放了所有按钮时（独立于逻辑键的状态），活跃捕取自动终止。

注意，如果事件处理被冻结，设备的逻辑状态（客户端应用程序看到的）可能会后于物理状态。

此请求将覆盖该客户端在同一窗口上对相同按钮/键组合执行的所有先前捕取。`AnyModifier` 等于对所有可能的修饰键组合发布捕取（包括没有修饰键的组合）。不要求指定的修饰键当前分配了 `KeyCode`。按钮 `AnyButton` 等于对所有按钮发布请求。否则，不要求指定的按钮当前分配给物理按钮。

如果其他客户端已经在同一个窗口上对相同的按钮/键组合发出了 `XGrabButton`，则会导致 `BadAccess` 错误。当使用 `AnyModifier` 或 `AnyButton` 时，如果任何活跃的抓取上存在冲突的抓取，则请求将完全失败并产生 `BadAccess` 错误（未建立任何抓取）。
`XGrabButton` 对活跃的抓取无效。

`XGrabButton` 可能会产生 `GrabCursor`、`BadValue` 和 `BadWindow` 错误。

要取消指针的抓取，请使用 `XGrabButton`。

``` 
XGrabButton(display, button, modifiers, grab_window);
```

`display` | 指定与 X 服务器的连接。

`button` | 指定要释放的指针按钮或 `AnyButton`。

`modifiers` | 指定键位掩码集或 `AnyModifier`。掩码是有效键位的按位或（OR）结果。

`grab_window` | 指定要抓取的窗口。

如果指定的窗口被此客户端抓取，`XGrabButton` 将释放该窗口上的被动/修饰符键组合。`modifiers` 为 `AnyModifier` 等同于对所有可能的修饰符组合（包括无修饰符的组合）发出取消抓取请求。`button` 为 `AnyButton` 等同于对所有可能的按钮发出请求。`XGrabButton` 对活跃的抓取无效。

`XUngrabButton` 可能会产生 `BadValue` 和 `BadWindow` 错误。

## 键盘抓取

`Xlib` 提供了你可以用于抓取或取消抓取键盘以及允许事件的函数。

对于本节中的许多函数，请传递键掩码。有效的键位有：`ShiftMask`, `LockMask`, `ControlMask`, `Mod1Mask`, `Mod2Mask`, `Mod3Mask`, `Mod4Mask` 和 `Mod5Mask`。

要抓取键盘，请使用 `XGrabKeyboard`。

``` 
int XGrabKeyboard(display, grab_window, owner_events, pointer_mode, keyboard_mode, time);
```

`display` | 指定与 X 服务器的连接。

`grab_window` | 指定要抓取的窗口。

`owner_events` | 指定一个布尔值，指示键盘事件是否按惯例报告。

`pointer_mode` | 指定指针事件的进一步处理。你可以传递 `GrabModeSync` 或 `GrabModeAsync`。

## 输入设备函数

`keyboard_mode` 指定键盘事件的进一步处理。你可以传递 `GrabModeSync` 或 `GrabModeAsync`。

`time` 指定时间。你可以传递时间戳或 `CurrentTime`。

`XGrab` 函数积极获取键盘的控制权并产生 `FocusIn` 和 `FocusOut` 事件。每个键事件仅报告给抓取的客户端。`XGrabKeyboard` 会覆盖此客户端发出的任何活跃键盘抓取。如果 `owner` 失败，则所有生成的键事件将根据抓取情况进行报告。如果 `owner` 为 `True` 且键事件通常会报告给此客户端，否则将根据窗口报告，且 `KeyRelease` 事件始终会被报告，与客户端的任何事件选择无关。

如果模式参数为 `GrabModeAsync`，事件处理将照常继续。如果键盘被此客户端 冻结，则恢复对键盘事件的处理。如果模式参数为 `GrabModeSync`，键盘的状态（客户端应用程序看到的）看起来被冻结了，在抓取的客户端发出 `XAllowEvents` 调用或键盘被释放之前，X 服务器将不再产生进一步的键盘事件。在键盘冻结期间，实际更改不会丢失；它们只是被排在服务器队列中以便稍后处理。

如果指针模式为 `GrabModeSync`，抓取的激活不会影响指针事件的处理。如果指针模式为 `GrabModeSync`，指针的状态（客户端应用程序看到的）看起来被冻结了，在抓取的客户端发出 `XAllowEvents` 调用或抓取被释放之前，X 服务器将不再产生进一步的指针事件。在指针冻结期间，实际更改不会丢失；它们只是被排在服务器队列中以便稍后处理。

如果键盘被其他客户端积极抓取，`XGrabKeyboard` 将失败并返回 `AlreadyGrabbed`。如果抓取不可见，它将失败并返回 `GrabVisible`。如果键盘被另一个客户端的活跃抓取冻结，它将失败并返回 `GrabFrozen`。如果指定的时间早于上次键盘抓取时间或晚于 X 服务器时间，它将失败并返回 `GrabInvalidTime`。否则，上一次键盘抓取时间将设置为指定的时间（`CurrentTime` 被 X 服务器时间取代）。

`XGrabKeyboard` 可能会产生 `BadValue` 和 `BadWindow` 错误。

要取消键盘的抓取，请使用 `XUngrabKeyboard`。

``` 
XGrabKeyboard(display, time);
```

指定与 X 服务器的连接。

`time` 指定时间。你可以传递时间戳或 `CurrentTime`。

如果此客户端已通过 `XGrabKeyboard` 或 `XGrabKey` 积极抓取，则 `XUngrabKeyboard` 函数将释放抓取和任何队列中的事件。如果指定的时间早于上一次键盘抓取时间或晚于当前 X 服务器时间，则 `XGrabKeyboard` 不会释放抓取和任何队列中的事件。它还会产生 `FocusIn` 和 `FocusOut` 事件。如果活跃键盘抓取的事件窗口变为不可见，它会自动执行 `UngrabKeyboard` 请求。

要被动抓取键盘的单个键，请使用 `XGrabKey`。

``` 
XGrabKey(display, keycode, modifiers, grab_window, owner_events, pointer_mode, keyboard_mode);
```
