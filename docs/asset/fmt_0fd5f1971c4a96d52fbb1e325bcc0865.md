## 1.3 HELP – 它无法工作！

好了，不要恐慌。这将引导你完成让一切工作的过程，即使你没有 Linux 或以太网硬件的背景知识。

首先，你需要确定你的网卡型号，以便判断 Linux 是否有该特定卡的驱动程序。不同的网卡通常有被主机计算机控制的方式，而 Linux 驱动程序（如果有的话）以允许 Linux 使用该网卡的格式包含这些信息。如果你没有任何关于网卡型号的说明书或类似物品，可以尝试帮助处理神秘网卡的章节（参考章节：识别未知网卡）。
