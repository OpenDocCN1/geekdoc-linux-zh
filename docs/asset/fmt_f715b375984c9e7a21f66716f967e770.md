
另一种从你提取的 MP3 和 Ogg Vorbis 文件播放随处可用的音频 CD 的方法是 *Serpentine 音频 CD 刻录器*，这是一个与你的系统捆带的应用程序。要采用此路线，进入**应用程序**（Applications）菜单并选择**音频与视频**（Sound & Video > Serpentine Audio CD Creator**。当 Serpentine 出现时，点击**添加**（Add）按钮并导航到你想添加的歌曲，将歌曲添加到主窗格。你可以添加任何混合的歌曲以及任何混合的音频格式。你也可以通过**文件**（File）菜单并选择**打开播放列表**（Open Playlist）或**打开 Rhythmbox 播放列表**（Open Rhythmbox Playlist，取决于列表类型），添加已保存到播放列表的歌曲。如果你是一个喜欢拖放的人，也可以直接从 Nautilus 窗口或 Rhythmbox 内的播放列表将音频文件图标拖到 Serpentine 窗口的主窗格。

当你向 Serpentine 窗口添加内容时，CD 图像将显示你在磁盘上的可用空间（默认磁盘大小为**15-11**）。74 分钟是 650MB CD 的标准，所以如果你使用的是 700MB 的 CD，请点击**磁盘容量**（Disc Capacity）旁边的下拉菜单并进行相应选择，将设置更改为80 分钟。

当你添加所有想要刻录到 CD 的歌曲后，点击**写入光盘**（Write to Disc）按钮。Serpentine 将开始准备要刻录磁盘的曲目。当准备就绪，它会在新窗口中提示你向驱动器插入空白 CD，只需操作即可，一旦驱动器上的 LED 灯开始闪烁，点击**确定**（OK）。Serpentine 将开始刻录光盘，完成后，它会自动弹出光盘并在另一个窗口中通知你任务已完成。你就可以取出光盘，将其放入车里或任何你想播放的地方，享受结果。

#### Beep

在现有这么多功能丰富的音乐播放器中，很容易忽视原始的，或者在这种情况下，是原始的克隆版本——Beep。Beep 本质上是经典 X Multimedia Stereo (XMMS) 播放器的更符合 GNOME 习惯的版本，XMMS 曾是 Linux 音频播放器的王者。Beep 像 XMMS 一样，被设置为像组件立体声响一样工作（带有移动组件！）。它支持皮肤，这意味着你可以（通过 Synaptic）让它看起来像真实的组件立体声响。你可以通过 Ubuntu 或 Synaptic 下载并安装 Beep。要试用一下，前往“应用程序 > 声音和... > Beep 媒体播放器”。

如果你是一个网络网民，可能没有比 Streamtuner（图 15-17）对你更有用的程序了。Streamtuner 名如其义，是一个在线收音调器。通过从各种来源下载流，你就可以轻松地浏览。当你发现喜欢的内容时，只需选择流，点击 *Play*（播放）按钮，流就会在你选择的播放器中打开（尽管配合 RealPlayer 或 XMMS 效果最好）。如果你将使用不同的播放器进行播放，请选择 *Preferences*（偏好），然后在设置窗口的右侧面板更改播放的默认应用程序（大多数为 XMMS）。例如，如果你想通过 Beep 播放，点击 *Listen to a .m3u file*（播放 .m3u 文件），向右滚动，并将 *XMMS* 改为 *beep-media-player*。

如果你正在安装 Streamtuner，不妨也安装一下 Streamri，它是一种互联网音频流录制器。它与 Streamtuner 配合工作，允许你录制正在听的流（甚至你没听的流）并将它们保存为 MP3 文件。要从 Streamtuner 录制流，只需右键点击目标流，然后在弹出菜单中选择 *Record*（录制）。
