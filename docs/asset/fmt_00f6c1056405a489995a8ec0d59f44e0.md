# spline — 插值平滑曲线

### 概要

`/usr/bin/spline [-aknpx]...`

## 描述

`spline` 命令从标准输入接收数值对，作为函数的横坐标和纵坐标。它产生一组类似的点，这些点近似等距且包含输入集。标准样条输出具有连续二阶导数，并且在绘图（例如通过 `graph(1)`）时具有足够的点看起来平。

## 选项

- `-a` 自动提供横坐标（输入中缺少这些坐标）；通过下一个参数指定间距，如果下一个参数不是数字，则默认为 `1`。
- `-k` 在边界值计算中使用常数 `k`（末尾的二阶导数） = `k*(末尾相邻二阶导数)`，由下一个参数设置。默认 `k=0`。
- `-n` 分配输出点，使得上下 x 限制之间产生大约 `n` 个间隔。（默认 `n=100`）。
- `-p` 使输出具有周期性，使末端导数匹配。第一个和最后一个输入值通常一致。
- `-x` 下一个（或两个）参数是下限（及上限）x 限制。通常情况下，这些限制从数据中计算。自动横坐标从下限开始（默认值为 `0`）。
