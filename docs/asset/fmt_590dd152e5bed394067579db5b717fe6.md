
网址: `www.morpheusarch.co.uk` 许可证: `GPL v2` 版本: `2018.4`

奇怪的是，该项目最好的部分（`LinDiag`）默认并未包含在发行版中，目前功能过于有限且难以使用。

### 其他考虑

正如我们之前提到的，我们在过去几期中介绍的许多救援发行版已不再维护。虽然它们可能不支持最新硬件，或者捆绑的实用程序不是最新版本，但你仍然可以使用它们来修复较旧的机器。例如，有 `Rescatex`（Tux 的手指不应该被！ —— 编者注），它有一个有趣的辅助应用程序，帮助你修复安装的不同部分，而无需了解底层的 CLI 工具。

还有 `Trinity Rescue Kit`，它拥有一个复杂的引导菜单，旨在帮助你找到正确的修复工具。许多修复和救援工具也将其实用程序整合到 `Live CD`（启动光盘）中，这样如果你知道需要使用哪个工具，就可以直接使用。例如，`Boot-Repair` 有一个 `Live CD`，非常适合修复各种引导加载器相关问题。`GParted` 也有自己的 `Live CD`，其中包含其他几个修复和救援实用程序，如 `TestDisk`、`FSArchiver` 等。

## Pop!_OS

让热爱吸睛发行版的 `Jonni Bidwell` 向你展示 System76 专属 Linux 发行版的入门技巧。

人们一直在努力让 Linux 更人性化。今天我们认为——也欢迎持不同意见——Linux Mint 和 elementary OS 是最易用且通用的发行版。当然，它们感谢 Ubuntu 提供了坚实的基础和卓越的软件包选择——而 Ubuntu 本身又得益于 Debian。但也可以争论说，其中的部分流行程度，或者至少过去是，源于用户对 Ubuntu 桌面的不满。

不喜欢 Unity 的人喜欢 Cinnamon，而喜欢 Unity 的人不喜欢 GNOME 3（Ubuntu 从 17.10 开始使用）。elementary OS 的类 macOS 桌面 Pantheon，不仅吸引了那些喜欢水果品牌科技公司（暗示 Apple）的粉丝，也吸引了任何被复杂配置、风格不一致的应用程序和丑陋字体所困扰的人。当然，Windows 10 也在不断将用户推向 Linux，因为开始菜单开始变得像某种不断扩大的广告牌农场，而且更新总是挡道。硬件兼容性也是一个重要问题。如今，发行版必须适应各种新奇配置：HiDPI 分数缩放、多显示器和混合 GPU 配置、磁盘加密。用户希望轻松访问最新软件，开发者希望轻松访问首选开发工具。如果你是像科罗拉多州的 System76 这样的 Linux 系统制造商，提供这些功能尤为重要，这就是它开发了神秘标点符号命名的 Pop!_OS 的原因。让我们来看看它。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_45_0.png)

希望此时你已经试玩过 `Pop!`，并明白了所有喧哗的原因。你甚至可能迫切想要安装它，如果是这样，请查看分步指南。但在这样做之前，你应该知道，如果你拥有 Nvidia 硬件并且通常希望生活更轻松，你绝对应该使用 Pop 的 Nvidia 版本，可从 `https://system76.com/pop` 获取。该版本预装了 Nvidia 专有驱动程序，开箱即用，非常有用。

AMD/Intel 版本仅包含开源驱动程序，包括用于 Nvidia 显卡的 `Nouveau` 驱动，但对于 AAA 级游戏或 `CUDA` 编程来说没什么大用。如果你在启动 Live 光盘或 Pop!_OS USB 时遇到任何问题，请确保你在 UEFI 设置中禁用了安全启动（通常在启动时按 F2 或 Delete 键即可找到）。不同的 BIOS 使用不同的热键调出引导菜单，但 F1、F2 和 F12 比较常见。像大多数不熟悉的发行版一样，你可能会在安装过程中发现一些怪癖，需要你去摸索，但通过资源查找和查阅在线 FAQ 可以最小化这些影响。

### 像它热的那样点它（Pop it like it's hot）

指南涵盖了与 Windows 并排安装；不过如果你有可用的独立硬盘，我们总是建议安装在不同的驱动器上。UEFI 启动意味着 Windows 通常能保持独立，或者将破坏限制在其自身范围内。如果你使用传统 BIOS，可能会发现 Windows 不时重写引导加载器，这很烦人，但可以修复。无论如何，在 Windows 控制面板的电源选项中禁用快速启动很重要，否则你将无法启动另一个操作系统。如果你将 Pop 设置为唯一操作系统，可以安全忽略所有分区说明；只需从安装程序中选择“擦除整个磁盘”，一切都会为你设置好。

你也应该能够安全使用 Pop!_OS 安装程序的分区工具来调整 NTFS 分区大小，但让默认系统（Windows）做这些魔鬼的工作（重组 NTFS 结构）可能更安全。如果你的 EFI 分区小于 512MB——一些 Windows 安装似乎接受 100MB——你需要使用第三方工具调整大小，并可能需要移动 Windows 系统保留分区，这我们绝对不建议。希望这不是你的情况，你无需担心。`Distri`（Pop 专属且令人愉悦的简单安装程序）将在整个安装过程中紧紧握住你颤抖的手。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_46_0.png)

`Videos` 应用提议安装你可能需要的任何编解码器，或者替代安装 `VLC` 或 `MPV`。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_46_1.png)

Pop!_OS 并不真正像 Windows 或 macOS，它只是模糊地类似于 Ubuntu 当前的 GNOME 设置。但它很容易上手：按下 Super（Windows）键或点击左上角访问活动视图，然后开始输入以查找已安装的应用程序。这也会显示你可以从 `Pop!_Shop` 安装的应用程序（好吧，那名字确实有点滑稽）以及最近打开的匹配文件。我们的初始安装重量约为 5.5GB，这在今天看来相当适中。与许多发行版一样，`LibreOffice` 是捆绑安装的，但除了 `Firefox` 和核心工具外，没有庞大且疯狂的应用程序包。包含了一些瑰宝，如讨人喜欢的 `Geary` 邮件程序和 System76 自己的 `Pop!_USB` 写入工具。还有 `Eddy`，它与其押韵的兄弟 `Gdebi` 一样是一个 GUI 工具。

> 如果你选择将 Pop!_OS 安装在独立驱动器上，可以启用全盘加密，确保你的数据在静止时是安全的。

## 细节之处

许多区分 Pop!_OS 的地方在于其幕后对细节的关注。传统上令人烦恼的事情在 Pop! 上很简单。System76 编写了自己的 HiDPI 守护进程，你可以在 `http://bit.ly/1x2SHiDI` 阅读所有相关内容。它轻松处理你运行的任何复杂显示配置，甚至还可以管理具有不同缩放比例的混合 HiDPI 显示器。`Wayland` 默认禁用，但你可以通过编辑 `etc/gdm3/custom.conf` 并注释掉该行来启用它：`WaylandEnable=false`。然后，当你在登录时输入密码时，你会看到常见的齿轮图标，并且可以选择 `Wayland` 和 `X.Org` 会话。在某些多 DPI 情况下，`Wayland` 性能优于 `X`，在我们的测试中，我们只遇到了一些小问题——主要是使用来自 `https://firefox-flatpak.mojoredora.cz` 的 Fedora 实验性 Firefox `Wayland` flatpak。

很容易将 Pop!_OS 视为又一个 Ubuntu 克隆，但我们在平淡无奇的发行版上不会做特性介绍，所以它一定有什么特别之处。除了我们在这里写的内容，还有许多其他让生活更简单的小调整。这些调整做得很巧妙，你几乎不会注意到它们。以用户为设计核心，并受 OEM 独特观点启发，Pop 非常诱人。它作为初学者发行版完美无缺，但在任何方面都没有“降低难度”。它如此灵活和强大，更高级的用户也会喜欢它。天哪，我们刚刚将其安装在官方的 VDF 笔记本电脑上（John 的 `Eee PC`！ —— 编者注）。就这样。

### 发行版

用于安装 DEB 文件 – 适合那些不喜欢使用命令行的用户。

从“活动”视图中，通过输入名称或点击右侧 Dock 上的“显示应用程序”按钮来找到 `Pop!_Shop` 启动器，可以稍作停留，欣赏一下大胆得图标设计。你可以说，Pop!_OS 最初的应用程序选择相当少，但理念是你只需添加所需的内容。并非每个人都想要 `Visual Studio Code` 或 `Slack`，但如果你需要，它们在 `Pop!_Shop` 中很容易找到。

今天的应用推荐由字母 G 带来：`Goxel` – 制作体素艺术意外地令人平静；`GNOME Twitch` – 用于观看 Linux 上的游戏视频；以及 `GIMP`，它仍然是处理图像的最佳方式。

自然，也可以通过命令行使用 `apt` 进行安装，许多软件包也没有 `Pop!_Shop` 条目。Pop 安装中缺少的一项内容是 `NetworkManager` 的 `OpenVPN` 插件，如果你使用 VPN（或预计将来会使用），你会希望用以下命令来解决这个问题：

```
$ sudo apt install network-manager-openvpn-gnome
```
