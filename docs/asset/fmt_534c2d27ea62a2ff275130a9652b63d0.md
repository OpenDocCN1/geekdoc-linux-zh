### 1. type 命令说明

在没有任何选项的情况下，`type` 指示每个名称在用作命令时如何被解释。它会显示名称是别名、内置命令、函数还是可执行文件。如果使用 `-all` 选项，`type` 会显示别名、内置命令、函数和可执行文件的详细信息。使用 `-type -path` 选项，它只显示可执行文件的路径。

### 2. BASH Shell 登录初始化

BASH shell 拥有一组配置文件，用于在你登录、注销或每次进入新的 BASH shell 时配置你的系统。

#### 2.1 .bash_profile

`.bash_profile` 文件是 BASH 的登录初始化文件。它是一个在用户登录时自动执行的脚本文件。该文件包含了 shell 命令，用于定义特殊的环境变量来管理你的 shell。这些变量可能是系统定义特殊变量的重新定义，也用户定义特殊变量的定义。例如，当你登录时，你的用户 shell 需要知道哪些目录包含 Linux 命令。它将引用 `PATH` 变量来查找这些目录的路径名称。然而，`PATH` 变量必须首先分配这些路径名称。在 `.bash_profile` 文件中有一个赋值操作正是为此目的的。由于它位于 `.bash_profile` 文件中，该赋值会在用户登录时自动执行。

特殊变量还需要使用 `export` 命令进行导出，以便你可能进入的任何子 shell（subshells）都能访问它们。你可以通过将变量列为参数在一个 `export` 命令中导出多个变量。通常在 `.bash_profile` 文件的末尾有一个 `export` 命令，列出了该文件中定义的所有变量。如果某个变量未在此列表中，你可能无法访问它。请注意接下来描述的示例中 `.bash_profile` 文件末尾的 `export` 命令。

接下来的示例列出了在你创建账户时为你提供的标准 `.bash_profile` 副本。注意 `PATH` 是如何赋值给自身以及 `$HOME` 值的。`PATH` 和 `HOME` 都是系统已经定义的系统特殊变量。`PATH` 存储你输入的任何命令要搜索的目录路径，而 `HOME` 存储你的主目录的路径。赋值 `PATH=$PATH:$HOME/bin` 的效果是将 `PATH` 重新定义为包含你的目录——你的 bin 目录也会被搜索命令，包括你自己创建的命令，例如脚本和程序。注意 `PATH` 被导出了，以便任何子 shell 访问。如果你也想搜索你的主目录，可以使用 Vi 或 Emacs 编辑器修改 `.bash_profile` 文件中的此行，改为 `PATH=$PATH:$HOME:$HOME`，在末尾添加 `:HOME`。事实上，你可以更改此条目以添加你需要的任何目录。

```bash
# .bash_profile
## .bash_profile

## 获取别名和函数
if [ -f ~/.bashrc ]; then
    ~/.bashrc
fi
```

#### 2.2 用户特定环境和启动程序

```bash
PATH=$PATH:$HOME/bin
ENV=$HOME/.bashrc
USERNAME=""
```

```bash
export USERNAME ENV PATH
```

你的 Linux 系统也有它自己的配置文件，并在你每次登录时执行它。该系统初始化文件简单称为 `.profile`，位于 `/etc` 目录，即 `/etc/profile`。它包含了系统需要为每个用户提供的特殊变量定义。后面是系统 `.profile` 副本。

注意 `PATH` 如何被重新定义以包含 `/usr/X11R/bin` 目录。这是在你在使用 Caldera Desktop 时执行的 W-Window 命令所在的目录。`HISTFILE` 也被重新定义以包含数量更多的事件。

```bash
# /etc/profile
## /etc/profile
```

```bash
## 全局环境和启动程序
## 函数和别名位于 /etc/bashrc
```

```bash
PATH="$PATH:/usr/X11R6/bin"
PS1="[@u\@h \$$]"
```

```bash
ulimit -c 100000
umask 022

HOSTNAME=`bin/hostname`
HISTSIZE=1000
HISTFILESIZE=1000
## arena 浏览默认页面
WWW_HOME=file:usr/doc/calderadoc-0.80-1/Caldera_Info
## CRISPlite 的默认路径
CRPATH=/usr/lib/CRISPlite/macros
```

```bash
export PATH PS1 HOSTNAME HISTSIZE FILESIZE
WWW_HOME CRPATH

if [ "$TERM" == "--console" ];
then
  MINicom=-1 -m -con -tmc; export MINICOM
fi
```

你的 `bash_profile` 初始化文件是一个文本文件，可以像其他文件一样用文本编辑器编辑。你可以通过编辑 `.bash_profile` 并使用命令在分配给 `PATH` 变量的路径列表中插入新的目录路径名称，轻松地向 `PATH` 添加新目录。你甚至可以添加新的变量定义。但是，请务必将新变量名包含在 `export` 命令的参数列表中。例如，如果你的 `.bash_profile` 文件没有 `EXINIT` 变量的定义，你可以编辑该文件并添加新行为 `EXINIT` 赋值值。定义 `EXINIT='set nu ai'`

### 3. BASH Shell 退出初始化文件：.bash_logout

`.bash_logout` 文件也是一个初始化文件，它在用户退出时执行。它的设计是为了在你退出时执行你想要的操作。与变量定义不同，`.bash_logout` 文件通常包含 shell 命令，形成一种关机程序——即你在退出前总是执行的操作。一个常见的退出命令是清除屏幕并发出告别消息。

与 `.bash_profile` 一样，你可以向 `.bash_logout` 中添加自己的 shell 命令。事实上，当账户首次创建时，并不会自动设置 `.bash_logout` 文件。你需要使用 Vi 或 Emacs 编辑器自行创建它。然后，你可以添加告别消息或其他操作。在下一个示例中，用户在 `.bash_logout` 文件中包含了一个 `clear` 命令和一个 `echo` 命令。当用户退出时，`clear` 命令将清除屏幕，而 `echo` 命令将显示消息“Good-bye for now”。
