# 第一章：了解 `VIZ`

停靠和浮动工具栏。`VIZ` 用户界面具有多种功能，包括隐藏或浮动程序的工具栏。`掌握` 从 `VIZ` 窗口右侧分离面板并让其浮动在 `VIZ` 窗口中间。再次选择面板并将其附加左侧。显示工具栏并停靠在面板左侧。

解答

- 1. 将光标放在工具（`Utilities`）选项卡左侧。工具提示将显示“面板（`Command Panel`）”。

- 2. 点击并拖动面板并将其释放到视口上方。面板现在是浮动的。

- 3. 在步骤 1 相同的位置点击并拖动面板标题栏，向左移动直到出现停靠光标。

- 4. 释放鼠标。面板现在停靠在 `VIZ` 窗口的左侧。

- 5. 在任何工具栏的空白区域点击右键。

- 6. 从出现的上下文菜单中选择任何工具栏。该工具栏出现在 `UI` 中。

- 7. 点击标题栏将其拖动到 `VIZ` 窗口的最左侧并释放鼠标。工具栏停靠在面板左侧。

复制对象并使用变换工具。变换（移动 `Move`、旋转 `Rotate` 和缩放 `Scale`）在 `VIZ` 中最常用。通过它们，你可以根据需要对场景中定位、方向和缩放你的对象。你可以通过按住 `Shift` 键并使用任何变换工具在 `VIZ` 中快速创建副本，此过程被称为克隆（`cloning`）。

`掌握` 制作一个 3' 长、10' 宽、8' 高的盒子。制作盒子的五个实例克隆，每个克隆旋转比前一个多 20 度。这些盒子形成螺旋楼梯，每个楼梯的幅度最大，且楼梯之间留留垂直或水平间隙。

解答

- 1. 创建一个盒子，并在参数（`Parameters`）列表中将长度设置为 3'，宽度设置为 10'，高度设置为 8"。

- 2. 点击主工具栏中的选择移动工具（`Select and Move`）。

- 3. 按住 `Shift` 键并拖动 `Z` 轴句柄，直到变换区域中的 `Z` 读取约为 8"，然后释放鼠标。

- 4. 在出现的克隆（`Clone`）对话框中，选择对象到实例（`Object to Instance`）并将副本数量（`Number Copies`）设置为 5，然后点击确定。五个克隆出现在视口中。

- 5. 在移动变换仍然激活的情况下，选择第一个克隆（从底部数起的第二个盒子），如果盒子移出视线，在命令下输入 8，然后在单位设置（`Units Setup`）对话框中将默认单位（`Default Units`）设置为英寸（`Inches`）并再次移动盒子。

- 6. 重复剩余步骤，设置每个的高度比前一个精确高 8"。

- 7. 点击主工具栏中的选择旋转工具（`Select and Rotate`）。

- 8. 从第二个盒子开始，选择每个盒子，在变换区域中输入 `Z` 旋转值，比上一步高出 20 度。

- 9. 切换到四视口布局，并将顶部视口（`Top viewport`）设置为线框（`Wireframe`）渲染模式。

- 10. 使用移动变换，选择透视视口（`Perspective viewport`）中的每个盒子，并将其移动到顶部视口的位置。

创建了命名选择集。每当任何对象被称为选择集时。通常你可能需要为不同的操作重复选择相同的对象。通过创建命名选择集，你可以通过从列表中选择选择名称来快速选择对象。

`掌握` 继续上一个掌握练习，将盒子重命名为 `Step1`、`Step2`、`Step3` 等，从顶部楼梯开始。制作并测试两个命名选择集，一个包含底部三个阶梯，另一个包含偶数阶梯。

解答

- 1. 选择命名为 `Step1`、`Step2` 和 `Step3` 的盒子。

- 2. 在主工具栏的命名选择集输入框中，为包含底部三个阶梯的选择输入一个名称，然后按回。

- 3. 点击视口的空白区域以清除选择集。

- 4. 展开命名选择下拉列表，点击你刚刚输入的名称。底部的三个阶梯被选中了。

- 5. 选择命名为 `Step1`、`Step3` 和 `Step5` 的盒子。

- 6. 在主工具栏的命名选择集输入框中，为包含三个奇数阶梯的选择输入一个名称，然后按回。

- 7. 点击视口的空白区域以清除选择集。

- 8. 展开命名选择下拉列表，点击你刚刚输入的名称。每隔一个阶梯被选中。

## 第 2 章：介绍 `VIZ` 对象

应用修改器。修改器提供了许多操作对象的方法，而这些方法通过手动变换对象的子对象可能无法实现。修改器在修改器栈中出现的顺序决定了最终结果。

`进阶练习` 创建一个茶壶（`Teapot`）原始对象并对其应用切片（`Slice`）修改器。提高切片子对象直到它穿过对象的中间。在切片参数（`Slice Parameters`）卷叠中选择移除（`Remove`）选项以删除切片平面上方的所有内容。在堆栈顶部添加一个封封洞（`Cap Holes`）修改器。

解决方案

- 1. 点击修改器栈中 `Slice` 条目旁边的加号（`+`）符号进入切片平面（`Slice Plane`）子对象。

- 2. 在修改器栈中选择切片平面子对象级，然后点击主工具栏中的选择并移动（`Select and Move`）变换。

- 3. 拖动移动变换坐标轴的 `Z` 轴句柄来提高切片平面的高度。

- 4. 在修改面板（`Modify panel`）的 `Slice` 参数卷叠中，选择移除顶部（`Remove Top`）选项。切片平面上方的内容都会消失。

- 5. 点击修改器栈中的 `Slice`，或按下顶部行键上的 1（非数字小键盘），以退出切片平面子对象级。

- 6. 展开修改器列表（`Modifier List`）并应用封封洞修改器。你的场景应该与下面的茶壶相似，茶壶现在被封了面。

为 `VIZ` 对象克隆。你创建的克隆类型决定了修改器和参数更改是否也会影响克隆以及原始对象。副本是独立的对象，实例（`instances`）会保持所有克隆之间的更改，而引用（`references`）则保持引用栏以下的所有更改。

`进阶练习` 从上一个练习中选择茶壶并创建两个克隆：一个实例和一个引用。关闭实例的切片修改器，然后应用扭曲（`Twist`）修改器并增加对象中反映的扭曲量。选择引用克隆，并在堆栈顶部应用球体化（`Sphifier`）修改器。

解决方案

- 1. 使用移动变换通过按住 `Shift` 键拖动创建茶壶的克隆。

- 2. 在克隆选项（`Clone Options`）对话框中，选择实例（`Instance`）。

- 3. 再次克隆原始茶壶，但这次在克隆选项对话框中选择引用（`Reference`）。

- 4. 选择实例克隆，通过点击修改器栈中 `Slice` 条目旁的小图标来关闭切片修改器。所有克隆的切片修改器都已禁用。

- 5. 展开修改器栈并从可用修改器列表中选择 `Twist`。你可以多次按下 `T` 键以在列表中找到该修改器。

- 6. 在参数（`Parameters`）卷叠中，增加角度（`Angle`）值，直到茶壶显示出显著的扭曲。

- 7. 选择引用克隆，展开修改器列表并应用球体化修改器。下图显示了当对所有茶壶应用 115 度的扭曲，且仅将球体化修改器（设置为 50%）应用到引用克隆时的结果。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_874_0.png)

操作组。组提供了一种关联分离对象的方法，使其表现得像单个对象一样。组可以被打开，允许选择单个成员对象、对其炸散（`exploded`）或更改与其关联的成员。

`进阶练习` 为上一个练习中的每个茶壶创建一个克隆。选择这三个原始对象并将它们组成一个组。从组中移除球体化的茶壶，然后将剩余未球体化的茶壶添加到组中。

解决方案

- 1. 选择三个茶壶，按住 `Shift` 键并使用移动变换创建克隆。对于本次练习，选择什么克隆类型无关。

- 2. 使用选择对象（`Select Object`）工具或选择对象（`Select Objects`）对话框选择原始三个茶壶。

- 4. 选中组后，点击关闭（`Close`）。
