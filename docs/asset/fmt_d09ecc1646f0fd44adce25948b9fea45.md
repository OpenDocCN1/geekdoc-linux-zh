16. `setled -L -caps` 使锁定灯关闭。

17. 控制灯光的实用方法是脚本。使用你喜欢的编辑器创建一个名为 `blink` 的文件。在文件中添加这些行：

```
while [ true ];
  setled -L +caps
  sleep 1
  setled -L -caps
  sleep 1
done
```
