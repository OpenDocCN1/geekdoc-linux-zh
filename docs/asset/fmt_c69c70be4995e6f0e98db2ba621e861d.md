
一个彻底的实模式内存测试器。`Memtest86` 扫描你的 RAM 是否存在错误。该测试器独立于任何操作系统运行——它在启动时运行，因此可以测试你的*所有*内存。你可能想看一眼 `memtest`（位于 `sysutils` 包中），它允许在 Linux 内部测试内存，但这个并不是测试 RAM 的最佳选择。它曾是 `htools` 包的一部分，该包包含另一个针对 `mm` 机器优化的实模式内存测试器（但维护较少）。它可以输出由 `BadRAM` 内核补丁使用的坏区域列表，以便你仍然可以使用具有 0 或 2 个坏比特的旧 RAM。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

# menu

为此包的某些意图提供 `update-menus` 函数，该包的意图之一是简化 debian 中的菜单（如 `fwmf2`）。为此，`menu` 提了一个 "`update-menus`" 命令，它将运行所有已安装的菜单（通过 `/usr/lib/menu` 中提供的路径），并首先运行各种窗口–etc/menu– 前端，以为窗口管理器（或 `pdmenu`）创建启动项。用户和系统管理员可以轻松地基于用户或系统基础覆盖菜单文件。来自 Debian 3.0r0 APT
