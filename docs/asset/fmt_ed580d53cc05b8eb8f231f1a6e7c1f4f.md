
# 重要标志和选项

- `-9`：使用最好但最慢的压缩方法。
- `-f`：即使 `.gz` 文件已存在也强制压缩。
- `-K`：如果 `.Z` 文件比新的 `.gz` 文件小，则保留。
- `-t`：在删除原始 `.Z` 文件之前测试新的 `.gz` 文件。
