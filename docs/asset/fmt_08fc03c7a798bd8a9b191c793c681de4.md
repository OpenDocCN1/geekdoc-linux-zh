
# 水盾蝽总科（Corixoidea）

水盾蝽总科（Corixoidea）是一个总科，仅包含水盾蝽科（Corixidae），即水舟甲。水盾蝽没有单眼，具有独特的口器类型。水盾蝽以背面朝上的姿态游泳，利用桨状的中足和后足划水。卵具柄，幼虫有五个龄期。成虫有时会以大量个体飞向灯光。

## 半翅目（Hemiptera）

（注：此处原文重复使用了 Hemiptera 作为标题，可能是原文排版错误，实际上是在描述异翅目 Heteroptera 的特征）

昆虫纲（Insecta）中的一个目，有时被称为异翅目（Heteroptera）。这两个名称都指向前翅，前翅分化为加厚的基部区域和膜质的末端区域。这些是真正的蝽类（true bugs）。半翅目包括臭虫（bedbugs）、接吻虫（stink bugs）、植盲蝽（plant bugs）、网蝽（lace bugs）和划蝽（backswimmers）等常见昆虫。

真正的蝽类约有 2,500 个物种。它们在全球除南极洲外的所有大陆均有记录，并出现在大多数岛屿上。半翅目的体型范围从长度约 0.04–0.08 英寸（1–2 毫米）的小型水生和地栖形态，到 4 英寸（100 毫米）或更大的巨大水蝽。

在习性上，真正的蝽类从严格依赖单一宿主植物的植食性类型，到其他昆虫的广食性捕食者，甚至到蝙蝠的专性体外寄生虫，种类多样。许多物种作为植物害虫或疾病媒介具有重要的经济意义。

在蝎蝽总科（Nepidoidea）中，蝎蝽科（Nepidae），即水蝎，腹部尖端有一条长长的呼吸管，通过它直接从水面获取空气。其喙短而粗壮，用于吸食其他昆虫的体液，它们以此为食。负子蝽科（Belostomatidae），或称电光蝽（注：此处“electric-light bugs”可能为误译或特定俗名，通常指水蜈蚣），腹部尖端有短小的带状呼吸附肢。属 *Lethocerus*（大田鳖属）的巨大水蝽是鱼池中的害虫，它们会攻击鱼苗。如果在处理时不小心，它们可以造成痛苦的咬伤。

仰泳蝽总科（Notonectioidea）包括仰泳蝽科（Notonectidae），即仰泳蝽：它们以腹部朝上游泳，后足作为桨使用。呼吸由气泡辅助，通过将腹部尖端接触水面来获取空气。

微蝽科（Pleidae）和 Heteroptidae（小蝽科）（微蝽总科 Pleyoidea）的微小蝽类呈亚椭圆形，足部不适合划行。

爬行水蝽（水螽总科 Naucoroidae）有时与 Naucoridae（水螽科）和 Aphelocheiridae（扁蝽科/裂蝽科）分开。它们的身体呈亚椭圆形。呼吸通过气泡或鳃（glans，此处可能指某种呼吸结构）进行。在旧世界（古北区）属 *Aphelocheirus*（扁蝽属）中，前胸背板由一束超显微毛发组成，充当物理鳃；因此，这种蝽能够永久保持在水下。
