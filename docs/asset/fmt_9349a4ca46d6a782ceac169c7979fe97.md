# 锰

一种金属元素，`Mn`，原子量`54.38`。它是地壳中含量第十二的元素（约`0.1%`），以金属形式自然存在，也以碳酸锰（`MnCO3`）和包括二氧化锰（`MnO2`）在内的氧化物存在。

锰比周期表中的相邻元素更电正，因此具有活性。金属暴露在空气或水分中会发生表面氧化，特别是被切割时。

锰是多种生物系统（包括细菌、植物和动物）必需微元素。与周期表中的铁相比，锰在许多系统中的确切功能尚不清楚。从细菌、植物和动物中分离出的锰歧化酶分子量低，其功能是通过部分还原细胞中的`O2`来保护活组织免受活性氧（`O2−`）有害影响。

锰最重要的角色是植物和某些细菌光合作用水氧化的酶。这代表了地球上氧气的来源，并负责最常见生命形式的发展。

## 氧化锰

以锰（`Mn`）或羟氧离子（`OH-`）为主要成分的氧化锰。目前已鉴定出 20 多种氧化锰。它们可以根据矿物中锰的氧化态分类为四价锰（`Mn⁴⁺`）、三价锰（`Mn³⁺`）或二价锰（`Mn²⁺`）。

氧化锰的结构单元是由一个锰阳离子周围的六个氧原子构成的八面体（`MnO₆`）。这些八面体通过共享氧原子（棱）或顶点连接。在某些情况下，这些八面体相互连接形成单元链，在另一些情况下形成层或八面体簇。

氧化锰呈黑色且不透明，颜色取决于锰的氧化态，从锰（祖母绿）到光锰（紫色）。两者在暴露于空气时都会变成黑色。大多数氧化物的比密度为 4-5，硬度为 5-7。某些矿物的硬度非常高。

氧化锰在土壤中很常见，以块状或颗粒状存在。许多红树林社区在微细尺度上与其他锰或其他矿物紧密交织在一起。

化学成分为 `MnO(OH)` 的矿物，在八面体系统中结晶，具有深条纹的原始晶。

比密度为 4.3。光泽为金属光泽，颜色为黑色。在哈特山脉、英国康沃尔郡和美国密歇根州发现了细晶。

在美国，锰发现于佛罗里达州和夏威夷州。密歇根州是锰的最稀产地之一。

## 流形（数学）

具有某个整数 `$n$` 的 `$n$` 维图图空间的豪斯夫拓扑。`$n$` 是流形的维度。如果 `$M$` 是豪斯夫空间，`$h$` 是 `$M$` 上的映射 `$(U, h)$`，其中 `$U$` 到 `$n$` 维欧几里得空间 `$R^n$` 中的开集 `$V$` 是同胚的。`$n$` 维形是指覆盖 `$M$` 的所有图图 `$(U, \psi)$`。参见：拓扑（TOPOLOGY）。

在流形上加上适当的附加结构，就可以讨论实值函数的微分性或光滑性。在这种范围内，可以定义光滑映射以及引入的映射的微分。

“图幅”（charts）和“地图集”（atlases）这些术语源于地理学家观察地球表面的方法。流形通过二维球面 `$M = S^2$` 来描述。许多流形是连通的，因此基础拓扑由度量给出，有时不需要度量。
