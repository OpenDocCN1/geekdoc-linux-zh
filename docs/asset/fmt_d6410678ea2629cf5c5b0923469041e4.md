### 删除文本：

- 1. 使用阴影光标或键盘按键将插入点移动到你想要删除文本的位置（图 17）。
- 2. 按键盘上的 `Backspace` 键删除插入点右侧的字符。
  或
- 按键盘上的 `Delete` 键删除插入点左侧的字符。

### 提示

当文本被删除时，插入点右侧的任何文本都会自动向左移动以关闭被删除字符留下的空间。自动换行会自动调整文本行。

### 使用叠印创建自定义符号

使用键盘，您可以创建上一页访问的符号集未包含的字符。如果您想创建自定义字符，您应该知道有些打印机不具备打印它们的能力。

#### 创建自定义符号：

1. 在文档中将插入点定位到希望自定义符号出现的位置。
2. 从“格式”菜单的“排版”子菜单中选择“叠印”（图 22）。将打开“叠印”对话框（图 23）。
3. 在“字符”文本框中，键入您希望以叠印方式打印的字符。字符之间不要添加空格。此外，字符顺序无关紧要。
4. 要为自定义符号添加格式属性：
   A. 单击“字符”文本框右侧带左向箭头的按钮（图 24）。
   B. 从下拉列表中选择一个格式属性。
5. 单击“确定”。您在文本框中输入的字符将以叠印方式打印在文档中（图 21）。

### 提示

要在“叠印”对话框的“字符”文本框中插入符号，请在“叠印”对话框打开时按键盘上的 `Ctrl+W`。将出现“符号”对话框，您可以选择并插入所需的符号。

### X Clipboard

X Clipboard 由所有 X Windows 程序使用。 （有关 X Windows 程序的更多信息，请参见第 20 页。）X Clipboard 是内存中的一个区域，用于保存剪切或复制的文本或图形以供以后使用。

#### 粘贴文本：

- 1. 复制或剪切要粘贴的文本。
- 2. 将插入点移动到要粘贴文本的位置。
- 3. 从编辑菜单中选择粘贴（图 35）。
