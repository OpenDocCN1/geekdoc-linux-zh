| 展示作品权 | 是 | 是 |

Linux 分发使用的 `GPL` 可能是其中最重要的一部分。它旨在保护自由。它的设计初衷是确保一个病毒能够以任何效率传播的操作系统。然而，如果你从版权所有者处获得许可，你可以在商业程序中整合 `GPL` 软件。`GPL` 绝不比一个“典型的”专有许可证更具限制性或强迫性。`GPL` 是一种授予接收者原本不具备但又赠出的权利的许可证。违反 `GPL` 的人被排除在 `GPL` 使用之外。

通常，版权规定了 5 权利：复制作品、制作衍生作品、分发作品、表演作品和展示作品。

这是一张比较 Linux 与 MS Windows 许可证的表格（由一位 RedHat 律师编写，`http://www.grokial.net/article.php?query=200312319027900`）

## 给犹豫不决者（Linux 的优势）

- 如果你只有一个小小的律师在追你，那你就就像个电脑黑客（别担心，很可能没人会追你）。

- MS Windows 试图成为一个“公约数最小”的操作系统（无论好坏），而 Linux 是为了那些更高级、对功能有渴求的计算机用户设计的（在这一点上如此）。

- MS Windows 构建在 DOS 之上；Linux 基于 UNIX。MS Windows 图形用户界面 (GUI) 基于微软拥有的规范。Linux GUI 则基于行业标准的透明 X 窗口系统。

- Linux 在网络功能、开发平台、数据处理能力以及作为重要的工作站方面胜于 Windows。Windows 桌面外观更精美，通用应用程序更流畅，并且为孩子们提供了更多游戏（但这些并不更好——Linux 游戏应该更加复杂）。

- Linux 的功能远比你想象的丰富。在互联网上听过：“加州大学出的两个大产品：UNIX 和 LSD。我不认为这是巧合。”MS Windows 更加简单。

## 1.7 我不相信自由软件等等

那么你相信互联网吗？互联网和 Linux 共享底层的理念并有共同的根源。你还记得几年前对互联网的怀疑吗？那些永无止止的、看似不可行的争论，认为自由互联网是不可能存在的？“到底是谁在为此买单呢？”

事实很简单。合作和善意将造及许多人：你的获益并不是我的损失。互联网正在运行并快速扩张。Linux 也是如此。

这里有一位 IBM 高管的观点：“我们之所以对 Linux 如此兴奋，是因为我们相信 Linux 能为应用程序做的事情，就像互联网为网络做的那样”（`http://linux.com/news.story.php?tsn=2000-08-17-004-PS-EL`）。IBM 刚刚（2002年）花费了 10 亿美元，在其所有的硬件平台上运行了 Linux（主机、工作站、PC、笔记本电脑）。

我们还可以补充一点，Linux 对操作系统起的作用，就像 IBM 的开放 PC 规范对计算机硬件起的作用一样。

## 1.9 我需要保修和安全。对于商业软件，如果出问题了我可以找到负责人。

别指望诉讼。我的 MS Windows NT 机器每天都会出问题，而且法院没有任何赔偿。阅读我们的 Windows 许可协议就会发现，它完全不保证运行。尝试使用软件将浪费你的钱。Linux 也不提供任何保证，尽管它比任何版本的 MS Windows 都安全得多（假设安装了功能）。如果你对安全敏感，可以使用公司构建的高安全性工具，这些公司依赖源代码的可用性来设计和测试其安全功能（例如，德国的 Kryptonym 提供高安全性防火墙）。MS Windows 中实施的‘隐蔽式安全’已被反复证明是一种天幼稚的方法。

## 1.11 我需要 MS Windows 阅读 Word 文档

在企业环境中，你可能没有多少选择——他们通过大量生产不可移植的模板、基于视觉的网页以及许多其他 Office“工具”将你锁定了。也许对于专有软件，一个更恰当的名称应该是“锁定软件”。在小型环境中，你可以使用 OpenOffice.org，它可以在 Linux、Windows、MS、Mac、Solaris（以及更多）系统）上运行，并具有文件级兼容性。它可以免费下载和安装（没有任何限制），因此没有人真的应该抱怨这种格式（尽管仍有人这样做）。只需确保 OpenOffice 可以导入具有合理性的 MS Word 和 Excel 文档即可。OpenOffice 的文件格式从根本上优于微软（而且它是非专有的）。OpenOffice 几乎可以做 MS Office 能做的任何事情，甚至更多。取决于你是谁，易用性程度不异，从“难用 50%”到“易用 20%”（经验丰富的 MS 用户样本）。非常复杂的文档以 `PDF` 格式传输，你可以随时生成它们。

所以，你可能不再需要 MS Office 了。在以下地址下载适用于 Windows 和/或 Linux 的免费版本：`http://www.openoffice.org/`

最新的营销语录：“等等，不需要 OpenOffice。微软 `已经在` 开发一种文件格式了，微软将扩展该文件格式使其变得甚至 `更好`。”嗯，我们不需要更好的格式。我们需要一个开放标准的文件格式。
