
# 同步辐射源

可以将特殊磁体插入环形弯曲磁体之间的直线段中，以产生具有扩展光谱范围或比环形弯曲磁体可能的更高通量和亮度的光束。这些称为 `Wig` 磁体和 `Undulator`（振荡器）磁体的装置，利用周期性横向磁场产生电子束的横向振荡，而不产生净偏转或位移。它们比环形弯曲磁体在通量和亮度方面提高了另一个数量级或更多，再次开辟了新的研究机会。然而，其潜力远远超过其在第一代和第二代源中的性能水平。

第三代源是具有许多直线段用于 `Wig` 和 `Und` 插入装置源的存储环，并且具有较小的横向尺寸和较小的流注电子束角发散了。横向尺寸和发散度的乘积称为发射度。电子束发射度越低，光子束亮度和相干功率水平越高。具有较小的横向发射度和能够容纳更长 `Undulator` 的直线段，第三代环比早期源提供了两个或更多数量级的更高亮度和相干功率水平。

这些源非凡亮度的一个后果是 X 射线束部分相干。通过对光束进行孔径限制，可以获得完全相干光束，但以牺牲通量为代价。尽管如此，仍保留足够的通量来探索相干 X 射线束的使用和应用。参见 `COHERENCE`（相干性）。

多个第三代环正在运行。低能（通常 1–2 GeV）第三代环（参见插图）旨在优化产生真空紫外（VUV）和软 X 射线光谱范围内的高亮度辐射，光子能量高达约 2–3 keV。高能环（通常 6–8 GeV）旨在产生能量为 10–20 keV 及以上的硬 X 射线。

以低能量做圆周运动的电子（速度远小于光速）产生的辐射较弱且方向性不强。在相对论能（速度接近光速）时，辐射功率显著增加，发射图案向前折叠成圆锥，其以弧度为单位的半开角近似为 $\gamma^{-1} = mc^2/E$，其中 `m` 是电子的静止质量能量（0.51 MeV），`E` 是总能量。因此，在约 1 GeV 的电子能量下，产生的强辐射大部分被限制在一个瞬时开角约为 1 mrad（0.06°）的前进圆锥内。在更高的电子能量下，这个圆锥甚至更小。产生的更多辐射加上天然准直赋予了同步辐射固有的高亮度。电子束的小横截面积（在第三代环中低至 0.01 mm²）进一步增强了亮度。 [A.B.; D.M.; G.She.; H.Win.]

# Sincarida（无甲目）

一种独特的鳃足类甲壳动物上目，特别以完全缺乏头胸甲或头胸甲盾而闻名。承认两个目，`Anaspidae`（无甲虫目）和 `Bathynellidae`（穴海虫目）。`Stygocoridae` 曾被视为一个独立的目，但现在被分配为 `Anaspidae` 内部的科级。

`Sincarid` 的身体构造简单，由头甲（头部和有时一个胸节）、由七个或八个体节组成的胸部，以及由六个体节和尾节或由五个体节和尾肢（与尾节融合）组成的腹部组成。具有叠加光学系统的眼镜可能是柄状、无柄状，有时甚至缺失。有六个到八个胸附肢（胸足），通常有两个到五个腹附肢（腹足），以及尾足。性别分离。幼体孵化为不成熟的成体，在成熟之前经过几次蜕皮。

现存的 `Sincarid` 特别适应于淡水，通常是间隙环境。虽然 `Anaspididae` 仅限于南半球（澳大利亚、塔斯马尼亚、新西兰、南美洲），但 `Bathynellid` 在除南极洲外的全球各地都有发现。参见 `BATHYNELLIDAE`；`CRUSTACEA`（甲壳类）；`MALACOSTRACA`（软甲纲）。 [P.A.M.C.]

# Synchronization（同步）

维持一个操作与另一个操作同步的过程。最常见的例子是电钟，其电机以电站中交流发电机速度的整数倍或亚倍数旋转。在电视中，同步是必不可少的，以便接收器图像管中的电子束在每一瞬间都位于屏幕上的确切位置，就像发射器电视摄像管中的束一样。参见 `TELEVISION`（电视）。 [J.Mar.]

# Synchronous converter（同步换流器）

一种用于将交流（ac）转换为直流（dc）或反之的同步机器。交流至直流换流器已被汞弧整流器取代（出于效率、低维护成本和较少故障的原因）或由电机-发电机组取代。换流器不再制造，但仍有一些换流器在使用。参见 `DIRECT-CURRENT GENERATOR`（直流发电机）；`SYNCHRONOUS MOTOR`（同步电动机）。 [L.V.B.]

# Synchronous motor（同步电动机）

一种以固定同步速度运行的交流（ac）电动机，该速度与所施加交流电源的频率成正比。同步机器可以仅根据其所施加的轴扭矩（是正、负还是零）及其励磁作为发电机、电动机或电容器运行。在针对这些角色中任意一种角色的机器的理论、设计或构造上没有根本区别，尽管每种角色的某些设计特征都被强调。在使用中，机器可能随时改变其角色。出于这些原因，最好不要为同步发电机、电动机和电容器建立单独的理论。最好建立一种适用于所有三种的一般理论，其中它们之间的区别仅仅是电流方向和扭矩角符号的差异。参见 `ALTERNATING-CURRENT GENERATOR`（交流发电机）；`ALTERNATING-CURRENT MOTOR`（交流电动机）；`SYNCHRONOUS CAPACITOR`（同步电容器）。有关特殊类型的同步电动机，参见 `HYSTERESIS MOTOR`（磁滞电机）；`RELUCTANCE MOTOR`（磁阻电动机）。 [R.T.S.]

# Synchroscope（同步指示器）

一种用于指示两个交流（ac）发电机或其他交流电压源是否在时间相位上相互同步的仪器。其主要用途在于电力供应网络中，如果两个发电机要并联运行或要将附加发电机连接到电网，则发电机电压必须在幅值、频率和相位上匹配。

新的电站通常配备自动同步发电机的装置。但许多传统类型的同步指示器仍在使用，并可能在许多年内保持这种状态。

# Syncline（向斜）

在其最简单的形式中，向斜是一种地质构造，表现为原本水平的岩层折叠成一个同步弯曲、凹向上方的轮廓几何形状（图 a）。向斜在褶皱序列中最老岩层的方向上是凸的，在最年轻岩层的方向上是凹的。虽然通常是直立的，但向斜可能是倒转的、平卧的或倒置的（图 d）。向斜出现在所有尺寸中，从微观到区域尺度。褶皱形式可以从平滑弯曲（图 a）到尖锐角度（图 b）。测量为向斜两翼结合处角度的向斜紧密度限制，可以非常平缓，以至于褶皱几乎难以察觉，也可以非常紧密，使得两翼几乎相互平行（图 c）。褶皱轴的取向是水平到浅倾，但向斜可以倾斜到垂直。

# Synthetic aperture radar (SAR)（合成孔径雷达）

机载或星载雷达，使用特殊的信号处理技术在穿越相当大的飞行路径时产生地球（或其他物体）表面的高分辨率图像。该技术有点像使用一个与穿越的飞行路径一样宽的“合成孔径”天线，这将形成一个非常窄的波束。合成孔径雷达在军事和民用遥感应用中都非常有价值，无论黑暗还是阻碍其他方法的天气条件，都能提供地表映射。

分辨率是清晰区分多个物体的质量。在雷达成像中，期望在距离维和方位维都具有精细分辨率。在使用脉冲的雷达中，通过使用宽带宽脉冲（相当于非常窄的脉冲）来实现距离分辨率，使雷达能够感知距离非常接近的物体的独立回波。这种技术称为脉冲压缩；在现代雷达中，轻松实现几纳秒（例如，5 ns ≈ 5 × 10⁻⁹ s 等于大约 0.75 m 或 2.5 ft 的分辨率）的分辨率。

方位分辨率更难以实现。通常，雷达主波束的宽度决定了方位或横向分辨率。例如，在 185 km（100 海里）的距离处，只有当目标在侧向分离超过 100 m（330 ft）时，3° 的波束宽度才能分辨目标，这对于高质量成像来说远远不够。

然而，表面物体在机载雷达飞过时会多普勒频移。在侧视雷达中（参见插图），即使远处的物体实际上也会从距离略微减小变为距离增加，产生多普勒时间函数。如果雷达能够维持高质量的多普勒处理，只要波束的“足迹”照亮场景，这些多普勒历史将揭示物体的横向位置。事实上，如果可以维持这种处理，可能的方位分辨率是实际使用的光学天线波束物理宽度的一半，即几厘米。此外，这种分辨率与距离无关，这与传统雷达中基于角度的横向分辨率截然不同。参见 `DOPPLER EFFECT`（多普勒效应）。

许多合成孔径雷达使用除固定侧视波束外的其他方法。聚焦雷达操纵光束以延长照明时间或以其他角度照亮指定场景。原理保持不变：

在方位向和侧摆向维度上均具有精细的分辨率（分别通过脉冲压缩和多普勒处理实现），使得成像能够使用具有极高分辨率的图像单元（像素）。如今，许多合成孔径雷达能够实现小于 1 m [3 ft] 的方形像素。[R.TH.]

## 合成燃料

一种气态、液态或固态燃料，自然界中并不存在；也称为合成燃料（synguel）。合成燃料可由煤炭、油页岩或油砂制成。该类别包括各种煤气，如替代天然气和合成气。参见煤炭；油砂；油页岩。
