
你可以使用的对象效果是有限制的。例如，如果使用`h`或`l`键配合的对象超出了光标所在行的开头或末尾，光标将停留在行的开头或末尾，并会发出“哔”声。

还有其他与`h`和`k`键类似的命令。它们的功能在表 3.2 中描述。熟悉它们工作方式最好的方法就是练习使用。最常用的移动键如表 3.2 所示。

**表 3.2. 常用的移动键。**

| 键位(s) | 移动 |
| :--- | :--- |
| `h` | 向左移动一个字符 |
| `j` | 向下一行 |
| `k` | 向上一行 |
| `l` | 向右移动一个字符 |
| `w`, `W` | 前移动一个单词 (`W` 忽略标点) |
| `b`, `B` | 向后移动一个单词 (`B` 忽略标点) |
| `$` | 到行尾 |
| `^` | 到行第一个非空格字符 |
| `0` | 到行首 |
| `G` | 回到缓冲区顶部 |
| `nG` | 其中 `n` 是整数，跳转到第 `n` 行 |

单词移动命令的大小写版本之间有细微的差别。小写版本将大多数标点符号视为“单词”。大写版本则会跳过它们，就像它们不存在一样。

你应该练习在示例文本中移动，使用之前描述的命令。虽然起初看起来可能很笨拙，但随着手指的训练，你很快就会适应它们。

## 最重要的编辑程序

让我们来看一些简单且最常用的编辑程序：

### 修改文本

没有人是完美的。所以你早晚会想要更改你创建的某些文本。事实上，在修改现有文本上花费的时间可能比输入全新的文本要多得多。因此，你需要一些简单的方法来更改文本。本节将展示如何做到这一点。

`x`--删除字符 删除文本最简单的方法是使用 `x` 命令。该命令会删除光标所处的字符，并将行上剩余字符向左移动一个字符。你可以认为是用 `x` 删掉你想要去掉的文本。如果删除的字符是行的最后一个字符，光标将向左移动一个字符，以避免落在不存在的文本上。如果行上没有更多文本，会发出哔哔声。

`d`--删除对象 删除命令需要一个要操作的文本对象。文本对象（简称为对象）是指使用移动命令时会经过的文本块。例如，`w` 将移动到下一个单词。因此 `dw` 将删除到下一个单词的开头。`5w` 将移动到第五单词的开头（记住，`w` 命令将标点符号视为“单词”）。因此，`5dw`（或者用 `d5w`）将删除到第五单词的开头。这两种形式都有效，因为 `5dw` 的意思是“执行五删除单词”；`d5w` 的意思是“删除五个单词”。

`dd`--删除行 `d` 命令最常用的形式之一是特殊版本 `dd`，它会删除整整行。和之前一样，`5dd` 会删除五行。

`D`--大删除 大写形式 `D` 用于从光标位置删除到行尾。它的动作与 `d$` 相同。

`u`--撤销 在学习了如何删除之后，我第一个想知道的是是否有撤销功能！有的。它通过 `u` 命令自然地调用。`u` 命令将撤销对文件的最近更改（不仅是删除，还包括任何编辑）。光标不需要位于最近更改的位置。遗憾的是，标准的 `vi` 只有一个撤销层级。一旦进行了第二次更改，你就无法撤销第一次了。如果你再次按下 `u`，它将“撤销撤销”，这有时被称为“重做”。反复按下 `u` 键将在两个版本之间来回切换文本。

`U`--大撤销 `u` 命令的“大哥” `U` 命令将撤销光标所在行中、自光标上次移动到该行以来所进行的所有更改。当光标离开某行后，`U` 命令将不再对该行已进行的编辑生效。

`.`--重复 重复上一次的编辑命令。

### 命令是如何形成的

到目前，你可能已经注意到 `vi` 命令的结构有一种模式。首先，命令是（某种程度上）助记的，这意味着命令的字母应该能提醒你正在执行的功能。其次，许多命令都有大写版本，它们通常是基础小写形式的变体。第三，所有命令都可以乘以一个重复计数，作为前缀输入。

查看命令如何形成的最简单方法如表 3.3 所示。你可以看到多种方法组合命令元素来获得你想要的结果。要重复命令，只需在命令本身之前输入重复计数，如之前的光标移动和删除示例所示。

**表 3.3. `vi` 命令的形成。**

| `vi` 命令的通用形式 |
| :--- |
| `{count}{command}{object}` 所有部分都是可选的（见下文）。 |
| `{count}` 如果存在，则导致命令执行指定的次数。 |
| `{command}` 如果存在，则触发某些动作。 |
| `{object}` 表示受影响的内容。 |

**表 3.4. 组合命令的示例。**

| 命令 | 结果 |
| :--- | :--- |
| `h` | 光标向左移动字符 |
| `dd` | 删除一行 |
| `w` | 光标向前移动单词 |
| `dw` | 删除一个单词 |

你现在拥有了让你入门的基础编辑命令。你可能希望开始练习这些命令。通过额外的命令，你可以让工作变得更快、更简单。计算机的目的是让工作变得轻松，所以为什么不利用 `vi` 的力量让计算机做它擅长的事呢！

### 其他有用命令

`a`--追加 `a` 命令用于追加文本。它与 `i` 命令几乎完全相同。细微的区别是 `i` 命令在光标位置插入文本；`a` 命令在光标位置之后立即追加文本。为了说明这种差异，我们将分别使用这两个命令向示例文本中插入 "able to"。例如，假设你的屏幕如下，光标位于 "recognize" 的 "r" 上：

```
If wise, a recognize changing
```

输入以下内容以使用 `i` 命令插入文本：

`iis able to`（单词 "to" 和 Esc 键之间有一个空格。）插入 "is able to" 后，你的屏幕应该像这样：

```
If wise, a commander is able to-recognize changing
```

现在通过撤销恢复文本。按下 `u` 键。（如果文本中插入了 "u"，说明你在第一次插入后忘记按 Esc 了。）现在尝试 `a` 命令之前，用 `h` 键将光标向后移动一个字符。你的屏幕现在应该是：

```
If wise, a commander_recognize changing
```

输入以下内容：

`ais able to`（Esc 键。）

如你所见，`i` 和 `a` 命令的操作区别在于插入起始的位置。

- `A`--行尾追加 (Big Append) 类似于 `a` 命令，但它从行尾开始开始追加。

**提示：** 你可以使用带有重复计数的插入或追加命令来插入一段重复的字符串序列。例如，要插入 78 个星号，你可以输入 `78i\*Esc`。

- `c`--修改对象 (Change Object) 要修改文本，可以使用 `c` 命令。`c` 命令接受一个对象来指示将要修改的文本块。`c` 命令的作用类似于先执行 `d` 命令后执行 `i` 命令。也就是说，它首先执行由 `d` 命令对相同对象执行的删除操作，然后允许插入任意长度的文本（包括换行符），直到按下 Escape 键。这种行为在以下情况下特别有用：当你想修改从光标位置到行首（使用 `c0`）或到行尾（使用 `c$`）的文本时。

- `cc`--修改行 (Change Line) 同样地，`cc` 命令的作用类似于先执行 `dd` 命令后执行 `i` 命令。它删除光标所在的行，然后插入在按下 Escape 键之前输入的所有按键。

- `C`--修改到行尾 (Big Change) `C` 命令的作用类似于先执行 `D` 命令后执行 `i` 命令；它删除从光标位置到行尾的文本；然后进入插入模式。`C` 命令的作用与 `c$` 相同。

- `r`--替换字符 (Replace Character) `r` 命令将替换光标所在处的单个字符。按下 `r` 键后，屏幕上不会有任何变化。输入的下一个键将替换光标位置的字符，然后 `vi` 返回到命令模式。这是一种仅更改单个字符的简单方法。
