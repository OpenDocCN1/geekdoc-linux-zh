## harden

“`harden`”（加固）一词意味着在计算机周围建立屏障以保护其免受入侵者的侵害。为了加固系统，你应该遵循以下技术：用最新的安全补丁修补操作系统。例如，当“死亡之 ping”攻击来临时，许多人需要修补他们的 TCP/IP 栈以防御它。用最新的安全补丁修补暴露的服务。例如，许多邮件服务器容易受到缓冲区溢出攻击的影响。这些漏洞通常在黑客社区发布后几天内就会修复。你需要定期用最新补丁检查软件。为了加固你的软件，供应商包含了默认账户、密码和示例。然而，这些可以被黑客轻易利用。你**必须**阅读针对特定操作系统软件包（尤其是 Web 服务器）的安全指南，并移除这些默认值/示例，或者例如，它们**将**被禁用。对于 Microsoft IIS 4，Web 服务器可能会通过微小的溢出或 RDO 漏洞被攻击，而网站管理员并（或不）知道该如何关闭它们。移除所有不必要的服务。例如，大多数 Sun Solaris 系统都可以通过加固 RPC 服务来防止攻击。Hacking-Lexicon http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
