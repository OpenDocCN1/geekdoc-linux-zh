# `expand`, `unexpand` — 将制表符转换为空格字符以及反之

# 语法

```
/usr/bin/expand [-t tablist] [file...]
/usr/bin/expand [-tabstop] [-tab1,tab2,...,tabn] [file...]
/usr/bin/unexpand [-a] [-t tablist] [file]
```

## 描述

`expand` 将文件（或标准输入）复制到标准输出，并将制表符扩展为空格字符。退格字符在输出中保留，并减少用于 Tab 计算的列数。`expand` 适用于处理包含字符的文件（在排序、查看特定列等之前）。

`unexpand` 将文件（或标准输入）复制到标准输出，并将数据放回制表符。默认情况下，只有前导空格和制表符被转换为制表符字符串。你可以通过 `-a` 选项覆盖默认行为。

## 选项

`expand` 命令的选项列如下。

- `-t tablist` 指定制表位。参数 `tablist` 必须由单个正十进制整数或多个由空白字符或逗号分隔并按升序排列的正十进制整数组成。如果你指定了一个数字，则制表符将按照 `tablist` 列位置间隔设置，而不是默认的 8。如果你指定了多个数字，则制表符设置在这些特定的列位置。

每个制表位位置 `$N$` 必须是大于 0 的整数值，且列表必须严格升序排列。从输出行的行开始，制表到位置 `$N$` 将输出该行第 `($N+1)` 列位置的下一个字符。

如果 `expand` 处理位于超出多个制表位列表中最后一个指定位置的制表符，则该制表符在输出中被替换为空格字符。

- `-tabstop` 设置制表符之间的间隔为 `tabstop`，其中 `tabstop` 是单个整数，而不是默认的 8。

- `-tab1,tab2,...,tabn` 将制表符设置在 `-tab1, tab2,...,tabn` 指定的列上。

`unexpand` 命令的选项列如下。

- `-a` 当替换两个或多个空格字符序列可以产生更小的输出文件时，插入制表符。

- `-t tablist` 指定制表位。`tablist` 必须是单个参数，由单个正十进制整数或多个由空白字符或逗号分隔并升序排列的正十进制整数组成。如果你指定了一个数字，制表符将按照 `tablist` 列位置间隔，而不是默认的 8。如果你指定了多个数字，则制表符设置在这些特定的列位置。

每个制表位位置 `$N$` 必须是大于 0 的整数值，且列表必须严格升序排列。从输出行的行开始，制表到位置 `$N$` 将输出该行第 `($N+1)` 列位置的下一个字符。当你不指定 `-t` 选项时，默认等于指定 `-t 8`（与 `-a` 的交互除外）。

对于超出多个制表位列表中最后一个位置的字符，不会发生空格到制表符的转换。
