# marshal

`marshal` 模块用于以一种“未文档”的 Python 特有数据格式序列化 Python 对象。`marshal` 与 `pickle` 和 `shelve` 模块类似，但功能较弱，且仅用于简单对象。它不应用于实现持久化对象（请使用 `pickle`）。然而，对于简单类型，`marshal` 模块是保存和加载数据的快速方法。

```python
dump(value, file [, version])
```

将对象写入打开的对象文件 `file`。如果 `value` 是不支持的类型，将抛出 `ValueError` 异常。`version` 是一个指定数据格式的整数。默认输出格式在 `marshal.version` 中，目前设置为 2。版本 0 是早期版本 Python 使用的旧格式。

```python
dumps(value [, version])
```

返回 `dump()` 函数写入的字符串。如果 `value` 是不支持的类型，将抛出 `ValueError` 异常。`version` 与上述相同。

```python
load(file)
```

从打开的对象文件 `file` 中读取并返回值。如果没有读取到有效值，将抛出 `EOFError`、`ValueError` 或 `TypeError` 异常。输入数据的格式会自动检测。

```python
loads(string)
```

从字符串 `string` 中读取并返回值。

## Notes

- 数据存储在与架构无关的二进制格式中。
- 支持 `None`、整数、长整数、浮点数、复数、字符串、Unicode 字符串、元组、列表、字典和代码对象。列表、元组和字典只能包含支持的对象。不支持列表、元组和字典中的类实例和递归引用。
- 如果内置整数类型精度不够，整数可能会被提升为长整数——例如，如果 `marshal` 数据包含一个 64 位整数，而在 32 位机器上读取该数据。
- `marshal` 的设计初衷不是为了防止错误或恶意构造的数据，不应用于从不可信源处反序列化数据。
- `marshal` 速度比 `pickle` 快得多，但灵活性较低。

# pickle

`pickle` 模块用于将 Python 对象序列化为字节流，以便在文件中、跨网络传输或存储在数据库中。这个过程被称为腌化（pickling）、序列化（serializing）、标记（marshalling）或扁平化（flattening）。生成的字节流也可以通过反序列化（unpickling）过程转换回一系列 Python 对象。

## pickle 227

使用以下函数将对象转换为字节流。

```python
dump(object, file [, protocol ]])
```

将对象的 pickle 化表示写入文件对象 `file`。`protocol` 指定数据的输出格式。协议 0（默认）是一种基于文本的格式，与早期版本的 Python 向后兼容。协议 1 是二进制协议，与早期的 Python 版本兼容。协议 2 是较新的协议，为类和实例提供了更高效的腌化。协议 3 被 Python 3 使用，且不向后兼容。如果 `protocol` 为负数，将选择最现代的输出。变量 `pickle.HIGHEST_PROTOCOL` 包含最高可用协议。如果 `object` 不支持腌化，将抛出 `pickle.PickError`。

```python
dumps(object [, protocol])
```

与 `dump()` 相同，但返回一个包含 pickle 化数据的字符串。

示例展示了如何使用这些函数将对象保存到文件中：

```python
f = open('myfile', 'wb')
ppickle.dump(x, f)
ppickle.dump(y, f)
... dump more objects...
f.close()
```
