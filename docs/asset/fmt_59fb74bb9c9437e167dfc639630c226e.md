# 浮点数学与 bc 工具

你是否曾经有在 shell 脚本中进行一些浮点运算的需求？如果答案是肯定的，那么你幸运了。在 Unix 机器上有一个名为 `bc` 的工具，它是任意精度算术语言的解释器。`bc` 命令是一个提供任意精度运算的活动程序。你可以在命令行中输入 `bc` 来启动交互会话。进入会话后，你可以像使用计算器一样输入大多数复杂的算术表达式。`bc` 工具的功能我在本章中涵盖得多，因此我们将范围限制在 shell 脚本中的简单浮点运算。

在本章中，我们将创建对数字列表进行加、减、乘、除和求平均值的 shell 脚本。对于这些脚本中的每一个，用户都可以指定 `scale`（精度），即小数点右边的有效位数。如果没有指定 `scale`，则结果将给出整数值。因为 `bc` 工具是一个交互式程序，我们将使用“在此文档”（here document）为交互式 `bc` 程序提供输入。我们将在本章详细介绍使用在此文档。

# 语法

现在你已经知道了这一套路：在创建 shell 脚本之前，我们需要知道语法。根据我们正在执行的操作，我们需要创建一个数学语句呈现给 `bc` 以便文档工作。在此文档的作用类似于其他编程语言中的标签。我们在本章中使用的语法格式如下：

```bash
VARIABLE=$(bc <<LABEL)
scale=$SCALE
($MATH_STATEMENT)
LABEL
```

在此文档的工作原理是在 `bc` 命令之后添加某个标签（在本例中为 `LABEL`）。这个 `LABEL` 是输入交互式程序的双重定向 `bc <<LABEL`。从这个开始标签到再次遇到该标签之间的所有内容都将作为 `bc` 程序的输入。通过这样做，我们正在实现交互式程序的自动化。我们可以使用 `echo`、`print` 和 `printf` 来打印数学语句的所有数据，并将输出传递给 `bc`。它的工作方式如下所示：

```bash
VARIABLE=$(print 'scale = 10; 10448/33215' | bc)
```

或者

```bash
VARIABLE=$(print 'scale = $SCALE; ($MATH_STATEMENT)' | bc)
```

在任何一种情况下，我们都在实现交互式程序的自动化。这就是在此文档的目的。
