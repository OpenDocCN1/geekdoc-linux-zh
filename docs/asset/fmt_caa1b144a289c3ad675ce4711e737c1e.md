## 1.18 Linux 可能会被发现违反了某人的“知识产权”（`IP`）

这是一个严肃且及时的问题（`2003年7月`）。最强大的 Linux 对手（微软）在他们的内部备忘录（已泄露给媒体）中表示，他们应该尝试通过法律途径处理 Linux（对知识产权的讨论需要与具体的行动挂钩”）。微软关于如何抹杀 Linux 的系列有趣（且“令人恐惧”）的蓝图已经泄露并以所谓的“万圣节文档”（`http://www.opensource.org/halloween/`）的形式发布。

有人说，由于政治压力，Linux 有可能在美国范围内消失。

Linux 开发者并不是抄袭者或小偷。他们每天都产生数千行代码。Linux 许可协议基于对“知识产权”的尊重，即作者对其创作进行分发的排他性权利。尽管如此，代码被挪用到 Linux 中的情况确实发生。考虑到 `GNU/Linux` 发行版中代码的数量和复杂度以及开发速度，这种情况迟早会发生。不诚实的开发者可能会在交付时“窃取”他人的代码并将其提交到任何公共的 Linux 相关项目，假装代码是自己的。这种 `IP` 问题不仅限于 Linux，也存在挪用到闭源软件包中（例如，在微软身上就发生过），而且无疑会再次发生。

至于代码挪用，“开源”与“专有、闭源软件”之间的主要区别在于，挪用行为在差异中很容易被检测，而在后者中几乎不可能。任何所有者保护其 `IP` 并报告（自愿的）侵权行为的义务都可以得到及时补救，并将潜在损失降至最低。

Linux 开发者并不疏忽。他们继续提交所有 Linux 源代码供公开审查和评论，以检测并防止任何违规行为。组织良好的存档得到了维护。Linux 的开放开发方法已被科学界采用，对于保护他人权利，这可能比任何闭源软件公司可以想象的实现的 `IP` 控制系统都更勤勉。因此，知识产权的挪用可以理所应当地被称为“行业内顶级水平”而非“最佳”。

Linux 拥有卓越的 `IP` 记录。当然，它没有被挪用代码的记录。如果从未发现过，我使用 Linux 在法律上是安全的吗？我觉得，一旦发生代码挪用到 Linux 的情况，任何侵权代码都将立即从 Linux 中被清除，并且“清洁”版本将供我使用。Linux 社区的一个目标一直是产生产生不含任何专有代码的代码。
