
## DSP 或 `DateSeparator`

指定 SQL 语句中日期字面量中的日期分隔符。除非 `DateFormat` 设置为 `0` ("*JUL")、`1` ("*MDY")、`2` ("*DMY") 或 `3` ("*YMD")，否则此属性无效。

**选择**：
- `0` = `/` (斜杠)
- `1` = `-` (连字符)
- `2` = `.` (点号)
- `3` = `,` (逗号)
- `4` = ` ` (空格)

**默认值**：`1`

## `DEC` 或 `Decimal`

指定 SQL 语句中数字字面量使用的数字分隔符。

**选择**：
- `0` = `.` (点号)
- `1` = `,` (逗号)

**默认值**：`0`

## `TFT` 或 `TimeFormat`

指定 SQL 语句中时间字面量使用的时间格式。

**选择**：
- `0` = `hh:mm` (*HMS)
- `1` = `hh:mm AM/PM` (*USA)
- `2` = `hh.mm.ss` (*ISO)
- `3` = `hh.mm.ss` (*EUR)
- `4` = `hh.mm.ss` (*JIS)

**默认值**：无

## `TSP` 或 `TimeSeparator`

指定 SQL 语句中时间字面量中的时间分隔符。除非 "time format" 属性设置为 "jms"，否则此属性无效。

**选择**：
- `0` = `:` (冒号)
- `1` = `.` (点号)
- `2` = `,` (逗号)
- `3` = ` ` (空格)

**默认值**：`0`
