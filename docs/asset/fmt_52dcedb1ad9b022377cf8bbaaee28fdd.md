
# 柯伊带

柯伊带是太阳系中位于海王星轨道之外的广阔冰冷体区域。在1992年David Jewitt和陆晓捷捷（Jane Lu）发现柯伊带对象 `1992 QB` 后，太阳系的跨海王星区域得到了探索。柯伊带对象的成员是行星形成期间形成的原始固体构件（行星子）的残留物。它们留在原位是因为距离巨行星很远，而不是被踢出太阳系。它们是太阳星云的遗迹，即产生太阳系的原始气体和尘埃盘。见海王星；行星；外行星。

1992年柯伊带对象的发现暗示遥远的行星可能仍然存在。这导致了跨海王星行星的想法。柯伊带首次于1990年被确定，并于1998年被柯伊伯（1951年曾发现过）重新发现。长周期彗星绕太阳运行一周的时间从200年到数百万年不等，长期以来被认为来自奥尔云，这是一个距离太阳数千个天文单位的球形彗星云。

柯伊带位于海王星之外，延伸到某个未知的外部边界。这些对象并非均匀分布在整个带区内，而是以簇或空间家族的形式存在。大多数柯伊带对象可以根据共振、经典或离散进行分类。

经典柯伊带对象位于海王星共振区之外，其特征是在黄道面上的近圆圆轨道。柯伊带对象并非太阳星云中的原始行星子，这表明它们成功保留了自身的起源。

离散柯伊带对象因其巨大的椭圆轨道与柯伊带的其他部分不同。离散柯伊带的轨道尚不清楚，但可能是产生奥尔云的散射过程的副产品。

# 黑流

黑流是流经中国沿岸和北太平洋上层水域洋流。黑流是被称为北太平洋环流的巨型环状循环的一个分支。这种环流横跨整个太平洋，角度在15至45度之间。它沿海岸风、季风以及北部的西风流动。

黑流的流速可达2 km/h。

黑流与该区域周围的水域相比具有异常的低盐度。它位于菲律宾主要岛吕宋岛的东南岸。黑流沿东中国海向日本东岸流动。从那里，它向东北方向流动，距离北美北岸仅1000公里（620英里），在何处转向东北回到东中国海。随后它沿加利福尼亚州岸向西南流动，在那里被称为日本暖。最后，它离开亚洲区域并作为黑流延伸体进入北太平洋内部。

北大西洋的墨西哥湾流和黑流将大量暖水从热带迅速带到中纬度地区。它是全球热分布的重要媒介。在北纬50度处，它与西风会合，北美洋流受海水融化的影响很大。

# Kutigoronia

`Kutigoronia` 是一种现存的蟑螂目，其所属的纲尚不确定。

成员发现于早期的柬埔寨和马达加斯加。雄性生殖器由对的刺和脊组成，但这些看起来不像蟑螂的齿和窝那样均匀。无翅蟑属（`Blachopterodes`）具有显著的节结构，其腿部与腿节具有真正的后缘，以及其他不相关的特征。

## 湖泊

内陆水体，面积巨大，由岩石沉积形成的。通常来说，大多数湖泊是冰川湖、盆地。湖泊分布在世界各地。湖泊的盐分含量取决于是间歇性的还是永久性的。盐湖包括咸海、咸罗等。所有盐湖都分布在沙漠或干旱气候区，蒸发率足以防止径流。淡水湖泊含有溶解的养分。见 淡水系统；水圈；金属湖泊；富营养化。
