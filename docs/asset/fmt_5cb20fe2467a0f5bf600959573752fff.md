由方程 (1) 形成的积分方程。主要问题是决定何时此类函数

```
\int K(x,y)f(y)dy + f(x) = \alpha\phi(x) (1)
```

$\phi(x)$ 是 $x$ 的函数，通常来自常微分方程的分析。像方程 (1) 这样的方程，如果 $\alpha=0$ 则为第一类方程，如果 $\alpha\neq 0$ 则为第二类方程。第二类 Volterra 方程可以通过近似法求解。

这些方程的一个特例是线性积分方程，其中 $f(x)$ 是 $\phi$ 的线性函数。第一类和第二类方程分别由方程 (2) 和 (3) 所示。核 $K(x,y)$ 称为核：

```
f(x) = \int K(x,y)\phi(y)dy (2)
```

```
\phi(x) = f(x) + \lambda\int K(x,y)\phi(y)dy (3)
```

复数 $\lambda$ 是一个参数。当 $f=0$ 时，第二类方程是齐次方程。在典型情况下，方程只有平凡解 $\phi(x)=0$。对于某些参数值 $\lambda$，可能存在非解。存在解的 $\lambda$ 值称为特征值，$\phi$ 称为 $K$ 的特征函数。这些概念与线性代数和算子理论有关。

积分方程 (2) 是 Fredholm 方程，如果 $\|K\| < \infty$，则 $K(x,y)$ 是 Fredholm 核，其中 $\|K\|$ 是 $K$ 的范数。它由下式定义：

```
\|K\|^2 = \int\int |K(x,y)|^2dxdy
```

如果 $K$ 是连续或有界。对于参数满足条件 $|\lambda|\|K|<1$ 的第二类 Fredholm 方程可以通过 Picard 方法证明有唯一解。通常，对于任何常数 $M>0$，只有许多 $|\lambda|<M$ 的特征值。此外，每个特征值对应有限个线性无关的特征函数。见积分。

两类函数之间的积分变换关系。对于像方程 (1) 这样的关系：

```
f(x) = \int G(x,y)\phi(y)dy
```

被定义为积分变换。可能有多个变换，$G(x,y)$ 和 $\phi$ 可能取决于更多的参数。这被认为是将 $\phi(x)$ 转换为另一类函数的变换的整体类（或空间）。积分核 $G(x,y)$ 是变换的核。此类变换的逆变换在一个问题中很难求解，而在另一个中可能很容易求解。

任何积分变换的两个基本问题是表示和逆。目标是从 $f(x)$ 恢复 $\phi(x)$，其中核 $G(x,y)$ 已知。也就是说，方程 (1) 被视为第一类积分方程，从 $f(x)$ 求解未知数 $\phi(x)$ 是一个逆公式，并且在变换中达到了最大单位，因为从空间显式地到另一个。在表示中，这些函数可以用核来写。第一类方程 (1) 对于 $f$ 是可解的。当解 $\phi(x)$ 被限制在正或有界的子空间时，这个问题可能变得更复杂。

## 集成电路滤波器

电子滤波器是集成的，通过连接电子电路制成。集成滤波的设计仅仅是一个积分变换。滤波器受到某些类型组件可用性的限制，例如压电谐振器，其尺寸很小。集成滤波器与系统的其他部分的重叠很少，而且制造复杂集成电路的成本很低。

滤波器有很多优点。其中一个优点是简化电路并允许对信号进行大量的采样或插值。采样模数转换器由集成电路（芯片）制造，更容易将脉冲转换为同一类。

## 集成电路 1165

金属氧化物半导体场效应晶体管（`MOSFET`）。超大规模集成（`VLSI`）是可能的，因为 `MOSFET` 是自隔离的，且平均尺寸为 10⁻⁴ 到 10⁻⁶ cm²。这使得在每个电路中使用数百万个晶体管成为现实。由于这种高能力，`MOSFET` 用于高密度随机存取存储器（`RAM`）、只读存储器（`ROM`）和处理器。参见存储技术（STORAGE TECHNOLOGY）；光电子（OPTOELECTRONICS）；半导体处理器（SEMICONDUCTOR PROCESSORS）。

20世纪60年代中期以来，开发出了多种类型的 MOS 器制造技术。它们是：(1) 金属 p通道 `MOSFET` (`PMOS`)，使用铝作为电极和结；(2) 硅沟道 `MOSFET` (`CMOS`)，使用硅作为栅极电极和第一层互连层；(3) 氮通道 `MOSFET` (`NMOS`)，使用硅栅极；以及 (4) 互补 `CMOS`，同时使用 p 沟和 n 沟道器件。

从概念和结构上说，`MOS` 晶体管比双极性晶体管要简单得多。事实上，它的工作自20世纪30年代后期就为人所知，而发现双极性晶体管的最初目标是为了开发 `MOS` 晶体管。这种简单器件在1964年之前缺乏商业集成，是因为它的运行取决于半导面的特性，而双极性晶体管主要取决于半导体晶体的体材料特性，这种特性已变得非常完善。

图2所示了一个简单的 `CMOS` 反相器。n 通道和 p 通道晶体管的栅极作为漏极连接。共栅是输入节点，共漏极是输出。在输出端增加了一个电容，以模拟流水线中后续阶段的负载电容。

当输入为“低”电平（0 V）时，p 通道的栅源电压为 0 V，而 n 通道的栅源电压为正电压，大于阈值电压（通常为 0.5–1 V），因此此处开始通过漏极传导电流。在 0 V 的栅源电压下，p 通道关闭，漏极和源极之间没有电流。然而，由于 p 通道在栅和源处需要小于阈值电压的负电压，p 通道将开启，从源极传导电流到漏极，从而为负载电容。

![](img/b16805e6127c92641547ee45e5728f7f_1174_0.png)

图2. 简单 `CMOS` 反相器 (a) 示意电路。输入为 0 V “低”电平时的电流流向。(b) 输入为 5 V “高”电平时的电流流。

当输入为 5 V 的“高”电平时，p 通道将关闭，n 通道将开启。这将允许负载通过 n 通道放电，电压从 5 V 降至 0 V 的“低”电平。再次，漏极和源极之间没有电位差（放电至0 V），电流从漏极流向源极。

这个简单的电路说明了 `CMOS` 电路的一个非常重要的特征：当输入变为高电平时，负载电容被迅速释放，且待机功耗非常低。这是由于 `CMOS` 在基于电池的系统中广泛应用。与 `NMOS` 相比，其制造步骤的要求较低（降低 10-20%）。

`CMOS` 集成电路在单块芯片上结合高性能双极性和高密度 `CMOS` 方面引起了极大兴趣。这一概念起源于双极性电路，当功能增加（从而增加了更多晶体管）时，功率限制变得明显。使用 `CMOS` 可以在不增加功耗的情况下向芯片中添加电路。`CMOS` 电路的工作速度与 `CMOS` 和双极性相当。双极性晶体管的缺点是，随着晶体管数量的增加——`CMOS` 的功率要低得多 (R.E. Yem, M.)

制造，集成电路制造始于经过抛光的高纯单晶硅晶圆，并结合物理和化学工艺来创建上述集成电路结构。衬底经热扩散或高能离子注入。集成电路之间的电气隔离通过热氧化生长的绝缘层实现。对于 `CMOS`，通过化学沉积功率更低。通过各种技术获得提供集成电路所需连接的层。光刻工艺在整个制造序列被用于定义几何特征、探测器等。集成电路的重要用途包括信号处理（例如频谱分析和模拟数字转换）以及通过光纤（即圆形（或椭圆形）波导）进行通信。

设计：使用硅技术设计并制造了在太赫频率下包含 10⁵ 个晶体管的集成电路。预测表明，硅可以包含 10⁹ 个晶体管，这在带宽集成限制复杂度增长之前对于高速动态随机存取存储器（`DRAM`）是可行的。晶体管尺寸可以减小的极限不是泄漏电流，而是高场条件下运行时的噪声退化以及性能和可靠性的退化。用于设计、数据管理和其他服务的计算机辅助工程 (`CAE`) 工具旨在支持这些复杂、高性能器件的设计。在许多情况下，复杂电路的设计是自动的，因此 `CAE` 系统也必须管理设计，以确保文档得到妥善处理，设计所需的更改得到做出并充分理解。
