## Domain Name

识别 Internet 站点的唯一名称。域名总是由点分隔的两个或多个部分组成。左侧部分最具体，右部分最通用。一个给定的机器可能有多个域名，但一个给定的域名只指向一台机器。例如，域名：`matisse.net` 和 `workshop.matisse.net` 可以指向同一台机器，但每个域名可能指向没有任何。网络上的所有机器都有相同的右侧部分（如上面的 matte.net）。域名可能存在但未连接到实际机器。这通常是为了让小组或企业在不建立真实 Internet 站点的情况下拥有互联网电子邮件地址。在情况下，某些互联网机器必须代表列出的域名处理邮件。来自 Matisse `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
