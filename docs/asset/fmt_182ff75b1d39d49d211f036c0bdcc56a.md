## Linux 总体安全

### 通过此 Linux 安全指南，在你的系统和网络上获得坚如磐石的防御

`Linux` 以其极高的安全性而享有卓著声誉，与 `Windows` 和 `OS X` 等操作系统相比更是如此。然而话虽如此，你并不能简单地高枕无忧，假设你的电脑无懈可击——尤其是在过去几个月 `Heartbleed`、`Shellshock` 和 `Turla` 恶意软件等安全恐慌事件的背景下，以及更直接的系统和账户入侵的持续威胁。

这个月，我们将在多个方面着手处理安全问题。首先，我们将用细齿梳一般仔细梳理良好的密码实践，指出你需要知道的一切，并向你展示如何创建超级安全的密码。然后，我们将通过运行机器的最佳设置来查看客户端安全性，并建议你如何确保所有重要内容都得到保护。接下来是网络——我们将解释如何构建防火墙并正确设置和控制端口，然后阐述渗透测试的原则。最后，我们将回归在线事务，查看保护你的各个账户的方法，包括使用双因素身份验证，并审查任何可能被用于入侵你账户的信息。让我们开始吧。

#### 密码安全

创建一个牢不可破的密码是保护一切事物的第一步。

保护任何事物安全的最重要步骤之一，就是创建一个极难破解的强密码。虽然电影会告诉你，精明的黑客只需环顾你的办公室就能猜出你的密码（“是他儿子的名字——太简单了”），但最常见的密码破解方法是对服务器和用户名的暴力破解。在暴力破解攻击下，短密码、未修改的字典词汇以及任何出现在热门密码列表中的内容都会很快被攻破。就密码长度与破解时间而言，随着 `CPU` 速度和带宽的进步，成功发现密码所需的小时数和天数都在不断缩短。使用简单的字母数字密码越来越不安全，即使它们长达 10 个字符。让我们从一个密码开始并对其进行修改——一个非字典词汇，长度适中。凭空想出的我们有：

```
dwanton
```

— 七个字符，小写字母

**破解时间：两秒**

七位相当短。如果你是在线使用，大多数网站要求最少 8 个字符，且包含一个大写字母和一个数字。这大大改善了密码的质量，无论是离线还是在线。一个基本的修改可以是：

```
Dwanton1
```

— 八个字符，大小写字母和数字混合

##### 我的密码有多安全？

![](img/30dc0459712b32ede1a3814d456b41b6_102_0.png)

*上图：有一些网站可以检查你的密码，但请确保使用类似的工具*

**破解时间：15小时**

好多了！密码的安全性立即呈指数级增长，虽然 15 小时仍然不算长。我们可以通过在易记的位置添加一个符号来进一步优化：

```
Dw@nton1
```

— 八个字符，字母数字和符号混合

**破解时间：3天**

又有了巨大的飞跃，达到 3 天。理论上，大多数人此时可能已经放弃，但由于我们面对的是自动化的暴力破解，这点并不重要。就暴力破解而言，我们现在的八个字符密码已经达到了相当高的安全性，而末尾的“1”有点基础。只需将其改为两位数字，我们就能进一步增加破解时间：

```
Dw@nton12
```

— 九个字符，字母数字和符号混合

**破解时间：275天**

275 天相当长一段时间，但对于坚持的破解者来说仍然可行。在这个密码末尾添加一个符号、字母或数字，可以将其寿命延长至 58 年。58 年对于某人在不升级硬件和软件或简单地忘记此事的情况下尝试破解你的密码来说，是一段极其漫长的时间。所以这里有一个优秀的起始密码理念示例：

```
Dw@nton12*
```

我们称之为“起始”，因为虽然这是一个优秀的密码，但你不应将其用于你拥有的每个账户。如果由于他人的不安全行为导致密码列表泄露，那么即使他们的破解时间很长，如果他们已经知道密码是什么，那也无济于事。如果你听到泄露消息，请立即更改密码。

> “使用简单的字母数字密码正变得越来越不安全”

##### 密码使用准则

- **应该做**
  - 使用大写字母、数字和基本符号
  - 每六个月重置一次在线密码
  - 确保长度至少为九个字符
  - 使用密码检查器测试类似你密码的内容
- **不应该做**
  - 使用字典词汇
  - 使用短语
  - 使用个人信息
  - 使用连续数字
  - 使用如两位出生年份这样的数字
  - 在所有地方使用相同密码
  - 写下来
  - 做得太长

#### 在线安全

有效使用你的在线密码并采用其他安全措施。

现在我们已经有了基本密码，是时候开始在线实施它了。安全专家建议你为每个账户使用不同的密码。像 `LastPass` 这样的服务可以通过为每个账户提供真正唯一的密码来方便地实现这一点，但你可能会对此感到不适。人类能记住的密码数量有限；既然你绝对不应该记录这些密码，我们建议根据你正在使用的网站对密码进行修改。

例如，让我们以 `Amazon` 为例。它存储有你的信用卡信息，因此保护账户极其重要。在“`dwaonton`”基础密码的“`Dw@en`”之后，我们有三个字符可以操作，因此我们可以为 `Amazon` 密码更改它们。以下是我们的操作：取网站名称中间的三个字母（由于 `Amazon` 有六个字母，我们选择“`maz`”），并将字母倒序为“`zam`”。现在将其插入密码：

```
Dw@nzam12*
```

这仍然具有高度的安全性，但与例如 `eBay`（`Dw@nab1e12*`）或 `Github`（`Dw@nhgb12*`）不同，这使得任何试图在其他网站和账户上使用该密码的破解程序无法立即识破。足够聪明的人类可能会破解代码，但这只是如何修改密码同时保持自己容易记忆的示例。

##### 安全与隐私

上一期我们探讨了如何尽可能保持详细信息私密。除了暴力破解攻击外，黑客还可以通过电话支持进行社会工程学和欺骗技巧来利用他们能从社交账户收集到的任何信息来欺骗你。一些注重隐私的建议可以帮助对恶意人员保密攻击角度。

检查你的社交媒体账户——主要是 `Twitter` 和 `Facebook`——查看你的隐私设置。确保没有敏感信息被设置为私密，甚至考虑删除个人资料中你不需要的项目，例如 `Facebook` 上的电话号码或 `Twitter` 上的位置。最重要的是，严格保密你的主要电子邮件地址：除非通过直接消息发送给信任的人，否则绝不要在 `Twitter` 上分享它，并且不要将其保留在个人资料中。对于工作电子邮件，使用不同的地址，并将尽可能少的账户链接到该电子邮件。

最后，虽然这是一个极端的步骤，你可以始终考虑不在你更公开的社交媒体账户上使用真实姓名。`Facebook` 不会真正允许个人账户这样做，但在其他地方如果可以的话，如果你希望尽可能安全和私密，使用别名是个好主意。

##### 双因素认证

双因素认证是近年来最佳的安全功能之一。`Google`、`Apple`、`Tumblr` 和许多其他服务和网站现在都包含双因素认证以增强安全性。通常，手机号码会安全地提供给公司，该公司随后会向你发送一条消息，其中包含一个特殊的、一次性使用的代码，与你正在尝试登录账户的任何系统配合使用。其他公司会通过电子邮件发送它，或允许你使用类似银行键盘的特殊应用程序。开启这个功能对某些人来说可能稍微不方便，但由此带来的安心感和增加的安全性是非常值得的。
