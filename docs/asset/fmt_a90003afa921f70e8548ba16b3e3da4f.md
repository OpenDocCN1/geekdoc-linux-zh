
## 环境变量

若干环境变量会影响相关的默认值。

- `NIS_DEFAULTS`: 指定一个覆盖默认值的字符串。该字符串由冒号分隔的令牌组成。这些令牌见下文。
  - `ttl`: 设置创建对象的默认生存时间。使用 `nischttl(1)` 定义的格式指定时间值。默认值为12 小时。
  - `owner`: 指定创建对象的默认所有者主体。默认值为执行命令的主体。
  - `group`: 指定创建对象的默认组所有者。默认为空。
  - `access`: 指定授予创建对象的默认访问权限集。使用 `nischmod(1)` 定义的格式指定权限值。默认值为 `---cdr---r---`。
- `NIS_PATH`: 覆盖默认 NIS+ 搜索路径。指定一个用冒号分隔的目录列表。美元符号 `$` 被特殊处理。将 `$` 附加在默认域和全局根之间深度至少两层的目录列表中。默认 NIS+ 搜索路径为 `$`。

## `niserror` — 显示 NIS+ 错误消息

### 概要

```
/usr/bin/niserror error-num
```

## 描述

使用 `niserror` 命令在标准输出上打印与状态值 `error-num` 相关的 NIS+ 错误。此命令用于 shell 脚本将返回的 NIS+ 错误转换为文本消息。

## 示例

以下示例打印与错误 20 相关的错误。

```
castle% niserror 20

未找到，无此类名称

castle%
```

以下示例打印与错误 21 相关的错误。

```
castle% niserror 21

名称/条目不唯一

cast%
```

## `nisgrep` — 搜索 NIS+

### 另
- `nis+(1)`
- `niserror(3)`
- `attributes(5)`

### 语法

```
/usr/bin/nisgrep [-A] [-s] pattern

/usr/bin/nisgrep [-A] [-s] name=pattern
```

## 描述

使用 `nisgrep` 命令搜索 NIS+ 组和成员列表。它可以向组添加或删除实体（principals），或测试成员身份。NIS+ 组的名称在语法上与 NIS+ 对象的名称相似，但它们占用独立的命名空间。名为 `a.b.c.d.` 的组由名为 `a.b.c.d.` 的 NIS+ 对象表示。组成员有类型：

- 显式成员仅为 NIS+ 实体名称，例如通配符。
- 隐式（“域”）成员，写为 `*.**`，意味着给定域中的所有实体都属于该成员。不允许其他形式的通配符：`wildcard.*` 和 `*wildcard.*` 都是无效的。请注意，给定域子域中的实体不包含在内。
- 递归（“组”）成员，写为 `@.*`，指向另一个组；属于该组的所有实体在此处都被视为。

你可以通过在成员名前前加上减号 `-` 使任何成员变为变为负成员。一个组可以包含显式、隐式、递归、负显式和负递归成员。如果一个实体属于至少一个非负成员且不属于任何负成员，则认为它属于该组。实体名称必须是完全限定的，而除了创建操作外，组名可以缩写。

## `nisadmin` — NIS+ 组管理

### 语法

```
/usr/bin/nisadmin [-a] [-t] group

/usr/bin/nisadmin [-d] [-M] [-s] group

/usr/bin/nisadmin [-c] [-D] [-s] group
```

## 描述

使用 `nisadmin` 命令管理 NIS+ 组及其组成员列表。它可以创建、销毁或列出 NIS+ 组，并用于管理组成员身份。NIS+ 组的名称在语法上与 NIS+ 对象的名称相似，但它们占用独立的命名空间。名为 `a.b.c.d.` 的组由名为 `a.b.c.d.` 的 NIS+ 对象表示。

## 选项
- `-a` 将指定的 NIS+ 实体列表添加到组中。实体名称必须是完全限定的。
- `-c` 在 NIS+ 命名空间中创建组。NIS+ 组名必须是完全限定的。
- `-d` 从命名空间中销毁（移除）组。
- `-D` 指定创建对象时使用的另一组默认值。默认字符串是一系列由冒号分隔的标记（tokens），代表用于对象属性的默认值。所有合法的标记均见下文描述。
- `-ttl=time` 为用此命令创建的对象设置默认的生存时间（TTL）。你按照 `nisttl(1)` 命令定义的格式指定时间值。默认值为 12 小时。
- `-owner=ownername` 指定 NIS+ 实体 `ownername` 拥有所创建的对象。通常情况下，此值与执行命令的实体相同。
- `-group=groupname` 指定组 `groupname` 为所创建对象的组所有者。默认值为空（null）。
- `-access=rights` 指定要授予给定对象的访问权限集。你按照 `nismod(1)` 命令定义的格式指定权限值。默认值为 `---rmcdr---r---`。
- `-1` 列出指定组的成员列表。（见 `-M`。）
- `-M` 仅主服务器。将查询发送到命名数据的主服务器。此选项保证了能看到最新的信息，但代价可能是主服务器可能会忙。请注意，`-M` 选项仅适用于 `-1` 选项。
- `-r` 从组中移除指定的实体列表。实体名称必须是完全限定的。
- `-s` 静默工作。返回结果，并使用命令的退出状态。该状态可以通过 `niserror(1)` 命令转换为文本字符串。
- `-t` 显示指定的实体是否为该组的成员。

## 示例

#### 管理组
以下示例在 `foo.com` 域中创建一个组。

```
castle% nisadmin -c my_buds.foo.com.
```

以下示例从当前域移除该组。

```
castle% nisadmin -d freds_group
```

#### 管理成员
以下示例展示了如何向组 `my_buds.foo.com` 添加两个实体 `bob` 和 `betty`。

```
castle% nisadmin -a my_buds.foo.com. bob.bar.com. betty.foo.com.
```

以下示例从 `freds_group` 中移除 `betty`。

```
castle% nisadmin -r freds_group betty.foo.com.
```

### 诊断信息
- `NIS_SUCCESS`: 成功时，返回退出状态 0。
- `NIS_PERMISSION`: 当你没有权限更改该组时，返回此错误。
- `NIS_NOTFOUND`: 当组不存在时，返回此错误。
- `NIS_TRYAIN`: 当命令执行期间组被其他人修改时，返回此错误。请稍后重试命令。
- `NIS_MODERROR`: 当组处于只读状态时，返回此错误。
