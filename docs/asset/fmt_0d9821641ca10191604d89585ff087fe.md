# 重要事项

请仔细遵循随 6.5.3 光盘附带的光盘说明书中的指令。在从 IRIX 6.5 之前的版本进行升级时，遵循这些指令尤为重要。这些指令告诉您在执行任何“keep”（保留）或“install”（安装）命令之前，如何插入所有相关的 IRIX 6.5 光盘（或打开所有网络发行目录）以及 6.5.3 光盘。如果不这样做，您的安装将无法成功（您将遇到无法解决的冲突）。请参考光盘安装说明书获取相关且必要的光盘列表。
