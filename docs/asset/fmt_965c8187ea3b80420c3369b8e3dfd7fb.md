
# 化学能

这是一个有用但已过时的术语，用于描述元素和化合物在反应时（如燃烧反应中）释放的能量。在精确的术语中，并不存在所谓的“化学能”，因为所有能量都以动能或势能的形式储存在物质中。参见**燃烧**；**能量**。

当发生化学反应时，反应物的原子会改变其键合模式并成为产物。断裂反应物中的键需要能量，而形产物中的键则释放能量。净能量变化通常被称为化学能。更准确地说，当反应发生时，随着键的断裂和新键的形成，系统的焓$H$会发生整体变化。这种焓变用$\Delta H$表示。在标准条件（压力为1 bar [100千帕]且所有物质纯净）下，该变化记为$\Delta H^{\circ}$，并称为反应的标准焓。只要压力保持恒定，标准焓可以识别为反应发生时以热量形式释放（当$\Delta H^{\circ} < 0$时）或吸收（$\Delta H^{\circ} > 0$时）的能量。$\Delta H^{\circ} < 0$的反应被归类为放热反应；$\Delta H^{\circ} > 0$的反应被归类为吸热反应。所有燃烧都是放热反应；释放的热量用于提供温暖或提高某种引擎中工作流体的温度。常见的吸热反应很少见；一个例子是硝酸铵在水中的溶解（例如，这一过程用于医疗冷敷贴）。

典型燃料可利用的“化学能”（即燃料燃烧过程中的焓变，此时碳氢键被更强的碳氧键和氢氧键取代）通常以比焓或焓密度形式报告。比焓是标准燃烧焓除以反应物的质量。焓密度是标准燃烧焓除以反应物的体积。当质量是重要考量因素时（例如将火箭送入轨道），比焓是主要关注点。当存储空间受限时，焓密度是主要关注点。氢气气体比焓相对较高（142 千焦/克），但其焓密度较低（13 千焦/升）。代表汽油的正辛烷的值分别为 488 千焦/克和 38 兆焦/升（注意单位变化）。正辛烷高焓密度意味着汽油箱无需很大即可存储大量“化学能”。参见[航空燃油](https://example.org/aircraft_fuel)；[能源](https://example.org/energy_sources)；[汽油](https://example.org/gasoline)；[火箭推进](https://example.org/rocket_propulsion)。[PWA]

## 化学工程

将工程原则应用于基于化学和物理现象的化学、设计、开发、操作或使用工艺和产品的领域。由于工程师中独特的理解和利用化学变化的能力，化学工程师被视为工程通才。他们运用数学、物理和化学原理，熟悉各种形态的物质和能量及其操控，因此非常适合在广泛的技术监督领域工作。

虽然化学工程主要起源于英国，但其主要发展在美国进行，最初由石油和重化工业推动，后来由石化工业推动，后者以石油和天然气为原料生产塑料、合成橡胶和合成纤维。20世纪初，化学工程发展了物理分离技术，如蒸馏、吸收和提取，将物质传递、流体动力学和热量传递原理结合在设备设计中。化学工程的化学和物理方面分别称为[单元过程](https://example.org/unit_processes)和[单元操作](https://example.org/unit_operations)。

如今，化学工程应用于生物技术、能源、环境、食品加工、微电子和制药工业等。在这些行业中，化学工程师从事生产、研究、设计、工艺和产品开发、营销、数据处理、销售，几乎无一例外地参与高层管理。参见[生化工程](https://example.org/biochemical_engineering)；[生物医学化学工程](https://example.org/biomedical_chemical_engineering)；[生物技术](https://example.org/biotechnology)；[化学转化](https://example.org/chemical_conversion)；[化工行业](https://example.org/chemical_process_industries)；[电化学过程](https://example.org/electrochemical_process)；[食品工程](https://example.org/food_engineering)；[单元操作](https://example.org/unit_operations)；[单元过程](https://example.org/unit_processes)。[WFF]

## 化学平衡

在动态或动力学意义上，化学平衡是化学反应正向和逆向速率相等，反应物质浓度不随时间变化的状态。在热力学意义上，这是系统组成没有变化趋势的状态；系统不发生任何变化，除非施加某种形式的功。从统计力学观点看，平衡态使系统处于与系统能量、体积和组成相容的最大自由度（或最小限制）状态。统计方法与热力学结合形成称为[统计热力学](https://example.org/statistical_thermodynamics)的领域；这一结合在理论激励和对平衡研究的实际贡献方面价值巨大。参见[化学热力学](https://example.org/chemical_thermodynamics)；[统计力学](https://example.org/statistical_mechanics)。

### 化学平衡

在三种观点中，热力学方法在提供平衡位置与控制因素之间定量关系方面远比其他方法更强大和富有成效。由于热力学研究可观测性质（如温度、压力、浓度、热量和功）之间的关系，这些关系具有普遍有效性，与分子行为理论无关。

### 化学势

热力学将每种化学物质赋予一种称为化学势的性质，可理解为该物质进入化学（或物理）变化的趋势。虽然物质化学势不能直接测量（除了相对基础），但化学势差异可测量。（单位是每摩尔能量。）

化学势的重要性在于其与反应亲和力或驱动力关系。考虑一般反应（1）。设 $\mu_{A}$ 为物质 A 的每摩尔化学势，$\mu_{B}$ 为 B 的每摩尔化学势，等等。

$$\mathrm{aA}+\mathrm{bB} \rightarrow \mathrm{cC}+\mathrm{dD} \quad(1)$$

那么，根据热力学基本原理之一（第二定律），当反应物总化学势大于产物总化学势时，反应自发性发生。因此，对于自发变化（自然发生过程），式（2）适用。达到平衡时，产物和反应物总化学势相等；因此在平衡时式（3）成立。

$$\left[\mathrm{c} \mu_{\mathrm{C}}+\mathrm{d} \mu_{\mathrm{D}}\right]-\left[\mathrm{a} \mu_{\mathrm{A}}+\mathrm{b} \mu_{\mathrm{B}}\right]<0 \quad(2)$$

$$\left[\mathrm{c} \mu_{\mathrm{C}}+\mathrm{d} \mu_{\mathrm{D}}\right]-\left[\mathrm{a} \mu_{\mathrm{A}}+\mathrm{b} \mu_{\mathrm{B}}\right]=0 \quad(3)$$

式（2）和（3）中化学势差称为过程或反应的驱动力或亲和力；显然，当化学系统处于化学平衡时为零。

对于恒温恒压下的反应（化学实验室常见限制），化学势差等于过程自由能变化 $\Delta G$。自由能减少表示从过程中获得的最大净功。当不再能获取功时，系统处于平衡。相反，若过程 $\Delta G$ 为正，则必须向过程或反应施加有用功才能进行；过程不能自然或自发发生。（此处自发仅表示过程可能发生。它不表示反应快速或瞬间。因此，根据此处定义，氢和氧反应是自发过程，尽管氢氧混合气在没有点燃或接触催化剂的情况下可多年不变。）

因为按定义催化剂在反应中化学不变，其化学势不出现在式（2）、（3）、（4）中。因此，催化剂对反应驱动力没有贡献，也不改变系统中化学平衡位置。参见[催化](https://example.org/catalysis)。

除了提供化学系统平衡态判据外，热力学方法走得更远。在许多情况下，它提供化学势变化（或自由能变化）与反应物质平衡浓度之间关系。为此，需将化学势表达为浓度（及物质其他性质）的函数。参见[浓度](https://example.org/concentration)（及状态）。
