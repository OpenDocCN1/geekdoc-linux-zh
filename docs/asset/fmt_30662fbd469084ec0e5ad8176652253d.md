# 访问服务器 (SSH)

SSH 是旧系统 Telnet 的现代替代方案。它允许系统之间安全地交换数据。使用远程 SSH，使用文件传输（SFTP）（也称为 SSH 隧道）。在本节中，我们将学习使用实现协议的 Python 模块使用 SSH，可以通过以下命令安装：

```bash
git clone github.com/paramiko
cd paramiko
python setup.py
```

`paramiko` 的核心是 `SSHClient` 类。它为你处理了 SSH 的大部分方面：

```python
client = paramiko.SSHClient()
client.load_system_keys()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
print(f"Connecting to {hostname}...")
client.connect(hostname, username=username, password=password)
print("Connected")
stdin, stdout, stderr = client.exec_command("ls -l")
print(stdout.read().decode())
```

示例展示了一个完整的交互式连接：

```python
import paramiko, os, socket, sys, traceback

paramiko.log_filename("demo.log")

def get_hostname():
    if len(sys.argv) > 1:
        return sys.argv[1]
    return socket.gethostname()

hostname = get_hostname()

username = ''
if hostname == '':
    hostname = 'localhost'
else:
    hostname = input("Hostname: ")

username = input("Username: ")
if username == '':
    username = 'root'

port = int(input("Port: "))
if port == 0:
    port = 22

password = input("Password: ")

client = paramiko.SSHClient()
client.load_system_keys()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

try:
    client.connect(hostname, username=username, password=password, port=port)
    print("Connected")
    stdin, stdout, stderr = client.exec_command("ls -l")
    print(stdout.read().decode())
    client.close()
except Exception as e:
    print(f"Connection failed: {e}")
    traceback.print_exc()
```
