
## 裸 X 服务器与 X 会话管理

裸 X 服务器是一个简化的 X 窗口系统，没有“窗口管理器”。你可以通过在 X 终端中输入程序名称（带前缀 `./` 或完整路径）来在此处执行 X 窗口程序，但你无法移动或调整窗口大小、添加图标等。

输入 `exit` 或按 `<Ctrl><Alt><Backspace>` 即可退出 X 服务器。如果 X 服务器无法正常工作，你可能需要重新调整配置文件。

挂载 `/etc/conf.modules`：

```
mount /etc/conf.modules
```

### 远程 X 会话设置

在远程服务器上启动一个 X 程序，并将显示重定向到你的本地屏幕，例如，你可以启动一个窗口管理器：

```
startkde -display local_machine_name:0.0 &
```

符号 `&` 将命令置于后台运行，这样你的 `telnet` 窗口仍然可用。
`:0.0` 表示“显示器 0，屏幕 0”，这是你第一台显示器上的第一个屏幕，这很合理，因为在你运行 Linux 的电脑上正运行着多个并发的 X 会话。

如果你的环境变量 `DISPLAY` 已经指定了当前终端的正确位置，你就不需要指定 `-display` 选项。在我的系统中默认就是这样，但对我其他人来说并不一定。你可以使用以下命令检查 `DISPLAY` 设置：

```
echo $DISPLAY
```

完成 X 会话后，使用以下命令恢复对 X 运行器的访问控制：

```
xhost -name_of_the_remote_server
```

或者

```
xhost
```

示例：这系列命令将在名为 `marie` 的远程机器上运行 `Netscape`，并将显示重定向到运行在本地机器 `hacker` 上的带有 X 窗口管理器的 X 服务器上：

```
startx
xhost marie
telnet marie
[login]
netscape -display hacker:0.0 &
[do my stuff]
[logout]
xhost -marie
```

原则上，你可以在网络上的任何计算机上运行程序，并将输出显示在任何一台（不一定是你正坐的这台）机器上。

我经常使用远程 X 窗口功能在轻量机器（486-33，8 MB 内存）上运行重量型程序（`kde`、`Word Perfect 8` 和 `Netscape`），而这些机器本身无法运行这些程序。对于没有设置 `nfs` 挂载的远程系统，这也是处理文件的一种既方便又快速的方法。

## 4.3.4 我可以同时运行多个 X 会话吗？

是的，可以的。当你在系统上发出第一个 `startx` 命令时，它会在默认显示器 0 上打开第一个 X 会话。第二个 X 会话必须在不同的显示器上打开。例如，这将在显示器 1 上打开第二个 X 会话：

```
startx -- :1
```

你可以最多拥有 6 个并发会话。使用 `<Ctrl><Alt><F7>` 切换到显示器 0，`<Ctrl><Alt><F8>` 切换到第二个屏幕，以此类推直到 `<Ctrl><Alt><F12>`。如果需要更多信息，请尝试 `startx`。

类似，你可以打开另一个不带窗口管理器的裸 X 服务器会话。这将在显示器 2 上打开一个：

```
xinit -- :2
```

在这个裸露的 X 显示器上，我可以在 X 终端中输入以下任意一个来运行不同的窗口管理器（以便同时运行两个）：

```
fvwm2
startkde
afterstep
fwm
AnotherLevel
gnome-session
```

对应运行：`fvwm2`、`kde`、`afterstep`、`fwm`、`AnotherLevel`、`Gnome`

当然，备用窗口管理器只有在它们安装在你的系统上时才会运行。上述窗口管理器在 `RH5.2` 的 CD 中提供，你可以根据需要决定是否安装它们（`Gnome` 除外，它不在 `RH5.2` 中，但是 `RedHat 6.0` 和 `6.1` 的默认选项）。我几乎只使用 `KDE`，尽管其他管理器可能更小更快。`Gnome` 是一个著名的 X 窗口项目，据说它比 `KDE` 更先进、更漂亮，但它仍然有很多 Bug，所以除非你不介意偶尔出现问题，否则可能不推荐。`RH6.0` 和 `6.1` 包含了这两个主要的 X 窗口系统：`Gnome` 和 `KDE`。

## 4.3.5 我可以 GUI 提示吗？

为了在启动时自动启动 X 服务器并显示图形化登录提示，你需要编辑 `/etc/inittab` 文件中的一个字符。该文件指定了类似以下的内容：

```
id:3:initdefault:
```

将其改为：

```
id:5:initdefault:
```

这将默认运行级别设置为 5，即 X-Windows。不同运行级别的含义在同一个 `/etc/inittab` 文件中有所解释：

-   `0` - 停机（**不要**将 `initdefault` 设置为此项）
-   `1` - 单用户模式
-   `2` - 多用户模式，但没有 `NFS`（如果你没有网络，则与 `3` 相同）
-   `3` - 全多用户模式
-   `4` - 未使用
-   `5` - `X11`
-   `6` - 重启（**不要**将 `initdefault` 设置为此项）

你可以通过命令行使用如下命令（以 `root` 身份）更改运行级别：

```
init 6
```

这将重启你的电脑。

## 4.4 打印机和声卡

### 4.4.1 如何设置我的声卡？

尝试（以 `root` 身份）运行：

```
setup
```

顶部的第三个按钮（"sndconfig"）设置声卡。除非你有一张昂贵的声卡，否则这对你将有效。在设置最后，Linus 介绍了他如何发音“Linux”（也可以直接从命令行运行 "sndconfig"——输入 `sndconfig`）。

你可能想尝试使用命令行 `cdplayer` 测试你的声卡和 CD-ROM。将一张音乐 CD 放入 CD-ROM 并输入：

```
cdplay
```

如果这不起作用，也许你没有 `/dev/cdrom`？检查你是否可以以 `root` 身份挂载 CD（查看此处 [第 62 页]），并通过将其链接到相应的驱动器（最可能是 `/dev/hdb`）来创建设备 `/dev/cdrom`，例如：

```
ln -s /dev/hdb /dev/cdrom
```

如果 `cdplay` 对 `root` 有效但对普通用户无效，也许你需要（以 `root` 身份）赋予所有人读写文件 `/dev/cdrom` 的权限：

```
chmod 666 /dev/cdrom
```

（`/dev` 目录是你所有设备以文件形式出现的地方。）

现在，既然你迷上了 `cdplay`，你可以播放第三首歌，尝试：

```
cdplay 3
```

你也可以使用 `cdp` 命令作为 `cdplay` 的简易命令行界面，但你可能更喜欢 X 窗口下提供的界面（例如，从 `KDE` 的 "K" 菜单中选择：“Multimedia-/CD Player”）。

要停止音乐，可以按下 CD-ROM 上的按钮或执行以下命令之一：

```
eject
cdplay stop
```
