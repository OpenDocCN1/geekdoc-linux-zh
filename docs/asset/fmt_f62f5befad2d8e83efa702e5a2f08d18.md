### 打印机类型

打印机既可以是你 PC 的本地设备，也可以存在网络上。无论哪种方式，在 Linux 中访问它们都不困难，特别是当你使用本地打印机时。

本地打印机几乎总是连接到你的 PC 的并行端口——在 Linux 中被称为 `lp` 的设备。在 DOS 和 Windows 中，端口命名为 `lpt1`、`lpt2` 等；在 Linux 中，它们命名为 `lp0`、`lp1` 等。
