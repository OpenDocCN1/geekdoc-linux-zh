
## 1039

### 描述

`postprint` 过滤器将文本文件转换为 PostScript 并将其写入标准输出。如果你没有指定文件名或 `-` 是输入文件之一，则读取标准输入。

### 选项

- `-c num` 打印每页的 `num` 份。默认情况下，只打印一份。
- `-f name` 使用字体打印文本。你可以使用任何 PostScript 字体，尽管只有使用等宽字体才能获得最佳结果。默认字体是 `Courier`。
- `-l num` 将页面的长度设置为 `num` 行。默认情况下，`num` 为 66。允许设置 `num` 为 0，`postprint` 将根据字号猜测值。
- `-m num` 按因子 `num` 放大每个逻辑页面。围绕原点进行等比例缩放，原点位于每个页面的左上角。默认放大倍数为 1.0。
- `-n num` 在每张纸上打印 `num` 个逻辑页面，其中 `num` 可以是任何正整数。默认情况下，`num` 设置为 1。
- `-o list` 打印逗号分隔列表中给出的页码页面。该列表包含若干数字 `N1–N2`。缺失 `N1` 表示最低页码，缺失 `N2` 表示最高页码。
- `-p mode` 以 `p`（竖向）或 `l`（横向）模式打印。`mode` 的第一个字符是有效的。默认模式为竖向。
- `-r num` 回车行为。如果 `num` 为 0 则忽略回车，如果 `num` 为 1 则跳转到第一列，如果 `num` 为 2 则生成新行。默认 `num` 为 0。
- `-s num` 使用字号 `num`。在横向模式下打印时，根据设备成像区域的因子对 `num` 进行缩放。竖向模式默认为 10。注意增大字号会增大虚拟图像尺寸，因此你只需要加载更大的纸，或者使用 `-10` 选项来缩放每页行数。
- `-t num` 假设每隔 `num` 列设置一个 Tab，从第一列开始。默认情况下，每隔 8 列设置一个 Tab。

## 1040

### postprint

- `-x num` 将原点沿正 x 轴平 `num` 英制。默认坐标系的原点固定在页面左上角，正 x 轴向右，正 y 轴向下。正数 `num` 将所有内容向右移动。默认偏移量为 0.25 英制。
- `-y num` 将原点沿正 y 轴平 `num` 英制。正数 `num` 将文本向上移动页面。默认偏移量为 -0.25 英制。

在当前页面打印 66 行或读取到 ASCII 换页符后，将启动一个新的逻辑页面。你可以使用 `-1` 选项更改每页行数。不可打印的 ASCII 字符将被忽略，过长的行将由打印机静默地截断。

### 示例

以下示例以横向模式打印 `file1` 和 `file2`。
```
castle% postprint -pland file1 file2
```

以下示例在纵向模式下，每个物理页面打印三个逻辑页面。
```
castle% postprint -n3 file
```

# postreverse

## postreverse — 反转 PostScript 文件中的页面顺序

### 概要

```
/usr/lib/lp/postreverse [-o list] [-r][file]
/usr/lib/lp/postscript/postreverse
```

### 描述

`postreverse` 过滤器反转符合 Adobe 版本1.0或2.0 文件结构规范的文件页面顺序，并将结果写入标准输出。只允许一个输入文件，如果未指定文件，则读取标准输入。

`postreverse` 过滤器可以处理一类违反页面独立性的文件，前提是所有全局定义都由 `%%BeginGlobal` 和 `%%EndGlobal` 注释括。此外，使用全局注释标记页面结束的文件也可以正确反转，只要可以找到序言（prologue）和尾（trailer）部分。如果 `postreverse` 找不到 `%%Prolog` 或 `%%EndSetup` 注释，整个文件将不修改地复制到标准输出。

由于全局定义是从单个页面提取并放入序言的，即使输入文件不符合规定，输出文件也可以基本符合。

> 注意 — 未处理全局变量或过程的重新定义情况。如果使用标准输入，则输入文件在反转前会被读取三次。

### 选项

- `-o list` 打印逗号分隔列表中给出的页码。列表包含单个数字 `N` 和范围 `N1–N2`。缺失的 `N1` 表示最低页码，缺失的 `N2` 表示最高页。页范围是逻辑页的表达式，而不是物理纸张。例如，如果你在一张纸上打印两页并指定范围为 4，则会打印两张包含四个页面布局的纸。如果你在请求每张纸打印两个逻辑页时指定页范围为 3–4，则只打印第 3 页和第 4 页，它们将出现在一张物理纸上。
- `-r` 不反转文件中的页面。

### 示例

以下示例反转文件中的第 1 到 100 页。
```
castle% postreverse -ol-100 file
```

# 1042

# posttek — 用于 Tektronix 4014 文件的 PostScript 翻译器

### 概要

```
/usr/lib/lp/posttek [-c num] [-f name] [-m num] [-n num] [-o list] [-p mode] [-w num] [-x num] [-y num] [file...]
/usr/lib/lp/postscript/posttek
```

### 描述

`posttek` 过滤器将 Tektronix 4014 图形文件翻译为 PostScript 并将结果写入标准输出。如果没有指定文件或 `-` 是输入文件之一，则读取标准输入。

> 注意 — 默认行宽对于写白太小了。

### 选项

- `-c num` 打印每页的副本。默认 `num` 为 1。
- `-f name` 使用字体。默认为 `Courier`。
- `-m num` 用倍数放大每页。默认 `num` 为 1。
- `-n num` 打印逗号分隔列表中给出的页码。列表包含单个数字 `N` 和范围 `N1–N2`。缺失的 `N1` 表示最低页码，缺失的 `N2` 表示最高页。页范围是逻辑页的表达式，而不是物理纸张。例如，如果你在一张纸上打印两页并指定范围为 4，则会打印两张包含四个页面布局的纸。如果你在请求每张纸打印两个逻辑页时指定页范围为 3–4，则只打印第 3 页和第 4 页，它们将出现在一张物理纸上。
- `-o list` 打印逗号分隔列表中给出的页码。列表包含单个数字 `N` 和范围 `N1–N2`。缺失的 `N1` 表示最低页码，缺失的 `N2` 表示最高页。
- `-p mode` 以纵向 (`p`) 或横向 (`l`) 模式打印。默认为纵向。
- `-w num` 设置图形使用的行宽（点）。
- `-x num` 将原点沿正 x 轴移动 `num` 英制。默认坐标系的原点固定在页面左上角，正 x 轴向右，正 y 轴向下。正数 `num` 将所有内容向右移动。默认偏移量为 0.0。
- `-y num` 将原点沿正 y 轴移动 `num` 英制。正数 `num` 将文本向上移动页面。默认偏移量为 0.0。

### 退出状态

- `0` 成功完成。
- `non-zero` 错误。

### 文件

```
/usr/lib/lp/postscript/forms.ps
/usr/lib/lp/postscript/ps.requests
```
