## 使用文件命令

你在命令行中输入的命令是程序，你可以根据你提供的选项（options）来控制它们。BASH 命令的通用格式为 `命令-选项(s) 参数(s)`。

请特别注意大小写，因为在 Linux 发行版中 `ls -S` 是按大小排序。同样，`FILE1`、`File1` 和 `file1` 是三个不同的文件，而 `ls` 可以是有效的命令、选项和文件名。例如 `ls -s file` 会显示文件。
