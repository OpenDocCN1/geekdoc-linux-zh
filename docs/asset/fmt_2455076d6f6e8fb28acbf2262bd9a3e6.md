
# Linux 环境变量与常用工具

## 环境变量基础

你可以通过简单输入 `env` 开始查看所有环境变量。你需要了解的是，所有可用的环境变量将是大写的，例如 `PATH`、`SHELL`、`HOME` 等。你也可以创建自己的用户用户定义变量集，这将在稍后讨论。命令列表将打印出各种你系统特有的变量。在大多数情况下，此命令列表非常长，无法在单个页面中查看。若要按行排列查看所有变量，你可以使用 `More` 命令打印输出结果。

在使用完 `More` 命令后，整个变量列表将填充屏幕并停止。它将等待你按回车键移动到下一行。你可以继续这样做，直到找到你正在寻找的任何变量。当你连续按下回车键时，你会发现一个名为 `HISTSIZE` 的变量。当你再次按回车时，它将带你通过这些变量中的每一个。当你使用 `More` 命令查看输出时，可以输入 `q` 退出，然后返回命令提示符。

与其滚动这个长变量列表（寻找感兴趣的变量是一项枯燥的工作），你也可以使用 `grep` 命令，它作为过滤命令并将帮助你轻松找到所需的变量。

## set 与 echo

`set` 命令将显示所有变量名称，但如果你想查看存储在变量中的值，你需要输入关键字 `echo`，后面跟着 `$` 符号以及变量名，例如：

```
echo $HISTSIZE
```

`$` 符号表示你想要操作内部提供的变量值，而不是变量的标签。

## MAC 地址修改

`MAC` 地址可以被任何系统的合法地址。有很多原因使得更改 `MAC` 地址非常重要。`MacChanger` 有助于在渗透测试期间更改 `MAC` 地址，例如对启用了 `MAC` 过滤的无线网络进行渗透测试。使用 `MacChanger`，你需要遵循以下命令：

```
~$ macchanger [options] networkDevice
```

可用选项有：

- `-h`, `--help`: 打印帮助信息
- `-V`, `--version`: 打印版本并退出
- `-e`, `--ending`: 不更改厂商的字节
- `-s`, `--show`: 打印 `MAC` 地址并退出
- `-a`, `--another`: 设置为相似类型的随机厂商 `MAC`
- `-p`, `--permanent`: 重置为原始形式的永久硬件 `MAC`
- `-A`: 设置为任意类型的随机厂商 `MAC`
- `-r`, `--random`: 设置完全随机类型的 `MAC` 地址
- `-l`, `--list`: 打印已知的厂商
- `-m`, `--mac=XX:XX:XX:XX:XX:XX`: 将 `MAC` 地址设置为 `XX:XX:XX:XX:XX:XX`

## 内核模块开发

在开始内核模块开发之前，增加知识和专业知识的最佳方法是从内核模块开始。内核模块是独立开发的，作为紧凑操作操作系统运行。内核模块由许多事物组成，如外围设备的驱动程序、文件管理器和其他低级功能。

内核模块入口的唯一障碍远低于开发内核的障碍。有许多模块是由不同的个人和团队开发的。因此，在开发入口没有特定的守门人。

当你使用一些主要的操作系统形式时，你是在间接地与 shell 交互。如果你使用 `Linux Mint`、`Ubuntu` 或任何其他 `Linux` 发行版，你每次使用终端时都会与 shell 交互。让我们讨论 `Linux` 编程的拆解，它由 `Linux` shell 以及 shell 脚本组成。

因此在我们开始之前，你需要熟悉一些术语：

- 内核
- shell
- 终端

内核本质上是一个作为操作系统核心的程序。它对系统中所有的元素拥有整体控制。它有助于管理基于 `Linux` 的各种资源：

- 文件管理
- 进程管理
- 设备及各种其他组件的管理

完整的 `Linux` 系统可以分解为：内核 + 安装脚本 + 其他管理脚本 + `GNU` 系统库和实用程序。

## Shell 基础

shell 是一种特殊的用户程序，有助于为与操作系统相关的服务提供良好的接口。shell 接收用户人类可读的命令，然后将其转换为内核可以理解的内容。它可以被视为命令语言的解释器，有助于执行从键盘等输入设备或从系统文件中读取的命令。shell 在用户登录系统或启动终端时启动。

shell 可以被轻松分为两类：

- 图形化 shell
- 命令行 shell
