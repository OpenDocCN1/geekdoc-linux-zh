## 使用 py2exe

`py2exe` 是 `cx_Freeze` 和 `Freeze` 的另一种选项。PyInstaller 实际上是一种扩展。这意味着你需要创建一个 `setup.py` 文件来生成程序的可执行版本。

from distutils.core import setup
import py2exe
setup(['myscript.py'])
