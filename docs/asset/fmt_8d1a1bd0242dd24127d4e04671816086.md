
# 厌氧感染

由厌氧细菌（不耐受氧气的生物体）引起的感染。大多数此类感染是混合性的，涉及一种以上的厌氧菌，且通常还涉及需氧或兼性细菌；许多侵入全身的肠道细菌可诱导菌群变化，几乎绝大多数厌氧感染是内源性的，主要例外是`艰难梭菌`结肠炎。易感因素包括破坏黏膜或其他表面（创伤、手术、恶性肿瘤或其他疾病）、降低氧化还原电位（成对的血液淤滞、组织坏死和非厌氧菌生长）的药物，以及抑制厌氧菌的药物（如氨基糖苷类）和厌氧菌产生的毒力因子（毒素、荚膜和胶原酶、透明质酸酶和其他酶）。厌氧革兰氏阴性杆菌（`拟杆菌属`、`普雷沃菌属`、`卟啉单胞菌属`、`梭杆菌属`）和需氧革兰氏阳性球菌（`链球菌属`）是最常见的厌氧病原体。`梭菌属`（产芽孢菌）可引起严重感染。`放线菌属`中的主要高阶、高温共生致病物种。在常见涉及厌氧菌的感染中，口腔和牙科、胸膜肺、腹内、产科-妇科以及皮肤和软组织感染在发生频率上最为重要。为了正确记录厌氧感染，必须获取培养标本以排除正常菌群，并必须在厌氧条件下运输标本。治疗包括手术和抗菌剂。**参见“抗生素”；“节肢动物”；“产气”；“感染”。** [S.M.F]

## 方钠石

一种具有骨架结构的矿物，其中所有铝硅酸盐四面体骨架相互连接，从而赋予长石、长石族矿物和沸石的特性。其化学式为 `NaH$_2$O$_2$[AlSi$_2$O$_7$]`，从这个意义上说，它是一种架状硅酸盐。方钠石结构类型包括其他几种矿物。这些包括高温白长石、钾霞石和沸石。晶体最常为`斜方晶系`，罕见时该矿物呈大块粒状。莫氏硬度为 5–5$^{1/2}$；比重为 2.27。方钠石最常作为低温矿物出现在玄武岩的孔洞中，与沸石（尤其是针钠石）、水硅氯镁石、磷硅镁钠石和方解石伴生。小颗粒作为沉积物成分，存在于与火山源相关的碳酸盐盆地中的沉积岩和泥中。**参见“长石”；“长石族矿物”；“白长石岩”；“沸石”。** [P.B.M.]

## 镇痛药

一类化学结构和生理效应各异的药物，常用于缓解疼痛。要作为镇痛药，药物必须选择性地减少或消除疼痛，而不会导致感觉迟钝

意识、精神错乱、不协调或瘫痪，以及中枢神经系统的其他功能障碍。

麻醉性生物碱镇痛药中最古老、最著名的药物是鸦片，这是一种通过提取罂粟籽汁液获得的药物，以及其活性最强的生物碱吗啡。吗啡及其相关药物可减少或阻断脊髓灰质中疼痛神经元的激活，以及脑干和丘脑中受体位点的激活。除用作镇痛药外，阿片类药物还具有其他生物效应，如镇静、瞳孔收缩、抑制咳嗽反射、呼吸抑制、降低肠道蠕动、损害节段性屈肌反射以及降低体温。

这种功能多样性归因于其他神经元抑制系统的激活。尽管吗啡是最强的医用镇痛物质，但还有许多源自鸦片的天然生物碱。其中最为知名的是可待因。所有阿片类药物的共同特点是：如果连续服用数周或数月，使用者将需要更大剂量才能获得相同的镇痛和镇静效果。这种反应被称为耐受性。如果停药，数小时至数天内会出现令人不适的戒断或戒断反应。会出现剧烈疼痛、出汗、流涎、过度通气、烦躁和意识混乱。这些戒断症状是药物习性的标志，迫使成瘾者采取极端措施获取麻醉剂，以避开这些症状。**参见：成瘾障碍；生物碱；内啡肽；吗啡生物碱；麻醉剂；阿片类药物；镇静剂。**

由于吗啡及相关化合物具有强烈的成瘾性，化学家合成了其他化学结构相似的药物。就成瘾性而言，其中表现最好的一种。这一努力仅取得部分成功。美沙酮是一种已作为吗啡替代品给瘾君子使用的药物，口服时是一种有效的镇痛剂，且成瘾性低于吗啡。哌替啶（杜冷丁）是一种强效的合成镇痛剂，但确实具有成瘾性。其他合成镇痛剂包括氢可酮（强痛定）、左旋奥施定（左旋右美沙芬）、丙次枕酊（痛可宁）和喷他佐辛（镇痛新）。这一系列药物中的最后两种引起的成瘾性很小或没有，但不幸的是，它们并不是强效镇痛剂。另一种合成药物，纳洛酮，能阻断所有阿片类激动剂的镇痛效果，并诱发成瘾者的戒断症状。

另一类非麻醉性（无成瘾性）镇痛药是水杨酸盐，其中最常见的是乙酰水杨酸（阿司匹林），以及其他水杨酸盐，如芬布替唑（布他佐林）、吲哚美辛（消炎痛）、醋苯那嗪和非那西汀。这些药物对缓解由炎症引起的骨骼疼痛（如关节炎）最有效。它们的镇痛作用远不如吗啡和合成阿片类药物，这是由其对周围神经系统和中枢神经系统的作用所致。这些药物还有许多其他效应，如退热（解热）和防止血小板聚集。它们是所有镇痛药物中最常用的，经常与咖啡因或巴比妥类镇静剂组合在一起，以各种商品名销售，用于缓解头痛、背痛等。**参见：阿司匹林；阿片类药物；神经系统（脊椎动物）；疼痛。** **[R.D.A.]**

## 模拟计算机

一种计算机或计算设备，其中问题变量以连续变化的物理量表示。模拟计算机实现的是所研究系统的模型。模拟的物理形式可能在功能上类似于该系统，但更多情况下，这种类比仅基于计算机变量与物理系统变量之间相互依赖关系的数学等价性。**参见：模拟。**

### 类型

模拟计算机根据其用途（`通用`或`专用`）或根据结构（液压、机械或电子）进行分类。通用意味着可编程性，以及适应不同应用或解决多种问题的能力。大多数通用模拟计算机都是通用系统，要么是实时模拟计算机，即在不改变时间尺度的情况下直接获得结果，要么用于高速重复的计算机应用。

自20世纪70年代以来，已开发出数字计算机程序，它们基本上复制了模拟计算机的功能。现代模拟语言，如ACSL、GASP、CSMP、SLAM和Simscript，已经取代了电子模拟计算机系统。它们提供了与电子模拟计算机几乎相同的高层交互和并行求解能力，但摆脱了电子系统的技术缺点：精度通常限制在0.01%，有效带宽为1 MHz，且编程繁琐耗时。模拟语言还避免了昂贵的购买投资和复杂电子系统持续维护的依赖。

另一种类型的模拟计算机是数字多处理器模拟系统，其中相对缓慢的顺序数字增量计算速度通过并行处理得到了极大提升。在这种类型的模拟计算机中，可以在近似传统电子模拟计算机的速度、交互潜力和并行计算的同时，保留数字计算机的编程便利性和数据存储。

数字多处理器模拟计算机通常使用几个专门设计的高速处理器，用于数值积分功能、数据（`或变量`）内存分布、算术功能以及决策（`逻辑`）和控制（`路由`）功能。所有使用的*a*或双态点数字数据，随时可访问以满足计算和操作需求。

### 描述

典型的现代通用模拟计算机由控制台组成，其中包含一组运算放大器；计算元件，如求和网络、积分器网络、衰减器、乘法器和函数发生器；逻辑和接口单元；控制电路；电源；补丁架；以及各种仪表和显示设备。补丁架被布置为将所有可编程设备的输入和输出终端集中到一个位置，在那里可以使用各种补丁线和插头方便地互连，以满足特定问题的要求。重新接线的程序板可以在几秒钟内在补丁架处交换，通常在一到两小时内设置新的系数。已经开发了广泛的自动电子补丁系统，以允许快速设置，以及远程和分时操作。

模拟计算机本质上代表了微积分的仪器化，因为它被设计用来解常微分方程。这种能力适用于实现动态系统的模拟模型。计算机通过生成类似系统中物理或数学变量的电压来工作。每个变量在编程计算单元的输出端被表示为连续变化的（`或稳定`）电压信号。模拟计算机的一个特定事实是，为每个被表示的特性或方程使用单独的电路，因此所有变量都是同时生成的。因此，模拟计算机是一种并行计算机，其中计算单元的配置允许在求解问题的所有过程中直接关联计算变量。

### 编程

为了使用模拟计算机解决问题，问题解决者需要经过一般分析、数据准备、模拟电路开发和硬件编程的过程。在对完整程序运行以获得特定最终答案之前，还可以对子程序进行测试运行，以检查局部系统的动态响应。问题求解程序通常涉及以下八个主要步骤：

#### 使用模拟计算机解决问题

1. 待研究的问题用一组数学方程来描述；如果无法这样做，则定义系统配置以及组件影响的相互关系，以方框图形式表示，每个方框用黑箱输入输出关系来描述。
2. 必要时，对系统的描述（方程或系统方框图）进行重新安排，使其更适合计算机的能力，即避免重复或过多的计算单元，或避免代数（非图形）环路。
3. 利用组装好的信息，绘制一张模拟电路图，详细说明计算机如何编程以处理该问题并实现研究目标。
4. 然后对系统变量和参数进行缩放，使其落在计算机的工作范围内。这可能需要对模拟电路图和计算单元的选择进行修订。
5. 将最终的电路布局连接在计算机的问题板上。
6. 在衰减器上设置数值，建立整个系统模型的初始条件，并检查测试值。
7. 运行计算机以解方程或模拟黑箱，从而获得结果值或系统响应。这提供了初步答案以及对系统的“感觉”。
8. 进行多次运行，以检查特定参数组的响应，探索问题（系统）变化的影响，以及当系统配置在不同激励函数作用下运行时的行为。

### 混合计算机

数字计算机计算精度通常可以通过双精度技术和更精确的算法来提高，但代价是求解时间延长，这是由于计算机的串行操作性质所致。此外，需要执行的计算步骤越多，数字计算机所需的时间就越长。另一方面，由于模拟计算机的并行性质，其基本求解速度非常快，但随着问题复杂度的增加，需要更大规模的计算机。因此，对于模拟计算机，无论问题复杂度如何，时间保持不变，但所需的计算机规模随问题增大。
