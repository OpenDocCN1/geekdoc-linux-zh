
早在19世纪的实验观察导致了对配位化合物的鉴定，但未能充分解释它们的性质。Werner 对这些化合物出了正确的解释。1893年，他引入了配位键的概念，并认为元素除了一级或普通价态外还有两种价态。

三种理论被用来解释配位键的本质。静电理论（包括晶体场修正）和分子轨道理论（也被使用的分子轨道理论）。金属配合物的价键考虑了金属上的电子对以及金属的杂化轨道，键本质上是共价或离子的。几种成键物质可以从该理论得到解释。电子理论解释了过渡金属的共价键，其中金属-配体键是由电荷和偶极之间的静电相互作用引起的。晶体场理论除了解释金属的结构和性质外，还为配合物的稳定性提供了适应性解释。分子轨道理论假设金属配合物的稳定性取决于金属所有核的重叠。这种方式，它同时使用了价键和晶体场理论。

例如，酸碱反应：

`Cu² + 6H₂O → [Cu(H₂O)₆]²⁺` (1)

`Ni² + 4NH₃ → [Ni(NH₃)₄]²⁺` (2)

`Fe³ + 6CN⁻ → [FeCN₆]³⁻` (3)

形成的产物是配位离子或化合物，这一化学领域被称为配位化学。

金属配合物的稳定性取决于金属和配体。金属配合物的稳定性随着电荷和尺寸的变化而增加，并随着亲力的增加而增加。配体的若干特征已知影响以下稳定性：(1) 碱性 (2) 金属-配体环的数量 (3) 配体的尺寸以及 (4) 空间效应。由于配位键是酸碱反应的结果形成的，其中金属离子作为路易斯酸，配体越碱，越倾向于形成更稳定的配合物。配体的尺寸是一个重要因素。对于饱和配体如乙烯，五元环是更稳定的配合物。

空间因素对金属配合物的稳定性有很大影响。这在靠近原子或配体的具有大基配体中经常观察到。因此，插图中的配体类型在该位置具有大基 R 比具有 H 要稳定得多。大基诱导了配体相互作用产生应变，因此在任何其他位置的任何取代都会使配合物更稳定，因为大基从配位点被移除了。

# 聚聚物 555

配位配合物：分子键具有共价性质的化学化合物；关于配位键的性质以及配合物的稳定性和活性的讨论，请参阅 螯合（CHELATION）；配位化学（COORDINATION CHEMISTRY）。

螯合 配合物包含一个中心原子或其周围的离子簇。简单的水合物，如 `MgCl₂·6H₂O`，也被记为 `[Mg(H₂O)6]Cl₂`，因为已知 6 分子水围绕着中心离子。因此，`[Mg(H₂O)6]Cl₂` 是一个配合物，该配合物的电荷为 +2，因为这是镁离子的电荷，而配位的水分子是电中性的。配位基团带电。配合物的电荷用金属电荷与配位离子电荷之和表示。见下文配合物向铂(IV) 配合物的进展。

| 化学式 | 名称 |
| :--- | :--- |
| `[PtNH₃]Cl₃` | 六氨合铂(IV) |
| `[Pt(NH₃)₂Cl₂]` | 二氯合铂(IV) |
| `[Pt(NH₃)₃]Cl₂` | 二氯胺(IV) |
| `[Pt(NH₃)₄]Cl₂` | 三氯胺(IV) |
| `[PtCl₄(NH₃)]` | 四氯合铂(IV) |
| `[K[Pt(NH₃)₆]]Cl` | 六氨合铂酸钾 |
| `[PtCl₆]` | 六氯铂酸盐 |

因此，`[Pt(NH₃)₄]⁴⁺` 的电荷为 +4，因为 Pt 为 +4 而 NH₃ 是中性的。`[PtCl₄]²⁻` 的电荷为 -2，因为 Pt 为 +4 而 Cl 为 -1。

金属配合物表现出多种类型的异构体。在无机化学中，这与在有机化合物中观察到的现象相似。当配数为四或六时，几何异构体也很常见。

仅含一种配体的金属配合物的合成通常涉及使用水溶液金属盐，并配体作为溶剂。

`Ni(OH)₂ + 6H₂O → [Ni(H₂O)6]²⁺ + 2OH⁻`

可以通过除水直至结晶得到所需的盐，或使用水-有机溶剂。该过程可能很缓慢，需要加热；因此，形成几何异构体通常是必要的。在更剧烈的条件下制备更为困难，在某些情况下，使用的方法是经验性的，可能会产生配合物的混合物，这些混合物通过它们在溶液中的差异进行分离。见下文。

桡目（Copepeda）：甲壳动物的一个亚类，有八条腿。发现超过 600 种，分布在许多淡水、海洋环境和其他栖息地。自由游离形式是海洋中最丰富的动物，不断取食许多鱼类、海鸟的食物，也是鲸鱼的猎物。

自由生活类：角足目（Calancoida）、桡足类（Copepods）和短足目（Harpacoida）是全浮游性的，这意味着由于是水生生物，它们大部分是浮游或主要是自由游的。

![](img/b16805e6127c92641547ee45e5728f7f_564_0.png)

桡足类的种类虽然在大小和形状上差异很大。在自由生活形式中，身体由一系列小的几丁质圆柱或节组成，每节有一对附肢。取食肢是一对触角，大多数是取食器器。腹部由六节和尾毛组成。性二型性通常很明显。自由生活物种的大小范围很大。

在成体阶段，大多数桡足类（足口目、长口目、单足目和膜足目）至少将生命的大部分时间在水里度过。它们的数量庞大，可能像“鱼”一样漂浮到深海，或者作为浮游生物存在。

桡足类具有多样的栖息地；大多数物种分布非常广，但它们在一生中大部分是浮游的，尽管某些物种只栖息在海层。它们仅存在于深达 650-1000 米（200-300 米）的上层。其他的则是深海浮游生物。然而，短足目主要是寄生性的，生活在其他宿主上或生长在海洋沉积物中。

桡足类在海洋经济中的作用主要是将浮游生物转化为动物。许多物种适应于直接取食构成海洋大部分的有机碎屑、微硅藻和甲藻。某些物种是其他浮游生物的捕食者，甚至是原生动物等小型动物。通常桡足类占浮游动物的约 70%，它们的数量巨大到足以产生鱼类。见海洋生态学（MARINE ECOLOGY）。

共聚物：其中两种或两种不同的单体被结合到聚合物链中。共聚物的性质取决于单体的性质及其在聚合物中的分布。某些单体 A 和 B 可以聚合聚形成 ABBAAB；它们可以交替聚合。

# Coquina 557

铜合金因其优良的耐腐性和抗冲蚀性，非常适用于工业和海洋设施以及热交换器。含磷铜合金（含量为3-10%）形成了一个重要群体，被称为青铜，其强度、硬度和韧性有所提高。这些合金被广泛用于弹簧。

## 合金；铜。(R.E.)

由于导体电流流动导致的铜损耗。当电流通过导体（具有电阻的导体）时，部分能量会转化为热量，这种情况发生在变压器、发电机和输线路中，是受运行条件影响的电气设备属性。人们已进行大量研究以减少机器的损耗并增加导体的输出能力。

## 超导设备。(E.C.)

铜的经济生产是从矿石和废金属中获得的。世界上 90% 的原生铜产自含有黄铜矿、辉铜矿、红铜矿和斑铜的硫化物矿物，这些矿物可以通过浮选法分离，然后通过焙烤处理。

## 冶；铜

在生产硫化铜矿石的工艺中，在高温（280°F 或 250 °C 以上）并经过细磨形成铜熔体后，熔融金属通过去除剩余的铁和硫精炼成作铜（99.9%），铜被铸造并进行电化学精炼以供大多数用途。

## 选矿。

熔炼和转化典型的铜矿（每吨50 份）以及产生的排放物必须控制以符合环境标准。这是通过将铜矿转化为接触合金实现的，因为其铜浓度超过了 40% 且存在可行的市场。电解用于精炼铜以及冶炼过程中集中的金属杂质（Au、Ag、Pb、Se 和 Cu），并作为宝贵的副产品进行回收。当施加直流时，阳极的铜发生电化学沉积并镀在阴极上，电解质中的不溶性杂质沉淀到槽底部。这些杂质经过处理，最终回收硒和贵金属氧化物。

## 电化学工艺；电冶金。

氧化铜矿石通过湿法冶金工艺处理更有效。矿石被破碎（必要时），并用稀酸、醚或通过堆堆或在槽中搅拌进行浸浸。从所得溶液中通过电解或溶剂提取回收铜。铜通过与废铁接触沉淀形成胶结，然后进行精炼。溶剂提取-电解已在该工艺中成功实施。所得溶液中的有机相被剥取，得到纯度更高、浓度更高的铜溶液。电解用于从溶液中回收铜并更节省能量。虽然阴极铜不如电解铜纯，但对许多应用仍然有用。

## 湿冶金；溶剂提取。

某些脊椎动物用于插入的交器，用于将精子直接沉积到生殖道内。雄藻类的鳍限于某些类群。鳃纲和全目纲演变为传递精子，是一种交握器或泄腔器官。在全目纲中，某些鱼类的雄性鳍从头部突出，位于改良的腹鳍中。在所有硬鱼类中，交配时可能伸长为生殖器。
