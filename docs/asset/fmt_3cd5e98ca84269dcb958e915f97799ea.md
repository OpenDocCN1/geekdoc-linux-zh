
尝试一下吧。Linux 内核现在内置了几个无线驱动程序，Ubuntu 的更新经常会提供新驱动，所以如果你使用的网卡兼容其中某一个驱动，那么一切将会非常顺畅。如果某些功能运行异常，请检查 Ubuntu 论坛寻找兼容的驱动程序，或查看是否有人对你的特定网卡有经验。

如果你想在家里或办公室建立无线系统，你还需要获取一个无线接入点（WAP），如图 4-3 左侧所示。幸运的是，Linux 在这方面的兼容性不是大问题，因为接入点在物理上并不与你的电脑交互。

遗憾的是（对于 Linux 用户而言），有少数 WAP 需要你使用 Internet Explorer 来处理其设置。由于不存在 Linux 版本的 Internet Explorer，除非家里其他地方有一台 Mac 或 Windows 电脑来完成工作，否则你会发现自己陷入了困境。糟糕糟糕，有些机器完全不支持基于浏览器的设置。相反，它们要求你安装 Windows 软件来完成工作。在为你的无线设置选择硬件时，显然最好避开此类 WAP。

## 激活你的无线网卡

设置兼容 Linux 的无线 PC 网卡相对简单。首先，将你的 WAP 连接到互联网源，并打开 WAP。当它运行时后，将你的无线 NIC 插入笔记本电脑的 PCMCIA 插槽中；当然，如果你的 NIC 是内置的，那么你就可以跳过这一步。此时，外部网卡上的任何 LED 灯可能都会亮起。

如果你在启动电脑时 WAP 是开启状态，且你的无线网卡在启动时已插入，那么你可能不需要做其他事情就可以访问互联网。只需按照以下步骤操作：

- 1. 点击网络管理器（Network Manager）组件，显示下拉菜单，显示附近存在的无线信号以及每个信号的强度（图 4-4）。
- 2. 从该菜单中通过点击选择你 WAP 的信号（或你想要连接的任何其他信号）。
- 3. 系统将尝试连接互联网，一旦建立连接，你将在网络管理器组件下方的消息中收到通知。网络管理器警报图标将变成一个小的强度指示器。非常方便。

注意：某些 WAP 采用了有线等效隐私（WEP）或更近期（且更安全）的 WEP 密钥形式的额外安全性。如果你尝试连接的 WAP 需要此类密钥，将弹出一个窗口提示你输入它。如果你恰好不知道密钥，那么你从根本就不应该建立该连接。真坏，真坏。

![](img/ba6b82a7869bba748202d57c97336dca_73_0.png)

图 4-4：网络管理器组件显示了可用无线网络及其信号强度

如果结果是你没有成功建立无线连接（系统会提示你），有几种情况可以避免这种恼人的不兼容场景。首先，双击检查确保你的网卡确实已开启。我知道这听起来很笨，但我曾多次犯过这个疏忽错误。

另一种可能性是你的网络利用了 DHCP，在这种情况下，你必须手动输入由网络管理员或服务提供商提供的连接设置。有了这些信息后，只需按照第 50 页“为非 DHCP 提供商设置电缆或以太网连接”中列出的步骤操作。只需确保在第 3 步点击**无线连接**而不是有线连接。

## 释放和刷新你的无线连接

有时你想要关闭无线网卡，例如当你在飞机上使用笔记本电脑时，或者你只是想刷新网络设置中的 IP 地址（释放）并用新网络的 IP 地址更新设置（刷新），因为你可能在不重启电脑的情况下从一个无线热点移动笔记本。

最后一点对你来说可能有点神秘，所以当你启动电脑时，你的无线网卡（NIC）会对可用网络（WAP）进行扫描，以查看它可以连接到哪一个。一旦找到一个网络，它就会通过 DHCP 从那里获取一个 IP 地址，以便你访问互联网。使用释放和刷新可以让你在无需重启电脑的情况下更换 WAP，或者当你的机器由于某种原因无法自行进行更改时。

要执行快速的释放/刷新操作，点击网络管理器组件以显示可用无线网络列表（即信号）。在列表中，点击你当前连接的网络。在二两秒内，你将收到已断开连接的通知。几秒后，你将收到已与同一网络建立连接的通知。哇。

好了，如何关闭无线网卡，特别是当你没有物理方式可以操作时？只需右键点击网络管理器组件，然后取消勾选“启用无线”（Enable Wireless）。非常简单。

噢，如果你想再次开启网卡，只需回到该菜单，然后再次选择“启用无线”。

## 设置拨号连接

世界上大部分地区正在转向高速互联网连接，但其中许多地方可能在使用拨号连接，这意味着你需要一个传统的拨号调制解调器来跨越你的盒子到达外部世界。以防宽带冲浪者忘记了，调制解调器是那些当你拨号到互联网服务提供商时会发出鸣叫、尖叫和吐声的奇妙机器。我想你可以把它们看作是吵闹的电话。

好消息是，设置拨号连接是一个简单的过程，与我目前为止涵盖的其他连接类型一样。现在是坏消息了——在 Linux 世界中，很少有内部调制解调器受到支持。这种兼容性问题背后的主要原因是大多数内置调制解调器取决于软件，而它们依赖的软件是 Windows 的一部分或为 Windows 设计的。此类调调器被称为 Winmodems。

## 外接拨号调制调器

所有解决方案中，也许是买一个外接调制调器是最安全的。外接调制调器放在电脑外的一个盒子里，连接到电脑背后的串口上，该端口通常是唯一带有细小针脚的连接器（见图 4-5）。因为调制调器不使用你的操作系统运行，因此它在忙碌时不会占用系统资源，这可能会导致电脑速度的提升。

## Firefox：你的网络浏览器

现在你已经连接到了互联网，你无疑想要开始进行一些网络世界的发现和探索，而最常用的方法就是使用网络浏览器。你 Ubuntu 系统中默认的网页浏览器是 Firefox，它不仅在 Linux 世界广受欢迎，在 Windows 和 Mac 世界也同样如此。你很可能已经是 Firefox 用户了，但如果你不是，也不必担心——所有浏览器中的功能大同小异。既然如此，你应该能够在无需任何指令的情况下使用 Firefox 的基本功能。当然，有些功能将 Firefox 与其竞争对手区分开来，我会提到它们。

### 使用标签页控制浏览器窗口混乱

通常，当你点击网页上的链接时，新页面会在同一个窗口中打开。在某些页面上，链接的编码使得新页面会在新的独立窗口中打开，或者你也可以通过右键点击链接并选择“在新窗口中打开链接”选项来选择在新窗口打开链接。这非常有用；但一旦你打开了多个窗口，就很难在所有打开的窗口中找到你要找的东西。它也会让速度变慢。
