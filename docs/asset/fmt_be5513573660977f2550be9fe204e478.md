
# 即时消息

即时消息软件是一种允许用户在网络上进行实时文本通信的数字工具。与电子邮件不同，这些对话是即时发生的，并提供了表情符号、语音通话、视频聊天和文件共享等功能。它对于快速更改非常高效，尽管缺乏事务控制且依赖于中央服务器，这引发了隐私担忧。某些服务还扩展到了聊天室和移动网络消息。尽管非常方便，但用户必须应对可能的服务暂停和隐私问题。

`Discord` 是一个用于即时消息、语音和视频通话的活力社交平台，通过服务器支持各种社区，用户可以在服务器中聊天、共享媒体并实时聚会。它拥有各大平台的应用程序和庞大的用户群，是游戏和各种兴趣小组的中心，提供了私人和小组通信技术、无缝交互的低延迟技术以及培养独特在线空间的自定义审核功能。`Discord` 将了日常对话的便利与加入一个更大社区的兴奋感，让数字聚会变得毫不费力且包容。

`ICQ` 是一款功能强大的即时通讯应用，提供私聊和群聊、消息和媒体的免费云存储，以及用于发布内容的匿名频道。它具有多达 25,000 名参与者的独特聊天、智能贴纸、实时摄像头滤镜以及使用昵称代替手机号码的功能。此外，`ICQ` 还提供了智能回答、语音消息转录、通话支持并在视频通话中使用 AR 滤镜。用户通过 `UIN` 识别，这是一种顺序数字系统，允许进行安全登录和账户恢复。

`Skype` 是微软一个分部门的软件，通过为数百万用户提供免费视频、语音通话和消息，彻底改变了全球通信。它支持多种设备，确保了可访问性。虽然基础功能免费，但电话通话和短信等额外服务需要付费。`Skype` 连接了商业世界，增强了协作。通过唯一的 `ID`，用户可以享受到即时消息、语音聊天等功能。它不支持紧急呼叫，但提供了如视频聊天背景模糊等创新功能。最近，它整合 `Bing AI` 聊天机器人，扩展了其功能。

`Session` 是一款由 `The Oxen Project` 创建的加密消息应用，优先考虑隐私。它适用于 `macOS`、`Windows`、`Linux`、`iOS` 和 `Android` 等主流平台，使用区块链网络进行安全通信，无需手机号码或电子邮件。相反，它使用唯一的 66 位数字 `ID`。尽管缺乏双重身份验证且协议仍在不断完善，但 `Session` 的加密已通过独立验证。它标志着传统方法的转变，提供了一种交换消息、语音备注和媒体的安全方式。

`Pidgin` 是一款多功能、免费且开源的即时消息客户端，通过支持多种协议简化了在线通信，允许用户通过一个界面连接到各种服务。它以 `Off-the-Record Messaging` 插件的强大加密而闻名，是隐私爱好者的喜爱，并包含在 `Tails OS` 中。凭借用户友好的 `GTK+` 界面、跨操作系统的兼容性以及通过插件增加功能的可扩展性（从协议到端到端加密等），`Pidgin` 成为即时消息需求的全面解决方案。

`Ferdium` 是一款多功能桌面应用，它将你喜爱的服务整合到一个平台以便于访问，消除了切换标签页或书签的麻烦。它允许同一服务的服务的多个账户，提供工作空间来区分个人和职业生活，并包含内置的待办事项面板。添加自定义服务非常简单，确保你不会受到应用初始提供的限制。`Ferdium` 优先考虑隐私，提供跨设备无缝访问的云同步，并能智能地休眠未使用的服务以节省资源。`Ferdium` 源自 `Franz`，在没有使用限制的情况下通过额外功能增强你的体验，并保持与现有的 `Franz` 账户兼容。

`Signal` 是一款安全的消息应用，通过先进的加密技术优先考虑隐私，确保没有人可以访问你的对话。它提供免费的文本、语音消息、照片、视频和通话，无需短信或 `MMS` 费用，即使是长距离。通过加密贴纸和群聊，`Signal` 增强了表达和连接，没有广告、追踪器或大型科技公司的背景。作为一个由用户捐支持的非营利组织，它代表了每个人的隐私和普及。

`Telegram` 是一款融合了通信和社交网络元素的多功能消息应用。它于 2013 年发布，支持消息、媒体共享以及语音或视频通话，并带有端到端加密以保护隐私。用户可以使用故事、大群组和用于广泛广播的频道。此外，`Telegram` 的开放 `API` 促进了自定义机器人和微型应用，丰富了用户交互。它适用于主流平台，因其注重安全性、用户友好的界面和丰富的功能脱颖而出。

## Discord

访问 `Discord` 官方网站 `https://discord.com/` 获取所有关于 `Discord` 的信息。

通过软件管理器安装 `DEB/FLATPAK` 程序包：

- 打开软件管理器并搜索 `Discord`。
- 点击 `Discord`，然后点击源选择框。
- 选择系统包或 `Flatpak` 并点击安装。

通过 `Snap Store` 安装 `Snap` 程序包：

- 在 `Snap Store` 中寻找 `Discord`。
- 点击 `Discord`，然后点击源选择框。
- 选择 `Snap` 下的最新/稳定版本并点击安装。

通过终端通过 `Snap` 安装 `Discord`：

输入此命令：

```bash
sudo snap install discord
```

通过终端通过 `Flatpak` 安装 `Discord`：

输入此命令：

```bash
flatpak install flathub com.discordapp.Discord
```

## 通过图形界面通过 .deb 安装 Discord

- 访问发布页面：`https://discord.com/api/download?platform=linux&format=deb`
- 进入 `~/Downloads`
- 双击 `discord-0.0.43.deb`
- 点击安装

## Skype

访问 `Skype` 官方网站 `https://www.skype.com/` 获取所有关于 `Skype` 的信息。

通过软件管理器安装 `DEB/FLATPAK` 程序包：

- 打开软件管理器并搜索 `Skype`。
- 点击 `Skype`，然后点击源选择框。
- 选择系统包或 `Flatpak` 并点击安装。

通过终端通过仓库安装 `Skype`：

输入以下命令：

```bash
sudo apt update
```

```bash
sudo apt install apt-transport-https
```

```bash
curl -s https://repo.skype.com/data/GPG-KEY | sudo apt-key add -
```

```bash
echo "deb https://repo.skype.com/deb stable" | sudo tee /etc/apt/sources.list.d/skype.list
```

```bash
sudo apt update

sudo apt install skype
```

通过 `Snap Store` 安装 `Snap` 程序包：

- 在 `Snap Store` 中寻找 `Skype`。
- 点击 `Skype`，然后点击源选择框。
- 选择 `Snap` 下的最新/稳定版本并点击安装。

通过终端通过 `Snap` 安装 `Skype`：

输入此命令：

```bash
sudo snap install skype
```

通过终端通过 `Flatpak` 安装 `Skype`：
