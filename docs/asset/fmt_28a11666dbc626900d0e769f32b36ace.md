### 引言

本课程涵盖如何使用命令行工具管理 Linux 文件和目录。

文件是具有名称和一组属性的数据集合。例如，如果你从手机传输一些照片到电脑并给它们命名描述性名称，那么你现在电脑上拥有一堆图像文件。这些文件具有属性，如文件最后访问或修改的时间。

目录是一种特殊的文件，用于组织文件。思考目录的好方法是把它们想象成柜中组织文件的文件夹。与文件文件夹不同，你可以轻松地将目录放在其他目录内部。

命令行是管理 Linux 系统文件最有效的方法。Shell 和命令行工具的特性使得使用命令行比图形化文件管理器更快、更方便。

在本节中，你将使用命令 `\ls`, `mv`, `cp`, `pwd`, `find`, `touch`, `rm`, `rdir`, `echo`, `cat` 和 `mkdir` 来管理和组织文件及目录。

### 大小敏感

与 Microsoft Windows 不同，Linux 系统上的文件和目录名称是大写敏感的。这意味着 `/etc/` 和 `/ETC/` 是不同的目录。尝试以下命令：

```
$ cd /
$ ls
bin dev home lib64 mnt proc run srv tmp var
boot etc lib media opt root sbin sys usr
$ cd ETC
bash: cd: ETC: No such file or directory
$ pwd
/
$ cd etc
$pwd
/etc
```

`pwd` 显示你当前所在的目录。如你所见，切换到 `/ETC` 没有作用，因为没有这样的目录。切换到存在的目录 `/etc` 则成功了。

### 创建目录

`mkdir` 命令用于创建目录。

让我们在主目录中创建一个新目录：

```
$ cd ~
$pwd
/home/user
$ ls
Desktop Documents Downloads
$ mkdir linux_essentials-2.4
$ ls
Desktop Documents Downloads linux_essentials-2.4
$ cd linux_essentials-2.4
$ pwd
/home/emma/linux_essentials-2.4
```

在本课程期间，所有命令将在该目录或其任一子目录中执行。

要从文件系统的任何其他位置轻松返回课程目录，你可以使用命令：

```
$ cd ~/linux_essentials-2.4
```

Shell 将字符 `~` 解释为你的主目录。

当你位于课程目录时，创建一些我们将用于练习的目录。你可以一次性将所有用空格分隔的目录名称添加到 `mkdir` 中：

```
$ mkdir creating copying/files copying/directories deleting/directories
deleting/files globs
mkdir: cannot create directory 'copying/files': No such file or directory
mkdir: cannot create directory 'copying/directories': No such file or directory
mkdir: cannot create directory 'deleting/directories': No such file or directory
mkdir: cannot create directory 'deleting/files': No such file or directory
$ ls
creating globs moving
```

注意错误信息，以及只有 `moving`、`globs` 和 `creating` 被创建了。`copying` 和 `deleting` 目录不存在。默认情况下，`mkdir` 不会在不存在的目录内创建目录。`-p` 或 `--parents` 参数指示 `mkdir` 在父目录不存在时创建它们。尝试使用 `-p` 选项运行相同的 `mkdir` 命令：

```
$ mkdir -p creating moving copying/files copying/directories deleting/directories
deleting/files globs
```

当你没有收到任何错误信息。让我们看看现在哪些目录存在：

```
$ find
./creating
./moving
./globs
./copying
./copying/files
./copying/directories
./deleting
./deleting/directories
./deleting/files
```
