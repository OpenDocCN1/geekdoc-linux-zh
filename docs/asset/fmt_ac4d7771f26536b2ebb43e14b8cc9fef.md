## 有机光化学

处理光诱导的有机物质变化的化学分支。由于研究电磁辐射与物质的相互作用，光化学涉及化学和物理两个方面。因此，在考虑光化学过程时，也必须考虑不涉及严格化学变化的物理现象，例如光的吸收和发射，以及电子能量转移。

由于已知几种天然光化学过程发挥重要作用（即植物的光合作用、视觉过程、向光性），有机光化学的研究在二十世纪初期就开始了。然而，突破仅在1950年之后才出现，当时商用的紫外线辐射源以及用于核磁共振（NMR）波谱和色谱分析的现代分析仪器变得可用。

通常，由于单键的自由旋转，大多数有机化合物由快速互变且不可分离的构象体组成。每个构象体具有特定的能量和给定的电子吸收光谱。这是有机化合物在溶液中产生宽吸收带的原因之一。构象体的平衡可能受溶剂和温度的影响。根据弗兰克-康登原理（该原理指出，通过吸收光子使电子跃迁的速度远快于单个振动），每个构象体将具有其自身的激发态构型。*参见* **构象分析，分子结构和光谱**。

由于底物激发时 $\pi$-键级的变化以及第一激发态的短寿命，激发态构象体并不处于平衡状态，且各自生成其特定的光产物。尽管不同的构象体可能导致相同的光产物，且一个激发态构象体可能导致几种光产物，但溶剂、温度或激发波长的变化会影响光产物的组成。这对于小分子尤为明显；带有芳香基团的大分子对波长的微小变化敏感度较低。

当初级光产物也吸收光并进而生成另一种光产物时，波长的影响也很重要。通过使用滤光片或单色器分别进行选定波长或单色光激发，可能对选择性生成初级光产物有益。同样，在低温下辐照有助于检测那些受热不稳定的初级光产物（热不稳定）。*参见* **色滤，WHEELER**。

## 有机反应机理

对有机化合物反应如何进行的完整、逐步描述。一个详尽的机理将关联反应物的原始结构与产物的最终结构，并解释反应进程中结构和能量的变化。它还应解释中间体的形成以及各种物种相互转化的速率。由于无法直接检测所有这些细节，反应机理的证据总是间接的。实验设计旨在产生结果为（但永远无法绝对证明）机理提供逻辑证据。对于大多数有机反应，基于大量实验证据，存在被认为是确立的机理。然而，经常会出现提供对机理新细节进一步洞察的新数据，并偶尔需要对已接受的机理进行彻底修订。

### 有机反应分类

描述有机反应机理通常包括指定总反应（例如，取代、加成、消除、氧化、还原或重排），反应中间体的存在（即，碳正离子、碳负离子、自由基、自由基离子、卡宾或激发态），引发反应的试剂性质（如亲电或亲核），是否存在催化作用（如酸或碱），以及任何特定的立体化学。例如，反应 (1) 可描述为烷基卤化物的协同亲核取代，该过程伴随立体化学反转。在单步进行中，没有中间体的反应被描述为协同或同步。反应 (1) 是 `S_N2` 机理（取代，亲核，双分子）的一个例子。

除了识别原始反应物和最终产物的能量水平外，势能图还指示了沿反应路径最高点的能量水平，称为过渡态。由于过渡态代表分子沿反应路径前进时必须达到的最高能量，因此过渡态的能量水平是反应容易发生程度的关键指标。使过渡态更稳定（能量更低）的特征会使反应更有利。这些稳定化特征可能是分子内的，如取代基的电子给予或撤回，或分子间的，如溶剂稳定化。参见 化学键；能量。

### 动力学

说明反应机理中涉及各个步骤的另一种方式是作为动力学方案，展示所有单个步骤及其速率常数。`S_N2` 机理是单步的，动力学必须代表该步骤；观察到速率取决于有机底物和亲核试剂两者的浓度。然而，对于多步机理，动力学可以是区分替代路径存在的有力工具。例如，当取代度更高的烷基卤化物发生亲核取代时，速率与亲核试剂的浓度无关。这一证据表明这是一种两步机理，称为 `S_N1` 机理，如反应方案 (2) 所示，其中 `k` 项代表速率常数。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1582_1.png)

`S_N1` 机理实现了相同的烷基卤化物总亲核取代，但通过离去基团（`Br⊖`）的初始解离形成碳正离子来完成，步骤 (2a)。随后，亲核试剂附着在碳正离子上形成最终产物，步骤 (2b)。在待取代碳原子周围体积较大的基团的烷基卤化物，较难通过直接的 `S_N2` 机理进行取代，因为亲核试剂在形成键到难以接近的位置时遇到困难（称为空间位阻）。如果这些烷基带有能够支持碳正离子结构的取代基，通常通过电子给予，那么 `S_N1` 机理就变得更可取。

多步反应机理的一个关键特征是确定速率决定步骤。总反应速率不可能快于其最慢的步骤。在 `S_N1` 机理中，断键反应 (2a) 通常比成键反应 (2b) 慢得多。因此，观察到的速率仅为第一步的速率。因此，动力学可以区分 `S_N1` 和 `S_N2` 机理，如方程 (3) 和 (4) 所示，其中 `R` 是烷基，`X` 是卤素或其他离去基团，`Nu` 是亲核试剂，括号内的项代表浓度。

速率 = `k [RX] [Nu]` 对于 `S_N2` 机理 (3)

速率 = `k [RX]` 对于 `S_N1` 机理 (4)

当观察到过量离去基团的存在 [例如反应 (2) 中的 `Br⊖`] 会影响速率（称为共同离子速率抑制）时，人们认识到对 `S_N1` 机理更完整的描述。这表明机理应包括一个逆向步骤 [反应步骤 (2a) 中的 `k_-1`]，其中离去基团返回阳离子，再生起始材料。在这种情况下，速率以复杂方式取决于亲核试剂和离去基团与碳正离子反应的竞争。参见 化学动力学；反应中间体；稳态动力学。

### 活化参数

速率常数的温度依赖性为速率决定步骤的过渡态提供了重要信息。阿伦尼乌斯方程 (5) 以温度的指数函数和活化能 `E_a` 表达这种依赖性；`A` 称为阿伦尼乌斯因子或指前因子，`R` 是气体常数。参见 气体；对数。

```
k = A e^{−Ea/RT} (5)
```

活化能代表反应物和过渡态之间的能量差，即为了成功沿反应路径从反应物到产物前进必须提供的能量量。

### 立体电子化学

仔细关注反应的立体化学通常对分子在通过反应机理时的特定取向提供关键洞察。在 `S_N2` 机理中观察到的完全立体化学反转提供了亲核试剂背面攻击的证据。通过 `S_N1` 机理发生取代的烷基卤化物不显示特定的立体化学，因为离去基团的丧失与亲核试剂的成键完全无关。
