
`decimal` 的各种属性（如精度和舍入）通过使用 `Context(prec=None, rounding=None, traps=None, flags=None, Emin=None, Emax=None)` 来控制。这创建了一个新的上下文。默认值为 'E'。`Emin` 和 `Emax` 是表示最小和最大范围的整数。`exact` 是表示溢出的布尔值。

`Context()` 的 `traps` 和 `flags` 参数是信号列表。计算期间可能发生的算术异常类型。除非列在 `traps` 中，否则信号将被忽略；否则，将抛出异常。定义了以下信号：

# 246 第 14 章 数学

## 信号

| 信号 | 说明 |
| :--- | :--- |
| Clamped | 指数已调整以适应允许的范围。 |
| DivisionByZero | 非无限数除以 0。 |
| Inexact | 发生了舍入误差。 |
| InvalidOperation | 执行了无效操作。 |
| Overflow | 舍入后指数超过了 `Emax`。也会产生 `Inact` 和 `Rounded`。 |
| Rounded | 发生了舍入。即使没有丢失信息也可能发生（例如，"1.00" 舍入为 "1.0"）。 |
| Subnormal | 指数小于之前的舍入值。 |
| Underflow | 数值下溢。结果被舍入为 0。也会产生 `Inact` 和 `Subnormal`。 |

这些信号名称对应于可以用于错误检查的 Python 异常。这是一个示例：

```python
x = a/b
except decimal.DivisionByZero:
    print "Division by zero"
```

与异常一样，信号被组织成层级结构：

- `ArithmeticError`（内置异常）
    - `DecimalException`
        - `Clamped`
        - `DivisionByZero`
        - `Inexact`
        - `Overflow`
        - `Underflow`
        - `InvalidOperation`
    - `Rounded`
    - `Overflow`
    - `Underflow`
- `Subnormal`

`Overflow` 和 `Underflow` 信号在表中出现多次，是因为它们也会导致父信号（例如，`Underflow` 也会触发 `Subnormal` 信号）。`decimal.DivisionByZero` 信号也派自内置的 `DivisionByZero` 异常。

在许多情况下，算术信号会被静默忽略。例如，计算可能会产生舍入误差但不会抛出异常。在这种情况下，可以使用信号名称来检查指示计算状态的一组标志。这是一个示例：

```python
ctxt = decimal.getcontext() # 获取当前上下文
x = a + b
if ctxt.flags[Rounded]:
    print "Result was rounded!"
```

当标志被设置后，它们会一直保持设置状态，直到使用 `clear_flags()` 方法清除。因此，你可以执行一整个序列计算，只在最后检查错误。

对现有 `Context` 对象 `c` 的设置可以通过以下属性和方法进行更改：

```python
c.capitals
```

设置为 1 或 0 的标志，决定使用 `E` 还是 `e` 作为指数字符。

```python
c.Emax
```

指定最大指数的整数。

```python
c.Emin
```

指定最小指数的整数。

```python
c.prec
```

指定精度位数的整数。

```python
c.flags
```

包含与信号对应的当前标志值的字典。例如，`c.flags[Rounded]` 返回 `Rounded` 信号的当前标志值。

```python
c.rounding
```

正在生效的舍入规则。例如 `ROUND_HALF_EVEN`。

```python
c.traps
```

包含导致 Python 异常的信号的 True/False 设置的字典。例如，`c.traps[DivisionByZero]` 通常为 True，而 `c.traps[Rounded]` 为 False。

```python
c.clear_flags()
```

重置所有粘性标志（清除 `c.flags`）。

```python
c.copy()
```

返回上下文的副本。

```python
c.create_decimal(value)
```

使用 `c` 作为上下文创建新的 `Decimal` 对象。这在生成精度和舍入行为覆盖默认上下文的数字时非常有用。

### 函数和常量

以下函数和常量由 `decimal` 模块定义。

```python
getcontext()
```

返回当前的 decimal 上下。每个线程都有自己的 decimal 上下文，因此它返回调用线程的上下文。

```python
localcontext([c])
```

创建一个上下文管理器，对于 `with` 语句体内部定义的语句将当前 decimal 上下文设置为 `c` 的副本。如果省略了 `c`，则创建当前上下文的副本。这是一个使用该函数的示例，它临时为一组语句将精度设置为五位小数：

```python
with localcontext() as c:
    c.prec = 5
    statements
```

```python
setcontext(c)
```

将调用线程的 decimal 上下文设置为 `c`。

### BasicContext

具有 9 位精度的前提。舍入规则为 `ROUND_HALF_UP`；`Emin` 为 -99999999；`Emax` 为 99999999；除了 `Inexact`、`Rounded` 和 `Subnormal` 之外，所有陷阱均启用。

### DefaultContext

创建新上下文时使用的默认上下文（存储此处的值用作新上下文的默认值）。定义了 28 位精度；`ROUND_HALF_EVEN` 舍入规则；以及针对 `Overflow`、`InvalidOperation` 和 `DivisionByZero` 的设置。

### ExtendedContext

具有 9 位精度的前提。舍入规则为 `ROUND_HALF_EVEN`，`Emin` 为 -99999999，`Emax` 为 99999999，且所有陷阱均禁用。抛出异常。结果可能是 `NaN` 或 `Infinity`。

### Inf

等同于 `Decimal("Infinity")`。

### negInf

等同于 `Decimal("-Infinity")`。

### NaN

等同于 `Decimal("NaN")`。

### Examples

以下是一些显示 decimal 数字基本用法的示例：

```python
>>> a = Decimal("42.5")
>>> b = Decimal("37.1")
>>> a + b
Decimal("79.6")
>>> a / b
Decimal("1.1455255250646900269541778976")
>>> divmod(a,b)
Decimal("1", Decimal("5.4"))
>>> max(a,b)
Decimal("42.5")
>>> c = [Decimal("42.5"), Decimal("37.1")]
>>> sum(c)
Decimal("79.6")
```

以下是使用 `Fraction` 实例的某些示例（使用上一个示例中创建的值）：

```
>>> f + g
Fraction(5, 2)
>>> f + g
Fraction(21, 16)
>>> b.limit_denominator(10)
Fraction(22, 7)
>>>
```

`fraction` 模块还定义了一个函数：

```
gcd(a, b)
```

计算整数 `a` 和 `b` 的公约数。如果 `b` 不为零，则结果与 `b` 符号相同；否则，与 `a` 符号相同。

### math

`math` 模块定义了以下标准数学函数。这些函数作用于整数和浮点数，而不是复数（可以使用另一个模块 `cmath` 来对复数执行类似的操作）。所有函数的返回值均为浮点数。所有三角函数均假设使用弧度。

| 函数 | 说明 |
|---|---|
| `acos(x)` | 返回 `x` 的反余弦。 |
| `acosh(x)` | 返回 `x` 的双曲余弦。 |
| `asin(x)` | 返回 `x` 的反正正弦。 |
| `asinh(x)` | 返回 `x` 的双曲正弦。 |
| `atan(x)` | 返回 `x` 的正切。 |
| `atan2(y, x)` | 返回 `atan(y / x)`。 |
| `ath(x)` | 返回 `x` 的双曲正切。 |
| `ceil(x)` | 返回 `x` 的向上取整。 |
| `copysign(x,y)` | 返回与 `y` 符号相同的 `x`。 |
| `cos(x)` | 返回 `x` 的余弦。 |
| `cosh(x)` | 返回 `x` 的双曲余弦。 |
