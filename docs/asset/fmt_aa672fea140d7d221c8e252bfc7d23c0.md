# 使用 bulk_extractor 进行数据提取

`bulk_extractor` 能够提取出若干种额外类型的信息，这些信息在调查中非常有用。尽管 `bulk_extractor` 能够很好地恢复和刻取图像、视频和文档文件，但 `bulk_extractor` 能够刻取和提取的其他数据还包括：

- 信用卡号
- 电子邮件地址
- URL
- 在线搜索
- 社交媒体简介和信息
