## 监控过时磁盘分区

监控过时磁盘分区是 AIX 技术。要理解这一章，你需要熟悉 AIX 操作系统的核心逻辑卷管理器 `LVM`。我们将在下一节介绍 `LVM`。在高级别，过时磁盘分区意味着镜像磁盘不同步。有时当你发现过时分区时，你可以重新同步镜像，一切都会正常。如果镜像无法同步，你可能已经看到了磁盘故障的早期迹象。

在本章中，我们将查看监控过时分区的三种方法：

- 在逻辑卷 `LV` 级别进行监控
- 在物理卷 `PV` 或磁盘级别进行监控
- 在卷组 `VG`、`PV` 和 `LV` 级别进行监控以获取全景

这三种方法都会报告过时磁盘分区的数量，但了解参与未同步镜像的 `VG`、`PV` 和 `LV` 是很有用的。我们将逐步构建这些 shell 脚本的整个过程，从查询系统所需的命令语法开始。在我们开始编写之前，我想向你提供 AIX `LVM` 以及我们将要使用的命令的高级概述。
