## 使用存储介质

在 Linux 中，你可以在硬盘之外存储介质上存储数据。你可以使用外部存储介质（如软盘、`zip` 磁盘或 `CD`）来存储文件。这有助于在系统崩溃时恢复数据。Linux 和 Windows 在使用外部存储介质方面最重要的区别是：在 Windows 中，你只需插入磁盘即可使用，而在 Linux 中，你必须先挂载（`mount`）磁盘驱动器才能使用。挂载磁盘磁盘的过程简单易懂。当你在 Linux 中挂载一个设备时，该设备的文件系统也会被挂载。当你在 Linux 中挂载驱动器或设备时，会为该驱动器或设备创建一个目录，并通过该特定目录访问驱动器或设备。此类目录是通过名为 `/mnt` 的目录创建的。例如，如果你挂载了一个软驱驱动器，可以通过名为 `/mnt` 的目录进行访问。

在本节中，你将使用 `df` 命令检查硬盘空间；将数据导出到可移动介质；查看 Linux 中的文件系统列表；挂载 `DVD-RW` 驱动器以及访问 `CD`/`DVD`。让我们从学习检查硬盘空间开始。
