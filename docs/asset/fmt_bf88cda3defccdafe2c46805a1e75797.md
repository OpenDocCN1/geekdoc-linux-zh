
### 5. C

计算机的 IP 地址和网络掩码（即子网掩码或网络掩码；选项 D）是 TCP/IP 网络配置最重要的组件。对于许多网络，你可能需要提供的额外信息包括 DNS 服务器的 IP 地址、路由器的主机名或 IP 地址以及计算机 DHCP（选项 A）。如果存在 DHCP 服务器，你应该使用 DHCP 而不是静态 IP 分配。NetBIOS 命名服务（NBNS）（选项 B）在 NetBIOS 网络上转换名称和 IP 地址。时间协议（NTP）（选项 E）帮助你维护所有计算机的系统时间，但基础网络配置并不需要它。更多信息请参见第 8 章“配置基础网络”。

### 6. wc

`wc` 命令显示指定文件（`report.txt`）中的数字、单词和字节计数。管道此数据会导致输出的副本存储在新文件（`wc`）中——不要在执行文件的目录下运行此命令！因此，选项 E 是正确的。与选项 A 相比，`wc` 不是编辑器，如果是编辑器，剩余的语法将打开文件。与选项 B 相比，`wc` 不计算窗口或打开新窗口。选项 C 描述了一切。与选项 D 相比，`wc` 与清理内存无关，也不直接使用 `report.txt` 文件。更多信息请参见第 1 章“探索 Linux 命令行工具”。

### 7. grub.cfg

`grub.cfg` 文件是一个 GRUB 2 文件。在这些文件中，每个操作系统或内核都以 `menuentry` 和一个左括号（`{`）开始，并以一个右括号（`}`）结束。因此，选项 C 是正确的。某些配置文件和编程语言在行尾使用分号，但 GRUB 2 不是这样的，选项 A 是错误的。虽然括号（`()`）在某些配置文件用于终止某些类型的选项，但在 GRUB 2 配置文件中使用磁盘标识符不会终止文件中的操作系统或内核定义，因此选项 B 是错误的。字符串 `""` 在 C 程序文件中终止术语，但在 GRUB 2 文件中未使用，因此选项 D 是错误的。在 GRUB Legacy 配置文件（`menu.lst` 或 `grub.conf`）中，两个启动加载以不同的方式结束操作系统/内核段，因此选项 E 是错误的。更多信息请参见第 5 章“启动 Linux 和编辑文件”。

### 8. /etc/passwd

`/etc/passwd` 目的第三字段持有账户的 UID，因此选项 E 是正确的。Linux 不使用任何名为 `human`（HID）的标准标识符；选项 A，虽然 HID 代表人机接口，这是一类 USB 设备。账户没有 PID 号（选项 B）；这些属于运行中进程的。账户的 GID 号（选项 C）存储在 `/etc/passwd` 的第四字段中——在本例中为 100。账户不使用全局 ID（GUID）数，因此选项 D 是错误的。更多信息请参见第 7 章“管理系统”。

### 9. grep

`grep` 命令查找包含指定字符串或模式的文件，如选项 B 所示。在文本文件的情况下，`grep` 显示该行或几行；对于二进制文件，它报告文件匹配模式。创建管道的方法（选项 A）涉及使用竖线 (`|`) 分隔两个命令。`grep` 可以用于管道，但它并不创建管道。连接文件的命令（选项 C）是 `cat`，显示文件最后几行的命令（选项 D）是 `tail`。但

`grep` 不属于这些命令之一。欲了解更多信息，请参阅第 1 章“探索 Linux 命令行工具”。

### 10. B, D, E

ReiserFS（选项 B）是为 Linux 从零编写的。第三代扩展文件系统 (ext3)；选项 D 是基于较旧的非日志第二代扩展文件系统 (ext2fs) 的日志文件系统；选项 C 是区段文件系统 (XFS)；选项 E 是由 SGI 为 Irix 设计并后移植到 Linux 的日志文件系统。高性能文件系统 (HPFS)；选项 A 是微软为 OS/2 设计的非日志文件系统。欲了解更多信息，请参阅第 3 章“配置硬件”。

### 11. A

正确描述了在此语境下 SSH 和 SSL 的功能。选项 B 是错误的，因为 SSH 应该能够很好地加密你的电子邮件，使其无法被你的系统和互联网服务提供商（ISP）邮件服务器解码。选项 C 反了；通过 SSH 传输的电子邮件将完全加密，包括标头信息，而 SSL 不解密标头，只解密正文。选项 D 是错误的，因为 SSL 不是病毒扫描器，它只是一个加密工具。选项 E 是错误的，因为 SSH 隧道加密所有内容，包括附件。欲了解更多信息，请参阅第 10 章“保护你的系统”。

### 12. A, D

端口 110（选项 A）被分配给互联网访问邮件协议 (IMAP)，两者均可从邮件服务器系统检索消息。端口 119（选项 B）被分配给网络新闻传输协议 (NNTP)，端口 139（选项 C）被分配给服务器块/通用网络文件系统 (SMB/CIFS) 协议，端口 443（选项 E）分配给带有 SSL 加密的超文本传输协议 (HTTPS)，这些都不常用于检索邮件。欲了解更多信息，请参阅第 8 章“配置基础网络”。

### 13. C

日志文件（如 `/var/log/messages` 以及有时 `/var/log` 中的其他文件）包含了服务器错误的有用信息。`tail` 程序显示文件的最后几行，因此在问题发生后使用它检查日志文件是一个非常有用的诊断方法。选项 C 正确地结合了这些功能。选项 A 的 `http://localhost:631` URL 访问的是 Unix 打印系统 (CUPS) 配置，与 SSH 无关。没有标准的诊断工具（选项 B）来帮助诊断服务器问题，也没有 `/dev/ssh` 文件（选项 D）。`sshd` 是 SSH 服务器，因此选项 B 仅仅会启动服务器。欲了解更多信息，请参阅第 5 章“启动 Linux 和编辑文件”。

### 14. B

`/profile` 文件是多个启动脚本之一，如选项 B 所示。它与选项 C 中的 ProFTPD 服务器文件管理器无关，后者是虚构的。用户的加密密码（选项 E）通常存储在 `/etc/shadow` 中。欲了解更多信息，请参阅第 9 章“编写脚本、配置电子邮件和使用数据库”。

### 15. E

`at` 工具用于在指定的未来时间点运行程序。因此，选项 A 和 C 可能有效；但它们都不是实现此目标的最佳方法。选项 A 会占用 CPU 时间，如果程序崩溃或系统在间隔期间关闭，消息将永远不会显示。选项 C 会更可靠，但它为你的每小时 `cron` 任务增加了不必要的复杂性。`cal` 程序显示文本模式日历，让你能够识别给定月份的星期几；它不像 B 建议的那样调度未来的作业。如 D 指定的 GUI 日历程序可能有效；但 NTP 是网络时间协议，一种用于同步跨网络时钟的协议和同名程序。因此，NTP 不是该任务的工具，选项 D 是错误的。欲了解更多信息，请参阅第 7 章“系统管理”。

### 16. D

选项提供了将 172.24.21.1 添加为默认网关的正确命令。选项 A 和 B 使用了虚构的 `gateway` 命令，它不存在，除非你为它创建了一个脚本，否则无法工作。选项 C 使用了正确的命令，但没有用于路由的 gateway 选项；你必须使用选项 D 那样的 `add default`。没有标准的 `gw` 命令，选项 E 是错误的。欲了解更多信息，请参阅第 8 章“配置基础网络”。

### 17. C

`BRLTTY` 软件包用于盲文显示器的附加守护进程，这些设备的某些功能已添加到 2.6 内核中，选项 B 和 C 是正确的。Emacspeak（选项 A）是语音转文本软件；它可以向用户“读出”文本显示，但它没有盲文驱动程序的接口。G（选项 D）是屏幕软键盘，帧缓冲区驱动程序（选项 E）是管理显卡的驱动程序；它们不是用来使用的。欲了解更多信息，请参阅第 6 章“窗口系统、本地化和打印”。

### 18. C

某些依赖关系源于编译时的动态链接库，通过编译源码可以解决这些问题，因此 C 是正确的。A 描述的是 Debian 软件包。Tarball（压缩包）需要进行编译才能使用，而不是 RPM 软件包。此选项 E 是限制性的。欲了解更多信息，请参阅第 2 章“管理软件包”。

### 19. D

`mv` 工具用于重命名文件并将其移动到另一个位置，因此 D 是正确的。`dd`（选项 A）用于复制文件，`rm`（选项 B）删除文件，`cp`（选项 C）复制文件，`ln`（选项 E）创建链接。

添加 `&` 用于在后台执行程序，这会占用 CPU 时间，因此 B 是正确的。`at` 工具用于在指定的未来时间点运行程序，因此选项 A 和 C 可能有效；但它们都不是实现此目标的最佳方法。如果程序崩溃或系统在间隔期间关闭，消息将永远不会显示。选项 C 会更可靠，但它为你的每小时 `cron` 任务增加了不必要的复杂性。`cal` 程序显示文本模式日历，让你能够识别给定月份的星期几；它不像 B 建议的那样调度未来的作业。如 D 指定的 GUI 日历程序可能有效；但 NTP 是网络时间协议，一种用于同步跨网络时钟的协议和同名程序。因此，NTP 不是该任务的工具，选项 D 是错误的。欲了解更多信息，请参阅第 7 章“系统管理”。

### 21. A, B

`fsck` 是 Linux 的文件系统工具。`-U` 参数用于升级软件包（选项 A），但这在软件包已安装的情况下。`-i` 参数用于安装软件包，这是错误的。选项 C 描述的是软件包名称，而不是完整的文件名。`-e`（选项 E）用于移除软件包。欲了解更多信息，请参阅第 2 章“管理软件包”。
