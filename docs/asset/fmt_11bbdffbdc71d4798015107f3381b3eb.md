
# 基因印记与性染色体遗传

一些遗传性状表达上的性别差异可能源于基因印记。基因印记指的是染色体、染色体部分或单个基因的不同表达，具体取决于它们是从两种性别中的哪一种遗传而来。为了实现印记，一些遗传物质可以在两种性别之一的配子产生或早期胚胎发育过程中被修饰，使得由印记基因决定的性状与典型的孟德尔遗传预期不同。越来越多的证据指向胞嘧啶残基在胞嘧啶-鸟嘌呤（CpG）二核苷酸背景中的甲基化作为印记的机制。这种甲基化，特别是如果发生在基因的启动子区域，可以使基因无法被转录。某些可以被印记的基因会在精子产生过程中被甲基化，其他则会在卵子产生过程中被甲基化，当它们通过相反性别的配子发生时，可以通过去甲基化重新激活。目前尚不清楚为什么某些等位基因受印记影响而其他基因不受影响，以及为什么它们在一种性别中比另一种性别更可能被印记。

红绿色盲是第一个被证明是由于特定染色体上的基因导致的人类性状。这种遗传模式的特点很容易看出。男性比女性受影响更明显或更严重；在红绿色盲的情况下，拥有一个突变基因拷贝的女性（即杂合子或携带者）完全不受影响。在一个色盲男人和一个女人的后代中，他们的一半儿子受影响，而一半女儿是携带者。受影响的父亲不能将他们的突变 X 染色体传给他们的儿子，但会传给所有的女儿，从而使她们成为携带者。许多其他知名的人类疾病也表现出这种行为，包括两种类型的血友病、杜氏肌营养不良以及葡萄糖-6-磷酸脱氢酶缺乏症，后者容易导致溶血性贫血。参见 贫血；色觉；血友病；肌营养不良。

印记可以涉及基因的扩增而不是灭活；即，当基因在一种性别的配子发生过程中通过时，其部分被复制，从而基因变大。这在神经母细胞瘤中可见，在那里人们通常发现含有 `N-myc` 原癌基因的 DNA 片段数量增加：这种扩增与疾病的预后不良相关。在绝大多数病例中，被扩增的是父源 `N-myc` 基因，这表明印记负责。类似的现象发生在亨廷顿舞蹈病中，这是一种常染色体显性遗传病，通常要到中年或更晚才会表现出来。更早的表现，甚至有时在儿童时期，与基因中某些 DNA 片段的扩增有关；但扩增，如果发生的话，仅存在于从父亲遗传的 `HC` 基因中。参见 脱氧核糖核酸（DNA）；遗传学。

精细的细胞遗传学和分子技术已补充了家庭研究，作为表征性连锁遗传和在许多物种中将基因映射到性染色体的方法。超过 400 个人类性状和疾病似乎由 X 染色体上的基因编码，其中超过 200 个已被映射。在哺乳动物中，X 染色体上的基因高度保守。因此，在小鼠中识别出性连锁性状是强证据，表明类似性状及其底层基因存在于人类 X 染色体上。参见 遗传学；人类遗传学；性别影响遗传。

## 六分仪

用于测量角度的航海仪器，主要是天体的仰角。最初，六分仪具有 60° 的弧，即圆的 1/6，因此仪器由此得名。由于使用的双重反射原理，仪器可以测量高达 120° 的角。在现代实践中，无论弧的长度如何（很少正好是 60°），六分仪的名称通常应用于此类所有仪器。六分仪的光学原理与棱镜六分仪相似。参见 棱镜六分仪。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_2003_0.png)

现代六分仪可分为两类：船用六分仪和航空六分仪。船用六分仪（见插图）是为航海者设计的。它利用可见的海平线作为水平参考面。设计用于飞机上的仪器称为航空六分仪。此类六分仪内置人工地平仪。大多数现代航空六分仪均为周期性设计，以便在无需机载天文罩的情况下观测天体。参见 天文导航。

### 两性异形

同一物种中雄性和雌性之间在形态或行为上的任何差异。在许多动物中，个体的性别可以一目了然地判断出来。例如，公鸡拥有鲜艳的羽毛、鸡冠和华丽的尾巴，而母鸡则缺乏这些特征。两性异形是两种性别不同繁殖功能的结果，也是自然选择和性选择共同作用的后果。诸如生殖器官结构等初级差异由自然选择驱动，是个体作为母亲或父亲功能的关键。而其他差异，如孔雀（`Pavo cristatus`）巨大的尾巴，则由性选择驱动，增加了个体获取配偶的成功率。参见 有机进化。

一种不太明显的两性异形是雄性和雌性配子大小的差异。在几乎所有情况下，精子（或花粉）比卵子小得多且数量更多。卵子之所以大，是因为它们包含胚胎发育所需的重要营养物质。然而，精子的唯一目的是受精卵子。精子不含任何营养物质，因此可以很小。在相同的营养物质投入下，雄性产生的精子数量多于雌性产生的卵子数量。例如，人类男性每次射精产生约3亿个具有运动能力的精子，而女性通常每月只产生一个卵子（单个卵子的体积是单个精子的3万倍）。参见 受精；配子发生；繁殖（动物）；生殖系统。

在几乎所有动物类群中（哺乳动物和鸟类除外），雌性都比雄性大，因为较大的雌性倾向于产生更多的卵子，并向下一代贡献更多的后代。相比之下，体型似乎并不限制雄性产生精子的能力。然而，在哺乳动物和鸟类中，雄性通常是体型较大的性别。体型和形状的差异可能由除繁殖成功之外的其他因素引起。两性异形可能是性别间资源竞争的结果，或者是因为两性利用不同的资源。例如，在许多蛇类物种中，雄性和雌性使用不同的栖息地并摄取不同的食物，这导致了它们在头部形状和取食结构上的差异。

植物也展现出明显的显眼度差异。许多植物同时具有雄花和雌花（同时雌雄同体），但雄花有时更大且更醒目。例如，与鲜黄色的雄性柔荑相比，柳树的雌性柔荑呈暗淡的灰色，因为雄花必须相互竞争以吸引传粉者。在具有分离性别的植物物种（雌雄异株）中，雄性倾向于比雌性产生更多的花朵。例如，美洲冬青（`Ilex opaca`）的雄性产生的花朵数量是雌性的七倍，以增加花粉向雌性转移的机会。参见 花；传粉。

动物和植物在其他性状上也表现出显著的两性异形。鸣叫、歌唱、信息素和气味标记都可以用雄性之间的竞争以及雌性的配偶选择来解释。参见 动物交流。

与形态学上的两性异形相关的是雄性和雌性之间的一些行为差异。其中许多与寻找配偶、雄性之间的竞争以及雌性的挑剔性有关。动物还表现出与其父母角色相关的两性异形。许多父母在后代出生后继续为其提供照顾，在大多数物种中，雌性承担大部分护理工作。哺乳动物雌性哺乳后代，而雄性由于缺乏乳腺而无法做到。然而，一些哺乳动物（如长臂猿和草原田鼠）和许多鸟类共同分担父母职责，雄性和雌性都喂养和保护后代。参见 母性行为。

### 性传播疾病

通过性接触获取和传播的感染。虽然几乎任何感染都可能在亲密接触中传播，但“性传播疾病”这一术语仅限制于主要依赖性接触在其种群中进行传播和流行的疾病。“性病”（venereal disease）一词在字面上与性传播疾病同义，但传统上仅与五种长期认可的疾病相关（梅毒、淋病、软下疳、腹股沟肉芽肿和多诺万病）。性传播疾病偶尔可通过非性途径获得（例如，新生儿从母亲处获得，或临床或实验室人员处理病原生物或受感染分泌物时获得），但在成人中，几乎从不通过接触受污染的无生命物体（如毛巾、厕所座圈或洗浴设施）获得。然而，某些性传播感染（如人类免疫缺陷病毒感染、病毒性肝炎和巨细胞病毒感染）在某些环境中主要通过性接触传播，而在其他环境中则通过非性途径传播。参见 淋病；梅毒。
