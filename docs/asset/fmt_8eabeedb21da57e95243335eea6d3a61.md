### multi-homed

计算机可能有多个适配器和多个 IP 地址。我们把这些主机称为多宿主主机 (`multi-homed hosts`)。这类机器的存在使得某些过程变得困难。基于 `UDP` 的事务（如 `DNS`）显示出异常，因为响应返回的 IP 地址与我们请求的地址不同。`Sun` 演示了甚至更困难的问题：如果工作站上安装了多个适配器，它们都被分配了相同的 `MAC` 地址。有时人们将两个适配器连接到同一个以太网中。这意味着每个传入的数据包都会被两个适配器接收，因此每个请求都会被看到多次并响应多次。症状是 `UDP` 响应返回。关键配置错误的多宿主主机很常见，这使得区分它们的地址与黑客的地址变得困难。

来自 Hacking-`http://www.tdp.org/LDP/Linux-Dictionary/index.html`
