
e2fsprogs 软件包包含 `chattr`, `lsattr`, `uuidgen`, `badblocks`, `debugfs`, `dumpe2fs`, `e2fsck`, `e2label`, `fsck`, `fsck.ext2`, `mke2fs`, `mkfs.ext2`, `mklost+found` 和 `tune2fs` 程序。

# e2fsprogs

## 描述

### chattr
`chattr` 修改 Linux 第二扩展文件系统上的文件属性。

### lsattr
`lsattr` 列出第二扩展文件系统上的文件属性。

### uuidgen
`uuidgen` 程序使用 `libuuid` 库创建一个新的通用唯一标识符 (UUID)。新的 UUID 在所有系统中都可以是唯一的。

### badblocks
`badblocks` 用于搜索设备（通常是分区）上的坏块。

### debugfs
`debugfs` 程序是一个文件系统调试器。它可以用于检查和更改 ext2 文件系统的状态。

### dumpe2fs
`dumpe2fs` 打印文件系统的超级块和数据块信息。

### e2fsck and fsck.ext2
`e2fsck` 用于检查 Linux 文件系统。`fsck.ext2` 执行与 `e2fsck` 相同。

### e2label
`e2label` 将显示或更改 ext2 文件系统上的系统标签。

### fsck
`fsck` 用于检查并可选地修复 Linux 文件系统。

### mke2fs and mkfs.ext2
`mke2fs` 用于在设备（通常是分区）上创建 Linux扩展文件系统。`mkfs.ext2` 执行与 `mke2fs` 相同。

### mklost+found
`mklost+found` 预分配磁盘块到目录，以便 `e2fsck` 使用。

### tune2fs
`tune2fs` 调整 Linux扩展文件系统上的可调文件系统参数。

# Fileutils

## 内容
Fileutils 软件包包含 `chgrp`, `chmod`, `chown`, `cp`, `dd`, `df`, `dir`, `dicolors`, `du`, `install`, `ln`, `ls`, `mkdir`, `mkfifo`, `mknod`, `mv`, `rm`, `rmdir`, `sync`, `touch` 和 `vdir` 程序。

## ls, dir 和 vdir
`dir` 和 `vdir` 是 `ls` 的不同版本，具有不同的默认输出格式。这些程序列出每个指定的文件或目录名称。目录内容按字母顺序排序。对于 `ls`，如果标准输出是终端，文件默认按列列出并垂直排序；否则，每行显示一个。对于 `dir`，文件按列列出并垂直排序。对于 `vdir`，文件默认以长格式列表列出。

### dircolors
`dircolors` 输出用于设置 `LS_COLOR` 环境变量的命令。`LS_COLOR` 变量用于更改 `ls` 及相关工具所使用的默认颜色方案。

### du
`du` 显示每个参数以及目录参数中每个子目录占用的磁盘空间。

### install
`install` 复制文件并设置它们的权限模式，如果可能，还会设置它们的所有者和组。

### ln
`ln` 在文件之间创建硬链接或软链接（符号链接）。

### mkdir
`mkdir` 创建指定名称的目录。

### mkfifo
`mkfifo` 根据每个指定的名称创建 FIFO（先入先出）文件。

### mknod
`mknod` 使用指定的文件名创建 FIFO、字符特殊文件或块特殊文件。

### mv
`mv` 根据传递给 `mv` 的参数将文件从一个目录移动到另一个目录或重命名文件。

### rm
`rm` 删除文件或目录。

### rmdir
`rmdir` 删除空目录。

### sync
`sync` 将更改的块强制磁盘并更新超级块。

### touch
`touch` 将每个指定文件的访问时间和修改时间更改为当前时间。如果文件不存在则创建一个空文件。

# Gzip

## 目录
Gzip 包包含 `gunzip`, `gzexe`, `gzip`, `zcat`, `zcmp`, `zdiff`, `zforce`, `zgrep`, `zmore` 和 `znew` 程序。

## 描述

### gunzip
`gunzip` 解压缩用 `gzip` 压缩的文件。

### gzexe
`gzexe` 允许你对可执行文件进行原地压缩，并在运行时它们自动解压并执行（会有性能损失）。

### gzip
`gzip` 使用 Lempel–Ziv 编码 (LZ77) 缩小指定文件的大小。

### zcat
`zcat` 解压缩命令行上的文件列表或其标准输入，并将解压缩后的数据写入标准输出。

### zcmp
`zcmp` 在压缩文件上调用 `cmp` 程序。

### zdiff
`zdiff` 在压缩文件上调用 `diff` 程序。

### zforce
`zforce` 强制所有 gzip 文件使用 `.gz` 扩展名，以便 `gzip` 不再次对其压缩。这对于文件传输后文件名被截断的文件很有用。

### zgrep
`zgrep` 在压缩文件上调用 `grep` 程序。

### zmore
`Zmore` 是一个过滤器，允许在软拷贝终端上（类似于 `more` 程序）一次一屏地查看压缩或纯文本文件。

### znew
`Znew` 将文件从 Z（压缩）格式重新压缩为 `.gz` (gzip) 格式。

# Ld.so

## 目录
从 Ld.so 包中，我们使用了 `ldconfig` 和 `ldd` 程序。

## 描述

### ldconfig
`ldconfig` 在命令行指定的目录、`/etc/ld.so.conf` 文件以及受信任目录 (`/usr/lib` 和 `/lib`) 中找到的最新共享库创建必要的链接和缓存（供运行时链接器 `ld.so` 使用）。`ldconfig` 在确定哪些版本应该更新其链接时，会检查它所遇到的库的头文件和文件名。

### ldd
`ldd` 打印每个在命令行上指定的程序或共享库所运行所需的共享库。
