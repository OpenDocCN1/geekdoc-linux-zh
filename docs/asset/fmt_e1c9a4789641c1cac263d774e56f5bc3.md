### 使用 RPM 命令安装软件包

## RPM

RPM 代表 Red Hat Package Manager。软件包以 `.rpm` 结尾。`rpm` 命令用于管理本地安装、更新和删除的软件。

### Commands

### 安装

#### 语法

```bash
rpm -ivh package_name
```

#### 示例

```bash
rpm -ivh package.rpm
```

### 更新

#### 语法

```bash
rpm -Uvh package_name
```

#### 示例

```bash
rpm -Uvh package.rpm
```

### 移除

#### 语法

```bash
rpm -e package_name
```

#### 示例

```bash
rpm -e package.rpm
```

### 查询已安装的软件包

#### 语法

```bash
rpm -q
```

#### 示例

```bash
rpm -q package
```

### 显示软件包的详细信息

#### 语法

```bash
rpm -qi package_name
```

#### 示例

```bash
rpm -qi package
```

### 列出软件包包含的文件

#### 语法

```bash
rpm -ql package_name
```

#### 示例

```bash
rpm -ql package
```

### 查询文件所属包

#### 语法

```bash
rpm -qf file_name
```

#### 示例

```bash
rpm -qf /usr/bin/ls
```

### 工具类

### Tar

用于将多个文件创建一个归档文件，用于磁带或其他介质备份。在创建归档文件时，也可以添加选项创建压缩文件。

#### 创建 tar

##### 语法

```bash
tar cvf name_of_archive_file files_or_directory_to_archive
```

其中

- `c` 创建
- `v` 详细模式
- `f` 归档文件类型类型

##### 示例

```bash
[root@redhat1 share]# tar cvf abc.tar *
applications/
applications/preferred-mail-reader.desktop
applications/preferred-web-browser.desktop
gvfs-metadata/
[root@redhat1 share]# ls -la
total 96
drwxr-xr-x. 4 root root 4096 Feb 12 10:58 .
drwxr-xr-x. 3 root root 4096 Feb 4 12:46 ..
-rw-r--r--. 1 root root 81920 Feb 12 10:58
abc.tar
```

#### 创建压缩 tar 文件

##### 创建 gzip 格式 tar 文件

```bash
tar cvfz abc.tar.gz name_of_files
```

##### 创建 bzip 格式

```bash
tar cvfj abc.tar.bz2 name_of_files
```

#### untar

```bash
tar xvf abc.tar
```

其中

- `x` 提取
- `v` 详细模式
- `f` 归档文件类型类型

#### 解压缩

##### 解压缩 gzip 格式

###### 语法

```bash
tar xvfz filename
```

###### 示例

```bash
tar xvfz abc.tar.gz
```

##### 创建 bzip 格式

###### 语法

```bash
tar xvfj filename
```

###### 示例

```bash
tar xvfj abc.tar.bz2
```

#### 列出归档 tar 文件

##### 语法

```bash
tar tvf filename
```

##### 示例

```bash
tar tvf abc.tar
```

#### 列出 gzip 压缩 tar 文件

##### 语法

```bash
tar tzvf filename
```

##### 示例

```bash
tar tzvf abc.tar.gz
```

#### 列出 bzip 压缩 tar 文件

##### 语法

```bash
tar tjvf filename
```

##### 示例

```bash
tar tjvf abc.tar.bz2
```

### cp

复制文件的命令

#### 语法

```bash
cp <options> source destination
```

#### 示例

```bash
cp /home/abc.txt /home1/
```

#### 递归复制目录下的所有文件

```bash
cp -R /home/* /home1/
```

#### 在任何覆盖前提示

```bash
cp -i /home /home1
```

#### 将所有新文件复制到目标

```bash
cp -u * /tmp
```

#### 强制复制文件

```bash
cp -f /tmp/abc.txt /backup/.
```

#### 不经提示直接覆盖

```bash
cp -n* t
```

#### 从本地机器复制到远程机器

##### 语法

```bash

```

#### 从远程主机复制 xyz 文件到本地主机

##### 语法

```bash

```

### CPIO

从归档内部和外部复制文件。用于创建和提取归档，以及将文件从一个地方复制到另一个地方。

#### 从目录 abc 创建归档到 /directory backup

```bash
cd abc
ls|cpio -ov> /backup/abc.cpio
```

#### 提取

```bash
mkdir newbackup
cd newbackup
cpio -idv < /backup/abc.cpio
```

#### 创建特定文件列表的归档

示例 :- 备份所有日志文件

```bash
find . -iname *.log -print|cpio -ov> backup/selog.cpio
```

#### 使用 cpio 创建 tar 文件

```bash
ls|cpio -ovH - abc.tar
```

#### 使用 cpio 提取 tar 文件

```bash
cpio -idv -F abc.tar
```

### Dump 和还原

#### dump

`dump` 工具用于备份整个文件系统或自上次 dump 以来更改的文件。

##### 语法

```bash
dump <options> target_device filesystem_to_be_up
```

##### 示例：

备份整个文件系统到设备

```bash
dump -uf /dev/st0
```

其中

`0` 是 dump 级别。从 0 到 9
- `-0` 自上次 dump 以来完整
- `-1` 自上次 dump 以来更新
- `-2` 自上次 dump 以来更改
- `-3` 自上次 dump 以来类似
- `-9` 自上次 dump 以来更新
- `u` 显示备份信息
- `f` 指定设备名称

#### restore

`restore` 命令用于还原 dump 命令存储的备份。

##### 语法

```bash
restore <options> backupdevice
```

##### 示例：

从 `/dev/st0` 还原备份

```bash
restore -if/0
```

其中选项 `i` 触发交互模式，允许选择文件和目录

#### 还原特定文件

```bash
restore -xf /etc/hosts
```
