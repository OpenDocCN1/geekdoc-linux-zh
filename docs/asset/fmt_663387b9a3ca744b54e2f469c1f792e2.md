## 无线网络的优势

无线网络的优势是其移动性和潜在范围。如果你有一个足够天线，你的网络可以延伸许多英里。这将是一个昂贵的网络，但它可以轻松突破办公室物理空间的限制。

无线网络对大学校园也是极大的优势，消除了拆除墙壁安装线缆的需要，因为越来越多的学生期望在宿舍里有连接。无线网卡的价格非常合理，可以根据需要轻松发放给每位学生。

家庭用户也可以从无线网络中获益。对于那些无法对房屋进行布线修改的人来说，这是一个潜在的解决方案。此外，无线网络消除了为了连接不同房间的电脑而沿着踢脚线和天花板运行的美观线条。有了家庭网络，你甚至不再限于房屋。取决于路由器的发射功率，你可以坐在后院，打字时看着云飘。

选择正确的无线设备类型是一项重要的决定。接下来的章节将讨论当前用于无线网络的协议之间的一些基本区别。

## 从可用的无线协议中选择

电气电子工程师学会（IEEE）从1990年开始认真研究无线网络。当时`802.11`标准首次引入。这是无线局域网标准小组引入该标准的时候。大型网络可以使用多个接入点。使用超过一个接入点的网络通常被称为分布式。目前，最便宜的Linux网络使用支持`802.11b`设备（如接入点或网卡）构建，尽管`802.11`具有更快的速度。设备被标记为`N`或`Pre-N`，意味着它们实现了一个草案标准。支持`N`的硬件可以获得更高的吞吐量和范围。

早期标准`802.11a`比`802.11b`提供更高的传输速率，并且`802.11a`无线网卡可用。（某些产品提供高达72Mbps，但不支持`802.11b`。）基于`802.11g`的无线设备具有`802.11a`的速度改进，并兼容`802.11b`，提供数据传输。蓝牙用于短距离设备通信（如打印机）。与需要视线的`IrDA`不同，蓝牙使用2.4GHz频段。你可以在`www.bluetooth.com/`找到更多信息。然而，由于法律规定，日本的无线网络限制在2471MHz到2479MHz的频率范围内。在这些范围内，每个网络分配不重叠通道。

## 跨越网络进入互联网

Ubuntu支持多种连接互联网和使用互联网资源的方法。本书的版本包含了丰富的互联网软件，你也可以从各种来源下载免费工具。要使用它们，你必须有一个工作的互联网连接。

在本节中，你将学习如何使用调制解调器和点点协议（PPP）在Ubuntu中设置互联网连接，以及其他连接方法，包括数字用户线路（DSL）和电缆调制解调器服务。几年前，让拨号连接工作很困难——书中有一个专门章节。今天，只要你有硬件调制解调器，拨号连接很简单。

尽管许多Linux用户继续使用手动脚本建立互联网连接，但新用户和经验丰富的系统管理员都认为Ubuntu的图形化网络配置界面更好用。你将在本章中学习如何使用互联网连接向导以及如何配置Ubuntu提供拨入支持。本章还描述了如何使用Roaring Penguin的DSL工具管理通过电缆调制解调器连接的连接。

# 常见配置信息 403

如果你是少数仍使用拨号调制解调器的人（由于其使用的点对点协议被称为Linux PPP），你的互联网服务提供商（ISP）将为你的计算机提供静态或动态互联网协议（IP）地址。动态IP地址在每次拨号时都会更改，而静态IP地址则保持不变。ISP可能会自动为你的计算机提供域名服务（DNS）服务器的名称。你需要知道计算机拨号连接所需的电话号码；你的ISP也会提供该号码。你还需要一个工作的调制解调器，并知道调制解调器的设备名称（通常为`/dev/modem`）。

## 注意

大多数IP地址由ISP动态分配；ISP拥有一个地址池，你将获得任何可用的地址。从ISP的角度来看，少量的地址就可以服务许多人，因为并不是所有人都会同时在线。对于大多数互联网服务，动态IP运行良好，因为将信息路由到你那里是ISP的工作，而且它位于你和你想要使用的服务之间。但动态IP地址会变化，如果有人需要在相同的地址找到你（例如，你运行着网站或文件传输），那么每次登录都更改的IP就无法工作了。为此，你需要静态IP。因为你的ISP无法将该IP复用给其他客户，他们对静态IP的收费可能会比动态IP更贵。普通消费者不需要静态IP的好处，因此乐意为动态分配的IP支付较低费用。此外，信息可以通过ISP通过`DHCP`自动提供。

如果你正在使用DSL或电缆调制解调器，你可能通过`DHCP`获得动态IP，也可能被分配静态IP。如果你使用`DHCP`，可能会自动获得DNS服务器的名称，或者你可能需要手动设置DNS（在这种情况下，你必须知道DNS服务器的IP地址）。

在所有情况下，你都必须知道你的用户名、密码，以及其他服务的配置所需的邮件服务器和新闻服务器名称。如果你明确要求，可以从ISP获得这些信息。

## 注意

本书中的信息可以帮助你理解并避免许多连接问题，因为你可能会遇到连接问题。如果无法建立，，拨打你ISP技术帮助服务的电话。请注意，很少有ISP提供Linux支持，如果你的特殊情况无法通过从书中学到的知识来解决，你可能需要向精通Linux的朋友寻求帮助。当然，最好的查找地方是互联网。使用Google的Linux页面（`www.google.com/linux/`）研究问题，并查看其他用户是否发现了修复方法或替代方案。

# 配置数字用户线路接入

Ubuntu也支持使用数字用户线路（DSL）服务。尽管它将不同类型的DSL称为`xDSL`（包括`ADSL`、`IDSL`、`SDSL`和其他DSL服务变体），但你可以使用互联网连接向导配置所有这些类型。DSL服务提供256Kbps到24Mbps的传输速度，并通过电话线从市局传输数据到单个用户站点（如你的家）。许多DSL服务（技术上是电缆而非DSL）提供非对称速度，下载速度大于上传速度。

DSL服务是一种“始终在线”的互联网服务，尽管你可以使用Ubuntu下“系统 -> 管理 -> 网络”中的网络配置工具关闭连接。始终在线的连接会将你的计算机暴露在爬取互联网以获取其他系统访问权的黑客恶意攻击之下。除了具有关闭此类连接的能力外，Ubuntu还预配置为不监听任何网络端口，这意味着任何访问你计算机的尝试都会失败，因为Ubuntu拒绝了请求。这在Ubuntu中等同于在计算机周围围上一圈12英尺高的钢栅。

DSL连接要求你的计算机或笔记本电脑中有一个以太网网（有时是Linux中不易于支持的USB接口）。许多用户还会配置带有至少两个网卡的网关、防火墙或其他计算机，以与局域网共享连接。在本章早些时候查看了硬件和协议问题。防火墙或路由器的高级配置（你最初安装Ubuntu时未涵盖的内容）出了本书的范围。

# 理解以太网的 PPP

与提供静态IP地址的ISP建立DSL连接是简单的。遗憾的是，许多DSL提供商使用名为以太网的点对点协议（PPPoE）的PPP协议，该协议通过将PPP信息封装在以太网帧内部提供动态IP地址分配和认证。Roaring Penguin的`rr-pppoe`客户端可以在Roaring Penguin网站（`www.roaringpenguin.com/penguin/pppoe/rr-pppoe-3.8.tar.gz`）获取，这些客户端让难以配置的PPPoE连接变得更容易处理。你可以下载并安装新版本。（在本章末尾“参考文献”部分中的Roaring Penguin链接）。

当ISP最初开始推出ADSL服务时，他们通常会提供ADSL调制解调器。今天，在世界许多地方这些是可选的，这是一好事，因为许多人选择购买内置调制解调器的路由器来创建专用连接。在美国，这些设备很少见，但如果你愿意花钱，通常可以使用市售调制解调器替换提供的调制解调器。无论如何，使用路由器可以为你节省很多烦恼，并让你能够轻松将一个以上的计算机连接到互联网连接。请注意，如果你使用电缆连接，它们通常会带有一根以太线，在这种情况下你只需要一个路由器（这几乎是美国所有互联网访问的方式，因为组合调制解调器/路由器设备在美国很罕见）。在购买之前咨询你的ISP，以确保你最终使用的任何路由器都能得到他们支持。你可能会发现你的ISP作为软件包的一部分提供了路由器。
