# 物理常数

元素。特定的分析方法需要处理的四种元素。首先，函数被表示为分层分解，其中包含一个系统或组织的顶层函数。顶层函数被划分为子集，这些子集产生与顶层函数相同的结果。每个子集都可以进一步分解，只要分解过程持续。

这五个数值代表了不同类型的基本常数：`c`, `h`, `e`, `m_e` 和 `G`。它们是自然出现在某些物理学数学公式中的数量示例——分别是爱因斯坦的相对论和量子物理，以及表征所有物质基本粒子的物理数量示例。这种组合总是共同出现在物理方程中。

其次，功能分析图表示了功能分析内部数据或项的流向。随着功能及后续函数的分解，一个函数产生被系统或组织中其他函数使用的输出是很常见的。其他函数需要这些输出来产生所需且预期的输出。

物理常数需要可靠的数值，主要出于两个原因。首先，它们对于通过计算来获得结果是必要的。其次，更重要的是，通过计算从不同物理学领域获得的数值，可以测试物理常数的自洽性。通常，基本常数的精度多年年来不断提高。在过去，某些常数的精度达到了百万分之一，而今天十亿分之一已并不罕见。

处理指令是某些功能分析图包含的第三种元素。指令为函数的有效输入提供了所需的信息。

反馈和控制在功能分析和建模中起着重要作用。反馈和控制是一种实际特征，一个过程的输出通过输入转换为输出的过程作为另一个过程的输入。开环过程可能产生或不产生这种情况，但无论哪种情况不对开始的过程进行任何调整。闭环过程使用反馈作为调整或控制转换过程的过程。

第四种元素是控制，它对过程组成函数的方式和激活进行排序。

基本常数在物理学基础中起着基础作用。这些常数包括真空光速 `c`；电子电荷 `e`；基本长度单位 `l`；电子质量 `m_e`；普朗克常数 `h` 以及精细结构常数 `α`。

# 基本相互作用

作用于基本粒子之间的基本力，它们假设都是复合的。它们的性质总结在表中。强力克服了质子和中子之间的其他力。质子和中子被认为是由上夸克（`u`）和下夸克（`d`）组成的（`p = uud`，`n = ud`）。每个夸克被赋予赋予三种颜色（红、绿、蓝）之一。强力被感知为通过夸克之间交换自旋为1的中性色玻色子产生的，这些玻色子被称为胶子（`G`）。这四种相互作用（电磁、弱、核和强）假设分别由光子（`γ`）、`W±` `Z⁰`和胶子（`G`）介导，携带自旋1。这是由杨、Mills和R开创的规范场的特征。

| 相互作用 | 范围 | 交换量子 |
| --- | --- | --- |
| 引力 | 长 |  |
| 电磁 | 长 | 光子（`γ`） |
| 弱 | 短（10⁻⁸ m） | `W±` `Z⁰` |
| 强 | 短（10⁻⁵ m） | 胶子（`G`） |

引力相互作用表现为所有基本粒子之间的远程引力。电磁相互作用负责所有带电荷基本粒子的排斥和吸引。电磁相互作用的大小（由电子和质子之间斥力的强度决定）大约为 4 × 10⁻⁰。参见库仑定律；引力。

在现代场论中，电磁相互作用和粒子之间的斥力是由爱因斯坦（在麦克斯韦方程中）以及随后的相对论理论预测的一个或多个粒子（光子或光量子）交换引起的。类似的图可能也适用于引力相互作用。

第三种相互作用是弱核相互作用，它负责中子衰变为质子、电子和反中微子（1930年的发现）。核子之间的弱相互作用是短程的，力级为 10⁻³ N。

这一事实最终在1983年确立。弱相互作用主要由基本粒子`W±`和`Z⁰`粒子介导，这些粒子是1983年由Van der Meer和Rubin在CERN发现的，质量级为80 GeV/c²。这些粒子每个携带自旋为1（ħ）。这些粒子的质量与弱相互作用范围的平方成反比。参见因伯；矢量玻色子。

第四种相互作用（引力）也可以被视为一种规范相互作用，在这种情况下内在电荷被质量取代。引力与质量的乘积正比。引力与其他相互作用的区别在于引力量子（引力子）携带自旋2。关于引力是否为规范理论的问题尚未解决。

# 真菌生态学

微生物学和生态学学科研究群落组成和结构；单物种的活动和功能；生态系统中的真菌。这些生物代表了生态生活的极端多样性，在异养养环境中几乎都是精英。真菌是主要的分解者，分解有机物并调节能量和物质的流动。
