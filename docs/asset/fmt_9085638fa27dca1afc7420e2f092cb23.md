# 第18章数组

在内存中，数组就是按顺序排列的相同的数据。

## 18.1 简介

```c
#include <stdio.h>

int main() {
    int a[20];
    int i;
    for (i=0; i<20; i++) {
        a[i]=i*2;
    }
    for (i=0; i<20; i++) {
        printf("%d=%d\n", i, a[i]);
    }
    return 0;
}
```
