
这使得创建某些子程序成为可能，这些子程序向作为参数传递的文件句柄写入。

**警告：** 在创建文件句柄引用时，不要忘记在 `\` 之后包含 `*`。（`*` 指向存储文件句柄的内部符号表。）

在创建标量变量、数组或子程序的引用时，不需要提供 `*`。

## 面向对象

Perl 5 提供了以面向对象的方式编写程序的能力。你可以通过创建包含执行指定任务代码的包（`packages`）来实现这些包可以包含私有变量和子程序，这些内容无法从程序的其他部分访问。

以下章节描述了包以及如何使用它们来创建类和对象。这些章节还描述了如何使用包创建可导出的程序模块。

**警告：** 如果你在使用 Perl 4，你将无法使用这里描述的许多功能，因为它们是在语言的第5 版本中添加的。

## 包

在 Perl 中，*package*（包）基本上是一个包含在独立命名空间变量和子程序集合。要创建一个包或从一个现有包切换到另一个包，请使用 `package` 语句：

```perl
package pack1;

$myvar = 26;

package pack2;

$myvar = 34;

package pack1;

print ("$myvar\n"); # 这打印 26
```

这段代码创建了两个包 `pack1` 和 `pack2`，然后从 `pack2` 回到 `pack1`。每个包都包含变量 `$myvar` 自己的版本：在包 `pack1` 中，`$myvar` 被赋值 `26`，在包 `pack2` 中，`$myvar` 被赋值 `34`。由于打印语句在 `pack1` 内部，它打印了 `26`，即 `pack1` 中变量 `$myvar` 的值。

子程序也可以定义在包内部。例如，以下代码在名为 `pack1` 的包内创建一个名为 `mysub` 的子程序：

```perl
package pack1;

sub mysub {
  print ("hello, world!\n");
}
```

要从另一个包访问属于一个包的变量或子程序，请指定包名两个冒号：

```perl
package pack1;

print ("$pack2::myvar\n");
```

此 `print` 语句打印属于包 `pack2` 的 `$myvar` 的值，即使当前包是 `pack1`。**注意：** Perl 4 使用单引号而不是双冒号来分隔包名和变量名。如果没有指定包，默认情况下所有变量和子程序都会被添加到名为 `main` 的包中。要切回使用默认包，请在程序中需要的地方添加 `package main;` 行。

## 创建模块

你可以将创建的包放在它自己的文件中，称为模块（`module`）。这使得在多个程序中使用同一个包成为可能。以下名为 `Hello.pm` 的文件创建了一个包含打印 `hello, world!` 的子程序的模块：

```perl
package Hello;

require Exporter;

@ISA = "Exporter";

@EXPORT = ("helloworld");

sub helloworld {
  print ("hello, world!\n");
}
```
