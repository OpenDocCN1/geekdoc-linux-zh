
# Linux 初学者指南 - 分步操作指南

## 引言

我想感谢并祝贺你下载了《Linux 操作系统》。这本书包含了关于如何运行 Linux 以获得真实体验的验证步骤和策略、获取系统管理命令的 Linux 书籍，以及在 Windows 上安装 Linux 等你在目录中看到的更多内容。听到 Linux 这个词时不要皱眉。它像 Windows 一样用户友好。

它是一个可以下载的免费操作系统，但你必须支付少量的费用来订购或从公司购买。Linux 诞生于 22 年前——它是由芬兰 Linux 之友（Linux Tords）与开源软件运动的一组程序员共同开发的。

Linux 一年一年都在稳步增长。在充满热情的社区支持下，在 IBM 和 HP 等大公司的支持下，难怪 Linux——这一曾经属于服务器的奇迹操作系统也进入了如今的桌面。

Linux 基于 Unix。大多数用户熟悉 Windows，但 Linux 可能有所不同。然而，它是强大且免费的。在本书中，我将引导你了解 Linux 的基础，让你习惯。

## 关于 Linux 的迷思

### 安装：

Linux 安装很难，对吗？其实并不难。大多数人也没有安装过 Windows——因为它是预装的。Linux 和 Windows 一样易于安装。你可以通过图形化界面安装它。如今的 Linux 版本比 Windows 更容易安装。但困扰大多数人的是在硬盘的第二个分区上安装 Linux，当他们想要同时使用两个操作系统时。

分区是组织硬盘空间的一种方式，通过创建相互独立的虚拟区域来实现。大多数运行 Windows 或 MS DOS 的计算机只有一个巨大的操作系统空间。这个空间就是 C 盘。如果你有一个大硬盘，它可能被分成了较小的分区。这些分区通常被称为 D:、E: 等，你可以在任何分区上安装 Linux。

Windows 98 在整个硬盘上创建 FAT32 文件系统，DOS 和 Win95 使用 FAT16。Linux 有许多文件系统，最流行的是 ext3。但你也可以在 Fat32 分区上安装 Linux。

你会觉得自己像在 Windows 中工作一样！GNOME 和 KDE 是这些系统中最流行的。GNOME 代表 GNU 网络模型环境（GNU Network Model Environment），KDE 代表 K 桌面环境。它们拥有允许拖放操作的工具，拥有面板和任务栏——几乎就像 Windows 的克隆。

### 硬件兼容性问题以及在 Linux 上运行的少数应用程序

嗯，大多数新发行版都能在短时间内检测并配置你的硬件，除非你拥有一些非常老旧或奇特的硬件。所有硬件都能被正确检测并安装驱动程序。只有由 Windows 驱动程序驱动的现代 Windows 系统才会遇到问题。

至于软件，有非常多。而且其中大部分都是免费提供给你，你可以根据自己的需要进行使用、修改和配置。几乎所有优秀的 Linux 软件都是免费的，你尝试一下也不会损失任何东西。你可以在网络上快速获得你可能有的任何查询的免费支持。你甚至不需要删掉 Windows。只需将 Linux 安装在不同的硬盘分区上，并根据你的意愿在它们之间切换即可。

其他软件包是商业性的，你必须购买软件——但这主要是是为了软件以及对你的培训，而不是为了软件本身。有时，如果你有 Windows 版本（作为一种保险），你可以下载一个小型程序，允许你在 Linux 中运行该游戏。Linux 中的游戏质量非常高且功能强大。你会喜欢它们的。这里有：

- 办公套件：`Star Office`, `Open Office`, `Appixware`, `Corel WordPerfect`
- 图形：`GIMP`, `Corel Photo pear`
- 音乐：`XMMS`, `Free amp`, `Real Player`
- 视频：`MTV`, `Xine`
- 游戏：`FreeCiv`, `Tux racer`, `Doom`, `Quake`, `Heretic`, `Unreal`，列表仍在不断增长。

### 适用于家庭用户的 Linux 种类：

既然有这么多人在开发它，很可能也有很多 Linux 版本。许多致力于 Linux 的公司都开发了所谓的 Linux 发行版（Linux distributions）。有些 Linux 版本是经过编译、打包并附带额外软件释放的。

- **`RedHat` (红帽)**：可能是最流行且在许多方面处于领先的版本。它目前是第 9 版本。安装和配置非常简单。蓝色的文件管理器和默认的 `GNOME` 桌面看起来非常惊艳。它有一系列工具，可以作为服务器和工作站使用。由红帽开发的红帽软件包管理器 (`RPM`) 格式几乎已经成为 Linux 世界软件分发的标准。安装新软件轻而易举。它还有一个先进且易用的字体管理系统，使得 `X Windows` 中的字体看起来非常漂亮。

- **`Mandrake Linux`**：现在是第 10 代。它可以使用 `Lin4Win` 工具安装在原生 Windows 分区上，这可能会减慢机器速度。它还允许你在自己的分区中进行传统的 Linux 安装。`Mandrake` 的配置和软件安装是非常轻松的。它遵循一种略微修改的 `RPM` 架构，称为 `mdk.rpm`，但大多数红帽软件也可以用于 `Mandrake`。该版本的显著特征是窗口管理器集合——视觉狂热者会度过一段极快的时光。

- **`SUSE` (苏萨)**：来自德国的“变色龙”`SUSE`。现在处于 8.x 版本，它拥有编译最全面的软件包集合之一，通过 `yast`（Yet Another Software Tool，又一个软件工具）可以轻松获取它们，`yast` 提供了一个集中式界面，你可以在从中选择要安装的软件。除外，`SUSE` 还带有一些惊艳的 3D 游戏，展示了 Linux 的游戏实力。

- **`Corel/Xandross`**：几年前带着 `Core Linux` 进入了 Linux 市场。现在它已合并为基于 `Core Linux` 的 `Xandross OS`。这是一个 `Debian` 类型的版本，在调整 Windows 分区大小后可以无需费力地安装。`Xandross` 包含了 `Crossover office`，这是 `WINE` 的精简零售版，你可以在其中安装并运行许多微软应用程序。

### Linux 中的 Windows 应用程序

某些应用程序已经移植到 Linux，另一些通过一个名为 `WINE` 的程序运行（`Wine` 并不是模拟器）。`Crossover` 这种商用可用软件也允许你在 Linux 上使用你的 Windows 程序。`VMware` 是另一个允许你在 Linux 上运行 Windows 的程序。现在许多软件公司开始为 Linux 开发高级软件。Linux 的酷炫之处在于大多数软件都是免费的，你可以合法盗版地使用它们。如果你担心 Linux 不像 Windows 那么漂亮，只需查看一些有趣的 Linux 界面和窗口管理器。如果你有一台运行两者的电脑，就可以轻松地在它们之间切换，获得两者的优点。

### Linux 与 Windows 的区别

本主题将讨论 Linux 和 Windows 之间的区别，我们将讨论每个系统的优缺点。

让我们先从 Linux 系统的通用概览开始。Linux 在最基本的形式是一个计算机内核（`Kernel`）。内核是用于与硬件和其他系统通信的底层计算机代码，它运行计算机的所有基本功能。

Linux 内核是一个运行在各种硬件和各种用途上的操作系统。Linux 能够运行在如手表或手机等简单设备上，也可以运行在家用电脑（例如 `Intel` 或 `AMD` 处理器），甚至运行在使用 `Sun` CPU 或 `IBM` PC 处理器的高端服务器上。某些 Linux 发行版只能运行一个处理器，而另一些可以同时运行多个。

Linux 的常见用途包括家庭计算系统，或者更常见的服务器应用程序，例如作为 Web 服务器或邮件服务器。你可以将 Linux 作为专用的防火墙来帮助保护同一网络上的其他机器。

使用命令行提示符的优点是它消耗系统资源较少，并让计算机将更多精力放在当前任务上。命令示例包括用于更改目录的 `cd` 命令、用于关闭系统的 `halt` 命令以及用于重启电脑的 `reboot` 命令。

现在我们对 Linux 操作系统有了了了解，可以注意到 Linux 与世界上最流行的操作系统——微软 Windows 之间的许多不同。从现在开始，我们将讨论 Linux 与 Windows 之间的一些最显著的不同。

首先，只有一家公司发布 Windows 操作系统，那就是微软。所有的 Windows 版本，无论是 `Windows XP` 家庭版、商业版还是 `Vista` 版，其所有更新、安全补丁和服务补丁均来自微软。相比之下，Linux 并不是由某一家公司发布的。

Linux 全范围内有数百万编码者和公司投入时间开发更新、新版本和软件应用程序。尽管有些公司对技术支持收费，另一些公司则对他们的 Linux 发行版收费，但通过将其与非免费软件打包，你始终可以免费获得 Linux 内核，并且可以免费获得带有所有通用所需应用程序的全功能 Linux 桌面。那些对 Linux 发行版收费的供应商也必须根据 `GPL` 许可协议发布免费版本。而微软 Windows 则需要你向微软支付软件费用，你还必须为你使用的大多数应用程序付费。
