- `"$!"` 文本在 `"use local"` 范围外现在是英文
- `"$!"` 文本在适当的情况下将以 UTF-8 返回
- 移除了对没有显式操作符的 `"PATTERN"` 的支持
- `"defined(@array)"` 和 `"defined(#hash)"` 现在是致命错误
- 将哈希或数组作为引用现在是致命错误。
