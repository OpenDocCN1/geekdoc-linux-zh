## 内存

如果你删除一个文件，变化是 Linux 上消耗最多内存的程序：在拨号连接时代，在线世界由公告板系统（`BBS`）组成。这些是用户聊天、交换代码、玩游戏等的远程聚集点。使用 Linux，我们仍然连接到一些活跃的 `BBS`：`ps aux` | `sort -rnk` 这按系统使用对输出排序。`telnet bestlarbbs.dy.org` 有无数 `BBS` 可用，访问此处 `www.telnetbbs.com/bbs/list/` 了解更多。(img/9eddebb0cf792a0bbe16478be74a68e1_64_0.png)

## SHREDDER

当你想删除一个文件时，拥有相应软件的人可以恢复它。然而，为了安全且永久地删除一个文件，目录树：如果你想用 `tree` 创建整个目录（或文件夹）：`shred -u filename.txt` `mkdir {subfolder1,subfolder2,subfolder3,subfolder4}` 这创建一个包含四个子目录的新目录。将 `filename` 替换为文件名。

## ASCII ART

`ASCII` 应用于图像时可能非常震撼。然而，通常很难做正确。你可以使用现有的图像创建一些 `ASCII` 艺术：被遗忘的命令记住所有的 Linux 命令并不容易。坦率说，我们可以使用 `apropos` 来帮助。只需使用它，并带有描述：`img2txt install filename.png` 将 `filename` 替换为系统中图像文件的实际名称。使用：`sudo apt-get install caca-utils`. `apropos "copy files"` `apropos "rename files"` (img/9eddebb0cf792a0bbe16478be74a68e1_64_2.png)
