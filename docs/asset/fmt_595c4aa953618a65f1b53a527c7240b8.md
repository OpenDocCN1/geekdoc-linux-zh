```

Output:

```

Security-Enhanced Linux (`SELinux`) 是 Linux 的安全架构。

* 强制 (`Enforcing`) - 执行 SELinux 策略。
* 许可 (`Permissive`) - SELux 打印警告而不是执行。
* 禁用 (`Disabled`) - 未加载 SELinux 策略。
