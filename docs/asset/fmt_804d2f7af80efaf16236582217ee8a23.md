
```bash
if [ -f /var/lock/subsys/qmail ]; then
  stop
  start
  RETVAL=$$
fi
;;
*)
echo $"Usage: $0 {start|stop|queue|status|restart|condrestart}"
exit 1
;;
esac
exit $RETVAL
```

### 步骤 2

最后，我们必须重启 Qmail 守护进程使更改生效。

- 要重启 Qmail，请使用以下命令：
`[root@]# /etc/init.d/qmail restart`
