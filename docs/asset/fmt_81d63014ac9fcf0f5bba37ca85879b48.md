
大多数相机都会产生 EXIF 文件，这些是带有额外信息的 JPEG 文件，包含图像信息。`EXIF` 库允许你解析 EXIF 文件并从这些标签中读取数据。该库不包含任何文档，但它似乎在 `libexif`（EXIF 的核心库）与基于 GTK 的图形前端之间建立了连接。来自 Mandrake 9.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`

`libgrade` 是一个运行时从 XML 描述加载用户界面的小型库。`libgrade` 使用由 `GLADE` 界面构建器生成的 XML 文件，因此 `libgrade` 是作为 `GLADE` 代码生成的替代方案。`libgrade` 还提供了一个简单的接口，将处理程序连接到各种信号（在库正常工作的平台上，可以使用一个函数连接所有处理程序）。一旦界面实例化，`libgrade` 不产生开销，因此在缩短初始界面加载时间的同时，没有性能权衡。来自 Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
