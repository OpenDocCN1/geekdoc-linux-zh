
```bash
[root@localhost ~] # vi /etc/vsftpd/vsftpd.conf
```

## 11.3 反思与进阶

### 1 项目背景

通过部署 FTP 服务共享学校提供的资料。随着 FTP 系统的增加，很多 Linux 系统用户无意中修改了系统中的其他文件。为了系统的安全，决定部署如下 FTP 服务：

- (1) 单独设置登录 FTP 服务，该用户不能登录本地系统。
- (2) 对于不同用户进行不同的权限限制。

### 2 实施目的

- (1) 掌握 FTP 服务的工作原理。
- (2) 学会配置 `vsftpd` 服务器。
- (3) 掌握基于虚拟用户的 FTP 服务器。
- (4) 能够根据实际情况部署 FTP 服务。

### 3 实施步骤

- (1) 经分析创建虚拟用户 `aaa` 和 `bbb`，并赋予它们不同的权限。
