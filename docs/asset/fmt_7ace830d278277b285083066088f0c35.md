# 合并

当你执行邮件合并时，WordPerfect 可以以表单形式显示合并代码、仅显示标记，或者什么都不显示。你可以在对话框的“合并代码”部分设置默认值（图 C.7）。

## 图 C.7

如果你合并的是短小的信息，选择将合并代码显示为“标记”或“隐藏合并代码”可以帮助你布局你的表单文件。
