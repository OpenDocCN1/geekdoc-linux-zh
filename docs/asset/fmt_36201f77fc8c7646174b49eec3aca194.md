# 16.10.3 垃圾邮件过滤器

尽管电子邮件有很多优点，但它也有巨大的缺点：垃圾邮件。广告行业发送的未经请求的大量邮件（即垃圾邮件）会塞满你的收件箱并导致传输传输。过滤工具可以将烦人的垃圾与重要邮件分开。SpamAssassin 就是一种嵌入到 KMail 中的工具。它依赖各种内置规则，并具有从垃圾邮件处理经验中学习的能力。这里介绍了该实用程序在 KMail 中的配置。

# 准备

在过滤垃圾邮件之前，需要存在实际软件。以 root 用户运行 YaAST，并使用包管理器（“软件”→“软件”）安装 `spamassassin` 包。

然后，通过在 YaAST（“系统”）中打开运行级别（RunLevel）编辑器来配置系统在启动时激活 SpamAssassin 服务。选择垃圾邮件服务列表并选择“激活”（activate）。点击“完成”（Finish）确认选择。这完成了 SpamAssassin 的安装过程。

在 KMail 中创建一个额外的文件夹（命名为 spam）以存储被分类为垃圾邮件的邮件。如果你已经收集了垃圾邮件，请尽可能将它们移动到此文件夹中。此文件夹可以作为训练样本，允许工具判断你的哪些传入邮件应该被分类为垃圾邮件。

# 垃圾邮件过滤

KMail 需要过滤器来处理垃圾邮件：

+ 1. 第一个过滤器检查邮件的大小。选择“设置”（Settings）→“配置过滤器...”（Configure filters...）。在出现的对话框中，创建一个新的过滤器条目并将其命名为 SpamAssassin（根据需要修改名称）。选择“字节大小”（Size in bytes）为过滤属性，选择“小于”（is less than）为限定符。将阈值设置为 `30000`。在“过滤动作”中选择“通过应用程序处理”（pipe through application），并在旁边的字段输入 `spam`。必须禁用“匹配条件时在此停止处理”（abort processing here upon matching condition）选项。点击“应用”（Apply）确认第一个过滤器。

此过滤规则规定 KMail 只将大小小于 300 KB 的邮件传递给垃圾过滤器。可以调整阈值。然而，随着大小阈值的增加，邮件的处理时间也会增加。SpamAssassin 会检查所有邮件的垃圾邮件特征，并通过添加 `X-Spam-Status: YES` 行来修改邮件头。第二个过滤器依赖于此。

+ 2. 向列表中添加第二个过滤器并将其命名为 SpamFilter。此过滤器将被 SpamAssassin 标记的邮件移动到垃圾文件夹。选择“标头字段”（<header field>）为属性，选择“包含”（contains）为限定符。在相应的文本字段中输入 `X-Spam-Status: YES`。将“过滤动作”选择为“文件夹”（file folder）并选择 `spam`。点击“应用”（Apply）确认。

# 区分需要的和不需要的邮件

SpamAssassin 带有预定义的规则，用于控制垃圾邮件的识别。该工具偶尔可能会漏掉邮件。这就是通过训练 SpamAssassin 降低误报率的地方。

为此，包含了实用程序 `sa-learn`。如果你的邮件以 MailDir 格式存储（参见第 258 页第 16.2 节），运行以下命令：

```
sa-learn --spam --dir ~/Mail/spam/cur/
```

如果你的邮件以 mbox 格式存储，运行以下命令：

```
sa-learn --mbox --spam ~/Mail/.spam.directory/*
```

在成功识别垃圾邮件后，SpamAssassin 返回以下消息：

Learned from 15 message(s)（从 15 封邮件中学习）

访问网站 http://www.spamassassin.org 或阅读相应的 man 页面以了解更多关于该工具的信息。

# 16.11 使用 PGP 或 GnuPG 加密邮件

你可以使用 KMail 加密发出的电子邮件。要加密你的邮件，请按照 16.11.1 节描述的方法生成密钥对。

# 16.11.1 签名邮件

为应该接收你密钥的人创建一条消息。只需在“创建消息”（Create Message）窗口中编写消息。在发送消息之前，点击窗口工具栏上的红色钥匙图标。现在可以发送消息了。如果 KMail 找不到收件者的密钥，将显示包含所有可用密钥的列表。从列表中选择合适的或取消过程。如果在加密过程中发生错误，KMail 也会通知你。如果你不在“安全”（Security）选项卡中点击“始终加密给自己”（Always encrypt to self），你将无法读取加密邮件。要签名电子邮件，KMail 需要知道你的密码。邮件应该被标记由你签名的通知。

# 16.11.2 检查接收邮件的签名

如果 KMail 能够验证电子邮件的签名，将显示一个带有密钥 ID 的绿色框。如果无法验证签名，将显示一个带有警告的黄色框。这意味着你没有合适的公钥。

# 16.11.3 发送公钥

要向你有公钥的收件者发送加密邮件，选择“附加”（Attach）→“附加公钥”（Attach Public Key）。然后即可发送邮件。无法保证签名邮件的接收者收到了正确的密钥。邮件在到达收件者的途中可能会被拦截并用另一个密钥签名。因此，收件者应该通过与之前接收的值对比来检查附加密钥。关于此的更多信息可以在 PGP 和 GnuPG 文中找到。

# 16.11.4 解密邮件

在 KMail 中选择要解密的邮件。在提示时输入你的密码。KMail 尝试解密邮件。如果是用你的公钥加密的，KMail 将以明文显示它。如果不是，你将无法读取电子邮件。KMail 以加密形式保存这些电子邮件，防止任何人在没有密码的情况下读取。

# 16.11.5 加密邮件

要向你有公钥的收件者发送加密邮件，只需在“创建消息”（Create Message）窗口中编写消息。在发送消息之前，点击窗口工具栏上的红色钥匙图标。现在可以发送消息了。如果 KMail 找不到收件者的密钥，将显示包含所有可用密钥的列表。从列表中选择合适的或取消过程。
