# Facebook 隐私与匿名性

`Facebook` 在伦理方面显得有些参差不齐。一方面，它之所以如此受欢迎且利润丰厚是有原因的：人们喜欢与亲戚、老邻居朋友、女朋友、情人以及政治联系人进行实时聊天。人们热爱连接，热爱那种团结和情结的感觉。如果你是那种喜欢即时满足的人，这种益处是立竿见见的。在你的朋友列表中看到已经二十五年未见的老朋友，而他们现在在一天中的几乎任何时候都能立即进行聊天，这种感觉是无与伦比的。

`Facebook` 以前并不像 `P2P` 网络那样真正依赖 `IP` 地址。时代变了。如今，你所有的个人信息都任由他们取用，在某些情况下，甚至是终端用户主动在数字餐盘上呈递。你的真实姓名、电话号码、你过去和现在的朋友是谁，甚至你的宠物，都是宝贵的数据，因为可以针对你性格的每一个原子进行定制广告的精准投放。你问，这会出什么差错呢？

`Facebook` 用户太容易将这箱数据宝库交给出价最高者了。更糟糕的是，`Facebook` 的角色并不是《第四修正案》的保护者，而是它的破坏者。许多政府机构和地方执法部门一直依赖 `Facebook` 个人资料来建立不在场证明、泄露私人电子邮件，并证明或反驳某些可能犯罪或不犯罪的行为。亲自阅读 `Facebook` 的隐私政策：

> “当我们诚实认为有必要防止欺诈或其他非法活动、防止紧迫在眉睫的人体伤害，或保护我们和您免受违反我们《权利与责任声明》的人员时，我们可能会共享信息。这可能包括与其他公司、律师、法院或其他政府实体共享信息。”

他们根据政府要求遵守传票获取用户信息数据，但任何未开启且时长少于 `181` 天的私信除外（这些需要搜令）。问题在于，最高法院从未承认《第四修正案》中的隐私权。这意味着，数据被与第三方共享，因此政府几乎拥有一张空白支票，可以进行“桶里打鱼”式的行动获取订阅信息，而这些信息可能与任何犯罪行为无关。因此，国家和企业在一种难以击败和预测的类法西斯主义中紧密相连，从未忽视过政府在往往无事可做时，会制定出注定会被打破的法律——一次又一次（限速规定，有人感兴趣吗？）。

因此，在关于匿名性的讨论之外，当敌人的箭手站在城堡塔楼上，用火箭对准裸露的君王时，我们无能为力。但我们还是会尝试的。

注意你在 `Facebook` 上输入的内容。实际上，请保持偏执，除非你是国王的愚者之一。这本该是不言而明的，但 `Facebook` 上层出不完的愚者往往甚至无法意识到你对隐私或匿名性的需求，更不用说他们自己了。他们习惯了这种个性化的界面，以至于你开始认为他们在互联网上大喊你的真实姓名是在针对你。在这里你不是匿名的，在任何其他社交媒体网站上——`Twitter`、`Pinterest`、`Google Plus` 等也是如此。事实上，一个新 `Facebook` 账户的隐私甚至比 `Emule` 这样的 `P2P` 网络上的账户更少。至于 `Emule`，你只需要担心 `IP` 地址。而对于 `Facebook`，你的私生活属于他们，除非你采取激进的行动来防止。是的，你可能从少数农民那里听过不少关于社交媒体缺乏隐私的抱怨。这并没有进入 `Facebook` 象牙塔高管的耳朵。

## Facebook 上的匿名性

在 2014 年 4 月，执行官扎克伯格宣布他们计划实施“匿名登录”，这对于用户来说是一个巨大的困惑。`Facebook` 对匿名性过敏。你可能听过他们对匿名账户持反对态度。这并不完全难以理解，如果他们不知道你是谁，就无法向你投放广告，而那是他们的赖以生存的根本。

需求使得即便如此，也无法消除对完全匿名性的需求。

当你深陷于 `Facebook` 的账户创建过程中时，你需要尽可能输入大量的虚假数据。特别是电子邮件地址，必须创建一个以完成完全匿名。大多数人犯的特大错误是认为隐藏 `IP` 地址是达到目的的充分手段。然而，大型媒体巨头雇用了许多跟踪机制——旨在匹配行为模式和偏好选择而设计的复杂算法。只要有一次失误，链条中的一个断点（例如连接到一个知道你真实身份的网站（如 `BBC`））就足以摧毁你所有的努力。等你反应过来时，所有其他人已经被机器人、警报提示和管理员提醒了，你曾与那个会话交流过。大功皆结。

问问自己这个问题：如果你在格拉斯节期间参加了新奥尔斯的一场盛大的装舞会，你最亲近的朋友通过你的名字称呼你吗？你敢肯定他们会，无论是否戴着面具，即使你曾恳求他们保护你的身份。其中一些人可能会低声念出你的名字，甚至没有考虑他们之前的保密誓言。

然后，在你还没反应过来时，另一个耳朵如狐狸灵敏的人偷听了你的名字。同样地，`Facebook` 就像其他人在装舞会上一样，通过你的熟人来识别你。是谁在和你说话？一个女性？年轻还是老年？高还是矮？他们说话时用手势吗？啊，那是罗马的 Maria。这真的并不困难，对 `Facebook` 来说也是如此。朋友和家人列表是 `Facebook` 和 `Google` 算法中的硬性标识。`Facebook` 采用的面脸识别技术随着它在网上搜寻其他地方的匹配项只会更加先进：`Flickr`。`Google`。`Amazon`。`Twitter`。通缉网站。监控视频。

然后还有你的照片需要担心：那些你的朋友拥有的、你对之无法控制的照片。

`Facebook` 在你的机器上安装了“超级 Cookie”（或通过许多第三方执行者安装其中一个），它们以多种方式跟踪你：通过 `Sid` 号、`MAC` 地址等。即使在你退出所有社交媒体网站后，它们也会继续跟踪你。不存在所谓的 100% 匿名这种事件，就像不存在完美的人一样。我们是那些薄弱环节。

但不要害怕，年轻的绝西大师。一切尚未结束。

虽然匿名化很难，但并非不可能。通过一些明智的决定，我们可以达到 98% 的匿名性。首先是投资。投资在 `VPN` 账户上。我们和目标之间的墙越厚，斗篷就越强。在 `VPN` 中，可见性是模糊的，因为它们屏蔽了你的许多行动。使用 `VPN` 很难检测位置，但要避免免费的公共代理，因为 `Facebook` 和每一个其他网站都被垃圾信息淹没了，并且已经针对那些 `IP` 地址范围进行了自我屏蔽。因此，一个合适的（受人尊敬的）`VPN` 才是久之计。你需要与其他非匿名用户混在一起。每一项指标都关重要。

你需要禁用大多数第三方 Cookie，并为每个会话允许 `Facebook`。使用 `Firefox` 便携版，你可以设置浏览器在退出每个会话时自动清除它们。
