
HTML 表单提供了一种从用户处输入数据的方法。表单上定义了一系列区域，允许不同类型的输入，如文本、隐藏、图像、密码、复选框、单选框、提交和重置。这些字段的使用如图表 15.2 所示。

### 表 15.2 表单字段类型。

| 字段类型 | 描述 |
| :--- | :--- |
| `text` | 用于输入普通文本 |
| `hidden` | 用户不可输入；用于在服务器接收表单时跟踪表单 |
| `image` | 基于指定图像的推按钮 |
| `password` | 接受用户输入但不进行回显 |
| `textarea` | 多行用户输入区域 |
| `select option` | 下拉或可滚动的选择列表 |
| `submit` | 将完成的表单发送到服务器 |
| `reset` | 清除表单内容 |

### 表格简述

HTML 表格用于以表格形式呈现数据。定义了一系列行和列，并填充数据。

图 15.23 显示了使用 Netscape Navigator 浏览器的一个带有边框的简单表格。Mosaic 浏览器不支持表格。列表 15.15 显示了其源代码。

#### 图 15.23.
*通过 Mosaic 查看的表格。*

#### 列表 15.15. 表格源代码。

```html
<html>
<head>
<title> Tables </title>
</head>
<body>
<Table border="1">
<CAPTION> <H5>带有标题标题的表格 </H5> </CAPTION>
<TR ALIGN=LEFT VALIGN=MIDDLE> <TH>First<br>column</TH><TH> second <br> column</TH><TH> third column</TH></TR>
<TR> <TD> 1</TD><TD> 100</TD></TR>
<TR> <TD> 2</TD><TD> 200</TD></TR>
<TR> <TD> 3</TD><TD> 300</TD><TD> comment</TD></TR>
</table>
</body>
</html>
```

### 工具

随着 Web 的普及，有很多工具可以创建 HTML。通过使用文本编辑器，可以创建 HTML 和 CGI 脚本。Java Applet 可在网页内提供交互式内容。`width` 和 `height` 参数设置 applet 的窗口大小。

### 表 15.4. 标签摘要--结构。

| 标签 | 描述 |
| :--- | :--- |
| `<HTML> </HTML>` | 包含整个文档 |
| `<TITLE> </TITLE>` | 描述文档标题 |
| `<HEAD> </HEAD>` | 包含文档标题 |
| `<BODY> </BODY>` | 包含文档的大部分 |
| `<!-- comment -->` | 包含注释文本 |
| `<ISINDEX>` | 为可搜索的文档提供搜索提示 |

### 表 15.5. 标签摘要--格式。

| 标签 | 描述 |
| :--- | :--- |
| `<Hn> </Hn>` | 标题级别，其中 n 为 1 到 6 或 7 |
| `<Hn ALIGN=xxx> </Hn>` | HTML 3--定义标题对齐方式：`LEFT`、`CENTER` 或 `RIGHT` |
| `<P> </P>` | 定义段落开始，通常前面有一个空行；结束标签可选 |
| `<P ALIGN=xxx> </P>` | HTML 3--定义段落文本对齐方式：`LEFT`、`CENTER` 或 `RIGHT` |
| `<ADDRESS> </ADDRESS>` | 定义地址块 |
| `<BLOCKQUOTE> </BLOCKQUOTE>` | 定义包含引用的块 |
| `<PRE> </PRE>` | 定义预格式文本块 |
| `<PRE WIDTH=nn> </PRE>` | 定义指定大小的预格式文本块 |
| `<CENTER> </CENTER>` | Netscape--段落居中 |
| `<BR>` | 换行（强制新行） |
| `<HR>` | 水平线（绘制一条线） |
| `<B> </B>` | 物理格式：粗体 |
| `<I> </I>` | 物理格式：斜体 |
| `<S> </S>` | 物理格式：删除线 |
| `<U> </U>` | 物理格式：下划线 |
| `<TT> </TT>` | 物理格式：打字机（等宽字体） |
| `<BLINK> </BLINK>` | Netscape--物理格式：闪烁 |
| `<FONT SIZE=n> </FONT>` | Netscape--指定字体大小，n 为 1 到 7 |
| `<BASEFONT SIZE=n>` | Netscape--文档默认字体大小，n 为 1 到 7 |
| `<EM> </EM>` | 逻辑格式：强调 |
| `<STRONG> </STRONG>` | 逻辑格式：强 |
| `<CITE> </CITE>` | 逻辑格式：引用 |
| `<CODE> </CODE>` | 逻辑格式：程序代码 |
| `<KBD> </KBD>` | 逻辑格式：键盘输入 |
| `<SAMP> </SAMP>` | 逻辑格式：输出示例 |
| `<VAR> </VAR>` | 逻辑格式：程序变量 |
