## 第3章 查找文件和文件夹

- 使用 `find` 命令搜索
- 使用 `find` 精细化搜索：
  - 仅搜索文件或文件夹
  - 按文件名或文件夹名搜索
  - 按路径搜索
  - 指定多个搜索选项
  - 运行不区分大小的搜索
  - 对表达式部分进行分组
  - 使用 NOT 操作符排除搜索结果
- 对搜索结果执行操作
  - 打印路径
  - 删除文件
  - 执行
  - 在执行前确认命令
