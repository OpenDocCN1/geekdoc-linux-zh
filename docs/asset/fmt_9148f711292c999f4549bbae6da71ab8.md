```
$\frac{\partial f}{\partial x} = \lim_{h\to 0} \frac{f(x+h,y)-f(x,y)}{h}$
```

在 $(a,b)$ 点可微的充分条件是偏导数 $f_x$ 和 $f_y$ 在 $(a,b)$ 可微。可微概念的主要意义在于为多变量提供了链式法则。该规则规定，如果一个函数是可微的，例如如果 $z(t) = f(x(t), y(t))$，其中 $f$ 是可微的，且 $x(t), y(t)$ 是可微的，那么复合函数 $z(t) = f(x(t), y(t))$ 关于 $t$ 也是可微的，且

```
$\frac{\partial z}{\partial t} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}$

$\frac{\partial z}{\partial x} = \frac{\partial f}{\partial x}, \frac{\partial z}{\partial y} = \frac{\partial f}{\partial y}$
```
