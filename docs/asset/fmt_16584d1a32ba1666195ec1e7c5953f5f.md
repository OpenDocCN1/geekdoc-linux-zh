# bibtex2html

BibTeX 到 HTML 的转换器和 BibTeX 过滤工具集，用于过滤 BibTeX 数据库以及从 BibTeX 数据库生成 HTML 文档：

- `auxbib` 提取一个 BibTeX 数据库，其中仅包含被一个文件引用的条目。
- `bibbib` 是一个过滤工具，它可以在多个参考文献文件上运行，根据给定标准过滤条目，并输出所选键的列表以及一个仅包含所选条目的新参考文献文件；
- `bibtexhtml` 是一个转换器，它能读取参考文献列表并生成两个 HTML 文档：一个是以精美格式展示的引用的参考文献，另一个是原始 BibTeX 文件，该文件被添加了多个透明的 HTML 链接以允许以任何视图进行查看。

请参阅 [bibtex2 页面](http://www.iri.fr/bibliothèque/bib2html/index.en.html)。来自 Debian 3.0r APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# bibview

X11 参考文献数据库工具是一个用于使用和设置 BibTeX 参考文献数据库的工具。LaTeX 随后可以在文档的引用和参考文献中自动使用这些数据库。来自其 README：它 [`bibview`] 支持你进行创建新条目、搜索条目以及将条目从一个 Bib 移动到另一个。`bibview` 是用 Xt 和 Athena Widget 实现的。`bibview` 中有六种窗口：主窗口包含用于自定义 `bibview` 和在文件级别处理 Bibs 的菜单。参考文献窗口（每个打开的 Bib 对应一个）显示条目列表，它负责操作 Bib。编辑窗口（每个打开的 Bib 最多一个）显示作者、标题、类型和年份。卡片窗口（每个条目最多一个）用于编辑条目的字段。可以通过将鼠标光标置于字段中来编辑这些字段。字段中的宏和连接符号 (`#`) 用前缀 `'@'` 标记。来自 Debian 3.0r APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- Beta 被 Alpha 伪装。
- Gamma 中的某人启动它，irc 服务器（在互联网上）获取 Gamma 中用户的用户名。所有这些计算机都运行 `bident`（来自 inet），Gamma 可以有任何 ident 守护进程，因为它不再进行进一步伪装。来自 Debian 3.0r APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
