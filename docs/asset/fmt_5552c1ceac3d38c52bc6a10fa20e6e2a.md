
# 说明
RHCSA 考试 `EX200` 在运行 RHEL 8 的桌面系统上以电子方式提供。考试列出了一需要在规定时间内完成的任务。需要考虑防火墙和 SELinux。在系统上执行的所有设置必须在系统重启后依然，否则将无法获得分数。考试期间禁止访问互联网、打印材料和电子设备。

# 模拟考试 1 的设置
构建一个带有 GUI 的 RHEL 8 Server 虚拟机（练习 1-1 和 1-2）。为操作系统添加 10GB 磁盘并使用默认存储分区。添加 2 个 300MB 的磁盘。添加一个网络接口，但不要配置主机名和网络连接。安装期间不要创建普通用户账户。
