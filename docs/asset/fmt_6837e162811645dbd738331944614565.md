
## 磁盘与目录

以下是 `/opt/informix/ids7.30` 和 `/opt/data` 目录包含内容的解释。

`/opt/informix/ids7.30.` 此目录存放软件——该树下的所有软件。为 Informix 软件至少预留 500MB。这里不存储任何数据。对 `$INMIXDIR` 变量使用此约定。

`/opt/data.` 此目录存放熟制文件 dbspaces；如果可能，这应该是另一个驱动器。这仅用于数据。

## 空间考虑

你应该预留多少空间？你可以采用 2GB 磁盘并分配如下。

对于运行空间：

- Rootdb: 50MB
- Physdbs: 50MB
- Logdbs: 100MB
- Tempdbs0: 300MB
- 总计: 500MB

对于数据空间：

- Dbs_dbs: 100MB
- Datadbs01: 250MB
- Indexdbs01: 250MB
- 总计: 600MB

例如，如果你预留了一个 2GB 磁盘，你现在分配了 1100MB，并且留有增长空间。这只是一个起点，并非对所有系统都是硬性的。这些大小也是保守的，不会浪费太多数据库空间。只有 rootdb 和 physdb 的大小是真正固定的，但这些也是随意的：在正确配置系统后，你会发现这些大小可以进行调整。从这里开始，如果需要，以后可以更改。完成后，rootdb 空间的使用量非常少，因此你不应该让它超过 50MB；在大多数情况下，20MB 就足够了。

`/work` 是你选择的用于工作的挂载文件系统。为此磁盘至少预留 1000MB。这是一个用于准备加载文件以及管理进出数据的 Linux 磁盘。

用于其首次在线操作的服务器。

## 配置

正如我在本章开头指出的，有三个环境变量需要设置。现在我们已经能够处理第二个变量，即 `INFORMIXSERVER`，以及第三个变量 `ONCONFIG`。

在本章的范围内，我们只关注如何启动服务器；性能考虑超出了本章的范畴，它们应该被视为持续学习过程、试错以及 Informix 运行文档的一部分。

`INFORMIXSERVER` 变量直接对应于 `$ONCONFIG` 文件中的 `DBSERVERNAME`。请为 `DBSERVERNAME` 使用与您为服务器设置的相同的名称。在想要连接到此服务器的客户端上，您也将在客户端的 `INFORMIXSERVER` 变量上使用相同的名称。`INFORMIXSERVER` 还被用于 `onstat` 等实用程序，以确保与正确的引擎实例进行交互。

我们将在 `$INFORMIXDIR` 和标准的 Linux `/etc` 目录中工作。如您所见，Informix 软件有自己的 `/etc` 目录，我们可以在那里找到配置所需的所有文件。两个最关键的文件 `onconfig.std` 和 `sqlhosts` 将是我们安装的重点。在引擎运行之前，您将制作这两个文件的副本。安装后，您将再次处理您的 `$ONCONFIG` 并进行调整，使 IDS 完全正常运行。

无论您在这里或在 *Administrator's Guide* 中读到了什么，都应该检查 IDS 的发行说明以获取最后的安装指令。您可以在 `$INFORMIXDIR/release/en_us/0333` 目录下找到这些说明。其中包含有关于您安装的软件各个方面的重要注意事项。

执行 `cd $INFORMIXDIR/etc` 并在此目录下运行 `ls -CaF`。您将看到各种文件——特别值得注意的是 `onconfig.std`。我们需要为该文件创建一个副本——该副本将取决于您设置的 `$ONCONFIG` 变量值。

```
$ cd $INFORMIXDIR/etc
$ cp onconfig.std rebel_shm.cfg
```

在这种情况下，它被命名为 `rebel_shm.cfg`。出于惯例，我们在结尾添加了 _shm_。

您可以在一个服务器上运行多个不同的 Informix 实例；_shm 仅代表共享内存，这取决于个人喜好。再次强调，您可以随意命名 ONCONFIG 文件——只需确保像我们为您展示的那样正确设置它即可。

复制完成后，请使用您喜欢的文本编辑器并遵循这些说明。将此文件保存为 ASCII 文本非常重要，因此请确保您的编辑器允许简单的文本编辑。我的个人偏好是使用 Vi；但在 Linux 中有几个类似于 Microsoft Windows 中记事本的文本编辑器。将以下命令替换为您喜欢的文本编辑器，即可编辑 ONCONFIG。

```
$ vi rebel_shm.cfg
```

```
****************************************************************************************************
# INFORMIX SOFTWARE, INC.
# Title:           onconfig.std
# Description:     Informix Dynamic Server Configuration Parameters
****************************************************************************************************
```

## Root Dbspace 配置

| ROOTNAME | rootdbs | Root dbspace 名称 |
| :--- | :--- | :--- |
| ROOTPATH | /dev/online_root | 包含 root dbspace 的设备路径 |
| ROOTOFFSET | 0 | root dbspace 在设备中的偏移量 (Kbytes) |
| ROOTSIZE | 20000 | root dbspace 的大小 (Kbytes) |

## 磁盘镜像配置参数

| MIRROR | 0 | 镜像标志 (Yes = 1, No = 0) |
| :--- | :--- | :--- |
| MIRRORPATH | | 包含镜像 root 的设备路径 |
| MIRROROFFSET | 0 | 镜像设备中的偏移量 (Kbytes) |
