在此示例中，输出是信息性的，没有错误。这并不常见。

你也可以使用 `dnf history` 来卸载软件包。有两种方法：回滚 `rollback` 或撤销 `undo`。
`rollback` 命令将反转从当前点到指定事务 ID 的所有 DNF 事务。`undo` 命令将撤销标识 ID 中的更改。

在测试系统中，你将看到 2022年4月17日安装的 Nmap，它是使用 `dnf history 34` 命令完成的：
