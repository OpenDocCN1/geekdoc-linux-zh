
# Bryopsis（裸藻属）
Bryopsis（裸藻属）中丝状、自由分枝的原始配子体产生大量叶状植物，这些植物可能直立、简单或稀疏分叉，生长成簇状，并产生顶端的雌生殖结构（颈卵器），这些结构可能是直立的、略微弯曲、簇生的、交织的垫状，并在侧面产生颈卵器。在大型直立生长的植物中，茎部可能具有类似于木质部和韧皮部但木质化程度较低的中央维管组织束。在较小的植物中，维管组织退化或缺失。假根是多细胞结构，呈纠缠状。花序通常被分化出的叶片包裹，且源自表层的性器官常与假器细胞（paraphyses）混合，尤其在雄性花序中。颈卵器呈烧瓶状；精子器呈香蕉状且带有柄。参见：门、木质部。长寿命的孢子体在光照和空气下呈丰富的绿色。孢蒴通过帽状的苞片（operculum）开裂，或者罕见地通过不规则破裂开裂。蒴壁通常呈海绵状，尤其是在孢子囊之前的颈部。气孔通常存在，尤其在颈部或蒴与蒴柄的交界处。孢子囊在孢子囊成熟后在蒴内形成；蒴壁由内生层（endothecium）的分裂形成。蒴帽（calyptra）可能是盔状（锥形且具裂片）或罩状（一侧开裂且呈兜帽状）。染色体数量差异极大；多倍体现象很常见，既存在于物种内部，也存在于相关物种之间。参见：ARCHIDIIDAE, BRYIDA, BRYOPHITA, BUXBAMIIDAE, DAWSONIIDAE, POLYTRICHIDAE, TETRAPHIDAE. [H.C.]

## Bryopsidales（石枝藻目）
绿藻门（Chlorophyceae）的一个目，也称为 Caulerpales（管藻目）、Codiaceae 或 Siphonales（丝状藻目），其植物体（藻体）为协调的丝状体（管状或虹状）。该目包含六个科，约有24个属。丝状体可能是离散、自由或侧面连接的分枝，或组织成具有明显形态特征的致密网络。隔膜（septa）通常较少且不完全，由离心沉积的细胞壁物质形成。大的连续中央液泡将细胞质限制在紧贴细胞壁的薄层中。细胞质含有不可变的细胞核、圆盘状质体和其他细胞器。无性生殖很常见，通常通过匍匐枝或碎片进行。生殖细胞可能在丝状体的非结区或微结区形成，或在特殊器官中形成。参见：AGARUM（江蓠属）, CHLOROPHYCEAE（绿藻纲）。[PC.S.I. R.L.McD.]

## Bryophyta（苔藓动物门）
*注：此处原文标题为 Bryophyta（通常指苔藓植物门），但根据下文描述“固着水生无脊椎动物”、“多足体（Polyzoa）”、“水螅体（zooids）”等特征，此处描述实为**苔藓动物门（Bryozoa）**（俗称苔藓虫）。翻译遵循原文意图描述苔藓动物。*
固着水生无脊椎动物（也称为多足体 Polyzoa）的一个门，它们形成由水螅体（zooids）组成的群落。每个水螅体在其基本形态上，具有位于内翻部（introvert）远端的、由纤毛触手组成的头冠（lophophore），一个口位于头冠内、肛门位于外的环状肠道，以及位于其内的一个小腔，腔内含有保护性的外骨骼。群落的大小和生活习性多变。有些被称为蕾丝珊瑚，另一些被称为海垫，但唯一通用的名称是苔藓动物（海苔藓）。群落可能非常微小，仅由单个取食水螅体及其直接芽体组成；也可能相当庞大，形成周长3英尺（1米）、长1.6英尺（0.5米）的团块，或面积2.7平方英尺（0.25平方米）的斑块。通常，群落形成仅几平方厘米的钙质覆层，高至约1.2英寸（3厘米）的小型枝状灌木，或最大维度约0.3英尺（0.1米）的软质团块。在许多群落中，大部分体积由水螅体外骨骼组成，这些外骨骼可能在生物死后长期留存，这也是化石苔藓动物遗骸丰富且常见的原因。
许多苔藓动物表现出多型现象，即某些水螅体在特定方式上适应执行专门功能，如保护、清洁表面、固定群落或庇护胚胎。非取食多型体的进化依赖于水螅体间某种形式的通讯。Bryozoa 是一个门的名称，Ectoprocta（外肛亚门）通常被视为其同义词，这些名称由动物学家根据个人偏好使用。Entoprocta（内肛亚门，同义词 Calcistellozoa）也被认为是一个独立的门。少数观点认为 Entoprocta 和 Ectoprocta 是 Bryozoa 内的亚门，而另一些观点保持 Ectoprocta 和 Entoprocta 为门，但将它们归为 Bryozoa 作为一个便利名称。参见：ENTROPROCTA（内肛亚门）。
该门包含约20,000个已描述物种，其中五分之一是现生种。这些物种分布在三个纲和数量多变的目中：

  - 纲 Stenolaemata（狭茎虫纲）
    - 目 Cyclostomata（环口目）
      - 亚目 Cyclostomata（环口亚目，已灭绝）
      - 亚目 Trepostomata（柱口亚目）
      - 亚目 Cryptostomata（隐口亚目）
      - 亚目 Hederellidae（常春藤苔科）
参见：GYMNOLAEAMATA; PHYLACTOLAEAMATA; STENOLAEAMATA.
淡水苔藓动物存在于大多数湖泊、池塘和河流中的淹没树根和水生植物上，特别是在碱性pH值的清澈水域中。大多数其他苔藓动物是海生的，尽管一些 Gymnolaemata（裸茎虫纲）栖息在咸淡水水域。它们在海中很常见，分布范围从海滨中部到超过26,000英尺（8000米）的深度，在大陆架水域中最为丰富。大多数附着在坚固的底质上，因此其分布主要取决于支撑物的可用性。淤泥不利于生存，除非提供了足够的石头、死贝壳、水螅体或大型有孔虫，否则沙地也不利。
苔藓动物的群落形态在一定程度上与栖息地有关。覆盖型和灌木型柔性物种适应波浪冲击；脆弱的枝状和叶状物种分布在较深处；更直立的分枝物种能耐受沉积物堆积。一组微小的圆盘状物种生活在温暖海域的沙中，在一个属中群落如此微小，实际上生活在沙粒之间；少数物种锚定在泥中生活。一些匍匐茎齿苔（stolone ctenostomates）钻入软体动物壳作为底质；其他物种仅与寄居蟹有关联，少数与虾或多毛类蠕虫共生。
苔藓动物的严重捕食者很少。裸鳃类软体动物和蜘蛛蟹（pycnogonids，海蜘蛛）专门取食水螅体，很少摧毁整个群落。内肛亚门（Loxosomatids）和水螅（Zanclea）是常见的共生生物。寿命各异。小型藻类共生种在几个月内完成其生命周期。许多物种能存活一年，但有两年重叠的世代；其他是多年生的，已知有能存活12年的物种。

# 化石苔藓虫
化石苔藓虫拥有悠久的地质历史，从奥陶纪早期（5亿年前 [500 Ma]）一直延续到最近时期。单个化石的尺寸从几毫米到最大维度数米不等。各种附着性或直立性的生长形式都很常见，尽管有些种类是自由生活的。分泌钙质骨骼的海洋类群代表（如Cyclostomata、Cystostomata、Cheilostomata及其他）通常在地生动生物繁盛的沉积岩中非常丰富。骨骼通常由方解石组成，尽管有些是文石或方解石与文石的混合物。Ctenostomata（羽苔虫纲）具有非矿化的骨骼，因此它们仅以海洋贝壳上的挖掘痕迹或钻孔形式，或者在覆盖它们的生物底面的形式保存下来。淡水Phylactolaemata（叶苔虫纲）具有凝胶状骨骼，但它们坚韧的休眠繁殖体（statoblasts）已被报告存在于可追溯至侏罗纪（至少150 Ma）的沉积物中。在奥陶纪、石炭纪和二叠纪期间，苔藓虫是许多浅海（深度小于100米）热带海域的化石珊瑚礁、礁坪及其他碳酸盐岩建造体的重要组成部分。苔藓虫通常在古生代之后的凉爽温带碳酸盐岩沉积物中占主导地位，并且可能达到极高的多样性，这表明古生代之后主要生存环境发生了转变。
尽管许多苔藓虫物种的群体很大，但每个水螅体（zooid，群体的基本单位）的个体骨骼直径从不到0.1毫米到约1毫米不等。较小的直径是分泌管状结构包裹水螅体的石苔虫纲（stenolaemate bryozoans）群居苔藓虫的典型特征，而较大的直径则是叶苔虫（cheilostomeans）等轴性水螅体的典型特征。鉴定基于许多外部以及对于大多数石苔虫来说也是内部特征，这些特征需要用显微镜进行研究。群体骨骼（zoaria）的特征以及个体水螅体骨骼（zoecia）的形态被用于对苔藓虫进行分类。许多化石苔藓虫只有一种类型的水螅体（营养水螅体，autozooids），它们显然能够进行摄食并执行群体的所有其他必要生物功能。其他种类具有多态性，具有各种类型的特化水螅体补充营养水螅体。多态体的数量、类型和形态对分类很重要。化石苔藓虫分类中其他重要的特征包括壁结构、生殖室、一般生长习性或群体的特定形状，以及某些种类的群体表面地形。[E.FK,MM]

## 七叶树属
*七叶树属*（*Aesculus*）是一个属于蔷薇目（Sapindales，即无患子目）的落叶乔木或灌木属。七叶树生长在北美、东南欧以及印度以东的亚洲。其显著特征是对生的掌状复叶，以及具有坚硬外壳的大型果实，通常包含一颗具有显著种脐的大种子。
