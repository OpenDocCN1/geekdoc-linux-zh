
如果你打印了错误的文件，可以使用 `lprm` `jobID` 命令取消作业，其中 `jobID` 是通过 `lpq` 或 `ipstat` 显示的信息获取。当有其他作业在该打印机的队列中等待时，此方法将有效。但是，你必须检查自己是否是唯一使用这台打印机的人，因为作业通常会被缓存并在几秒内发送到打印机。当它们到达打印机时，就太晚可以使用 Linux 工具移除作业了。

在这些情况下，或者在配置了错误的打印驱动程序导致打印出的内容不对的情况下，你可以尝试关闭电源。然而，这可能不是最佳行动方案，因为你可能会导致纸张卡壳或其他异常。

## 使用 tar 归档

大多数情况下，我们首先将备份的数据收集到一个归文件中，稍对其进行压缩。归档过程涉及合并列表的文件并去除无效块。在 Linux 中，这通常通过 `tar` 命令完成。`tar` 最初设计用于在磁带上归档数据，但它也可以创建归档（tarball）。

`tar` 有许多选项，最重要的列在下方：

- `-v`: 详细模式

- `-t`: 测试，显示 tarball 内容

- `-x`: 提取归档

- `-c`: 创建归档

- `-f archivedevice`: 使用 `archivedevice` 作为 tarball 的源/目标，设备默认为第一个磁带设备（通常为 `/dev/st0` 等）

- `-j`: 通过 bzip2 过滤，见“使用 tar 进行增量备份”章节

### 使用 GNU tar 以保持兼容性

在某系统中使用专有的 tar 版本创建的归档，可能与另一个专有系统上的 tar 不兼容。这可能会导致很多麻烦，例如，当需要在已不存在的系统中恢复归档时。在所有系统上使用 GNU tar，以防止你的系统管理员崩溃流泪。Linux 使用 GNU tar。在 UNIX 上工作时，输入 `tar --help` 来查看你使用的是哪个版本。如果你在某处没有看到“GNU”字样，请联系你的系统管理员。

在下面的示例中，创建并解压了一个归档。

```
gaby-> ls images/
me+tux.jpg  nimf.jpg
```

```
gaby-> cvf images-in-a-dir.tar images/
images/
images/nimf.jpg
images/me+tux.jpg
```

```
gaby-> cd images
```

```
gaby-> tar cvf images-without-a-dir.tar *.jpg
me+tux.jpg
nimf.jpg
```

```
gaby-> ls *.tar
```

```
gaby-> ls *.tar
images/images-without-a-dir
```

```
gaby-> tar xvf images-in-a-dir.tar
images/
images/nimf.jpg
images/me+tux.jpg
```

```
gaby-> tvf images-without-dir.tar
-rw-r-- gaby/gaby 42888 1999-06-30 20:52:25 me+tux.jpg
-rw-r-- gaby/gaby 7578 2000-01-26 12:58:46 nimf.jpg
```

```
gaby-> tar xvf images-without-a-dir.tar
me+tux.jpg
nimf.jpg
```

```
gaby-> ls *.jpg
me+tux.jpg  nimf.jpg
```

这个示例还阐明了 tar 目录和一组 tar 文件之间的区别。建议只压缩目录，这样文件在解压 tar 包时就不会散落到处处（tar 包可能在另一个系统，你可能并不知道那里已经有了文件，也不知道哪些是来自归档的文件）。

当磁带驱动器连接到机器并由系统管理员配置时，以 `.tar` 结尾的文件会被磁带设备名称替换，例如：

```
tar cvf /dev/tape mail/
```

### 使用 tar 进行增量备份

该工具支持创建增量备份，使用 `-N` 选项。通过此选项，你可以指定一个日期，`tar` 将将文件的修改时间与该日期进行对比。如果文件的修改时间晚于该日期，它们将被包含在备份中。示例使用了上一个归档的时间戳作为日期值。首先，创建初始归档并显示初始备份文件的时间戳。然后，当你进行新备份时，会创建一个新文件，其中仅包含新文件：

```
jimmy-> tar cvf /var/tmp/javaproggies.tar java/*.java
java/btw.java
java/error.java
java/hello.java
java/income2.java
java/income.java
java/inputdevice.java
java/input.java
java/master.java
java/method1.java
java/mood.java
java/moodwaitress.java
java/test3.java
java/TestOnes.java
java/TestTwo.java
java/Vehicle.java
```
