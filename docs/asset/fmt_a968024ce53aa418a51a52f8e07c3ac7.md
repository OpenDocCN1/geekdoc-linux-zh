
# 文件系统监控 135

既然我们知道了命令和输出在不同操作系统之间的差异，在创建加载每个系统的 shell 函数时，可以考虑到这一点。注意在下面的函数中，有一个或多个文件系统被设置为挂载，这是通过 `egrep` 指定的。

```
function load_AIX_FS_data {
    df -k | tail +2 | egrep -v '/dev/cd[0-9]|proc'
    awk '{print $1, $2, $3, $4, $7}'
}
```

```
function load_HP_UX_FS_data {
    bdf tail +2 | egrep -v '/mnt/cdrom'
    awk '{print $1, $2, $4, $5, $6}'
}
```

```
function load_LINUX_FS_data {
  df -k | tail +2 | egrep -v '/mnt/cdrom/'
  awk '{print $1, $2, $4, $5, $6}'
}
```

```
function load_Solaris_FS_data {
  df -k | tail +2 | egrep -v '/dev/fd|/etc/mntab|proc/'
  awk '{print $1, $2, $4, $5, $6}'
}
```
