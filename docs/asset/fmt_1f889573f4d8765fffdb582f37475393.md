Java 是一种高级、并发、面向对象的语言和运行时环境。Java 应用程序被编译为字节码（称为类文件），由 Java 虚拟机（JVM）执行，独立于计算机架构。JVM 通过垃圾回收器（garbage collection）来帮助处理不再使用的内存，而不是像其他语言中那样手动释放内存。

# 原则

Java 语言的设计具有以下主要目标：

- 1. 简单、面向对象且熟悉。

- 2. 健壮且安全。

- 3. 架构无关且可移植。

- 4. 执行具有高性能。

- 5. 解释型、多线程且动态。

- 6. 写一次，随处运行 (WORA)。
