
# Linux 命令速查

## 基础命令列表

- `basename`: 从文件名中去除目录和后缀
- `bash`: GNU Bourne-Again Shell
- `bc`: 任意精度计算器语言
- `bg`: 发送到后台
- `break`: 退出循环
- `builtin`: 运行 shell 内置命令
- `bzip2`: 压缩或解压指定文件
- `cal`: 显示日历
- `case`: 有条件地执行命令
- `cat`: 连接并打印（显示）文件内容
- `cd`: 更改目录
- `cfdisk`: Linux 分区表操作器
- `chgrp`: 更改组所有权
- `chmod`: 更改访问权限
- `chown`: 更改文件所有者和组
- `chroot`: 使用不同的根目录运行命令
- `chkconfig`: 系统服务 (runlevel)
- `cksum`: 打印 CRC 校验和及字节计数
- `clear`: 清除终端屏幕
- `cmp`: 比较两个文件
- `comm`: 逐行比较两个排序文件
- `cp`: 将一个或多个文件复制到另一个位置
- `cron`: 执行计划命令的守护进程
- `crontab`: 安排命令在以后时间运行
- `csplit`: 将文件分割为上下文确定的片段
- `cut`: 将文件分成几部分
- `date`: 显示或更改日期和时间
- `dc`: 桌面计算器
- `dd`: 转换并复制文件，写入磁盘头，启动记录
- `ddrescue`: 数据恢复工具
- `declare`: 声明变量并给予它们属性
- `df`: 显示可用磁盘空间
- `diff`: 显示两个文件之间的差异
- `diff3`: 显示三个文件之间的差异
- `dig`: DNS 查询
- `dir`: 简要列出目录内容
- `dircolors`: `ls` 的颜色设置
- `dirname`: 将完整路径名转换为仅路径
- `dirs`: 显示已记住的目录列表
- `dmesg`: 打印内核和驱动程序消息
- `du`: 估算文件空间使用量
- `echo`: 在屏幕上显示消息
- `egrep`: 在文件中搜索匹配扩展表达式的行
- `eject`: 弹出可移动媒体
- `enable`: 启用和禁用 shell 内置命令
- `env`: 环境变量
- `ethtool`: 以太网卡设置
- `eval`: 评估多个命令/参数
- `exec`: 执行命令
- `exit`: 退出 shell
- `expect`: 自动化通过终端访问的任意应用程序
- `expand`: 将制表符转换为空格
- `export`: 设置环境变量
- `expr`: 评估表达式
- `false`: 不做任何事情，不成功
- `fdformat`: 低格软盘
- `fdisk`: Linux 分区表操作器
- `fg`: 将作业发送到前台
- `fgrep`: 在文件中搜索匹配固定字符串的行
- `file`: 确定文件类型
- `find`: 搜索符合特定标准的文件
- `fmt`: 重新格式化段落文本
- `fold`: 将文本折行以适应指定宽度
- `for`: 展开单词，并执行命令
- `format`: 格式化磁盘或磁带
- `free`: 显示内存使用情况
- `fsck`: 文件系统一致性检查和修复
- `ftp`: 文件传输协议
- `function`: 定义函数宏
- `fuser`: 识别/终止正在访问文件的进程
- `gawk`: 在文件中查找和替换文本
- `getopts`: 解析位置参数
- `grep`: 在文件中搜索匹配给定模式的行
- `groupadd`: 添加用户安全组
- `groupdel`: 删除组
- `groupmod`: 修改组
- `groups`: 打印用户所在的组名
- `gzip`: 压缩或解压指定文件
- `hash`: 记住名称参数的完整路径名
- `head`: 输出文件的前几部分
- `help`: 显示内置命令的帮助
- `history`: 命令历史
- `hostname`: 打印或设置系统名称
- `htop`: 交互式进程查看器
- `iconv`: 转换文件的字符集
- `id`: 打印用户和组 id
- `if`: 有条件地执行命令
- `ifconfig`: 配置网络接口
