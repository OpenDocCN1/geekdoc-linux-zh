## 16.2.5 使用 TFTP 上传文件

虽然上述基于 Windows 的文件传输方法适用于自 Windows 7 和 Windows Server 2008 R2 以来的所有 Windows 版本，但在遇到较旧的操作系统时，我们可能会遇到问题。PowerShell 虽然非常强大且经常使用，但在 Windows XP 和 Windows Server 2003 等操作系统上默认并未安装，而这些系统在某些生产网络仍然可见。虽然 VBScript 和 FTP 客户端都存在且良好，在本节中，我们将讨论另一种在实战中可能有效的文件传输方法。

TFTP 是一种基于 UDP 的文件传输协议，通常受到企业出口防火墙规则的限制。

在渗透测试期间，我们可以使用 TFTP 从较旧的操作系统（如 Windows XP 和 2003）传输文件。这是非交互式文件传输的极佳工具，但在运行 Windows 7、Windows 2008 及更高版本的系统上默认并未安装。

由于某些原因，TFTP 并不是大多数情况下的理想文件传输协议，但在适当的情况下，它有自己的优势。
