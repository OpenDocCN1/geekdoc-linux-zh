## 历史替换

在许多情况下，调回和编辑命令可能并不容易。例如，bash 提供了类似于 sh 的操作符来进行历史操作（替换）。当 bash 遇到 `!` 运算符时开始历史替换，前提是其后面没有跟着空格、`=` 或 `(`。如果 `!` 运算符后面跟着这些字符，bash 将执行取反而非历史替换。

简单的历史替换是 `!` 运算符后跟随需要重新执行的命令的编号。例如：

```
!213
```

将执行历史记录中命令编号为 213 的命令。通常情况下，这种历史替换被称为 `!n`，其中 n 是命令编号。如果 n 是负数，则会调回并执行当前命令之前的第 n 条命令。例如，下所示：

```
!-10
```

将执行 10 个命令前所执行的命令，可以通过以下方式调回最后执行的命令：

```
!-1
```

由于调回上一个命令是一项常见任务，bash 为其提供了 `!!` 快捷方式。此外，可以通过提供命令开头或包含的字符串部分从历史记录中调回命令。例如，可以通过以下方式调回上次的邮件：

```
!mail
```

使用特定字符串调回命令的通用语法是 `!string`。在前面的示例中，这种历史替换不会调回包含字符串 `mail` 的其他命令（如 `sendmail` 或 `rmail`），但如果 `mailtool` 命令出现在历史记录中 `mail` 命令之前，它将调回该命令。如果历史替换的形式为 `!!?string?`，Bash 会调回包含特定字符串的命令。例如：

```
!?host?
```

可以用于调回 `hostname`、`gethostname`、`ypac hosts` 和 `echo $host` 命令。

有时调回命令是不够的，因为 bash 支持几种真正的替换历史替换。其中最简单的是 `^string1^string2^` 替换，它将上一个命令中的 `string1` 替换为 `string2`。如果执行了：

```
xv koala.gif
```

然后需要查看图片 `kangaroo.gif`，可以使用以下快速替换：

```
^koala^kangaroo^
```

更高级的替换操作可以调回传递给之前命令的参数。其中最简单的是 `!:0`，它调回上一个命令的名称。例如，如果给出了：

```
cpwd () { [ -n "$1" ]; then cd "$1"; fi; pwd
```

并且需要用 `type` 命令查看格式化版本，以下命令将产生所需结果：

```
type !:0
```

一旦看到了格式化后的函数，就需要使用它，因此，以下命令：

```
!:^ /bin
```

将调回函数的名称，该名称被作为 `type` 的第一个参数传递，因为 `:^` 替换调回传递给命令的第一个参数。有时需要调回最后一个参数，可以使用 `$!` 或 `!:$` 替换。这些操作符是更通用的 `!:` 替换的快捷方式，它调回传递给命令的第 n 个参数。如果需要命令的第三个参数，则将使用 `!:3` 替换。

仅仅为命令调回一个参数是不够的。例如，如果执行命令：

```
man -background white -geometry 135x55
```

并且想要相同背景颜色和几何形状的参数，以下替换：

```
perfmeter !*
```

将产生所需结果，因为 `*` 和 `!:*` 替换用于调回传递给命令的整个参数列表。这些替换是 `!:x-y` 替换的特殊形式，它们调回传递给命令的所有从 x 到 y 的参数。例如，如果以下命令是：

```
javac -d -O rectPanel.java
```

后续编译需要第二个和第三个参数（编译器标志），则替换：

```
javac !1-3 javaStartDate.java
```

将产生所需结果。

作为一个一般规则，历史替换可以混合使用，并写成 `!string:option`，其中 `option` 是之前讨论过的选项 `0`、`n`、`^`、`$`、`x-y` 和 `*`。例如，如果 finger 命令如下：

```
finger ranga@soda.berkeley.edu sriranga@ocf.berkeley.edu
```

在执行了几个其他命令后，需要向这些用户发送邮件，则以下命令：

```
mail !:*
```

将产生结果。

# Korn Shell

第 8 章“什么是 Shell”介绍了 shell 的基础知识，第 9 章“Bourne Shell”专门讨论了 Bourne shell。本章通过引入第二种主要的 shell 语言 Korn 来扩展这些主题。第三种主要 shell 语言将在第12 章“C Shell”。

Korn shell 以其作者 David G. Korn 命名，他在 1986 年编写了该程序的第一版本。因此，Korn 是 Bourne shell 的直接后代。它与 Bourne shell 几乎完全兼容；除了少数例外，任何为 Bourne shell 的脚本都可以由 Korn 正确执行。

由于 Korn 是作为 Bourne shell 的替代品和改进版引入的，最好作为对 Bourne shell 基本功能的扩展来进行讨论。第 9 章“Bourne Shell”中介绍的 shell 操作的方面在这里不再重复。相反，本章总结了 Bourne shell 和 Korn shell 之间的差异。Korn 的增强非常广泛，从深刻到细微不等。最显著的增强是那些便于与 shell 交互的功能，但你也应该了解 shell 语法和编程技术的的重要扩展：

- **命令别名。** 别名允许你缩写常用的命令而无需使用 shell 编程，提高了你的整体键盘效率。
- **命令历史。** 你可以单独使用命令历史，也可以结合命令编辑来修改和重用之前的命令。你也可以将历史记录作为键盘操作的日志。
- **命令编辑。** Korn 提供了两种命令编辑样式，允许你在输入时修订和修正命令。命令编辑可以大大减少你重输命令的时间。
- **目录管理。** Korn 提供了对 `cd` 命令的扩展、新的路径语法和新的 shell 变量，用于方便切换目录和缩写长路径。
- **算术表达式**。Bourne shell 提供的算术能力非常有限。如果需要强大的数字处理能力，即使是一台手持计算器也是更更好的计算工具。
- **语法改进**。Korn shell 在 `if` 语句、内置命令和命令替换表达式的语法上提供了改进，这可以提高你的 shell 脚本的功能和可读性。
- **通配符表达式**。Korn shell 提供了更多通配符格式，以减少你的输入工作量。
- **协处理器**。Bourne shell 传统的管道被扩展，允许你的 shell 脚本与你调用的命令之间进行更灵活的、程序化的交互。
- **作业处理**。Korn shell 包含了批监控功能，可以简化后台进程运行，并允许你同时执行更多任务。
- **特权模式切换**。Bourne shell 没有提供特殊特性来利用 UNIX 的 Set User ID（UID）功能。相反，Korn shell 的特权模式允许你开启和关闭 Set User ID 模式，从而开发以前需要 C 语言编程的进程脚本。

尽管你已经接触过 C shell，但你会发现 Korn shell 的特性与 C shell 重复，但语法不同。这是刻意为之。虽然 C shell 提供了许多理想特性，但它的通用语法与 Bourne shell 不兼容，这使其在 UNIX 世界中显得有些“格格不入”。Korn shell 通过提供人们想要的键盘和 shell 特性，并以一种与旧的、成熟的 Bourne shell 兼容的形式呈现，解决了 UNIX 世界中这一长期存在的难题。

## Shell 基础 (Shell Basics)

正如我之前提到的，Korn shell 是一个与 Bourne shell 等效的基础，在其之上增加了一层新功能。你可以根据对 Korn shell 特性的特殊知识，将 Korn shell 作为 Bourne shell 的对等替代品。除非你显式调用它们，否则 Korn 扩展不会发挥作用。

Korn shell 在以下领域与 Bourne shell 相同：

- **重定向输入和输出**。Bourne shell 的重定向运算符 `<<`、`>` 和 `>>` 以及文档设施 `<<label` 都具有相同的语法和工作方式。一个在此文档（here document）中的示例是将一个文本块插入脚本，并可以将其重定向到另一个进程或文件。例如：

```
$ cat <<--
This is a demonstration of here document. As you can see the
document uses the operator << to tell the shell that all the
text on the next
line to the label, in this case is !, is all to be read in and
redirected to
the cat command. This tells the shell to remove leading tabs
of the line.
!
```

这是一个文档的演示。如你所见，文档使用运算符 `<<` 告诉 shell 从下一行到标签（在此例中为 `!`）的所有文本都将被读取并重定向到 `cat` 命令。这告诉 shell 移除开头的制表符。

- **在一行中输入多个命令**。分号 (`;`) 标记语句的结束。要在一行中输入多个命令，只需在每个命令末尾加上分号即可。
