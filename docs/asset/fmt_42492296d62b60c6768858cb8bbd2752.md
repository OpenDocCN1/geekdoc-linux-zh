```bash
# 则对员工姓名进行次要排序。

# -t: 分隔符设定为冒号

# 注意：使用 (key) 时，第一个字段从 1 开始，而不是 0。

# -k5: 针对第 5 字段；按数字排序 (n)；

# -k5r: 针对第 5 字段；按数字排序 (n)，反序 (r)。

# -k4: 对 empl_name 字段进行次要排序。

# 更多示例见此文件底部。
```
