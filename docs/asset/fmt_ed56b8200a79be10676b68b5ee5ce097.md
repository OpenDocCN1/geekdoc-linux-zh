
## 集成开发环境 (IDE)

集成开发环境（IDE）是一种通过组合代码编辑器、调试器和构建自动化工具来辅助软件开发的软件。某些 IDE（如 `IntelliJ IDEA` 和 `Eclipse`）包含了编译器或解释器，简化了开发流程。它们模糊了更广泛开发工具的界限，通常包含版本控制和 `GUI` 构建工具。IDE 通过统一界面集成相关组件来提高效率，使得编写、调试和部署软件变得容易。它们适用于各种编程语言，某些针对特定语言。现代 IDE 是图形化的，尽管文本版本曾占据主导。

`Visual Studio Code` 由微软开发，是一款适用于 Windows、Linux 和 macOS 的多功能源码编辑器，提供调试、语法高亮、智能代码补全等功能。它支持广泛的编程语言，并通过主题、快捷键和扩展进行自定义，增强了其功能性。`VS Code` 集成了源码控制，允许自定义编码环境，并允许使用各种扩展支持新语言或工具。尽管会收集使用数据，但其开源性质确保了透明度。它没有传统的项目系统，而是允许打开目录并将其保存为工作区，适用于具有大量扩展支持的任何语言。

`Atom-ng` 是一款适用于 Linux、Windows 和 macOS 的现代可定制文本编辑器，基于 `Electron` 构建，注重定制化和易用性。它支持多种操作系统，包括旧版本的 Windows 和各种 Linux 发行版。最近更新改进了扩展安装，引入了 macOS x64 支持，并通过深色模式和更好的标签管理增强了用户界面。它还通过 `SIMD` 优化提供了性能提升，并对没有 `AVX` 的 CPU 保持兼容。

`Atom-ng` 将深度定制选项与易于上手的默认设置相结合，旨在满足所有用户的偏好。`VSCodium` 是微软 `VS Code` 编辑器的社区驱动开源版本，去除了遥测数据和品牌标识。它提供相同的功能，但通过移除跟踪和专有功能来尊重用户的隐私和自由。该项目简化了获取 `VS Code` 优势的途径，无需从源码编译，提供了根据 `MIT` 许可证许可的二进制文件。这项倡议解决了对软件自由和隐私的担忧，为那些偏好或需要开源解决方案的用户提供了这款流行编辑器的支持。`VSCodium` 确保所有人都能轻松获取最新的、纯净的 `VS Code` 版本。

`Atom` 是由 `GitHub` 开发的一款免费开源文本和源代码编辑器，适用于 macOS、Linux 和 Windows。它于 2015 年发布，因其高度的可定制性（hackability）而受到赞誉，允许使用 `HTML`、`CSS` 和 `JavaScript` 进行自定义。`Atom` 构建在 `Electron` 框架之上，支持 `JavaScript` 插件和内置 `Git` 控制，具有高度的适应性。用户可以通过 `Atom` 的包管理器 `apm` 通过第三方软件包和主题增强其功能。尽管 `Atom` 已经退役，但它作为一种功能多且友好的开发者编辑器的遗产依然存在，凸显了它在使用网络技术推进代码编辑方面的作用。

`Geany` 是一款免费、轻量级的文本编辑器，具有基础 IDE 功能，为速度设计，依赖项极少。它支持广泛的编程语言和标记语言，提供语法高亮、代码折叠、自动补全和项目管理等功能。`Geany` 的通用性跨越多个操作系统，包括 BSD、Linux、macOS、Solaris 和 Windows，尽管其 Windows 版本缺少内置终端和某些 Unix 工具（除非用户自行添加）。与传统的 Unix 编辑器不同，`Geany` 类似于 `Notepad++` 这样的 Windows 编程编辑器，使用 `Scintilla` 和 `GTK` 界面。它不断进化，遵循 `GPL v2` 或更高版本许可，展示了其对开源社区的承诺。

`Bluefish` 是一款为程序员和 Web 开发者设计的强大编辑器，对各种编程和标记语言提供广泛支持。它是一个遵循 `GPL` 许可的开源项目，运行在 Linux、macOS 和 Windows 等多个平台。`Bluefish` 以其快速、轻量级的设计和高效处理文档的能力脱颖而出。它支持多线程文件编辑、强大的搜索和替换、代码片段以及与外部程序的集成。此外，它还提供自定义语言支持、行拼写检查、自动恢复和站点管理工具，使其成为编码和 Web 开发的全面工具。

## `Visual Studio Code`

访问 `Visual Studio Code` 官方网站 [https://code.visualstudio.com](https://code.visualstudio.com) 获取所有相关信息。

通过软件包管理器安装 `DEB`/`Flatpak` 包：

- 打开软件包管理器搜索 `Visual Studio Code`。
- 点击 `Visual Studio Code`，进入源选择框。
- 选择系统包或 `Flatpak` 并点击安装。

通过 `APT` 仓库安装 `Visual Studio Code`：

输入以下命令：

```bash
sudo apt update
```

```bash
sudo apt-get install wget
```

```bash
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.gpg
```

```bash
sudo install -D -o root -g root -m 644 packages.gpg /etc/apt/keyrings/microsoft.gpg
```

```bash
sudo sh -c 'echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/microsoft.gpg] https://packages.microsoft.com/repos/code stable main" > /etc/apt/sources.list.d/vscode.list'
```

```bash
sudo apt install apt-transport-https
```

```bash
sudo apt update
```

```bash
sudo apt install code
```

通过 `Snap Store` 安装 `Snap` 包：

- 在 `Snap Store` 中查找 `Visual Studio Code`。
- 点击 `Visual Studio Code`，进入源选择框。
- 选择 `Snap` 下的最新/稳定版本并点击安装。

通过 `Snap` 安装 `Visual Studio Code`：

输入此命令：

```bash
sudo snap install code --classic
```

通过 `Flatpak` 安装 `Visual Studio Code`：

输入此命令：

```bash
flatpak install flathub com.visualstudio.code
```

通过 `GUI` 安装 `.deb` 版 `Visual Studio Code`：

访问发布页面：

https://code.visualstudio.com/#downloads

- 点击 `.deb` 下载 `Visual Studio Code`
- 进入 `~/` 文件夹
- 双击 `code_1.86.2-1707854558_amd64.deb`
- 点击安装
