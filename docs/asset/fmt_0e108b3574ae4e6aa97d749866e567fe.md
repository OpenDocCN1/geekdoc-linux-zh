mkdir -p opt/minicom/bin opt/minicom/etc/rc

### 20. 在嵌入式 Linux 工作坊中，每个 `opt` 包都可以包含一个 `Makefile`
该 `Makefile` 有三个目标：`everytime`、`binaries` 和 `dependencies`。`everytime` 目标通常不被使用。`binaries` 目标用于重新构建任何自上次构建以来源码发生更改的二进制文件，并将这些二进制文件移动到 `opt` 包中。一旦包构建完成，就会对这些二进制文件进行 `strip`（去除符号表）。`dependencies` 目标列出了 `opt` 包的任何依赖项。例如，`minicom` 可执行文件依赖于 `ncurses` 库。显然，你不需要使用 `cat` 命令来构建 `Makefile`；这里有一组命令；请注意缩进行是用单个制表键缩进的：

```
cat > opt/minicom/Makefile
everytime:
binaries:
  @cd ../src/minicom/src && make
  @cp -f ../src/minicom/src/minicom bin
  @strip bin/minicom
  @strip --remove-section=.note -remove-section=.comment bin/minicom
dependencies:
  @echo libncurses
```

在此处按 `Ctrl+D`。

### 21. 嵌入式 Linux 工作坊配备了一套启动脚本，其工作类似于 Red Hat 脚本
`/etc/rc` 目录下的每个以字母 `S` 开头的脚本都会按排序顺序执行。将脚本命名为 `S99(something)` 意味着它应该是最后一个运行的脚本，并且可能不会返回给调用者。这里有一组命令：

```
cat > opt/minicom/etc/rc/S99minicom

#!/bin/sh
echo "Press a key for minicom"
read x
minicom -s
```

在此处按 `Ctrl+D`。

我们在 Minicom 中使用的 `-s` 选项将直接进入设置模式。它默认是 `COM2`；必要时更改该设置。

在实际设备中，你会创建一个 `minicom` 配置文件并让它直接启动。你也不会强迫用户按键启动，但通过这种方式，你可以在 Minicom 擦除它们之前看到任何启动错误信息。

### 22. 现在使脚本变为可执行

```
chmod a+x opt/minicom/etc/rc/S99minicom
```

### `arch/*src`

`arch/*src` 目录包含大量的子目录，每个对应一个源码模块。每个源码模块内至少有一个压缩包、一个提取出的目录和一个指向该目录的符号链接。例如，在 `src` 目录下有以下条目：

| 文件 | 描述 |
| --- | --- |
| sed-02.tar.gz | 源码。 |
| 文件 | 描述 |
| --- | --- |
| sed-02 | 提取出的源码。你对环境所需的所有更改都在这里。 |
| sed | 指向 sed-02 的符号链接。对目录的任何引用都应通过此符号链接进行。这样，将来你升级到 sed 4.0 版本时，只需将源码下载到 `src` 目录，提取它，进行更改并将 sed 符号链接指向新目录即可。构建脚本或任何其他地方无需感知更改。 |

### `arch*/opt`

`arch*/opt` 包含了构建过程产生的对象。每次你从 `elw` 菜单选择构建时，该目录下的内容通常都会重新构建。然而，如果 `opt` 的构建过程失败，它将保持原样；通过这种方式，分发的 `elw` 包含了所有源码。

| README | 了解关于软件包的一些信息，如它们的来源、用途等。此文件供 ELW 开发者使用。 |

### `bin/elw`

嵌入式 Linux 工作坊的核心是 `elw` Perl 脚本。你的作者并不是 Perl 僧——所以这个脚本看起来更像 C。

#### 用法

在命令行输入 `elw --help` 会产生以下内容：

```
Usage:
elw [Options]:
--config DIR 告诉 elw 项目目录在哪里。
--define NAME 定义 NAME。可以作为配置中的标记。
--execute CMD 执行除菜单以外的 CMD。查看源码。
-?, --help 显示此用法信息。
-m DIR, --elhome DIR 如果 ELHOME 不是 /usr/local/elw 或未在环境变量 ELHOME 中设置，则设置。
--newproject DIR 在 DIR 中创建一个新项目。

-V, --verbose 详细输出。
```
