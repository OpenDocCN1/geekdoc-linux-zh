
ADR X0, A               ADR X0, A

label1: SUB X0, X0, #1 label1: SUB X0, X0, #1

label2: STR X1, [X0]    label2: STR X1, [X0]

## 函数返回值

许多函数通过 `X0` 寄存器返回值。例如：

```
long func();
```

返回值位于 `X0` 中。

```
bool func();
```

返回值位于 `W0` 中。

布尔值在内存中占用一个字节，因此编译器使用 `W0` 而不是 `X0`。

bool arithmetic (int a, int *b)
