## 练习

- 1. 从 Gnome 或 KDE 菜单打开音频配置面板。确保音箱或耳机已连接到你的系统，并找到一个适合你的输出水平。确保当你的系统兼容 ALSA 时使用的是正确的面板。
- 2. 如果你有麦克风，尝试录制自己的声音。确保输入音量不要太大，否则在他人交流时会出现高调音，或向对方传输背景噪音。在命令行中，你甚至可以尝试使用 `arecord` 和 `aplay` 进行录音和播放。
- 3. 在系统中找到音频文件并播放。
- 4. 插入 CD 并尝试播放。
- 5. 寻找一个聊天伙伴并配置 VoIP 程序。（你可能需要先安装一个。）
- 6. 你能听网络电台吗？
- 7. 如果你有 DVD 播放器且 DVD 盘上有电影，尝试播放它。
