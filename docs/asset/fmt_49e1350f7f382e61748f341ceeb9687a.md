
在使用 Oracle RAC 时，当 `oranstab` 文件放置在 `$ORACLE_HOME/dbms` 时，文件中的条目特定于共享数据库。在这种情况下，所有运行 Oracle RAC 的节点使用相同的 `$ORACLE_HOME/dbms/oranstab` 文件。在非共享 Oracle RAC 安装中，`oranstab` 必须在所有节点上进行复制。

2. 输入以下命令：

```

```
