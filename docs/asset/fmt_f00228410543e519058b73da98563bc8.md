
要从磁盘检索数据库，请使用 `XrmGetDatabase`。

```c
XrmDatabase XrmGetFileDatabase(filename);
```

`filename` 指定资源数据库名称。

`XrmGetFileDatabase` 打开指定的文件，创建一个新的资源数据库并根据指定文件中读取的规范加载它。指定的文件应包含 `ResourceLine` 格式的序列条目（见第 15.1 节）；从语法错误的文件读取时生成的数据库取决于具体实现。文件在当前区域设置中解析，数据库也处于当前区域设置中。如果无法打开指定的文件，`XrmGetFileDatabase` 返回 `NULL`。

要将数据库副本存储到磁盘，请使用 `XrmPutFileDatabase`。

```c
void XrmPutFileDatabase(database, stored_db);
```

`database` 指定要使用的数据库。

`stored_db` 指定存储数据库的文件名。

`XrmPutFileDatabase` 函数将指定数据库的副本存储在指定文件中。文本以 `ResourceLine` 格式的条目序列写入文件（见第 15.1 节）。文件在数据库的区域设置中写入。包含非主机可移植字符编码的资源名称或包含非数据库区域设置编码值的条目，将以取决于实现的方式写入。以除 `"String"` 外的其他表示类型写入条目的顺序将被忽略。

要获取显示器与屏幕无关的资源指针，请使用 `XResourceResourceManagerString`。

```c
char *XrmResourceManagerString(display);
```

`display` 指定到 X 服务器的连接。

## 资源管理器函数

`XResourceManagerString` 函数从服务器的零号窗口屏幕返回 `RESOURCE MANAGER` 属性，该属性是在使用 `OpenDisplay` 打开连接时返回的。该属性从 `STRING` 类型转换为当前区域设置。该转换与 `XmPropertyToToList` 生成单个 `STRING` 属性的结果相同。返回的字符串由 Xlib 所有，不应由客户端释放。属性值必须是 `XrmGetStringDatabase` 可接受的格式。如果不存在属性，则返回 `NULL`。

要获取屏幕资源的指针，请使用 `XScreenResourceString`。

```c
char *XScreenResourceString(screen);
```

`screen` 指定屏幕。

`XScreenResourceString` 函数从指定屏幕的窗口返回 `SCREENRESOURCES` 属性。该属性从 `STRING` 类型转换为当前区域设置。该转换与 `XmPropertyToToList` 生成单个元素属性的结果相同。属性值必须是 `XrmGetStringDatabase` 可接受的格式。如果不存在属性，则返回 `NULL`。调用者负责使用 `XFree` 释放返回的字符串。

从字符串创建数据库，请使用 `XrmGetStringDatabase`。

```c
XrmDatabase XrmGetStringDatabase(data);
```

`data` 使用字符串指定数据库内容。

`XrmGetStringDatabase` 创建新数据库并存储字符串中指定的资源。`XrmGetStringDatabase` 类似于 `XrmGetFileDatabase`，它从文件读取信息。字符串应包含 `ResourceLine` 格式的条目（见第 15.1 节）；从语法错误的文件读取生成的数据库取决于实现。文件在当前区域设置中解析，数据库处于当前区域设置中。如果无法打开指定的文件，`XrmGetStringDatabase` 返回 `NULL`。

要获取数据库的名称，请使用 `XrmLocaleDatabase`。

```c
char *XrmLocaleDatabase(database);
```

`database` 指定数据库。

`XrmLocaleDatabase` 函数返回绑定到数据库的名称，这是一个以空字符终止的字符串。该字符串由 Xlib 所有，在数据库销毁前不应释放。Xlib 不允许释放该字符串。

要销毁数据库并释放其内存，请使用 `XrmDestroyDatabase`。

```c
void XrmDestroyDatabase(database);
```

`database` 指定数据库。

## 资源管理器函数

如果 `database` 为 `NULL`，`XrmDestroyDatabase` 将立即返回。

将资源数据库与显示器关联，请使用 `XrmSetDatabase`。

```c
void XrmSetDatabase(display, database);
```

`display` 指定到 X 服务器的连接。

`database` 指定资源数据库。

`XrmSetDatabase` 函数将指定的资源数据库与显示器关联（如果之前有关联）。客户端可能会发现此函数非常方便。

要获取与显示器关联的资源数据库，请使用 `XrmGetDatabase`。

```c
XrmDatabase XrmGetDatabase(display);
```

`display` 指定到 X 服务器的连接。

`XrmGetDatabase` 函数返回与显示器关联的数据库。如果没有设置数据库，则返回 `NULL`。

## 合并数据库

将资源文件的内容合并到数据库，使用 `XrmCombineFileDatabase`。

```c
Status XrmCombineFileDatabase(filename, target_db, override);
```

`filename` 指定资源数据库名称。

`target_db` 指定要合并入的数据库。

`override` 指定哪些条目覆盖目标。

`XrmCombineFileDatabase` 将资源文件的内容合并到数据库中。如果文件中的条目使用了相同的指定项，当 `override` 为 `True` 时，文件中的条目将替换数据库中的条目；否则文件中的条目在当前区域设置中解析。如果找不到文件，返回零状态；否则返回非零状态。如果 `target_db` `NULL`，`XrmCombineFileDatabase` 将为其创建并返回新数据库。`target.db` 将被更新，不会被销毁。合并条目时无论区域设置如何，都不会更改值或类型。目标数据库的区域设置不会被修改。

将一个数据库的内容合并到另一个数据库，使用 `XrmCombineDatabase`。

```c
void XrmCombineDatabase(source_db, target_db, override);
```

`source_db` 指定要合并到目标数据库的资源数据库。

`target_db` 指定源数据库要合并到的资源数据库。

`override` 指定源项是否覆盖目标项。

`XrmCombineDatabase` 函数将一个数据库的内容合并到另一个数据库中。如果两个数据库中的条目使用了相同的指定符，则如果 `override` 为 `True`，则源数据库将替换目标数据库中的条目；否则，源数据库中的条目将被丢弃。如果目标数据库包含 `NULL`，`XrmCombineDatabase` 将仅存储源数据库。否则，源数据库在合并时会被销，但 `target` 指向的数据库不会被销。数据库条目将被合并，不会更改数据库区域设置的值或类型。目标数据库的区域设置不会被修改。

要使用带有覆盖语义将一个数据库的内容合并到另一个数据库，请使用 `XrmMergeDatabases`。

```c
void XrmMergeDatabases(source_db, target_db);
```

`source_db` 指定目标数据库要合并到的资源数据库。

`target_db` 指定源数据库要合并到的资源数据库。

调用 `XrmMergeDatabases` 函数等同于调用参数为 `True` 的 `XrmCombineDatabase` 函数。

## 查找资源

要从资源数据库中检索资源，请使用 `XrmGetResource`、`XrmGetResourceSearchResource`。

```c
Bool XrmGetResource(database, str_name, str_class, str_type_return, value_return);
```

`database` 指定要使用的数据库。

`str_name` 指定要检索的值的完全限定名（字符串形式）。

`str_class` 指定要检索的值的完全限定类（字符串形式）。

`str_type_return` 返回目的地的表示类型（字符串形式）。

`value_return` 返回数据库中的值。

```c
Bool XrmGetResource(database, quark_name, quark_class, quark_type_return, value_return);
```
