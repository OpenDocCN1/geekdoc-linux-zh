## 配置控制中心

如果你想使用控制中心管理工作站并在你的 DB2 服务器上调度运行脚本，你需要设置运行时（JRE）。你可以作为 Java 应用程序或通过 Web 服务器作为 Java Applet 运行控制中心。我们建议将 Java 应用程序运行控制中心。有关更多信息，请参考位于 `/usr/IMDBatch2/v6.1/cc/prime` 目录下的名为 `readme.htm` 的控制中心 README 文件。本节中的说明将假设你正在设置控制中心作为 Java 应用程序运行。如果你不想使用控制中心，可以跳过此节并继续进行本章后面的“安装 DB2 客户端”部分。

要在你的 DB2 服务器上设置控制中心，请执行以下步骤：

- 1. 以具有 root 权限的用户身份登录你的工作站。
- 2. 下载适当的 JRE。有关支持的 JRE 和浏览器的最新信息，请访问 http://www.software.ibm/data/db2/
要运行控制中心，你需要至少运行 Java 1.1.7 v3 或更高版本。
RedHat 的 JRE 可以从 Blackdown 网站 http://www.blackdown.com/java-linux/mirrors.html 获取。
对于此示例，我访问了镜像站点 ftp://www.blackdown.com/java-linux/mirrors.html。

你可以使用本节中的指令来安装 DB2 客户端或 DB2 管理客户端。在示例中，我们将安装 DB2 管理客户端，因为它存在于你安装 DB2 服务器时使用的 DB2 通用数据库 6.1 版本光盘中。DB2 管理客户端也提供于 DB2 管理客户端光盘中；DB2 运行时客户端仅提供于 DB2 运行时光盘中。欲更多信息，请参阅《DB2 和 DB2 Connect 安装与配置》。

安装 DB2 客户端，请执行以下步骤：

- a. 以具有 root 权限的用户登录 RedHat 工作站。
- b. 将 DB2 通用数据库 6.1 版本光盘插入光驱驱动器中。
  即使你正在运行 RedHat 6.1 版本的的工作站上安装 DB2 客户端，并且使用的是下载的补丁文件创建的镜像，你仍然需要使用 DB2 光盘。补丁文件使用其创建的文件以及 DB2 光盘上的文件来安装 DB2 客户端。更多信息，请参阅补丁附带的 `readme.txt` 文件。
- c. 输入以下命令挂载光盘：
  ```
  mount -t iso9660 -o ro /dev/cdrom /mnt/cdrom
  ```
- d. 输入以下客户端命令切换焦点到挂载的光盘目录：
  ```
  cd /mnt/cdrom
  ```
如果你在运行 RedHat 6.1 版本的的工作站上安装 DB2 客户端，不要忘记切换到你实施补丁文件时创建的目录。更多信息，请参阅补丁提供的 `readme.txt` 文件。

- e. 输入 `/db2setup` 命令启动 DB2 安装程序。如图 7.17 所示打开安装 DB2 V6 窗口。

DB2 安装程序将生成一个名为实例所有者 (`instance-owner`) 的默认用户。该用户对实例拥有系统管理员 (`SYSADM`) 权限。对实例拥有 `SYSADM` 权限的用户对实例中的所有对象具有完全的控制和权限。

在我们的示例中，接受默认值。在“密码”字段中输入与安装 DB2 服务器时相同的密码，在“验证密码”字段中进行验证，并选择“确定 (OK)”。

**提示** 我们将在 DB2 服务器和 DB2 客户端上使用相同的用户 ID 和密码，以简化我们的示例场景。

如果你未指定密码，将使用默认密码。

使用 TCP/IP 访问远程 DB2 服务器或该服务器上相应的代理，有时可能会出现挂起状态。DB2 使用 TCP/IP `SO_KEEPALIVE` 套接选项来检测是否存在故障以及 TCP/IP 连接是否断开。如果您在 TCP/IP 连接方面遇到问题，请参阅 *DB2 故障排除指南* 获取如何调整此参数的信息，以及有关其他常见 TCP/IP 问题的信息。

要配置 DB2 客户端通过 TCP/IP 与 DB2 服务器通信，请按照以下步骤操作：

- 1. 识别并记录所需的 TCP/IP 参数。这些参数如表 7.1 所示。

| **主机名 (hostname) 或 IP 地址 (ip_address)** | 使用 DB2 服务器的主机名或 IP 地址。<br><br>要解析此参数：<br>- 在 DB2 服务器上输入 `hostname` 命令获取主机名。<br>- 输入 `ping hostname` 命令获取 IP 地址，或联系您的系统管理员。 | db2server<br>或<br>92.125.124 | |
| **服务名 (svcename) 或 端口号/协议 (port_number/tcp)** | `/etc/services` 文件中的值。<br><br>服务名是代表 DB2 客户端端口的任意本地名称。DB2 客户端的端口必须与 DB2 服务器 `/etc/services` 文件中 `svcename` 映射的端口相同（`svcename db2inst1` 映射到端口 50000/tcp 由 DB2 服务器上的数据库配置定义）。此端口号不能被任何应用程序使用，且在 `/etc/services` 文件中必须唯一。 | 要确定 `svcename` 参数，请以 `SYSADM` 权限登录 DB2 服务器并输入 `db2 get db cfg` 命令。默认 DB2 服务器安装的 `svcename` 参数为 `db2inst1`，它映射到默认端口 `50000`。 | |

- 2. 确保远程 DB2 服务器的 TCP/IP 地址已解析。如果您计划直接指定 DB2 服务器的 IP 地址，或者您的网络中有名称服务器，则可以跳过此步骤。您可以使用 `ping hostname` 命令 ping DB2 服务器来验证。DB2 客户端必须能够解析其尝试建立通信的 DB2 服务器地址。如果您的网络不存在名称服务器，则必须在本地 `/etc/hosts` 文件中直接指定映射到服务器 IP 地址的主机名。

计划支持使用网络信息服务 (NIS) 的任何基于 Unix 的 DB2 客户端且未使用名称服务器，则必须更新位于 NIS 主服务器上的 `/etc/hosts` 文件。
