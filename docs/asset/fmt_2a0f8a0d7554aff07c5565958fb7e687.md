# 响应温度变化

在第 10 步中，你编写了读取温度并将值存储在变量中的代码。将其与当前温度进行比较。记住，如果有幽灵，就会出现突然的差异。如果温度在一秒内下降不到 5 度，则说明有幽灵。触发相机，然后将新温度设置为新的温度值。这将适应夜间温度的缓慢下降。

```python
***检查温度变化***
if current_temp - start_temp < 5:
    print("GHOST")
    start_temp = current_temp
```
