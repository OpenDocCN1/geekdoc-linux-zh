# 不间断电源系统

不间断电源系统提供对断电以及电压和频率变化的保护。

市电会影响贵设备的各种应用场景。这可能包括计算机系统、电话交换机、通信网络、医疗和实验室设备、电子收银机、监护室等。

不间断电源系统有三种基本类型。每种类型由复杂的组件组成：旋转电源、电池电源和固态不间断电源系统。

旋转电源由一个电池驱动的电机组成，该电机机械连接到交流发电机。电池通过连接到市电电线的充电器保持充电状态。在市电断电的情况下，电池驱动电机，电机驱动发电机。发电机通过输出端驱动负载。

电池电源由一个连接到直流逆变器的电池组成。逆变器通过开关为负载提供电源。充电器保持电池充电。正常情况下，负载由市电运行；市电断电时，开关将负载转移到逆变器的输出端。

固态不间断电源系统具有通用配置，但有一个重要的例外：与电池电源不同，负载连续从静态逆变器运行。市电中发生的所有变化都通过逆变器通过不间断电源系统的输出端过滤掉。

如果发生市电断电，电池电通过开关转移到负载。这种方案被称为自动在线反向变压器式不间断电源系统。
