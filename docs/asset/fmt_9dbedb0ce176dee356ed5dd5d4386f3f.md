# 附录 D 命令参考

* 语法部分中命令参数周围的方括号 `[]` 表示该参数是可选的，可以省略。

`cd`
更改当前目录。
* 语法
  `cd [directory name]`
* 常用选项
  `-` 切换到上一个目录。
* 相关命令：`ls`, `pwd`

`cp`
复制文件。
* 常用选项
  `-i` 尽可能保留原始文件权限。
  `-a` 在复制每个文件时请求确认。
  `-f` 如果目标位置已存在该文件，则复制的文件将覆盖现有文件。

`chgrp`
更改组所有者。
* 语法
  `chgrp [group] filename`
* 常用选项
  `-R` 递归更改目录。
* 相关命令：`chown`, `chmod`

`date`
显示日期。
* 语法
  `date [string]`
* 注意
  如果不指定字符串，则显示当前时间。

`chmod`
更改权限。
* 语法
  `chmod [mode] filename`
* 常用选项
  `-R` 递归更改目录。

`chown`
更改所有者。
* 语法
  `chown [user[:group]] filename`
* 常用选项
  `-R` 递归更改目录。

`diff`
比较文件差异。
* 语法
  `diff file1 file2`

`df`
显示磁盘空间。
* 语法
  `df [file]`
* 常用选项
  `-k` 以 KB 为单位显示。
  `-h` 以易读格式显示。

`du`
显示目录占用空间。
* 语法
  `du [options]`
* 常用选项
  `-h` 以易读格式。
  `-s` 显示汇总。

`find`
搜索文件。
* 语法
  `find [path] [expression]`
* 常用选项
  `-name` 按文件名搜索。
  `-size` 按大小搜索。
  `-type` 按类型搜索。

`grep`
在文件中搜索字符串。
* 语法
  `grep [options] pattern [file]`
* 常用选项
  `-n` 输出行号。
  `-i` 忽略大小。
  `-v` 显示不匹配的行。

`mkdir`
创建目录。

`mv`
移动或重命名文件。
* 语法
  `mv source destination`

`ls`
列出目录。
* 语法
  `ls [file]`
* 常用选项
  `-l` 以长格式显示。
  `-F` 在文件末尾添加类型标识。
  `-a` 显示所有文件，包括以点开头的文件。

`rm`
删除文件或目录。
* 语法
  `rm [options] file`
* 常用选项
  `-r` 递归删除。

`mount`
挂载文件系统。
* 语法
  `mount [-options] device mountpoint`

`umount`
卸载文件系统。
* 语法
  `umount [mountpoint]`

`pwd`
显示当前工作目录。
* 语法
  `pwd`

## `mount/unmount`
挂载和卸载文件系统。

## `ps`
* 语法
* `mount 设备名 挂载点`
* `unmount 设备名或 挂载点`
* 常用选项
* `-o` 挂载选项。
* `-t` 文件系统类型。

* 显示进程。
* 语法
* `[进程 ID]`
* 常用选项 
* 显示所有用户的进程。
* 显示未受终端控制的进程。
* 以用户名显示。
* 扩展每行的宽度。
* 在命令列中仅显示可执行文件的文件名。

* 相关命令：`df`, `fuser`, `stab`
* 注意
* 如果在执行 `mount` 命令时不指定设备名或挂载点，将显示与文件系统相关的挂载项。

* 相关命令：`top`, `tree`, `killall`
* 注意
* 如果执行 `ps` 命令时不指定进程 ID，则只显示用户执行的进程。如果指定了进程 ID，则只显示指定进程 ID 的进程。你必须在进程 ID 后输入一个选项。

## `mv`
* 语法
* `mv 文件 目录`
* 常用选项
* 如果目标位置已存在文件，移动的文件将覆盖现有文件。
* `-i` 每次移动时请求用户确认。
* 注意
* `mv` 命令也可用于重命名文件。

## `pwd`
显示当前目录。

* 语法
* `pwd`
* 相关命令：`cd`, `ls`

### `passwd`
更改密码。

* 语法
* `passwd [用户名]`
* 相关命令：`chfn`, `chsh`
* 注意
* 只有 root 可以更改用户名。普通用户只能更改自己的密码。

执行终端设置。
* 语法

* 相关命令：`st`

应用补丁。

* 语法
* `patch <file`
* 常用选项
* `-p` 指定补丁文件内文件名的描述。
* 相关命令：`diff`

## `rm`
删除文件。

* 常用选项
* 删除当前目录下的所有文件。
* `-f` 在不确认的情况下删除只读文件。
* `-i` 请求用户确认删除每个文件（红色默认设置）。

* 相关命令：`mv`, `in`
* 注意
* 删除的文件无法恢复，因此使用此命令时请小心。

## `shutdown`
退出系统。

## `su`
更改用户 ID。

* 语法
* `shutdown [-h|-r] 时间 [message]`

* 语法
* `su [username]`

* 常用选项
* `-h` 退出。
* `--` 将环境设置匹配给切换的用户。
* `-r` 重启。
* `-m` 将环境设置匹配给当前用户。
* `-c` 取消计划的关机。
* `-command` 执行命令。

* 相关命令：`sync`
* 相关命令：`id`
* 注意
* 如果在时间上指定 "now"，关机操作立即开始。已经开始的关机无法取消。如果没有指定 `-h` 或 `-r`，系统将切换到单用户模式。在单用户模式下，所有服务都将停止。在需要进行管理任务时使用此模式。

## `smbpasswd`
在 Samba 中更改密码。

* 语法
* `smbpasswd [username]`

## `sync`
将缓存写入磁盘。

* 语法
* 常用选项
* 相关命令：`df`
* `-a` 添加新用户而不是更改现有用户的密码。
* 注意
* 当你卸载挂载或关闭系统时，`sync` 会自动执行。你可以根据需要执行 `sync` 命令；这可以帮助避免缓存中数据无法写入文件的情况。

* 相关命令：`smbstatus`, `testpasswd`, `testprns`
* 注意
* 通过 `smbpasswd -a` 添加的用户必须已经是注册过的 Linux 用户。

## `tar`
收集文件（归档）。

* 语法
* `tar 目录`
* 常用选项
* `c` 创建归档。
* 相关命令：`smbpasswd`, `testpasswd`, `testpasswd,`
* `t` 显示归包中的文件列表。
* `x` 打开归包。
* `v` 显示命令进度。
* `f` 指定一个文件。
* 示例
* `tar xzf backup-home.tar.gz /home`
* `tar xvf aaa.tar.gz`
* 注意
* `tar` 命令最初是一种磁带归档。因此，如果不使用 `f` 选项指定文件名，Linux 将尝试将数据发送到磁带归档。
* `-n` 按算术排序（默认按字母排序）；
* `-r` 反向排序。
* `-u` 仅显示内容相同的行。
* `-b` 忽略开头的空白字符。

## `smstatus`
显示 Samba 状态。

* 语法
* `smbstatus`

* 语法
* `testpart [smb conf file]`
* `testprns printer机 name [printcap filename]`
* 注意
* 这些工具用于检查 Samba 设置。`testpart` 命令显示所有共享设置。`testprns` 命令检查打印机是否经过 Samba 打印服务的验证。

## `top`
监控进程状态。

* 键操作
* 空格刷新新状态。
* `u` 仅显示特定用户（用户名）。
* `k` 发送信号（输入进程 ID 和类型）。
* `l` 显示帮助。
* 相关命令：`ps`, `pstree`, `killall`
* 注意
* 此命令像 `ps` 命令一样持续显示。在 `top` 中，可以使用操作发送信号。

## `touch`
更改文件的时间。如果文件不存在，此命令将创建一个大小为 0 文件。

* 语法
* `touch file`

## `umask`
指定创建文件或目录时赋予的权限。
