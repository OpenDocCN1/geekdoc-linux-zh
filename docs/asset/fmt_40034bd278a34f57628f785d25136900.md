## 中间件

中间件是一个封装 HTTP 处理器并在处理器执行之前或之后执行某些操作的函数。常见用途包括日志记录、身份验证和请求压缩。

```go
package main

import (
    "fmt"
    "net/http"
    "time"
)

func loggingMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()
        next.ServeHTTP(w, r)
        fmt.Printf("%s %s in %v\n", r.Method, r.URL.Path, time.Since(start))
    })
}

func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprint(w, "Hello, World!")
}

func main() {
    mux := http.NewServeMux()
    mux.HandleFunc("/", handler)
    wrappedMux := loggingMiddleware(mux)
    http.ListenAndServe(":8080", wrappedMux)
}
```

package main

import (

type router struct {

    switch req.URL.Path {
    case "/a":
        fmt.Fprint(w, "Executing /a")
    case "/b":
        fmt.Fprint(w, "Executing /b")
    case "/c":
        fmt.Fprint(w, "Executing /c")

    }
}

    http.ListenAndServe(":8000", &r)
}

## 构建简单的中间件

现在我们来构建中间件，它是一种包装器，无论目标函数是什么，它都会在所有进入请求上执行。在列表 4-3 的示例中，你将创建一个显示请求处理开始和结束时间的日志器。

```go
package main

import (
    "fmt"
    "log"
    "net/http"
    "time"
)

type logger struct {
    Inner http.Handler
}

func (l *logger) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    log.Println("start")
    l.Inner.ServeHTTP(w, r)
    log.Println("finish")
}

func hello(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello\n")
}

func main() {
    f := http.HandlerFunc(hello)
    l := logger{Inner: f}
    http.ListenAndServe(":8000", &l)
}
```
