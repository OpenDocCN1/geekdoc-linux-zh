
你也可以使用八进制数来表示文件权限，如下：

```
chmod 755 student
```

该命令对应于以下内容：

```
4 (读) + 2 (写) + 1 (执行) = 7
4 (读) + 1 (执行) = 5
4 (读) + 1 (执行) = 5
```

它产生以下结果：

```
chmod 755 student
ls -l
-rwxrxr-x 1 root               root       2012-03-06 09:54 student
```

如果你在设置上述权限的同时设置粘滞位（`sticky bit`），命令看起来如下：

```
chmod 1755 student
ls -l
-rwxrxr-t 1 root               root       2012-03-06 10:14 student
```
