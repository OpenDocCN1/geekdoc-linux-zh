## 双引号、单引号（反引号）

我们如何知道在脚本和命令语句中应该使用哪一个呢？这个决定在编写脚本时造成了巨大的困惑。我们现在要把这个问题说清楚。

取决于任务的内容和所需的输出，使用正确的界符符号非常重要。未能正确使用这些符号将导致不可预测的结果。

我们在希望允许字符或命令替换的语句中使用 `"`（双引号）。在标准的美国 QWERTY 键盘上，`"` 位于回车键旁边。我们在不希望进行字符或命令替换的语句中使用 `'`（单引号，此处指反引号）。包含在 `'` 中是为了在变量或命令语句中使用字面量，而不进行任何替换。所有的特殊含义和功能都会被移除。我们在每次使用变量时读取它会使用它；`$PWD` 在处理 `PS1` 命令行提示符时经常使用。`\` 位于标准美国 QWERTY 键盘上的回车键旁边，在字符串前加上反斜杠 `\` 也可以移除字符或字符串的特殊含义。

我们在使用 `` ``（反引号/反引号）的语句中执行一个命令、脚本，并将其输出进行替换；这被称为命令替换。`` ` `` 位于标准美国 QWERTY 键盘左上角的 Escape 键（Esc）下方。命令替换也可以通过 `$(command)` 语法实现。我们将在书中看到这些许多不同的示例。

## 文件权限、suid 和 sgid 程序

将程序设置为始终以特定用户或某组成员的身份执行，通常用于允许所有用户或一组用户在适当环境中运行程序。例如，大多数系统程序需要以管理员用户（有时是 root）身份运行。我们不希望传递密码，因此可以让程序始终以 root 运行——这会让每个人的生活变得更轻松。我们可以使用表 1.6 中的选项来设置文件权限。此外，请复阅 `chmod` 页面。

### chmod 语法

`chmod` 的语法可以是符号的或八进制的。
`chmod [mode] file`
`chmod [octal] file`

使脚本可执行
```bash
chmod 755 script.sh
```
或
```bash
chmod u+rwx,g+rx,o+rx script.sh
```

## 在远程主机上运行命令

我们有时要在远程主机上执行命令并将结果显示在本地。例如获取一组机器的文件系统统计。我们可以通过 `rsh` 命令来实现。语法为 `rsh hostname command_to_execute`。这是一个非常有用的工具，但在 `rsh` 命令工作之前，需要在所有主机上设置一些系统文件。这些文件是 `.rhosts`（创建在用户主目录下，权限为 600）以及 `/etc/hosts.equiv` 文件。

出于安全考虑，默认 `.rhosts` 和 `hosts.equiv` 文件不允许执行远程 shell。小心！这可能会威胁系统安全。请参阅每个操作系统的文档以获取设置这些文件的详细信息。

# 脚本快速上手与回顾 21

谈及安全（security），更优的解决方案是使用 Open Shell (OpenSSH) 代替 `rsh`。在大多数情况下，OpenSSH 是 `rsh`、`telnet` 和 `ftp` 的免费加密替代品。要使用 OpenSSH 在另一台机器上执行命令，请使用以下语法：

```
ssh user@hostname command_to_execute
```

如果两台机器上都没有设置加密密钥对，此命令会提示你输入密码。设置密钥对关系通常少于一小时。该过程的详情在 `ssh` 页面（man `ssh`）中显示。可以通过以下 URL 下载 OpenSSH 代码：www.openssh.org。

## 设置陷阱 (Traps)

当程序在正常退出之前终止时，我们可以捕获退出信号。这被称为陷阱（trap）。表 1.7 列出了某些支持的退出信号。
要查看你的操作系统支持的信号列表，请输入以下命令：

```
kill -l
```

这是我们在 shell 脚本中一个非常好用的工具。捕获陷阱信号可以在我们实际退出 shell 脚本之前执行一些清理命令。在捕获信号时可以执行命令。如果 shell 脚本中加入了以下命令语句，它将在屏幕上打印“EXITING on a TRAPPED SIGNAL”，然后在信号 1、2、3 和 15 时执行干净退出。我们无法捕获 `kill -9`。

```
trap 'echo \nEXITING on a TRAPPED SIGNAL';exit' 1 2 3 15
```

我们可以添加退出前可能需要的各种清理命令。例如，我们可能需要在退出前删除 shell 脚本之前创建的一组文件。

| 1.7 退出信号 | 描述 |
|---|---|
| 0 | 正常终止，脚本结束 |
| 1 | SIGHUP | 挂断，线路断开 |
| 2 | SIGINT | 终端中断，通常为 CONTROL-C |
| 3 | SIGQUIT | 退出键，子进程在终止前先（die） |
| 9 | SIGKILL | kill -9 命令，无法捕获此类型的退出状态 |
| 15 | SIGTERM | kill 命令的默认操作 |
| 24 | SIGSTOP | 停止，通常为 CONTROL-Z |
