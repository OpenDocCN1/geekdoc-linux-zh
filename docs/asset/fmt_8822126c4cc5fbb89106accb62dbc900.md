# 使用 YUM 安装和更新软件包

## 目标

完成本节内容后，你将能够使用 `yum` 命令查找、安装和更新软件软件包。

## 使用 YUM 管理软件包

低层级 `rpm` 命令可以用于安装软件包，但它设计时并非为了处理依赖关系，也不会自动从多个源解析依赖关系。

`yum` 设计用于一个更优的系统来管理基于 RPM 的软件安装和更新。`yum` 命令允许你安装、更新、删除以及获取软件软件包及其依赖项的信息。你可以获取执行过的事务历史，并与多个 Red Hat 和第三方仓库一起工作。

- `yum help` 显示用法信息。
