# Linux 词典

### cache（缓存）

用于当前使用或最近访问数据的临时存储区域。缓存可以是系统级的（位于主板上的专用缓存内存中，或物理刻蚀在处理单元上），也可以基于磁盘的（位于硬盘或 RAM 等主内存中）。源自 Redhat9—Glossary http://www.ldp.org/LDP/Linux-Dictionary/index.html

### cache（缓存）

计算机科学中，缓存一词的意思是保留物品以备再次使用。例如，当你登录系统时，用户名和密码被存储在缓存内存中，因为你每次访问资源时系统都会反复使用它们。关键点：系统可以被用于缓存。示例：HTTP 代理服务器使用这些技术以便成千上万的用户可以缓存同一个 Internet 连接。它们存储使用过的网页，这样当多个用户访问同一个网站时，代理服务器只需访问一次链接即可为所有用户获取页面。一系列漏洞导致了一个用户登录另一个网站时，其他人可以看到该用户数据的情况。浏览器文件缓存：一旦黑客可以查看历史缓存（URL 列表）或文件，就可以重构此网站的操作，以监视用户去过哪里。由于某些上网习惯导致了这些信息发生尴尬、无意的泄露。浏览器缓存：网站的 Cookie 在 Cookie 中存储密码，因此窃取 Cookie 信息将允许黑客以用户身份登录。源自 Hacking（黑客行为）

### cacti

管理系统和服务的工具的前端。`Cacti` 是一个功能完备的工具，它创建图表并用数据填充它们所需的所有信息存储在 MySQL 数据库中。该框架完全由 PHP 驱动。在能够在数据库中维护图表、数据源和 Robin 存档的同时，`cacti` 还负责处理数据收集。对于那些使用 MRTG 创建图表的用户，还有 SNMP 协议。源自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
