
# Y染色体

Y染色体是大多数哺乳动物物种基因组中最小的染色体之一。通常，哺乳动物的Y染色体含有极高比例的异染色质，`Drosophila`的大型Y染色体也是如此。在哺乳动物或`Drosophila`中，Y染色体上的基因很少，且大多数这些基因都与性别决定或精子产生有关。在某些昆虫和其他无脊椎动物物种中，不存在Y染色体，这些物种的性别由X:常染色体平衡决定（XX雌性，XO雄性）。参见细胞核；遗传学；人类遗传学；性别决定；性连锁遗传。[O.J.M.; D.A.M.]

## 染色体畸变

细胞或生物体正常染色体组中任何数量或结构上的变化。

**异倍体。** 数量变化（异倍体）分为两种类型：多倍体和非整倍体。多倍体是染色体组数目的变化。例如，三倍体（`3n`）出现在约1%的人类妊娠中，但它几乎总是胚胎致死性状况。参见减数分裂；有丝分裂；多倍体。

非整倍体是染色体数目偏离二倍体（`2n`）数目（通常存在于有性繁殖生物体的体细胞中）或单倍体（`n`）数目（通常存在于生殖细胞中）以及某些单细胞生物的单倍体组的变化。它通常涉及单条染色体，但组中的任何染色体都可能涉及。非整倍体是减数分裂或有丝分裂期间一条或多条染色体异常分离的结果。如果减数分裂期间发生错误分离或不分离，一个子细胞接收该染色体的两个副本，而另一个子细胞则未接收。用非整倍体精子受精任一细胞，将产生具有该染色体三个副本（三体）或一个副本（单体）的合子。错误分离也可以在体细胞的有丝分裂期间发生，在原本整倍体的个体中产生三体或单体细胞。这种结果主要在某些形式癌症的起源和进展中具有重要意义。

人类活产婴儿中最常见的常染色体（非性染色体）三体是21三体，即唐氏综合征，它是智力残疾和先天性心脏病的主要原因。18三体和13三体个体也存在，但少得多。大多数常染色体三体对胚胎致死，导致自然流产。任何常染色体三体的发病率随母亲年龄呈指数增长。参见染色体；唐氏综合征。

在人类中，涉及性染色体的非整倍体类型比常染色体更多。最常见的是`XO`，发生在约1%的妊娠中。尽管99%的`XO`胎儿在妊娠早期死亡，但其余的1%（约每10,000名活产女性中有1名）存活下来。`XO`成人倾向于身材矮小，颈部有蹼，且由于通常缺乏对卵巢发育至关重要的生殖细胞，很少发育出第二性征或生育子女。这些特征是特纳氏综合征的特征。人类X染色体三体，通常称为`XXX`，与胚胎死亡或先天畸形无关。原因是所有哺乳动物中每个体细胞中只有一条X染色体是活性的。参见人类遗传学。

与常染色体三体相比，性染色体非整倍体随母亲年龄的增加仅略有增加，且额外的X染色体仅在约60%的情况下来自母亲。额外的X染色体可以存在于卵子或精子中；额外的Y染色体只能存在于精子中。`XXX`和`XXY`个体表现出其X染色体数目增加的最小表型效应。`XXY`个体通常与`XY`个体无法区分。Y染色体的存在会导致男性性分化，无论存在多少X染色体，这是因为Y染色体上存在一个单一的关键基因，称为`SRY`。在某些发育为女性的`XY`个体中发现该基因的突变。

**结构异常。** 结构异常（染色体突变）涉及在一条或多条染色体的脱氧核糖核酸（DNA）链连续性被破坏后，染色体片段的获得、丢失或重排。缺失涉及染色体片段及其携带的基因的丢失。末端缺失涉及从破坏点（断裂点）延伸到同一染色体臂末端的片段丢失，这相对不常见。中间缺失涉及染色体一个臂上两个断裂点之间片段的丢失。这种丢失的影响取决于缺失片段中包含的基因。

当每条臂发生一个断裂时，内部着丝粒片段的断裂端可能连接，导致形成稳定的环状染色体。两个末端片段中的每一个都缺乏着丝粒，且此类无着丝粒片段在细胞分裂期间丢失。环状染色体易发生大小减小，以及加倍。因此，具有环状染色体的个体可能表现出不仅缺失而且染色体部分重复的表型效应。

在其他情况下，重复更常发生。例如，染色体部分可在常规的染色体位点发生串联或倒位重复，或者该片段第二份拷贝可能被插入到另一条染色体中。

倒位可通过在染色体的两个断裂点处破坏DNA链，并以相反的方向重新连接断裂末端及中间片段来产生。这一过程会反转该片段上基因的排列顺序。

易位涉及两条或更多染色体之间两个或更多染色体片段的互换。如果易位断裂点破坏了某个基因，该基因的功能将被阻断或异常，这可能会对发育或功能产生有害影响。有时，原本沉默的基因会因染色体重排而与其旁边基因表达的强启动子相邻而被激活，这种变化是癌症的一个重要成因。如果易位未阻断必需基因的功能，也未激活原本沉默的基因，携带该重排的个体将表现正常。

结构异常可自发发生，也可由断裂染色体的因素诱导产生，例如X射线、放射性物质、紫外线及某些化学物质。最常见的原因可能是数种短散在元件（`SINES`）的巨大数量存在，即DNA序列，它们在大体量生物（包括人类）的全基因组中每几千个碱基对就出现一次。这些元件 predispose 在DNA复制或减数分裂期间的基因重组中发生错误，从而导致一条染色体上两个邻近散在重复序列之间区域的缺失或重复。它们也可能在倒位、插入和易位的形成中发挥作用。见“基因重复”、“诱变剂和致癌物”、“突变”。

结构异常的另一个原因在于基因组本身：大量存在的2、3或4个碱基对大小的短重复序列。某些三核苷酸重复序列，如 (`CGG`)n 或 (`CAG`)n，可在减数分裂和有丝分裂细胞分裂过程中发生扩展。这种扩展有时会影响基因功能并导致疾病。人类中最常见的X连锁智力障碍类型是由于 `FMR-1` 基因中特定三核苷酸重复序列 (`CGG`)n 的可遗传扩展，其中扩展数量 (`n`) 从正常的8-20左右增加到50-200或更多。出于未知原因，该扩展区域在某些条件下倾向于发生断裂，这种特定形式的智力障碍被称为脆性X综合征。人类及其他基因组中存在数十种，甚至可能数百种类似的脆弱位点。[OJM; D.A.M]

## 色球层

色球层是太阳及大多数恒星可见表面（光球层）上方的一种由高温气体组成的复杂结构。“色球层”这一术语最初被用来指代通过肉眼在日食时看到的日晕边缘的红环及大型促进星。氢在653纳米波长的巴尔末-alpha线的发射导致其呈现红色。色球层在可见光下是透明的，但在紫外连续光谱及丰富元素的强谱线中不透明且明亮，包括氢、氦（1868年日食期间首次观测到）、氧、钙和镁。气体温度范围从3500到30,000 K（3800到54,000华氏度），密度在每立方厘米 $10^6$ 到 $10^{12}$ 个粒子之间。见“太阳”。

太阳色球层从光球层上方约500公里（300英里）延伸至氢完全电离且气体温度迅速升至超过 $10^6$ K（$1.8 \times 10^6$ 华氏度）的日冕区。在强发射线下拍摄的高分辨率太阳图像揭示了由许多磁环组成的丝状结构。在色球层网络中，位于宽度30,000公里（19,000英里）超颗粒单元边缘处，磁场强，气体密集且高温，色球层厚度可能仅为500公里（300英里）。此处，磁加热率是平均值的10倍或50倍。

称为刺状的细薄气体射流聚集在色球层网络中。在超颗粒单元中心，磁场较弱处，色球层气体冷却至3500 K（5800华氏度），并向上延伸数千米。见“超颗粒化”。

有效温度低于约8000 K（14,000华氏度）的恒星（太阳为5770 K，9930华氏度）显示与太阳光球层相同的发射谱线，因此被认为具有类似区域。[LJL]

## 慢性疲劳免疫功能障碍综合征

一种导致大量、致残性疲劳并伴有多种症状的疾病，包括记忆力减退、注意力下降、睡眠障碍、头痛、低热、肌肉和关节疼痛以及对温度变化的不耐受。此病也被称为直立性疲劳、慢性疲劳综合征及肌痛性脑脊髓炎。它常与压力有关。

该疾病的严重程度差异很大：有些患者卧床不起，而另一些患者仅受轻度致残症状困扰。该病病因未知，尽管有假说将其归因于并发压力和既往感染（可能是病毒感染）导致的异常免疫反应。爱泼斯坦-巴尔病毒、人类疱疹病毒6型、巨细胞病毒、柯萨奇病毒、各种隐蔽病毒及一种逆转录病毒均被怀疑与其有关。所有这些病毒都非常常见，普通人群经常暴露于其中。该病不危及生命，且不被认为具有传染性。然而，如果证明是病毒感染所致，在病毒初次潜伏期期间或刚结束后将存在一个传染期。慢性疲劳免疫功能障碍综合征（`CFIDS`）没有确切的诊断测试；因此，必须排除导致疲劳的其他疾病的可能性。虽然大多数确诊`CFIDS`的患者对一种或多种相关病毒呈阳性抗体，但由于这些病毒非常普遍，抗体滴度可能具有提示性，但不具诊断意义。见“抗体”、“爱泼斯坦-巴尔病毒”、“疱疹”、“感染”。

目前没有标准治疗方法。然而，一些人认为基于逆转异常免疫反应的治疗是有益的。部分受`CFIDS`影响的个体随时间推移会好转；大多数未接受治疗者在数年内仍会保持功能受损状态。[Dn]

## 记录器

一种用于记录事件发生时刻的装置。在较早期的形式中，模拟记录器包含一个以恒定速度旋转的滚筒，以及由电磁铁驱动的笔。滚筒在纸上描绘出螺旋线。时钟信号产生一组时间标记，观察者产生的信号产生其他标记，从而可以确定所观测事件的发生时刻。

现代记录器为数字打印类型。一种形式中，旋转字轮携带数字。另一种形式中，时间以电子方式累积，当发出信号时，通过按键打印输出。见“时间间隔测量”。[WM]

## 精密计时器

一种大型、结构坚固的手表，专为海上船舶精确计时而设计。有时，该名称也松散地应用于任何精密手表。

精密计时器与手表的不同特征包括：

- 一个沉重的摆轮，其轴始终保持垂直；
- 卷绕成圆柱形的摆游丝，而不是近乎平面的螺旋；
