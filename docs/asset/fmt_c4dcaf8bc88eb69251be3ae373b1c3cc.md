# talk mode

- n. `Unix`、`IIS` 和某些其他操作系统支持的功能，允许两个或多个登录用户建立实时对话。它具有了口语的即时性，同时也具有书面语言的精确性（和冗长）。这种频率交流比较困难，尽管已经出现了一些约定（详情见 `Prex` 中的写作部分）。`talk` 有一套特殊的术语集，以节省打字，这些术语在口头上不用。其中一些术语与 1920 年代以来业余无线爱好者使用的电报码术语相同。`AFAIK`（据我所）`AFAIK`（据我所知）`BCNU`（我们看到）`BTW`（顺便说一句）`WHY BEN?` 你准备好解锁了吗？（这是对话的标准方式；其他类型 `BYFE` 确认或继续对话）`CUL`（回见）`ENQ?`（回传 `ACK` 或 `NAK`）`FOO?`你是吗？（通常出现在意料之外的链接中，也意味着“抱歉我插话……（链接）”或“怎么了？？（链接）”）`FWI`（供参考）`FYI`（供你娱乐）`GA` 开始吧

## taper

全系统备份工具。`taper` 是一个磁带备份和恢复程序，提供了一个友好的用户界面，允许备份/恢复到磁带。文件可以备份到硬盘上。选择文件进行备份非常简单，增量备份和自动恢复是默认设置。支持 `SCSI`、磁带和可移动驱动器。源自 `Debian 3.0r0 APT`

## tapir

用于实时音频和反馈的工具。`tapir` 是一个简单灵活的音频处理器，灵感源自自以来使用的经典磁带系统。它提供了一个由行（或“延迟”）组成的图形界面，可以对输入进行反馈。通过正确配置和连接延迟，可以实现效果。延迟和增益可以被控制。`Tapir` 需要 `ALSA` 音频驱动。

## TAR

用于将多个文件和目录合并成单个文件的归档工具。它的名字来自“`Tape Archive`”，该工具是为了制作 `Unix` 系统备份而创建的。源自 `Linux` 指南

## tar

`GNU tar` 是一个将一组文件打包为 `tar` 格式存档的程序。它的功能在概念上类似于 `DOS` 世界中的 `zip`。它被 `Debian` 软件包管理系统大量使用，对于执行系统备份和文件交换非常有用。源自 `Debian 3.0`

## TAR

## tar

`GNU` 程序将许多文件打包成一个存档，并可以从中恢复文件（或所有文件）。`tar` 还可以用于向存档添加文件或列出文件。`tar` 包含多存档支持、自动压缩/解压。如果你需要使用 `tar` 进行删除，你还需要安装 `rmt` 软件包。你应该安装 `tar` 软件包，因为处理文件时需要它的压缩和解压工具。源自 `Mandrake 9.0 RPM`

## Tar (磁带归档)

一种用于 `UNIX/Linux` 的文件封装，目的是将文件组合组合以便更容易存档。它最初为磁带备份设计，但现在可以使用其他存储介质。单独运行时，它执行 `.tar` 扩展的文件。与 `Gzip` 结合进行数据压缩时，生成的文件可能是 `.tgz`、`tar.gz` 或 `.tar.Z`。

## feather

后者的动作被称为“羽化”，部分是因为类比（即使只是想象的）你对飞机性能为了减少风阻力所做的事情；或者对燕麦为了减少阻力所做的事情；较小的文件也更容易通过通信链路传输。与更常见的 `tar` 进行比较。源自 `Jones` 词典

## Tarball

## tar and feather
