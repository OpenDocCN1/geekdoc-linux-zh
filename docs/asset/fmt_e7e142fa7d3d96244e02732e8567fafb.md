
# date — 写入日期和时间

### 概要

```
/usr/bin/date [-u] [+format]
/usr/bin/date [-a] [-]sss.fff
/usr/bin/date [-u] [[mmdd] HHMM | mmddHHMM[cc]yy] [.SS]
/usr/xpg4/bin/date [-u] [+format]
/usr/xpg4/bin/date [-u] [[mmdd] HHMM | mmddHHMM[cc]yy] [.SS]
```

# 描述

`date` 命令将日期和时间写入标准输出，或尝试设置系统日期时间。默认写入当前日期时间。支持月份和星期原生语言翻译规范。使用的月份和星期名称基于环境变量 `LC_TIME` 指定的 locale；参见 `environ(5)`。以下是 C locale 的默认格式：

```
%a %b %e %T %Z %Y
```

其中
`%a` 星期。
`%b` 月份。
`%e` 日期。
`%T` 时间。
`%Z` 时区。
`%Y` 年。

例如：
`Fri Jan 8 13:15:42 WST 1999`

注意 — 如果你尝试将当前日期设置为标准时间和交替时区变化的日期之一（例如，夏令时开始或结束的日期），并尝试将时间设置为标准时间结束和交替时间开始之间（或交替时间结束和标准时间开始之间）的时间，结果将不可预测的。

## 选项

- `-a [-]sss.fff`
  通过 `sss.fff` 秒缓慢调整时间（`fff` 代表秒的分数）。此调整可以是正的也可以是负的。系统时将加速或减慢直到偏移指定的秒数。

- `-u` 显示（或设置）格林尼治标准时间（GMT-通用时间）日期，跳过到本地时间的正常转换（或从本地）。

### 操作数

`+format` 如果参数以 `+` 开头，则设置格式。如果未指定格式，则使用默认格式。支持月份和星期原生语言翻译规范。使用的月份和星期名称基于环境变量 `LC_TIME` 指定的 locale；参见 `environ(5)`。以下是 C locale 的默认格式：

```
%a %b %e %T %Z %Y
```

# cut

## 用

参见 `largefile(5)` 查看 `cut` 在遇到大于或等于 2 Gbytes（2**31 字节）的文件时的行为。

## 示例

以下示例将用户 ID 映射到名称。

```
castle cut -d -f1,5 /etc/passwd
root:Super-User
daemon:
bin:
sys:
adm:Admin
lp:Line Printer Admin
smtp:Mail Daemon User
uucp:uucp Admin
uucp:uucp Admin
listen:Network Admin
nobody:Nobody
access:No Access User
body4:SunOS 4.x Nobody
winsor:
ray:
des:
```

以下 Bourne shell 示例将 `name` 设置为当前登录名。
```
$ name=`who am i | cut -f -d'\'`
$ echo $name
winsor
```

## 环境变量

参见 `environ(5)` 查看以下影响 `cut` 执行的环境变量：`LC_CTYPE`、`LC_MESSAGES` 和 `NLSPATH`。

## 退出状态

- 0 所有输入文件均已成功输出。
- 非 0 发生错误。

## 属性

参见 `attributes(5)` 查看以下属性的描述：

| 属性类型 | 属性值 |
|---|---|
| Availability | SUNWcsu |
| CSI | Enabled |
