
Linux 可以运行或执行所有可能的文件格式，并与大量文件格式兼容。

## 15. 快速方便的安装
Linux 可以从网上轻松安装，不需要任何先决条件，因为它可以运行在任何硬件上，即使是你最旧的系统上。

## 16. 硬盘的合理使用
即使在硬盘几乎满的情况下，Linux 也能高效执行所有任务。这提高了 Linux 的性能，因此 Linux 也提供了高性能。

## 17. 多任务处理
Linux 是一个多任务操作系统，它可以同时执行许多任务而不会降低速度，例如下载大文件不会减慢系统。

## 18. 运行多个桌面
Linux 提供了各种桌面环境以便于使用。在安装 Linux 时，你可以根据意愿选择任何桌面环境，例如 `KDE`（K 桌面环境）或 `GNOME`（GNU 网络对象环境）。

# 使用 Linux 有什么缺点？

Linux 没有标准版本。微软为每个版本的 Windows 提供了几个不同的版本，而 Linux 有无数种变体。对于新用户来说，要弄清楚哪一个最适合你可能会令人困惑。

Linux 对驱动程序（协调硬件和操作系统的软件）的支持较少。这意味着你有时会发现设置新设备更为困难。

对于新用户来说，Linux 并不像 Windows 那样易用。这在很大程度上是因为 Linux 给了你更多控制，但也意味着你必须花一些时间适应它的工作方式。

由于 Linux 既不像 Windows 流行，也不是商业产品，因此支持工作的方式不同。你可能需要花更多精力来寻找问题的答案，虽然 Linux 支持者更有可能提供帮助，但这种帮助可能并不总是匹配你自己的技术理解水平。

你在 Windows 中习惯的许多程序将仅通过复杂的模拟器在 Linux 中运行。这些程序不能保证能够完美运行，在某些情况下可能会明显变慢。

虽然 Linux 可能适用于个人用户，但它较小的市场份额意味着在企业环境中引入要困难得多。由于大多数办公室员工已经熟悉 Windows 和微软程序，将员工转为使用 Linux 系统 可能会产生显著的时间成本。

虽然许多 Windows 程序有完美的替代方案（例如各种 Office 组件），但某些像 Photoshop 这样的高级应用程序在 Linux 中没有类似的对等替代品。

PC 游戏粉丝可能会发现 Linux 提供的范围要有限得多。这部分是因为是因为最新的游戏几乎总是商业化运营，而且在 Linux 中重现要困难得多，因为它们比办公软件等更具个人化。

虽然没有特定理由说明这种情况是必然，但在实践中，许多用户报告说，在 Linux 中设置打印功能可能会非常麻烦。

由于 Linux 是一个免费的开源系统，如果你发现软件不符合标准或导致了问题，并没有法律上的追回手段。虽然不能保证你一定获胜，但对于像 Windows 这样的商业产品，你至少拥有某些投诉权。
