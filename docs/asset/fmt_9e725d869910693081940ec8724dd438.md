测试题以随机顺序出现，而且在一个问题中提到的许多元素或问题可能也会出现在其他问题中。发现一个题目的错误答案是另一个题目的正确答案，反之亦然，这并不常见见。请花时间阅读每个题目的每一个选项，即使你立即识别出了某个题目的正确答案。额外的阅读可能会激发记忆，或者提醒你某个 Linux 特性或功能，这有助于帮助你回答考试中的另一个问题。
