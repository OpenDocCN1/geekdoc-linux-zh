## ndtdp

NDTP 是一个通过 TCP 带有 NDTP（网络字典传输协议）的 CD 光服务器。你可以将服务器替换为 NDTP。NDTP 可以运行在 UNIX 衍生系统上。它支持 EB、EGB、EBXA、EBCA–EBXA 和 EPWING 格式的 CD 光。这些格式的 CD 光在日本流行。由于 CD 光本身采用 ISO 9660 格式，你可以像挂载其他 ISO 9660 光盘一样挂载这些光盘。源自 Debian 3.0 APT
