# freeswan

IPSEC 使用 FreeSwan 提供认证和加密服务。它使用强加密算法验证数据包来自正确的发送者且在传输过程中未被更改。加密防止未经授权的读取数据包内容。这些服务允许你通过不可信的网络建立安全隧道。通过不可信网络传输的所有内容都由 IPSEC 网关加密，并在另一端的网关解密。结果是虚拟专用网络 (VPN)。这是一个有效连接到几个不安全站点机器的网络。请注意，这需要内核支持。标准 Debian 支持 FreeSwan。你可以通过安装 `kernel-source` 包和 `kernel-freeswan` 来构建自己的内核。来自 Debian 3.0r0 APT-.

# freetable

方便制作 HTML 表格的 perl 脚本，该脚本作为过滤器，读取 stdin 并写入 stdout。语法如下：

```
<table>
  <tr>
    <th>表头选项</th>
    <td>初始文本 (X, Y)</td>
  </tr>
  <tr>
    <td>单元格选项 (X, Y)</td>
    <td>单元格文本 (X,Y)</td>
  </tr>
  <tr>
    <td>表头选项 (X,Y)</td>
    <td>单元格文本 (两者)</td>
  </tr>
</table>
```

行和单元格可以按顺序指定，数字从 1 开始/或颜色。如果为空则可以省略选项。单元格可能包含任意 HTML 文本。
