
本章还说明了另一个重要点：Unix 愿景可能来去去，但 Unix 哲学将持续很长时间。对于 Linux 来说尤其如此。Linux 最有可能成为满足“Unix 将成为世界首选操作系统”这一预测的 Unix 版本。即使 Linux 通过开放和包容克服了竞争对手和敌人，Linux 未来也可能看到自己被一个更新操作系统取代，而那个系统将以我们今天无法想象的方式体现 Unix 哲学。这也可以接受。当这种情况发生时，那些已经知道如何“用 Unix 思考”的人将准备就绪。

出发吧。只做一件事。把它做好。到最后，你所成就的将大于你所做一切的总和。
