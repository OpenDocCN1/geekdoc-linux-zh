# CompTIA Linux+ 和 LPIC-1：Linux 认证指南

上一个输出比之前的 `free` 命令提供了更多信息，包括以下内容：

- 等待运行的进程数 (r)

- 睡眠的进程数 (b)

- 使用的交换内存量，以 KB 为单位 (swpd)

- 空闲物理内存量 (free)

- 缓冲区使用的内存量，以 KB 为单位 (buff)

- 缓存使用的内存量 (cache)

- 每秒交换到磁盘的内存量（KB）（si)

- 每秒从磁盘交换出的内存量（KB）（so)

- 每秒发送到设备的块数 (bi)

- 每秒从设备接收的块数 (bo)

- 每秒发送到 CPU 的中断数 (cs)

- 用户时间 (us)

- 系统时间 (sy)

- CPU 空闲时间 (id)

- 等待 I/O 时间 (wa)

- 从虚拟机窃取的时间 (st)
