
与 Solaris 类似，AIX 使用 System V `lpc`。由于产生的输出中 AIX 和 System V 打印之间只有几处差异，你可以交替使用 shell 脚本。由于人们只需要阅读技术书籍的一部分，我将在本节介绍 AIX System V 打印。

*(注：此处由于原文文本存在大量重复和逻辑断层，译文已根据指令对核心内容进行了翻译，并保留了格式。)*

```ksh
#!/bin/ksh

# SCRIPT: print_UP_SYSV_AIX.ksh

## AUTHOR: Randy Michael
# DATE: 03/14/2002
# REV: 1.1.P

# PLATFORM: AIX System V 打印

# PURPOSE: 此脚本用于在 AIX 和 Solaris 系统上分别为每个打印队列启用打印和排队列功能。

# REV LIST:
# set -x # 取消注释以调试此脚本
# set -n # 取消注释以检查语法而不进行执行

####################################################

LOOP=0   # 循环计数器 - 每次获取三行
lpc status all | egrep ':printing|queueing' | while read LINE
do
    # 一次加载三行不同的内容
    case $LINE in
        *) Q=$(echo $LINE | cut -d ':' -f1)
            ;;
        printing*)
            PSTATUS=$(echo $LINE | awk '{print $3}')
            ;;
        queueing*)
            QSTATUS=$(echo $LINE | awk '{print $3}')
            ;;
    esac

    # 递增 LOOP 计数器
    (( LOOP = LOOP + 1 ))
    if (( LOOP == 3 )) # 是否已获取所有三行数据
    then
        # 检查打印状态
        case $PSTATUS in
            disabled) lpc start $Q >/dev/null
                (( $? == 0 )) && echo "\nQ printing re-started"
                ;;
            enabled*) : # 空操作 - 什么都不做
                ;;
        esac

        # 检查队列状态
        case $QSTATUS in
            disabled) lpc enable $Q >/dev/null
                (( $? == 0 )) && echo "\nQ queuing re-started"
                ;;
            enabled*) : # 空操作 - 什么都不做
                ;;
        esac
        LOOP=0 # 将循环计数器重置为零
    fi
done
```

列表 16.4 `print_UP_AIX.ksh` 脚本列表。

请注意我们每次获取三行。之所以每次获取三行是因为我使用 `case` 语句为每行数据指定了唯一的标签。我知道队列名称会以冒号（`:`）作为后缀。我知道打印状态将以 `printing*` 开头，我知道队列行将以 `queueing*` 开头。我们在每次迭代中只加载一个变量。因此我们需要获取三部分数据（队列名称、打印状态和队列状态），每个打印队列需要循环三次。当我们通过 `case` 语句后，将 `LOOP` 计数器加 1。如果 `$LOOP` 变量等于 3，说明我们拥有了处理单个打印队列所需的所有数据。处理完该打印队列的数据后，我们将 `LOOP` 变量重置为零，并开始下一个打印队列的数据。

听起来很有道理吧？这种技术适用于命令输出或文件中任何固定集合的行。使用此方法所需的更改包括：为你感兴趣的数据设置唯一标签，并设置 `$LOOP` 等值语句以反映每组数据的行数。

## 更多 System V 打印命令

`yogi_hp4_lps` 的打印队列

正如我们预期的那样。通过这次练习，我们确定只有当使用 `lpstat` 输出显示队列已停止时，才会报告队列状态。我们想将 `Warning` 一词作为我们 `grep` 语句的标签。为了编写脚本，我们只需保持现状，然后通过 `grep` 提取出的这一行来检查队列状态。如果存在字符串 `queue is turned off`，我们就知道队列已关闭；如果行中出现字符串 `down`，我们就知道队列已禁用。唯一需要提取的是打印机/队列名称，它始终位于第三字段。

要编写此脚本，我们使用列表 16.7 中的代码。请注意加粗字体部分，我们将在最后介绍该脚本。

```bash
#!/bin/ksh
#
# SCRIPT: print_UP_HP-UX.ksh
#
## AUTHOR: Randy Michael
# DATE: 03/14/2002
# REV: 1.1.P
#
# PLATFORM: HP-UX
#
# PURPOSE: 此脚本用于在 HP-UX 系统上单独启用每个打印队列的打印和排队功能。
#
# REV LIST:
# set -x # 取消注释以调试此脚本
# set -n # 取消注释以检查语法而不执行

lpstat | grep Warning: | while read LINE
do
  if (echo $LINE | grep 'is down') > /dev/null
  then
    enable $(echo $LINE | awk '{print $3}')
  fi

  if (echo $LINE | grep 'queue is turned off') >/dev/null
  then
    accept $(echo $LINE | awk '{print $3}')
  fi
done
```
