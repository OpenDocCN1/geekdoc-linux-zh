
- 命令行界面：终端是一个基于文本的界面，允许用户使用键盘输入命令。
- 强大：终端可用于执行各种任务，从最简单的文件管理到复杂的安全测试。
- 可定制性：用户有能力创建自己的脚本和别名（`aliases`），并选择各种 Shell 和命令行工具，这使得自动化各种任务成为可能。
- 无图形用户界面：终端没有图形用户界面（GUI），因此用户必须依靠文本命令与操作系统进行交互。
- 多功能性：终端可以在任何操作系统上包括 Kali Linux，对于熟悉它的人来说非常有用的工具。

## 在 Kali Linux 中使用终端的步骤

在熟悉基础命令后，在 Kali Linux 中利用终端是一个简单的过程。以下是各种形式操作终端的详细说明：

- 打开终端：要打开终端，点击任务栏上的终端图标或在开始菜单中搜索“terminal”。
- 输入命令：要输入命令，只需将其输入终端并按回键。例如，你可以使用 `ls` 命令列出当前目录下的文件。
- 使用选项和参数：许多命令都有用于修改其行为的选项和参数。选项通常使用单个连字符加字母指定，而参数是传递给命令的具体值。例如，`ls` 命令可以使用 `-l` 选项以长格式显示文件，使用 `-a` 选项显示隐藏文件。
- 查看手册：要了解更多特定命令，可以使用 `man` 命令查看该命令的手页。例如，查看 `ls` 命令的手页，可以输入 `man ls`。
- 使用命令补全：为了节省时间，可以使用 Tab 键自动补全你正在输入的命令或文件名。例如，如果你在当前目录下有一个名为“report.txt”的文件，你可以输入 `cat rep` 然后按 Tab 键自动补全命令为 `cat report.txt`。
- 使用上下方向键：你可以使用上下方向键在命令历史中导航并轻松复用之前的命令。
- 使用 bash shell：Kali Linux 终端默认使用 `bash` shell，它提供了许多实用功能，如命令历史、命令行补全和别名。

## 探索文件系统

### 文件系统层次级标准 (FHS)

“文件系统”（filesystem）一术是指在计算机上存储和组织文档和其他类型数据的方法。得益于这种由目录（称为文件夹）和树组成的层次级结构，用户能够以逻辑且有序的方式访问和管理他们的文件。

`/` 符号表示根目录，它是文件系统中最高级的目录。根目录是所有其他目录的起点。所有其他目录和文件都以树状直接排列在其下方。例如，`/home` 目录包含系统所有用户的家目录，`/etc` 目录包含系统级配置文件。

Kali Linux 的文件系统通常根据文件系统层次级标准（FHS）构建，该标准规定了类 Unix 操作系统的标准目录树，是文件系统组织的依据。文件和目录系统（FHS）使用户能够快速定位文件和目录，并确保与其他应用程序的兼容性。

### 文件系统的特点

以下是 Kali Linux 文件系统的的一些高级方面：

- 文件权限：在 Kali Linux 中，每个文件和目录都有关联的权限，以控制谁可以访问和修改它。有三种权限：读（`r`）、写（`w`）和执行（`x`）。这些权限可以为文件所有者、组所有和其他和其他设置。
- 链接：链接是为单个文件或目录创建多个引用的方法。有两种链接：硬链接（hard links）和符号链接（symbolic links）。硬链接创建一个指向原文件相同 inode 的新目录项，而符号链接创建一个包含原文件路径的特殊文件。
- 挂载点：在 Kali Linux 中，硬盘和可移动媒体不会自动挂载。相反，它们必须手动挂载到挂载点。挂载点是文件系统访问的目录。
- 文件系统类型：Kali Linux 支持多种文件系统类型，包括 `ext2`、`ext3`、`ext4`、`NTFS` 等。不同的文件系统类型具有不同的功能，可能适用于某些存储或工作负载。
- 文件系统工具：Kali Linux 包含了许多用于管理和维护文件系统的工具，如 `fsck`（文件系统检查）和 `mke2fs`（创建 ext2 文件系统）。这些工具可以检查和修复文件系统错误以及格式化文件系统。
- 文件系统标签：文件系统标签是可以分配给文件系统的可选名称，以便识别它们。它们在设备上有多个文件系统或使用可移动媒体时有用。
- 文件系统配额：文件系统配额用于限制用户或组在文件系统使用的磁盘空间和/或 inode（文件和目录）。它们对于管理磁盘使用以及防止单个用户或组占用所有可用空间有用。
- 文件系统加密：Kali Linux 支持文件系统加密，这允许用户通过加密其文件系统来保护数据。文件系统加密对于保护敏感数据有用，特别是在便携设备上。

## 文件系统的组件

以下是 Kali Linux 文件系统的一些主要组件：

- 目录：目录是文件和其他目录的容器。它用于以层次级结构组织文件。
- 文件：文件是存储在计算机上的数据集合。文件可以包含文本、图像、音频、视频和其他类型的数据。
- `inode`：`inode` 是一种存储文件或目录信息的数据结构，如其权限、大小和在磁盘上的位置。文件系统中的每个文件和目录都有关联的 `inode`。
- 链接（Links）：是对单个文件或目录创建多个引用的方法。链接有两种类型：硬链接和符号链接。
- 挂载点（Mount points）：挂载点是一个设备文件系统挂载并变得可访问的目录。
- 文件系统类型（File system types）：不同的文件系统类型具有不同的功能和能力，可能适用于某些类型的存储或工作负载。

“命令”（command）一词是指在命令行界面（CLI）或终端中输入的指令，用于执行特定的操作。在 Kali Linux 的语境下，命令被输入到终端中以执行任务并对操作系统执行操作。

## 命令的实现

在 Kali Linux 中，需要使用命令来执行各种任务，包括：

- 文件管理：如 `ls`、`cd`、`cp` 和 `mv` 等命令可列出、更改、拷贝和移动文件及目录。
- 系统管理：如 `sudo`、`apt-get` 和 `systemctl` 等命令用于管理系统资源、安装和更新软件以及控制系统服务。
- 网络：如 `ifconfig`、`ping` 和 `traceroute` 命令用于配置网络接口、排排除网络连接问题以及跟踪两个主机之间的路径。
- 安全：如 `nmap`、`wireshark` 和 `aircrack-ng` 命令用于扫描网络、捕获和分析网络流量以及进行无线安全评估。

- Shell脚本：可以将命令组合成脚本以自动化任务并执行复杂的操作。
- 进程管理：如 `ps`、`top` 和 `kill` 用于显示和控制运行中的进程。
- 磁盘管理：如 `df`、`du` 和 `fdisk` 用于显示磁盘使用情况、估计文件空间使用情况以及分区磁盘。
- 文件压缩和归档：如 `gzip`、`tar` 和 `zip` 用于压缩和归档文件。
- 文本编辑：`vi`、`emacs` 和 `nano` 是用于创建和修改文本文件的编辑器。
- 系统信息：如 `uname`、`cat /proc/cpuinfo` 和 `free` 用于显示系统信息，如内核版本、CPU 信息和内存使用情况。
- 软件包管理：如 `dpkg` 和 `apt` 用于在系统上安装、删除和管理软件包。

## 学习二进制文件

### 什么是二进制文件？

“二进制文件”（binaries）一词是指编译后即可执行的文件。Kali Linux 包含了许多以二进制形式提供的工具和实用程序，这些工具可以在终端中输入其名称来执行。

### 二进制文件的好处

在 Linux 中使用二进制文件有几个几处：

- 安装方便：二进制文件经过预编译，可以直接运行，可以使用包管理器轻松安装。这对于不擅长从源码编译的用户特别有用。
- 兼容性：二进制文件是针对特定的 Linux 发行版编译的，因此更有可能与系统兼容。
