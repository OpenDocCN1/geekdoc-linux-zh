# 使用超链接

超链接是 `Web` 页面中的引用，可以将您带到同一个 `Web` 页面的其他部分或另一个 `Web` 页面。我们简单地说它是同一个 `Web` 页面两个部分或两个 `Web` 页面之间的电子连接。它可以是一个下划线的单词、短语或图形，当我们点击它时，相应的 `Web` 页面就会打开。

在本节中，您将学习创建一个打开另一个 `Web` 页面的链接和电子地址链接，以及使用图像作为链接。

# 创建打开另一个 Web 页面的链接

您可以在 `HTML` 文档中创建链接，帮助您在 `Web` 页面的一个地方跳转到另一个地方，或在 `Web` 页面之间跳转。当您提供超链接时，访问者只需点击即可访问您的 `Web` 页面。`<a>` 标签（代表锚）用于创建链接。

在 `HTML` 中，创建超链接的语法如下：

```html
<a href="URL">link text</a>
```

`URL` 指的是统一资源定位符（Uniform Resource Locator），`link text` 指语法中可点击的部分。

执行以下步骤创建通到另一个 `Web` 页面的链接。

<br>
if you want to visit to Kogent web site, click the link:
<a href="http://www.kogentindia.com">welcome to kogent!</a>

## 创建框架

框架允许你在同一个浏览器窗口中查看多个 `HTML` 文档。显示在浏览器窗口中的每个 `HTML` 文档都称为一个帧（frame）。浏览器窗口中的所有帧都是相互独立的。在 `HTML` 文档中，我们使用 `<frameset>` 和 `<frame>` 标签。`<frameset>` 标签用于将窗口划分为多个帧。`<frame>` 标签用于指定每个帧中包含哪些 `HTML` 文档。

执行以下步骤创建框架：

- 1. 点击“文件（File）”菜单，并在文本编辑器中选择“新建（New）”选项，如图图 LP-157 所示：

![](img/12ecf7a0767a6080881fb04f59162115_554_1.png)

图 LP-157

文本编辑器窗口中打开了一个新文档（图 LP-158）。

- 2. 在文本编辑器窗口（图 LP-158）中按照代码列表 1.7 所示输入以下代码：
代码列表 1.7：创建框架的代码

```html
<!DOCTYPE HTML PUBLIC "//W3C//DTD HTML 4.01 Transitional//EN">
<html>
<head>
<title> Frame Creation</title>
</head>
```

```html
<head>
<frameset cols="50%,50%">
<frame src="home/kogent/HTML files/HTMLdoc.html">
<frame src="home/kogent/HTML files/HTMLdoc2.html">
</frameset>
</head>
```
