## 介绍 Linux 文件和目录结构

每个操作系统将信息组织成文件。文件存储在存储介质（如硬盘、优存器、磁带）上的数据流。一组目录可能包含在一个目录中，称为父目录（根目录）。Linux 文件系统按层次结构组织，根目录由正斜杠（`/`）表示。当你打开 Linux 文件时，你从根目录开始进入子目录。在 Windows 中，结构类似于 `C:\folder\file`。在 Linux 中，没有名为 `C` 或 `D` 的驱动器；此外，分区挂载在根目录（`/`）下供操作系统使用。Linux 遵循文件系统层次结构（`FHS`）来定义文件的名称和位置，如图 4.1 所示。

```

/etc

/mnt

/tmp

/var
```

## 操作文件与目录 49

图 4.1 显示了 Linux 中的目录结构，从根目录开始，分支到子目录和文件。以下是 Linux `FHS` 中各种目录的简单描述：

- `/bin`：包含可执行文件（准备运行的文件），用于启动和修复系统。此目录通常包含 `bash` 和 `csh` 等 shell，为 Linux 提供了基于文本的用户界面以及命令等。
- `/sbin`：存放仅供 `root` 用户使用的二进制文件。此目录包含启动系统所需的文件。
- `/home`：提供系统管理员和用户都可以访问的目录。`/home` 目录存储用户的个人文件、目录和程序。
- `/boot`：允许启动 Linux 系统。此目录包含 Linux 内核，它是 Linux 系统的核心组件。
- `/dev`：包含连接到 Linux 系统的设备的文件项。
- `/lib`：包含 Linux 系统程序使用的共享库。
- `/var`：包含所有应用程序的文档、配置文件和图表。它还包含系统的软件源码。它是 Linux 上最大的目录，存放终端（网络）和文件传输协议（`FTP`）等辅助程序。
- `/mnt`：指挂载点，你可以使用它来挂载文件系统或设备。
- `/var`：包含可变数据文件，如 `/var/log`、`/var/mail` 和 `/var/spool`。
- `/proc`：包含用于从内核提取信息或向内核发送信息的特殊文件。它是存储系统进程的特殊虚拟目录。
- `/etc`：包含系统所有的配置文件。此目录经常用于备份 Linux 系统。如果你需要重新安装 Linux 系统，它可以让你免于执行重新配置的过程。
- `/lost+found`：在系统崩溃或断电时允许恢复文件和数据。
- `/root`：允许超级用户访问家目录。超级用户是用 `root` 登录的用户。
- `/tmp`：在 Linux 中存储临时文件。
