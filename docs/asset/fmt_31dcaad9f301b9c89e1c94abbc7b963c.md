# 第 22 小时

配置新的共享，请执行以下操作：

- 在 `Comment` 注释输入框中为共享输入一个纯英文描述。
- 在 `Path` 路径输入框中输入您想要关联到此共享的目录树。
- 如果此共享是只读的，请在 `Read Only` 只读下拉列表中选择 `Yes` 是；否则，选择 `No` 否。
- 如果此共享应允许访客访问——这意味着 Windows 不需要输入账户或密码信息即可访问——请在 `Guest OK` 允许访客下拉列表中选择 `Yes` 是；否则，选择 `No` 否。当然，在向系统提供访客数据时应该小心，因为任何人都可以访问相关数据。

顺便说

### 文件共享时权限至关重要

| 为了让访客共享能够被 Windows 主机访问，其目录树必须具有允许公共（任何用户）读取的权限。如果您希望 Windows 主机能够写入访客共享，您还必须确保相关目录树的权限允许公共写入。 |

完成共享配置后，点击 `Commit Changes` 提交更改按钮保存此共享的配置。如需创建额外的共享，在 `Create Share` 创建共享输入框中输入您想要创建的共享名称，点击 `Create Share` 创建共享按钮，并重复此过程。直到创建完所有想要创建的共享。

| 如果您发现在移动共享后想要编辑它，请使用 `Choose Share` 选择共享下拉列表显示您想要编辑的共享，然后点击 `Choose Share` 选择共享按钮打开包含共享选项的页面。如果您只是想删除共享，请使用 `Choose Share` 选择共享下拉列表显示要删除的共享，然后点击 `Delete Share` 删除共享按钮将其移除。 |

如果 SWAT 显示 `smbd` 和 `nmbd` Windows 文件服务器的两个组件状态为 `running` 运行，请点击 `Start` 启动按钮，然后点击 `Start nmbd` 按钮以启动 Windows 文件服务器。如果两者都在运行，请点击 `Restart` 重启按钮，然后点击 `Restart nmbd` 按钮以激活您所做的更改。

您的 Windows 文件服务器现在已运行，但如果您希望它在每次启动 Linux 时自动启动，则必须进行额外的更改。

要使用桌面工具配置 Windows 文件服务器在每次 Linux 启动时自动启动，通过桌面工具、GNOME 菜单、Server Settings 服务器设置、Services 服务来显示 Service 配置工具。确保勾选了 `smbd` 服务。

勾选 `smbd` 服务后，点击 `Save` 保存、`File` 文件、`Quit` 退出返回服务配置工具。

您也可以在命令行上使用 `chkconfig` 命令配合 `--level` 选项，并提供 `smbd` 和参数 `on`，来配置 Windows 文件服务器为您的默认运行级别自动启动：

```
[root@workstation20 you]#$ /bin/chkconfig --level 5 smbd on

[root@workstation20 you]#$
```
