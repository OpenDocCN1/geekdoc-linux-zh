# devfsd

`devfsd` 程序是一个由系统运行的守护进程，可以为设备文件系统 (`devfs`) 提供智能管理。作为其阶段的一部分，`devfsd` 创建到 `/dev` 的符号链接。`syslog` 的启动会延迟到 `/dev/log` 创建。在启动时，该守护进程通常在后台运行，并向 `syslog` 发送消息。对于每个变化，`devfsd` 会生成事件。对于每次变化，`devfsd` 可以采取行动。源自 Mandrake 9.0 RPM

http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

# devscripts

用于简化 Debian 维护者生活的脚本包含以下脚本，括号中显示了依赖/建议项：
