
### 创建虚拟机

一旦安装了虚拟机管理程序，你就可以创建虚拟机。具体过程取决于你选择的管理程序，但以下是通用流程：

#### 使用 KVM 创建虚拟机（使用 virt-manager）

1. 打开`virt-manager` -> 用于管理 KVM 虚拟机的图形化工具。
2. 点击“文件 (File)”->“新建虚拟机 (New Virtual Machine)”启动创建向导。
3. 按照提示指定虚拟机详情，例如 CPU、内存、存储和安装源。
4. 完成向导，它将为你创建虚拟机。

#### 使用 VirtualBox 创建虚拟机（使用 VirtualBox GUI）

1. 从应用程序菜单打开`VirtualBox`。
2. 点击“虚拟机 (Machine)”->“新建 (New)”创建一个新虚拟机。
3. 按照`VirtualBox` GUI 中的步骤配置虚拟机，包括选择操作系统类型、设置内存和存储以及选择安装 ISO 文件。
4. 配置完成后，点击“创建 (Create)”生成虚拟机。
5. 启动虚拟机并继续操作系统的安装。

### 管理虚拟机

创建虚拟机后，你可以使用相应的管理程序工具对其进行管理。以下是一些常见任务：

- **启动和停止虚拟机：** 你可以使用管理程序的图形界面或命令行工具启动和停止虚拟机。
- **快照：** 创建快照可以捕获虚拟机的当前状态，用于备份或测试。
- **网络：** 配置虚拟机的网络，包括 NAT、桥接或仅主机网络。
- **资源分配：** 根据需要调整虚拟机的 CPU 和内存分配。
- **存储：** 管理虚拟磁盘并根据需要挂载额外的存储。
- **克隆：** 创建现有虚拟机的克隆或副本以实现快速部署。

总而言之，在 Linux 环境中设置和管理虚拟机涉及选择合适的虚拟化程序、安装它、创建虚拟机以及有效管理它们的生命周期。虚拟化程序的选择取决于您的特定需求，KVM 和`VirtualBox`都为 Linux 系统上的虚拟化提供了强大的选项。

# 第 11.3 节：容器与 Docker 简介

容器已成为应用程序开发和部署不可或缺的一部分。它们提供了一种轻量且高效的方式来打包和分应用程序及其依赖项。Docker 特别作为容器化平台广受欢迎。在本节中，我们将为您介绍容器和 Docker 的概念。

## 什么是容器？

容器是轻量级、独立且可执行的包，包含了运行应用程序所需的所有内容，包括代码、运行时、库和系统工具。与传统的虚拟机（VM）不同，容器共享宿主机操作系统的内核并作为隔离进程运行，这使得它们更高效资源且启动速度更快。

容器具有以下几个优势：

- **可移植性**：容器可以在不同环境（从开发笔记本电脑到生产服务器）中一致运行，确保应用程序在任何地方运行方式相同。
- **隔离性**：容器提供进程和文件系统隔离，允许多个容器在同一宿主机上运行而互不干扰。
- **资源效率**：由于容器共享宿主机 OS 内核，与虚拟机相比消耗的资源更少，适用于在单个服务器上运行多个实例。

## Docker 简介

Docker 是一个领先的容器化平台，简化了容器的创建、部署和管理。它由三个主要部分组成：

1. **Docker Engine**：这是运行容器的核心运行时。它包含服务器、REST API 和与容器交互的命令行界面 (CLI)。
2. **Docker Hub**：Docker Hub 是基于云的注册表，您可以在其中查找和共享容器镜像。它提供了适用于各种软件应用程序和操作系统的预构建镜像的海量库。
3. **Docker Compose**：Docker Compose 是一个使用 YAML 配置文件定义和运行多容器应用程序的工具。它简化了管理由多个相互连接的容器组成的复杂应用程序的过程。

## Docker 核心概念

### Docker 镜像 (Images)

Docker 镜像是一个只读模板，包含了应用程序的代码、库和依赖项。镜像用于创建容器实例。您可以使用`Dockerfile`构建自定义镜像，`Dockerfile`定义了镜像的配置和构建镜像的指令。

### Docker 容器 (Containers)

Docker 容器是 Docker 镜像的可运行实例。容器之间以及与宿主机系统相互隔离，确保它们不会互相干扰。可以根据需要启动、停止和删除容器。

### Docker 注册表 (Registry) 与 Docker Hub

Docker 镜像通常存储在 Docker 注册表中，用于共享和发布 Docker 镜像的仓库。Docker Hub 是默认的公共注册表，但您也可以使用私有注册表对镜像发布进行更多控制。

### Docker CLI

Docker 命令行界面 (CLI) 允许您与 Docker 交互并管理容器、镜像、网络和卷。您可以使用 CLI 构建、运行和管理容器。

## 开始使用 Docker

要开始 Docker，您需要：

1. **安装 Docker**：根据您的 Linux 发行版，您可以使用包管理器安装 Docker。例如，在 Ubuntu 上，您可以运行：

```
sudo apt install docker.io
```

2. **启动 Docker 服务**：启用并启动 Docker 服务以运行容器：

```
sudo systemctl enable --now docker
```

3. **拉取镜像**：使用`docker pull`命令从 Docker Hub 或另一个注册表下载 Docker 镜像。例如：

```
docker pull ubuntu
```

4. **运行容器**：使用`docker run`命令从镜像创建并启动容器。例如，要交互式地运行 Ubuntu 容器，您可以使用：

```
docker run -it ubuntu
```
