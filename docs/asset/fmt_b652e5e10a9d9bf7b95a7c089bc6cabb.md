
# Linux 词典

## `nfs-utils`
`nfs-utils` 包为内核 NFS 和相关工具提供了一个守护进程，其提供的性能比大多数用户使用的传统 Linux 服务器高得多。此包还包含 `showmount` 程序。`showmount` 查询远程主机上的守护进程，以获取有关远程主机 NFS（文件系统）的信息。例如，`showmount` 可以显示挂载在上面的上的客户端。来自 Mandrake 9.0 RPM

`http://www.tp.org/LDP/Linux-Dictionary/html/index.html`

## `nfsboot`
允许客户端通过网络启动。此包帮助你设置客户端通过 nfs 启动。此包应安装在服务器上，以便客户端连接到它。该包不包含 nfs 本身，但推荐了实现 nfsrooted 所需的所有包。来自 Debian 3.0r APT

`http://www.tp.org/LDP/Linux-Dictionary/html/index.html`

## `nfsbooted`
为你的 nfs 启动准备镜像。此包设置你的守护进程以从 nfs 启动。为了让不同的主机不产生冲突，需要完成几件事。来自 Debian 3.0r APT

`http://www.tp.org/LDP/Linux-Dictionary/html/index.html`

## `NIC`
通常指任何处理网络信息的办公室。其中最著名的是 Internic，大多数新域名都在那里注册，直到该过程被去中心化到一些私有公司。也意味着“网卡”，即你插入电脑以连接网线的卡。来自 Matisse

`http://www.tp.org/LDP/Linux-Dictionary/html/index.html`

## `N`
一个包含互联网相关信息的系统，包括文件传输协议 (`FTP`) 协议请求注释 (`RFC`)、互联网草案 (Internet Drafts)、供参考 (`FYI`) 论文以及其他文档，包括互联网使用手册。有许多网络信息中心，但官方的网络信息库是国防数据网 `NIC` (DDN `NIC`)。参见来自 QUEDIC 的 Internic
