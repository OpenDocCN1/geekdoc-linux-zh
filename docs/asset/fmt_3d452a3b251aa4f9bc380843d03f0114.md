在对请求进行排序以最小化旋转时间后，完成表 7.3 中相同的请求需要 28 ms，将旋转时间从 13 ms 减少到 5 ms。

为了实现此算法，设备控制器必须提供旋转感应，以便设备驱动程序能够实现。

然而，在检索并非按顺序存储的数据时，驱动器的访问时间可能更为重要。访问时间是指磁头（带有激光）移动到光盘上特定位置所需的平均时间。最快的单元具有最小的平均访问时间，这在随机搜索信息（如在数据库中搜索）时是最重要的因素。因此，对于磁盘的**顺序访问**（如视频播放），快速的传输率最重要；而在检索分散在光盘上的数据时，快速的访问则至关重要。

第三个重要特性是缓存大小，它对性能可能产生重大影响。硬件缓存通过在磁盘与内存之间传输数据块来充当缓冲区，预判用户可能想要检索的数据。假设系统预测准确，如果信息留在缓存中，数据检索速度将要快得多。在某些情况下，缓存还可以充当预读缓冲区，寻找磁盘上的下一块信息。预读缓存对于在连续数据流通过的多媒体播放中似乎最有用处。然而，由于它们会被填满，预读缓存在翻阅数据库或电子书时实际上变得更有用。在这种情况下，用户在使用当前信息时，缓存有时间进行恢复。

## CD 和 DVD 技术

根据介质和光盘的容量，有几种类型的光盘系统：如图 7.15 所示的 CD、DVD 和蓝光光盘。

![](img/ab986ea78dd2ff4c362e5e8d77f953d5_248_0.png)

要在光盘上写入数据，使用高强度激光束在光盘凹槽（pits）上烧蚀凹痕。这些凹槽与不平整区域（陆，lands）形成对比。起始扇区位于光盘中心附近；激光向外移动，依次到达每个扇区。光盘可以有一层或多层，允许激光穿透上层读取其下层的内容。例如，如果光盘有两个层，激光的路径将反转，机械臂从外边缘向内移动以读取第二层。

它是如何工作的？使用 CD 或 DVD 播放器，将低功率红色激光聚焦在光盘上，激光穿过光盘的保护层照射到记录数据的轨道上，来回读取数据。光照射在陆上会被反射到光电探测器，而照射在凹槽上的光会被散射和吸收。光电探测器将光强度转换为零和一的数字信号。

光介质的存档质量不同，取决于它是压制的还是刻录的。压制光盘具有凹槽和陆——光盘表面的物理凹痕——用于存档存储数据。另一方面，如果光盘是刻录的，则使用写入染料来存储在光盘上。随着时间的推移，染料可能会变质，导致长期存储的可靠性降低（国家档案馆，2016）。

如果 CD 或 DVD 驱动器允许写入但不允许重写，则对于 CD-R（可刻录光盘）和 DVD-R 技术需要更复杂的技术。例如，在单层上具有数据的 CD-R 具有几种涂层，包括一层反射涂层和一层用于记录数据的染料层。写头使用高功率激光束来记录数据。当激光束被吸收到染料中时，染料上会形成一个永久性标记；在记录后它无法擦除。当读取时，染料上标记的存在会导致激光散射，光线无法返回读写头。然而，当染料上没有标记时，金层会将光反射回读写头。这与读取凹槽和陆的过程相似。用于创建刻录光盘的软件使用标准格式（如 ISO 9096），它会自动检查错误并创建目录以跟踪每个文件的位置。

可重写光盘（如 CD-RW 和 DVD-RW）使用称为**相变**的过程来写入和重写数据。记录层使用银、铟和锑的合金。记录层有两种不同的相态：非晶态和晶态。在非晶态下，光不会像在晶态下那样被反射。

为了记录数据，激光束加热染料并将状态从晶态变为非晶态。当通过低功率激光束读取数据时，非晶态会散射出未被读写头拾取的光。这被解释为 0，与读取凹槽的情况相似。另一方面，当光击中晶态区域时，光会反射回读写头；这与读取陆的情况相似，并被解释为 1。要擦除，光驱使用激光束加热该区域，使其足以松动合金并恢复到原始的晶态。

尽管 DVD 使用与 CD 相同的设计且尺寸和形状相同，但它们可以存储更多数据。它的红色激光波长比 CD 的红外激光短，可以产生更小的凹槽，并使光盘单轨的螺旋更长、更紧密。因此，一张双层单面 DVD 可容纳等同于 13 张 CD 的数据。

当压缩技术（在下一章讨论）的优势加上 DVD 的高容量时，单面双层 DVD 可以存储 8.6 GB 的数据。

## 蓝光光技术

蓝光光盘的物理尺寸与 DVD 或 CD 相同，但用于读写数据的技术完全不同。蓝光光盘上的凹槽比 DVD 小得多，且蓝紫色激光波长比 DVD 的红色激光短。这使得数据可以更密集地排列并存储在更小的空间内。

此外，蓝紫色激光可以层层写入，极大地增加了单个光盘可以存储的数据量。蓝光光盘的容量大于 DVD。

像 CD 和 DVD 一样，蓝光盘也有几种格式：只读（BD-ROM）、可刻录（BD-R）和可重写（BD-RE）。

## 固态存储

固态存储使用浮栅中的电子，这些电子在断电后仍然存在。

### 闪存存储

闪存是一种电可擦除可编程只读存储器（EEPROM），以存储单元为单位组织。其非易失性存储介质可以模拟随机存储器，但与 RAM 不同，它在掉电时可以可靠地存储数据。它是移动介质使用的技术。

闪存的名字来源于擦除数据的技术。写入数据时，将较高的电压发送通过称为浮栅的晶体管，然后通过金属氧化层进入另一个称为控制栅的晶体管，电荷存储在那里。要重置所有值，会对整个卡应用强闪。

然而，闪存并非不可破坏。它有两个局限性：位只能通过应用闪来擦除，每次擦除都会导致存储区域变得不稳定。随着时间的推移，在使用有限的次数后（如 10,000 到 1,000,000 次），固态存储设备将不再存储数据。

### 固态硬盘

固态硬盘（SSD）技术提供了快速但目前昂贵的存储设备。SSD 可以依靠两种数据存储类型：闪存内存或主内存（如果内置了某种电池以防止突然断电时数据丢失）。

固态硬盘与机械硬盘相比如何？由于固态硬盘通过电子方式工作且没有移动部件，寻道时间、搜索时间和旋转延迟等概念并不适用，这暗示 SSD 提供了显著更好的性能。事实上，它们功耗更低，而且相对轻巧且安静。然而，SSD 技术也存在一些明显的缺点。例如，当 SSD 故障时，它通常在没有任何警告的情况下失效，也就是说，没有可以预警用户 SSD 即将故障的信息或数据错误。由于几乎没有机会尽力挽回宝贵数据，SSD 崩溃可能是灾难性的。

数据传输率通常随着时间的推移而下降。例如，新拆箱的 SSD 传输率远快于类似的硬盘，但在安装和使用后，SSD 在部署仅几周后就开始变慢，并在其整个寿命周期内持续下去。其原因之一是数据被加载到 SSD 上后，为了进行磨损均衡（wear leveling），通常会被移动多次，这种做法随着设备的使用的增加会导致设备的整体性能下降。

SSD 和硬盘技术可以结合在一个单元中以创建一个混合驱动器。或者，SSD 和硬盘也可以在系统内部组合，称为混合系统。

这两种技术都试图通过以下方式优化：将频繁变化的数据或较小的文件存储在 SSD 上，而将大文件或不常用的文件存储在硬盘上。
