# 使用 Python 在 Pi 上通过 GPIO 控制 LED

## 实验板
实验板（或原型板）提供了一个易于使用且无需焊接的环境，用于创建和更改你的开发电路。

### 实验板跳线
这是任何初级电气工程师的必备品，这些公对公和公对母的跳线可以快速方便地构建电路。

### GPIO 引脚
这为电气电路提供了收集输入和提供输出的机制，能够实现响应式程序设计。

### 彩色 LED
不同颜色的 LED 是物理映射运行软件部分的极佳方式，并能帮助你理解程序流。
