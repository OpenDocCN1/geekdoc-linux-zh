```
/bin/touch /var/lock/samba/STATUS.LCK
```

在这种情况下，`touch`在`/var/lock/samba`目录下创建了一个名为`STATUS.LCK`的空文件。此文件名必须全大写字母，因为`smbd`在启动时会查找该锁文件。
