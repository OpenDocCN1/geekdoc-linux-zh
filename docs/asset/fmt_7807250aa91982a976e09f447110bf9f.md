
# tplot, t300, t300s, t4014, t450, tek, ver 1359

## 描述
`tplot` 命令从标准输入读取绘图指令，并在标准输出产生适用于特定终端的指令。

如果不指定终端，则使用环境变量 `TERM`。默认终端为 `tek`。

## 环境变量
除 `ver` 之外，你可以配合 `lpr -g`（参见 `lpr(1B)`）使用以下终端类型产生绘图输出。

- `300` DASI 300 或 GSI 终端（Diablo® 机制）。
- `300s` DASI 300S DASI 300s 终端（Diablo 机制）。
- `450` DASI Hyterm 450 终端（Diablo 机制）。
- `4014 | tek` 带有增强图形模块的 Tekronix® 4014 和 4015 存储器。（使用不带增强图形模块的 Tektronix 4014 或 4015）。
- `ver` Versatec® D1200A 打印绘图。输出经过扫描转换，适用于 `lpr -v`。

## 文件

```

/usr/lib/t300s
/usr/lib/t4014
/usr/lib/t450
/usr/lib/tek
/usr/lib/vplot
```

# tput — 初始化终端或查询 terminfo 数据库

### 概要
```
/usr/bin/tput [-Ttype] capname [parm...]
/usr/bin/tput -S <<
```

## 描述
`tput` 命令使用 `terminfo` 数据库使 shell 可用终端相关的特性和信息（参见 `sh(1)`）；用于清除、初始化或重置终端；或返回请求的终端类型的名称。如果能力属性 `capname` 类型为字符串，`tput` 输出字符串；如果属性类型为布尔值，`tput` 仅设置退出状态（如果终端具有该能力则为 0，否则为 1）且不产生输出。在从标准输出使用返回值之前，你应该测试退出状态以确认其是否为 0 (?, 参见 `sh(1)`))。

## 选项
`-Ttype` 指示终端类型。通常你不需要使用此选项，因为默认值来自环境变量 `LINES` 和 `COLUMNS`，如果你指定了 `-T`，则不引用 shell 变量和层大小。
`-S` 允许每次调用 `tput` 时多个能力。你必须从标准输入将能力传递给 `tput`，而不是从命令行。每行只允许一个 `capname`。`-S` 选项更改了 0 和 1 布尔及字符串退出状态的含义。

### 操作数
`capname` 指示来自 `terminfo` 数据库的能力属性。参见 `terminfo(4)` 获取能力的完整列表以及每个能力关联的 `capname`。C 语言环境实现支持以下字符串作为操作数：
`clear` 显示清屏序列。
`init` 如果 `terminfo` 数据库存在且存在你的终端的条目（参见 `-Ttype`），将发生以下情况：
* 如果存在，输出终端的初始化字符串 (`is1`, `is2`, `is3`, `if`, `iprog`)。
* 设置 tty 驱动程序条目中指定的任何延迟（例如，换行）。

# tplot, t300, t300s, t4014, t450, tek, ver

## 示例
下面的示例显示了文件 `kookaburra-1` 的修改时间，并将访问时间和修改时间更改为当前日期时间。

```
castle% ls -1 kookaburra-1
-rw-r--r 1 winsor staff      264 Feb 20 16:12 kookaburra-1
castle% touch kookaburra-1
castle% ls -1 kookaburra-1
-rw-r--r 1 winsor staff      264 Apr 9 13:59 kookaburra-1
castle$
```

## 用法
参见 `largefile(5)` 关于 `touch` 在遇到大于或等于 2 Gbytes (**31 bytes**) 文件时的行为描述。

## 环境变量
参见 `environ(5)` 关于以下影响 `touch` 执行的环境变量描述：`LC_MESSAGES`, `NLSPATH` 和 `TZ`。

## 退出状态

```
0	touch 执行成功并已完成所有请求更改。
>0	发生错误。touch 返回无法成功修改时间的文件数量。
```

## 属性
参见 `attributes(5)` 关于以下属性的描述：

| 属性类型 | 属性值 |
| --- | --- |
| 可用性 | SUNWOS |
| CSI | Enabled |

# 另另
`time(2)`, `attributes(5)`, `environ(5)`, `largefile(5)`
