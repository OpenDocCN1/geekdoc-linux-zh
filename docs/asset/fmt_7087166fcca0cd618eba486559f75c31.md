## 第二部分：探索红帽 Linux

你可以看到，该文件被组织成若干部分，每个部分由方括号内的标签标识。每个部分指定了一组相关的选项，这些选项会影响 GUI 登录过程的某些方面。

你可以单独配置每个 X 显示器的 `kdm` 登录界面（greeter）——登录框的外观和感受。每个显示器的配置由具有以下格式的节名称指定：

```
[X-host:number_class-subsection]
```
