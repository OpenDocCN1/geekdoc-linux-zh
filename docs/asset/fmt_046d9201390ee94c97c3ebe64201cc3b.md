
也许比 SAMBA 项目更成功的可能是 Apache HTTP 服务器。该服务器运行在 Unix、Windows NT 以及许多其他操作系统上。它最初被称为“A Apache server”，基于现有代码和一系列“补丁文件”，这套成熟代码的名字应当用美洲原住民部落 Apache 来命名非常恰当，他们以在战争策略上的卓越技巧和无穷无尽的耐力而闻名。Apache 已证明比许多其他服务器运行更快、更稳定、功能更全。Apache 运行在每天数百万访问者的网站上，虽然开发者没有提供官方支持，但 Apache 社区为你的所有问题提供答案。现在已有多个机构提供商业支持。

# Linux 发行版

## Linux 与 GNU

尽管有许多 Linux 实现，但你发现在不同的发行版中会有许多相似之处，仅仅是因为每台 Linux 机器都是一个包含构建模块的箱子，你可以根据自己的需求和观点将它们组装起来。安装系统只是长期关系的开始。正当你拥有了一个正在运行的系统时，Linux 将模拟你的想象力和创造力，你越是意识到这个系统能带给你多大的力量，你就越会尝试重新定义它的极限。

Linux 的外观可能取决于发行版、你的硬件和个人品味，但所有图形和其他界面的基础是构建好的，并且保持相同。Linux 系统基于 GNU 工具（GNU 的 Unix），它提供了一套处理和使用系统的标准方法。所有的 GNU 工具都是开源的，因此它们可以安装在任何系统上。大多数发行版提供了许多常用工具的预编译包，例如 RedHat 上的 `RPM` 包和 Debian 上的包（也称为 `deb` 或 `dpkg`），所以你需要一个程序员在你的系统上安装包。然而，如果你喜欢并且喜欢自己做事情，你会更喜欢 Linux，因为大多数发行版都带有一套完整的开发工具，允许完全从源码安装新软件。这种设置还允许你在即使软件不存在适用于你系统的预包格式时，也能安装它。

常用 GNU 软件列表：

- `Bash`: GNU 壳（命令外壳）

- `GCC`: GNU C 编译器

- `GDB`: GNU 调试器

- `Coreutils`: 一组基础 UNIX 实用程序，如 `ls`, `cat` 和 `chmod`

- `Findutils`: 用于搜索和查找文件

- `Fontutils`: 将字体从一种格式转换为另一种格式或制作新字体

- `The Gimp`: GNU 图像处理程序 (GNU Image Manipulation Program)

- `Gnome`: GNU 桌面环境

- `Emacs`: 一个非常强大的编辑器

- `Ghostscript` and `Ghostview`: PostScript 文件的解释器和图形前端。

- `GNU Photo`: 与数字相机交互的软件

- `Octave`: 一种编程语言，主要用于数值计算和图像处理。

- `GNU SQL`: 关系型数据库系统

- `Radius`: 远程认证和计费服务器

- ...

Linux 有许多商业应用程序可用，关于这些包的更多信息，请参阅它们的特定文档。在本指南中，我们只讨论免费提供的软件，这些软件（大多数情况下）带有 GNU 许可证。

要安装[或]新包，你需要某种形式的软件管理。最常见的实现包括 `RPM` 和 `dpkg`。`RPM` 是 RedHat 包管理器，用于多种 Linux 系统。`Dpkg` 是 Debian 包系统，它使用 `apt-get` 接口，这也可以管理 `RPM` 包。Novel `YaST`（Xianian Red Carpet，新年红毯）是 `RPM` 的第三方实现，带有图形前端。其他第三方软件供应商可能有他们自己的安装程序，类似于 MS Windows 及其他平台上的 InstallShield 等。随着你深入学习 Linux，你可能会接触到这些包中的一个或多个。

## GNU/Linux

Linux 内核（你系统的骨架，称为“Kernel”的部分）不是 GNU 项目的一部分，但它与 GNU 软件使用相同的许可证。大多数实用程序和开发工具（你系统的肉）并非 Linux 特有，而是取自 GNU 项目。由于任何可用的系统都必须包含内核和至少一组基础的实用程序，一些人认为这样的系统应该被称为 GNU/Linux 系统。

为了获得发行版之间尽可能可能的独立性，这就是我们在整个课程中将讨论的 Linux 类型。如果我们讨论的不是 GNU/Linux 系统，将会提到具体的发行版、版本或名称。

## 我应该安装哪种发行版？

在安装之前，最重要的因素是你的硬件。由于每个 Linux 发行版都包含基础包并且可以构建以满足几乎任何需求（因为它们都使用内核），你只需要考虑该发行版是否支持你的硬件。

## 什么是 Linux？

大多数 Linux 发行版都经过了良好的和维护。标准的桌面环境在某些上可能是 `Gnome`，另一个可能默认提供 `KDE`。通常，所有主流发行版都提供 `Gnome` 和 `KDE`。高级用户可以使用其他窗口和桌面管理器。

标准安装允许用户选择不同的设置，例如工作站（安装日常使用和开发所需的包）或服务器安装（可以选择不同的网络）。专家用户可以在初始安装时安装他们他们任何组合。

本指南的目标适用于所有发行版。然而，为了方便起见，强烈建议初学者坚持主流发行版，它们默认支持所有常用硬件和应用程序。以下是初学者的良好选择：

- `Fedora Core` [`http://www.fedora.redhat.com`]

- `Debian` [`http://www.debian.org`]

- `SuSE Linux` [`http://www.suse.de`]

- `Mandrake` [`http://www.mandrake.com`]

- `Knoppix` [`http://www.knoppix.com`]: 一种从光盘运行的操作系统，你不需要安装。
