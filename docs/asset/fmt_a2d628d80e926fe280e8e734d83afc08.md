## 频率计数器

对于一个没有质量跨越边界的闭合系统，在可逆等温过程中可以完成的功由级数方程给出。

```
$W_{rev} = -\Delta A = -\Delta(E - TS) = -(\Delta E - T\Delta S)$
```

`$T$` 代表向环境释放的热量。如果过程是可逆的，`$\Delta S < 0$`，对环境所做的实际功小于系统的内能。`$(-\Delta A - T\Delta S)$` 可以被视为自由能，即在不可逆过程中可以转换成功的最大机械能。这就是“自由能”名称的由来。
