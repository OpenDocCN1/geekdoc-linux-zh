
# 槽 (Slots)

槽用于作为信号发射信息的接收者。许多槽都定义了参数，且槽参数的签名必须与其设计用于接收的信号签名相匹配。

本附录包含了在 KDE 和 Qt 类中定义的槽的字母顺序列表。槽也是一种方法，可以被应用程序间接调用，但这些方法实际上是由发射信号的应用程序定义的。
