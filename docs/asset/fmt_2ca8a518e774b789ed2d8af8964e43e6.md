# mifuz

A full text indexeder The purpose of `mifuz` is to provide a `C++` library to build and query a full text index. It is dynamically scalable (up to 1Tb indexes), controls amount of memory, shares index files and processes and compresses index files to 50% of the raw data. The query functions do not need to load the occurrences of a searched term. They consume few resources and many searches can run in parallel. Debian 3.0 APT
