## sockets

socket 是两个程序相互通信的端点。如果 socket 通过网络连接，程序可以运行在不同的设备上，例如笔记本电脑和数据中心。socket 有三种类型：

- Unix sockets：在同一设备上连接。
- UDP sockets（用户数据报协议）：使用一种快速但不可靠的协议。
- TCP sockets（传输控制协议）：比 UDP 更可靠，并允许数据按照发送时的精确顺序到达。

`ss` 命令允许管理员调查所有 sockets。它可以显示源地址、目的地址和类型。它的最佳功能之一是使用过滤器，用户可以监控任何感兴趣的连接。它可以带有一组选项来限制显示的信息。在不带任何选项的情况下，该命令显示所有已建立的 sockets。使用 `-p` 选项包含进程信息。`-s` 选项显示 sockets 摘要。还有许多可用选项：`-4` 和 `-6` 将 IP 缩小为 IPv4 或 IPv6，`-t` 和 `-u` 允许选择 TCP 或 UDP，`-l` 显示监听新连接的 socket。

例如，以下命令列出了所有使用的 sockets：


2. Linux 有一种名为“桥接”（bridging）的功能，它是做什么的？有什么用？

网接器连接了多个网络接口。所有连接到桥的接口都可以通信，就像它们连接到同一个链路层网络一样：所有设备使用同一子网的 IP 地址，且不需要路由器即可相互连接。
