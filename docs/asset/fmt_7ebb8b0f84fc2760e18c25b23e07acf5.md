## 异常处理

**PHP**
```php
try { ... } catch (ExceptionType $e) { ... }
```

**ASP/VBScript**
没有特别支持

**ASP.NET/C#**
```csharp
try { ... } catch (ExceptionType e) { ... } finally { ... }
```

**JSP/Java**
```java
try { ... } catch (ExceptionType e) { ... } finally { ... }
```

## HTTP POST 值

**ASP/VBScript**
```vb

```

**ASP.NET/C#**
```csharp
System.Web.HttpRequest.Form (NameValueCollection)
```

```java
request.getParameter() (method lookup)
```
