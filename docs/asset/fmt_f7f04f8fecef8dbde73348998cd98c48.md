
要全局安装字体以便机器上的所有用户都能使用，返回终端窗口。通过输入 `sudo fontname.ttf /usr/share/fonts/truetype/` 将你想要的字体复制到第 193 页项目 11B 第 1 步创建的系统字体文件夹。

### 卸载你的 Windows 分区

如果你是手动挂载的 Windows 分区，可以在完成工作后立即卸载它，也可以等到系统关机，届时它会自动卸载。在卸载之前，你必须确保你没有访问该目录，无论是通过终端窗口还是 Nautilus。因此，在执行卸载命令之前，如果你正在使用终端，输入 `cd` 回到主目录。输入 `sudo umount /media/windows`。

# 12 多语言的企鹅

Linux 说你的你的语言

![](img/ba6b82a7869bba748202d57c97336dca_220_0.png)

现如今，几乎所有的操作系统都是多语言的，或者至少具备多语言的能力。Linux 也是如此。只需打开网络浏览器，在不进行任何特殊安装的情况下，你就可以阅读任何欧洲语言的页面，包括带有西里尔字母的语言（如俄语）。你甚至可以查看中文、日语、泰语、阿拉伯语和希伯来语的页面，这仅是例子。

Linux 的多语言能力远于此，而且基于 GNOME 的发行版（如 Ubuntu）处理多语言的方式使得利用这些能力变得非常简单。正如你很快看到的，你甚至可以设置系统为你提供一个完全陌生的语言环境，让你完全用你选择的语言进行操作。再加上不断增加的用于语言学习的免费程序，你就拥有了一个真正有意义的语言学习工具。

## 只读语言支持

如果你只想能够阅读用外语编写的网页或文档，除了极少数情况外，你不需要安装任何额外的语言支持。从一开始，你就可以查看几乎任何你提供给系统的语言文档——无论是瑞典语、中文、意大利语、日语、阿拉伯语、希伯来语、俄语、越南语、亚美尼亚语还是泰语。你能够阅读任何你语言能力所及的内容（参见图 12-1 示例）。

## 在 Firefox 中更改字符编码

Firefox 通常会自动识别网页所编写的语言并正确显示页面。有时，页面的作者可能忘记在 HTML 中包含该页面的字符编码，在这种情况下，Firefox 由于不知道该页面是用另一种语言编写的，将以你系统的默认语言输出。结果是页面上你只能看到毫无意义的符号和字母的奇特组合。在这种情况下，尝试将 Firefox 中的字符编码更改为你认为该页面所属的语言。某些语言使用多一种编码方案，如果你不确定，请尝试每一种。你可以通过进入“查看”菜单并选择“字符编码”来做出选择。从子菜单中，你可以为该页面语言选择相应的编码。

## 使用键盘指示器

键盘指示已包含在你的系统中，因此无需安装。要访问它，只需在 GNOME 面板的某处点击右键，并从弹出菜单中选择“添加到面板”。当“添加到面板”窗口出现时，向下滚动并点击“键盘指示”，然后点击“添加”按钮。美国 就会出现在面板上。

现在，这本身除了你的默认键盘布局外什么都不提供，因此如果你想能够使用其他键盘布局，就必须配置键盘指示。要这样做，只需点击图标，并从弹出菜单中选择“打开字体偏好”，这将打开“字体偏好”窗口。

要添加键盘布局，点击该窗口中的“布局”选项卡，然后在新标签页中点击“添加”。这样做后，窗口将显示可用的键盘布局列表（图 12-3）。在窗口的左窗格中，向下滚动找到想要添加的语言的国家，然后点击它以选择该区域的标准键盘布局（点击国家旁的箭头查看你偏好的可选布局）。一旦做出选择，点击“确定”按钮，这将带你回到“字体偏好”窗口，你将在那里看到你的新键盘布局列表。然后点击“关闭”按钮完成设置。

关闭“字体偏好”窗口后，可以通过点击面板上的图标来更改键盘布局。你还可以通过进入“字体”窗口的“选项”选项卡并分配键盘快捷键来切换键盘布局。如果你不确定哪里

你想要输入的键位于新的键盘布局中，通过点击“键盘指示器”（Keyboard Indicator）面板切换到相应的键盘布局直到它出现，然后对其点击右键。在弹出的菜单中选择“布局视图”（Layout View），随后新布局的地图就会在一个单独的窗口中出现。默认窗口很小，但可以通过通常的拖动角落方式进行调整大小。

如果你想选择单一键盘布局来替换当前的布局（例如，使用英国英语代替美国英语，或使用德语代替西班牙语），你可以在“键盘偏好”（Keyboard Preferences）窗口中操作：添加你想要的键盘布局，勾选“默认”（Default）旁边的框框，并通过点击一下原始布局进行选择后再点击“移除”（Remove）按钮将其删除。

## 查看另一种语言的系统

最初吸引我 Linux 世界的众多原因之一是能够安装英语以外语言的支持。在我的其中一台机器上，我安装了中文、日语、瑞典语以及我默认的英语支持。只需简单注销并点击几次，我就可以以完全不同的语言重新登录。我可以随时随地使用中文、日语或瑞典语系统。

如果你打算用外语进行大量工作，或者正在学习外语并希望尽可能多地接触，这将非常有用。当有不同母语的用户使用同一台机器时，这也非常方便。例如，在我以前就读的大学，我的日本和中国学生有时会使用我的电脑，额外的语言支持允许他们使用自己的语言登录。总而言之，这是一个非常实用的功能。

在 GNOME 环境中利用这一功能非常简单，取决于你想要使用的语言，在特殊安装措施方面的要求很小。基本上，你所做的就是为想要添加到系统中的每种语言安装一组支持文件。你可以通过进入“系统”菜单并选择“管理支持”（Administration Support）轻松实现这一点。
