
## 定理 4.15
如果 `$G$` 是一个 `k`-连通图，`k >= 2`，那么 `G` 中的任意 `k` 个顶点都位于 `G` 的同一个圈上。

### 证明。
设 `S = {v1, v2, ..., vk}` 是 `G` 中 `k` 个顶点的集合。在 `G` 的所有圈中，设 `C` 是包含 `S` 中最多 `ℓ` 个顶点的圈。那么 `ℓ <= k`。如果 `ℓ = k`，则结果成立，因此我们可以假设 `ℓ < k`。由于 `G` 是 `k`-连通的，`G` 是 2-连通的，因此根据定理 3.3，`ℓ >= 2`。我们可以进一步假设 `v1, v2, ..., vℓ` 位于 `C` 上。设 `u` 是 `S` 中一个不位于 `C` 上的顶点。我们考虑两种情况。

*情况 1. 圈 `C` 恰好包含 `ℓ` 个顶点，设 `C = (v1, v2, ..., vℓ, v1)`.*

根据推论 4.13，对于每个满足 `1 <= i <= ℓ` 的 `i`，`G` 包含一条 `u-v_i` 路径 `P_i`，使得路径 `P1, P2, ..., Pℓ` 中任意两条仅共有顶点 `u`。用 `P1` 和 `P2` 替换 `C` 上的边 `v1v2` 会产生一个包含 `S` 中至少 `ℓ + 1` 个顶点的圈。这就产生了矛盾。

*情况 2. 圈 `C` 包含至少 `ℓ + 1` 个顶点.* 设 `v0` 是 `C` 上不属于 `S` 的一个顶点。由于 `2 < ℓ + 1 <= k`，根据推论 4.13，对于每个满足 `0 <= i <= ℓ` 的 `i`，`G` 包含一条 `u-v_i` 路径 `P_i`，使得路径 `P0, P1, ..., Pℓ` 中任意两条仅共有顶点 `u`。对于每个 `i`（`0 <= i <= ℓ`），设 `u_i` 是 `P_i` 中属于 `C` 的第一个顶点，设 `P_i'` 是 `P_i` 中从 `u` 到 `u_i` 的子路径。假设当我们沿着 `C` 的某个方向前进时，顶点 `u_i`（`0 <= i <= ℓ`）出现的顺序为 `u0, u1, ..., uℓ`。对于某个满足 `0 <= i <= ℓ` 的 `i` 且 `u_{i+1} = u0`，在 `C` 上存在一条 `u_i-u_{i+1}` 路径 `P`，其内部顶点不属于 `S`。用 `P_i'` 和 `P_{i+1}'` 替换 `C` 上的 `P` 会产生一个包含 `S` 中至少 `ℓ + 1` 个顶点的圈。再次产生矛盾。

然而，定理 4.15 的逆命题并不成立。例如，对于 `n >= k >= 3`，`G = C_n` 中的任意 `k` 个顶点都位于 `G` 的同一个圈上，但 `G` 不是 `k`-连通的。但是，存在一个与定理 3.3 和定理 4.15 都相关的定理。以下结果由唐·利克（Don Lick）[157] 提出。

## 定理 4.16
设 `k` 和 `n` 是整数，且 `n >= k+1 >= 3`。一个阶数为 `n` 的图 `G` 是 `k`-连通的，当且仅当对于 `G` 中由 `k` 个顶点组成的每个集合 `S` 以及 `S` 的每个二元子集 `T`，存在 `G` 的一个圈，该圈包含 `T` 的两个顶点，但不包含 `S-T` 中的任何顶点。

### 证明。
首先，假设 `T={u,v}`。根据定理 4.11，`G` 中存在 `k` 条内部点不相交的 `u-v` 路径。由于 `S-T` 中的 `k-2` 个顶点至多属于这些路径中的 `k-2` 条，因此存在两条路径不包含 `S-T` 中的任何顶点。这两条路径产生一个包含 `T` 的两个顶点且不含 `S-T` 中任何顶点的圈。

对于逆命题，设 `G` 是一个具有如下性质的图：对于 `G` 中由 `k` 个不同顶点组成的每个集合 `S` 以及 `S` 的每个二元子集 `T`，存在一个圈包含 `T` 的两个顶点，但不包含 `S-T` 中的任何顶点。假设相反，`G` 不是 `k`-连通的。那么 `G` 包含一个顶点割集 `W={w1,w2,...,w_{k-1}}`。由于 `n >= k+1`，图 `G-W` 至少包含两个顶点。设 `u` 和 `v` 是 `G-W` 中不同连通分支中的两个顶点。现在，设 `S={w1,w2,...,w_{k-2},u,v}` 且 `T={u,v}`。根据假设，存在一个包含 `T` 中顶点且不含 `S-T` 中顶点的圈 `C`。由于包含 `u` 和 `v` 的每个圈必须包含 `S-T` 中至少两个顶点，这就产生了矛盾。

梅滕斯定理（定理 4.10）和惠特尼定理（定理 4.11）在边割的意义上也有类似的定理。对于图 `G` 中两个不同的顶点 `u` 和 `v`，如果 `u` 和 `v` 位于 `G-X` 的不同连通分支中，则 `G` 的边割集 `X` 是一个 `u-v` 分离集。我们从定理 4.10 的边类似定理开始。

## 定理 4.17
对于图 `G` 中不同的顶点 `u` 和 `v`，`u-v` 分离集 `X ⊆ E(G)` 的最小基数等于 `G` 中两两边不公共的 `u-v` 路径的最大数量。

### 证明。
在这里证明一个更强的结果是方便的，允许 `G` 为多重图。

如果 `u` 和 `v` 是多重图 `G` 中不同连通分支中的顶点，那么定理是显然的。因此，我们可以假设所考虑的多重图是连通的。如果分离 `u` 和 `v` 的最小边数为 1，那么 `G` 包含一条桥 `e`，使得 `u` 和 `v` 位于 `G-e` 的不同连通分支中。因此，`G` 中的每条 `u-v` 路径都包含 `e`，所以 `G` 中两两边不公共的 `u-v` 路径的最大数量也是 1。

假设该陈述不成立。那么存在一个最小整数 `k >= 2`，使得存在包含两个顶点 `u` 和 `v` 的多重图，其中分离 `u` 和 `v` 的最小边数为 `k`，但不存在 `k` 条两两边不公共的 `u-v` 路径。在所有这样的多重图中，设 `G` 是规模最小的一个。

`G` 中 `u - v` 的边不交路径，这产生了一个矛盾。因此，`G` 包含一条长度为 3 或更长的 `u - v` 路径 `P`。

设 `e1` 是 `P` 中既不邻接 `u` 也不邻接 `v` 的一条边。考虑多重图 `G - e1`。由于 `G - e1` 的规模小于 `G` 的规模，`G - e1` 不可能包含分离 `u` 和 `v` 的 `k` 条边。因此，`e1` 必须属于每一个由 `k` 条边组成的、分离 `u` 和 `v` 的集合。设 `S = {e1, e2, ..., ek}` 为其中一个这样的集合。

我们现在细分 `S` 中的每条边，也就是说，`S` 中的每条边 `e_i = u_i v_i` 被替换为一个新的顶点 `w_i` 以及两条新边 `u_i w_i` 和 `w_i v_i`，其中 `1 <= i <= k`。将这 `k` 个顶点 `w_i` `1 <= i <= k` 视为同一个顶点，从而产生一个新的顶点 `w` 和一个新的多重图 `H`。（参见图 4.5 中的一种可能情况。）注意到 `w` 是 `H` 中的一个割点，且 `H` 中的每条 `u - v` 路径都包含 `w`。

![](img/598a6ae3fd44120830ada34717906f29_121_0.png)

记 `H_u` 为 `H` 中由所有 `u - w` 路径组成的子多重图，记 `H_v` 为由所有 `v - w` 路径组成的子多重图。`H_u` 中分离 `u` 和 `w` 的最少边数为 `k`，`H_v` 中分离 `v` 和 `w` 的最少边数也为 `k`。由于 `H_u` 和 `H_v` 的规模均小于 `G`，因此 `H_u` 包含 `k` 条两两边不交的 `u - w` 路径，且 `H_v` 包含 `k` 条两两边不交的 `w - v` 路径。

对于 `i = 1, 2, ..., k`，我们可以将 `H_u` 中的一条 `u - w` 路径与 `H_v` 中的一条 `w - v` 路径配对，从而生成 `H` 中一条包含边 `u_i w_i` 和 `w_i v_i` 的 `u - v` 路径。这产生了 `H` 中 `k` 条两两边不交的 `u - v` 路径。现在可以逆转在 `G` 中细分边 `u_i v_i` 并合并顶点 `w_i` 以得到 `w` 的过程，从而在 `G` 中生成 `k` 条两两边不交的 `u - v` 路径。然而，这产生了一个矛盾。

由于该定理已对多重图证明，因此它对图也成立。 ■
