## 零成本构建实验室

在虚拟化时代之前，信息技术（IT）专家、安全专业人员和学生都拥有装满 PC 设备的车库、地下室和其他房间。有时，这些 PC 和系统管理硬件从地板堆到天花板，电费单高得惊人。拥有大量的设备是一种折磨；如果你需要搬家，想象一下带走它们有多难。感激现在不是这样了。

无论你的 PC 运行的是 Windows、Mac 还是 Linux 操作系统，处理家庭虚拟化都有两种基本方法。这两个项目都不需要费用，并且适用于大多数运行 32 位或 64 位架构的各种操作系统。

### VMWare Player

优点
- 虚拟机（VMs）创建在专用于 NAT 的虚拟交换机上。许多虚拟机将能够选项相互通信，并可能从主机进行访问。
- 自然引入了 DHCP，因此所有虚拟机都可以相应获取 IP 地址。
- 对 Xen、XenServer、vSphere 等其他主流虚拟机程序提供高级虚拟化支持。

缺点
- 不支持 Mac、Solaris 或 FreeBSD 操作系统。
- 不考虑现有虚拟机的快或克隆。
- 与某些 Wi-Fi 组织连接器存在困难。

### VirtualBox

优点
- 适用于 Windows、Linux、Mac、Solaris 和 FreeBSD。
- 具有克隆虚拟机的功能（节省时间）。
- 支持日益增多的虚拟硬盘记录类型。这在运行下载和预制的虚拟机时特别有帮助。

缺点
- 除非在主机上启用了端口转发，否则虚拟机之间是相互隔离的。
- 不支持 Xen、XenServer、vSphere 或其他类型虚拟机程序所需的硬件虚拟化。
- 如果虚拟机崩溃，整个虚拟机损坏的概率更高。

本指南专门针对在 Microsoft Windows 7 专业版上引入的 Oracle VirtualBox 版本 4.2.16。选择使用 VirtualBox 而不是 VMware Player 是因为互联网上有更多资源可以在出现问题时提供帮助；尽管它需要一些额外的配置。

请记住，在选择虚拟化框架时，最好的测试就是你的研究。关于哪种最好有很多讨论，最终选择一个虚拟化框架而不是另一个是个人喜好。同样，与防病毒软件不同，两者都可以引入以满足不同的需求，因此可以在同一台 PC 上安装 VirtualBox 和 VMware Player。本指南使用的所有链接和引用在编写时是有效的。请注意功能、下载区域和数据可能会随时更改。

## 设置虚拟平台

为了将所有内容保持在虚拟化实验室中，创建一个可以运行 Kali Linux 的虚拟机是一个明智的主意。下面的步骤描述了如何设置 Kali Linux 以引导启动运行。在尝试或修改 ISO 时，可以使用此引导启动虚拟机且只需少量更改。

### 在 VirtualBox 中为 Kali Linux 设置虚拟机

打开 VirtualBox，点击“New”（新建）。

### 创建虚拟机
- 1. 为新虚拟机命名一个名称，此处使用 Kali-Linux-LiveDisc。将类型设置为 Linux，将变体设置为 Debian（64 位）（如适用），并点击“Next”继续。
- 2. 此阶段将仅在虚拟机内存中运行。确保将 RAM 大小至少设置为 2 GB。如果可用，建议 4 GB 更好。
- 3. 点击“Next”继续。下一步选择“创建虚拟硬盘”选项，并点击“Create”继续。
- 4. 选择 VMDK（虚拟机磁盘）选项，并点击“Next”继续。
- 5. 选择固定大小（Fixed Size）选项，并点击“Next”继续。
- 6. 默认名称和硬盘大小适用于引导启动情况；任何，如果你想在 VirtualBox 中完整安装 Kali Linux，将虚拟硬盘大小更改为 40 GB。点击“Create”继续。
- a. 完成完成后不要启动虚拟机。
- 7. 选择 Kali-Linux-LiveDisc 虚拟机，然后点击 Settings（设置）按钮。在左侧菜单中选择 General（常规）并切换到 Advanced（高级）选项卡。将共享剪贴板设置为 Bidirectional（双向），并将拖放设置设置为 Bidirectional（双向）。
- 8. 在左侧菜单中选择 Storage（存储）。点击标记为为空的 Controller: IDE “光盘”符号。在右侧勾选 Live CD/DVD 。浏览到下载的 Kali Linux ISO 文件。
- 9. 在左侧菜单中选择 Network（网络），并将 Attached to（连接到）设置为 Host-only Adapter（主机适配器）。

10. 点击确定保存更改并返回主界面。

Kali Linux 虚拟机的构建完成。

# 第 7 章：Metasploitable

Quick 预先配置了一台具有各种安全漏洞且故意不设防御的 PC。这是一个开始安全准备的极佳工具，但它并不建议作为基础工作框架。该虚拟机将为分析师提供许多利用 Metasploit Framework 学习渗透测试的机会。Metasploitable2 是一个预先工作完成且易于使用的虚拟机。这对于构建虚拟化实验室来说也是一个很好的入门阶段，因为在本节后续将进一步讨论的许多应用程序都可以在 Metasploitable2 虚拟机引入。

## 介绍 Metasploitable2

打开网络浏览器并访问：`http://sourceforge.net/`。使用搜索栏查找 Metasploitable。在结果中，点击 Metasploitable2 的链接。点击下载获取虚拟机。

将下载内容保存到会被记住的区域。如果没有成功打开，请启动 VirtualBox。

点击“新建”（New）按钮创建一个虚拟机。

- 1. 将虚拟机命名为 Metasploitable2，并将类型设置为：Linux。将版本设置为 Ubuntu，然后点击“下一步”（Next）继续。
- 2.（在向导之外）将 `Metasploitable2.zip` 文件夹的内容解压到：`C:/clients/%USERNAME%/VirtualBoxVMs/Metasploitable2/`。（回到 VirtualBox 向导）设置虚拟机的内存大小。点击“下一步”继续。512 MB 的内存应该足够；如有必要可以更改大小。

选择圆形按钮“使用现有的虚拟硬盘文件”（Use a current virtual hard drive document）。使用浏览按钮选择：`c:/clients/%USERNAME%/VirtualBox VMs/Metasploitable2/Metasploitable.vmdk`。

点击“创建”（Create）继续；现在不要启动虚拟机。

选择该虚拟机，然后点击“设置”（Settings）按钮。从左侧菜单中点击“通用”（General）。然后选择“高级”（Advanced）选项卡。

将“共享剪板”（Shared Clipboard）设置为：双向（Bidirectional），并将“拖放”（Drag'n'Drop）设置为：双向（Bidirectional）。从左侧菜单中选择“网络”（Network）按钮，并将“连接到”（Attached to）更改为：仅主机（Host-only Adapter）。点击确定保存更改。

选择 Metasploitable2 虚拟机，点击顶部的“启动”（Start）按钮。

使用默认凭登录 Metasploitable2：

用户名：`msfadmin`
密码：`msfadmin`

首先要记住，它显然没有图形用户界面（GUI）。Metasploitable 并不打算作为攻击阶段。目前登录 Metasploitable 的目的是确认其可用性并确定其 IP 地址，以便以后可以使用 Kali Linux 进行攻击。

检查分配给你虚拟机的 IP 地址。

- a. 输入：`ifconfig`
- b. 习惯情况下，VirtualBox 的 DHCP 服务器租出的 IP 通常以 `192.168.56.x` 开始。
- 假设：`192.168.56.101`

启动之前创建的 Kali-Linux-LiveDisc 虚拟机。登录 Kali 后，打开 IceWeasel（Kali 中的默认网络浏览器）并访问 Metasploitable2 虚拟机的 IP 地址。

## 扩展你的实验室

通过 Metasploitable2 项目，学习者不仅仅是获得了一台可以攻击的机器，而是获得了一个进入不同准备区域的门户。虚拟机本身通常对远程和本地攻击没有防御能力；随附的 Web 管理也随 Metasploitable 提供。

- 1. phpMyAdmin——通过 Web 界面管理 SQL 通常并不简单，但 phpMyAdmin 是用 PHP 编写的免费 Web 应用程序，改进了与 Web 服务器关联的 MySQL 数据库的管理。通过 phpMyAdmin 可以直接访问 MySQL 数据库，这是渗透测试人员和程序员极喜欢的目标。
更多信息：`http://www.phpmyadmin.net/`。

- 2. Mutillidae（名为 most-till-I-day）是 OWASP 的一个开源项目，致力于帮助安全专家和学生创建 Web 应用程序攻击技能。Mutillidae 是一个非常有用的准备工具，具有很高的网络支持并且不断更新。它包含在 Metasploitable2、SamuraiWTF 和 OWASP Broken Web Apps (BWA) 中。

Jeremy Drunin（在安全网络中称为 webpasswd）在 YouTube 上上传了许多关于 Mutillidae 的教程视频。随 Metasploitable 自然带的版本已经过时，且缺乏更现代的挑战。从 Sourceforge 项目页面下载最新版本的 Mutillidae 并将其传输到 Metasploitable2 的 `/var/www` 目录中以获取最新更新。
更多信息：
`http://sourceforge.net/projects/mutillidae/`
`http://www.youtube.com/client/webpwnized.`

- 3. WebDAV——网站管理员和经理可能需要更改网站内容。WebDAV 是 HTTP 协议的扩展，允许远程更改网站。WebDAV 使用用户名和密码组合来管理帐户访问。如果 WebDAV 设置未经过验证，攻击者可能会破坏网站、传输恶意文件并将 Web 服务器用于不同的邪恶目标。
更多信息：`http://www.webdav.org/`

- 4. DVWA——Damn Vulnerable Web App 是另一个供安全专家、教师、学生发现 Web 安全性的准备阶段，正如其名，它是没有防御的。
更多信息：`http://www.dvwa.co.uk`
`http://sourceforge.net/projects/dvwa/`

- 5. TWiki——一个强大的开源 Web 2.0 应用程序 wiki，已在 Metasploitable引入以测试 Web 2.0 应用程序。当前版本的 TWiki 已被企业巨头使用，例如 Yahoo!、Nokia 和 Disney。
更多信息：`http://twiki.org`。

上述所有应用程序都托管在 Apache Web 服务器上。任何放入 `/var/www` 的组织或站点都可以通过虚拟机上的 Web 界面访问。有许多像 Mutillidae 和 DVWA 这样的准备工具将帮助提高渗透测试的技能范围。

## 神奇的代码注入彩虹

Dan Crowley 是 Trustwave 的一名数据安全爱好者和自由科学家，他设计并生成了五个著名的准备套件。他最新的作品是将他的 Web 攻防工具结合成一个名为“神奇代码注入彩虹”（MCIR）的高级演练场。MCIR 包含以下模块：

- SQLol——一个 SQL 注入准备环境，它考虑了空白字符和序列的自定义，专注于基于测试的阶段，以准备测试和攻击 SQL 安全措施的关键技能。
- XMLmao——与 SQLol 类似，XMLmao 是一个可配置的 XML 注入准备环境。
- Shelol——一个用于命令注入的可配置框架 shell 准备环境。
- XSSmh——跨站脚本准备设备。
- CryptOMG——与 Andrew Jordan 合作，CryptOMG 是一个旨在利用加密基础漏洞的可配置横幅风格 Web。更多信息：`https://github.com/SpiderLabs/MCIR`。
