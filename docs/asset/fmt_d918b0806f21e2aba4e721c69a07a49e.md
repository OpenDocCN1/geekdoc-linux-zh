# X

X 字体服务器 `xfs` 是一个在网络上监听并为 X 服务器（以及/或 X 客户端）服务的守护进程。所有 X 服务器都有为自己提供本地安装字体的能力，但 `xfs` 使得从 X 服务器卸载这项工作成为可能，并在/或在字体上有一个中央字体库。

# xfs-xtf

X-TrueType 字体服务器提供一个 X-TrueType 字体服务器。这是一个兼容的 X 字体服务器，但增加了 Freebank 的 X-TrueType 字体处理方案支持。`XFree86` 4.0 的字体服务器可以处理 TrueType，但不能处理 Tcap。通过使用 Tcap 描述，支持如倾斜、调整字形宽度、伪布尔等变换。`xfs-xtf` 是一个在网络上监听并为 X 客户端（以及 X 客户端）服务的守护进程。所有 X 服务器都具有提供本地安装字体的能力，但它使得将该工作从 X 服务器中卸载，和/或在运行 X 服务的器的网络化机器上拥有字体库成为可能，这样所有机器就不需要各自的一套字体。用户也可以调用它，例如，在 X 或或正在运行的系统 `xfs-xtf` 无法访问的帐户中提供 X 字体。源自 Debian 3.0r0 APT https://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# xfsdump

XFS 文件系统包的管理实用程序，包含了 `xfsdump` 以及许多其他用于管理 XFS 文件系统的管理实用程序。`xfsdump` 检查文件系统中需要备份的文件，并将它们复制到指定的磁盘、磁带或其他存储介质上。它使用 XFS 特有的指令来优化 XFS 文件系统，并知道如何备份 XFS 扩展属性。用 `xfsdump` 创建的备份是“字节序安全的”，可以在不同架构的机器之间进行传输，也可以在 IRIX 之间之间传输。`xfsstore` 执行 `xfsdump` 的功能；它可以恢复文件系统的备份。随后的备份可以层在全量备份之上。单个文件和目录子树可以从全量或部分备份中恢复。源自 Debian 3.0r0 APT https://www.ldp.org/LDP/linux-Dictionary/html/index.html

# xfsprogs

管理 XFS 文件系统的实用程序。一组用于使用 XFS 文件系统的命令，包括 `mkfs.xfs`。XFS 是一种源自 SRIX 平台的高性能文件系统。它是完全多线程的，支持大文件和大文件系统、扩展属性、块大小，基于区（extent），并广泛利用 B 树（目录、空闲空间）来帮助性能和可扩展性。完整细节请参阅 http://oss.org/projects/xfs 上的文档。此实现与 IRIX 版本的 XFS 在磁盘上是一的。源自 Debian 3.0r0 APT https://www.ldp.org/LDP/linux-Dictionary/html/index.html
