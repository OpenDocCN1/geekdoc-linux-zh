
`partial()` 函数评估函数的某些参数，并返回一个对象，你可以调用该对象以稍后提供剩余参数。在以前述的示例中，变量 `f` 代表一个部分求值的函数，其中前两个参数已经计算完毕。你只需要提供剩余的参数值即可执行。函数参数的部分求值与被称为*柯里化*（currying）的过程密切相关，通过该过程，接受多个参数的函数（如 `f(x,y)`）被分解为一系列只接受一个参数的函数（例如，你通过固定 `x` 来获得一个新的函数，从而产生结果的值）。

## 转换函数

| 函数 | 描述 |

| `float(x)` | 将 `x` 转换为浮点数 |
| `complex(real, [imag])` | 创建复数。 |

## 条件表达式

一种常见的编程模式是根据表达式的结果条件地分配值。例如：

```
if a < b:
    minvalue = a
else:
    minvalue = b
```

这段代码可以使用条件表达式来缩短。例如：

```
minvalue = a if a <= b else b
```

在此类表达式中，中间的条件首先被求值。如果结果为 `True`，则求值 `if` 左侧的表达式。否则，求值 `else` 之后的表达式。

条件表达式应该谨慎使用，因为它们可能会导致困惑（特别是当嵌套或与其他复杂表达式混合时）。然而，一个特定的应用是在列表推导式和生成器表达式中。例如：

```
values = [1, 100, 45, 23, 73, 37, 69]
clamped = [x if x < 50 else 50 for x in values]
print(clamped) # [1, 50, 45, 23, 50, 37, 50]
```

## 循环与迭代

你使用 `for` 和 `while` 语句来实现循环。示例下：

```
while expression:
    statements
for i in s:
    statements
```

`while` 语句执行语句直到关联的表达式求值为假。`for` 语句遍历 `s` 的所有元素，直到没有更多元素可用。`for` 语句适用于任何支持迭代的对象。这显然包括内置的序列类型（如列表、元组和字符串），也包括任何实现迭代器协议的对象。

如果对象 `s` 可以与以下代码配合，则该对象支持迭代，这段代码镜像了 `for` 语句的实现：

```
it = s.__iter__()  # 获取 s 的迭代器
while True:
    try:
        i = it.next()  # 获取下一个项目（Python 3 使用 __next__）
    except StopIteration:
        break  # 没有更多项目
    # 对 i 执行操作
```

在 `for i in s` 语句中，变量 `i` 被称为迭代变量。在循环的每次迭代中，它都会从 `s` 接收一个新值。迭代变量的作用范围对于 `for` 语句是私有的。如果之前定义的变量具有相同的名称，该值将被覆盖。此外，迭代变量在循环完成后仍保留最后一个值。

如果迭代中使用的元素是相同大小的序列，你可以如下语句将它们解包到各个迭代变量中：

```
for x,y,z in s:
    statements
```

在此示例中，`s` 必须包含或产生每个具有三个元素的序列。在每次迭代中，变量 `x`、`y` 和 `z` 的内容被赋值为相应序列的项。虽然 `s` 是元组序列时这种情况最常见，但只要 `s` 中的项是任何类型的序列（包括列表、生成器和字符串），解包就都能工作。

在循环时，除了数据值之外，跟踪数值索引有时是有用的。示例下：

```
i = 0
for x in s:
    statements
    i += 1
```

Python 提供了一个内置函数 `enumerate()`，可以用于简化这段代码：

```
for i,x in enumerate(s):
```
