## 探索 Linux Shell

`Linux shell` 是一个允许用户与 Linux 操作系统 (`OS`) 交互的程序。它也被称为命令行界面 (`CLI`)。命令的输出显示在 `shell` 提示符上。`Shell` 不在内核中；它仅使用内核执行命令。内核是操作系统的核心组件，管理其资源，如内存和硬件设备。`Linux shell` 执行的基本功能是从命令行读取命令。

## 描述 Linux 中的 Shell 类型

`Linux` 提供了多种类型的 `Shell`，以下是：
*   `C shell`
*   `TC shell`
*   `Bash shell`

## C Shell (csh)

`Csh` 是一个由 `Bill Joy` 开发的交互式 `shell`。

## TC Shell (tcsh)

`Tcsh` 是为了增强 `csh` 而设计的 `shell`。

## Korn Shell (ksh)

`Korn shell` 是 `David Korn` 在 1980 年代开发的。

## Bash Shell

`Bash` 是 `Bourne Again Shell`，它是为 `GNU` 项目编写的，也是大多数操作系统的默认 `shell`。

# 运行命令

可以使用 `shell` 的历史功能重新运行命令。你还可以借助历史功能检查命令的进度。重新运行命令的一些功能如下：

*   **命令行编辑**：允许编辑命令行。此功能可以帮助你编辑输入错误的部分命令，而无需删除整行并重新开始。默认情况下，`Emacs` 是 `Bash shell` 的编辑器。也可以使用 `vi` 来编辑命令行。在你的主目录下的 `.bashrc` 文件中添加以下内容来设置 `vi` 命令行编辑：
    ```bash
    set -o vi
    ```
    使用控制键（`control`）、元键（`meta`，通常是 `Alt` 键）和方向键的组合来进行编辑。
*   **命令行补全**：允许通过输入命令的几个字符来补全命令行。
    ```bash
    $ cat /passwd | sort | less
    ```
*   **命令行回溯**：在输入命令后，将其保存在 `shell` 的历史记录中供以后使用。使用 `history` 命令查看历史列表。

# 连接和扩展命令

你可以通过组合两个或多个不同的命令来扩展命令。Linux `shell` 提供了将一个命令的输出重定向为另一个命令的输入的能力。这可以通过元字符连接命令来实现。某些元字符描述如下：

*   **管道命令**：使用管道元字符 (`|`) 将一个命令的输出连接到另一个命令的输入，例如：
    ```bash
    $ cat /etc/passwd | sort | less
    ```
    此命令列出 `/etc/passwd` 文件的内容，并将输出传递给 `sort` 命令，`sort` 命令将每行开头的用户名作为输入并按字母顺序进行排序。结果输出将被传递给 `less` 命令。
*   **顺序执行命令**：允许命令按顺序执行。顺序执行命令会在第一个命令完成后、第二个命令开始前运行另一个命令。可以通过在同一行中输入用分号 (`;`) 分隔的不同命令来按顺序运行命令，例如：
    ```bash
    $ date ; troff -me verylongdocument |
    ```
    在此示例中，一个文件被格式化了。第一个命令显示了格式化开始之前的文件日期和时间。`tro` 命令格式化文档并将输出发送到打印机。
*   **后台命令**：指需要时间完成的命令。在某些情况下，一个命令会等待另一个命令完成。在这种情况下，如果你不想让 `shell` 被阻塞，可以在后台运行命令。你可以使用连接符 (`&`) 在后台运行这些命令。后台命令的一个示例是：
    ```bash
    $ touch -me verylongdocument & |
    ```

## 变量

变量代表内存位置，可以分配名称和值。变量对大小写敏感，并且即使赋值了数值，也会被存储为字符串。当你从文件中提取信息时，变量前会有一个 `$` 符号。使用 `read` 命令将输入分配给变量，使用 `echo` 命令检索变量的内容。可以通过以下示例来说，我们创建了一个名为 `salutation` 的变量来检查其内容：

```bash
read salutation

HOW ARE YOU?

echo $salutation

HOW ARE YOU?
```

变量分为环境变量和参数变量。

## 环境变量

环境变量是一个命名的对象，包含由一个或多个应用程序使用的信息。它们与用户定义变量的区别在于，环境变量通常全大写，而用户定义的通常全小写。

# 条件

条件是检查命令是否执行了特定动作的语句。这些动作基于用户做出的决策，例如 `test` 命令。此 `test` 命令检查文件类型并比较值。`test` 命令的语法如下：

```bash
test EXPRESSION

[ EXPRESSION ]

test OPTION

DESCRIPTION
```

`test` 命令接受三种条件类型：字符串比较、算术比较和文件条件。可以与 `test` 命令一起的一些条件类型列在表 2.3 中：

| 字符串比较 | 结果 |
|---|---|
| `string1=string2` | 如果字符串相等则返回真 |
| `string1!=string2` | 如果字符串不相等则返回真 |
| `-z string` | 如果字符串为空则返回真 |
| 算术比较 | 结果 |
| `expression1 -gt expression2` | 如果 `expression1` 大于 `expression2` 则返回真 |
| `expression1 -le expression2` | 如果 `expression1` 小于或等于 `expression2` 则返回真 |
| `!expression` | 如果表达式为假则返回真，反之亦然 |
| 文件条件 | 结果 |
| `-file` | 如果文件是普通文件则返回真 |
| `-u file` | 如果文件设置了 `set-user-id` 则返回真 |
| `-x` | 如果文件是可执行的则返回真 |

# 控制结构

控制结构是指控制命令执行顺序的指令、语句或一组语句。换句话说，命令的流（执行动作的方向）被称为控制结构。一些控制结构如下：

*   `if`：测试命令的结果并根据条件执行一组语句。`if` 命令的语法如下：
    ```bash
    if condition

    then

    statements

    else

    statements
    ```
*   `for`：指的是对变量中存在的值范围进行循环。该值范围可以是任何字符串集合。`for` 命令的语法如下：
    ```bash
    for variable in value

    do

    statements

    done
    ```
*   `while`：允许用户在执行开始前未知命令执行次数的情况下，重复一系列命令。`while` 命令的语法如下：
    ```bash
    while condition

    statements

    done
    ```

## 输入与输出

`Linux` 中的命令处理可用输入、标准输入 (`stdin`) 和标准输出 (`stdout`)。通过键盘输入的输入是 `stdin`，显示在屏幕上的输出是 `stdout`（默认值）。

输入重定向是指您想要将一个文件视为命令的输入的过程。这可以通过使用小于符号 (`<`) 运算符来实现，如下例：

```bash
sort < myfile.txt
```

在这种情况下，`myfile.txt` 被视为输入命令。
输出重定向发生在输出被视为第二个命令或您希望将命令的输出保存到文件中。您可以使用大于符号 (`>`) 或管道 (`|`) 运算符重定向输出。输出重定向的示例例如：

```bash
$ ls >listing.txt
```

在前面的示例中，`ls` 的输出被重定向到文件 `dir_listing.txt`。
