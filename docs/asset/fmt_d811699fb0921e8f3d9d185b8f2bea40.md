# javah — C 头文件和存根文件生成器

### 概要

```
/usr/java/bin/javah [-classpath path] [-d directory] [-jni] -o outputfile][-stubs] [-td directory] [-trace] [-v] [-version] classname,

/usr/java/bin/javah_g [-classpath path] [-d directory] [-help] [-jni] -o outputfile][-stubs] [-td directory] [-trace] [-v] [-version] classname.
```

## 描述

`javah` 命令生成实现本地方法所需的 C 头文件和源文件。生成的头文件和源文件供 C 程序用于从本地源代码引用对象的实例变量。`.h` 文件包含一个结构定义，其布局与相应的类并行。结构中的字段与类中的实例变量对应。

头文件的名称以及其中声明的结构源于类名。如果传递给 `javah` 的类是一个包，则包名将附加在头文件名和结构名前之前。使用下划线 (`_`) 作为名称分隔符。

默认情况下，`javah` 会为命令行上列出的每个类创建一个头文件，并将文件放在当前目录中。使用 `-stubs` 选项创建源文件。使用 `-o` 选项将所有列出类的结果合并到一个文件中。

新的本地方法接口——Java Native生接口（JNI）不需要头文件信息或存根文件。你仍然可以使用带有 `-jni` 选项的 `javah` 命令来生成 JNI 风格本地方法所需的方法原型。结果存放在 `.h` 文件中。

`javah_g` 版本是 `javah` 的非优化版本，适用于 `jdb` 等调试器。

## 选项

- `-classpath path`: 指定 `javah` 用于查找类的路径。如果设置了 `CLSPATH` 环境变量，则覆盖其默认值。目录之间用冒号分隔。因此，路径的通用格式为：
- `-`: `your-path`: 例如：`:/home/avh/classes:/usr/local/java/classes`
- `-d directory`: 指定 `javah` 保存头文件或存根文件的目录。
- `-help`: 打印帮助信息。
- `-jni`: 创建一个包含 JNI 风格本地方法原型的输出文件。
- `-o outputfile`: 将命令行列出的所有类的生成的头文件或源文件合并到 `output` 中。
- `-stubs`: 从 Java 对象文件生成 C 声明。
- `-td directory`: 覆盖 `javah` 存储临时文件的默认目录。默认为 `/tmp`。
- `-trace`: 向输出添加跟踪信息。
- `-v`: 打印关于生成状态的消息。
- `-version`: 打印版本。
