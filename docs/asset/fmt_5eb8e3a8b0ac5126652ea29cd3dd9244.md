
## 描述

`vi` (visual) 是一种基于行编辑器的屏幕导向文本编辑器。你可以在 `vi` 内部使用 `ex` 的命令模式，也可以在 `ex` 内部使用 `vi` 的命令模式。本手册描述了视觉命令。有关所有行编辑器命令以及如何设置如自动行号和按下回车时自动开始新输出行等选项，请参考 `ex(1)` 手册。

# vi, view, edit

使用 `vi` 时，你对文件的更改会反映在终端屏幕上。屏幕上光标的位置表示文件中的位置。

`view` 的调用与 `vi` 相同，只是设置为只读标志。`edit` 的调用为初学者设计的。它与 `vi` 相同，只是报告标志设置为 `i`，设置了 `showmode` 和 `novice` 标志，并关闭了 `magic`。这些预设默认使得学习 `vi` 变得更容易。

## 注意事项

修改 `/usr/share/lib/terminfo/*` 或 `/usr/share/lib/terminfo/` 中的条目（例如更改或删除条目）可能会影响 `vi` 等期望条目存在且正确的程序。特别是删除 `dumb` 终端可能会导致意外问题。

使用 `^T` 的软件 `Tab` 在自动缩进后立即生效。

向左和向右移动不使用终端中的插入和删除字符操作。

标准的 Solaris 版本 `vi` 未来将由符合 POSIX 2 标准的版本（参见 `standards(5)`）替换。使用 `ex` 系列地址和功能的脚本应该使用这些命令的 `/usr/xpg4/bin` 版本。

## 选项

- `-s` 抑制所有交互式用户反馈。此选项在处理编辑器脚本时有用。
- `-C` 与 `-x` 选项相同，但模拟 `ex` 的 `C` 命令。`C` 命令类似于 `ex` 的 `X` 命令，只是读入的所有文本都被假设为加密过的。
- `-I` 设置为编辑 LISP 程序。
- `-L` 列出所有作为编辑器或系统崩溃结果保存的文件名。
- `-r filename` 在编辑器或系统崩溃后编辑文件名（恢复崩溃时缓冲区中的文件名 版本）。文件太大，无法通过 `-r` 选项恢复；加载文件时可能看到的消息表示文件可以成功编辑和保存，但如果丢失编辑会话，则无法通过 `-r` 选项恢复文件。
- `-R` 设置只读标志以防止覆盖文件。

结合 `-t` 标签使用，告诉 `vi` 不要对 `tags` 文件进行排序。如果二分查找（依赖排序的 `tags` 文件进行查找）未找到，则执行速度慢得多的线性搜索。由于线性搜索很慢，对于大文件，请确保 `tags` 文件已过排序，而不是使用此选项。创建 `tags` 通常会生成排序后的 `tags` 文件。有关 `tags` 文件的更多信息，请参见 `ctags(1)`。

- `-t tag`
编辑包含标签的文件，并将编辑器光标定位到其定义处。使用 `vi` 以显示编辑状态启动。你只需输入 `vi` 命令本身即可实现相同效果。

- `-v`
通过标准输入读取 `ex` 命令时，将输入回显到标准错误。此选项在 shell 脚本中处理命令时非常有用。

- `-V`
将默认窗口大小设置为 `n`。此选项在低速线路上使用编辑器时非常有用。

- `-wn`
模拟 `ex` 的 `x` 命令并提示按键。该键用于使用 `crypt` 命令的算法对文本进行加密解密。`x` 命令通过推断来确定 `ex` 中的文本是否已加密，它使用临时缓冲区文件，同时也你为 `-x` 选项输入的键的转换版本。

- `-x`
`+command |c command` 通过执行指定的编辑器命令（通常是搜索或定位命令）开始编辑。

# 命令摘要

## vi 模式

| 命令 | 描述 |
| :--- | :--- |
| 普通模式和初始模式。其他模式在完成后会返回命令模式。使用 `ESC`（Esc 键）取消部分命令。 |
| 输入模式 | 通过设置以下任一选项进入：`a` `A` `I` `O` `c` `C` `s` `R`。然后你可以输入任意文本。通常使用 `ESC` 字符退出输入模式，或异常情况下通过中断退出。 |
| 末尾模式 | 读取用于 `:` `/` `?` 或 `!` 的输入。按回车键终止。中断会取消终止。 |

# 示例命令

在描述中，`CR` 代表回车键（Return），`ESC` 代表 Esc 键。

- `+ <- |v |?^ ->` 箭头键移动光标。
- `h j k l` 与方向键相同。
- `itextESC` 插入文本。
- `cwnewESC` 将单词更改为 `new`。
- `easESC` 将单词变为复数（单词末尾）；添加 `s`；跳出输入状态。
- `x` 删除一个字符。
- `dw` 删除一个单词。
- `ddd` 删除一行。
- `3dd` 删除三行。
- `u` 撤销上次更改。
- `ZZ` 保存更改并退出。
- `:q!CR` 丢弃更改并退出。
- `/textCR` 搜索文本。
- `^U ^D` 向上或向下滚动屏幕。
- `:cmdCR` 任何 `ex` 或 `ed` 命令。

# vi 命令前的计数器

你可以在某些命令前输入数字。数字按以下方式之一进行解释。

- `+ z G |` 行/列号。
- `^D U` 滚动量。
- 大多数其他命令 重复执行效果。

# 中断与取消

- `+ ESC` 结束插入或未完成的命令。
- `DEL` 删除或擦除中断。

# 文件操作

- `+ ZZ` 如果文件已修改，则写入并退出；否则退出。
- `:wCR` 写回更改。
- `:w!CR` 如果原始权限无效，则强制写入。
- `:qCR` 退出。
- `:q!CR` 退出并丢弃更改。
- `e nameCR` 编辑文件名。
- `:e!CR` 重新编辑，丢弃更改。
- `:e +nameCR` 从文件名末尾开始编辑。
- `:e +nCR` 从第 `n` 行开始编辑。
- `e: #CR` 编辑交替文件。
- `e! #CR` 编辑交替文件，丢弃更改。
- `:w nameCR` 写入文件名。
- `:w! nameCR` 覆盖文件名。
- `:shCR` 运行 shell，然后返回。
- `:!cmdCR` 运行 `cmd`，然后返回。
- `nCR` 编辑参数列表中的下一个文件。
- `:n argsCR` 指定新的参数列表。
- `^G` 显示当前文件和行。
- `:ta tagCR` 将光标定位到标签。

通常情况下，你可以在冒号和返回之间输入任何 `ex` 或 `ed` 命令（如 `substitute` 或 `global`）。

# 文件内定位

- `+ ^F` 向翻页。
- `^B` 向后翻页。
- `^D` 向下滚动半屏幕。
- `^U` 向上滚动半屏幕。
- `G` 跳到指定行的开头（默认末尾），`n` 是行号。
- `/pat` 找到匹配 `pat` 的下一行。
- `?pat` 找到匹配 `pat` 的上一行。
