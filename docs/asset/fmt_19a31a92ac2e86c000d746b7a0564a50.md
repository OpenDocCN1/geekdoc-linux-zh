
此外，为了与网站之间传输信息保持一致，你可以使用特殊代码 `INPUT TYPE=submit`，它会在用户点击提交（Submit）按钮时将数据发送出去。你希望接收提交信息的目的地被编码在 `FORM` 标签中。`FORM` 标签指定了如何获取要传输的信息。有两种方法：`GET` 和 `POST`。`GET` 方法在 URL 内部传输数据。`POST` 使用 HTTP 请求体部分来传递参数。（在本章中你会使用 `POST` 方法。）

```perl
#!/usr/bin/perl

&ParseForm;
```
