### `mstcorefonts`
山标准时间 [-0700]（TZ, PDT, USA）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

Microsoft TrueType cores 安装程序。此包允许安装 Microsoft True Type 字体，包括：

- Andale Mono
- Arial Black（Arial, `斜体` `粗体斜体`）
- Sans MS（`粗体`）
- Courier New（`粗体` `斜体斜体`）
- Georgia（`斜体` `粗体`）
- Impact
- Times New Roman（`粗体` `斜体斜体`）
- Trebuchet（`粗体` `斜体斜体`）
- Verdana（`粗体` `斜体斜体`）
- Webdings

你需要连接互联网以从微软网站下载这些模块。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
