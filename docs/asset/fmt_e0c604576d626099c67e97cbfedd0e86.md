
`Ψ = A(r1,r2)...φ(r1)φ(r2)...`

对于电子，构造斯莱特行列式的效果使其作用的轨道消失。自旋轨道是空间轨道`ϕ`和电子自旋`α`或`β`的乘积。对于任何量子系统，都有无限个波函数，使得`Hartree-Fock`波函数是能量的极小值。

```
E = Σ ⟨ii|H|⟩ - 1/2 Σ ⟨ij|⟩
```

为了求解希尔伯特方程，要么使用一组解析函数，要么使用数值方法，后者得到了轨道。通过变分法是可能的。对于多原子分子的轨道，轨道者这种方法是可行的。后一种方法是用于多原子分子的轨道。希尔伯特方程的精确解仅适用于原子和双原子分子。这种对于多原子分子的轨道被放弃了。波函数是最小基组自洽方法。更精确地，结构通过最小基组自洽方法重现。对于多原子分子的自洽（`SCF`）场，能量由式(2)的函数(1)给出。这被称为自洽（`SCF`）方法。近`Hartree-Fock`。

```
E = ⟨Ψ|H⟩
```
