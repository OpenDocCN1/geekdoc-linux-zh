## 固体溶液

由于晶体结构中原子成分的替换或缺失产生的现象。固体溶液可以分类为置换型、间隙或装饰型。它们可以根据热力学性质（如熵和自由能）进行分类（例如理想、局部）。

固体溶液的概念考虑到特定的矿物群，如橄榄石。橄榄石具有多种结构，但橄榄石中的所有矿物都是同结构的（具有相似的晶体结构）。

## 固态

没有电解质泄漏的问题。通常具有很长的寿命，且性能不随温度变化（而像电解质冻结或沸腾可能引起的变化那样）。低功率设备本质上也更安全。这些技术的许多应用于电子设备，如起搏器、相机、电子显示器、手表和计算器。参见 Brown (M.S.)。

扩散和电导性是固态化学中不可缺的基础组成部分。见 扩散；金属的电导性。

固体电子结构的一个特征（它对固态化学尤为重要）是离子的价态以及在在该状态下改变价态所需的能量。

在固体中发生的许多光诱导过程可以被想象为固态反应。经典的那些是在照片和电影中展示的。见 光化学 (R.J.T.)。

固态化学是关于固体以及固体与其他物质之间发生并产生新固体的转变的基础性原子级科学。固态化学处理具有固体特征并导致宏观性质的微观特征。除了物理学各个分支之间的化学反应外，固态化学还包括相关领域，为那些更具学科本身特征的现象提供了概念和解释。

固态物理研究固体的性质，如电电、弹性和热学性质，以及它们在基础物理学中的理解。固态物理的研究可以被化学背景的科学家称为固态研究，反之亦然。固态物理对于对于大类化合物而言，其性质比化学组成预测的性质更重要。此外，固态化学倾向于更具描述性，而固态物理则倾向于对关系和电子结构具有更强的分析性。

固态化学与固态物理的重叠非常广泛。然而，两者的性质是不同的。通常情况下，这些性质是机械的，在固体中连续变化；固态化学关注那些由于化学反应引起的性质。固态化学将固态物理中的电子结构与化学空间联系起来。见 无机化学；固态物理。

许多科学家通过固态物理研究液体的性质，而“凝聚态物理”这一术语包含了固态物理的一些结果。它包括非晶体，如玻璃和玻璃态。见 非晶体材料。

# 溶解度积常数

定义了一种特殊的平衡常数 (`$K_{sp}$`)，用于溶液中盐与其各自相应离子之间的平衡，例如反应 (1)。对于这种相对简单的平衡，适用等 (2) 和等 (3)。

```
AgCl(s) \rightleftharpoons Ag^+ + Cl^-
```

```
[Ag+][Cl^-] = Ksp
```

实验证明，氯离子 (`Cl⁻`) 摩尔浓度的微增加会导致 `AgCl` 溶解度的降低。同样，`[Ag+]` 的增加也会降低溶解度。这两种浓度近似由等 (2) 和等 (3) 描述，因为盐会改变离子的活度。在浓度变化过程中，状态保持不变。对于固体，`AgCl` 的溶解度为单位，此处见等 (4)

```
[Ag+][Cl^-] = 1.8 \times 10^{-10} mol/liter
```

在实践中，变化源于：一种离子的含量多于另一种离子的表观浓度。添加普通盐（如盐），而非 `Ag⁺` 或 `Cl⁻`，不会与 `Ag⁺` 或 `Cl⁻` 反应，可能会通过平均离子亲和系数增加离子浓度。请参见地球化学-前化学。（T.V.E.）
