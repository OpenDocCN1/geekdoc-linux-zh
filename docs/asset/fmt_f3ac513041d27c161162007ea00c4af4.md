# 使用样条创建实体形状

你一直都在使用样条来创建酒杯的轮廓形状以及平面图的墙体。你也可以创建像你在上一节中看到的原始对象那样的实体形状。样条让你超越圆、矩形和正方形等原始形状，创建几乎任何你需要的形状。

在接下来的练习中，你将使用样条为目前为止创建的墙创建一个天花板。这涉及到创建墙的轮廓，然后使用挤出（`Extrude`）修改器赋予轮廓一定的厚度。

首先设置一个便于添加天花板的视图：

1. 在透视视图（`Perspective`）中进行圆弧旋转（`Arc Rotate`），以便看到墙的整个顶边。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_178_0.png)

2. 接下来，设置捕捉（`Snaps`）以将样条准确放置在墙的边缘。右键点击捕捉切换（`Snaps Toggle`）工具。

3. 在网格和捕捉设置（`Grid and Snap Settings`）对话框中，点击清除（`Clear All`），然后勾选端点（`Endpoint`）复选框。

4. 关闭网格和捕捉设置对话框。

5. 确保捕捉切换选项已开启。

现在你可以准备好添加将成为天花板的样条了：

1. 点击命令面板的创建（`Create`）选项卡，如果尚未选择形状（`Shapes`）工具，请点击它。

2. 点击线条（`Line`）工具。

3. 如图 3.40 所示，点击墙的外部角。当到达圆角时，点击图中指示的点。你稍后将移动并重塑该角。

4. 回到起始角时，点击它。在样条（`Spline`）对话框中，点击是（`Yes`）以关闭样条。

现在你已经用样条勾出了屋顶平面。现在，你需要对墙体圆角处进行调整：

1. 选中天花板，点击命令面板中的修改（`Modify`）选项卡。

2. 关闭捕捉切换，在选择（`Selection`）展开组中点击顶点（`Vertex`）图标，然后在主工具栏中点击选择并移动（`Select and Move`）工具。

3. 如图 3.41 所示，点击圆角处的顶点。

# 介绍样条类型

你已经使用过线条样条（`Line spline`）和矩形样条（`Rectangle spline`），并进行了编辑练习。在继续之前，你想了解一下其他样条类型。表 3.2 显示了不同的样条选项、创建方法以及每个对象的特性。你可能想在单独的文件创建不同的样条进行实验。

所有原始对象的通用参数位于渲染（`Rendering`）和插值（`Interpolation`）展开组。插值展开组用于调整每个顶点之间的步数或直线段。形状的步数越多，曲线越平滑，但当形状进行放样（`loft`）或挤出时，会导致更复杂的对象。

## 表 3.2：样条的创建方法

| 样条名称和功能 | 创建方法 | 创建选项* | 参数* |
|---|---|---|---|
| 线条—绘制样条 | 点击点放置直线段。当初始（`Initial`）或拖动（`Drag`）组选择平滑（`Smooth`）时，点击并拖拽会增加平滑度。 | 初始类型：角/ 平滑 拖动类型：角/ 平滑/ 贝塞尔 | 线条不是参数对象。 |
| 圆—绘制圆 | 点击中心并拖拽半径[中心]。或点击两点在圆周边缘定位点[边缘]。 | 边缘/ 中心 | 半径。 |
| 弧—绘制弧 | 点击放置第一个端点并拖拽放置第二个端点，然后调整并点击半径[端到端]。或点击中心，拖拽半径和第一端，再点击第二端[中心到端]。 | 端到端/ 中心到端 | 半径、起始、终止、扇形（创建从中心到端点的直线段构成的扇形形状）、反转。 |
