## 其他命令

SCCS 提供了其他用于管理项目的实用工具。

例如，`unget` 命令可以取消 `get` 操作，防止创建新的增量，并删除与之前的 `get` 相关的锁。另一个命令 `rmdel` 用于在增量应用后将其从 SCCS 文件中删除。

你可以使用 `cdc` 来更改与增量相关的注释。

为了合并两个增量，SCCS 提供了 `comb` 命令。该命令旨在减小 SCCS 数据文件的大小，而不是用于解决冲突。它产生一个 shell 脚本，然后运行该脚本执行压缩。SCCS 还提供了 `sccsdiff`，你可以用它比较 SCCS 数据文件，并在 `comb` 操作后检查文件。

（这意味着在在你确定一切无问题之前，应该保留文件的备份副本。）

`sact` 命令提供一份报告，说明哪些修订已检出并进行编辑，以及它们在检回时将变为什么修订。

`sccs` 命令为所有这些命令提供了简化的接口。请参阅其分发的手页。

## 额外的 SCCS 特性

SCCS 包含了额外的软件配置管理支持钩，这些钩子在创建 SCCS 文件时设置。你可以使用 `admin` 命令的 `-f x` 和 `-d x` 选项执行以下操作：

| x | 操作 |
| :--- | :--- |
| `v[pm]*` | 要求 `delta` 具有修改号。 |
| `c[eil]*` | 限制通过 `get` 获取的发布。 |
| `f` | 限制通过 `get` 获取的发布。 |
| `l[ist]*` | 限制通过 `delta` 提交的发布。 |
| `j` | 启用/禁用并发锁。 |
| `b` | 启用/禁用分支。 |
| `d[SID]*` | 为 `get` 设置默认修订。 |
| `n` | 为跳过的发布创建空增量。 |
| `q` | 控制某些关键字的扩展。 |

有关这些选项的更多细节，请参阅 `admin` 手页。

## 创建分支

使用 `get -b -e` 会导致 SCCS 从指定的修订创建一个分支。如果你想在之前的示例的 `1.2` 处创建一个第二个修订，可以执行以下命令：

```
$ get -b -e -r1.2 liner.txt
```

`1.2` 行反映了下一个 `delta` 将检入为 `1.2.1` 而不是 `1.3`。（注意，如果你在处理 `1.2.1` 时有人正在编辑修订 `1.3`，那么两个用户在检入时都必须为 `delta` 提供 `-r` 标志！）

SCCS 不支持像 RCS 那样的分支。

## 合并修订

合并修订是 SCCS 的一项功能，它不需要像 RCS 那样。`merge` 工具是随 UNIX 发布的。`merge` 比较两个文件并输出到标准输出。为了让 `merge` 能够工作，需要一个共同祖先。`merge` 考虑文件冲突。
