在练习中，你将显示并设置 Bourne Shell 变量。

- 1. 在你的主目录下，使用 `vi` 创建一个名为 `search1` 的文本文件，内容如下：

```bash
#!/bin/sh

grep -l $string *
```

- 2. 为文件设置执行权限：

```bash
chmod 744 search1
```

```bash
./search1
```

### 12.5 使用 while

本练习演示了在脚本中使用 `while` 循环。

预估时间：15 分钟

- 1. 在你的主目录下，使用编辑器创建一个名为 `msg` 的文件，内容如下：

```bash
#!/bin/sh
count=1
while [ $count -lt 12 ]
do
  echo "Hello, I'm here"
  sleep 5
  count=$((count+1))
done
```

- 2. 为文件设置权限：

```bash
chmod 744 msg
```

- 3. 执行脚本：

```bash
./msg
```
