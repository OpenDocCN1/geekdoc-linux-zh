## 3.5.1 配置简单防火墙 (UncomplicatedFirewall)

如果你的环境中使用了 `nftables` 或 `iptables`，请遵循它们各自章节中的指南，并跳过本节的指南。

简单防火墙 (`UFW`) 是一款用于管理 `netfilter` 防火墙的程序，设计简单易用。

- 使用由少数简单命令组成的命令行界面
- 使用 `iptables` 进行配置
- 规则将进行处理，直到遇到第一个匹配的规则。将应用第一个匹配的规则。

注意：

- 直接通过远程连接配置运行系统的防火墙通常会导致被锁定在系统之外
- 规则的顺序应使得 `ALLOW`（允许）规则位于 `DENY`（拒绝）规则之前。

### 3.5.1.1 确保 ufw 已安装（自动化）

**配置方案适用性**：

- 等级 1 - 服务器
- 等级 1 - 工作站

**描述**：

简单防火墙 (`ufw`) 是 `iptables` 的前端，特别适用于基于主机的防火墙。`ufw` 为管理 `netfilter` 提供了一个框架，并提供了用于操作防火墙的命令行界面。

**原理**：

需要一种防火墙工具通过 `iptables` 或 `nftables` 后端配置 Linux 内核的 `netfilter` 框架。

Linux 内核 `netfilter` 框架主机防火墙可以防止来自企业网络内部的威胁，包括恶意移动代码和主机上配置不当的软件。

注意：应仅安装和配置一种防火墙工具。`UFW` 依赖于 `iptables` 包。
