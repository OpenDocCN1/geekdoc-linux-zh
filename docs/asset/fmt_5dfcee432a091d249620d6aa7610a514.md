## 文本格式化

当文本出现在 HTML 文档中时，浏览器决定如何显示它。你可以控制字体，也可以控制它的格式。默认情况下，你输入的是不带格式的文本，它会自动两端对齐。

新段落以 `<P>` 标签开始，如果你想强制换行，则使用 `<br>` 标签。浏览器决定如何格式化文本，但它总会在行开头开始一个新段落（上方有一个空行），并且当你使用换行符时，它会在新行开始文本（上方没有空行）。

如果你有引用的文本，请将其放在 `<blockquote>` 标签之间——它通常会缩进显示，就像书中的引文出现一样。如果你有需要非常特定格式的文本，可以将其包含在 `<pre>`（预格式）块中——它将按照你输入的方式出现。

```
<html>
<head>
<title> 文本格式 </title>
</head>
<body>
<p>这是分两行输入的普通文本。如果窗口足够宽，它将显示为一行</p>
<p>这个段落在这里断开 <br> 然后在下一行继续。</p>
<p>水平规则（线）出现在此行下方 <hr> 且此行上方。</p>
<p><address> 这是一个地址字段，它本身就是一个段落 <br> 占据 2 行 </address></p>
<p><blockquote> 这段文本被视为块引用，通常会缩进 </blockquote></p>
<p><pre> 这段文本是预格式化的。我在两行的每行前面都放了 3 个空格。</pre></p>
</body>
</html>
```

标题和段落标签作为 HTML 3 版本的一部分得到了扩展。在新版本中，文本可以左对齐（默认）、居中或右对齐。Netscape 还支持 `<center>` 标签来使文本居中。

```

<head>
<title> 扩展文本格式化 </title>
</head>
<body>
<h5 align=left> 此标题左对齐 </h5>
<h5 align=center> 此标题居中 </h5>
<h5 align=right> 此标题右对齐 </h5>

<p align=center> 此文本居中 <br> 即使在第二行也是如此</p>
<p align=right> 此文本右对齐 <br> 即使在第二行也是如此</p>
<center> 此文本在多行中居中 <br> 使用 <br> Netscape 扩展 </center>

```

## 列表

HTML 支持以下五种类型的列表：

- 无序 (Unordered)
- 有序 (Ordered)
- 目录列表 (Directory)
- 菜单列表 (Menu)
- 词表 (Glossary)

除了词表（或定义）列表外，列表中的每个元素都通过 `<li>` 标签（列表项）指定。

无序列表使用 `<ul>` 标签指定，并以项目符号出现。在列表末尾使用 `</ul>` 标签。如果在无序列表内部编码了另一个 `<ul>` 标签，将创建另一个层级的列表（缩进的子列表）。用于子列表的项目符号可能与上方的列表相同或不同。

有序列表使用 `<ol>` 标签指定，并按顺序编号。在列表末尾使用 `</ol>` 标签。如果在有序列表内部编码了另一个 `<ol>` 标签，将创建另一个层级的列表（缩进的子列表）。编号序列为每个子列表重新开始。

无序列表可以包含有序列表，反之亦然。

目录列表使用 `<dir>` 标签指定，并以项目符号出现。在列表末尾使用 `</dir>` 标签。如果在目录列表内部编码了另一个 `<dir>` 标签，将创建另一个层级的列表（缩进的子列表）。用于子列表的项目符号可能与上方的列表相同或不同。

菜单列表使用 `<menu>` 标签指定，并按顺序编号。在列表末尾使用 `</menu>` 标签。如果在菜单列表内部编码了另一个 `<menu>` 标签，将创建另一个层级的列表（缩进的子列表）。编号序列为每个子列表重新开始。

无序列表可以包含有序列表，反之亦然。

在处理目录列表和菜单时，浏览器之间的行为有所不同。你可能无法嵌套列表，且显示格式会有变化（菜单列表通常带有项目符号）。
