
对已描述植物物种数量的保守估计为25万种。可能还有两到三倍数量级的物种尚未被发现，主要分布在南半球。植物被分为非维管植物和维管植物两大类，后者又分为无种子维管植物和种子植物类群。非维管植物包括苔藓、地钱和黑藻（角苔）。无种子的维管植物包括裸子植物（注：原文此处逻辑可能有误，裸子植物通常属种子植物，此处依原文直译可能对应蕨类等，但原文写的是gymnosperms，故保留）、木贼、蕨类和问荆（whisk ferns，此处可能指真蕨类的某类，依原文译）；种子植物包括苏铁、银杏、针叶植物、买麻藤目和开花植物。这些类群在植物学命名法中各自构成一个纲，相当于动物分类系统中的门。参见[PLANT TAXONOMY（植物分类学）](https://example.org/plant_taxonomy)。[M.L.A.]

## 植物解剖学

植物科学中研究植物内部结构的领域。它既处理成熟结构，也处理其起源和发育。

植物解剖学家解剖植物，并从不同切面和各种放大倍数下研究它。在细胞水平上，解剖学与植物细胞学重叠，后者专门研究细胞及其内容物。有时，植物组织学这一名称被应用于植物解剖学中专门研究组织细胞细节的领域。参见[PLANT CELL（植物细胞）](https://example.org/plant_cell)；[PLANT ORGANS（植物器官）](https://example.org/plant_organs)。[K.E.]

## 动植物相互作用

利用进化和整体性的视角来研究相互作用的植物和动物的生态学。例如，某植物物种防御性化合物的化学成分可能因食草动物长期影响导致的自然选择压力而改变。此外，现代食草动物的生理机能可能为了适应解毒或避免植物防御化学物质的过程，已发生数千年前的变化。

基于对动植物相互作用的理解所建立的理论的应用，有助于理解现代农业生态系统中的问题。此外，动植物相互作用在医学上也有实际应用。例如，一些植物化学物质（如来自毛地黄植物洋地黄毒苷）作为食草动物防御化合物演化而来，对人类具有有用的治疗作用。

### 各种相互作用类型对每个物种的影响

| 相互作用 | 对物种A的影响 | 对物种B的影响 |
| :--- | :---: | :---: |
| 互利共生 | + | + |
| 偏利共生 | + | 0 |
| 对抗 | – | – |
| 竞争 | 0 | – |
| 消灭 | 0 | 0 |
| 中性作用 | 0 | 0 |

+ = 有益，– = 有害，0 = 中性

动植物相互作用的进化后果各不相同，取决于对各参与者的影响。相互作用类型从互利共生（即对两个参与物种都有利的关系）到对抗（相互作用仅利于一个参与物种并对另一个产生负面影响）。相互作用类型的定义基于相互作用对每个相互作用物种的影响是有益、有害还是中性（见表）。[W.G.A.]

## 化石记录

在现代生态系统中，植物和动物以多种方式相互作用。这些相互作用从简单的食草（动物吃植物）例子到更复杂的相互作用（如授粉或种子和果实传播）不等。动物还依赖植物提供食物和庇护所。生物在地质时间尺度上的复杂相互关系不仅导致了生物在时间和空间上的丰富性和多样性，也为生物界中的许多进化适应做出了贡献。

古生物学家试图破译地质时间尺度上植物和动物之间存在的某些相互关系。地质过去生物体的化石记录正在与化石一起分析。因此，随着古生物学家对某些化石生物理解的加深，考察它们所生活生态系统的某些方面以及各类生物如何相互作用已成为可能。

### 食草

植物和动物之间最普遍的相互作用可能是食草，即植物被用作食物。确定化石记录中食草程度的一种方法是分析通过食草动物消化道的植物物质。

一些化石植物的茎显示出组织破坏，类似于动物取食活动穿透植物部分所造成的各种类型的伤口。随着植物发育出纤维层作为防御系统来覆盖其内部多汁组织，一些动物进化出了刺穿式口器，使它们能够穿透这些厚壁层。在一些化石植物中，还可以看到在这些渗透部位生长出的伤口组织证据。参见[COAL BALLS（煤球）](https://example.org/coal_balls)；[HERBIVORY（食草）](https://example.org/herbivory)。

### 拟态

另一个可以从化石记录中确定的动植物相互作用例子是拟态。某些化石昆虫的翅膀在形态上与植物叶片完全相同，从而当昆虫停在种子蕨叶片上时，提供免受捕食者侵害的保护色。

### 授粉

在被子植物中从花粉囊到可授粉柱头的花粉转移，或在裸子植物中到种子的转移，是植物和动物之间古老相互作用的例子。有建议认为，某些类群的授粉最初是某些动物无差别觅食行为的结果，后来专门进化为授粉方法。化石花粉粒的大小、形状和组织为潜在的授粉媒介提供了洞察。参见[GROSS](https://example.org/gross)；[PALAEOPOLLEN（古花粉）](https://example.org/palaeopollen)；[POLLINATION（授粉）](https://example.org/pollination)。[T.N.T]

## 植物细胞

几乎所有植物结构和功能的基本单位。尽管植物细胞在结构和功能上有各种修饰，但它们有许多共同特征。所有植物细胞最显著的特征是刚性细胞壁，这在动物细胞中是不存在的。植物细胞特化的范围和结合特征非常广泛。在最简单的植物形态中，单个细胞构成整个生物体并执行所有生命功能。在稍复杂一些的形式中，细胞在结构上相关联，但每个细胞似乎都能执行基本生命功能，尽管某些细胞可能专门用于参与生殖功能。在最先进的植物中，细胞在功能特化的组织中联结，相关组织构成如叶、茎和根等器官。参见[CELL WALLS (PLANT)（细胞壁（植物））](https://example.org/cell_walls_plant)。

植物和动物细胞由相同的组成成分组成——核酸、蛋白质、碳水化合物、脂质和各种无机物质——并以相同的基本方式组织。其组织的一个特征是单位膜的存在，这些膜由磷脂和相关蛋白质组成，在某些情况下还包括核酸。

植物细胞特有的特征中，最显眼且肯定研究最深入的是质体的存在。质体是具有内膜系统的膜结合细胞器。叶绿体和其他色素与内膜系统相关。参见[CELL (BIOLOGY)（细胞（生物学））](https://example.org/cell_biology)；[CELL PLASTIDS（细胞质体）](https://example.org/cell_plastids)；[CHLOROPLAST（叶绿体）](https://example.org/chloroplast)。[W.G.W]

## 植物通讯

信号或线索（可能是化学性的）在单个植物或植物部分之间的移动。这些化学线索是植物组织受损的结果，并刺激未受损的“接收”植物或组织发生生理变化。关于这一现象的研究非常少，因此关于其作用和意义理论相当推测性。

植物产生大量不参与植物主要或初级代谢（包括光合作用、营养获取和生长）的次级代谢产物。由于这些化学物质中的许多对动物或病原体具有非常特定的负面影响，生态学家推测它们可能是植物作为防御手段产生的。植物化学防御可能是始终存在的（组成性的），也可能是响应攻击而诱导的。响应病原体攻击产生的称为植物脱毒剂（phytoalexins）。为了证明诱导防御的存在，必须比较实际或模拟攻击前后植物组织化学或其对某些“敌人”（通过生物测定）的适宜性。当附近实验植物受损时，对照组或未受攻击植物在化学和适宜性上发现的变化，意味着某些信号或线索已从受损植物传递到未受损植物。受控研究表明，未受损植物的反应与受损邻居的邻近程度有关。参见[ALLELOPATHY（化感作用）](https://example.org/allelopathy)；[PHYTOALEXIN（植物脱毒剂）](https://example.org/phytoalexin)；[PLANT METABOLISM（植物代谢）](https://example.org/plant_metabolism)。[J.C.S.]

## 植物进化

植物界内部生物和有机变化的过程，使植物特征在世代间有所不同。从现存植物之间的比较中，进化的主要水平早已清晰，但化石记录在确定进化事件日期以及揭示现代类群之间灭绝的中间形式方面至关重要，这些现代类群彼此之间存在巨大的形态差异。支系系统学方法已阐明了植物进化，用于估计现存和化石类群之间的亲缘关系。这些方法试图通过共享的进化创新（例如，存在于其他类群中未发现的结构的出现）作为证据，来重建进化谱系（系统发育）的分叉，证明特定生物是同一祖先谱系（单系群或支系）的后代。许多传统类群实际上是进化等级而非支系；这些在下文用引号标注的名称表示。大多数植物学家将“植物”一词限定为陆地植物，它们在地球历史的90%之后入侵陆地。极有可能的是，植物起源可追溯到前寒武纪晚期。
