
8:   done

9:   echo

10:

11:  exit

```
该脚本的结果是：

```
# ./test.sh

Counting from 1 to 5

#
```

当然，你可以像列表 22.15 所示，非常简单地模拟 C 的 `for` 循环机制。

### 列表 22.15 使用类 C 构造的简单 for 循环示例（位于光盘的 `/source/ch22/forloop.sh`）
```

4:   do

5:   echo -n $var

6:   done

7:   echo

8:

9:   exit

```
### 列表 22.17 使用通配符替换列出系统上的用户子目录（位于光盘的 `./source/ch22/forloop4.sh`）
```
