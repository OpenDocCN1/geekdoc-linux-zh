
# 红碧母

红碧母是电气武石矿物的红紫色品种。在电气武石出现的多种颜色中，它是最受追求的。它是由于钛的存在引起的红色。它在矿物硬度标上为7-7。

# 红质红宝石

红质红宝石由于含有少量的氧化铬而高度透明。铬元素允许红宝石被用于产生红光的激光。参见刚晶（`CORUNDUM`）、激光（`LASER`）、蓝宝石（`SAPPHIRE`）。

## 钌

一种化学元素，原子序数44。是一种低密度的脆灰白色金属，通常与其他铂族金属共生。钌以稳定同位素的形式存在，并有十个天然放射性（同位素）不稳定状态。其中最主要的四个放射性大到仅在高温下才有危险。它可以使用电弧或电子束熔炼。参见：同位素（`ISOTOPES`）；金属的（`METALLIC`）；周期表（`PERIODIC TABLE`）；铂族（`PLATINUM GROUP`）。

该金属在室温下不被空气氧化但在900°C（1652°F）时产生氧化层（`RuO2`）表面层；在1600°C（2932°F）时溶解形成四氧化物（`RuO4`）化合物，它是挥发性的，其升华会导致金属损失。钌金属不溶于酸和王水，但程度有限。钌的性质见表。

钌相对稀有，在地壳中的自然丰度约为每百万0.0004部分。它存在许多其他金属矿石中，该元素的主要来源是锼和铱的天然合金。该元素也存在于其他铂族金属中；然而，需要用王水（含有钌、锼、铱和钠）处理将其分离出来。

**钌**一种化学元素，符号为`Rf`，原子序数104。钌是锕系元素之后第七周期的第一个元素。1964年，杜布纳和伯克利大学的`C. D. Ghior`及其同事发现了该元素。该元素的首次鉴定是1969年在加利福尼亚大学的劳伦斯辐射实验室完成的。

制备出的钌的性质尚未确定。

在伯克利发现该元素多年后，奥橡克国家实验室的一个小组发现了“`Rf`”的特征X射线线并确认了该元素。参见：惰性气体（`NOBLE GAS`）；元素（`ELEMENTS`）。

## 金钛石

三种钛矿物中最常见的一种；`TiO2`是唯一的两种多形体，是无水的。

该矿物出现在火成岩和变质岩中，通常以晶体形式重复。颜色为深红色、红褐色、黄色或白色。其莫氏硬度介于4.2到6.5之间。熔点为1835°C（3335°F）。

金钛石作为许多岩石（从火成岩到变质岩）的副矿物出现，并由于其抗风化性出现在沉积物和岩石中。某些花岗岩中发现了大型晶体；它也出现在透明石英中（条纹金钛石）。数量足够时，它被用钛矿。参见：钛（`TITANIUM`）。

钌原子包含单个在远离其他电子的原子核外运行的电子。这样的原子与氢原子相似，但处于与正电荷核心相互作用的状态。早期对钌化合物中此类原子的观测显示，其结果符合可见光中的莱德堡系。通过随后的微波辐射观测到能级之间的电跃迁。由于钌中的电子跃迁观察到谱线，正如在氢中观察到的，以及源于核某些低密度区域（`HI`）的发射。

## S

**伶貂（Sable）** 一种鼬科食肉目动物，分布于亚洲北部，从乌拉尔山到日本；它是一种珍贵的皮草动物，与北极火貂非常相似。伶貂通过捕食鸟类和小型动物获取食物。它非常适应这些活动，拥有纤细灵活的身体和四肢，每只脚短，末端有弯曲的爪。长而蓬松的尾巴是平衡器官。交配发生在夏季，产下四至六只后代。*食肉目，火貂。*

**裸舌亚目（Sacoglossa）** 蛞类；有时也称为须舌亚目。它们存在于所有海洋的浅水区，在热带海达到最大的体型和多样性。这个丰富目的成员具有两个共同特征：草食习性（除 `Olea` 属和 *Stiliger* 属物种外）以及拥有单齿舌（在软体动物中），这种舌经常折断，并留在身体内，不丢弃。

**糖精（Saccharin）** `o-`磺基苯甲酰胺的钠盐，由从甲苯或邻二甲酸开始的工艺制造。游离酰胺称为糖精因为它不溶于水，在药物中用作味剂。钠盐和钙盐易溶于水，被广泛用作甜味剂。

糖精比糖（蔗糖）甜的 300-500 倍。它们用于改善药物和牙膏的味道，并作为膳食食品和饮料中的非营养甜味剂。使用热量糖精代替糖，可以为热量限制饮食制定低热量产品，并为糖尿病患者制定低糖产品。参见*甜味剂，K.M.B.**
