# who：系统上的列表

# finger：用户列表

`finger` 命令显示登录到本地系统的用户列表。`finger` 提供了每个用户全名、用户登录的终端、以及用户登录的时间。系统连接到网络，你可以使用 `finger` 命令获取每个用户的详细信息。用户名字前的星号（*）表示该用户已登录（第 185 页）。
