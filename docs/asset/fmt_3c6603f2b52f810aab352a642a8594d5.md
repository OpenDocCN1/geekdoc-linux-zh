## 比较文本

比较文本版本通常非常有用。对于系统管理员和软件开发人员来说，这为重要。例如，系统可能需要将现有配置文件与之前的版本进行比较以诊断系统问题。同样，程序员需要查看程序随时间的变化。

### 按行比较两个排序的文件

该程序比较两个文本文件并显示每个文件特有的行以及共同行。为了演示，我们将使用 `cat` 创建两个相同的文本文件。

```
[me@linuxbox ~$ cat > file1.txt
a
b
c
d
[me@linuxbox ~$ cat > file2.txt
b
c
d
```

接下来，我们将使用 `comm` 比较这两个文件。

```
[me@linuxbox ~$ comm file1.txt file2.txt
a
b
c
d
```

如所示，`comm` 输出三列输出。第一列包含第一个文件特有的行，第三列包含两个文件共有的行。`comm` 支持 `-n` 形式的选项，其中 `n` 为 1、2 或 3。使用时，这些选项指定了要抑制的列。例如，如果我们只想输出两个文件共有的行，我们就会抑制第一列和第二列的输出。

```
[me@linuxbox ~$ comm -12 file1.txt file2.txt
b
c
d
```

## diff—按行比较文件

与 `comm` 命令类似，`diff` 用于检测文件之间的差异。然而，`diff` 是一个复杂得多的工具，支持许多输出格式，并能够一次处理大量文件。软件开发人员经常使用 `diff` 来检查程序源代码版本之间的更改，因此它具有递归检查源代码（通常称为源码树）差异的能力。`diff` 的一个常见用途是创建 diff 文件或补丁（patches），这些文件可用于 `patch` 命令（我们稍后会讨论）等程序将一个文件版本转换为另一个版本。

如果我们对之前的示例文件使用 `diff`：

```
me@linuxbox ~]$ diff file1.txt file2.txt
d1o
<a>
4a
> e
```

我们看到了它的默认输出样式：两个文件之间差异的描述。在默认格式中，每组更改之前都有一个范围操作形式的更改命令，用于描述将第一个文件转换为第二个文件所需的更改的位置和类型，如表 20-4 所示。

表 20-4：diff 更改命令

| 更改 | 描述 |

|---|---|

| r1a r2 | 将第二个文件中位置 r2 处的行追加到第一个文件的位置 r1 处。 |

| r1cr2 | 将替换第一个文件中位置 r1 处的行变为第二个文件中位置 r2 处的行。 |

| r1dr2 | 删除第一个文件中位置 r1 处的行，这些行本应出现在第二个文件的范围 r2 中 |

在这种格式中，范围是一个由逗号分隔的起始行号和结束行号列表。虽然这是默认格式（主要是为了符合 POSIX 标准并与传统 Unix 版本的 `diff` 保持向后兼容），但它并没有作为主要或可选格式被广泛使用。最流行的两种格式是上下文格式（context format）和统一格式（unified format）。

当使用上下文格式（-c 选项）查看时，我们将看到以下内容：

```
me@linuxbox ~]$ diff -c file1.txt file2.txt
*** file1.txt 2008-12-23 06:40:13.000000000-0500
--- file2.txt 2008-12-23 06:40:34.000000000-0500
*** 1,4 ****
- a
- b
c
d
--- 1,4 ---
b
c
d
+ e
```

输出以两个文件的名称及其时间戳开头。第一个文件用星号（*）标记，第二个文件用连字符（-）标记。在后续列表中，这些标记代表各自的文件。接下来，我们看到一组组更改，包括默认数量的周围上下文行。在第一组中，我们看到：

*** 1,4 ***

这表示第一个文件的第 1 到 4 行。稍后我们看到：

--- 1,4 ---

这表示第二个文件的第 1 到 4 行。在一个更改组内，行以表 20-5 描述的四种指示符之一开头。

### 表 20-5：diff 上文格式更改指示符

| 指示符 | 含义 |

|---|---|

| 空格 | 用于上下文的行。它不表示两个文件之间的差异。 |

| - | 被删除的行。该行将出现在第一个文件中，但不会出现在第二个文件中。 |

| + | 被添加的行。该行将出现在第二个文件中，但不会出现在第一个文件中。 |

| ! | 更改的行。该行的两个版本将分别显示在更改组的相应部分中。 |

统一格式与上下文格式类似，但更简洁。它通过 -u 选项指定。

```
$me@linux~$]$ diff -u file1.txt file2.txt
--- file1.txt 2008-12-23 06:40:13.000000000 -0500
+++ file2.txt 2008-12-23 06:40:34.000000000 -0500
@@ -1,4 +1,4 @@
-a
b
c
d
+e
```

上下文格式和统一格式之间最显著的区别是消除了重复的上下文行，使得统一格式的结果比上下文格式更短。在我们之前的示例中，我们看到了类似于上下文格式的文件时间戳，随后是字符串 `@@ -1,4 +1,4 @@`。这表示第一个文件中的行和第二个文件中的行。之后是行本身，以及默认的上下文行。每行都以表 20-6 描述的三个字符之一开头。

### 表 20-6：diff 统一格式指示符

| 字符 | 含义 |

|---|---|

| 空格 | 空白行。 |

| - | 被移除的行。 |

| + | 被添加的行。 |
