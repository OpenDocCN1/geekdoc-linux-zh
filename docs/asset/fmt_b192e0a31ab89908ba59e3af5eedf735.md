### 数据集

我们现在不会涵盖 C++ 中的 STL。它超出了本文阅读的范围。因为我们不涵盖 STL，所以我们不会讨论`vector`（向量）以及你如何在 C++ 中使用它们。如果你对学习 C++ `vector`和`set`（集合）的工作原理感兴趣，我建议你去 Google搜索；在许多 C++ 程序中，考虑到最初使用 C++ 的原因，尝试用`vector`处理这类事情通常是违反直觉的，因为与分配的内存集合相比，它们占据了过多的内存空间。然而，它们也比数组更容易处理一点。这在很大程度上取决于情况，但很有可能，如果你正在创建一个使用`vector`合合理的程序，那么这种程序可能使用完全的另一种语言才更合理。

在本节中，我们将不涵盖`vector`，而是涵盖数组（arrays）。数组是 C++ 中存储数据的主要方法。它们具有高度扩展性，可以存储许多相互相关的数据。我们稍后会在这里讨论一下实际概念。尽管如此，关于需要知道的关键点是，它们实际上分配了内存空间——仅足够存放数组中列出的所有元素。然后数组被分为单独的空间，这就是我所指的元素。这些元素从零开始计数。如果我们有一个 10 空间的数组，它将组织如下：

这些槽可以接受创建数组时指定的类型的值。当你引用这些位置之一时，数组将处理内存中的该位置并修改对应的值。（这是数组的优点之一）

然而，在此之外，它们具有原始实用性。那个基于指针的函数在你开始处理指针之前可能是不需要的，直到你开始处理 C++ 函数和函数声明。无论如何，在你开始处理指针之前，你可能需要某些来建立这些数组。创建一个空外壳，我们需要这些值来填充数组。填充数组最简单的方法是通过赋值来初始化它：

### 循环

C++ 中的循环相对直观。你只需要了解两种循环。

C++ 中的`while`循环工作方式与 Bash 类似。只要语句 true结果为`true`，它就会一直执行。

以下是在 C++ 中从 1 计数到 10 的方法：`int i = 1;`

```cpp
while (i <= 10) {
cout << i << "\n"; i++;
}
```

同时，`for`循环的工作方式与 Python 或 Bash 都不同。C++ 中的`for`循环仍然用于迭代，但它们的逻辑路径更清晰，并且并不专门用于遍历不同的列表。

你可以这样理解 C++ 中的`for`循环：

```cpp
for (iterator variable; continuation condition; iteration step) {
// 代码写在大括号内部
}
```

如果我们想用数组从 1 计数到 10，可以这样做：

```cpp
for (int i = 0; i <= 10; i++) {
cout << i << "\n";
}
```

每当循环完成，迭代步就会改变迭代变量`i++`或`i = i + 1`，表示数值增加。

### Note

Python 循环实际上非常简单。`while`循环的功能与其在 C++ 中的对应版本几乎相同，只是使用了 Python 风格的语法。以下是使用`while`循环从 1 计数到 10：

```python
i = 1
while i <= 10:
    print i += 1
```

注意，Python 中不存在自增 1 和自减 1 的运算符。使用`+=`或`-=`会更有帮助。

同时，`for`循环则相对不同。它们都用于迭代某些内容。然而，Python 中的迭代目的要清晰得多。在 Python 中使用`for`循环，你必须有一个列表供其遍历。Python `for`循环的语法如下：

```python
for iterator in list:
    do something
```

不过，如果你想创建一个从 1 到 10 的范围，是可以实现的。Python 中有一个`range`方法，它会返回两个起始点之间的元素列表（如果不指定起始点，则从 0 开始）。以下是使用`for`循环从 1 计数到 10 的方法：

```python
for i in range(1,10):
    print i
```

迭代变量旨在整个循环过程中代表列表中的每个对象（无论其类型如何），并承担列表中当前对象的属性。这意味着如果你有一个单词列表，如下所示：`sentence = ["I", "like", "cats"]`，那么你可以一次一行地打印每个单词：

```python
for a word in sentence:
    print word
```
