
# VSCodium 安装指南

通过 Snap Store 安装 Snap 包：
- 在 Snap Store 中查找 `VSCodium`。
- 点击 `VSCodium`，进入源选择框。
- 选择 Snap 下的最新/稳定版本并点击安装。

通过 Snap 安装 `VSCodium`：
输入此命令：

```
sudo snap install codium --classic
```

通过 Flatpak 安装 `VSCodium`：
输入此命令：

```
flatpak install flathub com.vscodium.codium
```

通过 GUI 安装 `.deb` 版 `VSCodium`：
访问发布页面：

`https://github.com/VSCodium/codium/releases`

- 点击 `.deb` 下载 `VSCodium`
- 进入 `~/` 文件夹
- 双击 `codium_1.86.2-1707854558_amd64.deb`
- 点击安装

# Atom 安装指南

访问 `Atom` 官方网站 `https://atom-editor.cc/` 获取所有相关信息。

通过软件包管理器安装 DEB/Flatpak 包：
- 打开软件包管理器搜索 `Atom`。
- 点击 `Atom`，进入源选择框。
- 选择系统包或 Flatpak 并点击安装。

通过 APT 仓库安装 `Atom`：
输入以下命令：

```
sudo apt update
```

```
sudo apt install software-properties-common apt-transport-https wget
wget -qO- https://packagecloud.com/AtomEditor/atom/gpgkey -O- | sudo apt-key add --
add-apt-repository "deb [arch=amd64] https://packagecloud.com/AtomEditor/atom/ main"
```

```
sudo apt update
```

```
sudo apt install atom
```

通过 Snap Store 安装 Snap 包：
- 在 Snap Store 中查找 `Atom`。
- 点击 `Atom`，进入源选择框。
- 选择 Snap 下的最新/稳定版本并点击安装。

通过 Flatpak 安装 `Atom`：
输入此命令：

```
flatpak install flathub io.atom.Atom
```

通过 GUI 安装 `.deb` 版 `Atom`：
访问发布页面：

`https://github.com/atom/atom/releases/tag/v1.60.0`

- 点击 `atom-amd64.deb` 下载 `Atom`
- 进入 `~/` 文件夹
- 双击 `atom-amd64.deb`
- 点击安装

# 直播软件

在线直播软件允许您通过捕获和编码来自摄像头、麦克风或屏幕的内容，在线直播视频和音频。与将文件保存到设备上的下载不同，流媒体使用数据包进行流畅播放，而不进行本地存储即可实时播放媒体。这种方法节省了空间，并允许即时访问视频和音乐，成为享受在线娱乐和实时分享时刻的首选方案。

`OBS Studio` 是一款免费的开源软件，适用于 `Windows` 和 `macOS` 等主要平台进行直播和录屏录制。它支持多种视频编码方法，并与 `YouTube` 和 `Twitch` 等平台集成。用户可以混合音频、无缝切换场景并自定义过渡效果。其界面可根据用户偏好进行调整，包括多场景画布、音频混音器和便于配置的简化设置。`OBS` 还提供插件支持和脚本集成以增强功能，满足了追求专业级制作的初学者和高级用户。

`Owncast` 是一个自托管、可自定义的直播和聊天平台，被描述为“箱中的 `Twitch`”。它允许对您的内容和社区进行完全控制，并支持与流行的广播软件集成。`Owncast` 具有内置聊天功能以增强观众互动、自定义表情和聊天机器人。它专为寻求独立于大型平台的直播主播设计，提供无跟踪的体验。它兼容 `Linux` 和 `macOS` 服务器，只需最少设置即可开始直播。`Owncast` 还连接到联邦宇宙（Fediverse），扩大了受众范围。对于那些希望在不受主流服务限制的情况下进行自定义、无广告直播的人来说是理想选择。

## OBS Studio

访问 `OBS Studio` 官方网站 `https://obsproject.com/` 了解关于 `OBS Studio` 的一切信息。

通过软件管理器安装 DEB/FLATPAK 软件包：
- 打开软件管理器并搜索 `OBS Studio`。
- 点击 `OBS Studio`，然后点击“源选择框”。
- 选择“系统软件包”或“Flatpak”，然后点击“安装”。

在终端通过 APT 安装 `OBS Studio`：
只需输入以下命令：

```
sudo apt update
sudo apt install obs-studio
```

在终端通过 APT 仓库安装 `OBS Studio`：
只需输入以下命令：

```
sudo apt update
sudo add-apt-repository ppa:obsproject/obs-studio
sudo apt update
sudo apt install obs-studio
```

通过 Snap Store 安装 Snap 软件包：
- 在 Snap Store 中查找 `OBS Studio`。
- 点击 `OBS Studio`，然后点击“源选择框”。
- 在 Snap 下选择最新/稳定版本并点击“安装”。

在终端通过 Snap 安装 `OBS Studio`：
输入此命令：

```
sudo snap install obs-studio
```

在终端通过 Flatpak 安装 `OBS Studio`：
输入此命令：

```
flatpak install flathub com.obsproject.Studio
```
