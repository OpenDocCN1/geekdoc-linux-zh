
## `/etc/pcmcia`
此目录包含了个人内存卡国际协会（PCMCIA）操作所需配置和启动文件。除非你使用的是笔记本电脑，否则你可能不需要这些。

## `/etc/ppp`
关于点对点协议（PPP）文件用于互联网流量。你的防火墙掩码和独立配置文件也位于此处。

# 理解 Linux 文件系统布局

### `/etc/profile.d`
此目录包含系统 shell 的其他配置信息。你的 `ls` 命令的颜色创建以及 `ll` 的别名也存储在这里。语言文件和 `less` 配置可以在 `lang*` 和 `less*` 文件中找到。

### `/etc/rc.d`
我们在本章早期已经介绍过此目录下的文件。总结来说，这些文件在 Linux 初始启动期间使用，用于设置系统和基本命令。如果你想获取有关这些文件的更多信息，请参见早前的章节“rc 脚本及其 Kill 和启动文件”。

### `/etc/rpm`
在本章早些时候，你使用 `rpm` 安装了 `pipe`，其中包含 `pico`。`rpm` 的配置文件在此目录中。该目录包含的文件相对较少。`marco` 文件包含 `rpm` 内部使用的预构建命令，而 `platform` 文件包含了一行指定你系统类型的单行内容。

### `/etc/security`
`/etc/security` 目录下的文件为指定的用户或组设置权限，以授予访问和限制。我们将在第 6 章“Linux 安全”中更详细地讨论此文件。

### `/etc/ssh`
`/etc/ssh` 目录包含 Secure Shell 登录程序的配置和密钥。当你远程访问服务器传输加密信息时，使用密钥系统来确保安全。我们将在接下来的章节更详细地讨论密钥和 `ssh`。修改 `ssh_config` 文件将更改通过 `ssh` 系统的所有用户的设置。

### `/etc/sysconfig`
切换到此目录并获取目录列表将为你提供许多配置系统所需的文件。你可以读取 `/usr/share/doc/initscripts-x.xx/sysconfig.txt` 获取所有选项的完整列表。`x.xx` 是 Linux 内核版本。以下是该目录包含的一些主要配置文件以及每个文件中可用的一些选项：

#### `/etc/sysconfig/authconfig`
用于 `authconfig` 存储系统用户信息和身份验证设置的信息；对此文件进行的更改在下次运行 `authconfig` 之前将不会生效

```
USEHID=no
是否正在使用 hesid 命名服务。
如果未设置，authconfig 将检查
/etc/nsswitch.conf 中的 passwd 设置。
LDAP=no
是否将 LDAP 作为命名服务使用。如果
未设置，authconfig 将检查
/etc/nsswitch.conf 中的 passwd 设置。
```

`USENIS=no`

是否正在使用 NIS。如果未设置，`authconfig` 将检查 `/etc/nsswitch.conf` 中的 `passwd` 设置。

`USEKEERBEROS=no`

是否正在使用 Kerberos。如果未设置，`authconfig` 将检查 `/etc/pam.d/system-auth` 中的设置。

`USELDAPAUTH=no`

是否正在使用 LDAP 进行身份验证。如果未设置，`authconfig` 将检查 `/etc/pam.d/system-auth` 中的设置。注意此选项与 `USELDAP` 是独立的，且两者都不蕴含另一个。

`USEMDS=no`

在设置密码时是否应使用基于 MDS 的哈希。如果未设置，`authconfig` 将检查 `/etc/pam.d/system-auth` 中的设置。此选项影响使用本地文件和 LDAP 的身份验证。

`USHESHADOW=no`

是否正在使用 shadow 密码。如果未设置，`authconfig` 将检查 `/etc/shadow` 是否存在。

`USEMBUTH=no`

是否正在使用 SMB 认证。如果未设置，`authconfig` 将检查 `/etc/pam.d/system-auth` 中的设置。

#### `/etc/sysconfig/clock`
来自早期版本的弃用值：

`CLOCKMODE=GMT`

表示时钟设置为 UTC

`CLOCKMODE=ARC`

仅在 alpha 上表示 ARC 控制台的 42 年时间偏移当前生效。当前正确值是：

`UTC=true,yes`

表示硬件时钟设置为 UTC。

`UTC=no,false`

表示硬件时钟设置为本地时间（Local Time）。

未设置 `UTC` 将默认使用上次使用的值（如果记录在 `adjtime` 文件中），或者如果不存在 `adjtime` 文件，则使用本地时间。

`ARC=true`

仅在 alpha 上表示 ARC 控制台的 42 年时间偏移生效；否则假设使用标准的 Unix 纪元（epoch）。

`SRM=true`

仅在 alpha 上表示 SRM 1900 纪元生效；否则假设使用标准的 Unix 纪元。

`ZONE="*filename*"`

表示 `/usr/share/zoneinfo` 下的 `zonefile`，`/etc/localtime` 是该文件的副本，例如：

`ZONE="US/Eastern"`

#### `/etc/sysconfig/desktop`
`DESKTOP=GNOME|KDE|AnotherLevel`

这决定了新用户的默认桌面。

`DISPLAYMANAGER=GNOME|KDE|XDM`

这决定了由 `/etc/X11/prefdm` 启动的显示管理器，独立于桌面环境。

#### `/etc/sysconfig/init`
`BOOTUP=<some boot mode>`

`BOOTUP=graphical`

意味着 X Windows 图形启动

`BOOTUP=color`

意味着彩色文本模式显示。

`BOOTUP=verbose`

意味着旧式显示。其他任何内容都意味着简化显示，但没有颜色或 ANSI-格式

`LOGLEVEL=<ca number>`

设置内核的初始日志级别。默认值为 7。8 表示一切（包括调试）；1 表示除内核 panic 之外的一无所有。`syslog` 在其启动之前将覆盖此设置。

`LOGLEVEL=<ca number>`

设置日志级别。

`MOVE_TO_COL=<ca number>`

将光标移动到指定的列。

`RES_COL=<ca number>`

```
SETCOLOR_SUCCESS=no
是否使用了成功颜色。
如果未设置，authconfig 将光标设置为
绿色。
SETCOLOR_FAILURE=no
是否使用了失败颜色。
如果未设置，authconfig 将光标设置为
红色。
SETCOLOR_WARNING=no
是否使用了警告颜色。
如果未设置，authconfig 将光标设置为
黄色。
SETCOLOR_NORMAL=no
是否使用了普通颜色。
如果未设置，authconfig 将光标设置为
普通。
```

#### `/etc/sysconfig/keyboard`
```
KEYTABLE=<table>
例如：KEYTABLE="usr/lib/keytables/us"
如果导出键映射（使用 'dump'），将在启动时加载。
KEYBOARDTYPE=sun
在 SPARC 上表示连接了 sun 键盘
在 /dev/kbd 表示 PS/2 端口。
```

#### `/etc/sysconfig/mouse`
```
MOUSETYPE=microsoft|mouseman|atbm|logitech|immseries
XEMU3=yes|no
在必要时模拟三个按钮（特别是在 X 中）
DEVICE=<ca device>
（鼠标设备）
```

#### `/etc/sysconfig/network`
`NETWORKING=yes|no`

`HOSTNAME=<默认情况的完全限定域名主机名>`

`GATEWAY=<网关 IP>`

`GATEWAYDEV=<网关设备>`

（例如 `eth0`）

`NISDOMAIN=<nis 域名名>`

`VLAN=yes|no`

`IPX=yes|no`

`IPXAUTOPRIMARY=on|off`

（注意必须是 `on|off`，而不是 `yes|no`）

`IPXAUTFRAME=on|off` （再次，不是 `yes|no`）

`IPXINTERNALNETNUM=<网络号>`

`IPINTERNALNODENUM=<节点>`

所有 IPX 内容都是可选的，并且默认为关闭。

`NETWORKING_IPV6=yes|no`

启用或禁用全局 IPv6 初始化默认：`no`

`IPV6FORWARDING=yes|no`

启用或禁用所有接口的全局 IPv6 包转发。注意：实际的数据包转发无法按设备控制，请使用 `netfilter6` 处理此类问题默认：`no`

`IPV6INIT=yes|no`

谨慎启用或禁用所有接口的 IPv6 配置！默认：在此文件中未设置

`IPV6_AUTCONF=yes|no`

设置基于设备的自动配置的默认值。默认：如果 `IP6_FORWARDING=yes`，否则否

`IPV6_ROUTER=yes|no`

设置基于设备的主机/路由器行为的默认值。默认：如果 `IP6_FORWARDING=yes`，否则否

`IPV6_AUTOTNEL=yes|no`
