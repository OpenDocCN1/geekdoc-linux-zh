# 脚本、工具和其他文件

上述列表中的 `//IDG` 目录包含了我添加到 CD-ROM 中的文件——即除了你在标准 Red Hat 发行版中找到的文件之外的文件。以下简要概述：

- `user_aliases`

该文件在第 6 章的侧边栏“解释 Bourne Again Shell 别名”中描述。我个人认为这些别名很有用。要设置这些别名，请输入命令：

```
source user_aliases
```
