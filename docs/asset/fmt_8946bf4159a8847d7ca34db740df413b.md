# rootkit (根内核工具包)

在 UNIX 机器被成功攻破后放置的一套无神论工具的名称。一个典型的 `rootkit` 包括：系统常用程序（如 `inetd`）的密码嗅探器替换二进制文件，如 `ls` 这样的后门程序，以便它们不会暴露 `rootkit` 文件的存在。关键点：`rootkit` 包含许多木马。这些程序被用于允许黑客重新进入系统并隐藏黑客的行踪。对于木马，`ps` 命令可能会隐藏进程列表中的黑客的守护进程（daemon）。或者，黑客可能会劫持现有的守护进程 `inetd` 来运行后台进程。关键点：最重要的木马是那些用于以特定特权集访问系统的工具。例如，守护进程或运行所需的 root。Rootkits 包含了普通用户可以使用以提升其权限的特权木马。查看此项以检查你的系统是否被黑客入侵。文化：也称为 "root kits"。例如：“f0n”工具包，包括如 "0mfind" 等实用程序并替换了它们。2000 年，`rootkit` 曾是多个 Linux 节点的一部分。源自 Hacking-Linux

# rot13
