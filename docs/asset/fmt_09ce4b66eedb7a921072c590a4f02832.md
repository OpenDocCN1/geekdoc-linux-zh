你可以依靠《Linux 系统管理》获取关于安装、配置和管理 `Linux` 的答案。本书由两位 `Linux` 专家编写，教授你设置维护成功的 `Linux` 环境所需的标准和高级技术。涵盖：

- 安装 `Linux` 服务器
- 使用新命令和功能
- 设置用户和组帐户
- 添加和删除软件
- 使用 `Red Hat` 包管理器验证
- 使用 `Samba` 和 `NFS` 共享文件
- 实施备份策略
