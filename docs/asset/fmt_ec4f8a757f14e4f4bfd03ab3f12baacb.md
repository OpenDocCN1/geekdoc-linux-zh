# 消旋化

从纯对映异构体形成外消旋体的过程。或者，消旋化是将一种对映异构体转化为两种对映异构体（+ 和 −，或 R 和 S）的 50:50 混合物的过程。消旋化通常与光学活性随时间推移而消失有关，因为对映异构体的 50:50 混合物是光学非活性的。参见 光学活性。

消旋化是一个能量上有利的过程，因为它反映了从更有序的状态到更随机状态的变化。但是，除非有合适的机理途径可用，对映异构体消旋化的速率通常相当慢，因为消旋化通常（但并不总是）要求断开对映异构体手性中心处的化学键。具有多个手性中心的对映异构体的消旋化要求一半分子的所有手性中心都翻转其构型。参见 对映异构体。

对消旋化的观察和研究对于理解化学反应机理以及手性天然产物（如多肽）的合成和分析具有重要的意义。此外，消旋化具有经济重要性，因为它提供了一种将不需要的对映异构体转化为有用对映异构体的方法。合成药物通常以非晶态（racemates）形式在工业上生产。在没有消旋化不需要的异构体并循环使用产生的非晶态体的可能性的情况下，在分离和隔离所需的对映异构体后，将不得不丢弃一半产品。 [S.H.W]

# 雷达

无线电探测与测距（Radio Detection And Ranging）的缩写，这是雷达最初的也是仍然主要的应用。这个名字既适用于该技术，也适用于所使用的设备。

雷达是一种传感器；其目的是为用户提供其周围环境某些特性的估计，通常是其附近飞机、船舶或其他车辆等物体的存在、位置和运动。在其他用途中，雷达提供关于地球表面（或其他天体表面）或气象条件的信息。为了向用户提供完整的传感器能力，雷达通常与其他更完整系统要素结合使用。

雷达通过向周围环境发射电磁能量并检测由物体反射的能量来工作。如果通过定向天线发射窄束能量，则可以估计反射来源的方向，从而估计物体的方位。通过测量雷达脉冲发射和回波接收之间的周期，来估计到反射物体的距离。在大多数雷达应用中，这个周期将非常短，因为电磁能量以光速传播。

## 雷达的类型

雷达的物理特性差异很大。有一些雷达可供小型船只作为安全和导航辅助使用，有些小到可以由操作员携带。另一种手持式雷达是警方用于测量汽车速度的雷达。参见 航海。

也许最大的雷达是覆盖数英亩土地的那些，所有长的天线阵列协同工作，以监测航天器或天体的飞行。其他非常大的雷达旨在监测相当距离内的飞行活动。这些之所以很大，主要是因为它们必须使用比通常更长的无线电波长，这与电离层对信号的包含有关，用于视距外操作。

更常见尺寸的是在机场看到的雷达，带有 20–40 英尺（6–12 米）宽的旋转天线。 intended for 移动使用的雷达，特别是机载雷达，相当紧凑。参见 机载雷达。

# 雷达

机载和星载雷达已通过特殊的多普勒敏感处理技术得到发展，当雷达移动相当一段距离时，它们能以极高的分辨率执行地面测绘。这类雷达被称为合成孔径雷达（SAR），因为在处理进行时，其覆盖路径形成了非常大的虚拟天线。干涉测量可提供地形信息（3D SAR），极化和其他信号分析可提供关于地表性质的更多信息（例如植被类型）。参见 [REMOTE SENSING]（遥感）；[SYNTHETIC APERTURE RADAR (SAR)]（合成孔径雷达）。

主要用于确定雷达下方区域内反射目标的存在和位置的雷达被称为搜索雷达。其他雷达会对检测到的目标进行更深入的考察：例如，垂直扫描天线可对准指定目标测高的高度测量仪，以及持续对准指定目标以获得高精度目标运动估计的跟踪雷达。在一些现代雷达中，这些搜索和跟踪功能通常与某种计算机控制相结合。监控雷达暗示了这种类型的操作，比单纯的搜索功能稍多。还有一些非常复杂和多功能的雷达，配有大量的计算机控制，执行许多功能，因此被称为多功能雷达。专为导弹测试场或类似试验场使用的高精度跟踪雷达被称为测量雷达。设计用于探测云层和降水的雷达被称为气象雷达或天气雷达。参见 [PASSIVE RADAR]（无源雷达）。

一些雷达拥有独立的发射天线和接收天线，有时这两者相距数英里。这些被称为双基地雷达，而更传统的单天线雷达被称为单基地雷达。一些有用的系统根本没有发射器，并配备有设备以雷达目的测量来自目标本身的信号。这类系统通常被称为无源雷达，但术语辐射计或信号截获系统通常更为合适。参见 [PASSIVE RADAR]（无源雷达）。

主要和次要这两个术语分别用于描述接收到的信号由目标反射的雷达，以及发射导致搭载在目标上的应答机（发射-应答机）向雷达传回信号的雷达。参见 [AIR-TRAFFIC CONTROL]（空中交通管制）；[ELECTRONIC NAVIGATION SYSTEMS]（电子导航系统）。

**工作原理。** 将雷达视为由四个主要部分组成是方便的：发射器、天线、接收机和显示器（见插图）。

发射器提供具有足够强度（功率）的射频信号，以满足所需的雷达灵敏度，并将其发送到天线，天线使信号沿所需方向辐射到空间中。该信号在空间中传播（辐射），其中一部分被反射体拦截。这些反射（至少部分）被辐射回天线。天线收集它们并将所有此类接收信号路由到接收机，在那里它们被放大和检测。接收信号中出现发射信号的回波揭示了目标的存在。回波由检测器输出的突然上升指示，该输出产生一个电压（视频），其值与正在接收的射频信号之和及接收机内部固有的射频噪声成正比。发射和接收回波之间的时间揭示了到目标的距离。目标的方向或方位由接收到回波时天线的指向揭示。

环行器允许同一天线用于发射和接收，并配备保护设备，以阻止非常强的发射信号到达敏感的接收机并损坏它。天线形成波束，通常既是定向的，又在搜索示例中旋转遍历要搜索的区域。参见 [ANTENNA (ELECTROMAGNETISM)]（天线（电磁学））。

雷达反射是在两次传输之间天线接收的信号之一。大多数搜索雷达具有脉冲重复频率（PRF）、天线波束宽度和旋转速率，使得当天线扫描通过目标时，会发送多个脉冲（可能是 20 到 40 个）。这允许累积正在接收的回波。大多数雷达都配备了低噪声射频预放大器以提高灵敏度。然后，信号与本地振荡器信号“混频”（相乘），以产生方便的中频（i-f）信号，通常为 30 或 60 MHz。所有外差无线电接收机都使用相同的原则。本地振荡器信号由发射器振荡器在接收期间提供，其频率比发射频率精确偏移了此中频。在中频电路中的其他重要信号处理之后（在许多较新的雷达中具有数字性质），检测器产生视频信号，该电压与处理后的中频信号的强度成正比。此视频可应用于阴极射线管（CRT）显示器，从而形成成比例的亮点（堆积物），这可能被判断为源自目标回波。然而，越来越多的雷达使用基于视频计算机分析的人工类计算机显示器。自动检测和自动跟踪（基于一系列停留）是此类数据处理的典型特征；报告既为雷达操作员管理而显示，也立即提供给用户系统。参见 [CATHODE-RAY TUBE]（阴极射线管）；[ELECTRONIC DISPLAY]（电子显示）；[HETERODYNE PRINCIPLE]（外差原理）；[MIXER]（混频器）；[PREAMPLIFIER]（预放大器）；[RADIO RECEIVER]（无线电接收机）。

雷达载波频率通过一种起源于战时服务、后来被发现非常方便并被广泛接受的命名法进行广泛识别。频谱被划分为波段，其频率和波长在表中给出。电离层中带负电的层在略低于大多数雷达微波频率的无线电频率下呈现出高折射率壳层。因此，为了利用这种跳跃路径，已在 10 MHz 频段构建了超视距雷达。参见 [CONTINUOUS-WAVE RADAR]（连续波雷达）；[MONOPULSE RADAR]（单脉冲雷达）；[RADIO SPECTRUM ALLOCATIONS]（无线电频谱分配）。[R.T.H.]
