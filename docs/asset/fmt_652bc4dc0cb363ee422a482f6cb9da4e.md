
# Linux Mint 18：初学者指南

作者：William Rowley

## 引言

世界上绝大多数人已经转向使用 Linux 而不是常见的 Windows 操作系统。这是因为他们已经意识到 Linux 是多么强大，以及使用 Linux 可以成就很多目标。当被称为“Linux 极客”时，人们也会感到自豪。Linux 有多种发行版，每种发行版都是为了特定的领域而设计的。

Linux Mint 是可选的 Linux 发行版之一，基于 Ubuntu 和 Debian 开发。你可以使用这个 Linux 发行版完成许多任务。本书是一份关于如何使用 Linux Mint 的指南，并已更新至 Linux Mint 18.0。阅读愉快！

## 第 1 章 什么是 Linux Mint？

Linux Mint 是全球数百万用户使用的常用 Linux 发行版之一。该 Linux 发行版提供完整的多媒体支持，并且易于使用。它是开源的，这意味着用户可以下载它并对其进行一些定制以满足自己的需求。Linux Mint 的开发是社区驱动的，这意味着用户能够对其使用 Linux Mint 的体验提供反馈，以改进它。

Linux Mint 的开发基于 Ubuntu 和 Debian，并配备了最优秀的软件包（多达 30,000 个）以及最好的包管理器。Linux Mint 的第一个版本于 2006 年作为 Linux Mint 1.0 发布，这是一个测试版本。随后，发布了 Linux Mint 2.0，它使用 Ubuntu 作为代码库。

2010 年，发布了基于 Debian 的 Linux Mint 版本。这个版本的 Linux Mint 不受限于 Ubuntu 软件包。

## 第 2 章 Linux Mint 的安装

可以免费下载 Linux Mint 操作系统。它将以 ISO 文件的形式下载，你可以将其刻录到 DVD 中。LiveDVD 是启动的，并包含一个功能完整的操作系统，你可以在不更改电脑的情况下对其进行尝试。建议你先尝试 LiveDVD，如果你喜欢你看到的内容，再安装 Linux Mint。你可能需要的所有工具（包括分区工具）都将可用。

您可以选择“启动 Linux Mint”然后按下回车键。实时系统将启动，您将看到它的屏幕。几分钟后，实时系统将准备就绪，并显示桌面。

请注意，此时 Linux Mint 尚未安装到您的计算机上，它仅在从 DVD 运行。然而，一旦您将其安装到计算机上，它将与您现在从 DVD 运行的完全相同。此外，您应该知道，从 DVD 运行系统会比安装在电脑上慢。这背后的原因是数据必须从 DVD 读取，而不是从速度较快的硬盘中读取。

点击桌面上的“安装 Linux Mint”图标。安装程序随后将会出现。此外，多阅读一下发布说明也对您大有益，这样您就可以了解更多功能，以及如何处理可能出现的任何问题。

选择您需要的语言，然后点击“继续”。系统将显示一个询问您是否需要安装第三方软件的界面。这指的是那些并非完全开源但具有某些许可限制的软件。如果您需要使用这些软件，只需勾选该框然后点击“继续”。

在下一步下一步中，笔记本电脑用户应确保已连接到电源、互联网连接，并且有足够的磁盘空间。然后您可以点击“继续”。

## 第 3 章 - Linux Mint 桌面

桌面是操作系统的一部分，负责显示您在桌面上看到的元素。这些包括壁纸、面板、菜单、控制中心等。

### Cinnamon 桌面

Cinnamon Linux Mint 使用“Cinnamon”桌面，该桌面非常强大且直观。

### 桌面设置

桌面是一个允许您更改您主要使用的 Cinnamon 桌面的菜单。

要启动它，点击屏幕左下角的“菜单”，选择“系统设置”，然后点击“桌面”。

Linux Mint 自带默认的 Cinnamon 菜单。如果您需要启动菜单，点击屏幕左下角的“菜单”按钮或按下 `CTRL+SUPER_L`。键盘上的 SUPER_L 指左 Windows 键。

### “位置”菜单

一旦您选择“位置”部分，将向您显示五个项目。这些项目将为您提供对 Cinnamon 桌面某些位置的快捷访问。

它是显示您计算机中存储卷的项。如果您挂载了计算机中的所有分区，并将“桌面设置”设置为在桌面上显示“挂载卷”，那么您就不需要经常访问这些位置了。然而，对于那些选择不在此桌面上显示挂载卷的用户，或者需要挂载以前未挂载的分区的用户，您将必须访问此位置，因为它对您很有用。

“主目录”位置是对您证明非常有用的位置之一。

对于过去使用 Cinnamon 桌面的用户，您可能习惯了点击桌面上的“主目录”图标。当您打开了太多窗口导致桌面消失时，菜单将帮助您能够快速访问“主目录”。

如果你将某些数据放在此文件夹中，它也将被添加到桌面上。你也可以通过将文件拖到桌面来实现相同的操作。“网络”位置负责向你显示共享设备、域以及其他计算机，以及你计算机上可用的工作组。“废弃篓”位置负责保留已删除的文件。

在文件上点击右键后，你将获得两个选项，即“删除”和“移动到废弃篓”。如果你选择“删除”，该文件将被永久删除；但如果你选择“移动到废弃篓”，该文件将简单移动到“废弃篓”处，你可以从菜单访问它。如果你需要恢复文件，可以将其拖放到你需要的地方。如果你需要永久删除废弃篓中的所有项目，你必须选择“清空废弃篓”，这些文件将被永久删除。

### “系统”菜单

该菜单为我们提供了许多系统选项。它们能够帮助我们快速访问系统最核心的功能。未经授权的用户无法访问这些内容，因为访问这些内容需要密码。

“软件管理器”按钮将打开 Linux Mint 软件管理器。它是 Linux Mint 中安装软件的最佳程序。为了让你获得系统权限，系统将要求你提供密码。

“软件包管理器”按钮将打开一个名为“Synaptic”的应用程序。该软件包负责管理已安装在计算机上的程序，以及存储库中提供的程序。

“系统设置”按钮打开 Cinnamon 控制中心。该程序允许我们配置 Cinnamon 桌面的每一个方面以及整个计算机。让我们讨论一下此控制中心中包含的项目。

“终端”按钮打开一个名为“终端”的应用程序，它允许用户使用键盘输入命令。对于习惯 Windows 系统的用户来说，这可能有一点复杂，因为它的命令提示符没有进步多少。Linux Mint 终端非常强大，一旦习惯了，它会变得轻而易举。值得你了解，在 Linux Mint 图形化桌面上运行的任何命令都必须通过终端。一个很好的例子是当你点击桌面上的图标时。在这种情况下，Cinnamon 被指示向终端传递一些文本信息。通过一个命令，终端就可以帮助你完成很多工作，而无需通过打开多个窗口来实现相同的目标。

“锁定屏幕”按钮用于锁定你的屏幕。解锁时，系统会提示你输入密码。当你点击“注销”按钮时，会弹出一个允许你注销或切换用户的窗口。

“退出”按钮将启动一个对话框，允许你选择所需的选项。“挂起”选项会将会话保存到内存中，计算机将进入睡眠状态直到你按下按键。“休眠”选项会将会话保存到硬盘中，计算机将关机。“重启”选项将重启计算机。“关机”选项将关闭计算机。

## 第 4 章- 软件管理

### 包管理

对于第一次使用 Linux Mint 的用户，你可能不知道如何将软件组织成一个“包”。在安全和访问便利性方面，这是一个非常好的功能。

Linux Mint 的设计使得任何连接的硬件都会被自动检测，并且所有驱动程序都会自动安装。它还让 Linux Mint 用户能够完成大多数任务，而无需寻找任何第三方软件。Linux Mint 的安装版还带有一个功能完整的办公套件、一个高质量且专业的图像编辑解决方案、IRC 和 IM 客户端、几个媒体播放器、一个磁盘刻录机以及许多实用配件。这些都是免费软件！

当你从第三方网站寻找要在 Linux 系统上使用的软件时，会遇到很多问题。首先，你很难知道该软件是否经过测试，以及是否已被证明与你的操作系统兼容。此外，很难知道该软件是否能与系统中的其他软件兼容并按你预期的方式运行。该软件还可能来自未知的开发者，你不确定该软件是否会损坏你的计算机。

你可能会从不同的供应商下载并安装多个不同的程序。然而，这样做的问题在于，你的系统将缺乏一种管理结构。此外，你最好能制定一个计划，说明如何确保你下载到系统中的软件部分能够保持更新。有时，你可能会对某个程序感到厌倦。你将如何摆脱该程序呢？有些软件程序在安装后不提供移除选项，即使它们可能随之附带，程序也不会从系统中完全删除。这意味着在你电脑上运行了该程序的安装程序后，它获取了你电脑的一些控制权，更忘了该程序是由陌生人编写的。
