Valgrind 报告关于动态内存的报告，Valgrind 可以诊断未初始化内存。请考虑以下程序，`ch15-badmem3.c`:

```c
/* ch15-badmem3.c --- 对非动态内存进行违规操作 */
```

```c
#include <stdio.h>

#include <stdlib.h>

int main(int argc, char **argv) {
    int a_var;   /* 这两个都是未初始化的 */
    int b_var;

    /* Valgrind 不会标记此；参见测试。 */
    a_var = b_var;

    /* 使用未初始化的内存；这会被标记。 */
    printf("%a_var = %d\n", a_var);

    return 0;
}
```
