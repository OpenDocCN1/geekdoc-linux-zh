# 第 4 章 内存映射

在本章中，我们将讨论 x86-64 中如何转换地址。

## 4.1 内存映射

x86-64 进程的内存映射分为几个段。最重要的包括代码段、数据段、bss 段和栈。代码段包含可执行的指令。数据段包含初始化的全局变量。bss 段包含未初始化的全局变量。栈用于局部变量和函数返回地址。

## 4.2 页表

x86-64 的内存管理通过页完成。每个页通常为 4KB。从虚拟地址到物理地址的转换由硬件通过页表处理。
