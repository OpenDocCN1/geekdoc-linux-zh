
- VFAT (Virtual File Allocation Table)——Linux 中可能使用的非日志记录文件系统。
- virtual memory（虚拟内存）——硬盘上的一个区域（交换分区），当物理内存（RAM）被过度使用时，可以用于存储通常驻留在物理内存中的信息。
