
备份系统中的文件

### 1. 项目背景

作为学生，课还需要完成课程任务。IT协会的学生决定在下次备份的基础上手动备份几个文件到 `/tmp/`。

1) 拷贝到 `/tmp`，并查看，命令如下：

```bash
[root@localhost]# cp -r /etc/* /tmp
[root@localhost]# ls /tmp
```

2) 备份到 `/tmp`，并查看，命令如下：

```bash
[root@localhost]# cp -r root /tmp
[root@localhost]# cd tmp
[root@local tmp]# ll
```
