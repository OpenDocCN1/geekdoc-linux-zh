访问 Samba 共享的另一种方法实际上是在文件系统中挂载该共享。我们可以使用 `mount` 命令来实现此。首先，我们创建一个挂载点。

```
[root@alpha ~]# mkdir /mnt/samba_hotel
```

然后我们通过指定文件系统类型（在此为 cifs）、Samba 服务器和共享位置以及挂载点来挂载共享。
