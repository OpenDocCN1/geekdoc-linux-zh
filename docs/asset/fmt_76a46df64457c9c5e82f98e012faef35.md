# Struct 对象 (Struct Objects)

`struct` 模块定义了一个 `Struct` 类，为打包和解包提供了另一种替代接口。使用该类更高效，因为格式字符串只会被解释一次。

### `Struct(fmt)`

根据给定的格式代码创建一个表示打包数据的 `Struct` 实例。`Struct` 实例 `s` 具有以下方法，其功能与上一节中的对应函数版本完全相同：

| 方法 | 描述 |
|---|---|
| `s.pack(v1, v2, ...)` | 将值打包为字节字符串 |
| `s.pack_into(buffer, offset, v1, v2, ...)` | 将值打包到缓冲区对象 |
| `s.unpack(bytes)` | 从字节字符串解包值 |
| `s.unpack_from(buffer, offset)` | 从缓冲区对象解包值 |

# 第 16 章 字符串和文本处理 (Chapter 16 String and Text Handling)

| 格式 | C 类型 | Python 类型 |
|---|---|---|
| `'%f'` | float | 浮点型 |
| `'%d'` | double | 浮点型 |
| `'%s'` | char[] | 字符串 |
| `'%p'` | char[] | 长度编码在第一个字节中的字符串 |
| `'%p'` | void * | 整型 |

每个字符可以使用整数指定来表示重复次数（例如，`'%4i'` 等同于 `'iiii'`）。对于 `'%f'` 格式，该计数代表字符串的最大长度；对于 `'%10s'`，它代表一个 10 字节的字符串。`'%0s'` 格式表示长度为 0。`'%p'` 格式用于编码字符串，其中长度出现在第一个字节，随后是字符串本身。这在处理 Pascal 代码时非常有用，在 Macintosh 上有时是需要这种。请注意，在这种情况下字符串的长度限制为 255 个字符。

当使用 `'I'` 和 `'L'` 格式解包值时，返回值为 Python 长整型（long）；在 `'%P'` 格式中，可能会根据机器的大小返回整型或长整型。

每个格式字符串的第一个字符还可以指定打包数据的字节序和对齐方式，如下：

| 格式 | 字节序 | 大小和对齐 |
|---|---|---|
| `'@'` | 原生 (Native) | 原生 (Native) |
| `'='` | 原生 (Native) | 标准 (Standard) |
| `'<'` | 小端序 | 标准 |
| `'>'` | 大端序 | 标准 |
| `'!'` | 网络（大端序） | 标准 |

原生字节序可能是小端序，也可能是大端序，取决于机器架构。原生大小和对齐对应于 C 编译器使用的值，并取决于具体实现。标准对齐假设任何类型都不需要对齐。标准大小假设 short 是 2 字节，int 是 4 字节，long 是 32 位，float 是 64 位。`'%P'` 格式只能使用原生字节序。

# 注意事项 (Notes)

- 有时有必要将结构体的末尾对齐到特定类型的对齐方式。为了做到，可以使用使用重复次数为零的代码作为结尾字符串。例如，格式 `'%1h0'` 指定了一个在 4 字节边界结束的结构（假设 longs 是按 4 字节边界对齐的）。在这种情况下，在 `'h'` 代码指定的 short 值之后会插入两个填充字节。这仅在使用原生大小和对齐时有效——标准大小和对齐不强制执行对齐规则。
- `'%q'` 和 `'%Q'` 格式只有在用于构建 Python 的 C 编译器支持 long long 数据类型时，才在“原生”模式下可用。
