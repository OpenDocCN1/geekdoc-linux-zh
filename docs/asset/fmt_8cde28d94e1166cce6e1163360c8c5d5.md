
任何未经你同意进入你家的人理论上都在实施违法行为。你的计算机系统是你边界的延伸，不容侵犯。当某人以任何方式获得对你计算机的未授权访问，或利用计算机技术实施重罪时，他/她就犯了网络犯罪。

一提到网络空间的违规行为，黑客总是第一个进入脑海的人。毕竟，还有谁能有知识储备且足够大胆去闯入别人的计算机系统呢？

黑客曾经有更崇高的目标。在计算机技术的早期，他们是计算机专家/天才，在所有者同意下测试计算机系统，查找漏洞，并推荐更好的程序或自行修复错误，以挫败利用缺陷系统更危险的“生物”的努力。他们甚至有自己的黑客行为准则。

有两种类型的黑客：道德专业人士，这些是高技能的专业人士，他们将技能租赁给关注自身网络安全性的组织。他们代表了早期一代的 hackers。另一种类型是 CyberRamboes 或单纯的破解者——被精英黑客所鄙视。破解者为了肤浅的原因破坏系统。（UC 圣地亚哥分校心理学部：计算机与网络资源）

无论他们被称为什么，这些网络罪犯对他们的受害者来说已变得完全匿名且无名的“黑客”。

## 关于动机

大卫·本顿（David Benton）在线文章“破解者内部结构是什么？”（'What's Inside a Cracker?'），刊载于 SANS（系统管理员、审计、网络、安全）信息安全阅览室，引用了加拿大心理学家、曼尼托巴大学心理学研究生部、前警方网络犯罪调查员马克·罗杰斯（Marc Rogers M.A.）记录的对恶意黑客的七种心理画像：

- **新手/工具包（NT）**：黑客新手，计算机/编程能力有限；依赖互联网上现成的软件（工具包）；
- **内部人员（IT）**：对公司内部系统运作熟练的失望员工或前员工；
- **编码者（CD）和病毒编写者**：希望将自己视为精英的程序员；他们编写代码，但不是供个人使用。他们拥有用于实验的“动物园”网络。他们留给其他人将系统引入“野外”或互联网。（杰里米·昆特纳的《黑客心理学 101》）；
- **赛博朋克（CP）**：反社会的极客，最显眼，社交能力差，携带未解决的愤怒进入网络空间；他们与计算机的相处比与人更融洽，拥有更好的计算机技能以及一些

### 老派黑客（OG）

他们没有真正的犯罪意图，但表现出对私人财产的惊人漠视，并对智力活动表现出极大兴趣。

### 职业罪犯（PC）和网络恐怖分子（CT）

最具威胁性；他们是职业罪犯和前情报人员，属于雇佣枪手。他们专门从事企业间谍活动，受过异常良好的训练，并且能够获得最先进的设备。

此外，罗杰斯指出，并非所有黑客都是罪犯。他将他们分类如下（杰里米·奎特纳，《*黑客心理入门*》）：

- **老派黑客**：类似于 1960 年代来自斯坦福/MIT 的计算机程序员，对他们来说，成为黑客是一种荣誉；他们对分析系统没有犯罪意图；他们认为互联网被设计为开放系统。
- **脚本小子/赛博朋克**：想当黑客和破解者的人；粗心地使用其他破解程序，意图破坏和损坏系统；经常因为在网上吹嘘他们的罪行而被当场抓获。
- **职业罪犯**：入侵系统并出售信息是他们的生计；他们受雇从事间谍活动；通常与有组织犯罪集团有关联；对破坏网络不感兴趣，更倾向于窃取情报数据。

动机的列表是无尽的：无聊、非法刺激、成瘾、勒索或低自尊，以及在匿名保护下，出于对黑客同行群体认可的迫切渴望，所有这些行为都是懦弱的表现。

“犯罪黑客的心理深处可能隐藏着一种深刻的自卑感。掌握计算机技术或导致主要网站关闭并造成数百万美元的损失，是一种真正的权力享受。”（J. 奎特纳，《*黑客心理入门，黑客：计算机罪犯*》）

乔治·华盛顿大学的精神科医师贾罗德·M·波斯特说：“（黑客）是一个由于无法维持现实世界的人际关系而躲在计算机中的人群。”

你在互联网上分享的信息越少越好。但作为计算机奇才，黑客总是能找到方法来重建你的身份，即使他们只掌握很少的细节。

然而，你作为合法的互联网用户，有多种方式可以得到保护。了解警告信号，并学习如何挫败任何试图利用你的尝试。不要坐视不理地承受网络打击。

> “对知识的持续关注和更新是抵御任何攻击的最佳防御，”谢恩·格雷格（CA (NZ), CISA, CMC）在《*'对近期网络攻击的回应'*》（信息系统审计与控制协会 InfoBytes）中写道。

我推荐由 ZDNet 执行编辑普雷斯顿·格拉拉撰写的《*保护在线自我的完全白痴指南*》。它内容全面，易于理解，是每个互联网用户图书馆的必备读物。

## 黑客、赛博朋克等

黑客或破解者并不独占网络犯罪。在你的社区中，雇用计算机专家在线实施其非法活动的恋童癖者、小偷或毒贩同样有罪且令人鄙视。

就像在现实世界中四处游荡的罪犯一样，网络罪犯是一群心理上失衡且误入歧路的公民，他们恰好具备实施电子违规行为或雇用计算机专家完成工作的灵巧性，并且尽管获得了网络荣耀和“征服”，却永远不满足。

然而，犯罪的倾向隐藏在无害的表象之下，而不知情的人往往措手不及。你没看到的东西有时恰恰是你得到的。

> 黑客不能被严格地刻板化。五大公司毕马威（KPMG）的首席安全架构师彼得·希普利断言：“我认识许多黑客，其中包括一个每天花一个半小时在健身房的人。他身材魁梧。我认识那些被击倒的美丽女性也是黑客。”

## 没有例外

每当那些对科技极度狂热的人通过你的线路使你的计算机系统故障、窃取你的身份或收钱给你制造麻烦时，这都表明你在登录时没有采取必要的预防措施。

当时当我静静地问自己，“为什么是我？”我想回答会是，“为什么不是我？”就像大多数发明一样，互联网正在被滥用和误用。而一如既往，无助的受害者完善了这场戏剧。

无论一个人是否诚实、受过教育、高知名度、居住在全球另一端或是一位在家努力和平工作的全职主妇，任何人都可能随机成为受害者。

黑客不在乎他/她的猎物会有什么感受。

但我仍然希望，这种令人印象深刻的脑力活动能被当今的黑客善加利用，正如他们的先驱者打算那样使用黑客技术。

## 首次使用 Linux 用户的正确路径

你是 Linux 的新手，还是打算第一次使用它？等等！我在这里说什么鬼话！根本没有“Linux 新手”或“首次使用 Linux 的用户”这种说法。在没有意识到的情况下，你很可能每天都在使用它！而且你认为 Linux 是给编程怪咖、黑客以及使用那个过时的绿色终端的人用的！

那是种族歧视，你知道吗。

主要的问题应该是——你是个人 Linux 计算的新手吗？嗯，如果你的答案是“是”，那么别担心，一个卓越的操作系统已准备好服务于它唯一的主人。看我刚才玩了什么文字游戏？我的意思是，只有你才是你的硬件和软件的主人。不会有人在你在网上欣赏“搞笑小猫视频”时，安装一些你不需要的糟糕应用或更改系统设置！

在个人 Linux 计算的世界中，有大量的选择可供挑选。来自 Linux 星球的人们称之为“发行版”。这意味着，虽然主要的系统“内核”是相同的，但外观、感觉和整个生态系统可能不同。

就我日常桌面工作而言，我个人最喜欢的至少是 Kali Linux。它是一个源自 Debian 的 Linux 发行版，专为数字取证和渗透测试设计。然而，对于个人使用，我更喜欢 Linux Mint 或 Elementary OS。但以下是一些你可能听说过的其他发行版：

- Fedora
- Zorin
- openSUSE
- Debian

这些在用户数量方面是最主要的发行版。然而，作为初学者，你应该使用“Linux Mint Cinnamon 版”。它非常类似于你的 Windows PC，如果你来自“果”（Apple）的世界，我建议尝试“Elementary OS”或“Deepin OS”。它们非常类似于 Mac 生态系统。

**坚持使用 Linux Mint**：从迁移的第一天起，建议坚持使用像 Linux Mint、Zorin、Linux Lite 等发行版。它们易于安装和使用，并且拥有大量的在线用户群。这些用户相对知识丰富且友善；询问你面临的问题，如果你不在几分钟内得到正确答案，也会在几小时内得到！Linux Mint 开箱即用的软件相当不错。这些包括 LibreOffice（一个免费且开源的办公套件）、Thunderbird（邮件客户端）、Rhythmbox（音乐播放器）和 Firefox（你可以轻松安装 Chrome 和 Chromium）。当你熟悉 Linux 环境后，你可能会开始尝试不同的发行版和 DE（桌面环境）。不过，目前坚持使用 Linux Mint 并慢慢了解 Linux 的工作原理是个好主意。

**沉浸式体验**：与 Linux 建立关系最好的方法是让它成为你的日常驱动。毫无疑问，头几天的体验会是颠簸和奇怪的，就像所有新鲜事物和超出舒适区的事情一样。

像 Linux Mint、Zorin 和 Ubuntu 这样的发行版试图使从 Windows 或 Mac 到 Linux 宇宙之旅变得顺畅而神奇！很快，我可以保证你会奇怪为什么你以前使用的是 Linux 以外的任何东西！

**不要害怕终端**：像 Ubuntu 和 Linux Mint 这样的发行版旨在让你如果不愿意，就永远不需要打开终端命令行。然而，了解命令行是被强烈鼓励的，而且它并不像乍一看那样痛苦。在许多情况下，终端比图形用户界面（GUI）更好且更具生产力。在 GUI 中需要多次点击、滚动、按键和更多点击的事情，通常可以通过单条终端命令完成。这就是简单性！
