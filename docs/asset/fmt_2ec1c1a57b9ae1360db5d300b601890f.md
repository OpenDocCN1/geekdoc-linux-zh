## ARM

引用了一种精简指令集计算机（RISC）CPU，其不基于 x86 指令集。通常用于嵌入式、移动、平板电脑和电池供电设备。树莓派使用的是 ARM 版 Linux。

`/proc/cpuinfo` 文件包含了有关系统处理器的详细信息。遗憾的是，这些细节对普通用户并不友好。通过 `lscpu` 命令可以获得更通用的结果。树莓派 B+ 的输出：

```
$ lscpu
Architecture: armv7l
Byte Order: Little Endian
CPU(s): 4
On-line CPU(s) list: 0-3
Thread(s) per core: 1
Core(s) per socket: 4
Socket(s): 1
Model: 
Model name: ARMv7 Processor rev 4 (v71)
CPU max MHz: 1400.0000
CPU min MHz: 600.0000
BogoMIPS: 38.40
Flags: half thumb fastmult edsp non vfp3 tls vfpv4 idiva divt vfp32
lpaev evstrm crc32
```

对于大多数人来说，厂商、处理器家族和规格因素代表了令人困惑的选择。尽管如此，当普通用户和管理员需要指定运行环境时，通常仍需要考虑与 CPU 和处理器相关的几个因素：

### 位宽

对于 CPU 来说，这个数字与它所处理的数据原生大小以及它能够访问的内存量有关。大多数现代系统是 32 位或 64 位。如果应用程序需要访问超过 4GB 的内存，它必须在 64 位系统上运行，因为 4GB 是使用 32 位可以表示的最大地址。虽然 32 位应用程序通常可以在 64 位系统上运行，但 64 位应用程序无法在 32 位系统上运行。

### 频率

通常以兆赫（MHz）或吉赫兹（GHz）表示。这涉及到处理器处理指令的速度。但处理器速度只是影响系统响应时间、等待和吞吐量的因素之一。每个活跃的多任务用户很少会让普通桌面式 PC 的 CPU 活跃时间超过 2% 或 3%。尽管如此，如果你使用涉及加密或视频渲染等计算密集型应用程序，那么你的 CPU 速度可能会吞吐量和等待时间产生显著影响。

### 缓存

CPU 需要持续的指令和数据流才能运行。以 CPU 时钟频率访问数 GB 系统内存的成本和功耗将是惊人的。CPU 高速缓存内存集成在 CPU 芯片中，在 CPU 和系统内存之间提供高速缓冲区。缓存被分为多个层，通常称为 L1、L2、L3 甚至 L4。在缓存方面，通常越多越好。

### 核心

核心指的是单个 CPU。除了核心代表物理 CPU 之外，超线程技术（HTT）允许单个 CPU 同时处理多条指令，从而在虚拟上充当了多个单处理器 CPU。最常见的情况是，多个核心被封装在单个处理器芯片中。然而，也有主板支持多个物理处理器芯片。从理论上讲，为任务提供更多核心似乎总是产生更好的系统吞吐量。遗憾的是，桌面应用程序通常只让 CPU 忙碌 2% 或 3%，增加更多空闲的 CPU 可能对吞吐量的提升微乎其微。更多核心最适合运行编写为多个独立操作线程的应用程序，例如视频帧渲染、网页渲染或多用户虚拟机环境。

### 存储

存储设备提供保留数据的方法。硬盘（HDD）和固态硬盘（SSD）是最常见的存储设备。HDD 使用旋转盘片存储数据，而 SSD 使用闪存。SSD 通常比 HDD 更快、更耐用且更昂贵。其他存储设备包括光驱驱动器（CD、DVD、蓝光）、闪存盘（USB 优存盘）和网络存储（NAS）。

磁盘分区是将存储设备划分为多个逻辑部分的方法。这允许操作系统将每个部分视为一个独立的驱动器。例如，你可以有一个分区用于操作系统，另一个分区用于个人文件，还有第三个分区用于交换空间。常见的文件系统包括 NTFS、ext4 和 APFS。

文件系统是计算机用于在磁盘驱动器上存储和检索数据的方法。没有文件系统，存储在驱动器上的数据将是一个巨大的数据簇，无法知道一个文件何时结束，另一个何时开始。要在操作系统中使用磁盘驱动器，必须先进行格式化。格式化会创建文件系统结构并为驱动器的使用做好准备。

设备是允许数据输入、处理、存储或传输的任何物理硬件。常见设备包括键盘、鼠标、显示器、打印机和硬盘。设备可以分为输入设备、输出设备、存储设备和通信设备。

驱动程序是软件集合，告诉计算机硬件如何与其他软件通信。它在操作系统和硬件之间充当翻译官的角色。没有正确的驱动程序，操作系统将无法正常使用硬件。

操作系统是管理计算机硬件资源并为计算机程序提供服务的软件。常见示例包括 Windows、macOS、Linux 和 Android。操作系统负责管理内存、进程、数据访问和文件系统管理。

命令是告诉计算机执行特定任务的指令或文本行。程序使用 Python、C++ 或 Java 等编程语言编写，然后被编译或解释为计算机可以执行的机器码。

脚本是由解释器执行的一组命令。常见的脚本语言包括 Python、Bash 和 PowerShell。

API（应用程序接口）是一组允许软件应用程序相互通信的规则和协议。它允许开发者使用现有代码和功能，而无需理解底层实现。

数据库是结构化信息或数据的组织集合，通常以电子方式存储，用于管理数据。常见的数据库系统包括 MySQL、PostgreSQL 和 MongoDB。

是向其他计算机提供服务的计算机或程序。常见的服务器类型包括 Web 服务器、文件服务器、电子邮件服务器和数据库服务器。

客户端是请求服务器服务的计算机或软件程序。

网络是连接计算机和其他设备的集合，用于共享资源和信息。网络可以是局域网（LAN），也可以是互联网。

协议是规定数据如何在网络上传输的规则。常见协议包括 TCP/IP、HTTP 和 FTP。

IP 地址是分配给设备的唯一数字标签。

域名是人类可读的地址。例如，google.com 是一个域名。

DNS（域名系统）是将域名转换为 IP 地址的系统。

浏览器是用于查看和导航网站的软件应用程序。常见示例包括 Google Chrome、Mozilla Firefox 和 Safari。

万维网（WWW）是可以通过互联网访问的互连网页系统。

电子邮件是使用电子设备交换消息的方法。

社交媒体是指允许用户创建和共享内容并参与社交网络的数字平台。示例包括 Facebook、Twitter (X) 和 Instagram。

电子商务是在互联网上买卖商品和服务。

区块链是一种去中心化的账本技术，记录网络中许多计算机上的交易。

加密货币是一种使用区块链进行安全的数字货币。比特币是第一个且广为人知的加密货币。

物联网（IoT）是指嵌入了传感器和软件，用于通过互联网交换数据的物理对象网络。示例包括智能恒温器和智能家电。

虚拟现实（VR）是一种创建用户可以交互的模拟虚拟环境的技术。

增强现实（AR）是一种将数字信息叠加到现实世界上的技术。

元宇宙是一个假设性的概念，一个人们可以相互交互的虚拟空间。

量子计算是一种利用量子力学属性解决复杂问题的计算类型。

生物技术是使用生物系统开发产品的领域，用于医学、农业和工业。

自动化是使用技术在最少人工干预的情况下执行任务。

机器人学是涉及设计、构造和操作机器的技术科学分支。

计算机视觉是计算机看到并解释视觉信息的 AI 领域。

自然语言处理（NLP）是让计算机理解、解释和生成人类语言的 AI 领域。

深度学习是机器学习的一个子集，专注于构建从数据中学习以进行预测而非显式编程的系统。

大数据是指使用传统方法难以处理的庞大数据集。分析大数据以发现模式和洞察。

机器学习是人工智能的一个领域，专注于构建从数据中学习以进行预测的系统。

人工智能（AI）是计算机科学的一个领域，旨在创建能够执行通常需要人类智能的任务的系统。

数据科学使用方法和算法从数据中提取洞察的领域。它被用于医疗保健、金融和零售等行业。

数据分析是收集、转换和分析数据以做出决策的过程。

数据可视化是将数据以图形格式（如图表或图形）表示以便更容易理解的过程。

安全是保护计算机系统、网络和数据免受未经访问或损坏的实践。常见安全措施包括加密、防火墙和反病毒软件。

加密是将信息转换为代码以防止未经访问的过程。它需要密钥进行解密。

防火墙是一种网络安全设备，根据预定义的安全规则监控并控制入站网络流量。

反病毒软件是旨在检测、防止和删除恶意软件的程序。

云计算是通过互联网交付计算服务，包括服务器、存储和软件应用程序。常见的云提供者包括 AWS、Azure 和 Google Cloud。

可持续性是以特定速率维持或处理或无限支持的能力。

可再生能源是指来自自然补充的能源，如太阳能和风能。

气候变化是指温度和天气模式的长期转变。

全球变暖是由于主要是人类活动引起的温室效应导致地球总体温度逐渐上升。

保护是防止资源浪费或过度使用的实践。

回收是将废弃材料转换为新材料和物品的过程。

堆肥是将有机物分解为土壤改良剂的自然过程。

有机农业是不使用合成肥料或农药的耕作方法。

生物多样性是世界或特定栖息地的生命多样性。

生态系统是生物与其物理环境相互作用的生物群。

环境指的是人、动物或植物生活的周围。

废物管理是对废物进行收集、运输、处理和处置。
