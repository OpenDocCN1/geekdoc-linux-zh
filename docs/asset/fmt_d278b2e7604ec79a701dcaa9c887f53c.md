# 应用样式

你可以使用右键菜单为形状添加一些视觉上有趣的格式。首先，右键点击形状查看此菜单。点击“`Line`”，打开“线条”对话框。此对话框不仅控制线条的格式，还控制多边形和圆形的边框。选择一种样式和颜色并设置宽度；然后点击确定以在你的对象上查看结果。

点击右键菜单上的“`Area`”选项。在“区域”对话框中，你可以设置对象的填充颜色，并从额外的选项卡中按你的需要进行配置。选择“`Shadow`”标签并点击“阴影”。接下来，点击“`Transparency`”标签并点击“透明度”。将透明度设置为80%，然后点击确定。你的对象现在有了新的填充颜色、投影，并且是半透明的。

最后，点击右键菜单上的“`Position and Size`”选项。更改对象的宽度然后点击“`Rotation`”标签。在“`Rotation Angle`”选项中，设置为45度，然后点击确定。你的对象现在变宽了并向右旋转了45度。

# 修改形状上的胶点

通过更改对象的胶点（glue points），你可以在对象上创建或修改连接器。放置胶点是控制连接器出现在形状位置的方法。

连接器是用于视觉上将一个对象与另一个对象连接的线条。例如，如果你想连接对象——作为流程图的一部分——你可能会使用连接器。胶水将对象形状上被称为胶点的位置连接在一起。胶点和连接器的组合非常有用，因为即使你移动或重塑对象，这些连接也会保持存在。

默认情况下，Draw对象包含四个胶点：分别位于对象的顶部、底部、左侧和右侧。

有一个专门的“`Gluepoints`”工具栏，允许你修改对象的胶点。要使用该工具栏，请按照下面的步骤操作。或者，你可以通过点击 查看 -> 工具栏 -> 胶点来激活该工具栏。

胶点工具栏包含用于创建和编辑胶点的工具。你可以在下面的步骤中添加新的胶点。你可以添加任意数量的胶点，虽然默认胶点在对象的边缘上，但你可以在任何地方放置新胶点，包括对象内部。

- 点击“`Connectors`”按钮。
- 对象的胶点变得可见。
- 点击“`Gluepoints`”按钮。

# 额外内容

胶点工具栏还有几个你应该熟悉的额外选项。紧邻“新建胶点”按钮右侧的是四个具有相关功能的按钮。使用这些按钮可以强制要求到对象的连接仅附加到指定的点上。例如，如果你希望所有到你对象的连接都来自对象底部，请选择“`Exit Direction Bottom`”按钮。

其余的七个按钮相互相关。七个中的第一个“`Gluepoint Relative`”使你的胶点放置相对于对象的形状。换句话说，如果你选择了此按钮并调整对象的大小，胶点的位置将相对于对象的形状发生移动。

取消激活“`Gluepoint Relative`”将使胶点工具栏上的其他六个按钮变为激活状态。其余六个按钮允许你固定形状内部的点。通过使用这些选项，即使对象的大小或形状发生，胶点也不会移动。

对于大多数情况，你会希望勾选“`Gluepoint Relative`”按钮，因为这减少了编辑对象时的复杂性。

# 对齐形状

或者，你可以选择对象并右键点击选择“`Alignment`”选项。“对齐”子菜单提供了许多选择，都与对象之间的相对对齐有关。

# 额外内容

正如你可以更改形状之间的对齐一样，你也可以更改形状之间的排序。当我们在 Draw 中讨论排序时，我们指的是前后排序，即哪些对象显示在其他对象前面并可能遮挡它们。

要设置对象的顺序，右键点击对象并选择“`Arrange`”选项。“排列”子菜单提供了许多选择，都与在屏幕对象顺序中向前后移动对象有关。

选择“`Bring Front`”将你的对象移动到屏幕上所有对象之前。选择“`Send Back`”将对象移动到顺序的最后。如果你想将对象后移动一步，请选择“`Bring Forward`”或“`Send Backward`”。如果页面上有多个对象，你可能需要重复此步骤。每次你选择该选项，它都会向前或向后移动一步。

如果你想同时移动多个对象，请选择这些对象并选择“排列”选项作为一个整体移动它们。

# 插入图像

你可以向 Draw 文档中添加图片和其他图形文件。图像可以与你在 Draw 中创建的矢量图相结合，并且在一定范围内可以在内部进行操作。

要插入图像，你首先从“插入”菜单上的“图片”子菜单开始。“图片”子菜单允许你选择使用位于硬盘上的现有图像，或者扫描一个新图像。如果你选择插入图像，将打开“插入图像”对话框，你可以在其中选择计算机上的图像。

或者，你可以点击底部工具栏上的“从...”按钮。它的工作方式相同，只是它会立即打开“插入图像”对话框。

请注意，当图像出现在你的文档中时，上面会有八个绿色的手柄。手柄允许你通过点击并拖动它们来调整图像的大小。当你将光标悬停手柄上时，它会改变形状以指示手柄处于激活状态。

要移动图像，点击它并将其拖到屏幕上的新位置。

右键点击图像会显示修改图像的其他方法。“位置和大小”选项会打开一个对话框，允许你通过 X 和 Y 坐标设置图像在页面上的位置。你可以设置图像的宽度和高度。单独的选项页允许你对其进行旋转。

## 其它

你不仅可以在 Draw 中插入图像，还可以将 Draw 中创建的图像导出到多种其他格式。以原生 Open 格式保存的文档仅供其他 OpenOffice 用户使用。然而，你可以将文档导出为不同的格式。

在“文件”菜单下有两个选项：“`导出`”和“`导出为 PDF`”。导出”选项会打开一个对话框，为你提供 12 种导出格式，包括最流行的格式：HTML、TIFF、GIF、JPG、PNG、EPS 和 BMP。

你也可以从此菜单导出为 PDF，但这可能更希望使用“导出为 PDF”选项。选择“导出为 PDF”会打开 PDF 选项对话框，其中包含许多自定义输出的配置选择。如果你是为了为打印机导出文档，你很可能想以 PDF 格式导出文档，并使用 PDF 选项对话框中的选择来实现最高质量的输出。
