## 7.5. Macintosh 风格的文件和打印服务

# 带有 Netatalk

Linux 也可以使用 Netatalk 包提供 Appleshare 服务（例如 Macintosh 风格的网络文件和打印机共享）。本节将描述如何配置共享，以及如何从客户端机器访问它们。

为了使用 Netatalk，你需要在 Linux 内核中具有 Appletalk 网络支持。Red Hat 的标准内核通常已经以模块形式包含了此项支持，或者你可以自行编译具有此类支持的自定义内核。

![](img/846ec8d157c5d667ec22f4e21c29db61_68_0.png)

注意：确保 Appletalk 支持被编译为模块，而不是作为内核的一部分包含（有关如何升级或自定义 Linux 内核的详情，请参见第 10.4 节）。否则，在停止并重启 Netatalk 守护进程时将遇到困难。

一旦你确保你的内核能够支持 Appletalk，你就需要安装 Netatalk 包。由于 Netatalk 未包含在 Red Hat 发版中，你需要下载并安装副本。Netatalk 包可以在 Red Hat 的“contrib”站点上找到，地址为 `ftp://ftp.redhat.com/contrib/libc6/i386`。

安装 Netatalk 后，你需要修改 "`/etc/stalk/`" 中的至少一个或多个配置文件。大多数文件包含示例配置示例，因此至少具有某种程度的自文档性。这些文件是：

```
config
```

此文件包含调优你的 Netatalk 守护进程的配置信息。这些信息在环境变量中指定，该文件在 Netatalk 启动脚本启动服务之前被“源化”（即读取）。你可以指定并发连接数、是否允许访客登录等。你几乎肯定需要根据需求修改此文件。

```
atalk.conf
```

此文件包含关于使用何种网络接口的信息，以及你的 Appletalk 路由、名称注册和其他相关信息。你可能不需要修改此文件；所需的网络信息在首次启动 Netatalk 服务器时会被检测到并添加到此文件中。然而，你可能可能想添加你的服务器名称。

> 注意：输入 "`man atalk`" 获取有关此文件的更多信息。

`afpd.conf`

此文件允许你指定通过命令行选项传递给 Netatalk 的额外参数。你可以指定你希望运行 Netatalk 服务器的端口或 IP 地址，添加显示给连接用户的登录消息，以及其他相关选项。你可能不需要修改此文件。

> 注意：输入 "`man afpd`" 获取有关此文件的更多信息。
