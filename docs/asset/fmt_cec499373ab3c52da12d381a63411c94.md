### 供犹豫不决者参考（`Linux` 的优势）

- 免费使用软件，不受任何限制，
- 复制、分发或销售未修改的副本，
- 免费使用带有自定义（例如你的）修改的软件，只要你不分发或销售修改后的版本，
- 修改并分发或销售修改后的软件版本，因为源代码是以原始版本（`GPL`）相同的条款许可并包含的，
- 销售软件支持服务，不受任何限制。

`GPL` 许可证允许复制接收者做的是：获取受 `GPL` 保护的软件，修改软件，并在专有许可证下分发修改后的软件版本。直白地说，`GPL` 许可证本身禁止盗取（某人的）软件并将其整合到纯商业产品中。然而，如果你从版权所有者处获得许可，你可以在商业程序中整合 `GPL` 软件。`GPL` 绝不比“典型的”专有许可证更具限制性或强迫性。`GPL` 是一种授予接收者原本不具备但又赠出的权利的许可证。违反 `GPL` 的人被排除在 `GPL` 使用之外。

通常，版权规定了 5 权利：复制作品、制作衍生作品、分发作品、表演作品和展示作品。

这是一张比较 `Linux` 与 `MS` `Windows` 许可证的表格（由一位 `RedHat` 律师编写，`http://www.grokial.net/article.php?query=200312319027900`）

| `Linux` | `MS` `Windows98` |
|---|---|
| 复制权 | 是 | 否 |
| 制作衍生作品权 | 是 | 否 |
| 重新分发权 | 是，在相同许可下 | 否 |
| 执行作品权 | 是 | 是 |
| 展示作品权 | 是 | 是 |
