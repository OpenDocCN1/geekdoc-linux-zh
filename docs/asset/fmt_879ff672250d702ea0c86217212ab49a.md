
通过增加标尺长度或使用多次反射来提高电流计分辨率所达到的极限，可以通过使用负反馈网络让电流计在其平衡位置工作来克服。在该系统中，从电流计镜面反射的光束被导向一对串联对置的光电池。随着电流计线圈旋转，照射在其中一个光电池上的光增加，而另一个减少，从而产生放大的输出电流，其符号和大小分别取决于线圈偏转的方向和幅度。输出乘以外部指示器，并约为电流计输入电流的 1800 倍。这种光电池输出还向系统提供负反馈电流，使电流计保持在平衡位置，从而改善系统的线性度和输入电阻。在这种结构中，通常可以非常接近由线圈的布朗运动或与电流计连接的电路的约翰逊噪声所施加的角运动分辨率的理论极限。在低灵敏度电流计中，这一理论分辨率可能约为 0.001 µV。参见布朗运动；电气噪声；物质运动论。

电流计是一种极其高效的低通滤波器，并且在输入阻抗为 1 kΩ 或更低时，它仍然是最灵敏的低电平探测器。在较高的输入阻抗下，斩波稳幅放大器（称为纳伏计）比电流计表现出更好的分辨率、噪声和漂移特性。这些仪器通过使用斩波器（机械触点、晶体管或光控开关）对输入直流信号进行调制，然后通过传统的直流技术放大信号，以实现 10 nV 或更低的灵敏度。目前，具有纳伏分辨率的先进数字电压表已可用，并作为低电平探测器使用。参见安培计；电滤波器；电气干扰；电气测量；电子伏特；伏特计。[E.K.H.; RFD.]

## 博弈论

策略博弈理论可以简要地描述为将数学分析应用于冲突情境的抽象模型。该理论分析的第一个此类模型是象棋、扑克和桥牌等休闲游戏。自那时以来，源自行为科学（如经济学、社会学和政治学）的模型也已被分析。博弈论被用于或与其他领域紧密相连，如线性规划、统计决策、管理科学、运筹学和军事规划。在某些领域，即使对应的数学不存在，该理论的语言和概念有时也会被使用。参见线性规划；运筹学。

### 扩展式博弈

博弈的参与者被称为“人”，这种“人”实际上可以由一个或多个真实的人组成（例如，在桥牌中，东西方搭档和南北方搭档各自构成游戏中的一个玩家）。机会移动发生在从洗好的牌堆中发牌、掷骰子或旋转指针时。人们常说所有机会移动都分配给“机会玩家”，这是一种在博弈标准性质中有用的虚构设定。

当由规则列表指定时，一个博弈被称为处于扩展式形式。出于数学目的，使用标准化形式的博弈是方便的，而这需要纯粹策略的概念。

对于某个玩家（非机会玩家）的纯粹策略，是他或她在游戏过程中可能出现的每一种情况下，对所有合法移动选择的完整列表。这比通常称为策略的决策列表要完整得多。即使对于像井字游戏这样幼稚的游戏，一个博弈中纯粹策略的数量也可能是天文数字般的庞大。由于纯粹策略的数量巨大，博弈论对休闲游戏甚至的实际应用都受到计算困难的严重限制。已经发展出这些游戏的简化版本，以便可以完全完成计算。

### 标准化形式的博弈

在玩家已经在一个博弈中选择了纯粹策略后，他们无需实际下棋。相反，他们可以将其策略交给一个中立的人，即裁判，由裁判执行其指令并做出他们本来会做的移动。这个直观上显而易见的想法自然引向了博弈的标准化形式。

暂时假设博弈中没有机会移动，即假设有 `$n$` 个真实玩家但没有机会玩家。用 `s_1, s_2, ..., s_n` 分别表示玩家 `1, 2, ..., n` 的特定纯粹策略。给定这些策略，博弈必须且只能以一种方式被玩，并且会产生唯一的结局。令 `P(s_1, s_2, ..., s_n)` 为此次博弈中玩家 1 的货币结果。

在引入机会玩家的影响之前，必须解释数学期望这一重要概念。假设 `O_1, O_2, ..., O_k` 是一个随机事件的互斥货币结果，并且假设它们发生的概率分别为 `p_1, p_2, ..., p_k`，其中 `p_i > 0` 且 `p_1 + p_2 + ... + p_k = 1`。那么，该随机事件的数学期望 `E` 定义为和 `E = p_1 O_1 + p_2 O_2 + ... + p_k O_k`。参见概率。

如果博弈中有利机会移动，一组纯粹策略（每个玩家一个）将不会决定博弈的唯一结果，而仅仅是一组可能的结果。这些结果将是互斥的，且具有取决于其发生相关机会移动的概率。因此，在这种情况下，对于每个 `i = 1, 2, ..., n`，可以令 `P(s_1, s_2, ..., s_n)` 为预期支付给玩家 `i` 的金额。

现在，博弈的标准化形式定义为每个玩家在每一种可能的纯粹策略组合下的所有预期支付的列表。在两人博弈的情况下，最方便的是将这些列表在称为矩阵的表格中列出。参见矩阵论。

### 博弈的分类

如果对于每一种可能的纯粹策略 `n`-元组 `s_1, ..., s_n`，所有玩家的支付之和为零，即式 (1) 成立，则称该博弈为零和博弈。如果对于某些纯粹策略 `n`-元组，此总和不为零，则称该博弈为非零和博弈。

$$P_1(s_1,\dots,s_n)+P_2(s_1,\dots,s_n)+\dots+P_n(s_1,\dots,s_n)=0 \quad (1)$$

如果扩展式博弈中，每个玩家都知道并记住其对手在每一步所做的每一个移动，则称该博弈具有完美信息。如果每个玩家都知道并记住自己做的每一件事（但不一定知道对手做了什么），则称该博弈具有完美回忆。桥牌不具有完美回忆，因为玩家的个性（发牌人）被分为两张牌；正式的桥牌玩家北方看不到南方手中的牌（即使当南方是明手时也是如此），即使他们是同一团队的成员。

然后，可以根据玩家数量、是否为零和、以及是否具有完美信息或完美回忆，对博弈进行分类。

### 非零和博弈

博弈理论中最令人满意的部分是零和两人案例，即矩阵博弈。该理论在经济、社会学和政治学等领域的应用几乎总是导致多人数非零和博弈。虽然尚未开发出涵盖这些博弈的普遍接受的理论，但已经做出了许多有趣且有益的尝试来处理它们。

当冲突情境涉及超过两个人时，博弈的重要特征就变成了博弈的联盟结构。联盟是一群联合起来并实际上作为游戏中一个新玩家行动的玩家的群体。需要考虑两种极端情况。一种是禁止此类联盟的非合作博弈。下面讨论的均衡点解为这类博弈提供了相当令人满意的解决方案。另一种极端情况是所有玩家联合起来形成一个联盟，以最大化他们的总支付。允许形成联盟的博弈称为合作博弈。

在非合作博弈中，每个玩家只关心他或自己的支付。在这种博弈中，均衡点指的是一组（混合）策略 `s_1, ..., s_n`，使得式 (2) 成立：

$$P_i(s_1, s_2, ..., s_i, ..., s_n) = P_i(s_1, s_2, ..., s_i, ..., s_n) \quad (2)$$

对每个 `i = 1, ..., n` 以及玩家 `i` 的所有策略 `s_i` 成立，这意味着没有玩家可以通过改变策略（假设其他策略保持不变）来提高支付。根据 J. Nash 的一个定理，每个博弈至少有一个均衡点解（通常有几个）。

### 简单博弈

应用于政治行为的一个重要 `n` 人博弈类是所谓的简单博弈。在这种博弈中，每个联盟可以是赢的、输的或阻挡的。例如，赢的联盟可能是一组可以选出其候选人的投票者，或是一组可以通过其法案的立法者。不在给定赢联盟中的玩家形成一个输联盟。最后，如果一个联盟既不能强制实现其意愿，其外部玩家也不能强制实现其意愿，则该联盟是阻挡联盟。

### 连续博弈

如果，在博弈的标准化形式中，允许每个玩家拥有一组连续的纯粹策略范围，并且支付函数允许是每个玩家策略范围内的两个实变量的函数，则结果是连续博弈。

### 博弈机器

大型电子计算机在数值问题上的早期应用之一是解决大型矩阵博弈。已经制定了多种寻找此类解的方法。其中一种方法是单纯形法。所谓的分解方法可以将这些方法扩展到具有数千甚至数百万变量和约束的某些问题。该方法的主要应用是解决线性规划问题，可以证明这些问题等价于矩阵博弈。

计算机也被编程来玩跳棋和象棋等棋类游戏。严格来说，它们目前并不使用博弈理论，而是使用设计代码的人的一些游戏直觉。参见决策论；信息论；随机过程。 **[G.L.T.]**

## 配子发生

通过涉及减数分裂的过程产生配子，即由雌性产生的卵细胞或由雄性产生的精子。在动物中，最终分化为卵细胞和精子的细胞起源于在胚胎形成早期从潜在的体细胞中预留出来的原始生殖细胞。

配子发生的最终产物是较大的、静止的卵细胞，以及较小的、运动的精子。每种类型的配子都是单倍体，即它们含有体细胞（二倍体）染色体组的一半。DNA 含量的减少是通过减数分裂完成的，其特征是一个 DNA 复制周期后跟随两个细胞分裂周期。参见染色体；减数分裂。

精子的产生与卵母细胞的产生不同，每个初级精母细胞分裂两次，产生四个等同的精细胞，它们仅在性染色体内容上有所不同（在 XY 性别决定系统中，这是哺乳动物的特征，两个精子含有 X 染色体，两个含有 Y 染色体）。精子的形态高度特化，具有独特的鞭毛，既提供后部运动装置，也提供前部顶体，后者有助于受精时穿透卵母细胞。参见精子发生。
