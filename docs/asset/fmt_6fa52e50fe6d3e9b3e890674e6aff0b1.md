## renice — 修改运行进程的优先级优先级

### 概览

```
/usr/bin/renice [-n increment][-g -p] [-u] ID...
/usr/bin/renice priority [-p] pid...[-g gid...][-p pid...][-u user...]
/usr/bin/renice priority -g gid... [-g gid...][-p pid...][-u user...]
/usr/bin/renice priority -uuser [-g gid...][-p pid...][-u user...]
```

### 描述

> 注意 — `priocntl` 命令包含了 `renice` 的功能。

使用 `renice` 命令修改一个或多个运行进程的调度优先级。默认，通过进程 ID 指定受影响的进程。

如果第一个操作数是优先级范围（−20 到 20）内的数字，`renice` 将其视为优先级（如所有第一个概览形式所示）；否则，`renice` 将其视为 ID（如第一个第一个概览形式所示）。

### 修改进程优先级

超级用户的用户只能修改其拥有的进程的优先级，并可以在 0 到 19 的范围内单调地增加其 nice 值。此限制防止了行政性操作。超级用户可以修改任何进程的优先级，并将优先级设置为 −20 到 19 范围内的任何值。有用的优先级是：

- `19`—运行
- `0`—默认
- `-20`—最高优先级
