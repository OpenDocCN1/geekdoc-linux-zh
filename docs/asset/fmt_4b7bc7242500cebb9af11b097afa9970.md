## 打印

您可能有多个想要打印的文档，并且计算机可能连接了多台打印机。在这里我们将讨论一些将文档打印到指定打印机并查询打印机状态的命令。我们还将讨论取消指定打印作业的命令。

在 UNIX 系统中，你有多个打印机，但只有其中一台可以被设置为默认打印机，如果未指定打印机名称，所有打印请求都将发送到该打印机。

### 取消

如果你之前使用 `lp` 命令队列了一个或多个文档的打印请求，并希望取消这些请求，请使用 `cancel` 命令。使用 `cancel` 命令，你可以取消指定的作业，也可以取消特定打印机队列的所有队列请求。如果你是普通用户，仅取消属于你用户 ID 的作业。

你可以使用 `cancel` 命令指定一个或多个作业 ID 或打印机名称。

示例：使用以下命令取消 ID 为 734 的作业：

```
cancel 734
```

要取消您在 `our_printer` 打印机中队列的所有请求，请使用以下命令：

```
cancel our_printer
```

### lp

要打印一个或多个文件到指定的打印机，请使用 `lp` 命令。默认情况下，`lp` 命令接受来自标准输入的输入。您正在打印的文件在打印之前必须存在，因为 `lp` 命令不会在打印时创建文件的副本（除非你使用 `-c` 标志）。

以下是可以与 `lp` 命令配合使用的标志列表：

- `-c`：创建文件的副本，以便在打印进行时删除或修改该文件。
- `-dprintqueue`：指定打印请求指向的打印机队列。
- `-m`：在打印请求成功完成后，通过邮件通知请求用户。
- `-ncopies`：指定打印的副本数量。
- `-ttitle`：在横幅页（banner page）上打印指定的标题。

示例：执行以下命令打印文件：

```
lp file1
```

在此示例中，`file1` 将在默认行打印机上打印。如果你想打印到命令旁边的 `our_printer` 打印机，请在以下命令中使用 `-d` 标志：

```
lp -dour_printer file1
```

如果文件很大，且你希望在打印作业成功完成后收到通知，请在命令中使用 `-m` 标志：

```
lp -m -dmain_printer file1
```

如果你想打印文件的副本并分发给同事，请在以下命令中使用 `-n` 标志：

```
lp -n15 -dour_printer file1
```

上面的示例将在名为 `our_printer` 的打印机上打印 15 份 `file1`。如果你想在横幅页上打印标题 `urgent memo`，请在以下命令中使用 `-t` 标志：

```
lp -n15 -t"urgent memo" -dour_printer file1
```

上面的示例将在 `our_printer` 上打印 15 份 `file1`，并在横幅页上打印标题 `urgent memo`。

### pr

`pr` 命令默认接受来自标准输入的输入，并在标准输出上生成输出。该命令将输出格式化为带有文件名、日期、时间和页码的页面。如果行长度大于宽度，它将被截断。由于 `pr` 命令会对输出进行格式化和分页，你可以将 `pr` 命令的输出通过给 `lp` 等命令来打印输出。

以下是可以用于 `pr` 命令的一些标志：

- `-d`：以双倍间距生成输出。

- `-h "heading"`：在每页页眉上打印标题而不是文件名。

- `-r`：抑制诊断消息。
- `-t`：抑制打印页眉和页脚。
- `-width`：指定每页的宽度为 `width`，而不是默认的 72。
- `+pagenumber`：指定显示应从页码 `pagumber` 开始，而不是从 1 开始。
