
下表显示了实例 `i` 的特殊属性：

| 属性 | 描述 |
| --- | --- |
| `i.__class__` | 实例所属的类 |
| `i.__dict__` | 存储实例数据的字典 |

`__dict__` 属性是标准做法，所有与实例相关的数据都存储在这里。当值存储在此处时。然而，如果用户定义的类使用了 `__slots__`，则会使用更高效的内部表示，实例将不会有 `__dict__` 属性。关于对象和 Python 对象系统的更多详细信息可以参阅第 7 章。

## 模块

模块是一个容器，保存了通过 `import` 语句加载的对象。当程序中出现 `import foo` 语句时（例如），名称 `foo` 被赋值给相应的模块对象。模块定义了一个命名空间，该命名空间是通过属性 `__dict__` 访问的字典实现的。每当引用模块的属性（使用点运算符）时，它会被转换为字典查找。例如，`m.x` 等同于 `m.__dict__['x']`。同样，对属性的赋值（如 `m.x = y`）等同于 `m.__dict__['x'] = y`。可用的属性如下：

| 属性 | 描述 |
| --- | --- |
| `__dict__` | 与模块关联字典 |
| `__doc__` | 模块文档字符串 |
| `__name__` | 模块名称 |
| `__file__` | 加载模块的源文件 |
| `__path__` | 完全限定的包名，仅当模块对象引用包时定义 |

## 代码对象

代码对象代表原始编译后的可执行代码、字节码，它们通常由内置的 `compile()` 函数返回。代码对象与函数相似，不同在于它们不包含代码定义所在命名空间的任何上下文，代码对象也不存储默认参数值的信息。代码对象 `c` 具有以下只读属性：

| 属性 | 描述 |
| --- | --- |
| `c.co_name` | 函数名。 |
| `c.co_argcount` | 位置参数的数量（包括默认值）。 |
| `c.co_nlocals` | 函数使用的局部变量数量。 |
| `c.co_varnames` | 包含局部变量名称的元组。 |
| `c.co_cellvars` | 包含嵌套函数引用的变量名称的元组。 |
| `c.co_frevars` | 包含嵌套函数使用的自由变量名称的元组。 |
| `c.co_code` | 表示原始字节码的字符串。 |
| `c.co_consts` | 字节码使用的字面量量。 |
| `c.co_names` | 字节码使用的名称。 |
| `c.co_filename` | 编译代码的文件名。 |
| `c.co_firstlineno` | 函数的第一行。 |
| `c.co_notab` | 编码到行号的偏移量。 |
| `c.co_stacksize` | 所需的栈大小（包括局部变量）。 |
| `c.co_flags` | 整数解释器标志。如果函数使用 `*args` 使用位置参数，则设置第 2 位。如果函数允许使用 `**kwargs` 使用任意关键字参数，则设置第 3 位。 |

## 回溯对象

回溯对象在异常发生时创建并包含堆栈跟踪信息。进入异常时，可以使用 `sys.exc_info()` 函数检索堆栈跟踪。以下是只读属性：

| 属性 | 描述 |
| --- | --- |
| `t.tb_next` | 堆栈跟踪的下一层 |
| `t.tb_frame` | 当前层的执行帧 |
| `t.tb_lineno` | 异常发生的行号 |
| `t.tb_lasti` | 执行的指令 |

## 生成器对象

当生成器函数被调用时（参见第 6 章，“函数与函数式编程”）创建生成器对象。每当函数使用 `yield` 关键字时就会定义生成器函数。生成器对象既是迭代器也是生成器信息的容器。以下属性和方法：

| 属性 | 描述 |
| --- | --- |
| `g.gi_code` | 生成函数的代码对象。 |
| `g.gi_frame` | 生成函数的执行帧。 |
| `g.gi_running` | 表示生成器当前是否运行的整数。 |
| `g.next()` | 执行到下一个语句并返回值（该方法在 Python 3 中调用 `__next__`）。 |
| `g.send(value)` | 向生成器发送值。传递的值由生成器中下一个 `yield` 表达式返回。`send()` 返回在该表达式中的值。 |
| `g.close()` | 通过在生成器函数中抛出 `GeneratorException` 关闭生成器。此方法在生成器垃圾回收时自动执行。 |
| `g.throw(exc, [exc_value, exc_tb])` | 在生成器的 `yield` 语句处抛出异常。`exc` 是异常类型，`exc_value` 是异常值，`exc_tb` 是可选的回溯。如果产生的异常被捕获并处理，则返回给下一个 `yield` 语句的值。 |

## 切片对象

切片对象用于在扩展切片语法中表示切片，例如 `a[i:j:stride]`、`a[i:j, n:m]` 或 `a[..., i:j]`。切片对象也可以通过内置的 `slice(i, j, [stride])` 函数创建。以下是只读属性：

### 第 3 章 类型与对象

| 属性 | 说明 |
| --- | --- |
| `s.start` | 切片的下界；如果省略则为 None |
| `s.stop` | 切片的上界；如果省略则为 None |
| `s.step` | 切片的步长；如果省略则为 None |

切片对象提供了一个简单易的方法 `s.indices(length)`。该函数接受一个长度并返回一个元组 `(start, stop, stride)`，指示该切片如何应用于长度为该长度的序列。这里是一个示例：

```
s = slice(10,20)      # 切片对象代表 [10:20]

s.indices(10)             # 返回 (10,20,1) -> [10:20]

s.indices(15)             # 返回 (10,15,1) -> [10:15]
```

## Ell圆对象 (Ellipse Object)

Ellipse对象用于表示索引查找中存在省略号 `...`。该类型只有一个对象，通过内置名称 `Ellipsis` 访问。它没有属性，且求值为 True。Python 的内置类型没有使用 Ellipsis，但如果你正尝试为你的对象在索引运算符 `()` 中构建功能，它可能会很有用。以下代码展示了如何创建 Ellipse 并将其传递给索引运算符：

```python
class Example(object):
    def __getitem__(self, index):
        print(index)

e = Example()
e[3, ..., 4]      # 调用 __getitem__((3, Ellipsis, 4))
```
