
- `type [command]`：打印命令的类型（例如，`pwd` 是一个内置 shell 命令）。
- `typeset`：与 `declare` 相同。设置变量并赋予其属性。
- `ulimit`：显示并设置进程资源限制。
- `umask [octal digits]`：设置用户文件创建模式掩码，针对所有者、组和其他用户。
- `unalias`：取消别名设置。
- `unset [name]`：取消变量或函数的值。
- `wait [pid|n]`：等待 PID 号为 `n` 的后台进程并报告终止状态。

a. 选项适用于 `bash` 2.x 及更高版本。
