## 使用 KMail

使用 KDE 桌面面的 Linux 发行版通常提供 KMail 应用程序用于访问电子邮件。KMail 是另一个类似于 Evolution 的全功能软件包——它在同一个窗口内提供了电子邮件客户端、日历和任务调度器。

本节将介绍让 KMail 软件与你的 ISP 邮件服务器协同工作所需的步骤，然后向你如何发送和接收电子邮件。
