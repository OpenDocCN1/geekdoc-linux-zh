## RAII

![](img/c36cc1b69ac7baa75db5d13135bb9d30_246_0.png)

最后，RAII 范式专门用于管理资源，包括内存。

### RAII 定义

```cpp
struct Resource {
  Resource Acquisition Is Initialization
  Resource() {
    // 获取资源，例如 new
    // 初始化资源，例如将内存值置为 0
  }
  // 资源释放
  ~Resource() {
    // 释放资源，例如 delete
  }
}
```

RAII 结构体在其构造函数中封装了同步的“原子性”资源获取与初始化，并在析构函数中包含了资源释放逻辑。

代码示例：

```cpp
struct Resource {
  Resource() {
    // 获取资源，例如 new
    // 初始化资源，例如将内存值置为 0
  }
  ~Resource() {
    // 释放资源，例如 delete
  }
}
```

### RAII 优势

```cpp
RAII  Advantages

* 资源安全
void foo() { Resource r; }

* 资源生命周期可预测

* 异常安全

try {
    Resource r;
    throw -1;
} catch (...) {
}
```

使用 RAII 范式有几个优势。当离开作用域时，由于析构函数的调用，资源会自动释放：

```cpp
void foo() { Resource r; }
```

在存在异常的情况下，析构函数会自动释放已获取的资源。这些因素共同贡献了可预测的资源生命周期。

```cpp
try {
    Resource r;
    throw -1;
} catch (...) {
}
```

### 文件描述符 RAII

```cpp
struct RAII_FD : FD
{
    RAII_FD(int _fd) : FD(&fd, fdDeleter), fd(_fd) {};
    void operator=(int _fd) { 
        FD::reset(); 
        fd = _fd;
        FD::reset(&fd); 
    }
    operator int() const { return fd; }
private:
    int fd;
};

int foo ()
{
    RAII_FD fd = ::open(...);
    if (fd == -1)
        // return -1;
    return 0;
}
```

### C/C++ 中的线程

```cpp
void *thread_proc (void *arg) {
```
