## 其他需要考虑的事

这组 shell 脚本对许多企业都有用，但你可能根据自己的环境对这些 shell 脚本进行调整。接下来的章节列出了你可能想要考虑的一些选项。

## 使用命令行开关控制执行

通过使用 `getops` 解析命令行选项，你可以修改这些 shell 脚本，使得所有变量都能通过命令行中的开关和开关参数进行赋值。这种修改允许你指定目标主机、本地和远程工作目录，以及要操作的文件。我们在书中多次使用了 `getops`，因此请查看其他一些使用 `getops` 解析命令行开关的章节，并尝试作为练习对其进行一些修改。

## 留存活动日志

记录每次连接的日志并检查返回码是一个非常好的主意。如果你使用 `ftp -v`，你将获得关于每个事务连接活动的详细说明。记住在每个日志条目中添加时间戳，并记住定期修剪日志，以防文件系统填满。

## 为脚本添加调试模式

如果连接失败，你可以通过添加一个名为 `debug` 的函数将脚本放入调试模式。在这个函数中，首先要做的是 ping 远程机器以查看它是否可以访问。如果无法通过 ping 访问机器，那么尝试 ftp 到远程机器是徒用的。

你也可以在开启调试选项执行 `ftp` 命令，通过 `-d` 开关指定。有关 ftp 调试模式的更多信息，请参 `ftp` 命令的 man 页。

## 查找“大”文件

文件系统警告！我们都讨厌收到文件系统满的警告，特别是在周五下班时，当时开发者正试图赶截止日期。通常的罪祸首是一个或多个刚刚创建、编译或加载的大文件。大文件的定义因系统环境而异，但“大”文件可以很快填满文件系统，尤其是在开发环境中。为了找到这些大文件，我们需要一个灵活的工具来搜索大于用户定义的值的文件。需要搜索文件系统时，`find` 命令是你的朋友。

`find` 命令是系统中最灵活、强大的命令之一。在我们开始之前，打印 `find` 命令的手册页。输入以下命令：

```
man find | lp -d print_queue_name
```

上命令会将主页输出打印到由 `print_queue_name` 定义的打印机。通过学习 `find` 手册，你可以看到 `find` 命令是系统中最灵活的命令。你可以通过修改/创建时间、最后访问时间、精确大小、大于大小、所有者、组、权限以及大量其他选项来查找文件。你还可以使用 `-exec` 命令开关执行一个命令来对文件进行操作。对于本章，我们将集中在查找大于命令行指定的整数值的文件上。与我们所有的 shell 脚本一样，我们首先需要为我们的任务获取正确的命令语法。

## 语法

我们将为 `find` 命令使用 `-size` 选项。在使用 `-size` 命令开关时有两点需要考虑。我们必须为此开关提供一个参数，且该参数必须是一个整数。但作为 `-size` 开关参数的整数指定的是一个*精确*值，且该值是以 512 字节块为单位表示的，而不是按字节测量大小。为了获得更熟悉的测量单位，我们希望以兆字节（MB）为单位指定搜索值。要指定以 512 字节块为单位的字节，可以在整数值后添加字符 `c` 作为后缀，要获得 MB，我们可以添加六个零。我们还想查看**大于**命令行值的值。要指定大于，我们在整数值前添加 `+`（加号）作为前缀。根据这些指定，命令看起来像像：

```
find $SEARCH_PATH -size +integer_value -print
```
