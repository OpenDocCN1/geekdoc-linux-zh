Intel IA32 CPU Microcode Utility The `microcode_util` is the IA32 microprocessor driven by Ivan Aravigian<ivan@veritas.com>. The utility has two uses:

a) decodes and sends microcode to the kernel to be loaded to Intel IA32 families. (Pentium Pro, PII, Celeron, Xeon, Pentium 4 each)

b) allows the kernel driver to release any buffer after it may Hold The microcode update is volatile and needs to be reloaded on each boot i.e. doesn't re-flash the CPU permanently, but it reverts back to the old microcode. The ideal place to load microcode in BIOS, but most never update it! To enable microcode, it need some kernel support, thus I needs the kernel 2.2.8 or later, or 2.4.0 or later. From Debian 3.0 APT
