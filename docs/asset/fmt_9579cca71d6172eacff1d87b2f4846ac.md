
`XIMAnimationStyle` 在其 `count_styles` 字段中包含支持的输入样式数量。这也是 `supported_styles` 数组的大小。

支持的样式是一个位掩码列表，指示了每个支持区域的样式组合。这些区域在后文中分别描述。列表中的每个元素都应为每个区域选择一个位掩码值。列表描述了支持的完整组合集。输入法仅支持这些组合。

预编辑（preedit）类别定义了输入法对预编辑信息（preedit information）提供了何种类型的支持。

### XIMPreeditArea
如果选择此项，输入法将要求客户端为其预编辑提供某些区域值。请参考 `XIC XArea` 和 `XNAreaNeeded`。

### XIMPreeditPosition
如果选择此项，输入法将要求客户端提供位置值。请参考 `XIC XNSpotLocation` 和 `XFocusWindow`。

### XIMPreeditCallbacks
如果选择此项，输入法将要求客户端定义一组预编辑回调。请参考 `XIC XNAPreeditStartCallback`、`XNAPreeditNoneCallback`、`XNAPreeditDrawCallback` 和 `XPreeditCaretCallback`。

### XIMPreeditNothing
如果选择此项，输入法可以在没有任何预编辑反馈的情况下运行。任何预编辑值都将被忽略。此样式与其他预编辑样式互斥。

### XIMPreeditNone
输入法不提供任何预编辑反馈。任何预编辑值都将被忽略。此样式与其他预编辑样式互斥。

状态（status）类别定义了输入法对状态信息（status information）提供了何种类型的支持。

### XIMStatusArea
输入法要求客户端提供某些区域以便以便进行状态反馈。见 `XNArea` 和 `XNAreaNeeded`。

### XIMStatusCallbacks
输入法要求客户端定义一组状态回调：`XIMStatusStartCallback`、`XIMStatusDoneCallback` 和 `XIMStatusDrawCallback`。

### XIMStatusNothing
输入法可以在没有任何状态值的情况下运行。

### XIMStatusNone
输入法不提供任何状态反馈。如果选择此项，任何状态值都将被忽略。此样式与其他状态样式互斥。

## 资源名称与类

`XResourceName` 和 `XResourceClass` 是字符串，用于指定输入法使用的全名和类。在查找可能随输入法而变化的资源时，这些值应用作名称和类的前缀。如果未设置这些值，资源将无法完全指定。

设计意图并非将 XIM 值的值设置为资源。

## 销毁回调

`XNDestroyCallback` 参数是一个指向类型为 `XIMCallback` 的结构的指针。当输入法停止服务时，会触发 `XNDestroyCallback`。在调用回调后，输入法将关闭，关联的输入上下文将由 Xlib 销毁。

该回调的通用原型为：

```c
void DestroyCallback(XIM im, ClientData client_data, CallData call_data);
```

- `im`：指定输入法。
- `client_data`：额外的客户端数据。
- `call_data`：此回调不使用，始终传递为 NULL。

# 查询 IM/IC 值列表

`XQueryIMValuesList` 和 `XQueryICValuesList` 用于查询输入法支持的 XIM 和 IC 值。

参数值可能是一个指向返回值存储位置的指针。返回值是一个指向类型为 `XIMValuesList` 的结构的指针。客户端负责释放 `XIMValuesList`。请使用 `XFree` 进行释放。

```c
typedef struct {
    unsigned short count_values;
    char **supported_values;
} XIMValuesList;
```

## 可见位置

`XVisiblePosition` 参数指示 `XIMFeedback` 中的可见位置掩码是否可用。

参数必须指向返回值存储位置的指针。返回值的类型为 `Bool`。输入法使用 `XIMFeedback` 中的可见位置掩码；否则不使用掩码。

由于此 XIM 是可选的，客户端应调用带有参数 `XQueryIMValuesList` 的函数。如果 `XQueryIMValuesList` 返回的 XIM 值列表中不存在 `XVisiblePosition`，则 `XIMFeedback` 中的可见位置掩码将不被使用。

# 预编辑回调行为

最初包含在 X11R6 规范中的 `XNRPreeditCallback` 参数已废弃。在 X11R6 规范的制定过程中，R6PreeditDrawCallbacks 的行为将与 R5 回调有显著不同。规范的更改合并了 R5 和 R6 的行为，消除了对 `XNR6PreeditCallback` 的需求。遗憾的是，该参数在规范发布前未移除。

`XNRPreeditCallback` 参数指示返回 `XIMPreeditDrawStruct` 值的预编辑回调行为遵循 Release 5 还是 6 语义。

该值类型为 `Bool`。查询 `XNRPreeditCallback` 时，如果返回 True，输入法使用 Release 6 行为；否则使用 Release 5 行为。默认值为 False。为了使用 Release 6 语义，必须将 `XNR6PreeditCallback` 的值设置为 True。

## 输入上下文函数

输入上下文是一种抽象，用于包含输入法所需的（如果有）数据以及显示这些数据所需的信息。

# 语言区域与国际化文本函数

一个输入法可能对应多个输入上下文。用于创建、读取或修改输入上下文的编程接口使用变长列表。参数列表中的名称元素称为 XIC 值。设计意图是通过这些 XIC 值来控制输入法。创建了新的 XIC 值后，应向 X 联盟（X Consortium）注册。

要创建一个输入上下文，使用 `XCreateIC`。

```
XIC XCreateIC(im);
```

`im`：指定输入法。
... 指定映射到 XIC 值的变长参数列表。

`XCreateIC` 函数在指定的输入法内创建一个上下文。

某些参数在创建时是强制性的，如果未提供这些参数，将不会创建输入上下文。强制性参数是输入样式和文本回调集（如果输入样式需要回调）。所有其他输入上下文值都可以在稍后设置。

如果无法创建输入上下文，`XCreateIC` 将返回 NULL 值。由于以下任何原因都可能返回 NULL 值：

- 设置了必需的参数。
- 设置了只读参数（例如 `XNFilterEvents`）。
- 参数不被识别。
- 输入法遇到了依赖于实现的错误。

`XCreateIC` 可以产生 `BadAtom`、`BadColor`、`BadPixmap` 和 `BadWindow` 错误。

要销毁输入上下文，使用 `XDestroyIC`。

```
void XDestroyIC(ic);
```

`ic`：指定输入上下文。

`XDestroyIC` 销毁指定的输入上下文。

为了就客户端侧键盘焦点的变化与输入法进行通信和同步，使用 `XSetFocus` 和 `XUnsetICFocus`。

```
void XSetFocus(ic);
```

`ic`：指定输入上下文。

`XSetFocus` 函数允许客户端通知输入法，附加到指定输入上下文的焦点窗口已接收键盘焦点。输入法应当采取行动提供适当的反馈。完整的反馈规范取决于用户界面策略。

调用 `XSetFocus` 不会影响焦点窗口的值。

```
void XUnsetICFocus(ic);
```

`ic`：指定输入上下文。

`XUnsetICFocus` 函数允许客户端通知输入法，指定的输入上下文拥有键盘焦点，且不再预期附加到该输入上下文的焦点窗口上有更多输入。输入法应当采取行动提供适当的反馈。完整的反馈取决于用户界面策略。

调用 `XUnsetICFocus` 不影响焦点窗口；客户端可能会接收来自输入法并指向焦点窗口的事件。

要将输入上下文的状态重置为初始状态，使用 `XmbResetIC` 和 `XwcResetIC`。

```
char *XmbResetIC(ic);
```

```
wchar_t *XwcResetIC(ic);
```
