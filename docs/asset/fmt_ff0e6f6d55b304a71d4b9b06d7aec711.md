# SNMP (Simple Network Management Protocol)

Internet 基础设施由许多分布在各处的设施组成。`SNMP` 是允许“管理”所有这些的方法。我所说的“管理”是指监控通过设备的流量大小、在发生故障时触发报警、远程更改设备配置等。关键点：设备带有公共和私有的默认密码（又名团体字符串）。这些允许你从设备读取信息（流量、温度、电压等）并对其进行重新配置。关键点：一种常用技术是追溯到害者的拨号机器，从而发现他们拨入硬件的 IP 地址。然后，你可以使用带有“private”团体字符串的 `SNMP` 命令让硬件断开害者的连接。此外，垃圾邮件发送者已使用这种技术来寻找用户的真实登录名。来自 Hacking-Lexicon `http://www.tld.org/LDP/linux-Dictionary/html/index.html`

# snmptrapd

# snooper
