## 在 `if` 语句中使用条件表达式

你可以在 `if` 语句中使用条件表达式而不仅仅是命令。使用条件表达式允许你比较数字、进行字符串比较并执行替换。条件表达式采用以下通用形式：

```
[[ conditional expression ]]
```

这是测试值是否相等、大于、小于或不相等的地方。（额外的表达式请参考第 3 章和主页。）
