
# 一个将 Microsoft PowerPoint .ppt 文件转换为 HTML 的程序

`pphtml` 程序将 PowerPoint 97 作为输入并转换为 HTML。输出通过标准输出，因此可以重定向到管道或作为网关。源自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`。

## PPTP

点对点隧道协议 (MS, Ascend, IP)。源自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## PPTP

点对点隧道协议 – 一种允许互联网作为安全虚拟网络 (VPN) 的网络技术。源自 Linux Guide @FirstLinux `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## pptp-linux

微软点对点隧道协议 (`PPTP`)。允许连接到基于 `PPTP` 的 VPN 以及某些电缆和 ADSL 服务提供商。需要内核支持 `MPPE`，请使用 `kernel-patch-mppe` 软件包。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`。

## ppptpd

`PPoTP` 点对点隧道服务器实现了一个与微软 VPN 客户端兼容的虚拟网络服务器 (VPN)。它允许 Windows 通过拨号连接到防火墙网络。源自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`。

## PPU

外处理器单元。源自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## ppxp-applet

`PpXP` GNOME 面板控制台。GNOME 面板控制台。`PpXP` 是另一个 `ppp` 程序。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
