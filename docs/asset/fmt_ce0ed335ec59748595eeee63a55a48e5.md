## PERL 命令: `kill`

对应的 BASH 或 KSH 命令: `kill`

目的: 终止进程。

更多信息: `'man kill'`, `'perdoc -f kill'`

示例:

- ksh 或 bash: `kill -9 1234`
- Perl: `kill 9, 1234`

在 Perl 中，如果“信号”（例如 `-9`）为负数，它会杀掉一个“进程组”而不是单个进程；因此，你不应该使用负号！
