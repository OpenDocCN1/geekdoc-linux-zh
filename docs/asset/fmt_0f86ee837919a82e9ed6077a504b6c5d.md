
复合字符串（compound string）是 Motif 表示字符串的自然用语。对于典型的 C 程序，以空结尾的数组表示字符串。在 Motif 中，字符串由其使用的字符集定义，并保存在 `XmString` 中。为了从普通的 C 字符串获取复合字符串，使用以下函数：`XmStringCreate(char *text, char *tag)`。它返回一个给定空结尾 C 字符串和 `tag` 的等效复合字符串。`tag` 指定使用的字体列表，默认为使用默认值。C 字符串中的换行符必须由 Motif 中的特殊分隔符处理。创建字符串并保留换行符使用此调用：`XmStringCreateTable(char *text, char *tag)`。复合字符串像其他对象一样被创建和销毁。它们在创建它们的调用之后仍然存在。因此，在返回之前释放本地使用的 `XmStrings` 是好主意，否则字符串的引用将丢失。释放 `XmString` 的声明如下：你可以在 ASCII 程序下运行字符串操作，只是名称不同。使用 `Boolean XmByteCompare(XmString s1, XmString s2)` 进行严格的字节比较。对于文本比较，使用 `XmStringCompare(XmString s1, XmString s2)`。

检查字符串是否为空，使用以下：`Boolean XmStringEmpty(XmString s1)`。

要合并两个字符串，使用以下：`XmStringConcat(XmString s1, XmString s2)`。它通过将 `s2` 拼接到 `s1` 创建一个新的字符串。这个新资源必须像 `s1` 和 `s2` 一样被释放。

如果你想使用 `sprintf`，对临时缓冲区使用它并创建一个新字符串。例如：

```c
char str[32];
XmString xms;
......
sprintf(str, "pi = %lf, Area = %lf", PI, TWOPI);
xms = XmStringCreateTable(str, XmFONIST_DEFAULT_TAG); ......
n = 0;
XtSetArg(arg[n], XmNlabelString, xms); n++;
XtSetValues(someLabel, arg, n);
XmStringFree(xms);
```

字符串值随时间损坏，检查控件是否没有复制传递的 `XmString`。有时控件只保留 `XmString` 指针。如果该字符串被“释放”，控件可能会指向错误数据。

检查的一种良好方法是设置 `XmString` 资源。然后使用 `XtGetValues` 函数从控件获取相同的资源。如果 `XmStrings` 的值相同，则控件没有为自己创建副本。如果它们不同，则释放原始是安全的，因为控件正在创建本地副本。默认操作是假设控件为自己创建此类资源的副本。

可以使用类似的测试来确定控件是否返回其资源的指针。使用前面的列表，但这次使用 `XtGetValues` 两次获取相同的资源。然后进行比较。

```c
/**
 * 这是一个示例部分列表，用于检查
 * XtGetValues 和 XtSetValues 调用返回的数据
 * 是副本还是引用。
 */
#include "Xm/Text.h"

..Widget w;
XmString x1, x2, x3;
x3 = XmStringCreateTable("test", XmFONTLIST_DEFAULT_TAG); XmTextSetString(w,x3);
...
x1 = XmTextGetString(w);
x2 = XmTextGetString(w);
XtWarning(" Checking SetValues");
if (x1 != x3)
    XtWarning("Widget keeps a copy ! Free original!");
else
    XtWarning("Widget does not keep a copy! Do NOT free original");
XtWarning(" Checking GetValues");
if (x1 == x2)
    XtWarning("Widget returns a copy! Do NOT free");
else
    XtWarning("Widget does not return a copy! You should free it ");
```

`XtWarning()` 消息对于调试程序的执行特别有用。消息被传递到调用应用程序的 `stderr`。如果这是一个 `xterm`，你将在该终端窗口看到错误消息。如果调用者没有可用的 `stderr`，消息将丢失。

**提示:** `XtSetArg` 宏定义为：

```
#define XtSetArg(arg,n,d) \
 ((void)((arg).name = (n).(arg).value = (XtArgVal)))
```

不要使用 `XtSetArg(arg[n++], ...`，因为会导致 `n` 增加两次。

## Label

Label 组件用于显示字符串或*位图 (pixmaps)*。在使用此组件之前，请在源文件中包含 `Xm/Label.h` 文件。该组件的资源包括：

- `XmNalignment`: 该资源决定小部件内文本的对齐方式。允许的值为 `XmALIGNMENT_END`、`XmALIGNMENT_CENTER` 和 `XmALIGNMENT_BEGIN`，分别对应右对齐、居中对齐左对齐。

- `XmNrecomputeSize`: 布尔资源。如果设置为 TRUE，当字符串或位图的大小动态变化时，小部件将调整大小。这是默认值。如果设置为 FALSE，小部件将不会尝试调整自身大小。

- `XmNlabelType`: 该类型的默认值为 `XmSTRING`，用于显示字符串。然而，当显示 `XmNpixmap` 资源中指定的位图时，也可以将其设置为 `XmPIXMAP`。

- `XmNlabelPixmap`: 用于指定当 `XmNlabelType` 设置为 `XmPIXMAP` 时使用哪个位图。

- `XmNlabelString`: 用于指定用于标签的 `XmString` 复合字符串。默认值是标签的名称。请参见本章稍后的“Motif 中的字符串：复合字符串”部分。

要了解标签的左对齐和右对齐，请参阅 CD-ROM 上的 `2_2`。此列表还展示了如何通过编程和通过 `.Xresource` 文件设置资源来更改小部件参数。

避免在标签名称中使用 `\n`。如果你必须创建一个多字符串小部件，请使用 `XmStringCreateLtoR` 调用来创建一个复合字符串。设置字符串的另一种方法是在资源文件中指定它，然后合并资源。

列表显示了要右对齐的标签。你可以通过不指定对齐方式并让其默认为中心值，轻松地使字符串水平居中。或者，尝试将对齐参数设置为 `XmALIGNMENT_BEGINNING` 以实现左对齐标签。

## List

List 组件显示项目列表，用户可以从中进行选择。列表由一组复合字符串创建。用户可以从此列表中选择一个或多个项目。该组件的资源包括：

- `XmNitemCount`: 决定列表中的项目数量。

- `XmNitems`: 复合字符串数组。每个条目对应列表中的一个项目。注意，当使用 `XtSetValues` 时，List 组件会对其列表中的所有项目拷贝；但在返回值给 `XtGetValues` 调用时，它会返回指向其内部结构的指针。因此，不要从 `XtGetValues` 释放此指针。

- `XmNselectedItemCount`: 当前选择的项目数量。

- `XmNselectedItems`: 选中项目的列表。

- `XmNvisibleItemCount`: 同时显示的项目数量。

- `XmNselectionPolicy`: 用于设置单选或多选能力。如果设置为 `XmSINGLE_SELECT`，用户只能选择一个项目。每次选择都会调用 `XmNsingleSelectionCallback`。选择一个项目将取消之前选中的另一个项目。如果设置为 `XmEXTENDED_SELECT`，用户可以选择列表中一组连续的项目。选择一个或多个新项目将取消之前选中的其他项目。每次选择都会调用 `XmNmultipleSelection` 回调。

- 如果设置为 `XmMULTIPLE_SELECT`，用户可以按任何顺序选择多个项目。选择一个项目不会取消之前选中的另一个项目。每次选择都会调用 `XmNmultipleSelection` 回调。

- 如果资源设置为 `XmBROWSE_SELECT`，用户可以在按下按钮的情况下跨所有选择项移动指针，但只会选中一个项目。当按钮在最后一个浏览的项目上释放时，将调用 `XmbrowseSelectionCallback`。与 `XmSINGLE_SELECT` 设置不同，用户不需要按下并释放按钮来选择项目。
