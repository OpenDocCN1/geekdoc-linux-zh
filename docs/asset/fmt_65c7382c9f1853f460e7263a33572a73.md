## 23.1.6 推出音频 CD

使用 `cdject` 弹出 CD–ROM 驱动器中的光片。如果光片正在播放，它将停止并弹出光片。

- 要推出 CD，输入：

```
$ cdject RET
```

**注意：** 如果 CD–ROM 当前未挂载在 `section CD–ROMs` 部分，此命令也将弹出 CD–ROM（数据 CD）。

## 24.1 处理音频文件中的选择
