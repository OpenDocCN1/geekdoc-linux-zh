# 前言

从诞生之初，`LINUX` 已经在大型场所的服务器上——业务数据中心、校园网络、研究集群——找到了自然的归宿。`LINUX` 的高可靠性，加上“如果出现问题，你可以自己修复”的保证，使其对那些工作过载且预算不足的系统管理员具有巨大的吸引力。

尽管 `LINUX` 处处可用，但直到最近，它对核心硬件的渗透一直是一个相当隐蔽的过程。通常，系统管理员会更换运行其他操作系统的提供 `Web` 服务、邮件、`DNS` 或文件共享服务的机器，而没有在管理上进行任何改进。在大多数情况下，性能和运行时间的剧增被除了系统管理员以外的所有人看作是理所当然的，而管理员只要因为少接了凌晨 3:00 的呼传机电话而感激不尽了。

这本书是 Linux 变得“不再隐身”的标志。在过去的 18 个月里，Linux 赢得了足够的声誉，进入了管理层认可的工具箱。那些一直在使用它的精明管理员正从衣柜里搬出 Linux 机器，而许多其他人也开始第一次尝试它。

这本书既是经验丰富的 `LINUX` 管理员的参考书，也是新手的者的指南。它提炼了作者在应对现实挑战时丰富的实战经验——包括 Jim Dennis 在《`LINUX` Gazette》中以其“答疑专家”身份所积累的所有知识。

掌握了书中的知识，你应该能够像专业人士一样配置、部署和保护 `LINUX` 机器。这会让你的生活变得更容易。它还将加速那一天的到来，你可以对老板说：“`NT`？`Windows`？`Novell`？是时候抛弃那些遗留软件了；它们的性能根本不……”

征服它们。而且也要玩得开心！

**Eric S. Raymond**

# 前言

这个世界上针对技术读者的技术书籍比针对非技术读者的技术书籍要多得多。作为技术读者，系统管理员有大量的关于系统管理的技术书籍可供选择。但这些书籍是不够的，因为系统管理的工作只有一半是技术性的。

在深入系统管理的技术细节之前，这本书满足了技术读者对一本非技术性书籍的需求。第一部分从全局视角概述了系统管理，涵盖需求分析、恢复计划、容量规划、网络原理和安全策略。目标读者是来自其他背景（如编程或金融）的专业系统管理员。

第一部分对于对系统管理感兴趣的读者来说都是易读的。因此，对于想要知道系统管理员在不在时在做什么的程序员和其他用户，以及想要理解孩子职业做什么的系统管理员的父母来说，它是理想的。

第二部分从微观视角审视系统管理的各个方面。它是面向系统管理员的实用指南，而不考虑他人的易读性。某些程序员、网络管理员和数据库管理员可能对第二、第三部分感兴趣，但对于不负责 `LINUX` 系统实际管理的非技术经理和其他人，可以直接跳到术语表。

第三部分概述了系统和应用程序所依赖的主要服务。大多数系统管理员会发现这些服务对于履行职责至关重要：电子邮件、打印、`NFS`、`NIS` 以及各种网络服务。

最后，在 Linux 管理过程中可能出现的紧急情况指南作为附录包含。我们希望大多数读者很少需要它。
