# 柏属

柏属（Cupressus）在植物学上与杉属（Chamaecyparis）相似。美国所有的柏属物种从俄勒冈一直到墨西哥。西南州的亚利桑那柏（Cupressus arizona）和加州的州的蒙特利柏（Cupressus macrocarpa）具有极高价值。意大利柏（Cupressus sempervirens）及其变种是观赏植物，原产于欧洲南部和土耳其。其他树也是柏属，例如波特奥斯福德杉（Chamaecyparis lawsoniana），又称肖松松，以及阿拉斯加雪杉（Thuja plortii），也称为假杉。

圆柱。侧面绕轴旋转形成的固体是圆柱，或更准确地说是直圆柱。更广泛地说，圆柱一词在几何学中用于描述由两个平行平面和一个圆柱表面边界组成的任何固体。在几何学中，圆柱一词既指固体也指圆柱面（见图）。这种表面由直线生成，该直线移动时与平面曲线相交，并保持与交圆柱平面的直线平行。这些轨道轨迹为圆、椭圆、抛物线或双曲线，称为圆柱形、椭圆形、抛物线形或双曲线圆柱。它们都是二次曲面。

# 鲤形目 (Cymoprines)
