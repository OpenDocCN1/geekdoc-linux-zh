
使用“超时”，定义启动加载程序在启动默认系统之前等待项的秒数。可以通过“选项”指定许多其他选项。然而，使用这些选项需要更深入的理解，本文未对此涉及。请参阅《管理指南》中的相关章节以及 GRUB 和 LILO 的手册页（`man grub`、`man lilo` 和 `man lilo.conf`）。此外，GRUB 的详细在线手册可用位于 `http://www.gnu.org/software/grub/`

## 4.85 LVM

逻辑卷管理器 (`LVM`) 是一种通过逻辑驱动单独对硬盘进行分区的工具。由于这是一个真正的专家工具，在本用户指南的范围内不提供额外信息。欲需更多信息，请参阅《管理指南》。

## 4.8.7 配置文件管理器 (SCPM)

`SCPM`（系统配置方案管理）模块提供了创建、管理和切换系统配置的可能性。这对于在不同位置（不同网络）和由不同用户使用的移动计算机特别特别有用。尽管如此，此功能对于固定式机器也有用，因为允许使用各种硬件组件或测试配置。尽管带有帮助文档的模块易于使用，但配置方案是一项应由专家或系统管理员执行的任务。有关 `SCPM` 基础和处理的更多信息，请参阅《管理指南》中的相应章节。

## 4.8.8 运行级别编辑器

`SUSE LINUX` 可以在多个运行级别运行。默认情况下，系统启动到运行级别 5，它提供了多用户模式、网络访问和图形用户界面 (`X Window 系统`)。其他运行级别提供了不带网络的 X 多用户模式（运行级别 3）、不带网络的多用户模式（运行级别 2）、单用户模式（运行级别 1 和 S）、系统停止（运行级别 0）和系统重启（运行级别 6）。

如果在较高的运行级别遇到特定服务（X 或网络）的问题，则各种运行级别将非常有用。在这种情况下，系统可以启动到较低的运行级别进行修复。可以通过 `Ctrl` + `Alt` + `F1` 切换到文本控制台，以 root 身份登录并使用命令 `init 3` 切换到运行级别 3。这将关闭 X。重启图形系统，输入 5。

在默认安装中选择了运行级别 5。通过“运行级别属性”，可以确定在哪些运行级别启动哪些服务。

> 注意 服务和运行级别的错误设置会导致系统失效。为了保持系统的可用性，请在修改这些设置之前考虑可能的后果。

有关 `SUSE LINUX` 运行级别的更多信息，请参阅《管理指南》。

## 4.8.9 Sysconfig 编辑器

`/etc/sysconfig` 目录包含 `SUSE LINUX` 重要设置的文件（以前集中管理在 `/etc/rc.config` 中）。`sysconfig` 编辑器良好的格式显示所有设置。可以修改值并保存到单独的文件。通常不需要手动编辑，因为在安装包或配置服务时，文件会自动调整。

> 注意 如果您不确定自己在做什么，请不要编辑 `/etc/sysconfig` 中的文件，因为可能会严重影响系统的可用性。

更多信息请见《管理指南》。

## 4.10 文本模式下的 YaST2 (ncurses)

`YaST` 也可以通过文本终端进行控制。这对于无法运行 `X Window 系统`或不需要 X 的系统（如专用服务器或防火墙机器）特别有用。它对于管理员远程访问系统也很有帮助。

### 4.10.1 控制

使用方法可能很陌生，但非常简单。基本上，整个程序可以通过 `Tab`、`Alt` + `Tab`、`Space`、方向键 (↑) 和 (↓) 以及快捷键来控制。首先出现的是 `YaST` 控制中心，如图 4.32 所示。

### 4.10.2 键组合的限制

如果您在 X 服务运行时具有系统范围的 `Alt` 键组合，则 `YaST` 中的 `Alt` 组合可能无法工作。此外，`Alt` 或 `Shift` 等键可能被终端设置占用。

将 `Alt` 替换为 `Esc`：`Alt` 快捷键可以使用 `Esc` 代替 `Alt` 执行。例如，`Esc`-H 替换 `Alt`-H。

将后退和向前导航替换为：可以使用 `Ctrl`+F 和 `Ctrl`+B 替换 `Alt` 组合。

限制键组合：如果您在 X 服务运行时具有系统范围的 `Alt` 键组合，则 `YaST` 中的 `Alt` 组合可能无法工作。此外，`Alt` 或 `Shift` 等键可能被终端设置占用。

将 `Alt` 替换为 `Esc`：`Alt` 快捷键可以使用 `Esc` 代替 `Alt` 执行。例如，`Esc`-H 替换 `Alt`-H。
