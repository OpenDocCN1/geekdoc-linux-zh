## 使用 getopts 解析命令行参数

**getopts** 函数是解析命令行参数的器工具。通过 **getopts** 函数，我们可以在找到有效命令行参数时直接采取操作或设置变量。如果无效命令行参数以减号 (`-`) 开头，我们也可以找到它们。**getopts** 函数与包含 **case** 语句的 **while** 循环一起使用。基本语法在列表 10.9 中。

```bash
while getopts :n V: m M: ARGUMENT 2>/dev/null 2>&1
do
    case $ARGUMENT in
        n|N) # 处理 -n 和 -N 的内容
            ;;
        m|M) # 处理 -m 和 -M 的内容
            ;;
        V) # V 后的冒号 (:) 指定
            # -V 在命令行上必须带有一个选项。
            ;;
        \?) # 第一个冒号 (:) 指定任何未知
            # 参数（例如 -A）产生问号 (?) 作为
            # 输出。对于这些未知参数，我们显示用法
            # 消息并带返回码退出。
            ;;
    esac
done
```
