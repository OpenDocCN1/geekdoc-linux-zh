## 命令行管道

重定向主要用于存储命令的结果，以便由另一个命令处理。如果你想让数据经过多个处理过程，这种中间过程可能会变得非常繁琐和复杂。为了避免这种情况，你可以通过管道直接链接命令。换句话说，第一个命令的输出自动成为第二个命令的输入。这种连接是通过 `|`（竖线）运算符实现的：

```
$ cat /etc/password | less
root:x:0:0:root:/bin/bash
daemon:x:1:1:daemon:/usr/bin:/bin/sh
bin:x:2:2:/bin:/bin/sh
:
```

在示例中，管道操作符后的 `less` 命令修改了文件的显示方式。`less` 命令显示文本文件，允许用户一次向上或向下滚动一行。正如之前的课程所述，`less` 也默认用于显示帮助文档（man pages）。

可以同时使用多个管道。接收输入并产生输出的中间命令被称为过滤器。让我们以 `ls -1` 命令来统计输出的前 10 行的单词数。为了实现这一点，我们必须使用 `head` 命令（它默认显示文件的前 10 行），然后使用 `wc` 命令统计单词数：

```
$ ls -1 | head | wc -w
10
```

如前所述，默认情况下，`head` 只显示指定文本文件的前 10 行。这种行为可以通过特定选项进行修改。检查命令的帮助页以获取更多信息。

另一个显示文件末尾的命令是 `tail`。默认情况下，该命令选择最后 10 行并显示它们，但像 `head` 一样，也可以修改行数。检查 `tail` 的帮助页以获取更多详情。

> 注意：`-f` 选项可以在文件更新时显示该文件的行。在监控如 `syslog` 等文件的持续活动时，此功能变得非常有用。

`wc`（word count）命令默认统计文件的行、单词和字节。如练习所示，`-w` 选项导致命令仅统计所选行内的单词。你可以配合此命令的最常用的选项有：`-1`，指定命令只统计行；以及 `-c`，用于仅统计字节。命令的更多变体和选项，以及关于 `wc` 的更多信息可以在命令的帮助页中找到。

### 引导式练习答案

- 1. 列出你当前目录的内容，包括所有者和权限，并将输出重定向到家目录下的 `contents.txt` 文件。

```
ls -l > ~/contents.txt
```

- 2. 对当前目录下的 `contents.txt` 文件进行排序，并将其追加到名为 `contents-sorted.txt` 的新文件末尾。

```
sort contents.txt >> ~/contents-sorted.txt
```

- 3. 显示 `/etc/passwd` 文件的 10 行，并将其重定向到用户 Documents 目录下的新文件中。

```
head -n 10 /etc/passwd > ~/Documents/passwd
```

- 4. 统计 `contents.txt` 文件中的单词数，并将输出追加到家目录下 `field2.txt` 文件的末尾。你需要同时使用输入和输出。

```
wc -w < contents.txt >> ~/field2.txt
```

- 5. 显示 `/etc/passwd` 文件的前 5 行，并按字母反序排序输出。

```
head -n 5 /etc/passwd | sort -r
```

- 6. 使用之前创建的 `contents.txt` 文件，统计最后 9 行的字符数。

```
tail -n 9 contents.txt | wc -c
```

- 7. 统计 `/usr/share` 目录及其子目录中名为 `test` 的文件数量。注意：`find` 命令输出的每一行代表一个文件。

```
find /usr/share -name test | wc -l
```

### 探索性练习答案

- 1. 选择 `contents.txt` 文件的第二个字段，并将标准输出和错误输出重定向到另一个名为 `field1.txt` 的文件。

```
cut -f 2 -d "/" contents.txt > field1.txt
```

- 2. 使用输入重定向运算符和 `tr` 命令，删除 `contents.txt` 文件中的破折号（-）。

```
tr -d "-" < contents.txt
```

- 3. 仅将错误重定向到文件的最大优势是什么？

仅将错误重定向到文件有助于经常监控的日志文件。

- 4. 将字母排序后的 `contents.txt` 文件中的所有重复空格替换为单个空格。

```
sort contents.txt | tr -s " "
```

- 5. 在一条命令行中，消除重复空格（如上一个练习所示），选择第九个字段，并对其按字母反序且不区分大小写进行排序。你需要多少个管道？

```
cat contents.txt | tr -s " " | cut -f 9 -d " " | sort -fr
```

该练习使用了 3 个管道，每个管道对应一个过滤器。

### 使用 grep 搜索文件

在本课程讨论的第一个工具是 `grep` 命令。`grep` 是“global regular expression print”的缩写，其主要功能是在文件中搜索指定的模式。命令将输出包含指定模式的行并高亮显示。
