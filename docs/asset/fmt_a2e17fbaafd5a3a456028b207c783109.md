
# C++ 模板代码示例与分析

## 代码片段：Array 模板类实现

```cpp
template <class T>
Array<T>::Array(const Array &rhs)
{
    itsSize = rhs.GetSize();
    pType = new T[itsSize];
    for (int i = 0; i < itsSize; i++)
        pType[i] = rhs[i];
}

// operator=<class T>
template <class T>
Array<T>& Array<T>::operator=(const Array& rhs)
{
    if (this == &rhs)
        return *this;
    delete [] pType;
    itsSize = rhs.GetSize();
    pType = new T[itsSize];
    for (int i = 0; i < itsSize; i++)
        pType[i] = rhs[i];
    return *this;
}

// driver program
int main()
{
    Array<int> theArray; // an array of integers
    Array<Animal> theZoo; // an array of Animals
    Animal *pAnimal;

    // fill the arrays
    for (int i = 0; i < theArray.GetSize(); i++)
    {
        theArray[i] = i;
        pAnimal = new Animal(i);
        theZoo[i] = *pAnimal;
        delete pAnimal;
    }
    // print the contents of the arrays
    for (int j = 0; j < theArray.GetSize(); j++)
    {
        cout << "theArray[" << j << "]:\t";
        cout << theArray[j] << "\t";
        cout << "theZoo[" << j << "]:\t";
        theZoo[j].Display();
        cout << endl;
    }
    return 0;
}
```

## 模板函数

**输出**  
第 8-26 行提供了一个简化的 `Animal` 类，以便可以将用户定义的类型添加到数组。

**分析**  
第 29 行声明了模板，模板参数为类型 `T`。`Array` 类有两个构造函数，其中一个接收大小并默认为 `DefaultSize`。

声明了赋值运算符和索引运算符，包含 `const` 和非 `const` 版本。提供的访问器只有 `GetSize()`，它返回数组的大小。

可以想象出一个更完整的接口，对于任何严肃的 `Array` 程序，这里提供的是不够的。至少需要删除元素、扩展数组、打包数组等运算符。这些都在本节末尾讨论的 STL 容器类提供。

私有数据包括数组的大小指向内存中实际对象的指针。

如果你想将一个 `Array` 对象传递给函数，必须传递数组的特定实例，而不是模板。因此，如果 `SomeFunction()` 接收整数数组，你可以写：

```cpp
void SomeFunction(Array<int>&); // OK
```

但你不能写：

```cpp
void SomeFunction(Array<T>&); // 错误
```

因为不知道 `T` 是什么。你可能也不会写：

```cpp
void SomeFunction(Array &); // 错误
```

因为没有类——模板和实例。

## 模板函数详解

为了实现更通用的方法，必须声明模板函数。

```cpp
template <class T>
void MyTemplateFunction(Array<T>&); // OK
```

在这里 `MyTemplateFunction()` 通过第一行声明为模板函数。注意与其他函数一样，模板函数可以是任何名称。

模板函数除了参数化形式还可以接收模板的实例。以下是一个示例：

```cpp
template <class T>
void MyOtherFunction(Array<T>&, Array<int>&); // OK
```

注意此函数接收两个数组：一个参数化数组和一个整数数组。前者可以是任何对象的数组，后者始终是整数数组。

## 模板与友元

模板类可以声明三种友元：

- 非模板友类或函数
- 通用模板友类或函数
- 特定类型的模板友类或函数

### 非模板友类和函数

可以将任何类或函数声明为模板类的友元。类的每个实例都会正确处理该友元，就像在该特定实例中进行了声明一样。列表 19.3 在 `Array` 模板定义中添加了一个简单的友函数 `Intrude()`，驱动程序调用了 `Intrude()`。由于它是友元，`Intrude()` 随后可以访问 `Array` 的私有数据。由于这不是模板函数，因此它只能对 `int` 类型的 `Array` 调用。

#### 列表 19.3 非模板友函数

```cpp
// Listing 19.3 - Type-specific friend functions in templates
#include <iostream.h>

const DefaultSize = 10;

// declare a simple Animal class so that we can
// create an array of animals

class Animal
{
public:
    Animal(int);
    Animal();
    ~Animal() {}
    int GetWeight() const { return itsWeight; }
    void Display() const { cout << itsWeight; }
private:
    int itsWeight;
};

Animal::Animal(int weight):
    itsWeight(weight)
{}

Animal::Animal():
    itsWeight(0)
{}

template <class T> // declare the template and the parameter
class Array             // the class being parameterized
{
public:
    // constructors
    Array(int itsSize = DefaultSize);
    Array(const Array &rhs);
    ~Array() { delete [] pType; }

    // operators
    Array& operator=(const Array &rhs);
    T& operator[](int offset) { return pType[offset]; }
    const T& operator[](int offset) const
        { return pType[offset]; }

    // accessor
    int GetSize() const { return itsSize; }

    // friend declaration
    friend void Intrude(Array<int>);

private:
    T *pType;
    int itsSize;
};

// implementations follow...

// implement the Constructor
template <class T>
Array<T>::Array(int size):
    itsSize(size)
{
    pType = new T[size];
    for (int i = 0; i < size; i++)
        pType[i] = 0;
}

// copy constructor
template <class T>
Array<T>::Array(const Array &rhs)
{
    itsSize = rhs.GetSize();
    pType = new T[itsSize];
    for (int i = 0; i < itsSize; i++)
        pType[i] = rhs[i];
}

// operator=<class T>
template <class T>
Array<T>& Array<T>::operator=(const Array& rhs)
{
    if (this == &rhs)
        return *this;
    delete [] pType;
    itsSize = rhs.GetSize();
    pType = new T[itsSize];
    for (int i = 0; i < itsSize; i++)
        pType[i] = rhs[i];
    return *this;
}

void Intrude(Array<int> theArray)
{
    cout << "\n*** Intrude ***\n";
    for (int i = 0; i < theArray.GetSize(); i++)
        cout << "i: " << theArray[i] << endl;
    cout << "\n";
}

// 驱动程序
int main()
{
    Array<int> theArray; // 一个整数数组
    Array<Animal> theZoo; // 一个动物数组
    Animal *pAnimal;

    // 填充数组
    for (int i = 0; i < theArray.GetSize(); i++)
    {
        theArray[i] = i*2;
        pAnimal = new Animal(i*3);
        theZoo[i] = *pAnimal;
        delete pAnimal;
    }

    for (int j = 0; j < theArray.GetSize(); j++)
    {
        cout << "theZoo[" << j << "]:\t";
        theZoo[j].Display();
        cout << endl;
    }

    cout << "现在使用友元函数来 ";
    cout << "查找 Array<int> 的成员";
    Intrude(theArray);

    cout << "*\n\nDone.\n";
    return 0;
}
```

**分析**  
`Array` 模板的声明已扩展，以包含友元函数 `Intrude()`。这声明 `int` 数组的每个实例都将 `Intrude()` 视为友元函数；因此，`Intrude()` 将访问数组实例的私有成员数据和函数。

在 `Intrude()` 函数中，直接访问 `itsSize` 和 `pType`。使用这些方法是没有必要的，因为 `Array` 类为这些数据提供了公共访问器，但它的目的是演示如何用模板声明友元函数。

### 通用模板类或函数

为 `Array` 类添加一个显示运算符将很有帮助。一种方法是为每种可能的 `Array` 类型声明一个显示运算符，但这将破坏创建 `Array` 模板的初衷。

我们需要一个适用于任何可能的 `Array` 类型的插入运算符 `<<`。

```cpp
template<class T>
ostream& operator<<(ostream&, Array<T>&);
```

为了使其工作，你需要将 `operator<<` 声明为模板函数。

```cpp
template<class T>
ostream& operator<<(ostream&, Array<T>&);
```

现在 `operator<<` 是一个模板函数，你只需要提供实现。列表 19.4 显示扩展后的 `Array` 模板，包含了此声明并提供了 `operator<<` 的实现。
