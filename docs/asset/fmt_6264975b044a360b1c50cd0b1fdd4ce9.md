# 19.1 ALSA PCM 类型

从高级 Linux 音频体系 (ALSA) 的 0.9 版本开始，PCM 设备的概念被根本性的修改和扩展。PCM 是“脉冲编码调制”（Pulse Code Modulation）的缩写，在涉及声卡时指定输出接口。用户可以通过选择特定的 PCM 类型来影响 ALSA 寻址声的方式。主要的 PCM 类型是 `hw` 和 `plughw`。

要理解这两个类型的区别，请考虑 PCM 设备是如何打开的。它必须使用以下参数的特定设置打开：采样格式、采样频率、通道数（以前称为片段）和周期大小。例如，应用程序可能会尝试播放采样频率为 44.1 kHz 的 WAV 文件，尽管声卡并不支持此频率。在这种情况下，ALSA 可以自动将插件层（plug-layer）中的数据转换为声卡支持的格式。该转换影响以下参数：采样格式、采样频率和通道数。

通过选择 PCM 类型 `plughw` 激活插件层。如果选择 PCM 类型 `hw`，ALSA 将尝试用应用程序所需的参数直接打开 PCM 设备。PCM 设备的完整标识符由 PCM 类型后跟冒号、卡号和设备号组成，例如 `plughw`。

插件层是 ALSA 最近添加的特性。它允许应用程序共享不支持原生支持该功能的声卡。PCM 设备的完整标识符由 PCM 类型后跟冒号、卡号和设备号组成，例如 `plughw`。

# 19.2 混音器

混音器提供了控制声卡音量和输入的方便方法。PCM 设备的完整标识符由 PCM 类型后跟冒号、卡号和设备号组成，例如 `plughw`。

按下空格键确定录音源。“capture”控制器调节输入放大器。使用“Line”控制器还是“MIC”控制器取决于录音源。

更多信息，请输入 `man alsamixer`。`alsamixer` 是一个具有图形界面、可以通过鼠标操作的 alsamixer 变体。

## 注意

`alsamixer` 的外观和感觉取决于所使用的声卡类型。文中提到的混音器功能参考了 AC97 标准。如果您的声卡不符合此标准，某些功能可能无法支持。对于配备 Envy24 (ice1712) 芯片的声卡，应使用 Envy24 混音器（见第 19.2.7 节）。

## 注意

19.2.6 Soundblaster Live! 和 Audigy 的混音器参数

除了“AC97”标准的参数外，Soundblaster Live! 和 Audigy 声卡还有许多额外选项。“AC97”、“Wave”和“Music”控制器用于播放。“AC97”可用于调整“AC97”混合的电平。该混合信号接收来自“line”、“mic”和“CD”的信号输入。“Wave”调整 PCM 通道的电平。“Music”控制 MIDI 数据内部波表合成的量。

除了用于录音的“Capture”参数外，“AC97 Capture”控制器用于控制“AC97”录音源的电平。此外，“Wave”和“Music”可以被选择录音源。通过选择“Mix”控制器作为录音源，可以在“AC97”标准中激活此内部环路捕获。

### 19.2.7 音芯片 Envy24 的混音器

`envy24control` 是一个用于 Envoy24 (ice1712) 芯片声卡的混音器应用程序。通过“USE”->“Multimedia”->“Sound”启动此混音器，或从命令行通过 `envy24control &` 启动。Envy24 芯片的灵活性导致不同声卡具有不同的功能。关于此音芯片的最新细节，请参阅 `/usr/share/doc/packages/alsa/alsa-tools/envy24control`。
