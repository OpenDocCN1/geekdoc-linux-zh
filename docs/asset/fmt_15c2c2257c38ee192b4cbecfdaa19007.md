
- `display`
指定与 X 服务器的连接。

- `w`
指定窗口。

- `hints_return`
返回 XSizeHints 结构。

- `supplied_return`
返回用户提供的提示。

- `property`
指定属性名称。

`XGetWMSizeHints` 返回指定窗口上指定属性中存储的尺寸。如果该属性类型为 WM_SIZE_HINTS、格式为 32 且足够长以容纳旧的（ICCM 之前的）或新的尺寸提示，`XGetWMSizeHints` 将设置 XSizeHints 属性的各个字段，将 `supplied_return` 参数设置为用户提供的字段列表（或任何未包含定义值的值的内容），并返回非零状态。否则，它返回零状态。要获取窗口的普通尺寸提示，您可以使用 `XGetWMNormalHints` 函数。

如果 `XGetWMSizeHints` 成功返回且存在预-ICCM 尺寸提示属性，则 `supplied_return` 参数将包含以下位：

```
(USPosition|USSize|PPosition|PSize|PMinSize|
PMaxSize|PResizeInc|PAspect)
```

如果属性足够大，能够容纳基础大小和窗口引力字段，则 `supplied_return` 参数还将包含以下位：

```
PBaseSize|PWinGravity
```

`XGetWMMSHints` 可以产生 BadAtom 和 BadWindow 错误。

# 设置和读取 WM_CLASS 属性

XLib 提供了可以使用函数来为给窗口设置和获取 CLASS 属性。这些函数使用了 XClassHint 结构，该结构定义在 `<X11/Util.h>` 头文件中。

要分配 XClassHint 结构，请使用 `XAllocClassHint`。

```
XClassHint *XAllocClassHint();
```

`XAllocClassHint` 函数分配并返回指向 XClassHint 结构的指针。请注意，XClassHint 结构中的指针最初被设置为 NULL。如果可用内存不足，XClassHint 返回 NULL。要释放分配给此结构的的内存，请使用 `XFree`。

XClassHint 包含：

```c
typedef struct {
char *res_name;
char *res_class;
} XClassHint;
```

`res_name` 成员包含应用程序名称，`res_class` 成员包含应用程序类。请注意，该属性中的名称可能与设置为 WM NAME 的名称不同。也就是说，WM NAME 指定了应该在标题栏中显示的内容，因此它可以包含临时信息（例如，当前在编辑器缓冲区中的文件名）。另一方面，作为 WM CLASS 的部分指定的名称是在从资源数据库中检索应用程序资源时应使用的正式名称。

要设置窗口的 WM_CLASS 属性，请使用 `XSetClassHint`。

```
XSetClassHint(display, w, class_hints);
```
`display` 指定与 X 服务器的连接。
`w` 指定窗口。
`class_hints` 指定要使用的 XClassHint 结构。

`XSetClassHint` 函数为指定窗口设置类提示（class hint）。如果字符串不在主机可移植字符编码（Host Portable Character Encoding）中，结果取决于实现。

`XSetClassHint` 可以产生 BadAlloc 和 BadWindow 错误。

要读取窗口的 WM_CLASS 属性，请使用 `XGetClassHint`。

```
Status XGetClassHint(display, w, class_hints_return);
```
`display` 指定与 X 服务器的连接。

`w` 指定窗口。

`class_hints_return` 返回 XClass 结构。

`XGetClassHint` 函数将窗口的类提示返回到提供的结构成员中。如果服务器返回的数据是拉丁可移植字符编码（Latin Portable Character Encoding），则返回的字符串取决于实现。成功时返回非零状态；否则返回零状态。在完成字符串处理后，使用 `XFree` 分别释放 `res_name` 和 `res_class`。

`XSetClassHint` 可以产生 BadWindow 错误。

# 设置和读取 WM_TRANSIENT_FOR 属性

XLib 提供了可以使用函数来为给窗口设置和读取 WM_TRANSIENT_FOR 属性。

要设置窗口的 WM_TRANSIENT_FOR 属性，请使用 `XSetTransientHint`。

```
XSetTransientHint(display, w, prop_window);
```
`display` 指定与 X 服务器的连接。
`w` 指定窗口。
`prop_window` 指定要设置的 WM_TRANSIENT_FOR 属性。

`XSetTransientHint` 设置指定窗口的 WM_TRANSIENT_FOR 属性。

`XSetTransientHint` 可以产生 BadAlloc 和 BadWindow 错误。

要读取窗口的 WM_TRANSIENT_FOR 属性，请使用 `XGetTransientHint`。

```
Status XGetTransientHint(display, w, prop_window_return);
```
`display` 指定与 X 服务器的连接。

`w` 指定窗口。

`prop_window_return` 返回指定窗口的 WM_TRANSIENT_FOR 属性。

`XGetTransientHint` 函数返回指定窗口的 WM_TRANSIENT_FOR 属性。成功时返回非零状态；否则返回零状态。

`XGetTransientHint` 可以产生 BadWindow 错误。

# 设置和读取 WM_PROTOCOLS 属性

XLib 提供了可以使用函数为给窗口设置和读取 WM_PROTOCOLS 属性。

要设置您的 WM_PROTOCOLS 属性，请使用 `XSetWMProtocols`。

```
Status XSetWMProtocols(display, w, protocols, count);
```
`display` 指定与 X 服务器的连接。
`w` 指定窗口。
`protocols` 指定协议列表。
`count` 指定列表的数量。

`XSetWMProtocols` 用 `protocols` 参数指定的原子替换指定窗口上的 WM_PROTOCOLS 属性。如果该属性尚不存在，`XSetWMProtocols` 将根据 `protocols` 参数指定的原子列表在指定窗口上设置 WM_PROTOCOLS 属性。该属性存储的类型为 ATOM，格式为 32。如果无法转换 WM_PROTOCOLS 原子，`XSetWMProtocols` 返回零状态。否则，返回非零状态。

`XSetWMProtocols` 可以产生 BadAlloc 和 BadWindow 错误。

要读取 WM_PROTOCOLS 属性，请使用 `XGetWMProtocols`。

```
Status XGetWMProtocols(display, w, protocols_return, count);
```
