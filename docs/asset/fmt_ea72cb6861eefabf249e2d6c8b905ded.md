
`mkfs` 在设备上构建 Linux 文件系统，通常是硬盘分区。

### `mkfs.bfs`
`mkfs.bfs` 在设备上创建 bfs 文件系统，通常是硬盘分区。

### `mkfs.minix`
`mkfs.minix` 在设备上创建 Linux MINIX 文件系统，通常是硬盘分区。

### `mkswap`
`mkswap` 在设备或文件中设置 Linux 交换区。

### `sfdisk`
`sfdisk` 是一个分区表管理器。

### `swapoff`
`swapoff` 禁用分页和交换的设备和文件。

### `swapon`
`swapon` 启用分页和交换的设备和文件。

# `cal`
`cal` 显示一个简单的日历。
