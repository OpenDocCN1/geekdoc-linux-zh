
M4 是一个宏处理器。它将输入复制到输出，并在过程中展开宏。宏可以是内置的或用户定义的，并且可以接受任意数量的参数。除了执行宏展开，`m4` 还具有内置函数，用于包含命名文件、运行 UNIX 命令、进行整数运算、以各种方式处理文本、递归等。`M4` 可以用作编译器的前端，也可以作为独立的宏处理器使用。

## Texinfo

目录

`Texinfo` 包包含 `info`、`install-info`、`makeinfo`、`texi2dvi` 和 `texindex` 程序

### 描述

`info`

`info` 程序读取 Info 文档，通常位于你的 `/usr/doc/info` 目录。Info 文档类似于手册（man）页，但它们往往比仅仅解释程序的选项更深入。

### install-info

`install-info` 程序更新 info 条目。当你运行 `info` 程序时，将呈现一个可用主题的列表（即：可用 info 文档）。`install-info` 程序用于维护此可用主题列表。如果你决定手动删除 info 文件，则需要删除索引文件中的主题。该程序用于此类操作。当你添加 info 文档时，它反之亦然。

## makeinfo

`makeinfo` 程序将 Texinfo 源文档转换为各种格式。可用格式有：info 文件、纯文本和 HTML。

## texi2dvi

`texi2dvi` 程序打印 Texinfo 文档

### texindex

`texindex` 程序用于排序 Texinfo 索引文件。

### autoheader

`autoheader` 程序可以创建一个包含 `#define` 语句的模板文件供配置使用

### autoreconf

如果你有许多 `Autoconf` 生成的配置脚本，`autoreconf` 程序可以节省一些工作。它在当前目录树中反复运行 `autoconf`（在适当运行时 `autoheader`）以重制 `Autoconf` 配置脚本和配置模板。

### autoscan

`autoscan` 程序可以帮助软件包创建一个 `configure.in` 文件。`autoscan` 检查作为参数的目录树中的源文件，如果没有提供则检查当前目录。它搜索源文件中的常见移植性问题并创建一个初步的 `configure.scan`

`autoupdate` 程序更新使用旧名称调用 `Autoconf` 宏的 `configure.in` 文件到当前的宏名称。

### ifnames

`ifnames` 在为软件包编写 `configure.in` 时很有帮助。它打印软件包在 C 预处理器条件中使用的标识符。如果软件包已经设置了某些移植性，此程序可以帮助你确定 `configure` 需要检查的内容。

## Automake

目录

`Automake` 包包含 `aclocal` 和 `automake` 程序

### 描述

`aclocal`

`Automake` 包含了一些 `Autoconf` 宏，可以在你的软件包中使用；其中某些在特定情况下是 `Automake` 需要的。这些宏必须在 `aclocal.m4` 中定义；否则 `autoconf` 将看不到它们。

`aclocal` 程序根据 `configure.in` 的内容自动生成 `aclocal.m4` 文件。这为获取 `Automake` 宏提供了一种方便的方法，无需到处寻找。此外，`aclocal` 机制可以扩展扩展。

`automake`

要创建软件包的所有 `Makefile.in`，在顶层目录下运行 `automake` 程序且无需带参数。`automake` 将自动找到每个 `Makefile.am`（通过扫描 `configure.in`）并生成相应的 `Makefile.in`。

### 描述

`Flex` 是一个用于生成识别文本中模式程序的工具。模式识别在许多应用程序中非常有用。你设置规则来规定查找的内容，`flex` 就会创建一个查找这些模式的程序。人们使用 `flex` 的原因是，设置查找内容的规则比编写实际查找文本的程序要容易得多。

# Binutils

### 描述

`Binutils` 软件包包含 `ld`、`as`、`ar`、`nm`、`objcopy`、`objdump`、`ranlib`、`size`、`strip`、`c++filt`、`addr2line` 和 `nlmconv` 程序。

### ld

`ld` 合并多个对象文件和归档文件，重定位它们的数据并连接符号引用。在构建一个要运行的新编译程序时，最后一步通常是调用 `ld`。

### as

`as` 主要用于汇编 GNU C 编译器 `gcc` 的输出，以供链接器 `ld` 使用。

### ar

该程序创建、修改和从归档中提取内容。归档是一个单一文件，它以特定的结构持有一组其他文件，使得能够检索原始的单个文件（称为归档的成员）。

### nm

`nm` 列出对象文件中的符号。

### objcopy

`objcopy` 工具将对象文件的内容复制到另一个文件中。`objcopy` 使用 GNU BFD 库来读写对象文件。它可以以与源对象文件不同的格式写入目标对象文件。

### objdump

`objdump` 显示一个或多个对象文件的信息。选项控制显示哪些特定信息。这些信息对于正在开发编译工具的程序员来说非常有用，而不是对于那些只想让自己的程序编译并运行的程序员。

# Linux From Scratch

### ranlib

`ranlib` 生成归档内容的索引并将其存储在归档中。该索引列出了归档中每个成员（如果是可定位对象文件）所定义的符号。

### size

`size` 列出参数列表中每个对象文件 `objfile` 的节大小以及总大小。默认情况下，为归档中的每个对象文件或模块生成一行输出。

### strings

对于给定的每个文件，`strings` 会打印长度至少为 4 个字符（或程序选项指定的数量）且后跟一个不可打印字符的可打印字符序列。默认情况下，它只打印对象文件中初始化和加载区域的字符串；对于其他类型的文件，它会打印整个文件的字符串。`strings` 主要用于确定非文本文件的内容。

### strip

`strip` 从对象文件中删除所有或特定的符号。对象文件列表可能包含归档。必须至少提供一个对象文件。`strip` 修改参数中指定的文件，而不是以不同的名称写入修改后的副本。

### c++filt

C++ 语言提供了函数重载，这意味着你可以编写许多许多函数（为每个函数提供不同类型的参数）。所有 C++ 函数名都被编码为低级汇编标签（此过程称为符号修饰）。`c++filt` 程序执行反映射：它将低级名称解码（去修）为用户级名称，以便链接器防止重载函数导致崩溃。

### addr2line

`addr2line` 将程序地址转换为文件名和行号。给定一个地址和一个可执行文件，它使用可执行文件中的调试信息确定与给定地址相关的文件名和行号。

### nlmconv

`nlmconv` 将可定位对象文件转换为 NetWare Loadable Module 文件，可选地读取头文件以获取 NLM 头信息。

# Bzip2

### 内容

`Bzip2` 软件包包含 `bzip2`、`bunzip2`、`bzcat` 和 `bzip2recover` 程序。

### 描述

### Bzip2

`bzip2` 使用 Burrows–Wheeler 块排序文本压缩算法和霍夫编码压缩文件。压缩率通常远比基于传统的 LZ77/LZ78 的压缩器实现的要，并接近 PPM 系统计压缩器的性能。

### Bunzip2

`Bunzip2` 解压缩用 `bzip2` 压缩的文件。

### bzcat

`bzcat` (或 `bzip2 -dc`) 将所有指定的文件解压缩到标准输出。

### bzip2recover

`bzip2recover` 从损坏的 `bzip2` 文件中恢复数据。

### Diffutils

### 内容

`Diffutils` 软件包包含 `cmp`、`diff`、`diff3` 和 `sdiff` 程序。

### 描述

`cmp` 和 `diff`

`cmp` 和 `diff` 都会比较两个文件并报告它们的差异。两个程序都有额外的选项，可以在不同情况下比较文件。

### diff3

`diff` 和 `diff3` 之间的区别是 `diff` 比较 2 个文件，`diff3` 比较 3 个文件。

### sdiff

`sdiff` 合并两个文件并交互式地输出结果。
