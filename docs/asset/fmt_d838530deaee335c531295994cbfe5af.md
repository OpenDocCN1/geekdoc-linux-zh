
## 端点样式

- `CapBut`（方形）：线在端点处为正方形（垂直于线的斜率），且没有额外的投影。
- `CapRound`（圆端）：线具有一个圆弧，直径等于线宽，圆心位于端点处。（对于宽度为零的线等同于 `CapBut`）。
- `CapProjecting`（投影端）：线在末端是正方形，但路径在端点之外延伸了线宽的一半距离。（对于宽度为零的线等同于 `CapBut`）。

## 连接样式

连接样式（`join-style`）定义了宽线的拐角如何绘制：

- `JoinMiter`（斜接连接）：两条线的外边缘延伸并以某个角度相交。然而，如果角度小于 11 度，则改用 `JoinBevel` 样式。
- `JoinRound`（圆角）：拐角是一个圆弧，直径等于线宽，圆心位于端点处。
- `JoinBevel`（平角连接）：拐角具有 `CapBut` 端点样式，且三角形缺口被填充。

## 重合端点语义

对于重合端点 `x1=x2, y1=y2`，当端点样式同时应用于两个端点时，其语义取决于线宽和端点样式：

| Cap | 宽宽 | 结果 |
| :--- | :--- | :--- |
| `CapNotLast` |  | 结果取决于设备，但预期的效果是不绘制任何内容。 |
| `CapBut` |  | 结果取决于设备，但预期的效果是绘制单个像素。 |
| `CapRound` |  | 结果与 `CapBut`/细线相同。 |
| `CapProjecting` |  | 结果与 `CapBut`/细线相同。 |
| `CapBut` | 宽 | 不绘制。 |
| `CapRound` | 宽 | 闭合路径是一个圆，圆心位于端点，直径等于线宽。 |
| `CapProjecting` | 宽 | 闭合路径是一个正方形，对齐端点，边长等于线宽。 |

对于重合端点 `x1=x2, y1=y2`，当连接样式应用于一个或两个端点时，其效果就像该线已从整体路径中移除。然而，如果总路径由一个自连接的点组成或简化为一个点，效果与应用端点样式时相同。

## 平铺/条纹

平铺/条纹（`tile/stripe`）代表无限二维平面，平铺/条纹在所有维度上复制。当它被叠加在图形应用程序的可绘制对象上时，某些平铺/条纹实例的左上角位于平铺/条纹原点指定的坐标处。平铺/条纹和裁剪操作相对于图形请求中指定的任何可绘制对象的原点进行解释。平铺图必须具有相同的深度，并且在 `BadMatch` 错误时具有相同的结果。条纹位图的深度必须满足填充为 `FillStrip` 但非 `FillOpacity` 的条件；条纹图案然后在单个平面内平铺，并作为额外的裁剪掩码与裁剪掩码进行与逻辑运算。虽然某些尺寸可能比其他尺寸更快，但任何位图都可以用于平铺或描边。

## 填充样式

填充样式（`fill-style`）定义了线、文本和填充请求的内容（例如 `XDraw`, `XText16`, `XFillRectangle`, `XFillPolygon`）；对于带有 `LineOff` 或 `DoubleDash` 的线，结果如下：

| Style | 结果 |
| :--- | :--- |
| `FillSolid` | 前景 |
| `FillTiled` | 平铺 |
| `FillOpaqueStippled` | 在点纹为 0 处为背景，在点纹为 1 处为前景 |
| `FillStippled` | 背景 |

在绘制带有 `DoubleDash` 的线时，奇数虚线由填充样式控制：

| Style | 结果 |
| :--- | :--- |
| `FillSolid` | 背景 |
| `FillTiled` | 偶虚线 |
| `FillOpaqueStippled` | 偶虚线 |
| `FillStippled` | 背景 |

将位图存储在 GC 中可能不会产生副本。如果位图随后作为目标使用，更改可能不会反映在 GC 中。如果位图同时作为目标和点纹使用，结果未定义。

为了获得性能，应尽可能使用 GC 绘制（而不更改其组件）。相对于使用不同的 GC，更改组件的成本取决于显示硬件和服务器实现。显示硬件可能会缓存少量的 GC。

虚线值（`dashes value`）实际上是 `SetDashes` 中双元素列表 `[N, N]` 的简化形式。指定值 `N` 等同于指定元素列表。该值必须非零，否则将产生 `BadValue` 错误。

裁剪掩码限制到目标绘制对象。裁剪掩码设置为位图，位图必须具有与 GC 相同的深度，否则将产生 `BadMatch` 错误。如果裁剪掩码设置为 `None`，无论裁剪原点如何始终绘制。裁剪掩码也可以通过调用 `SetClipRectangles` 或 `XRegion` 函数来设置。只有掩码位为 1 的像素会被绘制。在掩码位为 0 的区域外不绘制像素。裁剪掩码影响所有请求。裁剪掩码不裁剪。

原点相对于图形请求中指定的任何可绘制对象的原点进行解释。

你可以将子窗口模式（`subwindow-mode`）设置为 `ByChildren` 或 `IncludeInferiors`。对于 `ByChildren`，源窗口和目标窗口根据其 `InputOutput` 通道被额外裁剪。对于 `IncludeInferiors`，两个窗口都不会被裁剪。这将导致包含子窗口内容并绘制目标子窗口。在具有不同深度从的窗口上使用 `IncludeInferiors` 是非法的，但核心协议未定义其语义。

## 填充规则

填充规则（`fill-rule`）定义了 `XFillPolygon` 请求中路径的哪些像素是内部的（绘制的），可以设置为 `EvenOddRule` 或 `WindingRule`。对于 `EvenOddRule`，如果以点为原点的无限射线交叉路径的奇数次，则该点在内部。对于 `WindingRule`，以点为原点的无限射线

穿越了数量不等的顺时针和逆时针方向的路径段。顺时针方向路径段是指从该点观察，从左到右穿过射线的段。逆时针段是指从该点观察，从右到左穿过射线的段。定向直线与射线重合的情况没有意义，你可以简单地选择另一条不与线段重合的射线。

对于奇偶数规则（`EvenOdd`）和绕数规则（`WindingRule`），像素是无限小的，路径是无限细的线。如果像素的中心点在内部且中心点不在边界上，则该像素位于内部。如果中心点在边界上，则当且仅当多形内部位于其右侧（`x` 增加）时，该像素位于内部。中心位于水平边缘的像素是一个特殊情况，当且仅当多形内部位于其正下方（`y` 增加方向）时，它们位于内部。

`XFill` 函数中的弧模式填充可以设置为 `ArcSlice`（弧扇）或 `ArcChord`（弧弦）。对于 `ArcSlice`，弧形是扇形的；对于 `ArcChord`，弧形是填充的。

图形暴露标志 `Graphics:Ex` 用于 `XCopyArea` 和 `XCopyPlane` 请求（以及扩展定义的类似请求）的事件生成。

# 图形上下文函数

要在具有可绘制深度的屏幕上创建一个可用的 GC（图形上下文），使用 `XCreateGC`。

```
GC XCreateGC(display, d, valuemask, values);
```

- `display` 指定到与 X 器的连接。
- `d` 指定可绘制对象（`drawable`）。
- `valuemask` 指定要使用指定 `values` 结构中的信息设置 GC 中的哪些组件。此参数是零或多个有效 GC 组件掩码位的按位包含或运算的结果。
- `values` 指定由 `valuemask` 指定的任何值。

`XCreateGC` 函数创建一个图形上下文并返回一个 GC。该 GC 可以与与指定可绘制对象具有相同根和深度的可绘制对象配合。与其他可绘制对象配合会导致 `MatchError` 错误。

`XCreateGC` 可能会生成 `BadAlloc`, `BadDrawable`, `BadFont`, `BadMatch`, `BadPixmap` 和 `BadValue` 错误。

要将组件从源 GC 拷贝到目标 GC，使用 `XCopyGC`。

```
XCopyGC(display, src, dest, valuemask);
```

- `display` 指定到与 X 器的连接。
- `src` 指定源 GC 的组件。
- `valuemask` 指定要拷贝到目标 GC 的 GC 中的哪些组件。此参数是零或多个有效 GC 组件掩码位的按位包含或运算的结果。
- `dest` 指定目标 GC。

`XCopyGC` 函数将指定的组件从源 GC 拷贝到目标 GC。源 GC 和目标 GC 必须具有相同的根和深度，否则会发生 `BadMatch` 错误。`valuemask` 指定使用哪个组件，方式与 `XCreateGC` 相同。

`XCopyGC` 可能会生成 `BadAlloc`, `BadGC` 和 `BadMatch` 错误。

要更改给定 GC 中的组件，使用 `XChangeGC`。

```
XChangeGC(display, gc, valuemask, values);
```

- `display` 指定到与 X 器的连接。
- `gc` 指定 GC。
- `valuemask` 指定要使用指定 `values` 结构中的信息更改 GC 中的哪些组件。此参数是零或多个有效 GC 组件掩码位的按位或运算的结果。
- `values` 指定由 `valuemask` 指定的任何值。
