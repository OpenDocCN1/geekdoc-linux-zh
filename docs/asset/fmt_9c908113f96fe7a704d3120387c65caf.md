## 扫描仪

扫描仪非常有用，而且是你能买到的最廉价的外围设备之一。它们允许你将图像或文本页转换为数字格式并输入计算机——就像你在复印机上复制文档一样。

尽管扫描仪已经存在很长时间了，但 Linux 对它们的支持仍然有些不稳定。幸运的是，随着每个新 Linux 版本的发布，这种情况正在向好发展。后端——Linux 系统中处理扫描仪识别和支持的隐藏部分被称为 *Sane*。如果你想知道 Linux 能否识别你的扫描仪，或者你正在考虑购买什么类型的扫描仪，可以访问 Sane 网站：*http://www.sane-project.org/sane-mfgs.html*。你可以在那里查看你的扫描仪是否受支持，或获取购买扫描仪的建议。该页面很长，因此你可能需要使用浏览器的查找功能（在 Firefox 中选择 **编辑** -> **查找**）来搜索你的扫描仪型号。正如我提到的，你也可以尝试 Ubuntu 论坛（*http://www.ubuntuforums.org/*），并在那里寻求针对 Ubuntu 的特定建议。

### 使用 Simple Scan 无需多问地扫描

Simple Scan 是 Ubuntu 默认应用程序系列中较新的成员，它确实名副其实——将文档从扫描仪平台传输到电脑屏幕只需点击几次。要运行 Simple Scan，请确保你的扫描仪已连接并开启，然后从启动器（Dash）中打开 **Simple Scan**。如果收到未检测到扫描仪的警告信息，请跳到第 196 页的“无法识别的扫描仪”。

假设你的扫描仪已被识别，你将看到图 10-10 所示的界面。

从这里开始非常简单——从“扫描”按钮旁下拉菜单（图标为一个小向下箭头）中选择要扫描的文档类型（文本或照片），然后点击 **扫描**。你的扫描仪将开始工作，稍等片刻，你将看到放置在扫描仪上的图片或文档的预览。你可以通过“页面”菜单中的选项或右键点击预览来对图像进行裁剪和旋转。当你对扫描结果满意时，选择 **文档** -> **保存** 完成操作。

一个小提示：要更改扫描分辨率，请选择 **文档** -> **偏好设置** 并调整出现窗口中的设置。高分辨率扫描需要更长的时间并占用更多磁盘空间，但低分辨率效果可能很糟糕，所以请明智选择！

### 使用 XSane 进行不简单的扫描

Simple Scan 能够处理你的大部分扫描需求，但如果你需要进行某些特别复杂的扫描，可以使用 XSane。XSane 是一个真正的扫描程序“巨兽”，充满了专业功能和微调选项（见图 10-11）。使用 Ubuntu 软件中心搜索并安装 XSane，然后从启动器中打开 **XSane Image 扫描程序**。XSane 会搜索连接的扫描仪。如果找到了，它将启动；如果没有找到，会弹出一个显示“无可用设备”的窗口。如果发生这种情况，点击 **关闭** 按钮并跳到第 196 页的“无法识别的扫描仪”。

### 无法识别的扫描仪

如果你在扫描时收到未检测到扫描仪的提示，可以尝试以下几点：

- 安装 Gocr 后，像以前一样将文档扫描到 XSane。这次，在点击 **保存图像** 之前，点击左侧的第二个按钮（显示 ABCDEF 的那个），你会发现现在也可以将文件保存为文本文档。文本识别并非完美，所以请务必检查文本文件是否有拼写错误。

### 为什么扫描图像这么大？

在本节结束之际，让我回答一个困扰了很多人的问题：为什么屏幕上的扫描图像看起来比对应的副本大得多？这是因为每英寸的像素增加了三倍，所以它看起来大了三倍。基本上，如果是为了在计算机上（例如网页）显示而扫描图像，最好使用与典型屏幕分辨率相似或略高的 PPI：96ppi 到 150ppi。

涉及到打印时，会有一套全新的考虑因素。首先是扫描仪的限制，因为不同型号有不同的最大分辨率。打印机的分辨率限制也是一个重要的考虑因素。例如，激光打印机和喷墨打印机的特性不同；激光打印机的质量通常比喷墨打印机好，而喷墨输出受纸张的影响更大。如果你以比打印计划更高的分辨率进行扫描，打印输出不会受到影响，但你会产生大量的磁盘空间。记住，*扫描图像的分辨率越高，文件体积越大*。

以较低分辨率扫描的图像在屏幕上看起来更好，但如果你全尺寸显示它将会巨大。这是因为每英寸的像素增加了三倍，所以它看起来大了三倍。例如，查看图 10-13，你可以看到三种分辨率下的相同图像：96ppi、150ppi 和 300ppi。你可以看到，最左侧的 96ppi 图像（尺寸为 5x6 英寸——大约是纸质副本的大小）最小，中间的正常，最大的看起来有点奇怪，没有另外两个那么清晰。

*图 10-13：不同分辨率下的相同图像*

扫描时使用什么分辨率取决于多种因素，其中最重要的是你完成后打算对图像做什么。当我从屏幕上查看图 10-13 时，最小的图像看起来最好，中间的正常，最大的看起来有点奇怪，没有另外两个那么清晰。

如果你正在使用诸如 GIMP 的应用程序（在第 13 章中详细介绍），但如果你不希望从一开始就对磁盘空间的使用得那么随意，可以遵循这些非常通用的指南：

- 如果你使用激光打印机，请按打印所需的相同分辨率进行扫描。

- 如果你打算使用照片相纸配合喷墨打印机，请按目标打印分辨率的 80% 左右扫描——对于 300dpi 的打印输出约为 240ppi。

- 如果你使用普通纸张配合喷墨打印机，请按目标打印分辨率的 65% 左右扫描——对于 300dpi 的打印输出约为 195ppi。

不用说，这些只是供你入门的建议。最适合你和你特定的扫描仪/打印机设置的方法可能略有不同。没有什么比实验和试错更有效的。在这种情况下，你实际上不会出错。只需给自己一点时间，不要感到沮丧，而且最重要的是，不要在急需扫描某些东西时才开始尝试——要领先一步。
