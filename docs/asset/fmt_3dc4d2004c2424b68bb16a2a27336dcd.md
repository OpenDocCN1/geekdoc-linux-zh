```bash
# 变量 $8 指向值 34。
FIELD=8

# 错误用法
echo $$FIELD
3243FIELD

# 正确用法
echo '$$FIELD'
34
```

## 使用 sar 测量系统负载

大多数 Unix 版本默认设置了 `sar` 数据收集。当执行不带任何开关的 `sar` 命令时，会显示 `sar` 数据。这些数据在全天范围内按计划间隔自动收集，并在一天结束时编译成报告。默认情况下，系统保留一个月的数据供使用。这对于查看机器在全天负载时的基本趋势非常有帮助。如果我们想在特定时间段收集数据，则需要设置每次采样的秒数和总采样间隔。注意，我们使用了 `SECS` 而不是 `SECONDS`。

## 使用 sar 命令编写脚本

脚本的下一步是定义我们需要哪些字段。不同的 Unix 版本的输出有所不同，但基本思想是相同的。在每情况下，我们定义一个 `INTERVAL` 变量来指定总采样次数，以及一个 `SECS` 变量来定义每次采样的秒数。这就是脚本发挥作用的地方。让我们看看如何编写解决方案。
