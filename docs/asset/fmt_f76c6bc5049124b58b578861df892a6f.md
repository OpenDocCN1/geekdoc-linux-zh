
最后，是 Ubuntu 预配置安全策略带来的防御优势——Ubuntu 没有开放的入站端口。这意味着你的系统更不容易受到入侵。

# 我的系统需要保护吗？

所以，有了这些关于 Linux 卓越安全性的说法，你可能想知道是否需要担心它。嗯，如果你看看 Ubuntu 论坛，你可能会感到有些困惑。当询问 Linux 用户是否需要安装反病毒软件或防火墙时，大多数用户会给出一个坚定的“不需要”。另一方面，你也会发现有很多人已经安装或正在尝试安装这些软件。嗯。

那么，Linux 用户该怎么办？

如果你在一个网络中经常在 Windows 机器之间传输文件，你可能想要考虑安装一些反病毒软件，仅仅是为了那些 Windows 系统和那些用户的利益——例如，你未经保护的（即使用 Windows 的）邮件朋友。如果你天生比较谨慎，你可能也想尝试一下。基本上，如果安装某些保护让你感到更安全，尽管去吧。如果安装我在这一章中涵盖的全防御机制让你感到更安全，无论你选择哪种方式，都不会浪费你的费用，而且对你产生任何伤害。

# 第一道防线

无论你使用的是哪种系统，任何永久连接到互联网的计算机的第一道防线都是路由器——一个电子

该设备允许局域网（如您的家中或办公室）上的多台计算机相互连接并共享来自互联网服务提供商（ISP）的单一连接。虽然路由器通过电缆连接到调制调器，但从路由器到局域网计算机的连接可以是有线的、无线的或兼有的。

路由器与你电脑的防御有什么关系？嗯，大多数路由器包含一个防火墙，其基本功能是将互联网上所有的恶性内容隔在你的电脑之外，就像防火墙防止发动机的热量、废气和噪音进入客舱一样。这种内置防火墙是即使是只有一台电脑的人（他们可以轻松地将电脑直接连接到电缆或 DSL 调制调器）也会使用路由器的原因之一。当然，你在防火墙设置软件中选择哪种过滤器取决于你的需求——例如，一个常见且实用的过滤器（特别是对于无线路由器）可以将互联网访问限制在防火墙访问列表指定的机器上。这防止了你的邻居通过你的 ISP 连接“搭便车”。毕竟，他们并没有在付账单。

路由器的设置内置在路由器内部，因此你不需要担心软件安装和系统兼容性问题。在 Linux 上使用路由器与在 Windows 上使用没有区别。你可以通过简单的网络浏览器访问设置并修改你的配置，如图 18-1 所示。只需在浏览器的地址栏输入路由器的 IP 地址（通常在用户手册中提供），按回车键，即可开始使用。

## 软件防火墙

如果你没有路由器且不打算买一个，或者你已经有一个，但你正处于偏执症的边缘，你可能想考虑使用软件防火墙，特别是 Linux 上最流行的软件防火墙之一：Firestarter。

你可以通过 Automix 下载并安装 Firestarter，方法是点击左侧面板中的 Utilities（工具），在右侧面板中选择 Gnome Security Suite，然后点击 Start（启动）按钮。一旦安装完成，通过 System Administration（系统管理）► Firestarter 运行它。系统会提示你输入密码，输入密码并点击 OK 按钮。

### 控制 Firestarter

你可以通过创建自己的策略来控制 Firestarter 如何处理各种网络事件。Firestarter 中的默认策略基本上允许你执行通常通过互联网执行的任何操作，同时它会阻止来自互联网或网络上任何其他计算机到你电脑的新连接。

为了让策略更严厉，你可以点击 Policy（策略）选项卡，在 Editing（编辑）旁边的下拉菜单选择 Outbound traffic policy（出站流量策略），然后选择 Restrictive by default, traffic（默认限制流量）。如果你想拒绝任何操作你电脑的人访问特定网站，只需点击 Deny connections to host（阻止到主机的连接）字段选择它，然后点击 Add Rule（添加规则）按钮。在 Add New Outbound Rule（添加新出站规则）窗口中，输入目标站的 URL，点击 Add，然后在 Firestarter 主窗口中点击 Apply Policy（应用策略）按钮。

### 确认 Firestarter 自动运行

在第一次运行 Firestarter 后，它将自己为每次你启动系统时自动启动。当你启动它时没有看到图形界面，不要担心；Firestarter 将在后台运行，静静地保护你的电脑。

如果你是个多疑的人，可以打开 Terminal（终端）窗口，输入 `/etc/init.d/firestarter status` 然后按回车键，检查 Firestarter 是否真的在后台运行。如果 Firestarter 正在运行，你会在终端窗口看到消息 `* Firestarter is running...`。大可宽心。如果 Firestarter 未运行，响应将是 `* Firestarter is stopped.`。

## Cl：杀毒软件，Linux 风格

尽管缺乏能够破坏你 Linux 系统的病毒，但你的电脑仍然可能充当病毒的发射器。正如之前提到的，你在病毒扫描期间可能遇到的病毒都是针对 Windows 系统的，这些病毒无法影响你的 Linux 系统，扫描你的 Windows 分区（如果有的话）以及任何将作为邮件附件发送的文件是有益的。

### ClamAV

尽管 ClamAV 可以在操作系统上运行，但它被认为是 Linux 的杀毒软件包。它是开源的、完全免费的，你不需要担心许可证或续期的烦恼。遗憾的是，ClamAV 是一个命令行应用程序，这使得它不那么用户友好。幸运的是，所有人都有图形界面可用，尽管很简单，即 ClamTk。ClamAV 和 ClamTk 都通过 Automix 提供。事实上，它们与 Firestarter 一起包含在 Gnome Security Suite 中，如果你想尝试，只需按照上一节安装 Firestarter 的说明操作。
