## 24.8.3 后渗透阶段枚举

这是一个很好的时机，让我们退后一步，看看目前为止我们有什么。我们有两个被攻陷的 Linux 主机（Ajla 和 Zora）。第一个主机运行在外部网络中，第二个主机运行在内部网络中。我们还有 Poultry，一个加入域并在内部网络中被攻陷的 Windows 主机。最后，我们目前正在攻陷 Cevapi。
