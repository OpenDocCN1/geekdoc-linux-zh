## 5 Sendmail

Sendmail 是标准的邮件传输系统，也是 RedHat 默认邮件传输系统（使用 Postfix）。作为用户，你并不直接使用 `sendmail`——`sendmail` 是后台为所有用户管理机器邮件的底层服务器。若要在文本模式下读取/发送邮件，你可能想使用 `pine`（选择一个并坚持使用它——使用不同的客户端可能会不方便）。在 KDE 中，你可以使用 `kclient`（邮件客户端）。要通过你的 `ppp` 拨号与外部世界通信（直接连接到基于 `ISP` 的邮箱，从而绕过本地计算机上的邮件设施），你可以使用像 `email`（或 Thunderbird）这样流行的邮件客户端，或使用命令行程序来发送和接收邮件。

Sendmail 非常强大、健壮且可靠。但如果你需要配置特定的需求，它管理起来也是出了名的困难。幸运的是，Red Hat (5.2 或 6.x) 自带开箱即用的 `sendmail`（带有某些限制），你可以从内部网络的一个用户向另一个用户发送邮件。在你的系统（RedHat 设置）上，我可以顺利地向同一台机器上的其他用户发送邮件（例如使用 `pine`）。一旦我通过调制调器连接到互联网提供商（启用 IP 伪装），我就可以向世界的任何地方发送邮件。

但当我没有连接时，邮件会留在队列中，等待连接互联网。邮件会被发送到我家庭网络上的另一台计算机（这是一个小小的困扰）。这种情况的发生是因为 `sendmail` 正在尝试进行 `DNS` 查询，而这在我的系统中不可用——RedHat 默认 DNS 仅限缓存）。如果你真的想在 `RH6.x` 上避免这种情况，可以使用 `config`（作为 root）并指定 `sendmail` 完全不使用 `DNS`（`sendmail` 随 `RH5.2` 提供）。

# 7 简单 Web 服务器 (Apache)

使用你的 RedHat 发行版 (7.1)，设置 Web 服务器可能更简单——它是开箱即用的。这是 `apache` 服务在 `/etc/inetd.conf` 中默认启用的方式。以下是相关部分：

```text
http /etc/inetd.conf
```

要管理 `apache` 服务器，你可以使用以下命令：

```bash
/etc/rc.d/httpd start
/etc/rc.d/httpd status
/etc/rc.d/httpd restart
/etc/rc.d/httpd stop
```

如果 `apache` 没有运行，你可以作为 root 手动启动它：

```bash
/etc/rc.d/httpd start
```

`apache` 配置位于 `/etc/apache` 目录。Web 文件位于 `/var/www/html`。
