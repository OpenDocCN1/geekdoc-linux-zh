
在上述的示例中，`str` 包含五个字符，最后一个是空格。`test` 命令中的第二个字符串只包含四个字符。不相等运算符在等价运算符返回假的地方都会返回真值。

```
$ str=abcd
$ test $str != abcd
$ echo $?
1
$
```

上一个示例中的，两个字符串操作（不带运算符的字符串测试和使用 `-n` 运算符的测试）几乎完全相同，如下一个示例所示：

```
$ str=abcd
$ test $str
$ echo $?
0
$ test -n $str
$ echo $?
0
$
```

上一个示例中两个命令之间的区别虽然细微，但它指出了使用 `test` 命令的一个潜在问题，如下一个两个不同测试的示例：

```
$ str=""
$ test $str
$ echo $?
1
$ test "$str"
$ echo $?
0
$ test -n $str
test: argument expected
$ test -n "$str"
$ echo $?
0
```

在上述的示例中，第一个测试为假。为什么呢？记住，shell 解释器在处理命令行之前会进行变量替换，并且在处理命令行时，它会移除空格。当 `$str` 没有加双引号时，空格会被传递给命令行并被剥离；当使用双引号时，空格会被传递给 `test`。第三个测试中发生了什么？当解释器移除空格时，`test` 只接收到了 `-n` 选项，该选项需要一个参数。

### 数值数据

`test` 命令像 `expr` 一样，具有将字符串转换为整数并执行数值操作的能力。`expr` 对整数执行算术运算，而 `test` 执行的是逻辑比较。可用的数值比较如下：

| int1 -eq int2 | 如果 int1 在数值上等于 int2，则为真 |

| int1 -ne int2 | 如果 int1 不等于 int2，则为真 |

| int1 -gt int2 | 如果 int1 大于 int2，则为真 |

| int1 -ge int2 | 如果 int1 大于等于 int2，则为真 |

| int1 -lt int2 | 如果 int1 小于 int2，则为真 |

| int1 -le int2 | 如果 int1 小于等于 int2，则为真 |

数值等价与字符串等价之间的差异在下面的示例所示，该示例定义了两个字符串并分别使用数值等价和字符串等价对它们进行比较。

```
$ str1=1234
$ str2=01234
$ test str1 = $str2
$ echo $?
1
$ test str1 -eq $str2
$ echo $?
$
```

在第二种情况下，字符串被转换为整数并发现数值上是等的，而原始字符串并不等价。

### 测试文件

`test` 命令可以检查的第三类条件是文件的状态。`test` 命令像 `expr` 一样可以检查文件的状态。使用 `test` 命令，可以确定文件是否存在、是否可写。常用的测试选项如下：

| -r filename | 如果文件可读，则为真 |

| -w filename | 如果文件可写，则为真 |

| -x filename | 如果文件有执行权限，则为真 |

| -f filename | 如果是普通文件，则为真 |

| -d filename | 如果是目录，则为真 |

| -c filename | 如果是字符设备文件，则为真 |

| -b filename | 如果是块设备文件，则为真 |

| -s filename | 如果文件大小不为零，则为真 |

| -t filename | 如果是终端设备，则为真 |

### 组合与取反测试

到为止讨论的表达式都是单元操作，因为它们只测试一个条件。你可能感兴趣的不是什么是真的，而是什么为假。要找出什么为假，你可以在任何单元前面使用单元取反运算符 `!`。创建一个空文件并尝试以下示例：

```
$ cat >empty
Ctrl+d
```

```
$ test -r empty
$ echo $?
0
$ test -s empty
$ echo $?
1
$ test ! -s empty
$ echo $?
0
```

`test` 命令中的表达式可以使用逻辑与运算符 `-a` 或逻辑或运算符 `-o` 进行组合。当你使用 `-a` 运算符时，只有当两个单元都为真时，组合表达式才为真。当你使用 `-o` 运算符时，只要一个单元为真，组合表达式就为真。使用上面的文件，查看文件是否可读且包含数据：

```
$ test -r empty -a -s empty
$ echo $?
1
$
```

组合表达式为假。第一个表达式因为文件可读为真，但第二个表达式因为文件大小为0而失败。

### 测试测试方法

由于 `test` 命令是 shell 编程中非常重要的部分，为了让 shell 程序看起来像其他语言，Bourne shell 提供了一种使用 `test` 的替代方法：将整个封装在方括号 `[]` 中。

```
$ int1=4
$ [ $int1 -gt 2 ]
$ echo $?
0
$
```

记住，尽管看起来不同，上述示例仍然是 `test` 命令且用法是相同的。

**嵌套 if 语句和 elif 结构（Nested if Statements and the elif Construct）** 你经常可能希望你的程序执行以下操作：

- 1. 检查主条件，并且

  - A. 如果主条件为真，执行某操作。

  - B. 如果主条件为假，检查次要条件。

    - (2) 如果次要条件为假，检查第三个条件，但

if command

else

    then
      command
  else
    if command
      then
        command
    fi
fi
```

elif command
then
  command
elif command
then
  command
fi
```

两种方法都能产生结果。

# 在程序中构建重复结构

到目前为止，你所过的程序都是从上到下的线性进展。程序语句从上到下执行。计算机程序最有益的特性之一是它们处理大量数据的能力。为了实现这一点，编程语言必须具备某种结构来导致程序的部分发生重复。在计算机术语中，这通常被称为循环。

例如，你有一个计算机文件，其中包含地址和 ZIP 编码的记录，你只需要打印匹配特定 ZIP 编码的记录。你希望编写一个程序，读取记录，对 ZIP 编码进行匹配，打印匹配的记录，并重复该过程直到数据耗尽。

Bourne 语言内置了三种循环结构。程序在无意中进入无限循环往往在无意中浪费了许多小时的时间。这三种结构之间的主要区别是终止循环的方法。三种类型的循环是 `while` 循环、`until` 循环和 `for` 循环；接下来的章节将分别对其进行讨论。

在 `while` 循环中重复：`while` 结构允许你指定在某些条件为真时执行的命令。

`while` 结构的一般格式如下：

```
while command
do
    command
    ...
    command
done
```

考虑列表 9.6 中名为 `squares` 的程序中的以下示例。

# 列表 9.6. while 循环示例。

```
# squares - 连续打印整数的平方
int=1
while [ $int -lt 5 ]
do
sq=`expr $int * $int`
echo $sq
int=`expr $int + 1`
done
echo "Job Complete"
```

```
$ squares
1
4
9
16
Job Complete
$ 
```

在列表 9.6 的程序中，只要 `int` 的值小于 5，循环内部的命令就会执行。在第五次重复时，与 `while` 语句关联的测试条件返回一个非零值，`done` 语句之后的命令将被执行。
