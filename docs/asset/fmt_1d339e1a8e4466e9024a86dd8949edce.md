
## SQL 语句

你使用 `WHERE` 子句来指定 `SELECT`、`UPDATE` 和 `DELETE` 命令作用的记录。当你使用等于、小于、大于等于、大于时，请指定包含通配符字符的字符串。你还可以使用 `AND` 来组合多个子句。

```sql
WHERE LastName = 'Smith'
```

```sql
SELECT
 FROM Customers
ORDER BY Price, DESC
```

```sql
SELECT
 FROM Customers
ORDER BY LastName
```

```sql
SELECT
 FROM Customers
WHERE LastName = 'Smith'
```

```sql
INSERT INTO Customers (LastName, FirstName)
VALUES ('Smith', 'John')
```

```sql
UPDATE Customers
SET TotalBalance = 50
WHERE LastName = 'Smith'
```

```sql
DELETE FROM Customers
WHERE LastName = 'Smith'
AND FirstName = 'John'
```

```sql
DELETE FROM Customers
WHERE LastName = 'Smith'
AND FirstName = 'John'
```
