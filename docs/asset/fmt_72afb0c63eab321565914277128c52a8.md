### 12.5 Java 和 JavaScript

不要区分这两种语言。Java 是由 Sun Microsystems 开发的面向对象、平台无关的编程语言。它经常被用于小型程序（Applet），这些程序在互联网上执行，用于网上银行、聊天和购物等功能。JavaScript 是一种解释型脚本语言，主要用于网页的动态结构化（例如用于菜单和其他效果）。

Konqueror 允许你启用或禁用这两种语言。这甚至可以以特定领域的方式进行，这意味着你可以允许某些主机访问，并阻止其他主机的访问。出于安全考虑，Java 和 JavaScript 经常被禁用。遗憾的是，某些网页需要 JavaScript 才能正确显示。

### 13.1 针对网络优化

Galeon 的主要设计目的是让浏览互联网尽可能方便。在默认配置下，Galeon 提供第二个工具栏，允许快速访问流行的 Google 搜索引擎及其新闻和图像搜索功能。它还可以提供对在线字典的访问并使用*书签*。这是通过 Galeon 内置的小型 JavaScript 函数实现的，例如，查询页面的时效性或允许网站在屏幕上缓慢滚动。

### 13.2 使用标签页高效浏览

Galeon 可以在单个应用程序窗口中显示多个文档。要以新标签页的形式打开网站中的链接，右键点击该链接。在弹出菜单中选择“在新标签页中打开”。点击“文件”->“打开新标签页”创建一个全新的 Galeon 标签页。点击标签页切换显示。

### 13.3 智能书签

智能书签可以在访问网站地址的同时访问其功能，并使用 Google 搜索搜索术语。在 Google 图标后的输入字段中输入单词。结果将在几秒后显示。要激活或创建额外的智能书签，选择“书签”->“智能书签工具栏”->“文件夹操作”->“编辑...”。将打开一个编辑书签的窗口。要创建一个新书签，勾选“智能书签工具栏”并选择“文件”->“新建项目”。在“名称”中输入名称，在“URL”中输入网络地址。“Smart URL”字段是一个包含整个字符串通配符的 URL。例如，Google 的智能 URL 为 `http://www.google.com/search?q=%s`。`%s` 是通配符。通过“文件”->“保存”保存你的书签。
