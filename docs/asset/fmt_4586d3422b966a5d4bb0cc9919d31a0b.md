# 关于 sed 命令的解释：

我们在 `sed` 命令框架中的命令所示：

`cat INPUT_FILES/blank_lines.sed`

+   - `/^^[[:space:]]*$/`

- 文件包含若干行；两者都是“删除”(d) 命令。

- 插入命令看起来像这样：`/$d$`

- 我们想要放置在内部的内容：两个斜杠之间。

- "a" 意味着“行首”。"e" 意味着“行尾”。"d" 意味着“删除”。

- 空行是因为在行首 (^) 和行尾 ($) 之间没有任何内容。

- 这里是我们的第二个命令：`/^^[[:space:]]*$/` 删除空格（ " " \ ）

- 而不是空行，这些空格一直持续到行尾 ($)，

然后删除 (d) 该行，因为它是一个空行。

- 行的第二个字符是可选的制表符或空格；为什么是

* 字符呢。

- 可选的？因为 "*" 意味着“前一个字符出现零次或多次”。
