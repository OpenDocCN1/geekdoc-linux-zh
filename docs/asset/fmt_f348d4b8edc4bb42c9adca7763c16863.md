
# IMAGEBOARDS (图站)

图站（Imageboards）是强调图像而非文本的网络论坛，起源于日本。它们通过图片帖子促进多样化的讨论，运行方式类似于公告板，但更侧重于瞬即性内容。用户可以匿名发布，通常使用 `tripcode`（旅行码）——一种哈希密码——来标识身份，而无需存储个人数据。与在线画廊不同，其内容主要来自外部源。像 `4chan` 这样的看板提供“安全的” `tripcode` 以增强匿名性，这些平台以其视觉与匿名互动的结合而与众。

`YChanEx` 是一个用于从 `4chan` 和 `8chan` 等各种图站下载线程和图片的工具。它可以在 Windows（通过 .NET 4.5）或 Linux（通过 `WINE`）上运行，引入了独特的 `ychanex:` 浏览器协议以便下载。该应用程序仍在开发中，支持多种看板并并代理支持、`brotli` 压缩和线程历史等功能。更新改进了可靠性和用户界面，并有进一步增强的计划。`YChanEx` 旨在简化图站内容的存档。

# 从命令行和 GUI 创建 YChanEx 的 wine .desktop 快捷方式：

要为 `YChanEx` 创建 `.desktop` 快捷方式，请在终端中执行以下步骤：

使用命令进入应用程序目录：

```bash
cd /usr/share/applications
```

运行以下命令打开一个新的新的 `.desktop` 文件进行编辑：

```bash
sudo gedit ychanex1.desktop
```

```ini
[Desktop Entry]
Name=YChanEx
Comment=Download images and threads
Exec=wine /path/to/YChanEx.exe
Type=Application
Icon=ychanex
Categories=Network;
```

# EBOOK READERS (电子书阅读器)

虚拟化软件或虚拟机管理程序可以将一台计算机转换为多个虚拟机，允许在单台 PC 上运行多个操作系统。这项技术最大化地利用了资源，简化了备份过程，并能够无缝运行不同的操作系统或过时的应用程序。它通过隔离潜在威胁来防止恶意软件和浏览器漏洞。除了个人用途外，虚拟化还支持 `IaaS`，提高了企业的可扩展性和效率，降低了成本，并改进了灾备和测试。它是灵活、高效计算的核心。

`Oracle VirtualBox` 是一款适用于企业和个人使用的强大虚拟化工具，兼容 Windows、Linux 和 macOS 等多种操作系统。它提供了丰富的功能集以实现高性能体验，支持从 Windows 版本到 Linux 发行版的众多客操作系统。作为 GPL v3 协议下的开源软件，`VirtualBox` 在 Oracle 的支持下在专业质量的同时专业的同时。它定期更新，增加了更多支持的系统和功能，并包含了为开发者提供的预构建虚拟机等资源。

`Virt-manager` 主要由 Red Hat（红帽）开发，是一个通过 `libvirt` 管理虚拟机（VM）的桌面工具。它支持创建、编辑、启动和停止虚拟机，并可以查看它们的性能和控制台。它兼容 `KVM`、`Xen`、`QEMU`、`LXC` 容器，甚至自 2014 年起支持 FreeBSD 的 `bhyve` 虚拟机管理器。其套件包括用于快速设置虚拟机的 `virt-install`、用于与虚拟机显示交互的 `virt-viewer`、用于克隆虚拟机的 `virt-clone`、用于编辑虚拟机配置的 `virt-xml` 以及用于设置基于 `libvirt` 的容器根文件系统的 `virt-bootstrap`。

## Oracle VirtualBox

访问 `Oracle VirtualBox` 官网 `https://www.virtualbox.org/`。

在终端中通过 APT 仓库安装 `Oracle VirtualBox`：

只需输入以下命令：

```bash
sudo apt update
```

```bash
sudo nano /etc/apt/sources.list
```

将以下内容添加到上述 `sources.list` 文件的末尾：

```
deb [arch=amd64 signed-by=/usr/share/keyrings/oracle-virtualbox-2016.gpg] https://download.virtualbox.org/virtualbox/debian jammy contrib
```

按下 `CTRL + S` 保存，然后按下 `CTRL + X` 退出。

在终端中运行以下命令：

```bash
wget -O https://www.virtualbox.org/download/oracle_vbox_2016.asc | sudo gpg --yes -- output /usr/share/keyrings/oracle-virtualbox-2016.gpg --deararm
```

```bash
sudo apt update
```

```bash
sudo apt install virtualbox-7.0
```

## Virt-manager

访问 `Virt-manager` 官网 `https://virt-manager.org/`。

通过软件管理器安装 DEB/FLATPAK 软件包：

打开软件管理器并搜索 `Virt-manager`。

点击 `Virt-manager`，然后点击源选择框。

```bash
sudo apt update

```
