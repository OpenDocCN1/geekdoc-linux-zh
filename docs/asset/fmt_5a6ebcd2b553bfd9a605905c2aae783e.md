
在数论中，两个数 $m$ 和 $n$ 的加法表示为 $m + n$，和称为该运算的结果。运算的结果是一个数，该运算被称为封闭的。该运算也被认为是交换的，因为 $m + n = n + m$。该运算也被认为是结合的，因为 $(m + n) + p = m + (n + p)$。

```
a+(b+c) = (a+b)+c
a+b = b+a
a+(b·c) = a·b+a·c
```

加法的一个重要性质是它是减法的逆运算。对于每个实数 $a$，存在唯一的实数 $-a$，使得 $a + (-a) = 0$。这种性质被称为**加法逆元性质**。在复数中，两个复数 $z_1 = x_1 + iy_1$ 和 $z_2 = x_2 + iy_2$ 的加法由 $(x_1 + x_2) + i(y_1 + y_2)$ 给出。

## 腺垂体激素

来自内分泌腺、即前叶垂体（或称腺垂体）的激素占据首要地位，因为它通过分泌各种激素来控制某些其他内分泌腺的功能，即肾上腺皮质、甲状腺和性腺。此外，前叶垂体分泌的激素通过直接作用于骨骼、肌肉和其他组织，影响机体的生长和代谢。垂体通过对来自靶器官的激素循环水平敏感的反馈机制来维持对各种靶器官的控制。

一种反馈机制的例子是促肾上腺皮质激素（ACTH）对肾上腺皮质的控制。这种激素刺激肾上腺皮质分泌皮质醇，一种类固醇激素。当血液中皮质醇水平升高过多时，下丘脑减少其ACTH的分泌，肾上腺皮质随之减少皮质醇的分泌。通过这种方式，血液中的皮质醇水平保持在正常范围内。

垂体激素也会在代谢状况的刺激下释放，而这些激素有助于控制这些状况。例如，影响生长激素分泌的一个因素是血糖水平。

有八种前叶垂体激素的存在已得到确凿证实。它们包括两种促性腺激素：间质细胞刺激素（ICSH，或称黄体生成素，LH）和卵泡刺激素（FSH）；促甲状腺激素（促甲状腺素，TSH）；泌乳激素（催乳素）；生长激素（GH，或称促生长激素，STH）；促肾上腺皮质激素（ACTH，或称促皮质素，或称皮质促激素）；以及两种黑素细胞刺激素（$\alpha$-MSH 和 $\beta$-MSH）。此外，已分离出的两种肽在结构上与 ACTH 和 MSH 相关。这些肽被命名为 $\beta$-脂溶激素（$\beta$-LPH）和 $\gamma$-脂溶激素（$\gamma$-LPH）。腺垂体的激素由肽键连接的氨基酸组成，因此根据其大小被归类为多肽或蛋白质。此外，三种激素——TSH、ICSH 和 FSH——含有碳水化合物，因此被归类为糖蛋白。参见*氨基酸；激素；蛋白质*。

在女性中，FSH 启动卵巢卵泡的发育。ICSH 与 FSH 协同作用，对卵泡成熟的最终阶段及雌激素的产生是必需的。ICSH 还刺激黄体的发育。在男性中，FSH 通过作用于睾丸的生发上皮来刺激精子生成，而 ICSH 主要激活产生雄激素的勒迪希细胞。

TSH 刺激甲状腺的生长及甲状腺激素的分泌。

通过一个还需要其他激素参与的过程，泌乳激素刺激乳腺分泌乳汁。有证据表明，在某些哺乳动物物种中，泌乳激素在维持卵巢黄体方面也起作用。与所有已调查的非灵长类动物不同，从未从猴子或人类的垂体中分离出明确的泌乳激素。在这两个物种中，确实可以从垂体中分离出具有泌乳活性的激素，但它也具有促进生长的活性，并在很大程度上等同于从非灵长类动物中分离出的生长激素。因此，在非灵长类动物中，可以从垂体中分离出一种没有泌乳活性的明确生长激素。然而，在灵长类动物中，促生长活性和泌乳活性存在于同一分子中。尽管具有双重活性，灵长类激素通常仅被称为生长激素，它促进体型增大。它刺激骨骼、肌肉和其他组织的生长，并增强其他垂体激素对其靶器官的作用。尽管已知生长激素的某些细胞效应，如增加氨基酸掺入肌肉蛋白，但该激素在细胞层面发挥作用的生化机制仍是一个谜。

ACTH 激素刺激肾上腺皮质的生长以及皮质醇和其他皮质激素的分泌。ACTH 分子的一个有趣方面是，它部分包含在黑素细胞刺激素和脂溶激素中发现的序列（见下文）。根据其化学相似性，所有这些激素都表现出黑素细胞刺激和脂解活性并不令人惊讶。

黑素细胞刺激素也被称为中间素，因为它们可以从具有明确中间叶的动物垂体的中间叶中分离出来。黑素细胞刺激活性是指这些激素使黑素细胞中的色素颗粒分散、导致皮肤变黑的能力。已分离出两种类型的 MSH。$\alpha$-MSH 是最强的黑素细胞刺激素；$\beta$-MSH 具有 $\alpha$-MSH 约 50% 的活性，而 ACTH 和 LPHs 具有约 1% 的活性。

## 三磷酸腺苷 (ATP)

1965–1966年，$\beta$-脂溶激素和$\gamma$-脂溶激素从绵羊垂体中分离出来并进行了化学表征。脂溶一词指的是这些物质对脂肪组织的脂解活性。后来发现，它们还具有刺激泌乳的活性。脂解活性是指某些激素刺激脂肪组织中脂质分解为游离脂肪酸和甘油的能力。如前所述，ACTH 和 MSHs 也是脂溶激素，事实上，在这方面它们的效力甚至大于 LPHs。参见*动物生长；哺乳；垂体；甲状腺*。[C.H.L.]

## 二磷酸腺苷 (ADP)

作为细胞代谢中重要的辅酶和中间体的，是三磷酸腺苷的部分去磷酸化形式。该化合物是 5'-腺嘌呤核苷酸，其通过焦磷酸键连接了一个额外的磷酸基团。ADP 由三磷酸腺苷产生，并在涉及生命系统能量代谢的偶联反应中重新转化为该化合物。ADP 也是通过腺嘌呤三核苷酸（ATP）向 5'-腺嘌呤核苷酸转移磷酸基团产生的，该反应由肌激酶催化。参见*金属主义*。

## 三磷酸腺苷 (ATP)

作为辅酶以及所有生物代谢中最重要的化合物之一，因为它充当不同酶促反应之间的偶联剂。三磷酸腺苷（ATP）是二磷酸腺苷（ADP），通过焦磷酸键连接了一个额外的磷酸基团到末端磷酸基团（见图示）。由于其三个磷酸基团之间磷酸酯键的性质，ATP 是向适当受体提供磷酸基团的强力供体。例如，在葡萄糖的磷酸化过程中，这是碳水化合物代谢中必不可少的反应，己糖激酶催化末端磷酸基团的转移。

ATP 是肌肉执行机械功的直接能量来源。在其存在下，肌肉蛋白原肌球蛋白收缩并生成二磷酸腺苷和无机磷酸。ATP 还参与氨基酸的活化，这是蛋白质合成中必要的一步。参见*肌肉*。

在代谢中，ATP 主要由产能氧化还原反应，从二磷酸腺苷和无机磷酸中生成。因此，在电子通过细胞色素系统从底物传输到氧气的过程中，ATP 得以生成。在光合生物中，ATP 是由光化学反应生成的。参见*甲酸盐代谢；细胞色素*。

凭借其富含能量的焦磷酸键，ATP 充当了生命系统可利用的能量来源与伴随着生命物质生长、繁殖和维持的化学及机械功之间的纽带。因此，它被称为能量库。

由于 ATP、ADP 和腺嘌呤核苷酸在许多代谢过程中不断相互转化，它们作为其作用的偶联反应的辅酶发挥作用。参见*生物化学；生物氧化；辅酶；代谢*。[M.J.]

## 腺病毒-SV40 杂交病毒

一种缺陷病毒颗粒类型，其中乳头病毒 SV40 的部分遗传物质被封装在腺病毒蛋白质外壳（衣壳）中。腺病毒具备与原父代腺病毒不同的特性。它在新生仓鼠中产生肿瘤；它在猴细胞培养物中复制；虽然它不产生感染性 SV40，但它使培养中的猴细胞产生一种已知是 SV40 特异性诱导的新细胞抗原——SV40 肿瘤，或 T，抗原。因此，新的病毒株表现得像腺病毒。事实证明，它是一个由两种不同病毒颗粒组成的群体。一种颗粒是真正的腺病毒。另一种颗粒是腺病毒-SV40 杂交体，它具有腺病毒外壳，但其遗传物质似乎由缺陷的腺病毒 7 型 DNA（约占腺病毒基因组的 85%）共价连接到 SV40 基因组的一部分（约 50%）组成。

在这种病毒群体中，携带 SV40 遗传物质的颗粒被称为 PARA（辅助腺病毒复制的颗粒）。PARA 被认为是一种无条件缺陷病毒，因为在任何已知条件下，它都无法自我复制，除非在与腺病毒共感染的细胞中。腺病毒被认为是有条件缺陷的，因为它可以在人类细胞中独立复制，但不能在猴细胞中复制。参见*腺病毒；动物病毒*。[L.E.M.]

## 腺病毒

与咽结合膜热、急性呼吸道疾病、流行性角结膜炎以及儿童发热性咽炎相关的病毒类别。从手术患者切除的扁桃体和腺样体中分离出多种类型。尽管腺病毒引起的大多数疾病是呼吸性的，但腺病毒经常随粪便排出，某些腺病毒已从污水中分离出来。已知哺乳动物和禽类有不同的血清型。这些属分别含有 87 种和 14 种。参见*动物病毒*。

直径为 70 纳米的感染性病毒颗粒是二十面体，其外壳（衣壳）由 252 个亚基（衣壳粒）组成。未找到外部包膜。基因组是双链脱氧核糖核酸（DNA），分子量为 $20-25 \times 10^{6}$。通过差速离心可以从感染性颗粒中分离出三种主要的可溶性抗原。这些抗原——一种所有腺病毒类型共有的群特异性抗原、每种类型独有的型特异性抗原，以及一种具有群特异性的毒性解旋酶物质——代表以远大于合成感染性病毒所用量的程度产生的病毒结构蛋白亚基。

已知的人类腺病毒类型至少有 33 种，且仍在继续分离出之前未识别的类型。血清型在中和试验中抗原性不同，但它们共享一种补体结合抗原，这很可能是病毒的一个较小的可溶性部分。

该病毒通常在实验动物中不产生急性疾病，但具有细胞毒性，即破坏人体组织培养中的细胞。人类腺病毒血清型注入新生仓鼠时会产生癌症。
