### 什么是控制语句？

在编程中，决策是程序创建复杂程序的一个重要角色。通过使用控制语句，我们可以创建动态程序，而不是不考虑用户视图的普通静态程序。通过使用这些控制语句，我们可以让用户决定想对程序做什么。

例如，在玩电脑游戏时，可以选择启动游戏或退出游戏。当用户点击“开始”按钮时，电脑游戏代码执行游戏；而在另一种情况下，它直接退出。这是计算机程序中实现控制语句的一个实际示例。

`if` 和 `else` 是控制语句的两个重要区块。当条件为真时执行第一个，而当条件为假时执行后者。让我们来看一个示例！

Python 程序代码：

```
I = 3
J = 5
```

```
If i == j
    Print(" These are equal numbers")
Else:
    Print(" These are not equal")
```

### 解释：

这个示例提供了一个简单的场景来解释 Python 中控制语句的重要性。

- i) 首先，创建两个带有值的变量，然后使用 `if` 控制语句对它们进行比较。

- ii) 在这里，“==” 表示运算符。它表示如果变量中的两个值相等，则应该在屏幕上打印下面的字符串。

- iii) 在接下来的代码块 `else` 中，如果语句为假，则执行打印语句。

在现实世界的程序中，我们可以使用嵌套的控制语句和单次执行的控制语句块来增加复杂性。Python 中的控制语句非常方便，可以帮助我们创建与用户输入交互的高效程序。

### Python 中的循环是什么？

循环是用于反复执行某语句的编程语句。Python 以及几乎每种编程语言都提供了不同类型的循环，如 `for` 循环、`while` 循环。在本节中，我们将详细讨论循环的哲学，并结合示例对 `for` 和 `while` 循环进行简要说明。请继续阅读！

#### A) For loop

`for` 循环是 Python 中使用循环最流行的方法。在使用 `for` 循环时，我们检查逻辑并打印建议的结果直到条件停止。当条件不再满足时，程序将直接退出，而不进入下一步。

这里是格式：

```
for ( i=0; i > 30 ; i++)
// 这里 i 是变量
```

这里是解释：

每当使用循环时，用户都会通过输入设备提供 'I'。现在，当程序启动时，它通过检查存在的的输入来操作。这里使用 `I>30` 条件来满足循环过程。通过循环，我们可以只用一个 `print` 语句就打印无限数字。

#### B) While loop

`while` 循环使用相同的过程，但只会在成功执行后打印结果。`for` 和 `while` 之间的主要区别在于，`for` 可以有效地用于在没有任何延迟的情况下打印嵌套循环，而 `while` 循环可以在解决问题时用于决策。

### 什么是模块？

从通俗上说，模块就像盒子，可以放在在任何需要的地方。在编程术语中，模块是独立的代码，但在任何需要时都可以被其他项目使用。它们是车辆中的备零件，但提供了比默认功能更多的能力。

模块通常有两种类型，即系统模块（标准模块）和第三方模块。

#### A) 标准模块

标准模块是在 Linux 系统安装 Python 时默认自带的模块。例如，用于在屏幕上显示信息的 `print` 语句是 Python 中的输入/输出模块。甚至某些数学函数（如 `max`、`min`）之所以工作也是因为 Python 安装时默认带了 `Math` 模块。

然而，由于能力限制，标准模块对于创建新软件绝对是不够的。如果你想通过 Python 实现更多功能，你需要了解第三方模块。

#### B) 第三方模块

第三方模块是通常不是默认安装的模块。你需要搜索并将它们下载到你的系统中进行安装。安装第三方模块最常用的方法是使用如 `pip` 这样的包管理器。

### 什么是 PIP？

Pip 是一个包管理器，负责管理 Python 仓库中提供的所有重要包，以便下载和升级。要在系统中安装 pip，请使用以下命令。

```
root@server : apt-get install python3-pip
```

这会安装 pip，这是一个轻量级的包管理器，可以在安装时高效地链接所有文件。

### 如何从 PIP 安装包？

在尝试安装包之前，先在 Google 上搜索一下你期望通过模块实现的目标。例如，如果你是一个机器学习爱好者，并希望创建一些机器学习算法，那么你需要在你的系统中安装 `Numpy`，一个机器学习 Python 模块。

所以，为了确认包是否正确，使用以下命令。

```
root@server : pip3 show numpy
```

上述命令将显示关于你尝试下载的包的所有信息。大部分信息将关于包名、所有者名称、下载次数及其创建日期。某些包还会提供许可协议详情以及该包的 URL 地址。

### 安装 Python 模块的其他方法：

并不是所有的包都可以通过 `pip` 等包管理器获得。某些模块需要从官方网站或如 GitHub 等网站下载。

从其他来源安装 Python 模块请使用以下步骤：

- 1) 首先，对你尝试下载的模块进行彻底研究。某些模块可能会刻意减慢系统。所有重要的 Python 模块都可以从 pip 获取。如果你在寻找这种选项，它可能是某个程序员编写的执行特定任务的脚本。许多 Python 脚本通常用于自动化任务。

- 2) 现在，如果源包可用，使用 `wget` 将其下载到 Python 库。Wget 是用于从网络下载任何 URL 的 Python 命令。

这里有一个命令：

```
root@server : wget https://github.com/sample
```

该命令将包下载到当前目录。

- 3) 通常下载的 Python 模块将是 `tar` 包格式。你需要使用以下命令进行解压。然而，如果你不习惯命令行解压，可以使用 GUI 压缩工具，如 gZip。

这里是命令：

```
root@server : tar -xf filename.tar.gz
```

该命令将包解压到同一目录下的独立文件夹中。

4) 现在，将文件解压到目录后，寻找名为‘install.py’ 的文件。所有的第三方模块在该目录中都有这个文件。如果你确认了文件存在，请输入下方提供的命令。

以下是命令：

```
root@server : python3 install.py
```

这将在 Linux 系统中安装该包/模块。过程完成后，你可以在终端中运行包的命令来检查包是否已安装。

如何在你自己的代码中使用模块？

### 什么是面向对象编程？

面向对象编程是一种编程范式，是在函数式编程和过程化编程发明很久之后开发的。在函数式和过程化编程中，每当需要完成任务时，就会创建并使用方法。在面向对象编程中，我们使用类和对象来完成这些任务。

我们并不是主张面向对象编程是最好的，因为每种范式都有优劣。面向对象编程的成功主要归功于它的简单性，以及创建可以在更大项目中使用类的逻辑化方法。这就是为什么 Java 和 C++ 等 OOP 语言在企业和业务中被广泛使用的原因。

# 什么是面向对象对象和类？

简单来说，对象是为了复制现实世界事物而创建的编程实体。在现实世界，事物具有属性并执行方法。同样，在 OOP 模型中，对象复制了这些属性和方法。

类是对象的集合，这种意义可以帮助我们理解其重要性。类可能不是顺序的，但由一组相似的对象组成，因此在任何项目中都易实现。

真实的示例：

想象现实世界中的船。它们是事物，因此在编程世界中作为对象。它们有引擎、甲板和颜色，这些被称为属性。这些也是属性，通常在编程中用变量和常量修饰符表示。

另一方面，可以使用这些属性来创建方法。例如，船可以使用这些存在的属性进行行驶、加速和提升重量。没有属性，你就无法完美解释方法；而没有方法，属性就没有用处。

在语法术语中，属性注定是评价名词（对象）的形容词。所有的方法都被称为执行通用工作的动词。

当我们收集不同类型的船对象并将它们分组时，这些被称为类。我们还可以创建具有更具体评估子类来创建更高效的程序。

在 Python 中：
