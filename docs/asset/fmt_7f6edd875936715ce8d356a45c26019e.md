
# 营养不良

由于缺乏单一维生素或矿物质导致的缺乏状态很少达到饮食最低营养需求的限度。在人类中，单一营养缺乏在滥用酒精或药物的个体身上最为明显。临床上经常报道烟酸缺乏（皮血病）、硫胺（维生素B）、维生素C（坏血病）和维生素D（佝性病）的临床状况。尽管有了食品强化并开发了全年提供食物和发放的计划，但在低收入家庭中仍然处于匮乏状态。在发展中国家，在许多依赖一种主食作为主要营养来源的人群中仍然观察到此类情况。具有公共卫生意义的问题是维生素A，它是发展中国儿童失盲的主要原因，也是导致疾病的主要因素。

> [D.M.L.]

营养不良是由缺乏、过量或失衡引起的。为了维持人体健康，必须在饮食中获得适量的充足能量（来自碳水化合物、蛋白质和水）以及其他食物物质。营养不良可能是由于长期摄入这些任何物质的高于或低于正常范围的水平引起的，并且可能仅指示缺乏。

因饮食摄入不足而遭受营养不良的人数尚不确定，但即使是最保守的估计也表明数百万人受影响；许多人估计这一数字接近10亿。大多数营养不良者生活在发展中国家，那里收入低，不足以购买、运输、储存和处理食物，营养缺乏几乎总是与贫困有关。在工业化国家，饮食摄入不足的慢性状况通常局限于体重减轻、禁食或采用不寻常限制性饮食的老年人，其营养需求很少能得到满足。

营养缺乏也可能由于疾病、外伤或影响食物分子吸收、消化或代谢的药物过量而引起；或者由于增加营养素需求的疾病所致。继发性营养不良在许多长期无法正常进食的患者中也经常观察到。在影响方面，营养的流失范围从轻微症状到严重的蛋白质-能量营养不良，或多种营养缺乏不等。

长期摄入低于预期的能量会导致由于体力活动变化引起的体重和肌肉量流失；这些影响会导致人变得虚弱、冷淡、抑郁，并无法完成扭转营养不良所需的工作。营养不良的后果体现在许多系统中，且变化迅速。这些变化在胃肠道、皮肤、血液和神经系统，以及吸收、排泄、贫血或神经或行为变化中最为常见。人们会特别关注伴随营养不良的免疫功能。

幼儿童蛋白质流失和感染的共同作用导致蛋白质-能量营养不良。根据外表以及蛋白质和碳水化合物的比例，它分为两种类型：消瘦症和水肿热。

饮食中的热量。消瘦症儿童由于饮食长期缺乏热量及其他营养素，导致表现为明显的消瘦。水肿热儿童也非常瘦，但由于水分滞留和肝脏脂肪积聚，身体呈现肿胀，这些症状归因于饮食中缺乏蛋白质。

## 麦芽饮料

一种由谷物发酵产生的饮料。谷物是一个通用术语，描述用谷物（特别是大麦）以麦芽形式制成的酒精饮料。艾啤酒、拉格啤酒和世啤是通过受控发酵过程制造的不同种啤酒。美国是世界最大的啤酒消费者。

乳腺是一种分泌乳汁以养幼的独特解剖结构。乳腺由许多腺泡组成，每个腺泡由一群呈球排列的上皮细胞组成。腺泡上皮细胞从血液吸收营养并分泌到腔内。这些细胞用于合成乳汁的独特成分并将其分泌。每个腺泡都连接到一个导管，通向共同导管系统，最终通过称为乳汁孔的乳头或乳头排出。
