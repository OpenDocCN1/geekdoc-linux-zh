# 9.3.3 Burp Suite

`Burp Suite`²⁴⁴ 是一个面向 Web 安全的工具集，被誉为强大的代理工具。虽然社区版包含手动测试工具，商业版包含额外功能，如强大的 Web 扫描器。`Burp Suite` 在 `OSCP` 考试中是允许的，但它并不是必要的。

> ²⁴⁴ (PortSwigger, 2019), https://portswigger.net/burp
