
## sccs-get, get

### 选项

- `-c date-time` 获取 `date-time` 参数指定的日期之前提交的最新版本。`date-time` 格式为 `yy[mm[hh[ss]]]`。指示日期省略单位的 `t7502` 等于 `-c75022823599`。非数字字符的数量表示不同的 2 位组件。如果出现空格字符，你必须对 `date-time` 指定加引号。

- `-e` 获取用于编辑的版本。对 `s.file` 加锁，以便无人向你检出的版本提交更改。如果 `s.file` 中设置了 `j` 标志，则锁是建议性的：`get` 将获得警告消息。对不同 `sid` 同时使用 `-e` 是允许的；如果目录中存在可写版本，`get` 不检出文件版本。`s.file` 中存储的所有 SCCS 保护（包括发布上限和授权用户列表）都会被 `get -e` 尊重。

- `-g` 获取 SCCS 版本 ID，而不检索版本本身。用于验证特定 `sid` 是否存在。

- `-G newname` 使用最后的版本名（`lastname`）作为检索版本的名称。

- `-i sid-list` | `-isid-list` 指定要包含在检索版本中的增量列表（deltas）列表。包含的增量将在标准输出消息中命名。`sid-list` 是一个用逗号分隔的 `sids` 列表。要指定增量范围，请在列表两个侧之间使用连字符 `-` 分隔符代替逗号。

- `-k` 抑制 ID 关键字的展开。`-k` 会由 `-e` 隐含。

- `-l[p]` 获取增量表（版本日志）的摘要并将其写入列表文件（命名为 `f`，称为 1. 文件）。当使用 `-lp` 时，将摘要写入标准输出。

- `-m` 在检索的每行前面加上该行被添加到文件中的增量 `sid`。`sid` 与行之间用制表符（Tab）隔开。

- `-n` 在每行前面加上 `%M` ID 关键字和一个制表符。当使用 `-m` 和 `-n` 选项时，ID 将位于 `sid` 和文本行之前。

- `-p` 将检索版本的文本写入标准输出。将所有通常发送到标准输出的消息改为写入标准错误。

- `-s` 抑制所有正常写入标准输出的输出。然而，致命错误消息（始终发送到标准输出）不受影响。

- `-t` 获取给定发布版本（`release`）中最近创建的（顶部的）增量，例如 `-rl`。

### `/usr/ccs/bin/get`

- `-r[sid]` 获取与指定的 `sid`（增量）对应的版本。

给定增量的 `sid` 是一个 Dewey 格式的数字，由两个字段组成：发布（`release`）和级别（`level`）字段，对于分支增量，还包括分支（`branch`）和序列（`sequence`）字段。例如，`1.2` 是 `sid`，`1` 是发布号，`2` 是级别号。`1.2.3.4` 是 `sid`，`3` 是分支，`4` 是序列号。

使用 `get` 检索版本时，不需要指定整个 `sid`。如果你完全省略 `-r` 或者省略了 `release` 和 `level`，`get` 的 `d` 标志将设置为 `s.` 文件中的 `sid`，以检索最高的发布和级别。如果你省略了 `sid`，`get` 将检索该标志指示的默认版本。

当你指定了发布但省略了级别时，`get` 将检索该发布中的最高级别。如果该发布不存在，`get` 将从下一个存在的发布中检索最高级别。

分支的情况也是如此，如果你指定了发布、级别和分支，将检索该分支中最高的序列。

### `/usr/xpg4/bin/get`

- `-r sid` | `-rsid` 与 `/usr/ccs/bin/get` 相同，但 `sid` 是强制性的。

- `-x sid-list` | `-xsid-list` 从检索版本中排除指定的增量。被排除的增量将在标准输出消息中注明。`sid-list` 是一个用逗号分隔的 `sids` 列表。要指定 `sids` 范围，请在列表两个 `sids` 之间使用连字符 `-` 分隔符代替逗号。

## 输出

### `/usr/ccs/bin/get`

`/usr/ccs/bin/get` 命令具有以下输出格式：

```
"%s\n%d\n", sid, 行数
```

### `/usr/xpg4/bin/get`

`/usr/xpg4/bin/get` 命令具有以下输出格式：

```
"%s\n%d\n", sid, 行数
```

## 用法

### ID 关键字

在没有 `-e` 或 `-k` 的情况下，通过将其替换为检索源码文本中的指定值来展开以下 ID 关键字。

- `%A` ID 行的简写表示，带有对于(I) 的数据，格式为 `%Y%%Y% %M %I%%Z%`。
- `%B` 分支组件。
- `%C` 当前行号。用于标识程序输出的“这不应该发生”的错误消息。它不是用于在每行上提供序列号。
- `%D` 当前日期，格式为 `yy/mm/dd`。
- `%E` 最近应用的增量创建的日期，格式为 `yy/mm/dd`。
- `%F` SCCS `s.` 文件名。
- `%G` 最近应用的增量创建的日期，格式为 `mm/dd/yy`。
- `%H` 当前日期，格式为 `mm/dd/yy`。
- `%I` 检索版本的 `sid`，格式为 `%R%.%L%.%B%.%S%`。
- `%L` `sid`-级别组件。

### sccs-get, get

- `%M` 模块名称，可以是 `s.` 文件中 `m` 标志的值（见 `sccs-admin(1)`）或去掉前缀的 `s.` 文件名。
- `%P` 完全限定的 `s.` 文件名。
- `%Q` `s.` 文件中 `q` 标志的值。
- `%R` `sid` 发布组件。
- `%S` `sid` 序列组件。
- `%T` 当前时间，格式为 `hh:mm:ss`。
- `%U` 最近应用的增量创建的时间，格式为 `hh:mm:ss`。
- `%W` 带有 `forwhat` 的 ID 行的简写表示，格式为 `%W%M% %I%.`。
- `%Y` `s.` 文件中 `t` 标志的模块类型值。
- `%Z` 四字符字符串：被 `what` 识别的 `theta` `#`。

# sccs-prs, prs — 显示 SCCS 历史的选部分

## 摘要

```
/usr/ccs/bin/prs [-ael] [-c date-time] [-d dataspec] [-r sid] s.filename..
```

## 描述

使用 SCCS `prs` (peruse) 命令以用户指定的格式显示 SCCS 文件 (`sccs-file(4)`) 的部分或全部。

如果用目录名代替 `s.filename` 参数，`prs` 命令将适用于该目录下的所有 `s.` 文件。不可读的文件会产生错误；将继续处理下一个文件（如果有）。使用破折号 `-` 作为 `s.filename` 参数表示从标准输入读取文件名称，每行一个 `s.` 文件。

## 选项

在没有选项的情况下，`prs` 显示增量版本（版本日志）。在没有 `-d` 或 `-l` 的情况下，`prs` 显示由其他选项指定的每个增量的条目。

- `-a` 包含所有增量，包括标记为已删除的增量（参见 `sccs-rmdel(1)`）。
- `-e` 请求早于并包含 `-r` 或 `-c` 指定增量之前的所有增量的信息。
- `-l` 请求晚于并包含 `-r` 或 `-c` 指定增量之后的所有增量的信息。
- `-c date-time` 显示在 `date-time` 参数指定的日期和时间之前提交的最新增量的信息。`date-time` 的格式为 `yy[dd[[hh[ss]]]]`。指定的日期和时间省略的单位默认为最大可能值；例如 `-c7502823599`。任意数量的非数字字符都可以分隔两个两位组件。如果出现空白字符，则必须对 `date-time` 规范加引号。
