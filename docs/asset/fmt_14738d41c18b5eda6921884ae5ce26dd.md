
氧化钙（`CaO`）是通过连续工艺对尾矿中的碳酸盐矿物进行热分解的。该氧化物因其亮度被用于高强度空气光（石灰灯），并作为钢铁制造中的熔剂。冶金工业在矿过程中广泛使用该氧化物。

氢钙（`Ca(OH)2`）用于需要氢气的混合物。在生产氢氧化物的过程中，水的溶解度扩大以产生钙（`Ca(OH)2`）。氢氧化物还用作二氧化碳吸收剂，用于石膏或木灰。

硫化钙（`CaS`）是从石灰制成的电解产物。碳酸钙（`CaCO3`）通过在电弧中将石灰和碳的混合物加热到5432 F（C）产生。

它被生产乙炔的电极。钙是工业各种重要化学化合物的原料。

纯碳酸盐以两种晶体形式存在：方解石（六棱柱形，显示双折射性）和菱形。冰岛和西班牙自然产生的本质上是纯碳酸盐，而另一种更软、更致密的变体，可能具有高纯度，尽管碳酸盐在水中几乎不溶，但在二氧化碳中具有相当的溶解度；文石。

从晚古生时代（炭盆纪和二叠纪）保存的主要方解石是斯芬克斯石。在二叠纪，尽管带有羽状骨的碳酸盐首次出现。斯芬克斯石和羽状骨在二叠纪和三叠纪非常丰富。在浅水地区常见的钙质海绵一直持续到三叠纪结束，之后斯芬克斯石逐渐减少变为羽状骨。[R.M.F.]

钙化石是脊索动物门中棘皮动物类型的化石成员。它们出现在寒武纪到白垩纪的海洋岩中（3.3亿至6600万年前），它们的大部分骨后来被方解石取代。许多显示棘皮动物与脊椎动物关系密切的脊椎动物化石表明它们是钙化的。钙质脊索动物分为三大类：`Soluta`组、`Corina`组和`Miocrata`组。[R.M.F.J.]

## 向量积分

在可能的情况下，寻找一个具有连续导数 `$F'$` 的函数，使得当 `$x_1 \leq x \leq x_2$` 时 `$F'(x) = f(x)$`。此时方程 (1) 可以写为：

$$\int_{x_1}^{x_2} f(x) dx = F(x_2) - F(x_1) \quad (1)$$

这是两个中心定理之一。如果 `$f$` 是连续的，且由 (2) 定义函数 `$F$`：

$$F(x) = \int_{x_1}^{x} f(t) dt$$

[A.L. Ta.] 则 `$F$` 有导数 `$F'(x) = f(x)$`。

如果一个函数定义在从 `$x_1$` 到 `$x_2$` 的有限区间上，`$f$` 从 `$x_1$` 到 `$x_2$` 的定积分，记为：

$$\int_{x_1}^{x_2} f(x) dx$$

它是通过应用一种涉及所谓的近似和细节的过程定义的。当 `$f$` 在某些限制条件下连续连续时，这一过程最终通过确定近似和的极限来确定极限。从 `$x_1$` 到 `$x_2$` 的定积分，除非该和收敛于定义良好的极限，否则它不是积分。此的一个充分条件是函数 `$f$` 是连续的。

定义定积分的过程有一个几何表示，它为近似和收敛到某个极限提供了合理的论据。如果我们把从 `$x_1$` 到 `$x_2$` 的区间分为 `$n$` 个等份，这些部分的长度为 `$h_n$`，并令 `$x_i$` 为第 `$i$` 部分中 `$x$` 的值（图 2）。

`$f(x_1)h + f(x_2)h + \dots + f(x_n)h$`

被称为近似和。在图 2 中，当 `$f$` 连续且所有值均为正时，该和等于阴影矩形的面积，整个矩形是 `$f$` 图像下方面积的近似值。为了包含极限，该过程通过增加 `$n$` 并使高度 `$h_n$` 趋于 0 来完成。此时需要明确定积分是曲线和 x 轴之间的面积。这种积分的解释是微积分的基本应用，即面积计算。

我们还可以通过计算近似和的极限来计算定积分。因此，通过数学推理，可以证明一个联系导数和积分的定理，使得在许多重要情况下可以通过更简单的步骤计算定积分。
