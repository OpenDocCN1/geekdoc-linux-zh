#### 第 12 章：嵌套循环和快速退出

##### 1. 编写一个程序，询问某人输入其姓名，并且仅当此人输入单词 `stop` 时才结束程序。

**提示：** 使用 `break` 关键字结束程序中的循环。

```bash
#!/bin/bash
declare flag="go"
while [ "$flag" -eq "go" ]
do
    clear
    echo "Enter your name or type stop to end:"
    read friend
    if [ "$friend" -eq "stop" ]
    then
        break
    fi
done
```

##### 2. 修改上述程序，使计算机在某人输入名字 `Tom` 时返回循环顶部。

**提示：** 使用 `continue` 关键字。

```bash
#!/bin/bash
declare flag="go"
while [ "$flag" -eq "go" ]
do
    clear
    echo "Enter your name or type stop to end:"
    read friend
    if [ "$friend" -eq "stop" ]
    then
        break
    fi
    if [ "$friend" -eq "Tom" ]
    then
        continue
    fi
done
```

##### 3. 修改上述程序，使得仅当用户没有输入名字 `Tom` 且没有输入单词 `stop` 时，才显示个人问候语。

```bash
#!/bin/bash
declare flag="go"
while [ "$flag" -eq "go" ]
do
    clear
    echo "Enter your name or type stop to end:"
    read friend
    if [ "$friend" -eq "stop" ]
    then
        break
    fi
    if [ "$friend" -eq "Tom" ]
    then
        continue
    fi
    echo "Hello, $friend"
done
```

##### 4. 编写一个使用 `if` 语句确定姓氏是否为 `Smith`，然后确定名字是否为 `Bob` 的程序。如果匹配，在屏幕上向 `Bob Smith` 说 `Hello`。

**提示：** 使用嵌套的 `if` 语句。

```bash
#!/bin/bash
declare fname="Bob"
declare lname="Smith"
if [ "$lname" -eq "Smith" ]
then
    if [ "$fname" -eq "Bob" ]
    then
        echo "Hello Bob Smith"
    fi
fi
```

##### 5. 编写一个程序，显示 `name has these degree degrees`，但将 `Bob`、`Mary` 和 `Joan` 替换 `name`，将 `BS`、`MS` 和 `Ph. D.` 替换 `degree`。

**提示：** 使用嵌套的 `for in` 循环。

```bash
#!/bin/bash
for name in Bob Mary Joan
do
    for degree in BS MS Ph.D.
    do
        echo "$name has these $degree degrees"
    done
done
```
