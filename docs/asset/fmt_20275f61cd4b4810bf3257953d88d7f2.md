
位于`/etc`目录下的`auto.master`文件是默认的主映射，其由`/etc/autofs.conf`配置文件中的`master_map_name`指令定义。该映射可用于定义间接映射和直接映射的条目。然而，建议将用户自定义的映射文件存储在`/etc/auto.master.d`目录下，AutoFS服务在启动时会自动解析该目录。以下提供了两个示例，以说明映射条目的格式：

```
/-/etc/auto.master.d/auto.direct
/misc      /etc/auto.misc
```

第1行定义了一个直接映射，并指向`/etc/auto.master.d/auto.direct`文件以获取挂载详情。

第二个是间接映射，通知AutoFS参考`/etc/auto.misc`文件获取挂载详情。伞形挂载点`/misc`将位于`/etc/auto.misc`文件列出的所有挂载点条目之前。该间接映射条目通常用于自动挂载移动文件系统，如CD、DVD、外部USB磁盘等。

你可以在`auto.master`文件中的任何一个条目后添加选项；但是，该选项将全局应用于指定映射文件中的所有子条目。

## 直接映射 (The Direct Map)

直接映射用于在任意数量不相关的挂载点上自动挂载共享。使用直接映射时需要注意以下几个关键点：

- 直接挂载的共享对用户始终可见。
- 本地和直接挂载的共享可以在同一个父目录下共存。
- 访问包含许多直接挂载点的目录会挂载所有共享。

每个直接映射条目都会向`/etc/mtab`文件放置一个单独共享条目，该文件维护了所有已挂载文件系统的列表（无论是本地还是远程）。当本地文件系统、可移动文件系统或远程共享被挂载或卸载时，该文件就会更新。

### 练习 16-3：使用直接映射访问 NFS 共享

此练习应在`server1`上以`user1`身份执行，需要时使用`sudo`。

在此练习中，你将配置一个直接映射来自动挂载来自`server2`的NFS共享`/common`。你将安装相关软件，创建本地挂载点`/autdir`，并设置AutoFS映射以支持自动挂载。注意，`/common`已经通过`fstab`文件挂载在`server1`（NFS客户端）的`/local`挂载点上。两者之间配置或功能上不应有冲突。

3. 编辑`/etc/auto.master`文件，并在文件开头添加以下条目。该条目将引导AutoFS服务指向`auto.dir`文件以获取额外信息。

