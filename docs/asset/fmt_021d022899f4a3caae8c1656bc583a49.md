# Linux 词典

传输控制协议。TCP/IP 的传输协议。关键点：TCP 是“面向连接的”。这意味着在发送任何数据之前必须完成三次握手。对比：有两种传输协议：TCP 和 UDP。由于 TCP 面向连接，基于 UDP 的应用程序很容易被伪造。格式：

| 端口 | 目标端口 |
| :--- | :--- |
| 序列号 | |
| 确认号 | |

校验和 本包内第一个字节的序列号。确认号 反方向包的预期序列号。未使用。注意“字段”实际上指的是：数据偏移的低位和标志位的高位。紧急标志用于发送所谓的带外数据。关键点：TCP/IP 堆栈通常不实现第一个，没有任何应用程序使用它。事实上，针对 Windows 的 Winuke 攻击是因为 Windows 在处理数据时会崩溃。ACK 当确认字段有效时设置。关键点：每个包都会设置，但第一个不是，因为每个 TCP 包都会确认最后接收的数据。关键点：为了阻塞连接，防火墙通常允许设置了 ACK 位的包。换句话说，阻塞 TCP 连接的第一个包将阻止连接建立。关键点：黑客无法连接到服务器，他们仍然可以使用这种技术进行端口扫描。PSH 正常：TCP 将多个数据包合并为一个包，这比分片更有效，但是以延迟为代价的（在接收第一个分片后，它必须等待一会儿是否有其他分片到达）。此位告诉堆栈立即推送数据而无需等待。RST 告知对方发生了错误。这将关闭连接或将其设置为回退状态。关键点：TCP/IP 堆栈会对不同条件发送重置，这可以用于识别堆栈指纹。SYN 开始连接。最重要的考虑是同步双方的序列号。SYN 获取更多信息。FIN 关闭连接。关键点：如果向开放端口发送 FIN 包，它将不会响应。某些错误的堆栈会响应，从而允许你识别系统指纹。关键点：监控网络流量的 IDS 系统有时会通过伪造 FIN 来杀死 TCP 会话。

## TCP 序列号预测

在尝试伪造 TCP 连接时，入侵者面临着一个困难：他永远无法看到 SYN 数据包的响应。这个问题需要发送回伪造的地址以继续对话，而该连接使用的是受害者使用的序列号。历史：凯文·米特尼克（Kevin Mitnick）被中村俊武（Ttsumu Shimura）发现正在进行 TCP 序列号预测并被捕。当中村能够捕获到米特尼克以预测下一个序列号时，你必须首先通过非伪造连接获取上一个数字。历史：最早指出这一问题之一是 Robert T. Morris，他在 1985 年发表了一篇题为《2.2BSD UNIX/IP 服务器的弱点》的论文。出自 Hacking–Lexicon `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

## TCP 传输控制协议

（通常写作 TCP/IP，它运行在 IP 之上）。TCP 是一种确保数据按顺序接收且无误的协议。这是因为计算机数据在互联网上传输时会被分成许多小的“数据包”，这些数据包可能会通过不同的路由传输。出自 Faculty–of–Education `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

## TCP-IP

传输控制协议/网协议。它是 Linux 机器上最常用的数据通信协议。[传输控制协议/网协议] 构成互联网的广域网协议，也是唯一大师们在说出它的名字时不会大笑或作呕的协议。与所谓的“标准”竞争对手（如 X.25、DECNet 和 ISO 7 层协议栈）不同，TCP/IP 是通过实际使用演化出来的，而不是由供应商或带有高度政治色彩的标准委员会分发的。出自 Guide @FirstLinux `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

## tcp-wrappers

几乎所有提供的服务都是通过 `tcp-wrappers` 守护进程调用，`tcp-wrappers` 机制为所有请求它的服务提供了访问控制限制和日志记录。它可以用于 TCP 或 TCP 服务，因为这些服务是通过入站的 telnet、ftp、rsh、login 等调用的。请求选项包括针对主机、名称和/或服务的访问控制；检测主机名欺骗或地址欺骗；用于实施预警系统的弹跳陷阱。出自 Linux System Security `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

## TCP/IP

`/TCP-IP/` 名词。1. [传输控制协议/网协议] 构成互联网的广域网协议，也是唯一大师们在说出它的名字时不会大笑或作呕的协议。与所谓的“标准”竞争对手（如 X.25、DECNet 和 ISO 7 层协议栈）不同，TCP/IP 是通过实际使用演化出来的，而不是由供应商或带有高度政治色彩的标准委员会分发的。因此，它 (a) 可以工作，(b) 实际上促进了廉价平台间的连接，(c) 磨炼了各地企业和政府帝国建设者。黑客看重这三个属性。有些人从中看到了造物论。2. [业余数据包电电] 曾被揭露为“Phil 在推的垃圾”。该引用指的是 Phil Karn (KA9Q)，背景是大多数运行 AX 的站点与 TCP/IP 继站之间正在进行的技术/政治战争。出自 Jargon Dictionary `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## TCP/IP (TCP/IP 族，TCP/IP 协议栈)

描述互联网上使用的协议。该术语的演变是因为这是工程师最重要的两个协议。如果你谈论如何让数据跨网络从机器传输，你就是在谈论 IP 包。如果你对应用程序之间的抽象通信感兴趣，你就是在谈论 TCP 连接。如果你谈论通用的传输数据封装（涵盖机器和应用两个概念），那么简单称为 TCP/IP。出自 Hacking-Linux `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## TCP/IP (传输控制协议/网协议)

这是定义互联网的适用协议。TCP/IP 软件最初为 UNIX 操作系统生成，现在已包含在各种操作系统中。要尝试互联网，你的计算机必须拥有 TCP/IP 软件。出自 Matisse `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
