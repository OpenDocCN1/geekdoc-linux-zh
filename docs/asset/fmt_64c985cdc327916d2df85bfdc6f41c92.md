# 商业可用备份实用工具

目前市面上有几种商业可用的备份实用工具。与使用系统实用工具、`export`/`import`甚至`RMAN`进行手动操作相比，这些工具具有若干优势。大多数这些商业备份实用工具实际上使用`RMAN`从数据库中获取数据，但具备企业级备份解决方案所需的增强功能。以下是一些此类功能：

- **磁带库支持** 大多数大型安装必须使用复杂的磁带库，以支持需要备份的数据量。
- **自动调度** 这允许你安排定期备份。
- **磁盘暂存** 几种商业备份解决方案允许磁盘暂存以及磁带备份。
