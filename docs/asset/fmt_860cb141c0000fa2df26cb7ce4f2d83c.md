
由于这种安装程序的出现，现在有越来越多基于 USB 接口的应用程序，如 USB 键盘、USB 鼠标、USB 光驱等。在安装系统时，虽然可以使用 USB 光驱进行安装，但目前 USB 光驱的成本相对较高，而通过 U 盘安装系统不仅成本低，而且快速方便。在大规模系统安装中，通过 U 盘已成为主流程序。

通过 U 盘安装 Linux 系统的基本步骤如下：

1) 首先，需要一个大约 8GB 的 U 盘。容量越大越好。如今 Linux Mint 的完整 ISO 镜像文件大小已达到 7GB。在决定制作 USB 安装介质之前，请务必确认文件大小。

2) 从开源网站 (`http://mirrors.163.com`) 下载 Linux Mint 的 ISO 文件。或者您可以直接访问 Linux Mint 官方网站选择您偏好的磁盘镜像进行安装。

3) 从互联网下载一个 U 盘刻录工具。常用的 U 盘刻录工具包括 UltraISO、USBWriter 和 Rufus。这里推荐使用 USBWriter，因为它易于使用，且可以一步刻录磁盘镜像文件。虽然 UltraISO 也可以将 ISO 镜像刻录到 U 盘，但刻录的 U 盘在安装和启动过程中有时会出现问题。如果您使用 Windows 系统制作安装介质，我们强烈建议您使用 Rufus 来刻录 U 盘，因为它更方便且是推荐的做法。

4) `USBWriter` 是一个开源工具，可以从 `http://sourceforge.net/projects/usbwriter/` 下载。它是一个专门用于 Linux 系统的 U 盘刻录工具。

它的工作原理是将 U 盘分为两个分区：一个 FAT32 分区（大小仅几 MB）用于安装启动程序，另一个 Linux 分区用于存储系统安装包。

有时会出现一个已知问题：

使用 `USBWriter` 刻录后，U 盘的容量会自动变小。这是因为只能看到一个 FAT32 分区，另一个 Linux 分区在 Windows 下是不可见的。但不用担心，很容易将 U 盘恢复到原始大小。从互联网下载 `Diskius` 工具即可将 U 盘恢复到原始大小。

5) 使用 `USBWriter` 将下载的 ISO 镜像文件刻录到 U 盘。首先选择 ISO 镜像文件的位置，并指定需要刻录的 U 盘（例如选择一个 16GB 的 U 盘）。选中后点击“写入（Write）”按钮开始刻录过程。

将 ISO 文件刻录到 U 盘后，U 盘上之前的所有数据将丢失，刻录前请备份 U 盘中的数据。

6) U 盘刻录过程相对快，通常需要 10 到 30 分钟。如果刻录过程中没有错误，则刻录基本上就成功了。U 盘刻录完成后，将提示刻录成功。

7) U 盘刻录成功后，你需要重新插入 U 盘。此时，在 Windows 磁盘管理器中，你可以看到 16GB 的 U 盘大小变成了约 6MB。

8) U 盘刻录成功后，将 U 盘插入服务器的 USB 接口，然后进入 BIOS 设置从 USB 设备启动，然后重启系统进入提供更多选项的界面。

9) 接下来的安装过程与我们之前介绍的光驱安装方法完全相同，因此将不再重复介绍。但需要注意的是磁盘分区阶段，你会看到两个磁盘。

在完成（U 盘刻录）后，U 盘就就绪了，你可以用它在任何电脑上安装 Linux。

# 第一章

## 在 Linux 中安装软件和软件包

与所有操作系统一样，安装软件也是 Linux 的一个必用用例。Linux 使用了组织良好的包管理系统，并在操作正确的情况下，以一种更完美的方式安装软件。初次处理 Linux 软件的安装和更新时，可能会感到有些复杂，但随着时间的推移，你会发现 Linux 的安装哲学是非常有条理且易于的。作为一名黑客，理解并找到简单的软件安装方法至关重要，以防破坏系统。即使你是在使用 Live USB 进行黑客攻击，理解 Linux 中包的安装工作原理也是至关重要的。

为了帮助你理解这些概念，我们在本章中提供了各种用例和示例。请跟随我们一起！

### 它与 Windows 有何不同？

与 Linux 相比，Windows 的安装程序可能看起来很直观，但事实并非如此。Windows 安装文件巨大，因为它们创建了一个沙箱来包含软件在不同实例调用的所有 API。这导致安装文件变大，并可能在以后引起延迟问题。

然而，Linux 使用不同的方法来安装文件。它使用紧密封装且独立的软件包，并由它们自己的实例进行更新。这有时可能会引起问题，但大多数时候它运行得非常完美。

### 如何在 Linux Mint 中安装软件？

众所，Mint 是一个基于 Debian 的轻量级系统，甚至可以在低端系统上运行。不同的 Linux 发行版使用不同的包管理器。例如，Arch Linux 作为一个开发者喜爱的 Linux 发行版，使用 `Pacman` 来安装软件。

所有基于 Debian 的系统基本上都使用 `apt` 来安装软件。`Apt` 是一个简单的包管理器，它紧密集成了所有组件，并使用脚本文件中提供的指令将它们安装到 Linux 中。

#### 它是如何工作的？

当调用一个软件时，首先下载第一个脚本文件，然后包管理器将分析系统正常运行所需的所有组件。如果系统已经安装了某个组件，它将跳过到下一个进行下载。在安装所有组件后，软件将在几秒钟被打包并安装到 Linux 系统中。

这是一个命令：

```
apt-get install python
// 这将 Python 下载到 Linux 系统中
```

### 如何搜索软件包？

`Apt` 几乎提供了 Linux 爱好者和开发者青睐的所有著名软件包。然而，由于兼容性原因，有很多第三方软件包可能无法使用。

如果你正尝试下载一个软件包，且你不确定该软件包是否存在于包管理器中，你可以使用搜索命令来找到它。如果你没有针对包名得到任何准确的结果，那么显而易见 apt 不支持你的软件包。

这是一个命令：

```
root@server : apt-cache search Python4
// 这将搜索 apt 仓库并在命令行中显示“no results”
```

为了获得更准确的结果，请使用 apt 仓库的网页版本，那里所有可用软件包甚至根据类别进行了排序。

如果你正在使用 Arch Linux，`Pacman` 也提供了搜索选项，在下载和安装软件包之前进行检查。

### 如何删除软件？

从操作系统中删除软件与将软件安装到系统中同样重要。

你可能会疑惑，为什么删除一个对你的 Linux 系统没有造成任何损害的软件是重要的？但请听专家的建议，因为过时的空闲软件可能会与新安装的软件发生冲突。

如果 Linux 系统中存在潜在冲突，可能会导致整个操作系统崩溃。删除不需要的软件可以提高系统性能，并帮助用户将那些浪费的内存资源分配给更有价值的事物。

伦理黑客也应该理解如何删除软件，因为当他们检测到攻击者为了劫持系统而插入任何木马或爬虫时，他们应该能够尽快从系统中清除痕迹。某些高风险木马在你不手动找到并结束其进程之前是不会删除的。如果黑客使用潜在危险的方法来实现软件，那么删除软件将非常困难。

现在，我们将学习使用像 `apt` 这样的包管理器来删除软件。

是一些命令：

```
apt-get remove python
// 这将删除 python
```

对于黑客来说，许多自动化某些任务的脚本通常是由黑客上传给社区的。许多键盘记录工具和监控工具也是由开源社区上传的。

如果你是一个初学者，并尝试使用代码来实现你的攻击技术，那么将该仓库克隆到你的 Linux 系统中是合情逻辑的。要实现这一点，请使用下文提到的命令。

```bash
root@server : apt-get install git

// 这会在你的 Linux 系统中安装支持 git 的系统
root@server : git clone https://github.com/enterurlhere

// 这会将你所需的仓库克隆到 Linux 系统
```

至此，我们已经完成了关于在 Linux 中使用包管理器安装、更新和删除软件的简要介绍。你也可以在必要的权限后，使用可执行的 `.deb` 文件在 Linux 中安装软件。在下一章节中，我们将学习进程管理，这被认为是对于使用 Kali Linux 进行攻击的黑客来说是一项必备技能。请跟上节奏！

# 第二章

## Linux 中的进程管理

在深入理解安装哲学和 Linux 用途之后，你现在已经准备好进入一个新的 Linux 领域，这可以帮助你作为黑客激发更多重大的思考。Linux 使用进程来维护并让所有组件与 Linux 内核进行交互。如果没有进程在运行，那么我们可以肯定地说 Linux 系统已经关机。作为一名黑客，理解进程、操纵它们并在必要时结束它们是一项受幸运的技能。在本章中，我们不仅提供关于 Linux 进程的基础知识，还将提供可以帮助你更具体地理解 Linux 基础的示例。请跟上节奏！

### 什么是进程？

进程是 Linux 程序运行的内容。它们代表了软件/命令行工具正在与 Linux 内核等系统资源交互，以完成它应该做的事情。Linux 中运行的每个软件都有一个进程，如果手动结束该进程，软件将停止工作。

作为一名黑客，当你访问系统时，你很容易被 Linux 系统中运行的防病毒进程监控到。为了让它们停止向系统管理员发送日志，你可能需要手动结束它们的进程。

虽然像使用 Windows 任务管理器那样结束进程看起来很简单，但如果操作不当，可能会导致严重的后果。你需要具备实践经验并对进程管理有良好的理论理解，才能实现你的愿望。

在接下来的章节中，你将学习一些查找和管理进程的技巧，以及根据你的方便自动管理它们的方法。

### 如何查看进程？

每当 Linux 系统启动时，某些进程会自动开始打开。每当你打开终端或网络浏览器时，相应的进程就会被打开。当你关闭某些进程时，部分进程会自动关闭，而其他将在后台运行并消耗你的系统资源。

这里是查看进程的命令：

```bash
root@server : ps
// 这显示 Linux 系统中运行的所有进程
```

这里是示例输出：

```
PID
45637
// 这些数字是进程的标识符
```

如果你想对特定进程进行任何更改，那么你应该记录下进程号。输出信息将显示其他信息，如进程名称、时间和以及它正在使用的命令类型。如果你是从终端打开的进程，那么 bash 命令将出现在输出信息中。

注意：

查找进程有时是一项艰巨的任务，因为你需要从几十个正在运行的进程中进行搜索。在更改进程状态之前，请务必确保你是信心的。如果你以任何方式终止了运行 Linux 系统的系统进程，可能会停止响应，直到下次重启。

### 如何显示额外信息？

通常使用 `ps` 命令，你只能获得基本信息。你可以使用 `aux` 命令显示有关进程的额外信息。让我们通过示例检查。

```bash
root@server : ps aux
// 这打印出描述关于进程大量信息的输出
```

这里是示例输出：

```
PID - 2134 %CPU -2.3%MEM - 32% Start Time - 22:34
// 它显示了额外信息，例如它消耗的内存和 CPU 功率。它还显示了启动时间以便于估计进程名称
```

`aux` 命令还描述了启动进程的实例。这对于法医调查人员至关重要，因为他们可以使用此程序轻松地追踪攻击的源点。

### 如何过滤进程？

想象你正在寻找一个你急需停止的进程，但由于输出屏幕上显示了许多其他进程，很难找到它。如果你很聪明，你会找到一种过滤所需进程的方法，而不是手动遍历所有进程来寻找你想要的。

如果你想表现得聪明，Linux 为你提供了。Linux 专门提供了使用 `grep` 命令过滤进程的功能。这里有一个供你理解的示例。

```bash
root@server : burp suite
// 首先使用默认命令启动一个进程或你喜欢的任何软件
root@server : ps aux | grep burpsuite
```

```bash
// 现在使用此命令过滤掉通过使用 "burp suite" 命令启动的进程
```

这将显示类似于我们之前展示的输出，其中包含了理解该进程所需的所有信息。

### 如何找到问题进程？

在描述贪婪进程之前，我们应该谈论一个这些来变得非常流行的场景，特别是在 Windows 系统中。

如今许多垃圾邮件发送者和黑客在安装到你系统的应用程序中包含了挖矿程序。当你自愿或出于其他原因安装它时，你的计算机将变得非常慢，且无法正常运行。

### 为什么会发生这种情况？

因为挖矿程序强制使用所有系统资源并在后台运行。普通用户无法观察它，因为它是隐藏的。只有能够访问终端的专业人士才能判断操作系统是否存在恶意软件。作为系统管理员，你应该意识到杀死贪婪进程。

### 如何找到高资源进程？

要找到高资源进程，你只需要作为 root 用户输入以下命令。

```bash
root@server : top
// 这将显示分配了最大资源的信息
```

如果你觉得这些高资源进程中的任何一个对你的系统都是不必要的，你可以用 `kill` 命令结束它们，我们将在接下来的章节中讨论。

### 如何在 Linux 中设置优先级？

在一个运行大量进程的 Linux 系统中，作为道德黑客或系统管理员，始终建议使用 `nice` 命令为进程设置优先级。

### 为什么要设置优先级？

如果你是一个个人用户，那么设置优先级看起来并不智能，因为你拥有所需的所有资源。但想象如果你在企业并使用 Linux 维护的其他用户的资源，那么为你自己使用所有系统资源是不可能的。如果你这样做，你的系统管理员可能会发现并暂时阻止你的访问。

许多新手黑客破解系统后一次性攻击所有资源，通知系统管理员并关闭对系统的访问。如果你是一个聪明的黑客，你会仔细地设置进程优先级而不引起过多注意，当你获得所有所需的敏感信息时，结束进程并删除所有日志，这样就不会给法医调查人员留下任何足迹。

### nice 命令到底是做什么的？

`nice` 是一个 Linux 工具命令，开发用于根据其重要性给进程打分。优先级数字可以自定义，但它们通常范围在 -19 到 +19 之间。在这里，0 是中性范围，而 -19 用于确定最弱的偏好进程，+19 用于确定最偏好的进程。

```bash
root@server: nice -n 5 /bin/terminal
// 这是一个优先级为 5 的进程
root@server: nice -n 10 /bin/game
```

```
// 这是一个优先级为 -10 的进程
```

因此，当系统资源下降时，优先级为 -10 的进程将自动结束。任何情况下，低优先级进程都不应该占用系统。系统管理员通常会花费大量时间为系统中的完美进程进行优先级排序。如果你是一个黑客，你也应该学习如何进行排序，以便在尝试窃取信息的同时有效管理资源。

你可以随时使用 `renice` 命令更改进程的优先级顺序。

```
root@server: renice 13 7732
// 在这里将进程 ID 7732 的优先级更改为 13
```

在下一节中，我们将讨论如何杀死进程。学习杀死进程对于黑客来说是一项备受推崇的技能，因为他们经常需要关闭管理员使用的入侵检测系统。

### 如何杀死进程？

某些进程通常被称为“僵尸进程”，因为即使它们在系统中处于冻结或卡住状态，也会消耗大量资源。如果你运行了任何不值其所占资源之价值的进程，那么不计代价地杀死它们是一个明智的选择。

这里有一个命令：

```
root@server : kill -1 3638
// 这个 -1 表示在先杀死进程后应将其重启
root@server : kill -9 3638
// 这个 -9 表示该进程需要立即终止
```

在本章的最后一节中，我们将讨论进程调度。

### 如何调度进程？

在任何操作系统或计算机操作管理系统中，进程调度都是一项必须掌握的重要技能。调度不仅可以减少工作量，还能帮助你理解如何智能地使用资源。

例如，你可以安排仅在从网络浏览器下载文件后才启动杀病毒进程。

在 Linux 中，使用 `at` 工具来调度进程。

这里有一个命令：

```
root@server : at 9:00pm
// 这将启动 at 命令实用程序，它可以用于调度进程
root@server : at > /root/users/startscript
// 在上述时间，提到的脚本将作为进程启动
```

通过使用调度功能，黑客即使在失去访问权限也可以运行远程程序。你可以将程序与 metasploit 漏洞脚本绑定，使它们在几秒钟将信息发送到你的手机或服务器。

### 接下来做什么？

至此，我们已经完成了对进程管理的简要且完整的介绍。在下一章中，我们将结合大量示例讨论 Linux 文件管理。让我们开始吧！

# 第三章

## Linux 中的文件管理

在上一章中，我们一致地讨论了进程管理对黑客的重要性。如果你在认真地使用 Linux 进行黑客活动，你应该具备足够关于 Linux 文件管理和目录权限的信息。

许多新黑客在获得访问权限后，由于缺乏文件和目录权限而无法获取所需信息。Kali Linux 使用复杂的目录结构和目录管理哲学来应对普通 Linux 发行版可能面临的漏洞。在本章中，我们将通过具体的示例讨论许多此类场景。请跟上！

### Linux 中的用户和组是什么？

每个操作系统都使用“用户”概念来确定谁在使用什么。例如，Windows 使用一些某些名为“管理员”的复杂账户来访问系统文件。如果你不是管理员，就没有机会访问对黑客重要的 C 程序和系统文件。

同样，Linux 使用了更复杂的用户管理系统，以便更方便的访问和高级安全功能。

- 用户 - 用户是指可以访问系统特定区域的个人。
- 组 - 组是用户组合，可以共同访问特定的资源。

现在我们将更详细地讨论 Linux 中不同类型的用户。

1) 首先，你需要了解 Linux 系统的头部。也就是说，它是所有人中最强大的一个。它通常被称为 `root 用户`。`root 用户`是最强大的，可以在系统中做任何事情。他可以随所欲添加或删除用户和组。通常，root 权限被授予企业的系统管理员。作为黑客，你的主要格言应该是获得 root 权限，因为有了它你可以做任何你想做的事。

2) 接下来就很简单了。普通用户是指没有 root 权限的用户。他们可以访问什么完全由 root 用户决定。如果有一家服务公司，开发者将仅获得代码资源，而管理员工将仅获得管理文件。每家企业都有自己的方法来决定用户应该访问什么。

### 如何授予权限？
