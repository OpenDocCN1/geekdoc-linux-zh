# 第 7 章

## 光与影

到目前为止，你一直集中在 `VIZ` 中构建场景的方法上。在本章中，你将学习如何通过操纵光影来控制所构建对象的外观。

影响模型外观三个主要要素是：材质、摄像和照明。本节将向你介绍照明的影响。

照明是 `VIZ` 中最有趣的话题之一。你可以使用照明来创建效果、强调模型的某些部分，或者简单地设置一个白天场景。通过照明，你可以控制阴影、调节反射颜色、计算光穿过透明材料时的折射，并根据灯具制造商的规格模拟灯具。最好将 `VIZ` 中的灯光使用被视为一种绘图工具，用来为你的模型增加重点、色彩或真实感。

在本章中，你将学习如何：

- 创建并调整不同类型的灯光
- 渲染场景
- 定义阴影效果
- 保存和恢复场景状态

## 为你的模型布光

灯光是你手头最重要的工具之一。你是否能够成功渲染模型，在很大程度上取决于你对模型中照明的控制和操纵能力。糟糕的设置可能会毁掉出色的建模工作，而适当的光照可以强调场景中最好的部分。这个主题有很多要介绍，所以让我们从概述 `VIZ` 中提供的不同类型的灯开始吧。

## 理解灯光的类型

到目前为止，你一直依赖 `VIZ` 的默认照明。在开启了平滑+高光（`Smooth + Highlights`）的透视视图中，光源来自观众的位置。在摄像机视图（`Camera view`）中，默认光源与相机的位置相同。

`VIZ` 提供了令人目花缭乱的灯光类型。有五种标准灯光、两种照明系统（日光和阳光）、八种光度灯、两种 `mental ray` 灯光以及天光（`Skylight`）。天光、照明系统、光度灯和 `mental ray` 灯光相当复杂，作为入门介绍，你将首先关注标准光。之所以有这么多灯类型，部分是历史原因，并与你渲染模型的各种方式有关，你将在第 11 和第 12 章中学习。

### 标准光类型详解

标准光包括目标聚光灯（`Target Spot`）、目标直光（`Target Direct`）、自由聚光灯（`Free Spot`）、自由直光（`Free Direct`）和全向光（`Omni`）。正如你从名字中猜的那样，目标（`Target`）和直射（`direct`）灯有两个版本。

名称带有 `Free`（自由）的灯光使用目标助手，该助手与光源相连并可以与其分离。光源始终指向其自己的目标，因此你通过移动目标来改变灯光的方向。

名称带有 `Free`（自由）的灯是不需要放置目标点的光源。你可以自由地旋转和移动自由灯光，而不需要变换目标位置。自由灯光的缺点是它们稍微难对准，因为你必须旋转光源来调整这些灯的方向。优点是它们在动画场景中更容易移动，你不需要同时移动它们的目标。

在移动自由灯光时，始终使用本地参考系统（`Local Reference System`）以获得对旋转更好的控制。

以下是这些不同类型灯光的简要介绍：

- `Target Spot`（目标聚光灯）：像聚光灯或汽车大灯一样，目标聚光灯从单个点光源发射光束，并可以指向特定方向。从它发出的光线随着距离光源的增加而发散。目标聚光灯可能是 `VIZ` 中使用的最多功能的光源之一。
- `Target Direct`（目标直光）：也称为方向光，目标直光是一种光线保持平行的光源，而不是随着与光源距离增加而发散。直光是一个单一、非常直接的光源，就像我们的这种，其光线在到达地面时几乎是平行的。
- `Free Spot`（自由聚光灯）：自由聚光灯与目标聚光灯类似，但它没有目标助手。使用目标聚光灯时，你必须移动目标来旋转灯。自由聚光灯可以使用工具在任何方向自由旋转。
- `Free Direct`（自由直光）：自由直光与目标直光相同，只是不使用目标助手。像自由聚光灯一样，自由直光可以自由旋转而不涉及目标点。
- `Omni`（全向光）：全向光像白炽灯一样向所有方向辐射光。像目标聚光灯一样，全向光是你经常使用的多功能光源。由于全向光没有特定方向，它没有版本区分。
