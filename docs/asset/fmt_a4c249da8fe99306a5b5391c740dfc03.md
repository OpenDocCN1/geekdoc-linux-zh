## 输入/输出

在执行命令之前，你可以使用 shell 解释的特殊符号来重定向它的输入和输出。以下语法可以用在简单命令的任何位置，或者放在命令之前或之后，且不会传递给被调用的命令。命令和参数替换在单词或数字使用之前发生，但下文另有注释。文件名生成仅在模式匹配单个文件时发生，且不进行空白解释。

- `<word` 使用文件作为标准输入（文件描述符 0）。
- `>word` 使用文件作为标准输出（文件描述符 1）。如果文件不存在，则创建它。如果文件存在且设置了 `noclobber`（禁止覆盖）选项，则错误；否则将其截断为 0。
- `|word` 与 `>` 相同，但覆盖 `noclobber` 选项。
- `>>` 使用文件作为标准输出。如果文件存在，则寻找到文件末尾（EOF）并追加内容；否则创建文件。
- `<>word` 打开文件进行读写作为标准输入。
- `<<-word` 读取标准输入直到与 `word` 相同的行或文件末尾。对 `word` 不执行参数命令、替换或文件名生成。生成的文档称为“在此文档”（here-document），如果 `word` 的任何字符被引号引用，则对文档字符不进行任何解释；否则将进行参数和命令替换，忽略 `\newline`，并且必须使用 `\` 来引用字符 `\$`, `\^`, `\``, 以及 `word` 的第一个字符。如果你在 `<` 后面附加 `-`，则从 `word` 和文档中删除开头的制表符。
- `<&digit` 从文件描述符 `digit` 复制标准输入（参见 `dup(2)`）。同样，使用 `>&digit` 可用于标准输出。
- `<&-` 关闭标准输入。同样使用 `>&-` 用于标准输出。
- `<&p` 将协进程的输入移动到标准标准输入。
- `>&p` 将协进程的输出移动到到标准输出。

如果上述任何符号前面有一个数字，则所指的文件描述符由该数字指定（而不是默认的 0 或 1）。例如，... `2>&1` 意味着打开文件描述符 2 用于写入，作为文件描述符 1 的副本。

指定的重定向顺序非常重要。shell 会根据评估时的（文件描述符，文件）关联关系来评估每个重定向。例如，... `1>file2>&1` 首先将文件描述符 1 与文件名关联。它将文件描述符 2 与文件描述符 1 关联的文件（即 fname）。如果重定向顺序反过来，文件描述符 2 与终端关联（假设文件描述符 1 已经关联），然后文件描述符 1 与文件名关联。如果命令后面跟着 `&`，则作业控制未激活，此时该命令的默认标准输入是空文件 `/dev/null`。否则，执行命令的环境将包含经输入/输出规范修改的、调用 shell 的文件描述符。

## 执行

每当执行一个命令时，上述替换将按照以下顺序进行。

- 如果命令名匹配特殊命令之一，则它在当前 shell 进程中执行。
- 检查名名是否匹配用户定义的函数之一。如果是，则保存位置参数并重置为函数调用的参数。当函数完成或返回时，将恢复位置参数列表，并执行函数内对 `EXIT` 设置的任何 `trap`（捕捉）。函数的值是 shell 进程的值。
- 如果命令名既不是特殊命令也不是用户定义的函数，则创建一个进程并尝试使用 `exec()` 执行该命令。shell 变量 `PATH` 定义了包含命令的目录的搜索路径。备用目录用冒号 (`:`) 分隔。默认路径为 `/bin:/usr/bin::`（按顺序指定 `/bin`、`/usr/bin` 和当前目录）。可以通过两个或多个相邻的列，或者通过路径列表的开头或结尾来指定当前目录。如果命令名包含 `/`，则不使用搜索。否则，在路径中的每个目录中查找可执行文件。如果文件具有执行权限但不是目录或输出文件，则假设它是一个包含 shell 命令的文件。将产生一个子壳来读取它。在这种情况下，所有未导出的别名、函数和变量都会被移除。括号中的命令在子壳中执行，且不会移除未导出的内容。

## 算术扩展

由双括号包含并在美元符号 `$` 前前的算术表达式 `$$ ((arithmetic-expression))` 被替换为双括号内算术表达式的值。算术扩展提供了一种求值算术表达式并执行其值的机制。算术扩展的格式如下：

`$((expression))`

表达式的处理方式就像在双引号中一样，但表达式内部的双引号不被特殊处理。shell 会扩展表达式中的标记用于参数扩展、命令替换和删除引号。

接下来，shell 将其视为算术表达式并替换表达式的值。算术表达式根据 ISO C 的规则进行处理，但有以下例外：

- 仅整数整数算术。
- 不需要 `sizeof()` 运算符以及前缀和后缀 `++` 和 `--` 运算符。
- 如果表达式无效，shell 将向标准错误写入消息。

下面的简单示例使用了算术：

```bash
# 重复命令 100 次

x=100

while [ $x -gt 0 ]

do

  echo $x

  x=$((x-1))

done
```

## 参数替换

参数是一个或多个数字的标识符或字符 `*`, `@`, `#`, `$`, 和 `!` 中的任意。变量（由标识符表示的参数）有一个值和零或多个属性。你可以使用特殊命令分配值和属性。导出的变量将值和属性传递给环境。

shell 支持一维数组功能。数组变量的元素通过下标引用。下标用 `[` 表示，后面跟着一个算术表达式，最后是 `]`。要给数组赋值，请使用 `set -A name...`

所有下标的值必须在 0 到 1023 的范围内。数组不需要声明。任何带有有效下标的变量引用都是合法的，并在必要时创建数组。不带下标或 `*` 或 `@` 的数组引用等于引用元素 0。

你可以通过以下方式为变量赋值：`name=value`

如果为 `name` 设置了整数属性 `-i`，则该值将按照下文所述进行算术求值。位置参数（由数字表示的参数）可以使用 `set` 命令赋值。参数 `$0` 在 shell 调用时从参数 0 设置。如果参数是一个或多个数字，则它是位置参数。多位数字的位置参数必须括在大括号中。

## 参数扩展

参数扩展的格式如下：

`$(expression)`

其中 `expression` 包含直到匹配的 `)` 的所有字符。被反斜杠转义或位于引号字符串中的字符，以及嵌入算术扩展、命令替换和变量扩展中的字符，不会用于确定匹配的 `)`。

参数扩展最简单的形式是：

`$(parameter)`

参数的任何值将被替换。
