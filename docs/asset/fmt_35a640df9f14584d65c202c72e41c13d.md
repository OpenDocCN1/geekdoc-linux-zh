
## 文件操作

### 移动文件
在桌面上同时打开原文件夹和目标文件夹，按住鼠标左键拖动您想要移动的文件到新文件夹的空白处，然后释放鼠标按钮。从出现的菜单中点击 移动。（您也可以使用此菜单复制文件或创建链接。）

### 链接文件
将文件从一个文件夹拖放到另一个文件夹。当菜单出现时，点击 在此创建链接。（链接文件允许您从新位置访问文件，而无需复制原始文件。当您打开链接时，指向原始文件的指针会导致其打开。）

还有几项功能用于查看 Konqueror 窗口中文件和文件夹的信息：

### 查看快速文件信息
将鼠标指针指向文件。当鼠标指针在 Konqueror 窗口中悬停在文件上时，信息会出现在窗口底部的页脚中。这包括文件名、文件大小和文件类型。

### 查看隐藏文件
选择 查看 → 显示隐藏文件。这允许您看到以点 (.) 开头的文件。点文件通常用于配置，一般不需要在日常工作中查看。

### 查看文件系统树
选择 查看 → 查看模式 → 树视图。这将显示文件夹的树视图，在文件系统中显示当前文件夹上方的文件夹。您可以点击树视图中的文件夹直接跳转到该文件夹。还提供多栏、详细列表和文本视图。

### 更改图标视图
选择 查看 → 图标大小，然后选择 大、中 或 小 以设置窗口中显示的图标大小。您也可以选择 默认大小 以恢复默认图标大小。

要同时对一组文件进行操作，可以采取以下几种操作。选择 编辑 → 选择。弹出窗口允许您匹配所有 (*) 文件，或通过输入字母、数字和通配符来匹配任意一组文档。或者，要选择一组文件，在文件夹的空白处按住鼠标左键并拖动指针覆盖您想要选择的文件。框选范围内的所有文件都将被高亮显示。文件高亮后，您可以像前面描述的那样移动、复制或删除这些文件。

## 搜索文件

如果您正在寻找特定的文件或文件夹，可以使用 Konqueror 的查找功能。要打开查找窗口以搜索文件，请选择 工具 → 查找文件。（您也可以在终端窗口中输入 `kfind` 来启动 kfind 窗口。）图 3-17 显示了 kfind 窗口。

![](img/27a85d56d393921ced6412ae6e8336bf_133_0.png)

图 3-17：从 kfind 窗口搜索文件和文件夹。

只需在 命名 框中输入要搜索的文件名，在 查找范围 框中输入要搜索的文件夹（包括所有子文件夹）。然后点击 查找 按钮。如果需要，可以在搜索中使用元字符。例如，搜索 `*.rpm` 可查找所有以 `.rpm` 结尾的文件，搜索 `z*.doc` 可查找所有以 `z` 开头并以 `.doc` 结尾的文件。您还可以选择使搜索区分大小写，或点击 帮助 按钮获取更多搜索信息。

要进一步限制搜索范围，您可以点击 日期范围 选项卡，然后输入日期范围（介于）、距今天的月数（在之前的 x 个月内）或距今天的天数（在之前的 x 天内）。选择 高级 选项卡可选择将搜索限制为特定类型的文件（类型）、包含您输入文本的文件（包含文本）或特定大小的文件（大小为）以 KB 为单位。

## 创建新文件和文件夹

在使用 Konqueror 窗口时，您可以创建多种文件类型。选择 编辑 → 创建新建，然后选择以下类型之一：

### 目录
打开一个对话框，让您输入新目录名称。输入名称，点击 确定，代表新目录的图标随即出现。

### 插图文档
打开一个对话框，让您创建一个 kontour 格式的文档（插图）。输入要创建的文档名称并点击 确定。如果希望文档自动在 kontour 中打开，文档应具有 `.kil` 后缀。

### HTML 文件
打开一个对话框，让您输入要创建的 HTML 文件名。

### 文本文件
打开一个对话框，让您创建文本格式的文档并将其放置在 Konqueror 窗口中。输入要创建的文本文档名称并点击 确定。

### CD/DVD-ROM 设备
打开一个对话框，让您输入新的 CD-ROM 或 DVD-ROM 设备名称。点击 设备 选项卡并输入设备名称（`/dev/cdrom`）、挂载点（如 `/mnt/cdrom`）和文件系统类型（标准 CD-ROM 文件系统可用 `iso9660`，Linux 可用 `ext2`，DOS 可用 `msdos`）。图标出现后，您可以打开它以挂载 CD-ROM 或 DVD-ROM 并显示其内容。

### 软盘设备
打开一个对话框，让您输入新的软盘名称。点击 设备 选项卡并输入设备名称（`/dev/fd0`）、挂载点（如 `/mnt/floppy`）和文件系统类型（可用 `auto` 自动检测内容，Linux 可用 `ext2`，DOS 可用 `msdos`）。图标出现后，打开它以挂载软盘并显示其内容。

### 硬盘
打开一个对话框，让您输入新硬盘或硬盘分区的名称。点击 设备 选项卡并输入设备（`/dev/hda1`）、挂载点（如 `/mnt/win`）和文件系统类型（可用 `auto` 自动检测内容，Linux 可用 `ext2` 或 `ext3`，Windows 文件系统可用 `vfat`）。图标出现后，您可以打开它以挂载文件系统并显示其内容。

### 应用程序链接
打开一个窗口，让您输入应用程序的名称。点击 权限 选项卡设置文件权限（如果要将文件作为应用程序运行， 可执行 必须开启）。点击 执行 选项卡并输入要运行的程序名称（在 单击时执行 字段中）以及要显示在应用程序标题栏中的标题（在 窗口标题 字段中）。如果是基于文本的命令，请勾选 在终端中运行 复选框。勾选 以不同用户身份运行 复选框并添加用户名。点击 应用程序 选项卡将应用程序分配给处理特定 MIME 类型的文件。点击 确定。

### 位置链接 (URL)
选择此菜单项将打开一个对话框，让您创建指向 Web 地址的链接。输入一个名称来代表该地址，并输入站点的 URL（Web 地址）名称。（请务必添加 `http://`、`ftp://` 或其他前缀。）

### 演示文档
打开一个对话框，用于创建 kpresenter 格式的文档（演示文稿）。输入要创建的文档名称并点击 确定。如果希望文档自动在 kpresenter 中打开，文档应具有 `.kpr` 或 `.kpt` 后缀。

### 电子表格文档
打开一个对话框，让您创建 kspread 格式的文档（电子表格）。输入要创建的文档名称并点击 确定。如果希望文档自动在 kspread 中打开，文档应具有 `.ksp` 后缀。

### 文本文档
打开一个对话框，使您能够在 KWord 中创建文本文档。为文本文件键入一个文件名并单击“确定”。如果您希望文档能在 KWord 中自动打开，该文档应具有 .txt、.kwd 或 .kwt 后缀。

创建 MIME 类型和应用程序将在本章后面介绍。

## 使用其他浏览器功能

因为 Konqueror 既可以作为 Web 浏览器也可以作为文件管理器，所以它包含其他几种浏览器功能。例如，您可以使用书签功能保存已访问网站的书签列表。您添加到书签列表中的任何书签都会显示在单击“书签”时出现的下拉菜单中。从该列表中选择即可返回某个站点。有几种方法可以添加和更改书签列表：

### 添加书签
要将当前显示页面的地址添加到书签列表中，请选择“书签”→“添加书签”。下次单击“书签”时，您将在“书签”菜单上看到刚刚添加的书签。除了 Web 地址，您还可以为任何文件或文件夹添加书签。

### 编辑书签
选择“书签”→“编辑书签”将打开书签的树状视图。在出现的“书签编辑器”窗口中，您可以更改书签的 URL、图标或其他特性。还有一个很好的功能，可让您检查书签的状态（即地址是否可用）。

### 新建书签文件夹
您可以向 Konqueror 书签列表添加一个新的书签文件夹。要创建书签文件夹，请选择“书签”→“新建文件夹”。然后为新书签文件夹键入一个名称并单击“确定”。新书签文件夹将出现在您的书签菜单上。您可以通过单击文件夹名称并选择“添加书签”将当前位置添加到该文件夹中。

## 配置 Konqueror 选项

您可以更改 Konqueror 窗口的许多视觉属性。您可以选择显示哪些菜单栏和工具栏。您可以让以下任意栏出现在 Konqueror 窗口中：菜单栏、工具栏、额外工具栏、位置工具栏、书签工具栏。选择“设置”，然后单击您想要显示（或隐藏）的栏对应的菜单项。当旁边显示复选标记时，该栏就会出现。

您可以通过选择“设置”→“配置 Konqueror”来修改 Konqueror 的各种选项。将出现“Konqueror 设置”窗口，提供以下选项：

### 行为（文件）
更改文件管理器行为。

### 外观
更改文件管理器字体和颜色。
