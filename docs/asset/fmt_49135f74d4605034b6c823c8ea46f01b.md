## SYSSTARTUP:APACHESSTART.COM

```
$ file = SYSSTARTUP:APACHESDOWN.COM
$ if fsearch("$file").nes then "$file"
```

通过向 `SYSMANAGER:SHUTDOWN.COM` 添加以下行，在系统关机时关闭 Apache 服务器：

```
$ file = SYSSTARTUP:APACHESDOWN.COM
$ if fsearch("$file").nes then "$file"
```
