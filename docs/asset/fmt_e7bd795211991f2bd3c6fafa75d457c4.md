## 1023

- `plimit`

## 描述

不带参数时，`plimit` 进程的限制。当您指定一个或多个参数时，`plimit` 设置指定资源的软（当前）和硬（最大）限制。

## 选项

- `-k` 以 KB 为单位显示文件大小，而不是字节。
- `-m` 以 MB 为单位显示文件大小和内存大小。

软限制不能超过硬限制。

- `-c` 设置文件大小限制（默认单位 512 字节）。
- `-d` 设置数据段（堆）大小限制（默认单位 KB）。
- `-f` 设置文件大小限制（默认单位 512 字节）。
- `-n` 设置文件描述符限制（无单位）。
- `-s` 设置栈大小限制（默认单位 KB）。
- `-t` 设置 CPU 时间限制（默认单位秒）。

# plot, aedplot, atoplot, bgplot, critplot, dumbplot, gigiglot — 各种绘图仪的图形过滤器

### 概要

```
/usr/ucb/plot [-Tterminal]
```

## Description

`plot` 命令从标准输入读取绘图指令（参见 `plot(4B)`），
并在标准输出上产生适用于特定终端的绘图指令。

如果不指定终端，则使用环境变量 `TERM`。
默认终端为 `tek`。

## 环境变量

除 `ver` 之外，你可以配合 `lpr -g`（参见 `lpr`）使用以下终端类型
来产生绘图输出。

- `- 2648 | 2648a | h8 | hp2648 | hp2648a`: 惠尔-Packard® 2648 图形终端。
- `hp7221 | hp7 | h7`: 惠尔-Packard 7221 绘图仪。
- `- 300`: DASI 300 或 GSI 终端（Diablo 机制）。
- `- 300s | 300S`: DASI 300s 终端（Diablo 机制）。
- `- 450`: DASI Hyterm 450 终端（Diablo 机制）。
- `- 4013`: Tektronix 4013 存储示波器。
- `- 4014 | tek`: 带有增强图形模块的 Tektronix 4014 和 4015 存储示波器。（对于没有增强图形模块的 Tektronix 4014 或 4015 使用 4014）。
- `- aed`: AED 512 彩色图形终端。
- `bgplot | bitgraph`: BBN bitgraph 图形终端。
- `- crt`: 任何可以运行 `vi(1)` 的 CRT 终端。
- `dumb | un | unknown`: 不带光标寻址哑终端或行打印机。
- `gigi | vt125`: DEC® vt125 终端。
- `implot`: Imagen® 绘图仪。
- `var` Benson Varian 打印机-绘图仪。
- `ver` Versatec D1200A 打印机-绘图仪。输出经过扫描转换，适用于 `lpr -v`。

## postdaisy — 用于 Diablo 630 针轮文件的 PostScript 翻译器

### Synopsis

```
/usr/lib/lp/postdaisy [-c num] [-f num] [-h num] [-m num] [-n num]

[-o mode] [-r num] [-s num] [-v num] [-x num] [-y num] [file...]

/usr/lib/lp/postscript/postdaisy
```

## Description

`postdaisy` 过滤器将 Diablo 630 针轮文件转换为 PostScript
并将结果写入标准输出。如果不指定文件或 `-` 是输入文件之一，则读取标准输入。

## Options

- `-c num`: 打印每页的 `num` 份。默认情况下只打印一份。
使用字体名称打印文件。你可以使用任何 PostScript 字体，但只有使用等宽字体才能获得最佳结果。默认字体为 Courier。
- `- f name`: 设置初始水平移动索引为 `num`。除非使用 `-s` 选项，否则确定字符步进和默认字体大小。默认为 12。
- `- h num`: 按因子 `num` 放大每个本地页面。围绕原点（位于每页左上角）均匀缩放。默认放大倍数为 1.0。
- `- m num`: 在每页纸上打印 `num` 页，其中 `num` 可以是正整数。默认情况下，`num` 设置为 1。
- `- n num`: 打印逗号分隔列表中给出的页码。列表包含单个数字 N 和范围 N1–N2。缺失 N1 表示编号最小的页，缺失 N2 表示最大的页。
