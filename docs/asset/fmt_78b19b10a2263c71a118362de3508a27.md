
你可以使用 `search` 子命令按名称搜索软件包。例如，要搜索一个名为 `package-name` 的软件包，可以使用以下命令：

```
apt-cache search package-name
```

这将在软件包索引中搜索任何匹配搜索词 `package-name` 的软件包，并向你显示结果列表。

## 列出已安装的软件包

要列出系统中所有安装的软件包，你可以使用带有 `--installed` 选项的 `list` 子命令：

```
apt list --installed
```

这将显示你系统中所有安装软件包的列表，以及它们的版本以及是否为最新。

## 列出可用软件包

要列出从软件包仓库中可以安装的所有软件包，可以在不带任何选项的情况下使用 `list` 子命令：

```
apt list
```

这将显示软件包仓库中所有可用软件包的列表，以及它们的版本以及它们是否已经安装在你的系统中。

值得注意的是，这些只是 `apt` 提供的许多选项和子命令的几个示例。你可以通过查阅 `apt-cache` 手页或你特定 Linux 发行版的文档来获取有关使用 `apt` 的更多信息。

## 安装软件

在 Linux 计算机上，你可以使用 `install` 子命令，并通过 `apt`（高级软件包工具）包管理系统指定你要安装的软件软件包名称。这将允许你在计算机上安装软件和程序。例如，要安装名为 `package-name` 的软件包，可以使用以下命令：

```
sudo apt-get install package-name
```

这将下载并安装 `package-name` 软件包，以及它所需的任何依赖项。

你还可以通过指定由空格分隔的软件包名称列表来同时安装多个软件包：

```
sudo apt-get install package-name-1 package-name-2 package-name-3
```

值得注意的是，你需要拥有 root 权限（例如通过使用 `sudo` 命令）才能使用 `apt` 安装软件。

在安装新软件包之前更新软件包索引文件也是一个好主意。你可以通过使用 `update` 子命令来实现这一点：

```
sudo apt-get update
```

这将从软件包仓库下载最新的的软件包索引文件，并确保你可以访问所有可用软件包的最新版本。

值得注意的是，这些只是 `apt` 提供的许多选项和子命令的几个示例。你可以通过查阅 `apt-get` 手页或你特定 Linux 发行版的文档来获取关于 `apt` 的更多信息。

## 移除软件

在使用 Linux 系统上的 `apt`（高级软件包工具）管理系统移除软件和程序时，你可以使用 `remove` 子命令并指定你要移除的软件包名称。例如，要移除名为 `package-name` 的软件包，可以使用以下命令：

```
sudo apt-get remove package-name
```

这将移除 `package-name` 软件包，但会留下该软件包的配置文件。

要移除软件包及其配置文件，你可以使用 `purge` 子命令：

```
sudo apt-get purge package-name
```

你还可以通过指定由空格分隔的软件包名称列表来同时移除多个软件包：

```
sudo apt-get remove package-name-1 package-name-2 package-name-3
```

值得注意的是，你需要拥有 root 权限（例如通过使用 `sudo` 命令）才能使用 `apt` 移除软件。

在移除软件包之前更新软件包索引文件也是一个好主意。你可以通过使用 `update` 子命令来实现这一点：

```
sudo apt-get update
```

这将从软件包仓库下载最新的软件包索引文件，并确保你可以访问所有可用软件包的最新版本。

## 理解存储库

仓库是存储软件包并提供供安装的中心位置。包管理系统（如 `apt` 或 `yum`）使用存储库将软件包下载并安装到 Linux 系统上。

仓库可以包含用于各种目的的软件包，包括系统库、应用程序和实用。仓库中的软件包通常被组织成不同的类别，并为不同版本的 Linux 发行版提供。

Linux 发行版中常用的仓库有几种不同类型：

- 官方仓库（Official repositories）：这些是由 Linux 发行版开发者维护的仓库，包含该发行版支持的软件软件包。
- 第三方仓库（Third-party repositories）：这些是由 Linux 发行版开发者以外的组织或个人维护的仓库，可能包含官方仓库中未包含的软件包。
- 个人仓库（Personal repositories）：这些是由个人用户创建并维护的仓库，可能包含自定义软件包或在其他仓库中不可用的软件包。

要配合包管理系统使用仓库，你通常需要将仓库添加到系统的可用仓库列表中。这通常通过向 `/etc/apt/sources.list.d/` 目录（针对 `apt`）添加包含仓库详情的配置文件，或者在 `/etc/yum.repos.d/` 目录（针对 `yum`）创建新的仓库配置文件来实现。

一旦仓库添加到系统，你就可以使用包管理系统从仓库中搜索、安装、更新和移除软件包。

### 官方仓库

官方仓库由 Linux 发行版开发者维护，包含该发行版支持的软件软件包。这些仓库包含广泛的软件包，包括系统库、应用程序和实用程序，它们针对该发行版进行了测试和打包。

例如，Ubuntu 有一组官方仓库：

- `main`：包含大部分软件
- `restricted`：包含受限制的软件
- `universe`：包含由社区维护的软件
- `multiverse`：包含可能有法律许可问题的软件

### 第三方仓库

第三方仓库是由 Linux 发行版开发者以外的组织或个人维护的，可能包含官方仓库中未包含的软件包。这些仓库通常用于。

例如，Google 维护着包含 Chrome 和其他应用程序的第三方仓库。该仓库可以添加到基于 Debian 的系统中。

### 个人仓库

个人仓库由个人用户创建并维护，可能包含自定义软件包或其他仓库中不可用的软件包。这些仓库通常用于与小小组共享软件，或在发布到更大的仓库之前对软件包进行测试。

## 探索 ‘sources.list’ 文件

### 理解 ‘sources.list’

`sources.list` 文件是一个配置文件，包含了包管理系统（如 `apt` 或 `yum`）的仓库列表。这些文件用于指定软件包仓库的位置，允许包管理系统从这些仓库下载并安装软件包。

在基于 Debian 和 Ubuntu 的系统中，`sources.list` 文件通常位于 `/etc/apt/` 目录，包含了 `apt` 包管理系统的可用仓库列表。该文件是一个纯文本文件，可以手动编辑以添加、删除或修改列表中的仓库。

`sources.list` 文件具有特定的格式，由仓库类型、仓库地址和发行版代号组成。以下是一个基于 Debian 的系统的 `sources.list` 文件示例：

```
deb http://deb.debian.org/debian stable main
deb-src http://deb.debian.org/debian stable main

deb http://security.debian.org/ stable/updates main
deb-src http://security.debian.org/ stable/updates main
```

在本示例中，该文件包含了两个仓库：主 Debian 仓库和 Debian 安全仓库。`deb` 和 `deb-src` 行分别指定了仓库类型（别是二进制包或源包）和仓库地址，而 `stable` 和 `main` 参数则分别指定了发行代号和仓库组件。

值得注意的是，虽然 `sources.list` 文件是 `apt` 软件包管理系统的配置文件，但也可以通过在 `/etc/apt/sources.list.d/` 目录下创建独立的文件为系统添加额外的仓库。这些文件具有 `.list` 扩展名且格式与 `sources.list` 文件相同。

### 查看和编辑 ‘sources.list’ 文件

要在 Debian 或 Ubuntu-Linux 系统上探索 `sources.list` 文件，你可以使用文本编辑器打开文件并查看其内容。`sources.list` 文件是一个纯文本文件，可以使用任何文本编辑器（如 `nano`、`vi` 或 `geit`）进行编辑。

以下使用 `nano` 文本编辑器查看 `sources.list` 文件内容的示例：

```
sudo nano /etc/apt/sources.list
```

这将将在 `nano` 文本编辑器中打开 `sources.list` 文件，允许你查看和编辑其内容。
