
# 第 4 章 使用控制结构

在程序语言中，程序不仅仅是指令的线性序列，它可以包含重复代码。控制结构决定了语句的执行顺序。控制结构的示例包括 `if-else` 和 `switch`：

- 条件结构
- 循环结构
- 跳转语句

在 C 语言中，控制结构分为类，如下：

- 条件结构：根据特定条件执行单个语句或一组语句。`if-else` 和 `switch` 属于此类。
- 循环结构：在满足条件时重复执行一个或多个语句。`do-while` 和 `for` 属于此类。
- 跳转语句：改变程序执行流。`break`、`continue` 和 `goto` 属于此类。

在本章中，你将学习各种控制结构。本章将从条件结构（`if`、`else` 和嵌套 `if-else`）开始。接下来，你将学习循环结构（`do-while` 和 `for`）。最后，你将学习跳转语句（`break`、`continue` 和 `goto`）。

## 使用条件结构

条件结构是一种允许你在程序中选择一个或多个执行路径的控制结构。它在评估给定条件表达式后执行代码块。如果条件表达式为真，则执行相应的代码块；否则，不执行并传递到下一个代码块。条件结构提供了以下语句：

- `if` 语句
- `if-else` 语句
- `if-else` 阶梯
- 嵌套 `if-else` 语句
- `switch` 语句

### `if` 语句

`if` 语句在指定条件为真时执行简单或复合语句。简单语句由单个语句组成，而复合语句包含多个语句。使用 `if` 语句执行简单语句的语法如下：

```c
if (conditional_expression)
{
    statement;
}
```

使用 `if` 语句执行复合语句的语法如下：

```c
if (conditional_expression)
{
    statement1;
    statement2;
    statement3;
}
```

在上述语法中，当 `if` 语句中的条件表达式为真时，执行简单或复合语句（语句块）。否则，程序传递到下一个语句。列表 4.1 展示了使用 `if` 语句的示例：

**列表 4.1：使用 `if` 语句的示例**

```c
#include <stdio.h>

int main() {
    int grade;
    printf("Enter your grade\n");
    scanf("%d", &grade);

    if (grade > 7) {
        printf("You are excellent performer\n");
        return 0;
    }

    return 0;
}
```

上述列表的输出如下：
- 输入你的成绩
- 9
- 你是优异者

在列表 4.1 中，你需要在运行时输入你的成绩。如果你输入的成绩大于 7，则执行 `if` 语句中的陈述；否则，该语句将不会执行。在我们的案例中，我们输入 9 作为成绩，它大于 7；因此显示了 "You are excellent performer" 的消息。

### `if-else` 语句

当 `if` 中提供的条件表达式为真时，执行 `if` 下的语句。然而，当 `if` 中指定的条件表达式为假时，它将执行 `else` 语句下的语句。

`if-else` 语句的语法如下：

```c
if (conditional_expression)
{
    statement1;
}
else
{
    statement2;
}
```

在上述语法中，当 `if` 中指定的条件表达式为真时，执行 `statement1`；否则，执行 `statement2`。

**列表 4.2：使用 `if-else` 语句**

```c
#include <stdio.h>

int main() {
    int a, b;
    printf("Enter the value of a and b\n");
    scanf("%d %d", &a, &b);

    if (a != b) {
        printf("a and b are not equal\n");
    }
    else {
        printf("a and b are equal\n");
    }

    return 0;
}
```

上述列表的输出如下：
- 输入 a 和 b 的值
- 45
- 45
- a and b are equal

在列表 4.2 中，你需要在运行时输入 `a` 和 `b` 的值。如果 `a` 的值不等于 `b` 的值，则执行 `if` 语句；否则，执行 `else` 语句。在我们的案例中，我们输入的 `a` 和 `b` 的值均为 45；因此执行了 `else` 语句并显示了消息 "a and b are equal"。

### `if-else` 阶梯

当在序列中使用多个 `if-else` 语句时，它被称为 `if-else` 阶梯。`if-else` 阶梯的语法如下：

```c
if (conditional_expression_1)
{
    statement1;
}
else if (conditional_expression_2)
{
    statement2;
}
else if (conditional_expression_3)
{
    statement3;
}
```

在上述语法中，如果条件表达式 1 为真，则执行 `statement1`。如果条件表达式 1 为假且条件表达式 2 为真，则执行 `statement2`。如果前两者均为假且条件表达式 3 为真，则执行 `statement3`。你应当注意，根据条件的不同，这些语句中仅有其中一个会被执行。列表 4.3 展示了 `if-else` 阶梯的示例：

**列表 4.3：使用 `if-else` 阶梯**

```c
#include <stdio.h>

int main() {
    int a, b, c;
    printf("Enter the value of a, b, and c\n");
    scanf("%d %d %d", &a, &b, &c);

    if (a > b && a > c) {
        printf("a is greater than b and c\n");
    }
    else if (b > a && b > c) {
        printf("b is greater than a and c\n");
    }
    else if (c > a && c > b) {
        printf("c is greater than a and b\n");
    }

    return 0;
}
```

上述列表的输出如下：
- 输入 a, b, c 的值
- 56
- 89
- 32
- b is greater than a and c

在列表 4.3 中，你需要在运行时输入 `a`, `b`, `c` 的值。如果 `a` 的值大于 `b` 和 `c`，则执行第一个 `if` 语句；如果 `b` 的值大于 `a` 和 `c`，则执行第二个 `if` 语句（`else if`）；如果 `c` 的值大于 `a` 和 `b`，则执行第三个 `if` 语句。在我们的案例中，我们输入的 `a`, `b`, `c` 的值分别为 56, 89 和 32。这意味着第二个条件（`b > a && b > c`）为真。因此，显示了消息 "b is greater than a and c"。

### 嵌套 `if-else` 语句

在嵌套的 `if-else` 语句中，`if` 部分包含一个 `if-else` 语句，或者 `else` 部分在其体内部包含一个 `if-else` 语句。

嵌套 `if-else` 语句的语法如下：

```c
if (conditional_expression_1)
{
    statement1;
}
else
{
    if (conditional_expression_2)
    {
        statement2;
    }
    else
    {
        statement3;
    }
}
```

在上述语法中，`if-else` 嵌套在 `else` 语句中。当条件表达式 1 为真时，执行 `statement1`；否则，当条件表达式 2 为真时则执行 `statement2`。列表 4.4 展示了一个嵌套 `if-else` 的示例：

**列表 4.4：使用嵌套的 `if-else`**

```c
#include <stdio.h>

int main() {
    int age1, age2;
    printf("Enter the value of age1 and age2\n");
    scanf("%d %d", &age1, &age2);

    if (age1 > 50)
    {
        if (age2 > 50)
        {
            printf("Both are greater than 50\n");
        }
        else
        {
            printf("Only age1 is greater than 50\n");
        }
    }
    else
    {
        printf("Age1 is not greater than 50\n");
    }

    return 0;
}
```

上述列表的输出如下：
- 输入 age1 和 age2 的值
- 60
- 70
- Both are greater than 50

在列表 4.4 中，你需要在运行时输入 `age1` 和 `age2` 的值。如果 `age1` 大于 50，则执行内部的 `if` 语句。如果 `age2` 也大于 50，则显示消息 "Both are greater than 50"。

### `switch` 语句

`switch` 语句用于将特定值与多个值进行比对。如果该值与任意一个值匹配，则执行相应的语句组。`switch` 语句的语法如下：

```c
switch(expression)
{
    case value1:
        statement1;
        break;
    case value2:
        statement2;
        break;
    case value3:
        statement3;
        break;
    default:
        default_statement;
}
```

在上述语法中，表达式的值与 `case` 标签提供的常量进行比较。如果表达式的值与某个值匹配，则执行与该常量关联的代码。然而，当与指定的常量匹配后，执行遇到 `break`，`switch` 语句结束。当 `switch` 表达式与任何 `case` 常都不匹配时，则执行 `default` 语句中的代码。列表 4.5 展示了一个使用 `switch` 语句的示例：

**列表 4.5：使用 `switch` 语句**

```c
#include <stdio.h>

int main() {
    int grade;
    printf("Enter your grade (from 1 to 5):\n");
    scanf("%d", &grade);

    switch(grade)
    {
        case 1:
            printf("Your grade is A: Excellent\n");
            break;
        case 2:
            printf("Your grade is B: Very Good\n");
            break;
        case 3:
            printf("Your grade is C: Good\n");
            break;
        case 4:
            printf("Your grade is D: Bad\n");
            break;
        case 5:
            printf("Your grade is E: Fail\n");
            break;
        default:
            printf("You have entered wrong grade\n");
    }

    return 0;
}
```

前一个列表的输出如下：

```text
Enter your grade (from 1 to 5)
2
Your grade is B: Very Good
```

在列表 4.5 中，你在运行时提供的值存储在 `grade` 变量中。该变量被 `switch` 表达式用作参数，并与 `case` 标签中的常量进行比较。在我们的例子中，输入了 2，它与 `case` 标签 2 匹配。因此显示评级为 B: Very Good 的消息。

## 使用循环控制结构

循环意味着对一组指令进行多次执行，或者直到获得特定的结果。反复执行的语句称为迭代语句。循环根据条件表达式重复执行代码块，只要该条件的值为真，循环就会继续。当条件表达式的值为假时，循环退出，控制权转移到循环后的下一个语句。C 语言支持此类循环。

- `while` 循环
- `do-while` 循环
- `for` 循环

让我们详细讨论一下。

### `while` 循环

`while` 循环执行语句，直到其中指定的条件表达式为假（即当条件为真时持续执行）。当条件变为假时，循环终止。使用 `while` 循环的语法如下：

```c
while (conditional_expression)
{
    simple_or_compound_statement;
}
```

在上述语法中，如果条件表达式的值为真，则执行 `while` 循环体内的语句。当条件表达式的值为假时，循环终止。注意，基于条件表达式执行的语句可以是简单语句，也可以是复合语句。简单语句直接写在 `while` 语句之后（通常建议加括号），而复合语句在大括号内指定。列表 4.6 显示了使用 `while` 循环的示例：

**列表 4.6：使用 `while` 循环**

```c
#include <stdio.h>

int main() {
    int n = 0;

    while (n < 5) {
        printf("%d\n", n);
        n++;
    }

    return 0;
}
```

前一个列表的输出如下：

```text
0
1
2
3
4
```

在列表 4.6 中，整数变量 `n` 初始化为 0。`while` 循环检查 `n` 的值是否小于 5。如果变量 `n` 的值小于 5，`printf()` 函数显示其中存储的值，然后 `n` 的值加 1。当变量 `n` 的值大于或等于 5 时，`while` 循环停止。

### `do-while` 循环

`do-while` 循环无论条件真假，至少执行一次循环体。首先，它执行循环体中指定的语句，然后评估条件。使用 `do-while` 循环的语法如下：

```c
do
{
    simple_or_compound_statement;
}
while (conditional_expression);
```

在上述语法中，关键字 `do` 后面跟着一个简单或复合语句，然后是带有条件表达式的 `while` 子句。该简单或复合语句代表 `do-while` 循环的体。`do-while` 循环至少执行一次，不取决于循环中的条件。如果循环中指定的条件在第一次评估后变为假，则退出循环；如果为真，则再次执行循环。

注意，当使用简单语句构建 `do-while` 循环时，循环体不用大括号表示（但为了可读性，通常建议使用）。列表 4.7 显示了使用复合语句的 `do-while` 循环：

**列表 4.7：使用 `do-while` 循环**

```c
#include <stdio.h>

int main() {
    int num;

    num = 0;

    do {
        printf("%d\n", num);
        num = num + 1;
    } while (num > 0 && num <= 5);

    return 0;
}
```
