
在本章中，我们继续讨论正规顶点着色。我们考虑所谓的完美图，对于这类图，团数起着重要作用。我们还将考虑图中每个顶点允许使用的颜色预先指定的正规顶点着色。

## 15.1 完美图

在推论 14.3 中，我们看到图 `G` 的团数 `ω(G)` 是 `χ(G)` 的一个下界。虽然有许多图 `G` 满足 `χ(G) = ω(G)` 的例子，如完全图和二部图，但也有许多图的色数超过其团数，例如长度至少为 5 的奇圈和彼得森图（如图 15.1 所示，其中展示了一个 3-着色）。在这些情况下，图的色数为 3，而团数为 2。正如我们即将看到的，团数为 2 的图可以具有任意大的色数。

### 色数较大的无三角形图

对于给定的图 `F`，回忆一下，如果图 `G` 的任意诱导子图都不同构于 `F`，则称 `G` 为 `F`-自由的。还要回忆一下，`K_3`-自由图通常被称为无三角形图。因此，任何非空无三角形图的团数都为 2。图 15.2 中的图 `G` 是无三角形图（因此 `ω(G) = 2`），但 `χ(G) = 4`。该图的一个 4-着色如图 15.2 所示。因此，在这种情况下，`χ(G)` 比 `ω(G)` 大 2。该图被称为**格罗茨赫图**（Grötzsch graph），以德国数学家赫伯特·格罗茨赫（Herbert Grötzsch）的名字命名。已知它是唯一最小的（就阶数而言）既是 4-色色的

又是无三角形图。无三角形图可以拥有较大色数这一事实已由许多数学家确立，包括布兰什·德卡特（Blanche Descartes）[66]、约翰·B·凯利（John B. Kelly）和利罗伊·M·凯利（Leroy M. Kelly）[141] 以及亚历山大·日科夫（Alexander Zykov）[263]。然而，我们在此给出的这一事实的证明归功于扬·米切尔斯基（Jan Mycielski）[174]。

![](img/598a6ae3fd44120830ada34717906f29_406_1.png)

**定理 15.1** 对于每个正整数 $k$，都存在一个无三角形的 $k$-色色图。

**证明。** 由于色数为 1 或 2 的图不包含三角形，因此该定理对 $k = 1$ 和 $k = 2$ 显然成立。为了验证 $k \geq 3$ 的情况，我们对 $k$ 进行归纳。正如我们已经观察到的，`χ(C_5) = 3` 且 `C_5` 是无三角形图；因此该陈述对 $k = 3$ 成立。

假设存在一个色数为 $k$ 的无三角形图，其中 $k \geq 3$。我们将证明存在一个色数为 $(k+1)$ 的无三角形图。设 `H` 是一个色数为 `χ(H) = k` 的无三角形图，其中 `V(H) = {v_1, v_2, …, v_n}`。我们通过添加 $n + 1$ 个新顶点 `u, u_1, u_2, …, u_n`，将 `u` 与每个顶点 `u_i`（$1 \leq i \leq n$）相连，并将 `u_i` 与 `v_i` 在 `H` 中的每个邻居相连，从而从 `H` 构造图 `G`。（参见图 15.3，其中 $k=3$ 且 `H=C_5`。在此情况下，得到的图 `G` 是图 15.3 中的格罗茨赫图。）

![](img/598a6ae3fd44120830ada34717906f29_407_0.png)

我们要证明 `G` 是一个无三角形的 $(k+1)$-色色图。首先，我们证明 `G` 是无三角形图。由于 `S = {u_1, u_2, …, u_n}` 是 `G` 的一个独立顶点集，且 `u` 不与 `H` 的任何顶点相邻，因此 `u` 不属于 `G` 中的任何三角形。因此，如果 `G` 中存在三角形 `T`，则 `T` 的三个顶点中必有两个属于 `H`，而第三个顶点属于 `S`，设 `V(T) = {u_i, v_j, v_k}`。由于 `u_i` 与 `v_j` 和 `v_k` 相邻，可知 `v_i` 与 `v_j` 和 `v_k` 相邻。由于 `v_j` 和 `v_k` 相邻，`H` 包含一个三角形，这与假设矛盾。因此，正如所述，`G` 是无三角形图。

接下来，我们证明 `χ(G)=k+1`。由于 `H` 是 `G` 的子图且 `χ(H) = k`，可知 `χ(G) ≥ k`。给定 `H` 的一个 $k$-着色，并为 `u_i` 分配与 `v_i` 相同的颜色（$1 \leq i \leq n$）。将颜色 $k+1$ 分配给 `u` 就产生了 `G` 的一个 $(k+1)$-着色，因此 `χ(G) ≤ k+1`。于是，`χ(G) = k` 或 `χ(G) = k+1`。假设 `χ(G)=k`。那么存在 `G` 的一个使用颜色 $1,2,…,k$ 的 $k$-着色，例如 `u` 被分配颜色 $k$。必然地，顶点 `u_1,u_2,…,u_n` 中没有任何一个被分配颜色 $k$；也就是说，`S` 中的每个顶点都被分配了颜色 $1,2,…,k-1$ 中的一个。由于 `χ(H) = k`，`H` 中有一个或多个顶点被分配了颜色 $k$。对于 `H` 中每个着色为 $k$ 的顶点 `v_i`，将其重新着色为 `u_i` 所分配的颜色。这产生了 `H` 的一个 $(k-1)$-着色，这是不可能的。因此，`χ(G)=k+1`。

### 大围长 k-色色图

定理 15.1 可以用图的团数和色数来描述：对于每个正整数 $k$，存在一个非空图 `G`，使得 `ω(G)=2` 且 `χ(G)=k`。借助定理 15.1，可以证明对于任意两个整数 `ℓ` 和 `k`（满足 $2 \leq ℓ \leq k$），存在一个图 `G`，使得 `ω(G)=ℓ` 且 `χ(G)=k`（见练习 2）。

回忆一下，图 `G` 的围长 `g(G)` 是 `G` 中最小圈的长度。因此，定理 15.1 也可以用图的围长和色数来描述：对于每个整数 $k \geq 4$，存在一个非空图 `G`，使得 `g(G) ≥ 4` 且 `χ(G)=k`。这种解释在某种意义上强调了 `G` 的稀疏性，因为 `G` 没有 3-圈。定理 15.1 已被厄多斯（Erdős）[79] 和洛瓦斯（Lovász）[158] 扩展，他们证明了存在色数和围长都任意大的图。

**定理 15.2** 对于任意两个整数 $k \geq 2$ 和 `ℓ ≥ 3`，存在一个图 `G`，使得 `g(G)> ℓ` 且 `χ(G)=k`。

定理 15.2 的证明将在第 21 章中讨论。

### 完美图

虽然人们对于那些满足 `χ(G)> ω(G)` 的图 `G` 表现出很大兴趣，但人们对于那些不仅满足 `χ(G)= ω(G)`，而且对于 `G` 的每个诱导子图 `H` 都满足 `χ(H)= ω(H)` 的图 `G` 表现出更大的兴趣。如果对于 `G` 的每个诱导子图 `H` 都有 `χ(H)= ω(H)`，则称图 `G` 为**完美**的。因此，完美图的每个诱导子图也是完美的。这个定义是由克劳德·贝热（Claude Berge）[24] 引入的。这一概念导致了两个猜想，两者都受到了极大的关注。在描述这些猜想之前，我们考虑几类完美图。

显然，如果 `G=K_n`，则 `χ(G)= ω(G)=n`。此外，`K_n` 的每个诱导子图 `H` 也是一个完全图，因此 `χ(H)= ω(H)`。所以，每个完全图都是完美的。另一方面，如果 `G=overline{K_n}` 且 `H` 是 `G` 的任何诱导子图，则 `χ(H)= ω(H)=1`。所以，每个空图也是完美的。二部图构成了更有趣的一类完美图。

**定理 15.3** 每个二部图都是完美的。

**证明。** 设 `G` 是一个二部图，`H` 是 `G` 的一个诱导子图。如果 `H` 非空，则 `χ(H)= ω(H)=2`；如果 `H` 为空，则 `χ(H)= ω(H)=1`。在两种情况下，都有 `χ(H)= ω(H)`，因此 `G` 是完美的。 ■

下一个定理是蒂博尔·盖莱（Tibor Gallai）[98] 的一个结果的推论，描述了一类相关的完美图。

**定理 15.4** 每个补图为二部图的图都是完美的。
