## detc

## dd

`/dev/vt.`。 [Unix: IBM JCL] 等于 `cat` 或 `BLT`。最初是一个适用于块设备的具有特殊选项的复制命令；它经常用于密集的系统维护，如“在磁带上运行 `dd` 根分区，然后使用启动 PROM 将其引导回新磁盘”。`dd(1)` 设计了一种奇特的、明显的非 Unix 语法，让人联想到 IBM System/360 JCL（它具有复杂的 I/O 设备 `Dataset Definition` 规范）；该接口设计显然是一个玩笑。该术语在 Unix 站点已非常罕见且几乎已过时，已被 `BLT` 或简单的英语 `copy` 所取代。来自 argon Dictionary http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## ddd

数据显示调试器，一个图形前端。数据显示调试器 (`DDD`) 是 `GDB`、`DBX`、`XDB` 等 UNIX 调试器的流行图形界面。除了查看源码和断点等“通常”前端功能外，`DDD` 还提供了交互式图形显示，数据结构以图表的形式显示。使用 `DDD`，你可以通过数据对应用程序进行推理，而不仅仅是查看代码。其他 `DDD` 功能还包括使用 Ada、C、C++、Fortran、Java、Modula、Perl 和 Python 编写的程序进行调试；机器级调试；超链接源码导航和查找；断点、回溯和历史编辑器；偏好和设置编辑器；在终端模拟器中执行程序；远程主机调试器；Motif 用户界面的交互式帮助；具有完整编辑、历史和完成功能的 `GDB`/`DBX`/`XDB` 命令行界面。此版本链接了 Lessif（一个 GPL 的 Motif 实现）。来自 Debian 3.0 APT
