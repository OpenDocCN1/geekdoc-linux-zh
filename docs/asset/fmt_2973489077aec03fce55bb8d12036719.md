## 计数器

虽然从 HTML 源代码来看可能并不直观，但计数器通常是通过使用 CGI 程序实现的。当 Web 浏览器尝试加载与其关联的图像时，程序会被执行。程序接收附加在 URL 上的任何查询字符串（通常是用于唯一标识请求来源页面的字符串），并返回递增后的计数。

计数器最常见的形式是 gif 或 jpeg 图像。图像看起来像汽车里程表或数字显示器。在 HTML 中，引用方式如下：

```
<IMG SRC="http://www.domain.com/cgi-bin/counter.gif?unique_string">
```

随后， CGI 程序必须返回一个格式正确的图像，以便 Web 浏览器处理和显示。这一过程在 shell 脚本中执行相当困难，因此示例在点击链接时会在一个独立的 HTML 页面上显示计数器。

列表 20.8 显示了用于触发计数器的 HTML。列表 20.9 显示了 CGI 程序。

### 列表 20.8. HTML：计数器示例。

```
<html>
<head>
<title> Counters </title>
</head>
<<body>>
<p>计数器用于跟踪某些内容。你可以通过将其描述为图像（大多数浏览器都会加载图像）或显式点击链接来触发计数器。</p>
<p>你可以使用类似 &lt;img src="http://www.name.com/cgi-bin/count1?up" &gt; 的链接来更新计数器。通常，使用某些唯一字符串作为查询来区分不同的项目。</p>
<br>
<p>你也可以使用这样的引用 <a href="http://www.name.com/cgi-bin/count1?up">来更新计数。</a></p>
<br>
<p>你也可以使用这样的引用 <a href="http://www.name.com/cgi-bin/count1?recall">来检索已有的计数。</a></p>
</body>
</html>
```

### 列表 20.9. C 程序：计数器示例。

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
int main ()
{
    char *env_var;
    int adder, counter_value;
    FILE *counter_file;
    printf("Content-type: text/html\n\n");
    printf("<html>\n");
    printf("<head>\n");
    /*
     处理选项
    */
    env_var = getenv("QUERY_STRING");
    if (strcmp(env_var, "up") == 0) adder = 1;
    else if (strcmp(env_var, "down") == 0) adder = -1;

        printf("</p> </body> </html>\n");
        fflush(stdout);
        exit (0);
    }
    printf("<title>Counter</title>\n");
    printf("</head>");
// ... (其余代码继续)
```

## 特殊处理

数据和数据库查询或搜索是 CGI 程序的常见用途。本节包含一个简单的示例，在文本文件中搜索特定记录。在实际应用程序中，键值不会是（伪）随机数，而是用于识别数据的标识。

```
if (saying_file== NULL) /* error - didn't open file */
{
printf("Internal failure #1 please report %d\n", errno);
printf("</p> </body> </html>\n");
fflush(stdout);
exit (1);
}
srand(time(NULL)); /* init pseudo-random number */
record_number = rand()%10; /* get and scale random number */
for (loop_index = 0; loop_index <= record_number; loop_index++)
fgets(input_line, sizeof(input_line), saying_file);
printf("<h2>Saying Number %d</h2>\n", record_number);
printf("<p>\n");
printf("%s\n", input_line);
printf("</p> </body> </html>\n");
fflush(stdout);
fclose (saying_file);
exit (0);
}
```
