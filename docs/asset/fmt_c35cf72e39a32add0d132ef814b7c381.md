## 572 高级 UNIX 编程

成员 `XAnyEvent` 定义了若干与任何事件都共有的额外成员：

```c
typedef struct {
    int type; /* 事件类型 */
    unsigned long serial; /* 服务器处理的最后一个请求的数 */
    Bool send_event; /* 如果来自 SendEvent 请求则为真 */
    Display *display; /* 读取该事件的显示器 */
    Window window; /* 事件掩码中请求的窗口 */
} XEvent;
```
