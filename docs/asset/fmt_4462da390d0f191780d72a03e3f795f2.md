
```c
Bool XQueryPointer(display, w, root_return, child_return, root_x_return, root_y_return, win_x_return, win_y_return, mask_return);
```

- 指定与 X 服务器的连接。
- 指定窗口。
- 返回指针所在的根窗口。
- 返回指针所在的子窗口（如果有）。
- 返回相对于根窗口原点的指针坐标。
- 返回相对于指定窗口的指针坐标。
- 返回修饰键和指针按钮的当前状态。

`XQueryPointer` 函数返回指针逻辑所在的根窗口以及相对于根窗口原点的指针坐标。如果 `XQueryPointer` 返回 `False`，则指针与指定窗口不在同一屏幕上，且 `XQueryPointer` 向 `child_return` 返回 `None`，并向 `win_x` 和 `win_y` 返回 `None`。如果 `XQueryPointer` 返回 `True`，指向 `win_x` 和 `win_y` 的指针坐标相对于指定窗口的原点。在这种情况下，`XQueryPointer` 返回包含指针的子窗口（如果有），否则返回 `None`。

`XQueryPointer` 在 `mask return` 中返回键盘按钮和修饰键的当前逻辑状态。它将 `mask` 设置为一个或多个按钮或修饰键位掩码的按位或结果，以匹配鼠标按钮和修饰键的当前状态。

注意，如果设备事件被冻结，通过 `Xlib` 看到的设备逻辑状态可能会后于物理状态（见第 12.1 节）。

`XQueryPointer` 可能会产生 `BadWindow`。

## 窗口信息

函数

`y_return`

返回定义可图区域位置的 x 和 y 坐标。对于窗口，这些坐标指定相对于其父窗口原点的左上外角。对于位图（pixmaps），这些坐标始终为 0。

`width_return`

返回可图区域的尺寸（宽度和高度）。对于窗口，这些尺寸指定内部大小，不包括边框。

`height_return`

返回以像素为单位的边框宽度。如果可图区域是位图，则返回 0。

`border_width_return`

返回可图区域的深度（像素比特）。

`depth_return`

`XGetGeometry` 函数返回根窗口和可图区域的几何结构。可图区域的几何结构包括 x 和 y 坐标、高度、边框宽度深度。这些在参数列表中描述。解析类为 `isOnly` 的窗口是合法的。

`XGetGeometry` 可能会产生 `BadDrawableError`。

## 翻译屏幕坐标

应用程序有时需要从一个窗口的坐标空间到另一个坐标空间进行坐标变换，或者确定指针所在的窗口层深度。`XTranslateCoordinates` 和 `XPointer` 通过请求 X 服务器执行这些操作来满足这些需求（避免任何竞态条件）。

要将一个窗口中的坐标翻译到另一个窗口的坐标空间，请使用 `XTranslateCoordinates`。

```c
Bool XTranslateCoordinates(display, src_w, dest_w, src_x, src_y, dest_x_return, dest_y_return, child_return);
```

- `display`: 指定与 X 服务器的连接。
- `src_w`: 指定源窗口。
- `dest_w`: 指定目标窗口。
- `src_x`: 指定源窗口内的 x 和 y 坐标。
- `dest_x_return`: 返回目标窗口内的 x 和 y 坐标。
- `child_return`: 如果坐标包含在目标窗口的映射子窗口中，则返回子窗口。

如果 `XTranslateCoordinates` 返回 `True`，它返回相对于源窗口原点的 src 这种坐标，并将这些坐标作为相对于目标窗口原点的 `dest_x` 和 `dest_y` 返回。如果 `XTranslateCoordinates` 返回 `False`，则 `src_w` 和 `dest` 在不同的屏幕上，且 `dest_x` 和 `dest_y` 返回 0。如果坐标在 `dest_w` 的映射子窗口中，则返回给 `child_return`。否则，`child_return` 被置为 `None`。

`XTranslateCoordinates`可能会产生 `BadWindow`。

## 信息函数

`XInternAtom` 函数返回与指定名称字符串关联的原子（atom）标识符。如果 `only_exists` 为 `False`，则当该原子不存在时会创建它。因此，`XInternAtom` 可能返回 `None`。如果该原子不在主机可移植字符编码（Host Portable Character Encoding）中，结果取决于实现。大小写敏感；字符串 `"thing"`、`"Thing"` 和 `"thingG"` 代表不同的原子。即使客户端连接断开，该原子仍将保持定义。只有当与 X 服务器的最后一个连接关闭时，它才会变为未。

`XInternAtom` 可以产生 `BadAlloc` 和 `BadValue` 错误。

要返回一组名称对应的原子，请使用 `XInternAtoms`。

```c
Status XInternAtoms(display, names, count, only_if_exists, atoms_return);
```
`display` 指定与 X 服务器的连接。
`names` 指定数组中原子的数量。
`only_if_exists` 指定一个布尔值，表示必须创建该原子。
`atoms_return` 返回原子。

`XInternAtoms` 函数返回与指定名称关联的原子标识符。原子存储在调用者提供的 `atoms_return` 中。调用此函数等同于依次为每个名称使用指定的 `only_exists` 值调用 `XInternAtom`，但此函数最大限度地减少了客户端与 X 服务器之间的往返协议交换次数。
