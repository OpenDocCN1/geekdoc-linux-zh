
# 理解用户与组

用户管理是系统健康维护的基础活动。出于安全考虑，管理应仅限于少数需要管理账户的用户。有三个主要的用户管理策略：

- `/etc/passwd` - 识别系统的授权账户。
- `/etc/shadow` - 保存相应账户的加密密码。大多数 Unix 系统都有此文件。
- `/etc/group` - 包含组信息。

## /etc/passwd

第一个且最重要的——`/etc/passwd`。此文件包含了 Unix 系统上账户的大部分信息。几乎任何拥有账户的用户都可以查看此文件，但 `root` 可以修改它。

### 帮助页结构

帮助页通常分为几个章节，这些章节通常取决于帮助页作者的偏好。以下是一些常见的章节：

- **NAME**—命令名称。
- **SYNOPSIS**—命令的通用用法参数。
- **DESCRIPTION**—通常描述命令本身及其功能。
- **OPTIONS**—描述命令的所有参数或选项。
- **ALSO**—列出帮助页中与该命令直接相关或功能相似的其他命令。
- **BUGS**—解释命令或其输出中存在的任何已知问题或错误。
- **EXAMPLES (or TIPS)**—常见用法示例，让读者了解如何使用该命令。
- **AUTHORS**—帮助页/命令的作者。

### 搜索帮助页

你并不总是知道你需要的命令，但如果你知道某个命令的主要点，可以使用 `-k` 选项来搜索帮助页，该选项会在帮助页中查找关键词。例如，如果你需要更改文件的权限，但不记得要用哪个命令，可以输入：

```bash
man -k permission
```

我们将得到一个关键词中包含 `permission` 单词的命令列表。

### Emacs 配置技巧

将以下内容添加到你的 `.emacs` 文件中，然后按下 `F1` 即可获得当前光标位置库调用的帮助页。

```elisp
(global-set-key [[f1]] (lambda () (interactive) (manual-entry (current-word))))
```

### 获取纯文本版帮助页

要获取不包含退格键和下划线的纯文本版帮助页，请尝试：

```bash
man foo | col -b > foo.mantext
```

## /etc/passwd 文件详解

查看文件中的任意某行（示例使用了 `beginningunix` 行），你可以看到它由七个不同的部分——称为“字段”组成，并用冒号分隔。虽然某些字段可以为空，但文件中的每个条目都必须包含所有七个字段。

```
root:x:0:0::/root:/bin/bash
daemon:x:1:1:::
bin:x:2:2:/bin:/usr/bin/nologin
sys:x:3:3:/dev:/usr/bin/nologin
adm:x:4:4:/var/adm:/usr/bin/nologin
lp:x:5:7:12:/var/spool/lp:/usr/bin/nologin
uucp:x:6:8:uucp:/usr/lib/uucp:/usr/bin/nologin
sssmp:x:25:25:Mail Submission::::
list:x:27:27:bin:/bin:/usr/bin/nologin
ngin:x:50:50:Reserved UID::/usr/bin/nologin
webadm:x:80:80:Web Server Reserved UID::/usr/bin/nologin
nobody:x:6000:6000:NFS Anonymous User::/usr/bin/nologin
noacess:x:6002:6002:No Access User::/usr/bin/nologin
nonexistent:x:65534:65534:No Anonymous User::/usr/bin/nologin
beginningunix:x:510:100:Beginning Unix:/export/home/beginningunix:/usr/bin/bash
```

### 字段说明

每行包含以下七个字段：

1. **用户名**
2. **加密密码或 `x`** (占位符，实际密码存储在 `/etc/shadow`)
3. **UID** (用户标识符)
4. **GID** (组标识符)
5. **GECOS/注释** (用户全名、办公室、电话等信息)
6. **家目录**
7. **登录 Shell**
