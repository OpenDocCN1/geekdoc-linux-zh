
由 `Linux Torvalds` 及其朋友从 1991 年开始创建的自由 Unix 世界。读音 `/linuks/` 更受欢迎，因为“Linux”这个名字在瑞典语中有一个 ee（瑞典人家族是芬兰 6% 的瑞典裔少数民族），而在英语中是短音 i 读作 lee/ 或英语的长 l/。这可能是历史上最注目的黑客项目——一个为 386、488 和 Pentium 机器设计的完整 Unix 克隆，通过网络免费分发源码（也用于 Alpha、Spar 以及其他机器的端口）。`Linux` 是 `(GNU)` 所指的，它与 GNU 工具相关。但自由软件基金会（`FSF`）直到 1999 年才生产与之配套的内核，这太晚了。其他努力如 `FreeBSD` 和 `NetBSD` 尚未能像 `Linux` 那样成功解决问题；正如 2001 年所示，`Linux` 正在严峻地挑战微软的操作系统。它显然已占据 31% 的服务器市场和 25% 的通用业务服务器。此条目的早期版本写道：“`Linux` 成功的秘密在于 `Linux`，它付出了更多努力让开发过程开放并招募了其他黑客，创造了雪球效应。”比我们知道的还要真实。[大集市]。（有些人反对认为，“`Linux`”这个名称应该只指代内核，而不是整个操作系统。这是一个关于底层争议性标题的主张；那些坚持整个系统的人声称：“`GNU/Linux` 希望 [`FSF`] 获得 `Linux` 的大部分功劳，而 `RMS` 和他的朋友编写了许多用户工具。无论这种理论还是“`GNU/Linux`”这个术语都没有获得超过少数派的认可。）出自典型的前线术语（文件 4.3.0，2001 年 4 月 30 日）[j语]

# Linux

“`Linux`”一词提供了许多供应商提供的完整软件包，或者具体说是它们所基于的内核。这些软件包被称为发行版（distributions）或简称为 `dist`。众名的 `Linux` 发行版包括 `RedHat`、`SUSE`、`Turbo/Linux` 等。这些发行版大部分完全依赖开源软件。要点：`Linux` 认为 `Solaris` 和 `Windows` 是互联网服务器最流行的操作系统。对比：`Linux` 是一个类 Unix 操作系统，更类似于 `UNIX 5` 而不是 `BSD Unix`。自《黑客词汇表》

## Linux 词典

一种兼容 UNIX 的操作系统（内核），使用自由软件工具设计并移植到多种硬件架构。`Linux` 起初由 `Linux Torvalds` 于 1991 年开发。`Linux` 是开源软件 (`OSS`)，旨在成为竞争操作系统的可行替代方案。出自 `RedHat–9` – 词表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux 西里尔版

`UrbanSoft` 创建了 `Linux` 西里尔版，即俄语版的 `Red Hat`。该网站已不再可用 [ 2002 年 5 月]。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux DA OS

更多信息请见 `LinuxDevices`。这些技术为 `Motorola Dragonfly` 平台制作了这一可用操作系统。其他平台正在“开发中”。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux Eeware

提供盒装版，包含桌面版和服务器版。提供支持、课程和其他服务。西班牙发行版。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux for Windows 9

这是一个对 9X 友好的 `Linux` 版本。它安装在 `Windows 9` 上。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux Loader (LILO)

一种用于操作系统的加载器。`LILO` 在主引导记录 (`MBR`) 上运行。出自 `RedHat–9` `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux MLD

这是一个基于媒体的发行版，它包含一个文本界面和 Web 界面。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux Router

这是一个可以放在光盘上的微型 `Linux` 发行版。它几乎可以在任何带有操作系统的 PC 上运行。它提供了网络路由器等服务。`http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux SIS

`SIS` 是一个基于网络的发行版，用于学校。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux/Epia

一个用于 `Epoxy` 的发行版。它提供了多种编译好的软件包。0.01 版本于 2003 年 6 月 11 日发布。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux/Coldfire

一个针对 `Motorola` 架构的发行版。它提供了许多 `Linux` 管理工具。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux/MNIS

一个基于 `Debian` 的法语发行版。它支持 `Intel` 平台。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux4Geeks

`Linux4Geeks` 是一个基于 `LFS` 的小型发行版，解决了主流发行版的某些问题。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## LinuxAlpha

一个用于 `Alpha` 处理器的 `Linux` 。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## Linux Bootable Card

`LBT` 是一个可以放在信用卡介质上的完全可用 `Linux` 发行版。它几乎可以在任何操作系统上运行。它提供了超过 108MB 的软件，包括内核、`Xfree 4.1`、无线连接等。出自 `LWN` 发布列表 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

## linuxconf

一个功能强大的 `Linux` 管理工具，`linuxconf` 提供文本、`X` 界面和 Web 界面。这是基础软件包，仅包含文本和 Web 界面。更多信息请访问 `Linuxconf` 主页 `http://www.solucorp.qc.ca/linuxconf/`。出自 `Debian 3.0 APT` `linuxconf` 是一个极其强大的系统配置工具。提供了四种界面供你选择：命令行、字符单元（类似于安装程序）、基于 `X` 系统的 GUI 和 Web 界面。`Linuxconf` 可以管理大部分系统操作，包括网络、用户账户、文件系统、启动参数等。`Linuxconf` 将简化你的配置。除非你完全满意手动配置系统，否则你应该安装 `linuxconf` 软件包并使用它。出自 `Mandrake 9.0` `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

## linuxbook

旨在帮助忙碌现代用户的技巧和方法，这是 `Michael Stutz` 编写、`No Star Press` 出版的在线版本。该书涵盖了普通用户如何开始使用 `Linux`，从文件移动到声音以及网络话题。出自 `Debian 3.0 APT` `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

## linuxDoc DTD

`linuxdoc-tools` `nuxdoc` 是一套基于 `SGML` 的文本格式套件，使用 `Linuxdoc` 文档类型。`linuxdoc-tools` 允许从单个 `SGML` 源产生 `LaTeX`、`HTML`、`GNU info`、`LyX`、`RTF`、纯文本（通过 `groff`）以及其他输出格式。`linuxdoc-tools` 用于编写技术软件文档。出自 `Redhat 8.0 RPM` `http://www.tldp.org/LDP/Linux-Dictionary/index.html`
