以下练习将向你展示如何通过添加位图图像为别墅模型添加天空：

1. 继续之前的练习或打开 `Savoye9b.max`。
2. 选择渲染（`Rendering`）➤ 环境（`Environment`）或按下 `8` 键。显示环境和效果框。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_485_1.png)

3. 点击“使用地图”（`Use Map`）框正下方标记为“无”（`None`）的环境地图按钮。材质/地图浏览器打开，显示地图类型列表。
4. 点击地图列表中的位图（`Bitmap`）选项，然后点击确定（`OK`）。

### 关闭视口背景

环境背景会自动显示在视口中。要关闭此项，选择 `Views`（视图） ➤ `Viewport Background`（视口背景），并在 `Viewport Image`（视口图像）对话框中取消勾选 `Display Background`（在视口中显示背景）。

#### 对背景进行调整

在许多情况下，背景图像需要调整以适应场景。背景图像可能无法正确匹配，或者可能太暗或太亮。你发现背景略低于水平且整体偏暗。在本节中，你将学习如何使用 `Material Editor`（材质编辑器）对背景进行调整。

1. 点击工具栏上的 `Material Editor` 按钮。
2. 在 `Material Editor` 对话框中，点击右侧的样本槽。点击 `Get Material` 按钮。
3. 在 `Material/Map Browser` 对话框中，点击 `From Group` 中的 `Scene` 单选按钮。材质列表将显示场景中的所有材质。
4. 选择显示 `SUNSET90.JPG` 的列表。你会在对话框左上角的预览窗口看到材质样本。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_487_1.png)

### 第 9 章布局设计

5. 双击 `SUNSET90.JPG`。日落图像出现在 `Material Editor` 的选中样本中。修改位图的参数也显示在 `Material Editor` 的下部。关闭 `Material/Map Browser`。记住，你不能直接将贴图应用于对象——贴图通常是材质的子级。一旦在 `Material Editor` 中获取背景图像，就可以控制它的外观。接下来你将使用 `Coordinates`（坐标）面板来偏移视口中的背景。

1. 进入 `Coordinates` 面板，拖 `U` 和 `V Offset`（偏移）调节器。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_488_0.png)

环境背景图像相对于 `Mycamera01` 视口中的静态几何体移动。

2. 右点击 `Mycamera01` 视口，选择 `Views` ➤ `Mycamera`。
3. 使用 `Pan Camera`（平移相机）工具向上移动视口。你现在有了更好的天空视野。如果你关闭了视口中的环境贴图显示，现在将其开启。
4. 点击 `Coordinates` 面板中的 `Mapping`（映射）下拉列表。将映射类型更改为 `Spherical`（球形）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_488_1.png)

### 环境映射

`Cylindrical`（圆柱形）和 `spherical`（球形）映射将环境位图包裹在这些凸形状的内部。`Shrink-wrap`（收缩）映射使贴图贴合凹面。`Screen`（屏幕）包裹是最常用的选择，因为它像平面绘画一样简单将位图贴在背景上。观察图像在围绕大球体内部拉伸时是如何畸变的。你可以看到云在环绕球体时略微弯曲。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_488_2.png)

**图 9.11**

球形环境映射

![](img/7e143440dd5a0ed9683d4f26f3c074f_0.png)

鱼眼镜头具有适用于球形环境映射的畸变。为了使用球形、圆柱形或收缩环境映射，位图必须以相同的方式进行畸变。否则，“正常”位图在这种用法下会显得拉伸。由于你将使用 `SUNSET90.jpg` 位图，你应该使用屏幕映射直接将图像贴到环境中而不产生畸变：

1. 将映射类型更改为 `Screen`。

| Coordinates | | |
| :--- | :--- | :--- |
| Texture | Environment | Screen |
| Show Map on Black | | |

2. 在 `Coordinates` 面板中，`U` 和 `V Offset` 的值回到 `0`。位图将直接贴到背景中，如图 9.12 所示。

**图 9.12**

屏幕环境映射

![](img/7e143440dd5a0ed9683d4f26f3c074f8_489_1.png)

右点击任何调节器都会将值设置为最低非负值。你可以根据需要调整 `Offset`（偏移）和 `Tiling`（平铺）调节器，移动并拉伸背景上的日落，直到它与建筑的关系处于美观的位置。现在让我们如何调整背景图像的亮度：

1. 在 `Material Editor` 中，滚动到 `Output`（输出）面板并展开它。你会看到一个图和一组复选框和调节器，如图 9.13 所示。
2. 点击 `Output` 面板中的 `Enable Color Map`（启用色彩映射）框。图被高亮，以便你调整其设置。

**图 9.13**

`Material Editor` 的 `Output` 面板

![](img/7e143440dd5a0ed9683d4f26f3c074f8_490_0.png)

如果你是 `Adobe Photoshop` 用户，`Color Map` 图应该看起来有些熟悉，因为它与 `Photoshop` 中的 `Curves`（曲线）类似。`Color Map` 允许你通过操纵图中的线条来调整图像的色调范围。现在，线条从左下角的 `0,0` 直到右上角的 `1,1`。你可以通过在图中添加控制点来调整图像的亮度、对比度和色调范围。接下来的练习将展示 `Color Map` 的功能：

1. 滚动 `Output` 面板以看到整个 `Color Map`；然后点击 `Color Map` 工具栏上的 `Add Point`（添加点）工具。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_490_1.png)

2. 点击 `Color Map` 图线条的中点，如图 9.14 所示。线条上出现了一个方形手柄。

**图 9.14**

点击线条的中点

![](img/7e143440dd5a0ed9683d4f26f3c074f8_490_2.png)

在此处添加点。

3. 点击 `Color Map` 工具栏上的 `Move`（移动）工具。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_490_3.png)

4. 点击刚刚创建的点并向上拖动释放。观察 `Material Editor` 中样本图像的变化。它变亮了。

`Output Curves` 的更改不会显示在视口中，但显示在 `Material Editor` 和渲染视图中。通过向上调整中间点的线条，你增加了图像中的暗调量。通过查看 `Output` 面板底部的样本渐变来获取更改的直接反馈。
