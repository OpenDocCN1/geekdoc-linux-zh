## 获取 Linux 副本的方法

如果你有一个高速互联网连接（绝对不是 28.8 调制解调器）并且你不是完全的新手，下载 Linux 可能对你来说仍然是一个选择。如果网站不是太忙，可以尝试：`http://ftp.redhat.com/pub/`。

有很多方法。你可以从 Linux Mall (`http://www.LinuxMall.com/`) 购买“RedHat”CD，或者从 cheapbytes (`http://cart.cheapbytes.com/cgi-bin/cart`) 购买——据我上次检查，那里“非官方”的 RedHat 6.1 GPL 分别为 1.89 美元和 1.99 美元（不含运费和手续费）。他们会邮寄给你一张光盘。你得不到说明书，也没有启动支持，但价格很合适，而且里面包含了说明书和制作启动盘的工具。我在 "cheapbytes" 购买了几个软件包，它们总是送得很快，质量没有问题，我的信用卡扣费也没有任何问题（作者与 "cheapbytes" 没有任何关系）。

(2) 从互联网上同一个地方或你喜爱的软件供应商那里购买盒装 Red Hat，价格从 40 美元起——你会得到一个带有“捆绑”应用程序的启动盘，可能还有其他的（免费更新）。

(3) 从你朋友那里拷贝安装 CD。这完全没问题且可以——Linux 是免费的。附带 CD 的 Linux 手册包含一个完整的发行版。这是开始学习 Linux 的好方法！拥有一本精美的 Linux 手册绝对是好事。由于 Linux 命令数非常多，我一直需要手册。当附近有 Linux “免费安装”活动时，去那里看看。当地的“Linux 大师”会在你的电脑上安装 Linux（让电脑变免费），而且当你带上 1 张或更多空 CD-R 去参加聚会时，你可能会得到一张（两张）Linux CD。在网上查找 Linux 用户组，看看你附近什么时候可以找到安装服务。这是与其他 Linux 用户交流的好方法。

(4) 如果你缺钱，或者是在世界上某些地方 2 美元可以花很多钱当 Linux 先驱，可以寻找“linux exchange”或“giveaway”——那些捐赠 Linux CD 的人（例如尝试：`http://visar.csustan.edu/giveaway.html`）。如果你住在大城市，你甚至可能很幸运，有人帮助你安装/设置 Linux。如果你找不到任何地方，请告诉我 (`bklimas@magma.com`)。我会尝试安排一份 Linux CD 给你（如果你不是在开玩笑的话）。再次强调，如果你手里有一张 Linux CD，不要把它借给你的邻居。

## BIOS 启动设置

如果你的电脑可以从光驱启动（大多数电脑都是如此），你就不需要启动盘来安装 Linux。查看你的 BIOS 设置，你可以自行设置启动选项。我的电脑在 BIOS 中将光驱指定为第一个启动设备，但仍然无法从光驱启动。因此，BIOS 设置并不意味着你只需将 RedHat CD 插入光驱并重启电脑就能进入 RedHat Linux 安装程序。

如果你不知道如何访问 BIOS 设置，请阅读此段。通常可以在启动时通过在正确的时刻按下某个键（通常是在短暂显示字母时）进入 BIOS 设置。通常是 `<Del>` 键。以下是常用 BIOS 使用的按键组合列表：

- 戴尔笔记本：在开机自检 (POST) 期间按下 `<F2>`。
- 华硕微 (AMI)：在开机自检期间按下 `<Del>`。
- Award：`<Del>` 或 `<Ctrl><Alt><Esc>`。
- 康柏 (Compaq)：启动过程中屏幕右上角出现方框后按下 `<F10>`。
- 戴尔 (Dell)：`<Ctrl><Alt><Enter>`。
- DTK：在开机自检期间按下 `<Esc>`。

## 双系统安装注意事项

如果你计划进行双启动（在同一台电脑上安装 Linux 和 MS Windows），请先使用你的 DOS/Windows 工具 `FDISK` 创建 MS Windows 分区。留出硬盘的一部分不分区以供 Linux 使用。你将在 RedHat 安装期间创建并格式化 Linux 分区。将 MS Windows 分区设为“主分区”且“可启动”的。在安装 Linux 之前，请先安装、配置并测试你的 MS Windows。如果你只想运行 Linux，刚开始只需要一个干净的硬盘（无分区）即可。
