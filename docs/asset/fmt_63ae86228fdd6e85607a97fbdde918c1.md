# sccs-delta, delta — 为 SCCS 文件创建增量

### 概要
```
/usr/ccs/bin/delta [-dnps][-g sid-list | -g sid-list]
[-m mr-list | -m mr-list][-r sid | -r sid][-y[comment]]
s.filename=...
/usr/xp4/bin/delta [-dnps][-g sid-list | -g sid-list]
[-m mr-list | -m mr-list][-r sid | -r sid][-y[comment]]
s.filename=...
```

## sccs-delta, delta

## 描述
使用 SCCS `delta` 命令提交对受 SCCS 控制的检出（checked-out）文件进行的逐行差异记录。这些更改取自通过 SCCS `get` 命令获取的可写工作副本（参见 `sccs-get(1)`）。该工作副本没有 `s.` 前缀，也被称为 `g-file`。

如果你使用目录名代替 `s.filename` 参数，`delta` 命令将适用于所有 `s.` 文件。不可读的 `s.` 文件会产生错误；继续处理下一个文件（如果有）。使用连字符 `-` 文件名参数表示从标准输入读取读取的文件名，每行一个 `s.` 文件（需要 `-y`，在某些情况下需要 `-m`）。

- `delta` 可以根据指定的选项、`s.` 文件中设置的标志向标准输出发出提示（参见 `sccs-admin(1)` 以及 `-m` 和 `-y` 选项）。

`/usr/xpg4/bin/delta`
增量的 `sid` 不回显到标准输出。

## 选项
- `-d` 使用 `diff(1)` 命令代替 `diff(1)`。如果你未指定 `s.filename` 参数，则返回退出状态 `2`。
- `-g sid-list | -g sid-list`
  在由此增量创建的 SCCS 版本 ID (`sid`) 访问文件时，指定增量列表。`sid-list` 是逗号分隔的 `sid` 列表。要指定增量范围，请在列表中的两个 `sid` 之间使用连字符 `-` 分隔代替逗号。
- `-m mr-list | -m mr-list`
  为新增量指定一个或多个修改请求 (`MR`) 号。如果 SCCS 具有 `v` 标志（参见 `sccs-admin(1)`），`mr-list` 采用空格分隔列表的形式。如果你不使用 `-m` 且标准输入为终端，`delta` 将提示列表（显示注释）。

`/usr/xpg4/bin/delta`
增量的 `sid` 不回显到标准输出。

- `-n` 保留处理后通常会被删除的编辑 `g-file`。
- `-p` 向标准输出显示逐行差异（`diff(1)` 格式）。
- `-r sid`
  已检出两个或多个版本，指定要提交的版本。此 `sid` 值可以是命令行指定的 `sid`，也可以由 `get` 报告的新版本 `sid`。如果指定的 `sid` 有歧义或未提供，则产生诊断结果。
- `-S` 不显示警告或确认消息。抑制错误消息（写入错误）。
- `-y[comment]`
  为增量提供注释。空注释会被接受并在日志。如果你不指定 `-y` 且标准输入为终端，`delta` 将提示未转义的换行。

## 退出状态
- `0` 完成。
- `1` 发生错误且你未指定 `-d` 选项。
- `2` 发生错误是因为你指定了 `-d` 选项但未包含 `s.filename` 参数。

# sccs-get, get — 获取 SCCS 文件的版本

### 概要
```
/usr/ccs/bin/get [-begkmnpst][-1[p]][-a sequence]
-c date-time [-c date-time][-G g-file]
-i sid-list [-i sid-list][-r sid]
-x sid-list [-x sid-list] s.filename...
/usr/xpg4/bin/get [-begkmnpst][-1[p]][-a sequence]
-c date-time [-c date-time][-G g-file]
-i sid-list [-i sid-list][-r sid]
-x sid-list [-x sid-list] s.filename
```

## 描述
使用 SCCS `get` 命令通过指定的选项从 SCCS 历史文件中获取工作副本。

对于每个 `s.filename` 参数，`get` 显示 SCCS 增量 ID (`sid`) 和获取的行数。

如果你使用目录名代替 `s.filename` 参数，`get` 命令将适用于该目录下的所有 `s.` 文件。不可读的 `s.` 文件会产生错误；程序将继续处理下一个文件（如果有）。使用连字符 `-` 作为 `s.filename` 参数表示从标准输入读取的文件名，每行一个 `s.` 文件。

获取的文件通常与 `s.file` 相同的文件名（去掉前缀），被称为 `g-file`。

对于每个处理的文件，`get` 向标准输出响应，所访问的 `sid` 以及从 `s.` 文件中获取的行数。

## 选项
- `-a sequence` 获取对应于指定增量序列号的版本。此选项主要供 SCCS `comb` 命令使用（参见 `sccs-comb(1)`）；`-r` 是指定版本的更简单方法。当两者都使用时，`-a` 覆盖 `-r`。
- `-b` 创建新分支。带有 `-e` 选项指示新增量应在新分支中具有 `sid`。而不是增加要提交版本的层级，而是在要提交增量的 `p.file` 中指定初始化新分支和序列（如果当前层没有现有分支）或增加 `sid` 的分支部分。如果 `s.file` 中未设置 `b` 标志，则忽略此选项。
