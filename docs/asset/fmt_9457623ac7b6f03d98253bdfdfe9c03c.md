## 使用电子表格

电子表格是数据的表格化表示。数据按行和列排列，使得信息更容易存储、组织和分析。`OpenOffice Calc` 是一个专门为处理表格格式数据设计的程序。在电子表格单元格中输入的数据可能是数值或文本。电子表格支持以下函数：

- `ADDRESS()` 函数
- `COLUMN()` 函数
- `ROW()` 函数

让我们详细讨论这些每一个函数。

### `ADDRESS()` 函数

`ADDRESS()` 函数根据指定的行和列号以文本形式返回单元格地址（引用）。你可以确定该地址是被解释为绝对地址（例如：`$A$1`）、相对地址（`A1`）还是混合形式（`$A1`）。你还可以指定工作表的名称。以下是 `ADDRESS()` 函数的语法：

```
ADDRESS(row; Column; Abs; "Sheet")
```

在前面的语法中：

- `Row`（行）：代表单元格的行号。
- `Column`（列）：代表单元格的列号。
- `ABS`：确定引用类型。
- `Sheet`（表）：代表工作表名称。必须放在双引号中。

执行以下步骤查找地址：

1. 点击公式栏上的函数向导。出现函数向导对话框（图-`Calc-2.1`）。
2. 点击 `Category`（类别）列表框上的向下箭头。选择所需的函数类别。在本例中，我们选择了 `Spreadsheet`（电子表格）类别（图-`Calc-2.3`）。
3. `Spreadsheet` 类别显示在 `Category` 列表框中（图-`Calc-2.35`）。
4. 从 `Function`（函数）列表中选择所需的函数。在本例中，我们选择了 `ADDRESS` 函数（图-`Calc-2.35`）。
5. 点击 `Next`（下一步）按钮（图-`Calc-2.35`）。

![](img/12ecf7a0767a6080881fb04f59162115_466_1.png)

### `COLUMN()` 函数

`COLUMN()` 函数提供所选单元格的列号。`COLUMN()` 函数的语法如下：

```
COLUMN(Reference)
```

在前面的语法中，`Reference` 指单元格或区域。如果没有使用引用作为输入，则返回函数所在的列号。执行以下步骤查找单元格的列号：

1. 点击公式栏上的函数向导。出现函数向导对话框（图.`Calc-2.1`）。
2. 点击 `Category`（类别）列表框上的向下箭头。选择所需的函数类别。在本例中，我们选择了 `Spreadsheet`（电子表格）类别（图-`Calc-2.38`）。
3. `Spreadsheet` 类别显示在 `Category` 列表框中（图-`Calc-2.41`）。
4. 从 `Function`（函数）列表中选择所需的函数。在本例中，我们选择了 `COLUMN` 函数（图-`Calc-2.41`）。
5. 点击 `Next`（下一步）按钮（图-`Calc-2.38`）。
6. 在 `reference` 文本框中输入单元格地址。在本例中，我们输入了 `B6`（图-`Calc-2.39`）。
7. 点击 `OK` 按钮（图.`Calc-2.39`）。

`ROW()` 函数返回单元格引用的行号。如果引用是单元格，则返回该单元格的行号。`ROW` 函数的语法如下：

ROW(Reference)
