# 6 操作符在哪里？

在现实世界中，有操作总机、计算机、推土机、坦克等的操作员。在 Perl 中，操作符作用于数字和字符串，或者两者的组合。操作符是基于某些规则产生结果的符号，例如 +, -, *, >, <。本章专门介绍 Perl 操作符、其用法及其规则。

```
$year= (localtime) [5] + 1900;

$year % 4 == 0? printf "Year %d is leap year."\n",$year :

```
