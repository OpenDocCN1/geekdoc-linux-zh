在 23.2 中，我们有几点需要指出。首先，注意用法函数，以及我们如何直接从系统提取脚本的名称，该名称由 `SCRIPT_NAME=\`basename $0\`` 指定。这种使用反引号的命令替换位于键盘左上角 ESC 键下方。使用这种技术等同于美元括号方法，即 `$(command)`，正如我们在本书书中大多数章节的赋值任务中使用的的那样，其中 `basename $0` 命令处理 shell 脚本的名称。在 shell 脚本的主体中，在使用于用法函数之前，我们总是希望向系统查询脚本名称。如果我们在函数响应中使用 `basename $0`，返回将是函数的名称，而不是 shell 脚本的名称。我们永远不想硬编码脚本名称，因为将来有人可能会更改脚本的名字。

我想指出的下一点是对正则表达式的修改。之前，我们测试的是二进制数，它可以只由 0 和 1 组成。这次我们测试的是十进制数，它可以只由数字 0 到 9 组成。新的正则表达式所示：

```
        ;;

```

在这个 `case` 语句中，我们正在测试 `ARG[1]` 变量，它由位置参数 `$1` 表示。只有当数字在 0 到 9 之间时，此正则表达式才会将 `$1` 赋值给变量 `BASE_10_NUM`。如果在字符串中找到任何其他字符，将显示错误信息并在脚本以返回码 1 退出之前调用用法函数。

在 `BEGIN_OF_MAIN` 处，我们开始使用以下命令查询系统的 IP 地址：

```bash
IP=$(host $hostname) | awk '{print $3}' | awk -F ',' '{print $1}'
```

让我们逐步分析此命令的每个部分。在我的系统中，为了演示，我们凭空获取了一个 IP 地址。`yogi` 命令替换 `host $hostname` 产生如下输出：

```bash
[root@yogi:~/scripts]$ host $hostname
yogi is 163.155.204.42.
```

从输出可以看出，IP 地址位于第三字段，`163.155.204.42`。注意 IP 地址末尾多了一个逗号（,），我们没有包含它。在从命令输出中提取第三字段后，我们将其传递给 `awk` 语句（`cut` 命令在这里效果相同）。在语句的 `awk` 部分，我们通过逗号（,）设置字段分隔符并去掉它，使用 `-F ','` 符号表示字符串是用命令分隔的，以便我们提取出第一个字段，即 IP 地址。此结果通过命令替换赋值给 `IP` 变量。

现在我们已经有了整个 IP 地址，可以将其切分为四个数字。现在我们可以将每个数字转换为它们的十六进制值。为了将 IP 地址拆分为独立的各个数字，我们可以使用 `cut`、`sed` 或 `awk`。为了保持一致性，让我们使用 `awk`。这次我们使用点（.）对字符串（即 IP 地址）进行分字段，然后使用 `awk` 命令的 `print` 参数打印四个字段中的每一个。此时，我们剩留下了以下四个数字：

163 155 204 42

现在我们有一些数字可以处理了。因为我们想单独处理每个数字，我们将此输出通过到 `while` 循环中，并将四个数字分配给不同的变量。然后，在循环内部，我们将每个十进制数转换为十六进制。整个命令显示在此：

```bash
echo $IP | awk -F '.' '{print $1, $2, $3, $4}' | while read a b c junk
```

注意 `while` 语句末尾的最后一个变量 `junk`。我添加它是为了捕获上一个管道输出中可能产生的任何额外内容。是否有任何内容需要捕获并不重要，但如果有“额外”字段，`junk` 变量将捕捉输出中剩余的所有内容。除此之外，四个字段分别存储在变量 `a`、`b`、`c` 和 `d` 中。
