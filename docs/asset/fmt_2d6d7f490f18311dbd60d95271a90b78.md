
NetWare 4.x 及更高版本使用名为 eDirectory 的目录服务。用户账户配置在目录中。eDirectory 也可以运行在 Windows 和 Linux 等服务器上。eDirectory 使用以下方式组织：

- 树（Tree）代表整个网络，可能是一个或多个不同的部门。

- 资源以对象表示（如用户、服务器和卷）。
