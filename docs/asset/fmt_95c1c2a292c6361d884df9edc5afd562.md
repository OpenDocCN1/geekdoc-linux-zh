### 1.8.2 确保 GDM 登录 banner 已配置（自动化）

**配置适用性：**

- 级别 1 - 服务器
- 级别 1 - 工作站

**描述：**

`GDM` 是处理 `GNOME` 系统图形登录的管理器。

运行以下脚本验证登录屏幕 `banner` 已启用并设置：

```bash
#!/usr/bin/bash
{
  pkgoutput=""
  if command -v dpkg-query > /dev/null 2>&1; then
    pkgoutput="dpkg-query -W"
  elif command -v rpm > /dev/null 2>&1; then
    pkgoutput="rpm -q"
  fi
  pcl="gdm3" # 检查的包列表
  for pn in $pcl; do
    $pkgoutput "$pn" > /dev/null 2>&1 && pkgoutput="$pkgoutput\nPackage: $pn exists on the system - checking configuration"
  done
  if [ -n "$pkgoutput" ]; then
    output="" output2=""
    echo -e "$pkgoutput"
    # 查找现有设置
    gdmfile=$(grep -P "banner-message-enable" /etc/dconf/db/*)
    if [ -n "$gdmfile" ]; then
      # 设置 dconf 目录 (.d) 名称
      gdmprofile=$(awk -F'/' '{split($NF,a,.");print a[1]}' "$gdmfile")
      # 检查是否启用
      if grep -P "banner-message-enable" "$gdmfile"; then
        output="$output - The banner-message-enable option is enabled in $gdmfile"
      else
        output2="$output - The banner-message-enable option is not enabled"
      fi
      lsbt=$(grep -P "^banner-message-text:*" "$gdmfile")
      if [ -n "$lsbt" ]; then
        output="$output - The banner-message-text option is set to $lsbt"
      else
        output2="$output - The banner-message-text option is not set"
      fi
      if grep -P "system-db:*" "$gdmfile"; then
        output="$output - The gdmprofile exists"
      else
        output2="$output - The gdmprofile doesn't exist"
      fi
      if [ -f "/etc/dconf/$gdmprofile" ]; then
        output="$output - The gdmprofile exists in the dconf database"
      else
        output2="$output2 - The gdmprofile doesn't exist in the dconf database"
      fi
    else
      output2="$output2 - The banner-message-enable option isn't configured"
    fi
  fi
  echo -e "\n - GNOME Desktop Manager isn't installed\n - Recommendation is Not Applicable\n- Audit result:\n *** ***"
# 报告结果。如果没有失败 output2，则通过
if [ -z "$output2" ]; then
    echo -e "\n- Audit Result:\n ** PASS **\n$output"
else
    echo -e "\n- Audit Result:\n ** FAIL **\n - Reason(s) for audit failure:\n$output2\n"
    [ -n "$output" ] && echo -e "\n- Correctly set:\n$output\n"
fi
```
