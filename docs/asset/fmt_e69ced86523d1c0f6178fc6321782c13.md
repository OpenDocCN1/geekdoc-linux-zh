## AWS

一种强大且功能丰富的 Web日志分析器 Advanced Web Statistics (AWSs) 是一个用 `perl` 写的强大 Web日志分析器，它可以向你显示所有的 Web 统计数据，包括独立访问者、页面、访问量、高峰、搜索引擎、搜索你网站的关键词、损坏链接等。`webalizer` 提供更详细的信息和更好的图表，易于使用。可以作为 `CGI` 与 Web 服务器日志格式以及从命令行工作。支持多种语言（英语、法语、荷兰语、西班牙语、意大利语、德语、波兰语、希腊语……）。源自 Debian 3.0r APT

## axel

一个轻级下载工具 - 控制台版 该程序尝试通过为单个下载使用多个连接来加速下载。从 0.97 版本开始，程序还可以为一个下载使用多个镜像。该程序尽可能保持轻量（二进制格式为 25–30k），因此在字节关键型系统中可能作为 `wget` 的克隆有用。源自 Debian 3.0r0

Apache AxKit 的 XML 交付工具包是一个适用于 Apache 的 XML 应用程序服务器。它提供使用 W3C 标准技术或自定义代码将 XML 实时转换为任何格式（如 HTML、WAP 或文本）。AxKit 还使用内置的 Perl 解释器为 XML 转换提供一些极其强大的技术。AxKit 的重点是内容与呈现的分离。AxKit 使用的水线技术允许内容转换为可呈现格式，允许数据为他人提供不同的服务。AxKit 允许 Web 开发者专注于 Web 设计，允许内容人员基于纯内容工作，允许网站管理员专注于他们的核心竞争力。AxKit 基于组件构建。网站开发人员可以基于 AxKit API 创建完全自定义的 XML 应用程序服务器。AxKit 可以提供缓存设施，或者你可以创建自己的缓存处理器，以便在需要时进行 XML 转换（这可能非常耗时）。该工具包对于构建基于组件的网站和动态内容也有助益。完全支持数据库集成，允许从数据库交付 XML，或从数据库查询生成 XML。可以使用 Perl 语言构建动态组件，使可能性像 CGI 脚本一样无限，而不会产生编程可能带来的混乱。源自 Debian 3.0r
