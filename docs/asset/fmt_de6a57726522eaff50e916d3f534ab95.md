# Lsh

带有 DOS 兼容命令的初学者微 shell。Lsh 的灵感部分源于某些 PC 显示器的命令解释器（包括 4-DOS、DR-DOS、MS-DOS、N-DOS、PC-DOS、Q-DOS，这些可能是其所有者的商标，且已广为人知）。然而，此 shell 的大多数功能简单地改编自 Unix（这恰恰也是一个商标）shell。Lsh 对于具有某些 DOS 经验且不需要在 UNIX 下进行操作的用户来说特别有用。此 shell 将简化他们的过渡，并使使用拨号服务变得极其简单。请注意，这与 lsh Secure v2 (`SSH2`) 协议实现无关。如果你需要 SSH2 客户端，请安装 `lsh-client` 和 `lsh` 命令。上游网页页：`http://people.cs.uct.ac.za/~mwelt/lsh.html` 来自 Debian 3.0r APT

`http://www.ldp.org/LDP/Linux-Dictionary/index.html`
