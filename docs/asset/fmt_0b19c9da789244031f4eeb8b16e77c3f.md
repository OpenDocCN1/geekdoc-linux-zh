# 控制动画长度

许多动画师试图在太短的片段内放入过多内容。在建筑动画中，较慢的运动通常更好，这意味着要渲染更多的帧。一个典型的动画可能有几千帧长。

在继续之前，我将总结物体动画化过程中涉及的步骤。你可以通过开启“自动关键”按钮，使用滑块选择时间点，然后通过移动、旋转或缩放物体来在 `WIZ` 中创建运动。这创建了一个关键帧。在开启“自动关键”的状态下移动物体，新的位置信息将替换关键帧中的旧信息。你可以通过移动滑块选择某个时间点来创建关键帧。当你移动物体时，会创建一个关键帧。你可以通过右键点击时间轴来删除关键帧。当你开启“自动关键”时，要小心。你可以看到时间轴显示出一个关键帧。
