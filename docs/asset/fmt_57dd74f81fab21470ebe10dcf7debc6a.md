# 亚毫米天文学

通过探测约0.3到1毫米的亚毫米波长电磁谱对宇宙进行研究：亚毫米波段由毫米（1–10 mm）波长限制，更短的波长则由微波（20–1000 μm）限制。与10开尔文到数百公里之间的物体相互作用（通常在气体和尘埃介质中）在亚毫米波段特别强。

亚毫米波段是宇宙光谱最后被探索的部分之一。这是由于制造必须保持低温的灵敏探测器存在技术困难，并且为了避免地球大气的影响。大气分子、水蒸气、氧气吸收信号并发射自身的辐射，从而掩盖天文信号。这种影响在最短波长处最为严重，只有高山海拔站点和空间平台能够进行观测。观测仅在三个大气窗口内进行，波长约为0.35、0.45和0.85毫米。0.85毫米的辐射可以穿透海平面以上约2公里（1英里）处；而在干燥的夜晚，只有波长为0.35或0.45 μm的光子穿过大气并在夏威夷的茂纳亚山上4200米（14000英尺）处被探测。

几座望远镜在高山上运行，包括19米（49英尺）的詹姆斯·克拉克·麦克斯韦望远镜（JCMT）和10米（32英尺）的加州亚毫米望远镜（CSST）；位于智利的15米（49英尺）瑞典亚毫米望远镜（SEST）。这些望远镜看起来像卫星天线，但它们的表面是金属的，加工精度达到λ/2000。它们的大气吸收比空间望远镜多；但因为体积更大，它们可以收集更多的辐射。

在南极亚毫米红外天文台（SOFA），一台安装在747飞机上的8.2英尺望远镜按预期工作。以前的柯珀高空观测站（KAO）也曾飞行至14公里（46英尺）高度。飞行高度约为40公里（25英里）的平流层气球也可用于携带亚毫米望远镜；天文学家通过广泛的亚毫米观测研究温度为10–100 K的宇宙和宇宙背景。气体和尘埃的热化学、银河中恒星的形成、遥远星系之间介质的性质以及星系的演化都在亚毫米波段进行研究。对于富含尘气的区域，亚毫米观测是必要的。这些区域对可见光是不透明的，但亚毫米光仍然可以看到，使得这些区域能够被研究。

## 亚声反应

亚声反应是一种化学反应，其中一个或多个基团（原子）取代另一个基团或分子或离子。通常，整体化学结构不会因被替换的基团而改变。

亚声反应涉及反应物的攻击，该反应物被另一个原子或基团取代到发生取代的分子或离子。这涉及新键的形成和旧键的断裂。亚声反应根据反应物的性质、底物的性质（饱和碳化合物；亲核取代；或芳香族化合物）进行分类。

这些反应的系统命名由基团部分组成：感应 + 去 + 被替换的基团 + 与，取代、消除或基团变化。甲基基取代溴称为甲基溴化。
