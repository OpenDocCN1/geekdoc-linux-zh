
# 容量调节
除了原始的淡水循环无颌类（`Myxine`）外，所有现代脊椎动物，无论是淡水生物还是陆生生物，其血液中的盐分浓度仅为海水的三分之一到二分之一。肾小球的早期发育可以被视为一种响应体液容量调节需求的机制。因此，在低渗的淡水环境中，通过鳃和其他通透体表水分的渗透性流入会被一个简单的自我调节系统平衡，该系统通过血液容量增加导致静水压升高，进而提高肾小球滤过率。在淡水无脊椎动物中也能发现类似的机制，其中水分可能是通过心脏做功、收缩性血管泡或此类特化“肾脏”（如焰细胞、管细胞或肾管）中的纤毛排出，这些结构从体腔而非循环系统中提取多余水分。因此，这些通过平衡渗透性流入和静水流出而为无脊椎动物维持恒定含水量的结构，与脊椎动物中调节淋巴液跨毛细血管内皮壁生成的结构具有相同的基本参数。参见“`OSMOREGULATION MECHANISMS`”（渗透调节机制）。

## 电解质平衡
通过产生血浆超滤液来调节容量的系统，还必须保存离子和其他重要的血浆成分。保盐作用似乎是包裹肾小球的肾小管的主要功能。当滤液沿着肾小管向体外流动时，无机电解质通过高度特异性的主动细胞重吸收过程从滤液中提取出来，从而将这些成分恢复到循环系统中。

## 水分移动
肾小管细胞间的水分浓度梯度是通过水跟随盐分或其他溶质的主动移动而实现的。在水分可以自由跟随钠和阴离子主动重吸收的地方，例如近曲小管，存在等渗状态。在水分不能自由跟随盐分移动的地方，例如在缺乏抗利尿激素的远端小管段，会产生低渗的管液。

## 含氮废物
在主要的有机食物类别中，碳水化合物和脂质代谢的末端产物很容易通过二氧化碳和水的主要形式排出。然而，蛋白质更难排出，因为其代谢的主要衍生物——氨——是一种相对有毒的化合物。对于生活在水生环境中的动物，氨可以通过简单的扩散通过鳃快速排出。然而，当氨不能自由扩散到实际上无限的水生环境中时，其毒性就会成为一个问题，特别是对于完全在紧密包裹的卵或壳内发育的陆生形式胚胎。对于这类生物，氨的解毒是生存的必要条件。在脊椎动物的进化过程中，产生了两种依赖能量的生物合成途径，分别将潜在的有毒氨整合到尿素和尿酸分子中。这两种化合物即使在高浓度下也相对无害，但前者需要相对大量的水来确保其排出，而尿酸则需要一种特定的、消耗能量的肾小管分泌过程来确保其有效排泄。参见“`UREA`”（尿素）；“`URIC ACID`”（尿酸）。

## 尿液浓缩
哺乳动物肾脏独特的功能特征是浓缩尿液的能力。人类尿液的渗透浓度可以是血浆的四倍，一些生活在沙漠中、仅以种子为食且不喝水的老鼠，其尿液/血浆浓度比高达 9。哺乳动物浓缩尿液的能力最高可达 17。像海狸这样更多水生形态的生物，其浓缩能力相应较差。

浓缩作用依赖于一种溶质浓度梯度的存在，该梯度从内髓质乳头尖端向外延伸至皮质。髓质溶质的高浓度是通过一个双套索（双 U 形）逆流倍增系统实现的，该系统由尿液经过 Henle 环升支时主动去除盐分提供动力（图 2）。盐分在扩散回 Henle 环降支后，重新输送到髓质尖端。通过这种方式，在收集管末端周围的液体中建立了高渗状态。尿液通过完全被动的过程浓缩，水分从收集管管腔离开，以与围绕其末端的高渗液体达到平衡。参见“`URINE`”（尿液）；“`UROGENITAL SYSTEM`”（泌尿生殖系统）。[`RFE`]

# 尿路疾病
从肾盂到尿道外部区域的泌尿系统流出通路的疾病。肾脏本身疾病在另一篇文章中讨论。参见“`KIDNEY DISORDERS`”（肾脏疾病）。

膀胱是肿瘤的常见部位，这些肿瘤几乎总是起源于移行上皮细胞。恶变为移行细胞癌很常见。

膀胱排空不完全可能是由各种因素引起的。一种形式是，尿道内口抬高至其正常的下垂位置以上，导致膀胱底部出现未排空的残余尿液池。这种抬高在男性通常由前列腺增大引起，在女性则通常由膀胱膨出（`cystocele`）引起，即膀胱下壁向阴道膨出。另一种梗阻形式是膀胱颈部或尿道被诸如异常的先天阀门、前列腺增大、结石、肿瘤或淋病后尿道狭窄等多样化的病变阻塞。排空不完全的第三种主要原因是神经源性的，通常继发于脊髓损伤或疾病。

膀胱炎或膀胱炎症是一种极其常见的疾病，因伴随疼痛和尿频排尿而令人烦恼。膀胱结石通常由感染和梗阻引起。它们常常长得很大，直径可达数英寸。它们通常由多种尿液成分组成，特别是磷酸盐和尿酸盐。

膀胱或女性尿道与阴道之间的异常通道并不罕见。此类瘘管最常继发于分娩时的损伤。主要影响是感染和尿液通过阴道持续泄漏。

### 肾盂
肾盂是将尿液从肾脏输送到输尿管的囊状结构，容易受到多种疾病的影响。肾盂畸形很常见。肾盂可能分为两个或更多的囊，这些囊可能汇入单一输尿管或分别汇入独立的输尿管。仅凭这种畸形本身是良性的，但如果伴有梗阻，可能会出现疼痛症状以及肾组织的破坏。结石可能在肾盂中形成，通常在上皮层下方。结石的原因通常是某种代谢缺陷，导致草酸盐、尿酸盐、胱氨酸或钙盐等废物排泄过多。

### 女性尿道
该结构并不经常发生病变。在老年女性中，尿道外口可能出现一种由炎性组织组成的、类似覆盆子的疼痛肿胀，称为肉阜（`caruncle`）。[`RNB.`]

当找不到其他内在原因导致输尿管-肾盂梗阻时，通常将纤维带和异常血管归咎于梗阻的原因。

### 男性尿道
前列腺可能会发生癌变；然而，如果在早期发现，治疗这种疾病是有多种选择的。

盆腔的急性感染通常与肾脏感染（肾盂肾炎）相关。这种情况最常见于年轻女孩，会引起发热、背痛和排尿困难。盆腔肿瘤很少见；当它们出现时，通常是恶性程度不同的移行细胞癌。它们引起梗阻和血尿。

尿道容易发生梗阻。最常见的原因是前列腺的良性增生，这是一种非癌性生长。这种生长是与衰老相关的自然过程，可能会阻塞前列腺尿道，导致启动尿液流和完全排空膀胱进行困难增加。参见“`REPRODUCTIVE SYSTEM DISORDERS`”（生殖系统疾病）。[`B.R.F, M.L.S`]

### 输尿管
这些细长的管道将尿液从肾盂输送到膀胱；它们与肾盂易患相同的疾病。

输尿管在任意部位的重复现象都可以被发现，从双头起始到后来的融合，到完全分离和分别植入膀胱。除非产生梗阻，否则这种异常通常是良性的。

如果防止膀胱尿液回流到输尿管的正常类似阀门机制存在缺陷，就会导致膀胱-输尿管反流。当个体（通常是年轻女孩）排尿时，部分尿液回流到输尿管，导致膀胱不能完全排空。这种残余尿液容易受到细菌感染。

肿瘤通常是移行细胞癌，与肾盂和膀胱中看到的肿瘤没有显著差异。

# 尿液
有机和无机物质的水溶液，主要是代谢废物。肾脏通过排泄这些废物并调节水和电解质的丢失，使体液在数量和成分上保持相对稳定，从而维持身体的内部环境稳态。

引起腹部和腰部疼痛（常放射至腹股沟或睾丸）的最常见原因之一是，小结石甚至晶体群通过输尿管排出。偶尔，输尿管会被腹膜后纤维化、肿瘤或主动脉瘤的外部压力阻塞。

尿液通常是清澈的，比重为 1.017–1.020，具体取决于摄入的液体量、出汗和饮食。比重大于水的增量是由于溶解固体的存在，其中约 60% 是尿素、尿酸、肌酐和氨等有机物质；40% 是钠、氯化物、钙、钾、磷酸盐和硫酸盐等无机物质。

其反应通常呈酸性（pH 6），但这也会随饮食变化。它通常因尿色素而呈淡黄色，但颜色会根据浓缩程度以及某些食物（例如大黄）或泻药的摄入而变化。它通常具有特征性的芳香味，原因尚不清楚。参见“`KIDNEY`”（肾脏）；“`UREA`”（尿素）；“`URIC ACID`”（尿酸）；“`URINALYSIS`”（尿液分析）；“`URINARY SYSTEM`”（泌尿系统）。[`R.SS.`]

# 有尾目
两栖纲的一个目，也称为有尾目。该目的成员是有尾两栖动物，即蝾螈，它们通过拥有尾巴而与蛙类和蟾蜍（无尾目）在表面上区分开来，并通过拥有四肢而与蚓螈（无足目）区分开来。蝾螈在形态上类似蜥蜴，因为两个类群的成员通常都有相对拉长的身体、四肢和尾巴。然而，这种相似性仅是表面的。最明显的外部差异——两栖动物多腺体的皮肤与爬行动物干燥有鳞片的皮肤——背后是区分爬行动物和两栖动物的众多特征。参见“`ANURA`”（无尾目）。

### 膀胱
膀胱易患异常、梗阻、炎症、结石、瘘管和肿瘤。

一种相当常见且令人痛苦的异常是膀胱外翻，即下腹壁和膀胱前壁均未闭合。尿液直接通过腹壁缺损排出。

# 泌尿生殖系统
绝大多数蝾螈体长不足一英尺（0.3米）。其中最大的是日本和中国的大鲵，体长可达5英尺（1.5米）。其近亲美洲蝾螈（hellbender）生活在美国东部的溪流中，体长可达2英尺（0.6米）以上。

蝾螈通常具有四条发育良好的四肢，但美国东南部的泥蛇（`*Amphiuma*`）的腿部是极小的附属物，对运动没有作用。同一地区的泥鳅鱼（`*Siren*` 和 `*Proteus*`）、泥蛇以及水栖蝾螈的四肢退化程度更深，仅保留微小的前肢。四肢正常的蝾螈通常前脚有四个脚趾，后脚有五个脚趾，但也有少数种类四只脚均只有四个脚趾。尾螈目（Urodeli）的一个特征，是不同于无尾目（Anura）的，即它们具有再生四肢的能力。
