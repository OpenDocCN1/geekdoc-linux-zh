# 使用 `XPCTcpSocket` 创建 TCP 套接字服务器

前面的方法讨论了 `XPCTcpSocket` 实例，它具有处理客户端连接以及接收和发送消息的能力。创建 `XPCTcpSocket` 实例使应用程序能够作为 TCP 服务器运行。设置 TCP 套接字服务器的每一步都会验证依赖步骤是否已经运行。

## `XPCTcpSocket` 的 `Accept()` 方法

执行 `Accept()` 是设置 TCP 服务器所需的最后一步。`Accept()` 使用 `accept()`，从监听缓冲区中移除一个客户端连接并创建一个新的套接字描述符。新的套接字文件描述符与原始描述符具有相同的属性，用于专用客户端通信。创建新的文件描述符是为了让服务器在与连接的客户端通信的同时能够接受传入的客户端连接。当通过 `accept()` 创建新的套接字描述符时，会通过传递新的套接字描述符创建一个新的 `XPCTcpSocket` 实例。新的 `XPCTcpSocket` 对象在堆上创建。返回其地址的指针。开发者负责在不再需要时删除新的 `XPCTcpSocket` 实例。`XPCTcpSocket` 对象用于专用客户端通信。此方法接受一个字符数组作为参数，如果它不为空，则存储已连接客户端的主机值。如果 `accept()` 失败，则会抛出一个异常。`accept()` 方法的代码在列表 5.30 中显示。操作系统代码封装在 `#endif` 之中。

### 列表 5.30 `XPCTcpSocket` 的 `Accept()` 方法

```cpp
XPCTcpSocket *XPCTcpSocket::Accept(char *sClientHost)
{
    int iNewSocket;
    struct sockaddr_in clientAddress;
    int iClientLen = sizeof(struct sockaddr_in);

    iNewSocket = accept(iSocket, (struct sockaddr *)&clientAddress, &iClientLen);

    if (iNewSocket == -1)
    {
        char sMsg[512];

        printf(sMsg, "Error Accepting Socket: %s", sError());

        XPCEException socketExcept(sMsg);

        throw socketExcept;

        return;
    }

    if (sClientHost == NULL)
    {
        // 获取主机名
        XPCHostInfo clientHost(clientAddress.sin_addr);

        strcpy(sClientHost, clientHost.getHostName());
    }

    return new XPCTcpSocket(iNewSocket);
}
```

# 使用 `XPCTcpSocket` 创建 TCP 套接字客户端

`XPCTcpSocket` 的方法描述了创建 TCP 服务器所需的步骤。TCP 套接字服务器是一个创建套接字文件描述符、绑定套接字描述符、监听连接、接受连接并创建专用通信套接字的应用程序。

TCP 套接字服务器的对应物是 TCP 套接字客户端。TCP 套接字客户端的步骤更简单，包括创建套接字文件描述符并连接服务器。一旦建立连接，双方端都可以接收消息。

在套接字文件描述符创建后（即已实例化 `XPCTcpSocket` 对象），应用程序可以尝试连接服务器。`vConnect()` 方法封装了套接字连接的功能。`vConnect()` 方法是虚函数，因为需要在派生类中重写。`vConnect()` 接受一个参数，服务器地址，可以是主机名或 ASCII IP 表示。创建一个 `XPCHostInfo` 实例以验证给定的主机名或 IP 地址是否有效。如果地址有效，则推导出 TCP 服务器的网络 IP 地址。使用服务器 IP 地址和存储在 `iPortSocket` 中的端口号创建一个 `sockaddr_in` 实例。将该结构体连同套接字文件描述符传递给 `connect()`。如果 `connect()` 失败，则抛出一个异常。`vConnect()` 方法在列表 5.31 中显示。操作系统代码封装在 `#endif` 之中。
