# 第二章. Linux 下 Windows 程序的的主要替代品

## II.3 应用软件

这些程序主要用于普通用户。它们解决特定类别的任务。这些是直接满足用户信息需求的软件。可以说，这些程序是为特定的应用程序或任务开发的，并供最终用户使用。它们与管理计算机或其他设备并确保计算机执行基础操作的系统软件不同。

应用软件示例包括：

- 文本编辑器；
- 电子表格；
- 图像处理程序；
- 视频处理程序；
- 浏览器；
- 图像处理程序；
- 游戏程序；
- 内容管理系统；
- 数据库操作程序；
- 业务流程自动化程序等。
