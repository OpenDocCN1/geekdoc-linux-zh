
# 术语表

### 基于队列的打印
起源于 NetWare 3 的一种打印系统，旨在支持简单打印机和基于 DOS 的应用程序。

### 读取属性权限
一种 eDirectory 安全权限，包含比较权限，允许受托人查看存储在对象属性字段中的值。

### 只读 (Ro)
一种文件属性，防止文件内容被修改。

### 读取 (R) 权限
一种访问权限，允许用户读取目录中的文件或运行程序。

### 读取/写入 (Rw)
一种默认文件属性，允许更改文件的内容。

### RedHat 包管理器 (RPM)
由 `rpm` 命令用于安装和管理软件的软件安装文件格式。

### 参考时间服务器
类似于单一参考时间服务器，但用于大型网络环境，并参与包含主时间服务器的时间提供者组。

### 常规驱动器指针
分配到每个卷上数据目录的驱动器指针。

### 相对可分辨名称
一个无歧义的名称，以客户端的当前上下文开头，但省略了前导点。

### 远程打印机
连接到另一台客户机计算机的打印机。

### 远程打印机管理 (RPM)
Novell 的系统，使用 Web 浏览器管理网络打印机。

### 远程附加打印机
附加到联网计算机端口并由打印服务器控制的打印机。

### 重命名条目权限
一种 eDirectory 安全权限，授予更改对象名称的权限。

### 重命名禁止 (Ri)
一种文件或目录属性，防止更改文件或目录的名称。

### 副本
存储在 NetWare 服务器上的 eDirectory 数据库的副本。

### 基于角色的服务 (RBS)
用于在 iManager 中分配用户执行任务所需权限的 NetWare 服务。

### 基于角色的服务 (RBS) 容器对象
用于存储 iManager 管理角色的 eDirectory 容器对象。

### 根驱动器指针
表现得像卷根一样的常规驱动器指针。

### 根对象
表示网络 eDirectory 服务树起点的 eDirectory 对象。

### 根分区
eDirectory 树在树根处开始的初始划分。在 Linux 中，它是文件系统的开始，存储所有其他 Linux 操作系统文件和文件夹的地方。

### [Root] 受托人对象
代表 eDirectory 树中定义的所有用户的特殊受托人对象。已登录到 eDirectory 树的所有用户都是 [Root] 受托人对象的一部分。

### Samba
一种允许 Windows 客户端通过使用 `CIFS` 协议访问 Linux 服务器上数据的服务。

### 可扩展性
处理不同规模系统的能力。

### 搜索驱动器指针
通过 DOS 路径引用可执行文件和应用程序目录的驱动器指针。

### 辅助时间服务器
从中央时间源获取时间，然后将其分配给网络客户端的时间服务器。

### 安全容器对象
用于存储安全对象（如服务器证书）的 eDirectory 容器对象。

### 安全等价性
一种安全分配，授予对象与另一对象相等的权限。

### 串行端口 (COMn)
通常用于通过长电缆发送信号，以连接通信设备（如调制解调器和打印机）的打印机端口。串行端口一次只发送一位数据，因此串行电缆可以仅由几根线组成。

### 服务器
提供一个或多个网络服务的计算机。

### 服务器集群
一种配置，其中两台或多台服务器可以共享一个公共磁盘系统，以便在一台服务器发生硬件故障时数据仍然可用。

### 服务器配置阶段
NetWare 6.5 安装阶段，在此期间指定服务器名称，安装 eDirectory，并提供网络设置。

### 服务器消息块 (SMB)
客户端用于访问网络服务的专有 Microsoft 协议。

### 以服务器为中心
用户必须登录到中央服务器才能访问网络服务的网络系统。

### 影子化
在多个位置分配和同步 DIB 的过程。

### 可共享 (sh)
一种文件属性，允许多个用户同时使用文件。

### 共享目录
可供多个用户存储和检索数据文件的目录。

### 外壳
用于输入命令和启动程序的 Linux 命令行环境。

### 单一参考时间服务器
在 Novell 默认时间服务器配置中，它是安装在 eDirectory 树中的第一台服务器，并将时间分配给辅助时间服务器和客户端。

### 欺骗
一种通过创建看似来自授权实体的伪造数据包来非法访问网络资源或攻击网络服务的方法。

### 存储位置对象
用于存储将通过 NetStorage 可用的目录路径的 eDirectory 对象。

### 存储池
NSS 文件系统组件，用于将一个或多个分区分组为一个存储区域，该区域可划分为一个或多个卷。

### 子分配
传统卷的一项功能，将块划分为更小的 512 字节增量，使多个文件可以共享同一块，从而节省磁盘空间。

### 监督者属性权限
一种 eDirectory 安全权限，授予对属性的所有权限，除非被对象的 IRF 阻止。

### 监督者条目权限
一种 eDirectory 安全权限，授予所有访问权限，包括对对象所有属性或特性的监督者权限。

### 监督者 [S] 权限
一种访问权限，授予目录及其子目录的所有权限；此权限不能被阻止或重新分配给较低目录或文件级别。

### 交换分区
用于将程序段调入和调出内存的 Linux 分区。为了获得最佳性能，Linux 交换分区的大小至少应为系统 RAM 的两倍。

### 交换机
参见集线器。

### 语法
编写登录脚本命令时必须遵循的规则。

### 系统目录
NetWare 创建的必需操作系统目录，包含仅服务器和 Admin 用户可用（其他用户不可用）的系统软件和命令。

### 系统组
Linux 操作系统创建的组账户，用于授予访问特定系统资源的权限。

### 系统 (Sy)
标记文件或目录供操作系统使用的文件或目录属性。

### 线程
Web 服务器进程，允许多个 CPU 同时处理 Web 应用以提高性能。

### 时间限制
一种安全限制，允许用户仅在指定时间内登录到网络。

### 时间变量
包含系统时间信息（如小时、分钟、上午或下午）的登录脚本变量。

### 传统卷
使用旧版 NetWare 文件系统架构的传统 NetWare 分区划分。传统卷可用于存储用户和应用程序数据，以向后兼容以前版本的 NetWare。

### 事务跟踪系统 (TTS)
保护事务性属性的系统，确保所有事务要么完成，要么保持原始状态。

### 事务性 (T)
用于数据库文件的文件属性，如果事务未完成，系统可以将文件恢复到其先前状态。

### 传输控制协议/互联网协议 (TCP/IP)
通常用于在计算机之间格式化和路由数据包的协议；也用于互联网。

### 受信任网络
IP 地址范围已知安全或可由您的组织控制和监控的网络。

### 受托人分配
文件或目录的 ACL 中的一项条目，使用户成为目录或文件的受托人。

### 带类型
包含对象类型缩写（O、OU 和 CN）的可分辨名称。

### 不带类型
根据位置假设对象类型的可分辨名称，而不是包含对象类型缩写。

### 不间断电源 (UPS)
一种备用电源系统，在电力中断期间使用电池向计算机提供持续电力。

### 未知网络
未在防火墙中指定为受信任或不受信任网络的 IP 地址范围。防火墙将未知网络视为不受信任网络。

### 不受信任网络
可能包含攻击者或其他恶意实体的 IP 地址范围。来自列为不受信任网络的分组由网络防火墙检查。

### 用户登录脚本
针对单个用户的个性化登录脚本命令，存储在用户的 eDirectory 账户的登录脚本属性中。用户登录脚本在任何容器或配置文件脚本命令完成后运行。

### 用户模板
一种用于定义标准设置并配置容器中每个用户限制属性的属性。

### 用户变量
允许用户为其自己的登录脚本输入参数的登录脚本变量。

### 虚拟文件系统切换 (VFS)
一种操作系统接口系统，将进程的用户请求发送到实际的磁盘文件系统。

### 虚拟办公室
一种 Novell 系统，允许用户在虚拟团队中工作，并通过 Web 浏览器界面进行通信和访问数据。

### 虚拟专用网络 (VPN)
一种可信网络，通过不可信网络（如互联网）发送数据包。

### 虚拟团队
一组共享通用文件和日程安排的虚拟办公室用户。

### 病毒
自我复制的程序，可嵌入软件中以在计算机之间传播，最终可被触发以影响计算机性能或破坏数据。

### 卷位置数据库 (VLDB)
一种 DFS 设置，用于标识包含存储 DFS 连接点中使用的路径的数据库的服务器和卷。

### 卷对象
一种用于表示 eDirectory 树中物理 NetWare 卷的 eDirectory 对象；提供了 eDirectory 系统与文件系统之间的链接。
