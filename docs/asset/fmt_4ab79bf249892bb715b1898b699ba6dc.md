## 第 24 章

本章使用的技术涉及“反色视频”（reverse video），正如我们在第 15 章创建 grep shell 脚本时看到的那样。这一次，我们将使用 `tput` 命令选项在菜单界面中使用反色视频。

### 反色视频语法

首先，我们想为菜单在屏幕顶部提供一个反色视频标题栏。为了释放内存，开启反色视频时我们使用 `tput smso`，而关闭高亮时使用 `tput rmso`。对于这个标题栏，我们将在标题中使用系统的主机名。脚本启动后，我们将留在菜单中，直到输入 99（退出）作为菜单选择。我们还希望突出菜单选项，选项标签除外。标题栏是先显示的。

```bash
clear # 首先清理屏幕

tput smso # 开启反色视频

echo $(hostname)\c* # 33 个空格

echo " " # 39 个空格

tput rmso # 关闭反色视频
```

在前面的代码中，我们首先使用 `clear` 命令为菜单清理屏幕。第二行将使用 `tput smso` 命令开启反色视频。一个执行 Unix 命令 `hostname` 的替换语句随后执行。在两个 `echo` 语句中，空格被高亮了，这导致屏幕顶部出现一条条，中间是系统主机名，并以反色视频显示。注意，在主机名之前有 33 个空格，主机名之后还有 39 个空格。这允许标题栏中间的主机名最多包含 8 个字符。你可以根据需要调整这些间距。

### 创建用于反馈的消息栏

我们菜单中的另一个好功能是消息栏。它可以用于显示无效选择的消息，并可禁用某个消息选项。为了实现这一点，我们希望设置假设为无效选择，如果有有效输入，我们将其清空消息变量。如果我们需要禁用菜单中的某个选项，可以注释掉想要禁用的命令，并在消息变量中放入一个禁用选项的注释。列表 24.2 所示的接几行代码用于显示消息栏。

```bash
# 在屏幕底部绘制一条反色消息栏，
# 如果有消息，则显示错误消息。

tput smso # 开启反色视频

echo "$(MSG)\c" # 30 个空格

echo " " # 26 个空格

tput rmso # 关闭反色视频

# 提示菜单选项。

echo "Selection: \c"

read OPTION

# 假设选择是无效的。因为总是显示消息，

MSG="已选择无效选项.*" # 24 个空格
```
