# 理解 MySQL 表

在设置 MySQL 表时，你有很大的灵活性。为了让你的 MySQL 数据库尽可能高效运行，你希望为列分配最合适的大小和数据类型，以存储你需要存储的数据。

使用下表作为分配给列的不同数据类型的参考。MySQL 中可用的数据类型分为以下几类：数字、时间和字符串。关于在这些表中使用，有以下几点需要了解：

- 数据类型的最大大小为 255。
- 数据类型范围是 22 到 25 字节。
- D 选项表示列的位数。
- 填充（ZEROFILL）选项会在列中填充零。
- 整数类型范围是 22 字节。
- M 选项表示列的位数。
- 填充（ZEROFILL）选项会在列中填充零。
- 括号中的 (M) 是可选。
