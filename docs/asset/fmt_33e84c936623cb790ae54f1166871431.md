
# Linux 词典

## Xinetetd
`Xinetetd` 根据远程主机的地址和/或访问权限为所有服务提供访问控制并可以防止攻击。`Xinetetd` 提供了详细的日志记录，服务器参数数量没有限制，你可以将特定服务绑定到本地主机上的 IP 地址。每个 `Xinetetd` 都有自己特定的配置文件，位于 `/etc/xinetetd/` 目录下。来自 Redhat 8.0 RPM http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## xinit
`X Window` 系统初始化器。来自 Whatatis
http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## xinitric
`xinit` 包包含 `xinit` 文件，这是一个用于配置你的 `X` 系统会话或启动窗口管理器脚本。来自 Mandrake 9.0 RPM
http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## XInput
`XInput` 设备的运行时配置和测试。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## XInput 扩展
一个标准的 `X` 扩展。该扩展的目标是允许 `X Window` 系统进行额外的输入设备管理。来自 Linux Guide @FirstLinux http://www.tld.org/LDP/Linux-Dictionary/index.html

## XINU
`XINUS Is Not Us` (操作系统) 来自 VERA http://www.tld.org/LDP/Linux-Dictionary/index.html

## Xinv3d
`XInvaders 3D` 3D 空间是一个基于 3D 向量的 `X Window` 系统太空入侵者克隆。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## XIOS
扩展输入/输出系统（Novell, Never）来自 VERA http://www.tld.org/LDP/Linux-Dictionary/index.html

## xipmsg
弹出式通信软件 `IP Messenger` 是一种多平台的弹出式通信软件。它基于 `TCP/IP(UDP)`。`Xipmsg` 是 `IP Messenger` 的 XI1 版本。它可以与 Windows/MacOS 的 `IP Messenger` 通信。来自 Debian 3.0r0 http://www.tld.org/LDP/Linux-Dictionary/index.html

## xisnodload
`xisnodload` 定期显示 `ISDN` 网络上的平均直方图。来自 Redhat 8.0 RPM http://www.tld.org/LDP/Linux-Dictionary/index.html

## xtalk
用于终端 `talk` 的拦截器工具。如果你在你的 `xterms` 中禁用了消息，`xtalk` 将接收所有请求/写入。它可以启动会话，播放声音。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xtermthai
`xthai` 是一个支持泰语的 `x-terminal` 模拟器。它内置了泰语输入。需要泰语字体来显示泰语字符。来自 Debian 3.0r0 http://www.tld.org/LDP/Linux-Dictionary/index.html

## xjed
面向程序员的编辑器（`x11` 版本）。从 `JED` 缓冲区读取完全可自定义的信息。多种编程语言包括 `Pascal`, `C++`, `FORTRAN`, `SH`, `IDL`, `DC`, `NROFF`, `PostScript`。支持 `BibTeX`。矩形剪；正则表达式；搜索多个文件；`shell` 模式；目录编辑器；邮件；等。注意：运行时程序现在位于 `commando`。这些文件在 `jed` 中。在这个版本中，删除字符而不是加载。帮助现在在 `Esc`。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xjwel
一个像俄罗斯块类的掉落游戏，当直线上有三个或更多相同的块时，它们从板上移除。当移除块时可以实现有趣的级联效果，导致另一组块。来自 Debian 3.0r0 http://www.tld.org/LDP/Linux-Dictionary/index.html

## xjig
一个拼图游戏，尽可能在屏幕上放置拼图。任何 `GIF` 图像都可以加载并放入碎片。目标是（带有任何拼图）重新组合原始图片。可以使用鼠标自由旋转瓷砖（用于双面拼图），甚至在桌面上显示形状（快速机器/视频）。示例在 `/usr/lib/games/xjig` 中。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## xjokes
`X11` 连接了 4 个键：`yasit`, `blackhole`, `mor1` 和 `mor2`。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xjove
`jove` 的 `X11` 前端——一个紧凑、强大的编辑器。这是 `jove` 的 `X11` 前端。`Jove` 是一种紧凑、强大的类 `Emacs` 文本编辑器。它提供了常用的键盘绑定，以及一组最受欢迎的功能（例如交互模式）窗口、完成、语言切换，同时权衡 `CPU`、`内存` 和磁盘需求 `vi(1)`。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xjump
用于 `X` 的跳跃游戏。`X` 的跳跃游戏。玩这个游戏非常简单，很好。你做的只是跳跃并向上跳。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xkbcomp
编译 `XKB` 键盘描述。来自 What http://www.tld.org/LDP/Linux-Dictionary/index.html

## xkbdev
`XKB` 事件守护进程。来自 What http://www.tld.org/LDP/Linux-Dictionary/index.html

## xkbprint
打印 `XKB` 键盘描述。来自 What http://www.tld.org/LDP/Linux-Dictionary/index.html

## xkbsel
用于选择、定义和指示 `XKB` 键盘映射的工具，无需以任何方式修改 `X11`。此包包含了 `xkb` 基础功能和二进制文件，雅典键盘切换苹果。主页：http://penguin.cz/~stans/sk/xkbsel。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xkbelsgnome
用于选择、定义和指示 `XKB` 键盘映射的工具。`xkbsel` 是定义、选择和指示 `XKB` 键盘映射的框架，无需以任何方式修改 `X11`。此包包含了 `Gnome` 键盘切换苹果。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/index.html

## xkeycaps
操作键映射（用于 `xmodmap`）。`xkeycaps` 是 `xmodmap(1)` 的图形化工具。它打开一个看起来像键盘的窗口；鼠标移动过键会显示该键生成的 `KeySym` 和修饰位。点击键模拟 `KeyPress/KeyRelease`，可以通过基于鼠标的界面更改 `KeySym` 和修饰符。此程序还可以为 `xmodmap` 写入输入文件，以便在未来的会话中重建你的更改。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## xkeysym
用于 `X Window` 的键盘布局。它的主要功能是：
- 窗口切换。你可以在不同的窗口中使用不同的布局。
- 无限制的布局。
- 灵活切换。布局可以有用于切换到其他布局的“热键”。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
