# RDBMS 概念

1. 什么是数据库？

- 数据库是相关信息或数据的集合，是为了某些特定目的而设计、构建和运行的。

2. 什么是 RDBMS？

- `RDBMS` 是一组程序，允许用户在关系型数据库中创建、更新和维护数据。

3. 什么是键？

- 键是用于标识表中某条记录的属性。
- 主键
- 外键
- 唯一键
- 复合键
- 候选键

4. 什么是约束？

- 约束是应用到表列的规则，以确保数据的准确性和可靠性。
- 实体完整性约束
- 引用完整性约束
- 域约束
- 检查约束

5. 什么是数据类型？

- 数据类型定义了列中可以存储的值类型。
- 整数
- 字符
- 可变
- 日期
- 布尔
