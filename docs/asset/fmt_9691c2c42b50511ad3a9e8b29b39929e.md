
# 动态空间定向游戏系统 XShipWars

动态空间定向游戏系统 `XShipWars` 是一种专为网络设计的、高度可定制且动态的空间定向游戏系统。你可以创建自己的宇宙，并使用大量的自定义设置构建你的船只。`XShipWars` 的图形/视频/声音由许多才华横溢专业艺术家创作。更多信息可以在 `XShipWars` 网站 `http://www.wolfpack.com/net/XShipWars/` 找到；源自 `Debian 3.0r0 APT`

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## xsiag

一个带有 X11 用户界面的电子表格。`Siag Office` 的表格部分，它还包含 `EGON` 和 `PW`。`Siag` 使用 `Office DNN` 拖放协议。`Siag` 是一个基于 X 和 scheme 的电子表格。基于某些 scheme，它允许你以能够想象的任何方式确保 `siag` 的功能。它可以读取和写入 `1–2–3` 文件，以便与其他著名的电子表格进行互操作。你可以在几种语言中输入表达式：`C`, `guile`, `SDL`, `TCL`。需要一个 `WWW` 浏览器来读取在线文档。`postscript` 查看器用于文档预览。它使用了基于 Athena 工具包的 X11 用户界面。你将在 `siag` 包中找到相关文本。源自 `Debian 3.0r0 APT`

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## xidplay

用于 C64 和 Amiga 的播放器。这是一个为 C64 和 Amiga 曲目设计的非常复杂的播放器。模拟参数和控制子曲非常简单。`README` 包含了如何下载和如何安装此数据库文件的说明。有一个相当“隐藏”的专家模式，可以启用内置的示波器。请查看 `README.Debian` 和 `README` 获取更多信息（以及可能的问题）。源自 `Debian 3.0r0 APT`

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## xsitecopy

一个用于 `FTP` 或 `HTTP(GNOME)` 管理网站的程序。其目标是将网站复制到本地。通过单个命令，即可将网站复制到本地。`xsitecopy` 可以同步文件到远程服务器。它保留了原始功能，并增加了网络操作的便利性。源自 `Debian 3.0r APT`

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
