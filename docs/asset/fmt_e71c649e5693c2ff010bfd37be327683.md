
在启动 Pure-FTPd 后，使用随后的指令进行测试是一个明智的主意。

```bash
ftp {IP_Address}
```

当提示时输入客户端名 `sam` 和秘密短语。如果确认成功，则 FTP 服务器正在正常工作。如果执行无效，请重启电脑并再次尝试连接到服务器。

为了完成使 Pure-FTPd 可实用的关键步骤，参考了来自 `http://samiux.blogspot.com/2011/08/howto-unadulterated-ftppd-and-fatpd-on-backtrack.html` 的指南。

## SSH 服务器

安全外壳 `SSH` 是一种从远程访问 Kali Linux 文件系统内容日益安全的技术。`SSH` 在传输计算机之间提供了一个受保护的加密的交换通道。

这对于渗透分析师非常有用，因为它允许文件移动发生而不会被入侵检测系统 `IDS` 和入侵防御系统 `IPS` 等网络安全设备监测。

## 生成 SSH 密钥

为了安全地使用 SSH，必须生成加密密钥以促进安全加密的通信。要生成这些密钥，在命令行中输入以下内容。

将第一个 SSH 密钥从其默认索引移动；不要删除它们。

```bash
mkdir -p /etc/ssh/original_keys
mv /etc/ssh/ssh_host_*/* /etc/ssh/original_keys
cd /etc/ssh
```

创建新的 SSH 密钥。

```bash
dpkg-reconfigure openssh-server
```

启动/重启 SSH 守护进程。

```bash
service ssh (start restart)
```

## 通过 Kali GUI 处理 SSH 服务

SSH 服务器集成在 Kali GUI 的主文件结构中，获取方式与启动或停止 Apache 服务器类似。要访问 SSH 菜单，从 Kali 屏幕顶部栏选择“应用程序”`Applications`。在显示的下拉菜单中选择 Kali Linux。然后在下一个菜单中，从弹出菜单中选择 SSH Server 55 上的 SSH 选择。这将显示启动、停止和重启 SSH 管理的选项。

## 从命令行处理 SSH 服务器

SSH 服务器也可以从这里启动、停止和重启。按照以下说明在执行命令 `/etc/init.d/ssh` 后操作。

```bash
/etc/init.d/ssh start
/etc/init.d/ssh stop
/etc/init.d/ssh restart
```

## 访问远程系统

当 Kali 框架上启动 SSH 管理时，可以通过在命令行输入以下命令从 Linux 框架远程访问电脑（客户端名为 `sam`，远程框架 IP 地址为 `192.168.1.66`）。

```bash
ssh sam@192.168.1.66
```

Windows 用户访问 SSH 将需要使用 SSH 客户端。

许多此类工具可以在互联网上找到；例如 `putty` 是一个可以从 `http://putty.org` 获取的常用工具。引入客户端并提供 Kali Linux 电脑的 IP 地址或名称作为凭证，并与远程 Kali 电脑交互。

## 设计与访问外部媒体

在 Kali Linux 中，访问硬盘或优 盘等外部媒体比在之前的 Backtrack 版本中要简单得多。通常，与框架使用通用串行 `USB` 接口相关的媒体将被工作框架识别并可访问。然而，如果没有发生这种情况，则可能需要物理挂载驱动器。

## 物理挂载驱动器

物理挂载驱动器到 Kali Linux 时必须执行的第一件事是将物理驱动器连接到电脑。接下来打开命令行并创建一个挂载点。应该为所使用的文件提升挂载点的权限；如果不是使用 root 账户，这可以通过 `sudo` 命令实现。以下命令将在媒体索引中创建一个名为 `newdrive` 的挂载点。

使用 `fdisk` 命令确定你正在连接的驱动器和分区，细节取决于你正在添加的驱动器。主硬盘通常是 `hda`，该驱动器上的主分区将是 `hda1`。此安排适用于与电脑相关的额外的驱动器，第二个是 `hdb`，第三个是 `hdc`。通常，主内部驱动器标记为 `hda`，因此主外部驱动器将命名为 `hdb`。要将 `hdb` 的主分区挂载到上一步创建的 `newdrive` 索引，请使用以下命令。

```bash
mount /dev/hdb1 /media/newdrive
```

完成后，通过浏览 `newdrive` 索引即可访问驱动器内容。

```bash
cd /media/newdrive
```
