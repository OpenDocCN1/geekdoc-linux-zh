如你所见，`ftp` 只有几个命令。然而，你实际上只需要查看你最频繁使用的那些。

### 启动 FTP 会话
`open` 命令用于与远程主机打开 FTP 会话。其语法为

```
open hostname
```

通常只有当你打算在 FTP 会话期间连接到多个一个站点时，才需要使用此命令。如果你只想在会话期间连接到一台计算机，只需在命令行中将远程主机名作为 `ftp` 命令的参数指定即可。

### 结束 FTP 会话
`close`、`disconnect`、`quit` 和 `bye` 命令用于结束与远程计算机的 FTP 会话。相同的 `close` 和 `disconnect` 命令会保留你与远程计算机的连接，但让你留留在本地计算机的 `ftp` 程序中。`quit` 和 `bye` 命令也类似。

### 更改目录
`cd` 和 `cdup` 命令用于更改目录。`lcd` 命令更改本地目录。

### 远程列出
`ls` 命令列出远程目录的内容。`dir` 命令也列出内容，但提供了更多细节。

### 从远程服务器获取文件
`get` 命令用于从远程计算机检索文件。`mget` 命令检索多个文件。

### 更改文件传输模式
`ftp` 会以 ASCII 文件传输文件，除非你指定其他模式。这对于纯文本没有问题，但对任何二进制数据都是毫无用处的。`ascii` 和 `binary` 命令设置传输模式，以防止二进制文件损坏。

### 检查传输状态
在传输大文件时，你可能希望获得传输进度的反馈。`hash` 命令导致 `ftp` 在每次完成数据缓冲区传输时在屏幕上打印 `#` 字符。

### FTP 中的本地命令
`char` 用于在进入 `ftp` 时向本地计算机的命令 shell 传递命令。当你需要在 FTP 会话期间执行某些操作时，这非常有用。假设你需要创建一个目录存放接收的文件。如果你输入 `mkdir new_dir`，Linux 会在当前本地目录下创建一个名为 `new_dir` 的目录。
