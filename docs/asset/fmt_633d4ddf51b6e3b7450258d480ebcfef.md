
Foo 的类型将与 `object` 类型。

如果没有指定基类，`class` 语句会检查名为 `_metaclass__` 的全局变量是否存在。如果找到该变量，将用它来创建类。如果你设置了这个变量，它将控制使用简单 `class` 语句时类的创建方式。示例：

```python
_metaclass__ = type

class Foo:
    pass
```

最后，如果找不到 `_metaclass__` 值，Python 将使用默认元类。在 Python 2 中，默认是 `type.Class`，它作为旧式类被弃用（自 Python 2.2 起被弃用，对应于 Python 中类的原始实现）。尽管这些类仍然被支持，在新代码中应避免使用，且本文不再涉及。在 Python 3 中，默认仅为 `type`。

元类的主要用途是在需要对用户定义对象的定义进行更多断言的框架中。使用元类时，它继承自 `type()` 并重新实现方法如 `__init__()` 或 `__new__()`。这是一个强制所有方法都具有文档字符串的元类示例：

```python
class DocMeta(type):
    def __init__(self, name, bases, dict):
        for key, value in dict.items():
            # 跳过特殊和私有方法
            if key.startswith("_"): continue
            # 跳过任何不可调用的
            if not hasattr(value, "__call__"): continue
            # 检查是否存在文档字符串
            if not getattr(value, "__doc__"):
                raise TypeError("%s must have a docstring" % key)
        super().__init__(name, bases, dict)
```

在这个示例中，`__init__()` 方法被编写为检查类字典的内容。它扫描字典中的方法并检查它们是否具有文档字符串。如果没有，则生成一个 `TypeError`。否则，将调用 `__init__()` 的默认实现来初始化类。

要使用此元类，类需要显式选择它。最常用的技术是按如下方式定义基类：

```python
class Documented:
    # 在 Python 3 中，使用以下语法
    _metaclass__ = DocMeta (metaclass=DocMeta)
```

## 模块、包与发行

大型 Python 程序被组织成模块和包。此外，Python 标准库中包含了大量的模块。本章将详细描述模块和包系统。此外，它还提供了有关如何安装第三方模块和发布源代码的信息。

### 模块与 import 语句

任何 Python 源文件都可以作为模块。例如，考虑以下内容：

```python
# spam.py
a = 37

def foo():
    print("Im foo and a is %s" % a)

def bar():
    print("Im bar and I am calling foo")

fooo()

class Spam(Object):
    def grok(self):
        print("Im Spam.grok")
```

要将此代码作为模块使用，请使用 `import spam` 语句。第一次使用它加载模块时，它会执行三件事：

- 1. 它创建一个新的命名空间，作为相应源文件中定义的所有对象的容器。当模块内定义的函数和方法使用 `global` 语句时，访问的就是这个命名空间。
- 2. 它在新创建的空间内执行模块中包含的代码。
- 3. 它在模块内创建一个指向模块名的名称。该名称与模块匹配，并如下所示使用：

```python
import spam           # 加载并执行模块 'spam'
x = spam.a               # 访问模块 'spam' 的成员
spam.foo()             # 调用模块 'spam' 中的函数
s = spam.Spam()          # 创建 spam.Spam() 的实例
s.grok()
```

## 第 8 章 模块、包与发行

需要强调的是，`import` 会执行加载的源文件中的所有语句。如果模块在定义变量、函数和类之外还执行了计算或产生了输出，你将看到其结果。此外，关于模块的一个混淆涉及对类的访问。请记住，如果文件 `spam.py` 定义了一个类 `Spam`，你必须使用名称 `spam.Spam` 来引用该类。

要导入多个模块，可以为 `import` 提供一个逗号分隔的模块名称列表，如下：

```python
import socket, os, re
```

可以使用 `as` 标识符更改用于引用模块的名称。这里有一个示例：

```python
import spam as sp
import socket as net
sp.foo()
sp.bar()
net.gethostname()
```

当使用此类不同的名称加载模块时，新名称仅适用于 `import` 语句出现的源文件或上下文。其他模块仍然可以使用其原始名称加载该模块。

更改已导入模块的名称可以作为编写可扩展代码的有用工具。例如，假设你有两个模块 `xmlreader.py` 和 `csvreader.py`，它们都定义了一个从文件中读取数据的函数 `read_data(filename)`，但格式不同。你可以编写代码选择性地选取读取器：

```python
if format == 'xml':
    import xmlreader as reader
elif format == 'csv':
    import csvreader as reader
data = reader.read_data(filename)
```

模块是 Python 中的一等对象。这意味着它们可以赋值给变量，放在列表等数据结构中，并作为实例在程序中传递。上一个示例中的变量 `reader` 指向对应的模块对象。在底层，模块对象是字典的一层封装，用于存储模块命名空间的内容。该字典可以通过模块的 `__dict__` 访问，每当你查找或更改模块中的值时，你都是在操作这个字典。

`import` 语句可以出现在程序的任何位置。无论你多少使用 `import` 语句，每个模块都只会被加载和执行一次。后续的 `import` 语句会将模块名绑定到之前的导入已创建的模块对象。你可以在变量 `sys.modules` 中找到包含所有当前加载模块的字典。该字典将模块名称映射到模块对象。该字典的内容用于判断导入是否加载了模块的新副本。

### 从模块中导入指定的符号

`from` 语句用于将模块中的特定定义加载到当前命名空间。`from` 语句与 `import` 相同，不同在于它不是创建一个指向新创建的模块命名空间的名称，而是将模块中定义的一个或多个对象的引用放入当前命名空间：

```python
from spam import foo    # 导入 spam并将 'foo' 放入当前命名空间
foo()                   # 调用 spam.foo()
spam.foo()               # NameError: spam
```

`from` 语句也接受逗号分隔的对象名称列表。例如：

```python
from spam import foo, bar
```
