如果你的电脑可以光驱器启动（大多数电脑都是如此），你就不需要启动盘来安装 Linux。查看你的 `BIOS` 设置，你可以自行设置启动选项。我的电脑在 `BIOS` 中将光驱器指定为第一个启动设备，但仍然无法从光驱启动。因此，`BIOS` 设置并不意味着你只需将 `RedHat CD` 插入光驱器并重启电脑就能进入 `RedHat Linux` 安装程序。

如果你不知道如何访问 `BIOS` 设置，请阅读此段。通常可以在启动时通过在正确的时刻按下某个键（通常是在短暂显示字母 `a` 时）进入 `BIOS` 设置。通常键是 `<Del>` 键。以下是常用 `BIOS` 使用的按键组合列表：

- 锐尔笔记本：在开机自检 (`POST`) 期间按下 `<F2>`。

- `Award`：`<Del>` 或 `<Ctrl><Alt><Esc>`。
- 康睿 (`Compaq`)：启动过程中屏幕右上角出现方框后按下 `<F10>`。
- 戴尔 (`Dell`)：`<Ctrl><Alt><Enter>`。
