
事实上 `C14` 在大气中已经产生，特别是在对地质学和海洋学做出贡献之后。20世纪50年代，核武器测试增加了大气中 `C14` 的含量。`C14` 是由于宇宙射线轰击大气层产生的。由于 `C14` 在短于其半衰期的时间尺度上在全球范围内分布在各种大气、生物和水文库中。海洋中的代谢过程随后在表层海水中迅速混合，使海洋中的 `C14` 保持在约恒定的水平。地质同时代“弹头”时中的天然 `C14` 是每克碳分钟15次衰变。碳核酸：：同位素。

由于 `¹⁴C` 已经长期没有发生显著变化而产生平衡或稳态，在现代材料中观察到的 `¹⁴C` 可能具有与相应碳相似的特征。一旦样本从与其交换的库中移除（在生物死亡时），`¹⁴C` 的量将随其寿命而减少。样本中残余 `¹⁴C` 与取样过量年龄标准的比较测定由方程给出：

$$A = A_0 e^{-\lambda t}$$

每年的放射性活度，其中 $\lambda$ 与半衰期 ($T_{1/2}$) 的关系为 $\lambda = \ln 2 / T_{1/2}$，$A$ 是现代标准的活度，$A_0$ 是未知年龄标准的活度。放射性碳碳年代使用此公式计算，采用国际公认的5560年半衰期和 ±3% 标准。

天然发生的同位素按比例约为 98.9% 的 `¹²C`、`¹³C` 和 `¹⁴C` 出现。自然材料中极量的放射性约为每万分之一，它主要在大气中产生并在进入生命周期之前。如果要求宇宙射线产生的 `¹⁴C` 保持足够长的时间，以在大气或通过各种库中建立 `¹⁴C` 的稳定状态，则自然测量可以提供样本年龄含量的估计。样本中的碳同位素除了放射性衰变外没有丢失，样本中的总碳量没有被改变。由于 `¹⁴C` 在地质同时代“弹头”中的天然放射性，必须测定其年龄和精确度。[1]

# 放射性实验室

用于研究和处理放射性化学品的实验室取决于处理的放射性发射类型、数量、半衰期和物理形式（液体、气体或固体）。必须采取措施密封放射性废物。工作表面应该是平滑且易于清洗的，以便在需要时去污。通风、辐射监测和防护至关重要。参见通风。

涉及少量（微居）γ 射线发射且通过便携仪器难以检测的调查可以在实验台上进行。在这种情况下，使用吸收纸、防护手套和实验服等措施可能是足够的。如果放射性废物是具有高生物毒性的发射发射粒子，必须在通风橱内处理以确保密封并在需要时产生警报。对于发射 β 射子的同位素工作，使用长柄或其他工具处理较高水平的放射性。参见 α 粒子；β 粒子；辐射；辐射；辐射屏蔽。放射性需要发射粒子的厚壁封闭装置。某些情况需要小型封闭装置，而其他则需要热室。热室配备了带有高密度铅玻璃的远程手套。

放射性是一个涵盖放射性同位素方面的学科。它有精确的定义并与原子核有关。同位素在化学中的应用基于放射性物质发射的性质。第一个性质是活度与样本中放射性原子的数量成正比。例如，在给定计数器中的衰变率用于测量放射性化合物。对于发射辐射的元素（如没有同位素的碳和氧），可以将同位素掺入化学化合物并通过辐射检测。第二个性质是衰变率不受同位素化学形式或化学环境性质的影响。通过替换或标记分子中的原子，同位素可以追踪原子在化学反应过程中的路径。参见核化学；辐射；辐射；放射性。[2]

# 放射生态学

研究环境中辐射的命运和影响。

对辐射应激的反应对其所属的个体和种群、群落或生态系统产生影响。当长期暴露辐射时，例如，生物群落的物种可能会减少，并被变异类型取代，或发生物种组成的变化。放射性技术也可评估自然环境中的放射性水平。例如，可以给动物安装发射器以便定期释放和重新捕获。当可以测定同位素量并对血液或组织样本进行分析时。在这种情况下，即使发育和结构的变化也可能暗示辐射导致的遗传损伤。在某些情况下，放射性污染物造成的损害可能会因协同效应而恶化。
