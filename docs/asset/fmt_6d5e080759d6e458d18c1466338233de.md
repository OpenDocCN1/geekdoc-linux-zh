
# 中级命令

- 10. `locate` — `locate` 命令用于在 Linux 系统中定位文件，就像 Windows 中的搜索命令一样。当你不知道文件保存在何处或文件的实际名称时，这个命令非常有用。在命令中使用 `-i` 参数可以忽略大小写（大写或小写都没关系）。所以，如果你想要一个包含“hello”单词的文件，当你输入 `locate -i hello` 时，它会列出 Linux 系统中所有包含“hello”单词的文件。如果你记得两个单词，可以使用星号（`*`）将它们分开。例如，要定位一个包含“hello”和“this”单词的文件，你可以使用命令 `locate -i *hello*this`。

- 1. `echo` — "`echo`" 命令帮助我们移动一些数据，通常是将文本写入文件。例如，如果你想创建一个新的文本文件或向已有的文本文件添加内容，你只需要输入 `echo hello, my name is alok >> new.txt`。你在这里不需要用反斜杠来分隔空格，因为我们在完成需要写入的内容时使用了两个大于号。

- 2. `cat` — 使用 `cat` 命令显示文件内容。它通常用于方便查看程序。

- 3. `nano`, `vi`, `jed` — `nano` 和 `vi` 是 Linux 命令行中已安装的文本编辑器。`nano` 命令是一个很好的文本编辑器，它用颜色标记关键词并能识别大多数语言。而 `vi` 比 `nano` 更简单。你可以使用此编辑器创建新文件或修改文件。例如，如果你需要创建一个名为"check.txt" 的新文件，可以使用命令 `nano check.txt` 创建它。编辑后，你可以使用组合键 `Ctrl+X` 然后按 `Y`（或按 `N` 否）保存文件。根据我的经验，使用 `nano` 编辑 HTML 看起来并不好，因为其颜色的原因，所以我推荐 `jed` 文本编辑器。我们很快就会介绍安装包。

- 4. `sudo` — Linux 命令行中一个广泛使用的命令，`sudo` 代表 "SuperUser Do"超级用户执行）。在 Linux 命令行中，如果你想以超级用户执行某些操作，如果你需要管理员权限，请使用 `sudo` 命令。例如，如果你想编辑某个文件，可以使用 `sudo` 命令。如果你想以 root权限执行某些操作，可以使用 `sudo`。

- 5. `df` — 在 Linux 系统中使用 `df` 命令查看挂载分区的磁盘空间。它可以查看每个分区的可用/已空间。如果你想以 MB 显示，可以使用命令 `df -m`。

- 6. `du` — 使用 `du` 查看文件的磁盘使用情况。如果你想查看某个文件夹或文件的磁盘使用情况，可以使用 `du` 命令并输入其名称。例如，如果你想查看 Linux 中文件夹的磁盘使用情况，可以使用 `du`。你也可以使用命令 `ls -lah` 查看所有文件的大小。

- 7. `tar` — 在命令行中使用 `tar` 命令处理 tar 包（或压缩在 tar 包中的文件）。它有很多用途。它可以用于压缩和解压不同类型的 tar 存档，如 `.tar`, `.gz`, `.bz2` 等。它根据给定的参数运行。例如，`-cvf` 创建 `.tar` 存档，`-xvf` 解压包，`-tvf` 列出包的内容等。由于这是一个广泛的话题，这里有一些 `tar` 命令示例。

- 8. `zip`, `unzip` — 使用 `zip` 将文件压缩为 zip 存档，使用 `unzip` 从 zip 存档中提取文件。

- 9. `uname` — 使用 `uname` 显示你所运行的系统信息。使用命令 `uname -a` 会打印有关系统的大部分信息。这包含了内核发布日期、版本、处理器类型等。

- 10. `apt-get` — 在 Linux 命令行中使用 `apt` 处理软件包。使用 `apt-get` 安装软件包。这需要 root 权限，因此配合 `sudo` 命令使用。例如，如果你想安装文本编辑器 `jed`，我们可以输入 `sudo apt-get install jed`。同样，包都可以这样安装。在每次尝试安装新包之前，更新存储库是好的。你可以通过输入 `sudo apt-get update` 来实现。通过 `sudo apt-get upgrade` 升级系统。我们也可以通过 `sudo apt-get dist-upgrade` 升级发行版。命令 `apt-cache search` 用于搜索软件包。如果你想搜索某个包，可以输入 `apt-cache search jed`（这不需要 root）。

在这种情况下可以使用命令 `chmod +x numbers.py`。你可以使用 `chmod 755 numbers.py` 来赋予其 root 权限，或者使用 `sudo chmod +x numbers.py` 赋予 root 执行权限。这里有关于 `chmod` 命令的更多信息。

- 12. `hostname` — 使用 `hostname` 了解你在主机或网络中的名称。基本上，它会显示你的主机主机名和 IP 地址。只需输入 `hostname` 即可获得输出。输入 `hostname -I` 则可以获取你在网络中的 IP 地址。

- 13. `ping` — 使用 `ping` 检查你与服务器的连接。维基百科说：“Ping 是一种计算机网络管理实用程序，用于测试 Internet 协议 (IP) 网络上主机的可达性”。简单来说，当你输入例如 `ping google.com` 时，它会检查是否可以连接到服务器并返回。它会测量这种往返时间并提供相关细节。对于像我们这样的普通用户来说，使用此命令的作用是检查互联网连接。如果它 ping 通了 Google 服务器（在这种情况下），你可以确认你的互联网连接是活跃的！

# LINUX 命令行使用技巧与提示

你可以使用 `clear` 命令来清除终端，如果它被太多命令填满了。

`TAB` 键可以用于补全终端内容。例如，你只需要输入 `cd Doc` 然后按 `TAB`，终端就会补全剩余部分并变为 `cd Documents`。

`Ctrl+C` 可以安全地停止终端中的任何命令。如果通过此操作无法停止，可以使用 `Ctrl+Z` 强制停止。

你可以通过 `exit` 命令退出终端。

你可以通过命令 `sudo halt` 和 `sudo reboot` 来关闭电源或重启电脑。

# Linux 的优势

现在让我们简要讨论一下 Linux 的一些优势：

- 1. 开源

Linux 的主要优势之一是它是开源操作系统，也就是说它的源代码对所有人开放。任何能够编程的人都可以为任何人、出于任何目的贡献、修改、增强和分发代码。

- 2. 安全

与 Windows 等其他操作系统相比，Linux 更安全。Linux 并非完全安全，因为也有针对它的恶意软件，但它比其他系统更脆弱。Linux 中的每个程序（无论是应用程序还是病毒）都需要管理员以密码的形式进行授权。除非输入密码，否则病毒不会执行。

在 Linux 中，你会遇到数量大量的软件更新。这些软件更新的速度比任何其他操作系统的更新都要快得多。Linux 的更新可以很容易完成，无需面临任何重大问题或担忧。

- 5. 定制化

一个比其他操作系统具有主要优势的功能是定制化。由于 Linux 是开源操作系统，你可以根据需要自定义任何功能、添加或删除任何功能。不仅如此，还可以安装各种壁纸和吸引人的图标主题，为你的系统提供惊艳的外观。

- 6. 多种发行版

Linux 还有许多可选发行版。它为用户提供了多种选择或口味。你可以根据需求选择任何发行版。Linux 的发行版包括 `Fedora`、`Ubuntu`、`Arch Linux`、`Debian`、`Linux Mint` 等。如果你是新手，可以使用 `Ubuntu` 或 `Linux Mint`。如果你是一个优秀的程序员，可能可以使用 `Debian` 或 `Fedora`。

- 7. 免费使用（低成本）

Linux 可以在网上免费下载和使用。你不需要为它购买许可证，因为 Linux 及其许多软件都遵循 GNU 通用许可协议 (`GPL`)。这证明了 Linux 与 Windows 及其他操作系统相比的主要优势之一。你需要花费巨资购买 Windows 许可证，而 Linux 并非如此。

- 8. 大大的社区支持

网上由热心的用户建立了论坛，以帮助和解决任何其他用户面临的问题。那里有许多专门的程序员，尽可能在任何时间任何地为你提供帮助。

- 9. 稳定性（可靠性）

Linux 提供了高稳定性，这也是很好的优点，即它不需要在短时间内重新启动。你的 Linux 系统很少会变慢或死机。在 Windows 中，你需要在安装或卸载应用程序或更新软件后重新启动系统，但 Linux 并非如此。你可以在 Linux 系统上不受任何干扰地工作。

- 10. 隐私

Linux 确保用户数据的隐私，因为它在使用其发行版或软件时从不从用户那里收集大量数据，但许多其他操作系统并非如此。

- 11. 性能

Linux 在各种网络和工作站上提供高性能。它允许大量用户同时工作，并高效地处理他们。

- 12. 网络支持

Linux 支持网络功能，因为它是程序员在互联网上编写的。Linux 帮助你以简单快速的方式在计算机系统上设置客户端和服务器系统。

- 13. 灵活性

Linux 提供了很高的灵活性，因为你可以只安装所需的组件。没有必要安装完整的套件。你还可以将 Linux 文件保留在多个分区下，这样如果其中一个损坏，就不会有重大损失。你只需要修复那个特定的分区，而不是整个文件，与其他操作系统不同。
