# 命令替换

与 C/TC shell 和 Bourne shell 类似，UNIX/Linux 命令的输出可以通过将命令用反引号括起来分配给变量，或用作字符串中命令的输出。Korn shell 还提供了一种新的语法。不是将命令放在反引号之间，而是将其包含在一组括号中，并在前面加上美元符号。

### 示例

```
variable_name=`command`
variable_name=$( command )
echo $variable_name

echo "Today is `date`"
echo "Today is $(date)"
```
