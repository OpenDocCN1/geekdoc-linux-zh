
文档字符串的缩进必须与定义中的所有其他语句保持一致。此外，文档字符串不能作为表达式从变量进行计算或赋值。文档字符串必须是一个用引号括的字符串字面量。

## 装饰器（Decorators）

函数、方法或类的定义之前可以有一个名为“装饰器”的特殊符号，其目的是修改其后的定义行为。装饰器用`@`符号表示，并且必须放置在相应函数、方法或类之前单独的一行。这里有一个示例：

```
class Foo(object):

    @staticmethod

    def bar():

        pass
```

可以使用多个装饰器，但每个装饰器都必须单独占一行。这里有一个示例：

```
@foo

@bar

def spam():

    pass
```

关于装饰器的更多信息可以在第 6 章“函数与编程”和第 7 章“类与面向对象”中找到。

## 源代码编码

Python 源代码通常使用 ASCII 编写。然而，在 Unicode 环境中工作的用户可能会发现这很不方便——当他们必须编写国际字符时。可以通过包含特殊的注释以不同的编码编写源代码：

```python
#!/usr/bin/env python
### -*- coding: utf-8 -*-
s = "ñ"
```

## 类型与对象

Python 中的所有数据都围绕对象的概念构建。对象包括数字、字符串、列表和字典等基本类型。还可以类的形式创建自定义对象。此外，与程序结构相关的对象也是公开的。本章介绍了对象模型的内部机制，并提供了内置类型的概述。第 4 章“运算符与表达式”进一步描述了这些。

## 术语

存储的每个数据都是对象。每个对象都有标识、类型（也称为类）和值。例如，当你写入`a = 42`时，会创建一个值为 42 的整数对象。你可以将对象的标识视为指向其内存位置的指针，尽管这特定于 Python 的实现且没有此类标识的解释。
对象的类型（也称为类）描述了对象的内部表示以及它支持的方法和操作。当创建特定类型的对象时，该对象被称为该的实例。实例创建后，其标识和类型不能更改。如果对象的值可以修改，则该对象是可变的（mutable）。如果值不可修改，则该对象是不可变的（immutable）。引用其他对象的对象容器或集合。

大多数对象以许多数据属性和方法为特征。属性是与对象的值。方法是在作为函数调用时对对象执行操作的操作。属性和方法通过点（`.`）运算符访问，如下所示：

```
a = 3 + 4
r = a.real      # 创建复数
               # 获取实部（一个属性）
b = [1, 2, 3]   # 创建列表
b.append(7)     # 使用 append 方法添加新元素
```

## 对象标识与类型

内置函数`id()`返回对象的标识（整数）。这个整数通常对应于对象在内存中的位置，尽管这特定于 Python 的实现且没有此类标识的解释。

## 第 3 章 类型与对象

`is`运算符用于比较两个对象的标识性。内置的`type()`函数返回对象的类型。这里有一个比较两个对象的不同方法的示例：

```python
### Compare two objects
def compare(a,b):
    if a is b:
        # a and b 是同一个对象
        statements
    if a == b:
        # a and b 的值相同
        statements
    if type(a) is type(b):
        # a and b 的类型相同
    statements
```

对象的类型本身也是对象，被称为对象的类（class）。这个对象是唯一定义的，并且对于给定类型的所有实例，它总是相同的。因此，可以使用运算符对类型进行比较。所有类型对象都分配了名称，可以用于类型检查。其中大多数是内置类型，如`list`、`dict`和`file`。这里有一个示例：

```python
if type(s) is list:
    s.append(item)
if type(d) is dict:
    d.update(t)
```

由于可以通过定义类来特化化类型，因此检查类型的更好方法是使用内置的`isinstance(object, type)`函数。这里有一个示例：

```python
if isinstance(s,list):
    s.append(item)
if isinstance(d,dict):
    d.update(t)
```

由于`isinstance()`函数感知继承关系，它是检查任何 Python 对象类型的首选方法。
尽管可以向程序中添加类型，但类型检查通常没有你想象的那么有用。首先，过度的检查会影响性能。其次，程序并不总是定义整齐地符合继承层次结构中的对象。例如，为了让前面的`isinstance(s, list)`语句测试其是否是“类列表”的，对于具有与`list`相同编程接口但没有继承内置`list`类型的对象，它将不起作用。在程序中添加类型检查的另一种方法是定义抽象基类。这在第 7 章中描述。

## 引用计数与垃圾回收

所有对象都经过引用计数。当对象被赋值给一个新名称或放入容器（如列表、元组或字典）时，它的引用计数就会增加，如下：

```python
a = 37 # 创建一个值为 37 的对象
b = a # 增加 37 的引用计数
c = []
c.append(b) # 增加 37 的引用计数
```

这个示例创建了一个包含值 37 的单个对象。`a`仅仅是引用新创建对象的名称。当给`b`赋值时，`b`变成该对象的新名称，对象的引用计数随增加。同样，当你将`b`放入列表时，对象的引用计数再次增加。在整个过程中，只有一个对象包含 37。所有其他操作只是创建指向该对象的新引用。

对象的引用计数会通过`del`语句减少，或者当引用超出作用域（或重新赋值）时减少。这里有一个示例：

```python
del a
b = { # 减少 37 的引用计数
    # 减少 37 的引用计数
c[0] = 2  # 减少 37 的引用计数
```

可以通过`sys.getrefcount()`函数获取对象的当前引用计数。例如：

```python
>>> a = 37
>>> import sys
>>> sys.getrefcount(a)
7
```

在许多情况下，引用计数比你猜的要高得多。对于数字和字符串等不可变数据，解释器会积极地在程序的不同部分之间共享对象以节省内存。

当对象的引用计数达到零时，会被垃圾回收。然而，在不再使用的对象之间可能存在循环依赖。这里有一个示例：

```python
a = {}
b = {}
a['b'] = b  # a 包含对 b 的引用
b['a'] = a  # b 包含对 a 的引用
del a
del b
```

在这里，`del`语句减少了`a`的引用计数并销除了引用底层对象的名称。但由于每个对象都包含指向另一个对象的引用，引用计数不会降零，对象保持分配状态（导致内存泄漏）。为了解决这个问题，解释器定期执行循环检测器，搜索不可访问的对象并将其删除。循环检测算法会随着解释器在执行期间分配越来越多的内存而定期运行。确切的行为可以使用`gc`模块中的函数进行精细调优和控制（见第 13 章“Python 运行时服务”）。

## 引用与复制

当程序执行如`a = b`的赋值时，会创建一个指向`b`的新引用。对于数字和字符串等不可变对象，这种赋值会创建`b`的副本。然而，对于列表和字典等可变对象，行为则不同。

```python
>>> a = [1,2,3,4]
>>> b = a  # b 是指向 a 的引用
>>> b is a
True
```

因为在这个示例中`a`和`b`指向同一个对象，对其中一个变量的更改会反映在另一个变量上。为了避免这种情况，你必须创建一个对象的副本而不是新引用。

```python
>>> b[2] = -100      # 修改 b 中的一个元素
>>> a                   # 注意 a 也发生了发生了变化
[1, 2, -100, 4]
>>>
```

复制有两种类型：浅拷贝和深拷贝。浅拷贝创建一个新对象，但用原始对象的引用来填充它。深拷贝创建一个新对象，并递归地拷贝其中发现的所有对象。这里有一个示例：

```python
>>> a = [1,2,3,4]
>>> b = a  # b 是指向 a 的引用
>>> b is a
True
>>> b[2] = -100      # 修改 b 中的一个元素
>>> a                   # 注意 a 也发生了变化
[1, 2, -100, 4]
>>>
```

为了避免这种情况，你必须创建一个对象的副本而不是新引用。对于可变对象，你可以使用`copy`模块：

```python
import copy
```
