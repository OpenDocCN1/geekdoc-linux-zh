
# 操作指南

现在仔细观察窗户。你已经安装了窗头，但窗户下方还需要部分墙体来填充。你需要复制窗头并更改它们的挤出数量：

1. 选择 `Layer:Wall-viz-sill` 对象。你可以使用“选择对象”对话框来操作，也可以简单地点击建筑后方的一个窗头。
2. 在选中“选择移动”工具的情况下，按住 `Shift` 点击变换手柄组件（`Transform gizmo`）的蓝色 Z 箭头并向下拖动选中的窗头，以创建窗头的克隆，大致将其放置在地面水平。
3. 在“克隆选项”（`Clone Options`）对话框中，点击“复制”（`Copy`）按钮启用它。你可以保留 `Layer:Wall-viz-sill` 名称。点击“确定”（`OK`）接受克隆。
4. 点击“绝对/偏移模式变换类型输入”工具切换到绝对模式；然后右键点击 Z 旋钮，将坐标显示中的 Z 值改为 0。
5. 将“修改”选项卡中“参数”的“数量”（`Amount`）值改为 2'。

## 导入冻结层

冻结层会自动排除在导入 `VIZ` 之外。然而，你可以手动选择导入时包含哪些层，无论它们在 `AutoCAD` 中的层状态如何（但工作流效率较低）。

2. 使用缩放范围（`Zoom Extents`）工具查看目前的工作（见图 17.24）。你现在拥有了二层的轮廓和两个穿过地板开口。

## 导入二层

下一步是将你的工作导入到 `VIZ`：

1. 返回 `VIZ` 并选择 文件（`File`） ▷ 重置（`Reset`）。由于你已经保存了工作，可以直接重置场景了。
2. 选择 文件（`File`） ▷ 导入（`Import`）。然后，在“选择导入的文件”对话框中，找到并打开你从 `AutoCAD` 保存的 `savoye-second.dwg` 文件。如果你没有 `AutoCAD`，请打开 `savoye-second-outline.dwg` 文件。
3. 在 `AutoCAD DWG/DXF` 导入选项对话框中，调整设置以匹配图 17.25 所示。
4. 点击 `AutoCAD DWG/DXF` 导入选项对话框中的层（`Layers`）选项卡。默认选中“跳过冻结层”（`Skip Frozen Layers`）按钮。此设置会自动跳过你在 `AutoCAD` 中冻结的层。

当你点击 `AutoCAD DWG/DXF` 导入选项对话框中层选项卡上的“从列表选择”（`Select from List`）按钮时，你可以通过取消列表边缘的勾选来手动检查导入哪些层。列表中显示的层（开启/关闭，冻结/解冻，锁定/解锁）代表 `DWG` 或 `DXF` 文件的当前状态，并非功能性的。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_845_0.png)

5. 点击确定（`OK`）导入图形并关闭 `AutoCAD DWG/DXF` 导入选项框。

你现在可以看到你在 `AutoCAD` 中创建的二层轮廓了。

最后一步非常简单。你只需要扩展脊线，开口就会自动出现：

1. 点击选择对象工具；然后点击地板。
2. 选择面板中的修改（`Modify`）选项卡；然后从修改器（`Modifier`）下拉列表中选择拉伸（`Extrude`）。
3. 设置数量（`Amount`）参数以匹配。你现在拥有了带有完整开口的二层地板。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_846_1.png)

4. 如果你需要，将此文件保存为 `savoye-second`。通过扩展脊线，开口就会自动出现。
