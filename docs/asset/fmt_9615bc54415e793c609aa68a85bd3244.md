## 数组元素

那么，数组有什么用呢？就像许多数据管理任务可以通过电子表格程序完成一样，许多编程任务也可以通过数组完成。
让我们考虑一个简单的数据收集和展示示例。我们将构建一个脚本来执行指定目录下文件的修改操作。根据这些数据，我们的脚本将输出一个表格，显示文件在一天中几小时最后被修改。这种脚本可以判断系统何时最活跃。这个名为 `hours` 的脚本产生如下内容：

```
[melinux ~]$ hours .

00 0 12 11
01 1 13 7
02 0 14 1
03 0 15 7
04 1 16 6
05 1 17 5
06 6 18 4
07 3 19 4
08 1 20 1

```
总文件数 = 80

我们执行 `hours` 程序，指定当前目录为目标。它产生了一个表格，显示一天中每个小时（0–23）有多少个文件最后被修改。生成此内容的代码如下：

```bash
#!/bin/bash
# hours: 按修改时间统计文件的脚本
usage () {
  echo "usage: ${$0##*/} directory" >&2
}
# 检查参数是否为目录
if [ ! -d "$1" ]; then
  usage
  exit 1
fi
# 初始化数组
for i in {0..23}; hours[i]=0; done
# 收集数据
for i in $(stat -c %Y "$1" | cut -c 12-13); do
  j="${hours[i]}
  ((++hours[j]))
  ((++count))
done
```

```bash
# 显示数据
echo -e "Hour\tFiles\tHour\tFiles"
for i in {0..11}; do
  printf "%02d\t%d\t%02d\t%d\n" $i ${hours[$i]} $((i+12)) ${hours[$((i+12))]}
done
echo "Total files = $count"
```

# 删除数组

要删除一个数组，请使用 `unset` 命令。

```
[me@linuxbox ~]$ foo=(a b c d e f)
[me@linuxbox ~]$ echo ${foo[@]}
ab c d e f
[me@linuxbox ~]$ unset foo
[me@linuxbox ~]$ echo ${foo[@]}
```

```
[me@linuxbox ~]$
```

`unset` 可用于删除单个数组元素。

```
[me@linuxbox ~]$ foo=(a b c d e f)
[me@linuxbox ~]$ echo ${foo[@]}
ab c d e f
[me@linuxbox ~]$ unset 'foo[2]'
[me@linuxbox ~]$ echo ${foo[@]}
ab d ef
```

在这个示例中，我们删除了数组的第三个元素，下标为 2。记住，数组下标从 0 开始，而不是 1！注意，数组元素必须加引号以防止 shell 执行路径名扩展。

有趣的是，给数组赋值空值并不会清空其内容。

```
[me@linuxbox ~]$ foo=(a b c d e f)
[me@linuxbox ~]$ foo=
[me@linuxbox ~]$ echo ${foo[@]}
c d f
```

任何对没有下标的数组变量的引用都指向数组的零元素。

```
[me@linuxbox ~]$ foo=(a b c d e f)
[me@linuxbox ~]$ echo ${foo[@]}
ab c d f
[me@linuxbox ~]$ foo=A
[me@linuxbox ~]$ echo ${foo[@]}
B c d f
```

# 关联数组

`bash` 4.0 及更高版本支持关联数组。关联数组使用字符串而不是整数作为数组索引。这种功能允许管理数据的新颖方法。例如，我们可以创建一个名为 `colors` 的数组并使用颜色名称作为索引。

```bash
declare -A colors
colors["red"]="#ff0000"
colors["green"]="#00ff00"
colors["blue"]="#0000ff"
```

与索引数组不同（索引数组仅通过引用即可创建），关联数组必须使用 `declare` 命令配合新的 `-A` 选项来创建。关联数组元素的访问方式与整数索引数组相同。

```
echo ${colors["blue"]}
```

在下一章中，我们将查看一个很好利用关联数组来生成有趣报告的脚本。

## 总结

如果我们在 bash 页面中搜索 `array` 一词，会发现很多 bash 使用数组变量的实例。其中大多数都相当晦涩，但在某些特殊情况下可能会提供偶尔的效用。事实上，数组的整个主题在 shell 编程中相当没有被充分利用，这很大程度上是因为传统的 Unix 程序（如 `sort`）缺乏对数组的支持。这种缺乏普及程度是遗憾的，因为数组在其他编程语言中被广泛使用，并为解决许多编程问题提供了强大的工具。

```
for ((expr; expr; expr))
```

### 组命令与子壳

`bash` 允许将命令分组。这可以通过两种方式之一实现：使用*组命令*（group command）或使用*子壳*（subshell）。

以下是组命令的语法：

```
{ command1; command2; [command3; ...] }
```

以下是子壳的语法：

```
(command1; command2; [command3;...])
```

两者的区别在于，组命令用大括号包围其命令，而子壳使用括号。需要注意的是，根据 bash 实现组命令的方式，大括号与命令之间必须留有空格，并且最后一个命令在闭合括号之前必须以分号或换行符结束。

那么，组命令和子壳的作用对于什么呢？虽然它们有重要的区别（我们稍后会介绍），但它们都用于管理重定向。让我们考虑对多个命令执行重定向的脚本。

```
ls -l output.txt
echo "Listing of foo.txt" >> output.txt
cat foo.txt >> output.txt
```

这非常直观。三个命令的输出都被重定向到名为 `output.txt` 的文件中。使用组命令，我们可以这样编写代码：

```
{ ls -l; echo "Listing of foo.txt"; cat foo.txt; } > output.txt
```

使用子壳也是类似的。

```
(ls -l; echo "Listing of foo.txt"; cat foo.txt) > output.txt
```

使用这种技术我们节省了一些打字量，但组命令或子壳真正大放异彩在于管道。在构建命令管道时，将几个命令的结果合并到一个流中通常很有用。组命令和子壳使得这一切变得简单。

```
{ ls -l; echo "Listing of foo.txt"; cat foo.txt; } | lpr
```

在这里我们合并了三个命令的输出并将其管道到一个打印报告中。
