
化能自养细菌能够利用无机化合物氧化过程中释放的化学能，将无机碳还原为有机碳（化能合成）。因此，它们的存在并不受光照限制，而是取决于氧气和合适的无机电子的可用性。与光合生产者（考察深海热液喷口发现的过程）相比，它们作为有机碳生产者的作用微不足道。氨和亚硝酸盐氧化为硝酸盐（硝化作用）提供了化学稳定且生物可利用性最强的无机氮形式，供光合作用使用。参见：氮循环。

由厌氧细菌化能合成产生的甲烷和乙酸，在缺氧的海洋沉积物中很常见。参见：甲烷生成（细菌）。

### 海洋微生物硫循环
硫酸盐是海水中在数量上最重要的阴离子。由于多种异养细菌在溶解氧耗尽后可将其用作呼吸过程中的电子受体，所产生的含硫化合物使海洋环境在微生物学上与淡水及大多数土壤有明显区别。海洋厌氧、异养、硫酸盐还原细菌分为三个属：脱硫弧菌属（`Desulfovibrio`）、脱硫梭菌属（`Desulfotomaculum`）和梭菌属（`Clostridium`）。

还原性含硫化合物的进一步循环。海洋好氧硫氧化细菌分为两组：硫杆菌型和丝状或单细胞生物。前者包含从专性到兼性化能自养物种（氧化无或某些有机化合物）的广泛范围，后者中仅有少数被纯培养分离出来，且仅在少数中证明了化能自养特性。

### 热液喷口细菌
可以研究两种类型的热液喷口：热喷口（8–25 °C 或 46–77 °F），流速为每秒 1–2 米（0.4–0.8 英尺）；和热液喷口（260–360 °C 或 500–600 °F），流速高达每秒 5 立方英尺（0.14 立方米）。在其附近，发现了密集的底栖无脊椎动物群落，其生物量比通常在这些深度依赖光合食物来源的生物量高出几个数量级。这一现象被解释为通过还原性无机化合物的化能合成氧化产生有机碳的细菌初级生产。此过程所需的化学能与光合作用中使用的光能类似，由地热还原无机化学物种提供。排放的喷口水中适合细菌化能合成的特定化合物主要是硫化氢、氢气、甲烷以及还原态的铁和锰。从热液喷口分离出的极端嗜热微生物，除了古细菌中的`Thermotoga`属外，都属于古细菌（Archaeabacteria）。在八个细菌属中，在约 75–110 °C（165–230 °F）的温度范围内生长的，有三个属如果在施加必要压力以防止沸腾的条件下，能够在水的沸点以上生长。这些生物是严格厌氧的。然而，与嗜温细菌不同，嗜热海洋分离菌株在冷却至其最低生长温度以下时能耐受氧气。参见：古细菌；热液喷口。[H.W.J.]

# 海洋采矿
从海水中以及海底表面和下方的矿床中回收矿产财富的过程。虽然海洋表面和下方确实存在价值数万亿美元的矿产资源，但开采它们并非易事。在大多数这些矿床能够与陆地资源开采相竞争之前，必须克服许多环境问题并实现许多技术进步。海洋环境的矿产资源分为三种基本类型：溶解在海水中的矿物质；海洋海滩、大陆架和深海海底的非固结矿物沉积物；以及海底基岩中包含的固结沉积物。与陆地矿床一样，生产可市场商品前的初始阶段包括发现、评估矿床价值和可开采性的特征化，以及包括将材料选矿至可销售产品在内的开采。[M.J.Cru.]

# 海洋导航
以安全且迅速的方式将船舶引导至目的地的过程。从已知的当前位置出发，确定一条避开危险的航向，并根据该航向估算时间表。任务在于定期执行中途检查并进行必要的调整。

使用的方法取决于船舶类型及其角色或任务。可用的设备范围从简单的罗盘到许多先进的电子系统。在所有情况下，领航员必须通过整理仪器以及检查可预见的潮流和潮汐效应和航行危险来进行规划和准备。此准备包括

拥有最新且正确的海图，并查阅航海指南、灯标表及现行通告的相关章节。

用于满足这些阶段要求的方法属于以下某一种主要的导航类别：航位推算、陆标领航、天文导航和电子导航。前三类已经变得相对标准化；第四类则一直在不断进行创新性的发展。

虽然导航员主要关注航向、航速、距离和定位，但绝不能忽视船舶的安全性。集成化导航-操舵系统的基本功能是通过计算机在拥挤状况下关联大多数可用数据，从而帮助减少船舶之间的事故数量，并通过以更易用的形式呈现这些数据，减轻导航员的负担，使其能够做出更好、更快的决策。该系统通常包括一个避碰装置和一个通用计算机。计算机从导航传感器以及船舶推进和船舶状态站接收输入信号。集成控制台的设计旨在优化船舶控制和导航的人因工程方面。

具有不同复杂程度的避碰系统（`CAS`），也称为自动雷达标绘辅助系统（`ARPA`），已被开发出来，以减轻导航员的工作量并消除人为错误。通常，此类系统由一个数字计算机组成，该计算机接收来自船舶雷达、罗经和计程仪的输入信号，确定并显示碰撞威胁，在某些安装中还提供建议的避让行动。

为了减少碰撞和搁浅事故数量并保护海洋环境，世界上许多交通繁忙的港口已建立了船舶交通服务（`VTS`）。通常，该服务提供咨询性质的海上交通管理，但在特别危险的情况下，`VTS`可能需要对船舶运动实施紧急控制。参见“船舶交通服务”（VESSEL TRAFFIC SERVICE）。

为了降低海上碰撞风险，世界上许多高交通密度区域已建立了分道通航制。典型的方案是建立平行的交通道，道之间由缓冲区隔开，类似于分道的高速公路。[A.B.M., R.Gre.]

电子海图在视频屏幕上显示水手在传统航海海图中所寻求的同类水文信息。电子海图集成了多种信息，其硬件和软件能够处理水文数据库以支持决策制定，可归类为电子海图显示与信息系统（`ECDIS`）。除了显示船舶在水道中的实时位置外，`ECDIS` 还管理导航和领航信息（通常包括船舶航迹监控、航迹保持和航迹规划信息），以支持导航决策。

自动化船舶驾驶舱部署了各种智能系统：领航专家系统、工程与振动专家系统、用于自适应和智能舵控的神经网络系统，以及自动化智能靠泊系统。参见“专家系统”（EXPERT SYSTEMS）；“神经网络”（NEURAL NETWORK）。

集成驾驶台系统旨在使驾驶台能够作为船舶上导航和监控任务的操作中心。在许多情况下，这些驾驶台成为船舶的操作中心，整合了所有关键船舶功能的控制与监控，包括导航、引擎控制和通信。参见“导航”（NAVIGATION）。[M.R.G.]

## 船用制冷
船用制冷设备既用于船舶产品的冷藏，也用于旅客和船员舱室的空调。船舶冷藏对于在运输过程中保存易腐品以及供旅客和船员使用的食品是必要的。船用制冷还用于保持某些货物产品处于液态，否则这些产品在环境条件下储存时会蒸发。参见“空调”（AIR CONDITIONING）；“制冷”（REFRIGERATION）。

多年来一直使用的常见制冷剂，即已知为`CFC`（氯化氟烃）和`HCFC`（氢氯化氟烃）的物质，正逐渐被淘汰，因为它们含有氯，会消耗地球的平流层臭氧层。这些制冷剂的替代品，已知为氢氟碳化物（`HFCs`），不会破坏臭氧层。它们通常是开发出的制冷剂，以氟代替氯，不破坏臭氧层。在某些系统中，货物本身被用作制冷剂，例如运输氨或丙烷或丁烷等石油产品时。

对于使用绝缘舱室的制冷系统，液态制冷剂被输送到冷却盘管，在那里制冷剂膨胀并作为低压液体进入蒸发器。在那里，它通过吸收被冷却空间的热量而蒸发。然后，制冷剂蒸气被压缩机从蒸发器中抽出，压缩机以高压、高温蒸气的形式将制冷剂输送到冷凝器。冷凝器通常是由海水流过管束冷却的壳管式换热器，当制冷剂冷凝为高压液体时，移除在蒸发器中吸收的热量以及压缩热。随后制冷循环重复进行。对于集装箱系统，每个集装箱都有自己的制冷系统，由压缩机、风冷冷凝器、冷却盘管和循环风扇组成。对于绝缘罐中的液体货物，当蒸发液体改变状态变为气体时，汽化潜热被释放。[J.H.M.]

## 海洋沉积物
矿物和有机残留物在海底的堆积。海洋沉积物的成分和物理特征因水深、距陆地的距离、沉积物来源的变化及其环境的物理、化学和生物特征而各不相同。海洋沉积物的研究是海洋学研究的一个重要领域，与陆地沉积物及沉积过程的研究一起，构成了地质学中被称为沉积学的分支。参见“海洋学”（OCEANOGRAPHY）。

传统上，海洋沉积物根据其沉积深度分为浅海沉积物（littoral，0–66 英尺 / 0–20 米）、大陆架沉积物（neritic，66–660 英尺 / 20–200 米）和大陆坡沉积物（bathyal，660–3000 英尺 / 200–2000 米）。这种划分过分强调了深度。更有意义但不够严格的是区分主要由源自陆地的物质组成的沉积物，和主要由起源于海洋的生物和矿物物质组成的沉积物。此外，沿大陆和大岛边缘形成的沉积物与远离陆地的深海远洋沉积物之间存在显著且普遍的区别；前者受陆地邻近性的强烈影响，通常发生在较浅的水域。

### 大陆边缘沉积物
这些包括沿海海域的沉积物、通常以最大水深 330–660 英尺（100–200 米）为界的大陆架沉积物，以及大陆坡的沉积物。由于沉积过程存在巨大差异，可以做出一个有用的区分：一方面是沿海沉积物（浅海），另一方面是开阔的大陆架和陆坡沉积物（大陆架和大陆坡）。此外，在接收大量陆地碎屑物质的区域与沉积物主要源自生物或化学起源的区域之间，沉积物特征和沉积模式存在显著差异。
