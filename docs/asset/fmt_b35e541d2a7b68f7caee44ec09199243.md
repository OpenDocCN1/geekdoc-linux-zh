
## The few (non-user-specific) exceptions might be in `/dev`, `/sys` or `/proc`.
These are special, dynamically-generated filesystems. You may occasionally read information from these filesystems, but most of the time you shouldn't be writing directly to them.

### Task 3:
Run the following commands in your Terminal:

+ • `free -m`
+ • `ps -ef`
+ • `top # press q to quit`

These are three common tools to monitor processes and their resource usage. (Got a runaway process that won't quit via the normal means? Try `kill` or `pkill`.)

### Notes:
`/dev` contains special files called device nodes, which are linked to device drivers. `/sys` and `/proc` contain files by which the kernel presents non-process and process-related information, respectively. (In reality, this is more muddled, but that is the ideal separation.)
