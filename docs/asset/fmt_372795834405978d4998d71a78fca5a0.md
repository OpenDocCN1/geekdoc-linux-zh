
在全球各地的动物、植物、土壤和水中都检测到了 PCB，甚至在水深 11,000 英尺（3400 米）以下的动物体内也有发现。这些现象是食物链中生物富集和生物放大的结果。在少数情况下，家禽产品、牛和猪被发现在食用受 PCB 污染的饲料后含有高浓度的 PCB。尚不清楚有多少 PCB 被释放到环境中，但主要来源是工业和市政废物处置、含 PCB 设备的泄漏和溢出，以及 PCB 混合物的制造和处理。参见[大气：环流](https://example.org/atmosphere_general_circulation)；[生物圈](https://example.org/biosphere)；[食物网](https://example.org/food_web)；[人类生态](https://example.org/human_ecology)。

PCB 可通过肺部、胃肠道和皮肤进入人体，在全身循环，并储存在脂肪组织中。已在人体脂肪组织以及牛和人的乳汁中检测到 PCB。某些 PCB 具有改变哺乳动物生殖过程的能力。人们担心 PCB 在人类中可能具有致癌性。[K.Gr.]

## 多裂目

一类海洋扁形动物，其叶状身体长达数毫米至数厘米，具有中央肠和辐射状分支。

大多数物种生活在底层、海藻或其他物体上的潮间带，或者是贝类和寄居蟹壳内的共生物。没有寄生虫。除了在暖水中，它们很少色彩鲜艳。参见[扁形动物](https://example.org/turbellaria)。[E.R.J.]

## 聚酯树脂

由二羧酸与二元醇酯化制成的合成聚合物树脂。脂肪族聚酯倾向于相对柔软，而芳香族衍生物通常是坚硬且脆的，或者坚韧。这两类产品的性质都可通过交联、结晶、增塑剂或填充剂进行修改。参见[酯](https://example.org/ester)。

商业产品包括烷基树脂，用于涂料、瓷漆和模塑料；不饱和聚酯或不饱和烷基树脂，广泛用于玻璃纤维制造的船体和面板；脂肪族饱和聚酯；芳香族聚酯，如用于纤维和薄膜的聚对苯二甲酸乙二醇酯；以及芳香族聚碳酸酯。聚(烷基)酯虽然经常与聚酯一起列出，但不是如上定义的真聚酯。参见[聚树脂](https://example.org/polyvinyl_resins)。

## 聚四氟乙烯树脂 1743

烯丙基（或指代不饱和聚酯中的烯基端基）通常用作涂料。常规植物油干燥油与醇酸树脂的组合构成了大多数油溶性涂料的基础。干燥油-烯丙基体系可通过引入一种乙烯基单体（如苯乙烯）进行改性。部分苯乙烯进行聚合（可能形成接枝聚合物），而剩余部分在涂料最终的干燥和固化过程中发生聚合和共聚。参见“干燥油”；“涂料”；“聚合”。

不饱和聚酯与玻璃纤维结合后，被应用于板材、屋顶、雷达罩、船体以及士兵防护装甲等领域。这些材料以易于成型和具有高抗冲击性而著称。参见“聚合物复合材料”。

饱和脂肪族聚酯长期以来经常作为中间体，用于制备制造分段式聚氨酯的预聚合物。内酯环开环反应也可生成线性聚酯。

具有普遍重要性的芳香族聚酯是聚对苯二甲酸乙二醇酯，它们可制成具有极高强度和耐化学性的纤维及薄膜。对苯二甲酸聚酯是涤纶纤维的主要成分。聚对苯二甲酸乙二醇酯可通过模塑或挤出工艺制成材料，在某些汽车、电气及特种应用中可替代金属或热固性树脂，特别是当其与玻璃纤维或矿物填料增强时。

芳香族聚碳酸酯是一类强度高、韧性好的热塑性聚合物，通常由双酚A和光气制成。这类聚碳酸酯产品以具有高软化温度、高抗冲击性、透明性以及耐蠕变性而著称。聚碳酸酯通常以模塑料的形式供应。凭借其高强度、韧性和软化点，该树脂无论是单独使用还是作为玻璃纤维增强材料，在许多家用、室内及工程应用中均有所应用。它常被用来替代玻璃和金属。实例包括瓶子、防碎窗户、电器部件、电气外壳、船用螺旋桨以及霰弹枪弹壳。由于其燃烧时毒性低且烟雾排放少，阻燃级聚碳酸酯备受关注。

聚二烯丙基酯是二烯丙基酯的聚合物。通过严格控制初始聚合度，可以制成热固性模塑料，从而获得一种可熔化的产物。其主要应用领域包括电子化合物、密封剂、涂料及玻璃纤维复合材料。参见“塑料加工”。[J.A.M.]

## 聚醚树脂

指在聚合物链中含有醚氧键（—C—O—C—）的热固性或热塑材料。根据反应物的性质和反应条件的不同，可以制备出具有广泛性能特征的多种聚醚。常用的主要聚醚类别包括环氧树脂、酚氧树脂、聚氧化乙烯和聚氧化丙烯树脂、聚环氧乙烷以及聚氧化乙烯。

环氧树脂是一类重要且用途广泛的热固性交联聚醚，其特点是具有优异的耐化学性、对玻璃和金属的附着力、电绝缘性能以及易于精密加工。在环氧配方中，通常使用碳酸钙、金属纤维和粉末、玻璃纤维等多种填料，以改善强度、耐磨性和耐高温性等性能。某些反应型增塑剂作为固化剂使用，它们会永久结合到环氧基团上，通常被称为柔韧剂。加入橡胶状聚合物可提高韧性和抗冲击强度。环氧树脂常用于保护性涂料。它们也用作灌封或封装化合物，以保护精密电子组件免受火箭飞行中热冲击和机械冲击的影响，或用作冲压金属零件的模具。

聚氧化乙烯和聚氧化丙烯是热塑性产品，其性能受分子量影响很大。低分子至中等分子量的聚氧化乙烯形态可从油状变化为蜡状固体。它们相对无反应活性，可溶解于多种溶剂中，并被广泛用作增稠剂、增塑剂、纺织纤维润滑剂以及多种上浆剂、涂料和化妆品配方的成分。具有相似分子量的聚氧化丙烯性质与其略有相似，但更倾向于油溶（疏水）且水溶性（亲水）较差。虽然聚氧化乙烯本身在结构材料方面不具吸引力，但聚氧化丙烯在聚氧化乙烯泡沫的制备中应用广泛。

酚氧树脂透明、强度高、韧性好且耐蠕变，总体而言其行为类似于苯乙烯碳酸酯。其主要应用是作为保护性涂料（尤其是金属底漆）的成分。参见“聚酯树脂”。

聚氧化联苯（PPO）是一种工程塑料的基础，以化学、热及尺寸稳定性为特征。聚氧化联苯在耐水性方面表现卓越。其用途包括医疗器械、泵部件和绝缘材料。[J.A.M.]

聚甲醛树脂（或称聚缩醛树脂）是甲醛的聚合物。由于具有高分子量和高结晶度，它们既强韧又耐用，是工程热塑性塑料中的代表性类别。聚缩醛通常具有耐疲劳、耐蠕变、耐有机化学品（但不耐强酸或强碱）的特性，且摩擦系数低。其电气性能也良好。这些性能的组合使其拥有许多用途，如水暖管件、泵和阀门部件、轴承和齿轮、计算机硬件、汽车车身部件以及电器外壳。参见“塑料加工”；“聚合”。

## 聚烯烃树脂

这类树脂以其耐高温和耐化学品性能以及高结晶能力而著称。主要产品基于四氟乙烯（F₂C=CF₂，简称TFE）、六氟丙烯（F₂C=CFCl₂，简称HFP）和氯乙烯三氟乙烯（CFCl=CF₂，简称CTFE）。

聚（四氟乙烯）是四氟乙烯的聚合物，通常以商标名 Teflon® 为人所知。它不溶于水，耐热（高达 275 C 或 527 F）且耐化学腐蚀，拥有所有固体中最低的摩擦系数。然而，由于聚（四氟乙烯）与其他物质结合力较差，必须进行特殊的表面处理才能使其具备附着力。聚（四氟乙烯）（TFE 树脂）用于轴承、阀门密封面、填料、垫圈、涂料和管材，并能承受相对恶劣的条件。由于其卓越的电气性能，当需要在高温下工作时，聚（四氟乙烯）可作为介质材料使用。

其不粘特性常用于包裹滚轮和饼干等材料，防止物质粘附。

聚（氯乙烯三氟乙烯）（CTFE）树脂的性能通常与聚（四氟乙烯）相似；然而，前者的氯原子使得该聚合物在耐热性和耐化学性上稍逊一筹。

聚（氯乙烯三氟乙烯）的应用通常与聚（四氟乙烯）类似。由于其稳定性和惰性，该聚合物在制造垫圈、衬里和阀门密封面方面非常有用，这些部件可耐受高温和腐蚀性环境。它还可用作介质材料、气体和液体阻隔层以及微孔过滤器。

聚（偏二氟乙烯）的性能与其他含氟树脂通常相似：相对惰性、低介电常数和热稳定性（可耐受约 150 或 300 F）。然而，与 TFE 和 CTFE 树脂相比，这些树脂（PVF 树脂）强度更高，且更耐蠕变和磨损。聚（偏二氟乙烯）的应用主要作为电气绝缘体、管道、工艺设备，以及作为液态分散形式的保护涂料。

已开发了几种含氟且非晶化的弹性体，以满足（通常为军用）对高温性能优异，以及对油、热、辐射和风化具有高度抵抗性的要求。参见 卤代烃；塑料加工；聚合物。

[J.A.M.]

## Polygalales（花烛目/百部目）
