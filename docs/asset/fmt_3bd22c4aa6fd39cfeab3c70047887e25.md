
## Select base:
0. Current partition table (unnamed)
1. All Free

Choose base (enter number)? 1

`All Free` 方法允许你在分配完其他分区后，选择一个分区来接收磁盘的剩余部分。例如，该磁盘将成为你希望尽可能大的 `/web` 分区（假设是的话）。一旦你选择选项 1，你就会看到以下内容：

| Part | Tag | Cylinders | Size | Blocks |
|---|---|---|---|---|
| 0 | root | 0 | 0 | (0/0) |
| 1 | swap | 0 | 0 | (0/0) |
| 2 | backup | 350 | 1.99GB | (3508/0/0) |
| 3 | unassigned | 0 | 0 | (0/0) |
| 4 | unassigned | 0 | 0 | (0/0) |
| 5 | unassigned | 0 | 0 | (0/0) |
| 6 | usr | 0 | 0 | (0/0) |
| 7 | unassigned | 0 | 0 | (0/0) |

Do you wish to continue creating a new partition based on above? yes

因为分区表看起来合理，所以同意将其作为你系统的基础。系统将询问你哪个分区应该是 `Free Partition`（空闲分区），即在所有内容分配后接收磁盘剩余部分的分区。对于我们的方案，我们将分区 5 设置为空闲分区。5

回答这个问题显示了关于其他分区大小的问题列表。对于我们的 Web 服务器，我们需要一个 `root` 分区大约为 200 MB 用于系统，`swap` 分区...

你必须回答的最后一个问题也可以从厂商规格书中找到。

```
Enter number of data sectors/track: 72
```

剩余的问题应该保持默认值。

```
Enter number of physical sectors/track[default]:
Enter rpm of drive[3600]:
Enter format time skew[default]:
Enter cylinder skew[default]:
Enter track skew[default]:
Enter tracks per zone[default]:
Enter alternate tracks[default]:
Enter alternate sectors[default]:
Enter cache control[default]:
Enter prefetch threshold[default]:
Enter minimum prefetch[default]:
Enter maximum prefetch[default]:
```

关于磁盘你必须回答的最后一个问题是它的标签信息。在此问题中，用双引号输入厂商和型号。对于我们的示例磁盘，应该是：

```
Enter disk type name (remember quotes): "SEAGATE ST32550N"
```

有了这些信息，Solaris 开始创建分区。

在完成 `type` 命令的最后一个问题后，你将处于 `format>` 提示符下。输入 `partition` 进入分区菜单。

```
format> partition
```

我们的新磁盘是系统外部，因此我们知道它位于控制器 1 上。单元 6 是链上唯一的磁盘，因此我们知道它就是我们刚刚添加到系统的磁盘。

要对磁盘进行分区，请运行带有任意参数的 `fx` 命令。它会提示我们输入设备名称、控制器和驱动器编号。选择默认设备名称，并为另外两个问题输入适当的信息。

在我们的示例系统中，它看起来如下：

```
# fx
fx version 6.2, Mar 9, 1996
fx: "device-name" = (dksc)
fx: ctrl# = (0) 1
fx: drive# = (1) 6
fx: lun# = (0)
... opening dksc(1,0)
...controller test...OK
Scsi drive type == SEAGATE ST32550N 0022
-- please choose (2 for help, .. to quit this menu) -----
[exilt] [d]ebug/ [l]abel/
[b]adblock/ [r]exercise/ [r]partition/
fx>
```

我们看到希捷硬盘已准备就绪可以工作。在菜单中，我们选择 `r` 对磁盘进行分区。`fx` 显示了关于磁盘的信息，并专门提供了用于磁盘分区的下一个菜单。

```
fx> r
partitions----
part type cyls blocks Megabytes (base+size)
7: xfs 3 + 3521 3570 + 4189990 2 + 2046
8: volhdr 0 + 3 0 + 3570 0 + 2
10: volume 0 + 3524 0 + 4193560 0 + 2048
```

容量 4194058 块

```
-- please choose (2 for help, .. to quit this menu) -----
[r]otdriveiveu]srootdrive [o]optionrive [re]size
fx/repartition>
```

查看结果，此磁盘在 IRIX 中从未被分区过。分区 7 代表可分区的空间大小，分区 8 是卷头，分区 10 是实体磁盘。

由于此磁盘将用于用作一个大分区，你将从菜单中选择 `optiondrive`。选择该后，系统会询问你想要使用哪种文件系统。IRIX 6 及以上版本默认使用 `xfs`，而 IRIX 5 默认使用 `efs`。请使用适用于你的 IRIX 版本的文件系统。

我们的示例系统运行 IRIX 6.3，因此我们接受 `xfs` 的默认值：

```
fx/repartition> o
```

fx/repartition/optiondrive: type of data partition = (xfs)

接下来系统询问我们是否想要创建一个 `/usr` 分区。由于我们的主系统已经有一个 `/usr` 分区，所以我们在这里不需要再创建一个。输入 **no**。

fx/repartition/optiondrive: create usr log partition? = (yes) no

系统准备好对驱动器进行分区。在执行之前，它会发出最后的警告，允许你在任务完成前停止分区。因为你确定正在分区的是正确的磁盘，你可以给它一个“提前停止”：

警告：更改分区布局后，你必须重新安装所有软件并从备份中恢复用户数据。更改分区会导致驱动器上的所有数据丢失。如果其中包含任何数据，请务必已备份。继续吗？**y**

系统花费几秒钟在磁盘上创建新分区。一旦完成，它会报告当前的分区状况如下：

```
| partitions part type cyls blocks Megabytes (base+size) |
| 7: xfs | 3 + 3521 | 3570 + 4189990 | 2 + 2046 |
| 8: volhdr | 0 + 3 | 0 + 3570 | 0 + 2 |
```
