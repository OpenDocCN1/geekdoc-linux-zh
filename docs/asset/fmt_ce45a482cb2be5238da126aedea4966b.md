# 足盘亚
足盘亚（`Pelmatoza`）是壳体动物门的一个分支，由在生命某些阶段锚定在基底上的生物组成。曾被视为与信天�形目一个分类单元，它们拥有那些喉囊；最大的喉囊出现在鹈类身上，它们将其作为网使用。羽毛，或白鹈通过从空中或水面俯冲捕获鱼类、甲壳类和乌鱼，并从表面或其他鸟类处获取。

# 珀帖耳效应
珀帖耳效应（`Peltier effect`）一门由 `J. C. Peltier` 于 `1834` 年发现的现象，他发现两种金属通过电流时温度升高或降低，取决于方向。参见 塞贝克热电效应、磁体。

## 宾夕尼亚纪 1625

`1938`年。青霉素（作为青霉素 `G`）在第二次世界大战后期提供欧洲的盟军。青霉素产生从霉中分离的真菌 `*P. chrysogenum*`。其生物合成过程已明确，参与形成这种次生代谢物的所有酶均已分离并纯化。

青霉素 `G` 和青霉素 `V` 易被细菌产生的酶（`β-内酰胺酶`）破坏，这使其产生抗性。甲氧西林、氧唑西林、氯西林和地氯西林等青霉素能够抵抗 `β-内酰胺酶` 的水解，用于治疗链球菌感染。氯西林和地氯西林是广谱青霉素，主要用于对抗链球菌和其他呼吸道病原体——`*流感杆菌*`，用于窦炎、支气管炎和肺炎。它们在儿科中被广泛使用，并用于治疗单增李斯特菌和`*沙门菌*`属。参见抗生素；耐药性；沙门菌；链球菌。

青霉素 `G` 是最常用的青霉素，通过加入前体苯乙酸产生青霉素 `V`。两者均在有机溶剂中以 `pH` 值和沉淀或钠盐的形式回收。青霉素 `G` 通过注射用于对青霉素敏感的链球菌，如肺炎球菌（脑膜炎），以及心内炎和出血。青霉素 `V` 稳定，通常口服。它对治疗上呼吸道感染和急性腹膜炎有效。参见 `GOERNER`；`MENKELE`。

`[R.A.]`

哺乳动物的交配器官或阴茎，由这些勃起组织团组成。中央海绵体（尿道）位于成对的海绵体内。尿道沿阴茎长度延伸，并在末端扩大成一个锥形尖端，即龟头，它在阴茎末端是扁平的。尿道在皮肤处结束，并形成包状物或包皮。

勃起是由性刺激导致阴茎动脉扩张和阴茎静窦扩张引起的。在除灵长类以外的许多哺乳动物中，阴茎在不用时会缩回鞘内。鳄鱼类、龟类和某些鸟类拥有组织构成的阴茎，位于泄腔底部。当勃起时，它能保护泄腔并在交配中起作用。大多数脊椎动物缺乏阴茎，尽管某些器官可能会发育出来，例如鲨鱼第一齿上的夹器和某些鱼类生殖腺上的夹器。

环节动物亚纲的羽毛虫总目，通常被称为海扇。这些动物具有长柄，身体嵌入海底的底基质中。触手由许多放射状分支和一个多肉的柄组成，柄末端有一个吸盘。萼是分枝的，看起来像羽毛，由许多从细长的主轴或性腺的叶状板产生的次级聚虫组成。在另一种形式（在 `Vellaria` 中）参见插图和 `Corall`。它有一个高度不分枝的轴。

宾夕尼亚纪是晚古生代，被视为一个独立的时期，或作为石炭纪较晚的时期。在北美，宾夕尼亚纪被广泛认为一个地质时期，其名称源于一系列主要是正常的含煤层。宾夕尼亚纪始于北极纪初，结束于约 `3.2` 亿年前。在北欧，早期地层与石炭纪中晚期的地层年龄几乎相当。

在北美，宾夕尼亚纪的特征是海洋沉积和阿勒格尼亚-奥卡哈塔造运动的抬升，该运动形成于大陆西部（主要是非洲西北，即现在的佛罗里达州，以及南美洲北部）变形为北美东部之时。参见造运动。

北美大部分地区经历了稳定的低洼碎屑岩平台，以海洋和陆地碎屑岩沉积为特征。这些沉积是在海平面反复上升以及冈瓦纳南极冰川沿太平洋西部推进和退缩时沉积的。宾夕尼亚地层被由砂岩、角岩和煤炭组成的海洋沉积侵蚀。

在宾夕尼亚纪，古海平面延伸从加利福尼亚州到纽芬兰，穿过西欧进入东欧的乌克兰地区，以及中国部分地区。这是裂谷带内大量煤炭形成的时期，该带也横跨古赤道南北 `15` 度。这一时期的煤炭也非常丰富且相对广泛，具有巨大的经济价值。

石油常见于宾夕法尼亚州的海洋沉积物中，特别是宾夕尼亚纪砂线海滩和礁中的碳酸盐岩，以及与海侵海岸线相关的丘状体和角岩。许多此类圈对石油的形成有显著贡献。参见地质。

# 感知 1627

作为蛋白质。谷氨酰酸是哺乳动物中最丰富的肽。催产素（`8`）、胰高血糖素（`29`）和肾上腺皮激素（`39`）等激素是肽，其结构已经变性；但实际上，氨基酸合成的生物过程正常进行。

在每一步中，一种特定的酶或复合物催化每个反应并沿着生物合成路线存在。然而，尽管未知，尽管合成生物学由许多被称为核糖体的不同细胞结构促进。核糖体需要信使 `RNA`（`RNA`）；蛋白质的生物合成是由核糖体催化的。另见：氨基酸蛋白；核糖酸（`RNA`）；核糖体。`[J.M.]`

比率（`Rate`），总是指每 `100` 中的某种手段，可以显示每 `100` 中有 `50` 的几率，而不是每 `100` 中那么多。`6%` 的比率意味着每美元有 `6` 分，而这 `6` 是在美元之外的。税额可以通过将比率乘以收益的月份来通过数学方法计算。
