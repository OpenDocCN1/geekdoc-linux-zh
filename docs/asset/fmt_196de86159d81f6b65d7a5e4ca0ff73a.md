# 任务 10.4：使用 i, a, o, 0 向文件中插入文本

在文件中移动是很有用的。然而，编辑器的实际功能是让你能够轻松添加和删除（在编辑器术语中）信息。vi 编辑有一个特殊的插入模式，你必须使用它向文件添加内容。四种进入插入模式的方法，你将在本单元学习所有它们。
