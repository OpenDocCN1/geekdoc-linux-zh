## 验证并解压归档

在解压归档之前，你应该检查其签名以确保没有被篡改。Linux 归档中的文件经过 OpenPGP 签名，你可以使用这些数字签名证明你是从归档下载的。当前的 Linux 内核归档 OpenPGP 密钥可以从 `http://www.kernel.org/signature.html` 获取。
