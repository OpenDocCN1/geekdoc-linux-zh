# 使用数据库表

表是数据库系统的主要构建模块。表存储了你所有的信息。数据库的所有其他部分都使用存储在表中信息来工作。查询在表中搜索以找到你正在寻找的精确记录，或关联一系列表之间的信息。你可以使用 `Applix Data` 对表进行各种更改：添加信息、编辑现有信息或删除信息，以及对修改后的信息进行排序。
