### 流行的脚本语言：

Bourne、Bash 和 Korn shell 都是脚本语言；它们不需要编译。Perl 语言也是一种脚本语言，因为它不需要编译。相比之下，C 编程语言不是脚本语言，因为它总是需要编译。

Bourne、Bash 和 Korn shell 语言比 Perl 更容易学习。

Perl 比 C++ 或 Java 更容易学习。

如果你的脚本的第一行是 `#!/bin/bash`，那么它就是一个 bash shell 脚本。

```
#!/bin/sh -- 这是一个 Bourne shell 脚本。
#!/bin/bash -- 这是一个 Bash shell 脚本。
#!/bin/ksh -- 这是一个 Korn shell 脚本。
#!/usr/bin/perl -- 这是一个 Perl 脚本。
```

### 对速度的需求：

有时，程序执行的速度并不非常重要；但在其他时候，速度是关重要的。Bourne、Bash 和 Korn shell 程序运行得良好。对我个人来说，当我的某些脚本运行不够快，无法满足我（以及我的老板）时，我强迫自己学习 Perl。

例如，当你的程序需要处理超过 10,000 条记录时，你会发现 Korn shell 程序和 Perl 程序在处理记录的速度上有**巨大的**差异。Perl 在几秒钟内就能处理 100,000 条记录（事实上，我毫不犹豫使用 Perl 程序处理数百万条记录）。通常，当你需要在最短的时间内处理百万条记录或交易时，请使用 C、C++ 或 JAVA。

### 如何创建并执行脚本：

- 1. 使用 `vi` 文本编辑器创建你的脚本：
`vi /tmp/myscript.ksh`
另参阅：[如何使用 UNIX-LINUX vi 文本编辑器]，这是 Larry L. Smith 写的另一本书：LarrySmithBooks.com
- 2. 使你的脚本具有可执行权限：
`chmod 755 /tmp/myscript.ksh`
或者
`chmod +x /tmp/myscript.ksh`
另参阅：`chmod ./myscript.ksh`（在本书中）。
- 3. 检查你的脚本是否包含语法错误：
`ksh -n /tmp/myscript.ksh`
如果该命令没有输出，则说明你没有严重的错误。
- 4. 执行（运行）脚本：
`/tmp/myscript.ksh`
