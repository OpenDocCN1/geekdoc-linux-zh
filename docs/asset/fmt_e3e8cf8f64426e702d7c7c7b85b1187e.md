
从 `bin/cue` 到 `iso/cdr/wav` 的 CD 格式转换器。`bchunk` 包包含 `BinChunker` 程序的 UNIX/重写版本。`BinChunker` 将 `.bin/.cue`（有时为 `.raw/cue`）的 CD 镜像转换为一组 `iso` 和 `.cdr/wav` 轨道。`.bin/.cue` 格式被某些非 UNIX CD 刻录软件使用，但在其他 CD 刻录程序上不支持。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## BCPL

基础组合语言。由 Martin Richards 于 1967 在剑桥开发。它以其语法、编译器体积（仅 16k）和极高的移植性而闻名。它在很早期就达到了平衡点，而且原始世界的语言非常棒。它被发布到了许多不同的系统中。它只有一种数据类型（字），可以用作整数、字符、浮点或指针或任何内容。BCPL 是 C 语言的前身，继承了它的许多特性。字典 `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
