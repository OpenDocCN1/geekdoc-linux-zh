### Terraform 命令

这是你运行初始化 `terraform` 的第一个命令。它将设置状态并下载所需的模块。

```bash
terraform init
```

### Terraform plan

`plan` 命令将验证我们是否连接并显示 Terraform 想要做的更改。这是一个很好的命令，如果你对云环境运行 Terraform，你会运行 `plan` 来验证你的服务器与代码保持同步。

### Terraform apply

这是执行更改的命令。计划：1 个添加，0 个更改，1 个删除。

