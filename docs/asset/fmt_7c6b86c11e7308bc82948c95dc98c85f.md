## asp

发现动态连接主机的当前地址。`Asp` 发现动态分配 IP 地址的主机的当前 IP 地址。当你想要连接到动态主机或寻找其他主机（在这种情况下你运行 `asp` 服务器）时，这非常有用。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/linux-Dictionary/html/index.html

## aspell

更智能的 `ispell` 替代品是一种交互式拼写检查器，旨在最终替代 `ispell`。它在提供可能的建议方面比 `ispell`（在某些情况下比 Microsoft Word 97 拼写检查器）做得得多。它还支持非英语。`aspell` 可以从拼写错误中学习。`aspell` 设计为 `ispell` 的直接替换品。此包带有一个最小的映射。如果你需要更详细的文档，应该安装 `aspell-doc` 包并读取 `/usr/share/doc/aspell-doc` 中的文档。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/linux-Dictionary/html/index.html

## aspell

一种旨在最终替代 `ispell` 的拼写检查器。`Aspell` 的主要优势（相对于 `ispell`）是具有更大的纠正拼写能力。`Aspell` 包含了对非英语语言的编译和运行时支持，并可以检查 `(La)TeX` 文件。来自 Redhat 8.0 RPM http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## aspell

GNU `Aspell` 是一种旨在最终替代 `ispell` 的免费开源拼写检查器。它可以作为库，也可以作为独立的拼写检查器。它的主要特性是在提供可能的建议方面，比英语的任何其他拼写检查器（包括 `Ispell` 和 Microsoft Word）做得得多。它相比 `ispell` 有许多增强，使用共享内存处理字典，并智能地在一个 `Aspell` 进程打开时处理个人字典。来自 Mandrake 9.0 RPM http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### Astaro Security Linux
