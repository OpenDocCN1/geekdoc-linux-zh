在 Bourne shell 中，函数的定义是通过提供一个名称后跟一对左括号和右括号完成的。使用大括号 `{}` 来标记函数体的开始和结束。

通过直接输入其名称来调用函数：

`print_menu`

`sleep`、`read` 和 `exit` 命令执行其名称所蕴含的功能。

## sleep 命令

`sleep` 命令导致 shell 脚本在执行时按参数指定的秒数进行暂停。

```bash
sleep 2
```

## read 命令

`read` 命令用于从标准输入读取内容并赋值给变量。

```bash
read
```

## exit 命令

`exit` 命令退出 shell 脚本。

```bash
exit 0
```
