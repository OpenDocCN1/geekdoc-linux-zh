
@list = qw(a b c d d a e b a b d e f);

1 %uniq = keys %{{ map { $_ => 1 } @list }};

2 print "@list\n@uniq\n";

```
**（输出）**
a b c d d a e b a b d e f
e c a b d f
```

### 解释

- 1. `map`函数遍历`@list`数组中的值，创建一个哈希，其中`@list`中的每个元素都成为未命名哈希的一个键（`$_`），每个键被赋予对应的值1。哈希创建完成后，内置的`keys`函数返回唯一键的列表，该列表被赋值给数组`%uniq`。
- 2. 原始列表`@list`和新列表`@uniq`都被打印出来，表明原始列表中的重复值已被移除。

## 5.4.5 按键和值排序哈希

对哈希进行排序时，使用内置的`sort`命令可以非常方便地按字母顺序排序键，正如我们在前一节中对数组所做的那样。但你可能希望按键进行数值排序，或者按哈希的值进行排序。这需要做一些额外的工作。

你可以定义一个子程序来比较键或值。（参见第11章，“子程序如何工作？”）该子程序将被内置的`sort`函数调用。它将接收一个待比较的键或值的列表。比较可以是ASCII（字母顺序）比较或数值比较，具体取决于所使用的运算符。`cmp`运算符用于比较字符串，`<=>`运算符用于比较数字。保留的全局标量`$a`和`$b`在子程序中用于存储正在比较的值。这些标量的名称不能更改。

**按升序对哈希的键排序。** 对哈希中的键执行ASCII或字母顺序排序相对简单。Perl的`sort`函数接收一个键列表，并返回按升序排列的排序结果。使用`foreach`循环逐个遍历哈希的键。

### 示例 5.49

```perl
# (在脚本中)

use warnings;

1 my %wins = (
        "Portland Panthers"   => 10,
        "Sunnyvale Sluggers"  => 12,
        "Chico Wildcats"      => 5,
        "Stevensville Tigers" => 6,
        "Lewiston Blazers"    => 11,
        "Danville Terriors"   => 8,
    );

2 print "\n\tSort Teams in Ascending Order:\n\n";

3 foreach my $key(sort keys %wins) {
    printf "\t%-20s%5d\n", $key, %wins{$key};
}
```

**（输出）**

Sort Teams in Ascending Order:

Chico Wildcats            5
Danville Terriors         8
Lewiston Blazers          11
Portland Panthers         10
Stevensville Tigers       6
Sunnyvale Sluggers        12

### 解释

- 1. 一个名为`%wins`的哈希被赋予了键值对。
- 2. `foreach`循环将用于遍历来自名为`%wins`的哈希的按字母顺序排序的键列表中的每个元素。
- 3. `printf()`函数格式化并打印排序后的键及其值。

**按降序对哈希的键排序。** 要按字母顺序降序对哈希的键进行排序，只需在前一个示例中添加内置的`reverse`函数。在反向排序后，使用`foreach`循环逐个获取哈希中的键。

### 示例 5.50

```perl
# (在脚本中)

use warnings;

1 my %wins = (
  "Portland Panthers"   => 10,
  "Sunnyvale Sluggers"  => 12,
  "Chico Wildcats"      => 5,
  "Stevensville Tigers" => 6,
  "Lewiston Blazers"    => 11,
  "Danville Terriers"   => 8,
);

print "\n\tSort Teams in Descending/Reverse Order:\n\n";

2 foreach $key (reverse sort keys %wins) {
3 printf "\t%-20s%d\n", $key, %wins{$key};
}
```

**（输出）**
Sort Teams in Descending/Reverse Order:
   Sunnyvale Sluggers   12
   Stevensville Tigers   6
   Portland Panthers     10
   Lewiston Blazers      11
   Danville Terriers     8
   Chico Wildcats        5

### 解释

- 1. 一个名为`%wins`的哈希被赋予了键值对。
- 2. `foreach`循环将用于遍历哈希中的每个元素。`reverse`函数接收来自`sort`函数的按字母顺序排序的列表并将其反转。
- 3. `printf()`函数格式化并打印键和排序后的值。

**按数值对哈希的键排序。** 使用用户定义的子程序来按数值对哈希的键进行排序。在子程序中，Perl的特殊变量`$a`和`$b`用于存储正在比较的值，并使用相应的运算符。对于数值比较，使用`<=>`运算符；对于字符串比较，使用`cmp`运算符。`sort`函数会将键列表发送给用户定义的子程序。排序后的列表随后被返回。

### 示例 5.51

```perl
# (在脚本中)

use warnings;

1  sub desc_sort_subject {
2      $b <=> $a;  # 数值降序排序
   }

3  sub asc_sort_subject{
4      $a <=> $b;  # 数值升序排序
   }

5  my %courses = (
      "101" => "Intro to Computer Science",
      "221" => "Linguistics",
      "300" => "Astronomy",
      "102" => "Perl",
      "103" => "PHP",
      "200" => "Language arts"
   );

6  print "\n\tCourses in Ascending Numeric Order:\n";
7  foreach my $key (sort asc_sort_subject(keys %courses)) {
      printf "\t\t%-5d%s\n", $key, $courses{$key};
   }

8  print "\n\tCourses in Descending Numeric Order:\n";
   foreach my $key (sort desc_sort_subject(keys %courses)) {
      printf "\t\t%-5d%s\n", $key, $courses{$key};
   }
```
