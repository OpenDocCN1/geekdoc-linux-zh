
# 红树林群落

红树林群落的植物属于许多不同的属和科，其中许多在系统发育上并不密切相关。然而，存在各种形态、生理和生殖适应性，使它们能够在不稳定、恶劣和咸涩的环境中生长。全世界公认约80个属于红树林的植物物种，分布在超过20科的约30个属中。约60个物种出现在非洲和澳大利亚的东海岸，而约20个物种出现在西半球。在属级别，`Avicennia`（榄仁树属）和 `Rhizophora`（红树属）是全世界红树林群落的优势植物，每个属在两个半球都有几个密切相关的物种。然而，在物种级别，只有少数物种，如 portia 树（`Thespesia populnea`）、红树蕨（`Acrostichum aureum`）和沼泽锦葵（`Hibiscus tiliaceus`），出现在两个半球。

红树林群落通常以平行于海岸线的方式显著分带，从开放水域到向陆边缘呈现不同优势物种的序列。这些分带是单个物种对潮间带区域淹没频率、积水、养分可用性和土壤盐浓度梯度的响应，而非如早期研究建议的那样反映生态演替。参见“生态演替”。

红树林群落的大多数植物是盐生植物，很好地适应了盐水和潮汐水平变化。许多物种显示出改化的根结构，如支柱根或气生根，在半液态或移动的沉积物上提供支撑，而其他物种具有直立的根结构（呼吸根），有助于在缺氧环境中使氧气渗透到根部。盐腺存在于几个物种中，允许多余的盐通过叶片排出；其他物种则显示出一系列生理机制，要么将盐排除在植物之外，要么通过将其与植物的敏感酶系统分离来最小化过量盐造成的损害。几个物种具有发达的胎生现象，即子叶在果实仍附着在树上时发育。幼苗通常具有浮力，能在海中漂浮长距离，一旦在适宜栖息地搁浅就能迅速建立。参见“植物”；“咸水环境”。

红树林可以被视为一种受保护的、泥质的潮间带栖息地，或一种森林群落。红树林群落的沉积物表面物种丰富，具有海洋亲缘关系，包括色彩鲜艳的招潮蟹、筑堆的泥螯虾以及各种软体动物和蠕虫，以及特化的虾虎鱼（弹涂鱼）。红树林之间的水道是各种幼鱼和甲壳类的重要觅食和育苗区。与红树林相关的具有森林亲缘关系的动物包括蛇、蜥蜴、鹿、老虎、吃蟹猴、蝙蝠和许多鸟类。

在经济上，红树林是木材、电线杆、茅草和燃料的主要来源。一些树的树皮用于制革材料，而其他物种具有食物或药用价值。参见“生态群落”；“森林管理”。 [Psae.]

## 流形（数学）

具有某个整数 `n` 维坐标卡图册的豪斯多夫拓扑空间。整数 `n` 被称为流形的维度。如果 `M` 是一个豪斯多夫空间，`M` 上的 `n` 坐标卡是 (`U`, `phi`) 这一对，其中 `U` 是 `M` 的开子集，`phi` 是 `U` 到 `n` 维欧几里得空间 `R^n` 开子集 `phi(U)` 的拓扑同胚映射。`M` 的 `n` 维图册是 `n` 坐标卡 (`U_i`, `phi_i`) 的系统，使得集合 `U_i` 的并集是整个 `M`。参见“拓扑学”。

术语“坐标卡”和“图册”源于地理学家对地球表面的观察方式。在这种情况下描述的流形是二维的，其中 `M = S^2`。

许多数学家在流形的定义中包含额外的限制——有时底层拓扑空间是连通的，有时拓扑由度量给出，有时两者兼有。

在流形上具备适当的额外结构时，可以谈论实值函数的可微性或光滑性。在这种设定下，可以定义光滑流形之间的光滑映射概念，并且可以引入光滑映射的微分，它是导数的推广。

图册中两个坐标卡 (`U_i`, `phi_i`) 和 (`U_j`, `phi_j`) 在定义光滑性时是兼容的，如果映射 `phi_j circ phi_i^{-1}` 从 `R^n` 中的开集 `phi_i(U_i cap U_j)` 到开集 `phi_j(U_i cap U_j)` 是无限可微的，并且具有无限可微的反函数。

如果图册中的所有坐标卡彼此兼容，则该图册确定 `M` 上的一个可微结构，并配备其图册的 `M` 随后被称为光滑流形。如果问题中的所有坐标卡彼此兼容，则两个图册确定相同的可微结构。光滑流形也被称为可微流形、微分流形和 `C^infty` 流形。

坐标卡兼容性的其他定义导致其他类的流形。因此，流形及其图册被称为分片线性（PL）或实解析的，如果其所有映射 `phi_j circ phi_i^{-1}` 具有相应的性质。

如果维度 `n` 是偶数，比如 2*m`，那么 `R^n` 中的开集可以被视为复空间 `C^m` 中的开集。如果映射 `phi_j circ phi_i^{-1}` 是多元解析函数，则配备其图册的流形被称为维度为 `m` 的复流形。复流形用于代数几何中簇的研究。参见“代数几何”；“复数和复变函数”；“级数”。 [A.W.K.]

## 压力计

一种双管液柱仪表，用于测量两种流体压力之间的差值。微压计是精密仪器，通常测量从极低压力到50毫米汞柱（6.7千帕）的压力。

气压计是压力计的一种特殊情况，其中一个压力为零绝对压力。参见“气压计”。

*U型管压力计。*

各种类型的压力计与U型管压力计有许多共同点，U型管压力计由一个空心管（通常是玻璃的）、部分填充管内的液体，以及一个测量一个液面相对于另一个液面高度的刻度尺组成（参见插图）。如果该压力计的支管连接到不同的压力源，液体将在压力较低的支管中上升，在另一支管中下降。液面高度差是施加压力和加压及填充液体的比重的函数。

井式压力计有一个支管直径相对较小，第二个支管是一个储液池。储液池的横截面积可以是垂直支管的1500倍，使得储液池的水平面在压力变化时不会发生明显变化。默卡托气压计通常制成井式压力计。

倾斜管压力计用于测量低于10英寸（250毫米）水柱差的表压。井式压力计的支管从垂直方向倾斜以延长刻度。倾斜双管U型管压力计也用于测量非常低的差压。参见“压力测量”。 [H.J.T.]

## 人造纤维

由天然或合成化学物质生产的若干纺织纤维之一；后者也被称为合成纤维。人造纤维的天然来源包括植物纤维素和蛋白质、橡胶、金属和非金属无机物。合成纤维由源自石油、煤和天然气的有机中间体生产。参见“天然纤维”；“纺织品”。

除了玻璃和金属纤维外，人造纤维都是由称为线性聚合物的非常长的链状分子制成的。这些聚合物可能是天然存在的（来自棉花或木浆的纤维素）或合成的（聚酯）。无论其化学性质如何，成纤聚合物必须具备以下特征：

- (1) 很长的长度——链中必须连接至少200个单体单元；
- (2) 高度的分子内和分子间吸引力，无论是通过初级化学键还是其他吸引力；
- (3) 能够沿纤维轴取向；以及
- (4) 形成有序晶体或准晶体的能力。

所有这些参数都对聚合物的化学性质和人造纤维的性能敏感。反过来，它们确立了纤维的特性，如强度、柔韧性、回弹性和耐磨性，这些特性有助于其在服装、家居用品以及商业和工业应用中的各种最终用途中的实用性。参见“聚合物”。

只有少部分能够形成纤维的物质证明具备商业成功所需的所有特征。美国主要重要的人造纤维类型按成分分类如下：纤维素（由再生纤维素、二乙酸纤维素和三乙酸纤维素组成）；合成纤维（由聚酰胺、聚酯、聚丙烯酸、聚乙烯基和聚烯烃树脂组成）；和无机物（由玻璃和金属组成）。

所有人造纤维都根据相同的原则生产：

- (1) 成纤材料首先必须制成流体；
- (2) 流体在压力下被强制（挤出）通过小孔进入使其固化的介质；以及
- (3) 固态纤维经过进一步加工以获得最佳性能。

通常使用这些程序之一来生产纤维。例如，在湿法纺丝中（如通过粘胶法生产人造丝），聚合物溶解在适用的试剂中形成流体（纺丝液）。然后，流体通过含有许多小孔的金属板（喷丝板）泵入适当组成的液体浴中。纺丝液和浴液之间的化学反应导致纤维固化。在干法纺丝中，聚合物再次溶解在适当的溶剂中并通过喷丝板挤出。然而，液体纺丝液被一股温暖气体（通常是空气）取代，蒸发溶剂并允许聚合物作为丝状物固化。二乙酸纤维素和三乙酸纤维素以此方式生产。

在熔融纺丝中，尼龙、聚酯和其他热塑性塑料...

纤维是通过熔融纺丝法生产的。由于聚合物可以被熔化成可接受的分解形式，因此不需要溶剂或试剂。因此，流体由热的熔融聚合物组成，当被挤入冷气流时，会固化为丝状物。根据模具的不同，纤维可制成各种尺寸，从比人类头发更细到牙刷用的粗刷毛。它们还可以制成不同的横截面形状，如圆形、叶瓣形、方形或狗骨形。

挤出后，纤维通常会被拉伸（拉紧）。拉伸通过延伸纤维分子使其更紧密地堆积，从而提高了有序度（结晶度），并使分子沿纤维的纵向轴取向。更高的取向度和增加的结晶度会提高纤维的强度，减少其伸长，并改善其弹性。

通常，人造纤维会经过起毛处理以改善其舒适度。由光滑、直的纤维纱线制成的织物不如由较短的天然纤维纺成的纱线制成的织物舒适。起毛处理在纤维长度上引入不规则性（卷曲），使纤维纱线更加蓬松，其性能更接近于纺纱。

聚合物和纤维技术的进步促使开发出具有极高耐温性和极高强度的纤维。这些特性在飞机和其他大众交通工具的室内装潢和地板覆盖物、消防员和其他紧急人员的防护服、士兵和警察的防弹衣、消防、运动和工业传送带等应用中是理想的。
