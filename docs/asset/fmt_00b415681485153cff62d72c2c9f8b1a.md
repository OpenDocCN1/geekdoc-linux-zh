# 第12章 软件安装与管理

在许多其他发行版中已预装。如果有必要，你可以从发行版的软件包仓库中获取最新版本。

与 `apt-get` 类似，服务器端命令 `yum-arch` 会从大量软件包（通常是整个发布版本）编译头头信息数据库。然后，该头数据库通过 HTTP 或 FTP 在软件包之间共享。客户端使用 `yum` 命令来获取和安装软件包；`yum` 会计算完成请求包安装所需的任何额外工作。如果请求的包依赖其他包，`yum` 将下载并安装这些包。
