
通常，最稳定的配合物具有中心金属离子的最大配位数。在极端情况下，所有配体都是惰性的，因此观察不到配合物的形成。对于二价金属离子尤其如此，因为金属与配体形成非常稳定的盐。参见化学键；磁化学；固态化学；立体化学。

# 配位络合物

一类化学化合物，其中分子结合的一部分是配位共价键类型。关于配位键的性质以及配合物的稳定性和反应性讨论。参见螯合；配位化学。

配位络合物包含一个中心原子或离子以及环绕它的一组离子或分子。许多简单的水合物，如`MgCl₂ · 6H₂O`，最好表述为`[Mg(H₂O)₆]Cl₂`，因为已知6个水分子环绕中心镁离子。因此，`[Mg(H₂O)₆]²⁺`是一个复杂离子，`[Mg(H₂O)₆]Cl₂`是一个复杂化合物。复杂离子的电荷为+2，因为这是镁离子的电荷，且配位水分子是中性的。然而，如果配位基团带电，那么复杂物的电荷由金属的电荷和配位离子的电荷之和表示。例如，参见下列铂(IV)配合物电荷的变化。

- `[Pt(NH₃)₆]Cl₄` 六氨合铂(IV)氯化物
- `[Pt(NH₃)₅Cl]Cl₃` 五氨合氯铂(IV)氯化物
- `[Pt(NH₃)₄Cl₂]Cl₂` 四氨合二氯铂(IV)氯化物
- `[Pt(NH₃)₃Cl₃]Cl` 三氨合三氯铂(IV)氯化物
- `[Pt(NH₃)₂Cl₄]` 二氨合四氯铂(IV)
- `K[Pt(NH₃)Cl₅]` 五氯合氨铂(IV)酸钾
- `K₂[PtCl₆]` 六氯合铂(IV)酸钾

因此，`[Pt(NH₃)₆]⁴⁺`的电荷为+4，因为Pt是+4且NH₃是中性的。但`[PtCl₆]²⁻`的电荷为−2，因为Cl⁻有6个，即+4 − 6 = −2。

金属配合物表现出各种类型的异构现象。在很多方面，无机立体异构与在有机化合物中观察到的相似。几何异构体在配位数为4和6的惰性配合物中很常见。参见立体化学。

仅包含一种配体的金属配合物的合成通常涉及金属盐在水溶液中与过量的配体试剂的反应，如下所示。

```
Ni(H2O)6(NO3)2 + 6NH3 → [Ni(NH3)6](NO3)2 + 6H2O
```

然后通过去除水分直到结晶，或添加与水混溶的有机溶剂使其分离，从而分离出所需的配合物盐。对于惰性配合物（反应缓慢的那些），通常需要对更剧烈的条件进行长时间处理。几何异构体的制备要困难得多，在大多数情况下，使用的方法相当经验性。通常，反应产生顺-反产物的混合物，这些混合物根据它们的溶解度差异进行分离。参见胺；水合物。 [FBA]

# 桡足类

甲壳动物亚纲的一个类群，有8个目。有超过6000种，其中大多数在水生环境中自由生活，尽管许多是寄生于其他水生动物或与其共生的。自由生活的形式是海洋中所有动物中最丰富的，直接构成了大量鱼类、许多无脊椎动物以及有时须鲸的主要食物。

桡足类的结构虽然基本模式相似，但变化很大（见插图）。在自由生活的形式中，身体外部由一系列小的几丁质圆柱体或节组成，其中一些可能或多或少融合在一起。头部有两对触角。取食附肢包括一对大颚、两对小颚和一对颚足。胸部由六个节组成，带有游泳足。腹部由一到五个节组成，除了称为尾叉的一对末端突起外，没有附肢。性别分离，且经常出现雌雄二型性。自由生活的物种通常长度在小于0.02英寸（0.5毫米）到约0.4英寸（10毫米）之间。

自由生活的桡足类。(a) 布氏桡足虫，一种桡足目。(b) 剑水蚤，一种剑水蚤目。(c) 桡足虫，一种桡足目。

三个目，桡足目、剑水蚤目和桡足目，完全或主要是自由生活的，由于数量压倒性多，具有最大的普遍兴趣。

在成体状态下，其余的目（异形口目、长吻目、异形虫目、杂类目和莫尔摩尼亚目）至少在其生活的一部分时间内是寄生的。它们的数量相对较少，但作为“鱼虱”可能很明显并很重要，深入钻入肉中或在皮肤和鳃外部取食。参见桡足目；剑水蚤目；杂类目；异形虫目；莫尔摩尼亚目；异形口目；长吻目。

桡足类的栖息地非常多样化，但绝大多数物种生活在海里。这些在整个生命周期中大多是浮游生物，一些仅出现在沿海水域，而其他生活在开阔海洋。许多仅在约650–1000英尺（200–300米）深度的上层水域频繁出现。其他是深海性的，生活在深处。然而，桡足目主要是底栖的，或居住在底部的类群，尽管许多确实是浮游的。

桡足类在海洋经济中的作用主要包括将植物转化为动物物质。许多物种适应直接取食有机物主要合成者，即构成海洋巨大牧场的微观硅藻和甲藻。一些物种捕食其他桡足类、鱼类幼虫和其他小动物，如原生动物。通常，桡足类占浮游动物的70%左右，有时它们的数量如此之多，以至于使海水呈现粉红色。参见海洋生态学。 [H.C.V.]

# 共聚物

一种大分子，其中两种或多种不同的单体物种被整合到聚合物链中。共聚物的性质取决于单体的性质及其在聚合物中的分布。因此，单体A和B可以随机聚合形成ABBAABABA；它们可以交替形成ABAB；它们可以形成

块体 AAAABB；或者一种单体可以接枝到另一种聚合物的链上：

```
AAAA
B
```

共聚物可以通过所有已知的聚合方法来制备：乙烯基单体的加聚（通过自由基、阴离子、阳离子或配位催化）、开环聚合，或缩聚。参见[聚合](https://example.org/polymerization)。

在两种单体 `M1` 和 `M2` 的聚合中，单体可以加接到以任一单体结尾的生长链上，分别记为 `M1*` 和 `M2*`。一阶近似下，只有生长链的末端基团是重要的，因此可以定义两个活性比：`r1` 是链末端 `M1*` 对单体 `M1` 和 `M2` 的相对活性，`r2` 是链末端 `M2*` 对单体 `M1` 和 `M2` 的相对活性。活性比可以通过分析不同单体投料下的聚合物组成来实验测定。参见[丙烯腈](https://example.org/acrylonitrile)；[聚丙烯腈](https://example.org/polyacrylonitrile)；[聚合物](https://example.org/polymer)。

## 铜

一种化学元素。`Cu`，原子序数 29，原子量 63.546。铜是一种有色金属，是地壳中丰度第二十高的元素，平均含量为 68 百万分之一（每短吨 0.22 磅或每公吨 0.11 公斤）。铜金属和铜合金由于其综合的电气、机械和物理性能而具有重要的技术意义。发现接近价态的 `Cu2(CuCl)` 簇在高达 125 K（`−134°F`）的温度下表现出超导性（零电阻）（液氮是一种廉价的冷却剂，在 90 K 或 `−297°F` 时沸腾），这引发了激烈的国际竞争，以理解这些新材料并开发技术应用。虽然自然界中存在一些纯铜金属，但商业铜是通过还原矿石中的铜化合物，然后进行电解精炼获得的。铜的丰富化学性质主要限于 `Cu(I)` 和 `Cu(II)` 价态；含有 `Cu(0)`、`Cu(III)` 和 `Cu(IV)` 的化合物很少见。可溶性铜盐在低浓度下是强效的杀菌剂和平藻剂，但在高剂量下对人类有毒。然而，铜是一种必需微量元素，存在于植物和动物生存所必需的各种金属蛋白中。参见[铜矿物](https://example.org/copper_minerals)。

铜位于元素周期表中镍和锌之间，属于第一行过渡元素，并与所谓的“货币金属”其他成员（银和金）位于同一副族。单质铜的电子构型为 `[1s² 2s² 2p⁶ 3s² 3p⁶]3d¹⁰4s¹` 或 `[氩]3d¹⁰4s¹`。乍一看，唯一的 4s 电子可能暗示其与钾（具有 `[氩]4s¹` 构型）在化学性质上相似。然而，金属铜与金属钾截然不同，其反应性相对较低。相对于钾，铜的核电荷较高，但这并未被 10 个额外的 d 电子完全屏蔽，结果导致铜的 4s 电子具有比钾更高的电离势（分别为 745.5 和 418.9 千焦/摩尔）。此外，铜的第二和第三电离势（分别为 1958.1 和 3554 焦耳/摩尔）远低于钾，这解释了过渡金属化学相对于碱金属化学在更高价态可及性方面的优势。参见[元素周期表](https://example.org/periodic_table)；[过渡元素](https://example.org/transition_elements)；[价态](https://example.org/valence)。

铜是一种相对较重的金属。纯固体在 20°C (68°F) 下的密度为 8.96 g/cm³ (5.18 oz/in³)。商业铜的密度随制造方法而异，平均为 8.90–8.92 g/cm³ (5.14–5.16 oz/in³) 对于铸造精炼形状，退火韧性强铜为 8.93 g/cm³ (5.16 oz/in³)，无氧铜为 8.94 g/cm³ (5.17 oz/in³)。液态铜在凝固点附近的密度为 8.22 g/cm³ (4.75 oz/in³)。

铜的熔点为 1083.0 ± 0.1°C (1981.4 ± 0.2°F)。其常压沸点为 2595°C (4703°F)。铜在 20°C 下的线性膨胀系数为 `1.65 × 10⁻⁵/°C`。
