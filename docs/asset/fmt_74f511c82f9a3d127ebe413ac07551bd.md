# 符号链接与硬链接

符号链接和硬链接可以通过 `ln` 命令创建。符号链接和硬链接通过 `link()` 和 `symlink()` 系统调用来实现，本章展示了它们的用法：

```
#include <sys/stat.h>
(const char *path, mode_t mode, dev_t dev);
```

`mode` 参数指定了要创建的文件类型，可以是以下之一：

- `S_IFIFO`: FIFO 文件（命名管道）。
- `S_IFCHR`: 字符文件。
- `S_IFDIR`: 目录文件。
- `S_IFBLK`: 块文件。
- `S_IFREG`: 普通文件。

文件访问权限也传递在 `mode` 参数中。权限是通过位或逻辑构造的，其取值与 `chmod()` 系统调用相同。
