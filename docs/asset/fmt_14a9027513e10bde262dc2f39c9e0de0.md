以下示例递归删除用户主目录下所有一周内未被访问过的 `a.out` 或 `*.o` 文件。
```
castle% $HOME -name a.out -name '*.o*' -atime +7 -exec rm \;
```
以下示例递归打印当前目录及其子目录下所有文件名，并跳过 SCCS 目录。
```
castle% find -name SCCS -prune -o -print
```
以下示例递归打印当前目录及其子目录下所有文件名，跳过 SCCS 目录的内容，但打印出 SCCS 目录本身。
```
castle% find -print -name SCCS -prune
```

castle$ if [ -n "$(find file -prune -newer file2)" ]; then printf %s

```
以下命令递归打印所有权限完全匹配用户读/写/执行，以及组和其他用户读/执行权限的文件名。
```
castle% find -perm u=rwx, g=rx, o=rx
```
你也可以在以下格式中指定命令。
```
castle find -perm a=rwx, g-w, o-w
```
以下命令递归打印所有权限包含（但不限于）其他用户写权限的文件名。
```
castle find -perm -o+w
```
`-atime`、`-ctime` 和 `-mtime` 的描述使用了以 24 小时为单位的术语。天与天之间的午夜界限不会影响 24 小时的计算。`-atime` 查找被访问过的文件，这意味着文件被读取或更改，或者目录被列出或进入。`-mtime` 查找被修改过的文件，这意味着文件以某种方式被更改，例如被编辑、移动、重命名或修订。`-ctime` 查找文件状态发生变化的文件，例如所有者更改或组更改。

以下示例查找在一天内被访问过的文件。
```
castle find . -atime -1 -print
```
假设你的磁盘最近满了，你想查找旧于不足三天的大文件。通过以下示例，你可以在主目录下搜索大小为 200c 或更大的文件。`c` 指定单位为字节。如果不加 `c`，你将指定单位为 512 字节的块。
```
castle find $HOME -size 200c -mtime -3 -user winsor -print
```
`-mtime -3` 选项查找在三天内修改过的文件。要查找在三天前修改的文件，请使用 `-mtime +3`。要查找恰好在三天前修改的文件，请使用 `-mtime 3`。

以下示例查找旧于小于六天的文件。
```
castle% $HOME -size 200c -mtime +3 -mtime -6 -user winsor -print
```
以下示例查找由 winsor 所有、且两天未未访问或在 14 天内未被修改的文件。
```
castle$ find $HOME (-atime +3 -o -mtime +14) -user winsor -print
```
以下示例对于旧于七天的文件记录核心转储，然后提示你确认是否可以删除它们。
```
castle% find /- -name core -mtime +7 -ok -exec {} \;
```

# finger — 显示本地和远程用户的信息

用法
`/usr/bin/finger [-bfhilmpqsw [username...]`
`/usr/bin/finger [-l] [username@hostname1@hostname2..@hostnamen] ...`
`/usr/bin/finger [-l] [@hostname1@hostname2..@hostnamen] ...]`

描述
`finger` 命令默认以多列格式显示关于每个登录用户的以下信息：

- 用户名。
- 用户全名。
- 终端名称（如果拒绝写入权限，则前加星号 *）。
- 空闲时间。
- 登录时间。
- 如果是远程登录，则显示主机名。

以下示例显示了不带参数的 `finger` 命令输出：
```
castle$ finger
```

## fmt — 简单文本格式化

### 概要
```
/usr/bin/fmt [-cs][-w width | -width][inputfile ...]
```

## 描述

fmt 是一个简单的文本格式化工具，通过填充和合并行来产生（最多）-w 选项指定的字符数量的输出行。默认宽度为 72。fmt 会合并作为参数列出的输入文件。如果你未指定输入文件，fmt 将从标准输入格式化文本。

输出中的空行以及单词之间的间距会被保留。为了与 nroff(1) 兼容，fmt 不填充或分割以点（.）开头的行。它不会填充或分割任何被识别为邮件头的连续非空行，其第一行必须以 From 开头。输出中的缩进会被保留，除非使用 -c 选项，否则不同缩进的行不会合并。

你也可以将 fmt 作为 vi(1) 的内联文本过滤器。以下命令重新格式化光标位置到段落结束之间的文本。
```
!)fmt
