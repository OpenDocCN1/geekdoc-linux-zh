
## 描述

使用 `fnattr` 命令更新和检查与联邦命名服务（FNS）命名对象相关的属性。该命令有四种用途：

- 添加属性或值。
- 删除属性或值。
- 修改属性的值。
- 列出属性的内容。

> 注意 — 你无法使用 `fnattr` 命令更新内置属性，例如用于用户的 `onc_unix_passwd`。这些属性的内容受底层命名服务（如 NIS+ 或 NIS）更新的影响。

## 选项

你可以在同一条命令行中组合用于添加、修改和删除属性及其值的选项。修改将按照你指定的顺序执行。

`fnattr`

任何未成功执行的修改都会终止命令行中后续的所有修改；已执行的修改将保留。未成功的的修改将作为 `fnattr` 的输出显示。

- `-a` 添加属性或为与名为 `composite-name` 的对象的属性添加值。`identifier` 是要操作的属性的标识符；除非使用 `-o` 或 `-U` 选项，否则其格式为 `FN_ID_STRING`。`value ...` 表示要添加的属性值。存储值的属性语法为 `fnattr_syntax_ascii`。
- `-A` 咨询权威源以获取属性信息。
- `-d` 删除与名为 `composite-name` 的对象相关的属性。如果不指定 `identifier`，则删除与该命名对象相关的所有属性。如果指定了 `identifier` 但没有值（`value..`），则通过标识符删除单个属性值。如果只从属性中删除，删除属性的最后一个值将意味着删除该属性本身。除非使用 `-o` 或 `-U` 选项，否则 `identifier` 的格式为 `FN_ID_STRING`。
- `-L` 如果复合名称绑定到 X/Open 联邦命名（XFN）链接，则操作指向该链接的对象的相关属性。如果不指定 `-L`，则操作与 XFN 链接相关的属性。
- `-m` 通过标识符修改与名为 `composite-name` 的对象相关的属性值。`old-value` 在指定的属性中被 `new-value` 替换。与 `composite-name` 关联的其他属性和值不受影响。除非使用 `-o` 或 `-U` 选项，否则 `identifier` 的格式为 `FN_ID_STRING`。
- `-O` `identifier` 的格式为 `FN_ID_ISO_OID_STRING`，作为 ASN.1、点分隔的整数列表字符串。
- `-s` 在覆盖模式下添加。如果已存在相同标识符的属性，则删除其所有值并用 `value` 替换。如果省略此选项，则指定属性的最终值是现有值与 `value` 的并集。
- `-U` `identifier` 的格式为 `FN_ID_DCE_UUID`，字符串形式的 DCE UUID。

### 操作数

- `composite-name`
  一个 FNS 命名对象。
- `identifier` 要操作的属性的标识符。

## 示例

### 添加

使用 `-a` 选项添加属性和值。以下命令将 `user/jane` 的 `shoesize` 值替换为 `7.5`。

```
castle% fnattr user/jane -a shoesize 7.5
```

以下命令为 `user/jane` 的 `projects` 属性中添加值 `Chameleon`。

```
castle% fnattr user/jane -a Chameleon
```

### 删除

使用 `-d` 选项删除属性和值。以下命令删除与 `user/jane` 关联的 `shoesize`。

```
castle% fnattr user/jane -d shoesize
```

以下命令从 `user/jane` 的 `projects` 属性中删除 `old_project`。

```
castle% fnattr user/jane -d old_project
```

以下命令删除与 `user/jane` 关联的所有属性。

```
castle% fnattr user/jane -d
```

### 修改

使用 `-m` 选项修改属性值。以下命令替换与 `usmith` 关联的 `projects` 属性中的 `Chameleon` 值。

```
castle% fnattr usmith -m projects Chameleon
```

以下命令是修改失败的示例。执行此命令的用户没有权限更新 `user/jane` 的属性，但允许添加新属性。命令添加了 `hatsize`，但 `dresssize -m` 失败且命令停止。

```
castle% fnattr user/jane -a hatsize -m dresssize 5 6
```

### 列出

无选项使用 `fnattr` 命令列出属性及其值。以下命令列出与 `user/jane` 关联的所有属性。

```
castle% fnattr user/jane
```

以下命令列出 `user/jane` 的 `projects` 属性的值。

```
castle% fnattr user/jane projects
```

以下命令列出 `user/jane` 的 `project` 和 `shoesize` 属性的值。

```
castle% fnattr user/jane shoesize
```

## 退出状态

- `0` 操作成功。
- `1` 操作失败。

# `fnbind` — 将引用绑定到 FNS 名称

### 概要

```
/usr/bin/fnbind [-s] [-v] [-L] name new-name

/usr/bin/fnbind -r [-v] new-name [-0 | -U]

ref-type { [-0 | -U] addr-type [-c | -x] addr-contents } ...
```

## 描述

`fnbind` 将由 `name` 名的联邦命名服务（FNS）引用绑定到名称 `new-name`。`fnbind` 的第二个概要（使用 `-r` 选项）允许使用命令行建议的参数将 `new-name` 绑定到构造的引用。

## 选项

- `-c` 以给定形式存储 `addr-contents`；不使用 XDR 编码。
- `-L` 使用 `name` 创建 X/Open 联邦命名（XFN）链接并将其绑定到 `new-name`。
- `-O` 指定标识符格式为 `FN_ID_ISO_OID_STRING`。

`fnbind`

- `-r` 使用 `ref-type` 作为引用的类型，使用一对或多个 `addr-type` 和 `addr-contents` 对作为引用的地址列表，并将此引用绑定到 `new-name`。除非使用 `-o` 或 `-U` 选项，否则将使用 `FN_ID_STRING` 作为 `ref-type` 和 `add-type` 的标识符格式。除非使用 `-c` 或 `-x` 选项，否则将 `addr-contents` 存储为 XDR 编码字符串。
- `-s` 即使 `new-name` 已经绑定也进行绑定。如果省略此选项，当 `new-name` 已经绑定，`fnbind` 将失败。
- `-U` 将标识符格式指定为 `FN_ID_DCE_UUID`，即字符串形式的 DCE UUID。
- `-v` 显示绑定到 `new-name` 的引用。
- `-x` 将 `addr-contents` 指定为十六进制字符串。将其转换为十六进制表示并存储；不使用 XDR 编码。

## 示例

以下命令将名称 `thisoriginunit/service/pr` 绑定到由 `thisoriginunit/service/printer` 定义的引用。任何绑定到 `thisoriginunit/service/pr` 的引用都会被覆盖。

```
$castle fnbind -s thisoriginunit/service/printer thisoriginunit/service/pr
```

以下示例将名称 `thisoriginunit/service/pr` 绑定到使用名称 `thisoriginunit/service/printer` 构建的 XFN 链接。

```
$castle fnbind -L thisoriginunit/service/printer thisoriginunit/service/pr
```

以下命令将名称 `thisoriginunit/service/calendar` 绑定到引用类型为 `SUNW_cal`、地址类型为 `SUNW_cal_desket_onc`、地址内容为 `staff@exodous` 的引用。

```
$castle fnbind -r thisoriginunit/service/calendar SUNW_cal

SUNW_cal_desket_onc staff@exodous
```
