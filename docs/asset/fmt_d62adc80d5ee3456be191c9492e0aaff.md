
- `-d` `[-]` 如果参数是一个目录，仅列出其名称（不列出内容）；配合 `-1` 使用以获取目录状态。

- `-f` 强制将每个参数解释为 `off -1`，并列出每个槽位找到的名称。此选项关闭 `-1`、`-t`、`-s` 和 `-r`，并开启 `-a`；顺序为项在目录中出现的顺序。

- `-F` 在目录末尾加上斜杠（`/`）、目录文件末尾加上大于号（`>`）、可执行文件末尾加上星号（`*`）、FIFO 末尾加上竖线（`|`）、符号链接末尾加上 符号（`@`）、以及 `AF_UNIX` 地址族套接字末尾加上等号（`=`）。

- `-g` 与 `-1` 相同，但不打印所有者。

- `-i` 对于每个文件，在报告的第一列打印 inode 号。

- `-l` 以长格式列出内容，给出每个文件的模式、ACL 指示、链接数、所有者、组、以字节为单位的大小以及最后修改时间。如果文件是特殊文件，大小字段包含主设备号和从设备号。如果最后修改时间是六个月以前，对于 POSIX 区域设置，将显示为“月 年 类别”格式。当 POSIX 区域设置未设置 `LC_TIME` 区域类别时，可能会使用不同的时间字段格式。六个月内修改的文件显示“月 日 时”。如果文件是符号链接，则打印文件名后跟 `-->` 和被引用文件的路径。

- `-L` 如果参数是符号链接，则列出文件或目录引用而不是链接本身。

- `-m` 流式输出格式；跨页列出文件，用逗号和空格分隔。

- `-n` 与 `-l` 相同，但打印所有者 UID 和组 GID 数字，而不是相关的字符字符串。

- `-o` 与 `-l` 相同，但不打印组。

- `-p` 如果文件是目录，在每个文件名后加上斜杠（`/`）。

- `-q` 强制将文件名中的不可打印字符打印为问号（`?`）。

- `-r` 反转排序顺序，根据情况获取反向字母顺序或最旧文件。

- `-R` 递归列出子目录。

- `-s` 按时间排序（最新优先）而不是按名称排序。默认是最后修改时间。（见 `-u` 和 `-c`。）

- `-u` 使用访问时间而不是修改时间进行排序（配合 `-t` 选项）或打印（配合 `-l` 选项）。

- `-x` 显示多列输出，并跨页对项进行排序。

- `-1` 每行输出一个项。

# m4 — 宏处理器

### 概要

`/usr/ccs/bin/m4 [-e] [-s] [-Bint] [-Hint] [-Sint] [-Tint] [-Dname =val] ... [-U name]... [file...]`

`/usr/xpg4/bin/m4 [-e] [-s] [-Bint] [-Hint] [-Sint] [-Tint] [-Dname =val] [-U name]... [file...]`

## 描述

`m4` 是 C 、汇编器和其他语言的宏处理器前端。每个参数文件按顺序处理；如果没有文件或文件为 `-`，则读取标准输入。处理后的文本将写入标准输出。

## 宏语法

宏调用的形式为：

`name(arg1, arg2, ..., arg)`

`(` 必须紧跟在宏名称之后。如果定义的宏名称后面没有 `(`，则被视为对该宏的无参数调用。潜在的宏名称由字母、数字字符和下划线 `_` 组成，其中第一个字符不能是数字。

在收集参数时，会忽略未引号的起始空格、制表符和换行符。使用左、右单引号来引用字符串。引用字符串的值是去掉了引号的字符串。

## 宏处理

当识别出一个名称时，将通过寻找匹配的右括号来收集其参数。如果提供的参数少于宏定义中的参数，则末尾参数被视为空。在收集参数期间，宏评估会正常进行，嵌套调用值内部出现的任何逗号或右括号，其效果与原始输入文本中的符号相同。参数收集完成后，宏将重新推回输入字符串并重新扫描。

## 选项

- `-e` 以交互式模式运行。忽略中断并缓冲输出。

- `-s` 为 C 预处理器启用行同步输出（`#line...`）

- `-B int` 修改回推缓冲区和参数收集缓冲区的大小，默认值为 4096。

- `-H int` 修改符号表哈希数组的大小，默认值为 199。

- `-S int` 修改调用栈的大小，默认值为 100 个槽位。宏占用三个槽，非宏参数占用一个。

- `-T int` 修改标记（token）缓冲区的大小，默认值为 512 字节。

要使上述选项生效，请将它们放在任何文件名之前，以及任何 `-D` 或 `-U` 选项之前。

```
-D name={val}
  定义 name 为 val，或在 val 缺失时为空。
-U name  取消定义 name。
```

### 操作数

- `-file` 待处理的文本文件的路径名。如果未指定文件或文件为 `-`，则读取标准输入。

## 用

`m4` 命令提供了以下内置宏。你可以重新定义这些宏，但如果你这样做了，就会失去它们的原始含义。除非另有说明，否则宏值均为空。

```
changequote 将引号符号更改为第一个和第二个参数。符号长度可达五个个字符。不带参数的 changequote 将恢复原始值（即 {}）。
```

### changecom
