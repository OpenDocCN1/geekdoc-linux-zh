
**注意：** 示例 awk 脚本假设数据的第一条输入记录是检查日期；由于如此，总行数（`NR`）并不是要发出的检查次数。我本可以使用 `NR-1`，但为了清晰放弃了简洁。

使用数组比为每个使用的元素列出单独的变量要容易得多、整洁且快速得多。这意味着当元素数量（例如员工）发生变化时，你不需要更改代码。awk 仅支持单维数组。（请参见“高级概念”章节了解如何模拟多维数组。）这一点以及其他几点使得 awk 数组区别于其他编程语言的数组。本节关注数组及其用途、特殊属性，以及帮助你处理数组的 awk 三种特性（一个内置函数、一个内置变量和一个运算符）。

awk 中的数组像变量一样，不需要声明。此外，不需要预先给出大小标示；从编程术语来说，你可以说 awk 中的数组是动态的。要创建一个数组，给它起一个名称并在名字后的方括号（`[]`）中放入下标，例如不是使用 `name2`，而是使用 `name[2]`。下标也称为数组的索引；在 `name[2]` 中，`2` 是数组名称的索引，它访问存储在位置 `2` 的那个名称。

**注意：** awk 的一个特殊之处是元素并不是按照它们输入的顺序存储的。这个 bug 在较新版本中已修复。

awk 数组与其他编程语言的数组不同，因为在 awk 中，数组下标是以字符串存储的，而不是数字。从技术上讲，这个术语是*关联数组*，这在编程语言中是不寻常的。注意，如果你纯从数值角度考虑，使用字符串作为下标可能会让你感到困惑。因为 `"3" > "15"`，下标为 `15` 的数组元素将存储在下标为 `"3"` 的元素之前，尽管在数值上 `3 > 15`。

由于下标是字符串，下标可以是一个字段值。`grade[$1]=$2` 是一个合法的语句，`salary["John"]` 也是。

## 数组特殊性

`Nawk++` 增加了专门用于数组的扩展功能。第一个是成员身份测试。假设 Mark Turner 晚期参加了我教的一门课程，我不记得是否已经把他的名字加到了电脑上保留的列表里。以下程序为我检查该列表：

```awk
BEGIN {i=1}

{ name[i++] = $1 }

END { if ("Mark Turner" in name)

 print "He's enrolled in the course!"

 }
```

`delete` 函数是一个内置函数，用于从计算机内存中删除数组元素。例如，要删除一个元素，可以使用 `delete name[1]` 命令。

**警告：** 在你从内存中删除一个元素后，它就消失了，且不会回来！如果不确定，请保留它。

尽管技术在进步，内存不再是曾经认为的那种珍贵资源，但在编写程序时，清理自己仍然是一个好习惯。想想支票打印程序。两百名字不会填满内存。然而，如果你的程序控制人员活动、开具支票和存根、添加和删除员工并绘制销售图表，最好将每个文件更新到磁盘并移除不再使用的数组。这样读取过时数据的概率更小。它还消耗更少的内存，并尽可能减少了使用旧数据数组执行新任务的概率。清理可以很容易完成：

```awk
END {i=totalemps

 while(i>0) {

 delete name[i]

 delete data[i]

 i-- }

 }
```

`Nawk++` 创建了另一个用于模拟多维数组的内置变量。“高级概念”章节中讨论了更多关于它的内容。它被称为 `SUBSEP`，默认值为 `"\034"`。要向 awk 中添加此变量，只需在你的程序中使用该名称即可：

```awk
BEGIN { SUBSEP = "\034" }
```

记住，在 awk 中，数组下标是以字符串形式存储的。由于每个列表都包含一个名称及其相关的数字，你可以匹配名称和匹配文件。

## 算术

尽管 awk 主要是用来用于模式匹配的语言，因此文本和字符串比数学和数字更容易进入脑海，但 awk 也拥有一套很好的数学工具。在本节中，我首先展示基础知识，然后讨论 awk 内置的数学函数。

### 运算符

Awk 支持常用的数学运算。表达式 `x^y` 是 `x` 的 `y` 次幂，即 `x` 的 `y` 次方。`%` 运算符在 awk 中计算余数：`x%y` 是 `x` 除以 `y` 的余数，结果取决于机器。所有数学运算使用浮点数，无论以何种格式表示，数字都是等价的，因此 `100 = 1.00e+02`。

awk 中的数学运算符由四个基本函数组成：`+`（加法）、`-`（减法）、`/`（除法）和 `*`（乘法），加上用于指数和余数的 `^` 和 `%`。正如你在最近销售中看到的，字段可以用于算术运算。如果在月中，我的老板要求一份最新的每月总额列表，我不需要为被丢弃的数字而恐慌；我只需要打印一个新的列表。我的第一次尝试似乎足够了。（参见列表 4.2。）
