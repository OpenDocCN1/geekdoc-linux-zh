为了持续传递指南以找到正确的一个。类比：如果有人偷了你的银行卡，他们无法坐在取款机前输入所有可能的 PIN 码。在尝试失败若干次后，银行取款机将“吃掉”你的卡。关键点：安全系统（Unix，Windows NT）在尝试失败若干次后会锁定账户。这些锁定可能是暂时的（并自动恢复），或者是永久的，直到管理员干预并解锁账户。关键点：非安全系统（Win9x 以及文件和共享）不会锁定账户。如果你有带有密码的 Win9x，黑客可以持续且在不察觉的情况下访问你的机器。没有任何东西被锁定。当开始暴力破解时，黑客会自己进行所有计算（与被盗的加密密码进行比较）。在进行“Gr破解”时，黑客必须一个接一个输入密码，而目标系统会进行计算以查看它们是否有效。入侵检测系统可以检测，但不能破解。源自黑客词典 http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# grmonitor

图形化进程监器（Graphical Process Monitor）显示 UNIX 系统上进程的信息。对于每个进程，它会显示 CPU 使用率、消耗内存、驻留集和空闲时间的 3D 条形图。进程按用户名分组。用户名分组位于自己的小底座上。来自 Debian 3.0.0 http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# groff

GNU 文本格式系统包含 GNU 文本格式系统的可选组件。核心包 `groff-base` 包含传统工具如 `troff`、`tbl`、`tbl`, `eq`。此包包含了额外的设备和驱动，用于输出 DV、HTML、HP 激光打印机、佳能 CANSL LP-4 和 LP-8 打印机以及 Post。此包包含描述该语言及其宏的页面、info、文档以及若干辅助包：– `gmp`，用于‘grifmlit’中图片的预处理器；– `tftmodit`，为 `groff -Tvi` 创建字体；– `hpfdotit`，为 `groff -Tja` 创建字体；– `amit`，为 `groff -Tps` 创建字体；– `refer`，其预处理器为用于 `groff` 的参考文献创建引用；– `indexbib`，通过 `ref` 为文献数据库创建倒排索引；– `Ikbib` 和 `lookbook`，用于搜索文献数据库；`groff` 为 `troff` 字体添加度量信息供 `groff` 使用；`pbtops` 将 `.pbmf` 格式的 PostScript 字体转换为 ASCII 供 `groff` 使用；`mmroff` 是一个用于扩展 `mm` 中引用的简单预处理器。支持所有标准包。来自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# groff

`groff` 是一个文档格式化系统。Groff 将标准文本和格式命令作为输入并产生输出。创建的文档可以在显示器上显示或在打印机上打印。Groff 的格式命令允许你指定字体和大小、粗体、斜体、页数和列数，如果你格式化页面，应该安装 `groff`。如果你要在 X Window 系统中使用它，还需要安装 `groff–xdxiv` 包。来自 Mandatory 9.0 RPM http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# groff-base

GNU 文本格式系统（基础系统组件）。此包包含了传统的 Unix–X 格式工具：`troff`、`tbl`、`eqn` 和 `pic`。这些实用程序配合 `man-db` 包对于显示在线手册页至关重要，`groff-base` 是一个精简包，包含了读取以 ASCII、Latin-1 和 UTF-8 格式的手册页的必要组件。想要安装包含标准设备集（字体、宏和文档）的完整安装的用户应该安装 `groff` 包。来自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/html.html

# groff-for-man

`groff-for-man` 包包含了查看手册页（manpages）所需的 groff 文本处理器部分。如需完整的 groff 包，请安装 `groff` 包。来自 Mandatory 9.0 RPM http://www.tld.org/LDP/Linux-Dictionary/html.html

# groff-x11

用于 X Window 系统的 GNU proof。此包包含 X75、X75–12、X100 和 X100–12 设备，允许 `groff` 使用标准的 X11 字体在显示器上方便地输出。这些设备使用 `gdx` 显示输出，`gdx` 也包含在内。可以使用 `xview` 使用 `groff` 查看 PostScript 输出。安装此包后，`man` 可以在图形窗口显示显示页。来自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/html.html
