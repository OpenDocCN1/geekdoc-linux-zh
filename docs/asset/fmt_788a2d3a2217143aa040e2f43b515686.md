将`HARD_SERVER_LIMIT`或`HARD_THREAD_LIMIT`更改为高于默认值时，请确保您拥有适当的系统资源。例如，将`prefork` MPM的`HARD_SERVER_LIMIT`更改为 1024 将使您能够通过指示 Apache 使用指令`StartServers`、`MinSpareServers`和`MaxSpareServers`创建该数量的子进程来创建 1024 个 Apache 子进程。

然而，如果您的系统内存不足，将硬性限制更改为更高的值不会带来太大好处。请记住，限制越高，您需要的资源越多。您还需要增加系统允许单个用户使用的文件描述符数量。在 Linux 和 Unix 系统上，您应该使用`ulimit`命令来查找（并可能设置）文件描述符限制。

另外请注意，`MaxClients`指令设置创建的用于处理请求的子进程数量的限制。当服务器在没有线程的情况下构建时，同时服务的客户端数量不能超过此数字。若要配置超过 256 个客户端，您必须编辑`mpm_default.h`中的`HARD_SERVER_LIMIT`条目并重新编译。

### 编译和安装 Apache

使用`configure`脚本配置 Apache 源代码后，您需要按照以下步骤编译和安装 Apache：

- 运行`make`命令以编译源代码。
- 运行`make install`命令，安装 `httpd` 和支持文件到你在使用`--prefix`选项时指定的目录。
- 更改到安装目录并浏览该目录。你应该能看到诸如`bin`、`cgi-bin`、`conf`、`htdocs`、`icons`、`include`、`lib`和`logs`等子目录。例如，如果你在源代码树配置过程中使用`configure`脚本时采用了`--prefix=/usr/local/apache`，那么`make install`将创建如下目录结构：

```
/usr/local/apache

+---include
+---lib
+---bin
+---conf
+---htdocs
    |
    +---manual
        +---developer
        +---howto
        +---images
        +---misc
        +---mod
        +---platform
        +---programs
        +---search
        +---vhosts
    |
+---icons
    |
    +---small
+---logs
+---cgi-bin
```
