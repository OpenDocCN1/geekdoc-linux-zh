# tbl — 为 nroff 或 troff 化表格

### 概要

`/usr/bin/tbl [-me][-mm][-ms][filename]...`

# tbl 1319

## 描述

`tbl` 命令是一个用于为 `nroff(1)` 或 `troff(1)` 格式化表格的预处理器。表格是条目的矩形排列。通过使用正确的命令，你可以创建多列表格并将它们封装在框中。`tbl` 命令会自动产生正确的列位置。输入文件名称将被复制到标准输出，但 `.TS`（表格开始）和 `.TE`（表格结束）命令行之间的行被假设为描述表格并被重新格式化。

如果你不指定任何参数，`tbl` 将读取标准输入，因此你可以将 `tbl` 作为过滤器使用。当你将 `tbl` 与 `eqn(1)` 或 `negn` 一起使用时，将 `tbl` 命令放在前面，以减少通过管道的数据量。

你通过在表格的第二行指定以逗号分隔的全局选项列表（如下文所示）来定义表格的结构。

| 选项 | 描述 |
| --- | --- |
| center | 将表格在页面上居中。 |
| expand | 将表格宽度扩展到当前行长度。 |
| box | 为整个表格画一个框。 |
| doublebox | 为整个表格画一个双线框。 |
| allbox | 为表格中的每个单元格画框。 |
| tab(x) | 使用字符 x 作为数据分隔符。 |
| linesize(n) | 设置所有行均为 n 点字号。 |

在表格结构内部，你可以按照下表所述指定列条目的格式。

| 代码 | 结果 |
| --- | --- |
| ^ | 将条目从上一行扩展到此行。 |
| a | 从左对齐向右缩进一个 em 字符。 |
| c | 数据居中。 |
| 1 | 数据左对齐。 |
| n | 按小数点或个位对齐数字。 |
| r | 数据右对齐。 |
| s | 通过通过将前一列的数据扩展到此列来跨列。 |
| t | 垂直跨越，文本位于列的顶部。 |

# tcopy — 复制磁带

### 概要

```
/usr/bin/tcopy source [destination]
```

## 描述

使用 `tcopy` 复制由 `source` 指定的磁带。磁带内容的唯一假设是结尾有标记。当你只指定 `source` 时，`tcopy` 扫描磁带并显示记录的大小。如果你指定了 `destination`，`tcopy` 将 `source` 带复制到 `destination` 带，并保留块。在复制时，`tcopy` 与仅扫描磁带产生的输出相同。注意 — `tcopy` 仅在支持关联 `ioctl(2)` 请求的系统中运行。
