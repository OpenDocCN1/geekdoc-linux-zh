## 使用 `break`, `continue`, `exit` 和 `return`

有时需要跳出 `for` 或 `while` 循环、继续执行后续代码块、完全退出脚本，或向调用函数的脚本返回结果。

`break` 用于终止整个循环的执行，执行完 `break` 语句之前的所有代码。然后它跳转到循环结束后的代码。

`continue` 用于将控制转移到下一组代码，但它继续执行循环。

`return` 用于函数向调用它的脚本发送数据，或返回结果。

## Here Document

文档用于将输入重定向到交互式 `shell` 脚本或程序。通过为交互式程序或交互式 `shell` 脚本提供输入，我们可以在没有用户操作的情况下运行交互式程序。这就是为什么被称为在这里文档。

## Here Document 的语法

```
program_name <<LABEL

程序_Input_1

程序_Input_2

程序_Input_3

程序_Input_#
```
LABEL
```

示例：

```
/usr/local/bin/My_program << EOF

Randy

Robin

Rusty

Jim

EOF
```

## 变量

变量是一个分配了赋值的字符字符串。分配的值可以是数字、文本、文件名、设备或其他任何类型的数据。变量无非是指向实际数据的指针。我们将使用变量，这样我们就不需要在脚本中硬编码值了。

## `shift` 命令

`shift` 命令用于将位置参数向左移动；例如，`shift` 会使 `$2` 变为 `$1`。我们可以在 `shift` 命令后加上数字来移动多个位置；例如，`shift 3` 会使 `$4` 移动到 `$1` 位置。

有时我们会遇到传递给 `shell` 脚本或函数的参数数量未知或不断变化的情况。使用 `shift` 命令是按列表顺序处理每个参数的好方法。为了解释 `shift` 命令，我们将展示如何处理传递给列表 1.2 所示 `shell` 脚本的未知数量参数。尝试跟踪这个示例脚本。该脚本使用 `shift` 命令处理未知数量的命令行参数（或位置参数）。

# 脚本快速上手与回顾

```bash
do |
    COUNT=`expr $COUNT +1` # 在 shell 脚本中的简单数学运算
    TOKEN='$$COUNT' # 遍历每个从 $1 开始的 token
    process each $TOKEN |
    shift # 获取下一个 token，即 $2 变成 $1
done |
```

## 特殊参数 `*` 和 `$@`

有一些特殊的参数，允许我们一次性访问*所有*命令行参数。`$*` 和 `$@` 的作用相同，除非它们被包含在双引号 `" "` 中。

## 特殊参数定义

- `*` 特殊参数指定*所有*命令行参数。
- `$@` 特殊参数也指定*所有*命令行参数。
- `"*"` 特殊参数将整个列表作为一个参数处理，中间用空格分隔。
- `"$@"` 特殊参数获取整个列表并将其拆分为独立的参数。
