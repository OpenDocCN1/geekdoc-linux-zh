    -   `<0>` - 系统不可用
    -   `<1>` - 必须立即采取行动
    -   `<2>` - 关键状态
    -   `<3>` - 错误状态
    -   `<4>` - 警告状态
    -   `<5>` - 正常但重要的状态
    -   `<6>` - 提示信息
    -   `<7>` - 调试级别消息

## 5.5 网络

### 5.5.1 建立我的家庭网络值得吗？

这是一个极佳的主意。它能让你现在衣柜里那些由于性能不足而无法独立运行的机器变得有用。益处包括共享硬盘、CD-ROM、打印机、声卡，远程运行程序，通过一个连接在所有计算机上同时浏览互联网。如果你失去了对机器的控制，你可能还可以远程关机以避免可能的问题——详情见“关机”答案。

### 5.5.2 如何设置我的家庭网络？

硬件必须正确设置。你的网卡应该在 Linux 安装期间已被检测并配置好。如果你后来添加了网卡，很可能它已经被检测到了。如果没有检测到，你可能现在需要设置网络。如果你的电脑上有一个多个网卡，你可能还需要进行其他设置。系统使用 `inetd` 的地方。

`network("广播地址")`。中间的两组数字可以是 `0` 到 `255` 之间的任意数字。`223.223.223.1` 是 C 网络 `223.223.223.0` 第一台机器（最后的 `0` 表示网络，广播地址为 `223.223.223.255`）。C 网络的子掩码为 `255.255.255.0`（除非你将网络划分为更小的“子网”，这里不进行讨论）。

与其自己发明一个 IP 号，不如使用一个为“私有网络”保留的数字可能更安全/更好。对我来说，IP 号 `192.168.1.1` 运行得很好。这样一来，你发明的 IP 地址就保证不会与世界上可能存在的任何 IP 冲突。
