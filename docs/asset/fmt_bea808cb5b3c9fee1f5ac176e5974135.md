### 11.2 嵌套循环

嵌套循环是循环中的循环，外层循环体内包含另一个循环。内层循环每次外层循环迭代都会执行。

### 示例 11-20. 嵌套循环

```bash
#!/bin/bash
# nested-loop.sh: 嵌套 "for" 循环。

outer=1
# 设置外层循环计数器。
for a in 1 2 3 4 5
do
    echo "Pass $outer in outer loop."
    echo "----------------------"
    inner=1
    # 重置内层循环计数器。
    # ===================================
    # 内层循环开始。
    for b in 1 2 3 4 5
    do
        echo "Pass $inner in inner loop."
        let "inner+=1" # 增加内层循环计数器。
    done # 内层循环结束。
    # ===================================

    let "outer++" # 增加外层循环计数器。
    echo
    # 外层循环通过块之间的空格。
done
```

## 11.4. 测试与分支

`case` 和 `select` 结构在技术上不是循环，因为它们不会迭代执行代码块。然而，循环是根据代码块顶部或底部的条件来引导程序流。

在代码块中控制程序流

`case (in) ... esac`

`case` 结构是 Shell 脚本中 C/C++ 中 `switch` 的对应物。它允许根据条件测试跳转到多个代码块之一。它作为多个 `if/else` 语句的简写形式，是创建菜单的合适工具。

```bash
case "$variable" in

  "$condition1")

    command...

    ;;

  "$condition2")

    command...

    ;;

esac
```

- 给变量加引号不是强制的，因为不会发生单词拆分。
- 每个测试行都以右括号 `)` 结束。
- 每个条件块以双分号 `;;` 结束。
- 如果条件测试为真，则执行相关命令并终止 `case` 块。
- 整个 `case` 块以 `esac`（`case` 的倒序写法）结束。

### 示例 11-25. 使用 `case`

```bash
#!/bin/bash

# 测试范围。

echo "按一个键:"

read Keypress

case "$Keypress" in

# 如上所述

  [a-z]) echo "小写字母"

  [A-Z]) echo "大写字母"

  [0-9]) echo "数字"

  *) echo "标点符号、空白或其他"

esac
```

### 示例 11-29. 检查字母字母输入

```bash
#!/bin/bash

# isalpha.sh: 使用 "case" 结构过滤字符串。

SUCCESS=0

FAILURE=-1

  # 曾经是 FAILURE=-，

  # 但 Bash 不再允许负数作为返回值。

isalpha () {

  # 测试输入字符串的*第一个字符*是否为字母。

  if [ -z "$1" ]; then

    # 没有传递参数？

    return $FAILURE

  fi

  case "$1" in

    [a-zA-Z]*) return $SUCCESS;; # 以字母开头？

    *) return $FAILURE;

  esac

}

# 与 C 语言中的 "isalpha()" 函数对比。

isalpha2 () {

  # 测试"整个字符串"是否为字母。

  [ $ -eq 1 ] || return $FAILURE

  case $1 in

    *[!a-zA-Z]*\*) return $FAILURE;

    *) return $SUCCESS;

  esac

}

isdigit () {

  # 测试"整个字符串"是否为数字。

  # 换一种顺序，则测试整数变量。

  [ $ -eq 1 ] || return $FAILURE

  case $1 in

    *[!0-9]*\*) return $FAILURE;

    *) return $SUCCESS;

  esac

}
```
