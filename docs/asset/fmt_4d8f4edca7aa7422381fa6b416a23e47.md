
打开压缩包成员并返回一个用于读取内容的文件类对象。`name` 可以是字符串或描述压缩包成员的 `ZipInfo` 实例。`mode` 是文件模式，必须是只读文件模式之一，如 `'r'`、`'ur'` 或 `'U'`。`pwd` 是用于加密压缩成员的密码。返回的文件对象支持 `read()`、`readline()` 和 `readlines()` 方法，并可以使用 `for` 语句进行迭代。

### `z.printdir()`

将压缩包目录打印到 `sys.stdout`。

### `z.read(name {, pwd=})`

读取成员名称的内容并将数据作为字符串返回。`name` 是字符串或描述压缩包成员的 `ZipInfo` 实例。`pwd` 是用于加密压缩成员的密码。

### `z.setpassword(pwd)`

设置用于从压缩包中提取加密文件的默认密码。

### `z.testzip()`

读取压缩包中的所有文件并验证它们的 CRC 校验和。返回第一个损坏文件的名称，如果所有文件均完整，则返回 `None`。

### `z.write(filename[, arcname[, compress_type]])`

使用 `arcname` 将文件写入压缩包。`compress_type` 是压缩参数，可以是 `ZIP_STORED` 或 `ZIP_DEFLATED`。默认情况下使用传递给 `ZipFile()` 或 `ZipFile()` 函数的压缩参数。必须以 `'w'` 或 `'a'` 模式打开压缩包才能写入。

### `z.writepy(pathname)`

此方法仅适用于 `ZipFile` 实例，用于将 Python 源文件 (`**.py` 文件*) 写入 zip 压缩包，并可轻松地打包 Python 进行发行。如果 `pathname` 是文件，它必须以 `.py` 结尾。在这种情况下，将添加相应的 `.pyo`、`.pyc` 或 `.py` 文件之一（按此顺序）。如果 `pathname` 是目录且该目录不是 Python 包目录，则所有相应的 `.pyo`、`.pyc` 或 `.py` 文件都将添加到顶层。如果目录是一个包，则文件将以文件路径的形式添加到包下。如果子目录也是包目录，它们将递归地添加。

## `z.writestr(arcinfo, s)`

将字符串 `s` 写入 zip 文件。`arcinfo` 是压缩包内存储数据的文件名，或者是包含文件名、日期和时间的 `ZipInfo` 实例。

## zlib

`zlib` 模块通过访问 zlib 库支持数据压缩。

### `adler32(string [, value])`

计算字符串的 Adler-32 校验和。`value` 用作起始值（可用于计算多个字符串拼接后的校验和）。否则，使用固定的默认值。

### `compress(string [, level])`

压缩字符串中的数据，其中 `level` 是 1 到 9 的整数，用于控制压缩级别。1 是快的（压缩），9 是最好的（最慢）。默认值是最小的（6）。返回包含压缩数据的字符串，或在发生错误时抛出异常。

### `decompress([level])`

返回一个压缩对象。`level` 的含义与 `compress` 相同。

### `crc32(string [, value])`

计算字符串的 CRC 校验和。`value` 用作起始值（可用于计算多个字符串拼接后的校验和）。否则，使用固定的默认值。

### `decompress([level])`

返回一个压缩对象。（注：此处原文重复了 `decompress`）

### `compress(string [, level])`

返回对象形式的数据。

### `compress(data)`

返回包含压缩文件数据的字符串。

### `decompress(data)`

解压缩数据并返回原始字符串。

## ConfigParser, configparser

Python 3 中的 ConfigParser 模块（称为 `configparser`）用于读取基于 Windows INI 格式的 .ini 格式文件。这些文件由命名节组成，每个节都有自己的变量赋值，如下所示：

```python
# A comment
; A comment
[section]
name1 = value1
name2 = value2

[section2]
; 变量变量的另一种语法
name1: value1
name2: value2
...
```

## ConfigParser 类

以下类用于管理配置变量：

```python
ConfigParser([defaults=[, dict_type]])
```

创建一个新的 `ConfigParser` 实例。`defaults` 是一个可选的值字典，可以在配置中使用字符串指定符（例如 `'%key'`）来引用这些值，其中 `key` 是 `defaults` 中的一个键。`dict_type` 指明了用于存储配置变量的字典类型。默认情况下，它是 `dict`（内置字典）。

`ConfigParser` 实例具有以下操作：

```python
c.add_section(section)
```

向存储的配置参数中添加一个新节。`section` 是一个带有节名称的字符串。

### `c.defaults()`

返回默认值的字典。

### `c.get(section, option [, raw, [vars]])`

以字符串形式从节 `section` 返回选项 `option` 的值。默认情况下，返回的字符串会通过插值步骤处理，其中如 `%(option)s` 类的格式化字符串会被展开。在这种情况下，`option` 可能会映射到同一节中另一个配置选项的，或者映射到通过 `defaults` 参数提供的默认值。`raw` 是一个布尔标志，用于禁用此插值功能，返回未经修改的选项。`vars` 是一个包含用于 `%s` 展开的值的可选字典。

### `c.getboolean(section, option)`
