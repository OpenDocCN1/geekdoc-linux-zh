# sudo

`sudo`（超级用户）允许系统管理员赋予用户（或用户组）以 root 运行某些命令的能力并记录所有命令。`sudo` 按命令操作。功能包括：限制用户在-主机之后运行的内容、记录每个命令（提供谁做了什么的清晰审计轨迹）、`sudo` 命令的可配置超时以及在许多不同的机器上使用相同的配置文件 (`sudoers`)。来自 Redhat 8.0 RPM `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## SUID

## SUID (设置用户 ID)

`SUID` 权限允许脚本以脚本所有者的身份运行，而不是以启动它的身份运行。以这种方式运行程序通常被认为是一种坏习惯，因为它可能会引发许多安全问题。后续版本的 Linux 内核将禁止运行具有此类属性的 shell 脚本。`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
