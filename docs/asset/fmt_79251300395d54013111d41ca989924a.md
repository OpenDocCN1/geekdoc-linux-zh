## 光周期性

诸如叶片的形成、根的起始、种子期叶生器或子胚钩的开启、表皮毛的发、茎部导管元素的形成以及花类配子体阶段形态的变化，仅列举这些。植物中的许多形态发生过程也受光频率控制：向光性运动、某些叶片中涉及黄酮类、花青素、叶绿素和类胡萝卜醇合成的化学反应。

**光子**是一种可以描述为电磁辐射的实体。根据经典电磁学，任何数量的能量都可以连续传输。在辐射量子理论中，能量是以离散的形式传递的。光子的能量是其频率与普朗克常数的积。除了能量外，光子还拥有自旋成正比的角动量。（角动量；能量，光子；自旋（量子力学））。

## 光倍增管

光倍增管由一个真空管组成，它可以将光或辐射通量转换为电子；一个或多个二次发射光阴极或倍级极，用于放大电子数量；以及一个收集电子并提供输出信号的阳极。这一过程被称为光电效应。由于极大的放大机制，二次发射相对于管内电子的通过要快得多，因此光倍增管是用于快速计时实验的理想设备，特别是在需要快速响应的情况下。

插图显示了光电检测的典型设置。从光阴极发射的电子数量取决于入射光的强度。光电流发射的效率称为量子效率，相对于入射光子进行测量。光电子在加速电场的引导下到达第一个倍级极，根据动量守恒，取决于材料和外电压，在那里产生 3 到 30 个电子。二次电子被引导向第二个倍级极，该过程重复，直到最后一个倍级极产生的倍增电子被阳极收集。

原子中电子对 X 线的散射提供了光子行为的另一种证明。电子因为入射光子的动量而发生回弹，因此散射 X 线的频率和波长发生了变化。如果 X 线通过中心原子散射，其波长将由这种散射决定的量发生偏移。电子的能量由动量守恒决定。参见康普尔效应。

从更基础的观点来看，光子是电磁场的量子。此类场中电场和磁场的麦克斯韦方程解对应于谐振子的解。根据量子理论，振荡器的能量由 $(n+1/2)hf$ 给出，其中 $h$ 是振荡频率，量子数是 $n=0, 1, 2, ...$。这种量子关系最早由普朗克针对热环境中原子的分子碰撞提出，以获得热场辐射密度的正确形式，也被爱因斯坦提出，以解释辐射场的本质和场中光子的数量。参见谐振子；非相对性量子理论；电动力学；量子力学。

典型的光倍增管可能具有 10 级二次发射，并可以在 2000 V 的过电压下运行。级之间的电流由电极成形状的静电场引导。一些为高电压设计的特殊光倍增管使用交叉电磁场引导电子在级之间沿圆周路径运动。

自发明以来，光倍增管一直有效地用于光度法和光谱学。最重要的应用是粒子计数，这些构成了整个示踪化学科学的基础，该科学已应用于农业、医学和工业问题。在医学中，光倍增管闪烁计数器用于伽马射线探测器和正电子扫描仪。参见计算机断层；伽马射线探测器；核医学；放射性；闪烁计数器。

光周期是指生物对昼夜长度的生长、发育或响应。植物和动物中观察到了光周期，但在细菌（原核生物）、其他单细胞生物或真菌中没有。

真正的光周期响应是对昼长变化的响应。某些物种对白天增加和黑夜缩短做出反应（例如在春季开花）。这被称为长日植物。其他物种可能以相同的速率或同一物种的不同方式对白天缩短和黑夜增加做出反应。响应相对于昼长或独立昼长的植物被称为中性植物。许多植物对光周期有反应。这些包括春季生殖结构的发育、开花、叶和果实发育；许多草本植物以及针叶和落叶树的茎伸长（通常是长日响应）以及可能最广泛的光周期响应；植物（短日）；秋季落叶和冬季休眠芽（短日）；抗性的发育（短日）；根的形成；许多地下储藏器官，如鳞茎（洋葱）、块茎（土豆）和根（短日）；匍者的形成（草莓；短日）；开花或结果的平衡（短日）。

# 光合作用

光合反应。其剩余的 25% 以二氧化碳的形式释放。光降解通过三种方式降低光合作用的速率：释放二氧化碳；能量从光合作用转移到光保护；以及碳与二氧化碳之间的竞争减少了核羧加氧酶（`RuBisCO`）的活性。

光合作用的总化学反应如下方的方程所示，其中 `CH₂O` 代表碳水化合物（糖）。

```
H₂O + CO₂ + energy \xrightarrow[chlorophyll enzymes]{CH₂O + O₂}
```

光合作用的光化学反应属于氧化还原反应，其中 `CO₂` 作为电子受体，水（氢或氧）作为供体。这种特定氧化还原反应的性质是在能量上是“反向”的；也就是说，它将能量转换为不稳定的产物。光被用于使反应自发。

通过减少光合作用，光合速率可以被刺激 50%。由于光合作用为植物生长提供了必要的物质，光合作用抑制会导致生长减缓并最终死亡（同化）。

光合作用是一个复杂的多阶段过程。主要阶段包括：(1) 初级光化学过程，其中光被吸收并转化为某些富能中间体形式的化学能；(2) 酶催化（即非光化学）反应，通过这种反应将这些中间体转化为最终产物和游糖。

某些自养植物的细胞内二氧化碳由核酮糖磷酸羧基加氧酶固定。许多植物可以通过在夜间吸收二氧化碳并在光合作用期间释放来实现。这些植物被归类为景肉植物酸代谢（`CAM`）。其他植物，如玉米（`CAM`），在白天通过一种缓慢积累的机制吸收二氧化碳，并在晚上释放。

实验表明，植物可以在卡尔文循环（`C3` 或 `PS I` 反应）将二氧化碳转化为糖，而光依赖反应（`PS II`）则发生在类囊体中。
