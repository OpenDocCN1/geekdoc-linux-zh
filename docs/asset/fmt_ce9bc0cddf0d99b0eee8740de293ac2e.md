## slice

一种通过调制调器连接互联网的 ASCII 标准。SLIP 是此方法的两种标准之一（另一种是点对点协议 PPP）。SLIP 让未连接到局域网（LAN）的计算机能够连接到互联网。这种连接方式远优于 shell 访问（拨号、纯文本的计算机），因为它允许同时运行多个 Internet 应用程序并将数据直接下载到电脑，无需中间存储。来自 QUCED `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## slurp

使用拨号 shell 账户的 SLIP/PPP 模拟器。这是一种 SLIP 模拟器，可以将普通的 shell 转换为 SLIP/PPP 账户。这允许用户使用如 Netscape、Mosaic、CSeeMe 等高级 Internet 应用程序。请注意，你的 ISP 并不喜欢你使用 slurp，因为他们想对 PPP 连接收费，所以请自担风险使用。来自 Debian 3.0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

### slocate

Slocate 是 `locate` 的安全增强版本。与 `locate` 一样，slocate 通过一个中心数据库（每晚更新一次）搜索匹配给定模式的文件。Slocate 允许你快速找到系统上任何地方的文件。来自 Redhat 8.0 RPM

`http://www.ldp.org/LDP/Linux-Dictionary/index.html`

### sloccount

用于统计物理源代码行数（SLOC）的程序。SLOCount（读作 "sloc-count"）是一套用于统计可能大型软件系统中物理源代码行数（SLOC）的程序（因此，SLOCount 是一种“软件指标工具”或“软件测量工具”）。SLOCount 可以自动统计多种语言的物理 SLOC 行；按字母顺序排列为：Ada, Assembly, Awk, Bourne, C, C++, Shell, Fortran, Java, lex/lisp（包括 Scheme）, Modula, Object-C, Pascal, Perl, PHP, Python, sed, TCL 和 Yacc 会自动判断文件是否为源代码。因此，你可以完全自动地分析大型系统。SLOCount 还包含一些报告生成工具，用于统计并以几种不同的格式展示数据。来自 Debian 3.0r0 APT
