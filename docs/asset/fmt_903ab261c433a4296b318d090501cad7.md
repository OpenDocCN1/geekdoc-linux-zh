
### 复制对象并使用变换工具

### 创建命名选择集

每个版本的 VIZ 都整合了新的且令人兴奋的功能。VIZ 2008 欢迎屏幕对话框（见图 1.1）现在包含了解释新功能的视频链接。当你不再希望在打开 VIZ 时出现该对话框时，请取消左下角的“启动时显示（Show at Startup）”。

新功能和技能位于 Autodesk 网站，需要连接 Internet 才能查看它们。

**欢迎屏幕对话框**

![欢迎屏幕对话框](img/7e14344dd5a0ed683d4f26c827_0.png)

VIZ 场景的所有方面现在都可以进行外部引用（XRef'd），包括对象和材料。控制器（决定如何管理动画对象）可以维护外部引用对象之间的依赖关系。

在导入或链接的 AutoCAD Architecture（原为 Architectural Desktop）文件中，使用相同样式的项目可以使用新的“选择相同（Select Similar）”命令快速选择。

虽然 VIZ 的许多组件对于 Windows 程序来说是典型的，但有很多是独特的。为了开始探索 VIZ 2008 界面，请通过以下任一方式启动程序：

- 双击桌面上的 Autodesk VIZ 2008 图标。
- 选择 开始 ▷ Autodesk ▷ Autodesk VIZ 2008 ▷ Autodesk VIZ 2008。

你将在 VIZ 窗口中看到各种组件（见图 1.2）——有些是熟悉的，有些则不是。

书中的图像使用了“大图标”选项以更好地显示工具栏按钮。要激活此选项，选择“自定义 ▷ 首好设置”以打开首好设置对话框。在“常规”选项卡下的“UI 显示”中，勾选“大工具栏按钮”，然后关闭并重新打开 VIZ 使选项生效。

**标准的 Autodesk VIZ 2008 窗口**

![标准的 Autodesk VIZ 2008 窗口](img/7e143440dd5a0ed9683d4f26f3c074f8_29_0.png)

在顶部，你可以看到典型的 Windows 菜单栏和 VIZ 主工具。你可能还会看到多五个浮动工具栏，其中包含额外的 VIZ 工具，以及用于存放场景材质、灯光和摄像机的工具面板。在中心，是视口区域，在屏幕右下角，你可以看到调整当前视口中视图的视口导航工具。你还会看到用于创建和播放动画的时间控制、提示行和状态栏，以及 MAXScript 微型监听器（用于创建宏）。在用户界面的右侧，是命令面板，它包含了你在 VIZ 中创建和编辑对象时将用到的几乎所有工具。让我们仔细观察这些组件。VIZ 提供了多种方法（包括工具栏、命令面板、菜单和快捷键）来完成许多任务。

VIZ 提供了丰富的工具，其数量之多可能会让人无从从。为了初步了解 VIZ 窗口，让我们逐个查看窗口的每个组件，从菜单栏开始。

#### 菜单栏

屏幕顶部是菜单栏。在这里，你会找到用于文件维护的典型 Windows 命令，以及专门针对 Autodesk VIZ 2008 的命令。

菜单栏中的选项组织方式与其他大多数 Windows 应用程序相同。点击选项会发出一个命令，并且你需要执行某些操作。选项后带有三个点（称为省略号）的选项会打开对话框，通常允许更改与该选项相关的设置。带有向右箭头的选项会在所谓的“级联菜单”中显示更多选项。

![菜单栏](img/7e143440dd5a0ed9683d4f26f3c074f8_30_0.png)

通过查看“单位设置”（`Units Setup`）对话框来尝试菜单。

1. 选择 `Customize` -> `Units Setup`。显示单位设置对话框。
2. 选择 `US Standard` 单选按钮，并确保下方选择了 `Feet / Decimal Inches`，并且默认单位了 `Inches`，如图 1.3 所示。

**在单位设置对话框中定义单位**

![在单位设置对话框中定义单位](img/7e143440dd5a0ed9683d4f26f3c074f8_30_1.png)

3. 点击 `System Unit Setup` 按钮，你会看到另一个小对话框。确保 1 个单位设置为 1 英寸。不要更改系统单位设置对话框中的其他内容，并点击确定关闭两个对话框。

![系统单位设置](img/7e143440dd5a0ed9683d4f26f3c074f8_30_2.png)

通过设置单位设置对话框，你可以确保在未来的练习中使用的单位与书中讨论的单位相同。

Autodesk VIZ 2008 有点变色龙属性。它可以根据你建模需求的重点改变自己的外观。如果你的 VIZ 2008 窗口看起来与本书中的插图不同，请选择 `Customize` ➤ `Revert to Startup Layout`。你会看到一条警告信息，告诉你所做的任何界面（`UI`）更改将丢失。点击“是”，以使你的 VIZ 窗口与书中所示界面匹配。

#### 主工具栏

菜单栏下方是主工具栏。工具栏上的工具带有提示，帮助你记住它们的用途。工具栏的最左侧是 `Undo` 和 `Redo` 选项。点击这些按钮可以撤销你的最后操作（默认最多 25 次），或重做任何已撤销的操作。右键点击每个按钮会弹出你可以选择的操作列表。

![撤销和重做按钮](img/7e143440dd5a0ed9683d4f26f3c074f8_31_0.png)

接下来是一组用于链接和选择对象的工具。两个链接工具（一个用于链接，另一个用于取消）会导致一个对象根据应用于另一个对象的命令进行移动、旋转或缩放。选择工具允许通过点击或按名称选择来选择对象。你还可以使用选择窗口设置选择对象的方法，该窗口通过在对象周围放置矩形、圆形或其他边界来提供指示选择的方法。

![链接和选择工具](img/7e143440dd5a0ed9683d4f26f3c074f8_31_1.png)

选择工具右侧是变换工具。这组工具允许你移动、旋转和缩放对象。使用轴点选项，你还可以选择参考坐标系，使用不同的吸附选项设置变换中心，与命名选择集一起工作，并使用工具合并和对齐对象。

![变换工具](img/7e143440dd5a0ed9683d4f26f3c074f8_31_2.png)

右侧的下一组工具包括访问图层管理器（`Layer Manager`）、图表编辑器工具，以及材质和渲染工具。图表编辑器工具以图表或连线图的形式显示场景信息。材质通过定义和应用表面属性来控制对象的显示。通过这些工具，你可以创建颜色、纹理、透明度和其他材质属性，然后将这些属性应用于模型。你还可以打开 `Render Scene` 对话框，选择渲染类型，并使用右侧的按钮进行快速渲染。

![图层管理器、图表编辑器、材质和渲染工具](img/7e143440dd5a0ed9683d4f26f3c074f8_31_3.png)

渲染工具控制 Autodesk VIZ 2008 场景的输出。与大多数应用程序不同，VIZ 2008 的输出很可能是图像或动画文件。渲染工具允许设置输出的类型和大小，从单幅静态图到视频动画。

如果你使用的分辨率低于 `1280x768`，则右侧的工具将不可。渲染工具允许设置输出的类型和大小，从单幅静态图到视频动画。

除了主工具栏外，你还会看到几个“浮动”工具栏。你可以将浮动工具栏固定或将停靠工具栏浮动。尝试以下练习更改工具栏的位置：

1. 点击并拖动图层工具栏的标题栏，直到其位于主工具栏下方（见图 1.4）。在释放鼠标之前，图层工具栏会以虚线水平轮廓显示。
2. 当轮廓位于图 1.4 所示的位置时，释放鼠标。图层工具栏现在处于停靠位置。

![将图层工具栏固定在主工具栏下方](img/7e143440dd5a0ed9683d4f26f3c074f8_32_0.png)

在许多图形程序中，屏幕空间总是宝贵的。使用双显示器系统可以减少杂乱。层是帮助你组织的叠加层。

![将图层工具栏固定在主工具栏下方示意图](img/7e143440dd5a0ed9683d4f26f3c074f8_33_4.png)

3. 将“扩展”（`Extras`）工具栏停靠在图层（`Layers`）工具栏的右侧（也在主工具栏下方）。

![扩展工具栏停靠位置](img/7e143440dd5a0ed9683d4f26f3c074f8_34_0.png)

4. 右键点击“扩展”工具栏左侧的两条垂直线（称为工具栏手柄），打开快捷菜单。

![工具栏手柄快捷菜单](img/7e143440dd5a0ed9683d4f26f3c074f8_34_1.png)

5. 从快捷菜单中选择“浮动”（`Float`）。“扩展”工具栏将返回其浮动位置。此操作的另一种方法是按手柄将工具栏拖入视口。
6. 工具栏可以停靠在视口的任意侧。但是，如果工具栏具有下拉列表，应避免将工具栏停靠在界面的左右两侧，否则列表将无法显示。选择“捕捉对齐”（`Snaps`）工具栏并将其停靠在用户界面的左侧。

![捕捉对齐工具栏停靠位置](img/7e143440dd5a0ed9683d4f26f3c074f8_34_2.png)

7. 选择剩余的浮动工具栏并将它们停靠在视口的顶部或左边缘。你的屏幕应该与图 1.5 所示的 VIZ 窗口相似。

在此次练习中，你学会了如何停靠和浮动工具栏，以及如何访问快捷菜单来切换工具栏的开启。你可以根据自己的意愿隐藏或浮动工具栏。

你可能注意到，主工具栏中的某些工具在工具图标的右下角有一个小箭头。
