## cgitb

- 在 UNIX 上，Python CGI 程序可能需要设置适当的执行权限，并且程序的第一行需要出现如下行：

```python
#!/usr/bin/env python

```

- 为了简化调试，请导入 `cgitb` 模块——例如，`import cgitb.enable()`。这会修改异常处理，使得错误可以在 Web 浏览器中显示。

- 如果你调用了外部程序——例如通过 `os.system()` 或 `os.popen()`——请小心不要将从客户端接收的任意字符串传递给 shell。这是一个众知的安全漏洞，黑客利用它在服务器上执行任意 shell 命令（因为传递给这些函数的命令首先由 shell 解释，而不是直接执行）。特别是，不要将 URL 或表单数据的任何部分传递给 shell，除非已通过彻底检查，确保字符串只包含字母字母、数字、下划线和点。

- 不要在此模块上使用 'from cgi import *'。`cgi` 模块定义了大量的名称和符号，你可能不希望它们出现在你的命名空间中。

- 在 UNIX 上，不要给 CGI 程序设置 setuid 模式。这是一个安全隐患，并且在所有机器上都不受支持。
