## 游形鱼目

一种肉肉性硬鱼类，其目分类与鳕形目（Gadiformes）密切相关。其特征包括大的尾鳍，每个尾鳍通常带有有一到四根前刺；腹鳍（如果有）位于位于腹部位置，有三到八根鳍条；腹带（如果有）附着在后锁骨上；鱼囊无管；身体覆盖有圆鳞或栉鳞。见 游鱼目；鳕形目。

# 橄榄岩

岩石由超过90%的毫米至厘米级橄榄石、辉石和角闪石晶体组成，其中橄榄石超过40%。所有其他矿物主要是斜长石、铬铁矿和榴石。岩石的大部分体积由橄榄石组成。

橄榄岩有三种成分模式，对应其纹理：(1) 具有完整橄榄石晶体的橄榄岩称为铁锰；(2) 具有斜长石和辉石的橄榄岩具有类火岩颗粒晶体，其边界可能不规则；(3) 橄榄岩也出现在深层地幔的岩石中，如到达地面的榴岩。

橄榄岩富镁，反映了地幔的成分。层状火岩岩石的成分各异，反映了辉石、铬铁矿和斜长石的相对比例。

# 周期倍频

标志着正常过程从规则到混沌转变的信号。各种自然过程的发展方式取决于环境因素。环境的性质被称为参数，并固定为在发育过程中选定的值。

一个过程需要一种自然机制来使其具有规则且易于理想运动周期，但在其他参数范围内，它会产生复杂且难以描述的运动。在流体流动中，含物的化学反应速率被称为混沌（包括了在底层循环出现之前的流体湍流）。

随着环境参数的变化，过程可能会系统性地增加运动，导致通过周期倍频进入混沌状态。这些转换的现象被称为混沌。存在多种定性差异导致变化，每种场景似乎都是不同的。周期倍频在自然系统中经常遇到并导致混沌。

为了观察这一场景，只需固定除一个外的所有参数。在该参数的某些范围内，可以增加振荡频率，直到观察到运动是周期性的。在参数的某个值之后，运动变得更加复杂（发生了分叉）；然而，在时间 T 内（即运动在分叉之前重复自身的时间后），运动仍然无法循环，尽管是重复的，但在7个周期后变为14个周期。这意味着周期从7倍增加到14倍。在新周期循环的前半部分后同步。

参数的进一步增加产生另一个分叉，导致周期的倍增；在两个周期周期之后，运动仍然无法重复，随着参数的增加，会出现连续的倍增，次数越来越多，直到在无限次之后出现一个临界值，使得运动不再具有周期性，并且具有比以前更复杂的特征。

# 周期运动

任何运动都在规则间隔内识别自身。

如果 `x(t)` 代表任何时间 `t` 的循环状态，那么如果对于变量 `t` 的每一个值，由方程定义的属性都成立，则运动是周期性的。

```
x(t+T)=x(t)
```
