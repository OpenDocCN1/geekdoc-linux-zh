## 什么是 Linux？

你的电脑尽管是复杂部件的集合，但本身只是一堆机器；它只能开关机。为了让它做任何有用的事情，它需要操作系统 (OS) 来引导它。

你已经知道并可能使用过许多操作系统中的一个。Windows、Mac OS 都是这样的操作系统，而 Linux 是另一个。Linux 在功能和传承方面与这些操作系统均不同。Linux 并不是由公司或某些为了赚钱的人创建的。Linux 核心被称为内核 (kernel)，是一个芬兰人，他想创建一个可以在个人电脑上运行的类 Unix 系统。

Torvalds 没有把他的创造留给自己，而是向世界开放了（可以说），Linux 内核与硬件通信，使得全球电脑极客创建的其他应用程序和支持库得以使用，从而让 Linux 变得更好更强大。围绕内核构建的应用程序组合才是所有 Linux 发行的精髓。

尽管你可以单独使用 Linux，通过在黑屏幕上输入命令完成所有任务（这是 Linux 作为服务器时最常见的处理方式），但你不必这样做。同样，许多 Linux 世界的成员感到需要并渴望图形化。各种 GUI（被称为窗口管理器和桌面环境）以及一个用于处理它们的子系统（有些令人困惑地称为 X 窗口系统）是由广大社区开发的，以带来这种变革。包含在你的 Ubuntu 发行版中的图形化桌面环境 GNOME，就是这种开发成果的例子之一。

## 关于企鹅

你可能对章节标题中的企鹅感到好奇，所以我不妨现在就解释一下。这只企鹅是由林斯·托瓦尔斯（Linus Torvalds）选为 Linux 的吉祥物，而被大家公认为的 Linux 企鹅是由拉里·尤文（Larry Ewing）设计的，并命名为 Tux（参见图 1-1）。这不仅解释了整书中各处的鸟类学引用和图形，还解释了为什么 Linux 发行版中有如此多的企鹅图标，以及许多包含企鹅或 Tux 的程序，例如 TuxRacer、XPenguins 和 Pingus。这结合 Linux 是一台革命性的操作系统这一事实，有助于解释为什么 Linux 用户有时会被称为“企鹅主义者”（Penguinistas）。
