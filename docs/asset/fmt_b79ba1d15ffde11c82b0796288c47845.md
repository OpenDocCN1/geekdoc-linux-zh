系数 `$\gamma$` 称为速度梯度或剪切速率，由 `$V/h$` 给出，其中 `$h$` 是板之间的距离。预计剪切应力随距离的增加而增加，但这两个值的比值仅取决于流体属性。该比例用于定义剪切粘度 `$\eta$`，如公式 (2) 所示。剪切粘度取决于压力和温度。

```
$$\eta = \frac{\text{shear stress}}{\text{shear rate}} = \frac{\tau}{\gamma}$$
```

牛顿在1687年提供了流体粘度的第一个实用模型。牛顿提出抵抗流力与板相互推开时的流体速度成正比。牛顿粘度定律是一个经验性描述；许多流体（如低分子流体）在广泛范围内具有这种特性。然而，许多其他流体，如聚合物溶液和熔体、墨水、液晶和胶体悬液，不能用牛顿定律很好描述。

```
$$\tau = \mu\gamma$$
```

根据公式 (2) 和 (3)，流体的粘度由压力和温度给出。例如，在库特流中，当板的距离为 `1 cm` (`$h=1\text{ cm}$`) 时，对 `1 cm²` 板施加单位切向力即可产生 `1 s⁻¹` 的速度。粘度通常使用粘度计测量。不同流体的粘度表现出一些一般趋势。例如，气体的粘度通常小于液体，且随温度升高而减少，液体情况相反。

# 病毒感染

是指一种病毒对另一种病毒感染的抑制。病毒可能是无关的、局部的或相同的。在某些情况下，如果第一个病毒被感染，病毒干扰可能会发生。互斥性已应用于细菌病毒中的这一现象。

几种干扰机制被识别：(1) 一种病毒对受体的灭活可以防止第二种病毒的吸附和穿透。(2) 第一个病毒抑制或修改复制所需的细胞蛋白。(3) 第一个病毒可能会破坏酶或细胞以合成保护性屏障，防止感染。(4) 第一个病毒可能通过竞争细胞中可用的蛋白质（或环境）来抑制该病毒的复制；这种类型的病毒干扰被称为缺陷蛋白或突变体，见：动物病毒 (ANIMAL VIRUS);病毒 (VIRUS)，缺陷 (DEFE-
