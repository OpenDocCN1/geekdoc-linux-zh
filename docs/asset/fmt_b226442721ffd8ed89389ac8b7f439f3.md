以下函数用于操作文件：

`access(path, accessmode)`

`chflags(path, flags)`

更改 `path` 上的标志。`flags` 是后续列出的常量的位或结果。以 `UF_` 开头的标志可以由任何用户设置，而 `SF_` 开头的标志只能由超级用户更改 (UNIX)。

| Flag | 含义 |

| `stat.UF_APPEND` | 文件仅支持追加操作。 |
| `stat.UF_OPAQUE` | 目录是透明的。 |
| `stat.UF_NOUNLINK` | 文件可能不能被删除或重命名。 |
| `stat.SF_ARCHIVED` | 文件可以归档。 |
| `stat.SF_IMMUTABLE` | 文件是只读的。 |
| `stat.SF_APPEND` | 文件仅支持追加操作。 |
| `stat.SF_NOUNLINK` | 文件可能不能被删除或重命名。 |


创建一个设备特殊文件。`path` 是文件名，`mode` 指定权限和类型，`device` 是 `makedev()` 创建的设备号。在设置文件权限时，`mode` 接受与 `open` 相同的参数。此外，`stat_IFREG`、`stat_IFCHR`、`stat_IFBLK` 和 `stat_IFIFO` 被添加到 `mode` 中以指示文件类型。

```python
removedirs(path)
```

递归删除目录函数。工作方式类似于 `rmdir()`，但如果叶子目录成功删除，对应的右侧路径段将被修剪，直到路径被消耗，或者如果叶子目录无法成功删除则抛出 `OSError`。

然而，取决于系统的不同，可能还有额外的属性。`stat()` 返回的对象看起来也像一个包含参数的 10 元元组 (`st_ino`, `st_dev`, `st_nlink`, `st_uid`, `st_gid`, `st_size`, `st_atime`, `st_mtime`, `st_ctime`)。后一种形式是为了向后兼容而提供的。`stat` 模块定义了从此元组中提取字段的常量。

| `f_bfree` | 空闲块总数 |
| `f_bavail` | 非超级用户可用的空闲块 |

| `f_free` | 空闲 inode 总数 |
| `f_avail` | 非超级用户可用的空闲节点数 |

返回的对象的行为也像一个按列出的顺序包含这些属性的元组。标准模块 `statvfs` 定义了常量，可用于从返回的 `statvfs` 数据（UNIX）中提取信息。
