
## 描述

使用 `nohup` 命令运行即使注销也会继续运行的后台作业。`nohup` 命令带参数调用指定的命令。

`nohup`。当命令被调用时，`nohup` 让进程忽略 `SIGHUP` 信号。
当 `shell` 退出时，系统会向子进程发送 `SIGHUP` 信号，默认会杀死它们。然而，当你知道命令运行时间很长并且可以在不中断命令的情况下退出终端时，可以使用 `nohup` 命令。在调用命令之前加上 `nohup` 命令（如果进程通过程序选择忽略 `SIGHUP`），所有停止、运行和后台作业都会忽略 `SIGHUP`，并自动将输出（包括标准错误）发送到 `nohup.out` 文件。

`/usr/bin/nohup`
由 `/usr/bin/nohup` 运行的进程忽略 `SIGHUP`（挂断）和 `SIGQUIT`（退出）信号。

`/usr/xpg4/bin/nohup`
由 `/usr/xpg4/bin/nohup` 运行的进程忽略 `SIGHUP`。
`nohup` 命令并不安排进程对 `SIGTERM`（终止）信号产生免疫，因此除非你安排进程忽略 `SIGTERM`，或者 `shell` 强制它们忽略 `SIGTERM`，否则它们会接收该信号。

如果 `nohup.out` 在当前目录不可写，输出将重定向到 `$HOME/nohup.out`。如果创建了文件，该文件具有读写权限（`600`, `chmod(1)`）。如果标准错误是一个终端，输出将重定向到标准输出；否则不重定向。`nohup` 运行的进程的优先级不会改变。

## 警告

如果你使用 Korn shell (`ksh(1)`) 作为登录 `shell` 并且在尝试注销时有运行的 `nohup` 作业，将收到消息：
`You have jobs running.`

你需要再次注销才能真正注销；但是，你的后台作业将继续运行。

## 注意

C shell (`csh(1)`) 有内置的 `nohup` 命令，它可以提供对 `SIGHUP` 的免疫，但不会将输出重定向到 `nohup.out`。使用 `&` 执行的命令会自动忽略 `HUP` 信号。
`nohup` 不识别命令序列。在以下命令的情况下，`nohup` 命令仅适用于 `command1`。

```
$ nohup command1; command2
```

`nohup` 

以下命令在语法上是错误的。
```
$ nohup (command1; command2)
```

### 操作数

- `command`: 将要调用的命令名称。如果命令操作数的名称是任何特殊的 `shell_builtins(1)` 命令之一，则结果是未定义的。
- `argument`: 在调用命令操作数时作为参数提供的任何字符串。

## 示例

通常情况下，希望将 `nohup` 应用于管道或命令列表。你可以通过仅将管道和命令列表放在一个单独的文件（称为 `shell` 脚本）中来实现这一点。如果你使用以下命令运行该脚本，那么 `nohup` 将应用于该文件中的所有内容。
```
$ nohup sh file
```

如果需要执行该 `shell` 脚本文件，可以通过赋予权限来消除输入 `sh` 的需要。
当你添加一个符号 `&` 时，文件内容将在后台运行，同时忽略中断信号（见 `sh(1)`）。
```
$ nohup file &
```

## 环境变量

请参见 `environ(5)` 以了解以下影响 `nohup` 执行的环境变量的描述：`LC_CTYPE`, `LC_MESSAGES`, `PATH` 和 `NLPATH`。

- `HOME`: 确定用户主目录的路径。如果无法在当前目录创建输出文件 `nohup.out`，则 `nohup` 命令将使用名为 `HOME` 的目录创建该文件。

## 退出状态

- `126`: 找到了命令但无法调用。
- `127`: `nohup` 发生错误，或未找到命令。

否则，`nohup` 的退出值为该命令操作数的退出值。

# nroff — 为显示或行打印机格式化文档

概要
`/usr/bin/nroff` `[-ehiq]` `[-nname]` `[-nN]` `[-opagelist]` `[-raN]` `[-sN]` `[-Tname]`

描述
`nroff` 为类打字机设备格式化命名文件中的文本。另请 `troff(1)`。
如果你未指定文件参数，`nroff` 将读取标准输入。由横字符 (`-`) 组成的参数被视为对应于标准输入的文件。

注意事项
之前的文档错误地将数字寄存器 `yr` 描述为“当前年份的最后两位”。实际上，`yr` 是自 1900 年以来的年数。为了获取 2099 年之前当前年份的最后两位，你可以在文档中包含字符串寄存器 `yr` 的以下定义以显示两位年份。注意，你可以用任何其他单字符或双字符寄存器名称替换 `yr`。

选项
你可以按任何顺序指定选项，只要它们出现在文件之前即可。

- `-e`
使用全终端分辨率在调整后的行中产生等间距的单词。
- `-h`
在水平间距期间使用输出 Tab 字符以加快输出并减少输出字符数。假设 Tab 设置为八个等宽的名义字符宽度。
- `-i`
在输入文件耗尽后读取标准输入。
- `-mname`
在输入文件之前前加上宏文件 `/usr/share/lib/tmac/tmac.name`。
- `-nN` 为生成的生成的第 N 页 编号。
- `-opagelist` 打印页码仅出现在逗号分隔的数字和范围列表中的页面。范围 `N-M` 表示从第 N 到第 M 页；初始 `-N` 表示从开始到第 N 页；最后的 `N-` 表示从 N 到结束。
- `-q` 调用 `rd(9F)` 请求的同步输入输出模式。
- `-raN` 将寄存器（单字符）设置为 N。
- `-sN` 每 N 页停止一次（默认 N=1）以允许装纸或更换。在收到换行符时恢复。
- `-Tname` 为指定名称的设备准备输出。已知的名称有：

- `37` Teletype Corporation Model 37 终端（默认）。
- `1p | tn300` GE 任意行打印机或不具备半行能力的终端。
- `300` DASI-300。
- `300-12` DASI-300–12-pitch。
- `300S` DASI-300S。
- `300S-12` DASI-300S。
- `382` DASI-382 (fancy DTC 382)。
- `450` DASI-450 (Diablo Hyterm)。
- `450-12` DASI-450 (Diablo Hyterm)–12pitch。
