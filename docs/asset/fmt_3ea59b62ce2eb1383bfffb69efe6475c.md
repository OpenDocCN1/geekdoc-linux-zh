这个输出看起来稍微好一点，但我们仍然对几个点感兴趣。`/cdrom` 处于用率为 100%，而 `/proc` 挂载点有值。`/proc` 文件系统接近 AI（伪文件），因为它没有实际值，我们希望从输出中剔除它。注意第 1 列中的设备，CD-ROM 的设备是 `/dev/cd0`。这是我们想要使用的标签，用于匹配，而不是使用可能在其他地方的挂载点，例如 `/mnt`。我们可能还会有 `/dev/cd1` 和 `/dev/cd2` 设备，如果未来的话。这也需要处理。我们可以扩展命令语句，使用 `grep` 语句从输出中排除这两行，如下所示：

```
df -k | tail +2 | grep -v '/dev/[0-9]\|/proc'
```

在语句句中，我们使用了带有 `-v` 开关的 `grep` 命令。该开关显示除匹配模式以外的所有内容。`grep` 用于扩展表达式；在这种情况下，我们想要排除两行输出。为了节省一个额外的 `grep` 语句，我们使用 `grep` 并对单引号进行匹配，并用管道符号分隔列表中的每个项目。这两个命令是等效的：

```
df -k tail +2 | grep -v '/dev/[0-9]\|/proc'
df -k tail +2 | grep -v '/dev/[0-9]\|/proc'
```

另外请注意，两个语句都匹配 CD-ROM 设备的模式。`grep` 语句将匹配从 `/dev/cd0` 到最后一个设备（例如 `/dev/cd2`）的设备，使用 `/dev/[0-9]` 作为模式匹配。不要忘记 `/dev/[0-9]` 周围的引号，否则 `grep` 语句可能会失败。使用 `egrep` 可以节省少量代码，但两个命令产生相同的输出，如下：

在继续之前，我们需要使用 `sed` 语句来处理这个 `%` 符号。`sed` 用于字符替换，在这种情况下，是字符删除。`sed` 语句就在循环数值比较之前。请查看列表 5.1，注意加粗文本。

```bash
#!/usr/bin/ksh
# 脚本: fs_mon_AIX.ksh
# 作者: Michael
# 日期: 08-22
# 目的: 此脚本监控文件系统
# 版本: 1.1

##### 定义变量
THISHOST=$(hostname) # 获取主机名
WORKFILE="/tmp/df.work" # 工作数据文件
OUTPUTFILE="" # 输出文件
FMAX="85" # 阈值

##### 命令开始
# 获取文件系统数据
df -k | tail +2 | egrep -v '/dev/[0-9]\|/proc' > $OUTPUTFILE

##### 主循环
# 遍历每一行
while read FSDEVICE SIZE USED FREE MOUNT; do
  # 移除 % 号并类型转换
  FSVALUE=$(echo $USED | sed s/\/%g)
  # 超过测试
  if [ $FSVALUE -gt $FMAX ]; then
    echo "$FSDEVICE mounted on ${FSVALUE}%" >> $OUTPUTFILE
  fi
done < $WORKFILE

##### 输出结果
if [[ -s $OUTPUTFILE ]]; then
    echo "$THISHOST 上的满文件系统:"
    cat $OUTPUTFILE
fi
```

关于命令语句的前述部分，需要注意的是，我们必须使用反斜杠 `\` 对百分号 `%` 进行转义。这是因为 `%` 在 Unix 中是一个特殊字符。为了移除该函数的特殊含义或对其进行转义，我们在 `%` 符号前面加上一个反斜杠，即 `\%`。这让我们能够将 `%` 作为文本字符使用，而不是其系统定义的数值或功能。请参见列表 5.2。

## 为监控添加异常功能

`fs_mon.ksh` 脚本对于其设计用途非常好，但在现实世界中，我们总是必须处理异常情况，并在编写脚本时力求涵盖所有的陷阱。现在，我们将添加一个覆盖默认 `FSMAX` 阈值的功能。由于我们能够覆盖或降低默认阈值，因此如果能够针对单个文件系统进行定制，那就太棒了。

为了实现这种脚本定制，我们需要一个数据文件来存储我们的异常情况。我们希望使用数据文件，这样人们在每次更改文件系统阈值时都不需要修改脚本。为了简单起见，让我们使用 `/usr/local/bin/exceptions` 文件并通过 `EXCEPTIONS` 变量指向该文件。现在我们知道了文件名，需要为异常文件中的数据定义一种格式。该数据文件的一个良好格式是 `/mount_point` 和 `NEW_MAX%`。我们还希望忽略任何以井号 `#` 注释的条目。这听起来可能很多，但修改脚本代码并添加一个读取异常的函数实际上并不困难。现在我们可以进行设置了。
