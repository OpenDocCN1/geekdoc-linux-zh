
# 变质作用

受温度和压力影响的原有岩石块体，但不包括风化和沉积作用产生的变化。这些变化可能包括新矿物、结构或构造的产生，或三者兼有。它们赋予岩石整体一种独特的新特征，但不涉及岩石块体个体性的丧失（例如由熔融引起的变化）。在定量上，包括片麻岩和混合岩在内的变质岩是大陆地壳中最重要的岩石组。参见：片麻岩；变质岩；混合岩。

可以根据特定标准定义不同种类的变质作用，例如假设导致变质作用的地质过程，或看起来在决定变质作用过程中起主导作用的物理和化学条件。使用这些标准，下面提到了三种一般类型的变质作用。

### 1. 位移、机械或动力变质作用
地壳中沿断层（dislocations）的压力（或应力）的结果。
变形岩石通常显示出极细粒岩石的破碎带，如糜棱岩，其结构由晶粒的破碎和运动决定，而不涉及旧矿物的重要重结晶或新矿物的生长。这种类型的变质作用是局部的，且分布有限。

### 2. 接触或热变质作用
由于相邻岩浆侵入导致温度升高而发生的。
岩石的化学重构是由于岩浆挥发作用；其他条件，如围压，起次要影响。

### 3. 区域变质作用
最广泛的类型，由造山带内温度和压力的升高引起，造山带是由褶皱山脉代表的地壳巨大片段。
热和压力主要是向下弯曲和深埋的结果。压力也由伴随造山运动的剪切应力产生。参见：造山运动。[FTWF/R.C.N] 流体相在变质过程中作为热量和质量转移的介质起着重要作用。矿物晶粒周围存在的静态流体膜极大地促进了化学反应，因为流体膜加速了物质从反应物矿物向产物矿物的移动。流动流体携带大量溶解物质，可能沉淀在远离源区的地方。与热传导相比，流动流体使加热岩石冷却得更快，并使冷却岩石加热得更快。变质岩中的流体主要由水（H₂O）、可变量的二氧化碳（CO₂）和甲烷（CH₄），以及少量的硫化氢（H₂S）、一氧化碳（CO）、氢气（H₂）和二氧化硫（SO₂）组成。[D.Rum.]

# 变态发育（Metamorphosis）

一种动物内部和外部形态在短时间内发生的显著变化，由外部和内部信号的某种组合触发。形态变化的程度在不同类群中差异很大。即使形态变化相对轻微，变态发育通常也会带来栖息地和生活方式的显著转变。构成变态发育的精确形态、生理和生化变化；控制这些变化的神经、激素和遗传机制；以及这些变化的生态后果及其发生时间，继续在多种动物中进行研究。变态发育的激素和遗传控制在少数昆虫、两栖动物和鱼类（如比目鱼）物种中研究得最好，但变态发育的其他方面也在许多昆虫、两栖动物和鱼类物种以及海洋无脊椎动物中，甚至几乎所有动物门类的代表中得到了调查。

两栖动物在变态发育期间表现出广泛的组织重塑，包括尾部肌肉和骨骼系统的吸收；消化道的重大重建；幼体皮肤再生和皮肤化学成分明显改变；后肢和前肢的生长；鳃及相关支持结构的退化；氮排泄模式从氨到尿素的转变；视觉系统生化学的改变；幼体血红蛋白被成体血红蛋白取代；以及小脑的差异生长。参见：两栖动物。

昆虫中的变态发育主要与翅膀发育相关。毛翅目（Bristleflats，此处指没有翅目的昆虫，如原翅目等）以及不发育翅膀且并非源自有翅祖先的其他物种没有明显的变态发育。

全变态种类（holometabolous species）的变态发育最为剧烈，它们经历一个独特且基本不活动的蛹期；在这些物种中，将幼虫形态和生理与成虫区分开的所有转化都在蛹内进行。翅膀、复眼、外部生殖器官和胸部步行足从在幼虫发育期间形成的离散折叠组织囊（幼叶盘，imaginal discs）中发育而来。参见：昆虫纲；蜕皮（节肢动物）。

鱼类中最剧烈的变态变化见于比目鱼和其他鲽形目鱼类；在这些物种中，变态发育期间对称的鱼类幼体变成不对称的成体，两只眼睛都转移到背侧表面。幼鳗（leptocephalus larvae）转化为幼年鳗鱼的过程也很剧烈；这种转化包括泌尿和消化道位置从后部到前部的转移。参见：鳗鱼；硬骨鱼总目。

螃蟹、藤壶、腹足类、双壳类、苔藓虫、棘皮动物、海鞘和其他海洋无脊椎动物中变态发育的控制了解甚少，部分原因是幼体非常小——它们很少超过 1 毫米长，且大多数小于 0.5 毫米。某些海洋无脊椎动物物种的幼体受与同种成体相关的特定物质触发而变态，例如它们捕食的藻类或动物。参见：多毛纲（ANNELIDA）；海鞘纲（UROCHORDATA/BRACHIOPODA? 原文 BRAVIALIA 可能是 Brachiopoda 腕足动物 或 其他，结合上下文 MARINE INVERTEBRATES，可能是笔壳纲或类似，此处 BRAVIALIA 可能是 Brachiopoda 的误拼，译为腕足动物）；蟹；十足目（甲壳纲）；棘皮动物门；腹足纲；软体动物门。

在昆虫中，变态发育的时机受温度、湿度、光周期、邻近个体产生的信息素以及食物营养质量等环境因素影响。在许多物种中，幼体可以对不利的环境条件产生发育停滞（滞育），从而使变态发育延迟数月甚至数年。对于多种昆虫物种，这种效应的激素基础已至少部分被阐明。

在海洋无脊椎动物中，以及至少在部分鱼类物种中，变态发育的时机也具有相当大的灵活性。在海洋无脊椎动物发展的某个阶段，显然也在某些珊瑚礁鱼类的发展中，个体幼体变得“有资格”进行变态。尚不清楚是什么使幼体具备这种资格；外部受体细胞的发育，或特定神经通路的完成及其受体中激素系统的激活可能是可能的原因。参见：内分泌机制；内分泌系统（无脊椎动物）；无脊椎动物胚胎学。[J.A.Pu.]

# 交代作用

岩石的大致化学成分通过引入外部来源的组分，从先前状态发生变化的过程。与变质作用不同，在变质作用中岩石转化为新的矿物组合而大致成分变化很小或没有变化，交代作用涉及通过化学活性流体进行化学组分的输入和输出。

经典岩石和中基性至酸性火成岩以类似的方式通过碱、碱土金属和氢的交换与交代岩石缺乏相似性。水液蚀变主导低温交代过程。水硅酸盐涉及氢离子交代——氢离子与钾、钠和钙交换。

铝贫岩石、碳酸盐和超基性岩石的交代作用通常涉及二氧化硅、金属和氧化铝的添加。

# 亚稳态

在量子力学中，亚稳态是指一种并非真正定态，但几乎处于定态的状态。

在实际应用中，特别是在原子物理和核物理领域，“亚稳态”这一术语通常专门指代那些寿命异常长的状态。例如，原子的激发态通常通过发射单个光子而衰变，其持续时间约为 10⁻⁸ 秒。然而，原子氢的第二个激发亚稳态（2S 态）无法通过同时发射两个光子而衰变；因此，其寿命延长至估计值 0.15 秒。因此，原子氢的 2S 态通常被称为亚稳态，但大多数其他的氢样原子状态则不是。同样，激发核发射伽马射线光子通常发生在 10⁻¹³ 秒或更短的时间内；然而，¹³N 同位素的一个激发态（该状态通常被称为亚稳态）的寿命约为 100 分钟。由于光子发射的辐射跃迁概率通常随着频率的降低而迅速减小，低能的原子或核激发态可能具有比大多数原子和核激发态更长的寿命，但正如前述实际意义上的定义，它们并不一定是亚稳态，因为该状态的光子发射可能并未受到任何普遍要求或选择定则（如氢的 2S 态那样）的阻碍。参见：激发态；核同质异能性；放射性。[E.G.]

# 后兽下纲

后兽下纲（Metatheria）是兽类哺乳动物的一个下纲，包含单一的一个目，即有袋目。后兽下纲通过众多特征与真兽下纲（即胎盘哺乳动物）区分开来。后兽类的脑颅较小，下颌的髁突向下弯曲，且一对有袋骨与骨盆相连。几乎所有现生的有袋动物在雌性腹部都有一个育儿袋，幼崽出生后会在此携带。早期的有袋动物无法与更进步、更晚出现的胎盘动物竞争，因此在南美洲和澳大利亚以外的地区灭绝了，在这些地区它们因水域屏障而与世隔绝。参见：真兽下纲；哺乳纲；兽类。[D.D.F./S.S.]

# 后生动物

后生动物界（Metazoa，或亚界）包含所有多细胞动物，无论它们是由简单的组织层还是复杂的器官构成。在某些五界系统和用于生物分类的六界系统中，后生动物构成一个独立的界；而在较老的两界系统和某些三界系统中，后生动物亚界构成了动物界的大部分。最常见的分类方法将后生动物细分为大约 30 个多细胞动物门（如节肢动物门或软体动物门），每个门代表一种主要的身体构造类型。在所有分类系统中，未包含在后生动物界的唯一动物形式是单细胞的原生动物（Protista）以及独立进化的海绵动物（Porifera）。参见：动物界；真核生物；多孔动物门；原生生物界。

后生动物由真核细胞组成，每个细胞都有膜包围核物质，且细胞分裂机制始终涉及染色体的有丝分裂。细胞分化很常见。除了增加细胞间的功能相互依赖性外，后生动物较高级门的进化还涉及尺寸增大的潜力和代价，特别是与表面积-质量比相关的方面。尽管结构和功能复杂性等级不同，器官、组织和细胞类型之间的相互依赖性构成了构成（亚）界后生动物的动物门的诊断特征。参见：生物分类法；稳态。[W.D.R.H.]

# 流星

流星是指夜间可见的持续数秒或几分之一秒的发光轨迹，当一个固态天然天体冲入地球（或其他行星）的大气层时产生。进入天体称为流星体，如果其在穿越大气层过程中有任何剩余部分，则剩余部分称为陨石。进入大气层并留下非常短暂、微弱尾迹的宇宙尘埃微粒（质量微克级）被称为微流星，其残留碎片被称为微陨石。如果流星的视亮度超过从地球看到的金星亮度，它被称为火球；当明亮的流星被观察到爆炸时，它被称为陨石雨（bolide，巨流星）。参见：陨石；微陨石。

在正常的、晴朗的大气条件和黑暗的天空下（无月光或人造光），观察者平均每小时会看到五个流星。流星体轨道相对于太阳的空间分布及其与移动地球的相交情况，导致了流星速率的显著变化。
