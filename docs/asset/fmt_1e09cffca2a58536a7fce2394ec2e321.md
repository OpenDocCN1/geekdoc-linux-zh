## 25.1 Bash 简介

在 KDE 任务栏中，有一个描有贝壳显示器的图标。当你点击此图标时，会打开一个控制台窗口并在其中输入命令。控制台通常运行 `Bash`（Bourne shell），这是一个作为 GNU 项目一部分开发的程序。到目前为止，它是 Bourne shell `sh` 最广泛使用的衍生版本。一旦打开了 shell，第一行会出现提示符。提示符通常由用户名、主机名和当前路径组成，但可以进行自定义。当光标位于此提示符之后时，你可以直接将命令发送到你的计算机系统：`tux $`

### 25.1.1 命令

一个命令由几个元素组成。第一个元素是实际命令，后面跟着参数或选项。按下回车键时执行命令。在执行之前，可以轻松地编辑命令行、添加选项或纠正输入错误。最常用的命令之一是 `ls`，可以带参数或不带参数使用。在控制台中输入纯 `ls` 命令会显示当前目录的内容。

选项以连字符开头。例如，命令 `ls -l` 显示目录内容的完整详细信息。在每个文件名旁边，可以看到文件的创建日期、以字节为单位的文件大小以及进一步的细节（这些将在后文中介绍）。许多命令都有一个非常重要的选项，即 `--help`。通过输入 `ls --help`，可以显示 `ls` 命令的所有选项。

还使用 `ls` 命令查看其他目录的内容。要这样做，必须将目录指定为参数。例如，要查看桌面（Desktop）的内容，请输入 `ls -l Desktop`。

### 25.1.2 文件与目录

为了高效地使用 shell，了解 Linux 系统的文件和目录结构实际上非常有帮助。你可以将目录想象成电子文件夹，其中存储了文件、程序和子目录。层次结构中的顶层目录是根目录，称为 `/`。这是访问所有其他目录的地方。

`/home` 目录包含了个人用户存储其个人文件的目录。图 25.1 显示了 Linux 中的标准目录树，其中包含示例用户 xyz、linux 和 tux 的家目录。Linux 系统的目录树具有遵循文件系统标准的函数结构。

### 25.1.3 Bash 函数

shell 有两个重要的函数，可以让你的工作变得更容易：

- 历史函数——按下向上键重复以前输入的命令，直到它出现在提示符处。通过按下向下键向前移动。要编辑命令行，只需使用方向键将光标移动到所需位置并输入。使用 `Ctrl+R` 在历史中搜索。
- 扩展函数——输入名称首字母后将其扩展为完整长度。要这样做，输入首字母然后按 `Tab` 键。如果有多个相同字母的文件名，按两次 `Tab` 获取列表。

## 第一个示例：管理文件

现在你已经知道了命令的形式、SUSE Linux 中存在哪些目录以及在使用 Bash 时如何加速，请通过一个小练习来实践这些知识。

1. 点击图标从 KDE 桌面打开控制台。
2. 输入 `ls` 命令查看你的家目录内容。
3. 使用 `mkdir` 命令（意为创建目录）通过输入 `mkdir test` 创建名为 test 的子目录。
4. 现在按 `Alt+F2` 输入框中输入 `kedit` 启动 KEdit。在编辑器中输入几个字母，然后将其保存为家目录下的 Testfile。Linux 区分大小写。在本示例中，请使用大写 T。
5. 查看你的家目录内容。不要再次输入 `ls`，按两次向上键，`ls` 命令就会重新出现在提示符处。按回车执行命令。新创建的目录应该显示为蓝色，而 Testfile 显示为黑色。这就是在控制台中区分目录和文件。
6. 使用 `mv` 命令将 Testfile 移动到子目录 test。为了加速这一操作，使用扩展函数：只需输入 `mv T` 并按 `Tab` 键。只要没有其他以该字母开头的文件即可。

在目录下，shell 会扩展文件名并添加字符串 estfile。否则，请自行添加一或两个字母，并每次按 `Tab` 键查看 shell 现在是否可以扩展该名称。最后，输入一个空格，然后在扩展后的文件名后再次进行测试，并按 `Enter` 键执行命令。

- 7. 此时，Testfile 不再位于目录中。再次输入 `ls` 来检查此项。
- 8. 要查看文件是否已成功移动，使用命令 `cd test` 进入该目录。现在再次输入 `ls`。你应该能在列表中看到 Testfile。仅输入 `cd` 回到你的主目录。
- 9. 要创建一个副本，请使用 `cp` 命令。例如，输入 `cp Testfile Testbackup` 将 Testfile 复制为 Testbackup。再次使用 `ls` 命令查看目录内容。

## 25.1.4 指定路径

在处理文件或目录时，指定正确的路径是重要的。然而，你不需要从根目录输入整个（绝对）路径。相反，你可以直接从当前目录或你的主目录开始。因此，列出 test 目录的内容有两种方法：使用相对路径 `ls test/` 或使用绝对路径 `ls /test/*`。
