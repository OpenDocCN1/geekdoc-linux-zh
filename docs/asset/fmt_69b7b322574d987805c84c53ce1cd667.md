# gpsim

Microchip PIC Gpsim 模拟器是一个针对 Microchip PIC 微控制器的全功能模拟器。Gpsim 的设计目标是尽可能准确。准确性涵盖了 PIC——从核心到 I/O 点，包含了所有的内部外设。因此，可以创建刺激并将将其连接到 I/O 点，从而像在现实世界中那样对 PIC 进行测试。Gpsim 的设计目标是尽可能快速。可以实现 20MHz PIC 的仿真速度。已经实现了包括断点、单步执行、反汇编、内存检查与修改在内的标准范式。在 gpsim 中支持仅在在位仿真器上才可用的调试功能。一个连续跟踪缓冲区会记录模拟器的每一个操作。此外，还可以在值上设置读/写断点（例如，当从寄存器读取或写入特定值时停下）。来自 Debian 3.0r APT
