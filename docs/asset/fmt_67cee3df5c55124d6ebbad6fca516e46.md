
用于 IPv4 和 IPv6 的替换 `indent` 守护进程 (`rfc1413`)。`oident` 允许具有权限的用户识别服务器完成查询的响应。`oident` 还允许在查询完成后返回伪随机字符串（例如 "user"，后面跟 0 到 9999 之间的数字，或一个 UID），包括 `netfilter`。源自 Debian 3.0r0 APT
