## 文件切换与环境

这些文本处理器还允许你更改输入文件并修改输出文件。你可以通过三种方式修改输入：

- 你可以使用 `.rd` 请求来请求输入。可以提供一个参数作为提示，并从终端读取输入，直到输入两个连续的换行符为止。这种方法通常用于插入到表单类型的文档中。
- 可以使用 `.so` 命令解释整个文件。如果你创建了自己的宏集，你可能希望将其保留在单独的文件中并并在此请求在随后的文档中包含该文件。文件被读取并解释后，文本处理器将继续从当前文件读取。这种方法对于嵌入标准文本（如公司地址）也有用。
- `.nx` 请求与 `.so` 请求类似，不同在于当文件完成后，文本处理器被认为已完成输入。

这三个请求的示例显示在列表 8.24 中。列表 8.25 显示了头文件的内容，它定义了一些宏。列表 8.26 显示了终端会话。

\n(mo/\n(dy/

大多数程序员生活中的痛苦之一就是生成要发送给组织外部客户的文本。由于这些材料将由公众（即使只是一小部分）看到，因此文本的视觉美效果非常重要。编写处理格式、居中、分页、页眉和加粗等的代码（特别是当可能使用不同的打印机时）是一项巨大的工程，并且需要大量的精力进行调试。

与其担心这些小细节，你可以利用 `nroff`/`troff` 来完成格式化工作。你只需要创建一个包含适当 `nroff`/`troff` 命令的文件，然后让工具完成困难的工作即可。

图 8.30 显示了使用 `troff` 格式化程序输出的最终结果。列表 8.27 显示了一个用 C 语言编写的示例程序，让 `nroff`/`troff` 处理文本格式。列表 8.28 显示了该程序的输出。注意，C 语言使用反斜杠作为自身的转义序列；因此，当输出中需要反斜杠时，在 `printf` 语句中必须出现两个。单引号对 C 语言也有特殊含义，并且必须进行转义才能在输出中正确显示。

**图 8.30。** 由 `troff` 处理的 C 程序输出。

**列表 8.27. 使用 `nroff`/`troff`格式化输出的 C 程序。**

```c
#include <stdio.h>

#include <stdlib.h>

main ( )

{

  int index;

  char *sayings[6] = {

  "To Err is human. To really foul things up takes a COMPUTER.",

  "Rome wasn't built in a day, why should this system be?",

  "Do unto others and run!",

  "Do unto others, then split!",

  "Oh well, I can't think of any saying now.",

  "It's later than you think." };

  printf("\\\\\\" This file produced by a program!\\n");

  printf(".ad l \n");

  printf(".nf \n");

  printf(".pl 9i \n");

  printf(".ll 6.5i \n");

  printf(".sp 20 \n");

  printf(".ce 2 \n");

  printf("Sayings\n as of \\\\n(mo/\\\\n(dy/\\\\n(yr \n");

  printf(".bp 1 \n");

  printf(".tl \\'\\\\d\\\\dSayings\\'\\' \\\\n(mo/\\\\n(dy/\\\\n(yr \\' \n");

  printf(".sp 1 \n");

  printf(".ce 1 \n");

  printf("\\fB First Set of Sayings \\\\fP \n");

  for (index = 0; index < 6; index++)

  {

    printf(".sp 1 \n");

    printf("%s\n", sayings[index]);

  }

}
```
