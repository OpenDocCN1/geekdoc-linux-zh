
一个循环语句可以在循环内部使用任何其他类型的命令，包括其他循环命令。这被称为嵌套循环。在使用嵌套循环时需要小心，因为你正在迭代中执行迭代，这会使命令运行的次数成倍增加。如果你不密切注意这一点，可能会导致你的脚本出现问题。

这是一个在另一个 `for` 循环内部嵌套 `for` 循环的简单示例：

```
$ cat test14
#!/bin/bash
# 嵌套 for 循环

for (( a = 1; a <= 3; a++ ))
do
  echo "Starting loop $a:"
  for (( b = 1; b <= 3; b++ ))
  do
    echo "Inside loop: $b"
  done
done
$ ./test14
Starting loop: 1
Inside loop: 1
Inside loop: 2
Inside loop: 3
Starting loop: 2:
Inside loop: 1
Inside loop: 2
Inside loop: 3
Starting loop: 3:
```

（继续）

嵌套循环（也称为内层循环）在外层循环的每次迭代中遍历其值。注意，两个循环的 `do` 和 `done` 命令之间没有区别。`shell` 在执行第一个 `done` 命令时就知道它指的是内层循环而不是外层循环。

在混合循环命令时，情况也是如此，例如将一个 `for` 循环放在 `while` 循环内部：

```
$ cat test15
#!/bin/bash
# 将 for 循环放在 while 循环内部

var1=5

while [ $var1 -ge 0 ]
do
  echo "Outer loop: $var1"
  for ((var2 = 1; $var2 < 3; var2++))
  do
    var3=$var1 * $var2
    echo "Inner loop: $var1 * $var2 = $var3"
  done
  var1=$[$var1 - 1]
done
$ ./test15

## 第13 章：更多结构化的命令

`shell` 再次区分了内层 `for` 循环的 `do` 和 `done` 命令与外层 `while` 循环中的相同命令。

如果你真的想挑战大脑，甚至可以组合 `until` 和 `while` 循环：

```
$ cat test16
#!/bin/bash
# 使用 until 和 while 循环

var=3
until [ $var -eq 0 ]
do
  echo "Outer loop: $var"
  var2=1
  while [ $var2 -lt 5 ]
  do
    var3=$(echo "scale=4; $var / $var2" | bc)
    echo "Inner loop: $var / $var2 = ${var3}"
  done
  var=$[$var - 1]
done

## 第 13 章：更结构化的命令

```bash
for (( a = 1; a < 4; a++ ))
do
  echo "Outer loop: $a"
  for (( b = 1; b < 100; b++ ))
  do
    if [ $b -eq 5 ]
    then
      break
    fi
    echo "Inner loop: $b"
  done
done
```

```
./test19 1

Inner loop: 2

Outer loop: 2
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
Outer loop: 3
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
```

内部循环中的语句指定迭代到变量 `b` 等于 100。然而，内部循环中的 `if-then` 语句指定了当 `b` 变量的值等于 5 时，执行 `break` 命令。请注意，尽管内部循环通过 `break` 命令终止了，但外部循环仍按照指定继续运行。

## 退出外部循环

有时你可能处于内部循环中，但需要停止外部循环。`break` 命令包含一个单一命令行参数值：

```bash
break n
```

其中 `n` 表示要退出的循环层级。默认情况下，`n` 为 1，表示退出当前循环。如果你将 `n` 设置为值 2，`break` 命令将停止下一层级的外部循环：

```bash
$ cat test20
#!/bin/bash
# breaking out of an outer loop
```

（待续）

```bash
for (( a = 1; a < 4; a++ ))
do
  echo "Outer loop: $a"
  for (( b = 1; b < 100; b++ ))
  do
    if [ $b -gt 4 ]
    then
      break 2
    fi
    echo " Inner loop: $b"
  done
done
$ ./test20
Outer loop: 1
Inner loop: 1
Inner loop: 2
Inner loop: 3
Inner loop: 4
```

现在，当 `shell` 执行 `break` 命令时，外部循环停止了。

## `continue` 命令

`continue` 命令是一种提前停止处理循环内命令的方法，但并不会完全终止循环。这允许你在循环内部设置条件，使得 `shell` 不执行某些命令。这里是在 `for` 循环中使用 `continue` 命令的简单示例：

```bash
$ cat test21
#!/bin/bash
# using the continue command
for (( var = 1; var < 15; var++ ))
do
  if [ $var -gt 5 ] && [ $var -lt 10 ]
  then
    continue
  fi
  echo "Iteration number: $var"
done
$ ./test21
Iteration number: 1
Iteration number: 2
Iteration number: 3
Iteration number: 4
Iteration number: 5
Iteration number: 10
Iteration number: 11
Iteration number: 12
Iteration number: 13
Iteration number: 14
$ 
```
