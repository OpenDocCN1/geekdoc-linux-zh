使用 `iotop` 监控磁盘利用率

`iotop` 是一个用于监视 Linux 系统磁盘 I/O 操作的工具。它对于监控磁盘性能以及追踪资源密集型应用程序非常有用。上述示例展示了默认的 `iotop` 界面。

> **提示** 按 `Q` 键退出 `iotop` 工具。

常见用法示例：

- `iotop`

  监控系统 I/O 统计信息

- `iotop -o`

  仅显示执行 I/O 操作的进程

- `iotop -u [USER]`

  仅显示指定用户的 I/O 活动

- `iotop -d [SECONDS]`

  以指定间隔（秒）更新
