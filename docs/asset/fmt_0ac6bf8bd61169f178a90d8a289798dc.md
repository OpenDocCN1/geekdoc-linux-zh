
# 地球电学

与地球相关的电磁现象和电流，主要是自然起源的。地球物理方法利用天然和人工电流来探测地球内部的性质，并寻找自然资源（例如，石油、水和矿物）。地球电学有时被称为陆地电学。固体地球中所有的电流（自然或人工，局部或全球性的）都被归类为地球电流。地中电流这一术语专指那些起源几乎完全在大气层之外的天然全球性电流。地电磁学是一个比地球电学更全面的术语。任何磁场的时变都伴随着在导电介质（如地球）中感应电流的电场。

磁场、电场和电流是电磁学的组成部分，并通过麦克斯韦方程相互关联。例如，插图显示了在地球表面同一地点同时测量的天然磁场和电场的时间变化。这两条轨迹不仅通过麦克斯韦方程相互关联，还通过测量点附近地下岩石的物理性质相互关联。如果知道地下岩石的性质，可以通过合成计算从其中一条轨迹推导出另一条。反过来，这两条轨迹共同可以提供地质信息；这是一种地球物理勘探或探矿的形式。因此，地球电学、地磁学和地电磁学这几个术语基本上是 interchangeable（可互换的），尽管每个术语可能略有不同的侧重点。例如，地磁学一词有时用于指代地球准静止主磁场的研究。参见：地磁学；地球物理勘探。[S.H.X]

## 地理信息系统

用于存储、操作和分析地理参考信息的基于计算机的技术。属性信息和空间信息通过数据层的概念集成到地理信息系统（GIS）中，该概念在两种基本数据模型中实现：栅格和矢量。主要的应用类别包括城市和环境清单与管理、政策决策支持、规划；工程和国防应用；以及科学分析和建模。

地理信息系统与其他计算机化信息系统的主要区别有两点。首先，此类系统中的信息是地理参考的（地理编码的）。其次，除了常规的数据输入、存储、检索和输出功能外，地理信息系统还具有相当强大的数据分析与科学建模能力。

地理信息系统由软件、硬件和数据组成。数据层（或覆盖）和叠加操作的概念是大多数为地理信息处理设计的软件的核心。（参见：地图。）

两种基本的数据模型——矢量模型和栅格模型——体现了地理信息系统中的叠加思想。在矢量地理信息系统中，覆盖的几何构型以点、弧段（线段）和多边形的形式存储，这些构成了属性数据库中的可识别对象。在栅格地理信息系统中，一个层由像素基本单元阵列组成，每个像素保持一个属性值，而不显式引用像素所属的地理特征。参见：计算机图形学；电子显示；图像处理。

数据层或覆盖整合了两类信息：属性和空间（地理）。地理信息系统的功能包括捕获、存储、操作、分析以及向用户呈现信息的方式。空间数据捕获（输入）可以来自主要来源，如遥感扫描仪、雷达或全球定位系统，或来自对遥感衍生的图像和地图进行扫描或数字化。输出（无论是阴极射线管上的显示还是硬拷贝）通常以地图或图表形式呈现，并辅以将空间数据和属性数据链接起来的表格和报告。关键的数据管理和分析功能分为四类：检索、分类和测量；叠加功能；邻域操作；以及连接功能。参见：数字计算机；遥感。[H.Co.]

地理信息系统的商业应用日益普及，包括市场分析、商店选址和抗生素（例如，确定耕作田地每个点所需的肥料或农药的正确数量）。工程师在建模地形、建造道路和桥梁、维护地籍图、车辆路由、钻探水源、确定从地形上任何一点可见的内容、整合敌方目标的情报信息等方面使用地理信息系统。这类应用通过地理信息系统与全球定位系统的集成得到了促进。参见：坐标系统；卫星导航系统。

该技术最早且仍然最广泛的应用之一是土地信息和资源管理系统（例如，森林和公用事业管理）。在城市政策背景下，地理信息系统的其他常见用途包括紧急计划、确定消防站和其他公共服务的最优位置、协助犯罪控制和记录、以及选举和学校重新定向。地理信息系统的使用已经远远超出了其源学科地理学的范围，现在涉及大多数处理空间数据的综合科学，包括社会科学和自然科学。这些领域中地理信息系统应用的性质范围从简单的用于说明的主题制图到复杂的用于假设探索或动态过程表征的统计和数学建模。[H.C.]

## 地理学

对自然和人文景观、影响它们的过程、它们如何及为何随时间变化，以及它们如何及为何在空间上分布的研究。地理学家在不同程度上考虑自然和人类对景观的影响，尽管通常有一个将人文地理学和自然地理学分开的一般划分。自然地理学家可能研究地貌（地貌学）、水（水文学）、气候和气象（气候学）、生物环境（生物地理学）或土壤（土壤学）。人文地理学家包括城市、区域和环境规划者；文化地理学家；区域和地区专家；经济地理学家；政治地理学家；交通分析师；选址分析师；以及民族或性别问题的空间性质专家。参见：生物地理学；气候学；地貌学；水文学；土壤学。

许多地理学家参与支持空间分析研究或作为数据展示空间信息的技术和应用开发。地图，无论是印刷的、数字的还是概念的，都是地理学的基本工具。地理学家参与地图解释和使用，以及地图制作和设计。制图员监督地图、地球仪和其他图形表示的汇编、设计和开发。参见：制图学。

地理信息系统（GIS）是一项相对较新的技术，它将计算机辅助制图的优势与空间数据库管理的优势结合起来。它促进了空间信息的存储、检索和分析，形式为数字地图“叠加”，每个代表不同的景观成分（地形、水文特征、道路、植被、土壤类型或任何可绘制因素）。这些数据层中的每一个都可以数字拟合到相同的地图比例尺和地图投影——以任何组合——允许分析输入到地理信息系统中的任何组合的环境变量之间的关系。参见：地理信息系统。

许多地理学家是应用实践者，使用各种工具解决问题，包括计算机辅助制图、统计方法、遥感图像、全球定位系统（GPS）和地理信息系统。如今，几乎所有地理学家都使用，或他们专业领域的某些部分使用。参见：地球资源模式；自然地理学；地形区域。[J.F.P]

## 地质测温

测量或估计地质过程发生时的温度。

使用的方法可分为两组：非同位素和同位素。非同位素方法通过地表和近地表特征直接测量地球温度，或通过矿物和化石的各种性质间接测量。同位素方法涉及确定较轻元素的各种同位素在不同温度下平衡态的化合物对之间的分布，并将这些数据应用于这些化合物（通常是矿物）在自然界中形成的温度问题。[E.I.]

## 地质时间尺度

一个有序的、内部一致的、国际公认的时间间隔序列，每个间隔在其历史和地球生命记录中都是独特的，包括将绝对时间（以年为单位）分配给每个地质时期。地质时间尺度（见表）有一个相对时间尺度，由按历史顺序排列的命名地质历史间隔组成；以及一个数值（或绝对）时间尺度，为这些间隔的边界提供绝对年代。
