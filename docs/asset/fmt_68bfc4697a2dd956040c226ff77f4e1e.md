以下示例显示了一个具有四个选项的 `KComboBox`。在鼠标移动后，该组件会弹出列表，并以第三个选项作为默认值。
```cpp
/* showcombobox.cpp */
#include <app.h>
#include <kcombobox.h>
const char *list[] = {
    "First Selection",
    "Second Selection",
    "Third Selection",
    "Fourth Selection"
};
int main(int argc, char **argv) {
    KComboBox *combobox = new KComboBox();
    combobox->insertStrList(list,4);
    combobox->show();
    app.mainWidget(combobox);
    return(app.exec());
}
```
