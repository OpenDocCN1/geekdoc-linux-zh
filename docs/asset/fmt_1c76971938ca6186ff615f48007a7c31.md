
在我们卸载文件系统并使用 `raidstop` 停用阵列后，我们就可以创建更复杂的镜像。在本例中，我们将创建一个由两个 RAID 0 级阵列组成的镜像。这需要在 `/etc/raidtab` 中使用三个段落，并且在这种情况下，条目的顺序至关重要。`/etc/raidtab` 文件是顺序解析的，因此我们必须先定义两个 RAID 0 级阵列，然后再定义镜像。下面是其外观：

### 由两个条带阵列组成的镜像

```
raiddev    /dev/md0

raid-level 0

persistent-superblock 0

chunk-size 32

nr-raid-disks 2

nr-spare-disks 0

device     /dev/sdb1

raid-disk  0

device     /dev/sdc1

raid-disk  1

raiddev    /dev/md1

raid-level 0

persistent-superblock 0

chunk-size 32

nr-raid-disks 2

nr-spare-disks 0

device     /dev/sdd1

raid-disk  0

device     /dev/sde1

raid-disk  1

raiddev /dev/md2

raid-level 1

persistent-superblock 0

chunk-size 32

nr-raid-disks 2

nr-spare-disks 0

device /dev/md0

raid-disk 0

device /dev/md1

raid-disk 1
```

这种设置的一个优点是，对镜像组件的写入可以获得 RAID 0 级的性能优势，同时镜像在读操作上也有性能优势。这种组合在网络上一些 Linux RAID 文档中被错误地称为 RAID 10。实际上它与 RAID 10 正好相反，RAID 10 是由两个 RAID 1 级阵列组成的 RAID 0 级阵列。下面是创建此配置的外观：
