
# Python 文件操作与数据结构

以下程序打开一个文件并逐行读取内容：

```python
f = open("foo.txt")  # 返回文件对象
line = f.readline()  # 在文件上调用 readline() 方法
while line:
    print line,
    print(line, end='')  # 末尾的 '\n' 忽略换行符
    line = f.readline()  # 在 Python 3 中使用
f.close()
```

`open()` 函数返回一个新的文件对象。通过调用此对象上的方法，你可以执行各种操作。`readline()` 方法返回单行输入，包括终止的换行符。文件末尾会返回空字符串。

在示例中，程序简单地遍历了 `foo.txt` 文件中的所有行。当程序遍历数据集合（例如输入、数字、字符串等）时，通常被称为迭代（iteration）。因为迭代是一个非常常见的操作，Python 提供了一个专门的语句用于迭代各个项。例如，同样的程序可以写得更简洁，如下所示：

```python
for line in open("foo.txt"):
    print line
```

列表 1.2 中的程序通过从命令行指定的读取读取数字列表并输出最大值，展示了列表的几个高级特性。

## 列表 1.2 高级列表特性

```python
import sys # 加载 sys 模块
if len(sys.argv) != 2 # 检查命令行参数的数量
    print("Please supply a filename")
    sys.exit(1)
f = open(sys.argv[1]) # 命令行上的文件名
lines = f.readlines() # 将所有行读入列表
f.close()
```

```python
### 将所有输入值从字符串转换为浮点数
fvalues = [float(line) for line in lines]
```

```python
### 打印最小值和最大值
print("The minimum value is ", min(fvalues))
print("The maximum value is ", max(fvalues))
```

该程序的第一行使用 `import` 语句从 Python 库中获取 `sys` 模块。该模块被加载用于获取命令行参数。

`open()` 函数使用了作为命令行选项提供并放在 `sys.argv` 中的文件名。`readlines()` 方法将所有输入行返回为一个字符串列表。表达式 `[float(line) for line in lines]` 通过遍历列表中的所有字符串并对每个元素应用 `float()` 来构建新列表。这种特别强大的列表构建方法被称为列表推导式。文件中的行也可以使用循环读取，通过像这样的单语句转换值来缩短程序：

```python
fvalues = [float(line) for line in open(sys.argv[1])]
```

在将输入行转换为浮点数列表后，内置的 `min()` 和 `max()` 函数计算最小值和最大值。

## 元组

为了创建简单的数据结构，你可以使用 `tuple` 将一组值打包成一个简单对象。你通过将一组值括在括号中创建一个元组，如下：

```python
stock = ('GOOG', 100, 490.10)
address = ('python.org', 80)
person = (first_name, last_name, phone)
```

如果缺少括号，Python 经常能识别出元这是一个元组：

```python
stock = 'GOOG', 100, 490.10
address = 'python.org', 80
person = first_name, last_name, phone
```

为了完整性，可以定义 0 个元素和 1 个元素的元组，但它们有特殊的语法：

- `a = ()` 空元组
- `b = (item,)` 注意末尾逗号
- `c = item,` 注意末尾逗号

元组中的值可以像列表一样通过数字索引提取。然而，更常见的做法是将元组解包为一组变量，如下：

```python
name, shares, price = stock
host, port = address
first_name, last_name, phone = person
```

虽然元组支持列表的大多数操作（如索引、切片和拼接），但元组在创建后不可修改（也就是说，你不能向现有元组中替换、删除或添加新元素）。这反映了元组被视为一个由多个部分组成的单一对象，而不是一个你可能会插入或删除项目的对象的集合。

由于元组和列表之间没有重叠，通常使用列表，因为它们看起来更灵活。然而，如果你要创建大量列表（即包含少于12个项的列表），将会浪费内存。列表会稍微分配内存以优化添加新项的操作性能。由于元组是不可变的，它们使用更紧凑的表示方式，其中没有额外空间。

元组和列表经常结合使用来表示数据。例如，此程序展示了你如何读取一组用逗号分隔的不同数据集：

```python
# 格式为 "name,shares,price" 的文件行
filename = "portfolio.csv"
portfolio = []
for line in open(filename):
    fields = line.split(",") # 将每行分割为列表
    name = fields[0] # 提取并转换单个字段
    shares = int(fields[1])
    price = float(fields[2]) # 创建元组 (name, shares, price)
    stock = (name, shares, price)
    portfolio.append(stock) # 添加到记录列表中
```

字符串的 `split()` 方法根据指定的分隔符将字符串分割为字符串列表。此程序创建的 `portfolio` 数据结构看起来像一个行列组成的二维数组。每行由一个元组表示，并如下所示访问：

```python
>>> portfolio[0]
('GOOG', 100, 490.10)
>>> portfolio[1]
('MSFT', 50, 54.23)
```

## 集合

集合是唯一元素的无序集合。与列表和元组不同，集合没有索引，因此你不能通过位置访问元素。然而，集合进行成员测试非常高效。

创建集合时可以使用大括号或 `set()` 函数：

```python
>>> s = {1, 2, 3}
{1, 2, 3}
>>> s = set([1, 2, 3])
{1, 2, 3}
```

你可以使用 `add()` 和 `update()` 方法向集合添加元素：

```python
>>> s.add(4)
{1, 2, 3, 4}
>>> s.update([5, 6])
{1, 2, 3, 4, 5, 6}
```

要删除元素，可以使用 `remove()` 或 `discard()`：

```python
>>> s.remove(2)
{1, 3, 4, 5, 6}
>>> s.discard(10) # 如果元素不存在不会报错
{1, 3, 4, 5, 6}
```
