## 文本居中

现在“Hello Books”已经渲染了足够的顶部间距，我们希望将文本显示在屏幕中间。`Center` (`Center`) 组件将其子组件居中。将`Text` (`Text`) 组件封装在`Center`组件中，可以将“Hello Books”显示在屏幕中心。

```dart
class HelloBooksApp extends StatelessWidget {

}
```
