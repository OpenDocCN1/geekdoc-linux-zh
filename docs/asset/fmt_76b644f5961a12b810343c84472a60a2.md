
# `pactl load-module module-role-ducking,trigger-roles-phone ducking_roles=music,video volume=-10dB`

```
pactl load-module module-role-ducking,trigger-roles-phone ducking_roles=music,video volume=-10dB
```

然后通过示例播放确保其工作正常，例如：

- `pactl ls`
- 列出项目，同时：
- `pactl ls si properties` 显示当前使用的输出设备的属性。此命令可以缩短为：

```
$ PULSE_role='media.role:phone' player -o audio.sample.mp3
```
