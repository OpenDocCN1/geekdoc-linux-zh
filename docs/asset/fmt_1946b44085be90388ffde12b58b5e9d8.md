
## 第 10–20 题解析

1. D. `logger` 工具可用于创建你指定的、一次性的日志文件条目。在最简单的形式下，它不需要任何特殊参数，只需要要插入日志文件中的消息，如选项 D 所示。选项 A 中的 `dmesg` 工具用于查看内核环形缓冲区；它不会创建日志文件条目。选项 B 中的 `syslog` 命令不是 Linux 用户态命令，尽管它是日志系统的通用名称，也是一个编程语言命令。选项 C 的 `rsyslog` 是几个系统日志守护进程之一的名称；它维护系统日志，但不用于手动插入日志条目。选项 E 的 `wall` 命令向所有登录到虚拟控制台终端的用户发送消息。它不会创建问题所要求的日志文件条目，且并非在所有发行版中都安装了。

2. C. 通过在 `cron` 中为其添加条目，可以定期且无人干预地启动 `logrotate` 程序，因此选项 C 是正确的。如果你想让程序只运行一次，则会使用 `at` 工具（选项 A）。选项 B `logrotate.d` 是存储在 `/etc` 目录下的文件，定义了程序如何处理特定的日志文件。`initabb ntpd` 程序（选项 E）是网络时间协议守护进程，用于将系统时钟与外部源时间同步。

3. E. `hwclock` 工具用于查看或设置硬件时钟。`--systc` 根据软件时钟的当前值设置硬件时钟，因此选项 E 是正确的。选项 A 的 `date` 工具可以设置软件时钟但不能硬件时钟；它没有 `--hwclock` 选项。选项 B 的 `nptdate` 用于将软件时钟设置为 NTP 服务器维护的时间；选项 C 的 `sysclock` 工具是虚构的。选项 D 的 `time` 命令用于计算命令完成所需的时间；它没有 `--set` 或 `--hw` 选项，且不设置硬件时钟。

4. A. `date` 命令日期代码的格式为 `[MMDDhhmm[[CC]yy[.ss]]`。由于问题指定了一个八位代码，这意味着项目以两位数字为块的排列顺序是：月-日-时-分。选项 A 正确解析了此顺序，而选项 B、C、D 和 E 则没有。

5. `etcnt conf` 中的多个服务器条目配置系统轮询所有命名的服务器，并向提供最佳时间数据的服务器请求时间。选项 C 是正确的。（`pool.ntp.org` 子域名和子域名内的编号计算机提供了对各种公共时间服务器的轮询访问。）选项 A 和 B 都错误地声称某条语句高估了数量，但事实并非如此。问题中显示的服务器语句格式正确，因此选项 D 是错误的。虽然如选项 E 所述，如果公共池服务器不可用，该配置确实会指向 `tardis.example.com`，但这并不是 NTP 服务器使用 `tardis.example.com` 的唯一原因；例如，如果池服务器提供了较低的时间信号，也会发生这种情况。因此选项 E 是错误的。

6. D. 一旦你配置了网络中的一台计算机使用外部时间源并运行 `ntp`，其余计算机都应使用第一台计算机作为时间参考。这种做法减少了外部服务器的负载以及你自己的外部流量。因此选项 D 是正确的。（非常大的网络可能会配置两个或三个内部服务器来引用外部服务器以冗余，这对于问题描述的小型网络并非必要。）选项 A 描述了当公共池服务器不可用时，为配置好的计算机定位时间服务器的程序（`gateway.pangaea.edu`），但对于后续计算机并非如此。使用 `.example.com` 而不是 `gateway.pangaea.edu` 是可能的，但这会增加你的网络流量和 `.example.com` 服务器的负载。因此选项 B 和 C 都是错误的。与选项 E 相，NTP 适用于某些小型网络，在在使用 `Kerberos` 等协议时非常有用。

7. B, D. `cron` 工具适用于可以以无人干预方式执行的任务，例如删除临时文件（选项 B）或检查磁盘空间是否不足（选项 D）。需要交互或按计划执行的任务（如创建账户，选项 C）不属于 `cron` 任务。虽然 `cron` 任务可以在系统启动时重启（选项 A），但它并不用于调度 `.example.com`。将文件发送到打印机（选项 E）通常由 `cupsd` 守护进程处理。

8. B. `cron` 任务不包含用户名指定（选项 A 和 C）。选项 C 和 D 中的 `*/` 规格导致任务每小时执行一次；选项 A 和 B 中的 `7,19` 规格导致每天执行两次（配合 `15` 分钟规格，即 7:15 a.m. 和 7:15 p.m.）。因此选项 B 提供了正确的语法每天运行两次，如问题所示，而选项 A、C 和 D 都是错误的。选项 E 导致任务每天运行一次，而不是两次。

9. B. `anachron` 程序是 `cron` 的补充，确保日志轮、每日备份和其他任务在计算机关闭时（以及 `cron` 未运行时）也能处理。这是向系统以以所述目标的方法，选项 B 是正确的。没有常见的 Linux 工具 `tempus`，所以选项 A 是错误的。`ntpd` 程序（选项 D）是 NTP 守护进程，帮助系统时钟与外部源同步。虽然在笔记本上运行 `ntpd` 是可能的，但它不会直接帮助日志轮的任务。`syslog-ng` 包是一个替代守护进程，但该程序无法解决使用标准 `cron` 时错过备份的问题，因此选项 E 是错误的。

10. E. 命令在未来的指定时间运行指定的程序。这可以通过多种方式指定，其中一种代表 4:00 p.m.。因此选项 E 是正确的。选项 A、B、C 和 D 中的反对均无效。（你可以通过 `-f` 参数将脚本传递给 `at`，但这不是要求的。）

11. A, C. `etcdaily` 的内容在大多数 Linux 发行版中每天运行，`crontab` 工具可以创建在任意时间间隔运行程序的 cron 任务，因此 A 和 C 都是正确的。选项 B 中的 `at` 命令可运行一次程序，但不是定期运行（如每日）。选项 D 的 `runparts` 工具被某些发行版用于帮助在 `etc/cron.*` 子目录下运行程序，但它不用于调度任务。虽然 `crontab` 程序可以维护用户的 crontab，但它并非如选项 E 所示的使用，且没有 `-d` 参数。

## 第 8 章：配置基础网络

1. A, B, E. 以太网（选项 B）是目前本地网络最常见的有线硬件。Linux 支持良好，还包括支持令牌环（选项 A）和光纤通道（选项 E）硬件。DHCP（选项 C）是在 TCP/IP 网络上获取 TCP/IP 配置的协议。它不是一种网络硬件，但可以在支持 TCP/IP 的硬件上使用。NetBEUI（选项 D）是一种网络栈，可以在多种网络硬件上替代或补充 TCP/IP。Linux 不直接支持 NetBEUI。

2. B. IP 地址由四个单字节数字（0–255）组成。它们通常以十进制表示并用句点隔开。`63.63.63.63` 符合这些标准，因此选项 B 是正确的。`202.95.27.33` 包含一个不是单字节数字的数值（`257`），因此选项 A 是错误的。`107.29.53.2` 包含了五个单字节数字，因此选项 C 是错误的。`98.7.104.0/24`（选项 D）是一个网络地址——末尾的 `24` 表示最后一个字节是机器标识符，前 3 个字节指定网络。选项 E `255.255.255.255` 构成了 IP 地址的基本形式，但它是一个特殊情况——这是一个广播地址，指向所有计算机而不是问题指定的单一计算机。

3. 网关计算机是在两个或多个网络段之间传输数据的路由器。因此，如果计算机未配置网关，它将无法与本地网络段之外的通信，选项 C 是正确的。与本地网络段内的其他系统通信不需要网关，因此选项 A 是错误的。网关在 IPv4 和 IPv6 网络中具有相同的功能，因此选项 D 是正确的。DHCP 不需要网关即可运行，只要 DHCP 服务器与其客户端位于同一本地网络段（通常情况下如此），因此选项 E 是错误的。

4. D. 安全外壳（SSH）协议使用端口 `22`，因此如果指向端口 `22` 的流量使用了正确的协议，它就是 SSH 流量，选项 D 是正确的。

超文本传输协议（HTTP；选项 A）通常绑定到 `80` 端口；简单邮件传输协议（SMTP；选项 B）使用 `25` 端口；Telnet（选项 C）使用 `23` 端口；以及网络新闻传输协议（NNTP；选项 E）使用 `119` 端口。这些协议中通常不会指向 `22` 端口。

5. D. 交互式邮件访问协议（IMAP）被分配到 TCP 端口 `143`。端口 `21`、`25`、`110` 和 `443` 分别分配给文件传输协议（FTP）、简单邮件传输协议（SMTP）、邮局协议第 3 版（POP3）和基于 SSL 的超文本传输协议（HTTPS）。尽管某些 IMAP 服务器程序也支持 POP3，因此可能同时监听 `110` 和 `143` 端口，但题目指定的是 IMAP 交换，因此选项 D 是唯一正确答案。

6. E. 选项 C `dhcp` 是 DHCP 服务器。选项 E `ifconfig` 可用于网络配置，但本身不是 DHCP 客户端。其他所有都是 DHCP 客户端。任何计算机都只会使用一个 DHCP 客户端（或不使用），但 A、B 或 D 中的任何一个都是选项。
