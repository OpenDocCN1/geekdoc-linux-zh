
# Ubuntu 安装与配置指南

## 设置根分区

您需要执行的最后一个分区任务是设置根目录 `/`。这是 Ubuntu 安装的地方，它将使用所有剩余空间。将挂载点设置为 `/` 并点击“确定”。

![](img/55dc7df089fe0011a7e15a61689f37ea_15_2.png)

从下方的屏幕点击“安装”。

## 安装配置

现在您已准备好继续了。Ubuntu 现在将开始安装到您的计算机。在复制期间，您需要设置一些设置：

1. 在世界地图上选择您所在的区域，以便 Ubuntu 正确设置日期和时间
2. 选择计算机名称或键盘
3. 通过列表中选择语言和类型来配置计算机和鼠标设置

完成后，点击“下一步”。

## 用户账户设置

系统将提示为计算机输入用户名和密码。输入密码，Ubuntu 将告诉您密码是弱密码还是强密码。您可以更改 PC 的名称。

- 如果您希望自动登录，Ubuntu 将直接启动到桌面
- “记住我的密码”选项安全得多
- 如果您选择后者，还可以选择“加密我的主文件夹”以增加安全性

准备就绪后，点击“下一步”。

## 笔记本电脑安装

在便携式电脑上安装 Ubuntu——即使是配置相对较低的电脑——也能让它焕发新生。Linux 的最大优点之一是与 Windows 相比，它需要的资源较少。这对于像上网电脑（netbooks）这样的低配置电脑尤为重要。Windows 可能会是一个资源大户，并且并不是为小屏幕运行设计的，而 Ubuntu 的设计旨在充分利用低分辨率和运行速度较慢的机器性能。

### 准备工作

在开始之前，你需要打开电脑并进入 Windows。Windows 上网电脑或笔记本电脑需要 Windows 软件才能使快捷键生效。这些键在 Ubuntu 中可能无法工作，因此最好依赖于无线网络或其他你可以使用的设备。完成后，关闭电脑。

### 创建启动 U 盘

安装文件可以从 `http://ubuntu.com` 免费下载。点击链接将把 CD 大小的 ISO 文件下载到你的电脑。

**使用 USB 光驱：**
如果你的上网电脑或笔记本电脑带有 USB 光驱驱动器，可以使用 CD 刻录软件（`CDBurnerXP`）作为一个极佳的免费选择，将 ISO 写入 USB 驱动器。

**使用 U 盘（推荐）：**
由于我们大多数人没有光驱驱动器，因此使用 U 盘更好。你需要一个容量至少为 2GB 的驱动器。确保你已备份存储在上面的任何文件，因为使用它时驱动器会被格式化。我们遇到过某些 USB 驱动器无法被电脑识别，所以如果一个无法工作，你可能需要另一个。

打开一台运行 Windows 的电脑，将选择的驱动器插入电脑，并通过点击开始菜单记录它的驱动器编号。记住这一点至关重要，否则你可能会丢失重要数据。

![](img/55dc7df089fe0011a7e15a61689f37ea_17_0.png)

### BIOS 设置

接下来，配置你的上网电脑或笔记本电脑从 USB 驱动器启动。将 USB 插入 USB 端口并打开笔记本。你需要按下正确的键进入 BIOS：这通常是 `F2` 或 `F10`，但请留意屏幕上的任何信息。

进入 BIOS 后，寻找“启动优先级”（Boot Priority）部分。这在每台电脑上的位置都不一样，所以你可能需要到处找找。一旦找到，将第一个启动设备设置为你的 USB 驱动器：

![](img/55dc7df089fe0011a7e15a61689f37ea_18_0.png)

完成后，选择保存设置并退出 BIOS 的选项。你的笔记本电脑应该重启并从 USB 驱动器启动。你看到的第一个界面是菜单：
- 第一个选项允许你在不安装系统的情况下尝试 Ubuntu
- 第二个选项允许你在笔记本电脑上安装此操作系统

### 通用 USB 安装程序

要让 U 盘变为可启动状态，你需要从 `http://ubuntu.com/download` 下载通用 Ubuntu 安装程序并从你的 USB 驱动器运行它。你可以从下拉列表中进行选择。你会发现所有最流行的发行版的选择，并且有一个下载版本 ISO 文件的选项；然而，Ubuntu 11.04 可能不在列表中。如果没有，请从第一个下拉菜单中选择“其他 ISO”。点击“浏览”按钮并导航到你下载的 Ubuntu ISO 文件。

首先，插入你的 U 盘并按照你之前记录的步骤操作，点击格式化驱动器并点击“创建”。你的 U 盘将自动转换为启动盘。

# Ubuntu 桌面巡检

一旦 Ubuntu 运行起来，你就能轻松熟悉它的操作。在这里，我们将带你对桌面进行一次快速的巡检。

Ubuntu 11.04 拥有全新的 Unity 界面，它消除了许多旧版菜单。点击 Ubuntu 按钮打开搜索栏。输入内容将匹配应用程序和文档，其操作方式类似于 Windows 7 的开始菜单。

![](img/55dc7df089fe0011a7e15a61689f37ea_21_0.png)
![](img/55dc7df089fe0011a7e15a61689f37ea_22_0.png)

### 启动器

启动器（Launcher）是一个用于应用程序快捷方式的专用栏。当前运行的应用程序旁边会有白色箭头。
- 若要将应用程序保留在启动器中：右键点击并选择“保留在启动器中”
- 要从启动器中移除应用程序：只需取消勾选即可
- 如果启动器消失了：将鼠标移动到屏幕左侧

### 通知区域

这是通知区域，看起来和 Windows 一样。图标会出现在这里通知你各种功能的状态：
- Wi-Fi 信号强度（由蓝色条指示）
- 点击扬声器图标更改音量
- 点击信封图标将显示所有消息应用程序的菜单，包括 Empathy（Ubuntu 的默认消息程序）

![](img/55dc7df089fe0011a7e15a61689f37ea_22_1.png)

### 用户菜单

点击你的用户名会弹出一个类似于 Windows 关机菜单的界面。这允许你：
- 重启电脑
- 进入睡眠模式
- 切换到不同的用户账户
- 关闭电脑

用户名左侧的图标显示你当前的即时通讯状态。

### 标题栏菜单

与 OS X 一样，应用程序共享一个标题栏，其中包含菜单（文件、帮助等）。将鼠标悬停在此区域即可查看菜单。

![](img/55dc7df089fe0011a7e15a61689f37ea_22_2.png)

### 文件管理

在 Ubuntu 中，在文件和文件夹之间导航非常简单。如果你在 Windows 中这样做，你会感到如归在家。从菜单到导航图标和文件夹列表，几乎所有内容看起来都像 Windows。它预创建了文档、音乐、图片和视频文件夹。

# 添加外设

如果安装硬件的想法让你对 Linux 望而却步，请重新考虑：现在在 Ubuntu 中添加外设变得非常容易。

曾几何时，在同一个句子中出现“Linux”和“硬件”就足以让 IT 专家流泪，但现在不再了。Linux 已经成长了，处理外设时就像 Windows 一样简单。在过去的几年里，开源开发者忙于为 USB 和蓝牙编写驱动程序和应用程序，这使得他们的工作变得更加轻松，但与任何操作系统一样，仍有一些问题需要注意。Windows 经常会有当前硬件出现问题，而 Linux 则倾向于让过时的硬件引起问题。在 Ubuntu 中，支持得非常好，以至于你可能遇到的唯一问题就是决定你想在设备上使用哪些应用程序。在接下来的页面中，我们将展示如何使用 Ubuntu 安装一系列常见外设。

## 音频建议

在 Linux 中，让硬件运行起来不应该存在任何问题，任何现代声卡都可以直接工作。Linux 硬件的工作方式与 Windows 不同，因此值得查看一下情况。

点击 Ubuntu 图标并输入“设置”（Settings）然后按回车加载控制中心（Control Centre）。选择“声音”（Sound）选项：如果你在播放 CD 时找不到任何东西，这应该是你首先查看的地方。“声音偏好”（Sound Preferences）对话框列表在“硬件”（Hardware）选项卡的下拉菜单中列出了可用设备。在大多数情况下，这将是同一个声卡。

### 常见音频问题排查

一个常见的音频问题是由扬声器插入 PC 的音频接口并让 Linux 使用数字输出引起的。如果观察到错误或者在“声音偏好”对话框选择的音频设备名称中看到“数字”（Digital），请按以下步骤纠正：

1. 使用下拉菜单将其更改为“模拟立体声”（Analog Stereo）并点击“测试”按钮。这应该产生一个稳定的音调
2. 如果没有，尝试“音频输出系统”（OSS）下拉选项
3. 如果你听到任何噪音，请尝试“自动检测”（Autodetect）

### 系统声音自定义

你还可以使用此对话框更改为系统事件播放的声音。在“声音”（Sounds）选项卡上，你会看到一个事件列表，每个事件的状态为“默认”（Default）或“禁用”（Disabled）。如果你点击状态并选择“自定义”（Custom），就可以导航到你选择的声音文件。

一旦板载声音正常，你就可以从任何 USB MP3 播放音乐了。
