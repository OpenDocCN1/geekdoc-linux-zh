记住，你在这里定义的变量可以命名为任何你，并且 `do... done` 内部的所有行将为数组中的每个元素执行一次。让我们观察脚本的输出：

现在，假设我们想让输出看起来更人性化化。我们希望问候在同一行。

```bash
#!/bin/bash
2
### a friendly script to greet users
4

if [ $# -eq 0 ]
then
    echo "Please enter at least one user to greet."
    exit 1
else
    echo -n "Hello $1"
11 shift
12 for username in $@
13 do
14 echo -n ", and $username"
15 done
16 echo ""
17 exit 0
18 fi
```

几点说明：

- 在 `echo` 使用 `-n` 将抑制打印后的换行。这意味着所有的 `echo` 将打印在同一行，并且只有在第 16 行的 `echo ""` 之后才会打印换行。

- `shift` 命令将删除我们数组的第一个元素，使得：

| | 1 | 2 |

| Carol | Dave | Henry |

变成：

| 0 | 1 |

| Dave | Henry |

让我们观察输出：

```bash
$ ./friendly2.sh Carol
Hello Carol!
$ ./friendly2.sh Carol Dave Henry
Hello Carol, and Dave, and Henry!
```

# Linux 内核与 Linux 发行版

在谈论 Linux 发行版时，操作系统是 Linux。Linux 是*内核*，也是每个 Linux 发行版的核心。Linux 内核的软件由一组个人维护，林纳·托瓦尔斯（Linux Torvalds）领导。托瓦尔斯受一家名为 Linux 基金会（The Linux Foundation）的行业联盟聘用从事 Linux 内核。

> Linux 内核最早由芬兰的学生林纳·托瓦尔斯于 1991 年开发。1992 年，在 GNU 通用公共许可证第 2 版 (GPLv2) 下发布的第一个内核版本是 0.12 版本。

### Linux 内核

正如我们所提到的，所有 Linux 发行版运行的都是同一个操作系统 Linux。

### Linux 发行版

当人们谈论红帽 Linux（Red Hat Linux）或 Ubuntu Linux 时，他们指的是*Linux 发行版*。Linux 发行版将带有一个 Linux 内核和一个环境，该环境以我们能够交互的方式使内核有用。至少我们需要一个像 Bash 这样的命令行 shell 以及一组允许我们访问和管理系统的基本命令。当然，开源的 Linux 发行版将具有完整的桌面环境，如 Gnome 或 KDE。
