
# 晶体生长

块状单晶体通常从液相生长。液体可能具有与固体大致相同的组成；它可能是主要由晶体的一个组分组成的溶液；或者它可能是溶剂在晶体组成中至多占很小比例的溶液。最重要的块状晶体生长技术是晶拉法或直拉法（`Czochralski法`），其中旋转的种子晶体被浸入熔体中（图 2）。旋转减少了径向温度梯度，旋转种子的缓慢抽出导致单晶材料圆柱体的生长。晶体直径和长度取决于温度和拉速的细节以及熔体容器的尺寸。晶体质量非常关键地取决于最小化增强位错形成的温度梯度。直径 6 英寸（15 cm）的拉制硅晶体对半导体工业至关重要。红宝石、蓝宝石和第 13–15 族化合物半导体晶体是通过直拉法常规生长的众多晶体中的一些。

非常薄但质量极高的外延层生长方法的演进在很大程度上是由于需要半导体和磁性石榴石这样的外延层。与用于块状晶体生长的方法最相关的技术是液相外延。对于典型的二元半导体，生长是在基底单晶晶圆上进行，来自富含最低分压组分的溶液。对于二元化合物，生长层可能仅在摩尔浓度上有所不同，以改变其电学特性。更常见的是，需要具有不同主要成分组成但具有相同晶体结构和晶格常数的多层结构。具有层间主要成分变化的液相外延的最简单例子是在砷化镓（`GaAs`）衬底上生长铝镓砷（`AlGa$_{1-x}$As; $1 > x > 0$`）层。

通过液相外延进行生长是在类似设备中进行的，外面的晶圆通常与具有所需组成的溶液接触，并且可以过饱和或冷却以实现生长。对于除 `AlGa$_{1-x}$As` 之外的晶体固溶体，需要非常精确地控制溶质组成以实现晶格匹配。通常，通过液相外延生长的结构具有四到六层，组成范围广泛，厚度从 `$10^{-7}$` 到 `$10^{-5}$` 米。

对大晶圆区域上可高度重复生长的13–15族化合物及更薄的外延层的需求导致了分子束外延和几种形式的化学气相沉积的发展。分子束外延是一种超高真空技术，其中由加热蒸发炉提供的晶体组成元素的原子或分子束撞击加热的衬底晶体。它已被用于生长薄至 0.5 纳米的外延层。分子束外延也用于第 12–16 族化合物和硅。参见 `ARTIFICIALLY LAYERED STRUCTURES`（人工分层结构）；`MOLECULAR BEAMS`（分子束）；`SEMICONDUCTOR`（半导体）；`SEMICONDUCTOR HETEROSTRUCTURES`（半导体异质结构）；`VAPOR DEPOSITION`（气相沉积）。 [M.B.P]

# 晶体光学

研究光在晶体固体中的传播及相关现象。对于简单立方晶体，原子排列使得晶体在通过晶体的每个方向上都呈现出相同的光学外观。在各向异性晶体中，原子在某些穿过材料的平面中比在其他平面中更靠近。在各向异性晶体中，不同方向上的光学特性不同。在经典物理中，电磁波在材料中的行进涉及电子的周期性位移。在各向异性晶体中，抵抗这些位移的力取决于位移方向。因此，光波在不同方向以及不同偏振态下的速度不同。波的吸收在不同方向上也可能不同。参见 `DICHROISM`（二色性）；`TRICHROISM`（三色性）。

在各向同性介质中，点光源的光在球形壳中扩散。嵌入各向异性晶体中的点光源的光在两个波面中扩散，其中一个比另一个传播得更快。光的偏振在每个波面上从点到点变化，并且在来自源点的任何特定方向上，两个表面的偏振是相反的。这些表面的特性可以通过对给定晶体进行实验测量来确定。

在透明的各向异性介质的一般情况下，介电常数在三个正交方向上不同。

因此，有许多晶体例如关于某轴具有四重或六重旋转对称性，对于这些晶体，折射率椭球不能有不相等的三个轴，而是一个旋转椭球体。在这种晶体中，光沿该轴传播时，就好像晶体是各向同性的一样，传播速度与偏振状态无关。折射率椭球垂直于该方向的截面是一个圆。这样的晶体被称为**单轴晶体**，其光学行为的数学描述相对简单。

在低对称性晶体中，折射率椭球具有三个不相等的轴。这些晶体被称为**双轴晶体**，并且具有两个方向，在这些方向上波速与偏振方向无关。这对应于椭球的两个圆形截面。参见**晶体学**。

平面波的波法线以**相速度**移动。**惠更斯波长**，即从点扰动向外传播的光，将以**射线速度**传播。正如可以使用折射率椭球来计算相速度或波速一样，也可以使用**射线椭球**来计算射线速度。该椭球的轴长由电矢量位于轴方向的线性偏振射线的速度给出。参见**相速度**。

光线穿过各向异性单轴晶体表面时的折射，可以按照与各向同性材料相同的方式，利用惠更斯波长进行计算。对于椭球形波前，这导致了一种与通常与折射相关行为完全不同的光学行为。

与此行为相关的射线被称为**异常射线**。在光轴以一定角度倾斜的晶体表面上，垂直入射的非偏振光线会被分裂成两束：**寻常射线**，它穿过表面而不发生偏折；以及**异常射线**，它被偏折，偏折角由从其中一个惠更斯椭球波面中心引至椭球与平行于表面的直线切点的线段确定。这两束光具有相反的线性偏振。 [B.H.H]

## 晶体结构

晶体结构 晶体中 atom、离子或分子的排列。晶体是在空间的三个维度上都具有规则重复内部结构单元的固体。

晶体已使用 X 射线进行研究，X 射线激发来自原子的信号。这些信号的强度不同，取决于原子核周围的电子密度分布。轻原子产生较弱的信号，而氢对 X 射线是不可见的。然而，被称为晶体结构的原子相互排列可以根据固体的化学公式和物理密度推导出来，这是基于这样的知识：原子位置不是任意的，而是由晶体对称性决定的，并且接收到的衍射信号是规则重复的内部图案单元内散射体之间系统建设性干涉的结果。参见**晶体学**；**多晶现象（晶体学）**；**X 射线晶体学**；**X 射线衍射**。

晶体在空间、种群和相互排列方面进行定义。晶体空间被表示为由周期性重复点组成的无限延伸晶格。晶格的周期性由包围图案的三个晶格矢量的长度和相互方向定义。种群定义为形成图案的基本结构单元的总数和种类。晶体的有序性和周期性必须在空间的三个维度上都延伸到大约 100 纳米，才能产生通过 X 射线绘制结构细节所需的尖锐定义的衍射信号。在中态有序中可以看到**液晶**，它们具有长的分子或基本结构单元。在**向列态**下，这些单元以长度彼此平行的方式排列，但没有周期性。在**烟晶态**下，有等间距平面中的取向，但没有横向周期性，就像在多车道高速公路上自由流动的交通一样。参见**液晶**。

实际上，晶体空间通常并不完美。生长过程以约束和湍流为特征，并以晶体及其环境之间的动态相互作用为特征。该过程反映在形成的结构中，即原子集合体被收集并通过释放称为**结晶热**的能量而变得相对静止。结果形成的晶体区域类似于略有不规则对齐的子晶体区域的马赛克。这对于 X 射线晶体学研究来说是有利的。完美对齐会导致由于反射束（主消光）的 180° 反转与初级光束干涉而减去能量。内部衍射束也会因来自其上方区域的内部反射而衰减（次级消光）。参见**晶体生长**。

假设单个晶体中每个空间上未对齐的马赛克块在其内部保持晶格周期性。这一假设通过观察到的尖锐衍射图样得到证实。存在一些“错误”原子、空位晶格位点、被困气体原子等，原子占据者会抖动，同时也以复杂的内部运动模式相干且同步地振动。密切的电子交换模式被执行，并且对于具有磁矩的原子，自旋取向的系统性变化可能会发生。这些细节对于理解原子和分子水平上的结构确定以及决定宏观性质和功能的协同行为之间的关系至关重要。参见**晶体缺陷**；**晶格振动**。

图中概述了一个具有两种可能单元的矩形空间晶格。它们具有相同的单元体积但不同的对称性。由于晶体学单位晶胞由三个晶格矢量完全定义，参考此晶格的晶体对称性不能高于**正交晶系**：`a ≠ b ≠ c` (`OA ≠ OB ≠ OC`)，且所有角度均等于 90°。与此相同的矢量 `a` 和 `b`（`OA` 和 `OB`）且有一个角度不等于 90° 的可能**单斜晶胞**也被概述。如果旋转 `OAB` 平面并将矢量 `a` (`OA`) 延伸至下一个晶格点，则所有角度均不等于 90°，表示的晶体对称性变为**三斜晶系**。晶胞种群的相互排列和原子坐标必须使得从空间晶格的每一点看过去的环境保持不变。
