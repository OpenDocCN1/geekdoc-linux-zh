# eject — 从驱动器中弹出如 CD-ROM 和软磁盘等介质

### 概要

```
/usr/bin/eject [-dfnpq] [device | nickname]
```

## 描述

将 `eject` 命令用于没有手动弹出按钮的可移动介质设备，或者用于那些由卷管理（参见 `void(1M)`）管理的设备。你可以通过其名称或别名指定设备；如果卷管理正在运行且未指定设备，`eject` 将使用默认设备。

> 注意 — 只有支持程序控制下弹出的设备会对此命令做出响应。`eject` 的响应取决于卷管理是否正在运行。

`eject` 还可以显示其默认设备和别名列表。

## 使用卷管理

当你对只能手动弹出的介质使用 `eject` 时，它会执行除移除介质以外的所有操作，包括在文件系统已挂载时时卸载它。在这种情况下，`eject` 会显示介质现在可以手动弹出。如果窗口系统正在运行，消息将以弹出窗口的形式显示；如果你使用 `-p` 选项，消息将同时显示在标准错误和介质现在可以物理移除。

卷管理具有默认设备的概念，如果你没有指定路径名或别名，`eject` 将使用它。使用 `-d` 选项检查使用的是哪个默认设备。

## 无卷管理

当卷管理未运行且你指定路径名时，`eject` 将弹出命令发送到该路径名。如果你提供别名而不是路径名，`eject` 将识别下方显示的别名。要显示此列表，你可以输入 `eject -n` 并按回车。

### 别名表

| 别名 | 路径 |
|---|---|
| fd | /dev/rdiskette |
| fd0 | /dev/diskette |
| fdl | /dev/diskette |
| diskette | /dev/diskette |
| disk0 | /dev/diskette |
| disk1 | /dev/diskette |
| floppy | /dev/diskette |
| floppy0 | /dev/diskette |
| floppy1 | /dev/diskette |
| rdiskette | /dev/rdiskette |
| rdisk0 | /dev/rdisk0 |
| rdisk1 | /dev/rdisk1 |
| rdsk | /dev/rdsk/c0t60 |
| s0 | /dev/rdsk/c0t30 |
| s2 | /dev/rdsk/c0t32 |

如果卷管理正在运行，`eject` 会显示介质现在可以手动弹出（参见 `mount(1)`）。例如，如果你有一个位于 `/dev/dsk/c0t32` 的 CD-ROM 驱动器已挂载，在卷管理运行的情况下，`eject` 会弹出 CD-ROM 驱动器。

### 缺陷

应该有一种按用户更改默认设备的方法。如果卷管理未运行，可以弹出已挂载的卷（参见 `mount(1)`）。例如，如果你有一个位于 `/dev/dsk/c0t32` 的 CD-ROM 驱动器已挂载，在卷管理未运行的情况下，`eject` 会弹出 CD-ROM 驱动器。

```
castle$ eject /dev/dsk/c0t30s2
```

弹出路径名为 `/dev/dsk/c0t30s2` 的 CD-ROM 驱动器，在卷管理未运行时。

```
/dev/dsk/c0t30s2
```

## 选项

- `-d` 显示要弹出的默认设备名称。
- `-f` 如果卷管理未运行，即使设备忙也强制弹出。
- `-n` 显示别名到设备的转换表。
- `-p` 不要尝试调用 `eject_popup` 程序。
- `-q` 查询介质是否存在。

## 操作

`device` 通过 `/dev` 目录中的名称指定要设备。
`nickname` 通过此命令已知的别名指定指定的设备。

## 示例

以下示例使用 `-d` 选项查找默认弹出设备。在第一个示例中，软磁盘或 CD-ROM 驱动器都没有介质。在第二个示例中，软磁盘驱动器中有软磁盘，使用 `volcheck` 命令通知系统它在那里。在第三个示例中，CD 在 CD-ROM 驱动器中而不在软磁盘驱动器中。

```
castle$ eject -d
默认设备：nothing插入

castle$ volcheck

castle$ eject -d
默认设备是:/vol/dev/rdisk0/unnamed_floppy

castle$ eject

castle$ eject -d
默认设备是:/vol/dev/rdsk/c0t6d0/jumpingjavascript

castle$ eject
```

以下示例在卷管理运行期间，从其驱动器中弹出 CD（假设只有一个 CD-ROM 驱动器）。

```
castle$ eject cdrom0
castle$ 
```

以下示例无论卷管理是否运行，都弹出软磁盘。

```
castle$ eject floppy0
castle$ 
```

> 注意 — 在卷管理未运行的情况下，必须是超级用户才能挂载、卸载和弹出 CD-ROM。

## 退出状态

- `0`: 操作成功，或者在使用 `-q` 选项时，介质在驱动器中。
- `1`: 操作失败，或者在使用 `-q` 选项时，介质不在驱动器中。
- `2`: 指定了无效选项。
- `3`: `ioctl()` 请求失败。
- `4`: 手动弹出的介质现在可以移除。

## 文件

- `/dev/diskette0`: 默认软磁盘文件。
- `/dev/sr0`: 默认 CD-ROM 文件（已弃）。
- `/dev/disk/c0t6d0s2`: 默认 CD-ROM 文件。
- `/usr/lib/v/eject_popup`: 用于手动弹出介质的弹出窗口。

## 属性

参见 `Attributes(5)` 获取以下属性的描述：

| 属性类型 | 属性值 |
| --- | --- |
| 可用性 | SUNWcsu |

## 诊断

如果指定未知选项，将打印简短的帮助信息。如果无法打开设备或设备不支持弹出，将打印诊断信息。

- 设备忙忙 (Device Busy): 尝试弹出已挂载文件系统的设备。在强制弹出已挂载设备时，会打印警告消息。

# elfdump — 导出对象文件的选定部分

### 概要

```
/usr/ccs/elfdump [-cdeihnprsvG] file [-w file] [-N name] filename ..
```

## 描述

使用 `elfdump` 命令以符号形式导出对象文件（s）的选定部分。选项允许你显示文件的特定部分。

`elfdump` 命令的功能与 `dump(1)` 命令相似，后者提供了一个较旧且不那么符合用户喜好的界面，尽管 `dump(1)` 在某些用途（如 shell 脚本）中可能更为合适。

要查看显示信息的完整描述，请参考《链接器与库指南》(Linker and Libraries Guide)。

## 选项

- `-c` 导出段头信息。
- `-d` 导出 `.dynamic` 节的内容。
- `-e` 导出 ELF 头部。
- `-i` 导出 `.interp` 节的内容。
- `-G` 导出 `.got` 节的内容。
- `-h` 导出 `.hash` 节的内容。
- `-n` 导出 `.note` 节的内容。
- `-N name` 使用特定名称限定选项。例如，在包含多个符号表的文件中，你可以使用以下命令显示 `.dynym` 表：

```
% elfdump -s -N .dynym filename
```
