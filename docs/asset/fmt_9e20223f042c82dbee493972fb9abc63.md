
# 术语表

## system process（系统进程）
在系统启动期间运行并在用户特定请求的进程。`init`、`getty`、`cron` 和 `lpsched` 是一些系统进程。另见 daemon。

## tab（制表符）
模拟连续一组空格的单个字符。通过按下特殊键或 `[Ctrl-i]` 生成。它是空白字符的一种。常用于对齐列。

## tagged regular expression (TRE)（标记正则表达式）
用于表示使用转义圆括号 `\(` 和 `\)` 对正则表达式进行分组的术语。该组在行的其他位置通过标记 `\n` 或 `$` (perl) 重复，其中 `n` 是 1 到 9 之间的数字。被 `grep`、`sed` 和 `perl` 命令使用。

## TCP/IP
传输控制协议/网络协议——一组用于连接不同操作系统和不同硬件的计算机的网络协议。它具有完整的错误纠正功能确保可靠传输。

## TELNET
一种 TCP/IP 协议，允许用户在提供用户名和密码后登录到远程机器。登录后，用户可以使用远程机器就像本地机器一样。所有文件都在远程机器上创建。`telnet` 命令使用此协议。

## The Open Group（开放组）
UNIX 标准的所有者和单一 UNIX 规范（The Single UNIX Specification）的制定者。其包含 X/OPEN。还维护 X Window 系统。

## toggle switch（切换开关）
一种反转其前一次调用效果的命令。emacs 有许多起当切换作用的命令。

## top-level domain (TLD)（顶级域名）
根域名 (.) 下任何未分配给特定国家的域名。TLD 包含通用域名 `com`、`edu`、`org`、`net`、`museum`、`biz` 等。

## umask（掩码）
在 shell 中维护的一个数字，用于确定文件的默认权限。从系统默认权限中减去该数字即可文件的实际权限。可以使用同名命令显示和设置该值。

## Uniform Resource Locator (URL)（统一资源定位符）
指定 Web 上资源的字符字符串。由协议的完全限定域名（FQDN）以及要运行的文件或程序的路径名组成。

## unmounting（卸载）
将文件系统从主文件系统中分离的过程。`mount` 命令执行此卸载操作。另见 mounting（挂载）。

## user（用户）
`chmod` 命令理解的文件所有者。另见 group 和 others。

## user mode（用户模式）
CPU 运行程序时的模式。在此模式下，程序无权访问内核所使用的内存。另见 kernel mode（内核模式）。

## user-id (UID)
用户用于访问系统的名称。授权名称列表维护在 `/etc/passwd` 中，并带有数字表示。另见 login name（登录名）和 username（用户名）。另见 group-id（组 ID）。

## username
与 user-id 同。

## virtual console（虚拟控制台）
在单一 UNIX 机器上使用多个屏幕和登录的系统。通过 `[Alt]` 和功能键打开新屏幕。

## vnode table（vnode 表）
内存中 inode 的映像。除了 inode 形成外，它还包含一个引用计数，显示指向该表的进程数。只要此表打开，文件就无法完全删除。另见 file table（文件表）。

## wait（等待）
用于指子进程运行时启动新进程的术语。通常，父进程等待子进程结束以获取其退出状态。它还有一个同名的 shell 内置命令和系统调用。

## wake（唤醒）
用于表示当事件发生时终止休眠状态的术语。当特定事件发生（如 I/O 完成）时，内核会唤醒处于睡眠状态的进程。

## watchpoint（观察点）
调试器用于监控变量。当变量值改变时，程序暂停。另见 breakpoint checkpoint（断点检查）。

## Web page（网页）
包含文本和图形的 HTML 文档，以页的形式在每个网站展示。网页有指向其他页面的链接——通常在不同的机器上。

## Web server（Web 服务器）
运行 HTTP 协议的 TCP/IP 应用。万维网通过 Web 服务器提供所有资源。

## whitespace（空白字符）
连续的空格、制表符或换行符。也是 IFS 变量的默认值。用分隔符。

## wild card（通配符）
用于匹配模式的特殊字符。也是正则表达式。

## word（单词）
不包含空白字符的连续字符串。

## World Wide Web（万维网）
互联网上具有链接文档的服务。

## zipped file（压缩文件）
任何使用 gzip、zip 或 bzip2 压缩的文件。

## zombie（僵尸进程）
退出状态尚未被父进程获取的进程。
