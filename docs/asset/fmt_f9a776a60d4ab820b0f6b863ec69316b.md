# 176 第十章

| 命令 | 动作 |
|---|---|
| `:` | 进入 ex 模式。 |
| `:w` | 保存缓冲区到磁盘。 |
| `:q` | 退出 vi（如果未保存会警告）。 |
| `:wq` | 保存并退出 vi。 |
| `:x` | 保存并退出 vi（同于 `:wq`）。 |
| `:q!` | 在不保存更改退出 vi。 |
| `:w [filename]` | 保存缓冲区到文件名。 |
| `:w>>filename` | 将 vi 缓冲区追加到文件名。 |
| `:w![filename]` | 用缓冲区替换文件名。 |
| `:w! [filename]` | 用缓冲区覆盖文件名。 |
| `:n[number]` | 移动到行号。 |
| `:$` | 移动到最后一行。 |
| `:[command]` | 执行 ex 命令。 |
| `:set [option]` | 设置选项。 |
| `:setno [option]` | 取消选项。 |
| `:set` | 显示所有选项。 |
| `:?` | 显示帮助消息。 |
| `:/` | 向前搜索模式。 |
| `:?` | 向后搜索模式。 |
| `:s/old/new` | 在当前行替换 old 为 new。 |
| `:s/old/new/g` | 在当前行替换所有匹配。 |
| `:s/old/new/c` | 替换并确认每个匹配。 |
| `:g/old/new` | 在全局范围内替换。 |
| `:g/old/new/g` | 在全局范围内替换所有匹配。 |
| `:g/old/new/c` | 全局替换并确认每个匹配。 |
| `:v` | 进入可视模式。 |
| `:V` | 进入行可视模式。 |
| `:` | 进入块可视模式。 |
| `:%` | 指定整个文件。 |
| `:!` | 执行外部 shell 命令。 |
| `:|` | 管道命令。 |
| `:?` | 搜索命令。 |
| `:w` | 写入命令。 |
| `:q` | 退出命令。 |
| `:x` | 退出命令。 |
| `:r` | 替换命令。 |
| `:a` | 追加命令。 |
| `:i` | 插入命令。 |
| `:d` | 删除命令。 |
| `:c` | 更改命令。 |
| `:t` | 查找命令。 |
| `:f` | 查找命令。 |
| `:F` | 查找命令。 |
