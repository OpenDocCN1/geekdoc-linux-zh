## 7.3.2 使用 NSE 脚本

在上一节中，我们学习了 NSE 类别，而 `vulners` 脚本提供了映射到检测到的版本的所有 CVE 的概览，我们有时想要检查特定的 CVE。这在我们想要扫描网络是否存在某个漏洞时特别别有帮助。如果我们已经有了 `vulners` 脚本，我们需要审查大量的量。对于大多数现代漏洞，我们需要手动集成专门的 NSE 脚本。
