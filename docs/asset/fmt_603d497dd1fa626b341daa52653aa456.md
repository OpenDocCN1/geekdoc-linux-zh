# 环境变量

`DISPLAY`

获取要使用的默认主机和显示器

## 缺陷

你不能在命令行上指定显示器，因为 `-display` 是一个有效的命令行参数（表示你想从访问列表中移除名为 `display` 的机器）。

# xieperf

X 服务器存储的是地址，而不是主机名。这并不是真正的缺陷。如果你在服务器运行时更改了主机的地址，则必须使用 `xhost` 添加新地址/或移除旧地址。
