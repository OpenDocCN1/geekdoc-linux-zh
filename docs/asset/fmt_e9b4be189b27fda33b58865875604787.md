# 过程参考：与 UPS 设备相关的问题

- 1. 确认 UPS 设备已正确连接到服务器。
- 2. 验证串口配置是否正确。
  - a. 确认 `setserial -a /dev/ttyS0` 命令输出中列出的设置与您的设备规格匹配。
