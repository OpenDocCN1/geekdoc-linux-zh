# 粒子加速器

一种将带电或亚原子粒子加速到高能量的电装置。粒子可以是带电的或带负电的。如果是亚原子的，它们可能是电子、质子或来自周期表各种元素的离子。

用于在高能产生亚原子粒子的加速器在医学和工业中作为基础研究。静电发生器、回旋加速和同步加速用于产生各种辐射，这些辐射可用于塑料聚合、无热灭菌以及医学和工业中治疗某些疾病的放射性同素。它们还可用于产生高强度的质子、中子和反物质束。反物质通常由加速电子撞击固体靶产生X射线。然而，同步加速产生同步辐射。X射线的实际应用已在该领域显示。参见 Calculus：可微性。

加速器分为两大类：静电加速器和磁加速器，以及采用交变电场的加速器。交变加速器必须在真空管内加速连续流。

时间变加速器。一种电场变化但不使用磁场聚焦的加速器通常被称为线性加速器。在实现中，使用具有相反电位的电极来吸引并加速它们。每个电极交替加速和减速。

如果间隙安排以适应增加的后续间隙，那么通过这种方式粒子束可以通过加速器的频率被无限加速（尽管受到限制）。

所有传统的（非超导）线性加速器以脉冲模式运行，因为它们的运行需要极高的功率。脉冲可以根据占空比或全功率时间调整到实际成本合理的数值。脉冲周期在术语上限制了它们的研究范围；然而，它们在同步加速器实验中非常有效且被广泛使用。电子束设施（CEBAF）在跑道场布局中加速电子，其中直线位于跑道的直边，电子的整流为两次通过加速器提供了不同的粒子束。同步加速器接收5 MeV电子束并将其加速到4 GeV的最终能量，并用于许多实验。超导线性加速器允许连续束而非脉冲，这对于脉冲束是可能的。
