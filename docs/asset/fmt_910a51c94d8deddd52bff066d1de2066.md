
# 片理

变形岩石的一种次级平面构造。片理具有渗透性和系统性，这与可能单独出现或呈宽间距组状出现的裂隙和剪切带不同。片理在细粒岩石中通常比在粗粒岩石中发育得更好。该术语的应用源于岩石沿此结构劈开的能力。

简单的片理通常平行于褶皱的轴面。对于由岩石质量均匀流动形成的褶皱，若原层理表现为被动标记物，上述说法成立。当岩层发生挠曲时，作为力学不连续面的原层理会导致早期发育的片理在褶皱后续生长过程中呈扇状展布。片理还与断层有关。参见断层及断层构造；褶皱及褶皱体系。

连续（微观上具有渗透性的）片理，如板岩中的片理，是岩石中最早可识别的构造面理要素。片理也在变形程度和变质程度低于板岩的岩石中发育。在这些岩石中，片理表现为离散的层面或细缝，常涂有一层粘土或碳质薄膜；片理面之间由未变形的沉积岩层隔开。这些层面可以是光滑的、异常的或 stylolitic（缝合线状的）。参见变质作用；岩石力学；板岩。[D.B.E.]

## 岩石磁性

岩石和矿物在从原子到全球各种尺度上的永久磁性和感应磁性，包括对地磁场异常和古地磁场的应用。天然指南针，即被称为 lodstones 的磁铁矿（$Fe_2O_3$）富集物，是人类最古老的装置之一。1600年，W. 吉尔伯特发现地球本身是一个巨大的磁铁，并推测其磁性可能源于地下的 lodestone 矿藏。1906年，B. 布鲁内尔观察到某些岩石的磁化方向与当前地磁场方向相反，1929年，M. 松山（M. Matuyama）发现反向磁化和正常磁化的岩石对应不同的地质时期，这些观察表明地磁场是动态的，南北磁极经常发生反转。

然而，岩石的永久性磁性仍然重要，因为它唯一地提供了过去地质时期地磁场强度、方向和极性的记忆。从这一磁记录中，我们获得了大陆漂移、海底扩张和板块构造的大量证据。参见大陆漂移；地磁学；磁体；磁学；古地磁学；板块构造。

岩石的磁性源于磁铁矿等少数百分比或更少比例的矿物的亚铁磁性或铁磁性。这些矿物中相邻原子的磁矩呈平行或反平行耦合，产生自发磁化强度 $M$。所有磁记忆，包括计算机、永久磁铁和岩石的磁记忆，都源于这种磁性的自发性和永久性。自发磁化不需要磁场即可产生，且不能被退磁。

在磁性矿物颗粒的尺度上，磁性可以被随机化，因为晶体不同区域的 $M_S$ 矢量往往指向不同方向。这些区域被称为磁畴。仅包含一个磁畴的微小颗粒（单畴颗粒）是最强且最稳定的古地磁记录器。较大的多畴颗粒也可以通过磁畴数量、大小或方向的不平衡来保存古地磁记忆，但这种记忆更容易随时间和地质条件的变化而改变。参见铁磁性；磁学；磁化；磁力计。[D.J.D.]

## 岩石力学

应用力学和地质学原理来量化岩石在环境力作用下的响应，特别是当人为因素改变原始环境条件时。岩石力学是一门跨学科的工程科学，需要物理学、数学和地质学以及土木工程、石油工程和采矿工程之间的相互作用。目前的知识水平仅允许在理论预测和经验结果之间进行有限的关联。因此，最有用的原则基于从实验室和原位测量以及原型行为（已建成工程设施的行为）中获取的数据。由于岩石特性被视为具有现场特异性，即同一地点的岩石系统特性可能与另一地点显著不同，即使地质环境相似，因此对原位测量的强调日益增加。参见工程地质学。

由于跨学科特性，岩石力学术语没有标准化。然而，以下术语和定义非常有用。

- 环境因素是岩石力学工程问题中需要考虑的自然因素或人为影响。主要的自然因素包括地质学、环境应力和水文地质。人为影响源自建设（或破坏）过程中化学、电气、机械或热能的应用。
- 环境应力场是指人类扰动之前环境中应力的分布和数值。
- “岩石系统”一词包括能够影响将构成工程结构一部分的地球壳层部分行为的所有环境。通常包括所有自然环境因素。
- 岩石元素是构成岩石系统的基本组分，是连贯且完整的岩石块体，其物理、力学和岩相特性可以通过对每个此类元素的实验室测试来描述或测量。岩石系统和岩石元素的概念使得伴随的工程优化设计可以根据系统工程原理进行优化。参见系统工程。

当岩石系统或元素不再能执行其预期的岩石工程功能时，就会发生“岩石破坏”。破坏的证据可能表现为裂隙、形状畸变或强度降低。“破坏机制”包括岩石破坏方式的原因。参见岩爆；土力学；隧道；地下采矿。[W.R.J.]

## 岩石漆

暴露于大气的岩石表面上的深色涂层。岩石漆可能是堆积最缓慢的沉积物，增长率仅为每千年几微米到几十微米。其厚度范围从不到 $5 \mu m$ 到超过 $700 \mu m$ 不等，通常约为 $100 \mu m$。虽然岩石漆在所有陆地环境中都能发现，但它主要在干旱至半干旱沙漠中发育良好并得到保存；因此，另一个常用名称是沙漠漆。岩石漆由约30%的锰和铁氧化物、高达70%的粘土矿物以及十多种微量和稀土元素组成。岩石漆的基本组成物质主要是作为空气尘埃吹入的。尽管岩石漆形成的机制尚不清楚，但已提出两种假说来解释岩石漆中锰的巨大富集（通常比相邻环境如土壤、基岩或尘埃高出50倍以上）。非生物假设认为 pH 值的微小变化可以通过地球化学过程浓缩锰。生物假设认为细菌以及可能其他微生物浓缩了锰；这得到培养实验和对细菌增强锰的直接观察的支持。参见沉积岩。

由于岩石漆记录了区域甚至全球同步的环境事件，特别是气候事件，岩石漆微层序学可作为定年工具。在没有放射性定年校准的情况下，岩石漆微层序学本身可用于估计具有岩石漆的地貌或考古特征的相对年代。具体而言，对于岩画和大地图形，岩石漆的分层模式在赋予年龄方面具有最大的潜力。参见考古年代学；定年方法；岩石年龄测定。[T.L.]

## 火箭

推进系统或由这种推进发动机驱动的完整飞行器。火箭发动机提供了一种手段，通过燃烧化学物质释放其中储存的能量，并通过高速喷射燃烧产物（工作流体）消耗该能量。喷射使飞行器获得与喷射物质方向相反的运动。火箭飞行器由火箭反作用力推进，包括此类推进所需的所有组件以及有效载荷，如爆炸装药、科学仪器或机组人员。火箭飞行器还包括安装在结构机翼或航天器上的制导和控制设备。参见火箭推进；火箭分级；卫星（航天器）；航天飞行；太空探测器。[G.P.S.]

## 火箭天文学

利用探空火箭的学科，这些火箭沿近垂直路径飞行，携带科学仪器进入从25到超过300英里（40到1500公里）高度的范围。气球可达30英里（48公里）高度，因此探空火箭通常用于更高的高度，以测量无法穿透地球大气的太阳或其他天体的发射。探空火箭未达到轨道速度；发射阶段完成后，有效载荷遵循弹道轨迹，允许在回收前进行5–15分钟的数据采集。参见火箭。

与在卫星上发射的实验相比，火箭具有简单性、相对频繁的可发射机会、从概念到实现的更短时间尺度、较低的成本以及可回收的有效载荷和飞行后仪器校准、翻新和重新飞行的可能性。主要缺点是观测时间短、覆盖范围局部化以及有效载荷的尺寸和重量限制。参见卫星天文学。

科学火箭计划侧重于大气化学、磁层物理、气象学和材料科学，以及天文学和天体物理学。在许多这些科学学科中，在25–125英里（40–200公里）高度对相关大气参数进行垂直剖面测量能力至关重要。在太阳影响或控制地球高层大气和磁层条件的程度上，太阳天文学与更局部的研究领域之间存在紧密联系。参见大气化学；电离层；磁层。

太阳色球层的发射由紫外光和X射线光子主导。在20世纪50年代末和60年代初，开发了聚焦X射线并由此提供色球层直接成像的技术。这些研究揭示了大气的高度结构化特征，热等离子体的近似半圆形环勾勒出底层磁场的形状，磁场约束着热气体。火箭色球层研究的显著进展之一是开发了一种新的X射线成像技术：使用多层涂层来增强X射线反射率。参见太阳；X射线天文学；X射线望远镜。

从探空火箭对非太阳源的观测受到发射强度低以及在飞行期间将有效载荷指向源的目标问题的阻碍。[L.Gd.]

## 火箭推进

通过喷射物质的动量给飞行飞行器（如导弹或航天器）施加推力的过程。这种称为推进剂的物质储存在飞行器中并以高速喷射。在化学火箭中，推进剂是经历化学燃烧反应的化合物，释放能量以热力学方式加速并高速喷射气态反应产物。因此，化学火箭推进与其他类型的火箭推进相区别，后者使用核能、太阳能或电能作为动力源，并且可能使用除气体绝热膨胀以外的机制来实现高速喷射。使用液体推进剂（如煤油和液氧）的推进系统传统上被称为火箭发动机，而使用固体形式推进剂的则被称为火箭马达。参见电热推进；行星际推进；离子推进；等离子体推进；推进；航天器推进。

性能。由火箭推进系统推进的导弹或航天飞行器的性能通常用射程、飞行最大速度增量、有效载荷、最大高度或达到特定目标的时间等参数来表示。推进性能参数（如火箭排气速度、比冲、推力或推进系统重量）用于计算这些飞行器性能。

| 推进系统参数 | 典型数值范围 |
| :--- | :--- |
| 海平面比冲 | 280–390 s |
| 高空比冲 | 215–470 s |
| 海平面排气速度 | 5800–15,000 ft/s (1800–4500 m/s) |
| 燃烧温度 | 4000–7200 $^\circ$F (2200–4000 K) |
| 室压 | 100–3000 lb/in.$^2$ (0.7–20 MPa) |
| 推力与推进系统重量之比 | 20–150 |
| 推力 | 0.01–6 $\times$ 10$^6$ lb (0.05–2.9 $\times$ 10$^7$ N) |
| 飞行速度 | 0–50,000 ft/s (15–0.05 km/s) |

*具体数值取决于应用、推进系统设计和推进剂选择。
