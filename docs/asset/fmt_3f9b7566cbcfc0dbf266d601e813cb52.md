
# 运输工程概述

## 铁路工程
装卸设施、轨道、桥梁和隧道，以及货运和客运的办公/控制系统。对于轻型运营，重点在于开发更高效的装卸、调车（车辆移动）和列车运行系统。设施包括大型编组站，其中使用电子设备来控制铁路车辆的移动。此外，轨道上也出现了一种趋势，即开发更多自动化系统，从而由电子设备自动设置信号和道岔。集装箱的自动化运输、隧道和旧线路正在被扩建，以提供双层集装箱列车服务。参见**铁路工程；隧道**。

## 航空运输工程
航空运输工程包括航站楼、跑道和助航设施的规划、设计和施工，以提供客运和货运服务。高容量、长航程、燃油效率高的飞机（如640座的波音777，航程为7200英里（12,000千米））是理想的。更广泛地使用复合材料以及用电子控制替代机械装置可以减轻重量，从而提高燃油经济性。较小的飞机在短途运输中更高效。参见**航空导航；空中交通管制；航空运输；复合材料**。

## 水上运输工程
水上运输工程涉及一系列设施的施工和建造，如运河、船闸和堤坝，以及港口设施。运输系统包括内陆水道上的驳船和拖船运输，以及远洋船舶运输。尽管有一些客运（如渡轮和游轮），但水上运输主要用于货运。参见**运河；堤坝；河流工程**。

## 管道运输
管道运输包括管道、泵站和储存设施的设计和施工。管道用于长距离运输水、天然气和石油制品等液体。此外，粉煤灰和铁矿石等产品也可以在水浆状态下运输。参见**管道；储罐**。

## 城市运输工程
城市运输工程关注轻轨系统、地铁和自动旅客运输系统（people-movers）的设计和施工，以及传统公交系统的设施。为了提高公众对新建和扩建系统的接受度，正越来越多地使用计算机辅助设计（CAD）来可视化车站和设施的替代方案。此外，还使用动画视频系统进行计划的交互式可视化。参见**计算机辅助工程；港口和码头；地铁工程**。

## 多式联运
多式联运，常被称为集装箱化，涉及使用特殊集装箱通过卡车、铁路或海船运输货物。工程师必须设计和建造多式联运设施以实现高效运营。集装箱由钢或铝制造，设计为能够承受装卸过程中产生的力。船舶在甲板下建有用于容纳集装箱的格状舱室结构，甲板也可以容纳一或两层集装箱。其优点包括节省劳动力成本、减少货物被盗以及降低保险费率。参见**起重机械；海上集装箱；商船**。

## 环境与能源考虑
在规划、设计和建造运输设施时，环境和能源消耗被纳入主要考虑因素。减少能源使用的努力源于多种关切，包括安全问题与环境影响。通过鼓励更多地使用拼车（如设立专用高速公路车道）和鼓励更多地使用公共交通来缓解城市拥堵的努力，值得进一步强调。 [R.L.布鲁斯]

# 转座子

**类型** 可转座元件（Transposable elements）由大的离散脱氧核糖核酸（DNA）片段组成，这些片段能够从一个染色体位点移动到新位置。在细菌中，可转座元件可分为两类：插入序列（Insertion sequences）和转座子（Transposons）。可转座元件插入质粒或可从一个生物体传播到另一个生物体的细菌病毒（噬菌体）中的能力，使其得以迅速传播。参见**噬菌体；质粒**。

插入序列最初是通过其诱导糖代谢相关蛋白结构基因产生异常突变的能力而被识别的。这些插入序列相对较小（约500–1500个核苷酸对），只能通过其诱导这些突变的能力被追踪。大多数细菌染色体含有数个此类插入序列元件的拷贝。

转座子是较大的DNA片段（2000–10,000个碱基对），编码几种蛋白质，通常包含一到两种元件移动所需的蛋白质，以及一种常赋予含有该元件拷贝的宿主选择优势的其他蛋白质。许多转座子的结构表明，它们可能进化自更简单的插入序列元件。

所有可转座元件，无论是简单的插入序列元件还是更复杂的转座子，都具有相似的结构和遗传组织。元件的末端代表识别位点，并定义了正在发生转座的DNA片段。在元件一端存在的短序列在另一端以反向方式重复。这些末端反向重复序列（terminal inverted repeats）是每种元件的特征。

一个广泛存在的转座子群体——Tn3家族——的成员都具有相似的结构，并似乎通过相似的机制移动。转座酶（Transposase），一种由该元件编码的蛋白质，促进了被称为接合中间体（cointegrates）的中间体的形成，在此过程中该元件通过复制实现加倍。第二种由元件编码的蛋白质，接合酶（resolvase），通过将近合中间体转化为转座的最终产物——插入新位点的转座子——来完成这一过程。Tn3元件编码的第三种蛋白质赋予宿主对氨苄西林（antibiotic ampicillin）的抗性。

已知有一些转座子编码对几乎所有抗生素以及许多有毒金属和化学品的抗性。此外，一些转座子获得了指导合成能代谢碳水化合物、石油和农药的蛋白质的能力。其他可转座元件产生肠毒素，导致饮用携带该元件的细菌污染水的人生病。可转座元件编码的广泛活性证明了伴随其进化而来的强大选择优势。

可转座元件不仅限于原核生物。酵母以及高等真核生物都具有能够移动并引起突变的DNA片段。真核元件与其原核对应物有许多共同点：元件末端由反向重复序列组成，许多较大的元件由两个小的类插入序列区域组成，包围着独特的中心区域。一类真核病毒，即RNA逆转录病毒（注：原文提到rhinovirus acid (RNA) retrovirus，此处应理解为逆转录病毒），也具有这种结构，并被认为是通过类似转座的机制整合到宿主染色体中。参见**抗生素；基因；基因作用；逆转录病毒；病毒**。 [R.E.]

# 超铀元素

**这些合成元素** 的原子序数大于铀（原子序数92）的原子序数。它们是锕系元素的成员，从镎（原子序数93）到锘（原子序数103），以及超锕元素（原子序数大于103）。在这些元素中，钚作为一种核武器爆炸材料和核能燃料（因为其具有裂变特性），已经以最大（吨级）规模制备，而其他一些元素则以千克规模（镎、锔、锎）或极小数量（铹、锎、锿）产生。

应用于天然元素的原子量概念不适用于超铀元素，因为任何给定样本的同位素组成取决于其来源。在大多数情况下，结合最长寿命同位素的质量数及其可用性评估已足够。目前不错的选择包括：镎，237；钚，242；镅，243；锔，248；锫，249；锎，249；锿，254；锘，257；镄，258；锘，259；锿，260；𬬻，261；𬭊，262；和𬭶，263。锕系元素在化学性质上相似，并与镧系元素（稀土元素，原子序数 57–71）有强烈的化学相似性：超锕系元素，原子序数为 104–118，出现在扩展元素周期表中铪（72 号）开始到氡（86 号）结束的那一行下方。这种排列允许预测这些元素的化学性质，并暗示它们与在周期表中直接位于其上方的元素具有化学类比关系。

截至锘（原子序数 100）的超铀元素，主要通过核反应堆中中子的连续捕获大量生产。随着原子序数的增加，产量减少，可称量生产的最重元素是锿（99 号）。通过在加速器中用带电荷的原子弹丸轰击重靶同位素，可以生产许多额外的同位素；在锘之后，所有元素都通过重离子轰击生产。

在多姆斯塔特（原子序数 110）之后，已生产了 111–116 号超锕系元素，尽管它们的接受尚待确定。参见：锕系元素；镅；锫；𬭛；锎；锔；𬭊；锿；元素 111；元素 112；锘；𬭶；镎；锘；核化学；核裂变；核反应；元素周期表；钚；稀土元素；𬬻；𬭶。（J.R. G.T.S）

# 固体中的陷阱

材料中能够捕获并局域化电子或空穴的局部区域，从而阻止电子或空穴在材料中移动，直到提供足够的热或光能量。固体中的陷阱与材料中由杂质或晶体缺陷引起的缺陷相关。参见：固体能带论；晶体缺陷；固体中的空穴态。

作为陷阱行为的缺陷通常与作为复合中心的缺陷有所区别。如果缺陷处被捕获的电子（或空穴）在与自由空穴（或自由电子）复合之前被热重新激发到导带（或价带）的概率大于复合的概率，则该缺陷被称为表现为电子（或空穴）陷阱。如果缺陷处被捕获的电子（或空穴）与自由空穴（或自由电子）复合的概率大于被热重新激发到能带的概率，则该缺陷被称为表现为复合中心。材料中特定的化学或结构缺陷在某种温度和光强度条件下可能表现为陷阱，而在另一种条件下表现为复合中心。

陷阱在许多涉及光电导和发光的 phenomenon 中起重要作用。例如，在光电导体中，陷阱的存在降低了灵敏度并增加了响应时间。其效果可通过光电导和发光上升和衰减瞬态的变化、热刺激电导和发光（其中陷阱在低温下填充，然后通过受控方式增加温度来排空）、与具有未成对自旋的捕获电子相关的电子自旋共振，以及涉及半导体结电容的各种技术（如光电容和深能级瞬态谱）检测到。参见：电子顺磁共振（EPR）光谱；发光；光电导；热致发光。（R.H.Bu.）

# 创伤

由物理或化学手段造成的组织损伤。机械性损伤包括擦伤、挫伤、裂伤和切口，以及刺伤、穿刺伤和枪伤。骨骼和关节的创伤会导致骨折、脱位和扭伤。头部受伤往往很严重，因为出血、颅骨骨折或脑震荡等并发症。

热、电和化学烧伤造成严重伤害，部分原因是它们使组织凝固并阻断恢复性血流。窒息，包括溺水引起的窒息，会对大脑和呼吸中枢以及其他器官造成快速损伤。

创伤的常见并发症是休克（由外周循环衰竭引发的衰竭状态），以及出血、感染和愈合不当。参见：感染愈合；休克综合征。[E.G.S] [L.N.K.M.]
