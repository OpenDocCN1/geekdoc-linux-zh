
# 安装概览

即使 PostgreSQL 是世界上最先进、最复杂的数据库系统，安装 PostgreSQL 并不复杂。事实上，使用二进制 RPM 安装所需时间不到五分钟。如今，即使是低成本的 PC 系统也配备了 10GB 硬盘和 64MB 内存，这已经足够了。本节将为你提供安装过程的概览。如果你具有一些 Linux 和 RedHat RPM 软件包的经验，只需按照后续步骤操作，即可在五分钟内完成 PostgreSQL 的安装。

如果你是 Linux/UNIX 的初学者，请参考下一节“详细指令”，该节详细解释了每一个步骤。在 RedHat Linux 系统上，请使用以下步骤。在 Debian 上，步骤将类似，但请将 `rpm` 替换为 `deb`。在 Debian 上，如果你没有 PostgreSQL 软件包，可以使用 `rpm2deb` 程序将 RedHat RPM 软件包转换为 Debian 软件包。

以 root 身份登录并按照 bash 提示符执行以下命令：

```bash
# cd /mnt/cdrom/RedHat/RPMS
# ls *.rpm (查看软件包列表)
# rpm -qpi *.rpm | less (查看包信息)
# rpm -qpl *.rpm | less (查看每个包内部的文件列表)
# ps -auxw | grep -I postmaster
```

如果 postmaster 正在运行，请退出所有 PostgreSQL 程序并停止 postmaster 进程。

**注意**：如果你看到一个 postgres 用户，你可能需要备份并清理主目录 `~postgres`，删除该 UNIX 用户，或者将该 UNIX 用户重命名为类似 postgres2 的名称。必须是干净的安装。安装所需的 `postgresql` 软件包——你必须安装客户端、数据和服务器的所有包才能运行。

```bash
# rpm -i *.rpm
```

在系统启动时启动 PostgreSQL：

```bash
# man chkconfig
# chkconfig --add postgresql
```

这将在 `/etc/rc.d` 目录下添加以下软链接到 `/etc/rc.init.d/postgresql`：

```
init.d/postgresql
rc0.d/K15postgresql
rc1.d/K15postgresql
rc2.d/K15postgresql
rc3.d/S85postgresql
rc4.d/S85postgresql
rc5.d/S85postgresql
rc6.d/K15postgresql
```

现在所有 PostgreSQL 系统文件已就位，通过输入命令立即启动 Postgres 服务器：

```bash
# /etc/rc.d/init.d/postgresql start
```

## 详细安装

本节是对“快速安装指南”中每个步骤的详细解释。将最新的 RedHat CD-ROM 放入光驱并以 root 身份登录。在 bash 提示符下给出以下命令：

```bash
# mount /mnt/cdrom
# cd /mnt/cdrom/RedHat/RPMS
```

现在切换目录到所有 RPM 文件所在的目录。你需要了解一些关于 RPM 软件包的基础知识。要查看解释 rpm 选项和用法的在线文档，请执行以下命令：

```bash
ls *.rpm
```

PostgreSQL RPM 通常命名为 `postgresql-aaa-x.x-r.rpm`，其中 aaa 是包（例如 jdbc server）；x.x.x 是版本号（例如 7.0.0）；r 是包发布版本（例如 1, 2, 3 等）。查看 PostgreSQL RPM 列表：

```
postgresql-6.5.2-1.i386.rpm
postgresql-devel-6.5.2-1.i386.rpm
postgresql-jdbc-6.5.2-1.i386.rpm
postgresql-odbc-6.5.2-1.i386.rpm
postgresql-perl-6.5.2-1.i386.rpm
postgresql-python-6.5.2-1.i386.rpm
postgresql-server-6.5.2-1.i386.rpm
postgresql-tcl-6.5.2-1.i386.rpm
postgresql-test-6.5.2-1.i386.rpm
```

要读取关于 PostgreSQL RPM 的信息，使用 `-I` 选项并将其通过到 `less` 命令以逐页滚动。输入 `man less` 查看在线手册：

```bash
# rpm -qpi *.rpm | less

Version : 6.5.2

```

有时检查 RPM 软件包内部的文件列表是一个好主意。要查看 PostgreSQL RPM 中的文件列表：

```bash
# rpm -qpl *.rpm | less
```

RPM 选项 `-q` 是查询模式（query），`-p` 是包（package），`-l` 是列出文件（list files）。

如果你的系统中已经存在 PostgreSQL 且数据库正在默认端口上运行，你**必须**先停止 postmaster 进程。要检查是否有任何 PostgreSQL 进程在运行，输入：

```bash
# ps -auxw | grep -I postmaster
```

如果 postmaster 正在运行，退出所有 PostgreSQL 程序并停止 postmaster 进程。你可以通过执行以下命令停止 postmaster：

```bash
# /etc/rc.d/init.d/postgresql stop
```

PostgreSQL 安装必须始终是一个“干净的起点”，即你的系统不能有先前的 PostgreSQL 安装。如果上述步骤对你不起，可以从 http://www.postgresql.org 获取更多信息。Lamar Owen 是 PostgreSQL RPM 的维护者；他的邮箱地址为 lamar.owen@wgcr.org。此外，请熟悉 RedHat 包管理器以管理 PostgreSQL 安装。从 http://www.postgresql.org 下载 Maximum RPM 并寻找文件名 `maximum-rpm.gz`。在 Linux 上使用以下命令读取：

```bash
cd /usr/doc/postgresql
man admin.gz
man maximum-rpm.gz
```

要阅读所有的常见问题（FAQs）、用户指南、程序员指南和教程，请使用压缩的 postscript 文件：

```bash
man postgres.gz
```

此将启动 Linux 进程 postmaster，它将监听 TCP 端口 5432 上的请求。要查看运行中的进程，请输入

```bash
# ps -auxw | grep -I postmaster
```
