
## Synopsis

```
/usr/bin/ldapmodify [-a] [-b] [-c] [-n] [-v] [-F] [-d debuglevel]
[-D binddn] [-w passwd] [-h ldaphost] [-M authentication] [-p ldapport]
[-f file] [-1 nb-ldap-connections]
/opt/SUNWconn/bin/ldap [-b] [-c] [-n] [-v] [-F] [-d debuglevel]
[-D binddn] [-w passwd] [-h ldaphost] [-p ldapport] [-f file]
[-1 nb-ldap-connections]
```

## Description

`ldapmodify` 打开到 LDAP 服务器的连接并进行绑定、修改或添加条目。条目信息从标准输入或通过 `-f` 选项指定的文件读取。`ldapadd` 实现为 `ldapmodify` 的硬链接。当作为 `ldapadd` 调用时，`-a`（添加新条目）选项会自动开启。

`ldapadd` 和 `ldapmodify` 都会拒绝同一条目的重复的属性名/值对。

## Options

- `-a` 添加新条目。`ldapmodify` 的默认值是修改现有条目。如果作为 `ldapadd` 调用，此选项始终被设置。
- `-b` 假设任何以 `/` 开头的值都是包含实际属性值的文件路径。此选项对于二进制格式的属性值有用。
- `-c` 连续操作模式。报告错误并继续修改。默认情况下在报告错误后退出。
- `-d debuglevel` 设置 LDAP 调试级别。`ldapmodify` 和 `ldapadd` 适用的调试级别包括：
  - `1` 跟踪（Trace）。
  - `2` 数据包（Packets）。
  - `4` 参数（Arguments）。
  - `32` 过滤器（Filters）。
  - `128` 访问控制（Access control）。

若要请求超过一类的调试信息，请添加掩码。例如，若要请求跟踪和过滤器信息，请指定调试级别 `33`。
- `-D binddn` 使用唯一标识符 `binddn` 绑定到目录。
- `-f file` 从文件而非标准输入读取条目修改信息。
- `-F` 强制应用所有更改，无论以 `replica:` 开头的输入行内容如何：默认情况下，`replica:` 行会与正在使用的 LDAP 服务器主机名和端口进行比较，以决定是否应用 replog 记录。
- `-h ldaphost` 指定运行 `slapd` 服务器的备用主机。
- `-1 nb-ldap-connections` 指定 `ldapadd` 或 `ldapmodify` 为处理目录修改时打开的 LDAP 连接数。默认是一个连接。
- `-M authentication` 指定用于绑定目录的身份验证机制。此选项的取值为 `CRAM-MD5`。使用此选项时，绑定 DN 和绑定密码是强制性的。
- `-n` 预览修改但不对条目进行任何更改。适用于与 `-v` 和 `-d` 配合调试。
- `-p ldaport` 指定 `slapd` 服务器监听的备用 TCP 端口。
- `-r` 用指定的值替换现有值（`ldapmodify` 的默认值）。当您调用 `ldapadd` 或指定 `-a` 选项时，`-r` 选项将被忽略。
- `-v` 使用详细模式并将诊断信息写入标准输出。
- `-w passwd` 使用 `passwd` 作为目录身份验证的密码。

## Examples

文件内容（或未指定 `-f` 选项时使用标准输入）的格式如下所示。

文件 `/tmp/entrymods` 包含以下修改指令：

```
dn: cn=Me, o=XYZ, c=US
changetype: modify
replace: mail
mail: modme@atlanta.xyz.com

- add: title
title: System Manager
- add: jpegPhoto
jpegPhoto: /tmp/modme.jpeg
- delete: description
```

以下命令 `-b -r -f /tmp/entrymods` 将按照如下描述修改 Modify Me 条目。

```
castle@ ldapmodify -b -r -f /tmp/entrymods
```

1. 将 `mail` 属性替换为 `modme@atlanta.xyz.com`。
2. 添加 `title` 属性为 `System Manager`。
3. 添加 `jpegPhoto` 属性为 `/tmp/modme.jpeg`。
4. 删除 `description` 属性。

## ldapmodrdn

`ldapmodrdn` — ldap 修改条目的相对名称 (RDN)。

## Exit Status

- `0`

  未发生错误。
- `non-zero`

  发生错误，并将诊断信息写入标准错误输出。
