### 14.4 ARM

Non-optimizing Keil 6/2013 (ARM mode)

```
main
  STMFD SP, {R4,LR}
  MOV R4, #2
  B   loc_368
loc_35C ; CODE XREF: main+1C
  MOV R0, R4
  BL  printing_function
  ADD R4, R4, #1
loc_368 ; CODE XREF: main+8
  CMP R4, #0xA
  BLT loc_35C
  MOV R0, #0
  LMFD SP, {R4,PC}
```

上述代码中的 `R4` 寄存器用于存储循环计数器（即变量 `i`）。

`MOV R4, #2` 给变量进行初始化值。

`MOV R0, R4` 和 `BL printing_function` 指令构成循环体。前者负责向被调用函数传递参数，后者直接调用 `printing_function()` 函数。

`ADD R4, R4, #1` 指令在每次迭代之后进行自增的运算。

`CMP R4, #0xA` 指令会比较变量和数字10（十六进制的 `0xA`）。下一条指令 `BLT`（Branch Less Than）会在 `<10` 的情况下跳转；否则执行。

Optimizing Keil 6/2013 (Thumb mode)

```
_main

PUSH       {R4,LR}
MOVS       R4, #2

loc_132    ; CODE XREF; _main+E
MOVS       R0, R4
BL         printing_function
ADDS       R4, R4, #1
CMP        R4, #0xA
BLT        loc_132
MOVS       R0, #0
POP        {R4,PC}
```

这段代码似乎不需要更多解释。
