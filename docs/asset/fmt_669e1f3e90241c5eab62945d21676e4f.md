
内核监控 `AppArmor`，它是强制访问控制的一种实现。以下参数将监控对 `/etc/apparmor/` 和 `/etc/apparmor.d/` 目录的任何写入访问（目录内文件的新增、删除或修改）或属性更改。

**注意：** 如果使用了不同的强制访问控制方法，则应审计对相应目录的更改。

原理：

`/etc/apparmor/` 和 `/etc/apparmor.d/` 目录下的文件更改可能表明未经授权的用户正尝试修改访问控制并更改安全上下文，从而导致系统被破坏。

## 审计：

### 磁盘配置

运行以下命令检查磁盘规则：

```bash
# awk '^\ -w/ | \
\&(\/\/etc\apparmor\/|\/etc\apparmor.d/) \
\& -p wa/ \
\&( key=[!~]* *$\|/| -k *[!~]* *$\/) /etc/audit/rules.d/*.rules
```

验证输出是否匹配：

- `-w /etc/apparmor/ -p wa -k MAC-policy`
- `-w /etc/apparmor.d/ -p wa -k MAC-policy`

### 运行中配置

运行以下命令检查已加载的规则：

```bash
# auditctl -l | awk '^\ -w/ | \
\&(\/\/etc\apparmor\/|\/\/etc\apparmor.d/) \
\& -p wa/ \
\&( key=[!~]* *$\|/| -k *[!~]* *$\')'
```

验证输出是否匹配：

- `-w /etc/apparmor/ -p wa -k MAC-policy`
- `-w /etc/apparmor.d/ -p wa -k MAC-policy`

## 修复：

在 `/etc/audit/rules.d/` 目录下编辑或创建一个以 `.rules` 结尾的文件，并包含相关规则以监控修改系统强制访问控制的事件。
