
## 动态显示终端窗口大小

```bash
#!/bin/bash

## term_size2 - 动态显示终端窗口大小

redraw() {

  clear

  Width = $(tput cols)

  Height = $(tput lines)

}

trap redraw WINCH

redraw

while true; do

  :

done

```

通过这个脚本，我们启动了一个空循环，但由于我们为 `SIGWINCH` 信号设置了 `trap`，每当终端窗口调整大时，`trap` 就会触发并显示新的终端大小。要退出此脚本，请输入 `Ctrl-c`。

## 控制光标

下面的能力名称输出包含控制代码的字符串，这些代码指示终端操纵光标：

| Capname | 说明 |
| --- | --- |
| `sc` | 保存光标位置 |
| `rc` | 恢复光标位置 |
| `home` | 将光标移动到左上角 (0,0) |
| `cup <row> <col>` | 将光标移动到指定的行、列位置 |
| `cudl` | 光标向下移动 1 行 |
| `cuul` | 光标向上移动 1 行 |
| `civis` | 设置光标为隐藏 |
| `cnorm` | 设置光标为正常状态 |

## 光标控制能力名称

我们可以修改之前的脚本，使用光标定位功能并在终端调整大小时将窗口尺寸信息置于中心：

```bash
#!/bin/bash

## term_size3 - 动态显示终端窗口大小

## 带有文本居中

redraw() {

    local str width height length

    width=$(tput cols)

    height=$(tput lines)

    str="Width = $width Height=$height"

    length=$(#str)

    clear

    tput cup $((height / 2)) \$((width / 2) - (length / 2))

    echo "$str"

}

trap redraw WINCH

redraw

while true; do

  :

done

```

与之前的脚本一样，我们为 `WINCH` 信号设置了 `trap` 并启动了无限循环。此脚本中的 `redraw` 函数要复杂一些，因为它必须在每次窗口大小变化时都重新计算终端窗口的中心点。

| Capname | 说明 |
| --- | --- |
| `bold` | 开始加粗文本 |
| `smul` | 开始下划线文本 |
| `rmul` | 结束下划线文本 |
| `rev` | 开始反色显示（反 video） |
| `blink` | 开始闪烁文本 |
| `invis` | 开始不可见文本 |
| `smso` | 开始“突出”模式（standout） |
| `rmso` | 结束“突出”模式 |

## 文本效果能力名称

某些能力（如下划线和突出显示）具有用于开启和关闭该属性的能力名称，而另一些能力只有开启该属性的能力名称。在这种情况下，可以使用 `sgr0` 能力名称将文本渲染恢复到“正常”状态。这是一个演示常用文本效果的简单脚本：

```bash
#!/bin/bash

## tput_characters - 测试各种字符属性

clear

echo "tput character test"

echo "======================"

echo

tput bold; echo "这段文本有加粗属性."; tput sgr0

tput smul; echo "这段文本有下划线 (smul);"; tput rmul

# 大终端模拟器都不支持闪烁文本（尽管 xterm

# 支持），因为闪烁文本被认为是不够雅的 ;-)

tput blink; echo "这段文本正在闪烁 (blink)."; tput sgr0

tput rev; echo "这段文本有反色属性"; tput sgr0

## 在许多终端上，突出模式是反色的，在其他终端上是粗体的。

tput smso; echo "这段文本处于突出模式 (smso)."; tput rmso

tput sgr0

echo

```

输出示例：

```text
tput character test
============
这段文本有加粗属性。
这段文本有下划线 (smul)。
这段文本正在闪烁 (blink)。
这段文本有反色属性
这段文本处于突出模式 (smso).
me@linuxbox ~ $
```

## 屏幕擦除

使用这些能力，我们可以构建一个带有菜单和独立输出区域的脚本来显示系统信息：

```bash
#!/bin/bash

# tput menu: 菜单驱动的系统信息

BG_BLUE="$(tput setab 4)"

BG_BLACK="$(tput setab 0)"

FG_GREEN="$(tput setaf 2)"

FG_WHITE="$(tput setaf 7)"

## 保存屏幕

tput smcup

## 显示菜单直到 selection 0

while [ "$selection" != "0" ]; do
  echo -n "${BG_BLUE}${FG_WHITE}"

  clear

  cat <<EOF

  请选择：

  1. 显示主机名和运行时间

  2. 显示磁盘空间

  3. 显示主目录空间使用率

  0. 退出

EOF

  read -p "输入选择 [0-3]: " selection

  # 清除下方区域

  tput cup 10

  echo -n "${BG_BLACK}${FG_GREEN}"

  tput ed

  tput cup 11 0

  # 根据选择操作

  case $selection in

    1)

      echo "主机名: $HOSTNAME"

      uptime

      ;;

    2)

      df -h

      ;;

    3)

      if [ $(du -u) -eq 0 ]; then

        echo "所有用户的主目录空间使用率"

        du -sh /home/* 2>/dev/null

      else

        echo "$HOME"

        du -s $HOME/* 2>/dev/null | sort -nr

      fi

      ;;

    0)

      break

      ;;

    *)

      echo "输入无效。"

      ;;

  esac

  printf "\n\n按任意键继续..."

  read -n 1

done

## 恢复屏幕

tput rmcup

echo "程序已终止。"

```
