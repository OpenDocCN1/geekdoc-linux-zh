
|    |    |
|----|----|
| 1000 Ω | MHz |

只有一种前缀用于单位：

|    |    |
|----|----|
| 1000 kg | Mg |
| 10^-9 s | ns |
| 1000 m | Mm |

此外，当一个单位被平方时，前缀适用于整个单位，例如 km² = 1000 m²。国际单位制的一些定义见表4。

## 国际单位制

为了简化并使交流理解，1960年创建了一个国际接受的单位系统，简写为 SI（源自法语 Système International）。

该系统基于基础单位，以允许对物理现象进行更精确的测量。例如，米（meter）的定义是光在真空中经过 1/299792458 秒所传播的距离。秒（second）是根据在塞夫尔维护的铯原子频率定义的。千克（kilogram）最终可能会通过一个固定普朗常数数值的定义被重新定义。

尽管 SI 被科学家和工程师广泛使用，但在许多情况下也使用其他单位。
