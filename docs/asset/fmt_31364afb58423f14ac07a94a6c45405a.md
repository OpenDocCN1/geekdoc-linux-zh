属性框（property box）由调用 `gnome_property_box_new()` 创建。调用 `property_box_append_page()` 会添加一个新页面，并附带显示为其选项卡标签的文字。“应用”回调信号连接到 `GnomePropertyBox`，每当一个或多个值发生变化且需要将其存储为新的属性值时，就会调用函数 `propertyboxCallback()`。

每当点击“确定”或“应用”按钮时，都会调用 `propertyboxCallback()`。事实上，它会被调用多次。首先，它会针对每个发生变化的页面编号调用一次，然后再次以页面编号 `-1` 调用。例如，如果第 0 页和第 3 页有变化，而第 1、2 和 4 页保持不变，则回调首先以页面编号 0 调用，接着以 3 调用，最后以 -1 调用。在大多数情况下，你只需关注 -1 的调用即可。然而，可能存在某些情况需要对某些页面进行特殊处理，如果在回调每次执行时都这样做将是低效的。

“确定”和“应用”按钮在某个页面上发生任何更改之前都保持不活动状态。让你的应用程序告知 `GnomePropertyBox` 何时发生更改是你的职责。在此示例中，所有单选按钮都会导致回调函数 `radioCallback()` 执行，进而调用 `gnome_property_box_changed()` 来注册有东西已更改的事实。并且，由于 `GnomePropertyBox` 知道当前页面是哪个，它会记录该信息，以便将其传递给“应用”信号回调。

```c
/*  gnomescores.c  **/
#include <gnome.h>

static gchar *names[3] = { "Peter", "Laura", "Norton" };

static gfloat values[3] = { 93/81.0, 99751.0, 4429.0 };

static time_t times[3];

int main(int argc, char *argv[])
{
    GtkWidget *scores;
    gnome_init("gnomescores", "1.0", argc, argv);
    times[0] = time(NULL);
    times[1] = times[0] - 100000;
    times[2] = times[1] - 100000;
    scores = gnome_scores_new(3, names, values, times, FALSE);
    gtk_widget_show_all(scores);
    gtk_main();
    exit(0);
}
```
