# NFS 如何工作

NFS 设计用于在网络上共享文件和目录，需要配置 NFS 服务器（文件和目录所在的位置）和 NFS 客户端（远程访问文件和目录的用户计算机）。

文件系统由 NFS 服务器导出，并在 NFS 客户端上的出现和行为就像它们位于本地机器上一样。

例如，每个用户的主目录可以由 NFS 服务器导出并导入到客户端，从而从每个工作站或网络访问相同的主目录。
