## 互联网/局域网应用程序

Linux 系统是提供网络极佳平台。在本节中，我们将尝试概述最常见的网络服务器和应用程序。

## 服务器类型

### 独立服务器

向用户提供服务有两种方法：守护进程或服务可以运行在独立模式，也可以通过另一个服务来激活。

被频繁或持续使用的网络服务通常以独立模式运行；它们是始终运行的独立程序守护进程。它们可能在系统启动时被请求，并在设置好的特定连接端口或端口上等待请求。当请求到来时，将进行处理，并继续监听直到下一次请求。Web 服务器是一个典型的例子；你希望它 24 小时可用，如果它太忙，你可以创建更多的监听实例来服务同时的用户。其他例子是大型软件库，如 source [http://sourceforge.net] 或你的 Tuc 镜像 [http://trows.com]，它们每天必须处理数千个 FTP 请求。

你家电脑上独立网络服务的示例可能是 `named`（名称守护进程）缓存服务器。独立服务有其正在运行的进程，你可以随时使用 `ps` 进行检查：

```
bob: ps auxw | grep named
named 908 0.0 1 14876 5108 ? S Mar14 0:07 -u named
```

然而，你可以在电脑上使用一些服务，即使这些服务没有运行服务器进程。示例可以是 FTP 服务、安全拷贝服务（`scp`）或 finger 服务。这些服务由互联网守护进程（`inetd`）在它们的位置进行监听。

### (inetd)

在你的家电脑上，情况通常会平静一些。你可能有一个小型网络，可能可能需要使用 FTP 或 Samba（用于与 Windows 机器连接）在不同的电脑之间传输文件。在这种情况下，启动所有你偶尔需要的服务并让它们一直运行将浪费资源。这个超级服务器——互联网服务在系统初始化时启动。有两种常见的实现方式：`inetd`（扩展互联网服务的 inetd 守护进程）。Linux 系统上通常运行其中之一：

```
bob: ps -ef | grep inetd
root 926 1 Mar14 ? 00:00:00 xinetd-ipv6 -stayalive -reuse -pidfile /var/run/xinetd.pid
```

由互联网守护进程负责的服务列在其配置文件中，对于 `inetd` 是 `/etc/inetd.conf`，对于 `xinetd` 则是 `/etc/xinetd.d` 目录。常见的服务包括文件共享和打印服务、SSH、FTP、Samba 配置守护进程、talk 和时间服务。

一旦接收到连接，中央服务器将启动所需的服务器。因此，在下面的示例中，当用户 bob 启动到本地的 FTP 会话时，只要服务处于激活状态，FTP 守护进程就会运行：

```
bob-> ps auxw | grep ftp
bob 793 0.1 0.2 3960 1076 pts/6 S 16:44 0:00 nctfp localhost
ftp 794 0.7 0.5 5588 2608 ? SN 16:44 0:00 ftppd:
localhost.localdomain: anonymous@bob@his.server.com: IDLE
```

当然，当你连接到远程主机时，情况也是类似的：要么由一个守护进程直接回答，要么由远程服务（`xinetd`）在你需要时启动，在你不需要时停止。

# 邮件 (Mail)

## 服务器

`Sendmail` 是 UNIX 平台上标准的邮件服务器程序或邮件传输代理（MTA）。它健壮且可扩展；在通过适当硬件进行良好配置的情况下，它可以轻松处理成千上万用户的请求。关于如何配置 Sendmail 的更多信息包含在 `sendmail` 和 `sendmailcf` 软件包中，你可以阅读 `/usr/share/doc/sendmail` 目录下的 `README` 和 `README.cf` 文件。**主邮件 (mainmail)** 和许多**别名 (aliases)** 很有用。

`Qmail` 是另一个邮件服务器，因为它声称比 Sendmail 更安全而受欢迎。Sendmail 是一个单体程序，而 Qmail 由多个较小的交互程序部分组成，这些部分可以被安全保护。Postfix 是另一个日益受欢迎的邮件服务器。

这些服务器处理邮件列表、病毒扫描过滤等功能。Linux 提供了免费和商业扫描器可以使用。邮件列表软件的示例有 Mailman、Listerv、Majordomo 和 Eznim。请访问你喜欢的病毒扫描器的网页获取有关 IMAP 客户端和服务器支持的信息。Avit 和 Spassassin 是病毒扫描器和垃圾邮件扫描器的免费实现。

## 远程邮件服务器

远程访问邮件最流行的协议是 POP3 和 IMAP4。IMAP 和 POP 都允许离线操作、远程访问新邮件，并且都依赖于 SMTP 服务器来发送邮件。

虽然 POP 是一个简单的协议，易于实现并被几乎任何邮件客户端支持，但更优选择 IMAP：

- 它可以操作消息的状态标记。
- 它可以存储以及获取邮件消息。
- 它可以访问并管理多个邮箱箱。
- 它支持并发更新和共享邮箱箱。
- 它也适合用于 Usenet 消息和其他文档。
- IMAP 在在线和离线状态均可工作。
- 它针对在线性能进行了优化，特别是在低速链路之上。

# 邮件用户代理 (Mail user-agents)

有大量的文本和图形化邮件客户端，我们只列出常见的几种。选择一个你喜欢的即可。

UNIX `mail` 命令已经存在多年了，甚至在网络出现之前就有。它是一个简单的接口，用于向他人发送消息和小文件，对方可以保存消息、重定向它或在该处进行回复。

虽然它现在不再常用作客户端，但 `mail` 程序仍然很有用，例如将命令的输出发送给某人。

```
mail <future.employer@whereIwant2work.com> < cv.txt
```

`elm` 阅读器是对 `mail` 的一个急需的改进，`pine`（Pine Is Not ELM）也是如此。`mut` 邮件阅读器则更现代，提供了线程等功能。

对于那些喜欢使用图形化界面处理邮件的人（以及有网球肘或鼠标手臂的人），有数百种选择。新用户最流行的是 Mozilla Mail/Thunderbird，它具有简单的反垃圾邮件配置选项，以及 MS Outlook 的克隆版本 Evolution。Kmail 在 KDE 用户中很流行。
