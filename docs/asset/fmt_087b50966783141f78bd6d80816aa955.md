
# 电弱理论

| | 弱核力 | $10^{-6}$ | 弱荷 ($t_3$, s) | 玻色子 ($W^+$, $Z^0$) | $10^{-16} \text{ m}$ |
| 引力 | $10^{-40}$ | 质量 (m) | 引力 (G) | $\infty$ |

某些可测量的物理量。通过格尔德·特·霍夫特（G. 't Hooft）、马丁·维尔特曼（M. Veltman）等人的开创性工作，已证明该理论可以通过规范对称性的自发破缺以及引入一种新粒子——希格斯玻色子，来消除无穷大，赋予粒子质量，从而使其可重整化。参见“规范理论”、“希格斯玻色子”、“重整化”、“对称性破缺”。

中性规范玻色子 $W^0$ 和 $B^0$ 形成一个量子力学混合态，从而产生两种物理上可观测的规范玻色子：$\gamma$ 和 $Z^0$，如方程 (1) 所示。$\gamma$ 是众所周知的、媒介电磁相互作用的光子；$Z^0$ 媒介中性流弱相互作用；$W^{\pm}$ 媒介带电弱相互作用。通过这种方式，所有这些相互作用都由一个共同的统一理论来描述。方程 (1) 中形成 $\gamma$ 和 $Z^0$ 的混合角 $\theta$ 被称为弱混合角，是该理论的基本参数。粒子相互作用的强度和性质由矢量耦合常数和轴矢量耦合常数 $g_V$ 和 $g_A$ 决定。在弱电模型中，所有这些耦合都通过理论的单参数——弱混合角以及轻子和夸克性质来表示。该模型还给出了电荷 $q$ 与弱荷 $t_3$ 和 $y$ 之间的关系，如方程 (2) 所示。

```
\begin{aligned}
\gamma &= \sin \theta \ W^0 + \cos \theta \ B^0 \\
Z^0 &= \cos \theta \ W^0 - \sin \theta \ B^0
\end{aligned} \qquad (1)
```

```
q = t_3 + \frac{1}{2} y \qquad (2)
```

参见“非相对论量子理论”、“量子力学”。

支配所有粒子弱电相互作用的耦合常数可总结如下：
- 电磁相互作用：$g_V = q, g_A = 0$
- 带电弱相互作用：$g_V = - g_A = t$
- 中性弱相互作用：$g_V = t_3 - 2q \sin^2 \theta$，$g_A = - t_3$

在上述表达式中，$t$ 代表弱同位旋的大小，$t_3$ 是其在量子化轴上的投影。电弱理论具有强大的预言能力。其第一个也是最具标志性的预言是中性流弱相互作用的存在，这种相互作用由 $Z^0$ 玻色子媒介。在提出该预言之前，人们认为弱相互作用仅具有带电性质，没有中性流成分。

电弱理论的第二个重大胜利是 1983 年在瑞士日内瓦欧洲核子研究中心（CERN）的质子-反质子对撞机中发现 $W$ 和 $Z$ 玻色子，其质量非常接近理论预测值。此时，该理论的有效性被认为已得到确凿证实。参见“粒子加速器”。

成功的电弱理论结合描述强核相互作用的量子色动力学（QCD），构成了所谓的粒子物理标准模型。该标准模型在准确预测和描述从原子物理的弱电能量范围到最大现有粒子对撞机 100-GeV 能量范围的广阔能量范围内的所有实验结果方面取得了辉煌的成功。因此，它代表了实验物理和理论物理的一座里程碑。参见“量子色动力学”、“标准模型”。

尽管取得了巨大成功，该领域仍有两个主要问题有待解决。第一个问题是，标准模型当前的形式无法解释基本组分——夸克和轻子——的质量。这些质量的变化范围很大，从几电子伏特到 $174 \text{ GeV}$。标准模型所基于的基本规范对称性表明，这些质量应该都是相同的。因此，一定还缺少谜题的另一部分，通常被称为电弱对称性破缺的来源，亟待发现。关于模型中这一缺失要素的假想理论，从预言一种额外的粒子——希格斯玻色子，到预言数十种新基本粒子的复杂模型（如超对称）不等。参见“希格斯玻色子”、“超对称”、“对称性破缺”。

第二个未解决的问题是寻找一种不仅描述强核相互作用和电弱相互作用，还包含引力的理论。标准模型基于量子力学原理，而目前对引力的理解基于爱因斯坦的广义相对论。迄今为止，无人能够将这两种理论结合起来；也就是说，量子引力理论尚不存在。寻找这种大统一理论是理论物理学的重点研究方向之一。参见“基本粒子”、“量子引力”、“相对论”。[C.B.]

## 元素（化学）

元素是由具有相同原子序数的原子构成的物质。一些常见的元素包括氧、氢、铁、铜、金、银、氮、氯和铀。大约 75% 的元素是金属，其余的是非金属。大多数元素在室温下是固体，其中两种（汞和溴）是液体，其余的是气体。

少数元素在自然界中以游离（未结合）状态存在。这些元素中的一些包括氧、氮、惰性气体（氦、氖、氩、氪、氙和氡）、硫、铜、银和金。自然界中大多数元素以化合物的形式与其他元素结合。地球上最丰富的元素是氧；其次是硅。宇宙中最丰富的元素是氢，其次是氦。参见“元素的地球化学分布”。

元素在周期表中按族或组分类。元素也常被分类为金属和非金属。金属元素是指其原子在溶液中形成阳离子的元素，非金属元素是指其原子在溶液中形成阴离子的元素。参见“周期表”。

特定元素的原子具有相同的原子序数，但可能不具有相同的原子量。具有相同原子序数但不同原子量的原子被称为同位素。例如，氧由原子量分别为 16、17 和 18 的原子组成。氢由同位素 1、2 和 3 组成；质量数为 2 和 3 的同位素分别称为氘和氚。碳由同位素 11、12、13 和 14 组成。碳-14 具有放射性，用作许多化学实验中的示踪剂。

所有元素都有同位素，尽管在某些情况下仅已知人工合成同位素。例如，氟在自然界中以 $^{19}$F 形式存在，但可以产生人工放射性同位素 $^{18}$F。不同元素的许多同位素是不稳定的，即具有放射性的，因此它们会衰变形成该元素或其他元素的稳定原子。参见“原子质量”、“放射性”。

人们相信，化学元素的起源是极高温度（约 100,000$^{\circ}$C 或 180,000,000$^{\circ}$F 或更高）下简单核子（质子和中子）的聚变合成过程的结果，首先合成较重的原子核，如氦的原子核，然后合成较轻元素的更重、更复杂的原子核（锂、硼等）。氦原子轰击较轻元素的原子并产生中子。中子被元素的原子核捕获，从而产生较重的元素。参见“核合成”。

一些在自然界中仅存在极微量或根本不存在的元素，如锝、钷、砹、镭以及原子序数大于 92 的所有元素，都是通过多种核反应合成的。这些核反应涉及通过轰击某元素的中子或快速粒子（质子、氘核和 $\alpha$ 粒子）来改变该元素的原子序数，从而将一种元素的原子嬗变为另一种元素的原子。参见“原子结构与光谱”、“超铀元素”。

## 111号元素

111号元素于1994年末被发现。它应该是金、银和铜的同族元素。预计它是6d壳层中的第九个元素，但目前已知唯一同位素的半衰期为1.5毫秒，太短而无法进行化学研究。参见“铜”、“金”、“半衰期”、“放射性同位素”、“银”。

记录111号元素发现的衰变链序列。方框下方的数字是$\alpha$能量和相关时间。111号元素通过反应 $^{209}$Bi + $^{49}$Ca $\to$ $^{271}$111 + 1n 产生。

该元素于1994年12月17日在GSI（重离子研究所；德国达姆施塔特）被发现，通过探测同位素 $^{272}$111（111号元素质量数为272的同位素）实现。该同位素由镍-64弹核与铋-209靶核融合，融合系统通过发射一个中子冷却后产生。通过连续$\alpha$衰变至铹-268、𬬭-264、𬭊-260和鑪-256，并利用已知的 $^{256}$Db 和 $^{256}$Lr 的衰变特性，实现了身份识别。在衰变链（见图）中，前三个成员是新的同位素。同位素 $^{272}$111 的半衰期为1.5毫秒，其产生截面为3.5 $\times$ 10$^{-36}$ cm$^{2}$。总共观察到了三条衰变链。新同位素铹-268和𬬭-264是目前已知这些元素最重的同位素。它们70毫秒和0.4秒的半衰期分别长于这些元素先前已知的同位素。参见“$\alpha$粒子”、“中子”、“核反应”。

## 112号元素

112号元素于1996年被发现。它应该是汞、镉和锌的重同族元素。预计它是6d壳层中的最后一个元素。由于所有截面都在 10$^{-36}$ cm$^{2}$ 范围内且半衰期很短，近期无法进行化学研究。参见“镉”、“半衰期”、“汞（元素）”、“锌”。
