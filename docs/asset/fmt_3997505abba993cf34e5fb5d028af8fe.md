
`function name(args,...) { statements }`

你可以在 `awk` 程序的任何地方引用函数；特别是，你可以在函数被定义之前调用它。函数的作用域是全局的。

函数参数可以是标量或数组；如果将数组名作为函数用作标量的参数传递，或者将标量表达式作为函数用作数组的参数传递，则行为是未定义的。函数参数如果是标量则按值传递，如果是数组名则按引用传递。参数名对于函数是局部的；所有其他变量名都是全局的。同名不能既作为数组又作为函数名或变量名。同名不能既作为全局作用域的变量又作为函数名。在同一作用域内不能既作为标量变量又作为数组。

函数定义中的参数数量不需要与函数调用中的参数数量匹配。多余的形式参数可以作为局部变量。如果函数调用提供的参数少于函数定义中的参数，在体中作为标量使用的额外参数将初始化为空字符串值，作为数组的参数将初始化为空数组。如果函数调用提供的参数多于函数定义中的参数，则行为是未定义的。

调用函数时，在函数和左括号之间不要留空格。你可以嵌套函数调用并对函数进行递归调用。在任何嵌套或递归调用返回时，除了按引用传递的数组参数外，所有调用函数参数的值都保持不变。你可以使用 `return` 语句返回一个值。如果 `return` 语句出现在定义之外，则行为是未定义的。

# newialases — 重建邮件别名文件的数据库

# 摘要

`/usr/bin/newialases`

## 描述

`newialases` 命令重建邮件别名文件 `/etc/mail/aliases` 的随机访问数据库。当 `/etc/mail/aliases` 新于 `/etc/mail/aliases.pag` 时，`sendmail(1m)`（在默认配置下）会自动运行它。
`newialases` 接受 `sendmail(1m)` 接受的所有标志。然而，这些标志中的大多数没有影响，除了 `-C` 选项以及可以通过 `-o` 选项从配置文件设置的三个处理选项外。

- `-C /path/to/alt/config/file` 使用备用配置文件。
- `-oFile` 指定可能的别名文件。
- `-oLn` 将默认日志级别设置为 n。默认值为 9。
- `-on` 在重建 `aliases(4)` 数据库时验证别名的右侧部分（RHS）。

`newialases` 会自动以详细模式运行（`-v` 选项）。

## 示例

对不同于 `sendmail(1m)` 默认 `/etc/mail/aliases` 的别名文件运行 `newialases`：

```
castle$ newialases -oA/path/to/alternate/alias/file
```
