- 3. 不存在 TCP 内存压力。

接下来，我们检查为接收缓冲区分配的总内存是否仍然超过配额。如果在尝试将接收缓冲区配额提高到 `sysctl_tcp_rmem[2]` 的情况下该条件可能为假。如果是这样，我们返回。否则，我们尝试减小窗口限制（window clamp）并获取慢启动阈值。窗口限制对宣告的窗口大小设置了上限，而慢启动阈值对任何时刻要宣告的窗口设置了限制（参见第 11.3.7 和 11.3.5 节）。
