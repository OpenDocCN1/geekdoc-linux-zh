
# rm

递归删除 `abc`

### `rm -r abc`

### More

当你想查看大于一屏的文件时，可以使用 `more` 工具。它每次显示一屏文本。

#### 语法
`more filename`

#### 示例
```
more /etc/hosts
```

### less

`Less` 程序与 `more` 类似，但允许在文件中后向和向前移动。

#### 语法
`less filename`

#### 示例
```
less /etc/hosts
```

### mv

`mv` 命令用于将文件从一个位置移动到另一个位置。它也可以重命名文件。

#### 移动文件
##### 语法
`mv filename destination_directory`

##### 示例
```
mv a.txt /tmp/
```
将 `a.txt` 从当前目录移动到 `/tmp`

#### 重命名
##### 语法
`mv filename newfilename`

##### 示例
```
mv a.txt b.txt
```

### grep

在一个或多个文件中搜索字符串。显示包含字符串的每一行。

#### 语法
`grep string file`

#### 示例
```
grep '127.0.0.1' /etc/hosts
```

### head

将文件的前 10 行打印到标准输出。你可以指定显示多少行。

#### 语法
`head file`

#### 示例
```
head -20 /etc/mime.types
```
显示 `mime.types` 的前 20 行

### tail

将文件的最后 10 行打印到标准输出。你可以指定显示多少行。

#### 语法
`tail file`

#### 示例
```
tail -20 /var/log/logfile
```
显示最后 20 行

#### 使用 tail 持续监控文件
```
tail -f /var/log/logfile
```
显示增长的文件末。按 `Ctrl + c` 中断

### Diff

比较两个文件。

#### 语法
`diff First_file Second_file`

#### 示例
```
diff abc.txt bbc.txt
```

### file

确定文件类型

#### 语法
`file file_name`

#### 示例
```
file bbc.txt
```

### Echo

显示文本

#### 语法
`echo text`

#### 示例
```
echo hello
```

### Date

打印或更改系统日期时间。

#### 语法
`date`

#### 示例
```
date
```
检查日期
```
date -s "24 feb 2017 19:00"
```

# 第 12 章

## 管道和重定向

### 输出输出到文件 (`>`)

通常我们会在屏幕上看到输出，但如果我们希望将其保存到文件中，则使用大于符号 (`>`) 将标准输出发送到文件。

#### 示例
```
ls > abc.txt
```

### 从文件发送输入 (`<`)

如果我们使用小于符号 (`<`)，我们就可以从文件中读取数据并通过程序的 STDIN 流将其输入给程序。

#### 示例
```
wc -l < abc.txt
```

### 管道 (`|`)

为了将数据从一个程序发送到另一个程序，我们使用管道 (`|`)

```
ls | head -10
```

## 压缩工具

主要有三种工具可以压缩文件

| 压缩 | 扩展名 | 解压缩 |
|---|---|---|
| bzip2 | bz2 | bunzip2 |
| Gzip | gz | gunzip |
| Zip | zip | unzip |

### 压缩

#### Bzip2 格式
##### 语法
`bzip2 file_to_backups filename`

##### 示例
```
bzip2 * abc
```

#### gzip 格式
##### 语法
`gzip file_to_backups filename`

##### 示例
```
gzip * abc
```

#### zip 格式
`zip file_to_backups filename`

##### 示例
```
zip * abc
```

### 解压缩

#### Bzip2 格式
##### 语法
`bzip2 filename`

##### 示例
```
bunzip2 abc.bz
```

#### gzip 格式
##### 语法
`gunzip filename`

##### 示例
```
gunzip abc.gz
```

#### zip 格式
##### 语法
`unzip filename`

##### 示例
```
unzip abc.zip
```

# 管理服务和守护进程

### 守护进程 (Daemons)

守护进程是在后台运行且不进行交互的进程。守护进程会在预定的时间执行预定义的操作。通常守护进程在启动时运行并持续到关机。大多数守护进程的名字以 `d.` 结尾。

### 服务 (Services)

服务是位于 `/etc/rc.d/init.d` 目录下的初始化脚本。这些脚本用于管理守护进程。可以使用 `start`、`stop`、`restart`、`status` 和 `reload`（重载）等参数调用服务脚本来管理守护进程。
可以使用 `chkconfig service_name on` 命令在系统启动时启动服务。

### 运行级别 (Run level)

运行级别是操作系统运行的运行或模式。每个运行级别都有一定数量的停止或启动的服务，从而控制机器的行为。共有七种种运行级别：

- 0 关机
- 1 单用户模式
- 2 未使用，用户可以使用
- 3 无 GUI 的命令行多用户模式
- 4 未使用，用户可以使用
- 5 带 GUI 的多用户模式

### 命令

#### 检查当前运行级别
```
runlevel
```

#### 更改默认运行级别

在此示例中编辑 `/etc/inittab` 文件以更改命令行运行级别 3

```
Id:3:default:
```

# 管理服务启动

#### 列出所有服务及其在每个运行级别下的状态
```
chkconfig --list
```

#### 列出特定服务的当前设置
##### 语法
```
chkconfig --list service_name
```
##### 示例
```
chkconfig --list vsftpd
```

#### 在运行级别 2, 3, 4, 5 中启用服务
##### 语法
```
chkconfig Service_name on
```
##### 示例
```
chkconfig httpd on
```

#### 在特定运行级别启用
```
chkconfig service_name --level 35
```

#### 在 2, 3, 4, 5 运行级别中禁用服务
##### 语法
```
chkconfig service_name off
```
##### 示例
```
chkconfig httpd off
```

#### 在特定运行级别禁用
##### 语法
```
chkconfig service_name off --level 3
```
##### 示例
```
chkconfig service_name off --level levelno
```

# 管理服务状态

#### 确定服务是否正在运行
##### 语法
```
service service_name status
```
##### 示例
```
service vsftpd status
```

#### 显示所有服务的状态
```
service --status-all
```

#### 启动服务
##### 语法
```
service service_name start
```
##### 示例
```
service httpd start
```

#### 停止服务
##### 语法
```
service service_name stop
```
##### 示例
```
service httpd stop
```

#### 重启服务
##### 语法
```
service service_name restart
```
##### 示例
```
service httpd restart
```
