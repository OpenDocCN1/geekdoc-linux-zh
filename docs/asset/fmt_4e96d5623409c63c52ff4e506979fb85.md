<!DOCTYPE type>

在列表 1.1 中，`<!DOCTYPE>` 表明 HTML 版本。`<html>` 和 `</html>` 标签定义了 HTML 文档的开始和结束。`<head>` 和 `</head>` 标签定义了文档头部。在文档头部中，我们使用 `<title>` 和 `</title>` 标签来定义所需的标题。`<body>` 和 `</body>` 标签定义了文档正文部分的开始和结束，那里是您放置实际内容的地方。在接下来的章节中，您将简要学习这些部分：

## 声明文档类型

`<!DOCTYPE>` 声明是你需要在 HTML 文档中添加的第一个内容。它不是一个 HTML 标签，它用于 `<html>` 标签之前，作为一条指令指定文档所使用的文档类型定义 (DTD)。DTD 定义了标记语言遵循的规则以及你正在使用的文档类型版本。HTML 4.0 带有三种类型的文档：

- HTML 4.1 Strict（严格型）：结构元素优于表现性元素。它不包含已弃的元素。该文档类型的声明如下：
`<!DOCTYPE HTML PUBLIC "//W3C//DTD HTML 4.01//EN" http://www.w3.org/TR/html4/01/strict.dtd">`
- HTML 4.1 Transitional（过渡型）：包含结构元素、表现性元素和已弃元素。该文档类型的声明如下：
`<!DOCTYPE HTML PUBLIC "//W3C//DTD HTML 4.01 Transitional//EN" http://www.w3.org/TR/html4/transitional.dtd">`
- HTML 4.1 Frameset（框架型）：指的是与过渡类型相似的文档类型，但它还支持为你的 HTML 文档创建框架所需的元素。该文档类型的声明如下：
`<!DOCTYPE HTML PUBLIC "//W3C//DTD HTML 4.01 Frameset//EN" http://www.w3.org/TR/html4/frameset.dtd">`

## 探索 HTML 标签

HTML 文档包含定义网页整体布局的 HTML 标签。这些 HTML 标签使用符号 `<`。在符号 `< >` 之间提供元素名称。大多数 HTML 标签都有开始标签和结束标签。开始标签定义了标签从哪里开始，而结束标签指定了它在哪里结束。例如，`<html>` 和 `</html>` 是定义 HTML 文档开始和结束的标签标签。

## 探索文档头部

文档头部包含 HTML 文档的处理信息和元数据。元数据包含关于网页的信息。`<head>` 和 `</head>` 是文档头部的开始和结束标签。文档头部部分的信息不会出现在 浏览器中。

## 探索文档标题

每个文档都需要一个标题名称来标识网页。HTML 文档的标题在 浏览器中显示时会出现在顶部。HTML 提供了 `<title>` 标签来为你的文档添加标题。标题的结束标签是 `</title>`。你可以为你的 HTML 文档指定标题，以便让人对 HTML 文档的内容有一个了解。例如，假设你想将 Kogent Solutions 作为你 HTML 文档的标题名称。那么你如下所示：

```
<title>Kogent Solutions</title>
```

## HTML 文档的正文

在准备 HTML 文档时，除了编写基础 HTML 标签外，你会在文档中添加一些文本、图像、列表和表格。所有这些内容都在 HTML 文档的正文中。你想放入 HTML 文档正文的所有内容都在 `<body>` 和 `</body>` 之间。你在这两个标签中添加的信息是可以在 浏览器中显示的实际内容。

## 探索元数据

元数据是描述其他数据的数据。在 HTML 文档中，元数据包含信息，例如你使用的编辑器类型、作者信息、内容描述以及版权信息。除了标题之外，元数据添加到 HTML 文档的头部。`<meta />` 标签用于元数据。该标签提供了网页的简短描述。下面的示例展示了如何在 HTML 文档中使用 标签：

```
<meta name="description" content="everything you wanted to know about Kogent" />
```
