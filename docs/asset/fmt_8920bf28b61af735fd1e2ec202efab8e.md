# 守恒定律（物理）

守恒定律规定，对于孤立系统，特定物理量的总值随时间保持不变。守恒定律在物理学基础中占据重要地位。

经典力学中的实现。力学有三大守恒定律：线性动量守恒（通常称为动量守恒）、角动量守恒和能量守恒。

粒子的线性动量或简单动量等于其质量与速度的积。它是一个矢量。粒子系统的动量是每个单个粒子动量的和。守恒定律确保了这一总动量随时间改变。参见动量守恒。

粒子的能量与其质量和速度的平方成正比。能量守恒定律确保孤立系统的总能量保持恒定。参见能量守恒。

能量守恒是最重要的定律。能量是一个标量，具有两种形式：动能和势能。粒子的动能定义为质量与速度平方乘积的一半。势能从局部定义为做功的能力。

总能量是动能和势能之和，根据能量定律，它在孤立系统中保持恒定。

线性动量守恒定律被理解为空间向同性的结果，而角动量守恒定律被认为是时间向同性的结果。参见角动量守恒。

控制图：一种用于确定过程是否处于统计控制状态的图表技术。在统计控制状态下，由原因引起的变异没有超过根据过程性质和预期用途、基于过程自然变异所预期的范围。

其他图表对无法控制且无法消除的随机因素具有某些敏感性。例如，对于统计测量，随机因素可能会导致估计值的失真；通过对制造设备的选择，导致影响操作速度和趋势的供应波动；以及操作人员表现的变异。过程固有的变异性是各个原因的累计结果，每个原因的影响都很微小。

控制图技术适用于产生连续输出的工艺。控制图的设计目的是检测由于可以纠正的特定原因引起的变异。当识别出特殊原因时，可以容易且经济地将其消除。制造领域可能出现的变异原因示例包括：不合格的原材料、机器故障和操作人员的方法。

控制图是过程随时间变化的二维图表。水平轴代表时间，具有不同的样本量。垂直轴代表样本统计量的值，这可能是平均值、标准差或任何其他变量测量值，或者是不合格单元数、不合格率或每单位不合格零件平均数。

典型的控制图有三条平行线（见插图）：一条中心线和两条控制限。中心线代表稳定状态下（仅有自然变异）的过程水平。中心线上方和下方的线分别表示上控制限（UCL）和下控制限（LCL）。它们规定了样本统计量的范围。控制限限制了垂直轴，使得当只存在过程的自然变异时，样本点落在控制限之外并导致误报的概率将是非常昂昂的。通常，控制限位于中心线两侧三个标准差处。这导致了误报的概率为 0.0027。

控制图的工作原理简单，由五个通用步骤组成：

1. 定期从过程中抽取样本。
2. 对单元的观测值进行统计量计算；在统计测量中，根据观测值计算数学函数。
3. 将统计量的值随时间绘制成图表；任何落在控制限之外或任何随机模式都表明过程发生了变化，无论是其设定还是变异。
4. 如果检测到变化，停止过程并进行调查以确定变化的原因。
5. 一旦确定了原因并采取了任何必要的措施，过程即可恢复。

控制图的主要优点是提供了一种视觉手段，用于识别过程水平或变异何时因异常发生变化，从而不再处于统计控制状态。指示失控状态的视觉模式或需要关注的点集被称为离群值、点链（runs）、趋势、循环和混合物。控制系统；价值评定 [T.R.A]。

## 控制系统

形成系统的连接将提供所需的系统响应时间。汽车的转向是一个熟悉的例子。驾驶员观察汽车的位置，并通过转动方向盘进行调整。汽车随方向改变响应，驾驶员试图减小预期路径与实际路径之间的误差。在这种情况下，控制输出是转向，反馈是驾驶员，路面是控制器。工程师的目标是设计一种对于任务有效的控制机制。不同的控制系统和设计结果会导致不同的速度，例如汽车的速度相对较慢。

# 配位化学

根据 G. N. Lewis 的定义，配位化学通常用于描述金属及其与分子或离子的相互作用。配位化合物包含一个中心原子或离子，该离子周围环绕着分子或离子。由于配位键倾向于保持其身份，因此不易逆转，尽管可能会发生部分解离。配位物种可以是正的、零或负的，取决于中心原子携带的电荷。它们被分类为阳离子、中性或阴离子，后者被称为配位化合物。这些化合物的其他名称包括配合物、配位配合物或简单配合物。

早在19世纪的实验观察导致了对配位化合物的鉴定，但未能充分解释它们的性质。Werner 对这些化合物出了正确的解释。1893年，他引入了配位键的概念，并认为元素除了一级或普通价态外还有两种价态。

三种理论被用来解释配位键的本质。静电理论（包括晶体场修正）和分子轨道理论（也被使用的分子轨道理论）。金属配合物的价键考虑了金属上的电子对以及金属的杂化轨道，键本质上是共价或离子的。几种成键物质可以从该理论得到解释。电子理论解释了过渡金属的共价键，其中金属-配体键是由电荷和偶极之间的静电相互作用引起的。晶体场理论除了解释金属的结构和性质外，还为配合物的稳定性提供了适应性解释。分子轨道理论假设金属配合物的稳定性取决于金属所有核的重叠。这种方式，它同时使用了价键和晶体场理论。

例如，酸碱反应：
`Cu² + 6H₂O → [Cu(H₂O)₆]²⁺ (1)`
`Ni² + 4NH₃ → [Ni(NH₃)₄]²⁺ (2)`
`Fe³ + 6CN⁻ → [FeCN₆]³⁻ (3)`

形成的产物是配位离子或化合物，这一化学领域被称为配位化学。

金属配合物的稳定性取决于金属和配体。金属配合物的稳定性随着电荷和尺寸的变化而增加，并随着亲力的增加而增加。配体的若干特征已知影响以下稳定性：(1) 碱性 (2) 金属-配体环的数量 (3) 配体的尺寸以及 (4) 空间效应。由于配位键是酸碱反应的结果形成的，其中金属离子作为路易斯酸，配体越碱，越倾向于形成更稳定的配合物。配体的尺寸是一个重要因素。对于饱和配体如乙烯，五元环是更稳定的配合物。

空间因素对金属配合物的稳定性有很大影响。这在靠近原子或配体的具有大基配体中经常观察到。因此，插图中的配体类型在该位置具有大基 R 比具有 H 要稳定得多。大基诱导了配体相互作用产生应变，因此在任何其他位置的任何取代都会使配合物更稳定，因为大基从配位点被移除了。

## 572 库仑爆炸

分子结构模型并诱发自由电子的产生。清晰结构。

库仑爆炸发生在高速运动的分子撞击固体时，键由于与固体电子的剧烈碰撞被撕裂，分子随后分解为带电原子团，这些原子在相互库仑斥力下分离。

库仑爆炸主要使用粒子加速器研究（核物理中通常称为范德格拉夫发生器等），以产生被加速的离子束。分子射流在穿透箔层的前几纳米米内运动的库仑爆炸，在射流进入箔层下游真空后转向并完成。位于下游的探测器测量碎片相对于束的能量和电荷。
