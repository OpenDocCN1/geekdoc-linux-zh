## semantic

一个用 `elicit` 编写的词法处理器、解析器生成器和解析器。`Semantic Bovinar` 的目标是为语言无关工具的作者提供一个中间 API，以便他们能够以通用的方式处理语言。它为精通语言的作者提供了一种简单的方法来为这些工具提供解析器，而无需了解这些细节。`Semantic Bovinar` 由这些重要部分组成：

- `lexer`（词法处理器）：将语言转换为标记流 –
- `parser`（解析器）：根据语言将流转换为非终符流。
- `parser-generator`（解析器生成器）：将语言转换为解析器可表（使用 `Semantic Bovinar` 编写）。

## secvpn

安全虚拟专用网络 (`secvpn`)，一种基于 Linux VPN HOWTO 中描述的基于 `ssh` 和 `ppp` 的 VPN。（请查看该处获取更多信息）所有到 `secvpn` 主机的必要路由都将通过 `secvpn` 完成。`Secvpn` 将尝试重新建立断开的连接。来自 Debian 3.0r APT

## sed

`Sed`（流编辑器）是一种流或批（非交互式）编辑器。`Sed` 将文本作为输入，对文本执行一个操作或一组操作，并输出修改后的文本。`sed` 执行的操作（替换、删除、插入等）可以在脚本文件中或从命令行指定。来自 Redhat 8.0 RPM

http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

## 安全策略说明

（等同于“通过隐蔽实现安全”）黑客用来嘲笑 OS 厂商最喜欢的复制安全漏洞的方法——即忽视它们，不记录任何已知的漏洞或底层的安全算法，并相信没人会工作太久，而且发现它们的人不会利用它们。这种“策略”可以维持很长时间，并偶尔会让世界陷入数十年的困境，例如 1988 年的 `RTM` 蠕虫（见大蠕虫），但一旦由安全漏洞引起的短暂恐慌过去，最脆弱的供应商都愿意收场并回到睡眠中。之后，修复漏洞很快，在营销营销意愿清单上实施用户界面训练的资源就不再需要了，而且，如果他们开始关注安全，客户最好想象他们的声誉保证带给他们某种比未签名的 Windows 中文功能更少的系统，那样我们又会怎样呢？历史说明：关于这个术语的起源存在矛盾说法。有人声称它首次用于 Unix 克隆系统 `Aegis/DomainOS` 中的 Unix 新系统（他们什么都没改），旨在呼吁 `HP/Apollo` 修复系统中的安全问题。另一方面，IT 粉丝认为这个词是几年前为了反对走廊尽头极其深奥的 `Multics` 人士而提出的，对他们来说，安全就是一切。在行业中，它指的是：(1) 当一个游客弄清楚如何确保自己已经达到了那个门槛时，他觉得自己成了该社区的一部分；以及 (2) （自嘲地）文档覆盖范围差以及许多命令的晦涩。

允许对运行中的 IT 系统进行补丁的命令（`escape control–R`）称为 `$$` 如果你 `alted alt $D`，这是一个会在你稍后进入系统时阻止系统打补丁的设置。来自 Jargon Dictionary
