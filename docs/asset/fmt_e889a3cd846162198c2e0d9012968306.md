
## 安装步骤验证
如果您正使用 DVD 安装 Kali Linux，请尝试以最慢的刻刻录 DVD。确保您已禁用了系统上的防火墙或防病毒软件，以防其中断写入过程。如果您遇到磁盘空间不足的错误，请尝试增加磁盘的分配空间。检查您为安装 Kali Linux 分配的空间。最佳选项是分配至少 20 GB 的空间，加上交换分区（`swap`）空间。您也可以通过删除并重新对磁盘上的空空间进行分区来排查安装中的问题。您也可以允许安装程序自动对磁盘上的空空间进行分区，这可能会解决您的问题。

Kali Linux 是信息安全领域闻誉全球的名字。它由 Offensive Security 资助和维护，该公司是渗透测试和信息安全相关服务的提供商。Kali Linux 已成为黑客攻击的首选发行版。在几分钟内，您就可以拥有一个功能完备的测试箱，以及在其他地方可能找不到的各种工具集。Kali Linux 预装了大量工具，减少了安装其他工具的压力。

您可以选择在您的系统上完全安装 Kali Linux。但在大多数情况下，您用于渗透测试或伦理黑客攻击的系统可能要求您仍保留 Windows 或任何其他操作系统作为主操作系统。在这种情况下，您只能使用虚拟化工具，然后在虚拟机中运行 Kali Linux。然而，如果运行 Windows 或任何其他操作系统的系统内存不足，可能会导致虚拟机频繁崩溃。另一个选项是在安装了 Kali Linux 的外部 USB 驱动器上在并运行 Kali Linux。

这种方案带来的唯一问题是缺乏加密。

从加密的外部可启动 USB 盘上安装并运行 Kali Linux 被认为是最佳选项。

但是，您还需要确保其安全。因此，为了做到这一点，您需要遵循以下步骤。

- 首先使用相关公司拥有的 USB 盘。
- 使用磁盘完全加密功能，在 1 TB USB 盘上对 Kali Linux 进行完整安装。
- 随后，您需要对 USB 盘上的数据进行加密。由于内置硬盘也通过不同形式的加密处于加密状态，因此在从 USB 盘启动到操作系统时，内置硬盘也将无法访问。
- 由于您使用的 USB 盘是公司拥有的，所有使用的数据都存储在公司的硬件中。
- 整个项目结束后，您可以将外部 USB 盘交回公司，所有相关的测试信息和数据返回给客户。

要开始此过程，您需要下载 Kali Linux 安装程序的 ISO 文件，然后将镜像写入您正在使用的外部 USB 盘。将外部 USB 盘插入到将要运行 Kali Linux 的机器上。确保您在启动系统之前将 USB 盘插入系统。

### 设置驱动器
您需要遵循的下一步是设置驱动器、对其进行加密和分区。将弹出一个对话框，要求您选择安装所需的分区类型。选择“引导式使用整个磁盘”（`Guided-Use Entire Disk`）以获得最佳性能。与仅对 `/home` 目录加密相比，这也有助于对整个 USB 盘进行完全加密。请始终记住，在渗透测试时，Kali Linux 的工具会将所有数据存储在主目录（`home directory`）之外的各种其他地方。

接下来的屏幕将要求您选择要安装 Kali Linux 的磁盘。此时，请确保您选择的是用于安装 Kali Linux 的目标 USB 盘，而不是系统的任何本地驱动器。如果您选择了任何本地驱动器，将删除该驱动器上的操作系统。选择 USB 盘后，点击“继续”。

- 下一个窗口将询问您如何对 USB 盘进行分区。选择“所有文件分区”（`All Files on one partition`）并点击“继续”。
- 接下来，系统将要求您保存所有分区信息，然后开始分区过程。当您选择继续时，USB 盘上的所有数据将被擦除。因此，在点击继续之前，请选择“是”。
- 磁盘加密过程将与分区过程同时开始。驱动器先被完全擦除然后进行加密。整个过程将需要一段时间。如果您使用 64 GB 的 USB 盘，加密将需要 30 分钟。如果您使用 1 TB 的 USB 盘，加密大约需要 10 小时。
- 过程完成后，将要求您提供一个用于加密的口令（`passphrase`）。请确保使用强密码，因为将在启动 Kali Linux 时使用它。
- 确认更改并选择“完成分区”。
- 现在系统将开始分区过程，分区完成后安装系统将启动。
- 系统将询问您是否要使用任何镜像（`Mirror`）。点击“是”，这将选择附近的镜像并有助于加速更新。

将 USB 盘插入机器并启动。在启动过程中，打开启动菜单并选择要使用的 USB 盘。现在将要求输入口令，输入成功后系统将启动。

在开始 Kali Linux 的其他方面之前，您有必要了解一些基础工具和命令。

让我们来看一些基础组件。

相对于市场上的其他操作系统，特别是 Linux，当谈到“命令”（`Command`）一词时，它是用于应用程序或功能的单行指令。然而，这种区别对于终端用户来说意义不大。

这两者的使用方法相同。您需要在您的终端模拟器中输入单词，它将提供输出结果。

# 管理文件系统的 Linux 命令

- **`ls`**: 此命令有助于列出当前目录下的所有内容。当向它提供路径时，它将仅列出特定路径的内容。您需要了解的一些有用选项有 `-l` 和 `-a`，它以长列表格式显示信息，包含更详细的信息，并显示点点隐藏文件。
- **`cd`**: 此命令有助于从当前目录跳转到指定的目录。当您不带任何参数使用此命令时，它将返回主目录。当您使用带有两个点的命令 `cd..` 时，它将带您返回上一级目录；使用带有连字符的命令 `cd –` 则将返回到之前的目录，无论其相对于当前目录的位置如何。
- **`pwd`**: 此命令有助于打印当前目录。当您的提示符不包含此特定信息时，此命令非常有用。它对于获取执行代码时的目录引用的 BASH 编程非常有用。
- **`file`**: 该命令有助于指明文件类型。由于 Linux 系统中的文件并不强制要求具有与系统相关的扩展名即可运行，用户有时难以获取文件的确切类型。此命令有助于解决与 Linux 相关的这类类型问题。
- **`cp`**: 该命令用于复制所有目录和文件。由于此命令默认不递归复制目录，请务必记住在使用命令时配合 `-a` 或 `-r`。`-a` 命令可以在复制的同时帮助保留文件的所有权、模式和时间戳。
- **`mv`**: 它用于重命名或移动目录和文件。重命名和移动可以被视为单一操作，重命名仅仅是将一个单个文件以不同的名称移动到相同的位置。
- **`rm`**: `rm` 命令用于删除目录和文件。这是一个非常基础的命令，你需要它，因为没有它你无法移除任何杂物。然而，在使用此命令时必须格外小心，因为它会永久删除文件和目录。与其他命令不同，此命令甚至不会将删除的文件和目录存储在其他地方以便日后找回。一旦删除，就永远消失了。因此，在这种情况下，配合命令使用 `-r` 开关是非常重要的。
- **`ln`**: 此命令用于在文件之间创建符号链接或硬链接。软链接（符号链接）类似于 Windows 的快捷方式，提供了一种访问任何特定文件夹或文件的非常方便的方法。
- **`chmod`**: 它有助于更改用户的权限。权限包括对文件的写入、查看和执行。任何用户都可以更改其拥有文件的用户权限。
- **`chown`**: 该命令用于更改文件的所有权。只有 `root` 用户（`root`）才能使用此命令并更改文件所有权。为了递归更改目录内所有文件的所有权，你可以使用带有 `-R` 参数的命令。
- **`find`**: 此命令用于在整个文件系统中搜索特定的目录或文件。此命令本质上非常强大，不仅是因为它具有搜索能力，还因为它允许用户在匹配或不匹配的文件上执行任何任意形式的命令。
- **`locate`**: 与 `find` 相反，`locate` 命令通过数据库搜索文件名的模式。这种数据库形式由整个文件系统的快照组成。
- **`du`**: `du` 命令用于显示目录或文件的大小。在各种可用选项中，`--s` 提供摘要而非完整列表，`-h` 将报告的大小转换为更符合人类阅读习惯的格式，`--d` 则有助于控制目录的递归深度。
- **`df`**: 此命令用于显示磁盘的使用情况。该命令的默认输出列出了每一个文件系统，报告它们的大小以及已用空间和可用空间。你可以在此命令上添加 `-h` 以获取更符合人类阅读习惯的格式报告。
- **`dd`**: 该命令有助于根据手册转换和复制特定文件。你需要为此命令提供源和目的地，它将分别复制文件。
- **`mount/unmount`**: 这对命令执行文件系统的挂载和卸载功能。这一系列操作范围可以从 USB 闪盘到 ISO 镜像。
- **`more/less`**: 这两个命令的功能非常相似，允许用户按屏幕显示量分块查看文本。假设某些命令（如用于文件的 `cat`）产生了非常庞大的输出，而模拟器需要一些时间来滚动整个文本。当你使用这些命令中的任一个时，现在可以轻松地滚动文本了。与 `more` 相比，`less` 更为现代，因此现在不再使用 `more`。
- **`head/tail`**: 这也是一对命令，但它们都有各自的用途。`head` 命令有助于输出文件从第一行开始的内容，`tail` 命令通过提供任何文件最后一行的内容来提供帮助。默认输出行数
- **`grep`**: 此命令通过在文本中搜索模式来提供帮助。它可以是正则表达式也可以是普通字符串。它还可以打印匹配或不匹配的行。
- **`sort`**: 此命令用于根据标准对行进行排序。此命令可以使用的有用开关有 `-n`（数字）和 `-r`（降序）。
