以下是使用 `chmod` 配合数值的示例：

## 表 2-7

| `chmod` 命令 | 说明 |
|---|---|
| `chmod 754 hello.txt` | 所有者拥有所有权限，组具有读取和执行权限，其他用户具有读取权限。 |
| `chmod 777 hello.txt` | 所有用户（用户、组和其他用户）均获得所有权限。 |

这些命令更改分配给文件或目录的所有者或组。

作为 `root` 用户，你可以使用以下语法通过 `chown` 命令更改文件的用户和组所属关系：

```
chown new_user.new_group file
```
