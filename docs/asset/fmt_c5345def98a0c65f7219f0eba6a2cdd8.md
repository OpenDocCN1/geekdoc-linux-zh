# 通用降级与活动降级

你可能已经注意到视口配置对话框显示了两个具有相同设置的组。通用降级（General Degradation）组影响非活动视口，而活动降级（Active Degradation）组影响活动视口。

如果你想牺牲细节来获得更平滑的播放，可以使用边界框（Bounding Box）设置。边界框是最快的显示模式，仅适用于具有数百万多边形的复杂场景。正如你所看到的，这些选项提供了预览动画的不同方式。这些工具将帮助你完善动画。
