## 分区标签：e2label

Linux 可以在硬硬盘分区上为 ext2 和 ext3 文件系统使用文件系统标签。因此，在所示的 `/etc/fstab` 文件中，第一个条目使用标签作为其设备名称，所示。在这种情况下，标签是斜杠 `/`，表示根分区。你可以使用 `e2label` 更改此设备的标签，但务必更改其在 `/etc/fstab` 中的条目。

```
LABEL=/ /  ext3 defaults 0 1
```
