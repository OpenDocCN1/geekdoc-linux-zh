
# 第5章 HP-UX性能工具简介

## netstat

### 选项

- `-a` 显示所有套 和接口。
- `-A` 显示所有网络接口的统计数据。
- `-b` 显示路由表。
- `-c` 显示连接。
- `-d` 显示内核统计数据。
- `-e` 显示以太网统计数据。
- `-f` 显示族类型。
- `-g` 显示组统计数据。
- `-h` 显示主机统计数据。
- `-i` 显示接口统计数据。
- `-j` 显示统计数据。
- `-m` 显示内存统计数据。
- `-n` 显示地址。
- `-o` 显示输出统计数据。
- `-p` 显示协议统计数据。
- `-q` 显示队列统计数据。
- `-r` 显示路由表。
- `-s` 显示所有协议的统计数据。
- `-u` 显示 UDP 统计数据。
- `-v` 显示额外信息。
- `-x` 显示扩展统计数据。

### 示例

- 列出所有套：

```
netstat -a
```

- 显示路由表：

```
netstat -r
```

- 显示接口统计：

```
netstat -i
```

- 显示协议统计：

```
netstat -p
```

### 描述

被动套状态显示本地和远程地址、发送和接收队列大小（字节）、协议以及协议的内部状态。地址格式为 `host.port`，如果套接字地址的主机部分为 `0`，则为 `network.port`。如果已知，主机地址和网络地址将使用 `gethostbyname(3N)` 和 `getbyname(3N)` 以符号形式显示。如果地址的符号未知，或者指定了 `-n` 选项，则地址将以该地址族的数值形式显示。有关互联网“点点格式”的更多信息，请参阅 `inet(3N)`。未指定的或“通配符”地址显示为星号（`*`）。

界面显示了关于转发的数据包、错误和连接的累积统计表。还会显示接口的网络地址和最大传输单元（MTU）。当指定了间隔时，它将显示相关接口的运行计数。此显示包含一列主接口（自动配置期间找到的第一个接口）和一列所有接口的摘要。要将主接口替换为另一个接口，请使用包含自系统上次重启以来摘要信息的命令行。随后的输出行显示的是在前一间隔内的累积值。

路由表指示了可用路由及其状态。每条路由由一个目的主机或网络、掩码以及转发数据包时使用的网关组成。`Flags` 字段显示路由是否可用（`U`）、路由是否到网关（`G`）、路由是否为主机或网络（带有 `H`）、路由是否为动态创建（`D`）或通过路径 MTU 发现重定向，以及网关路由是否被修改（`M`），或由于缺少及时的 ARP 响应而翻倍（`?`）。

`Netmask` 字段显示应用到待转发数据包 IP 地址的掩码。结果将与路由项中的目的地址进行比较。如果相同，则该路由是路由此 IP 数据包的候选之一。如果有多个候选，将选择最长掩码字段（从左侧位开始的连续 1）（参见 `routing(7)`）。

`Gateway` 字段显示到达目的地的直接网关地址。如果目的地位于直接连接的网络上，它可以是输出接口的地址。

`Refs` 字段显示该路由当前活动使用的次数。面向连接的协议通常在连接期间运行在单一路由上，而无连接协议通常在每条消息之前获取路由。该字段显示使用该路由发送的数据包计数。`Interface` 字段识别用于该路由的接口。

`Pmtu` 和 `PTime` 字段仅适用于主机路由。默认路由的 `Pmtu` 字段与用于路由的接口 MTU 相同。如果使用静态 MTU 值创建路由，路由字段包含单词 `perm`，`Pmtu` 值将永久覆盖接口 MTU。如果路由是动态创建（`Flags` 字段中的 `D`），则相应 `PmtTime` 字段中的值是在重新测量 `Pmtu` 之前的剩余分钟数，系统在发生变化时会重新发现该路由的 PMTU。当 PMTU 与接口的 MTU 相同时，`PmtTime` 字段为空。`Pmtu` 字段中的星号（`*`）表示用户已禁用该路由的 PMTU 发现。

## ps

### 名称

`ps` - 报告进程状态

`ps(1)`

### 用法

`ps [-aadeflP] [-g grplist] [-p proclist] [-R prmgrplist] [-t termlist] [-u uidlist]`

### XPG4 用法

`ps [-aAcdefHP] [-C cmdlist] [-g grplist] [-G gidlist] [-n namelist] [-o format] [-p proclist] [-R prmgrplist] [-s sidlist] [-t termlist] [-u uidlist] [-U uidlist]`

### 描述

`ps` 打印所选进程的信息。使用选项指定选择哪些进程以及打印关于它们的哪些信息。

### 进程选择选项

使用以下选项选择选择哪些进程。

注意：如果选项在默认（标准 HP-UX）和 XPG4 环境中均使用，则此处提供的描述遵循默认行为。请参考“外部影响”下的 `UNIX5` 变量以获取有关 XPG4 行为的附加信息。

- `(无)` 选择与当前终端关联的进程。

- `-A`（仅限 XPG4.）选择所有进程。（`-e` 的同义词）。

- `-a` 选择所有进程组组进程和与终端未关联的进程。

- `-C cmdlist`（仅限 XPG4.）选择执行 `cmdlist` 中给定基名命令的进程。

- `-d` 选择除进程组组以外的所有进程。

- `-e` 选择所有进程。

- `-g grplist` 选择所有进程组组在 `grplist` 中的进程。

- `-G gidlist`（仅限 XPG4.）选择真实组 ID 数字或组名在 `gidlist` 中指定的进程。

- `-n namelist`（仅限 XPG4.）此选项被忽略；允许其存在。

- `-p proclist`：选择指定 ID 的进程。

- `-R prmgrplist`：选择指定资源组的进程。

- `-s sidlist`：选择指定会话 ID 的进程。

- `-t termlist`：选择指定终端的进程。

- `-u uidlist`：选择指定用户 ID 的进程。

- `-U uidlist`：选择指定用户 ID 的进程。

### 输出字段

#### `process` 字段

`process` 列的可能取值：

- `0` 已交换到内存（Swapped）
- `1` 在核心内存中（In core）
- `2` 系统进程
- `4` 锁定在核心中（例如用于物理 I/O）
- `10` 正在被另一个进程跟踪
- `20` 另一个跟踪标记

此列的默认标题为 `F`。

- `intpri`：内核内部存储的进程优先级。提供此列是为了向后兼容，不建议使用。

- `gid`：有效进程所有者的组 ID 号。

- `group`：有效进程所有者的组名。

- `nice`：`nice` 值；用于优先级计算（详见 `nice(1)`）。此列的默认标题为 `N`。

- `pcpu`：该进程在最后一个调度周期内占用的 CPU 时间的百分比。此列的默认标题为 `%CPU`。

- `pgid`：该进程所属进程组的组 ID 号。

- `pid`：进程的 ID 号。

- `ppid`：父进程的 ID 号。

- `pri`：进程的优先级。该值的含义取决于进程调度类；参见上文的 `cls` 和 `rtsched(1)`。

- `prmid`：PRM 进程资源组 ID 号。

- `prmgrp`：PRM 进程资源组名。

- `rgid`：真实进程所有者的组 ID 号。

- `rgroup`：真实进程所有者的组名。

- `ruid`：真实进程所有者的用户 ID 号。

- `ruser`：真实进程所有者的登录名。

- `sid`：该进程所属会话的 ID 号。

- `state`：进程的状态：

    - `0` 不存在（Nonexistent）
    - `S` 睡眠（Sleeping）
    - `W` 等待（Waiting）
    - `R` 运行（Running）
    - `I` 中间
    - `Z` 终止（Terminated）
    - `T` 停止（Stopped）
    - `X` 增长（Growing）

此列的默认标题为 `S`。

- `stime`：进程的启动时间。如果经过时间超过 24 小时，则显示启动日期。

- `sz`：进程核心映像的物理页大小，包括文本、数据和堆栈空间。物理页大小由头文件 `<unistd.h>` 中的 `SC_PAGE SIZE` 定义（详见 `sysconf(2)` 和 `unlist(5)`）。

- `time`：进程的累计执行时间。

- `tty`：进程的控制终端。如果指定了 `-o`，此列的默认标题为 `TT`，否则为 `TTY`。

- `uid`：有效进程所有者的 ID 号。

- `user`：进程所有者的登录名。

- `vsz`：进程核心映像的字节（1024 字节）大小。参见上文的 `colzn`。
