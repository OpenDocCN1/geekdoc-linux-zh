# 描述 Linux 内核架构

Linux 内核架构提供以下组件：

- `SCI`（系统调用接口）：定义操作系统的所有服务。该接口取决于架构，如处理器家族内部。
- 进程管理：处理进程执行。内核中的进程被称为线程，代表处理器的个体虚拟化（线程头、数据、栈和 CPU 寄存器）。在用户空间中使用进程；尽管 Linux 实现将进程和线程视为是相同的。内核提供应用程序编程接口（API）来创建新进程（`fork`、`exec` 或可移植操作系统接口 `[POSIX]`）、停止新进程（`kill`、`exit`）以及开发通信和同步。
- 虚拟文件系统：为文件系统提供通用抽象。虚拟文件系统（`VFS`）是内核的一个有趣方面，因为它在内核和文件系统之间提供了一个切换层。
- 内存管理：以 KB 为基础。硬件资源（如 CPU）使用虚拟内存来提高性能。内存按页进行管理（大多数架构的大小为 4 KB）。Linux 管理可用内存以及单独分配给硬件设备的内存。
- 网络栈：设计上遵循层次模型。它由多个层组成，如数据链路层和物理层，它们负责将数据传输到网络。互联网协议（`IP`）是位于传输协议（最常用传输控制协议，或 `TCP`）之下的核心网络协议。该层的数据称为包，并通过 `IP` 将数据传输到传输层。`TCP` 层之上是 `sockets` 层，通过 `SCI` 调用。
- `Arch`：展示内核的架构。`Arch` 定义了内核中取决于架构的部分，包含多个特定于架构的子目录。你可以在 `linux/arch` 中找到架构相关代码。
- 设备驱动：Linux 内核中包含大量代码，使特定的硬件设备可用。Linux 代码树提供了一个驱动子目录，进一步划分为各种设备，如蓝牙、`I2C` 和串口。你可以在 `linux/drivers` 中找到驱动源。

## 描述内核数据结构

内核数据结构提供了安装在 Linux 内核中的程序结构信息。它存在于操作系统的物理内存中，仅供内核及其子系统访问。该数据结构列出了 Linux 操作系统中新创建程序的条目。它还包含了系统使用的数据和文件。内核数据结构使用以下数据结构将其数据与其他数据结构连接起来：

- 链表
- 哈希表
- 抽象接口

让我们详细学习这些结构：

### 链表

链表将内核数据结构中的数据连接起来。在链表中，根指针包含列表中第一个数据结构的地址，每个随后的后的数据结构都包含一个指向列表中下一个元素的指针。最后一个元素的下一个指针将为 `NULL`，以表示列表的结束。

### 哈希表

哈希表是指针的数组或向量。它简单来说是出现在内存中连续出现的一组数据。例如，数组通过索引进行访问，而索引是设置在内存中的。哈希表包含有关结构的信息，并加快了对公共需要数据结构的访问速度。Linux 中的哈希表通常用于实现缓存。缓存提供了对特定区域可用信息的访问。数据结构被添加到缓存并保留，因为内核经常访问它们。缓存的缺点是，如果你在缓存中找到了该数据结构，可以将其添加到哈希表中。如果缓存中无法找到该数据结构，则需要搜索所有相关的数据结构。一旦找到该数据结构，就会将其添加到哈希表中。当新条目被添加到数据结构时，旧的缓存会被丢弃。Linux 决定丢弃哪个数据结构，因为一旦数据结构被丢弃，就无法恢复。

### 抽象接口

在 Linux 中，以良好方式运行的例程和结构集合被称为抽象接口。例如，所有网络设备驱动程序必须提供某些例程来对特定结构进行操作，这些例程被称为抽象接口。可以存在使用特定代码低层服务（接口）的通用代码。网络层是通用的，并由符合标准接口的设备特定代码支持。

在前面的节中，你已经学习了内核的数据结构。现在让我们学习内核模块。

## 介绍内核模块

内核指的是内核模块，它们在初始化时加载到内核中。操作系统只加载对系统至关重要的内核模块。GNU 统一引导加载程序 (GRUB) 将启动时所需的动态模块加载到内存磁盘 (`initrd`) 中。你可能还会加载完成其他任务所需的其他模块，例如管理音频和视频设备的内核模块。你可以在 `/lib/modules/` 目录下找到额外的内核模块。内核模块也被称为第三方驱动程序，通常用于为新硬件、文件系统添加支持并添加系统调用。当内核模块不再需要时，可以卸载它以释放内存。

## 描述内核模块工具

内核模块工具是指在 Linux 操作系统中映射内核模块的命令组。如果你安装了 `modutils` 包，就可以使用内核模块工具。内核模块工具提供了几个命令，例如 `insmod`，用于安装内核模块。

内核模块工具提供以下命令：

- `depmod`: 处理可加载内核模块的依赖请求
- `insmod`: 在内核中安装可加载的模块
- `lsmod`: 列出已加载的模块
- `modprobe`: 显示对可加载模块的高级处理
- `rmod`: 卸载可加载的模块

让我们学习如何加载和卸载内核模块。

## 加载和卸载内核模块

当 Linux 操作系统中的内核初始化时，内核模块会自动加载。少数对运行内核至关重要的模块直接包含在内核中。这些模块执行各种任务，例如减少内核中设备驱动程序不必要的内存需求，并允许在不重启系统的情况下多次使用它们。在 Linux 中，你可以使用 `modprobe` 命令加载和卸载模块。在 Linux 操作系统的终端模式下执行以下命令加载内核模块：

```bash
root@localhost ~# insmod bluetooth
```

执行以下命令卸载已安装的模块：

```bash
root@localhost ~# modprobe -r bluetooth
```

`lsmod` 命令提供了所有已加载模块的列表及其相应的大小和用途。例如，要查看当前安装的模块，输入以下命令：

```bash
root@localhost ~# lsmod
```

前面的命令显示如下输出：

```
bluetooth 48608 5 bnepsco,12cap
```
