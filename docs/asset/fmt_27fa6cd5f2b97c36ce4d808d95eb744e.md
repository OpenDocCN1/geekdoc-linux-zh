### 描述 (Description)

`graph` 命令绘制由 `gprof` 生成的调用信息图。图可以输出到屏幕或文件。图由节点和边组成。每个节点代表一个函数，每条边代表函数之间的调用。边的厚度与调用次数或在函数中花费的时间成正比。

可以使用各种选项对图进行自定义。您可以更改标签、颜色和布局。图还可以以不同的格式输出，例如 PostScript 或 ASCII 艺术。图是识别程序瓶颈的有用工具。

## grep — 在文件中搜索模式

### 语法概要

```
/usr/bin/grep [-bchilnsvw] limited-regular-expression [filename...]
```

```
/usr/xpg4/bin/grep [-E | -F] [-c | -1 | -q] [-bhinsvwx] -e pattern-list [-f pattern-file] ... [file]
```

```
/usr/xpg4/bin/grep [-E | -F] [-c | -1 | -q] [-bhinsvwx] -e pattern-list -f pattern-file [file...]
```

```
/usr/xpg4/bin/grep [-E | -F] [-c | -1 | -q] [-bhinsvwx] pattern [file...]
```

## 描述

`grep` 命令在一个或多个文件中搜索模式，并打印包含该模式的所有行。`grep`（代表 global regular expression and print，即全局正则表达式并打印）使用复杂的非确定性算法。

> 注意 — 在 `pattern-list` 中使用字符 `$` `*` `^` `|` `(` `)` 和 `\` 要小心，因为它们对 shell 也有含义。最安全的方法是用单引号 `'...'` 将整个 `pattern-list` 包裹起来。

如果你没有指定文件，`grep` 将假设使用标准输入。通常情况下，找到的每行都会被复制到标准输出。如果有多个输入文件，则会在每行之前打印文件名。

### /usr/bin/grep

`/usr/bin/grep` 命令使用受限正则表达式（如 `regexp(5)` 手册页中描述的正则表达式）来匹配模式。

行的限制仅取决于可用虚拟内存的大小。对于嵌入空字节的行，`grep` 仅匹配到第一个空字节；如果匹配成功，`grep` 将打印整行。

### /usr/xpg4/bin/grep

`/usr/xpg4/bin/grep` 是 `/usr/bin/grep` 命令的 POSIX 标准版本。请参见 `standards(5)`。

选项 `-E` 和 `-F` 影响 `/usr/xpg4/bin/grep` 解释 `pattern-list` 的方式。如果你指定 `-E`，`/usr/xpg4/bin/grep` 将 `pattern-list` 解释为正则表达式。如果你指定 `-F`，`grep` 将 `pattern-list` 解释为固定字符串。如果你两者都未指定，`grep` 将 `pattern-list` 解释为基本正则表达式，如 `regex(5)` 手册页所述。

如果输入文件包含长度超过 `LINE_MAX` 的行或包含二进制数据，则结果是不指定的。`LINE_MAX` 定义在 `/usr/include/limits.a` 中。

## 选项

`/usr/bin/grep` 和 `/usr/xpg4/bin/grep` 都支持以下选项：

- `-b` 在每行前加上找到该行所在的块编号。此选项对于通过上下文定位块非常有用（第一个块为 0）。
- `-c` 打印包含模式的行数。
- `-h` 防止包含匹配行的文件名被追加到该行之后。当搜索多个文件时。
- `-i` 忽略比较过程中的大小写区别。
- `-l` 打印包含匹配行的文件名，用换行符分隔。当模式出现多次时，不要重复打印文件名。
- `-n` 在文件的每行前加上其在文件中的行号（第一行是 1）。
- `-s` 抑制关于不存在或不可读文件的错误信息。
- `-v` 打印除包含模式以外的所有行。
- `-w` 如果表达式被 `\<` 和 `\>` 包围，则将其作为单词进行搜索。

以下选项仅由 `/usr/xpg4/bin/grep` 支持：

- `-e pattern-list` 指定在搜索输入时使用的一个或多个模式。用换行符分隔 `pattern-list` 中的模式。除非你指定了 `-E` 或 `-F` 选项（这会将每个模式视为基本正则表达式），否则你可以通过两个相邻的换行符指定一个空模式。`grep` 接受多个 `-e` 和 `-f` 选项。在匹配行时会使用所有指定的模式，评估顺序不指定。
- `-E` 使用全正则表达式进行匹配。将指定的每个模式视为一个全正则表达式。如果任何整个正则表达式模式匹配输入行，则该行被匹配。空正则表达式匹配每一行。按照 `regex(5)` 手册页所述将每个模式解释为全正则表达式，但 `\(` 和 `\)` 除外，并包括：
    * 完整正则表达式后紧跟 `+`，表示匹配该完整正则表达式的一次或多次出现。
    * 完整正则表达式后紧跟 `?`，表示匹配该完整正则表达式的 0 次 1 次。
    * 用 `|` 或换行符分隔的全正则表达式，匹配字符串。
- `-f pattern-file` 从文件中读取模式。
- `-F` 使用固定字符串进行匹配。
- `-q` 静默模式，不输出任何内容。
- `-v` 反向匹配，排除匹配行。
- `-w` 仅匹配单词。
- `-x` 仅匹配整行。
