
## 2.4 我的硬件在 Linux 下能运行吗？

并不是所有的 PC 硬件都受 Linux 支持，但大多数都支持，特别是那些标准且旧的型号。这些适用于`SCSI`、`CDROM`、刻录 CD 以及可写 CD（`CD-R`和`CD-RW`）、显卡、鼠标、打印机、调制调器、网卡、扫描仪、`Iomega`设备等。

最明显的例外是所谓的`Winnows`（即`MS Windows`窗口，也称为“软件调制调器”）。避免使用这些——它们比大多数产品便宜一点，但功能被阉割了（处理由主 CPU 而不是调制调器完成），而且你几乎不可能在 Linux 上运行`Winnow`（关于`Winnows`的更多信息，请参阅`http://www.iter.org/gromitkc/winennom.html`）。如果是购买的外部调制调器则不是“`Winnows`”（外部调制调器更贵，但它们不会消耗 PC 电源，易于在电脑间携带，外观更好，并且能显示调制调器活动）。关于调制调器的其他需要考虑的点：不支持。见下——

另一个潜在问题领域是显卡。如果你有一块“尖端”的 3D 或罕见的显卡，你可能需要检查其兼容性`http://www.Xfree86.org`。驱动程序的`Zip`包也是很需要的。

我不会将`Linux TWAIN`（即没有趣名字的技术，这里没开玩笑）视为扫描仪，无论制造商声称其具有兼容性。

所以短答案是肯定的，极有可能，你的标准 PC 将没有任何问题地运行 Linux。在购买 Linux 时你可能不知道情况，所以可能确保问题的方法是在你现有的硬件上尝试安装。如果你想检查硬件是否受支持，可以查看`http://hardware.redhat.com/hw/page2.html`和`http://metalab.anc.edu/LDP/Hardware-HWTO.html`的 Linux 硬件兼容列表。

在购买新设备时，我会在上述列表中检查其 Linux 兼容性。你也可以询问硬件是否受支持，这通常没问题。但要保留意见——太多公司的销售人员/技术支持能力平庸。在购买新电脑时，我会考虑预装了 Linux 的系统。许多供应商（特别是大型供应商）提供带 Linux 的系统，但很多公司都提供。你也可以从较小的供应商那里获得预装 Linux 的系统。

如果你是一个喜欢冒险的人，我建议不要关注上述顾虑，硬件可以工作的概率是 90-100%。

如果某项硬件（显然）在你当前的 Linux 发行版中不受支持，不要放弃。检查以下情况：

(1) 它受支持，但你不知道如何设置它。（解决方案：留在 Linux 中呆几周，然后你可能会对你的系统工作原理有所了解，然后你可能就能设置它了）。

(2) 你必须通过更复杂的设置来支持该硬件（也许是一些晦涩的命令或内核编译，这并没有看起来那么困难）。

(3) 一个更新过的（不同的？）发行版已经“开箱即用”地支持它（你可以花 1.99 美元购买）。

(4) 网上已经有了升级程序，如果你能找到它，下载它并弄清楚如何安装它。升级将在下个月可用——Linux 的发展真的非常快！

### 安装 Linux 之前

另一个可能出现问题的领域是笔记本电脑，因为笔记本通常包含非常不规的硬件，需要原始厂商的支持。请参阅`http://www.linux.org/hardware/laptop.htm`获取安装帮助。在 Linux 兼容性方面，`IBM`笔记本电脑似乎是一个安全的选择。要购买 Linux 笔记本电脑，你也可以尝试`http://www.linuxcertified.com/linux_laptops.html`

## 2.5 我如何下载 Linux？

为自己省点吧，不要下载 Linux。改为买一张安装 CD。Linux 可以从互联网下载，但它是一个巨大且复杂的操作系统。下载可能需要几个小时或几天时间，而且你可能会遇到问题和挫败，例如下载的文件错误。

如果你有快速的互联网连接（绝对不是 56k 调制调器，但可能是电缆调制调器）并且你不是完全的新手，Linux 下载对你来说可能是一个选项。访问`http://www.linuxiso.org/ready-to-burn`下载所选 Linux 发行版的 CD 镜像（`ISO`格式）以避免问题，在购买之前（在 Linux 上）检查下载的`MD5`镜像。

`md5 sum the_file`这个命令将花费一些时间（几分钟？）来检查文件 (640 kByte) 镜像。`MS Windows`不包含检查`md5sum`的实用程序，但可以免费下载此类实用程序。

工具`md5`会生成一个 32 字符的字符串，它取决于文件内容。如果文件中即使只有一个比特位发生了变化，上面的命令就会生成一个签名字符串（“`md5 sum`”），将此字符串与你下载文件的网页上列出的字符串进行比较。请注意，数据在大规模下载过程中可能会损坏，因此检查字符串真的是非常好的主意。

## 2.7 安装

### 该怎么办？

如果你不知道如何进入 BIOS 设置，请阅读此段。可以通过在正确的时刻按下键进入 BIOS 设置。大多数公共 BIOS 使用的按键组合：

| 制造商 | 按键组合 |
| --- | --- |
| `Acer` 笔记本 | `Del` |
| `Compac` | 在方框出现后按 `F10` |
| `Dell` | `Ctrl+Alt+Esc` |
| `IBM 535` | 在方框出现时按 `F1` |
| `IBM PS/2` | `Ctrl+Alt+Del`，然后按 `Ctrl+Alt+Ins` |
| 某些地区的 `Packlord` | `F1` 或 `F2` |

如果你的电脑无法从光驱启动，请在`DOS`或`MS Windows`下制作启动盘。（你必须进入“关机”并“重启到 `MS-DOS` 模式”，而不仅仅运行`DOS`）。

重要的是磁盘程序不会检查软盘是否写入正确。此外，不要指望格式化损坏的软盘不会有问题。如果我是你，我会一次制作两个或三个磁盘——你会惊讶于自己需要多少个磁盘。如果你的安装磁盘无法启动，再制作一个——它绝对应该启动。

这里是命令。制作启动盘：

```
F:\dosutils\rawwrite.exe -f F:\install.img -a -n
rawwrite.exe -f F:\support.img -a -n
```

假设光驱在`DOS`中是`"F:"`。

### 安装 LINUX 之前

上述命令运行`"rewrite"`工具，并在选项`"-f"`之后指定输入文件（“磁盘镜像”），以及目标驱动器（在选项`"-d"`之后），并抑制插入软盘的提示（`"-n"`）。你可能会发现不带任何参数运行更简单——它将交互式地提示你输入镜像（如上述命令所示选择文件名）和目标驱动器。

来自 Linux，你可以进行低级格式化，可以在 Linux 下使用以下命令进行格式化：

```
ddformat /dev/fdHI440
mount /dev/cdrom
mount The Red CDROM:
cd /mnt/cdrom/
```

```
dd if=boot.img of=/dev/fd0
"dd" 命令复制文件。上述命令指定输入文件 ("if") 为 "boot.img"，输出文件 ("of") 为 /dev/fd0，这是第一个软盘驱动器，即编号为零的软盘驱动器
```

要验证磁盘镜像已正确写入软盘，可以使用以下方法之一：

+   [方法 1]

`cmp boot.img /dev/fd0`

+   [方法 2]

`diff boot.img /dev/fd0`

+   [方法 3]

`mdsum boot.img /dev/fd0`

`mdsum /dev/fd0`

[比较两个返回的 md5 校验是否一致]

+   [方法 4]

`sum boot.img`

`sum /dev/fd0`

[比较两个返回的和是否一致]

## 2.8 安装前我需要阅读什么？

你想要了解你的硬件：你拥有多少个以及多大尺寸驱动器，每个驱动器上所有分区的类型、数量、顺序和大小，哪一个是`DOS/Windows`启动分区（如果你计划双系统），你拥有什么种类型的鼠标，什么类型的显卡以及多少内存，什么显示器（同步频率）。
