
```cpp

```

正旋转为逆时针。0 度点在右侧。起始和结束角度用相对术语的。也就是说，起始角度指定从零点开始绘制的距离，结束角度指定从起始角度到绘制结束的距离。这两个数字都可以正负。如果起始角度小于结束角度，绘制按正方向（逆时针）进行。如果起始角度大于结束角度，绘制按负方向（顺时针）进行。
