
### kernel
内核是任何操作系统的核心。它加载设备驱动程序。你可以重新编译 Linux 内核以获取额外的驱动程序、加快加载速度并减少所需的内存。

### kernel module
内核模块是插拔式驱动程序，可以根据需要加载和卸载到内核中。某些加载的内核模块可以通过 `lsmod` 命令显示。

### Kernel-Based Virtual Machine (KVM)
基于内核的虚拟机是 Linux 原生虚拟化技术之一，类似于 Xen。

### Kickstart
Kickstart 是由 Red Hat 开发的自动化安装系统，允许你在安装过程中提供所需的答案。配置好后，Kickstart 软盘可以允许你启动计算机并从网络源自动安装 Ubuntu Linux。

### Kubuntu
Ubuntu Linux 的一个版本，将 KDE 桌面作为默认 GUI。

### LAMP
LAMP 是 Ubuntu Server 的安装选项，用于安装 Linux、Apache、MySQL 和 PHP。

### Launchpad
Launchpad 是 Canonical 用于托管源代码项目、错误跟踪等更多功能的专有平台。

### LDP (Linux Documentation Project)
LDP 是一项为 Linux 操作系统各个方面制作可靠文档的全球性工作。其工作可以在 `www.tldp.org` 在线查看。

### lftp
`lftp` 命令启动一个与 `ftp` 命令客户端相比具有中等灵活性的 FTP 命令行客户端。

### Lightweight Directory Access Protocol (LDAP)
轻量级目录访问协议允许在中央网络服务器上进行认证信息存储。

### LILO (Linux Loader)
一种适用于 Ubuntu Linux 的旧启动加载程序；GRUB 的替代方案。

### Line Print Daemon (LPD)
行打印守护进程 (`LPD`) 服务是一种仍然适用于 Ubuntu Linux 的旧打印服务。

### Line Printer, Next Generation (LPRng)
下一代行打印机 (`LPRng`) 是一种仍然适用于 Ubuntu Linux 的旧打印服务。

### Linux Terminal Server Project (LTSP)
Linux 终端服务器项目 (`LTSP`) 支持创建连接到 Ubuntu Linux 服务器的无盘客户端。

### LinuxMint
Ubuntu Linux 的派生版本，“侧重于更优雅的环境”。

### Linux Terminal Server Project
一种适用于 Ubuntu Server 的系统，用于支持瘦客户端。

### Live CD
一种直接从 CD/DVD 驱动器启动的计算机操作系统，无需安装在硬盘上。

### localization
本地化根据语言、方言、自定义以及特定国家格式（如货币、字符集等）来定制 Linux 系统的方法；在 UCP 课程中拼写为 localisation。

### locale
`locale` 指定系统的当前本地化设置。`locale -a` 命令返回可用的默认语言选项。

### locate
`locate` 命令搜索文件和目录的默认数据库。该数据库通过 `/etc/cron.daily/` 目录下的 `mlocate` 或 `slocate` 脚本每天刷新。

### Long Term Support (LTS)
长期支持 Ubuntu Linux 的常规版本支持期为 18 个月。长期支持 (`LTS`) 版本在桌面端支持三年，在服务器端支持五年。

### logical extent (LE)
逻辑区 (`LE`) 是对应于物理区 (`PE`) 的磁盘空间块。

### logical volume (LV)
逻辑卷 (`LV`) 由一组逻辑区 (`LEs`) 组成。

### Logical Volume Management (LVM)
逻辑卷管理 (`LVM`) 允许你在多个分区上设置文件系统。也称为逻辑卷管理器。

### Ipadmin
`/etc/group` 中的 `Ipadmin` 组员被配置为 Ubuntu Linux 中 CUPS 实现的默认打印管理员。

### Ipc
你可以使用 `lpc` 命令扫描所有已配置的打印设备和队列。

### Ipinfo
你可以使用 `lpinfo -v` 命令显示可用的打印设备。

### Lpq
你可以使用 `lpq` 命令查看仍在进行打印作业。

### Ipr
你可以使用 `ipr` 命令发送打印请求。

### Iprm
你可以使用 `lprm` 命令从队列中删除打印作业。

### Isattr
`Isattr` 命令列出文件属性。

### Ihal
`Ihal` 命令列出检测到的硬件。

### Ismod
`Ismod` 命令列出已安装的内核模块。

### Lspci
`LSP` 命令列出检测到的 PCI 设备及相关设置。`lspci -v` 和 `lspci -vv` 命令提供每个硬件设备的详细数据。

### Lspcmcia
`Lspcmcia` 命令列出检测到的 PC Card (`PCMCIA`) 设备。

### Isusb
`Isusb` 命令列出检测到的 USB 总线和设备。

### Itsp-build-client
`Itsp-build-client` 命令在 LTSP 服务器上构建 LTSP 客户端系统所需的文件。

### Ivcreate
`Ivcreate` 命令从指定数量的可用物理区 (`PEs`) 创建逻辑卷 (`LV`)。

### Ivdisplay
`Ivdisplay` 命令指定逻辑卷 (`LVs`) 的当前配置信息。

### Ivextend
`Ivextend` 命令允许增加分配给逻辑卷 (`LV`) 的物理卷 (`PV`) 区域。

### Ivremove
功能上与 `Ivcreate` 命令相反。

### masquerading
伪装技术允许你通过单个公共 IP 地址为局域网上的所有计算机提供 Internet。

### main repository
Ubuntu Linux 主仓库包含 Canonical 支持的开源软件包。

### Malone
Malone 有时被称为 "Bugsy Malone"，是 Launchpad 的错误跟踪器。

### MBR (Master Boot Record)
主引导记录是启动磁盘的第一个扇区。一旦 BIOS 循环完成，它会在启动磁盘的 MBR 上寻找指针，然后查看如 `grub.conf` 等启动加载器配置文件以如何启动操作系统。

### Microsoft Exchange
Microsoft Exchange 服务器是与 Microsoft Outlook 关联的一组套件。Evolution 可以配置连接到 Microsoft Exchange。

### mirror site
镜像站点是存储相同信息的服务器。镜像站点通常用于 Linux 仓库。

### mkfs
`mkfs` 命令可以帮助你格式化新分区的内核系统。多种变体可用，包括 `mkfs.ext3`，用于格式化 ext3。

### mksmbpassword
`mksmbpassword` 命令为 Samba 准备受管理的认证数据库。

### modprobe
你可以使用 `modprobe` 命令控制要安装的设备模块。

### mount
你可以使用 `mount` 命令指定挂载本地或网络分区。

### mount.cifs 和 umount.cifs
`mount.cifs` 和 `umount.cifs` 命令在正确配置的情况下，允许用户通过 Samba 网络挂载共享目录。

### mstforefonts
Ubuntu 的 Microsoft 字体软件包。

### Multiverse repository
Ubuntu Linux Multiverse 仓库包含 Canonical 不支持的软件包。

### Mythuntu
一种基于 Ubuntu 的发行版，整合 MythTV 数字多媒体应用。

### NAT (Network Address Translation)
网络地址转换是一种与 `iptables` 等防火墙命令相关的功能，将局域网内的计算机连接到 Internet 同时隐藏其真实 IP 地址。NAT 修改数据包头。对于返回消息过程相反。与伪装密切相关。

### NFS (Network File System)
NFS 是由 Sun Microsystems 开发的文件共享协议；它是 Linux 和 Unix 计算机网络常用的网络文件。相关的 Ubuntu 服务器是 NFS 内核服务器。

### NIC (Network Interface Card)
网卡将计算机连接到网络。网卡可以是千兆以太网适配器，也可以是电话解调器。

### NIS (Network Information System)
NIS 允许为网络上的 Linux 和 Unix 系统共享一个管理的数据库。

### nisdomainname
`nisdomainname` 命令为 NIS 网络查找并为本地系统分配域名。

### oem-config-prepare
`oem-config-prepare` 命令为原始设备制造商 (`OEM`) 定制 Ubuntu 安装。

### PAM (Pluggable Authentication Modules)
PAM 将进程与单个应用程序分离。PAM 由一组动态加载的库模块组成，配置应用程序在访问前如何验证用户。

### part
是标准的磁盘分区命令工具，允许你修改物理和逻辑磁盘分区布局。使用时要小心，因为更改会立即写入分区表。

### partprobe
你可以使用 `partprobe` 命令在不重启的情况下重新读取最近更改的分区表。

### netstat
`netstat` 命令显示网卡的连接性信息。例如内核存储路由表。
