
| 命令 | 类别 | 描述 |
| :--- | :--- | :--- |
| `list function` | 函数 | 显示函数的行。 |
| `list num,num` | 数字 | 显示行号范围。 |

使用 `print` 命令来显示变量的内容。输入单词 `print` 并在后跟变量名。在下一个示例中，用户显示了 `count` 变量的内容。

```
(gdb) print count
10
```

有时，你可能需要在 `gdb` 会话期间更改变量的值。你可以通过 `set` 操作来实现这一点。输入 `set` 关键字，后跟变量、等号和新值。在下一个示例中，用户将 `count` 变量设置为 41。

```
(gdb) set count = 41
41
```

通过 `where` 命令，你可以显示程序中任何一点被调用的函数名和函数参数。在下一个示例中，用户当前处于 `calc` 函数中。输入 `where` 命令会显示函数 `main` 以及 `calc` 及其参数。

```
(gdb) where
#3 calc(newcost = 2.0) at calc.c:25
#1 main ( ) at main.c:19
#2 0x8000455 in __crt_dummy__ ()
```

你可以获取函数中所有变量和参数的列表。`info locals` 命令将显示当前定义的变量和参数值。在下一个示例中，用户显示了定义的变量。

```
(gdb) info locals
cost = 2
name = "Richard\000\000"
count = 10
count2 = 10
nameptr = 0x8000570 *petersen
countptr = (int *) 0xbffffde
```

## gdb 符号调试器

你可以通过指定行号、行范围或函数来显示源代码行。`list` 命令本身会显示从当前行开始的后续十行。若要显示函数中的行，请在 `list` 命令后跟随函数名。要列出特定行，在 `list` 命令后输入行号。如果你想显示一个行范围，输入 `list` 命令，后跟用逗号分隔的第一行和最后一行。

| 命令 | 功能 |
| :--- | :--- |
| `list 17` | 显示从第17行开始的后续十行。 |
| `list 12,15` | 显示第12行到第15行。 |
| `list calc` | 显示 `calc` 函数的行。 |

在下一个示例中，用户列出了第14到第17行：

```
(gdb) list 14,17
14 cost = 2.00;
15 count = calc (cost);
16 *countptr = count;
17 strcpy (name, "Richard");
```

## 指针

指针有三种用法：指向简单变量的指针、指向结构体的指针以及指向数组的指针。作为指向变量的指针，可以使用此命令显示指针指向的内容：

`print *pointer`

在下一个示例中，用户显示了 `countptr` 指向的变量的内容。

```
(gdb) print *countptr
4
```

当指针持有错误的地址时，会发生很多错误。如果指针本应该指向某个变量，你可能需要比较指针中的地址与变量的地址，以查看它们是否相同。获取变量的地址，要在变量前加一个取地址符号 `&`。当放在变量之前时，`&` 符号变成了地址运算符。在下一个示例中，

用户显示了 `count` 的地址和 `countptr` 的内容，以查看它们是否相同。

```
(gdb) print &count
0x7ffffbcd4
(gdb) print countptr
0x7ffffbcd4
```

指针还用于引用数组。在这种情况下，你只需要指定指针本身。引用指针本身将显示整个数组。

`print pointer`

要使用结构体指针显示结构体的元素，需要两个要素：指向结构体的指针以及你想打印的结构体元素。以下命令使用结构体指针来显示其中的某个特定元素。注意箭头。它是必要的。

```
print pointer->elementname
```

## 停止与单步

虽然你的程序可能没有导致停止的错误，但程序可能由于某些原因给出错误的答案。这被称为运行时错误。此时，你需要在 `gdb` 中在你想检查程序的地方停止程序的运行（你可以检查该点变量的值）。然后，你可能想逐行单步程序，以查看错误发生在哪里。

你可以使用 `break` 命令在程序中设置断点。当到达断点时，程序将停止。然后你可以使用 `next` 或 `step` 命令逐行单步执行程序。当你愿意时，可以使用 `cont` 命令跳进到下一个断点。

| 命令 | 单字母等效写法 | 功能 |
| :--- | :--- | :--- |
| `next` | `n` | 执行单步执行，逐行执行当前行。 |
| `step` | `s` | Step入函数内部。 |
| `cont` | `c` | 继续执行直到下一个断点。 |

## xxgdb

`xxgdb` 为 `gdb` 调试器提供了易于使用的 X-Window 访问。`xxgdb` 被组织为一组垂直排列的子窗口。初始时显示五个子窗口。顶部的子窗口称为“文件窗口”（file window），显示当前正在显示的文件。下一个子窗口显示程序的源代码文件，称为“源窗口”（source window）。左侧的滚动条允许你滚动文本。下方是显示 `gdb` 状态和错误消息的“消息窗口”（message window）。底部的子窗口称为“对话窗口”（dialog window），用于输入 `gdb` 命令并显示其结果。左侧的滚动条允许你查看之前的命令及其结果。对话窗口上方是“命令窗口”（command window）。这是一个列出用于不同 `gdb` 命令的一系列按钮的子窗口。要执行 `run` 或 `step` 命令，只需点击该按钮即可。你可以使用位于子窗口之间分隔符右侧的小方块来水平地更改任何窗口的大小。

通过命令按钮，你可以轻松设置 `gdb` 命令，指示断点或指定要显示的变量。如果命令设计为对对变量或函数名等对象进行操作，你首先需要在源窗口中选择该对象。例如，要在某个函数上设置断点，你首先在源窗口中点击该函数名，然后点击“断点”（break）按钮。你将看到源窗口中出现一个红色箭头，指向该函数的第一行代码。当你逐行执行代码时，左侧的蓝色指针将显示你执行了哪行代码。

要显示变量的内容，你首先选择它们，然后点击“显示”（display）按钮。将在屏幕底部打开另一个名为“显示窗口”（display window）的子窗口，用于显示所选的变量。当你选择更多变量进行显示时，它们会被添加到窗口中。

“打印”（print）按钮将在消息窗口中打印所选变量或表达式的内容。然而，如果你右键点击“打印”按钮，则会弹出一个单独窗口显示该变量的内容。在对象内容显示上方是弹出窗口的标签，带有对象的名称。要关闭弹出窗口，点击该标签。如果你右键点击任何以指针值显示的地址窗口，这将弹出一个窗口来显示该指针所指向的对象的内容。
