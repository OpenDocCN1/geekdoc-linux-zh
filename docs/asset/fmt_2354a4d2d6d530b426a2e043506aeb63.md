
# 念珠菌属

*念珠菌属*（*Candida*）物种，尤其是*白色念珠菌*（*C. albicans*），引起几乎所有 70% 的酵母菌感染。然而，医疗实践最近的变化，如广谱抗生素、类固醇和免疫抑制药物的使用，以及对新型且致残性强的疾病（例如获得性免疫缺陷综合征[艾滋病]）的认识，增加了这些感染病原体的多样性。曾经在患者样本中很少遇到的物种（例如*副念珠菌*（*C. parapsilosis*）、*克鲁伯念珠菌*（*C. krusei*）和*季也蒙念珠菌*（*C. guilliermondii*））正以增加的频率被分离出来。同样重要的是，从未被描述为人类感染原因的酵母菌（例如*头芽生孢酵母*（*Blastoschizomyces capitatus*）、*都柏林念珠菌*（*C. dubliniensis*）和*角状毛孢子菌*（*Trichosporon cutaneum*））现在虽然罕见，但也与人类疾病有关。参见[获得性免疫缺陷综合征（艾滋病）]；[医学真菌学]；[机会性感染]。

## 易感因素

由于酵母菌不像其他微生物病原体那样擅长逃避或压倒人体的免疫防御，它们通常需要人体自然保护机制的某种破坏才能引发感染。从皮肤上的轻微破损（如由切割或刮伤引起）到皮肤完整性更严重的破坏（如通过静脉导管输送药物或营养素造成）都能为致病性酵母菌提供进入人体的途径，并可能引发感染。使用广谱抗菌剂会消除大量正常细菌菌群，使口腔和肠道中的酵母菌迅速生长并进入血液，造成暂时的良性感染或慢性的、潜在的危及生命的感染。由妊娠或糖尿病引起的自然激素失衡，以及由皮质类固醇等药物使用引起的激素失衡，会抑制免疫系统，使个体易感酵母菌感染。免疫抑制药物的常用性以及如艾滋病等较新人类疾病相关的免疫系统低下，导致免疫系统预防和消除酵母菌感染的能力下降。最后，上述医疗进步带来的人类预期寿命延长，促成了老年人人口数量的不断增加，他们对所有形式微生物感染的抵抗力自然降低。参见[免疫抑制]。

## 临床症状

虽然酵母菌感染通常影响皮肤和黏膜，但疾病可采取几种不同的形式，每种形式都有不同的症状。例如，在新生儿和婴儿中，念珠菌病可表现为皮肤感染（尿布皮疹）的发红和水疱样病变，或表现为口腔黏膜组织上的白灰色病变（鹅口疮）。在绝大多数酵母菌感染中观察到的症状与其他微生物病原体的症状相似，因此在确定其病因方面通常价值不大。大多数酵母菌感染的诊断包括从患者那里获取详细的病史，进行广泛的体格检查，分析临床实验室数据，并利用主治医生和传染病专家的教育、培训和经验。参见[临床微生物学]。

## 治疗

第一种临床有效的抗真菌抗生素（制霉菌素）的引入紧随抗菌药物（青霉素）的使用之后。然而，发现制霉菌素仅在与感染病原体直接接触时有效。另一同化学家族成员两性霉素 B 的广谱和杀真菌（杀死真菌）活性，使其保持作为几种酵母菌感染首选药物以及当所有其他抗生素失效时最后选择的抗真菌药物。两类密切相关的药物家族，即唑类和三唑类，于 20 世纪 70 年代初引入，并迅速确立为酵母菌感染的一线抗真菌药物。然而，较新的三唑类药物是抑真菌的（限制生长）而非杀真菌的。因此，一旦停止治疗，感染复发频繁。虽然新的抗真菌抗生素继续被引入，但具有广谱和杀真菌活性、易于给药且副作用有限的完美药物尚未找到。参见[抗生素]；[抗微生物剂]；[抑真菌剂和杀真菌剂]；[青霉素]。[I.F.S.]

# 黄热病

一种急性、发热性、蚊媒传播的病毒性疾病，重症病例以黄疸、蛋白尿和出血为特征。无症状感染也会发生。

病原体是一种黄病毒，B 组虫媒病毒。该病毒在蚊体内增殖，蚊子终身保持感染状态。在蚊子摄入含病毒的血液后，需要 12–18 天的间隔（称为外潜伏期）才能具有传染性。参见[动物病毒]；[虫媒脑炎]。

病毒通过蚊子叮咬进入人体，在淋巴结中增殖，在血液中循环，并定位于肝脏、脾脏、肾脏、骨髓和淋巴结。疾病的严重程度以及出现的主要体征和症状，取决于病毒定位的部位以及细胞破坏的程度。潜伏期为 3–6 天。发病初期，患者出现发热、寒战、头痛和背痛，随后出现恶心和呕吐。通常随后出现短暂的缓解期。大约在第四天，中毒期开始，脉搏相对于发热缓慢，并常伴有黄疸状态。在重症病例中，尿液中蛋白质水平很高，并有出血表现；呕吐物可能因血液变性而呈黑色；且血液中淋巴细胞数量异常低。当疾病进展到重症状态（黑吐和黄疸）时，死亡率很高。然而，感染可能轻微且未被识别。诊断通过尽可能早地从个体血清中分离病毒，或血清抗体升高来确定。参见[抗体]；[补体结合试验]；[中和反应（免疫学）]。

黄热病有两个主要流行周期：经典型或城市流行型黄热病，以及森林型或丛林黄热病。城市黄热病涉及西半球和西非的埃及伊蚊（*Aedes aegypti*）在人与人之间传播。这种蚊子在伴随人类定居的水体积聚处繁殖。丛林黄热病主要是猴子的疾病。在南美洲和非洲，它通过栖息在最上层树冠的树栖蚊子（*Haemagogus* 和 *Aedes* 属物种）在猴子之间传播。动物中的感染范围从严重到无症状。在森林中与这些蚊子接触的人可能会感染。当受感染的猴子造访人类栖息地并叮咬埃及伊蚊时，丛林黄热病也可能发生，随后该蚊子将病毒传播给人类。强有力的蚊子灭治计划实际上已消除了城市黄热病。然而，随着现代航空旅行的速度，存在埃及伊蚊的地方仍有黄热病爆发的威胁。目前有优秀的减毒活疫苗。参见[疫苗接种]。[J.L.M.]

# 紫杉（Yew）

*Taxus*属，一种常绿树属或灌木属，其果实含有一粒种子，种子外包裹着鲜红色、肉质、杯状的假种皮（aril）。叶片扁平，呈针状（acicular），叶背绿色，茎上有向下延伸的叶柄。唯一具有商业价值的本土美国物种是太平洋紫杉（*T. brevifolia*），这是一种中等大小的树木，分布于太平洋沿岸和落基山脉北部地区。虽然它不是常见的树种，但其木材有时用于制作电线杆、桨、弓和小型家具。

欧洲紫杉（*T. baccata*），原产于欧洲、北非和亚洲北部，以及日本紫杉（*T. cuspidata*）在美国作为常绿观赏植物被广泛栽培。参见：TAXALES（紫杉目）。

# 亚甲基（Ylide）

一类有机化合物，包含两个相邻原子，分别带有形式正电荷和负电荷，且两个原子都具有完整的电子八隅体。最常用作正原子杂原子包括磷、氮、硫、硒和氧，而负原子通常涉及碳、氮、氧或硫。亚甲基可以存在于无环或环状环境中，在后者中，亚甲基基团可以是环内的或环外的。在有机合成中最有用的亚甲基是那些包含磷或硫以及相邻碳负离子的化合物。

磷亚甲基被称为 phosphorane（磷鎓）。此类亚甲基反应活性极高。含硫亚甲基（*α*-磺酰基）有两种类型：硫鎓亚甲基和氧化硫鎓亚甲基，两者的区别在于后者在硫原子上连接了一个氧原子。参见：REACTIVE INTERMEDIATES（活性中间体）。

亚甲基基团也可以被引入杂环体系中。例如，meso-离子性的 sydnone 分子含有 azomethine imine（偶氮亚甲基亚胺）亚甲基，而从3-羟基吡啶衍生出的 mesomeretic 碱（betaine）含有 azomethine（偶氮亚甲基）亚甲基。这些亚甲基常被称为掩蔽亚甲基。[KTP]

# 卵黄囊（Yolk sac）

一种延伸到脐带中的胚胎外膜。在某些软骨鱼、鸟类和爬行动物中，它富含卵黄，作为胚胎发育的营养来源。

在哺乳动物中，与鸟类一样，卵黄囊通常从胚胎外中胚层（extraembryonic splanchnopole）发育而来，并延伸至发育中的胚胎下方。血管网络在哺乳动物卵黄囊衬里中发育。尽管这些血管是空的，它们在从母体吸收营养和氧气方面起着重要作用。因此，虽然高等哺乳动物的卵黄囊可以被视为其产卵祖先在进化上的残留，但它仍然在幼胚中发挥着重要的功能。随着胚胎的成熟，卵黄囊体积缩小，尿囊（allantois）接管了营养供给的角色。参见：ALLANTOIS（尿囊）。[S.BO]

# 杨氏模量（Young’s modulus）

一个常数，标记为 *E*，当材料表现出弹性行为时，是应力与相应应变的比值。杨氏模量由应力-应变图的初始直线段的斜率 *E* = ∆S/∆e 表示。更准确地说，*E* 是刚度的度量，具有与应力相同的单位：磅/平方英寸或帕斯卡。当应力和应变不直接成正比时，*E* 可以表示为应力-应变曲线上切线的斜率或连接两点的割线的斜率。此时模量被称为在指定应力值下的切线模量或割线模量。专门应用于拉伸的弹性模量称为杨氏模量。参见：ELASTICITY（弹性）；HOOKE’S LAW（胡克定律）；STRESS AND STRAIN（应力与应变）。[WJJ,WGB]
