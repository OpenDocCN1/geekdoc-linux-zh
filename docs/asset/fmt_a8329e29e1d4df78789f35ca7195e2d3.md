
URL 的通用形式为 `"scheme://netloc/path;params?query#fragment"`。

```python
urlparse(urlstring [, default_scheme])
```

解析 `urlstring` 并返回 `ParseResult` 实例。如果未指定 `default_scheme`，则使用 `'http'`。定义的属性如下：

| 属性 | 描述 |
| --- | --- |
| `r.scheme` | URL 方案（例如 `'http'`） |
| `r.netloc` | 网络位置指定（例如 `'www.python.org'`） |
| `r.path` | 分级路径（例如 `'/index.html'`） |
| `r.params` | 附加到路径的参数 |
| `r.query` | 查询字符串（例如 `'name=David'`） |
| `r.fragment` | 不带 `#` 的片段 |
| `r.username` | 如果 `netloc` 格式为 `'username@hostname'` 则返回用户名 |
| `r.password` | 来自 `netloc` 的密码 |
| `r.hostname` | 来自 `netloc` 的主机名 |
| `r.port` | 如果 `netloc` 格式为 `'hostname:port'` 则返回端口号 |

`ParseResult` 可以通过 `r.geturl()` 转回 URL 字符串。

```python
urlsplit(parts)
```

由 `urlsplit()` 的元组表示构建 URL。`parts` 是一个包含五个组件的元组或可迭代对象。

```python
urlparse(url)
```

返回一个元组 `(newurl, fragment)`，其中 `newurl` 是去掉了片段的，`fragment` 是包含片段部分（如果有）的字符串。如果 `url` 中没有片段，则 `newurl` 等于 `url`，`fragment` 为空字符串。

```python
urljoin(base, url [, allow_fragments])
```
