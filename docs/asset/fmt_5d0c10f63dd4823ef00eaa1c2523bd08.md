## 总结

本章详细介绍了透明传输数据加密（TDE）、始终加密（Always Encrypted）、行级安全（RLS）和动态数据掩码。透明传输数据加密是保护物理介质的安全功能。始终加密是一种保护敏感数据的客户端加密技术。行级安全是控制行访问的安全功能。动态数据掩码是随 SQL Server 2016 引入的另一个安全功能；它通过对非特权用户进行掩码来限制敏感数据的暴露。
