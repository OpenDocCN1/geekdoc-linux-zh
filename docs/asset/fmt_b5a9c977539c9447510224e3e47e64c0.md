# kbd — 键盘命令

## 概要

```
/usr/bin/kbd [-r] [-t] [-c on | off] [-a enable | disable] [-d keyboard device]
/usr/bin/kbd -i [-d keyboard device]
```

## 描述

使用 `kbd` 命令操作键盘状态、显示键盘类型或更改键盘终止序列。设置的默认键盘设备为 `/dev/kbd`。`i` 选项从键盘默认文件 `/etc/default/kbd` 读取并处理点击和终止设置的默认值，如下：

```
java$ more /etc/default/kbd

#pragma ident "@(#) 1.2 96/06/07 SMI"

# Copyright 1996, Sun Microsystems, Inc.

# All Rights Reserved.

# /etc/default/kbd

# kbd default settings processed via kbd(1).

#

# 

# KEYBOARD_ABORT 影响键盘序列的默认行为，详见 kbd(1)。默认值为 "enable"

# 可选值为 "disable"。其他值均被忽略。

# KEYCLICK 影响默认按键点击行为。可能值为 'on' 和 'off'。其他值均被忽略。默认行为是保持当前点击设置不变。

# 取消以下行的注释以更改默认值。

# KEYBOARD_ABORT=enable

# KEYCLICK=off
```

只有支持点击的键盘响应 `-c` 选项。你可以从命令行通过 `-c` 更改会话的点击设置。

要默认开启点击，编辑 `/etc/default/kbd` 文件，移除 `KEYCLICK` 变量行开头的注释 `#`，并将默认值设置为 `on`，如下：

```
KEYCLICK=on
```

然后运行命令 `kbd -i` 更改当前设置。`KEYCLICK` 变量的有效设置为 `on` 和 `off`。其他值均被忽略。如果默认文件中未指定该变量，则设置不变。在大多数系统中，键盘终止序列的默认效果是挂起操作系统并进入调试器或监视器。大多数系统的终止序列是键盘上的 Ctrl-A 或 STOP-A，以及串口输入设备上的 BREAK。

> 注意 — 某些系统具有安全位置的开关。在这些系统中，安全位置的开关会覆盖用 `kbd` 命令设置的任何软件默认值。

从命令行设置时无法确定键盘点击设置的状态。

只有超级用户可以使用 `-a` 选项更改键盘终止序列。超级用户可以从命令行更改键盘终止序列。

作为超级用户要永久更改终止序列的默认效果，编辑 `/etc/default/kbd` 文件，移除 `KEYBOARD_ABORT` 行开头的注释 `#`，并将默认值设置为 `disable`，如下：

```
KEYBOARD_ABORT=disable
```

然后运行命令 `kbd -i` 更改当前设置。`KEYBOARD_ABORT` 变量的有效设置为 `enable` 和 `disable`。其他值均被忽略。

## 选项

- `-a` 启用/禁用 状态：

启用或禁用键盘中断序列的效果。默认情况下，键盘中断序列（通常是键盘上的 Stop-A 或 L1-A，以及串行控制设备上的 BREAK）会挂起大多数系统的操作系统。此选项仅供超级用户（superuser）使用。

- `enable`: 启用键盘中断序列的默认效果，即挂起操作系统并进入调试器或监控器。

- `disable`: 禁用默认效果并忽略键盘中断序列。

- `-c` 开启/关闭 状态：

开启或关闭键盘点击功能。

- `on`: 启用点击功能。

- `off`: 禁用点击功能。

- `-d` 键盘设备：

指定键盘设备 `set`。默认值为 `/dev/kbd`。

- `-i`: 从键盘默认文件设置键盘默认。此选项与 `-d` 键盘设备选项以外的所有其他选项互斥。此选项指示键盘命令从 `/etc/default/kbd` 文件读取并处理按键点击和键盘中断的默认值。此选项仅供超级用户使用。

- `-r`: 重置键盘，类似于上电启动。

- `-t`: 返回正在使用的键盘类型。

# kdestroy

`kdestroy` 通过向包含票据的文件写入零来销毁用户的活动 Kerberos 授权票据。如果票据文件不存在，`kdestroy` 将显示相应的消息。覆盖文件后，`kdestroy` 会从系统中删除该文件。该命令会显示指示操作成功或失败的消息。如果 `kdestroy` 无法销毁票据文件，它将通过终端蜂响警告你。

删除移除票据文件外，`kdestroy` 还会失效内核中持有的、用于 NFS 请求的用户的所有 Kerberos 凭据。你可以将 `kdestroy` 命令放在 `.logout` 文件中，这样当你注销时会自动销毁票据。

> 注意 — 当你将 `kdestroy` 放在 `.logout` 文件中时，注销后代表你执行的操作将失败。

### 缺陷

只有用户当前票据文件中的票据会被销毁。单独票据文件用于持有 `root` 实例和密码更改票据。这些文件可能也应该销毁，或者将用户的所有票据都保留在一个票据文件中。

## 选项

- `-f`: 不显示状态消息。

- `n`: 不使内核中的 NFS 凭据失效。凭据将一直有效直到正常过期时间，尽管在再次为该用户运行 `kinit(1)` 之前无法获取新凭据。

- `q`: 如果 `kdestroy` 未能销毁票据，不要让终端蜂响。
