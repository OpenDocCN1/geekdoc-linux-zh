
## 说明

- 1. 打开 `datebook` 文件用于读取。
- 2. `-s` 测试选项返回由文件句柄引用的 `datebook` 文件的大小。
- 3. `read` 函数从文件句柄读取 `Size` 字节（字符）并将其存储在标量 `$Buffer` 中。`read` 函数将所有字符视为字符，包括换行符、空格、制表符等。
- 4. `split` 函数的第一个参数是一个正则表达式，匹配换行符或冒号，它是拆分 `$buffer` 中字符串的分隔符，`$buffer` 是第二个参数。（请记住，`split` 拆分的是一个标量，并返回一个数组或列表。）当在 `$buffer` 中匹配到换行符或冒号时，`split` 返回一个元素以存储在数组 `@Lines` 中。数组的第一个元素将是名称（例如，Steve Blenheim），第二个元素将是 Steve 的电话号码，然后是地址、生日和薪资。当匹配到换行符时，下一个元素将是 `$buffer` 中的下一个名称。当拆分完成后，将创建一个大型数组。
- 5. 使用 `foreach` 循环来遍历数组中的每个元素。
- 6. 数组中的每个元素都随换行符打印。
- 7. 当到达最后一个字段时，即包含薪资的字段，打印一行由 35 个短划线组成的行。在正则表达式中，薪资表示为“以一位或多位数字开头和结尾”。由于薪资字段是行中的最后一个字段，因此它包含一个换行符。通过打印短划线行和另一个换行符，输出显示了一条分隔记录的线。

### 10.1.4 从文件加载哈希

从文件加载哈希需要选择哪些将作为键，哪些将作为值。由于键必须是唯一的，此方法可用于基于键删除重复项。

#### 示例 10.10

**(数据文件)**

```
Ann Willy:530-444-5678

Joe Shmoe:415-333-4567

Jack Sprat:213-453-1098

Ann Willy:530-444-5678

Jack Sprat:213-453-1098

Jack Sprat:213-453-1098
```

**(脚本)**
```perl
open($fh, "<", "datafile") or die "$!";

while(<$fh>){
1   ($name, $phone)=split(":");
2   $duphash{$name}=$_,
}
3 foreach $key (sort keys $duphash){
4   print $duphash{$key};
}
close $fh;
```

**(输出)**

```
4 Ann Willy:530-444-5678

Jack Sprat:213-453-1098

Joe Shmoe:415-333-4567
```

## 说明

- 1 每一行按冒号拆分为两个变量，`$name` 和 `$phone`。
- 2 正在即时创建一个名为 `%duphash` 的哈希。唯一的键将是名称字段中的值。分配给键的值是当前行。
- 3 `sort` 函数将以字母顺序对新创建的名为 `%duphash` 的哈希中的所有键进行排序。
- 4 哈希的值是来自文件的一行。所有行都被打印，重复项已被移除。

### 10.2 从 STDIN 读取

正如您可能回忆起的，三个文件句柄 `STDIN`、`STDOUT` 和 `STDERR` 是分配给三个预定义流 `$stdin`、`$stdout` 和 `$stderr` 的名称。默认情况下，这些文件句柄与您的终端相关联。当向终端屏幕打印输出时，使用 `STDOUT`。当打印错误时，使用 `STDERR`。当将用户输入赋值给变量时，使用 `STDIN`。

Perl 的 `< >` 输入运算符包围 `STDIN` 文件句柄，以便可以从终端键盘读取下一行标准输入并将其赋值给变量。与 shell 和 C 读取输入的操作不同，Perl 在从标准输入读取一行时保留字符串末尾的换行符。如果您不想要换行符，则必须显式地移除它，或者“chomp”掉它（参见以下第 10.2.2 节，“chop 和 chomp 函数”）。

#### 10.2.1 将输入赋值给标量变量

当从文件句柄 `STDIN` 读取输入时，如果上下文是标量，则读取一行输入（包括换行符），并将其作为单个字符串赋值给一个标量变量。

##### 示例 10.11

**(脚本)**
```perl
# 从键盘获取一行输入。
print "What is your name? ";
$name = <STDIN>;
print "What is your father's name? ";
$fname=<STDIN>;
print "Hello respected one, $fname";
```

**(输出)**

```
What is your name? Isabel
What is your father's name? Nick
Hello respected one, Nick
```

##### 说明

- 1. 字符串 `What is your name?` 被发送到 `STDOUT`，默认情况下这是屏幕。
- 2. 包围 `STDIN` 的输入运算符 `< >`（称为菱形运算符）读取一行输入，并将该行及其尾随的换行符赋值给标量变量 `$name`。当输入赋值给标量时，字符会被读取，直到用户按下 Enter 键。
- 3. 字符串被打印到 `STDOUT`。
- 4. 如果输入运算符为空，则从 `STDIN` 读取下一行输入，行为与第 2 行完全相同，只是输入被赋值给 `$fname`。

#### 10.2.2 chop 和 chomp 函数

`chop` 函数移除标量变量中的最后一个字符以及数组中每个单词的最后一个字符。它的返回值是被切掉的字符。`chop` 主要用于移除进入程序的输入行中的换行符，无论它是 `STDIN`、文件还是命令替换的结果。当您刚开始学习 Perl 时，尾随的换行符确实很烦人！

`chomp` 函数在 Perl 5 中引入，用于移除标量变量中的最后一个字符以及数组中每个单词的最后一个字符，*仅当* 该字符是换行符（或者更准确地说，是代表输入行分隔符的字符，初始定义为换行符并存储在 `$/` 变量中）时。它返回切掉的字符数。使用 `chomp` 代替 `chop` 可以防止您无意中移除除换行符以外的某些字符。

##### 示例 10.12

**(脚本)**
```perl
# 移除 *尾随* 的换行符。使用 *chomp* 代替 *chop*。
1 print "Hello there, and what is your name? ";
2 $name = <STDIN>;
3 print "$name is a very high class name.\n";
4 chop($name); # 无论最后一个字符是什么都移除它。
5 print "$name is a very high class name.\n";
6 chop($name);
7 print "$name has been chopped a little too much.\n";
8 print "What is your age? ";
9 $age=<STDIN>; # 如果是换行符则移除最后一个字符
# 如果是换行符则移除。
10 chomp($age); # 除非是换行符，否则不移除最后一个字符
# 除非是换行符。
11 print "For $age, you look so young!\n";
```

**(输出)**

```
1 Hello there, and what is your name? Joe Smith
3 Joe Smith
is a very high class name.
5 Joe Smith is a very high class name.
7 Joe Smit has been chopped a little too much.
8 What is your age? 25
11 For 25, you look so young!
```
