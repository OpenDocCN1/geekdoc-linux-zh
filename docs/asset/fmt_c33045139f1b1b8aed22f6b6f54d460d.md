# 内分泌系统（脊椎动物）

经典的化学通信系统由一组分泌激素（进入血液循环）的腺体组成。内分泌系统调节各种器官。

内分泌系统受控制机制调节，激素与其靶标之间最常见的关系是负反馈，即对激素的反应会抑制自身。例如，胰岛β细胞对高血糖水平做出反应。胰岛素释放到血液中，导致细胞吸收葡萄糖，从而降低血糖。当血糖浓度下降时，胰岛素被抑制。这种过程通过胰岛素调节血糖：代谢。

甲状腺（同样地）分泌的控制涉及复杂的反馈回路。这些内分泌环路受到垂体促甲状腺激素和下丘脑释放甲状腺激素水平的影响。

## 钙调节

甲状旁腺的名称源于它们在哺乳动物中嵌入在甲状腺腺腺。这些微小腺体对生命至关重要，因为它们调节血液和细胞外液中的钙浓度。如果钙过低，会导致张力性抽挛；而如果钙过高，细胞的正常功能将无法维持。

抗利尿激素的分泌由下丘脑分泌神经元调节，这些神经元对细胞外液中的盐浓度敏感。在缺乏抗利尿激素的情况下，个体会排出大量稀尿，导致严重脱水（尿崩症）。

维生素 D 作为一种类类固醇激素受调节，尽管它并不是一种内分泌激素。它通过饮食中的前体合成，或由皮肤产生，起到促进肠道钙吸收和骨骼矿化的作用。

醛固酮受两种相互拮抗的激素调控。醛固酮是一种肾上腺类固醇，能促进肾小管对钠的重吸收并减少其在尿液中的排出。相比之下，利尿肽（心利尿激素）作用于肾脏，增加尿液中钠的排出。

但它最重要的功能是增强跨膜钙转运，从而提高细胞密度。

参见维生素 D。

参见渗透压调节机制。

钙旁素是一种新由甲状腺细胞（不同于产生甲旁腺腺激素的细胞）和非哺乳脊椎动物产生的肽激素。钙旁素与胰岛素共同作用，抑制骨骼钙的吸收。从钙调节的角度来看，它似乎是最重要的。

## 生殖激素

研究最充分的内分泌激素是男性的睾丸和女性的卵巢。这些激素由卵巢分泌的卵泡刺激激素和黄体形成激素调节。在男性中，这些激素刺激睾丸的立质细胞形成精子并产生睾酮，这是主要的性激素。

参见甲旁腺腺体。

睾酮还介导精子的最终成熟，并通过血液促进男性生殖系统的发育和性特征形成。

## 碳水化合物调节

胰岛素和胰血糖素是由胰腺细胞产生的激素。胰岛素是唯一调节葡萄糖（血糖）水平的激素。它作用于靶细胞（肌肉细胞）以增加葡萄糖的摄取。另一方面，胰血糖素促进葡萄糖用于代谢反应或通过释放糖（一种大碳水化合物）。

雌激素。高水平的雌激素对下丘脑和垂体具有正反馈作用，增加促性激素的分泌，从而导致排卵。黄体（排卵卵囊）产生雌激素和另一种女性激素——孕酮。孕酮对于维持增厚的子宫内膜是必需的。雌激素和孕酮对于女性生殖周期的调节都非常重要。雌激素对于女性性特征的生长发育也是至关重要的。

胰岛素还会导致靶细胞中氨基酸转化为蛋白质和脂肪。例如，如果氨基酸水平较低，细胞无法获得足够的葡萄糖，因此身体必须利用氨基酸进行能量平衡，或积累在尿中排出的代谢产物。

参见生殖系统；参见卵巢。

相比之下，胰血糖素是一种升血糖激素。它是由胰岛 α 细胞产生的小肽，作用于肝脏，通过激活复杂代谢途径中的酶将糖原转化为葡萄糖。

## 其他激素

还有许多其他因素以各种方式作用于稳态或细胞间通信，例如腺体中发现的大量肽。这些作为激素调节胃肠道的分泌物和汁液。

许多其他激素调节血糖水平。例如，肾上腺素（肾上腺素）是一种源自肾上腺髓的氨基酸，其作用途径与胰血糖素相同，可增加血糖水平（心脏和肌肉组织除外）。肾上腺素是一种压力激素，通过增加葡萄糖和酮形式的能量可用性，为应对紧急情况做好准备。

相反，已证明肾上腺素在神经系统中作为神经递质，有助于强调细胞间通信中内分泌系统与神经系统之间的关系，或者它可能有其他功能。

生长激素是由垂体产生的蛋白质激素，响应低血糖水平而分泌。这种激素刺激细胞对葡萄糖的使用，并通过增加脂肪而非葡萄糖作为能量来源利用。

许多肾上腺激素（如皮质醇）也被称为糖皮质质激素，因为它们也调节血糖水平。这些类固醇激素促进从蛋白质和脂肪分解葡萄糖，而非胰血糖素，并具有抗炎作用，这使得它们治疗关节炎和其他疾病非常有用。

参见肾上腺。

## 盐和水平衡调节

多种激素作用于维持或分泌盐和水的能力。抗利尿激素（抗利尿激素）促进肾小管对水的重吸收，使该器官排出水分。

# 内分泌

腺体向血液中分泌特定物质（如细胞、碳水化合物和蛋白质，以及动物糖等分子中的大分子）的过程。细胞参与至少三种内吞作用：细胞吞噬特定物质的胞吞作用、受体介导的大分子内吞作用以及小分子胞吞作用。

# 818 内胚层

细胞需要的一些营养物质在环境中是稀缺的。环境通过表达针对大分子或分子的高亲力受体（或表面受体）来实现。这些内吞受体能够在进入细胞之前在细胞表面与其配体结合，从而提高摄取效率。

在另一种途径中，内吞始于质膜的内陷，并将该膜转换为称为内体的封闭囊泡。内内体包含各种货物。随着泡泡的组装，可能会将膜变形为泡泡的形状。然后，泡泡迁移到细胞。

# 内毒素

内质网形成一个管状网络（见插图）。糖体。

粗内质网是分泌蛋白和溶酶体蛋白从细胞质易位到细胞内空间，以及膜蛋白整合的场所。除了线粒体、过氧化体外，所有膜蛋白都会整合到内质网中并留在那里，或随后分布到其他膜上。

肽类具有独立的名称，例如内啡肽和β-内啡肽。它们的发现极大地增强了对药物作用机制的理解，并使痛觉感知在中枢神经系统内维持。参见：肽。

信号假说的提出是为了解释蛋白质是如何被靶向并跨内质网膜进行易位或整合的。它认为所有被靶向的多肽都包含一个离散序列（信号序列），该序列与一种触发孔开启的复杂机制匹配，肽通过该孔穿过。对于膜蛋白，由于锚定拓扑序列的存在，其随后触发通道的开启允许多肽易位并将蛋白质整合到脂质双层中。

粗内质网还含有许多酶，其中大多数参与了内质网上新生链的修饰。内质网膜的主要功能是作为分泌、溶酶体和整合蛋白的入口，并作为修饰的场所。

内啡肽及其许多同义类似物是作用于阿片类受体的肽配体，或定位于封闭脑区域内的神经元表面。这些受体已被识别，且对各种阿片类药物和肽的特异性以及它们介导的作用各异。这些高度特异性受体的存在通过向脑内注射内源性肽产生类吗啡效应得到证实，这种效应会被内啡肽终止。参见：类吗啡。

不属于内质网的溶酶体蛋白和分泌蛋白被运输到高尔基体。它们在包囊中运输，并最终与高尔基体囊融合。参见：高尔基体。
