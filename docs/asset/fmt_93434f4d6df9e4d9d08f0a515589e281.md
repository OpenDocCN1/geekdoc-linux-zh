# Linux

点点协议 `PPP` 允许您通过电话连接并运行传输控制协议 `TCP/IP`。让我们如何配置 `PPP`。


# 网络

作者：Salim Douba

在过去的几年里，计算机网络已成为大多数主要生产环境中日益不可或缺的一部分。除了用户可以透明共享的基本文件和打印服务外，网络还允许他们使用不断扩展的其他生产力工具包，如电子邮件、日历、成像以及语音/视频会议应用程序。网络在生产环境中日益普及的另一个因素是它们比其他方式更易连接。对于许多组织而言，互联网为他们提供了另一个业务平台，可以利用它来提高生产力和市场触达范围——即通过互联网将远程办公室连接到总部的附加能力。

由于上述原因，实施和维护满足用户对网络资源和生产力工具需求的网络正成为一项越来越具有挑战性的任务。UNIX 挑战性并不亚于其他网络。如果说的话，安装和配置网络的任务比其他网络更为复杂。这种复杂性源于 UNIX 网络底层协议本质，即 TCP/IP（传输控制协议/网络协议）。

本章涵盖了 UNIX 系统管理员为了安装、配置和维护 UNIX 连接而需要具备必要概念和技能。第一部分是管理 TCP/IP 通信的概念概述，第二部分详细阐述了实现维护 UNIX 连接目标所需的必要 UNIX 工具和技能。

# TCP/IP 通信基础

1969 年，美国国防部高级研究计划局 `DARPA` 被赋予了开发一种实验性分组交换网络的任务。其目标是将所有政府资源连接到单一的全球网络中，而不考虑支持这些资源的硬件或操作系统。因此，建立了一个名为 `ARPANET` 的实验性网络，用于开发和测试符合所分配任务的通信协议。`TCP/IP` 通信协议是这一努力的直接产物。通过使用 `TCP/IP`，可以构建连接混合平台（而不仅仅是 UNIX 平台）的大型网络。从桌面电脑的任何地方设备都可以属于并跨同一个 `TCP/IP` 网络进行通信——没有比互联网本身更能体现这种能力了，它连接了来自全球供应商的超过 1000 万台计算机。

- 征求意见 `RFC`

在本章以及本书的其他章节中，将引用一些标准文档，这些文档以 `RFC XXXX` 的形式（其中 XXXX 指代文档编号）包含了对所讨论的 `TCP/IP` 协议的描述和正式规范。例如，`RFC 959` 是指定文件传输协议的标准文档。好奇的读者可能会发现，某些 RFC 有助于更好地理解当前问题，或解决在他们的网络上遇到的问题。只要你能够访问互联网，获取 RFC 副本是一件简单的事。一种方法是向 `rfc-info@ISI.EDU` 发送电子邮件，使用以下格式：

```
To: rfc@ISI.EDU
Subject: getting rfc
help: ways_to_get_rfc
```
