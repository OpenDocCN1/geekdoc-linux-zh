
这将执行最基本的扫描类型，即由 `-sP` 选项指定的 ping 扫描。你可以通过使用 `-v` 选项查看更多信息，它告诉 Nmap 输出更详细的信息；在大多数情况下你会发现这些额外信息很有价值。由于防火墙拦截 ping 尝试是很常见的情况，如果你在不带 `-sP` 选项的情况下运行扫描，可能会有更好的运气。正常的 TCP 三次握手包括发起扫描发送一个带有 SYN 位的数据包。目标返回一个设置了 SYN 和 ACK 位的数据包。正常系统向目标发回 ACK 数据包。通过这种方式，SYN 扫描 `(-S)` 将发送初始 SYN 包，但当目标主机回复 SYN ACK 时，Nmap 将完成三次握手以完全建立会话。这种方法非常快速且高效，因此它是 Nmap 使用的默认方法。如果你没有指定哪些端口，Nmap 将扫描 `nmap-services` 中定义的所有 TCP 端口。如果你习惯在 Linux 或 Windows 上进行操作，Nmap 在两者上的功能几乎完全相同。然而，有一个显著的差异，那就是速度。Nmap 在 Linux 上的运行速度比 Windows 快得多。在小型网络中这可能不是考虑因素，但如果你正在扫描大量的主机或端口，扫描时间的差异可能会非常显著。

# Nmap

Nmap 是最广泛使用的通用型网络扫描器。你可以从 `http://insecure.org/nmap/` 下载适用于 Windows、Linux、MAC OS X、Solaris 以及其他操作系统的版本。无论你在 Windows 还是 Linux 上运行 Nmap，其操作大体相同。最显著的例外是，如果你在 Windows 上运行 Nmap，你需要 Windows 数据包捕获驱动程序 `WinPcap`。
