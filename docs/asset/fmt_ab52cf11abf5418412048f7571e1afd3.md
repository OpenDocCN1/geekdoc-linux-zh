## UUCP

几乎每个 Unix 系统上都有一个特定的命令 `uucp`（在 man 部分 C 中称为 Unix-Unix copy），你可以直接用它发送和接收文件。它只是 UUCP 网络软件中的一个元素，这是一系列多样的程序和文件，它们连接了全球及之外的 Unix 系统。注意大写的 UUCP 以示区别。小写的 `uucp` 在许多 Unix 通信工具中是基础。

### 建立联系

在可以使用 UUCP 之前，有一些必要条件。远程计算机上必须安装 UUCP。首先，本地和远程站点都必须安装。其次，安装 UUCP 是一个复杂的操作。

#### UUCP 应用程序

UUCP 提供了一些重要的服务：

- 确定本地名称
- 在 Unix 站点之间交换邮件
- 在远程 Unix 系统上执行命令
- 在 Unix 站点之间传输文件
- 检查 UUCP 任务的状态和进度

在接下来的章节中，我们将描述如何使用所有这些命令。

#### `uuname` 命令

`uuname` 命令用于确定你的本地名称以及你的系统已知的所有 UUCP 系统名称：

```
% uuname
basis
ola
isis
mxinu
beast
...
% _
```

`uuname` 不带选项列出你站点已知的所有 UUCP 系统。

`uuname` 带有 `-l`（local）选项会显示你的本地系统名。`uuname` 带有 `-c` 选项会列出 `cu` 命令已知的所有系统。这个列表通常与 `uuname` 给出的相同，但 `cu`（call up）严格来说不是一个 UUCP 命令。我稍后会解释这些差异。

#### 你要找谁？

假设你知道登录名为 `anne` 的 Anne 是名为 `isis` 的系统上的一个有效用户。`uuname` 告诉你 `isis` 可以从你的系统直接“访问”，由于你的系统被命名为 `basis`。给 Anne 发送邮件就像给你自己系统的人发邮件一样简单：

```
% mail isis!anne
From: basis!stan (Stan Kelly-Boot)
To: isis!anne (Anne B. Margaret)
Subject: 这是一个测试！
```

亲爱的 Anne：如果你没有收到这条备忘，请告诉我。

Stan

% _
```

注意，接收者的登录名称带有目标系统名称和感叹号（`!`）的前缀。UUCP 地址的通用语法是 `systemname!username`。

在 C shell 中，你必须用反斜杠转义感叹号。这是因为 C shell 将其解释为历史替换前缀。在 Bourne shell 中，你可以直接 `mail isis!anne`，因为 `!` 不是 Bourne shell 的元字符。我打算习惯性地使用 `\!`，无论我运行的是哪种 shell。邮件正文中的感叹号不会被“看到”。
