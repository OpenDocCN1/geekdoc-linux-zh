## TCSH Shell 初始化文件

TCSH shell 有三个初始化文件：`.login`、`.tcshrc`和`.logout`。这些文件根据它们所执行的操作命名。

## TCSH 配置 107

`.login`文件是一个登录初始化文件，在每次登录时都会执行。`.tcshrc`文件是一个 shell 初始化文件，在每次进入 TCSH shell 时都会执行，无论是通过登录还是通过`tcsh`命令从另一个 shell 显式切换到 TCSH shell。`.logout`文件在每次注销时执行。

### .login

TCSH shell 有自己的登录初始化文件，称为`.login`文件，它包含了用于配置你的 shell 的 shell 命令和特殊变量定义。`.login`文件对应于 BASH 和 ZSH shell 中使用的`.profile`文件。

`.login`文件包含`setenv`命令，这些命令用于为特殊环境变量（如`TERM`）赋值。你可以通过使用任何标准编辑器编辑`.login`文件来更改这些分配的值。你也可以添加新值。但请记住，在 TCSH shell 中，为环境变量赋值的命令是`setenv`。在下一个示例中，定义了`EXINIT`变量，并为其分配了 Vi 编辑器的行号显示和自动缩进选项。

```bash
> setenv EXINIT 'set nu ai'
```

编辑`.login`文件时要小心。无意的更改可能会导致变量设置错误或完全不设置。在编辑之前对`.login`文件进行备份是明智的。

如果你对`.login`文件进行了更改，并希望这些更改在当前的登录会话期间生效，你需要重新执行该文件。你可以使用`source`命令来实现。`source`命令实际上会执行任何初始化文件，包括`.tcshrc`和`.logout`文件。在下一个示例中，用户重新执行了`.login`文件。

```bash
> source .login
```

### .tcshrc

`.tcshrc`初始化文件在每次进入 TCSH shell 或生成任何子 shell 时都会执行。如果 TCSH shell 是你的登录 shell，那么在登录时`.tcshrc`文件会和`.login`文件一起执行。如果你从另一个 shell 进入 TCSH shell，`.tcshrc`文件会自动执行，其中包含的变量和别名定义将被定义。

`.tcshrc`shell 初始化文件实际上在每次生成 shell 时都会执行，例如当你运行 shell 脚本时。换句话说，每当创建一个子 shell，`.tcshrc`文件就会被执行。这允许你在`.tcshrc`初始化文件中定义局部变量，并在某种程度上将它们导出到任何子 shell 中。尽管作为历史记录的用户定义变量是局部的，但它们会为每个生成的子 shell 定义。通过这种方式，每个子 shell 都设置了历史。然而，每个子 shell 都有自己的本地`history`变量。你甚至可以在一个子 shell 中更改本地`history`变量，而不影响其他子 shell 中的任何变量。在 shell 初始化文件中定义特殊变量允许你像处理 BASH shell 导出变量一样处理它们。在 BASH 或 ZSH shell 中，导出变量只会向任何子 shell 传递它的副本。更改副本不会影响原始定义。

`.tcshrc`文件还包含了用于开启 shell 功能的别名（aliases）和功能变量定义。别名和功能变量在 shell 内部定义。但`.tcshrc`文件会在每个 shell 中定义它们。因此，`.tcshrc`通常持有作为`rm`、`cp`和`mv`命令的别名。下一个示例是一个包含许多标准定义的`.tcshrc`文件。

```bash
set shell = /usr/bin/csh

set path = $PATH (/bin /usr/bin . )

set cpath = (/home/chris/reports /home/chris/letters)

set prompt = '! $cdw >'

set history = 20

set ignoreeof

set noclobber

alias rm = 'rm'

alias cp = 'cp'

alias mv = 'mv'
```

### .logout

`.logout`文件也是一个初始化文件，但它在用户注销时执行。它旨在在你每次注销时执行任何想要的操作。而不是变量定义，`.logout`文件通常包含组成关闭程序的 shell 命令。例如，一个常见的注销命令是检查任何活动作业的；另一个是清除屏幕并发布告别消息。

就像`.login`一样，你可以在`.logout`文件中添加自己的 shell 命令。使用 Vi 编辑器，你可以更改告别消息或添加其他操作。在下一个示例中，用户在`.logout`文件中有一个`clear`和`echo`命令。当用户注销时，`clear`命令将清除屏幕，`echo`将显示“Good-bye for now”消息。

```bash
clear
echo "Good-bye for now"
```
