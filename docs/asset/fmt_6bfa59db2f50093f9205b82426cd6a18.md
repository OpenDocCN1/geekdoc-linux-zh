# 基础示例考试系统要求

RHEL 6 的测试系统需要更多的配置。在 RCSA 或 RHCE 考试的目标中，并没有要求进行物理的“裸机”安装。然而，对于 RHCSA 考试，你确实需要“配置一台物理机来托管虚拟机客户”。由于默认的 RHEL 6 虚拟机解决方案 `KVM` 只能从其 64 位版本进行安装，因此你应该拥有 64 位硬件。

- 在物理 64 位硬件上进行安装。
- 接受与另一个操作系统的双启动配置。
- 红帽不支持 Intel Itanium（安腾）CPU。
