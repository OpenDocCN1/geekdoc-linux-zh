# Python 数据库访问

本章描述了 Python 用于与关系型和哈希表型数据库交互的编程接口。与其他描述特定库模块的章节不同，本章的内容适用于第三方扩展。例如，如果你想让 Python 与 MySQL 或 Oracle 数据库交互，你首先需要下载一个第三方扩展模块。该模块随后将遵循这里描述的基本规范。

## 关系型数据库 API 规范

为了访问关系型数据库，Python 社区开发了一个名为 Database API Specification V2.0 的标准，简称为 PEP 249（正式描述可以在 http://python.org/dev/peps/pep-249/ 处找到）。特定的数据库模块（例如 MySQL、Oracle 等）遵循此规范，但本节涵盖了在大多数应用程序中使用它所需的所有元素。

从高层次来说，数据库 API 定义了一组用于连接数据库服务器、执行 SQL 查询和获取结果的函数和对象。为此使用了两个主要对象：管理数据库连接的 `Connection` 对象和用于执行查询的 `Cursor` 对象。

### 连接 (Connections)

要连接到数据库，每个数据库模块都提供了一个模块级函数 `connect(parameters)`。具体的参数取决于数据库，但通常包括如数据源、用户名、密码、主机名和数据库名等信息。这些信息通常通过关键字参数 `dsn`、`user`、`password`、`word`、`host` 和 `database` 分别提供。因此，对 `connect()` 的调用可能像所示：`connect(hostname="DBNAME",user="michael",password="peekaboo")`

如果执行成功，将返回一个 `Connection` 对象。`Connection` 的实例 `c` 具有以下方法：

```
c.close()
```

关闭与服务器的连接。

```
c.commit()
```

将挂起的事务提交到数据库。如果数据库支持事务，则必须调用此方法使更改生效。如果底层数据库不支持事务，此方法将不起任何作用。

```
c.rollback()
```

将数据库回滚到任何挂起事务的开始。此方法用于不支持事务的数据库，以撤销对数据库所做的任何更改。例如，如果代码在更新数据库的过程中发生异常，你可能可以使用此方法来撤销异常前所做的更改。

```
c.cursor()
```

创建一个使用该连接的新 `Cursor` 对象。游标是你将用于执行 SQL 查询并获取结果的对象。这将在下一节中描述。

### 游标 (Cursors)

为了在数据库上执行任何操作，你首先创建一个连接 `c`，然后调用 `c.cursor()` 方法创建一个 `Cursor` 对象。`Cursor` 的实例具有若干用于执行查询的标准方法和属性：

```
cur.callproc(procname, parameters)
```

使用带给定的参数调用存储过程。结果是一个元组序列，其中每个元组是结果集的一行。

```
cur.execute(query, parameters=None)
```

执行查询。`query` 是字符串，`parameters` 是序列或映射。

```
cur.executany(query, parameters)
```

重复执行查询。`query` 是字符串，`parameters` 是序列。

```
cur.fetchone()
```

返回结果集的下一行。如果没有更多行，则返回 `None`。

```
cur.fetchmany(size=None)
```

返回行的序列。`size` 是要返回的行数。如果省略，则使用 `arraysize` 作为默认值。

```
cur.fetchall()
```

返回剩余行的序列。

```
cur.nextset()
```

丢弃当前结果集中的剩余行并跳到下一个结果集（如果有）。如果没有更多结果集，则返回 `None`；否则返回 `True`。

```
cur.setinputs(sizes)
```

为游标提供后续 `execute` 方法传递的参数提示。`sizes` 是类型序列（描述符或短整数），提供了每个参数的最大预期长度。

```
cur.setoutputsize(size, column=None)
```

设置结果集中特定列的缓冲区大小。`column` 是结果行中的整数索引，`size` 是字节数。如果省略 `column`，则为结果中的所有列设置限制。

```
cur.close()
```

关闭游标。

```
cur.arraysize
```

一个提供 `fetchmany()` 操作默认值的整数。

```
cur.description
```

一个提供当前结果集中每列信息的信息的元组序列。每个元组的形式为 `(name, type_code, display_size, internal_size, precision, scale, null)`。

```
cur.rowcount
```

由 `execute(*)` 方法产生的结果列表中的行数。如果设置为 `-1`，则意味着没有结果集或无法确定行数。

虽然规范没有要求，但大多数数据库模块中的 `Cursor` 对象实现了迭代协议。在这种情况下，像 `for row in cur:` 的语句将遍历上一次 `execute (*)` 调用创建的行结果集。
