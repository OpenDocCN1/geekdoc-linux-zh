# 关于作者

Chris Negus 编写或合著了数十本关于 Linux 和 UNIX 的书籍，包括《红色 Linux 圣经》（所有版本）、《Fedora 和红帽企业级 Linux》、《故障排除圣经》以及最近的《Toys II》。在搬到加利福尼亚之前，他在 AT&T 开发 UNIX 的组织工作了八年。
