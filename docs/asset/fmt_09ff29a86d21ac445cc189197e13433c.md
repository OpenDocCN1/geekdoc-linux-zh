## 9.13 文件选择

要创建一个新的文件选择框，使用：

要获取用户输入或点击的文本，使用此函数：

## 固定容器 (Fixed Container)

`Fixed` 容器允许你相对于窗口的左上角，将控件放置在窗口内的固定位置。控件的位置可以动态更改。

与 `fixed` 控件相关的函数只有三个：

```c
GtkWidget* gtk_fixed_new( void );
```

```c
void gtk_fixed_move( GtkFixed *fixed,
                   GtkWidget *widget,
                   gint16 x,
                   gint16 y );
```

`gtk_fixed_new` 函数允许你创建一个新的 `Fixed` 容器。

`gtk_fixed_put` 将控件按照 `x` 和 `y` 指定的位置放在固定容器中。
`gtk_fixed_move` 允许指定的控件移动到新位置。

以下示例说明了如何使用 `Fixed` 容器。

```c
/* example-start fixed fixed.c */
#include <gtk/gtk.h>

/* 我打算偷懒，用一些全局变量来
* 存储控件在 fixed
/* 容器中的位置 */
gint x=50;
gint y=50;

/* 此回调函数将按钮移动到 Fixed 
* 容器中的新位置。 */
void move_button(GtkWidget *widget,
    GtkWidget *fixed) {
    x = (x+30)%300;
    y = (y+50)%300;
    gtk_fixed_move (GTK_FIXED(fixed), widget, x, y);
}

int main(int argc,
    char *argv[]) {
    /* GtkWidget 是控件的存储类型 */
    GtkWidget *window;
    GtkWidget *fixed;
    GtkWidget *button;
    int i;
    /* 初始化 GTK */
    gtk_init(&argc, &argv);
    /* 创建新窗口 */
    window = gtk_window_new (GTK_WINDOW_TOPLEVEL);
    gtk_window_set_title (GTK_WINDOW(window), "Fixed Container");
    /* 此处将 "destroy" 事件连接到信号处理器 */
    gtk_signal_connect (GTK_OBJECT(window), "destroy",
        GTK_SIGNAL_FUNC(gtk_main_quit), NULL);
    /* 设置窗口的边框宽度。 */
    gtk_container_set_border_width (GTK_CONTAINER(window), 10);
    /* 创建一个 Fixed 容器 */
    fixed = gtk_fixed_new();
    gtk_container_add (GTK_CONTAINER(window), fixed);
    gtk_widget_show (fixed);
```
