## 正向运动学 (FORWARD KINEMATICS)

到目前为止，你已经在节点之间建立了链接。这些链接被称为运动学链。运动学是对对象或系统的研究。

在正向运动学（`FK`）中，你变换层级中的顶部节点来影响整个链。例如，当你旋转肩膀时，会影响前臂和手。再次，通过示例是理解这一概念的最佳方法：

-   1. 关闭“分布”框。选择“暂存保存”（`Hold`）以进行实验。
-   2. 在透视视图中选择 `Base` 并移动它。观察到（由于它们已链接）所有对象会一起移动。
-   3. 选择 `Arm02` 并移动它。注意 `Arm01`、`Swivel` 和 `Base` 留在原地，只有其子级受影响。如图 11.41 所示。

## 逆向运动学 (INVERSE KINEMATICS)

在逆向运动学（`IK`）中，链是反向解析的。你变换层级中的底部节点，从而影响所有的祖先节点。而不是让所有节点跟随子节点，节点会保持连接。这类似于将手举过头，导致前臂和手臂之移动。

-   1. 切换到命令面板的“层级”选项卡。
-   2. 点击 `IK` 按钮，然后点击“交互 `IK`”按钮开启此功能。在你关闭它之前，执行 `IK` 模式下的任何变换。
-   3. 选择 `Point01.Target` 在 `XY` 平面上移动它。观察所有节点如何移动，因为它们需要与链中的其他节点保持连接（见图 11.42）。除了 `Base` 之外的所有节点都在移动，`Base` 是 `IK` 的终端。
-   4. 关闭交互 `IK` 模式并选择编辑 `Fetch` 以结束实验。弹出一个对话框询问是否恢复。点击“是”。

# 添加视口默认照明

你的灯具在视图中可能看起来非常暗。这是因为场景中的光线背对着灯具，而且没有其他照明。书中的图像使用了额外照明以提高清晰度。你可以强制场景的默认照明在视口中显示，即使你已经添加了光源。选择自定义（`Customize`） > 视口配置（`Viewport Configuration`）。在渲染方法（`Rendering Method`）选项卡中，在渲染选项（`Rendering Options`）组框中，勾选默认照明（`Default Lighting`）。旁边的单选按钮允许你选择使用一个或两个灯光的默认照明。此设置不会影响使用“渲染场景”（`Render Scene`）或“快速”（`Quick`）方法渲染的场景输出。

- 3. 注意变换手柄（`Transform gizmo`）的绿色 `Y` 轴环表示该关节应该旋转的方向。取消“旋转关节”展开列表中 `X` 轴组和 `Z` 轴组中的活动（`Active`）复选框。现在，该关节将仅允许按照设计在单方向上旋转。
- 4. 在 `Y` 轴组中，勾选限制（`Limited`）。然后将“从”（`From`）数值调节器向下到约 -45 度。当你设置此关节限制时，引擎罩将在视口中旋转，当你松开调节器时，它将回到原始朝向。
- 5. 将数值调节器拖到约 45 度以设置旋转上限。
- 6. 将阻尼（`Damping`）设置为 0.5，使其在旋转时产生 50% 的阻力。
- 7. 选择 `Arm02`，并取消 `X` 轴和 `Z` 轴的活动（`Active`），因为此关节也应该只在 `Y` 轴方向旋转。勾选限制（`Limited`）并将限制设置为从 -45 到 45 度。同样给它提供 50% 的阻尼。
- 8. 按 `Page Up`（上页）键移动到层级中的上一个祖先（`Page Down` 向层级向下移动）。你现在应该选中了 `Arm01`。
- 9. 取消此关节 `X` 轴和 `Z` 轴的活动（`Active`）。将此关节的运动范围限制在 -30 到 30 度之间，且不带阻尼。
- 10. 按 `Page Up` 键进到旋转关节（`Swivel joint`）。这次，取消其 `X` 和 `Y` 的活动（`Active`）。你不需要为旋转关节设置限制，因为它可以全方位旋转。
- 11. 按 `Page Up` 到底座（`Base`）对象。取消所有三个旋转轴的活动（`Active`），因为底座完全不会旋转。
- 12. 将参考坐标系从父级（`Parent`）切换回视图（`View`），表示你已完成约束设置（见图 1）。
- 13. 最后，你必须将底座设置为该 链的终止者（`terminator`）。终止者将不会相对于链的其他部分移动。打开层级面板顶部的对象参数（`Object Parameters`）展开列表。勾选终止者（`Terminator`），你就告完成。

# 测试关节约束

既然你已经费了精力指定了每个关节允许旋转的方向、范围以及难易程度，现在是时候测试模型并看看它是否符合你的预期了。

- 1. 选择编辑（`Edit`） > 测试（`testing`）。`IK` 中的某些操作是无法撤销的，所以一直按住是个好主意。
- 2. 点击层级（`Hierarchy`）选项卡、`IK` 按钮，并开启交互模式（`Interactive mode`）。
- 3. 选择 `Point01.Target` 对象，点击 `UI` 底部的锁定（`Lock`）或按空格键锁定你的选择，并在所有方向上移动目标。观察灯具所有部分的运动。如果你想微调其设置中的任何内容，现在就是操作的时机。
- 4. 当你对灯具的行为满意时，关闭交互式 `IK`（`Interactive IK`）模式并执行编辑（`Edit`）。灯具应该以准确且真实的方式移动。你可以通过拖动灯目标到任何你想的地方来变换所有部分。

# 使用求解器（`Solver`）

投入大量时间构建关节模型的一个问题是，你的同事需要相同水平的知识才能利用你的工作。如果他们不理解 `IK`，就无法按照你的意图驱动关节模型。你可以让模型更易于使用的一个方法是在 `IK` 链上应用反向依赖求解器（`Inverse Dependent Solver`）。你的模型用户不再需要理解正向运动学（`Forward Kinematics`）和反向运动学（`Inverse Kinematics`）之间的区别。求解器使得无需反复切换 `IK` 即可变换关节模型。所有计算都永久地应用到你的模型中，人们可以在不理解 `IK` 技术细节的情况下使用它。
