
# 金属卤化物灯

金属卤化物灯需要高压才能启动。一旦弧光放电点燃，内部蒸气压开始增加，直到达到预设值，通常为 5 atm (500 千帕斯) 左右。这些灯总是连接到一个称为镇流器的辅助电源，它提供启动和运行灯所需的适当电压和电流。随着各种成分开始蒸并发光，光输出在大约 2 分钟内逐渐增加。弧光放电的光来自碘化物化合物的金属成分，通常是钠、铊、铟、钪、镝和有时锡碘化物的混合物。这些金属的组合产生令人愉悦的高效率白光，效率在每瓦 80 到 120 流明之间，甚至更高。参见 电弧放电。

可以使用特殊原料放在这些灯内，使其更适合植物生长、光刻和卫星用途。某些类型的紧凑型金属卤化物灯非常适合用于电影和幻灯片投影。在这种情况下，选择的原料（通常是铟）是因为它们产生小而强烈的亮度高的弧光。这些灯的光谱几乎是连续的，接近白炽灯的光谱。参见 电影摄影术；白炽灯；光学投影系统。

在希望光源更柔和的情况下，可以用白色荧光粉涂覆灯的外套，以扩散光线并改变输出颜色，在某些情况下甚至提高效率。

## 金属氢化物

一种氢与金属或类金属元素化学键合的化合物。这些化合物通常分为离子型、过渡金属型和共价氢化物。共价氢化物有两个亚型：二元型和复杂型。某些氢化物已获得一定的工业重要性，但大多数仅具有理论兴趣。

在电放电等极端条件下，许多金属形成易挥发的、短寿命的瞬时氢化物，通式类型为 MH。虽然其中一些可以实验制备，但大多数仅通过其光谱观察到。它们在研究分子键合方面很重要。低温下原子氢的作用在许多金属表面形成不稳定的氢化物薄膜。参见 氢络合物；氢。

## 金属基复合材料

一种连续金属相（基体）与另一相（增强体）结合的材料，后者占材料总体积的百分之几到约 50%。在最严格的意义上，金属基复合材料并非通过常规合金化生产。这一特征使大多数金属基复合材料与许多其他多相金属材料（如珠光体钢或过共晶铝硅合金）区分开来。参见 合金。

金属基复合材料表现出的特定好处，如密度降低、比强度和比刚度增加、高温性能极限提高以及耐磨性改善，取决于基体合金和增强相的性质。基体的选择是经验性的，使用现成的合金；主要考虑因素是增强相的性质。存在大量种类的金属基复合材料。增强相可以是纤维状、片状或颗粒状（在所有方向上具有相等尺寸）；其尺寸也可以有很大变化，从大约 0.1 到超过 100 微米。基于大多数工程金属的基体都已被探索，包括铝、镁、锌、铜、钛、镍、钴、铁和各种铝化物。这种广泛的体系导致了这些材料及其制造所用加工方法的同样广泛的性能谱系。金属基复合材料中使用的增强剂分为五类：

- 连续纤维，
- 短纤维，
- 晶须，
- 等轴颗粒，
- 和互连网络。

复合材料的性质首先且最重要的是取决于复合材料的性质；然而，复合材料的某些详细微观结构特征可能会对其行为产生重大影响。金属的物理性质，可因添加增强剂而显著改变，主要取决于增强剂的分布。一个很好的例子是铝-碳化硅复合材料，其中陶瓷的存在大大增加了金属的弹性模量，而对其密度影响不大。然而，改进程度取决于碳化硅的形状和对齐。此外，它取决于增强剂的处理；对于相同的增强剂形状（连续纤维），由微晶多晶衍生的碳化硅纤维产生的改进远小于结晶 ß-碳化硅纤维。其他性质，如金属基复合材料的强度，取决于复合材料的方式要复杂得多。

## 金属轧制

通过旋转轧辊施加的压缩力来减小或改变工件的横截面积。送入轧辊的原始材料通常是来自铸造厂的钢坯。热轧生产中最大的产品称为坯；通过连续的热轧然后是冷轧工艺，坯被轧制成方坯、板坯、厚板、板材、带材和箔材，其厚度和尺寸依次减小。轧制过程对钢坯的初步破碎将粗粒、脆性和多孔的结构转变为具有更好延展性和更细晶粒尺寸的精炼结构。

## 金属玻璃

具有非晶态或玻璃态结构的合金。玻璃是一种从液体中获得且冷却时不结晶的固态材料。因此，它是不结晶态固体，这意味着原子以与液态相似的大小程度上随机的方式堆积。玻璃一词通常与常见的透明硅酸盐玻璃相关，这些玻璃主要含有二氧化硅以及铝、镁、钠等的其他氧化物。这些玻璃不是金属性的；它们是电绝缘体，且不表现出铁磁性。具有金属特性的玻璃是从含有金属元素而不是氧化物的熔体中获得的。然而，液态金属和合金在冷却时结晶速度极快，直到 1960 年才得到第一种金属玻璃，即金和硅（Au$_{95}$Si$_{5}$）的合金，其中含金 80 at. %，含硅 20 at. %。参见非晶态固体。

向纯金属中添加溶质原子，特别是当它们的大小和化学性质与宿主原子不同时，其作用是抑制凝固温度，从而增加了熔体在无结晶情况下凝固的概率。相应地，最容易发生玻璃形成的合金体系是表现出共晶点的一个或多个的体系。因此，液相线温度最低的组成，即接近共晶组成的，最容易形成玻璃。已知的玻璃形成家族包括含有约 10–30% 半金属（例如，铂/磷 (Pt$_{55}$P$_{25}$) 或 铁/硼 (Fe$_{82}$B$_{18}$)）的过渡金属或贵金属合金，仅含早期过渡金属的合金（例如，锆/钯 (Zr$_{46}$Pd$_{54}$) 或 铌/铷 (Nb$_{48}$Rb$_{52}$)），含有周期表第 2 族金属的合金（例如，镁/锌 (Mg$_{28}$Zn$_{72}$) 或 钙/镁 (Ca$_{70}$Mg$_{30}$)），以及稀土金属和过渡金属的合金（例如，钆/钴 (Gd$_{25}$Co$_{75}$) 或 镱/铁 (Yb$_{63}$Fe$_{37}$)）。在少数情况下，玻璃形成组成不在共晶点，而是在富次元素的组成范围内，例如铝 (Al) 和稀土金属的合金（例如，Al$_{80}$Y$_{10}$ 或 Al$_{90}$Gd$_{10}$）。二元合金玻璃只能作为约 0.002 英寸 (50 $\mu$m) 厚的薄箔获得，因为保留玻璃态需要 1.8 $\times$ 10$^{5}$ $^\circ$F/s (10$^{5}$ K/s) 的临界淬火速率。当进一步替代溶质时，稳定性和玻璃形成趋势可以大大增强。三元合金玻璃，例如，钯/铜/硅 (Pd$_{35}$Cu$_{45}$Si$_{27}$)、钯/镍/磷 (Pd$_{40}$Ni$_{40}$P$_{20}$) 和 铂/镍/锡/磷 (Pt$_{50}$Ni$_{25}$Sn$_{25}$P$_{25}$)，已被制备成直径为 0.100 英寸 (2.5 mm) 的圆柱形杆，淬火速率为 1.8 $\times$ 10$^{5}$ $^\circ$F/s (10$^{5}$ K/s) 或更低。参见相平衡。

晶态金属和合金的电气特性同样被很好地理解。金属玻璃中晶体点阵的缺失导致其电性能发生显著变化，并在固体中输运性质的研究中具有理论应用。

金属玻璃的电阻率很高，例如 100 n$\Omega\cdot$cm 或更高，与广泛用作电路中电阻元件的熟悉镍铬合金在同一范围内。金属玻璃电阻率的另一个有趣特性是其随温度变化不大。由于对温度变化不敏感，金属玻璃适用于该特性为基本要求的电子电路应用。

1975 年报告了第一种超导金属玻璃。这是一种含有 80 at. % 镧 (La) 和 20 at. % 金的合金。一些超导金属玻璃只含两种金属，如 Zr$_{72}$Rh$_{28}$，而有些是更复杂的合金，其中含有约 20% 的类金属元素，主要是 B、Si 或 P。继续研究新型超导玻璃的主要原因之一是预测其在高场电磁铁中的实用性，这些电磁铁将用于约束聚变反应堆中的高温等离子体。参见超导性。

金属玻璃的铁磁特性受到了极大的关注，可能是因为这些材料有可能用作变压器铁芯。

在开发从液态快速冷却技术之前，就已经制备了铁磁非晶态合金。NiP 合金的电沉积物在 P 浓度低于 17 at. % 时具有轻微的铁磁性。非晶态 CoP 合金可以在 P 浓度从 18 到 25 at. % 的范围内以非晶态形式电沉积；Co 和 Fe 也是铁磁性的。还在气相沉积薄膜形式的 Co-Au 合金中测量到了铁磁性。这些结果表明，应该可以从含有足够高百分比的铁磁金属的液态合金中获得铁磁金属玻璃。合金元素的选择基于尝试满足原始 AuSi 玻璃的低熔点共晶组成，Fe 是最明显的金属组成选择。
