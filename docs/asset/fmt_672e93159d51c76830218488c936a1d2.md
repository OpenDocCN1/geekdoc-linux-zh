
# 个人数据隐私

个人数据隐私是我们基本权利的核心方面，涉及控制我们个人详细信息（如姓名、位置或在线行为）的共享方式。随着数字交互的增长，保护这些信息以维护在线信任的重要性也随之增加。滥用可能导致欺诈、不希望的营销或压制自由表达，使得数据保护法对于保护我们的隐私免受泄露和滥用至关重要。这关乎确保我们的信息被负责任使用，在日益连接的世界中维护我们的自由和安全。

`Searx` 是一款免费的开源元搜索引擎，通过不共享 IP 地址或搜索历史来优先考虑用户隐私。它阻止跟踪 `Cookie` 并使用 `HTTP POST` 进行查询以增强隐私。受 `Seeks` 启发，`Searx` 提供了网站的直接链接，并带有缓存或代理视图选项。它支持跨多个域搜索，并允许用户运行私人实例或使用公共实例（包括 `Tor` 服务）。`Searx` 从 80 多个引擎获取结果，自定义设置保存在 `Cookie` 中。它还支持特殊搜索运算符以进行更具针对性的查询。

`OpenStego` 是一款免费的基于 Java 的隐写工具，它可以将数据隐藏在图像中并提供水印以保护版权，适用于多种平台。它支持加密以增加额外安全性，使其成为在不改变数字文件外观的情况下隐藏信息或验证所有权的全面解决方案。

`Tor` 是“洋葱路由”（The Onion Router）的缩写，是一种通过全球志愿者中继网络引导互联网流量来实现匿名通信的免费软件。它最初为美国情报的安全通信而开发，现在为数百万用户服务，从监控隐藏用户的位置和互联网使用。尽管其意图是隐私和自由，但 `Tor` 的用途范围从合法活动到非法交易和信息泄漏，引发了关于隐私与安全之间影响的争议。

`i2pd` 是一个用于访问 `I2P` 的 C++ 工具，这种加密网络通过隐藏用户的 IP 地址确保匿名通信。与 `I2P` 不同，`i2pd` 专门专注于路由，不需要 Java，且性能更好。

`Hyphanet` 是一款免费软件，允许在“暗网”模式下进行匿名文件共享、浏览和发布，在该模式下连接仅限于信任的联系人，检测变得困难。用户通过捐赠带宽和存储空间来支持网络，内容的流行程度决定了文件的保留。`ZeroNet` 发布于 2015 年，是一种使用点对点技术的去中心化网络。它实现了开放、免费且不可审查的网站，利用了比特币加密和 `BitTorrent` 协议。`ZeroNet` 网站通过比特币地址识别，使其能够抵抗封锁和审查，即使在中国等限制国家也是如此。它通过 `Tor` 支持匿名，无需中心服务器运行，其内容由用户直接托管，确保了其保持可用并能够抵抗故障。`Hyphanet` 的大量下载量及其对全球分发被审查信息的影响，通过其学术和法律讨论得到了进一步的印证。

## Searx

访问 `Searx` 官方网站 `https://github.com/searx/searx` 了解关于 `Searx` 的一切信息。

在终端通过 `APT` 安装 `OpenStego`：

只需输入以下命令：

更新您的软件包列表：

```bash
sudo apt update
```

安装必要的软件包：

```bash
sudo apt install git rsync make gcc libc6-dev libssl-dev zlib1g-dev libpcre2-dev libevent-dev build-essential zlib1g-dev libpcre2-dev libsqlite3-dev libssl-dev libevent-dev curl wget git libxslt-dev python3-dev python3-babel python3-venv python3-pip
```

准备 `Searx` 环境：

```bash
cd ~/
```

```bash
git clone https://github.com/searx/searx.git
cd searx
python3 -m venv venv
source venv/bin/activate
```

打开 `requirements.txt` 并将任何 `werkzeug` 条目（如果不存在则添加以下内容）替换为 `werkzeug==2.2.2`，然后保存更改。

安装 Python 依赖：

```bash
pip install -r requirements.txt
```

复制默认配置文件并进行自定义：

```bash
cp searx/settings.yml searx/settings_custom.yml
gedit searx/settings.yml
```

根据你的喜好编辑 `settings.yml`，包括更改密钥（`secret key`）。

通过在 `preferences.py` 中将 `advanced_search` 设置为 `True` 来启用高级搜索：

```bash
gedit searx/preferences.py
```

找到 `settings['ui'].get('advanced_search', False)`，并将 `False` 改为 `True`。

保存所有更改并退出编辑器。退出虚拟环境：

使用以下命令启动 `Searx`，将 `username` 替换为你的实际用户名：

```bash
sh -c '/home/username/searx/venv/bin/python /home/username/searx/searx/webap.py'
```

本指南确保你已安装并配置了个人使用的 `Searx`，增强了你的隐私性和对搜索数据的控制。

# Searx.py .desktop 快捷方式

要为 `Searx` 创建桌面快捷方式，首先打开终端并导航到应用程序目录：

```bash
cd /usr/share/applications
```

然后，使用你喜欢的文本编辑器并 `sudo` 权限创建一个名为 `searx1.desktop` 的新文件：

```bash
sudo xed searx1.desktop
```

在 `searx1.desktop` 文件中，输入以下内容，确保将 `username` 替换为你的系统用户名：

```ini
[Desktop Entry]

Type=Application

Name=Searx

Comment=Searx - 尊重隐私的开源元搜索引擎

Exec==sh -c '/home/username/searx/venv/bin/python /home/username/searx/searx/webapp.py'

Icon=terminal

Terminal=false

Categories=Network;WebBrowser;
```

输入详细信息后，保存进度。你可以点击“保存”、使用“文件”菜单选择“保存”，或点击 ≡ 图标选择“另存为”并确认。最后，退出编辑器。

## Tor Browser Launcher

访问 `Tor Browser Launcher` 官方网站 `https://www.torproject.org/` 了解所有关于 `Tor Browser Launcher` 的信息。

- 打开软件管理器并搜索 `Tor Browser Launcher`。
- 点击 `Tor Browser Launcher`，然后点击源选择框。
- 选择系统包（System Package）或 `Flatpak` 并点击安装。

在终端中通过 `APT` 安装 `Tor Browser Launcher`：

只需输入这些命令：

```bash
sudo apt update
sudo apt install torbrowser-launcher
```

在终端中通过 `Flatpak` 安装 `Tor Browser Launcher`：

输入此命令：

```bash
flatpak install flathub org.torproject.torbrowser-launcher
```
