# 磁带驱动

Corel Linux 支持以下磁带驱动：

- 使用固定长度且小于驱动长度块的 SCSI 磁带（在发行源中设置为 `32k`）
- `Iomega Inc. (www.iemega.com)` `DITTO` 内部式（`ftape 3.04c` 及更高版本），所有版本
- `QIC-117`, `QIC-40/80`, 以及 `QIC-3010/3020` (`QIC-WIDE`) 驱动，所有版本

### 终端

Corel Linux 支持串口上的以下终端：

- `VT52`
- `VT100`
- `VT220`
- `VT320`
- `VT420`
