
## 控制结构

`while`, `for` and `for-in`, `repeat`, `select`, and `foreach`。有几种条件结构：`if`, `switch`, and `case`。

### 控制结构：`AND`, `OR` 或 `NOT`

| 命令 | 功能 |
|---|---|
| `command &&` | 逻辑 `AND` 条件在当两个命令都返回真值（0）时，返回真值（0）；如果其中一个命令返回非零值，则 `AND` 条件为假并同样返回非零值。 |
| `command \|\| command` | 逻辑 `OR` 条件在当两个命令中任一个返回真值（0）时，返回真值（0）；如果两个命令都返回非零值，则 `OR` 条件为假并同样返回非零值。 |
| `! command` | 逻辑 `NOT` 条件会反转命令的返回值。 |

### 循环控制结构

`while`, `until`, `for`, `for-in`, `select`

| 命令 | 功能 |
|---|---|
| `while command do command` | 只要其测试命令为真，`while` 就会执行操作。 |
| `until command do command` | 只要其测试命令为假，`until` 就会执行操作。 |
| `for variable in list-values do command` | `for-in` 设计用于值列表；变量操作数会被连续赋值为列表中的值。 |
| `for variable do command` | `for` 设计用于引用脚本参数；变量操作数会被连续赋值为每个参数值。 |

#### 示例

```
select string in item-list
do command
done
```

`select` 根据 `item-list` 中的内容创建一个菜单；然后执行 `command`；`command` 通常是一个 `case` 语句。

### 条件控制结构

`if`, `else`, `elif`, `case`

#### 示例

```
if command then
command
fi

if command then
command
else
command
fi

if command then
command
elif command then
command
else
command
fi

case string in
(pattern)
command;
esac
```

*   `if` 在其测试命令为真时执行某项操作。
*   `if-else` 在测试命令的退出状态为真时执行某项操作；如果为假，则执行 `else` 操作。
*   `elif` 允许你嵌套 `if` 结构，从而在多个备选方案中进行选择；在第一个为真的 `if` 结构处，将执行其命令且控制权将离开整个 `elif` 结构。
*   `case` 将字符串值与多个模式进行匹配；如果匹配到某个模式，则执行其关联命令。

## 作业：后台、杀死与中断

`Z shell` 具有与 `BASH shell` 相同的作业控制功能。命令大大相同。你可以在执行其他命令的同时在后台运行一个作业。你还可以在命令完成执行之前取消它们。你甚至可以中断一个命令，稍后从离开的地方重新启动。

# 运算符

`Z-shell` 拥有一套标准的算术、关系和赋值运算符，这在大多数编程环境中常见，以及用于 shell 函数的运算符（如重定向和后台操作）。

## 变量的定义与评估：`=`, `$`

当你第一次使用变量名时，在 shell 中定义了一个变量。变量名可以是任何字母组合，包括下划线。名称也可以包含数字，但数字不能是名称的第一个字符。名称不能包含任何其他类型的字符，例如感叹号、安培符号甚至空格。这些符号被留给自己使用，因为 shell 使用空格来解析命令，分隔名称和参数。你使用赋值运算符给变量赋值。你输入变量名、赋值运算符 `=`，然后是所赋值的值。注意你不能在赋值运算符周围放置空格。任何字符集都可以赋值给变量。在下一个示例中，变量 `greeting` 被赋值为 `"Hello"`。

```bash
greeting="Hello"
```

一旦给变量分配了值，就可以使用该值来引用它。你通常将变量的值作为命令的参数。要使用变量名前加的 `$` 来引用值，美元符号是一个特殊的运算符，它实际上使用变量名来引用值。因此，无论 `$` 放在变量之前，变量名都会被替换为该值。

## Here：`<<`

## 双引号、单引号与反斜杠：`""`, `''`, `\`

双引号、单引号和反斜杠的操作与 `BASH shell` 中描述的相同，用于引用字符串和字符。（需详细解释，请参见此标题。）

## 反引号：`` `` ``

反引号的操作与 `BASH shell` 中描述的相同，执行包含的命令并返回其值。（需详细解释，请参见此标题。）

## 位置参数：`$`

像 Linux 命令一样，shell 脚本可以接受参数。当你调用脚本时，使用位置参数来引用命令行的不同部分。命令行上的参数从 1 开始顺序编号。第一个参数用 `$1` 引用，第二个用 `$2` 引用，依此类推。`$0` 脚本名称。一组特殊变量允许你共同引用固定数量的参数：`*`、`$@`、`#`。`$$` 参数数量。`*` 也引用命令行上的所有参数，但允许使用 `for-in` 控制结构对每个参数进行单独引用。

| 位置参数 | 描述 |
|---|---|
| `$0` | Linux 命令名称 |
| `$n` | 从 1 开始的第 n 个命令行参数；你可以使用 `set` 来更改它。 |
| `$*` | 从 1 开始的所有命令行参数；你可以使用 `set` 来更改它们。 |
| `$@` | 单独引号的命令行参数。 |
| `#` | 命令行参数的数量。 |

| 进程变量 | 描述 |
|---|---|
| `$$` | 当前进程的进程 ID。 |
| `!` | 最近后台作业的 PID。 |
| `?` | 上一个执行命令的退出状态。 |

## 算术运算符

算术表达式使用与 C 语言几乎相同的语法、优先级和结合性。此处列出的运算符按优先级从高到低分组。优先级可以通过嵌套括号覆盖。

| 运算符 | 描述 |
|---|---|
| `+, -, ~, ++` | 一元正/负、逻辑取反、补码、增、减 |
| `&` | 逻辑 `AND` |
| `^` | 逻辑 `XOR` |
| `|` | 逻辑 `OR` |
| `*, /, %, **` | 乘、除、取余、和幂 |

# 运算符

| 运算符 | 描述 |
|---|---|
| `+, -` | 加法、减法 |
| `<<, >>` | 左移、右移 |
| `<, <=, >=` | 比较 |
| `==, !=` | 等于和不等 |
| `&&` | 逻辑 `AND` |
| `\|\|, ^` | 逻辑 `OR`, `XOR` |
| `?, ;` | 三元运算符 |
| `=, -=, *=, %=` | 赋值 |
| `&=, ^=, \|=, <<=, >>=` | 复合赋值 |

你可以使用 shell 变量作为操作数。以 0 开头的常量被解释为八进制数；前缀 `x` 表示十六进制。将 `#` 运算符放在字符前给出该字符的 ASCII 值。

## 条件表达式

测试命令配合条件运算符测试文件的属性并比较字符串。你可以使用双括号来评估条件表达式，例如 `[[ $myfile > "justin" ]]`。如果为真，则 `[[` 返回 0。

```
[ expression ]
```
