## 报警是否触发了 SNMP 陷阱？

正如你在第 17 节“报警”中所学到的，你可以在 vCenter Server 中设置报警，当 vSphere 环境中发生特定事件时，报警将触发。报警将执行一个或多个动作。用于监控的一种动作类型是触发 SNMP 陷阱。此 SNMP 陷阱将传输到监控服务器，你可以在那里对发生的事件采取适当行动。

但如果你很确定事件已经发生，却从未在监控服务器上收到 SNMP 陷阱呢？
