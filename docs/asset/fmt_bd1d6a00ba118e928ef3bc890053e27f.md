
在整个过程中，最让人苦恼的可能是放弃控制权并仅仅接受外部人士可能实际上更懂行这一事实。另一个困难是在公司中找到一位强有力的技术领导者。这个人必须在两个层面上——技术层面和政治层面——获得所有人的信任。这个人必须能够承认项目从一开始就存在缺陷。与其试图掩盖此类问题，领导者必须能够说服每个人，最好的做法是回头重新开始，这意味着破坏现有成果。这不是人们想听到的信息。然而，来自受人尊敬之人的信息，人们会接受。

鉴于办公室政治的本质和公司的典型运作方式，技术负责人必须是一个性格相当坚定的人。他或她应该是喜欢通过电子邮件工作并且避免选边站队的人。我不会使用“联络员”这个词，因为那暗示这里有两个不同的阵营——内部阵营和外部阵营。而这并不是应该有的状态。这位技术负责人受雇于公司从事开源工作。他或她知道，其他人也知道，这个人不是为了同意公司内同行的观点而受薪，而只是为了执行项目。让领导人与公司关联过于紧密存在风险。人们可能信任他或她的技术能力，但不信任其非技术判断。

这里有外交官吗？

就像“帮我找一个诚实的人”一样。

这就是为什么多年来我一直极力避免与 Linux 公司卷入纠葛。随着资金变得具体化，这一点现在变得越来越关键。随着大量资金在场，人们开始质疑你的动机。对我来说，一直被视为保持中立是有帮助的。你无法想象保持这种中立性对我有多重要。这让我抓狂。

好吧。你是对的，我应该停止说教。开源并非适合每个人、每个项目或每家公司。但人们开始审视 Linux 的成功时，他们越来越多地意识到，这并非那些理想化、未净身的高中生在情绪激动下的胡言乱语。

开放任何事物，可能性就会随之而来。我已经谈论开源的时间之久，堪比记者们询问我此事的时间，基本上就是过去的五年。过去你必须一遍又一遍地解释它有什么伟大之处。坦率地说，这感觉像是一次无尽的跋涉。就像在泥沼中艰难前行。

现在人们明白了。

“名声的负担怎么办？”这是有些人会问我的。让我告诉你，“负担”根本不是负担。出名是有趣的，声称并非如此的名人只是在试图友善，让不出名的人感觉他们过得更好。你应该对名声保持谦逊，并抱怨它如何毁掉你的生活。

但面对现实吧，每个人都梦想着名和财。我知道我也是。十几岁时，我希望成为一名著名的科学家。阿尔伯特·爱因斯坦，但更优秀。谁不这么想呢？如果不是科学家，那就是赛车手。或者是摇滚明星。或者是特蕾莎修女。或者是美国总统。

实际上，达到那里一点也不痛苦。是的，我可能不是阿尔伯特·爱因斯坦，但我对真正产生影响以及做一些有意义的事情感到安心。因此，因这些事获得认可使整件事变得更好。所以，下次当你听到有人抱怨名声和财富时，忽略他们吧。他们这么做只是因为这是你应该做的。

那么，一切都好吗？当然不。广为人知确实有缺点。我不记得有人在街上认出我（或者至少不经常），但我收到的海量电子邮件中偶尔夹杂着一些真的很难回答、也很难忽视的信息。你对一个要求你为从未见过的父亲致悼词的人说什么？我从来没有……

我回复了那封邮件，但我至今仍为此感到些许愧疚。对某个人来说，那是一件非常重要的事，但对我来说，那只不过是个麻烦罢了。

或者，当有人邀请你在一场会议上做主题演讲，而你真的既没时间也没心情时，你该如何告知对方？当你早就不再听电话留言信息时，你如何让别人明白这一点，同时又不显得自己是个没心没肺的混蛋？毕竟，你实际上就是如此。我并非因为自己深刻关心我因 Linux 而闻名的那个议题，就对每一个议题都投入深切的关怀。

当然，久而久之，直接说“不”就变得非常容易。或者干脆完全忽略这些请求；这正是我爱电子邮件的原因之一——它如此便捷且容易被忽略——在我每天收到的几百封邮件中，再多一封有什么大不了？媒介与个人之间的距离是如此遥远，以至于它很少亲近到足以让你因忽视它而感到内疚。这种情况会发生（如上所述），但并不常发生。而且即使你没有忽略它，通过电子邮件说“不”也比当面或通过电话说容易得多。

问题的根本在于人们对名人最终产生的种种期望。而事实显而易见，你不可能满足所有的期望——尽管你感觉自己至少应该去努力尝试。这在一定程度上使得写这本书成了一段相当紧张的经历——试图写一本相对私人的书，同时又不让那些期待得到不同内容的人感到失望。

有些期望简直荒谬可笑。我常有一种感觉，一些人期望我成为一名现代隐士——过着独居、简朴的生活。仅仅因为我认为让 Linux 在网络上开放且免费可用是个好主意，且我没有采用传统的商业软件模式。因此，对于我实际上享受花钱，以及我终于把那辆老旧的庞蒂亚克 Grand Am 升级成了更有趣的东西这一事实，我会变得敏感且带有防御性。

这引出了继“名声负担”之后的第二个问题。即，“成功是否会毁掉林纳斯（和/或 Linux）？”。我会不会变成一个以自我为中心的娇纵混蛋，写书只是因为喜欢看到自己的名字印刷成文，并且这本书能还掉他那辆毫无用处的新车贷款？

答案当然是：会。

毕竟，想象一下一个人，他毕生的哲学就是寻找乐趣并做些有趣的事，然后再加上一些金钱和名声，你期望会发生什么？瞬间变成慈善家？我不这么认为。捐钱给慈善机构这件事，直到大卫在制作这本书的过程中实际提出这个问题之前，我从未想过。我一脸茫然地看着他。“给鲸鱼剃毛”是我脑海中浮现的第一个念头。显然，我生来就不具备承担巨大财务责任的能力。

成功是否改变了他看问题的方式？是的。当只有五十位非常技术性用户时，Linux 与如今拥有 2500 万（或者今天这个数字是多少）普通用户——他们至少偶尔会使用它——时的 Linux 截然不同。同样，Linux 在最初的开发阶段也与现在不同，那时唯一参与开发的人是纯粹因为乐趣和兴趣而为之的人——没有任何如今显而易见的商业利益。

对于林纳斯这个人也是如此。事物在改变，声称并非如此并不会改变事实。Linux 不再是五年前的那个运动，林纳斯也不再是那时的他。让参与 Linux 对我而言如此有趣的一部分原因，恰恰是因为它没有一成不变，而是因为新问题不断涌现。这些不仅仅是技术问题，还涉及在成功面前 Linux 的整体意义如何变化。否则生活将会枯燥乏味。

因此，我更喜欢说商业成功让 Linux 和我都变得“不同”，而不是使用“被宠坏”这个词。我会犹豫说“成熟”——我认为，对我来说，拥有三个孩子在这方面带来的改变要大得多——只是不同。在很多方面更好，但也失去了些许纯粹。Linux 过去只属于技术人员，是极客们的避风港。一个纯粹的要塞，在那里技术至关重要，其他都无足轻重。

如今情况已不再如此。Linux 仍然拥有强大的技术背景，但拥有数百万用户使得每个人都意识到，你在做事时必须更加谨慎。向后兼容性突然成为一个因素——总有一天，二十年后，会有人出现，说足够了，并启动他自称为“Fredix”的新操作系统。没有那些历史包袱。而这正是应有的结果。

但让我格外自豪的是，即使“Fredix”出现，事物也不会再回到从前。退一步说，Linux 所做到的，就是让人们意识到一种做事的新方式，意识到开源实际上如何使人们能够在他人的工作基础上进行构建。开源存在已久，但 Linux 所做的就是将其带入大众意识。因此，当 Fredix 出现时，它将不必从头开始。

就这样，世界变得更美好了一点点。

*庞蒂亚克 Grand Am 并没有什么不对，它是一辆好车。它也可能是美国整个最“普通大众”的汽车，一些记者发现我开这么一辆俗气的车很有趣。它甚至都不是日本车，天哪！当我承认我花了好几个小时纠结于我那辆新车的精确颜色时，人们就会对我失去所有敬意——那是一辆实用得多的宝马 Z3。记住——“只是为了好玩”。那辆车除了好玩之外，完全且绝对毫无用处。而这正是我喜欢它的样子。

*或者，视情况而定，是“Diannix”。再过二十年，希望计算机科学能超越当前男性主导的局面……

在我们开始写这本书近一年后，我和林纳斯在一个周五晚上去了那家我们在几个月前曾互相竞技的赛车/击球练习场。这一次，林纳斯在这两项活动中都击败了我：他开车更快，击球更好。后来，在享用土耳其菜时，我将我糟糕的表现归咎于工作中特别令人沮丧的一天。

他抬头说：“嗯，你得再坚持三个月。”

“为什么？”

“那不是你的第一批股票期权兑现的时候吗？”

我提到这件事的原因是，在我们之前在那家赛车/击球练习场竞技的那个晚上，林纳斯承认，由于他记忆力差，他经常需要托芙提醒他电话号码。突然，他现在记住了别人的期权兑现日程，并能详细复述我第一次向他提起这件事时我们在哪里。一年前，他似乎很享受那种心不在焉的教授角色，对任何比超弦理论或他早期计算机内存容量次要的细节都模模糊糊。现在他变得异常敏锐。

今年一月，我们坐在我那个旧的热浴缸里，我开玩笑说 Marin 历史委员会缠着我把它捐给他们的博物馆。八月时，他随口说：“嘿，你打算什么时候捐出那个热浴缸？”他不需要查阅电子设备来记住 Avuton 来访的日期。他以一年前似乎没有的方式，融入了朋友和同事的个人细节中。事实上，他甚至还知道我的同事在做什么。对于一个开口对我说“实际上，我不太记得我的童年”的人，他似乎突然召集起了记忆：“我告诉过你，当我母亲想让我向祖父索要购买我第一块手表所需额外 100 FM（芬兰马克）时，我有多尴尬吗？”
