# 卷后记

《面向非技术人员的 Ubuntu》(Ubuntu for Non-Geeks) 第二版使用 Adobe FrameMaker 进行排版。使用的字体族包括用于正文的 New Baskerville，标题和表格的 Futura 以及标题的 Dogma。

本书在密歇根州安娜伯市的 Malloy Incorporated 公司印刷并装订。使用的纸张是 Glatelter Thor 60# Smooth，由 15% 的后消费内容制成。本书采用 RepKover 装订方式，使其在打开时可以平放放置。
