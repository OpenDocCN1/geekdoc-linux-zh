### 备用安装 CD 上的选项

图 3-37 显示了从 Ubuntu 安装 CD 启动系统时显示的菜单。

![](img/c20d2eef7a2778ee7a3a4ec5714c4d3c_134_0.png)

备用安装 CD 启动菜单上的选项如下：

- `Install Ubuntu`：使用准图形安装程序向您的硬盘安装基础 Ubuntu 桌面系统。使用此安装程序安装 Ubuntu 桌面系统与安装 Ubuntu 服务器系统非常相似，在本章前面的部分已详细讨论。使用标准安装程序和准图形安装程序安装 Ubuntu 桌面系统的差异将在下一节“在文本模式下安装桌面系统”中讨论。
- `Check disc for defects`：测试当前插入系统的 CD 或 DVD 的完整性，并验证其内容。
- `Test memory`：执行若干内存测试以验证系统的内存和相关缓存。您可以按字母 `c` 显示配置菜单，允许您运行或重新运行测试。完成系统内存测试后，按 `Esc` 重启系统并返回备用安装 CD 启动菜单。
- `Boot from first hard drive`：跳过从备用安装 CD 启动，直接从系统驱动器启动。如果您在不打算安装 Ubuntu 或运行可用系统测试的驱动器中意外插入了备用安装 CD，请使用此选项。
- `Rescue a broken system`：提示输入一些信息，如要显示的语言和地理位置，然后启动从 CD 运行的无磁盘 Linux 版本，可以使用它修复损坏的磁盘、纠正或重新安装 GRUB 引导加载程序等。

#### 提示

如果在进入救援模式时遇到问题，从书中附带的 Ubuntu CD 启动将提供相同的功能，但具有华酷的图形界面。

备用安装 CD 具有可以通过按 `F4` 显示的额外选项，显示图 3-38 所示的弹出菜单。选项如下：

- `Normal`：使用准图形安装程序安装标准桌面系统。
- `OEM Install (for manufacturers)`：使用 Ubuntu 的准图形化安装程序向您的硬盘安装 Ubuntu 系统。与标准安装不同，OEM 模式安装定义了一个 OEM 用户，您可以利用它自定义要分发给终端用户的系统。在自定义系统后，OEM 运行一个简单命令返回 OEM 用户并定义一个标准特权用户。安装 OEM 系统在“以 OEM 模式安装”节中讨论。
- `Install a command-line system`：使用准图形安装程序向您的硬盘安装命令行系统。

安装额外的软件包，根据需要删除软件包，然后将系统重新分发给客户。为了在完成配置后将此系统转换为具有客户特定特权用户的标准 Ubuntu 桌面安装，OEM 应该执行 `sudo oem-prepare` 命令，该命令将删除 OEM 用户，并在下次启动系统时提示客户输入客户特定的用户信息并回答配置问题。

在整个 OEM 安装过程中，屏幕左上角的横幅会标识您正在进行 OEM 模式安装。与其他准通用型安装程序一样，准通用型 OEM 安装程序遵循与本章早些“在文本模式下安装桌面系统”节中讨论的相似系列提示和步骤。由于 OEM 系统是以特权用户 OEM 身份安装的，因此安装过程不会提示您输入用户名和登录信息，而只会要求输入 OEM 用户的密码。随后，OEM 模式安装程序将继续进行标准模式的安装和配置。

在进入最终安装界面之前，OEM 模式安装程序会显示一个汇总了 OEM 模式使用方法的屏幕界面，如图 3-40 所示。

### 安装命令行系统

从备用 CD 的模式菜单中选择“安装命令行系统”，允许您安装一个不包含任何图形化或 X Window 系统应用程序所需软件包的 Ubuntu 桌面系统。这提供了一个占用空间较小的安装，随后可以在其中添加任何您感兴趣的图形化软件包。此安装选项为创建一个小型、高度定制且个性化的基于 Ubuntu 系统提供了一个极佳的起点。从备用 CD 安装命令行 Ubuntu 桌面系统的安装过程与本章“在文本模式下安装桌面系统”节描述的安装标准 Ubuntu 桌面的过程完全相同，区别在于安装的软件包较少。
