# BSD lpr 打印池系统
BSD 打印池守护程序及相关实用程序。你可以将其用于本地和远程打印机。如果你安装了 `mastfilter` 或 `asfilter`（同 `ghostscript`），`lpr` 将自动处理特殊文件类型（如 Postscript 和 PDF 文件）。如果你有 `printers-pp`，`lpr` 将通过 PPD 文件处理特定设备的选项。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# 用于传真调制解调器的实用程序 lpr
提供了一系列脚本和程序，通过 LRPr 打印系统控制网络传真打印池。其目标是允许在任何应用程序中通过 `lpr -Pfax-number` 或名称实现透明传真。功能包括：

- 与 `mgetdy/send` 规范和配置文件的集成
- 在多个传真调制解调器之间进行负载均衡
- 远程队列/日志检查，以及通过 `banner-page` 过滤器生成自定义封页
- 从作业规范中自定义的名称/号码查找
- 通过 `lrpng` 自动修复传真 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

# lpr/lpd 打印池系统
LRPr 软件是 Berkeley LPR 软件（标准 UNIX 打印池）的增强、扩展和可移植版本。你可以将其用于本地和远程打印机。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# LPRng
Berkeley LPR 打印功能的增强、扩展和可移植实现。`LPRng` 提供了相同的接口并满足 RFC1179 要求，但其实现是完全全新的，并支持以下内容：

- 轻量级（无需数据库）的 `lpr`、`lpc` 和 `lrpr` 程序；
- 服务单个队列的打印机动态重定向；
- 客户端程序不需要以 SUID root；
- 高增强的安全检查；
- 大改进的权限和授权机制。

`LPRng` 兼容所有使用 LPR 接口并符合 RFC1179 的打印池和打印机网络。`LPRng` 为 SVR4 `ip` 和 `Lpstat` 程序提供了仿真包，消除了对另一个打印池包的需求。这些仿真包可以相应地修改，以支持旧的打印系统。对于需要安全或身份验证打印支持的用户，`LPRng` 支持 Kerberos V、MIT Kerberos IV 打印以及 PGAuthentication。额外的认证支持非常简单。Red Hat 8.0 RPM `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

# lprng
LPrng 的 GUI 前端 `/etc/printcap` LPrngTool 是一个用于在 LPrng 系统上配置 `/etc/printcap` 的图形化工具。它基于 Red Hat 的，但增加了许多新功能。它支持配置本地、远程、SMB、JetDir 和原始打印机及队列。它支持许多队列管理功能，例如：

- 暂停/重打印错误作业
- 查看远程打印机的能力
- 删除作业
- 作业重定向
- 停止或开始队列、打印或两者兼具。来自 Debian 3.0rt `http://www.tldp.org/LDP/Linux-Dictionary/index.html`
