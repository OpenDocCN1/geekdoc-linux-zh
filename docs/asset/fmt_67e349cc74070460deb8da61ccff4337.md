
此模块的设置为运动障碍用户方便使用键盘。该模块由“基本”、“过滤”和“鼠标”三个选项卡组成。在修改设置之前，激活“启用键盘辅助功能”。

开启粘滞键 某些快捷键要求在输入快捷键其余部分时，保持按住某个键（这适用于 Alt、Ctrl 或 Shift）。当使用“粘性”键时，系统会在按下一次按键后将这些键视为已按下状态。为了在每次按下修饰键（Ctrl 或 Alt）时提供听觉反馈，请在按下修饰键时激活“哔哔”。如果勾选“两个键同时按下时禁用”，则在同时按下两个键时，这些键将不再粘滞。系统随后认为快捷键已完全输入。

重复键 激活“重复键”可以为滑块设置“延迟”和“速度”。这决定了必须按住键多长时间才能激活自动键盘重复功能，以及随后将以多快的速度输入字符。

在对话框窗口底部的字段中测试设置的效果。选择反映你正常打字习惯的参数。

开启慢键 为了防止意外输入，设置一个最小限制，即键在被系统识别为有效输入之前必须按下并保持的时间。还决定了是否为按键事件、接受的按键和拒绝的按键提供听觉反馈。

开启弹跳键 为了防止双击输入，设置一个最小时间限制，以接受同一键的两个后续按键事件作为两个独立字符的输入。如果需要，在拒绝按键事件时激活听觉反馈。

切换键 可以在按下键帽修饰键时请求系统提供听觉反馈。

鼠标 激活键盘鼠标 — 鼠标指针由数字小键盘上的方向键控制。使用滑块设置鼠标指针的最大速度、达到最大速度所需的加速时间，以及按下按键与光标移动之间的延迟。

## 6.2.10 快捷键

使用此模块管理全局键盘组合键。可以确定文本输入期间以及桌面对象上使用的键盘组合键。

列表概览窗口显示所有当前可用的操作列表及其快捷键。通过点击相应的快捷键条目来禁用或更改快捷键。然后输入新快捷键或使用 `(Delete)` 删除当前快捷键。所有更改将立即生效。通过点击其条目并点击“关闭”退出对话框来恢复当前快捷键。

## 6.2.11 声音（系统警报）

此模块允许某些系统事件和应用程序警报与特定的音频信号关联。对话框包含两个标签页（“常规”和“声音事件”）。必须激活“常规”标签页中的两个复选框以便对某些桌面事件使用音频信号。

在第二个标签页中，确定哪些事件和应用程序警报应该与哪些声音关联。列出了所有已为应用程序定义的关联。先选择“事件”列中相应的通知，然后点击“播放”来测试声音。通过点击“事件”然后点击“浏览”来更改声音。出现的对话框提供了供选择的文件列表。点击“确定”关闭它。

### 6.3.1 在 Nautilus 中导航

Nautilus 的导航行为与大多数浏览器相似。通过右键点击桌面的空白区域然后选择“新窗口”来打开新窗口。或者，双击个人文件夹。

### 6.4.2 使用 File Roller 管理存档

在 GNOME 中，使用 File Roller 管理文件存档。此应用程序适用于以下类型的存档：`.tar`, `.tar.gz`, `.tgz`, `.tar.bz`, `.tar.bz2`, `.tar.z2`, `.zip`, `.lha`, `.rar`, `.lzh`, `.ear`, `.jar` 和 `.war`。可以使用 File Roller 轻松查看存档内容，File Roller 支持拖放，无需解压存档。

允许你从桌面或文件管理器（Nautilus）将文件图标拖入 File Roller（压缩管理器）对话框并释放此处。

要创建一个新的压缩包，选择“压缩(Archive)”->“新建(New)”。在下一个对话框中，在左侧窗口选择创建压缩包的目录。在扩展名下方的输入框中输入新压缩包的文件名。通过主字段上方的下拉菜单确定压缩类型。点击“确定(OK)”退出对话框并返回 File Roller 的主视图。现在，你可以通过从桌面或文件管理器拖拽插入文件，或者选择“编辑(Edit)”->“添加文件(Add Files)”来向压缩包添加文件。在随后的对话框中，选择一个或多个文件（按住 Ctrl 键可以选择多个文件）或目录。如有必要，可以为压缩包确定以下高级选项：

- 如果更新则添加（Add if newer）：压缩包中已包含同名文件，只有当该文件比包中现有文件较新时才会添加。
- 包含子文件夹（Include subfolders）：要压缩整个目录，请激活此选项以包含所有子目录。
- 排除备份文件 (*）：在创建压缩包时禁用包含备份副本，以避免产生不的数据垃圾。
- 排除隐藏文件 (*)：通常，隐藏文件不包含任何与用户相关的数据。默认情况下，它们不会包含在压缩包中以减少数据量。
- 排除文件（Exclude files）：明确从压缩包中排除某些文件。如果你想压缩整个目录但排除某些文件，此选项非常有用。除了文件名，你还可以指定搜索模式。
- 忽略大小写（Ignore case）：File Roller 会忽略文件名和扩展名的不同拼写，例如 JPEG 或 jpeg。

完成选择和配置后，退出对话框。创建的压缩包可以在指定位置进一步处理。要解压压缩包，将其加载到 File Roller，点击“编辑(Edit)”->“解压到(Extract to)”并指定目标目录。
