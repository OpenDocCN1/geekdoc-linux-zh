## Vim 概述

Vim 是一个强大的跨平台编辑器，许多计算机专业人士用它编写计算机程序和文本文档。（Vim，如图 8-3 所示，是 Visual editor 的缩写）。与目前介绍的编辑器不同，你不需要通过菜单使用 Vim 编辑器。然而，可以使用相同的编辑选项和功能。
