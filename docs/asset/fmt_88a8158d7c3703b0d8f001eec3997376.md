# 心理语言学

心理学是一个源自语言学的研究领域，关注语言的问题。心理学家长期以来对语言领域感兴趣，而且语言学是一门比心理学更古老的科学；这两个领域的科学家自 20 世纪 50 年代以来一直努力解码人类。乔姆斯基的工作改变了这个领域，让心理学家充分意识到他们对语言结构缺乏知识，以及尝试这种尝试是徒劳的。因此，心理学家自 20 世纪 60 年代以来一直尝试更好地理解人类语言抽象规则如何通过语音音频介质从人向人地传递有意义的信息。研究还涵盖了语言的演化发展、语言的生物学基础和神经系统；句法、意义的规则以及语言学习的过程。

心理学研究人类行为和心理过程。心理学深受应用研究和实验研究的影响。研究和应用心理学中代表了许多领域。

心理学研究人员研究广泛的领域。认知研究通常被包含为主观认知研究以及中央心理过程如何运作、大脑与思维的关系，以及翻译系统如何将物理规律转化为认知科学，这源于科学、认知心理学、心理心理；语言学、神经心理学和人类学的共同基础。人类注意的研究是处于所有领域中心的认知科学。

社会心理学涉及个体与群体之间的互动，以及群体对个人、态度和行为的影响。心理学领域处理社会背景下的从众性、权威、偏见、说服和决策问题。

发展心理学有三个分支：终身发展、儿童发展和老年。该领域的大多数研究集中在能力、社会关系和情感发展上。

心理学家通常被称为心理学家（psychologist）；精神分析学家是精神分析治疗的专家，许多心理学家经医学考评委员会认证为精神分析学家。精神分析学家并不都是精神分析学家。

神经心理学家是具有实验或临床背景的心理学家，但他们并不作为心理学家认证。他们用临床神经学方法治疗脑损伤个体。

临床心理学家在咨询中与客户、群体工作，并在诊所或与健康专业团队合作。专业心理学家在各种环境中工作，解决从压力危机、物质滥用到精神症和严重精神障碍的问题。

法庭心理学工作涉及人类因素，这些因素适应于机器与其人类操作之间的接口设计。它处理软件和硬件计算机设计。工业心理学也包括涉及管理组织和咨询的人员。

在法庭心理学中，法律基于心理学的自然结果。心理学家参与了陪团选择、证据组织、证人证言以及法庭案件。法庭心理学家和心理学家也被要求诊断潜在的精神障碍以及是否有受审能力。

## 热电性（生物学）

电极化是一种由温度变化引起的生物学过程。热电性基本上是所有生物体的物理性质。最早于1966年发现，此后已证明存在于许多植物和动物组织及单个细胞中。

热电性在生物体过程（形态发生和生理功能（如感觉感知））的发展中起着基础性作用。

生物（以及非热电）结构的元素组成部分（例如分子）具有永久偶极矩，或者其排列使得所有的偶极矩都指向一个方向而非相反方向。

热解是指化合物通过热量转化为一个或多个产物的过程。这种定义通过加热催化剂或在无氧的情况下被排除在外。

$CaCO_3 \xrightarrow{1200^\circ C} CaO + \frac{1}{2}CO_2$ (2)

热解也发生在其他有机材料和固体中。碳酸盐挥发物的热分解或煅烧是制造碳铁的基本方法。

自发热电性取决于温度；此时，偶极矩的变化会导致极轴末端电荷的变化。所有热电结构也具有热电性，但反之不然。

“热解”一词通常与有机化合物的反应相关。植物和动物结构材料的热解为组成提供了一些最早的线索，正如从橡胶分解中形成碳一样。

通过热解产生包括萘、吡啶和许多其他有机化合物在内的丰富物质。这些热解过程导致了具有来源特征且具有高碳含量的挥发性产物的形成。

热电性的要求是：(1) 分子聚集体中存在偶极矩以及(2) 形成尽可能对齐（或至少不阻碍其）形状的分子簇。

这两个条件很容易被自由分子或板状分子满足。例如，永久偶极矩可以具有不对称的分子结构。

热解反应被用作制备方法，用于生成可以观察或通过光谱观察的中间体，或为了各种目的对其进行淬灭。

具有这些分子性质的重要有机物包括动物和植物的表皮，特别是神经系统和骨骼系统的膜中。

生物体能够探测并区分环境中的不同动物，例如辐射变化、照明温度和单轴压力。这些刺激代表了不同形式的能量，并被转导、转换为正常的反应类型。在600-800 °C (1100-1500 F)，大多数有机化合物获得足够的能量导致化学键断裂并形成自由基。烷烃发生氢（C-H）键和碳（C-C）键的断裂形成自由基，自由基基通过重组产生较低的烯、烷烃和高分子化合物[3]。
