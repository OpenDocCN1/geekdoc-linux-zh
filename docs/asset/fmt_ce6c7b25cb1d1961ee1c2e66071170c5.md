## 居氏温度 电密度

**居氏温度** 铁磁性或铁磁性材料的关键有序或无序温度。居氏温度 `T` 是指在该温度以下，在没有外磁场的情况下存在自发磁化 `M`，而在该温度以上，材料呈现顺磁性。

虎果科醋属（`*Ribes*`）的一种植物。栽培的黑醋、红醋和和醋果都属于醋果，但该属也包括带有刺的果实或非醋果类的果实。

在高于居氏温度的无序状态下，热能足以克服磁矩之间的任何相互作用。在居氏温度以下，这些相互作用占主导地位，导致磁矩沿优选方向对齐。

**醋果** 在美国主要为了果实而种植，但醋果在花园和制作果胶中很受欢迎。红色品种，包括黑醋和红醋果（`*Ribes*` 物种）也被用作灌木。欧洲的黑醋品种（`*R. nigrum*`）广泛用于商业榨汁。野生品种可食用，但有些并不美味，另一些在果实非常充足时有时会被采集。

在铁磁性情况下，随着 `T` 从下方增加，自发磁化减少到 `T = 0` 时的 `M_s`。此时，随着温度升高，磁化强度降低直到达到居氏温度。

电流平衡基于安培电路，该电路指出沿闭合路径周围的磁力等于通过该路径的互联电流之和。电流平衡通过不同匝数的绕组来测量两个电流的比率，使得绕组周围的磁力恰好等于电流和的倒数。

**反铁磁性** 在尼尔温度以下，磁性子点格变得有序。在尼尔温度以上，材料呈顺磁性。

**居氏-韦斯** 一种关于磁化率以及铁磁体、反铁磁体、铁电体和反铁电体变成它们的温度的关系式。居氏-韦斯定律描述了顺磁材料向铁磁材料转变区域的行为。

> `χ = C / (T - θ_C)`

`C` 是常数，`T` 是绝对温度，`θ` 被称为居氏温度。对于反铁磁体，居氏-韦斯定律指的是从顺磁到材料转变附近的磁电行为。它并不总是完美的，在过渡温度附近的区域会失效。否则，磁化率将随不同的 `C` 和 `θ` 值变化。
