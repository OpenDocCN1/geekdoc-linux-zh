
# PostgreSQL 的 GUI 前端工具

安装 PostgreSQL 后，你可能想要安装其他软件包和工具（如 GUI 前端）来开始使用数据库系统。浏览器将是未来最流行的 GUI 前端。大部分代码应该使用 Web 服务器脚本（及编译）语言 `PHP+Zend` 编译器、`HTML`、`DHTML`，并在 Web 客户端使用少量 `JavaScript` 和 `Java-Applets`。建议将你的旧版 `Windows 95/NT` 迁移到 `PHP+Zend` 编译器。

按偏好排序的最佳工具有：

- `PHP+Zend` 编译器处的 `PHP` 脚本和 `Zend` 编译器
- 支持 `C++`、`Java` 和 `MFC` 的 `X-Designer`，地址：`http://www.ist.co.uk/xd`
- 适用于 `Windows95` 和 `UNIX` 的 `Qt`，地址：`http://www.troll.no` 和 `ftp/ftp.troll.no`
- `Linux` `CD` 盘上的 `Code Crusader`，基于 `MetroWorks Code Warrior` 的免费软件，地址：`http://www.kaze.stetson.edu/cdevel/code_crusader/about.html`
- `MetroWorks` 的 `Code Warrior`，地址：`http://www.metrowerks.com`
- 来自 `(RedHat) Cygnus` 的 `GNU Pro C++ IDE`，地址：`http://www.cygnus.com`
- 适用于 `Linux` 的 `Borland C++ Builder`，地址：`http://www.inprise.com`
- 适用于 `Linux` 的 `Borland Java JBuilder`，地址：`http://www.inprise.com`

按偏好排序的语言选择有：

- `PHP` Web 服务器脚本、`HTML`、`DHTML` 以及 `Javascript` 客户端脚本和 `Java Applets`
- 使用 `Perl-Qt` 或 `Perl-Tk` 的 `Perl` 脚本语言数据库接口

在流行的 `C++` (`GNU g++`) 语言中：

- `Fast CGI`（用 `GNU C++` 编写）配合 `Javascript/Java Applets` 作为 `Web-GUI` 前
- `GNU C++` 和 `QtEZ` 或 `QT`
- 带有 `Lesstiff` 或 `Motif` 的 `GNU C++`
- `Java` 语言，但其程序运行非常慢（比 `C++` 慢 20 倍！）且需要许可费。

其他可用工具：`PostgreSQL` 分发中包含一个名为 `pgTcl` 的 `Tcl/Tk` 接口库。参见：

- `Lesstiff Motif` 工具：`ftp/ftp.redhat.com/pub/contrib/i386/lesstiff*.rpm`
- `Tcl/Tk`：`http://www.scriptics.com`
- `Tcl` 的对象对象扩展名为 `INCR`：`http://www.tcltk.com`
- `Java FreeBuilder`：`ftp://ftp.redhat.com/pub/contrib/i386/free*.rpm`
- `SpecTCL`：`ftp://ftp.redhat.com/pub/contrib/i386/spec*.rpm`
- 用于 `PostgreSQL Kanchenjunga` 的 `Java RAD` 工具：`http://www.man.ac.uk/~whaley/kj/kanch.html`

# ODBC、JDBC 和 ODBC 驱动程序

`PostgreSQL` 用户可能会要求 `DBA` 安装 `ODBC`、`UDBC` 等数据库访问驱动程序。`ODBC`（开放数据连接）由微软建立，是访问来自不同供应商数据库信息的流行标准。使用 `ODBC` 驱动程序编写的应用程序保证可以在 `PostgreSQL`、`Oracle`、`Sybase`、`Informix` 等各种数据库上运行。

- `PostODBC` 已包含在分发版中，位于 `PostgreSQL CD` 盘上。访问主网站：`http://www.postgresql.org`。
- `Open Link Software Corporation` (`http://www.openlinksw.com`) 正在销售 `PostgreSQL` 及其他数据库的 `ODBC`。`Open Link` 还提供免费的 `ODBC`（限制席）——去查看一下。
- 用于 `PostgreSQL` 的 `Insight ODBC` (`http://www.insightdist.com/psqlodbc`)。这是官方 `PostODBC` 站点。
- `FreeODBC` 软件包 (`http://www.ids.net/~bjepson/freeODBC/`)。这是 `ODBC` 的免费版本。

`ODBC` 是 `ODBC` 的静态版本，不依赖于驱动程序管理器和 `DLL`，用于将数据库连接性直接嵌入到应用程序中。

- `Open Link Software Corporation` (`http://www.openlinksw.com`) 正在销售 `PostgreSQL` 及其他数据库的 `UDBC`。`Open Link` 还提供免费的 `UDBC`（限制席）——去查看一下。

`Java` 是一种由微软开发的平台无关语言。鼓励 `Java` 程序员使用 `JDBC`（`Java` 数据库连接）编写应用程序，以便在 `PostgreSQL`、`Oracle`、`Informix` 等数据库之间迁移。如果你编写 `Java` 应用程序，可以从以下站点获取 `PostgreSQL` 的 `JDBC` 驱动程序：

- `JDBC` 驱动程序已包含在 `PostgreSQL` 分发版中：`postgresql-jdbc*.rpm`
- 适用于 `PostgreSQL` 的 `Java` 连接：`http://www.demon.co.uk/finder/postgres/index.html`
- 微软的 `Java` 连接性：`ftp://ftp.ai.mit.edu/people/rst-jdbcbc.tar.gz`
- `Open Link Software Corporation` (`http://www.openlinksw.com`) 正在销售 `PostgreSQL` 及其他数据库的 `JDBC`。`Open Link` 还提供免费的 `JDBC`（限制席）——去查看一下。
- `JDBC` 站点，地址：`http://www.retep.org.uk/postgres`
- `JDBC FAQ` 站点，地址：`http://eagle.eku.edu/tools/jdbcbc/faq.html`

`JDBC` 首页、指南和 `FAQ` 位于：

- `JDBC HOME`：`http://splash.javasource.com`
- `JDBC` 指南：`http://splash.javasource.com`
- `JDBC FAQ`：`http://splash.javasource.com`

通过在同一个 `Perl` 脚本中连接到不同供应商的两个数据库，可以获得类似的优势；例如，我想从 `Oracle` 数据库读取数据并将其插入 `Informix` 数据库，而所有操作都在一个程序内完成。`DBI` 层允许让你简单且强大地实现这一目标。
