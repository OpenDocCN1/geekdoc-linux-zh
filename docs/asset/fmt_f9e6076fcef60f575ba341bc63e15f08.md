
如果 `history` 变量未设置，C shell 只保存最近的 200 条命令。使用 `!` 开始历史替换（尽管你可以通过 `histchars` 变量更改此字符）。`!` 可以出现在命令行的任何位置；历史替换不会嵌套。包含历史替换的行会在终端上回显，但在其他替换发生或命令执行之前，它们会被扩展。

### 事件标识符

事件标识符是历史列表中命令项的引用。

- `!` 开始历史替换，除非后面是空格、Tab、换行符、`=` 或 `(`。
- `!!` 引用上一个命令。通过此替换重复上一个命令。
- `!n` 引用第 `n` 条命令。
- `!-n` 引用倒数第 `n` 条命令。
- `!str` 引用以 `str` 开头的最新命令。
- `!?str` 引用包含 `str` 的最新命令。
- `!h` 删除尾部路径部分，保留头部。
- `!r` 删除 `.xxx` 格式的后缀，保留基名。
- `!e` 删除后缀以外的所有内容，保留扩展名。

## history, fc

`s/oldchars/replacements` 对 `oldchars` 进行替换。`oldchars` 是字符。

- `t` 引用路径部分，保留尾部。
- `g` 应用于第一个匹配。
- `p` 打印上一个命令。
- `q` 引用命令但不执行。
- `/` 使用命令行。
- `^` 引用从开始的命令行。
- `$` 引用从结束的命令行。
- `!` 引用从开始的命令行。
- `!n` 引用第 `n` 条命令。
- `!-n` 引用从结束的第 `n` 条命令。
- `!str` 引用以 `str` 开头的命令。
- `/` 替换字符串的首次出现。
- `//` 替换字符串的所有出现处。
- `/?` 替换字符串的最后一次出现。
- `/^` 替换从开始的字符串。
- `/$` 替换到结束的字符串。
- `/str` 替换字符串 `str`。
- `/?str` 替换从结束的字符串 `str`。
- `/^str` 替换从开始的字符串 `str`。
- `/$str` 替换到结束的字符串 `str`。
- `#` 将字符串替换为空

## 命令重入

从终端设备输入的最后 `HISTSIZE`（默认128）条命令文本保存在文件中。如果没有设置 `HISTFILE` 变量或文件不可写，使用 `$HOME/.sh_history` 文件。shell 可以访问使用相同 `HISTFILE` 名称的所有交互式 shell 的命令。特殊命令 `fc` 用于列出或编辑此文件的部分。可以通过编号或提供起始和结束部分来选择要编辑或列出的文件部分。如果你指定编辑器程序作为 `fc`，则使用 `FCEDIT` 的值。如果 `FCEDIT` 未定义，则使用 `/bin/ed`。离开编辑器后，编辑后的命令将打印并重新执行。编辑器名称 `-` 用于跳过编辑阶段，并使用 `old=new` 格式的参数在执行前修改命令。例如，如果 `r` 别名为 `fc -`，那么输入 `r bad=good` 将重新执行以字母 `c` 开头的最新命令，将字符串 `bad` 替换为字符串 `good`。

在组合中使用 `fc` 命令从历史文件中删除整个命令。

## 选项

- `-e` 使用名为 `editor` 的编辑器编辑命令。编辑器字符串是一个命令名，取决于 `PATH` 变量。当你没有指定 `-e` 时，使用 `FCEDIT` 变量的值作为默认。如果 `FCEDIT` 为空或未设置，则使用 `ed` 作为编辑器。
- `-h` 显示不带前导数字的历史。使用此选项产生的文件可以通过 csh 内建命令的 `-h` 选项进行加载。
- `-l` 列出命令而不是对它们调用编辑器。按照第一个和最后一个操作数的顺序写入命令（受 `-r` 影响），每个命令前都有命令编号。
- `-n` 在使用 `-l` 时抑制命令。
- `-r` 反转列出（-i）或编辑命令的顺序。
- `-s` 在不调用编辑器的情况下重新执行命令。

### 操作数

`first last` 选择要列出或编辑的命令。可以访问的之前的命令数量由 `HISTSIZE` 变量的值决定。`first` 或 `last` 或两者都取以下值之一：

- `-` `+number` 一个正整数，表示命令编号；你可以使用 `-l` 选项显示命令编号。
- `-` `number` 一个负的十进制数，表示之前执行的命令。例如，`-1` 是上一个命令。
- `-` `string` 一个字符串，表示最近进入的、以该字符串开头的命令。如果你没有使用 `-s` 指定 `old-new` 操作，则第一个操作数的字符串形式不能包含嵌入的符号。
- `-` `old=new` 用字符串 `new` 替换要重新执行的命令中第一个出现的 `old`。

当你在配合 `-s` 使用概要形式时：

- 如果省略了 `first`，则使用上一个命令。在概要形式中，当指定 `-1` 时，`last` 形式默认为上一个命令；否则，默认为 `first`。
- 如果你省略了 `first` 和 `last`，则列出之前的 16 条命令或编辑之前的单个命令（基于 `-l` 选项）。
- 如果你指定了 `first` 和 `last`，则编辑从 `first` 到 `last` 的所有命令。在编辑多个命令时，编辑器每次会显示所有命令，每个命令从新行开始。如果 `first` 代表比 `last` 更新的命令，则命令将按反序列出或编辑，等同于使用 `-r`。例如，第一行的以下命令等于第二行的相应命令：

```
fc -r 10 20
fc 30 40
fc 20 10
fc -r 40 30
```

当你使用命令范围时，可以指定不在历史列表中的 `first` 或 `last` 值；`fc` 会根据情况将其替换为列表中代表最旧或最新命令的值。例如，如果历史列表中只有 10 条命令（编号为 1 到 10），以下命令将列出并编辑所有 10 条命令：
```
fc -l
fc 1 99
```

## 输出

当你使用 `-l` 选项列出命令时，列表中每个命令的格式如下：
```
line-number command
```

如果你同时指定了 `-l` 和 `-n` 选项，每个命令的格式为：
```
"\t%s\n", command
```

如果命令包含多行，第一行之后的行显示为：
```
"\t%s\n", continued-command
```

```
7 history

date
Mon Jan 18 17:53:34 WST 1999
castle$ !5
du
262 ./SCCS
336
castle$ !ls ma*
ls -t malloc.c
malloc.o
malloc.c
```
