## `free` 命令

`free` 命令用于显示 Linux 系统上的可用内存和交换空间量。以下是该命令的详细描述，它显示：

- `total`：上的物理内存总量；
- `used`：系统当前使用的内存；
- `free`：当前空闲内存；
- `shared`：进程间共享的内存；
- `buffers`：系统存储临时数据的内存；
- `cache`：系统存储缓存内存；
- `available`：可用于新操作的内存，包括空闲、缓冲区和缓存。

`free`

此命令的输出如下：

```
total used free shared/cache available
Mem: 2047112 324340 1486508 7572 236264 1599672
Swap: 2097148 0 2097148
```

第一行显示物理内存总量、使用量和新操作可用内存。数字以字节 `kB` 为单位。

通过带选项使用 `free` 命令，你可以自定义输出以显示你需要的信息。是一些常用选项：

- `-h`：以人类可读格式显示数字，这意味着以兆字节 `MB` 或吉字节 `GB` 而不是字节 `kB`
- `-s`：按固定间隔显示信息，`SEC` 是每次显示之间的秒数；
- `-t`：在输出底部显示每列的总计行。

例如，这里是使用 `-h` 选项使用 `free` 命令的方法：

```bash
free -h
```

这是一个示例输出：

```
total used free shared/cache available
Mem: 2.0G 335M 1.4G 7.4M 232M 1.5G
Swap: 2.0G 0B 2.0G
```

这一次，数字是以千字节 `GB` 而不是千字节 `kB` 表示的，这使得显示的信息更容易阅读和理解。

总而言之，"`free`" 命令是一个监控 Linux 系统上可用 RAM 和交换空间 `swap space` 的实用工具。通过适当选项，你可以自定义输出以显示你所需的信息，并以更易读的格式显示。这对于监控系统性能以及确定是否需要升级内存非常有帮助。

### 关于交换内存的提醒

`Swap` 行代表用于内存交换的存储空间。交换空间是操作系统用于临时存储当前不在随机存存储器 `RAM` 中使用的数据的存储空间。当 `RAM` 满时，操作系统可以将非活动数据从 `RAM` 移动到交换空间，从而为活动数据释放 `RAM` 中的空间。

交换空间通常是专门为此目的预留的文件或磁盘分区。`free` 命令的 `Swap` 行显示了已用交换空间的大小以及可用交换空间的大小。

然而，使用交换内存会显著降低系统性能，因为硬盘访问速度远慢于 `RAM` 访问。因此，监控系统上的可用内存量非常重要，并在必要时计划内存升级，以避免过度使用交换内存。

总而言之，交换内存是操作系统用于存储 `RAM` 中未活动使用的数据的临时存储空间。虽然它可以帮助释放 `RAM` 空间，但过度使用交换内存会导致由于硬盘访问缓慢而引起的系统变慢。

你是一个 Linux 服务器的系统管理员，你需要使用 "`free`" 命令检查系统上的内存使用情况。你必须执行以下任务：

- 以 `KB` 为单位查看内存信息，包括系统使用的内存、用户可内存以及系统内存总量。
- 以 `GB` 为单位显示内存信息。
- 检查系统内存是否不足，如果是，则确定需要多少额外内存。

修正后：

要以 `KB` 为单位查看内存信息，只需只需输入不带任何参数的命令 "`free`" 。以下是一个示例：

```
free
total used free shared buff/cache
Mem: 4045388 2201744 816636 1013008 128334
Swap: 2097148 317224 1789924
```

在这个示例中，我们可以看到系统内存总量为 `4045388 KB`，其中 `2201744 KB` 正在使用，而 `816636 KB` 是可用的。

要以 `MB` 为单位显示内存信息，你可以使用 "`-m`" 选项。以下是一个示例：

```
free -m
total used free shared buff/cache
Mem: 3952 2154 797 20 89
Swap: 2047 310 1747
```

在这个示例中，我们可以看到系统内存总量为 `3952 MB`，其中 `2154 MB` 正在使用，而 `797 MB` 是可用的。

要以 `GB` 为单位显示内存信息，你可以使用 "`-g`" 选项。以下是一个示例：

```
free -g
total used free shared buff/cache
Mem: 3 0 0 1
Swap: 2 0 1
```

在这个示例中，我们可以看到系统内存总量为 `3 GB`，其中 `0 GB` 正在使用，而 `0 GB` 是可用的。

要确定系统内存是否不足，你可以检查 "`free`" 命令输出中 "`available`" 的值。如果可用内存接近于零，说明系统内存不足，可能会观察到性能下降。在这种情况下，你可能考虑添加物理或虚拟内存。

例如，在本次练习使用的 "`free`" 命令输出中，用户可用的内存量为 `816636 KB`，这对于大多数任务都是足够的。如果 "`available`" 的值低得多，将表明系统内存不足，可能会观察到性能下降。

此外，你还可以通过 "`free`" 命令检查使用的交换内存量。如果使用的交换内存量接近限制，这可能表明系统内存不足，可能需要添加额外内存。例如，在本次练习使用的 "`free`" 命令输出中，使用的交换内存量为 `317224 KB`，约占系统可用总交换空间的 `15%`。如果使用的交换内存量更接近限制，也将表明系统内存不足，可能会观察到性能下降。

最后，需要注意的是，内存使用情况取决于运行在系统上的应用程序和工作负载。因此，定期监控内存使用情况非常，以确保系统有足够的资源来正常运行。 "`free`" 命令可以用于此类监控，并确定是否需要调整内存。

## `kill` 命令

`kill` 命令用于向运行在 Unix 类系统上的进程发送信号。信号可以请求进程干净地退出，也可以在进程无响应时强制终止。

这里是 `kill` 命令的通用语法：

`kill [-s signal] PID`

- `-s signal`：（可选）指定要发送给进程的信号。如果没有指定信号，默认将发送 `SIGTERM` 信号。
- `PID`：要发送信号的进程的进程标识符 `PID`。

有几种可以使用 `kill` 命令发送的可用信号，例如 `SIGTERM`、`SIGKILL`、`SIGSTOP` 等。最常用的信号是 `SIGTERM` 和 `SIGKILL`。

- **SIGTERM**：此信号用于请求进程干净地退出。进程接收此信号后，可以在终止前执行清理操作或保存数据。
- **SIGKILL**：此信号用于强制立即终止进程。此信号无法被进程拦截或忽略，因此通常用于杀死无响应或崩溃的进程。

`kill` 用于停止在 Linux 系统上运行的进程。该命令以你想要停止的进程 ID 作为输入。

`kill -s SIGTERM 12345`

此命令将向 `PID` 为 `12345` 的进程发送 `SIGTERM` 信号，要求该进程干净地退出。命令 `kill -SIGTERM` 的作用方式与 `kill -15` 相同，因为它也会向指定 `PID` 的进程发送 `SIGTERM` 信号。然而，使用缩写形式 `kill -15` 更常见。

`kill -s SIGKILL 12345`

`kill -s SIGKILL` 命令的效果与 `kill -9` 相同，通过立即强制停止进程，而不给予其退出或释放资源的机会。

## `ps` 命令

`ps` 显示 Linux 系统上运行的进程列表。此命令用于监控进程状态并确定哪些进程消耗了大量的系统资源。

以下是 `ps` 使用的选项：

- `-A` 或 `-e`：显示系统上的所有进程，包括其他用户的进程。
- `-f`：显示扩展格式，包括执行的命令名称、进程所有者名称、CPU 时间等。
- `-u`：显示每个进程的 CPU 和内存使用信息。
- `-p PID`：使用标识符 `PID` 显示特定进程的信息。
- `-H`：以树形式显示进程，显示进程间的父子关系。

`ps -ef`

此命令将显示系统上运行的所有进程列表，并带有扩展格式，包括执行的命令名称、进程所有者名称、CPU 时间等。

查找系统上所有属于用户 `john` 的进程的 `PID` 和总 `CPU` 时间。你可以使用以下选项来实现：

`ps -u john -o pid,pcpu=CPU_TIME --sort=-pcpu | head`

解释：

- `-u john`：仅显示属于用户 `john` 的进程。
- `-o pid,pcpu=CPU_TIME`：指定输出中显示的列。在这里我们显示进程标识符 `PID` 和每个进程的总 `CPU` 时间。我们还将 `pcpu` 列重命名为 `CPU_TIME` 以提高可读性。
- `--sort=-pcpu`：按总 `CPU` 时间对进程进行倒序排序。
- `head`：仅显示找到的前 10 个进程。

这将得到类似以下的结果：

```
PID CPU_TIME
13456 0.4
```

13420 0.2

11300 0.1

...

这意味着属于用户 `john` 的进程 `13456` 和 `13420` 消耗系统中最多的 `CPU` 时间。

假设你想找到系统中所有 `CPU` 使用率超过 `10%` 的进程，并且你想显示正在执行的命令名称、`PID`、`CPU` 占用率以及每个进程的总执行时间。你可以使用以下选项来实现目标：

```
ps -eo comm,pid,pcpu,etime --sort=-pcpu | awk '$3 > 10 {print $0}'
```

## 解释

- `-eo comm,pid,pcpu,etime`：指定结果中要显示的列。在这里，我们显示当前正在执行的命令名称 `comm`、`PID`、`CPU` 占用率 `pcpu` 以及每个进程的总执行时间 `etime`。
- `--sort=-pcpu`：按 `CPU` 占用率对进程进行降序排序。
- `awk '$3 > 10 {print $0}'`：使用 `awk` 过滤出 `CPU` 使用率超过 `10%` 的进程。

将得到类似下面的的结果：

```
COMMAND PID %CPU ETIME
some_high_cpu_proc 12345 11.2 1:23:45
other_high_cpu_proc 12346 12.5 2:34:56
...
```

这意味着进程 `some_high_cpu_proc` 和 `other_high_cpu_proc` 目前正在使用系统中超过 `10%` 的 `CPU`，且运行时间分别超过了 `1` 小时和 `2` 小时。

## `top` 命令

`top` 命令是一个实时进程监控工具，可用于显示运行在类 Unix 系统上的进程信息。它是监控系统性能和识别哪些进程消耗最多资源的最流行工具之一。

```
top
```

当你运行 `top` 命令时，你将获得系统状态的实时概览，包括进程信息、`CPU` 使用情况、内存和磁盘空间。你可以使用各种键在显示的不同信息之间进行导航并执行各种操作，例如杀死进程、更改更新频率、排序进程等。

`top` 的主显示分为几个部分，包括：

- Header（页眉）: 显示常规系统信息，如当前时间、运行时间、活动进程数量、`CPU` 和内存使用情况等。
- Body Section（主体部分）: 显示详细进程信息，如 `PID`、所有用户、进程名称、进程状态、`CPU` 使用率、内存消耗等。
- Legend（图例）: 描述主体部分中显示的列。

`top` 显示 Linux 系统上运行的进程列表。该命令用于监控系统资源，如工作负载、内存消耗、`CPU` 使用率等。

top

此命令将启动 `top` 并显示你系统上运行的进程信息，并进行实时更新。你可以使用各种键来导航显示的信息并执行各种操作。

仅显示特定用户 "`john`" 的进程。你可以使用 `-u` 选项指定用户。此命令将启动 `top` 并仅显示用户 "`john`" 的运行进程信息。

你还可以使用 `-d` 选项指定显示信息的不同更新频率。例如，每 `3` 秒更新一次信息。

你还可以使用 `-n` 选项指定 `top` 更新 更新的次数。例如，显示 `5` 次更新后的 `top` 信息。

按内存使用情况对运行中的进程进行排序。你可以使用 `-o` 选项指定排序列。

需要注意的是，你可以将 `-o` 选项用于 `top` 输出中的任何可用列，例如 `%CPU`、`%MEM`、`COMMAND` 等。

## `find` 命令

`find` 命令是一个在文件系统中查找文件的强大工具。它可以根据名称、类型、修改日期、大小等查找特定文件。

以下是 `find` 命令使用的选项：

- `-name`：允许你根据文件名搜索文件。
- `-type`：允许你根据类型搜索文件（普通文件、目录、符号链接等）。
- `-mtime`：根据修改日期搜索文件。
- `-size`：允许你根据大小搜索文件。
- `-perm`：允许你根据权限搜索文件。
- `-print`：显示找到的文件的全路径。
- `-exec`：为找到的每个文件执行命令。

```
find /home/user -name "*.txt"
```

"`find /home/user -name "*.txt"\"" 命令在 `/home/user` 目录及其子目录中查找所有扩展名为 "`.txt`" 的文件。

命令的详细解释：

- `"/home/user"` 是搜索的起始目录。
- `"-name"` 是 "`find`" 命令的一个选项，指定搜索应基于指定的内存。
- `"*.txt"` 是指定的文件名，使用正则表达式表示文件名必须以 "`.txt`" 结尾。

```
find . -type f -name "A*"
```

"`find . -type f -name "A*\""` 命令在当前目录下查找所有名称以 "`A`" 开头的文件。

该命令的详细解释：

- `"."` 是搜索的起始目录。
- `"-type f"` 是 "`find`" 命令的一个选项，指定搜索仅限于普通文件（排除目录）。
- `"-name"` 是 "`find`" 命令的一个选项，指定搜索应基于指定的文件。
- `"A*"` 是指定的文件名，使用正则表达式表示文件名必须以 "`A`" 开头。

```
find . -type f -mtime -30
```

在当前目录及其子目录下查找 `30` 天内修改的文件。

```
find . -mtime +7
```

在当前目录及其子目录下查找 `7` 天前修改的文件。

```
find . -type f -perm 755
```

权限为 `755` 文件。

```
find . -type f -user username
```

在当前目录及其子目录下查找所有属于特定用户的文件。

```
find . -name "*.extension"
```

在当前目录及其子目录下查找具有指定扩展名的文件。

```
find . -name "*.txt" -exec ls -lh {}
```

该命令使用 `find` 查找所有扩展名为 "`.txt`" 的文件。

- `"."` 表示当前目录和子目录，意味着 `find` 从你所在的目录开始搜索。
- `"-name"` 是一个选项，指定要查找的文件名，而 `"*.txt"` 是一个匹配所有 `.txt` 扩展文件的 shell 表达式。
- `-exec` 是一个选项，为找到的每个文件执行命令。
- `"ls -lh {};"` 是为找到的每个文件执行的命令。"`ls -lh`" 是列出带有权限、大小等详细信息的命令。`"{}"` 是一个标记，在每次迭代中都会替换为找到的文件名。`";"` 结束 `-exec` 执行的命令。

综之，此命令在当前目录及其子目录下查找所有扩展名为 `.txt` 的文件，然后显示找到每个文件的详细信息。

```
find . -name "*.txt" -size +100k -exec cp {} bigfiles \;
```

在当前目录及其子目录下查找所有大于 `100KB` 的 `.txt` 文件，并将它们拷贝到名为 "`bigfiles`" 的新目录。
