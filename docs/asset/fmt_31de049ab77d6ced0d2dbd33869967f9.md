`deny` 块与问题审核脚本中的 `deny` 块相同：

```php
[<a href='adminmodsubown.php?func=main'>No</a>]";
            break;
```

此代码提示用户确认他是否希望拒绝该请求。如果用户点击“否”，页面将重定向到 main 部分；否则，它将重定向到 `denyconf` 部分。
