系统是一组占据数 `n`，其中每个能级 `i` 中的粒子数代表一个有限范围。记住 `$n_i$` 代表包含 `$g$` 个简并态的能量。在费米统计中，每个能级的粒子数要么为零要么为一——在这样的状态下二是不允许的。如果考虑状态本身，两个粒子可以占据该状态。这是对泡利不容原理的简单表示，即没有两个电子可以占据相同的状态。包含 `$g$` 个简并能级的能级由方程 `(1)` 描述，它在给定总能量 `E` 和粒子数 `N` 的情况下给出了 `n` 的数量：

```
$W = \prod_i \frac{g!}{n_i!(g-n_i)!}$
```

方程 `(3)` 适用于这种概率更大的分布。在这里 `$\beta$` 和 `$\alpha$` 是需要根据方程 `(3)` 确定的参数；事实上，`$\beta = 1/kT$`，其中 `k` 是玻尔兹曼常数，`T` 是温度。当忽略分母中的 1 时，

```
$$\sum_i n_i = N \quad (2a)$$
```

```
$n_i = \frac{g_i}{e^{\beta\epsilon_i} + 1} \quad (3b)$
```

## 878 铁磁性石榴石

铁磁性中子感应条。参见协调机制；COVALENCE（共价键）；铁；（T.M.）

铁磁性石榴石是一类具有立方结构的铁磁性材料。铁磁性石榴石的典型公式为 `$X_3Fe_2O_{12}$`，其中 `X` 是三价离子或原子数大于 61 的稀土离子。（稀土离子的半径过大，无法放入石榴石结构中。）

铁磁性石榴石很重要，因为铁磁性铁氧石具有石榴石结构，公式为 `$M_3Fe_2O_{12}$`，其中 `M` 是稀土离子或三价离子。钋石榴石用于微波设备。

铁磁性石榴石引起了极大兴趣，因为它们含有稀土离子，具有高磁各向异性（由于原子运动顺序的原因，某些离子的磁性较小），并且由于强晶场效应的影响。

第三类石榴石具有六角晶结构，公式为 `$MFe_2O_3$`，其中 `M` 通常是 Y、Sc 或 Pb。这些是稀土磁致伸材料，具有高矫顽力，这是永磁体材料的重要属性。

铁磁性石榴石的实际工程应用归功于钋石榴石，由于其稀有的铁磁特性，它被用于多种微波设备。为了用于固态存储设备，大量的研究工作集中在铁磁性铁石榴石上。在这些中，不同的稀土石榴石被同时使用，以产生影响内存参数的多种磁性。

铁氧石器件。基于铁氧石（磁性氧化物）的使用和特性的电子器件。铁氧石分为两类，取决于铁氧石是软的（低矫顽力）还是硬的（高矫顽力），用于变压器、电感器和微波设备。

软铁氧石的电阻率是所用铁氧石组件的 `10^8-10^{10}` 倍。这减少了 10 kHz 以上频率下的涡流损耗。硬铁氧石用于磁记录头、支架和固定装置。
