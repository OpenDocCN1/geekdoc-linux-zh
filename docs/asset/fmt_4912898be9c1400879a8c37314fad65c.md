在大多数系统中，你需要 root 权限才能在网络接口上运行 Snort 嗅探流量。获取这些权限并运行以下命令：

```
snort - <if> -vd
```

在这里，`<if>` 是你的网络接口名称——`eth0`、`eth1` 等（你可以通过输入 `netstat -i` 获取它）。

如果输出流得太快，按下 `Ctrl+C` 停止并通过管道输出。列表 22.7 提供了 Snort 输出示例。
