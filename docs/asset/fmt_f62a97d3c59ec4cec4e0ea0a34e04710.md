5. 继续为公式添加组件直到完成。

假设你想将矩阵乘以 3。要找到这一点，按 Enter 键进入命令窗口的下一行（作为“草稿纸”），右键显示弹出菜单，并选择单元/二元运算符。此选择会在矩阵代码下方添加“`times`”词。现在你知道如何格式化乘法了，所以删掉这个词，并作为指南将你的公式改为：

```
3 times matrix(A # B ## C # D)
```
