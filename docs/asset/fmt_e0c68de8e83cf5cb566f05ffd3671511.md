## 查看文件内容

到目前，本章讨论了用于导航目录和查看文件类型的命令。你还需要知道如何显示文件的内容。目前最常用的文件类型是文本。要在屏幕上显示文本文件的内容，可以使用 `cat` 命令。以下是 `project4` 的示例：

```
[root@server1]# ls
current myprogram project12 project2 project4
Desktop myscript project1 project13 project3 project5
[root@server1]# cat
```
