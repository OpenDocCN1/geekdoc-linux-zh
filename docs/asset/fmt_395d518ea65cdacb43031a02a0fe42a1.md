## 9.4 命令注入

### 9.4.1 OS 注入

Web 应用程序需要与操作系统交互，例如通过文件上传创建文件时。Web 应用程序应该始终提供使用准备命令的特定功能。然而，这些 API 和函数通常需要大量计划。在这种情况下，Web 开发人员倾向于直接接受用户输入并进行清理。这意味着会对用户输入过滤任何可能出于恶意目的触发应用程序行为的命令。
