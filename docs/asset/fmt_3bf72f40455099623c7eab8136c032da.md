# 测量系统

## 美国习惯单位制与公制

在过去的200多年里，科学家和工程师使用了两种主要的测量系统。这些通常被称为美国习惯单位制（继承自英国帝国单位制）和公制（发展于法国大革命期间）。

在习惯单位制中，基本单位是码（yard）和磅（pound），其细分单位如英寸（inch），以及像吨（ton）这样的单位也是基础。公制已被世界大部分地区采用为通用，因为它在科学测量中非常方便。米（meter）和千克（kilogram）及其单位（如千克）以及分数单位（如克 gram）是公制的基础。20世纪后半叶见了了单位被应用于特定的科学领域，例如位于塞夫尔尔（Sèvres）维护的国际原型——铂铁圆柱体。

在习惯单位制中，同类单位的划分几乎是随机的。例如，长度单位有码和英里（mile）。在公制中，单位之间的关系是直接十进制的（毫米、米和公里）。

然而，从技术上讲，每个系统内部的单位选择并没有统一。例如，时间可以选择小时或秒（second），而长度可以选择厘米（centimeter）或米。

由于在科学家中极其常用，一些单位仍与国际单位配合使用，例如电子伏特（electronvolt）、伦（roentgen）和坎德（candle）。

一点是，1967年10月，第十三届国际量衡会议决定将热力学温度单位命名为开文（kelvin）。对于温度，符号是 K。
