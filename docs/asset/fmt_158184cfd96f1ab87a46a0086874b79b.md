### `SSH`
Shell（或 `SSH`）是一种通过加密连接运行命令行程序和图形化应用程序以及传输文件的方法，它既是一种协议，也是一组小型命令行应用程序，可用于各种功能。`SSH` 替换了旧的 `Telnet` 程序，并可用于跨互联网的远程管理。然而，它也具有许多特性。`SSH` 通过自动设置 X 权限提高了远程运行应用程序的便利性。如果你登录到一台机器，它允许你在上面运行图形化应用程序，而 `Telnet` 则要求用户理解通过 `xauth` 和 `ssh` 命令操作的 X 认证机制。`SSH` 内置了压缩，允许你的图形化应用程序在网络上运行得快得多。`SCP`（安全复制）和 `SFTP`（SSH FTP）允许通过 `SSH` 自身的命令行工具或像 `Gnome FTP` 这样的图形化工具通过网络链路传输文件。像 `Telnet` 一样，`SSH` 是跨平台的。你可以找到 Linux、Unix 的 `SSH` 服务器和客户端，以及适用于 Windows、BeOS、PalmOS、Java 以及路由器使用的嵌入式操作系统的所有功能。来自《高级 Linux Handbook》

### `ssh-askpass`
在 X 环境下，为 `ssh-add` 向用户询问密码。这是 Jim Knoble 对 `ssh-askpass` 程序的实现。Jim 将其称为 `x11-ssh-askpass`，但我决定将其命名为 `ssh-askpass` 以于查找，这几乎肯定是你想要的。如果你感兴趣，OpenSSH 的另外两个版本也可用（`ssh-askpass-gtk` 和 `ssh-gnome`）。非免费版本已不再维护。其源码仍作为 `ssh-nonfree` 源码的一部分可以获取。来自 Debian 3.0 http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

### `ssh-gnome`
在 X 环境下，为 `ssh-add` 向用户询问密码。该包已从主 `ssh` 包中分离出来，这样 `ssh` 就不需要依赖 Gnome 库。你可能想要安装 `ssh-askpass` 包，但这取决于你的喜好和配置。来自 Debian 3.0APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
