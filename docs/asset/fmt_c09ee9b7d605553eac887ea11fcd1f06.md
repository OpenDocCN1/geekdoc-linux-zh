
## `fromfd(fd, family, socktype, [proto])`

```
从内部文件描述符 `fd` 创建套接字对象。其 `family` 地址、套接字类型和协议号与 `socket()` 相同。文件描述符必须指向之前之前创建的套接字。它返回一个 `SocketType` 实例。
```

## `getaddrinfo(host, port [, family, socktype, [proto, [flags]]])`

```
给定关于主机的 `host` 和端口信息以建立套接字连接。`host` 是一个包含名称或数字 IP 地址的字符串。`port` 是数字或表示服务名称的字符串（例如 `"http"`、`"ftp"`、`smtp"`）。每个返回的元组包含五个元素 `(family, socktype, proto, canoname, sockaddr)`。`family`、`socktype` 和 `proto` 项的值与传递给 `socket()` 的值相同。`canoname` 是一个表示主机规范名称的字符串。`sockaddr` 是一个包含套接字地址的元组，如互联网地址示例中所示。这里有一个示例：
```

```
>>> getaddrinfo("www.python.org", 80)
[(2,2,17,('194.109.137.226',80)), (2,1,6,('194.109.137.226',80))]
```

在此示例中，`getaddrinfo()` 返回了关于两个可能的套接字连接的信息。第一个 `proto=17` 是 UDP 连接，第二个 `proto=6` 是 TCP 连接。`getaddrinfo()` 的额外参数可用于缩小搜索范围。例如，此示例返回了关于建立 IPv4 连接的信息：

```
>>> getaddrinfo("www.python.org", 80,AF_INET,SOCK_STREAM)
[(2,2,17,('194.109.137.226',80)), (2,1,6,('194.109.137.226',80))]
```

`value` 是一个包含二进制编码的四字符字符串。这在将地址传递给 C 语言或地址必须被封装进传递给其他程序的数据结构中时可能非常有用。它不支持 IPv6。

## `inet_ntoa(packedip)`

将二进制打包的 IPv4 地址转换为使用标准点分表示法的字符串（例如，'135.128.11.209'）。`packedip` 是一个包含 IP 地址 32 位编码的四字符字符串。如果从 C 接收到地址或从数据结构中解包了地址，该函数可能很有用。它不支持 IPv6。

## `inet_ntop(address_family, packed_ip)`

将表示 IP 地址的二进制打包 `packed_ip` 转换为类似 '123.45.67.89' 的字符串，`address_family` 通常是 `AF_INET` 或 `AF_INET6`。这可以用于从字节缓冲区（例如，从底层网络数据包的内容）获取网络地址字符串。

## `inet_pton(address_family, ip_string)`

将类似 '123.45.67.89' 的 IP 地址转换为打包的二进制。`address_family` 是地址族，通常是 `AF_INET` 或 `AF_INET6`。当你尝试将网络地址编码为原始二进制数据包时，可以使用此函数。

## `ntohl(big)`

将 32 位整数从网络字节序（大端序）转换为主机字节序。

## `ntohs(big)`

将 16 位整数从网络字节序（大端序）转换为主机字节序。

## `setdefaulttimeout(timeout)`

为新创建的套接字对象设置默认超时时间。`timeout` 是以秒为单位指定的浮点。可以使用 `None` 表示无超时（这是默认值）。

## `socket(family, type, [proto])`

使用给定的地址族、套接字类型和协议号创建一个新的套接字。`family` 是地址族，`type` 是本节第一部分讨论的套接字类型。要打开 TCP 连接，请使用 `socket(AF_INET, SOCK_STREAM)`。要打开 UDP 连接，请使用 `socket(AF_INET, SOCK_DGRAM)`。该函数返回一个 `SocketType` 实例（稍后描述）。

协议号通常省略（默认为 0）。这通常用于原始套接字（`SOCK_RAW`），并被设置为取决于所用地址族的常量。对于 `AF_INET` 和 `AF_INET6`，下面的列表显示了 Python 可能定义的所有协议号，取决于它们在主机系统上的可用：

| `IPPROTO_BIP` | Vanyan VEN |
| `IPPROTO_DOPTS` | IPv6 目的选项 |
| `IPPROTO_EGP` | 外部网关协议 |
