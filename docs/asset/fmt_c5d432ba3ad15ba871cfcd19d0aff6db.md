2. 输入 `((x=100-3**2))` 并按回车，通过计算 `3` 的 `2` 次方并从 `100` 中减去结果来改变“`x`”的值。
3. 输入 `((y=(100-3)**2))` 并按回车，通过先从 `100` 中减去 `3` 然后进行 `2` 次方来改变“`y`”的值。

5. 退出终端模拟程序，输入 `exit` 然后按回车。
6. 注销。

> 表达式仅对整数操作。除以零会导致错误。
