## `cat`

`cat` 程序有许多有趣的选项。其中许多用于可视化文本内容。有时我们想知道可见文本中是否嵌入了控制字符。最常见的是制表符（相对于空格）和回车符（通常作为 MS-DOS 风格文本文件的行尾字符出现）。另一种常见情况是包含行尾空格的文件。

让我们使用 `cat` 作为一个原始文字处理器来创建一个测试文件。要实现此，只需输入 `cat` 命令（同时指定一个重定向输出的文件）并输入文本，然后按回车键结束行，最后按 CTRL-D 表示我们已到达文件结束。在示例中，我们输入了一个前导制表符，并在行尾随了一些空格：

```
@linux ~$ foo.txt
	The quick brown fox jumped over the lazy dog.
@linux ~$
```

接下来，我们使用带 `-A` 选项的 `cat` 来显示文本。

```
@linux ~$ cat -A foo.txt
^IThe quick brown fox jumped over the lazy dog. $
@linux ~$
```

正如结果所示，文本中的制表符被表示为 `^I`。这是一种常见的表示法，事实证明 CTRL-I 同于制表符。我们还看到 `$` 出现在真正的行尾，表明我们的文本包含行尾空格。

## 文档

在 Unix 类系统中找到的许多命令行程序都是为了支持系统管理和软件开发而创建的，文本处理程序也不例外。文本处理对软件开发者很重要，是因为所有软件都是文本。源代码、程序实际写入的内容始终是文本。

### MS-DOS 文本 VS UNIX 文本

你可能想使用 `cat` 来查找文本中的非打印字符的原因之一是发现隐藏的回车符（carriage returns）。隐藏的回车符从哪里来？DOS 和 Windows！Unix 和 DOS 在文本中对行尾的定义不同。Unix 以换行符（ASCII 10）结束，而 MS-DOS 及其衍生版本使用回车符（ASCII 13）和换行符的序列来终止每行文本。

有几种方法可以将文件从 DOS 格式转换为 Unix 格式。在许多 Linux 系统上，有 `dos2unix` 和 `unix2dos` 程序，它们可以将文本文件在 DOS 格式和反 Format之间转换。然而，如果你的系统中没有 `dos2unix`，也不要担心。将文本从 DOS 格式转换为 Unix 格式的过程非常简单；它涉及删除这些问题的回车符。通过本章稍后讨论的几个程序就可以轻松实现。

`cat` 还有用于修改文本的选项。最突出的两个是 `-n`（对行进行编号）和 `-s`（抑制多个空行的输出）。我们可以演示一下：

```
@melinuxbox]$ cat > foo.txt
The quick brown fox
```

```
@melinuxbox]$ cat -ns foo.txt
1 The quick brown fox
2
3 jumped over the lazy dog.
@melinuxbox]$
```

在这个示例中，我们创建了一个新版本的 `foo.txt` 测试文件，它包含两行由空行分隔的文本。在用 `-ns` 选项处理 `cat` 之后，多出的空行被删除了，剩余的行被编号。虽然这算不上复杂的操作，但它确实是一个过程。

## `sort`

`sort` 程序启动标准输入的内容或命令行上指定的一个或多个文件，并将结果发送到标准输出。使用与处理 `cat` 相同的技术，我们可以如下演示直接从键盘处理标准输入的过程：

```
@melinuxbox]$ sort > foo.txt
c
b
a
```

```
[me@linuxbox ~]$ cat foo.txt
```

输入命令后，我们输入字母 c、b 和 a，然后按 CTRL-D 表示文件结束。然后我们查看生成的文件，发现行现在按排序顺序排列。

由于 `sort` 可以接受命令行上的多个文件作为参数，因此可以将多个文件合并成一个完整的排序后的整体。例如，如果我们有三个文本文件并想将它们合并成一个排序后的文件，我们可以这样做：

```
sort file1.txt file2.txt file3.txt > final_sorted_list.txt
```

`sort` 具有许多有趣的选项。表 20-1 提供了部分列表。

### 表 20-1：常用的 sort 选项

| 选项 | 长选项 | 说明 |
| --- | --- | --- |
| `-b` | `--leading-blanks` | 默认情况下，是对整行排序，从行的第一个字符开始。此选项使 `sort` 忽略行开头的空格，并根据行的第一个非空白字符计算排序 |
| `-f` | `--ignore-case` | 使排序忽略大小写 |
| `-n` | `--numeric-sort` | 根据字符串的数值求值进行排序。使用此选项允许 `sort` 对数值进行排序，而不是字母值 |
| `-r` | `--reverse` | 逆序排序。结果为降序而非升序 |
| `-k` | `--key=field1,[field2]` | 根据从 field1 到整行的键字段进行排序。见下文讨论 |
| `-m` | `--merge` | 将每个参数视为预先排序文件的名称。将多个文件合并为单个排序结果，而不执行任何额外的排序 |
| `-o` | `--output=file` | 将排序后的输出发送到文件而非标准输出 |
| `-t` | `--field-separator=char` | 定义字段分隔符。默认情况下，字段由空格或制表符分隔 |

尽管这些选项中的大部分都自俗易懂，但有些并不是。首先，让我们看看用于数值排序的 `-n` 选项。使用此选项，可以根据数值对值进行排序，而不是按字母顺序。我们可以通过 `du` 命令的结果来演示这一点，以确定磁盘空间最大的用户。通常情况下，`du` 命令按路径名顺序列出摘要结果。

```
[me@linuxbox ~$ du -s /usr/share/* | head
252 /usr/share/aclocal
96 /usr/share/acpi-support
8 /usr/share/adduser
196 /usr/share/alacarte
344 /usr/share/alsa
8 /usr/share/alsa-base
12488 /usr/share/anthy
8 /usr/share/apmdq
21440 /usr/share/app-install
48 /usr/share/application-registry
```

在这个示例中，我们将结果管道到 `head`，以将结果限制在前 10 行。我们可以产生一个数值排序的列表，显示这种方式下最大的 10 个消费者。

```
[me@linuxbox ~$ du -s /usr/share/* | sort -nr | head
509940 /usr/share/locale-langpack
242660 /usr/share/doc
197560 /usr/share/fonts
179144 /usr/share/gnome
146764 /usr/share/myspell
144304 /usr/share/gimp
13588 /usr/share/dict
76508 /usr/share
62844 /usr/share
```

179144 /usr/share/gnome
