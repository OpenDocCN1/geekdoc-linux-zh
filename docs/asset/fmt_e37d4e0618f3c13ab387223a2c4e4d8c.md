
# GRASP

是一种基于栅格的 GIS（地理信息系统）、图像处理系统和图形制作系统。它由美国陆军兵团工程研究实验室（USA/CERL）创建，并由许多其他机构增强，广泛应用于全球政府部门、大学和商业机构。它用 `C` 语言编写，适用于各种 `UNIX` 机器。`GRASP` 包含 40 多个在显示器和纸张上渲染图像的程序；30 多个水体处理程序；30 多个多光谱图像处理程序；14 个数据管理程序；以及 60 个文件管理程序。`GRASP` 的优势在于几个领域。简单的用户界面使其成为那些首次接触 GIS 的人的理想平台。希望编写自己代码的用户可以通过查看现有源代码、与带文档的 GIS 库建立接口以及使用 `GRASP` 手册来实现。这允许更复杂的功能被完全集成到 `GRASP` 中。其他优势还包括 `GRASP` 对数据库中混合数据集的处理、通过运行编码和重分类表对栅格地理区域进行图像压缩、`GRASP` 动态缩放显示图像以填充显示屏、其基本设计准则是对环境问题进行强大的计算机可执行分析（如所提议的），并追求复杂的制图结果输出。`GRASP` 以免费、非版权的源代码形式提供，可在宿主机上进行编译。某些编译后的二进制文件可以通过 Internet 免费获得。它运行在多种 `UNIX` 平台上。内容节从 Project Into 复制到 `GRASP`。

`http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`
