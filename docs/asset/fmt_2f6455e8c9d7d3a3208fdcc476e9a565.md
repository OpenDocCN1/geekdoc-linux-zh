# tweak

1. 微调，通常相对于某个值。也与 `twiddle` 同义。如果一个程序几乎正确，与其引入问题，倒不如继续微调直到它正常工作。使用 `fricibrate` 和 `fudge factor`；也称为软调试。 2. 调整或炸弹；英国的偏选用法。来自《术语词典》
2. 波浪号 (ASCII 11110,)，也称为 'squiggle'、'squiggle' (此处如此误 — 发音为 /skig/l)、'twiddle'，但 `twiddle` 是最常用的术语。对程序进行微小但重大的改变。通常修复一个 bug 并产生几个新 bug（也称为软调试）。 3. 以某种方式改变事物。例如，比特位（Bits）经常被 `twiddled`。转动开关或旋钮比 `tweaking` 或 `taking` 更有目的性；谈论 `twaddling a bit` 意味着漫无目的，充其量没有说明你对比特做了什么；拥有一个 bit 有更具体的含义（`bit twiddle`, `toggle`）。 4. 旋转鹦鹉的非常用名称。来自《术语词典》 `http://www.ldp.org/LDP/Linux-Dictionary/html.index`
