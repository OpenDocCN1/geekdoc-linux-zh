> 警告：在使用类似爬虫（spiders）和漏洞扫描器等自动化工具时要小心，特别是当爬虫或扫描器处于身份验证状态时。如果你以用户身份登录，你可能拥有 Web 应用程序上的管理功能，而爬虫和其他自动化工具会毫不犹豫地自动触发这些功能，可能导致潜在风险。
