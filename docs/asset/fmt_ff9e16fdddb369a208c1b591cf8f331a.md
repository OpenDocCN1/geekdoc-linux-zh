# 对象数据流、缩放的参数对象和可编辑多边形

当你选择一个对象时，对象的外观尺寸会受到影响，但对象的参数不受影响。例如，如果你创建了两个球，第一个半径为 `2`，第二个半径为 `1`，第一个看起来是第二个的两倍；正当你将第一个球缩放为其尺寸的 `50%` 时，它看起来和第二个球一样。依次选择每个球，并在“修改”面板中验证其半径值。尽管它们看起来相同，但第一个半径是 `2`，第二个是 `1`。这可能会导致很多困惑。

当你考虑 VIZ 中的对象数据流时，这种奇怪行为的原因变得更加清晰。你可能记得，VIZ 在显示对象之前会按照特定顺序评估与对象相关的数据。该评估顺序是主对象、修改器、变换和属性。对象的属性属于主对象，它是对象数据流中的第一项。变换位于评估顺序中。变换影响主对象，但对主对象内部的参数或数据没有影响。

## 平滑网格

你在第 2 章中了解到许多棱体系对象（`primitive objects`）都有 `Smooth`（平滑）参数。平滑是网格对象的固有属性。

### 选择网格而非组

你可能选择使用 `Attach`（附加）作为使用组的替代方案来组织场景。附加到网格上的对象会丢失其堆栈中的修改器，并且通常需要使用更复杂的多/子对象（`Multi/Subobject`）材料，你将在第 8 章学习。然而，与组相比，网格元素所需的内存更少。所有网格由直线连接的顶点组成。边定义了表面（取决于它们是多面的还是多边的）。平滑是通过融合相邻表面的外观，在离散的顶点集上产生的一种视觉效果。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_257_0.png)

每个网格对象存储了可以编辑的平滑信息。你将学习两种调整平滑的方法：网格内部和使用 `Smooth` 修改器。
