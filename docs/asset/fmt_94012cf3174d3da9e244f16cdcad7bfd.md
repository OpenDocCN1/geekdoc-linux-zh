
### `libnsl`
名称服务，SVR4 单元上的名称服务调用库（`getpasswd`, `getservwnam`, 等）。GNU lib 将此用于 NIS (YP) 和 NIS 函数。源自 Linux Guide http://www.tdlp.org/LDP/Linux-Dictionary/html.html

### `libnpr`
NSPR 为非 GUI 操作系统提供平台独立性。这些设施包括线程、线程同步、普通文件和网络 I/O、间隔计时和日历、基本内存管理 (`malloc`) 以及共享库链接。源自 Mandrake 9.0 RPM http://www.tldp.org/LDP/Linux-Dictionary/html.html

### `libnss`
网络服务 (SSL) 是一组旨在支持安全启用应用程序跨平台开发的库。使用 NSS 构建的应用程序可以支持 SSL v2 和 v3、PKCS #5、PKCS #7、PKCS #11、PKCS12、X509 和其他标准。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/html.html

### `libao`
OAF（对象框架）为 GNOME 组件提供了激活机制。它是 GNOME 框架中 Gtk 的替代品。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/html.html

### `libogg`
`libao` 是一个用于访问音频输出的库。`Libogg` 是一个用于解析 Ogg 格式的库。`libogg` 支持来自 Ogg 的流。源自 Redhat 8.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libole2`
程序需要 POSIX 类型的数据。一种方法是使用 OLE2。在 OLE 文件中，`posix` 使用了它。通过 POSIX 能够读取和写入文件。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libopenssl`
SSL 是包含 DES、RC4 等各种加密算法的库。由 OpenSSL 项目开发，位于 http://openssl.org/。许多程序需要它。位于 http://www.tdlp.org/LDP/Linux-Dictionary/html.html

### `libnss`
CORBA（对象请求架构）允许程序在不考虑编程语言或运行操作系统的范围内进行通信。CORBA 是一种允许程序之间进行网络请求的架构。此包包含了 CORBA 技术实现。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libpango1.0`
`libpango1.0` 是一个处理 Unicode 字符串的库，以及双向字符串。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libcap`
`libcap` 为网络流量提供了低级捕获。几乎所有基于 Unix 的程序都使用此库。

### `libpcre`
PCRE 有自己的 API，但 `libpcrebase` 还提供了一组基于 POSIX API 的“封装”。其正则表达式仍然遵循 Perl 语法和语义。POSIX 风格函数的头文件是 `posix.h`。POSIX 的官方名称是 `reg`，但它不希望以这种方式分发会导致与现有文件产生问题。为了让使用 POSIX API 的现有程序可以使用，必须将其重命名或通过链接指向它。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libpng`
`libpng` 包包含创建和处理 PNG（网络图形接口）图像文件的函数库。PNG 是一种类似于 GIF 格式的位图格式。PNG 的创建是为了取代 GIF 格式，因为 GIF 使用了专利数据压缩算法。源自 Mandrake 8.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libpq`
C 和 C++ 库允许用户与 PostgreSQL 后端通信。后端可以在另一台机器上并通过 TCP/IP 访问。源自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### `libPropList`
LI 的目的是紧密模仿 GNU/OPENSTEP 中使用的列表（它们位于 `SSString`, `NSData`, `NSArray` 和 `NSDictionary` 类中）并完全兼容。PL 允许使用配置或偏好文件的程序使其与 GNU/OPENSTEP 用户默认处理机制兼容，而无需使用 Objective-C 或 GNU/OPENSTEP 方法。源自 Mandrake 9.0 RPM

### `libpwdb`
`pwdb` 包包含了 `libdb`，即密码数据库库。`libpwdb` 是实现通用用户信息数据库的库。`libpwdb` 专门设计与 Linux 的 PAM（可插式认证模块）工作。`libpwdb` 允许访问和管理 `/etc/passwd`、`/etc/shadow` 以及 NIS 和 Radius 在内的网络安全工具。源自 Mandrake 9.0 RPM

### `libqt3`
`libqt3` 是一个完整且定义良好的多平台对象框架，用于使用 C++ 编写图形用户界面（GUI）应用程序。Qt 与 OpenGL/Mesa 3D 库无缝集成。Qt 在 Windows 系统上开发自由软件是免费的。它包含了 X 版本的源代码以及适用于 Linux、Solaris、SunOS、FreeBSD、OSF/1、Irix、BSD/OS、NetBSD、HP-UX 和 AIX 的 Makefile。此 Qt 可以根据 `LICENSE.QPL` 文件的条款进行修改和分发。Qt 还支持 95 和 NT，具有原生的外观和感受。针对运行 Windows 95/NT 版本的 Qt 进行了反编译，反之亦然。Qt 在世界软件开发项目历史上占有重要地位，包括 KDE 桌面环境（http://www.kde.org）。更多示例请参阅 http://www.troll.com/qtprops.html。Qt 拥有卓越的文档：750 页打印版和完全交叉引用的在线文档。它可以在 http://doc.troll.com/qt 获取，易于学习，所有类之间具有一致性，并带有一个 14 节的带结果链接在线教程。许多第三方书籍也自动缩短了编写 Windows 用户界面软件的开发时间和复杂性，允许程序员直接关注任务本身，而无需担心底层的 Motif/X11。Qt 同样是面向对象的。所有对话框都是 C++ 对象，并且支持继承，创建新小部件既简单又自然。Qt 革命性的信号/槽机制提供了编程的可能。可重用组件可以在彼此不知道对方的情况下共同工作，并以类型安全的方式进行。Qt 是一个非常快速的绘制引擎，与其他不同。Qt 基于 Xlib 和其他库，而不是 Motif 或 X11。Qt 提供两种不同的许可协议：用于开发商业软件的专业版许可：http://www.troll.com/pricing.html – 用于开发自由软件（Windows 系统）的公共 Q 许可（QPL）。此包包含共享库。来自 Mandrake 9.0 RPM http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### LibreGNU
LibreGNU 是一个面向桌面的 Debian 发行版。2.7 版本于 2002 年 9 月 4 日发布。2.8 版本于 2003 年 5 月 1 日发布。来自 LWN 列表 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### libraries
可执行文件没有未定义的符号，只有符号；所有有用的程序都引用它们未定义的符号（例如 `print` 或 `write`）。这些引用通过从库中提取对象文件到可执行文件中来解析。http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
