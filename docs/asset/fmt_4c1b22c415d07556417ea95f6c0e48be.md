
# 癌症
癌症的进展或程度变化很大，取决于肿瘤类型和对治疗的反应。治疗可能包括手术、放射治疗、化疗和免疫治疗。每种癌症的治疗都非常具体，并会使用组合方法，例如手术后进行放射治疗或化疗，以确定肿瘤的位置、大小和扩散范围。见 化疗；免疫学；肿瘤学；放射学；[S.P.H.]

# 犬瘟热
犬瘟热涉及呼吸道分泌物，这是主要的传播途径。病毒在初始感染后 7 天开始排毒。受感染的狗和其他肉食类动物无论是否显示临床症状，都会在所有的体液分泌物中排出病毒。

犬瘟热的持续时间和严重程度存在很大差异，范围从无症状到死亡不等。约 50% 的病例免疫系统崩溃。前 3-5 天为发热期，随后（几天后）通常伴有鼻腔分泌物、发热和食欲不振。感染早期白细胞计数减少。胃肠道和呼吸道症状可能随后出现，通常由继发性感染加剧。

犬瘟热的特定不良影响尚不明确。瘟热是非抑制性的且抗炎的。针对感染性呼吸道和炎症性道进行治疗。补充液体和电解质可能是治疗犬瘟热最重要的方法，因为狗可能会出现严重脱水。

犬瘟热是副呼吸病毒科的一种麻疹病毒，与麻疹以及狐狸和犬的狂热（以及瘟热）有关。它是一种包膜病毒，由核糖酸组成，包含六种蛋白：RNA 聚合酶和两种酶（核蛋白和 M 蛋白），以及血凝蛋白和融合蛋白。病毒从上皮细胞分泌。病毒；副呼吸病毒。

# 碳水化合物
碳水化合物指的是一组包括糖、淀粉和纤维素以及许多相关结构的物质。这组化合物在植物和动物的生活中用作结构元素和功能表现的。植物的独特之处在于，在自然界中只有它们有能够在光合作用产生的能量的情况下，利用二氧化碳和水合成碳水化合物。

碳水化合物分为两类：还原糖和非还原糖。还原糖的定义是它们含有游离的醛基或酮，且溶于水。淀粉和纤维素等糖的性质取决于其结构的本质。

碳水化合物在体内通常以单糖的形式产生，例如葡萄糖（`C₆H₁₂O₆`）、果糖（`C₆H₁₂O₆`）和半乳糖-蔗糖（`C₁₂H₂₂O₁₉`）。这些糖随后形成较大的碳水化合物，如淀粉、直淀粉和糖原。

还原糖由单糖、二糖和三糖组成。二糖包括麦糖和乳糖，三糖包括海藻糖、麦糖和蔗糖。最为人知的还原糖是二糖麦糖。
