
# 分支聚合物

连接一个或多个链段的聚合物链分支。分支聚合物的例子通常包括：与主链具有相同重复单元的长链（通常为分支聚合物）；含有与主链不同的单元的长链（分支聚合物）；每个重复单元上有一条长分支（称为梳状聚合物）；以及从主链分支出的的小分子（树枝状聚合物）。如果分支是多功能的，会导致随生长的分支。星形、梳状和星爆发状聚合物（见图），特别是最后一种，代表了有趣的分子结构，可能导致不稳定结构（例如胶粒和胶聚体），从而改变生物分子的功能。BIOLYMER：聚聚。

(G.E.W.)

## 鳃足亚

壳动物纲的一个类，类似于鱼类。水蚤是一个属。它们是一个包含100种植物的小群体，多样性丰富，且外观迥异。无头的胸部（或头胸）牢固融合，末端带有细小的附肢。较大的物种长度可达1英寸（25毫米）。

所有附肢均位于头胸部，由两对触角组成，触角是用于进食的改良足。带有蜡质头的头胸允许肢体扁贴在鱼的皮肤上。高度流线型的轮廓最大限度地减少游泳时的阻力。它们的运动方式如水一般。

## 布雷顿循环

一种热力学循环（也称为焦循环或等压膨胀循环），具有两个逆（等熵）过程。气体循环的热效率是压缩比的函数。对于柴油循环，热效率较低。布雷顿循环具有其固有的热效率，在给定的功率输出下需要大量的气体。布雷顿循环用于燃气轮机处理工作流体。

## 金属焊接

硬焊通过加热填充金属进行。填充金属的熔点高于850°F（454°C），但低于焊接金属的熔点。它们通过毛细作用进入金属之间的间隙，通过形成金属键将它们连接。该过程与焊接相似，但使用的填充金属更硬，温度更高。良好的硬焊处在应力、振动和温度负载下具有高强度。在良好的硬焊处，任何失效将发生在基金属而非焊处。有许多设计需要考虑。所有的焊接都可以归类为两种基础设计：搭接焊或对接焊。没有通用的填充金属可以满足所有设计要求，但有很多类型可用。有焊接工艺。喷焊中，通过某些类型的火炬对基金属加热。填充金属可以放在焊处或送入焊处。感应焊接是将待焊接部件放置在射频电源附近。通常使用助焊剂和填充金属。电阻焊接采用电极，放置在部件上形成焊处。热量由部件对电流流的电阻产生。浸焊中将填充金属放在或位于焊处，并浸入熔盐或助焊剂浴中，直到达到焊接温度。这种循环的变体中，组装体预填并插入焊接填充金属浴中。红外焊接是一种使用高强度灯具照射在待连接处的过程。它是一种广泛使用的技术，特别是当待焊接部件加工到最终尺寸时，或者为了组装已经连接或固定的复杂组装体时。焊处的内部大气必须受控制以确保一定的灵活性。一个重要优势是加热和冷却产生的金属变形可以通过氛围控制和消除。焊缝在氛围中形成。

扩散焊与此不同，它不是通过加热方法，而是通过多种溶剂金属向基金属的扩散。扩散温度和时间、焊接温度、时间、某些情况下压力和填充材料受到控制，使填充金属渗透基金属。此时焊处的性能非常接近基金属。

其他使用的工艺包括电焊、块焊和双面焊。

在施加电势下，气体从绝缘体到导体的转变发生在毫秒到纳秒之间，具体取决于施加场的形式和气体的种类。这种转变取决于气体中电子、离子和光子的行为，特别是产生或耗尽自由电子的过程。电离需要气体具有高电压，并需要根据各种目的对气体混合物进行调整，使其能够承受高电位。参见电气击穿、电导率。

具有高介质强度（如高击击穿电压）的气体绝缘体的系统性开发对于多种应用的高科技具有重要意义。介质气体用于绝缘高压输线、断路器、变压器、变电站、电压弧和其他电气设备。参见断路器、介质压力。

### 乳腺

人体腺体，通常用于成年女性，但在现实中有限。成年女性乳腺包含15–20个分支，从乳头放射。在乳汁期间，其分泌物通过乳管排出。

在女性体内，乳腺增大过程中会发生激素变化，但很大程度上是因为虽然腺芽已经形成。怀孕的完成会导致进一步发育。如果怀孕结束，腺体组织会退化。泌乳持续并在母乳后结束。

乳腺囊肿可能由于先天或发育性异常、激素失衡和/或肿瘤形成引起。

先天缺陷通常是不可接受的，除非它们具有美感或宇宙性的不完美。多乳头和乳腺辅助组织是常见的。

浸润并不一定与囊肿破裂或损伤引起的导管侵入有关。炎症可能导致瘢痕形成，但癌症发生率显著较高。

激素失衡被认为是各种常见乳腺疾病（如囊性增生）的原因。这些变化被认为是月经期间由于雌激素或孕酮增加引起的。尽管临床和病理变异存在广泛，但三种趋势较为流行：第一是纤维腺瘤或乳腺病；第二是囊性增生，其特征是腺体组织和导管上皮增加并形成囊肿；第三类是腺瘤，在腺体增生中很常见。每种主要的增生形式都有其自身的特征，乳腺癌的发生也与良性和恶性肿瘤不同。这些情况被发现易于随后发展为癌症。

乳腺癌是乳腺最严重的病变，美国每年有25,000–30,000人死于此。它始于绝经前，之后逐年增加，在绝经前注意到一个高峰式增长。早期乳腺癌可能表现为小肿块；坚硬、触痛且活动自由。

## 乳腺疾病

乳腺 人体腺体的良性和恶性病变。良性乳腺病变有无症状和有症状，但没有恶性潜力。恶性病变具有在乳腺中生长并扩散到血液进入身体其他部分的潜力。

生理变化是器官对激素水平波动的反应。生理变化如囊性疾病、乳腺炎和囊性增生是用于描述乳腺组织、压痛和硬度的术语。这些被认为是对激素变化的正常反应，而不是独立的周期。乳腺癌也可能对雌激素产生，即使是在绝经前或绝经后的女性中。

良性疾病（包括导管炎等乳腺感染）与恶性不同；它们是持续的，或者远离乳腺组织。它们可能由损伤、囊肿或增生引起，在确定肿块性质时，取决于患者的年龄。

主要类型包括纤维腺瘤、囊肿、多形性腺瘤和纤维囊肿，可能发生于任何年龄，但在三十多岁的女性中最常见。它们是柔软、圆形肿块，可活动且无痛的良性肿瘤。其未知，但没有证据支持乳腺组织生长可能报告的激素水平失衡。

男性乳房症是男性乳腺的良性增大，可以发生于任何年龄和双侧乳腺，是对激素、药物或潜在健康状况的生理反应。

增生性疾病包括小叶增生。认为那些增生疾病代表了癌性变化，因为它们标志着乳腺癌风险的增加。与普通人群相比，具有非典型细胞的增生的癌症风险很高。非典型增生的女性患乳腺癌的风险是非典型的者的4倍。这种病变发生在人口的4-10%中。

## 角屑

角屑是由角状碎屑组成的碎屑岩，被认为等同于角岩。砾石大小是指平均粒径大于2 mm，这意味着50%或更多的颗粒属于这种尺寸。各种分类的具体数值差异很大。有人将角屑归类为亚角形（圆度0.25），而另一些则将角屑限制为角形（圆度0.1）。见地质学。

角屑也被称为角岩，因为碎屑的角性指示了来源或运输过程中与岩源的距离。明显的角性表明短距离运输。这种类型的元素包括悬崖底部的崩石角屑和沉积在河流旁边的角屑。

内地角屑和构造角屑是沉积岩的重要大类。它们由同一地层内的破碎和胶结形成，这需要胶结（对于形成过程）。构造角屑在短距离内运输，没有显著的成岩。不连接角屑通常限于粘土或粘土碳酸盐（碎屑岩），由沉积过程形成，如河流岸破碎或侵蚀沉积的砾石，以及崩塌或等密度流中的泥块侵蚀。
