## 调试 `in.named` 守护进程

为了调试 `in.named` 进程，你可以强制它提供更多的输出。调试默认是禁用的，但你可以通过多次运行以下命令来启动调试并增量地增加调试级别：

```
ultra10# pkill -USR1 in.named
```

每当你向 `in.named` 发送一次 `USR1` 信号，调试级别就会增加，从而产生更多输出。调试输出存储在 `/var/named/named.run` 文件中。
