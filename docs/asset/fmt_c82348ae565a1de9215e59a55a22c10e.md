## Linux 版 Java

如果您选择安装 Oracle8i，则必须安装 Java 运行时环境。Oracle8 的图形安装模式在 Oracle8i 中被新的 Java 安装程序 Oracle Universal Installer（OUI）取代。该安装程序需要运行 X Windows 的机器。如果您的系统没有 X Windows，可以将 X Windows 会话转发到另一个运行 X Windows 的机器。您需要从 `http://www.blackdown.org` 下载 Linux 版 Java 运行时环境 (JRE)。您应该下载 JRE 1.1.65。下载时，RedHat 5.2 使用 libc5 版本，RedHat 6.0 及以上使用 glibc 版本。将 JRE 复制到 `/usr/local`。解压文件并在 `/usr/local` 创建符号链接。通用安装程序似乎期望 JRE 安装在 `/usr/local/jre`。

```
# cd /usr/local
# tar xzvf jre_1.1.6-v5-glibc-x86.tar.gz
# ln -s v5 jre
```

将 `/usr/local/jre/bin` 放入您的 `PATH` 环境中。

`PATH=$PATH:/usr/local/jre/bin` 警告：除 1.1.65 以外的 JRE 版本报告过问题，例如安装程序无法启动或某些安装步骤失败。不要假设新版本会更好。同样，不要使用 JDK。如果之前的 Oracle 安装失败，重新安装前应删除之前安装的文件。

## 获取 Oracle 软件

Oracle8 和 Oracle8i 可以从 `http://www.oracle.com/software/linux` 的 Oracle Store 购买。也可以从 OTN 站点订阅 Linux 版 Oracle。订阅服务提供 12 个月的更新。Oracle 有一个适用于 Linux 的站点：`http://www.oracle.com/linux/`。如果您决定下载软件，请预期长时间下载时间。

## Oracle 补丁

以 `oracle` 用户身份登录并创建一个名为 `patches` 的目录。您应该下载最新的补丁。对于 Oracle8，请从 `ftp://oracle.com/server/patchsets/LINUX/80510/` 下载以下文件，或从 Oracle 技术网络 (OTN) `http://www.oracle.com/support/tech/linux/support_index.htm` 下载。OTN 要求打开免费账户。将下载的补丁放入 patch 目录：`glibpatch.tgz`、`lnxpath.tgz` 和 `linux_80510`。如果您在 RedHat 5.2 上安装 Oracle8，则不需要 `glibpatch.tgz`。对于 Oracle8i，下载以下补丁：`linux_815patches.tgz`。读取每个补丁的 README。补丁 FAQ 将提供有用信息。如果遇到问题，这些是您应该检查的内容。

## 安装 Oracle8

Oracle8 使用名为 `orinst` 的安装程序。该安装程序用起来有点笨。使用 TAB 键在字段和按钮之间移动。使用空格键选择选项。如果字段太短无法显示内容，使用 TAB 键移动字段。

1. 以 `oracle` 用户身份登录

2. 进入包含 Oracle 安装程序的目录。

```
cd /mnt/cdrom/orinst
```

3. 以文本模式启动 Oracle 安装程序（Linux 下不支持 GUI 模式）。见图 3.1。

```
./orinst
```

> 提示：如果您使用 CD-ROM 且 `orinst` 无法运行，请确保挂载 CD-ROM 时使用了 `exec` 参数。

# 安装补丁

安装 Oracle8 之后，您需要安装补丁。如果您尚未下载补丁，它们位于 `ftp://oracle-ftp.oracle.com/server/patchsets/unix/LINUX/80patchsets/80510/`。如果您需要 `glibcpatch.tgz` 补丁且在上述站点未找到它，则您需要在 Oracle Technology Network (`http://technet.oracle.com`) 获取一个免费账户，并查找 Linux 的软件版本。检查是否有新发布的补丁。目前 Oracle8 有三个补丁：`glibcpatch.tgz`、`lnxpatch.tgz` 和 `linux_80510patchset.tgz`。只有当您在 Red Hat 0.6 或更高版本上安装 Oracle 8.0.5 时，才需要 `glibcpatch.tgz` 文件。在应用后续补丁后，可能需要重新安装 `glibcpatch`。如果您在 RedHat 5.2 机器上安装，则没有必要 `lnxpatch.tgz` 包含了适用于 Linux 平台的特定补丁。`linux_80510patchset.tgz` 包含 Oracle8 的通用修复。您应该阅读补丁随附的任何文档。
