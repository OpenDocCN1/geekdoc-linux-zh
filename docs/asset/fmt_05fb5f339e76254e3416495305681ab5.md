## 处理传入的请求

```python
def handle_request(self):

    self.get_request = True

    header_data = self.request_data[:self.request_data.find(b'\r\n\r\n')]

    header_text = header_data.decode('latin-1')

    header_lines = header_text.splitlines()

    request = header_lines[0].split()

    op = request[0]

    url = request[1:]

    self.process_request(op, url)
```

## 处理请求

```python
def process_request(self, op, url):

    if op == 'GET':

        if not os.path.exists(url):

            self.send_error(404, "File not found\r\n" % url)

        else:

            type, encoding = mimetypes.guess_type(url)

            size = os.path.getsize(url)

            self.push_text('Content-Length: %d\r\n' % size)

            self.push_text('Content-Type: %s\r\n' % type)

            self.push_text('\r\n')

            self.push_text('\r\n')

            self.push_text(open(url,'rb').read())

    else:

        self.send_error(501,'method not implemented' % self.op)
```

## 错误处理

def send_error(self, code, message):

    self.push_text('HTTP/1.0 %d %s\r\n' % (code, responses[code]))

    self.push_text('Content-Type: text/plain\r\n')

    self.push_text('\r\n')

    self.push_text(message)

```python
def handle_write(self):

    chunk = self.write_queue.popleft()

    bytes_sent = self.send(chunk)

    if bytes_sent != len(chunk):

        self.write_queue.appendleft(chunk[bytes_sent:])

    if not self.write_queue:

        self.close()
```

# select

`select` 模块提供了对 `select()` 和 `poll()` 系统调用的访问。`select()` 通常用于实现轮询或在不使用线程或子进程的情况下对输入/输出流进行多路复用处理。在 UNIX 上，它适用于文件、socket、管道以及大多数其他文件类型。在 Windows 上，它仅对 sock 有效。

```python
select(fd, owd, ewtd [, timeout])
```

查询一组文件描述符的输入、输出和异常状态。前三个参数是列表，其中包含整数文件描述符或具有 `fileno()` 方法的对象（该方法可用于返回文件描述符）。`iwd` 参数指定等待输出的对象，可以为空。`ewtd` 参数指定等待输出或异常条件的对象。每个列表可以包含一个超时浮点数，指定以秒为单位的超时时间。如果省略了 timeout，函数将等待直到至少有一个文件描述符就绪。如果为 0，函数将执行轮询 `select()` 并立即返回。返回值是一个包含已就绪对象的列表元组。这些对象是第一个参数的子集。如果在超时发生之前没有对象就绪，则返回空列表。如果发生错误，将抛出 `select.error` 异常。它的值与 `IOError` 或 `OSError` 返回的值相同。

```python
poll()
```

创建一个利用 `poll()` 系统调用的轮询对象。这在支持 `poll()` 的系统中可用。

- 由 `poll()` 返回的轮询对象支持以下方法：

```python
p.register(fd [, eventmask)
```

注册一个新的文件描述符，`fd` 是整数文件描述符或提供 `fileno()` 方法的对象（可以通过该方法获取描述符）。`eventmask` 是以下标志的位或结果，这些标志表示感兴趣的事件：

| 常量 | 描述 |
| --- | --- |
| POLLIN | 有数据可读。 |
| POLLPRI | 有紧急数据可读。 |
| POLLOUT | 准备好写入。 |
| POLLERR | 错误状态。 |
