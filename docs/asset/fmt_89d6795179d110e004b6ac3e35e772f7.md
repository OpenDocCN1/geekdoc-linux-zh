通过对图 \(G\) 中的非邻接顶点对系统地应用定理 16.10，我们最终会到达一个已知色多项式的完全图集合。我们现在以此为例进行说明。假设我们要计算图 16.21 中图 \(G\) 的色多项式。对于 \(G\) 的非邻接顶点 \(u\) 和 \(v\) 以及通过识别 \(u\) 和 \(v\) 得到的图 \(H\)，根据定理 16.10，\(G\) 的色多项式是 \(G + uv\) 和 \(H\) 的色多项式之和。

在此时，采用 Alexander Zыков [263] 引入并由 Read [196] 后来使用的惯例是有益的。而不是反复写出定理 16.10 陈述中出现的方程，我们通过绘制图的草图来表示图的色多项式，并在草图中指出哪一对非邻接顶点 \(u, v\) 将通过添加一条边进行连接以及被识别。因此，对于图 16.21 中的图 \(G\)，我们有图 16.21 中所示的“方程”。

采用这种方法，我们可以看到，任何图的色多项式都是完全图色多项式之和。这一观察的一个推论如下：

**定理 16.12** 图 $G$ 的色多项式 $P(G, \lambda)$ 是 $\lambda$ 的多项式。

### 色多项式的性质

每个图的色多项式都具有一些有趣的性质。事实上，如果 $G$ 是一个阶数为 $n$、边数为 $m$ 的图，那么 $G$ 的色多项式 $P(G, \lambda)$ 可以表示为

`P(G, λ) = c₀λⁿ + c₁λⁿ⁻¹ + c₂λⁿ⁻² + ··· + cₙ₋₁λ + cₙ`,

其中 `c₀ = 1`（因此 `P(G, λ)` 是一个首项系数为1的 `n` 次多项式），`c₁ = −n`，若 `i` 为偶数且 `0 ≤ i ≤ n`，则 `c_i ≥ 0`；若 `i` 为奇数且 `1 ≤ i ≤ n`，则 `c_i ≤ 0`。由于 `P(G, 0) = 0`，因此 `c_n = 0`。

以下定理由 Whitney [256] 提出。

**定理 16.13** 设 $G$ 是一个阶数为 $n$、边数为 $m$ 的图。那么 `P(G, λ)` 是一个首项系数为1的 `n` 次多项式，其中 `λ^{n-1}` 的系数为 `-m`，且其系数符号交替。

**证明.** 我们对 `m` 进行归纳。若 `m = 0`，则 `G = \bar{K}_n` 且 `P(G, λ) = λ^n`，如我们所见。那么 `P(\bar{K}_n, λ) = λ^n` 具有所需的性质。

假设该结果对所有边数小于 `m` 的图成立，其中 `m ≥ 1`。设 `G` 是一个边数为 `m` 的图，且设 `e = uv` 是 `G` 的一条边。根据推论 16.11，

`P(G,λ) = P(G - e,λ) - P(F,λ)`，

其中 `F` 是通过将 `G` 中的 `u` 和 `v` 合并得到的图。由于 `G - e` 的阶数为 `n`、边数为 `m - 1`，根据归纳假设，有

`P(G - e,λ) = a_{0}λ^{n} + a_{1}λ^{n-1} + a_{2}λ^{n-2} + ⋯ + a_{n-1}λ + a_{n}`，

其中 `a_{0} = 1, a_{1} = -(m - 1)`，若 `i` 为偶数且 `0 ≤ i ≤ n`，则 `a_{i} ≥ 0`；若 `i` 为奇数且 `1 ≤ i ≤ n`，则 `a_{i} ≤ 0`。此外，由于 `F` 的阶数为 `n - 1`、边数为 `m'`，其中 `m' ≤ m - 1`，因此有

`P(F,λ) = b_{0}λ^{n-1} + b_{1}λ^{n-2} + b_{2}λ^{n-3} + ⋯ + b_{n-2}λ + b_{n-1}`，

其中 `b_{0} = 1, b_{1} = -m'`，若 `i` 为偶数且 `0 ≤ i ≤ n - 1`，则 `b_{i} ≥ 0`；若 `i` 为奇数且 `1 ≤ i ≤ n - 1`，则 `b_{i} ≤ 0`。根据推论 16.11，

```
P(G, λ)    =    P(G-e, λ) - P(F, λ)
= (a_0 λ^n + a_1 λ^{n-1} + a_2 λ^{n-2} + … + a_{n-1} λ + a_n) -
= (b_0 λ^{n-1} + b_1 λ^{n-2} + b_2 λ^{n-3} + … + b_{n-2} λ + b_{n-1})
= a_0 λ^n + (a_1 - b_0) λ^{n-1} + (a_2 - b_1) λ^{n-2} + …
        + (a_{n-1} - b_{n-2}) λ + (a_n - b_{n-1}).
```

由于 `a_0 = 1`，`a_1 - b_0 = -(m-1)` 即 `a_1 = -m`，若 `i` 为偶数且 `2 ≤ i ≤ n`，则 `a_i - b_{i-1} ≥ 0`；若 `i` 为奇数且 `1 ≤ i ≤ n`，则 `a_i - b_{i-1} ≤ 0`。因此，`P(G, λ)` 具有所需的性质，定理由数学归纳法得证。$\blacksquare$

假设图 `G` 包含一个端点 `v`，其唯一的邻点是 `u`。那么，显然，`P(G-v, λ)` 是 `G-v` 的 `λ`-着色数。顶点 `v` 可以分配 `λ` 种颜色中除分配给 `u` 的颜色以外的任意一种。这一观察给出了以下结论。

**定理 16.14** 若 `G` 是一个包含端点 `v` 的图，则

`P(G, λ) = (λ-1)P(G-v, λ).`

定理 16.14 的一个推论是以下结果，其逆命题也成立（见练习 22）。

**推论 16.15** 若 `T` 是一个阶数为 `n ≥ 1` 的树，则

`P(T, λ) = λ(λ-1)^{n-1}.`

**证明.** 我们对 `n` 进行归纳。当 `n=1` 时，`T=K_1` 且显然 `P(K_1, λ) = λ`。因此，归纳的基础步骤成立。假设对于每一个阶数为 `n-1 ≥ 1` 的树 `T'`，都有 `P(T', λ) = λ(λ-1)^{n'-2}`，并设 `T` 是一个阶数为 `n` 的树。设 `v` 是 `T` 的一个端点。因此，`T-v` 是一个阶数为 `n-1` 的树。根据定理 16.14 和归纳假设，

`P(T, λ) = (λ-1)P(T-v, λ) = (λ-1)[λ(λ-1)^{n-2}] = λ(λ-1)^{n-1},`

证毕。$\blacksquare$
