
让我们来看 `Tor` 与普通互联网使用之间的类比。你正坐在客厅里通过 `Tor` 网络匿名浏览。而你的妻子正坐在厨房里用着她的 `Macbook` 在没有使用 `Tor` 的情况下浏览。你可能会想她的浏览习惯是否破坏了你的匿名性。它们没有……在某种程度上是如此。虽然你的 `ISP` 不知道*你*在网上做什么，但他们对你妻子的情况确实很清楚。

想象你自己正开着一辆带有色膜窗的奔驰汽车在主街上行驶。没有人可以看向内部看你在红灯处做什么。即使是警察也不行。而你妻子的窗户不是色的。人们可以毫不费力地瞥一眼，判断她是否在抽烟、听 `iPod` 或在打手机。你是匿名的。她不是。`ISP` 以及她访问的任何网站都可以看到她在网上所做的一切切。然而，他们看不到你在做什么。

`Firefox`（以及许多其他浏览器）与不同的主机通信，路由器充当交通警察。一个例子：

- 你的机器：端口 `X`，机器 `A`（`Tor`：所有流量均加密）
- 你的妻子：端口 `Y`，机器 `B`（未使用 `Tor`：所有流量均可见）

这就像在桶里射击，对于 `NSA` 来说，比这还容易。同样的概念也适用于你使用 `Tor` 在你的机器上可能进行的任何其他事情。如果你使用 `BitTorrent`，即使你同时运行 `Tor`，你的 `ISP` 仍然可以看到你在 `P2P` 网络上做什么。但它看不到 `Tor` 网络的内容。

因此，不要在你的 `P2P` 网络上做任何你不想让 `ISP` 知道的事情。然而，`Tor` 是另一回事，因为他们看不到 `Tor` 中继之间正在发生什么。从所有意义上来说，`Tor` 就像一件隐身衣，保护你免受所有旁观者的视线，除非你不小心撕开了这件斗篷的漏洞（即开启了 `javascript`）。如果你在想：“哇，通过 `Tor` 运行 `BitTorrent` 这样就不会被起诉”。这是一个很棒的目标，只是 `BitTorrent` 开发者并没有急于实现这个功能，而且 `Tor` 网络根本无法处理这种带宽。

如果你决定使用 `Tor` 网络，列出一些最佳实践可能是明智的。首先，尽管 `Tor` 软件包包含一个预配置的 `Firefox` 浏览器，但你仍需要遵循一些可能并不明显的规则。

- 1.) 永远在网络上提供任何可能用于识别你身份的敏感信息。这意味着使用你的信用卡购买物品、登录 `Facebook` 等社交媒体网站。卡交易是可追踪的。事实上，`Tor` 甚至会导致通过 `Tor` 出口节点的标记。
- 2.) 永远不要混合浏览器。不要使用你每天访问 `Facebook` 和 `ISP` 邮箱的同一个浏览器来访问 `Tor` 网络。超级 `Cookie` 可以泄露你在 `Tor` 之外访问的网站，并导致对你身份/`IP` 地址的关联攻击。
- 3.) 始终禁用 `Javascript`。此的原因是因为漏洞可以通过使用 `Flash` 暴露你的 `IP` 地址。`Flash` 视频只有在启用此项时才能工作。安装 `Tor` 后，确保 `NoScript` 插件的设置是开启的，而不是在插件选项屏幕默认关闭。
- 4.) 安装最少量的浏览器插件。你希望像其他人一样纯净。过多的添加项、插件、游戏等可以作为身份灯塔——你使用的字体、你使用某些功能的时间，都可以用来建立你的个人画像。保持纯净。
- 5.) 禁用浏览器选项卡中的任何自动更新。这也包括任何插件的更新。你应该手动更新，而不是自动更新。

# 第 3 章 - Tor 与种子下载

关于 `Torrent` 和 `Tor` 网络的一些说明。从表面上看，通过 `Tor` 网络运行你的 `Torrent` 客户端似乎是一个显而易见的好主意。毕竟，如果 `Tor` 能掩盖你普通的 `Firefox` 下载，那么它一定也能处理 `Torrent`，对吧？嗯，既是如此，也不是如此。是的，你可以使用你喜欢的 `Torrent` 客户端通过 `Tor` 路由流量，但由于几个原因，这并不是一个好主意。

首先，`Tor` 的开发初衷并不是为了承受 `Torrent` 下载通常产生的那种破坏性的流量带宽压力。

其次，大多数如 `uTorrent`、`BitSpirit` 和 `libTorrent` 等 `Torrent` 客户端在代码上并不完善，无法在 `Tor` 网络上让你匿名。它们通常会忽略其 `socks` 代理设置，因为 `Torrent` 下载深度涉及 `UDP` 协议，它们会将你的真实 `IP` 地址发送给追踪器（`tracker`），从而完全背离了 `Tor` 的目的。事实上，`Tor` 仍然在执行其代码中定义的功能：通过 `Tor` 网络匿名地将任何数据包发送到你的目的地。然而，它在发送时，同时也把你的 `IP` 地址包含在了 `Torrent` 器之中……匿名地。

这就像是直接把一封密信寄给了你正试图躲避这封信的人。这并不是 `Tor` 本身的问题，而是 `Torrent` 追踪器的编码方式。唯一的解决办法是 `Torrent` 程序的开发者亲自重写他们的程序，使其与 `Tor` 网络和谐工作，而他们可能在短期内不会抽空去做这件事（这让 `Tor` 开发者们非常高兴）。

## Tor 的洋葱站点 (Tor Onion Sites)

`Tor` 网络中最秘密的元素之一是 `Tor` 的洋葱网站（`onion` websites），它们是作为匿名隐藏服务的伪顶级域名。换句话说，它们之所以是“隐藏的”，是因为它们只能由 `Tor` 网络内部的 `Tor` 用户访问，无法通过开放网访问。创建此类隐藏站点的目的是让网站管理员以及访问此类站点的人无法被追溯。由于基于隐藏服务协议的站点无法从普通互联网访问，你必须知道要寻找的 `onion` 地址。你可以像访问普通网站一样，通过在地址栏中输入地址来连接 `Tor` 上的 `onion` 网站。例如，你可能访问 `Tor2Web`，此时地址是：

`http://tor2web.org/`

关于 `tor2web` 的警告：它旨在提供单向安全保护，即保护在 `Tor` 上发布内容的人的身份，而不是浏览内容的人。如果你想在浏览时保持安全，你需要安装 `Tor` 程序。在涉及安全时，便利性和速度应该始终让位。

不需说，如果一个隐藏网络不是真正匿名的，它就不会对不法网站管理员完全无害。为此，开发了隐藏 `Wiki`（`Hidden Wiki`），这是一个单一的 `.onion` 页面，类似于维基百科的结构，概述了从政治活动分子到可以想象的所有可能的犯罪团体。它提供了指向数百个各种 `.onion` 站点的链接，涵盖了从如何获取非法药物、盗版操作、病毒制作、匿名使用比特币、非法色情、被黑客攻击的 `Paypal` 账户甚至如何雇佣职业杀手的一切内容。不需说，这些网站中的某些需要谨慎对待。

请注意你所在国家关于法律允许获取物品的规定。在阿姆斯特丹或日本通行的做法在美国当局眼中可能行不通。记住，存在于深网（`Deep Web`）中的仅仅是：信息。信息本身无法做任何事。文字是重新排列的字母，用来传达你的观点。图片和视频只是在你的屏幕上移动的 `0` 和 `1`。是它们最终的用途定义了道德。

从本质上说，隐藏 `Wiki` 与任何普通的线下黑市运作并没有太大区别。它恰好是在线，并且任何具备一点搜索引擎搜索能力的人都可以访问。深网中的并非所有信息都用于不法目的。像 `Freenet` 一样，有很多不同的网站专注于暴露人权侵犯、政治腐败和涉及高层政治家的政府丑闻。归根结底，你如何处理这些数据决定了犯罪因素。

## 测试你在 Tor 上的 IP 地址可见性

安装好 `Tor` 后，你可能想要测试你的 `IP` 地址，看看它是否真的广播 `Tor IP` 而不是你的真实 `IP` 地址。如果你安装了 `Tor` 的默认安装包，`Tor` 将把你广播的 `IP` 作为你的起始页显示。如果你想自己检查，请访问：

`http://whatismyipaddress.com/`

这不仅会显示你的 `IP` 地址，还会显示你的互联网服务提供商（`ISP`）以及它在谷歌地图上的位置。还会显示城市和国家。当你使用 `Tor` 时，你将看到与你目前居住地不同的城市/国家。记录下你在 `Tor` 之外的 `IP` 地址，如果你特别疑神的话（我就是如此），那么在启动 `Tor` 时检查这个网站即可。

## VPN

过去几年出现了许多不同的 `VPN`（虚拟专用网络）提供商，在几乎每个国家都有服务器机群。`VPN` 的作用与 `Tor` 网络有些相似。它向你的目的地发送不同的 `IP` 地址，无论该目标是网页、`Usenet` 提供商还是网络主机。这有其优缺点。首先，`VPN` 的费用与你获取 `Usenet` 相同：每月大约十美元。这个金额随提供商的不同而波动。有时多一点，有时少一点，但所有提供商都让你像登录 `ISP` 一样登录他们的服务。大部分配置是自动的，不需要任何技术魔术即可完成。大约五分钟。

另一个区别是，虽然 `Tor` 提供匿名性且是免费的，但 `VPN` 会为你提供*隐私性*，但不一定是*匿名性*。这是因为中间人（在这种情况下是 `VPN`）知道你的真实 `IP` 地址。他们必须知道这些信息以便转发你的请求。`VPN` 服务基于与 `Tor` 不同的技术。它是为了*速度*和*稳定性*而构建。你说 `Torrent`？随你便。

此外，假设你是一个中国异见人士。你不喜欢国家在言论和人权方面的走向。你不能恰恰在周报上批评中国政府，对吧？当然不能。那么，一个良好的、守法的异见人士该怎么办呢？你使用另一个国家的 `VPN` 建立一个新闻网站，并通过互联网门户传播你的异见。你不一定非要建立一个网站。你只需设置你的新闻阅读器通过 `VPN` 连接访问 `Usenet`。这样，中国政府就无法通过 `IP` 地址确定任何反政府信息的来源（除非当然，你暗示了某些足以定罪的个人信息）。
