## 11.2.1 问题调查

正如方法论中讨论的，首先要做的是收集有关系统的信息。因此，我们运行 `top` 命令来查看动态资源利用率。在示例 11-5 中，`top` 报告 WebSphere Application Server 使用的 CPU 约为 1%。分配给系统的内存已被完全利用。交换字段应为零。如果不是，则操作系统正在通过使用磁盘空间来模拟存在更多的 RAM，这是一个比实际存储慢得多的过程。
