# 运算符

| 选项 | 返回 |
| :--- | :--- |
| `-r file` | 如果文件存在且可读，则返回 `True`。 |
| `-s file` | 如果文件存在且大小大于零，则返回 `True`。 |
| `-t fd` | 如果文件描述符 `fd` 已打开并与终端设备关联，则返回 `True`。 |
| `-u file` | 如果文件存在且设置了 `setuid` 位，则返回 `True`。 |
| `-w file` | 如果文件存在且写，则返回 `True`。 |
| `-x file` | 如果文件存在且可执行，则返回 `True`。如果文件存在是目录，则当前进程可以搜索该目录。 |
| `-z string` | 如果字符串长度为零，则返回 `True`。 |
| `-L file` | 如果文件存在且是符号链接，则返回 `True`。 |
| `-O file` | 如果文件存在且属于此进程的有效用户 ID，则返回 `True`。 |
| `-G file` | 如果文件和组与此进程的有效组 ID 匹配，则返回 `True`。 |
| `-S file` | 如果文件存在且是套接字 (`socket`)，则返回 `True`。 |
| `file1 -nt file2` | 如果 `file1` 存在且比 `file2` 新，则返回 `True`。 |
| `file1 -ot file2` | 如果 `file1` 存在且比 `file2` 旧，则返回 `True`。 |
| `file1 -ef file2` | 如果 `file1` 和 `file2` 存在并指向同一个文件，则返回 `True`。 |
| `string = pattern` | 如果 `string` 匹配模式，则返回 `True`。 |
| `string != pattern` | 如果 `string` 不匹配模式，则返回 `True`。 |
| `string1 < string2` | 根据字符的 `ASCII` 值，如果 `string1` 在 `string2` 之前则返回 `True`。 |
| `string1 > string2` | 根据字符的 `ASCII` 值，如果 `string1` 在 `string2` 之后则返回 `True`。 |
| `exp1 -eq exp2` | 如果 `exp1` 等于 `exp2`，则返回 `True`。 |
| `exp1 -ne exp2` | 如果 `exp1` 不等于 `exp2`，则返回 `True`。 |
| `exp1 -lt exp2` | 如果 `exp1` 小于 `exp2`，则返回 `True`。 |
| `exp1 -gt exp2` | 如果 `exp1` 大于 `exp2`，则返回 `True`。 |
| `exp1 -le exp2` | 如果 `exp1` 小于或等于 `exp2`，则返回 `True`。 |
| `exp1 -ge exp2` | 如果 `exp1` 大于等于 `exp2`，则返回 `True`。 |
| `(exp)` | 如果 `exp` 为真，则返回 `True`。 |
| `! exp` | 如果 `exp` 为假，则返回 `True`。 |
| `exp1 && exp2` | 如果 `exp1` 和 `exp2` 均为真，则返回 `True`。 |
| `exp1 || exp2` | 如果 `exp1` 或 `exp2` 任一为真，则返回 `True`。 |

## 重定向与管道：`<`, `<<`, `>`, `|`

`ZSH` shell 还支持 `BASH` 章节中描述的标准输入输出重定向操作和管道。（详细解释，请参见第 1 章。）如果设置了 `noclobber` 特，要通过重定向覆盖现有文件，需要使用 `>!` 而不仅仅是 `>`。

## 背景：`&`

你通过在命令行的末尾添加一个符号 `&` 来在后台执行命令。当你这样做时，会显示用户作业号和系统进程号。放在括号中的用户作业号是用户引用作业的数字。系统进程号是系统识别作业的数字。在下一个示例中，打印文件 `mydata` 的命令被放在后台执行。

```
$ lpr mydata &

[1] 534

$ 
```

以下是每个 `Z-shell` 内置命令的描述。命令按字母顺序排列。每个描述都从命令的语法开始。

## 冒号 (`:`)

```
: [arguments]
```

冒号允许你在同一行命令上列出多个命令，每个命令之间用 `:` 分隔。退出码为 0。

## 点 (`.`)

```
. filename [arguments]
```

## `Z-Shell` 命令

点操作从当前 shell 中的文件读取并执行命令。它返回该文件中执行的最后一个命令的退出状态。如果文件名不包含完整路径名，则使用 `PATH` 中定义的路径名来定位文件名所在的目录。如果设置了 `PATHDIRS`，shell 会在 `PATH` 的组件中查找包含该文件的目录。

## 双括号：`(( ))`

```
((expression))
```

这是 `let` 命令的另一种形式，在两个双括号之间包含算术表达式。在 `((` 之后，直到匹配的 `))` 之前，所有的字符都被视为带引号的表达式。

## 双括号：`[[ ]]`

```
[[expression]]
```

包含双括号会评估条件表达式，如果为真，则返回 0 退出状态。

## `CTRL-z`：中断

你可以使用 `CTRL-z` 命令中断作业并停止它。这会将作业放在一旁，直到它重新启动。作业并没有结束；它只是保持挂起状态，直到你想继续执行。当你准备好时，可以使用 `fg` 或 `bg` 命令在前台或后台继续该作业。`fg` 命令将在前台重启中断的作业。`bg` 命令将中断的作业放在后台运行。（更详细的解释，请参见第 1 章中的此标题。）
