# 有爪动物 (Kinorhynchs)

一个自由生活的海洋无脊椎动物门，长度小于 0.04 英寸（1 毫米）。它们具有分节结构，且缺乏外部纤毛（见插图）。有爪动物是底栖生物，之所以这样称呼是因为它们通常居住在从潮间带到深海栖息地的泥或沙中。通常承认两个目：圆吻有爪纲 `Cyclorhagida` 和同型有爪纲 `Homoloroidida`。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1225_1.png)

身体覆盖着由下方表皮分泌的透明角质层。角质层仅在幼体生长过程中蜕皮。身体被划分为三个区域：头节、颈节和一个由11个体节组成的躯干。头部可以完全缩回。当外翻时，它会伸出五到七个环状的后弯刺，称为钙刺 `scalds`。颈部由称为钙片 `placids` 的板块组成，当头部缩回时，这些板块起到关闭躯干前开口的作用。大多数有爪动物在第三或第四体节的腹面有一对粘附管。[R.P.H.]

# 基尔霍夫电路定律 (Kirchhoff's laws of electric circuits)

处理节点处电流关系和回路中电压关系的基本自然定律。这些定律常用于网络的分析和求解。可以直接使用它们来解决电路问题，它们也是用于更复杂网络的电路定理的基础。基尔霍夫电压定律的一种表述方式是：“在每一时刻，沿闭合回路同一方向计算的电压升的代数和等于电压降的代数和。”基尔霍夫电流定律可以表述为：“在任何给定时刻，流向某点的所有电流的瞬时值之和等于离开该点的所有电流的瞬时值之和。”参见 `电路`（电学）。[K.Y.T.; R.T.W.]

# 风筝 (Kite)

一种系留的飞行装置，通过风与装置相对运动产生的空气动力学力来支撑其自身以及连接地面的缆绳。这种相对风可能仅仅源于空气的自然运动，也可能是由通过连接缆绳拖曳风筝而产生的。

所有风筝的升力都是通过向下偏转空气产生的。动量的这种变化产生了一个向上的力。为了成功飞行，风筝必须具有极低翼载荷（重量/面积），以便即使在风速不高的日子也能飞行。它必须完全稳定，因为操作员可用的唯一控制手段是缆绳的长度以及收线或放线的速率。高效的设计要求其升阻比尽可能高。参见 `空气动力`；`空气动力学`。[D.C.H]

# 猕猴桃 (Kiwifruit)

一种生长旺盛的落叶结果藤本植物（猕猴桃科 `Actinidiaceae`），原产于中国中部，通常生长在森林边缘潮湿且受遮蔽的区域。猕猴桃的成功结果需要同时拥有母本品种和父本授粉品种。猕猴桃产业依赖于单一的母本品种“哈维” `Hayward`，其果实具有奶白色的中心芯、黑棕色种子，以及被浅棕色毛皮包围的明亮半透明绿色果肉。它适应温带地区的温和气候，需要 600–850 小时的冬季低温休眠（温度在 32 °F 和 45 °F 之间，即 0 和 7 °C）以确保芽均匀萌动。`猕猴桃` 的木质部在低于 14 °F（–10 °C）的温度下易受冬季伤害，花蕾在低于 29 °F（–1.5 °C）的霜冻下会受到损害。

猕猴桃 `Actinidia deliciosa` 于 1904 年随着从中国带去的种子被引入新西兰进行栽培，使其成为最近驯化的结果植物之一。看起来，新西兰现在的所有藤本植物都源自一株父本植株和两株母本植株。主要的猕猴桃生产国有意大利、新西兰、日本、智利、法国、希腊、美国（加利福尼亚州）和澳大利亚。

`猕猴桃` 是维生素 C、矿物质（如钾、钙和磷）以及膳食纤维的来源。主要用途是鲜食市场，但等外果可加工成罐头、冷冻果片、酒、果酱、果汁和干果。参见 `果实`；`噻嗪类`。[J.K.H]

# 克雷伯氏菌 (Klebsiella)

一种革兰氏阴性、非运动性细菌属。特征性的巨大粘液菌落是由于产生大量的荚膜物质。`Klebsiella` 物种常见于土壤和水中、植物上以及动物和人体内。`Klebsiella` 的无害菌株是有益的，因为它们能在土壤中固定氮。致病性物种包括 `K. pneumoniae`（肺炎克雷伯菌）、`K. rhinoscleromatis`（鼻硬结克雷伯菌）和 `K. ozaenae`（臭鼻克雷伯菌），也称为 `K. pneumoniae` 的亚种 `pneumoniae`、`rhinoscleromatis` 和 `ozaenae`。

`Klebsiella pneumoniae` 是临床实验室中第二常见的肠相关细菌。`Klebsiella` 含碳水化合物的荚膜通过保护包裹的细菌免受白细胞吞噬从而促进毒力；无荚膜的 `Klebsiella` 变异株不致病。荚膜 1 型和 2 型引起肺炎；8 型、9 型、10 型和 24 型常见于尿路感染。参见 `大肠杆菌`；`肺炎`。

`克雷伯氏菌` 占医院内获得性感染的大量百分比，主要是皮肤感染（在免疫功能受损的烧伤患者中）、菌血症和尿路感染。它也是静脉输液（如葡萄糖溶液）和其他医疗设备的最常见污染物。参见 `医院感染`。

`克雷伯氏菌` 可能产生类似 `大肠杆菌` 的肠毒素，并引起婴儿和幼儿的急性胃肠炎。由 `克雷伯氏菌` 引起的肠道疾病在人口密度较大、卫生条件较差的地区更为普遍。`克雷伯氏菌` 的其他毒力因子包括其相对较高的在宿主外多种环境中存活和繁殖的能力，以及其相对简单的营养需求。参见 `内毒素`。

`克雷伯氏菌 rhinoscleromatis`（鼻硬结克雷伯菌）引起鼻硬结病，这是一种上呼吸道慢性破坏性肉芽肿性疾病，最常见于东欧、中非和热带南美洲。`克雷伯氏菌 ozaenae`（臭鼻克雷伯菌）是慢性鼻炎（臭鼻症）的一个病因，这是一种鼻粘膜破坏性萎缩，偶尔在尿路感染和菌血症中分离出来。参见 `医学细菌学`。[D.J.Ev]

# 速调管 (Klystron)

一种真空电子束管，其中电子束中的电子获得的初始速度调制随后导致电子束的密度调制。速调管可作为微波频段的放大器或振荡器使用。

用作放大器时，速调管通过输入腔接收微波能量，电子束穿过该腔。微波能量调制束中电子的速度，随后电子进入漂移空间。在此处，较快的电子追上较慢的电子形成电子团。以这种方式，初始束的均匀电流密度被转换为交流电流。具有显著交流电流成分的团状束随后通过输出腔，束将其交流能量转移给输出腔。参见 `微波`。

速调管可以通过将部分输出反馈到输入电路作为振荡器工作。更广泛使用的是反射波振荡器，其中电子束本身提供反馈。束聚焦通过腔并在其中进行速度调制，类似于放大器。腔通常有栅极，以在短距离内集中电场，使场能够与缓慢、低速的电子束相互作用。离开腔后，束进入一个由其运动方向相反、由相对于阴极具有负电位的反射极产生的直流电场区域。电子没有足够的能量到达电极，但在空间中被反射并返回再次通过腔。反射点由电子速度决定，速度较快的电子在对抗电场的方向上前进得更远，因此返回所需的时间比速度较慢的电子更长。反射波振荡器用作 3 到 200 GHz 的信号源。它们还用作视距无线电中继系统中的发射管以及低功率雷达。[R.B.N]

# 克努森数 (Knudsen number)

在气体动力学中，分子平均自由程 $\lambda$ 与某个特征长度 $L$ 的比值：$\text{Kn} = \lambda/L$。所选的长度取决于所考虑的问题。例如，它可以是管道的直径、浸入流体中的物体或边界层或激波的厚度。参见 `平均自由程`。
