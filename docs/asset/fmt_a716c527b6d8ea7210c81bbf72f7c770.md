
# Perl 语法与结构（续）

## 变量

Perl 支持三种基本变量类型：标量、数组和哈希（关联数组）。Perl 没有原生的布尔数据类型，如 `true` 或 `false`，但通过比较字符串和整数来获得相同的行为。

Perl 变量在使用前不需要声明。

变量名以一个“特殊字符”（也称为 `sigil`）开头，后跟一个字母和任意数量的字母数字字符（标识符），包括下划线。特殊字符表示数据类型和上下文。特殊符号后面的字符区分大小写。

如果变量名以字母开头，它可以由任意数量的字母（下划线算作字母）和/或数字组成。如果变量名不以字母开头，它必须由单个字符组成。

参见第 5 章“名字里有什么？”

## 标量

标量变量保存单个值、单个字符串、数字等。

标量变量名称前以 `$` 符号开头。标量上下文意味着正在使用 *一个值*。

参见第 5 章“名字里有什么？”

**示例**

```perl
$first_name = "Melanie";
$last_name = "Quigley";
$salary = 125000.00;
print $first_name, $last_name, $salary;
```

## 数组

数组保存标量的 *有序列表*；即，字符串和/或数字。数组的元素从 0 开始的整数进行索引。数组名称前以 `@` 符号开头。

一些常用的内置数组函数：
- `delete` 从数组元素中移除一个值
- `pop` 移除最后一个元素
- `push` 向数组末尾添加新元素
- `shift` 移除第一个元素
- `sort` 对数组元素进行排序
- `splice` 从数组的某个位置移除或添加元素
- `unshift` 向数组开头添加新元素

参见第 5.3 节“数组函数”。

**示例**

```perl
@names = ( "Jessica", "Michele", "Linda" );
print "@names"; # 打印数组，元素之间用空格分隔
print "@names[0] and @names[2]"; # 打印 "Jessica" 和 "Linda"
print "$names[-1]\n"; # 打印 "Linda"
$names[3]="Nicole"; # 将新值分配为第 4 个元素
```

## 哈希

称为 *哈希* 的关联数组是一个无序的键/值对列表，由字符串索引。哈希名称前以 `%` 符号开头。（当 `%` 被包含在单引号或双引号中时，它不会被评估。）只要键不以数字开头或包含空格、内部连字符或特殊字符，键 *就不需要加引号*。

一些常用的内置哈希函数：
- `keys` 获取哈希中的所有键
- `values` 获取哈希中的所有值
- `each` 从哈希中获取一个键/值对
- `delete` 移除一个键/值对
- `exists` 测试键是否存在

参见第 5.4 节“哈希（关联数组）函数”。

**示例**

```perl
%employee = (
    "Name"    => "Jessica Savage",
    "Phone"   => "(925) 555-1274",
    "Position" => "CEO"
);
print "$employee{Name}";  # 打印一个值
$employee{"SSN"}="999-333-2345";  # 分配一个键/值
```

## 预定义变量

Perl 提供大量预定义变量。以下是一些常见预定义变量的列表：
- `$_` 默认的输入和模式搜索空间。
- `$.` 最后访问的文件名的当前行号。
- `$@` 来自最后 `eval()` 运算符的 Perl 语法错误消息。
- `$!` 产生当前错误消息的值，用于 `die`。
- `$0` 包含正在执行的程序名称。
- `$$` 运行此脚本的 Perl 的进程号。
- `@ARGV` 包含命令行参数。
- `ARGV` 一个特殊文件名，迭代 `@ARGV` 中的命令行文件名。
- `@INC` 库文件的搜索路径。
- `@_` 在子例程中，数组 `@_` 包含传递给该子例程的参数。
- `%ENV` 哈希 `%ENV` 包含你当前的环境。
- `%SIG` 当设置时，哈希 `%SIG` 包含信号的信号处理程序。

参见附录 A 的第 A.2 节“特殊变量”。

## 常量（字面量）

常量值一旦设置，就不能被修改。常量的示例是 `Pi` 或一英里中的英尺数。它不会改变。常量通过 `constant` 指令定义，如下例所示。

**示例**

```perl
use constant BUFFER_SIZE => 4096;
use constant Pi => 4 * atan2(1, 1);
use constant DBGLOGGING => 0;
use constant ISBN => "0-13-028251-0";
Pi += 6; # 不能修改 Pi；会产生错误。
```

### 数字

Perl 支持整数（十进制、八进制、十六进制）、浮点数和科学计数法。

参见第 4.3.2 节，“字面量（数字、字符串和特殊字符）”。

**示例**

```perl
$year = 2016; # 整数
$mode = 0775; # 八进制数
$product_price = 29.95; # 十进制浮点数
$favorite_color = 0x33CC99; # 十六进制整数
$distance_to_moon = 3.844e5; # 科学计数法浮点数
$bits = 0b10110110; # 二进制数
```

### 字符串和引号

字符串是包裹在引号中的字符序列。引号必须匹配；例如，'string' 或 "string"。

标量变量和数组变量（`$x`, `@name`）以及反斜杠序列（`\n`, `\t`, `\v` 等）在双引号内会被解释；反斜杠可以转义引号。

可以在双引号中嵌入单引号；也可以在单引号中嵌入双引号。

*here* 文档是嵌入在用户定义标签之间的文本块；第一个标签前由 `<<` 引导。

以下展示了三种引用字符串的方式：
- 单引号：'It rains in Spain';
- 双引号："It rains in Spain";
- *here* 文档：

```perl
print <<EOF;
    It rains in Spain
EOF
```

参见第 4.3.1 节，“引号很重要！”和第 4.3.3 节，“无引号打印——*here* 文档”。

**示例**

```perl
$question = 'He asked her if she wouldn\'t mind going to Spain';
$answer = 'She said: "No, but it rains in Spain."';
$line = "\tHe said he wouldn't take her to Spain\n";
$temperature = '78';
print "It is currently $temperature degrees.";
# 打印：'It is currently 78 degrees.'，因为变量
# 在双引号内会被解释，但在单引号内不会
print <<END;
    It
    rains in
    Spain
END
# 打印："It rains in Spain"
```
