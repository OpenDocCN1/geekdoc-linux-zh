## 检查安全上下文

与 `ls`、`id` 和 `ps` 命令一起使用的 `-z` 选项分别用于检查文件、用户和进程的安全上下文。安全上下文告知你访问给定进程或对象所需的用户角色：

```bash
ls -lZ

id -Z

ps -eZ
```
