
# 饱和潜水

这种潜水类型允许长时间浸没（1–2 周）。它利用了在给定深度下，人体将被呼吸气体完全饱和这一事实，因此无论浸没时间多长，返回水面所需的减压时间都不会增加。使用这种方法，潜水员可以在海底生活，进行详细的测量和观察，并工作而不产生不良影响。这种潜水需要在特制的舱室内进行较长时间的减压，以消除潜水员体内高浓度的呼吸气体。对于超过 200 英尺（60 米）的深海潜水，以天或周为单位的减压时间（随深度增加而增加）很常见。

# 生理学

水下环境对浸没潜水员的影响与海平面处体验到的截然不同。潜水过程中有两个因素非常明显。随着周围水深度的增加，潜水员所呼吸空气的压力也随之增加。此外，随着压力增加，潜水员组织中气体的溶解度也增加。因此，组织会积聚某些未被代谢的气体。某些气体含量的增加会导致特定且往往危险的生理效应。

海平面处的总大气压约为 760 mmHg 或 30.4 in. Hg。水下压力以每下降 33 英尺（10 米）增加 1 atm（10 千帕）的速率上升。施加在身体和呼吸气体上的总压力随深度按比例增加。随着气体压力的增加，身体吸收的气体量也增加。如果潜水员在沉箱内呼吸空气，这一点尤为明显，因为呼吸气体中氮气的百分比随氧气被移除的量而成比例增加。同样，在潜水过程中，体内的二氧化碳含量也会增加，特别是如果呼出的空气未与吸入的空气分离时。

气体对潜水员产生的较明显效应之一是由氮气引起的。氮气占通常呼吸空气的约 78%，其在组织中的溶解度随大气压增加而增加。当氮气溶解在体内时，超过 50% 存在于脂肪组织中；这包括包裹许多神经细胞的髓鞘。当潜水员经历压力增加时，神经组织中的氮气量增加，导致氮醉或“深海狂喜”。氮醉可在 415 英尺（130 米）或 5 atm（500 kPa）时发生，并随着潜水员下潜到该深度以下而加剧。氮醉中常见的非理性行为和精神亢奋可能导致潜水过程中的严重甚至致命错误。潜水员在水中保持时间而不出现症状的最大时间随深度增加而减少。

与人类潜水相关的早期被认识到的问题之一是减压病，也称为潜水员病或沉箱病。如果允许潜水员在表面下停留很长时间，组织中溶解气体的体积将增加。对于呼吸空气的情况，氮气的情况尤为如此。当氮气在组织中积聚时，只要压力保持恒定，它就保持溶解状态。然而，当上升过程中压力降低时，组织中会形成气泡。氮气气泡可能出现在神经或肌肉中引起疼痛，或者出现在脊髓或大脑中导致瘫痪、头晕、失明甚至昏迷。在循环系统中形成的气泡会导致空气栓塞。如果栓塞发生在肺部循环中，则发生一种称为“窒息”的状况。参见 减压病。

J. S. Haldane 于 1907 年提出了一种预防减压病的方法。Haldane 引入了阶段性减压法，即让潜水员上升几英尺，然后停留在该水平，直到体内组织中的气体在新压力下重新平衡。这种逐级上升一直持续到潜水员最终到达水面。该方法的现代变体是在潜水员到达水面后将其放入减压舱中，以模拟海洋深度的减压时间段。

# 潜水动物

真正的水生动物不需要专门的潜水反应，因为它们能够直接从水中获取氧气，从而在水生环境中无限期生存。另一方面，陆生或陆地动物在许多情况下以不同程度上回到了水生生活方式。所有这些动物都面临着在仅有陆地动物生理能力的情况下，在水生环境中获得必要气体交换的问题。许多这些陆生动物适应得很好，在水中几乎获得了完美的自由。

所有陆生脊椎动物类别（鸟类、哺乳动物和爬行动物）都有部分时间生活在水下或通过潜入水中一段时间来寻找食物或庇护所的物种。例如，淡水哺乳动物物种之一是北美的海狸。在这些及其他动物中观察到的第一个变化通常是心跳缓慢。水面的接触导致心率降低，称为心动过缓。然而，那些传统上利用水生栖息地的动物在短时间内表现出更明显的心率降低。在另外两个包含潜水动物的类别中，爬行动物和鸟类，如此优秀的例子反映了与哺乳动物相似的心率降低。

恒温动物对浸没的反应比爬行动物类型快得多。那些传统上存在于开阔海洋环境中的哺乳动物，如海豹，表现出最剧烈的反应。爬行动物通常比恒温动物使用更少的氧气，静息心率较慢，因此预期其反应不那么壮观。此外，爬行动物的反应时间通常比哺乳动物慢，并通常受其潜水的温度影响，因此预期对潜水刺激的反应较慢。

具体而言，潜水反应使动物能在水下停留更长时间。不仅心率减慢，流向特定肌肉的血流也减少或完全停止。因此，肌肉无氧糖酵解产生的乳酸不太可能进入体循环并改变大脑和心脏等重要器官的功能。这种反应还降低了血液中出现氢离子积聚并刺激化学感受器（响应血液二氧化碳水平和氢离子浓度变化的感受器）的可能性，这些感受器控制呼吸。因此，在潜水期间，流向最重要器官（如大脑、心脏和肺）的血液保持恒定且不受限制，这些器官中的动脉氧保持正常水平，毛细血管的血液灌注未发生改变。

潜水动物体内的其他变化也很明显，但被视为全身化学的变化。例如，糖原和三磷酸腺苷是肌肉的主要能量来源，在潜水动物中供应充足，似乎是为了在最需要时储存。氧气储备是潜水动物浸没时间长短的关键，潜水动物肌肉中的肌红蛋白浓度赋予了它们储存氧气的惊人能力。参见 潜水。

# 除法

在算术和代数中，当已知两个因子的乘积和其中一个因子时，寻找另一个因子的过程。在英语和美国算术基础教学中，使用符号 `÷` 来表示除法。除法更常由双点 `·`、横杠 `–` 或实字符 `;` 表示；因此 `x/y`、`x̄` 或 `x/y` 表示数字 `x` 除以数字 `y`。视为乘法逆运算时，`x/y` 是一个符号，表示与 `y` 相乘等于 `x` 的数字。基于乘法定义除法的另一种方式是由数字倒数概念提供的。如果 `y` 是任何非 0 的数字（实数或复数），则存在一个数字，表示为 `1/y`，称为 `y` 的倒数，其与 `y` 的乘积为 1。那么 `x/y` 是 `x` 和 `1/y` 乘积的符号。这种除法观点提供了一种将概念扩展到实数或复数以外的对象的方法。参见 代数；乘法。

# 多齿兽类

多齿兽类是已知最原始的哺乳动物目之一，发现于北美和英格兰的侏罗纪以及可能的拉赫特沉积物中。多齿兽的下颌关节由齿骨和鳞骨形成，但关节骨和方骨形成次要颌关节。其他中生代目的早期成员具有相同的双重关节，但到晚期侏罗纪时期，只有多齿兽仍保留这种过渡性的爬行动物-哺乳动物状态。参见 哺乳纲。

# 狗

所有家犬品种、野犬及相关物种都属于犬科。尽管已知有各种家犬品种，但所有家犬的科学名称均为家犬（`Canis familiaris`）。家犬的起源不明，但它们似乎与狼关系最密切。在许多方面，狗在结构上是原始的，并表现出遗传可塑性，这解释了众多品种的存在。

## 家犬品种

家犬品种有 100 多种，其分类主要基于用途。家犬品种包括运动型犬、猎犬、梗犬、工作犬和玩赏犬。

运动型犬经过训练并用于检索或寻找猎物。此类中最大的群体是猎鹬犬，约有 10 个类型。猎鹬犬经过训练检索猎物，因此猎取鸟类和水生动物。检索犬专门训练用于为猎人定位和检索猎物，最常用于猎取水禽。有四个品种：卷毛犬、切萨皮克湾猎犬、金毛寻回犬和拉布拉多犬。指示犬和指示鸟犬用于猎取山地猎物，它们在猎人前方奔跑，指示猎物位置直到猎人到达，并在猎物被惊起和射击后检索猎物。用于这些活动的品种包括魏玛犬、英国和爱尔兰指示犬以及德国短毛指示犬。

猎犬群包括巴吉度猎犬、寻血猎犬、惠比特犬、腊肠犬、爱尔兰猎狼犬和比格犬。灵缇犬，最古老的品种之一，以其瘦削的身体和长腿为速度而建。寻血猎犬和狐猎犬（较小且活泼的狗）用于狩猎，主要靠嗅觉。比格犬现在更多是宠物而非猎犬，也能追踪气味，且步行跟踪更容易。

梗犬最初培育用于猎取穴居动物，如獾和狐狩。波士顿梗是唯一起源于美国的品种。猎狐梗，该群体的典型代表，可能源自狐猎犬。它最初为猎狐而培育，但也是优秀的灭鼠犬。其他梗犬包括阿伊鲁代尔梗（群体中最大的）以及苏格兰梗和苏格兰高地梗。

大多数工作犬是大型动物，用作挽兽、警察工作、放牧以及盲人导盲犬。其他挽兽品种包括阿拉斯加马拉缪特犬、爱斯基摩犬和萨摩耶犬。用作护卫犬和警察工作的动物包括杜宾犬、德国牧羊犬和大丹犬。柯利犬、比利时牧羊犬和英国牧羊犬是出色的牧羊犬。斗牛犬现在更多是宠物和家犬而非护卫犬，但如果遇到闯入者会好斗且不会松口。贵宾犬据说是最聪明的狗，可训练为枪猎犬，最初用于猎鸭。

一些玩赏犬已有数百年历史，主要是家犬，可能会发展出保护雇主场所的本能。它们都很小，有些是大型犬的迷你版。吉娃娃是最小的。一些更受欢迎的品种包括博美犬、京巴犬和巴哥犬。

## 狗木

**野生物种。** 该科的野生物种约有 26 种，分布广泛，包括几种野生犬、狼、郊狼、狐和豺。还有许多从未被驯化的野生犬，这与澳大利亚的澳大利亚野犬（`Canis dingo`）不同，后者据信是在史前时期引入澳大利亚的家犬，随后野化回野生状态。亚洲野犬分布在亚洲、爪哇和苏门答腊全境，通常被视为三个不同的物种：野猪犬，以及一个被认为是 `Cuon alpinus` 亚种的物种，后者也被称为西伯利亚野犬。非洲野犬（`Lycaon pictus`）分布于非洲东部和南部的草原地区，但其数量已大幅减少。

欧洲常见的狼（`Canis lupus`）是曾经广泛分布于欧洲、亚洲和北美温带森林地区的物种。该物种已在不列颠群岛灭绝，在法国也几乎绝迹，但在意大利、西班牙和巴尔干半岛等其他欧洲国家仍有分布，且在斯堪的纳维亚国家仍然十分丰富。灰狼或森林狼原本在北美极其常见，现在仅限于阿拉斯加和加拿大亚北极地区。

郊狼（`Canis latrans`）有时被称为草原狼，是真正狼的密切近亲，尽管它的体型比狼小。它们栖息于北美的草原、开阔平原和沙漠地区。
