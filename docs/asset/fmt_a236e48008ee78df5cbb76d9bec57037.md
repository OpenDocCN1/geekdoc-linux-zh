
## ReadError
在打开 tar 文件时发生错误时抛出（例如打开无效文件时）。

## CompressionError
当数据无法解压时抛出。

## StreamError
在类流的 `TarFile` 对象上执行不支持的操作时抛出（例如需要随机访问的操作）。

## ExtractError
提取过程中发生非致命错误时抛出（仅当 `errorlevel` 设置为 `2` 时）。

## 示例

```python
# 打开一个 tar 文件并将一些文件放入其中
t = tarfile.open("foo.tar","w")
t.add("README")
import glob
for pyfile in glob.glob("*.py"):
    t.add(pyfile)
t.close()
```

```python
# 打开一个 tar 文件并遍历其所有成员
t = tarfile.open("foo.tar")
for f in t:
    print("%s %d" % (f.name, f.size))
```

```python
# 扫描 tar 文件并打印 "README" 的内容
t = tarfile.open("foo.tar")
```

```python
for f in t:
    if os.path.basename(f.name) == "README":
        data = t.extractfile(f).read()
        print("**** %s ****" % f.name)
```

## tempfile

`tempfile` 模块用于生成临时文件名和临时文件。

```python
mktemp(suffix, prefix, [dir])
```

创建一个仅供调用进程所有者访问的临时目录，并返回其绝对路径。`suffix` 是一个可选后缀，将附加到目录名之后；`prefix` 是一个可选的前缀，将插入到目录名的开头；`dir` 是应该创建临时目录的位置。

```python
mkfile(suffix, prefix, dir, text])
```

创建一个文件并返回一个元组 `(fd, pathname)`，其中 `fd` 是由 `os.open()` 返回的整数文件描述符，`pathname` 是文件的绝对路径。`suffix` 是附加到文件末的可选后缀，`prefix` 是插入到文件名开头的可选前缀，`dir` 是应该创建文件的目录，`text` 是一个布尔标志，表示以文本模式还是二进制模式打开文件（默认位二进制）。只要系统支持 `os.open()` 的 `O_EXCL` 标志，就能保证文件的创建是原子性的（且安全的）。

```python
mktemp([suffix, prefix, [dir]])
```

返回一个唯一的文件名。`suffix` 是一个插入到文件名开头的可选前缀，`dir` 是创建文件的目录。此函数仅生成唯一文件名，而不会实际创建或打开临时文件。由于此函数在文件实际打开之前创建了名称，它引入了潜在的安全问题。为了解决这个问题，请考虑使用 `mkfile` 代替它。

```python
gettempdir()
```

返回创建临时文件的目录。

```python
gettempprefix()
```

返回用于生成临时文件的前缀。不包含文件可能所在的目录。

```python
TemporaryFile([mode, bufsize, suffix, [prefix, dir]]])
```

使用 `mktemp()` 创建临时文件，并返回一个支持与对象文件相同方法的类文件对象。`mode` 是文件模式，默认认为 `'w+b'`。`bufsize` 指定缓冲行为，`suffix`、`prefix`、`dir` 的含义与 `mktemp()` 相同。此函数返回的对象只是内置文件对象的封装器，可以通过 `file` 属性访问。此函数创建的文件在临时文件对象被销毁时会自动删除。

## NamedTemporaryFile([mode [, bufsize, suffix, prefix, dir [, delete]]])

创建一个与 `TemporaryFile()` 相似的临时文件，但它确保该文件在文件系统中是可见的。可以通过访问返回的文件对象的 `name` 属性获取文件名。注意，某些系统可能会在临时文件关闭之前阻止其被重新打开。`delete` 参数如果设置为 `True`（默认），则强制在临时文件关闭时立即将其删除。

## SpooledTemporaryFile([max_size [, mode [, bufsize, suffix [, prefix [, dir]]])

创建一个临时文件，与 `TemporaryFile()` 相同，但文件内容在达到 `max_size` 指定的大小之前完全存储在内存中。溢出（Spooled）的实现是通过首先将内容保留在 `StringIO` 中，直到需要实际写入文件。如果使用 `fileobj()` 方法执行了任何低级文件 I/O 操作，内存内容将立即写入由 `TemporaryFile` 对象定义的正式临时文件中。`SpooledTemporaryFile` 返回的对象还有一个可以使用 `rollover()` 方法。

| 变量 | same |
| --- | --- |
| max_size | 写入磁盘前的最大大小（字节）。 |
| mode | 打开文件的模式。 |
| bufsize | 缓冲行为。 |
| suffix | 附加到文件名的可选后缀。 |
| prefix | 附加到文件名的可选前缀。 |
| dir | 应该创建文件的目录。 |

## zipfile

`zipfile` 模块用于处理 zip 文件。以下由 `zipfile` 定义的函数和类：

```python
is_zipfile(filename)
```

测试是否为有效的 zip 文件。如果是则返回 `True`；否则返回 `False`。

```python
ZipFile(filename [, mode [, compression [,allow64]]])
```

打开 zip 文件并返回一个 `ZipFile` 实例。`mode` 为 `'r'` 读取现有文件，`'w'` 截断写入新文件，或 `'a'` 追加现有文件。对于 `'a'` 模式，如果文件名是现有文件，将追加到末尾。如果文件名不是 zip 文件，将使用 `ZIP_STORE` 或 `DEFLATED` 创建存档。默认是 `ZIP_STORE`。`allow64` 启用 `ZIP64` 扩展，可用于创建超过 2GB 大小的 zip 文件。默认设置为 `False`。

```python
PyZipFile(filename [, mode [, compression [,allow64]]])
```

打开 zip 文件 `ZipFile()` 但返回一个特殊的 `PyZipFile` 实例，该实例有一个额外的方法 `write()`，用于向存档添加 Python 文件。

```python
ZipInfo(filename [, date_time])
```

手动创建一个新的 `ZipInfo` 实例以包含存档成员的信息。通常情况下不需要调用此函数，除非使用 `ZipFile` 实例的 `writestr()` 方法（后文介绍）。`filename` 和 `date_time` 参数为 `filename` 和 `date_time` 属性提供值。

`ZipFile` 或 `PyZipFile` 实例支持以下方法和属性：

```python
z.close()
```

关闭存档。必须在程序终止前调用以便刷新记录到 zip 文件。

```python
z.debug
```

调试范围 `0`（无输出）到 `3`（大部分输出）。

```python
z.extract(name [, path [, pwd ]])
```

从存档中提取文件并将其放在当前工作目录。`name` 是指定存档成员的字符串或 `ZipInfo` 实例。`path` 指定提取文件的不同目录，`pwd` 是用于加密存档的密码。

```python
z.extractall([path [, members [, pwd ]])
```

将所有成员提取到当前工作目录。`path` 指定不同目录，`pwd` 是加密存档的密码。`members` 是要提取的成员列表，必须是 `namelist()` 方法（下文介绍）返回列表的真子集。

`z.getinfo(name)`

返回关于压缩包成员名称的信息，作为一个 `ZipInfo` 实例（稍后将描述）。

`z.infolist()`

返回一个包含压缩包所有成员的 `ZipInfo` 对象的列表。

`z.namelist()`

返回压缩包成员名称列表。

`z.open(name, mode {, pwd=})`
