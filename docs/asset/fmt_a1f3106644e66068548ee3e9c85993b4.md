
我们将逐一演示并解释这些属性。由 Bash 定义的变量和函数默认是局部的，进入子进程后它们将不再被调用和使用。使用 `set -a` 可以让所有变量和函数默认被子进程调用。

默认情况下，Bash 支持大括号替换（brace replacement），使得可以使用简单的命令快速生成数据序列，例如字母序列表和数字序列表。

可以通过 `braceexpand` 属性开启或关闭该功能。有时在脚本开头设置 `set -e`（错误时退出）是必要的。如果我们写一个脚本，脚本的主功能是创建账户、账户密码并最后输出提示信息。

```
root@server : vim script.if
set -e (error exit)
```

当账户已存在或由于原因导致账户创建失败时，默认脚本仍会坚持执行所有的脚本命令。

显然，这会引发雪崩式的错误提示。有很多这样的脚本，而相关的脚本（如安装软件、修改配置文件和启动服务）可能会因为前面的一个微小错误导致整个脚本出现大规模的错误。设置 `set -e` 可以在第一个命令出错时停止脚本。

### 什么是哈希 (HASH)？

“Hash”允许 Bash 记录已执行命令的 `PATH` 并将其保存在内存哈希表中，这样下次执行该命令时，就不需要通过路径变量搜索命令路径了，这通常会提高效率。

但有时程序的路径会发生变化，因为 Hash 记录的存在会导致命令执行失败。可以看出之前执行的外部命令具有特定的记录信息，而 `hits` 代表命中次数，即系统通过读取哈希表定位命令路径的次数。

```
root@server : hash sample.txt
```

通常情况下上述情况没有问题。但是，如果我们把 `ip` 命令从 `/usr/bin/` 目录移动到 `/bin/` 目录，系统仍会根据哈希表中记录的位置执行命令，导致找不到 `ip` 程序。

```
root@server : hash -d
root@server : hash -r
```

我们可以使用 `hash -d` 删除特定的记录，使用 `hash -r` 清除整个哈希表，或者使用 `set +h` 直接禁用哈希表。这些方法可以解决类似的问题。Hash 通过设置 `histexpand` 属性支持使用感叹号调用。

```
root@server : histexpand
```

历史命令，`yum` 可以直接调用历史中的最后一个命令。默认情况下，当我们使用重定向符号如 `>>` 时，文件会被覆盖，这可能导致数据丢失。

```
root@server : yum <history
```

设置 `noclobber` 可以防止数据被覆盖。如果脚本使用 `tar`、`rsync` 和 `mysqldump` 等工具备份数据，由于备份需要一定时间，脚本被重复执行，例如打开多个终端重复执行同一个脚本，或多个远程用户执行同一个脚本，最终导致备份的文件混乱。

```
root@server : no clobber tar
```

除了使用 `set` 和 `sh` 命令修改 Bash 属性外，我们还可以使用 `tput` 命令来查看或设置命令行终端的属性。`Cols` 可以显示当前终端的列数，134 列表示一行可以显示 134 个字符。

```
root@server : tput
```

你可以通过 `lines` 显示当前终端的行数。`Clear` 命令可以清空当前终端，其效果与执行 `clear` 命令或按下 Ctrl+L 相同。

通过 `cup`，你可以将光标移动到特定的行和列。`sc` 可以保存当前光标位置，而 `rc`可以将光标恢复到上次 `sc` 保存的位置。

```
root@server : cup
```

你可以通过 `civis` 设置不显示光标，通过 `cnorm` 设置显示光标。`blink`可以将终端设置为闪烁模式，`bold`可以将终端设置为加粗模式，而 `rev` 可以交换当前终端的字体颜色和背景颜色。

```
root@server : cvvis
```

通过 `smcup`，你可以保存当前屏幕，`rmcup` 可以恢复最近保存的屏幕状态。通过 `sg0`，你可以取消所有终端属性并将终端恢复到正常状态。`reset` 命令也可以将我们的当前终端重置为初始状态。

```
root@server : rmcup
```

### 在虚拟机中安装 KALI LINUX

在本书的第一模块中，我们简要介绍了如何使用光驱和 USB 驱动器安装 Linux。虽然两者都非常方便且易安装，但由于隐私问题，它们仍然不够安全。对于黑客来说，最重要的方面是通过任何手段隐藏自己的身份。你不能在黑进系统的同时留下系统和 IP 地址的足迹，这些可以追溯到你的家里。此外，使用虚拟机比购买和安装一台全新的系统成本更低。

### 什么是虚拟机？

虚拟机是功能完备的操作系统但在沙箱中运行，而不是直接与硬件通信。虽然与原生硬件性能相比，它们的功能可能较少，但它们仍然非常快速且易用。它们提供了传统方式无法实现的功能。

### 什么是最好的虚拟机软件？

虚拟机软件并不多。其中，Virtual box 和 VMware 广受推荐。在本书中我们将使用 Virtual box，因为它易于使用而且是开源软件。加分项！

### 推荐黑客使用虚拟机吗？

虚拟机指的是具有完整硬件系统功能的完整计算机系统，它由软件模拟并在完全隔离的环境中运行。作为一名黑客，没有什么可以像虚拟机那样对系统文件进行实验。黑客在学习系统如何构建的同时会不断破坏东西。如果你破坏了原生的宿主机系统，可能会给你带来头疼，而且通常不建议这样做。你既能破坏东西又能不破坏任何工作文件的唯一方法就是使用虚拟机客机操作系统。

虚拟机会生成现有操作系统的全新镜像。如今，Linux 发行版开发人员通常都会发布虚拟机文件。它具有与真实操作系统完全相同的功能。进入虚拟机后，所有操作都可以在这个全新的独立系统中自由进行。

### 使用虚拟机技术的优势是什么？

几乎所有企业都使用虚拟化技术来维护其服务和服务。例如，著名的企业软件 Docker 也使用虚拟化技术来提供其服务。在本节中，我们将详细讨论虚拟机的优势。

#### 它降低成本

如果你想在没有虚拟机的计算机上安装 Linux 和 Windows 系统，有两种方法。一种是安装多个硬盘，每个配合操作系统使用。这种方法的缺点是成本较高。

第二种方法是在一个硬盘上安装双系统。这种方法的缺点是安全性不够，因为系统盘的 MBR（主引导记录）是操作系统的必经之路，而 Windows 更加具有主导性。

每次重新安装系统时，几个安装的系统可能会同时崩溃。使用虚拟机软件既省钱又安全。因此，对于新手来说，通过虚拟机学习 Linux 是再不过不过了。

#### 安全且方便

在虚拟机上安装好 Linux 系统后，你不需要担心格式化硬盘。你甚至可以随心所欲地设置和更改虚拟系统的设置。你可以格式化虚拟硬盘，也可以使用 VirtualBox 的高级功能对虚拟系统硬盘进行重新分区。

由于虚拟机软件运行在真实系统上，对虚拟机系统进行的任何操作实际上都是对软件进行的操作。它还可以轻松地使用硬盘或 U 盘导入到其他 Linux 或 Windows 系统中。它非常方便，而且通过加密选项为你提供了大量的隐私保护。对于黑客来说，这确实是一个福音。

#### 简单高效

虚拟机模拟的 Linux 系统与真实的 Linux 系统完全相同。现在，各公司的专用 Linux 服务器通常不会允许新手操作，而测试用的 Linux 服务器通常比较稀缺。如果你在电脑上安装一个虚拟 Linux 系统，你可以随心所欲地学习和测试，不受任何环境的影响。

### 虚拟机运行环境和硬件要求

#### 1. 运行环境

流行的虚拟机软件包括 VMware 和 VirtualBox，它们都有 Windows 和 Linux 版本，也可以用于 macOS 操作系统。

也就是说，它们可以安装在 Windows 和 Linux 平台上：Windows、Linux、UNIX 等可以在 Windows 平台下虚拟化。同样，Windows、Linux、UNIX 等电脑也可以在 Linux 平台上虚拟化。但请记住，根据 Apple 的 EULA（用户许可协议），你只能在苹果硬件上虚拟化 macOS。

注意：

运行虚拟机软件的操作系统称为主机操作系统（Host OS），运行虚拟机中的操作系统称为虚拟机操作系统（Guest OS）。

#### 2. 硬件要求

虚拟机软件将两个或多个计算机的任务整合到一个计算机中。因此，对硬件的要求较高，主要涉及内存、硬盘和 CPU。

内存必须足够大，因为每个虚拟机都会占用一定量的内存资源，内存总量等于每个虚拟系统内存之和。幸运的是现在内存非常便宜，所以这不是问题。同样，硬盘空间也会被每个虚拟机占用。CPU 现在已经发展到多核阶段，硬盘价格也不应该是问题。

## VIRTUAL BOX 的安装与使用

### 1. VirtualBox 软件概述

VirtualBox 是一款开源虚拟机软件。它最初由德国 Innotek 公司开发，由 Sun Microsystems 生成的软件使用 Qt 编写。在 Sun 被 Oracle 收购后，正式更名为 Oracle VirtualBox。

VirtualBox 可以被认为是最强大的虚拟机软件。它不仅功能丰富，而且性能卓越且易于使用。它可以虚拟化 Windows、Mac OS X、Linux、OpenBSD、Solaris、IBM OS2 甚至其他操作系统。

VirtualBox 不仅开源的，还具有许多优势。本模块将介绍如何使用 VirtualBox 等虚拟机软件来学习 Kali Linux 操作系统。

VirtualBox 的主要功能如下：

- 它支持 64 位客户端操作系统，即使主机使用 32 位的 CPU。
- 它支持虚拟硬盘快照。
- VirtualBox 支持在主机和客户端之间共享剪贴板。但记住需要安装客户端驱动。
- 它支持在主机和客户端之间建立共享文件夹，但需要安装客户端驱动。
- 它可以虚拟化 Windows、Mac OS X、Linux、OpenBSD、Solaris、IBM OS2 甚至其他操作系统。

### 3. 创建虚拟机

虚拟机软件安装好后，双击桌面上的 VirtualBox 图标启动应用程序并创建虚拟机。

具体步骤如下：

- 1) 按 `CTRL+N` 键新建虚拟机，弹出“新建虚拟机”窗口。在这里填写名称、类型和系统版本。虚拟机名称为“Kali Linux”，类型为“Linux”，版本为“Linux (64位)”。选择合适的选项后点击“下一步”。

- 3) 添加虚拟硬盘，在这里选择“现在创建虚拟硬盘”按钮，然后点击“创建”。
- 4) 设置虚拟硬盘文件类型。在这里选择“VDI (VirtualBox 映像)”按钮，点击“下一步”。如果你使用的是 VMware 则应选择 `.vmdk` 文件格式。

- 6) 设置虚拟硬盘文件的位置和大小。在这里选择文件位置为“F:\files\KaliLinux.vdi”（你可能不同），虚拟硬盘大小为“100GB”，点击“创建”完成虚拟硬盘创建。
- 7) 虚拟机打开且虚拟硬盘创建完成后，虚拟机已创建。这是 VirtualBox 的整个控制管理界面。点击左侧的虚拟机名称可以查看该虚拟机的配置属性。
- 8) 在 VirtualBox 控制管理界面中，你可以创建、管理和启动虚拟机。首先选择左侧的虚拟机名称，然后点击“设置”按钮设置虚拟机，关于系统的具体设置。
