
`static unsigned char name_bits[] = { xNN, ... }`

使用 `x_hot` 和 `y_hot` 后缀的变量行是可选的，因为只有当为此位图定义了热点时才会存在。其他变量的行是必须的。`unsigned` Word是可选的；也就是说，*bits array* 的类型可以是 `char` 或 `unsigned char`。*bits array* 必须足够大以包含位图。位图单位为 8。

要从文件读取位图并将其存储在 pixmap 中，请使用 `XReadBitmapFile`。

```c
int XReadBitmapFile(display, d, filename, width_return, height_return, bitmap_return, x_hot_return, y_hot_return);
```

- `display`: 指定到 X 服务器的连接。
- `d`: 指定屏幕的可绘制区域（drawable）。
- `filename`: 指定文件名。
- `width_return`: 返回位图的宽度。
- `height_return`: 返回位图的高度。
- `bitmap_return`: 返回 pixmap。
- `x_hot_return`: 返回 x 热点坐标。
- `y_hot_return`: 返回 y 热点坐标。

`XReadBitmapFile` 函数从文件读取位图并将其存储在 pixmap 中。`filename` 指定要使用的文件。文件格式取决于实现。如果无法打开文件，返回 `BitmapOpenFailed`。如果文件已但未包含有效位图，返回 `BitmapInvalid`。如果分配的内存不足，返回 `BitmapNoMemory`。如果文件可读且有效，返回 `BitmapSuccess`。该函数返回宽度和高度，并将 pixmap 分给调用者。调用者必须在完成后释放 pixmap。

要从文件读取位图并作为数据返回，请使用 `XReadBitmapFileData`。

```c
int XReadBitmapFileData(filename, width_return, height_return, data_return, x_hot_return, y_hot_return);
```

- `filename`: 指定要使用的文件名。文件格式取决于实现。
- `width_return`: 返回位图的宽度。
- `height_return`: 返回位图的高度。
- `data_return`: 返回位图数据。
- `x_hot_return`: 返回 x 热点坐标。
- `y_hot_return`: 返回 y 热点坐标。

`XReadBitmapFileData` 函数从文件读取位图并返回数据，与 `XReadBitmapFile` 的方式相同，但它直接返回数据而不是在服务器上创建 pixmap。位图数据通过 return 返回；客户端必须在完成后使用 `XFree` 释放该存储空间。状态和其他返回值与 `XReadBitmapFile` 相同。

要将位图从 pixmap 写入文件，请使用 `XWriteBitmapFile`。

```c
int XWriteBitmapFile(display, filename, bitmap, width, height, x_hot, y_hot);
```

- `display`: 指定到 X 服务器的连接。
- `filename`: 指定文件名。
- `bitmap`: 指定位图。
- `width`: 指定宽度。
- `height`: 指定高度。
- `x_hot`: 指定 x 热点（不存在则为 -1）。
- `y_hot`: 指定 y 热点（不存在则为 -1）。

`XWriteBitmapFile` 函数以 X 版本 11 格式将位图写入文件。输出文件的名称通过删除目录前缀从文件名导出。如果无法打开文件，返回 `BitmapOpenFailed`。如果分配的内存不足，`XWriteBitmapFile` 返回 `BitmapNoMemory`；否则，如果没有错误：返回 `BitmapSuccess`。如果 `x_hot` 和 `y_hot` 不是 -1, -1，`XWriteBitmapFile` 将它们写入作为位图的热点坐标。

要创建一个 pixmap 并将位图数据存储其中，请使用 `XCreatePixmapFromBitmapData`。

```c
Pixmap XCreatePixmapFromBitmapData(display, d, data, width, height, fg, bg, depth);
```

`d`: 指定指示屏幕的可绘制区域（drawable）。
`data`: 指定位图格式（bitmap format）的数据。
`width`: 指定宽度和高度。
`height`: 指定要使用的前景和背景像素值。
`fg`: 指定像素图（pixmap）的深度（depth）。

`XCreatePixmapFromBitmapData` 函数根据给定数据创建一个像素图，然后将该数据转换为位图格式的 XImage。该深度必须被指定的绘绘制区域支持，否则将导致 BadMatch 错误。

`XCreatePixmapFromBitmapData` 可能会产生 BadAlloc、BadDrawable、BadGC 和 BadValue 错误。

若要在程序中直接包含由 `XWriteBitmapFile` 写入的位图，而不是在运行时每次读取它，请使用 `XCreateBitmapFromData`。

```c
Pixmap XCreatePixmapFromBitmapData(display, data, width, height);
```

`display`: 指定与 X 服务的器的连接。
`data`: 指定位图数据的位置。
`width`: 指定宽度和高度。

`XCreateBitmapFromData` 函数允许你在 C 程序中（使用 `#include`）直接包含一个由 `XWriteBitmapFile` 写入的位图文件（X 版本 11 格式），而无需读取该位图文件。以下代码创建一个灰色位图：

```c
#include "gray.bitmap"
```

```c
Pixmap bitmap; bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height)
```

如果分配的工作空间不足，`XCreateBitmapFromData` 返回 None。你有责任在完成后使用 `XFreePixmap` 释放位图。

`XCreateBitmapFromData` 可能会产生 BadAlloc 和 BadGC 错误。

# 应用实用函数

## 使用上下文管理器

上下文（context manager）提供了一种将数据与程序中的资源 ID（通常是窗口）关联的方法。请注意，这是局限于你的程序的；数据不会存储在服务器的属性列表中。任意数量、任意片段的数据都可以与资源 ID 关联，并且每段数据都有与其关联的类型。上下文需要知道资源 ID 才能存储或检索数据。

本质上，上下文可以被视为一个二维稀疏数组：一个维度由 X 资源 ID 订阅，另一个维度由类型字段订阅。数组中的每个条目包含一个指向数据的指针。Xlib 提供了管理函数，你可以通过这些函数保存数据、获取数据值、条目并创建一个唯一的上下文类型。所使用的符号位于 `<X/Xutil.h>` 中。

要保存与资源 ID 和类型对应的数据值，请使用 `XSaveContext`。

```c
int XSaveContext(display, rid, context, data);
```

- `display`: 指定与 X 服务的连接。
- `rid`: 指定与数据关联的资源 ID。
- `context`: 指定数据所属的上下文类型。
- `data`: 指定与窗口和类型关联的数据。

如果已存在指定资源 ID 和类型的条目，`XSaveContext` 将用指定的上下文覆盖它。如果发生错误，`XSaveContext` 返回非零错误，否则返回零。可能的错误是 `XCNOMEM`（内存不足）。

要获取与资源 ID 和类型关联的，，请使用 `XFindContext`。

```c
int XFindContext(display, rid, context, data_return);
```

- `display`: 指定与 X 服务的连接。
- `rid`: 指定与数据关联的资源 ID。
- `context`: 指定数据所属的上下文类型。
- `data_return`: 返回数据。

由于它是一个返回值，因此该数据是一个指针。如果发生错误，`XFindContext` 返回非零错误，否则返回零。可能的错误是 `XCNONT`（未找到上下文）。

要删除给定资源 ID 和类型的条目，请使用 `XDeleteContext`。

```c
int XDeleteContext(display, rid, context);
```
