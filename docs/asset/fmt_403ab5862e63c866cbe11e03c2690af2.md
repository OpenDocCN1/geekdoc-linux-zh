- 创建和删除文件、目录和符号链接
- 管理系统，从网络和软件包安装到进程管理
- 使用标准输入和输出、重定向和管道
- 使用 `vi`（世界上最流行的文本编辑器）编辑文件
- 编写 shell 脚本来自动化常见或枯燥的任务
- 使用 `cut`、`paste`、`grep`、`patch` 和 `sed` 对文本文件进行切片和切块
