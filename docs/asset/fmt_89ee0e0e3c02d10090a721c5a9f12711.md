
`sudo`命令允许你以 root 权限执行命令，这种权限是 Linux 系统中的最高权限。root 用户对系统拥有完全控制权，并有能力在系统上执行任何操作，包括修改系统文件、安装和卸载软件以及创建和删除用户。

通常情况下，以普通用户登录并在仅在需要时使用`sudo`命令执行 root 权限的命令是一个好主意。这有助于防止对系统进行无意或恶意的更改，因为它要求在执行之前使用自己的密码来验证`sudo`命令。

使用`sudo`命令还有助于提高安全性，因为它允许你在无需登录 root 用户的情况下执行 root 命令。这有助于防止未经授权访问 root 权限，并有助于防止对系统进行无意或恶意的更改。

例如，如果你需要更新 apt 软件包器的包列表，可以使用以下`sudo`命令：

```
sudo apt-get update
```

此命令将更新 apt 软件包器的包列表，这需要 root 权限。当你执行此命令时，系统会提示你输入自己的密码来身份验证`sudo`命令。

## 技巧#2：保护敏感文件和目录

在 Linux 中，使用`chmod`命令对敏感文件和目录设置限制性权限时，你可以使用符号法或八进制法来指定想要设置的权限。

以下是一个使用`chmod`命令和符号法对敏感文件设置限制性权限的示例：

```
sudo chmod u=rw,g=o= /etc/shadow
```

此命令将为`/etc/shadow`文件的所有者赋予读和写权限，并为组所有者和其他用户取消任何权限。`/etc/shadow`文件包含系统加密后的密码，被视为敏感文件，因此设置限制性权限以防止未经授权的访问和更改至关重要。

以下是一个使用`chmod`命令和八进制法对敏感目录设置限制性权限的示例：

```
sudo chmod 700 /etc/ssh
```

此命令将为`/etc/ssh`目录的所有者赋予读、写和执行权限，并为组所有者和其他用户取消任何权限。`/etc/ssh`目录包含 ssh 服务的配置文件，允许用户远程连接到系统，被视为敏感目录，因此设置限制性权限以防止未经授权的访问和更改至关重要。

## 技巧#3：安全使用 SUID 和 SGID 位

SUID（设置用户 ID）和 SGID（设置组 ID）位允许你对文件和目录设置权限，使其以所有者或组所有者的权限执行，而不是执行文件的用户的权限执行。这在某些情况下非常有用，例如允许用户在不以 root 用户登录的情况下以 root 权限执行某些命令。

然而，谨慎使用 SUID 和 SGID 位非常重要，因为如果将它们设置在不受信任或恶意用户拥的文件或目录上，可能会带来安全风险。如果攻击者能够控制具有 SUID 或 SGID 权限的文件或目录，他们可能会以更高的权限执行该文件，并可能危及系统。

为了安全地使用 SUID 和 SGID 位，你应该只对由受信任用户或组拥有、且需要以更高权限执行的文件和目录设置这些位。你还应该仔细检查具有 SUID 和 SGID 权限的文件和目录的权限和所有权，以确保它们没有以不安全的方式使用。

以下是一个使用 SUID 位允许用户以 root 权限执行`passwd`命令的示例：

```
sudo chmod 4755 /usr/bin/passwd
```

此命令将在`/usr/bin/passwd`文件上设置 SUID 位，允许用户更改自己的密码。通过在该文件上设置 SUID 位，用户可以在不以 root 用户登录的情况下，以 root 权限执行`passwd`命令。

# 第 6 章：探索 Shell：‘BASH’‘ZSH’ 和‘FISH’

## 理解 Shell

Shell 是一种命令行界面，允许你与操作系统进行交互。它允许你通过在提示符输入命令、运行程序并执行各种任务。

Shell 脚本编写是在 Shell 编程语言中编写脚本（一组指令）以自动化任务或在系统上执行操作的过程。Shell 脚本可用于自动化任务、创建和管理系统配置，以及执行系统维护和管理。

Shell 脚本在开发者中非常流行，因为它是自动化任务和在系统上执行操作的一种强大且灵活的方式。对于那些需要在多个系统或不同环境中执行任务或操作的开发者来说也非常有用，因为 Shell 脚本可以在各种系统中轻松地编写和执行。

Shell 脚本同样流行，因为它允许开发者利用 Shell 提供的许多功能和工具，例如命令行编辑、命令历史、变量和控制结构。这可以使在系统上执行任务和操作变得更加简单和高效。

Linux 有多种不同的 Shell 可用，每种 Shell 都有自己的功能和能力。Linux 最流行的三种 Shell 是`bash`、`zsh`和`fish`。以下是这些 Shell 的简要概述：

### bash

`bash` (Bourne-Again SHell) 是大多数 Linux 发行版上的默认 Shell。它是一个命令行界面，允许你通过在提示符输入命令来与操作系统进行交互。`bash`是一个强大且灵活的 Shell，支持许多功能，包括：

- 命令行编辑：`bash`允许你使用各种按键和快捷键编辑和修改命令行。
- 命令历史：`bash`会留留你输入过的命令历史，你可以使用`history`命令或上/下方向键来访问这些历史。
- 变量：`bash`允许你定义变量来存储数据或信息。你可以使用变量存储命令的输出、在脚本之间传递数据，或设置选项偏好。
- 控制结构：`bash`支持一系列控制结构，如`if`语句、`for`循环和`while`循环，你可以用它们控制脚本的执行流。
- 函数：`bash`允许你定义和使用函数，以组织和重用脚本中的代码。
- 通配符：`bash`支持使用通配符，你可以根据模式或表达式指定一组文件或目录。
- 管道和重定向：`bash`允许你使用`|`（管道）运算符将一个命令的输出发送到另一个命令，并使用`>`和`<`运算符将输入输出重定向到文件。

`bash`被广泛使用，是熟悉命令行的用户的良好选择。

### zsh

具有额外的功能，例如改进的命令行编辑、拼写纠错，以及对插件和主题的支持。`zsh`的一些关键特性包括：

- 命令行编辑：`zsh`包含了改进的命令行编辑能力，例如自动建议和对错误命令的纠正。
- 拼写纠错：`zsh`包含内置的拼写纠错功能，会对拼错误的命令给出建议。
- 插件和主题：`zsh`支持使用插件和主题，允许你扩展 Shell 的功能并自定义其外观。
- 别名（Aliases）：`zsh`允许你为命令定义别名，可用于简化或自定义你与 Shell 交互的方式。
- 函数：`zsh`支持使用函数，你可以用它们组织和重用脚本中的代码。
- 通配符：`zsh`支持使用通配符，你可以根据模式或表达式指定一组文件或目录。
- 自动建议：`zsh`包含内置的自动建议功能，会在你输入时建议可能的命令和参数。

`zsh`在高级用户和开发者中非常流行，是想要更强大、可自定义 Shell 的用户的良好选择。

### fish

`fish` (Friendly Interactive SHell) 是一种用户友好的 Shell，旨在易于使用和理解。它比`bash`和`zsh`等其他 Shell 更直观、友好，并包含了语法高亮、自动建议和内置的手页查看器等功能。

`fish`的一些关键特性包括：

- 语法高亮：`fish`包含语法高亮，用不同的颜色突出命令行中的不同元素（如命令、参数和变量），以便更易阅读和理解。
- 自动建议：`fish`包含内置的自动建议功能，会在你输入时建议可能的命令和参数。
- 手页查看器：`fish`包含内置的手页查看器，允许你在不离开 Shell 的情况下查看命令和工具的文档。
- Web 端配置：`fish`允许使用基于 Web 的界面配置 Shell，这比其他配置方法更加友好且易于使用。
- 函数：`fish`支持使用函数，你可以用它们组织和重用脚本中的代码。
- 别名：`fish`允许你为命令定义别名，用于简化或自定义你与 shell 交互的方式。

`fish`是新用户或想要更直观、更用 shell 的用户的良好选择。

以下是一些可以在`bash`、`fish`和`zsh`中使用的常用通用 shell 命令列表：

- `sort`：对文件或输出的行进行排序。
- `uniq`：移除文件或输出中的重复行。
- `wc`：统计文件或输出的行数、单词和字符数。
- `echo`：显示消息或变量值。
- `printf`：格式化并显示消息或变量值。
- `chmod`：更改文件或目录的权限。
- `chown`：更改文件或目录的所有者和组所有。
