### 13.1.5 ARM64: 优化的 GCC (Linaro) 4.9

```
f12:

cmp w0, 1

beq .L31

cmp w0, 2

beq .L32

cbz w0, .L35 ; default case

adrp x0, .LC15 ; "something unknown"

add x0, x0, :lo12:.LC15

bl puts

.L35:

adrp x0, .LC12 ; "zero"

add x0, x0, :lo12:.LC12

bl puts

.L32:

adrp x0, .LC14 ; "two"

add x0, x0, :lo12:.LC14

bl puts

.L31:

adrp x0, .LC13 ; "one"

add x0, x0, :lo12:.LC13

bl puts
```

优化的效果显著。CBZ（Compare and Branch on Zero）在 W0 为零的情况下跳转。此外，在调用 `puts()` 时，本例使用的是 JR 而不是常规的调用，这反映了 13.1.1 节过的函数方式。
