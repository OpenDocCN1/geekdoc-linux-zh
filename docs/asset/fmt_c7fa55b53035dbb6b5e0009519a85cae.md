# nwall

使用 GNU readline 的 `wall` 版本，是一个基于 BSD 的系统本地聊天程序。它记录聊天内容，并为希望接收系统墙消息提醒但不想被 `nwall` 聊天打扰的用户提供退出锁定功能（opt-out lockers）。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html

# nwatch

网络服务检测器。`Nwatch` 是一种搜索工具，但可以被概念化为“被动端口扫描器”，因为它只对 IP 流量感兴趣，并将资源组织为端口扫描器在短时间内进行检测。该工具的优势是，当连续扫描映射失败时可以使用 `NWatch` 检测到服务。缺点是服务必须被活动使用才能被检测到。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html

# nwrite

`write` 命令的增强替代品。`nwrite` 是标准 `write` 程序的替代品，它允许你向另一个终端写入内容——而无需承担 `talk` 接管整个屏幕的开销，也不需要另一个用户响应。相比传统的 `write`，`nwrite` 的优势包括可以同时向多个用户发送相同的消息，以及接收者可配置的消息格式，包括每行开始处一个识别发送者的标签。来自 Debian 3.0r3 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# nxtvepg

Nextview EPG 解码器和浏览器。在这个软件包中，你可以找到一个 Nextview 解码器——一种针对模拟需求的电子电视节目指南（与大多数数字网络自带的数字 EPG 不同）。德国、奥地利、法国和瑞士大多数主要网络的节目列表。目前 Nextview EPG 通过以下频道传输：

- 德国和奥地利：Pro7, 3sat, RTL-II
- 瑞士：Euronews, SFI, TSR1
- 德国：Canal+, M6, TVS
- 土耳其：TRT（截至 2001 年6 月仍为测试传输）

EPG 信息从 `/dev/bi` 读取，也就是说你需要某些提供 VBI 数据流的电视卡。`btv` 卡有效。`zor` 可能也可以用，但由于缺少硬件我还没有测试……

来自 Debian 3.0r3 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# obj-poc

Object-C 编译器。端口对象编译器（`obj-poc`）是一个 Objective-C 编译器。包括：

- 一个现代、可移植的、“全 C”Object C 运行时。绝对不需要语言，也不依赖于栈布局、寄存器分配约定等。大多数其他运行时源自“全 C”-Stepstone 运行，这是一个重要的防御点。
