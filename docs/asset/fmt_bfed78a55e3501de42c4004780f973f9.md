stalin

极其激进的 Scheme 编译器。stalin 是一种激进的 Scheme 编译器，旨在生成具有高性能的独立执行文件。它是一个像 `gcc` 一样的批处理编译器，而不是解释器，设计用于代码编译后使用。它对源代码内容有一些限制。例如，你不能在运行时 `LOAD` 或 `EVAL` 新表达式或过程定义，作为交换，可以进行各种分析以将 Scheme 类型转换为 C 并使用原生 C 算术运算，前提是这些操作被证明是安全的。进一步的 stalin 可以减少或消除检查和分发，并针对限制范围或访问权限省略垃圾回收，它具有指向 Xlib 和 OpenGL 的免费过程接口。来自 Debian 3.0r apt

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## 标准通用标记语言 (SGML)

一种标记语言的手段，例如超文本标记语言（HTML），一种在世界网（WWW）上广泛使用的标记语言。SGML 是由国际标准组织（ISO）定义的开放式国际标准。源自 QIEC `http://www.tld.org/LDP/Linux-Dictionary/index.html`

## 标准输入 (standard input)

用户输入命令和值的默认位置，例如键盘。源自 Redhat–9–Glossary `http://www.tld.org/LDP/Linux-Dictionary/index.html`

## 标准输入 (standard input)

命令的信息源。这被假设为从文件或另一个命令重定向或管道的键盘输入。源自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/index.html`

## 标准输出 (standard output)

命令的终点。这被假设为重定向或管道到文件或另一个命令的终端输出。源自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/index.html`

## starplot

三维透视查看器 starPlot 是一个 GTK+ 程序，可以交互地查看恒星的三维透视图表。可以通过鼠标点击对图表进行重新中心、旋转或放大/缩小（当然也可以通过对话框进行精确操作）。可以通过光谱分类和绝对星等查看（或忽略）恒星。StarPlot 配合 사전使用，这是一个将行定向数据记录转换为 StarPlot 格式的实用程序。如果有一个描述原始文件格式的短文件供 starconvert 使用，互联网上大多数的恒星数据文件都可以以此方式转换。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
