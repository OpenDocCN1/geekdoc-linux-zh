# 141: 如果共享具有“create mask”为“700”，这意味着什么？

# 186: SPF 记录有什么用途？

**答案：**

基于域的反垃圾邮件保护。它指定允许为某个域发送邮件的主机。

# 187: DKIM 和 SPF 有什么区别？

**答案：**

DKIM 对电子邮件进行数字签名（以确认该邮件消息来自该域名的权威邮件服务器），而 SPF 指定允许代表该域发送邮件的主机。DKIM 需要在发送服务器上进行软件实现，而 SPF 纯粹是一个 DNS 记录，不需要安装其他软件。
