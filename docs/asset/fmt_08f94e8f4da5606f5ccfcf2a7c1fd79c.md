# 使用 Nautilus Burn 程序

`Nautilus` 提供了一个替代的 CD 刻录实用程序。只需将 `CD-R` 或 `CD-RW` 光盘插入 CD 驱动器，`Nautilus` 就会完成其余工作。这些步骤描述了如何使用该系统：

- 1. 以任何用户身份登录并将 `CD-R` 或 `CD-RW` 光盘插入 CD 写入器。
- 2. 双击桌面左上角的主目录图标。打开 `Nautilus` 窗口，显示主目录的内容。
- 3. 点击并按住任何文件或目录，将其拖到 `burn` 窗口。所有文件和目录都显示在 `burn` 窗口中；这些文件和目录并没有真正复制，而是链接到 `burn` 窗口。
- 4. 点击任何一个文件和目录以进行高亮。选择文件或目录即可将其写入 CD。
- 5. 点击 `Write to CD` 按钮，就可以开始了。经过短暂思考后，写入 CD 对话框打开。当 CD 写入完成后，默认会弹出光盘。
- 6. 完成后点击 `Close` 按钮。
- 7. 将光盘推回驱动器以关闭 CD 托。打开 `Nautilus` 窗口，显示你刚刚完成写入的光盘的内容。

## 第 11 章：冲浪网络与音乐

## 刻录吧，亲爱的：刻录 CD

本节的步骤描述了如何创建或刻录 CD-ROM。你可以将任何类型的文件复制到你的 `CD-R` 或 `CD-RW`：

- 1. 以任意用户身份登录，并将 `CD-R` 或 `CD-RW` 光盘插入你的 CD 刻录驱动器。（当 `Burn` 打开时，请将其关闭。）你可以刻录什么？世界是你的游乐场，你可以为任何想要的内容制作 CD：数据、软件或音乐。一个很好的开始点是在 CD 上备份你的 `/home` 目录。
- 2. 点击 `GNOME` 菜单按钮并选择系统工具（`System Tools`）：更多系统工具（`More System Tools`）：CD 刻录机（`CD Writer`）。打开 `GNOME Toaster` 窗口，如图 11-4 所示；弹出一个信息对话框，你可以点击 `OK` 关闭。
- 3. 点击窗口左下角的文件夹图标。`Toaster` 拥有自己的文件管理器。
- 4. 通过点击文件存储的目录，找到你想要刻制的文件或目录。例如，双击 `/home` 和 `paul/ogg/Pat Metheny` 目录。
- 5. 点击并拖动文件或目录（在本例中为 `rh18fd` 目录）到步骤 3 中打开的文件夹子窗口。你不需要使用 `GNOME Toaster` 文件管理器来选择要刻制的文件。你可以打开 `Nautilus` 窗口并将文件拖到 `Track` 子窗口。
- 6. 点击窗口左下角 `Track` 按钮正下方的 CD 图标。`Record` 子窗口将打开并替换 `Track` 子窗口。你将看到几个选项，用于控制 `CD-R/RW` 驱动器。默认设置适用于 ISO 镜像。ISO（国际标准组织）在此上下文中是指一种可以被许多类型计算机系统读取的文件系统。
- 7. 点击 `Record` 按钮，CD 刻录过程开始倒计时。你有九秒钟放弃任务。
- 8. 你可以通过按下 `Stop` 按钮停止进程。你的主目录已刻录到 CD 中，创建了一个简单、可靠且有效的备份系统。它易于使用。

# 第 12 章：网络直播

## 本章内容

- 使用 `XMMS` 收听音频流
- 使用 `MPlayer` 收听直播电台和播放 DVD

最近的伟大创新之一是利用互联网传输——音频和视频节目。流媒体技术让任何人都有地理上不受限制地创建电台或电视台的能力；这确实可以实现。使用流媒体技术，计算机用户可以在任何地方收听或观看这些广播。本章描述了如何将你的 Red Hat Linux 机器作为音频接收器和 DVD 视频播放器。我们使用开源 `XMMS` 和 `MPlayer` 应用程序来听网络。

## 使用 XMMS 音频播放器

开源 `XMMS`（X 多媒体系统）应用程序是收听音频流和文件的绝工具。`XMMS` 默认播放 `.wav` 文件。它还支持即将推出的开源 Ogg/Vorbis 格式（解码器）。Ogg 解码器不使用任何专有或专利算法。Ogg 供任何人免费使用，不想依赖专有系统的个人和组织正在发现它；Ogg 还能从其他流行系统（如 `MP3`）产生更高保真的音频流。既然不需要，为什么要依赖另一个公司的随心所欲呢？

你可以使用 `XMMS` 收听你在第 11 章中可能保存的一些音乐。如果你以前将音乐保存到主目录并想收听它们，打开 `XMMS` 并右键点击窗口。选择 `Open` 并选择你创建的任何 `WAV` 文件。

Ogg 是格式化音频流的系统，Vorbis 用于压缩它们。与大多数其他系统不同，Ogg/Vorbis 不是一个缩写，而是用科幻小说人物命名的。有关关于 Ogg/Vorbis 及类似的开源多媒体系统的更多信息，请访问 `www.vorbis.com`。

现在你已经有了一些技术背景，可以开始使用 `XMMS` 收听 Ogg/Vorbis 流了：

- 1. 登录你的计算机，点击 `GNOME` 面板上的蓝色地球图标打开 `Mozilla`。在 `Mozilla` 文本框中输入地址 `www.vorbis.com/music`。
- 2. 点击任何 `Track` 链接。例如，点击第一个 `Lepidoptera`。打开“Downloading Lepidoptera.ogg”对话框。
- 3. 点击 `OK` 按钮，然后点击 `Save` 按钮。打开“保存文件名称”窗口，`Mozilla` 将音乐文件保存到你的主目录。
- 4. 点击 `GNOME` 菜单并选择 `Sound & Video` -> `Audio Player` 启动 `XMMS`。打开一个 `XMMS` 窗口。图 12-1 显示了播放器。
- 5. 右键点击 `XMMS` 窗口，选择 `Play File`，点击刚刚保存到磁盘的文件。当你点击 `OK` 按钮时，`XMMS` 开始播放音乐。

![](img/45336450e32ffec24f7d88ac782496_177.png) 图 12-1：`XMMS` 窗口。

Vorbis 网页提供了指向其他支持 Ogg 源的链接。例如，点击 ... 页面顶部附近的 `Music Sites Page` 链接。你会看到一个带有其他来源链接的页面。例如，点击 `WCPE` 链接进入一个直播古典音乐的网页。

现在是描述如何让 `Mozilla` 在你每次点击 Ogg/Vorbis 源和流时自动启动 `XMMS` 的好时机：

- 1. 登录并打开 `Mozilla`，然后点击 `Edit` -> `Preferences` 菜单。打开 `Preferences` 窗口。
- 2. 选择 `Navigator` -> `Helper Applications`。`Preferences` 窗口中打开 `Helper Applications` 子窗口。Red Hat 为 Ogg 添加了 MIME（多用途互联网邮件扩展）条目，在 `File types` 子窗口中显示为 `application/x-ogg`。
- 3. 点击 `application/x-ogg` 然后点击 `Edit` 按钮。弹出 `Edit Type` 对话框，显示了它知道如何处理 Ogg 格式媒体的信息。图 12-2 显示了完成后的 `Edit` 对话框。此列表描述了各种字段：
  - `MIME type`：与辅助程序相关的 MIME 类型。如果你读过第 10 章，你就知道 MIME 类型有助于计算机决定如何处理媒体类型。在此字段中输入 `application/x-ogg`。
  - `Description`（描述）：描述 MIME 类型的简短文本。
  - `Extension`（扩展名）：此字段中的扩展名。在这种情况下，Ogg 使用 `ogg`。
  - `When a file of this type is encountered`（当遇到此类类型的文件时）：强制 `Mozilla` 在对 MIME 类型执行任何操作之前询问你。
- 4. 点击 `OK` 按钮并在文本框中输入 `/usr/bin/xmms`。
- 5. 点击 `OK` 按钮返回 `Preferences` 窗口。
- 6. 点击 `OK` 按钮返回 `Mozilla`。
