
# Linux 词典

### RTX16

实时执行内核 - 16 (`Real Time eXutive - 16 (OS, Honeywell, ...)`), "`RTX-16`" 来自 `VERA` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### RU.nix

`RU.nix` 致力于 PlayStation 和 MIPS 上的 Linux。内容为英文，但要获取真实信息，你需要阅读俄语页面。最后一条目日期为2003年3月22日。来自 LWN 分发邮件列表 http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### RUA

远程用户代理 (`Remote User Agent`) 来自 `VERA` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### RUAC

远程用户访问中心 (`Remote User Access Centers`) 来自 `VERA` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### rubibtex

`rubibtex` (等待，很可能是 `rubbibtex`，但保留原文)

使用俄语字母作为名称为 (`LaTeX`) 创建参考文献。来自 `Whatis` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### ruby

面向对象语言的解释器，是一种用于快速面向对象编程的解释型脚本语言。它具有许多处理文件和系统管理任务的功能（如 `perl`）。它简单、直观且可扩展。来自 `Debian 3.0` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

《Programming Ruby》这本书是 `Ruby` 语言的教程。使用 `Ruby`，你将写出更好的代码，提高效率并享受编程。这本书是面向对象语言的指南，介绍了基础知识以及如何编写大型程序、使用 `C` 语言扩展等。`David Thomas` 和 `Andrew Hunt` 编写，由 `Addison` 出版，采用 `Open` 许可。来自 `Debian 3.0` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### rubymagick

`ImageMagick` 的 `Ruby` 接口

### rubyunit

`RubyUnit` 的简单框架。你可以在下一个站点获取关于测试的信息：`URL://www.programming.com/`。来自 `Debian 3.0` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### RUI

现实用户界面 (`Reality User Interface`) 来自 `VERA` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### remakeindex

使用西里字母处理 `LaTeX` 索引。来自 `Whatis` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### rumba-manifold-demo

使用 `Rumba` 映像库的示例程序。来自 `Debian 3.0` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### rumba-utils

`Rumba` 映像实用程序。来自 `Debian 3.0` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### rubambiew

`rubambiew` (很可能是 `rumba-viewer`)

`Rumba` 项目映像查看器。来自 `Debian 3.0` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### run

监控程序并在它们崩溃时重启。它允许运行一个程序，并确保同时只有一个程序在运行。我想运行某个程序，但如果它已经在运行则不运行。`run` 完成了这些通常需要繁琐脚本才能完成的任务。请注意：`run` 会考虑“损坏的程序”并在主页建议除非准备好否则运行。然而，`run` 似乎运行良好。如果你想构建，请删除冲突文件。来自 `Debian 3.0` http://www.tldp.org/LDP/linux-Dictionary/index.html

### run-mail

通过邮箱文件执行程序。来自 `Whatis` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### run-parts

目录中的 `run` 脚本或程序。来自 `Whatis` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### run-with-ispell

帮助使用 `aspell` 替代 `ispell` 的脚本。来自 `Whatis` http://www.tld.org/LDP/Linux-Dictionary/index.html

### rungetty

一种极简的 `getty`，可以运行你寻找的任何 `getty`，而不只是登录。如果使用了不同的程序作为 `nobody`、`nobody` 或命令行上指定的用户/组，`rungetty` 在某些情况下可以配置为自动登录。更多信息请参见手册页。安装包后，你需要更改 `/etc/initab` 中的某些行。`rungetty` 基于 `keyring`，因此不适合使用。来自 `Debian 3.0` http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### runlevel

查找当前和之前的系统级别。`Runlevel` http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

`runlevel` 由 `runlevel` 控制启动的进程。`runlevel` 是 0 到 6 之间的数字或 `S`。级别 0、6 留用于关机、重启；1 是单用户模式；2–5 是各种多用户模式；6 是系统重启。

`UNIX` 系统的工作模式。`Red Hat` 有七个运行级别（0–6）；0 是独立系统；6 是重启。

### RunOnCD

无需安装。`RunOnCD` 的 2.1 版本基于 `Red Hat 7.1`。该网站大部分是韩语，部分英语。2.1 版本日期为 2001 年 12 月 7 日。基于 CD 的分发。来自 LWN 分发邮件列表 http://www.tld.org/LDP/Linux-Dictionary/html

### runq

邮件传输代理 (`Mail Transfer Agent`) 来自 `Whatis` http://www.tldp.org/LDP/Linux-Dictionary/index.html

### runscript

`Mimicom` 的脚本解释器。来自 http://www.tld.org/LDP/Linux-Dictionary/index.html

### RUNT

`RUNT` (`ResNet USB Tester`) 是为 128 MB U 盘设计的 `Slackware`。它由启动软盘镜像和一个 `zip` 文件组成，类似于 `zipslack`。它旨在作为测试工具的 Linux 安装，能够在任何带有 USB 端口和软驱的 `x86` 计算机上启动。`RUNT 0.92` 初始版本为 2002 年 11 月 27 日。1.11 版本于 2003 年 5 月 5 日发布。一种“特殊用途/最小”分发。来自 LWN 分发邮件列表 http://www.tldp.org/LDP/Linux-Dictionary/html/index

### RUOW

远程办公 (`Remote Office of Work (DRDA, IBM))`, "`RUOW`" 来自 `VERA` http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### RUS

斯图加特大学中心（例如，德国斯图加特大学）来自 `VERA` http://www.tldp.org/LDP/Linux-Dictionary/html.index

### users

显示登录到本地网络机器上的用户。`users` 命令产生类似于 `who` 的输出，但是针对本地网络上的主机列表或所有机器。对于每个响应 `users` 查询的主机，每行都会打印主机名和当前登录用户的名称。`users` 命令将等待一分钟以捕捉迟的响应者。来自 `Debian 3.0r0 APT` http://www.tld.org/LDP/linux-Dictionary/index.html

### usersd

登录用户服务器。这是一个返回当前登录系统信息的服务器。来自 `Debian 3.0r0 APT` http://www.tldp.org/LDP/Linux-Dictionary/html/index
