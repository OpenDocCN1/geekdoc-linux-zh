# 气凝器 (Vapor condenser)

一种将热力学流体从气态冷结成液态的热传递设备。冷凝器通过较低温度的热传质流体，从高温源蒸汽中提取汽化潜热。蒸汽可能是湿的、饱和的或过热的。冷凝器通常浸在空气、液水等流体中。当使用空气为冷凝器加热时，冷凝流体被称为加热器，不属于冷凝器的正常分类。

任何两个组件之间的卡诺循环给出了输入功效率的极限。这种效率取决于工作流体的性质。朗肯循环在描述电厂和系统的理想性能方面更为更具现实意义。循环：朗肯循环。[待定。]

冷凝器可分为两类：作为处理系统的一部分使用（过程冷凝器）以及用于发电厂中冷凝蒸汽或水（热力循环冷凝器）。它们可以根据运行模式进一步分为表面冷凝器或接触式冷凝器。接触式冷凝器；表面冷凝器。

气相沉积是在加热表面和气相中获得的材料膜。气相涂层用于多种材料，包括金属、合金和聚合物。沉积膜的成分可以通过两个基本组（蒸发和溅射）控制。此外，还有如喷射沉积等过程，它是蒸发和溅射的子集。这种过程被广泛使用并利用煤气，导致多孔或饱和沉积。内容：复合材料；材料内容。

冷凝器在需要不接触的情况下，通过含有空气或非冷凝气体的蒸汽进行冷凝。冷凝器最常用表面冷凝器，因为蒸发器或系统中的空气可能是蒸汽污染的常见原因，已经开发了多种设计来减少这种影响。非冷凝气体的积累会影响热传递，通过在冷凝器内提供一个独立的热传递表面并位于蒸汽路径末端，通过除湿除去非冷凝气体来防止。[J.ESf.]

所有沉积过程都包括三个阶段：沉积物种的产生、物种传输到基底以及在表面的生长。虽然气相沉积过程同时发生或在基底上发生，但气相沉积过程步骤是顺序进行的并可以独立控制。

在物理气相沉积中，第一步涉及通过真空蒸发、使用直流或射频功率或溅射源产生沉积物种。接两步涉及传输到基底。

气凝器运行在蒸汽循环上，其中蒸汽在高压下产生水，且蒸汽在其中或穿过。蒸汽是处于或接近其冷凝点的状态。它可能是湿的、干的或轻微过热的。饱和状态是一种分析上的理想状态，在实践中仅是瞬态的。热；热力学循环。

蒸汽电厂运行在水循环上，其中蒸汽在高压下产生水，且蒸汽在其中或穿过。蒸汽是处于或接近其冷凝点的状态。它可能是湿的、干的或轻微过热的。饱和状态是一种分析上的理想状态，在实践中仅是瞬态的。

基底膜的生长涉及气相沉积的两个基本过程：蒸发和溅射。在蒸发中，固体或液体的热能用于将材料传输到基底。在溅射中，靶是负极，被工作气体轰击，从而击出原子并转化为气态。
