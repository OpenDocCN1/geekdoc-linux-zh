# 数据源

![](img/ba6b82a7869bba748202d57c97336dca_238_0.png)

顶行倒数第二个按钮是 Data Source（数据源）按钮。点击此将在文档的新面板中打开 Data Source 浏览器。从该面板中，你可以访问并编辑存储在你在 OpenOffice.org 中注册的任何数据库中的记录。例如，对于一个包含个人信息的数据库（如 Evolution 的地址录），你只需对单个条目进行搜索，然后将该条目的名称、地址、电话号码和/或电子邮件地址拖入你的文档中，而不是重新搜索数据并全部输入。

# 其他酷酷的应用

除了更传统的应用程序外，系统中还包含许多可以归类为生产力的应用程序。我将在这里介绍几个。

## Sticky Notes（便签笔记）

Mac 用户会熟悉类似于便利签的数字笔记，称为 Sticky Notes（图 13-9），它是 GNOME 的一部分。GNOME 的 Sticky Notes 是一个面板组件，你可以通过右键点击任何面板空间并在弹出菜单中选择 Add to Panel（添加到面板）来添加。当 Add to Panel 窗口出现时，转到 Accessories（配件）部分，点击 Sticky Notes，然后点击 Add（添加）按钮。现在你就可以做笔记了。

![](img/ba6b82a7869bba748202d57c97336dca_240_0.png)

![](img/ba6b82a7869bba748202d57c97336dca_240_1.png)

我应该提到，Sticky Notes 有一个稍微令人烦恼的“功能”，让它与你可能习惯的有所不同。当你点击桌面时，所有的笔记都会消失。这是本该的，尽管我个人并不明白其中的意义。不过幸运的是，你只需点击 Sticky Notes 面板即可找回你的所有笔记。事实上，如果你决定移除面板并在稍后的时间将其带回，你会很高兴地发现之前创建的所有笔记都会回来。

## Tomboy

如果 Sticky Notes 无法满足你对笔记的需求，也许你会发现系统自带的另一个名为 Tomboy（图 13-10）的应用程序可以帮助你。像 Sticky Notes 一样，Tomboy 也作为一个面板工作，但它的功能更全，且没有任何贴纸的主张。相反，你可以通过点击 Tomboy 面板本身弹出的菜单来创建各种笔记。总之，这是一个非常实用的方法。

![](img/ba6b82a7869bba748202d57c97336dca_241_0.png)

图 13-10：严肃对待笔记——Tomboy

然而，真正让 Tomboy 引自资本的是它的搜索和超链接功能。这些功能允许你在整个 Tomboy 笔记库中搜索条目，并创建将一个笔记中的链接到另一个笔记的超链接。事实上，每当你输入一个与你现有的笔记标题匹配的单词时，Tomboy 都会创建一个超链接。

为了让事情变得更加有趣（或者至少更有用），Tomboy 通过其插件功能允许你将笔记导出为 HTML 或将其打印出来，可以是纸质版或 PDF 文档。

如果你想尝试一下 Tomboy，请先进入应用程序（Applications）► Tomboy Notes，之后 Tomboy 就会出现在顶部的 GNOME 面（Panel）中。

## GnuCash

如果你熟悉个人财务管理软件 GnuCash，那么你可能对 GnuCash（如图 13-11 所示）感兴趣，它是 Linux 世界在个人财务领域最著名的产品。它能读取 Quicken 和 Intuit QIF 文件，这让事情变得更加简单——你本应该正在从另一个操作系统迁移过来。遗憾的是，除非你住在德国，否则你无法将 GnuCash 用于网上银行付款；但正如 GnuCash 的人员自己所说，不要埋怪你的银行。

要安装 GnuCash，只需在 Synaptic 中搜索 `gnucash`，然后同时勾选 `gnucash` 和 `gnucash-docs` 进行安装。安装完成后，你可以通过应用程序（Applications）► GnuCash Finance 运行该程序。

![](img/ba6b82a7869bba748202d57c97336dca_242_0.png)
