
# 可可粉

可可粉源自可可树（`Theobroma cacao`），生长在赤道线以下的狭窄带内。这些树并不高，树干下部的分支被五颜色的冠层包围。它们很清晰且没有巧克力味。每颗豆约1–3厘米。

刺胞动物自中生代纪以来便为人知。它们在侏罗纪早期和晚期具有高度多样性；它们的常见形式差异巨大。因此，形态变化极少。在过去的8000万年中没有化石。大多数化石指的是某些形态；尽管如此，刺胞动物整体已完全灭绝。

水母是四倍体或放射对称的个体，且自由游泳。身体通常呈钟形，口悬挂在钟下部的中心。在水虫中，触手不是直接包围口，而是位于伞的边缘。伞的任何部分都可能认为具有触手，无论是自由的还是在伞缘上的。口通向中心胃，胃产生四个或多个放射状通道。这些放射状通道作为胃血管系统，将营养分配到贯穿整个身体的通道中。

刺胞动物独特且最显著的特征是伞，无脊椎动物效应细胞刺丝，也称为刺细胞或刺囊细胞。每个组织细胞都可以快速爆发以捕获猎物，或防御捕食者及敌人。刺细胞产生于称为刺囊的细胞内。水母纲的刺囊限制了最简单的刺胞动物；形动物纲的形动物在水虫和内肠皮中都带有刺囊。
