
- 安装新的启动加载程序：启动 YaST 启动加载程序配置模块。详情见第 120 页的第 4.8.4 节
- 运行分区工具：启动 YaST 中的专家分区工具。详情见第 22 页的第 2.5.5 节
- 修复文件系统：允许检查已安装系统的文件系统。首先会提供所有检测到的分区选择，然后可以选择要检查的分区。
- 恢复丢失的分区：可以尝试重建损坏的分区表。首先会显示检测到的硬盘列表供选择。点击“确定”开始检查。这取决于处理能力和硬盘的大小。

> 注意
> 分区的表的重建是复杂的。YaST 试图通过分析硬盘的数据区来识别丢失的分区。成功识别后，丢失的分区将被添加到重建的分区表中。然而，这在所有想象的情况下并不都能成功。

- 将系统设置保存到磁盘：允许将重要的系统文件保存到软磁盘上。如果其中一个文件损坏，可以从磁盘恢复。
- 检查已安装软件：检查软件包数据库的一致性以及最重要的包的可用性。可以使用此工具重新安装任何损坏的已安装包。

## 4.1 开始 YaST

使用 YaST 进行系统配置会使用各种用途的 YaST 模块，例如键盘配置或系统语言选择。可以通过多种方式访问这些模块。所有模块的概述可以在 YaST 控制中心获得，该中心可以通过面板左上角的 SUSE 图标启动。选择“SUSE”->“系统”->“YaST”。单个模块也可以从 KDE 控制中心访问。如果你使用 KDE，也可以按 (Alt+F2) 启动 YaST。在打开的窗口中输入 `kdesu /sbin/y2` 并按 (回车)。如果你不想启动图形版本的 YaST，请输入 `/sbin/yast` 而不是 `/sbin/y2`。此时 YaST 将按照第 4.10 节所述在控制模式下运行。

由于这些方法通常由普通用户使用，YaST 会打开一个输入 root 密码的小对话框。所有 YaST 模块都需要 root 权限，因为只有该用户允许修改 Linux 系统文件。

如果由于原因无法按照描述的方法启动 YaST，可以从命令行启动。在 shell 中切换到 root 用户。输入 root 密码并运行命令 `yast2`。

左侧框架显示相应主题的帮助文本，解释了所需的输入项。完成所需的设置后，在最后一个配置对话框中点击“完成”以完成程序。随后将保存配置。

#### 4.3.1 更改安装源

安装源是包含要安装软件的介质。YaST 可以管理多个安装源。它允许为了安装或更新目的选择这些源。

启动此模块时，将显示所有之前注册过的源的列表。在从 CD 正常安装后，列表中仅列出安装 CD。点击“添加”可以在此列表中包含更多源。你可以添加可移动介质（如 CD 和 DVD）以及网络服务器（如 NFS 和 FTP）。甚至是本地硬盘硬盘上的目录也可以选择为安装介质。请参阅详细的 YaST 帮助文本。

在安装或更新期间，YaST 可以考虑多个安装源。因此，所有注册的源在列表的第一列中都有一个激活状态。点击“激活或禁用”来激活或禁用单个安装源。YaST 将从激活的安装源范围中选择合适的安装源。当你通过“关闭”退出模块时，当前设置将被保存并应用于“安装和删除软件”以及“系统更新”配置模块。

#### 4.3.2 YaST 在线更新

YaST在线更新（YOU）允许安装重要的更新和改进。相应的补丁可以在 SUSE FTP 服务器和各种镜像服务器上下载。在“安装源”下，选择各种服务器之一。当你选择一个服务器时，相应的 URL 将复制到下方的输入框中，可以在其中对其进行编辑。你还可以以“file:/my/path”或简单的“my/path”格式指定本地 URL。使用“新服务器”使用更多服务器扩展现有列表。点击“编辑服务器”可以修改当前选择服务器的设置。

模块启动时，“手动选择补丁”处于激活状态，允许确定是否应该获取单个补丁。要应用所有可用的更新包，请禁用此选项。然而，取决于连接带宽和要传输的数据量，这可能会导致长时间的下载。

如果你激活了“重新下载所有补丁”，将从服务器下载所有可用的补丁、安装和描述。如果未激活此复选框（默认值），则仅检索系统中未安装的补丁。

此外，还有自动更新系统的可能性。点击“配置全自动更新”来配置一个每天自动查找并应用更新的过程。该过程是全自动的，不需要任何交互。这只有在更新时存在到更新服务器的连接（如互联网连接）时才有效。

如果你决定执行手动更新（默认值），请点击“下一步”加载所有可用补丁的列表并启动第 59 页第 4.3.4 节介绍的包管理器。在包管理器中，YOU 补丁的过滤器已激活，允许选择要安装的更新。建议安装的补丁是预设的。通常情况下，你应该接受此建议。

做出选择后，在包管理器中点击“接受”。所有选定的更新将将从服务器下载并安装在你的机器上。取决于连接速度和硬件性能，这可能需要一些时间。任何错误将在窗口中显示。如有必要，跳过相应的包。在安装之前，某些补丁可能会打开显示详细信息的窗口，允许你确认安装或跳过包。

在下载和安装更新期间，在日志窗口中跟踪操作。完成后点击“完成”。如果你在安装后不需要更新文件，可以使用“更新后删除源包”来删除它们。最后，执行 SUSEConfig 以使系统配置适应新情况。

除了 YaST 界面上的常用操作外，专家还可以从控制台窗口的命令行运行 YaST在线更新。在这种情况下，所需的操作作为命令行参数传递：`online_update[command line parameter]`。可用参数及其用途显示在以下列表中。

##### YaST 在线更新

YaST 在线更新（YOU）是从 SuSE 更新服务器获取所有推荐更新和安全修复的简单方法。

- 手动选择补丁：将显示所有可用补丁，从中选择要安装的补丁。
- 从服务器重新加载所有补丁：将从服务器或从本地之前的下载中获取所有补丁。
- 点击“新服务器”后：选择本地安装介质或 HTTP 服务器，或选择另一个来提供所选服务器的位置。
- 配置全自动更新：打开一个对话框，在其中配置 YOU 检查更新的顺序。
