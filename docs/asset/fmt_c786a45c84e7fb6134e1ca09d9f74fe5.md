
- 如果你的一个或多个磁盘驱动具有 GUID 分区表 (`GPT`)，那么 `gptfdisk` 或 `parted` 将非常有用。

- 最后，此时对以下配置文件进行审查也是合适的。

- `/etc/bashrc`

- `/etc/colors`

- `/etc/fstab`

- `/etc/hosts`

- `/etc/inputrc`

- `/etc/profile`

- `/etc/resolv.conf`

- `/etc/vimrc`

- `/root/.bash_profile`

- `/root/.bashrc`

- `/etc/sysconfig/network`

- `/etc/sysconfig/ifconfig.eth0`

既然我们已经说了这么多，让我们第一次启动我们那闪闪新的 LFS 安装吧！首先退出 `chroot` 环境：

```bash
logout
```

然后卸载虚拟文件系统：

```bash
mount -v $LFS/dev/pts
mount -v $LFS/dev
mount -v $LFS/run
mount -v $LFS/proc
mount -v $LFS/sys
```

卸载 LFS 文件系统本身：

```bash
mount -v $LFS
```

如果创建了多个分区，请在卸载主分区之前卸载其他分区，如下：

```bash
mount -v $LFS/usr
mount -v $LFS/home
mount -v $LFS
```

现在，使用以下命令重启系统：

```bash
shutdown -r now
```

假设已经按照前面的说明方法设置了 `GRUB` 引导加载程序，菜单已设置为自动启动 LFS 8.0。
