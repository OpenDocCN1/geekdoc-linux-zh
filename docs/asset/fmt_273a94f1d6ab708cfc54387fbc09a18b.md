在同一个书架上（或者你至少听过它们），你可能也在好奇这些书籍之间有什么区别。这些问题完全合理。简单来说，区别有两点：目标读者的经验水平以及每本书涵盖的发行版范围。《非技术人士的 Linux》（Linux for Non-Geeks）基于 Fedora Core 1，是我的第一本书，它是为像我一样的人编写的——即那些在 Windows 或 Mac 世界中拥有一定经验、对 Linux 感兴趣但不敢尝试的普通电脑用户。我的第二本书《轻松玩转 Linux》（Linux Made Easy）基于 Xandros 3，编写得更基础一些，适用于那些只想找到一种免费且简单的方法来摆脱微软帝国错综复杂网络的人们。

正如你所想象的，《非技术人士的 Ubuntu》（Ubuntu for Non-Geeks）是基于 Ubuntu 的，而原版的《非技术人士的 Linux》针对的是对 Linux 感兴趣但觉得需要某种跳板的读者。它与前作之间有一些相似之处，但由于基于 Debian 的 Ubuntu 与基于 RPM 的 Fedora Core 之间的本质差异，以及 Linux 整体的进步，《非技术人士的 Ubuntu》是与众不同的。这些进步使得系统比以往任何时候都更易用、更方便。

如果你熟悉电脑但不熟悉 Linux，且没有 Ubuntu，那么你本质上就是我写这本书的读者。为了避免你产生任何误解（尽管这有冗余的风险），我必须重申，这不是一本为资深极客或高级用户准备的书。它是一本入门指南，将为新用户提供实践经验，让他们启动、运行并熟悉 Linux Ubuntu 发行版。

## 版本兼容性

本书是为 Ubuntu 7.04 (Feisty Faun) 桌面版准备的。书中附带了一份完整的系统拷贝，位于单张光盘上，它不仅可以作为安装光盘，还可以作为 Live CD。这意味着你可以直接从光盘运行 Ubuntu，而无需触碰你的硬盘。这样你就可以在做出任何硬件投入之前尝试一下 Ubuntu。既然我们谈到了硬件，也值得指出的是，运行 Live CD 让你有机会看看 Ubuntu 是否与你现有的硬件兼容。

如果你喜欢你看到的内容，并且所有硬件看起来都能正常工作，你就可以在电脑上安装全部内容……而且还是使用同一张光盘（说明见第 2 章）。

计算机世界是极其动态的，因此在本书发布后，软件或书中项目文件的链接可能会发生变化。我会在 `www.edgy-penguins.org/UFNG` 发布任何此类更改。

## 概念与方法

作为一名语言老师，我一直喜欢编程书籍、数学和老式的外语学习教材，因为它们具有直观的、以技能为导向的特点，每一章都建立在前一章所获得的技能之上。我尝试以这种方式组织这本书，让你永远不会要求去做你尚未学过的事情。我也喜欢这样的书籍，因为它们不仅教你如何做某事，还提供机会让你通过练习将那些知识点付诸实践。我在书中包含了几项练习或项目，以便你有机会应用所学知识。本书将作为参考，并提供一种正如人们所说的“在做中学到”的动态学习体验。
