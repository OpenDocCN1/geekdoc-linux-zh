
## Install（安装）
你可以使用此选项安装一个或多个软件包；你可以使用此函数安装整个组。假设你使用 Fedora Core 3 发行版包含的 XMMS 多媒体播放器，但默认没有安装。你的 DVD 在另一个房间，你不想起身去拿。（我们暴露了太多我们懒惰的习惯了。）不，你连接了互联网，运行 `yum install xmms` 命令并且拥有它。

## Info（信息）
此选项提供软件包的摘要。运行 `yum info mozilla` 命令，YUM 就会出去并提供 Mozilla 软件包信息摘要。

## List（列出）
此选项提供有关你计算机上安装的软件包的信息。使用 `yum list mozilla` 命令可以查找安装在你计算机上的 Mozilla 软件包的信息。

## Provides（提供）
使用此选项使用字符字符串和通配符来查找由什么功能或文件提供内容。

## Remove（删除）
使用此选项删除一个或多个软件包及其依赖项。

## Search（搜索）
使用此选项查找匹配你提供的文本字符串的软件包。例如，如果你输入 `yum search`，你将获得软件包列表。

## Update and check-update（更新和检查更新）
`update` 用于更新软件包或你的整个计算机；更新过程会移除旧版本并安装新版本。如果你运行 `yum update`，你的整个计算机将被更新。指定单个软件包（例如，`yum update mozilla`）将更新该软件包。

你可以显示哪些软件包可以更新。输入 `yum check-update` 命令，你计算机的所有可用软件包更新将被显示。

## Upgrade（升级）
此选项不再使用并在将来被移除。请使用 Update 选项。
