
## 复选框组

`-name` 和 `-values` 是必填的，其功能与独立复选框相同。所有其他参数都是可选的。`-default` 是默认选中的值列表或单个选中值的名称。如果将 `-linebreak` 设置为 `true`，则每个复选框之间将换换行，使其以垂直列表的形式出现。否则，它们将在同一行内相邻列表。`-labels` 是每个值标签的关联数组，与弹出菜单中的相同。如果指定了 `-nolabels`，则按钮旁边不打印标签。

如果你想生成一个包含复选框的 html3 表格，可以使用 `-rows` 和 `-columns` 参数。如果设置了这些参数，组中的所有复选框将被放入一个使用指定的行和列数的 html3 表格中。如果你愿意，可以省略 `-rows`，系统将为你计算正确的数量（基于你在 `\-columns` 中指定的值）。此外，你还可以使用 `-rows` 和 `-columns` 添加表头。

```
print $cgi->checkbox_group( -name=>'group_name',
 -values=>['one', 'two', 'three'],
 -size=>4,
 -multiple=>'true',
 -labels=>\%labels);
```

## 单选按钮组

你使用 `radio_group()` 方法创建单选按钮。如果你有一组在逻辑上相互关联的单选按钮，可以使用它们。

```
print $cgi->radio_group( -name=>'group_name',
 -values=>['uno', 'dos', 'tres'],
 -default=>'dos',
 -linebreak=>'true',
 -labels=>\%labels);
```

`-name` 和 `-values` 是必填的，其功能与独立复选框相同。所有其他参数都是可选的。`-default` 是默认选中的值列表或单个选中值的名称。如果将 `-linebreak` 设置为 `true`，则每个复选框之间将换行，使其以垂直列表的形式出现。否则，它们将在同一行内相邻列表。`-labels` 是每个值标签的关联数组，与弹出菜单中的相同。

## 提交按钮

你使用 `submit()` 方法创建提交按钮。如果你有一组在逻辑上相互关联的单选按钮，可以使用 `submit()`。

```
print $cgi->submit( -name=>'submit_name',
 -value=>'value',
 -label=>'Submit Form');
```

`-name` 是一个包含提交按钮名称的参数；它是唯一的必填参数。提交按钮的名称也会用作按钮旁的可读标签，除非 `-label` 另有指定。`-value` 指定了按钮被提交时的值。`-label` 指定了按钮旁边显示的内容。

## 重置按钮

这里显示的 `reset()` 方法将表单重置为默认值。该方法与 `reset()` 不同，后者只是取消用户做的更改。

```
print $cgi->reset( -name=>'reset_name',
 -value=>'value',
 -label=>'Reset');
```

## 默认按钮

这里显示的 `defaults()` 方法将表单重置为默认值。该方法与 `reset()` 不同，后者只是取消用户做的更改。如果给了一个参数，它被用作按钮标签。

```
print $cgi->defaults('button_label');
```

## 隐藏字段

这里显示的 `hidden()` 方法产生一个对用户不可见的文本字段。这种功能用于从一个表单向另一个表单传递数据，而不会让屏幕充满信息。

```
print $cgi->hidden( -name=>'field_name',
 -default=>['value1', 'value2', 'value3']);
```

两个参数都必须给出。与其他情况一样，第二个可以是匿名数组或命名数组的引用。

## 可点击图像按钮

所以你不满足于普通的超链接作为链接？想用图像代替？按如下方式使用 `image_button()` 方法：

```
print $cgi->image_button( -name=>'button_name',
 -src=>'/images/clickMe.gif',
 -align=>'middle',
 -alt=>'Click Me!');
```

当你使用 `image_button()` 时，`-name` 和 `-src` 是必填的。点击图像时，不仅表单会被提交，点击图像位置的 *x* 和 *y* 坐标也会通过两个参数提交：`button_name.x` 和 `button_name.y`。

## JavaScript 按钮

这里的 `button()` 创建 JavaScript 按钮。这意味着在 `-onClick` 中引用的 JavaScript 代码将被执行。注意，如果浏览器不支持 JavaScript、浏览器关闭了此功能，或者浏览器位于过滤 JavaScript 的防火墙之后，此方法将完全不起。

```
print $cgi->button( -name=>'big_red_button',
 -value=>'Click Me!',
 -onClick=>'doButton(this)');
```

你正在实现一个包含从文件中读取信息的表格。可能使用 `print` 来打开 `<TABLE>` 标签，使用方法返回表格内容，然后使用另一个 `print` 关闭表格会更好。对象纯主义者可能更倾向于完全通过 CGI 方法来完成所有操作，但在实践中，有时在程序中直接嵌入一个带有原始 HTML 的 `print` 语句更符合逻辑（从简单性和可读性的角度来看）。

由于 CGI 模块正在不断增强，请务必检查 CGI.pm 文档以获取方法、参数和功能的完整列表。你可以在 Web 上找到该文档：

`http://www.genome.wi.mit.edu/ftp/pub/software/WWW/cgi_docs.html`

## Netscape Cookies

使用 Cookie 是另一种维护状态信息的方法。Cookie 仅仅是包含多个键/值对的数据，这些数据在 HTTP 头部中在客户端和服务器之间传递，而不是在查询字符串中。除了键/值对外，还有几个可选属性。

以下是一个演示如何使用该方法的示例 Cookie：

```
$my_cookie = $cgi->cookie( -name=>'myBigCookie',
 -value=>'chocolate chip',
 -expires=>'+5y',
 -path=>'/cgi-bin',
 -domain=>'.example.com',
 -secure=>1);
 print $cgi->header(-cookie=>$my_cookie);
```

`cookie()` 方法创建一个新的 Cookie。其参数如下：

- `-name`

此必选参数用于标识 Cookie。

- `-value`

此参数指定 Cookie 的值。它可以是一个标量值、数组引用或关联数组引用。

- `-path`

此参数指定 Cookie 有效的路径路径。

- `-domain`

此参数指定 Cookie 有效的部分域名。

- `-expires`

此参数指定 Cookie 的过期日期。其格式与 HTTP 头部部分中描述的相同。

- `-secure`

如果将此参数设置为 1，则 Cookie 仅在 SSL 会话中使用。

使用 `cookie()` 方法创建的 Cookie 必须按照如下方式通过 `header()` 方法在 HTTP 头部中发送：

```
 print $cgi->header(-cookie=>$my_cookie);
```

你可以通过向 `header()` 传递数组引用来发送多个 Cookie，并为要发送的每个 Cookie 命名：

```
print $cgi->header(-cookie=>[$cookie1, $cookie2]);
```

要检索 Cookie，可以使用 `cookie()` 方法在不带 `-value` 参数的情况下通过名称请求它：

```
use CGI;
 $cgi = new CGI;
 $stuff = $query->cookie(-name=>'stuff');
```

要删除 Cookie，发送一个与要删除的同相同的空白 Cookie，并将过期日期指定为过去的某个时间。

注意，Cookie 有一些局限性。客户端一次不能存储超过 300 个 Cookie。每个 Cookie 的长度不能超过四千字节（包括其名称）。每个域名不能指定超过 20 个 Cookie。
