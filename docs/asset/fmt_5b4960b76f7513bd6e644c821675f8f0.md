
# 亚毫米波

电磁波谱中亚毫米波波段中辐射的产生、探测和应用。实际上，这一区域对应于波长约30微米至3毫米之间（见插图）。在其两端，该区域与微波和红外波段重叠，其独特之处在于相邻波段特有的两种传播方式——导波传播和自由空间传播——在整个区域内均被使用。参见电磁辐射；红外辐射；微波。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_2150_0.png)

亚毫米波区域及其附近的电磁波谱，显示其频率、波长、波数和光子能量等效值。

直到20世纪50年代末和60年代初出现两项革命性进展后，亚毫米波区域才得到广泛应用：

- (1) 傅里叶变换光谱学的实用化，这极大地提高了宽频亚毫米波光谱学的质量；以及
- (2) 两种强度相对较高的亚毫米波激光源——氰化氢和氘代水蒸气电激发激光的发现。

参见红外光谱；激光。

## 辐射源

非相干辐射源的主要应用是作为傅里叶变换光谱仪中的宽频源。最常用的两种源是水银蒸气灯和光棒。参见水银蒸气灯；微波管。

相干亚毫米波辐射源有几种类别：

- (1) 非相对论电子束管，如腔调、互作用振荡器、Orotرونs、Leptotrons、Caricintorons或回波振荡器，它们以不同的可调性和输出功率振荡；
- (2) 相对论电子束器件，如回旋管、自由电子激光器和同步加速器；以及
- (3) 固态器件，如耿氏和IMPATT振荡器。

除了自由电子激光器外，这些都是长波器件。最后一类，气体激光器，覆盖了整个亚毫米波区域。参见回旋管；腔调；微波固态器件；同步辐射。

## 探测器

大多数亚毫米波探测器是热探测器、检波探测器或光子探测器。第一类响应由吸收辐射产生的热量，第二类响应辐射场感应电流的整流，第三类响应单个光子的吸收。它们通常直接和变频探测系统中使用。热探测器包括室温热电堆、高莱盒和热释电探测器，而更敏感的半导体辐射剂量计则在液氦温度下运行。检波器件包括金属-半导体和金属-金属点接触以及肖特基势垒二极管，均为室温器件，以及工作于约4.2 K（-452 F）的约瑟夫森型器件。亚毫米波光子探测器基于半导体，依赖于光子吸收改变载流子密度或迁移率，从而改变探测器的电导率。参见辐射剂量计；热释电；辐射测温；超导器件。

## 大气透明度

在可见光和微波区域之间，大气几乎是 opaque（不透明的），例外是近红外处的两个窗口和亚毫米波区域的三个窗口，位于94、140和220 GHz。亚毫米波窗口的显著特征是，恶劣天气条件对衰减水平的增加不像近红外那样严重。这使得它们在许多应用中具有吸引力。然而，这些窗口相关的衰减相当高，意味着地面低频亚毫米波系统的相对有限的传播距离。这在某些应用中可能是有利的。

## 应用

过去，亚毫米波区域的辐射应用均匀分布在雷达和 largely 非雷达活动上。然而，现在随着集成化、低成本发射机和接收机系统的发展，应用包括许多以94 GHz大气窗口为中心的雷达和电信相关活动。这些应用主要是军事的，但预计会有民用领域的溢出效应。

亚毫米波区域的光子能量对应于许多化学、机械和生物现象的活化能，该区域的光谱技术已广泛应用于研究这些现象。其他光谱应用集中于开发辐射测温方法，以满足聚变等离子体诊断和天文学的需求。参见亚毫米波天文学。

亚毫米波区域已广泛用于基本频率计量，将亚毫米波气体激光器的频率直接追溯至主频率标准。重要后果包括将光速定义为固定量以及重新定义米作为由此导出的单位。参见光；物理测量。

亚毫米波区域以两种方式影响聚变等离子体研究。首先，在托卡马克等装置中，它提供了一种研究电子温度时空演化的方法。第二种应用是电子回旋加热，即通过微波辐射在电子回旋频率下加热电子，这一现象已被证明。高功率回旋管振荡器通常用作辐射源。参见核聚变；等离子体[物理学]；等离子体诊断。

在快速电磁脉冲传播的研究和应用中，亚毫米波区域开发了多种新颖技术。这些脉冲的产生和探测可以通过超短光脉冲驱动光导开关，或基于非线性传输线的全电子系统来实现。用于天文学的亚毫米波辐射计被称为T波或太赫兹波。参见光脉冲。[R.J.B.]

# 亚音速飞行

飞行器以明显低于声波传播速度的速度穿越大气层的运动。亚音速飞行范围从零（悬停）延伸到约为当地温度下声速85%的速度。在较高的飞行器速度下，飞行器表面附近气流局部速度可能超过声速，此时真正的亚音速飞行不再存在。

飞行器类型可以从小型直升机（始终工作在速度尺度的下限）到洲际弹道导弹（虽然该导弹在此及其他速度区间均工作，但仅在亚音速飞行中持续几秒钟）。每种类型的设计都受相同的亚音速空气动力学原则影响。流体（如空气）的亚音速流动可按速度范围细分，在较低速度范围内（低于约300英里/小时或135米/秒），流动可视为不可压缩而无显著误差；而在较高速度范围内，流体的可压缩性变得显著。在这两种情况下，流体的粘性都很重要。适用于可压缩无粘性流体的理论几乎无需修改即可用于某些低亚音速问题，而在其他情况下，这些理论得出的结果可以修改以考虑粘性和压缩性。参见“可压缩流”；“概率飞行”；“粘度”。

典型的亚音速机翼剖面（翼型）具有圆弧形的前部（前缘）和尖锐的后部（后缘）。接近前缘的气流会在前缘上的某一点静止，该点上方的气流绕过机翼上表面流向后缘，下方的气流则沿下表面流向同一点，在此处气流理论上再次具有零速度。局部速度为零的两个点被称为驻点。如果从前驻点到后驻点的路径沿上表面比沿下表面更长，则沿上表面流动的平均速度必须大于沿下表面流动的平均速度。因此，根据能量守恒原理，上表面的平均静压必须小于下表面的平均静压。这种压力差施加在表面面积上并适当考虑力的方向，就产生了净升力。升力定义为垂直于流体相对于物体流动方向的力，或者更明确地说，垂直于自由流速度向量的力。参见“翼型”；“伯努利定理”。

机翼作为升力产生装置，无论是飞机中的固定式，还是直升机中的旋转式，可能是飞机中最重要的空气动力学部件。然而，亚音速飞机的稳定性和操纵特性取决于完整的结构。操纵是指飞机绕其重心处三个相互垂直的轴中任意轴旋转的能力。静稳定性是指飞机在受到绕任意轴的力矩扰动后，倾向于返回其原始飞行姿态的特性。[J.E.Ma.]

# 取代反应

一类化学反应中的一种，其中一个原子或原子团（基团）取代分子或离子结构中的另一个原子或原子团。通常，新基团占据被取代基团原来的结构位置。

取代反应涉及试剂（新原子或基团的来源）对底物（发生取代反应的分子或离子）的攻击。它们涉及新键的形成和旧键的断裂。取代反应根据试剂的性质（亲电、亲核或自由基）以及取代位点的性质（饱和碳原子或芳香碳原子）进行分类。参见“亲电试剂和亲核试剂”。

取代反应的系统命名由以下部分组成：引入的基团名称 + de + 被取代基团的名称 + ation，并根据语音和谐原则进行适当的省略或元音变化。因此，用甲氧基取代溴原子被称为“甲氧基去溴化”（methoxyde bromination）。参见“有机反应机理”。[J.EB.]

# 次同步共振

串联电容补偿电气系统与汽轮发电机机械弹簧-质量系统在次同步频率之间的共振。大约从1950年开始，在长距离交流输电线（250公里（150英里）或更长）中安装了串联电容器，以抵消线路固有感性电抗的一部分。直到1971年，在某些长距离线路中，高达70%的60赫兹感性电抗被串联电容器抵消，而对副作用的关注很少。（如果抵消了线路70%的感性电抗，则称该线路具有70%的串联补偿。）1970年，以及再次在1971年，内华达州南部莫哈维发电厂的一台汽轮发电机在经历将汽轮发电机辐射到串联补偿输电线路上的切换事件后，经历了轴损坏，每次都需要数月时间修复。轴损坏是由于发电机-励磁机轴两端之间的扭振引起的。在第二次事件发生 shortly 之后，人们确定扭振是由扭振相互作用引起的，这是次同步共振的一种类型。此后，还报告了其他两种类型的次同步共振，即感应发电机效应和转矩放大。参见“交流电路理论”；“交流发电机”；“输电线路”；“涡轮机”。

已明确建立，通过使用计数器抑制装置可以控制次同步共振，从而使人能够享受串联电容器的明显优势。已成功应用了大约一打计数器抑制装置，自1971年以来没有报告过次同步共振事件。次同步共振对策通过两种方法之一保护汽轮发电机轴免受有害扭振的影响。首先，当检测到次同步共振状态时，可以跳闸汽轮发电机。这限制了汽轮发电机轴经历的扭振次数。这种计数器抑制装置相对便宜，但如果预计的次同步共振状态预计频繁发生，则不可接受。通常，如果预计会导致汽轮发电机每10年跳闸超过一次，则不会将此对策作为唯一的次同步共振保护。应用了三种扭振计数器抑制装置：

- 扭振运动继电器，
- 电枢电流继电器，以及
- 发电机跳闸逻辑方案。

第二种保护方法不涉及汽轮发电机跳闸，但可消除或限制有害的扭振。参见“电力系统”。[R.G.F]
