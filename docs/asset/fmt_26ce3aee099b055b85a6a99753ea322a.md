### 关闭文件描述符

```bash
n<&-
关闭输入文件描述符 n。
0<-, <-
关闭 stdin（标准输入）。
n>&-
关闭输出文件描述符 n。
1>&, >-
关闭 stdout（标准输出）。
```

子进程会继承文件描述符。这就是为什么管道可以工作的原因。要防止 `fd` 被继承，请将其关闭。

## 20.1. 使用 exec

`exec <filename>` 将 `stdin` 重定向到文件。从该点开始，所有的 `stdin` 都将来自该文件，而不是它的原始源（通常是键盘输入）。这提供了一种按行读取文件的方法，并可能使用 `sed` 和/或 `awk` 对每行输入进行解析。
