### PNG (便携网络图形)
`PNG` 是一种专门为万维网设计的图形格式。`PNG` 允许在不损失质量的情况下压缩图像，包括高分辨率图像。`PNG` 的另一个重要特性是，任何人都可以创建处理 `PNG` 图像的软件而无需支付任何费用——`PNG` 标准没有任何任何许可费用。来自 Matisse http://www.ldap.org/LDP/Linux-Dictionary/html/index.html

### pngcrush
`PNG`（便携网络图形）文件的优化器。`pngcrush` 是 `PNG`（便携网络图形）文件的优化器。它的主要目的是通过各种压缩级别和 `PNG` 过滤方法减小 `PNG` `IDAT` 流的大小。它还可以用于删除不需要的辅助块，或添加 `gAMA`、`tRMS` 和文本块。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux–Dictionary/html/index.html

# pnm2ppa

# pnm2ppa
通过使用 `pnm2ppa` 将 `PPM` 转换为 `PVA`，可以在 Linux 上运行 HP–GDI 打印机。这些打印机通常是“Windows 专用”的，并使用专有的 `PPM` 协议。`pnm2ppa` 支持色彩且运行速度应该比 `pbm2ppa` 快。`pnm2ppa` 支持以下打印机：HP Deskjet 7XX 系列、HP Deskjet 820 系列和 HP Deskjet 1000 系列。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux–Dictionary/html/index.html
