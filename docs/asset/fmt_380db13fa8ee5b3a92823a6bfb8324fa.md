
### 参数扩展

```bash
[me@linuxbox ~] foo=bar
[me@linuxbox ~] echo ${foo:-substitute value if unset}
bar
[me@linuxbox ~] echo $foo
```

这是另一种扩展，我们使用等号代替横线：
`${parameter=word}`

如果 `parameter` 未设置或为空，则该扩展的结果为 `word` 的值。此外，`word` 的值会被赋值给 `parameter`。如果 `parameter` 不为空，则扩展的结果为 `parameter` 的值。

```bash
[me@linuxbox ~] foo=
[me@linuxbox ~] echo ${foo=substitute value if unset}
substitute if unset
[me@linuxbox ~] echo $foo
```

```bash
[me@linuxbox ~] foo=bar
[me@linuxbox ~] echo ${foo=substitute value if unset}
bar
[me@linuxbox ~] echo $foo
```

```bash
[me@linuxbox ~] foo=
[me@linuxbox ~] echo ${foo:-default value if unset}
default if unset
[me@linuxbox ~] echo $foo
[me@linuxbox ~] $foo-bar
[me@linuxbox ~] echo ${foo:"default value if unset"}
bar
[me@linuxbox ~] echo $foo
```

> 位置参数不能以这种方式赋值。

我们使用问号：
`${parameter?word}`

如果 `parameter` 未设置或为空，该扩展会导致脚本退出，并将 `word` 的内容发送到标准错误。如果 `parameter` 不为空，扩展的结果为 `parameter` 的值。

```bash
[me@linuxbox ~] foo=
[me@linuxbox ~] echo ${foo?"parameter is empty"}
bash: foo: parameter is empty
[me@linuxbox ~] echo $?
```

```bash
[me@linuxbox ~] foo=bar
[me@linuxbox ~] echo ${foo?"parameter is empty"}
bar
[me@linuxbox ~] echo $?
```

我们使用加号：
`${parameter:+word}`

如果 `parameter` 未设置或为空，扩展结果为空。如果 `parameter` 不为空，`word` 的值将替换 `parameter`；但是，`parameter` 的值不会改变。

```bash
[me@linuxbox ~] foo=
[me@linuxbox ~] echo ${foo:+substitute value if set}
substitute value if set
```

```bash
[me@linuxbox ~] foo=bar
[me@linuxbox ~] echo ${foo:+substitute value if set}
substitute value if set
```

### 返回变量名的扩展

shell 能够返回变量名。这被用于某些奇特的情况。

```
${!prefix*}
${!prefix@}
```

此扩展返回以 `prefix` 开头的变量。根据 bash 文档，这两种扩展的形式是相同的。在这里列出环境中以以下开头的变量：

```bash
[me@linuxbox ~] echo ${BASH*}
BASH_ARGC BASH_ARGV BASH_COMMAND BASH_COMPLETION BASH_DIR BASH_LINENO BASH_SOURCE BASH_VERSION
```

### 字符串操作

有很多扩展可以用于操作字符串。许多扩展特别适用于路径。以下扩展：

```
${#parameter}
```

扩展为 `parameter` 所包含的字符串长度。通常，`parameter` 是一个字符串；但如果 `parameter` 为 `*`，扩展的结果是字符个数。

```bash
[me@linuxbox ~] foo="This string is long"
[me@linuxbox ~] echo "${#foo} characters long"
"This string is long is 20 characters long.
```

以下扩展用于提取 `parameter` 所包含字符串的部分：

```
${parameter:offset}
${parameter:offset:length}
```

提取从字符串第 `offset` 个字符处开始，直到字符串结束，除非指定了 `length`。

```bash
[me@linuxbox ~] foo="This string is long"
[me@linuxbox ~] echo ${foo:5}
string is long.
[me@linuxbox ~] echo ${foo:5:6}
string
```

如果 `offset` 的值为负数，则意味着从字符串末尾而不是开头开始。注意值前面必须有一个空格以防止与 `${parameter:-word}` 扩展混淆。如果存在 `length`，它不能小于零。如果 `parameter` 为 `@`，扩展的结果是从 `offset` 开始的长度。

```bash
[me@linuxbox ~] foo="This string is long"
[me@linuxbox ~] echo ${foo:-5}
long.
[me@linuxbox ~]
lo
```

以下扩展根据 `pattern` 移除 `parameter` 字符串的头部部分。

```
${parameter#pattern}
${parameter##pattern}
```

`pattern` 是类似于路径扩展中使用的通配符。两种形式的区别在于：`#` 形式移除最短匹配，而 `##` 形式移除最长匹配。

```bash
[me@linuxbox ~] foo=file.txt.zip
[me@linuxbox ~] echo ${foo*}
txt.zip
[me@linuxbox ~] echo ${foo##}
zip
```

以下与之前的 `#` 和 `##` 扩展相同，但它们是从 `parameter` 字符串的末尾而不是头部移除文本。

```
${parameter%pattern}
${parameter%%pattern}
```

这里有一个例子：

```bash
[me@linuxbox ~] foo=file.txt.zip
[me@linuxbox ~] echo ${foo.*}
file.txt
[me@linuxbox ~] echo ${foo%%*}
```

以下扩展对 `parameter` 的内容执行搜索并替换操作：

```
${parameter/pattern/string}
${parameter//pattern/string}
${parameter#pattern/string}
${parameter%%pattern/string}
```

如果文本匹配通配符模式，它将被替换为 `string` 的内容。在普通形式下，只替换 `pattern` 的第一次出现。在 `//` 形式下，替换所有出现。`#` 形式要求匹配发生在字符串开头，`%` 形式要求发生在字符串结尾。在每种形式中，`/string` 都可以省略，被 `pattern` 匹配到的文本将被删除。

```bash
[me@linuxbox ~] foo=JPG.JPG
[me@linuxbox ~] echo ${foo/JPG/jpg}
jpg.JPG
[me@linuxbox ~] echo ${foo//JPG/jpg}
jpg.JPG
[me@linuxbox ~] echo ${foo#JPG/jpg}
jpg.JPG
[me@linuxbox ~] echo ${foo%/JPG}
JPG.JPG
```
