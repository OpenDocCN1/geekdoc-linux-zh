# 对应原理

一个基本假设，经典力学可以被理解为量子力学的极限；反之，只要重新解释经典力学，量子力学的许多特征在经典力学的基础上是一致的。这由 Bohr 在一组理解简单原子和分子的规则中首次提出。每个自由度的频率被相应的作用取代。Bohr 注意到，只要波长足够大，这种对应对于光从一个能级跃迁到另一个能级产生了正确的理论结果。因此，Bohr 理论中明显的矛盾通过对应原理得以解决。

1925年后，新的量子力学（特别是波力学）将对应原理简化为原子状态的极限。经典力学对于粗略估计（例如某能量以下的能级数量）仍然足够，那里不需要量子力学。然而，对应原理获得了更深远的意义。原子、分子和核物理中的实验证据证明了它的实用性。在经典力学方法无效或无效的地方，已有数千个能级的高精度数据。然而，基本思想仍然有效。对于高激发态必须从经典力学的角度理解量子力学，即使基态保持不可预测和混沌。Bohr 对应原理的应用也解决了许多难题，使其有了新的视角。原子结构与光谱、化学键、分子和原子结构、量子力学。[M.C.J.]

**宇宙射线** 电子和原子核（主要是氢）以接近光速的速度离开太阳系。这些具有相对论论速度的原子核通常被称为宇宙射线，以区别于它们在与太阳大气层顶部的粒子碰撞时产生的次级粒子级。

初级宇宙射线提供了太阳系外物质的唯一直接样本，其成分有助于我们理解构成太阳系的物质中哪些方面是银河系的典型特征，哪些方面对于特定的局部环境可能是不常的。因此，带电粒子会被微弱到无法到达地球的磁场偏转；它们可以被用于确定地球的成分。在太阳系之外，宇宙射线的成分与磁场进行比较，因此宇宙射线可能在决定磁场结构，以及宇宙射线与渗透其中的稀薄气体（化学成分种类多样）和地球产生的伽马射线之间的平衡中起着主要作用，提供了有关这种气体起源的信息。
