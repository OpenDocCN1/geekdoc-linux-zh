# 硬件要求

您可以通过评估版光盘在计算机上设置 SuSE Linux，而无需更改硬盘的分区。如果您的硬盘上有大约 100 MB（理想情况下为 200 MB）的可用空空间，甚至可以永久安装该评估系统。

需要至少具备以下硬件的计算机：特腾处理器（或兼容处理器）、64 MB RAM（内存）、一个可启动的 CD-ROM 驱动器以及一个支持 2.88 MB 启动镜像的 BIOS，以及已分区并格式化的硬盘。
