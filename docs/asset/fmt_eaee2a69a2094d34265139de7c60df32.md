
对石油（或原油）进行分析，以确定其在现代炼油作业中的价值。此外，还开发了用于润滑油分析的程序。对于炼油作业而言，石油分析（或试验）必须为炼油规划人员提供必要的数据，以预测在广泛的炼油操作条件和产品需求下的收率、质量和运营成本。在炼油厂中，原油根据其组分的沸点被蒸馏并分离成产品（参见下表）。参见：石油（PETROLEUM）；石油产品（PETROLEUM PRODUCTS）。

| 产品 | 碳原子范围 | 沸程，°F (°C) |
| :--- | :--- | :--- |
| 气体 | C₂ 和 C₃ |  |
| 石油气 | C₄ 和 C₅ |  |
| 汽油 | C₆ 到 C₁₀ | 59–370 (15–190) |
| 煤油 | C₈ 到 C₁₅ | 300–540 (150–280) |
| 中间馏分 | C₁₀ 到 C₁₅ | 390–640 (200–340) |

原油试验遵循大致相同的程序。石油被蒸馏并分离成多达 40 个窄沸程切割馏分。然后每个馏分 undergo 一系列足以表征其可纳入产品的测试。炼油规划人员随后可以通过混合包含在特定产品中的各馏分的收率和质量，计算任意产品的收率和质量。

石油主要由含 1 到约 60 个碳原子的碳和氢化合物组成。天然石油中的碳原子存在于直链和支链（石蜡烃/烷烃）中，存在于单环或多环饱和环（环烷烃或环烷族）中，以及存在于芳香族类型的环状结构中，如苯、萘和菲。环状结构上可能连接石蜡碳侧链。在润滑油中，通常将环烷环构建在芳环上并连接有侧链。在炼油厂裂化生产的产品中，也发现了烯烃或具有碳-碳双键的化合物，以及净化的芳环。石油的高沸点馏分含有越来越多的氧、氮和硫化合物，以及钒、镍和铁等金属有机化合物的痕迹。

有三种类型的测试用于表征原油及其窄沸程馏分：
1. 物理性质测试，如比重、折射率、凝固点、蒸气压、辛烷值和粘度；
2. 特定化学物质测试，如硫、氮、金属以及总石蜡烃、环烷烃和芳烃；
3. 确定实际化学组成的测试。

使用过的润滑油分析是许多类型发动机和工业设备维护计划的一部分。要分析润滑油，需收集在正常操作温度下在系统中流动的有代表性的润滑油样本，装入透明容器并贴上相关数据标签。随后尽快将样本送至测试实验室。对使用过的机油进行的测试包括粘度、燃料稀释、水分、不溶物以及光谱化学或光谱光度分析。磨损金属的浓度以百万分比（ppm）测定；这些金属除了硅之外，还可能包括银、铝、铬、铜、铁、镍、铅和锡。其中任何一种浓度的增加都可能表明发动机存在异常磨损。参见：发动机（ENGINE）；内燃机（INTERNAL COMBUSTION ENGINE）；光谱学（SPECTROSCOPY）。

# 海上石油与天然气

多年来，石油公司止步于水边，或仅在毗邻陆上产区的内陆水域或浅海中寻找和开发油气藏。直到石油能源需求增加以及陆上钻探回报率下降，从而提供了在海洋钻井所需巨额投资的动力，深海勘探及领土界限以外大陆架上的开采才开始真正兴起。参见：大陆边缘（CONTINENTAL MARGIN）；石油与天然气（OIL AND GAS）；钻井（DRILLING）；石油储量（PETROLEUM RESERVES）。

如今，海上石油勘探和生产已是一个全球性的产业。到 1990 年代初，海上来源占全球原油产量的 30% 和全球天然气产量的 14%。到目前为止，大多数海上产量来自位于大陆架下、水深达 600 英尺（180 米）的油藏。受技术进步和寻找额外安全能源需求驱动，勘探和生产正进一步远离海岸，深入大陆坡的更深水域。已在比 9000 英尺（2750 米）更深的水域钻探了勘探井，并正在从比 5000 英尺（1500 米）更深水域的海上油田开采碳氢化合物。

石油工业转向大陆架和大陆坡是有坚实地质依据的。在现今世界海洋之下，存在有利的沉积物和构造，其地质设置已在陆地上被证明高产。事实上，地下地质条件的相似性（在某些情况下甚至优于陆地地质条件）是世界在海上勘探和生产领域扩大投资的关键因素。参见：海洋地质学（MARINE GEOLOGY）。

在墨西哥湾、巴西近海、西非近海以及挪威、爱尔兰和英国海岸外的北大西洋，正在水深达 10,000 英尺（3050 米）的地方进行重要的勘探。在墨西哥湾和巴西近海，水深已达 5500 英尺（1675 米）的油气田已开始投产。在设得兰群岛以西的北大西洋，由于天气条件特别恶劣，已开始从水深达 1500 英尺（450 米）的油藏进行生产。参见：石油地质学（PETROLEUM GEOLOGY）。

进军开放且往往恶劣的海洋，不仅需要开发钻井船，还需要大量的辅助设备和技术。已形成了一个完整的工业体系来服务于海上工业，包括建造固定平台结构，目前世界大多数海上石油和天然气都是从这些平台上钻探和生产出来的。

美国墨西哥湾沿岸是全球大部分海上钻探活动的所在地，经常遭受飓风袭击，导致平台受损或摧毁。早期固定的平台成功项目因强风和巨浪而早早失去。然而，对环境的更好地理解，以及更先进的材料和结构分析技术，已显著减少了因环境力导致的故障。目前事故的主要原因在于人为错误、过程危害以及通过直升机往返于海上设施的交通。参见：人为因素（HUMAN FACTORS）。

改进的油气田管理以及新的发现增加了陆上油田的产量，因为那里的成本低于海上。然而，世界对石油能源日益增长的需求迫使人们继续在更深水域和世界更偏远的角落寻找新的储量。

# 油气田开发

在石油工业中，油层是指含有一或数个具有商业价值的油或气藏、或两者兼有的区域，其间没有实质性中断。单个油藏（或无法单独开采的油藏群）称为油气池。几个被无孔隙、不透气的岩石分隔开的油气池可能在同一油气池内上下叠加。油气池的平面范围各不相同。位于油层内任何足够深的井应从其中一个或多个油气池中产出油气。然而，每口井不能从每个油气池中产出，因为不同的油气池具有不同的平面界限。

油层的开发包括为在该油层中生产具有商业可采性的石油和天然气所必需的井的位置确定、钻探、完井和设备配置。

## 一般考虑

石油和天然气的生产必然紧密相关，因为美国总天然气产量的约三分之一是从被归类为油井的井中采出的。然而，石油中天然存在的碳氢化合物不仅是液态和气态，甚至可能以固态形式存在，如沥青和某些沥青质。

当无油产气时，生产问题简化了，因为产品在井的全生命周期内自然流动，无需举升到地面。然而，气井中有时会出现气积聚问题，需要从井中泵出水以维持最大或经济的气产量。油井和气井之间的界限并未明确确立。大多数气井产生可凝缩蒸气，如丙烷和丁烷，这些可以液化并作为燃料销售，而随气产生的更稳定的液体可用作天然汽油。

## 生产方法和举升液体

油井常见的生产方法包括：
- 自喷
- 抽油杆泵
- 气举
- 液压潜水泵
- 电动离心井泵
- 气抽（swabbing）

然而，大多数井不自喷，必须采用各种举升方法。在美国，约 90% 通过某种人工举升方法投产的井装备有抽油杆式泵。在这些泵中，泵安装在油管柱的下端，并由从地面延伸至潜水泵的一串抽油杆驱动。两种常见的变体是机械式和液压式长冲程泵。其他举升机制包括气举、液压潜水泵、气抽器、捞油器、喷射泵和声泵。参见：油气井完井（OIL AND GAS WELL COMPLETION）。

## 油气井完井

**生产仪器。** 在石油生产作业中，常见且较为重要的仪器包括以下几种：
- 1. 气体流量计，通常为孔板型，设计用于记录孔板前后的压差以及静压。
- 2. 记录式井下压力计，其尺寸足够小，可放入内径（ID）为 2 英寸（3 厘米）的管柱中运行，广泛用于测量流动气体管柱中的压力梯度、记录关井时的压力恢复情况，以及测量平衡井底压力。
- 3. 井下采样器，设计用于在管柱的不同层级采集井液样本，以确定其物理性质。
- 4. 各种类型的油计量器，用于计量流向或流出储罐的原油。
- 5. 力矩仪，用于测量光杆载荷。
- 6. 液位计和控制器。它们与其他行业中使用的类似设备相似，但针对封闭式租约罐进行了特殊设计。

**油气储存** 通常是指从天然储层开采后，以大量形式储存原油和天然气。也会储存大量的精炼产品；储存是必要的，以应对季节性和其他需求波动；保证生产设备、管道、油轮和炼油厂的运行效率；以及供紧急使用。

**原油和精炼产品。** 来自生产井的石油首先收集在焊接钢制、螺栓钢制或木制储油井中，容量为 100 桶（16 立方米）或更大。这些储罐为带有低坡度锥形顶盖的直立圆柱体，在石油等待运输时提供临时储存。几个储罐组合在一起构成一个罐组。大型钢制储罐的集合称为罐场，用于管道泵站、油轮装卸点以及炼油厂的较永久性储存。

对于 offshore 生产区，设计了许多独特的储存系统。在某些情况下，油轮被改造用于储存，驳船则专门建造用于海上储存用途。

为了最大限度地减少蒸发损失，租约罐有时会被配备以承受数英寸压力的装置。在大容量储存站点，通常使用特殊储罐。带升举式或浮顶的储罐用于储存原油、车用汽油和挥发性较低的天然汽油。车用汽油和天然汽油也储存在球形容器的容器中。球形容器用于储存更易燃的液体，如丁烷。卧式圆柱形容器用于丙烷和丁烷的储存。允许以较低压力储存丙烷的制冷隔热罐系统也在使用中。
