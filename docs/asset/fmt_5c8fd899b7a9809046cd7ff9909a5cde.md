#### 6.1.1 确保 /etc/passwd 权限配置正确
(自动化)

**配置适用性**：
- 级别1 - 服务器
- 级别1 - 工作站

**描述**：
`/etc/passwd` 文件包含许多系统实用程序使用的用户账户信息，因此为了让这些程序运行，必须是可读的。

**原理**：
确保 `/etc/passwd` 文件免受未经授权的写访问至关重要。虽然它默认受到保护，但文件权限可能会无意中或通过恶意行为被更改。

**审计**：
运行以下命令验证 `/etc/passwd` 模式为 644 或更严格，Uid 为 0/root，Gid 为 0/root：

```bash
# stat -Lc "%n %a %u/%U %g/%G" /etc/passwd
/etc/passwd 644 0/root 0/root
```

**修复**：
运行以下命令在 `/etc/passwd` 上删除多余权限并设置所有者和组：

```bash
# chmod u-x,go-wx /etc/passwd
# chown root:root /etc/passwd
```

**默认值**：
`/etc/passwd` 644 0/root

#### 6.1.5 确保 /etc/shadow 的权限已配置
（自动化）

**配置适用性**：
- Level 1 - 服务器
- Level 1 - 工作站

**描述**：
`/etc/shadow` 文件用于存储有关用户账户的信息，这些信息对于账户的安全性至关重要，例如哈希密码和其他安全信息。

**理据**：
如果攻击者获得对 `/etc/shadow` 文件的读取权限，他们就可以地针对哈希密码运行密码破解程序来破解它。存储在 `/etc/shadow` 文件中的其他安全信息（如过期时间）也可能用于破坏账户。

**审计**：
运行以下命令验证 `/etc/shadow` 模式是否为 640 或更严格，Uid 为 0/root 且 Gid 为 0/root：

```bash
$ stat -Lc "%n %a %u/%U %g/%G" /etc/shadow
```

**示例**：

```
/etc/shadow 640 0/root 42/shadow
```

**修复**：
运行以下命令之一将 `/etc/shadow` 的所有权设置为 root，并将组设置为 root 或 /shadow：

```bash
# chown root:shadow /etc/shadow
-OR-
# chown root:root /etc/shadow
```

运行以下命令移除 `/etc/shadow` 上的多余权限：

```bash
# chmod u-x, g-wx, o-rwx /etc/shadow
```
