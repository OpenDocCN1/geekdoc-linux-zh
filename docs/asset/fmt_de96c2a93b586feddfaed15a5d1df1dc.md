
尝试这一点最快速简单的方法通常是使用 Kali 自带的 `searchsploit` 工具。如果你还没有发现这个工具，一个全新的世界将出现在你的指尖。`Searchsploit` 基本上根据你提供的关键词在 `exploit-db` 数据库中搜索，并返回可以在 `Metasploit` 中使用的漏洞以及不同语言的独立代码漏洞。其语法易于记忆：

```bash
searchsploit keyword1 keyword2...
```

如果你对 `Metasploit` 有丰富的经验，你可能已经熟悉有效负载（payload）的概念。当你使用 `Metasploit` 模块时设置的有效负载决定了漏洞利用在有效的攻击尝试中实际执行的操作。通常，你想打开一个 `Meterpreter` 会话或一个反弹 Shell，这样你就能控制受害者机器。

在 `Metasploit` 中选择有效负载时，类似于在漏洞利用代码中手动切换有效负载。因此，为了替换 `Metasploit`，我们所做的就是手动切换有效负载。这通常意味着我们需要产生某种机器码（shellcode）。

幸运的是，`Msfvenom` 被允许用于测试。我们可以使用它来生成自定义有效负载，然后将其为我用。如果你正在参加 `OSCP` 测试，提醒一点：坚持使用常规的反弹 Shell 有效负载，不要使用 `Meterpreter` 的。`OSCP` 测试中禁止使用 `Meterpreter`。


## 无线渗透测试

安装无线系统比在有线网络上进行要容易。如果你离得足够近，能够“听见”（或至少你的无线适配器可以听到）任何在空气中传输的信号，你就实际上无法针对无线媒介强制执行良好的物理安全措施。正如你目前所看到的，有一系列设备已经准备就绪可以使用。

执行无线网络渗透测试可能需要的额外代码和设备见下文。这是我实际使用的工具包，它非常合用。

你可以下载 Kali 作为你电脑上唯一的操作系统，或者运行 `.iso` 文件。后一种方案是我正在使用的，即使用 Oracle VM VirtualBox（免费软件）来打开 Kali Linux 的 `.iso` 文件。

无线卡：如果你在虚拟机中运行 Kali UNIX 操作系统，你将能够直接在虚拟机中使用电脑的无线网卡。为了这一目的，你需要一个外部无线适配器（本教程前面的章节中介绍了良好的无线网卡的描述）。顺便说一下，我使用的是 ALFA AWUS036NH，我感受到它的“质量”。它具有高增益控制（1W）和内置的 5dBi 天线。你可以考虑将它用于你的 Wi-Fi 接入，因为它比大多数笔记本自带的某些“Intel”型号好得多。

准备好这一切就可以大显身手了。

无线渗透测试流程：无线网络的测试总是分为两个阶段——被动阶段和主动阶段。你可以想象的任何可能的攻击（无论是无线还是其他任何）总是从某种被动阶段开始。

入口分析器（或攻击者）在脱离阶段收集有关目标的数据。攻击可能会有不同类型的被动部分——对环境的感知。

在互联网、媒体上查阅目标的安全措施。与合法用户讨论安全控制措施。

### 嗅探流量

某些实验可能已经处于那个阶段了。黑客有可能直接从无意识的合法用户那里获取了他想要的所有数据，或者他嗅到的流量已经足够让某些离线的攻击（离线的野兽力量、离线的词汇或异常的机密钥数据）被移动到嗅探到的明文内容包中。

相反，如果信息不足，就会有一个后续的阶段，一个功能性的阶段。这是攻击者合法地与目标个体交流的地方。他们可能会发送钓鱼邮件，明确要求用户的凭据。

- 注入无线帧以诱导特定动作（例如用于取消认证的区块）。
- 构建合法用户用于连接到无线网络的虚假 AP。

本章提到的所有攻击都是被动的，或者是被动与主动的结合。当读者在它们之间移动时，很容易看出被动阶段何时结束，主动阶段何时开始。

我们都听过关于公司的 Wi-Fi 被用来破解其安全的故事。最著名的案例是 TJ Maxx。TJ Maxx 的母公司使用无线等效隐私（WEP）保护其无线局域网（LAN）。WEP 是保护无线局域网最弱的安全类型。黑客破解并窃取了记录，以及许多信用卡号。

TJ Maxx 的安全泄露发生在几年前，当时的 Wi-Fi 保护选项较低且较弱。简而言之，WEP 协议中存在一个为人知的漏洞，由于 TJ Maxx 没有意识到或忽略了这一事实，这对他们的财务状况和信誉产生了负面影响。该公司不想再重蹈覆辙，因此请确保你的尽职以防止类似情况的发生。

无线渗透测试可以使用类似于典型有线渗透测试的技术对网络进行测试。然而，我们应该依靠无线作为破解漏洞后门。因此，选择合适的合作伙伴来进行无线渗透测试是一个重要的决定。寻求 `OSCP`、`OSCE`、`GPEN`、`CEH`、`CPT` 和 `CWNP` 等认证。

选择一个具有技术专长的组织。当他们的经验深而广时，他们能够深入挖掘并为你提供额外的价值信息。索取一份类似的无线渗透测试的发行报告示例。报告应该是内容丰富且自俗其懂的。凭借良好的业务洞察力，测试人员将根据你的行业领域和监管要求调整他们的工作。渗透分析旨在尽可能地模拟现实中的攻击。

无线渗透测试有许多优势。识别风险行为者可能利用的漏洞至关重要。检查你的安全策略的有效性并识别潜在缺陷，使得组织能够在这些问题实际发生之前进行修复。这种渗透检查也将作为对你业务威胁/漏洞管理的第三方验证。

最后，你必须记住 Wi-Fi 并不是黑客可以唯一无线技术。还有大量的蓝牙和低功蓝牙（BLE）技术。其他无线技术如 ZigBee、Z-wave 和 DECT（无线电话）也可用。

### 理解数据收集与评估

无线渗透测试有多个阶段。第一阶段是知识收集，然后是分析。为了让良好的测试人员知道如何从无线网络收集数据，测试人员需要理解信号泄漏。基本上，信号泄漏（或溢出）是任何超出覆盖区域的无线信号。无法完全消除这种泄漏。尽管如此，减轻信号泄漏并确保感知存在是最佳实践。无线专家需要理解无线操作中采用的安全协议。

《健康保险流通与与责任法案》（HIPAA）保障了患者健康信息的隐私。《家庭教育权利与隐私法》（FERPA）保护了学生教育数据的隐私。信息安全管理体系（ISMS）是一种策略和系统结构，涵盖了企业信息风险管理过程中涉及的所有法律、物理和技术控制。

深入了解这些不同的机构，将使你的无线渗透测试变得至关重要，能够根据你的技术进行定制，并充当你业务的第三方审计员。熟练的测试人员在无线技术方面应具备相关技能。这包括查看非 FAA 许可的点对点连接。研究蓝牙将有助于发现在你的网络中使用该软件时出现的任何缺陷。

无线渗透测试员不仅必须是一个出色的渗透测试员，还必须な一名高水平的无线工程师。在选择公司进行无线渗透测试时，要提问对你的业务或行业重要的问题。如果你这样做，你就能从更专业的人员中筛选出经验较少的使用者。

### 理解 Wi-Fi 测试技术

渗透测试的研究流程如下：

- 无线局域网 (WLAN) 评估
- 越权访问点 (Rogue AP) 分析
- 无线热点
- 加密协议

`WLAN` 评估包括几项操作：活动 AP 指纹技术、数据项泄露、以及对 `Kismet` XML 文件的服务器后处理分析。使用 `Kismet` 和 `Wireshark` 识别 `WLAN` 上使用的认证和加密方法，并绘制室内外 `WLAN` 的范围。评估在数据披露监测模式下收集的流量、通过 MAC 分析识别多播协议、分析加密流量和私有身份验证功能，均有助于判断你 `WLAN` 的强弱。
