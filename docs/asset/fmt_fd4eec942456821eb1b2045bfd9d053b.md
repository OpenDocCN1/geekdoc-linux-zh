
## `HEAD` 命令

Linux 中的 `head` 命令用于显示文件或输入的前几行。默认情况下，它显示前 10 行。该命令对于快速查看文件开头以理解其结构或内容，无需打开整个文件。

### 基础语法

`head [OPTION] [FILE]...`

### 常用选项

- `-n [NUMBER]`：显示文件的前 `NUMBER` 行。
- `-c [NUMBER]`：显示文件的前 `NUMBER` 字节。
- `-q`：在检查多个文件时抑制头信息。
- `-v`：在检查多个文件时始终显示头信息。

### 显示文件的前 10 行

`head filename.txt`

### 显示文件的前 20 行

```bash
head -n 20 filename.txt
```

### 显示文件的前 50 字节

```bash
head -c 50 filename.txt
```

### 显示多个文件的前 5 行

```bash
head -n 5 file1.txt file2.txt
```

### 显示多个文件的前 10 行（不带头信息）

```bash
head -q file1.txt file2.txt
```

### 显示多个文件的前 10 行（始终带头信息）

```bash
head -v file1.txt file2.txt
```

### 总结

`head` 命令是一个简单而强大的工具，用于快速查看文件的开头。它可以自定义显示特定数量的行或字节，并可以通过控制头信息的选项处理多个文件。该命令通常用于脚本编写和命令行数据检查，以预览文件内容。

## `tail` 命令

Linux 终端中的 `tail` 命令用于显示文件的最后部分。默认情况下，它显示文件的最后 10 行，但可以自定义显示不同数量的行甚至字节。它对于监控日志文件或检查文件的最新更改特别有用。

### 语法

`tail [OPTION] [FILE]...`

### 常用选项

- `-n,--lines=[+]NUM`：输出最后 `NUM` 行，而不是最后 10 行。带有前缀 `+` 则从从第 `NUM` 行开始输出。
- `-c,--bytes=[+]NUM`：输出最后 `NUM` 字节；带有前缀 `+` 则从第 `NUM` 字节开始。
- `-f,--follow`：随着文件的增长追加的数据；适用于日志文件。
- `-q,--silent`：不输出带有文件名的头信息。
- `-v,--verbose`：始终输出带有文件名的头信息。
- `-s,--sleep-interval=N`：使用 `-f` 时，迭代之间睡眠约 `N` 秒（默认值为 1.0）。

### 显示文件的最后 10 行

```bash
tail filename.txt
```

此命令显示 `filename.txt` 的最后 10 行。

### 显示文件的最后 5 行

```bash
tail -n 5 filename.txt
```

此命令显示 `filename.txt` 的最后 5 行。

### 显示文件的最后 20 字节

```bash
tail -c 20 filename.txt
```

此命令显示 `filename.txt` 的最后 20 字节。

### 跟踪文件（实时监控）

```bash
tail -f /var/log/syslog
```

此命令实时监控 `/var/log/syslog` 文件，在添加新行时显示。

### 显示从第 5 行开始的行

```bash
tail -n +5 filename.txt
```

此命令显示从 `filename.txt` 的第 5 行开始到文件结束的内容。

### 以特定睡眠间隔跟踪文件

```bash
tail -f -s 2 /var/log/syslog
```

此命令监控 `/var/log/syslog` 文件，每隔 2 秒检查一次更新。

### 显示多个文件的最后 10 行

```
tail file1.txt file2.txt
```

此命令显示 `file1.txt` 和 `file2.txt` 的最后 10 行，并带有指示这些行所属哪个文件的表头。

### 总结

`tail` 命令是一个强大的实用，用于显示文件的末尾，对于实时监控日志文件特别有用。它支持各种选项来定制输出，包括行数或字节数、实时更新以及指定文件内起始点的能力。最常见的用例包括调试、日志文件监控和快速检查文件内容。

`uname [OPTION]...`

- `-m` 或 `--machine`：打印机器硬件名称。
- `-p` 或 `--processor`：打印处理器类型或 "unknown"。
- `-i` 或 `--hardware-platform`：打印硬件平台或 "unknown"。
- `-o` 或 `--operating-system`：打印操作系统。

### 显示内核名称

uname -s

输出可能为：

```
Linux

### 显示网络节点主机名

uname -n

uname -r

5.11.0-37-generic

uname -v

输出可能为：

```
41~20.04.2-Ubuntu SMP Fri Sep 24 09:06:38 UTC 2021

### 显示机器硬件名称

```bash
uname -m
```

输出可能为：

```
x86_64
```

### 显示处理器类型

```bash
uname -p
```

输出可能为：

```
x86_64

### 显示硬件平台

uname -i
```

输出可能为：

x86_64

### 显示操作系统

uname -o
```

输出可能为：

```
GNU/Linux
```

uname -a
```

输出可能为：

### 总结

`uname` 命令是 Linux 中一个简单但强大的工具，提供基本的系统信息。它对于获取内核和操作系统的详细信息特别有用，这对于故障排除、系统监控和配置任务很有帮助。`uname -a` 命令提供了可用信息的全面总结，是获取系统状态快照的快捷方法。

## `top` 命令

Linux 中的 `top` 命令是监控系统性能的强大工具。它提供了系统任务的动态实时视图，显示当前运行的进程及其资源使用情况。

用途：实时监控系统性能和资源使用。

关键特性：

- 显示关于 CPU 和内存使用的信息。
- 列出运行中的进程及其资源消耗。
- 允许用户交互以对显示的信息进行排序和过滤。

### 基本用法

要启动 `top` 命令，只需输入：

```bash
top
```

这将打开默认的 `top` 界面。显示分为两个主要部分：

1. 系统摘要：显示整体系统性能指标。
2. 进程列表：显示关于每个运行进程的详细信息。

### 关键区域和字段

在屏幕顶部，你将看到几行系统摘要信息：

- `uptime`：第一行显示当前时间、系统运行时间、登录用户数和平均负载。
- `tasks`：显示任务总数，以及运行中、睡眠中、停止和僵尸任务的数量。
- `CPU(s)`：显示 CPU 使用率百分比，分为用户、系统、nice、空闲、等待、硬件中断、软件中断和窃取时间。
- `Mem`：显示总内存、已用内存、空闲内存、缓冲区和缓存内存。
- `Swap`：显示总交换内存、已用交换内存和空闲。

### 进程列表

在系统摘要下方，你将看到进程列表，每个进程都有几列：

- `PID`：进程 ID。
- `USER`：拥有该进程的用户。
- `PR`：进程的优先级。
- `NI`：进程的 nice 值。
- `VIRT`：进程使用的虚拟内存。
- `RES`：进程使用的驻留内存。
- `SHR`：进程使用的共享内存。
- `S`：进程状态。
- `%CPU`：CPU 使用率百分比。
- `%MEM`：内存使用率百分比。
- `TIME+`：进程使用的总 CPU 时间。
- `COMMAND`：启动进程的命令。

### 交互命令

在 `top` 运行时，你可以使用各种键盘命令与其进行交互：

- `h`：显示帮助。
- `k`：杀死进程。
- `r`：调整进程优先级。
- `u`：按特定用户过滤进程。
- `P`：按 CPU 使用率排序。
- `M`：按内存使用率排序。
- `N`：按进程 ID 排序。
- `T`：按时间排序。
- `q`：退出 `top`

### 基本用法

```bash
top
```

此命令将打开 `top` 界面，显示系统性能和运行进程的实时视图。

### 按内存使用率排序

在 `top` 运行时，按 `M` 按内存使用率对进程排序。

### 按用户过滤

在 `top` 运行时，按 `u`，然后输入用户名按用户过滤进程。

### 杀死进程

按 `k`，然后输入你想杀死的进程 PID。

### 调整进程优先级

按 `r`，然后输入你想调整优先级的进程 PID，接着输入新的 nice 值。

这里是 `top` 界面的示例：

```
top - 15:22:10 up 1 day, 2:14, load average: 0.00, 0.00, 0.00
Tasks: 105 total, 2 running, 103 sleeping, 0 stopped, 0 zombie
%Cpu(s): 0.3 us, 0.2 sy, 0.0 ni, 99.5 id, 0.0 wa, 0.0 hi, 0.0 si, 0.0 st
KiB Mem: 2048576 total, 610196 free, 133838 used, 38874 buff, 61126 cached
KiB Swap: 2047996 total, 204796 free, 0 used
PID USER PR NI VIRT RES S %CPU %MEM TIME+ COMMAND
234 root 20 0 16272 1644 S 0.3 0.1 0:00.05 ssh
5678 user 20 0 155672 2352 S 0.0 0.1 0:01.10 bash
```

### 总结

`top` 命令是 Linux 中一个重要的工具，提供基本的系统信息。它的交互功能允许对系统进程进行灵活的监控。

## `du`（磁盘使用）命令

Linux 中的 `du` 命令用于估算文件空间占用。它可以各种格式显示文件和目录的大小，对于理解磁盘空间的使用情况很有用。

### 基本用法

```bash
du [OPTIONS] [FILE/DIRECTORY]
```

### 常用选项

- `-a` 或 `--all`：显示所有文件的大小，而不只是目录。
- `-h` 或 `--human-readable`：以人类可读的格式打印。
- `-s` 或 `--summarize`：仅显示每个参数的总计。
- `-c` 或 `--total`：生成一个总计。
- `-dN` 或 `--max-depth=N`：显示命令行参数下方 N 层以内的目录总量。

### 基本用法

```bash
du
```

这将显示当前目录及其所有子目录的磁盘使用情况。

### 人类可读格式

```bash
du -h
```

这将以人类可读的格式显示大小，便于理解每个目录的大小。

### 汇总目录的磁盘使用

```bash
du -s /path/to/directory
```

这将显示指定目录的总磁盘使用情况。

### 包含所有文件

```bash
du -ah
```

这将以人类可读的格式显示所有文件和目录的磁盘占用情况。

### 限制深度

```bash
du -h --max-depth=1
```

这将显示从当前目录开始的一级目录的磁盘占用情况。

### 总磁盘使用量

```bash
du -ch /path/to/directory
```

这将显示每个目录和文件的磁盘占用情况，并在最后包含一个总计。

### 总结

`du` 命令是分析 Linux 系统上磁盘使用情况的强大工具。它提供了关于文件和目录如何使用磁盘空间的详细信息，允许用户识别可能占用过多空间的大文件和大目录。通过使用各种选项，用户可以自定义输出，以人类可读的格式显示磁盘使用情况，包括单个文件、汇总总量以及限制目录遍历的深度。

## `df` 命令（磁盘文件系统）

Linux 中的 `df` 命令代表 "disk filesystem"磁盘文件系统），用于显示计算机文件系统上的可用磁盘空间量。它提供了有关每个挂载系统的总空间、已用空间、可用空间以及使用百分比的信息。

### 基础语法

```bash
df [OPTION]... [FILE]...
```

### 常用选项

- `-h` 或 `--human-readable`：以人类可读的格式显示大小。
- `-a` 或 `--all`：大小为 0 块的文件系统。
- `-T` 或 `--print-type`：显示文件系统类型。
- `-i` 或 `--inodes`：显示 inode 信息而不是块使用情况。
- `--total`：在最后产生总计。
- `--output`：允许指定输出中包含的列。

### 基础用法

```bash
df
```

此命令将显示所有挂载系统的基本磁盘空间使用情况。

### 人类可读格式

```bash
df -h
```

输出：

```
Filesystem Size Used Avail Use% Mounted on
/dev/sda1 50G 20G 30G 40% /
tmpfs 3.9G 2.1M 3.9G 1% /run
/dev/sda2 100G 60G 40G 60% /home
```

`h` 选项通过将字节转换为 KB、MB、GB 等，使输出更易读。

### 包含所有文件系统

```bash
df -a
```

这包含了所有文件系统，即使是大小为 0 块的。

### 显示文件系统类型

```bash
df -T
```

输出：

| Filesystem | Type | 1K-blocks | Used | Available | Use% | Mounted on |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| /dev/sda1 | ext4 | 52403200 | 20971520 | 31431680 | 40% | / |
| tmpfs | tmpfs | 4096000 | 2048 | 4093952 | 1% | /run |
| /dev/sda2 | ext4 | 104857600 | 629144560 | 41943040 | 60% | /home |

### INODES 信息

```bash
df -i
```

输出：

| Filesystem | Inodes | IUUsed | IFree | IUUse | Mounted on |
| :--- | :--- | :--- | :--- | :--- | :--- |
| /dev/sda1 | 3276800 | 20480 | 3256320 | 1% | / |
| tmpfs | 524288 | 10 | 524278 | 1% | /run |
| /dev/sda2 | 6553600 | 102400 | 6451200 | 2% | /home |

这显示 inode 使用情况而不是块使用情况。

### 大总计

```bash
df --total
```

输出：

```
Filesystem 1K-blocks Used Available Use% Mounted on
/dev/sda1 52403200 20971520 31431680 40% /
tmpfs 4096000 2048 4093952 1% /run
/dev/sda2 104857600 62914560 41943040 60% /home
total 161920800 83888128 78032672 52%
```

### 指定列

```bash
df --output=source,fstype,size,used,avail,percent,target
```

输出：

```
Filesystem Type Size Avail Use% Mounted on
/dev/sda1 ext4 50G 20G 30G 40% /
tmpfs tmpfs 3.9G 2.1M 3.9G 1% /run
/dev/sda2 ext4 100G 60G 40G 60% /home
```

### 总结

`df` 命令是监控系统磁盘空间使用情况的有用工具。它提供了各种选项以不同的格式显示信息，例如人类可读的大小、inode 使用情况、文件系统类型等。通过使用适当的选项，你可以获得磁盘使用的视图，从而更有效地管理你的文件系统。

## `FREE` 命令

### 语法

```bash
free [options]
```

### 常用选项
