
Bash 包含了多项特性，使其成为初学者和专家眼中非常优秀的 shell。其中许多特性与 `csh`、`tcsh` 和 `ksh` 相似，这降低了在它们之间切换的难度。

- Bash 的命令行编辑功能与 `tcsh` 和 `ksh` 类似。光标可以移动到命令行的任何位置，允许对命令进行编辑。编辑控制可以设置为 `vi`、`emacs` 或用户定义的模式。

- Bash 还具有历史回溯和编辑功能。回溯的命令可以被编辑和执行。Bash 可以将一个会话的历史保存供其他会话，，多行命令（如循环或函数）。Bash 还具有几个变量，可以自定义历史保存和回溯的行为。

- Bash 具有补全部分输入单词的能力。变量名、用户名、主机名、命令和文件名都可以进行补全。

- Bash 内置 `cd` 命令可以修正路径中的简单拼写错误。

- Bash 支持函数和别名。别名对于简单任务非常有用，例如为命令创建替代名称。函数具有更扩展的能力，适用于更复杂的任务。

- Bash 还实现了 `disown` 命令，允许后台作业在父进程退出后仍继续运行。

- Bash 2.0 支持无限大小的数组。

Bash 允许二到六十四进制算术运算，并支持大多数 C 算术运算符。Bash 在命令行上内置的数值评估和替换功能允许将算术表达式作为命令执行。

Bash 提供了特殊的字符序列来自定义提示符。Bash 允许在提示符中使用其他 shell 构建。

## 定义

以下术语在 `BASH(1)` 手页中有定义，并在本文中具有相同的含义：

| 术语 | 描述 |

|---|---|

| blank | 空格或制表符。 |

| word | 被 shell 视为单个单元的字符序列。也称为标记（token）。 |

| name | 仅由字母、数字和下划线组成的单词，以字母、数字或下划线开头。也称为标识符（identifier）。 |

| metacharacter | 在未加引号时分隔单词的字符。以下符号之一：`&` `(` `)` `<` `>` 空格 `tab` |

| control operator | 执行控制函数的标记。它是以下符号之一：`|` `&` `;` `;;` `(` `)` `<换行>` |

## 安装 Bash

Bash 存在于许多系统中，但如果你必须安装 bash，下节将介绍安装步骤。

### 要求

构建/安装 bash 需要以下应用程序：

- `gunzip`: 用于解压存档
- `tar`: 用于解压 tar 包
- `ar`: 用于构建 bash 使用的库
- `gcc` 或 `cc`: 用于构建 bash
- `make`: 用于控制编译过程

要确保这些程序可用，请使用 `whereis` 命令。

### 步骤

一旦获得 `bash-2.0.tar.gz` 文件，请按照以下步骤构建 bash：

1. 进入包含 g-zipped tar 包 `bash-2.0.tar.gz` 的目录。

2. 解压文件：

```bash
gunzip bash-2.0.tar.gz
```

文件 `bash-2.0.tar.gz` 将被文件 `bash-2.0.tar` 替换。要查看 `gunzip` 的作用，请加上 `-v` 选项。

3. 从 `bash-2.0.tar` 中提取源文件：

```bash
tar -xvf bash-2.0.tar
```

这会创建 `bash-2.0` 目录并将源文件放入该目录。

4. 进入包含源文件的目录：

```bash
cd bash-2.0
```

5. 为你的机器配置源码树：

```bash
./configure
```

shell 脚本 `configure` 尝试为编译期间使用的系统相关变量估算正确值，并创建相应的 Makefile 以及以下文件：

- `config.h`：包含系统相关性定义的文件
- `config.status`：一个重新创建当前配置的 shell 脚本
- `config.cache`：保存测试结果的文件，以加速重新配置
- `config.log`：包含编译器输出的文件

配置可以自定义，但默认配置通常对于大多数安装来说已经足够了。`configure` 具有一个帮助选项，详细列出了其他配置选项：

```bash
./configure --help
```

一个实用的配置选项指定了 bash 应该安装在哪个目录，而不是默认位置 `/usr/local`：

```bash
./configure --prefix=[directory]
```

在较旧版本的 System V 上，如果从 `csh` 执行 `configure`，`csh` 可能会尝试将 `configure` 作为 `csh` 脚本执行。为了避免这种情况，请使用：

```bash
sh ./configure
```

配置过程可能需要一些时间，在 Sun Sparc10 上大约需要 15 分钟，在 Sun Ultra 上大约 10 分钟。

6. 构建 bash：

```bash
make
```

默认情况下，`make` 将使用 `gcc`，即使已经安装并可以运行 `cc`。要使用 `cc`：

```bash
make CC="cc"
```

`make` 也需要很长时间，在 Sun Sparc10 上大约 20 到 25 分钟，在 Sun Ultra 上大约 15 到 20 分钟。

7. 测试构建（可选但建议）：

```bash
make tests
```

这将编译并运行源代码附带的测试，以确认 bash 工作正常。如果检测到任何问题，可能需要重新构建 bash。测试完成后，可能需要重新构建 bash。

8. 剥离执行文件以调试符号（可选但建议）：

```bash
strip bash
```

要查看 `strip` 对文件大小的影响：

```bash
strip bash
```

9. 安装 bash：

```bash
make install
```

要查看安装将执行的操作而不实际执行：

```bash
make -n install
```

将 bash 安装到配置位置的其他地方：

```bash
make install prefix=[directory]
```

## 调用

Bash 可以以不同的模式调用。两种主要模式是交互式和非交互式。

### 交互式 shell

交互式 shell 是标准输入输出连接到终端的 shell。三种主要的交互式 shell 类型是登录、非登录和限制。

Bash 通过 `istty` 调用来确定 shell 是否为交互式。在初始化文件和脚本中，可以使用 `test -s` 或 `-t` 判断交互式，如果输入是 tty 则返回（真）。交互式 shell 会设置 `PS1`，测试其是否存在另一种方法。

当 bash 作为登录 shell 调用时，它尝试读取多个初始化文件并报告遇到的任何错误。如果初始化文件不存在，将使用默认环境。首先，bash 读取并执行 `/etc/profile`。然后从 `~/.bash_profile`、`~/.bashlogin` 和 `~/.profile` 中读取第一个存在的。Bash 可以给出 `nfile` 选项以防止读取初始化文件。当登录 shell 退出时，它会读取 `~/.bash_logout`；bash 将读取并执行命令。

当非交互式 shell 启动时，bash 使用 `--rcfile` 选项从不同的初始化文件读取并执行命令。可以通过 `--norc` 选项防止读取任何初始化文件。

如果给出 `--posix` 选项，Bash 将以 posix 模式启动。bash 首先检查 `$ENV` 是否设置。如果是，bash 将 `$ENV` 扩展为文件名并读取并执行该文件。Bash 在 posix 模式下不会读取任何其他启动文件。在这种模式下，bash 的行为会发生微调以符合 POSIX 标准。

在某些 bash 名为 `sh` 的系统中（例如 Linux）。在这种情况下，bash 会像 `sh` 一样启动然后进入 posix 模式。profile 读取并执行 `/etc/profile`。`noprofile` 选项将防止读取这些初始化文件。如果非登录 bash 作为 `sh` 调用，其启动行为与 posix 模式相同。

最后感兴趣的交互式模式是限制模式。Bash 可以通过使用 `-r` 选项或以限制模式启动。

调用它或 bash。在受限模式下，bash 的行为与正常一致，但不允许某些操作，例如更改目录、修改 `$SHELL`、运行 `exec`、运行包含 `/` 的命令以及使用重定向。bash 1.x 中不提供受限模式。

### 非交互式 Shell

非交互式 shell 主要用于运行 shell 脚本。当 bash 使用 `-c` 选项被调用时，也会运行非交互式 shell。当启动非交互式 shell 时，bash 会检查 `$BASH_ENV`。如果该变量存在，bash 会尝试从变量指定的文件中读取并执行命令。这种行为就像执行了以下命令：

```bash
if [ -n "$BASH_ENV" ]; then "$BASH_ENV"; fi
```

指定的 `$BASH_ENV` 文件名不会在 `$PATH` 中进行搜索。

### 调用选项

如上所述，bash 可以通过多个单字符和多字符选项调用。以下是这些选项及其功能的摘要：

| `-c string` | 此选项导致从字符串运行命令。如果 string 包含多个单词，第一个单词被赋值给 `$0`（即命令），其他单词被赋值给位置参数，即 `$1`、`$2` 等。示例为：`bash -c ls /tmp` |

| `-i` | 此选项允许 bash 在交互模式下运行。 |

| `-r` | |

| `-restricted` | 这些选项允许 bash 在受限模式下运行。这些选项在 bash 1.x 中不可用。 |

| `-login` | 此选项强制 bash 像登录 shell 一样运行。 |

| `-posix` | 此选项强制 bash 符合 POSIX 标准。如果用名称 `sh` 运行 bash，则隐含此选项。 |

| `-verbose` | 此选项强制 bash 在读取所有输入行后回显这些输入行。 |

| `-help` | 此选项导致 bash 打印用法帮助信息。 |

| `-version` | 此选项导致 bash 打印版本信息。在 2.0 或更高版本中，bash 在打印版本信息后将成功退出。在 1.14 及之前的版本中，必须手动退出 bash。 |

| `-noprofile` | 此选项导致交互式登录 bash 跳过读取初始化文件。 |

| `-norc` | 此选项导致交互式非登录 bash 跳过读取 `~/.bashrc` |

| `-rcfile` | 此选项导致交互式非登录 bash 从文件而非 `~/.bashrc` 读取初始化命令 |

## 将 Bash 用作登录 Shell

更改登录 shell 最常见的方法是使用 shell 命令 `chsh`。在某些没有 `chsh` 的系统上，可以使用 `password -s` 或 `password -e` 来更改 shell。在其他系统上，必须使用 `chch`（此处）来更改 shell。在许多系统（例如 SunOS 5.5.x）上，必须在 `/etc/shells` 中包含 bash 可执行文件的全路径，然后才能将其指定为有效的登录 shell。

如果无法更改默认登录 shell，可以通过修改默认 shell 的初始化文件来更改 bash。如果默认登录 shell 是 `csh` 或 `tcsh` 且 bash 位于 `/usr/local/bin/bash`，在 `~/.login` 中添加如下内容可以允许 bash 作为登录 shell 执行：

```bash
if ( -f /usr/local/bin/bash ) exec /usr/local/bin/bash --login
```

在 `~/.login` 文件中调用 bash 更好，因为它只在登录时读取，而 `~/.cshrc` 文件在每次启动 `csh` 时都会读取。在 `~/.cshrc` 中执行 bash 可能会在 `csh` 脚本尝试运行时导致问题。在 `~/.cshrc` 文件中调用 bash 的最佳方法是在 `csh` 为交互模式运行时执行：

```bash
if ($?prompt) exec /usr/local/bin/bash --login
```

如果登录 shell 是 `sh` 或 `ksh`，则必须完成两件事。首先，在 `~/.profile` 中必须添加类似下面的行：

```bash
[ -f /usr/local/bin/bash ] && exec /usr/local/bin/bash --login
```

必须创建一个空的 `~/.bash_profile` 文件，以防止执行的 bash 尝试运行 `~/.profile` 并导致重新执行自身。或者，可以在 `~/.profile` 中添加以下内容：

```bash
case "$0" in
  *bash)
    echo "Bash already running"
  *)
    [ -f /usr/local/bin/bash ] && exec /usr/local/bin/bash --login
  ;;
esac
```

如果你在 `~/.profile` 中使用了 `case` 语句，则不需要创建空的 `~/.bash_profile`。

## 语法

Bash 支持类似于 `sh` 和 `bin/bash` 的语法。

## 变量

Bash 2.0 支持标量变量和数组变量。在 bash 中设置变量，标准的 `sh` 赋值语句是：

```bash
name=value
```

数组变量可以通过两种方式设置。第一种形式设置单个元素：

```bash
name[index]=value
```

第二种形式可以设置多个元素（而非整个数组）：

```bash
name=(value1 value2 value)
```

在这种形式下，使用从 0 开始的连续数组索引。例如

```bash
myarray=(derri terry mike gene)
```

等价于

```bash
myarray[0]=derri
myarray[1]=terry
myarray[2]=mike
myarray[3]=gene
```

在设置多个数组元素时，可以将数组索引放在值之前，因此执行上述赋值的第三种方法是：

```bash
myarray([0]=derri [1]=terry [2]=mike [3]=gene)
```

```
$PATH 命令的搜索路径。它是一个由冒号分隔的目录列表，shell 在这些目录中查找命令。常见值为：

PATH=/bin:sbin:/usr/bin:/usr/local/bin:/usr/ucb

$HOME 当前用户的家目录；cd 内置命令的默认参数。
```

除了这些类型的变量外，bash 还支持两种额外的参数类型：位置参数和特殊参数。这两种参数的值都由 bash 分配，但只有位置参数的值可以更改。

位置参数由从 1 开始的一个或多个数字表示，并可以通过提供参数数字作为变量名来单独访问。如果参数数字包含多个数字，则必须使用括号。例如，第一个参数可以通过 `$1` 访问，而第 11 个元素必须通过 `${11}` 访问。

有几个与位置参数相关的特殊参数：

- `$@` 这将展开为一个单个单词，其中包含所有位置参数的列表，并以 `$IFS` 的第一个字符（通常是空格）分隔。
- `$*` 这个位置将被替换为一系列单词，而不是像 `$@` 那样的单个单词。
- `$#` 这展开为位置参数的数量。

位置参数是调用函数或 shell 脚本时的参数。这意味着 `$1` 的值在函数内部和外部是不同的。

其他特殊参数与命令执行有关，并在“历史变量”部分介绍。

变量和数组都可以使用 `unset` 命令取消设置。

```bash
unset name
unset -v name
```

- 第二种形式中的 `-v` 选项用于指示 `unset name` 是一个 shell 变量。这不是要求的。

## 扩展

当 bash 遇到如下形式的赋值语句时：

```bash
name=value
```

在执行波浪号、变量和字符串扩展后，该值会被赋值给 name。Bash 在赋值之前还会对该值进行命令替换、算术求值和引号去除。

当 `~`（波浪号）是单词的第一个字符时，执行波浪号扩展。在适当的情况下，bash 将波浪号后的字符视为名称，并将家目录替换为波浪号后的字符。如果波浪号本身出现或跟随斜杠（/）和 `$HOME`，bash 将波浪号替换为 `$HOME` 的值。否则，如果给出 `+`，bash 将其替换为当前用户的家目录。如果给出 `-`，它被替换为 `$PWD` 的值（当前目录）。如果给出 `--`，它被替换为 `$OLDPWD` 的值（上一个工作目录）。如果没有任何波浪号扩展起作用，bash 将保持波浪号不变。

当遇到 `$` 时，bash 执行变量扩展。最简单的形式是：

```bash
foo=$bar
foo=${bar}
```

在这里，变量 `$bar` 的值被替换并赋值给变量 `$foo`。在第二种形式中，括号可以自由地显式指示解析器变量名称的结束位置。例如：

```
foo=24
echo $foo
```

打印变量 `$foo` 的值，而

```bash
foo=24
echo ${foo}th
```

打印 24th，即 `$foo` 的值后追加 "th" 后的结果：

变量也可以通过更高级的方式进行替换：

- 如果 `$bar` 未设置或为空，且需要产生错误：

  `${bar?:"Error, no bar"}`

- 如果 `$bar` 未设置或为空，但它需要一个默认值：

  `${bar:="foose"}`

- 如果 `$bar` 未设置或为空，但 `$foo` 需要一个值：

  `foo=${bar:-"foose"}`

- 当 `$bar` 未设置或为空时， `$foo` 需要一个值：

  `foo=${bar:+"foose"}`

bash 还支持变量扩展，可以将一个变量的一部分赋值给另一个变量：

```
foo=${bar:offset:length}
```

offset 是 `$bar` 中的起始位置，length 是要获取的字符数。如果没有指定长度，则返回 offset 之后的所有字符。

当给出如下命令时，执行命令替换：

```bash
$ $(command)
`command`
```

这两种形式都将被替换为命令的输出。除非在双引号环境中，否则命令的每行输出都成为一个独立的单词。在双引号环境中，输出被视为一个带有嵌入换行的单个单词。

当遇到如下形式时，执行算术求值：
