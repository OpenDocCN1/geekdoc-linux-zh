
# 大陆演化

导致大陆形成的过程。如今地球地壳在解剖学上是移动的。洋壳通常约为`4`（`7 km`）厚，在地壳形成的海底洋脊处会厚得多。相比之下，厚度为`22–25 km`（`35–40 km`）的大陆地壳形成于俯冲带，大陆地壳由海平面地壳通过地力支撑。洋壳循环回到地幔中，但大陆地壳浮力较小，寿命约为`40亿年`。因此，大陆平均年龄为`20亿年`，最大年龄为`40亿年`，是地球大部分地区的可观测跨度。由于其古老且地质脆弱，它们结构上比洋壳更复杂。见 地壳；洋脊。

俯冲过程是大陆地壳破坏的原因（见插图）。破坏性过程涉及俯冲和俯冲侵蚀。构造过程和破坏过程可能在俯冲带同时发生。

![](img/b16805e6127c92641547ee45e5728f7f_555_0.png)

俯冲带的大陆地壳循环。箭头显示运动方向。随着时间的推移，由于对流增厚的岩圈，碰撞区可能会发生地壳的选择性破坏。

即使在具有发育良好的增生沉积物的俯冲带，沉积物也会在地幔下方变形。一些留在地幔底部，一些通过熔融转移到弧区。一些逃逸并深陷地幔，构成了地幔中可同位素识别的成分。其余部分在表面侵蚀的补给下，优先破坏上地壳。

地壳岩圈和地幔载体可能会固结在俯冲板中，导致构造剥蚀。与俯冲沉积物不同，地壳沉积物在通过地幔下方时能够熔融，可能还包括地壳岩圈和地幔。

大陆岩圈增厚，寒冷的岩圈地幔被推入更热的地幔。岩圈增厚产生侧向热梯度，驱动地幔对流。增厚的岩圈地幔变得不稳定并最终俯冲。与洋壳沉积物不同，地壳不会被干或湿的大陆熔融所破坏。

## 大陆与地球历史

恒定地壳的年龄约为二十亿年。传统的解释是在俯冲时期之后后期通量，地壳自第一次开始一直在增长，在`20-30亿年前`达到峰值，之后开始下降。然而，另一种解释表明，这种稳定性通过地壳循环速率的长期衰减来解释，可能是由于地幔通量速率降低以及板块构造的影响。在这些解释中，对大陆地壳循环的重要性赋值不同。在生长模型中，很少超过`30亿年`的物质，但地壳已经形成了。在稳态中则存活。稳态解释与同位素数据一致，显示原始地壳保持高度发育，而地幔是异质且存在同位素贫乏区域的。此外，稳态迭代得到了比较板块构造的支持，表明地壳地幔没有丢失，除非在可能观察到的近表面熔融处。见 大裂谷；漂移；地球；时代；对流，进入与断层结构；地幔地质；板块构造；板块。

## 连续波雷达

发射器连续的雷达，与脉冲雷达相反，`CW`雷达的优点之一是能够通过多普勒频移极精确地测量速度。检测到的反射波频率偏移是发射器和接收器之间相对速度的函数。见 多普勒。为了测量目标的距离，必须对输出进行某种形式的频率调制（`FM`）。传输信号的频率以单位速率变化。距离通过比较回波频率与发射频率确定。见 频率调制。

连续波雷达是一种使用单一天线进行接收和传输的雷达，这使得在没有发射器的情况下很难保护目标。此外，发射器和接收器受到高达`200 W`输出功率的保护。对于磁偏振荡器（`YIG`），使用了几种类型，`X`波`CW`雷达中的调谐脉冲级。见 频率记录仪

连续波雷达的应用包括导弹探测；目标探测；地形清除和杂波抑制；激光系统运行；安全；医疗用途；传感器发送和跟踪病人。

连续波雷达可以提供导弹距离引导。通常从地面跟踪导弹并同时对其进行照明。在某些情况下，同一台连续波雷达可以用于照明和跟踪目标。见 脉冲多普勒监测器

`CW`雷达的设计目标包括：

- 形成发射器和输出消除距离模糊
- 分辨距离
- 区分接近和远离的目标
- 消除噪声
- 同时测量距离和速度
- 处理目标杂波
- 提高接收信噪

## 等高线

用于地形测的等海拔线。等高线表示等高面，相邻等高线之间的海拔差为地图的等高线间隔。因此，它们在平面地图上表示地形的形状（等高线密集表示坡度陡；或无等高线表示平缓或平坦）。

### 548 控制图

除非存在重叠，否则控制线互不交叉。参见地形测量与制图。[R.H.Doc]

控制图：一种用于确定过程是否处于统计控制状态的图表技术。在统计控制状态下，由原因引起的变异没有超过根据过程性质和预期用途、基于过程自然变异所预期的范围。

其他图表对无法控制且无法消除的随机因素具有某些敏感性。例如，对于统计测量，随机因素可能会导致估计值的失真；通过对制造设备的选择，导致影响操作速度和趋势的供应波动；以及操作人员表现的变异。过程固有的变异性是各个原因的累计结果，每个原因的影响都很微小。

控制图技术适用于产生连续输出的工艺。控制图的设计目的是检测由于可以纠正的特定原因引起的变异。当识别出特殊原因时，可以容易且经济地将其消除。制造领域可能出现的变异原因示例包括：不合格的原材料、机器故障和操作人员的方法。

控制图是过程随时间变化的二维图表。水平轴代表时间，具有不同的样本量。垂直轴代表样本统计量的值，这可能是平均值、标准差或任何其他变量测量值，或者是不合格单元数、不合格率或每单位不合格零件平均数。

典型的控制图有三条平行线（见插图）：一条中心线和两条控制限。中心线代表稳定状态下（仅有自然变异）的过程水平。中心线上方和下方的线分别表示上控制限（`UCL`）和下控制限（`LCL`）。它们规定了样本统计量的范围。控制限限制了垂直轴，使得当只存在过程的自然变异时，样本点落在控制限之外并导致误报的概率将是非常昂昂的。通常，控制限位于中心线两侧三个标准差处。这导致了误报的概率为 `0.0027`。

控制图的工作原理简单，由五个通用步骤组成：

1. 定期从过程中抽取样本。
2. 对单元的观测值进行统计量计算；在统计测量中，根据观测值计算数学函数。
3. 将统计量的值随时间绘制成图表；任何落在控制限之外或任何随机模式都表明过程发生了变化，无论是其设定还是变异。
4. 如果检测到变化，停止过程并进行调查以确定变化的原因。
5. 一旦确定了原因并采取了任何必要的措施，过程即可恢复。

控制图的主要优点是提供了一种视觉手段，用于识别过程水平或变异何时因异常发生变化，从而不再处于统计控制状态。指示失控状态的视觉模式或需要关注的点集被称为离群值、点链（runs）、趋势、循环和混合物。控制系统；价值评定 [T.R.A]。

## 控制系统

形成系统的连接将提供所需的系统响应时间。汽车的转向是一个熟悉的例子。驾驶员观察汽车的位置，并通过转动方向盘进行调整。汽车随方向改变响应，驾驶员试图减小预期路径与实际路径之间的误差。在这种情况下，控制输出是转向，反馈是驾驶员，路面是控制器。工程师的目标是设计一种对于任务有效的控制机制。不同的控制系统和设计结果会导致不同的速度，例如汽车的速度相对较慢。

许多控制系统受到外部干扰的影响，导致系统提供不准确的输出。反馈系统的益处在于，尽管受到输入、噪声和意外干扰的影响，但可以有效地减少这些影响。

**反馈的成本。** 在上述列出的控制系统优点增加反馈之外，这些优点伴随成本是自然的。反馈的成本首先体现在组件数量的增加。反馈的成本第二体现在实施的复杂性。反馈的成本第三体现在潜在的不稳定性。最后，反馈的成本第四体现在组件成本的增加。反馈的成本第五体现在设计成本的增加。反馈的成本第六体现在测试成本的增加。反馈的成本第七体现在维护成本的增加。反馈的成本第八体现在控制系统具有闭环配置。例如，闭环系统具有一个恒温器来维持所需的温度并减小误差，以及一个用于速度的电机。在其他情况下，用于家庭、锅炉等许多地方。

## 550 受控整流器

通过转换器从模拟转换为数字形式。数字转换器处理输入，并提供数字形式的输出，然后由数字转模拟转换器进行处理。参见模拟-数字转换器；数字转模拟转换器。

工业自动处理用于危险、重复或简单的任务。自动运行的机器负责装卸货物，或为了获得精度、安全性和可靠性而使用。集成机器人是可编程的。它们经常在重复任务中代替人工。某些设备甚至具有拟人机制，高级任务可能需要这种机制。机器人广泛应用于空间和装配。它们灵活且准确。参见机器人学。[R.C.]

受控整流器 一种具有四个交替导电类型 `p-n-pn` 区域的三端半导体结，也称为晶闸闸管。这种开关具有特征器件发射极电压，在受控整流器保持控制之前，它会产生很小的压降。此类设备用作高电流开关，可用于微波和继电器。
