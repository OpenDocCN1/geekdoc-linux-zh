# 第 4 章：虚拟进程内存

## 4.10 页异常的处理

虚拟内存与物理内存之间的关联直到实际需要数据时才会建立。如果进程访问内存的一部分，内核会自动触发页异常。这是最重要且复杂的方面之一，因为内核必须确定：

- 页异常是由访问用户空间的有效地址引起的吗？
- 是否存在映射？
- 应该使用哪种机制来获取数据？
