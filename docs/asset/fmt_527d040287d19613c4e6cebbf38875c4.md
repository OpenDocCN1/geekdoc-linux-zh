“处理器和特性”（`Processor and Features`）区域还包含与 `CPU` 类型及相关选项相关的内核设置。其他选项包括：

### SMP 支持

对称多处理 (`SMP`) 指的是带有多个 `CPU` 的计算机。内核需要特殊支持才能利用每台计算机上的多个 `CPU`。

### APIC 支持

高级可编程中断控制器 (`APIC`) 是内置在某些 `CPU` 中的中断控制器，而不是内置在主板芯片组中。如果你的 `CPU` 支持此功能，请启用此选项。

### 机器检查异常

主板和 `CPU` 越来越多地支持硬件问题检测电路。此选项增加了对某些工具的支持，例如检测处理器何时过热的温度传感器。

#### 获取最佳视频性能

**`CPU` 频率缩放**：某些 `CPU` 支持“动态”更改其时钟频率，这对于节省笔记本电脑的电池寿命有用。选择此选项（在“电源管理选项”区域）以添加对该功能的支持。更多信息请查看 `http://www.brodo.de/cpufreq/`。

**笔记本支持**：某些笔记本电脑提供软件“钩子”（`hooks`），以便操作系统检查 `CPU` 的状态和电源管理。你可以将这些钩子编译进内核。

**设备接口**：`/dev/cpu` 目录下的某些文件提供了对 `CPU` 的访问，但前提是你在内核中启用了相应的支持。

**高内存支持**：高内存支持有三个设置：`Off` 支持内存小于 `1GB` 的机器；`RAM` 支持高达 `4GB` 的内存；`64GB` 支持超过 `4GB` 的内存。

**数学求值**：`1386`、某些 `1486` 以及某些早期的 `Pentium` `CPU` 缺少浮点单元 (`FPU`)，也称为数学协处理器。Linux 软件依赖于 `FPU` 的存在，因此当系统中不存在 `FPU` 时，内核会包含它来模拟一个。只有当你的 `CPU` 非常老，或者你在主板上添加了独立的 `FPU` 芯片时，你才需要包含它。

**`MTRR` 支持**：英特尔 `Pentium Pro` 及后续的 `CPU` 提供了内存类型范围寄存器 (`MTRR`) 功能，它改进了对 `CPU` 与设备之间共享内存访问的支持。这种配置在集成视频硬件主板的笔记本电脑和其他电脑上最常见。要启用此支持，你必须将相应的端口编译进内核。

注意：如果你正在使用 `2.4` 或更早版本的内核，配置工具看起来与图 1.1 显示的不同，但它提供了许多相同的选项。

内核配置本身是一个非常重要的课题。第 15 章“创建自定义内核”更详细地描述了这一过程。

## 获取最佳视频性能

用户通过键盘、鼠标和显示器与工作站交互。显示器反过来由计算机的显卡控制。如今，如 `X` 窗口系统（简称 `X`）等 `GUI` 环境的使用在工作站上已无处不在。此类环境要求显卡能够显示高分辨率（通常为 `1024 x 768` 或更高）、高位深（`16` 位或更高）的图形。`X` 显示这些内容以创建窗口及所有修饰。所有主流显卡都能满足这一最低要求。更关键的意义在于区分硬件，因此，还包括显卡超出这些最低要求的程度，以及显卡显示文本和图形的速度。这些衡量标准受显卡硬件和其 `X` 驱动程序的共同影响。

### 重要和不重要的显卡功能

走进电脑店或办公用品店，你可能会看到架子上摆着售价 `100` 美元或以上的显卡。然而，这样的支出能买到什么呢？真的有必要吗？高端显卡上常见的特性包括：

**快速视频总线**：如今出售的大多数显卡使用加速图形端口 (`AGP`) 总线。该总线专为高速显卡设计，主板也包含用于显卡的 `AGP` 总线。旧的显卡使用专用插槽部件 (`PCI`) 总线，该总线仍被大多数非视频插件使用；或者甚至是更慢的总线，如工业标准架构 (`ISA`) 总线。

**多输出**：某些高端显卡支持多个输出——例如，同时处理显示器和电视。此功能在某些情况下很有用，但大多数 Linux 用户并不需要。

**`2D` 加速**：显卡使用板载内存存储屏幕的位图。`X` 可以多或少直接地修改此窗口，因此；这会消耗 `CPU` 时间和视频总线的带宽。一种更快的方法是在显板上包含足够的智能性，以响应来自 `X` 服务器的命令绘制特定形状。这种特性被称为 `2D` 加速，它存在于所有现代显卡中。

**`3D` 加速**：过去几年显卡设计中改进最大的领域是 `3D`。

**大量内存**：由于显卡内存越多，显示性能越好，这种特性是常见的。如表 1.2 所示，显卡需要这种数量的内存。

# 优化系统架构用法

许多显卡都支持多种模式。然而，并非所有驱动程序都支持 `2D` 加速——即使这些功能在硬件上是可用的。通常情况下，对于比最新型号至少一代的卡，支持效果最好；这种时间差让 `XFree86` 开发者能够在其驱动程序中实现加速。详情请参阅你所使用的 `XFree86` 版本的发布说明。

显卡制造商：某些显卡制造商现在允许为显卡提供 `X` 驱动。这些驱动可能在官方 `XFree86` 驱动支持之前就支持加速，因此如果你发现某个显卡在 Linux 或 `X` 环境下性能不佳，最好向你的显卡制造商确认。

`Mesa`：`Mesa` 项目在 `X` 环境下提供 `3D` 加速。`Mesa 3D` 加速驱动程序适用于小部分具有 `2D` 加速驱动的显卡。在这种情况下，在购买用于 `3D` `Mesa` 应用程序的显卡之前，检查是否有这些驱动程序至关重要。

# 加快 X：设置 XFree86 选项

第 16 节“优化 X 配置”描述了如何设置 `X` 以最大化利用显卡的性能。它还包含了性能提示，例如关于改进 `X` 环境下字体外观的信息。不过，目前有几条经验法则可以让你让 `X` 运行得尚算良好：

尝试多个服务器：`XFree86` 在 `3.x` 和 `4.x` 版本之间发生了重大变化；在 `3.x` 版本中，驱动程序与 `X` 服务器集成——这些程序是调解显示器与单个程序之间交互的媒介。因此，对于 `ATI` 板，你会运行一个 `X` 服务器，而对于 `Matrox` 板则运行另一个。从 `XFree86 4.0` 开始，开发了一个单一的 `X` 服务器，用于加载特定硬件的驱动程序。但这种变化意味着许多旧的 `XFree86 3.x` 驱动代码必须重写。截至 `XFree86 4.2` 为止，并不是所有的 `4.x` 驱动程序都符合旧 `3.x` 代码的标准。因此，如果你的显卡在 `XFree86 4.x` 之前出现问题，你可能想要尝试 `3.3.6` `X` 服务器。

研究驱动选项：`XFree86AuthConfig`（通常安装在 `/etc` 或 `/etc/X11`）控制 `XFree86`，包括指向显卡驱动的选项。其中某些驱动程序会影响性能，你可能想要研究它们。

低色深：`X` 可以运行在 `1` 位显示器上，但最好至少使用 `16` 位以从大多数程序获得合理的色彩真度。超过此值后，对于许多用途来说改进有限。然而，更高的色深会增加操作显示的工作量，从而降低性能。降低色深（通过设置 `XFree86AuthConfig` 文件 `Screen` 部分中的 `Defaultdepth` 选项）可能会提高你的性能。

# 通过驱动程序控制硬件

所有操作系统（`OS`）都使用驱动程序来连接硬件和软件。驱动程序使操作系统能够为硬件用户程序提供一致的软件接口，从而与直接访问方法相比，简化了应用程序的设计。通过要求用户程序通过操作系统访问硬件，驱动程序还帮助防止多个程序相互干扰硬件设备。遗憾的是，现代计算机可用的硬件极其丰富，特别是在 `IA-32` 世界，这意味着需要大量的驱动程序。这种转变有时会导致问题——有时很难识别和安装驱动程序。幸运的是，稍微了解 Linux 驱动的情况会有极大帮助。

注意：本节及其子节描述了 Linux 内核的一部分的驱动程序。其他一些设备——最显著的是显卡、鼠标和扫描仪——需要在用户空间程序（如 `XFree86`、`Ghostscript` 或 `Access Next Any (SANE)`）中驱动支持。这些驱动程序将在书中子节中详细介绍，包括第 3 节“使用外部外设”、第 13 节“管理打印机”和第 16 节“优化 X 配置”。

# 识别正确的驱动程序

安装驱动程序时必须克服的第一障碍是识别要使用的正确驱动程序。现代 Linux 发行版在安装时会识别你的硬件，但有时会遗漏或误判组件。当你添加新设备或替换内核时，也可能需要知道使用什么。驱动程序实际上有两个步骤：

- 识别硬件
- 识别匹配硬件的驱动程序

# 识别硬件

芯片组是一组提供设备核心功能的多个芯片。通常，制造商从另一公司购买芯片组，将芯片安装到电路板上，并以自己的名称销售产品。由于不同制造商的设备使用相同的芯片组，大多数 Linux 驱动程序需要相同的驱动代码，而不是特定的设备制造商。某些制造商开发自己的芯片组并据此设置板。你可以使用几种不同的策略来识别硬件的芯片组：

文档：如果你足够幸运，设备的文档将识别出它所使用的芯片组。这些文档可能是纸质手册、驱动程序磁盘上的 `README` 文件或网页。你可能还会从制造商提供的其他操作系统驱动程序的配置文件中获取信息。某些制造商为其产品提供 Linux 驱动程序。这些驱动程序通常只是重命名后的标准 Linux 驱动。如果你的制造商提供了此类驱动程序，请在 Linux 内核源码中寻找类似的驱动程序。

视觉检查：你通常可以通过肉眼观察来了解设备。找到最大的芯片并注意它们上的任何标记。例如，图 1.2 显示了 `Ultra100 ATA` 控制器卡上的大芯片。该芯片标记为 `Promise PDC2026`。有时，芯片上覆盖有带有板制造商名称的纸贴。这些贴纸可以安全地撕掉；这样做可能会损坏芯片使其无法正常工作。

`![图 1.2](img/52af56b4699677fa15da240f44_0.png)` 当 Linux 启动时，它会尝试通过多种方式识别这些设备。一种是使用 `dmesg` 命令，它显示启动消息。此命令通常会产生大量输出，因此通过管道传递给 `grep` 也是个好主意。你还可以使用 `/proc` 文件系统，将在随后的章节中详细介绍。“解析 `/proc` 文件系统” `./proc` 的 `GUI` 接口，如 `Mandrake` 自带的 `hardrake` 工具（如图 1.3 所示）或大多数发行版的类似工具，也有帮助。遗憾的是，如果你在激活设备时遇到问题，这些方法并不理想，但如果你想记录这些信息以备后用，它们可能有用。

## 硬件与驱动匹配

识别出芯片组后，你需要将该芯片组匹配相应的 Linux 驱动程序。如果你正在重新编译内核，则需要阅读相关类别中的各种设备，直到找到匹配项。即使你没有安装新内核，这种方法也是很有用的。在内核配置工具中找到你的设备，并记下它在该工具中的名称。你的驱动程序可能类似于这样的内容。
