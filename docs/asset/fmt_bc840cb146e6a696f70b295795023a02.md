## 代码示例 2

```php
// 通知用户其已成功登录或注销。
function inform_auth()
{
    global $login;
    global $logout;
    global $login_success;
    global $uc_user_first_name;
    If ($Login) {
        If ($login_success) {
            Print "<H3>登录成功！欢迎，$uc_user_first_name!</H3><HR><BR>";
        } Else {
            Print "<H3>登录失败!</H3>";
            Print "禁止未经授权的访问，将将追究。请",";
            Print " <a href=\$PHP_SELF?create_account=1>";
            Print "创建一个账户</a>如果您已经有了有效的账户，";
            Print "请重试。<BR><HR><BR>";
        }
    endif;
    If ($logout) {
        // 除非出现数据库问题，否则注销总是成功的。
        // 从用户的电脑中删除 cookie 可能有用。
        Print "<H3>注销成功！请继续浏览。</H3><HR><BR>";
    }
    endif;
}
```
