```
extracting: dir/file1

```

### 引言

在本实验室中，我们将重点关注通过特定工具将信息从一个源重定向或传输到另一个源。Linux 命令行通过特定的标准通道重定向信息。命令的标准输入（`stdin` 或通道 0）被认为是键盘，标准输出（`stdout` 或通道 1）被认为是屏幕。另一个用于重定向命令的错误输出（`stderr` 或通道 2）或程序错误消息的通道。输入和/或输出可以被重定向。

在运行命令时，有时我们需要向命令传输某些信息，或将输出重定向到特定文件。这些功能都将在接下来的两个节中进行讨论。

### I/O 重定向

I/O 重定向允许用户使用文本文件将信息重定向到或来自命令。正如之前所述，标准输入、输出和错误输出都可以被重定向，并且可以从文本文件中获取信息。

## 重定向标准输出

要将标准输出重定向到文件而不是屏幕，我们需要使用 `>` 运算符，后跟文件名。如果文件不存在，将创建一个新文件；否则信息将覆盖现有文件。

为了查看我们创建的文件的内容，我们可以使用 `cat` 命令。默认情况下，该命令在屏幕上显示文件内容。请查看手册页以了解其功能。

下面的示例演示了该运算符的功能。在第一次实例化，创建了一个包含“Hello World!”文本的新文件。

```
$ echo "Hello World!" > text
$ cat text
Hello World!
```

在第二次调用中，同一个文件被新文本覆盖：

```
$ echo "Hello!" > text
$ cat text
Hello!
```

如果想想在文件末尾添加新信息，我们需要使用 `>>` 运算符。如果该运算符找不到现有文件，它也会创建一个新文件。

第一个示例显示了文本的添加。如所示，新文本被添加在下一行：

```
$ echo "Hello to you too!" >> text
$ cat text
Hello!
Hello to you too!
```

第二个示例演示了将创建一个新文件：

```
$ echo "Hello to you too!" >> text2
$ cat text2
Hello to you too!
```

为了重定向错误消息，用户需要使用 `2>` 运算符，后跟将写入错误的文件名。如果文件不存在，将创建一个新文件；否则文件将被覆盖。
