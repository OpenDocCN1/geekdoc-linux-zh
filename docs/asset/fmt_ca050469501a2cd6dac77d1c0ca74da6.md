# lookup-el

通过 Emacs 电子字典的接口。该软件原始名称是 `lookup`，之后此包被称为“Lookup”。`Lookup` 是用于 Emacs 的搜索软件（原始 `Lookup` 支持 `Mug`，但 deb 包不支持）。`Lookup` 为网络字典提供简单统一的搜索接口。`Lookup` 的功能：

- 可以同时搜索多个字典
- 你可以添加新的搜索命令（查看信息）
- 如果需要，可以自定义搜索结果（查看信息）

来自 Debian 3.0r0 APT

# loopback

一种允许计算机系统挂载镜像文件（回环设备）或为本地机器运行服务（回环地址）。来自 Redhat–9–Glossary `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# loopback address

特殊的 IP 号（`127.0.0.1`），指定用于机器的回环接口。`127.0.0.0` 到 `127.255.255.255` 也预留给回环并用于本地机器内部测试。来自 Linux Guide @FirstLinux `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# loopback device

是一种可以当作磁盘使用但实际上指向某处普通块设备。如果你的想象力已经开始飞跃，考虑使用带有文件系统的软盘，在实际上没有软盘的情况下，随时可以将此创建到软盘。你也可以在 Windows 分区的 500 MB 文件中拥有另一个 Linux 系统并进入——无需重新分区 Windows 机器即可运行 Linux。这一切都可以通过回环和 RAM 设备实现。来自 Route-Users-Guide `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# LoopLinux

这是一个可以从 DOS 系统（MSDOS, PCDOS, DRDOS 以及 DOS 模式下的 Win9）安装和运行的 Linux 操作发行版。有了 loop 版本的 Linux 系统不需要修复。Linux 系统将只是当前 DOS/Win9 系统上的一个文件或目录，就像在分区上一样。`LoopLinux3.0` 于2003 年 6 月 4 日发布。来自 LWN Distribution List `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# 无损压缩

一种在不牺牲任何原始数据的情况下减小文件大小的压缩技术；被 Stacker 等程序使用，用于压缩硬硬盘上的所有程序和文档。在无损压缩中，扩展或恢复的文件是压缩前原始文件的副本；而在有损压缩中，数据会以人类无法察觉的方式丢失。无损压缩适用于文本和计算机代码，而有损压缩主要用于缩小音频和图形。来自 QUEDIC `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# 有损压缩

一种通过丢弃数据来大幅缩小压缩文件大小的压缩技术。有损压缩技术可以将文件缩小到原来的 1/50（或，与无损压缩技术的平均三分之一相比）。有损压缩用于图形文件，此时数据丢失（例如关于图形数百万颜色的信息）是不明显的。例如 JPEG 压缩，参见无损压缩。来自 QUEDIC `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# 丢失簇

簇保留在磁盘上，尽管文件分配表 (FAT) 不包含其与文件链接的记录。当计算机关闭（或断电）或在写入文件时尝试执行其他操作，就会发生丢失簇。来自 QUEDIC `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# lout

排版系统，是 (La)Tex 的替代方案，一种风格与 LaTeX 相似的文档格式系统，它通过标记文件工作——包含控制格式命令的纯文本文件。Layout 提供了全功能，包括 PostScript、PDF 和纯文本文件输出、通过自动连字符优化的参数和分页、PostScript EPS 文件的包含与生成、公式格式化、表格、旋转和排序索引、参考文献数据库、页眉和自动交叉引用，或多语言文档的连字符（支持大多数欧洲语言，包括俄语）、C/C++ 程序的格式化。Layout 可以通过编写定义来扩展，这些定义比 LaTeX 简单得多。Macros 相比 (LaTeX) 具有优势。它小得多，而且在 Lout 中学习如何操作（包括编写定义）比 LaTeX 容易得多。Lout 脚本处理非常简单清晰。它的使用频率比 (LaTeX) 低得多，因此 Lout 的插件较少，也没有足够的本地专家来咨询问题。你可能在网络上找不到许多 Lout 文档。来自 Debian 3.0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
