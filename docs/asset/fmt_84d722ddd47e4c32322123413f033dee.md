# fnrename — 重命名 FNS 名称的绑定

### 概要

`/usr/bin/fnrename [-s][-v] context-name old-atomic-name new-atomic-name`

## 描述

`fnrename` 在 `context-name` 上下文中将 `old-atomic-name` 的联邦命名服务 (FNS) 绑定重命名为 `new-atomic-name`。`old-atomic-name` 和 `new-atomic-name` 必须是原子名称，并在 `context-name` 指定的范围内解析。

## 选项

+ `-s` 覆盖已绑定到 `new-atomic-name` 的任何引用。如果省略此选项，当 `new-atomic-name` 已经绑定，`fnrename` 将失败。
+ `-v` 显示重命名的绑定。

## 示例

以下示例在 `/usr/jsmith/service` 上下文中将 `calendar` 绑定到 `cinder` 的引用，并解绑 `cinder`。`fnrename user/jsmith/service/ calendar`

# insearch — 根据指定属性搜索 FNS 对象

### 概要

## 描述

`insearch` 命令显示在 `composite-name` 处或其目录下满足给定过滤表达式属性的联邦命名服务 (FNS) 对象的名称，以及可选的属性和引用。根据搜索过程中检查对象的属性和引用的标识符和值的逻辑表达式指定过滤表达式。关于 FNS 的通用信息，请参 `fns(5)`。

## 选项

- `-a ident` 显示符合过滤表达式的对象的指定属性。如果不使用 `-a` 选项，则显示所有属性。来自（外壳）的空 `ident` `""` 则表示不显示任何属性。你可以提供多个 `-a` 选项。`ident` 的语法详见于第 392 页的“显示所选属性”章节。
- `-A` 咨询权威源获取信息。
- `-1` 显示每个符合过滤表达式的对象的引用（reference）。
- `-L` 在搜索过程中遵循 X/Open 联邦命名命名 (XFN) 链接。
- `-n max` 将显示的对象最大数量限制为给定的数字（正整数）。默认没有限制。
- `-s scope` 将搜索范围设置为以下之一：
  * `object` 仅搜索对象复合名称（composite-name）。
  * `context` 搜索直接绑定到复合名称的对象。
  * `subtree` 搜索绑定到复合名称或其任何上下文的对象。
  * `constrained_subtree` 类似于 `subtree`，但将搜索限制为由实现上下文定义的子上下文集。
你可以将 `scope` 缩写为任何无歧义的前缀，例如 `o` 或 `cont`。
如果你没有指定 `-s scope` 选项，默认行为是 `-s context`。
- `-v` 详细显示每个符合过滤表达式的对象的引用。此选项的优先级高于 `-1`。

### 操作数

- `composite-name` 一个 FNS 命名的对象。

## 使用方法

### 简单过滤表达式

过滤表达式最简单的形式是测试属性的值。你只需提供属性名称即可形成此表达式。例如，以下命令搜索具有名为 `for_sale` 属性的对象。

```
% fnsearch composite-name for_sale
```

另一个简单的过滤表达式是测试特定属性的值。以下命令找到年龄小于 17 岁的对象。

```
% fnsearch composite-name "age < 17"
```

字符串值通过在单引号中对字符串来指示。例如，以下命令找到所有红色的对象。

```
% fnsearch composite-name "color == 'red'"
```

注意，此示例中的双引号（`""`不是过滤表达式的一部分。相反，它们防止外壳（shell）解释表达式中包含空格和单引号。

### 逻辑运算符

你可以使用逻辑运算符 `or`（或）、`and`（与）和 `not`（非）来组合简单的过滤表达式，如下例所示。

```
% fnsearch composite-name "age >= 35 and us_citizen"
```

你可以使用括号来分组表达式，如下例所示。

```
% fnsearch composite-name "not (make == 'olds' and year == 1973)"
```

运算符的优先级如下，按优先级递增排序：

- `or`
- `and`
- `not`
- 关系运算符

逻辑运算符 `and` `and` `and` `or` 是左关联的。

### 关系运算符

你可以使用以下关系运算符将属性与提供的值进行比较：

| 运算符 | 描述 |
| :--- | :--- |
| `==` | 如果属性的至少有一个值等于提供的值，则为真 |
| `!=` | 如果属性的没有任何一个值等于所提供的值，则为真 |
| `<` | 如果属性的至少有一个值小于提供的值，则为真 |
| `<=` | 如果属性的至少有一个值小于或等于提供的值，则为真 |
| `>` | 如果属性的至少有一个值大于提供的值，则为真 |
| `>=` | 如果属性的至少有一个值大于或等于提供的值，则为真 |
| `~` | 如果属性的至少有一个值根据某些特定上下文近似匹配准则匹配提供的值，则为真。此准则必须包含严格相等。 |

比较和排序特定于所测试属性的语法或规则。

## 显示所选属性

默认情况下，`fsearch` 命令显示匹配搜索标准的每个对象的名称和所有属性。你可以限制列表，显示匹配搜索标准的对象的名称和属性。使用 `-a` 选项。

```
% fsearch -a color "shape == 'small'"
```

- 标识符的格式是 `FN_ID_`，ASCII 字符串。
- 标识符的格式是 `FN_ID_`，一个点分隔的整数字符串。
- 标识符的格式是 `FN_ID_`。

## 过滤属性

你可以使用替换令牌替换表达式的某些部分，替换令牌是一个百分号（`%`）后跟一个字符。表达式的该部分以 `printf(1)` 的方式给出。替换令牌为：

- 属性
- 字符串
- 标识符
- 属性值

> 注意 — `%v` 目前支持的语法是 `ascii_syntax`。

## insearch

### 通配符字符串

通配符字符串由指示符和字符串交替组成。通配符指示符由星号（`*`）表示，表示任何字符的多次出现。使用通配符来指定。以下是一些示例：

- `*` 任何字符串。
- `'tom'` 字符串 `tom`。
- `'harv*'` 以 Harv 开头的字符串。
- `'*ing'` 以 ing 结尾的字符串。
- `'*a**b'` 以 a 开头并以 b 结尾的字符串。
- `'jo**ph'*ne'` 包含字符串。

### 扩展操作

扩展运算符是谓词（返回真或假的函数），你可以将其与表达式中的运算符自由混合。通过提供带引号的运算符名称，后跟一个参数来指定扩展操作。目前定义了以下三个扩展操作：

- `'name'` (`WildcardedString`)：如果对象的名称匹配提供的通配符字符串，则为真。
- `'retype'` (`Identifier`)：如果对象的引用类型等于提供的标识符，则为真。
- `'addtype'` (`Identifier`)：如果引用的任何地址类型等于提供的标识符，则为真。

以下示例显示搜索名称以 `bill` 开头且 `IQ` 属性大于 80 的对象。
`% infix composite-name "name('bill*') and IQ > 80"`

### 过滤表达式的语法

过滤表达式的完整语法如下。它是基于 X/Open 联邦命名 (XFN) 规范定义的（参见 `FN_search_filter_TN`）。此语法中的字符串字面量用双引号括；引号本身不是表达式的一部分。使用大括号分组；使用括号表示可选元素。未引号的星号（`*`）表示前一个元素的多次出现，加号（`+`）表示一次或多次出现。

```
FilterExpr ::= [Expr]

Expr ::==Expr "or" Expr

      Expr "and" Expr

      "not" Expr

      "(" Expr \
```
