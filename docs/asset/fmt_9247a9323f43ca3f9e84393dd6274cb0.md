
在文本模式下设置从键码到终端代码映射的主要方法是使用`loadkeys`程序。该程序加载指定的键盘映射文件，并指示内核终端驱动程序在键盘输入时使用该文件。Linux发行版通常在配置文件中包含对`loadkeys`的调用。例如，在SuSE 6.3中，文件`/etc/rc.d/init.d/kbd`包含此调用。在Caldera OpenLinux 2.3中，等效的调用在`/etc/rc.d/init.d/keytable`中。其他发行版可能将此调用放在其他位置。

修改键盘映射的技巧是更改`loadkeys`使用的键盘映射。在美国，大多数用户在安装时将系统配置为调用适当的美国键盘映射。这个键盘映射文件通常名为`us.map`，并位于诸如`/usr/lib/kbd/keymaps/1386/qwerty`这样晦涩的目录中。当然，Linux安装程序处理了映射细节的设置，因此您可能并未意识到这些细节。要更改键盘映射，我建议找到指定键盘映射文件的脚本或配置文件，然后更改该文件。例如，在Caldera OpenLinux 2.3中，`/etc/sysconfig/keyboard`文件包含键盘映射文件的名称。您可以将此定义更改为另一个预定义文件，或者更改为您自己创建的文件。然后，您可以复制并修改一个几乎正确的键盘映射文件。

键盘映射文件由一系列如下行组成：

```
keycode 8 = seven          ampersand braceleft  Control_underscore
```

此行列出了键码的四种含义。使用哪种含义取决于使用了哪个修饰键（大多数键盘上有Shift、Ctrl或Alt，并可选择左/右变体）。每个修饰键都有一个值，如表 15.1 所示。使用的键含义取决于修饰键值之和。例如，在没有修饰键的情况下，值为 0，因此使用第 0 个字段——即前面示例中的`seven`。按下Shift键时，值为 1，因此值为`ampersand`。`Ctrl`+`Shift`组合产生值为 5，因此使用第 6 个字段。前面的一行只包含四个字段，因此在实际操作中，该组合可由各个程序自行处理。由于修饰键的值可达 128，键盘映射文件中的行可以非常长——最多可有 256 个条目。

**表 15.1 键盘映射文件中使用的修饰键**

| 键 | 值 |
| --- | --- |
| Shift | 1 |
| AltGr | 2 |
| Ctrl | 4 |
| Alt | 8 |
| ShiftL | 16 |
| ShiftR | 32 |
| CtrlL | 64 |
| CtrlR | 128 |

`AltGr`指的是右Alt键。`Shift`和`Ctrl`分别指的是左或右的`Shift`或`Ctrl`键，而带有`L`或`R`后缀的名称仅指左键或右键。

如果您只想修改一两个键，可以在不调整整个键盘映射的情况下做到这一点。您可以使用`keycode`命令来实现，其形式为：

```
keycode n = function
```

使用此命令时，您必须知道键码编号和功能名称。您可以使用`showkey`命令找到按键生成的键码。输入`showkey`后，程序会显示您按下的任何按键生成的键码。

## 基于 X 的键盘布局

X键盘布局调整的原理与基于文本的键盘布局类似，但某些细节有所不同。基本的键盘布局选择由`XF86Config`文件中的`Keyboard`部分处理。该部分应类似于以下内容：

```text
    Section  "Keyboard"
    Protocol "Standard"
    XkbRules "xfree86"
    XkbModel "omnikey101"
    XkbLayout "us"
    XkbVariant "nodeadkeys"
    EndSection
```

此示例将键盘布局设置为使用`us`规则。您可以通过将此代码更改为另一个适当的代码（例如，用于德国键盘布局的`de`）来更改布局。

您可以使用`xmodmap`命令对单个按键或整个映射进行调整。要调整单个按键的含义，您可以使用`-e`参数将键码绑定到一个操作，例如：

```bash
xmodmap -e 'keycode 23 = Tab'
```

要调整一组按键绑定，您可以将前面示例引号内的此类赋值一行一个地放入文件中。然后，您可以将该文件传递给`xmodmap`，例如：

```bash
xmodmap xmodmap-bindings.txt
```

### 提示

许多发行版配置为在您登录时运行`xmodmap`并传递`~/.Xmodmap`文件。因此，您可以将您的调整放在此文件中，而无需自己调用`xmodmap`。

某些Linux发行版配置`Backspace`和`Delete`键的方式会让大多数用户感到困惑。您可以通过使用以下`xmodmap`赋值来改变它们的行为：

```text
keycode 22 = BackSpace
keycode 107 = Delete
```

# 鼠标与变异鼠标

计算机鼠标于20世纪60年代开发，但在1973年`Xerox Alto`计算机发布之前并未得到广泛应用。直到十年后`Apple Lisa`和`Macintosh`计算机的发布，鼠标才真正普及。此后，鼠标扩展到了各种各样的计算机系统，包括`x86` PC。如今，所有比掌上电脑大的计算机都配备有鼠标或某种替代指向设备——而且掌上电脑通常使用触摸屏，可以替代鼠标使用。

如今，鼠标和计算指向技术可供选择的方式相当广泛。幸运的是，这些选项中的大多数不需要特殊的驱动程序支持，因为这些选项涉及对软件透明的内部技术，或者与鼠标形状等人体工程学因素有关。当然，作为指向设备的人类购买者，这些都是重要的考量因素。

**注意**

我将在后续页面中介绍几种流行的指向设备，但并未涵盖所有可用的指向设备。如果您碰巧遇到某种不寻常的指向设备，它有很大概率能在Linux上正常工作。

## 传统鼠标

传统鼠标（如图 15.7 所示）是一种尺寸适合握在手掌中的设备。其底部装有某种跟踪机制——通常是一个在传感器上滚动的球，用于检测运动，但有时是全光学传感器网格。（我将在本章稍后的“鼠标技术”部分介绍这些技术。）在顶部，有时在现代鼠标的侧面，有一个或多个按钮。如今的`Macintosh`计算机随附的是单按钮鼠标，但`x86` PC通常随附的是双按钮或三按钮鼠标。某些型号包含更多按钮。许多现代鼠标用*滚轮*取代了一个按钮。该装置可以像轮子一样旋转，用于滚动窗口中的文本。滚轮通常也可以像按钮一样按下。如果在没有特殊滚轮驱动的情况下配置，滚轮在Linux中作为按钮工作，但滚动功能无法使用。即使使用特殊的滚轮驱动程序，滚轮也需要针对应用程序或应用程序类型进行配置才能使用滚轮。

传统鼠标仍然是当今`x86`计算机上最受欢迎的指向设备类型。大多数计算机用户都熟悉鼠标的操作，而且鼠标仍然是可用的最精确的指向设备之一。购买鼠标时需要考虑的一些标准包括：

- **接口** 串行、`PS/2`和`USB`是最常见的鼠标接口。它们都能很好地与Linux配合工作，尽管您可能需要升级内核才能使用`USB`鼠标。

- **传感器技术** 如前所述，鼠标使用多种传感器技术，这些技术会影响鼠标的性能。

- **分辨率** 通常以每英寸点数（`dpi`）衡量，分辨率指您需要移动鼠标多远才能在屏幕上实现指针的特定移动。较高的分辨率意味着给定的物理移动会产生更大的指针移动。或者，在高分辨率设备上，可以将鼠标在屏幕上的跟踪灵敏度向下调整，从而获得更高的精度。因此，您可能会倾向于选择高分辨率设备，特别是如果您需要用鼠标进行高精度操作（如处理图形图像）。

**提示**

如果您发现鼠标跟踪速度不够快，可以使用`xset m acceleration threshold`命令来调整鼠标速度。将`acceleration`设置为 1 或更大的整数值以加快鼠标速度，将`threshold`设置为触发加速前移动的像素数。这种组合允许您在鼠标移动短距离时缓慢移动，这在精确放置对象时很有用。同时，更大的移动量可以从加速中受益。

- **对称性** 一些鼠标左右对称，这意味着它们对左撇子和右撇子使用者同样适合（或同样不适合）。其他鼠标则设计为适合右手或左手。左撇子使用者很难找到适合左手使用的鼠标，因为制造商通常忽视左撇子市场。

- **总体人体工程学** 没有两个人的手是完全相同的。因此，最好在购买鼠标之前先试用。它是否适合您的手？是否有不自然的凸起？按下按钮所需的力度是否过大或过小？只有您能判断这些因素。
