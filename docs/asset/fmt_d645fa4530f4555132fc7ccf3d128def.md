## 示例

以下示例列出了文件 `foo` 的权限。接着，它为文件 `foo` 添加了一个 ACL，仅赋予用户 `ray` 读权限，并再次列出权限。`ls -l` 命令输出的权限列表末尾的 `+` 号表示该文件存在 ACL。然后，示例使用 `getfacl` 命令列出文件的 ACL 信息。

```
castle% ls -l foo
-rw-r-- 1 winsor staff      0 Apr 2 14:23 foo
castle% setfacl -m user:ray:r-- foo
castle% ls -l foo
-rw-r--r+ 1 winsor staff      0 Apr 2 14:23 foo
castle%
```

```
# file: foo
# owner: winsor
# group: staff
user::rw-
user:ray:r--      #effective:r--
group::           #effective:r--
mask:r---
other:r---
castle%
```

以下示例替换了文件 `foo` 的整个 ACL，添加了一个允许用户 `ray` 读/写的条目、一个允许文件所有者所有访问的条目、一个允许组仅读的条目、一个允许组类读/写的条目，以及一个禁止其他人进行所有访问的条目。

```
castle% setfacl -s user:ray:rw-, user:rwx,group:r--, mask:rw-,other:--- foo
castle% getfacl foo
```

```
# file: foo
# owner: winsor
# group: staff
user::
user:ray:rw--      #effective:rw-
group::r--           #effective:r--
mask:rw---
other:---
castle%
```

> 注意 — 执行此命令后，文件权限位被设置为 `rwxrwx----`。

尽管文件所有者组仅有读权限，但所有额外用户 ACL 条目和组 ACL 条目的最大可用权限是读和写，因为 `mask` 条目指定了这些权限。以下示例在文件 `bar` 上设置了与 `foo` 相同的 ACL。

```
castle% getfacl foo | setfacl -f - bar
castle% getfacl bar

# group: staff

group::r-- #effective:r--
mask:rw-
other::-

```

### 概要

```
/usr/bin/sh [-acefhkinprstuvx] [argument...]

```

## 描述

Bourne shell 是由 Steve Bourne 在 AT&T 贝尔实验室期间编写的，是原始的 UNIX shell。由于其编程能力和通用性，该 shell 优用于 shell 编程。它缺乏用于交互使用的特性，例如内置算术。

Bourne shell 是 root 账户的默认登录 shell，如果你在密码文件中没有指定其他 shell，它将默认的用户登录 shell。Bourne shell 用于所有系统级管理脚本。Bourne shell 命令为 `/bin/sh`。默认提示符是美元符号 (`$`)。root 提示符是井号符号 (`#`)。

`/usr/bin/sh` 命令是一种种执行从终端或文件读取的命令的命令编程语言。

`/usr/xpg4/bin/sh` 命令与 `/usr/bin/ksh` 相同。参见 `ksh` 命令，它是 shell 的一种接口，提供了 `sh` 的所有功能，并支持作业控制（参见第 1229 页的“作业控制”）。

shell 的参数列在第 1228 页的“调用”中。

# 定义

空白是制表符或空格。名称是 ASCII 字母、数字和下划线的序列，以字母或下划线开头。参数是一个名称、数字或字符 `*`, `@`, `#`, `?`, `-`, `$`, 和 `!` 中的任何一个。

## 用法

# 命令

一个简单命令是一个由空白分隔的非空白单词序列。第一个单词指定要执行的命令名称。除下文指定外，其余单词将作为参数传递给被调用的命令。命令名称作为参数 0 传递（参见 `exec(2)`）。命令的值在它正常终止时为其退出状态，如果它异常终止，则为（八进制） `200+status`；状态值列表参见 `signal(5)`。
