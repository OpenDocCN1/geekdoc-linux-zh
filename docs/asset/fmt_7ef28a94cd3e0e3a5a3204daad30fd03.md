
进入 Ubuntu 的现场版光盘运行

想要体验 Ubuntu 的风味（并检查你的硬件是否与 Ubuntu 完美契合），可能没有比直接从现场版光盘运行 Ubuntu 更好的方法了。要做到这一点，只需将 Ubuntu 桌面光盘插入磁盘驱动器并重启机器。当机器再次启动时，它应该从 CD 启动，在屏幕滚动过一些白色文字后，你将看到第一个 Ubuntu 启动屏幕（图 2-1）。如果屏幕没有出现，而是你的机器进入了你通常的操作系统，那么很有可能是你机器的 BIOS 需要更改，以便允许你从 CD 启动。

**图 2-1:** Ubuntu 现场会话启动屏幕

你可以通过重启并按下屏幕指令分配的用于访问 BIOS 的任意键来访问机器的 BIOS。这通常使用 `DELETE` 或 `F1`，但并不是所有机器都是一样的。如果屏幕上的信息消失得快以至于你错过了，可以查看用户手册以确定正确的按键。一旦进入 BIOS 设置界面，更改启动顺序，使你的 CD 驱动器处于第一。

一旦你的机器确实从现场版光盘启动，并且看到如图 2-1 所示的 Ubuntu 现场会话启动屏幕，按下 `ENTER` 或什么都不做大约 30 秒以继续。这将以英语和美式键盘布局启动你的 Ubuntu。记住，你的硬盘将不会被触碰，所以放心吧——你不会碰到它，更不用担心损坏它。

如果你希望系统显示不同的语言，请按 `F2`，使用光标键选择你选择的语言，然后按 `ENTER`。你可以通过按 `F3` 并按照相同的步骤更改默认键盘布局。完成后，按 `ENTER` 启动系统。

现场版光盘会话不支持输入某些语言（如中文、日语和韩语）所需的特殊输入机制。

从那以后，你就完全进入了自动驾驶模式——你所做的就是等待。现在会偶尔滚动一些白色文字，偶尔会有几秒钟的停顿，最后当 `GNOME` 桌面环境开始其初始化过程并完成后，一切将完全变为图形化……那时，你将面对 Ubuntu 桌面，这意味着你已经准备就绪了——但我留到第 3 章再谈这个。

## 投入深渊——安装 Ubuntu

如果你已经在机器上安装了 Ubuntu，对从现场版光盘运行感到满意，或者还没有决定做什么，你可以直接跳过本章的其余部分，进入下一章开始使用 Ubuntu 桌面。然而，如果你还没有安装 Ubuntu 并且准备好安装，那么你最好留在这里继续阅读。

### 单 单启动还是双启动设置？

如果你的机器上没有安装 Windows，你可以跳过这一节。另一方面，你将决定是否要保留它。

在同一台机器上同时安装 Windows 和 Linux 并让它们和谐共存可能的。这被称为双启动设置。设置这样的系统也变得极其简单。我是从双启动设置开始的；但最终发现我只使用 Linux 端。一个我不使用的 Windows 系统占据了这么多磁盘空间似乎是浪费了宝贵的资源，于是我放弃了整个系统，改为了纯 Linux 独占设置。我的感觉是，除非你真的需要某些 Linux 端无法提供的应用程序（可能可能是某些游戏），否则就选择纯 Linux 设置并忘掉 Windows 吧。Linux 已经有了你需要的大部分功能，而且 `OpenOffice` 办公套件中的应用程序可以读写 Microsoft 文件，如果你担心这个问题，你将能够与 Windows 用户协作。

你可能在想，如果按照我的建议在安装 Linux 时丢弃 Windows 系统，那么如果你不喜欢 Linux 或无法正确安装，你可能需要重新安装 Windows。你信不信，如果你决定以后回来，这样做是种好办法。这在开始时需要一点精力，但从长远来看，你是在给自己帮大忙。另一方面，如果你选择了双启动设置，你将兼得两者的优点。启动任何系统都很简单。当你启动机器时，你将看到大引导加载程序 `GRUB` 界面，从那里你可以选择 Linux 或选择 Windows。之后，你选择的系统将正常启动。

所以如你所，无论你选择哪种方式，都不会出错。只需在开始安装之前备份你的重要文件；带着常识、耐心和积极的态度进行；你将会没问题的。简而言之：别担心。

### 准备行动

安装 Ubuntu 需要准备的内容比许多 Linux 发行版要少。一旦你决定了是否采用双启动路线，你唯一手头需要的是你的 Ubuntu 光盘，为了指导和安全，请参考本书。你可能需要花费精力想一个用户名和密码，就像大多数其他操作系统一样。

#### 用户名与用户密码

你的用户名是你将经常使用的东西。你每次启动系统时都要输入它，所以确保它是你能够接受的，特别是在输入方面。它可以是你的名字、缩写，或者你喜欢的任何名称。它通常以小写字母开头，后面跟着数字或其他小写字母。我的就是简单的 `ng`，但你可以使用像 `hopeu2pal`，尽管每天登录输入会很累。

你还需要一个用户密码，你每次登录时都需要输入。当你安装新软件或更改系统设置时需要用到它。长度至少为八个字符，并包含数字和字母（大和小写）以提高安全性。如果你愿意，当然可以使用更短的字符和仅字母。如果密码输入不可接受，安装程序会提示你，所以不用太担心。确保把它写下来，并将纸条放在安全的地方，以免把自己锁在系统之外。

注意：如果你有其他 Linux 发行版的运行经验，可能会惊讶地发现 Ubuntu 默认禁用了 `root` 账户。因此，它没有输入 `root` 密码的安装步骤。你可以查看本书的网站（`www.edgyuins.org/UFNG`）来了解绕过此设置的方法。你也可以在系统安装后的任何时间设置 `root` 密码，所以如果 `root` 账户对你来说很重要，请不要担心。

## 双启动用户请注意

如果你打算创建一个双启动设置，在继续安装 Ubuntu 之前，先对 Windows 磁盘进行碎片整理是一个好主意。这将使安装过程中的重新分区更快、更安全。

你可以在运行 Windows 的状态下执行此操作：双击“我的电脑”，右键点击硬盘图标，并选择“属性”。然后，你可以通过点击“属性”窗口中的“选项卡”并点击“立即整理”来对硬盘（在 Windows XP 中）。在 Windows NT 中，你可以通过进入菜单并选择控制面板>管理工具>计算机管理>磁盘碎片整理来执行；而在 Windows 98 及某些其他版本中，你可以通过选择程序>系统工具>磁盘碎片整理来执行相同的操作。

## 正式开始

好了，既然我们已经涵盖了所有准备工作，让我们进入实际的 Linux 安装阶段。把书放在腿上方便你跟进，然后准备大干。

幸运的是，安装过程非常简单，因为只有极少数步骤是你真正需要做任何操作的。你大部分的工作就是点击屏幕上的按钮。这没什么难的，对吧？

当然，当你看到这里列出的指令和描述时，它看起来可能像是一个繁琐的过程。其实不是。它结束得比你想象的要快。经常参考本文的初学者可能会花一点时间，但不用担心。总而言之，整个过程比 Windows XP 或 Mac OS X 更快、更简单。请记住，你在安装操作系统时只带有几个启动应用程序。而在 Ubuntu 安装中，你安装的不仅是操作系统本身，还有你未来可能想要或需要使用的大部分应用程序。你将一次性完成很多工作。

在我们开始之前有一点。有些人在安装系统时会感到非常忐不安。这个过程让他们紧张，仿佛如果他们在回溯过程中点错了某个地方，房子就会付飞烟灭。不用说，没必要这样担心。只要你备份了数据，就没事的。如果第一次安装搞砸了，那又怎样？重新开始就好了。没有任何损失，因为你没有什么可以损失的。只需确保为这个过程留出比你需要更多的时间。不要在要上班一小时前或要去市中心见朋友一小时前开始安装。匆忙会让人们做奇怪的事。给自己留充足的时间，并且正如我之前提到的，备份好任何你可能会心疼丢失的数据。

如果你准备好了，以下是步骤：

- 1. **启动** 如果你还没有这样做，请用 Ubuntu 桌面光盘启动你的机器。

- 2. **开始安装** 双击 Ubuntu 桌面上的**安装（Install）** 图标开始安装。这将弹出安装向导的第一页（图 2-2）。

- 3. **欢迎（选择语言）** 选择你想使用的语言，在安装过程完成后点击**下一步（Forward）**按钮。无论你选择哪种语言，系统安装后你始终可以选择使用英语启动。你也可以以后添加对其他语言的支持。

- 4. **你在哪里？（选择位置）** Ubuntu 安装程序将为你选择的安装语言选择默认安装位置。如果你的位置不同，请直接点击向导地图（图 2-3）选择适合你的位置。选择完成后，点击**下一步（Forward）**。

选择你所在国家和时区的城市。如果在选择了正确的时区后显示的当前时间仍然不，你可以在重启进入已安装的系统后进行调整。

- 5. **键盘布局** 下一个屏幕将显示你所选的安装语言的默认键盘布局。如果你的键盘布局不同，请从列表中选择合适的选项。如果你不确定是否选对，可以在窗口底部的文本框中输入几个单词进行双重检查。完成后，点击下一步。如有需要，你可以在系统安装后以后添加其他键盘布局。

- 6. **准备磁盘** 你在此时的操作取决于你机器上的内容。假设磁盘上已经有了操作系统（如 Windows），请接受最上方的选项（默认选中）。这将把 Windows（或其他操作系统）的安装大小缩小到磁盘大小的一半，然后使用空空间安装 Ubuntu。如果磁盘上没有操作系统，请选择使用整个磁盘的选项。
