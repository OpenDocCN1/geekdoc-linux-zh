
# 2.1 设备文件访问

## 2.1.1 初始化与打开

不幸的是，我没有 SMP 机器来检查它在 SMP 模式下的工作情况。

设备打开计数增加：

```c
Device_Open++;
```

初始化消息：

```c
sprintf(Message,
        "If I told you once, I told you %d times - %s",
        counter++,
        "Hello, world\n");
```

> **注意**：我们之所以允许这样做，是因为消息的最大长度（假设 32 位整数 - 最多 10 位数字加负号）小于 `BUF_LEN`（即 80）。请小心不要溢出缓冲区。尤其是在内核中！

设置消息指针：

```c
Message_Ptr = Message;
```

确保模块在文件打开期间不会被移除。通过增加使用计数（即模块的打开引用数，如果它不为零，`rmmod` 将会失败）来实现：

```c
MOD_INC_USE_COUNT;

return SUCCESS;
```

## 2.1.2 关闭设备

此函数在进程关闭设备文件时被调用。在版本 2.0.x 中，它没有返回值，因为它不能失败（你总是必须能够关闭设备）。在版本 2.2.x 中，它允许失败 - 但我们不会让它失败。

```c
#if LINUX_VERSION_CODE >= KERNEL_VERSION(2,2,0)

static int device_release(struct inode *inode,
                          struct file *file);

#else

static void device_release(struct inode *inode,
                           struct file *file);

#endif

#ifdef DEBUG

printk("device_release(%p,%p)\n", inode, file);

#endif

/* We're now ready for our next caller */
Device_Open = 0;

/* 减少使用计数，否则一旦你打开了文件，
 * 你就永远无法卸载模块。
 */
MOD_DEC_USE_COUNT;

#if LINUX_VERSION_CODE >= KERNEL_VERSION(2,2,0)

return 0;

#endif
```

## 2.1.3 读取设备

此函数每当进程尝试从已打开的设备文件读取数据时被调用。

```c
#if LINUX_VERSION_CODE >= KERNEL_VERSION(2,2,0)

static ssize_t device_read(struct file *file,
                            char *buffer, /* 填充数据的缓冲区 */
                            size_t length, /* 缓冲区的长度 */
                            loff_t *offset) /* 我们在文件中的偏移量 */

#else

static int device_read(struct inode *inode,
                       struct file *file,
                       char *buffer, /* 填充数据的缓冲区 */
                       int length) /* 缓冲区的长度
                                    (不要写超过这个长度！) */

#endif

/* 实际写入缓冲区的字节数 */
int bytes_read = 0;

/* 如果我们在消息末尾，返回 0
 * (表示文件结束)
 */
if (*Message_Ptr == 0)
    return 0;

/* 实际上将数据放入缓冲区 */
while (length && *Message_Ptr) {

    /* 因为缓冲区在用户数据段中，
     * 而不是内核数据段中，直接赋值不起作用。
     * 相反，我们必须使用 put_user，它将
     * 数据从内核数据段复制到
     * 用户数据段。
     */
    put_user(*Message_Ptr++, buffer++);

    length--;
    bytes_read += 1;

#ifdef DEBUG

    printk("Read %d bytes, %d left\n",
           bytes_read, length);

#endif

    return bytes_read;
}
```

```c
 */

#include <asm/uaccess.h> /* 用于 put_user */

#endif

#define SUCCESS 0
```

设备声明：

```c
/* 设备声明 *****************/

/* 我们的设备名称，它将显示
 * 在 /proc/devices 中 */
#define DEVICE_NAME "char_dev"

/* 设备发出的消息的最大长度 */
#define BUF_LEN 80

/* 设备现在是打开状态吗？用于防止
 * 并发访问同一设备 */
static int Device_Open = 0;

/* 当设备被请求时它将提供的消息 */
static char Message[BUF_LEN];

/* 读取消息的进程是如何
 * 获取的？如果消息比我们填充
 * device_read 的缓冲区大，这很有用。
 */
static char *Message_Ptr;
```
