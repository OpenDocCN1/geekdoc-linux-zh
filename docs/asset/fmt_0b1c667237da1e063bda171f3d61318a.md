| 4 | `caa` | 集群可用性 (CAA) 信息 |

CAA 的好消息是你将使用的命令以`caa_`开头。你只需要记住你想执行的操作。注意，GUI 不显示在`man -k`或`sysman`的输出中。这是因为 GUI 是一个`sysman`插件。使用`sysman -list`命令查找加速器列表。

```
# sysman -list grep -i caa
```

使用`caa`加速器通过`sysman`管理 CAA：

```
# sysman caa
```
