
# SuSE Linux 6.2 深度解析

## 专家见解

本书对 SuSE Linux 6.2 的核心功能和复杂性进行了重点介绍，包括：

- SuSE Linux 6.2 的安装、配置和使用
- 对最新 SuSE Linux 软件工具的跟时介绍
- 使用 SuSE, Inc. 的 `yast` Linux 工具进行系统管理任务
- SuSE Linux 6.2 X 窗口系统的网络设置和管理配置

## 权威建议
