## IPv4 汇总

### 目的与配置

好了，你终于通过了子网划分和 `VLSM`。现在是时候汇总（Summarize）了，或者用 `Spock` 的话来说，“路由聚合队长”（你可能注意到我是原版《星际迷航》的超级忠实粉丝）。这实际上意味着，我们必须将许多小网络聚合成一个或可能两个网络，然后将它们发布给我们的核心路由器，从而减小它们的路由表。您的核心路由器不需要了解所有不同的局域网（`LAN`）来做出路由决策。“路由聚合”的另一个用途是发布汇总地址。这是为了让目的层的设备能够根据其意愿分配 `IP`。

汇总允许路由器在分析其自身的路由表以查看到达目的地需要哪条路径时，处理时间更短。

`Cisco` 有一个名为“`Cisco` 三层模型”的标准。该模型就像 `OSI` 模型一样，是一个理论模型。该模型仅根据路由器在拓扑中的位置告诉您某些路由器可能执行的角色；让我们来看下：

**`Cisco` 三层模型**

| 层 | 描述 |
| :--- | :--- |
| 核心层 (`Core`) | 核心层的唯一目的是可靠、快速地交换信息。 |
| 分布层 (`Distribution`) | 该层的主要目的是提供路由、过滤、`WAN` 访问，并决定有多少数据可以访问核心。此层也可以“工作组层”。 |
| 接入层 (`Access`) | 这一层也称为“桌面层”，是分布层的扩展。这是我们谈论的地方。 |

有 15 条条目需要确定将数据包发送到哪里。然而，我们将通过总结每个局域网网络并将它们的汇总地址通告给总部路由器来帮助解决这种情况。这将条目数量减少到三条学习到的路由，反之，减少它的三个连接路由。这样做将减少开销，路由器只需要查看 3 条学习到的路由，而不是 12 条。那么，我们该如何做到呢？让我们来看看吧？

请记住起始掩码是 `/24`。随后，我们从左到右计数；你将从第三字节的开始开始，这就是感兴趣字节（interesting octet）。

汇总地址 `192.168.8.0/22`

现在我们已经通过在公共位和非公共位之间画线找到了汇总地址，现在是时候通过面向总部路由器的接口向总部路由器通告了。以下是你将使用的命令：

`LAN1`

```
IP summary-address EIGRP 100 192.168.0.0 255.255.252.0
```

`LAN2`

```
IP summary-address EIGRP 100 192.168.4.0 255.255.252.0
```

`LAN3`

```
IP summary-address EIGRP 100 192.168.8.0 255.255.252.0
```
