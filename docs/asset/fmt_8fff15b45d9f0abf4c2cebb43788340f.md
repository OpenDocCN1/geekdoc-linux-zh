## 其他考虑事项

## 第 27 章 使用 Dirvish 配合 rsync 创建快类型备份 931

如果你想跟踪用户从登录到注出的期间的操作，只要你有足够的日志文件空间。这一功能可以通过脚本命令来实现。

```
0 * * * * /usr/local/sbin/dirvish-expire -quiet

0 * * * * /usr/local/sbin/dirvish-run --quiet
```
