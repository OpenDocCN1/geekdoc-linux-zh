# 屡获殊名的红帽 Linux 操作系统

红帽 Linux 连续三年被 *InfoWorld* 杂志评为“年度操作系统产品”，这款开源系统比任何其他操作系统都能提供更卓越的稳定性、性能和控制力。

## 新操作系统特性

### 易于使用

- 硬件的自动检测与配置
- 全新的图形用户界面
- 安装完成后自动启动 GUI

### 新 2.2 内核

- 增强的性能
- 自动支持 SMP
- 支持更多硬件
- 最新的优化的 C 编译器
