
`XCreateSimpleWindow` 函数为指定的父窗口创建一个未映射的 InputOutput 子窗口，返回该窗口的 ID，导致 X 服务器生成 CreateNotify 事件。该窗口相对于兄弟窗口在堆叠顺序上处于顶端。超出父窗口边界的部分将被裁剪。仅输入窗口的 `border_width` 必须为 0，否则将产生 BadValue 错误。`XCreateSimpleWindow` 继承其父窗口的深度、颜色。除了背景外，所有其他窗口属性都有默认值。

`XCreateSimpleWindow`可能会产生 BadAlloc、BadMatch、BadValue 和 BadWindow 错误。

`display` 指定与 X 服务器的连接。

`w` 指定窗口。

`XDestroySubwindows` 可能会产生 BadWindow 错误。

## 映射窗口

如果对一个窗口执行了 `XMapWindow` 调用，则该窗口被视为已映射（mapped）。由于以下原因之一，它可能在屏幕上不可见：

- *它被另一个不透明窗口遮挡。*
- 它的某个祖先窗口未映射。
- 它完全被某个祖先窗口遮挡。

当窗口的部分或全部在屏幕上可见时，会为该窗口生成事件。如果客户端请求了 Expose 事件，则会接收到。窗口在取消映射（unmapped）时会保留其在堆叠顺序中的位置。

窗口管理器可能想要控制子窗口的放置。如果窗口管理器在父窗口（根窗口）上选择了 `SubstructureRedirectMask`，其他客户端在子窗口上发起的映射请求（map request）将不会执行，而是向窗口管理器发送 MapEvent。然而，如果子窗口上的覆盖重定向标志（override-redirect flag）被设置为 True（通常用于弹出菜单），则会执行映射请求。

平铺窗口管理器可能会决定重新定位并调整其他客户端窗口的大小，然后决定将窗口映射到其本地位置。想要提供装饰的窗口管理器可能会将子窗口重绘到第一帧。更多信息请参见第 3.2.8 和第 10.10 节。一次只能有一个客户端选择 `SubstructureRedirectMask`。

同样，一个客户端可以在父窗口上选择 `ResizeRedirectMask`。然后，其他客户端尝试调整窗口大小的操作将被抑制，该客户端将接收到 Resize 事件。

要映射给定窗口，请使用 `XMapWindow`。

## 窗口函数

`XMapWindow(display, w);`

`display` | 指定与 X 服务器的连接。

`w` | 指定窗口。

`XMapWindow` 函数映射该窗口及其所有接收过映射请求的子窗口。映射一个具有未映射祖先窗口的窗口不会显示该窗口，但将其标记为当祖先窗口映射时即可显示的状态。这种窗口被称为“不可见的（unviewable）窗口”。当其所有祖先窗口都已映射时，该窗口变为可见（viewable），如果它没有被另一个窗口遮挡，则将在屏幕上可见。如果窗口已经映射，则此操作没有影响。

如果窗口的 override-RedirectMask 为 False 且其他客户端在父窗口上选择了 Substructure，则 X 服务器会生成 MapRequest，且 `XMapWindow` 函数将不会映射该窗口。否则，窗口将被映射，X 服务器将生成 MapNotify。

如果窗口变为可见且没有记住先前的内容，X 服务器将窗口与其背景进行平铺（tile）。如果窗口的背景未定义，则不会更改现有的屏幕内容，X 服务器将生成零或多个 expose 事件。如果在窗口取消映射期间维护了备用存储（backing-store），则不生成 expose 事件。如果现在将维护备用存储，则始终生成全窗口显示。否则，可能仅报告可见区域。对于任何新的下级窗口，将进行简单的平铺和显示。

如果窗口是一个输入输出窗口（InputOutput window），`XMapWindow` 会在每个要显示的输入输出窗口上生成 expose 事件。如果客户端映射并绘制窗口且开始处理事件，则窗口会被绘制两次。为了避免这种情况，请请求 Expose 事件然后映射窗口，以便客户端像往常一样处理输入事件。事件列表将包含每个出现在屏幕上的窗口的 Expose 事件。客户端对 expose 事件的正常响应应该是重绘窗口。这种方法通常会导致更简单的程序，并与窗口管理器进行良好的交互。

`XMapWindow` 可能会产生 BadWindow 错误。

要提升窗口（raise），请使用 `XMapRaised`。

`XMapRaised(display, w);`

`display` | 指定与 X 服务器的连接。

`w` | 指定窗口。

`XMapRaised` 函数基本上与 `XMapWindow` 相似，它映射该窗口及其所有接收过映射请求的子窗口。然而，它还将将指定的窗口提升到堆栈顶端。更多信息请参见 `XMapWindow`。

`XMapRaised` 可能会产生多个 BadWindow 错误。

要映射指定窗口的所有子窗口，请使用 `XMapSubwindows`。

`XMapSubwindows(display, w);`

`display` | 指定与 X 服务器的连接。

`w` | 指定窗口。

`XMapsubwindows` 函数按照从上到下的堆叠顺序映射指定窗口的所有子窗口。X 服务器在每个新显示的窗口上生成显示事件。这比一个一个地映射多个窗口要高效得多，因为服务器只需要对所有窗口执行一次大部分工作，而不是每个窗口执行一次。

`XMapsubwindows` 可能会产生 BadWindow 错误。

## 配置窗口

Xlib 提供了用于移动窗口、调整窗口大小或更改窗口边框宽度的函数。要更改这些内容，请设置 `XWindowChanges` 的成员并在 ConfigureWindow 中设置相应的掩码。

```
/*窗口值掩码位 */
#define CWX (1<<0)
#define CWY (1<<1)
#define CWWidth (1<<2)
#define CWHeight (1<<3)
#define CWBorderWidth (1<<4)
#define CWSibling (1<<5)
#define CWStackMode (1<<6)
```
