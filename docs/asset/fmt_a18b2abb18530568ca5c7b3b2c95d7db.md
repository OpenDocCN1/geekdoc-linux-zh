# awk

字段编号。例如，输入行的第二个字段是 `$2`。如果你在 shell 程序中使用 `awk` 命令，字段（`$1,$2` 等）不会与 shell 的位置参数混淆，因为 `awk` 变量被括在在大括号 `{}` 中，这会让 shell 忽略它们。
