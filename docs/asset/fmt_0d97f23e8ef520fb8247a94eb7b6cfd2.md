## 使用数码相机

数码机的普及并不意外。它们易于使用、重量轻，并且能够产生可以立即共享的图像。然而，直到最近，数码相机和 Linux 还是不稳定的盟友。Fedora 现在提供了一个实用的程序，让使用数码相机成为一种轻松且无压力的体验。

> 注意 你必须有一台可以通过 USB 线连接到计算机的数码相机才能在 Fedora 中使用你的相机。使用“相机”下拉菜单中的“添加相机”工具配置 gtkam 以识别你的相机。
