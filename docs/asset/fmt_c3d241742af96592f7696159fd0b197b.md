### 注释
以双斜杠开头的行是注释。这意味着它们不会被执行，并且会被编译器忽略。注释旨在帮助你或查看你代码的另一个程序员解释发生了什么。注释有两种类型：`//` 用于多行注释，`/* */` 用于单行注释。

### <<
在这里使用的尖括号是插入运算符。这意味着尖括号后的任何内容都将插入到代码中：例如`std::cout`。在这种情况下，它们是 "Hello, world!"，在编译和执行代码时将显示在屏幕上。

```cpp
helloworld.cpp

#include <iostream>

int main() {

    //My first C++ program

}
```

```cpp
helloworld.cpp

#include <iostream>

using namespace std;

int main() {

    //My first C++ program

    cout <<;
}
```
