
- 调用时，颜色规格数组中从 0 到 `index` - 1 的元素可以假设位于屏幕色域内。此外，这些颜色规格已经是某种设备依赖的格式（通常为 `XmsRGB`）。如果对这些颜色规格进行了任何修改，它们在返回时必须处于初始的设备依赖格式。

- 调用时，颜色规格数组中由 `index` 参数指定的元素包含调用程序遇到的超出屏幕色域的颜色规格。此外，该颜色规格可以被假设为 `XmsCIEXYZ`。返回时，该颜色规格必须是 `XmsCIEXYZ`。

- 调用时，颜色规格数组中从 `index` 到 -1 的元素可能也可能位于屏幕色域内。此外，这些颜色规格可以被假设为 `XmsCIEXYZ`。如果对这些颜色规格进行了任何修改，它们在返回时必须是 `XmsCIEXYZ`。

- 传递给色域压缩程序的颜色规格已经调整为屏幕白点。这意味着该点颜色的白点就是屏幕白点。

- 如果色域压缩程序使用了颜色管理系统最初无法访问的设备无关颜色空间，请使用 `XmsAddColorSpace` 确保其被添加。

## 支持的色域压缩程序

以下方程对于描述色域压缩函数非常有用：

```
%CIELab-Psychometric-Chroma ~ sqrt(a_star^2 + b_star^2)
%CIELab-Psychometric-Hue ~ atan(b_star / a_star)
%CIELuv-Psychometric-Chroma ~ sqrt(u_star^2 + v_star^2)
%CIELuv-Psychometric-Hue ~ atan(v_star / u_star)
```

`Xms` 提供的色域压缩程序有：

- `XmsCIELabClip`: 通过减少或增加 L*a*b* 颜色空间中的亮度（L*），将超出色域的颜色规格带入屏幕色域。如果颜色规格的色度对于色相是最大的，则在保持色相的情况下，颜色将被剪裁至最大色度的 L* 坐标。参见 `XmsCIELabMaxC`。

- `XmsCIELabClip`: 通过减少色度将超出色域的颜色规格带入屏幕色域，同时保持色相在色域内。

- `XmsCIELuvClip`: 通过替换为落在色域内的 L*u*v* 坐标将超出色域的颜色规格带入屏幕色域，同时保持原始色相并使其向量坐标最短。

- `XmsTekHVCClip`: 通过减少或增加 `TekHVC` 颜色空间中的 Value 维度，直到颜色位于色域内，从而将超出色域的颜色规格。如果色度规格超过了特定色相的最大值，则在保持相同色相的情况下，颜色将被剪裁至代表该色相最大色度的 Value 和 Chroma 坐标。

```c
typedef Status (*XcmsWhiteAdjustProc) (ccc, initial_white_point, target_white_point, target_format, colors_in_out[], ncolors, compression_flags_return[]);
```

`ccc` 指定 `CCC`。

`initial_white_point` 指定初始白点。

`target_white_point` 指定目标白点。

`target_format` 指定目标颜色规范格式。

`colors_in_out` 指定一个颜色规范数组。`Pixel` 成员应被忽略，并且在返回时必须保持不变。

`ncolors` 指定颜色规范数组中 `XcmsColor` 结构体的数量。

`compression_flags_return` 返回一个布尔值数组，用于指示压缩状态。如果提供了非空指针且给定索引处的颜色被压缩，则应在该数组的对应索引处存储为 True；否则，不应修改该数组。

## 提供的白点调整程序

`Xlib` 提供的白点调整程序如下：

- `XcmsCIELabWhiteShiftColors`

- 此程序使用 CIE L*a*b* 色彩空间来调整颜色的色特性，以补偿源点和终点之间的色差。该程序简单地使用源白点将颜色规范转换为 `XcmsCIELab`，然后使用终点的白点将其转换为目标规范格式。不需要客户端数据。

- `XcmsCIEuvWhiteShiftColors`

- 此程序使用 CIE L*u*v* 色彩空间来调整颜色的色特性，以补偿源点和终点之间的色差。该程序简单地使用源白点将颜色规范转换为 `XcmsCIEuv`，然后使用终点的白点将其转换为目标规范格式。不需要客户端数据。

- `XcmsTekHVCWhiteShiftColors`

- 此程序使用 `TekHVC` 色彩空间来调整颜色的色特性，以补偿源白点和目标白点之间的色差。该程序简单地使用源白点将颜色规范转换为 `XcmsTekVC`，然后使用终点的白点将其转换为目标规范格式。该程序相对于之前描述的方法优点是尝试尽可能减少色调。不需要客户端数据。

# 颜色管理函数

从实现角度来看，这些白点调整程序使用一个白点将颜色规范转换为设备无关但依赖白点的色彩空间（例如 CIE L*a*b*、CIE L*a*b*、`TekHVC`），然后使用另一个白点将这些规范转换为色彩空间。换句话说，规范带着一个白点进入色彩空间但带着另一个白点出来，导致初始白点和目标白点之间产生色偏。假设为白点独立的 CIE 色彩空间是 CIE XYZ、CIE ZYZ 和 CIE XY。在开发颜色管理系统中最初无法访问设备无关色彩空间的自定义白点调整程序时，使用 `XcmsAddColorSpace` 确保其被添加。

例如，如果 `CCC` 指定了白点调整且客户端点与屏幕白点不同，则 `XcmsAllocColor` 函数将使用白点调整程序：

- 一次转换为 `XmsRGB`

- 第二次从 `XmsRGB` 转换

例如，假设规范在 `XmsCIEUv` 中，且调整程序为 `XmsCIEUvWhiteShiftColors`。在转换为 `XmsRGB` 期间，对 `XcmsAllocColor` 的调用会导致以下颜色规范转换：

- 使用客户端白点从 `XmsCIEUv` 转换为 `XmsCIELuv`

- 使用屏幕白点从 `XmsCIELuv` 转换为 `XmsCIEUv`

- 从 `XmsCIEUv` 转换为 `XmsCIEXYZ`（CIE u*Y 和 XYZ 是白点无关色彩空间）

- 从 `XmsCIEXYZ` 转换为 `XmsRGBi`

- 从 `XmsRGB` 转换为 `XmsRGB`

生成的 RGB 规范传递给 `XAllocColor`，`XAllocColor` 返回的 RGB 规范通过反转颜色转换序列转换回 `XmsCIEUv`。

## 色域查询函数

本节描述了 `Xlib` 提供的色域查询函数。这些函数允许客户端根据 CIE L*a*b*、CIE L*u*v* 和 `TekHVC` 色彩空间查询屏幕色域边界。还提供了函数允许您查询以下颜色的颜色规范：

- 白色（全强度红、绿、蓝）

- 红色（全强度红色，而绿色和蓝色为零）

- 绿色（全强度绿色，而红色和蓝色为零）

- 蓝色（全强度蓝色，而红色和绿色为零）

- 黑色（零强度红、绿、蓝）

传递给并从这些色域查询函数返回的颜色规范白点假设为屏幕白点。这是一个合理的假设，因为客户端正在尝试查询屏幕色域。

`Max` 和 `Min` 函数使用以下命名约定：

```
Xcms<color_space>QueryMax<dimensions>
Xcms<color_space>QueryMin<dimensions>
```

`<dimensions>` 由标识非固定色彩空间维度的字母或多个字母组成。例如，`XcmsTekHVCQueryMaxC` 是一个给定的色调和亮度，其对应的色度最大。

## 红、绿、蓝查询

为了获取黑色（零强度红、绿、蓝）的颜色规范，我们使用 `XcmsQueryBlack`。

```c
Status XcmsQueryBlack(ccc, target_format, color_return);
```

`ccc` 指定 `CCC`。`CCC` 的客户端白点和白点调整程序被忽略。

`target_format` 指定目标颜色规范格式。

`color_return` 返回零强度红、绿、蓝的格式。返回的规范白点假设为屏幕白点。像素成员未定义。

`XcmsQueryBlack` 函数返回零强度红、绿、蓝的格式。

为了获取蓝色（全强度蓝色，而红色和绿色为零）的颜色规范，我们使用 `XcmsQueryBlue`。

```c
Status XcmsQueryBlue(ccc, target_format, color_return);
```

`ccc` 指定 `CCC`。`CCC` 的客户端白点和白点调整程序被忽略。

`target_format` 指定目标颜色规范格式。

`color_return` 返回全强度蓝色的格式。返回的规范白点假设为屏幕白点。像素成员未定义。

`XcmsQueryBlue` 函数返回全强度蓝色的格式。

为了获取绿色（全强度绿色，而红色和蓝色为零）的颜色规范，我们使用 `XcmsQueryGreen`。

```c
Status XcmsQueryGreen(ccc, target_format, color_return);
```

`ccc` 指定 `CCC`。`CCC` 的客户端白点和白点调整程序被忽略。

`target_format` 指定目标颜色规范格式。

`color_return` 返回全强度绿色的格式。返回的规范白点假设为屏幕白点。像素成员未定义。
