
# 交换基础
交换系统通常执行三个基本功能：通过一个或多个独立通道将信号传输到目标方（地址、电话号码），并警报（被叫站）；它们通过交换连接建立整个通话期间的对话使用；并保持连接直到交换连接的建立和销毁。

## 寄存器电路
代码中的信息随后注册并在电路的存储元件中存储和保留，当需要时，以相同代码或不同代码取出信息。寄存器具有各种容量的存储元件，从几个到数百个不等。寄存器的一种常用形式是移位寄存器。这种寄存器能够将其存储的信息移动到不同位置，以表示代码示例中的数值。例如，在必要时，代码注册可以从个位移到十位。这类寄存器的优势在于数字计数；例如，部分乘积需要向上进位以进行加法。

在不需要实时通信的数据存储情况下，交换网络被用于存储消息的临时内存所取代。这种交换被称为存储和转发。

符号计算根据数学逻辑规则管理数字和变量的过程。变量被用于表示一个实数或一组实数，并具有精确的精度。数字可以进行加、减、乘、除。数值计算或符号计算涉及对符号的操控。例如，如果符号 `$x \cdot y$` 表示乘法，`$x/y$` 表示除法，那么使用

```
(3 + 5)/7 = 2
```

代表了一个结果为2的数值计算。在数学中，也可以使用符号来表示并对符号进行计算。例如，

```
ax + b = 0 （其中 a ≠ 0）
x = -b/a
```

在此计算中，使用了上述除法和减法的数学规则。符号 `x` 被视为待求解的未知数或变量，而 `a` 和 `b` 被视为参数且从未被使用。

在20世纪90年代，出现了可以根据数学规则操控符号的数学软件。这些也被称为符号计算包，没有小数表达式。这些软件包具有从符号中获得精确答案的能力。例如，

将 `x^2 = 2, x > 0`

输入到符号计算包中，软件将返回答案。

# 对称齿目 (Symetrodonta)

从从三生纪晚期到白垩纪的灭绝哺乳动物集合。它们的化石发现在中生代沉积物中。这些化石包含类似于啮齿类或老鼠的哺乳动物。

对称齿目的特征是一个独的特征：它们的牙齿群被排列在对称的上下颌中，相对牙齿之间没有间隙，用于压碎昆虫或切割蠕虫。对称齿目下齿缺乏一个允许对反复食物进行磨的盆。

对称齿目被归类为哺乳纲。在多样的物种中，有三个科值得注意：酮齿科 (`Ketodontidae`)，被认为是已知最早的哺乳动物；鼠足齿科 (`Spalacoodontidae`)，其特征是高度三角形的牙齿和最多样化的齿列。
