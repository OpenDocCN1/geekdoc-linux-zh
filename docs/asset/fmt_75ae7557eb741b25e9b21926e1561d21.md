## 从 Emacs 执行 shell 命令

如果你想在 emacs 内部执行 shell 命令，可以按下 `M-!`。这会让你进入一个 shell 提示符，你可以在其中输入命令并按回车执行。执行完成后，你将回到 emacs。如果你想运行一个命令并在缓冲区中显示输出，可以按下 `M-|x`。这会打开一个交互式 shell 运行命令，执行完成后输出结果到一个新的缓冲区。

## 撤销操作

如果你想撤销对缓冲区所做的某些更改，可以按下 `C-/u`。emacs 会撤销最后一次更改。如果你想撤销一个已经撤销的操作，可以按下 `C-x u`。如果你想恢复文件到某个之前的状态，可以按下 `C-x <`，然后输入时间戳。这允许你回溯到文件历史中的某个特定时间点。

## 保存文件

如果你想将缓冲区保存为文件，可以按下 `C-x s`。emacs 会在底部提示你输入文件名。输入文件名并按回车，文件就会被保存。如果文件已经存在，emacs 会询问你是否要覆盖。输入 `y` 覆盖，`n` 取消。如果你想另存为新文件，可以按下 `C-x C`。这会让你输入一个新文件名，并将当前缓冲区保存到新文件中，而保持缓冲区不变。

## 使用文件

如果你想加载另一个文件进行编辑，emacs 可以将新文件加载到当前缓冲区，也可以加载到一个新的缓冲区而保持当前缓冲区不变。emacs 还允许你将另一个文件的内容插入到当前缓冲区。要用另一个文件的内容替换当前缓冲区，可以按下 `C-x v`。emacs 会在命令行提示符处提示文件名。如果你不记得原始文件名或者文件名很长，可以使用 emacs 的补全功能。当 emacs 提示文件名时，你可以输入名称中的前几个字母然后按下 `<Tab>`。emacs 将扩展缓冲区以匹配具有这几个字母的文件。如果有多个文件匹配，emacs 会显示一个包含所有匹配文件的窗口，让你选择其中一个。要将文件检索到新缓冲区，请按下 `C-x f`。在命令行提示符处输入文件名。emacs 通常会用文件名命名缓冲区，但你可以通过按下 `<Esc><Enter>` 修改缓冲区名称，输入新名称后按回车。模式行会显示新名称。

但如果 emacs 自动保存了文件或者你保存了带有意外更改的文件呢？嗯，emacs 在第一次保存文件时会备份文件，但直到你保存文件才会创建。备份文件的文件名与文件名相同，但在开头和结尾各多了一个 `#`。因此，如果你的文件名为 `emacs-pract.1`，那么备份文件名就是 `#emacs-pract.1#`。如果你不小心用意外更改覆盖了当前文件，可能可以使用备份文件重新开始。

要将文件插入到当前缓冲区中，只需将光标移动到文件中所需的位置并按下 `<Ctrl-x><f>`。

## 光标定位

当你编辑文本时，需要将光标置置于你想要插入额外文本、删除文本、纠正错误、更改单词或在现有文本末尾附加文本的位置。你执行的命令被称为*光标定位命令*。

### 方向键

你可以在许多（但不是所有）系统上使用方向键来定位光标。很容易看出方向键是否工作：在打开一个已有文件的情况下启动 emacs，观察方向键会产生什么影响。你可能还可以使用 `<Page Up>` 和 `<Page Down>` 键。

## 添加文本

要向编辑缓冲区添加文本，你必须将光标置于你想要开始输入文本的位置。随后，你输入的任何普通文本字符都会被添加到缓冲区。如果你按下 `<Return>`，emacs 会在缓冲区中“打开”或添加一行。在开始添加文本之前，先将光标置置于你想要添加文本的位置。然后你只需输入文本即可。

要在当前行下方添加一行文本，请使用命令 `<Ctrl-o>`。这会在缓冲区中“打开”一行并允许你添加文本。在下面的示例中，你向某些现有文本添加了一行。

修改前：

+   - All jobs complete

- please call

- if you have any questions.

光标在第二行。按下 `<Ctrl-o>` 在该行下方添加一行或多行，然后输入以下内容：

+   - Lee Nashua

- 555-1837

修改后：

+   - All jobs complete

- please call

- Lee Nashua

- 555-1837

- if you have any questions.

尽管你只添加了两行，但你可以在每行末尾按下 `<Return>` 来添加更多行。自然地，你也可以通过不按 `<Return>` 只添加一行。
