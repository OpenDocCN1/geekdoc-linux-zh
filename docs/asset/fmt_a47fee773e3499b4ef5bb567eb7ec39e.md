# make

## 809

### 库维护

以下格式的目标名称指的是库中的成员，或以空格分隔的成员列表，`ar(1)` 库：

```
lib(member...)
```

你必须将库成员对文件的依赖作为 Makefile 中的显式项。此项可以使用模式规则处理：

```
lib(%s) : %s
```

其中 `%s` 是成员的后缀；对于对象库，该后缀通常为 `.o`。以下格式的目标名称指的是名为 `symbol` 的对象库成员：

```
lib($(symbol))
```

## 命令执行

命令行逐行执行，每个命令都有自己的进程或 shell。除非 Makefile 中有转义换行符，否则 Shell 命令是无效的。在执行之前会打印该行（宏展开后）。如果行以 `@` 开头，则抑制打印；如果 Makefile 中有 `.SILENT:` 项，则防止打印但不执行；包含 `$(MAKE)` 的行无论如何都会执行，包含 `@` 特殊字符的行会被打印。`-t` (touch) 选项在不执行任何规则的情况下更新文件的修改日期。当源码由多人维护时，这种行为可能是危险的。

`make` 使用 `-e` (出错时退出) 选项调用 shell。因此，分号分隔的命令序列中，后续命令的执行取决于前一个命令的成功。这种行为可以通过在命令行开头加 `-` 或通过编写返回相应非零状态的 shell 脚本来覆盖。

### Bourne Shell 构造

使用 Bourne shell 控制结构进行分支，使用以下格式的命令行：

```
if expression ; \
  then command ; \
      ... ; \
  else command ; \
      ... ; \
fi
```

尽管由多个输入行组成，但转义字符确保 `make` 将它们视为一条（shell）命令行。

## 810

使用 Bourne shell 控制结构进行循环，使用以下格式的命令行：

```
for var in list; \
  do command; \
  ...; \
  done
```

引用 shell 变量使用双美元符号 (`$$$`)。这种语法防止 `make` 对美元符号进行展开。

## 命令替换

要在宏中引入 shell 命令的标准输出，使用以下格式的定义：

```
MACRO:sh =command
```

命令只执行一次，标准错误输出被丢弃，换行符被替换为空格。如果命令退出状态非零，`make` 将停止报错。

要在宏引用中捕捉 shell 命令的输出，使用以下格式的引用：

```
$$(MACRO:sh)
```

其中 `MACRO` 是包含有效命令行的宏名。在这一行中，每当评估引用时都会执行命令。通过 shell 命令替换，引用会被替换为命令的标准输出。与规则中的命令不同，该命令不受宏替换；因此你不需要将美元符号 (`$`) 替换为双美元符号 (`$$$`)。

### 示例

下面的 Makefile 说明 `pgm` 依赖于两个文件 `a.o` 和 `b.o`，而它们又依赖于对应的源文件（`a.c` 和 `b.c`）以及一个公共文件 `incl.h`。

```
pgm: a.o b.o
  -o $(LINK.c) a.o b.o
a.o: incl.h a.c
  cc -c a.c
b.o: incl.h b.c
  cc -c b.c
```

# make 811

以下 Makefile 使用隐式规则表示相同的依赖关系：
```makefile
pgm: a.o b.o
	cc a.o b.o -o pgm
a.o b.o: incl.h
```
