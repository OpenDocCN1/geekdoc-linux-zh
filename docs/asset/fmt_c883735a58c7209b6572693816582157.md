
# Linux 源代码安装步骤

## 步骤 1
Linux 的源代码文件通常以 `.TAR.GZ` 或 `.TAR.BZ2` 的形式出现。两者都是压缩文件，包含“制作”应用程序所需的所有核心文件。从这个教程的开始，让我们在 Home 目录下创建一个新文件夹：`mkdir Vim`。

## 步骤 2
顺便说一下，Vim 是一款高级文本编辑器，我们将用它作为安装示例。进入新文件夹，`cd Vim`，然后在新 Vim 文件夹内，在终端中输入以下命令：`wget ftp://ftp.vim.org/pub/vim/unix/vim-7.4.tar.bz2`。

![](img/d501697c83491ed0bb4b382b0d28ef0a_51_0.png)

![](img/d501697c83491ed0bb4b382b0d28ef0a_51_1.png)

## 步骤 3
`wget` 命令从互联网获取内容，在此情况下是 Vim 的 `.BZ2` 文件。要检查文件是否下载成功，请输入：`ls`。根据 Mint 的文件系统颜色键，压缩文件应以红色显示。

![](img/d501697c83491ed0bb4b382b0d28ef0a_51_2.png)

![](img/d501697c83491ed0bb4b382b0d28ef0a_51_3.png)

## 步骤 4
现在我们需要解压文件内容，所以请在终端中输入：`tar -xf vim-7.4.tar.bz2`。注意：你可以输入 `tar -xf v` 并按 Tab 键自动填充剩余的文件名。

## 步骤 5
如果你再次输入 `ls`，你会注意到创建了一个新文件夹：`vim74`；在 Mint 中，文件夹以浅蓝色文本表示。为主应用程序创建根文件夹总是很有用的，这样当你通过这种方法升级应用程序时，每个版本都会有自己的文件夹。

![](img/d501697c83491ed0bb4b382b0d28ef0a_52_0.png)

## 步骤 6
输入 `cd vim74` 进入该文件夹，并再次输入 `ls` 查看其内容。可能会出现相当数量的文件；大多数是应用程序的核心文件，而另一些会被标记为 `README` 或 `INSTALL`。先阅读这些文件是明智的，因为它们提供了有关安装的重要信息。

![](img/d501697c83491ed0bb4b382b0d28ef0a_52_1.png)

## 步骤 7
安装的第一部分要求你输入 `./configure`。`./configure` 命令会检查系统中是否存在与该应用程序相关的缺失依赖项。如果你收到关于 C 编译器的错误，请输入：`sudo apt-get install build-essential`。记录显示缺少第三方应用程序 Ncurses。我们需要通过以下命令安装它：`sudo apt-get install libncurses5-dev libncursesw5-dev`。

![](img/d501697c83491ed0bb4b382b0d28ef0a_52_2.png)

## 步骤 8
根据应用程序的不同，你可能需要持续安装新的依赖项。每次安装新的依赖项后，重新运行 `./configure`，当它不再报告错误时，你可以继续安装的下一阶段。注意：你可能需要在线搜索某些错误信息。

![](img/d501697c83491ed0bb4b382b0d28ef0a_52_3.png)

## 步骤 9
成功运行 `./configure` 后，系统将创建 `Makefile`。这需要通过在终端中输入 `make` 来“制作”。根据应用程序的大小，这可能需要一段时间。

![](img/d501697c83491ed0bb4b382b0d28ef0a_52_4.png)

## 步骤 10
最后，你需要在终端中输入：`sudo make install`。这将安装应用程序，使其在系统中就绪可用。完成后，你可以执行该应用程序，在此情况下通过在终端中输入 `vim` 或通过 Dash 搜索它。

![](img/d501697c83491ed0bb4b382b0d28ef0a_52_5.png)

## 使用终端创建文件

使用终端，您可以创建文件夹、文件，甚至可以执行 Linux Mint 应用程序。事实上，即使您手边没有 GUI，您仍可以通过终端完成相同的工作。

### 更多终端操作

使用终端创建内容并不像第一眼看上去那样费力。是的，对于新手来说，终端可能看起来是一个令人望而生畏的地方，但一旦掌握，它其实非常直观。

#### 步骤 1
打开终端，确保您位于主目录（Home folder）。如果没有，请使用 `cd ~` 命令从您当前所在的位置返回主目录。

![](img/d501697c83491ed0bb4b382b0d28ef0a_55_0.png)

#### 步骤 2
让我们开始在主目录内创建一个新文件夹，并命名为 `Test`。您需要的命令是 `mkdir`。输入命令后，按下 `Enter` 键创建文件夹，然后输入 `cd Test` 并按下 `Enter`。这将更改目录（因此称为 `CD`）到 newly created Test 文件夹。

![](img/d501697c83491ed0bb4b382b0d28ef0a_55_2.png)

#### 步骤 3
您的命令行应该会切换到 Test 文件夹，如果您输入 `ls`（列出文件夹内容），会发现文件夹内没有任何内容，因为您刚刚创建了它。`mkdir` 命令相当自解释：Make Directory（创建目录）后接您选定的名称。

![](img/d501697c83491ed0bb4b382b0d28ef0a_55_1.png)

#### 步骤 4
要创建一个名为 `Test.txt` 的空文本文件，请在终端中输入：`touch Test.txt`。然后可以使用 `ls` 查看文件夹中的新文件。`Touch` 是一个标准的 Linux 命令，允许创建文件，而无需打开文本编辑器、保存文件，然后关闭编辑器。

![](img/d501697c83491ed0bb4b382b0d28ef0a_55_3.png)

#### 步骤 5
假设您现在想要创建一个包含一些内容的文本文件，我们将它命名为 Test2.txt。为此，请输入：`cat > Test2.txt`。这将创建文件 Test2.txt 并将终端置于编辑模式。

![](img/d501697c83491ed0bb4b382b0d28ef0a_56_0.png)

#### 步骤 6
您会注意到光标在 `cat > Test2.txt` 命令下方闪烁，没有通常的提示符。此编辑模式允许您输入文件将包含的文本。输入一些文本，然后按下 `Ctrl+D` 退出并将内容写入文件。

![](img/d501697c83491ed0bb4b382b0d28ef0a_56_1.png)

#### 步骤 7
当然，您不必总是使用终端向文件输入文本。Mint 附带了一个名为 Xed 的文本编辑器，类似于 Windows 的记事本。要在 Xed 中查看之前创建的文件，请在终端中输入：`xed Test2.txt`，并按下 `Enter`。

![](img/d501697c83491ed0bb4b382b0d28ef0a_56_2.png)

#### 步骤 8
Xed 是一个 GUI 应用程序，您可以使用应用程序的主窗口以及其顶部菜单栏中的 `文件 > 保存` 或 `文件 > 另存为` 功能来输入文本并相应地保存文件或任何文件。

![](img/d501697c83491ed0bb4b382b0d28ef0a_56_3.png)

#### 步骤 9
然而，如果您更喜欢继续留在终端中编辑/保存/创建文件，您可以使用 Nano。Nano 是一个简单的基于终端的文本编辑器。要在示例中尝试使用它，请输入：`nano Test2.txt`。屏幕底部有一个菜单。要在 Nano 中退出并保存任何内容，请按下 `Ctrl+X` 并按照屏幕上的说明进行操作。

![](img/d501697c83491ed0bb4b382b0d28ef0a_56_4.png)
