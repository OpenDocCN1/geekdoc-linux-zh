
从 Linux 2.6.26 开始，通用的 KGDB 支持已整合到 kernel.org 提供的 Linux 内核中。一旦按照前面的描述编译了带有 KGDB 支持的内核，就可以通过两个内核命令行参数在运行时配置 KGDB。`kgdboc` 用于指定使用的串口，`kgdbwait` 用于导致内核执行断点，从而允许调试器（gdb）获得控制权。`kgdboc` 的语法与第 14.2.5 节描述的 `kgdb8250` 相同，指定串口和波特率。独立使用时不带参数。与第 14.2.5 节的示例类似，Linux 2.6.26 及以上版本的 KGDB 内核命令行参数如下。注意这些参数的顺序很重要。在指示内核执行断点之前，必须先指定串口。

```
kgdboc=ttyS1,115200 kgdbwait
```

#### 14.3.1 gdb 远程协议

GDB 包含一个调试开关，允许我们观察开发主机上的 GDB 与目标之间使用的远程协议。这对于理解底层协议非常有用，对于排除表现异常或不正常的目标也同样。要启用此调试模式，请执行以下命令：

```
(gdb) set debug remote 1
```
