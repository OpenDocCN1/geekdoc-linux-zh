列表 15-2 显示了另一个 SQL 查询示例，这次使用了 `case` 语句，它类似于 `switch` 或嵌套的 `if/then/else` 编程结构。

# 列表 15-2: 一个 SQL 查询

```
SELECT ACCT_NO
FROM (
  SELECT
    CASE ACCT_NO WHEN 3 THEN 0
    ELSE ACCT_NO END AS ACCT_NO
  FROM TABLE1
)
AS NEW_TABLE;
```
