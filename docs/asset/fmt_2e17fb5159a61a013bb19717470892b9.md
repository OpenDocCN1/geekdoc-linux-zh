- `KDE 登录管理器` — 从`KDE`控制中心，你可以使用登录管理器（在`KDE`控制中心，选择“系统管理 -> 登录管理器”）来修改你的`KDE`显示管理器。你可以更改标志、背景、配色方案以及与登录界面视觉效果相关的特征。
