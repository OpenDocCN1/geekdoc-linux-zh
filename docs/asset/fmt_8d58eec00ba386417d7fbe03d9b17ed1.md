# systune
针对 `/proc` 文件系统的内核调优。它将之前保存在配置文件中的内核参数写入 `/proc` 文件系统。这使得可以在无需重新编译内核的情况下调整内核参数。`systune` 可以作为 `actsys(8)` 的替代方案。它在大多数守护进程和其他 `init.d` 脚本之后启动，因此可以作为“第二阶段”的 `systctl` 使用。

来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# sysutils
各种小型系统工具。这是一个包含以下小型工具的软件包：

- `procinfo` - 显示来自 `/proc` (v2) 的信息，
- `memset` - 测试系统内存是否存在错误 (v2.93.1)，
- `bogomps` - 在不重启的情况下显示当前的伪评分（bogus rating）（v1.2），
- `tofords` - DOS <-> Unix 文本文件 (v1.4)。

来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# sysvbanner
System-V banner 的克隆版本。以 System V banner 相同的方式（水平）显示“banner”。

来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# sysvinit
类 System-V 的 init。它是系统启动后运行的第一个程序，并一直作为 1 号进程运行，直到系统停止。它的工作是启动其他对系统运行至关重要的程序。所有进程都继承自 `init`。更多信息，请参阅手册页 `init(8)`。

来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# SysVinit
SysVinit 软件包包含一组控制系统最基本功能的进程。SysVinit 包含了 `init` 程序，这是 Linux 内核在系统启动时启动的第一个程序。随后控制所有其他程序的启动、运行和关闭。来自 Mandrake 9.0 RPM http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
