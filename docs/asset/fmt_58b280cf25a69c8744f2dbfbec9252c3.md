## 8.3.3 枚举和滥用 API

在许多情况下，我们的渗透测试目标是一个内部构建的闭源 Web 应用，它随带了许多应用程序编程接口（API）。这些 API 负责与后端逻辑交互，并为 Web 应用提供坚实的功能骨干。

一种名为表述状态转换（REST）的特定类型 API 被用于各种目的，包括身份验证。

在典型的白盒测试场景中，我们会收到完整的 API 文档来帮助我们完整映射攻击面。然而，在进行黑盒测试时，我们需要推导出目标。
