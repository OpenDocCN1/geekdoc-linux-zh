
# 前言

### 表 2 Solaris操作系统环境演进（续）

| 版本 | 新功能 |
| --- | --- |
| Solaris 2.4 (SunOS 5.4) | 本版本包含可插拔身份验证模型 (`PAM`)。`PAM` 提供了一个一致的框架，使访问控制应用程序（如登录）能够选择系统上任何可身份验证方案，而无需担心实现细节。（本书未包含文档）。此版本包含 `C2` 安全。（本书未包含文档）。针对 `SCSI` 磁盘的 `format(1)` 命令发生了变化。（本书未包含文档）。此版本包含了一种通过各种点对点连接提供 `IP` 网络连接的 `PPP` 网络协议产品。（本书未包含文档）。此版本包含了用于 `NFS` 的缓存文件系统 (`CacheFS`)。`CacheFS` 是一种通用的易失性缓存机制，通过使用小型快速的本地磁盘来提高某些文件系统的性能。此版本包含了新的 `NIS+` 设置脚本。与其使用单独的 `NIS+` 命令，使用 `nisserver(1M)`、`nispopulate(1M)` 和 `nisclient(1M)` 脚本可以让你更快速、更方便地设置 `NIS+` 域。通过这些脚本，你可以避免冗长的手动设置过程。 |
| Solaris 2.5 (SunOS 5.5) | 增加了用于 `Solaris` 软件安装的新 `Motif` `GUI`。（本书未包含文档）。 |
| Solaris 2.5.1 (SunOS 5.5.1) | `Telnet` 客户端升级到 `4.4 BSD` 版本。改进了 `rlogin` 和 `telnetd` 的远程登录能力。（本书未包含文档）。用户 `ID` 和组 `ID` 值的限制被提高到 `2147483647`，即有符号整数的最大值。`nobody` 用户和组 (`60001`) 以及无访问用户和组 (`60002`) 在之前的 `Solaris` 版本中保留相同的 `UID` 和 `GID`。 |
| Solaris 2.6 (SunOS 5.6) | `Solaris 2.6` 打印软件的更改比之前 `Solaris` 版本中的 `LP` 打印软件提供了更好的解决方案。你可以使用 `NIS` 或 `NIS+` 轻松地设置和管理打印客户端，实现网络系统和打印机的打印管理中心化。新功能包括重新设计打印包、打印协议适配器、捆绑的 `SunPrint™` 客户端软件以及网络打印机支持。`nisbackup` 和 `nisrestore` 命令提供了快速高效的方法来备份和恢复 `NIS+` 命名空间。新的补丁工具（包括 `patchadd` 和 `patchrm` 命令）用于添加和删除补丁。这些命令取代了以前随每个单独补丁发送的 `installpatch` 和 `backout` 命令。（参考《Solaris 高级管理员指南》）。新的 `filesync` 命令确保数据在便携式计算机和服务器之间自动移动。（本书未包含文档）。之前的平坦 `/proc` 文件系统被重构为目录层次结构，包含用于状态信息和控制函数的额外子目录。此版本还提供了一个路点设施，用于监控进程地址空间内数据的访问和修改。`adb(1)` 命令利用该设施提供断点。 |
|  | `UFS`、`NFS` 和 `CacheFS` 文件系统支持大文件。应用程序可以在 `UFS` 挂载的文件系统上创建和访问高达一个 `Tbyte` 的文件，在 `NFS` 和 `CacheFS` 挂载的文件系统上则受限于 `NFS` 服务器的限制。一个新的 `-mount` 选项可以禁用 `UFS` 文件系统上的大文件支持。使用 `-mount` 选项允许系统管理员确保无法安全处理大文件的旧应用程序不会无意中对大文件操作。`Kerberos` 身份验证现在使用 `DES` 加密来提高网络安全性。`NFS` 和 `RPC` 网络服务的内核实现支持一种基于泛义安全服务 `API` (`GSS-API`) 的新 `RPC` 身份验证变体。这种支持为未来 `NFS` 环境中更强的安全性提供了钩子。（参考《Solaris 高级系统管理员指南》）。`PAM` 身份验证模块框架允许你“插入”新的身份验证技术（参考《Solaris 高级系统管理员指南》）。字体管理器 (`Font Admin`) 允许为 `X Window` 系统轻松安装和使用字体。它支持多字节语言的 `TrueType`、`Type0`、`Type1` 和 `CID` 字体，并提供比较字体预览功能。它完全集成到 `CDE` 桌面中。通过 `X` 和 `Display PostScript` 支持 `TrueType` 字体。字体管理器允许将第三方字体轻松安装并集成到 `Solaris` 环境中。（本书未包含文档）。`Solaris 2.6` 操作系统符合 `2000` 年标准。它使用无歧义的日期并在适当的情况下遵循 `X/Open` 指南。（本书未包含文档）。`WebNFS` 软件文件可以通过 `NFS` 协议通过 `Web` 访问。该协议非常可靠，并在重负载下提供更高的吞吐量。（本书未包含文档）。 |
|  | `Java` 虚拟机 `1.1` 为 `Solaris` 操作系统环境集成了 `Java` 平台。它包含了 `Java` 运行时环境和开发 `Java` `Applet` 和应用程序所需的各种工具。（本书未包含文档）。 |
| Solaris 7 (SunOS 5.7) | 对于 `IA` 系统，配置助手 (`Configuration Assistant`) 界面是新引导系统（`Intel` 版本）的一部分。它确定系统中有哪些硬件设备，计算设备使用的资源，并允许用户选择启动设备。对于 `IA` 系统，`kdconfig` 配置鼠标、图形适配器和显示器。如果存在 `owconfig` 文件，`kdconfig` 会从中提取任何可用信息。此外，`kdconfig` 会检索 `defconf` 程序在 `devinfo` 树中留下的信息，并使用这些信息自动识别设备。（本书未包含文档）。此版本完全符合 `X/Open UNIX 95` 和 `POSIX` 标准。（本书未包含文档）。增加了 `Solaris 64` 位操作系统环境（仅限 `SPARC` 版本）（本书未包含文档）。`UFS` 日志改进了文件系统支持。轻级目录访问协议 (`LDAP`) 改进了名称数据库的管理。（本书未包含文档）。`Solaris Java` 开发包显著提高了应用程序的可扩展性和性能。动态重新配置显著减少了系统停机时间。`AnswerBook` 服务器在 `Web` 服务器上。（本书未包含文档）。增加了具有多脚本能力的 `Unicode` 区域并添加了六个新的 `Unicode` 区域。 |
|  | `RPC` 安全性增加了完整性和机密性。（本书未包含文档）。`Solaris` 通用桌面环境 (`CDE`) 包含新工具，可以轻松查找、操作和管理卡片、应用程序、电子邮件地址、文件、文件夹、主机、进程和 `Web` 地址。（本书未包含文档）。 |
| Solaris 8 (Sun 5.8) | `IPv6` 增加了地址空间并通过使用简化的头部格式进行身份验证和隐私、地址分配自动配置以及新的服务质量能力，改进了 `Internet` 功能。`Solaris` 操作系统提供了基于轻级目录协议 (`LDAP`) 的命名服务切换后端目录服务。（本书未包含文档）。`Solaris Java2` 开发工具包显著提高了应用程序的可扩展性和性能。（本书未包含文档）。`Solaris 8` 安装光提供了一个图形化、基于向导、由 `Java` 驱动的应用程序，用于安装操作系统和其他软件。（本书未包含文档）。`Solaris 8` 操作系统支持通用磁盘格式 (`UDF`) 文件系统，允许用户交换存储在光盘、磁盘、软盘、`DVD` 和其他光介质上的数据。`Solaris` 智能卡功能允许安全管理员通过要求用户使用智能卡进行身份验证来保护计算机桌面或应用程序。`PDA` 同步 (`PDA Sync`) 应用程序将来自桌面日历、桌面邮件、备忘录和联系人等应用程序的数据与用户个人数字助器 (`PDA`) 上类似应用程序的数据进行同步。（本书未包含文档）。 |
| Solaris 8 | `Solaris 8` 软件 `CD` 和语言 `CD` 包含对 `90` 多个区域的支持，涵盖 `37` 种语言。（书中未介绍。）<br><br>`Solaris` 通用桌面环境 (`CDE`) 包含新的且增强的功能，整合了易于使用的桌面生产力工具、`PC` 互操作性和桌面管理工具。（书中未介绍。）<br><br>`X Server` 升级到 `X11R.6` 行业标准，其包含提高用户生产力和移动性的功能，包括通过在任何桌面上的 `Web` 浏览器远程执行 `X` 应用程序。支持 `Xnerama`、色彩利用策略、`EnergyStar` 支持，以及针对开发工具套件的新 `API` 和文档。（书中未介绍。）<br><br>基于角色的访问控制 (`RBAC`) 允许系统管理员创建特定角色，通过这些角色为一个或多个用户分配特定任务的超级用户权限。 |
