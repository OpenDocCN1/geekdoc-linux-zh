## 控制中心中的 LOAD 向导

DB2 控制中心提供了 Load 向导，调用 Load 向导的步骤如下：

- 1. 在控制中心中，展开对象树，直到找到 Tables 文件夹。
- 2. 单击 Tables 文件夹。窗口右侧窗格（内容窗格）中会显示所有已存在的表。
- 3. 右键单击内容窗格中您想要的表，然后从弹出菜单中选择 Load。此时将打开 Load 向导窗口。

有关控制中心的详细信息，请参阅其联机帮助。
