
### 桌面环境安装

#### GNOME

在终端中通过 `apt` 安装 `gnome`：

```bash
sudo apt update
sudo apt install gnome
```

在终端中通过 `tasksel` 安装 `GNOME`：

要在终端中使用 `tasksel` 安装 `GNOME`，只需输入命令 `tasksel`。打开后，使用方向键找到 `GNOME`，然后按 `SPACEBAR`（空格键）对其进行选择，在该选项上标记一个星号（`*`）。接下来，使用方向键移动到“Ok”并按回车键开始安装。此过程简单高效，让你能够毫无烦恼地享受 `GNOME` 流畅且可定制的界面。

### 编程语言

编程语言是编写软件的系统，通过类型和错误处理等特征平衡了形式（语法）和意义（语义）。受计算机架构的影响，它们已从特定于硬件演变为抽象化，增强了简单性。编程语言涵盖了从命令式到面向对象的类型，在满足各种需求的同时，平衡了收益与权衡（例如简单性与性能的平衡）。这种演变反映在计算机科学中充满活力的研究和分类中，使编程成为一个充满活力的领域。

`Zig` 由 `Andrew Kelley` 创建，是一种紧凑的静态类型编译语言，旨在系统编程，定位为 `C` 语言的现代继任者。`Zig` 追求简单高效，摒弃了宏和预处理器，转而拥抱流控制、易用的函数调用和直接库导入。它通过编译时泛型和些许反射借鉴了新语言的优点，增强了灵活性。`Zig` 优先考虑安全性但不要求运行时检查，提供了可选类型和内置测试框架来在没有垃圾回收的情况下管理手动内存，使其与 `Go`、`Rust` 和 `Carbon` 等同类语言区分开来。

`Go` 由 `Robert Griesemer`、`Rob Pike` 和 `Ken Thompson` 在 `Google` 开发，是一种高级静态类型语言，类似于 `C` 语言，但增加了内存安全、垃圾回收和并发。它在简单安全的基础上蓬勃发展，是可扩展系统的理想选择。在 `Google` 支持下，`Go` 或 `Golang` 拥有健壮的标准库、内置并发和充满活力的生态系统。它的主要实现包括用于多种平台和 `WebAssembly` 的“`gc`”编译器，以及通过 `gofrontend` 的 `gccgo` 或 `gollvm`。`GopherJS` 甚至通过将 `Go` 编译为 `JavaScript` 将引入 `Web`。

`Rust` 由 `Graydon Hoare` 于 `2006` 创建，后来由 `Mozilla` 支持，是一种多功能编程语言，以强调性能、类型安全和并发而闻名，不需要垃圾收集。它独特的“借用检查器”（`borrow checker`）有助于管理内存和数据竞态。`Rust` 被 `Amazon` 和 `Google` 等科技巨头采用，甚至集成到 `Linux` 内核中，其在系统编程领域的应用脱颖而出。

`Lua` 是一种 `1993` 年诞生于巴西的多功能编程语言，以其高效和轻量而闻名。它是嵌入的理想选择，运行在跨平台解释器上并提供了简单的 `C API` 用于集成。由于其动态类型、自动内存管理和对多种范式的支持，它在脚本、配置和快速原型方面表现出色。

`OpenJDK` 是 `Java` 平台标准（`SE`）的免费开源版本，由 `Sun Microsystems` 在 `2006` 年发起并根据 `GPL-2.0` 许可（带有特殊例外）。它是爱好者和开发者推进 `Java SE` 及其相关项目的地方，提供了各种操作系统的最新 `OpenJDK JDK 21` 二进制文件。参与 `OpenJDK` 社区可以探索或贡献 `Amber`、`Loom`、`Panama`、`Valhalla` 以及 `Java` 的未来。对于实用的 `Java` 应用，`dev.java` 是你的首选。无论学习、下载还是贡献，`OpenJDK` 都体现了 `Java` 演进中的协作与创新。

### Rust

访问 `Rust` 官方网站 `https://www.rust-lang.org/` 了解关于 `Rust` 的所有信息。

在终端中通过 `curl` 安装 `Rust`：

只需输入这些命令：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

source "$HOME/.cargo/env"
```

### OpenJava

访问 `OpenJava` 官方网站 `https://openjdk.org/` 了解关于 `OpenJava` 的所有信息。

通过软件管理器获取 `DEB/FLATPAK` 软件包：

打开软件管理器并搜索 `OpenJava`。

点击 `OpenJava`，然后点击源选择框。

选择系统软件包（`System Package`）或 `Flatpak` 并点击安装。

在终端中通过 `apt` 安装 `OpenJava`：

只需输入这些命令：

```bash
sudo apt update
```

```bash
sudo apt install default-jre default-jdk
```
