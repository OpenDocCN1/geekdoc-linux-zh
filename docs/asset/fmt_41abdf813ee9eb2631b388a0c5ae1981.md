
你可以用数字、日期显示它，或者将列表保存到文件中。

你的`man`文档组织成一系列章节标题宏，带有它们的名称和正文。下面的模板让你了解如何组织你的`man`文档。这通常是Linux命令在线手册所遵循的组织结构。

```
.TH COMMAND Section -number

.SH NAME

命令及其功能的简要描述。

.SH SYNOPSIS

命令和选项。每个选项都括括号内。此章节有时被称为 SYNTAX（语法）。

.SH DESCRIPTION

命令和选项的详细描述。使用段落宏处理新段落：PP、LP 和 IP。

.SH OPTIONS

用于命令的选项。

.SH EXAMPLES

命令使用的示例。

.SH FILE

命令使用的文件。

.SH "SEE ALSO"

对其他文档或手册文档的引用。

.SH DIAGNOSTICS

任何异常输出的描述。

.SH WARNINGS

关于命令可能的危险用途的警告。

.SH BUGS

意料之外的功能和错误。
```

在章节正文中，你可以添加其他宏来实现特定的文本处理操作。你单独成行输入这些宏。某些宏也会接收参数。`.PP`宏开始一个新段落，通常用于显示选项。你将选项作为`.IP`宏的参数输入，随后的文本将与其缩进。`.I`宏给文本加下划线。`.B`宏会将文本加粗。`.B`和`.I`宏都将你想要加粗或下划线的单词作为参数。

| 宏 | 功能 |
| :--- | :--- |
| `.TH title-number` | 输入文档的运行标题。 |
| `.SH section-name` | 输入章节标题。 |
| `.B word` | 加粗单词。 |
| `.I word` | 下划线。 |
| `.IP option` | 格式化缩进段落；输入选项。 |
| `.PP` | 格式化段落；开始新段落。 |

## `man`目录

`man`工具会在专门为手册设置的系统目录查找特定的手册文档，例如`/usr/man`。`/usr/man`目录本身并不包含手册文档。相反，它包含了若干被称为“节目录”（section directories）的子目录，这些子目录又包含了文档。节目录的名字以`man`单词开头，并以节数字结尾。`man1`是手册中第一个节目录的名称。通常有大约7个节目录，从`man1`开始到`man7`结束。在您自己的手册页中，您可以根据需要创建任意数量的节目录，但始终必须包含一个`man1`目录。

节目录允许您为同一个命令或主题创建多个不同复杂程度和主题的文档。例如，第1节中关于`man`命令的文档仅提供概括性描述，而第7节中关于`man`命令的文档则列出了所有的`man`宏（macros）。文档通过节号进行识别，并存储在相应的节目录中。如前所述，文档的节号作为`.TH`宏的参数输入。若要从特定节检索在线文档，请在命令名之前输入节号。下一个示例显示了位于第三个节目录中的`bookrec`命令的文档。如果您没有输入节号，则假设为第1节。

### `man 3 bookrec`

在创建自己的手册目录时，您需要添加节目录。在节目录内部，您可以放置创建的`man`文档。至少，您需要一个`man1`节目录。`man`命令始终会查找节目录，如果没有指定，它将选择`man1`。在下一个示例中，用户在用户主目录下创建了一个名为`man`的目录，在此情况下为`/home/chris/man`。在该目录中，用户创建了一个名为`man1`的目录，并将`bookrec`文档拷贝到其中。

```
$ mkdir man
$ cd man
$ mkdir man1
$ cp ../bookrec.1 man1
$ cd man1
$ pwd
/home/chris/man/man1
$ ls
bookrec.1
```

### 应用在线手册：`man`

要让`man`工具从您自己的手册目录检索手册文档，可以使用`-M`选项配合该目录路径名。`-M`选项指示`man`在本地目录查找`man`目录。您在`-M`选项后输入本地目录的路径。在下一个示例中，用户在自己的目录中查找手册文档：`/home/chris/man`。

```
$ man -M $HOME/man bookrec
```

与其显式指定自己的`man`目录，不如通过将路径名添加到特殊变量`MANPATH`中来让`man`自动搜索它。您需要遵循与任何shell特殊变量相同的规则来分配新值。您可能想将此赋值放在初始化文件中，这样每次登录时，您的`man`目录都会被自动添加到`MANPATH`中。`BASH`和`TCSH` shell中的赋值语法有所不同。在`BASH` shell中（如下所示），任何新添加的目录之间都用冒号分隔：

```
$ MANPATH=$MANPATH:$HOME/man
```

在`TCSH` shell中（如下所示），任何新目录都将作为`TCSH` shell数组的元素添加。此类赋值应放在您的`.cshrc`初始化文件中。

```
% setenv MANPATH ($MANPATH) $HOME/man
```

使用`MANPATH`，`man`命令将搜索所有系统手册目录以及您自己的目录。如果您希望在查找在线文档时限制`man`只搜索您自己的`man`目录，只需创建您自己的Linux `man`命令的变体即可。在下一个示例中，用户创建了一个名为`myman`的shell脚本，包含`man`命令和带有指定本地`man`目录的`-M`选项。该脚本将在该目录下查找手册文档。

#### `myman`

```
man -M $HOME/man $1
```

```
$ myman bookrec
```
