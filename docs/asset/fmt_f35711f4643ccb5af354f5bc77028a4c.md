# 字母游戏 (wordplay)

字母变位 Wordplay 可以生成单词或短语的字母变位。例如，“Debian/Gnu Linux” = "blade in uniq","ad dun nix","dual begin in" 或 "lad begin uniq"。来自自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 单词 (words)

`words` 文件是 `us/share/dict` 下的英语单词词典。程序使用这个单词数据库来检查拼写。密码检查器使用它来寻找弱密码。来自自 Redhat 8.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 变通方案 (workaround)

1. 一种用于绕过或避免系统 bug 或误用的技术。从理论上讲，变通方案通常会被修复（fixes）所取代；但在实践中，客户经常发现自己很长时间在使用变通方案。“代码处理了输入中的 NULL 字符，所以我将其修复为将其解释为空格。”那可不是变通方案！它应该是用户为了实现某些目前无法正常的功能而应该采用的程序。一个假设性的例子：使用 `META-F7` 会导致 Wemax 4.33 崩溃，作为变通方案，你使用 `CTRL-R`，然后 `SHIFT-F5`，并删除剩余的部分。”来自 Jargon Dictionary http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 骨骼播放器 (workbone)

一个简单的基于文本的 CD 播放器。Workbone 是一个基于 curses 的简单 CD 播放器，通过 nook-lcd 键控制。可以使用 `quickly` 命令在播放 CD 前确定 CD 的内容。来自自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 进程管理器 (worker)

一个高度可配置的双窗管理器。Worker 是一个类似于 Amiga 上 DiOrOp 的管理器。它可以通过鼠标或键盘控制。按钮功能的数量或类型没有限制。文件通过扩展名和内容进行识别，识别你所显示的文件中的常见字节。支持拖放（Drag & Drop）。如果安装了 `xfi`，它可以在选项面板中快速预览图像。如果安装了 `xbase-clients`，则使用 message 显示一些信息性消息。来自自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 工作组 (workgroup)

一组本地连接的个体用户，通常通过同一个项目或组织内的某个部门连接。工作组的成员在处理数据时共享共同数据并相互协作。来自自 Redhat-9 Glossary http://www.tdlp.org/LDP/Linux-Dictionary/index.html

当前目录的另一个名称，或者用户当前正在工作的目录。来自自 I-gloss http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 工作目录 (working directory)

你正在工作的目录；也称为当前目录。来自自 Linux Guide @FirstLinux http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 工作日志 (worklog)

跟踪在项目上花费的时间。来自作者：Worklog 是一个帮助你跟踪自己时间花费的程序。我写这个程序是因为我有几个项目需要我记录时间表。它可以在这里花上 5 分钟处理各种杂项的行政任务。与其为每段微小的时间花费都调用编辑器编辑时间表，我在任何任务开始或更改时只需一两次击键即可完成。Worklog 就是一个实现此点的简单程序。来自自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

# 工作者 (workman)

用于在 CD-ROM 驱动器上播放音频 CD 的图形工具。WorkMan 可以从舒适的 OpenLook 界面播放并控制 CD。它可以从 CDDB 服务器获取 CD 信息，将这些信息存储在数据库中，并在以后插入 CD 时提取。来自自 Debian, 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

# 工作空间 (Workspace)

根窗口（Root Window）或桌面的另一个名称。来自自 I-gloss http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

在 X 系统中，所有窗口叠加其上的根窗口或桌面。来自自 Linux Guide @FirstLinux http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

# 工作站 (Workstation)

通常是比个人电脑（Mac 或 PC）更强大的计算机。工作站的特征是高分辨率显示器、大内存容量以及在 UNIX 或类似操作系统上运行的卓越多任务能力。来自自 Faculty–of-Education http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 蠕虫 (worm)

一种在网络上传播并自我复制的程序。它通过利用漏洞感染其他计算机。在理论上，蠕虫通常会被修复所取代；但在实践中，客户经常发现自己很长时间在使用变通方案。“代码处理了输入中的 NULL 字符，所以我将其修复为将其解释为空格。”那可不是变通方案！它应该是用户为了实现某些目前无法正常的功能而应该采用的程序。一个假设性的例子：使用 `META-F7` 会导致 Wemax 4.33 崩溃，作为变通方案，你使用 `CTRL-R`，然后 `SHIFT-F5`，并删除剩余的部分。”来自 Jargon Dictionary http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 蠕虫 (worm)

一种设计用于在内存或磁盘中查找其遇到的所有数据的程序。蠕虫可能会更改内存中的数据，通常会导致数据损坏。来自自 http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 蠕虫 (worm)

一种不感染其他程序的蠕虫。它通过制作副本并感染网络连接来传播，但不附加到其他程序；然而蠕虫可能会安装或破坏文件。来自自 http://www.tdlp.org/LDP/Linux-Dictionary/index.html

# 蠕虫
