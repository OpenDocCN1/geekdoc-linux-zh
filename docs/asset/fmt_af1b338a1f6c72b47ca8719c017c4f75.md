## 使用 Excel 电子表格计算基本统计量

本附录中的许多统计量都可以使用 Microsoft Excel 电子表格程序非常轻松地计算出来。本附录中的第一个表（表 I.1）显示了某班 28 名学生在两次测试中的分数。我们使用该表中的分数来演示如何使用 Excel 程序。您需要按照右侧示例所示，将学生姓名和分数输入到电子表格中。请注意，行以数字编号，列以字母编号。这些列字母和行号会自动出现，无法更改。
