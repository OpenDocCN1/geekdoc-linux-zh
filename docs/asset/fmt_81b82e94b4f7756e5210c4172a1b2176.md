
```python
try:
    from http.server import BaseRequestHandler, HTTPServer # Py 3
except ImportError:
    from BaseHTTPServer import BaseRequestHandler, HTTPServer # Py 2
class DictRequestHandler(BaseRequestHandler):
    def __init__(self, thedict, *args, **kwargs):
        self.thedict = thedict
        BaseRequestHandler.__init__(self, *args, **kwargs)

    def do_GET(self):
        key = self.path[1:] # 去掉开头的 '/'
        if key not in self.thedict:
            self.send_error(404, "No such key")
        else:
            self.send_response(200)
            self.send_header('content-type', 'text/plain')
            self.send_headers()
            resp = "Key: %s\n" % key
            resp += "Value: %s\n" % self.thedict[key]
            self.wfile.write(resp.encode('latin-1'))
```

## 使用示例
```python
d = {
    'name': 'Dave',
    'values': [1, 2, 3, 4, 5],
    'email': 'dave@dabeaz.com'
}
from functools import partial
serv = HTTPServer(('', 9000), partial(DictRequestHandler, d))
import threading
d_mon = threading.Thread(target=serv.serve_forever)
d_mon.start()
```

要测试此示例，请运行服务器并在浏览器中输入 URL `http://localhost:9000/name`。如果运行成功，你将看到字典的内容。

此示例还展示了如何让服务器使用额外参数来实例化处理程序的技巧。通常情况下，服务器使用一组预定义的参数传递给 `__init__` 来创建处理程序。如果你想添加额外的参数，请按所示使用 `functools.partial()` 函数。这会创建一个包含你的额外参数的可调用对象，并保留服务器预期的调用签名。

## `http.cookies` (Cookie)

`http.cookies` 模块为处理 HTTP cookies 提供了服务端支持。在 Python 2 中，该模块被称为 `Cookie`。

Cookies 用于为实现会、用户登录及相关功能的服务器提供状态管理。为了在用户的浏览器上放置 cookie，HTTP 服务器通常会在 HTTP 响应中添加一个类似于下方的 HTTP 头部：

```http
Set-Cookie: session=8273612; expires=Sun, 18-Feb-2001 15:00:00 GMT; \
path=/; domain=foo.com
```

或者，可以通过在 HTML 文档的 `<head>` 部分嵌入 JavaScript 来设置 cookie：

```html
<SCRIPT LANGUAGE="JavaScript">
document.cookie = "session=8273612;expires=Sun, 18-Feb-2001 15:00:00 GMT; \nFeb 17;path=/; Domain=foo.com";
</SCRIPT>
```

`http.cookie` 通过提供一个特殊的字典类对象简化了生成 cookie 值的任务，该对象存储并管理 cookie 值，被称为 marshals。每个 marshal 都有一个名称、一个值以及一组包含提供给浏览器的元数据的属性 `[expires, path, comment, domain, max-age, secure, version, httponly]`。名称是一个简单的标识符，因为 "name" 不同于 "expires" 或 "path" 等元数据名称之一。值是一个短字符串。要创建一个 cookie，只需像这样这样创建：

```python
c = SimpleCookie()
```

接下来，可以使用普通的字典赋值设置值（marshals）：

```python
c["session"] = 8273612
c["user"] = "beazley"
```

特定 marshal 的额外属性设置方式如下：

```python
c["session"] = "/"
c["domain"] = "foo.bar.com"
c["expires"] = "18-Feb-2001 15:00:00 GMT"
```

要将 cookie 数据输出为一组 HTTP 头部，使用 `c.output(method)`。

```python
print(c.output())
# 生成两行输出
# Set-Cookie: session=8273612; expires=...; path=/;...
# Set-Cookie: user=beazley
```

当服务器向 HTTP 服务器发回 cookie 时，它被编码为键=值对的字符串，例如 "session=8273612; user=beazley"。`expires`、`path` 和 `domain` 等可选属性不会被返回。该 cookie 字符串可以被解析为 `SimpleCookie` 对象。`http.cookie` 通过提供一个特殊的字典类对象简化了生成 cookie 值的任务，该对象存储并管理 cookie 值，被称为 marshals。每个 marshal 都有一个名称、一个值以及一组包含提供给浏览器的元数据的属性 `[expires, path, comment, domain, max-age, secure, version, httponly]`。名称是一个简单的标识符，因为 "name" 不同于 "expires" 或 "path" 等元数据名称之一。值是一个短字符串。要创建一个 cookie，只需像这样创建：
