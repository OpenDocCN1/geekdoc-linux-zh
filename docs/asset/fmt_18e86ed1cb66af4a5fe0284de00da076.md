### 选项 (Options)
大多数命令都有一个或多个可以添加的选项，以改变它们的行为。选项通常由单个字母组成，前面带有一个连字符。例如，你通常可以在单个连字符后组合多个选项。例如，`ls -la`列出当前目录的内容。`-l`请求详细的（长格式）信息列表，而`-a`请求以点（`.`）开头的文件。当shell选项由单词组成时，它前面通常带有双连字符（`--`）。例如，你可以使用许多命令的帮助选项，只需在命令行中输入`--help`。

> 你可以使用`--help`命令来查看它们支持的选项和参数。例如，`hostname --help`。

### 参数 (Arguments)
许多命令允许在输入某些选项后或在整个命令行的末尾输入参数。参数是额外的信息，例如文件名，可以被命令使用。例如，`cat /etc/passwd`在你的屏幕上显示`/etc/passwd`的内容。在这种情况下，`/etc/passwd`就是参数。

### 环境变量 (Environment variables)
shell将可能对用户shell会话有用的信息存储在所谓的环境变量中。环境变量的示例包括`$SHELL`（识别你正在使用的shell）、`$PS1`（定义你的提示符）和`$MAIL`（识别你的信箱位置）。本章稍后的“Shell环境变量”部分将提供更多信息。

你可以随时检查环境变量。输入`declare`来列出环境变量。或者你可以输入`echo $VALUE`，其中`VALUE`被替换为你想要列出的特定环境变量的值。

### 元字符 (Metacters)
这些字符对输出有特殊含义。它们可以用于将命令输出重定向到文件（`>`），将输出通过到另一个命令（`|`），以及在后台运行命令（`&`），或为文件命名。元字符将在本章稍后讨论。

# 从 Shell 运行命令

为了节省输入时间，shell有一些功能可以存储你想运行的命令、召回之前的命令并编辑命令。你可以创建别名（`aliases`），让你能够输入一个短命令来运行一个较长的命令。shell将之前输入的命令存储在历史列表中，你可以显示该列表并从中召回命令。你将在本章稍后部分看到它是如何工作的。

除非你特意切换到另一个shell，否则`bash`是你在Linux系统中使用的shell。`bash` shell包含了其他shell中提供的大部分功能。虽然本章的描述带你了解许多`bash` shell特性，但你可以通过输入`man bash`更多关于`bash` shell的知识，侧边栏“使用Shell获取帮助”向你展示了学习使用shell的其他方法。

# 定位命令

如果你知道包含要运行的命令的目录，运行它的的一种方法是输入该命令的完整路径。例如，你可以通过输入以下内容运行`/bin`目录下的`date`命令：

```bash
$ $PATH
/bin:/usr/bin:/local/bin:/usr/X11:/usr/X1R6/bin:/usr/home/chris/bin
```

当然，这可能并不方便，特别是当命令位于路径名很长的目录时。更好的方法是将命令存储在已知目录中，并将这些目录添加到shell的`PATH`环境变量中。路径由目录列表组成，对于你输入的命令按顺序缓存这些目录。要查看当前路径，请输入以下内容：

```bash
echo $PATH
```

结果显示了普通Linux用户的默认路径。列表中的目录由冒号分隔。大多数与Linux自带的命令存储在`/bin`、`/usr/bin`或`/usr/local/bin`目录中。虽然图形界面命令（用于GUI）包含在`/usr`中，但有一些特殊的X命令位于`/usr/bin/X11`和`/usr/X11R6/bin`目录中。显示的最后一个目录是用户家目录下的`bin`目录。

> 如果你想添加自己的命令或shell脚本，请将它们放在你的家目录中（例如对于名为`chris`的用户，是`/home/chris`）。在某些Linux系统中，该目录会自动添加到你的路径中，但在其他Linux系统中，你可能需要创建该目录或将其添加到`PATH`。只要你将具有执行权限的命令添加到你的`bin`（在本章稍后的“理解文件权限”部分进行了描述），你就可以通过直接在shell提示符处输入该命令立即开始使用它。

# 使用 Shell 获取帮助

当你开始使用shell时，它可能会令你感到畏惧。你看到的只有一个提示符。你怎么知道哪些命令是可用的，它们使用哪些选项，或者如何使用高级功能？幸运的是，有很多帮助可用。你可以查看以下几个地方来补充本章的内容：

- **检查 PATH**：输入`echo $PATH`。你会看到包含命令的目录列表。显示这些目录的内容列出了大多数Linux命令。（输入`help`来翻页列表。）
- **某些内置 shell 的命令**：它们没有出现在目录中。`help`命令列出了这些命令以及每个命令可用的选项。对于特定内置命令的帮助，输入`help command`，将`command`替换为你感兴趣的名称。
- **`--help` 命令**：许多命令包含一个`--help`选项，你可以获取有关如何使用命令的信息。例如，使用`date --help | less`。输出不仅显示了选项，还显示了你可以配合`date`的格式。
- **`man` 命令**：要了解更多关于特定命令的信息，输入`man command`。（替换`command`命令。）命令及其选项的描述出现在屏幕上。
- **`info` 命令**：`info`命令是另一个从shell显示命令信息的工具。`info`命令可以在节点层次中移动以找到有关命令和其他项目的信息。并不是所有命令在`info`数据中可用，但有时可以在那里找到更多信息。

如果你是`root`用户，包含管理命令的目录通常在你的路径中。这些目录包括`/bin`和`/usr/sbin`。（你可能需要带有`-l`或登录选项启动shell以将`/sbin`和`/usr/sbin`添加到`PATH`。）

路径顺序很重要。目录从左到右检查。因此，在这个示例中，如果`/bin`和`/usr/bin`目录中存在命令`foo`，则执行`/bin`中的那个。对于运行的另一个`foo`命令，你只需输入命令的完整路径或更改你的`PATH`变量。（更改`PATH`并向其添加目录将在本章稍后描述）

## 从 Shell 运行命令

由一系列命令组成的函数。这里是shell检查你输入的命令的顺序：

1. 别名 (Aliases)：通过`alias`命令设置的名称，代表特定的命令和一组选项。（输入`alias`查看设置了哪些别名。）通常，别名允许你为长而复杂的命令定义一个短名称。
2. Shell 保留字 (Shell reserved word)：shell为特殊用途保留的单词。许多你在编程类型函数中使用的单词，如`do`、`while`、`case`和`else`。
3. 函数 (Function)：在当前shell中执行的一组命令。
4. 内置命令 (Built-in command)：内置在shell中的命令。因此，该命令在文件系统中没有表示。你将使用的一些常用命令都是内置命令，例如`cd`（切换目录）、`echo`（将文本显示在屏幕）、`fg`（将后台运行的命令调至前台）、`history`（查看运行过的命令列表）、`pwd`（列出工作目录）、`set`（设置shell选项）和`type`（显示命令的位置）。
5. 文件系统命令 (File system command)：存储并从计算机文件系统中执行的命令（这些命令是由`PATH`变量的值指示的命令）。

要找到某个特定命令是从哪里获取的，可以使用`type`命令。（如果你使用的是`bash`以外的shell，请使用`which`命令。）例如，要查找`bash` shell的位置，输入以下内容：

```bash
$ type bash
bash is /bin/bash
```

尝试使用`type`命令输入以下几个命令以查看命令的其他位置：`which`、`case`和`return`。如果命令存在于多个位置，你可以添加`-a`选项以打印该命令的所有已知位置。

> 提示：有时你运行一个命令会收到错误消息，提示未找到命令或拒绝运行该命令。在第一的情况下，检查命令拼写是否正确以及它是否位于你的`PATH`变量中。在第二的情况下，命令可能在`PATH`变量中，但可能不可执行。为命令添加执行权限将在在本章稍后的部分介绍。

shell历史记录（`history`）是你之前输入过的命令列表。在`bash` shell中使用`history`命令，你可以查看之前的命令。然后，通过各种shell功能，你可以从列表中回溯单个命令行并按你的意愿修改它们。
