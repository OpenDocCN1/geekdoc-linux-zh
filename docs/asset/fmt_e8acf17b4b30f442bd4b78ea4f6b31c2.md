# 3D 和 2D 植被各有优劣

请注意，3D 植被会消耗大量的内存和渲染时间，因为每片叶子都被建模为几何体。不透明度映射背景（`Opacity-mapped entourage`）效率高得多，但仍然是平面的。在相机移动的动画中，3D 植被更具说服力。

# 光线追踪的反射与折射

到目前为止，你还没有在渲染图中看到过有说服力的玻璃表面。这是因为你制作的材质没有考虑到光从表面的反射或穿过半透明表面的光（折射）。为了模拟这种现象，你将使用光线追踪渲染器。（光线追踪器已内置 `VIZ` 多个版本，并用于 `Raytrace map` 或 `Raytrace` 材质的功能。）你无法在视口中看到光线追踪效果——它们必须经过渲染。

现在，你将使用光线追踪在表面上创建准确的反射。

物体中可以关注的一个元素是玻璃本身。目前玻璃看起来是完全透明的，但在现实生活中，玻璃会反射周围的环境。让发光物体更好的快速方法是使用 `Reflection` 通道。位图允许你反射一张通用照片，但它们仍有不足。在 `Reflection` 通道中使用的位图会在物体材质的发光部分反射位图本身。在现实世界中，物体不会反射通用物体（如天空或建筑）；它们反射的是房间内的实际物体。

如果你追求最大的精度，你会很高兴地发现可以反射房间内的实际物体。你可以使用所谓的 `Raytrace map`。`Raytrace map` 是一种程序化贴图，它根据从观察位置、反射表面和周围环境物体获取的信息组合，产生准确的反射。

# 仅在贴图级别使用光线追踪

或者，你可以使用 `Raytrace map` 代替 `Standard` 材质中的 `Raytrace map`。两种效果都是样的。

在当前的 `Villa Savoye` 模型中，玻璃是使用反射位图通过 `Standard` 材质创建的。在这里你将有机会学习如何将 `Raytrace map` 添加到 `Standard` 材质。在下面的练习中，你将使用 `Refractive map` 修改玻璃材质，然后通过快速渲染查看结果。

2. 滚动到 `Maps`，观察此材质的 `Reflection` 通道中有一个名为 `Lake_mt.jpg` 的位图。点击 `Reflection` 通道中的 `Map19` 按钮进入子贴图。
4. 点击 `Bitmap` 按钮。你将在第 5 步更改贴图类型。
