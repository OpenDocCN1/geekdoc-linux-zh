
```ksh
print "METHOD 1A:"
print "Before: counter is $counter"
(( counter = counter + 1 ))
print "After adding 1: counter is $counter"
```

```ksh
print "METHOD 1B:"

((counter++))
print "After adding 1: counter is $counter"
```
