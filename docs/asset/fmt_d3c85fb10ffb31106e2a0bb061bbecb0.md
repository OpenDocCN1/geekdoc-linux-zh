```
keytool -certreq -file Brian.csr
```

此命令将在当前目录创建一个包含某些数据的小文本文件。你可能不想花钱从 CA 处获得签名的证书，因此为了演示之目的，我们只需要导出我们的自签名证书。你也可以导出证书，以便其他用户将其导入到自己的密钥库中。
