
# 小波变换

存在许多不同的数学工具，用于得出给定信号的时频表示，每个工具都有其独特的优势和劣势。小波变换就是这样的时频分析工具。它的优势在于能够很好地处理瞬态高频现象，如突然的峰值或不连续性，以及信号的平滑部分。（例如，受损唱片声音中的裂纹，或音乐音符起始处的起音。）小波变换不太适合信号中谐波振荡的部分，对于这部分，傅里叶类型的方法更为合适。

小波的应用包括各种形式的数据压缩（如用于图像和指纹），数据分析（核磁共振、雷达、地震图和声音），以及数值分析（偏微分方程的快速求解器）。参见微分方程；积分变换；数值分析。

[D.J.]

## 瓦瓦石

一种含水的铝磷酸盐矿物，其组成为 Al₁₁(OH)₇(PO₄)₈ · 5H₂O，其中少量的氟和铁可分别替代羟基（OH）和铝（Al）。瓦瓦石结晶于斜方晶系。晶体呈短柱状至长柱状，但罕见。瓦瓦石通常以纤维状结构的球状聚集体以及壳状和钟乳石状团块的形式出现。瓦瓦石晶体颜色从白色或灰白色到深蓝、绿、黄、棕和黑色的深色调不等。瓦瓦石在欧洲和北美的许多地方都有发现；它在玻利维亚拉腊戈的锡矿脉中也丰富存在。参见磷酸盐矿物。

## 蜡，动物和植物

含有较高脂肪酸酯和长链物质适中等量的任何物质。由于定义允许将液态蜡称为蜡，加上少量固体酸，这个定义是不充分的。然而，因为它允许将液态蜡称为蜡，所以它是充分的。蜡在室温下是固体，但在低温下熔化。它们通常是混合物，可能含有高分子量酯、醇、醚、酮、烃类和类固醇，并且不是聚合物。参见酯。

实用的蜡配方使用蜡油，而不是化学性质来定义蜡。蜡在 68°F (20°C) 必须是固体；必须是结晶的；在 140°F (60°C) 以上熔化而不分解；在熔点以上具有相对低的粘度；具有强烈依赖于温度的一致性和溶解性特性；并且能够在轻压下抛光。

蜡来源丰富。它们已从细菌的外层、植物的根、茎、叶、果实和花、昆虫的分泌物、某些动物的皮肤和毛发、以及某些海洋和陆地动物的身体中分离出来。巴西棕榈蜡是从巴西棕榈树（Copernicia prunifera）叶片上的渗出物中提取的。烛台蜡是从 Euphorbia antisphracta（一种无叶沙漠灌木）茎部的涂层中获得的。蜂蜡是蜜蜂的分泌物。羊毛蜡是从羊毛中获得的。许多其他蜡在一段时间内具有重要的商业价值，但它们的供应或成本迫使它们退出市场。参见巴西棕榈蜡、脂肪和油。

## 蜡，石油

主要由石油润滑油分数的脱蜡生产的一种物质。它可能是结晶型或微晶型。石油蜡有广泛的用途。它用于涂层纸制品，与其他蜡混合制造蜡烛，用于电气设备制造，并作为许多产品（包括蜡和清漆）的添加剂。用于食品加工的石油石蜡，经过适当净化后，正被用作医药产品。参见石油脱蜡；石油加工；石油产品。

## 弱核相互作用

在自然界中扮演重要角色，在基本粒子和核物理中意义重大，并通过参与所有基本费米子以及不守恒宇称等特殊性质与其他此类相互作用区分开来的相互作用。弱力具有非常短的程（小于 10⁻¹⁷ 米），与强力和电磁力相比极其微弱，但可以通过其特殊特征与它们区分开。例如，根据目前的观点，所有物质由某些基本的自旋-1/2 成分组成，即夸克和轻子，统称为基本费米子。虽然只有夸克参与强相互作用，只有夸克和带电轻子（例如，e⁻ 和 e⁺）参与电磁相互作用，但所有的基本费米子，包括中微子，都参与弱相互作用。此外，强相互作用和电磁相互作用尊重空间反演对称性（即守恒宇称），并且也是粒子-反粒子（电荷共轭）对称的，而弱相互作用违反这两个对称性。参见基本相互作用；轻子；宇称（量子力学）；夸克；对称定律（物理学）。

弱相互作用根据参与弱反应的粒子是否发生一个电子单位的电荷变化，分为“带电荷”或“中性”。观察到的带电荷弱相互作用包括核β衰变和电子俘获，μ子对原子核的俘获，以及不稳定的基本粒子如 μ 和 τ 轻子，π、K 和粲介子，以及超子和粲重子的慢衰变。还有带电荷的中微子-核子和中微子-轻子散射反应。中性弱相互作用包括中微子-核子和中微子-轻子散射，以及可通过电磁相互作用发生的电子-原子核反应。参见重子；基本粒子；超子；介子。

弱相互作用研究中最重要的发展是基于局域规范不变性原理和自发对称性破缺原理创建了一个成功的理论。该理论提出了统一电磁相互作用和弱相互作用的单一基础，并且事实上，尽管观察到的强、电磁和弱相互作用特征存在显著差异，但类似类型的重要理论思想表明所有这些相互作用拥有共同起源。

## 弱相互作用大质量粒子 (WIMP)

一种假想的基本粒子，可能构成宇宙中的大多数物质，并且也在超对称理论中被预测存在。大多数物质只能通过其引力效应探测到；这种“暗物质”尚未被观察到发射、吸收或反射任何波长的光。暗物质的总量似乎大约是所有普通宇宙物质的十倍，是所有可见物质的一百倍左右。暗物质的性质尚不清楚，尽管正在进行许多实验试图直接或间接地发现它。参见宇宙学；宇宙。

基本粒子物理中当前几乎所有可用的数据都可以用一个称为标准模型的来解释，在该模型中，物质由夸克（质子和中子的构建块）和轻子（包括电子和中微子）组成，而强、弱和电磁力由光子（电磁力的载体）等粒子传递。然而，标准模型没有预测任何粒子——比如说，X——可能是暗物质。超越粒子物理标准模型的大多数努力都基于超对称的概念，而超对称的大多数版本都预测存在一种稳定的弱相互作用大质量粒子（WIMP），这将是一个X粒子的自然候选者。由WIMP构成的暗物质将是“冷”暗物质（CDM），CDM理论的一个版本已成为宇宙学中结构形成的标准理论。参见：[基本粒子](https://example.org/elementary_particle)；[标准模型](https://example.org/standard_model)；[超对称](https://example.org/supersymmetry)。

目前，关于星系、星系团以及宇宙更大尺度上存在暗物质的证据已大量涌现。距离星系较远的气体和小卫星的轨道速度与小距离处的相似，这表明星系中大部分的质量并不在中心（即大多数恒星所在的地方），而是在一个大致呈球形的暗物质晕中，该晕的范围可能延伸至光学上星系大小的十倍，且其质量至少是所有恒星质量的十倍。来自引力透镜观测的证据证实了这种暗物质晕的存在，显示较远星系的光线被较近星系的引力所弯曲。参见：[天体力学](https://example.org/celestial_mechanics)；[河外星系](https://example.org/external_galaxy)；[引力透镜](https://example.org/gravitational_lens)；[银河系](https://example.org/milky_way)。

关于星系团中存在暗物质也有大量证据。天文学家弗里茨·兹威基在1933年指出，一个邻近星系团中的星系运动速度极快，除非存在比其星光所指示的质量多得多的物质，否则它们无法被引力束缚在一起。后来发现其他星系团也是如此。随后，通过对星系团的X射线观测和引力透镜观测得出了类似的结论。

超对称是一种假设，认为已知的两类粒子——玻色子和费米子——之间存在某种关系。根据超对称理论，宇宙中每一种玻色子都必须存在一个具有相同电荷且与其他粒子相互作用非常相似的对应费米子。由于这些假设的超对称伙伴粒子尚未被发现，如果超对称理论是正确的，那么它们的质量必须大到目前的粒子加速器无法产生它们。迄今为止，支持超对称的证据仅是间接的，如果理论正确，许多超对称伙伴粒子应该在像正在瑞士日内瓦建造的大型强子对撞机（LHC）这样的加速器上产生。参见：[粒子加速器](https://example.org/particle_accelerator)；[量子统计](https://example.org/quantum_statistics)。

直接探测WIMP的努力基于探测它们与原子核的散射。WIMP也可以间接探测，例如通过寻找来自其湮灭的粒子。预计WIMP也会在这种加速器（如LHC）中由较重的超对称伙伴粒子的快速衰变产生，如果在此前的直接或间接搜索实验中未发现它们，这可能是它们首先被发现的地方。如果在LHC能量级别未能观察到超对称粒子，则意味着当前关于超对称的观点是错误的。[J.R.P.]

## 磨损

由于滑动接触而从固体表面去除材料的过程。这是社会制品（汽车、洗衣机、录音机、相机、服装）变得无用并需要更换的主要原因。磨损现象有少数几种用途，但在绝大多数情况下，磨损是一种麻烦，需要耗费巨大的人力物力资源来克服其影响。

粘着磨损是唯一的普遍形式的磨损，并且在许多滑动系统中也是主导形式。它源于这样一个事实：在滑动过程中，滑动表面之间会形成称为“结点”的粘着结合区域。如果这些结点中的一个没有沿着其原始界面断裂，那么其中一个滑动表面的一块材料就会转移到另一个表面上。通过这种方式，就形成了一个粘着磨损颗粒。这些颗粒最初附着在另一个表面上，但很快变得松动，并可能在滑动系统中分散。参见：[摩擦](https://example.org/friction)。

磨粒磨损是由坚硬、锋利的表面滑过较软的表面并挖出沟槽而产生的。磨粒可以是其中一个表面（如锉刀），也可以是第三方成分（如轴承中的沙粒，相互磨损材料）。与粘着磨损系数相比，磨粒磨损系数要大得多。因此，向滑动系统中引入磨粒颗粒可大大增加磨损率；例如，汽车设有空气和机油滤清器，以在造成损伤之前捕获磨粒。
