
# 巨共振

巨共振通常用三个特征量子数分类：`L`、`S` 和 `T`，其中 `L` 是轨道角动量，`S` 是固有自旋，`T` 是由共振振荡携带的异旋。数字 `L` 也是多极阶数，可能的值为 `L = 0`（单极）、`L = 1`（偶极）、`L = 2`（四极）、`L = 3`（八极），等等。自旋量子数 `S` 为 0 或 1。`S = 0` 的共振通常称为电的，而 `S = 1` 的称为磁的（`EL` 或 `ML`，其中 `L` 是多极阶数），源于这些巨共振具有强衰变模式的事实，涉及发射电的（对于 `EL` 共振）或磁的（对于 `ML` 共振）与共振具有相同多极阶数的多个光子。`S = 0` 的巨共振对应于核质量（或电荷密度）的纯空间振荡，而 `S = 1` 的对应于自旋振荡。异旋量子数 `T`，也是 0 或 1，决定了中子相对于质子的相对相位：在 `T = 0` 的同位标量巨共振中，中子和质子以同相振荡，而在 `T = 1` 或同向矢共振中，中子和质子以相反相位振荡。参见多极辐射；核磁矩。

这些共振被称为“巨”是因为它们具有巨大的强度，达到理论极限的 50–100%，集中在紧凑的能量区域。振荡能量是巨共振类型的特征，由恢复力和核质量决定；力源于核子之间的核吸引力，其中最重要的部分是与巨共振具有相同多极阶数的分量。巨电偶极（`E1`）共振是最古老和最好的核巨共振。它是伽马射线引发的反应中的主要特征。吸收伽马射线诱导巨 `E1` 振荡，在这种情况下，它通过发射中子而分解。此共振也是逆过程中的主要特征，其中通过质子和中子轰击核产生伽马射线。同位标量巨电 `E0`（电单极：`L = 0`, `S = 0`, `T = 0`）共振在能量上非常接近巨 `E1` 共振，而同位标量巨电 `E2`（电四极：`L = 2`, `S = 0`, `T = 0`）共振则稍低。两者都在高能 alpha 粒子的向前角度非弹性散射中被强烈激发。同位标量 `E0` 共振被称为呼吸模式，因为整个核子 undergoes 纯径向振荡，交替膨胀和收缩。同位标量 `E0` 共振能量对于确定核压缩率很重要。

在普通的核 beta 衰变中，核内的中子转变为质子，并产生电子和反中微子。在最简单类型的 beta 衰变之一，称为 Gamow-Teller 衰变中，转化的中子除了其自旋可能反转外，其他方面不受干扰。结果是核通常获得少量能量。如果 beta 衰变涉及更高的能量量子，能量足够大，可以驱动巨 Gamow-Teller 核共振，这是一种纯自旋振荡，其中中子自旋和质子自旋反相振荡（`L = 0`, `S = 1`, `T = 1`）。巨 Gamow-Teller 共振是 `(p, n)` 反应中的强特征，其中中子从被高能质子击中的核中射出。此反应通过自旋依赖的相互作用，以类似于 beta 衰变但能量转移大得多的方式，用质子替代核中的中子。

巨 Gamow-Teller 共振的特性在某些核天体物理问题中很重要。

对巨电偶极共振的研究已扩展到高能激发热核。这些研究提供了关于此类核（特别是其形状）特性的独特信息。形状敏感性源于变形核中的共振分裂。分裂的大小给出变形的大小，而分量的相对强度决定变形的方向：长椭圆形（足球形）或扁椭圆形（门把手形）。

巨共振在自然界中发生的能量核反应中起着重要作用。最好的例子之一是超新星爆炸。电子捕获反应的速率，它冷却参与爆炸的大质量恒星的核心并加速其引力坍缩，取决于巨 Gamow-Teller 共振的特性。由坍缩产生的冲击波强度与上文在巨同位标量 `E0` 共振背景下讨论的核压缩率直接相关。来自恒星中心区域的更高能量中微子向外传播，并通过激发各种巨共振的非弹性散射反应加热幔层中的核。自然界中发现的某些元素可能主要作为这些反应中的巨共振衰变产物产生。另见引力坍缩；中微子；中子星；核反应；核光谱；核结构；共振（量子力学）。

## 巨星

恒星演化中的一个中间状态，在此过程中，恒星在死亡前膨胀到巨大的比例。在恒星生命中最长和最稳定的阶段，恒星（如太阳）通过其致密、炎热核心深处的氢到氦的热核聚变获得能量。当氢燃料耗尽时，核心在引力作用下收缩和加热，新的氢在包围耗尽核心的壳层中点燃，恒星变得更亮、更大，表面更冷。较低的表面温度产生更红的颜色，因此常用术语红巨星。像太阳这样的恒星亮度增加 100 倍，半径增长近 50 倍。

实际上有两个分开的巨星阶段。第一个如上所述，当核心温度升高到氦点燃并聚变成碳时终止。此事件稳定了恒星，但当氦耗尽时，早期的行为会重复。恒星随后膨胀到巨大的比例，也许是两个天文单位（2.8 × 10^6 英里或 3 × 10^9 公里），变得比以前更红。它可能会脉冲，并且可以通过强风损失大部分质量。参见赫茨普龙-罗素图；恒星演化。

## 贾第虫病

由原虫寄生虫 *Giardia lamblia*（蓝氏贾第鞭毛虫）引起的一种疾病，特征为通常持续 1 周或更长的慢性腹泻。腹泻可能伴有一个或多个以下症状：腹部绞痛、腹胀、排气。

疲劳或体重减轻。粪便有恶臭，呈淡灰色。无症状的感染也很常见。

弓形虫病在世界范围内均有发生。由受污染饮用水引发的社区流行病中，多达 50% 到 70% 的居民已被感染。在饮用未处理溪流水的背包客和露营者中也出现过暴发病例。人类和动物（如河狸）粪便对溪水的污染被认为是水源性暴发中贾第鞭毛虫病例的来源。狗体内以及可能其他动物体内的贾第鞭毛虫种也被认为对人有传染性。通过人际传播导致的流行病发生在托幼机构（针对学龄前幼儿）和精神障碍者机构中。托幼机构中的婴儿和儿童比已进行如厕训练的较大儿童更容易被感染。参见“流行病学”。[D.D.J.]

## 赤霉素

一类高等植物激素家族的成员，其特征是具有 *ent*-赤霉烷骨架。其中一些化合物对植物生长和发育的许多方面具有深远影响，这表明其具有重要的调节作用。

赤霉素分为两类：19 碳赤霉素和 20 碳赤霉素。由 20 碳赤霉素形成的 19 碳赤霉素是具有生物活性的形式。赤霉素还根据羟基在 *ent*-赤霉烷骨架碳原子上的位置和数量而变化。羟基化对生物活性有深远影响。

赤霉素在调节高等植物发育过程中，最明确的作用之一是茎的生长。赤霉素诱导茎生长的细胞基础可以是茎部细胞长度的增加，或者是主要产生更多数量的细胞。外施赤霉素通常能促进休眠种子的发芽，这一特性表明赤霉素参与了打破休眠的过程。赤霉素也密切参与种子发芽的其他方面。外施赤霉素促进或诱导需要低温或长日照才能开花的植物开花。赤霉素可能不是开花激素或开花刺激物，因为不同反应类型中的开花刺激物似乎是相同或相似的。施用赤霉素通常会改变性别表达，通常导致雄花数量增加。参见“休眠”；“花”；“植物生长”；“种子”。

虽然与其他农药（如除草剂）相比，赤霉素在农业上的应用范围有限，但已经开发了几项重要用途，包括生产无籽葡萄。在花期施用赤霉素可增加浆果大小并减少浆果腐烂。赤霉素还用于提高酿造大麦麦芽的产量，并缩短麦芽化过程完成所需的时间。赤霉素在植物育种中也有显著应用。赤霉素在农业中的其他用途包括减少柑橘果实的环斑变色、增加甘蔗产量、促进果树坐果以及促进芹菜叶柄生长。参见“植物激素”。[J.D.Me.]

## 姜

一种重要的香料或调味品；也是获取该香料植物，*Zingiber officinale*，属于姜科（Zingiberaceae）。该植物原产于东南亚。它是一种直立的多年生草本植物，具有厚实、有鳞片状外皮、分枝的根茎，其中含有淀粉、树胶、一种赋予辛辣味道的挥发油树脂（姜油）以及赋予香味的精油。姜用于医学、烹饪制备以及调味饮料如姜汁汽水和姜汁啤酒。该植物种植于中国、日本、塞拉利昂、牙买加、澳大利亚（昆士兰州）和印度尼西亚。参见“姜目”。[PD.S.; E.L.C.]

## 银杏目

一个几乎灭绝的裸子植物（Pinophyta）目，现仅存一种活体物种，即银杏（*Ginkgo biloba*）。其扇形叶片类似于凤尾蕨的叶片。叶片具有二叉分枝脉（叉脉），通常或多或少有裂片（见插图）。

该物种是雌雄异株的；也就是说，雄性和雌性生殖结构分别出现在不同的植株上。*银杏* 被广泛种植在路边、庭院和城市公园中。参见“松门纲”。[A.Gr.]

## 银杏纲

一个主要灭绝的裸子植物（Pinophyta）纲。包含的目有芦木目、丽叶木目、阿贝尔目、盾叶木目、银杏目、瘦杉目、凯顿木目、奔巴木目和麻黄目。最古老的类群芦木目和丽叶木目生存于石炭纪；阿贝尔目从晚石炭纪延续到三叠纪；盾叶木目从二叠纪到侏罗纪；瘦杉目和凯顿木目从三叠纪到白垩纪；银杏目主要存在于从三叠纪到白垩纪时期，其中有一个物种 *Ginkgo biloba* 一直延续至今。麻黄目是唯一主要现生的类群，但其花粉化石记录始于晚三叠世。参见“凯顿木目”；“麻黄纲”；“银杏目”。
