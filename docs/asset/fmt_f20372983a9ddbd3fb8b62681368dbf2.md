在上面的代码中，`carousel` 对象被设置为循环。这意味着当到达图像列表的末尾时，它将简单地循环回到列表的开头，永远继续下去。下一部分定义了更新 `carousel` 的回调。它只是调用 `carousel` 的 `load_next()` 方法来显示列表中的下一张图像。在 `build()` 方法中，第一步是创建图像文件名列表。您可以使用之前建议的任一方法，或者您自己设计的方法。一旦有了那个列表，您就可以遍历每一个，并为它们中的每一个创建一个新的 `Image` 对象。这些新的 `Image` 对象使用 `add_widget()` 方法添加到 `carousel` 中。`build()` 方法的最后一步是使用 `Clock` 对象创建一个计划。使用 `schedule_interval()` 方法，这段代码将每 2.5 秒更换一次图像。这种方法作为起步很好，但如果您想要图像之间更有趣的过渡怎么办？这可以通过使用另一组称为 `Screen` 和 `ScreenManager` 的类来实现。如果您的图像列表没有占用太多 RAM，您可以简单地创建一个新的 `Screen` 对象

## 你能改用 PyGame 吗？

对于每张图像。以下代码演示了如何实现这一功能：

```python
import kivy
from kivy.app import App
from kivy.uix.image import Image
from kivy.uix.screenmanager import Screen, ScreenManager, FadeTransition
from kivy.clock import Clock

class PhotoFrame(App):
    def __init__(self):
        super(PhotoFrame, self).__init__()
        self.screen_manager = ScreenManager()
        self.transition = FadeTransition()
        self.screens = []
        self.curr_screen = None
        self.filelist = []
        self.build_filelist()
        self.build_screens()
        self.screen_manager.add_widget(self.curr_screen, 'current')
        self.root = self.screen_manager
        Clock.schedule_interval(self.my_callback, 2.5)

    def build_filelist(self):
        # Create the list of files in list filelist
        self.filelist = []
        for file in os.listdir('images/'):
            if file.endswith(('.jpg', '.jpeg', '.png', '.gif')):
                self.filelist.append('images/' + file)
        self.filelist.sort()

    def build_screens(self):
        # Create screens using filelist
        for file in self.filelist:
            screen = Image(source=file)
            screen.name = file
            self.screens.append(screen)
            self.screen_manager.add_widget(screen, screen.name)
        self.curr_screen = self.screens[0]

    def my_callback(dt):
        # Switch to next screen
        index = self.screens.index(self.curr_screen)
        index = (index + 1) % len(self.screens)
        self.curr_screen = self.screens[index]
        self.screen_manager.current = self.curr_screen.name
        self.screen_manager.transition = self.transition
        self.screen_manager.switch_to(self.curr_screen, direction='left')

if __name__ == '__main__':
    PhotoFrame().run()
```

如前所述，与之前的示例相比，创建屏幕并添加图像的过程要复杂一些。当你遍历图像文件列表时，需要创建一个新的 `Image` 部件。然后创建一个新的 `Screen` 部件，并将 `Image` 部件作为子部件添加进去。最后一步是需要将这个新的 `Screen` 部件添加到类顶部创建的 `ScreenManager` 对象中。我们重用 `schedule_interval` 方法，使屏幕每隔 2.5 秒进行切换。不过，回调函数需要修改。`ScreenManager` 有一个名为 `current` 的属性，用于标识当前显示的屏幕。当你更改由 `current` 属性标识的内容时，两张图像将通过在创建 `ScreenManager` 对象时定义的过渡方法进行切换。如果你使用的是 Kivy 的最新版本，有一个名为 `switch_to` 的新方法可用。在这种情况下，你不需要将 `Screen` 对象作为部件添加到 `ScreenManager` 对象中。`switch_to` 方法会移除当前显示的屏幕并添加新屏幕，同时应用正在使用的过渡方法。树莓派仓库中可用的 Kivy 版本较旧，因此我们使用了较旧的屏幕管理方法。之前的示例使用 `FadeTransition` 方法在屏幕之间进行切换。其他可用的过渡方法包括 `NoTransition`、`SlideTransition`、`SwapTransition`、`WipeTransition`、`FadeToTransition` 和 `RiseInTransition`。如果你希望图像显示拥有更多样化的效果，可以通过更改 `ScreenManager` 对象的 `transition` 属性来改变每张照片的过渡方法。

这段代码仅用于显示图像，但这并不是你能做的唯一事情。你还可以创建一个交互式相框，用它来操作图片。如果你使用触摸屏作为显示设备，上述代码允许你通过左右滑动来显示其他图像。如果你移除 `Clock.schedule_interval` 命令，除非通过滑动更改当前显示的图像，否则图像显示将保持静止。此外，还有一个名为 `Scatter` 的部件，可以在将图片添加到屏幕对象之前将其加载。`Scatter` 类允许你使用多点触控来旋转、拉伸或缩小图像。如果你想创建一个相册应用程序而不是相框显示，这可能会非常有用。希望这能激发你对这个强大框架所能实现的功能产生兴趣。
