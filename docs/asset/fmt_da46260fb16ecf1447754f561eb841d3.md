本节目前主要处理标准输出的重定向。重定向标准输入远没有重定向输出那么有用，但可以使用如下结构来实现：

```
cat my file

cat my marker

> another line from the keyboard
> my marker [该标记对应的代码结束了内联重定向].
```

除了重定向到文件和过滤器（如上例所示）之外，还可以将输出重定向到/从设备及其他特殊文件。以下是一些示例。

输出重定向到设备文件的示例。以下命令显示根终端 `/dev/tty4` 上的文件列表：

```
dir > /dev/tty4
```

重定向到 "FIFO" 文件的示例。此命令向 `icq` 用户显示消息 "you are lucky"（假设你已使用 `licq` 程序连接到 `icq` 服务器）：

```
echo message 77777777 > /tmp/licq_fifo
```

上述操作之所以有效，是因为你 `licq` 目录下的 `licq_fifo` 文件是一个“特殊的”（先进先出）队列文件。还有比向漂亮的 `licq` GUI 前端发送消息更有用的什么呢？例如，你可以写一个脚本，通过相同的消息给许多用户留深刻印象：

```
#!/bin/bash
echo message UIN: $1 Message: $2 Times: $3
# 该命令将“在线、隐身”状态置入 licq。
echo status "command" > /tmp/licq_fifo
c=4
while [ $c -le 3 ];
do
  echo message $1 $2 > /tmp/licq_fifo
  c=expr $c - 1
  echo $c ""
done
echo "status offline" > /tmp/licq_fifo
echo "all done"
```

得益于智能的 `licq` 通信模型（`fifo` 文件）和简单的文件重定向，上面的示例可以让你了解如何使用 `licq` 进行自动化操作。

### 4.4.8 特殊字符（元字符）

通常情况下，这些字符对 shell 有特殊含义：

`\ < > | ; <Space> <Tab> ( ) { ? $ ^ & * = `

以下是其中一些字符的含义：

- `+` 和 `' '` 用于引用，之前已描述过。
- `<` 和 `>` 用于输入/输出重定向，之前已描述过。
- `|` 管道将管道符号 `|` 左侧命令的输出传递到管道符号右侧命令的输入。
- `;` 分隔写在单行的多个命令。
- `<Space>` 和 `<Tab>` 分隔命令。
- `<Newline>` 完成一个命令组合。
- `( )` 包裹要在单独 shell（子 shell）中启动的命令 组。例如：`( dir )`。

- `{ * }` 包裹一组由当前 shell 启动的命令。例如：`{ dir }`。它需要空格。
- `&` 导致前面的命令在后台执行（即异步执行，作为其自身的独立进程），这样下一个命令就不必等待其完成。
- `*` 当执行文件名时，它匹配除带点以外任何文件名（或文件名的任何部分，初始部分除外）。
- `[` 当执行文件名时，匹配 `[]` 内部的任何单个字符。
- `*[` 当执行文件名时，它匹配 `[]` 括号之外的任何单个字符。
- `&&` 是连接两个命令的“与”逻辑。`command1 && command2` 只有在 `command1` 以状态 0（无错误）退出时才会执行 `command2`。例如：`cat file1 && cat file2` 只有在 `file1` 成功时才显示 `file2`。
- `||` 是连接两个命令的“或”逻辑。`command1 || command2` 只有在 `command1` 以非零状态（有错误）退出时才会执行 `command2`。例如：`cat file1 || cat file2` 只有在 `file1` 未成功时才显示 `file2`。
- `=` 给变量赋值。示例命令：

```
variable=value
```

使用：

```
echo $*
```

- `$` 跟在要展开的变量名之前。这些变量要么使用 `=` 赋值，要么是预定义变量之一（可以赋值为）：
    - `$0` 正在执行的 shell 或 shell 脚本的名字。
    - `$#` 传递给命令的位置参数数量。
    - `$1` 传递给命令的第一个位置参数的值。`$2` 传递给命令的第二个参数，依此类推。
    - `$*` 展开为传递给命令的所有位置参数。
    - `$@` 展开为传递给命令的位置参数，在使用 `"$@"` 时每个参数会被单独引用。

如果你真的需要更多信息，请查看 `man bash`。

# 4.5 软件包安装与 rpm 包管理器

## 4.5.1 如何安装从网上下载的程序？

答案取决于你下载的是哪种包。如果你以 Red Hat 二进制包 `*.rpm` 的格式下载程序（如果有选择，我会选择这种格式），就可以避免许多安装上的头疼问题。

### 4.5.1.1 安装 RedHat 二进制包 (*.rpm)

如果你想安装 RedHat 二进制包 (`*rpm`)，可以使用命令行或 GUI 工具。使用命令行工具是因为它快速且无故障。RedHat 软件包管理器安装工具称为 `rpm`。首先我读取包内容的信息（可选）：

```
rpm -qpi my_new_file.rpm
```

此命令查询尚未安装的包（选项 "p"），以便显示包包含的信息（选项 "i"）。如果我想安装程序，运行（以 root 身份）：

```
rpm -dhv my_new_file.rpm
```

上述命令执行了安装工作。它运行 `rpm` 并告诉它安装该包（模式 "i"，必须是横杠后的第一个字母），同时在屏幕上打印比平时更多的信息（选项 "h" = 显示解压进度，选项 "v" = 详细模式）。

如今 `rpm` 被认为是一个非常智能的软件管理器。如果其中任何一个失败了，可能需要阅读 `README` 或安装文件（如果环境提供了新程序的话）。某些程序可能需要对环境自定义（例如定义路径）或安装：

- 安装失败是因为已存在相同版本的包，且版本冲突。解决方案：升级包 `rpm -Uvh myfile.rpm`。
