
# Linux 词典

## APM (高级电源管理)

一种行业标准，允许系统处理器和各种组件进入低功电模式，包括挂起、睡眠和关机。APM 软件对于移动设备尤为重要，因为它可以节省能量。来自 I-gloss

http://www.tld.org/LDP/Linux-Dictionary/index.html

## apmd

APMD 是一组程序，用于控制大多数现代笔记本电脑中的高级电源管理守护进程（daemon）和 deitiis 工具。APMD 可以监控你笔记本电脑的电池，并在电量低 {时向你发出警告。APMD 还能在挂起之前关闭 PCMCIA 接口。如果你需要在笔记本电脑上控制系统，请安装 `apmd` 包。来自 Mandrake 0.9 RPM

http://www.tld.org/LDP/Linux-Dictionary/index.html

## apmd

用于笔记本电脑的高级电源管理 (APM) 实用程序。电源管理 (APM) 支持提供了对电池状态信息的访问，并根据你的笔记本电脑和 APM 的实现，可能帮助你节省电力。`apmd` 程序还允许在发生 APM 事件时运行任意程序（例如，当你挂起时可以弹出 PCMCIA 设备，或在连接电池时更改硬盘超时时间）。此包包含 `apmd(8)`，一个用于记录和处理 APM 事件的守护进程；以及 `apmd(1)`，一个提供内核中信息的客户端。最近的 Debian 内核使用可读格式的 `/proc/apmd`。内核中的 APM 驱动程序会向你通知事件。如果你想启用该驱动程序，需要在启动内核时带有 `apm=on` 选项（你可能需要将其添加到命令行中）。来自 Debian 3.0r0 APT

http://www.tld.org/LDP/Linux-Dictionary/index.html

## app

`/ap/` n. "应用程序"（application program）的缩写，与系统程序相对。Apps 是系统厂商倾向于开发者为其环境创建的内容，以便他们可以卖出更多硬件。黑客倾向于不将他们运行的东西视为 apps；因此，阻碍性能的包括程序、编辑器、游戏和消息系统，例如一个用户可能会认为所有这些内容都是 apps。（广义上，一个 app 通常是执行某些定义定义任务（如“文字处理”）的自包含环境；黑客则倾向于使用更具通用性的工具。）参见杀手级应用（killer app）；相反工具，操作系统。来自 Jargon 词典

http://www.tld.org/LDP/Linux-Dictionary/index.html

## append mode

在字符、行或文件的之后或末尾放置。在 vi 编辑器中，某些命令允许你向文档中追加文本。在 Bourne & shell 中，符号 `>>` 允许你将内容追加到现有文件末尾（如果文件不存在则创建一个新文件）。来自 Linux Guide @FirstLinux

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## append Symbol

在 vi 中，允许你在文件中现有内容之后输入新文本的模式；通过按 ESC 键结束此模式。来自 Linux Guide @FirstLinux

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## >

`>` 字符（即 `>>`）。它用于将命令的输出发送到文件，并追加到文件末尾，而不是替换现有内容。例如，`ls >> output.txt` 将当前目录列表发送到名为 `output.txt` 的文件，并将其添加到文件末尾。来自 I-gloss

http://www.tld.org/LDP/Linux-Dictionary/index.html
