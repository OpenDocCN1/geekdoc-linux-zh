## 管理内存

内存是计算机中最重要的硬件组件之一。所有应用程序都需要内存。从广义地说，内存分三个层面管理：硬件、操作系统和应用程序。硬件层内存管理涉及存储数据的电子设备，包括 RAM 和内存缓存。在操作系统中，必须为用户程序分配内存并在不再需要时回收。此外，操作系统可以预测硬件拥有更多内存，并且每个程序都在使用特定的内存；这些都是虚拟内存系统的特征。

应用程序管理是从有限的资源为程序对象和数据结构提供内存，并在不再需要时回收。由于应用程序无法预测变化的内存需求，以下是 Linux 操作系统中帮助高效管理内存的命令和技术：

- `top`
- `vmstat`
- `free`
- 需求分页
- Linux 页缓存

### 理解请求分页技术

请求分页是一种在计算机中实现虚拟内存的技术。Linux 使用分页技术为虚拟内存加载计算机进程的可执行映像。

### Linux 页缓存

页缓存是存储在内存中的物理页的缓存。Linux 页缓存的作用是加速对磁盘上文件的访问。Linux 页缓存读取内存映射文件并将其存储在它们的页缓存中。如果页面存在缓存中，则易于读取；如果不存在，则从持有映像（可执行文件）的文件系统中将其调入内存。Linux 为内存分配一个物理页并从磁盘上的文件读取该页面。在学习了管理内存之后，让我们学习在 Linux 中管理进程。

## 进程管理

进程是指正在执行的程序。在简单的情况下，单个进程可能与单个用户的作业相关。进程管理涉及分配给进程的进程（任务或作业）的管理。多处理是指多处理器系统同时执行两个或多个进程的过程。在分时系统中，用户的程序位于计算机的内存中。每个用户为其程序分配了部分 CPU 时间。当进程被提交给 CPU 时，它可能处于三种状态之一：

- 运行（Running）：当进程的序列由处理器执行时，进程处于运行状态。
- 就绪（Ready）：如果满足进程处于运行状态的所有条件并正在等待处理器，则进程处于就绪状态。
- 阻塞（Blocked）：当进程在继续执行之前等待事件发生时，进程处于阻塞状态。

让我们进一步学习 Linux 中的进程调度。

## 进程调度

进程调度意味着对作业进行优先级排序并在适当的时间处理新作业。当用户作业提交时，系统会记录其到达以及进程是 CPU 密集型还是 I/O 密集型。调度技术通过考虑所有这些因素。调度器执行以下操作：

- 允许创建保存在内存中的进程的新副本
- 帮助确定进程提交到完成之间的总时间以及进程在队列中等待的总时间
- 接收中断并将其返回相应的内核子系统
- 向用户进程发送信号
- 管理定时器（用于设置计算机硬件中的时间）
- 在进程执行结束时清理资源

调度器还支持动态加载模块。这些模块代表在内核启动执行后可以加载的功能。这种可加载模块功能被虚拟文件系统和网络接口使用。

## 虚拟内存

虚拟内存包含其当前执行的映像（例如 `bash`）的信息，并包含指向 `vm_area_struct` 数据结构的指针。每个 `vm_area_struct` 数据结构包含虚拟内存的起始和结束位置，以及进程对内存操作集的访问权限。在虚拟内存中，所有地址都是虚拟的，而不是物理的。进程将这些地址转换为物理地址。之后，处理器使用操作系统维护的表集信息来执行任务，例如执行进程。每个进程都有一个页表，根据 VPN 的偏移将进程的虚拟页帧号（VPN）转换为物理地址。
