
功能被表示为一个层级分解，其中系统或组织拥有一个顶层功能。顶层功能被划分为一组子功能，这些子功能使用与顶层功能相同的输入并产生相同的输出。然后，这些子功能中的每一个可以进一步划分，分解过程可以持续进行，直到在有用的范围内。

功能分析图可以表示功能分解中任何部分内部功能之间的数据或项目流动。随着对第一次及后续功能分解的检查，常见的是一个功能产生的输出在系统或组织边界之外没有用处。其他功能需要这些输出以产生所需和预期的外部输出。

处理指令是功能分析图中出现的第三个要素。这些指令包含了功能将输入转换为输出所需的信息。

第四个要素是控制流，它按顺序终止和激活功能，从而使过程既高效又有效。

### 反馈与控制

反馈在功能分析和建模中起着重要作用。反馈和控制是将输出的实际特征与该输出的期望特征进行比较，目的是调整将输入转换为该输出的过程。开环控制过程可能也可能不进行这种测量，但在两种情况下，一旦开始，它都不会对过程进行调整。闭环控制过程使用输出的测量值作为反馈，以调整或控制转换过程。（D.M.B.）

## 基本常数

在物理学基本理论中起基本作用的那组物理常数。这些常数包括真空中的光速，`$c$`；电子电荷的绝对值，`$e$`，它是电荷的基本单位；电子的质量，`$m_e$`；普朗克常数，`$\hbar$`；以及精细结构常数，`$\alpha$`。

这五个量代表了基本常数的不同来源。`$c$` 和 `$h$` 是自然出现在某些物理理论的数学表述中的量的例子——分别是爱因斯坦的相对论和量子理论；`$e$` 和 `$m_e$` 是构成所有物质的基本粒子特征的量的例子；而 `$\alpha$`，量子电动力学（QED）的基本常数，是其他基本常数组合的例子，但因为它在物理学基本方程中总是以相同的组合出现，所以它本身也是一个常数。

需要可靠的物理基本常数数值值主要有两个原因。首先，如果要获得物理理论的定量预测，这些常数是必需的。其次，也是更为重要的是，通过仔细互相比对从物理学不同领域的实验中获得的这些基本常数的数值值，可以严格检验物理学基本理论自洽性。一般来说，基本常数测定的精度多年来一直在不断提高。过去，100 ppm（0.01%）甚至 1000 ppm（0.1%）的测量很常见，而如今 0.01 ppm 或更好的测定并不罕见（ppm = 百万分之一）。

常数组和换算因子之间可能存在复杂的相互关系，特定常数可以通过直接测量或通过其他直接测量常数的适当组合间接确定。如果直接值和间接值具有可比的精度，那么为了得到该数量的最佳值，必须将两者都考虑在内。（所谓最佳值是指被认为最接近真实但未知值的那个值。）通常，通向特定常数的几条路径，无论是直接的还是间接的，都会给出略微不同的数值。这种状况可以通过一种称为最小二乘法的数学方法得到满意的处理。这种技术提供了一种自洽的程序，用于从所有可用数据中计算常数的最佳“折中”值。它自动考虑所有可能的路径，并为每个可计算的常数确定一个单一的最终值。它根据相对不确定度对不同的路径进行加权来实现这一点。适当的权重来自于分配给构成原始数据集合的各个测量的不确定度。

## 基本相互作用

基本相互作用是作用于基本粒子之间的基本力，假设所有物质都由这些基本粒子组成。

目前，区分出四种基本相互作用。它们的性质在下表中总结。

**四种基本相互作用的性质**

| 相互作用 | 作用范围 | 交换量子 |
|---|---|---|
| 引力相互作用 | 长程 | 引力子 (`$g$`) |
| 电磁相互作用 | 长程 | 光子 (`$\gamma$`) |
| 弱核相互作用 | 短程 $\approx 10^{-18}$ m | `$W^{+}$`, `$Z^{0}$`, `$W^{-}$` |
| 强核相互作用 | 短程 $\approx 10^{-15}$ m | 胶子 (`$G$`) |

引力相互作用表现为所有基本粒子之间的长程吸引力。

电磁相互作用负责相同或不同电荷之间的长程排斥力或吸引力。在可比距离上，引力相互作用与电磁相互作用之比（由电子和质子之间各自力的强度确定）大约为 `$4 \times 10^{-37}$`。参见 COULOMB'S LAW（库仑定律）；ELECTROSTATICS（静电学）；GRAVITATION（万有引力）。

在现代量子场论中，电磁相互作用以及带电荷粒子之间的吸引或排斥力被描述为次级现象，源于一个初级过程：根据麦克斯韦方程，加速电荷发射一个或多个光子（光粒子或光量子），随后这些量子被第二个带电粒子重新吸收。类似的图像对于引力相互作用也可能成立。

第三种基本相互作用，即弱核相互作用，负责中子衰变为质子、电子和反中微子。与电磁作用和引力不同，弱相互作用是短程的，力程大约为 `$10^{-18}$` m。

一个重要的问题终于在 1983 年得到了解答：弱相互作用是否像电磁作用那样，主要由中间客体 `$W^{+}$` 和 `$W^{-}$` 粒子介导？在日内瓦 CERN 实验室发现的实验答案是，`$W^{+}$` 和 `$W^{-}$` 确实存在，其质量为 80.4 GeV/`$c^2$`。每个粒子都携带大小为 `$\hbar$` 的自旋，其中 `$\hbar$` 是普朗克常数除以 `$2\pi$`，就像光子（`$\gamma$`）一样。这些粒子的质量决定了弱相互作用的作用范围。参见 INTERMEDIATE VECTOR BOSON（中间矢量玻色子）。
