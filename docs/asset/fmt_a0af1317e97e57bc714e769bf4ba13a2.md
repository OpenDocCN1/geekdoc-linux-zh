
`Texture Mapping`决定`VIZ`是否为网格对象生成映射坐标。“Generate Coordinates for All Objects”选项为所有网格对象创建映射坐标，对于大型`AutoCAD`文件这可能需要一段时间。在导入已为其对象分配映射坐标的`AutoCAD`文件时，应始终使用此选项。“Generate Coordinates On-Demand”选项允许`VIZ`在为链接几何体分配材质时自动分配映射坐标。

`Curve Steps`让您可以控制曲线的渲染方式。低阶数会导致曲线看起来像直线，而高值会生成更准确的曲线。

`Maximum Surface Deviation for 3D Solids`控制从`AutoCAD` `3DSOLID`实体转换的对象在`VIZ`上的网格化。较小的数值产生具有更多面数的精确表面，而较大的数值使用的内存较少，但精确表面面数较少。

`Include Group`此组包含多个可以切换的复选框，用以指示您想要链接到`VIZ`中的对象类别。选择包括外部引用（这些是来自`AutoCAD`的外部引用（`XRefs`，而非`VIZ`）、来自`AutoCAD`的填充（`Hatches`）、点、光源、视图和相机以及`UCS`（网格）（`UCS`代表用户坐标系）。

## 链接的填充会增加文件大小

在文件链接中包含填充图案通常不是一个好主意。`VIZ`无法像`AutoCAD`那样高效地存储组成图案的实体，结果通常会消耗大量的内存、文件大小以及转换到`VIZ`的时间。

`Derive AutoCAD Primitives By`让您决定`AutoCAD`实体如何在`VIZ`中创建。此下拉列表中最简单的选择是“Layer, Blocks as Node Hierarchy”它将`AutoCAD`图层转换为链接几何，并将块转换为节点层次结构。类似的“Layer, Blocks as Node Hierarchy, Split by Material”选项将`AutoCAD`图层转换为链接几何，然后根据分配给每个对象的材料对每个图层上的`AutoCAD`对象进行细分。使用此选项的块将被分配一个节点层次结构。下一个选项是“Entity, Blocks as Node Hierarchy”它将`AutoCAD`实体转换为链接几何，并将块转换为层次结构。

您也可以选择“Layer”、“Entity”或“Color”，它们会根据图层、实体或颜色对对象进行分组，然后将它们转换为`VIZ`块。“Entity”选项会为`AutoCAD`文件中的每个实体创建一个对象。“One Object”选项将将整个`AutoCAD`图纸转换为单个`VIZ`块。

`The Derive Primitives By option`仅在修改预设时可用。`Select Layers to Include`点击此按钮打开“选择图层”对话框（见图17.33），您可以在此处“跳过所有图层（默认）”或“Select from List”。除非正在重新加载链接文件，否则此按钮将呈灰色。勾选的图层将被链接，无论它们在`AutoCAD`中的图层状态如何。注意，对话框中显示的图层状态数据仅供参考，不具备功能，且不会在`AutoCAD`中更新。此按钮在“Attach”选项卡中也可用。

`Create Helper at Drawing Origin`将包含一个原点辅助对象。该辅助对象放置在链接文件中以识别其原点并方便与其他文件对齐。

`Use Extrude Modifier to Represent Thickness`选中时，此设置将应用挤出修改器，匹配任何具有厚度值的实体的高度。注意，厚度是`AutoCAD` 3D建模早期（`AutoCAD`发布12版本之前）的一个非常老的概念，现在已不再被广泛使用。大多数现代3D建模在`AutoCAD`中是使用面或实体完成的。

`Create One Object for Each AutoCAD Architecture One`选中时，`AutoCAD Architecture`特有的对象（如门窗）将作为单个对象导入，而不是单独导入每个组件。

`Use Scene Material Definitions`将来自`AutoCAD`文件的材料与`VIZ`中的材料名称进行匹配。如果勾选且匹配，将使用`VIZ`中的材料名称。如果未勾选，材料名称始终取自`DWG`文件。注意，`DXF`文件不支持材料。

`Use Scene Assignments on Reload`这一重要选项允许您在重新加载`DWG`文件后保留您在`VIZ`中分配的材料。如果未勾选，当重新加载链接文件时，来自`AutoCAD`的材料将覆盖`VIZ`中的材料。

`Selective Reload`当您只想重新加载链接文件中的部分对象时，勾选“选择性重新加载”。如果您不想将`CAD`文件中的后续更改链接到`VIZ`，则可能需要这样做。选择性重新加载也可用于复杂场景，以尽量减少加载整个链接数据库所需的时间。

当“选择性重新加载”时，您可以手动在场景中选择要重新加载的对象，或者通过点击“Linked Objects”从“链接对象”对话框（见图17.34）中选择。此选项仅在重新加载链接文件时可用。

### 现实场景

## 整个流水线中的 AUTODESK 产品

一家大型珠宝店链正在重新设计其独立门店，配备客户休息室。

`Revit`（见本章稍后部分的“将 Revit 导入 VIZ”）首先被用于设计建筑并创建施工文档。墙、门、窗、隔断等均在`Revit`中建模。然后使用`AutoCAD`或`AutoCAD Architecture`对内部组件（如展柜、POS功能、固定装置和家具）进行建模。`AutoCAD`图纸被导入`Revit`，立面、剖面、视图和注释全部完成并组装成一套图纸。

为了创建渲染图，来自`Revit`的结构组件和来自`AutoCAD`的内部组件链接到`VIZ`场景。材料、灯光和动画在`VIZ`中完成并通过电子形式发送给客户审核。所需的更改在`Revit`或`AutoCAD`中进行，并反映到`VIZ`场景或`VIZ`本身。
