
# 电视发射机与天线

电视台被授权在特定频道上运行，但由于传输电视图像需要非常宽的带宽，这些频道分配在广泛的频率范围内。2至6频道是低频甚高频（VHF）频道，而7至13频道是高频VHF频道。14至69频道是超高频（UHF）频道。每个频道宽度为6 MHz。由于频率范围很宽，电视发射机被设计为仅在前述组中运行其中一个，并采用针对相关频道最有效的特定电路。参见“无线电频谱分配”。

电视发射机天线的水平辐射图案是圆形的，向指南针的所有方向提供相等的辐射信号强度。高增益天线通过减少地平线以上和以下垂直角度处的辐射功率，在地平线方向上实现更大的功率。由于这可能导致靠近发射机的某些接收机信号较弱，因此经常使用波束倾斜和波束填充来降低最大辐射功率的角度。由于电视信号沿“视距”传播，发射天线通常放置在相对于周围服务区域尽可能高的位置。这允许观众将接收天线朝向一个方向以获得来自所有台的最佳接收效果。参见“天线（电磁）”。

VHF模拟视觉电视发射机设计哲学有两个主要类别。经典方法是在中等功率级别调制视觉载波，通过高功率线性放大器将载波放大至额定输出功率，然后通过高功率电路进行滤波以获得所需的残留边带信号。更现代的方法，被几乎所有发射机制造商采用，使用对中间频率（i-f）信号在极低功率级别进行调制。所需的残留边带信号施加在低电平信号上，通常通过高稳定性的表面声波滤波器实现，随后信号上变频至载波频率，并由线性放大器放大至额定输出功率。参见“放大器”、“表面声波器件”、“电视”。

## 碲

碲是一种化学元素，符号Te，原子序数52，化学原子量127.60。天然碲有八种稳定同位素。碲占地球火成岩的约$10^{-5}$%。它以游离元素的形式存在，有时与硒相关。更常见的是以碲化物硫化物（图纹碲）、纳格氏矿（黑碲）、特贝莱矿、黑铋碲矿、阿里卡特矿、科罗拉多矿以及其他银金碲化物，以及氧化物碲黄铁矿的形式存在。参见“元素周期表”。

单质碲有两种重要的同素异形体变体，即晶体形式和非晶态形式。晶体形式呈银白色，具有金属光泽。这种形式在$841.6^\circ\mathrm{F}$（$449.8^\circ\mathrm{C}$）熔化，在$2534^\circ\mathrm{F}$（$1390^\circ\mathrm{C}$）沸腾，比重为6.25，莫氏硬度为2.5。非晶态形式（棕色）比重为6.015。碲在空气中燃烧产生蓝色火焰，形成二氧化碲，$\mathrm{TeO}_2$。它与卤素反应，但不与硫或硒反应，并形成除其他产物外，既像硒化物一样的二碲化物阴离子$(\mathrm{Te}_2^{2-})$，又像铂(IV)一样的四价碲阳离子$(\mathrm{Te}^{4+})$。

碲主要用作钢的添加剂以增加其延展性，用作电镀浴中的光亮剂，用作石油裂化催化剂的添加剂，用作玻璃的着色材料，以及用作铅的添加剂以增加其强度和耐腐蚀性。参见“硒”。 [Sk]

## 四孢子虫纲

孢子虫亚门下的一个纲。这些原生动物被分为两个亚纲：动胞虫纲（Gregarina）和孢子虫纲（Coccidii）。该群体所有成员都是细胞内或细胞外寄生虫，且生活史[包含]有性和无性阶段。孢子缺乏极囊，并从卵囊中发育。孢子虫是通常的感染阶段，启动生活史中的无性阶段。参见“球虫”；“动胞虫”；“原生动物”；“孢子虫”。 [ERB,N.D.L]

## Temnopleuroidea

海胆纲（Echinacea）的一目，具有心盘状灯笼，简单或棒状头部，瘤状突起无孔或有孔（且通常呈锯齿状），步足板为双冠型或海胆型，以及通常较浅的腕足裂。包含三个科：Glyphyphymidae、Temnopleuridae 和 Toxopneustidae。参见 ECHINACIA。[H.F.]

## Temnospondyli

晚石炭纪迷齿螈类（Labyrinthodont temnospondyls）两大主要谱系中较常见的类群，其特征是面骨通过缝与颅顶相连，从而与羊膜动物区分开来。它们的椎骨结构——其中背侧椎很少突出，而间椎较大——类似于一些鱼龙目（hipelididae crossotergpysidians，注：原文此处拼写可能存在特定语境或错误，按字面意译）成员的椎骨结构，这类成员包括所有两栖动物的祖先。陆生 temnospondyls 在晚石炭纪和早二叠纪达到了最大的多样性，在此期间它们是最常见的陆生脊椎动物。大型水生 temnospondyls 的最后一类出现在澳大利亚的侏罗纪早期。参见 AMPHIBIA; ANTHRACODONTIA; CROSSOPTERYGII; LABYRINTHODONTIA。[R.L.C]

## Temperature

一个与热量从一个物体或空间区域流向另一个物体或区域相关的概念。它不仅延伸到了冷热感官，还包括数值标度和温度计。该概念的基础是绝对温标、绝对零度以及绝对温度与原子和分子运动之间的关系。

温度计并不测量一种特殊的物理量。它们测量长度（如汞柱的长度）、压力或体积（如美国国家标准与技术研究院使用的气体温度计），或电压（如热电偶）。基本事实是：如果两根汞柱在接触两个不同的、分离的物体时长度相同，当这两个物体接触时，热量将不会从一个物体流向另一个物体。参见 THERMOMETER。

温度计刻度上的数值仅仅是历史选择；它们在科学上并非根本性的。最常用的标度是华氏度（°F）和摄氏度（°C）。以前使用的是百分度标度，将冰水（冰点）定为 0°，将在一大气压下沸腾的水（沸点）定为 100°，但已被以不同方式定义的摄氏标度所取代。然而，在摄氏标度上，冰点和沸点的温度与 0° 和 100° 仅相差几分之一度。插图展示了摄氏标度和华氏标度的对比，以及它们如何对应于绝对标度。参见 ICE POINT。

1848 年，威廉·汤姆森（开尔文勋爵）遵循萨迪·卡诺的思想，提出了以测量物体间流动的热量来定义绝对温标的概念。最重要的是，开尔文构想了一种不会释放任何热量且处于绝对零度的物体。实验表明，绝对零度对应于 −273.15° C 或 −459.7° F。两种绝对标度，如插图所示，是开尔文（K）和兰金（R）。在实践中，绝对温度是通过使用低密度氦气和稀释的顺磁性晶体来测量的，这些材料是实际材料中最接近理想的。使用气体或磁性温度计测量主要温度是一个单点事件，在国家标准实验室进行。只有少数温度被测量过，包括金的凝固点（1337.91 K 或 1948.57° F）、硫的沸点（717.85 K 或 832.46° F）、氧（90.18 K 或 −297.35° F）和氦（4.22 K 或 −452.07° F）。各种类型的温度计（铂、碳和掺杂锗电阻器；热电偶）在这些温度下进行校准，并用于测量中间温度。参见 TEMPERATURE MEASUREMENT; THERMODYNAMIC PRINCIPLES。[R.A.H.]

## Temperature adaptation

动物由于特定的生理适应而在广泛不同的温度下存活和运作的 ability。温度是环境中无处不在的属性，限制了动物的活动、分布和生存。

温度变化通过决定化学反应速率和指定平衡来影响生物系统。因为温度对具有足够能量以发生反应（即超过活化能）的分子百分比的影响大于其对系统动能的影响，所以适度的温度降低（例如，从 77 到 59° F，或从 25 到 15° C，仅对应平均动能降低 3%）会导致反应速率显著抑制（降低两到三倍）。此外，温度影响非共价相互作用（静电、疏水和氢键相互作用）在蛋白质结构高级层次和生物膜等大分子聚集物的形成与破坏之间的平衡。维持适当的结构柔性是酶催化和膜功能的必要条件。然而，低温限制了蛋白质和膜脂质的构象柔性，而高温则使其松弛，从而干扰生物功能。参见 CELL MEMBRANES; ENZYME。

根据决定体温的因素，动物被分为两大类。对于变温动物（ectotherms），体温由体外热源决定；静息代谢率（和产热）水平较低，且保留热量的机制有限。这类动物常被称为变温性或冷血动物，因为它们的体温通常符合环境温度。相比之下，恒温动物（endotherms）产生更多的代谢热，并具有专门的保热机制。因此，体温高于环境温度；一些恒温动物（称为恒温性或温血动物）维持相对恒定的体温。变温动物和恒温动物之间没有自然的分类学划分。大多数无脊椎动物、鱼类、两栖类和爬行类是变温动物，而真正的恒温动物仅限于鸟类和哺乳类。然而，飞行昆虫在飞行前和飞行中常提高其胸部肌肉的温度（达 96° F 或 36° C），几种金枪鱼通过血管逆流热交换器在其运动肌肉中保留代谢热。参见 ADIPOSE TISSUE; HIPERTHEMIA; THERMOREGULATION。[J.R.H.]
