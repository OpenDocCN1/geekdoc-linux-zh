# 第 12 章：配置 OpenLDAP

## 1.
打开文件 `/etc/openldap/cn=config/olcDatabase={2}bdb.ldif`。更改 `olcRootDN` 参数以指定使用哪个用户作为根账户。接下来，打开第二个终端，从那里使用 `slapppasswd` 为你想使用的根密码创建一个哈希值。接着，在 `cn=config.ldif` 文件中找到 `olcRootPw` 参数，并将哈希后的密码复制到该参数。搜索 `olcSuffix` 指令，使其具有你想要启动 LDAP 查询的默认完全限定域名。

要设置此域名 `dc=example,dc=com`，请包含内容：`olcSuffix: dc=example,dc=com`。关闭配置文件的编辑器。使用 `slapd restart` 重启 LDAP 服务器。此时，你应该已经准备好开始填充条目信息了。

## 2.
创建一个包含以下内容的文件，并使用 `ldadd` 将其导入目录：

```
dn: dc=example,dc=local
objectClass: dcObject
objectClass: organization
o: example.local
dc: example
```

```
dn: ou=users,dc=example,dc=local
objectClass: organizationalUnit
objectClass: top
ou: users
```

```
dn: ou=groups,dc=example,dc=local
objectClass: organizationalUnit
objectClass: top
ou: groups
```

## 3.
创建一个 LDIF 文件来导入用户及其主组。内容应该类似于下面的示例文件。使用 `ldadd` 导入该 LDIF 文件。

```
dn: uid=lisa,ou=users,dc=example,dc=local
objectClass: top
objectClass: account
objectClass: posixAccount
objectClass: shadowAccount
cn: lisa
uid: lisa
uidNumber: 5001
gidNumber: 5001
homeDirectory: /home/lisa
loginShell: /bin/bash
gecos: lori
userPassword: {crypt}x
shadowLastChange: 0
shadowMax: 0
shadowWarning: 0

dn: cn=lisa,ou=groups,dc=example,dc=com
objectClass: top
objectClass: posixGroup
cn: lisa
userPassword: {crypt}x
gidNumber: 5000
```

## 4.
创建一个 LDIF 文件来创建 `sales` 组，并使用 `ldapadd` 将其添加到目录。

```
dn: cn=sales,ou=groups,dc=example,dc=com
objectClass: top
objectClass: posixGroup
cn: sales
userPassword: {crypt}x
gidNumber: 600
```

## 5.
使用 `ldapmodify` 修改组，并将你刚刚创建的用户作为新组成员。

```
dn: cn=sales,ou=groups,dc=example,dc=com
changetype: modify
add: memberuid
memberuid: lisa

dn: cn=sales,ou=groups,dc=example,dc=com
changetype: modify
add: memberuid
memberuid: linda

dn: cn=sales,ou=groups,dc=example,dc=com
changetype: modify
add: memberuid
memberuid: lori
```

## 6.
`ldapsearch` 命令应显示为：

```
ldapsearch -x "cn=linda,dc=example,dc=com" -w password -b "dc=example,dc=com\(objectclass=)"
```

## 7.
使用 `system-config-authentication` 提供一个简单的界面，用于设置客户端在 LDAP 上进行身份验证。

# 第 13 章：配置你的服务器进行文件共享

## 1.
确保你想创建的目录在文件系统中存在，并向其拷贝一些随机文件。接着，创建 `/etc/exports` 文件并放入以下行：

```
nfsfiles 192.168.1.70(rw)
```

使用 `service nfs` 启动 NFS 服务器，并使用 `chconfig nfs` 启用它。

使用 `showmount -e localhost` 验证其是否可用。

## 2.
在主机上，编辑 `/etc/auto.master` 并确保它包含以下行：

```
mnt/nfs /etc/auto.nfs
```

创建文件 `/etc/auto.nfs` 并赋予其以下内容：

```
* -rw 192.168.1.70/nfsfiles
```

访问 `/data` 目录创建数据目录，并在其中放入一些文件。创建一个 Linux 组 `saambaers`，使该组成为 `/data` 目录的所有者，并赋予其 rwx 权限。安装 `samba` 和 `samba-common` 包，并编辑 `/etc/samba/smb.conf` 文件包含以下最的共享配置：

```
[sambadata]
path = /data
writable = yes
```

将 SELinux 上文类型设置为 `public_t`。
