
化学分类学将对细菌细胞成分的分子架构的系统数据应用于解决分类学问题。自 20 世纪 50 年代以来，这是一种强有力的工具，并且已经确定了许多化学分类学标记，范围从原核生物或特定细菌群落的独特分子，到表征属或种的代谢机制或产物。氨基酸分析、聚合物序列分析、气相色谱和薄层色谱、发酵产物和脂质等技术的可用性及相对简单性，使得系统研究成为可能。这些导致基于细胞壁组成的生化评估、膜脂质组成、异戊二烯醌类型、选择性蛋白质的氨基酸序列，以及蛋白质（如细胞色素和许多其他大分子）的特性，对分类群的有效定义。参见 [化学分类学](https://example.org/chemotaxonomy)。

核酸研究迄今为止是最强大的数据生成者和相关性的仲裁者，具有在分类安排系统发育评估中的应用能力。参见 [脱氧核糖核酸 [DNA]](https://example.org/deoxyribonucleic_acid)；[核糖核酸 [RNA]](https://example.org/ribonucleic_acid)。

## 细菌学

研究细菌的科学，因此是微生物学的一个专门分支。它涉及细菌作为生物实体的性质和特性，它们的形态和发展历史，生态学，生理和生物化学，遗传学，以及分类。

相继处于细菌学研究前沿的主要主题包括细菌的起源，其性质的恒定或可变性，它们作为疾病和食物腐败致病剂的作用，它们在物质循环中的意义，它们的分类，以及它们的生理、生物化学和遗传特征。参见 [细菌](https://example.org/bacteria)；[微生物学](https://example.org/microbiology)。 [C.B.V.] [R.G.E.M.]

## 噬菌体

感染细菌细胞的任何病毒。它们是离散的颗粒，尺寸大约从 20 到 200 纳米。特定的细菌病毒只能感染一种或少数几种相关的细菌物种；这些构成了其宿主范围。噬菌体由两个基本成分组成：核酸，其中编码遗传信息（这可能是核糖核酸或脱氧核糖核酸），以及蛋白质衣壳（衣壳蛋白），它作为保护壳包含核酸，并参与病毒感染的效率和宿主范围。

对细菌病毒的描述涉及通过电子显微镜（参见插图）研究其形状和尺寸，其宿主范围，其衣壳的血清学性质，其包含的核酸类型，以及其在特定宿主上形成的噬菌斑的特征。核酸和衣壳蛋白均对个体病毒具有特异性；对于衣壳蛋白而言，这种特异性是病毒血清学鉴定的基础。

## 天平

一种用于精确测量小重量或质量（范围从微克到几千克）的仪器。参见 MASS（质量）；WEIGHT（重量）。

天平根据设计、称量原理和计量标准进行区分（见表）。对于给定的称量任务，选择天平主要依据其最大称量负载（Max）以及其重量读取装置（刻度盘、数字显示器、读数）的最小分度值（d）。天平还可以通过其分辨率或分度数 `n = Max/d` 与秤进一步区分。天平通常具有超过 10,000 个分度的分辨率，而秤的大部分低于此值。

| :--- | :--- |
| 类型 | 分度值 (d) |
| 超微量分析 | 0.1 $\mu$g |
| 微量分析 | 1 $\mu$g |
| 半微量分析 | 0.01 mg |
| 宏量分析 | 0.1 mg |
| 精密 | $\geq 1$ mg |

*注：原表还列出了“典型容量（Max）”。*

传统的机械天平由一个对称杠杆（称为天平梁）、悬挂在其两端的两个托盘以及位于中心的支点（ fulcrum）组成（参见插图）。待测物体放在一个托盘上，然后在另一个托盘上放置所需量的砝码，使天平达到平衡。因此，物体的重量定义为在经典等臂天平上恰好能平衡该物体的校准标准质量所代表的量。虽然这在现代天平和秤上并非显而易见，但重量的测量仍然基于这一原始理解。

*图 1：机械天平设计。(a) 等臂天平的关键设计要素。(b) 使用等臂天平称量微小的重量差。(c) 顶部加载式等臂天平。F，支点；E，端点枢轴；C，重心。*

替代原理代表了机械天平演化的决定性步骤。替代天平只有一个悬挂组件，其中包含负载托盘和内置在保持架上的砝码组。悬挂组件通过刚性连接到梁另一端的配重块进行平衡。物体的重量是通过将砝码从保持架上提起，直到天平返回其角度差称量范围内的平衡位置来确定。在离散刻度盘步骤之间的微小重量增量是从与天平梁刚性连接的刻度光学分划板投影屏幕图像上读取的。

电子（更准确地说是机电）天平的演化始于 20 世纪 60 年代后期，并跨越了多代电子技术。在众多技术可能性中，电磁力补偿这一操作原理很早就成为高精称量的标准。该原理由 K. Ångström 于 1895 年首次描述，随着固态电子元件的进步，电磁力补偿原理变得适用于技术应用。

在每个机电称量系统中，都有三个基本功能：

1. 负载传递机构，由称量平台或托盘、杠杆和导向装置组成，接收托盘上的随机分布压力作为称量负载，并将其转化为可测量的单一力。
2. 机电力传感器，通常称为称重传感器（load cell），将机械输入力转换为电气输出，例如电压、电流或频率。
3. 天平的电子信号处理部分接收输出信号，将其转换为数字，执行计算，并在显示屏上显示最终重量数据。

除了提高精度、可靠性和操作速度外，该技术的主要优势还包括为人机交互优化而设计的人体工程学设计，以及众多操作便利功能，如按键置零、自动校准、用于常用工作程序的内置计算能力，以及向打印机和计算机输出数据。参见 PHYSICAL MEASUREMENT（物理测量）；WEIGHT MEASUREMENT（重量测量）。

## 蔓足类（Balanomorpha）

蔓足类的边界（注：原文 A border of the Thoracica 可能意指属于胸足类的边缘类群或相关分类）。该群体包括常见的藤壶。外套膜分泌高度钙化的外壳，形成双侧对称的锥形壳，通常由前端的喙部、后端的龙骨以及一对至三对侧板组成。宽大的基部为膜质或钙质。外壳（外套膜）开口由一对瓣膜关闭，每个瓣膜由两个相互咬合的板组成。这些动物是雌雄同体的，异花授粉是正常的。已记录有微型雄性个体。

蔓足类藤壶几乎可以在任何可能的附着点找到，无论是窄小的还是活着的（注：innameow 似为原文错误，可能意为 in narrow 或 similar）。它们在潮间带和浅水区最为丰富。一些物种出现在很深的地方。少数种类已成为经济问题，作为污损生物附着在船体和海洋设施上。参见 BARNACLE（藤壶）；[H.G.S.] THORACICA（胸足类）。
