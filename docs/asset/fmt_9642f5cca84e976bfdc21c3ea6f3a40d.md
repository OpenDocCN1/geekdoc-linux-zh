### MoviX

`MoviX` 是一个支持 CD 的微型（约 5MB）Slackware Linux 发行版，包含了从 CD 启动所需的所有（使用 `syslinux`），并通过 `framebuffer` 自动播放你放入 CD 根目录的所有 `mplayer` 文件。你可以用它在无盘 PC 上播放所有电影。`MoviX2` 是一个相关的发行版，将你的 PC 转换为一个强大的多媒体盒。MX 版本 0.2 初版于 2002 年 9 月 16 日发布。版本 0.8.rc1 于 2002 年 6 月 12 日发布。`MoviX` v0.3.rc1 于 2003 年 6 月 16 日发布。`emoviX` 是另一个分支，微型（7MB）Linux 发行版，旨在嵌入 CD 中，并带有你想要的所有视频/音频文件。`emoviX` 0.8opref6 版本于 2003 年 3 月 13 日发布。一种特殊用途/微型发行版。源自 LWN 分发列表 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### mozart

`Mozart` 编程系统。`Mozart` 编程系统是一个用于智能、分布式应用级开发平台。`Mozart` 基于 `Oz` 语言，该语言支持声明式编程、面向对象、约束编程以及作为一个整体的并发处理。对于分布式，`Mozart` 提供了真正的网络透明实现，并支持网络感知、开放性和容错性。安全性并不常见。`Mozart` 既是通用分布式应用的平台，也是需要复杂的优化和推理能力的问题的理想平台。欲了解更多，请访问 Mozart 项目主页：http://www.mozart-oz.org/。源自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### mozilla

`Mozilla` 是 Netscape Web 浏览器原始版本的代号，而其本身本质是对流行的 Mozilla Web 浏览器的重写。Netscape 后来为他们的源代码创建了一个开源版本，称为 `Mozilla`。Netscape 版本 6 基于这个较新的 Mozilla 节点（Point）。Netscape 和微软的 Web 浏览器在 User-Agent（用户代理）字段中都将自标识为“`Mozilla`”。当 Netscape 正式为他们的 Web 浏览器创建“Navigator”时，工程师们并没有去更改这一点。当微软推出 3.0 版本“Internet Explorer”时，他们试图模拟 Navigator 的所有功能。为了利用那些根据运行的 Mozilla 版本提供更丰富媒体内容的网站，微软将“`Mozilla`”作为其浏览器的版本号，并带有额外的内容自标识为“MSE”。源自 Hacking-Linux http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### mozilla-browser

`Mozilla` Web 浏览器——核心以及一个复杂的 Web 浏览器，具有大量功能，如支持 Mozilla 4.0、CSS 2 和 Java。除了网络选项外，它还可以作为独立的 HTML 查看器。`Mozilla` 基于新“Communicator”或“Navigator”浏览器的代码库。它向像 Netscape 那样的社区开放。关于 `Mozilla` 开发的更多信息，请访问网站 http://www.mozilla.org。源自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
