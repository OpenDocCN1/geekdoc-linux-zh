## 保存我们的工作

`vi` 中还有几种不同的方法可以保存编辑过的文件。我们已经涵盖了 `:w` 命令，但其他一些我们可能觉得有用。

在命令模式下，输入 `ZZ` 将保存当前文件并退出。同样，`:wq` 命令会将 `:w` 和 `:q` 结合。

从一个文件移动到另一个文件，`vi` 执行策略：如果当前文件有未保存的更改，则阻止切换文件。要强制 `vi` 切换文件并放弃更改，请在命令后添加一个感叹号 `!`。

除了已经描述的切换方法，`vim`（以及 `vi` 的某些版本）提供了一些更容易管理多个文件的命令。我们可以通过 `:buffers` 命令查看编辑过的文件列表，它将在屏幕底部显示文件列表。

```
:buffers
1 % "foo.txt" line 1
2 "ls-output.txt" line 0
Press ENTER or type command to continue
```

要切换到另一个缓冲区（文件），输入 `:buffer` 后跟你想要编辑的缓冲区编号。例如，要将文件 `foo.txt` 切换到包含文件 `ls-output.txt` 的缓冲区 2，我们使用以下类型：

```
:buffer 2
```

我们的屏幕现在显示第二个文件。另一种更改缓冲区的方法是使用之前提到的 `:bn`（buffer next 的缩写）和 `:bp`（buffer previous 的缩写）命令。

## 打开额外的文件进行编辑

还可以将文件添加到当前的编辑会话中。命令 `:edit`（"edit" 的缩写）后跟文件名将打开一个额外的文件。让我们结束当前的编辑会话并返回命令行。

仅一个文件启动 `vi`。

```
[melinuxbox ~]$ vi foo.txt
```

要添加我们的第二个文件，输入以下内容：

```
:edit ls-output.txt
```

它应该出现在屏幕上。我们可以验证的是，第一个文件仍然存在。

```
:buffers
1 # "foo.txt" line 1
2 % "ls-output.txt" line 0
Press ENTER or type command to continue
```
