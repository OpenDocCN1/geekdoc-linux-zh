
如果你在某个频道中并将表达式设置为`*`字符，你只会看到当前所在频道的信息。如果你在使用`*`字符作为表达式时不在任何频道中，则会列出所有可用频道。

`/list`命令有多个可用选项。这些选项通过指定一个或多个不同的开关与命令一起使用来启用。有关可用控制开关的摘要，请见表 7.3。不带任何表达式或开关使用`/list`命令可能会产生大量输出。

如果你连接的服务器负载较高，你可能不被允许运行`/list`命令。如果发生这种情况，通常可以在稍后重试`/list`命令。

### 表 7.3 `/list`命令的控制开关

| 开关 | 描述 |
| :--- | :--- |
| `-ALL` | 覆盖之前的`-PUBLIC`和`-PRIVATE`控制开关。 |
| `-MAX n` | 仅列出当前用户数多于`n`的频道。 |
| `-MIN n` | 仅列出当前用户数少于`n`的频道。 |
| `-PRIVATE` | 仅列出标记为私有的频道。 |
| `-PUBLIC` | 仅列出对所有人开放的频道。 |
| `-TOPIC` | 仅列出设置了主题的频道。 |
| `-WIDE` | 以尽可能少的空间列出频道信息。此开关可能接受以下参数以更改列表的排序顺序： |
| `-NAME` | 按频道名称对列表排序。 |
| `-USERS` | 按每个频道中的用户数对列表排序。 |

## nick

语法：

```
/nick nickname
```

此命令用于设置你的昵称，或简称`nick`。如果其他人正在使用你请求的昵称，系统会提示你输入一个新的昵称。当你启动`ircII`客户端时，它将使用你的Linux登录名作为默认昵称。你可以通过为`ircII`创建`.ircrc`配置文件来修改此行为。

在某些IRC网络上，可以注册并保留你的昵称。这样做可以确保你是该网络上唯一可以使用该昵称的人。如果你打算经常使用该IRC网络，这可能是个好主意。此外，如果你有一个注册的昵称，你的聊天伙伴可以比较放心地确定与你聊天的人真的是你。

昵称注册的行为在不同的IRC网络上可能有所不同。最常见的方法大致如下：如果你试图将你的昵称设置为已被他人注册的昵称，你将被给予60秒的时间来指定另一个昵称。如果你在规定的60秒内没有更改名称，服务器将为你的昵称进行更改。它会设置一个类似`guest<编号>`的昵称模式。许多IRC频道不允许拥有此类昵称的人加入。因此，最好尽快更改为合适的昵称。

## /version

**语法：**

```
/version server
```

该命令允许你连接到IRC服务器。如果你已经连接到一个服务器，你将断开与那个服务器的连接，并且新指定的服务器将成为你的主服务器。只要你保持在同一个IRC网络中，你应该能保留你的昵称并停留在频道内。然而，有时服务器切换未能及时完成。在这种情况下，新服务器会认为其他人已经在使用你的昵称，并且该用户已登录在之前的服务器上。因此，你将无法再次使用相同的昵称。当这种情况发生时，你需要等待一小段时间后重新设置昵称并重新加入你想要的频道，或者你可以指定一个新的昵称。

在提供服务器名称的同时，你还可以指定要连接IRC服务器的端口号。如果你不指定端口号，将使用默认的IRC端口号。IRC流量的默认端口号是`6667`。

`ircli`客户端有一个内置的服务器列表，包含你访问过的服务器。如果你在没有参数的情况下输入`/server`命令，将显示这些服务器的列表。如果你在没有指定特定服务器的情况下启动`ircli`客户端，将从内置列表中选择一个服务器。

### /who

**语法：**

```
/who expression
```

这将产生当前所在IRC服务器上的用户列表。如果你将`*`作为表达式指定，则仅列出当前频道上的用户。如果你将`@`作为表达式指定，则显示整个IRC网络上的所有用户。除了这两个特殊情况外，你可以提供任何包含正则表达式的有效字符串，该命令将尝试仅列出匹配此表达式的用户。有关`/who`命令可用开关的更多信息，请参阅表 7.5。

**表 7.5 /who 命令的控制开关**

| 开关 | 描述 |
| :--- | :--- |
| `-away` | 仅列出标记为离开的用户。 |
| `-chops` | 仅列出频道操作员。 |
| `-file filename` | 仅列出在文件中列出的用户。 |
| `-here` | 仅列出标记为在场的用户。 |
| `-host` | 仅列出来自指定主机的用户。 |
| `-luusers` | 仅列出非操作员。 |
| `-name username` | 仅列出用户ID匹配`username`参数的用户。 |
| `-nick` | 仅列出昵称匹配的用户。 |
| `-operators` | 仅列出操作员。 |
| `-server` | 仅列出来自指定服务器的用户。 |

### /whois

**语法：**

```
/whois nicknames
```

这用于获取具有指定昵称的用户的详细信息。你将获得关于每个用户的以下信息：用户名、主机、服务器、真实姓名以及他们的离开消息。真实姓名需要谨慎对待，因为用户可以将其设置为任意内容。

例如，如果你尝试以下命令，可能会得到以下输出：

```
/whois wsb.
*** wsb is wsb@test.gnulix.org (William B.)
*** on channels: @Gnulix
*** on irc via server irc-2.mit.edu (Massachusetts Institute of Technology)
*** wsb has been idle 27 seconds
```

### /whowas

**语法：**

```
/whowas nickname
```

这显示了最后使用指定昵称的用户的详细信息。即使该用户未登录，也会显示这些信息。将显示与`/whois`命令输出相同的信息。
