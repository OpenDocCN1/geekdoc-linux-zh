
侧边栏是一个实用的功能，但有时你可能更希望有更多空间来查看窗口内容，并想临时去掉侧边栏。你可以通过进入 Nautilus 窗口的“视图”（View）菜单并取消勾选“侧边栏”（Side Pane）轻松实现这一点。取消将消失的项目旁边的标记，该项目将会消失，侧边栏也会随之消失。要恢复它，返回“视图”菜单并再次选择“侧边栏”。勾标记将重新出现，侧边栏本身也会出现。

还有一种隐藏侧边栏的方法，许多人会偶然发现，通常会导致一些不必要的恐慌。如果你看侧边栏右侧的灰色边框，你会注意到中心有一个小的条纹区域（见图 6-3）。点击该条纹区域充当隐藏或显示侧边栏的开关。大多数用户所经历的恐慌是因为，当侧边栏以这种方式隐藏时，“视图”菜单中的“侧边栏”选项仍然被勾选，表示侧边栏仍在视图中，尽管你的眼睛告诉你的事实并非如此。

所以秘密就在这里——侧边栏的小秘密。不，它并不是一个特别有趣的秘密，但它不仅能为你提供额外的便利，还能让你感到安心。

## Nautilus 中的文件处理

由于 Nautilus 本质上主要是一个文件管理器，因此直接进入使用它的具体操作是合理的。当然，今天大多数使用电脑的人已经熟悉了拖放操作，因为几乎没有其他创建文件夹以及复制、剪切和移动文件的方法。对于那些不熟悉这些基本程序的任一方法的人，我认为最好的办法是将它们全部说明白。如果你觉得这些有些多余，请为了大众的利益多多包涵我。

### 创建、命名和重命名文件夹

创建文件夹是一项简单的任务，有两种方法可以实现。据我看来，最简单的方法是在空白处点击右键并选择“新建文件夹”（New Folder）。或者，你也可以使用键盘快捷键`Ctrl+Shift+N`。文件夹创建好后，你就可以输入它的名称。以后要重命名文件夹，只需右键点击它并选择“重命名”（Rename），或者选择文件夹并按`F2`。要删除文件夹，右键点击它并选择“移动到垃圾箱”（Move to Trash），或者选择它并按`Delete`键。

假设你有一个名为`gooseberries`的文件夹，它位于名为`Dalarna`的文件夹内，而后者位于`SwedeStuff`之中，`SwedeStuff`又位于你的主目录下。如果你通过双击`NordicStuff`文件夹并进入`gooseberries`文件夹，Nautilus 将显示该文件夹的标签页……以及在此之前打开的任何文件夹。请看图 6-4 以我的意思。

![](img/ba6b82a7869bba748202d57c97336dca_103_0.png)

图 6-4：Nautilus 中的标签页导航

你可以看到，从你的主目录（在此例中）到目标：`gooseberries`，路径上的每个文件夹都有一个标签按钮。这又怎样呢？好吧，假设你想回到`NordicStuff`文件夹来打开一个包含你想复制并粘贴的文本的文档，这听起来有点麻烦，对吧？

那么，与其使用“返回”按钮反复切换，只需点击`NordicStuff`按钮，该文件夹的内容就会出现在你面前。需要回到`gooseberries`吗？点击`gooseberries`标签按钮即可。回到`SwedeStuff`？只需点击`SwedeStuff`标签按钮。

## Nautilus 中的书签

在通过层层点击进入深层子文件夹时，值得提一下 Nautilus 的另一个非常实用的功能：书签。是的，Nautilus 允许你对导航过的文件夹创建书签。虽然你对经常访问的网页创建书签已经非常熟悉，但你可能会纳奇，到底为什么要在文件系统中创建书签。

嗯，假设你有一个经常需要使用的文件夹，但它比我上一节中的`gooseberries`文件夹还要深得多。到达那里需要极其大量的鼠标点击，而所有的点击注定会让你患上严重的腕管综合症。虽然这对你的医疗保险（HMO）大有利，但对你来说绝对没好处。与其想象，不如你点击进入该文件夹一次，然后在 Nautilus 窗口的“书签”菜单中选择“添加书签”（Add Bookmark）。此以后，当你想回到该文件夹时，只需点击“书签”菜单，文件夹就会出现在下拉列表中等候你。

Nautilus 书签的另一个方便之处是，它们也会出现在“另存为”的对话框中，例如当你保存一个 OpenOffice 文档或通过 Firefox 下载文件时。在任何“另存为”对话框中，只需点击“保存”按钮，就能找到你的书签。

## 理解 Linux 文件系统

通过你刚刚学习的这些路径操作、导航和书签功能，你应该能够很好地弄清楚从这里回到你的主目录。尽管如此，了解主目录在整个体系中的实际位置可能也是好主意，万一你在某个地方真的迷路了。为了理解这一点，你应该对 Linux 文件系统有一个基本的了解，因为你会发现，它与你以前在操作系统中习惯的有所不同。

与 Windows 不同，Linux 文件系统全部源于一个名为“根”（root）的单点，并用单个斜杠（`/`）表示。你的所有账户位于`/home`，或者说，位于根目录下的家文件夹。如果你的用户账户名称和我的相同（即为 rg），那么该文件夹的路径就是`/home`，或者说是 home 根目录下的`rg`文件夹。无论你的用户账户或机器上任何其他账户的名称是什么，请记住，当你迷路时，文件夹以及机器上所有其他带有用户账户的文件夹都位于主文件夹内。如果你是一个更倾向于图形化操作的人，图 6 的映射应该对你有所帮助。

## 其他文件夹里装了什么？

不用说，Linux 文件系统不仅有根、家和用户账户文件夹。在与家同级还有其他几个目录，尽管在大多数情况下，除非你知道自己在做什么，否则你不应该仅仅在它们里乱逛。幸运的是，这些文件夹大部分都是写保护的，所以你应该能免受自己的误操作。尽管如此，对这些其他文件夹的用途好奇是很自然的，因为……嗯，它们就在那里。为了为了满足你的好奇心，我会稍作解释。

![](img/ba6b82a7869bba748202d57c97336dca_105_0.png)

图 6-6：用户文件夹在 Linux 文件系统中的位置

在 Ubuntu 中，有四个文件夹包含了系统中的大部分应用程序。你系统的基本元素位于`/bin`。系统需要的其他元素（它们可能不被使用，如命令等）也位于`/bin`。你实际上认为是程序并以实际操作方式使用的大部分程序位于`/usr`。最后，还有一些附加应用程序，例如 RealPlayer，它们会将自己安装到`/opt`。

还有其他你可能感兴趣的顶层文件夹：`/etc`、`/lib`和`/media`。其中第一个`/etc`是系统上所有配置文件的位置。第二个`/lib`是系统或安装在其上的应用程序所需的所有库的位置。这些库是 Windows `.dll` 文件的 Linux 等物。当你插入外部媒体（如 USB 驱动器和 CD）时，其内容将会显示。

还有其他顶层文件夹，但对于普通 Linux 新手来说，它们的用途没有那么直观，而且坦率地说，在游戏的这个阶段，并不是所有的文件夹你都感兴趣。总之，正如我之前提到的，目前你没有理由去折腾这些文件夹中的任何一个，因为其中的项目可以通过不同且安全得多的方式访问。

## Nautilus 作为网络浏览器

Nautilus 的另一个功能是它可以作为网络浏览器使用。例如，你可以通过点击 GNOME 面板上的“位置”菜单并选择“网络服务器”，查看你的家庭或办公室网络中有哪些网络和共享。你也可以在 Nautilus 窗口内通过进入“前往”菜单并选择“网络”来实现。该网络上的任何网络或计算机图标将出现在 Nautilus 窗口中，如图 6-7 中的设置所示。从该窗口，你可以双击进入你有权限访问的共享，例如 Windows 机器的共享文件夹或 Mac 的公共文件夹。

![](img/ba6b82a7869bba748202d57c97336dca_106_0.png)

图 6-7：Nautilus 中的网络浏览

顺便说一下，由于你好奇什么是共享，我为你解释。基本上，*网络共享*（network share）是计算机上的一个位置，网络上的用户可以在那里访问并保存文件。Windows 系统上的共享文件夹就是一个很好的例子。网络上的其他用户可以从共享文件夹复制文件并（通常）写入文件，而他们无法访问该主机文件系统的其他部分。
