Bash 中需要注意的一个重要点是，双引号和单引号（`''`）的行为非常非常。。双引号被认为是“弱性”的，因为它们允许解释器在引号内部执行替换。单引号被认为是“强性”的，因为它们阻止任何替换的发生。考虑以下示例：

```bash
#!/bin/bash

# 这是我们的第一个注释。对所有脚本进行注释也是良好的习惯。

username="Carol Smith"

echo "Hello $username!"
echo 'Hello $username!'
```

```
$ ./new_script.sh
Carol Smith!
Hello $username!
```

在第二个 `echo` 命令中，解释器被阻止将 `$username` 替换为 `Carol Smith`，因此输出是字面意义上的。

### 条件逻辑

在 Bash 中使用条件逻辑是一个广泛的主题，本课程将不会深入探讨。让我们通过回顾我们希望实现的内容开始。在这种情况下，我们测试的是`#`的值是否等于 1。

- 如果条件为真，采取的操作是问候用户。
- 如果条件为假，我们将打印一个错误。

现在逻辑很清晰，我们将关注实现所需的语法。

```bash
#!/bin/bash

### 一个简单的问候用户的脚本

if [ $# -eq 1 ]
then
    username=$1
    echo "Hello $username"
else
    echo "Please enter one argument."
fi
echo "Number of arguments: #"
```

条件逻辑包含在 `if` 和 `fi` 之间。要测试条件位于方括号 `[ ]` 之间，操作位于 `then` 之后。注意方括号之间的空格。省略此空格会导致错误。

此脚本将输出我们的问候信息，或者错误消息。但它总是打印参数的数量。

```
$ ./new_script.sh
Please enter one argument.
Number of arguments: 0.
$ ./new_script.sh
Hello Carol!
Number of arguments: 1.
```

注意这个 `if` 语句。我们使用了 `-eq` 来进行数值比较。在这种情况下，我们测试的是 `#` 的值是否等于 1。我们可以执行的其他比较还包括：

- `-ne` 不等于
- `-gt`: 大于
