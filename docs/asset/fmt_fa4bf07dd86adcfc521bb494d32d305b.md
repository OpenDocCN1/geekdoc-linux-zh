
然而，Windows 在关于用户对计算机恐惧的设计哲学上与 VMS 最相似。回想一下，VMS 的开发者假设用户认为计算是令人生畏的。在为 Windows 设计软件时，软件开发者必须尽力让操作系统对初学者来说易于使用。

这是 Windows 和 Unix 哲学之间的根本区别。记住，Unix 并没有尝试满足初学者对易用性的关注。它的文本用户界面及其完成任务的方式，仍然顽固地抵制学者的快速吸收。用户必须经历一条相对陡峭的曲线才能利用其内在的力量。他们必须花费几天、几周甚至几个月的时间来精通 Unix，以便执行某些在基于 Windows 的系统中几分钟内就能学会并执行的任务。

微软会定期向其合作伙伴以只读格式提供 Windows 源代码。但微软很少允许其他公司进行更改。微软通常进行所有的修改。

Linux 试图通过提供 KDE 和 Gnome 桌面环境等 GUI 选择来弥补新手和专家用户之间的差距。KDE 和 Gnome 提供了类似 Windows 的用户界面，提供了通常的“点点”功能，并增加了自己的新花样。它们形成了一个盾牌，保护用户免受许多底层命令的影响，通常将可用选项限制在初级到中期用户最佳使用的范围内。经验丰富的用户只能通过文本命令行界面访问真正复杂的内容。

由于其极大的灵活性，Linux 允许你在文本界面和图形界面共存的双重世界中运行。然而，这提出了一个重要的问题。尽管 Linux 可能提供类似 Windows 的环境，但为什么不运行 Windows 获取真正的呢？如果你已经有了 Windows，为什么还需要一个几乎像 Windows 的东西呢？正如歌中所说，“没有什么比得上真东西，宝贝！”

一个答案是，虽然 Linux 和 Windows 桌面看起来相似，但存在显著的架构差异。Windows 内核是专有的单体。Linux 内核是开源的，这意味着任何人都可以检查或修改它。这允许了快速开发和社区驱动的创新。

# 内容很重要，笨蛋！

如果你出生在 20 世纪 70 年代后期，你与计算机的第一次有意义的接触可能是一台 WIMP（窗口、图标、菜单、指针）个人电脑。你的电脑一直都有 GUI，你可以在上面指向并点击被称为图标的小图像。

事实是，微软并没有发明 WIMP 用户界面，是罗拓（Xerox）——那些造复印机的人——发明的。Xerox Star 是 1981 年由罗拓的帕洛阿尔托研究中心（又称“Xerox PARC”）推出的，它是带有 WIMP 用户界面的产品的首次发布。其他早期系统，如 Smalltalk 和 Alto，体现了 Star 中的一些想法，但在 Star 中，开发者首次将所有元素整合在了一起。

Star 系统的许多方面都可以在微软 Windows、苹果 Macintosh 和各种 Linux 环境中看到。桌面隐喻（用户被邀请将屏幕对象视为办公桌上放置的物体）源于 Star。位图显示、图标和鼠标的使用在 Star 的用户界面中是一致的。

微软也没有发明全球网（World Wide Web）。蒂姆·伯纳斯-李（Tim Berners-Lee）拥有这一荣誉。他对万维网的愿景不是基于成为富有信息的军主的梦想，而是基于对人们能更好地交流的真诚愿望。他与罗伯特·卡尤（Robert Cailliau）于1990 年在 CERN（跨越法瑞的欧洲物理实验室）编写了一个简单的、无功能的 Web 浏览器来实现他的愿景。

# 内容才是一切，笨蛋！

在 AltaVista 早期（它是 Web 上的第一个“超级搜索引擎”）的时代，开发者们喜欢说：“内容才是一切，笨蛋！”他们的意思是是，无论你是否拥有最快的搜索引擎、最亮眼的图形效果，还是最华丽的搜索桌面，这些并不重要。用户对闪烁和亮丽外观的印象只能维持一段时间。最终，你必须提供满足个人需求的信息。否则，用户就会寻找他处。如果你没有价值的内容，你就一无所有。

虽然微软的 Windows 帮助将内容传输到桌面，但微软并不创作内容。内容是由其他人生成的：新闻服务、电影制片厂、独立制片人，以及数百万使用文字处理器、电子表格和图形编辑器的用户。Windows 提供了传输这些内容的媒介。尽管 Windows 拥有图形用户界面（GUI）和流畅的桌面，它提供的是“火候”，而没有提供“牛排”。在这种情况下，“牛排”就是应用程序的内容。当然，你如何传输内容也非常重要。但 GUI 的重要性是由你试图传输的内容支撑的。

事实上，内容主宰一切。事实上，内容如此重要，以至于即使电脑不存在，制作者们也会找到方法获取它。起初，内容通过口头传播在村庄之间传递。随着印刷机的发明，内容以书籍和报纸的形式通过文字在城市之间传递。后来，广播和电视成为向大量人群传递内容的媒介。万网 Web 和互联网 仅仅是传输这种至关内容的下一种手段。

如果微软、Linux 和 Web 不存在，内容也会找到通往你的路。它非常重要。无论通过何种方式，只要信息很重要，你就会得到它。有些人出于商业或意识形态的原因而确保这一点的实现。他们会利用任何可用的手段将其传递给你。

是否有 GUI 并不是次要的。重要的是所传达的信息。如果你没有看到对你重要的内容，你就会打发信使走人，并寻找下一个信使。

但难道某些传输机制在传输内容方面不比其他机制更好吗？简而言之，是它们。虽然你可能倾向于认为视频无与伦比，但你可能会惊讶地发现，即使在今天，它在文字的力量面前也显得黯然失色。

让我们来看看三种主要的传输机制：视觉、听觉和文本。通过研究这些机制，希望你开始理解 Unix——一个主要以文本为导向的系统——在 CNN 和 MTV 时代仍然极其强大。

让我们先看看视觉媒体，它是三者中最虚弱的。Hub？你什么意思是“三者中最虚弱的？”每个人都知道视频的力量。听听我说一分钟。读完这一页左右的内容后，你可能会不同的想法。记住，我们正在对 Windows（一种视觉型操作系统）与对比 Unix（一种以文本为导向的操作系统）得出结论。

## 10.1.1 视觉内容：“我亲眼所见。”

别担心；视觉媒体确实很强大。它们特别擅长唤起观众的情绪。当你看到某些东西时，就好像你与屏幕或页面上的场景之间建立了一种纽带。无论是以正面还是负面的方式，大多数视觉效果都会导致你以情感的方式做出反应。

视觉媒体有两种：静态和动态。静态视觉媒体是图画和照片。在万网 Web 和互联网时代，静态图像随处可见。人们访问的几乎每个网站都有静态图像。许多大型商业网站都会显示所谓的“横幅广告”，这些商业图形旨在诱导你点击并将你带到另一个网站，在那里，你可能会为了根据你的人口统计学特征而被选中接收信息的某种产品或服务而付费。

静态图像通常很容易制作，使它们成为一种相对廉价的媒介。可以使用数码相机快速捕捉照片，或从视频源获取静态帧。其他图形可以使用常用的图形应用程序制作，例如 Adobe 的 Photoshop 或名为“Gimp”的流行开源应用程序。

静态图像的一个缺点是，如果没有某种形式的文字说明，它们很难被分类和检索。例如，如果你想找到一张伐木工砍树的照片，你可能需要花很长时间在成千上万张照片中仔细寻找其中一张。大型图库服务通过提供照片内容的文本描述，使这项任务变得简单得多。这些服务的消费者通过文本描述（通常在复杂的搜索引擎帮助下）搜索，以找到他们感兴趣的照片。

在典型的电脑桌面屏幕上，静态图像通常被用作图标，表示要执行或操纵的功能。因为人们识别图像的速度通常比识别文字快，用户经常发现在使用 GUI 时，图标可以提高他们的工作效率。问题是，在你了解这些图标代表什么之前，这些图标实际上会减慢你的速度。

动态视觉媒体确实很强大。它们特别擅长唤起观众的情绪。当你看到某些东西时，就好像你与屏幕或页面上的场景之间建立了一种纽带。无论是以正面还是负面的方式，大多数视觉效果都会导致你以情感的方式做出反应。

最后，口语由可以用文本形式表示的听觉内容组成。口语可以是从新闻广播、电台谈话节目到历史演讲的任何内容。它经常出现在听众发现自己的时间分散在吸收口语和完成某些其他任务（如通勤或做家务）之间的场合中。印刷媒体中承载的信息经常与口语重叠，因此在例如《今日美国报》（USA Today）等报纸上看到的相同信息，也会在本地和国家新闻节目中得到详细介绍。

口语的一个缺点是它是语言敏感的。说话者必须与听众使用相同的语言——在某些情况下是同一种语言的同方言。否则，几乎没有交流，口语的价值会大大削减。更糟糕的是，某些情况下，口语可能带有文化偏见，因为词汇会根据上下文以及听众和说话者的背景而具有不同的含义。虽然存在人工翻译服务，但优秀口译员的成本以及口语的媒介性，使得大多数说话者的内容无法翻译成其母语。

这三种类型的听觉内容为了发挥作用，都有编目和分类的共同需求。所有的音乐作品、声音站点和录制演讲都必须记录在某种允许快速检索的文本介质中。例如，假设某人拥有一千首没有标签的 CD 盘音乐集。人们可以想象，在任何时候寻找自己想听的特定曲目时会有多大的挫败感。文本标签即使磨损或几乎无法辨，也有助于分类每张光盘的内容。
