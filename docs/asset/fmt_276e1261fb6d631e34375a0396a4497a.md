
那么，如果我们需要大于 255 的数字怎么办？我们可以简单地使用多个字节的组合来表示更大的数字。两个字节可以表示 0 到 65536 之间的任何数字。四个字节可以表示 0 到 4294967295 之间的任何数字。现在，编写程序来将字节拼接在一起以增加数字的大小是非常困难的，并且需要一些数学知识。幸运的是，计算机会为我们完成长达 4 字节的操作。事实上，四字节数字正是我们默认处理的数字。

我们之前提到过，除了计算机拥有的普通内存外，它还有称为*寄存器*（`registers`）的专用存储位置。寄存器是计算机用于计算的地方。将寄存器想象成桌面上的一个地方——它存放着你正在处理的东西。你可能有很多信息储存在文件夹和抽屉里，但你现在正在处理的东西在桌子上。寄存器保存你当前正在操作的数字内容。

在我们正在使用的计算机上，每个寄存器都是四个字节长。典型寄存器的大小称为计算机的*字长*（`word size`）。`x86` 处理器具有四字节字长。这意味着在这些计算机上，一次处理四个字节进行计算是最自然的。这给了我们大约 40 亿个值。

地址也是四个字节（1 个字长）长，因此也可以存入寄存器。如果安装了足够的内存，`x86` 处理器可以访问多达 4294967296 字节。注意，这意味着我们可以像存储任何其他数字一样存储地址。事实上，计算机无法区分地址值、数字值、ASCII 码值或你决定用于其他用途的值之间的区别。当你尝试显示一个数字时，它就变成了一个 ASCII 码；当你尝试查找它所指向的字节时，它就变成了一个地址。花点时间思考，因为这对理解计算机程序如何工作至关重要。

存储在内存中的地址也被称为*指针*（`pointers`），因为它们内部不是存储普通值，而是指向内存中的另一个位置。

正如我们提到的，计算机指令也存储在内存中。事实上，它们的存储方式与其他数据完全相同。计算机知道某个内存位置是指令的唯一方法是一个称为*指令指针*（`instruction pointer`）的专用寄存器指向某一点。如果指令指针指向一个内存字，它就会被加载为指令。除此之外，计算机无法区分程序和其他类型的数据。

## 解析内存

计算机非常精确。因为它们非常精确，程序员也必须同样精确。如果你告诉计算机从某个位置开始执行指令而不是程序指令，谁知道计算机如何解释——但它一定会尝试。计算机将按照你指定的精确顺序执行你的指令，即使这完全没有意义。

点在于，计算机将完全执行你告诉它的事情，无论它多么不合理。因此，作为程序员，你需要确切知道你的数据在内存中是如何排列的。记住，计算机只能存储数字，所以字母、图片和其他所有内容都被编码为数字。

## 数据访问方法

处理器有许多不同的数据访问方式，称为寻址模式（`addressing modes`）。最简单的模式是*立即寻址*（`immediate mode`），其中要访问的数据嵌入指令本身中。例如，如果我们想将寄存器初始化为 0，而不是给计算机一个读取地址，我们将指定立即寻址并给出数字 0。

在*寄存器寻址*模式中，指令包含一个寄存器，而不是内存位置。

在*直接寻址*模式中，指令包含要访问的内存地址。例如，我可以说将地址 2002 的数据加载到寄存器中。计算机将直接访问字节 2002 并复制内容。

在*索引寻址*模式中，指令包含一个要访问的内存地址，并指定一个索引寄存器来偏移该地址。例如，我们可以指定地址 2002 和索引寄存器。如果索引寄存器包含数字 4，实际加载的地址将是 2006。这样一来，如果你有一组从 2002 开始的数字，你可以使用索引寄存器在它们之间循环。在 `x86` 处理器上，你还可以为索引指定一个倍数。这允许你一次访问一个字节或一次访问一个字（4 字节）。如果你访问的是整个字，你的索引需要乘以 4 获取第四元素的精确位置。例如，如果你想访问从 2002 开始的第四个字节，你会将索引寄存器设置为 3（记住，我们从 0 开始计数），并将系数设置为 1，因为你一次访问一个字节。这将得到位置 2005。然而，如果你想访问从 2002 开始的第四个字，你会将索引寄存器设置为 3，并将系数设置为 4。这将加载位置 2014 —— 第四个字。

在*间接寻址*模式中，指令包含一个寄存器，该寄存器包含指向要访问数据位置的指针。例如，如果我们使用间接地址模式并指定了 `%eax` 寄存器，而 `%eax` 寄存器包含值 4，无论内存位置 4 处是什么什么值，都将使用它。在直接寻址中，我们只需加载值 4，但在间接寻址中，我们使用 4 作为地址来查找我们想要的数据。

最后是基址寻址模式。这与间接寻址相似，但在使用寄存器值进行查找之前，你还会包含一个名为“偏移量”（`offset`）的数字。我们将在书中经常使用这种模式。

在“解释内存”一节中，我们讨论了内存中一个存储客户信息的结构。假设我们要访问客户的年龄（它是数据的第八个字节），并且我们在寄存器中有了该结构起始的地址。我们可以使用基址寻址，并将寄存器指定为基指针，将 8 指定偏移量。这类似于索引寻址，区别在于偏移量是常量且存储在寄存器中，而指针是常量。

还有其他形式的寻址，但这些是最重要的。

## 输入程序

好了，第一个程序非常简单。事实上，它除了退出之外什么都不做！它很短，但它展示了汇编语言和 Linux 编程的一些基础知识。你需要在编辑器中完全按照书中所写的输入程序，文件名为 `exit.s`。程序如下。不要担心不理解它，这一节只处理输入和运行。在“汇编程序大纲”一节中，我们将描述它是如何工作的。

```assembly
#PURPOSE: 一个退出并向 Linux 内核返回 
## 状态码的简单程序

#INPUT: 无
#OUTPUT: 返回一个状态码。可以通过输入
## 命令来查看
#
echo $?
#
```

```assembly
## 运行程序后
#
#VARIABLES:
## %eax 存储系统调用号
## %ebx 存储返回状态
#
.section .data

.section .text
.glob _start
_start:
    movl $1, %eax
    # 这是 Linux 内核命令
    # 退出程序的编号（系统调用）
    # 一个程序

    movl $0, %ebx
    # 这是我们将返回给
    # 操作系统的状态码。
    # 修改它，它将向
    # echo $? 返回不同的内容

int $0x80
    # 这唤醒内核来运行
    # exit 命令
```

你输入的内容被称为源代码。源代码是程序的人可读形式。为了将其转换为计算机可以运行的程序，我们需要对它进行汇编和链接。

第一步是汇编。汇编是将你输入的内容转换为机器指令的过程。机器本身只读取数字序列，但人类更倾向于使用单词。汇编语言是一种更具人类可读性的形式。
