
# 心宿二

天蝎座中的一颗星，是一颗光谱类型为`M1Ib`的凉凉超巨星，其红色在仲夏夜空中格外突出。心宿二的有效温度约为6000°F（3600 K），与红超巨星中最亮的参宿四相似，如果它取代太阳，其体积将延伸至火星轨道之外。心宿二距离太阳仅约100秒差距（325光年），其角直径约0.045角秒，已通过干涉法和月掩星法测得。这种类型的红超巨星起源于质量至少为太阳20倍的恒星。此类恒星迅速通过热核聚变的连续阶段演化。最终，超巨星会在II型超新星爆炸中塌缩。心宿二在一百万年内极有可能遭遇这种命运。在这一戏剧性事件之前，心宿二将通过恒星风丢失高达50%的质量，其物质被吹向周围的星际介质。参见参宿四；天蝎座；光谱类型；恒星演化；超巨星；超新星。

心宿二是一个主要由年轻恒星组成的星团成员，并与其光谱类型为`B3V`的热蓝色恒星在引力上结合，形成双星系统。这两颗恒星围绕彼此公转，周期约为900年，由此可确定红、蓝两个组分的质量分别约为太阳的15倍和7倍。超巨星强大的物质风与质量较小、较热伴星辐射的相互作用，在热星周围产生了异常朦胧的环境。参见双星；星云；恒星。

## 食蚁兽

这一名称与主要三大类现存哺乳动物中五个不同目的几种动物相关联（见表格）。它们之所以得名，是因为它们是食虫动物，以蚂蚁和白蚁为食。最常与此名称相关的动物是陆生的三趾食蚁兽 `Myrmecophaga tridactyla`，即大食蚁兽（属于无齿目 `Edentata` 食蚁兽科 `Myrmecophagidae`；见插图）。该科还有另外三种物种：四趾食蚁兽 `Tamandua tetradactyla`、`三趾食蚁兽` `T. tridactyla` 和食蚁兽 `Cyclopes didactylus`，它们都是树栖的。

所有四个物种都局限于南美洲和中美洲的热带地区。`Myrmecophaga tridactyla` 偏好草原和较为开阔的森林地带。包括约2英尺（0.6米）长的尾巴在内，该动物体长约6英尺（1.8米）。它没有牙齿，头部延伸成细长的管状吻部，嘴开口小。舌头长、可伸出，并覆盖有粘性粘液，用以捕捉昆虫。前脚具有扩大的爪子，用于挖掘蚁丘和白蚁堆，并作为防御武器。身体覆盖着长毛，在 `Cyclopes` 中尾巴具有抓握能力。雌性通常只产下一只幼崽，她可能会将其背在背上，直到幼崽长得相当大。参见土豚；无齿目；有袋类；单孔类；穿山甲目；管齿目。

## 羚羊

这一名称指牛科 `Bovidae` 亚科 `Antilopinae` 的一组中空的、偶蹄反刍动物，它们严格局限于非洲和亚洲的各种区域。它们被归类于 `Antilopinae` 亚科，包括31个属中的91个物种。

一般来说，第三和第四趾发育良好，而第二和第五趾退化或缺失。雄性和通常雌性的羚羊都有一对不分叉的角，各种羚羊物种之间角的外观差异很大。这些动物体型差异从肩高约10-12英寸（25-30厘米）的侏羚（`Neotragus pygmaeus`）到肩高约6英尺（1.8米）、重约1吨（0.9公吨）的巨型长角羚（`Taurotragus derbianus`）不等。参见偶蹄目；哺乳动物。

## 天线（电磁学）

将无线电系统的发射或接收网络与空间耦合的装置。无线电波用于通过空间从源传输信号。信息在目的地被接收，在某些情况下，如雷达，该目的地可以是发射源所在处。因此，天线既用于发射也用于接收。参见雷达。

为了具有高效率，天线的尺寸必须与所关心辐射的波长相当。在长波长情况下，如广播使用的频谱部分（1 MHz 的频率对应自由空间波长 λ 为 300 米），尺寸要求带来了严重的结构问题，因此必须使用尺寸为波长一部分的结构（如 0.1 λ 或 0.25 λ）。这样的天线可以描述为仅仅是从地球表面突出的准静电探针。

为了控制能量的扩散，可以将天线组合成阵列。随着波长变短，相对于波长可以增加天线的尺寸；按比例更大的阵列也是可能的，且

在声学和光学中熟悉的技法可以被应用（图 1）。例如，可以建造与波长相比孔径较大的喇叭。喇叭的设计可以实现从传输线（在这种情况下通常是单导体波导）到自由空间的平缓过渡。结果是宽带阻抗特性以及能量在空间分布的方向性。另一种技术是使用基本天线（如喇叭或偶极子）配合反射器或透镜。基本天线本质上是点源，基本设计问题是光学问题，即将来自点源的光线转换为平行光线束。因此，无线电探照灯通过抛物面反射器或透镜来构建。这种基本形式中尺度非常小的结构作为接收天线使用（配合适当设计的接收机）时，充当射电望远镜。用于与航天器或卫星通信的天线通常也是（与波长相比）结构。参见 射电望远镜；空间通信；传输线；波导。

小的电偶极子或磁偶极子不沿其轴方向辐射能量，恒定能量的轮廓是一个圆环面。天线最基本的要求通常涉及这个空间轮廓，称为辐射方向图。发射天线的目的是将功率引导到指定区域，而接收天线的目的是接受来自指定方向的信号。对于车辆，例如带有车载收音机的汽车，接收天线需要非方向性方向图，以便能够从位于不同位置的电台接收信号，并随着汽车移动而从任何单一电台接收信号。广播站的天线可以是方向性的；例如，位于沿海城市的电台会倾向于使用将大部分功率集中在有人居住陆地的天线。用于与通信卫星发射或接收的天线应具有朝向卫星的窄辐射方向图以实现高效工作，最好在其他方向辐射的功率基本为零，以避免干扰。参见 方向性；无线电广播。

辐射电磁波的电场平面取决于电流在天线上流动的方向。电场位于与磁偶极子轴线垂直的平面内。辐射电磁波平面对天线取向和类型的这种依赖性被称为偏振。接收天线需要与要接收的波具有相同的偏振。通过组合具有公共中心的电偶极子和磁偶极子的场，辐射场可以是椭圆偏振的；通过控制每个偶极子的贡献，可以产生从平面偏振到圆形偏振的任何椭圆度。参见 波的偏振。

天线的输入阻抗是将换能器连接到发射机或接收机的终端处电压与电流的比值。对于在某频率调谐的天线，阻抗可以是实数，但在其他频率通常会有电抗部分。

天线阵列是多个独立天线的排列，其间距和相位使得它们在优先方向上的单个贡献相加，而在其他方向上抵消。一个实际目标是提高所需方向上的信噪比。另一个目标可能是保护其他无线电台（如广播站）的服务区域。参见 信噪比。

最简单的阵列由两天线组成。它使得各种辐射方向图成为可能，从方位角上近乎均匀的辐射到将大部分能量集中在一个半球，或从能量分布在两个或多个等瓣中到辐射到对称但不等的瓣中。

为了对辐射方向图进行进一步控制，优选的布置是侧射箱形阵列。在此阵列中，天线被放置在与双向波束垂直的线上。单个天线电流在幅值和相位上是相同的。通过将相同的阵列放置在后方 90° 并保持在 90° 相位，可以将阵列制成单向的。这种箱形阵列的方向性随阵列的长度或孔径增加而增加。

阵列概念的进一步应用使得通信得到改进。通过为每个天线单元引入网络，可以接收来自源方向的信号并在源方向返回信号。返回的信号可以被调制、放大或改变频率。这样的阵列称为逆向定向阵列。基本上，阵列寻找传入信号并返回一个具有有用特性的信号，例如移动车辆与静止或缓慢移动源之间通信所需的那些特性。

天线的带宽可能受方向图形状、偏振特性和阻抗性能的限制。带宽 critically 取决于 Q 值的大小；因此，存储的电抗能量相对于辐射的电阻能量的比例越大，带宽就越窄。参见 Q（电学）。
