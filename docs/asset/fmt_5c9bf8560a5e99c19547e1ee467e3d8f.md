胚胎诱导被认为在大多数动物的组织和器官发育中起着重要作用，从低脊椎动物到高等脊椎动物。

# 肺气肿

看起来相当均匀，在19世纪以前它被认为是一种单一矿物。这种聚集体呈灰黑色，极其坚硬且难以破碎。其比重在3.7到4.3之间变化，取决于其组成矿物的相对含量。硬度约为8（莫氏度），小于纯刚蓝（9），更多取决于聚集态的物理状态或刚蓝的含量。

在许多早期用途中，所有的合成磨料已取代了云粒石，但它仍被实验室用磨料和抛光材料，并用于透镜、棱镜和其他光学设备的加工。云粒石轮、云粒石砂纸不仅用于实验室，还用于钢材的磨削和抛光。参见 磨料；磨削；磁性矿石。[C.S.Hu.]

# 发射光谱化学分析

一种通过监测和测量待分析材料发射的光谱的技术。通常，有许多进行发射测量的方法；某些结果主要取决于发射辐射在电磁光谱中的位置。发射光谱化学分析是指基于真空紫外电磁光谱（波长在800至1000纳米之间）的分析技术。该技术在实际中用于检测（定性）和确定（定量）各种条件下材料属性，例如每个样品可以检测出少于10⁻⁶的元素。

使用，电路通常是多级放大器的末级，以便能够更好地驱动低电阻负载。参见 放大器。[R.S.C.]

# 肺气肿是一种由气隙引起的肺炎症疾病。

在这个定义中，该词意味着肺实质气体能力的不可逆性丧失。这种情况并不一定意味着炎症，且肺破坏不被正确归类为肺气肿。

肺气肿可能有多种；主要是慢性支气管炎。此水平的狭窄会导致空气滞留，导致肺隔扩张和破裂。肺气肿通常由过度过度引起，或作为吸烟的结果。随着气隙扩张，肺部的总空气空间增加。

## 内分泌系统（脊椎动物） 815

放牧和房屋开发导致了水域的因果关系。很大程度上由于这种污染，美国有三类淡水鱼面临灭绝的风险。参见酸雨；水污染。

许多物种在整个栖息范围内已因人类活动而灭绝或处于濒危。例如，斑鸠鸽已经灭绝。这种曾是美国数量最多的水生鸟之一，很大程度上是因为过度开发而灭绝。这种过度开发对依赖大量个体的物种构成了威胁，例如被大型商业渔场捕捞的物种，这对许多海洋和淡水物种也是威胁。参见渔业。

保护物种的努力重点在于结束灭绝、栖息地流失和恢复种群数量。在美国，1973年的《稀危物种保护法》保护了稀危物种及其占据的生态系统。通过《濒危物种国际贸易公约》（CITES），物种免受消耗全球数量的贸易影响。超过140个国家同意禁止濒危物种贸易，并监管和监测那些可能变得濒危的物种的贸易。例如，为了防止大象数量进一步下降，国际象牙贸易已被停止。

通常，第一步是识别在整个栖息范围内面临灭绝危险的物种，并将它们加入名单。一旦被列入稀危物种名单，它们就能免受栖息地破坏、采集和繁殖等行为的侵害。这些列表包含了48个州中最濒危的物种。夏威夷州的濒危物种比任何其他州都多。与其他岛屿不同，夏威夷拥有多样化的独特物种，这些物种被认为极易灭绝，因为它们的种群数量较小，而且对引入的环境特别为敏感。

对于许多濒危物种，全球数十个设施具有巨大的容纳能力。通过繁殖个体，遗传变异可以成为拯救正在灭的物种的手段。只有当野外种群灭绝时，人工养殖才存在。对于某些物种，圈养个体被引入自然栖息地以重新建立小种群。由于物种的耗尽，重新引入可能非常困难且昂贵，特别是那些可能找不到食物或无法抵御捕食者侵害的动物。参见灭绝。

# 内分泌系统（脊椎动物）

所有具有脊椎（脊柱）的动物中的整合系统。内分泌系统由各种腺体、组织和器官组成，它们产生激素（hormone）来调节和协调身体功能。关于进化程度更高的脊椎动物所产生的激素的所有信息，将在下文中讨论——

昆虫和棘皮动物、软体动物，尤其是两两类两栖动物和爬行动物。无脊椎动物中的所有激素都是激素，它们由细胞产生。参见神经细胞。

昆虫。在幼虫发育过程中，昆虫的生长周期性发生，当一种被称为“蜕皮”的过程触发对外骨骼的限制时。一旦昆虫成年，它必须再次蜕皮。蜕皮的序列导致旧皮的脱落和新皮的生长，这由三种激素控制。雌性大脑产生一种神经激素，刺激前胸的一对腺体（前胸腺体），导致蜕皮激素（蜕皮激素）的释放。

一种由大脑附近的一对腺体产生的幼体激素，功能是抑制成年阶段的分化。幼体激素防止生长但促进成熟。参见蜕皮激素。

在昆虫的拮抗作用中，幼体激素作为一个插入起作用。另一种激素由分泌到马氏管（Malpian tubules）的细胞产生，即排泄激素。这种拮抗激素通过减少从肠道移除的液体来保护水分，同时降低马氏管中蜕皮激素的排出。

碱素（Bason）负责完全形成的身体的硬化。对于某些物种，会发生部分发育停止，被称为变态。控制神经系统和生殖系统的激素也存在，但在某些物种中，有证据表明存在调节变态的激素。极少数物种经历变态，但随着时间的推移，表皮细胞内色素颗粒的着色。这是由于表皮细胞产生的激素引起的。

甲壳动物。甲壳动物具有一种结构，在大多数物种中位于外骨骼中，用于储存和释放抑制蜕皮激素。位于身体靠近排泄器官的Y器官（Y organs）是蜕皮激素（甲壳皮激素）的来源。甲壳皮激素也从神经系统释放，可导致甲壳动物蜕皮。Y器官是神经内分泌细胞。

色素细胞。色素细胞（chromatocytes）存在于许多脊椎动物的皮肤中，特别是爬行动物和两栖动物。这些细胞的作用受细胞内色素迁移以及具有活性物质的调节。参见色素细胞。
