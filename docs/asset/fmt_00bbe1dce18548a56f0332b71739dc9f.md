## 常用命令

这是一个 Linux 和其他 Unix 类操作系统的常用控制台命令列表。每个命令都有简短说明和基本语法。列表中的所有程序都支持更复杂的命令行用法和选项，因此您应该查阅相应的 man 页以获取详情。列表按用途和/或组织，但许多命令在您的系统中具有重叠的作用。

注意，Fedora Core 还其他供您在控制台或图形桌面使用的客户端。

### 文件实用

- `bzip2` 压缩、解压缩输入。语法：`bzip2 [opts] [filenames]`
- `cat` 合并输入文件。语法：`cat [opts] [file]`
- `cdraw` 读取音频 CD。语法：`cdraw [opts] [device] [speed] [toc]`
- `dcrecord` 刻录 CD。语法：`dcrecord [opts] [device] [image]`
- `chmod` 设置文件的读、写和执行权限。语法：`chmod [opts] [file]`
- `chgrp` 更改文件或组的所有权。语法：`chgrp [opts] [group]`
- `convert` 转换图形文件。语法：`convert [opts] [file1] [file2]`
- `cp` 复制文件。语法：`cp [opts] [source] [destination]`
- `cpio` 复制、提取归包。语法：`cpio [opts] [archive]`
- `chown` 更改文件所有权。语法：`chown [opts] [username]`
- `dd` 转换为文件系统。语法：`dd [opts] [input] [output]`
- `df` 显示挂载文件系统的可用空间。语法：`df [opts] [file]`
- `diff` 比较文件或目录列表。语法：`diff [opts] [from] [to]`
- `du` 显示指定目录的大小。语法：`du [opts] [path]`
- `dump` 备份文件系统。语法：`dump [opts] [file]`
- `fdisk` 编辑设备分区。语法：`fdisk [opts] [device]`
- `filetype` 确定文件类型。语法：`filetype [opts] [file]`
- `find` 返回文件系统查询。语法：`find [opts] [path]`
- `grep` 搜索包含模式的行。语法：`grep [opts] [pattern]`
- `gpg` 加密目录。语法：`gpg [opts] [command]`
- `gzip` 压缩、解压缩输入。语法：`gzip [opts] [file]`
- `import` 从本地或远程桌面获取源。语法：`import [opts] [display]`
- `ln` 创建文件或目录的符号链接。语法：`ln [opts] [target] [name]`

### 文件实用（续）

- `mount` 挂载本地可用的远程文件系统。语法：`mount [opts] [dir]`
- `mv` 重命名文件或目录。语法：`mv [opts] [destination]`
- `parted` 编辑设备分区。语法：`parted [opts] [device]`
- `restore` 恢复文件系统。语法：`restore [opts] [dump]`
- `rm` 删除文件和目录。语法：`rm [opts] [file]`
- `rdir` 删除空目录。语法：`rdir [opts] [dir]`
- `tar` 创建、列出或解压缩归包。语法：`tar [opts] [file1] [file2]`
- `touch` 创建文件或更新时间戳。语法：`touch [opts] [file]`
- `tree` 显示目录树。语法：`tree [opts] [path]`
- `ummount` 从文件系统中卸载设备。语法：`ummount [opts] [dir]`
- `zip` 压缩解压缩归包。语法：`zip [opts]`

### 网络实用

- `curl` 通过 FTP、HTTP 获取文件。语法：`curl [opts] [URL]`
- `dig` 查询域名。语法：`dig [opts] [domain]`
- `elinks` 文本浏览器。语法：`elinks [opts] [URL]`
- `fetchmail` 从远程服务器获取邮件。语法：`fetchmail [opts] [filename]`
- `ftp` 传输协议客户端。语法：`ftp [opts] [fileserver]`
- `mail` 编写、接收和发送。语法：`mail [opts] [user]`
- `ncpft` FTP 客户端。语法：`ncpft [opts] [URL]`
- `slr` 读取新闻项目。语法：`slr [opts]`
- `traceroute` 显示到远程主机的路由。语法：`traceroute [opts] [host]`
- `wget` 通过 FTP、HTTP 获取文件。语法：`wget [opts] [URL]`
- `wdial` 连接工具。语法：`wdial [opts]`

### 网络实用（续）

- `hostname` 显示计算机的主机名。语法：`hostname [opts] [hostname]`
- `ifconfig` 配置网络接口。语法：`ifconfig [interface] [address]`
- `iwconfig` 配置无线接口。语法：`iwconfig [interface] [opts]`
- `nc` 网络读写。语法：`nc [opts] [host]`
- `netstat` 端口网络信息。语法：`netstat [opts]`
- `ping` 测量两个主机之间的往返时间。语法：`ping [opts] [host]`
- `scp` 安全拷贝命令。语法：`scp [opts] [user@file:1] [user@file:2]`

`cal` 显示当前或指定的日历。语法：`cal [opts][month][year]`
`cd` 切换目录。语法：`cd [opts]`
`chconfig` 编辑配置的网络服务。语法：`chconfig [service][action]`
`crontab` 在定期调定的时间执行命令。语法：`crontab [opts]`
`date` 显示当前日期和时间。语法：`date [MMDDhhmm]`
`dmstat` 显示网络连接。语法：`dmstat`
`echo` 将参数打印到终端。语法：`echo [opts]`
`exit` 退出当前 shell；登录。语法：`exit [status]`
`free` 显示空闲内存、交换分区和其他系统信息。语法：`free [opts]`
`hwlock` 设置系统和/或硬件锁。
`info` 显示关于命令的 GNU 信息。语法：`info [opts][name]`
`kill` 使用 ID 停止或控制运行中的进程。语法：`kill [opts][PID]`
`man` 显示帮助页。语法：`man [opts][name]`
`mc` 运行视觉化 shell。语法：`mc [opts]`
`minicom` 显示控制台客户端。语法：`minicom [opts]`
`ps` 显示进程。语法：`ps [opts]`
`pwd` 打印工作目录。语法：`pwd [opts]`
`rm` 移除管理器。语法：`rm [opts][name]`
`screen` 管理多个控制台话。语法：`screen [opts]`
`shutdown` 重启或关闭工作站/服务器。语法：`shutdown [opts][time]`
`start` 从命令行启动 X 会话。语法：`start [opts]`
`uptime` 显示系统运行时间。语法：`uptime [opts]`
`w` 向所有用户显示消息。语法：`w [opts][message]`
`watch` 每 2 秒执行一次命令。语法：`watch [opts][command]`
`what` 显示命令的页眉。语法：`what [opts][name]`
