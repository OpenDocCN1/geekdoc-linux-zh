
# 第 14 章 使用 C 标准流 I/O 函数

## 14.5 fgets 和 fputs

`fgets` 的第一个参数用于接收行数据的字符数组，第二个参数是数组的大小。该大小被传递给函数以防止缓冲区溢出。`fgets` 最多向数组中读取 `size - 1` 个字符。当它遇到换行符或文件末尾时它会停止读取。如果它读取了换行符，它会将换行符存储在缓冲区中。无论是否读取了完整的一行，`fgets` 总是会在其读取的数据末尾放置一个 0 字节。成功时返回 `s`，发生错误或遇到文件末尾时返回 `NULL` 指针。

`fputs` 写入 `s` 中的字符串，但不包含字符串末尾的 0 字节。你有责任在数组中放置任何所需的换行符并在末尾添加 0 字节。成功时返回一个非负数，错误时返回 `EOF`。

在 `fgets` 之后使用 `sscanf` 从数组中读取数据是非常有用的。它类似于 `scanf`，不同在于第一个参数是一个字符数组，它会尝试以与 `sscanf` 相同的方式进行转换。使用这种模式让你有机会使用 `sscanf` 读取数据，确定数据不是你预期的，然后使用不同的格式字符串通过 `scanf` 再次读取。

以下代码将文本从一个流拷贝到另一个流，并跳过以 `;` 开头的行：

```assembly
lea      rdi, [s]
mov      esi, 200
mov      rdx, [ifp]
call     fgets
cmp      rax, 0
je       done
mov      al, [s]
cmp      al, ';'
je       more
lea      rdi, [s]
mov      rsi, [ofp]
call     fputs
jmp      more
done:
```

### 函数原型

```c
char *fgets(char *s, int size, FILE *fp);
int fputs(char *s, FILE *fp);
```

## 14.6 fread 和 fwrite

`fread` 和 `fwrite` 函数设计用于读取和写入数组。它们的原型为：

```c
int fread(void *p, int size, int nm, FILE *fp);
int fwrite(const void *p, int size, int nm, FILE *fp);
```

`fread` 的第一个参数是要读取的数组指针，第二个参数是元素的大小，第三个参数是元素的个数。`fread` 返回实际读取的元素个数。如果返回的值小于 `nm`，则发生了错误或文件结束。`fwrite` 的第一个参数是要写入的数组指针，第二个参数是元素的大小，第三个参数是元素的个数。`fwrite` 返回实际写入的元素个数。如果发生错误则返回 `EOF`。

## 14.7 fseek 和 ftell

定位流使用 `fseek` 函数，而 `ftell` 用于确定当前位置。它们的原型为：

```c
int fseek(FILE *fp, long offset, int whence);
long ftell(FILE *fp);
```

`fseek` 的第二个参数是偏移量，第三个参数是基准（`SEEK_SET`、`SEEK_CUR` 或 `SEEK_END`）。`ftell` 返回当前位置的字节数。

## 14.8 fclose

`fclose` 用于关闭流。这是重要的，因为你可能向其写入了数据。

# 第 15 章 数据结构

数据结构在应用程序编程中被广泛使用。它们经常用于算法目的以实现栈、队列和堆。它们还被用于基于键的数据存储，被称为“字典”。

所有这些数据结构的一个共同特征是使用“节点”结构，它包含数据和指向其他节点的一个或多个指针。这些节点的内存将使用 `malloc` 分配。

## 15.1 链表

链表是由节点链组成的结构。下面是链表的插图：

| 12 | | 4 | | 16 | | 19 |

你可以看到链表有 4 个节点。这个链表中的数据没有明显的顺序。

列表可以是无序的，也可能按照插入时间有序。在列表头部插入新节点非常容易，因此列表可以按照插入时间的倒序排列。

列表通过存储在标记为 `list` 的内存位置的指针进行引用。在维护和使用该列表的代码中，列表上的节点没有用特定的标签标识。访问这些节点的唯一方法是使用列表中的指针。

### 15.1.1 列表节点结构

我们的列表将包含 2 个字段：一个数据值和一个指向下一个节点的指针。yasm 结构体定义如下：

```asm
struct      node
n_value resq  1
n_next  resq  1
        align    8
        endstruct
```

在结构体中有 2 个双字（quad-words）时不需要对齐指令，但它可以防止我们稍后产生混淆。

### 15.1.2 创建空列表

设计容器结构体时的第一个决定是如何表示一个空容器。在这个链表设计中，我们将采取最简单的选择，使用 `NULL` 指针作为空列表。尽管如此简单，但有一个创建一个空列表的函数是有益的。

```asm
newlist:
  xor     eax, eax
  ret
```

### 15.1.3 向列表插入数字

将空列表实现为 `NULL` 指针的决定为插入留了一个小问题。每次插入都会发生在列表头部，这意味着每次插入都会在列表起始指针中存储一个新的指针。有两种方法可以处理这个问题。一种方法是将指针的地址传递给插入函数。另一种方法让插入指针返回新指针，由插入代码在返回时分配该新指针。避开指针地址问题更不容易困惑。以下是插入代码：

```asm
; list = insert ( list, k );
.list equ 0
.k equ 8
push rbp
mov rbp, rsp
sub rsp, 16
mov [rsp+.list], rdi ; 保存列表指针
mov [rsp+.k], rsi    ; 并在栈上
mov edi, node_size   ; ra 将是节点指针
call malloc
mov r8, [rsp+.list]  ; 获取列表指针
mov [rax+n_next], r8 ; 将指针保存到节点中
mov r9, [rsp+.k]     ; 获取 k
mov [rax+n_value], r9 ; 将 k 保存到节点中
leave
ret
```

### 15.1.4 遍历列表

遍历列表需要使用指令 `mov rbx, [rbx+n_next]` 从一个节点的指针移动到下一个节点。我们首先检查指针看它是否为 `NULL`。如果不是，则进入循环。处理完一个节点后，我们移动指针，如果指针不为 `NULL` 则重复循环。下面的 `print` 函数遍历列表并打印每个数据项。代码展示了为什么在调用中保护几个寄存器是很好的。我们依赖 `printf` 保留 `rbx`。

```asm
print:
    segment .data
.print_fmt:
    db "%ld ",0
.newline:
    db 0x0a,0
    segment .text
.rbx equ rbp
push rbp
mov rbp, rsp ; 减去16的倍数
sub rsp, 16
mov [rsp+.rbx], rdi ; 保存 rbx 的旧值
cmp rdi, 0
je .done
mov rbx, rdi
.more:
    lea rdi, [.print_fmt]
    mov rsi, [rbx+n_value]
    xor eax, eax
    call printf
    mov rbx, [rbx+n_next]
    cmp rbx, 0
    jne .more
.done:
    lea rdi, [.newline]
    xor eax, eax
    call printf
    mov rbx, [rsp+.rbx] ; 恢复 rbx
    leave
    ret
```

我们有一个 `main` 函数，它创建一个列表，使用 `scanf` 读取值，将值插入列表并在每次插入后打印列表。

```asm
main:
.list equ 0
.k equ 8
  segment .data
.scanf_fmt:
  db "%ld",0
  segment .text
  push rbp
  mov rbp, rsp
  sub rsp, 16
  call newlist
  mov [rsp+.list], rax
.more:
  lea rdi, [.scanf_fmt]
  lea rsi, [rsp+.k]
  xor eax, eax
  call scanf
  cmp rax, 1
  jne .done
  mov rdi, [rsp+.list]
  mov rsi, [rsp+.k]
  call insert
  mov [rsp+.list], rax
  mov rdi, rax
  call print
  jmp .more
.done:
  leave
  ret
```

这里是使用该程序的示例会话，输入 1 到 5 的数字：
- 1
- 2 1
- 3 2 1
- 4 3 2 1
- 5 4 3 2 1

## 15.2 双向链表

双向链表每个节点有 2 个指针：一个指向下一个节点，一个指向前一个节点。如果你将列表设为环形并在列表头部保留一个未使用的单元，管理双向链表就会变得非常简单。这里是一个包含 4 个数据节点的列表示例：

![](img/443639abd490bee82d518502d35b07b9_171_0.png)

我们看到变量 `list` 指向列表的第一个节点，称为“头节点”。头节点有一个值，但我们从不使用它。每个节点中的指针指向列表中的下一个节点和前一个节点。头节点的前一个指针是列表中的最后一个节点。这使得列表能够实现栈（后进先出）、队列（先入先出）。双向环形列表的主要优势是消除了特殊情况。在头节点插入节点，一旦创建了列表，头节点的指针就不会改变。

### 15.2.1 双向链表节点结构

我们的列表将包含 3 个字段：一个数据值、一个指向下一个节点的指针和一个指向前一个节点的指针。yasm 结构体定义如下：

```asm
struct      node
n_value resq  1
n_next  resq  1
n_prev  resq  1
        align    8
endstruct
```

### 15.2.2 创建空列表

创建双向链表的代码分配一个新节点并设置其后继和前驱指针。这里是创建代码：

```asm
; list = newList();
newlist:
    push rbp
    mov rbp, rsp
    sub rsp, 16
    mov edi, node_size
    call malloc
    mov r8, rax
    mov [r8+n_next], r8
    mov [r8+n_prev], r8
    mov rax, r8
    leave
    ret
```

### 15.2.3 在列表头部插入

要在列表头部插入新节点，需要将头节点的后继指针指向新节点，并将头节点的后继指针放在新节点的后驱槽位。这在下面的图中所示。旧链接是虚线，新链接是带编号的实线。

![](img/443639abd490bee82d518502d35b07b9_173_0.png)

双向环形列表的优雅特性之一是消除了特殊情况。在头节点插入节点与插入任何节点的代码完全相同。插入代码如下：

```asm
; insert ( list, k );
insert:
.list equ 0
.k equ 8
push rbp
mov rbp, rsp
sub rsp, 16
mov [rsp+.list], rdi ; 保存列表指针
mov [rsp+.k], rsi    ; 并在栈上
mov edi, node_size   ; ra 将是节点指针
call malloc
mov r8, [rsp+.list]  ; 获取列表指针
mov r9, [r8+n_next]  ; 获取头节点的后继
mov [rax+n_next], r9 ; 设置新节点的后继
mov [rax+n_prev], r8 ; 设置新节点的前驱
mov [r8+n_next], rax ; 设置头节点的后继
mov [r9+n_prev], rax ; 设置新节点后继的前驱
mov r9, [rsp+.k]     ; 获取 k
mov [rax+n_value], r9 ; 将 k 保存到节点中
leave
ret
```

### 15.2.4 列表遍历

双向链表的遍历与单链表的遍历有些相似。我们需要跳过头节点，并且将当前指针与头指针进行测试以检测列表的结束。这里是打印列表的代码：

```asm
; print ( list );
print:
      segment .data
.print_fmt:
      db "%ld",0
.newline:
      db 0x0a,0
      segment .text
.list    equ     0
.rbx     equ     8
push    rbp
mov      rbp, rsp
sub      rsp, 16
mov      [rsp+.rbx], rbx
mov      [rsp+.list], rdi
mov      rbx, [rdi+n_next]
cmp      rbx, [rsp+.list]
je      .done
.more:
    lea     rdi, [.print_fmt]
    mov      rsi, [rbx+n_value]
    call    printf
    mov      rbx, [rbx+n_next]
    cmp      rbx, [rsp+.list]
    jne     .more
.done:
    lea     rdi, [.newline]
    call    printf
    mov      rbx, [rsp+.rbx]
    leave
    ret
```
