
# Linux 面试题：你最有可能遇到的问题

# Linux 问题

*复习这些典型的面试问题，并思考你会如何回答。阅读列出的答案，你将找到最佳答案以及策略和建议。*

## 硬件

**1：哪个命令显示与硬件相关的内核消息？**

- a) `dmesg`
- b) `messages`
- c) `kmesg`

**答案：**

`dmesg`

**2：哪个命令显示 PCI 卡信息？**

- a) `show_pci`
- b) `lspci`
- c) `cat /var/log/messages`

**答案：**

`lspci`

**3：命令 `lsmod` 的作用是什么？**

- a) 列出当前已加载的模块
- b) 列出可用的模块
- c) 列出未加载的模块

**答案：**

a) 列出当前已加载的模块

**4：命令 `insmod` 的作用是什么？**

- a) 显示模块信息
- b) 显示可用模块
- c) 加载一个可用模块

**答案：**

c) 加载一个可用模块

**5：服务器上第一块 SATA 驱动器的设备名称是什么？**

- a) `/dev/hda`
- b) `/dev/sda`
- c) `/dev/disk1`
- d) `/dev/diska`

**答案：**

`/dev/sda`

**6：服务器上第一块 IDE 驱动器的设备名称是什么？**

- a) `/dev/sda`
- b) `/dev/disk1`
- c) `/dev/diska`
- d) `/dev/hda`

**答案：**

`/dev/hda`

**7：哪两家显卡厂商需要专有驱动程序才能获得完整的硬件支持？**

- a) `Intel`/`Nvidia`
- b) `Nvidia`/`ATI`
- c) `ATI`/`Intel`
- d) 以上都不是

**答案：**

`Nvidia`/`ATI`

**8：哪个设备对应物理内存？**

- a) `/dev/mem`
- b) `/dev/kmem`
- c) `/dev/memory`
- d) `/dev/umem`

**答案：**

`/dev/kmem`

**9：哪个守护进程检查硬盘的健康状态？**

- a) `SMARTD`
- b) `Ide-Status`
- c) `Watchdog` `Syslog`

**答案：**

`SMARTD`

**10：哪个命令将安装基于 Realtek 8139 网卡所需的驱动程序？**

**答案：**

`insmod rt8139` 或 `modprobe rt8139`

**11：正确设置显示器需要哪两个值？**

- a) `hsync`, `esync`
- b) `hsync`, `vsync`
- c) `vsync`, 刷新率
- d) 刷新率, 位深

**答案：**

`hsync`, `vsync`

**12：32 位内核可寻址的最大 RAM 量是多少？**

- a) 3.5 GB
- b) 3 GB
- c) 4 GB
- d) 使用 `PAE` 可达 64GB

**答案：**

d) 使用 `PAE` 可达 64GB

**13：当今最流行的架构是什么？**

- a) `i386`
- b) `i686`
- c) `x86_64`
- d) `ia64`

**答案：**

`i386`

**14：你应该使用哪个命令重建 `modules.conf` 文件？**

- a) `depmod`
- b) `rmmod`
- c) `insmod`

**答案：**

`depmod`

**15：使用新的 `/proc` 布局，对应第一个串行设备端口的设备是什么？**

**答案：**

`/proc/ttyS0`

**16：哪个文件包含所有可挂载的文件系统以及所有挂载选项？**

**答案：**

```
/etc/fstab
```

**17：哪个挂载选项通过不记录每个文件的访问时间来提高磁盘性能？**

**答案：**

`noatime`

**18：你要将格式化为 `ext3` 的分区 `/dev/sda1` 挂载到 `/mnt/linux`，应该使用哪个命令？**

**答案：**

```
mount -t ext3 /dev/sda1 /mnt/linux
```

**19：哪个实用工具允许你逐块复制磁盘，或保存磁盘的逐块副本？**

**答案：**

`dd`

**20：将设备 `/dev/sda` 逐块复制到设备 `/dev/sdb` 的确切命令是什么？**

**答案：**

```
dd if=/dev/sda of=/dev/sdb
```

**21：将设备 `/dev/sda` 的逐块备份存储到文件 `/tmp/sda.img` 的确切命令是什么？**

**答案：**

```
dd if=/dev/sda of=/tmp/sda.img
```

**22：假设分区未挂载，且你想交互式地扫描 `/dev/sda1` 上的文件系统（`ext3`）错误，该如何操作？**

**答案：**

```
fsck /dev/sda1
```

**23：哪个实用工具可用于配置 `ext2`/`ext3` 文件系统的参数？**

**答案：**

`tune2fs`

## Red Hat Linux

**24：列出所有已安装 RPM 包的正确命令是什么？**

- a) `rpm -qa`
- b) `rpm -q`
- c) `rpm -list`
- d) `rpm -l`

**答案：**

`rpm -qa`

**25：在 RHEL 下，Apache 的默认配置文件在哪里？**

- a) `/etc/httpd/conf/httpd.conf`
- b) `/etc/apache2/conf/httpd.conf`
- c) `/etc/httpd/conf.d/httpd.conf`
- d) `/etc/httpd.conf`

**答案：**

`/etc/httpd/conf/httpd.conf`

**26：基于 `ncurses` 的用于配置启动服务的实用工具是什么？**

- a) `sysv`
- b) `sysrq`
- c) `ntsysv`
- d) `rund`
- e) `initd`

**答案：**

`ntsysv`

**27：你可以在哪个文件中找到已安装的 Red Hat Linux 版本？**

- a) `/etc/redhat-version`
- b) `/etc/redhat-release`
- c) `/etc/redhat/version`
- d) `/etc/uname`

**答案：**

`/etc/redhat-release`

**28：安装软件包 `httpd` 及其所有依赖项的正确命令是什么？**

- a) `rpm -i httpd-version.rpm`
- b) `yum install httpd`
- c) `yum install httpd-version.rpm`
- d) `yum search httpd | rpm -i`

**答案：**

`yum install httpd`

**29：命令 `yum clean all` 的作用是什么？**

**答案：**

移除缓存的软件包和头部文件

**30：哪个实用工具会在 `/etc/rc.d` 目录中添加启动符号链接？**

- a) `update-rc.d`
- b) `chkconfig`
- c) `init.d`
- d) `init-rc.d`

**答案：**

`chkconfig`

**31：真或假：CentOS 和 RHEL 功能相同——为其中一种设计的工具可以免费在另一种上使用。**

**答案：**

真

**32：RHEL 自带的默认 DNS 服务器是什么？**

**答案：**

`BIND`

**33：以下哪种邮件服务器软件 NOT 包含在 RHEL/CentOS 中：**

- a) `Sendmail`
- b) `Postfix`
- c) `Exim`
- d) `Qmail`

**答案：**

`Qmail`

**34：在 Red Hat Linux 安装中，哪个命令会更新所有可用的软件包？**

- a) `yum update`
- b) `yum -u upgrade`
- c) `rhn_notify`
- d) `rpm update`

**答案：**

`yum update`

**35：在使用 Red Hat Network 时，安装更新的首选命令是什么？**

- a) `yum`
- b) `yast`
- c) `up2date`
- d) `rhn_notify`

**答案：**

`up2date`

**36：在 RHEL/CentOS 中，Apache 以哪个用户身份运行？**

- a) `apache`
- b) `httpd`
- c) `apache2`
- d) `www-data`

**答案：**

`apache`
