## Linux 字典

一种功能丰富的 irc 客户端 IRC（互联网中继聊天）提供了一种与世界各地的人进行实时通信的方法。它由各种独立的 IRC 服务器网络（或称为“nets”）组成，这些机器允许用户连接到 IRC。最大的网络有 EFNet（原始的 IRC 网络，然而其同时性在线人数曾超过 32,000 人）、Uncle、DALNet、NewNet 和 Open。通常情况下，用户（如你）运行一个程序（“客户端”）来连接到某一个 IRC 网络上的服务器。该服务器在同一网络内的其他服务器之间中继信息。`irc` 程序是第一个被广泛使用的 IRC 客户端。Blackened 衍生了其他 IRC 客户端，即现代的客户端，它们都保留了 `irc` 客户端的功能并添加了各种有用或不太有用的功能。Blackened 是一个增强型的 `irc` 客户端，提供了其他客户端未包含的各种功能，包括为 IRC 服务器操作员和管理员设计的。普通用户也能受益于额外的功能。另请参考 Blackened 官方网站 `http://www.blackened.com/blackened/`。摘自 Debian 3.0rt `http://www.ldp.org/LDP/linux-Dictionary/index.html`

## blas

基础代数子程序，库 BLAS（基础线性代数子程序）是一组针对大多数向量和矩阵操作的高效例程。它们被广泛用作高质量线性代数软件的基础，例如 lapack 和 lappack。此实现是在 netbib 上找到的 Fort77 参考实现。该软件包包含该库的共享版本。摘自 Debian 3.0rt APT `http://www.ldp.org/LDP/linux-Dictionary/index.html`
