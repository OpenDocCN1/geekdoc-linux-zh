# 引言

系统访问仅通过系统管理员设置的用户登录帐户允许。用户帐户包括用户登录和使用系统所需的信息——用户登录名、密码、用户的主目录和登录初始化文件。用户帐户范围从偶尔需要只读访问少数文件的访客，到需要在多个部门之间共享信息的常规用户。
