
现代磁谱仪使用复杂的计数器望远镜和多丝正比计数器，这不仅允许识别由特定曲率半径（因此是动量，或其他）值特征化并导致信号被识别的粒子的记录。当代磁谱仪系统不仅利用了复杂的磁场、探测器和电子装置排列，而且通常还需要强大的计算机来监测和分析结果。参见“粒子探测器”。 [FA.S.]

# 核结构

在每个原子的中心都有一个微小、致密的原子核，它在不到其体积的 `10⁻¹²` 内携带了超过 `99.97%` 的原子质量。原子核是一个由强相互作用力紧密束缚的质子和中子系统，由于其作用范围极短，这些强相互作用力在自然界中通常无法被察觉。原子核的小尺寸、强相互作用力以及大量粒子构成了一个高度复杂且独特的量子系统，目前仍难以进行精确分析。对原子核及其束缚力的研究构成了核结构物理领域。参见“原子结构和光谱”；“中子”；“质子”；“量子力学”；“强核相互作用”。

原子核中的质子带正电，产生球对称电场，原子电子在其中轨道运动。带负电的原子电子云通常平衡了正核电荷，使原子呈电中性。质子的原子序数通常用 `Z` 表示，电中性的中子数用 `N` 表示。质子和中子（或核子）的总数是质量数 `A = Z + N`。同位素具有相同的原子序数 `Z`，因此是同一化学元素的形式，具有相同的化学性质，但它们的中子数不同；同中子异能素具有相同的中子数 `N`，同质量数素具有相同的质量数 `A`。参见“同质量数素”；“核物理”；“同位素”；“同中子异能素”。

原子核的质量小于其组成部分的质量之和；缺失的质量 `ΔM` 必须由结合能 `ΔM c²` 来解释（其中 `c` 是光速），结合能将核系统结合在一起。特征能量尺度以兆电子伏特为单位（`1 MeV = 1.6 × 10⁻¹³ J`）。核内相互作用力产生一个吸引势阱，将原子核结合在一起，核子在其中以高度相关的模式轨道运动。原子核的体积随质量数 `A` 大致线性增加，半径大约为 `R = 1.2 × 10⁻¹⁵ A¹/³ 米`。参见“核结合能”。

## 尺寸、形状和密度分布

已经开发了一系列精密技术来精确估计核电荷分布，包括电子散射、缪子原子研究和超精细原子结构激光光谱。核电荷分布的整体图景浮现出来。核电荷密度在内部饱和，除了最轻的核以外，其值大致恒定。原子核具有弥散的皮层，其厚度几乎恒定。

许多原子核被发现具有非球形形状。与具有由原子核产生的球对称库仑场的原子不同，核场是由核子之间短程相互作用的复杂叠加组成的，最稳定的核形状是使系统能量最小的形状。一般来说，它不是球形的，核形状最简单地由多极幂级数描述，其中最重要的项是核四极矩。正的四极矩反映了原子核伸长的形状，呈长椭球或橄榄球形，而负值则反映了扁球形状，如地球的形状。参见“核磁矩”。

准确确定核物质分布，即原子核中质子和中子的分布，更难精确测定。

## 核质量和结合能

平均结合能随质量数的变化可由贝特-魏茨泽克质量公式近似，该公式以其简洁性在重现整体结合能系统学方面值得注意。该公式通过将原子核建模为液滴来开发。通过与液滴的类比，存在一个依赖于粒子数的吸引体积项；一个排斥表面张力项；以及由于质子之间的相互库仑排斥力而产生的项，这是重核结合能减少的原因。该模型在重现核结合能、质量和核裂变能量学的整体趋势，以及预测中子和质子变得未束缚的稳定性极限方面取得了惊人的成功。然而，在预测平均核形状的情况下，将贝特-魏茨泽克质量公式的预测与测量质量进行比较时，显示出随 `N` 和 `Z` 的周期性波动，这是由于量子壳层效应。参见“核裂变”。

## 核激发态

原子核的小尺寸和紧密束缚性质对质子和中子在该系统内部可经历的轨道施加了非常严格的限制。因此，每个原子核都有一系列量子态供粒子占据。泡利原理要求每个粒子具有唯一的量子标签组。每个核态可以容纳四个粒子：自旋“向上”和“向下”的质子，以及同样两个中子。参见“角动量”；“能级（量子力学）”；“排他原理”；“宇称（量子力学）”；“量子数”；“夸克”；“自旋（量子力学）”。

当原子核的所有核子都占据最低的允许态而不违反其占据规则时，原子核最为稳定。这称为核基态。在核碰撞过程中，质子和中子可以从其最束缚态激发到较高的未占据态。这个过程通常非常短暂，粒子在大约 `10⁻¹⁵ 秒` 的时间尺度内衰减到其最稳定的构型。能量通常以伽马射线的形式释放，具有对应于初始和最终核态之间能量差的一定定义能量。有时，由于角动量选择定则，伽马衰变不被青睐，从而产生长寿命核异构体。参见“伽马射线”；“核异构现象”；“核谱”；“选择定则（物理学）”。

# 成核（核物理）

不同的时间尺度和能量。原子核非常复杂，在相似的能量下会激发出旋转、振动和单粒子自由度，且它们往往强烈混合。参见*分子结构和光谱*。

核态的静态电偶极矩和磁偶极矩以及动态跃迁矩的测量提供了大量信息。电偶极矩揭示了一系列增强的集体激发模式，包括细长形、扁平形和梨形的核形状。磁偶极矩提供了关于涉及中子（负磁矩）和质子（正磁矩）的激发之间差异的详细信息。

对于原子，使用库仑势求解薛定谔方程可以合理预测量化原子态的能量，以及它们的自旋、宇称和磁矩。试图对原子核取得同样的进展，使用各种具有核尺寸尺度的球形对称几何势，却未能重现已知的性质，直到 1949 年 M. G. Mayer 和 J. H. Jensen 独立地认识到，需要额外的自旋-轨道势才能重现已知的核态序列。这种形式的势能将自旋与轨道角动量平行的核子态结合得更紧，而不平行时则较松。随后的量子壳层间隙和亚间隙序列被正确重现。壳层模型迅速发展，其适用范围从双幻数核附近的球形受限区域扩大，涵盖了大多数质量数 `A < 60` 的轻核以及壳层闭合点附近的变形区域。

当价粒子添加到闭合的核子核心上时，相互残余相互作用可以协同作用，使核系统偏离球形产生极化。当价质子和价中子都参与时，极化效应最强。变形核势随后可以进行集体旋转，这通常涉及比其他自由度更少的能量，因此主导强烈变形核的谱。

核围绕球形和变形形状进行集体振动。这些振动的柔软程度由布居态所需的激发能来表征。振动态激发态的显著特征是它们分组为近似简并的角动量多重态，每组之间由特征声子能量分隔。

核结构研究的一个目标在于开发能够整合上述所有特征以产生统一核图的模型。广义核模型的开发与其他物理学领域相关。

有许多同位素在实验室中永远无法触及，但可能存在于恒星中，或在早期宇宙时间中存在过。广义模型的演化极大地增强了预测核行为的能力，并为宇宙学计算提供了所需的信息。参见*宇宙学*；*核合成*。

### 高激发能下的原子核

随着原子核被激发到越来越高的激发能，预计壳层效应将逐渐被统计或混沌行为所取代。在每个自旋和宇称空间内，每兆电子伏特激发能的状态数量随激发能的增加呈指数增长，直到能级变得足够接近从而强烈重叠和混合，形成连续的态。

在这一能量区间的顶部，核集体性的新模式变得可及。可以激发巨共振态，涉及核介质的压缩和振荡，其中质子和中子的振动同相（等标量）或相互拍频（同位矢量）。这些巨共振的激发和衰变可以提供关于高激发态下核形状以及核物质压缩系数的信息。巨共振研究的结果表明，壳层效应在以前被认为属于统计行为的区域内依然持续存在。参见*核巨共振*。

热核物质的半经典统计和流体动力学行为及其实验、理论和天体物理方面在最高核能区域备受关注。

正在研究压缩和热量对核物质密度的影响，以便类比经典流体的性质来测量核的状态方程。有观点认为核物质在压缩下可能发生相变，高密度凝聚态可能提供一种可测量的新状态。在最高密度和温度下，核子本身被迫重叠并合并，形成由核子构成组分夸克和胶子组成的等离子体。参见*夸克-胶子等离子体*；*相对论重离子碰撞*。[C.J.I.]

# 成核

在不稳定的过饱和溶液中形成首批能够自发生长成大晶体的沉淀颗粒。这些首批可行颗粒称为晶核，它们可以由系统中已存在的固体颗粒形成（异相成核），也可以由过饱和溶液自身自发生成（同相成核）。参见*过饱和溶液*。

成核在分析化学中具有重要意义，因为它影响沉淀的物理特性。成核期间发生的进程决定了沉淀速率以及最终结晶颗粒的数量和大小。参见*胶体*；*沉淀（化学）*。[D.H.K., L.M.G.]

# 核酸

一种酸性、链状生物大分子，由多次重复的磷酸、糖以及嘌呤和嘧啶碱基单元组成。作为一类，核酸参与每个活细胞中遗传信息的保存、复制和表达。核酸有两种类型：脱氧核糖核酸（DNA）和核糖核酸（RNA）。参见*脱氧核糖核酸（DNA）*；*核糖核酸（RNA）*。[E.J.o]

# 核子

质子或中子的统称。这些亚原子粒子是原子核的主要成分，因此也是宇宙中大多数物质的成分。质子和中子具有许多共同特征。它们具有相同的内禀自旋，几乎相同的质量，与其他亚原子粒子有类似的相互作用，并且可以通过弱相互作用相互转化。因此，通常很有用将它们视为同一种粒子——核子——的两种不同状态或构型。与原子尺寸相比，核子很小且相对较重。其特征尺寸约为典型原子尺寸的 `1/10,000`，其质量约为电子质量的 `2000` 倍。

质子和中子的主要区别在于它们的电磁性质。质子带有 `+1` 电荷，与电子相反，而中子电中性。它们具有显著不同的内禀磁矩。由于中子比质子略重（大约相差千分之一），中子是不稳定的，它会衰变成质子、电子和反中微子，其特征寿命约为 `900 秒`。尽管一些统一场理论预言质子是不稳定的，但尚未有实验探测到质子衰变。
