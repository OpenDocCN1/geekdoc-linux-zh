
在使用此命令之前，你需要为 `locate` 创建一个文件名数据库。这可以使用刚刚学过的 `sudo` 命令轻松完成，然后是 `updatedb`（等等，又一个命令！）。在要求 `sudo` 时输入密码后，看起来一段时间没有任何反应，但不要担心。只要终端光标在闪烁，当提示符返回，你就成功创建了数据库文件。

## 有点分量的命令

你目前为止尝试的简单命令都是那种安全、理智且经过消防员批准的类型；它们只是向你的终端打印信息。现在你将尝试通过你使用的命令获得一些真实切实的结果。只要你遵循我的指令，这些命令本质上是安全且理智。

## $ mkdir

你已经学会了如何通过鼠标创建文件夹，但你也可以使用命令行来实现。该命令是 `mkdir`（make directory，创建目录），使用起来像切菜一样简单（尽管我从未确定切菜是否真的简单）。

为了查看此命令如何工作，并配合后续命令进行操作，请使用 `mkdir` 命令创建一个名为 `command_exp`（命令实验）的文件夹。你只需要在一个新的终端中输入 `mkdir command_exp` 并按回车。新文件夹应该出现在你的主目录（home folder）中，所以点击桌面上的主目录图标来检查它是否存在。

好了，漂亮，非常棒！现在让我们在新文件夹内部创建另一个新文件夹——如果可以称之为子文件夹。我们将它命名为 `sub`。所以，只需输入 `mkdir command_exp/sub`。现在你可以去看看 `sub` 子文件夹是否已经已经出现在了 `command_exp` 文件夹中。

## $ mv

下一个命令是 `mv`（move，移动）命令，但在我们实验它之前，我们需要创建一个空文件——毕竟我们需要有东西可以移动。我们可以通过另一个命令——`touch` 来实现。要创建文件（我们称其为 `expfile.txt`），进入终端，输入 `touch expfile.txt` 并按回车。新文件现在会出现在你的主目录中。

当然。要移动你创建的文件，你将使用 `mv` 命令，输入 `mv expfile.txt command_exp/sub`（这告诉系统要移动哪个文件以及移动到哪里），并按回车。该文件将位于你的子文件夹中。

## $ cd

到为止，你一直是从主目录使用命令行。通过 `cd` 命令，你可以将终端的路径更改到另一个文件夹。这是一个非常实用的命令，当你执行书中的其他项目时会经常用到。来试用一下吧，通过输入 `cd command_exp` 并按回车进入 `command_exp` 文件夹。如果你操作正确，终端中的提示符应该显示为 `username@computer:~command_exp`。如果是这样，你可以给自己拍拍掌了。

当你在那里时，可以尝试带有 `-R`（recursive，递归）标志的 `ls` 命令来看看它是如何工作的。只需输入 `ls -R` 并按回车。你的终端现在将向你显示你找到了名为 `sub` 的子文件夹以及该子文件夹内部的名为 `expfile.txt` 的文件。

这就是你现在真正想做的所有操作，所以要返回主目录，只需输入 `cd` 并按回车，这将带你回到家（字面意义上的）。

作为参考，值得注意的是另外两个 `cd` 快捷键。如果你在一个文件夹的子文件夹中并想向后退一步（例如，从 `/home/rg/peas/` 回到 `/home/rg/`），你可以通过输入 `cd ..`（`cd` 和 `..` 之间有一个空格）并按回车来实现。你也可以输入 `cd -`（`cd` 和 `-` 之间有一个空格）回到你之前所在的目录（例如，从 `/home/rg/peas` 回到）。

## $ cp

由于人类天性中反复无常，你可能决定不想让 `expfile.txt` 留在子文件夹中，而是又想在它最初所在的主目录中也保留一份副本。要复制 `expfile.txt`，你可以使用 `cp`（copy，复制）命令。

执行此操作，命令需要知道你想复制的文件是什么、它叫什么，以及你想把它复制到哪里（即你的主目录）。通常情况下，你会输入 `cp command_exp/sub/expfile.txt /home/username` 来执行，但如果你记得我在第 8 章或本章开头提到的它，你可以将命令字符串中的 `/home/username` 部分缩写为 `~`，它的含义相同，这是一个需要记住的重要提示，因为波浪号在在线教程中被频繁使用。由于减少手指磨损始终是一个理想目标，请输入以下命令，然后按回车：

```
cp command_exp/sub/expfile.txt ~/
```

请确保在正在复制的文件和目标路径之间留有一个空格。完成后，该文件将出现在你的主目录中。

![](img/ba6b82a7869bba748202d57c97336dca_156_0.png)

如果你更倾向于使用字母和数字，那么你会高兴地知道还有另一种更改权限的方法，可能更加简单。在这种方法中，你只需要处理一组字母以及 `+` 和 `-` 符号。

第一组字母包含：

- `u` - User（文件所有者）
- `g` - Group（指定的用户组）
- `o` - Others（任何不是该用户也不是该组成员的其他人）
- `a` - All（以上所有项）

第二组字母包含：

| 符号 | 权限 |
| :--- | :--- |
| `r` | 读取 |
| `w` | 写入 |
| `x` | 执行 |

你可能已经能推算出这一切是如何运作的了，但以防你今天的直觉已经用尽了精力，我会为你详细解释。假设你想更改一个文件（例如 `butteraters.txt`）的权限，以便机器上的所有用户都能对其读取和写入。在打开终端窗口后，你可以通过输入 `chmod a+w butteraters.txt` 并按回车完成更改。

噢！记住，你不希望任何人更改文件的内容，对吧？好吧，要收回该文件的写入权限，你只需要输入 `chmod a- butteraters.txt` 然后按回车。如你所示，`+` 赋予权限，而 `-` 则移除权限。

不得不承认，这简单得多。

## $ apt-get

在结束本节之前，让我们用一个你可能觉得熟悉的命令来结尾：`apt-get`。是的，这个命令确实是控制强大的软件包下载和安装工具 APT 的关键，我在第 5 章中介绍过它。虽然通过命令行使用 APT 可能没有通过 Synaptic 或“添加/删除程序”时那么愉快，但在某些情况下它大派用场。我在这里为你介绍基础知识。

在使用 `apt-get` 命令之前，请确保关闭你可能打开的任何 APT 前端（例如 Synaptic）。正如我之前提到的，你一次只能运行一个 APT 工具。一旦环境允许，你应该在开始任何涉及 `apt-get` 的操作之前，先更新 APT 数据库，以便你下载到最新的内容。要做到这一点，只需输入命令 `sudo apt-get update`。

如果你想在不进入 Synaptic 的情况下安装单个软件包，可以通过输入 `sudo apt-get [package-name]` 实现。例如，如果你想下载并安装 Shufflepack 的克隆游戏 Tuxpack，你将输入 `sudo apt-get tuxpack`。如果你最终在输了太多次后对 Tuxpack 感到厌烦，可以通过输入 `sudo apt-get remove tuxpack` 来卸载它。

最后，考虑到第 5 章中提供的所有警告，如果你想通过命令行升级系统，可以输入 `sudo apt-get dist-upgrade`（但必须在先执行了 `sudo apt-get update` 之后）。
