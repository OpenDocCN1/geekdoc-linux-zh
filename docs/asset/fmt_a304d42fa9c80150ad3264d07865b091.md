# 获取邮件

- 点击“获取邮件”（Get Msg）检查新邮件。
- 可能会弹出一个对话框要求输入密码。
- 输入你的电子邮件账户密码。
- 2 点击你想阅读的邮件。
- 此区域显示另一封邮件的内容，点击该邮件。
- 3 点击“确定”。

注意：如果你让 Netscape Messenger 在第13步记住了你的密码，它只会在你第一次检查新邮件时要求输入密码。
