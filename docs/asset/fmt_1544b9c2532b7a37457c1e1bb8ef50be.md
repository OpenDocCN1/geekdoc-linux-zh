## 示例

一个 `m4` 输入文件生成两个输出文件的示例如下。`file1.m4` 可能包含如下行：

程序的条件可能包含以下行：

你可以使用 `-U` 选项定义 `VER`。如果 `file1.m4` 包含以下语句：

```
if (VER, 1, do_something)

```

那么 `Makefile` 将包含：

```
file1.0.c :

nm4 -U VER file1.m4 > file1.0.c
...

...
file1.2.c :
nm4
nm4 -D VER=2 file1.m4 > file1.2.c
...
```

## mail, rmail — 读取邮件或向用户发送邮件

### 概要 (Synopsis)

发送邮件

`/usr/bin/mail [-tw][-m message-type] recipient...`

`/usr/bin/mail [-tw][-m message-type] recipient...`

读取邮件

`/usr/bin/mail [-ehpPqr] [-f file]`

调试

`/usr/bin/mail [-x debug-level][other-mail-options] recipient...`

## 说明 (Description)

收件者通常是 `login(1)` 识别的名字。当你指定收件者时，`mail` 假设正在发送消息。它从标准输入读取到文件结束（Control-D），或者如果从终端读取，直到读取到只由一个句号组成的行。当收到这些指示器之一时，`mail` 将信件添加到每个收件者的邮件文件中。

一封信由一些头部行组成，随后跟一个空行，然后是消息内容。信件的头部行由一个或多个 UNIX 邮戳组成：

`From sender-date-and-time [remote-system-name]`

`keyword-name: [printable text]`

其中 `keyword-name` 由除 `(:)` 以外的任何可打印非空格字符组成。`Content-Length:` 指明消息内容字节数的头部行始终存在，除非信件仅由头部行组成而没有消息内容。`Content-Type:` 描述消息类型（如文本、二进制或多部分）的头部行也同样存在，除非信件仅由头部行组成。如果该信件以空格开头，则头部行可以延续到下一行。

## 选项 (Options)

发送邮件

`-m message-type`

  在头部中添加一个 `Message-Type:` 行，其值为指定的 `message-type`。

`-t`

  为每个预期的收件者在头部中添加一个 `To:` 行。

`-w`

  向远程收件者发送信件，而不等待传输完成。
