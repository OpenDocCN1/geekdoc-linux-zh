
一种食虫哺乳动物。构成三齿洞熊科（Solenodontidae）的两个物种仅限于西印度群岛。该科与其他食虫动物的关系尚不明确。古巴三齿洞熊（`Atopogale cubana`）仅存在于古巴，而海地三齿洞熊（`Solenodon paradoxus`）仅限于海地。北美已知有该科已灭绝的成员，如 `Apterodous` 和 `Micropterodous`。由于捕食性的食蟹狐（mongoose，原文如此，通常指獴/食蟹狐）的引入（最初是为了对抗蛇类），现存的两个物种如今都变得稀少。

三齿洞熊类长约 2 英尺（0.6 米），具有类似大鼠的身体。它们类似于十指豪猪（tenrecs），除了三齿洞熊类有长尾巴且没有刺。每个脚趾都有一个有力的爪子，前肢上的爪子相当大。眼睛小，吻部极度延长，腹股沟和腋窝区域有臭腺，乳腺位于臀部。它们总共有 40 颗牙齿。三齿洞熊类在夜间活动，寻找昆虫、蠕虫、植物和小型脊椎动物。参见：定义；食虫目；十指豪猪。[C.B.C]

# 螺线管（电学）

通电的绝缘线圈，在线圈内部产生磁场。如果线圈产生的磁场被用来磁化并吸引柱塞或衔铁到线圈内的一个位置，该装置可以被视为电磁铁的一种特殊形式，在此意义上，螺线管和电磁铁是同义词。在广泛的科学意义上，螺线管可用于产生均匀的磁场进行各种研究。只要线圈的长度远大于其直径（20 倍或更多），线圈中心的磁场在感觉上是均匀的，磁场强度几乎精确地由无限长螺线管方程给出。

当用作电磁铁的柱塞型时，螺线管通常有一个铁或钢外壳。外壳增加了作用在柱塞上的机械力，并有助于约束磁场。在螺线管一端添加一个按钮或止动器可以显著增加当柱塞与止动器之间距离较小时作用在柱塞上的力。图示

# 螺管（气象学）

在气象学用法中，螺管是由一组等压面（isobaric surfaces）和一组空气比容等值面（isosteric surfaces）或等密度面（isopycnic surfaces）在空间中相交形成的管状结构。等压面和等比容面的定义使得压力和比容的值从一个面到下一个面分别变化一个单位。当没有螺管存在时，即当等压面和等比容面重合时，大气状态被称为正压（barotropic）。任何单位面积平面面元切割的螺管数量是压梯度力施加的扭矩的量度，该力倾向于加速空气围绕该面积边界循环流动。参见[正压场](https://example.org/barotropic_field)；[等密面](https://example.org/isopycnic)。[FS.; H.B.B.]

# 立体（几何学）

一个由连续连接的点组成的三维几何图形，并通过称为`立体边界`的表面与空间其余部分分隔。边界上的点通常被视为立体的一部分。如果存在一个有限半径的球体可以包围该立体，则该立体是有界的。如果任何线段的所有点（该线段端点在边界上）也是立体的点，则该立体是凸的。[H.L.Ba.]

# 固溶体

由于晶体结构中原子成分被替代或缺失而导致的结晶物质的成分变化。固溶体可分为替代型、间隙型或缺失型。它们还可以根据其热力学性质（如焓、熵和自由能）进行分类（例如，理想、非理想和规范固溶体）。

可以通过考虑像橄榄石这样的特定矿物组来理解固溶体的概念。虽然橄榄石族矿物可能表现出范围广泛的成分，但它们都具有相似的晶体结构。因此，橄榄石族中的所有矿物都是同构的（具有相似的晶体结构）。然而，在这种结构框架内，成分变化很大。这种化学变化可以通过定义涉及的原子替代的性质和程度，或用极限端元成分来描述中间成分来描述。除了晶体结构内的替代外，成分变化还可通过间隙替代或缺失固溶体发生。间隙固溶体发生在离子或原子占据晶体结构中通常空位的位置时。缺失固溶体发生在原子或离子缺失于特定晶体学位置时。参见[橄榄石](https://example.org/olivine)。

固溶体在矿物中普遍存在。事实上，很少有天然矿物以纯端元物质形式存在，但都表现出微量到广泛的固溶体。固溶体的程度取决于所涉及原子或离子的相对尺寸、离子的电荷、其他矿物或液体（例如，岩浆）的共存和成分，以及形成的温度和压力条件（其中温度的影响更为显著）。[J.C.D.]

# 固态电池

一种电池，其电极和电解质均为固体（参见插图）。固体电解质是一类也称为超离子导体和快速离子导体的材料，但它们的研究属于一个称为固态离子学的科学领域。作为一类物质，这些材料是极好的离子导体，但对电子基本上是绝缘的，这些性质是任何电解质的前置条件。高离子导电性最小化了电池的内阻，从而允许高功率密度，而高电子电阻最小化自放电率，从而延长了其使用寿命。此类材料的例子包括用于Ag$^+$导电的Ag$_4$RbI$_6$；用于Li$^+$导电的Li$^+$AlLi$_2$O$_6$混合物；以及用于Na$^+$和其他一价和二价离子的粘土和$\beta$-铝石族化合物（NaAl$_x$O$_{y}$)$_n$。在室温下，钠$\beta$-铝石单晶的离子电导率为0.035 S/cm，与0.1 M HCl溶液的电导率相当。然而，由于使用粉末或陶瓷材料而非单晶，这种电导率在电池中会降低2–5倍。玻璃态和聚合物材料引起了极大兴趣，因为它们可以容易地制成薄膜形式，从而增强整个系统的速率能力。参见[电解质](https://example.org/electrolyte)；[电导率](https://example.org/electric_conductance)；[离子晶体](https://example.org/ionic_crystals)。

固态电池通常属于低功率密度和高能量密度类别。前者的限制源于在固-固界面上获取大电流的困难。然而，这些电池确实具有某些超过这一缺点的优势：它们容易微型化（例如，可以制成薄膜形式），并且没有电解质泄漏问题。它们往往具有非常长的使用寿命，通常没有与电解质冻结或沸腾相关的火灾或温度问题。作为低功率设备，它们也本质上是安全的。这些电池的主要应用是在电子设备中，如心脏起搏器、电泳显示器、手表和计算器。参见[电池](https://example.org/battery)。 (M.S.W.)

# 固态化学

研究固体基本、原子组成以及在固体内部和固体与其他相之间发生转化的科学，以产生固体。固态化学主要处理那些固体所特有的微观特征，这些特征是固体宏观化学性质和化学反应的原因。与其他物理科学分支一起，固态化学还包括提供概念和解释那些更属于该学科本身现象的相关领域。

固态化学与固态物理的重叠范围广泛。然而，两者的目的不同。一般来说，固态物理处理在固体中连续变化的性质，如能量和熵，而固态化学关注由于化学反应而不连续变化的性质。此外，固态化学倾向于基于构型空间的结构，而固态物理倾向于基于动量空间。参见[无机化学](https://example.org/inorganic_chemistry)；[固态物理](https://example.org/solid_state_physics)。

固态化学没有单一统一的理论基础，并倾向于主要是一门由几种理论基础支持的实验科学。因此，其主题划分尚未确立。固态化学的方面包括化学键、晶体缺陷、晶体结构、晶体场理论、固体中的扩散、离子晶体、晶格振动和非化学计量性。参见[非化学计量化合物](https://example.org/nonstoichiometric_compounds)。

结构研究为理解固体中的化学键、它们的性质、它们之间的反应以及成分的可变性提供了基础。许多二元化合物或相具有层状结构。层相对于彼此位移，使得结构可以分类为空间群，但当其他元素或化合物被掺入层间时，结构高度扭曲。被最广泛认为具有层状结构及相关固态化学的材料是石墨。结构信息由原子在晶格网络上的位置来表示。结构通过x射线、中子或电子的衍射来确定。固体结构的另外两个特征是给定原子周围的局部结构和更大尺度上的扩展结构。参见[石墨](https://example.org/graphite)。

固体的结构是原子间或离子间力的作用以及原子或离子的尺寸和形状的结果。因此，从逻辑上讲，应先描述键合，再描述结构。然而，电子在原子间力中的详细作用如此复杂，且关于最小化所有可能构型势能的定量方面如此困难，以至于无法推导结构。相反，有必要通过模型从结构、内聚能、折射率、电子结合能、极化率和其他性质中推导一些关于键合的信息。简单的基于经典模型的模型通常可归类为离子键、共价键、金属键以及这三种键的组合。参见[化学键](https://example.org/chemical_bonding)；[结构化学](https://example.org/structural_chemistry)。
