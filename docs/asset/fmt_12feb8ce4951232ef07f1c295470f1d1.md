# 3.9 总结

套接字抽象有两个层次。顶层是定义为`struct socket`的BSD套接字层，然后是定义为`struct sock`的协议特定套接字。

`sock_register()`是一个为不同网络族注册BSD套接字的接口。对于`INET`族，注册了类型为`net_proto_family`的`inet_family_ops`。`net_families`是一个根据网络族编号索引的全局数组。网络族套接字在此表中注册。

`inet_register_protosw()`是一个注册`INET`族支持的协议的接口。这些协议包括TCP、UDP和RAW。

`inetsw_array`是一个注册`INET`族协议的全局表，对象类型为`inet_inet_protos`。

`inet_stream_ops`是INET流BSD套接字的操作集，而`tcp_prot`是TCP套接字的协议特定操作集。

使用`sock_register()`注册的inet族类型初始化例程在应用程序调用`socket()`时会初始化BSD套接字以及协议特定的套接字。我们向`socket()`传递协议族以及协议类型，例如，创建TCP套接字时，网络族为`PF_INET`，类型为`SOCK_STREAM`。

应用程序通过描述符访问套接字，其方式与访问文件相同。`socket()`创建一个套接字并将其与VFS链接。套接字的`inode`中嵌入了一个`socket`对象，而`socket`对象也包含指向其所属`inode`的反指针。套接字的`inode`在进程文件表中创建一个条目。
