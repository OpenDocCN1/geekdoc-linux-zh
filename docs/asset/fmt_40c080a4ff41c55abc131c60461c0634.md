
# 疱疹病毒
疱疹病毒群由 50 种病毒组成，其中 7 种已知会影响人类，指的是由这些病毒引起的感染。这些病毒在自然界无处不在；大多数人人都暴露过这些病毒并对其产生免疫力。五大类包括单纯疱疹病毒 I 型和 II 型、巨细胞病毒和水痘疹病毒。在免疫受损的宿主中，大多数疱疹感染表现为病毒感染的非特异性症状，并可自愈。然而，临床表现出的感染可能导致影响个体出现严重疾病。疱疹感染的再激活（特别是免疫受损患者）是晚期癌症患者治疗和化疗期间监测的重要关注点。

疱疹病毒具有脱氧核糖核酸（DNA）核心，大小约为 150 至 200 纳米，具有二十面体对称性，并被蛋白质屏障（壳）覆盖，由感染的宿主细胞包裹。病毒颗粒结构通常包含蛋白质-水化合物结构，允许细胞粘附和细胞极化。所有病毒都需要细胞进行复制；它们可能会复制并破坏细胞，或者复制并允许细胞生存，或者将其基因组整合到宿主细胞中。这种结合现象被称为潜伏。例如，疱疹病毒在宿主系统的细胞内存在潜伏细胞。EB病毒引起淋巴细胞（循环血液中的白细胞）潜伏感染，巨细胞病毒也引起潜伏感染。病毒整合进宿主细胞，尽管目前没有抗病毒药物，因为治疗药物无法选择性地破坏或抑制病毒基因组。导致再激活的因素涉及宿主免疫系统的一部分。[癌症，疱疹；感染，潜伏，持续，静默。]

疱疹治疗干预的基础涉及几种与病毒结构相似的化合物。碱基类似物竞争或抑制组装病毒 DNA 所需的病毒聚合酶。

单纯疱疹感染是由在病毒排毒期间接触活动性病变引起的。它们通常影响生殖器，也可能影响口腔，导致皮肤出现疼痛性溃疡，且病毒在局部细胞中潜伏。再激活的机制尚不清楚，但可能持续于宿主系统。长期潜伏感染可导致严重颈宫癌的发生。

单纯疱疹病毒 I 型（口疮、发热性）影响美国 40% 的人口，通常影响口腔区域。单纯疱疹病毒 II 型（生殖器疱疹）影响生殖器、淋结或角膜炎（眼睛炎症），作为炎症性感染。单纯疱疹也可以作为继发感染发生。

单纯疱疹也会影响皮肤，引起类似水痘，但对免疫受损患者会有严重的并发症。继发感染通常影响宿主内带有潜伏病毒的老年人，涉及病毒沿皮肤扩散，这被称为带状疹。其病因是水痘疹病毒。

巨细胞病毒大多数感染发生在新生和成年人。亚急性单核细胞增多是一种综合征，其自身都是自限性疾病。然而，在受损的宿主中，接受晚期疾病化疗的患者可能会发生巨细胞病毒感染；[疱疹。]

异时性（Heterochrony）一种涉及发育速率和时间变化的进化现象。当动植物从胚胎阶段生长到成体时，它们的尺寸和形状会发生变化。个体的这种变化与其个体发育有关。个体在发育过程中经历的生长量可能比其祖先多或少。这可以应用于整体或特定部分。

进化可以看作是产生尺寸和形状变化的个体发育修饰，这可能是进化水平上的遗传学与属水平上的自然选择之间的联系。

如果进化序列中的一个性状发育比其祖先更晚，则该过程称为过发育（peramorphosis）。如果它生长得比祖先更多，则该过程称为幼态持续（paedomorphosis）。

如果发育在较早的阶段停止（例如比祖先早，在性性成熟之前），后代将保留幼体特征（早衰，progenesis）。如果后代中特定结构的发育延迟，则该结构将比祖先小（后推，postdisplacement）。

对于过发育，发育可以在后代中更早开始（比祖先更早；称为前推，predisplacement）；或者增加生长速率（加速，acceleration）；或者通过推迟性成熟尺寸而持续更长时间（过度发育，hypermorphosis）。

在生物体内，如果生长速率增加，它会产生更大的尺寸。生长时间和生长速率的变化是细胞分裂时间以及细胞生长与细胞死亡之间平衡的反映。异时性生长受起始、速率和迁移决定性元素的控制。其表达时间的变化也受控制其产生时间的基因控制。
