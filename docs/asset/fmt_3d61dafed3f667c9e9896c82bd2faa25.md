# 表 17-5 Linux `df -k` 输出感兴趣输出列

| DF 输出列 | 列内容 |
|---|---|
| 第 1 列 | 文件系统设备名称，`Filesystem` |
| 第 2 列 | 以 1k 块为单位的文件系统大小，`1k-blocks` |
| 第 4 列 | 文件系统可用空间（千字节），`Available` |
| 第 5 列 | 使用容量百分比，`Use%` |
| 第 6 列 | 文件系统的挂载点，`Mounted on` |
