### 什么是 GUI？

UNIX 在最初开发时其用户界面是基于字符的。`curses`窗口包在某种程度上是一种缓解，但在显示器上显示复杂图形或图片方面并没有提供帮助。需要更多东西；一种能为用户提供图形界面的东西。这促成了图形用户界面（GUI）一词的诞生。GUI 是底层操作系统的图形界面。

GUI 的最少组件如下：

- 一个用于以文本和/或图形形式显示数据的屏幕。

- 一个供用户输入信息的键盘接口。

- 一个控制用户可以在屏幕上移动的光标或指向设备的设备。该接口的设备可以是鼠标、光笔、调色板或手套。

此列表绝不完整，但它说明了典型 GUI 的一些最低要求。

UNIX 标准的基于字符的界面提醒了人们它的悠久。X Windows 是 UNIX 进入 GUI 时代的标志。X Windows 的开发是为了成为 UNIX 平台的标准图形用户界面而开发的。开发工作是在马萨诸塞理工学院（MIT）完成的。该 MIT 项目被称为雅典计划，由许多公司资助。最大的贡献来自数字设备公司（DEC）。

**注意：** X Window 系统有时被称为 X、X Windows、X11R5 或 X11，这取决于你正在读什么内容。

### X Windows

X Windows 的首次商业发布是 1986 年的 X10.4，它是某些商业应用程序的基础。下一次发布是 1987 年的 X11R1，随后是 1988 年的 X11R2。第 11 版本是一个完整的窗口软件包，在速度、功能灵活性和多屏幕样式方面优于 X10。X11 及后续版本已成为 UNIX 系统的*事实上的* GUI，因此是本章的重点。

**提示：** X11R4 的读法是“X Version 11, Are Four”。

X Windows 提供的主要功能如下：

- 适用于更多 UNIX 工作站的标准 GUI。请参见第 2 章“面向程序员的图形用户界面”，该章节涉及多个窗口平台和标准。

- 高可移植性。它用 C 语言编写，并设计为可移植的。

- 它具有高度的可扩展性。新功能可以实现在内核中、作为单独应用程序运行，或者可以使用 X 自带的现有应用程序。

- 它非常灵活。X中的功能数量使其变得非常复杂。然而，你可以用它做更多，因为你可以根据需要对其进行修改，并且你可以访问大量的 UNIX 工具集。

## 客户端/服务器架构

X Window 的设计目标是独立于平台和内核的。因此，它不是任何正式操作系统的一部分。X 的架构基于客户端/服务器架构。X Window 系统中的服务器与网络服务器非常不同。

服务器为用户应用程序客户端提供显示能力。这就是为什么它们被称为显示服务器（display servers）。服务器位于客户端和硬件之间。客户端向服务器请求显示操作。服务器将这些请求翻译为底层系统的硬件指令。图 1.3 显示了服务器与客户端之间的逻辑关系。

**图 1.3。**

*X 服务器与客户端的逻辑关系。*

请求通过消息队列并使用 X 协议发出。X 协议是客户端与服务器之间用于请求和响应的通信手段。X 服务器跟踪所有来自键盘和指针的用户输入。它通过 X 协议将这些信息传回给客户端。

客户端和服务器之间的工作业分工允许它们分别运行在通过网络连接的完全不同的平台之上。这提供了几项优势：如果大多数计算密集型工作可以在远程站点完成，你可以在另一个系统上运行服务器，从而让已经过载的系统免受图形开销的负担。

此外，只有服务器应用程序需要针对特定硬件进行设计。所有的客户端软件都可以设计为与平台无关，并且更容易移植。

你可以从你的服务器在多台机器上运行多个客户端。每个客户端随后都可以利用其运行所在机器的性能。

客户端还可以与其他客户端进行通信。服务器可以将此类信息保存在公共位置，并供所有其他客户端使用。这些信息被称为属性（properties）。属性仅仅是服务器为客户端记录的一段信息。更多信息请参阅 X Window 系统提供的`xprop`程序。

对于所有可自定义客户端的选项存在大量的选择。以`xterm`的手册页（man page）作为示例。X 还提供了另一种自定义外观的方法，使用名为`.Xresources`的资源文件。该文件通常位于家目录下。

**提示：** `.Xresources`文件有时被称为`.Xdefaults`。

## 窗口管理器简介

窗口的排列是由一个称为“窗口管理器”（window manager）的特殊程序的功能。窗口管理器控制特定显示器所有窗口的“外观和感受”。窗口管理器允许用户移动、重新堆叠、调整大小以及将窗口图标化（iconify）。

X Window 自带了两个窗口管理器。这些管理器分别称为标签窗口管理器（`TWM`）和 OPEN LOOK 窗口管理器（`OLWM`）。`TWM`也称为 Tom's Window Manager，以其作者 Tom LaStrange 的名字命名。X 的早期版本还提供通用窗口管理器（`UWM`）；但现在已不再提供，因为它不符合 X 联盟的《客户端间通信规范手册》（ICCCM）标准。

X 中的窗口管理器与其他窗口系统管理器不同，因为你被允许选择任何你喜欢的管理器。只要管理器遵循 ICCCM 标准，它就可以作为你的窗口管理器。

今天最流行的窗口管理器是来自 OSF 的 Motif 窗口管理器（`MWM`）。由于 Motif Window Manager 现在被开放软件环境（COSE）采用，它在 GUI 界面中比以往任何时候都重要。图 1.4 显示了`MWM`包围窗口的方式。
