
# Linux 基础 (版本 1.6) | 主题 4：Linux操作系统

## 硬件设备

记住，在 Linux 中“万物皆文件”。这意味着硬件设备信息与内核配置设置一样，都存储在位于虚拟目录中的特殊文件中。

## `/dev` 目录

设备目录 `/dev` 包含所有连接硬件设备的设备文件（节点）。这些设备文件用作设备与使用这些设备的进程之间的接口。每个设备文件属于两类之一：

## 块设备

是指以块为单位进行读写且可以被单独寻址的设备。示例包括硬盘（及其分区，如 `/dev/sda1`）、USB 闪盘、CD、DVD 等。

## 字符设备

是指数据以一次一个字符的方式顺序读写的设备。示例包括键盘、文本控制台（`/dev/console`）、串口（如 `/dev/ttyS`）等。
