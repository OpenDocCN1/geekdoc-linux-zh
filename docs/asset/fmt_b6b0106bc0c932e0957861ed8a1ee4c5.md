
`/sbin/lidsadm` `-A` `[-s subject]` `[-t | -d | -i]` `-o object` `-j TARGET`

上述命令中的选项在以下列表中解释：

- `-A`选项告知`/sbin/lidsadm`程序添加新的ACL。
- `-s subject`选项指定ACL的主题。主题可以是任何程序，例如`/bin/cat`。当不指定主题时，ACL将适用于所有内容。
- `-t`、`-d`、`-i`选项通常不需要。
- `-o object`选项用于指定对象的名称，可以是文件、目录或能力。每个ACL都需要一个命名的对象。
- `-j TARGET`选项指定ACL的目标。当新ACL的对象是文件或目录时，目标可以是`READ`、`WRITE`、`APPEND`、`DENY`和`IGNORE`。如果对象是Linux能力，则目标只能是`INHERIT`或`NO_INHERIT`，这定义了对象的子进程是否具有相同的能力。

## 保护文件和目录

您可以使用`lidsadm`来保护重要文件和目录。您可以使文件或目录只读，控制写访问，控制追加模式文件访问，并拒绝访问。LIDS为文件或目录提供以下类型的保护：

- `READ`——使文件或目录只读
- `WRITE`——允许修改文件或目录
- `IGNORE`——忽略为文件或目录设置的所有其他保护
- `APPEND`——允许向文件添加内容
- `DENY`——拒绝访问文件或目录的所有权限

## 使文件或目录只读

要使名为`/path/filename`的文件只读，请运行：

```
/sbin/lids -A -o /path/filename -j READ
```

要使名为`/my/path`的目录只读，请运行：

```
/sbin/lids -A -o /my/path -j READ
```

请注意，由于您在上述任何命令中都没有指定主题，ACL适用于所有程序。因此，没有程序可以写入上述文件或目录。如果您指定了主题，则该命令仅适用于指定的文件或目录。

## 拒绝访问文件或目录

要拒绝访问名为`/etc/shadow`的文件，请运行：

```
/sbin/lids -A -o /etc/shadow -j DENY
```

运行上述命令并重新加载LIDS配置后，您可以运行诸如`ls -l /etc/shadow`和`cat /etc/shadow`等命令，以查看是否可以访问该文件。由于您隐含指定主题为系统内的所有程序，因此这些程序都将无法看到该文件。但是，如果您需要允许诸如`/bin/login`之类的程序访问`/etc/shadow`文件，您可以通过创建新的ACL来赋予其读取权限，例如：

```
/sbin/lids -A -s /bin/login -o /etc/shadow -j READ
```

## 允许追加访问

通常，程序只需要对诸如`/var/log/messages`或`/var/log/secure`等关键系统日志进行追加访问。您可以使用以下命令为这两个文件启用追加模式：

```
/sbin/lids -A -o /var/log/messages -j APPEND
/sbin/lids -A -o /var/log/secure -j APPEND
```

## 允许仅写访问

若要允许名为`/usr/local/apache/bin/httpd`的程序能够向名为`/home/httpd`的保护目录写入数据，请运行以下命令：

```
/sbin/lids -A -o /home/httpd -j DENY
/sbin/lids -A -s /usr/local/apache/bin/httpd -o /home/httpd -j READ
```

## 删除 ACL

若要删除所有ACL规则，请运行`/sbin/lidsadm -Z`命令。若要删除单独的ACL规则，只需指定该ACL的主体（如果有）和/或对象。例如，如果您运行`/sbin/lidsadm -D -o /bin`命令，则以`/bin`为对象的所有ACL规则都会被删除。但是，如果您运行`/sbin/lidsadm -D -s /bin/login -o /bin`命令，则只有指定`/bin/login`为主体且`/bin`为对象的ACL会被删除。

> **注意** 不带任何指定`-Z`或`-D`选项会删除您所有的ACL规则。

## 一种良好的文件和目录保护方案

在本节中，我将向您展示一种您可以与LIDS配合使用的良好保护方案。该方案允许您将`/boot`目录（或分区）设为只读，这意味着内核不能被入侵者修改；它还将系统库目录`/lib`、`root`用户的家庭目录`/root`、系统配置目录`/etc`、系统守护程序二进制文件目录`/sbin`和`/usr/sbin`，以及标准二进制文件目录`/usr/bin`和`/bin`设为只读。它还仅允许对`/var/log`目录中的文件进行追加操作，从而确保日志文件不会被任何入侵者破坏。该配置如下所示：

```
# 将 /boot 目录或分区设为只读
/sbin/lidsadm -A -o /boot -j READ

# 将系统库目录设为只读
# 这也保护了 lib/modules
/sbin/lidsadm -A -o /lib -j READ

# 将 root 用户的家庭目录设为只读
/sbin/lidsadm -A -o /root -j READ

# 将系统配置目录设为只读
/sbin/lidsadm -A -o /etc -j READ

# 将守护程序二进制文件目录设为只读
/sbin/lidsadm -A -o /sbin -j READ

# 将其他守护程序二进制文件目录设为只读
/sbin/lidsadm -A -o /usr/sbin -j READ

# 将通用二进制文件目录设为只读
/sbin/lidsadm -A -o /bin -j READ

# 将其他通用二进制文件目录设为只读
/sbin/lidsadm -A -o /usr/bin -j READ

# 将通用库目录设为只读
/sbin/lidsadm -A -o /lib -j READ

# 将系统日志目录设为追加模式
/sbin/lidsadm -A -o /var/log -j APPEND

# 将 X Windows 二进制文件目录设为只读
/sbin/lidsadm -A -o /usr/X11R6/bin -j READ
```
