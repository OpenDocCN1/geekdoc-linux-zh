
`/etc/named.conf`文件包含一个用于`localhost`区域的区域语句，该语句指定区域文件为`localhost.zone`。该文件位于Fedora Core的`/var/named`目录、SUSE的`/var/local/named`目录，以及Debian和Xandros的`/etc/bind/db.local`。以下是`localhost.zone`文件内容的列表：

```text
TTL 86400
$ORIGIN localhost.
@ ID IN SOA @ root (
    42 ; serial (d. adams)
    3H ; refresh
    15M ; retry
    1W ; expiry
    1D ) ; minimum
    ID IN NS @
    ID IN A 127.0.0.1
```

此区域文件以一个`$TTL`指令开始，该指令将后续未定义TTL的记录的默认TTL（生存时间）设置为一天（86400秒）。接下来，一个`$ORIGIN`指令将域名设置为`localhost`。

在这两条指令之后，`localhost.zone`文件包含三个资源记录（RR）：一个`SOA`记录、一个`NS`记录和一个`A`记录。`SOA`和`NS`记录将`localhost`指定为该区域的主权威名称服务器。`A`记录将`localhost`的地址指定为`127.0.0.1`。

# 127.0.0.1 反向映射的区域文件

`/etc/named.conf`文件中的第三个区域语句指定了一个名为`0.0.127.in-addr.arpa.`的反向映射区域。对于此区域，在Fedora Core中区域文件是`/var/named/named.localhost`，在SUSE中是`/var/lib/named/127.0.0.zone`，在Debian、MEPIS、Ubuntu和Xandros中是`/etc/bind/db.127`。此区域文件包含以下内容：

```text
$TTL        86400
@   IN  SOA     localhost.    root.localhost.   (
                                    1997022700 ; Serial
                                    288000 ; Refresh
                                    14400 ; Retry
                                    3600000 ; Expire
                                    86400 ) ; Minimum
            IN      NS      localhost.
1            IN  PTR     localhost.
```

`SOA`和`NS`记录将`localhost`指定为主名称服务器。`PTR`记录将`localhost`指定为地址`127.0.0.1`对应的名称。

![](img/11709a8f88c8cd03868a929dc94c0e2b_681_0.png)

`SOA`记录还显示了`root.localhost.`作为该域名技术联系人的电子邮件地址。请注意，DNS区域文件使用`user.host.`（注意结尾的点）格式来表示电子邮件地址。在向联系人发送任何电子邮件时，你必须将第一个点替换为`@`，并去掉最后的点。

# 缓存名称服务器：启动与测试

在研究了缓存名称服务器的配置文件后，你可以启动名称服务器并观察其运行状态。

![](img/11709a8f88c8cd03868a929dc94c0e2b_681_1.png)

要启动名称服务器，请以`root`身份登录，并在Fedora Core和SUSE中键入`/etc/init.d/named start`。为了确保每次重启系统时`named`服务器都能启动，请在Fedora Core和SUSE中键入`chkconfig --level 35 named on`。在Debian、MEPIS、Ubuntu和Xandros中，键入`/etc/init.d/bind9 start`来启动`named`服务器。

### 配置缓存名称服务器

`named`服务器会在`/var/log/messages`文件中写入诊断日志消息。启动`named`后，你可以打开`/var/log/messages`文本来查看日志消息。如果没有来自`named`的错误消息，你可以继续进行名称服务器的测试。

在尝试使用缓存名称服务器之前，你必须指定该名称服务器作为你的主名称服务器。为此，请确保`/etc/resolv.conf`文件的第一行如下所示：

```
nameserver 127.0.0.1
```

现在，你可以使用`host`命令来测试名称服务器。例如，要通过本地主机（`localhost`）上的缓存名称服务器查询`www.gao.gov`的IP地址，请输入以下命令：

```
host www.gao.gov localhost
```

以下是`host`命令的结果输出：

```
Using domain server:
Name: localhost
Address: 127.0.0.1#53
Aliases:
  www.gao.gov  has address 161.203.16.2
```

输出显示，`host`命令使用`localhost`作为DNS服务器并返回`www.gao.gov`的IP地址。如果你得到类似的输出，说明缓存名称服务器已经启动并正在运行。

### 配置主名称服务器

配置主名称服务器最好的方法是从配置缓存名称服务器开始（如前几节所述）。然后，添加你希望此名称服务器作为主名称服务器的域的主区域。例如，假设我想为`naba.net`域定义一个主名称服务器。以下是我在Fedora Core系统上（登录为`root`后）配置该主名称服务器所经历的步骤：

1. **在`/etc/named.conf`文件中添加以下区域语句：**

   ```text
   zone "naba.net" IN {
     type master;
     file "naba.zone";
   };
   zone "0.168.192.in-addr.arpa" IN {
     type master;
     file "0.168.192.zone";
   };
   ```

2. **创建区域文件**`/var/named/naba.zone`，**包含以下行：**

   ```text
   $TTL	86400
   $ORIGIN naba.net.
   			@		1D	IN	SOA
   						@ root.naba.net (
   						100		; serial
   						3H		; refresh
   						15M		; retry
   						1W		; expiry
   						1D )
   				; minimum
   			
   			1D	IN	NS	@
   			1D	IN	A		192.168.0.7
   wpxp		IN	A	192.168.0.2
   ```

3. **创建区域文件**`/var/named/0.168.192.zone`，**包含以下行：**

   ```text
   $TTL	86400
   ; Remember zone name is: 0.168.192.in-addr.arpa
   @		IN	SOA	wpxp.naba.net.	root.naba.net. (
   			1		; Serial
   			28800	; Refresh
   			14400	; Retry
   			3600000 ; Expire
   			86400 ) ; Minimum
   		
   			IN	NS		wpxp.naba.net.
   7		IN	PTR	wpxp.naba.net.
   2		IN	PTR	wpxp.naba.net.
   ```

4. **要测试新配置，使用以下命令重启**`named`**服务器：**

   ```sh
   /etc/init.d/named restart
   ```

5. **使用**`dig`**或**`host`**查询**DNS**服务器。**

   例如，以下是我如何使用`host`在运行于`localhost`的DNS服务器上检查主机`wpxp.naba.net`地址的方法：

   ```sh
   host wpxp.naba.net localhost
   ```
