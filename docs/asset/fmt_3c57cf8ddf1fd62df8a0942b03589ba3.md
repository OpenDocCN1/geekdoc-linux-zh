## 液压跳跃

自由表面液体流动中深度的突然增加。液压跳跃的特征是上游侧流速快、水深小，而下游侧水深大、流速小。只有当上游流动为急流时，跳跃才能形成，即流体速度大于浅水重力波的小扰动传播速度 $c$（$c = \sqrt{gh}$，其中 $g$ 是重力加速度，$h$ 是水深）。在从急流转换为缓流的过程中，有相当多的能量耗散。参见“明渠流动”；“液体中的波运动”。

## 液压机

由一个大缸和一个小缸通过管道连接并充满流体组成的装置，使得作用在小活塞上产生流体压力的较小力会导致大活塞上产生较大的力。

其工作原理基于帕斯卡原理，该原理指出：当液体静止时，在一点施加压力（单位面积上的力）会导致所有其他点的压力产生相同的增加。

液压机的原理用于千斤顶、土方机械和金属成形压机（见插图）。

相对较小的供给泵在液压油中产生压力。流体随后作用在尺寸大得多的活塞上，以产生作用力。重物在液压秤上被精确称重，其中精密研磨的活塞产生的摩擦力微乎其微。参见“机械优势”；“简单机械”。

## 水力涡轮机

一种将高位供水能量转换为旋转轴机械能的机器。大多数旧式水车直接利用水的重力效应，但所有现代水力涡轮机都是喷射式和叶片式流体动力机械的一种形式，基于冲动或反作用原理工作，因此涉及将压力能转换为动能。轴驱动发电机，且转速必须为可接受的同步值。参见“发电机”；“冲动涡轮机”；“涡轮机”。

水力涡轮机装置的效率总是很高的，在扣除所有水力、冲击、轴承、摩擦、发电机和机械损失后，效率仍超过85%。材料选择不仅是机器设计和来自运行速度及水力涌浪的应力载荷问题，还涉及制造、维护以及对侵蚀、腐蚀和气蚀坑洞的抵抗能力。

抽水蓄能水电站采用各种类型的设备，在用电低谷期将水抽到高处的蓄水水库，并在用电高峰期间，当水从高处的水库流经水力涡轮机时发电。参见“水力发电”。

## 液压挺柱

一种消除内燃机气门机构中机械间隙需求的装置。通常需要考虑间隙，以防止气门机构受热膨胀时气门被顶开并损坏。然而，间隙需要频繁调整，并且是许多运行噪音的来源。液压挺柱是凸轮和气门之间连杆中的伸缩式压缩支柱，由活塞和气缸组成（见插图）。当不存在对抗载荷时，弱弹簧移动活塞，延伸支柱并消除任何间隙。此动作通过止回阀将油吸入气缸。被困住的油以极小的变形传递开启气门的力。支柱顶端的轻微泄漏槽允许气门关闭。当弹簧在无载荷下再次延伸支柱时，泄漏的油会被替换。[ARR.]

## 水力学

工程学的一个分支，专注于收集和储存、测量、输送、控制和使用水及其他液体的实际问题。它与更理论化的流体力学不同，流体力学还包括对气体的研究；也与水文学不同，水文学是研究地球水的性质、分布和循环的学科。参见“流体力学”；“水文学”。

许多水力学问题涉及管道流动。管道流动沿能量降低的方向发生。根据伯努利定理，管道中的主要能量形式是位能（流体高度）、压力能和动能。如果压力能和动能足够大，足以克服位能，流体可以被强制向上流动。这可以通过向液体添加压力能的泵来实现。参见“伯努利定理”；“泵”。

运动液体在速度或流动方向改变时都会产生力。例如，在消防水枪喷嘴处、管道弯头处以及当流动的水用于驱动涡轮时都会产生力。该力通常与流量、质量密度和速度变化成正比。参见“流体流动”；“水动力学”；“射流流动”；“涡轮机”。

液体通常通过明渠而不是管道输送。与管道一样，能量不平衡导致明渠中的流动。主要的能量形式是位能、流动深度和动能。能量平衡方法用于解决许多渐变流（即深度随短距离缓慢变化）的问题，但急变流需要动量平衡。

水力学原理适用于许多其他科学和工程领域。例如，地下水流动在地质学中研究，并受水力学原理支配。海岸水力学是海洋学的一个重要子集。某些结构（如防波堤、大坝、溢洪道、船闸、栈桥、堤防、干船坞和水箱）的设计需要理解水力学概念。为了更好地了解与这些大型结构相关的复杂力和水流，经常使用比例模型。参见“海岸工程”；“大坝”；“量纲分析”；“地质学”；“地下水水文学”；“河流工程”。[R.J.H.]

## 肼

一种无色液体，H₂NNH₂（沸点 114 C 或 237 F），具有霉味和类似氨的气味。物理性质上与水相似，但在化学性质上具有还原性、可分解性、碱性及双功能性。其衍生物从简单的盐到环化合物、聚合物和配位络合物不等。肼的主要用途包括如此多样的应用，如火箭燃料、锅炉中的腐蚀抑制、生物活性物质的合成，以及橡胶硫化泡沫橡胶生产。[H.D.]

## 氢化物

孤立的原子氢阴离子，H⁻。它由一个单电荷正原子核和两个电子组成。电子-电子排斥几乎抵消了核-电子吸引。因此，“额外”的电子被弱束缚，并易于捐赠。含有这种大且易极化离子的离子盐具有高度反应性、强碱性和强还原性。尽管它们极易被相对酸性的化合物水（H₂O）的存在或空气中相对氧化性的双氧（O₂）破坏，但它们仍是重要的试剂。参见“电子构型”。

术语氢化物也指含有 H⁻ 阴离子和高度电正性碱金属或碱土金属阳离子的盐。盐的名称反映了这种离子特性；例如，氢化钠（NaH）。在此类盐中，H⁻ 的离子半径与 Cl⁻ 相当。

存在由 H⁻ 盐与某些更具共价性的金属或类金属氢化合物形式反应形成的复杂金属氢化物。最早被研究的包括氢化铝锂（LiAlH₄）和硼氢化钠（NaBH₄）。

一些具有金属-氢键的化合物也被称为氢化物。例如，六羰基钴 [Co(CO)₆] 和二氢四羰基镍酸盐 [H₂Ni(CO)₄] 常通过类比相应的卤化物被称为钴四碳硼基氢化物和 H-铁羰基二氢化物。参见“配位络合物”；“金属氢化物”。

理想情况下，氢化物这一术语应保留给那些含有 H⁻ 或至少在所谓的氢化物转移反应中形式上将此离子转移给另一种物质的物种。此类反应存在于异丁烯和异丁烷工业合成 2,2,4-三甲基戊烷（异辛烷）的过程中，以及许多经典有机化学命名反应中。在维生素烟酸（烟酰胺）的许多生物重要性氧化还原反应中，烟酰胺腺嘌呤二核苷酸（加氢烟酰胺腺嘌呤二核苷酸）（NAD⁺/NADH）和烟酰胺腺嘌呤二核苷酸磷酸（NADP⁺/NADPH）形式的氢化物转移也很重要。参见“烟酸”；“烟酰胺腺嘌呤二核苷酸（NAD）”；“烟酰胺腺嘌呤二核苷酸磷酸（NADP）”。[F.L.]

## 氢化物络合物

含有与中心原子结合的氢化物配体的络合氢化物。有时使用前缀 hydride 而非氢化物。所有此类物质均溶于芳香烃。它们相当昂贵，但其特定的还原能力使其成为合成高价值产品（如药物、调味剂、香料、染料和杀虫剂）的诱人选择。参见“配位络合物”；“金属氢化物”。[J.C.W.]

## 氢硼化反应

通过二硼烷加到不饱和有机化合物上产生有机硼烷的过程。在其他溶剂中，二硼烷加到此类底物上极其迅速且基本是定量的。因此，该反应使有机硼烷易于获得。由于有机硼烷作为有机合成中间体的应用日益增加。

二硼烷在四氢呋喃中高度可溶，在其中以加合物四氢呋喃-硼烷的形式存在。此类溶液常用于氢硼化反应，大多数研究涉及使两种反应物如反应（1）所示结合。

```
3RCH = CH₂ + C₄H₈OHB₃ → (RCH₂CH₂)₃B + C₄H₈O (1)
```

或者，可以利用硼氢化钠通过添加三氟化硼乙醚来实现氢硼化。这由反应（2）表示。通常有机硼烷不被分离，而是在原地利用，类似于合成中格氏试剂的应用。

```
12RCH = CH₂ + 3NaBH₄ + 4C₄H₈OBF₃ → 4(RCH₂CH₂)₃B + 3NaBF₄ + 4(C₄H₈)₂O (2)
```

有机硼烷是有机化学家可用的最多样的合成中间体之一。氢硼化反应使这些中间体易于获得。参见“硼烷”。[H.C.B.]
