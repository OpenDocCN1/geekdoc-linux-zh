# `sag` — 系统活动图

### 概要

`/usr/sbin/sag [-e time] [-f file][-i sec][-s time] [-T term] [-x spec] [-y spec]`

## 描述

使用 `sag` 命令图形化显示由之前的 `sar(1)` 运行存储在二进制文件中的系统活动数据。你可以绘制任何 `sag` 数据项的单独图或组合，作为交叉图或随时间变化的图。你可以指定数据的简单算术组合。`sag` 调度 `sar` 并找到所需的

通过字符串匹配数据列标题获取数据（运行 `sar` 查看可用内容）。`sag` 命令需要图形化终端来绘制图表，并使用 `tplot(1)` 生成输出。在运行 Solaris 2.3 和 OpenWindows 运行时，请执行以下步骤：

- 1. 以 root 身份，输入 `xterm -t` 并按回车，以 Tektron 终端模式运行 xterm。
- 2. 在 xterm 窗口中，输入 `sag -T tek options` 并按回车。

以下选项将传递给 `sar`。

- `- time` 选择某个时间之前的数据。默认为 18:00。
- `file` 使用文件作为 `sar` 的数据源。默认是当前每日数据文件 `/usr/adm/sa/sadd`。
- `interval` 以尽可能接近几秒钟的间隔选择数据。
- `time` 选择 `hh[:mm]` 格式时间之后的数据。默认为 00:00。

其他选项：

如果 `spec` 包含空格，请用双引号 (`" "`) 将其括起来。

x 轴允许指定单个 `spec`。如果未指定，则使用时间。

- `-y spec` 使用与 `-x` 相同格式的 `spec` 指定 y 轴。你可以指定最多五个用分号 (`;`) 分隔的 `spec` 参数。

```
-y "%usr 0 100; %sys 0 100; %usr + %sys + %wio 0 100"
```

## `sar` — 系统报告

### Synopsis

`/usr/sbin/sar [-aAbcdgkmpqruvvy] [-o filename] t [n]`

`/usr/sbin/sar [-aAbcdgkmpqruvvy] [-etime] [-ffilename] [-isec] [-stime]`

### Description

使用 `sar` 命令查看时间段内所有系统活动的完整概。在第一种摘要格式中，`sar` 以每 `t` 秒为间隔对操作系统中的活动计数进行采样，其中 `t` 应该为 5 或更大。如果你通过多个选项指定 `t`，将打印所有头，且输出可能难以阅读（如果采样间隔小于 5，`sar` 自身的活动可能会影响采样）。如果你指定 `-o` 选项，`sar` 将以二进制格式将采样保存在 `filename` 中。`n` 的默认值为 1。

在第二种摘要格式中，你没有指定采样间隔。相反，`sar` 从之前记录的文件中提取数据，可以是 `-f` 选项指定的文件，或者是默认的当天 `dd` 的标准系统活动每日数据文件 `/var/adm/sa/sad`。你可以使用 `-e` 和 `-s` 参数配合 `hh[:mm[:ss]]` 格式的时间来限制报告的开始和结束时间。`-i` 选项按每 `sec` 秒的间隔选择记录。否则，将报告数据文件中找到的所有间隔。

### Options

以下选项修改由 `sar` 报告的信息子集。

- `-a` 报告文件访问系统例程的使用情况 `get/s`, `namei/s`, `dirlkb/s`
- `-A` 报告所有数据。等同于 `-abcdgkmpqruvvy`。
- `-b` 报告缓冲区活动：`bread/s`, `bwrite/s` 系统缓冲区与磁盘或其他块设备之间每秒传输的数据传输量。`read/s`, `lwrit/s` 访问系统缓冲区。`rcache`, `%cache` 缓存命中率，即 `(1-read)` 的百分比。`pwrite/s` 每秒写入量。
- `-c` 报告系统调用。`scall/s` 所有类型的系统调用。`read/s`, `wchar/s` 每秒读取的字符，写入的字符。
- `-d` 报告每个块设备（例如磁盘或磁带）的活动。`spec` 规定是磁盘或磁带。`spec` 规定是。磁带。`spec` 规定是磁盘。`seek/s` 传输量。`avseek/s` 磁盘的寻道次数，平均寻道时间。
- `-e` 选择某个时间之前的数据。默认为 18:00。
- `-f` 使用文件作为 `sar` 的数据源。默认是 `/usr/adm/sa/sadd`。
- `-g` 报告分页活动：`pgout/s` 每秒换出页面。`pgfree` 报告空闲内存页。`pgscan/s` 每秒被扫描的页面。
- `-i` 以每 `sec` 秒的间隔选择记录。
- `-k` 报告内核内存分配。`smi_s`, `alloc/s` 内存分配量。
- `-m` 报告信号量活动。`msg/s`, `sem/s` 每秒信号量。
- `-o` 以二进制格式将采样保存在 `filename`。
- `-p` 报告分页错误。`pgin/s` 每秒换入页面。`ppgin/s` 每秒换入页面。`pflt/s` 每秒保护页错误。`flt/s` 每秒非法错误。
- `-q` 报告平均队列长度。`run-sz` 运行队列长度。
- `-u` 报告 CPU 使用率，`$usr`, `%sys`, `%wio`, `%idle` 在用户模式运行、系统模式运行、等待 I/O 以及其他空闲的时间百分比。
- `-v` 报告进程、inode、表的状态。`proc-sz`, `in-sz`, `file-sz`, `lock-sz` 每个表在采样点评估一次。
- `-w` 报告系统交换和进程切换活动。`swpin/s`, `swpot/s`, `bwin/s`, `swot/s` 采样点之间的溢出。`pswch/s` 进程切换。换入和换出的 512 字节传输量（包括某些程序的初始加载）。
- `-y` 报告 TTY 设备活动。`rawch/s`, `canch/s`, `outch/s` 输入字符率、经处理的输入字符率、输出字符率。
- `rcvin/s`, `xtmin/s`, `mdmin/s` 接收、传输和调制调器中断率。
