# 故障排除域名服务

域名服务（DNS）故障表现为应用程序由于无法解析所需的 IP 地址而无法连接远程主机。名称解析问题会导致工作站屏幕上显示诸如“unknown hostname”（未知主机名）或“Host name lookup failure”（主机名查找失败）之类的错误消息。

有两个同样强大的工具可以用于排查 DNS 问题：`nslookup` 和 `dig`。在前面的章节中，介绍了 `nslookup` 的一些功能。在本节中将介绍它的更多功能。`dig` 提供了几乎相同的能力，区别在于：`nslookup` 与 `named`（即 DNS 守护进程）建立交互会话，而 `dig` 不。由于 `nslookup` 和 `dig` 之间的相似性，感兴趣的读者自行研究 `dig` 的 man 页面以获取详情。

# DNS 故障排除方法

遵循导致“不可靠”DNS 服务的主要原因：

- **输入错误**：从哪里开始寻找 DNS 故障的原因？如果被问及，十个 named 管理员中有一个会建议你从这里开始。用户报告的问题主要是由于输入错误，这非常常见。然而，每当用户遇到应用程序无法建立到名称服务查找的连接时，你都要去该用户的工作站，让用户再试一次。注意用户是如何使用远程主机的。如果错误仍然存在，请使用输入的名称对该问题进行进一步调查。
- **数据库文件序列化错误**：系统管理员在更新后增加 `named` 数据库文件的序列号这并不是一个罕见的错误。记住之前的讨论，如果主服务器的数据库序列号增加了，从服务器将忽略区域传输（zonal transfer）以获取更新。当需要刷新时，从服务器会将其所拥有的的每个数据库文件的序列号与主服务器上的对应文件进行匹配。如果主服务器的序列号不大于从服务器，则后者认为没有需要传输的内容。
- **数据库文件序列化错误会导致一个或两个问题**：
    - **名称解析不一致**：表现为根据响应查询的服务器不同，对查询的答案存在冲突。这种情况主要发生在响应查询的服务器上。（注：提供的 OCR 文本在此处似乎断开/重复，此处遵循提供的文本）。

## 故障排除

以下是 NFS 的常见症状：

- 服务器挂起：对挂起服务器的响应是超时。事务未完成会导致客户端无限重试。挂起的服务器强制 `rpcinfo` 带错误消息退出。
- 连接性问题：由于传输基础设施故障引起的连接性问题通常会导致错误消息 `rpcinfo: can't contact portmapper: RPC: tls error`。传输失败可能是由于“可达性”（Reachability）部分已处理的任何原因。请参考该章节处理这些情况。
- RPC 服务版本不匹配：任何服务的客户端和服务器端都必须运行所调用服务的兼容版本。否则，即使 NFS 文件系统“成功”挂载，服务器也可能无法提供客户端请求的服务。使用以下 `rpcinfo` 语法有助于验证版本兼容性：
    - `rpcinfo -u hostname [version]`
    - 或
    - `rpcinfo -t hostname [version]`

在此语法中，`u` 和 `t` 分别代表 UDP 和 TCP 传输。`program` 指定服务的名称，`version` 是你想要的版本。这是一个示例：

```
# rpcinfo -u nfs 2
program 100003 version 2 ready and waiting
```

相反，如果你想要指定服务的所有支持版本列表，可以忽略版本指定。这是一个示例：

```
# rpcinfo -u tenor lockmgr
program 100021 version 1 ready and waiting
rpcinfo: RPC: Procedure unavailable
program 100021 version 2 is not available
program 100021 version 3 ready and waiting
```

运行级别错误：除非将 UNIX 启动到运行级别 3，否则主机不会启动 NFS 服务。

因此，用户将无法从该处挂载 NFS 文件系统。系统管理员可以手动启动三级运行。除非更新启动脚本以反映进入三级的意图，否则主机在 UNIX 重启时将无法进入该级别。验证系统所处的级别非常简单，只需输入以下命令即可：

```
# who -r
run-level 3  Apr 11 20:27  3  0  2
```

`nfsstat` 更像是一个性能监控工具，调用时它会提供与 NFS 服务相关的统计数据。在未指定选项的情况下，`nfsstat` 会返回服务的客户端和服务器端的统计数据。在尝试改进或调整 NFS 性能时，这些数据可能非常有用。建议读者咨询手册以获取有关使用 `nfsstat` 命令的更多细节。以下是执行 `nfsstat` 的示例，使用 `-s` 选项指定服务器统计信息：

```
# nfsstat -s
```
