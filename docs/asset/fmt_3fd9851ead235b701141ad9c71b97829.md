
颗粒和孔隙的大小、形状和取向是岩石与其成因相关的最重要特征。这些特征也影响密度、孔隙度、渗透率、强度和磁性行为。此外，为了命名岩石并推断其形成条件，了解组成颗粒的矿物的身份、丰度和成分也是必不可少的。

岩石学家研究有机沉积物和无机物体，岩石学分析对古生物学家和石油地质学家都有用。煤的质量通过偏光显微镜和反射光显微镜揭示。橄榄石和盐晶体中的石油和沥青包裹物帮助科学家推断石油形成与沉积物压实及其他改性的联系。参见[古生物学；石油地质学]。

岩石学家还研究合成物体。岩石学家通过研究金属和合金的晶粒组织来理解是什么使这些材料具有强度和耐蚀性。玻璃和陶瓷中的缺陷通过显微技术和偏光技术揭示。某些陶器中的矿物和岩石碎片有助于确定其来源，并帮助追溯史前贸易路线。空气和水中颗粒物的工业、农业和自然来源可能通过岩石学研究来确定。参见[矿物学；岩石学]。[A.T.A.]

## 石油膏

石油膏是矿物油与从石油润滑油残余类型中结晶出的蜡形成的光滑半固体混合物。蜡分子是微晶体，并以凝胶形式保持大量油。石油膏之所以有用，是因为它们能附着、润滑并抵抗水分和氧化。它们用作银行和凸轮加工中的润滑剂；抛光剂、化妆品和软膏的载体；防锈剂；纸张的防水剂；以及其他需要惰性油脂材料的用途。[J.K.R.]

## 石油

未精炼的油，即原油，存在于地下和海床下，位于砂岩、石灰岩或白云岩颗粒之间的空隙中（不在洞穴中）。石油是液体的混合物，颜色从几乎无色到漆黑不等，粘度从比水稀到比糖浆浓不等，密度从轻质气体到比水重的沥青不等。它可以通过蒸馏分离成分馏分，范围从轻质、低密度、低粘度到相反极端。在原油从地面渗出的地方，其挥发性馏分已蒸发，留下致密、黑色的油部分形成沥青或焦油池（如加利福尼亚州的布雷油池）。如今，世界上的大部分原油是通过钻探井生产的。参见[石油工程]。

石油主要由烃分子组成。烃的四个主要类别是烷烃（也称为石蜡）、烯烃、环丙烷（环烷烃）和芳香烃。原油中不含烯烃，但可以在某些精炼过程。最简单的烃类是由一个碳原子与四个氢原子结合而成的（化学式 CH₄），称为甲烷。参见*烷烃*；*石蜡*。

石油通常包含除炔烃以外的所有可能的烃类结构，每个分子中的碳原子数量可达一百个甚至更多。这些馏分包含含有硫、氮、氧和金属原子的化合物。随着分子尺寸的增加，含有这些原子的化合物比例也随之增加。

沥青质分子包含许多环状化合物，其中环状结构含有硫、氮或氧原子；这些被称为杂环化合物。吡啶就是一个例子。参见*沥青与沥青岩*。

普遍认为，石油的形成过程类似于煤炭形成的过程，但它是源自小型动物而非植物。死亡的生物体在数百万年间被掩埋在泥沙中。覆盖在这些泥沙层之上的进一步沉积层在某些情况下已达到数千英尺的厚度，并压实了下面的地层，直到泥沙变成页岩岩。泥沙层受到上层加热和压缩。泥沙中生物体的遗骸分解并转化为脂肪状液体和固体。加热这些脂肪物质很长一段时间导致其分子分解为更小的碎片并结合成更大的分子，因此最初的分子尺寸范围大大扩展到了原油中发现的范围。细菌通常存在，并有助于从分子中去除氧气，将其转化为烃类化合物。上覆岩层的巨大压力有助于将石油从压实的页岩层中挤压出来，进入页岩层旁边压实程度较低的石灰岩、白云岩或砂岩层。参见*地质学*；*石灰岩*；*有机地球化学*；*石油地质学*；*砂岩*；*沉积作用*；*页岩*。

在深度超过约 25,000 英尺（7620 米）时，温度极高，石油转化过程完全变成天然气并停止。由转化过程形成的天然气如今也在各种深度被发现，这些深度并不指示其原始来源的深度和温度。参见*天然气*。

由自然热力和细菌过程形成的石油被从压实的泥沙层中挤压出来，进入砂岩或石灰岩层，并在倾斜的层中向上迁移。构造过程导致这种向上隆起和鼓胀，形成脊和穹窿。当脊和穹窿被已经形成的页岩覆盖时，页岩的孔隙太小，无法让石油通过，因此页岩起到了密封盖的作用。当石油无法继续上升时，它就被封闭了。含有石油或天然气的多孔岩石所在的这种结构被称为石油或天然气储层。

典型储层的采油率并不像人们想象的那样高。多层储层通常包含具有广泛渗透率范围的含油层。当从最高渗透率层中达到尽可能完全的采油后，低渗透率层通常仅被轻微耗尽，尽管已做出各种努力以提高采收率。尽管采取了提高采收率的措施，原始存在于石油储层中的石油有一半或更多仍然留在其中。参见*石油提高采收率*；*石油储层*；*石油储层工程*。

重油和油砂油（沥青质）是发现于沉积岩中的石油烃类。它们由原油的氧化和生物降解形成，以液态或半固态形式存在于石灰岩、砂岩或砂中。参见*沥青*。

这些石油的特征是其粘度；然而，当无法获得粘度测量值时，密度（或 API 比重）也被使用。重油含有 3 wt% 或更多的硫，以及高达 200 ppm 的钒。钛、锌、锆、镁、锰、铜、铁和铝是可以发现于这些矿床中的其他微量元素。其高石蜡酸含量使炼油加工设备容易受到腐蚀。参见*油气田开采*。

## 石油工程

用于开发原油和天然气储层的技术。通常细分为石油物理、地质、储层钻井、生产和建设工程等分支。在发现石油或天然气储量后，储层的技术监督权移交给石油工程团队，尽管在勘探阶段，钻井和石油物理工程师在发现的评价和完井中发挥了作用。

通过使用井下测井工具和对钻井作业期间岩心的实验室分析，石油物理工程师估算在钻井现场采样的储层岩石的孔隙度、渗透率和含油率。参见*测井*。

地质工程师利用石油物理数据、勘探期间进行的地震调查以及对区域和环境地质学的分析，开发关于储层侧向连续性和范围的推断。参见*石油地质学*。

储层工程师利用石油物理和地质工程师的初步研究以及钻入储层的早期井的表现，试图评估单口井和整个储层能够维持的产量（每天多少桶石油或多少百万立方英尺天然气）。储层工程师的主要任务之一是估算来自初级和加强采油的最终产量。参见*石油提高采收率*；*石油储量*；*石油储层工程*。

钻井工程师负责通过井眼有效地穿透地球，以及从地面到通常刚好位于目标储层上方的深度对钢套管进行固井。钻井工程师或泥浆工程师中的另一位专家负责管理通过钻杆连续循环并在钻杆与井眼之间的环空返回地面的流体。

生产工程师在与石油物理和储层工程师协商后，规划井的完井程序。这包括选择跨地层设置衬管或射开已固井跨储层的套管，选择适当的泵送技术，以及选择地面收集、脱水和储存设施。参见*油气井完井*。

重大建设工程，如海上平台的设计和建造，要求石油工程部门的人员中增加土木工程师；而天然汽油和天然气加工厂的设计和实施则要求增加化学工程师。参见*海上油气*；*石油*。

关系型数据库和高级计算机图形学被用于石油勘探。重点在于快速收集数据并提取选定项目，以提供有效的显示和解释。总体而言，石油计算可以视为三个层次：地球物理计算、地球物理计算（此处原文重复，照译）和工程应用。地质计算趋势集中在数据库和空间系统配置上，以及诸如剖面平衡或地球化学建模等专门应用。地球物理计算倾向于计算机密集型；解释安装与所有交互式工作站和微型室一样，由图形驱动。工程应用也是计算机密集型的；它们通常被归类为模拟或过程类型。

## 石油提高采收率

用于提高多孔地层中石油采收率的技术，使其超过常规手段获得的水平。常规石油采收技术平均仅能生产出原地石油量的三分之一。常规技术是初级或次级的。初级技术依靠原生能量，即以流体和岩石压缩性及天然含水层的形式，从地层中将石油产出至井中。次级技术通过向注水井注入水或低压气体来补充原生能量，驱动石油流向生产井。加强石油采收技术的目标是那部分未被初级和次级采收系统采出的大量石油。参见*石油工程*。

次级技术面临的许多挑战与加强采收技术面临的挑战相同。这些挑战包括降低残余油饱和度、提高波及效率、使技术适应储层非均质性，以及最小化前期和操作成本。

在岩石被水、气体或任何其他采收流体扫过后，残余油仍然被困在多孔岩石中。残余油饱和度是残余油占据孔隙空间百分比。残余油饱和度取决于孔隙大小分布和连通性、采收剂与油之间的界面张力、岩石表面相对于采收剂和油的可润湿性、流体粘度以及流体通过岩石的流速。

波及效率指定了被采收剂接触到的储层部分。波及效率随注入流体体积的增加而增加。它还取决于注入和生产模式，以及岩石、石油和采收流体的综合作用效果，以及地层的非均质性。

人们已考虑了多种过程来提高石油采收率：热力过程、高压气体过程和化学过程。具体而言，通过选择提供油与流体之间极低界面张力的采收流体，可以获得低残余油饱和度。极低界面张力意味着毛细数较大。此外，通过选择低流动度的采收剂或增加石油的流动度，可以获得高波及效率。[R.L.C.H.]
