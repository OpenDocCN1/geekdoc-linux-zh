### 显示消息

大多数 Shell 命令会产生自己的输出，并在脚本运行的控制台监视器上显示。然而，很多时候，你会希望添加自己的文本消息，以帮助脚本用户了解脚本内部正在发生的事情。你可以使用 `echo` 命令来实现这一点。如果你将字符串放在命令之后，`echo` 命令可以显示简单的文本字符串：

```
$ echo This is a test
This is a test
$
```

请注意，默认情况下，你不需要使用引号来界定你要显示的字符串。但是，如果你在我的字符串中使用引号，这可能会变得棘手：

```
$ echo Let's see if this'll work
Let's see if this'll work
$
```

`echo` 命令使用双引号或单引号来界定文本字符串。如果你在字符串内使用它们，你需要在文本内使用一种引号，并使用另一种引号来界定字符串：

```
$ echo "This is a test to see if you're paying attention"
This is a test to see if you're paying attention
$ echo 'Rich says "scripting is easy".'
Rich says "scripting is easy".
$
```

现在所有引号都正确显示在输出中。

你可以在 Shell 脚本中任何需要显示额外信息的地方添加 `echo` 语句：

```
$ cat test1
#!/bin/bash
# This script displays the date and who's logged on
echo  The time and date are:
date
echo "Let's see who's logged into the system:"
who
$
```

这很好，但如果你想在命令输出的同一行上 `echo` 一个文本字符串怎么办？你可以使用 `echo` 语句的 `-n` 参数来实现。只需将第一个 `echo` 语句行更改为：

```
echo -n "The time and date are: "
```

你需要在字符串周围使用引号，以确保回显的字符串末尾有一个空格。命令输出将正好从字符串输出停止的地方开始。现在输出看起来将像这样：

完美！`echo` 命令是与用户交互的 Shell 脚本中的一个关键部分。你将在许多情况下使用它，特别是当你想要显示脚本变量的值时。让我们接下来看看那一点。

#### 环境变量

你已经见过一种 Linux 变量的作用。第 6 章描述了 Linux 系统中可用的环境变量。你也可以从你的 Shell 脚本中访问这些值。

Shell 维护着追踪特定系统信息的环境变量，例如系统名称、登录到系统的用户名称、用户的系统 ID（称为 `UID`）、用户的默认主目录，以及 Shell 用于查找程序的搜索路径。你可以使用 `set` 命令显示可用的活动环境变量完整列表：

```
$ set
BASH=/bin/bash
...
HOME=/home/Samantha
HOSTNAME=localhost.localdomain
HOSTTYPE=i386
IFS=$' \t\n'
IMSETTINGS_INTEGRATE_DESKTOP=yes
IMSETTINGS_MODULE=none
LANG=en_US.utf8
LESSOPEN="|/usr/bin/lesspipe.sh %s"
LINES=24
LOGNAME=Samantha
...
```

你可以通过在环境变量名称前加上美元符号来在脚本内部利用这些环境变量。以下脚本演示了这一点：

```
$ cat test2
#!/bin/bash
# display user information from the system.
echo "User info for userid: $USER"
echo UID: $UID
echo HOME: $HOME
$
```

`$USER`、`$UID` 和 `$HOME` 环境变量用于显示有关已登录用户的相关信息。输出应该看起来像这样：

```
$ chmod u+x test2
$ ./test2
User info for userid: Samantha
UID: 1001
HOME: /home/Samantha
$
```

请注意，在运行脚本时，`echo` 命令中的环境变量会被其当前值替换。还要注意，此代码将 `$USER` 系统变量放在第一个字符串的双引号内，并且 Shell 脚本仍然能够理解其含义。然而，使用此方法有一个缺点。看看这个例子中发生了什么：

```
$ echo "The cost of the item is $15"
The cost of the item is 5
```

这显然不是预期结果。每当脚本在引号内看到美元符号时，它都会假设你正在引用一个变量。在这个例子中，脚本试图显示变量 `$I`（未定义），然后是数字 5。要显示实际的美元符号，你必须在其前面加上反斜杠字符：

```
$ echo "The cost of the item is \$15"
The cost of the item is $15
```

这就好多了。反斜杠使 Shell 脚本将美元符号解释为实际的美元符号，而不是变量。下一节展示如何在你的脚本中创建自己的变量。

> **注意**
>
> 你还会看到使用 `${variable}` 格式引用变量。变量名称周围的额外花括号通常用于帮助将变量名称与美元符号区分开来。

#### 用户变量

除了环境变量之外，Shell 脚本允许你在脚本内部设置和使用自己的变量。设置变量允许你临时存储数据并在整个脚本中使用它，使 Shell 脚本更像真正的计算机程序。

用户变量可以是多达 20 个字母、数字或下划线字符的任何文本字符串。用户变量对大小写敏感，因此 `Var1` 变量与 `var1` 变量不同。这个小规则经常让新手脚本程序员陷入麻烦。

使用等号将值分配给用户变量。变量、等号和值之间不能出现空格（这是新手另一个容易出错的地方）。以下是一些将值分配给用户变量的示例：

```
var1=10
var2=-57
var3=testing
var4="still more testing"
```

Shell 脚本将所有变量值存储为文本字符串；由 Shell 中的单个命令确定用于变量值的数据类型。在 Shell 脚本中定义的变量在整个 Shell 脚本的生命周期内保持其值，但当 Shell 脚本完成时会被删除。

就像系统变量一样，可以使用美元符号引用用户变量：

```
$ cat test3
#!/bin/bash
# testing variables
days=10
guest="Katie"
echo "$guest checked in $days days ago"
days=5
guest="Jessica"
echo "$guest checked in $days days ago"
$
```
