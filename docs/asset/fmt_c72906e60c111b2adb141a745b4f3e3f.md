
## clearenv LibC.pas

```pascal
function clearenv: Integer;
```

### 描述
`clearenv` 清空环境变量键值对列表。此函数仅对当前进程以及使用 `fork` 或 `exec` 函数从应用程序创建的任何子进程有效。

### 返回值
如果环境变量已清除，函数返回 0；如果环境变量未清除，则返回 -1。

### 参见
`getenv`, `setenv`, `putenv`, `secure_getenv`

### 示例
列表 4.18 - 使用 clearenv 函数

```pascal
procedure Tform1.Button1Click(Sender: TObject);
begin
  // 清空环境变量
  if clearenv = 0 then
    showmessage('环境变量已清空。')
  else
    showmessage('无法清除环境变量。');
end;
```

## daemon LibC.pas

```pascal
function daemon(
  NoChDir: Integer;
  NoClose: Integer
): Integer;
```

### 描述
调用 `daemon` 设置进程表现像守护进程。它将使进程没有控制终端，并提供关闭标准输入、输出和错误的选项，以及更改目录的选项。

### 参数
- **NoChDir**: 当此值非零时，将进程的当前目录更改为根目录 `/`。对于守护进程，建议这样做，这样进程就不会在无意中访问设备并减慢处理速度。
- **NoClose**: 当此值非零时，进程将关闭标准输入、标准输出和标准错误。

### 返回值
如果函数执行失败，函数将返回 -1，可以通过调用 `errno` 函数获取错误原因。

### 参见
`fork`

### 示例
列表 4.19 - 使用 daemon 函数

```pascal
// 让进程在后台运行并将
// 目录更改 '/' 并关闭
// 标准输入、输出和错误
daemon(1, 1);
```

## execl LibC.pas

### 语法
```pascal
function execl(
  __path: PChar;
  __arg: PChar
): Integer; cdecl; varargs;
```

### 描述
`execl` 用传递给 `__path` 参数的应用程序替换当前进程。在 `__path` 参数之后，函数要求包含参数，并以一个 `nil` 参数结束。第一个参数应该是应用程序名称，以模拟从 Linux shell 将参数传递给应用程序的方式。

### 参数
- **__path**: 这是要替换当前进程的应用程序的完整路径。
- **__arg**: 这是传递给新应用程序的第一个参数。新应用程序的其他参数应作为 `varargs` 参数传递，并用 `nil` 指针表示没有更多参数。

### 返回值
此函数仅在执行失败时才会返回值，在这种情况下返回值为 -1。如果函数执行成功，新的原始进程将被新应用程序替换。

### 参见
`execlp`, `execle`, `execv`, `execve`

### 示例
参见列表 4.10 - 使用 exec 函数。

## execle LibC.pas

### 语法
```pascal
function execle(
  __path: PChar;
  __arg: PChar
): Integer;
```

### 描述
`execle` 用传递给 `__path` 参数的应用程序替换当前进程，并为新应用程序定义环境变量名称/值对。在 `__path` 参数之后，函数要求包含应用程序的参数，并以一个 `nil` 参数结束，然后是一个指向 `PChar` 数组的指针，该数组持有环境值。

第一个参数应该是应用程序名称，以模拟从 Linux shell 将参数传递给应用程序的方式。

### 参数
- **__path**: 这是要替换当前进程的应用程序的完整路径。
- **__arg**: 这是传递给新应用程序的第一个参数，其值应与传递给 `__path` 参数的值相同。新应用程序的其他参数应作为 `varargs` 参数传递，并用 `nil` 指针表示没有更多参数。
- **varargs**: 此应用程序的 `varargs` 参数应该是程序名之后的所有参数，随后后跟一个 `nil` 值以表示参数的结束。

### 返回值
此函数仅在执行失败时才会返回值，在这种情况下返回值为 -1。如果函数执行成功，原始进程将被新应用程序替换。

### 参见
`execl`, `execlp`, `execv`, `execvpe`

### 示例
列表 4.20 - 使用 Execle 函数

```pascal
program UsingTheExecleFunction;

{$APPTYPE CONSOLE}

uses
  Classes, SysUtils, Libc;

var
  pFileNameToRun: array[0..250] of char;

begin
  If ParamCount = 1 then
  begin
    writeln('About to call execle...');
    StrCopy(pFileNameToRun, ParamStr(1));
    execle(pFileNameToRun, pFileNameToRun, nil, envp);
  end
  else
  begin
    writeln('');
    writeln('One parameter was expected.');
    writeln(' Usage ' + ParamStr(0) + ' <filename>');
    writeln('');
  end;
end.
```

## execv LibC.pas

### 语法
```pascal
function execv(
  PathName: PChar;
  const argv: PPChar
): Integer;
```

### 描述
`execv` 函数用传递给 `PathName` 参数的应用程序替换当前进程。在 `PathName` 参数之后，函数要求包含应用程序的参数，并以一个 `nil` 参数结束。第一个参数应该是应用程序名称，以模拟从 Linux shell 将参数传递给应用程序的方式。

### 参数
- **PathName**: 这是要替换当前进程的应用程序的完整路径。
- **argv**: 这是传递给新应用程序的参数向量。

### 返回值
此函数仅在执行失败时才会返回值，在这种情况下返回值为 -1。如果函数执行成功，原始进程将被新应用程序替换。

### 参见
`execl`, `execlp`, `execle`, `execve`

### 示例
列表 4.22 - 使用 execv 函数

```pascal
program ExecUsingVectors;

{$APPTYPE CONSOLE}

uses
  Classes, SysUtils, Libc;

(*
此应用程序演示了需要向量参数的 exec 函数
*)

var
  pFileNameToRun: array[0..255] of char;
  NewArguments: TStringList;
  counter: integer;

function StringToPPChar(Value: TStrings): PPChar;
var
  i: integer;
  str: PChar;
  CompleteList: PPChar;
begin
  // 此函数将 TStrings 转换为 PPChar
  // 以便可以在 execv 函数中使用
  // 分配环境列表的大小
  // 我们需要增加一个允许空条目
  CompleteList := malloc(sizeof(PChar) * (Value.Count + 1));
  // 存储结果所在的位置
  Result := CompleteList;
  // 此函数根据内存中的名称/值对
  // 为新进程返回自定义环境。
  for i := 0 to Value.Count - 1 do
  begin
    str := malloc(Length(Value[i]) + 1);
    StrCopy(str, Value[i]);
    // 现在，将其添加到指针数组
    CompleteList^ := str;
    inc(CompleteList);
  end;
  // 将空条目添加到环境指针列表中
  // 以确认它在末尾。
  CompleteList^ := nil;
end;

begin
  if ParamCount = 1 then
  begin
    writeln('About to call execv...');
    StrCopy(pFileNameToRun, ParamStr(1));
    NewArguments := TStringList.Create;
    NewArguments.Add('PATH=/usr/bin:/bin');
    NewArguments.Add('LANG=en_US.UTF-8');
    if (execv(pFileNameToRun, StringToPPChar(NewArguments)) = -1) then
      writeln('execv failed');
  end
  else
  begin
    writeln('');
    writeln('One parameter was expected.');
  end;
end.
```

## execve LibC.pas

### 语法
```pascal
function execve(
  PathName: PChar;
  const argv: PPChar;
  const envp: PPChar
): Integer;
```

### 描述
`execve` 函数将当前进程替换为通过 `PathName` 参数传递的应用程序，并将参数传递给该应用程序，同时为新应用程序建立环境变量。在 `PathName` 参数之后，该函数要求将应用程序的参数包含在 `PChar` 数组中，这也被称为参数向量。应包含另一个名称/值对的向量，以表示该新应用程序的环境变量。

### 参数
- **PathName**: 这是要替换当前进程的应用程序的完整路径。
- **argv**: 这是要替换当前进程的应用程序的参数向量。列表中的第一个项应与 `PathName` 的值相同，以模拟 Linux shell 如何将参数传递给应用程序的。
- **envp**: 这是另一个表示环境变量的参数向量。该向量中的每个项都应该是格式为 "name=value" 的字符串。

### 返回值
此函数仅在执行失败时返回一个值，在这种情况下，返回值为 -1。如果函数执行成功，原始进程将被新应用程序替换。

### 参见
`execl`, `execlp`, `execle`, `execvp`, `execv`

### 示例
列表 4.23 - 使用 execve 函数

```pascal
program ExecVectorsAndEnvironment;

{$APPTYPE CONSOLE}

uses
  Classes,
  SysUtils,
  Libc;

(* 此应用程序演示了如何使用需要向量作为参数的 exec 函数，并发送了环境变量 *)

var
  pFileNameToRun: array[0..250] of char;
  NewArguments: TStringList;
  NewEnvironment: TStringList;
  counter: integer;

function StringListToPPChar(Value: TStrings): PPChar;
var
  i: integer;
  str: PChar;
  CompleteList: PPChar;
begin
  // 此函数将 TString 转换为 PPChar
  // 它可以用于 execve 等函数中
  // 分配环境列表的大小。
  // 我们需要加一以允许空项
  CompleteList := malloc(sizeof(PChar) * (Value.Count + 1));
  // 存储结果的原始位置
  Result := CompleteList;
  // 此函数根据内存中的名称/值对
  // 为新进程返回一个自定义环境。
  for i := 0 to Value.Count - 1 do
  begin
    str := malloc(Length(Value[i]) + 1);
    StrPCopy(str, Value[i]);
    // 现在，让我们将其添加到指针数组中
    CompleteList^ := str;
    inc(CompleteList);
  end;
  // 向环境指针列表添加 nil 项
  // 以确认它在末尾。
  CompleteList^ := nil;
end;

begin
  if ParamCount = 1 then
  begin
    writeln('About to call execve demonstrate using vectors.');
    NewArguments := TStringList.Create;
    NewArguments.Add(ParamStr(1));
    for counter := 1 to 8 do
      NewArguments.Add(IntToStr(counter));
    StrPCopy(pFileNameToRun, ParamStr(1));
    NewEnvironment := TStringList.Create;
    NewEnvironment.Add('book=Tomes of Kylix');
    NewEnvironment.Add('author=Glenn Stephens');
    // ... 后续代码省略
  end
  else
  begin
    writeln('');
    writeln('One parameter was expected.');
    writeln(' Usage ' + ParamStr(0) + ' <filename>');
    writeln('');
  end;
end.
```
