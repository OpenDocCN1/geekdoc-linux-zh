
```
deb http://deb.debian.org/debian stable main
deb-src http://deb.debian.org/debian stable main

deb http://security.debian.org/ stable/updates main
```

在本示例中，该文件包含了两个仓库：主 Debian 仓库和 Debian 仓库。`deb` 和 `deb-src` 行分别指定了仓库类型（别是二进制包或源包）和仓库地址，而 `stable` 和 `main` 参数分别指定了发行代号和仓库组件。

你可以使用 `nano` 文本编辑器通过使用方向键移动光标并修改文本来查看和编辑 `sources.list` 文件的内容。完成后，你可以按 `CTRL + O` 保存更改并按 `CTRL + X` 退出编辑器。

# 第 5 章：管理所有权和权限

## 命令概述

所有权和权限是指用户和进程访问修改文件文件目录的能力。Linux 系统使用一组权限位和所有权信息来控制对文件和目录的访问。

你可以使用几个不同的命令在 Kali Linux 系统上查看和修改所有权及权限。以下是一些常用命令的简要概述：

### ls

`ls` 命令用于列出目录内容。你可以使用 `-l` 选项显示有关每个文件和目录的详细信息，包括所有权权限。

### ls -l

这将向你显示当前目录下的文件和目录列表，以及每个项的所有权权限信息。

### chown

`chown` 命令用于更改文件或目录的所有者。你可以使用 `chown` 命令更改文件或目录的所有者或组所有者。

```
chown new-owner file
chown new-owner:new-group file
```

这将分别将文件的所有者或组所有者更改指定的 `new-owner` 或 `new-group`。

`chmod` 命令用于更改文件或目录的权限。你可以使用 `chmod` 命令更改文件或目录的读取权限、写入权限和执行权限。

```
chmod octal-permissions file
```

这将文件的权限更改指定的八进制权限。八进制权限使用三位数字指定，每个数字分别代表所有者、组和其他用户的读、写、执行权限。

例如，给所有者读写权限，给组用户读取权限，并不给其他用户任何权限，可以使用以下命令：

```
chmod 640 file
```

你也可以使用符号权限通过字符来指定权限。例如，给所有者读写权限，给组读取权限，并不给其他用户任何权限，可以使用以下命令：

```
chmod u+rw,g+r,o-rw
```

## 十进制表示

十进制法是一种使用十进制（基10）数值系统表示数字的方法。十进制法用于 Linux 中的许多不同场景，包括在指定权限、文件大小和其他数值时。

例如，当在 Linux 中指定权限时，你可以使用十进制法表示权限位。

## 使用十进制法

在 Linux 中，权限位通常用十进制法表示。以下是权限位表示方式的示例：

```
rw-r--r-- - 644
rwxr-xr-x - 755
rwxrwx - 777
```

在本示例中，`r` 权限由 4 表示，`w` 权限由 2 表示，`x` 权限由 1 表示。值得注意的是，虽然十进制法是表示权限的常用方法，你也可以使用八进制（基8）或符号表示。

## 文件大小

在 Linux 中，文件大小通常用十进制法表示，单位使用字节、千字节、兆字节等。例如，一个大小为 100KB 的文件可能被表示为 100,000 字节。

## 文件时间戳

在 Linux 中，时间戳（例如文件最后修改的日期时间）通常用十进制法表示为 Unix 时间戳，即自 Unix 纪元（1970 年 1 月 1 日 UTC 午夜）以来经过的秒数。

例如，一个在 2021 年 1 月 1 日 12:00 AM UTC 最后修改的文件的时间戳可能是 1609459200。

## 网络地址

在 Linux 中，网络地址（例如 IP 地址、MAC 地址）通常用十进制法表示。例如，IPv4 地址可能表示为四个由点分隔的十进制数字（例如 192.168.1.1）。同样，MAC 地址可能表示为六组由冒号分隔的十六进制对（例如 00:11:22:33:44:55）。

## UGO

在 Linux 中，UGO 指的是访问文件或目录的三种基本用户类型：所有者（U）、组（G）和其他用户（O）。这些术语用于指定设置文件或目录的权限，并决定谁能够读取、写入和执行文件或访问目录内容。

Linux 中的权限使用权限位指定，权限位是一系列分别代表所有者、组和其他用户的读、写、执行权限的数字。每种权限由一个特定的数字表示，文件或目录的权限位由这些数字之和表示。

使用 UGO 记法为文件或目录指定权限，你可以使用这些值的组合来分别表示所有者、用户组和其他用户的读、写和执行权限。

例如，要给所有者读、写、执行权限，给用户组读和执行权限，并且不给其他用户任何权限，你可以可以使用以下命令：

```
chmod u=rwx,g=rx,o= file
```

此命令将将文件的权限位设置为 741，这代表所有者具有读、写和执行权限 (7)，用户组具有读和执行权限 (4)，而其他用户没有权限 (1)。

值得注意的是，UGO 记法只是 Linux 中指定权限的方法一种。你还可以使用八进制表示法或符号表示法来指定权限。例如，可以使用以下八进制表示法指定上述相同的权限：

```
chmod 741 file
```

或使用如下符号表示法：

```
chmod u+rwx,g+rx,o-rwx file
```

## 掩码 (Masks)

掩码（Mask）是一个用于设置或修改文件或目录权限的值。掩码通常与 `umask` 命令配合使用，该命令用于为新创建的文件和目录设置默认权限。

`umask` 命令接受一个掩码值作为参数，该值被用于确定应用于新创建的文件和目录的默认权限。将掩码值从 `rwxrwxrwx` 的完整权限（八进制表示法为 777）中减去，即可确定默认权限。

## `umask` 命令

例如，如果掩码值为 022，则新创建的文件和目录的默认权限将是 755 (`rwxr-xr-x`)。如果掩码值为 027，则默认权限将是 750 (`rwxr-x---`)。

以下是你可能使用 `umask` 命令为新创建的文件和目录设置默认权限的示例：

```
umask 022
```

此命令将将掩码值设置为 022，并导致新创建的文件和目录具有 755 (`rwxr-xr-x`) 的默认权限。

值得注意的是，`umask` 命令只影响新创建的文件和目录的默认权限。它不会修改现有文件或目录的权限。要修改现有文件或目录的权限，你可以使用 `chmod` 命令。

值得注意的是，掩码值通常以八进制表示法指定，每个数字分别代表所有者、用户组和其他用户的读、写和执行权限。例如，掩码值 022 代表所有者具有读和写权限，用户组没有权限，而其他用户具有读权限。

这里是更多关于掩码值及其对应默认权限的示例：

| 掩码值 | 默认权限 |
|---|---|
| 022 | rwxr-xr-x |
| 027 | rwxr-x--- |
| 007 | rwx------ |
| 077 | rwx------ |

值得注意的是，Linux 系统上使用的特定掩码值和默认权限取决于特定的配置以及系统中用户和进程的需求。你可以通过查阅你特定 Linux 发行版的文档或咨询在线资源获取更多关于在 Linux 中指定掩码值和设置默认权限的信息。

## 显示当前掩码值

除了设置新创建的文件和目录的默认权限外，`umask` 命令还可以用于显示当前的掩码值。要显示当前的掩码值，你可以使用不带参数的 `umask` 命令：

```
umask
```

这将以八进制表示法显示当前的掩码值。

你也可以使用 `umask` 命令将掩码值设置为特定值。要做到这一点，你可以将所需的掩码值作为 `umask` 命令的参数。例如：

```
umask 022
```

此命令将将掩码值设置为 022，导致新创建的文件和目录具有 755 (`rwxr-xr-x`) 的默认权限。
