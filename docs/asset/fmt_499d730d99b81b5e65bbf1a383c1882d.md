
16就是`sizeof(SYSTEMTIME)`，即`malloc`分配空间的大小，并将空间的指针传递给`EAX`寄存器。`malloc()`函数根据参数的大小分配一个空块，在`ESI`寄存器中获取了这个指针。Win32的`GetSystemTime()`函数把返回的空值存储到`ESI`指针指向的空空间，接下来的两个寄存器依次读取这些值并将其再次推入内存；`printf()`函数即可。

此处的`MOVZX`（零扩展移动移动）是前文没有介绍过的指令。该指令的参数和`MOVS`（参见第14节）的区别是，`MOVZX`在处理格式化时会将它的高位清零。由于`printf()`函数需要的数据类型是`WORD32`整型，而我们的结构`SYSTEMTIME`里的字段是`WORD`数据类型，所以此处需要转换数据类型。`WORD`类型是无符号数据，因此要把`WORD`数据按照`int`型数据空间的低位，并将高位地址（第16位到第31位）清零。高位地址必须清零，否则转换后的`int`型数据可能会受到数值问题的不良影响。

在本例中，我们可以使用8`WORD`类型重构上述结构体：

```c
#include <windows.h>
#include <stdio.h>

void main()
{
    WORD *t;

    t=(WORD *)malloc(16);

    GetSystemTime(t);

    printf("%04d-%02d-%02d %02d:%02d:%02d\n",
t[0] /* wYear */, t[1] /* wMonth */, t[3] /* wDay */,
           t[4] /* wHour */, t[5] /* wMinute */, t[6] /* wSecond */);

    free (t);

    return;
}
```

### 21.3 UNIX: struct tm

我们研究一下Linux文件`tm`结构。

```c
#include <stdio.h>
#include <time.h>

void main()
{
    struct tm t;
    time_t unix_time = time(NULL);

    localtime_r(&unix_time, &t);

    printf("Year: %d\n", t.tm_year + 1900);
    printf("Month: %d\n", t.tm_mon);
    printf("Day: %d\n", t.tm_mday);
    printf("Hour: %d\n", t.tm_hour);
    printf("Minutes: %d\n", t.tm_min);
    printf("Seconds: %d\n", t.tm_sec);
}
```
