## crontab

UNIX 系统有一个是一直运行的守护进程，`cron` 按照固定的间隔定期运行。你可以在一个文件中指定 `crontab` 命令执行的任务，`cron` 守护进程会在 `cron` 守护进程初始化或当对文件进行添加或修改时检查该文件。

你在 `crontab` 文件中可以的条目由以下字段组成（用空格或制表符分隔）：

- minute（分钟）
- hour（小时）
- day（日期）
- year（年份）
- day of the week（星期）
- command（命令）

每个字段都可以有多个离散的值（用逗号分隔）、一个值范围，或者一个 `*`（星号），表示匹配所有值。

以下是可与 `crontab` 命令配合使用的标记列表：

- `-l`：列出你的 `crontab` 文件。
- `-e`：编辑或创建你的 `crontab` 文件。
- `-r`：删除你的 `crontab` 文件。
- `-v`：列出 crontab 任务的状态。

**示例** 如果你想在每天下午 12:30 显示 "Time to go for lunch" 字符串，请设置如下：

```
30 12 * * * echo "Time to go for lunch"
```

如果你想在每周周五下午 4:00 执行 `my_job`，请设置如下：

```
0 16 * * * 5 my_job
```

## pack

如果你想节省空间，可以使用 `pack` 命令以类似于 `compress` 命令的方式压缩文件。`pack` 命令会压缩文件并生成一个文件名在末尾附加 `.z` 的新文件。原始文件将被删除。节省空间的大小取决于文件的内容。通常情况下，文本文件可以获得约 30% 到 50% 的压缩率。默认情况下，如果 `pack` 命令无法减小文件大小，则不会进行压缩。

以下是可以与 `pack` 命令一起使用的标志列表：

- `-s` 显示压缩统计信息。
- `-f` 强制打包。

示例：如果你有一个想要压缩的文件，请使用以下命令：

```bash
pack file
pack: file1: 41.7% Compression
```

如果你想获取更多关于压缩的信息，请在以下命令中使用 `-`（连字符）标志：

```bash
pack - file
pack: file1: 41.7% Compression
from 28160 to 16404 bytes
Huffman tree has 15 levels below root
102 distinct bytes in input
dictionary overhead = 124 bytes
effective entropy = 4.66 bits/byte
asymptotic entropy = 4.62 bits/byte
```

在某些情况下，`pack` 可能无法压缩文件，并在以下命令中报错：

```bash
pack file1
pack: file1: no saving
- file unchanged
```

在这种情况下，要强制压缩，请像以下命令所示使用 `-f` 标志：

```bash
pack -f file1
pack: file1: 40.8% Compression
```

使用 `date` 命令来显示日期

要显示日期，你必须指定一个 `+`（加号）符号。格式可以如下：

- `%A` 显示星期名称。

- `%B` 显示月份名称。
