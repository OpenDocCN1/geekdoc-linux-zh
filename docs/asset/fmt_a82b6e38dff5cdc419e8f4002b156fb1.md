### http.client (httpplib)

`http.client` 模块为 HTTP 客户端提供了低层 socket 支持。在 Python 2 中，该模块被称为 `httpplib`。请改用 `urllib` 包中的函数。该模块支持 HTTP/1.0 和 HTTP/1.1，并且如果 Python 构建时支持 OpenSSL，还额外允许通过 SSL 连接。通常不要直接使用此包；而应该考虑使用 `urllib` 包。然而，由于 HTTP 是一个非常重要的协议，你可能会遇到 `urllib` 无法轻松处理的底层细节——例如，如果你想发送 `GET` 或 `POST` 命令以外的请求。有关 HTTP 的更多细节，请参考 RFC 2616 (HTTP/1.1) 和 RFC 1945 (HTTP/1.0)。

可以使用以下类与服务器建立 HTTP 连接：

```
HTTPConnection(host [, port])
```

创建一个 `HTTPConnection` 对象，`host` 是主机名，`port` 是远程端口号。默认端口为 80。返回一个 `HTTPConnection` 实例。

```
HTTPSConnection(host, [ port , key_file=key_file, cert_file=cert_file])
```

创建一个 HTTP 连接但使用安全 socket。默认端口为 80。`key_file` 和 `cert_file` 是可选的关键字参数，用于指定客户端 PEM 格式的私钥和证书链文件，它们将用于客户端认证。然而，不会对服务器证书进行验证。返回一个 `HTTPSConnection` 实例。

### http 包

`HTTPConnection` 或 `HTTPSConnection` 的实例 `h` 支持以下方法：

```
h.connect()
```

初始化到 `HTTPConnection()` 或 `HTTPSConnection()` 传递的主机和端口的连接。如果尚未建立连接，其他方法会自动调用此方法。

```
h.close()
```

关闭连接。

```
h.send(bytes)
```

向服务器发送字节流 `bytes`。不建议直接使用此函数，因为可能会破坏底层的响应/请求协议。它最常用的用法是在 `h.endheaders()` 被调用后向服务器发送数据。

```
h.putrequest(method, selector, [skip_host, skip_accept_encoding])
```

向服务器发送一个请求。`method` 是 HTTP 方法，即 'GET' 或 'POST'；`selector` 指定要返回的对象，如 `/index.html`。`skip_host` 和 `skip_accept_encoding` 参数是标志，允许禁用 HTTP 请求中的 `Host:` 和 `Accept-Encoding` 头部。默认情况下，这两个参数均为 `False`。由于 HTTP/1.1 允许在单个连接上发送多个请求，如果连接处于禁止发布新请求的状态，可能会抛出 `CannotSendRequest` 异常。

```
h.putheader(header, value, ...)
```

向服务器发送 RFC-822 风格的头部。如果提供了参数，它会向服务器发送一行由头部、冒号和空格组成。额外的参数被编码为头部中的延续行。如果 `h` 不处于允许发送头部的状态，则抛出 `CannotSendHeader` 异常。

```
h.endheaders()
```

向服务器发送一个空行，表示头部的结束。

```
h.request(method, url, {body, headers})
```

向服务器发送一个完整的 HTTP 请求。`method` 和 `url` 的含义与 `h.putrequest()` 相同。`body` 是一个可选字符串，包含请求发送后要上传到服务器的内容。如果提供了 `body`，`Content-length:` 头部将自动设置为适当的值。`headers` 是一个 `header:value` 对的字典，将传递给 `h.putheader()`。

```
h.getresponse()
```

从服务器获取响应并返回一个可以读取数据的 `HTTPResponse` 实例。如果 `h` 不处于可以接收响应的状态，则抛出 `ResponseNotReady` 异常。

由 `getresponse()` 方法返回的 `HTTPResponse` 实例 `r` 支持以下方法：

```
r.read([size])
```

从服务器读取最多 `size` 字节。如果省略 `size`，则返回该请求的所有数据。

```
r.getheader(name [,default])
```

获取响应头部。`name` 是头部的名称。`default` 是未找到该头部时返回的默认值。

```
r.getheaders()
```

返回一个 `(header, value)` 元组的列表。

`HttpResponse` 实例还具有以下属性：

```
r.version
```

服务器使用的 HTTP 版本。

```
r.status
```

服务器返回的 HTTP 代码。

```
r.reason
```

服务器返回的 HTTP 错误信息。

```
r.length
```

响应中的字节数。

### 异常

在处理连接过程中可能会引发以下异常：

| 异常 | 说明 |
|---|---|
| `HTTPException` | 所有 HTTP 相关错误的基类。 |
| `NotConnected` | 请求已发出但未连接。 |
| `InvalidURL` | 给予的 URL 或端口错误。 |
| `UnknownProtocol` | 未知的协议。 |
| `UnknownTransferEncoding` | 未知的传输编码。 |
| `UnimplementedFile` | 未实现的文件模式。 |
| `IncompleteRead` | 接收到的数据不完整。 |
| `BadStatusLine` | 未知的状态码。 |
| `ImproperConnectionState` | 所有连接状态的基类。 |
| `CannotSendRequest` | 无法发送请求。 |
| `CannotSendHeader` | 无法发送头部。 |
