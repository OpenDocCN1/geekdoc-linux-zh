## 隐藏文件 (hidden file)

在 UNIX 和 Linux 系统中，文件名包含句点（.）的文件。它们被称为“隐藏文件”，是因为它们在目录列表或文件管理器中默认不显示。例如，用户配置文件通常是隐藏的，以防止意外删除或修改。RedHat–9术语表 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## 隐藏标志 (hidden flag)

n. [科学计算] 在不调用序列的情况下向例程添加的额外选项。例如，程序员可能没有添加输入变量来运行例程以提供额外的诊断输出，而是直接为现有功能的某些无意义特征（如负质量）添加一个测试。使用隐藏标志会导致程序非常难以调试和理解，但在程序仓忙修改或进行修补时，这种情况非常普遍。来自术语词典 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## 高位 (high bit)

n. [源自‘高阶位'] 1. 字节中的最高位。2. [常用] 引申为，除数据字节以外的事物的最重要的部分：“省去整个故事，只要给我高位即可.. 另见 meta, hobbit, dread high–disease，并对比主流俚语‘bottom line’”。来自术语词典 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## 高地拉 (High Sierra)

一种过时的数据 CD-ROM 编码标准。虽然与 High Sierra 类似，但广泛使用的 ISO 9660 标准与之不兼容。来自 QUEDIC http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## 高级语言 (high-level language)

可以在许多不同系统中使用的计算机语言。相比之下，低级语言指的是特定的硬件位置，与特定的硬件架构不可分。低级语言的另一个名称是汇编语言。来自 Linux Guide @FirstLinux http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## 格式进格式化

重新格式化 HTML 代码。此工具重新格式化 HTML 代码，使其具有正确的缩进/嵌套以提高可读性。你可以原样缩进现有行，也可以重新格式化代码使每个标签占一行。Hindent 在解析软件生成的、仅有一行巨行的 HTML 代码时非常有用，或者用于寻找最后一个结束标签，或通过渐进式未来主义处理代码。用 Perl 编写，适用于 Unix。支持所有 HTML 3.2 嵌套标签。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
