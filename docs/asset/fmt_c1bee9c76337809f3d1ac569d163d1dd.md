# 引导性练习题答案

1. 假设一个程序需要创建一个一次性的临时文件，该文件在程序关闭后将不再被需要。创建该文件的正确目录是什么？

由于我们不在乎程序运行结束后的该文件，因此正确的目录是 `/tmp`。

2. 在启动过程中必须清理的临时目录是哪一个？

该目录是 `/run`，或者在某些系统上是 `/var/run`。

3. `chmod` 符号模式下用于对目录启用粘滞位（sticky bit）的参数是什么？

符号模式下代表粘滞位的符号是 `t`。由于我们要为目录启用（添加）此项权限，因此参数应该是 `+t`。

4. 假设在 `/home/carol/Documents` 目录下有一个名为 `document.txt` 的文件。在当前目录下创建一个名为 `text.txt` 指向它的符号链接的命令是什么？

`ln -s` 是创建符号链接的命令。由于你应该指定要链接的文件的完整路径，因此命令为：

```bash
$ ln -s /home/carol/Documents/document.txt text.txt
```

5. 解释文件硬链接与文件副本之间的区别。

硬链接仅仅是文件的另一个名称。尽管它看起来像是原始文件的副本，但对于所有用途而言，链接和原始文件都是相同的，它们指向磁盘上的相同数据。对链接内容所做的更改将反映在原始文件中，反之亦然。副本是一个完全独立的实体，占据磁盘上的不同位置。对副本的更改将不会反映在原始文件中，反之亦然。

# 探索性练习题答案

1. 假设你在一个目录下创建一个名为 `recipes.txt` 的文件。在该目录下，你还会为该文件创建一个硬链接，名为 `receitas.txt`，并创建一个符号链接（或软链接），名为 `rezepte.txt`。

```bash
$ touch recipes.txt

$ ln recipes.txt receitas.txt

$ ln -s recipes.txt rezepte.txt
```

目录的内容应该如下所示：

```bash
$ ls -lhi

total 160K

538833 -rw-r--r-- 4 carol 77K 17 17:25 receitas.txt

538833 -rw-r--r-- 4 carol 77K 17 17:25 recipes.txt

538837 lrwxr-xr-x 1 carol 12 jun 24 10:12 rezepte.txt -> recipes.txt
```

记住，作为硬链接，`receitas.txt` 指向与 `recipes.txt` 相同的 inode。如果删除了 `receitas.txt` 名称，软链接 `rezepte.txt` 会发生什么？为什么？

软链接 `rezepte.txt` 将停止工作。这是因为软链接指向的是名称和 inode，而 `receitas.txt` 名称已不再存在，即使数据仍然以 `recipes.txt` 的名称存在于磁盘上。

2. 假设你有一个 U 盘插入了系统，并挂载在 `/media/user/FlashA`。你想在你的家目录下创建一个名为 `schematics.pdf` 的链接，指向 U 盘根目录下的 `schema.pdf`。于是你输入命令：

```bash
$ ln /media/user/FlashA/schema.pdf
```

会发生什么？为什么？

命令将失败。错误信息将是“Invalid cross-device link”（跨设备链接无效），原因是硬链接无法指向不同的分区或设备。创建此类链接的方法是使用符号链接，添加 `-s` 参数。
