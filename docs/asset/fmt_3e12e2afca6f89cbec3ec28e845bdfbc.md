
# Linux 字典

### `vsftpd`
安全 FTP 守护进程（Very Secure FTP Daemon）。一个从底层开始就考虑安全性的轻量级 FTP 服务器。`vsftpd` 支持匿名和非匿名 FTP、`PAM` 认证、带宽限制和 Linuxfile 功能。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### `vsound`
虚拟环回音频录制器和真实音频转换器。此程序允许你录制任何标准 OSS 程序（使用 `/dev/dsp` 进行声音）的输出，而无需修改或重新编译程序。它使用 `sock` 将原始数据转换并保存为所需的格式，并有助于将真实音频文件转换为其他非专有格式。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### `vtk-tk`

### `vtkdata-installer`
VTK 示例数据的安装程序。Visualization Toolkit 带有 C++ 和 Python 代码。这些示例引用使用此包中 `get-vtkdata` 脚本安装的数据文件。`get-vtkdata` 脚本通过互联网传输约 30 MB，并在 `/usr/share/vtkdemo/vtkdata` 中获取约 115 MB。请相应规划你的网络和磁盘使用。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
