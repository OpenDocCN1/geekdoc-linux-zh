
### AddIconByType

`AddIconByType`指令也允许你为一个或多个MIME类型分配图标。

- **语法：** `AddIconByType icon_file MIME_type [MIME_type...]`
- **上下文：** 服务器配置、虚拟主机、目录、每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

例如，以下`AddIconByType`指令告诉Apache为所有`text/html`文件显示`/icons/html.gif`图标。

```
AddIconByType (HTML,/icons/html.gif) text/html
```

### DefaultIcon

当没有为文件匹配任何`AddIcon`、`AddIconByEncoding`或`AddIconByType`时，可以显示默认图标。`DefaultIcon`指令允许你设置该图标。

- **语法：** `DefaultIcon URL`
- **上下文：** 服务器配置、虚拟主机、目录、每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

例如，以下指令每当文件的图标关联未知时显示`idontknow.gif`：

```
DefaultIcon /icon/idontknow.gif
```

### FancyIndexing

`FancyIndexing`指令允许你启用或禁用目录的详细索引。你可以通过`IndexOptions`指令实现相同的效果。

- **语法：** `FancyIndexing On | Off`
- **上下文：** 服务器配置、虚拟主机、目录、每目录配置（`.htaccess`）
- **覆盖：** `Indexes`

### HeaderName

如果你使用`FancyIndexing`，可以在索引列表的顶部插入文件内容。`HeaderName`指令允许你指定用于此类插入的文件名。

- **语法：** `HeaderName filename`
- **上下文：** 服务器配置、虚拟主机、目录、每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

例如，以下指令告诉Apache在列表目录中查找名为`welcome`或`welcome.html`的文件；如果找到此类文件，内容将插入在实际列表之前：

```
HeaderName welcome
```

### IndexIgnore

如果你需要某些文件或文件扩展名在目录列表中不可见，可以使用`IndexIgnore`指令来实现这一点。

- **语法：** `IndexIgnore file [file...]`
- **上下文：** 服务器配置、虚拟主机、目录、每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

例如，以下指令确保Apache不在目录列表中列出`welcome`、`welcome.html`或每目录配置文件（`.htaccess`）：

```
IndexIgnore welcome welcome.html .htaccess
```

点号（`.`）字符自动包含在`IndexIgnore`列表中；因此，以该字符开头的文件不会被列出。然而，你可能仍倾向于将每目录配置文件（`.htaccess`）添加到列表中，只是为了让你感到更安全。

### IndexOptions

`IndexOptions`指令指定自动生成的目录索引的行为。

- **语法：** `IndexOptions option [option] [...]`
- **上下文：** 服务器配置、虚拟主机、目录、每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

#### IndexOptions

表5-7展示了您可以与`IndexOptions`配合使用的选项。

| 选项 | 作用 |
|---|---|
| `FancyIndexing` | 开启目录的花式索引。注意，`FancyIndexing`和`IndexOptions`指令会**相互覆盖**。 |
| `IconHeight[=pixels]` | 允许Apache在图标的`IMG`标签中包含`HEIGHT=pixels`属性，这使得大多数浏览器加载图标时速度更快。如果您未指定像素值，则使用标准默认值。 |
| `IconsAreLinks` | 使图标成为文件名锚点的一部分，用于花式索引。 |
| `IconWidth[=pixels]` | 允许Apache在图标的`IMG`标签中包含`WIDTH=pixels`属性，这使得大多数浏览器加载图标时速度更快。如果您未指定像素值，则使用标准默认值。 |
| `ScanHTMLTitles` | 如果您希望Apache读取HTML文档的标题（由`<TITLE>`和`</TITLE>`标签对标识）以进行花式索引，请使用此选项。但是，如果您已使用`AddDescription`指令指定了描述，则不会使用此选项。请注意，读取每个文件的内容并搜索标题信息是一个耗时任务，可能会减慢目录列表的生成速度。我不推荐此选项。 |
| `SuppressColumnSorting` | 默认情况下，Apache会为花式目录索引创建可点击的列标题，这允许用户对该列中的信息进行排序。此选项将禁用该功能。 |
| `SuppressDescription` | 如果您不想在花式目录列表中显示文件描述，请使用此选项。 |
| `SuppressHTMLOreamble` | 如果目录确实包含由`HeaderName`指令指定的文件，该模块通常会在标准HTML前导内容（`<HTML>`、`<HEAD>`等）之后包含该文件的内容。`SuppressHTMLOreamble`选项会禁用此行为。 |
| `SuppressLastModified` | 抑制在花式索引列表中显示最后修改日期。 |
| `SuppressSize` | 抑制在花式索引列表中显示文件大小。 |

### IndexOrderDefault

`IndexOrderDefault`指令允许您通过排序名称、日期、大小和描述等各个字段来更改目录列表视图，这些目录是使用`FancyIndexing`功能显示的。

- **语法：** `IndexOrderDefault Ascending | Descending Name | Date | Size | Description`
- **上下文：** 服务器配置，虚拟主机，目录，每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

### ReadmeName

如果您希望在花式目录列表的末尾插入一个文件，请使用`ReadmeName`指令。

- **语法：** `ReadmeName filename`
- **上下文：** 服务器配置，虚拟主机，目录，每目录访问控制文件（`.htaccess`）
- **覆盖：** `Indexes`

例如，以下设置使Apache查找名为`readme.html`（默认扩展名）或`readme`的文件并将其插入到列表末尾：

```
ReadmeName readme
```

## Response Header Modules

Apache允许您在发送数据时发送自定义HTTP响应头。本节中的模块如表5-8所示，允许您配置各种自定义响应头。

表5-8 响应头模块

| 模块 | 用途 |
| --- | --- |
| `mod_alias` | 发送包含自身HTTP头的文件。 |
| `mod_headers` | 为资源添加任意HTTP头。 |
| `mod_expires` | 为资源应用`Expires`头。 |
| `mod_cern_meta` | 支持HTTP头元文件。 |

### mod_asis

`mod_asis`模块默认已编译。此模块允许您原样发送文档——也就是说，文档在不带HTTP头的情况下发送给客户端。这在不需要脚本帮助的情况下重定向客户端时非常有用。要原样发送文件，您需要确保`httpd.conf`文件包含如下条目：

```
AddType httpd/send-as-is .asis
```

这将`httpd/send-as-is`MIME类型分配给文件扩展名`.asis`。如果您创建一个名为`foobar.asis`的文件并且客户端请求它，该文件将在没有HTTP头的情况下发送给客户端。您需要在文件中包含适当的头。例如，如果您想通过`.asis`文件提供重定向机制，您可以创建具有如下头的文件：

```
Status: 301 Text Message
Location: new-URL
Content-type: text/html
```

清单5-2展示了一个名为`redirect.asis`的文件，它将客户端重定向到新位置。

清单5-2: `redirect.asis`

```
Status: 301 We have moved.
Location: http://www.our-new-site/
Content-type: text/html
```
