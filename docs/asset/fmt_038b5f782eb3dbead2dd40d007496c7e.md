
判断语句会分出箭头，一条是红色的，一条是绿色的。当条件值为真，程序采用绿色箭头流程；如果条件不成立，程序采用红色箭头流程。图解模式下，也可以对节点命名。

7.12 使用`Hiew`观察`main()`函数

`Hiew`能够识别并显示`ASCIIZ`，以`null`为结束字节的`ASCII`字符。它还能识别导入函数的名称。

如图7.13所示，将光标标记移动至`00040127`处（即`JNZ`命令所在的位置），我们使其失效，按`F3`，然后输入“`9090`”。“`9090`”是两个连续的`NOP`（No Operation，空操作）`opcode`。

![](img/a13a81a53f805f55074b2e5d2ec754b6_146_0.png)

图7.13 在`Hiew`中将`JNZ`替换为两条`NOP`指令

然后按`F9`（更新），将修改后的可执行文件保存到磁盘。

连续的`9090`是典型的修改特征，有人会觉得很美。此外还可以把这个`opcode`的第二个字节为零（`opcode`的两个字节代表`jump offset`），令`jcc`指令跳转的偏移为`0`，从而继续运行下一条指令。

这种修改方法可以迁移指令流。除此之外我们还可以强制程序进行跳转。我们可以把`jcc`对应的`opcode`的第一个字母替换为“`EB`”，不去修改第二节(`offset`)。这种方法把条件指令替换为了无条件跳转指令。经过这样的调整之后，本例中的可执行文件无条件显示错误信息“`What you entered? Huh?`”

## 7.3.5 MSVC:x64

本例使用的变量是`int`变量。在`64`位平台上，`int`变量还是`32`位。在`64`位系统中，访问寄存器的（低`32`位）时，在汇编语言中我们需要使用寄存器名称。

```assembly
DATA SEGMENT

$SG24 DB  'Enter X: ', 0AH
$SG26 DB  '%d', 0AH
$SG27 DB  'You entered %d ', 0AH
$SG29 DB  'What you entered? Huh?', 0AH

ENDS

TEXT SEGMENT

$ = 32

main  PROC
$LN5:
    sub     rsp, 56
    lea     rcx, OFFSET:$SG24 ; 'Enter X: '
    call    printf
    mov     eax, DWORD PTR [rsp]
    lea     rcx, OFFSET:$SG26 ; '%d'
```
