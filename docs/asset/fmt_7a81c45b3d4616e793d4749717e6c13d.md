# 第 19 章：添加、删除和更新软件

## 列出软件包信息

一旦你找到了感兴趣的软件包，就有等数量的方法可以获取有关该软件包及其内容的更详细信息。然而，由于 `apt-cache` 和 `aptitude` 工具会返回搜索结果，因此使用它们来显示已识别的任何软件包是有意义的。例如，要查找上一节列出的 `emacs21` 软件包的详细信息，你可以使用 `apt-cache show emacs21` 或 `aptitude emacs21` 命令，它们返回的信息几乎完全相同。下面的示例显示了 `aptitude show emacs21` 命令的输出，它稍微详细一些：

## 提示

你可以使用 `apt-file` 工具列出未安装软件包所提供的文件，使用的命令形如 `apt-file list package` 的命令，其中 `package` 是你感兴趣的软件包名称。`apt-file` 工具将在本章稍后的“确定哪个软件包提供了缺失的文件”中进行更详细的描述。■

## 确定现有文件提供的软件包

在 Ubuntu 上工作了一段时间并安装、更新和删除了一些软件包后，你可能对系统中某个文件是由哪个软件包提供的感到好奇。使用 `dpkg` 命令的 `--search` 选项很容易确定，如下例所示，我很好奇是哪个软件包提供了 `/usr/bin/ar` 工具：

```
$ dpkg --search /usr/bin/ar
binutils: /usr/bin/ar
```
