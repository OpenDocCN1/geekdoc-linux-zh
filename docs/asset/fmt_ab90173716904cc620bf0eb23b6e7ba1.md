
# 生物化学工程

生物化学工程通过与生物医学工程相比，侧重于生物化学和生物电子学，并应用于医疗保健而区别于生物医学工程。然而，现在生物化学工程师越来越多地参与医疗保健产品的直接开发。生物化学工程一直是生物技术产业发展的核心，特别是由于需要以足够用于测试、监管评估和后续商业生产的规模产生前瞻性产品（通常使用遗传工程微生物）。参见`生物制药工程`。

在该学科发展的初期，生物化学工程师主要关注在最高达数千升的规模下优化需氧条件下微生物的生长。尽管学科范围已经扩展，但这种关注点仍然存在。目标往往是开发一个经济的过程，以最大化生物量生产（从而产生特定的化学物质、生化物质或蛋白质），同时考虑原料和其他运营成本。生物量的基本成分（碳、氮、氧、氢，以及较少量的磷、硫、矿物盐和少量某些金属）被添加到生物反应器（通常称为发酵罐）中，并随着细菌产生和进行代谢过程而被消耗。向发酵罐中加入足量的氧气（通常以无菌空气供应），以这种方式促进其对生长培养物的可用性。参见`生物量`；`化学反应器`；`发酵`。

在某些情况下，可能会培养那些活性受溶解氧存在不利影响的微生物。厌氧培养是产生有机酸和溶剂的发酵的典型特征；这些系统通常以较慢的生长速率和较低的生物量收率为特征。厌氧微生物的最大应用在于废水处理，其中厌氧消化器包含厌氧微生物的混合群落。厌氧消化的主要应用之一是通过污泥处理中的有机废物产生甲烷。[E.Pr.]

**结构与功能研究。** 酶的结构与其催化活性之间的关系正变得越来越清楚。现在，可以通过X射线晶体学来可视化某些酶中的原子和原子团。现在，一些酶催化的过程可以就酶表面基团的空间排列以及这些基团如何影响反应分子以促进反应来描述。还可以解释酶分子形状的变化如何增加或降低酶的催化活性。一个重要的进展是开发了一种将氨基酸连接成预定序列的自动化程序。这项技术将允许合成略有改变的酶，并改善对酶结构与功能关系的理解。此外，该程序允许合成医学上重要的多肽（短的氨基酸链），如某些激素和抗生素。

**分子遗传学。** 在分子层面解释遗传学是一个深入研究的主题。现在已明确建立，遗传信息编码在DNA的核苷酸序列中，并且除了某些利用RNA的病毒外，DNA是遗传信息的最终储存库。蛋白质的核苷酸序列在DNA中编程；该信息首先通过复制DNA的核苷酸序列到信使RNA中来转录，然后该序列被翻译成蛋白质的特定氨基酸序列。参见`遗传密码`；`分子生物学`。

许多由遗传引起的疾病的生物化学基础，其原因已追溯到缺陷蛋白的产生，已被确定。镰状细胞贫血就是一个突出的例子；已充分确立，血红蛋白中单个氨基酸的改变导致了血红蛋白分子性质的严重异常。参见`疾病`。

**调节。** 对生物过程中化学事件的理解加深，使得对这些事件的调节成为可能。一个重要概念是化学反馈回路：一系列反应的产物本身可以影响反应速率。例如，当细胞内ATP供应较低时，导致ATP产生的反应剧烈进行，但当ATP充足时，它们明显减慢。这些观察可以在一定程度上由以下事实解释：ATP分子结合到涉及的某些酶上，改变酶的表面特征，足以降低其作为催化剂的有效性。还可以通过改变酶的_amount_来调节这些反应；酶的量可以通过调节其特异性信使RNA的合成，或通过调节RNA分子的信息翻译为酶分子来控制。另一个调节水平涉及多细胞生物中细胞和组织间的相互作用。例如，内分泌腺可以感知某些组织活动，并适当分泌控制这些活动的激素。涉及细胞和组织“通信”中的化学事件和物质已成为许多研究的主题。

**光合作用与固氮。** 两个具有重大意义的主题是光合作用和固氮过程。在光合作用中，二氧化碳气体转化为碳水化合物的化学反应是理解的，但光能量被捕获并转化为合成碳水化合物所需的化学能的过程尚不清楚。固氮过程涉及将氮气转化为可用于合成多种生物重要物质的化学形式；该过程的化学事件尚未完全理解。参见`氮循环`；`光合作用`。 [A.S.L.]

# 生物降解

有机化合物被微生物破坏的过程。微生物，特别是细菌，负责自然界中天然和合成有机化合物的分解。矿化导致化合物完全转化为其无机矿物成分（例如碳来自二氧化碳，有机硫来自硫酸盐或硫化物，有机氮来自硝酸盐或铵，有机磷酸酯来自磷酸盐，有机氯来自氯化物）。由于碳构成了有机化合物最大的质量，矿化可以从CO₂释放的角度来考虑。放射性碳-14（¹⁴C）同位素使科学家能够区分来自污染物的矿化和土壤固有物质的矿化。然而，任何化合物的矿化都不是100%，因为其中一部分（降解总量的10-40%）被结合到细胞质量或成为无定形土壤有机物质的一部分，通常被称为腐殖质。因此，生物降解包括矿化和转化为无机产物，即生物量和腐殖质。初级生物降解的范围更有限，指的是化合物由于其生物转化到其他产物而消失。参见`腐殖质`。

易于生物降解的化合物通常被单个微生物用作生长基质。许多石油产品（以及废物、水和废水）的化合物，如苯、甲苯、乙苯和二甲苯，被许多属的细菌用作生长和能量的唯一碳源。

化合物未被用作生长或能量，但被微生物转化为其他产物的过程被称为共代谢。氯化芳香烃，如滴滴涕（DDT）和多氯联苯（PCBs），是最持久的环境污染物之一；然而，它们被几个属的细菌共代谢，特别是*假单胞菌属*（*Pseudomonas*）、*产碱杆菌属*（*Alcaligenes*）、*红球菌属*（*Rhodococcus*）、*不动杆菌属*（*Acinetobacter*）、*关节杆菌属*（*Arthrolobacter*）和*棒杆菌属*（*Corynebacterium*）。共代谢是由具有非常广泛的底物特异性酶引起的。参见`细菌生长`；`多氯联苯`。

利用微生物修复受污染环境的过程被称为生物修复。该过程在如表面土壤或地下水等封闭系统中最为成功，其中添加营养物质（主要是无机氮和磷）以促进微生物生长，从而增加生物降解速率。由于营养物质水平（即微生物密度）太低，无法实现实质性的生物降解，且系统的规模和分布阻止了营养物质的添加，该过程在大型开放系统如海湾或湖泊中的应用很少或没有。

由于在污染区分布营养物质的难度更大，以及氧气（O₂）的限制，从地下水中修复石油产品比从表面土壤中更难实现。[D.D.F.]
