
# 与该虚拟主机相关的错误信息将在此处记录。如果你为 `<VirtualHost>` 容器定义了错误日志，那么主机的错误将记录在并在而不是在这里。

```
ErrorLog /var/log/httpd/error_log
```

# LogLevel: 控制记录到 `error_log` 中的消息数量。

可能的值包括：`debug`, `info`, `notice`, `warn`, `error`, `crit`, `alert`, `emerg`。

```
LogLevel warn
```

# 下列指令定义了一些用于 `CustomLog` 的格式别名（见下文）。

```
LogFormat "%h %l %u %t\ %s %b \%{Referer}i\ \%{User-Agent}i" combined
LogFormat "%h %l %u %r\ %s %b" common
LogFormat "%{Referer}" -> "%U"
LogFormat "%{User-agent}" agent
```

# 访问日志文件的位置和格式（通用日志文件格式）。

如果你没有在 `<VirtualHost>` 容器内定义任何访问日志，它们将记录在此处。反之，如果你定义了每个 `<VirtualHost>` 的访问日志，事务将记录在其中而*不在*此文件中。

```
# CustomLog /var/log/httpd/access_log common
CustomLog /var/log/httpd/access_log combined
```

# 如果你想拥有 agent 和 referer 日志文件，请取消注释以下指令。

```
#CustomLog /var/log/httpd/referer_log referer
#CustomLog /var/log/httpd/agent_log agent
```

# 如果你倾向于使用包含访问、agent 和 referer 信息的单日志文件（合并日志文件格式），可以使用以下指令。

```
#CustomLog /var/log/httpd/access_log combined
```
