
# openjade DSSL 语言的实现
OpenJade 是 ISO/IEC 1019:1996 标准 DSSL 语言的实现。它基于 Clark 的 Jade 软件。它是 OpenJade 的最新发布。最新且前沿的 ‘openjade’ 包。OpenJade 处理器结合 DSSL 表，能够将 SGML 翻译成其他格式。目前支持的输出格式有 RTF、HTML、MIF、JadeTex 和流对象树的 XML 表示。使用其非标准系统，还能将一种 SGML 或 XMLTD 转换为另一种：OpenJade 团队 `<jade-devel@infomansol.com>`：主页：`http://openjade.sourceforge.net/` 源自 Debian 3.0r APT

## H.323 会议服务器
OpenH32 控制台交互式会议服务器，允许两个或多个使用 H.323 的人员在聊天室中相互通话。该服务器混合来自所有参与者的声音并分割图像，以便多达 4 个人看到画面。有关 OpenH323 项目的更多信息，请访问：`http://www.openh323.org/`。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## openmix
管理 openunix 集集的实用工具。Openmix 是 Linux 内核的扩展，支持可扩展和透明的集群计算。增强后的内核允许基于 Intel x86 架构的工作站和服务器协作工作，就像单个系统的一部分。此包提供了运行 openmix 集集的实用工具。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## openoffice
OpenOffice.org 是一个开源、社区开发的、多平台办公套件。它包含了关键应用程序，如文字处理器、电子表格、演示文稿、公式编辑器和绘图程序，其用户界面和功能set与其他办公软件类似。OpenOffice.org 功能先进且灵活，还支持多种文件格式，包括 Microsoft Office。只需输入 "`office`" 即可运行 OpenOffice.org，或从桌面菜单中选择所需的组件（Writer, Calc, Draw, Impress 等）。如有必要，办公封装脚本将在用户的家目录下安装几个文件。来自 Redhat 8.0 RPM `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## OpenOffice.org
OpenOffice.org 是一个开源、社区开发的、多平台办公套件。它包含了关键应用程序，如文字处理器、电子表格、演示文稿、公式编辑和绘图程序，其用户界面和功能集与其他办公软件类似。OpenOffice.org 功能先进且灵活，还支持多种文件格式，包括 Microsoft Office。OpenOffice.org 可用的语言包括：英语、法语、德语、西班牙语、意大利语、瑞典语、芬兰语、俄语、中文、日语、韩语、丹麦语、捷克语、土耳其语、阿拉伯语。OpenOffice.org-* 可用的本地化帮助文件包括：法语、德语、西班牙语、意大利语、瑞典语、俄语、捷克语、日语、韩语。拼写检查和连字符字典分别位于 mys-* 和 myspell-* 包中。请根据您的语言需求安装最合适的包。使用方法：只需输入 "`office`" 即可运行 OpenOffice.org，或从桌面菜单中选择所需的组件（Writer, Calc, Draw, Impress 等）。如有必要，办公封装脚本将在用户的家目录下安装几个文件。来自 Mandrake 9.0 RPM `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## opensp
opengroup 的 SGML 解析。此包是一个名为 OpenSP 的 SGML/XML 工具集。它是 James Clark 的 SP 套件的分支。这些工具用于解析、验证和规范化 SGML 和 XML 文件。此包包含的核心程序有 '`oonsgm`'（替换了 sgml）、'`openspt`'、'`opensgmnr`' 和 '`sgml2xml`'。来自 Debian 3.0r APT `http://www.tdlp.org/LDP/Linux-Dictionary/html.index.html`

## openssh
用于登录远程机器以及在远程机器上执行命令的 SSH（安全外壳）。它旨在取代登录 rsh，并在不安全的网络上在不可信的主机之间提供安全的加密通信。X11 连接和 TCP/IP 端口也可以通过安全通道进行转发。OpenSSH 是 OpenBSD 的最新版本 SSH，它在安全和功能方面使其与时代同步，并移除所有专利算法剥离到独立库中（如 OpenSSL）。此包包含了 OpenSSH 客户端和服务器所需的核心文件。为了使此包有用，您还应该安装 openssh-clients、openssh-server 或两者。来自 Mandrake 9.0 RPM `http://www.tdlp.org/LDP/Linux-Dictionary/index`
