
$ mkisoofs -J -r -V "volume name" - ../image.iso /

该命令在当前目录的父目录下创建一个名为`image.iso`的镜像文件，使用工作目录（`./`）的内容作为镜像内容。`-j`和`-r`选项分别启用Joliet和Rock Ridge扩展，`-V`选项将卷标设置为你指定的任何内容。还有几十个其他选项和变体；详情请查阅`mkisoofs`页面。

一旦你创建了镜像文件，就可以使用以下命令刻录它：

$ cdrecord dev=0,4,0 speed=2 ../image.iso

在此示例中，`dev=0,4,0`选项指定使用SCSI主适配器`0`，刻录到SCSI ID为`4`的逻辑单元（LUN）CD-R上。速度使用`speed`选项设置，最终参数指定要刻录的文件源。使用`mkisoofs`和`cdrecord`。

## 使用外部外设

前面的章节描述了各种设备（如CPU、显卡和硬盘），这些设备通常驻留在计算机机箱内部。然而，许多计算机设备是外部的——它们位于计算机外部，并通过电缆（有时是红外或无线链路）与计算机连接。示例包括键盘、鼠标、扫描仪、摄像头、调制解调器和打印机。大多数此类设备通过三种类型的端口或接口进行连接：通用串行总线（USB）、RS-232串口端口或并行端口。少数设备（包括许多键盘和鼠标）通过其他端口接口。本章从这三个主要端口开始介绍；当你处理本章未明确涵盖的设备（如摄像头、调制解调器和打印机）时，你需要了解它们。本章将介绍三类不同的外部设备：键盘、鼠标和扫描仪。

## 识别 USB 设备

USB于20世纪90年代推出经过了一段时间才普及，但它现在已是极其流行的设备接口。某些计算机（特别是Macintosh）已经抛弃了RS-232串口和并行接口，转而采用USB端口，USB比RS-232串口端口更快，比并行端口更灵活。然而，USB的灵活性是有代价的：Linux需要不同的驱动程序来支持许多可用的USB设备。因此，配置USB支持可能是复杂的。遗憾的是，Linux并不支持所有的USB设备，尽管Linux支持许多最流行的USB设备。

## USB 驱动程序要求

为了使用USB设备，你的计算机至少需要两种类型的驱动程序。在某些情况下，你可能还需要额外的驱动程序：

### USB 主机控制器驱动程序

主机控制器驱动程序（HCD）是USB身的驱动程序，由你主板或USB扩展卡上的芯片组实现。从2.54内核开始，Linux支持三种HCD：增强型主机控制器接口（EHCI）、开放主机控制器接口（OHCI）和通用主机控制器接口（UHCI）。EHCI处理USB 2.0协议，其速度最高可达60MB/s，而USB 1.x则为1.5MB/s。UHCI是Intel和VIA主板芯片组使用的USB 1.x控制器。OHCI是大多数使用非Intel或VIA制造商芯片组的扩展卡和主板所使用的USB 1.x控制器。如果你的系统支持2.0，你同时需要EHCI驱动程序以及UHCI或OHCI驱动程序之一。

### USB 设备驱动程序

每个设备都有唯一的地址并支持自己的命令。例如，Linux必须能够将USB Zip磁盘视为块设备（以便单次操作传输512字节块），而USB键盘必须配置为设备字符，以便以单字节块的形式传输数据。此外，Zip磁盘需要扇区寻址、磁盘锁命令以及键盘不需要的功能。每个USB设备都需要它们自己的驱动程序。其中某些驱动程序（如键盘、鼠标和打印机的驱动程序）适用于整类设备。其他驱动程序（如用于磁盘和类磁盘设备的块存储驱动）是针对特定品牌和型号的设备编写的，尽管通用驱动程序有时也能用于明确支持的设备。

`非 USB 驱动程序` 某些USB驱动程序连接到内核设备驱动程序层级中的较旧非USB端口。最值得注意的是，大规模存储驱动程序让USB设备在Linux中看起来像SCSI驱动程序。程序还有USB转RS-232串口和并行适配器，它们分别连接到RS-232串口和并行系统；以及在软件中像声卡的设备。在所有这些情况下，你都需要对模拟设备进行基本支持。例如，为了使用Zip驱动器，你需要SCSI和磁盘支持。USB存储驱动程序的作用就像SCSI适配器的驱动程序。

除了这些驱动程序外，Linux内核选项包含一些调整性能或修改Linux与USB设备交互的功能。例如，设备系统创建一个名为`/proc/bus/usb/devices`的虚拟文件，包含USB设备的信息。

> 注意：USB文件系统不在`/dev`目录中创建任何文件或子目录。如果你在启动时激活此文件系统，Linux将为USB设备创建条目。大多数Linux发行版支持大多数USB设备。然而，如果你重新编译内核，你需要查看第1章“自定义内核”。因此，你应该检查`http://www.linux-usb.org`获取进展。

## 使用 USB 设备

由于USB设备多种多样，无法提供简单完整的说明。使用USB的通用概述如下：

- 1. 将USB设备插入计算机。
- 2. 如果适用，开启设备。
- 3. 加载设备的Linux内核模块，正如第1章“优化系统架构”所述。在大多数情况下，驱动程序会在插入开启设备时自动加载。
- 4. 像使用其他同类设备一样使用该设备。例如，使用`/etc/X11/XF6.conf`中的`mount`为鼠标创建适当条目；或使用`mount`挂载USB磁盘。
