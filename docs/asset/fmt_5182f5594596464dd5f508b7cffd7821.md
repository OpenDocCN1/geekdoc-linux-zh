## 工作目录

你可能会想象，每次想访问文件时都输入完整路径是很累的且容易出错的。为了方便，Unix 允许你指定一个工作目录（也称为当前目录）。每当你使用工作目录中的文件时，只需要输入文件名；不需要指定整个路径。例如，假设你的用户 ID 是 `harley`，主目录是 `/home/harley`。要使用 `vi` 编辑 `memo`，以下命令是等价的：

```

```

```

```

```

/home/harley/document
```

```
document
```
