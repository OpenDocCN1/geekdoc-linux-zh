
# 正长岩

一种显晶质（可见晶体）侵入岩，具有颗粒状结构，主要由碱长石（正长石、微斜长石，通常含钒）组成，辅以次要的斜长石（钠长石）和深色（基性）矿物（黑云母、角闪石和辉石）。如果钠质斜长石（钠长石或中长石）的数量超过碱长石，则该岩石称为似长石岩（monzonite）。似长石岩通常为浅至中灰色，但正长岩的颜色种类繁多（灰色、绿色、粉色），某些石材使该材料成为理想的装饰石。正长岩是一种不常见的侵入岩，通常出现在相对较小的岩体中（岩墙、岩床、岩株和小型不规则岩株）。参见[火成岩](IGNEOUS ROCKS)。[CA.C.J.]

## 共生星

恒星演化晚期的双星系统。由于共生系统通常位于双星系统中的宽轨道上，食相是稀有的天体。“非官方”的共生星列表包含188个确定条目，其中15个为河外星系天体，30个为疑似候选对象。

证据积累表明，所有星云都是周期在一年到数十年之间的双星。它们的轨道足够宽，使得两颗恒星不直接接触，且两颗恒星都安全地位于其`Roche lobe`内。因此，这两颗恒星的演化应以使其质量交换几乎不受伴星影响的方式进行。因此，在其演化晚期，变化会剧烈发生。参见[双星效应](DOUBLE EFFECT)；[食变星](ECLIPSING VARIABLE STARS)。

光谱学指示存在一颗表面温度低于4000 K的冷M型恒星，以及一个热星云，其非常类似行星状星云。其光输出在数天、数月乃至数年的时间尺度上是可变的。参见[天文学光谱学](ASTRONOMICAL SPECTROSCOPY)；[光变曲线](LIGHT CURVES)；[星云](NEBULA)；[行星状星云](PLANETARY NEBULA)；[变星](VARIABLE STAR)。

共生星云中的气体温度约为15,000 K，对于通过碰撞电离星云中的原子达到观测到的程度来说，这个温度太低了。星云气体必须由一颗小而非常热的恒星通过辐射电离。观测和模型计算表明冷恒星是一颗红巨星。对于热恒星，发现其温度在50,000到200,000 K之间。该恒星的尺寸与白矮星或行星状星云的中心恒星相当，介于-0.01到-0.1个太阳半径之间。

共生星云通常具有与红巨星预期相同的化学成分。这被取作证据，表明红巨星遭受显著的质量损失。共生星始恒星质量约为5个太阳质量。质量较大的恒星更快地穿过主序星阶段，当它到达红巨星区时，通过恒星风失去了大部分质量。该物质有时仍可在更广阔的环境中检测到。该恒星已变成一颗热的白矮星。原本质量较小的恒星保留其质量，并已进入红巨星阶段，伴有巨大的质量损失。参见[恒星演化](STELLAR EVOLUTION)；[白矮星](WHITE DWARF STAR)。

红巨星失去的部分质量被白矮星捕获。吸积释放引力能，这些能量可转化为辐射能，并负责部分不规则的光度变化。当白矮星积聚到...

积累到氢的关键质量后，其表面发生热核反应，作为一次持续超过 100 年的能量爆发。这种能量产生爆发可达到太阳的数千倍。其机制类似于新星爆发。然而，与共生新星相比，经典新星的峰值能量输出更高且持续时间更短。参见 `灾变变星：新星`。

观测显示，热星以前丢失的物质留下了痕迹。然而，如上所述，目前检测到的电离星云的大部分物质是由于红巨星通过恒星风失去的。在其活跃期，白矮星可能有自己的恒星风。在这种情况下，双风碰撞将强烈塑造星云环境。这导致出现温度达数百万开尔文的激波区。在几颗共生双星中观测到的双极气体射流的起源尚不清楚。观测证据表明白矮星拥有强磁场，这可能起主要作用。[H.N.]

## 符号计算

根据数学逻辑规则操纵数字和变量的过程。变量用于以某种精度表示实数或实数集。数字可以进行加法、减法、乘法和除法运算。数值计算涉及执行这些运算。例如，如果符号 * 用于表示乘法，/ 用于表示除法，那么方程

$$(3 \times 5 - 11) / 7 = 2$$

表示结果为 2 的数值计算。在数学中，也可以使用符号来表示数字，并对符号进行运算。例如，

$$ax + b = 0 \quad (\text{其中 } a \neq 0)$$

也可以表示为

$$x = -\frac{b}{a}$$

在此计算中，遵循减法和除法的数学规则。符号 *x* 被视为需要求解的未知数或变量，*a* 和 *b* 是代表未知但固定的数字的参数。

20 世纪 90 年代，出现了可以根据数学规则操纵符号的数学软件包。它们也被称为符号计算包，并且是编程环境，因为任何实数都有小数展开式。这些软件包能够以符号形式获得精确答案。例如，如果

$$x^2 - 2 = 0, \quad x > 0$$

被输入到符号计算包中，软件包将返回答案

$$x = \sqrt{2}$$

软件包还允许用户要求 2 的任意位数近似值。2 的小数位是通过执行数值计算（称为数值算法）的算法确定的。符号计算包允许进行符号计算和数值计算。参见 `算法`；`计算机编程`；`数学软件`。

小型计算机和手持计算器能在短时间内执行极其复杂的计算的能力，推动了能够执行符号操纵的数学软件包的开发。这些符号操纵软件包（也称为计算机代数系统或符号计算系统）可以通过根据数学规则操纵符号，比庞大的数学家团队更快地进行代数、三角学、数论、微积分、常微分方程和偏微分方程、矩阵代数以及其他数学领域的运算。答案以符号形式精确给出，然后可以使用软件包中的例程进行数值近似。

计算机可视化的出现使得这些软件包能够以多种形式绘制数据或函数成为可能。函数以符号形式输入，软件对其进行数值评估以便绘制数字。绘图例程生成的图形可以标注、旋转或动画处理，还有众多其他可能性。

手持计算器可以执行符号操纵、绘制数据或函数图形，并可以编程以执行一系列操作。已经开发出能够执行符号操纵、绘制数据或函数图形，并使用软件包中的例程进行编程的数学软件包。这些软件包在大多数常用操作系统上运行。它们也可以由计算机程序调用，在程序中执行操纵。还有执行统计学、计算金融、计算物理和计算化学的软件包。参见 `计算器`；`操作系统`；`编程语言`。 [J.So]

## 对称齿类

一群已灭绝的哺乳动物，时间跨度从晚三叠世到晚白垩世。其化石遗骸已在世界各地的中生代地层中发现。这些小型食虫或食肉哺乳动物大小如鼩鼱或老鼠。它们被认为是更高等陆生哺乳动物的远亲，包括已灭绝的真兽类，如干olestids（dryolestids）以及现生的胎盘类和有袋类哺乳动物。

对称齿类的一个显著特征是：其颊齿的主尖呈对称三角形。三角形上下颊齿填补相邻齿列之间的空隙，专门用于压碎昆虫或咬断蠕虫。然而，对称齿类的下齿缺乏类似盆地的后缘，这使得它们无法像更高等的现生真兽类哺乳动物及其近亲那样研磨食物。对称齿类还缺乏下颌角，从而与更高等的兽类区别开来。

对称齿类被归类为哺乳纲下的对称齿目。在多样化的对称齿类中，有三个科值得一提：被认为接近所有其他真兽类哺乳动物祖先的 Kuhmoetheriidae（库莫热齿科）；Amphidontidae（双齿科）；以及 Spalacotheriidae（三尖齿科），后者以高度尖锐的三角形颊齿为特征，是对称齿类中多样性最高的科。 [Z.L.]

## 对称性破缺

指对精确对称性的偏离。根据现代物理理论，基本物理定律具有极高的对称性。关于为什么特定的物理系统甚至整个宇宙展现出的对称性低于定律本身的理解，带来了对自然界的几个深刻洞察。

### 自发对称性破缺

这种机制发生在多种多样的情况下。支配给定系统的基本方程的最对称解可能是不稳定的，因此在实践中，系统处于对称性较低但稳定的状态。当这种情况发生时，称对称性发生了自发破缺。

例如，物理定律在任何空间平移下保持不变，但晶体晶格仅在特殊类别的平移下保持不变。晶体确实保留大量对称性，因为它在那些有限平移下保持不变，但这远远不及基本定律的全对称性。

另一个例子是铁磁性材料。这类材料中电子的自旋倾向于沿某一特定方向排列，即磁极的轴。支配这些自旋之间相互作用的物理定律在任何空间旋转下保持不变，但自旋的对齐构型对称性较低。事实上，它仅在绕极轴旋转时保持不变。参见 `铁磁性`。

在这两个例子中，对称性的丧失与有序的出现相关。这是自发对称性破缺的一个普遍特征。

### 后果

与自发对称性破缺相关的一组重要的可观测后果。Nambu-Goldstone 玻色子是与有序结构的轻微破坏相关的一类低能激发。因此，如果这是铁磁体的一类激发，即作为自发对称性破缺的后果而存在且能量非常低的磁子。类似地，在晶体的情况下，声子与晶格结构的轻微畸变相关。参见 `磁子`；`声子`。

在高温下，通过假设有序结构获得的能量越来越被其施加的约束所导致的熵损失所抵消，在某个点，热平衡中自发对称性破缺将不再有利。从破缺对称性到未破缺对称性的变化由相变标记。对于磁体，转变发生在居里温度。对于晶体，它是熔化为液体或升华为气体。参见 `居里温度`；`熵`；`相变`；`热力学原理`。

缺陷是有序结构的不完善之处。最熟悉的例子是磁体中的畴壁。参见 `晶体缺陷`；`磁畴（电磁学）`。

在具有长程力以及自发对称性破缺的系统中，即使遥远区域显著相互作用，渐变也不一定只需少量能量。因此，Nambu-Goldstone 玻色子不再具有非常低的能量，且不易被激发。相反，系统将表现出特殊的刚性，遥远点之间存在强关联。这些概念是现代超导理论和粒子物理理论（希格斯机制）的核心。参见 `电弱相互作用`；`希格斯玻色子`；`超导性`。
