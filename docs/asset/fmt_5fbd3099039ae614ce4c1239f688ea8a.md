
# AlphaProject 数据库设计与迁移指南

## 核心需求与实体规划

在设计模式之前，我们首先为 AlphaProject 规划核心需求和实体。假设 AlphaProject 是一个具有以下功能的项目管理应用程序：

- 用户管理
- 项目跟踪
- 任务分配与状态更新
- 耗时跟踪

### 识别实体

识别应用程序涉及的主要实体。对于 AlphaProject，主要的实体有：

- 用户
- 项目
- 任务
- 时间条目

### 定义表和列

根据识别出的实体，定义这些表及其对应的列。

#### `users` 表

`users` 表将存储应用程序用户的信息。

```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### `projects` 表

`projects` 表将存储应用程序内管理的项目信息。

```sql
CREATE TABLE projects (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  description TEXT,
  start_date DATE,
  end_date DATE,
  created_by INT REFERENCES users(id),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### `tasks` 表

`tasks` 表将存储与项目相关的任务信息。

```sql
CREATE TABLE tasks (
  id SERIAL PRIMARY KEY,
  project_id INT REFERENCES projects(id),
  name VARCHAR(100) NOT NULL,
  description TEXT,
  status VARCHAR(20) DEFAULT 'pending',
  assigned_to INT REFERENCES users(id),
  due_date DATE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### `time_entries` 表

`time_entries` 表将跟踪在任务上花费的时间。

```sql
CREATE TABLE time_entries (
  id SERIAL PRIMARY KEY,
  task_id INT REFERENCES tasks(id),
  user_id INT REFERENCES users(id),
  hours DECIMAL(5, 2) NOT NULL,
  entry_date DATE NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 定义关系

使用外键建立表与表之间的关系：

- 每个任务都通过 `project_id` 外键与一个项目关联。
- 每个任务都可以通过 `assigned_to` 外键分配给某个用户。
- 每个时间条目都通过 `task_id` 和 `user_id` 外键与一个任务和一个用户关联。

### 定义约束

添加约束条件以确保数据的完整性和一致性。常见的约束包括 `PRIMARY KEY` 和 `FOREIGN KEY`。例如，如果我们想确保电子邮件地址是唯一的：

```sql
ALTER TABLE users
ADD CONSTRAINT unique_email UNIQUE (email);
```

### 索引

创建索引以提高查询性能。索引通常创建在频繁用于搜索条件或连接操作的列上。

在 `username` 列上创建索引以加快查找：

```sql
CREATE INDEX idx_users_username ON users(username);
```

在 `tasks` 表的 `project_id` 列上创建索引，以便通过项目快速访问任务：

```sql
CREATE INDEX idx_tasks_project_id ON tasks(project_id);
```

## AlphaProject 的数据库集成

现在数据库模式已经就绪，你可以将其集成到 AlphaProject 应用程序中。确保你的应用程序使用了正确的连接设置，并执行必要的数据库操作，如创建、读取、更新和删除记录。

例如，在 Python 应用程序中使用 SQLAlchemy：

```python
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker, relationship
from sqlalchemy import Column, Integer, String, Text, DateTime, Numeric, Date, ForeignKey

DATABASE_URL = "postgresql://user:password@localhost/alphaproject_db"

engine = create_engine(DATABASE_URL)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()

# 定义映射数据库的模型
class User(Base):
    __tablename__ = 'users'
    id = Column(Integer, primary_key=True, index=True)
    username = Column(String(50), unique=True, nullable=False)
    password = Column(String(255), nullable=False)
    email = Column(String(100), unique=True, nullable=False)
    created_at = Column(DateTime, default='CURRENT_TIMESTAMP')

class Project(Base):
    __tablename__ = 'projects'
    id = Column(Integer, primary_key=True, index=True)
    name = Column(String(100), nullable=False)
    description = Column(Text)
    start_date = Column(Date)
    end_date = Column(Date)
    created_by = Column(Integer, ForeignKey('users.id'))
    created_at = Column(DateTime, default='CURRENT_TIMESTAMP')

class Task(Base):
    __tablename__ = 'tasks'
    id = Column(Integer, primary_key=True, index=True)
    project_id = Column(Integer, ForeignKey('projects.id'))
    name = Column(String(100), nullable=False)
    description = Column(Text)
    status = Column(String(20), default='pending')
    assigned_to = Column(Integer, ForeignKey('users.id'))
    due_date = Column(Date)
    created_at = Column(DateTime, default='CURRENT_TIMESTAMP')

class TimeEntry(Base):
    __tablename__ = 'time_entries'
    id = Column(Integer, primary_key=True, index=True)
    task_id = Column(Integer, ForeignKey('tasks.id'))
    user_id = Column(Integer, ForeignKey('users.id'))
    hours = Column(Numeric(5, 2), nullable=False)
    entry_date = Column(Date, nullable=False)
    created_at = Column(DateTime, default='CURRENT_TIMESTAMP')
```

数据和模式的随时间变化的管理需要数据库迁移。开发者可以使用迁移来分阶段应用更新，确保跨环境的一致性，并升级或迁移数据库。在这里，我们将展示如何使用一种方便迁移的工具，解释其必要性并介绍具体的迁移步骤。

## 安装和设置 Alembic

Alembic 是一个轻量级的数据库迁移工具，用于 SQLAlchemy（Python 的数据库工具包 ORM）。Alembic 设计用于与 SQLAlchemy 支持的数据库工作，包括 PostgreSQL。它提供了一种简单的方法，通过版本化的迁移脚本来管理数据库模式的更改。

### 安装 Alembic

首先，使用 pip 安装 Alembic：

```bash
$ pip install alembic
```

### 初始化 Alembic

进入你的项目目录并初始化 Alembic：

```bash
$ alembic init alembic
```

此命令会创建一个 `alembic` 目录和一个配置文件。

### 配置 Alembic

编辑 `alembic.ini` 文件以配置数据库连接字符串：

```ini
[alembic]
# 迁移脚本的路径
script_location = alembic

[loggers]
keys = root,sqlalchemy,alembic

[handlers]
keys = console

[formatters]
keys = generic

[logger_root]
level = WARN
handlers = console
qualname =

[logger_sqlalchemy]
level = WARN
handlers =
qualname = sqlalchemy.engine
propagate = 0

[logger_alembic]
level = INFO
handlers =
qualname = alembic
propagate = 0

[handler_console]
class = StreamHandler
args = (sys.stderr,)
level = NOTSET
formatter = generic

[formatter_generic]
format = %(asctime)s %(levelname)s -5s [%(name)s] %(message)s

sqlalchemy.url = postgresql://alphaproject_user:yourpassword@localhost/alphaproject_db
```

### 编辑环境脚本

更新 `alembic/env.py` 文件以将 Alembic 与 SQLAlchemy 模型连接：

```python
from sqlalchemy import engine_from_config, pool
from logging.config import fileConfig
from alembic import context

# 导入你的 SQLAlchemy 模型
from your_project.models import Base

# 这是 Alembic 配置对象，它提供了
# 对正在使用的 .ini 文件中值的访问。
config = context.config

# 为 Python 日志解析配置文件。
# 这一行基本上设置了日志记录器。
fileConfig(config.config_file_name)

# 在此处添加你的模型的 MetaData 对象
# 以支持 'autogenerate'
target_metadata = Base.metadata

def run_migrations_offline():
    """在“离线”模式下运行迁移"""
    url = config.get_main_option("sqlalchemy.url")
    context.configure(url=url, target_metadata=target_metadata,
                     literal_binds=True)
    with context.begin_transaction():
        context.run_migrations()

def run_migrations_online():
    """在“在线”模式下运行迁移"""
    connectable = engine_from_config(
        config.get_section(config.config_ini_section),
        prefix="sqlalchemy",
        poolclass=pool.NullPool)

        context.configure(connection=connection,
```
