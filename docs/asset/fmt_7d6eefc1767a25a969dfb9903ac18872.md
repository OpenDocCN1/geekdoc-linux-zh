# 1 第一要准则

**提供并维护系统资源的访问**是系统管理员的“首要准则”。归根结底，我们所有的专业活动都源于或涉及这一目标。无论涉及何种计算平台，所有的操作系统都提供了管理资源的机制。这些资源包括文件、应用程序、外设、服务、带宽、`CPU` 周期、内存和存储空间。

识别资源、其所有者和用户，并定义访问的形式和涉及的权限，是一个需求分析的过程。系统管理员必须将这种通用性描述转化为针对其系统、用户和管理的具体细节。

维护对系统资源的访问超越了对系统本身访问的维护。如果系统由于某些灾难而故障或无法使用，系统管理员将被及时恢复正常运行。大多数人认为“做备份”就满足了这一要求。然而，我们的重点将放在恢复规划上——这包括执行备份，还涉及风险评估、测试等内容。

在正常运行期间，特别是当组织增长和适应时，跨系统的资源利用率会发生变化。当任何资源的尝试利用率超过容量时，很可能被视为一种灾难。系统管理员在提供必要访问的首要准则上就失败了。一个故障也可能导致其他服务的故障。例如，如果系统日志填充磁盘分区，可能会导致无法发送邮件。这些灾难必须通过容量规划来避免。

安全是我们首要准则的推论——拒绝对系统资源的访问，并确保在外部或内部人员攻击期间和之后恰当地提供服务。安全涉及策略管理和执行。

必须根据每个资源所有者的授权，提供适当访问的形式。定义和执行这些策略的过程是系统安全的两个基本组成部分。安全渗透到系统管理的每一个方面，尽管我们对每个安全主题都单独包含了一章，但我们在每一章中都会提到安全影响。

这些主题——需求分析、恢复规划、容量规划和安全——是系统管理员工作的核心，构成了 `Linux` 系统管理的第一部分。在讨论这些主题时，使用了基于 `GNU/Linux` 的示例，但大多数适用于其他 `UNIX` 变体。这些概念适用于计算机系统。

本书其余部分涵盖了管理 `LINUX` 系统的实用细节，包括启动和关机、内核、网络配置文件以及最常用服务器和工作站的示例配置说明。

## 为什么系统需要管理？

通过 `LINUX`，我们拥有了一个易于安装的 `UNIX` 版本，它可以在各种常用（且便宜）的硬件上运行，以至于经验不丰富的用户也能胜任。相比十年前销售的 `MS-DOS` 版本，流行的 `LINUX` 发行版容易安装得多。

然而，在 `PC` 上安装 `LINUX` 并运行典型应用程序是一回事，几乎任何人都可以这样做。但要以符合业务需求的方式这样做，则需要专业人士。习惯了家庭电脑的人自然会问：“为什么这些系统需要持续维护？”事实是，许多系统并不需要。“嵌入式”和“开箱即用”系统需要的维护更少。

## 谁来管理 Linux 系统？

然而，大多数组织的计算机系统是动态的。计算机是通用设备，大多数操作系统和市售软件都是为通用用途编写的。因此，系统管理员的工作是将这些工具适应到特定的需求。这些需求会随时间变化，并在部门之间存在差异。

## 谁来管理 Linux 系统？

如果你正在阅读这本书，你可能正在管理至少一个 `Linux` 系统，或者在不久之后将负责一个或多个 `Linux` 系统。

也许你一直在管理一个充满 `Unix` 工作站和服务器的局域网，并且正在向网络加入 `PC`。这可能是由低成本、普及性或其他任何其他因素驱动。你可能还在考虑在旧的 `Sun` 或 `SGI` 工作站上运行 `SPARC` 或 `MIPS` 的 `Linux`。

也许你是从 `PC` 世界接触 `Linux` 的。你一直在管理 `NetWare`、`LAN Manager` 或 `Windows NT` 服务器，现在你需要用某种形式的 `Unix` 来管理或替换这些。

也许你关心的甚至不是服务器。你的某些用户可能要求访问 `Unix` 世界的应用程序和工具。`Linux` 版 `WordPerfect` 的发布以及该软件包的最近更新，加上 `StarOffice` 商业应用的成熟，以及 `LyX`、`Sciave` 和 `GIMP` 等免费软件的持续开发，都在导致这种需求。

也可能是你的管理层对桌面系统有更集中的控制和安全性要求，这是更多的 `PC` 和 `Macintosh` 操作系统无法实现的。

也许你是一个丰富的 `Linux` 用户，但这些系统的专业管理对你来说是新的。多用户和网络系统的管理比维护和使用家庭系统复杂得多。

# 标题与角色

许多主要工作职责包括管理 `Unix` 或 `Linux` 操作系统的人员并没有“系统管理员”这一头衔。事实上，“系统管理员”在《职业名称字典》[26]中根本没有出现过。根据《系统管理员杂志》（`SysAdmin Magazine`）的一项调查，超过 70% 的订阅主要负责管理一个或多个 `UNIX` 系统，他们拥有其他的职位名称。

系统管理员协会（`SAGE`）在《系统管理员职位描述》[28]中详细讨论了这一点。`SAGE` 是 `USENIX` 协会内部的一个特殊技术小组。其使命是促进对系统管理作为一项职业的认可，并制定该领域的命名、培训以及可能的认证标准。

查看 `SAGE` 薪资调查，我们发现他们的成员名单列出了一百多个职位名称。在某些情况下，这是由于简单的官僚命名导致的；而在另情况下，这反映了系统管理员职责之间的真实差异。

我们定义了全文将使用的标题和相应的角色。除了系统管理员外，还包括数据库管理员、网络管理员、操作员和经理。当我们使用特定标题时，其隐含的角色将如我们在此处定义的那样。

# 系统操作员与经理

许多组织将其系统管理员、网络管理员、数据库管理员及相关人员放入信息系统（`IS`）或信息技术（`IT`）部门。他们可能还会增加系统分析师、网页工具和作者以及网站管理员，可能还有一个帮助台团队，以及一些管理人员。
