`sys_stat()`返回文件系统的数据。`sys_fstat()`返回 inode 的数据。`sys_lstat()`返回符号链接的数据。这三者在可用时都使用`new_stat`结构。

系统调用通过`syscall`宏进行转换。

# Errors

`EBADF` - 如果`fd`无效。`ENOENT` - 如果路径不存在。
