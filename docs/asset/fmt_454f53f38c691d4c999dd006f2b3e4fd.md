
Second argument: `b`

Third argument: `c`

Fourth argument: `d`

Fifth argument: `e`

Sixth argument: `f`

Seventh argument: `g`

Eighth argument: `h`

Ninth argument: `i`

注意，位置参数只能使用到 `$9`。如果你需要更多参数，可以使用 `${10}`、`${11}` 等格式。

使用下面的脚本演示：

```bash
#!/bin/bash

echo "Tenth argument: ${10}"

echo "Eleventh argument: ${11}"

echo "Twelfth argument: ${12}"
```

运行该脚本：

```bash
bash script.sh a b c d e f g h i j k l m
```

输出将是：

```
Tenth argument: k

Eleventh argument: l

Twelfth argument: m
```

## 参数扩展

除了位置参数，shell 还提供了许多其他特殊变量来处理命令行。

- `$#`：传递给脚本的参数个数。
- `$@`：所有参数的列表，每个参数被视为独立的字符串。
- `$*`：所有参数的列表，所有参数被视为单个字符串。
- `$0`：用于执行的脚本名称。

使用下面的脚本测试这些变量：

```bash
#!/bin/bash

echo "Number of arguments: $#"

echo "All arguments (unquoted): $@"

echo "All arguments (quoted): $* "
```

运行该脚本：

```bash
bash script.sh "hello world" apple "cherry pie"
```

输出将是：

```
Number of arguments: 3

All arguments (unquoted): hello world apple cherry pie

All arguments (quoted): "hello world apple cherry pie"
```

注意 `$@` 和 `$*` 的区别：当在双引号中使用时，`$@` 会保留每个参数的独立性，而 `$*` 则会将所有参数合并成一个字符串。

## 移动参数

`shift` 命令用于将位置参数向左移动。

```bash
#!/bin/bash

echo "Before shift: $1 $2"
shift
echo "After shift: $1 $2"
```

运行该脚本：

```bash
bash script.sh a b
```

输出将是：

```
Before shift: a b

After shift: b 
```

`shift` 会移除 `$1`，并将 `$2` 变成 `$1`，`$3` 变成 `$2`，以此类推。你也可以为 `shift` 指定一个数字来一次移动多个参数：

```bash
#!/bin/bash

echo "Before shift 2: $1 $2 $3"
shift 2
echo "After shift 2: $1 $2"
```

运行该脚本：

```bash
bash script.sh a b c d
```

输出将是：

```
Before shift 2: a b c

After shift 2: c d
```

`shift` 命令在循环中处理所有参数时非常有用：

```bash
#!/bin/bash

while [ $# -gt 0 ]; do
  echo "Processing: $1"
  shift
done
```

运行该脚本：

```bash
bash script.sh a b c
```

输出将是：

```
Processing: a

Processing: b

Processing: c
```

## 默认值

shell 允许你为变量设置默认值。

- `${parameter:-word}`：如果 `parameter` 未设置或为空，则使用 `word`。
- `${parameter:=word}`：如果 `parameter` 未设置，则将其赋值为 `word`。

使用下面的脚本演示：

```bash
#!/bin/bash

unset VAR
echo "Value: ${VAR:-default}"
echo "Value after: ${VAR:=default}"
echo "VAR is now: $VAR"
```

运行该脚本：

```
Value: default

Value after: default

VAR is now: default
```

## 字符串替换

shell 提供了强大的字符串替换功能。

- `${parameter/pattern/replacement}`：替换 `parameter` 中第一个匹配 `pattern` 的 `replacement`。
- `${parameter//pattern/replacement}`：替换 `parameter` 中所有匹配 `pattern` 的 `replacement`。

使用下面的脚本演示：

```bash
#!/bin/bash

STR="hello world, hello"
echo "First match: ${STR/world/good}"
echo "All matches: ${STR//hello/hi}"
```

运行该脚本：

```
First match: hello good, hello

All matches: hi world, hi
```

## 字符串截取

你还可以从字符串中截取部分。

- `${parameter:offset:length}`：从 `offset` 开始截取 `length` 个字符。
- `${parameter:offset-}`：从 `offset` 开始截取到末尾。

使用下面的脚本演示：

```bash
#!/bin/bash

STR="bash programming"
echo "Substring: ${STR:0:4}"
echo "From index 5: ${STR:5}"
echo "Last 4 chars: ${STR:-4}"
```

运行该脚本：

```
Substring: bash

From index 5: programming

Last 4 chars: ming
```

这意味着我们创建一个脚本或 shell 函数来简化对另一个程序的调用。在这种情况下，包装器（wrapper）提供了一系列命令行选项，并将一组参数传递给底层程序。

shell 为此目的提供了两个特殊参数。它们都能展开完整的位置参数列表，但在展开方式上存在细微的差别。表 32-1 描述了这些参数。

## 表 32-1：* 和 @ 特殊参数

| 参数 | 描述 |
| --- | --- |
| `$*` | 展开为从 1 开始的位置参数列表。当被双引号包围时，它会展开为一个包含双引号的字符串，该字符串包含所有位置参数，每个参数之间由 IFS 变量的第一个字符（默认为空格）分隔。 |
| `$@` | 展开为位置参数列表；当被双引号包围时，它会将每个位置参数展开为一个独立的单词，就像每个参数都被双引号包围一样。 |

下面是一个展示这些特殊参数作用的脚本：

```bash
#!/bin/bash
# posit-param3: script to demonstrate $* and @
print_params() {
  echo \$1 = "$1"
  echo \$2 = "$2"
  echo \$3 = "$3"
  echo \$4 = "$4"
}
```

```bash
pass_params() {
  echo -e "\n" '**' : ''; print_params $*
  echo -e "\n" '**' : ''; print_params "$*"
  echo -e "\n" '**' : ''; print_params "$@"
  echo -e "\n" '**' : ''; print_params "$@"
}
```

```bash
pass_params "word" "words with spaces"
```

在这个相当复杂的程序中，我们创建了两个名为 `word` 和 `words with spaces` 的参数，并使用特殊参数 `$*` 和 `$@` 的四种方法将它们传递给 `pass_params` 函数。执行时，脚本揭示了它们之间的。

```
[melinuxbox ~/ posit-param3
$ $* :
$1 = word
$2 = words
$3 = with
$4 = spaces
```
