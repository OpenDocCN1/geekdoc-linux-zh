
有效的设备名称及其主、次设备号列在内核源码目录下的 `devices.txt` 文件中，该路径为 `/usr/src/linux`。在创建设备时，你根据要创建的特定类型设备使用主设备号、次设备号以及设备名称前缀。这些设备大部分已经为你创建好了，并列在 `/etc/dev` 目录下。

## 设备信息：/proc

`/proc` 文件系统维护着有关你设备的特殊信息。`/proc` 文件列出了你安装的所有硬件和块设备以及它们的主设备号。当前设备使用的 IRQ、DMA 和 I/O 端口分别列在 `interrupts`、`dma` 和 `ports` 中。某些文件列出了涵盖多个设备的信息，例如，`pci` 列出了你所有的 PCI 设备，`sound` 列出了你所有的声设备。

| 文件路径 | 描述 |
| :--- | :--- |
| /proc/interrupts | 当前用于设备的 IRQ |
| /proc/dma | 当前用于设备的 DMA |
| /proc/ports | 当前用于设备的 I/O 端口 |
| /proc/pci | 你所有的 PCI 设备 |
| /proc/sound | 你所有的声设备 |
| /proc/scsi | SCSI 设备 |
| /proc/ide | IDE 设备 |
| /proc/net | 网络设备 |

# printconf

Red Hat 发行版提供的 `printconf` 工具是一个用于设置和管理打印机的简单接口。仅需 `printconf`，你就可以在 Linux 系统上轻松安装打印机。你可以通过选择 Gnome 系统菜单中的“Printer Configuration”项来启动 printconf。`printconf` 工具允许你为打印机选择合适的驱动程序，并设置纸张大小和打印分辨率等打印选项。一旦你使用 printconf 配置了打印机，`printconf` 将在 `/etc/printcap` 文件中为其生成条目。更多详情请参见《Red Hat 定制指南》中的 `printconf` 部分。

当你启动 `printconf` 时，会弹出一个列出已安装打印机的窗口。要添加新打印机，点击“New”按钮。要编辑已安装的打印机，双击其条目，或选择它并点击“Edit”按钮。完成更改后，你可以点击“Apply”按钮保存更改并重启打印机守护进程。如果系统中有多个打印机，你可以通过选择它并点击“Default”按钮将其设置为默认打印机。“Delete”按钮将移除打印机配置。你可以从“Test”菜单中通过 PostScript、A4 或 ASCII 测试页来测试打印机。

当你选择“New”时，将显示一系列对话框，你可以在其中输入打印机名称、类型及其驱动程序。你也可以编辑打印机以更改任何设置。在编辑时，会显示四个选项页面板，分别用于打印机名称、队列类型、驱动程序和选项。

对于队列选择，你可以指定打印机设备和输出池打印目录的条目。设备是打印机连接的端口。对于前三个并行端口，这些是 `lp0`、`lp1` 和 `lp2`；对于串口端口，这些是 `ttyS0`、`ttyS1` 和 `ttyS2`；此类推。见图 33-1。通过下拉菜单，你还可以指定打印机是本地连接还是通过 Linux/Unix、Windows (SMB) 或 NetWare 网络远程连接。

## 配置 lpd

LPRng 允许你配置 lpd 服务器，提供对其他服务器的支持，例如安全访问或设置全局默认值。只有两个配置文件需要管理，且两者都有详细的注释。Red Hat 为这两个文件提供了基本版本。它提供了大量功能，允许你创建具有强大且复杂能力的服务器。

### 通用配置：lpd.conf

lpd 打印机的通用配置在 `/etc/lpd.conf` 文件中处理。在这里，你可以指定适用于所有打印机和打印管理的功能。你应该将这些视为默认功能，因为其中任何一个都可以在打印机的 `printconf` 中被覆盖。
