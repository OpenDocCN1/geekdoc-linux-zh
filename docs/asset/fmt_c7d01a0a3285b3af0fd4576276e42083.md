## 使用 nmap 审计你的网络服务公告

对于某些 Linux 网络服务，你希望获得大量的关注。而对于其他网络服务，你只希望获得少数授权人员的关注。你需要知道你的网络服务是如何公布的。换句话说，你想知道恶意扫描器是否能看到你的 Linux 服务器的网络端口以及它们提供的服务。
