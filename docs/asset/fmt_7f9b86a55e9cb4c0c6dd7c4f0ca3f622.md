# discover

# 磁盘工作站 (Disk workstation)
在局域网 (LAN) 中，具有中央处理器 (CPU) 和随机访问存储器 (RAM) 的终端没有自己的磁盘驱动器。无盘工作站确保组织中的每个人都产生兼容的数据并有助于降低安全风险。然而，无盘工作站会导致速度、灵活性和原创性的严重损失，并且对磁盘或系统崩溃的影响更具脆弱。来自 QUECID

## dist
用于开发、维护和发布软件的工具。`dist` 软件包是一组确保可移植软件易于构建和维护的工具。第一个组件是 `Configure` 脚本生成器 `metacconfig`，它自动从你的源码构建 `Configure` 脚本，理想的用户接收源码后需要阅读你的 `README` 文件，运行 `Configure` 脚本（自包含文档）并运行 `make`。第二个组件是 `Makefile` 生成器，它是一个通用的 `Makefile`，复用了由 `Configure` 计算出的部分信息，以及通用的 `Makefile` 描述。第三个组件是感知 RCS 的包生成器，用于构建 shell 以分发你的源码，随后可以使用 `patch` 程序将其应用到原始分发版中。第四个也是最后一个组件是 `patch` 生成器，用于更新此软件包的上游源码，这些更新可以从 CPAN 下载，如下：http://search.cpan.org/doc/RAM/dist-3.0/70 来自 Debian 3.0 apt http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
