- 3. 按如下方式输入带有时间指定的 `at` 命令：

`$ at now + 15 minutes`

- 4. 在 `at>` 提示符下，输入此循环命令：

`at> for i in /etc/*conf`

- 5. 在下一个 `at>` 提示符下输入 `do` 命令。

- 6. 在下一个 `at>` 提示符下输入 `wc -w $i`。

7. 在下一个 `at>` 提示符下输入 `done`。你的屏幕现在应如下所示：

```
$ at now + 15 minutes
at> for i in /etc/*conf
at> do
at> wc -w $i
at> done
at>
```

8. 按 `Ctrl+d` 完成你想要自动化的命令的输入。你看到了什么消息？指定了什么时间？它是相对时间还是基于你输入的时间指定的绝对时间？
