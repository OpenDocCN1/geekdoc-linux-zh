
# 图形化 shell

图形化 shell 提供了各种方法用于操作基于 GUI 或图形用户界面的程序。这是通过允许关闭、打开、调整大小和移动窗口等操作，以及在窗口之间切换焦点来实现。Ubuntu 操作系统和 Windows 操作系统可以认为是很好的示例，它们为用户提供了 GUI，以便与各种程序进行交互。

# 命令行界面

用户可以使用 CLI 或命令行界面访问 shell。Linux 中提供了一种名为终端（terminal）的特殊类型程序，用于输入诸如 `ls`、`cat` 等其他人类命令，并对其进一步执行。最终结果将直接显示在终端上，供用户查看。假设你执行了 `ls` 命令并带有 `-l` 选项。这将以长列表的形式列出当前工作目录下的所有可用文件。

# Linux 中的 Shell 类型

在 Linux 系统中，有多种类型的 shell 可供用户：

- `BASH`: 也称为 Bourne Again Shell，广泛用于基于 Linux 的系统。它被作为 Linux 系统登录的默认 shell。如果你需要，也可以在 Windows 操作系统中安装它。
- `CSH`: 也称为 C shell，它使用 C shell 的语法，其用法与 C 编程语言大同。
- `KSH`: 也称为 Korn shell，它是 POSIX Shell 标准的基础。

每种 shell 的功能方式相同，但它们都能够理解各种命令并提供各种内置函数。

# Shell 脚本

通常情况下，shell 本质上是交互性的，这意味着它们可以接受用户的命令作为输入并执行它们。然而，可能会出现你需要或想要以例行方式执行大量命令的情况，这样你每次都需要在终端内输入所有命令。由于 shell 也可以以文件的形式接受命令，你可以将命令写在一个文件中，然后在 shell 中执行它们，以避免重复任务。所有这些文件被称为 Shell 程序（Shell Programs）或 Shell 脚本（Shell Scripts）。Shell 脚本的结构与 MS-DOS 中的批文件相似。每个 shell 脚本都以 `.sh` 文件扩展名保存，例如 `yourscript.sh`。

shell 脚本也像所有其他语言一样具有语法。如果你已经熟悉 C、C++ 或 Python 等任何编程语言，那么开始编写 shell 脚本对你来说更容易。shell 脚本包含：

- Shell 关键字：包括 `else`、`if`、`break` 等
- Shell 命令：包括 `ls`、`cd`、`echo`、`touch`、`pwd` 等
- 控制流：包括 `if..then..else`、`shell` 和 `case` 循环等

你可以使用 shell 脚本来避免重复性工作，从而选择自动化。它有助于监控系统，并允许为 shell 添加各种新功能。

# Linux 开发环境

Linux 正在成为开发者的编程天堂。这主要是因为 Linux 的开源特性以及它是一个完全免费的操作系统。Turbo 编译器是旧形式的编译器，用于编译程序。在 Linux 上也可以完成相同的工作，创建一个新的编程环境。让我们来看看如何使用 C 语言来编写、编译和运行基于 C 的程序。

如果你的系统中还没有如 Ubuntu 之类的 Linux 发行版，可以在系统上安装任何虚拟机，例如 VirtualBox。这是由 Oracle 设计的产品，允许用户在计算机系统上运行任何形式的虚拟机。这意味着你可以轻松地在 Apple 或 Windows 系统上运行 Linux。

下载好虚拟机后，将其安装在计算机上，然后重启系统，最后创建一个全新的虚拟机。创建虚拟机步骤：

- 点击“新建”（New）按钮创建新虚拟机。
- 为你的虚拟机提供适当的名称。
- 将操作系统选择为 Linux 和 Ubuntu 64 bit。
- 点击“下一步”（Next）。
- 点击“创建虚拟硬盘”（Create Virtual Hard Disk）。
- 点击“创建”（Create）。
- 打开终端窗口。前往“应用程序”（Applications）下的“辅助工具”（Accessories），然后点击“终端”（Terminal）。这将打开一个新的终端窗口。
- 为了在系统中运行 C 程序，你需要安装必要的包。要实现此目标，你需要在终端窗口中输入命令：

`sudo apt-get install build-essential`

现在它会要求输入管理员密码。在你正确输入密码后，将开始安装过程。为了安装这些包，你需要连接互联网。完成需要一些时间，取决于网速。
- 现在你可以编写并运行你所需的程序了。

# 在 Linux 中编写 C 程序

在 Linux 中编写 C 程序，请遵循以下步骤：

- 打开任何文本编辑器，如 `gedit`。你可以通过输入命令 `gedit prog.c` 来实现。
- 编写程序。例如：`#include<stdio.h>int main() { printf("Hello"); return 0;}`
- 然后以 `.c` 扩展名保存程序。
- 然后你需要编译程序。
- 然后你可以运行或执行程序。
- 在终端窗口输入以下命令来打开编辑器。

```
gedit prog.c
```

- 编辑器打开后，你现在可以编写程序了。
- 程序编写完成后，保存并关闭编辑器。
- 你可以编译程序：

```
gcc prog.c -o prog
```

- 如果你的程序没有错误，屏幕上不会显示任何内容。如果程序中有任何形式的错误，将会显示出来。你还需要再次打开编辑器，然后重复步骤消除错误并保存。
- 运行程序输入此命令：

```
./prog
```

- 程序运行后，你可以在另一个终端窗口看到程序输出。

C 可以被视为一种过程性的编程语言。它由 Dennis Ritchie 在 1969 年至 1973 年间开发。

最初，它的开发是为了用于编写完整的操作系统而设计的编程语言。C++ 语言的主要特点具有对系统内存的底层访问、非常简单易用的关键字集以及整洁的风格。这些特性使得 C++ 语言非常适合各种系统编程，如操作系统甚至编译器的开发。第一步包括安装一些开发工具以及如 GCC、GNU、C++ 编译器，用于编译程序和在 Linux 中执行整体代码。C 和 C++ 大为相似，为了理解 C++，让我们先看看 C。

# C 程序示例

现在让我们考虑一个非常简单的 C 程序文件，命名为 `Sort.c`：

```c
int main( void )
{
    printf("Hello! Sort\n");
}
```

```c
return 0;
}
```

编译这个简单的程序，你可以使用：

```
cc filename.c -o executable_file_name
```

在这条命令中，`filename.c` 是 C 程序文件，`-o` 选项用于显示代码中的错误。如果代码中没有错误，它将生成一个名为 `executable_file_name` 的可执行文件。

```
cc Sort.c -o sortoutput
```

在这里，`sortoutput` 是一个本质上是可执行的文件，并且它正在被生成。因此，你可以这样执行它：

```
./sortoutput
```

# C++ 编程

C++ 是一种为了通用编程而开发的编程语言，如今被广泛用于竞争性编程。

它具有面向对象、命令式和泛型编程的特征。

你可以在 Linux、Windows、Mac、Unix 等许多平台上运行 C++。在我们开始使用 C++ 编程之前，你只需要：

```
g++ sort.cpp -o sortoutput
```

在此条命令中，`sortoutput` 是正在生成的生成执行格式文件。因此，你可以如下所示执行它：

```bash
./sortoutput
```

如果你正在使用基于 Linux 的系统，如 CentOS、Red Hat、Fedora 或其他，你可以以 root 身份输入此命令安装 C++ 编译器：

```bash
yum install -y gcc-c++*
```

为了验证 GCC 编译器是否已正确安装在系统中：

```bash
rpm -qa | grep -i c++
```

你也可以使用 `which` 命令：

```
which c++
```

- 从终端窗口，使用 `vim` 命令打开一个新文件进行编辑：
`vim hello.cc`
- 在 `vim` 编辑器中，你现在可以输入你的 C++ 程序或代码。
- 完成后，保存并退出文件。
- 为了编译这个新的 C++ 程序，你需要在终端中输入此命令：

```bash
c++ hello.cc
```

如果编译过程运行过程中没有任何错误，屏幕上将不会打印任何形式的输出。
- 当前目录下将创建一个以 `a.out` 为默认名称的可执行文件。
- 要运行这个程序，你可以像执行任何 Linux 可执行文件一样，执行已生成的可执行文件。

在不指定任何选项的情况下编译 C++ 程序将生成名为 `a.out` 的可执行文件。如果你想为你选择的可执行文件指定特定的名称，有两种方法：第一，是在创建后重命名默认的 `a.out`；第二是在编译时使用 `-o` 选项指定可执行文件的文件名。

```bash
c++ hello.cc -o /opt/hello.run
```
