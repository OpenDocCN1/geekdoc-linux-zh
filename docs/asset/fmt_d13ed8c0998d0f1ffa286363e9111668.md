# 02 获取 pygame 代码

接下来，我们需要从源下载 Pygame 的代码。在终端中，你可以这样做：

```bash
$ git clone https://github.com/pygame/pygame
```

这将下载 `pygame` 文件夹。进入 `pygame` 文件夹我们可以继续构建。

# 03 构建 pygame 模块

要安装它，我们需要分两个步骤进行。首先，我们需要使用终端准备代码：

```bash
$ python setup.py build
```

完成后，你实际上可以使用以下命令安装它：

```bash
$ python setup.py install
```

这不会花费长时间。

# 04 以其他方式安装
