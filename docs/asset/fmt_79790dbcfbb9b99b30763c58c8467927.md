# 20 在 Python 解释器终端执行函数

你可以使用 `'help()'` 在 Python 解释器终端执行函数。

示例：

```python
def sum(x):
    print(x*4)
def message(x):
    print('Executing Now')
import atexit
atexit.register(sum)
atexit.register(message)
```

示例：

```
Executing: 9
```

## 整数转换为二进制

使用 `bin()` 和 `hex()` 将整数转换为二进制和十六进制格式。

示例：

```python
>>> bin(24)
0b111000
>>> hex(24)
0x18
>>> oct(24)
0o30
```

## 25 禁用垃圾收集

当你需要在运行时启用或禁用垃圾器时，可以使用 `'gc'` 模块来启用或禁用垃圾收集。

示例：

```python
import gc
>>> gc.disable()
# <内置函数>
>>> gc.enable()
```
