# NURBS 信息

`NURBS` 代表非均匀比例 B 样条（`Non-Uniform Rational B-Spline`）。它是一种特别适用于创建平滑曲线的对象类型。你可以在附录 C 中找到更多关于 `NURBS` 的信息。

现在，让我们应用来自 `Photoshop` 的位图：

1. 点击 `Modify`（修改）选项卡，然后从修改器列表（`Modifier List`）下拉列表中选择 `Displace`。你会在对象空间修改器（`Object-Space Modifiers`）标题下找到它。请勿使用世界空间修改器（`World-Space Modifiers`）标题下的 `Displace Mesh` 修改器。
2. 在参数面板（`Parameters rollout`）的 `image`（图像）组中，点击标记为 `None` 的 `Bitmap`（位图）。

4. 进入 `Displacement`（置换）组，将 `Strength`（强度）设置更改为 `12`。你会注意到平面开始变形，尽管它看起来完全不像图 15.34 所示那样。

# DISPLACE 修改器的 MAP 和 BITMAP 选项

你可能注意到 `Displace` 修改器参数中的 `Image` 组提供了组选项：`Bitmap`（位图）和 `Map`（映射）。虽然你使用了 `Bitmap` 选项，你也可以使用 `Map` 选项来应用位图。`Map` 选项允许你使用其他类型的映射，例如材质/映射浏览器（`Material/Map Browser`）提供的程序化映射。你可以同时使用 `Bitmap` 和 `Map` 选项来置换网格。

现在回到 `Displace` 修改器参数，看看其他一些选项的作用：

1. 在修改器栈中选择 `Displace`。
2. 在参数的 `Displacement` 组中，点击并拖动 `Strength` 调节器到 `2~6°` 或 `30°`。`Strength` 值表示位图中黑色部分到白色部分之间的距离。
3. 勾选 `Luminancer`（亮度）复选框，如果确保确保 `Center`（中心）值已设置为 `0.5`。网格下凹了。`Luminancer` 告诉位图中哪些深浅的灰色会将网格顶点移动到 `Displace` 坐标轴器（`gizmo`）上方或下方。`gizmo` 位于构造网格上。
4. 滚动到 `Map` 组，将长度值改为 `95`，将 `Width` 值改为 `75`。现在表面看起来真的很像一个带有法边的真空成型塑料物体。
5. 使用 `U Tile` 调节器增加 `U Tile` 值，然后对 `V Tile` 值执行相同的操作。随着这些值的增加，平面宽度方向上的凸起数量增加。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_771_0)

你可能注意到 `Displace` 修改器参数中的 `Image` 组提供了两组选项：`Bitmap` 和 `Map`。尽管你使用了 `Bitmap` 选项，你也可以使用 `Map` 选项来应用位图。`Map` 选项允许你使用其他类型的映射，例如材质/映射浏览器提供的程序化映射。你可以同时使用 `Bitmap` 和 `Map` 选项来置换网格。

注意在 `Map` 组中，`Planar`（平面）按钮被选中了。这是 `gizmo` 设置。事实上，由于 `Displace` 与映射协同工作，`gizmo` 类似于 `UVW` 设置。

当你完成对象的操作后，可以使用右键菜单折叠修改栈（`collapse`）。
