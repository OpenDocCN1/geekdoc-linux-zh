
`local` 用于定义局部变量。命名的变量将使用等号（`=`）被定义并赋予初始值。`local` 也用于函数内部，将变量的作用范围限制在该函数及其子函数中。在没有参数的情况下，`local` 显示局部变量列表。`local` 命令只能在函数内部使用。它不能直接在 shell 脚本或交互式 shell 中。除非在函数外使用或提供了非法名称，否则命令返回 0。

## notify

`notify job-number`

在 Linux 中执行任何命令后，系统都会告诉你当前运行的后台作业（如果有的话）哪些完成了。系统不会中断任何操作（如编辑）来通知你已完成的作业。如果你希望在特定作业结束时立即收到通知，无论你正在系统上做什么，都可以使用 `notify` 命令指示系统通知你。`notify` 命令接受作业号作为参数。当作业完成时，系统将中断你正在进行的操作并通知你作业已结束。接接的示例告诉系统，在 2 号作业完成后通知用户。

```
$ notify %2
```

## popd

## select

```
select variable in list-of-items
do
  commands
done
```

`select` 命令用于为用户显示一个简单的编号项目菜单以供其选择。跟在 `in` 之后的项目列表显示在标准错误输出中，每个项目前面都有一个数字。如果省略了 `in`，则使用位置参数的值。显示项目后，会提示用户输入一个数字。将显示 `PS3` 提示符，提示用户从标准输入读取内容，并依次与每个项目对应的数字进行匹配。如果找到了对应的值，`select` 将该单词赋值给变量。如果用户输入空行，则重新显示菜单。如果读取到 `EOF`，命令终止。`select` 的退出状态为最后一个执行的命令的退出状态，如果没有执行任何命令，则为 0。

```
select mychoice in Sizes Information Cfiles
do
  case $mychoice in
    Sizes)
      ls -s
      ;;
    Information)
      ls -l
      ;;
    Cfiles)
      ls *.c
  esac
done
```

## set

`set [--abefhkmnptuvxdchP] [-o option name][arguments ...]`

你使用 `set` 命令设置各种 shell 选项或列出 shell 变量。单个选项设置通用功能。可以使用 `+o` 后跟选项名称开启特定功能。使用 `-o` 和选项名称关闭它们。除非另有说明，否则选项默认是关闭的。在未指定选项的情况下，`set` 命令将列出所有定义的 shell 变量。除非遇到非法选项，否则 `set` 总是真的。

你也可以调用 `BASH` shell 时列出这些选项。当前选项集列在 `$-` 中。在处理选项参数后，任何剩余的参数将被赋值为位置参数 `$1`, `$2`, ..., `$n`。
