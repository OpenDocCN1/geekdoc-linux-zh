
## 变量与哨兵节点

变量指向第一个节点的迭代器开始和结束。双向链表通常采用这种特殊节点（称为哨兵 `sentinel node`）实现。这种方法简化链结构并提升效率。迭代器其实指向节点的指针，而 `list.begin()` 和 `list.end()` 返回的值：

- node at `.begin`:
  `ptr=0x000034a0` `_Next=0x0028fe90` `x=3` `y=4`

- node at `.end`:
  `ptr=0x00003498` `_Next=0x000034b0` `_Prev=0x000034a0` `x=5` `y=6`

事实上，最后一个节点的 `Next` 指向第一个节点，`Prev` 指向最后一个元素。因此很容易想到循环表。可以利用第一个指针（实例）找到最后一个节点，不必遍历整个链。利用这种结构，我们还可以插入其他节点。运算符 `++` 和 `--` 就是迭代器的 `[当前节点->prev]` 或 `[当前节点->next]` 值。反向迭代器（`reverse iterators`）的作用与其相似，只是相反。运算符 `*` 用于返回节点。

在链表插入和删除节点时，我们只需要分配（或释放）节点的内存，然后更新相关的指针，即可保证表的有效性。在删除节点之后，相邻的迭代器可能会指向无效节点，此时迭代器就会失效。指向无效节点的迭代器又叫 `dangling pointer`。

在 GCC 4.8 版本编译 `std::list` 实例，它存储了总数。这意味着内置函数 `size()` 的运行缓慢，因为它必须遍历完整表才能返回个数。因此，那些与节点数有关的所有函数 `n` 的时间开销接近底层。
