# 第 1 章：GLib

## 1.1 引言

G 是无处不在的。为了开始使用 GLib 及其所有类型，请在源代码中包含 glib.h 头文件：

```
#include <glib.h>
```

在后续章节中，可以使用 GLib。本章详细介绍了 GLib 重要的函数和数据结构。

## 1.2 GLib 命名约定

与其他库一样，GLib 为了一致性和可读性有命名规则：

- 函数名全小写，部分之间用下划线连接：`g_timer_new()`, `g_list_append()`。此外，所有函数以 `g_` 开头。
- 类型名不包含下划线，且大写字母开头：`GList`。
- 如果函数操作特定类型，其前缀为 G。
