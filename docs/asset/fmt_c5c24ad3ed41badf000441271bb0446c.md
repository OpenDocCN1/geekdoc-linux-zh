- `dial-in`: 拨入：通常这些必须显式开启或关闭，当有数据包发送时可以使用 dial 拨通 `SLIP` 或 `PPP` 链路，空闲时关闭链路。`dial` 通过在伪设备上设置虚拟链接并设置指向结果接口的路由来运行。这被称为代理，`dial` 监控代理以确定是否建立真实的通信链路。当真实链路从代理路由到真实链路时，它需要关闭。如果链路意外中断，`dial` 将重新建立链路。控制这些操作的规则在运行时启动文件中可以广泛配置。你使用的 `dial` 使用接口（在最近内核内核可用）或 `SLIP` 来提供代理接口。

- `Dialog`: 一种实用，允许你在 `TTY`（文本模式）中显示对话框（包含问题或消息）。在 `shell` 脚本中调用 `dialog`。实现了以下对话框：是/否、菜单、输入、消息、文本、信息、复选列表、单选列表和进度条。如果你想创建 `TTY` 对话框，请安装 `dialog`。来自 Redhat 8.0 `RPM`
http://www.tdp.org/LDP/Linux–Dictionary/html/index.html

- `Dialog`: 从 `shell` 脚本显示友好的对话框。此应用程序提供了从 `shell` 脚本显示不同类型对话框的方法。这允许脚本开发者以更友好的方式与用户交互。你可以使用以下类型的框：
  - yes/no：带有 Yes 和 No 按钮的典型样式框
  - scrolling list：带有单条目输入的菜单选择
  - Query box：带有文本字段的查询框
  - message：类似于是/否框，但只有一个 OK 按钮
