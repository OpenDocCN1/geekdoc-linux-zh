
等待子进程完成并返回一个包含其进程 ID 和退出状态的元组。退出状态是一个 16 位数，其低字节是杀死进程的信号号，高字节是退出状态（如果信号号为 0）。低字节的高字节表示产生了核心文件（core file）。如果提供了 `pid`，则指定要等待的进程。如果省略，`wait()` 返回任何退出的子进程（UNIX）。

```
waitpid(pid, options)
```

根据给定的进程 ID `pid` 等待子进程状态的变化，并返回一个包含其 `pid` 和退出状态码的元组，编码方式类似于 `wait()`。`options` 应设置为 0 以进行正常操作，或设置为 `WOHANG` 以在没有没有可用的子进程时避免挂起。此函数也可用于收集因某些原因停止执行的子进程的信息。将 `options` 设置为 `CONTINUED` 可以在子进程被作业控制停止后恢复运行时从其收集信息。将 `options` 设置为 `WTRACED` 可以从已停止但未报告状态信息的子进程处收集信息。

```
wait3(options)
```

与 `waitpid()` 相同，但该函数等待任何子进程的状态变化。返回一个 3 元元组 (code, status, rusage)，其中 `pid` 是子进程 ID，`status` 是退出状态码，`rusage` 包含 `resource.getrusage()` 返回的资源使用信息。`options` 参数的含义与 `wait1()` 相同。

```
wait4(pid, options)
```

与 `waitpid()` 相同，但结果是 `wait3()` 返回的相同元组。

以下函数接收 `waitpid()`、`wait3()` 或 `wait4()` 返回的状态码，并用于检查进程状态（UNIX）。

```
WCOREDUMP(status)
```

如果进程转储了核心内存，则返回 True。

```
WIFEXITED(status)
```

如果进程使用 `exit()` 系统调用退出，则返回 True。

```
WEXITSTATUS(status)
```

如果 `WIFEXITED(status)` 为真，则返回传递给 `exit()` 系统调用的整数参数。否则，返回值没有意义。

### WIFCONTINUED(status)

如果进程已从作业控制停止中恢复，则返回 True。

### WIFSIGNALED(status)

如果进程由于信号退出，则返回 True。

### WIFSTOPPED(status)

如果进程已停止，则返回 True。

### WSTOPSIG(status)

返回导致进程停止的信号。

### WTERMSIG(status)

返回导致进程退出的信号。

## 系统配置

这些函数用于获取系统配置：

### constr(name)

返回一个字符串值的系统配置。`name` 是指定的名称。如果配置未知，则返回 -1。

### getloadavg()

返回一个包含过去 1、5、15 分钟运行队列平均数量的 3 元组。

### sysconf(name)

返回整数值的系统配置。`name` 是指定的名称。POSIX 定义的参数在大多数系统中均可用：

| 参数 |  |
| :--- | :--- |
| SC_ARG_MAX | 用于 exec() 的参数的最大长度。 |
| SC_CHILD_MAX | 每个用户的最大进程数。 |
| SC_CLK_TCK | 每秒时钟周期。 |
| SC_NROUPS_MAX | 最大组 ID。 |
| SC_STREAM_MAX | 进程可以打开的流数。 |
| SC_TZNAME_MAX | 时区字节数。 |
| SC_OPEN_MAX | 进程可以打开的文件数。 |
| SC_JOB_CONTROL | 系统支持作业控制。 |
| SC_SAVED_IDS | 表示进程是否有保存 ID 和保存组 ID。 |

### random(n)

返回一个包含系统生成的 n 个随机字节的字符串（例如 UNIX 上的 `/dev/random`）。返回的字节适用于密码学。

## 异常

os 模块定义了一个异常来指示错误。

```
error
```

当函数返回系统错误时抛出的异常。这与内置的 `OSError` 相同。异常带有两个值：`errno` 和 `strerr`。第一个包含 errno 模块描述的整数错误值。后者包含字符串错误消息。对于涉及文件系统的异常，异常还包含第三个属性 `filename`，即传递给函数的路径。

# os.path

os 模块用于以移植的方式处理路径名。它被 os 模块导入。

```
abspath(path)
```

```
basename(path)
```

返回路径名的基。例如，`basename('/usr/local/python')` 返回 `'python'`。

```
commonprefix(list)
```

返回列表中所有字符串的前缀的最长字符串。如果列表为空，则返回空字符串。

```
dirname(path)
```

返回路径名的目录名。例如，`dirname('/usr/local/python')` 返回 `'/usr/local'`。

```
exists(path)
```
