## pcmcia-cs
`PCMCIA` 卡服务通常用于笔记本电脑，以提供扩展容量，例如增加内存。某些桌面式电脑可以接受 `PCMCIA` 卡，尽管这种情况很少见。Card for Services 是一个完整的 `PCMCIA` 软件包。它包含一组针对特定卡的客户端驱动程序，以及一个可以处理插入和拔出事件的守护进程，并根据需要卸载驱动程序。它支持 `PCMCIA` 卡的热插拔，因此可以随时插入和拔出。此软件包所需的内核模块包含在 `pcmcia-modules-<kernel version>` 软件包中，其中 `<kernel version>` 是编译这些模块的内核版本。网络适配器需要 `wireless-tools` 软件包。2.4（及以后）内核使用 PCI (`Cardbus`) 设备需要 `hotplug` 软件包。来自 Debian 3.0r APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pcmcia-modules-2.2.20
用于 Linux 的 `PCMCIA` 模块（内核 2.2.20）。此软件包包含了 `PCMCIA` 卡服务接口的可加载内核模块集。它们已编译为与 `kernel-image-2.2.20` 软件包中的 2.2.20-5 版本的内核兼容。如果你有自己的内核，可能需要使用 Debian 源文件重新编译 `PCMCIA` 模块。使用这些 `PCMCIA` 模块需要 `pcmcia-cs` 软件包。来自 Debian 3.0r APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html。
