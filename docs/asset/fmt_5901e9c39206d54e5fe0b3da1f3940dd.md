# 词汇表 1067

## URI
通用资源标识符（Universal Resource Identifier）。名称和地址的通用集合。常见的 URI 类型是 `URLs`。

## URL
统一（通用）资源定位符（Uniform Resource Locator）。指定互联网上对象（通常是网页）位置的标准方法。`URLs` 是 `URIs` 的子集。

## usage message（用法说明）
当你错误地调用命令时显示的消息。

## User Datagram Protocol
参见 UDP。

## User ID
参见 UID。

## user interface
用户界面参见 1042。

## user mode
用户模式系统在执行工作时的状态标识，例如运行程序（但不包括系统调用）。与系统模式（system mode，第 1064 页）对比。

## username
在 `login:` 提示处输入的名称。他人使用你的用户名向你发送邮件或联系你。每个用户名都有对应的用户 ID。用户名和用户 ID 都存储在 `passwd` 数据库中。

## userspace
用户空间应用程序所在的内存部分。运行用户空间的代码无法直接访问硬件，无法访问分配给其他应用程序的内存。也称为 `island`。参见 KernelAnalysis-HOWTO。

## UTC
协调时（Coordinated Universal Time）。UTC 等同于经午线（0 度）的平均太阳时。也称为 Zulu（Z 代表经度）和 GMT（格林尼治标准时间）。

## UTF-8
一种允许使用 8 位字节序列表示 `Unicode`（第 1066 页）字符的编码。

## utility
工具 Linux 标准部分的程序。你通常通过在 shell 提示符输入命令或在 shell 脚本中调用工具。工具通常被称为命令。与 `builtin (command)`（第 1027 页）对比。

## UUID
全局唯一标识符（Universally Unique Identifier）。用于唯一标识互联网对象的 128 位数字。在 Linux 系统上用于标识 `ext2` 或 `ext3` 分区。

## variable
变量和一个关联的值。shell 允许你创建变量并在脚本中使用。此外，它在被调用时会继承几个变量，并

## viewport
视口。同 workspace（第 1069 页）。

## virtual console
虚拟控制台。可以在系统中查看的其他控制台或显示器，或物理控制台。更多信息见第 136 页。

## virus
病毒。一种破解（第 1031 页）程序，它搜索其他程序并通过在其中嵌入自身的副本来“感染”它们，使其变成特木马（第 1065 页）。当这些程序执行时，嵌入的病毒也会随之执行，在用户不知情的情况下传播“感染”。类比生物病毒，

## VLAN
虚拟局域网（Virtual LAN）。它是两个或多个节点的逻辑分组，这些节点不一定位于物理网络分段上，但共享相同的网络号。VLAN 与交换以太网相关联。

## VPN
私有网络。存在于公共网络（如互联网）上的私有网络。VPN 是公司拥有/租赁线路的廉价替代品，并使用加密（第 992 页）来确保隐私。一个优点是，你可以通过隧道（第 1066 页）将非互联网协议通过 VPN IP 流中，从而在 VPN 连接上发送，例如 AppleTalk、IPX 或 NetBIOS（第 1049 页）。

## W2K
Windows 2000 专业版或服务器版。

## W3C
世界维网联盟（www.w3.org）。

## WAN
广域网。一种连接局域网（第 1044 页）和城域网（第 1047 页）的网络，跨越较大的地理区域（通常为州或国家）。

## WAP
无线接入点。有线网络和无线网络之间的桥器或路由器。WAP 通常支持某种形式的访问控制，以防止未经的客户端连接到网络。

## Web ring
Web 网。提供单一主题或一组相关主题信息的 Web 站点集合。Web 网中的每个页面都有系列链接，让你可以在站点之间跳转。

## whitespace
空格。空格 SPACES 和/或制表符 Tabs 以及偶尔出现的换行符 NEWLINES 的统称。也称为空白。

## wide area network
见 WAN。

## widget
控件。图形用户界面的基本对象。按钮、组合框（第 1029 页）和滚动条（第 1059 页）都是控件的示例。

## wildcard
通配符。见第 1047 页的元字符。

# 词表 1069

## Wi-Fi
无线保真（Wireless Fidelity）。指代任何类型的 802.11（第 1022 页）无线网络的通用术。

## window 窗口
显示屏幕上运行或由特定程序控制的区域。

## window manager 窗口管理器
控制窗口在显示屏幕上出现方式以及你如何操作它们的程序。

## Windows share 共享
见第 1059 页的 share。

## WINS
Windows 网上命名服务（Windows Internet Naming Service）。负责将 NetBIOS 名称映射到 IP 地址的服务。WINS 与 NetBIOS 名称之间的关系，如同 DNS 与互联网域名之间的关系。

## WINS server WINS 服务器
负责处理 WINS 请求的程序。该程序在本地网络中缓存了关于本地网络上主机的名称信息，并将其解析为 IP 地址。

## wireless access point 无线接入点
一个或多个非空字符的序列，通过 TABS、SPACES 或 NEWLINES 与单词隔开。用于指代单个命令参数。在 vim 中，一个“单词”（word）类似于英语中的单词——一个由标点符号、数字、TAB、SPACE 或 NEWLINE 边界定义的一个或多个字符的字符串。

## word 单词/字
vim 在编辑时存储文本的位置。在向编辑器发出写入命令之前，Work 缓冲区中的信息不会写入磁盘。

## working directory 工作目录
你在任何时候所关联的目录。你使用的相对名称是相对于工作目录的。也称为当前目录。

## workspace 工作空间
桌面（第 1033 页）的子划分，占据整个显示器。见第 106 页。

## workstation 工作站
小型计算机，通常为办公室设计，供个人使用，通常配备位图图形显示器、键盘和鼠标。与终端（第 1064 页）的区别在于其智能性。工作站运行在 Linux 上，同时连接到运行 Linux 的终端。

## worm 蠕虫
一种在网络上传播并在过程中自我复制的程序。该词带有负面含义，因为假设只有破解者才会编写蠕虫。与病毒（第 1068 页）和特木马（第 1065 页）相比。源自 John Brunner 的小说《冲击波骑者》（The Shockwave Rider, Ballantine Books, 1990，通过 Xerox PARC）。

## WYSIWYG 所见即所得
一种图形应用程序（如文字处理器），其显示内容与其打印输出相似。

# 1070 词表

## X server X 服务器
X 服务器是 X Window 系统中运行鼠标、键盘和显示器的部分。（应用程序是客户端。）

## X terminal X 终端
为运行 X Window 系统而设计的图形终端。

## X Window System X 窗口系统
一种用于编写灵活、可移植窗口应用程序的设计和工具集，由 MIT 的研究人员和几家领先计算机制造商共同创建。

## XDMCP
X 显示管理器控制协议（X Display Manager Control Protocol）。XDMCP 允许登录服务器接受网络显示器的请求。XDMCP 内置于许多 X 终端。

## xDSL
不同类型的 DSL（第 1035 页）通过前缀识别，例如 ADSL、HSDL、DSL 和 VDSL。

## Xinerama
X.org 的扩展。Xinerama 允许窗口管理器和应用程序使用两个或多个显示器作为一个大的显示器。参见 HOWTO。

## XML
可扩展标记语言（Extensible Markup Language）。用于 Web 上结构化文档的通用格式。由 W3C（第 1068 页）开发，是 SGML 的简化版本。见 www.w3.org/XML/1999/

## XSM 会话管理器
此程序允许创建一个包含应用程序的会话。在会话运行时，你可以执行检查（保存状态）或关闭（退出会话）。当你登录时，可以加载会话，使会话中的一切保持运行。

## Z Shell
zsh。一种整合了 Bourne Again Shell（第 1026 页）、Korn Shell（第 1044 页）和 TC Shell（第 1064 页）许多特性的 shell。

## Zulu time 零时
见第 107 页的 UTC。
