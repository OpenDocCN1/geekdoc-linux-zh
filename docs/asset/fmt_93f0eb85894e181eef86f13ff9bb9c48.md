## PATH 变量

`PATH` 变量是 Linux 系统最重要的环境变量之一。它存储了一个由冒号分隔的目录列表，这些目录包含了可以作为 Linux shell 命令执行的可执行程序。

```bash
$ echo PATH
/home/user/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/bin:/usr/games
```

要向变量中添加目录，你需要使用冒号 (`:`)。

```bash
$ PATH=$PATH:new_directory
```

这里有一个示例：

```bash
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

$ PATH=$PATH:/home/usr/bin

$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/home/usr/bin
```

你可以看到，`PATH` 被用于赋值给 `PATH` 的新值。该变量在命令执行期间会被解析，并确保变量的原始内容被保留。当然，你也可以在赋值中使用其他变量：

```bash
$ mybin=/opt/bin
$ PATH=$PATH:$mybin
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/home/usr/bin:/opt/bin
```

### 引言

命令行是一个非常复杂的工具。每个命令都有其独特的选项，在操作 Linux 系统时，文档是关键。除了存储了大部分文档的 `/usr/share/doc/` 目录外，其他各种工具也提供了关于使用 Linux 命令的信息。本章将重点介绍访问这些文档的方法，目的是获取帮助。

在 Linux 命令行中有许多方法可以获取帮助。`man`、`help` 和 `info` 只是其中几个。对于 Linux Essentials，我们将重点关注 `man` 和 `info`，因为它们是获取帮助最常用的工具。

本章的另一个主题是定位文件。你将主要使用 `locate` 命令。

### 在命令行上获取帮助

#### 内置帮助

当带有 `--help` 参数启动时，大多数命令会显示关于其用法的简短说明。虽然并不是所有命令都提供此开关，但学习命令的参数仍然是一个很好的尝试。请注意，与本节其余部分将讨论的其他文档源相比，`--help` 提供的说明通常要简短得多。

#### 手册页 (Man Pages)

大多数命令都提供一个手册页或“man”页。这些文档通常随软件一起安装，可以通过 `man` 命令访问。将要显示的 man 页面对应的命令作为参数传递给 `man`：

```bash
$ man mkdir
```

此命令将打开 `mkdir` 命令的 man 页面。你可以使用向上和向下箭头键或空格键来浏览 man 页面。要退出 man 页面，请按 `q`。

| ARGUMENTS | 可用参数 |

## 信息页 (Info Pages)

另一个可以帮助你处理系统的工具是 `info` 页面。`info` 页通常比 man 页面更详细，并且以超文本格式化。`info` 页可以如下显示：

```bash
$ info mkdir
```

对于每个 `info` 页面，它都是树形结构。`info` 命令包含链接，可以让你在树中移动。你可以通过将光标放在 `info` 页面上的访问这些节点。类似于 man 页面，`info` 工具也有页面导航。你可以通过按 `h` 位于 `info` 页面来了解更多这些功能。

## 定位文件

### locate 命令

Linux 系统由许多目录和文件组成。Linux 有许多工具可以定位特定文件。最快的是 `locate` 命令。`locate` 在数据库中搜索，然后输出匹配给定字符串的所有名称：

```bash
$ locate note
```
/lib/udev/keymaps/zenote

/usr/bin/zipnote

/usr/share/doc/initramfs-tools/maintainer.html

/usr/share/man/man1/zipnote.1.gz
```

`locate` 命令支持通配符和正则表达式，因此搜索字符串不需要匹配整个名称。默认情况下，`locate` 的行为就像模式被星号包围，所以 `locate PATTERN` 等同于 `locate *PATTERN*`。

### find 命令

`find` 是另一个用于搜索文件的非常流行的工具。此命令与 `locate` 命令的方法不同。`find` 命令递归搜索目录，包括其子目录。`find` 在每次调用时都进行此类搜索，它不像 `locate` 那样维护数据库。与 `locate` 类似，`find` 也支持通配符和正则表达式。`find` 至少需要路径。此外，可以添加所谓的表达式来提供要显示文件的过滤标准。一个例子是 `-name` 表达式，它查找特定名称的文件：

```bash
$ cd Downloads
~/Downloads
$ find -name thesis.pdf
./thesis.pdf
~/Downloads
$ find ~ -name thesis.pdf
/home/carol/Downloads/thesis.pdf
```
