## C Shell 中的命令行替换

与 Korn shell 不同，C shell 并没有一种可以调回之前执行的命令行并使用 vi 编辑器快捷键进行修改的命令行编辑功能。相反，C shell 拥有一种命令行替换功能，它允许你通过用新字符串替换旧字符串并执行，从而仅对最后一条命令进行更改。其语法如下：

```

```

每个字符串可以是任何长度。插入符号 (`^`) 告诉历史记录在前一个命令中定位字母串 `old_string` 第一次出现的位置，将其替换为字母串 `new_string`，并执行修改后的命令。插入符号和字符串之间没有空格。

图 14-15 中的第一个示例将上一个命令中的 `z` 替换为 `s`。第二个示例结合了历史记录和命令行替换，用于调回并更改之前的命令。首先使用 `p` 来查看第 38 号命令而不执行它。然后将 `d` 替换为 `s`。
