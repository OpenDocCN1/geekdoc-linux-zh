## XML (扩展标记)

`XML` 是一种 `HTML` 格式化语言。误区：开发互联网协议时的建议建议是“在输出时保持保守，在接收时保持慷慨”。虽然在早期这种哲学促进了互操作性，但经济学家可以告诉你这种做法的长期影响。它导致了许多显著不兼容的协议实现，这些实现大多可以运行，但没有一个运行得良好。例如，`FTP` 是最老的协议之一，基本上没有完全合规的客户端或服务器，构建一个完全互操作的客户端/服务器极其困难，需要了解所有流行实现中的所有怪癖。因此，`XML` 选择了相反的方法：合规的实现应该拒弃所有非“良好格式”的输入，即使意图很明确。这不仅从长远来看避免了互操作性错误，还通过保证只有一种解释方式来提高安全性。来自 Hacking-Lexicon

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## XML (扩展标记语言)

一种广泛用于定义数据格式的系统。`XML` 提供了一个非常丰富的系统来定义文档和结构，如图像、分子数据、新闻订阅、词汇表、库存描述、房地产等。作为程序员，你可以使用 `XML` 定义一组数据（通常称为“模式”`schema`），然后你可以创建一个程序来可靠地处理任何按照规则格式化的数据。来自 Matisse

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## xml-resume-library

一组用 `XML` 编写简历的工具。`Resume Library` 支持映射、添加元数据、格式化以及个人简历。它由以下组件组成：

- 用于描述简历的 `XML` 类型定义 (`DTD`)。

- 用于将 `XML` 简历转换为以下内容的样式表：

  - 网络就绪 `HTML`

  - 打印就绪 `PDF`

  - 或纯文本

来自 Debian 3.0

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
