## 自动私用地址

如果 Windows 配置为使用 DHCP 但无法从 DHCP 服务器获取 IP 地址，计算机将通过名为“自动私用地址”（简称 APIPA）的功能自动分配私用地址。APIPA 从 169.254.x.x 范围分配私用地址，并使用特殊算法确保该地址在网络上是唯一的。一旦 DHCP 服务器可用，计算机就会请求新地址，因此 APIPA 仅在 DHCP 服务器不可用时使用
