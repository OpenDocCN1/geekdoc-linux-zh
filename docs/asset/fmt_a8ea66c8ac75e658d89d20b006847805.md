## 8.1 文件菜单

“新建”（Ctrl+N）创建一个新文件，并同时打开一个新的 KWrite 窗口以便开始输入您的文本。

“打开...”（Ctrl + O）使用此项打开现有文件。它会打开一个类似于文件管理器的对话框。左侧区域提供了多个快速导航按钮，只需点击即可列出主目录或软盘上的文件。或者，使用顶部工具栏中的输入字段，抑或使用箭头按钮浏览目录。一旦选择了目录，文件和子目录将列在对话框的右侧部分。为了加快速度，可以在“过滤器”下指定文件扩展名（例如 .txt），按文件类型缩小列表。要标记当前目录以便以后快速返回，请点击工具栏上的星号按钮为其创建书签。通过这种方式书签的任何目录随后都可以通过菜单访问，避免反复遍历整个文件系统。可以通过扳手图标访问配置菜单，以自定义对话框中项的排序和查看方式。

“保存”（Ctrl + S）以当前形式保存文档。如果您正在编辑一个新文档，程序将显示一个对话框，在其中指定文件名及其位置（目录）。

另存为... 这将打开一个对话框，在其中指定保存文档的名称和目录。该对话框与选择“文件”->“打开...”后显示的对话框基本相同。

“打印...”（Ctrl + P）这将打开一个简单的对话框，在其中定义文档的打印选项并启动打印作业。

“关闭”（Ctrl + W）关闭当前加载的文档。如果有尚未保存的更改，将弹出对话框询问是否保存。

“退出”（Ctrl + Q）退出编辑器。如果加载的文档有未保存的更改，KWrite 将显示一个对话框请求在退出前保存。

## 8.2 编辑菜单

此菜单提供了程序所有的编辑功能，例如查找和替换。

撤销/重做 使用此项撤销或重做操作。这些功能可以通过 Ctrl + Z 使用。

“剪切” 切切选中的文本。快捷键为 Ctrl + X。

“复制” 将选中文复制到剪贴板。快捷键为 Ctrl + C。

“粘贴” 从剪贴板插入文本。快捷键为 Ctrl + V。

“全选” 选择文档中的所有文本。快捷键为 Ctrl + A。

取消选择 此菜单取消当前选定的区域。快捷键为 Shift + A。

切换块选择 切换行或段落的选择。快捷键为 Ctrl + B。

切换插入 更改输入模式。默认情况下，在光标处插入文本。快捷键为 Ins。

查找... 和 替换... 将显示一个对话框，用于查找字符串或正则表达式。还可以定义搜索方向、起点和其他详细信息。要跳转到下一个匹配项，按 F3。要返回上一个匹配，按 Shift + F3。要替换搜索项，使用 Ctrl + R。

“转到行...” 要跳转到文档中的特定行，选择此项，在对话框中输入行号，然后点击确定。

## 8.3 视图菜单

通过此菜单更改文本显示的多个方面。启用或禁用编辑器的换行功能（F11）。还可以决定是否显示图标边界（F6）以查看书签。最后，菜单有一个设置文本编码的项。

## 8.4 书签菜单

在 KWrite 中，书签是对文档特定位置的引用。它可以快速导航到指定行，这对于长文档特别有用。要使用书签，首先启用图标边界（视图 -> 显示图标边界）。点击目标行的图标添加书签。之后会出现一个回夹，表示书签已设置。点击相应的回夹删除书签。

要切换书签，请按 Alt + Page down（下一个书签）和 Alt + Page up（上一个书签）。通过选择“清除书签”一次性删除所有书签。

## 8.5 工具菜单

此菜单提供了许多可以基本格式化当前文档的操作。

“高亮模式”默认设置为“普通”，但您可以根据不同的文档格式（如 HTML）和编程语言选择多种高亮模式。

“行结束符”KWrite 设置的行结束字符应根据使用和分发文档的操作环境进行设置。使用此菜单选择“UNIX”、“Windows/DOS”或“Macintosh”。

“缩进” 文本块按一定量缩进，该量在“设置 -> 配置编辑器... -> 编辑”中定义。要缩进当前文本，选择缩进或按 Ctrl + I。要取消一级缩进，选择取消缩进或按 Ctrl + Shift + I。

## 8.6 设置菜单

“显示工具栏” 启用此项以显示主要编辑功能的工具栏。

‘显示状态栏’启用此项后，KWrite 将在其窗口底部包含一个状态栏。状态栏将显示当前行号和列号、输入模式以及文档的保存状态。

‘显示路径’如果启用此项，KWrite 将窗口标题栏中显示加载文档的文件名及其完整路径（而不仅仅是文件名）。

‘配置编辑器……’这会打开一个包含 KWrite 所有可用配置选项的对话框。这包括所使用的颜色方案和字体、缩进、文本选择和自动换行的设置、快捷键和高亮选项以及其他设置。该对话框允许您定义默认视图配置并集成外部语法检查模块。

‘配置快捷键……’这会打开一个对话框，可以在其中更改现有键盘快捷键或定义自定义快捷键。

‘配置工具栏……’这会打开一个对话框，可以在其中添加和删除工具栏按钮。

## 8.7 帮助菜单

此菜单可以访问 KWrite 手册。点击‘这是什么？（或使用快捷键 Shift+F1）可以调用所有可用的上下文提示。
