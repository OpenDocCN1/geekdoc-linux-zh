`hosts` 文件是你计算机上的一个简单文本文件，将主机名映射到 `IP` 地址。它对于正确引导互联网流量至关重要，特别是在设置新域名或传输域名时，这些域名可能因为传播延迟而无法立即解析。通过编辑 `hosts` 文件，你可以跳过这些延迟，确保立即访问你的网站。该文件植根于互联网早期，为域名解析提供了一种快速解决方案，在网络地址解析过程中充当第一站或回备方案。它将控制权交到你手中，让你能够管理计算机如何访问网页。

`hosts.deny` 和 `Superhosts.deny` 是 `Linux` 用于访问控制的文件，允许你根据主机名或地址拒绝特定主机的网络服务。它与 `hosts.allow` 配合工作；如果客户端的请求不匹配 `hosts.allow` 中的任何规则，则会检查 `hosts.deny`。如果匹配，则拒绝访问；如果不匹配，则默认允许访问。该系统支持通过模式进行细致控制，包括通配符和 `IP` 地址的网/掩码对。这是一种通过显式拒绝访问不受信源来保护网络服务的有效方法，确保只有授权的用户或系统可以访问某些网络守护进程。这种方法简单而强大，为管理网络访问提供了简单性与深度结合。

## 导入自定义 UFW 规则

要导入自定义 `UFW` 规则，打开终端并执行以下命令：

- 导航到等：`cd /etc`
- 移除现有 `UFW` 配置：`sudo rm -rf ufw`
- 清除 `UFW` 安装：`sudo apt purge ufw`
- 重新安装 `UFW`：`sudo apt install ufw`
- 删除任何剩余的 `UFW` 目录：`sudo rm -rf ufw`
- 移动保存自定义 `UFW` 规则的目录，例如 `~/Downloads/UFW`。
- 将自定义 `UFW` 规则复制到等 目录：`sudo cp -r ufw /etc`
- 返回等 目录：`cd /etc`
- 更新所有权为 `root`：`sudo chown -R root ufw`
- 设置适当权限：`sudo chmod -R 755 ufw`
- 启用 `UFW`：`sudo ufw enable`
- 验证状态以确认新规则：`sudo ufw status`

此过程确保你的自定义防火墙规则有效应用以增强安全性。

## UFW 单端口规则

要配置 `UFW` 允许特定端口流量，打开终端并输入以下命令：

- `TCP` 端口：允许 80 端口：`sudo ufw allow 80/tcp`
- `UDP` 端口：允许 80 端口：`sudo ufw allow 80/udp`

这些命令将允许通过 `TCP` 和 `UDP` 的 80 端口，相应调整你的设置。

## UFW 多端口规则

要配置 `UFW` 允许多个端口流量，打开终端并输入以下命令：

- `TCP` 端口：允许 80,443：`sudo ufw allow 80,443/tcp`
- `UDP` 端口：允许 80,443：`sudo ufw allow 80,443/udp`

此步骤打开指定的 `TCP` 和 `UDP` 端口，确保你的防火墙设置适应必要的流量。

## UFW 端口范围规则

要在 `UFW` 中应用端口范围规则，在终端中启动这些命令：

- `TCP` 端口：`sudo ufw allow 1119:1120/tcp`
- `UDP` 端口：`sudo ufw allow 1119:1120/udp`

此操作允许通过指定的 `TCP` 和 `UDP` 端口范围流量，有效调整你的防火墙以满足需求。

## UFW 多端口与端口范围规则

要在 `UFW` 中设置多个端口和端口范围的规则，在终端中输入这些命令：

- `TCP` 端口：`sudo ufw allow 80,443,1119:1120/tcp`
- `UDP` 端口：`sudo ufw allow 80,443,1119:1120/udp`
- 检查 `UFW` 端口状态，使用：`sudo ufw status`

这些步骤将配置你的防火墙，允许通过指定的 `TCP` 和 `UDP` 端口及范围流量，确保你的系统网络设置正确调整。

## 删除 UFW 端口规则

要删除特定的 `UFW` 端口规则，在终端中遵循以下步骤：

首先，显示所有带编号的活动 `UFW` 规则：

```
sudo ufw status numbered
```

这将显示按顺序添加的所有规则列表。接下来，移除规则，使用：

```
sudo ufw delete 33
```

根据上一个命令提供的列表，将 33 替换为要删除的规则编号。再次列出规则以确认删除：

```
sudo ufw status numbered
```

此过程确保你可以高效地管理并验证从 `UFW` 配置中移除特定的防火墙规则。
