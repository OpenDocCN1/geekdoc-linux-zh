数据库列表本身并不重要，只要 Snort 数据库存在即可。表列表必须准确。如果缺少任何一个表，Snort 在运行时将会生成错误。

- 10. 安装 `php-gd`，它用于在 BASE 中生成图表。在 Fedora Core 5 上，你只需输入 `yum install php-gd`。

- 11. 安装 `ADODB`，这是一个用于 PHP 的数据库抽象库。在 Fedora 上，你只需输入 `yum install php-adodb`。

- 12. 现在是配置 BASE 本身了。编辑 `/usr/share/base-php4/base_conf.conf` 文件，确保以下行配置了适用于你配置的路径和设置。

```
$BASE_path = '/base';
$DBlib_path = '/usr/share/odbc/';
$DBtype = 'mysql';
$alert_dbname = 'snort';
$alert_host = 'localhost';
$alert_port = '';
$alert_user = 'snort';
$alert_password = 'snortpass'
```

- 15. 点击 `Main Page` 链接。这应该带你进入图 5.5 所示的 BASE 主界面。

尽管此窗口可能看起来不太华丽，但你可以发现其中丰富的信息。例如，通过点击 `Today's` 告警右侧，你可以获得唯一告警的排序列表、所有告警的列表，或者按源 IP 地址或目的 IP 地址排序的列表。这些功能可以让你快速查看特定的告警，而无需通过菜单导航。
