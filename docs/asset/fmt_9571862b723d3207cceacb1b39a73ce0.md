## ZSH-Shell 配置

Z shell 有多种初始化文件、许多配置变量以及各种 shell 选项。初始化文件与 BASH 和 TCSH shell 中的文件相似，其中一个被称为 `.zhenv`。shell 配置变量也与 BASH 和 TCSH shell 中的非常相似。Z shell 拥有一系列广泛的选项来配置你 shell 的许多方面。

## ZSH 初始化文件

系统首先读取系统 `/etc/zshenv` Z-shell 初始化文件中的命令（带有 `-f` 或 `NO_RCS` 选项时将跳过所有其他初始化文件）。然后读取用户的 `.zhenv` 文件。此文件和其他用户初始化文件（见下列表）可以位于用户的家目录，也可以分配给 `ZDOTDIR` 的目录。如果启动的 shell 是登录 shell，则读取 `/etc/zprofile` 文件，然后是用户的 `.profile` 文件。如果该 shell 还是交互式的，则会读取 `/etc/zshrc` 文件以及用户的 `.zshrc` 文件。如果该 shell 随后是登录 shell，则读取 `/etc/zlogin` 和用户的 `.zlogin` 文件。

```
$ZDOTDIR/.zshenv
$ZDOTDIR/.zprofile
$ZDOTDIR/.zshrc
$ZDOTDIR/.zlogin
$ZDOTDIR/.zlogout
/tmp/zsh*
/etc/zshenv
/etc/zprofile
/etc/zshrc
/etc/zlogin
```
