
| `timeout(delay)` | 类似于 `break`（以及 `halfdelay`）模式，但带有超时值 |
| `typeahead()` | 启用/禁用刷新时的跟进 |

```c
while (ch=getch()) != '\n'
```

`while` 循环继续执行 `keypad`，但在输入换行符（按下 Enter）时停止。

```c
keypad(editor,TRUE);
ch = wget(editor);
```

上述，`keypad()` 函数应用于窗口 `editor`，意味着可以读取特殊键。这些键随后使用 `wget()` 函数读取，并与字母数字键一起存储在变量 `ch` 中。

## 示例程序

```c
#include <ncurses.h>

int main(void);
{
  int key;
  initscr();
  noecho(); /* 关闭输入回声 */
  addstr("Type your name: ");
  while((key=getch()) != '\n') {
    switch (key) {
      case 'a':
        addch('A');
        break;
      case 'e':
        addch('E');
        break;
      case 'i':
        addch('I');
        break;
      case 'o':
        addch('O');
        break;
      case 'u':
        addch('U');
        break;
      default:
        addch(key);
        break;
    }
    refresh();
  }
  getch();
  endwin();
  return 0;
}
```
