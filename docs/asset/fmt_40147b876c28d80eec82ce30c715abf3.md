## sg-utils

用于处理 SCSI 设备的工具。此包包含许多操作 `sg`（版本 2）设备驱动的程序，并在较小程度上操作 2.0.x 内核中的版本 1 驱动；如果你正在使用 2.4，请安装 `sg3-utils` 包。该包包含：

- `isize` - 给 iso9660 文件系统中的字节数
- `scsi_query` - 与 `sg_inq` 相同，仅用于 `SCSI_IOCTL_COMMAND`
- `sg_dd` - 适用于 scsi 接口的 `dd` 变体
- `sg_debug` - 所有打开的 scsi 描述符的调试信息
- `sg` - 用于测试 SCSI INQUIRY 命令的工具
- `sg_map` - 显示 SCSI 设备与 sg 设备之间的映射
- `sg_rbuf` - 测试 SCSI 速度
- `sg_readcap` - 测试 READ CAPACITY 命令的输出
- `sg_command`
- `sg_run_ex` - 一个测试 sg 驱动版本的示例程序
- `sg_scan` - 在标准输出显示 SCSI 总线
- `sg_start` - 启动（或停止）磁盘
- `sg_test_rbuf` - 测试 SCSI 主机适配器
- `sg_turs` - 在给定设备上执行 TEST READY 命令
- `sg_whoami` - 显示给定设备的信息
- `sginfo` - 对 scsiinfo 程序到用户设备的重新报告
- `sg_dd` - `sg_dd`，仅多线程版本。它还包含了 `sg_simple1` 和 `sg_simple2`，它们演示了对 SCSI INQUERY 和 TEST READY 命令的调用。它们仅区别在于错误处理：`sg_simple` 使用 `sg_err[h]` 进行错误处理，而 `sg_simple2` 则进行自己的原始检查。来自 Debian 3.0r4 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## sgb

斯坦福图基础 Stanford GraphBase：组合数据和算法。为研究组合算法和数据结构的研究人员提供的高度可移植的程序和数据集合。这些程序本身作为文学化编程的示例非常有趣。因此，斯坦福图基础也可以被视为一组大约 30 篇供程序员阅读和享受的文章，无论他们是否正在进行研究。这些程序是用 CWEB 编写的，这是 TeX 和 C 的优点，任何知道这些语言的人都可以轻松使用，任何熟悉 C 基础知识的人都可以轻松阅读。此包仅包含库和演示程序；关于可读的源代码（它也构成了文档），请参见 Debian 3.0r 的 `sgb-doc` 包 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
