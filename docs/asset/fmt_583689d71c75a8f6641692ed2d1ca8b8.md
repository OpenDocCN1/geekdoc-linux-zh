## `NET HELP`

`NET HELP` - 使用此命令获取任何 `NET` 命令的帮助。

一个常用选项如下：

`NET HELP command \| more` - 这提供有关您指定的命令的信息。

以下示例展示了发出 `NET HELP` 命令以获取可用帮助的命令列表：

```
C:\ NET HELP
此命令的语法为：
NET HELP_command
或者
NET command /HELP
可用命令如下：
NET ACCOUNTS      NET HELP          NET SHARE
NET COMPUTER      NET HELPMSG       NET START
NET CONFIG        NET LOCALGROUP    NET STATISTICS
NET CONFIG SERVER NET NAME          NET STOP
NET CONFIG WORKSTATION NET PAUSE    NET TIME
NET CONTINUE      NET PRINT         NET USE
NET FILE          NET SEND          NET USER
NET GROUP         NET SESSION       NET VIEW
NET HELP SERVICES 列出您可以启动的网络服务。
NET HELP SYNTAX 解释如何阅读 NET HELP 语法行。
NET HELP command \| MORE 一次显示一屏帮助。
```

以下示例展示了发出 `NET HELP` 命令以获取有关 `NET GROUP` 命令的信息：

```
C:\ NET HELP NET GROUP
此命令的语法为：
NET GROUP  [groupname [[/COMMENT:"text"]] [/DOMAIN]
          groupname [/ADD [[/COMMENT:"text"]] | [/DELETE]] [/DOMAIN]
          groupname username [...] [/ADD | /DELETE] [/DOMAIN]
NET GROUP 在服务器上添加、显示或修改全局组。
如果没有参数，它将显示服务器上的组名。
```

**参数：**

- `groupname`：是添加、扩展或删除的组的名称。仅提供一个组名以查看组中的用户列表。
- `/COMMENT:"text"`：为新组或现有组添加注释。注释最多可以包含 48 个字符。用引号将文本括起来。
- `/DOMAIN`：在当前域的主域控制器上执行操作。否则，操作将在本地计算机上执行。此参数仅适用于属于 Windows Server 域的 Windows 工作站计算机。默认情况下，Windows Server 计算机在主域控制器上执行操作。
- `username[...]`：列出要添加到组中或从组中移除的一个或多个用户名。用空格分隔多个用户名条目。
- `/ADD`：添加组，或将用户名添加到组中。
- `/DELETE`：删除组，或将用户名从组中移除。

`NET HELP command | MORE` 一次显示一屏帮助。

## `NET LOCALGROUP`

`NET LOCALGROUP` - 该命令显示并允许您在计算机上操作组。如果不指定任何选项，此命令将列出组。

以下是 `NET LOCALGROUP` 命令的摘要。

```
C:\> NET LOCALGROUP /?

NET LOCALGROUP [groupname [[/COMMENT:"text"]] [DOMAIN]
              groupname [/ADD [][/COMMENT:"text"] | [/DELETE)] [(/DOMAIN]
              groupname name [...] [/ADD | /DELETE] [][/DOMAIN]
```

以下是一些常用选项：

- `/ADD` - 将组添加到域或将用户名添加到组。
- `/DELETE` - 从域中删除组或从组中删除用户名。
- `groupname` - 指定操作的 `groupname`。如果没有选项，将显示属于本地组的用户。您还可以将 `ADD` 或 `DELETE` 选项与 `groupname` 一起使用，以指定要添加到组中的用户名。
- `/COMMENT:"text"` - 将此注释添加到 `groupname`。
- `/DOMAIN` - 操作将在主域控制器上执行。如果不使用此选项，操作将在本地计算机上进行。这是 Windows 服务器系统的默认设置。
- `name` - 这是要添加或从组中移除的用户名或组名。可以指定任意数量。

## `NET NAME`

`NET NAME` - 此命令用于向计算机添加或删除消息名称。请注意不要将 `NET NAME` 与用于在系统中添加或删除用户账户的 `NET USER` 混淆。

以下是 `NET NAME` 命令的摘要。

```
C:\ NET NAME /?
NET NAME [name [/ADD | DELETE]]
```

常用选项如下：

| 选项 | 说明 |
| --- | --- |
| `name` | 要添加或删除的名称。 |
| `/ADD` | 向计算机添加名称。 |
| `/DELETE` | 从计算机删除名称。 |
