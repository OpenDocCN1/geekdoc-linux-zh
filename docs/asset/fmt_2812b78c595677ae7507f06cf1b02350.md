
# wall [file]

## 描述

`wall` 将文件内容（或在未指定文件时，默认为标准输入）显示在所有当前登录用户的终端上。
只有超级用户可以向那些选择了拒绝消息或正在使用自动拒绝消息程序的用户的终端写入内容。

## 参见

`mesg(1)`, `talk(1)`, `write(1)`, `shutdown(8)`

## 历史

`wall` 命令出现于 AT&T v7。

Linux 0.99, 1999年3月8日
