## 主目录 FTP 服务

从主目录工作有时会丢失文件。为了解决这个问题，请在 Red Hat Linux 上安装匿名 FTP 服务。将任何供下载的文件放在 `public` 目录下。使用 `wu-ftp` 来管理特权用户的访问。通过这种设置，你可以支持客户在世界任何地方快速下载文件。如果你没有连接互联网，可以设置你的机器允许客户使用 FTP 下载文件。

## 配置 `wu-ftpd`
