# logger — 向系统日志添加记录

### 概要 (Synopsis)

`/usr/bin/logger [-i][-f file] [-p priority] [-t tag][message]...`

### 描述 (Description)

`logger` 命令提供了一种从命令行向系统日志添加单行记录的方法。您可以在命令行上指定一个或多个参数，在这种情况下，每个参数都会被立即记录。如果您未指定命令行参数，则将 `-f` 指定的文件或标准输入添加到日志中。否则，您可以指定一个包含一组待记录行的文件。`logger` 逐行从标准输入读取并记录消息。

## 选项 (Options)

- `-f file` 使用文件内容作为要记录的消息内容。

- `-i` 在每行记录中记录 `logger` 进程的进程 ID (PID)。

- `-p priority` 以指定的优先级输入消息。消息优先级可以通过数值或作为“设施.级别”对来指定。例如，`-p local3.info` 将消息优先级分配为 `local3` 设施的信息级别。默认优先级是 `user.notice`。

- `-t tag` 用指定的标记标记添加到 `logger` 的每行记录。

### 操数 (Operands)

`message` 字符串参数之一，其内容将按指定顺序串联，并用单空格字符分隔。

### 示例 (Examples)

以下示例显示了将消息 System rebooted 以默认优先级级别 notice 发送，`syslogd` 将像处理用户 设施的其他消息一样处理它。

```
$ castle logger System rebooted
$%
```

# login — 登录系统

### 概要 (Synopsis)

`/usr/bin/login [-p] [-d host] [-h terminal] [-r hostname] [...]`

### 描述 (Description)

在终端开始处使用 `login` 命令向系统识别您的身份。系统建立连接时调用 `login`。如果作为命令调用 `login`，它将替换初始 `shell`。

C shell 和 Korn shell 有自己的登录命令。请参见 `ksh(1)` 和 `csh(1)` 的描述。如果未提供参数，`login` 会请求用户名，并在适当的情况下请求密码。在输入密码时，尽可能关闭回显，使其不在屏幕上显示。
