前面的示例显示，`inet_aton(3)` 函数取代了功能更有限的 `inet_addr(3)` 函数。`inet_addr(3)` 的问题是，当地址无效时它会返回 `INADDR_NONE` 值。当 IP 地址 `255.255.255.255` 转换为 32 位值时，其返回值与常量 `INADDR_NONE` 相同。因此，无法区分无效的输入 IP 地址和通用广播地址。使用 `inet_aton(3)` 函数可以避免这种歧义。
