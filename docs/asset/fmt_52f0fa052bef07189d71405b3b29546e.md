
这种最后的函数定义方法对于后继你的脚步并修改该 shell 脚本的人来说更加直观。我希望你注意到了最后一句使用了“将”这个词。

```bash
get_arch ()
{
# 查询系统的硬件架构。较新的
# 机器使用 -M 参数，旧的微通道
# 架构 (MCA) 使用 'uname' 命令的 -p 选项。
  ARCH=$(uname -M)
  if [[ -z "$ARCH" && "$ARCH" = '' ]];
  then
    ARCH=$(uname -p)
  fi
  echo "$ARCH"
}
###########################################
```
