
### 引导加载程序

计算机启动时运行的第一个软件程序。它加载然后将控制权转移给操作系统。Linux 的两个主要引导加载程序是 `GRUB` 和 `LILO`。

### BOOTP

`BOOTP`。自举协议，一种 TCP/IP 网络协议，使无盘工作站能够发现其自身的 IP 地址、网络上 `BOOTP` 服务器的 IP 地址以及一个用于启动机器加载到内存的文件。

### BRI

`BRI`。基本速率接口，一种 ISDN 服务，提供两个 B 信道和一个 D 信道，称为 `2B+D`。这提供总共 144 Kbps 的带宽，即两个 64 Kbps 的 B 信道加上一个 16 Kbps 的 D 信道。

### BSD

`BSD`。Berkley 标准分发版，一种 Linux 操作系统启动过程，运行较少但较大的启动脚本，并用于所有开源 `BSD` 操作系统。

### 证书颁发机构

一个颁发数字证书的服务器。证书颁发机构可以是内部的，也可以是外部的受信任第三方。

### CHAP

`CHAP`。质询握手身份验证协议，一种提供远程客户端对服务器身份验证的协议，同时提供比 `PAP` 更多的安全性。`CHAP` 在连接期间定期验证远程客户端的身份，而 `PAP` 只验证一次。`CHAP` 不允许远程客户端在首先接收到来自服务器的质询之前尝试身份验证。

### 校验和

一种错误检测方案，其中每个传输的消息都伴随一个基于消息中位数值的数字值。如果接收主机发现数值与消息不一致，则假定该消息无效。

### CLI

`CLI`。命令行接口，一种用于控制操作系统的文本模式界面。

### 客户端/服务器

这些术语指的是网络中单台计算机的角色。为其他计算机提供服务的机器称为服务器，使用服务器提供的服务的机器称为客户端。一台计算机可以同时是客户端和服务器。

### CMOS

`CMOS`。互补金属氧化物半导体，一种用于 PC 内存中存储日期、时间和其他系统设置参数的晶体管材料。

### 版权保留

一种使程序软件免费且要求程序的所有修改和扩展版本也必须为免费软件的通用方法。

### 核心转储

将内存内容转储到文件中，通常用于跟踪软件错误。

### cron

`cron`。“command run on”的缩写，一个守护进程，可用于执行计划任务。

### CSMA/CD

`CSMA/CD`。`Carrier Sense Multiple Access/Collision Detection`（载波侦听多路访问/冲突检测）的缩写，一组确定当两个设备试图同时传输数据包（冲突）时网络设备如何响应的规则。标准以太网网络使用 `CSMA/CD`。

### 守护进程

在后台运行并执行特定任务的进程。该术语用于 Unix 系统，源自希腊神话，其中守护者是保护灵魂。

### DEB

`DEB`。为 Debian Linux 发行版设计的打包管理系统。用于在 Linux 操作系统上安装、卸载、验证、查询和更新软件包。

### Debian

`Debian`。Linux 操作系统的一个发行版。

### DHCP

`DHCP`。`Dynamic Host Configuration Protocol`（动态主机配置协议）的缩写，一种在 TCP/IP 网络上用于向请求该服务的主机分配网络地址的协议。请求通过端口 68 发送，回复通过端口 67 发送。

### 数字证书

出于安全目的附加到另一消息上的电子消息。数字证书用于验证发送消息的用户是否是其声称的人。

### DIMM

`DIMM`。双列直插内存模块，一种 `RAM` 类型。

### DMA

`DMA`。直接内存访问，一种将数据从主存储器传输到设备而不经过 `CPU` 的技术。

### DNS

`DNS`。`Domain Name System`（域名系统）的缩写。它是一种将域名转换为 IP 地址的网络服务。

### 域名

标识 IP 地址的名称。

### DSL

`DSL`。数字用户线。其两个主要类别是 `ADSL` 和 `SDSL`。`DSL` 比拨号连接提供更快的连接时间。

### EIDE/ATA

`EIDE/ATA`。增强型集成驱动器电子/先进技术架构，大多数计算机系统用于连接硬盘的标准接口。

### 嵌入式 Linux

嵌入式 `Linux` 是 `Linux` 的一个功能丰富的子集，精简到仅包含在嵌入式系统上有用的 `Linux` 元素。嵌入式 `Linux` 操作系统的较小尺寸允许设备使用闪存 `RAM` 而不是硬盘来容纳操作系统。

### 企业服务器

一种 `Linux` 安装类型，在保持高可用性的同时整合服务器服务。

### 环境变量

一个提供命名信息以支持程序的变量。

### 以太网

一种局域网架构，使用物理总线拓扑，通常使用逻辑星形拓扑。以太网网络支持高达 1 `gigabit per second`（千兆比特每秒）的数据传输速率。

### 提取

从归档中移除文件。

### FAQ

`FAQ`。`Frequently Asked Questions`（常见问题解答）的缩写。`FAQ` 是一种在线文档，提供关于特定主题的一系列问题及相应的答案。

### Fedora

`Fedora`。Linux 操作系统的一个发行版，前身为 `Red Hat Linux`。

### 文件系统

放置在逻辑磁盘或分区上的数据结构，允许操作系统记录有关存储在该处文件的信息。

### Finger

`Finger`。一个 Unix/Linux 程序，接受电子邮件地址作为输入并返回拥有该地址的用户的详细信息。它使用端口 79。

### FireWire

也称为 `IEEE 1394`，`FireWire` 是一种非常快速的外部总线标准，支持高达 800 `Mbs` 的数据传输速率。它可以用于连接多达 63 个外部设备。

## 防火墙

一个软件包或网络硬件设备（例如思科的 `PIX` 防火墙），用于限制对特定端口的访问，从而使 `Linux` 操作系统成为更安全的环境。

## Foomatic

大多数当前 `Linux` 版本使用的打印机驱动数据库。它提供通用的打印机驱动，生成符合 `Adobe` 标准的 `PPD` 文件，允许轻松配置具有所有驱动程序选项访问权限的打印队列。`Foomatic` 是一个基于 `XML` 的系统，将自由软件驱动与所有通用打印假脱机系统集成在一起。

## 格式化

描述为在计算机系统上使用而对存储设备进行准备的术语。

## 自由软件基金会

`GNU` 项目的主要组织赞助方。

## FreeBSD

`FreeBSD`。Unix 操作系统的免费版本，类似于 `Linux`。

## 免费软件

可以自由分发的软件，但保留作者的版权。

## FTP

`FTP`。文件传输协议（`File Transfer Protocol`）的缩写，`FTP` 是用于在 TCP/IP 网络上传输文件的协议。`FTP` 使用 21 端口进行文件传输控制，使用 20 端口进行文件传输数据。

## 网关

数据可以被路由以与本地网络外部的网络通信的 IP 地址。

## GID

`GID`。`group ID`（组标识符）的缩写，是分配给每个组的唯一数字。

## GNOME

`GNOME`。`GNU` 网络对象模型环境，一种具有面板、桌面、系统图标和图形文件管理器的图形用户界面（`GUI`）桌面环境。

## GNU

`GNU`。`GNU's Not Unix` 的回文缩写。`GNU` 是由自由软件基金会（`FSF`）开发的一个兼容 Unix 的软件系统。`GNU` 软件可以被修改并自由重新分发。

## GPG

`GPG`。`GnuPG` 是 `PGP` 的免费替代方案，并基于 `PGP` 开发。它提供公钥加密，用于交换具有保密性和身份验证的文件或消息。

## GPL

`GPL`。通用公共许可（`General Public License`）的缩写。此许可证通常伴随开源软件，允许软件被复制、分发和修改。

## 组

用户和资源的逻辑分组。

## GRUB

`GRUB`。`GRand Unified Boot loader`（大型统一引导加载程序）的缩写。

## GUI

`GUI`。图形用户界面（`Graphical User Interface`）的缩写。

## 硬件

计算机系统的物理部分。

## 主机名

本地主机的常用名称。

## 主机

连接到网络并通过唯一值识别以允许通过网络通信的设备。

## HTTP

`HTTP`。超文本传输协议（`HyperText Transfer Protocol`），一种用于在 TCP/IP 网络上请求和传输文件的协议。它使用 80 端口。

## 集线器

`OSI` 模型物理层设备，用于将多个主机连接到网络。

## IETF

`IETF`。互联网工程任务组（`Internet Engineering Task Force`）。

## IMAP

`IMAP`。互联网消息访问协议（`Internet Message Access Protocol`），一种用于接收电子邮件的协议。`IMAP` 类似于 `POP3`，但支持更多附加功能。它使用 143 端口。

## IP 地址

分配给 TCP/IP 网络中每个主机的地址，由一个以四个用小数点分隔的十进制数表示的 32 位数字组成。例如，`192.168.0.1` 是一个 IP 地址。

## iptables

`iptables`。一个用于启用数据包过滤、网络地址转换（`NAT`）和其他数据包操作的 `Linux` 程序。

## IPsec

`IPsec`。一种强加密机制，提供身份验证和加密服务。

## IRQ

`IRQ`。`Interrupt ReQuest`（中断请求）的缩写，`IRQ` 向 `CPU` 发送中断信号，以指示某个设备需要执行任务。

## ISDN

`ISDN`。综合业务数字网（`Integrated Services Digital Network`），一种用于通过数字电话线发送语音、视频和数据的国际通信标准。
