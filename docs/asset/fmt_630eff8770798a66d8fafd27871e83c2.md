## 5. 在这种情况下，有一个损坏的在线日志序列号 264，因此你需要恢复日志序列 263。

```
RMAN> run {
2> allocate channel chl1 type disk;
3> set until logseq=263 thread=1;
4> restore database;
5> recover database;
6> sql "alter database open resetlogs";
7>
```
