你可能会惊讶于基于 `MIPS` 架构的 32 位处理器已经上市了 20 多年。`MIPS` 架构是在 1981 年由斯坦福大学的 Hennessy 博士设计的，他后来创立了 `MIPS Computer Systems, Inc.`。该公司演变成了现在的 `MIPS Technologies`，其主要工作是设计和授权 `MIPS` 架构和核心。`MIPS` 是一种精简指令集计算机 (`RISC`) 架构，具有 32 位和 64 位实现。`MIPS` 处理器出现在从高端到消费级的各种产品中。其中一些知名品牌包括 Sony、Texas Instruments、Cisco 等其他。`MIPS` 网站列出了 73 个从事制造的授权方，其中最大且最成功的是 `Broadcom Corporation`。`Broadcom` 是领先的 `SoC` 解决方案供应商，适用于电缆机顶盒、调制解调器、HDTV、无线网络、千兆以太网和网络语音 (`VoIP`) 等市场。`Broadcom` 的 `SoC` 在这些市场非常受欢迎。正如前面提到的，在 2000 年，`Broadcom` 收购了 `SiByte Inc.`，导致了目前的产品线。单核处理器包括 `BCM1122` 和 `BCM1125H`，均基于 `MIPS64` 核心。这些 `SoC` 包含了 `DDR SDRAM` 控制器、四个独立的千兆以太网 `MAC` 控制器以及 64 位 `PCI-X` 主控制器。它们还包含 `SMBus`、`PCMCIA` 和四个串口。双核处理器包括 `BCM1250`、`BCM1255` 和 `BCM1280`。同样基于 `MIPS64` 核心，这些处理器的运行频率从 600MHz (`BCM1250`) 到 1.2GHz (`BCM1255` 和 `BCM1280`)。这些双核芯片集成了外设控制器，各种千兆以太网控制器、64 位 `PCI-X` 接口、`SMBus`、`PCMCIA` 和多个 `UART` 接口。与其单核兄弟一样，这些双核实现具有低功耗。例如，`BCM1255` 在 1GHz 运行时的功耗为 13W。四核处理器包括 `BCM1480` 通信处理器。与其他处理器一样，这些都是基于 `MIPS64` 核心。核心运行频率从 800MHz 到 1.2GHz。这些 `SoC` 包含了集成的 `DDR SDRAM` 控制器、四个独立的千兆以太网控制器以及 64 位 `PCI-X` 主控制器。它们还包含 `SMBus`、`PCMCIA` 和四个串口。

### 3.2.13.1 BeagleBoard

如果你接触嵌入式 Linux 已经有一段时间，你一定听过 `BeagleBoard`。它的受欢迎源于其低廉的价格、易于获取以及广泛的社区支持。该板支持流行的 `U-Boot` 引导程序，使得内核集成变得简单。`BeagleBoard` 基于 `TI OMAP3530`。它提供了连接键盘和显示器的接口、用于内核和根文件系统的 `SD` 卡、用于控制台的串口连接以及双模式 `USB 2.0` 端口。

`BeagleBoard` 是实验和学习的绝佳平台，也是各种 `OMAP` 相关开发项目的完美开发平台。`BeagleBoard` 唯一的缺点是缺少以太网端口。幸运的是，这个问题被一家名为 `Tin Tools` 的公司解决了。他们开发了一个名为 `BeagleZippy Ethernet Combo Board` 的配套板。除了增加以太网端口外，它还增加了另一个 `SD/MMC` 接口、电池备份实时时钟、一个 `I2C` 扩展接口和另一个串口。你可以在 `www.tincantools.com/product?productid=16147&cat=255&page=1` 找到更多信息。

> * 这些芯片内部支持连接到 `AC97` 音频流。此外，请注意集成的 `DSP` 可以运行各种音频和视频解码器。
