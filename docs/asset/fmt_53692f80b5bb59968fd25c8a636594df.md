绝大多数人认为，渗透分析师（或程序员）需要做的只是坐在电脑前，开始编写一串黑色的代码，然后——哒哒！地球上的任何电脑都瞬间被攻破了。这种存在于好莱坞传说中的概括与现实相径远。该领域的专家在发现和利用计算机框架漏洞时，所使用的方法极其严谨。经过一段时间的开发，已经形成了一套被熟练的道德黑客使用的结构。该结构的四个阶段引导渗透分析师通过实验性滥用数据框架的过程，从而获得一份详尽的报告，在必要时可以使用其来重现测试任务的部分。这一程序为分析师提供了一个框架，同时也为渗透测试活动制定了高水平的设计。每个阶段都扩展了之前的进展，并为随后的进展提供了细节。虽然程序是连续的，但许多分析师会返回之前的阶段以解释发现并确认结果。

过程中的前四个阶段由 Patrick Engebretson 在其书籍《黑客与渗透测试基础》（The Basics of Hacking and Penetration Testing）中描述。这些阶段分别是：侦察、扫描、渗透和维持访问。

本书使用了这些阶段，并在 Patrick 的工作基础上增加了一个额外阶段：报告。此外，与 EC-Council 在其著名的认证道德黑客（CJEH）课程中描述的五阶段过程相比，许多人可能会发现该程序的最后一个阶段“隐藏踪迹”（Covering Tracks）缺失了。这是刻意为之，旨在关注之前的阶段并留出一个用于报告的部分，这是许多关于该主题的书籍所忽略的主题。

本书还通过消除生命周期的循环表示来区别于之前的书籍，取变为一种更直接的感知描述，这符合道德黑客在普通任务中通常的体验。这始于对目标数据框架的监控，结束于渗透分析师或测试小组长向数据框架管理员报告所发现的内容。

## 渗透测试生命周期

第 6 节：渗透测试生命周期简介展示了生命周期的各个阶段。此外，它还概述了安全领域的工程师们首选使用的工具。这些章节将不会详尽，但将开始揭示什么工具或策略可以帮助引导此类测试。大量的工具或系统都有专门的书籍——有时是多本书介绍它们的正确用法和应用。

## 第一阶段：侦察 (RECONNAISSANCE)

在一个灯光昏暗的小房间里，专家和官员正在检查和审查威胁区域的地图。房间里的其他人盯着显示全球地图的电视屏幕，疯狂地做着笔记。这个房间里的最后一次会议正在对被检查的目标的一切情况进行细致的评估。虽然这种情况展示了在对潜在目标进行军事观察时可能发生的情况，但这与渗透分析师在渗透生命周期侦察期间所做的事情相似。

这一阶段的核心在于掌握有关目标系统和关联的一切信息。这是通过浏览互联网和对目标进行潜在扫描完成的。在这个阶段，分析师尚未真正进入系统，而是识别并报告目标可能产生的任何会话数据。

## 第二阶段：扫描 (SCANNING)

在敌军后方，一名孤独士兵躲在灌木丛和树丛中。传回的报告告知其他人关于营地的区域以及每栋建筑正在进行的工作类型。报告还记录了穿过整个营地的路线以及可见的各种类型。

模型中的士兵通过侦察阶段的调查已经获得了一个战略目标。这适用于渗透测试生命周期的第二个阶段。分析师将利用第 1 阶段收集的数据来真正开始过滤目标系统和数据框架。

## 第三阶段：渗透 (EXPLOITATION)

四名军官穿过一片开阔的地野；月亮像一条弯月并被雾气遮挡，战士们在幽灵的光芒中看到一切。他们冲入建筑，溜过栅栏上的一个洞，然后通过一个开放的间接入口。在目标处只待了几分钟，他们就带着关于未来几个月部队部署和计划的基本数据撤离离开了。

同样，这符合道德黑客在渗透阶段将做的事情。该阶段的计划是进入目标框架并利用框架漏洞和已证明的系统秘密带走数据。

## 第四阶段：维持访问 (MAINTAINING ACCESS)

根据攻击小组提供的图纸，一群才华横溢的建筑师在某处发现了之前获取的关键数据的房间。这一阶段的目的是为对手利用提供易于访问的空间。对于分析师来说，这就是当框架被用于间接访问，且在框架上留了 rootkits 以允许日后访问的情况。

## 第 5 阶段：报告

打击小组负责人在指挥官和高级海军军官面前进行汇报，澄清攻击的细微之处。每一个进展都将以极其详尽的进行阐明，详细说明导致滥用发生的每一个细节。渗透分析师也应该创建详尽的报告，以澄清黑客攻击过程中的每个步骤、被滥用的漏洞以及真正被破坏的框架。此外，按照规定，可能需要小组中的某个人（有时是多个人）向目标数据框架的高级倡议人员和专业人员提供逐项准备说明。

## 演示

正如军事组织者在制定战斗方案之前会仔细分析可用数据一样，成功的渗透分析师也应该在引导有效的渗透测试之前，仔细分析可以获取的全部数据。通常，这些数据可以通过使用 Google 等其他工具浏览互联网来获取，包括那些专注于数据共享和在线生活的工具。数据也可以在互联网的名称服务器上找到，这些服务器为客户端程序提供引导。电子邮件可以通过关联进行跟踪，甚至回执邮件也能帮助渗透分析师。

创建并分析目标网站的离线副本可以提供大量的重要数据源，并在以后可用作社交工程任务的工具，前提是测试规则（ROE）允许。

此阶段始于测试小组对目标的进行最少思考。给予小组的详细程度可以从仅知道关联名称和可能的网站地址，到详细且明确的框架数据，包括在 ROE 中描述的用于限制或缩小测试范围的 IP 地址空间和创新技术。ROE 可能还会限制测试小组开展活动的能力，记住禁止进行社交工程和破坏性活动，例如拒绝服务（DoS）和分布式拒绝服务（DDoS）攻击。

目标是尽可能多地获取有关关联的数据。

关于该关联应当解决的几件事包括：

- 层级结构，包括逐项的高级、部门和小组授权大纲；
- 层级基础，包括 IP 空间和系统拓扑；
- 使用的进展，包括设备阶段和软件软件包；
- 代表性的电子邮件地址；
- 授权人员；
- 授权办公室的物理区域；
- 电话号码。

# 第 8 章：从目标自己的网站开始

目标的官方网站为构建攻入档案提供了海量数据。例如，许多地方乐意展示授权大纲和关键人物的简介。这些应该被作为建立目标档案和关联中关键人物数据的依据。它们可以用于通过网络化社交媒体场所进行进一步的数据获取，并用于社交工程，前提是所表 ROE 允许。

许多授权网站还包含招聘职位页面。这对于决定关联中使用的技术具有基础性。例如，招聘了解 Active Directory 和 Windows Server 2012 的框架负责人的公告将是一个强有力的指标，表明关联至少在使用 Windows Server 2012。类似的招聘熟悉 Windows Server 2003 或 2000 管理的负责人或大师的公告应该让任何渗透分析师警觉，因为这些阶段与更新的操作系统相比是无能的。

每个网页都应该检查是否有连接网络邮箱的链接，一旦发现就应该对其进行评估。如果点击链接显示 Outlook Web Access 页面，那么可以推断正在使用 Microsoft Exchange 服务器处理电子邮件。如果显示 Office 365 页面，这是一个良好的指示，表明电子邮件服务正在被重用，且邮件服务器可能过度依赖大多数 ROE。这对于 Google 网页邮箱也有效；无论如何，这应该在承诺开始前界定的限制范围内进行。如果存在关于跨越限制可行性的查询，应该使用被认为承诺的操作员来确定该查询。

## 网站镜像

有时，复制关联的整个网站以进行离线评估更有力。这可能是为了使用自动化工具扫描术语，或者仅仅是为了在对当前网站上的敏感数据进行更改时有一个副本。仅仅拥有网站的副本以进行离线监控也是有价值的。像 `wget` 命令行这样的工具可以复制网站的所有 html 文档并将其存储在本地硬盘上。`wget` 工具包含在 Kali Linux 中，是一个简单易用的工具。通过在终端窗口运行以下命令将下载整个网站的 html 文档。必须注意的是，wget 不会复制页面的服务器端程序，例如那些使用 PHP 内容制作的页面。

`wget -m -E -v http://foo.com`

在这个模型中，`wget` 命令后跟着各种开关或选项。与 Kali Linux 上的设备一样，可以参考用户手册来决定工具对承诺任务的使用。要查看 `wget` 手页，请使用相应命令。`man wget`

进入手册页后，使用上下方向键进行翻阅内容。按 h 键获取帮助，按 q 键退出手册页。对 `wget` 手页中此设置的审核显示了以下：

- -m reflect，开启适用于镜像的选项；
- -p page or essentials，此选项确保下载所需的文档，包括图片和 css 记录；
- -E alter extension，这将使所有页面在本地保存为 html 文档；
- -k convert interfaces，这允许文档转换为本地查看；
- -K keep original files，将原始文件以 .orig 后缀备份。

从关联的 Web 服务器移动的文档将存放在以被复制网站命名的封包中。在复制网站时，下载制作或包含 PHP 的页面可能会出现错误。这是因为制作页面的许多代码是由网站页面背后的服务器内容生成的，这是一个大多数克隆应用程序无法访问的区域。

## 包含所有这些词

此字段用于发现包含交换框中输入词汇的页面，而不忽略这些词汇在网页上的具体位置。这些词汇不需要在请求中组合或相邻，只需出现在页面的某个地方即可。要进行此查询，在对话框中输入各种术语并点击“高级搜索”按钮。通过这样做，在开发搜索页面中输入的词汇将转换为查询字符串，然后发送到 Google，就像直接在 Google 主页搜索框中输入它们的一样。

## 确切的词或短语

在此选项左侧的字段中输入查询术语，将使 Google 网页搜索工具发现精确请求中组合的词汇或表达式。与“包含所有这些词”搜索不同，只有在准确请求中包含且相邻出现该表达式或词汇的网页才会被包含在结果集中。此查询通过在语句内部设置搜索术语来工作。

## 包含这些词中的任意一个

使用此字段时，Google 搜索将发现包含其中任何一个词的页面。与“包含所有这些词”字段完全不同，返回的页面并不包含所输入的全部词汇。这种搜索通过在查询框中的术语之间放置 OR 连接符来工作。

## 不包含这些词

在此内容框中输入的词汇将用于排除随后的 Google 搜索中的页面。任何包含输入词汇的页面都将从结果集中删除。此搜索通过在结果集中你不需要的词汇或术语前加上一个短横号来工作。

## 数字范围

通过利用此处的两个内容字段，搜索将发现具有输入范围范围内数字的页面。这种搜索可以通过包含计量单位进行分类，例如，磅 (lb)、英里或毫米 (mm) 或像 $ 这样的货币。通过在数字之间设置两个句点，可以在主搜索框中直接进行此查询。

## 语言

通过下拉选择器选择语言，后续页面大部分将使用所选语言。此查询限制器可以用于将结果限制在以目标所在地通用语言编写的页面上。例如，通过关注德国网站，一个对德国公司进行渗透测试的小组可以更有可能寻找与该特定任务相关的数据。

## 地位置/地区

通过下拉选择器选择位置，后续页面将来自位于所选区域的站点页面。如果使用方言下拉菜单没有产生选择，则选择区域后的搜索结果将包含分布在该位置的页面，而不考虑所使用的基本语言。通过同时选择语言和地区，可以引导更深层次的搜索。

## 最后更新时间

通过在下拉菜单中选择时间限制，只有在所选时间范围内更新的页面才会被记录。这将确保较旧的页面被排除在结果之外，并可用于确保后续页面是在关键事件之后。例如，作为渗透测试重点的协会最近与另一家公司完成了合并或收到了另一项创新，搜索可以限制在自事件发生以来的时间，以确保查询结果具有更高的相关性。

## 站点或域名

在缩小目标项目列表时，此内容框可能是最有帮助的工具之一。例如，寻找管理机构可能通过将结果限制在 .gov 空间内而获益，而寻找 Foo 公司则可能通过将结果限制在 foo.com 区域而获益。这种限制也可以通过在基础 Google 搜索内容框中使用 site 搜索限制器来引导，后跟应应在结果集中返回的区域或空间。例如，使用 site: foo.com 将结果限制为仅来自 foo.com 区域的页面。

## 词出现出现

使用此下拉列表，可以将搜索问题集中在页面的特定部分。清楚地选择“页面上的任何位置”将在整个互联网目标页面上运行搜索，而对查询问题的关注位置没有实际限制。

使用“在页面标题中”的搜索将仅关注网站页面的标题。

具体而言，页面标题是显示在互联网浏览器标签页中的网站页面页级部分。此查询也可以通过在搜索框中使用 intitle: administrator 在 Google 主页上进行引导。

使用限制器“在页面内容中”将把搜索限制在页面内容上。它将阻止诸如图片、记录和如标题之类的页面结构等内容。如果这些内容被写在页面内容中，查询将在结果中恢复这些内容。例如，如果页面内容中引用了图片，则该图片将出现在索引列表中；这对于内容中的图片标记和链接同样有效。在 Google 搜索框中使用 intext: administrator 等同于从下拉列表中选择此选项。

使用“在页面 URL 中”将把搜索限制到页面统一资源定位符 (URL)。URL 是显示在互联网浏览器位置框中的站点页面位置。最后，使用“与页面的连接中”将发现连接到查询标准的页面。此搜索可以通过使用 inurl: administrator 在主 Google 搜索框中引导。

## 安全搜索

安全搜索有两种替代方案：“显示最重要的结果”和“过滤明确内容”。过滤内容设置可以减少索引列表中的显式内容记录和图片。选择选择显示最重要的结果”不会对显式不当内容进行过滤。

## 理解程度

阅读级别选择将根据网站页面内容的多方面性来过滤结果。“无阅读级别”将在不分阅读级别的情况下执行搜索。“显示具有阅读级别的结果”将返回具有任何阅读级别的结果。“按阅读级别过滤结果”将返回具有特定阅读级别的结果。“按阅读级别排序结果”将返回具有特定阅读级别的结果。

## Google 黑客攻击 (Google Hacking)

Google Hacking是一种由 John Doe 发头的方法，它利用网络搜索中的显式操作符和术语，通过 Google 爬虫返回重要数据。该策略的核心是利用特定关注的短语在 Google 数据库中搜索有关个人和协会的数据。这一过程会让 Google 进行扫描并对其结果进行加载。Google 黑客攻击利用运算符专注于可以在 Google 爬虫中运行的问题。通常，这些项目侧重于收集有关特定进展的数据，例如服务和其他搜索。已经编写了一些解释 Google 黑客技术的精彩书籍，其中最著名的是 John Doe 编写的《渗透测试员的 Google 黑客》。

## Google 黑客数据库 (Google Hacking Database)

大量的 Google 黑客搜索字符串已被汇集到 Google 黑客数据库 (GHDB) 中。第一个数据库位于 http://www.hackers.org/ghdb/，Offensive Security 在 http://www.offensive-security.com/network/google-database/ 同样拥有开发的第一个数据库，并使用了“Google dorks”一词，这是 Google 发现的字符串的别称。在编写时，由 Offensive Security 维护的 GHDB 包含超过 3350 个分类。其中超过 160 个查询字符串可以发现包含密码的文档。下面展示了一个尝试发现密码的查询字符串示例：“current arrangement”。运行搜索返回了近百万个结果。请考虑到返回的部分记录可能不包含密码，但返回的结果数量惊人。可以通过包含额外的运算符（例如网站或空间）对此搜索进行进一步完善。

## 网络生活 (Web Based Life)

网络生活已成为个人生活中不可或的一部分。这一现实使得社交网络成为时期社交数据的宝库。在物理世界中由个人保护的数据由这些个人通过社交媒体发布。通过使用 Facebook、Instagram、Twitter 等目标，可以创建该领域工作人员的完整简介。这有助于社交工程设计。LinkedIn 在联系专家方面特别有用。LinkedIn 会经常填写个人资料中的空白处，包括层级大纲甚至是地址记录。尽管这项高级功能通常需要社交工程设计，因为电子邮件地址不会公开显示。在允许社交工程的情况下，发现曾工作于该协会的人是极佳的数据源。

## 制造分身 (Make a Doppelganger)

故事中的分身是人的复制品。在开始网络生活之前，建立一个人格（persona）是通常的做法。使用安全专家或准入分析师的简介对目标进行直接研究通常不是一个好主意。更好的主意是分析师可以通过社交网络与该协会的人建立社交联系。如果分析师拥有一个声称曾在目标协会工作过或与分析师试图接触的机构上过相似学校的人格，将更具吸引力。显然，分析师必须小心不要完全接管真实个人的身份，这种行为可能会导致某些人认为发生了欺诈。个人可能拥有相似的名字。例如，建立一个名为 John Smith、就读于威斯康星大学的完全虚构的人格并不等同于获取就读于那里的真实 John Smith 的身份。无论如何，确保你的人格不会渗透到欺诈或虚假中。这意味着除了其他事情外，不要填写有你身份名称的申请表，或使用该身份参加合法活动。使用分身的界限应该从承诺开始就标明，如果允许社交工程，则应该建立一个当社交构建成为重要因素时可行的分身。在填写网络生活注册表时，分析师应关注使用方法，以确保使用分身时没有违反策略、规则或法律。
