# 序言

GNU 调试器（也称为 GDB）是一种源码级调试器，提供了在源码级和机器级上调试应用程序的能力。此外，GDB 允许对已经运行的应用程序进行调试（通过附加应用程序的进程 ID）以及进行事后调试。你对源码级调试器所期望的所有传统功能在 GDB 中均可用，包括多语言和多架构支持。

本章介绍了 GDB 并以教程的方式探索了它的功能和能力。
