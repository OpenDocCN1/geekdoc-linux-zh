
你在机加工之外的现实物体并没有以锐角连接的垂直面。它们在表面之间通常有圆弧（圆角 `fillet`）或直形（斜角 `chamfer`）的过渡。虽然在视觉上可能并不明显，但场景中的这种过渡将通过创建一个观众能够观察到的状态，使之看起来更加真实。在适当的光照下，过渡表面可以产生华丽的高光，微妙地引起对该状态的注意。`Extrude` 修改器不提供圆角或斜角，但这些功能可以在 `Bevel`（倒角）修改器的选项中找到，如下步骤所示。尽管此示例使用了文本，但 `Bevel` 修改器可以用于任何脊线（`spine`）。`Bevel` 修改器的 `Bevel` 值具有控制项，可以在相对于脊线当前位置垂直的三个不同位置设置高度和轮廓量。`Outline` 值是一个偏移量，它根据指定的 `Height` 值相对于其原始尺寸调整形状大小。下一个练习演示了为文本添加 `Bevel` 修改器的步骤：

- 1. 选择文本，点击 `Modify`（修改）选项卡，从 `Modifier`（修改器）列表下拉菜单选择 `Bevel`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_190_2.png)

- 2. 在 `Bevel` `Values` 面板中，将 `Level` `1` `Height` 参数设置为 3”，并保持 `Outline` 设为 0.0"。这将为字母生成一个初始的直段。

- 3. 勾选 `Level` `2` 复选框。将 `Level` `2` `Height` 设置为 0.25”，并将 `Outline` 设置为 -0.25”。

```
| Bevel Values |
|---|---|
| Start Outline [0.0] |
| Level 1 | Height [3.0] | Outline [0.0] |
| [x] Level 2 | Height [0.25] | Outline [-0.25] |
| [ ] Level 3 | Height [0.0] | Outline [0.0] |
```

- 4. 放大字母以查看 `Bevel` 修改器的斜角效果，如图 3.48 所示。

- 5. 在 `Parameters` 面板中，在 `Surface` 组中选择 `Curved` `Sides`，将 `Segments` 设置为 4，并勾选 `Smooth` `Across` `Levels`。这些设置通常会平滑层与层之间的过渡，并且当存在较小的 `Outline` 值时，可以在文本边缘创建一个棱边。
