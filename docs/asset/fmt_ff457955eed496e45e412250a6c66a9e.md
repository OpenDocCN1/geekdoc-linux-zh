
# Macintosh

苹果 Macintosh，即 Mac（[www.apple.com](https://www.apple.com)），在配有 `X_Server` 的情况下，是一款极具吸引力的互联网和/或工作组服务器。核心操作系统是基于开放标准构建的；因此，开源软件社区为其发展做出了贡献。该操作系统被称为 Darwin，它为互联网、发布和关键任务服务器应用提供了所需的性能更高的可靠性。借助新的 3D 技术 `OpenGL`，Mac 将业界支持最广泛的 2D 和 3D 图形 API 提升到了全新的高度。

## 责任

入侵状态： 配置控制。

漏洞： `MacOS 8x`。


到 `80` 端口，然后按两次回车键，即可切换 Mac 网络共享功能。
