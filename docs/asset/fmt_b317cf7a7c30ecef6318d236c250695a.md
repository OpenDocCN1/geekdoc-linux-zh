
然后，你使用所输入的信息尝试连接到远程系统。消息区域将显示连接尝试的进度信息。连接建立后，你将在文件列表（gFTP 窗口右侧）中看到远程系统当前位置的文件列表。图 13.26 显示了一个连接到远程系统的 gFTP 窗口。

# 桌面网络连接

## 将文件复制到远程系统

若要使用 gFTP 将文件上传或复制到你连接的远程系统，请按照以下步骤操作：

- 1. 在 gFTP 窗口左侧的面板（本地面板）中，导航到包含你想从本地系统复制的文件目录。这可以通过连续双击目录图标直到到达正确的目录栏，或者直接在当前工作目录栏中输入路径（例如 `/home/you/myfiles`）来实现。
- 2. 在 gFTP 窗口右侧的面板（远程面板）中，使用相同的技术导航并将你的文件复制到远程副本。
- **图 13.26**

建立连接后的 gFTP 窗口。右侧面板不是空的；它显示了远程系统当前工作目录的文件。

![](img/92a94ba94656919835b7a50a27c9d9ba_341_0.png)

- 3. 在本地面板中，点击你想传输的文件名使其显示高亮。
- 4. 点击 `Copy` 按钮。在文件传输时，传输详细信息将出现在 `Filename Progress` 框中。传输完成后，文件也会出现在右侧的远程目录列表中。
- 5. 对你想复制每个文件重复步骤 3 和 4。

如果你想一次复制多个文件，可以通过点击并高亮第一个文件，然后按住 `Shift` 键点击最后一个文件来选择文件范围。整个范围的文件将被高亮，任何复制操作将应用于你选的整个文件列表。

你也可以通过按住 `Ctrl` 键点击每个文件来单独选择多个文件。

## 从远程系统复制文件

若要使用 gFTP 从连接的远程系统下载或复制文件，请按照以下步骤操作：

- 1. 在 gFTP 窗口右侧的面板（远程面板）中，导航到包含你想复制到本地系统的文件的目录。
- 2. 在 gFTP 窗口左侧的面板（本地面板）中，导航到你想存放远程文件的目录。
- 3. 在远程面板中，点击你想传输的文件名使其显示高亮。
- 4. 点击 `copy-from` 按钮。文件将从远程系统传输到你的系统。传输完成后，文件也会出现在左侧的本地目录列表中。
- 5. 对你想复制每个文件重复步骤 3 和 4。

## 关闭 FTP 连接

点击 `Connect` 按钮打开 gFTP 连接。连接将关闭，远程面板中的文件列表将被清空。

退出 gFTP，点击 `Quit`。

## 使用应用程序帮助

查找应用程序帮助或文档信息最自然的地方是在应用程序内部。你在 Linux 中使用的几乎每一个桌面应用程序都包含了某种形式的在线帮助，你可以直接从应用程序中打开它。

这类文档最为有用，因为是由该应用程序的作者编写的。此类文档通常假设读者在阅读帮助信息时实际上在使用该应用程序。因此，你应该能够使用文档来解决你的问题，并获得替代建议和其他信息来帮助你可能遇到的障碍。

## 查找和启动应用程序帮助

当应用程序包含其自己的帮助文件或文档文件时，通常可以通过应用程序菜单栏中的 `Help` 菜单访问（按照习惯，`Help` 菜单是菜单栏中最右侧的菜单）。

在任何应用程序中，`Help` 菜单包含一个帮助和文档相关的选项列表。在 GNOME 应用程序中，`Help` 菜单包含（至少）`Contents` 选项，它会启动应用程序文档；以及 `About` 选项，它显示应用程序版本、版权、作者和其他杂项信息。

典型的 GNOME 应用程序帮助菜单如图 14.1 所示。

在 KDE 应用程序中，`Help` 菜单通常更详尽，通常包含以下选项：

- `Handbook`：包含应用程序文档。
- `What's This?`：为应用程序窗口的不同部分提供上下文感的帮助。
- `Report a Bug`：允许用户报告在使用应用程序时遇到的问题。

## 使用帮助菜单中的“关于”选项

当你需要了解有关你的 KDE 或 GNOME 应用程序的版本、许可或其他信息时，选择 `Help` 以打开 `About` 信息屏幕。许可信息提供了有关你被允许如何使用和分发应用程序的详细信息。如果你需要提交错误报告，版本信息对应用程序作者很有帮助；而在某些独立应用程序本应协同工作但仅适用于特定版本组合的情况下，了解版本信息也是很有用的。

在 GNOME 应用程序中，`About` 信息包含了程序作者的电子邮件地址（点击 `致谢` 按钮查看）。如果你有错误报告、功能请求或关于应用程序在线文档中未涵盖的应用程序的特定问题，你可以使用 `About` 对话框中的联系信息写信给应用程序作者并直接询问他们。在提交应用程序的错误报告或向作者询问有关应用程序的问题时，请务必包含以下信息：

- 你正在使用的 Linux 操作系统版本（Red Hat Linux 9）
- 所述应用程序的名称
- 你遇到问题或对此有疑问的应用程序版本
