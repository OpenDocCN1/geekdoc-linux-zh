## 18.1.1.12 枚举自动提升权限的二进制文件

在本模块的稍后部分，我们将探索能够自动提升权限的二进制文件。在 Windows 系统上，我们可以根据如何将输出通过到 `Where-Object` 来针对性地目标这些设置。我们可以使用 `reg query` 来检查这些设置：
