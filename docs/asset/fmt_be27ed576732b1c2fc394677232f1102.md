
## 证明

我们对 4-色图 `G` 的阶数 `n ≥ 4` 进行归纳。归纳基础成立，因为 `K_4` 是唯一一个阶数为 `4` 且色数为 `4` 的图。对于整数 `n ≥ 5`，假设每个阶数 `n'` 满足 `4 ≤ n' < n` 且色数为 `4` 的图都包含 `K_4` 的细分。设 `G` 是一个阶数为 `n` 且 `χ(G) = 4` 的图。我们将证明 `G` 包含 `K_4` 的细分。

设 `H` 是 `G` 的一个临界 4-色子图。如果 `H` 的阶数小于 `n`，则由归纳假设可知 `H` 进而 `G` 也包含 `K_4` 的细分。因此，我们可以假设 `H` 的阶数为 `n`。从而，`H` 是 2-连通的。

首先假设 `κ(H) = 2`，且 `S = {u, v}` 是 `H` 的一个点割。设 `F1, F2, …, Fs` `s ≥ 2` 为 `H - S` 的分支，对于 `1 ≤ i ≤ s`，设 `Hi = H[{u, v} ∪ Fi]` 为 `H` 由此产生的 `S`-分支。由于每个 `S`-分支都是 `H` 的真子图，可知对于每个 `i` `1 ≤ i ≤ s`，都有 `χ(Hi) ≤ 3`。如果存在每个 `S`-分支 `Hi` 的 3-着色 假设使用颜色 1, 2, 3，使得 `u` 和 `v` 被赋予不同的颜色，那么通过必要时交换颜色，可使 `u` 被赋予颜色 1，`v` 被赋予颜色 2，从而得到 `H` 的 3-着色，这是不可能的。因此，存在某个 `S`-分支，设为 `H'`，使得 `u` 或 `v` 具有相同的颜色，这意味着 `uv ∉ E(H')`。由于 `H' + uv` 没有 3-着色，可知 `χ(H' + uv) = 4`。由于 `H' + uv` 的阶数小于 `n`，由归纳假设可知 `H' + uv` 包含 `K4` 的某个细分 `F`。如果 `F` 不包含边 `uv`，则 `H'` 进而 `G` 包含 `F`。因此，我们可以假设 `F` 包含边 `uv`。在这种情况下，设 `H''` 是 `H` 中不同于 `H'` 的一个 `S`-分支。由于 `S` 是最小点割，`u` 和 `v` 都与 `H - S` 的每个分支中的顶点相邻。因此，`H''` 包含一条 `u` 到 `v` 的路径 `P`。将 `F` 中的边 `uv` 替换为 `P`，即在 `H` 中得到 `K4` 的一个细分。

现在我们可假设 `H` 是 3-连通的。设 `w ∈ V(H)`。则 `H - w` 是 2-连通的，从而包含一个圈 `C`。借助推论 4.13，存在 `C` 上三个互异的顶点 `w1, w2, w3`，使得 `H` 包含内部点不相交的 `w - wi` 路径 `Pi` `1 ≤ i ≤ 3`，其中这些路径中任意两条仅有 `w` 公共，且 `wi` 是 `Pi` 在 `C` 上唯一的顶点。那么 `C` 和路径 `Pi` `1 ≤ i ≤ 3` 在 `H` 中产生 `K4` 的一个细分。

由于 `H` 包含 `K4` 的细分，图 `G` 也包含。■

因此，对于 `2 ≤ k ≤ 4`，每个 `k`-色图都包含 `Kk` 的细分。

### Hajós 的猜想

1961 年，György Hajós [116] 猜想对于每个整数 `k ≥ 2`，所有 `k`-色图都包含 `Kk` 的细分。

> **Hajós 的猜想** 如果 `G` 是一个 `k`-色图，其中 `k ≥ 2`，则 `G` 包含 `Kk` 的细分。

1979 年，Paul Catlin [42] 构造了一组图族，证明了 Hajós 的猜想对于每个整数 `k ≥ 7` 都是错误的。例如，图 16.18 中阶数为 15 的图 `G` 由五个互不共顶点的三角形 `Ti` `1 ≤ i ≤ 5` 组成，其中如果 `|i - j| = 1` 或 `{i, j} = {1, 5}`，则 `Ti` 的每个顶点与 `Tj` 的每个顶点相邻。这里，`ω(G) = 6` 且 `χ(G) = 8`。由于 `ω(G) = 6`，图 `G` 不包含 `K8` 作为子图 甚至也不包含 `K7` 作为子图。事实上，我们声称 `G` 也不包含 `K8` 的细分。假设 `H` 是 `G` 的一个这样的子图，则 `H` 包含八个度数为 7 的顶点，且 `H` 的其他所有顶点度数均为 2。

首先，我们证明对于任意的三角形 `Ti` `1 ≤ i ≤ 5`，在 `H` 中都不能恰好包含一个度数为 7 的顶点。假设三角形 `Ti` 例如恰好包含这样一个度数为 7 的顶点 `v`。则 `v` 是通往 `H` 中其余七个度数为 7 的顶点的七条路径的起点，且这些路径中任意两条仅有 `v` 公共。由于 `v` 在 `T1` 外部仅与六个顶点相邻，这是不可能的。

图 16.18：Hajós 猜想对于 k = 8 的反例

接下来，我们证明对于任意的三角形，在 `H` 中都不能恰好包含两个度数为 7 的顶点。假设三角形 `T1` 例如恰好包含两个这样的顶点，即 `u` 和 `v`。则 `u` 是通往 `T1` 外部六个顶点的六条路径的起点。显然，这六条路径必须包含 `T2` 和 `T5` 中的所有六个顶点。然而，顶点 `v` 也满足此性质。这意味着 `T2` 和 `T3` 中的六个顶点是 `H` 中其余度数为 7 的顶点。因此，在 `T5` 中存在两个顶点 `v2` 和 `v5`，在 `T2` 中存在两个顶点 `u2` 和 `v2`，使得路径 `u5 - v2`、`v5 - v2`、`v5 - u2` 和 `v5 - v2` 的内部顶点仅包含 `T2` 和 `T3` 中的顶点。由于这四条路径必须内部点不相交，而 `T3` 以及 `T4` 仅包含三个顶点，这是不可能的。

因此，任意的三角形 `Ti` `1 ≤ i ≤ 5` 在 `H` 中都不能恰好包含一个或两个度数为 7 的顶点。从而，任意的三角形 `Ti` `1 ≤ i ≤ 5` 在 `H` 中也不能恰好包含三个度数为 7 的顶点。因此，正如所述，`G` 不包含 `K8` 的细分。于是，图 `G` 是 Hajós 猜想对于 `k = 8` 的反例。

设 `k` 为整数且 `k ≥ 9`，考虑图 `F = G ∨ Kk-8`。则 `χ(F) = k`。我们声称 `F` 不包含 `Kk` 的细分。假设 `H` 是 `F` 中的一个这样的子图。删除属于 `H` 的所有 `Kk-8` 中的顶点，得到 `G` 的一个子图 `H'`。这说明 `H'` 包含 `K8` 的细分，这是不可能的。因此，Hajós 的猜想对于所有整数 `k ≥ 8` 都是错误的。如前所述，Catlin 证明了该猜想对于每个整数 `k ≥ 7` 都是错误的 参见练习 9。

回忆一下，如果对于 `G` 的每个诱导子图 `H` 都有 `χ(H) = ω(H)`，则称图 `G` 为完美图。此外，对于图 `G` 及其顶点 `v`，`G` 的复制图 `Rv(G)` 是通过向 `G` 添加一个新顶点 `v'` 并将 `v'` 与 `v` 的闭邻域 `N[v]` 中的每个顶点相连而得到的图。我们在定理 15.9 中看到，如果 `G` 是完美图，则对于每个 `v ∈ V(G)`，`Rv(G)` 都是完美图。Carsten Thomassen [235] 证明了完美图与 Hajós 的猜想之间存在联系。

**定理 16.8** 图 `G` 是完美图当且仅当 `G` 的每个复制图都满足 Hajós 猜想。

### Hadwiger 猜想

此外，回顾一下，如果图 `H` 可以通过对图 `G` 进行一系列收缩、边删除和顶点删除 顺序任意 而得到，则称 `H` 是 `G` 的 minor 小图。而且，根据定理 10.19，如果图 `G` 包含图 `H` 的细分 subdivision，则 `H` 是 `G` 的 minor。特别地，如果一个 `k`-色图 `G` 包含 `Kk` 的细分，则 `Kk` 是 `G` 的 minor。当然，我们已看到对于 `k ≥ 7`，`k`-色图未必包含 `Kk` 的细分。然而，这并不意味着 `k`-色图不能包含 `Kk` 作为其 minor。事实上，早在 Hajós 猜想提出之前，1942年12月15日，Hugo Hadwiger 在瑞士苏黎世大学的一次讲座中提出了以下猜想。

**Hadwiger 猜想** 每个 `k`-色图都包含 `Kk` 作为其 minor。
