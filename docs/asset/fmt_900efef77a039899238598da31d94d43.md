# 1906型呼吸器

“外部”呼吸器更适用于有机体与其环境之间 `$O_2$` 和 `$CO_2$` 的交换。在多细胞生物和几乎所有的脊椎动物中（除少数缺乏肺和鳃的蝾螈外），体外呼吸发生在特殊的呼吸结构中，例如鳃或皮肤。见[肺]；[呼吸系统]。

引起导致跨组织气体运动的最终过程受限于扩散。呼吸气体交换发生在两个表面：第一是向外部介质（空气或水）呼吸交换表面的运输；第二是氧气通过血液跨越内部呼吸表面的运输。两者统称为通风（ventilation）和灌注（perfusion）。这一切都是通过肌肉活动驱动的压力实现的。

在所有脊椎动物和许多无脊椎动物中，循环介质（血淋、血红蛋白或血液）运输氧气，例如血红蛋白或血血蓝蛋白。各种呼吸色素通过增加血液的运输能力以及影响跨气体交换表面的气体压力（浓度）梯度来增强气体交换。见[血液]；[膜倒置]。

对环境变化以及产出的代谢能量需求的生理调节调节着氧气交换和运输的变化。这些调节通过呼吸系统的快速通风以及呼吸表面和血液的长期改变来实现。

**呼吸器**。一种旨在保护佩戴者免受有害气体、蒸汽和气溶胶伤害，或向佩戴者提供氧气或药物剂的设备。呼吸器用于工业以保护暴露于有害气溶胶的工人，用于军事以防止化学、生物或放射性剂的影响。呼吸器的设计各不相同，分为大气净化式和供气式。

大气净化呼吸器用于氧气不足或对佩戴者健康极其危险的大气。这些可以用于矿井、建筑、地堡和其他封闭环境。自给式呼吸器（`SCBA`）是一个配合空气或氧气供应使用的完全自给的装置。封闭式呼吸器配备与 `SCBA` 相同的各种面具，但这些面具可以通过面罩和风机向面具供气——面罩来自带有压力气流和调节设备的压缩气源——即气管式面具。在大气净化呼吸器中，空气通过过滤器以去除污染物。这些设备不提供氧气，也不防止氧气缺乏或低压环境。一种广泛使用的大气净化呼吸器是面罩过滤器式，其可更换的滤通过排气阀排出。正压呼吸器通过由皮带或头盔式风扇驱动的风机强制空气通过过滤器并在压力下供应给佩戴者，最大限度地减少了面具周围的泄漏问题。

**呼吸色素**（无脊椎动物）。与氧气可逆结合的金属蛋白，存在于无脊椎动物的体液或组织中。这些色素的动物体功能主要是增加分子氧的运输。它们与参与消耗氧的呼吸色素区别开。

无脊椎动物中存在四类不同的呼吸色素：血红蛋白（红色，结合氧气）、血蓝蛋白（绿色、蓝色，结合氧气）和血红蛋白（无色，结合氧气）。

每种色素由两部分组成：结合一个或多个小型辅基的大型蛋白分子，每个辅基负责运输，且这种结合赋予了色素的颜色。在血红蛋白中，呼吸色素是一种称为血红蛋白的铁蛋白。铬蓝蛋白含有类似的铁蛋白，与血红蛋白的区别在于铁原子被铜取代了。

在缺乏色素的情况下，血红蛋白类似于由两个多肽亚基组成的结构，这些亚基在体内是不稳定的，但它们不能与氧气发生可逆结合。

呼吸色素取决于与氧气的结合。在缺乏金属的情况下，辅基蛋白失去有效携带氧气的能力。尽管如此，金属由于溶解而失活。
