## 总结

现在您已经拥有了 Linux 版本的 IDS，可以用它做什么呢？首先，您可以将任何符合 ODBC 标准的用户界面连接到服务器，并立即开始开发应用程序以及将应用程序连接到数据库引擎。您可以使用 ODBC、JDBC 和 I-connect 网络连接直接创建并/连接 Web 应用程序和客户端到引擎。应用程序范围仅限于您的想象力。

Informix IDS 7.3x 是一个非常强大的 SQL 数据库引擎，具备企业级数据库服务器所需的所有功能。该服务器能够处理涉及低速率和高速率访问的各种数据存储和检索操作，具有极高的可靠性和健壮性。当今最快的数据库服务器之一是 UNIX 上的 Informix 数据库服务器。Informix 的性能优于其他供应商的竞争服务器，并继续保持领先。Linux 版本的 IDS 在内部上与其他 UNIX 平台并无异；您将面临的唯一限制是当前的 Linux 内核和您的硬件平台。

IDS 7.3 可以从 1 个到 N 个用户进行扩展，唯一的限制当然是您的硬件。您可以在 Linux 版本中学习 UNIX 版本，例外是高性能加载器 `loader` 和原始磁盘 `raw disks`，在本文编写时尚未不可。IDS 在某种程度上与标准引擎（Standard Engine）兼容，但仅限于核心功能。标准引擎比 IDS 中的共享内存引擎更少，数据类型也更少。标准引擎是一个被动的、基于 isam 的引擎。SE 具有高可靠性，但功能不如 IDS 引擎的一些高级功能。你会发现 SE 与 IDS 的对比，就像螺旋桨飞机与配备喷气发动机的喷气式飞机对比一样。两者都是有效的飞行器，且各有其用途。

如果您已经准备好了环境，总安装时间可以快至两小时，或者取决于您未准备好的部分。阅读《管理员指南》对您来说非常重要，以便熟悉您可以在引擎上实施的各种设置和控制。
