# 从名称服务器

区域的从名称服务器从主名称服务器读取该区域的数据，并对该区域具有权威性。从服务器的目的是与主服务器分担负载或在主服务器宕时处理整个负载。此过程称为区域传输（zone transfer）。

从互联网获取 db.cache 文件后，不要忘记将其到您安装 DNS 服务器的服务器上的 `/var/named/` 目录。

设置从名称服务器所需的文件有：

- `named.conf`
- `db.127.0.0`
- `db.cache`
- `named script`
