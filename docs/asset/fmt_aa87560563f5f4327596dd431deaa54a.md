
# 电离层

电离层：大气层上层中充分电离的部分，其自由电子浓度影响无线电波的传播。电离层的存在于1902年由英国的 O. Heaviside 和美国的 A. Appleton 同时提出。

铁和其他的其他用途。与铁蛋白结合形成铁蛋白，当细胞在3-5天的生命周期后脱落时使用。肌肉细胞丢弃和同化的机制尚不清楚。

铁有几种同素异构体形式。铁素体或α铁在760°C（1400°F）以下保持稳定。变为β铁涉及从体六角形到面心立方晶格的磁重排。未改变的γ铁具有原子的立方密堆积排列，在910到1400°C（1670至2552°F）之间稳定。铁在1400°C（2600°F）以上也稳定，并具有与铁类似的晶格。

一旦铁与铁蛋白结合，它就会血液中循环，直到转移到红细胞。结合后，转移受体复合体进入内吞，铁被还原为铁。转移受体复合体随后释放铁，铁进入线粒体并在铁螯合酶的作用下插入原卟啉中，形成血红蛋白，血红蛋白与珠蛋白蛋白结合形成呼吸色素。

这种金属是一种良好的反应性剂，取决于条件，它可以被氧化为2+、3+或6+状态。在铁化合物中，仅存在亚铁离子。大多数铁化合物呈浅黄色至绿棕色；水化铁`Fe(OH)₂`不溶于水；在溶液中很浅。铁形成配合物的倾向很，除非与酸、聚合物和卟啉等强试剂结合。铁由于其高电荷密度，很容易水合。离子`[Fe(H₂O)₆]²²`与`OH⁻`、`F⁻`、`CN⁻`、`SO²⁻`等反应形成配合物。参见氧化反应。

除非铁与血红蛋白结合，否则红细胞无法吸收氧气。血红蛋白被血红蛋白氧化酶分解。60%的铁返回并产生红细胞，其余部分留在铁蛋白中作为释放池，或被其他组织吸收而不用于形成血红蛋白。铁储存在血铁蛋白中，形成颗粒状氧化铁/氢氧化物球（血铁蛋白）。

铁的一个有趣方面是它与碳成键化合物的化学。铁茂烷是许多有机化合物的成分。这些铁金属配合物非常稳定，与其它铁化合物相比并不特别敏感。这种铁配合物是独特的。

## 岛屿地理

动植物在岛屿上的分布。岛屿拥有最多的特有种。许多岛屿上的生命处于孤立种群状态，面临新环境，导致进化出与其大陆祖先截然不同的物种。

植物物种产生种子、果实，通过风、水、羽毛以及鸟兽的漂浮足迹进行传播。动物的扩散概率较低，但动物也可以通过风暴和洋流进行远距离迁移。远距离扩散充当了过滤器，决定了岛链的初始组成。

许多起源于大陆的物种可能到达岛屿；因此，岛屿物种最多，但岛屿上的物种密度（单位面积物种数）低于面积相当的区域。种群扩散。
