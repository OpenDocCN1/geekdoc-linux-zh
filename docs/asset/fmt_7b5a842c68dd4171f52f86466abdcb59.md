`cont`（继续）命令导致进程从上次停止的地方继续运行。`testtab` 仅包含一行；进程执行完毕，结果显示在屏幕上。调试器报告程序的退出代码。在程序执行完毕后给出 `cont` 命令会提醒你程序执行已完成。随后，调试话通过 `quit` 命令结束：

```
(gdb) cont

Continuing.

  abc xyz

Program exited normally.

(gdb) cont

The program is not being run.

(gdb) quit

$ 
```
