
- 将现有的服务从 `/etc/services` 备份到 `/etc/services.orig`
- 从 `examples/Nassau/services` 拷贝 `services` 文件到 `/etc/services`
- 创建一个新文件 `/etc/rrpasswd`——内容为你当前的 BPC 密码
- 如下所示更改 `PATH` 环境变量：`PATH=$PATH:/usr/local/bin ; export PATH` （这可能不是必要的）
- 按照以下方式登录 BPC：`rrclientd -u <username> /etc/rrpasswd dce-server`
  如果你的用户名是 `jsmith`：`rrclientd -u jsmith /etc/rrpasswd dce-server`

如果执行成功，你将在 `/var/log/messages` 中看到指示操作正常的消息。`tail /var/log/messages` 将显示文件的末尾。

- 输入 `rrclientd -k` 退出 BPC。
- 要实现自动化——你需要设置 `PATH` 并在每次系统启动时调用 `rrclientd`。
