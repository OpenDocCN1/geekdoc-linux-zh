### 4.2.10-Can-I-set-32-bit-hard-drive-I/O?

`I-know-nothing-about-hardrives,but-saw-a-review-of-RedHat-6.0-by-Edward-Choh(http://hardwarezone.com.sg/main.htm),in-which-he-gave-some-interesting-tips-including-setting-up-32-bit-input/output(I/O)-and-direct-memory-access(DMA)`. `I-tried,and-it-worked-fine-for-me`. `Be-warned-that-it-can-possibly-harm-your-harddriv-not-do-it-if-you-are-a-real-newbie,don't-feel-geeky-today,or-have-heart`.

`The-turning-on-32-bit-I/O-and-DMA-has-to-be-done,and-I-did-it-in-single-user-mode(to-minimize-the-damage-to-the-filesystem-if-something-went-wrong-and-I-had-to-reboot)`. `I-definitely-would-not-do-it-in-a-system-currently-running-many-programs-or-X-windows,and-would-have-backup-of-any-data`.

`To-boot-your-computer-in-single-user-mode,type-this-at-the-lilo-prompt(during-bootup)`

```
linux single
```

`Enable-32-bit-I/O-on-my-first-IDE-harddrive-which-is-"hda".First,time-the-harddrive-performance-and-note-the-score`

```
hdparm -t /dev/hda
```

`Now,display-my-current-I/O-and-DMA-settings`

```
hdparm -c /hda
```

`(my-system-showed-0,meaning-that-32-bit-I/O-is-turned-off-and-the-default-16-bit-access-is-used)`

```
hdparm -d /hda
```

`(my-system-showed-0-again,meaning-that-the-harddrive-DMA-access-is-turned-off)`.

`Now,turn-on-32-bit-I/O-and-DMA`

```
hdparm -c 1 /hda
hdparm -d 1 /hda
```

`Now,I-can-time-the-performance-of-the-harddrive-again-to-compare-the-score-with-the-original-one`

```
hdparm -t /hda
```

`If-everything-worked-ok,and-the-performance-has-improved,I-can-"commit"-the-new-settings-so-they-can-survive-a-soft-reset`

```
hdparm -k 1 /hda
```

`To-have-the-new-settings-in-effect-every-time-you-reboot-the-machine,you-may-add-a-line-at-the-end-of-the-file-`/etc/rc.d/rc.local`(this-file-is-something-like-AUTOEXEC.BAT-in-DOS)`

```
hdparm -c 1 -d -k 1 /hda
```

`If-something-did-not-work-as-expected,or-the-performance-did-not-really-improve,I-can-reboot-at-any-time-and-the-old-settings-will-be-in-effect-as-long-as-I-did-not-perform-the-last-operation`.

`-performed-this-tune-up-on-4-hard-drives-on-our-home-network`. `It-was-a-success-on-3-newer-hardrives;the-performance-improved-by-30-300%-and-at-least-one-computer-"feels"-faster-than-before`. `One-harddrive(which-is-always-flaky)-hung-the-computer-hard-during-the-performance-test-and-I-had-to-reset-the-machine(no-damage-done)`.
