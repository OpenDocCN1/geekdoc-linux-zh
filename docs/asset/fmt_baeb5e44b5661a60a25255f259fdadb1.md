
login: 已连接关闭

1. 来自你本地机器标准输入的任何数据都将作为远程机器命令的输入。
2. 远程机器的任何输出都将作为标准输出传递到本地机器。
3. 这共同使得远程命令看起来实际上是在你的本地系统上执行的。
4. 如果你没有向 `rsh` 传递任何命令，它将像你使用 `login` 一样登录。

## 14.8.3 远程访问命令：login

你可以使用 `login` 命令登录到远程主机。`login` 命令的工作原理类似于 `telnet`。然而，它使用了不同的协议。例如，以下命令序列将你登录到名为 `unix3.university.edu` 的远程系统。`-l` 告诉 `login` 以名为 `david` 的用户登录。默认情况下，使用使用 `login` 的用户名。

```
$ login -l david unix3.university.edu
. 以 david 登录到 unix3.university.edu。

password: . 已连接。输入你的密码。
远程系统的提示。

$ whoami . 你可以在此 shell 上运行任何命令。

david. . whoami 的输出。

$ exit . 远程系统的提示。
关闭连接。

login: 连接关闭 . 本地系统的提示。
```

### Emacs 模式行（Mode Line）字段

**模式行**出现在回行（echo line）的正上方，是屏幕上倒数第二行。模式行显示状态信息，例如缓冲区是否正在显示、在使用哪些主模式和子模式，以及缓冲区是否包含未保存的更改。通常，模式行如下所示，并由几个字段组成：

| 字段符号 | 描述 |
| :--- | :--- |
| - | 缓冲区未被编辑 |
| %+ | 只读缓冲区已编辑 |
| %% | 只读缓冲区未被编辑 |
| buffer / filename major mode | 缓冲区 /文件名 主模式 |
| All | 显示整个缓冲区 |
| Top | 缓冲区开头 |
| Bot | 缓冲区结束 |
| NN% | 缓冲区上方占百分比 % |
| | 窗口顶部 |
| | 行号 |

示例：`- - : - - Example <Fundamental> | - L4--- ALL - - - - - - - -`
