# samba-server

Samba-server 提供一个 SMB 服务器，可向 SMB（有时称为“Lan Manager”）客户端提供网络服务。Samba 在 TCP/IP (NetBT) 之上使用 NetBIOS (NetBT) 协议，并且不需要 NetBIOS。工作的 NT 域控制能力允许启用 SWAT（Web 管理工具），允许使用你喜欢的 Web 浏览器远程管理 samba 的配置文件。

目前通过 xneted 在 TCP 端口 901 上启用此功能。SWAT 现在包含在其子包 `samba-swat` 中。其他版本用于在没有 Windows 域控制器的网络上将 Samba-2.2 作为 Windows NT4 域控制器使用。此版本尚未具备备份域控制能力。请参阅 `WHATNEWS.txt` 文档获取更多信息。此二进制包含加密密码支持。请阅读文档中的 `smb.conf` 文件和 `ENCRYPTION.txt` 的实现细节。来自 Mandrake 9.0 RPM

沙箱（sandbox）是一种运行程序的模式，防止其完全访问系统的其余部分。对于像 Java 这样的移动代码尤为重要。如果在沙箱中运行的代码不会损坏系统，客户端就可以信任从网站自动下载的代码。

关键点：沙箱更多且更常用于服务器。这在不同组件之间建立了屏障，有助于阻止（或减慢）已进入系统一部分的入侵者。最重要的技术是以用户账户运行服务，而不是管理员/root 账户。

例如，微软的 IIS 创建了一个名为（IUSR_XXXX，XXXX 为名称）的特殊用户账户，Web 服务器以此运行。当有人入侵 Web 服务器时，他们仍然无法控制整个系统（除非他们运行某种本地漏洞来跳出此沙箱）。

# sash

Sash 是一个简单的静态链接 shell，包含了 `ls`、`dd` 和 `gash` 等内置命令的简化版本。Sash 是静态链接的，因此它可以在没有共享库的情况下工作，这对于从某些类型的系统故障中恢复特别有用。Sash 还可以用于安全地升级到新版本的共享库。来自 Mandrake 9.0 RPM http://www.tld.org/LDP/Linux-Dictionary/html/index
