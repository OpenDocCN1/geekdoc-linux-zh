## 前言

这本书诞生于 20 世纪 90 年代后期，最初作为一份实验室手册，用于补充我 Linux 工作讨会的其他材料。它不断成长、演变，并有了自己的生命。最终，它取代了其他工作讨会材料，自成了一本完整的练习册。

我在工作中同时使用 Windows 和 Linux。我对操作系统并不热情。我更倾向于将激情留给家庭、音乐、剧院、体育、食物和生活。我将操作系统视为完成任务的工具。我不会对铲子产生热情，为什么又应该对操作系统产生热情呢？
