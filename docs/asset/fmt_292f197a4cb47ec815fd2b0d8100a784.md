
# Linux 从零构建指南

![](img/5d380cfe124be661028a03d22e6e9695_0_0.png)

## 产品描述

Linux From Scratch 描述了如何从已安装的 Linux 发行版开始，仅使用所需的软件源代码，从零开始创建自己的 Linux 系统的过程。

作者引言：

“在使用过许多不同的 Linux 发行版后……

这个在当时看来非常疯狂的想法似乎非常困难，有时几乎是不可能的。大多数问题的原因在于我对某些程序和步骤缺乏了解。在处理了各种依赖问题、编译问题等之后，一个手动构建的 Linux 系统被创建并完全运行。我将这个系统称为 LFS 系统，代表 Linux From Scratch（从零构建 Linux）。”
