# 添加更多帧以实现额外的相机运动

现在，假设你想为当前动画添加一些额外的相机运动。尽管看起来你已经用了环绕建筑之旅的所有可用帧，但你仍然可以在帧段的开头或结尾添加额外的帧。

## 在帧段末尾添加帧

在帧段末尾添加帧是一个相当的操作。方法如下：

1. 点击用户界面底部的`“时间配置”`（`Time Configuration`）工具。
2. 在`“时间配置”`对话框中，在动画组的`“长度”`（`Length`）输入框内输入 `400`；然后点击确定。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_662_1.png)

注意时间滑块的变化。位置 `300` 出现在时间滑块左侧约四分之三处，总帧数显示为 `400`。

虽然你为动画添加了更多帧，但额外的帧对现有帧没有影响。相机路径中的帧数没有改变。你只是在动画的末尾添加了更多帧。这些额外帧尚未被利用。

现在让我们使用这些额外帧：

1. 将时间滑块一直向右移动，直到显示为 `400/400`。
2. 将相机移动到图 13.16 所示的位置。
