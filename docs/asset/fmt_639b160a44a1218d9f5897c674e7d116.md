
# 第 7 章

## 欢迎来到命令行

`mv` 命令将文件移动到另一个位置或重命名文件。示例如下：`mv file foo` 将原始文件重命名为 `foo`。`mv foo ~/Desktop` 将 `foo` 移动到你的桌面目录但不会重命名它。重命名文件时必须指定新文件名。使用 `mv` 后，原始文件将不再存在；如果是移动，则该文件将继续存在并创建一个新副本。

为了减少输入量，你可以用 `~` 代替主目录，因此 `~/home/username/pictures` 与 `~/pictures` 是相同的。

> 如果你配合 `sudo` 使用（这在主目录之外通常是必要的），将无法使用 `~` 快捷方式。相反，你必须使用文件的完整路径。

`rm` 使用此命令移除或删除目录中的文件，例如 `rm file.txt`。它对包含文件的目录不起，这些目录必须清空并可以使用 `rmdir` 命令删除。在某些高级情况下，你可能可以使用 `rm` 来删除目录，但讨论这些内容超出了本章的范围。

`ls` 命令显示当前目录下的文件。配合选项使用时，它可以查看文件大小、创建时间和文件权限。例如，`ls ~` 会显示你主目录中的文件。

`mkdir` 命令允许你创建目录。例如，`mkdir music` 会创建一个名为 `music` 的目录。

`chmod` 命令更改列出文件的权限。权限基于一个相当简单的模型。你可以为用户、组和所有人设置权限，并指定每种身份是否可以读取、写入和或执行文件。例如，如果允许所有人读取一个文件但只有用户可以写入该文件，则权限将为 `rw-xr-r--`。要添加或删除权限，可以在特定权限前加上加号 (`+`) 减号 (`-`)。例如，要允许组编辑上例中的文件，你可以输入 `chmod g+w file`。

`chown` 命令允许用户更改文件的所有者和用户组所有权。例如，`sudo chown jim file` 将文件的所有权更改为 `jim`。

## 系统信息命令

系统信息命令包括以下：

`df` 命令显示所有分区的文件系统磁盘空间使用情况。`df -h` 可能是最有用的。它使用兆字节 (M) 和千字节 (G) 而不是块来报告（`-h` 表示“人类可读”）。

`free` 命令显示系统中空闲和已用内存量。例如，`free -m` 使用兆字节提供信息，这对于目前的计算机可能最有用。

`top` 命令显示你的 Linux 系统、运行中的进程和系统资源的信息，包括 CPU、RAM、交换分区使用情况以及正在运行的任务总数。要退出 `top`，请按 `Q`。

`uname -a` 带有 `-a` 选项的 `uname` 命令打印所有系统信息，包括机器名称、内核名称、版本以及其他细节。此命令对于检查你正在运行哪个内核最有用。

`lsb_release -a` 带有 `-a` 选项的 `lsb_release` 命令打印你正在运行的 Linux发行版本信息。例如：

```
username@computer:~$ lsb_release -a
```

无 LSB 模块可用。

Distributor ID: Ubuntu

Description: Ubuntu 16.04 LTS

Release: 16.04

Codename: xenial

`ifconfig` 命令报告系统的网络接口情况。

`iwconfig` 命令显示任何无线网络适配器及其特定的无线信息，如速度和网络连接状态。

`ps` 命令允许你查看机器上运行的所有进程。

以下命令列出了你计算机上的硬件，可以是特定类型或通过特定方法。当硬件工作不正常时，它们对于调试最有用。

`lspci` 命令列出所有 PCI 总线及其连接设备。这通常包括网卡和声卡。

`lsusb` 命令列出所有 USB 总线上任何连接的 USB 设备，如打印机和优存盘。

`lhal` 命令列出硬件抽象层 (HAL) 知知的设备，这应该是系统中的大部分硬件。

## 搜索和编辑文本文件

使用以下命令搜索和编辑文本文件。

`grep` 命令允许你在许多文件中搜索特定的搜索模式并打印匹配的行。例如，`grep blah file` 将在文件中搜索 "blah" 文字并打印匹配的行。

`sed`（或流编辑器）命令允许你在文件中搜索并替换特定字符串。例如，如果你想在名为 `pets` 的文件中找到字符串 "cat" 并将其所有出现处都替换为 "dog"，请输入 `sed s/cat/dog/g pets`。相比之下，输入 `sed s/cat/dog/ pets`（在最后一个斜杠后不加 "g"）将只会替换 `pets` 文件中第一个 "cat" 单词。

`grep` 和 `sed` 都是极其强大的程序。有很多优秀的教程解释如何使用它们，但这里有几个好的网站可以帮助你入门：

- `https://wiki.example.org/grep`
- `https://wiki.example.org/sed`

除了 `grep` 和 `sed`，`cat` 处理文件非常有用。

`cat` 命令是“连接”的缩写，用于查看和合并文件内容。

`nano` 是一个简单的命令行文本编辑器。要打开一个文件，使用 `nano filename`。

底部的命令可以通过按 `Ctrl+X` 访问。

## 处理用户和组

你可以使用以下命令管理用户和组。

`adduser` 命令创建一个新用户。要创建一个用户，只需输入 `sudo adduser username`。这会创建用户的家目录和默认组。它会提示密码以及关于用户的详细信息。

`passwd` 命令更改密码。如果由普通用户运行，将更改其密码。如果使用 `sudo` 运行它可以更改任何用户的密码。例如，`sudo passwd joe` 更改 `joe` 的密码。

`who` 命令告诉你谁登录了机器。

`addgroup` 命令添加一个组。要创建一个组，输入 `sudo addgroup groupname`。

`deluser` 命令从系统中删除用户。要删除用户的文件和主目录，你需要添加 `--home` 选项。

`delgroup` 命令从系统中删除一个组。你不能删除任何用户的用户主组。

`chgrp` 命令更改文件和目录的所有组。

## 获取命令行帮助

本节提供了一些在命令行获取帮助的技巧。`-help` 和 `man` 是命令行中两个最重要的工具。

几乎所有命令都理解 `-h`（或 `--help`）选项，该选项会产生命令及其选项的短期用法描述，然后返回命令行。尝试 `man -h` 或 `man --help` 来查看效果。

Linux 中的每个命令和几乎每个应用程序都有 `man`（手册）文件，因此找到此类文件只需输入 `man command` 即可显示指定命令的详细手册条目。例如，`man mv` 会显示 `mv`（移动）手册。

使用 `man` 命令的一些有用提示包括：

- 箭头键：使用箭头键在 `man` 文件中上下移动。
- `q`：通过输入 `q` 退出并返回命令行。
- `man man`：`man man` 会调出 `man` 命令的手册条目，这是一个很好的开始！

`man intro` 特别有用。它显示了《用户命令介绍》，这是一份关于 Linux 命令行编写得很好且相当简短的介绍。

还有 `info` 页面，它们通常比 `man` 页面提供更深入的信息。尝试运行 `info info` 来查看 `info` 页面的介绍。

## 查找 man 文件

如果你不确定需要使用哪种命令或应用程序，可以尝试搜索 `man` 文件。

`man -k foo` 这会在 `man` 文件中搜索 `foo`。尝试运行 `man -k nautilus` 看看它是如何工作的。

注意：`man -k foo` 等同于 `apropos` 命令。

`man -f foo` 这只搜索系统 `man` 文件的标题。例如，尝试运行 `man -f unity`。

注意：`man -f foo` 等同于 `what` 命令。

## 使用通配符

有时你需要同时查看或使用多个文件。例如，你可能想删除所有 `.rar` 文件或将所有 `.odt` 文件移动到另一个目录。坦率地说，你可以使用一系列通配符来完成此类任务。

`*` 匹配任意数量的字符。例如，`*.rar` 匹配任何以 `.rar` 结尾的文件。

`?` 匹配任意单个字符。例如，`?.rar` 匹配 `a.rar` 而不是 `ab.rar`。

## 执行多个命令

`[characters]` 匹配括号内的任意一个字符。`[ab].rar` 匹配 `a.rar` 和 `b.rar`，但不匹配 `c.rar`。
