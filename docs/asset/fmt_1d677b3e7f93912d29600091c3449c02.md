如果你使用的是 Microsoft 网络客户端：

*   如果没有域服务器验证你的密码，请检查网络属性并勾选“登录 Windows 域”。
*   如果现在可以登录了，问题解决了。
*   如果不是，故障排除失败（参见后续建议）。
*   如果网络中存在重复的计算机名，进入网络属性，点击“标识”选项卡，并输入不同的名称。

如果出现了其他问题，故障排除失败（参见后续建议）。

*   如果你看到了“网络名称无效或无法访问”的消息，进入网络属性并打开 Netware 客户端的属性。确保列出了正确的服务器。如有必要请咨询管理员。
*   没有域服务器验证你的密码。

*   如果网络没有执行本该执行的登录脚本，进入网络属性并打开 Netware 客户端的属性。确保勾选了“启用登录脚本处理”。如有必要请咨询管理员。

**我无法连接到特定的计算机。**

*   如果您在网络上找不到该计算机，则使用“查找计算机”（`Find Computer`）功能来查找它。
*   如果您找到了它，则：
    *   打开它。
    *   如果您可以查看其资源，您可能没有访问它的权限。
    *   否则，如果您无法查看其资源，它可能当前没有任何可用资源。
    *   否则，如果您没有找到它，它可能存在问题；请联系您的管理员。
*   如果您在网络上找到了该计算机，但无法查看共享资源，该计算机当前可能没有可用的共享资源。请联系您的管理员。
*   如果您可以查看共享资源，但无法连接到它们，您可能没有权限使用这些资源。请联系您的管理员。
*   否则，如果发生了其他问题，`TS` 失败（请参备注以获取更多建议）。

**我无法在我的电脑上共享文件夹或打印机。**

*   如果“网络属性”中有“文件和打印机共享”按钮，则：
    *   如果两个复框都没有勾选，勾选（激活）它们。
        *   如果您可以共享您的文件，您的问题已解决，退出 `TS`。
        *   否则，如果您仍然遇到问题，`TS` 失败。
    *   否则，如果该按钮不可用，您的网络不支持文件共享，或者该功能未启用（请寻求管理员帮助）。

**网络上的人员无法连接到我的共享资源。**

*   如果网络上的其他客户端可以在“网络邻域”中看到您，则：
    *   如果他们看到了正确的共享内容，您的计算机已启用共享（查看“网络属性”）。
    *   如果“文件和打印机共享”按钮可用，开启它。
    *   如果不起作用，`TS` 失败。
    *   如果“文件和打印机共享”按钮不可用，您的网络不支持文件共享，或者您的网络管理员尚未启用。
*   否则，如果其他网络客户端可以在“网络邻域”中看到您，则：
    *   如果“网络属性”中没有列出正确的客户端，进入“网络属性”并添加该客户端。
    *   如果列出了正确的客户端，则：
        *   如果没有列出正确的协议，进入“网络属性”并添加该协议。
        *   否则，如果列出了正确的协议，在“网络属性”窗口中，选择网络适配器、其属性，最后是它的“绑定”（`Bindings`）选项卡。确保勾选了正确的协议按钮。

**我无法设置网络适配器。**

*   如果您已经在电脑上设置了硬件，则：
    *   如果“设备管理器”报告了任何冲突，启动故障排除器（参见“帮助：查找”）并在之后重启。
    *   否则，如果没有报告，检查网络。
        *   如果网络上的计算机是可用的，您的问题已解决；退出故障排除器。
        *   否则，如果它们不可用，进入“网络属性”。
            *   如果您使用的正确的客户端，重启故障排除器。
            *   否则，如果列出了正确的客户端：
                *   如果您使用的正确的协议，重启故障排除器。
                *   否则，如果列出了正确的协议，进入“网络属性”并确保勾选了“登录 Windows NT 域”（`Log To Windows NT Domain`）。
                *   如果问题解决了，退出 `TS`。否则，`TS` 失败（请参备注以获取更多建议）。

备注：如果 `TS` 失败，请考虑网络可能原因：

*   网络上存在重复的计算机。
*   您忘记了密码。
*   发生了故障排除器未知的问题 —— 这可能与网络无关。

### 诊断 Linux 机器：保罗的故障排除器

你的 Linux 机器是你网络的基石。为了让任何程序运行，它必须经过正确设置。如果你仔细地遵循了第 1 章提供的安装说明，你的网络应该会运行得非常顺畅。如果它没有运行，或者你有一些不特殊的设置，你可以检查几种不同的原因。以下章节描述了你可以采取的几个步骤。将我在这些章节中提供的指南看作是保罗的故障排除器。

如果你的计算机上的网络无法工作，请将以下章节作为你可以遵循的简单树，来排除网络故障。我将这个故障排除器分为两个主要领域：`Linux` 网络和 `Samba`。这个故障排除器并不是全面的，但它确实涵盖我遇到的一些典型问题。
