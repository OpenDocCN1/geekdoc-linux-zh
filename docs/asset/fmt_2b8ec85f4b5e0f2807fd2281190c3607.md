# 推文页面

现在您可以在 `urls.py` 中添加以下内容：

```python
from django.urls import path, include

urlpatterns = [
    path('tweets/', include('twitter_stream.urls', namespace='twitter_stream')),
]
```

您还需要将其添加到 `settings.py` 中的 `INSTALLED_APPS` 中：

```python
INSTALLED_APPS = [

]
```
