# ELF: 可执行与链接格式. 第 9 章

节头表包含除 ELF 头部、程序头表和节头表本身以外的 ELF 文件中每个部分的信息。节头表是节头结构体的列表（或数组），它定义了 ELF 文件中不同的节。

ELF 头部包含节头表的偏移量（`e_section`）、节头的大小（`e_shentsize`）以及节的数量（`e_shnum`）。我们可以查看节头表中的节头信息：

```bash
readelf -S foo
```
