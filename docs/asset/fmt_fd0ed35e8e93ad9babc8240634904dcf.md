# 总结

概述

`Shellinbox` 是一个基于 `Web` 的工具，可以将 `SSH` 连接导出到仪表板。它允许通过浏览器管理多个 `SSH` 会话。

# 用户需求

`Shellinbox` 使用 `Web` 服务器，允许用户使用用户名和密码登录并通过浏览器访问其远程机器。

# 特性

`Shellinbox` 支持多个加密连接。必须安装 `SSL` 证书。
