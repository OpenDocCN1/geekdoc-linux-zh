# PEM

增强邮件 (PSRG, RFC 1421/1422/1424) 来自 VERA http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

PEM（仅具有历史意义），PEM 是加密/签名电子邮件的首标准。它后来演变为 S/MIME。对比：PEM 的核心组件影响了后来的标准，如 SSL。例如，某些 SSL 实现使用的后缀为 "pem" 的证书。对比：PEM 和 PGP 在电子邮件加密方面是相似的。主要区别是 PEM 基于 X.509 等 PKI 标准，而 PGP 使用更多即时技术。框架的基本区别是 PEM 使用 X.509 证书机构体系，而 PGP 使用更分布式的“信任网”。来自 Hacker-Lexicon http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
