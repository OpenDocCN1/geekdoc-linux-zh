
```
sudo openvpn --cd /etc/openvpn --daemon configfile.conf
```

`--cd` 选项指定不带路径的文件（如上例所示）所在的目录，`--daemon` 选项告诉 OpenVPN 如果守护进程可以正确启动，则从启动它的命令行环境中分离，`--config` 选项指定该连接的名称。
