## mv

![](img/6969df54e516231f8e64fd1177ac1127_1765_0.png)

`mv` - 重命名文件和目录。

一些常用的选项如下：

- `-i` 交互式移动，当发生文件名冲突时，系统会提示你确认是否覆盖现有文件。
- `-f` 如果发生文件名冲突，强制用移动的文件覆盖现有文件。

## rm - 删除文件和目录。

一些常用的选项如下：

- `-d`: 删除目录以及其他类型的文件。
- `-i`: 交互式删除，当删除现有文件时，系统会提示你确认是否要删除。
- `-f`: 强制删除文件。
- `-r` `-R`: 递归删除目录的内容以及目录本身。

![](img/6969df54e516231f8e64fd1177ac1127_1766_0.png)

## touch

`touch` - 修改文件的修改时间和/或最后访问时间，或创建一个文件。

一些常用的选项：

- `-c` 如果指定的文件不存在，则不创建。
- `-f` 无论权限如何，强制对文件进行 touch。

以下示例使用 `touch` 创建了 `file1`：

```
D:\> ls -l file1
ls:file: No such file or directory
```

```
D:\> touch file1
```

```
D:\> ls -l file1
-rw-rw-rw- 1 Administ Administist 0 Feb 20 11:45 file1
```

![](img/6969df54e516231f8e64fd1177ac1127_1767_0.png)

## wc

`wc` - 单词、行和字符的计数。

一些常用的选项如下：

- `-l` 打印文件的行数。
- `-w` 打印文件的单词数。
- `-c` 打印文件的字符数。

第一个示例列出了目录内容并将输出通过管道给 `wc`。第二个示例提供了关于 `system.ini` 文件的 `wc` 信息。
