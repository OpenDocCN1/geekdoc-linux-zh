# 转义字符

有时候我们只想对单个字符进行引用。为了这一点，我们可以在字符前面加一个反斜杠，这被称为转义字符。通常这位于双引号内部，以选择性地防止扩展：

```
[me@linuxbox~$] echo "The balance for user IS: \$5.00"
The balance for user is $5.00
```

通过转义来消除字符在文件名中的特殊含义也很常见。例如，在文件名可以使用通常对 shell 具有含义的字符。这些字符包括 s、!、&、空格等。若要在文件名中包含特殊字符，我们可以这样做：

```
[me@linuxbox~$] mv bad\filename good_filename
```

为了允许反斜杠出现，通过输入 `\` 进行转义。请注意，在单引号中，反斜杠会失去它的特殊含义，并被视为普通字符。
反斜杠的另一个用途是抑制别名。例如，如果 `ls` 命令被别名为 `ls='--color=auto'`（这是 Linux 发行版的默认设置），我们可以在命令前加一个反斜杠；别名将被忽略，`ls` 将不带颜色选项的情况下执行。

## 反斜杠转义序列

除了作为转义字符外，反斜杠还被用作表示某些称为控制代码的特殊字符的符号。ASCII 编码方案中的前 32 个字符用于向类似终端的打字机设备传输命令。其中一些代码是熟悉的（制表符、退格、换行和回车），而另一些则不是（空、传输结束和确认）。

表 7-2 列出了一些常见的反斜杠转义序列。

## 表 7-2：反斜杠转义序列

| 转义 | 含义 |
| :--- | :--- |
| \a | 响铃（一种导致电脑蜂响的警告）。 |
| \b | 退格。 |
| \n | 换行。在 Unix 类系统上，这产生换行符。 |
| \r | 回车。 |
| \t | 制表符。 |

使用反斜杠这种表示法源于 C 编程语言，已被许多其他语言采用，包括 shell。

在 `echo` 中添加 `-e` 将启用对转义序列的解释。你也可以将它们放在放在''` 内部。在这里，使用 `sleep` 命令，我们可以创建一个简单的程序，它只等待指定的秒数然后退出，一个原始的倒计时器：

```
sleep 10; echo -e "Time\'s up\a"
```

我们也可以这样做：

```
sleep 10; echo "Time\'s up" $\\\a'
```

随着我们继续学习 shell，我们会发现扩展和引用的使用频率会越来越高，因此很好地理解它们的工作原理是有意义的。事实上，可以认为它们是学习 shell 最重要的课题。如果对扩展没有适当的理解，shell 将永远是神秘和困惑的源头，其大部分潜力都被浪费了。

## 命令补全

shell 帮助我们的另一种方式是通过补全，当我们在输入命令时按下 TAB 键发生。让我们看看它是如何工作的。假设我们的主目录看起来如下：

```
[@linuxbox ~]$ ls
Desktop ls-output.txt Pictures Templates Videos
Documents Music Public
```

尝试输入以下内容，但不要按回车键（ENTER）：

```
[me@linuxbox ~]$ ls l
```

现在按下 TAB 键：

```
[me@linuxbox ~]$ ls ls-output.txt
```

看 shell 是如何为我们补全行的？让我们再试一个。同样，不要按回车键：

```
[me@linuxbox ~]$ ls D
```

按下 TAB 键：

```
[me@linuxbox ~]$ ls D
```

没有补全，什么都没有发生。这是因为 **\*** 匹配了目录中的多个条目。要成功成功补全，我们提供的“线索”必须是明确的。如果我们进一步输入，例如：

```
[me@linuxbox ~]$ ls Documents
```

然后按下 TAB 键，

```
[me@linuxbox ~]$ ls Documents
```
