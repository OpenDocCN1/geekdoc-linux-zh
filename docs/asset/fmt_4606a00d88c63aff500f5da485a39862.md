
# 电流测量

电流测量以流过电阻分流器两端出现的电压表示，已成为安培表最普遍的基础，主要因为它使非常宽的电流测量范围成为可能，以及最近与数字技术的兼容性。参见[电单位与标准](https://example.org/electric_units_and_standards)；[万用表](https://example.org/multimeter)；[伏特表](https://example.org/voltmeter)。

动圈、永磁体（d'Arsonval）安培表在直流测量中仍然很重要。通常它们的精度中等，不超过 1%。由于数字仪表在需要高分辨率时读数更容易，数字仪器已接管了所有更高精度的测量。

动铁仪表广泛用作低频交流应用的安培表。

高频电流通过电流流过物理上小型电阻元件的热效应来测量。在现代仪器中，导线中心的温度由热电偶感测，其输出用于驱动动圈指示器。参见[热电偶](https://example.org/thermocouple)。[R.B.D.K]

# 氨合物

氨分子与金属离子配位形成的一类复杂化合物中的一种，在少数情况下，如钙、锶和钡，与金属原子配位。虽然氨合物在许多方面形式上类似于许多水合物盐，但该类氨合物的总体特性与水合物有很大不同。例如，水合 Co(II) 盐是强氧化剂，而 Co(II) 氨合物是强还原剂。主要感兴趣的氨合物是过渡金属和锌族的氨合物，但即使在这里，稳定性或分解速率也有很大差异。氨合物是通过用氨处理金属盐水溶液或在某些情况下通过干燥的气态或液态氨作用于无水盐来制备的。参见[氨](https://example.org/ammonia)；[配位化学](https://example.org/coordination_chemistry)。[H.H.S]

# 氨

由氮和氢元素组成的最熟悉的化合物，NH$_3$。它由大多数含氮有机物的分解形成，其存在由其刺鼻和刺激性的气味表明。

氨具有广泛的工业和农业应用。其用途的例子包括硝酸和铵盐（特别是硫酸盐、硝酸盐、碳酸盐和氯化物）的生产，以及包括许多药物、塑料和染料在内的数百种有机化合物的合成。其稀水溶液用作家用清洁剂。无水氨和铵盐用作肥料，无水氨还因其高汽化热和相对容易液化而用作制冷剂。参见[肥料](https://example.org/fertilizer)。

氨的物理性质与水（water）和氢氟酸（hydrogen fluoride）类似，其物理常数相对于各自周期族中其他成员的二元氢化合物是不正常的。这些异常可能与分子通过分子间氢键结合有关。氨在液态下具有高度流动性，并具有较高的热膨胀系数。

氨的大部分化学反应可分为三个主要类别：(1) 加成反应，通常称为氨解；(2) 取代反应，通常称为氨解；(3) 氧化还原反应。

氨化反应包括氨分子与其他分子或离子加成的反应。氨化反应中最熟悉的是与水反应形成氢氧化铵。水和氨结合的强烈趋势体现在氨在水中的极高溶解度上。氨与强酸反应 readily 形成铵盐。固态弱酸的加成反应 readily 分解为氨和游离酸。加成也发生在各种能够充当电子受体的分子（Lewis 酸）上，如三氧化硫、二氧化硫、四氟化硅和三氟化硼。氨化反应包括与许多金属离子（特别是过渡金属离子）形成络合物（称为氨合物）的反应。氨解反应包括氨中酰胺基（$-NH_2$）、亚酰胺基（$>NH$）或氰基（$\equiv N$）取代反应分子中一个或多个原子或基团的反应。

氧化还原反应可分为涉及氮原子氧化态变化和释放元素氢的两类。第一类的一个例子是氨在空气中的催化氧化生成一氧化氮。在无催化剂存在的情况下，氨在氧气中燃烧产生热的氮气。另一个例子是用氨还原热的金属氧化物，如氧化铜。

液态氨的物理和化学性质使其适合作为某些类型化学反应的溶剂。液态氨的溶剂特性在许多情况下在质上介于水和乙醇之间。这在介电常数方面尤为正确；因此，氨通常是比乙醇更好的离子物质溶剂，但在这方面不如水。另一方面，氨通常比水是更好的共价物质溶剂。

哈伯-博世合成（Haber-Bosch synthesis）是工业氨的主要来源。在一个典型的过程中，水煤气（CO, H$_2$, CO$_2$）与氮气混合，通过洗涤冷却器以去除灰尘和未分解的物质。CO$_2$ 和 CO 分别通过 CO$_2$ 净化器和氨性硫酸铜溶液去除。剩余的 H$_2$ 和 N$_2$ 气体在高压（高达 1000 atm 或 100 兆帕）和高温（约 1300$^\circ$F 或 700$^\circ$C）下通过催化剂。氨的其他工业来源包括煤的干馏副产物，以及通过氰氨化物过程合成。在实验室中，氨通常通过强碱从铵盐（无论是干的还是溶液中的）中置换出来形成。另一个来源是金属氮化物的水解。参见[酰胺](https://example.org/amide)；[氮](https://example.org/nitrogen)。

# 铵盐

氨，NH$_3$，与各种酸反应的产物。形成的通用反应为 NH$_3$ + HX $\rightarrow$ NH$_4$X。铵盐的例子包括氯化铵，NH$_4$Cl，硝酸铵，NH$_4$NO$_3$，硫酸铵，(NH$_4$)$_2$SO$_4$，和碳酸铵，(NH$_4$)$_2$CO$_3$。这些化合物是氨和酸的加成产物。因此，它们的化学式有时写为 [H:NH$_3$HX]。所有铵盐在加热时分解为氨和酸。然而，它们的稳定性因酸的性质而异。弱酸盐在比强酸盐更低的温度下分解。

硝酸铵由氨和硝酸制备。它用作一氧化氮，N$_2$O，或笑气，的来源，并在炸药制造中使用。硝酸铵和三硝基甲苯的混合物被称为 amatol。

硫酸铵，由氨和硫酸获得，通过 commercially 制备，方法是让氨和二氧化碳，CO$_2$，通入细磨硫酸钙，CaSO$_4$ 的悬浮液中。大量硫酸铵也作为焦炭炉和煤气厂的副产物产生。硫酸铵的主要用途是作为肥料。

碳酸铵可以通过在 aqueous 溶液中使氨和二氧化碳结合来制备。也可以通过加热硫酸铵和细悬浮碳酸钙的混合物获得。参见[氨](https://example.org/ammonia)；[肥料](https://example.org/fertilizer)；[水解](https://example.org/hydrolysis)。[F.J.J.]

# 健忘症

一种显著但相对选择性记忆障碍。健忘症可以根据其发作沿两个维度描述：无法记住健忘症发作后发生的事件被称为顺行性健忘症，而无法记住健忘症发作前发生事件的缺陷被称为逆行性健忘症。

健忘症可能由各种原因引起，并可根据原因是主要神经学起源还是心理学起源进行分类。神经学健忘症是大脑功能障碍的结果，是暂时性或永久性的。它们通常以严重的顺行性健忘症和相对较轻的逆行性健忘症为特征。暂时性健忘症是暂时的记忆障碍，持续时间从几小时到几个月不等，取决于原因和严重程度。它们可能由癫痫、头部外伤和电休克疗法（最常用于治疗抑郁症）引起。在暂时性全面性健忘症的情况下，这是一种广泛的健忘症，通常是突然发作并在一天内解决；原因尚不清楚，尽管许多人认为它是血管起源的。

永久性健忘症通常发生在大脑损伤之后，累及间脑或内侧颞叶。由内侧颞叶损伤引起的健忘症可能发生在缺氧、脑血管意外、头部外伤和脑部病毒感染之后。内侧颞叶中参与记忆处理的主要结构是海马体和杏仁核。间脑健忘症最常见的原因之一是韦尼克-科尔萨科夫综合征（Wernicke-Korsakoff syndrome），这是一种由硫胺素缺乏引起的疾病，通常与慢性酒精中毒有关。

不与大脑损伤相关的记忆损伤被称为功能性健忘症。功能性健忘症可以根据健忘症是非病理性还是病理性进行分类。非病理性功能性健忘症是对婴儿期和幼儿期、睡眠、催眠和麻醉期间发生的事件的正常记忆丧失。病理性功能性健忘症是功能性逆行性健忘症和多重人格病例中发现的异常记忆丧失。与神经学健忘症相比，病理性功能性健忘症通常伴随比顺行性健忘症更严重的逆行性健忘症。参见[大脑](https://example.org/brain)；[记忆](https://example.org/memory)。[R.S.E.]

# 羊膜

一种薄的、细胞性的、胚胎外膜，在所有的爬行动物、鸟类和哺乳动物中形成一个包围胚胎的封闭囊。它仅存在于这些生物中；集合术语羊膜动物应用于这些动物。羊膜包含胚胎浸没其中的浆液。参见[羊膜动物](https://example.org/amniota)。

通常，羊膜壁是一层坚韧、透明、无神经且无血管的膜，由两层细胞组成，一层是内层的单细胞厚度外胚层上皮，另一层是外层的间质、结缔组织和特化的平滑肌组织。在羊膜形成早期，肌肉的收缩波会越过羊膜囊，产生胚胎特征性的摇摆。参见**胚层**。

羊膜及其液体的一项重要功能是为娇嫩的胚胎提供保护。因此，陆生动物的发育阶段所具备的防机械冲击的缓冲机制，与水生生物所处的水环境所提供的机制类似。参见**胎膜**。[N.T.S.]
