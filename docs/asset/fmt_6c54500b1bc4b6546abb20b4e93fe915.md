# dirproxy

为在不同工作站上使用 IRC 的人员提供的 IRC 代理。dirproxy 是一个 IRC 服务器，专为在许多不同工作站上使用 IRC 或希望连接并查看离开期间错过的内容的人而设计。通过 dirproxy 连接到 IRC，即使在你删除了客户端，它也会保持你与服务器的连接。在脱离状态下，它会记录频道和私信以及重要事件，当你重新挂上时，它会通知你错过了什么。这可以提供与使用 `screen` 一起使用大致相同的功能，你可以使用任何喜欢的 IRC 客户端，包括图形界面的！Debian 3.0

http://www.tldp.org/LDP/Linux-Dictionary/index.html

# 目录服务 (Directory Service)

目录类似于数据库，但倾向于包含更多描述性的、基于属性的信息。目录中的信息读取次数多于写入次数。因此，目录不利用数据库所使用的事务或回滚方案。目录更新通常是“全有或全无”的变化，如果允许的话话。来自 Linux Guide: Linux

http://www.tldp.org/LDP/Linux-Dictionary/index.html
