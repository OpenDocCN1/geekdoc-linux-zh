我如何运行 MS Windows 应用程序（使用“wine”）？
如果你需要 MS Windows 程序，你可能想要安装 Wine 来运行 MS Windows 应用程序。对于你电脑上的双启动（在另一个分区上安装 MS Windows）。

尽管如此，基于 Linux 的“wine”允许我执行某些 MS Windows 二进制文件，尽管会有严重的速度损失。在我的系统上（已安装 Wine），我通过在 X-windows 终端输入命令来运行 MS Solitaire：

```
wine /mnt/dos_hda1/windows/sol.exe
```

`/mnt/dos_hda1` 是包含 MS Windows 的硬盘分区的挂载点，并且已挂载。
