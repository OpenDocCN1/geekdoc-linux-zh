## 现实中的文件系统

对于大多数最常见的系统管理任务，接受文件和目录按树形结构排列就足够了。然而，计算机并不理解树或树形结构。

每个分区都有自己的文件系统。通过将所有这些文件系统想象在一起，我们可以对整个系统的树形结构有一个概念，但事实并不简单。在文件中，文件由一个 `inode`（索引节点）表示，这是一种包含构成文件的实际数据信息的序列号：该文件属于谁，以及它在硬盘上的位置。

每个分区都有自己的组 `inode`；在具有多个分区的系统中，文件可以具有相同的 `inode` 号。

每个 `inode` 描述硬盘上的一个数据结构，存储文件的属性，包括文件数据的物理位置。当硬盘被初始化以接受数据存储时（通常在初始安装过程中或向现有系统添加额外磁盘时），每个分区都会创建一个固定数量的 `inode`。这个数量是该分区上同时存在的所有类型文件（包括目录、特殊文件、链接等）的最大数量。我们通常每 2 到 8 千字节的存储计算 1 个 `inode`。

在创建新文件时，它会获得一个空闲的 `inode`。该 `inode` 包含以下信息：

- 文件所有者和组所有者。
- 文件类型（普通、目录、...）。
- 称为“访问权限：Linux 的第一道防线”的文件部分权限。
- 创建、最后读取和修改的日期与时间。
- `inode` 中发生更改的时间信息。
- 到此文件的链接数（见本章稍后部分）。
- 文件大小。
- 定义文件数据实际位置的地址。

在这个示例中，`inode` 不包含的唯一信息是文件名和目录。这些存储在特殊的目录文件中。通过比较文件名和 `inode` 号，系统可以为用户账户构建树形结构。用户可以使用 `ls` 的 `-i` 选项显示 `inode` 号。`inode` 在硬盘上有它们自己的独立空间。

## 文件系统中的导航

### 路径

当你想要系统执行一个命令时，你几乎不需要给出命令的完整路径。例如，我们知道命令在 `/bin` 目录中（使用 `ls -a` 检查），我们不需要输入命令 `/bin/ls` 就能让计算机列出当前目录的内容。

```
rogier:> echo $PATH
/opt/local/bin:/usr/bin:/usr/X11R6:/usr/sbin:/bin
```

在这个示例中，系统会在 `/opt/local/bin`、`/usr/X11R6`、`/usr/bin`、`/usr/sbin` 和 `/bin` 中搜索程序。一旦找到匹配，搜索就会停止，即使路径中的每个目录都没有被搜索。这可能会导致奇怪的情况。在第一个例子中，用户知道发送 `sendsms` 发送短信，同一系统上的另一个用户可以使用它，但不能。区别在于 `PATH` 变量的配置：

```
[jenny@blob login]$$ sendsms
bash: command not found
[jenny@blob login]$$ echo $PATH
/bin:/usr/bin:/usr/X11R6:/home/jenny/bin
[jenny@blob login]$$ su - tony
Password:
tony->:which sendsms
sendsms is /usr/local/bin/sendsms

tony->:echo $PATH
/home/tony.Linux:/home/tony:/usr/local/bin:/usr/local/sbin:/usr/X11R6/bin:/usr/bin:/usr/sbin:/bin
```

注意 `su`（切换用户）功能的使用，它允许你在另一个用户的环境中运行 shell，前提是你知道该用户的密码。

反斜杠 `\` 表示该行在下一行延续，而不需要用回车将两行分开。

在下一个示例中，用户想要调用 `wc`（字计数）命令来检查文件的行数，但什么都没有发生，他不得不使用 `Ctrl+C` 组合键中断：

```
jumper-> wc -l test

(Ctrl-C)
jumper-> which wc
wc is hashed /home/jumper/bin/wc
jumper-> echo $PATH
/home/jumper/bin:/usr/local/bin:/usr/sbin:/usr/X11R6/bin:/usr/bin:/usr/sbin:/bin:/sbin
```

`which` 命令的使用告诉我们该用户的主目录下有一个 `bin` 目录，其中包含一个也叫 `wc` 的程序。因为在搜索 `wc` 的路径时首先发现了他主目录中的程序，所以这个“主模式”程序被执行了，它可能无法理解，所以我们必须停止。要解决这个问题有几种方法（在 UNIX/Linux 中总有解决办法）：可以提醒用户使用 `wc` 程序，或者用户可以给出他想要的精确命令的完整路径，可以通过使用 `which` 命令的 `-a` 选项找到。

如果用户更频繁地使用目录中的程序，他可以更改路径以查看他自己的目录：

```
jumper-> export PATH=$home/jumper/bin:/usr/local/bin:/usr/sbin:/usr/X11R6/bin:/usr/bin:/usr/sbin:/bin
```

注意 `su`（切换用户）功能的使用，它允许你在另一个用户的环境中运行 shell，前提是你知道该用户的密码。

反斜杠 `\` 表示该行在下一行延续，而不需要用回车将两行分开。
