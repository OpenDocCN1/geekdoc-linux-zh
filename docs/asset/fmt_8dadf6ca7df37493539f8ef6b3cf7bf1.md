
# 蒸汽冷凝器

`蒸汽冷凝器`用于冷凝的热转换器。蒸汽具有独特的汽化潜热，与氨相当。蒸汽的比热相对较高，在实际温度下它可以携带比其他用途更多的热能。参见锅炉；波义定律；查尔斯定律；道顿定律；电；发电机；蒸汽加热；蒸汽涡轮机；热力学循环；动态参数。

该同步发电机由两部分组成：定子（固定）和转子（旋转）。定子由一个固定在框架上的叠层圆柱体和一个和一个由绝缘叠片制成的铁芯安装在轴上组成。铁芯在轴线上开有槽，在槽内放置了场绕组。定子经过电气绝缘。转子由一个锻造实心钢轴组成。绕组沿转子轴线方向绕周缘绕制，形成了转子体。

转子旋转。带有绕组的磁场成对排列（始终为偶数以减少谐波对磁场的影响）并连接到电刷。旋转磁场在定子中感应出电流。参见电磁感应。

# 2106 蒸汽机

发电器的输出与转子速度直接成正比，转子速度通过与蒸汽涡轮配套的调速系统保持恒定。交流电发电机：发电机。

同步发电机的尺寸从几千伏到 1,500,000 不等。蒸汽驱动的同步发电机运行速度为 3600 rpm 或 1800 rpm，或 50Hz。这些双极和四极发电机采用圆形结构；水力（水能）驱动和空气驱动的同步发电机运行速度较低，低达 62 rpm（11 个周期）。大型（大于 100,000 VA）发电机的定子输出在 13,800 V 到 27,000 V 之间。

热发电机的损耗少于定子电阻、转子电阻、铁芯电阻和摩擦损耗。消除与这些损耗相关的热量是机器设计的挑战。定子、转子线组和铁芯的冷却需求随负载增加而增加。早期的同步发电机是风冷的。需要空冷换热器来除去热量。

发动机可分为单作用或双作用，并根据相对于活塞运动方向分为水平式或垂直式。如果蒸汽先在一个气缸中完全膨胀，然后在第二个气缸中膨胀并释放部分初始能量，则发动机可能设计为双级或三级膨胀。

蒸汽机也可以根据功能制造，并在其应用要求最严苛的各种条件下运行。固定式蒸汽机发电机（启动扭矩很重要）、用于泵和压缩机（恒定扭矩是……）。

例如，蒸汽机转换为运动机构的机械能。蒸汽机可以利用来自蒸汽或锅炉的任何形式的热。大多数现代发动机具有活塞、环和阀门机构、活塞环、连杆、曲轴、调速器和齿轮等元件。

蒸汽机的主要工作是膨胀。蒸汽涡轮取代蒸汽机成为发电的原动机。内燃机燃烧任何类型的挥发性液体燃料（汽油或柴油），已用柴油机完全取代了蒸汽机，并用电机和螺旋桨取代了海洋蒸汽机。它还消除了航空领域的蒸汽动力。

典型的往复式发动机由一个配有活塞（1）的气缸组成。连杆和曲轴将活塞的往复运动转换为旋转运动。安装在曲轴上的飞轮使运动平滑。气缸的膨胀由作用在活塞面上的蒸汽压力控制。D 型滑阀允许高压蒸汽进入气缸并允许蒸汽排出（2）。产生的功率取决于每单位时间内吸入气缸的蒸汽压力和数量。
