## 圆满工作

轻松地下载、安装和更新程序

![](img/d35fa962e6f9664d66dc83916f426418_114_0.png)

Ubuntu 从一开始开始就安装了许多实用的程序——所谓的“开箱即用”。你有一个浏览器、一个电子邮件客户端、全全办公套件、音乐播放器、纸龙游戏……你还有什么想要的呢？嗯，无论默认安装中挤了多少内容，拥有选项总是好的。而 Ubuntu 的核心就在于选项。

Ubuntu 的软件安装方式与你习惯的的不同。在 Windows 上，你可能必须在网站上四处寻找一个 `.exe` 文件进行下载，或者去商店买一张刻有软件的 CD。然后你运行安装程序，在看似无止尽的选项和问题中不断点击，它才会决定开始安装你的新应用程序。在 Mac OS 上，你可能需要做类似的事情，尽管麻烦会少一点。

相反，Ubuntu 拥有“软件中心（Software Center）”——一个真正的你所有软件需求的一站式商店。不需要在线搜索下载内容，也不需要等待安装 CD 邮寄到达。更不需要告诉某个傲慢的安装程序你的鞋码和喜好的颜色。不，软件中心会为你完成一切，且事儿最少。在很多方面，它就像智能手机上的“应用商店”，你只需点击一下即可获取最新、最强大的应用程序。

这背后的引擎被称为“高级软件包工具（APT）”，它允许你轻松地下载、安装、更新和删除 DEB 归档或包。

`APT` 是一种非常可靠的程序安装方法；任何东西都不会丢失，因为 `APT` 会自动下载并安装你正在安装的应用程序运行所需的任何文件。寻找此类文件（被称为“依赖项（dependencies）”）曾是 Linux 用户的极大头疼问题。寻找并安装这个文件或那个文件，以及这些文件本身可能具有任何依赖的痛苦过程，导致缺失的依赖被称为“依赖地狱（dependency hell）”。`APT` 让这几乎成为了过去式。

那么，`APT` 在哪里找到所有这些文件和应用程序呢？`APT` 搜索、下载和安装的内容位于一组特定的仓库（repositories）中。这些仓库是在线服务器，我们在上面存储了许多应用程序、支持文件等，供你的系统使用。所有最初与系统捆绑的文件，包括系统本身（内核）和更新（在可用时），也存储在其中。

考虑这样一个问题：它是一个命令驱动的应用程序。这意味着你通过在 `Terminal` 中输入命令来控制它。这正是软件中心派上用场的地方它是 `APT` 的前端。广而言之，软件中心是 `APT` 的前端。在本章中，你将学习关于软件中心的所有知识，以及你可能会遇到的其他几个前端。

### Ubuntu 软件中心

图 6-2：在软件中心中浏览可用的游戏

对于大多数人来说，没有必要考虑这些技术项目，因此你可以点击窗口底部的 `Hide` 按钮将它们隐藏起来。如果你倾向于摆弄这类东西，在着手之前，你需要注意几点。这些项目中的许多实际上对你系统的日常运行非常重要，删除它们可能会产生一些负面影响。例如，有一个程序负责管理你的 Internet 连接；可能最好让它其自其妙。此外，许多技术项目是熟悉的应用程序，如网络浏览器和电子邮件客户端。因为移除该技术项目会导致依赖于它的所有内容一并移除。再次强调，这可能不是你想要的。如果它隐藏在“技术项目”列表中，你可能并不想卸载它。

关于 Ubuntu 的内部工作原理，目前就介绍到这里了。是时候做些实用的操作了。是时候体验一下软件中心了。

### 6A-1：选择要安装的应用程序

Ubuntu 软件中心可以同时安装多个应用程序，所以为了尝试一下，你可以尝试安装几个有趣的应用程序。让我们从选择一个非常酷且绝对实用的日记/日志应用 Rednotebook 开始（如图 6-3 所示）。如果你还没有进入该界面，点击工具栏上的 `All Software` 按钮返回软件中心的启动屏幕。然后选择 Rednotebook，点击列表左侧的 `Office` 类别以显示。将出现一个很长的可用应用程序列表，并按流行程度排序。嗯……Rednotebook 似乎并不在列表的最顶部。在整个列表中寻找它可能会很无聊，所以让我们换一种方式排序：从窗口右上角的下拉框中，选择 `By Name` 选项。这将使列表按字母顺序排列。向下滚动可用应用程序列表，直到你开始找到字母 R，然后双击 RedNotebook 项目。将显示一个包含有关 Rednotebook 信息的页面。你会发现它受到了其他用户的极推崇——五星中的四半星——而且完全免费下载。右侧还有它的图片，你可以对其放大。如果你继续向下滚动页面，你会发现几条信息，随后是一大堆评论。“目前最好的日记笔记本了，”Scott 说道。听起来不错。假设你也被这些赞誉有加评论说服了，你只需要点击 `Install` 并在提示时输入你的密码。这将开始安装。

将出现一个进度指示。安装完成后，页面将刷新，并在单词一词旁边显示一个绿色勾选图标，表示它已成功添加到你的计算机。如果你愿意，可以点击窗口底部出现的 Dash 启动器上的 `Add to Launcher`，将 Rednotebook 添加到启动器中。否则，进入 Dash 并搜索 Rednotebook 来启动程序。操作就大此了！

### 6A-2：搜索应用程序

接下来是 Sound Converter（我将在第 14 章中详细介绍如何使用此应用程序）。滚动程序列表可能会很无聊，所以这次使用搜索功能。点击工具栏上的 `All Software` 按钮返回主软件中心，然后在右上角的搜索框中输入 Sound Converter。搜索结果将立即开始出现。在你完成输入之前，Sound Converter 应该就会出现在结果列表的最顶部，因此点击它进行选择，然后点击 `Install`。安装将像以前一样开始——但这次，在程序仍在安装时点击 `All Software`。所有的安装魔力都将在后台继续，你仍然可以浏览其他程序。无需等待！

最后，让我们添加一个名为 Sysinfo 的有用实用程序（图 6-4），这是一个系统性能分析器，可以告诉你关于你计算机的各种信息。只需在搜索框中输入 `sysinfo`，点击点击出现的 `Sysinfo` 搜索结果，然后点击 `Install` 将其添加到安装队列中。一旦软件中心处理完 Sound Converter，它就会被安装。

### 6A-3：卸载应用程序

如你所见，通过软件中心安装应用程序非常简单。幸运的是，卸载它们也很容易。导航到（或搜索）你想删除的程序，在列表中点击它，然后点击出现的 `Remove` 按钮。如果提示，输入你的密码并看着程序被卸载。如果你想一次性卸载几个程序，可能点击工具栏上的 `Installed` 按钮遍历应用程序列表会更快。

### 6A-4：商业软件与免费软件

Ubuntu 的一个较新变化是可用软件可用。在早期，Linux 发行版如 Ubuntu 只包含免费软件——免费意味着“不收费”，也意味着“自由”。那是当时的方式——许多人分享他们编写的程序，通常出于兴趣，没有任何意图。在大多数情况下，目前仍然如此：大多数为 Linux 编写程序的软件开发者继续公开共享他们的应用。但最近，一些发行版开始引入商业开发者，他们对自己的产品收费。Ubuntu 就是其中之一。这种想法是大多数人习惯为软件付费，并没有因为开源属性就不喜欢有更多选择。免费应用将一直在那里，而且它们将占据大多数。
