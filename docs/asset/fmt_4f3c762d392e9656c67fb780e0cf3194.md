
# 油菜

油菜（*Brassica rapus*）和甜菜油菜（*B. campestri*）植物是十字花科的成员。其名称源自拉丁语 *rapum*，意为“芜菁”，这些植物与芜菁亲缘关系密切。油菜植物的地上部分被培育以生产油料、饲料和蔬菜作物。油菜籽小、圆，通常为黑色，但也种植种皮为黄色的品种。

## 稀土元素

种子含油率超过 40%。油菜籽提供全球约 10–12% 的可食用植物油供应，是少数可在加拿大北部、欧洲和亚洲生产，或作为冷季作物在亚热带地区生产的可食用油料作物之一。菜籽粕是榨油后的副产品，是 livestock 和家禽的高质量蛋白质饲料补充剂。在某些亚洲国家，它也被用作烟草和柑橘类水果等特种作物的肥料和土壤调理剂。油菜被广泛用作牧草。在一些国家，整株植物被割下并喂给牛。**参见 芜菁；油菜。** [R.K.D.]

## 裸藻纲

叶绿素 *a* + 藻胆素系（Chromophyta）中一小类知之甚少的双鞭毛单细胞藻类（裸藻类）纲。有时被称为绿球藻纲（Chloromonadophyceae），其成员被称为绿球藻，但这种命名令人困惑，因为它让人联想到 *Chloromonas*，这是一个与绿藻（Chlorophyceae）完全无关的属。此处使用的替代命名法源自裸藻（Raphidomonas），这是该纲内的一个属名。**参见 藻类纲（Chromophyceae）。** [T.Ba.]

承认有两个科。所有光合裸藻类被归入 Vacheaephaceae。Thauratomastigaceae 包括少数无色的形式，具有伪足。它们是渗透营养型或吞噬营养型，或两者兼有。两个科中的大多数属都出现在淡水（酸性至中性）中，但也有咸水和海洋形式会产生显著的藻华。例如，*Heterosisign* 是日本内海赤潮的常见原因。[PC.S.; R.L.MoE]

## 稀土元素

原子序数为 21、39 和 57–71 的 17 种化学元素的组。镧系元素这一名称保留用于 58–71 号元素。稀土这一名称是一个误称，因为它们既不稀有也不是土。**参见 锕系元素；镧系收缩；元素周期表。**

稀土的早期大多数用途利用了它们的共性，主要集中在玻璃、陶瓷、照明和冶金行业。如今，这些应用使用大量混合稀土，就像从矿物中获取的那样，尽管有时这些混合物会通过添加额外的铈或去除部分镧和铈部分来补充。这些元素表现出非常复杂的光谱，混合氧化物受热时会发出强烈的白光，类似于阳光，这种特性应用于有色碳弧中，如电影工业中使用的那些。稀土金属对非金属元素具有很强的亲和力，例如氢、碳、氮、氧、硫、磷和卤化物。相当数量的混合稀土被还原为金属，如钕铁硼混合金属，这些合金用于冶金工业。由铈和混合稀土制成的合金用于制造打火机火焰石。稀土也用作石油化工行业的催化剂。钇铝石榴石（YAG）在珠宝业中被用作人造钻石。尽管稀土在自然界中分布广泛，但通常浓度较低。它们以混合物的形式在许多矿物中以高浓度存在。不同稀土在各种岩石、地质构造和恒星中的相对丰度对地球物理学家、天体物理学家和宇宙学家来说极具吸引力。稀土元素是具有独特个体性质的金属。许多稀土金属和合金的性质对温度和压力非常敏感。它们沿不同晶轴测量时也不同

金属；例如，电导率、弹性常数等。稀土元素与羧酸盐、草酸盐和螯合剂形成复杂的盐。这些螯合物取代了离子周围的某些水，增强了各个稀土元素之间性质的差异。现代离子交换分离方法利用了这一技术。参见：螯合；离子交换；过渡元素。[IFH.Sp.]

## 稀土矿物

天然存在的固体，由地质过程形成，将稀土元素——镧系元素（原子序数 57–71）和钇（原子序数 39）——作为基本组成成分。在稀土矿物中，至少有一个晶体学位置含有镧系元素和钇的总原子比大于任何其他元素。矿物名称通常有一个后缀，称为 Levinson 修饰语，指示主导的稀土元素；例如，磷铈锶矿-(La) [LaPO₄] 主要含有镧，而磷铈锶矿-(Ce) [CePO₄] 主要含有铈。参见：矿物；磷铈锶矿；元素周期表；稀土元素。

到目前为止，已经描述了约 170 种不同的稀土矿物物种。大量的碳酸盐、磷酸盐、硅酸盐、钇酸盐和氟化物被称为稀土矿物。需要获取矿物的结构以及化学信息，才能判断其稀土元素的重要性（即稀土元素是矿物理想化学式的一部分，还是一种杂质）。有时，具有显著稀土含量的矿物被当作稀土矿物处理，即使其稀土元素含量对于该矿物来说似乎是多余的。包括磷灰石族矿物、石榴石族矿物和氟萤石在内的 60 多种矿物属于这一类别。参见：磷灰石；萤石；石榴石。

在火成岩中，稀土矿物可以作为伴生矿物被观察到，例如花岗岩中的磷铈锶矿-(Ce)。碳酸盐岩是稀土矿物（如氟碳铈矿-(Ce) [Ce(CO₃)F] 和磷铈锶矿-(Ce)）的典型寄主岩。稀土矿物也产于伟晶岩中。在碳酸盐岩和伟晶岩中，稀土元素通过熔体的初级结晶和热液反应富集。全球各地都发现了含有稀土元素的碳酸岩矿床。化学性质稳定的稀土矿物不易风化。因此，它们作为重矿物沉积在海滩砂中。这些矿床分布在东南亚和澳大利亚西部。参见：碳酸岩；伟晶岩。

在稀土矿物中，氟碳铈矿-(Ce) 是稀土元素最重要的来源。磷铈锶矿-(Ce)、辛地矿-(Ce) [Ca(CO₃)₂F]、氧化钇矿-(Y)、巴顿矿-(Ce) [Ce₂(Ca)₄(SiO₄)₃(OH)] 和褐帘石-(Ce) [CaCeAl₃Fe(AlO)₆(SiO₄)₃(OH)] 也是来源。稀土元素与含有放射性核素（如钍和铀）的矿物伴生出现，但并未作为原料使用。参见：粘土矿物。

## 稀薄气体流动

低于标准大气压的气体流动，有时称为低压气体流动。这种流动可能局限于管道，介于待抽真空的腔室和容器与泵之间；或者它可能是从孔口发出进入大型抽真空腔室的分子束，或者是从发射到高层大气中的火箭排气羽流中发出的分子束。例如。流动速度是相对于固定边界测量的，例如管道壁、火箭或喷气飞机的表面，或风洞中的模型。参见：流体流动；气体；分子束；管道流动；真空泵；风洞。

对于通过导管（管道）的流动，最初涉及的气体必须是必须抽真空的腔室内原有的大气气体。然而，即使原本的大部分气体已被移除，泵也必须继续移除从表面逸出的气体以及通过墙壁缺陷泄漏进来的气体。在某些情况下，气体通过阀门以受控速率引入，因为正在进行的工艺是在低压下进行的。

由于管道中的流动涉及与墙壁的相互作用或阻力，在管道的入口和出口之间会产生压降。此外，当压力极低时，来自泵的气体杂质可能会流向腔室。因此，导管系统的适当设计包括选择具有足够内径的管道和阀门，以确保最小的压降，并插入屏障或捕集器，以减少来自泵的杂质进入工艺腔室。

由于墙壁产生的阻力取决于质量流动速度，并且可能取决于气体粘度和气体的压力或密度。分子的平均自由程是气体中分子与其他分子碰撞之间的距离。参见：物质动力学理论；平均自由程；粘度。

低压流动的分析根据克努森数 Kn 的值分为三或四个流动区域，Kn 定义为平均自由程与特征长度之比，以及无量纲雷诺数。特征长度可以选择为受限流动情况下的管道平均直径，或例如悬挂在风洞中的测试模型相关的长度。参见：气体动力学；克努森数；雷诺数。

气体流动动力学中使用的另一个无量纲数是马赫数 (Ma)，定义为质量流动速度与气体局部音速之比。参见：马赫数。

当平均自由程远小于管道直径 (Kn < 0.01) 时，气体像连续粘性流体一样流动，在远离管道入口的位置，管道轴线附近的速度远高于靠近墙壁的气体层中的速度。速度剖面作为轴向距离的函数，取决于与入口的距离和气体的粘度。当雷诺数小于 2000 时，剖面是一个简单的曲面，因此流动是层流（层流流动区域）。当平均自由程变得大约大于直径的 0.01 倍时，剖面受到边界层效应的影响而变形，且靠近墙壁的速度不会趋近于零（有时称为滑移流动）。参见：层流。

对于超过临界值（大约 2100）的雷诺数，流动受到边界几何形状引起的不稳定性影响，并在高雷诺数时变得湍流（湍流流动区域）。参见：湍流。

当平均自由程大约等于或大于管道直径 (Kn ≥ 1) 时，气体分子很少相互碰撞，分子要么通过管道而不撞击墙壁，要么在墙壁上的各种点之间随机前后散射，最终通过出口逃逸或通过入口向后通过。这种气体流动类型被称为自由分子流（分子流动区域）。层流区域和分子流动区域之间的过渡区域 (0.01 < Kn < 1) 被称为克努森或过渡流区域。

流动也可以根据边界条件或马赫数进行分类。例如，库埃特流动涉及两个表面之间稀薄气体的流动，这些表面以不同的平行切向速度相对运动。对于高超声速流动，Ma ≥ 5。[B.D.Ba.]
