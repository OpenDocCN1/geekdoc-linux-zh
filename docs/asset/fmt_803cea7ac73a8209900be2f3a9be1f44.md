
iproute2 软件包提供了高级网络工具和功能，包括配置网络接口、管理路由表和设置网络策略。`ip` 命令是 iproute2 的一部分。

### 显示网络接口

```bash
$ ip link
```

### 查看路由表

```bash
$ ip route
```

### 使用 `ipsets` 和 `iptables` 设置网络策略

```bash
$ ipset create myset hash:ip
$ iptables -A INPUT -m set-match-set myset src -j DROP
```

### 6. 使用 `tc` 进行流量整形

`tc` 命令也是 iproute2 软件包的一部分，用于流量控制和整形。它允许为不同的应用程序或流量分类优先级并限制网络带宽。

例如，限制接口的带宽：

```bash
$ tc qdisc add dev eth0 root tbf rate 1mbit burst 32kbit latency 400ms
```

### 7. 虚拟局域网 (VLANs)

VLAN 用于将网络分割成多个虚拟局域网，每个局域网都有自己独立的广播域。这是增强网络安全、优化网络性能和组织网络资源的有效技术。

在 Linux 上配置 VLAN，你需要一个支持 VLAN 标记的管理型交换机和一个兼容的网卡 (NIC)。

### 8. IPv6 配置

随着 IPv6 采用不断增长，熟悉 Linux 系统上的 IPv6 配置变得非常重要。你可以使用 `ip` 和 `iptables` 等工具配置 IPv6 地址、路由和防火墙规则。

### 9. 网络绑定 (Network Bonding)

网络绑定（也称为网卡聚合/NIC teaming）允许将多个网络接口组合成单个逻辑接口，以实现冗余和增加带宽。它对于高可用负载均衡非常有用。

在 Linux 上设置网络绑定，你需要根据所需的配置配置 `bonding` 驱动接口。

### 结论

高级网络工具和技术是 Linux 系统管理员和网络专业人士的宝贵资产。无论是排除网络故障、优化网络性能，还是保护你的网络基础设施，深入理解这些工具和技术都是至关重要的。通过掌握这些高级网络概念，你可以高效地管理和维护基于 Linux 的网络，确保其满足组织网络需求的需求。

## 第 5 章：系统管理基础

## 5.1. 用户与组管理

用户和组管理是 Linux 系统管理的一个基本方面。它涉及创建、修改和删除用户账户，以及管理用户权限和访问权限。在本节中，我们将探索用户和组管理的本质命令和技术。

### 1. 创建用户账户

要创建一个新用户账户，可以使用 `useradd` 命令后跟用户名。例如，要创建一个名为“john”的用户，请使用以下命令：

```bash
$ sudo useradd john
```

默认情况下，`useradd` 命令会创建一个在 `/home` 目录下具有家目录的新用户。

### 2. 设置用户密码

在创建用户后，使用 `passwd` 命令设置密码：

```bash
$ sudo passwd john
```

### 3. 修改用户账户

你可以使用 `usermod` 命令修改用户属性。例如，更改用户的家目录：

```bash
$ sudo usermod -d /home/new john
```

### 4. 删除用户账户

要删除用户账户及其家目录，请使用 `userdel` 命令：

```bash
$ sudo userdel -r john
```

### 5. 创建组

组用于管理具有相似权限的用户。要创建一个新组，使用 `groupadd`：

```bash
$ sudo groupadd mygroup
```

### 6. 将用户加入组

要将用户添加到组，可以使用 `usermod` 命令配合 `-aG` 选项：

```bash
$ sudo usermod -aG mygroup john
```

### 7. 列出用户和组

列出系统中所有的用户账户可以使用 `getent` 命令：

```bash
$ getent passwd
```

列出所有组：

```bash
$ getent group
```

### 8. 管理用户权限

用户权限和许可通过使用 `sudo` 来控制。可以通过将用户添加到 “sudo” 组或配置 `/etc/sudoers` 文件来授予管理员权限。

### 9. 锁定和解锁用户账户

要锁定用户账户（防止登录），可以使用 `passwd` 命令配合 `-l` 选项：

```bash
$ sudo passwd -l john
```

解锁用户账户：

```bash
$ sudo passwd -u john
```

### 10. 用户和组文件

用户和组信息存储在系统文件中，例如用于用户账户的 `/etc/passwd` 和用于组的 `/etc/group`。避免手动编辑这些文件，而是使用适当的用户和组管理命令是非常重要的。

用户和组管理是系统管理的一个基础性方面。通过掌握这些基础技术，系统管理员可以高效地管理用户账户、控制访问权限并确保 Linux 系统的安全性和完整性。良好的用户和组管理对于维护良好且安全的计算环境起着至关重要的作用。

## a. CPU 优化

- `CPU 亲和性`: 你可以使用 `taskset` 命令为特定进程设置 CPU 亲和性，将其绑定到特定的 CPU 核。

```bash
$ taskset -c 0,1 myprocess
```

- `CPU 调度器`: 在支持 CPU 频率缩放（`cpufreq`）的系统上，你可以更改 CPU 调度器来控制 CPU 性能和功耗。常见的调度器包括 `demand`、`performance` 和 `powersaver`。

```bash
$ sudo cpufreq-set -g performance
```

## b. 内存优化

- `Swappiness`: 调整 `swappiness` 值来控制系统将 RAM 数据交换到磁盘的频率。较低的值会优先将数据保留在 RAM 中。

```bash
$ sudo sysctl vm.swappiness=10
```

- `清理页缓存`: 你可以清理页缓存、目录项（`dentries`）和索引节点（`inodes`）来释放内存。

```bash
$ sudo sync; echo 1 > /proc/sys/vm/drop_caches
```

## c. 磁盘 I/O 优化

- `I/O 调度器`: 为你的存储设备调整 I/O 调度器。选项包括 `cfq`、`deadline` 和 `noop`。使用 `cat` 命令检查当前调度器：

```bash
$ /sys/block/sdX/queue/scheduler
```

- `文件系统挂载选项`: 在挂载文件系统时，考虑使用 `noatime` 等选项，通过禁用访问时间更新来减少磁盘 I/O。

```bash
$ mount -o remount,noatime /path/to/mount
```

## d. 网络优化

- `TCP 调优`: 使用 `sysctl` 调整 TCP 参数以优化网络性能。例如，你可以增加 TCP 窗口大小：

```bash
$ sudo sysctl -w net.ipv4.tcp_window_scaling=1
```

- `网络网聚合`: 实现网络绑定（`bonding`）以增加吞吐量并提供容错能力。

## 3. 资源监控与告警

使用 `sar`（系统活动报告）等工具随时间收集系统性能数据。结合 `cron` 任务，根据资源阈值调度定期报告和告警。

```bash
$ sar -u 5 10 # 每 5 秒收集一次 CPU 使用数据，共 10 次迭代
```

## 4. 日志与故障排除

检查 `/var/log` 中的系统日志以查找任何问题或错误消息。常见的日志包括 `/var/log/syslog`、`/var/log/auth.log` 和 `/var/log/messages`。使用 `grep` 等工具搜索特定条目。

```bash
$ grep "error" /var/log/syslog
```
