## 基础服务器安全

你可能需要在默认端口 `22` 的端口使用 `ssh` 守护进程，以避免最频繁的端口扫描。你可以通过编辑 `/etc/ssh/sshd_config` 并将 `Port: default` 更改为某些不起眼的 `2222` 来实现，在加固 SSH 并创建适当防火墙规则后：

$ sudo ufw allow 2222
