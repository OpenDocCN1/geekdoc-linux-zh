## 12.7 获取 Shell

现在需要做的是将我们的 payload 放在缓冲区开头，该缓冲区可以通过第一阶段触达并由 A 组成。我们选择使用反向 shell（reverse shell）作为我们的 payload，并使用 `msfvenom` 生成它。我们使用 `-p` 分别指定 `LHOST` 和 `LPORT` 的 payload 值。我们还使用 `-b` 标志指定要避免的字符，使用 `-f` 指定格式字符串，并使用 `-v` 指定使用的变量名。
