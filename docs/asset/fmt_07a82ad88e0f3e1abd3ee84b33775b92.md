
`sudo yum install git`

### 2. 初始化 Git 仓库

要开始跟踪项目中的更改，请导航到项目的根目录并运行：

```
git init
```

此命令会在当前目录下初始化一个新的 Git 仓库。Git 会创建一个名为 `.git` 的隐藏文件夹，该文件夹在其中存储仓库的所有配置和历史数据。

### 3. 暂和提交更改

当你对代码进行更改时，可以使用以下工作流在 Git 中跟踪并保存这些更改：

- **添加 (Add)：** 为了为提交暂存更改，使用 `git add` 命令。例如，要暂存名为 `myfile.txt` 的文件，运行：

```
git add myfile.txt
```

- **提交 (Commit)：** 一旦更改被暂存，你就可以带上描述性消息对其进行提交：

```
git commit -m "Added new feature"
```

这将创建一个包含你所做更改的项目快照，方便你跟踪项目的历史。

### 4. 检查状态和历史

你可以随时通过以下命令检查仓库状态：

```
git status
```

此命令会显示关于已修改、暂存或未跟踪的文件的信息。

要查看提交历史，请使用：

```
git log
```

这将显示提交列表，以及它们的作者、日期和提交信息。

### 5. 分支与合并

Git 允许你通过使用分支同时处理不同的功能或修复漏洞。要创建一个新分支，运行：

```
git branch new-feature
```

要切换到新分支，使用：

```
git checkout new-feature
```

你可以在此分支中进行更改，而不影响主项目。

当你完成分支上的工作后，可以使用以下命令将其合并回主分支（通常是 `master`）：

```
git checkout master
git merge new-feature
```

### 6. 与远程仓库协作

Git 允许通过托管在 GitHub、GitLab 或 Bitbucket 等平台上的远程仓库与其他开发者进行协作。

要添加远程仓库，使用：

```
git remote add origin <repository-url>
```

要将你的更改推送到远程仓库，使用：

```
git push origin master
```

这会将你的本地提交发送到远程仓库的 `master` 分支。

### 7. 解决冲突

当多个开发者同时处理同一个文件并产生冲突的更改时，Git 会帮助你解决冲突。Git 会标记出冲突的行，你可以手动编辑文件以保留理想的更改。

### 8. Git 资源

这只是对 Git 的简要介绍。Git 提供了广泛的功能和能力，可以显著改进你的开发工作流。要学习更多信息，请参考 Git 官方文档，并考虑探索在线教程和课程以掌握 Git 的高级功能。

在本节中，你已经对 Git 的工作原理有了基本的了解，包括安装、仓库初始化、提交更改、检查状态和历史、分支与合并、远程仓库协作以及解决冲突。Git 是一个强大的工具，将极大有利于你的 Linux 编程事业。

## 第 14.4 ：构建与编译软件

构建和编译软件是 Linux 开发中的基本任务。这一过程涉及将人类可读源代码转换为机器可执行的二进制文件。在本节中，你将探索在 Linux 系统上构建和编译软件的基础知识。

### 1. 源代码与编译

源代码是用 C、C++ 或 Rust 等编程语言编写的人类可读程序。为了运行程序，必须将源代码翻译成 CPU 可以理解的格式。这种翻译过程被称为编译。

在 Linux 上编译 C/C++ 代码的主要工具是 GNU 编译器集合 (GCC)。要编译名为 `my_program.c` 的 C 程序，使用：

```
gcc -o my_program my_program.c
```

此命令指示 GCC 将 `my_program.c` 编译为名为 `my_program` 的可执行文件。

### 2. Makefile

对于具有多个源文件、依赖项和各种编译选项的复杂项目，手动运行 GCC 命令可能会变得繁琐。`Makefile` 是一个常见的解决方案。`Makefile` 是一个自动化构建过程的脚本。

这里有一个包含两个源文件 `main.c` 和 `helper.c` 的 C 程序的简单 `Makefile` 示例：

```
CC = gcc
CFLAGS = -Wall -g

my_program: main.c helper.c
	$(CC) $(CFLAGS) -o my_program main.c helper.c
```

在这个示例中，我们定义了编译器 (CC) 和编译标志 (CFLAGS)。`my_program` 目标依赖 `main.c` 和 `helper.c`。当你运行 `make` 时，它会根据 `Makefile` 中定义的规则编译程序。

### 3. 从源码构建软件

Linux 软件通常以源代码形式发布，允许用户为其特定系统进行编译。从源码构建软件请遵循以下常用步骤：

- **下载源码：** 从网站或版本控制仓库获取源代码。
- **解包归档：** 如果源代码是归档格式（例如 `.tar.gz`），请使用以下命令提取：

```
tar -xzvf source_code.tar.gz
```

- **配置 (Configure)：** 运行 `configure` 脚本以检查系统依赖并生成 `Makefile`：

```
./configure
```

- **编译 (Compile)：** 使用 `make` 构建软件：

```
make
```

- **安装 (Install)：** 编译完成后，安装软件：

```
sudo make install
```

此过程会将软件安装到系统范围内，使所有用户都可以访问。

### 4. 包管理器

Linux 发行版提供了包管理器（例如 `apt`、`yum`、`pacman`）来简化软件的安装和管理。这些包管理器处理依赖解析、自动更新和系统集成。

使用包管理器安装软件可以使用如下命令：

```
sudo apt install package_name
```

这从发行版仓库中获取预编译的二进制包，是获取软件最简单、高效的方法。

### 5. 结论

构建和编译软件是 Linux 开发者的关键技能。理解如何编译软件、使用 `Makefile` 工作、从源码构建软件以及利用包管理器，将使你能够在 Linux 系统上管理和自定义软件。无论你是在开发自己的项目，还是在使用开源软件，这些技能对于成功的 Linux 开发都至关重要。

## 第 14.5 ：跨平台开发注意事项

Linux 中的跨平台开发涉及创建可以在不同操作系统（如 Linux、macOS 和 Windows）上运行的软件。本节介绍了开发跨平台应用程序的关键考虑和技术。

### 1. 选择跨平台工具和库

为了高效地开发跨平台软件，选择正确的工具和库至关重要。以下是一些流行的选项：

- **Qt：** `Qt` 是一个 C++ 框架，允许你通过单一代码库为多个平台创建应用程序。它提供了广泛的功能，包括 GUI 组件、网络和数据库访问。
- **Electron：** `Electron` 是一个框架，允许使用 HTML、CSS 和 JavaScript 等 Web 技术构建桌面应用程序。它适用于创建具有原生能力的跨平台桌面应用。
- **Java：** `Java` 以其跨平台兼容性闻名。你可以编写运行在任何带有 Java 虚拟机 (JVM) 的平台上的 `Java` 程序。
- **Python：** `Python` 是一种具有跨平台支持的多功能语言。你可以使用如 `Tkinter`、`PyQt` 或 `Kivy` 等库开发跨平台 GUI 应用。

### 2. 编写平台无关的代码

在编写跨平台代码时，避免特定于平台的依赖至关重要。以下是实现平台无关代码的一些策略：

- 使用抽象层：利用在跨平台之间提供一致 API 的抽象层或库。例如，使用 `Qt` 的跨平台功能进行 GUI 开发。

- 条件编译：使用预处理器指令或条件编译来仅在需要时包含特定于平台的代码。例如，你可以为不同的操作系统有条件地编译代码块。

```
#ifdef _WIN32
// Windows 特有代码
#elif __linux__
// Linux 特有代码
#elif __APPLE__
// macOS 特有代码
#endif
```
