# 同步转换器 (Synchronous converter)

同步转换器通过将交流（ac）转换为直流（dc）或反之来工作。同步转换器已被电子转换器取代，但仍在使用。

> 见直流；同步电流。

# 同步发电机 (Synchronous alternator)

同步发电机是一种与频率同步以固定速度运行的交流（ac）机器。它可以作为电机或发电机使用，取决于应用。

对于同步发电机，电机优于同步电容器。它们在设计上没有根本区别，区别在于电子线圈。

> 见交流发电机；同步电容器。

# 同步器 (Synchronoscope)

一种用于判断交流（ac）发电机或其他电压源是否相位同步的仪器。其主要用途是电网，即两个发电机并联运行，或增加额外的发电机以使电压、频率和相位匹配。

新的电站通常配备同步发生器。但许多此类类型仍在使用，并可能持续使用很多年。

## 合成孔径雷达 (SAR)

雷达（无论是机载还是卫星）利用特殊的信号处理在穿越飞行路径时产生地球（或其他行星）的高分辨率图像。该技术类似于使用合成天线，随着车辆沿飞行路径移动形成一个新阵列。合成孔径雷达在军事和遥感应用中都非常有用，结合其他方法提供粗糙或黑暗表面的映射。

结果的质量取决于几个因素。在雷达中，分辨率分别在距离和方位方向上设计。距离分辨率通过使用宽带脉冲（等同于窄脉冲）来实现，允许雷达分离空间上距离密近物体的回波。现代雷达的距离分辨率在几纳秒级（例如，5 n × 10⁻⁵ ns 产生约0.75米或2.5英尺的分辨率）。

方位分辨率比距离分辨率粗得多。雷达主波宽度决定了分辨率。例如，在185公里（100英里）距离处的3°波束只能分辨间距大于10公里的物体。

表面物体会产生改变图像的多普勒位移。与侧视雷达（见插入）一样，远处物体通过距离的减少产生类似多普勒效应。如果雷达具有高质量的多普勒处理，这将揭示物体的侧面细节。

评估系统设计的需求必须进行汇总并明确。此外，必须遵循结合评估因素和决策的分析过程。设计选择是符合客户需求的优先选择。参见系统（SYSTEM）、运筹（OPERATION-RESEARCH）；优化（OPTIMIZATION）；系统分析（SYSTEMS ANALYSIS）。[W.F.]

按照通常的发展，系统分析在“硬”系统中被定义且结构良好，这些是指定义良好且结构良好的系统（例如，血库和集成系统、复杂的工业流程）。软系统分析是最好的替代方案。相比之下，软系统关注涉及定义模糊和非结构化系统的问题，尤其是高复杂的系统。这些系统通常涉及交互的公共和私立组织（例如，福利系统的设计、公司结构的结构和重要性）。这些系统是有问题的，事实上，问题的系统本身并非分析。软系统的目标涉及人类参与者。

系统分析：将数学方法应用于研究复杂的人类系统。系统是对象的排列或集合，为了共同的发挥功能。这些对象可能包括数学建模、仿真、网络、组织或社会群体，以及生物实体。系统中的一切都被视为系统环境的一部分。系统在环境中运行，该环境可能是物理的、社会的或区域生态系统，如高速公路系统、公司的生产流程、天线系统和导弹的制导系统。

还需要大型系统的需求，其定义最为复杂。找到分析比工业组织、大陆污染问题或全球农业系统更大的系统的方法至关重要。这些是具有解决方案标准的多媒体（多维度）问题。此类系统的分析可以通过基于计算机的方法或非常初步的方法进行。但必须谨慎地处理，要意识到由于个人和社会的复杂性，所采用的方法和员工都是分析性系统。参见系统理论（SYSTEM THEORY）；线性系统分析（LINEAR SYSTEM ANALYSIS）。[S.G.]
