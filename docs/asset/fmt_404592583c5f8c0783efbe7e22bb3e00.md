# sing

一个完全可编程的范围测量工具。`Sing` 是一个从命令行发送自定义 ICMP 数据包的小工具。其主要目的是通过某些增强功能来替代/补充需求巨大的 monster 命令：

- 发送分段包（Linux 和 BSD）。
- 发送/读取伪造包（发行版包含 Libcap）。
- 在 ECHO REQUEST 类型中发送多种 ICMP 信息类型，如默认的地址请求、时间戳信息、路由器请求 (`Router Solicitor`) 和路由器公告 (`Router Advertisement`)。
