- `CSS` (层叠样式表)

一种用于指定文本和其他元素外观的标准。`CSS` 开发用于 Web 页面中的 HTML，它也用于其他情况，特别是在使用单一样式“库”的应用中，这些样式被广泛应用于大量相关文档，例如网站。一个 `CSS` 文件可以指定所有编号列表都以*斜体*显示。通过更改这一个规范，就可以轻松改变大量文档的外观。来自 Matisse `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
