# what — 从文件中提取 SCCS 版本信息

## 概要
`/usr/ccs/bin/what [-s] filename ...`

## 描述
使用 `what` 命令打印源码控制系统 (`SCCS`) 文件的标识字符串。`what` 命令搜索每个文件名中模式 `@(#)` 的出现，该模式由 `SCCS get` 命令（参见 `sccs-get(1)`）替换 `%Z ID` 关键字，并打印其之后的内容直到遇到 `>`、换行符、`\\` 或空字符。

## 选项
`-s` 在第一次出现模式后停止。

## 示例
例如，如果文件 `program.c` 中的 C 程序包含行 `char sccsdid[] = "@(#)identification information";`，

并且 `program.c` 编译生成 `program.o` 和 `a.out`，以下命令将列出 `@(#)` 之后的字符串。

```
castle$ what program.c program.o a.out

program.c:

  identification information

program.o:

  identification information

a.out:

  identification information

cast$
```

# which

> 注意 — `which` 不是 shell 内置命令；它是 UNIX 命令 `/usr/bin/which`。

### 缺陷
仅使用来自 `~/.cshrc` 的别名和路径；不会尝试从当前环境导入。`which` 命令必须由 `csh(1)` 执行，因为只有 `csh` 知道别名。

为了补偿 `~/.cshrc` 文件中依赖于 `prompt` 变量被设置而生效的别名，请将此变量设置为空值。如果 `~/.cshrc` 在 `prompt` 被设置时产生输出或提示输入，`which` 可能会产生一些奇怪的结果。

## 示例
在下面的示例中，`which` 命令无法找到 `whence` 命令。相反，它显示了它尝试查找该命令的搜索路径。

```
castle%
```

```

castle%
```

# while — 执行条件动作的 Shell 内置函数

# 语法法
```
sh, ksh

while [ conditions ]; do actions ; done

csh

while ( conditions )

  .. # do actions

end
```

## 描述
你可以使用循环来控制脚本中的执行流。循环是一种迭代机制，重复执行一组指令，直到满足预定的条件。`while` 循环反复执行循环体内的组命令，直到表达式中的测试条件不再成立。换句话说，`while` 循环表示：“当表达式为真时，执行这些命令。”

# sh, ksh
`while` 命令反复执行 `while` 条件，如果条件列表中最后一个命令的退出状态为 0，则执行 `do actions`；否则循环终止。如果 `do actions` 中没有执行任何命令，`while` 命令返回 0 退出状态。你可以使用 `until` 代替 `while` 来反转循环终止测试。

> 注意 Bourne shell (`sh`) 和 Korn shell (`ksh`) 均可以在其 `if`、`for` 和 `while` 内置命令的语法中交替使用分号和回车。

# csh
当 `while` 条件为真（求值为非零）时，`while` 命令重复执行其与匹配的 `end` 语句之间的动作。`while` 和 `end` 必须单独出现在输入行中。如果 shell 输入来自终端，它将用问号提示命令，直到你输入 `end` 命令为止，然后执行循环中的命令。

# 循环中断
你可以使用内置的 `continue` 命令终止当前 `while` 或 `until` 循环的执行，并使用内置的 `break` 命令终止 `while` 或 `until` 命令的执行。

## 示例
在以下示例中，系统会反复提示要查找的文件名，直到你通过输入空行来选择结束执行。

# sh, ksh
```
filename=anything

while [ $filename ]
  do
    echo "file?"
    read filename # 从终端读取
    find . -name $filename -print
done
```

# csh
`$filename` 周围的括号是评估所需要的（参见 `if(1)` 手册页中的 `test-build` 命令）。此外，必须用空格将每个括号与其内部字符分开。

```
set filename = anything

while ( "$filename" != "" )
  echo "file?"
  set filename = $< # 从终端读取
  find . -name $filename -print
end
```
