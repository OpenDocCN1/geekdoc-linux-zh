## 第 7 章 嵌入式 Linux 工作坊

本质上，这段代码将该项目使用的每个 opt 软件包中的所有文件复制到根文件系统的目录中。在复制之前，我们必须删除目标目录中的所有文件名，因为符号符号链接会导致麻烦。

# 复制所需的设备并使用指定的设备

if ($(cd /dev;tar cf - $REQUIRED_DEV) | (cd $TMP/dev;tar x -)); then return;
sif(-n "$SDEV\" && (cd $dev;tar cf - $SDEV); (cd $TMP/dev;tar cf -\)); fi
