## 开始使用 Python

```python
#!/usr/bin/env python2

# 我们通过编写想要的变量名，后跟一个等号，
# 然后是想要存储在变量中的值来创建一个变量。
# 例如，下面的行创建了一个名为 hello_str 的变量，
# 创建了字符串 "Hello World"

hello_int = 21

hello_bool = True

hello_tuple = (21, 32)

hello_list = ["Hello","this","is","a","list"]
```

下行代码创建了一个名为 `hello_int` 的整数变量，值为 21。注意它不需要加引号。

布尔值也遵循相同的原理。

我们以以下方式创建一个元组（`tuple`）：并以这种方式创建一个列表（`list`）：现在这包含 5 个字符串。注意这些字符串之间没有空格，所以如果你想将它们组合成一个句子，你必须在每个元素之间添加空格。

你也可以通过以下方式创建相同的列表：

```python
hello_list = []
hello_list.append("Hello")
hello_list.append("this")
hello_list.append("is")
hello_list.append("a")
hello_list.append("list")
```

第一行创建了一个空列表，接下来的行使用列表类型的 `append` 函数向列表中添加元素。在处理预先知道的字符串时，这并不真正有用，但在处理动态数据（如用户输入）时可能非常有用。由于我们使用了与上一个列表相同的变量名，此列表将在无任何警告的情况下覆盖第一个列表。

我们完全可以在这里创建一个字典（`dictionary`）。注意我们是如何对齐下面的冒号以使其看起来整齐的。

```python
hello_dict = {"first_name": "Liam",
  "last_name": "Fraser",
  "eye_color": "Blue"}
```

让我们评估集合中的一些元素。我们将开始更改 `hello_list` 中字符串的值，并在末尾添加一个感叹号。`"list"` 是列表中的第 5 个元素。Python 中的索引是从 0 开始的，这意味着第一个元素的索引为 0。

```python
print(hello_list[4])
hello_list[4] += "!"
hello_list[4] = hello_list[4] + "!"
print(hello_list[4])
```

注意当我们打印该元素时，会有两个感叹号。

### 缩进详解

正如前面提到的，缩进的级别决定了 Python 如何读取代码。在其他语言中，使用大括号来组织代码块。因此，使用一致的缩进级别至关重要。在 Python 中，它通常被用来表示单级缩进。你可以使用制表符（tabs），但制表符没有明确定义，特别是当你在多个编辑器中打开同一个文件时。

```python
#!/usr/bin/env python

import sys

int_count = 5

if int_count < 6:
	sys.exit("indentation error was >= 6")
else:
	print("int_count >= 6 continuing...")
```

> `for` 循环使用本地副本，因此循环中的更改不会影响列表

代码采取的路径将取决于 `int_count` 的值。如果条件为真，将执行 `if` 块中的代码。真语句是加载 Python 库；这允许函数执行，允许你退出程序并打印错误信息。注意使用缩进（四个空格）来表示下方的代码块状态：
