
## `bc`—任意精度计算器语言

我们已经看到 shell 如何处理许多类型的整数算术，但如果我们需要进行高阶数学甚至使用浮点数怎么办？答案是：不，shell 无法直接做到。为此，我们需要使用外部程序。有几种方法可以采取。嵌入 Perl 或 AWK 程序是一种解决方案，但遗憾的是这超本书的范围。

另一种方法是使用专门的计算器程序。许多系统中找到这样一个程序是 `bc`。`bc` 程序读取一个用它自己的类 C 编写的文件并执行它。`bc` 脚本可以是一个单独的文件，也可以从标准输入读取。`bc` 语言支持一些功能，包括变量、循环和程序员定义的函数。我们不会完全涵盖 `bc`，只需足够让你了解即可：`bc` 的 `man` 页面提供了良好的文档。

让我们从一个简单的示例开始。我们将编写一个 `bc` 脚本来计算 2 加 2：

```bash
/* 一个简单的 bc 脚本 */
2+2
```

脚本的第一行是注释。`bc` 使用与 C 语言相同的注释语法。注释可以跨多行，以 `/*` 开始，以 `*/` 结束。

### 使用 `bc`

如果我们把之前的脚本保存为 `foo.bc`，可以这样运行它：

```bash
[me@linuxbox ~] \$ bc foo.bc
```

## 位运算 (Bit Operations)

有一类运算符以一种特殊的方式处理数字。这些运算符在位级别上工作。它们被用于某些低级任务，通常涉及设置或读取位标志（bit flags）（详见表 34-5）。

表 34-5：位运算符

| 运算符 | 描述 (Description) |
| --- | --- |
| `~` | 按位取反。反转数字中的所有位。 |
| `<<` | 左移。将数字中的所有位向左移动。 |
| `>>` | 右移。将数字中的所有位向右移动。 |
| `&` | 按位与。对两个数字的所有位执行 AND 运算。 |
| `\|` | 按位或。对两个数字的所有位执行 OR 运算。 |
| `^` | 按位异或。对两个数字的所有位执行异或（exclusive OR）运算。 |

注意，对于所有的按位取反，也有对应的赋值运算符（例如 `<<=`）。在这里我们将演示如何使用位移运算符生成一个 2 的幂次列表：

```bash
[me@linuxbox ~] for ((i=0;i<8;++i)); do echo $((1<<i)); done
1
2
4
8
16
```

## 逻辑 (Logic)

正如我们在第 27 章中发现的，`(( ))` 复合命令支持多种比较运算符。还有几个可以用于评估逻辑。表 34-6 提供了完整列表。

表 34-6：比较运算符

| 运算符 | 描述 (Description) |
| --- | --- |
| `<=` | 小于等于。 |
| `>=` | 大于等于。 |
| `<` | 小于。 |
| `>` | 大于。 |
| `==` | 等于。 |
| `!=` | 不等于。 |
| `&&` | 逻辑或 (OR)。 |

`expr1?expr2:expr3` 比较（三元）运算符。如果表达式 `expr1` 求值为非零（算术真），则执行 `expr2`；否则执行 `expr3`。

当用于逻辑操作时，表达式遵循算术逻辑规则；即值为零的表达式被视为假，而非零表达式被视为真。`(( ))` 复合命令将结果映射到 shell 的正常退出码。

```bash
[melinux] ~$ if ((1)); then echo "true"; else echo "false"; fi true
[melinux] ~$ if ((0)); then echo "true"; else echo "false"; fi false
```

逻辑运算符中最强大的是三元运算符。该运算符（模仿 C 语言语言中的三运算符）执行一个独立的逻辑测试。它可以作为一种 `if/then/else` 语句使用。它作用于三个算术表达式（字符串不起作用），如果第一个表达式为真（或非零），则执行第二个表达式。否则，执行第三个表达式。我们可以在命令行上尝试：

```bash
[melinux] ~$ a=0
[melinux] ~$ ((a1?+a:--a))
[melinux] ~$ echo $a
```

```bash
[me@linuxbox ~] \$ ((a<1?+:a--))
[me@linuxbox ~] \$ echo a
0
```

在这里我们看到了三元运算符的作用。这个示例实现了一个切换（toggle）。每执行一次该运算符，变量的值就会从 0 切换到 1，反反之。

请注意，在表达式内部进行赋值并不是简单的。当尝试这样做时，`bash` 会报告错误。

```bash
[me@linuxbox ~] \$ a=0
[me@linuxbox ~] \$ ((a<1?a+=1:a-=1))
bash: (( a<1?a+=1:a-=1)): attempted assignment to non-variable (error token is "-=1"))
```

可以通过在赋值表达式周围加上括号来缓解这个问题。

```bash
[me@linuxbox ~] \$ ((a<1?a+=1):(a--)))
```

接下来是一个在脚本中使用算术运算符的更完整的示例，它生成一个简单的数字表格：

```bash
#!/bin/bash
# arith-loop: 演示算术运算符的脚本
finished=0
a=0
printf "%d\t%d\n" "$a"
until ((a<10)); do
    a=$((a++))
    c=$((a++))
    printf "%d\t%d\n" "$a" "$c"
done
```

在这个脚本中，我们根据 `finished` 变量的值实现了一个 `until` 循环。初始时，变量设置为零（算术假），我们继续循环直到它变为非零。如果 `a` 小于 10（最大迭代次数），则加 1，否则给变量赋值 1，使 `finished` 为真。运行脚本得到结果：

```bash
[me@linuxbox ~] \$ arith-loop
...
```
