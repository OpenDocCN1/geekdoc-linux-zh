内核是 Linux 的心脏。它负责硬件之间的通信。

### 内存管理 (Memory Management)

内核负责管理 RAM。它确保不同的进程拥有所需的内存，并防止它们干扰彼此的内存。

### 进程管理 (Process Management)

内核管理运行在系统上的进程。它调度哪个进程可以使用 CPU 以及使用多久。

### 设备管理 (Device Management)

内核处理连接到系统的各种硬件设备。它提供驱动程序，允许软件与硬件通信。

### 系统调用 (System Calls)

系统调用是程序向内核请求服务的接口。当程序需要读取文件或使用网络时，它会发出系统调用。

### 系统库 (System Libraries)

系统库是程序用于执行常见任务的函数集合。开发者通常不直接进行系统调用，而是调用来自 `glibc` 等库的函数。

## 第四章：Linux 与 Bash

### 脚本

计算机的一项卓越能力是它可以为你执行自动化任务。在 Linux 系统中，你可以通过编写“程序”来控制功能。

`alias tomorrow = 'date +"%A, %B, %Y"'`

如示例所示，创建的别名是 "`tomorrow`"。它的任务是显示日期。

别名（`alias`）是用于简化长命令的工具。别名就像快捷方式，你可以为复杂的命令设置短名称。

用于脚本的另一种命令被称为 Shell 函数（`shell functions`）。Shell 函数与别名类似，区别在于它们可以处理更复杂的指令集。

Shell 函数也称为子脚本。由于它们的本质，管理脚本有时可能很困难，它们被视为在脚本内部。

示例：

```
function tomorrow {
echo "Tomorrow’s date is:" date +"%A, %B %Y"
}
```

如示例所示，"`tomorrow`" 函数用于显示日期。这与别名相似，但区别在于它可以接收自定义的参数。

### 学习与使用 Bash

`Bash` 是 Bourne-Again Shell 的缩写，是一个读取脚本的处理器。它在终端中运行。

`Bash` 支持通配符（glob），这些字符可以指定文件名。这里是一些通配符字符：

- `-` 匹配单个字符
- `*` – 匹配某些字符
- `[abc]` – 匹配括号内的任意字符
- `![abc]` – 匹配不在括号内的任意字符
- `[a-z]` – 匹配范围内的任意字符
- `![a-z]` – 匹配不在范围内的字符

当 Bash 设置为并发模式时的示例：

`first command & second command`

如示例所示，"`first command`" 被执行。执行完成后完成后`second command`" 被处理。

### Bash 规则

使用 `&` 符号，命令可以在后台执行。通常，命令的执行是在前台（foreground）完成的。你可以通过 `ctrl + z` 将运行进程挂到后台（background）。

后台进程可能会继续运行。此外，存在一个名为 `bg` 的命令。一旦被调用，默认的文本编辑器会启动。完成后，表单将发送给维护者。

### 在 Linux 上编写脚本

在这里，我们将介绍如何使用 Bash 创建 Linux 脚本。

本质上，任何你通常在终端中输入的内容都可以放入 Bash 脚本中，功能上是相同的。同时，你可以利用这些脚本逻辑来自动化某些通常难以实现的事情。

你也可以添加不同的内容来让这些脚本能够执行更多操作，比如变量或条件。

让我们开始吧。每个 Bash 脚本的起始方式相同：`#!/bin/bash`

创建一个新文本文件并输入以下内容：

```
#!/bin/bash
echo hello world
```

然后随意将其保存为 *filename here.sh*。.sh 是 Shell 脚本的文件扩展名。回到终端，导航到保存脚本的地方。等等！你不能立即运行脚本。你必须修改脚本的权限才能运行它。这非常简单，你只需要输入：

```
chmod 755 scriptnamehere.sh
```

然后你可以这样运行它：

```
./scriptnamehere.sh
```

之后，你应该看到终端回显 *hello world*。好了！你的第一个 Bash 脚本。

回到你的脚本，将文本改为：`#!/bin/bash

echo "here are the contents of the directory:" ls -l`

从这个示例中，你可以明白我之前的意思是：Bash 脚本实际上允许你创建之前在终端中使用的相同命令的长版本。

### 变量

变量是任何类型脚本的必要部分。Bash 脚本有几个你需要了解特殊变量。

主要的是命令行参数（command-line arguments）。Bash 脚本会接受许多命令行参数——这些是你在输入脚本时给它的参数。例如，`$1` 和 `$2` 代表第一个和第二个命令行参数。如果你有以下脚本：

```
echo $1 and $2
```

并且你这样启动脚本：

```
./script.sh "peanut butter" "jelly"
```

它会像这样打印：

`peanut butter and jelly`

当然，这些也可以用于更严谨的用途。你可以使用 `cp` 命令将一个目录复制到另一个目录。在你的脚本中：

```
cp $1 $2
```

然后当你执行脚本时：

```
./myscript.sh directory1 directory2
```

你也可以轻松地在 Bash 脚本中开发自己的变量。你可以通过命名变量并将其赋值为某个值来实现，如下：

```
apples=6
```

然后你可以通过在变量名前前加 `$` 来调回变量：

```
echo I have $apples
```

### 接收输入

有时，你需要在脚本从用户那里读取信息。这很容易！你只需要这样做：`read variableName`

然后你就可以通过再次使用 `$` 引用它来随心所欲地操作 `variableName`（任何你想要）。无论如何，这就是始终引用变量的方法。

你也可以一次读取多个变量，只需要求 `read` 多个：

```
read variable1 variable2
```

### Bash 数学

Bash 的数学运算与其他语言和程序的数学概念是类似的。它在窗口中运行。Bash 支持通配符（glob），这些字符指定文件名。

在 Bash 中，赋值是在前台完成的。你需要使用 `let` 关键字来完成赋值，如下：

```
let "var3 = 4 * 5"
```

### 条件

Bash 允许设置条件语句。你可以这样设置它们：

```
if [ condition ]
then
    # code
fi
```

而 `else` 条件可以这样设置：

```
if [ condition ]
then
    # code
else
    # code
fi
```

最后，你可以这样设置 `else if` 条件：

```
if [ condition ]
then
    # code
elif [ condition ]
then
    # code
else
    # code
fi
```

这些最困难的部分是设置正确的条件。以下是可以用来检查不同条件的各种测试：

- `a = b`: 检查两个是否在字母上相同。
- `a != b`: 检查两个是否*不*相同。
- `a -eq b`: 检查两个在数值上是否相等（01 等于 1）。
- `a -gt b`: 检查 a 是否大于 b。
- `a -lt b`: 检查 a 是否小于 b。

### 循环

Bash 脚本中有你需要了解两种主要的循环，就像 C 和 Python 一样：*while* 和 *for* 循环。

*while* 循环在给定语句为真的情况下一直执行。

```
while [ condition ]
do
    # code
done
```

同时，*for* 循环将遍历对象列表并对列表中的每个项目执行某些操作。

```
fruits = 'bananas apples oranges pears'
for fruit in $fruits
do
    echo $fruit
done
```

### 函数

Bash 函数非常简单。它们接收参数的方式与普通 Bash 脚本类似，使用 `$1`, `$2` 等。这里是 `calculateSquareFootage` 函数作为 Bash 函数：

    expr (( $1 * $2 ))
