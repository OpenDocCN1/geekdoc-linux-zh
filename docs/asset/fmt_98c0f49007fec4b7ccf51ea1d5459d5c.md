## Linux 逻辑卷管理器

Linux 系统提供了一种功能，用于在您最初不知道分区将占用多少空间时管理磁盘：逻辑卷管理器（LVM）。LVM 允许您将多个磁盘合并在一起，形成一个更大的逻辑磁盘，然后在这个逻辑上更大的磁盘上组织您的分区。图 6-8 显示了在 LVM 下管理磁盘的示例。

![](img/b0a4b9056f819dccd4781a5105c92d45_322_0.png)

*图 6-8 Linux LVM 管理四个 DASD。*

如您所见，四个 DASD（1、2、3 和 4）被用来形成一个容纳系统分区的单一逻辑磁盘。根文件系统（`/`）*实际上*分配在三个不同的 DASD 上。系统并不知道也不关心这一点，因为 LVM 代码处理地址转换并访问真实磁盘上的数据。`/home` 分区也跨越两个 DASD，而 `/var`、`/tmp` 和 `/opt` 分区位于单个 DASD 上。

在第 171 页的 4.4 节“安装 Linux”中，我们选择在多个 3390-3 卷上为其根文件系统腾出空间。例如，假设我们创建的 3 GB `/home` 分区空间刚刚用完，我们希望给它更多空间。解决此问题的传统方法是向系统引入一个新的 DASD，该 DASD 大于承载 `/home` 分区的那个，并将其移动，将内容复制到新的磁盘区域。这非常笨拙、耗时且容易出错。而使用LVM，这就变成了一项简单的任务。

扩展逻辑卷（例如我们 Linux 安装中的 `/var` 分区）只需向逻辑组添加一块磁盘或磁盘的一个条带，以便将这个新空间分配给其任何逻辑卷。粗略打个比方，这类似于在客厅旁边新建一个房间，然后拆掉它们之间的墙壁。你得到的是完全相同的客厅和额外的空间。图6-9以磁盘为例说明了这一点。

![](img/b0a4b9056f819dccd4781a5105c92d45_323_0.png)

图6-9 通过向LVM添加更多DASD来扩展Linux分区

各种Linux发行版（如YaST）提供了用户通过界面与LVM交互的机制。在没有这种界面的系统中，命令也可以完成LVM管理。需要了解的几个命令如下：

- `pvcreate` 在磁盘上创建物理卷条目，以便LVM识别该磁盘。
- `vgscan` 扫描所有磁盘以查找卷组，并构建文件 `/etc/lvmtab` 和 `/etc/lvmtab.d/*`，这些文件是所有其他LVM命令的数据库。
- `vgcreate` 使用作为参数传入的磁盘创建卷组。这些磁盘必须先用 `pvcreate` 初始化。
- `vgextend` 将磁盘添加到卷组。该磁盘必须先用 `pvcreate` 初始化。
- `lvcreate` 在卷组内创建逻辑卷。
- `lvremove` 从卷组中移除逻辑卷。应仅对空卷或数据不再需要的卷使用此命令。
- `lvextend` 使用卷组中未分配的空间扩展逻辑卷。

要扩展我们的 3 GB `/home` 分区：

1. 以z/VM MAINT身份，将另一个3390-3 DASD连接到我们的z/VM系统。
2. 以z/VM MAINT身份，在其上定义一个迷你磁盘并将其分配给我们的Linux客户机。
3. 以Linux root身份，使用 `vgextend` 将其添加到我们的卷组。
4. 以Linux root身份，使用 `lvextend`，利用新添加到卷组的存储空间扩展我们的 `/home` 逻辑卷。

有关Linux LVM及其使用方法的更详细讨论，请参阅《Linux for IBM eServer zSeries and S/390: Distributions》，SG24-6264。

您还可以参考以下网址的LVM HOWTO：

http://tldp.org/HOWTO/LVM-HOWTO/

有关LVM本身的性能讨论，请参阅：

- 磁盘性能优化：http://www.ibm.com/developerworks/linux/linux390/perf/tuning_rec_dasd_optimizedisk.html
- 卷管理：http://www.ibm.com/developerworks/linux/linux390/perf/tuning_rec_dasd_volMan.html
