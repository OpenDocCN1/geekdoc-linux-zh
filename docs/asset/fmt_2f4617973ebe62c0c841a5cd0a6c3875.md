在 `%` 字符和转换字符之间，会出现以下修饰符，出现顺序如下：

- `*` 括号中的键，用于选择映射对象中的特定项。如果不存在该元素，则会抛出 `KeyError` 异常。
- 以下内容的一个或多个：
    - `-` 号（sign），表示左对齐。默认情况下，值是右对齐的。
    - `+` 号，表示应该包含数值符号（即使是正数）。
    - `0`，表示零填充。
- 一个指定最小字段宽的数字。转换后的值将打印在至少此宽的字段中，并在左侧（如果给出 `-` 标志，则在右侧）填充以达到字段宽度。
- 分隔字段宽度和精度的点。
- 一个指定从字符串中打印的最大字符数的数字，浮点数小数点后的数字位数，或整数的最大数字位数。

此外，星号 (`*`) 字符可以代替任何宽度字段中的数字。如果存在，则宽度将从元组中的下一个项中读取。以下代码说明了几个示例：

```
a = 13.142783

... (省略重复代码)
```
