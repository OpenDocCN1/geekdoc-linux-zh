# 前言

自 1991 年诞生以来，Linux 迅速成为主流企业操作系统 并推动了开源软件在计算机行业中的广泛采用。最近，许多组织由于其先进的图形桌面环境和丰富的生产力软件而采用 Linux 作为主要桌面操作系统。

一个很好的例子是 Novell 将 SUSE Linux 切换为其主要企业和桌面平台。今天，全球有数百万 Linux 用户、管理员和开发者，随着公司采用 Linux 和开源技术，这一社区不断增长。
