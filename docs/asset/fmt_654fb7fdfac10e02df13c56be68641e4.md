# 第 12 章 / Tiger

Tiger 接着检查 SUID 二进制文件的潜在问题。我截取了几条与下面列出的两条类似的消息。Tiger 某一个 CERT 文档的漏洞，并且足够智能报告可能受影响的文件。在这种情况下，这个潜在漏洞在几年前就被修复了。

关于 `uucp` 程序中相对路径名的警告并不严重。另一方面，它引发了一个问题：为什么最初在这台机器上要安装 UUCP 设施？
