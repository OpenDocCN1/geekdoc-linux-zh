
## 使用 `ps` 命令的组合选项

如果你在使用`ps`命令时，你可能会发现你经常组合使用几个选项。

### 按 PID 排序

假设我们创建一个显示并按`PID`排序的别名：

```bash
# 假设我们创建一个显示并按 PID 排序的别名
```

```
$ ps --sort=pid 
```

```
$ ps -C bash
PID EUSER RUSER %CPU %MEM
9318 freddie 0.0 0.0
```

### 按 CPU 排序

或者按`CPU`排序：

```bash
# 或者按 CPU 排序
```

```

 0.0 0.0
```
