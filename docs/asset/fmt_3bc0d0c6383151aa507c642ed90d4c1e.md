## 整数和浮点数的测试

在继续之前，我想回顾一下整数和浮点数测试。在脚本的这一点，我们拥有一组“数字”——至少它们应该是数字——并且这个列表被赋值给 `NUM_LIST` 变量。我们的工作是验证列表中的每个值都是整数或浮点数。查看列表 22.2 中的代码段。

```bash
# 检查数字以确保“数字”
# 要不是整数就是浮点数。

for num in $NUM_LIST
do
    case $num in
        +([0-9])) # 检查是否为整数
            : # 无操作，什么都不做。
            ;;
        +(-([0-9]))) # 检查负整数
            : # 无操作，什么都不做。
            ;;
        +([0-9]|\.[0-9])) # 检查正浮点数
            : # 无操作，什么都不做。
            ;;
        +([0-9][.[0-9]])) # 检查正浮点数
            # 带有 - 前缀
            : # 无操作，什么都不做。
            ;;
        +(-([0-9][.[0-9]]))) # 检查负浮点数
            : # 无操作，什么都不做。
            ;;
        +(-([.-0-9]))) # 检查负浮点数
            : # 无操作，什么都不做。
            ;;
        +([.-0-9]))) # 检查正浮点数
        *) echo "\nERROR: $NUM 不是有效的数字
            usage
            exit 1
            ;;
    esac
done
```

我们使用 `for` 循环来测试 `NUM_LIST` 中的每个值。在每次循环迭代中，`$NUM_LIST` 中的当前值被赋值给 `num` 变量。在 `for` 循环内部我们设置了一个 `case` 语句。测试使用正则表达式来表示我们期望的范围或值类型。如果值不符合我们定义的标准，则匹配 `*` 我们在退出 shell 脚本之前执行 `usage` 函数。

关于加号 (`+`)、减号 (`-`) 和小数点 (`.`) 的说明。在测试字符串时，加号、减号和小数点的位置的位置非常重要。由于浮点数（包括正数和负数）有多种表示形式，我们需要测试所有的组合。正如从所需的测试数量所示，浮点数是最难编写的测试之一。

## 为 `bc` 命令构建数学语句

一旦我们确定所有数据都是有效的，就可以开始构建将与 `bc` 实用程序使用的实际数学语句了。为了构建此语句，我们将遍历新确认的 `$NUM_LIST` 数字列表，并在 `$NUM_LIST` 中的每个数字之间构建一个加号 (`+`) 来生成一个字符串。这是一个巧妙的技巧。我们首先如如下所示初始化两个变量为 NULL（空值）。

```

```

在第一次迭代中，只有 `$NUM_LIST` 中的第一个数字被赋值给 `ADD` 变量。在随后的每次迭代中，都会添加一个加号 (`+`)，然后是 `$NUM_LIST` 中的下一个数字（该数字由每次循环迭代中的 `X` 变量指定），直到所有数字和加号都已赋值给 `ADD` 变量。例如，我们有以下数字列表：

另外注意，我们对以 `+` 号开头的数字添加了测试。我们需要剔除这个字符，以便在向 `bc` 程序呈现方程时不会出现两个加号相连的情况，否则会发生错误。在我们构建数学语句时，每次循环迭代都会对 `ADD` 变量进行以下赋值：
