
### 隐私与数据擦除

如果你使用 `YubiKey`，`SystemRescueCd` 确实采取措施增强了你的隐私。它包含 `YubiKey Manager` 应用程序以及 `YubiKey Personalization Tool`，后者可以帮助你重新编程设备上的配置插槽，以启用 `OTP` 等额外的身份验证功能。除此之外，你还可以找到多个帮助安全删除数据的工具，包括 `shred`、`wipe` 和 `THC-Secure Deletion` 工具。

与其同行类似，尽管确保安全和隐私并不是 `UBCD` 的目标之一，但该发行版确实有一个专门的类别，列出了大约一打工具（包括多个低级实用工具），用于安全擦除磁盘。还有扫描器来嗅探病毒和恶意软件。

### 修复能力

它们能纠正哪些错误？

无论困扰你安装环境的病症是什么，这些发行版都能帮助你摆脱困境。它们中的许多都可以对磁盘进行镜像和克隆，识别并列出损坏的扇区，并从物理损坏的磁盘中提取可恢复的数据。然而，有些比其他更有用。

例如，`MorpheusArch` 唯一宣传的目的是数据恢复，因此你几乎没有其他用途可以使用该发行版。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_43_0.png)

首次用户可以使用 `MorpheusArch` 中的 `LinDiag` 工具，尝试使用 `drescue` 工具进行数据恢复。

`AIO System Rescue Toolkit` 拥有少量救援工具，用于修复启动错误并救援误删的文件。不过，其大多数工具用于修复 `Windows` 安装，可用于修复专有操作系统中的各种问题。

`ALT Linux Rescue` 随附的工具可以执行多种修复任务。在专家手中，该发行版可以修复引导加载程序、优化文件系统、恢复误删的文件和分区，甚至诊断网络问题。

同样，你可以使用 `SystemRescueCd` 纠正硬盘的各种问题，包括恢复分区表。它还可以将文件系统的内容保存为压缩归档文件，安全删除文件并恢复误删的文件。你还可以使用该发行版从无法启动的 `Windows` 机器中救援数据。

与其他大多数情况一样，`UBCD` 比其他竞争者更进一步，它不仅能够修复引导加载程序，还能够恢复 `BIOS` 设置，以及恢复和备份 `CMOS`。这除了通常的救援任务（如恢复密码和删除的文件）之外，该发行版还包含多个诊断实用工具。

### 自定义

你可以根据需要调整它们吗？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_43_1.png)

`AIO System Rescue Kit` 的 `Lite` 版本运行多个修复工具，帮助修复 `Windows` 安装中的大多数常见问题。

尽管拥有相当庞大的应用程序集合，但这些发行版并不包含所有可用的维修和救援工具。部分原因是某些流行的救援工具存在许可限制，阻止开发者将其包含在发行版中。无论如何，比起携带多个发行版以完成不同的任务，高级用户和技术人员更愿意充实他们最喜欢的发行版，以包含他们需要的所有工具。

如果你想要反编译并组装自己的救援发行版，使用 `ALT Linux Rescue`、`MorpheusArch` 或 `AIO System Rescue Toolkit` 无法走得太远。它们中的任何一个都不提供自定义发行版的选项，尽管你可以使用它们各自的包管理器拉取额外的实用工具，并根据需要充实实时环境。此外，`AIO System Rescue Toolkit` 有一个 `Lite` 版本，旨在让没有经验的用户有机会轻松修复他们的安装。

另一方面，`SystemRescueCd` 的一个标志性功能是其允许任何人编译自定义版本的能力。曾经有一堆脚本来简化重新制作旧版本发行版的过程。在新的基于 `Arch` 的版本中，这一过程已简化，你可以简单地使用项目 `Git` 仓库中发布的源代码进行重建。你需要拥有一个 `Arch` 安装环境才能运行 `SystemRescueCd` 的构建脚本，这些脚本基于 `archiso` 工具。

`UBCD` 允许用户提取 `ISO` 镜像，然后通过添加自己的软盘和 `ISO` 镜像以及基于 `FreeDOS` 的应用程序来自定义环境，然后编译新的 `ISO` 镜像。网站文档还列出了更新病毒定义的过程。`UBCD` 自定义机制的一个特别好处是，由于所有修改都存储在单个文件夹中，你可以轻松升级到 `UBCD` 的新版本，而不会丢失你对发行版所做的任何更改。

| MORPHEUSARCH | 1/10 | | |

`SystemRescueCd` 和 `UBCD` 是唯二允许你使用自己的工具和实用程序制作自定义版本的发行版。

## 救援发行版

## 最终裁定

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_44_0.png)

救援受损电脑的第一步是获取正确的工具，这也是为什么我们青睐那些拥有大量工具集合的发行版。但对于缺乏经验的用户来说，仅仅拥有最大的工具库并没有什么太大用处。考虑到这一点，本轮评测的获胜者必须是一个能被大量人群使用的发行版，无论其技能和经验水平如何。这就是 `ALT Linux Rescue` 落选的原因。虽然该发行版配备了处理各种修复和救援任务的能力，但在新手用户手中却没什么用处——它是专为经验丰富的技术人员设计的。

`MorpheusArch Linux` 因类似但不同的原因落选。与 `ALT` 不同，该发行版启动进入图形桌面，但其配备的所有工具均基于命令行界面，且发行版未提供协助来引导用户选择适合任务的正确工具。我们确实喜欢其 `LinDiag` 工具，尽管其覆盖范围有限，但它努力让部分工具对首次使用者更加友好。但未被默认包含在发行版中这一点是一个巨大的减分项。

`SystemRescueCd` 也存在一些相同的问题。与早期版本拥有综合引导菜单不同，当前版本只对熟悉其工具库的人有用。

给我们留下最深刻印象的两个选项是 `AIO System Rescue Kit` 和 `UBCD`。两者都装满了工具和实用程序，并有定制界面帮助你找到正确的工具。然而，`AIO` 因其对 `Windows` 特定修复的强烈关注而输给了 `UBCD`。甚至当该发行版在 `Windows` 内部运行时，其定制菜单也会出现。

`UBCD` 赢得了本轮评测，因为它在我们设定的两项标准上都表现优异。该发行版工具丰富，且对初学者来说依然足够直观。其逻辑清晰的引导菜单也是其独特卖点，提供有用信息帮助你识别正确的工具，并直接引导进入该工具。

   网址: `www.ultimatebootcd.com` 许可证: *各种* 版本: `5.3.8`
   `UBCD` 内置了足以证明其名称的实用程序，并通过用户友好的界面呈现它们。

   网址: `https://paul.is-a-geek.org/aio-srt` 许可证: *各种* 版本: `2018-01-02`

   网址: `www.system-rescue-cd.org` 许可证: *GPL v2* 版本: `6.0.2`
