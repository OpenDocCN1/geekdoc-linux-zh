## 定义

`continue` 块是一种语法结构，允许将条件附加到另一个块（通常是 `while` 块）。`continue` 块中的任何语句在附加的块重复之前都会评估。

## 示例

```perl
$i=0;
print "continue() ";
while ($i<10) {
    if ($i % 2) {
        print "${i}o "; next;
    }
    else {
        print "${i}e ";
    }
}
continue ($i++)
print "\n";
```
