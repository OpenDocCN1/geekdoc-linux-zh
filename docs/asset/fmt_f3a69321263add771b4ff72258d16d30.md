# 核物理

核物理学门学科研究原子核的结构及其相互之间、与组成粒子的相互作用，以及通过大型粒子加速器探测的基本粒子的性质。原子核包含一个原子尺的中心电势，以及与电粒子力同数量级的力；然而，核力是唯一一个四种基本作用力都可以被研究的系统；它为测试和扩展基本对称性和自然法则提供了一个天然的实验室。

核能带来了一种在其他工作领域极少遇到的潜在危险；例如，核反应堆芯的碎片曾释放到大气中。由于放射性是意料之外的，可以通过系统设计的仔细工程和法规来避免这些危险。参见核废物管理（NUCLEAR WASTE MANAGEMENT）。

核自旋的独特之处在于，它是原子最基础、最重要的方面之一。其仪器设备在化学和医学等领域具有广泛的应用性；核医学和核工程是应用科学的两个重要领域。参见核工程（NUCLEAR ENGINEERING）；核辐射生物学（NUCLEAR RADIATION BIOLOGICAL）；放射生物学（RADIOBIOLOGY）；核医学（NUCLEAR MEDICINE）。

当粒子相互接近到原子核尺度距离（10⁻¹² cm）时，由于非弹性碰撞而发生的过程。虽然核反应在自然界中存在，但对它们的理解和利用使其主要局限于实验室环境。

根据其发生的尺度，以及入射粒子的动能转化为内部激发能的程度。很大比例的反应观察到的性质与两种反应机制一致，这两种机制代表了这一通用分类中的极端情况。它们分别是复合子核机制和直接相互作用机制。

**核反应的类型。** 一种广义的过程，入射粒子引发先前静止的原子核，产生任意数量的最终产物，被称为散射。散射可以是弹性的或非弹性的，取决于部分动能是否转移以激发涉及的粒子。如果产物与初始粒子对不同，则该过程被称为反应。
