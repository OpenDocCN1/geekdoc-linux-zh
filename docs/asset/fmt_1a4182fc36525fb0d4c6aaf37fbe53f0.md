
# WINS Server - 告诉 Samba 的 NMBD 组件作为 WINS 客户端。

# 注意：Samba 可以是 WINS 服务器，也可以是 WINS 客户端

`; wins server = w.x.y.z`

# WINS Proxy - 告诉 Samba 代表非 WINS 客户端回答解析查询，要使此功能生效，网络上至少有一个 WINS 服务器。默认值为否。

`; wins proxy = yes`

# DNS Proxy - 告诉 Samba 是否尝试通过 nslookup 解析 NetBIOS 名称。1.9.17 版本的内置默认值为 yes。

```
# 此项在版本 1.9.18 已更改为 no
dns proxy = no
```

# 其他示例。

# 一个私有打印机，仅供 fred 使用。池数据将

# 放在 fred 的家目录中。注意 fred 必须对池目录具有写入权限，

# 无论该目录在哪里。

```
comment = Fred 的打印机
valid users = fred
path = /homes/fred
printer = freds_printer
public = no
writable = no
printable = yes
```

# 一个私有目录，仅供 fred 使用。注意 fred 需要

# 该目录的写入权限。

```
comment = Fred 的服务
path = /usr/somewhere/private
valid users = fred
public = no
writable = yes
printable = no
```

# 为每个连接到此的机器提供不同的目录，

# 这允许你为接入的机器定制化配置。

你也可以

# 使用 %U 选项按用户名进行定制。

# % 会被替换为正在连接的机器名称。

```
comment = PC 目录
path = /usr/pc/%%
public = no
writable = yes
```

```
# 一个公共访问的目录，所有用户均可读/写。注意
# 用户在目录中创建的所有文件都将属于默认
用户，因此
# 任何具有访问权限的用户都可以删除其他用户的文件。
显然，此
# 目录必须允许默认用户写入。当然，也可以
# 指定另一个用户，在这种情况下，所有文件将属于
该用户。
;[public]
; path = /usr/somewhere/else/public
; public = yes
; only guest = yes
; writable = yes
; printable = no

# 以下两个条目演示了如何共享目录，
使得两个
# 用户可以在那里放置文件，这些文件将属于特定的
# 用户。在这些
# 设置中，目录应对所有用户可写，并应该
# 设置粘滞位（sticky bit）以防止滥用。显然这可以扩展到
# 数量的用户。
;[myshare]
; comment = Mary 和 Fred 的东西
; path = /usr/somewhere/shared
; valid users = mary fred
; public = no
; writable = yes
; printable = no
; create mask = 0765
```
