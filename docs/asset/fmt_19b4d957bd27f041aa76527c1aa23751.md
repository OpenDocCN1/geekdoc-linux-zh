#### 使用 `netstat`

`netstat` 命令显示当前的网络状态。它有许多选项可用于过滤状态数据。最有用的 `netstat` 选项在表 13.5 中概述。

##### 表 13.5 选定的 `netstat` 选项

| 选项 | 描述 |
|---|---|
| `-a` | 显示所有活动的网络连接及其状态 |
| `-i` | 显示每个网络接口的摘要信息 |
| `-s` | 按协议排序显示数据包摘要 |
| `-r` | 显示路由表及其状态的信息 |
| `-c` | 每秒更新并显示连续输出 |
| `-N` | 显示有关接口或路由创建或删除的消息 |
