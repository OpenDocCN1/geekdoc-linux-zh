## 降水（气象学）

从大气中落下的水滴或颗粒。当它是雨或毛雨时，或者当结冰为雪、冰雹、小冰粒（也称为冰；在美国，称为雨夹、雪霰、冰）、雪、针状物和冰晶。在英国，它被定义为雨和融雪的混合物。从大气中收集的露水、霜和雾也被归类为降水。

所有降水类型都是水态的，其他形式可以是湿的、雾状、吹出的喷射。当雨或毛雨在接触地面时结冰，称为雨夹（sleet）；如果被称为冰暴或冻融、毛雨或霜，俗称为阵雨或错误地称为雨夹风暴。见：冰阻塞（ICE CLOG）。

降水可能以阵雨形式或持续形式发生。稳定的降水在长时间的高强度期间可能是间歇性的。冰雹、雨夹和雪粒发生在阵雨中。大颗粒和雪可能作为持续性降水落下。阴影源于云族的不稳定性，而强降水源于层云。

## 压力容器

一种能够承受所封闭材料施加压力的圆柱形或球形容器。压力容器非常重要，因为许多液体和气体必须在高压下储存。特别强调容器的主体，以防止因破裂导致爆炸。此类容器的安全标准影响了特殊条件下的容器设计。

大多数容器需要承受低压，由卷成圆柱形的管和板材制成。压力容器必须承受高压，因此必须增加壁厚以提供足够的强度。液压和气压缸以各种压力容器的形式形式制造。[J.R.]

## 高压高炉

一种运行压力高于正常压力的高炉。压力通过节流废气流获得，这允许更大容量空气以较低的速度和增加的冶炼速率通过炉。该工艺限制了高温空气进入炉底重量增加，减少了焦炭的分解速率，并且由于底部和顶部之间压力降低，允许使用更少的熔剂更多的氧气。[M.E.C.]

## 预应力混凝土

在使用过程中诱导应力的混凝土，以抵消由载荷产生的应力。预应力对于无弹性的混凝土最有效。产生压应力是将构件放置在两个支座之间，其末端锚在混凝土中。筋通常由钢棒或钢丝、电缆制成，为了将它们锚在混凝土中，它们必须拉伸以恢复初始长度。筋可以使用千斤顶或电加热进行拉伸。

预应力混凝土对桥梁特别有利。它允许承受比钢筋混凝土大几倍的压力。在钢筋混凝土设计中，如果混凝土底部都需要处于拉伸并开裂状态导致失效，那么使用预应力混凝土在弯曲处是有效的。钢筋混凝土：应力与应变 [F.S.M.]

为了让程序执行这些指令，这些指令需要存储在内存中。程序的每条指令都占用某些内存位置，并以二进制数字序列（0 和 1）的形式存储，其中每个数字表示要执行的指令（操作符）或指令所操作的数据段（操作数）。除非是用机器语言编写的，否则指令是不会被直接理解的。

### 数据操作。数据操作提供设置每个已声明数据的值。在这种情况下，通过三步过程完成：一组用于转换每个数据值的操作符、执行操作，以及用于更改某些数据值的赋值。

### 执行结构。程序的目的是产生答案。当按顺序执行操作以产生答案时，必须有一种机制来决定执行哪些指令或重复它们。1966 年的 ALGOL 60 显示编程语言只需要三种基本控制结构：赋值、IF 语句和循环结构。在执行期间，我们需要简化程序的结构。使用 IF 语句……

# 进展

IF 语句意味着 IF 语句。如果 THEN 语句的求值为真，则执行语句。如果值为假，则执行下一个。IF-ELSE 语句类似于，除了 THEN 或 ELSE 子句，执行下一个。异常循环由 WHILE 和 REPEAT 组成。只有一个是必要的；继承是序列的第三种形式。它是构建面向对象的语言 C 和 C++。继承涉及类的使用。对象继承类的属性，等等。数据对象继承其创建的类属性。整数对象可能会继承类的属性。

一个 Prolog 程序由一系列句组成，每个句由一个头和一个体组成。评估通过这些句进行。每个关系都是一种评估，类似于在 C++ 等命令式语言中调用过程值。

与其他语言不同，Prolog 不是一种完全语言。许多语言是完全的，但它们不利于搜索大型数据库。Prolog 是一种描述事物的有效机制。软件：SOFTWARE-[MWV.2]
