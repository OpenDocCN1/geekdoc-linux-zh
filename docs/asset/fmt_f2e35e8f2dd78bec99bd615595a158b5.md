
在匹配 Unicode 字符串时，`\d`, `\D`, `\s`, `\w` 和 `\W` 字符的解释方式有所不同。在这种情况下，它们都匹配符合描述属性的 Unicode 字符。例如，`\d` 匹配任何被分类为数字的 Unicode 字符，如欧洲、阿拉伯和印度数字，这些数字占据不同的字符范围。

## 函数

以下函数用于执行模式匹配和替换：

```
`compile(str, flags)`
```

将正则表达式字符串编译为正则表达式对象。此对象可以作为模式参数传递给后续的所有函数。该对象还提供了一些后文稍将描述的方法。`flags` 是以下标志的按位或操作结果：

| 标志 | 描述 |
| --- | --- |
| A or ASCII | 执行仅 8 位 ASCII 的匹配（仅限 Python 3）。 |
| I or IGNORECASE | 执行不区分大小写的匹配。 |
| L or LOCALE | 对 `\w`, `\W`, `\b` 和 `\B` 使用区域设置。 |
| M or MULTILINE | 使 `^` 和 `$` 匹配每行的开头和结尾，而不仅仅是整个字符串的开头和结尾。（通常 `^` 和 `$` 只匹配项目的开头和结尾）。 |
| S or DOTALL | 让点 (`.`) 匹配所有字符，包括换行符。 |
| U or UNICODE | 使用 Unicode 字符属性数据库的信息用于 `\w`, `\W`, `\b` 和 `\B`。（仅限 Python 2。默认）。 |
| X or VERBOSE | 忽略模式字符串中未转义的空白和注释。 |

```
`escape(string)`
```

返回一个对所有非字母数字字符进行转义斜处理的字符串。

```
`findall(pattern, string [, flags])`
```

返回字符串中 `pattern` 所有非重叠匹配项的列表，包括空匹配。如果模式包含分组，则返回一个由分组匹配的文本列表。

如果使用了多个分组，列表中的每个项将是一个包含每个分组文本的元组。`flags` 的含义与 `compile()` 相同。

```
finditer(pattern, string, {flags})
```

与 `findall()` 相同，但返回的是一个迭代器。迭代器返回类型为 `MatchObject` 的项。

```
match(pattern, string, {flags})
```

检查 `string` 开头的零个或多个字符是否匹配 `pattern`。成功时返回 `MatchObject`，否则返回 `None`。`flags` 的含义与 `compile()` 相同。

```
search(pattern, string, {flags})
```

在字符串中搜索 `pattern` 的第一个匹配项。`flags` 的含义与 `compile()` 相同。成功时返回 `MatchObject`，若未找到匹配则返回 `None`。

```
split(pattern, string, {maxsplit = 0})
```

通过 `pattern` 的出现位置分割字符串。返回由模式中任何分组匹配的字符串列表。`maxsplit` 是执行的最大分割次数。默认情况下执行所有可能的分割。

```
sub(pattern, repl, string, {count = 0})
```

使用替换内容 `repl` 替换字符串中 `pattern` 的非重叠出现项，`repl` 可以是字符串也可以是函数。如果是函数，则将传入一个 `MatchObject` 调用并返回替换字符串。如果 `repl` 是字符串，则使用如 `\<name>` 的反引用来引用命名分组。`count` 是最大替换次数。默认替换所有出现项。虽然函数不接受像 `compile()` 那样的 `flags` 参数，但通过在本节前面的部分使用 `(?imsux)` 符号可以实现相同的效果。

```
subn(pattern, repl, string, {count = 0})
```

与 `sub` 相同，但返回一个包含新字符串和替换次数的元组。

# 正则表达式对象

由 `compile()` 函数创建的编译后的正则表达式对象 `r` 具有以下方法和属性：

`r.flags`

编译正则表达式对象时使用的 `flags` 参数，如果未指定标志，则为 0。

`r.groupindex`

一个字典，将由 `r'(?P<id>)'` 定义的符号分组名称映射到分组数字。

`r.pattern`

用于编译正则表达式对象的模式字符串。

```
r.findall(string [, pos [, endpos])
```

与 `findall()` 函数相同。`pos` 和 `endpos` 指定了搜索的起始位置和结束位置。

```
r.finditer(string [, pos [, endpos])
```

与 `finditer()` 函数相同。

```
r.match(pattern, string, {flags})
```

检查 `string` 开头的零个或多个字符是否匹配 `pattern`。成功时返回 `MatchObject`，否则返回 `None`。`flags` 的含义与 `compile()` 相同。

```
r.search(pattern, string, {flags})
```

在字符串中搜索 `pattern` 的第一个匹配项。`flags` 的含义与 `compile()` 相同。成功时返回 `MatchObject`，若未找到则返回 `None`。

```
r.split(pattern, string, {maxsplit = 0})
```

通过 `pattern` 的出现位置分割字符串。返回模式中任何分组匹配的字符串列表。`maxsplit` 是执行的最大分割次数。

```
r.sub(pattern, repl, string, {count = 0})
```

使用替换内容 `repl` 替换字符串中 `pattern` 的非重叠出现项，`repl` 可以是字符串也可以是函数。如果是函数，则将传入一个 `MatchObject` 调用并返回替换字符串。如果 `repl` 是字符串，则使用如 `\<name>` 的反引用来引用命名分组。`count` 是最大替换次数。

```
r.subn(pattern, repl, string, {count = 0})
```

与 `sub` 相同，但返回一个包含新字符串和替换次数的元组。
