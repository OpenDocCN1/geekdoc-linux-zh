# gbase

小型数值进制计数器（如果你在命令行上指定一个数字）。通过一个开关描述该数字为 n，程序将在控制台上显示所有四进制并退出。你也可以使用该开关允许你输入/显示带符号的数字。（这允许在小数前使用 –（减号））。不带任何开关直接运行程序将显示主窗口。有四个输入框，分别对应四进制中的每一个。你可以输入其中任何一个，其他的将自动更新。程序将忽略该特定进制不允许的字符。如果启用了选选项，它将只在小数开头允许使用 –（减号）。来自 Debian 3.0r APT

# gbiff

# gbuffy

一个类似于 GTK+-XBuffy 的邮箱“biff”程序。GBuffy 拉取多个邮箱以获取新邮件。它会列出你配置的每个邮箱中的消息数量。它还会突出显示有新邮件的邮箱。带有邮件的邮箱左键将显示每条新消息的发送者和主题。此外，GBuffy 将显示消息的 X-Face 标头。点击邮箱中间键将启动配置的命令，即使用你喜欢的邮件阅读器读取邮箱的命令。点击右键将调出配置菜单。GBuffy 能够监控 MBOX、Mdir 和 MH 文件夹。这支持开启了 XOVER 的 MAP4 和 NNTP。计划支持外部程序进行通知。来自 Debian 3.0r0 APT

### GCC

由 Richard Stallman 等编写的 GNU C 编译器，适用于 C、C++ 和 Objective-C。它设计用于将其转换为寄存器传输语言，然后转换为目标体系汇编代码。来自 Linux Guide

http://www.tldp.org/LDP/Linux-Dictionary/index.html

### gecc

C 语言内存访问调试器。Checker（读、写、执行访问）* 写入只读内存 * 访问未初始化字节（原子动态内存）* 读写“区域”（原子动态内存）* 来自 malloc 的释放地址。Checker 的主要优势是会导致程序运行慢得多。通过将 gcc 替换为 checkcalls 来编译你的程序。此版本的 Checker 只支持 GNU gcc 95。不支持早期或更晚的版本。对 C++ 支持有限，不支持 libc++。来自 Debian 3.0r0 APT
