## A.2 特殊变量

### 表 A.2 文件句柄

| 变量 | 作用 |
| :--- | :--- |
| `$I` | 如果非零，则在当前选定文件句柄上的每次写入和打印后强制刷新缓冲区 |
| `$;` | 当前选定文件句柄的当前页码 |
| `$=` | 当前选定文件句柄的当前页长度 |
| `$-` | 当前选定文件句柄上页面剩余的线条数 |
| `$--` | 当前选定文件句柄的当前报告格式名称 |
| `$^` | 当前选定文件句柄的当前页首格式名称 |

### 表 A.3 局部于 Dloc

| 变量 | 作用 |
| :--- | :--- |
| `$1, $9` | 包含记住的子模式，引用对应的括号集（等同于 `\1`、`\9`） |
| `$&` | 由最后一次模式匹配匹配的字符串（类似于 sed 编辑器） |
| `$$` | 最后一次模式匹配中匹配内容之前的字符串 |
| `$'` | 最后一次模式匹配内容之后的字符串 |
| `$+` | 最后一次搜索模式匹配的最后模式 |

**示例 A.1**

```text
$str="old and restless";

    print "&$&\n" if $str =~ /and/;

    print "$'$\n" if $str =~ /and/;

    print "&$'\n" if $str =~ /and/;

    print "\nold string is: $str\n";

    $str=~(old) and (restless)/$2 and $1/;
```
