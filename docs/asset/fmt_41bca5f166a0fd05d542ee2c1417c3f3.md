## 访问命令行帮助

正如您在前一节中学到的，Linux 命令有许多选项，必须准确输入才能获得您想要的结果。然而，记住即使是常见 Linux 命令的所有选项也是几乎不可能的，因此 Linux 为每个命令提供了内置的手册或信息页。您可以使用 `man` 或 `info` 命令访问此信息，如下面的部分所述。

### 使用 Man 页

`man`（manual 的缩写）命令提供了关于特定命令的 man 页中的详细帮助信息。例如，要查看 `ls` 命令的 man 页，请键入命令 `man ls` 以获取图 13-9 中显示的结果。您可以使用 Page Up 和 Page Down 键浏览 man 页。查看完 man 文档后，按 Q 退出手册并返回到 shell 提示符。请注意，每个 man 页的标题在左侧和右侧显示命令名称，后跟括号中的部分编号，表示该 man 页所属的部分。图 13-9 中的默认部分编号 (1) 表示正在显示有关用户命令选项的信息。其他部分编号可用于显示各种主题（见表 13-3）的 man 页。

![](img/840007e8f98ea6653e5877e945c27dc6_546_0.png)

图 13-9 `ls` 命令的 man 手册（第 1 节）页面

#### 表 13-3 man 命令的手册节选项

| 手册节号 | 描述 |
| :--- | :--- |
| 1 | 可执行程序及用户 Shell 命令；默认的手册节号 |
| 2 | 系统调用 |
| 3 | 函数和库例程 |
| 4 | 设备文件 |
| 5 | 配置文件和文件格式 |
| 6 | 游戏 |
| 7 | 宏包和文件格式 |
| 8 | 系统管理命令 |

例如，要查看 `crontab` 命令的配置文件和文件格式（参见图 13-10），请输入命令 `man 5 crontab`。

![](img/840007e8f98ea6653e5877e945c27dc6_546_1.png)

图 13-10 `crontab` 命令的 man 手册（第 5 节）页面

### 使用 Info 页面

Linux 拥有另一种命令文档来源，称为 info 页面，它们通常提供更新版本的命令文档，并可以使用 `info` 命令进行阅读，如图 13-11 所示。在 SUSE Linux 中，info 文件存储在 `/usr/share/info` 目录中，与 man 手册相比具有以下优势：

- Info 文件在文档布局中使用标准结构。
- Info 文件包含特定章节，可以通过目录直接访问，而 man 命令需要使用手册节号。
- Info 文件的章节可以链接起来形成完整的文档。

![](img/840007e8f98ea6653e5877e945c27dc6_547_0.png)

您可以使用表 13-4 中列出的多个命令键在 info 页面中移动。

#### 表 13-4 常用 info 命令键

| 命令键 | 描述 |
| :--- | :--- |
| 空格键、Page Down | 下翻一屏 |
| Backspace、Page Up | 上翻一屏 |
| b | 将光标移动到 info 页面的开头 |
| t | 将光标移动到下一个引用处 |
| h | 显示帮助 |
| q | 退出 info 页面 |

## 从命令行创建用户和组
