
从此窗口中，你可以将任何图案拖到你的主窗口或任何 `Nautilus` 窗口中，该图案将成为你所有 `Nautilus` 窗口的背景。因此，为了练习，请向下滚动找到名为“马尼拉纸”（`Manila Paper`）的图案色块，然后将其拖到主窗口主面板的空白区域。完成操作后，之前白色的窗口区域看起来就像律师办公室的壁纸一样。如果你喜欢那种风格的话，非常漂亮。当然，你可以用同样的方法更改为不同的背景，或者通过将“重置”（`Reset`）开关拖入窗口来返回默认的白色。

> 注意：如果你更喜欢使用自己的图像作为 `Nautilus` 背景，也可以非常轻松地做到。只需在新的 `Nautilus` 窗口中找到该图像，同时用鼠标左键和右键点击它（如果你使用的是三键鼠标，则只需点击中间键），然后将图像拖到窗口内的任何开放空间。当你松开按钮时，在随后弹出的弹出菜单中选择“设置为背景”（`Set as Background`）。

除了图案和颜色色块按钮外，“背景和图标”窗口中还有第三个按钮，名为“图标”（`Emblems`）。点击“图标”按钮将显示你在第 107 页项目 TB-2 中看到的所有图标，你会发现有很多方法可以为文件夹添加图标。在为多个文件夹添加图标或在系统进行时，这种方法要方便得多。

要查看这是否有效，点击“图标”按钮。将“相机”（`Camera`）图标拖到你的“照片”文件夹，将“包”（`Package`）拖到你的“下载”文件夹，由于没有更好的选择，将“特殊”（`Special`）拖到你的“PDF”文件夹。选中的图标将立即出现在这些文件夹上。

你也可以为侧边栏添加不同的背景图案，但为了练习，让我们添加一种颜色吧。要这样做，点击“背景和图标”窗口中的“颜色”（`Colors`）按钮。窗口将充满各种色块。将“柚子”（`Grapefruit`）色块拖到你的侧边栏，它将从灰色变成柚子色（一种非常深且颜色不寻的柚子）。你还可以通过添加另一种颜色来创建双色渐变效果。将“芒果”（`Mango`）色块拖到侧边栏的最底部（但在面板内），你将在面板中获得一个从柚子色到芒果色的渐变。当然，如果你对这组颜色不满意，可以将“重置”色块拖到该区域以返回原始的默认灰色面板。完成后，关闭“背景和图标”窗口。

# 7B-6: 下载并安装艺术管理器 (GNOME Art)

在互联网上搜索要安装的壁纸感觉像是一场冒险，但有时也觉得像项苦差事。对你、我以及所有参与此类的人来说，有一个更简单的方法：艺术管理器（`Art Manager`）。艺术管理器也称为 `GNOME Art`，是一个实用的应用程序，它可以搜索 gnome.org 网站，并下载一份带有缩略图的此处可用壁纸列表。它还可以对你在本项目后续部分使用的各种窗口边框、控件和图标主题执行执行操作。使用缩略图列表，你可以轻松地下载并安装所需的任何内容——完全无需在网络浏览器中放置光标。不用说，艺术管理器绝对酷毙！

遗憾的是，艺术管理器默认没有安装；但在在读完第 5 章后，你知道下载和安装像艺术管理器这样的应用是多么简单。你只需要运行 `Synaptic`，搜索 `gnome-art`，然后安装它。

你可以通过选择“系统 > 偏好 > 艺术管理器”来运行艺术管理器。`GNOME Art` 窗口将会出现，但空空如物。为了使用它并消除空虚感，请进入“艺术”（`Art`）菜单，选择“`GNOME` 背景”。如果你愿意，可以选择“全部”（`All`）而不是“`GNOME`”，但下载可用壁纸列表将花费更长的时间。

一旦做出选择，艺术管理器将开始下载 http://art.gnome.org 提供的所有可用列表。可能一分钟内似乎什么都没有发生，但请耐心等待。完成后，你将看到供你选择的缩略图列表（图 7-11）。

![](img/ba6b82a7869bba748202d57c97336dca_132_0.png)

图 7-11：使用艺术管理器安装桌面壁纸

现在你可以通过向下滚动直到找到一个你心仪的壁纸，点击它使其高亮，然后点击“安装”按钮。艺术管理器将下载它、安装它，然后自动打开“桌面和背景偏好”，这样如果你愿意，就可以立即将其应用到你的桌面。正如我之前提到的，这是一个非常方便的工具，尤其是你很快就会在本项目中更多地使用它了。

# 7B-7: 更改窗口边框、控件和图标集

现在我们到了这段数字美容整形之旅我中最喜欢的部分——更改 `GNOME` 中窗口边框和控件的外观。让我们开始这样做吧。

操作实际上非常简单。进入“系统”菜单，选择“偏好 > 主题”。“主题偏好”窗口将打开，你将看到你系统上安装的主题列表（见图 7-12）。Ubuntu 的默认主题名为“`Human`”，正如你所见，还有其他几个。

为了熟悉情况，请通过逐一点击列出的每个主题来查看。更改将立即生效。只需点击你的窗口边框、控件，甚至如果你看一眼你的主文件夹，还有图标。当你点击 `Crux` 或 `Glider` 时，这种变化尤为明显。

每个主题都由一个窗口边框、一组控件和一组图标组成。正因如此，你可以根据自己的意混合并搭配这些元素。例如，假设你喜欢 `Crux` 中准工业风控件的颜色和设计，但你更偏于 `Mist` 中的图标和 `Human` 中的边框。好吧，你不绝望，因为你可以创建一个由这些不同元素组成的自定义主题。

![](img/ba6b82a7869bba748202d57c97336dca_133_0.png)

图 7-12：在 `GNOME` 中选择主题

要创建你自己的混搭主题，只需点击“主题偏好”窗口中的“自定义”按钮。一个新窗口将打开，你会发现三个标签卡：“控件”、“窗口边框”和“图标”。从这些标签卡中的每一个都可以选择你喜好的组件。首先点击“控件”标签并选择 `Crux`。然后点击“窗口边框”标签并选择 `Human`。最后，点击“图标”标签并选择 `Mist`。

现在保持“主题”窗口打开，但打开你的主文件夹看看你做了什么。嗯……不错。但也许，你并不喜欢所有完全匹配的 `Human` 窗口边框外观。要找到你更喜欢的，再次点击“窗口边框”标签，向下查看列表，点击每个条目直到你看到你喜欢的（`Metabox` 看起来效果不错），并选择它。好点了吗？现在满意了，点击“关闭”按钮。

你将回到“主题”窗口，你会注意到列表顶部有一个名为“自定义主题”的新条目。如果你想保存这个新组合，点击“保存主题”按钮。这样做将打开一个对话框，你可以在其中为主题命名并编写简短说明。所以，为你的主题命名，如果你愿意写写说明，然后点击“保存”。你的新主题现在将按照你选择的名称字母顺序出现在列表中。

一旦完成，你的主文件夹窗口应该看起来像图 7-13 那样（顺便看一眼你的面板和应用程序）。啊，太棒了！

# 7B-8: 额外的窗口边框、控件和图标

好了，现在事情确实有点像 Mac 了，但我们还有更多可以强调的首先。打开 `Nautilus` 窗口，点击“计算机”按钮，并将“文件系统”图标拖到桌面。这将为你的硬盘创建一个别名。接下来，进入底部面板，删除所有“垃圾桶”。之后，通过右键点击垃圾桶右侧的区域并在弹出菜单中选择“属性”，打开面板的偏好窗口。在窗口的“通用”标签中，取消勾选“扩展”，然后将面板增大到 54 像素左右。完成后，点击“关闭”，然后为你使用的应用程序设置启动器。

最后，在顶部菜单中，移除“系统”菜单旁的三个图标。之后，添加一个“窗口选择器”小组件，以便你有一种方式在窗口之间进行切换。你可能还想更改主文件夹中的背景，因为目前的暖色调不再匹配你新的颜色配置。

转换现在已完成，你的桌面应该看起来像图 7-14 那样。你可以坚持使用新的 OS X 风格主题，也可以切换到其他。
