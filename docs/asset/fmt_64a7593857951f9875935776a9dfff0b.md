
`touch /var/lock/subsys/pold` 是强制的，并且与脚本名称相同，如果你希望运行停止序列（`K01pold` 链接）。

6. 使用 `chkconfig` 设置你的脚本在运行级别 3、4 和 5 下启动，在其他运行级别下停止。

```
chkconfig --add pold
```

只有当脚本中存在 `# chkconfig:` 和 `# description:` 行时，上述命令才会生效。
