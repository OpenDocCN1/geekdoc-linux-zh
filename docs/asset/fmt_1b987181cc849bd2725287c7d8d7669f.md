
```
$ ps ax | grep postmaster
```

这应该列出若干进程的进程号，如下所示：

```
263 ? SW 0:00 (postmaster)
777 pl S 0:00 grep postmaster
```

输入以下行，将 `pid` 替换为 `postmaster` 进程的进程 ID（在此例中为 `263`）。（不要使用 `grep postmaster.` 进程的 ID。）

```
$ kill pid
```

**提示** 在在系统启动时启动 PostgreSQL 的系统上，可能有一个启动文件可以实现的功能。例如，在 RedHat 系统上，您可能会发现：

```
$ /etc/rc.d/init.d/postgres.init stop
```

是有效的。此外，将旧目录移出。输入以下内容：

```
$ mv /usr/local/pgql /usr/local/postgresql.old
```

或者替换特定的路径。

### 4. 为您的系统配置源代码
在这一步中，您可以为构建过程指定实际安装路径，并对要安装的内容进行选择。进入 `src` 子目录并输入：

```
$ ./configure
```

随后跟上您可能想要提供的任何选项。对于首次安装，您应该可以在不使用任何参数的情况下完成。要查看完整的选项列表，请输入：

```
./configure --help
```

一些较常用的选项有：

- `--prefix=BASEDIR` 为 PostgreSQL 的安装选择不同的基础目录。默认是 `/usr/local/pgsql`。
- `--enable-locale` 允许您使用本地化（locales）。
- `--enable-multibyte` 允许使用多字节字符编码。这主要用于日语、韩语或中文等语言。
- `--with-perl` 构建 Perl 接口。请注意，Perl 接口将安装在 Perl 模块的位置（通常在 `/usr/lib/perl` 下），因此您必须拥有 root 权限才能成功使用此选项。
- `--with-odbc` 构建 ODBC 驱动包。
- `--with-tcl` 构建需要 Tcl/Tk 的接口库和程序，包括 `libpgctl`、`pgtclsh` 和 `pgtksh`。

$ gmake

### 7. 告诉您的系统如何找到新的共享库
此方法因平台而异。通常通用的方法是设置环境变量 `LD_LIBRARY_PATH`：

```
$ LD_LIBRARY_PATH=/usr/local/postgresql/lib
$ export LD_LIBRARY_PATH
```

您可能想将其放入 shell 文件（如 `~/.bash_profile`）。在某些系统上，以下是首选方法，但您必须拥有 root 权限。编辑文件 `/etc/ld.so.conf` 并添加一行：

```
/usr/local/postgresql/lib
```

然后运行命令 `/sbin/ldconfig.`。如果有疑问，请参考系统的手册页。如果您收到如下消息：

```
/psql: error in loading shared libraries libpq.so.2: cannot open object file: such file or directory
```

那么上一步是必要的——现在执行即可。

### 8. 创建数据库安装
要执行此操作，您必须登录 PostgreSQL 超级用户。以 root 身份运行将无效。

```
$ mkdir /usr/local/postgresql/data
$ chown postgres /usr/local/postgresql/data
$ su postgres
$ /usr/local/postgresql/initdb -D /usr/local/postgresql/data
```

`D` 选项指定数据存储的位置。可以使用任何您需要的路径——不必位于安装目录下。只需确保超级用户可以向该目录写入（如果您已经进行了安装，可能需要临时以 root 身份登录来创建）。

### 9. 启动数据库服务器
上一步告诉您如何启动数据库服务器——因此它将在前台启动服务器。要将其分离到后台，请使用 `-S` 选项。

```
$ /usr/local/postgresql/bin/postmaster -D /usr/local/postgresql/data
```

### 10. 升级
如果您正在从现有安装升级，请将您的数据还原：

```
$ /usr/local/postgresql/bin/psql < db.out
```

您还可能想复制旧的 `pg_hba.conf` 文件以及您设置过的任何其他文件（如密码文件）。安装到此。为了让您的工作更高效、愉快，请查看以下可选步骤和建议。设置一些环境变量会让您的生活更方便。首先，您可能想包含 `/usr/local/postgresql/bin`。由于您已经进行了安装，您可能需要临时以 root 身份登录来创建。确保超级用户可以向该目录写入。

# man xhost
