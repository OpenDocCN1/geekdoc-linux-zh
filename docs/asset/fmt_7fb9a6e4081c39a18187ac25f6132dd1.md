
### 智能调制调器 (Smart Modem) mgetty
`mgetty` 是一个处理调制调器各个方面的用途程序。`mgetty` 还包含基础传真功能，并可用于创建传真。`mgetty-voice` 用于语音功能。`mgetty` 还可以配置为根据电话号码拒绝连接。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### MGI
多功能解释器 (Multi-Function Interpreter) 来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### mgm
一种高度可配置的糟糕的系统加载器。`MGM` 是用 `Perl` 编写的系统加载器，内存占用可能比 `Emacs` 大。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### MGM
内存授予 (Memory Grant) (Informix) 来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### mgp
`MagicPoint`——一个 X11 演示工具。`MagicPoint` 是一种 X11 演示工具，旨在让示例变得容易制作。它的演示文件（通常为 `.mlp`）只是用你喜爱的编辑器（如 `Emacs`）创建的文本。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### mgt
一种原始游戏的记录编辑器。`mgt` 允许用户查看 `SmartGo` 格式的游戏树文件。`mgt` 还具有游戏编辑功能，可用于创建或编辑游戏树。`Mailgo` 是一个使用 `mgt` 作为编辑器来管理电子邮件游戏的工具。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### MH
移动主机 (Mobile Host) (MHP) 来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### MH
改进霍夫曼 (Modified Huffman) (传真) 来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### mh-book
`MH` & `nnh`：用于 `MH` 和 `nnh` 用户代理的后端。这本书由 Jerry Peek 编写，由 O'Reilly & Associates, Inc. 出版。这本书涵盖了 `MH`、`nnh` 以及 `MH` 的几种接口，包括 `xm`、`nmh` 和 `mh-e`。此包是 `http://ics.uci.edu/~mh-book/` 的快速快照。来自 Debian 3.0r0 APT

### mh-e
`mh` 和 `nnh` 用户代理的 GNU 前端。这可能是一个比自由 `Emacs` 软件包更新的 `mh-e` 版本。它还包含了最新的 Info 格式文档，以及未与 GNU Emacs 分发的贡献功能：`mh-aliases.el` 邮件别名和替换，`mh-frame.el`——在独立框架中打开 `mh-e`。`mh-e` 的网页地址为 `http://mh-e.sourceforge.net` 来自 Debian 3.0r0 APT

# Linux 词典

以下特性：
- 简单的数据结构允许你以多种方式操作存储的数据。
- 预约可以以灵活的方式重复。
- 强大但简单的预约表达式。
- 多种用户界面，如命令行(`emacs`/`GUI`/`Web`)。`MHC` 目前具有以下接口；
- 使用 `Mew`、`Wanderlust` 或 `Gnusher`（`Emacs` 世界中流行的 `MUA`）配置的 Elisp 程序包 (`emacs/mhc`)
- `MHC` 以 `MH` 相同的格式调度文章；你不仅可以通过工具操作这些消息，还可以通过许多 `MUA`、编辑器、`UNIX` 命令行或你的 `mhc/.` 目录操作。

欲了解更多信息，你可以在 `http://www.quickhack.net/#mhc/` 处查阅。
