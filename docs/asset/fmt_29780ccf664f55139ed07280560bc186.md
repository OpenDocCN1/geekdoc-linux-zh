## cpbk
用于备份文件的镜像实用程序。Backup 基本上是一个智能程序，允许用户将文件从一个地方复制到另一个地方。在覆盖之前的副本时，关键功能允许拷贝备份中新的或不存在的文件。这节省了时间并减少了对磁盘的负载。在文件复制功能中内置了删除程序。如果从源路径删除了某个文件，则在下次执行备份时删除该文件。这提供了一个与源完全相同的备份，而不会填满磁盘。作为额外选项，在覆盖之前的备份时所有将被覆盖或删除的文件都有机会被存储。你可以根据需要清理备份以释放磁盘空间。来自 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## cpp
`Cpp` 是 GNU C 兼容预处理器。它是一个宏处理器，在 C 编译器编译程序之前，由编译器自动调用。它之所以被称为宏处理器，是因为它允许你定义宏（较长构造的缩写）。C 预处理器提供四种功能：包含头文件（包含声明的文件，这些文件可以替换到你的程序中）；宏展开（你可以定义宏，预处理器会在整个程序中将宏替换为定义）；条件编译（使用预处理指令，你可以根据各种条件包含或排除程序的部分）；以及行号控制（如果你使用程序将源文件合并或重新排列成用于编译的中间文件，可以使用行号控制告知编译器每行源自何处）。源自 Redhat 8.0 RPM

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## cpp
GNU C 预处理器是一个宏处理器，由 GNU C 编译器在实际编译之前自动转换程序。此软件包从 `gcc` 中分离出来，以便那些只需要预处理器而不需要编译器的用户。这是一个依赖包，为 Debian GNU/Linux 系统提供默认的 GNU C 预处理器（架构 i386 版本 2.95.4）。源自 Debian 3.0.0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

## cproto
生成 C 函数原型并转换函数定义。`cproto` 是一个从 C 源码生成函数原型和声明的程序。它还可以在旧样式和 ANSI C 样式之间转换函数定义。此转换会覆盖原始文件，因此请为你的文件创建备份，以防发生故障。源自 Debian 3.0.0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`
