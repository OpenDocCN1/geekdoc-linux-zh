
# Linux 词典

### postgresql
PostgreSQL 是一个对象关系数据库管理系统 (DBMS)，支持几乎所有的 SQL 结构（包括事务、子集以及用户定义类型和函数）。PostgreSQL 包包含了访问 PostgreSQL DBMS 服务器所需的客户端程序和库。这些 PostgreSQL 客户端程序是直接操作 PostgreSQL 服务器上 PostgreSQL 数据库内部结构的程序。这些程序可以位于与 PostgreSQL 服务器相同的同一台机器上，也可以位于通过网络连接访问 PostgreSQL 服务器的远程机器上。此包包含了 C 和 C++ 的库，以及用于管理 PostgreSQL 服务器上 PostgreSQL 数据库的命令行实用程序。如果你需要操作远程 PostgreSQL 服务器上的 PostgreSQL 数据库，你需要这个包。如果你正在安装 `postgresql-server` 包，也需要安装此包。源自 Mandrake 9.0 RPM http://www.tld.org/LDP/linux-Dictionary/index.html

### postilion
一个处理 MIME、PGP 和拼写检查的邮件用户代理 (MUA)。它主要用 C 编写，但用户界面使用 tcl/tk。以下是非穷尽举的功能列表：
- 多语言界面
- MIME 支持
- 撰写
- 多地址
- 消息数据库
- 虚拟文件夹
- 消息挂起
- “输入时”拼写检查
- POP3 和 IMAP 文件夹
- 支持交付通知
- 支持 PGP/MIME
源自 Debian 3.0 APT http://www.tld.org/LDP/linux-Dictionary/index.html

### Posting
网络通信系统的单条消息。源自 Matisse http://www.tld.org/LDP/linux-Dictionary/index.html

### postit
一个从你的本地新闻服务器向另一个主机发送新闻 (de) 的程序。源自 Debian 3.0 APT http://www.tld.org/LDP/linux-Dictionary/index.html

### postmark
来自 NetApp 的文件系统基准测试。一种围绕数据操作的基准测试。源自 Debian 3.0 APT http://www.tld.org/LDP/linux-Dictionary/index.html

### postmark
邮局
在 PostgreSQL 服务器上通过网络连接访问 PostgreSQL 服务器的远程机器。一个邮件处理系统。它发送的邮件中带有 X-Post 报头，如果有人使用它，则很容易通过代理进行获取。源自 Jargon Dictionary http://www.tld.org/LDP/linux-Dictionary/index.html

### postmaster
邮件处理系统 (RFC-222) 中的邮件管理员。源自 Jargon Dictionary http://www.tld.org/LDP/linux-Dictionary/index.html

### postnews
通过命令行向 Usenet 发送文章的文章。源自 Debian 3.0 APT http://www.tld.org/LDP/linux-Dictionary/index.html

### PostScript
由 Adobe Systems 开发的页面描述语言，用于在页面上显示文本或图形。源自 I-gloss http://www.tld.org/LDP/linux-Dictionary/index.html

### PostScript
由 John 和 Evans 在 1976 年开发并最终由 XEROX 实现的复杂页面语言 (PDL)。Postscript 使用位图映射来描述图像（黑客们认为 Postscript 在所有方面都更优）。源自 Jargon Dictionary http://www.tld.org/LDP/linux-Dictionary/index.html

在激光打印机或其他打印网上生成的 Postscript 代码。Postscript 是一种输出高质量文档的编程语言 (PDL)。源自 QUED http://www.tdlp.org/LDP/Linux-Dictionary/index.html

### PostScript (PS)
一种标准的文档渲染语言，将文档文本、图像和边界视为对象。大多数打印机都可以输出 PS 文档，大多数桌面出版应用都可以渲染 PS 文件。源自 Redhat-9--Glossary 300 dpi

### PostScript Fonts
适用于 OS/2、Windows 和 X 窗口系统的各种字体。包含 `.afm`、`.pf` 扩展的文件。有些被称为 Adobe Type 1 字体或 ATM (Adobe Type Manager) 字体通常需要支持 PostScript 的打印机。（另外请参见 BDF 和 TrueType 字体）。源自 I-gloss http://www.tld.org/LDP/linux-Dictionary/index.html

### POSYLB
用于分布式应用程序的编程语言。源自 VERA http://www.ldp.org/LDP/Linux-Dictionary/index.html

### potool
一个辅助处理 gettext po 文件的程序。此包包含过滤器 `potool` 以及一些辅助脚本：
- `poedit` 帮助在你喜欢的编辑器中编辑 po
- `posts` - 打印文件的统计信息
源自 Debian 3.0r0 apt http://www.ldp.org/LDP/linux-Dictionary/index.html

### POTS
普通电话系统 (语言、Usenet、IRC)。源自 VERA http://www.ldap.org/LDP/linux-Dictionary/index.html

### POV
视觉暂留 (光线追踪)。源自 VERA http://www.ldp.org/LDP/linux-Dictionary/index.html

### POWER
基于 RISC 的功率优化 (芯片) (IBM、苹果、摩托罗拉)。源自 VERA http://www.ldp.org/LDP/linux-Dictionary/index.html

### power-apple
GNOME 电池量监控应用，用于读取 `/proc/apm` 的 GNOME 面板程序。它有主题功能（很糟糕），并能执行一些巧妙的操作，例如在电量低时（因为电量低，所以你不希望在动画上浪费 CPU 周期周期）。源自 Debian 3.0r0 apt http://www.ldp.org/LDP/linux-Dictionary/index.html

### powermaga
一款基于 X11 的具有彩色 3D 图形的纵版射击游戏。Powermaga 是一款包含 60 种敌人、40 颗陨石、多种武器、许多关卡 Boss、飞船强化道具以及其他内容的射击游戏。来自 Debian 3.0 apt
http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### poweroff
停止系统。来自 http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### powershell
用于 Gnome Shell 的电源终端模拟器，是一个基于 GNOME/GTK 的模拟器，它在单个窗口中支持多个终端（仅受内存限制）。每个终端作为一个“笔记本”标签页，可以在不同终端之间进行切换。它还具有 URL 识别能力、透明度、位图背景等功能。来自 Debian 3.0 apt
http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### powerweak
优化性能的工具，是一种用于调整 Linux 系统以达到巅峰性能的工具。它调整 PCI 使用最佳设置并启用 CPU 的性能增强功能。此包不包含任何文件。只有当你安装了以下包：`powerweak`、`powerweak-extra`、`powerweak-gtk`，它才会生效。来自 Debian 3.0 apt
http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### powerweak
优化性能的工具，是一种用于调整 Linux 系统以达到巅峰性能的工具。它调整 PCI 使用最佳设置并启用 CPU 的性能增强功能。要使用 `powerweak` 的所有功能，你需要支持 `/proc/busci` 和 `/dev/cpu2` 接口的 Linux 内核。此包包含需要进行本地调整的守护进程。你需要 `powerweak-extra` 或 `powerweak-gtk` 来选择你想在系统上执行的操作。`powerweak-extra` 包包含了一些额外的调整。来自 Debian 3.0 apt
