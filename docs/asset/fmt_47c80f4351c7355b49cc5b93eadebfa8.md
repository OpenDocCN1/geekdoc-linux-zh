
`NSurf`允许你在`NURBS`对象的堆栈中任何位置放置子对象选择。这与`Mesh Select`修改器类似，但仅对`NURBS`对象可用。

# 世界空间修改器 (World-Space Modifiers, WSMs)

世界空间修改器是使用世界空间作为参考点的修改器，而不是其所绑定的对象对象空间。`MapScalar`修改器是`WSM`的一个示例，因为它将对象的贴图与世界空间关联，不受其所附对象对象空间的影响。使用`MapScalar`修改器可以缩放为任何大小或形状，并且附加到对象上的任何贴图都不会被缩放。

# 相机贴图 (CAMERA MAP, WSM)

有时，你可能希望一个对象在场景中保持存在的同时是不可见的。例如，假设你有一个显示车库的相当复杂的背景图像，你想创建一个汽车进入车库的幻觉。你可以创建一个简单的盒子，其开口形状与背景车库的开口相似，然后使用`Camera Map`修改器将盒子融合到背景中。一旦完成操作，你就可以在最终动画中让汽车驶入车库。这允许你保持几何形状简单，同时拥有显示大量细节的动画。

`Camera Map`修改器对对象应用平面`UVW`贴图，并对齐该贴图使其与指定的摄像机垂直。贴图通常与背景相同，产生不可见对象的幻觉。由于该对象可以捕捉并接收阴影，你可以创建不同的效果。例如，如果你正在使用`Camera Match`工具将建筑设计与建筑场地的照片匹配，你可以使用`Camera Map`修改器在背景中的建筑上包含阴影。

此修改器可以在摄像机移动运行，因为它会在每帧更新贴图。还有一个对象空间修改器（`OSM`）版本。

# 置换网格 (DISPLACE MESH, WSM)

`Displace Mesh`允许你使用位图图像变形表面。它类似于材质中的物体置换贴图，但它不是简单地通过改变表面法线来创建凹凸表面的幻觉，`Displace Mesh`实际上改变了凹凸表面的几何结构。有关`Displace Mesh`修改器的详细描述，请参见第15章。

如果你为对象分配置换贴图，通常在渲染之前无法看到贴图的效果。`Displace Mesh`修改器允许你在编辑时看到置换贴图的效果。正如第15章所述，`Displace Mesh`还可以让你将置换贴图转换为可编辑网格。

# 置换 NURBS

`NURBS`修改器执行与`Displace Mesh`修改器相同的功能，但它应用于`NURBS`对象。

# LS 颜色 (LS COLORS, WSM)

`Lightscape`是一个用于计算辐射解决方案的`Autodesk`独立产品。`Autodesk`不再提供或支持`Lightscape`，但旧场景可以导入`VIZ`。`LS Colors`修改器将`Lightscape`辐射网格颜色转换为`Autodesk VIZ`顶点颜色。当你从`Lightscape`将光照解决方案（`*.lis`文件）导入`VIZ`时，这非常有用。

# 利用 Lightscape 材质 (UTILIZING LIGHTSCAPE MATERIALS)

你可以使用`Lightscape Materials`工具来帮助将光照解决方案数据转换为`VIZ`。

# 贴图缩放 (MAPSCALAR, WSM)

当你希望材质贴图保持其原始比例时（无论应用对象的比例如何），请应用此版本的修改器。此修改器允许你“锁定”贴图的比例，因此对象的变化不会影响关联贴图。使用`OSM`版本将关联贴图的比例锁定到对象空间。

# 补丁变形 (PATCHDEFORM, WSM)

此修改器允许你根据`Patch`对象的形状变形对象。`Patch`对象是一种可以通过编辑顶点形成平滑、弯曲表面的对象。例如，你可以创建一个平面并将平面转换为可编辑补丁。然后可以编辑可编辑补丁的顶点，以将平面塑成你想要的任何形状的平滑、弯曲表面。此类表面可以使用`PatchDeform`修改器来变形其他对象。使用此修改器的`OSM`版本，对象将移动到补丁的位置。

# 路径变形 (PATHDEFORM, WSM)

`PathDeform`修改器的工作方式与`PatchDeform`修改器类似，但它使用样条或`NURBS`曲线而不是`Patch`对象。例如，你可以使用此修改器沿样条路径变形对象。一个例子是文字弯曲以适应柱子或球体的形状。在此版本的修改器中，对象将移动到路径处进行变形。另见`OSM`版本。

# 细分 (SUBDIVIDE, WSM)

`Subdivide`修改器允许你手动对对象应用辐射网格。`Subdivide`修改器的工作方式与第11章中的辐射网格化参数类似，但它不是全局应用网格，`Subdivide`允许对单个对象或子对象层级应用网格。如果是修改器，可以直接从修改器堆栈进行编辑。使用此修改器，细分网格的大小锁定在世界空间；如果缩放对象，网格保持大小不变。

# 表面映射器 (SURFACE MAPPER, WSM)

`UV Map`修改器有一组固定的七种映射选项，允许将贴图应用于大多数形式。但当这些选项都不适用于你的设计时会怎样？如果你有一个需要自定义映射的有机形状，你可以使用`Surface Mapper`修改器。`Surface Mapper`要求你使用编辑的`NURBS`表面将其调整为所需贴图的形状。你在应用贴图的物体周围形成`NURBS`表面，并对`NURBS`表面和对象分配相同的材质。完成后，对对象或多个对象应用`Surface Mapper`修改器。贴图根据`NURBS`表面上法线的方向投影到修改器上。在此版本的修改器中，`UV`空间的比例与世界空间绑定；如果缩放对象，`UVW`坐标将保持原始大小。

# 表面变形 (SURFDEFORM, WSM)

`SurfDeform`修改器的工作方式与`PathDeform`修改器类似，但它使用`NURBS`表面而不是曲线。你可以使用此修改器根据`NURBS`表面的形状变形对象。此版本锁定在世界空间。

# 对象空间修改器 (Object-Space Modifiers)

这些修改器在对象自身的局部坐标系中影响对象。在处理纹理贴时，对象空间通常使用`UVW`坐标描述。

# 影响区域 (AFFECT REGION)

影响区域允许你对表面应用凸起。两个点控制凸起：一个点设置凸起的基部，另一个点确定凸起的顶点。每个点都可以独立进行调整。你可以通过衰减（`Falloff`）、收缩（`Pinch`）和气泡（`Bubble`）参数来控制凸起的形状。

# 自动展平 UV (AUTOMATIC FLATTEN UVs)

这与`Unwrap UVW`修改器相同。该修改器由“渲染到纹理”（`Render to Texture`）操作自动应用。

# 弯曲 (BEND)

你可以使用`Bend`修改器在任何轴上弯曲对象。你可以控制弯曲的程度、发生的位置以及发生的轴。该修改器将在第2章中演示。

# 倒角 (BEVEL)

倒角允许你挤出`2D`形状并添加倒角。该修改器的倒角值（`Bevel Values`）面板允许你设置挤出的高度。每个层都有自己的高度和轮廓设置，因此你可以通过调整高度以及在所选层上扩展或收缩轮廓形状来控制倒角。表面（`Surface`）参数允许你控制挤出的段数以及侧面是弯的还是直的。通常，`Bevel`用于文字倒角，但也可以用于其他形状（见图 B.1）。

# 相机修正修改器 (CAMERA CORRECTION MODIFIER)

广角相机视图往往会夸大高物体的三点透视。例如，建筑的顶部看起来太快地收缩成一个尖点。相机修正修改器允许你减少这种失真。
