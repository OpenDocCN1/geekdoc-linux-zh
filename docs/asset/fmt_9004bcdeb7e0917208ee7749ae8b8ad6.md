## 命名空间

命名空间定义了域名及其 IP 地址在系统中的排列方式。它为设备提供了唯一的符号名称，并规定了名称可以拥有的字符（符号）数量。每个命名空间使用特定的结构，描述了名称是如何构建和解释的。命名空间遵循平直命名空间结构或层次命名空间结构。

让我们在后面的章节中讨论命名空间结构。

## 平直命名空间

在平直结构中，每个名称都被分配一个特定的地址。平直命名空间将名称和地址在两个独立的列中。这种结构的缺点是无法在大型网络中使用。

## 分级命名空间

分级命名空间结构是一种树形结构，它由各种层级组成，例如组织的名称、类型和部门。在这种结构中，中央控制和权限被分配给单一层级，由它管理一组其他层级。

## 域名空间

域名空间是基于分级命名空间设计的。图 AT-2.21 显示了一个根节点在顶部的倒置树结构。从 0（根级）到 127（最高级），一个树最多可以有 128 层。DNS 中的名称是不区分大小写的，例如，`express` 被视为 `Express` 或 `EXPRESS`。

## 介绍 Telnet

Telnet 是一种帮助一台计算机的用户访问另一台计算机的程序。它是 TCP/IP 网络（如互联网）的终端仿真程序。用于访问的计算机必须是 Telnet 客户端以便连接 Telnet 服务器。Telnet 管理员或其他用户可以访问任何计算机。当 Telnet 客户端与远程主机连接时，客户端变为允许您与远程主机通信的虚拟终端。HTTP 和 FTP 协议允许您从远程计算机上传和下载特定文件。通过 Telnet 访问计算机，您的权限保持不变。Telnet 通常运行在 TCP/IP 端口 `23` 上。您需要在命令提示符处输入 `telnet` 命令，后跟远程主机的 IP 地址来访问计算机：

```
Telnet 192.168.1.30
```
