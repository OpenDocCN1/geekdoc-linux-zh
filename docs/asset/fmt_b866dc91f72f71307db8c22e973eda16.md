
# Linux 词典

## pident
TCP/IP IDENT 服务器。`pident` 是一个实现了 RFC 1413 提出的 IDENT 用户识别协议的服务器。来自 Debian 3.0r0 APT
http://www.tldp.org/LDP/Linux-Dictionary/html.index

## pident-des
支持 DES 的 TCP/IP IDENT 服务器。`pident` 是一个实现了 RFC 1413 标准 IDENT 用户识别协议的服务器。该包已使用 DES 构建。来自 Debian 3.0r0 APT
http://www.tldp.org/LDP/Linux-Dictionary/html.index

## pake
强大的解释型编程语言 Pike 是一种解释型的、面向对象的、动态编程语言，其语法与 C 语言相似。它具有许多强大的类型和模块系统，例如，它提供了图像处理、数据库连接和加密功能。源自 Debian 3.0r APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pileup
用于 SB 兼容音轨的斯电码叠加器。`Pileup` 是一个使用指定数量 SoundBlaster 声道生成信号的 {程序。这模拟了 CW 密集呼（pileup）的声音。该生成器根据你在业余无线电大会使用的磁带上发出的声道数量来测试人们的技能。然而，它更具随机性且可以更高效！你必须使用兼容音频或 soundblast 的声卡。源自 Debian 3.0r0 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pilot-link
此套件允许你为 LINUX/UNIX 机器和带有 Ical 的 PalmPilot 应用上传和下载文件。注意，如果你需要 Python、Tcl 或 Perl 绑定，你可能还需要考虑 `pilot-link` 的源码。如果你想将你的 Palm 与 Redhat Linux 系统同步，则使用 `pilot-link`。源自 Redhat 8.0 RPM
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pilot-link
通过串口与 3COM PDA 通信的工具。`pilot-link` 是一组与 3COM Palm PDA 通信的工具。源自 Debian 3.0r APT
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pilot-link-perl
通过串口与 3COM PDA 通信的 Perl 工具。此包提供了能够直接与 Pilot 通信的 Perl 程序。源自 Debian 3.0r APT
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pilot-manager
PalmPilot PIM、UI 和 Conduit PilotManager 是一个允许你将 3COM PalmPilot 上的数据库与 Unix 平台上的应用程序进行同步的工具。它是一个更易用的 HotSync 守护进程。开发者可以编写自己的客户端，将 Pilot 数据库与选定的桌面应用程序进行同步。源自 Debian 3.0r APT
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pilot-template
PalmPilot 程序的代码生成器，`pilot-template` 将为 Palm It 编程生成骨架代码、Makefiles、图标等。它最好配合 `prec-tools`（允许你为 Debian 机器编译）和 `pilrc`（Pilot 资源编译器）一起使用，这些工具也可以作为 Debian 包提供。源自 Debian 3.0r APT
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## pilrc
PalmOS 资源编译器，PilRC 是适用于运行 Palm 系统的 PDA 的资源编译器。它旨在与 `prc-tools` 包提供的 PalmOS GCC 交叉编译器配合。此版本的 PilRC 包含了 `pilircui`（基于 GTK 的测试版 PilRC 前端）。源自 Debian 3.0r0 APT
http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
