# man：显示系统手册

除了图形帮助中心外，`man` 工具将其输出发送到分页器（通常是 `less`），它一次显示一个屏幕。当你访问手册页时，`less` 在底部显示提示 [例如，手册页 (1) 第 1 行]。在显示每个屏幕后，按空格你需要另一个屏幕。你也可以使用 PAGE UP、PAGE DOWN 方向键导航文本。按 `h`（帮助）显示命令列表。按 `q`（退出）停止 `less` 并让 shell 显示提示。
