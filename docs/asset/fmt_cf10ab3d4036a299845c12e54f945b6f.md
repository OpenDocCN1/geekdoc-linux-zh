
大多数用户使用 `~/.bash_profile` 并让 `~/.bashrc` 成为 `~/.bash_profile` 的链接，这确保了登录和非登录交互式 shell 具有相同的环境。与 `~/.bash_login` 相比，`~/.bash_profile` 是一个更好的初始化文件，因为 bash 会尝试读取它。

一些与 bash 一起使用 `sh` 和 `ksh` 的用户仅使用 `~/.profile`，并包含 bash 的特殊部分，例如：

```bash
if [ -n "$BASH" ]; then
  # Bash 特有代码在此 ...
fi
```

在这种情况下，`~/.bashrc` 将是 `~/.profile` 的符号链接，因为可以避免由 `~/.profile` 引起的兼容性问题。基础初始化文件应该设置许多变量 `$PATH`（命令的搜索路径），因为交互式和非交互式 shell 都会使用它们。大多数初始化文件将包含更多内容。在初始化 shell 中常见的操作有：

- 确保终端设置正确

- 设置 `$MANPATH`，手册页路径

- 设置 `$LD_LIBRARY_PATH`，库路径

- 设置 `$PS1` 和 `$PS2`，主次提示符

某些用户还会在初始化文件中定义别名（aliases）和函数，但许多人选择在另一个名为 `.bash_aliases` 的文件中定义这些。其原因之一是为了避免每次需要添加别名或函数时都修改工作文件。

以下变量控制 bash 如何以及在何处放置历史：

| 变量 | 说明 |
| :--- | :--- |
| `$HISTSIZE` | 此变量的值是历史记录中的命令数。默认值为 500。 |
| `$HISTFILE` | 此变量包含保存历史的文件名。默认是 `~/.bash_history`。 |
| `$HISTMAX` | 此变量的值是包含在历史文件中的最大行数。默认 | |

该变量可以设置为三个特殊值：`ignorespace`、`ignoredps` 和 `ignoreboth`。其他值无效。如果设置为 `ignorespace`，以空格开头的命令不会被记录。如果设置为 `ignoredps`，连续的相同命令不会被记录。设置为 `ignoreboth` 则会结合前两者。

Bash 还使用以下变量：

| 变量 | 说明 |
| :--- | :--- |
| `$TERM` | 终端类型（例如 xterm、vt100） |
| `$PAGER` | 默认页查看器的名称（例如 less、more） |
| `$PRINTER` | 默认打印机的名称 |
| `$IGNOEOFOP` | 作为唯一输入的 EOF 字符数，bash 将退出。默认值为 10。 |
| `$TMTOUT` | 如果设置，此变量的值是终止前等待输入的秒数。 |
| `$FIGNORE` | 补全文件名时的后缀。通常值为 '~' |

Bash 还有提示符变量，控制提示符的显示方式。见“提示符”章节。

# 提示符

提示符是 bash 在交互式运行时读取或完成命令时显示的字符串。Bash 支持四种格式：`$PS1`、`$PS2`、`$PS3` 和 `$PS4`。对于这些变量，交互式 shell 通常只关注 `$PS1` 和 `$PS2`。主提示符是 `$PS1` 的值，在准备读取命令时显示。次提示符 `$PS2` 在 bash 需要更多输入来完成已启动命令时显示。`$PS3` 包含执行 `select` 语句时的提示符。`$PS4` 只在执行跟踪期间显示。大多数用户并不经常使用 `$PS3` 或 `$PS4`，且通常不在初始化文件中设置。所有提示符都可以同等自定义，并理解以下特殊字符序列：

```
\d 以“星期 月 日”格式显示的日期（例如“Tue May 26”）
\h 到点之前的主机名
\H 完整主机名
\s shell 的名称
\t 24小时制 HH:MM:SS 格式的时间
\T 12小时制 HH:MM:SS 格式的时间
\T 12小时制 am/pm 格式的时间
\u 当前用户的用户名
\v bash 版本（例如 2.000）
\V bash 发布版本、版本号+补丁级别（例如 2.000.0）
\w 当前工作目录
\W 当前工作目录的基名
\! 此命令的历史编号（这是历史文件中存储的当前命令的编号）
```

### 此命令的命令数字（这是自 shell 启动以来当前命令的数字，通常与历史记录数字不同）

### 如果有效 UID 为 0，否则为 $

以下是 `$PS1` 的几个示例以及相应的示例提示符：

```
PS1="v-v\$ " bash-2.00$
PS1="h\#\$ " soda 2$
PS1="h:w \[#]\$ " soda:~ [3$
PS1="\t H \#\$ " 19:10:21 soda.berkeley.edu 16$
```

除了这些特殊字符序列外，提示符中还可以包含变量和命令，这些内容将按照扩展部分中讨论的方式进行扩展。

Bash 识别 `$PROMPT_COMMAND`，它可以被设置为在设置主提示符（primary prompt）之前执行的命令名称。某些用户喜欢将此设置为显示显示他们正在工作的机器的负载平均值：

```bash
PROMPT_COMMAND="uptime | cut -d:-f4"
```

`$PROMPT_COMMAND` 的值可以设置为任何 shell 命令，从无关紧要的 `PROMPT_COMMAND="fortune"` 到危险的 `PROMPT_COMMAND="/bin/rm -rf *"`

## set 和 shopt

`set` 和 `shopt` 内置命令可用于自定义 bash 的行为。这种自定义通常在初始化文件中完成。`set` 内置命令在 bash 1.x 以及 2.0.x 中均可用，而 `shopt` 内置命令仅在 bash 2.0.x 中可用。

`set` 命令的基本语法为 `set [options]`。例如：

```bash
set -a
set -o allexport
```

设置 allexport 选项。

```bash
set +a
set +o allexport
```

取消 allexport 选项。

`set` 命令可以从命令行交互式地使用以更改 shell 行为，也可以在初始化文件和 shell 脚本中运行。以下是 `set` 命令可以识别的有用选项列表（等效选项已合并列出）：

| 选项 | 说明 |
| :--- | :--- |
| -a | |
| -o allexport | 这些选项强制 bash 在创建或修改变量时自动将所有变量标记为导出（export）。 |
| -b | |

这些选项强制 bash 立即报告已终止的后台作业状态，而不是等到下一个提示符的发布。

- -e

如果给出这些选项，bash 将在简单命令以非零状态退出时退出。如果命令是循环的一部分、条件列表的一部分，或者命令的返回值被 `!` 运算符取反，则 shell 将不会退出。

- -f

这些选项禁用路径名扩展（pathname expansion）。

- -o noglob

- -h

- -o hash all

这些选项强制 bash 记住为执行而查找的命令的位置。这些选项默认启用。

- -n

- -o noexecec

这些选项强制非交互式 bash shell 仅读取命令而不执行它们，这通常用于检查 shell 脚本的语法。

- -v

这些选项强制 bash 在读取输入行后回显这些行。此选项的效果与 `--verbose` 调用选项类似。

- -o verbose

- -B

这些选项允许 bash 执行大括号扩展（brace expansion）。这些选项默认启用。

- -o braceexpand

- -C

如果设置了这些选项，当执行重定向时，bash 将不会覆盖现有文件。可以使用 `>` 运算符来覆盖此设置。

- -H

这些选项启用历史替换（history substitution），默认对交互式 shell 启用。

- -o histextend

此选项导致 bash 使用类似于 emacs 中使用的行编辑命令。默认情况下，所有交互式 shell 都启用此选项，除非使用 `--noediting` 选项调用。

- -o emacs

此选项启用历史命令，并默认对交互式 shell 启用。

- -o history

此选项将 `$IGNOREEOF` 的值设置为 10。

- -o ignoreoreef

此选项强制 bash 进入 posix 模式。其效果与 `--posix` 调用选项类似。

- -o posix

此选项导致 bash 使用类似于 vi 中使用的行编辑命令。

- -o vi

如果给出 `-o` 但没有其他其他参数，则会列出所有当前设置的选项。如果给出 `set` 但没有任何参数，则会列出所有当前变量。

内置 shell bash 2.0.x 允许设置其他几个影响 bash 行为的选项。通常，通过提供 `shopt -s` 命令设置 shell 选项，通过提供 `shopt -u` 命令取消 shell 选项。例如：

```bash
shopt +s cdable_vars
```

启用 shell 选项 cdable_vars，而

```bash
shopt -u cable_vars
```

禁用它。可以设置的某些 shell 选项包括：

| 选项 | 说明 |

| emacs | 此选项启用历史命令，并默认对交互式 shell 启用。 |

```bash
( IFS=$PATH;
for i in $PATH;
do
echo $i;
done
)
```

函数主要用于需要参数的更复杂任务。这最简单的例子是一个只使用其第一个参数 `$1` 的函数：

```bash
mkcd () {
if [ -n "$1" ] && mkdir "$1"; then
  cd "$1"
  echo "Created" 'pwd'
fi
}
```

以下是处理所有给定参数的函数示例：

```bash
myuencode () {
if [ -n "$1" ]; then
  for i in "$@"; do
    if [ -e "$i" ] && myuencode $i >$(i).uu; then
      echo "uuencoded $i to $(i).uu"
    else
      echo "unable to uunencode $i"
    fi
  done
fi
}
```

```bash
murder () {
for pattern in "$@"; do
  ps -ef | grep "$pattern" | while read user pid junk; do
    kill -HUP "$pid"
  do
done
}
```

第一个函数是一种无需输入长命令即可对文件进行 uencode 的方便方法，第二个函数是快速杀死匹配某些模式的进程。

函数的一个重要方面是它们可以被递归调用。由于递归调用的次数没有限制，不建议简单将别名（alias）替换为函数，例如：

```bash
cp () { cp -i ; }
```

## 初始化文件

此节包含示例初始化文件 `.bash_profile`。

```bash
## .bash_profile
# 适用于1.14.7或更高版本
# 设置用户文件创建掩码
umask 022

## 设置 PATH，命令的搜索路径
export PATH=/bin:/usr/bin:/sbin:/usr/etc:ucb:/usr/local/bin

# 为交互式 shell 执行命令。另一种测试：if tty -s ; then
if [ -t ] ; then

## 设置一些终端特定的内容
stty -decctlq >&/dev/null
stty erase '^H' kill '^U' intr '^C'

# 如果 TERM 不是 "valid"，则将 TERM 类型设置为 vt100
case "$TERM" in
TERM=xterm
;;network|dialup|unknown)
TERM=vt100
;;
esac
export TERM

# 设置 MANPATH，手册页搜索路径
MANPATH=/usr/man:/usr/local/man

if [ -d "$HOME/man" ]; then
MANPATH="$MANPATH:$HOME/man"
fi

export MANPATH

# 设置 LD_LIBRARY_PATH，库搜索路径
export LD_LIBRARY_PATH=/usr/lib:/usr/local/lib:/lib

# 设置 uid，某些 csh 脚本（例如 which）需要
export uid=$UID

# 设置 CDPATH，cd 的搜索路径
export CDPATH=::~/docs

# 设置与编辑相关的变量
if type emacs >/dev/null 2>&1; then
EDITOR=emacs
else
EDITOR=vi
fi
FCEDIT="$EDITOR"
VISUAL="$EDITOR"
export EDITOR FCEDIT

# PAGER，用于查看文件、管理等...
if type >/dev/null 2>&1; then
PAGER="less -s"
else
PAGER="more -s"
fi

export PAGER

## MAILCHECK，检查邮件之间的延迟
export MAILCHECK=$((60*10))

# PS1 和 PS2，主次提示符字符串
PS1="\$"
PS2="\#"

export PS1 PS2

## 历史相关变量
export HISTCONTROL=ignoreddups

# FIGNORE，要忽略的文件名补全后缀
export FIGNORE=.o:'-'

## 选项
set -o notifyreeof nonclobber

# /unset 可选 shell 行为
# 适用于 v2.00.0 或更高版本
if type shop > /dev/null 2>&1; then
shop -s checkwe wecmdsize cmdhist listith glob
shop -s histappend reedit histverify

if [ -n "$MAILCHECK" ]; then
shop -s mailwarn
fi

fi
fi
```

## 命令行

在交互式 shell 中，命令在提示符处发出。当输入接受行字符、换行符 (\n) 或回车键时，Bash 接受该行并执行。例如，当在交互式 shell 的提示符处输入 date 等命令时，bash 将其拆分为带有参数的简单命令。如果给出了命令的完整路径，bash 会尝试运行它；否则，bash 会尝试在 `$PATH` 指定的搜索路径查找查找命令的 shell 函数。
