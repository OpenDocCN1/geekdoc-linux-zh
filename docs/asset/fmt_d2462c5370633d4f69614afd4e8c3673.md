（我通常称这种为反引号。）

`perl` 允许你用反引号包裹命令，但也允许你使用 `qx/command` 代替 `command` - 这是一个很好的功能，因为反引号很难看除非你戴着眼镜（在打印的页面上，反引号很容易被误认为是 'qx' 是 'Quoted execution' 的缩写）。

以下是使用反引号的几个示例：

以下行等于：

```bash
mmdd=$(date +%b%d)      # ksh or bash
mmdd=$(date +%b%d)      # ksh or bash
mmdd=$(date +%b%d)      # Perl
mmdd=$(date +%b%d)      # Perl
```

在 `date` 展开之前，我们的 `print` 语句看起来这样：

`print "TODAY IS $mmdd"`
