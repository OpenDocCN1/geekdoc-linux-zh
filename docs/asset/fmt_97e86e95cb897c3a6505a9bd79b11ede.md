# 第 24 章 使用 FTP 进行远程文件服务

可以使用`-u`选项在命令行传递用户名（和密码）。你可以利用此来减少检索远程文件时所需的交互式输入，在在shell脚本中使用`lftp`时提供帮助，以及当`lftp`作为后台进程检索文件时使用。

通过使用连接符`&`，检索将在后台进行，如上一个示例所示。`jobs`命令用于显示当前的传输。如果用户退出会话（使用`by`命令），如果文件传输尚未完成，它将作为后台进程继续。（这可以通过`ps`命令验证。）

`lftp`客户端具有许多额外功能，可以让文件传输工作比使用其他FTP客户端更简单。

Fedora包含的另一个实用的文本文件传输工具是`curl`，它支持通过HTTP进行文件检索。

## 使用 wget 命令进行文件传输

当启用远程代理时，`wget`命令用于通过FTP、HTTP以及HTTPS和SFTP等各种安全协议进行文件传输。与其他FTP客户端不同，`wget`只支持非交互式传输。这实际上是一个特性，因为`wget`可以作为后台进程下载文件，并递归地检索远程文件目录。该命令还支持下载部分下载的文件，这在连接断开或中断期间可以节省大量时间。
