# SOCKS V4 ⻙ SOCKS V5

目前流通中有两个版本的协议：`SOCKS V4` 和 `SOCKS V5`。它们都具有以下优点：

- `SOCKS` 缓解了出站连接对任何形式的伪装或 `NAT` 的需求，并提供了与其他代理类似的日志记录。

- 即使你不需要任何形式的地址转换，使用 `SOCKS` 守护进程也可以保护你客户端的（`IP`）身份（就像任何其他代理一样）。

- `SOCKS` 不依赖于应用程序协议，并且包含了针对更复杂的 `TCP` 协议（如 `FTP`）的扩展。
