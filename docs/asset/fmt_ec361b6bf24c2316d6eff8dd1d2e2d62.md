
# Red Hat Linux：第三版

## 专家洞察

本书对红帽 Linux 发行版的核心功能和复杂性进行了重点浅出的解释，包括：

- 安装和配置红帽 Linux 发行版
- 对为您的计算机配置窗口系统（Window System）进行了广泛介绍。关于系统管理、安全和网络服务的详细、及时的建议。

## 强大的软件

CD-ROM 包含：

- 最流行的红帽 Linux 5.2 发行版的最新版本
- 超过 1000 种系统管理、开发和其他软件工具
