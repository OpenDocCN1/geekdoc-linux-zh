
最后，您需要配置 `DHCP` 服务器以接受来自 `PXE` 客户端的请求。配置 `DHCP` 服务器是一个简单的过程，我们将在第 19 章中介绍。这意味着您需要在一台 Linux 计算机上配置 `DHCP` 服务器；家庭路由器上的 `DHCP` 服务器可能无法胜任。您可能需要向 `/etc/dhcpd.conf` 文件中添加以下几行：

```
allow booting;
allow bootp;
class "pxclients" {
```
