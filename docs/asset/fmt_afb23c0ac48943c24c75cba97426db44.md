`fetchmail`

`Fetchmail` 是一种远程检索和转发工具，用于按需连接的 TCP/IP 链接、SLIP 或 PPP 连接。`Fetchmail` 支持目前互联网上使用的远程邮件协议（POP2, POP3, RPOP, APOP, POP3, 所有 IMAPs, SMTP ETRN, IPv6 和 IPSec）进行检索。然后 `Fetchmail` 将其转发到你的 SMTP，这样你就可以通过喜欢的邮件客户端阅读它。如果你需要通过 SLIP 或 PPP 连接检索邮件，请安装 `fetchmail`。源自 Redhat 6.0 RPM

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

`fetchmail`

POP3, IMAP, IMAPS getcatcher/(加密加密的) `fetchmail` 是一个免费、功能全、健壮且文档良好的邮件检索和转发工具，旨在用于按需的 TCP/IP 链接（如 SLIP 或 PPP 连接）。它从服务器检索邮件并转发到你本地（客户端）机器的投递系统，以便让 elm、mne、pine (xemacs/users) 等邮件用户代理读取，或者 `fetchconf` 包包含一个为终端用户提供的交互式 GUI 配置器。如果编译了该包，则可以使用 Kerberos IV & V、API 和 GSSAPI。SSL 由 `fetchmail-ssl` 包提供。源自 Debian 3.0r4 APT
