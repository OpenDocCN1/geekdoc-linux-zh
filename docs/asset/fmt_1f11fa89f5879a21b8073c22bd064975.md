# toolame

`MPEG-1` 第2 层音频编码器。`toolame` 是一种非常快速（550mhz 时钟下实时）的第2 层音频编码器，其命令行语法与 `lame` 第3 层音频编码器几乎相同。由于第 3 层编码器的专利问题、`mpeg` 音频播放器播放第2 层文件的能力以及命令行语法的相似性，在某些情况下 `toolame` 是 `lame` 或其他第 3 层编码器的很好的替代品。来自 Debian 3.0 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
