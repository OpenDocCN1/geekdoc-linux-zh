# 豌 1621

豌是最古老的栽培作物之一。它原产于西亚，从地中海到喜马拉雅山脉。它似乎在史前时代就被带到了欧洲。豌在公元400年左右从波斯引入；很早就进入了欧洲。园豌（`P. sativum`）在干燥时成熟；野豌（`P. arvens`）具有柔软的皮壳。所有类型都有叶子。豌生长在纤细的藤蔓上，种子包裹在3–7厘米（15厘米）长的荚中。长籽的颜色从奶油色到绿色、黄色或棕色不等。短籽品种被采用于冷冻或罐装，而长籽品种被干燥并以各种方式准备，例如制作压豌。
