# 11.3 子群与拉格朗日定理

群论是一个庞大的学科，拥有海量的文献。我们将局限于那些与我们感兴趣的组合问题相关的方面。以下定义非常重要。

### 定义 11.4
假设 `G` 是一个群。`G` 的一个子集 `H` 被称为 `G` 的一个**子群**，如果 `H` 本身在使 `G` 成为群的同一运算下也形成一个群。

**注意：** 在这里，省略提及群运算非常方便。如果我们真的非常严谨，我们就必须区分 `G` 的群运算（记为 `*`，严格来说是一个映射 `* : G x G -> G`）和 `H` 上的运算（即 `*` 在集合 `H` 上的限制）。

由于 `H` 是 `G` 的子集，且我们使用的是与群 `G` 相同的运算，因此自动满足结合律。因此，为了使 `H` 成为 `G` 的子群，`H` 必须是 `G` 的一个满足以下标记为“SG”（代表“subgroup”，即子群）性质的子集。*

### 子群性质
- SG1. `H` 在运算 `•` 下自身封闭；也就是说，对于所有 `x`, `y ∈ H`，都有 `x • y ∈ H`。
- SG2. `H` 包含 `G` 的单位元 `e_G`。
- SG3. `H` 包含其所有元素的逆元；也就是说，对于每个 `x ∈ H`，也有 `x^{-1} ∈ H`。

我们现在给出一些子群的例子。

### 子群的例子
1. 我们已知 `Z`、`Q`、`R` 和 `C` 都是群的例子，每种情况下运算均为加法。由于 `Z ⊆ Q ⊆ R ⊆ C`，因此 `Z` 是 `Q` 的子群，`Q` 是 `R` 的子群，`R` 是 `C` 的子群。
2. 每个具有多于一个元素的群 `G` 都有两个*平凡*子群。仅包含 `G` 的单位元的集合 `{e_G}` 很容易看出满足子群条件。在另一个极端，整个群 `G` 本身也被视为它自身的子群。
3. 来自 `S4` 且对应于正方形对称性的八个置换构成了 `S4` 的一个子群。
4. 我们考虑集合 `{1, 2, 3}` 的所有六个置换组成的群 `S3`。而不是将这些置换写成循环形式，我们为它们引入以下符号。设 `p = (1 2 3)`，`q = (1 2)`，`r = (2 3)`，`s = (1 3)`，`t = (2 3)`（注：原文中 `r` 和 `t` 的符号定义重复，此处依原文保留），`e` 是单位元，如常。该群的凯莱表见表 11.3。

可以看出，表格的左上角单独拿出来也是某个群的凯莱表。换句话说，子集 `{e, p, q}` 构成了 `S3` 的一个子群。在这种情况下，发现这一点相当容易。一般来说，仅通过检查凯莱表来寻找子群是相当困难的。你能从这个凯莱表中找到更多的子群吗？事实上，除了两个平凡子群和子群 `{e, p, q}` 之外，只有另外三个子群，每个仅包含单位元和另一个元素。

当我们寻找子群时，一些理论知识会给予我们帮助。这涉及到子群中元素的数量与群中元素的数量之间的比较。群论家对于群或子群中元素的数量有专门的术语。

### 定义 11.5
群或子群的*阶*（order）是其包含的元素数量。

例如，`S3` 的阶是 6，正方形对称群的阶是 8。群论家通常使用符号 `o(G)` 表示群的阶，但我们已经引入了符号 `#(G)` 表示任何集合 `G` 中元素的数量，因此我们将沿用此符号。

接下来描述的核心思想是：给定一个群 `G` 和一个子群 `H`，我们可以使用 `H` 将 `G` 划分为若干个集合，在这种语境下称为*陪集*（cosets），它们拥有的元素数量都与 `H` 相同。它们的定义如下。为了使一般概念更具体，我们使用群 `S3` 作为例子。

### 定义 11.6
设 `G` 是一个群，`H` 是 `G` 的一个子群。对于每个 `g ∈ G`，*陪集* `gH` 被定义为集合 `{gh : h ∈ H}`。

我们使用符号 `gH` 表示陪集，因为它通过将 `G` 中的固定元素 `g` 与 `H` 中的所有元素依次结合而得到，因此符号 `gH` 具有暗示性，是良好的助记手段。我们现在具体考察群 `S3` 的例子，以使这些概念更加具体。

### 问题 11.1
求群 `S3` 的子群 `{e, r}` 的陪集。（回忆 `S3` 的凯莱表见表 11.3。）

## 解答
我们按如下方式计算陪集：

`eH = {ee, er} = {e, r}`， `qH = {qe, qr} = {q, s}`， `sH = {se, sr} = {s, q}`，

`pH = {pe, pr} = {p, t}`， `rH = {re, rr} = {r, e}`， `tH = {te, tr} = {t, p}`。

我们可以看到，不同元素的陪集可能是同一个集合。例如，陪集 `pH` 和 `tH` 都构成集合 `{p, t}`。注意，由于我们处理的是集合，我们在计算中列出元素的顺序无关紧要。在其他情况下，陪集完全不同。例如，没有元素同时属于 `pH` 和 `rH`。因此，不同的陪集将 `G` 划分为三个不相交的集合，即 `G = {e, r} ∪ {p, t} ∪ {q, s}`。此外，每个陪集包含的元素数量与子群 `H` 相同。因此 ` #(G) = 3 × #(H)`，由此推导出 ` #(H)` 是 ` #(G)` 的因子。

当然，我们不需要群论就能得出 2 是 6 的因子这一结论。然而，这个例子的要点在于，我们可以证明我们关于 `H` 的陪集所观察到的事实，对于所有群的所有子群都是成立的。我们现在来证明这一点。

首先证明一个引理会更方便，该引理给出了两个陪集 `g1H` 和 `g2H` 何时相同的有用判据。

## 引理 11.4
若 `G` 是一个群，`H` 是 `G` 的子群，且 `g1, g2 ∈ G`，则

`g1H = g2H ⇔ g2^{-1} g1 ∈ H.`

### 证明
