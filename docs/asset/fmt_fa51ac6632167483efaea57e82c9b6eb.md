
由于 Squid 是按顺序匹配这些规则的，因此将对 Web 拥有完全且未经过滤的访问。如果客户端 IP 地址不在 `directors` 列表中，则两个 `deny` 所在的行会被处理，导致用户无法下载 `.zip` 文件或在 Hotmail 上阅读在线邮件。在拦截这些类型的请求后，第四行的 `allow` 允许内部用户访问 Web，前提是他们仅在午休时间访问。最后一行（强烈建议添加）阻止所有其他用户使用代理。
