## `lpr` — 提交打印请求

### 概要

```
/usr/ucb/lpr [-P destination][-n number] [-C class][-J job] [-T][-i number]][-1|-2|-3|-4 font] [-w number] [-m][-h][-s] [file...]
```

## 描述

`lpr` 命令向目标提交打印请求。文件信息统称为打印请求。如果指定了文件，`lpr` 假设标准输入。

打印客户端按特定顺序要求目标信息。详情请参阅 `printers(4)` 和 `printers.conf(4)`。

## `lpr` 731

超过 52 个文件的打印请求将被截断。`lpr` 显示警告消息。

## 选项

`-P destination` 在特定打印机或打印机类上打印（参阅 `lpadmin(1M)`）。使用原子、POSIX 风格（`server:destination`）或联邦命名系统（FNS）指定目标（参阅 `.../printer/...names.conf(4)` 获取有关原子名称和 FNS 名称命名规范的信息，参阅 `standards(5)` 获取有关 POSIX 的信息）。

`-n number` 打印指定数量的副本。将数字作为正整数指定。默认值为 1。

`-C class` 在标题页上打印分类。如果分类包含空格，则用双引号括起来。如果未指定分类，则将系统名称（由 `hostname` 返回）作为分类。参阅 `hostname(1)`。

`-J job` 在标题页上打印作业名。如果作业包含空格，则用双引号括起来。如果未指定作业，则将文件（多个文件时为命令行上的第一个文件）作为标题页上的作业名。

`-T title` 在标题页上打印标题。如果标题包含空格，则用双引号括起来。如果未指定标题，则打印文件名。

`-i [number]` 按指定的特定空格数缩进输出。使用数字指示要缩进的空格数。将数字作为正整数指定。默认为八空格。

`-1|-2|-3|-4 font` 将字体挂载到字体位置 1、2、3 或 4。将字体作为有效的字体名称指定。

`-w number` 按宽度打印文件。数字指示列数。

`-m` 在文件打印后发送邮件（参阅 `mail(1)`）。默认情况下，打印请求正常完成后不发送邮件。

`-h` 抑制输出标题页的打印。

`-s` 使用完整路径（而非符号链接）复制文件。在打印完成之前，不应修改或删除文件。`-s` 仅防止本地文件在本地系统中创建副本。`-s` 仅对指定的文件有效。如果 `lpr` 命令位于管道末端，则文件被复制到后台队列中。

## `Iprm` — 从打印队列中移除打印请求

### 概要

```
/usr/ucb/lprrm [-P destination][-]request-ID...][user...]
```

## 描述

使用 `lprrm` 命令从打印队列中移除打印请求 (`request-ID`)。

## 734 `lprm`

不带参数时，`lprm` 删除当前的打印请求。`lprm` 会报告其删除的与打印请求相关的文件名。如果没有相应的打印请求可以删除，`lprm` 将保持静默。

您只能删除与您自己的所有名相关的打印请求。如果超级用户执行 `lprm` 并指定了用户操作数，`lprm` 将移除属于指定用户的所有打印请求。

客户端命令按特定顺序查找目标信息。详情请参见 `printers.conf(4)`。

> 注意 — 您只能删除与您的所有者名相关的打印请求。默认情况下，您只能删除提交打印请求的主机上的打印请求。如果超级用户在打印服务器的 `/etc/printers.conf` 中设置了 `user-equivalence=true`，您可以在任何主机上删除与您的用户名相关的打印请求。超级用户可以删除提交打印请求的主机上的打印请求。超级用户还会移除打印服务器上的打印请求。

## 选项

`-P destination` 指定要移除打印请求的打印机名称或打印机类（参见 `lpadmin(1)`）。使用原子性、POSIX 风格(`server:destination`) 或联邦命名服务(FNS)(`.../service/printer/...`) 名称指定目标。关于原子和 FNS 名称命名规范的信息请参见 `printers.conf(4)`，关于 POSIX 的信息请参见 `standards(5)`。

`-` 移除该用户拥有的所有打印请求。如果超级用户指定此选项，将移除打印队列中的所有请求。作业所有权取决于执行 `lpr` 时的系统登录名和主机名。

### 操作数

`user` 移除与特定用户相关的打印请求。指定 `user` 为有效的用户名。只有超级用户可以使用此选项。`request-ID` 移除特定的打印请求。指定 `request-ID` 为由 `lpq` 报告的与打印请求相关的作业号。参见 `lpq(1B)`。

## 示例

以下示例从目标 `killtree` 移除 `request-ID` 385。

`castle@ lprm -P killtree 385`
