
# 金属化合物的光化学研究

金属化合物的光化学研究随着分子电子结构和分子化学键的现代理论的发展而增长。光化学研究通常旨在探索和检验这些理论。相关研究的范围涵盖了化学的大多数子学科，包括或与光物理、激光材料开发、催化、光合成、氧化还原化学、酸碱化学、有机金属化学、金属茂化学、固态化学和表面化学等主题有关。参见 [化学键](CHEMICAL BONDING)；[化学动力学](CHEMICAL DYNAMICS)；[配位化学](COORDINATION CHEMISTRY)；[激光光化学](LASER PHOTOCHEMISTRY)；[光化学](PHOTO-CHEMISTRY)。

## 无机聚合物

由共价键连接的巨大分子，但在主分子骨架中缺乏或近乎缺乏碳氢单元；那些包含碳侧链、碳纤维、石墨等的材料被视为无机聚合物。

许多无机聚合物的一些特殊特性是与有机聚合物相比，具有较高的杨氏模量和较低的断裂应变。相对少量的无机聚合物在真正意义上可溶解，或者相反，如果它们溶胀，很少能恢复原状。结晶性和高玻璃化转变温度在无机聚合物中也比在有机聚合物中更常见。在高交联的无机聚合物中，应力松弛通常涉及键交换。参见 [杨氏模量](YOUNG’S MODULUS)。

无机聚合物可以以多种方式分类。有些基于骨架的组成，如硅氧烷（Si—O）、磷杂环（P—N）和聚合物硫（S—S）。其他基于其连接性，即将重复单元连接成网络的网状键的数量。因此，基于 `R₂SiO` 的硅氧烷、基于 `NPH₂` 的磷杂环和聚合物硫的连接性均为二，而基于 `B₂O₃` 的氧化硼的连接性为三，基于 `SiO₂` 的非晶二氧化硅的连接性为四（见图）。

著名的无机聚合物包括硅氧烷、硫族化合物玻璃、石墨、硼聚合物和硅酸盐聚合物。参见 [石墨](GRAPHITE)；[硅氧烷树脂](SILICONE RESINS)。

## 肌醇

六羟基环己烷的通用名称，被归类为碳水化合物。肌醇具有特殊的化学稳定性，且易于结晶。在自然界中常见的形式中，最普遍且生物重要性最高的是 `myo-`肌醇（间肌醇），一种水溶性结晶化合物。许多生物功能需要 `myo-`肌醇，因此它被确定为一种必需代谢物。虽然最初被归类为维生素，但 `myo-`肌醇现在已知是磷脂的细胞前体，这些磷脂作为代谢调节剂的来源以及某些蛋白质的膜锚定物。某些微生物需要外源 `myo-`肌醇才能生长。参见 [碳水化合物](CARBOHYDRATES)；[脂质](LIPID)。

## 生物防治（昆虫控制）

利用寄生生物、捕食者和病原生物来减少有害害虫昆虫的种群，从而减少它们造成的损害。病毒和细菌是最常用的病原生物，真菌、原生动物和线虫也可能是重要的生物防治剂。参见 [寄生虫学](PARASITOLOGY)。

生物防治基于三个生态假设。首先，天敌是导致害虫种群调节（或控制）的主要因素之一。其次，寄生生物、捕食者和病原生物产生的影响是密度依赖的。密度依赖性意味着天敌的杀伤力随猎物或寄主密度增加而增加。相反，由密度依赖天敌引起的死亡率随寄主密度降低而降低。在主导形式的生物防治（即经典生物防治）中，发现了第三个假设：当昆虫物种脱离其天敌逃逸到新区域时，它达到爆发水平并成为害虫。生物防治实践者认为，通过从害虫的原产地引入其天敌，可以重新建立调节机制。

在经典生物防治中，所有努力通常都致力于建立那些被留在原产地的天敌。经典生物防治是迄今为止使用最频繁的形式，前提是将抗性植物品种的使用排除在生物防治之外。

保护利用涉及操纵环境，以有利于天敌的生存、繁殖或其生物学其他影响其作为生物防治剂功能的方面。

生物防治研究和应用的各个方面可能涉及新的或改进的方法。通过选择、杂交或基因工程技术改进生物防治剂可能发挥重要作用。

具有不同连接性的聚合物：(a) 硅氧烷，二；(b) 磷杂环，二；(c) 硫，二；(d) 氧化硼，三；(e) 非晶二氧化硅，四。（引自 N. H. Ray, *Inorganic Polymers*, Academic Press, 1978.）

控制害虫的主要策略可能涉及使用基因工程技术将增强天敌性状的基因引入天敌，或将天敌中具有致死作用的性状（如昆虫病原体）引入植物。参见[植物育种](https://example.com/breeding_plant)；[基因工程](https://example.com/genetic_engineering)。[PB.]

# 昆虫病理学

一门涵盖病理学一般原理（最广义的疾病）应用于昆虫领域的生物学科。它指人类对昆虫疾病的原因、症状表现、病理学、组织病理学、发病机制及病因病理学的观察和行动；它关注昆虫身上可能发生的一切错误或异常现象。患病的昆虫可能正遭受由微生物引起的传染病或非传染性疾病的折磨，如代谢紊乱、遗传异常、致死性畸形、营养缺乏、物理或化学损伤，或由寄生虫或捕食者造成的损伤。

昆虫病理学借鉴并贡献于微生物学的通用领域，并提供了对昆虫与其非致病微生物之间存在的某些生物学关系的理解。昆虫病理学在农业、医学及一般生物学领域都有应用。微生物控制，即在生物防治中使用微生物，是应用昆虫病理学的一个领域。引入微生物以控制害虫，保护人类、其他动物及农作物。然而，抑制有益昆虫（如家蚕、蜜蜂、瓢虫）的疾病也具有重大的实际意义。参见[昆虫控制](https://example.com/insect_control)；[生物防治](https://example.com/biological_control)。

昆虫病理学的一个重要方面涉及疾病流行病学，即研究昆虫群体中的疾病，而非个体动物。任何影响昆虫种群的兽疫都涉及三个主要的自然实体：病原体、昆虫宿主和环境。这些因素各自具有某些属性，当它们与其他因素的属性适当关联时，在决定兽疫的发生、上升和衰退方面发挥相应作用。关于兽疫性质的知识对于一般的昆虫生态学及昆虫-微生物生态系统的理解都极其重要。致病微生物对宿主种群密度的依赖性、宿主昆虫对疾病的易感性、天气和其他环境条件对兽疫的影响、昆虫病原体的传播方式、微生物保持存活的成功率以及其他因素，都是昆虫疾病流行病学的重要方面。在利用微生物控制有害昆虫时，人类可以通过控制有效微生物的数量、分布方法和引入时间，引发并加速兽疫的快速发展。

昆虫病理学的大多数活动都集中在传染病上。导致昆虫疾病的病原体属于与其他生物引起类似疾病的主要病原体相同的类别：细菌、真菌、病毒、立克次氏体、原生动物和线虫。然而，一般而言，昆虫通常不感染那些引起人类、其他动物和植物疾病的特定微生物。此外，大多数导致昆虫致死性疾病的微生物对植物和高等动物是无害的。昆虫通常可以通过体液免疫和细胞免疫类型抵抗感染；获得性体液免疫表现在血淋巴中。然而，高等动物的抗体免疫特性似乎在昆虫中并不存在。

**苏云金芽孢杆菌**是研究最深入的昆虫细菌病原体之一，因为它被证明是控制多种害虫的有效微生物制剂，如苜蓿夜蛾、菜粉蝶幼虫以及某些蚊子、黑蝇和甲虫的幼虫形式。已知该芽孢杆菌的许多近缘物种会导致有益昆虫（如家蚕）的疾病。已知*苏云金芽孢杆菌*有几种不同的菌株或变种。某些类型仅影响鳞翅目昆虫，其他类型仅影响双翅目或鞘翅目昆虫。这些细菌的特征是在孢子形成阶段形成蛋白质晶体。构成晶体的蛋白质对某些昆虫具有高度毒性，但对其他生命形式显然无害。*苏云金芽孢杆菌*及其相关物种还产生一种耐热、水溶性物质，不同于晶体和亮氨酸晶体，当注入时对某些昆虫有毒，当双翅目幼虫在饲养介质中接触它时也有毒。含有*苏云金芽孢杆菌*或其变种孢子和晶体的制剂可喷洒或粉尘施用于农作物或水生栖息地，以消灭鳞翅目、双翅目或鞘翅目害虫。含有该芽孢杆菌的市售产品可供使用。此类防治的主要优势之一是该种及其他嗜虫微生物对植物和高等动物无毒且非致病。参见[昆虫生理学](https://example.com/insect_physiology)；[昆虫纲](https://example.com/insecta)；[杀虫剂](https://example.com/insecticide)。[J.D.Br.]

# 昆虫纲

节肢动物门中的一个纲，有时也称为六足动物总纲。实际上，六足动物是一个总纲，包括昆虫纲和相关的旁昆虫纲（包含跳虫和原尾目昆虫）。昆虫纲是生物多样性最丰富的生物类群，包含约90万种已描述物种，但实际昆虫物种可能多达500万甚至2000万种。与其他节肢动物一样，它们具有外部的几丁质覆盖层。已发现最早可追溯至早泥盆纪的昆虫化石。参见[旁昆虫纲](https://example.com/parainsecta)。

- **六足动物总纲 (Hexapoda)**

  - **旁昆虫纲 (Para-insecta)**

    - 目：原尾目；原尾类昆虫

    - 目：缨尾目；跳虫

  - **昆虫纲 (Insecta)**

    - **下纲：单爪下纲 (Mononychia)**

      - 目：双尾目；双尾类昆虫

      - 目：原口目；无肛类昆虫

    - **下纲：双爪下纲 (Dicondyla)**

      - **亚目：无翅亚目 (Apterygota)**

        - 目：啮虫目；衣鱼、衣鱼 *(注：OCR错误， likely Zygentoma)*
