
```
Fout.write("so is KDE", 10);

Fout.put('!');

Fout.close();
```

将写入：

```
Linux is open source so is KDE!
```

到`myfile.txt`中。

`ifstream`对象可以使用相同的两种技术连接到文件进行输入：

```cpp
ifstream Fin("myfile.txt");
```

或者：

```cpp
ifstream Fin;

Fin.open("myfile.txt");
```

一旦`ifstream`对象连接到文件用于输入，我们就可以使用`istream`类中定义的任何方法从流中读取信息。例如：

```cpp
char Input[80];

Fin.getline(Input, 79, '\n');

Fin.close();
```
