
### 14.

# RHCE 示例考试 I 讨论

### 2.
这是一个两个步骤的过程：在 `gamma` 上作为服务器运行，在 `whitehat` 上作为客户端运行。它们可以在各自的 `/etc/syslog.conf` 文件中配置。确保在 `gamma` 上开启 514 端口，使用配置的协议（TCP 或 UDP）。`gamma` 上的 `syslog.conf` 更改是简单的。选择 TCP 或 UDP，并激活与“syslog”相关的指令。`whitehat` 上的 `syslog.conf` 更改在文件底部稍复杂。只需记住为主机名或 IP 地址替换主机指令。如果你使用 UDP，请让其生效。
