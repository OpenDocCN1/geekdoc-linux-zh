## 茶壶原语的历史

茶壶是计算机图形的经典。自从 1975 年 Martin Newell 在犹他大学建模了这种茶壶形状以测试着色算法以来，人们一直使用具有交交和弯曲表面的茶壶作为渲染的测试和基准对象。

## 使用修改器（Modifiers）建模标准原语

你已经看到原语具有基本参数，这些参数可以在创建原语后的任何时候修改。此外，称为修改器（modifiers）的工具可以进一步作用于原语以改变其形状。你可以将修改器想象为不可见的附件，为原语添加功能，就像软件插件为你的 浏览器或其他程序添加功能一样。

现在让我们添加一个修改器将立方体的形状变为弯曲的立方体：

1. 确保立方体被选中。点击命令面板中的 `Modify` 选项卡。
2. 点击命令面板顶部的 `Modifier List`（修改器列表）下拉箭头。这会展开图 2.11 所示的可滚动修改器列表。
3. 点击 `Object-Space Modifiers`（对象空间修改器）列表下的 `Bend`（弯曲）修改器。注意 `Bend` 现在出现在 `Modifier List` 下拉列表下方的修改栈中。你还会看到叠加在对象上的橙色轮廓。这个橙色框是另一个工具，类似于第 1 章介绍的 `Move`（移动）、`Rotate`（旋转）和 `Scale`（缩放）工具，它显示了修改器的总体效果。还要注意 `Parameters` 展开显示的是 `Bend` 修改器的选项，而不是立方体的参数选项。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_96_1.png)

4. 在 `Parameters` 展开的 `Bend` 组中，点击并拖动 `Angle`（角度）调节器，观察立方体发生了什么：它向右倾斜，但没有弯曲，如图 2.12 所示。你可以看到橙色框显示修改修改器的结果，只有当对象足够灵活以匹配时才能实现。
5. 调整 `Angle` 调节器使其达到 60。或者，你可以突出 `Angle` 值然后输入 60。

`Bend` 修改器有一套自己的参数可以改变对象的形状。对于你可能在对象上使用的任何修改器都是如此。但添加修改器并不意味着不能返回对象的原始参数进行更改。

注意只列出 `Box` 的列表。这就是修改栈。你将在接下来的练习中使用它。还要注意 `Parameters` 展开列表中的选项。在这里你会看到标准的 `Length`、`Width` 和 `Height` 选项，以及 `Length Segs`（长度分段）、`Width Segs`（宽度分段）和 `Height Segs`（高度分段）选项。

## 已应用的修改器参数

你刚刚对立方体应用了 `Bend` 修改器，但结果可能完全符合你的预期。立方体现在看起来像一个梯形。为了让立方体看起来是弯曲的，你需要调整你之前在立方体参数中看到的 `Segs` 参数。目前，对象的修改栈包含 `Bend`（你刚刚添加的修改器）和 `Box`（当前对象类型）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_98_1.png)

1. 点击修改栈中的（`Modifier List` 下拉列表下方）`Box`。注意原始立方体参数出现在 `Parameters` 展开列表中。
2. 重复点击 `Height Segs` 调节器的向上箭头，观察立方体发生了什么。你在这里看到出现了水平线，水平分割了立方体。`Height Segs` 输入框中的值显示分段数。还要注意立方体现在看起来是弯曲的，如图 2.13 所示。
3. 将 `Height Segs` 值设置为 8。

## 使用修饰器对原始几何建模

在练习中，你看到了如何增加盒子的段数，这使得 `Bend`（弯曲）修饰器让盒子呈现弯曲的外观。你还看到了修改器栈（modifier stack）可以访问盒子的原始参数。修改器栈对于你在 VIZ 中编辑对象的能力起着关键作用，你在学习本书中的示例将会看到这一点。

现在让我们尝试对 `Bend` 修饰器的参数进行另一种调整：

1. 在修改器栈中点击 `Bend`。
2. 点击 `Parameters`（参数）面板中的 `Direction`（方向）数值并向上拖动。注意当你改变弯曲方向（`Bend Direction`）时，盒子的顶部会旋转，而底部保持固定。
3. 将 `Direction` 值调整为 180。这会导致 `Bend` 修饰器指向与其原始方向成 180 度角。你可以在图 2.14 中看到结果。

### 图 2.14

更改 `Direction` 参数会改变弯曲方向。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_99_0.png)

再次，你从一组参数切换到了另一组参数。这次，你从盒子的基础参数切换到了 `Bend` 修饰器的参数。当你调整第 2 步中的 `Direction` 数值时，你看到盒子在改变弯曲方向时似乎在绕轴旋转。

你可能注意到了修改器栈中 `Bend` 项目左侧的 `(+)` 号。如果你点击 `(+)` 号，列表会展开并显示该修饰器可用的额外参数，也称为子对象（subobjects）。对于 `Bend` 修饰器，`Gizmo` 和 `Center`（中心）是两个额外的选项。

| | |
|---|---|
| | `Gizmo` |
| | `Center` |

如前所述，`Gizmo` 选项指的是叠加在盒子上的形状。它让你看到修饰器是如何应用于对象的。`Center` 选项指的是修饰器对象的原点，这通常是你在创建对象时选取的第一个点。`Gizmo` 和 `Center` 选项都可以进行编辑，你将在稍后的章节中学习到这些。

现在让我们尝试另一个修饰器。`Taper`（锥化）修饰器的作用正如你猜想的那样：它让对象变锥形。

1. 首先将视图切换为可以显示更多盒子的视图。旋转（`Arc Rotate`）视图以更好地观察盒子。
2. 点击视口导航控制中的 `Zoom Extents`（缩放范围）工具。
