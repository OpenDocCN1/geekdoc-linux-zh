结缔组织是人体四种组织之一，与其他三种组织的区别在于其结构成分（纤维和细胞间质）非常丰富。它无法与血液分离，血液细胞可以产生结缔组织，而质膜不断与组织相互作用并增强其的功能。骨骼是结缔组织的例子。

结缔组织的功能多样。它们主要用于支持身体，或作为功能单元以及管状系统。对于机械或物理损伤的内外机制，结缔组织对于保护身体至关重要。身体所有细胞的营养及其废物都通过结缔组织进行交换。结缔组织作为营养和生长的介质非常重要。在维持盐水方面，它们构成了身体稳态机制的主要贡献者。它们作为水、盐和脂肪的储备库。在许多情况下，结缔组织决定了皮肤的色素。

三价碳展示了甲基基 (H) 的 $\sigma$-键如何对邻近的空轨道或甲基基 (CH3) 产生超共轭稳定作用。其 $\sigma$-键的超共轭轨道效应；在两种构型或旋转中，环上的甲基基都有一个与邻近碳 p 轨道重叠的轨道。由于氢是供体，甲基基作为供体来稳定空 p 轨道，作为远端供体来稳定右侧碳上的匹配轨道。这就是轨道效应。如果它被替换为另一个原子 X，X 的超共轭效应将小于 A，因为此时密度在 X 上，并且在 B 作为供体的构型或正常平面处达到最小。如果 X 是供体键，它将稳定一个空 p 轨道（如阳离子）。如果 X 是电负性更强的元素（如氟），C-X 键是受体键并将稳定一个空轨道（如阴离子）。因此，当单个 p 轨道被多键取代时，供体和受体效应同样重要。

结缔组织由细胞和细胞间质（基质）组成。细胞包括许多种类，但最常见的是成纤维细胞，其次是巨噬细胞（组织细胞）、肥细胞、浆细胞、黑色素细胞和脂肪细胞。结缔组织的细胞在防御和伤口修复中的作用具有重要价值。

许多科学现象取决于结缔组织的特性：这些包括视觉（由具有扩展共轭特征的分子触发的光受体）、听觉（如聚乙乙烯等共轭系统的受体）、颜色（光的波长）以及医学（许多抗生素和抗药物作用于通过共轭加成引发合酶合成产生的系统）。
