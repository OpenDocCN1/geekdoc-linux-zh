我们将使用 `scp` 命令将此 Porteus 中创建的密钥拷贝到 Kali 系统。

```
scp /root/.ssh/id_rsa.pub root@192.168.43.2:/root/.ssh/
```

由于 Kali 系统的 IP 号为 `192.168.43.2`，我们在命令行中输入了这个本地 IP 地址。此外，我们还命令将密钥保存到 `/root/.ssh/` 下。
