### traceroute
`traceroute` 内置于大多数系统中，跟踪互联网两点之间的路径。互联网上的每个数据包都有一个生存时间（TTL）字段。每个路由器在转发数据包时会将该字段减 1。这种设计是为了解决“循环”问题；路由器的配置不当会导致无限循环。TTL 字段保证了这些数据包最终会消失。当数据包以这种方式消失时，最后一个发送包的路由器会向发送者返回消息。因此（这是一个天才的想法），你可以创建较小的 TTL 来强制杀死数据包。你首先将 TTL 设置为 1，导致路由器丢弃它。你将 TTL 设置为 2，导致第二个路由器丢弃它。对点之间的路径重复此操作。来自 Hacking-Linux `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## Nano tracer
这是由 Ehud Gavron 在 aces 维护的 `traceroute` 程序。它基于 Van Jacobson/BSD `traceroute`，并具有额外的功能，如 AS 查找、TOS 支持、微秒级时间戳、MTU 发现、并行探测等，源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `trafstats` 收集并存储流量信息到 SQL 数据库中。该程序使用数据包捕获库 `libcap` 收集网络流量，然后存储在 PostgreSQL 数据库中。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Dictionary/index.html`

- `tramp` 远程办公室访问。TRAMP 代表透明远程（文件），多协议；该软件包提供了远程文件编辑，类似于 `ange-ftp` 和 `EFS`。不同之处（括号必须保留）：`[host]/dir` 或 `[method]/[host]/dir`。另一个区别是 `ange-ftp` 使用 FTP 在本地和远程主机之间传输文件，而 TRAMP 使用 `ssh` 和 `rcp` 或其他类似工作的程序，如 `shb/scp`。一个 emacs 允许使用 `telnet`、`rsh`、`ssh` 等更多工具在远程主机上编辑文件。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `trans-de-en` 德英翻译词典。一个包含约 124,000 条条目的德英语字典。该字典是为“dict”字典查询程序设计的，也可以被其他客户端使用。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `transcale` 微波和 RF 传输线控制器 Transcale 是一种分析和合成工具，用于计算各种类型 RF 和微波传输线的电气和物理属性。Transcale 使用 GMP 工具包 (GTK) 构建其界面。通过对话框，你可以输入各种参数的值，并计算其电气属性（分析），或使用给定的电气要求来合成所需传输线的物理参数。可用的传输线（此列表可能随后续版本进行扩展）：微带、矩形波导。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `transcribe` 使用集成编辑器处理语音数据。Trans 是一个 Tcl/tk 工具，能够对录制的语音进行转录。对于每个涉及音频文件检查和转录的任务（如录制的采访、歌词、广播节目等）都是不可或缺的。如果你活跃在语音研究领域也很有用。`snack` 库（包含在 `transcribber-1.2` 中）现在是一个独立的包。该包包含了 `html_library–0.3`。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `transfig` 用于处理 xfig 的工具。`transfig` 还包含用于将 xfig 转换为 LaTeX 文件的工具。注意：`transfig` 需要 `netbm-nonfree` 的支持。源自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `transformix` 一个 XSLT 处理器 Transformix 是一个独立的 XSLT 处理器。旨在完全符合 XSLT 1.0 标准，尽管尚未实现该目标。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
