
# 丽口菌目

丽口菌目（Lecanorales）是壳状亚门（Ascolichenes）的一个目，也称为碟状菌目（Discolichenes）。丽口菌目是地衣中最大且最典型的目，并与真菌的念菌目（Helotiales）密切相关。其子囊盘开放且呈盘状，具有典型的产孢组织（hymenium）和假子囊层（hypothecium）。共有四种生长形态——壳状、片状、叶状和枝状——它们显示出比地衣其他目都更大的变异性。

丽口菌目分为25个科，约160个属，以及8000至10,000个种。科的划分基于地衣体的生长形态、子囊盘的结构、共生的藻类物种以及孢子特征。种的区分依据如假皮层（isidia）、粉芽（soredia）、根状假根（rhizines）和孔隙，以及化学成分。较大的科包括：`Cladoniaceae`（Cladoniaceae科）、`Lecanoraceae`（Lecanoraceae科）、`Lecideaceae`（Lecideaceae科）、`Parmeliaceae`（Parmeliaceae科）、`Umbilicariaceae`（Umbilicariaceae科）和`Usneaceae`（Usneaceae科）。 [M.E.H.]

## Le Chatelier’s principle

勒夏特列原理描述了处于平衡状态的系统在决定平衡的某个变量发生变化时的响应。

- 对于任何化学反应平衡或相平衡，在恒压下升高温度会使平衡向系统吸热的方向移动。参见化学平衡；相平衡。
- 对于任何反应平衡或相平衡，在恒温下增加压力会使平衡向系统体积减小的方向移动。
- 对于稀溶液中的反应平衡，加入少量参与反应的溶质物种会使平衡向消耗部分所加溶质的方向移动。
- 对于理想气体反应平衡，在恒温恒容下加入参与反应的物种会使平衡向消耗部分所加物种的方向移动。对于理想气体反应平衡，在恒温恒压下加入参与反应的物种可能会使平衡向生成更多所加物种的方向移动，或者向消耗部分所加物种的方向移动；平衡移动的方向取决于反应、所加的物种以及平衡混合物的初始组成。 [INL.]

## Lectins

凝集素（Lectins）是一类非免疫来源的蛋白质，它们可逆且非共价地结合碳水化合物，而不诱导碳水化合物发生任何变化。凝集素结合多种细胞和细胞表面糖蛋白（碳水化合物结合蛋白）或糖脂（碳水化合物结合脂质）。每个凝集素分子具有两个或更多结合位点，使得许多细胞类型能够发生凝集，凝集反应已被广泛用于检测不同生物提取物中凝集素的存在。虽然凝集素在自然界中无处不在，但其生物学作用尚不清楚。参见碳水化合物。

已在1000多种植物分类群中发现凝集红细胞活性。然而，关于特征明确的凝集素分布的知识仅覆盖了4%至5%的被子植物科。此外，大多数特征最明确的凝集素来自单一科，即豆科（Leguminosae）。

动物凝集素也仅在少数物种中被表征，但它们几乎存在于所有无脊椎动物和有脊椎动物门中。无脊椎动物凝集素存在于体液或分泌物中，如鱼血清、蛇毒、精液、体腔液和血淋巴。脊椎动物凝集素作为可溶性蛋白或整合膜蛋白存在于胚胎和成体的体液、器官和组织中。

微生物凝集素主要被分离自细菌，但它们也存在于病毒、黏菌、原生动物、绿藻和真菌中。

从已知的少数实例来看，显然凝集素参与识别现象，而其结合特定碳水化合物结构的能力是其生物学功能的关键。这些识别功能包括它们参与与同一物种的细胞或细胞外材料的相互作用（自我识别）以及与外来颗粒或细胞的相互作用（非自我识别）。由凝集素介导的自我识别的最著名例子之一是肝凝集素，它们参与识别必须从循环系统中清除的糖蛋白。特异性凝集素识别并将靶蛋白内化至溶酶体中，在那里它们被破坏。参见溶酶体。

凝集素介导的非自我识别的例子可见于细菌表面凝集素在感染中的作用。许多细菌菌株产生表面凝集素，识别宿主细胞表面上的特定糖类，从而启动感染过程。另一个例子是固氮细菌与植物根系之间的共生相互作用。豆科植物根部存在的凝集素定位在根毛表面和根分泌物中，在那里它们识别合适的根瘤菌菌株，并部分解释了结节形成的特异性。

凝集素是非常有用的试剂，用于研究复杂碳水化合物和细胞表面，用于分离和鉴定特定细胞，以及刺激细胞增殖。共价连接到不溶性基质上的凝集素用于分离含有不同碳水化合物的糖蛋白或糖鞘脂。标记的凝集素也用于组织化学和细胞化学研究，以定位携带特定糖类的糖缀合物。这项技术特别有趣，因为凝集素结合模式的变化发生在胚胎分化、恶性转化、衰老以及某些病理状态期间。参见蛋白质。 [R.L.e.]

## Lecythidales

玉蕊目（Lecythidales）是一个被子植物目，属于双子叶植物纲（Magnoliopsida）金缕梅亚纲（Dilleniidae）。该目仅由一个科玉蕊科（Lecythidaceae）组成，约有400个物种。它们是热带木质植物，具有互生的全缘叶、对折的花萼、分离的花瓣、众多的向心雄蕊，以及具有中轴胎座的下位子房。巴西坚果是 `Bertholletia excelsa` 的种子，该物种属于玉蕊科。参见巴西坚果；金缕梅亚纲；木兰植物亚门。 [A.C.]

## Legionnaires' disease

军团病（Legionnaires' disease）是一种肺炎，通常由细菌 *Legionella pneumophila*（嗜肺军团菌）感染引起，但偶尔也由相关物种（如 *L. micdadei* 或 *L. dumoffii*）引起。该病最初于1976年在宾夕法尼亚州费城一个参加退伍军人协会（Legion Convention）的人员中作为流行病被观察到。初始症状包括头痛、发热、肌肉酸痛和全身不适感。体温迅速升高，达到 $102 \sim 105^{\circ}\mathrm{F}$（$32 \sim 41^{\circ}\mathrm{C}$），通常伴有咳嗽、呼吸短促和胸痛。腹痛和腹泻也常出现。在未治疗或诊断不当的情况下，死亡率可高达 $15\%$。红霉素、新一代氟喹诺酮类和利福平被认为是高度有效的药物，而青霉素类和头孢菌素类无效。

虽然军团病（也称为军团菌病，legionellosis）的流行病往往可以追溯到共同来源（冷却塔、饮用水或热水浴缸），但大多数病例似乎是散发性的。据估计，*Legionella* 菌属约占所有社区获得性和医院获得性肺炎的 $4\%$。军团病最常与免疫功能受损的人群相关。*Legionella* 细菌在全世界的新鲜水和潮湿土壤中被广泛发现，并通过吸入含有该细菌的气溶胶传播给人类。军团病不是传染病，表明人类感染不是这些细菌生存策略的一部分。因此，军团菌被视为人类的机会致病菌。是技术（空调）以及通过医疗进步（如移植和终末期疾病治疗）延长寿命的能力，使这些细菌与易感人群接近。

对于大多数暴露于 *L. pneumophila* 的人类，感染无症状或短暂。这归因于健康个体强烈的细胞免疫反应。从军团病中恢复通常能提供针对未来感染的免疫力。然而，目前尚无疫苗。参见医学细菌学；肺炎。 **[PST] [H]**
