
# 自定义内核编译指南

```
rpm -Uvh kernel-source-2.0.36-3.i386.rpm kernel-headers-2.0.36-3.i386.rpm
rpm -Uvh kernel-ibcs-2.0.36-3.i386.rpm
```

如果你在笔记本电脑上运行 Linux，你可能还需要安装 `kernel-pcmcia-cs-2.0.36-3.i386.rpm` 文件，它提供了电源管理功能。

安装内核文件后，你应该能在 `/usr/src/linux/` 目录找到新的源码树。

## 安装额外驱动

下一步是下载任何额外的驱动文件（如果适用），并将它们安装到新的内核源码树中。例如，为了添加对 Mylex DAC960 硬件 RAID 控制器的支持，我会从 http://www.dandelion.com/ 网站下载驱动软件。遗憾的是，此类驱动软件通常只以压缩包的形式提供，需要使用 `tar` 工具进行安装。

```bash
cd /usr/src/
tar zvxf DAC960-2.0.0-Beta4.tar.gz
```

如果适用，您应该阅读随额外驱动软件提供的文档。例如，DAC960 驱动程序包含一个 `README` 文件，它说明了新下载的文件应该放置在何处，以及如何应用内核补丁：

```bash
mv README.DAC960 DAC960.[ch] /usr/src/linux/drivers/block
patch -p0 < DAC960.patch
```

## 修正符号链接

下步是确保您的符号文件链接与新的内核树保持一致。实际上，这一步只需要一次，因此只有在你之前编译过自定义内核的情况下才需要执行以下操作：

```bash
cd /usr/src
cd /usr/include
rm -rf /usr/src/linux/include/asm-i386 asm
ln -s /usr/src/linux/include/linux linux
ln -s /usr/src/linux/include/scsi scsi
```

> 注意：上述步骤对于 2.2.x 或更高版本的内核已不再需要。

## 配置内核

下一步是配置您的内核设置。这是构建自定义内核最重要的一步。如果您禁用了错误的设置，可能会遗漏对您需要的特性或硬件的支持。然而，如果您开启了错误的设置，将无谓地增大内核体积并浪费宝贵的系统内存。

![](img/846ec8d157c5d667ec22f4e21c29db61_103_0.png)

尽管如此，可能宁可选择后者也不要选择前者要好。

确保您正确编译内核的最佳方法是了解您将需要使用哪些功能，以及系统中有哪些需要支持的硬件。在几次自定义内核经验后，这个过程就会变得“轻车熟路”，看起来不再那么令畏了！

输入以下内容开始配置过程：

```bash
cd /usr/src/linux
make mrproper
make menuconfig
```

如果您运行着 X Window 系统，可以输入 `make xconfig` 代替 `make menuconfig`：详情请参阅第 5 章如何使其运行。

要配置内核，请浏览各种设置并选择（启用）任何您需要的项，并取消选择（禁用）您不需要的项。您可以选择将此类支持直接内置内核，或者将其构建为模块，由内核根据需要加载和卸载。如果您将启动系统时实际需要的特性（例如 SCSI 驱动程序）编译为模块，您将需要创建一个 RAMDisk 镜像，否则系统将无法启动。这是通过 `mkinitrd` 命令完成的；该过程在后面稍有描述。

在浏览配置设置时，您可以选择 `<Help>` 来查看特定内核选项的用途。

配置好内核设置后，输入以下命令编译内核：

```bash
cd /usr/src/linux
make dep ; make clean
make bzImage
make modules
```

如果您正在重新编译与之前相同的内核（在本例中为 2.0.36-3），您可能想通过以下命令将现有模块移动到备份目录：

```bash
cd /usr/src/linux
mv /lib/modules/2.0.36-3 /lib/modules/2.0.36-3-backup
```

现在，输入命令实际安装新模块：

```bash
cd /usr/src/linux
make modules_install
```
