# mkmsgs — 创建 gettxt 使用的消息文件

## 概览

`/usr/bin/mkmsgs [-o] [-i locale] input-strings msgfile`

## 描述

`mkmsgs` 命令用于创建一个文本字符串文件，该文件可以被文本检索工具（`gettxt(1)`, `srchtxt(1)`, `exstr(1)` 和 `gettxt(3)`）访问。`mkmsgs` 接收一个特定地理区域（`setlocale(3)`）的文本字符串文件作为输入，并创建一个被 `gettxt(1)` 和 `gettxt(3)` 获取的格式的文本字符串文件。通过使用 `-i` 选项，你可以将文件安装到 `/usr/lib/locale/locale/LC_MESSAGES` 目录下（`locale` 对应于字符串字符串的语言）。

`input-strings` 是包含文本字符串的文件名。`msgfile` 是输出文件名，`mkmsgs` 将字符串以 `gettxt(1)` 和 `gettxt(3)` 可读的格式写入。`infile` 的长度可达 14 个字符，但不能包含 `\0`（空字符）或斜杠（`/`）或冒号（`:`）的 ASCII 代码。

输入文件包含特定地理区域的一组文本字符串。用换行符分隔不同的文本字符串。使用适当的转义序列表示非图形字符。消息从 `input-strings` 顺序转换并复制到 `msgfile`。要在 `msgfile` 中生成一个空消息，请在 `input-strings` 的正确位置留一个空行。

你可以通过编辑 `input-strings` 文件来更改字符串。仅在文件末尾添加新字符串；然后创建一个新的 `msgfile` 文件并将其安装到正确的位置。如果你不遵循此步骤，检索函数将检索错误的字符串，并破坏软件兼容性。

## 选项

- `-o` 如果 `msgfile` 存在，则覆盖它。
- `-i locale` 将 `msgfile` 安装在 `/usr/lib/locale/locale/LC_MESSAGES` 目录下。如果 `/usr/lib/locale` 不存在，则创建目录。只有超级用户或组组成员才能在此目录下创建或覆盖文件。

## 示例

以下示例显示了输入消息源文件 `C.str`。

`File %s:\t cannot be opened\n%s: Bad directory\n.write error\n.`

以下命令使用 `C.str` 中的输入字符串在当前目录下的 `UX` 文件中创建适当格式的文本字符串。

```
castle% mkmsgs C.str UX
```

以下命令使用 `FR.str` 中的输入字符串在 `/usr/lib/locale/fr/LC_MESSAGES` 目录下的 `UX` 文件中创建适当格式的文本字符串。

```
castle% mkmsgs -i fr FR.str UX
```

如果你设置了环境变量 `LC_MESSAGES=fr` 并调用了 `gettxt(1)`、`srchtxt(1)` 或 `exstr(1)` 检索工具之一，你就可以访问这些文本字符串。

`/usr/lib/locale/locale/LC_MESSAGES/*` 由 `mkmsgs` 创建的文件。

# more — 浏览或翻页文本文件

## 概述

`/usr/bin/more [-lines][pattern][file...]`
`/usr/bin/page [-lines][pattern][file...]`
`/usr/bin/more [-lines][pattern][file...]`
`/usr/bin/more [-pattern][file...]`

## 描述

`more` 命令是一个过滤器，一次一个屏幕显示文本文件的内容。通常在每个屏幕后暂停。`/usr/bin/more` 输出 `--More--` 而 `/usr/bin/more` 在屏幕底部打印文件。如果 `more` 是从文件而不是管道读取，还会显示已显示字符的百分比。

按下回车键滚动一个行。按下空格键显示另一个屏幕。其他命令列如下。

页面在显示下一屏幕文本之前清除屏幕；它提供一行的重叠。`more` 命令将终端设置为 NO 模式，以便输出是连续的。除了命令外，你通常不会在终端上看到命令。`usr/bin/more` 在显示最后一个指定的文件后退出；`/usr/bin/more` 在最后一行提示命令。

如果标准输出不是终端，`more` 的作用就像 `cat(1)`，除了在每行之前打印页头之外。

## 选项

以下选项适用于 `/usr/bin/more` 和 `/usr/bin/more`。

- `-c` 显示前清除。为了快速显示，重绘屏幕。如果终端没有清除结束的能力，则忽略此选项。
- `-d` 在使用未知命令时显示错误消息而不是响铃。这对于没有经验的用户有用。
- `-s` 将多个空行替换为单个空行。这在查看 `nroff(1)` 输出时有用。
- `-f` 不折叠长行。当行包含非图形字符或转义序列时（例如通过管道传输 `nroff(1)`），此选项有用。
- `-1` 不将换行符（Control-L）视为分页符。如果不使用 `-1`，`more` 在包含 `^L` 字符的行后暂停接受命令。此外，如果文件以换行符开头，在打印文件之前清除屏幕。
- `-r` 显示控制字符，例如 `^C`，其中 C 代表任何控制字符。通常，`more` 会忽略它不以某种方式解释的控制字符。
- `-u` 抑制生成下划线转义序列。通常情况下，`more` 会处理下划线（例如 `nroff(1)` 产生的下划线），并采取终端的方式。如果终端支持下划线或具有显示模式（standout mode），请根据文本文件的要求提供相应的转义序列。
- `-w` 在退出前提示并等待按下任意键。通常情况下，`more` 在到达输入末尾时退出。
- `-lines` 在每个屏幕中显示指定的行数，而不是默认值（终端屏幕的行数减去 2）。
- `-linenumber` 从指定的行号开始显示。
- `+pattern` 在包含正则表达式模式的行上方开始显示行。请注意，与编辑器不同，此结构不应以斜杠（`/`）结束。如果是，则将末尾的斜杠视为搜索模式中的一个字符。

### `/usr/xpg4/bin/more`

- `-e` 在写完参数列表中最后一个文件的最后一行后立即退出。
- `-i` 在搜索时不区分大小写地进行匹配。
- `-n number` 指定每屏幕的行数。`number` 参数为正整数。`-n` 选项会覆盖从环境中保留的任何值。
- `-p command +command` 对于检查的每个文件，首先执行命令参数中的 `more` 命令。如果 `command` 是定位命令（如行号或正则表达式搜索），则将当前位置设置为该命令的最终结果，而无需写入文件的任何中间行。例如，以下两个命令：

```
more -p 1000j file
more -p 1000G file
```
