
# 扩展与嵌入 Python

## 扩展与嵌入 Python

Python 最强大的功能之一是与用 C 编写的软件进行接口。将 Python 与外部代码集成有两种常用策略。首先，可以将外部函数封装成 Python 库以便通过 `import` 语句使用。此类模块被称为扩展模块（extension modules），因为它们通过非 Python 编写的额外功能扩展了解释器。这是到目前为止最常见的 Python-C 集成形式，因为它允许应用程序访问高性能库。Python-C 集成的另一种形式是嵌入（embedding）。这是一个从 C 以库的形式访问 Python 程序的过程。后一种方法通常被那些由于某些原因想要将 Python 嵌入到现有 C 应用程序框架中的程序员使用——通常是作为某种脚本引擎。

本章涵盖了 Python-C 编程接口的最基础知识。首先，介绍了如何使用 C API 的核心部分来构建扩展模块和嵌入 Python 解释器。本节并非教程，因此对该主题不熟悉的读者应该查阅位于 `http://docs.python.org/ext/` 上的“嵌入与扩展 Python 解释器”文档，以及位于 `http://docs.python.org/c-api` 的“Python/C API 参考手册”。接下来，介绍了类型库。这是一个非常实用的模块，它允许你在不编写任何额外 C 代码或不使用 C 编译器的情况下访问 C 库中的函数。

需要注意的是，对于高级的扩展和嵌入应用，大多数程序员倾向于使用高级代码生成器和编程库。例如，SWIG 项目（`http://www.swig.org`）是一个编译器，它通过解析 C 头文件的内容来创建 Python 扩展模块。关于此工具和其他扩展构建工具的参考可以在 `http://wiki.python.org/moin/IntegratingPythonWithOtherLanguages` 找到。

## 扩展模块

本节概述了为 Python 手写一个 C 扩展模块的基本流程。当你创建一个扩展模块时，你是在 Python 和用 C 编写的现有功能之间构建一个接口。对于 C 库，你通常从如下头文件开始：

```c
/* example.h */
#include <stdio.h>
#include <string.h>
#include <math.h>

typedef struct Point {
    double x;
    double y;
} Point;

/* 计算两个整数 x 和 y 的最大公约数 */
extern int gcd(int x, int y);

/* 将 s 中的每个 och 替换为 n 并返回替换次数 */
extern int replace(char *s, char och, char nch);

/* 计算两点之间的距离 */
extern double distance(Point *a, Point *b);

/* 预处理器常量 */
#define MAGIC 0x31337
```

这些函数在另一个文件中有某种实现实现。例如：

```c
/* example.c */
#include "example.h"
/* 计算两个正整数 x 和 y 的最大公约数 */
int gcd(int x, int y) {
    int g;
    g = y;
    while (x > 0) {
        g = x;
        x = y % x;
    }
    return g;
}
```

```c
/* 替换字符串中的一个字符 */
int replace(char *s, char oldch, char newch) {
    int nrep = 0;
    while ((s = strchr(s,oldch))) {
        *(s++) = newch;
        nrep++;
    }
    return nrep;
}
```

```c
/* 两点之间的距离 */
double distance(Point *a, Point *b) {
    double dx, dy;
    dx = a->x - b->x;
    dy = a->y - b->y;
    return sqrt(dx*dx + dy*dy);
}
```

这里是一个展示这些函数使用的 C `main()` 程序：

```c
/* main.c */
#include "example.h"
int main() {
    /* 测试 gcd 函数 */
    printf("%d\n", gcd(128, 72));
    printf("%d\n", gcd(37, 42));

    /* 测试 replace 函数 */
    char srep[] = "Skipping along unaware of the unspeakable peril.";
    int nrep;
    nrep = replace(srep, ' ', '-');
    printf("%d\n", nrep);
    printf("%s\n", srep);

    /* 测试 distance 函数 */
    Point a = { 10.0, 15.0 };
    Point b = { 13.0, 11.0 };
    printf("%0.2f\n", distance(&a, &b));
}
```

以下是程序的输出：

```
% a.out
8
1
6
Skipping-along-unaware-of-the-unspeakable-peril.
5.00
```
