你已经找到了文件；现在把它们带回家。使用 `binary` 命令传输文件，因为你想要服务器上文件的精确副本。`hash` 命令经常打印 `#` 以让你知道连接是活跃。这种交互如下：

```
ftp> binary
200 Type set to I.
ftp> hash
Hash printing on.
```
