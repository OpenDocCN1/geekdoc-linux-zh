
## 对象行为与特殊方法

Python 中的对象通常根据它们的行为和它们实现的特性进行分类。例如，所有的序列类型（如字符串、列表和元组）都被归为一类，因为它们都支持一组共同的序列操作，如 `s[n]`、`len(s)` 等。所有的解释器操作都是通过特殊方法实现的。特殊方法的名称前后各有一个下划线 (`__`)。这些方法由解释器作为程序执行器自动触发。例如，操作 `x + y` 被映射到内部方法 `x.__add__(y)`，而索引索引操作 `x[k]` 被映射到 `x.__getitem__(k)`。每个数据类型的行为完全取决于它所实现的特殊方法集合。

用户定义的类可以通过提供本节描述的特殊方法的适当子集，定义行为类似于内置类型的新方法。此外，列表和字典等内置类型可以通过重新定义某些特殊方法来被特化（通过继承）。

接下来的几节将描述与不同类别的解释器特性相关的特殊方法。

## 对象的创建与销毁

表 3.11 中的方法用于创建、初始化和销毁实例。`__new__()` 是一个用于创建实例的类方法。`__init__()` 方法初始化对象的属性，并在对象新创建后立即被调用。`__del__()` 方法在对象准备被销毁时调用。该方法仅在对象不再被使用时才被调用。需要注意的是，`__del__` 语句仅减少对象的引用计数，并不一定会导致对该函数的调用。关于这些方法的更多细节可以在第 7 章找到。

### 表 3.11 用于对象创建与销毁的特殊方法

| 方法 |  |
| --- | --- |
| `__new__(cls, *args, **kwargs)` | 创建新实例的类方法 |
| `__init__(self, *args, **kwargs)` | 用于初始化新实例的调用 |
| `__del__(self)` | 在实例被销毁时调用 |

`__new__()` 和 `__init__()` 方法用于创建和初始化新实例。当通过调用 `A(args)` 创建对象时，它会被转换为以下步骤：

```python
x = A.__new__(A,args)
if isinstance(x,A): x.__init__(args)
```

在用户定义的对象中，定义 `__new__()` 或 `__del__()` 是罕见的，它们通常定义在元类中，或者在继承自某一种不可变类型（整数、字符串、元组等）的用户定义对象中。`__del__()` 仅在存在某种关键资源管理问题时才会被定义，例如释放锁或关闭连接。

## 对象的字符串表示

表 3.12 中的方法用于创建对象的各种字符串表示。

### 表 3.12 用于对象表示的特殊方法

| 方法 | 说明 |
| --- | --- |
| `__format__(self, format_spec)` | 创建格式化表示 |
| `__repr__(self)` | 创建对象的字符串表示 |
| `__str__(self)` | 创建简单的字符串表示 |

`__repr__()` 和 `__str__()` 方法创建对象的简单字符串表示。`__repr__()` 方法通常返回一个可以求值以重建对象的表达式。该方法也是创建由内置 `repr()` 函数调用的值之输出的方法。这里有一个使用 `repr()` 和 `eval()` 的示例：

```python
a = [2,3,4,5]
## 创建一个列表
s = repr(a) # s = '[2, 3, 4, 5]'
b = eval(s)  # 将 s 转回列表
```

如果无法创建字符串，惯例是 `__repr__()` 返回一个格式为 `<message...>` 的字符串，如下：

```python
f = open("foo")
a = repr(f)
```

`__str__()` 方法由内置的 `str()` 函数调用。它与 `__repr__()` 的不同在于它对用户更易读。如果无法创建字符串，惯例是 `__repr__()` 返回一个格式为 `<message...>` 的字符串，如下：

```python
f = open("foo")
a = str(f)
```

`__format__()` 方法由内置的 `format()` 函数调用。它与 `__str__()` 的不同在于它允许更复杂的格式选项。`__format__()` 方法也被 f-strings 使用。（OCR 文本非常混乱，正在重构逻辑）。

## 属性包装与描述符

属性操作的一个微妙方面是，对象的属性被包装在了一层额外的逻辑中，这些逻辑会与前一节描述的 get、set 和 delete 操作进行交互。这种包装通过创建一个实现了表 3.17 中一个或多个方法的描述符来实现。请记住，描述符是可选可选的，而且很少需要定义。

表 3.17 描述符对象的特殊方法

| 方法 | 描述 |
| --- | --- |
| __get__(self, instance, cls) | 返回属性值或抛出 AttributeError |
| __set__(self, instance, value) | 将属性设置为 value |
| __delete__(self, instance) | 删除属性 |

描述符的 `__get__()`、`__set__()` 和 `__delete__()` 方法旨在与类和类型 `__getattribute__()`、`__setattr__()` 和 `__delattr__()` 的默认实现交互。如果你在用户定义的类体内放置描述符对象的实例，就会发生这种交互。在这种情况下，对描述符属性的所有访问都将隐式地调用描述符对象本身的相应方法。通常，描述符用于实现对象系统的低级功能，包括绑定和未绑定的方法、类方法、静态方法和属性。更多示例见第 7 章。

## 序列与映射方法

表 3.18 中的方法被模拟序列和映射对象的对象使用。

表 3.18 序列与映射的方法

| 方法 | 描述 |
| --- | --- |
| __len__(self) | 返回 self 的长度 |
| __getitem__(self, key) | 返回 self [key] |
| __setitem__(self, key, value) | 设置 self [key] = value |
| __delitem__(self, key) | 删除 self [key] |
| __contains__(self, obj) | 如果 obj 在 self 中则返回 True；否则返回 False |

这里有一个示例：

```
a = [1,2,3,4,5,6]
len(a)      # 6
x = a[2]    # 3
a[1] = 7    # None
del a[2]   # [1, 7, 4,5,6]
5 in a      # True
```

`__len__` 方法由内置的 `len()` 函数调用以确定一个非负长度。除非定义了 `__bool__()` 方法，否则该函数还会确定真值。

## 对象行为与特殊方法

对于项的操作，`__getitem__()` 方法可以根据键值返回一个项。`__setitem__()` 方法为元素分配一个值。当 `del` 操作应用于单个元素时，会调用 `__delitem__()` 方法。`__contains__()` 方法用于实现 `in` 操作符。

切片操作如 `x = s[i:j]` 是通过 `__getitem__()`、`__setitem__()` 和 `__delitem__()` 实现的。然而，对于切片，切 对象作为键传递。它具有定义所请求切片范围的属性。

```
a = [1,2,3,4,5,6]
```
