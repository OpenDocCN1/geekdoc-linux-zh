
`XrmDatabase` *database;

`XrmBindingList` bindings;

`XrmQuarkList` quarks;

`XrmRepresentation` *type;

`XrmValue` *value;

`XFpointer` arg;

`bindings` 和 `quarks` 由 `NULLQUARK` 终止。请注意，指向数据库和类型的指针会被解析，但这些值不应被修改。

该过程不得修改数据库。如果为线程初始化了 Xlib，则调用该过程时数据库是被锁定的，且该过程调用任何使用相同数据库的 Xlib 函数的结果未定义。

## 资源管理器函数

`XrmCommand` 函数可用于解析程序的命令行参数，并根据命令行选择的条目来修改和修改资源数据库。

```c
typedef enum {
    XrmOptionNoArg,            /* 值在 XrmOptionDescRec.value 中指定 */
    XrmOptionIsArg,           /* 值是选项字符串本身 */
    XrmOptionStickyArg,       /* 值是紧随选项的字符 */
    XrmOptionSepArg,         /* 值是 arg 中的下一个参数 */
    XrmOptionResArg,         /* 值是 arg 中的下一个资源和值 */
    XrmOptionSkipArg,        /* 忽略此选项和 arg 中的下一个参数 */
    XrmOptionSkipLine,      /* 忽略此选项和 arg 的剩余部分 */
    XrmOptionSkipNArgs,      /* 忽略此选项和后续 */
                            /* arg 中的 XrmOptionDescRec. 值 */
} XrmOptionKind;
```

请注意，`XrmOptionSkipArg` 等于 `XrmOptionDescRec.value` 字段包含值 1 的 `XrmOptionSkipNArgs`。另请注意，`XrmOptionSkipNArgs` 的值 0 表示仅跳过选项本身。

## 资源管理器函数

```c
typedef struct {
    char *option;         /* argv 中的选项指定字符串 */
    char *specifier;      /* 绑定和资源名称（不含应用程序名称） */
    XrmOptionKind kind;   /* 选项的值类型 */
    XPointer value;        /* 如果是 XrmoptionNoArg 或提供的值 */
    \                    /* XrmOptionSkipArgs */

```

要从 C 命令行加载资源数据库，请使用 `XrmParseCommand`。

```c
void XrmParseCommand(database, table, table_count, name, argc_in_out, argv_in_out);
```

`database`

指定资源数据库。

`table`

指定要解析的命令行参数表。

`table_count`

指定表中的条目数量。

`name`

指定应用程序名称。

`argc_in_out`

指定参数数量并返回剩余参数。

`XrmParseCommand` 函数根据指定的选项表解析 `(argc, argv)` 对，将识别出的选项以 "String" 类型加载到指定的数据库中，并修改 `(argc, argv)` 以移除所有识别出的选项。如果 `database` 包含 `NULL`，`XrmParseCommand` 将创建一个新的数据库并返回其指针。否则，条目将被添加到指定的数据库中。指定的表被用于解析命令行。表中的识别出的选项将使用 "String" 表示类型创建。如果 `name` 参数不在主机可移植字符编码中，结果取决于实现。

## 使用键盘实用函数

本节讨论了 KeyCodes 与 KeySums 之间的映射、KeySums 的分类，以及 KeySums 与字符串名称之间的映射。本节的前三个函数在键盘映射的缓存副本上操作。每个 KeyCode 的前四个 KeySums 会根据第 12.7 节给出的规则进行修改。要获取为按键定义的未转换 KeySums，请使用第 12.7 节中描述的函数。

要获取事件 KeyCode 的 KeySym，使用 `XLookupKeySym`。

```c
KeySym XLookupKeySym(key_event, index);
```

`key_event` 指定 KeyPress 或 KeyRelease 事件。

`index` 指定事件 KeyCode 对应的 KeySums 列表的索引。

`XLookupKeySym` 函数使用给定的事件和指定的索引，从列表中返回与 `XKeyPressedEvent` 或 `XKeyReleased` 结构体中 `KeyCode` 成员对应的 `KeySym`。如果该事件的 `KeyCode` 没有定义 `KeySym`，则 `XLookupKeySym` 返回 `NoSymbol`。

要获取特定 KeyCode 的 KeySym，使用 `XKeycodeToKeySym`。
