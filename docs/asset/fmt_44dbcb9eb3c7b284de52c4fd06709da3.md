
在这里我们使用 `uniq` 来报告我们的文本文件中发现的重复项数量，使用 `-c` 选项：

```
$ sort foo.txt | uniq -c
```

## 切片与处理

我们将讨论的三个程序将用于从文件中剥离列并以实用的方式重新组合。

### `cut` 从每行移除部分

`cut` 程序用于从行中提取部分并将提取的部分输出到标准输出。它可以接受多个文件参数或标准输入。

指定要提取的部分有些笨拙，它是使用表 20-3 中的选项指定的。

**表 20-3:** `cut` 选项

| 选项 | 长选项 | 描述 |
| :--- | :--- | :--- |
| `-c list` | `--characters=list` | 提取由列表定义的字符。列表可以是逗号分隔的范围。 |
| `-f list` | `--fields=list` | 从行中提取一个或多个字段。列表可以包含由逗号分隔的字段。 |
| `-d delim` | `--delimiter=delim` | 当指定了 `-f` 时，使用 `delim` 作为字段分隔符。默认情况下，字段由单个制表符分隔。 |
|  | `--complement` | 提取整行，除了由 `-c` 和 `-f` 指定的部分。 |

正如我们可以看到的，`cut` 提取并不灵活，它用于从其他程序产生的文本，而不是人类直接输入的文本。我们将查看 `distros.txt` 文件，看看它是否足够符合制表符文件的要求。如果我们在使用 `cut` 时使用 `-A` 选项，就可以查看文件是否满足要求。

```
[me@linux]$ cut -A distros.txt

Ubuntu	8.04	04/24/2008
Fedora	8	11/08/2007
SUSE	10.3	10/04/2007
Ubuntu	7.10	10/18/2007
Fedora	7	05/31/2007
Ubuntu	7.04	04/19/2007
Ubuntu	6.10	10/26/2006
Fedora	6	10/24/2006
Ubuntu	6.06	06/01/2006
SUSE	10.1	05/11/2006
Fedora	5	03/20/2006
Fedora	9	05/13/2008
Ubuntu	8.10	10/30/2008
```

Ubuntu\*16.06\*\*06/01/2006$  
Ubuntu\*8.10\*\*10/30/2008$  
Fedora\*5\*\*03/20/2006$

看起来不错。字段之间没有嵌入空格，只有单个制表符（tab）字符。由于该文件使用制表符而非空格，我们将使用 `-f` 选项来提取字段。

```
[me@linuxbox~]$ cut -f 3 distros.txt

由于我们的 distros 文件是制表符分隔的，最好使用 `cut` 来提取字段而非提取字符。这是因为当文件按制表符分隔时，每行包含相同数量字符的概率很小，这使得行内的字符位置定位变得困难或无法实现。然而，在之前的一个示例中，我们现在提取出的字段幸运地包含相同长度的数据，我们可以通过从每行提取年份来展示字符提取是如何工作的。

```
[me@linuxbox~]$ cut -f 3 distros.txt | cut -c 7-10
2006
2008
2008

2007
2006
2006

```

通过对我们的列表第二次运行 `cut`，我们能够提取第 7 到第 10 个字符，这对应于日期字段中的年份。`7-10` 表示法是一个范围示例。`cut` 的 man 页面包含了关于如何指定范围的完整说明。

在处理字段时，可以指定不同于制表符的分隔符。在这里，我们将从 `/etc/passwd` 文件中提取第一个字段：

$me@linux ~$ cut -d ':' -f 1 /etc/passwd | head

```

使用 `-d` 选项，我们可以指定冒号字符作为字段分隔符。

### `paste`—合并文件行

`paste` 命令的作用与 `cut` 相反。它不是从文件中提取一列，而是向文件中添加一列或多列文本。它通过读取多个文件并将每个文件中找到字段合并到标准输出的单个流中来实现这一点。与 `cut` 类似，`paste` 处理多个文件参数和/或标准输入。为了演示 `paste` 如何工作，我们将对 `distros.txt` 进行一些操作以产生按时间顺序的发布列表。

根据我们之前对 `sort` 的使用，我们将首先生成按日期排序的发行版列表，并将结果存储在名为 `distros-by-date.txt` 的文件中。

```
$me@linuxbox ~$ sort -k 3.7nr -k 3.1nr -k 3.4nr distros.txt > distros-by-date.txt
```

接下来，我们将使用 `cut` 提取文件的前两个字段（发行名称和版本），并将结果存储在名为 `distro-versions.txt` 的文件中。

```
$me@linuxbox ~$ cut -f 1,2 distros-by-date.txt > distros-versions.txt
$me@linuxbox ~$ head distros-versions.txt
Fedora 10
Ubuntu 8.10
SUSE 11.0
Fedora 9
Ubuntu 8.04
Fedora 8
Ubuntu 7.10
SUSE 10.3
Fedora 7
Ubuntu 7.04
```

最后的准备工作是提取发布日期并将其存储在 `distro-dates.txt` 文件中。

```
$me@linuxbox ~$ cut -f3 distros-by-date.txt > distros-dates.txt
$me@linuxbox ~$ head distros-dates.txt
11/25/2008
10/30/2008
06/19/2008
05/13/2008
04/24/2008
11/08/2007
10/18/2007
10/04/2007
05/31/2007
04/19/2007
```

我们现在拥有了所需的各个。为了完成整个过程，使用 `paste` 将日期列置于发行名称和版本之前，创建一个按时间顺序的列表。这是通过使用 `paste` 并排列其参数来实现的。

```
$me@linuxbox ~$ paste distros-dates.txt distros-versions.txt
11/25/2008 Fedora 10
10/30/2008 Ubuntu 8.10
06/19/2008 SUSE 11.0
05/13/2008 Fedora 9
04/24/2008 Ubuntu 8.04
11/08/2007 Fedora 8
10/18/2007 Ubuntu 7.10
10/04/2007 SUSE 10.3
05/31/2007 Fedora 7
04/19/2007 Ubuntu 7.04
12/07/2006 SUSE 10.2
10/26/2006 Ubuntu 6.10
10/24/2006 Fedora 6
06/01/2006 Ubuntu 6.06
05/11/2006 SUSE 10.1
03/20/2006 Fedora 5
```
