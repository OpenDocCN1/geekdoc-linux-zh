# build-essential

软件包信息列表。如果你不需要构建 Debian 软件包，就不需要这个包。此外，构建 Debian 软件包也不需要此包。该包包含了被认为构建 Debian 软件包必需的软件包信息列表。该包依赖于它所依赖的包，以便于安装 `build–essential` 软件包。如果你安装了这个包，你只需要安装任何你构建时依赖的包，或者你始终可以忽略该包所依赖的包。此包**并不是**哪些包是构建必需的的定义；真正的定义在《Debian 策略手册》中。此包仅包含一个软件包的信息列表。来自 Debian 3.0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
