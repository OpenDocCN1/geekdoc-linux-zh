
米粒有四个主要部分：外壳或壳，种皮或糠，胚或芽，以及胚乳。大米加工的主要目标是去除不可消化的外壳和额外的糠部分，以得到完整未破碎的胚乳。大米加工涉及相对简单的研磨和分离程序，产生取决于糠去除程度或胚乳破碎程度的各种产品。

即食米是通过在受控的烹饪、冷却和干燥条件下预处理全谷物米制成的，以赋予其快煮特性。即食早餐米片粥是用加工大米制成的片状或膨化产品。米糠油是增加从米糠中提取脂质的结果。它作为食用级油用于各种应用，也作为肥皂和树脂应用的工业原料。参见：谷物；脂肪和油（食品）；食品制造；溶剂萃取。[M.A.U]

## Ricinelu（里塞内卢）

## 立克次体病

继由多种高度特异性细菌引起的严重传染病之后，是立克次体和类立克次体生物引起的疾病。最为人熟知的立克次体病感染人类，通常由寄生节肢动物媒介传播。

立克次体和类立克次体生物是在光学显微镜下可见的最小微生物之一。尽管最初因体积微小且需在细胞内复制的特性而被误认为病毒，但立克次体和类立克次体生物具有基本的细菌（革兰氏阴性）形态特征。其关键代谢酶是典型细菌酶的变体。立克次体和类立克次体生物的遗传物质同样似乎遵循基本的细菌模式。所有类立克次体生物的基因组均由双链脱氧核糖核酸（DNA）组成。

立克次体通过吞噬作用进入宿主细胞，并以简单的二分裂方式繁殖。在不同属之间，生长和繁殖的位点各不相同。

在临床方面，人类立克次体病最常见的特征包括发热、头痛和某种形式的皮疹，常包括弥漫性皮疹，如流行性斑疹伤寒、鼠型斑疹伤寒和落基山斑点热所呈现的症状，或媒介叮咬部位的初发溃疡或焦痂，如地中海斑点热和丛林斑疹伤寒所呈现的症状。立克次体病个体病例间的疾病体征可能差异显著。Q 热在临床方面具有特殊性，包括经常缺乏皮肤损伤。

所有人类立克次体病，若在感染早期得到诊断，通常可用适当的抗生素有效治疗。四环素和氯霉素是最有效的抗生素之一；它们能阻止疾病活动的进展，但并不能实际杀死立克次体。推测免疫系统最终负责清除体内的感染生物。青霉素及其相关化合物不被认为有效。参见**抗生素**。

大多数立克次体病在自然界中作为非人类脊椎动物及其寄生虫的疾病得以维持。人类感染通常被视为正常自然感染周期的边缘环节，人传人并非普遍规律。然而，引起流行性斑疹伤寒的生物体（*Rickettsia prowazekii*）和引起战壕热的病原体（*Rochalimaea quintana*）具有在满是虱子的人群中快速传播的潜力。参见**人兽共患病**。

所有虱传斑点热群生物均由蜱虫传播。尽管各类疾病在全球范围内分布，但几乎所有斑点热群生物共享密切的遗传、抗原性以及某些病理特征。人类疾病示例包括落基山斑点热（南北美洲）、山热或地中海斑点热（南欧）、南非蜱叮咬热（非洲）、印度蜱传斑疹伤寒（印度次大陆）和西伯利亚蜱传斑疹伤寒（东北欧和北亚）。如果未施以适当的抗生素，落基山斑点热等疾病将是危及生命的疾病。参见**传染病**。

*修正思考*：作为文档工程师，如果原文有明显事实错误，通常应翻译原文，除非要求校对。但这里我是“翻译员”。我将直译。

如果在 $z = 1$ 处将 $\sqrt{z}$ 赋值为 $-1$，则电路末端的值为 $-1$。类似地，如果在 $z = 1$ 处将 $\log z$ 赋值为 $0$，则在允许数值连续变化的情况下，电路末端的值为 $2\pi i$。参见**复数**。

构建 $\sqrt{z}$ 的抽象曲面的过程如下：在该曲面上，$\sqrt{z}$ 在每个点都有单值，并且 $\sqrt{z}$ 的值在每个闭合路径周围连续变化，始终回到起始值。具体操作如下：从非负实半轴（$z = x + iy$，其中 $y = 0, 0 \leq x$）处移除复平面 C 的一部分。这个狭缝被称为有两个边缘：上边缘（或 + 边缘）和下边缘（或 - 边缘）（不计 $z = 0$ 点）。然后将该狭缝平面的另一个副本放置在原平面的上方，并与之平行，如同建筑物的第一层和第二层。接着，通过将底层 - 边缘连接到顶层 + 边缘，以及底层 + 边缘连接到顶层 - 边缘，将这两张纸连接起来。这样构建出的抽象曲面并没有嵌入欧几里得三维空间，因为在三维空间中执行这些连接会产生自相交。在上一层面上，$\sqrt{z}$ 在 $z$ 点上方被定义为具有正虚部，而在下一层面被定义为具有负虚部。

所构建的抽象曲面称为 $\sqrt{z}$ 的黎曼曲面。它在 $z$ 平面上是双层的，但在 $z = 0$ 点上方只有一个点，因此该点被称为分支点。

拥有 $n$ 个分支而非 2 个分支的 $\sqrt[n]{z}$ 的黎曼曲面在插图中展示。

在 20 世纪 20 年代初，H. Weyl 在新兴的拓扑学领域背景下定义了黎曼曲面。这个定义不依赖于手头有一个特定的函数，也不需要使用狭缝等看似人为的工具。黎曼曲面是具有复结构的二维连通拓扑流形（曲面）。参见**流形（数学）**；**拓扑学**。[J.A.M.]
