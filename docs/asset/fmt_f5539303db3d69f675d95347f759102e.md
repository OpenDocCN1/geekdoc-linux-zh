
# 恒星旋转
恒星由于其角动量而旋转，并不一定像固体一样旋转，但它们的角动量仍可能根据半径和纬度分布。然而，由于无法解析恒星表面或观察其内部，且观测能力有限，它们的旋转通常表述为一个数值，`v_{sin}`，其中 `v_{sin}` 是赤道旋转速度（单位千米/秒），它是恒星轴与视线之间的角。换句话说，`v_{sin}` 是恒星与观测者之间可见的旋转分量。我们测量恒星 `v_{sin}` 的范围从 `50 km/s` (`30 km/s`) 到 `400 km/s` (`250 km/s`) 或更高。
