
# 氧

一种气态化学元素，`O`，原子序数 8，原子量 15.9994。氧之所以备受关注，是因为它既是大多数活细胞呼吸过程中的基本元素，也是燃烧过程中的基本元素。它是地壳中丰度最高的元素。空气中约有五分之一（按体积计）是氧。

氧通过液化空气和分馏蒸馏从空气中分离出来。氧的主要用途按重要性顺序为：(1) 钢铁和其他金属的冶炼、精炼和制造；(2) 通过控制氧化制造化学品；(3) 火箭推进；(4) 生物生命支持和医学；以及 (5) 采矿、石材和玻璃制品的生产与制造。

未化合的气态氧通常以双原子分子 `O₂` 的形式存在，但氧也以独特的三原子形式 `O₃` 存在，称为臭氧。参见 `OZONE`（臭氧）。

在通常条件下，氧是无色、无味、无臭的气体。它冷凝为淡蓝色液体，这与在液态时无色的氮气形成对比。氧是一组弱顺性气体中的一员，也是该组中顺磁性最强的。液态氧也略有顺磁性。关于氧及其普通形式 `O₂` 的一些数据和一些性质列于表中。参见 `PARAMAGNETISM`（顺磁性）。

除了惰性气体外，实际上所有化学元素都与氧形成化合物。大多数元素在含氧气体氛围中加热时会形成氧化物。许多元素形成多于一种氧化物；例如，硫形成二氧化硫 (`SO₂`) 和三氧化硫 (`SO₃`)。最常见的二元含氧化合物包括水 `H₂O` 和二氧化硅 `SiO₂`，后者是沙子的主要成分。在包含两种以上元素的化合物中，最丰富的是硅酸盐，它们构成了大多数岩石和土壤。其他广泛存在的化合物包括碳酸钙（石灰石和大理石）、硫酸钙（石膏）、氧化铝（铝土矿）以及各种作为铁源的氧化铁。几种非金属元素也以氧化物形式被开采。过氧化氢 `H₂O₂` 是一种有趣的化合物，广泛用于漂白。参见 `HYDROGEN PEROXIDE`（过氧化氢）；`OXIDATION-REDUCTION`（氧化还原）；`OXIDE`（氧化物）；`PEROXIDE`（过氧化物）；`WATER`（水）。(A.W.E., L.M.S.)

# 氧中毒

由氧的一种形态在生物体内引起的毒性效应。氧具有两个侧面，一个是良性的，另一个是恶性的。那些利用双氧 (`O₂`) 提供的巨大代谢优势的生物体必须防御其毒性。将一个 `O₂` 分子完全还原为两个水 (`H₂O`) 分子需要四个电子；因此，在通过单价途径还原 `O₂` 的过程中必然会遇到中间体。`O₂` 还原的中间体，按其产生的顺序，是超氧自由基 (`O₂⁻·`)、过氧化氢 (`H₂O₂`) 和羟基自由基 (`HO⁻·`)。参见 `OXYGEN`（氧）；`SUPEROXIDE CHEMISTRY`（超氧化物化学）。

氧还原的中间体，而非 `O₂` 本身，可能是氧中毒的主要原因。因此，防御措施必须针对这些中间体。超氧自由基被催化以下反应的酶消除。

```
O_2^{-\cdot} + O_2 + 2H^+ \to H_2O_2 + O_2
```

这些酶被称为超氧化物歧化酶，已从多种生物体中分离出来。过氧化氢 (`H₂O₂`) 也必须被消除，这是通过两种酶机制实现的。第一种是 `H₂O₂` 歧化为水和氧的过程，由过氧化氢酶催化。第二种是 `H₂O₂` 在多种还原剂的作用下还原为两个水分子的过程，由过氧化物酶催化。参见 `ENZYME`（酶）。

超氧化物歧化酶、过氧化氢酶和过氧化物酶的多样性，以及这些酶极高的催化效率，为抵御 `O₂⁻` 和 `H₂O₂` 提供了强大的防御。如果 `O₂` 还原的前两个中间产物被消除，第三个（`HO•`）就不会产生。然而，没有任何防御是完美的，总会有一些 `HO•` 产生；因此必须将其有害影响降至最低。这在很大程度上是通过抗氧化剂实现的，它们阻止了自由基链式反应的传播。参见：抗氧化剂；链式反应（化学）；自由基；肽。

需氧生物体在含有 20% `O₂` 的大气中能够安然生存，这归因于一套复杂且高效的防御系统，用以对抗这种特殊的气体。事实上，这些防御很容易就被压倒，当生物体暴露于 100% `O₂` 中时，氧气中毒的明显症状就会显现。例如，一只在 100% `O₂` 中维持的老鼠会在 2 到 3 天内死亡。[L.F.]

## 夜行虫目

门下的鞭毛虫纲下的一个目，属于原生动物门。这些是无色的鞭毛虫共生体，生活在蟑螂 *Cryptocoptis* 和某些白蚁的消化道中。它们具有取食木质部的特性；也就是说，它们摄入宿主吞下的木屑。已鉴定出七个或更多的中大型属；生物体形状从梨形到卵形不等。在前端，一个柔软的颈状喙状结构将生物体附着在宿主的肠壁上，但有时它们是自由的。它们可以是单核或多核的。参见：鞭毛虫纲。[J.B.L.]

## 臭氧

元素氧气一种具有强氧化性的同素异形体。臭氧分子包含三个原子（`O₃`）。臭氧气体呈明显的蓝色，而液态和固态臭氧呈不透明的蓝黑色，类似于墨水。参见：氧气。

臭氧的一些特性列于表中。臭氧具有一种特征性的刺鼻气味，大多数人对此很熟悉，因为当电气设备在空气中产生火花时会形成臭氧。臭氧对黏膜有刺激性，对人类和低等动物有毒性。

臭氧比氧气更强的氧化剂，用臭氧进行的氧化反应会释放更多的热量，且通常比使用氧气时的起始温度更低。在水的存在下，臭氧是一种强力的漂白剂，其作用比过氧化氢、氯或二氧化硫更快。参见：氧化剂。

臭氧被用于饮用水的处理。产生异味和异味的烃类可通过臭氧氧化被有效消除。导致水变色的铁和锰化合物可通过臭氧处理减少。与氯相比，用臭氧进行细菌和病毒消毒的速度快 5000 倍。

臭氧在地壳大气中存在的程度不一。在地表附近，乡村空气中的浓度通常为 0.02–0.03 ppm，城市中更低，除非有烟雾。在海拔 13 英里（20 公里）以上的垂直高度，臭氧由大气中的氧气经光化学作用形成。最大浓度 5 × 10¹² 个分子/立方厘米（比地表正常峰值浓度高 1000 倍以上）出现在海拔 19 英里（30 公里）处。[A.W.F]

## 臭氧化合反应

一种利用臭氧断裂不饱和有机键的过程。通常，臭氧化合反应是通过将富臭氧的氧气或空气鼓入反应物的溶液中进行的。反应在中等温度下进行得很快。中间体通常不被分离，而是在进一步的氧化条件下处理以产生酸，或在还原条件下处理以形成醇或醛。不对称烯烃能够产生两种不同的产物，其结构与烯烃上的取代基团和双键的位置有关。

在第一次世界大战之前，臭氧化合反应被商业应用于从异丁香酚制备香草醛。该技术在美国唯一的现代应用是从油酸制造己二酸和壬二酸。参见：烯烃；臭氧。[R.K.Ba.]

## 太平洋群岛

一个地理名称，包括散布在太平洋上数千个主要由珊瑚和火山组成的小岛，从西边的帕劳到东边的复活节岛。位于亚洲大陆沿岸的岛屿群岛，如日本、菲律宾和印度尼西亚，即使位于太平洋盆地内，也不包括在内。构成巴布亚新几内亚和伊里安查亚大陆的大岛，以及澳大利亚大陆和新西兰（奥特亚罗瓦）的岛屿也被排除在外。后者连同亚洲太平洋群岛一起，拥有比通常被标记为美拉尼西亚、密克罗尼西亚和波利尼西亚的海洋岛屿更大的陆地区域，以及更多样化的资源和生态系统。参见：澳大利亚；新西兰；海洋岛屿。

这些岛屿中绝大多数陆地面积在 4 到 4000 平方英里（10 到 10,000 平方公里）之间。最大的三个岛屿包括新喀里多尼亚主岛（6220 平方英里或 16,100 平方公里）、斐济的维图勒武岛（4053 平方英里或 10,497 平方公里）和夏威夷链中最大的岛屿夏威夷（4031 平方英里或 10,440 平方公里）。当将 80 英里（200 公里）的专属经济区纳入表面积计算时，一些太平洋岛国拥有非常广阔的领土。这些陆地和海域领域，远比那些小且碎片化的陆地面积本身更能捕捉到对太平洋人民具有意义的岛屿世界的本质。参见：东印度群岛。

海洋岛屿通常根据其表面岩石性质的不同进行分类。通常区分西部太平洋较大的大陆岛屿、东部太平洋的火山玄武岩岛屿链和集群，以及中北部太平洋散布的珊瑚石灰岩环礁和礁岛。

有人建议，在板块边界岛屿和板内岛屿之间可以画出更有用的区别。前者与构成地球表面的巨大构造板块沿边界的运动有关。板块边界类型的岛屿形成于汇聚、发散或横向板块边界，它们代表了西部太平洋大多数大型岛群的特征。这些岛屿通常在火山和构造上活跃，并构成所谓的太平洋“火环”的一部分，该环从南极洲呈 sweeping 弧形延伸，经过新西兰、瓦努阿图、布干维尔岛、菲律宾到日本。
