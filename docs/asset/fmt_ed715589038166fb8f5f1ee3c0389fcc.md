## 实用函数

这里定义了一些实用函数：

```
dump(elem)
```

将元素导出到 `sys.stdout`。输出通常为 XML。

```
iselement(elem)
```

检查 `elem` 是否为元素实例。

```
iterparse(source, {events})
```

增量解析 XML。`source` 是文件名或类文件对象。`events` 是产生事件类型的列表。可能的事件类型有 `'start'`, `'end-ns'`。如果省略，仅产生 `'end'` 事件。此函数的返回值是一个迭代器，产生 `(event, elem)`，其中 `event` 是字符串 `'start'` 或 `'end'` `elem` 是正在处理的元素。对于 `'start'` 事件，元素是新创建的且为空；对于 `'end'` 事件，元素已完全填充。

```
parse(source)
```

将 XML 源完全解析为 ElementTree 对象。`source` 是文件名或类文件对象。

```
tostring(elem)
```

创建表示 `elem` 及其所有子元素的 XML 字符串。

考虑一个使用了命名空间的 XML 文件 `recipients.xml`：

```xml
<?xml version="1.0" encoding="iso-8859-1"?>
<recipe xmlns:r="http://www.dabeaz.com/namespaces/recipe">
  <title>
    Famous Guacamole
  </title>
  <description>
    A southwest favorite!
  </description>
  <ingredients>
    <item r="4"> Large avocados, chopped</item>
  </ingredients>
  <directions>
    混合所有配料并搅拌以确保一致性。
    搭配冰啤酒上菜并享用。
  </directions>
</recipe>
```

要处理命名空间，通常简单的方法是使用字典将命名空间映射映射到相关的命名空间 URI。如下所示，使用字符串格式化对 URI 进行操作：

```python
from xml.etree import ElementTree
doc = ElementTree.parse('recipients.xml')
ns = {
  'r': 'http://www.dabeaz.com/namespaces/recipients'
}
ingredients = doc.findall('.//{r}item' % ns)
for item in ingredients.findall('.//{r}item' % ns):
  num = item.get('num')
  units = item.get('units')
  text = item.text.strip()
  quantity = "%s %s" % (num, units)
  print("%-10s %s %" % (quantity, text))
```

就是使用 `ElementTree.iterparse()` 函数。这里是迭代处理上一个文件中 `<album>` 节点的示例：

```python
from xml.ElementTree import iterparse

iparse = iterparse('music.xml', ['start', 'end'])
# 找到顶层音乐元素
for event, elem in iparse:
    if event == 'start' and elem.tag == 'music':
        musicNode = elem
        break

# 获取所有专辑
albums = (elem for event, elem in iparse if event == 'end' and elem.tag == 'album')

for album in albums:
    # 某种处理
    musicNode.remove(album) # 完成后丢弃专辑
```

使用 `iterparse()` 的关键在于有效地丢弃你不再需要的数据。最后一条语句 `musicNode.remove(album)` 正在丢弃我们已经处理完的每个 `<album>` 元素（通过将其移除）。如果你监控上一个程序的内存占用情况，你会发现即使输入文件巨大，内存占用也会保持在低水平。

## Notes

- ElementTree 模块是 Python 中处理简单 XML 文档最快且最灵活的方法。然而，它没有提供许多花哨功能。例如，它不支持验证，也没有提供明显的方法来处理 XML 文档的复杂方面（如 DTD）。对于这些功能，你需要安装第三方包。其中一个包 `lxml`（位于 http://xml.org/lxml/）为流行的 libxml2 和 libxslt 库提供了 ElementTree API，并对 XPath、XSLT 和其他功能提供了完全支持。

- ElementTree 本身是一个由 Fredrik Lundh 在 http://effbot.org/zone/element-index.htm 创建的第三方包。在该网站上，你可以找到比标准库包含的更多、且提供额外功能的版本。

## xml.sax

`xml.sax` 模块提供了使用 SAX API 解析 XML 文档的支持。

```
parse(file, handler [, error_handler])
```

解析 XML 文档，`file.file` 是文件名或已打开的文件对象。`handler` 是内容处理对象。`error_handler` 是一个可选的 SAX 错误处理器对象，在在线文档中有更详细的描述。

```
parseString(string, handler [, error_handler])
```

与 `parse()` 相同，但解析包含在字符串中的 XML 数据。

## Handler Objects

要执行任何处理，你必须为 `parse()` 或 `parseString()` 函数提供一个内容处理对象。要定义处理器，你需要定义一个继承自 `ContentHandler` 的类。`ContentHandler` 的实例 `c` 具有以下方法，根据需要可以在你的处理器中重写：

```
c.characters(content)
```

由解析器调用以提供原始数据。`content` 是包含字符的字符串。

```
c.endDocument()
```

解析器在到达文档末尾时调用。

```
c.endElement(name)
```

解析器在元素结束时调用。

```
c.endElementNS(name, gname)
```

解析器在元素结束时调用。

```
c.endElement(name, gname)
```

解析器在元素结束时调用。`gname` 是完全限定名。

```
c.endPrefixMapping(prefix)
```

在 XML 命名空间声明结束时调用。`prefix` 是前缀，`uri` 是 URI。

```
c.ignorableWhitespace(whitespace)
```

当遇到忽略的空白时调用。`whitespace` 是字符串。

```
c.processingInstruction(target, data)
```

当遇到处理指令时调用。`target` 是类型。

```
c.setDocumentLocator(locator)
```

由解析器调用以提供定位器。`locator` 提供行号、列号等信息。
