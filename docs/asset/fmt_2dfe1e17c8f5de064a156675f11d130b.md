## 新的项目提交表单

`添加新项目`……链接指向 `add_form.php` 脚本。该脚本通过 HTTP GET 或 HTTP POST 调用，并且对每种方法表现出不同的行为。当通过 `GET` 调用时，它生成一个空白表单。当通过 `POST` 调用时，它将新的项目表单值存储在 SimpleDB 和 S3 中。
