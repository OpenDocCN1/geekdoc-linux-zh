# Samba

`Samba` 为 UNIX 增加了 Windows 网络支持。虽然 NFS 是 UNIX 之间共享文件最流行的协议，但 SMB 是 Windows 之间共享文件最流行的协议。`Samba` 软件包允许 UNIX 系统与 Windows 系统交互。

关键点：`Samba` 软件包包含：

- `smbd`：为其他机器从 UNIX 读取文件的 Samba 服务，提供 NetBIOS 支持。逻辑上，SMB 协议层层位于 NetBIOS 之上，而 NetBIOS 又在 TCP/IP 之上，挂载到允许 UNIX 隐式连接到另一机器的挂载点。可以像访问本地机器一样访问文件。
- `smbClient`: 允许显式通过 SMB 获取访问。这是一个类似于 FTP 工具的命令行工具，允许复制文件。与 samba 不同，如果文件是本地的，则无法访问。
- `smb.conf`: Samba 的配置文件。来自 Hacking-Lexicon

`http://www.ldp.org/LDP/Linux-Dictionary/html/index`
