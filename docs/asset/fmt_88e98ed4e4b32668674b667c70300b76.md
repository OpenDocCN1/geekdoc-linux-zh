熟悉的指令`invokevirtual`从常量池中提取`println`函数的信息，然后用该函数。我们已经知道，标准定义了许多版本的`println()`函数，每个都处理的数据类型各不相同。本例调用的 `println()`函数，肯定是专门用来处理`string`类型数据的那个版本。

此并不矛盾：只有在`System.out` 初始化为实例的时候，才能调用 `println()` 方法。

## 54.6 调用函数 `beep()` (蜂鸣器)

这是一个最简单的调用（调用无参数的两个函数），其功能就能发出蜂鸣声`beep`:

```java
public static void main(String[] args)
{
    java.awt.Toolkit.getDefaultToolkit().beep();
}
```

`public static void main(java.lang.String[])`
    `flags: ACC_PUBLIC, ACC_STATIC`

Code:
`stack=1, locals=1, args_size=1`

    0: `invokestatic #2` // Method
    `java/awt/Toolkit.getDefaultToolkit():()V`
    `java/awt/Toolkit:`
    3: `invokevirtual #3` // Method
    `java/awt/Toolkit.beep():V`
    6: `return`

第一指令是偏移量为0的`invokestatic`指令，它调用了`java.awt.Toolkit.getDefaultToolkit()`函数。后者的返回值是`Toolkit` Class 实例的引用指针。偏移量为3的`invokevirtual`指令调用这个类的 `beep()`函数。

## 54.7 线性随机数生成器 (PRNG)

我们再来看`PRNG` (Pseudo Random Numbers Generator) 随机数器，其实我们已经在在本的第20章介绍过的C语言代码了。

```java
public class LCG
{
    public static int rand_state;
    public static void my_rand(int init)
    {
        rand_state=init;
    }
    public static int RNG_a=1664525;
    public static int RNG_c=1013904223;
    public int my_rand ()
    {
      rand_state=rand_state*RNG_a;
      rand_state=rand_state+RNG_c;
      return rand_state & 0x7fff;
    }
}
```

程序启动初始化了几个成员变量（Class Fields）。这是如何进行的呢？这就得借助`javap`查看该类的构造函数：

```java
static ();
flags: ACC_STATIC
stack=1, locals=0, args_size=0 // int 166425
  0: ldc #5 // Field rand_a:I
  2: putstatic #3 // Field rand_a:I
  5: ldc #6 // int 101904223
  7: putstatic #4 // Field rand_c:I
  10: return
```

上述指令展示了变量的初始化过程。变量`RNG_a`和`RNG_c`分别参数的第三和第四槽单元。`putstatic`函数将有关数值存放在相应的地址。

函数`my_rand(int)`将输入值保存在变量`rand_state`中：

```java
public void my_rand(int);
flags: ACC_PUBLIC
Code:
stack=1, locals=2, args_size=2
  0: iload_1
  2: putstatic #2 // Field rand_state:I
  4: return
```

`iload_1`指令提取输入变量，然后将其压入栈中。但是为什么在此处用`iload_1`而不是读取第0个参数的`iland_0`指令呢？由于该函数调用的类的变量，由于要用第0个参数传递`this`。以此类推，函数的第二个参数槽用于传递成员变量，同时是隐性参数`rand_state`，此后的`putstatic`指令将把栈的值存在第二个参数槽、完成指定任务。

我们来看看`my_rand()`函数：

```java
public int my_rand();
flags: ACC_PUBLIC
Code:
stack=2, locals=1, args_size=1
  0: getstatic #2 // Field rand_state:I
  3: getstatic #3 // Field rand_a:I
  6: imul
  7: putstatic #2 // Field rand_state:I
  10: getstatic #2 // Field rand_state:I
  13: getstatic #4 // Field RNG_c:I
  16: iadd
  17: putstatic #2 // Field rand_state:I
  20: getstatic #2 // Field rand_state:I
  23: sipush 32767
  26: iand
  27: ireturn
```

这段代码标识提取实例的成员变量、进行各种运算，再使用`putstatic`指令将新的`rand_state`的值。在偏移量为20时，`rand_state`的值被重新入（此前的`putstatic`指令从栈里掉了）。虽然表面看来效率低，但是`JVM`能够充分优化、足以弥补代码的缺陷。

## 54.8 字段

来看一个简单的例子：

```java
public class abs {
    public static int abs(int a) {
        if (a<0)
            return -a;
        return a;
    }
}
```

`static int abs(int);`
`flags: ACC_PUBLIC, ACC_STATIC`

Code:
`stack=1, locals=1, args_size=1`

  0: `load_0`
  1: `ifge 7`
  4: `load_0`
  5: `ineg`
  7: `load_0`
  8: `ireturn`

如果栈顶的值大于，`if`就会跳转到量量7的指令。特别注意的是`if`指令还会栈顶一个值，就不能比较。后面的`ine`是对负运算。

再看一个例子：

```java
public static int min (int a, int b) {
    if (a>b) {
        return b;
    }
    return a;
}
```

这个函数的字节码所示：

```java
public static int min(int, int);
flags: ACC_PUBLIC, ACC_STATIC
Code:
stack=2, locals=2, args_size=2
  0: iload_0
  1: iload_1
  2: if_icple 7
  5: iload_1
  6: return
  7: iload_0
```
