
## 选项

- `-d dev` 将输出到备用音频设备。如果未指定 `-d` 选项，请查阅 `AUDIODEV` 环境变量。否则，使用 `/dev/audio` 作为默认音频设备。

- `file` 按照顺序播放命令行上指定的命名的音频文件。如果存在文件名，则播放标准输入流（如果它不是 `TTY`）。它也必须包含一个音频文件名的短横线 (`-`)，以读取标准输入流而不是文件。如果你提供了相对路径名，请查阅 `AUDIOPATH` 环境变量。

- `-?` 打印命令行用法信息。

## Usage

请参阅 `largefile(5)` 了解 `audioplay` 在遇到大于或等于 2 Gbytes (31 字节) 的文件时的行为。

## 环境变量

`AUDIODEV` 当你未提供 `-d` 参数时，要写入的音频设备的全名。如果未设置 `AUDIODEV` 变量，则使用 `/dev/audio`。

`AUDIOPATH` 指定一个由冒号分隔的目录列表，用于搜索由相对路径名命名的音频文件。你可以在搜索路径中显式地指定当前目录 (`.`)。如果未设置 `AUDIOPATH` 变量，则仅搜索当前目录。

## audiorecord — 录音频文件

### 概要

```
/usr/bin/audiorecord [-af] [-v vol] [-b bal] [-m monvol]
[-p mic | line internal-cd] [-c channels] [-s rate]
[-e encoding] [-t time] [-i info] -d dev [file]
```

### Description

`audiorecord` 将音频数据从音频设备复制到命名的音频文件中（如果没有指定文件名，则复制到标准输出）。如果你未指定文件且标准输出是 `TTY`，则命令行上指定的音量、平衡、监听音量、端口和音频格式设置将生效，程序退出。

默认情况下，单声道音频数据以 8 kHz 录制并以 `ulaw` 格式编码。如果音频设备支持额外的配置，你可以使用 `-c`、`-s` 和 `-e` 选项来指定数据格式。输出文件开头有一个音频头，该头用于识别文件中编码的数据格式。

录制立即开始，并持续到收到 `SIGINT` 信号（例如 Control-C）。如果你指定了 `-t` 选项，`audiorecord` 将指定时间到后停止。

如果音频设备不可用（即另一个进程当前具有读取权限），`audiorecord` 将打印错误信息并立即退出。

### 选项

- `-a`

将音频数据附加到命名的音频文件末尾。音频设备必须支持现有文件的音频数据格式。

- `-f`

当你指定 `-f` 标志时，音频设备的采样率必须与原始文件录制时的采样率匹配。如果你也指定了 `-f` 标志，将忽略采样率差异并在标准错误上打印警告信息。

- `-v vol`

在录制开始将录制增益设置为指定值，并在 `audiorecord` 退出时重置为之前的水平。`vol` 参数是 0 到 100 之间的整数值。如果你未指定此参数，则将输入音量保持为任何进程最近设置的水平。

- `-b bal`

在录制开始将平衡设置为指定值，并在 `audiorecord` 退出时重置为之前的水平。`bal` 参数是 -100 到 100 之间的整数值。值 -100 表示左平衡，0 表示中间，100 表示右。如果你未指定此参数，则将输入平衡保持为任何进程最近设置的水平。

- `-m vol`

在录制开始将输入监听音量设置为指定值，并在 `audiorecord` 退出时将其重置为之前的水平。`volume` 参数是 0 到 100 之间的整数值。非零值允许直接连接的输入源在录制过程中在输出扬声器上被听到。如果你未指定此参数，则将监听音量保持为进程最近设置的水平。

- `-p mic | line | internal-cd`

选择麦克风 (`mic`)、线路 (`line`) 或内部 CD (`internal-cd`) 作为输出音频信号的源。如果你未指定此参数，输入端口将保持不变。某些系统不支持所有可能的输入端口。如果命名的端口不存在，则忽略此选项。

- `-c channels`

指定音频通道数（1 或 2）。你可以指定整数或字符串 `mono`（单声道）或 `stereo`（立体声）。默认值为 `mono`。

- `-s rate`

指定采样率，单位为每秒采样数。如果数字后面跟着字母 `k`，则乘以 1000（例如，`44.1k = 44100`）。默认采样率为 8 kHz。

- `-e encoding`

指定音频数据编码。此值可以是 `ulaw`、`alaw` 或 `linear`。默认编码为 `ulaw`。

- `-t time`

指定录制的最长时间。你可以指定时间为浮点值（表示秒数）或 `hh:mm:ss` 格式。

- `-i info`

设置头部信息字段。

- `-d dev`

指定备用音频设备。如果你未指定 `-d` 选项，请查阅 `AUDIODEV` 环境变量。否则，使用 `/dev/audio` 作为默认音频设备。

- `file` 按照顺序播放命令行指定的命名的音频文件。如果存在文件名，则播放标准输入流（如果它不是 `TTY`）。它也必须包含一个音频文件名的短横线 (`-`)，以读取标准输入流而不是文件。如果你提供了相对路径名，请查阅 `AUDIOPATH` 环境变量。

- `-?` 打印命令行用法信息。
