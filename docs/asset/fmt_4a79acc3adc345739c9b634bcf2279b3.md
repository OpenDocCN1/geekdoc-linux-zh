# vipw — 编辑密码文件

# 概览

`/usr/ucb/vipw`

## 描述

`vipw` 在编辑 `passwd` 文件时会设置相应的锁，并在密码文件解锁后进行任何必要的处理。如果密码文件已经在编辑中，会提示你稍后再试。除非环境变量 `VISUAL` 或 `EDITOR` 指定了替代编辑器，否则将使用 `vi(1)` 编辑器。
`vipw` 对 `root` 的用户条目进行多次一致性检查，并不允许安装带有“损坏”的 `root` 条目的密码文件。。它还会检查 `/etc/shells` 文件以验证 `root` 的登录 `shell`。

# volcancel — 取消当前驱动器中不存在移除介质请求

# 概览

```
/usr/lib/vold/volcancel [-n][volume]
```

## 描述

`volcancel` 取消访问特定软磁盘或 CD-ROM 文件系统的请求。当包含文件系统的可移动介质不在驱动器中时，此命令非常有用。
使用路径 `/vol/rdsk/name_of_volume` 来指定卷。如果调用时未提供卷名，`volcancel` 将检查卷管理（Volume Management）是否正在运行。

## 选项

+   `-n` 显示别名到设备名称转换表。

## 示例

以下示例取消了访问未命名 CD-ROM 的请求。
`castle% /usr/lib/vold/volcancel vol/rdsk/unnamed_cdrom`

你可以使用 `volcancel` 命令检查卷管理是否正在运行。在以下示例中，卷管理正在运行。
`castle% /usr/lib/vold/volcancel`
`castle%`
