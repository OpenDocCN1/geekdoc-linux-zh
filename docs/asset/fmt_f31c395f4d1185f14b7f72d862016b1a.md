# octave

用于数值计算的 GNU 语言。`Octave` 是一种与 `R` 语言兼容的高级语言，主要用于数值计算。它为线性和非线性问题提供了良好的命令行接口。`Octave` 使用了一些优秀的稳健数值库，如 `dass`, `deiss`, `ffpack`, `lapack`, `onpack`, `slatec`。

# octave

用于数值计算的 GNU 语言。`Octave` 是一种与 `R` 语言兼容的高级语言，主要用于数值计算。它为线性和非线性问题提供了良好的命令行接口。这是一个过渡包。为了从旧版本的 `octave`（直到 `2.0-1`）平滑过渡到新的 `octave2.0`，需要此包。新的 `octave2.0` 可以与后续开发的包共存。一旦安装了 `octave2.0`，就可以删除此包。源自 Debian 3.00pt `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

# octave-ci

用于 GNU `Octave` 语言的贡献函数。`octave-ci` 包为 GNU `Octave`（一种与 `R` 兼容的高级语言）提供了近数百个函数。此包中的文件按以下目录分组：`defele`, `neurf`, `itsum`, `tifeun` 和 `misc`。此包中的其他功能已在 `2.13.92` 版本集成到 `Octave` 中。源自 Debian 3.00pt `http://www.t.org/LDP/Linux-Dictionary/html/index.html`

# octave-spk

GNU `Octave` 封装位图。`octave-spk` 包通过一组 `.m` 函数提供了一个创建封装位图 (`.eps`) 图表的工具包。大多数 2D 科学图形都是通过此生成的。生成的 `.eps` 文件非常小，可以导入到其他文档中而不会丢失质量。源自 Debian 3.00pt `http://www.t.org/LDP/Linux-Dictionary/html/index.html`

# octave-forge

GNU 的贡献函数。`octave-forge` 项目包含了 300 多个未包含主发行版中的 GNU `Octave` 贡献函数。这些函数根据以下子目录分组：`audio`, `comm`, `control`, `general`, `geometry`, `indent`, `image-linear-algebra`, `optim`, `path`, `plot`, `set`, `sparse`, `specf`, `special-matrix`, `splines`, `statistics`, `strings`, `time`。主 `octave` 语言在接受新函数和变更方面保守，而 `octave-forge` 非常开放。因此，请准备好应对-forge 函数中质量较低的代码和变化更快的接口。

## Linux 字典

`octave-forge` 项目托管于 `http://sourceforge.net/projects/octave/`。Debian `octave-forge` 包替换了（并扩展了）早期的 `octave-matcomp` 包。来自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

## octave-matcomp

用于 `octave-forge` 的空分区。`octave-forge` 包替换了 `octave-matcomp` 包。这个空 `octave-matcomp` 包通过显式依赖关系强制安装（新的）`octave-forge` 包。一旦两个包都已安装，就可以安全地删除或卸载。来自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

## octave-sp

用于 GNU `Octave` 的半正定规划函数。`octave-sp` 包提供了半正定规划的函数。它可以用于求解非线性、凸优化问题。要查看功能概览，请在 `Octave` 内部使用 `'demo'`。来自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

## odbcinst

访问 odbc ini 文件的支持库和帮助程序。此包包含了来自 unixdbc 的 `libodbc.so`，该库使用 ODBC 驱动程序从 `/etc/odbc` 和 `/odbc.ini` 读取其配置设置。将其作为一个独立包提供是有用的，这样无论应用程序是使用 odbc 还是 unixdbc 构建的，所有 ODBC 驱动程序都使用一致的库。此包还包含了 odbc 辅助工具，它允许 ODBC 驱动程序安装自己的驱动程序，以及描述单个 ODBC 驱动程序所支持功能的驱动设置插件。

组件：

- `libodbc.so` (ODBC 驱动程序助手)

- `libodbccfg5.so` (基于少数资源的 GUI 配置...)
