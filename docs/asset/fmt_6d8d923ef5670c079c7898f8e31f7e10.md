# lphoto

lphoto 是一个类似于 blackbox 的高度可配置窗口管理器，它源自 blackbox，并增强了对多桌面样式、工具栏和图标的支持。它支持 Gnome 和 KDE。它包含以下照片功能：

- 数码照片
- 专辑管理
- 网页展示
- 幻灯片
- 旋转
- 包含照片功能

来自 Mandrake 9 `http://www.tldp.org/Dictionary/index.html`

# fluxbox

轻量级窗口管理器（Fast Light Manager）尝试结合各种管理器的优点。它源自 blackbox，并增强了对多桌面、工具栏和图标的支持。它包含了 blackbox 的功能：

- 看起来像 Windows。
- 样式受来自 wm2 的影响。
- 带有图标的弹出菜单。
- 真正小巧且快速。
- 尽可能减少屏幕空间。边框和磁贴设计得非常薄。最大化窗口仅留有 15 像素！
- 窗口宽度和高度的独立边界。
- 多桌面，通过相同的菜单控制。

来自 Debian 3.0r0 `http://www.tldp.org/Dictionary/index.html`

# floatag

来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

# flying

pool/台球/台球/曲球等 X 游戏。特别是台球类变体非常好玩且漂亮。唯一的缺点是它只能在 8 位色深的屏幕（256 色）上运行；深度超过 8 位的显示器无法工作。你必须切换到 XFree4.0 并可以使用用的 8 位覆盖层。原作者放弃了游戏，因此色彩深度问题短期内不太可能解决。如果你能修复游戏，请发送补丁。来自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`
