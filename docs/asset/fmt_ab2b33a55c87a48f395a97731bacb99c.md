
# 染色体

每个细胞中携带个体遗传物质——脱氧核糖核酸（`DNA`）的普通成分之一。染色体存在于所有具有细胞核的生物体（真核生物）中，并位于细胞核内。每条染色体包含一个极长的单一`DNA`分子，该分子通过各种蛋白质包装成紧密的结构域。每个精子或卵细胞（动物）以及每个花粉粒或胚珠（植物）携带一套完整的染色体，即该生物的单倍体（n）基因组，包含该生物特有的完整基因集合。植物界和动物界中进行有性生殖的生物通过两个单倍体生殖细胞的融合开始其发育，因此是二倍体（2n），其每个体细胞中都有两套染色体。这两套染色体携带每个细胞中几乎所有数千个基因，除了线粒体（在动物中）和少数植物叶绿体中的极少量基因外。参见：`DEOXYRIBONUCLEIC ACID (DNA)`（脱氧核糖核酸（`DNA`））；`GENE`（基因）。

在细胞周期中，染色体的形态和致密程度会发生变化。在间期（细胞周期的主要阶段），染色体在光学显微镜下不可见，因为尽管它们非常长，但极其细。然而，在细胞分裂（有丝分裂或减数分裂）期间，染色体浓缩成较短且较粗的结构，可以用光学显微镜观察到。此时，它们表现为配对的棒状结构，具有明确的末端，称为四体，直到它们在着丝粒（`centromere`）处保持连接，直到细胞分裂的后期开始时分离。参见：`CELL CYCLE`（细胞周期）；`MEIOSIS`（减数分裂）；`MITOSIS`（有丝分裂）。

染色体通过长度和着丝粒的位置来区分。它们可以是中着丝粒型（着丝粒位于染色体中部）、近端着丝粒型（着丝粒靠近一端）或端着丝粒型（着丝粒位于末端或端粒处）。因此，着丝粒通常位于两个染色体臂之间，这些臂包含基因及其调控区域，以及其他功能未知的`DNA`序列。在许多物种中，碱基组成区域差异以及`DNA`复制时间差异作为基础，用于特殊的染色技术，使每个臂上可见一组独特的条带，这些条带可用于识别染色体。

## 致密化

人类或其他哺乳动物细胞中的每个核含有约60亿个`DNA`碱基对，如果展开，将形成一条长约6英尺（2米）的长丝。这些`DNA`必须被包装进染色体中，而细胞核比针尖还小（图1）。每条染色体包含一段单一长度的`DNA`，构成生物遗传材料的特定部分。微小的`DNA`片段，长约140个碱基对，含有酸性磷酸基团，分别缠绕在一个八聚体上，该八聚体由四种基本组蛋白`H2a`、`H2b`、`H3`和`H4`分子中的每种两个分子组成。这种排列产生称为核小体的小结构，并使`DNA`链致密化十倍。通过结合组蛋白`H1`和几种非组蛋白蛋白，进一步实现致密化，形成超螺旋结构，其中染色体在间期细胞核中致密化约1600倍，在中期和后期致密化约8000倍，此时遗传物质必须完全致密化以传输到两个子细胞。在最大致密化点，人类染色体的长度可以在约2到10微米之间，即小于0.0004英寸。参见：`EUCHROMATIN`（常染色质）。

### 结构

端粒封闭每条染色体的末端，并结合同一细胞中存在的特定蛋白质，以保护其不被酶（外切核酸酶）消化。最重要的是，端粒允许 `DNA` 复制一直进行到染色体的末端，从而确保其稳定性。端粒还参与染色体末端与核膜的附着以及减数分裂过程中同源染色体的配对。除果蝇（`Drosophila`）外，几乎所有真核生物中端粒 `DNA` 的结构都非常相似。`DNA` 的一条链富含鸟嘌呤，朝向染色体末端；另一条链富含胞嘧啶，朝向着丝粒。在大多数生物中，端粒由非常短的 `DNA` 重复序列的多个拷贝组成。

着丝粒负责在细胞分裂期间每对染色体的正确分离。在有丝分裂期间，每对染色体的两个副本以及减数分裂中每对同源染色体在着丝粒处连接在一起，直到后期（`anaphase`），此时它们分离并移向纺锤体极，从而分配到两个子细胞中。动粒是微管附着点，这些微管引导染色体向两极移动，它围绕着着丝粒组织。大多数物种中着丝粒的分子结构仍不清楚。构成着丝粒及其周围的重复 `DNA` 被称为异染色质，因为它在整个细胞周期中保持凝缩状态，因此染色强度极高。

每个物种中一条或多对染色体上有一个称为随体的区域，该区域染色效果不佳。该区域包含在核仁内转录核糖体 `RNA`（`rRNA`）的基因的多拷贝。活性 `rRNA` 基因的数量可能受到调节，如果生物体拥有的 `rRNA` 基因拷贝数过少，可能会发育异常并无法存活。参见 `核糖体`。

### 染色

使用吖啶橙（`quinacrine mustard`）染色可在染色体臂上产生一致、明亮和不那么明亮的荧光带（Q 带），这是由于 `CG`（胞嘧啶-鸟嘌呤）或 `AT`（腺嘌呤-胸腺嘧啶）碱基对相对含量的差异造成的。每条染色体独特的 Q 带模式使得能够识别人类基因组中的每一条染色体。吖啶荧光还可以揭示同源染色体对两个成员之间异染色质数量或类型的差异，这称为异型性或多态性。这种差异可用于识别特定染色体的亲本来源，例如 21 三体综合征个体中的额外染色体。另外两种方法涉及在吉姆萨（`Giemsa`）染色前对染色体进行各种处理。吉姆萨染色或 G 带模式本质上与 Q 带模式相同，而反转吉姆萨染色或 R 带模式则是 Q 带或 G 带模式的相反或互补形式。在人类、大多数其他哺乳动物和鸟类（仅巨大染色体）中，Q、G-和 R-带模式非常独特，因此可以单独识别每一对染色体，从而可以构建核型，即来自单个细胞的染色体对的有序排列（图 2）。染色体根据带模式进行识别，染色体对按某种顺序排列和编号，通常基于长度。在人类核型中，常染色体编号从 1 到 22，性染色体称为 X 和 Y。染色体的短臂称为 `p` 臂，长臂称为 `q` 臂；每个臂上的每个带都被赋予一个数字。

### 印记

无论染色体是由父亲还是母亲传递，它都携带相同的一套基因，并且这些基因大多在功能上是相同的。然而，少数哺乳动物基因的功能取决于它们是由卵子还是精子传递的。这种现象被称为印记。这似乎是由精子或卵细胞中某些基因的失活引起的，可能是通过被印记基因调节区（启动子）内胞嘧啶残基的甲基化实现的。由于印记作用，哺乳动物胚胎的正常发育需要母源和父源两组染色体同时存在。父系半合子（`paternohemigenic`），即由两套母源染色体形成正常个体，在哺乳动物中因此是不可能的。

### 性染色体

在大多数哺乳动物中，个体的性别由是否存在 Y 染色体决定，因为 Y 染色体携带男性决定基因 `SRY`。因此，XX 和罕见的 XO 个体是雌性，而 XY 和不常见的 XXY 个体是雄性。相比之下，果蝇的性别取决于常染色体（非性染色体）和 X 染色体的平衡。因此，在二倍体中，XX 和罕见的 XXXY 果蝇是雌性，而 XY 和罕见的 XO 果蝇是雄性。在哺乳动物和果蝇中，雄性都是异配性别，产生包含 X 或 Y 染色体的配子，而雌性都是同配性别，只产生包含 X 的配子。然而，在鸟类和蝴蝶中，雌性是异配性别，雄性是同配性别。其他性别决定机制也很常见：在某些物种中，性别由单个基因甚至环境因素（如某些海龟和鳄鱼的温度）决定，而不是由染色体介导的机制决定；另有一些物种（如 `Bonellia`，一种海洋蠕虫）的性别由附近是否存在雌性决定。

已有超过 900 个基因位点被映射到人类 X 染色体上。如果雌性哺乳动物细胞中两条 X 染色体上的基因完全表达，那么只有一条 X 染色体的男性细胞将只表现出女性一半的基因产物。然而，剂量补偿得以实现，因为只有一条 X 染色体上的基因被表达，而任何额外的 X 染色体上的基因都被失活。这种 X 失活随机发生在胚胎发育的早期阶段，并原封不动地传递给每个子细胞。因此，哺乳动物雌性是两种细胞类型的嵌合体：那些带有活性母源 X 的细胞和那些带有活性父源 X 的细胞。除哺乳动物外的其他物种不表现出这种针对性连锁基因的剂量补偿机制，有些则完全不表现出这种机制。
