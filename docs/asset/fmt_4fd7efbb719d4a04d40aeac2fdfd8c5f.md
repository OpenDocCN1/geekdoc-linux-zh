## Magic Wormhole

一个 Python 脚本，创建一次性加密通道，通过易于发音的代码识别，在互联网上的计算机之间传输文件。

`https://github.com/warner/magic-wormhole`

## uBlock Origin

`uBlock Origin` 浏览器扩展是一个广告拦截器，它还拦截跟踪服务器、恶意软件域等。它可在所有主流网络浏览器的应用商店中获取。

`https://github.com/gorhill/uBlock/`

## QuiterSS

`QuitterSS` 具备你期望从新闻阅读器中获得的所有功能。它可以拉取 RSS 和 Atom 源，为每个项目应用标签，并且提供大量自定义选项。

`https://quiteross.org`

## Vocal

功能丰富的播客抓取器 `Vocal` 可以订阅并即时流式传输播客，或下载它们以便离线收听。它与流行的桌面环境集成，并具有智能库管理功能。

`https://vocalproject.net`

## uFTPd

`uftp` 附带对大多数用户都有效的默认设置。它专为需要简单 FTP 服务器但不太在意安全性的家庭用户和开发人员设计。

`https://trogothib.com/projects/uftpd`

## 安全工具

确保不法分子无法触及您的系统和文件。

### ZULUCRYPT

虽然您可以使用用户帐户和文件权限来控制对计算机上数据的访问权限，但这些措施不足以防止蓄谋已久的入侵者获取您私人文件的访问权限。唯一可靠的保护个人数据不外泄的机制是对其进行加密。诚然，处理加密数据是一个复杂的过程，但它能在很大程度上增强您的安全性并保护您的数据。

`ZuluCrypt` 是一款图形化加密工具，拥有直观且易于操作的界面。使用该程序，您可以在文件、分区甚至 USB 磁盘内创建加密磁盘。它还可以使用 GPG 对单个文件进行加密。`ZuluCrypt` 可以执行块设备加密，这意味着它可以加密写入特定块设备的所有内容。该块设备可以是整个磁盘、分区，甚至是作为环回设备挂载的文件。在块设备加密模式下，用户在块设备上创建文件系统，加密层会在将数据写入实际底层块设备之前透明地对数据进行加密。在加密状态下，存储区域仅显示为一团巨大的随机数据，甚至不会透露其目录结构。所有这些功能及其他更多功能均可通过优秀的用户界面访问。`http://mhgomchangu.github.io/zuluCrypt`

### GUFW

`Gufw` 是 `UFW`（简单防火墙）的图形前端，它是 `iptables` 最易用的前端之一。该工具具有简单的界面，并包含预定义的配置文件以调节入站和出站流量。您可以根据需求修改这些配置文件的入站和出站策略。您还可以使用 `Gufw` 为特定应用程序和服务定义允许流量的规则。`http://gufw.org`

![](img/7a0a282248f9658f0c87e55744c797b6_175_0.png)

切换到“报告”选项卡以获取实时网络流量报告。

### BITWARDEN

`BitWarden` 密码管理器采用端到端加密，并使用 AES 256 位以及 PBKDF2 来保护您的数据。它之所以费力不讨好（指流程较复杂），是因为与其同类产品不同，它将加密后的密码存储在远程 Microsoft Azure 云端。该应用程序还可以从 24 多个来源导入密码。`https://bitwarden.com`

### OQUERY

您可以使用 `oquery` CLI 工具监控网络，该工具允许您像查询数据库一样查询您的设备。您可以使用该工具检查登录用户、监控防火墙、识别过时的内核并监控已加载的内核模块和正在运行的进程。`https://oquery.io`

### STEGOSUITE

隐写术是一种将数据隐藏在另一个看似无害的消息或图像中的艺术。实现这一技术的最常见机制是通过将常规计算机文件中未使用的数据替换为在查看原始数据时不可见的信息位来完成的。隐写术主要用于补充加密。

`Stegosuite` 是一款图形化工具，可以将文本消息以及任何类型的文件隐藏在图像中。启动该工具，选择一张图像，指向您想要隐藏在其中的文件，并输入一个秘密密钥将其“烧录”到图像中。要从图像中获取秘密文件，再次加载该图像，并使用“提取”按钮和秘密密钥从图像中提取隐藏的文件和消息。`https://stegosuite.org`

### MTR

`MTR` 是一个简单的 CLI 网络诊断工具，它结合了 `traceroute` 和 `ping` 工具的功能。因此，除了数据包路径外，它还显示大量其他相关信息。`www.bitwizard.nl/mtr`

### AIDE

您可以使用 `AIDE` 通过检查文件的完整性来帮助发现入侵。它会将其属性（如权限）与初始运行时创建的基准数据库进行比对。`http://aide.sourceforge.net`

### NIKTO2

一个 CLI Web 服务器扫描器，用于寻找潜在问题，如服务器配置错误、版本过时以及特定版本的问题。它还可以针对安全漏洞执行自动化测试。`https://cirt.net/Nikto2`

### JOHN THE RIPPER

一款密码破解工具。`John The Ripper` 用于暴露薄弱的 Unix 密码。它是一个 CLI 工具，但还有一个名为 `Johny` 的图形界面，可以展示其各种命令行选项。`www.openwall.com/john`

### MALTRAIL

`MalTrail` 是一个恶意流量检测系统，它使用可公开访问的黑名单、用户自定义的列表以及其他机制来检测和记录任何恶意流量。`https://github.com/stamparm/maltrail`

## 开发工具

使用这组功能强大的实用工具让您的编码生活更轻松。

### ATOM

Atom 自称为可修改的文本编辑器。由 GitHub 开发，该工具内置了包管理器，允许用户在其中搜索和安装插件。默认情况下，该实用程序附带约 80 个插件。其中一个更有趣的功能是查找和替换功能，它可以在您输入时修改多个文件中的文本。

Atom 也可以用作 IDE，其亮点之一是智能自动完成功能。还有一个括号匹配功能，它会高亮显示与光标下括号对应的闭合括号的行号。您还可以定义自定义按键绑定，并通过添加诸如小地图和特定语法片段库等项目的包来增加更多功能。`https://atom.io`

### BPYTHON

一个在终端窗口内提供现代 IDE 般特性的 Python shell。您可以使用默认设置开始使用，然后通过编辑其配置文件进行自定义。该 shell 支持代码自动完成，还会显示预期的参数列表。它会在您输入时突出显示语法，而 Rewind 功能会检查内存中保留的完整代码。

`https://bpython-interpreter.org`

![](img/7a0a282248f9658f0c87e55744c797b6_176_0.png)

BPython 允许您将会话保存到文件，甚至将其发送到 pastebin。

### ETHERPAD

协作是任何项目的关键。Etherpad 文本编辑器允许用户实时协作编写文本。它在 Web 浏览器中运行，并允许参与者通过基于文本的聊天进行互动。它功能丰富，您可以在其网站上试用。`http://etherpad.org`

### VIRT-MANAGER

Virtual Machine Manager（虚拟机管理器）是创建基于 KVM 的虚拟机的开源图形前端。它使用 `qemu-kvm` 管理程序，这是 `qemu` 机器模拟器的一种版本，并包含一个 VNC 和 SPICE 客户端，可为运行中的虚拟机显示图形控制台。`https://virt-manager.org`

### TURKEY APPLIANCES

在服务器上安装网络可访问的软件或 Web 应用程序可能是一项艰巨的任务，因为它们需要大量的基础架构软件，这可能花费您数小时来组装。从数据库服务器到基础库，在部署网络应用程序之前，您需要花费相当长的时间来组装一个功能完备的 Web 服务器。
