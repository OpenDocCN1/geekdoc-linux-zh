# vgrind — 格式化程序列表

## 摘要

```
/usr/bin/vgrind [-2fntvw] [-d defs-file] [-h header] [-language] [-sn] [-opagelist] [-Pprinter] [-Output-device] filename...
```

## 描述

`vgrind` 使用 `troff(1)` 对文件名参数指定的程序源进行格式化。注释使用*斜体*，关键字使用**粗体**，并且当遇到每个函数时，其名称会列在页边距。

`vgrind` 以两种基本模式运行：过滤模式或普通模式。在过滤模式下，`vgrind` 的作用类似于 `tbl(1)` 的过滤器。标准输入直接传递到标准输出，除非被以下类 `troff` 宏包围：

- `+VS` 开始处理。
- `+VE` 结束处理。

这些行按照上述描述进行格式化。此过滤器的输出可以传递给 `troff` 输出。不需要与 `eqn(1)` 或 `tbl(1)` 有特定的顺序。

在普通模式下，`vgrind` 接受输入文件名，进行处理，并将其传递给 `troff` 输出。如果你未指定文件名或将其作为参数指定，`vgrind` 将从标准输入读取（如果指定 `-f` 则为默认）。

在两种模式下，`vgrind` 都不转换任何以小数点开头的行。

### 缺陷

`vgrind` 假设遵循某种特定的编程风格。

- C：在行中仅用空格、Tab 或星号跟在函数名后。括号内的参数也必须在同一行。
- FORTRAN：将函数名与关键字 `function` 或 `subroutine` 放在同一行。
- MLisp：不要将函数名与之前的 `defun` 放在同一行。
- Model：将函数名与关键字 `beginproc` 放在同一行。
- Pascal：将函数名与关键字 `function` 或 `procedure` 放在同一行。

`tmac.vgrind` 中定义的宏与其他宏包无法良好地共存，导致过滤模式难以有效使用。`vgrind` 无法正确处理 `csh(1)` 脚本中的某些特殊字符。

`tmac.vgrind` 的格式化固定了页面高度以及双栏模式下使用的宽度，这实际上使得对于标准美国 8.5 比 11 英寸以外的纸张尺寸，双栏输出变得毫无用。对于其他纸张尺寸，你需要编辑 `tmac.vgrind` 中的尺寸值。更好的解决方案是创建一个专门用于横向输出和记录尺寸信息的 `troff` 输出设备规范。

## 选项

带参数的选项语法非常重要。某些选项在选项名和参数之间需要空格，而那些不需要空格的选项则不容忍空格。

- `-2` 生成双栏输出。将默认字体大小改为 8（如你指定的 `-s8` 选项）。通过向格式化器提供 `-L` 标志以便横向模式输出，并相应更改页面高度和宽度。
- `-d defs-file` 指定替代语言定义文件（默认是 `/usr/lib/vgrinds`）。
- `-f` 强制模式。
- `-h header` 指定出现在每个输出页中间的页眉。
- `-language` 指定要使用的语言。目前知的语言有：
  - `-lsh` Bourne shell
  - `-llc` C（默认）
  - `-llc` C++
  - `-lcsh` C shell
  - `-lmml` Emacs MLISP
  - `-lmf` FORTRAN
  - `-lI` Icon
  - `-li` ISP
  - `-ld` LDL
  - `-lm` Model
  - `-lp` Pascal
  - `-lr` Rat
- `-n` 不使用粗体。
- `-sn` 指定输出时的字体大小（与 `troff` size 参数完全相同）。
- `-W` 将 Tab 视为四个空格而不是默认的。
- `-x` 输出索引格式。当你运行 `vgrind` 且目录下有一个名为 `index` 的文件时，会生成该索引文件。你可以通过指定 `-x index-file` 来运行函数定义。
- `-opagelist` 仅打印逗号分隔的页码列表和范围索引。范围 N-M 表示从 N 页到 M 页，初始 N 表示从开始，最后的 N 表示从末尾。
- `-Pprinter` 将输出发送到命名的打印机。
- `-t` 将格式化文本发送到标准输出。与 `troff` 中的相同选项类似。
- `-Toutput-device` 为指定的输出设备（`output-device`）进行格式化输出。
- `-W` 强制输出到（宽）打印机而不是（窄）打印机。

### 操作数

- `filename` `vgrind` 处理的程序源名称。使用横杠 (`-`) 指定标准输入。

## 环境变量

在普通模式下，`vgrind` 将其中间输出传递给由 `TROFF` 变量指定的文本格式化器；如果环境中没有定义 `TROFF` 变量，则传递给 `troff`。

## 文件

- `index` 创建索引的源文件。
- `/usr/lib/vgrinddefs` 语言描述。
- `/usr/lib/font` 处理器。
- `/usr/share/lib/tmac/tmac.vgrind` 宏包。
