
# Modem

一种将计算机产生的数字信息转换为可以通过电话线发送的模拟信号的设备。源自远程教育术语 `http://www.tmdp.org/LDP/Linux-Dictionary/html/index.html`

`调制解调` (`Modulate Demodulate`) 的缩写。硬件通过将数字信号转换为模拟信号允许计算机通过所有电话线相互连接。源自远程教育术语
