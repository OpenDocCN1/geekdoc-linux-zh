## 量纲分析

量纲分析决定了所有量纲公式的结构。测量的单位。

在物理科学和工程中，许多问题在找到复杂的理论解决方案之前需要解决。然而，通过进行量纲分析将变量归类为无量纲组，所涉及的相互关联变量的数量会减少。

在为力学或电学等科学分支定义单位制时，会将某些量选为基本量，另选一些。选择取决于维持标准的依据。在力学中，基本单位通常选择为长度、质量和时间。

在研究复杂现象时，量纲组的优势包括：

- 1. 每个量纲组的“变量”数量的大幅减少减少了几个物理变量（这些变量可以被视为单个单位），从而减少了所需的实验次数以及时间，并澄清了实验数据。
- 2. 预测过程中某个单个变量变化引起的影响（这可能通过通过确定这些参数变化的影响来改变未知参数，这可能是可能的）可能需要非常谨慎地进行；
- 3. 使结果独立于所使用的单位制。

事实证明，每一个满足绝对负量值条件的次级量都可以表示为初级量幂的表达式。这种表达式就是所推导的次级量的量纲公式。

量纲分析技术有几种应用。直观上显而易见，当方程量纲相同时，方程的正确性取决于两侧具有相同的量纲。例如，方程`$10 = m/x$`是意义的。这避免了复杂的计算。当然，一个方程可以无缝地或通过使用纯数值因子使其正确。

- 4. 通过可以预测结果的推广方法，简化模型系统结果的缩放。
- 5. 从无量纲组的值推导出过程中特性的重要性；例如，组中的雷诺数表明，相关参数对通过体流（“惯性”）效应传输将变得不那么重要，因为雷诺数代表惯性力与粘性力之比。

> G.I. Grahame, 雷诺数。

量纲分析在推导未知数的应用取决于相似性概念。无论使用什么基本量纲单位，每个关系都保持真实。为了形成一个物理变量组`$x_1, x_2...$`，使其仅存在一种组合，则`$x_1...x_2...x_n = 0$`。其中这些量的量纲公式用具有`$m$`个常数的`$m$`个量纲组表示。

维度（长度、质量、时间）可以是量性质的指示。具有相同维度的量可以用相同的单位表示。例如，尽管速度可以用多种单位测量：英尺/秒或米/秒，但所有单位都使用长度与单位时间的比值；因此速度的量纲是长度与T的比，通常表示为`$LT$`。

```
F(x1, x2, ... xn) = 0
```

这被称为巴金汉π定理。它最初由E. Buckingham证明。该理论的主要用途是推导单位关系。该程序在水力学和航空工程中特别有用；可以从小比例模型中非常有见地地推断出流体的行为。每个模型的成本按其在可能模型中的值比例减少。参见维度（DIMENSION）。

化学方程可以通过涉及物理量的过程通过量纲分析进行测试，以评估方程两侧相同的维度。参见量纲分析；测量。

量纲公式还为次级量的定义提供了方便的符号，并有助于在不同单位之间进行转换。
