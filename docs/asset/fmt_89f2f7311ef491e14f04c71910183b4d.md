
现在操作在交换机之间以包交换数据的形式流动，通过一个独立于语音或数字通信通道的连接进行。这被称为带外。具体而言，两个交换系统之间的通道被称为干线（trunk）。一组交换机携带若干通道，其组合信号数据以 `56 kbps` 的速率作为公共信道传输。

这种技术被称为公共信道接口（common-channel interfacing, `cci`）。

# 电话系统结构

电话的传输设施（或外线）。电话系统或网络由一个或多个传输部分组成，称为通道或电路，这些部分经过专门设计和建造，在两个或多个点之间创建类型的电子信息信号。交换系统和传输设施是这些传输路径的组件。模拟或数字格式的语音、数据和视频信号传输。

1976年，第一个数字系统在美国部署，基于名为时分多址（`TDMA`）或码分多址（`CDMA`）的技术，提供的速率从 `9.6` 到 `20 kbps` 不等。参阅 分配规范（RADIO ALLOCATION SPECIFICATIONS）；速率通信（SPEED COMMUNICATION）。

公共信道信号的一个主要优势是数字交换机能够以最经济的方式满足需求。参阅 电话（TELEPHONE）。

同轴电缆具有宽带宽并可以在高频率工作。它们用于长途电话传输和电视。电缆由套管组成，核心是内导体，它保持在由聚乙烯绝缘的圆柱形铜外导体内。这些电缆通过金属套圈压在套管末端并进行拉伸进行屏蔽。系统用防潮层进行密封。参阅 同轴（COAXIAL）。

# 远摄

一种专门设计的摄影镜头，旨在通过较短的焦距提供远处物体的大型图像。远摄通常由一个正透镜和一个负透镜组成，两者之间隔着相当距离。相机（光学）。[M.JH.]

诞生了提供通用多厂商标准的愿望。另一个标准是开放系统连接（`OSI`）模型，它使用了国际标准组织（`ISO`）的标准。`OSI` 模型包含几个层，具有定义良好的接口，以确保不同厂商软件和硬件之间的兼容性。它被广泛认为在其实体中具有标准，提供了一个被广泛模拟的模型。数据通信；数字；电子；通信。[D-S.C.]

# 远程处理

通过在电信网上发送数据在计算机设备之间交换信息。远程处理已从批处理演变为紧密耦合网络。

对于任何形式的数据传输，都存在区别：第一是数字与模拟通信的区别。数字信号具有固定数量的离散状态；模拟信号具有连续的值范围。计算机使用双位系统在模拟通信网络上传输数字信号。这是通过使用调制解调器（调制em）来实现的。

基带（无论是模拟还是数字）都以其原始频率传输。宽带通信使用特定的频段来携带所需信息而不产生干扰。使用频复用技术将多个信息通道复用到一个通信链路中。语音级电话设计用于响应 `300` 到 `3400 Hz` 之间的频率。为了响应更宽的范围，可以将多个通信堆叠在 `4000 Hz` 的频率中。调制；复用。

计算机通信的快速增长以及数字语音服务的发展，导致了不仅仅是文本的革命性信息技术。使用中速度计算机通信的集成业务数字网络（`ISDN`）适用于许多社区。异步传输模式（`ATM`）整合了视频、语音和数据，越来越多地用于远程传输，并正在扩展到桌面。集成业务网络（`ISDN`）；电视；终端到计算机通信和计算机到计算机通信。在终端到计算机通信中，少数服务器作为许多廉价的远程输入/输出设备的集中枢纽。共享打印机和计算机上的终端是常见的例子。电信。

微型计算机的快速增长以及将处理分配到计算机间通信的经济效益正在增加。这最常见的例子是一个连接多台计算机的网络，每台计算机都有独立的计算资源，并被网络识别为自主对等节点。分布式系统（计算机）；微型计算机。

计算机网络范围从几十个用户的局域网（`LAN`）到跨越全球的广域网（`WAN`）。所有这些网络具有相互不同的特征：信号技术、传输介质、拓扑结构和接入。计算机网络；广域网。

# 望远镜

用于收集或测量来自远处物体电磁辐射的仪器。望远镜通过增加微光和寻找细节来克服眼睛的限制。此外，当使用适当时，它可以看到肉眼可见的光。光的波长会对望远镜的性能产生影响。

电磁辐射；光。

地球大气影响望远镜的效果。最明显的影响是图像闪烁，通常被称为抖动。这干扰了图像生成并降低了图像分辨率的质量。在观测站最好的夜晚，恒星会被模糊为 `0.25` 角秒直径；在普通夜晚，圆盘在 `1` 到 `2` 角秒之间变化。

由于来自太阳的电粒子流入，高层大气发出微光。大气光和星光的结合限制了望远镜观察物体的能力。一种解决方案是将望远镜放置在大气层之上。天文学中有三种光学系统：反射镜望远镜，其主要元件是透镜，通过反射聚焦光；折射镜望远镜，通过折射聚焦光；以及反射镜（透镜和反射镜的组合）。其中最著名的例子是卡塞格林相机。

天文学家使用大型望远镜观察宇宙。他们记录这些数据以供未来研究。现代天文学。

大多数天体的光由所有波长的辐射组成。这种光的特征可以通过光谱学提取。光谱学。

作为辐射收集器，望远镜可能是聚焦的或非聚焦的。聚焦望远镜用于能量为 X 射线和伽马（伽马射线、宇宙射线和无线电）的辐射。用于红外和紫外线的望远镜也类似。

## 摄像机

在西半球和日本，使用的是 `NTSC`（电视系统委员会），其中单幅图像（帧）被认为由 `525` 行组成，每行包含数百个元素。光值被发送到接收器，以便其重建图像。在每一行的结束处，图像是空白的，此时扫描束被指向下一行。在短时间的间隔期内，会传输同步信号，以保持接收端的扫描过程与发射端保持同步。为了充分利用视觉暂留，每帧都交替行进行扫描。这种技术被称为交错扫描。电视扫描标准。

用于传输同步视频和音频的频率分配给一个信道。在美国，视频载波频率比带下边缘高 `53.75 MHz`，音频载波频率比带上边缘低 `4.25 MHz`。

在美国，节目部分通过频率调制进行传输，其载波频率在图像上方 `4.5 MHz` 处。音频的最大频率偏离（带宽）为 `25 kHz`。频率调制。

在电视广播中，视频录像机不仅用于回放，还用于节目分发，以及后期编辑期间的节目存储。在后一种情况下，质量可能会比最初在摄像机或录像机馈端录制的质量显著降低。

电视节目有两种：直播和录制。然而，对于录制节目，代数并不是均匀的。图像质量受每代使用的摄像机和录像机的影响；录像机本身在每次通过都会增加噪声。为了减轻视频质量的下降，必须用数字技术取代模拟视频录像机。数字录像机的优点是不会通过重复录制而累积噪声。

数字系统也用于电视节目的全球交换，由于各个国家使用了许多不同的标准，因此需要标准转换。1981年采用了一种宽数字标准，结合了灵活性，以最大限度地提高不同系统使用设备之间的兼容性，并具有比任何国家复合系统更广泛的色彩和差分。1986年，为名为 D-1 的数字录像机提供了规范，它可以无损地录制任何色彩系统。

高清电视（`HDTV`）目前正在开发成为一种为家庭提供电影级观看的系统。它使用了 `16:9` 的宽幅比（标准电视为 `4:3`）和高保真音频。高清电视的水平和垂直分辨率都是标准电视的两倍。数字处理为视频信号提供了比模拟处理更好的精确度和多多的信噪比。参见网络电视标准。

摄像机。（汤姆）

从实际场景中，可以录制在磁带上供以后回放。摄像机可能属于几类之一：摄影棚（插图）、电视用或便携式。它也可能是用于远程观察核反应堆事故的高度专业摄像机。摄像机能够产生彩色或单色（黑白）。大多数现代摄像机使用由电荷耦合器件（`CCD`）组成的光敏元件。但在专用摄像机中可能会使用一个或多个真空管，称为电荷耦合器件。电荷耦合器件的表面。

每台摄像机都带有几个基本要素：光学系统、一个或多个显像管、取景器、棱镜、扫描电路和控制。某些摄像机还包括一套色彩编码。

获得高质量图像所需的其他因素还包括摄像增益、光圈校正和色彩平衡。由于设备对光平面变化没有线性响应，因此需要伽马校正。必须通过“拉伸”视频电平来捕捉高对比区域的细节。光圈校正为阴影区域提供了更好的效果，还有助于提高摄像机输出的信噪比。多管摄像机上必须调整准直，以确保独立的蓝、绿、红通道正确对齐。彩色摄像机上必须设置色彩平衡，并针对暗景进行调整，否则摄像机将出现客观的色调。

摄影棚摄像机配备了若干附件以增强其操作性。电子取景器（可能是可选的）允许操作员看到摄像机正在看到的图像，使对焦和图像对焦成为可能。指示灯系统由一个或多个指示灯组成，告知制作和操作人员哪台摄像机处于激活状态。摄像机内置了通话系统，以便导演与摄像机通信。摄像机安装在三脚架上，三脚架安装在推车底座上，允许摄像机在摄影棚地板上移动并根据需要升高或降低。云台允许摄像机向左或向右旋转。
