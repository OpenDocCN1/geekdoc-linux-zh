
# VirtualBox 的起点

无论你运行哪种操作系统，想尝试哪种操作系统，都要学习虚拟化的基础知识。

启动虚拟机最简单的方法之一是使用 `Oracle` 的 `VirtualBox`。它是适用于 `Windows`、`macOS` 和 `Linux` 的免费（GPL 许可）软件。`Windows` 用户应该从 `https://virtualbox.org` 下载，`Linux` 用户应该安装：

```bash
sudo apt install virtualbox
```

它适用于所有平台，因此无论使用什么操作系统（或你想运行哪种操作系统），你可以使用我们提供的方便的六步指南。如果你在尝试时卡了一会儿，为什么不从 `LXVF` 拷贝 `Linux` 或 `OpenMedia` 的 `ISO` 文件呢？你可以使用 `VirtualBox` 从那个东西中提取它；那将太棒了。

如果你发现自己处于全屏模式，只需按 `Ctrl+Alt` 返回窗口模式。如果你的鼠标光标被困在客户窗口中，只需再次按 `Ctrl` 右键。`Linux` 发行版支持无缝鼠标移动，所以他们不需要——将鼠标移过客户窗口的边缘来控制主机。

# VirtualBox 调整

启动虚拟机非常简单，但让我们看看 `VirtualBox` 提供的某些选项，以让你的虚拟生活感觉像你自己的生活一样真实。首先，如果你将虚拟磁盘镜像存储在传统的旋转硬盘上，你将经历沉重的负载，并且在你在使用时可能会注意到大量的磁盘活动。在类此任务下，如果你足够勇敢地运行 `Windows` 虚拟机，如果将其存储在 `SSD` 上，你的生活会好得多。

仿真创建软件，翻译或意味着主机可以理解的代码。虚拟化的不同之处在于，客户代码直接在主机上运行，这意味着它的速度更快（尽管有时在变慢时，其他硬件仍然需要被仿真），但也意味着只有可能虚拟架构并不相似。在虚拟化革命十年后，出现了一种新技术：容器被 `Docker` 在 2013 年流行起来，并带来了虚拟化的许多优势（隔离），但它们使用主机的内核，需要运行在相同的操作系统上。

容器可以看是服务器级虚拟化，而不是机器级。容器只需要包含运行特定应用程序所需的库，如果该应用程序仅在特定版本的二进制文件上运行，它们也知道依赖项。正如 `Qub` 运行在不同虚拟机的应用程序上，像 `Container OS (coreOS Linux)` 和 `LinuxOS` 运行在一切事物中。
