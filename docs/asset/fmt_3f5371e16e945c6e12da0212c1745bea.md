
```
<<html>

<head>

<title> This is the Title </title>

</head>

<body>

This is the body of the text

</body>

</html>
```

封装在 `<title>` 标签中的文本显示在窗口顶部。如果你在 `<head>` 部分包含了多个标题，则可能只有一个标题，通常只有最后一个会实际显示。`<head>` 标签包含的块用于设置文档并显示标题。`<body>` 标签包含的块是放置大多数标签和文本的地方。

正如你从图中的 URL 所示，此 HTML 文档是从我系统上的一个文件显示的；它并没有被放置在 Web 服务器上供全世界查看。

这个最小 HTML 文档演示了文档的部分，但实际上并没有什么用。它需要更多的标签和大量的文本。

## 字体控制

在文档正文中，你可以控制文本显示的字体。首先，有六级标题可用，分别使用标签 `<h1>` 到 `<h6>` 进行指定。

图 15.2 显示了使用 Mosaic Web 浏览器时标题标签的行为。列表 15.2 显示了它的源代码。

**图 15.2。**
*通过 Mosaic 查看的标题标签。*

**列表 15.2。标题标签的源代码。**

```html

<html>

<head>

<title> Heading Font Control </title>

</head>

<body>

<h1>Heading Level 1 - ABCDEF abcdef 1</h1>

<h2>Heading Level 2 - ABCDEF abcdef 2</h2>

<h3>Heading Level 3 - ABCDEF abcdef 3</h3>

<h4>Heading Level 4 - ABCDEF abcdef 4</h4>

<h5>Heading Level 5 - ABCDEF abcdef 5</h5>

<h6>Heading Level 6 - ABCDEF abcdef 6</h6>

<h1>Heading Level 7 - ABCDEF abcdef 7</h1>

<h2>Heading Level 8 - ABCDEF abcdef 8</h2>

<h3>Heading Level 9 - ABCDEF abcdef 9</h3>

<h4>Heading Level 10 - ABCDEF abcdef 10</h4>

</body>

</html>
```

查看图 15.2，你会发现从标题 6 之后行开始变得奇怪。当你超出标准允许的范围时，事情会变得异常。因为 `<` 和 `>` 符号对 HTML 有特殊含义，为了打印它们，你必须使用特殊字符表示。在列表 15.2 中，`&` 后面跟着分号（`;`）来完成特殊字符。如果你想打印 `&`，你会使用 `&amp;`。使用 Netscape 版本，产生的屏幕与图 15.3 所示略有不同。

**图 15.3。**
*通过 Netscape 查看的标题标签。*

对于其他字体，有逻辑标签和物理标签。对于逻辑标签，由浏览器决定如何显示它们。逻辑标签包括 `<EM>`（通常显示为斜体）、`<STRONG>`（通常显示为粗体）以及其他。图 15.4 显示了使用 Mosaic Web 浏览器时逻辑标签的行为。图 15.5 显示了使用 Netscape 浏览器时逻辑标签的行为。列表 15.3 显示了它的源代码。

**图 15.4。**
*通过 Mosaic 查看的逻辑字体样式。*

在图 15.4 中不同的字体类型并不明显。在图 15.5 中明显得多（它们得到了更好的支持）。

**图 15.5。**
*通过 Netscape 查看的逻辑字体样式。*

**列表 15.3。字体样式的源代码。**

```html

<html>

<head>

<title> Logical Font Styles </title>

</head>

<body>

<ADDRESS> Postal or E-mail address - ABCDEF abcdef</ADDRESS>

<CITE> Citations - ABCDEF abcdef</CITE>

<CODE> Program Code - ABCDEF abcdef</CODE>

<EM> Emphasis - ABCDEF abcdef</EM>

<KBD> Keyboard Input - ABCDEF abcdef</KBD>

<SAMP> Literal (Sample) Characters - ABCDEF abcdef</SAMP>

<STRONG> Strong or Important - ABCDEF abcdef</STRONG>

<VAR> Variable Name - ABCDEF abcdef</VAR>

</body>

</html>
```

除了无效标题标签外，它们都单独成行（根据定义，标题单独成行）。指定字体类型时，必须通过 `<br>`（换行）标签告诉浏览器到新行。物理标签包括 `<i>`（斜体）、`<b>`（粗体）以及其他。图 15.6 显示了使用 Mosaic Web 浏览器时物理字体样式标签的行为。图 15.7 显示了使用 Netscape 浏览器时物理字体样式标签的行为。列表 15.4 显示了它的源代码。

**图 15.6。**
*通过 Mosaic 查看的物理字体样式。*
