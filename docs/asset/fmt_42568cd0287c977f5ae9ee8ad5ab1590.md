### 注意事项

# 1. 归档文件（目录）。

你“最初”创建的文件。

### “什么是 TAR？什么是解压 TAR？”

# `tar` 命令允许你创建一个单一的“tar 文件”（tarfile），

# 它包含多个文件和多个目录的副本。

# 例如，`tar` 命令允许你创建任何目录

# （及其下方所有的子目录）。

# “解压”是从 tar 文件中解压一个或多个文件的过程，

# 或是将数据（提取）到复制的相同位置，

# 或者将数据（放置）在一个新的位置。

# 如果数据被放置在新位置，该位置可能

# 在同一台服务器上，也可能在不同城市的服务器上。

# 示例之后，请查看下方的“更多注意事项”部分。

# 如果 tar 对你来说是陌生的，请**首先**阅读“更多注意事项”。

# 即使 tar 对你来说并不陌生，也建议查看“更多注意事项”。

# 要查看作者**强烈推荐**的方法，请

# “强烈推荐”（STRONGLY RECOMMENDED）一词进行查找。

```bash
# 任务：创建一个包含所有 .ksh 脚本的 tar 文件。
# TAR_STEP1:
# 首先我们创建一个文件名列表（我们将在第2 步中 tar 它们）：
cd \$WHERE_TO_START_TARING
for filename in *.ksh
do
  # 如果它是一个有大小（非空）且可读的文件，那么……
  if [ -f "$filename" ] && [ -s "$filename" ] && [ -r "$filename" ]; then
    print "$filename" >> /tmp/.List_Of_Script_Names
  fi
done
```

```
print "正在创建要 tar 的文件列表。"
printf "\n要 tar 的文件总数：%d\n" $(cat /tmp/.List_Of_Script_Names | wc -l)
```

```bash
# TAR_STEP2:
# 现在使用列表中的所有文件 tar。
# 创建（-c）一个名为 TARFILE 的 tar 文件：

# 2>&1 将错误发送到标准输出（stdout）。
# 注意：以下类型的消息发送到 stderr：
# 有关 '-cvpf' 的更多信息，请看下方的“关于 -cvpf”。
```
