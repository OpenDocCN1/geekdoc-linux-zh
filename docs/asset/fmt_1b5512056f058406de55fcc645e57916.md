# 3. 查找失败设备的 HWID。

`EVM` 事件会记录出现故障的组件，但也可以使用 `hwmgr(8)` 命令找到它。

```
# hwmgr view device -dsk dsk4
HWID  Device Name     Mfg      Model          Location
------------------------------------------------------------
106:  /dev/disk/dsk4c  COMPAQ   8D009635C3     bus-3-targ-3-lun-0
```

# 4. 移除失败的组件。

```
# hwmgr del -id 106
hwmgr: Delete operation was successful
```
