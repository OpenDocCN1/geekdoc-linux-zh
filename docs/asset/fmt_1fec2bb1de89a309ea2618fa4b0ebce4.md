
# 妥氏综合症

妥氏综合症是以频繁的运动抽动和发性抽动为特征的神经障碍。运动抽动包括眨眼、任何肌肉群的运动、面部表情、鬼脸和手抖。某些运动抽动更为复杂、缓慢且明显，如点头、耸肩、触摸或跳跃。发性抽动通常是重复性声音，如清嗓子或吠叫。

发性抽动更为频繁，包括如反复清嗓子、吟唱和喉音。复杂的发性抽动可能更有意义，且在几乎每个族群中都有描述，估计发病率为每千人一或两次。运动和发性抽动发生在儿童时期，通常在5到12岁之间开始，严重程度不等。压力会加剧症状，而努力活动会减轻症状。该病是慢性的，抽动可以短期抑制，给人一种运动和声音是自愿的假象。

遗传模式与单基因染色体显性遗传有关。症状的发生是变化的并取决于性别。抽动可以从一性抽动到妥氏综合症不等，症状的复杂性与涉及妥氏综合症发展的的大脑区域密切相关。

治疗包括行为方法和通过在神经连接水平阻阻神经递质来影响大脑的药物。见脑（人类遗传；神经系统）。

# 毒素性综合征

一种由葡萄球菌属产生的毒素引起的严重、有时危及生命的疾病。其症状包括发热、低血压、恶心、呕吐、肌肉疼痛和皮疹，随后出现皮肤脱皮。

毒素性综合征于1978年在儿科患者中首次报道。在180例病例中，链球菌或葡萄球菌感染后观察到了恢复。流行病学家观察到这种现象主要发生在处于经期的链球菌感染的女性身上。在后来鉴定的葡萄球菌菌株中发现了毒素（T-11产生的毒素性综合征）。对于外国患者病例，假设毒素作为外源因子起作用，导致毒素性中毒在体内繁殖。

已报道了数例与月经无关的毒素性综合征。在这些病例中，它发生在男性和女性身上，且没有链球菌敏感性。

已证明毒素出现在约1%的葡萄球菌菌株中。然而，有证据表明该综合征可能由链球菌毒素引起。患有严重毒性休克症状的人应立即接受医疗治疗，以降低死亡几。(J.O. TOXICOSIS, TOXIN, SHOCK)

此类毒素的最常见原因是细菌感染。通过测定确定致死剂量来衡量毒性；给啮齿动物注射毒素直到记录到死亡。然后对数据进行绘图，发现50%动物的致死剂量（半致死剂量或 `LD50`）是毒性的标准。致死剂量。

毒素，如多氯联苯 (`PCB`) 和三氯乙烯 (`T`)，仅在多次暴露后表现出影响，被认为具有累积性。损害的程度和性质取决于暴露的毒素剂量。慢性效应发生在长期暴露之后——从几个月到一年。未观察到效应水平 (`NOEL`) 被用作慢性毒性的标准。缓解与致癌性。(M.A. RAM)

# 毒理学

研究化学物质对生物体产生的不利影响，也被称为毒理学（环境毒理学）。

影响化学物质毒性的最重要因素是其化学稳定性。所有必需物质都会受到氧化和还原的影响，这在大剂量给药时会限制其毒性。另一个因素是暴露途径。生物体可能通过吸入（进入肺部）、摄入（进入胃部）、皮肤吸收或注射进入身体。通常，物质通过肺部进入身体最为有效，肺部是最频繁的暴露途径。

进一步因素是化学物质暴露后的最终归宿。化学物质可能完全不吸收，从而限制其对生物体可能的不利影响。如果被吸收，它可能会遍布，并有可能从进入点引起一个或多个位点的效应。发生这些不利影响的部位称为靶器官。

毒素，一种源自细菌或真菌的非蛋白物质以及植物毒素，被所有细胞吸收。亲和力。（过敏原，毒素）

细菌毒素是致病细菌产生的蛋白质，通常被分泌并具有有害影响。已知有数百种。在极端情况下，单一毒素会导致疾病，影响肠道、白喉、破伤风和霍乱。引起感染的细菌通常影响感染周围的组织或被运输到血液中。

毒素可能帮助母细菌对抗防御，其程度相当于提供铁等营养物质，或通过允许细菌扩散。宿主生物体遭受的损害对于防止细菌没有益处。例如，肉毒杆菌中的肉毒毒素会导致神经系统细胞瘫痪。

植物毒素是复杂的分子，始终由两个部分组成，分别为A和B部分。部分是活性部分，而部分分子结合到细胞膜上的受体并将毒素置于细胞内部。部分毒素导致细胞膜发生化学反应，引起细胞瘫痪或细胞死亡。免疫毒理学。
