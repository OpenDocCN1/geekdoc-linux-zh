
在二十世纪，种族研究被人类变异和族群研究所取代，反映了两个重大发现。首先，种族（即最具生物学分歧的人群之间的对比）在人类物种的整体生物学变异中占比很小。其次，“种族”问题超越了生物学；它们是平等、权利、机会和偏见的问题。

然而，可以做出几个生物学概括。首先，自然界中人类种群中发现的连续性正是期望在微观进化过程运行中所预期的。其次，种群间的一些差异是适应，由自然选择对基因库的作用所改变。第三，分歧最大的人群只是最适合不同环境的人群——并非最原始的人群。第四，特定种群不能作为大洲的可靠代表。最后，观察到的种群间一致差异并不足以作为推断这些差异是天生的依据。几乎不可能控制所有相关的社会、经济和发展变量，仅仅研究种群间天生的生物学差异。参见 [体质人类学；社会生物学]。[J.J.M.]

# 加湿

增加气体中水蒸气含量（湿度）的过程。此过程及其反向操作，即除湿，对人类舒适度的空气调节和许多工业操作都是重要步骤。参见 [空调；舒适供暖；除湿；湿度]。

空气（或其他气体）可以通过直接注入水蒸气（蒸汽）来加湿，或者更常见的是，通过液水在与气流接触时蒸发来加湿。当蒸发发生时，需要提供热量来提供汽化潜热。如果没有外部热源，水或空气，或两者都会冷却。通过此过程冷却水是工业冷却塔冷却的基础，而在炎热干燥气候中常用的蒸发式空气冷却器则依赖于空气冷却效果。在这两种类型的装置中，空气会发生加湿，尽管这不是操作的主要目标。在主要设计用于加湿的装置中，进入的空气通常会被加热，以提供蒸发潜热，并允许空气以受控的温度和湿度水平离开装置。参见 [冷却塔]。[A.L.K.]

# 湿度控制器

一种测量和控制相对湿度的控制器。湿度控制器可用于通过调节电气或气动开关、阀门或风门来控制加湿或除湿设备。大多数测量湿度的方法依赖于材料随相对湿度增加和减少而发生的膨胀和收缩，例如人发、丝绸、角、金箔皮和木材。

电子湿度控制器包含一个传感元件和一个继电器放大器。传感元件由小块平板上的交替金属导体组成，并带有塑料涂层。相对湿度的增加或减少会导致两组导体之间电阻的减少或增加；电阻的变化由继电器放大器测量。参见 [湿度；湿度计]。[J.F.H., R.L.K.]

# 湿度

大气中的水蒸气含量，用几种度量表示，特别是相对湿度、绝对湿度、湿度混合比和比湿度。相对湿度是空气中实际含有的水分与在相同温度和压力下达到饱和时所能容纳的水分之比，以百分比表示。它是确定蒸发或水分吸收的干燥或潮湿程度的有用指标。参见 [湿度学]。

绝对湿度是单位体积空气中的水蒸气重量，例如表示为每立方米克数或每立方英尺英厘数。

湿度混合比是与单位质量干气混合的水蒸气重量，通常表示为每千克克数。比湿度是单位质量湿气的重量，其数值与混合比几乎相同。[J.R.F.]

# 湿度控制

调节空气和水蒸气混合物中水蒸气的饱和程度（相对湿度）或数量（绝对湿度）。湿度常被误认为是空气的一种品质。参见 [湿度]。

当空气和水蒸气的混合物在恒定压力下加热，且不存在水或热量的情况下，蒸气压与饱和蒸气压之比会降低；也就是说，相对湿度下降，但绝对湿度保持不变。如果将温暖的混合物引入与绝缘系统中水接触，则发生绝热加湿；温暖的气体和大部分水在转移到空气-水汽中蒸发的那部分空气时冷却，直到水蒸气达到与相应的水-空气-水汽绝对温度相对应的饱和压力。此时相对湿度为 100%，绝对湿度增加。混合物的加热以及使用加热后的混合物来蒸发水是许多工业干燥过程的典型特征，也是诸如吹干头发等常见家用应用的特点。当热炉空气流过湿润的多孔表面以加湿空气从而改善舒适度时，也会发生同样的过程。参见 空调。

为了从空气-水汽混合物中去除水分，通常通过将混合物经过制冷盘管或空气洗涤器（其中混合物与冷水接触）冷却到所需的露点温度（对应于需要达到的绝对湿度）来移除水分。结果是一种接近饱和的混合物，如果需要，可以重新加热以达到所需的相对湿度。参见 除湿器。

水分也通过吸收在没有制冷的情况下被移除，在这个过程中，混合物通过液体吸附剂的喷雾，该吸附剂在变得稀释时会发生物理或化学变化。典型的吸附剂包括氯化锂和氯化钙溶液以及乙二醇。参见 吸收。

另一种除湿方法是通过吸附，使用硅胶或活性白土，它们通过毛细作用降低其表面的蒸汽压，使得其附近的水蒸气处于过饱和状态并凝结。参见 吸附； 心理物理学。 [R.L.K]

# 辉石族矿物

一系列具有通式 Mg$_{2n+1}$(SiO$_{4}$)$_{n+1}$(OH)$_{2}$ 的镁岛状硅酸盐矿物同系物。已知物种包括诺贝石（n = 1）、软镁硅石（n = 2）、辉石（n = 3）和斜辉石（n = 4）。它们都基于六方最密堆积的氧和氟原子。Mg 原子占据八面体间隙，Si 原子占据四面体间隙。诺贝石和辉石是正交的；软镁硅石和斜辉石是单斜的；水镁石是三方的。这些矿物的锰类似物以粉红色颗粒的形式存在于由史前硅质碳酸盐岩和沉积锰氧化物衍生的变质锰矿中。其他可出现的替代阳离子包括 Fe$^{2+}$、Ca$^{2+}$、Al$^{3+}$ 和 Ti$^{4+}$。

辉石族矿物具有相似的物理性质。光泽为树脂状，颜色通常为黄色、棕色、橙色或红色。纯合成 Mg 端元是无色的。硬度为莫氏硬度 6–6½，比重为 3.1–3.2。它们很难在视觉上区分，需要 X 射线衍射、电子探针或光学技术。它们存在于区域结晶大理岩中，通常是与铁矿相关的硅卡岩矿物。参见 硅酸盐矿物。 [PB.M]

# 饥饿

该术语最常用来指伴随食物需求的自觉感受；然而，对该主题的研究已扩展到对食物摄入整体控制的考量。更具体地说，关于饥饿问题的实验工作关注的是引起饥饿感的感官线索，决定何时及摄入多少食物的生理机制，以及控制食物选择的机制。

食物消耗基本上受机体营养状态控制。食物剥夺导致进食，而摄入食物物质终止饥饿感。问题在于确定哪些生理过程随营养状态定量变化，并查明这些变化是否可以通过神经系统检测到，从而引发和终止食物消耗。

血糖水平比任何其他因素受到更多关注，可作为典型案例。血糖浓度确实以一般方式随着食物周期的周期性适当变化。然而，对正常生活中血糖变化的详细分析表明，血糖浓度与饥饿之间的关系并不足够紧密，以至于这种单一的体液因素能够以任何简单直接的方式控制饥饿。对更局部组织利用食物的评估证明是解决这一问题的更有希望的方法。现在有一些证据表明肝脏状态在进食控制中起着关键作用。肝脏糖原的剥夺刺激进食；其在实验对象（如大鼠和兔子）中的补充则终止进食。参见 碳水化合物代谢； 肝脏。

已识别出许多终止进食的刺激物。在食物剥夺的动物中，减少细胞水或血浆液体抑制进食。胃扩张以及向肠道和体循环（尤其是静脉肝循环）输注营养物质也会减少进食。营养物质吸收进入肠道产生的饱腹感可能部分由肠道激素胆囊收缩素介导。胆囊收缩素可能有效是因为它减少了食物通过胃的速率。过去关于进食起始和终止的离散神经中枢的观念已被放弃，因为进食行为的复杂性及其相应的神经复杂性已得到更广泛的认可。

某些特定食物物质的减少会引发对该所需物质增加的食欲。这种所谓的特异性饥饿行为已通过在儿童和所研究的低等动物中的许多物质（如盐、钙、脂肪、蛋白质和某些维生素）的实验得到证实。目前很清楚，只有在盐剥夺的动物中，对盐的饥饿感在动物学会盐摄入的有益后果之前才出现。对矿物质、蛋白质和维生素的特异性饥饿感仅逐渐出现，并反映动物学习到某些食物不再有益，甚至可能有害。参见 第一和第二食欲。 [E.M.B]

# 腐殖质

土壤中无定形的、通常深色的胶体物质，代表来自植物、动物和微生物的有机质组分中最抗分解的复合物。

腐殖质由已失去原始结构的有机质残留物组成，这些残留物在简单成分快速分解后形成，并包括合成的细胞物质以及微生物的副产品。它不是一种确定的物质，且处于持续变化中，通过缓慢分解消失，并不断通过残留物质的结合而更新。随着这些过程之间的平衡，腐殖质虽然不是静态的，但在特定土壤中其性质和数量保持相对均匀。它构成了稳定物质的储存库，赋予土壤有益物理、化学和生物特性。肥沃的土壤富含腐殖质。

# 亨廷顿舞蹈症

一种罕见的基底神经节遗传性疾病，会导致进行性运动不协调、异常不自主运动（舞蹈症）以及智力下降。该疾病在15至20年内逐渐恶化，且 invariably 致命。亨廷顿舞蹈症作为常染色体显性孟德尔遗传特征，携带该基因的个体若寿命足够长，将不可避免地发病。男女患病率相等。发病平均年龄介于35至40岁之间，但最早可在2岁发病，最晚可至80岁。

治疗仅为支持性治疗：没有任何药物能显著影响疾病的病程或患者的功能能力。然而，抑郁症或精神病性症状可通过抗抑郁药和抗精神病药物暂时缓解。
