| `1<<31` | $2^{31}$ | 2147483648 | `0x80000000` |

逆向工程的实际工作中出现这些常数（bit mask）。逆向工程人员备这个表格。虽然十进制常数很难记忆，但是十六进制并不困难。

它们经常被用作标志位。例如，在Apache 2.4.6的源码中，`ssl_private.h`用到了部分常量：

```c
/**
 * Define the SSL options
 */
#define SSL OPT_NONE (0)
#define SSL OPT_RELSET (1<<0)
#define SSL OPT_STDENVARS (1<<1)
#define SSL OPT_EXPORTDATA (1<<3)
#define SSL OPT_FAKEAUTH (1<<4)
#define SSL OPT_STRICTREQUIRE (1<<5)
#define SSL OPT_PRENEGOTATE (1<<6)
#define SSL OPT_LEGACYDNFORMAT (1<<7)
```

现在看看“点数”程序。宏`IS_SET`的作用是检测`flag`（变量`a`）的第`n`位是否为一。如果变量对应的位是1，则宏`IS_SET`返回；如果变量对应的位是1，`if()`语句的条件是“不是零”，否则哪种条件都会执行`then`模块。

## 19.5. x86

使用MSVC2010编译上述程序，得到的代码如下：

```assembly
rt = -8      ;size=4
i = -4       ;size=4
a = 8        ;size=4

f PROC
    push ebp
    mov ebp, esp
    sub esp, 8
    mov DWORD [ebp-8], 0
    mov DWORD [ebp-4], 0
    jmp SHORT LN4
LN3:
    mov eax, DWORD [ebp-8]
    add eax, 1
    mov DWORD [ebp-8], eax
LN4:
    cmp DWORD [ebp-8], 32
    ge SHORT LN2
    mov edx, 1
    mov eax, DWORD [ebp-8]
    shl eax, cl
    and eax, DWORD [ebp-8]
    je SHORT LN1
    mov eax, DWORD [ebp-4]
    add eax, 1
    mov DWORD [ebp-4], eax
LN1:
    jmp SHORT LN3
LN2:
    mov eax, DWORD [ebp-4]
    mov esp, ebp
    pop ebp
    ret
ENDP
```
