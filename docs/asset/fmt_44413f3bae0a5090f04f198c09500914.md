
当访客点击提交按钮时，`message.php`会再次被调用，这次PHP可以在`$_REQUEST`数组中找到可用的变量。给定该脚本，如果用户输入`12345`作为她的用户ID并输入`trustus`作为密码，PHP将为你提供设置为`12345`的`$_REQUEST['Userid']`和设置为`trustus`的`$_REQUEST['Password']`。请注意，除非你特别想要使用`GET`，否则使用`HTTP POST`至关重要。`POST`允许你发送更多的数据，并防止人们篡改你的URL来试图寻找脚本中的漏洞。

这就完了吗？嗯，差不多吧。这告诉你如何检索用户数据，但请务必对其进行净化，以便用户不会试图将HTML或JavaScript偷偷放入你的数据库中，伪装成无害的内容。PHP为此提供了`strip_tags()`函数。它接受一个字符串并返回一个去除了所有HTML标签的相同字符串。

## 数据库

对于许多人来说，PHP能够轻松地用于创建动态、数据库驱动的网站，是选择使用它的关键原因。标准版本的PHP支持`MySQL`、`PostgreSQL`、`SQLite`、`Oracle`、`MS SQL Server`、`ODBC`以及许多其他流行的数据库，因此你肯定会找到适合处理你的数据的工具。

如果你想尝试，你可以学习连接和操作PHP支持的每个数据库的所有单独函数，但更明智的做法是使用`PEAR::DB`。`PEAR::DB`是PHP支持的数据库之上的抽象层，这意味着你只需编写一次代码——通过最小的更改——即可在所有数据库服务器上运行。

`PEAR`是PHP的脚本存储库，包含众多工具和针对常见问题的预写解决方案。`PEAR::DB`可能是`PEAR`项目中最受欢迎的部分，但值得一看`PEAR`网站，以查看是否有其他吸引你的内容。

### PEAR::DB 简介

要基本使用`PEAR::DB`，你需要了解如何连接数据库、执行SQL查询以及处理结果。这并非SQL教程，因此我们假设你已经熟悉该语言。为了本教程的目的，我们还假设你正在处理一个名为`dentists`的数据库和一个名为`patients`的表，其中包含以下字段：

- `ID`——主键，自动递增的整数，用于存储每个患者的唯一编号
- `Name`——`varchar(255)`字段，用于存储患者姓名
- `Age`——整数
- `Sex`——男性为1，女性为2
- `Occupation`——`varchar(255)`字段，用于存储患者职业

同样，为了本教程的目的，我们将使用IP地址为`10.0.0.1`的数据库服务器，运行`MySQL`，用户名`fedora`，密码`aim65z`。你需要将这些详细信息替换为你自己的——使用`localhost`来连接本地服务器。

使用`PEAR::DB`的第一步是包含标准的`PEAR::DB`文件`DB.php`。你的PHP配置为在`PEAR`目录内查找`include()`文件，因此你不需要提供任何目录信息。

`PEAR::DB`是面向对象的，你在创建初始`DB`对象时指定连接详细信息。这是通过一种类似URL的系统完成的，该系统一次性指定数据库服务器类型、用户名、密码、服务器和数据库名称。在此指定数据库服务器后，其他一切都是抽象的，这意味着你只需更改连接行即可将代码移植到另一个数据库服务器。

第一个脚本连接到我们的服务器并打印一条状态消息（参见清单32.6）。

#### 清单 32.6 通过 PEAR::DB 连接数据库

```php

<?php

    include("DB.php");

$dsn = "mysql://fedora:aim65z@10.0.0.1/dentists";

$conn = DB::connect($dsn);

if (DB::isError($conn)) {

    echo $conn->getMessage() . "\n";

} else {

    echo "Connected successfully\n";

}

?>

```

你应该能看到连接字符串是如何分解的。首先是服务器名称，然后是用户名和密码（由冒号分隔），接着是`@`符号后跟要连接的IP地址，然后是斜杠和数据库名称。请注意调用`connect`的方式是`DB::connect()`，它直接调用`PEAR::DB`并返回一个数据库连接对象以存储在`$conn`中。连接详细信息使用变量名`$dsn`，因为它是“数据源名称”这一常见首字母缩略词。

如果`DB::connect()`成功连接到服务器，它返回一个我们可以用于执行SQL查询的数据库对象。如果没有，我们得到一个可以使用诸如`getMessage()`等函数查询的错误。在上面的脚本中，如果我们连接失败，会打印错误消息，但如果成功，也仅打印一条消息。接下来，我们将更改此行为，以便在拥有连接时执行SQL查询。

通过数据库连接的`query()`函数执行SQL查询，传入我们要执行的SQL。这会返回一个可用于获取数据的查询结果。此查询结果可以看作是一个多维数组，因为它有许多行数据，每行包含许多列属性。使用`fetchInto()`函数提取这些数据，该函数循环遍历查询结果，将一行数据转换为数组并将其作为返回值发送回来。你需要向`fetchInto()`传入两个参数，指定数据存储的位置以及你希望如何存储。除非你有特殊需求，否则为第二个参数指定`DB_FETCHMODE_ASSOC`是一个明智的选择。

清单32.7显示了新的脚本。

#### 清单 32.7 通过 PEAR::DB 运行查询

```php

<?php

include('DB.php');

$dsn = "mysql://fedora:aim65z@10.0.0.1/dentists";

$conn = DB::connect($dsn);

if (DB::isError($conn)) {

    echo $conn->getMessage() . "\n";

    exit();

}

echo "Connected successfully!\n";

$result = $conn->query("SELECT ID, Name FROM patients;");

while ($row = $result->fetchInto($row, DB_FETCHMODE_ASSOC)) {

    extract($row, EXTR_PREFIX_ALL, 'pat');

    echo "$pat_ID is $pat_Name\n";

}

?>
```
