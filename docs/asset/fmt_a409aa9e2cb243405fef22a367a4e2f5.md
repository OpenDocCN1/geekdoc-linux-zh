## Web 服务

Web 服务通常基于 HTTP 协议。某些高级通信协议用于特殊目的，包括用于安全（SSL）的 HTTPS 以及 Web 服务器代理。

本节描述了三种客户端与服务器组合：

- 堡垒机是服务器，或远程 Web 服务器的网关；汇聚机是客户端。
- 堡垒机是服务器，或网关；DMZ 中运行着 Web 服务器；且汇聚机是客户端。
- 堡垒机是服务器，或网关；汇聚机是本地 Web 代理服务器。

## 堡垒机作为 Web 服务器或客户端，汇聚机作为客户端
