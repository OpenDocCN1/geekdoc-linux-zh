# TLD (顶级域名)

完整域名的最后部分（右侧）。例如，在域名 `www.matisse.net` 中，“.”就是顶级域名。有大量的 `nbiz`, `.com`, `.edu`, `.gov`, `.info`, `.mil`, `.net` TLD，以及一组对应于国家代码的两个字母 TLD，如 `.ca`, `.jp`, `.uk`。来自 Matisse

`http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

`tled`

闪烁键盘 LED 以指示 TX 和 RX 网络包。这些程序有助于监控网络流量。当网络包离开机器时，它们会闪烁 Scroll-Lock LED（发光二极管），接收到时闪烁 Num-Lock LED。警告：在某些系统上已知会导致键盘部分或全部无法使用，这种情况很少见，通常发生在少数带有长线或旧缆的笔记本电脑和键盘上。这包括 IBM thinkpad 600 笔记本和 HP OmniXe2。来自 Debian 3.0r0 APT
