## real time (实时)

- 1. [tepoch] adj. 描述要求程序在很小的响应时间上限（通常为毫秒或微秒）内响应刺激的应用。化学工厂的过程控制就是一个例子。此类应用通常需要特殊的操作系统（因为其他一切必须为响应时间让位）和速度调优的硬件。
- 2. Adv. 术语指在人们等待或观察时完成某事。“我向她要了栈上的调用程序计数器，她实时给出了一个算法。”

# Linux 词典
