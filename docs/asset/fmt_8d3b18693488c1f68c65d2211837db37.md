
仅仅通过修改变量，你无法在子 shell 中取消变量并使其在父 shell 中取消。

### 发现默认变量

Bash shell 使用特定的环境变量来定义系统环境。你可以认为这些变量在你的 Linux 系统上已经设置或可以设置。由于 Bash shell 是原始 Unix Bourne shell 的派生，它还包含了在该 shell 中定义的环境变量。
