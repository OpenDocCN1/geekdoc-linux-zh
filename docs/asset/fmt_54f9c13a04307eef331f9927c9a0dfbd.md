
## 613 ksh, rksh

## 由 Shell 设置

shell 设置以下参数：

- `OPTARG`: 上一个处理选项的值。
- `OPTIND`: 上一个处理选项的索引。
- `PPID`: 父进程号。
- `PWD`: 当前工作目录。
- `RANDOM`: 生成 0 到 32767 均匀分布的随机整数。
- `REPLY`: 此变量由 `select` 语句设置。
- `SECONDS`: 自调用来的秒数。

## Shell 使用的变量

shell 为 `PATH`, `PS1`, `PS2`, `PS3`, `PS4`, `MAILCHECK`, `FCEDIT`, `TMOUT` 和 `IFS` 提供默认值，而 `HOME`、`SHELL`、`ENV` 和 `MAIL` 不 shell 设置（尽管 `HOME` 由登录设置）。在某些系统上，`MAIL` 和 `SHELL` 也会由登录设置。shell 使用以下变量：

- `PATH`: 指定 `cd` 命令的搜索路径。
- `COLUMNS`: 如果设置此变量，则使用该值定义 shell 编辑模式的窗口宽度以及打印选择列表的 own。
- `EDITOR`: 如果此变量的值设置为 `emacs`、`gmacs` 或 `vi` 且 `VISUAL` 未设置，则开启相应的选项（见特殊命令）。
- `ENV`: 当 shell 被调用时，此变量由 shell 进行参数扩展，并将结果作为包含在当前环境中执行的 shell 命令的文件路径。该文件不是可执行的。如果扩展后的 `ENV` 不是绝对路径，则结果未知。如果用户的实际有效用户 ID 或实际有效组 ID 不同，则将忽略 `ENV`。

- `FCEDIT` 指定 `ksh` 命令的默认编辑器。
- `FPATH` 指定函数定义的搜索路径。默认情况下，在 `PATH` 变量之后搜索 `FPATH` 目录。如果找到可执行文件，则在当前环境中读取并执行它。当引用带有 `-u` 属性的函数时，会在 `PATH` 之前搜索 `FPATH`。`autoload` 设置创建一个带有 `-u` 属性的函数。

- `HISTFILE` 如果在调用 shell 时设置了此变量，则使用该值作为存储命令历史的文件。

- `LC_COLLATE` 模式匹配中范围表达式、等价类和多字节字符排序元素的行为。

- `LINENO` 由 shell 设置为一个十进制数，表示脚本中当前的顺序行号（从 1 开始编号），或在执行每个命令之前。如果用户设置或重置了 `LINENO`，该变量在 shell 的生命周期内可能会失去其特殊含义。如果 shell 没有在执行脚本或函数，则 `LINENO` 的值未定义。

### 空解释 (Blank Interpretation)

在参数和命令替换后，会对替换结果扫描字段分隔符（在 `IFS` 中找到），如果发现此类字符，则将其分成不同的字符。显式空参数（`""` 或 `''`）会被保留。隐式空参数（由无值的参数产生）会被移除。

### 文件名生成 (File-Name Generation)

替换后，每个命令词都会扫描 `*`（除非指定 `-f` 选项）。如果发现这些字符，将替换为字典排序的文件名。如果没有匹配到模式，单词将保持不变。

- `*` 匹配任意字符。
- `?` 匹配零或多个字符。
- `+` 匹配恰好一个字符。
- `@` 匹配一个或多个字符。
- `!` 匹配一个或多个字符。
- `-` 匹配一个或多个字符。
- `(` 匹配一个或多个字符。
- `)` 匹配一个或多个字符。
- `[` 匹配一个或多个字符。
- `]` 匹配一个或多个字符。
- `{` 匹配一个或多个字符。
- `}` 匹配一个或多个字符。
- `|` 匹配一个或多个字符。
- `^` 匹配一个或多个字符。
- `$` 匹配一个或多个字符。
- `.` 匹配一个或多个字符。
- `\` 匹配一个或多个字符。
- `~` 匹配一个或多个字符。
- `/` 匹配一个或多个字符。
- `;` 匹配任意字符。

在参数替换后，会对替换结果扫描字段分隔符（在 `IFS` 中找到），如果发现此类字符，则将其分成不同的字符。显式空参数（`""` 或 `''`）会被保留。隐式空参数（由无值的参数产生）会被移除。

### 字符转义 (Quoting Escaping Characters)

每个元字符对 shell 都有特殊含义。要移除其正常含义，可以在其前面加上反斜杠进行转义。要引用字符串，可以将其封装在引号中。

- `'` 一对单引号之间的所有字符都被引用。单引号内不能出现单引号。
- `"` 双引号内的字符（`""`）会发生参数替换，且 `\` 转义 `'` 和 `$`。`\$` 和 `$` 在未引用或作为参数赋值或文件时含义相同。
- `` ` `` 反引号内的字符会被引用，`\` 转义 `` `` 和 `$`。如果反引号出现在双引号内，则是 "`。

可以通过引用保留字的任何字符来移除其特殊含义。函数名或特殊命令的识别无法通过引用它们来更改。

### 算术计算 (Arithmetic Evaluation)

`let` 命令提供了执行整数运算的能力。算术计算使用长整数进行。常量格式为 `base#n`，其中 `base` 是 2 到 36 之间的十进制数，表示算基，`n` 是该基下的数字。如果省略 `base`，则为 10。算术表达式使用 C 语言的语法、优先级和结合性。除了 `+`、`-`、`?` 和 `;` 之外的所有整数运算符都得到支持。在算术表达式中，可以直接通过名称引用变量，无需使用参数替换语法。

可以通过 `IPSET` 特殊命令的 `-i` 选项为变量指定内部整数表示。对带有 `-i` 属性的变量的每次赋值都会执行算术计算。如果你没有指定算术基，对变量的赋值将决定算术基。该基在发生参数替换时会被使用。许多算术运算符需要引用，提供了 `let` 命令的替代形式。对于任何以 `(` 开头的命令，直到遇到匹配的 `))` 之前的所有字符都被视为一个引用的表达式。更准确地说，`((...))` 等同于 `let "..."`.
