
骨架由硅质六射骨针构成的海绵纲。这些纯海洋海绵广泛分布于现代海洋中。其化石记录从晚太古宙延续至今生代。该纲的基本骨针类型是三相六射线，其中三对相对的光线彼此垂直，并位于立方体的三个轴之一上。近端光线末端和轴向丝在立方体中心交汇。这些主要骨针及其变体构成了海绵的骨架。

现生六放海绵主要是深海-海洋生物，最常见于 200-2000 米（660-6560 英尺）的深度，尽管许多物种已知生活在深海下层。活着的六放海绵通常呈高脚杯状或瓶状，尽管该纲中也存在分支状、块状、管状或绳状外观的海绵。许多具有长骨针的根丛，将其锚定在原位并将其支撑在海床之上。

# 六放海绵目（Hexactinosa）

六放海绵纲六放目（Hexascomopha）的一个目。该目海绵中的六射大骨针相互结合形成刚性框架，完全由排列成平行线列的简单六射线骨针组成。每列的成员通过二氧化硅的次要包膜彼此连接。*参见六放海绵纲* [W.D.H.]

# 六放海绵亚纲（Hexactinomorpha）

六放海绵纲的一个亚纲，其六射大骨针通常为六星形（小型、六射线骨针，末端常有分支）。这是一个多样化的海绵集合，通常通过基部牢固地附着在基底上，较少通过基部骨针丛或垫锚定。体部骨针有时是自由且未连接的，但六射大骨针常融合形成刚性连接的骨架。承认以下目：Hexactinosa, Lyssicosida, Lyssicososa, 和 Reticulosida。*参见 HEXACTINOSA; LYNCOSIDA; LYSSICOSA; 多孔动物门; RETICULOSA* [W.D.H.]

# 冬眠（Hibernation）

通常应用于冷血（变温）脊椎动物和无脊椎动物中休眠和昏睡状态的术语。（该术语也应用于相对

一些哺乳动物和鸟类物种，它们都是温血脊椎动物。¹ 这种相当普遍的现象容易观察到：当变温动物（poikilothermic animals）的体温随环境气温平行下降时。

### 变温动物

当暴露于低温时，动物会进入冬眠状态；在正常条件下，这主要发生在冬季，此时环境温度较低且持续时间长。一种相关的休眠形式称为夏眠（estivation）。许多动物在经历长期干旱或炎热干燥的夏季时会进入夏眠状态。就实际目的而言，动物的冬眠和夏眠是不可区分的，除了刺激因素不同：一个是寒冷，另一个是干旱环境。

目前并没有一份完整的冬眠动物清单；然而，在变温动物中，无论是脊椎动物还是无脊椎动物，都可以找到许多例子。变温动物有时被称为外温动物（ectotherms），因为它们的体温不是由内部调节的，而是随环境温度的升降而变化。在冬眠和冬季蛰伏期间，体温反映环境温度，通常精确到小数点后几分之一度。在变温动物中，经典的冬眠或夏眠者包括爬行动物、两栖动物和鱼类；在无脊椎动物中，包括昆虫、软体动物和许多其他无脊椎动物。

对于许多外温性脊椎动物（鱼类、两栖动物和爬行动物）来说，通过进入代谢不活跃状态来避免季节性和周期性环境严酷考验的能力，是它们生存的关键要素。具体而言，冬季休眠和夏季夏眠——这些术语应用于变温动物时的通常语境——使许多动物能够生存和繁衍，一方面通过减少季节性极端环境的影响，另一方面在不利活动时期（即食物稀缺时）显著降低外温动物的能量成本。

许多陆生爬行动物，如蜥蜴、蛇和乌龟，会进入休眠状态并通过在岩石缝隙、原木下以及冻土层以下的地下挖掘洞穴来冬眠。泽龟（Terrapin turtles）也会变得寒冷蛰伏，经常可以在冰下的泥潭或池塘中被发现完全浸没其中。

由于冬眠的爬行动物受到季节性低温持续时间的随机影响，因此没有明确定义的休眠期。冬眠期往往与纬度位置有关，龟鳖科（Emydidae）的情况就证明了这一点。栖息在北方气候区域的物种比它们南方的亲属冬眠时间更长，从而显示出与冬季时长成比例的冬眠期。冬眠的爬行动物会食欲不振并停止进食。尽管冬眠乌龟的代谢率降低了高达 95%，但仍会消耗一些储存的食物。主要类型的储备食物有两种：脂质和糖原（动物淀粉），后者比脂肪稳定性差，消耗速度更快。糖原通常位于肝脏和肌肉等组织中。有证据表明这些储备食物是被选择性利用的。在冬眠的乌龟中，组织中的糖原在冬眠的初始几天和几周内被消耗；随后，脂质被利用。

对冬眠的变温动物来说，一个主要的危险是冻死；冰晶会在自由原生质水中形成，最终破坏细胞和组织，导致动物死亡。尽管体温降至约 32 至 31°F（0 至 –1°C），青蛙、蝾螈和乌龟仍能存活。随着冬季临近，组织的水含量减少，血液变得更加浓缩。

鱼类不会冬眠。然而，许多鱼类在冬季的大部分时间里都处于静止状态，部分身体被冻结在泥浆和冰中。

夏眠现象在双名目（dipnoans），即肺鱼中最为人所知。这些鱼类局限于热带地区，那里有反复的干旱季节。它们通过变得休眠和蛰伏来度过旱季。肺鱼是更原始的呼吸空气动物之一，拥有利用大气氧气的肺。在夏眠的蛰伏期间，肺成为主要的呼吸器官。通常，随着旱季临近，肺鱼会遵循类似的行为模式。例如，*Prototorus* 会随着旱季期间水量减少而钻入底部的泥浆。从埋藏处到地表的隧道提供了一条空气通道。为了准备夏眠，*Prototorus* 会在自己周围分泌一层黏滑的粘液，这层粘液硬化成一个紧密的茧状腔室，防止鱼脱水。只有一个开口，形成在嘴周围。因此，隧道中的空气进入口中并到达肺器官。当旱季结束，水慢慢进入洞穴，软化内容物并唤醒肺鱼。在夏眠期间，肺鱼的新陈代谢处于低水平，其适度生命过程所需的能量来自组织蛋白的利用。

在某些蜗牛中，夏眠可能持续数年；在昆虫和蜘蛛中，冬眠期与生命周期中的某个阶段紧密相关。在冬季和炎热干燥的夏季，土壤中含有各种各样蛰伏的无脊椎动物，例如蚯蚓、蜗牛和蛞蝓、线虫、昆虫和蜘蛛、许多昆虫的幼虫、幼体和蛹、卵鞘以及茧。

昆虫在越冬时，大部分处于变态的卵或幼虫阶段。冬眠经常与卵或幼虫在冬季发生的休眠（diapause）或发育停滞相结合。人们熟悉的蝴蝶茧就是幼虫和蛹的冬眠所。另见昆虫生理学。

包囊化（encystment）现象在原生动物（单细胞动物）中很常见。包囊化与夏眠和冬眠非常相似，包囊化的原生动动物处于极度静止状态，几乎不进行代谢活动。另见原生动物。

### 温血脊椎动物

许多哺乳动物和一些鸟类在至少部分冬季时间里躲藏起来，但它们不会比正常睡眠更嗜睡。另一方面，一些哺乳动物在冬季经历代谢率和生理功能的显著下降，体温接近 32°F（0°C）。这种状态有时被称为深冬眠，这是温血脊椎动物——拥有复杂的体温控制机制——放弃其温血状态并冷却到环境温度的唯一状态。在嗜睡状态和深冬眠之间存在许多等级变化，关于这些等级变化知之甚少。熊、臭鼬、浣熊和獾是冬季会变得嗜睡的动物。虽然通常被认为是典型的冬眠者，但熊的体温下降幅度不超过几度。

深冬眠者局限于五个哺乳动物目：有袋类、翼手目（或蝙蝠）、食虫动物、啮齿动物，以及可能的灵长类。大多数，如果不是全部的话，温带气候中的食虫蝙蝠不仅在冬季冬眠，而且在栖息和睡觉时也会降低体温。对于一种小型哺乳动物来说，其散热表面积相对于体型来说过大，考虑到能量保存，这种优势是显而易见的。许多啮齿动物是深冬眠者，包括地松鼠、土拨鼠、睡鼠和仓鼠。脂尾猴和鼩鼱是冬眠或夏眠的灵长类动物。在鸟类中，花蜜鸟（Phaenoptilus）以及一些蜂鸟和雨燕在寒冷时期会经历体温和代谢率的降低。

除了蝙蝠之外，所有深冬眠者的冬眠都是季节性的，通常发生在寒冷的冬季月份。在所有情况下，它都发生在如果必须保持活跃并寻找食物将面临极其困难条件的动物身上。在冬眠的准备期间，动物要么变得肥胖，像土拨鼠那样，要么在越冬处储存食物，像花栗鼠和仓鼠那样。在冬眠之前，内分泌腺普遍发生萎缩，但至少部分这种情况发生在繁殖季节结束后不久，与冬眠没有直接关系。像地松鼠这样的动物在秋季变得更为蛰伏，即使在温暖环境中也是如此，表明可能存在由内分泌腺控制的深刻代谢变化。在大多数冬眠者中，缺乏食物几乎没有影响，冬眠的刺激因素尚不清楚。据报道，从冬眠动物血液中提取的物质注射到活跃且潜在冬眠的动物体内会诱导冬眠，这表明产生冬眠的因素可能是通过血液传播的。
