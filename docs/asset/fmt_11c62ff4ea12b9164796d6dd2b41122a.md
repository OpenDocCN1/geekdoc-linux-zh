
`Action` 指令将 CGI 脚本映射到处理器或 MIME 类型，而 `Script` 指令将 CGI 脚本映射到特定的 HTTP 请求方法（GET, POST, PUT 或 DELETE）。这些选项允许在请求相应 MIME 类型的文件、调用处理器或调用请求方法时执行脚本。

`MetaDir` 和 `MetaSuffix` 指令实现了可选的 CERN-httpd 守护进程的一项功能，允许在发送请求文件时发送额外的 HTTP 标头信息。如果上述两行被取消注释，则对文件的任何请求都将包括在同一目录中搜索一个名为 `.web` 的子目录，并在该目录下搜索一个与请求文件相同但后缀名为 `.meta` 的文件。例如，如果客户端请求 `http://www.mybox.com/services/grant.html`（存储为 `/home/httpd/services/grant.html`），文件 `/home/httpd/services/.web/grant.html.meta` 将为客户端提供额外的 HTTP 标头信息。

# 自定义错误响应

对于发生的不同的错误情况，你可以定义特定的响应。响应可以是纯文本、重定向到本地服务器上的页面，或重定向到外部页面：

# 可自定义错误响应（Apache 风格）

它们有三种形式

## 1) 纯文本

`#ErrorDocument 500 "服务器出了点小差错。\n# 注意：("") 将其标记为文本，不会被输出`

## 2) 本地重定向

`#ErrorDocument 404 /missing.html`

在 `www.unlt.com` 上的额外内容

将重定向到本地 url `/missing.html`

`#ErrorDocument 404 /cgi-bin/missing_handler.pl`

注意：可以重定向到使用服务器端包含的脚本或文档。

## 3) 外部重定向

`#ErrorDocument 402 http://some.other_server.com/subscription_info.html`

注意：与原始请求相关的许多环境变量 *将* 对脚本不可用。
