
你可以通过输入感叹号后跟数字按数字执行命令，例如输入`!210`执行第210条命令。输入`history -c`可以清除历史记录，如果你最近输入了不希望他人发现的命令（例如包含密码的命令），这非常有用。

bash历史记录存储在主目录下的`.bash_history`文件中。这是一个普通的文本文件，因此你可以使用文本编辑器或如`less`的命令（后文将在“使用 less 分页文件”中描述）来查看。

由于你的bash历史记录存储在文件中，任何可以读取该文件的人都可以查看。某些命令允许你在与命令本身相同的行中输入密码或其他敏感数据，因此可能存在风险。`~/.bash_history`文件不会记录你在响应其他程序提示时输入的内容，只记录你在bash提示符处直接输入的内容。如果你有选择，应该让需要密码（或其他敏感数据）的命令提示你输入这些数据，而不是在bash提示符处作为选项输入此类信息。

在练习1.1中，你将尝试shell的补全和命令编辑工具。

### 练习 1.1 编辑命令

为了尝试shell的补全和命令编辑工具，请遵循以下步骤：

1. 以普通用户身份登录。
2. 输入`mkdir test`创建一个临时目录。（目录和文件操作命令在第4章中有更详细的描述。）
3. 输入`cd test`进入test目录。
4. 输入`touch one two three`创建几个临时文件。此命令会创建名为one、two和three的空文件。
5. 输入`ls -l ta`，在不按回车键的情况下按Tab键。系统可能会向你发出蜂鸣或显示`two three`。如果没有显示`two three`，再次按Tab键它应该就会显示。这表明two或three都是你命令的有效补全，因为这是test目录中以字母t开头的两个文件。
6. 输入`h`，再次在不按回车键的情况下按Tab键。系统应该补全命令（`ls -l three`），此时你可以按回车键执行它。（你会看到关于文件的信息。）
7. 按向上箭头键。你应该看到`ls -l three`命令出现在命令行上。
8. 按Ctrl+A将光标移动到行首。
9. 按一次右箭头，输入`less`（不按回车）。命令行现在显示`less -l three`。
10. 按一次右箭头，按下Backspace键。命令行现在显示`less three`。按回车键执行命令。（注意，即使光标不在行尾也可以。）这启动了less分页器。（less分页器将在“使用 less 分页文件”中描述）。由于该文件是空的，你会看到一个空屏幕。
11. 按Q键退出less分页器。

## 探索 shell 配置

shell与许多Linux程序一样，通过文本格式的文件进行配置。bash配置文件实际上是脚本，在第9章会有更详细介绍。这些配置文件的示例包括`~/.bashrc`和`~/.profile`。

即使不熟悉shell脚本也可以对这些文件进行简单更改。在你喜欢的编辑器中编辑它们并修改。例如，你可以将目录添加到`$PATH`环境变量，该变量接受冒号分隔的目录列表。

更改bash配置文件要小心，特别是全局配置文件。在更改之前保存原始文件的备份，并通过登录另一个虚拟终端立即测试你的更改。如果你发现问题，请还原保存的副本。

## 使用环境变量

环境变量类似于编程语言中的变量——它们存储通过变量名引用的数据。环境变量与程序内部变量的区别在于它们是程序环境的一部分，其他程序（如shell）可以修改该环境。程序可以依赖环境变量来设置适用于许多不同程序的信息。例如，许多基于文本的程序需要知道你使用的终端程序的能力。这些信息通过`$TERM`环境变量传递，其值可能为`xterm`或`linux`。需要定位光标、显示彩色文本或执行其他依赖特定终端功能的任务可以根据信息自定义输出。

后续将详细描述环境变量及其操作。目前，你应该知道在bash中可以通过赋值（`=`）运算符后跟`export`命令来设置它们。一个有趣的环境变量是`$PS1`变量。它会修改你的shell命令行提示符：

```bash
$ PS1="My New Prompt: "

My New Prompt: export PS1
My New Prompt:
```

你可以将这两个命令合并为单一形式：

```bash
My New Prompt: export PS1="Prompt: "

Prompt:
Prompt:
```

两种方法都会将`$PS1`环境变量设置为新值。在设置环境变量时，你可以省略美元符号`$`，但随后的引用将包含美元符号以识别该变量为环境变量。此后，需要这些信息的程序就可以引用该环境变量。事实上，你可以在shell中直接使用`echo`命令来完成操作：

```bash
$ Prompt: echo $PS1

Prompt:
```

回显`$PS1`变量的值可能会让人有点困惑，因为它只显示了你当前的提示符设置。不过，你可以通过使用`echo`查看`$PATH`变量，来更好地对显示环境变量有一个感受：

```bash
Prompt: echo $PATH

usr/lib64/qt-3.3:usr/local:/bin:/usr/bin:usr/local/sbin:/usr/sbin:/bin:/home/Christine/bin

Prompt:
```

这样稍微好一点了。记住，`$PATH`环境变量为shell提供了一个目录列表，以便在你输入命令名或程序名时进行搜索。

![](img/f74c2c51e1985d4d3a6804ba2887d2f4_83_0.png)

某些环境变量（包括`$PATH`环境变量）是在通过shell配置登录时自动设置的。如果一个程序使用了环境变量，其文档应当说明这一点。

你也可以通过输入`env`来查看整个环境。结果可能是几十行环境变量及其值。第9章将详细描述其中许多变量的含义。

要删除环境变量，请使用`unset`命令。该命令接受环境变量的名称（不带前导`$`）作为选项。例如，`unset PS1`会移除`$PS1`环境变量。但如果你这样做，你将没有shell可用！

## 获取帮助

Linux提供了一套名为`man`的文本帮助系统。该命令名称是`manual`（手册）的缩写，它的条目（man页面）为命令、文件或其他功能的功能提供了简要摘要。例如，若要了解`man`本身的信息，你可以输入`man`。结果是`man`命令的描述。

可以使用选项来浏览特定命令或主题的man页面。例如，要阅读关于`export`命令的内容，可以在提示符下输入`man export`。如果你想学习更多关于shell内置（内部）命令的信息，可以在提示符下输入`man builtin`。

`man`工具默认使用分页器（pager）来显示信息。该程序一次显示一页文本。按空格键向前翻页，按`Esc`后再按`V`向后翻页，使用方向键逐行向上或向下移动，使用斜杠（`/`）键搜索文本，以此类推（输入`man less`了解所有细节，或参考接下来的章节“使用 less 翻阅文件”）。完成后，按`Q`退出`less`以及当前显示的man页面。

你并不局限于在`man`工具上使用`less`分页器。你可以通过`-P`选项更改分页器。例如，如果你决定使用`more`分页器来查询`uname`命令的信息，可以在shell提示符下输入`man -P /bin/more uname`。

偶尔，会出现你不记得要查找的命令的确切名称的情况。`man`工具有一个选项可以帮助你。你可以使用`-k`选项配合一个或两个关键词来搜索man页面：

```bash
$ man -k "system information"

dumpe2fs (8) - dump ext2/ext3/ext4 filesystem information
[...]
uname (1) - print system information

$
```
