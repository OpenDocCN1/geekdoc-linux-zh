## 修改值

要更改文件或目录的权限，你可以使用 `chmod` 工具。该工具接受数值或符号格式。例如，要更改文件权限允许所有人读取和写入，输入以下内容：

| 文件： | 目录 |
| --- | --- |
| 666 -rw-rw-- | 777 drwxrxrwx |
| 644 -rw-r-- | 755 drwxrx-x |

`图 8.3` 显示了新创建的实体在减去 `umask` 值后计算出的默认权限。
