
在被中断后（在本例中通过按下 `CTRL-C`），`ping` 会打印统计信息。成功的 "ping" 将表明网络元素（接口、路由和网关）工作正常。另一件需要注意的是，`ping` 到的机器可能与请求的机器不同。这是因为一台机器可以托管许多不同名称的站点。

# 在网络上传输文件

如果我们不能跨网络移动文件，网络还能算什么呢？有很多可以在网络上传输数据的程序。我们现在介绍其中两个，并在后续章节中介绍几个。

```
ftp
```

作为“经典”程序之一，`ftp` 的其名称源于它所使用的协议——文件传输协议（File Transfer Protocol）。`FTP` 曾是互联网上下载文件最广泛的方法。我们看到浏览器支持它，并且可能会看到以协议 `ftp://` 开头的 URI。

在浏览器出现之前，先有 `ftp` 程序。`ftp` 用于与 FTP 服务器通信，这些服务器包含可以在网络上上传和下载的文件。

`FTP`（其原始格式）是不安全的，因为它以明文发送账户名和密码。这意味着它们没有加密，任何嗅探网络的人都能看到它们。由于原因，几乎所有在互联网上进行的 FTP 操作都是通过匿名 FTP 服务器完成的。匿名服务器允许他人使用登录名“anonymous”和无意义的密码进行登录。

Shell 会话将持续直到用户在远程 Shell 提示符处输入 `exit` 命令或通过关闭远程连接来退出。此时，本地 Shell 会话将恢复，本地 Shell 提示符会重新出现。

也可以使用不同的用户名连接到远程系统。例如，如果本地用户在远程系统上有一个名为 `bob` 的账户，用户可以如下方式登录远程系统上的 `bob` 账户：

```bash
me@linux:~$ ssh bob remote-sys
bob@remote-sys's password:
上次登录：2025年8月30日 周六 13:03:21
bob@remote-sys -JS
```

如前所述，`ssh` 会验证远程主机的真实性。如果远程主机未通过身份验证，将出现以下消息：

```bash
me@linux:~$ ssh remote-sys
############################################################
@ 警告：远程主机身份已更改！ @
############################################################
可能有人正在进行某些坏事！
现在可能有人监听你的通信（中间人攻击）！
也可能只是主机密钥刚刚更改了。
```

远程主机发送的 ECDSA 密钥指纹为

SHA256:9u0dXHzPbzAIJs8ZDANfvy7ksU04MjySpR4KUTSKA。

请联系您的系统管理员。

在 `/home/me/.ssh/known_hosts` 中添加正确的主机密钥以消除此消息。

`/home/me/.ssh/known_hosts:42` 中的违规 ECDSA 密钥

使用以下命令删除：

```bash
ssh-keygen -f /home/me/.ssh/known_hosts -R "remote-sys"
```

主机验证失败。

此消息由两种可能的情况之一引起。首先，攻击者可能尝试进行中间人攻击。这种情况很罕见，大家都知道 `ssh` 会就此警告用户。更可能的元是远程系统发生了某种变化；例如，你的操作系统或 SSH 服务器被重新安装了。对于第一种可能性，不应断然否定。每当出现此消息时，请务必向远程系统的管理员确认。

在确定消息是由良性引起后，在客户端修复问题是安全的。这可以通过警告消息提供的建议来实现：

```bash
ssh-keygen -f /home/me/.ssh/known_hosts -R "remote-sys"
```

如果无效，我们可以使用文本编辑器（可能是 `vim`）从 `~/.ssh/known_hosts` 文件中删除过时的密钥。在之前的的例子中，我们看到：

`/home/me/.ssh/known_hosts:42` 中的违规密钥

这意味着 `known_hosts` 文件的第 42 行包含该密钥。从文件中删除此行，`ssh` 程序即可接受来自远程系统的新的身份验证凭据。

除了在远程系统上开启会话外，`ssh` 还允许你在远程主机执行执行命令并将结果显示在本地系统中，使用方法：

```bash
[me@linuxbox ~]-J ssh remote-sys free
me@twin4's password:
total used free shared buffers cached
Men: 775536 507184 0 110068 154596
-/ buffers/cache: 242520 533016
Swap: 1572856 0 1572856
[me@linuxbox ~]-J
```

这种技术可以用于更有趣的方式，例如下面的示例，我们在远程系统上执行操作并将输出重定向到本地系统的一个文件：

```bash
[me@linuxbox ~]$ ssh remote-sys 'ls * > dirlist.txt
me@twin4's password:
[me@linuxbox ~]$
```
