
在 UNIX 上，“hosts”机制允许一个系统信任另一个系统。这意味着如果用户登录到一个系统，他们就可以登录到他们信任的任何其他系统。只有某些程序使用此功能：`rsh`通知系统打开一个“shell”并运行指定的程序。`Login`在另一台计算机上创建一个交互式的 Telnet 会话。关键点：将后门放在`hosts`文件中。这会告诉系统信任所有人。关键点：该文件包含一个命名主机或 IP 地址的列表。或者，黑客可以伪造受信任系统的 IP 地址。源自 Hacking http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
