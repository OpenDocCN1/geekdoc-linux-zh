
直接利用溢出是困难的，但它历史上曾被用于攻击 `SSHv1` 协议（谢天谢地现在已弃用）；参见 <http://www.kb.cert.org/vuls/id/945216>。

### 克服缓冲区溢出

程序员们花了 30 年时间试图避免导致这些漏洞及其利用的那种疏忽。但正如我们引用对 Mozilla 程序员 Jim Blandy 的 2015 年采访所言：“实验已经完成。不能指望人来编写那种代码”。相反于放弃编写代码，专家们提出了新的“内存安全”语言，如 Mozilla 的 `Rust`、Google 的 `Go` 和 Apple 的 `Swift`，这些语言虽然并非完全无法被利用，但至少扼杀了许多常见的内存漏洞。

但用这些语言重写大型项目不可能一蹴而就，而且对于依赖 `C` 语言特性和速度的大型项目（如 `Linux` 内核）来说，这也不是一个选项。不过，并非全是悲观景象——这些语言在许多地方已被有效使用。Mozilla 自 2012 年起一直在开发基于 `Rust` 的 Web 引擎 `Servo`，`Go` 继续是时髦系统程序员的首选语言。`Swift` 也很流行，但与其引用一个实际例子，我们不妨把你引向 `@swift_on_security` Twitter 账号，在那里你会发现当今信息安全的离经叛道之述。

颠覆利用的一个重大突破在 2005 年左右成为主流，形式为地址空间布局随机化（ASLR，原始 `PaX` 内核补丁出现在 2000 年）。这在程序加载时打乱了所需的内存中的数据。在 ASLR 之前，攻击者可以弄清楚程序的资源（如堆栈和库）在内存中的位置。因此，如果程序存在某种漏洞，可以通过写入数据来利用，这些数据保证会覆盖，例如，堆栈。

在 Word 宏病毒和电子邮件蠕虫如潮水般涌来的中潮中——与数据执行保护（防止指定地址既可写又可执行）一起——这对 `Windows` 来说是个好消息。它消除了一整类漏洞。不再能仅找到任意漏洞并将其用于将任意 `shellcode` 粘入执行堆栈。不幸的是，不法之徒与时俱进，新的、更邪恶的技术（如返回导向编程和堆喷射）演化出来，且至今利用案例层出不穷。

幸运的是，像 `Valgrind` 这样的工具使检测其中的一些（至少）稍微容易一些。

`ASLR` 在 2014 年被扩展到 `Linux` 内核本身，创造了一个新缩写（`KASLR`），并防御恶毒的内核利用。然而，事实证明，`KASLR` 可以通过现代 CPU 上的计时漏洞来击败，因此需要进一步的防御。这些以内核页表隔离（`KPTI`）的形式出现，旨在解决 `Meltdown` 漏洞——尽管该漏洞在 2018 年 1 月公开之前一直被保密。`Meltdown` 意味着通过利用竞态条件，非授权进程可以提取特权信息。

最终，它使流氓进程能够读取内核或其他进程（如密码管理器）的内存。由于可以通过 `JavaScript` 利用，这也意味着一个标签页可以访问另一个标签页中的信息，这相当可怕。欲了解有关 `Meltdown`（及相关 `Spectre`）漏洞的更多信息，请参见我们在 `LXF235` 中的精彩专题。

### 猖獗的恶意软件

随着世界陷入地缘政治混乱，我们越来越多地听到关于国家阴影般的“网络行动”及其内部居住的邪恶天才黑客的消息。朝鲜、俄罗斯、中国和伊朗都被西方政府指责犯有各种网络不法行为。基于泄露的 `NSA` 利用工具 `EternalBlue` 的 `WannaCry` 勒索软件，通常被认为来自朝鲜。这差点使英国的医疗服务瘫痪，若非安全研究员 Marcus Hutchins 的灵巧工作，情况可能会更糟，他能够分析恶意软件并找到一个终止开关。不幸的是，Hutchins 最近承认在 2014 年涉及恶意软件研究的阴影面，犯有电信欺诈罪。自去年发现以来，`Russian` `VPNFilter` 恶意软件已在半百台路由器上检测到。思科研究人员将其描述为“瑞士军刀式黑客工具”，因为它具有模块化结构以及通过固件注入在重启后持续存在的能力。一个模块试图降级 `TLS` 连接，以便可以嗅探并可能篡改 Web 流量。一个主要的命令和控制（`CnC`）服务器被 `FBI` 没收，但感染仍在继续，表明僵尸网络具有相当的韧性。该恶意软件通过从 `Photobucket.com` 下载图像来寻找其他服务器，这些图像的 `EXIF` 数据中隐藏了 IP 地址。

我们将研究看起来唯一的开源杀毒软件 `ClamAV`。实际上我们在 `LXF131` 中很久以前就研究过了，老实说，除了版本号更高，它变化不大。`Ubuntu` 19.04 仓库包含几乎最新的 `ClamAV` 版本（其网站上的 0.100.3 对 0.101.2）。旧版本的程序可用于以前的 `Ubuntu` 版本，或者如果你胆子大可以自行编译——`PPA` 已不存在。一般来说，使用旧版本没问题，因为它仍会下载最新的定义。安装只需：

```
$ sudo apt update
$ sudo apt install clamav
```

`ClamAV` 核心包含三个主要组件：

- `clamscan` – 用于扫描文件和目录的命令行工具。
- `clamd` – 在后台运行，允许在访问时扫描文件的守护进程。
- `freshclam` – 用于更新病毒签名数据库的工具。

守护进程包含在一个单独的包中，因此如果你对按需扫描（可能会减慢系统或消耗大量内存）不感兴趣，别担心：

```
$ sudo apt install clamav-daemon
```

你可以手动运行：

```
$ sudo freshclam
```

来更新数据库，但提供了一个 `systemd` 服务文件来自动执行此操作。事实证明，如果在服务器运行时尝试运行该命令，你会得到错误。可以使用以下命令停止该服务：

```
$ sudo systemctl stop clamav-freshclam
```

这对于想要设置 `cron` 任务的人可能感兴趣（本着 `LXF131` 的精神）。与此同时，让我们继续测试我们光荣的杀毒软件。我们将下载 `EICAR` 测试文件，其中包含 `ClamAV` 应当识别的（无害的！）签名：

```
$ wget https://www.eicar.org/download/eicar.com.txt
$ clamscan eicar.com.txt
```

你应该看到与截图匹配的输出（见右上）。对于通用按需使用，你只需调用 `clamscan` 并附带你想扫描的文件或目录。若要深入目录或整个文件系统，请使用命令：

```
$ clamscan --recursive /
```

如果你感到偏执，可以从 `https://github.com/extremeshock/clamav-unofficial-signatures` 仓库下载一些第三方签名。这些来自各种来源（包括专注于 `Linux` 的 `Linux Malware Detect`，另一种开源恶意软件扫描器），会增加误报几率，但也可能增加你的安心感。

### 保护您的服务器

`Linux` 服务器比 `Linux` 桌面系统提供了更有吸引力的攻击目标，而且与接管 `Windows` 桌面机器相比，它们可能更具利用价值。互联网上有大量的 `Linux` 服务器，其中许多拥有可观的计算能力，并连接着带宽极大的网络链路。因此，它们是挖矿攻击或将其转化为垃圾邮件僵尸网络（`spam-spewing zombies`）的理想目标。
