### process ID 进程标识

内核用于唯一标识进程的整数。PID 由 `fork` 系统调用返回，并传递给 `wait()` 执行操作。用户可以轻松获取进程列表（Windows 上使用管理器，Unix 上使用 `ps`）以查看情况。关键点：木马、根特程序和其他软件会试图从进程列表中隐藏自己，通过为打印列表提供替换项（如 `ps`），或通过挂钩枚举进程的系统调用。来自 Hacking-Lexicon

### process identifier 进程标识符

# procmail

多功能且易于使用的邮件处理器。可用于创建真正的邮件服务器，将你的输入分类到单独的文件夹/文件中（排序一个或多个邮件列表或对邮件进行优先级排序时非常方便），对你的邮件进行预处理，在邮件到达时启动任何程序（以针对不同类型的邮件生成不同的任务），或自动选择某些传入邮件进行发送。源自 Debian 3.0 APT

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# procmail-lib

一个包含实用用 `procmail` 配方的库。包括用于自动确认入站邮件的配方、识别 Subject: 头部中 `procmail` 脚本命令的配方、用于提取地址的配方，以及用于 `procmail` 脚本的“list”脚本。源自 Debian 3.0r APT
