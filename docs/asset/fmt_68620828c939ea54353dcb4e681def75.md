# 引言

称我们为传道者、街头传教士或纯粹的狂热分子吧：我们热爱 Unix 及其所有的衍生版本。当我们获得机会写这本书时，我们认为这是一个展示这一优秀操作系统的绝佳机会，并帮助那些初接触该操作系统的用户学习如何充分利用它。Unix 是一个强大且稳健的操作系统，很少崩溃，并且即使对于最随意的用户也能提供远超其他系统提供的个人账户管理功能。
