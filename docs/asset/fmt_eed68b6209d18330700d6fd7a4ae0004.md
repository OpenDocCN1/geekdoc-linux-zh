
# POWER4 架构与 pSeries 服务器概述

`POWER4` 架构针对技术和科学市场进行了优化。`p690` 还引入了 `pSeries` 逻辑分区 `logical partitioning`，该技术源自 IBM 丰富的 mainframe 经验。

## p690 旗舰服务器

凭借最高达 32-way `SMP` 配置的 `POWER4` 处理器，运行频率为 `1.5 GHz` 或 `1.7 GHz`，内存容量为半兆字节 `512 GB`，`pSeries` 家族的旗舰产品是 `p690`，这是一款于 2001 年发布的 datacenter-class 服务器。它是首款使用 `POWER4` 处理器的 `pSeries` 服务器，目前提供最高达 32-way `SMP` 配置的 `POWER4` 处理器，运行频率为 `1.5 GHz` 或 `1.7 GHz`，内存容量为半兆字节 `512 GB`。`Logical partitioning` 在大多数基于 `POWER4` 的 `pSeries` 服务器上均受支持，详见本章后文的 “A Closer Look”。

## pSeries 660

`pSeries 660` 共有三种型号——`660-H0`、`660-H1` 和 `660-M1`，均采用机架式 `CEC` `Central Electronics` 抽屉，包含处理器、内存和 `I/O`，外加一个或多个 `I/O` 抽屉，包含 `PCI` 适配器插槽、存储设备和 `I/O` 端口。`pSeries 660` 型号 `H0` 和 `H1` 在电子上等同于 `p620-6F0` 和 `p620-6F1`。`p660-M1` 提供最高达八个 `POWER4` 处理器，频率为 `750 MHz`，在事务处理、Web 服务和 Java 应用的行业标准基准测试中提供出色的性能。

## pSeries 670

`pSeries 670` 是一款 4- 和 16-way 中端服务器，定位在 `p650` 与 `p690` 之间。它采用运行频率为 `1.5 GHz` 的 `POWER4` 处理器芯片模块 `MCMs`，支持 `LPAR`，内存最高达 `256 GB`，可连接三个 `I/O` 扩展抽屉。对于 `p670`，即 `pSeries` 中端线的顶端，IBM 提供转换为 `p690` 的型号转换，以满足客户增长所需的扩展。

## pSeries 655

基于 `POWER4` 的集群优化型 `p655` 在 `pSeries` 家族中填补了特殊细分市场。它是一种高密度配置，单台 24 英寸机架内最高可达 12 个处理器，使 `p655` 成为 `AIX 5L` 应用的理想选择。`Logical partitioning` 在大多数基于 `POWER4` 的 `pSeries` 服务器上均受支持，详见本章后文的 “A Closer Look”。

## IBM eServer Cluster 1600

`IBM eServer Cluster 1600` 本身并非一种产品，而是一个名称，IBM 所有基于 AI 的集群技术 `pSeries` 服务器、互连选项和软件产品均可以此进行订单和管理。`Cluster 1600` 是 `RS/6000 SP` 技术的逻辑扩展，该技术允许将数百个处理器在巨并行系统中组合，例如深蓝号 `1997` 年击败国际象棋大师加里·卡斯帕夫的系统和 `ACI World` `2000` 年位于劳伦斯·利弗浦国家实验室的世界最快超级计算机。最初，`RS/6000 SP` 系统中的服务器是经过特殊设计和封装的 `SP` 节点，其采用了与 `RS/6000 SMP` 计算机相同的 `PowerPC` 和 `POWER` 架构。在过去的几年里，将 `pSeries` 和 `RS/6000` 服务器作为“节点”连接到 `SP` 系统中的支持已日益增长。`pSeries 65` 的封装方式与早期的 `SP` 节点类似，使其成为需要最高处理器密度 `最小“占用空间”` 应用程序的理想选择。`Cluster 1600` 允许用户将 `pSeries` 服务器和或这些服务器的 `LPAR`、现有的 `SP` 节点以及高速互连技术集成到运行 `IBM AIX` 并行系统程序 `PSSP` 软件的统一系统中。

如前所述，像 `p620` 和 `p660` 这样的 `pSeries` 服务器取代了旧的 `RS/6000` 型，提供了类似的性能点和封装选项，但使用了更先进的技术。其他 `pSeries` 模型——如 `p610`、`p640` 和 `p690`——旨在满足新市场细分领域用户的需求。最近，采用最新 `POWER4` 和 `POWER4+` 技术、逻辑分区、行业标准 `I/O` 架构以及对 `AIX 5L` 和 `Linux` 支持的系统，确立了 `pSeries` 服务器独特的“身份”，使其与前身 `RS/6000` 家族区分开来。

## RS/6000 仍在供应的型号

目前，仍有几种 `RS/6000` 系统在供应，主要解决工作站和低成本服务器的需求。但预计这些产品将在不久后停止销售。

### RS/6000 Model 150

`RS/6000 Model 150` 是一款基于 `PowerPC 604e` 的系统，提供 `250 MHz` 或 `375 MHz` 两种速度。它也非常适合用作负载组。

### RS/6000 B150

`RS/6000 B150` 是一款紧凑型机架式服务器，使用与 `375 MHz` 的 `Model 150` 相同的 `PowerPC 604e` 电子设备。它仅有 `2U` 高，可以在行业标准的 `19` 英寸机架中安装许多 `B50`。`B150` 针对互联网服务提供商 `ISP` 和应用服务提供商 `ASP`，用于托管、防火墙和 Web 缓存等应用。

### RS/6000 Model 170

`RS/6000 Model 170` 是该产品线第一款 64 位单处理器工作站。其 `POWER3-II` 微处理器采用了 IBM 创新的铜制设计，运行速度为 `333 MHz`、`400 MHz` 或 `450 MHz`。`Model 170` 具有出色的浮点性能，当配置了 3D 图形适配器 `也称为“图形加速器”` 时，它是一个令人印象深刻的图形工作站和技术负载系统，且价格非常有吸引力。作为最便宜的 64 位系统，它是软件开发和测试的良好选择，同时也是技术和商业负载极具性价比的入门级服务器。

### RS/6000 Model 270

`RS/6000 Model 270` 是一款 1 到 4 路 `SMP` 系统，使用运行频率为 `375 MHz` 或 `450 MHz` 的 `POWER3-II` 多处理器。配备 3D 图形适配器卡，`Model 270` 工作站于 3D 图形性能方面表现出色。它也是技术和商业负载极具性价比的中端服务器。

## 入门服务器特征与性能

处理器速度或时钟频率仅是决定系统级性能的因素之一，而 `pSeries 610` 的设计为该价位的系统为内存和 `I/O` 设备提供了卓越的内部带宽。如图 1.4 所示，处理器到内存的总线宽度为 `128` 位，加上 `8` 位 `ECC`，在具有双比特错误检测和单比特错误纠正的情况下产生 `1.44 Gbps` `每秒十兆` 的最大带宽。`I/O` 总线可以在校验检查下运行高达 `528 Mbps`。这种速度和内部错误检查功能为入门级 `UNIX` 服务器提供了高系统性能。
