
#!/usr/bin/perl

$x = 1;

until ($x <= 5) {

  print("\\$x is now $x\n");

  ++$x;

}
```
在这里，大括号之间的语句将一直执行，直到表达式 `$x <= 5` 为真为止。在这种情况下，该表达式在第一次求值时就是真，这意味着 `print()` 语句永远不会执行。要修复这个问题，请反转算术比较的方向：

```perl
#!/usr/bin/perl

$x = 1;

until ($x > 5) {

  print("\\$x is now $x\n");

  ++$x;

}
```

现在这产生了与包含前面 `while` 语句的程序相同的输出。

**注意：** 如果你使用 `while`、`until` 或任何其他循环语句，你必须确保该语句不会无限循环下去：

```perl
$x = 1;

while ($x == 1) {

  print("\\$x is still $x\n");

}
```

在这里，`$x` 始终为 `1`，`$x == 1` 始终为真，`print()` 语句被无限次重复。

Perl 不会检查像上面那样的无限循环。确保无限循环不发生你的责任！

## 使用单行条件语句

如果只有在特定条件为真时才执行一条语句，你可以使用单行条件语句来编写你的条件语句。例如，与其写成

```perl
if ($x == 14) {

  print("\\$x is 14\n");

}
```

你可以使用以下单行条件语句：

```perl
print("\\$x is 14\n") if ($x == 14);
```

在两种情况下，如果 `$x` 等于 `14`，`print()` 语句都会执行。

你也可以在单行条件语句中使用 `unless`、`while` 或 `until`：

```perl
print("\\$x is not 14\n") unless ($x == 14);

print("\\$x is less than 14\n") while ($x++ < 14);

print("\\$x is less than 14\n") until ($x++ > 14);
```

注意在最后两个语句中自增运算符 `++` 是多么好用：它允许你一次性地比较 `$x` 并给它加 `1`。这确保了单行条件语句不会无限执行。

## 使用 `for` 语句循环

大多数循环——执行执行一次的代码段——都使用计数器来控制并最终终止循环的执行。这里有一个与你目前看到的类似的示例：

```perl
$count = 1; # 初始化计数器

while ($count <= 10) { # 在重复十次后终止

  print("the counter is now $count\n");

  $count += 1; # 增加计数器

}
```

如你所示，循环过程由三个部分组成：

- 计数器变量的初始化
- 确定是否终止循环的测试
- 循环中语句执行后计数器的更新

由于循环经常包含这三个部分，Perl 提供了一种通过使用 `for` 语句一次性完成它们的快速方法。下面的示例使用了 `for` 语句，行为与你刚刚看到的示例相同：

```perl
for ($count = 1; $count <= 10; $count += 1) {

  print("the counter is now $count\n");

}
```

在这里，循环的三个部分都出现在同一行中，用分号隔开。因为所有部分在一起，更容易记住提供所有部分，这使得编写出进入无限循环的代码变得更加困难。

## 遍历列表循环：`foreach` 语句

你看到的所有循环示例都使用标量变量作为计数器。你也可以使用 `foreach` 语句使用列表作为计数器：

```perl
#!/usr/bin/perl

@list = ("This", "is", "a", "list", "of", "words");

print("Here are the words in the list: \n");

foreach $temp (@list) {

  print("$temp ");

}

print("\n");
```

在这里，由 `foreach` 语句定义的循环为列表 `@list` 中的每个元素执行一次。结果输出为：

`Here are the words in the list:`
`This is a list of words`

$temp = 1;

@list = ("This", "is", "a", "list", "of", "words");
