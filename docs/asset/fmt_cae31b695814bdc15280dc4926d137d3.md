# SUSE Linux Enterprise Server 与 PostScript

`PPD`（PostScript Printer机描述）是描述 PostScript 打印机属性（如分辨率）和选项（如双面单元）的计算机语言。

这些描述对于使用各种打印机选项是必须的。如果没有 `PPD` 文件，打印数据将以原始状态到打印机，这通常不是所需要的。
