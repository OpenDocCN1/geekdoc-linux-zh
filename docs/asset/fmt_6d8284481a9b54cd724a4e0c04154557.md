
```
rich@ubuntu2404: ~ $ zsetattr testfile1.txt user.name "Rich Blum"
rich@ubuntu2404: ~ $ zlistattr testfile1.txt
user.name

rich@ubuntu2404: ~ $ zgetattr testfile1.txt user.name
Rich Blum
rich@ubuntu2404: ~ $
```

设置文件的扩展属性后，`zlistattr`命令显示该扩展属性存在，但不显示其值。要查看值，我使用了`zgetattr`命令。

要移除已安装的模块，请使用`-u`参数，并附上模块名称：

```
$ zmodload -u zsh/attr
$ zgetattr testfile.txt
zsh: command not found: zgetattr
$ 
```

这使得你可以通过标准的`zsh`Shell启动文件轻松管理模块（参见本章前面的“zsh Shell文件”部分）。

> **注意**
>
> 通常的做法是将`zmodload`命令放置在`$HOME/.zshrc`文件中，以便你喜欢的函数能自动加载。

# 使用 zsh 编写脚本

`zsh`Shell的主要目的是为Shell程序员提供高级编程环境。鉴于此，`zsh`Shell提供了许多使Shell脚本编写更容易的特性也就不足为奇了。

## 数学运算

正如你所预期的那样，`zsh`Shell允许你轻松执行数学函数。类似于`ksh93`Shell（参见第25章，“Korn Shell”），`zsh`Shell在其所有数学运算中完全支持浮点数。

### 执行计算

`zsh`Shell支持执行数学运算的两种相同方法，与`ksh93`Shell一样：

- `let`命令
- 双括号

当你使用`let`命令时，应该用双引号括住操作以允许空格：

```
$ let value1=" 4 * 5.1 / 3.2 "
$ echo $value1
6.374999999999999991
```

请注意，使用浮点数会引入精度问题。为了解决这个问题，使用`printf`命令并指定所需的十进制精度以正确显示答案始终是个好主意：

```
$ printf "%.3f\n" $value1
6.375
$
```

现在好多了！

第二种方法是使用双括号。此方法包含两种定义数学运算的技术：

```
$ value1=$(( 4 * 5.1 ))
$ (( value2 = 4 * 5.1 ))
$ printf "%.3f\n" $value1 $value2
20.400
20.400
$
```

请注意，你可以将双括号仅围绕操作（前面加上美元符号）或围绕整个赋值语句。两种方法产生相同的结果。

## 数学函数

在`zsh`shell中，内置的数学函数要么极为丰富，要么完全缺失。默认的`zsh`shell不包含任何特殊的数学函数。但是，如果你安装`zsh/mathfunc`模块，你将获得远超日常需求的数学函数：

```
$ value=$(sqrt(9))
zsh: unknown function: sqrt
$ zmodload zsh/mathfunc
$ value=$(sqrt(9))
$ echo $value
3.
$
```

很简单！现在你随时可以使用一整套数学函数库。

> **注意**
>
> 若要查看`zsh/mathfunc`模块提供的所有数学函数的完整列表，请参阅`zshmodules`的手册页。

## 结构化命令

`zsh`shell为你的shell脚本提供了常见的结构化命令集：

- `if-then-else`语句
- `for`循环（包括C风格）
- `while`循环
- `until`循环
- `select`语句
- `case`语句

`zsh`shell对这些结构化命令使用的语法与你从`Bash`shell中习惯的相同。`zsh`shell还包含一种名为`repeat`的不同结构化命令。`repeat`命令的格式如下：

```
repeat param
do
    commands
done
```

`param`参数必须是一个数字或评估结果为数字的数学运算。

然后`repeat`命令会执行指定次数的相应命令：

```
% cat test1
#!/bin/zsh
# using the repeat command

value=$(( 10 / 2 ))
repeat $value
    do
        echo "This is a test"
    done
$ ./test1
This is a test
This is a test
This is a test
This is a test
This is a test
$
```

此命令允许你基于计算结果重复执行代码段固定次数。

### 函数

`zsh`shell支持通过使用`function`命令或使用带括号的函数定义名称来创建自定义函数：

```
% function functest1 {
function> echo "This is the test1 function"
function> }
% functest2() {
function> echo "This is the test2 function"
function> }
```

```
$ functest1
This is the test1 function
$ functest2
This is the test2 function
$
```

正如`Bash`shell函数（参见第17章，“创建函数”）一样，你可以在shell脚本中定义函数，然后使用全局变量或向函数传递参数。这里是一个使用全局变量的示例：

```
$ cat test2
#!/bin/zsh
# testing functions in zsh

dbl() {
  value=$(( $value * 2 ))
  return $value
}
value=10
dbl
echo "The answer is $value"
. ./test2
The answer is 20
$
```

你不必将函数放在shell脚本内部。`zsh`shell允许你在单独的自定义文件中定义函数，当shell尝试解析函数名称时，它可以访问这些文件。

`zsh`shell通过`fpath`环境变量查找函数。你可以将函数文件存储在此路径的任何目录中。以下是我的Linux工作站上的`fpath`值：
