
# 系统分析

应当借助模型和仿真来寻求评估——即使可以使用专家意见来代替分析方法，系统结构建模也可能提供指导。参见`MODEL THEORY`；`SIMULATION`。

需要重新制定的模型。分析过程持续进行，直到证据表明系统结构是合适的；它具有足够的价值来为系统设计者或决策选择的问题提供答案。参见：`OPTIMIZATION`；

评估系统设计的需求必须进行汇总并明确。此外，必须遵循结合评估因素和决策的分析过程。设计选择是符合客户需求的优先选择。参见`SYSTEM`、`OPERATION-RESEARCH`；`OPTIMIZATION`；`SYSTEMS ANALYSIS`。[W.F.]

按照通常的发展，系统分析在“硬”系统中被定义且结构良好，这些是指定义良好且结构良好的系统（例如，血库和集成系统、复杂的工业流程）。软系统分析是最好的替代方案。相比之下，软系统关注涉及定义模糊和非结构化系统的问题，尤其是高复杂的系统。这些系统通常涉及交互的公共和私立组织（例如，福利系统的设计、公司结构的结构和重要性）。这些系统是有问题的，事实上，问题的系统本身并非分析。软系统的目标涉及人类参与者。

系统分析：将数学方法应用于研究复杂的人类系统。系统是对象的排列或集合，为了共同的发挥功能。这些对象可能包括数学建模、仿真、网络、组织或社会群体，以及生物实体。系统中的一切都被视为系统环境的一部分。系统在环境中运行，该环境可能是物理的、社会的或区域生态系统，如高速公路系统、公司的生产流程、天线系统和导弹的制导系统。

还需要大型系统的需求，其定义最为复杂。找到分析比工业组织、大陆污染问题或全球农业系统更大的系统的方法至关重要。这些是具有解决方案标准的多媒体（多维度）问题。此类系统的分析可以通过基于计算机的方法或非常初步的方法进行。但必须谨慎地处理，要意识到由于个人和社会的复杂性，所采用的方法和员工都是分析性系统。参见`SYSTEM THEORY`；`LINEAR SYSTEM ANALYSIS`。[S.G.]

系统分析涉及对包含人类要素的系统以及系统人类要素与其物理和机械组件之间行为的研究。例如，政策如政府福利系统、刑事司法系统、教育系统、公共安全系统和废物管理系统。系统分析的例子是分配系统以及石油公司的生产、精炼和市场系统。具有物理环境组件的例子是大气和水体。将数学概念直接应用于考虑人类要素的系统研究，必须受到基础模型局限性的限制。一个研究领域是系统分析。公共政策分析是对政府政策或私有领域的研究。参见`OPERATIONS RESEARCH`；`SYSTEMS ANALYSIS`。

系统由相互相关的对象组成，对象具有许多可衡量的属性。构建系统的数学模型，然后可以用于研究现实系统在初始条件下的如何运行，并系统地改变属性值和关系。参见`MODEL`。

系统分析是一个迭代过程，反复循环以下若干相互独立的阶段：1) 问题陈述根据其元素、目标、约束、标准、参与者（决策者、系统参与者、相关者）和其属性进行定义；2) 分析通过数学公式表示，在此期间开发并测试系统的数学描述；3) 评估，对所有备选结果进行评估，通过标准对备选设计进行评估和排序；以及4) 选择并实施最优解决方案。该过程包含了反馈回路，在其中会考虑其他阶段的结果。例如，在实施阶段，方案的实施可能会违反约束，从而导致数学上的[问题]。

系统架构创建具有特定能力的元素，其中任何一个都不会产生清晰的输出。“架构”一词用于描述系统的工程网络、指挥控制系统、软件和硬件接口。事实证明，在给定架构水平开发的软件会影响大型项目的成功或失败（不可避免的）。技术进步要求复杂性及其后果。系统由相似的元素组成。它们产生了元素本身无法实现的结果。增加值来自非常不同事物之间的交互或接口。例如，开环和闭环反馈（非常！）但在一个复杂的时代：复杂性可以通过标准规则或其他方法来处理。

随着项目变得越来越复杂和多学科化，需要使用新的结构来获得成功。分析不仅局限于已使用的系统。考虑到不同客户、系统政府和机构的多样性，系统需要唯一的优化解决方案。某些方案可能足够好，选择更多取决于辅助因素或成功标准，而非详细分析。

概念阶段。随着复杂系统的构建，其成功与否在项目早期就决定了。在项目早期阶段，关键假设、约束、选择和优先级决定了将成为什么。

评估与评价；还提供了该计划所有方面的文档记录。它将系统管理应用到问题的各个方面。这种方法的一个主要优势是它将大型复杂的问题分解为更容易理解、解决和处理的小问题。参见：系统分析；系统工程。[J.P.]

## 合拱

通常情况下，当三个物体中的一个物体上的观测者看到另外两个物体处于对冲或合相位置时，就发生了合拱（`syzygy`）。对冲发生在从该侧面看去，两个物体在天空中呈 180° 角度分布。合相发生在两个物体在天空中也彼此靠近时。

日食和月食是合子的戏剧性结果。在日食期间，当月球处于新月阶段时，太阳、地球和月球的排列近乎完美，使得月球的影子落在地球上。月食则发生在满月期间，月球穿过地球的阴影。

### 合拱 (Syzygy)

合拱是指太阳系中（或任何其他绕恒星运行的物体系统内）三个天体的对齐。合拱通常指在新月或满月期间太阳、地球和月球的对齐。并非每次合拱都是完美的排列，而且由于太阳系中任何三个天体的轨道平面很少重合，处于合拱状态的三个物体的几何中心几乎不在同一条直线上。参见：相位；太阳系。

掩星（`occultation`）是另一种可以在合拱期间发生的食现象。对于地球上的观测者来说，当看到月球通过行星或其他太阳系其他成员的前方时，就发生了掩星。月球遮挡恒星不被视为合拱，因为恒星远在太阳系的边界之外。参见：掩星。[H.PC.]

## T

### T 金牛座星 (T Tauri star)

`T Tauri star`一类非常幼的、光学、太阳质量恒星的成员，具有变变性和质量证据等特性。金牛座星是通过其异常强烈的发射线被发现的。许多辐射和超声波流出被定义为经典金牛座星（通过氢发射线调查识别），以及通过其 X 射线发射发现的弱线金牛座星或 T 金牛座星。描述的某些现象可能归因于它们被行星云和尘埃所包围。

然而，这些结构通常发育良好，或者完全不存在。板状体（Tabulata）根据柱构造（colulae）之间通信（孔隙或连接小管）的结构排列以及一系列灭绝形式，分为六个子集——Lichenina、Sarcinina、Favositina、Halysita、Helioporta。潮汐柱构造由碰撞事件的强度和环境条件决定。潮汐柱构造在温暖到避风的环境中最稀少且发育良好，特别是在干旱地区。

T 金牛座星之所以被探测到，是因为亮度的变化表明它们尚未达到某一阶段。它们的温度和亮度差异很大。锂缺乏的存在证实了其 10,000,000 至 10,000,000 年的年龄。

在经典金牛座星中观测到的异常强烈的发射线具有质量流出的典型延伸风特征。例如，在光学图像中可以看到极强的 100 km/s (60 m/s) 流出，从恒星的流道可以看到高速的、正向的喷射。它们已经可见，而 T 金牛座星仍处于吸积其起源气体的过程中。根据恒星的理论，残留物质被驱逐到盘中。盘和气体是辐射的主要来源。过量的紫外线以及最极端的谱线可能源于旋转盘与更旋转的恒星之间的边界层。

T 金牛座星与原恒星云相似，行星在其中形成。看起来很有可能，太阳在其早期阶段经历过金牛座阶段，金牛座星可能是其他行星系统的摇篮。参见：原恒星；太阳系；恒星演化。

### Tacan

`Tacan`是 rho-theta 导航系统的一员，它通过与信标的距离和方位来增强飞机的位置。此类系统能够准确地回答航海员“在什么方向”和“多远”的问题。它们基于地面、离岸或油井信号。此类系统的主要缺点是方位误差随着与信标距离的增加而增大。信号强度的降低会导致严重的衰减。
