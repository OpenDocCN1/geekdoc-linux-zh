使用 `iostat` 的一种实用方法是使用间隔选项，该选项提供可能有助于在物理硬盘之间平衡负载的信息。`-1` 选项会重复显示 `count` 次。如果未指定等待间隔，默认值为 1 秒。

### sar 实用程序

`sar` 实用程序使用 `-b` 选项报告 I/O 和传输速率。`sar -b` 报告以下 I/O 速率：

- `tps.` 每秒向设备发出的传输次数。
- `rtps.` 每秒向设备发出的总读取请求数。
- `wtps.` 每秒向设备发出的总写入请求数。
- `bread/s.` 每秒从设备读取的总数据量（以块为单位）。
