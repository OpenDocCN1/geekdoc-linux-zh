# 心理语言学

心理学是一个源自语言学的研究领域，关注语言的问题。心理学家长期以来对语言领域感兴趣，而且语言学是一门比心理学更古老的科学；这两个领域的科学家自 20 世纪 50 年代以来一直努力解码人类。乔姆斯基的工作改变了这个领域，让心理学家充分意识到他们对语言结构缺乏知识，以及尝试这种尝试是徒劳的。因此，心理学家自 20 世纪 60 年代以来一直尝试更好地理解人类语言抽象规则如何通过语音音频介质从人向人地传递有意义的信息。研究还涵盖了语言的演化发展、语言的生物学基础和神经系统；句法、意义的规则以及语言学习的过程。

心理学研究人类行为和心理过程。心理学深受应用研究和实验研究的影响。研究和应用心理学中代表了许多领域。

心理学研究人员研究广泛的领域。认知研究通常被包含为主观认知研究以及中央心理过程如何运作、大脑与思维的关系，以及翻译系统如何将物理规律转化为认知科学，这源于科学、认知心理学、心理心理；语言学、神经心理学和人类学的共同基础。人类注意的研究是处于所有领域中心的认知科学。

社会心理学涉及个体与群体之间的互动，以及群体对个人、态度和行为的影响。心理学领域处理社会背景下的从众性、权威、偏见、说服和决策问题。

发展心理学有三个分支：终身发展、儿童发展和老年。该领域的大多数研究集中在能力、社会关系和情感发展上。

心理学家通常被称为心理学家（`psychologist`）；精神分析学家是精神分析治疗的专家，许多心理学家经医学考评委员会认证为精神分析学家。精神分析学家并不都是精神分析学家。

神经心理学家是具有实验或临床背景的心理学家，但他们并不作为心理学家认证。他们用临床神经学方法治疗脑损伤个体。

临床心理学家在咨询中与客户、群体工作，并在诊所或与健康专业团队合作。专业心理学家在各种环境中工作，解决从压力危机、物质滥用到精神症和严重精神障碍的问题。

法庭心理学工作涉及人类因素，这些因素适应于机器与其人类操作之间的接口设计。它处理软件和硬件计算机设计。工业心理学也包括涉及管理组织和咨询的人员。

在法庭心理学中，法律基于心理学的自然结果。心理学家参与了陪团选择、证据组织、证人证言以及法庭案件。法庭心理学家和心理学家也被要求诊断潜在的精神障碍以及是否有受审能力。

# 免疫学

通过学科的交叉，对免疫系统、内分泌系统和激素的研究已演变为对适应过程产生更全面的理解。曾一度，免疫系统是一个独立的防御机制，保护有机体受异物侵害；然而，免疫系统也具有自我识别的能力。然而，来自行为和脑科学的交叉数据表明，免疫的调节起着关键作用。心理神经免疫学强调这些系统之间关系的功能性——不是取代而是补充对系统内部运作机制的传统分析——这些相互作用对健康和疾病的意义。神经免疫学中导致免疫的行为改变可能具有临床和治疗意义，在充分了解这些异常和病理状态的程度之前，这些意义将无法得到充分重视。内分泌系统（脊椎动物）；免疫学；神经系统（脊椎动物）；`[R.A.]`

## 脑-免疫系统

各种免疫系统刺激的证据表明，初级和二级淋巴组织受交感神经系统和针对激素和神经递质的淋巴细胞激活。垂体分泌的物质也作用于淋巴细胞因子，这些因子本身产生神经肽物质。这些是解剖学和神经学的通信通道，为免疫刺激的观察提供了功能性关系。

## 精神病理学

心理学的一个学科，研究特征不同疾病的认知、情感和行为。精神病理学侧重于影响思考、感受和行动的因素。精神病理学强调影响思想的药物，因此与精神医学有联系。精神病理学与精神医学密切相关，但不完全相同，分为四类主要的精神障碍：心境、焦虑和分裂症。

# 心理物理学方法

物理刺激与感官反应之间关系的研究（例如光的亮度和糖溶液的浓度或甜度）建立了这些关系。为了建立这些关系，需要对物理量表和主观量表进行测量。此类量表不是直接通过观察获得的，而是总结了关系与反应之间的差异。详见“感觉”（`SENSATION`）。

其他研究方法包括量表技术，该技术通常用于没有物理维度对应的主观维度，例如食物偏好。详见“多重”（`MULTIPLE`）。

1860 年，`G.` 费纳（`Fechner`）设计了心理物理学方法来测量阈值，定义了感知所需的最小刺激强度。阈值被定义为刺激可检测到的最小变化。所有数量都必须定义为统计平均值。费纳决定使用间度法（也称为最小变化法）和恒定刺激法。

在限度法中，实验从一个弱到受试者无法检测的刺激开始。在呈现过程中，刺激强度以小步长增加，受试者在每次呈现后报告刺激是否被感知，直到被检测到。然后开始下降序列，刺激强度从阈值以上的值开始逐级减小，直到刺激从感官中消失。通常会给出许多这样的序列。

在测量差异时，本质上涉及该程序，只是受试者现在要在大量的此类试验中报告两个刺激之间的差异，计算出这四个阈值中的每一个。

通过恒定刺激法测量阈值，实验者选择少量的刺激（此前已在该方法的内部中使用过），并以不规则的顺序在大量试验中呈现它们。每次呈现刺激时，受试者都会报告其存在或不存在。

数据提供了每个刺激产生感觉报告的比例。人们可以借此估计产生感觉的 50% 的值，该值定义为绝对阈值。通过这种方法可以获得敏感性的提高。

费纳建议使用这种关系来测量主观量表或尺度。将差异或显著差异（`nd`）作为主观单位，并将绝对阈值作为量表的零点。例如，光亮的主观量表如果被设定为高于阈值 100 个单位，则将被指定。主观量表被定义为物理量表的非线性函数。费纳提议使用这种关系来测量主观量表或尺度。
