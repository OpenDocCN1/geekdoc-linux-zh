## 常用目录

文件操作

你将在计算机上找到以下目录。

| 目录 | 说明 |
| :--- | :--- |
| `/` | 这是存储计算机上所有目录和文件的主目录。 |
| `/bin` | 包含运行所必需的程序。 |
| `/dev` | 包含 Linux 使用的硬件设备的文件，如显示器或打印机。 |
| `/etc` | 存储指定设置的文件，例如显示器分辨率设置。 |
| `/home` | 包含计算机上设置的每个用户的目录。每个目录存储一个用户的个人文件和设置。 |
| `/lost-found` | 存储损坏或丢失的文件。 |
| `/mnt` | 显示软盘或光驱驱动器的内容。 |
| `/root` | 存储 root 账户的个人文件和设置。root 账户是安装 Linux 计算机时设置的管理员账户。 |
| `/sbin` | 存储用于执行管理任务的程序。 |
| `/usr` | 包含人们经常访问的程序和信息，如游戏和帮助文件。 |
