### `dict([m])` or `dict(key1 = value1, key2 = value2, ...)`

表示一个字典。如果没有提供参数，则返回一个空字典。如果 `m` 是一个映射（例如字典），则返回一个与 `m` 具有相同键和值的新字典。例如，如果 `m` 是字典，`dict(m)` 仅仅是创建它的一个浅拷贝。如果 `m` 不是字典，它必须支持迭代，并产生一个 `(key, value)` 元组对序列。这些元组对被用于填充字典。`dict()` 也可以通过关键字参数调用。例如，`dict(foo=3, bar=7)` 创建字典 `{'foo': 3, 'bar': 7 }`。

### `enumerate(iter, initial_value)`

评估表达式。`expr` 是字符串、文件或由 `compile()` 创建的对象。`globals` 和 `locals` 是映射对象，分别定义操作的全局和局部命名空间。如果省略，表达式将在调用者的命名空间中求值。最常见的情况是将 `globals` 和 `locals` 指定为字典，高级应用程序可以使用自定义映射对象。

执行 Python 语句。`code` 是字符串、文件或由 `compile()` 创建的对象。`globals` 和 `locals` 分别定义操作的全局和局部命名空间。如果省略，代码将在调用者的命名空间中执行。如果没有提供全局或局部字典，该函数的行为在不同 Python 版本之间略有不同。在 Python 2 中，`exec` 被实现为一个特殊的语言语句，而 Python 3 将其实现为标准库函数。这种实现的副作用是可以自由地修改调用者命名空间中的局部变量。在 Python 3 中，你可以执行产生更改的代码，但这些更改在 `exec()` 调用自身后似乎没有任何持久影响。这是因为 Python 3 使用 `locals()` 来获取本地名称（如果未提供）。正如你在 `locals()` 的文档中所看到的，返回的字典仅允许检查，不可修改。
