# efax

`efax` 是一个小型 ANSI POSIX 程序，为使用任何 1 类或 2 类调制解调器的真真应用提供数据传输功能。如果你想发送真真并拥有 1、2 类调制解调器，则必须安装 `efax`。来自 Mandrake 9.0 RPM

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

# efax

发送和接收真真的程序。`efax` 是一个小型 ANSI POSIX 程序，为使用 1 类或 2 类调制解调器的真真应用提供数据传输功能。另一个程序在真真、文本、位图和灰度格式之间进行转换。一个脚本为 `efax` 和 fix 程序提供了简单的用户界面。它允许你将文本或 Postscript 文件作为文件发送，并接收、打印收到的真真。真真幻灯片需要 ghostscript 包，传入的真真也需要。注意，你可能需要根据需求调整 `/efaxrc`。来自 Debian 3.0
