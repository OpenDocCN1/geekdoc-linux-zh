## `return` 语句

正如我们之前看到的，大多数 Python 函数将包含一个返回值，该返回值可以是显式的或隐式的。

我们知道 `return` 是一个保留字，其目的是结束某些函数的执行，然后返回作为结果获得的值。如果你想查看这个例子，可以看“按位置参数”中的那个，因为可以观察到函数有 `return` 语句，它将返回 `a` 加 `b` 之和的值；而且，正如你在这个例子中观察到的，该值存储在变量 `c` 中，以便打印。

## `lambda` 函数

我们将 `lambda` 函数定义为一种特殊类型的函数，它是 Python 中预定义函数的一部分。这是什么意思？这种类型的函数主要以其“排他性”而闻名，因为它允许我们快速创建“匿名”函数，因为它有一种某种独有的语法。

`lambda` 函数能够执行一个表达式并返回其结果，它可以在结构中包含可选参数，但尽管如此，该函数也有自己的限制。

### `lambda` 函数的语法

Python 中 `lambda` 函数的语法非常简单，因为它仅基于编写保留字 `lambda`。

```python
# function.py
sum=lambda x,y: x+y
a=sum(3,10)
print(a)
```

在这个例子中，我们使用 `lambda` 赋值给变量 `sum`，它接收两个参数 `x` 和 `y`，冒号后面是 `x+y`。正如你可以看到，我们调用了 `sum` 函数，传递了 3 和 10，然后打印 `a`。

## `filter()` 函数

`filter()` 函数是负责过滤（正如其名称所示）的函数。这指的是什么意思？该函数接收一个序列作为参数，可以是列表或迭代器，然后它将返回一个过滤后的元素。

```python
# function.py
def pair(n):
    if n>0 and n%2==0:
        return True
    else:
        return False

numbers=[]
for x in range(25):
    numbers.append(x)
pairs=filter(pair, numbers)
for x in pairs:
    print("The number "+str(x)+" is pair")
```

## `map()` 函数

`map()` 函数负责对列表或元组中的每个元素执行操作，以便返回一个操作结果的元素序列。

```python
def sum(a, b):
    return a + b

list1=[1, 0, 1, 0, 1]
list2=[0, 2, 0, 2, 0]
c=map(sum, list1, list2)
print(list(c))

string1=["Hello, ", "are "]
string2=["how ", "you"]
c=map(sum, string1, string2)
print(list(c))
```
