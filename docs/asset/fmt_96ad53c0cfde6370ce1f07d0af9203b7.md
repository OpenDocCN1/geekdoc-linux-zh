## 重命名相机

`VIZ`自动为场景中创建的第一个相机分配名称`Camera01`。随后的相机被命名为`Camera02`、`Camera03`等。为了帮助将相机与视图相关联，你可能考虑为你的相机命名有意义的名称，就像你为模型中的几何体命名一样。

8. 右键点击`Perspective`；然后输入`C`。视图将更改为显示来自你新相机的视图。

你有选择定义各种相机设置。在`Parameters`展开栏的顶部，你会看到`Lens`设置，它用于调整相机的焦距。相机的焦距决定了它的视野。事实上，就在镜头设置正下方是`FOV`设置（`FOV`代表视野，`field of view`）。如果你愿意，可以以度而不是焦距输入视野。当你更改其中一个设置时，另一个设置也会以反比关系发生变化。`VIZ`默认焦距约为`43`毫米，或`FOV`为`45`度，这接近于大多数相机中典型的焦距。（`43`毫米设置模拟了人眼。）在下方，你可以从一组`Stock Lenses`——预定义的焦距中进行选择。

你可能还会看到允许`Orthographic Projection`的复选框。正如你猜的，这个复选框允许你将视图从透视切换为正交。

## 调整相机位置

与其他`VIZ`对象一样，相机和目标可以使用`transform tools`进行移动或旋转，尽管`Rotate`变换有一定的局限性。`Uniform Scale`选项对相机无效；然而，`Non-Uniform Scale`和`Squash`选项会改变相机视野的形状。自由相机有两种不同的风格，它们决定了相机的朝向方式：`free`和`target`。目标相机同时包含相机和一个目标辅助对象。无论移动哪一个对象，相机始终面向目标。变换只影响相机的本地`Z`轴，即指向目标的轴；它可以为相机增加横滚角（`roll`），但不能改变其朝向。旋转目标对相机生成的视图没有影响。如果你仔细观察，你会注意到一条连接相机和目标的线。选择此线可以同时选择相机和目标，以便进行同步移动或旋转操作。

自由相机没有目标，仅通过选择相机主体即可移动。旋转相机会旋转它生成的目标。在大多数情况下，应该使用`Local Reference Coordinate System`来旋转自由相机，以便更好地控制相机面对的方向。

# 理解 `VIZ` 相机

目标相机的工作原理类似于目标聚光灯。两者都有独立的、连接的目标助手，用于辅助定位和对准。

尽管`Camera`和`Target`是独立的对象，但正如你之后看到的，它们维持着关系。在练习中，你将看到移动相机如何影响你的视图。

# 使用视口工具编辑相机位置

在之前的章节中，你使用了`VIZ`窗口右下角的视口导航工具来控制你的`Perspective`和`Orthographic`视口。你了解到，在透视视口中，视口控件提供的工具会变为更适合透视效果的工具。同样，当你将相机视图分配给视口时，视口控件会提供一组专用于相机的工具。这些相机工具不仅用于更改相机视口中的视图，用于编辑相机的位置和朝向。

# 使用`Dolly Camera`和视场工具

为了获得模型特定部分的特写，通常在正交视口中使用`Zoom Region`工具或`Zoom`工具。在相机视口中，并没有等同于缩放区域的工具。你有两个效果与缩放和`Field-of-View`工具相同的工具。`Dolly Camera`工具通过沿直线靠近或远离目标，其作用类似于透视视口中的缩放。你的额外优势是可以看到推移相机对相机位置的影响。尝试以下练习查看推移相机的作用：

- 1. 如果尚未选中，选择`Mycamera`相机并在视口中右键点击以确保其处于激活状态。
- 2. 点击视口左上角的`Dolly Camera`工具。
- 3. 在`Mycamera`视口中点击并向上拖动，观察其他视口的情况。`Mycamera`视口放大，你可以看到相机在其他视口中靠近目标。注意只有相机移动了；目标保持不变。
