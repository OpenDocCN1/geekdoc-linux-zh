
### 17.1.5.1 The siginfo structure

此信号的扩展信息记录在 `struct siginfo` 或 `siginfo_t` 中。由于不同的信号需要不同的信息，结构体的体是一个大的联合，为不同类型的信号提供了选项。这使其看起来比实际上要复杂。

图 17.9 `siginfo` 结构

```c
typedef union sigval {
    int sival_int;
    void *sival_ptr;
} sigval_t;

#define SI_MAX_SIZE    128
#define SI_PAD_SIZE    ((SI_MAX_SIZE/sizeof(int)) - 3)

typedef struct siginfo {
    int si_signo;
    int si_errno;
    int si_code;
```
