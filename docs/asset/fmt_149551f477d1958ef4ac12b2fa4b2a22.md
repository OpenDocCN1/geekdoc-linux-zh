
# 窗口名称的获取与设置

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop_return` 返回 `XTextProperty` 结构。

方便函数 `XGetWMName` 调用 `XGetTextProperty` 以获取 `WM_NAME` 属性。成功时返回非零状态；否则返回零状态。

以下两个函数分别被 `XSetWMName` 和 `XGetWMName` 取代。你可以将这些额外的方便函数用于编码为 `STRING` 属性的窗口。

要为窗口分配名称，请使用 `XStoreName(display, w, window_name);`

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `window_name` 指定窗口名称。

`XStoreName` 函数将名称分配给窗口，该名称应该是以空结尾的字符串。窗口管理器可能会在显著位置（如标题栏）显示 `XStoreName` 传递的名称，以便用户识别。`XStoreName` 将名称分配给窗口，该名称应是以空结尾的字符串。如果字符串不是 X 编码，则结果取决于实现。

`XStoreName` 可能会产生 `BadAlloc` 和 `BadWindow` 错误。

# 客户端通信

获取窗口的名称，请使用 `XFetchName`。

```c
Status XFetchName(display, w, text_prop_return);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop_return` 返回 `XTextProperty` 结构。

`XFetchName` 返回窗口的名称。如果成功，返回非零状态；否则返回零状态。如果窗口未设置该属性，`XFetchName` 将 `value` 字段设为 `NULL`，`encoding` 字段设为 `None`，`nitems` 字段设为零。如果它能够读取并将数据存储在 `XTextProperty` 结构中，`XFetchName` 返回非零状态；否则返回零状态。返回的字符串编码取决于实现。

`XFetchName` 可能会产生 `BadWindow` 错误。

# 设置和读取 WM_NAME 属性

Xlib 提供了方便函数，你可以使用它们设置和读取给定窗口的 `WM_NAME` 属性。

使用提供的方便函数设置图标属性，请使用 `XSetWMName`。

```c
void XSetWMName(display, w, text_prop);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop` 指定要使用的 `XText` 结构。

方便函数 `XSetWMName` 调用 `XSetTextProperty` 来设置 `WM_NAME` 属性。

使用提供的方便函数读取窗口的图标属性，请使用 `XGetWMName`。

```c
Status XGetWMName(display, w, text_prop_return);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop_return` 返回 `XTextProperty` 结构。

方便函数 `XGetWMName` 调用 `XGetTextProperty` 以获取 `WM_NAME` 属性。成功时返回非零状态；否则返回零状态。

以下两个函数分别被 `XSetWMName` 和 `XGetWMName` 取代。你可以将这些额外的方便函数用于编码为 `STRING` 属性的窗口。

要设置在图标中显示的名称，请使用 `XStoreName`。

```c
XStoreName(display, w, window_name);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `window_name` 指定以空结尾的字符串。

`XStoreName` 函数将名称分配给窗口，该名称应是以空结尾的字符串。如果字符串不是 X 编码，则结果取决于实现。

`XStoreName` 可能会产生 `BadAlloc` 和 `BadWindow` 错误。

# 设置和读取 WM_HINTS 属性

Xlib 提供了函数，你可以使用它们设置和读取给定窗口的 `WM_HINTS` 属性。这些函数使用了在 `<X11/Xutil.h>` 头文件中定义的标志和 `XWHINTS` 结构。

要分配 `WMHINTS` 结构，请使用 `XAllocWMINTS`。

```c
WMHINTS *XAllocWMINTS();
```

`XAllocWMINTS` 函数分配并返回一个指向 `XWHINTS` 结构的指针。注意 `XWHINTS` 结构中的所有字段最初都被设置为零。如果内存不足，`XAllocWMINTS` 返回 `NULL`。要释放分配给该结构的内存，请使用 `XFree`。

`WMHINTS` 结构包含：

```c
/* Window hints掩码位 */

#define   InputHint      (1L<<0)

#define   StateHint      (1L<<1)
```
