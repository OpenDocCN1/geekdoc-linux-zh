## 黎曼流形几何

黎曼流形几何由 B. Riemann 在 1852 年发起，其中相邻点之间的距离由二次微分形式指定。这种形式允许将高斯几何推广到三维空间，以及非欧几里得几何（此前由 J. Bolyai 和 N. Lobachevsky 引入）和椭圆几何。黎曼流形推广了这一概念，源于其在流形理论中的应用。非洲的坦桑尼和尼拉萨裂谷小于 5 (km)。见地堑 (GRABEN)。

在裂谷中，谷截面完全是非对称的，朝向最高侧倾斜。断层系统由边界断层控制，其内部结构。

`n` 维流形是通过坐标系 `$i = 1, \dots, n$` 协调的空间，两点之间的无穷距离 `dx^i` 由二次微分形式 `g_{ij}` 给出，被称为度量。通常，`g_{ij}` 坐标-裂谷也被分为段。海洋裂谷的截面是非对称的。与大陆裂谷的截面不同，它不受边界限制。见断层 (FAULT)。

```
ds^2 = \sum_{i,j} g_{ij} dx^i dx^j; (1)
```

黎曼几何是局部的，因为它在坐标的邻域内有效。在坐标变换形式 `du^i = \partial u^i / \partial x^j dx^j` 下，性质 `u = u(x)` 是不变的。黎曼几何的基础是黎曼流形的概念。可微流形是在每个邻域内给出的 `ds^2` 相同空间，它是全局且与流形的整体属性一致。见流形 (MATHEMATICS)；拓扑 (TOPOLOGY)。

### 裂谷热 (Rift fever)

裂谷热是一种媒介病毒（蚊），是人类和许多物种动物致命病毒性疾病。裂谷热由立原病毒科（Bunaviridae）病毒引起。在羊和牛中，它由菱蚊（Culicoides）传播。该疾病发生在非洲西部、东部和南部，并延伸到北埃及。历史上，裂谷热与尼罗河三角洲泛滥以及蚊虫的繁殖地有关。

在人类中，裂谷热的症状包括发热，`i \le n`; `du^i = \partial u^i / \partial x^j dx^j`。

裂谷热会导致高死亡率、出血热或新生动物的广泛病变。该疾病由蚊子咬或接触感染组织或体体的病毒引起。通过广泛接种疫苗预防。见动物病毒 (ANIMAL VIRUS)；疫苗 (VACCINATION)。

刚体是一个扩展实体，在不施加运动时其形状保持不变。

# 刚体动力学

刚体动力学：刚体在力作用下的运动是一个质间距离固定的粒子系统。刚体的一般运动由平移（体内所有粒子的平行运动）和旋转（体内所有粒子绕某轴的圆周运动）组成。

质点 `m` 的运动可以通过相对于固定坐标系的位置向量 `\vec{r}`（坐标为 `(x_m, y_m)`）来规定。作用在质量上的力向量 `\vec{F}` 有相应的分量 `(F_x, F_y, F_z)`。牛顿关于 `m` 运动的第二定律如 (1) 所示：

```
$\vec{F} = m\vec{a}$
```

其中 `\vec{a} = d\vec{v}/dt` 或 `d^2\vec{r}/dt^2` 是 `m` 的加速度。

平移运动。如果对刚体中的所有粒子对 (1) 求和，则左侧变为总力

```
$\vec{F} = \sum \vec{F}_i$
```

作用在刚体上的总力。如果左侧遵循牛顿第三定律，则内力的贡献相互抵消，`\vec{F}` 是刚体上的总外力。右侧可以用质心（CM）位置 `\vec{R}` 和速度 `\vec{V}` 来表示。运动方程 (1) 的求和给出了方程 (3) 的形式。该刚体质心的运动方程

```
$\vec{R} = \frac{\sum m_i\vec{r}_i}{\sum m_i}$
```

```
$\vec{F} = M\vec{a}$
```

具有刚体在受到力 `\vec{F}` 影响下、位于 `\vec{R}` 处的质量 `M` 运动的形式。因此，刚体的运动是其质心的运动加上绕其组成部分的旋转。质心。

质点 `m` 的动量由其质量与速度的积给出，`\vec{p} = m\vec{v}`，其中 `\vec{v} = d\vec{r}/dt`。刚体的总动量通过对其各组成部分的动量 `\vec{p}_i` 求和给出，如方程 (4) 所示。用质心动量 `\vec{P}` 表示，质心的运动方程由方程 (5) 给出。对于孤立刚体，动量的变化率是：

```
$\vec{P} = M\vec{V}$
```

其中 `\vec{P}` 是常数。根据方程 (4)，这意味着质心以恒定速度 `\vec{V} = \vec{P}/M` 运动。

旋转运动。刚体绕坐标为 `\vec{o}` 的点 O 的总角动量是其组成部分角动量的和，如方程 (6) 所示。

```
$\vec{L}_0 = \sum m_i(\vec{r}_i-\vec{o})\times(\vec{v}_i-\vec{o})$
```

其中坐标向量 `(\vec{r}_i-\vec{o})` 与动量向量 `(\vec{v}_i-\vec{o})` 的叉积。方程 (7) 中 `L_0` 的导数。原点 O 应当固定在

```
$\vec{L}_0 = \sum m_i(\vec{r}_i-\vec{o})\times\vec{F}_i \quad(7)$
```

在这种情况下 `\vec{r}_i = \vec{o} = 0`）或者是质心。使用运动方程 (1)，`m` 可以被替换为 `F/a`。(8) 的总变化率是：

```
$\vec{L}_0 = \sum (\vec{r}_i-\vec{o})\times\vec{F}_i \quad(8)$
```

方程 (9) 的右侧称为力矩。内力对力矩的贡献根据“扩展的第三定律”消失；即作用力和反作用力相等且沿直线。在这种情况下，旋转运动由方程 (9) 给出，其中

```
$\vec{L}_0 = \sum (\vec{r}_i-\vec{o})\times\vec{F}_{ext} \quad(9)$
```

是作用在刚体上的总外力。角动量：力矩。通过方程 (6) 显示任意点 O 的总角动量与质心的角动量有关 (10)。刚体上的力矩也可以与质心的力矩有关，由方程 (11)。

```
$\vec{L}_0 = M(\vec{R}-\vec{o})\times\vec{V} \quad(10)$
```

```
$\vec{L}_0 = M(\vec{R}-\vec{o})\times\vec{F}_{ext} \quad(11)$
```

六个坐标规定了刚体中所有粒子的运动，刚体的运动由六个方程决定。质心的平移由方程 (5) 决定，旋转运动由 (9) 决定。这六个方程适用于任何粒子系统，完整描述了刚体的运动。孤立系统。方程 `L_0` 的形式与 `P=F` 相同。对于孤立系统，`P` 和 `F` 是常数，`P=0` 且 `F=0`。即使力不零，对于存在内部运动的系统存在某些差异。如果 `P=0`，无论内力如何，质心将保持静止。如果 `L_0=0`，角动量为常数，因此将保持为零，`L_0=0` 排除内部旋转。利用内力的系统运动。静平衡。在结构设计中，刚体在力作用下保持运动的条件非常重要。刚体的静平衡条件由方程 (12) 给出。然而，在许多情况下
