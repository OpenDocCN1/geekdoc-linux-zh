
在查看日志时，你应该熟悉一些常用的工具。`tail`工具默认打印文件的最后十行，这使其成为获取给定文件最新内容的很棒的工具：

```
$ tail /var/log/syslog
```

使用`-f`参数后，`tail`会进入跟踪模式，这意味着将打开文件并在变化发生时在屏幕上继续显示它们。如果你想用你新的系统管理员技能向朋友炫耀，你现在可以轻松地重现好莱坞电影经典：屏幕上飞速闪烁。

此外，`zgrep`、`zcat`和`zless`也非常有价值，它们的操作方式与没有z开头的工具类似，但针对的是gzip压缩文件。例如，为了获取所有压缩日志中包含“warthog”一词的行（不区分大小写），你应该执行以下命令：

```
$ zgrep -i warthog /var/log/.gz
```

### 网络安全简介

网络安全管理是另一个主要由操作系统提供的功能，因此在Ubuntu和任何其他现代Linux发行版没有区别。这意味着我们在这里不涵盖它，但会给你提供一个提示。

`iptables`命令是强大的Linux防火墙表的前端。遗憾的是，处理`iptables`可能相当困难，特别是当你试图设置复杂的防火墙策略时。为了解你的胃，这里有一个`iptables`的用法示例，丢弃所有来自某个著名时间杀手域的数据包：

```
$ sudo iptables -A INPUT -s www.slashdot.org -j DROP
```

网上关于`iptables`的教程、指南和文章随处可见，系统帮助手册（man pages）提供了关于所有可能选项的详细信息。花时间学习`iptables`是非常值得的，因为它能让你在任何Linux机器上设置网络安全，而且如果你需要，它还会让你学习其他操作系统的防火墙系统变得非常容易。

### 关于安全的结语

在这一节中，我们仅仅触及了系统安全的皮毛，尽管我们尝试为你提供一些关于从何处开始以及哪里获取更多学习信息的良好建议。但请让我们就通用的安全问题给你一些智者之言，因为这是一个痛苦的事实：世界上不存在完全安全的系统。保护系统安全不是为了让入侵变得不可能发生，而是为了让入侵变得极其困难，以至于攻击者认为不值一试。如果你的攻击者是一个坐在某个地下室里吃着冷披萨的无聊14岁少年，那么这个定义就非常模糊——你可以打赌，即使你的系统里存着机密信息，那个孩子也会放过你的；但从成本/收益的角度来看，让系统安全到让入侵对攻击者来说不值一试则要困难得多。

安全也非常奇妙，因为作为一个概念，它渗透了计算机科学的整个思想空间。真正精通安全需要对计算机系统的内部运作有极其深入的理解，这有一个显而易见的优势：如果你试图深入理解计算机系统但不知道从何处开始，你可以从安全开始，只需顺着线索追踪即可。利用好这一点吧！祝你好运。

### 总结

如果你以前从未管理过系统，那么从普通用户到管理员的转变将是困难，无论你选择学习管理哪种操作系统。这种困难源于所要求的更广泛的思维转变。你不再仅仅是确保自己的房间整洁，现在你必须运行并保护整栋大楼。但这种困难也是具有教育意义且有回报的。（我们意识到你在大学的理论物理课上可能说过同样的话，但我们没有在撒谎。）学习维护Ubuntu服务器对你来说是一个极佳的选择，因为你将受益于充满活力且乐于助的用户社区，而且在每一步中都会与顶尖操作系统打交道。

正当我们处于这本书第一版最后的编辑阶段时，Ubuntu的创始人Mark Shuttleworth在Sun的年度JavaOne大会议上，面对15,000名观众，与时新新任的Sun Microsystems首席执行官Jonathan Schwartz一同登台。2001年，Sun的前任执行官Scott McNeally曾著名地将大型机上运行Linux比作“就像在你的庄园后院放了一个拖车公园”。但在旧金山并肩而立时，Schwartz和Shuttleworth宣布Sun计划在其硬件上为Ubuntu Server提供商业支持。在演讲结束后与记者会面时，Schwartz Ubuntu为“世界上最重要的——如果不是最重要的——Linux发行版之一”，并补充说，[Sun]很有可能会积极支持Ubuntu正在做的工作。近期与Sun的合作使得在Ubuntu服务器上发布的一个Java版本以及对Sun SPARC架构的支持变得复杂。虽然要确切知道Sun与Ubuntu的长期合作如何发展还为时尚早，但在JavaOne发布之后有一点是肯定的：行业将Ubuntu Server视为服务器操作系统领域一个非常有竞争力的竞争者。

如果你是一个想来看看Ubuntu Server到底怎么回事的资深管理员，请拭以待。该项目在稳定性方面虽然很稳固，但在功能上仍处于幼年期，服务器团队正非常努力地打造最出色的服务器平台。我们正在强调高级功能。我们已经提供了一些出色的集群原语，并将扩展我们的集群支持，以包含资源管理和单系统映像（SSI）集群。我们正致力于将卓越的Xen虚拟机管理器集成到Ubuntu Server中。而且我们对每一个小细节的完美呈现都非常挑剔。

在上述两种情况下，如果你正在安装新服务器，请尝试一下Ubuntu Server。它是一个先进的系统，我们相信你会喜欢使用它的。与我们联系，告诉我们如何让它变得更好，并伸援手。帮助我们让Ubuntu在大型重型硬件上变得更加酷炫！

