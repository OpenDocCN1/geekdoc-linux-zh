
## 源路由 (Source Routing)

在网络中，源路由允许发送者部分或完全指定通过网络的路由。相比之下，非路由数据包由网络中的路由器确定路径。在某些情况下，系统从某些位置可能不可路由或不可访问（例如私有地址与互联网可路由地址），因此需要使用路由包。

### 原理

设置：

- `net.ipv4.conf.all.accept_source_route` = 0
- `net.ipv4.conf.default.accept_source_route` = 0
- `net.ipv6.conf.all.accept_source_route` = 0
- `net.ipv6.conf.default.accept_source_route` = 0

禁用系统接受源路由数据包。假设此系统能够向一个接口路由互联网可路由地址并在另一个接口路由私有地址。假设私有地址无法路由到互联网可路由地址，反之亦然。在正常路由情况下，来自互联网的攻击者无法利用该系统到达私有地址系统。然而，如果允许路由包，则可以使用它们访问私有地址系统，因为可以指定路由，而不是依赖于此类路由的协议。

### 审计

运行以下脚本验证：

- `net.ipv4.conf.all.accept_source_route` = 0
- `net.ipv4.conf.default.accept_source_route` = 0
- `net.ipv6.conf.all.accept_source_route` = 0
- `net.ipv6.conf.default.accept_source_route` = 0

## 3.3.2 确保接受 ICMP 重定向（自动化）

### 适用范围

- 级别 1 服务器
- 级别 1 工作站

### 描述

ICMP 重定向包是传递路由信息并告诉您的主机（作为路由器）通过备用路径发送包。这是允许外部路由设备更新系统路由表的方法。

### 原理

攻击者可以使用虚假的 ICMP 重定向包恶意更改系统路由表，使其向错误的网络发送数据。

通过设置：

- `net.ipv4.conf.all.accept_redirects` = 0
- `net.ipv4.conf.default.accept_redirects` = 0
- `net.ipv6.conf.all.accept_redirects` = 0
- `net.ipv6.conf.default.accept_redirects` = 0

系统将拒绝任何 ICMP 重定向包，因此不会允许外部更新系统的路由表。

### 审计

运行以下脚本验证：

- `net.ipv4.conf.all.accept_redirects` = 0
- `net.ipv4.conf.default.accept_redirects` = 0
- `net.ipv6.conf.all.accept_redirects` = 0
- `net.ipv6.conf.default.accept_redirects` = 0

  file="$(grep -s "\$1_kname" $searchloc | grep -v "\h*=\$1_kname\h*=\$1_value" | awk -F'\[\$1\]")

  fi
