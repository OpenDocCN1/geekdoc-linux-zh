
## 返回值

如果一切正常，返回零。如果发生错误，可以在 `errno` 中找到原因。

## 参数

| 参数 | 描述 |
| :--- | :--- |
| `fd` | 文件或套接字描述符 |

## 可能的错误

- `EBADF`：`fd` 不是有效的打开文件描述符。

## 示例

```c
int sockfd;

sockfd = socket(PF_INET, SOCK_RAW, htons(99));

if ( sockfd < 0 )
    PANIC("Raw socket create failed");

...

if ( close(sockfd) != 0 )
    PANIC("Raw socket close failed");
```
