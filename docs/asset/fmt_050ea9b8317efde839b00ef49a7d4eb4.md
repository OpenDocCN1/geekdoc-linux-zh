## 练习题与测验答案（补充）

### 9. BUG BURSTER：赋值运算符错误分析

**错误代码**：
```cpp
SQUARE SQUARE::operator=(const SQUARE & rhs) {
    itsSide = new int;
    *itsSide = rhs.GetSide();
    return this;
}
```

**问题**：
1. 返回类型错误：应返回 `SQUARE&`，而非 `SQUARE`，且应返回 `*this` 而非 `this`。
2. 缺少自赋值检查（`if (this == &rhs)`）。
3. 直接分配新内存导致原有内存泄漏，应先 `delete itsSide`。
4. 未处理 `rhs` 为空或异常安全。

**修正版**：
```cpp
SQUARE& SQUARE::operator=(const SQUARE & rhs) {
    if (this == &rhs)
        return *this;
    delete itsSide;
    itsSide = new int(*rhs.itsSide); // 假设 itsSide 为 int*
    return *this;
}
```

### 10. BUG BURSTER：`operator+` 错误分析

**错误代码**：
```cpp
VeryShort VeryShort::operator+(const VeryShort & rhs) {
    itsVal += rhs.GetVal();
    return *this;
}
```

**问题**：`operator+` 不应修改操作数，而应返回一个新对象。

**修正版**：
```cpp
VeryShort VeryShort::operator+(const VeryShort & rhs) const {
    return VeryShort(itsVal + rhs.GetVal());
}
```

# 第 11 天

## 测验

1. **什么是 v-table？**  
   v-table（虚函数表）是编译器管理 C++ 中虚函数的常用机制。该表维护了所有虚函数的地址列表，并根据所指向对象的运行时类型调用正确的函数。

2. **什么是虚析构函数？**  
   任何类的析构函数都可以声明为虚函数。当通过基类指针删除派生类对象时，将根据对象的运行时类型调用正确的派生类析构函数。

3. **如何声明虚构造函数？**  
   C++ 不支持虚构造函数。

4. **如何创建虚拷贝构造函数？**  
   通过在类中创建一个虚方法（通常命名为 `clone()`），该方法内部调用拷贝构造函数并返回新对象指针。

5. **如何在重写了该函数的派生类中调用基类成员函数？**  
   `Base::FunctionName();`

6. **如何在未重写该函数的派生类中调用基类成员函数？**  
   `FunctionName();`（直接调用即可，会自动解析到基类版本）

7. **如果基类声明函数为虚函数，派生类重写时未使用 `virtual` 关键字，第三代继承时仍是虚函数吗？**  
   是的，虚性会被继承且无法关闭。

8. **`protected` 关键字的作用？**  
   `protected` 成员可被派生类的成员函数访问，但不可被类外代码访问。

### 5. BUG BURSTER：代码片段分析
```cpp

```
**分析**：可能没问题。`SomeFunction` 期望 `Shape` 对象，传入的 `Rectangle` 会发生**对象切片**，仅保留 `Shape` 部分。若不需要 `Rectangle` 特有成员则可行；否则应修改 `SomeFunction` 接受 `Shape&` 或 `Shape*`。

### 6. BUG BURSTER：代码片段分析
```cpp

    Shape();
    virtual ~Shape();
    virtual Shape(const Shape&); // 错误
};
```
**错误**：**拷贝构造函数不能声明为虚函数**。

# 第 13 天 练习 4：抽象数据类型与继承

修改程序使 `Car` 成为 ADT，派生 `SportsCar` 和 `Coupe`。在 `Car` 中实现 `Vehicle` 的一个纯虚函数使其不再纯虚。

```cpp
class Vehicle {
public:
    virtual void Move() = 0;
    virtual void Haul() = 0;
    virtual ~Vehicle() = default;
};

class Car : public Vehicle {
public:
    void Move() override; // 实现 Move，使 Car 不再是抽象类（若 Haul 仍为纯虚则 Car 仍为抽象类）
    virtual void Haul() = 0; // 保持 Haul 为纯虚，强制子类实现
};

class Bus : public Vehicle {
public:
    void Move() override;
    void Haul() override;
};

class SportsCar : public Car {
public:
    void Haul() override;
};

class Coupe : public Car {
public:
    void Haul() override;
};
```

> **注意**：若 `Car` 实现了 `Move()` 但未实现 `Haul()`，`Car` 仍为抽象类，`SportsCar` 和 `Coupe` 必须实现 `Haul()` 才能实例化。

## 测验

1. **静态成员变量可以是私有的吗？**  
   可以。它们是成员变量，访问控制与普通成员一致。私有静态成员只能通过成员函数（常为静态成员函数）访问。

2. **静态成员变量声明**  
   `static int itsStatic;`

3. **静态成员函数声明**  
   `static int SomeFunction();`

4. **返回 `long`、接受 `int` 的函数指针声明**  
   `long (*function)(int);`

5. **修改为指向 `Car` 类成员函数的指针**  
   `long (Car::*function)(int);`

6. **包含 10 个此类指针的数组声明**  
   ```cpp
   typedef long (Car::*Function)(int);
   Function theArray[10];
   ```
   或（非 GNU 编译器偏好）：
   `long (Car::*Function)(int) theArray[10];`

### 1. 含静态成员变量的类程序

### 2. 驱动程序：创建三对象、显示成员与静态变量、销毁观察
```cpp
#include <iostream>

class myClass {
public:
    myClass();
    ~myClass();
    void ShowMember();
    void ShowStatic();
private:
    int itsMember;
    static int itsStatic;
};

myClass::myClass() : itsMember(1) {
    itsStatic++;
}

myClass::~myClass() {
    itsStatic--;
    std::cout << "In destructor. itsStatic: " << itsStatic << std::endl;
}

void myClass::ShowMember() {
    std::cout << "itsMember: " << itsMember << std::endl;
}

void myClass::ShowStatic() {
    std::cout << "itsStatic: " << itsStatic << std::endl;
}

int myClass::itsStatic = 0;

int main() {
    myClass obj1;
    obj1.ShowMember();
    obj1.ShowStatic();

    myClass obj2;
    obj2.ShowMember();
    obj2.ShowStatic();

    myClass obj3;
    obj3.ShowMember();
    obj3.ShowStatic();

    return 0;
}
```
