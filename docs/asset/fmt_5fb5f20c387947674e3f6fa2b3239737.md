# 21.3.5 枚举域共享

为了结束我们的手动枚举，我们将转向域共享。域共享通常包含有关环境的关键信息，我们可以利用这些取得优势。

我们将使用 `PowerView` 的 `Find-DomainShare` 函数来查找域中的共享。我们还可以添加 `-CheckShareAccess` 标记来仅显示我们可用的共享。然而，我们将跳过此标记以获取完整列表，包括我们可能的目标的所有共享。注意，`PowerView` 查找并列出共享可能需要一些时间。
