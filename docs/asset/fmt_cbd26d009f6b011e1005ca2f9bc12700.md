
`xconfig` 命令与 `menuconfig` 非常相似，但它使用图形界面。这对于许多用户来说通常更容易。

对于给定配置对话框中的几乎每个配置选项，都可以点击 `Help`（帮助）按钮获取有关该选项的详细或额外信息。

在网络对话框中向下滚动，在 `IP: TCP cookie 支持` 处点击 `y`，这允许合法用户继续使用遭受 SYN 洪水攻击（拒绝服务攻击的一种）的系统。如果你启用了此选项，稍后在配置过程中还需要启用 `sysctl` 和 `/proc` 文件系统支持（无论如何你都应该这么做），并将以下命令添加到 `/etc/rc.local` 或其他初始化脚本：

```
echo 1 > /proc/sys/net/ipv4/tcp_cookies
```
