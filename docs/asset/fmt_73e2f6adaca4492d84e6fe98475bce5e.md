
- 2) 选择 Troubleshooting Troubleshooting 并……。如果电脑没有图形界面，你可以使用字符……通常是图形化安装方法。

### 系统安装设置

前一章节为 Linux 爱好者了解不同的流程提供了一个良好的开始，这有助于理解 Linux 是什么。在本章中，我们将讨论 Linux 安装过程中常用的不同系统安装设置。请继续阅读！

#### 系统安装设置

- 1) 现在进入磁盘分区阶段。在所示的界面中，点击“安装目标”（INSTALLATION DESTINATION）进入磁盘分区阶段。你可以看到有一个大小为 100GB 的硬盘 `sda`。显示的大小将根据你的磁盘大小而定。

在分区之前，有一些关于 Linux 分区的必要说明。

Linux 系统下的必要分区是根分区（root partition，标记为 `/`）和交换分区（swap partition，标记为 swap）。交换分区等于 Windows 中的虚拟内存概念，即在内存与硬盘之间交换数据。关于交换分区的大小，许多来源指出它至少是物理内存的两倍，事实并非如此。

基本原则是：如果内存较小（根据经验，物理内存小于 4GB），通常将交换分区的大小设置为内存的两倍。如果物理内存大于 4GB 但小于 16GB，可以将交换分区的大小设置为与物理内存相等。如果内存大小超过 16GB，可以将交换分区设置为 0。虽然交换分区可以设置为 0，但并不建议这样做，因为设置特定大小的交换分区仍然具有的一定的效果。

虽然 Linux 默认只需要划分根分区和交换分区即可完成系统安装，但并不推荐这样做，因为如果只划分了根分区，当根分区损坏且数据存储在根分区中时，系统可能无法启动。数据也可能丢失，这非常不。因此，建议为独立的应用程序分配独立的分区，这样即使某个分区被破坏，也不会影响其他分区的数据，并可以尽力减少系统崩溃造成的损失。

安装系统时，建议独立分配以下分区：

- `/boot`：存储系统启动信息和内核信息。
- `/usr`：存储系统应用软件的安装信息。
- `/var`：存储系统日志信息。

关于每个分区的含义，请参考下一章获取更详细的。

根分区包含 Linux 系统所有的目录。如果安装系统时只分配了根分区，上述的 `/boot`、`/usr` 和 `/var` 都将包含在根分区，这意味着分区将占用根分区的空间。如果你单独划分了 `/boot`、`/usr` 等，这些分区将不再占用根分区的空间。

了解了一些基础分区知识后，开始下方的磁盘分区。

- 2) 在所示界面中，首先选择 100GB 的 `sda` 磁盘，然后在左下角会有两个分区选项。第一个是“自动分区”（Automatically configure partitioning），意味着自动分区。第二个是“我将配置分区”（I will configure partitioning），意味着手动分区。

如果你不熟悉分区，可以默认选择“自动”。然而，从学习的角度考虑，建议选择手动分区，即使你是新手，选择手动分区也有助于理解和掌握系统分区。在此选择手动分区。选择后，点击左上角的“完成”按钮进入界面。

- 3) 选择手动分区后，你还需要选择分区方案。你可以从左侧面板的下拉菜单中选择分区方案。可用的方案包括标准分区（Standard Partition）、Btrfs、LVM 和 LVM 精简配置（LVM Thin Provisioning）。

其中，标准分区可用于各种文件系统或交换空间（swap），是一种常用的分区方案。Btrfs 是下一代 Linux 文件系统，被 Oracle、Red Hat、Intel 和 Suse 等公司和社区使用。

LVM 是一种逻辑管理分区方案。创建 LVM 分区时，会自动生成 LVM 逻辑卷，可以通过 LVM 灵活使用物理磁盘并提高磁盘性能。使用 LVM 精简配置，你可以动态创建并分配存储池，然后自由地管理磁盘空间。LVM 精简配置是 LVM 的升级版本。

事实上，还有一种 RAID 分区方案。当有两个或多个磁盘时，会出现 RAID 分区方案。这是一种软件 RAID，可以为服务器提供高级存储功能和数据冗余安全。

在此处选择“标准分区”方案。添加分区有两个步骤。首先，你需要创建一个挂载点。点击左下角的“+”按钮来创建挂载点。

- 4) 首先创建一个根分区，并将根分区空间设置尽可能大，因为如果根分区空间满了，系统可能会停止响应，运行在系统上的应用程序可能会异常。由于 `/boot` 和 `/usr` 等分区已经分开，根分区 20GB 的空间是足够的。

事实上，分区大小设置与磁盘大小有关。如果磁盘足够大，确保系统充足而不浪费空间是磁盘分区的标准。

挂载点（Mount point）可以通过点击下拉列表选择，也可以手动填写。所需容量（Desired Capacity）如 20GB 可以直接填写“20G”，500MB 可以填写“500M”，以此此类推。设置完成后，点击“添加挂载点”按钮完成挂载点的添加。

- 5) 挂载点创建成功后，将进入界面。点击左侧面板中的挂载点，你可以在右侧面板进行各种修改，例如：编辑挂载点、修改分区大小、选择设备类型、选择文件系统类型、用于自定义的标签选项，以及对相应分区进行加密或重新格式化。

对于文件系统选择，默认是 xfs，但共有七种类型：swap、vfat、BIOS boot、ext2、ext3、ext4 和 xfs。其中，ext2、ext3 和 ext4 是 Linux 系统上的主流文件系统；在 RHEL/CentOS 7.x 之前的版本中，默认采用 ext 系列文件系统。VFAT 文件系统对应 Windows 上的 FAT 文件系统，而 swap 是 Linux 上的交换分区。BIOS boot 主要用于系统启动设备，是一个非常小的分区，而 xfs 系统是一种出现在 RHEL/CentOS 7.x 上的高性能文件系统。

“标签（Label）”选项是对应磁盘分区的标签，通过它可以快速识别分区。标签选项可以填写内容，也可以不填写，默认留白。

一旦建立了挂载点，对应的磁盘 ID 就会固定。例如，与分区对应的磁盘 ID 为 `/dev/sda1`。除非删除分区并重新建立，否则这个“sda1”是修改的。

所有设置修改完成后，点击界面中的“Update Settings（更新设置）”按钮完成磁盘分区的编辑。

- 6) 点击所示界面左下角的“+”按钮继续创建 `/boot` 挂载点。之后，在 Mount Point（挂载点）下拉列表中选择“boot”，并在 Desired Capacity（所需容量）输入框中选择输入的大小为“500M”。

`/boot` 分区不需要太大，因为它只用于存储一些系统启动信息和内核信息。点击 Add（添加）挂载按钮，即可创建 `/boot` 挂载点。

- 7) 然后创建一个 swap 类型的挂载点。在 Mount 下拉列表中选择 swap，然后在 Desired Capacity 输入框中输入大小，此处指定 4096M。

注意这是“swap（交换）”，而不是“root（根）”。

- 8) 然后分别创建 `/usr` 和 `/var` 分区。创建方法与 `/boot` 分区基本相同，但分区大小不同。

如果安装了应用软件，可以增大 `/usr` 分区。建议 `/var` 分区设得大一些，因为系统运行一段时间后会产生大量日志。

- 9) 在创建完系统所需的分区后，如果空间足够，还可以创建一个根分区来存储你的数据。在这里创建根分区。注意每个分区都是在 root 下创建的。

为了确保 Linux 使用所有磁盘空间，将剩余空间分配给根分区。具体操作是在输入框中输入 Mount Point，并留空 Desired Capacity。

- 10) 此时分区工作已基本完成，将显示已完成的分区。如需删除分区，可以点击界面左下角的“-”按钮。完成所有设置后。

- 11) 在所示界面中显示了所有与磁盘相关的操作，包括创建、调整大小或删除分区。你可以查看所有更改。如果需要修改分区，点击 Cancel（取消）按钮返回分区界面。要确认更改操作，点击 Done（完成）按钮。

到此为止，已经介绍了分区的所有基本操作。现在我们将进入网络配置。

# U 盘安装过程

如今大多数 PC 和服务器已不再配备 CD-ROM 驱动器，而是被 USB 接口设备取代。同时，USB 3.0 规范已广泛普及，U 盘的数据传输速度可以达到每秒千比特。根据您的需求，市场上上有从 2GB 到 2TB 不等的数十种产品。
