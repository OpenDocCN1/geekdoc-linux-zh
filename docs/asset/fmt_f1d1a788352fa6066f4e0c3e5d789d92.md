## 设置 `[global]` 参数

`[global]` 部分定义了适用于所有其他配置部分（即它们所定义的服务）的 Samba 参数。默认的 `[global]` 配置如下：

```
[global]
workgroup = MYGROUP
server string = Samba Server
printcap name = /etc/printcap
load printers = yes
log file = /var/log/samba/log.%m
max log size = 50
security = user
socket options = TCP_NODELAY
dns proxy = no
```
