## 微分方程

一个函数与其导数之间的关系。

如果有一个自变量，该微分方程称为常微分方程。此类方程的标准形式如 (1) 所示，其中 `t` 是自变量：

```
$F(t, u, u', \dots, u^{(n)}) = 0$ (1)
```

变量：`u` 是 `t` 的函数；`du/dt = u'`；`d^2u/dt^2 = u''`；`…`；`d^nu/dt^n = u^{(n)}` 是 `u` 的导数，`F(t, u, u', \dots, u^{(n)})` 是 `n+1` 个变量函数。正整数 `n` 称为微分方程的阶数：微分方程的阶数是方程中出现的最高导数。例如，考虑 (2)：

```
$u + u' = 0$ (2)
```

如果有多个自变量，该微分方程称为偏微分方程。同样，偏微分方程的阶数是方程中出现的最高偏导数。

### 微分几何

一门研究曲面空间内在性质的数学分支。该学科研究几何曲线和曲面，在直角坐标系 `(x,y)` 中具有广泛优势。空间可以通过一对依赖方程 `f(x,y) = 0` 和 `g(x,y) = 0` 定义，或者有意义地通过参数方程 `x = (x(t), y(t))` 定义，其中 `t` 是该类中的参数。两点 `t` 和 `s` 之间的线由给出：

```
$s = \int \sqrt{(\frac{dx}{dt})^2+(\frac{dy}{dt})^2+(\frac{dz}{dt})^2} dt$ (1)
```

显然，如果选择 `s` 为参数，见方程 (2)。在这里：

```
$s = \int \sqrt{(\frac{dx}{dt})^2+(\frac{dy}{dt})^2} dt$ (2)
```

考虑三个相邻的点 `P_1, P_2, P_3`。通过它们可以构造一个。`P_1` 和 `P_2` 的极限位置是曲面 `S` 的切平面。当 `P_1, P_2` 和 `P_3` 接近 `P` 时，曲率及其半径是曲率半径 `κ`；其值如 (3) 所示。曲线上 `P` 处的垂直面是法平面，`P` 处的垂直面是切法面。双曲

```
$$\kappa = \frac{\left(\frac{dx}{dt})^2+(\frac{dy}{dt})^2+(\frac{dz}{dt})^2\right)\left(\frac{d^2x}{dt^2})^2+(\frac{d^2y}{dt^2})^2+(\frac{d^2z}{dt^2})^2-\left(\frac{dx}{dt}\right)\frac{d^2y}{dt^2}-\left(\frac{dy}{dt}\right)\frac{d^2x}{dt^2}\right)}{\left(\frac{dx}{dt})^2+(\frac{dy}{dt})^2\right)^{3/2}} \quad (3)
```

在三维欧几里得空间中，可以通过 `f(x,y,z) = 0` 定义，或者局部通过方程 (4)。对于：

```
$x=x(u) \ y=y(u) \ z=z(u)$
```

描述曲面上的曲线，固定 `u` 值的线。这些是点的 `(u,v)` 曲线坐标。曲面上最重要的问题是曲线的弧长。由 (5) 给出，`E, F, G` 是 `(x,y)` 的导数。

```
$ds^2 = E^2 du^2 + 2F dudv + G^2 dv^2 \quad (5)$
```
