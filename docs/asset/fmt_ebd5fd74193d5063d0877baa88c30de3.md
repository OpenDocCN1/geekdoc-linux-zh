此外，可以使用标识符重命名通过 `from` 导入的特定对象。这里有一个示例：

```python
from spam import Spam as Sp
s = Sp(foo)
```

星号 (`*`) 通配符也可以用于加载模块中的所有定义，但下划线开头的除外。这里有一个示例：

```python
from module import * # 将所有定义加载到当前命名空间
```

`from import *` 语句只能在模块的顶层使用。特别是，由于其相互作用的方式，在函数体内部使用这种形式是非合法的。模块可以通过定义 `__all__` 来更精确地控制导入的名称集合。这里有一个示例：

```python
# 模块：spam.py
__all__ = ['bar', 'Spam']
```

使用 `from` 导入不会改变全局变量。例如，考虑以下内容：

```python
from spam import a, foo  # 导入全局变量
a = 42                    # 修改变量
foo()                     # 打印 "Im foo and is 37"
print(a)                  # 打印 "42"
```

在这里，重要的是理解赋值不是一种存储操作。相反，创建一个包含该值的新对象并将名称指向它。

## 作为主程序执行

Python 源文件有两种执行方式。`import` 语句在其命名空间内作为库模块执行代码。然而，代码也可以作为主程序或脚本执行。这发生在你将程序作为脚本提供解释器时：

```bash
% python spam.py
```

每个模块都定义了一个变量 `__name__`，其中包含模块名。程序可以检查此变量以确定它们正在执行的模块。解释器的顶层模块命名为 `__main__`。命令行指定的程序或交互式执行的程序运行 `__main__`。某些程序可能会根据是被导入还是在 `__main__` 中运行来改变行为。例如：

```python
# 检查是否作为程序运行
if __name__ == '__main__':
    # 是
    statements
else:
    # 否，我被作为模块导入
    statements
```

打算作为库使用的源文件通常使用这种技术，包括可选的测试或示例代码。例如，如果你正在开发一个 module，你可以像下面所示在 `if` 语句中编写用于测试库功能的代码，并只需将你的模块作为主程序运行 Python 即可执行它。这些代码不会为导入你库的用户运行。

## 模块搜索路径

在加载模块时，解释器会搜索 `sys.path` 中的目录列表。`sys.path` 中的第一个条目是一个空字符串 `''`，它指向当前工作目录。`sys.path` 中的其他条目由目录名称、zip 存档文件和 .egg 文件组成。`sys.path` 中条目的顺序决定了加载模块时的搜索顺序。要向搜索路径添加新条目，只需将它们添加到 `this` 中即可。

尽管路径通常包含目录名称，但任何包含 Python 模块的存档文件也可以添加到搜索路径。这是将一组模块打包成单个文件的方便方法。例如，假设你创建了两个模块 `foo.py` 和 `bar.py`，并将它们放在一个名为 `modules.zip` 的 zip 文件中。可以通过如下方式将文件添加到搜索路径：

```python
import sys
sys.path.append("modules.zip")
import foo, bar
```
