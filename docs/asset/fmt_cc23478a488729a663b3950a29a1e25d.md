### Verify Partitioning

In most cases, YaST's automatic partitioning is sufficient. However, you might need to change the partitioning manually if:

- You want to optimize disk usage.
- You want to configure LVM.
- You have more than one hard drive.
- You want to delete existing partitions.

To partition the hard drive manually, you need to know the following:

- The Basics of Hard Drive Partitioning
- The Basic Linux Partitioning Scheme
- YaST’s Partitioning Proposal
- YaST Expert Partitioner

### The Basics of Hard Drive Partitioning

Partitions divide a hard drive into logical units. Every hard disk has a partition table.

A **primary partition** is a partition that can be used to boot the system. An *extended partition* is a container for logical partitions.

If you need more than four partitions, you must create an extended partition.

It does not matter which partition is used for which purpose, as long as the partition table is correct.

Table 1.1 shows the Linux device names for hard drives.

| Device | Linux Name |
| Primary master IDE hard disk | `/dev/hda` |
| Primary slave IDE hard disk | `/dev/hdb` |
| Secondary master IDE hard disk | `/dev/hdc` |
| Secondary slave IDE hard disk | `/dev/hdd` |
| First SCSI or SATA hard disk | `/dev/sda` |
| Second SCSI or SATA hard disk | `/dev/sdb` |

Table 1-1

Partitions follow the naming convention shown in Table 1-2.

| Partition | Linux Name |
| First partition on first IDE hard drive | `/dev/hda1` |
| Second partition on first IDE hard drive | `/dev/hda2` |
| First partition on third SCSI hard drive | `/dev/sdc1` |
| First logical partition on first IDE hard drive | `/dev/hda5` |
| Second logical partition on first IDE hard drive | `/dev/hda6` |

Table 1-2

For example, `/dev/sda1` is the first partition on the first SCSI or SATA hard disk.

### The Basic Linux Partitioning Scheme

A basic Linux installation requires at least two partitions:

- A root partition `/` for the system files.
- A swap partition for virtual memory.

The root partition is usually formatted with `ext4`. The swap partition is used by the kernel for paging.

### YaST’s Partitioning Proposal

YaST proposes a partitioning scheme based on the available disk space. The proposal can be accepted or modified.

### YaST Expert Partitioner

The Expert Partitioner allows manual creation, deletion and resizing of partitions. Use it with caution, as incorrect changes can lead to data loss.
