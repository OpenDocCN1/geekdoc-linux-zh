
正如我们在最后一个示例所示，调用或声明全局变量并不复杂。我们可以说它与我们看到的声明变量相似；唯一的区别在于从现在起变量 `var` 将具有全局属性，这样任何函数都能以简单的方式访问它。

## 局部变量

局部变量是那些仅在一个函数使用的变量，并在执行完成后从内存中删除。与全局变量不同，局部变量允许我们节省大量的代码，使得模块化编程更加敏捷容易，从而允许代码复用，这使得 Python 成为最引人注目的编程语言之一。

在 Python 程序中使用局部变量的主要优势是便于阅读代码，使其易于理解；全局变量允许更有效、更容易地修复任何错误。减少了代码行，在解释时极不可能产生困惑。

在编程时使用局部变量被认为是一种良好的实践，因为现在的目标是获得让没有编程经验的用户更容易解释的简单代码。

为了更好地理解这一点，我们将做一个示例，清晰地解释在编程时这些变量的使用。

示例：我们将创建一个程序，该程序负责从用户那里获取以下数据：

- 1. 名字和姓氏
- 2. 年龄
- 3. 出生国家

# 第 3 章：运算符

运算符是在操作操作数之间执行特定操作的数学符号。因此我们可以得出，运算符是那些能够执行函数的符号。

运算符的类型：

- 逻辑操作符。
- 算术操作符。
- 比较操作符。
- 赋值操作符。
- 特殊操作符。

### 逻辑操作符
这类操作符通常用于分组、否定某些表达式。

1. `not` 操作符：这种操作符负责否定或返回与布尔值相反的值。
   - `not True=False`
   - `not False=True`

2. `Or` 操作符：这种操作符按顺序评估右侧的值和左侧的值，如果至少满足一个条件，则最终返回真值。
   - `False or True = True`
   - `True or false = True`
   - `True or True = True`
   - `False or False = False`

3. `And` 操作符：这种操作符负责评估左侧值与右侧值之间的条件是否满足。
   - `True and False = False`
   - `True and True = True`
   - `False and True = False`
   - `False and False = False`

### 比较操作符
这些类型的操作符用于比较（正如其名所示）程序中的某些值，以便稍后编译时返回 `True/False` 类型的值。

1. `!=` 操作符：这种操作符负责评估这些存储的值是否不同，根据分析结果，它将返回 `True/False`。
   - `20!=20` 结果将是 `False`
   - `14!=15` 结果为 `True`

2. `==` 操作符：这种操作符负责评估不同数据类型的值是否相同，根据得到的分析结果，其结果将交付我们 `True/False`。
   - `19 == 19` 结果为 `True`
   - `10 == 5` 结果为 `False`

3. `>` 操作符：这种操作符负责评估左侧输入的值是否大于右侧的值。
   - `30>25` 结果为 `True`
   - `9>28` 结果为 `False`

4. `<` 操作符：这种操作符负责评估左侧的值的值是否低于右侧的值。
   - `26<9` 结果为 `False`
   - `14 < 22` 结果为 `True`

大于或等于右侧位置的值。例如：
`20 > 14` 结果为 `True`
`10 > 26` 结果为 `False`
`10 >= 10` 结果为 `True`

5. `>=` 操作符：这种运算符用于评估左侧输入的值是否大于或等于右侧位置的值。

6. `<=` 操作符：这种运算符用于评估左侧输入的值是否小于或等于右侧位置的值。例如：
   - `20 < 11` 结果为 `False`
   - `16 < 25` 结果为 `True`
   - `15 <= 15` 结果为 `True`

### 赋值运算符
这些运算符在程序中用于为变量赋值（正如其名称所示），在这种情况下，这些运算符后面会跟一个等号 (`=`)

1. 等于 (`=`) 运算符: 这种运算符被认为是主要的运算符，将始终位于变量的左侧。例如：
   `A=10` → `A` 的值将为 10

2. 加法赋值 (`+=`) 运算符 这种运算符负责将右侧的值加到左侧变量上。例如：
   `A=10; A+= 8` → `A=18`
   等同于表示：`A=10; A + 8` → `A=18`

3. 减法赋值 (`-=`) 运算符 这种运算符负责从左侧变量中减去右侧的值。例如：
   `A= 10; A -=8` → `A=2`
   等同于表示：`A=10; A - 8` → `A=2`

4. 取模赋值 (`%=`) 运算符 这种运算符负责将左侧的除法余数返回给右侧的值。
   `A= 10; A %=8` → `A=2`
   等同于表示：`A= 10; A % 8` → `A=2`

5. 整数除赋值 (`//`) 运算符 这种运算符负责计算左侧变量与右侧值之间的整数除法。
   `A= 10; A //8` → `A=1`
   等同于表示 `A= 10; A // 8` → `A=1`

6. 乘法赋值 (`*=`) 运算符 这种运算符负责将左侧变量乘以右侧的值。例如：
   `A= 10; A *=8` → `A= 80`
   等同于表示：`A=10; A * 8` → `A=80`

7. 除法赋值 (`/=`) 运算符 这种运算符负责将左侧变量除以右侧的值。
   例如：
   `A= 10; A /=8` → `A=1,25`
   等同于表示 `A=10; A /= 8` → `A=1,25`

8. 幂赋值 (`**`) 运算符 这种运算符负责计算左侧变量的右侧值的幂。例如：
   `A= 10; A **= 8` → `A = 100000000`
   等同于表示 `A=10; A ** 8` → `A=100000000`

### 特殊运算符
这些运算符通常用于程序循环，用于检查重复变量，甚至判断一个元素是否存储在其他元素中。

1. `In` 运算符: 如果一个元素存储另一个元素内部，此运算符将返回 `'True'`。例如：
   `A=[80, 40] 80 in A`
   返回的结果将是 `True` 类型，因为值 80 位于 `A` 中

2. `Is` 运算符: 如果变量中存储的值相同，这种运算符将返回 `True`。例如：
   `X=80; Y=80` → `X is Y`
   返回的结果将是 `True` 类型，因为两个变量包含相同的存储值。

3. `Not in` 运算符: 如果一个元素没有存储在另一个元素内部，这种运算符将返回 `True`。例如：
   `A=[80, 40] 40 not in A`
   返回的结果将是 `False` 类型，因为值 40 位于 `A` 中。

4. `Not is` 运算符: 如果变量中存储的值不相等，这种运算符将返回 `True`。例如：
   `X=80; Y=40` → `X not is Y`
   返回的结果将是 `True` 类型，因为两个变量包含不同的存储值，因此它们是不同的。

### 算术运算符
这些运算符用于执行简单的数学运算。

1. 加法运算符 (`+`) : 这种运算符将加数值类型的值。例如：
   `40 + 40 = 80`

2. 减法运算符 (`-`) : 这种运算符将从数值类型中减去值。例如：
   `40 – 40 = 0`

3. 乘法运算符 (`*`) : 这种运算符将相乘值。例如：
   `40 * 40 = 1600`

4. 除法运算符 (`/`) : 这种运算符负责除法值。例如：
   `10 / 2 = 5`

5. 幂运算符 (`**`) : 这种运算符负责计算幂。例如：
   `10 ** 2 = 100`

6. 整数除法运算符 (`//`) 这种运算符负责计算整数除法。例如：
   `10 // 3 = 3`

7. 取模运算符 (`%`) : 这种运算符负责返回除法的余数。例如：
   `10 % 3 = 1`
