
# 微放射成像（Microradiography）

**微放射成像（Microradiography）**是指利用低能（0.1-10 keV）X 射线穿透微小标本，产生其内部薄层图像的过程。放大率可以通过曝光后，通过光学或电子方法（或两者结合）对初始图像进行放大来几何获得。与其他尺度的放射成像可以显示样品的质量分布和元素组成。如果采用脉冲（闪光）流或时间门检测器，可以捕捉快速变化物体的运动细节。微放射成像在生物学、材料科学、制备材料表征以及等离子体驱动的热核燃料压缩评估中有广泛应用。

![](img/b16805e6127c92641547ee45e5728f7f_1399_2.png)

微放射成像在很大程度上与利用 X 射线产生物体增强图像的增强技术同步发展。晶体的 X 射线显微镜可以使用衍射而非简单的吸收来完善，这种技术被称为通过 X 射线观测的微放射成像，它与用于表征微观结构的多种其他技术互补。参见[X 射线诊断][显微镜]。

![](img/b16805e6127c92641547ee45e5728f7f_1399_3.png)

微放射成像的光源有三类：电子束设备、同步辐射储存环和多层源。最新且最现代的研究是在电子阴极阳极和真空环境中进行的，在其中施加了高电压。参见[X 射线技术]。

![](img/b16805e6127c92641547ee45e5728f7f_1399_4.png)

高能（同步辐射级）电子撞击真空阴极，作为一个大型光源产生高度极化的强烈辐射。同步辐射以纳秒脉冲的高频率发射，每秒可以从光源发射数百到数百万次 X 射线。利用同步辐射进行微放射成像仍仍在发展中。参见[同步辐射]。

X 射线放射技术原理图。X 射线由直线表示。(a) 接触 (b) 投影 (c) 成像 (d) 扫描。

极高温度等离子体可以通过高功率激光加热。这种技术通常达到 10 mm 至 1 mm。多层等离子体主要在软 X 射线区域发射连续谱，跨越几公里，脉冲时间为 0.1-100 ns。同步辐射实验首次于 1982 年进行。参见[等离子体物理学]。

X 射线可以通过四种不同的几何方法获得。其中两种方法（接触和投影法）已使用了十年。然而，由于同步辐射和等离子体源可用，它们取得了显著进展。投影和扫描两种技术需要最复杂的设备。

微放射成像已用于观察不透明材料（例如生物材料）和制造材料（例如材料）的精细细节。光学显微镜长期以来可以观察物体表面并具有很大意义，但分辨率限制在 200 nm。电子显微镜需要多年才能达到亚微米分辨率，直到开发出亚微米细节。软 X 射线源和同步辐射的可用导致了微放射成像的复兴，特别是对于细胞生物学。该技术的使用有助于理解光显微镜可观察的生物结构（高达 200 nm）以及通过分子阵衍射的分子水平（约 1 nm）。无机物质、制造和动态残留的微放射成像具有研究价值。显微镜：光学，反射

## 微针藻目（Microscoida）

硅藻纲中一种常见的放射虫类，认可的 Microypogoida 包含两个物种。它们具有带有生长齿的孔状叶缘。壳和壳门由三角形复合板组成，其中上、下元件还原为二聚体。成对串列排列在肺泡柱中，管足具有独特性。大多数个体表现出凸形上皮，发现于印太平洋地区 1860 至 4290 $\mu$m（1850 至 1340 m）深度处。该分类群尚未发现确定的化石，但上侏罗纪的 Pedohydnaria 可能属于此类。纽约：预留区 [A.S.]。

## 微波电路

产生辐射对微波电路产生影响的物理设备。

微波传输最常用的方法是通过金属空心圆管或矩形管。微波能量包含在这些管内并通过电缆传输。

各种形式的条带被用于电路间的互连，例如微带线，其中在电介质上的金属条带或带带，该电介质粘接在接地基底上。由于微带线路的损耗大于波导中的损耗，它通常只用于短距离。

信息处理中需要滤波器来阻隔高频（低通）、阻隔频率（高通）、消除不需要的频带（带止）或在衰减其他频带的同时允许所需的频带通过（带通）。所有这些都可以使用谐振器、滤波器或其他传输系统制造。见滤波器：微波滤波器。

薄片可用于改变微波的相位或相移。如果薄片涂有光电导体材料并放置在波导中，它将吸收微波功率。这种衰减可以通过在波导路径中插入多或少的损耗条带来实现。见衰减：电子学。

移相器在不改变微波幅度的情况下改变微波相位。它可以以与衰器相同的方式通过阻塞部分损耗条带来构造。

衰器具有较大的损耗，用于阻隔高频信号和不需要的信号。它在降低信号功率水平而不产生反射。见放大器：微波：半导体。

热电计探测微波功率，引起温度升高电阻变化。热电计的速度不够快，无法响应信号的变化。

环路器是一种无损、非端口环路电路，其在一个方向上的相位移比另一个方向大 180 度。它用于隔离和频率分离。见方向：隔离器。

三端口电路具有以下特性：功率从端口 1 进入，从端口 2 输出，完全不进入端口 3。微波相位移是在波导中使用微波接头和外部磁体实现的。

隔离器是一种固态设备，其电容随电压变化变化。变容器用于从低频信号或电压控制振荡器获取微波功率。见变容器：振荡器。

微波放大器将低功率转换为高功率输出，同时保留一个或多个特性，例如输入信号的频率和相位。当使用线性放大器时，输出幅度往往保持恒定，输入信号的相位保持不变。

高功率输出通过电子管和行波管（TWT）实现，它们可以在微波范围内工作。中等功率通过晶体管放大器实现，它们的有用频率范围不断增加。积分和参数放大器实现了极低的噪声水平，两者都以牺牲同一电路为代价产生功率。见放大器：参数放大器。

## 微波集成电路

微波电路分为混合或单片集成电路（MMIC），它们由单个基底上的所有源性和无源器件组成。单片集成基底通过互连线连接。
