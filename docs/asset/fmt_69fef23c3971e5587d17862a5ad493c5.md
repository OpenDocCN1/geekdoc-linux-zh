从这三个 `ls` 输出中，你可以观察到设备的一些微差异。例如，Series 700 的类别为音频和软盘，Series 800 具有多路用器，而 V 类具有网卡。

你可以使用 `ioscan` 显示特定外设的设备文件。回到连接了四个磁盘和一个光驱的 Series 800，你可以执行以下 `ioscan` 命令来查看与磁盘相关的设备文件：

```
$ /usr/sbin/ioscan -fn -C disk
```
