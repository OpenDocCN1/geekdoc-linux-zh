
# X 射线晶体学 (X-ray crystallography)

通过 X 射线衍射技术研究结构。对于实验结构，它是原子的三维周期排列。这种模式的周期穿过给定的空间点，即单晶。如果通过衍射图已知构成晶体的所有原子的位置，就可以确定任何晶体的精确结构。晶体内原子非常接近且周期性的排列允许 X 射线发生衍射。见 晶体学 (CRYSTALLOGRAPHY)。

## 2402 X-衍射

X射线衍射：X射线被物质散射，由于干涉效应，在不同方向上产生不同变化的强度。X射线衍射是固体化学中最重要的工具之一，因为它为物质中的原子排列提供了一种强大且易于实现的方法。X射线衍射方法基于这样一个事实：1纳米米量级的X射线波长易于获得，而这一量级正是原子尺寸的数量级。当产生X射线束时，这些波从样品中的所有原子扩散出来，不同原子散射辐射的干涉导致辐射强度在各个方向上出现极大值和最小值。衍射。

用途。X射线衍射和无晶态材料的用途：

(1) 区分晶态和无晶态材料；
(2) 确定晶态材料的结构、晶胞的大小和形状以及晶内原子的位置；
(3) 确定晶胞内的电子密度；
(4) 确定晶体的取向；
(5) 确定多晶材料的织构性；
(6) 鉴定晶相；
(7) 测量相对比例；
(8) 测量溶解度极限并确定相；
(9) 测量各种随机性、晶粒、无序性并鉴定缺陷；
(10) 测量无晶态固体和液体的径向分布函数。

技术。下文讨论了研究晶态样品、液体和气体时采用的技术。

劳厄法（Laue method）。劳厄花样利用35-50 keV X射线管连续谱提供的多色X射线。衍射束的强度方向由米勒指数为 `hk` 的一组晶面的取向决定。透射劳厄花样曾用于结构确定，但其许多缺点使其在实际上已经过时。在最近案例中，背反射法已从晶体研究中获得了巨大收益。

**X射线光学** 凭借光学科学，X射线中具有与光相似性质的方面可以用来制造类似于可见光光学器的X射线仪器。这些仪器利用反射镜、偏带、透镜、棱镜和光栅等光学元件将X射线色散为光谱成分。X射线光学在许多领域都很重要，包括X射线文学、生物、医学、核物理和X射线晶体学。构建聚焦来自光源和同步辐射储存环的X射线仪器是重要的。参见几何光学；光学；物理；衍射。

当 `W. C.` 伦琴在 1895 年发现它时，他尝试用各种材料的反射镜、棱镜和透镜进行反射和聚焦。他的由于是一个明显的事实：短波长材料的折射率远小于1。此外，X射线会被材料吸收。

尽管表面在大角度掠射时的反射率很小，但可以通过沉积一系列具有高值和低值 `δ` 的超薄膜来增强反射。这些薄膜的底层厚度经过设计，使得来自每个界面的反射在表面顶部发生相长干涉。这种多层光学用于可见光。然而，多层反射镜需要数百纳米的厚度才能产生足够的反射……

作为聚焦光学元件的涂层，多层结构允许反射镜用于更短波长（更高的X射线能量），从而提高实验的收集效率。在长于 3 或 4 nm 的波长下，可以使用多层反射镜制造具有高反射能力的法入射镜。例如，由铝和硅组成的交替层在 13 nm 及更长波长下的反射率高达 65%。这些反射镜已用于构建光学系统，以定量确定许多组织、特殊组织（A.E.）的水分和元素组成，专门用于可见光的许多X射线光学。例如，法入射X射线望远镜波长约为 18 nm。波长为 13.5 nm 的多层光学可以通过投影小于 10 nm 的特征用于X射线显微。

# X射线粉末法

用于物质鉴定以及其他类型的分析，主要针对晶态材料。在技术上，单色X射线束射向粉末样品，并在胶片或探测器上记录衍射图样。这种X射线图样源于元素的原子排列。高能电子照射样品时会电离样品中的原子，发射特征X射线，其波长取决于原子序，且与元素状态（固体或液体）无关。不同物质具有不同的衍射图样。
