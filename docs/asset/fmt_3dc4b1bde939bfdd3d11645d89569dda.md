## 使用 GRUB 和 LILO 引导加载

引导加载程序帮助您启动安装在系统硬盘上的操作系统。Linux 操作系统允许您从两个引导加载程序 `GRUB` 或 `LILO` 中进行选择。安装程序后打开计算机时发生的第一个过程是启动。启动过程通过启动序列进行，该序列由一组启动计算机的初始指令组成。引导加载程序是一个负责计算机加载并启动 Linux 系统的应用程序。它可以通过以下方式调用：

- 基本输入输出系统 (BIOS) 将控制权传递给安装在驱动器主记录引导 (MBR) 中的初始程序加载器 (IPL)。
- BIOS 将控制权传递给另一个引导加载程序，后者又将控制权传递到安装在分区引导区内的 IPL。

`GRUB`，全统一引导加载（Grand Unified Boot Loader），是随 Linux 一的 GNU 引导程序。当您启动计算机时，`GRUB` 存在于您的系统硬盘上并启动 Linux。这是计算机启动后发生的第一件事。`GRUB` 是动态配置的（动态配置的配置在 Linux 操作系统启动时加载）。它还包括镜像选择、多引导和非多引导操作系统的启动功能。`GRUB` 可以从任何设备运行，如软盘、CD-ROM、USB 驱动器或网络。

`LILO` 代表 Linux Loader。`LILO` 加载器不依赖于任何文件系统，可以从软盘和硬盘启动操作系统。在某些 Linux 发行版（如 `Slackware`）中，`LILO` 是默认加载器而非 `GRUB`。`LILO` 放置在主记录引导 (MBR) 中，可以启动系统的每个分区。在我们案例中，我们将学习安装 `GRUB` 引导加载程序。您也可以根据需要使用 `LILO` 引导加载程序启动系统。如果您想使用 `LILO` 引导加载程序，可以通过两种方式实现。如果您正在重新安装任何 Linux 发行版，或它已安装在您的系统中，那么您首先需要下载最新版本的 `LILO`，然后以 `root` 用户身份在终端中输入以下命令：

```
/sbin/lilo -v
```

`LILO` 加载器不依赖于任何文件系统，可以从软盘和硬盘启动操作系统。在某些情况下，`LILO` 的默认的配置位于 `/etc/lilo.conf`。在我们的情况下，建议您使用 `GRUB` 引导加载程序启动您的设备，如 U 盘或外部硬盘。
