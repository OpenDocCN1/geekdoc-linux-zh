## 随机和重复图标

| 图标 | 设置 | 点击图标后发生的情况 |
|---|---|---|
| ⇄ | 随机关闭 | 歌曲一个接一个播放。 |
| ↗ | 随机开启 | 歌曲按随机顺序播放。 |
| ↷ | 重复关闭 | 歌曲不重复。 |
| | 重复当前歌曲 | 同一歌曲反复播放。 |
| 🔁 | 重复所有歌曲 | 列表中的所有歌曲反复播放。 |
