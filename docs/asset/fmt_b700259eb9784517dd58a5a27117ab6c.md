
# 描述音乐声音时

进入音乐声学描述时，经常使用四个属性：响度、音高、音品和持续时间。每种主观特性都取决于一个或多个可测量的物理参数。例如，响度主要取决于声压，但也取决于分音的频谱和物理持续时间。音高主要取决于频率，但也在较小程度上取决于声压和包络。音品包括所有用于区分具有相同音高和响度的声音的属性。将声音的物理特性与物理参数联系起来是心理声学中的一个核心问题，而音乐声学专家也关注音乐声音中存在的同样问题。参见“心理声学”。

声压级使用声级计测量，通常使用适当的参考水平和加权网络，以分贝（`dB`）的对数尺度表示。通过测量不同频率下的声压级，可以计算出以宋（`sones`）为单位的响度，它描述了平均听众听到的响度感觉。音乐家更喜欢使用从 `ppp`（非常弱）到 `fff`（非常强）的力度标记。参见“分贝”；“响度”；“声压”。

音高被定义为听觉感觉中允许声音按从低到高的尺度进行排序的那个属性。音高通常与音乐音阶相关，其中八度音程（而非临界带宽）是“自然的”音高间隔。参见“音高”；“音阶（音乐）”。

音品被定义为听觉感觉中允许听者判断两个感知相似且具有相同响度和音高的声音为不同的那个属性。音品主要取决于声音的频谱，但也取决于波形、声压、频谱的频率位置以及声音的时间特性。人们发现不可能构建单一的音品主观尺度（如响度的单一尺度）；相反，人们构建了多维尺度。“音色”一词常用来指音品中归因于音调稳态部分的那部分，但时间包络（尤其是起始音）也被发现对确定音品非常重要。

与音乐感知相关的另一个主题是组合音。当两个频率接近的音同时发声时，通常会听到拍音，其速率等于它们的频率差，直到拍音或频率差 `f` 超过约 `15` 赫兹；拍音感觉消失，并出现粗糙感。随着 `f` 进一步增加，会达到一个点，此时“用的”在平均频率处的音让位于两个音，仍然伴有粗糙感。基膜上的共振频率现在分开得足够大，能给出两个不同的音高，但激振重叠产生粗糙感。当分离度 `*` 超过临界带宽宽度时，粗糙感消失，两个音开始融合。参见“耳朵（脊椎动物）”。

古希腊的毕达哥拉斯被认为发现，由以简单比例（如 `2:1`、`3:2` 或 `4:3`）分成两部分的振动弦产生的音调听起来是和谐的。这些比例定义了所谓的纯音程，它们被认为具有最大的协和性。音乐中的其他协和音程包括大六度（`f2/f1 = 5/3`）、大三度（`f2/f1 = 5/4`）、小三度（`f2/f1 = 8/9 = 4/27`）、大六度（`f2/f1 = 8/9`）和小六度（`f2/f1 = 8/9 = 4/27`）。为什么某些音程比其他的更协和？H. 亥姆霍兹得出结论，当两个音的分音产生每秒 `30` 到 `40` 次拍音（这些拍音没有被听为拍音，而是产生粗糙感）时，不协和性（协和性的对立面）最大。一个音的分音与另一个音的分音在频率上重合得越多，产生粗糙感的可能性就越小。这解释了为什么简单的频率比定义了最协和的音程。最近的研究得出结论，协和性与临界带宽有关。如果两个纯音之间的频率差大于一个临界带宽，它们听起来是协和的；如果小于一个临界带宽，它们听起来是不协和的。最大不协和性出现在 `*` 约为一个临界带宽的 `1/4` 时，这与亥姆霍兹关于 `500` 赫兹左右音调的标准相当吻合。

## 乐器

产生音乐声音的乐器长期以来被分类为木管、铜管、打击乐器或弦乐器；在这些分类中必须添加电气和电子乐器。在声学中，所有乐器仅仅是共振器，并扩展了原始乐器——人声歌唱——的能力。上述类别对于按它们产生的声音类型对乐器进行一般性分组是有用的，尽管木管乐器不一定由木材制成，铜管乐器也不一定由金属制成。

### 木管乐器

木管乐器主要的特点是，通过依次打开侧孔来缩短振动气柱的有效长度。采用两种明显不同的方式产生声音。对于长笛及其半尺寸版本短笛，演奏者在靠近一端的吹口处吹气，使有节奏的空气脉冲进入管中；这些脉冲通过湍流转折纵向激发气柱。这种激励方法在声学意义上使管子保持开放状态，因为管内的空气振动就像在两端都通向大气的简单管子中那样。对于双簧管或大管，演奏者在双唇之间持有一对薄簧片（适当变薄、刮削并绑在一起的芦苇片），它们相互碰撞，将演奏者的呼吸转化为空气脉冲。对于萨克斯管等单簧管乐器，通过配重环附在吹口上的单个簧片以类似方式工作。簧片碰撞的吹口部分（斜面）必须近似为曲线形；声音的特性还受到吹口体积以及簧片的形状和材料的修改。

对于单簧管和双簧管乐器，簧片在从气柱远端反射回来的声波影响下振动，并在乐器内部声压较大时允许空气脉冲进入。因此（与长笛相反），簧片端的空气振动与声学上闭合的分支相关联。

### 铜管乐器

典型的铜管乐器由杯形吹口、略微锥形的吹管、包括用于改变音高的阀门的圆柱形管，以及通过拉伸在吹口上的振动嘴唇引入的空气脉冲组成。其作用类似于单簧管，即吹口端在声学上几乎闭合。气柱的长度通过使用活塞式或旋转式阀门切换管来增加；常见的布局是，第一个阀门使音高降低两个半音，第二个降低一个半音，第三个降低三个半音。对于给定长度的管子，通过紧张嘴唇以激发不同振动模式产生不同的音调，其频率大致符合 `2:3:4:5:6:8` 的比例。

### 打击乐器

定音鼓（锅形鼓）和木琴等乐器被称为打击乐器，因为声音是由敲击开始的。涉及两种类型的声源：与腔体相关的张紧膜（腔体可以影响振动频率，如定音鼓的情况）；以及横向振动的刚性条或板（其频率很少受可能附着的共振器的影响）。一些打击乐器发出定义明确的声音，激发确定的音高感觉，如教堂钟声；其他乐器，如鼓、钹和三角铁，主要用于节奏效果。

### 弦乐器

对于吉他和竖琴，通过拨动使弦振动；对于其他弦乐器，振动通常由拉弓启动并保持。振动频率主要由

弦的`长度`、`张力`和单位长度的`质量`。弦不仅以最低（基频）频率振动，同时也以趋近于基频整数倍的高次频率同时振动。因此，从乐器中辐射出的声音是复杂的。

弦乐器声音的辐射通过一个由近乎封闭的空腔组成的共鸣器得到增强。振动弦的一部分能量通过琴桥传递到空腔的壁上。在一把精心制造的提琴中，空腔的共振和振动壁的共振在频率上分布得当，以便在整个乐器的演奏音域内提供相对均匀的反应。

#### 键盘乐器

像 celesta（钢片琴）、管风琴、手风琴和钢琴这样的乐器通常被归入称为键盘乐器的一组，因为这些乐器中各自的振动簧片、管子、簧片和弦是通过键盘上的键选择来激振的。Celesta 和钢琴也可以被描述为打击乐器，因为琴槌敲击簧片和弦；管风琴和带有风驱自由簧片的手风琴是气鸣乐器。凭借其多重键盘（和脚键盘），管风琴将数以千计的独特声源置于单一演奏者的控制之下，这些声源的声音可以按指令再现。[F-W]

#### 电气、电子和软件乐器

电气乐器产生电气音调信号用于放大（和扬声器聆听），而不使用调谐的机械振动器或空气柱。早期的电气乐器早于电子技术，通过电磁或静电旋转机械产生其音调信号。后来，大多数乐器变成了电子乐器，从真空管电路，然后晶体管电路，再到现在的集成电子电路产生音调信号。在20世纪80年代，电子乐器从模拟过渡到数字，提供了更精确的调音（以及替代调音方式）和配置的可重复性。参见[集成电路](https://example.org/integrated_circuits)。

在电子乐器的进化过程中，使用过许多不同的声音生成手段。至少在概念上，最简单的电子方法是用电子电路源或软件算法直接替代每个传统的机械（弦、簧片）或声学（共振空气柱）声源，这些算法生成相同的复杂音调波。然而，在音阶的不同部分，同一乐器的波形通常不同。此外，键盘乐器要求同时产生许多音调。因此，与其他方法相比，替代方法在经济上不太可行。参见[波形](https://example.org/waveform)。

加法合成法通过将一个适当数量的简单（正弦）波在谐波相关频率上相加来合成每个所需的复杂音调，谐波波的相对振幅可调整以产生所需的合成波形。加法合成至少从20世纪60年代起就在计算机音乐领域得到广泛应用，并且它是几种小批量生产硬件设备的基础。然而，在当前的音乐合成器中，通常有比加法合成更有效的方法来产生所需的声音，而大批量生产的电子乐器通常不是基于加法合成。但是，加法合成的概念仍然很重要，并且有密切相关的衍生技术，如正弦建模和组加法合成。

减法合成在原理上与人类语音系统中语音（和歌唱）声音的形成相似。在每个所需的音乐频率上，电子电路产生一个标准的基本音调波形（如锯齿波），它已经包含了许多在已知相对振幅下的谐波。然后，乐器中提供多种电或电子滤波器；在开关选择下，单独或共同地，将基本音调信号转换为所需的音乐音调波形。减法合成在某种程度上是加法合成的反面，因为它实际上减去不需要的谐波，而不是加上去需要的谐波。半个多世纪以来，减法合成一直是大多数语音合成器的基础。参见[电子滤波器](https://example.org/electric_filter)、[函数发生器](https://example.org/function_generator)、[波形整形电路](https://example.org/wave_shaping_circuits)。
