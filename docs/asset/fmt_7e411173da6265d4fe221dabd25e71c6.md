vat

基于互联网的 LBNL 音频工具。LBNL 音频工具 `vat` 是一种用于互联网音频会议的实时、多方、多媒体应用程序。它基于 IETF 音频/视频工作组开发的实时传输协议（RTP）草案标准。RTP 是一个完全实现在内部的应用程序层协议，不需要任何特殊增强即可处理 RTP。虽然它可以使用标准 IP 地址进行点对点运行，但主要目的是作为多方会议应用程序。为了利用会议功能，你的系统必须支持 IP 多组播（IP Multicast），理想情况下，你的网络应该连接到 IP 多组播骨干网（MBone）。`Vat` 提供作为应用程序实现的工具。我们的视频工具称为 `vic`，白板工具称为 `wb`，UCL 开发了会话目录 `tdr`。其他相关应用包括 ISI 的多媒体会议 `mmcc`，Xerox PARC 网络视频工具 `nv` 以及 INRIA 的视频引用系统 `isvs`。来自 Debian 3.0r APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

VAX

`/vaks/` n. 1. [来自 Virtual Address eXtension，虚拟地址扩展]工业史上最成功的微型计算机设计，可能超过了它的祖先 PDP-11。在 1978 年发布到 1986 年后制造的杀手级微处理器取代之间，VAX 可能是所有黑客中最喜欢的机器，特别是在 1982 年发布 4.2 BSD Unix (BSD) 之后。它并不是因为它对汇编器程序员友好的指令集——这一资产在 RISC 革命中变成了一种负担。2. 英国一个主要的吸尘器品牌。被引用是因为它的页面“Nothing like a VAX!（没有什么像 VAX！）”是 RISC 分支的一种战斗口。甚至认为 DEC 实际上与生产吸尘器的人达成了一项交叉许可协议，允许他们在英国销售 VAX 计算机，而不挑战美国的吸尘器市场。一个竞争品牌实际上生产了口号：其原句是“Nothing like Electrolux（没有什么像伊莱莱克斯）”。这显然已成为不了解当地俚语风险（用于广告教科书）的经典案例。但在 1996 年，Electrolux AB 的新闻经理在确认公司犯了错误的同时也告诉我们，他们的营销人员意识到这种可能的双关含义，并打算借此获胜。并引起了关注——VAX-吸尘器的人认为这个口号是一个足够好的主意，值得复制。一些英国人报道称 1987–1986 年使用了 VAX 促销活动，我们从新西兰词典中看到那个臭名昭著的 vax 出现在广告中。来自术语词典 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
