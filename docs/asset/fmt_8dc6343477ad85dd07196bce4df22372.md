## 移除

22 列表重复项

如果你想移除列表中的重复项，只需将每个元素放入字典（如带有 `'None'` 的示例所示），然后检查字典的键即可。

```python
from operator import itemgetter
def deduplicate(list):
    d = dict(map(itemgetter(1), list, [None]*len(list)))
    return d.keys()
```
