## 启动 FTP 服务器

在按照您的喜好配置好 FTP 服务器后，您需要启动它。输入以下命令来启动服务器：

```
[root@root]# service vsftpd start      [ OK ]
Starting vsftpd for vsftpd:
```

此命令启动当前会话的 FTP 服务器，但没有设置服务器在每次系统启动时自动启动。要确保 FTP 服务器在系统启动时启动，请输入以下命令：

```
chkconfig -level 35 vsftpd on
```
