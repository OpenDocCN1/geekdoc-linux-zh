# 理解 IP 地址

IP 地址是一个由四部分组成的数字，每部分由一个 0 到 255 之间的数字表示（总共 256 个数字）。IP 地址的某些代表计算机所在的网络，而另一部分则标识该网络上的特定主机。以下是一个 IP 地址的示例：

```
192.168.35.121
```

最初，IP 地址根据 IP 地址分类进行分组，并分配给需要 IP 地址的组织。后来，创建了一种更高效的方法，称为无类域间路由（CIDR），以改进路由并减少 IP 地址的浪费。接下来的章节将描述这两种 IP 地址方法。

# IP 地址分类

遗憾的是，如果没有一些关于 IP 地址结构的解释，就很难理解 IP 地址的哪部分代表网络，哪部分代表主机。IP 地址的分配方式是给网络管理员分配一个地址池。当新计算机被添加到组织的本地局域网时，管理员可以在该池中分配特定的主机地址。IP 地址有三个基本类，每类代表一个不同规模的网络：

- `Class A` — `Class A` 地址的第一部分是 0 到 127 之间的数字。`Class A` 网络内的主机由后三部分中的任何数字组合表示。因此，一个 `Class A` 网络包含数百万个主机（大约 256×256×256，少数特殊数字是无效的）。整个 `Class A` 网络曾只分配给最大的组织，但据我所知，不再如此。一个有效的 `Class A` 网络是：
  - `24.`

- `Class B` — `Class B` IP 地址的第一部分是 128 到 191 之间的数字。然而，对于 `Class B` 网络，第二部分也代表网络。这使得 `Class B` 网络可以拥有 64,000 个主机地址（256×256）。整个 `Class B` 网络也很少被分配。一个有效的 `Class B` 网络数字是：
  - `135.84`

- `Class C` — `Class C` IP 地址的第一部分是 192 到 223 之间的数字。对于 `Class C` 网络，IP 地址的前三部分代表网络，而只有最后部分代表特定的主机。这使得每个 `Class C` 网络可以有 254 个数字（数字 0 和 254 不能分配给主机）。以下是一个 `Class C` 网络数字的示例：

```
194.122.56.0
```

在创建 IP 地址时，没有人预料到尽管这种方案代表了数百万个潜在地址，但并没有足够的地址供使用。现在，如果你从互联网获得分配的官方地址池，你将获得一个 `Class C` 地址或 `Class A` 或 `Class B` 地址的一部分。问题变成了：如何在不同网络之间划分网络号？答案是：使用子网掩码（netmask）。

# 理解子网掩码

假设你分配了 `Class B` 地址 `135.84`，但只给了你地址 `135.84.118` 的可用数字池。你如何告诉你的网络每个以 `135.84.118` 开头的地址代表你网络上的一个主机，而其他以 `135.84` 开头的地址应该路由到另一个网络？答案是使用子网掩码。

子网掩码本质上标识了网络的网络号。当你将与计算机关联的 IP 地址分配给局域网（`eth0`）时，系统会要求输入子网掩码。默认情况下，你的计算机将填充一个数字，掩码 IP 地址中代表网络分类的部分。例如，`Class A`、`Class B` 和 `Class C` 网络的默认子网掩码为：

- `Class A`：`255.0.0.0`
- `Class B`：`255.255.0.0`
- `Class C`：`255.255.255.0`

现在，如果你的网络被分配了网络号 `135.84.118`，为了告诉计算机 `135.84.118` 是网络号而不是 `135.84`（像通常的 `Class B` 地址那样），请添加 `255.255.255.0` 的子网掩码。因此，你的网络有 1 到 254 的可用主机（这些将进入数字的第四部分）。

为了让问题变得更加复杂，你可以只掩码 IP 地址中的一个或多个位。你不需要使用数字 255，而是可以使用 1 到 254 之间的任何其他数字来仅掩码该地址中该部分的一部分数字。

# 无类域间路由

分类 IP 地址的方法有几个主要缺点。首先，分类方法对于许多组织来说太小了。其次，路由器过载了。无类域间路由（CIDR）方案是为了解决这些问题而开发的。与其使用分类，CIDR 在分配 IP 地址方面提供了更大的灵活性。例如，互联网服务供应商可以被分配一个 `/13` 网络。CIDR 方案还通过通过路由表示许多网络来帮助减少路由问题。这里是一个 IP 地址的表示示例：

```
128./18
```

在这个示例中，前 18 位代表网络，其余部分代表主机。以下列表显示了有多少个主机：

- `/13`：524,288
- `/14`：262,144
- `/15`：131,072
- `/16`：65,536
- `/17`：32,768
- `/18`：16,384
- `/19`：8,192
- `/20`：4,096
- `/21`：2,048
- `/22`：1,024
- `/23`：512
- `/24`：256
- `/25`：128
- `/26`：64
- `/27`：32

# 获取 IP 地址

所以，为局域网上的计算机分配 IP 地址有什么影响？你选择什么 IP 地址取决于你的情况。如果你是一个大型组织的一部分，你应该从组织的管理员那里获取地址。即使你不连接其他局域网，拥有唯一的地址也可以让未来连接其他网络变得更容易。
