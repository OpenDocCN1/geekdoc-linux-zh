# 逻辑卷摘要

在查看了连接到系统的磁盘后，查看逻辑卷的摘要信息将非常有帮助。以下名为 `audlvsum.sh` 的脚本提供了系统逻辑卷的摘要：

```bash
#!/usr/bin/ksh

USAGE="Usage: $0 [-d]"

VOLORDER='y'  #默认按逻辑卷排序

              n = 按磁盘排序

while [ $# -gt 0 ]; do

  case "$1" in

-d ) VOLORDER='n'

;* ) echo "unrecognized option: $1"

echo USAGE

exit 1

esac

shift

done

if [ "$VOLORDER" = "y" ]

then

FINISH=sort

else

FINISH=cat

fi

# 根据命令行选项确定排序顺序
```
