
# find stdin stdout -file --opt --help --version

```
find [directories] [expression]
```

`find` 命令在一个或多个目录（递归其子目录）中搜索符合特定标准的文件。它非常强大，拥有 50 多个选项，遗憾的是其语法相当特殊。以下是从当前目录（用 `.` 表示）搜索整个文件系统的简单示例：

查找名为 `myfile` 的特定文件：

¹ tc shell 执行了一些技巧让 `which` 能够检测别名。

```
find . -type f -name myfile -print
./myfile
```

打印以“myfile”开头的文件名（注意通配符是如何转义的，以便 shell 忽略它）：

```
find . -type f -name "myfile*" -print
./myfile.zip
./myfile3
./myfile
./myfile2
```

打印所有目录名称：

```
find . -type d -print
.
./jpegexample
./dir2
./mydir
./mydir/dir
./dir1
./dir3
./d
```

## 有用选项

- `-name pattern`
- `-path pattern`
- `-iname pattern`

所需文件的名称 (`-name`)、路径 (`-path`) 或符号链接目标 (`-lname`) 必须匹配此 shell 模式，该模式可能包含通配符 `*`、`?` 和 `[]`。（但是，你必须转义通配符，这样它们会被 shell 忽略并原样传递给 `find`。）路径相对于正在搜索的目录树。

- `-iname pattern`
- `-ipath pattern`
- `-iregex pattern`

`-iname`、`-ipath` 和 `-iregex` 选项分别对应 `-name`、`-path` 和 `-regex`，但不区分大小写。路径（相对于正在搜索的目录树）必须匹配指定的正则表达式。

- `-type t`

仅查找类型为 t 的文件。这包括普通文件 (`f`)、目录 (`d`)、符号链接 (`l`)、块设备 (`b`)、字符设备 (`c`)、命名管道 (`p`) 和套接字 (`s`)。

- `-atime` / `-mtime` / `-ctime`

文件最后访问 (`-atime`)、最后修改 (`-mtime`) 或状态发生变化 (`-ctime`) 恰好在 N*24 小时前。使用 `+N` 表示“大于 N”，使用 `-N` 表示“小于 N”。

- `-amin` / `-mmin` / `-cmin`

文件最后访问 (`-amin`)、最后修改 (`-mmin`) 或状态发生变化 (`-cmin`) 恰好在 N 分钟前。使用 `+N` 表示“大于 N”，使用 `-N` 表示“小于 N”。

- `-newer file`

文件最后访问、修改或状态发生变化比 `other_file` 更晚。

- `-mindepth` / `-maxdepth`

考虑搜索目录树中至少 (`-mindepth`) 或至多 (`-maxdepth`) N 层深的文件。

- `-L`

解引用符号链接。

- `-depth`

使用深度优先搜索：在对目录本身操作之前，完全搜索（递归）该目录的内容。

- `-xdev`

将搜索限制在单个文件系统中（即不跨越设备边界）。

- `-size n[cwbkMG]`

考虑大小为 N 的文件，可以用块 (`b`)、单字节字符 (`c`)、千字节 (`k`) 或兆字节 (`M`) 给出。使用 `+N` 表示“大于 N”，使用 `-N` 表示“小于 N”。

- `-empty`

文件大小为零，且是普通文件或目录。

- `-user name`

文件由指定用户所有。

- `-group name`

文件由指定组所有。

- `-perm mode`

文件具有指定权限。

- `-exec command {} +`

- `-exec command {} \;`

- `-print`

- `-not` / `!`

- `-o` / `-or`

- `\( ... \)`

## 有用选项 (xargs)

- `-n k`

向每个执行的命令提供 k 行输入。常用的 `-n1` 保证每次执行都只处理一行输入。否则，`xargs` 可能会将多行输入传递给单个命令。

- `-0`

将输入的行尾字符设置为 ASCII 零而不是空白字符，并字面意思处理所有字符。当输入来自 `find -print0` 时使用此项。

# locate stdin stdout -file --help --version

```
locate [options]
```

`locate` 命令配合其伙伴 `updatedb` 创建文件位置的索引（数据库），可以快速搜索。¹ 如果你计划在一个长期变化不大的目录层次结构中长时间搜索许多文件，`locate` 是一个很好的选择。对于定位单个文件或对找到的文件进行更复杂的处理，请使用 `find`。

某些发行版会定期对整个文件系统进行索引（例如每天一次），因此你只需运行 `locate` 即可使用。但如果你需要自己为某个目录及其所有子目录创建索引（例如存储在 `/tmp/myindex` 中），请运行：

```
updatedb -l 0 -U directory -o /tmp/myindex
```

（注意 `-l` 是小写的 `l` 后面跟着一个零，而不是数字 `10`。） 然后要在索引中搜索字符串：

```
locate -d /tmp/myindex string
```

`locate` 有一个有趣的可选安全功能。你可以创建一个索引，该索引在被搜索时，只会显示用户许可查看的文件。因此，如果超级用户创建了一个受保护目录的索引，非超级用户可以搜索它但看不到受保护的文件。这是通过省略 `updatedb` 的 `-l 1` 选项并以 root 身份运行实现的：

```
sudo updatedb -U directory -o /tmp/myindex
```

> ¹ 我们的 `locate` 命令来自名为 "mlocate" 的包。某些系统有一个较旧的包名为 "slocate"，用法略有不同。如果你有 `slocate`，只需在示例中将 `updatedb` 替换为 `slocate` 即可。

## updatedb 索引选项

| 选项 | 说明 |
| :--- | :--- |
| `-u` | 从根目录向下创建索引。 |
| `-U directory` | 从目录向下创建索引。 |
| `-l (0\|1)` | 关闭 (0) 或开启 (1) 安全。默认为 1。 |
| `-e directories` | 从索引中排除一个或多个目录。用逗号分隔它们的路径。 |
| `-o outfile` | 将索引写入文件 outfile。 |

# which stdin stdout -file --opt --help --version

```
which file
```

`which` 命令在你的 shell 搜索路径中定位可执行文件。如果你通过输入名称来调用程序：

```
who
```

该命令告诉你此命令所在的位置：

```
which who
/usr/bin/who
```

你甚至可以找到 `which` 程序本身：

```
which which
/usr/bin/which
```

如果搜索路径中的多个程序具有相同的名称（例如 `/usr/bin/who` 和 `/usr/local/bin/who`），`which` 只报告第一个。

# type stdin stdout -file --opt --help --version

```
type [options] commands
```

`type` 命令像 `which` 一样，在你的 shell 搜索路径中定位可执行文件：

```
type grep who
grep is /bin/grep
who is /usr/bin/who
```

然而，`type` 是内置在 bash shell 中的，而 `which` 是磁盘上的一个程序：

```
type which type rm if
which is /usr/bin/which
type is a shell builtin
rm aliased to /bin/rm -i
if is a shell keyword
```

作为内置命令，`type` 比 `which` 更快；但它只在 bash 等某些 shell 中可用。

# whereis stdin stdout -file --opt --help --version

```
whereis [options] files
```

`whereis` 命令尝试通过搜索硬编码目录列表来定位给定的文件。它可以找到可执行文件、文档和源代码。`whereis` 有点奇怪，因为它的目录列表可能不包含你需要的目录。

```
whereis vim
vim: /usr/bin/vim /etc/vim /etc/share/vim ...
```

## 有用选项

- `-b`：仅列出可执行文件。
- `-m`：仅列出 man 页。
- `-s`：仅列出源代码文件。
- `-B dirs... -f`：在指定的目录中搜索可执行文件。
- `-M dirs... -f`：在指定的目录中搜索 man 页。
- `-S dirs... -f`：在指定的目录中搜索源代码文件。

在列出你寻找的文件之前，你必须使用 `-f` 选项跟随目录列表。

## 文件文本处理

- `grep`：在文件中查找匹配正则表达式的行。
- `cut`：从文件中提取列。
- `paste`：合并列。
- `tr`：将字符转换为其他字符。
- `expand`：在制表符和空格之间转换。
- `sort`：按各种标准对文本行进行排序。
- `uniq`：在文件中定位完全相同的行。
- `tee`：同时复制文件并将其打印到标准输出上。

也许 Linux 最强大的优势之一是文本处理：通过应用转换（通常在管道中）将文本文件（或标准输入）处理成所需的格式。任何读取标准输入并写入标准输出的程序都属于这一类。
