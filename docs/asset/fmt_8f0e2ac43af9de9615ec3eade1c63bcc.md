
在掷硬币的情况下，这导致假设实验中每个点的概率为 1/4。这里每个结果都导致成功或失败，且 `P(S) = p + q`，其中 `p + q = 1`。（这可以被视为公平硬币的模型）。连续 `n` 次独立试验会导致马尔可夫链。马尔可夫链代表了依赖试验的重要方案。假设在状态可能的 `$E_1, ..., E_n$` 且 `$E$` 发生时，下一次试验 `E` 的条件概率与之前试验中发生了什么无关。这里，如果 `p_0 + p_1 + p_2 + ... + p_n = 1`，那么 `p_i` 是转移概率。该过程现在由 `p_{ij}` 定义。

## 概率
尽管概率的定义和术语源自逻辑，但像“约翰会经常来”这样的模糊陈述不如“约翰很频繁”清晰，且它是概率论的产物。概率论构建了自然世界的抽象模型，然后用于描述我们看到事物的频率，或展示生活中事件发生的频率。有限概率空间只能以计数存在（不一定是完美的！）并且首先定义结果。有必要定义元素结果或事件。每个元素结果称为点；样本空间由样本空间定义，必须引入并识别每个结果。

## 事件
在桥牌中，人们可能会询问它是否包含将牌或其他条件。原则上，一个事件是满足条件的样本点集。每个事件都由样本空间的一个事件表示，在概率论中它们是同义的。使用标准符号来描述事件之间的关系。给定事件 `A`，可以考虑 `A` 不发生的情况。这是 `A` 的否定或补集，记为 `A’`

## 期望
随机变量 `$X$` 可以通过其分布 `f(x)` 识别。如果 `$X$` 取离散值 `x_1, x_2, ..., x_n`，对应的概率为 `p_1, p_2, ..., p_n`，则期望 `E(X) = \sum x_i p_i`。在连续情况下，`E(X) = \int x f(x) dx`。

## 随机变量
随机变量 `$X$` 是将样本空间中的每个结果映射到实数的函数。`$X$` 的分布由其概率质量函数（离散）或概率密度函数（连续）描述。分布函数为 `F(x) = P(X \le x)`。

## 独立性
如果两个随机变量 `X` 和 `Y` 是独立的，则对于所有集合 `A, B`，都有 `P(X \in A, Y \in B) = P(X \in A)P(Y \in B)`。这意味着联合密度 `f_{X,Y}(x,y) = f_X(x)f_Y(y)`。

## 协方差和相关性
`X` 和 `Y` 的协方差为 `Cov(X,Y) = E[(X-E_X)(Y-E_Y)]`。它衡量变量之间的线性关系。相关系数为 `\rho_{X,Y} = \frac{Cov(X,Y)}{\sigma_X \sigma_Y}`。

## 马尔可夫链
马尔可夫链是一种随机过程，其每个状态的概率仅取决于上状态，而不是之前的事件序列。它由转移矩阵 `P` 定义，其中 `P_{ij} = P(X_{n+1} = j | X_n = i)`。稳态分布 `\pi` 满足 `\pi P = \pi`。
