# `sed s[:digit:]]//g` '替换'

# `g` 在 `sed` 命令中代表全局（global）；
# （换句话说，不是每行只执行一次替换；
# 在所有行中进行所有可能的替换。）
# 斜杠作为分隔符（或“栅栏”），
# 例如，如果你看到 `'this/that/g'`，那么
# 每次输入包含 `'this'` 时替换为 `'that'`。

# 如果看到 `'///g'`，那么
# 每次输入包含 `'this'` 时替换为空。
# （因为两个斜杠之间没有任何内容，
# 系统知道你想替换为空。）
# '替换为空' 是说“删除”的一种形象说法。
