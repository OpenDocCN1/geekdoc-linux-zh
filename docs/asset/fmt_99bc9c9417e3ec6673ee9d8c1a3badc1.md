
# flavor

+ n. 1. [常用] 种类，类型。.DTD 命令有两种口味 (`flavors`)。“这些灯有两种颜色，大红的和小的。”“Linux 是 Unix 的一种变体 (`flavor`)。” 2. 使事物变得有趣的属性。通常用于短语“产生额外的风味 (`yields additional flavor`)。”“这种约定通过允许文本向右或倒置来增加风味。” 参见 `vanilla`。这种用法无疑被量子色动力学的术语所强化，夸克在夸克（例如，质子的组成部分）中有六种风味（上、下、奇、味、顶、底）和三种颜色（红、蓝、绿）。3. Lisp 机器中用于面向对象意义上的“类” (`class`) 的术语（特别是由 Common Lisp 设施设计的），Lisp 黑客仍将“`flavor`”作为“`class`”的通用同义词。源自日本词典 (`Japon Dictionary`) `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

# flawinder

检查代码安全性。`Flawinder` 遍历 `C/C++` 源代码寻找潜在缺陷，并按可能的严重程度排序。其工作原理与另一个程序 `ITS4` 类似，后者不是开源的。来自 Debian 3.0r0 `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

# flex

快速词法分析器。`flex` 是一个用于生成扫描器的工具，它读取输入并根据正则表达式进行模式匹配。`flex` 生成的 `C` 文件通过编译并链接库生成可执行文件。这种设计比分段更高效。`Flat address space` (`扁平地址空间`)

一种组织计算机内存的方法，操作系统可以无限制地分配部分内存。扁平地址空间的对面是 `MS–DOS` 和 `Microsoft Windows 3.1` 的分段内存架构，它将内存划分为 `64K` 的区域（称为段）。分页内存空间设计更高效，因为处理器不需要将每个内存地址映射到 `64K` 段，但这种设计要求使用 `32` 位内存地址。采用 `32` 位内存地址的 `Microsoft Windows 95` 为你的应用程序创建了扁平地址空间。来自 `QUEDIC` `http://www.ldp.org/LDP/Linux-Dictionary/index.html`
