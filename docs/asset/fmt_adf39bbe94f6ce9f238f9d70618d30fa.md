
$R = \frac{2hc^2}{\lambda^5(e^{hc/\lambda kT}-1)}$

是普朗克定律的表达式，它描述了在温度 $T$ 下，每平方厘米每单位波长的辐射强度（单位为瓦特每平方厘米）。温度 $T$ 以开尔文为单位，$e$ 是自然对数的底。该信息展示了不同温度下的普朗克定律图表，并显示了哪些物质吸收和发射热辐射。

玻尔兹曼定律规定，热体辐射的总能量与物体温度的四次方成正比。可以通过对普朗克定律进行积分推导出，表达式如下（公式 2）：

```
$R = 5.67 \times 10^{-8}T^4$
```

热传递以动能的形式通过三种方式发生：传导、对流和辐射。只有在存在温度差且沿温度降低的方向时，才会发生热传递。这些方式的机制和定律非常不同。参见：热；辐射；传导；对流；热传递。

通过利用热传递发生原理的知识，并对材料进行仔细选择和制造，设计师旨在控制热流。在许多情况下，大量的热必须从某点移动到另一个点，或者沿着其他流体的方向移动。所有方法都被应用于工艺和工业中。

在工业中，通常希望从一种流体中提取热量并添加到另一种流体中。为此目的设计的设备称为热交换器。它们通过板式或管式形式的热交换表面工作。汽车散热器、热水器、蒸汽锅炉、动力发动机中的冷凝器、冰箱以及日常使用的普通餐具都是热交换器。参见：热；交换器。

### 热处理（冶金）
一种对金属材料进行加热和冷却的过程。塑性变形可能包含在加热和冷却步骤序列中，从而定义了热机械处理。热处理的主要目标是硬化、软化、提高加工性、柔性、应力消除和尺寸稳定性。热处理按特殊名称分类，如退火、调质、工艺退火、硬化、回火、渗碳、固溶退火、析出硬化和热机械处理。

在合金中，常用热处理是因为会发生许多相变，它用于控制铁族金属属性的一致性。参见：热；铁。
