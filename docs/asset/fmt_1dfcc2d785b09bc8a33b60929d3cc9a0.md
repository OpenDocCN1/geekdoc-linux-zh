
```c
#include <stdio.h>

int add_them_up( int a, int b, int c )
{
    return a + b + c;
}

int main( void )
{
    int a = 1;
    int b = 2;
    int c = 3;
    int z = 0;
    z = add_them_up( 1, 2, 3);
    printf("Answer is: %d\n", z);

    return 0;
}
```

接下来，通过以下操作产生两个独立的汇编列表——一个用 `-O0` 编译，另一个用 `-O3` 编译：

```bash
$ gcc -O0 -S simple.c
$ gcc -Sahlm simple.s > simple.out.no-opt
$ gcc -O3 -S simple.c
$ gcc -Sahlm simple.s > simple.out.opt
```
