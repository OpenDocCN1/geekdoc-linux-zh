
# 介层与大气

许多介层螨是捕食性昆虫，或者是食腐动物和取食者，对土壤动物群产生影响。某些成员已知是有害的、破坏性害虫；异刺螨科（`Teretodontidae`）。其他形式寄生在昆虫或无脊椎动物上。除了类和蝙蝠，陆生节肢动物是唯一受迁移影响的影响。

介层与平流层之间的过渡带称为介界面。在介层底部，温度随高度增加而降低，而在顶部，温度再次随高度增加。

它们是迁徙鸟、哺乳动物和爬行动物的宿主。寄生它们的介层螨主要有两种：它们是呼吸系统的寄生虫，或者在宿主的组织中生殖。

介层温度相对较低，因为这一层吸收的太阳辐射很少。介界面是介层与平流层之间的边界。介层；气象学；大气；对流层。

中动物（`Meso`）是动物界的一个分类，介于原生动物和后生动物之间。由于缺乏身体对称性、它们的关系，以及专家对其亲缘关系以及对其生命周期事实和解释上的分歧，这些动物是较为人知的门。

在介层顶部，温度随高度增加而降低，而在底部，它随高度增加而增加。这种情况更多发生在冬季以及从冬季到夏季之间。反，，层层部的温度梯度意味着气压大幅波动。

# 中生代

中生代（`Meszoic`）是地质时代显生宙（古生代、中生代和新生代）三大主要划分之一，根据各种同位素年代，涵盖了从 2450 万年前到 6500 万年前（`MA`）。

在中生代，地球比现在温暖得多。中生代的结束标志着一次物种大灭绝事件，该事件消灭了恐龙。

中生代的记录在地质和历史记录中非常剧烈。在中生代初期，所有大陆合并成一个巨大的超级大陆（泛古大陆），海洋和陆地海洋均由大灭绝事件形成。

中生代的结束标志着一次物种大灭绝事件，通常与泛古大陆的分裂有关。

## 代谢疾病

中生代末期的灭绝，被子植物（开花植物）的出现。中生代的结束标志着一次物种大灭绝事件（白垩纪），恐龙的灭绝、陨石影响的崛起、哺乳动物的崛起以及新生代的开始和高级生命形式。

代谢疾病源于核酸的缺乏。先天缺陷导致各种系统的畸形，是核酸的特定遗传的结果。

中生代包含了地质上的三个时期：三叠纪（255–208 Ma）、侏罗纪（208–145 Ma）和白垩纪（145–66 Ma）。这些时期被划分为早期、中期和晚期（白垩纪没有划分）。每个时期又被划分为阶段，基础是不整合面（侵蚀面），或代表海洋、河流或演化的变化。白垩纪；侏罗纪；三叠纪。

遗传突变导致严重免疫缺陷综合征（`SCID`），导致淋巴细胞减少和抗体产生不良。淋巴细胞涉及移植物肿瘤排斥，这种异常与特定蛋白质缺乏有关。适应性免疫；组织；疾病；遗传；遗传酸。

蛋白质。蛋白质异常的疾病与氨基酸浓度增加、蛋白质缺乏、蛋白质合成以及异常氨基酸的排出有关。

蛋白质量的减少（尿蛋白）可能由于蛋白质合成酶缺乏、代谢阻塞或其他因素引起，特别是在肾脏疾病中。低蛋白血症也源于营养缺乏。在高球蛋白血症和低蛋白血症中，可能同时发生，血清蛋白显著降低，但球蛋白可能占总蛋白的 15-20%。高免疫球蛋白血症。

## 梅西星表

星云和恒星早期列表。查尔斯·梅西（1730–1817）最初对发现彗星感兴趣。他关于可能被误认为是彗星的天体列表随后于 1771 年在皇家科学院上发表。该汇编包含了球星团、弥散星云、行星状星云和河外星。

## 代谢疾病

代谢疾病涉及核酸、蛋白质或碳水化合物的平衡。这些通常由特定途径的缺乏或过度引起，导致物质积累或产物缺乏。所有代谢疾病背景上都是遗传性的，某些表现为特定的遗传疾病。

核酸代谢异常与多种疾病有关，包括风湿和红斑狼。遗传性疾病意味着核酸缺陷，尽管并非所有异常中核酸都有固有的缺陷。这可能是缺乏、过度或突变导致了异常蛋白质的形成。同样，脂质沉积性疾病导致异常苯丙氨酸，这是酶缺乏的结果，意味着特定核酸密码的缺陷。

异常蛋白质引起的代谢疾病包括多发性骨髓瘤、血红蛋白异常和各种氨基酸异常。代谢神经病（浆细胞的神经病性生长）是一种代谢疾病，其中产生了异常蛋白质。另一种蛋白质异常涉及辅酶或不同细胞的转运，细胞状态和贫中海（地中海地区）是两种最常见的血红蛋白疾病。第三类异常蛋白质发现于组织中，称为淀粉样变。淀粉样变；遗传；蛋白质；细胞。第四组代谢异常与特定疾病有关，其由于过多机制（血清氨基酸浓度超过肾小球膜转运阈值）或肾转运中氨基酸的吸收缺陷引起。这是常见的代谢疾病类型之一。

## 1362 代谢

对人而言是指与肥相关的脂质增加。参见肥胖（`OBESITY`）。

高脂血是指血液脂质过多，通常由不可控的糖尿病、低脂血症、低胆红素引起。脂肪细胞过度增称为脂肪瘤，偶尔会变为恶性。参见动脉粥硬化（`ARTEROSEROSIS`）。

在大量的遗传性脂质沉积疾病中，脂质因代谢差异而积累。这通常由于酶缺陷引起。固有的酸缺陷会导致酶结果异常，从而导致代谢异常。许多器官中大量脂质积累会损伤组织，如心脏、肝脏、脾和骨髓。异常脂质沉积发生在尼曼-匹克病、格谢氏病和糖症中。

该病最常见的形式是家族性高胆固醇症，其胆固醇水平是正常值的两倍，由冠状动脉粥硬化病变引起35-50岁时心肌梗死死亡。当胆固醇水平达到正常值的十倍时，15岁前死亡。这是由于低密度脂蛋白（`LDL`）受体缺陷引起的。参见胆固醇（`CHOLESTEROL`）；心脏病（`HEART DISEASE`）；脂质疾病（`LIPID DISEASES`）。

**碳化合物。**碳化合物糖尿病涉及影响胰岛素和糖代谢的遗传缺陷。碳化合物代谢的主要活动由肝脏和肌肉中的糖原储存调节，由胰岛素调节。其他碳化合物疾病涉及粘多糖储存，如霍勒病，以及半糖储存，如糖症。糖尿病代谢（`DIABETES METABOLISM`）。

与代谢相关的最重要的疾病是糖尿病。参见碳化合物代谢（`CARBHYDRATE METABOLISM`）。

**代谢**产生和维持生物有机物质的所有物理化学过程，以及为我们提供能量的转化。

详细来说，习惯上区分能量代谢和中间代谢，尽管两者在产生总热方面是协同的。例如，能量代谢是通过细胞和组织中与氧气的化学反应产生的。此时，“代谢”一词被解释为中间代谢。参见中间代谢（`INTERMEDIATE METABOLISM`）。

代谢包括细胞和组织内所有涉及构建、分解和功能的过程。组织结构的合成通常涉及较小分子结合成较大分子。分解组织的过程（如将蛋白质分子分解成较小分子）被称为分解代谢。相比之下，合成被称为合成代谢。

三大类食物——碳水化合物、脂肪和蛋白质的代谢非常重要，因为原质结构和代谢的任何明显缺陷都会导致严重疾病。碳水化合物、脂肪和蛋白质的代谢途径发生在许多点；这些代谢途径被不同组织和不同细胞类型共有。

植物和动物细胞原质的某些代谢过程发生在共同途径；植物中的碳化合物代谢与动物中的许多其他碳化合物代谢相似。因此，对任何生物代谢的研究在某种意义上是对所有原质代谢的研究。参见碳化合物代谢（`CARBOHYRATE METABOLISM`）；关键循环（`KEY CYCLE`）；代谢（`METABOLISM`）；蛋白质代谢（`PROTEIN METABOLISM`）。（`M.B.C.`）

**金属**化学上的任何元素。金属态的原子包含部分填充的轨道，空状态供占据。通常，进入金属态释放电子到静电系统中的键会促进离子和电子的传输与交换。但金属具有高熔点和高沸点；对于金属而言，它们在室温下也是固体，并且具有延展性、密度、韧性、凝聚力和高导电性。当原子簇形成金属尺度时，它们会降至熔点以下。此外，金属原子以各种比例相互结合，形成柔软、均匀、密堆的结构。相比之下，金属化合物由一个或多个离散计量结构组成。

关于代谢的详细讨论，特别是一般行为的例外，请参见每个金属的单独文章。参见元素（`ELEMENTS`）；周期表（`PERIOD TABLE`）。（`F.H.R.`）

**组件的机械性能**材料的测量属性（如拉伸强度、硬度、断裂韧性和弹性）在承受应时与材料相关。这些属性的研究是独立于弹性和塑性的，弹性和塑性是与外部应力相关的应力与应变属性。

应力是分布在物体表面（表面力）或分布在体积内（体力）的单位面积作用力；体力的例子是重力和离心力。除非对物体上消极极小部分受力的力大小、方向和作用点给出完整描述，否则力不会均匀地分布在区域上。一点上的所有力都可以分解为沿物体表面的法力和平行力。垂直于参考物体表面的力定义为应力。当力矢量是稳定状态的一部分时，它们是剪切应力。剪切应力总是成相反符号对出现。
