
如果您进行登录尝试，所有尝试可能记录在 `/var/admin/loginlog`（如果存在）。TTY 行将被删除。

如果启用了密码年龄且密码已过期（更多信息参见 `passwd(1)`），您将被强制更改密码。在这种情况下，将咨询 `/etc/nwitch.conf` 文件以确定密码库（参见 `nsswitch.conf(4)`）。密码更新配置限于以下情况：

+ `- passwd: files`
- `passwd: nis`
- `passwd: nisplus`
- `passwd: compat (==> files nis)`
- `passwd: compat (==> files nisplus)`

不符合这些配置将导致 `passwd(1)` 失败而无法登录系统。如果在规定时间内未成功完成登录，您可能会被静默断开。

登录成功后，统计文件将更新。设备所有者、组和权限将根据 `/etc/logindperm` 文件的内容进行设置，并打印您登录的时间（参见 `logindeperm(4)`）。用户 ID、组 ID、附加组以及文件中指定的解释器将启动。

基本环境初始化为：

```
HOME=your-login-directory
LOGNAME=your-login-name
PATH=/usr/bin:
SHELL=/bin/last-field-of-password-entry
MAIL=/var/mail/your-login-name
TZ=timezone-specification
```

对于 Bourne shell 和内核登录，shell 执行 `/etc/profile` 以及存在的 `$HOME/.profile`。对于 C shell 登录，shell 执行 `/etc/.login,$HOME/.bashrc` 和 `$HOME/.login`。解释器的名称将设置为 `-(dash)`，后跟解释器路径的最后一个组件，例如 `-sh`。

## 709

如果密码文件（见 `passwd(4)`）中的 `login-shell` 字段为空，则使用默认命令解释器 `/usr/bin/sh`。如果该字段为 `*`（星号），则指定的目录将成为根目录。此时，登录将在新层级重新执行，该层级必须有自己的根目录。

你可以通过在执行时或 `login` 请求登录时向 `login` 提供额外的参数来扩展或修改环境（`PATH` 和 `SHELL` 除外）。参数可以是 `xxx` 或 `xxx=yyy` 形式。如果没有等号（`=`），它们将被放入环境中：

```
Ln=xxx
```

其中 `n` 是从 0 开始的数字，每当需要变量名时就会加 1。包含 `=`（等号）的变量将不经修改地放入环境。如果这些变量已经存在于环境中，它们将替换原有值。

或者，你可以通过向 `login` 提供 `-p` 选项来传递当前环境。此选项表示 `login` 将尽可能地将所有定义的环境变量传递给新环境。此选项不会绕过上述的任何环境变量限制。如果通过两种方法传递了变量，则登录行上指定的变量具有优先级。

要启用远程登录，请编辑 `/etc/default/login` 文件，并在 `CONSOLE=/dev/console` 条目前插入井号（`#`）。

## Security

`login` 使用 `pam(3)` 进行身份验证、账户管理、会话管理和密码管理。通过 `/etc/pam.conf` 列出的 PAM 配置文件指定登录时使用的模块。下面是一个 `pam.conf` 文件，包含 `login` 命令的条目，使用了 UNIX 认证、账户管理、会话管理和密码模块。

```
login auth required /usr/lib/security/pam_unix.so
login account required /usr/lib/security/pam_unix.so
login session required /usr/lib/security/pam_unix.so
login password required /usr/lib/security/pam_unix.so
```

如果 `login` 服务没有条目，则使用其他服务的条目。如果列出了多个认证模块，用户可能会被提示多个密码。

## Warnings

UID 大于 `76695844` 的用户不受密码老化限制，系统不记录他们的最后登录时间。

如果你使用 `CONSOLE` 设置禁用 root 登录，你应该也安排 root 的远程命令执行被禁用。更多细节请见 `rsh(1)`、`rcmd(3N)` 和 `hosts.equiv(4)`。

## Options

- `-d` 指定 `login` 操作的 TTY 端口路径名。设备选项可以提高登录性能，因为 `login` 不需要调用 `tname(3)`。`-d` 选项仅对 UID 和有效 UID 均为 root 的用户可用。任何其他使用 `-d` 的尝试都会退出。
- `-h hostname [terminal]` 从 `in.telnetd(1)` 传递关于远程主机和终端类型的信息。
- `-p` 将环境变量传递给 `login` 壳。
- `-r hostname` 从 `in.rlogind(1)` 传递关于远程主机的信息。
