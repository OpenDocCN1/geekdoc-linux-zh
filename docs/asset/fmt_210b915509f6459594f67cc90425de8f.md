## Linux 命令指南

本附录是大多数系统中可用的 Linux 实用工具的快速参考。表 A-1 按字母顺序列出了命令，包括命令名称、用途以及任何用的选项。表 A-2 总结了 vi 编辑器命令。表 A-3 列出了与 shell 编程相关的命令。表 A-4 列出了 shell 使用的特殊字符。
