
## 20.7.5. `yum install`

### 20.7.5.1. 基本安装

安装一个应用程序，使用 `yum install $package`。`yum` 自然会安装所有必要的依赖项。

### 20.7.5.2. 安装多个包

你可以在这里添加多个参数。

```
yum install $package1 $package2 $package3
```

## 20.7.6. `yum update`

### 20.7.6.1. 更新所有包

要通过下载和安装将所有应用程序更新到最新状态，执行 `yum update`。所有通过 `yum` 安装的软件都将更新到仓库中提供的最新版本。

`yum update`

### 20.7.6.2. 更新单个包

如果你只想更新一个包，使用 `yum update $package`。
