## 8.6 通过 Socket 发送数据

描述 TCP 等复杂协议实现的最佳方法是跟踪数据在协议中的流向。本章剩余部分将检查 TCP 的发送端处理。请记住 TCP 可能是 TCP/IP 协议族中最复杂的部分。由于 TCP 在传输层提供面向连接的服务，它比 UDP 复杂得多。TCP 必须管理本地主机与远程主机之间的关系，包括重传错误和丢失的数据包、管理连接状态、缓冲数据以及建立和关闭连接。此外，正如你所看到的，它做的远比这些多。Linux TCP 实现了自 RFC 793 规定以来 20 多年来在安全、可靠性能方面的所有增强。本节主要关注与 socket 的连接，以及数据如何从应用程序移除并放入传输队列中。接下来，8.7 节讨论了实际的数据包传输。8.8 节涵盖了用于控制变量和配置选项的数据结构，8.9 节涵盖了主要用于发送端的 TCP 定时器。
