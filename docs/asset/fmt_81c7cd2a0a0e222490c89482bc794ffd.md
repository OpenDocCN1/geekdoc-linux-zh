
## 更改文本

你可以使用替换（`s`）命令对当前行内的某些文本进行更改：`s/old/new/`，其中 `old` 是你想要替换的字符串，`new` 是你用来替换 `old` 的字符串。

## 描述

如果你从空文件开始或想要添加一些新行，使用追加（`a`）命令。在你执行此命令后（按下回车键），`ed` 从你的终端读取行，直到你输入一个只包含点号（`.`）的行。该行变为当前行。插入（`i`）命令类似于追加，但它将你输入的行放在当前行之前。

## 保存并退出编辑器

在修改文件后，可以通过执行 `w`（写入）命令保存文件内容。可以通过发布 `q`（退出）命令离开编辑器。如果你在文件上运行 `ed` 但没有修改文件，则不需要退出（但写入缓冲区也没有大碍）。如果你在修改缓冲区后未将其写出的情况下尝试退出，将收到消息 `No write without last change (:quit! overrides)`，并且 `ed` 将等待另一个命令。如果你不想写入缓冲区，请执行退出命令并加一个感叹号（`q!`）。缓冲区将被不可恢复地销毁，并返回 shell。

# 编辑 297

缓冲区包含多行内容。请注意，你无法撤销写入（`write`）和退出（`quit`）等命令。

# 显示缓冲区中的行

`edit` 提供了许多不同的命令，允许你显示缓冲区中的内容。

- 输入 `=` 查找当前行号。
- 使用打印（`print`）命令显示一组行号：`1,23p` 打印文件的前 23 行，`1,$p` 打印整个文件，`,$p` 打印当前行加上文件的其余行。
- 使用数字（`nu`）命令显示带行号的缓冲区内容。你可以找到当前行号（`nu`）、一个行范围（例如 `5,10nu` 显示第 5 到 10 行的编号行），或文件中的所有行（`1,$nu`）。
- 按回车键（Return）查看缓冲区中的下一行。
- 要查看数字行，输入 `Ctrl-D`（按住 Control 键的同时按 d 键）而不是回车键。此按键序列在 CRT 显示器上显示半屏幕的行，或在硬拷贝打印终端上显示 12 行。可以通过执行 `z` 命令查看附近的行。当前行将显示在显示文本的中间，最后显示的一行将变为当前行；你可以输入 `''` 回到执行 `z` 命令之前的行。`z` 命令还有其他选项：`z-` 打印以你所在位置为结束的一组文本（或 24 行）；`z+` 打印当前行。如果行数少于一屏，输入 `z.11` 来显示当前行前后各 5 行。（输入 `z.n` 时，当 n 为奇数，它将总共显示 n 行并以当前行为中心显示；当 n 为偶数时，它显示 n-1 行，使得显示的行以当前行为中心分布。）你可以在其他命令后加上计数；例如，使用命令 `d5` 可以删除从当前行开始的 5 行。

你还可以对行引用进行算术运算。因此，行引用 `-5` 是最后一行之前的倒数第 5 行，而 `+20` 是当前行之后的 20 行。

> 注意 - `edit` 还有一个 `vi` 模式，允许你在编辑文件时查看其内容。有关关于使用 `vi` 模式的更多信息，请参见 `ex(1)`。

# 查找文本

要在文件中查找内容，你可以使用行号。你也可以通过提供形式为 `/text/` 搜索文本或 `?text` 向后搜索文本的命令，在文件中前后搜索字符串。如果搜索到达文件末尾仍未找到文本，它将循环并继续向后搜索你所在的行。这里一个有用的功能是形式为 `/^text/` 的搜索，它搜索行头的文本。同样，`/text$` 搜索行尾的文本。可以在这些命令中省略末尾的 `/` 或 `?`。

# 复制或移动文本

你可以使用复制（`c`）或移动（`m`）命令在同一个文件中复制或移动文本。你指定要移动的行或行范围，然后是命令以及你希望将文本放置之后的行号。例如，命令 `5,10c` 会在一个行范围内创建一个副本，即复制第 5 到 10 行并将其插入到缓冲区中第 20 行之后。符号点（`.`）语法表示当前行，它在移动文件中的某行时最有用，你可以通过符号名称 `$` 来引用它。因此，命令 `$d` 无论当前行是什么都会删除文件的最后一行，而命令 `10,20m` 将第 10 到 20 行移动到文件末尾。

# 使用内部缓冲区

`edit` 命令有 26 个内部缓冲区，命名为 `a` 到 `z`，你可以将它们作为临时剪贴板，将文本从一个文件复制或移动到另一个文件。在开始复制或移动之前，输入你想复制或移动的第一和最后一行号。例如，要移动第 10 到 20 行，输入 `10,20d a` 并按回车。这些行将从文件中删除并进入名为 `a` 的缓冲区。要将缓冲区的内容置于当前行之后，输入 `put a` 并按回车。如果你想将这些行移动或复制到另一个文件，先使用剪取（`y`）命令复制这些行，然后 `e filename` 是你要编辑的另一个文件的名称，例如 `e chapter2`。

> 注意 — 退出 `edit` 时，`a` 到 `z` 缓冲区的内容不会被保留。当你使用 `e` 或 `q` 命令时，如果这些缓冲区包含文本，`edit` 不会警告你。

`/usr/xpg/bin/edit` 命令与 `/usr/bin/edit` 相同。

## 选项

你可以使用 `set` 命令(1) 开启或关闭以下选项。

- `-s` 抑制所有的交互式用户反馈。此选项在处理编辑器脚本时有用。
- `-C` 模拟 `ex` 的 `C` 命令，假设所有读取的文本都已加密。
- `+command |c` 通过执行指定的编辑器命令开始编辑（通常是搜索或定位命令）。
- `-1` 设置编辑 LISP 程序。
- `-L` 列出所有作为编辑器或系统崩溃结果保存的文件名。
- `-R` 设置只读标记，以防止意外覆盖文件。
- `-r` 恢复系统崩溃时缓冲区中的文件名版本。
- `-t` 编辑包含标签的文件并定位编辑器。
- `-v` 使用 `vi` 以显示状态启动。你可以达到相同的效果。
- `-V` 详细模式。在处理多个文件时，使用 `vi` 选项可以实现相同的效果。
- `x` 模拟 `ex` 命令，这检查输入已加密。
- `-s` 静默工作，即除了错误消息外不显示任何内容。此选项对于检查错误状态有用。文本是否已加密。
- `-wn` 设置默认窗口大小。

## 示例

假设你想在你一个文件中查找包含 Michigan、Ohio 或 Indiana 单词的行。单个 `grep` 命令无法执行对多个模式的搜索。你可以使用 `grep` 在文件或具有相似扩展名的文件组中搜索多个模式。
`grep` 提供以下功能：

- 具有在“或”条件下同时搜索多个模式的能力。
- 可以使用包含模式的文件作为搜索基础。
- 一组扩展的正则表达式元字符集。

`egrep` 比 `grep` 慢，但它可以执行更复杂的搜索。

> 注意 — 使用 `egrep` 命令时，`\(`（后跟左括号）或 `\)`（后跟右括号）将作为字面文本匹配模式。左括号和右括号是用于分组模式部分的特殊字符。在 `grep` 命令中情况则反之。

以下示例搜索当前目录下所有 `.doc` 扩展的文件，查找包含 Michigan 或 Ohio 的行。

```
castle egrep "Michigan|Ohio" *.doc
```

以下示例强制 `egrep` 查找以 Michigan 或 Ohio 开头的行。`-i` 选项同时查找大写和小写。

```
castle egrep -i "^Michigan|Ohio" *.doc
```

你可以在文件中搜索模式，并将文件名作为 `egrep` 命令的参数。在开发不想在命令行中输入的复杂模式时，使用文件是非常方便的。

在以下示例中，一个名为 `pattern.file` 的文件包含行 `(Michigan|Ohio)`。

模式不需要引号，但需要括号。以下示例使用 `-f pattern.file` 作为 `egrep` 的参数。

```
castle egrep -f pattern.file *.doc
```

以下示例搜索所有具有 `.doc` 扩展的文件，查找包含一个或多个数字的字符串或字符串 `ABC` 的行。

```
castle egrep "([0-9]+)|ABC" *.doc

file1.doc: ABCDEFGHI

file5.doc: The following are numbers 1234567

file7.doc: 1 2 3 4 5 6

castle*
```
