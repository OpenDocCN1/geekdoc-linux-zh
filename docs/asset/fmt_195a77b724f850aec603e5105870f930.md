# 山地气象

山脉对大气的影响涵盖所有运动尺度，包括极小（如湍流）、局部（例如峰顶或山脊上的云形成）和全球（亚洲和北美尺度）。

山脉最显著的影响（即使是小山）也与空气的抬升有关。当风吹来时，它越过山峰或山脊导致云的形成。山坡通常是干燥的，因为空气在迎风侧流失。山脉最常见的影响是雨影效应。当潮湿空气被迫越过山时，它会冷却并凝结，在迎风侧形成云和降水。背风侧的空气是干燥的，形成了雨影。

山脉还可以影响局部风场。空气被迫通过山山口，这会产生强风。白天，空气沿山坡向上流动，晚上沿山坡向下流动。这些被称为山风和谷风。

山脉还可以影响周围空气的温度。高海拔比低海拔凉，因为高海拔空气稀薄。这就是为什么即使在夏天，山峰通常也有雪。

山脉还可以影响植物动物的分布。山上不同环境可以为许多物种提供栖息地。某些物种仅出现在山脉上。山脉还可以作为物种迁移的屏障。

## 消音器

用于衰减声音同时允许流体（通常为气体）通过的设备；英国英语中称为 silencer。反应式消音器用于减少排气噪声，而消能式消音器吸收声音能量。发动机噪声控制系统正在出现，大多数消音器最适用于使用被动消音技术。被动消音器分为反应式或消能式。反应式消音器将声音反射回声源，而消能式消音器使用材料吸收声音。反应式消音器设计用于无论消音器大小如何都在主频处提供衰减。此外，反应式消音器可用于消能或主动消音器可能无效的高频环境。在低中频下，声波长大于消音器的任何横截尺寸，在这些频率下，消音器可能表现反射或宽带衰减。另请参阅：声学消音器。
