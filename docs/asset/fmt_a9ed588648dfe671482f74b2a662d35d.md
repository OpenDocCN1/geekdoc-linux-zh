
## 取消订阅新闻组 (UNSUBSCRIBE FROM A NEWSGROUP)

1. 右点击你想取消订阅的新闻组。
2. 点击 Unsubscribe。
3. 将出现一个确认对话框。点击 OK 取消对新闻组的订阅。
4. 该新闻组将从列表中消失。

# 发送消息

加入新闻组

你可以向新闻组发送消息以提问或表达你的观点。

![](img/e2eac216eed4c6806c742998f1420a0c_304_0.png)

在发送消息之前，你应该至少阅读一周该新闻组中的消息。这可以帮助你避免发送他人已经读过的消息，并学习新闻组内的人是如何交流的。
