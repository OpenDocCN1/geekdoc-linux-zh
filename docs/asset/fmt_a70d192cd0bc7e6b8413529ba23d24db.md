## 简单自动化与实用脚本

逐行输入命令来获取系统信息、查找文件或重命名批量文件？脚本是更好的答案。

### 步骤 1
让我们尝试创建一个脚本来显示 Mint 系统信息；这是必备的。创建一个名为 `sysinfo.sh` 的新脚本并进入 `Nano` 或文本编辑器。

```bash
#!/bin/bash

# 信息：
echo "Hostname: $(hostname)"

## 文件系统使用情况
echo "Disk usage: $(df -h)"

## 空闲和已内存
echo "Memory: $(free -m)"

## 运行时间和性能
echo "Uptime: $(uptime)"

## 当前登录用户
echo "Users: $(who)"

## 系统使用的前五个进程
top -n1 | head -n 6
```

### 步骤 2
我们在这个脚本中包含了一些额外内容。第一个是 `echo` 的 `-e` 扩展，这将启用解释新行的额外细节以及特殊字符。前面的 `\033;37m` 元素用于前景和背景颜色。

```bash
david@david-mint:~/scripts$ ./sysinfo.sh
hostname: david-mint
Kernel: 5.4.0-101-generic
Machine: Sub3c275b37d4d3b3ee99ffcc37be718
Build: 61ceaa89f9469c-5fac890abe718el
Virtualization: none
Operating System: Linux Mint 20.1
Architecture: x86_64
pu: x86_64
```

### 步骤 3
每个部分都运行不同的终端命令，在适当的标题下输出结果。你可以包含更多内容，例如系统当前使用的别名、当前时间和日期等。此外，你还可以将所有信息重定向到一个方便的 HTML 文件，准备在浏览器中查看。

```bash
david@david-mint:~/scripts
david@david-mint:~/scripts > ./sysinfo.html
```
