
# R--行尾替换 (Big Replace)
`R` 命令的大写版本与 `r` 命令的区别，类似于 `d` 命令的大写版本以及 `c` 命令与其小写版本的区别。`R` 命令允许替换从光标位置到行尾的文本。在输入 `R` 后到按下 Escape 键之前输入的任何文本将覆盖屏幕上现有的文本，直到行尾。此后，输入的文本将追加到行尾。

当配合数字计数使用时，相同的替换将发生 *count* 次。这种 `R` 命令用法可能不会产生你预期的结果。

# o--在下方开行 (Open Line)
`o` 命令在光标所在行下方打开一个新行并进入插入模式。

# O--在上方开行 (Big Open Line)
`O` 命令在光标所在行上方打开一个新行并进入插入模式。

# 复制即“剪取” (Yank)
许多文本编辑器都有被称为“剪切和粘贴”或“复制粘贴”的功能。`vi` 将“复制和粘贴”中的复制部分称为 "yank"。你可以使用 yank 命令将任何文本块保存到撤销缓冲区（undo buffer）中。撤销缓冲区是 `vi` 内部保留的一个特殊地方。你无法直接看到该缓冲区的内容。可以使用 `p` 命令将缓冲区的内容放入文本中（见下文）。

每次使用 `y` 命令都会覆盖撤销缓冲区的内容，任何删除命令也是如此。在“如何使用缓冲区”章节中解释了更高级的 yank 命令，它可以将文本保存到多个命名的缓冲区中。

## y--剪取 (Yank)
yank 命令与对象的作用方式与 `c` 和 `d` 命令相同。你可以使用 `yw` 剪取一个单词，使用 `y$` 剪取到行尾，使用 `3yy` 剪取三行。

## Y--大剪取 (Big Yank)
然而，这种模式有一个例外。由于某种原因，`Y` 命令并不像 `C` 和 `D` 那样将作用到行尾。相反，它剪取整行，因此与 `yy` 相同。

## p--粘贴 (Put)
`p` 命令将撤销缓冲区中的内容插入到光标位置之后。

## P--行前粘贴 (Big Put)
`P` 命令将撤销缓冲区中的内容插入到光标位置之前。

# 搜索模式 `/`, `//`, `?`, `??`, `n`, 和 `N` -- 搜索
在文本中移动的实用方法之一是搜索模式。你可能正在编辑一个长源代码文件，想要回到你记得包含特定指令的例。你可以通过使用 `/`（正向搜索命令）或 `?`（后向搜索命令）来实现。在命令模式下，一旦输入斜杠或问号，光标就会移动到命令行。然后你输入想要查找的模式。该模式可以是一个字面文本字符串（即你想要查找的精确字符序列），也可以是一个正则表达式（在“正则表达式”章节有详细描述）。

在按下回车键后，文本将重新定位，使得包含模式第一次出现的位置行大致显示在屏幕中心（假设周围有足够的文本允许此操作），并且光标将位于匹配文本的第一个字符处。如果没有找到模式，命令行将显示消息“Pattern not found: *pattern*”。

你使用 `/` 命令在文本中正向搜索（即从光标所在位置到缓冲区末尾）。你使用 `?` 命令在文本中后向搜索（即从光标所在位置到缓冲区顶部）。你可以通过使用两个再次搜索命令（不带任何搜索文本的 `/` 和 `?`，`//` 和 `??` 同样有效）重复正向或后向搜索，而无需重新输入模式。在这些再次搜索命令后也必须输入回车。一旦输入模式，你可以混合使用正、后向搜索命令。

重复搜索命令的另一种变体是使用 `n` 命令，它以相同的方向（向前或向前）重复上一次搜索。`N` 命令以相反的方向重复上一次搜索。

`vi` 会在缓冲区的顶部和底部“循环搜索”。搜索模式时，如果 `vi` 碰到了缓冲区的一端，命令行将显示消息通知你这一事实。例如，可能会出现“search hit BOTTOM, continuing at TOP”。此时，你可以按回车继续搜索。（此行为可以更改；请参阅“高级用户：自定义 vi”章节以查看如何使用特殊设置来更改 `vi` 的默认行为。）

# 如何使用缓冲区

缓冲区仅包含最近一次复制（yank）或删除的文本。这意味着如果你打算复制某些文本并粘贴到某处，但在粘贴之前执行了任何删除操作，你会对结果感到失望。为了保持各种文本片段可供粘贴，你必须使用命名缓冲区。

## 命名缓冲区
命名缓冲区允许你保留多达 26 个独立的位置，可以在这些位置删除或复制文本。使用命名缓冲区可以解决中间删除替换你已复制或删除文本的问题。命名缓冲区的内容在你的 `vi` 会话结束之前保持不变，除非你使用命令刻意更改它。

缓冲区通过 `"` 后跟一个小写字母来命名。因此，缓冲区命名为 `"a` 到 `"z`。要向命名缓冲区复制或删除，请在复制或删除命令前加上名称。例如，要从光标位置复制两行到缓冲区 `z`，你将使用以下按键：`"z2yy`。从命名缓冲区粘贴的按键序列是缓冲区名称后跟 `p` 命令。表 3.5 显示了使用命名缓冲区的一些示例：
