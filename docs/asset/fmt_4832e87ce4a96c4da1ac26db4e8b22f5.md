
# 评测总结

`KaOS` 团队使用多个错误追踪器，并拥有一个安静的论坛。其网站提供了一份关于如何理智地提问和报告问题的实用指南，如果每个人都阅读这类指南，世界确实会变得更好。

**结论**

- `ANTEROS` 8/10
- `MANJARO` 9/10
- `ARCHLABS` 7/10
- `NETRUNNER ROLLING` 6/10
- `KAOS` 6/10

`Manjaro` 庞大的用户群意味着强大的社区，其中许多人在你提出真实问题时，不会默认让你“先读文档”（`RTFM`）。

## 值得注意的新增功能

有时候，正是这些小细节决定了成败...

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_21_0.png)

在 `Arch` 中设置打印机有点麻烦，但 `Antergos` 和 `Manjaro` 都包含 `Redhat` 的 `system-config-printer` 实用工具。除 `ArchLabs` 外的所有发行版都包含 `HP Device Manager`，如果你有这类设备需要管理，这将非常有用。

`Netrunner` 包含 `Grub customizer`，这是一个贴心的设计，和 `Manjaro` 一样，它也支持开箱即用的休眠功能。`KDE Discover` 是一种发现新应用程序和 `Plasma` 插件的好方法。它比过去稳固得多，我们发现它比 `Gnome Software` 讨厌得多。`Netrunner` 的 `Firefox` 安装版自带 `uBlock Origin` 和几个流行的拦截列表，这使得网络环境稍微不那么令人厌烦。

`KaOS` 包含一个 `Wayland` 会话，这对于一个 `KDE` 发行版来说是个很棒/勇敢的设计。由于偷懒，在 `Antergos` 上我们会尝试启动 `Wayland` 会话。脾气暴躁时，在 `ArchLabs` 上，看到 `Manjaro` 和 `Netrunner` 缺少 `bash-completion` 包让我们感到遗憾，但我们欣然接受了 `KaOS` 的 `bash` 配置及其中的标签页完成功能。`Manjaro` 和 `KaOS` 都为 `UFW` 防火墙提供了简单的前端。我们认为，中级及以上级别的用户开始关注哪些数据包进出系统是合时宜的，因此我们称赞这两家发行版。`Antergos` 和 `ArchLabs` 都保留了 `Arch` 的可定制性，主要是通过提供对 `Arch` 仓库中众多软件包的直接访问。我们认为应该给轻量级桌面更多机会，并且喜欢 `ArchLabs` 附带的 `Openbox/Panelbar/Compton` 配置。从头设置这比重新创建 `KDE/Gnome/Xfce` 配置要难得多。

> `Netrunner` 包含复古游戏 `Burgerspace`。遗憾的是，我们没时间好好玩玩。说实话。

| 发行版 | 结论 |
|---|---|
| `ANTERGO` | 7/10 |
| `ARCHLABS` | 8/10 |
| `KAOS` | 9/10 |
| `MANJARO` | 8/10 |
| `NETRUNNER ROLLING` | 8/10 |

我们提供的每个发行版中都有隐藏的珍宝，但 `KaOS` 的开发者确实认真考虑了用户会欣赏什么。

## 包含的工具

开箱即用的体验如何？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_21_1.png)

`Antergos` 安装了一组轻量的 `Gnome` 应用程序套件，但足以让你开始上手。拥有 `Gnome` 新的 `Documents` 工具是个不错的选择，同样 `Weather、Maps 和 Books` 也是如此。没有 `LibreOffice`，所以处理文书工作的人需要自行安装，但安装了 `Chromium`，这会让 50% 的人满意。对 `Gnome Software` 持批评态度的人可能会感激它的缺席。

`Manjaro`（延伸来说包括 `Netrunner Rolling`）包含一个硬件检测工具（`mhwd`），在安装时运行，也可以在安装后通过设置管理器或终端调用。还有一个方便的工具用于添加/移除内核，如果你遇到硬件兼容性问题，这会非常有用。在 `Netrunner Rolling` 中，如果你需要使用更新（甚至是实时）的内核滚动更新，这也极为有用。在这两个发行版中，`Flash` 播放器的实用性较低。

游戏玩家会欣赏 `Manjaro` 菜单中提供的 `Steam` 安装器快捷方式。有些人会欣赏指向 `MS Office Online` 网络工具的链接，但其他人可能认为这只是不必要的菜单杂乱。`Netrunner` 预装了许多多媒体应用程序。还有一些有趣的，我们赞赏 `GIMP-Inkscape-Krita` 图形三件套。`Skype`、`Steam` 和 `Virtualbox` 也可用。

`KaOS` 拥有 `Elisa` 音乐播放器、`Karbon` 矢量图形工具和 `Seafile` 同步实用工具。它与其他发行版区分开来的特点是使用 `Calligra` 办公套件。这在 `Plasma` 环境中看起来时尚，而且在许多方面比 `LibreOffice` 更不笨拙，但有些人可能难以习惯。由 `QtWebEngine` 驱动的 `Falkon`（前身为 `QupZilla`）是一个很好的网络浏览器，如果你不需要花哨的功能的话，但有些人可能迫切想要安装更主流的软件。

> 我们不确定是否认识使用 `Handlrake`、`Vokplayer` 和 `gmusic-brainer` 的人。如果你有，`Netrunner` 涵盖了这些需求。

`ArchLabs` 以其极简主义为荣，但你可以通过其欢迎菜单安装任何需要的软件。音乐和电影由 `mpv` 和 `Audacious` 搞定。向开发人员致意，它包含 `Geany` 代码编辑器，以及 `Arch` 的 `base-devel` 软件包组。我们赞同包含 `Nmap`，`Firefox` 则会讨好另一类 50% 的用户。

如果你认为少即是多，请无视 `ArchLabs` 的分数。不过 `Manjaro` 确实很好地做到了去粗取精。

## 基于 Arch 的发行版

**评测结论**

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_22_0.png)

对于部分用户而言，拥有一个纯粹的 `GTK` 或 `Qt` 系统将是福音，尽管这会极大限制其可用的应用程序数量。`Antergos`，尤其是 `KaOS`，对这类人群可能颇具吸引力。其他用户则会很高兴跨工具包的主题定制如今比以往好得多，不介意安装两个工具包。毕竟，存储空间很便宜。

在许多方面，我们觉得 `KaOS` 应该提供更新版本的 `KDE` 软件包，毕竟它在 `Arch` 仓库发布后很快就会跟进。当然，`KDE neon` 被认为是在 `Plasma` 星球上展示最新最强特性的首选发行版，因此与其竞争可能并无意义。`Blue Systems` 赞助的 `Netrunner Rolling` 是出色的努力，但我们觉得它试图面面俱到。

尽管各发行版付出了巨大的努力，但不熟悉 `Arch` 及其工作方式的用户迟早会感到困惑。`Manjaro` 可能是本月推荐中最友好的，但它并非 `Ubuntu` 或 `Mint`，把它当那样对待会带来失望。（生活充满了失望，但那是另一个《综述》的话题了。）你迟早得亲自上手处理一些问题。相反，如果你熟悉 `Arch`，那么你可能更倾向于留在那里（你是说骑在白马高头之上吗？——编辑注），或者从这些发行版中获得灵感并应用到你的 `Arch` 安装中。我们确实对 `ArchLabs` 桌面的禅意以及小于 200MB 的内存占用所能实现的功能印象深刻。

`Manjaro` 在其主打的 `Xfce` 版本上做得非常好。它表明这个桌面不仅美观，而且在资源利用上也很贴心。过去一年里它变得极受欢迎，并非因为人们对 `Ubuntu` 的抱怨，而是因为它是一个相当不错的发行版，能提供用户确切想要的东西。当 `Xfce 4.14` 发布且记者们不再为此开调侃玩笑时，它肯定会变得更加卓越。

`GNOME` 和 `KDE` 版本也很好。如果你喜欢最新的桌面花哨功能，它们很棒，但我们欣赏 `Manjaro` 专注于 `Xfce` 的大胆。
