### 注意事项

- 本模块中的函数不是线程安全的。如果你在不同的线程中生成随机数，应该使用锁来防止并发访问。
- 随机数生成器的周期（在数字开始重复之前的周期）为 `2**19937–1`。
- 本模块生成的随机数是确定性的，不应用于加密。
- 可以通过子类 `random.Random` 并实现 `random()`、`seed()`、`getstate()` 和 `jumpahead()` 方法来创建新类型的随机数生成器。本模块中的所有其他函数实际上上都是作为 `Random` 的方法实现的。因此，可以通过随机数生成器实例的方法来访问它们。
- 模块提供了两种替代随机数生成器——`WichmannHill` 和 `SystemRandom`——通过实例化相应的类并以前述函数作为方法调用来使用。`WichmannHill` 类实现了早期 Python 版本中使用的 SystemRandom 生成器。`SystemRandom` 类使用系统随机生成器 `os.random()` 生成随机数。

# 数据结构、算法与代码简化

本章中的模块用于解决与数据结构、算法以及涉及迭代、函数式编程、上下文管理器和类的代码简化相关的常见编程问题。这些模块应该被视为 Python 内置类型和函数的扩展。在许多情况下，底层实现是非常高效的，并且比内置函数更适合某些类型的问题。

# abc

`abc` 模块定义了一个元类（metaclass）和一对用于定义新抽象基类的装饰器。

# ABCMeta

元类代表一个抽象基类。要定义一个抽象类，你需要定义一个使用 `ABCMeta` 作为元类的类。例如：

```python
import abc
class Stackable:
# 在 Python 3 中，使用以下语法
    __metaclass__ = abc.ABMeta # class Stackable (metaclass=abc.ABMeta)
```

以这种方式创建的类与普通类在几个关键方面有所不同：

- 第一，如果抽象类定义了使用后文描述的 `abstractmethod` 和 `abstractproperty` 装饰的方法或属性，那么派生类无法实例化，除非它们提供了这些方法和属性的非抽象实现。
- 第二，抽象类有一个类注册器 `sub`，可以将额外的类型注册为逻辑子类。对于任何注册在此的类型，如果 x 是子类的实例，操作 `isinstance(x, AbstractClass)` 将返回 `True`。
- 抽象类的最后一个特性是它们可以可选地定义特殊方法 `__subclass__(cls, subclass)`。如果 subclass 被认为是子类，该方法应返回 `True`；如果不是子类则返回 `False`；如果未知则抛出 `NotImplemented` 异常。
