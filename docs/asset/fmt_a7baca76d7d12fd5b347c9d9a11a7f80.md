
# 干涉原理

如果我们使用单一光源并将光分成若干部分然后重新组合，光、声或机械波就可以发生干涉。在这种情况下，振幅和相位会随之变化。

产生狭缝图的最简单的技术是由杨在1801年完成的，它首次证明了光的波性。通过让光通过两个狭缝，导致光照射在两个相邻的狭缝上。

两个狭缝产生的干涉在屏幕上显示为一系列平行的条纹。这些条纹的位置大致描述如下：在图中，`$S_1$` 和 `$S_2$` 之间的距离为 `d`

![](img/b16805e6127c92641547ee45e5728f7f_1180_0.png)

杨双缝干涉。

`d`。距离 `d` 是到屏幕的距离。由于狭缝 `S_1` 与 `S_2` 和 `A_2` 等距，因此每个狭缝处的光相位是相同的。从 `S_1` 落在 `P` 点的光可以用等式 (1) 表示，从 `S_2` 的光可以用等式 (2) 表示，

`$A_1 = A_0 \sin 2\pi \frac{(d-x_1)}{\lambda}$ (1)`

`$A_2 = A_0 \sin 2\pi \frac{(d-x_2)}{\lambda}$ (2)`

`f` 是频率，`λ` 是光的波长；`x_1` 和 `x_2` 是 `P` 距离 `S_1` 和 `S_2` 的距离，`A_1` 和 `A_2` 是振幅。当狭缝靠得很近时，假设振幅为每个波的之和，且 `x_1` 和 `x_2` 几乎相同。`P` 点的振幅平方或强度可以写为等式 (3)：

`$I = 4A_0^2 \cos^2 \frac{2\pi}{c}(x_1-x_2)$ (3)`

通常情况下，`I` 远大于 `y`，因此等式 (3) 可以简化为等式 (4)：

`$I = 4A_0^2 \cos^2 \frac{\pi dx}{\lambda d}$ (4)`

当等式 (5) 成立时，等式 (4) 为极大值，等式 (6) 为极最小值，其中 `n` 是整数。

`$n = \frac{d}{\lambda}$ (5)`

`$y = (n + 1/2)\frac{\lambda}{d}$ (6)`

总体而言，屏幕上覆盖着一系列称为干涉条纹的明暗带。如果光源是具有不同波长的白光，那么条纹只在 `x_1-x_2` 较小的地方可见；否则红光将在距离较远的地方可见，条纹将混合成白光。

## 中频放大器

遗憾的是，中频放大器引入了比本地振荡器更低更高的噪声，因为它会产生更多噪声。两者中的一个是作为图像提取所需的信号。
