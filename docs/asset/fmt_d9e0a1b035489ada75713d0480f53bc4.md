
# 图形函数

`XDrawLine` 使用指定的 GC 组件在指定的点集 `(x1, y1)` 和 `(x2, y2)` 之间绘制一条线。

`CoordModeOrigin` 将所有坐标视为相对于原点，`CoordModePrevious` 将第一个点之后的所有坐标视为相对于上一个点。`XDrawPoints` 按照数组列出的顺序绘制点。

这两个函数都使用了这些 GC 组件：`function`、`plane-mask`、`foreground`、`subwindow-mode`、`clip-x`、`clip-y` 和 `clip-mask`。

`XDrawPoint` 可以产生 `BadDrawable`、`BadGC` 和 `BadMatch` 错误。

`XDrawPoints` 可以产生 `BadDrawable`、`BadGC`、`BadMatch` 和 `BadValue` 错误。

## 绘制单线和线

要在绘制对象的两个点之间绘制单条线，使用 `XDrawLine`。

```c
XDrawLine(display, d, gc, x1, y1, x2, y2);
```

- `display` 指定到 X 服务器的连接。
- `d` 指定绘制对象。
- `gc` 指定 GC。
- `x1`
- `y1`
- `x2`
- `y2` 指定要连接的点 `(x1, y1)` 和 `(x2, y2)`。

要在指定的绘制对象中绘制多条线，使用 `XDrawLines`。

```c
XDrawLines(display, d, gc, points, npoints, mode);
```

- `display` 指定到 X 服务器的连接。
- `d` 指定绘制对象。
- `gc` 指定 GC。
- `points` 指定一个点数组。
- `npoints` 指定数组中点的数量。
- `mode` 指定坐标模式。你可以传递 `CoordModeOrigin` 或 `CoordModePrevious`。

要在指定的绘制对象中绘制多条不连接的线，使用 `XDrawSegments`。

```c
XDrawSegments(display, d, gc, segments, nsegments);
```

- `display` 指定到 X 服务器的连接。
- `d` 指定绘制对象。
- `gc` 指定 GC。
- `segments` 指定一个段数组。
- `nsegments` 指定数组中段的数量。

`display`: 指定到 X 服务器的连接。

`d`: 指定绘制对象。

`gc`: 指定 GC。

`segments`: 指定一个段数组。

`nsegments`: 指定数组中段的数量。

## 绘制弧

`y` 指定 `x` 和 `y` 坐标，这些坐标相对于绘制对象的原点，并指定边界矩形的左上角。

`width`

`height` 指定宽度和高度，它们是圆弧的主轴和短轴。

`angle1`

指定相对于中心三点钟位置的弧起始点；单位为 `度 * 64`。

`angle2`

指定相对于弧起始点的弧的路径和范围，单位为 `度 * 64`。

要在指定的绘制对象中绘制多个弧，请使用 `XDrawArcs`。

```
XDrawArcs(display, d, gc, arcs, narcs);
```
