# dbbalancer

数据库连接池、负载均衡和写复制 `DBBalancer` 提供了透明实现功能：连接池化——跨多个后端负载均衡——向多个数据库进行写复制。`DBBalancer` 是一个位于数据库客户端（如 `C`、`C++`, `Java`, `JDBC`, `DBI` 等程序）和数据库服务器之间的守护进程。目前支持的服务器只有 `PostgreSQL`，但架构未来开放更多服务器。更多信息请见 http://dbbalancer.sourceforge.net/。源自 Debian 3.0r0

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# dbench

`bench`（磁盘）和 `tbench`（TCP）基准测试模拟了网络“行业标准”基准测试的负载，该测试用于衡量 Windows 文件服务器。与它们不同，不需要微软 Windows 库；`dbench` 在网络基准中产生文件系统，`tbench` 产生网络负载，从而隔离瓶颈。注意，此基准测试*并非*服务器正常负载的真实反映。
