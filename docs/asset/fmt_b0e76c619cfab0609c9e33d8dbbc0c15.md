# OpenOffice.org 文字处理器

## 更多文本编辑功能

### 查找和替换

这是文字处理器中一个非常实用的功能。它用于在整个文档中搜索特定的单词，然后用正确的单词替换它。它通常用于纠正文档中反复出现的错误。

点击 `编辑 → 查找和替换`

![](img/9a5b9efff92da1263a1b04aa9d4ae262_56_0.png)

# OpenOffice.org 文字处理器

将显示“查找和替换”对话框。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_57_0.png)

在 `Search for` 文本框中输入要查找的单词。在 `Replace with` 文本框中输入用于替换的正确单词。

点击 `Find` 或 `Find All` 按钮。

然后点击 `Replace` 或 `Replace All` 按钮。

> ### 思考园
> 尝试在查找特定单词时选中 `Match case`（匹配大小写）选项。

# OpenOffice.org 文字处理器

## 使用拼写检查和同义词库

### 使用拼写检查

OpenOffice.org 文字处理器内置了一个字典，用于检查文档中的拼写。拼写检查从光标当前位置开始，检查整个文档。

### 运行拼写检查

点击 `工具 → 拼写和语法`

![](img/9a5b9efff92da1263a1b04aa9d4ae262_58_0.png)

# OpenOffice.org 文字处理器

拼写对话框将显示文档中第一个拼写错误的单词，以及字典中提供的最接近的匹配建议。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_59_0.png)

1. `Ignore Once`（忽略一次），忽略仅一次出现的拼写。
2. `Ignore All`（全部忽略），忽略整个文档中的拼写。
3. `Change`（更改），接受并更改仅一次出现的拼写。
4. `Change All`（全部更改），接受并更改整个文档中的拼写。

### 使用自动拼写检查

![](img/9a5b9efff92da1263a1b04aa9d4ae262_59_1.png)

自动拼写检查在您输入文档时轻松识别页面上拼写错误的单词。拼写错误的单词下方可以看到一条红色波浪线。在拼写错误的单词上右键单击，从出现的列表中选择建议的替换词。更正将应用于文档。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_59_2.png)

### 使用同义词词典

同义词词典通过提供同义词列表（意思相近的词语）和相关的词语，帮助你改进词汇量。点击 `工具 → 语言 → 同义词词典`，或按 `[Ctrl+F7]`。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_60_0.png)

同义词词典对话框将显示出来。在“含义”列表中，选择与上下文相符的定义。在“同义词”列表中选择要替换的词语。点击“确定”。

### 处理图形

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_0.png)

#### 将图形作为副本插入

1. 点击标准工具栏上的`图库`图标，或通过选择 `工具 → 图库` 来打开`图库`。
![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_1.png)
2. 选择一个`主题`。
3. 单击选择要使用的`对象`。
![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_2.png)
4. 将对象拖入文档中，或者右键打开上下文菜单并选择 `插入 → 复制`。
![](img/9a5b9efff92da1263a1b04aa9d4ae262_63_0.png)

#### 将图形作为背景插入

1. 点击标准工具栏上的`图库`图标，或通过选择`工具 → 图库`来打开图库。
2. 选择一个主题。
3. 单击选择要使用的对象。
4. 打开上下文菜单并选择`插入 → 背景 → 页面或段落`。
![](img/9a5b9efff92da1263a1b04aa9d4ae262_63_1.png)

#### 在图形周围添加边框

选择图形，然后点击 `格式 \ 图形...`

或者，你可以右键点击图形并选择 `图形...`

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_0.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_1.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_2.png)

图形对话框将打开。选择`边框`标签。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_0.png)

在`线条排列`区域，选择五个按钮中的一个：

- 设置无边框，
- 设置所有四条边框，
- 仅设置左右边框，
- 仅设置上下边框，或
- 仅设置左侧边框。
