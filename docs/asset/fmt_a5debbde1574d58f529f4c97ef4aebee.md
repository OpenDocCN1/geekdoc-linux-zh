
正如“UNIX 历史”章节所描述，UNIX 起根于一个旨在简单并提供正交公共组件的系统。尽管现代 UNIX 系统已经变得相当庞大，但单体应用也并不罕见，原始的哲学仍然存在于所有 UNIX 系统可用的命令中。整个 UNIX 中有许多常用命令：

- 简单、正交的命令
- 通过管道连接的命令
- 一（大部分）通用的选项接口风格
- 无文件类型

有关命令及其连接的详细信息，请参阅 Shell 章节（第 8–13 章）和常用命令章节（第 5–9 章）。

# 简单正交的命令

原始的 UNIX 系统非常小，设计者试图通过编写短命令来利用这些小型机器的优势。每个命令都尝试很好地完成一件事。然后可以将这些工具组合（通过 Shell 脚本或 C 语言）来完成更复杂的任务。一个名为 `wc` 的命令专门用于统计文件的行数、单词数和字符数。要统计文件中所有的单词，你会使用 `wc *` 并得到如列表 1.1 所示的输出。

## 列表 1.1. 使用简单命令。

```
$ wc *
351 2514 170219 minix-faq
1011 5982 42139 minix-info
1362 8496 59160 total
$
```

# 通过管道连接的命令

为了将简单正交的命令变成强大的工具箱，UNIX 允许用户将一个命令的输出作为另一个命令的输入。这种连接被称为管道（pipe），由管道连接的一系列命令被称为流水线（pipeline）。例如，要统计所有文件中引用 MINIX 的行数，可以输入 `grep MINIX | wc` 并得到如列表 1.2 所示的输出。

## 列表 1.2. 使用流水线。

```
$ grep MINIX * | wc
105 982 6895
$
```

每个命令都有可以通过选项控制的操作，这些选项由连字符后跟单个字母指定（例如 `-1`）。某些选项接受参数选项，其指定方式为连字符后跟单个字母，再跟跟参数（例如 `-h Header`）。例如，要以每页 16 行的形式打印 `minix-info` 文件中所有提到 Tanenbaum 的行，你会使用 `wc minix-info | pr -1 16` 并得到如列表 1.3 所示的输出。

# 无文件类型

UNIX 不关注文件的内容（当你尝试将其作为命令运行时除外）。它不知道电子表格文件和文字处理文件之间的区别。文件中字符的含义完全由使用文件的命令提供。这个概念对 PC 用户来说熟悉，但它是 UNIX 与其他早期操作系统之间的显著区别。这种力量源于任何程序都可以处理文件。

## 登录成功后

登录成功后，屏幕上会出现几条消息。其中一些可能是你上次登录的日期和时间、系统的信息消息（称为“每日消息”，MDD），以及一条告知你是否有（电子）邮件的消息。每日消息是一条需要关注的重要信息，因为它是管理员与系统用户通信的一种方式。下次计划的停机时间（即无人可以使用系统）就是你可能在这里看到的信息示例。

## 退出

几乎任何 shell 的正常退出方式都是输入 `exit`。这会导致你的 shell 退出并停止运行。当你使用 shell 时，请退出。如果你使用 `csh`，你也会退出。

在 UNIX 操作系统上，有许多不同的 shell。如果你使用的是系统，请退出。这会导致你的 shell 退出并停止运行。任何 shell 的正常退出方式都是输入行结束符（通常是 `Control+D`，参见本章的“在 UNIX 上工作”）。

如果你有图形界面，请查阅手册或在线文档了解如何退出 GUI。

## 使用命令

在“登录”节描述的过程中，UNIX 执行了若干操作来准备系统。这些包括执行系统账户、初始化环境变量以及启动命令解释器（通常称为 shell）。命令是你告诉系统执行某些操作。命令解释器识别这些命令并将信息传递到需要的地方。UNIX 系统最初带有一个名为 Bourne Shell 的命令解释器（称为 `sh`，尽管某些系统提供 Korn 或 POSIX 作为 `sh`）。这种 shell 在大多数 UNIX 系统中仍然可用。一种较新的 shell 是 Korn Shell（称为 `ksh`）。另一个常用但并非普及的 shell 是 C Shell。在不同的 shell 之间，可用的命令存在某些差异。请参见第二部分关于这些 shell。

> 注意：名字代表了什么？

在各种 UNIX 系统上有许多常见的 shell。常见的如下：

| | |

|---|---|

| `sh` | Bourne Shell 是所有 shell 中最常见的。（可能安装为 bsh。） |

| `ksh` | Korn shell 是 Bourne shell 的派生物，增加了历史记录和命令行编辑。（有时安装为 `sh`。） |

| `sh` | POSIX shell 与 Korn shell 非常相似。POSIX 标准要求其安装为 `sh`。某些厂商将其标记为 `/bin/sh`。某些将其放在特殊目录并命名为，让 Bourne shell 留在 `/bin/sh`。 |

| `csh` | C shell 基于流行的 C 语言。 |

| `bash` | Born Again 不太常见。 |

| `tcsh` | 这是 C shell 的一个版本，具有交互式命令行编辑功能。 |

## 什么是命令？

UNIX 命令是你输入的一系列字符。这些字符由由空白符分隔的单词组成。空白符是输入一个或多个空格（Space）或制表符（Tab）的结果。第一个单词是命令名称。其余单词被称为命令的参数（arguments）。参数为命令提供了可能需要的信息，或者指定命令的行为。要调用命令，只需输入命令名称，后跟参数（任意数量的），以表示你正在输入并准备好执行该命令，然后按回车键（Enter）。

尝试一下。输入 `date` 命令。该命令名称是 "date"，它不接受任何参数。因此，输入 `date` 并按回车，看看会发生什么。你应该看到电脑打印了当前日期，如果时间与事实不符，请联系系统管理员修复。尝试一个带有参数的命令如何？尝试 `echo` 命令。该命令名称是 "echo"，它接受一系列参数。`echo` 命令会将这些输出写入（或“回显”）输出到你的屏幕上。尝试创建一个命令，在屏幕上写出你的姓和名。以下是我们的系统中命令和输出的样貌：

```
$ date
Sat Aug 5 11:11:00 EST 1995
$ echo MyName
MyName
$
```

> 注意：某些命令（如 `echo`）是你正在使用的特定 shell 的。这些被称为内置命令（built-ins）。在这种情况下，命令在不同系统之间并不是标准的。如果你学习了一个 shell 之后必须（或想）切换到另一个 shell，你可能需要学习新命令（并忘记其他命令）。其他命令是标准的 UNIX 命令，不依赖于你使用的是什么 shell。这些应该存在于每个 UNIX 系统上。其余命令是非标准的，可能不存在于特定的 UNIX 系统。

UNIX 命令使用一种特殊的参数称为选项（option）。选项的形式是一个破折号（使用减号 `-`）后跟一个或多个字符。选项为命令提供信息。大多数时候，选项只是破折号后的单个字符。两种不常用的形式是使用加号而不是减号，以及破折号后跟一个单词而不是单个字符。接下来的段落显示了一个带有不同选项的常用命令。`ls` 列出当前目录下的文件。

首先，尝试 `ls`。然后尝试使用 `-a` 选项，并注意目录列表包含几个以句号开头的文件。这些隐藏文件只有在你使用 `-a` 选项时才列出。接下来，尝试使用 `-1` 选项运行 `ls`。此选项更改目录列表的格式，使每个文件显示一些相关细节。最后，同时使用这两个选项尝试 `ls` 命令，这样你的命令输出如下：`ls -a -1`。

```
$ ls
visible
$ ls -a
.	.hidden visible
$ ls -l
total 0
-rw-rw-rw-	1 root	0	Mar 5 12:58	visible
$ ls -a -l
total 16
drwxr-xr-x	2 martin	1024	Mar 5 13:03	. *
drwx-xr-x	2 martin	1024	Mar 5 13:03	.
-rw-rw-rw-	1 root	0	Mar 5 12:58	hidden
-rw-rw-rw-	1 root	0	Mar 5 12:58	visible
$
```

`ls` 命令通常尝试选择有意义的字母。你可能会认为 `ls` 命令的 `-a` 意味着应该列出所有（all）文件（包括以句号开头的文件）。你可能将 `-l` 选项认为是长格式（long）目录列表，格式已更改，每行包含一个文件及其细节。

# 重定向输入和输出

UNIX 中一个普遍的概念是输入和输出的重定向。在查看重定向之前，先在不修改的情况下查看输入和输出是一个好主意。UNIX 使用标准定义默认或普通模式。UNIX 有标准输入（stdin），意味着来自键盘；标准输出（stdout），意味着去往屏幕。当你首次登录系统时，你的 shell 执行，你的标准输入被设置为你在键盘上输入的内容，你的标准输出被设置为显示器。

等等，`cat` 命令从标准输入获取任何字符并让你作为输出看到它们。例如，输入不带参数的 `cat` 命令。你的光标应该停在下一行。`cat` 正在等待你输入字符。你可以输入任意数量的内容，然后你应该指定你已完成。输入几个单词并按返回键。现在尝试特殊字符 Ctrl+D（按住 Control 键）。这是 "eof" 字符（关于字符的描述请参见后文）。你输入的单词应该通过从键盘输入显示，并且标准输出（在屏幕上打印的命令）。

```
$ cat
some words
[Ctrl+D]
$
```

虽然这个简单的例子现在看起来还不是特别有用，但等它作为重定向时的用法。UNIX shell 具有表示重定向的特殊字符。这里只涵盖了基础。请参考第二部分关于每个 shell 重定向的细节。输出重定向由 `>` 字符表示，输入重定向由 `<` 字符表示。输出被重定向到文件，输入从文件重定向。现在，继续剩余示例。

接下来，尝试使用输出重定向 `cat` 命令，保持输入不变。输入 `cat > filename`。`filename` 是你选择的名字。再次，`cat` 命令应该在等待输入。输入几个单词并按返回。现在尝试特殊字符 Ctrl+D（按住 Control 键）。这是 "eof" 字符。你输入的单词应该通过从键盘输入显示，标准输出（在屏幕上打印的命令）。输出被重定向到文件，输入从文件重定向。现在，继续剩余示例。

最后，尝试使用输入重定向 `cat` 命令，保持输出不变。输入 `cat < filename`。`filename` 是你选择的名字。再次，`cat` 命令应该在等待输入。输入几个单词并按返回。现在尝试特殊字符 Ctrl+D（按住 Control 键）。这是 "eof" 字符。你输入的单词应该通过从键盘输入显示，标准输出（在屏幕上打印的命令）。输出被重定向到文件，输入从文件重定向。

## 查看和设置环境变量

每个用户的环境看起来略有不同。为什么不看看你的环境是什么样子的呢？输入 `env` 命令且不带任何参数。输出格式和变量名取决于你正在使用的 shell 以及系统的配置。一个典型的环境可能包含以下内容：

```
$ env
HOME=/u/sartin
LOGNAME=sartin
MAIL=/usr/mail/sartin
MANPATH=/usr/man:/usr/contrib/man:/usr/local/man
PATH=/bin:/sbin:/usr/bin:/usr/contrib/bin:/usr/bin
SHELL=/bin/sh
TERM=vt10
TZ=CST6CDT
$ echo $HOME
/u/sartin
$
```

你环境中的变量数量非常大，以当你只想查看其中一个值时，并不想看到显示的所有值。如果是这种情况，你可以使用 `echo` 命令来显示环境变量的值。要指定某个单词应该被特殊对待——作为环境变量的值——请在变量名之前紧 preceding一个美元符号（`$`）。注意不要在 `$` 和变量之间输入任何空格。示例中的变量之一是 `HOME`。你的环境中很可能也有这个变量，尝试使用 `echo` 显示它的值。
