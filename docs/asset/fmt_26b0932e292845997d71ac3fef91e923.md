
幸运的是，Linux 确实有一个极其强大的办公套件，即 OpenOffice.org，顺便一下，它在 Windows 和 Mac 上也是免费的。OpenOffice.org 并不是什么轻量版；它是一个强有力的竞争者和一个赢家。

## OpenOffice.org 应用

整个 OpenOffice.org 套件由六个应用程序组成：

- Writer：文字处理器
- Calc：电子表格
- Impress：演示文片创建器
- Draw：矢量图形程序
- Base：数据库
- Math：数学编辑器

由于提供如何使用这些每个程序的完整详细说明将占据一整本书，我将简单向你介绍每个模块。

## Writer

如前所述，文字处理器是大多数用户最经常使用的办公应用程序。幸运的是，OpenOffice Writer 是一个很好的工具（见图 13-1）。它功能丰富，并且可以读取和保存 Word 文件。像 Word 一样，它甚至允许将文档保存为 HTML 文件，这样你可以轻松地将文档转换为网页。

## Calc

Calc 是 OpenOffice.org 的电子表格应用程序，在功能和常规布局上与 Excel 相似——重要的一点是，它可以读取和保存 Excel 文件。

![](img/ba6b82a7869bba748202d57c97336dca_232_0.png)

图 13-2：在 OpenOffice.org Calc 中创建的图表

大多数使用电子表格的人通常理解其原理，并在稍微摸索后，就能学会如何使用它们；我将不会提供关于使用 Calc 的任何入门教程。然而，由于许多其他人甚至认为没必要尝试使用电子表格，我将提到 Calc 可以做的一些简单事情，以希望能吸引你们一些人去尝试。

如果你对数字不感兴趣，仍然可以使用 Calc 来创建信息列表，例如生日列表、班级名单、购物清单、地址列表等等……任何内容。你甚至可以让 Calc 将列表按字母顺序排序，或者按出生日期排序等。每个人似乎都能找到 Calc 的用途，所以不要完全忽略它。

## Impress

Impress 是 OpenOffice.org 对微软 PowerPoint 的回应，它拥有兼容的幻灯片格式。它允许你在演示文中图形化地创建吸引人的幻灯片，还允许你为商务和教育环境创建实用的笔记或讲义，这些功能使得 Impress 对家庭用户来说也很有价值。

## Draw

对于家庭用户来说，OpenOffice.org Draw 更实用。尽管 Draw 并不是一个在艺术意义上创建真正图形的优秀程序，但它对于创建流程图、组织结构图（如婚礼招待或会议的座位安排）或任何你希望对文本和图形布局有更多控制权的文档（特别是当两者结合时）非常有用，例如传单、奖状、图表和通讯。从这个意义上说，Draw 可以非常有效地作为简单的页面布局工具，如图 13-3 所示。

![](img/ba6b82a7869bba748202d57c97336dca_233_0.png)

尽管 Draw 随 Ubuntu 带，但它不再列在应用程序列表中，可能是因为它的功能可以通过其他 OpenOffice.org 模块访问。尽管如此，它仍然实用的应用程序，如果你想以独立形式使用它，可以通过“运行应用程序”面板小部件输入 `office -draw`，或者手动将启动器添加到应用程序列表中。

要将 Draw 添加到应用程序列表，请右键点击“应用程序”并选择“编辑菜单”打开菜单编辑器。一旦编辑器出现，在左侧窗格中点击“图形”或“办公”（或两者都点），取决于你希望菜单启动器出现在哪里。在窗口的右侧窗格中，勾选 OpenOffice.org Drawing 旁边的复选框。完成后，点击“关闭”按钮，Draw 就会出现在菜单中。

## Base

OpenOffice.org 的一个新成员是 Base，它是你机器上任何数据库的图形化前端，学习 Base 自己的数据库 HSQL。遗憾的是，如果你有任何数据库应用程序的工作经验，学习如何使用 Base 也并非易事；如果你对这类应用的接触仅限于 AppleWorks 中的数据库模块，你可能想尝试一个相对容易理解的教程（其 URL 并不那么容易上手），地址为 `http://searchopensource.techtarget.com/tip/1-289483_sid39_gci148271.0.html`。

## Math

最后，我们可以打开 OpenOffice.org Math。由于我在数学方面有点外行，关于 Math 我真的能告诉你更多信息是：它是一个数学公式编辑器，允许你生成复杂的数学公式并将其作为嵌入对象粘贴到其他 OpenOffice.org 程序中。它是一个纯粹的编辑器，不进行计算。我认为我可以很有把握地说，大多数人在日常生活中不需要它，除非你真的要写一辈子的教科书。

与 Draw 类似，OpenOffice.org Math 未列在应用程序列表中，但你可以通过“运行应用程序”面板输入 `office -math` 来访问它。噢，如果你真的要写一辈子的教科书，你也可以像处理 Draw 那样，通过菜单编辑器为 Math 添加一个启动器。在编辑器窗口中，点击“新建项目”按钮。在出现的“创建启动器”窗口中，在“名称”框中输入 OpenOffice.org Math，在“命令”框中输入 `office -math`。完成后，点击“确定”。新项目将出现在菜单编辑器窗口中，被选中并准备就绪。

## Microsoft Office 和 OpenOffice.org 文件兼容性

尽管我在本节中一直提到了这一点，但值得再次强调的是 OpenOffice.org 可以读取和写入 Microsoft Office 文件。这种兼容性已经足够好，尽管表格有时会显得略有问题。

为了读取 Microsoft Office 文件，你只需要双击相关文件，它就会在相应的 OpenOffice.org 模块中打开。然而，要在 OpenOffice.org 中保存文件以便在 Microsoft Office 中，你必须将其保存为相应的格式，否则 OpenOffice.org 默认会将文件保存为原生格式：Writer 文档为 `.odt`，Calc 文档为 `.ods`，Impress 文档为 `.odp`。

在保存文件时执行此操作，请点击“保存”窗口中“文件类型”旁的小箭头，并从出现窗格中列出的可用格式列表中选择相应的 Microsoft Office 格式——例如，Writer 文档选择 Microsoft Word 97/2000/XP。

将你的图形添加到画库也相对简单。首先，你必须为你每组想要添加的图像创建一个新类别（称为主题）。要创建你自己的画库主题，请点击画库窗口中的 New Theme（新主题）按钮。这将打开 New Theme Properties（新主题属性）窗口。

窗口，你应该首先点击 General（常规）选项卡并为你的主题命名。完成后，点击 Files（文件）选项卡，然后是点击 Find Files（查找文件）按钮，这将弹出一个 Select Path（选择路径）窗口。从那里，你可以导航到你存储剪贴图、照片或其他图形的文件夹。一旦找到文件夹，点击 Select（选择）按钮，随后该文件夹中所有文件的列表将出现在 New Theme 属性中。
