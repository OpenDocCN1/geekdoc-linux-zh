
## 描述

`pax`（portable archive exchange）命令为 POSIX 兼容的系统提供了比 `tar` 或 `cpio` 命令更好的可移植性。使用 `pax` 命令可以复制文件、特殊文件、需要多个磁带卷的文件系统，或您想要在 POSIX 合规系统之间进行复制的文件。`pax` 命令的缺点是它不感知文件系统边界，且全路径名长度不能超过 255 个字符。`pax` 读取、写入并写入归档文件的成员列表并复制目录层次结构。它支持多种归档格式；请参见 `-x format` 选项。

## 运行模式

所采取的操作取决于 `-r`（读）和 `-w`（写）选项的存在。`-r` 和 `-w` 的四种组合称为四种运行模式：列表、读取、写入和复制模式，对应于概要所示的四种形式。

- 当你既不指定 `-r` 也不指定 `-w` 时，从标准输入读取归档文件，并将路径名匹配指定模式的归档成员列表写入标准输出。如果指定的命名文件类型为目录，也将写入该文件为根的目录层次结构。
- 当你指定 `-r` 但未指定 `-w` 时，从标准输入读取路径名匹配指定模式的文件，并提取其成员。如果提取的文件类型为目录，也将提取该文件为根的目录层次结构。相对于当前文件层次结构创建提取出的文件。恢复文件的文件的所有权、访问和修改时间以及文件模式在 `-p` 选项下讨论。
- 当你指定 `-w` 但未指定 `-r` 时，将文件操作数的内容以归档格式写入标准输出。如果未指定文件操作数，则从标准输入读取一个要复制的文件列表，每行一个。类型为目录的文件包括该文件为根的目录层次结构中的所有文件。
- 当你同时指定 `-r` 和 `-w` 时，将文件操作数复制到目标目录。如果未指定文件操作数，则从标准输入读取一个要复制的文件列表，每行一个。类型为目录的文件包括该文件为根的目录层次结构中的所有文件。复制的效果等同于将文件写入归档并随后提取，但目标目录是文件的一个子目录。如果目录不存在、用户不可写或不是目录，则报错。在读取或复制模式下，如果需要中间目录，`pax` 执行等同于 `mkdir(2)` 的操作，参数如下：
  - 使用中间目录作为路径参数。
  - 使用八进制值 777（读、执行权限）作为模式参数（参见 `chmod(1)`）。

如果指定的模式或文件操作数没有被文件或归档成员匹配，`pax` 将每个匹配项向标准错误写入诊断消息并以非零状态退出。归档格式根据输入自动检测。默认归档格式为 `tar(1)`。如果选定的归档格式支持链接文件，如果在提取归档时无法链接这些文件则报错。归档中的各种名称可用于选择提取的文件。

## 选项

- `-r` 从标准输入读取归档文件。
- `-w` 以指定的归档格式将文件写入标准输出。
- `-a` 将文件附加到归档末尾。此选项不支持某些归档设备，例如流式磁带和 8mm 磁带。
- `-b blocksize` 按正十进制字节数写入归档文件进行阻塞。设备和归档格式可以对阻塞实施限制。阻塞根据输入自动确定。可移植应用程序指定的块大小不能超过 32,256。创建归档时的默认阻塞取决于归档格式。（参见 `-x` 选项）。
- `-c` 匹配除模式或文件操作数指定之外的所有归档成员。
- `-d` 复制类型为目录的文件或提取的归档成员时，仅匹配文件或归档成员本身，而不是该文件为根的层次结构。
- `-f archive` 指定输入或输出归档的路径或标准输出模式。
- `-i` 交互式重命名文件或归档成员。对于每个匹配模式的归档成员或匹配文件操作，向 `/dev/tty` 写入提示。提示包含文件或归档成员的名称。然后从 `/dev/tty` 读取一行。如果行为空，则跳过该文件或归档成员。如果行由单个点组成，则处理该文件或归档成员而不修改其名称。否则，用行内容替换其名称。立即退出并返回

在读取响应时遇到文件结束（EOF）或无法为读写打开 `/dev/tty` 时，将返回非零退出状态。

- `-k` 防止覆盖已存在的文件。
- `-l` 链接文件。在拷贝模式下，尽可能在源和目标文件层次结构之间创建硬链接。
- `-n` 使用匹配每个模式操作数的第一个归档成员。每个模式操作数对应对应一个归档成员（尽管目录成员仍然匹配以该文件为根的文件）。
- `-o` 选项 留作用于特定格式的特殊选项。
- `-p string` 指定一个或多个文件特性选项（权限）。该字符串参数必须是指定在提取时保留或丢弃文件特性的字符串。该字符串由指定字符 `a`、`e`、`m`、`o` 和 `p` 组成。你可以在同一个字符串内串联多个特性，并指定多个 `-p` 选项。这些指定字符的含义如下：
  - `a` 不保留文件的访问时间。
  - `e` 保留用户 ID、组组 ID、文件模式位、访问时间和修改时间。
  - `m` 不保留文件的修改时间。
  - `o` 保留用户 ID 和组组 ID。
  - `p` 保留文件模式位。其他取决于实现的文件模式属性也可以被保留。

在上述列表中，`p` 表示存储在归档中的属性将赋予被提取的文件，但取决于调用进程的权限；否则，该属性将作为正常文件创建的一部分被确定。

如果你指定了 `e` 或 `o` 字符，但用户 ID 和组 ID 由于某种原因未被保留，`pax` 将不会设置文件模式的 `setuid` 和 `setgid` 位。

如果由于任何原因导致这些项目之一的保留失败，`pax` 会向标准错误写入诊断信息。未能保留这些项目会影响最终的退出状态，但不会删除已提取的文件。

如果任何字符串参数中的文件特性字母重复或相互冲突，则最后给出的具有优先权。例如，如果你指定了 `-p eme`，则会保留文件的修改时间。

## `pax`

- `-s replstr` 根据替换表达式 `replstr` 修改由模式或文件操作数命名的文件或归档成员名称。该表达式基于 `ed(1)` 的 `s`（替换）命令，并使用 `regex(5)` 手册页中的正则表达式语法。在 `pax` 命令的上下文中，地址和行的概念是没有意义的，且不能提供。其格式为：

```
-s / old/new/ [gp]
```

其中，在 `ed` 中，`old` 是一个基础正则表达式，`new` 可以包含与符号（`&`）或反引用，其中 `n` 是一个数字。`old` 字符串也允许包含换行符。

你可以使用任何非空字符作为分隔符（此处显示为 `/`）。你可以指定多个 `-s` 表达式；这些表达式按指定的顺序应用，并在第一次成功替换时终止。可选的末尾 `g` 是在 `ed` 命令中定义的。可选的末尾 `p` 将成功的替换结果写入标准错误。在读取和写入归档时，被替换为空字符串的文件或归档成员名称将被忽略。

- `-t` 将归档文件的访问时间重置为在被 `pax` 读取之前具有的数值。
- `-u` 忽略比具有同名的预存文件或归档成员更旧（具有较新的/更早的文件修改时间）的文件。
  - 读模式（read mode）：如果归档成员比文件新，则提取与文件系统中文件同名的归档成员。
  - 写入模式（write mode）：如果文件比归档成员新，则用文件系统中具有同名的文件替换归档成员。
  - 拷贝模式（copy mode）：如果源层次结构中的文件较新，则通过源层次结构中的文件或通过指向源层次结构中文件的链接来替换目标层次结构中的文件。
- `-v` 在列表模式下，提供详细的目录列表。否则，将归档成员路径名称写入标准错误。
- `-x format` 指定输出归档格式。`pax` 命令识别以下格式：

`cpio` 扩展的 `cpio` 交换格式；参见 IEEE 1003.1(1990) 规范。这种字符特殊文件的默认块大小为 5,120。实现支持所有小于或等于 32,256 的 512 倍数的块大小。

这种归档格式允许将 UID 和 GID 高达 262,143 的文件存储在归档中。UID 和 GID 大于此值的文件将 UID 和 GID 60001 进行归档。

`ustar` 扩展的 `tar` 交换格式；参见 IEEE 1003.1(1990) 规范。这种字符特殊归档文件的默认块大小为 10,240。实现支持所有小于或等于 32,256 的 512 倍数的块大小。

任何尝试以不同于现有归档格式添加归档文件的都会立即退出并返回非零退出状态。

这种归档格式允许将 UID 和 GID 高达 2,097,151 的文件存储在归档中。UID 和 GID 大于此值的文件将 UID 和 GID 60001 进行归档。

- `-X` 遍历由路径指定的指定的层次结构，`pax` 不进入具有不同设备 ID (`-st_dev`, `stat(2)`) 的目录。

操作文件或归档成员名称的选项（`-c`, `-i`, `-n`, `-s`, `-u` 和 `-v`）的交互作用如下：

- 在读模式下，根据用户指定的、经过 `-c`, `i`, `n`, `s`, `u` 和 `v` 修改的路径名来选择归档成员。然后 `-c`, `i`, `n`, `s`, `u` 和 `v` 写入修改后的名称。
- 在写入模式下，根据用户指定的路径名选择文件，并经过 `-c`, `i`, `n`, `s`, `u` 和 `v` 修改。然后 `-v` 写入修改后的名称。
- 如果你指定了 `-u` 和 `-n`，除非文件较新，否则。

### 操作数

- 目录 拷贝模式的目标路径名。
- 文件 要拷贝或归档的文件路径。
- 模式 匹配一个或多个归档成员的路径。模式必须符合 `fnmatch(5)` 手册页。如果没有指定模式，默认选择归档中的所有成员。
