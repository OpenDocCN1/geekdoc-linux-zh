如果你的网络连接是双绞线（10 Base T），则你必须使用交叉网线。与空调制解调器一样，交叉线会交换信号对，使得一端的发送器连接到另一端的接收器。在这一点上，我们目前无能为力。我们必须等待到启动 BlueCat 镜像后才能处理。
