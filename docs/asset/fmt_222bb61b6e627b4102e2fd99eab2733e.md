# script — 记录终端会话

## 概要

```
/usr/bin/script [-a][filename]
```

## 描述

使用 `script` 命令将终端上显示的所有内容复制到文件中，包括你的输入、系统提示和输出。记录将写入 `filename`。如果你未指定文件名，记录将保存在 `typescript` 文件中。

`script` 命令会派生并创建一个子 shell（使用 `$SHELL` 的值），并记录此会话的文本。当派生的 shell 退出或你输入 `Control-D` 时，`script` 结束。

## 选项

- `-a` 将会话记录追加到 `filename` 而不是覆盖它。

## 示例

以下示例显示使用默认的 `typescript` 文件启动 `script`，然后显示 `typescript` 文件的注释。

# sdiff — 打印两个文件的并列差异

## 概要

```
/usr/bin/sdiff [-l][-s][-o output]{-w n} filename1 filename2
```

## 描述

`sdiff` 命令使用 `diff` 命令的输出来产生两个文件的并列列表，标出不同的行。差异以以下方式显示：

- * 如果行相同，则在行之间打印一个空白间隙。
- * 如果行仅出现在 `filename1` 中，则在间隙中显示 `<`。
- * 如果行仅出现在 `filename2` 中，则在间隙中显示 `>`。
- * 如果行不同，则在行之间显示 `!`。

## 选项

- `-l` 仅打印任何相同行的左侧。
- `-s` 不打印相同的行。
- `-o output` 使用输出参数作为第三个文件的名称，该文件是 `filename1` 和 `filename2` 合并创建的。将 `filename1` 和 `filename2` 的相同行复制到 `output`。当一组差异共享一个公共字符时，打印由 `diff` 产生的差异集。在打印每组差异后，用 `#` 提示并等待你输入以下命令之一：
  - `l` 将左列追加到输出文件。
  - `r` 将右列追加到输出文件。
  - `s` 开启静默模式；不打印相同的行。
  - `v` 关闭静默模式。
  - `e` 带有左列调用编辑器。
  - `r` 带有右列调用编辑器。
  - `b` 带有连接字符串调用编辑器。
  - `e` 带有左列调用编辑器。
  - `q` 退出。
  - `w` 指定输出的宽度。
  - `l` 仅显示左侧。

## 使用

`sdiff` 的用法参见 `diff(1)`。

## 示例

以下示例显示了 `sdiff` 如何比较两个文件。

```
$ sdiff file1 file2
line1
|line2
>line3
!line4
```

# sed 编辑命令

以下列表指示了每个函数允许的最大地址数量。

`r` 和 `w` 命令允许指定可选的 `rfile`（或 `wfile`）参数，该参数与命令字母之间用一个或多个空格分隔。

你可以通过分号 `;` 分隔多个命令，从而在同一条命令行上指定多个命令。

文本参数由一行或多行组成，除最后一行外，所有行都以 `\` 结尾以隐藏换行符。你必须在文本中的每个嵌入换行符之前加一个反斜杠。文本中的其他反斜杠会被删除，就像 `s` 命令的替换字符串中的反斜杠被视为字面量一样，可以用于在对每个脚本行进行清理后保护初始空格和制表符。`rfile` 或 `wfile` 参数必须终止命令行，并且前面必须恰好有一个空格。使用 `wfile` 参数时，如果文件不存在则初始创建该文件，或者替换现有文件的内容。最多可以有三个不同的 `wfile` 参数。

正则表达式匹配整个字符串，而不只是单行，但在 `sed` 的正则表达式（RE）中通过 `\n` 匹配换行符；RE 中不允许出现换行符。还要注意，你不能使用 `\n` 来匹配输入行末尾的换行符；换行符是作为 `N` 编辑命令的结果出现在模式空间中的。

有两个命令接受一个命令列表，该列表是由换行符分隔的 `sed` 命令列表，如下所示：

```
command
command
}
```

你可以在 `{` 之前加上空白字符，在其后跟随空白字符。你可以在 `s` 命令之前加上空白字符。你必须在结束符 `}` 之前加上一个换行符，并在其前后加上空格。你可以在大括号前后加上空白字符。你可以在命令之前加上空白字符，但不能在后面加上空白字符。
