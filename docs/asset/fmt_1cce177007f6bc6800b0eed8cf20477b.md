## 迭代语句

你使用迭代语句来重复执行一组命令。迭代语句包括`while`和`foreach`。

### 使用 `while` 循环

你使用`while`语句重复执行一组语句，直到指定的特定条件发生。`while`命令非常通用。只要计算出的表达式产生真（true）的结果，它就会反复执行一组命令。

> **注意：** 在编写`while`循环时需要格外小心，因为设计不当可能会导致命令在无尽循环中无限重复，或者根本不执行。

`while`命令的通用语法如下：

```
while (expr)
  commands...
end
```

对于*expr*，请编写一个shell表达式（参见本章节前面的“在shell语句中使用表达式和运算符”）。对于*commands*，请编写在每次*while循环*迭代中要执行的一个或多个命令。简单命令和复合命令、管道以及括号化的命令列表都是有效的。

在编写shell脚本时，习惯是将包含在*while*或*foreach*语句范围内的命令进行缩进。缩进有助于明确命令与*while*或*foreach*语句的从属关系，并在视觉上突出它们包含在循环中。

shell在循环第一次迭代之前以及随后的每次迭代之前都会评估*expr*。如果*expr*的值非零（换句话说，为真），则会解释并执行*commands*。*commands*中的任何替换都会每次遇到命令时执行，允许在每次迭代中替换不同的值。

当遇到`while`语句时，shell会像处理`if`一样处理它。如果为真，shell继续执行下一个语句。同样，如果*expr*为假，shell遇到`while`语句时，会直接跳转到`end`语句，有效地跳过`while`和`end`之间的所有命令。当你编写`while`语句时，需要仔细编写测试表达式*expr*，要意识到shell可能会在表达式某些情况下完全跳过`while`语句。

这是一个`while`语句的简单示例：

```
while ($#argv > 0)
  if (! -f $1) 
    echo $1: missing
    shift
end
```

`while`语句在每次重复时评估表达式`$argv > 0`——它用于测试是否存在命令参数。只要答案是肯，它就会执行`if`和`shift`命令。当命令参数的数量变为0时它会停止；在经过足够的`shift`重复后，最终会达到这一点。对于每次重复，`if`语句都会测试是否存在一个与命令参数同名的文件——如果没有，它会写入警告消息。使用文件名列表调用`while`语句，它会列出缺少对应文件时的参数以突出显示。你可以通过简单输入命令`name name`获得类似的效果。区别在于，你必须从普通输出中挑选出该消息，而示例只是列出了那些不存在的文件。

`end`语句必须使用来标记`while`循环的结束。它只在`for`和`while`语句的范围内有效。否则，它会产生shell错误，shell将停止处理。

### 使用 `foreach` 循环

`foreach`命令用于处理列表。它为作为`foreach`命令参数提供的每个单词执行一组命令。shell设置一个变量来指示当前迭代是哪个单词；你可以在重复命令中使用该变量，以便对列表中的每个单词执行相同的通用操作——命令名称。

`foreach`语句的通用语法：

```
foreach name (wordlist)
  commands
end
```

对于*name*，指定一个shell变量名，单词列表将接继赋值给该变量。该名称不需要是新的；它可以是现有变量。尽管如此，变量的任何当前值将丢失。退出循环时，*name*包含最后一个单词列表的最后一个单词。

对于*wordlist*，使用标准的shell语法指定一个或多个命令。这些命令可以是带引号的字符串（"foo bar 'bas）、任何字符字符串（one two three）、变量引用（$var array arr[1]）、用引号括起来的命令替换字符串（`'cat /tmp/x.$`）、文件名模式（`*.cc, .hh`）或通过`(! 引入的历史替换。所有单词都会被替换并执行，字符串会被还原为单词（在第一次循环迭代之前被引号阻止的情况除外）。你可以对*wordlist*加括号，在这种情况下，shell使用命令参数作为单词列表。

*commands*中的最后一个命令后面必须跟一个独立的语句分隔符（`;`）；它可能出现在最后一个命令的同一行，与分号分隔符隔开，或者出现在新的一行。`end`语句仅在使用`foreach`或`while`语句时才是有效命令。在其他上下文中，它被视为非法命令并导致shell错误。

循环为*wordlist*中的每个单词执行一次。在循环的每次迭代之前，变量名被设置为当前单词，从左到右逐单词遍历列表。当循环为列表中的每个单词执行完毕后，在*commands*中你可以使用变量`$name`来识别重复是针对哪个单词；你甚至可以更改`$name`的值——shell不会抱怨。它只是在用完单词时将*name*设置为什么（反过来）。

`foreach`语句是一个非常方便的工具，它允许你对列表中的每个项重复执行操作。它作为shell脚本内部的头部非常有用。在以下示例中，它被用于更改一系列文件的shell，将它们从`.c`重命名为`.cc`。

```
foreach file (*.c)
  mv $file $file.cc
end
```

#### 修改循环执行：`continue` 和 `break`

`continue`命令用于跳过当前迭代的剩余部分并进入下一个单词。`break`命令用于立即终止循环。在使用`break`和`continue`时，必须记住它们只影响同一层的`foreach`语句。要跳出嵌套两层或以上的循环，你需要使用条件语句（如`if`）测试某些条件并执行另一个`break`或`continue`。

## 修改命令执行顺序：`goto`

你可以使用`goto`来改变命令的执行顺序：

```
goto word
```

通常，命令是顺序执行的。循环语句`foreach`和`while`允许你固定或变量次数地重复一组语句，`if`和`switch`命令允许你在两个或多个备选语句组之间选择。除此之外，语句执行的通用控制流是从shell脚本或命令序列的第一个到最后一个。`goto`命令使得任意方式更改控制流成为可能。

对于*word*，指定一个标识符（不带引号、不包含空格或制表符、且不包含对shell有特殊意义的标点符号的字符字符串）。*word*受到文件名和命令替换的影响。假设当前目录下存在文件`index`，以下所有的`goto`命令将跳转到标签`index:`goto index`、`echo index*`和`index*`。

shell为以*word*后面紧跟冒号（*word:*）的行创建命令输入流；这形成一个语句标签。如果语句标签存在，执行将从其后的第一个命令开始恢复。如果找不到标签，shell将返回错误消息并停止。

`goto`命令通常在shell脚本内部使用，在这种情况下搜索标签的语句范围是

受限于脚本文件的内容。在任何其他上下文中，退格键会尽可能地退回输入法的内容，然后向前查找语句标签。终端不支持退格操作，因此通过键盘发出`goto`语句。

> 注意：如果实际上存在可以跳转的标签，从键盘使用`goto`可能导致你的会话进入无限循环。请考虑历史缓冲区。

```
1 ls /usr/bin
2 jumpHere:
3 echo Infinite loop
```

带有标签`jumpHere:`。如果你输入`gotoHere`，C shell将`goto`命令插入到你的历史4中，并在你的历史列表中无限重复3和4。

## 指定信号的响应：onintr

使用`onintr`来指定当shell接收到信号时要采取的操作。例如：

```
onintr
onintr -
onintr label
```

`onintr`命令大致等同于Bourne shell的`trap`命令，但在语法和用法上有所不同。

在不带参数的情况下，`onintr`命令设置所有信号的默认操作。在脚本中使用时，这会导致大多数信号导致器脚本终止。从键盘使用时，它将重置你通过之前的`onintr`命令建立任何信号处理。

你可以使用`onintr`禁用并忽略所有信号。这种形式在脚本内部运行时非常方便，可以保护一系列敏感的命令，如果这些命令被中断（因为接收到信号导致脚本终止而被放弃），可能会留下不需要的文件或通用的无效结果。你可以使用不带参数的`onintr`来恢复正常的默认操作。

你可以使用`onintr label`使shell对语句标签执行隐式的`goto`。shell不提供接收到什么信号的指示。大多数信号代表终止的原因，因此这种`goto`形式可以在退出脚本之前执行有序的清理。你可以在shell脚本中使用`onintr label`，以便在进程`INTR`键（中断键，通常配置为Ctrl-C，使用`-a`查询你的终端设置）信号想要取消shell脚本的执行时提供一个清理程序。在执行完任何所需的操作后，脚本将使用`exit`命令退出。

有关语句标签的更多信息，请参阅本节中的`goto`命令描述。

如果你必须创建临时文件，遵循几个简单的指南可以节省大量的痛苦。

在命名临时文件时始终使用`$$`，并始终将文件放在`/tmp`中。使用`$$`确保了唯一性，在大多数Unix系统上，`/tmp`会定期删除未访问的文件。以下命令为脚本中的使用创建一个临时文件名：

```
set tmpfile=/tmp/foo$$
```

## 处理任意数量的参数：shift

你可以使用`shift`将位参数（$1, $2, $n）向左移动：

```
shift
shift name
```

执行后，$2`的值移动到`$1`，$3`的值移动到`$2`，依此类推。$1`的原始值被丢弃，位参数的总数（由`$argv`表示）减少1。

你可以使用`shift name`对命名变量执行相同类型的操作。

## 在当前 Shell 中解释脚本：source

你可以使用`source`在当前shell环境中读取并解释shell命令脚本：

```
source [-h] name
```

不会调用子shell，且由于shell中的命令引起的任何环境变化在执行后将仍然有效。执行脚本文件`source`可能导致的更改包括更改当前目录、创建或更改环境变量以及定义命令别名。

使用`source`解释的脚本中包含的`exit`语句会导致从当前shell层级退出；如果这是你的shell，你会被注销。

对于`name`，提供包含shell命令和语句的文件名或路径。如果你没有指定以`/`、`.`或`..`开头，某些C shell版本会在当前目录路径（`path`变量）搜索该文件。

`-h`选项允许将文件源到历史缓冲区而不执行执行命令。
