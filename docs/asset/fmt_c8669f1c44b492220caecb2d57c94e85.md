## 扫描 / 入侵测试工具

在过去的几年里，Windows 和 UNIX 安全工具的数量大幅增加，更令人惊讶的是，其中大多数在互联网上都是免费提供的。我将只介绍免费工具，因为大多数商业工具价格极其昂贵，不是开源的，在许多情况下被证明包含重大的安全漏洞（例如在安装后以明文存储密码）。如果任何严重的破解者/黑客都有这些工具可用，为什么你不能用呢？

工具分为几个大类：那些从主机内部进行扫描的工具、一种扫描其他主机并报告它们运行什么操作系统的工具（使用一种名为 TCP-IP 指纹识别的技术）、可用的服务等；在食物链顶端的是入侵工具，它们实际上会尝试执行漏洞利用，并报告执行是否成功；最后我包含了漏洞利用（exploits）类别，虽然它们严格来说本身不是入侵工具，但它们确实存在，你应该关注它们。

### 主机扫描器

#### Cops

`Cops` 极其过时，它在 CERT ftp 站的首页已不存在。

#### Tiger

`Tiger` 已经过时，但为了历史准确性，我想应该提一下。德克萨斯农业与机械大学曾要求 UNIX 主机在允许远程连接网络之前必须通过 `tiger` 测试。你可以从这里获取：ftp://net.tamu.edu/pub/security/TAMU/

#### SBScan

`SBScan` 是一种新兴的主机扫描器，它寻找各种问题，如坏文件、开放端口、无密码账户，并扫描网络中其他类型的异常行为。`SBScan` 获取地址为：http://sy.tx.org/

#### check.pl

`check.pl` 是一个很好的 Perl 程序，用于检查文件和目录，并会你任何可疑或“坏”的项（setuid、setgid、可写目录等）。非常有用，但它倾向于发现很多假报警。它的获取地址为：http://opop.nols.com/proggie.html。

### 网络扫描器

#### Strobe

`Strobe` 是较早的端口扫描工具之一，简单来说，它尝试连接到机器上的各种端口并报告结果（如果有）。它简单易用且速度极快，但不具备较新端口扫描器的任何功能。`Strobe` 几乎可以在所有发行版中作为其一部分或作为 contrib 包提供，源码地址为：ftp://suburbia.net/pub/

#### Nmap

`Nmap` 是一个较新且功能丰富得的主机工具。它具有先进技术，例如 TCP-IP 指纹识别，通过这种方法检查返回的 TCP-IP 数据包，并根据所有 TCP-IP 栈中存在的特性推断主机操作系统。`Nmap` 还支持许多扫描方法，从普通的 TCP 扫描（简单尝试打开连接）到隐蔽扫描和半开放 SYN 扫描（用于使不稳定的 TCP-IP 栈崩溃）。这无疑是可用最好的商业或非商业端口扫描工具之一。`Nmap` 获取地址为：http://www.insecure.org/nmap/index.html。

### 入侵扫描器

#### Nessus

`Nessus` 相对较新，但正迅速成为最好的入侵工具。它采用客户端/服务器架构，服务器目前运行在 Linux 上，客户端提供 Windows 版本，并有一个 Java 客户端。服务器与客户端之间的通信经过加密以增加安全性，它支持端口扫描，以及基于 IP 地址或主机名的攻击。`Nessus` 在攻击模式下速度较慢，这并不意外，但它目前有超过 200 种攻击方法。`Nessus` 获取地址为：http://www.nessus.org/

#### Saint

`Saint` 是 `Satan` 的续作，是一种几年前因媒体闻名的网络安全扫描器。`Saint` 同样采用客户端/服务器架构，但使用界面而不是客户端程序。`Saint` 产生易于阅读和理解的输出，按优先级对安全问题进行分级（尽管并不总是准确），还支持添加模块，使其非常灵活。`Saint` 获取地址为：http://www.saint/

#### Cheops

虽然 `Cheops` 本身不是扫描器，但它是加强版的“网络邻域”，它能构建域或 IP 块的图像。`Cheops` 能够构建域或 IP 块的图像。

虽然该软件尚未准备好供大众消费，但我认为应该提一下它，因为它是更大项目的一部分（Abacus 项目，http://www.psionic.com/abacus/）。基本上，`Host Sentry` 会构建一个用户访问的配置文件，然后将其与当前活动进行比较，以标记任何可疑活动。`Host Sentry` 位于：http://www.psionic.com/abacus/hostsentry。

## Pikt

`Pikt` 是一个非常有趣的工具，它实际上更像是一种面向系统管理的脚本语言，而不是一个简单的程序。`Pikt` 允许你执行诸许多操作，如杀死空闲用户进程、强制邮件配额、监控系统是否存在可疑的使用模式（非工作时间等）等。`Pikt` 唯一的问题可能是学习曲线曲线陡峭，因为它使用了自己的脚本语言，但我最终认为，如果你有许多系统需要管理，精通这种语言将是回报的（尤其是由于 `Pikt` 目前运行在 Solaris、Linux 和 FreeBSD 上）。`Pikt` 位于：http://pikt.uchicago.edu/pikt/

## 基于网络的攻击检测

## 主机监控工具

监控你的服务器和主机对于各种原因都非常重要，从追踪入侵到法律要求比应皆有。记住，防患胜于治疗。在“日志（Logging）”部分有多种监控工具可用，从 `syslog` 到 `audit`（允许你审计用户文件、运行的程序等）。我强烈建议你使用它们。因为还有许多特定的程序可以监控系统状态并防止用户做他们不该做的事。

## 数据包嗅探器

数据包嗅探是捕获并非指向你机器的网络数据的行为，通常用于查看机密/敏感流量，例如 telnet 会话或人们阅读电子邮件。遗憾的是，没有真正的方法可以检测数据包嗅探器，因为它是一种被动活动；但通过利用网络交换机和光纤骨干（这些很难被接管），你可以最大限度地减少威胁。

## 病毒/蠕虫/木马的消毒

备份你的数据，格式化并从已知的介质重新安装系统。一旦攻击者获取了 Linux 系统的 root 权限，他们字面上可以做任何事情，从破坏 `gcc/egcs` 到在启动时加载增加的内核模块。不要以 root 身份运行不可信软件。检查你下载文件的 PGP 签名等。稍防未缪就可以很大程度上阻止 Linux 下病毒、蠕虫和木马的传播。

处理病毒及病毒的最简单方法是使用系统完整性工具，如 `tripwire`、`L5` 和 `Gog&Magog`，你可以轻松地找到哪些文件被破坏，并对其进行恢复/替换/更新。

## 密码存储

这是许多人没有考虑过的问题。如何安全地存储密码？最明显的方法是记住它们，但这样做有缺点，如果你管理 30 个不同的网站，你通常想要 30 个不同的密码，而一个好的密码长度在 8 个字符以上，通常不是最容易记忆的。这导致许多人在多个系统中使用相同的密码（来吧，承认吧）。最简单的方法之一是将密码写下来，这是**大忌忌**，当人们发现到处乱丢时，以及他们在寻找时发现了什么，你会感到惊讶。更好的选项是以加密格式存储密码，通常以电子形式存储在你的计算机或掌电脑上，这样你只需要记住一个密码来解锁其他密码。可以使用像 `PGP` 或 `GnuPG` 这样简单的工具来实现这一点。

# Gpasman

`Gpasman` 是一个需要 `gtk`（在非 Gnome 系统上相对容易安装，只需加载 `gtk` 库）的应用程序，并使用 `rc2` 算法加密你的密码。程序启动时输入主密码，假设它是正确的，你将看到一个漂亮的用户账户、网站、密码和注释字段列表。`Gpasman` 的地址为：http://www.student.wau.nl/~olivier/gpasman/

# 执行基准/系统完整性

许多人在保护机器安全时的一个重大疏忽是忘记创建系统基准，基准是系统在正常运行时的配置、资源使用情况等。例如，简单的 `netstat -n > netstat-output` 就可以为你提供一个参考，以便稍后检查是否有不该开启的端口。内存使用和磁盘使用也是需要关注的事项，内存使用的的突然激增可能导致系统资源匮乏，磁盘使用也是如此，这可能是错误、恶意用户或已经入侵你的系统并正在扫描其他人的蠕虫程序。存在多种工具来测量内存和磁盘使用：`vmstat`、`free`、`df`、`du`，它们都由各自的涵盖。

至少要进行全系统备份，并定期备份配置文件和日志，当你准确定位发生了入侵时（例如用户账户 "rewrt" 在第 4 次备份后被添加，而该账户不在 3 月 20 日的备份中），这也能对你有帮助。一旦系统被破解，就会安装“根内核包”（rootkit），这些被木马化的二进制文件几乎不可能安全地删除，你最好格式化磁盘并从头开始。这条规则当然没有例外，如果你勤快并使用了如 `L5` 这样的文件/目录完整性工具，你就能轻松定位受影响的文件并处理它们。

`Tripwire` 不再是源码工具，我完全不反对商业软件，但当我依靠一个程序来提供安全时，如果我（或任何人）无法轻松查看源码（它根据某些特殊协议提供，可能是 NDA），我必须拒绝。`Tripwire` 在 Linux 上大约花费 70 美元，并且仅以 RPM 包的形式提供（其他操作系统上为 500 美元），对于一个可以被 `L5` 等替代方案替换的软件来说，这个价格偏高。`Tripwire` 地址：http://www.tripwiresecurity.com。

## 互联网连接检查清单

以下是为连接互联网的人员（PPP、DSL、电缆调制解调器等）准备的清单。虽然内容详尽，但应该有所帮助。

关闭所有不必要的守护进程和网络软件——除非你计划使用，否则禁用 telnet, ftp, rsh, auth, pop, imap 等。如果已关闭，风险会小得多。

尽可能使用 `ipfwadm/ipchains` 为服务设置防火墙，如果你默认开启了防火墙，这将极大地减少人们在你的机器上执行的扫描。通常情况下，NFS / Samba、imap 和 pop 等服务仅需要内部用户访问，阻止外部访问将极大地简化问题。

使用 `TCP_WRAPPERS` 来保护你留下的服务，在可能的情况下将 imap、pop 和 ftp 等服务的访问限制在内部或特定的互联网客户端。请记住，大多数发行版随带的 nfs 均配置了 `TCP_WRAPPERS`，且 SSH 也可以使用 `TCP_WRAPPERS`。这允许你轻松地集中对服务的访问控制。

将所有软件（特别是网络软件）更新到最新版本，检查适用于你发行版的错误列表 - 安全页面。

使用如 `AIDE` 或 `Gog&Magog` 等系统完整性工具来建立你当前（已知良好的）文件的列表和签名。如果你以后被黑客入侵了，这将让你的工作变得更轻松。

从外部站点运行渗透测试，即针对你的机器运行 `nmap / strobe, nessus` 类似的工具，以确保它被妥善锁住。记住，坏人拥有这些工具，所以你也应该使用它们。

保持软件 / 访问列表更新。定期使用 `logcheck` 等工具审计日志文件。如果可能，使用 `AIDE` 等工具监控并防止系统问题（例如，大量的邮件）。启用内核审计。确保你有足够的磁盘空间。
