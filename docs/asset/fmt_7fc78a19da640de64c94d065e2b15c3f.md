# 操作 Debian 包的命令

## dpkg 命令

此命令是执行 Debian 文件操作、获取信息或从系统中删除的主要工具。表 4.21 显示了 `dpkg` 命令的常用选项：

| 选项 | 说明 |
|---|---|
| `-i`, `--install` | 安装包。 |
| `-r`, `--remove` | 移除已安装的包并保留配置文件。 |
| `-P`, `--purge` | 卸载（如果已安装）并移除配置文件。 |
| `--configure` | 配置尚未配置的包。 |
| `-V`, `--verify` | 验证包的完整性。 |
| `-C`, `--audit` | 执行数据库一致性检查。 |
| `-l`, `--info` | 显示包的信息。 |
| `-l` `--list` | 列出匹配模式的包。 |
| `-s`, `--status` | 指定包的状态。 |
| `-L`, `--listfiles` | 列出安装到系统中的文件。 |
| `-S`, `--search` | 从已安装的包中搜索文件名。 |
