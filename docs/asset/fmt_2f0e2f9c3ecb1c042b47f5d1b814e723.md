# w — 显示当前登录用户的信息

### 概要

`/usr/bin/w [-hlsuw][user]`

## 描述

`w` 命令显示系统当前活动的摘要，包括每个用户正在做什么。标题行显示当前时间、系统运行时间、登录系统的用户数，以及在过去 1、5 和 15 分钟内运行队列中的平均作业数。`w` 是 `who`、`uptime` 和 `ps -a` 的组合。

显示的字段是用户的登录名、用户所处的 TTY 名称、用户登录当天的时间（小时:分钟）、空闲时间（即用户上次输入任何内容以来的分钟数，小时:分钟）、该终端上所有进程及其子进程占用的 CPU 时间（分钟:秒）、当前活动进程占用的 CPU 时间（分钟:秒），以及当前进程的名称和参数。

# Notes

当前进程的概念并不明确。当前的算法是终端上不忽略中断的编号最大的进程；如果没有则是终端上编号最大的进程。该算法在某些情况下会失效，例如在 `shell` 和编辑器等程序的关键区域，当在后台运行的故障程序派生（`fork`）且未能忽略中断时。在找不到任何进程的情况下，`w` 会打印 `-`。

CPU 时间只是估计值；特别是如果有人在注销后留下了后台进程运行，则该终端当前的人将被计入这段时间。

后台进程不会显示，尽管它们占据了系统的大部分负载。

有时进程（通常是后台进程）会带有空参数或乱码参数打印。在这些情况下，命令名称将打印在括号中。

`w` 并不知道检测后台作业的约定。它有时会找到后台作业而不是正确的作业。

## 选项

### 操作数

- `-user` 指定要显示登录信息的用户名称。

## 示例

以下示例未使用带选项的 `w` 命令显示当前系统活动的摘要。

```
castle% w

2:47pm up 58 min(s), 1 user, load average: 0.08, 0.05, 0.04

  tty login: idle JCPU PCPU what

winsor console 1:52pm 55 3 /usr/dt/bin/sdt_shell

-c unset

winsor pts/3 1:53pm 1 csh

winsor pts/4 1:53pm 1 /bin/csh

winsor pts/5 1:53pm 54 /bin/csh

winsor pts/6 1:53pm w

castle%
```

# wait

当卷管理找到包含文件系统的磁盘时，它调用 `rmmount` 来挂载它。如果你想在该磁盘上运行 `tar(1)` 或 `cpio(1)`，它必须先被卸载。

以下示例卸载了磁盘。

```
$ volmmount -e floppy0

$ 
```

在 `volmmount` 卸载磁盘后，如果你想重新挂载它（而不是弹出并重新插入），请使用以下命令。

```
$ volmmount -i floppy0

$ 
```

> Note — 如果你使用的是具名磁盘，可以使用它的名称代替 `floppy0`。
