- 3. 启动 GeeXBox 生成器——进入 `geebox-generator*` 目录并根据你用于重新生成 ISO 的操作系统启动以下命令之一：

```bash
# `/linuxi386-generator`          # 用于 Linux 系统

# `generator.exe`                            # 用于 Windows 系统

# `/.macosx-generator`                       # 用于 Mac OS X 系统
```
