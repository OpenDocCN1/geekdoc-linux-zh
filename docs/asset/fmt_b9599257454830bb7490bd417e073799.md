**方铅矿** 一含有`PbS`（铅）并属于`NaCl`（氯化钠）结构的矿物。方铅矿以立方体形式出现，有时被八面体形状修饰，具有完美的解理、、明亮的金属光泽、灰色、比重为7.5，且莫氏硬度为½。

方铅矿分布广泛，是铅最重要的矿石。尽管银、砷、铜和其他矿物经常与方铅矿紧密结合；因此，方铅矿也是许多有价值矿物的矿。主要矿床包括澳大利亚、密苏里州的密西比地区、堪萨斯州和俄拉荷马州；在科罗拉多州、蒙大拿州和爱达荷州有很多。[P.B.M.]

**伽利略变换** 牛顿力学中用于联系运动（相对）参考系空间和时间的数学变换族。在两个取向参考系沿它们共同的`(x, x')`轴运动的简单情况下，变换可以执行：

```
x' = x - vt
y' = y
t' = t
```

其中 `$x, y$` 和 `$x', y'$` 是点的坐标，`$v$` 是一个系统相对于另一个系统的速度。

**胆囊** 人类和脊椎动物中存在的一种肌肉器官，通过导管接收胆汁。它浓缩胆汁并将其排出肠道。它参与胆汁的肠肝（再）循环，并分泌脱结合的结合胆红蛋白，这是诊断目的的主要色素。

如果没有胆囊，胆囊将变为所谓的肝总管，作为总胆管或十二指肠胆管排入十二指肠。胆囊是肝外胆道唯一的囊性部分。

在大多数其他脊椎动物中，存在类似的元素，但没有胆囊，不过胆管的比例和排列存在差异；参见胰腺。[PANCAS]

胆囊的收缩通过触发机制完成，该机制由脂肪食物、十二指肠和小空肠中的胆酸触发。粘膜对这些物质的吸收释放出`CCK`（胆囊收缩素），它在血液中迅速移动并引起胆囊收缩和胆括肌松弛。最有效的食物是蛋黄。

**胆囊疾病** 尽管对生命并非不可或，但胆囊是人类严重炎症和疾病的来源。切除胆囊后，胆汁流会改变、减少并变得持续。胆囊作为胆汁的储库，可以浓缩并改变胆汁的成分。

胆石是椭圆形，由胆囊内盐和胆汁中的晶体形成。尽管其形成的机制和原因尚不清楚，但它们是术后黄疸、胆道梗阻、胆汁积聚（胆固醇、胆红蛋白和钙）的主要原因。胆石通过胆道可能引起梗阻、胆绞痛。

当胆石留在胆囊内时，可能会通过直接或间接炎症对胆囊、胆系统及相关结构造成损伤。胆石也出现在几乎所有物种中，尽管病例很少，特别是在牛中。胆汁沉积：胆滞。

胆囊炎是人类的一种常见疾病。它通常与胆石和感染有关。在许多情况下，被认为是胆汁化学刺激的结果，这导致炎症性胆汁发生部分或完全梗阻。长期或反复炎症可导致胆囊壁增厚和功能受损。

胆囊的恶性肿瘤几乎总是与胆石的存在有关。由于它们在进展之前几乎没有症状，而且由于容易侵犯肝脏，因此这些肿瘤在发现时很少通过手术治疗移除。人类良性肿瘤很罕见，尽管两者都含有某些胆汁盐。肠道对胆汁盐的吸收餐后几小时内胆汁的分泌。参见消化系统。[E.A.B.; J.G.]
