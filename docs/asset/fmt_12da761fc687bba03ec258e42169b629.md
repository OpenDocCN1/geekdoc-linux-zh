## case, switch, select — 用于从列表中选择操作的 Shell 内置函数

### 语法

```sh
case
word in [pattern | pattern] actions ;; ...
esac

csh
switch (expression)
    case comparison1:
        actions
        breaksw
    case comparison2:
        actions
        breaksw
    ...
    default:
        endsw

ksh
case word in [pattern | pattern] ) actions ;; ... esac
select identifier [in word ...]; do list ; done
```

## 描述

在 shell 脚本中，你可能根据变量或参数的值执行多种不同的操作。你可以在 Bourne shell 中使用 `case` 语句，在 C shell 中使用 `case` 和 `switch` 语句，或者在 Korn shell 中使用 `case` 和 `select` 语句来实现。

变量的值将与模式进行连续比较，直到找到匹配项。匹配模式随后的命令将立即执行，直到在 Bourne 和 Korn shell 中找到 `;;` 或在 C shell 中找到 `breaksw` 为止。Bourne 和 Korn shell 的最后一个测试 `*` 以及 C shell 的 `default:` 是默认操作。如果没有其他值匹配，shell 将执行默认操作。在许多脚本中，默认操作会显示错误信息并退出 shell。

`case` 语句对于处理函数的参数特别有帮助。

### Bourne Shell

`case` 命令执行与匹配 `word` 的第一个模式相关联的操作。模式的形式与用于文件名生成的形式相同，但斜杠、开头的点或紧跟在斜杠后的点不需要匹配。

## C Shell

C shell 使用 `switch` 语句，其中每个比较都会与指定的表达式进行连续匹配。表达式首先经过命令和文件名的扩展。你可以在 `case` 比较中使用文件元字符 `*` 和 `[...]`，这些字符会进行变量扩展。如果在找到默认项之前没有匹配项，执行将从行首的 `default` 语句之后开始。命令 `breaksw` 将在 `endsw` 之后继续执行。否则，控制将像 C 语言一样落到后续的 `case` 和默认语句中。如果没有匹配项且没有默认执行，执行将在 `endsw` 之后继续。

以下描述了 C shell 的语法。

`case comparison:` 

- `switch` 语句中的待比较表达式。
- `default:` 如果前面的没有任何比较都不匹配表达式，则为默认情况。

## Korn Shell

`case` 命令执行与匹配 `word` 的第一个模式相关联的操作。模式的形式与用于文件名生成的形式相同，但斜杠、开头的点或紧跟在斜杠后的点不需要匹配。

### select

`case` 命令执行与匹配 `word` 的第一个模式相关联的操作。模式的形式与用于文件名生成的形式相同，但斜杠、开头的点或紧跟在斜杠后的点不需要匹配。

## 选项

- `-n` 在每行输出前加上其行号。
- `-b` 对行进行编号，与 `-n` 类似，但跳过空行的行号。
- `-s` 对不存在的文件保持静默。
- `-u` 不对输出进行缓冲。（默认为缓冲。）
- `-v` 显示非打印字符（制表符、换行符和分页符除外）。ASCII 控制字符（八进制 000–037）打印为 `^x`，其中 x 是 100–137 范围内对应的 ASCII 字符（@, A, B, ..., X, Y, Z, [, \], \], ], ^, 和 _）；DEL 字符（八进制 0177）打印为 `^`。其他非打印字符打印为 `^M`，其中 M 是由低位 7 位指定的 ASCII 字符。

你可以将以下选项与 `-v` 选项结合使用。

- `-e` 在每行的末尾（换行符之前）打印一个 `$` 字符
- `-t` 将制表符打印为 `^`，将分页符打印为 `^L`。

如果你没有指定 `-v` 选项，将忽略 `-e` 和 `-t` 选项。

### 操作数

- `file` 输入文件的路径名。如果未指定文件，则使用标准输入。如果文件为 `-`，则在序列的该点从标准输入读取。`cat` 在此类引用时不会关闭并重新打开标准输入，但接受多次出现的横杠（`--`）作为文件。

## 用法

参见 `largefile(5)` 以获取 `cat` 在遇到大于或等于 2 Gbytes（**2**31** 字节）的文件时的行为描述。
