## 第二章 简介

`Linux 2.2.0` 版本于 1999 年 1 月 25 日发布：迈向世界统治……

也许你是 Linux 的新手，希望找到一份关于你可能需要定期配置和管理任务的总结。如果这听起来像你的情况，那么本文档正是你一直在寻找的内容！

### 2.1. 范围

本文档将尝试总结安装和配置，以及为了保持 Linux 服务器或桌面系统运行而应遵循的日常管理和维护程序。它并不是旨在对 Unix 操作进行全面概述，因为已有许多优秀的书籍以及在线文档，在需要更详细信息时可以参考。

通常，你的 Linux 系统只需最少的用户维护即可运行。常规任务（如系统日志轮转和删除）是自动化的。因此，在大多数情况下，即使用户干预极少，Linux 也能良好运行。但在有自定义需求或系统故障的情况下，本文档可能会有用。

我目前在家和工作中都使用 Linux。它对我很好，已经为我的雇主提供了稳定的互联网和文件/打印服务。

### 2.2. 选择 Linux 发行版

有多种 Linux 发行版可供选择。每个发行版提供相同的 Linux 内核和系统工具，但在安装方法和捆绑应用程序上有所不同。每个发行版都有自己的优缺点，因此在决定之前，花点时间研究特定发行版提供哪些功能是明智的。

以下是一些你可以访问的网站列表，它们将描述特定的 Linux 发行版，并提供有关如何下载或购买它的信息：

- http://www.redhat.com/

Red Hat 发行版由商业供应商 Red Hat Software 开发，是最流行的发行版之一。由于可以选择图形界面（GUI）和文本界面安装程序，`Red Hat 6.1` 可能是最容易安装的 Linux 发行版。它通过 `RPM` 工具提供了方便的升级和包管理，并包含了 GNU 网络对象模型环境（`GNOME`）和 `K 桌面环境`（`KDE`），两者都是 `X Window` 系统流行的 GUI 窗口管理器。该发行版适用于 Intel、Alpha 和 Sparc 平台。

- http://www.debian.org/

Debian 发行版由名为 `Debian 项目` 的非营利组织开发，是开源社区的宠儿。它同样通过 `dpkg` 工具提供了方便的升级和包管理。该发行版适用于 Intel、Alpha、Sparc 和 Motorola（Macintosh, Amiga, Atari）平台。

- http://www.suse.com/

S.u.S.E 发行版由商业供应商 S.u.S.E. 开发，是另一个流行的发行版，也是欧洲领先的发行版。它包含了 `K 桌面环境`（`KDE`），并通过 `YAST` 工具提供了方便的升级和包管理。该发行版适用于 Intel 和 Alpha 平台。

- http://www.caldera.com/

OpenLinux 发行版由商业供应商 Caldera 开发，面向企业用户。随着新的 2.2 版本发布，Caldera 以其似乎最易安装的特性提高了门槛。此外，它还配备了 `K 桌面环境`（`KDE`）。该发行版适用于 Intel 平台。

- http://www.mandrake.com/

Mandrake 发行版由商业供应商 MandrakeSoft 开发，将 Red Hat（你的选择）与额外的软件集成。

- http://www.slackware.com/

Slackware 发行版由 Walnut Creek Software 的 Patrick Volkerding 开发，是现代发行版的祖祖。提供相当简单的安装，但升级和包管理较差。该发行版适用于 Intel 平台。

## 第3章 Linux 概述

欢迎来到 Linux！

### 3.1. 什么是 Linux？

Linux 是一种真正的 32 位操作系统，运行在多种不同的平台上，包括 Intel、Sparc、Alpha 和 Power-PC（在其中某些平台上，如 Alpha，它实际上是 64 位的）。虽然也有其他端口可用，但我没有那方面的经验。

Linux 最早于 20 世纪 90 年代初由一位芬兰的小学生林纳斯·托瓦尔斯（Linus Torvalds）开发。当时 Linux 有一个“尖端”的 386 minix，决定编写一个基于 286 的 Minix 系统（一种主要用于操作系统课程的小型类 Unix 实现）的替代品，以利用当时新芯片上提供的额外指令集，并开始编写一个简单的裸机内核。

最终，他在 USENET 组 `comp.os.minix` 中宣布了他的小项目，邀请感兴趣的人士查看并为该项目做出贡献。结果是惊人的！

Linux 有趣的一点在于，它是完全免费的！Linux 决定采用自由软件基金会（Free Software Foundation）的 `GNU GPL` 许可证，这意味着代码受版权保护——但这种保护意味着它必须始终对他人可用。

免费意味着——你可以免费获取它，免费使用它，你甚至可以自由出售它以获利（这听起来并不奇怪；包括红帽（Red Hat）在内的几家机构将标准 Linux 内核、一组 GNU 工具打包，并附上他们自己“口味”的包含应用程序，将其作为发行版出售。一些常见且流行的发行版有 Slackware、Red Hat、SuSE 和 Debian！很棒的一点是你可以访问源代码，这意味着你可以根据自己的需求对操作系统进行定制，而不是迎合大多数商业厂商“目标市场”的需求。

Linux 可以且应该被视为 Unix 的完整实现。然而，它不能被称为“Unix”；这并不是因为不兼容或功能性匮乏，而是因为“Unix”一词是 AT&T 的注册商标，该词的使用仅在许可协议下才允许。

Linux 与任何其他操作系统解决方案一样，拥有同样的支持、可靠性和可行性（嗯，在我看来，它甚至比它们要好得多！）。然而，由于其起源、背后的哲学以及缺乏数百万美元的营销活动，关于它流传着很多神话。人们对这个精彩的操作系统还有很多需要学习！

### 3.2. 打破神话

我已经使用 Linux 几年了，我认为我对这个操作系统以及它能做和不能做什么有一定的了解。作为一名热衷的 USENET 读者，我关注最新的进展，当然还有各种必然出现的“口战”（那些该死的交叉发帖倡导者！:-) ））。我见过的神话比很多人认为的要多（这些神话通常被称为 FUD——“恐惧、不确定性、怀疑”，这似乎是商业技术供应商用来恐吓其市场远离竞争技术的一种常用策略）。所以，让我来试着列举几个最常见的神话，并尝试打破它们 :-)

- Linux 是免费软件（freeware），因此它是一个玩具。

某些人似乎有这样观念：由于某件软件是由没有营利动机的志愿者编写的，其结果显然必然逊于商业级产品。

这在过去可能是事实（我的意思是，在 DOS 和早期 Windows 世界中，有很多免费软件完全是垃圾），但在最近这绝对不是事实。

互联网的力量让全球最聪明的人聚集在一起成为可能，让他们对他们感兴趣的项目进行协作。参与开发 Linux 或成千上万 GNU 工具和应用程序包的人来自不同的背景，他们所有人对于想要贡献都有不同的个人理由。

有些人是硬核黑客，出于对编码的热爱而开发；另一些人有某些需求（例如，工作局域网的网络流量监控器）并决定自己编写；还有一些人是学者和计算机科学家，他们使用 Linux 进行研究。

与开发并销售包但排除源代码的商业产品不同，Linux 中使用的用户代码会受到任何有兴趣和能力的人审查、调试和改进。这种同行评审的行为是 Linux 能够提供如此高可靠性和高性能的原因之一。
