# 内置命令总结

- `alias`: 管理别名。
- `bg`: 在后台启动挂起的任务。
- `bind`: 管理键盘映射。
- `builtin`: 运行内置 shell 命令。
- `cd`: 目录。
- `command`: 运行 Linux 命令。
- `declare`: 声明变量。
- `dirs`: 显示目录栈。
- `disown`: 停止监控后台作业。
- `echo`: 输出标准输出。
- `enable`: 关闭内置 shell 命令。
- `eval`: 在执行 shell 替换/扩展后运行命令。
- `exec`: 离开并切换到一个程序。
- `exit`: 退出 Bash 并返回状态码。
- `export`: 管理导出变量。
- `false`: 返回非零状态码。
- `fc`: 查找并编辑命令历史。
- `fg`: 在前台运行挂起作业。
- `function`: 声明函数。
- `hash`: 管理 Bash 命令表。
- `history`: 管理命令历史。
- `jobs`: 管理后台作业。
- `let`: 表达式。
- `local`: 声明局部函数变量。
- `logout`: 交互模式下退出 shell。
- `pop`: 丢弃 cd 目录栈项。

# 录录 B 内置命令总结

- `printf`: 格式输出到标准输出。
- `pushd`: 添加目录栈项。
- `wpd`: 显示当前目录路径。
- `read`: 从标准输入或文件读取。
- `readonly`: 管理只读变量。
- `return`: 从函数返回。
- `set`: 开启/关闭 Bash 选项，或分配新参数值。
- `shift`: 选项。
- `shop`: 显示或更改 shell 选项。
- `source`: 运行另一个脚本并返回。
- `suspend`: 脚本睡眠。
- `test`: 评估表达式。
- `time`: 显示命令或 shell 的累计执行统计。
- `trap`: 管理信号处理程序或捕获信号。
- `true`: 返回状态码（即 0）。
- `type`: 确定命令类型（是内置的还是外部命令）。
- `typeset`: （过时）声明变量。
- `ulimit`: 管理用户资源。
- `umask`: 管理默认的文件创建权限。
- `unialias`: 丢弃别名。
- `unset`: 丢弃变量。
