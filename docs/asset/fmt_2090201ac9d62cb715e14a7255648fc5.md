## 14.4 通用 APIC 代码

无论是电平还是边沿触发，操作 IO APIC 寄存都是标准程序。本节将考虑为此提供的函数。IO APIC 上有两个主要操作：掩码和取消掩码 `irq`。有一个函数用于对 APIC 将特定 `irq` 与指定的 CPU 关联。最后，有一组工作函数实际读写 APIC 中的寄存器。
