
# Linux 词典

LIRC 是一个软件包，允许你解码和发送任何（但不是所有）使用遥控器的红外信号。早期版本的 home–brew 连接到串口和并行端口。当前版本的 LIRC 还支持多种其他硬件。LIRC 的大部分是解码设备驱动程序接收的 IR 信号并在套接字上提供信息的守护进程。它还会接受由名为 `decode` 的第二个守护进程发送的 IR 信号命令，并将解码后的 IR 信号翻译为动作。例如，你可以配置 X 使用你的遥控器作为远程设备。用户空间应用程序允许你用遥控器控制电脑。你只需按一下按钮即可发送 X 事件、启动程序等许多功能。可能的应用显而易见：红外模式、调谐器或 CD-ROM 的遥控控制、遥控关机、用电脑为你的 VCR 和卫星调谐器编程等。MP 播放器也非常流行。来自 LIRC http://www.ldp.org/LDP/linux-Dictionary/html/index.html

- `list`
一组由一个或多个管道组成的序列，由运算符 `;`、`&` 或 `|` 隔开，并以 `;`、`&`、`.` 或 `..` 结尾。来自 Linux Guide @FirstLinux
http://www.tld.org/LDP/Linux-Dictionary/index.html

- `listres`
在小部件中列出资源。来自 Whatis
http://www.tld.org/LDP/Linux-Dictionary/index.html

- `lists-archives`
邮件列表网络归档，为历史帖子邮件列表创建一个网站，并采用 Debian 项目使用的排序样式（http://www.debian.org/Lists-Archives）。它的工作原理是让 `procmail` 接收者订阅该列表。如果也安装了 `glimpse`，则可以进行全文搜索（注：Glimpse 虽不在归档中，但搜索脚本仍然存在）。此包也用作 `mailman` (www.list.org) 的后端存档。为了达到完整效果，请配置 `weserver`：`Alias/Lists-Archives/var/lib/lists-archives` 来自 Debian 3.0r APT
http://www.tld.org/LDP/Linux-Dictionary/index.html

- `LISTSERV`
提供一个交换信息和想法的论坛。Linux 下一种流行的邮件服务器是 Majordomo。来自 Linux Guide @FirstLinuxnhttp://www.tld.org/LDP/Linux-Dictionary/index.html

- `Listserv`
此类中最常见的类型，“Listserv”是 L-Soft international, Inc. 的注册商标。Listserv 起源于 BITNET，但现在在互联网上很常见。参见：BITNET, Internet (大写 1), Maillist 来自 Maitisse
http://www.tld.org/LDP/Linux-Dictionary/index.html

- `Listserver`
列表服务器（也称为邮件列表或电子讨论列表）将简单的通信扩展为使用户能够向大量观众发送一条消息。它们通常是半自动（有时是全自动）电子邮件分发系统，自 80 年代初以及纽约州纽约州立大学启动 BITNET 以来一直存在。来自 Faculty-Education http://www.tld.org/LDP/Linux-Dictionary/index.html
