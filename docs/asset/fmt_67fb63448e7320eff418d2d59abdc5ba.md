## sort（排序）

`sort` 命令用于按照指定的键按指定的顺序对一个或多个文件进行排序。当使用多个文件时，它也可以用于合并文件，`sort` 会根据规范在之前连接这些文件。

以下是可与 `sort` 命令配合的标志列表：

- `-k` 指定排序的键。键的规范包括起始字段和列位置以及结束字段和列。
- `-A` 指定按照 ASCII 排序顺序进行排序。
- `-c` 检查指定的文件是否按照指定的键和顺序已排序。
- `-d` 按字典序排序。
- `-f` 在排序前将所有字母转换为大写。
- `-i` 比较时忽略不可打印字符。
- `-m` 合并预先排序通过的输入文件。
- `-n` 按数值值排序。
- `-o` 将输出重定向到指定的文件而不是标准输出。
- `-r` 按指定顺序的反向顺序排序输出。
- `-u` 对于排序结果相同的行，在输出中仅保留一行。

根据一个或多个命令指定的规则处理行。

以下是可以在 `sed` 命令中使用的一些标志列表：

- `-e command`：使用指定的 `sed` 命令编辑文件。
- `-f filename`：使用文件名作为编辑脚本来编辑文件。
- `-n`：抑制 `sed` 的输出。

`sed` 命令在执行编辑时使用两个不同的区域：

- 模式区域（pattern area）：用于存放选定的行进行编辑。
- 保持区域（hold area）：用于临时存放行。

`sed` 子命令可以影响所有行，也可以仅影响指定的行。

以下是可以在 `sed` 命令中使用的一些子命令列表：

- `-` `#`：指定注释的开始。`#` 之后的行中的所有内容都被视为注释。
- `:label`：指定脚本中使用的可寻标签。
- `[/pattern]=`：输出包含指定模式的每行的行号。
- `[address]\atext`：在指定地址的行后追加文本字符串。
- `[address1][address2]\text`：用文本字符串替换地址范围内的行。
- `[address1][address2]d`：删除指定地址范围内的行。
- `[address1]i\text`：在每个指定的行之前插入文本。
- `[address1][address2]p`：打印指定地址范围内的行。
- `[address1][address2]n`：指定显示当前行，并将下一行设置为当前行。
- `[address1][address2]N`：指定将当前行通过换行符分隔追加到模式区域的内容之后。
- `[address]q`：遇到指定的地址时退出。
- `[address1][address2]s/old pattern/new pattern/[flag]`：在指定范围内用新模式替换旧模式。替换行为可以通过指定的标志进行修改。
- `[address1][address2]w file`：将指定范围的内容写入指定文件。
- `- [address1],[address2]y old character list/new character list/`：用新字符列表中的对应字符修改旧字符列表中的字符。

上述子命令是 `sed` 命令影响**模式区域**的命令。现在，让我们来看一些影响**保持区域**的子命令：

- `- [address1],[address2]g`：将保持区域的内容复制到模式区域，使其成为模式区域的新内容。
- `- [address1],[address2]G`：在指定地址之后，将保持区域的内容追加到模式区域之后。
- `- [address1],[address2]h`：将模式区域的内容复制到保持区域，使其成为保持区域的新内容。
- `- [address1],[address2]H`：在指定地址之后，将模式区域的内容追加到保持区域之后。
- `- [address1],[address2]x`：交换模式区域和保持区域的内容。

### 示例

在简单形式下，你可以指定几个字符作为正则表达式。如果你想使用以下命令在 `file1` 中找到 `really` 字符串：

```
grep really file1
This is really a test
Believe it, this is really a test
```

如果你想在行尾找到字符串 `THIS`，请在命令的正则表达式开头使用 `^`（脱字符符号），并在正则表达式的末尾使用 `$`（美元符号）：

```
grep ^THIS file1
THIS IS A TEST
```

如果你想同时找到 `believe` 和 `Believe`，请使用以下命令：

```
grep [Bb]believe file1
Believe it, this is really a test
```

在示例中，`[Bb]` 匹配 B 或 b。如果你想找到 b 以外的字符，请使用以下命令：

```
grep [^b] file1
THIS IS A TEST
```
