
# 汇编语言
程序的每个组件都代表程序员理解的操作，使用本应易于编程的名称。通过使用符号名称而不是二进制数，编程指令可以变得更具可读性。相对简单的汇编器可以将这种符号表示翻译成机器语言。

# 高级语言
第一批高级语言开发于 20 世纪 50 年代后期。例如，计算 `A = B - C` 并结果存储在内存位置 `D` 中，我们只需要在机器语言中写 `D = B - C`。在这些程序中，计算机必须执行的序列数量减少了。

`FORTRAN` 是在数学符号之后开发的。在数学中，用于方程部分的符号与表达式具有相同的值。然而在 `FORTRAN` 和其他语言中，符号代表一种操作。计算机在遇到此操作符时执行的动作是：

> 等号左侧命名的变量与右侧表达式的值相同。在某些语言中，语句将写为 `-D = D` 以暗示移动或变化……

`FORTRAN` 的编译器将语句翻译成机器语言序列。在这种情况下，我们不在乎编译器用于指令或数据的地址，只要我们使用了名称 `A`、`B`、`C` 以及我们想要的数据值即可。

编程语言各异。每种编程语言都有三个基本组件：(1) 用于包含程序用信息的数据存储机制；(2) 提供数据转换的数据操作；(3) 从头到尾执行指令的控制结构。

# 数据声明
数据可以是常量也可以是变量。常量的值始终为 `42`，不能有其他值。相反，我们可以定义带有符号名称的变量。变量的声明告知编译器应该有一个像变量 `A`（示例中）这样的内存位置，其机器地址为 `0312`。程序员可以选择程序执行时使用哪个内存位置。

每个数据对象都有特定的类型。数据对象是对象类型集合中的一个。类型可以是标量或聚合的。声明为标量的对象在组件中是不被理解的，而聚合类型定义了可以执行的操作。每个类型都有其自己的操作。程序员将选择程序执行时使用哪个内存位置。

# 数据操作
数据操作提供设置每个已声明数据的值。在这种情况下，通过三步过程完成：一组用于转换每个数据值的操作符、执行操作，以及用于更改某些数据值的赋值。

对于每种数据类型，语言定义了该类型的操作。对于算术类型，有加、减、乘、除操作。其他操作可能包括（幂、调用函数）或余数（除以另一个整数）。通常，用于比较（等于、大于或小于）的操作产生真或假的值。操作符的数量没有限制。编程语言赋予了程序员选择的自由。

# 1784 射影几何
如果一个数列的第一项为 `$a$`，公比为 `$r$`，则该数列的各项由等式给出。排除 `$r = 1$` 的情况（所有项均相同），`$n$` 项列表之和 `$S_n$` 由公式 `(4)` 给出：

`$x_1 = a, x_2 = ar, \dots, x_n = ar^{n-1}$` `(3)`

`$S_n = \frac{1-r^n}{1-r}$` `(4)`

`$n$` 项算术平均值 `$A$` 和几何平均值 `$G$` 由公式 `(5)` 和 `(6)` 定义：

`$A = \frac{x_1 + x_2 + \dots + x_n}{n}$` `(5)`

`$G = \sqrt[n]{x_1 \cdot x_2 \cdot \dots \cdot x_n}$` `(6)`

序列的倒数构成一个调和数列。`$n$` 项之和没有简洁的表达式。如果 `$x_1, x_2, x_3$` 构成调和数列，则公式 `(7)` 称为它们的调和平均数。`[L.B.]`

## 1786 螺旋桨（水上船只）
飞行方向等于所产生的推力。这些力作用于空气，产生一个与飞行方向相反的速度分量。根据动量理论，这种速度使推动螺旋桨的空气质量加速度等于推力。

螺旋桨的设计必须能够承受巨大的离心力。叶片还必须承受由振动力（例如不均匀流场引起）产生的推力。为了承受旋转产生的高应力，叶片采用了多种材料，包括木材、铝、钢和塑料复合材料。最常用的材料是实心铝；然而，由于具有极轻重量和高强度特性，复合材料叶片结构被用于船舶安装。

对于小型低功率飞机，使用的是非常简单的固定螺距单叶螺旋桨。这些螺旋桨的速度很大程度上取决于功率输入和叶片速度。由于这种螺旋桨采用固定桨角，它仅在一种速度下接近峰效率。考虑到简单固定螺距螺旋桨的局限性，使用了可变桨角的配置。这些叶片固定在轮毂中，并绕螺旋桨转子旋转。在正常工作范围内，桨角从起飞所需的低角到巡航速度所需的高角变化。参见《航空工程》，第14卷，第1期，1938年。

螺旋桨（水上船只）船舶推进动力将发动机能量转换为推进力或推力，通过移动尾部加速流产生的动量来克服船舶的水的阻力。自1860年以来，螺旋一直是船舶运输中唯一使用的类型，船舶发动机的演进需要更高的转子速度。

> “Great in Light”号的尾视图，显示了24节速度实验中的螺旋桨；RO/Vs 船只指向螺旋桨颈的前向应用。参见 Nav. Arch. Mar. 86, 264-276, 1978

螺旋桨的优点包括重量轻、应用灵活和船舶运动相对简单。螺旋桨系统的基础理论适用于所有形式的海船。在目前的形式下，一个螺旋桨由一个带有两个叶片的流线型轮毂组成，叶片安装在轮毂上。叶片可以是实心的或空的，可拆卸或移动的。螺旋桨具有螺纹的特征；它绕船舶轴线旋转，并在轮廓上遵循螺纹路径。

螺旋桨叶片被分为若干截面，具有楔形前缘、钝后缘且不产生空化。超空化螺旋桨在水流在流体介质中形成泡沫时运行。超空化螺旋桨通过来自水面的空气或螺旋桨提供的非水气体进行覆盖。
