## 加速键与记忆符 (Accelerators and Mnemonics)

菜单项的加速键（accelerator）是触发该特定项回调函数的按键。例如，要打开文件，可以使用 Ctrl+O。该加速键的资源可以在资源文件中如下设置：

`\*Open\*accelerator: Ctrl<Key>O`

相应的菜单项应显示为“Open Ctrl+O”，以便使用户知道此快捷键。你也可以通过 `.Xresources` 文件中的以下命令设置此资源：

`\*Open\*acceleratorText: "Ctrl+O"`

使用 `.Xresource` 文件是设置这些资源的首选方式。

记忆符（Mnemonics）是让用户在不使用鼠标的情况下选择菜单项的简写。例如，你可以使用 <meta>F 来调用文件菜单。这些通常也设置在 `.Xresources` 文件中。文件菜单使用 <meta>F 键的语法如下：

`\*File\*mnemonic: F`

## 对话框 (Dialog Boxes)

对话框向用户传达有关某些信息，并接收有限响应中的一种。例如，对话框可以显示“继续打印”并带有三个按钮——确定（OK）、取消（Cancel）和帮助（Help）。用户随后选择三个按钮之一。

典型的对话框显示一个图标、消息字符串和（通常）三个按钮。Motif 提供了预定义的对话框，但用户也可以创建自定义的。典型的对话框显示一个图标、消息字符串和（通常）三个按钮。Motif 为以下情况提供了预定义的对话框：

- 错误（Errors）、-、疑问（question）。

`Expose`

当一个被其他窗口覆盖的窗口带到栈顶或部分暴露时，服务器会生成一个 `Expose` 事件。

该事件类型的结构如下：

```c
typedef struct {
    int type; /* 事件类型 */
    unsigned long serial; /* 服务器处理的最后一个请求数 */
    Bool send_event; /* 如果此来自 SendEvent 请求则为 true */
    
    Display *display; /* 读取事件的显示器 */
    Window window;
    int x, y;
    int width, height;
    int count; /* 如果非零，表示至少还有多少个 */
} XExposeEvent;
```

注意前五个字段是如何在此事件与 `XAnyEvent` 共享的。`Expose` 事件保证按顺序出现。应用程序可能会从同一种条件获取多个 `Expose` 事件。`count` 字段记录了当应用程序接收到此事件时，队列中剩余的 `Expose` 事件数量。因此，是否等待重绘直到收到最后一个 `Expose` 事件（`count == 0`）由应用程序来决定。

### 指针事件

指针事件由鼠标按钮的按下或释放或任何鼠标移动产生。这种类型的事件被称为 `XButtonEvent`。请记住，最左侧的按钮是 `Button1`，但它可以被更改（参见第 1 章中的“左手用户”节）。按钮按下和释放返回的结构如下：

```c
typedef struct {
    int type; /* 事件类型 */
    unsigned long serial; /* 服务器处理的最后一个请求数 */
    Bool send_event; /* 如果此来自 SendEvent 请求则为 true */
    
    Display *display; /* 读取事件的显示器 */
    Window window; /* 相对于报告的“事件”窗口 */
    Window root; /* 事件发生的根窗口 */
    Window subwindow; /* 子窗口 */
    Time time; /* 毫秒 */
    int x, y; /* 事件窗口中的指针 x, y 坐标 */
    int x_root, y_root; /* 相对于根的坐标 */
    unsigned int state; /* 键或按钮掩码 */
    unsigned int button; /* 细节 */
    Bool same_screen; /* 同一屏幕标志 */
} XButtonEvent;
```

`typedef XButtonEvent XButtonPressedEvent;`

`typedef XButtonEvent XButtonReleasedEvent;`

移动事件被称为 `XMotionEvent`，其 `type` 字段被设置为 `MotionNotify`。

```c
typedef struct {
    int type; /* MotionNotify */
    unsigned long serial; /* 服务器处理的最后一个请求数 */
    Bool send_event; /* 如果此来自 SendEvent 请求则为 true */
    
    Display *display; /* 读取事件的显示器 */
    Window window; /* 相对于报告的“事件”窗口 */
    Window root; /* 事件发生的根窗口 */
    Window subwindow; /* 子窗口 */
    Time time; /* 毫秒 */
    int x, y; /* 事件窗口中的指针 x, y 坐标 */
    int x_root, y_root; /* 相对于根的坐标 */
    unsigned int state; /* 键或按钮掩码 */
    char is_hint; /* 细节 */
    Bool same_screen; /* 同一屏幕标志 */
} XMotionEvent;
```

`typedef XMotionEvent XPointerMovedEvent;`

### 键盘事件

当用户按下或释放按键时，会产生*键盘事件*。`KeyPress` 和 `KeyRelease` 两种类型的事件都会在 `XKeyEvent` 结构中返回。
