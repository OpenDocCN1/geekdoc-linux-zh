
燕麦是一种在世界上大多数温带地区国家种植以获取谷物和秸秆的农作物。在美国中西部的主要燕麦种植州（爱荷华州、北达科他州、南达科他州、明尼苏达州和威斯康星州），该作物主要作为谷物收获，而在南部各州（得克萨斯州、俄克拉荷马州和佐治亚州）则用作牧场或牧场与谷物的混合用途。每年燕麦谷物产量的90%左右用作动物饲料，10%左右加工成人类食品，例如燕麦片和其他谷物产品。一般而言，燕麦是冷季作物，需要潮湿的气候。只要水分和肥力营养充足，它在轻土和重土上都能生长良好。参见**动物饲料**；**谷物**。

燕麦属（*Avena*）的15个物种根据染色体数目分为三组：14、28或42。在42染色体的栽培物种中，不同品种在所有植物性状上存在广泛变异。燕麦属于禾本科（Graminae），因此燕麦植株在土壤表面形成冠层，其须根系由此深入土壤。茎通常生长2-5英尺（0.6-1.5米）高，并以称为圆锥花序的颖花结尾。每个圆锥花序通常在其众多分枝上结出10-75个小穗。小穗被两片纸质的外稃包裹，包含两到三朵花，每朵花有一个子房、两个柱头和三个花药，被内稃和外稃包裹（见图）。在大多数品种中，脱粒后内稃和外稃仍附着在燕麦籽粒上。用于确定燕麦市场等级的一个性状是外稃的颜色，其可能为白色、黄色、灰色、棕色、红色或黑色。区分野生与栽培燕麦的主要性状是籽粒脱落：在栽培物种中，籽粒附着是持久的，只有通过脱粒才能将其从圆锥花序上分离。参见**莎草科**；**花**；**禾本科作物**；**花序**。

由美国农业部维护的全球燕麦收藏库包含超过14,000个42染色体类型的品系。这些品系代表了来自野生物种和育种站生产品种的材料。该收藏库代表了可用于品种改良的巨大遗传类型范围。 [K.J.F]

燕麦的粉碎过程比小麦简单，且与大米或大麦粉碎作业有许多相似之处，因为籽粒的分选有限。燕麦籽粒表面覆盖着一层粗糙且紧密附着的颖壳，在生产原料或食品前必须去除。运抵磨坊的燕麦被称为青燕麦，必须清理以去除异种籽粒和杂质。干净、完好的燕麦在脱壳前需缓慢加热。青燕麦含有活性脂解酶（脂肪酶），会催化甘油三酯的水解并产生游离脂肪酸。加热、干燥或烘烤程序使脂肪酶失活，便于脱壳，并赋予燕麦产品独特的烤香味。烘烤后的燕麦在脱壳前需风冷和分级筛选。脱壳机的主要产品是整粒燕麦（燕麦米）和纤维颖壳，可通过气吸轻松分离。低密度燕麦颖壳含有特别高水平的纤维和戊聚糖，适合作为通过高温酸水解和脱水工业生产呋喃和/或细胞分裂素化学品的原料。完整的、干净的燕麦米在商业食品市场上并不常见。选定的大尺寸燕麦米非常适合膨化成即食谷物。

燕麦切分和小麦片工序提供了更广泛的燕麦米利用形式，即燕麦片。燕麦粉是通过进一步研磨或锤磨整粒燕麦米或燕麦片产品获得的。这种高蛋白面粉常用于即食谷物和许多预制婴儿食品的配方中。有人建议，将燕麦粉与其他谷物混合成的高蛋白复合面粉，因其具有较长的保质期，适合用于全球喂养计划。参见**食品制造**。 [M.A.U.]

# 肥胖

体内多余脂肪的存在。这种状况的高发病率、对身心健康的严重后果以及治疗难度使肥胖预防成为主要公共卫生优先事项。

肥胖通常通过相对于身高的体重来定义，因为身高和体重都很容易测量。肥胖被认为始于高于理想体重20-30%的体重-身高比，该理想体重取自寿险研究中与最长寿命相关的体重范围的中点。在人口调查中，肥胖被定义为达到或超过体重指数（BMI）第85百分位数的体重，BMI是一个与体脂含量良好相关的体重-身高指数。参见**体重：组织**。

肥胖的患病率随年龄增长而增加，女性高于男性，且在贫困和少数族裔群体中最高。肥胖增加了高胆固醇、高血压和糖尿病的可能性，从而增加了这些状况作为风险因素的疾病——冠心病、中风和肾脏疾病——的风险。它还增加了胆囊疾病和乳腺癌、子宫癌的风险。因此，肥胖会增加总体死亡率，且增加程度与超重程度和持续时间成正比。在最早年龄成为肥胖的个体面临最高的过早死亡风险。将多余脂肪分布在上半身而非下半身也可能增加风险。

大多数肥胖病例的原因尚不明确。在最简单的层面上，肥胖是由能量（卡路里）摄入超过消耗引起的，但这无法解释为什么有些人可以随意饮食而不发胖，而另一些人尽管持续节食仍保持超重状态。对遗传性肥胖动物和脑下垂体下部（下丘脑）受损个体的研究表明，个体可能会围绕“设定点”平衡体重，该设定点通过代谢率随卡路里摄入变化而维持——无需意识控制。不同人口群体中肥胖患病率的差异提示该状况具有遗传基础。体重调节机制的复杂性提示肥胖并非由单一原因引起，而是像其他慢性疾病一样，起源是多因素的。可能影响设定点的具体遗传差异包括神经解剖特征、已知影响食物摄入和利用率、能量代谢和能量消耗的神经学和生化因素。参见**内分泌机制**；**能量代谢**；**代谢障碍**。

由于肥胖的原因尚未完全理解，制定有效的治疗策略很困难。研究表明，结合饮食和运动的计划比单独使用其中任何一种计划能帮助肥胖者减更多体重并更长时间维持减重效果。参见**食物**；**营养**。 [M.N.]

# 面向对象编程

一种侧重于数据项而非过程的计算机编程方法。传统的软件开发模型假设自顶向下的方法。首先产生系统的功能描述，然后随着实现运行而被细化。根据数据结构（和文件结构）支持功能模型的优劣程度提出并评估它们。

面向对象方法首先关注被操作的数据项（实体、对象）。重点在于将数据项表征为能够为自己执行操作的主动实体，然后描述系统行为如何通过数据项的相互作用来实现。

面向对象方法的本质是使用抽象数据类型、多态性以及通过继承的重用。抽象数据类型定义了上述的主动数据项。编程语言中的传统数据类型仅描述数据项的结构。抽象数据类型还描述了可以请求数据项执行的操作。将操作与数据项关联的能力使它们变得主动。抽象数据类型在不揭示操作实现细节的情况下提供操作，防止程序员依赖于实现细节。操作的定义被视为抽象数据类型实现者与使用者之间的契约。只要操作履行其契约，实现者可以以适当的方式自由执行操作。面向对象编程语言将抽象数据类型称为类。

面向对象方法中的多态性指的是程序员能够通过对每个对象调用相同操作，以统一方式处理许多不同类型对象的能力。由于对象是抽象数据类型的实例，只要满足共同契约中的协议，它们可以以不同方式实现操作。

在面向对象编程中，只需说明新类型与某个现有类型的不同之处，即可创建新的抽象数据类型（类）。未描述为不同的特征将由两种类型共享，构成通过继承的重用。继承很有用，因为它取代了为了更改单一特征而复制整个抽象数据类型的做法。

在面向对象方法中，类用于定义抽象数据类型，类型的操作被称为方法。类的实例称为对象实例或简称为对象。要在对象实例上调用操作，程序员向对象发送消息。 [J.S.C.]

# 双壳纲中的无瓣纲（Obolella）

Obolella是一个小型的已灭绝无瓣纲腕足动物目，生存于早奥陶世到中奥陶世。壳体由方解石组成，轮廓通常为拉长的椭圆形且双凸。腹壳（带柄壳）在后部具有清晰定义的平坦台阶（伪间室）。柄孔位置在目中异常多变。它可以位于两壳之间、腹壳（带柄壳）的尖端处或腹壳尖端的前方。该群体的成员假定为表生且固着生活。参见**腕足动物**；**无瓣纲**。 [M.W.F.]

# 强迫症

一种焦虑障碍（通常称为OCD），其特征是反复、持续、不想要且令人不快的思维（强迫观念）或重复的、有目的性的仪式性行为，个人感到有驱动力去执行（强迫行为）。该障碍的一个主要特征是对强迫观念和行为的非理性或过度性的意识，以及无法控制它们的能力。

典型的强迫行为包括不可抗拒的清洗（特别是洗手）或清洁冲动、检查门窗是否锁好、反复回到电器旁确保其关闭、触摸、重复、计数、排列或保存。典型的强迫观念包括对污垢的过度担忧以及污染、害怕对暴力或攻击性冲动做出反应、对他人或他人的过度责任感、异常的宗教思想（亵渎性的和性意味的）以及对排列或对称的过度担忧。强迫观念可能伴随强迫行为出现，或者强迫行为可能单独出现。

强迫症与在原本健康的人身上出现的较轻形式的强迫观念或强迫行为的区别在于，对于患者而言，强迫观念或强迫行为会导致明显的痛苦，消耗大量时间，并显著干扰个人的正常日常作息、职业功能、通常的社交活动以及与他人的人际关系。

约三分之一的病例在青春期发病。另外三分之一在成年早期出现症状，最后一个三分之一则在更晚的年龄才开始出现症状。如果未得到适当治疗，该疾病往往是慢性的，症状会时轻时重。

强迫症通常对传统心理治疗具有抵抗力，这种治疗曾试图将这种状况追溯到早期童年的冲突。一种有效的心理治疗形式是行为疗法，在这种疗法中，患者逐渐暴露于他们恐惧或诱发症状的情境中，但被阻止执行伴随的强迫行为。这种方法侧重于治疗症状，而不是试图理解其起源，对于治疗仪式化行为（强迫行为）似乎比对于弥漫性思维（强迫观念）更有效。强迫症对用于治疗焦虑、抑郁和精神病的多数药物也表现出抗性。然而，它常常通过影响大脑5-羟色胺能系统的药物得到缓解，例如氯米帕明、氟伏沙明和氟西汀。

强迫症患者对5-羟色胺能药物的特定反应、他们对5-羟色胺能系统激活的高度敏感性，以及在那些患者中发现的独特的功能解剖学差异，提示该疾病可能有生物学病因。在这方面，强迫症代表了焦虑障碍研究从心理学方法向神经生物学方法的转变。参见：焦虑障碍；神经系统疾病；5-羟色胺。[JLZ]
