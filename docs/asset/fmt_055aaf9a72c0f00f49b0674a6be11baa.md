
## 2.11 MS Windows 分区占据了我的硬盘。我可以在不重新安装的情况下收缩/分割吗？

可能。可能有一个链接的 `FIPS`。许多 `BIOS` 有一个限制，即分区不能超出第一块硬盘的第 `1024` 磁道区。为了避免这一限制，请设置第一个（可启动的）分区，使其在第 `1023` 磁道之前结束（这使得该分区的大小约为 `512 MB`，对于 `/root` 分区来说足够了）。一旦安装了 `Linux`，`BIOS` 的限制就不再重要了，因为 `Linux` 处理硬件管理，你可以将分区扩展到磁道 `1023` 之外。

在安装和使用 `Linux` 时，你的驱动器显示为具有以下名称的设备：
- `hda`：第一个 IDE 硬盘（代表“hard a”，即第一个 IDE 接口上的主设备）
- `hdb`：第二个 IDE 硬盘（第一个 IDE 接口上的从设备）
- `hdc`：第三个 IDE 硬盘（即第二个 IDE 接口上的主设备）
- `hdd`：第四个 IDE 硬盘（即第二个 IDE 接口上的从设备）

这些数字在物理设备上的含义是：
- “`hda1`”是第一块 IDE 硬盘（`hd a`）的第一个分区
- “`hda2`”是第一块硬盘的第二个分区
- “`hda3`”是第一块硬盘的第三个分区
- “`hda4`”是第一块硬盘的第四个分区
- “`hdb1`”是第二块硬盘的第一个分区（如果 `CD-ROM` 是你第一个 IDE 接口上的从设备，则为“`hdb`”）
- “`hdc1`”——第三块硬盘的第一个分区

`SCSI` 硬盘具有类似的名称，并以字母“`sd`”开头（“`SCSI drive`”，即 `SCSI` 硬盘）。例如，“`sda4`”意味着第一个 `SCSI id` 设备。如果你在并行口上连接了外部 `zip` 驱动器，它在 `SCSI` 挂载环境中将显示为“`sdz`”（`zip` 驱动器）。

`Linux` 安装程序在安装期间显示的分区列表包含任何 `Windows` 分区。例如，`Windows` 分区：

| 挂载点 | 类型 | 大小 | 注释 |
| :--- | :--- | :--- | :--- |
| [未挂载] | `vfat` | 1280 MB | `Win C`, `hda1` |
| `/mnt/dos2` | `vfat` | 1600 MB | `Win D`, `hdd2` |

如果你想进行双系统，请在 `Linux` 安装期间删除这些 `Windows` 分区。如果你在 `Linux` 安装之前删除了 `Windows` 分区，你可能无法从之前的 `Windows` 分区中找回数据。“`msdos`”、“`vfat`”和“`ntfs`”是 `DOS` 和 `Linux` `3.x`/`95`/`98` 使用的典型文件系统。

作为参考，这里是 `Linux` 分区类型（文件系统）的简要总结及短描述。将其包含在 `Linux` 手册页中：`fs` 和 `man`（带有我在 `/usr/src/fs` 源代码文件中添加的一些内容）。带有下划线的文件系统是你更有可能使用的。其他文件系统（下文未列出）作为 `Unix` 操作系统可用、压缩等……第一个在 `Linux` 上运行的文件系统。它具有若干特点：`64GB` 分区大小限制、短文件名、单个时间戳，并且对于软盘和 `RAM` 磁盘仍然有用。

### 文件系统概述

- `ext` 是 `minix` 文件系统的扩展。它已被第二代扩展文件系统 (`ext2`) 完全取代，并最终将从内核中移除。

- `ext2` 是 `Linux` 用于固定式磁盘以及可移动媒体的高性能文件系统。第二扩展文件系统被设计为扩展文件系统 (`ext`) 的扩展，`ext2` 在（速度和 `CPU` 使用率方面）提供了 `Linux` 支持的文件系统中的最佳性能。简而言之，`ext2` 是主要的（默认、典型的）`Linux` 文件系统。

- `ext3` 是带有日志功能（`journaling`）的 `ext2` 文件系统的扩展。它与 `ext2` 向上和向后兼容。这意味着 `ext2` 可以在不重新格式化或丢失数据的情况下转换为 `ext3`（只需挂载即可）。`ext3` 也可以转换为 `ext2`，同样不会丢失数据。我从 `2001` 年 `10` 月以来一直频繁使用 `ext3`——它简单且无需手动干预。它作为安装项包含在。

- `ixfs` 设计为不再接受频繁使用的释放操作。强烈建议你使用此文件系统。它提供了基础功能而没有过度复杂。该文件系统被 `DOS`、`Unix` 和某些 `OS/2` 计算机使用。`msdos` 文件长度不再超过 `8` 个字符加上扩展名。

- `umdos` 是 `Linux` 使用的扩展 `dos` 文件系统。它为文件名、`UID/GID`、`POSIX` 以及命名管道等特殊文件增加了容量。

- `vfat` 是 `Microsoft` `Windows` `95` 和 `Windows` `NT` 使用的扩展 `dos` 文件系统。`VFAT` 为 `msdos` 文件系统增加了长文件名功能。

- `proc` 是一个伪文件系统，实现在内核中而不是读取和解释 `/dev/mem`。特别是，它不占用磁盘空间。

- `iso9660` 是符合 `ISO9660` 标准的 `CD-ROM` 文件系统。它自动支持两种扩展（下文列出）：
    - `iso9660-linux`
    - `iso9660-ridge`

- `hfs` 是在 `Os/2` 中使用的高性能文件系统。由于不可，该文件系统在线 `Linux` 下是只读的。

- `sys` 是 `System/380` `Coherent` 文件系统的实现，用于访问位于远程计算机上的磁盘。

- `smb` 是支持 `SMB` 协议的网络文件系统，供 `MS` `Windows` 工作组使用。要使用 `smb`，你需要一个特殊的挂载程序，可以在 `smbfs` 包中找到，地址为 `http://www.sunite.com/edu/Linux/system/Filesystems/smbfs`。

- `hfs`--=(分级文件系统) 用于 `Linux`。它是一个测试版本，即不建议用于关键数据，除非是只读的。

- `ntfs`--`MS` `NTFS` 文件系统在线 `Linux` 下仍是“实验性”的，即不建议用于生产机器，除非是只读（`2001` 年 `8` 月）。
