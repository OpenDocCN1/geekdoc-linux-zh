## 字典

字典是键值对的集合。它们通过键索引，键必须是不可变对象。你可以使用大括号和号创建字典：

```python
person = {"name": "Alice", "age": 30, "city": "New York"}
```

你可以通过键访问值：

```python
>>> person["name"]
'Alice'
```

你可以使用赋值添加或更新条目：

```python
>>> person["age"] = 31
>>> person["job"] = "Engineer"
```

使用 `pop()` 或 `del` 语句删除条目：

```python
>>> person.pop("age")
30
>>> del person["city"]
```

你可以遍历键、值或两者：

```python
for key, value in person.items():
    print(f"{key}: {value}")
```

## 迭代与循环

最常用的循环结构是 `for` 语句，它用于遍历集合中的项。迭代是 Python 最丰富的特性之一。然而，最常见的迭代形式是简单的遍历字符串、列表或元组等序列中的所有成员。这里有一个示例：

```
for n in [1,2,3,4,5,6,7,8,9]:
    print "%d is %d" % (n, 2**n)
```

在这个示例中，变量 `n` 在每次迭代中会被赋值为列表 `[1,2,3,4,5,6,7,8,9]` 中的连续后续项。由于遍历整数范围非常常见，因此第一种快捷方法也用于这种场景：

```python
for n in range(10):
    print "%d is %d" % (n, 2**n)
```

`range(i,stride)` 函数创建一个表示从 `i` 到 `j-1` 的整数范围的对象。如果省略了该值，则默认为 0。还可以使用可选的步长作为第三个参数。这里有一个示例：

```python
a = range(5)           # a = 0,1,2,3,4
b = range(1,8)        # b = 1,2,3,4,5,6,7
c = range(0,14,3)     # c = 0,3,6,9,12
d = range(8,-1)      # d = 8,7,6,5,4,3,2
```

使用 `range()` 的一个注意事项是，在 Python 2 中，它创建的值是一个包含所有整数值的完整列表。在极大的范围内，这可能会无意中消耗大量内存。因此，在旧的 Python 代码中，你会看到程序员使用替代函数 `xrange()`。例如：

```python
for i in xrange(1000000000):
    # i = 0,1,2,...,999999999
```

由 `xrange()` 创建的对象在请求查询时按需计算它所代表的内容。出于这个原因，它是表示极大量整数范围的首选方式。在 Python 3 中，`xrange()` 函数已重命名为 `range()`，且旧的 `range()` 函数的功能已被移除。

该语句不仅限于整数序列，还可以用于许多种类型的对象，包括字符串、列表、字典和文件。这里有一个示例：

```python
a = "Hello World"
### 打印 a 中的每一个字符
for c in a:
    print c
```

```python
b = ["Dave","Mark","Ann","Phil"]
### 打印列表 b 的成员
for name in b:
    print name
```

```python
c = {'GOOG': 490.10, 'IBM': 91.50, 'AAPL': 123.15}
### 打印字典的所有成员
for key in c:
    print key, c[key]
```

```python
### 打印文件中所有的行
f = open("foo.txt")

for line in f:
    print line,
```

`for` 循环是 Python 最强大的语言特性之一，因为你可以创建自定义的迭代器对象和生成器，为它提供值序列。关于迭代器和生成器的更多细节可以在本章后面部分以及第 6 章“函数与函数式编程”中找到。

## 函数

你定义 `remainder(a,b)` 来创建一个函数，如下所示：

```python
def remainder(a,b):
    q = a // b # 是截断除法
    r = a - q*b
    return r
```

要调用函数，只需使用函数名并传入包裹在括号中的参数即可，例如 `result = remainder(37,15)`。你可以使用元组从函数返回多个值，如下所示：

```python
def divide(a,b):
    q = a // b # 如果 a 和 b 是整数，则 q 是整数
    r = a - q*b
    return (q,r)
```

当在元组中返回多个值时，你可以像这样轻松将结果解包到变量中：

```python
quotient, remainder = divide(1456,33)
```

要为函数参数分配默认值，请使用赋值：

```python
def connect(hostname,port,timeout=300):
    # 函数体
```

当在函数定义中给出默认值时，在随后的函数调用中可以省略它们。当省略时，参数将直接采用默认值。这里有一个示例：

```python
connect('www.python.org', 80)
```

你还可以通过使用关键字并任意顺序提供参数来调用函数。然而，这要求你知道函数定义中的参数名称。这里有一个示例：

```python
connect(port=80,hostname="www.python.org")
```

当函数内部创建或赋值变量时，它们的作用域是局部的。也就是说，变量只在函数体内部定义，并在函数返回时被销毁。要从函数内部修改全局变量的值，请如下使用 `global` 语句：

```python
count = 0
def foo():
    global count
    count += 1 # 修改了全局变量 count
```
