# 关于作者

Scott Knaster 自早期在 LP-ROM 上听到音乐时代起就开始写作和破解技术。他的书在十多年里一直是 Mac 程序员的必读读目。Scott 最近的一本书是《Mac Toys》（与 John Rizzo 合著）。Scott 拥有每一期《MAD》杂志，这在很大程度上解释了他的人生哲学。
