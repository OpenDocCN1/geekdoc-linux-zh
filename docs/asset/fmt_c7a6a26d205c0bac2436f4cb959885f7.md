## 21.2.5 光标位置

我们也可以使用 `tput` 将光标放在屏幕的任何位置。其格式为：

```
cup r c
```

其中 `r` 是行号，`c` 是列号。最好将其作为一个函数使用，这样你可以传递行和列的值。

```
xy()
{
R=$1
C=$2
tput cup $R $C
}
clear
xy 1 5
echo -n "Enter name :"
read NAME
xy 2 5
echo -n "Enter age :"
read AGE
```

当然，也可以传递一个字符串来显示；稍微修改后的函数可以做到这一点。

```
xy()
{
R=$1
C=$2
TEXT=$3
tput cup $R $C
echo -n $TEXT
}
```

你可以这样调用上面的函数：

```
xy 5 10
```

## 21.2.6 在屏幕上居中文本

在屏幕上居中文本并不困难。我们需要从 `tput` 获取列数，然后计算字符串的长度，从列数中减去该值并除以二。剩下的就是我们显示字符串的行号。这是一段完成此任务的代码。输入字符，按回车，文本将显示在第 10 行的中间。

```
echo -n "input string "
read STR
# 获取字符串长度的快速方法
LEN=`echo $STR | wc -c`
COLS=`tput cols`
NEW_COL=`expr ($COLS - $LEN) / 2`
```

为了让上面的函数更灵活，你可能希望带有带有文本和行号来调用它。这个函数可以做到：

```
centertxt()
{
_ROW=$1
STR=$2
# 获取字符串长度的快速方法
LEN=`echo $STR | wc -c`
COLS=`tput cols`
NEW_COL=`expr ($COLS - $LEN) / 2`
tput cup $_ROW $NEW_COL
echo $STR
}
```

你可以这样调用上面的函数：

```
centertxt 15 "THE MAIN EVENT"
```

或者这样调用，将字符串作为参数：

```
centertxt 15 $1
```

## 21.2.8 在脚本中使用功能键

你可以使用 `cat` 命令查看任何特殊键（如 F1、上箭头等）发送了什么控制序列。输入 `cat -v`，然后按下任何控制键，即可让你的终端显示出该行内容。完成后，只需按下 `<CTRL->` 即可退出。

在此示例中调用了 `cat`。按下的键是 F1 (`[OP]`) 和上箭头 (`^[A]`)。

## 21.2.10 生成颜色

为了生成颜色，我们将控制字符嵌入 `echo` 语句中，因为这种方法适用于任何带有彩色终端的系统。但同样，与控制字符一样，你可以在 `echo` 语句内部使用转义序列来生成颜色。

要生成绿色前景的黑色背景：

对于通用方法 `<CTRL-V>`，按下 `<ESCAPE>` 键然后输入 `[40;32m]`。通用方法是我们在书中使用的方法。

你可能会发现，将颜色 `echo` 语句放在 `case` 语句中然后将其封装在函数内部是最好的。这是我的 `case` 颜色函数。

```bash
colour()
{
# 格式为 背景;前景
case $1 in
black_green)
echo '^[[40;32m'
;;
black_yellow)
echo '^[[40;33m'
;;
black_white)
echo '^[[40;37m'
;;
black_cyan)
echo '^[[40;36m'
;;
red_yellow)
echo '^[[41;32m'
;;
black_blue)
echo '^[[40;34m'
;;
esac
}
```

对于颜色 `red_yellow`（红色背景和黄色前景），你只需要执行：

`colour red_yellow`

在你的脚本中使用颜色的操作如下：

```
colour what_ever
echo something
# 现在切换到另一种颜色
colour what_ever
echo something
```

以下函数用于检查输入：

```bash
# 检查字符串长度
length_check()
{
# 长度检查
# $1=字符串, $2=最大长度
STR=$1
MAX=$2
LENGTH=$(echo -n "$STR" | awk '{print length($0)}')
if [ "$LENGTH" -gt "$MAX" ]; then
  return 1
else
  return 0
}
```
