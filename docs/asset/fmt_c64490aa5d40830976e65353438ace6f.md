# 登录你的新账户

要使用此新账户，请转到**系统**菜单并选择**注销**（或直接点击顶端面板最右角的**注销**按钮）。当注销窗口出现时，点击**注销**。几秒钟后，你将回到登录界面。在该窗口中输入你的新用户名，然后按回车。接着输入账户密码，再次按回车。你很快就会进入新用户账户的桌面。

## 切换用户

值得知道，除了简单注销一个账户并登录另一个之外，还有另一种切换用户的方法。这种替代方法在逻辑上被称为*切换用户*。切换用户与注销/登录方法的不同之处在于，当你登录另一个账户时，你仍然保持原始账户的登录状态（此时其他人正在你的电脑上使用他们的账户）。通过这种方式可以保留你已打开的所有窗口或应用程序，当你切换回原来所属的账户时，它们会方便地在那里等着你。

如果你计划在账户之间来回切换，这是一个很好的方法。当，比如你的孩子需要临时登录自己的账户进行快速检查、刻录一张 CD 播放或为学校打印文件时，这也是一个很好的方法。当你的孩子完成后，你可以快速回到之前的工作状态，而无需重新打开文件、网页或你在切换时正在处理的任何其他内容。

# 在独立窗口中登录另一个账户
