## IP 地址

MAC 地址用于在同一网络段上的机器之间通信；然而，要与互联网和其他大型网络上的计算机通信，需要更全面的寻址方案。`TCP/IP` 协议套件要求网络上的每个主机都有一个互联网协议（`IP`）地址。

使用 `TCP/IP` 时，每个主机都有一个唯一的 32 位逻辑地址。该地址以 32 位点分十进制格式表示。`192.168.0.1` 表示一个有效的 `IP` 地址，其二进制等效值 `11000000.10101000.00000000.00000001`。每组八个二进制值称为一个八位组。

## 二进制数

`TCP/IP` 地址实际上是四组八位（八位称为字节）。位可以具有 0 或 1 的二进制值。因此，八位的值范围是从 `00000000` 到 `11111111`，这在十进制中对应 0 到 255。

对于八个二进制位，从左到右，位的十进制值分别为 128、64、32、16、8、4、2 和 1（图 7–7）。如果八个位全为 1，通过相加每个位的值，你将得到 255 的值。要将二进制位转换为它们的十进制等效值，你需要相加所有二进制值为 1 的位所对应的值。例如，如果你有八个位（字节）`11001101`，你通过相加所有二进制值为 1 的位的值来确定十进制等效值。在这种情况下，你会相加 `128 + 64 + 8 + 4 + 1`，结果为 205。

## 网络和主机

`IP` 地址可以分为网络部分和主机部分（图 7–8）。网络部分标识主机连接到哪个网络。主机部分标识该网络上的特定设备。

![](img/37f079cee226b270f2e09b37a2e4a05d_183_0.png)

`IP` 地址分为五个类别。其中三类可用于网络上的主机，即 A 类、B 类或 C 类。另外两类为保留类别。D 类地址保留用于组播，E 类地址保留用于实验目的。

A 类地址在二进制格式下，总是以 0 开头。在 A 类网络中，最左边的八位位组用于网络标识，而右边的三个八位位组用于主机标识。A 类地址在第一个八位位组中的范围是 0–126。（127 保留用于指定本地主机。）A 类网络上可用的主机数量为 $2^{24}$ 减去 2，即 16,777,214 个。

> **注意**
>
> 因为主机占用最后三个八位位组（3 · 8），所以 2 的幂是 24。减去 2 的原因是，在主机部分中，全零用于网络标识，全一用于广播。

当源主机向网络上的所有主机发送数据时，就会发生广播。标识消息为广播消息的地址，其主机位总是全一。网络 `192.168.0.0` 的广播地址为 `192.168.0.255`（主机位全为 1，即 `1111 1111`）。

B 类地址在二进制格式下，前两位总是以 10 开头。在 B 类网络中，前两个八位位组用于网络标识，最后两个八位位组用于主机标识。B 类网络第一个八位位组的取值范围是 128–191。B 类网络上可用的主机数量为 $2^{16}$ 减去 2，即 65,534 个。

C 类地址在二进制表示中，前三位总是为 110。在 C 类网络中，前三个八位位组用于标识网络，最后一个八位位组标识主机。C 类地址在第一个八位位组中的范围是 192–223。C 类网络上可用的主机数量为 $2^8$ 减去 2，即 254 个。

理解 `IP` 地址为何包含网络和主机两部分非常重要。主机只能与同一网络上的其他主机直接通信。如果主机的网络 ID 不同，它们无法直接相互通信，中间必须有一个路由器。

网络位数的数量是固定的，具体取决于网络的类别。网络位由子网掩码标识。子网掩码为 32 位，与相关的 `IP` 地址对应。子网掩码位在网络位置上的值为 1，在主机位置上的值为 0。例如，地址为 `192.168.0.1` 的主机将拥有子网掩码 `255.255.255.0`（见图 7–9）。（全一，`1111 1111`，十进制等效值为 255。）

![](img/37f079cee226b270f2e09b37a2e4a05d_183_1.png)

这表明网络是 `192.168.0`，主机是 1。

有时，将主机位分配给逻辑组是合适的。如本章前文所述，网络中的主机只能与同一网络中的其他主机直接通信。例如，如果处理工资的主机用户位于一个单独的网络中，那么网络外的主机用户将无法连接工资资源。这将提高整个网络的安全性。

例如，如果你有一个 C 类地址，拥有 254 个可能的主机，你可能更喜欢按部门进行逻辑划分，而不是将所有用户组合在一起。假设以下条件：

- C 类地址为 `192.168.0.0`
- 库存控制有 10 个用户
- 应付账款有 8 个用户
- 应收账款有 8 个用户
- 工资部门有 5 个用户
- 管理层有 5 个用户

默认情况下，你有一个网络 `192.168.0.0`，以及 254 个主机（主机位 0–255，其中 0 用于网络地址，255 用于广播）。`TCP/IP` 寻址允许将部分主机位用于网络。从主机位中借出用于网络的位被称为子网位。为了有用，必须至少保留两位用于主机使用。（考虑到全零用于网络 ID，全一用于广播，这就为主机留下了两个地址。）

在将主机位借给子网位之前，确定你需要多少个 subnet。根据上述信息，你需要划分主机用户以获得至少 5 个组或子网。请记住，子网掩码中的网络位值为 1。在使用子网时，你拥有一组网络范围，子网中的 1 表示你正在使用哪个网络。（子网掩码中的默认网络位值始终为一。）

你只需计算所需的子网位数，并将值相加以确定可用的网络。图 7-10 计算了所需的子网位数。

## 其他地址

在你脱离单个子网之前，你必须有一种将数据包路由到远程网络的方法。如前所述，路由器是用于连接网络的设备。要完成网络设置，你必须拥有更多一些地址。

为了连接路由器，路由器上的接口必须拥有一个与主机所在网络兼容的网络地址。如果你使用的是网络 `192.168.0.0`，你的可用主机范围是从 `192.168.0.1` 到 `192.168.0.254`。路由器可以使用任何可用地址。无论路由器接口地址是什么，该地址都是网络网关的地址。

即使你可以使用路由器进行路由，你仍然需要知道连接到哪里。`DNS` 服务器接收请求的 `URL` 并返回拥有该 `URL` 的主机的 `IP` 地址。
