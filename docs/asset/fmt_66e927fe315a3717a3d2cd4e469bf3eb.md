## 名称解析

在 TCP/IP 网络上通信的计算机使用唯一的 IP 地址来标识自己；然而，这种识别方案对于人类使用来说是不实用的，因为 IP 地址很难记忆。因此，计算机通过名称来识别；因为网络上的每台计算机通常被称为主机（host），所以计算机名称被称为主机名（host name）。
