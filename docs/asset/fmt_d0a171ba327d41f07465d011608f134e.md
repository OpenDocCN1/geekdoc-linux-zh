## 探索 C 运算符

## 算术运算符

C 中的算术运算符用于执行数学运算。算术运算符有：`+`、`-`、`*`、`/` 和 `%`。取模运算符 (`%`) 用于寻找整数除后的余数。以下示例展示了如何在 C 中使用算术运算符：

列表 3.2：使用算术运算符

```c
#include <stdio.h>

int main() {
    int a=10;
    int b=20;
    int sum, sub, mul, rem;
    sum = a + b;
    sub = a - b;
    mul = a * b;
    rem = a % b;
    printf("sum=%d\n", sum);
    printf("sub=%d\n", sub);
    printf("mul=%d\n", mul);
    printf("rem=%d\n", rem);
    return 0;
}
```

## 逻辑运算符

逻辑运算符用于组合多个关系表达式。逻辑运算符有：`AND` (`&&`)、`OR` (`||`) 和 `NOT` (`!`)。当两个表达式都为真时，`AND` 运算符返回真。当任意一个表达式为真时，`OR` 运算符返回真。`NOT` 运算符返回值的反反。以下示例展示了如何在 C 中使用逻辑运算符：

列表 3.3：使用逻辑运算符

```c
#include <stdio.h>

int main() {
    int a=4;
    int b=8;
    int c=7;
    if(a<b && b>c)
    printf("a小于 b且 b大于 c\n");
    if(a>b || b<a)
    printf("a大于 b 或 b大于 a\n");
    return 0;
}
```

## 关系运算符

关系运算符用于测试两个实体之间的关系。关系运算符有：`<`、`<=`、`>`、`==`、`!=`。它们根据条件返回真或假。以下示例展示了如何在 C 中使用关系运算符：

# 条件运算符

条件运算符在 C 语言中更通称为三元运算符 (`?:`)，用于根据关系表达式的结果返回值。C 语言中条件运算符的语法如下：

```
e1 ? e2 : e3
```

在上述语法中，首先求值 `e1`，如果它为真，则计算 `e2`，其结果成为表达式的结果。如果为假，则计算 `e3`，其结果成为表达式的结果。列表 3.6 展示了如何使用条件运算符：

int exp1,exp2;

m=30;

n=50;

exp1 = m > n ? m : n;

printf("the value of exp1 is = %d\n", exp1);

exp2 = m < n ? m : n;

printf("the value of exp2 is = %d\n", exp2);

return 0;

}
```

```
The value of exp1 is = 50

The value of exp2 is = 30
```

# 自增/自减运算符

你可以使用自增 (`++`) 或自减 (`--`) 运算符增加或减少变量的值。自增运算符用于将其操作数加1，自减运算符用于从其操作数中减去1。换句话说，自增运算符将整数的值加1，自减运算符将整数的值减1。例如，如果 `int m=4`，则表达式 `m++` 意味着 `m = m + 1`。因此，`m` 的值变为 5。列表 3.7 展示了自增/自减运算符的使用。

return 0;

}
```

以下是上述程序的输出：

```

```

# 位运算符

位运算符对位串进行操作，位操作在该操作数上完成。C 语言中有 6 个位运算符：与 (`&`) 运算符、或 (`|`) 运算符、异或 (`^`) 运算符、取反 (`~`) 运算符、左移 (`<<`) 运算符和右移 (`>>`) 运算符。表 3.5详细解释了不同的位运算符：

表 3.5：位运算符及其说明

| 运算符 | 说明 |
|---|---|
| `&` | 比较第一个操作数的每一个位与第二个操作数的对应位。如果两者都为 1，则结果位为 1，否则设置为 0。 |
| `|` | 比较第一个操作数的每一个位与第二个操作数的对应位。如果其中任意一位为 1，则结果设置为 1，否则设置为 0。 |
| `^` | 比较第一个操作数的每一个位与第二个操作数的对应位。如果其中一位为 1 另一个为 0，则结果设置为 1，否则结果设置为 0。 |
| `~` | 将操作数中的每个 1 位在结果中移动为 0，反之亦然。 |
| `<<` | 将第一个操作数左移。 |
| `>>` | 将第一个操作数右移。 |

列表 3.8 展示了使用位运算符的示例：

```c
#include <stdio.h>

int main() {
int p=0;

p = 5;

q = 6;

p = p >> 1;

q = q << 1;

printf("p = %d\n", p);

printf("q = %d\n", q);

return 0;

}
```

以下是上述程序的输出：

```
p = 2

q = 12
```
