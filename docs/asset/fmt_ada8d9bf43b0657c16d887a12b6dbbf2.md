## 为什么要学习 Linux？

Linux 是一个增长迅速的操作系统，而且廉价且灵活。Linux 还是中小型服务器领域的一个主要参与者，对于工作站和桌面使用，它也成为一个日益可行的平台。通过了解 Linux，你将提高自己在就业市场上的竞争力。即使你已经熟悉 `Windows` 或 `Mac OS` 并仅使用这些系统，了解 Linux 也会让你在寻找新工作或晋升时拥有优势。例如，这些知识将帮助你在决定何时以及如何部署 Linux 时做出明智的判断。计算机技术行业协会（CompTIA）将 Linux+ 推崇为想要进入 Linux 职业领域的人员的入门认证。该考试旨在证明个人具备安装、操作和故障排除 Linux 系统所需的技能，并熟悉 Linux 特有的概念和基础硬件。

本书的目的是帮助你通过 2012 年更新的 Linux+ 考试（`LXO-101` 和 `LXO-102`）。由于这些考试涵盖了 Linux 的安装、配置、维护、应用、网络和安全，这些是本书重点介绍的主题。你将学到足够的知识让 Linux 系统运行起来，并为许多常见任务对其进行配置。即使在你参加并通过了 Linux+ 考试后，本书也应该是一份有用的参考。

> 2010 年，CompTIA 宣布与 LPI 认证（LPIC）计划背后的组织 Linux Professional Institute 建立合作伙伴关系。通过这一合作，CompTIA 在 Linux+ 的框架下提供 LPIC Level 1 考试。这两个项目的考试和考试目标是相同的；然而，Linux+ 候选人可以选择通过 CompTIA Linux+ 考试获得 `LPIC-1` 作为 `Novell Certified Linux Administrator` 认证。

## Linux 基础

Linux 是 `Unix` 操作系统（`OS`）的克隆，`Unix` 多年来在学术界和许多业务环境中一直流行。`Unix` 和 `Linux` 以前专门用于大型主机，而现在可以在小型计算机上运行——这些小型计算机实际上比几年前的大型机要强大得多。由于其大型机背景，`Unix`（因此也 `Linux`）扩展良好，能够胜任当今严苛的科学、工程和网络服务器任务。

Linux 由一个内核（核心控制软件）以及许多依赖内核以提供与用户交互功能的库和实用程序组成。该操作系统有许多不同的发行版，这些发行版是特定内核与特定支持程序的集合。
