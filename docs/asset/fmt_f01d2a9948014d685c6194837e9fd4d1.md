
## 字体安装

1. 启动控制中心并通过“系统管理”（System Administration）→“字体安装”（Font Installation）访问相应的模块。
2. 从图标栏或右键点击列表时显示的菜单中选择“添加字体”（Add Fonts）。
3. 在打开的对话框中选择一个或多个字体进行安装。
4. 标记的字体将安装到您的个人字体文件夹中。选择系统字体会显示预览。

要更新系统字体，首先选择“系统管理模式”（System administration mode）并输入您的 root 密码，然后按照描述的用户字体安装步骤进行。

禁用已安装字体的功能非常有用。它们并没有被删除，而是对系统不可用。选择“禁用”（deactivate）图标或右键菜单中的对应项。这将使绿色勾标记消失。点击“应用”（Apply）确认后，新设置将生效。禁用的字体将不再供应用程序使用。这减少了应用程序中显示的字体列表的大小。

## GNOME 桌面

GNOME（GNU Network Object Model Environment）是一个快速的 Linux 桌面。它的开发目标是使用户界面更加统一，同时简化外观和感受的各个方面。窗口管理的基本组件和其他组件实现了各种应用程序之间的数据共享，并基于统一的操作概念和帮助系统。

### 6.1 桌面

GNOME（GNU Network Object Model Environment）是一个快速的 Linux 桌面。它的开发目标是使用户界面更加统一，同时简化外观和感受的各个方面。窗口管理的基本组件和其他组件实现了各种应用程序之间的数据共享，并基于统一的操作概念和帮助系统。

#### 6.1.1 图标

默认情况下，桌面上具有三个符号：文件夹、垃圾桶等。双击图标将启动 Nautilus，显示介质的内容。通过拖放将文件拷贝到您的个人主目录。以相同的方式将文件拷贝到软磁盘。

#### 6.1.2 面板面板

面板包含已启动应用程序的图标。当您点击任务栏中的窗口名称时，它将移动到前景。如果程序已处于前景，点击它将将其最小化。在任务栏旁边，“工作区切换器”（Workspace Switcher）提供了对额外工作区域的访问。这些虚拟桌面提供了额外的空间来安排打开的应用程序和窗口。例如，将编辑器放在一个工作区，将其他放在另一个，并将您的电子邮件应用程序放在第三个。

#### 6.1.3 菜单

通过面板最左侧的图标打开菜单。除了分类组织的应用程序外，还可以找到默认功能，如“注销”（Log out）和“锁定”（Log screen）。使用“最近打开”（Open Recent）快速访问文件。使用“搜索文件”（Search for Files）查找文件。

通过“运行程序”（Run Program...），输入并运行命令，例如启动程序而不是通过各种程序菜单。从主菜单中，您还可以启动“GNOME 控制中心”来配置和安装额外软件。

#### 6.1.4 处理软磁盘、CD 或 DVD

要访问软磁盘、CD 或 DVD，请将介质插入相应的驱动器中。右键点击桌面空白处，从“驱动器”（Drives）列表中选择所需的介质。出现 CD 图标。双击图标将启动 Nautilus，显示内容质。通过拖放将文件拷贝到您的个人主目录。以相同的方式将文件拷贝到软磁盘。

### 注意事项

在使用后不要直接从驱动器中取出软磁盘。软磁盘、CD 和 DVD 必须始终从系统中卸载。关闭所有仍在访问该介质的 Nautilus 会话，然后对介质图标点击右键，并从菜单中选择“弹出”。然后安全地取出软磁盘或 CD（托盘会自动打开）。该图标将从桌面上消失。

也可以通过软磁盘菜单对软磁盘进行格式化。在对话框中，选择软磁盘的格式和密度。在“文件系统类型”，在“Linux 原生 (ext2)”（Linux 的文件系统）和“DOS (FAT)”之间进行选择，因为 Windows 无法访问 Linux 文件系统。“帮助”为该工具提供了一些说明。

## 6.2 设置

根据您的喜好和需求对 GNOME 桌面进行自定义。点击桌面上的“在此开始”图标。在桌面上点击右键，然后选择“新窗口”来启动 Nautilus。在“位置：”下，输入 `preferences://`。双击相应的图标可打开各种配置旋轮。

> 在各个模块中，可以通过“帮助”访问特定选项的帮助信息。系统会立即采用配置模块中进行的任何更改。

### 6.2.1 键盘

在“键盘”模块中，确定重复速率和与键盘相关的声音事件等设置。该模块由“键盘”和“音频”选项卡组成。使用“音频”选项卡为键盘配置音频信号。当按下错误的键时提供听力通知，请激活相应的单选按钮。通过“关闭”退出“键盘”模块，或通过“辅助功能”进入辅助功能模块。该模块的功能见第 175 页的第 6.2.9 节。

### 6.2.2 鼠标配置

鼠标配置由三个选项卡：“按钮”、“光标”和“移动”。“按钮”选项卡的配置选项参考“鼠标方向”。左手用户应激活“左手型鼠标”以交换左右鼠标键。使用滑块确定系统解释为双击的两次点击之间的最大延迟（秒）。

可以在“光标”选项卡下更改光标的外观和大小。提供四种不同的设置。更改在下次登录之前不会激活。在“定位指针”下，激活一个选项，使光标在您按下 Ctrl 键时高亮，以便更容易找到。在“移动”下，设置屏幕光标的“加速”和“灵敏度”。

### 6.2.3 菜单和工具栏

此模块中的设置影响所有兼容 GNOME 应用程序的菜单和工具栏。选择工具栏图标显示为“仅文本”、“仅图标”、“图标旁文本”或“图标下方文本”。默认设置为“仅文本”。

激活“工具栏”可以将其分离并移动，从而允许工具栏从所有其他窗口元素中分离，并允许在桌面上自由定位。这会在工具栏左侧出现一个抓取区域。点击并按住此区域可以重新定位工具栏。

任何应用程序菜单中的每个菜单项都可以显示相应的图标。激活“在菜单中显示图标”将使用提供的示例菜单测试设置。

### 6.2.4 屏幕保护

配置屏幕保护程序的模块细分为两个选项卡：“显示模式”和“高级”。在“显示模式”中选择屏幕保护程序。“高级”选项卡包含了一些通常不需要修改的特殊选项。

在“显示模式”选项卡下选择屏幕保护模式。从“随机屏幕保护程序”（从自定义列表中随机选择屏幕保护程序）、“仅一个屏幕保护程序”、“仅黑屏”或“禁用屏幕保护程序”中选择。

为运行模式“仅一个屏幕保护程序”或“随机屏幕保护程序”从列表中选择一个或多个屏幕保护程序。当前选择的屏幕保护程序显示在小型预览窗口中。“预览”按钮启动该屏幕保护程序的全屏预览，可以按任意键取消。点击选择列表上方相应的三角形来预览上一个或下一个屏幕保护程序。

在最后一步中，确定屏幕在多久后应该完全变黑（“黑屏后”）、何时切换屏幕保护程序模块（“循环后”）或何时应该锁定屏幕（“锁定屏幕后”）。所有时间引用均以分钟为单位。

### 6.2.5 窗口

此模块控制应用程序窗口的行为。确定窗口与鼠标指针或其标题接触时如何反应，并定义移动应用程序窗口时按住的键。

键盘辅助功能可以在一定时间后自动禁用。使用滑块设置一个以秒为单位的适当时间限制。系统在键盘辅助功能激活和禁用时可以额外提供音频反馈。

### 6.2.6 背景

为桌面确定背景。默认情况下，在此所做的更改将应用于所有虚拟桌面。如果您不想任何背景，点击“无图片”并定义背景样式。下拉菜单提供水平渐变、垂直渐变或无渐变。使用“颜色”在颜色编辑器中定义所需的颜色。

要使用图像文件作为背景，从文件管理器将其拖动并到“选择图片”。或者，点击“选择图片”打开对话框以选择所需的图像。

“图片选项”确定对所选图像应用哪些处理步骤以完美适应当前屏幕分辨率。选项有“居中”、“缩放”和“拉伸”。

### 6.2.7 字体

此模块决定桌面使用的字体。在第二步中，启用改进字体的可选效果。对话窗口的上部分显示为“应用程序字体”、“桌面字体”、“窗口标题字体”和“终端字体”选择的字体。点击任一按钮打开选择对话框，在其中设置字体族、样式和大小。“字体渲染”选项以及通过“详细信息”访问的其他配置选项已设置为最佳值。

### 6.2.8 主题

桌面上所有控制元素以及 GNOME 应用程序的样式在此设置。从各种预装主题中选择。在列表中选择样式将自动应用它。“详细信息”打开另一个对话框，自定义单个桌面元素（如窗口内容、边框和图标）的样式。做出更改并通过“关闭”离开对话框将主题切换到“自定义主题”。点击“保存主题”将您的修改后的主题保存为自定义名称。互联网和其他来源提供了许多 `.tar.gz` 格式 GNOME 主题。通过“安装主题”安装这些。
