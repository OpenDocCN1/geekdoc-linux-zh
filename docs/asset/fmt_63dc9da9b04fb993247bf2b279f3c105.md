# PostCSS

`PostCSS` 插件从你的样式表中生成雪花。它是一个基于 `JavaScript` 的开发工具，用于自动化 `CSS` 操作。此前由 `Andrew Sit` 设计，其初衷源于 `Martians`。它是一个框架，用于开发 `Sass` 和 `LESS` 等语言。`PostCSS` 拥有核心组件如下：

- 抽象语法树。
- 它是一组由类组成的树。
- 解析器。
- 生成器。
- 修改器。
- 插件。

# 功能

插件是与树工作的小程序。核心部分将 `CSS` 字符串转换为树，然后 `PostCSS` 将通过插件修改生成新的 `CSS` 字符串。
