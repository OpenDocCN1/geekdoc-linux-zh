# inttool

用于 `XML` 的实用脚本。自动从 `oaf`、`glade`、`bono oi`、`nautilus` 和其他 `XML` 文件提取字符串并放入 `po` 文件。自动将 `po` 合并回 `.oaf` 文件（编码为 7 位纯）。它扩展了这种合并机制以支持其他类型的 `XML` 文件。源自 Debian 3.0.0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

# IP 别名 (IP aliasing)

提供了在同一低层网络驱动程序上设置多个网络地址的可能性（例如在一个以太网卡上设置两个 IP 地址）。来自 Linux Guide @FirstLinux

# IP 过滤防火墙 (IP Filtering Firewalls)

工作在数据包级。旨在根据每个数据包包含的源、目的和端口类型来控制数据包流。来自 Linux Guide @FirstLinux

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# IP 伪装 (IP Masquerade)

Linux 中的一种网络功能类似于许多商用网络和网络路由器中的一到多 NAT（网络地址转换）。IP 伪装允许连接到此设备（通过 PPP、以太网等）的其他“内部”计算机访问互联网。即使这些内部机器没有正式分配的 IP 地址，Linux IP 伪装也能实现此功能。来自 Linux Guide @FirstLinux

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# IP 号 (Internet Protocol Number)

有时被称为点分四部分 (dotted quad)。由点分隔的 4 部分的唯一数字，例如 165.234.2。每一台在互联网上的机器都有 IP 号——如果一台机器没有 IP，它就真的不在互联网上。许多机器（服务器）还有一个或多个供人们记忆的域名。来自 Ramasse

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# IP 欺骗 (IP spoofing)

IP 欺骗是一种由多个组件组成的复杂攻击。它是一种安全漏洞，通过欺骗处于信任关系中的计算机让你认为你是你 true身份。关于这一点有一篇详尽的论文，以及 Phrack 杂志的第七、八期。来自 Linux Guide @FirstLinux

`http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
