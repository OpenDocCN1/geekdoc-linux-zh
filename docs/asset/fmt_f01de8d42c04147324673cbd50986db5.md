# Linux 词典

deconf-timy

用于升级的空包，依赖于 debconf 的空包。它的存在仅是为了确保从 potato（土豆）到 woody（木）的平滑升级，可以随时安全删除。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

deconf-utils

debconf 实用程序包含一些帮助用户和开发者的小型工具。有些工具可以帮助管理 debconf 数据库，另一些则可以翻译模板，以及一个可以从命令行直接与 debconf 通信的程序。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

debuster

现在想要安装的 Debian 软件包。debuster 是一个 apt 和 dpkg 的封装程序。第一次运行时，它会询问你想要保留已安装软件包的哪一个。之后，它会维护一个你必须在系统上安装的软件包列表。它会列出仅因为其他软件包依赖它们而被安装的“已检测”软件包。如果这些依赖关系之一发生变化，或者你想删除旧软件包，debuster 都会注意到。这有助于维护一个干净的 Debian 安装，而不让不再使用的旧（主库）软件包闲置在那里。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
