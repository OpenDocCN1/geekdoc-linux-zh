## 2.4 在 Kali 中穿行

### 2.4.1 Linux 文件系统

Kali Linux 遵循文件系统层次结构标准 (FHS)，为所有 Linux 用户提供了一个熟悉且通用的布局。你将最常用的目录有：

- `/bin` - 基本程序 (`ls`, `cd`, `cat`, 等)
- `/sbin` - 系统程序 (`fdisk`, `mkfs`, `swctl`, 等)
- `/etc` - 配置文件
- `/tmp` - 临时文件（通常在启动时删除）
- `/usr/bin` - 应用程序 (`ncat`, `ncat`, `nmap`, 等)
- `/usr/share` - 应用支持和数据文件

还有许多其他目录你很少需要进入，但对 Linux 文件系统布局良好的熟悉将极大提高你的效率。
