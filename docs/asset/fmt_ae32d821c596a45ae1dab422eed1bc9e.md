
在所有情况下，表达式都会求值并生成一个字符串，该字符串将作为完整路径名写入（对于 `>` 或 `>>`）或作为执行的命令（`|`）。使用前两种形式时，如果文件未打开则将其打开。如果有必要，将创建它。对于第一种形式，文件将被截断。然后输出将追加到文件中。只要文件保持打开状态，表达式求值为相同字符串的的后续调用只需将输出追加到文件中。文件将一直保持打开，直到调用 `close` 函数且其表达式求值为字符串值。

第三种形式将输出写入管道到命令输入的流中。如果当前没有打开的流，将创建一个流，并将表达式的值作为其命令名。创建的流等同于调用 `open(S)` 函数创建的流，其中表达式的值作为命令参数，`w` 值作为模式参数。只要流保持打开状态，表达式求值为相同字符串的后续调用将输出到现有流中。该流将一直保持打开，直到调用 `close` 函数且其表达式求值为相同的字符串值。此时，该流将通过调用 `pclose` 函数关闭。

这些输出语句接受一个由逗号分隔的表达式列表，在语法中，该列表由符号 `expr_list`、`print_expr_list` 或 `print_expr_list_opt` 引用。在此处将其被称为“表达式列表”，每个成员被称为“表达式参数”。

`print` 语句将每个表达式参数的值写入当前的输出记录字段分隔符中（参见变量 `ORS`）。所有表达式参数都被视为字符串，并在必要时进行转换；但例外是使用 `OFMT` 中的 `printf` 格式代替 `CONVFMT` 中的值。空表达式代表整个输入记录（`$0`）。

`printf` 语句根据类似于本文用于描述文件格式的“文件格式表示法”（File Format Notation）的符号产生输出。按照指定产生输出，第一个表达式参数作为字符串 `862`，后续表达式参数作为字符串 `arg1` 到 `arg`（包含边界），但有以下例外：

- 格式是一个实际的字符字符串而非图形化表示。因此，它不能包含空字符位置。格式字符串中的空格字符（在转换规范的标志之外的任何语境下）均被视为普通字符。
- 如果字符集包含 `\` 字符且该字符出现在格式字符串中，它被视为普通字符并复制到输出中。
- 以反斜线开头的转义序列被视为普通字符序列并复制到输出中。注意，当这些序列出现在字面量字符串时，`nawk` 会对其进行词法解释，但 `printf` 不对它们进行特殊处理。
- 字段宽度或精度可以使用 `*` 字符代替数字字符串。在这种情况下，将获取表达式列表中的参数，并取其数值值作为字段宽度或精度。
- 实现不会在 `d` 或 `u` 转换规范的输出前后带有格式字符串中未指定的空白字符。
- 实现不会在 `o` 转换规范的输出前带有格式字符串中未指定的前导 0。
- 对于 `c` 转换规范：如果参数是数值值，则输出编码为该值的字符。如果该值为 0 或不属于字符集中任一字符的编码，则其行为是未定义的。如果参数没有数值值，则输出字符串值的第一个字符；如果字符串不包含任何字符，则行为是未定义的。
- 对于每个消耗参数的转换规范，将求值下一个表达式参数。除了 `c` 转换外，该值将被转换为适用于该转换规范的类型。
- 如果表达式参数不足以满足格式字符串中所有的转换规范，则行为是未定义的。
- 如果格式字符串中的任何字符序列以 `%` 字符开头但未形成有效的转换规范，则行为是未指定的。`print` 和 `printf` 均至少输出 `(LINE_MAX)` 字节。

## 函数

`awk` 语言具有多种内置函数：算术、字符串、输入/输出和通用函数。

### 算术函数

除 `int` 外，算术函数均基于 ISO C 标准。在 ISO C 标准规定返回错误或行为未定义的情况下，其行为是未定义的。尽管语法允许内置函数在不带参数或括号的情况下出现，除非下列表中的参数或括号被指示为可选（通过在 `[ ]` 括号内显示），否则此类用法是未定义的。

- `atan2(y,x)` 返回 $y/x$ 的反正切。
- `cos(x)` 返回 $x$ 的余弦，其中 $x$ 为弧度。
- `sin(x)` 返回 $x$ 的正弦，其中 $x$ 为弧度。
- `exp(x)` 返回 $x$ 的指数函数。
- `log(x)` 返回 $x$ 的自然对数。
- `sqrt(x)` 返回 $x$ 的平方根。
- `int(x)` 将其参数截断为整数。
- `rand()` 返回一个随机数，使得 $0 < n < 1$。
- `srand([expr])` 设置 `rand` 的值。

### 字符串函数

支持以下字符串函数。尽管语法允许内置函数在不带参数或括号的情况下出现，除非下列表参数或括号被指示为可选（通过在 `[ ]` 括号内显示），此类用法是未定义的。

- `sub(ere,repl,[in])` 在字符串中将第一个正则表达式 `ere` 替换为 `repl`，并返回替换次数。从头到尾扫描 `repl` 时遇到每个反斜线 `\`，均将其下一个字符视为字面量，它失去其特殊含义。除了 `&` 外，任何此类字符的特殊含义是不指定的。如果你指定的 `in` 效的，则行为是未定义的。如果你省略 `in`，则替换当前记录（`$0`）。
- `index(s, t)` 返回 `t` 首次出现的字符位置，若未找到则返回 0。
- `length(s)` 返回参数的长度（字符）。
- `match(s, ere)` 返回扩展正则表达式 `ere` 出现的字符位置（从 1 开始）。将 `RSTART` 设置为匹配字符串的起始位置；将 `RLENGTH` 设置为匹配字符串的长度；若未找到则返回 -1。
- `split(s,a,[fs])` 将字符串 `s` 拆分为数组元素 `a[1], a[2], ..., a[n]` 并返回 `n`。如果你不指定 `fs`，则使用扩展表达式 `fs` 或字段分隔符进行分离。创建的数组元素具有字符串值。当当前本地的任何小数点字符变为点号时，分配给任何元素的字符串被视为数值字符串；数组元素也具有该字符串的数值。空字符串作为 `fs` 的值是不指定的。
- `sprintf(fmt,expr...)` 按照 `fmt` 给出的 `printf` 格式格式表达式并返回字符串。
- `gsub(ere,repl)` 行为类似于 `sub`，替换所有出现的 `ere`。
- `substr(s,m,[n])` 返回 `s` 中从位置 `m`（从 1 开始）开始的 `n` 个字符的子串。如果缺少 `n`，则子串长度限制为字符串 `s` 的长度。
- `tolower(s)` 返回基于字符串 `s` 的字符串。在返回的字符串中，将 `s` 中所有指示为具有 `tolower` 映射的大写字母替换为当前本地化 `LC_TYPE` 类别的小写字母。`s` 中的其他字符保持不变。
- `toupper(s)` 返回基于字符串 `s` 的字符串。在返回的字符串中，将 `s` 中所有指示为具有 `toupper` 映射的小写字母替换为 `LC_TYPE` 类别的大写字母。`s` 中的其他字符保持不变。

上述所有接受 ERE 作为参数的函数都期望一个模式或一个下文定义的正则表达式字符串值表达式。

## 输入输出与通用函数

下面列出了输入输出和通用函数。

`close(expression)`

关闭由 `print` 或 `printf` 语句或调用 `getline` 打开的文件或管道，使用具有相同字符串值的表达式。如果关闭成功，返回 0；否则返回非零。

| expression | getline [var] |
| :--- | :--- |
| 从从命令输出管道的流中读取输入记录。如果当前没有打开的流，则以 `expression` 的值作为命令名创建一个流。创建的流等同于调用该命令参数并以 `r` 作为模式参数创建的流。只要流保持打开状态，`expression` 中的后续调用将评估为相同的字符串值，并从文件中读取后续记录。流将保持打开，直到调用 `close` 函数并传入一个评估为相同字符串值的表达式。此时，将通过调用 `pclose` 函数关闭流。如果 `var` 缺失，则设置 `$0` 和 `NF`；否则，设置 `var`。 |

当在 `|`（到包含 `getline` 的表达式开头）左侧存在不在括号内的运算符（包括连接符）时，`getline` 运算符可能会形成歧义结构。在 `$` 的上下文中，它的行为类似于其优先级低于 `|`。评估其他运算符的结果是不指定的，所有可移植应用程序的使用都必须正确放在括号内。

`getline`: 将 `$0` 设置为当前输入文件的下一个输入记录。这种形式的 `getline` 会设置 `NF` 和 `NR` 变量。

`getline var`: 将变量设置为当前输入文件的下一条输入记录。这种形式的 `getline` 会设置 `FNR` 和 `NR` 变量。

`getline [var] < expression`: 从命名文件读取下一条输入记录。表达式评估为字符串并作为完整路径名。如果命名文件当前未打开，则打开它。只要流保持打开状态，`expression` 中的后续调用将评估为相同的字符串值，并从文件中读取后续记录。文件将保持打开，直到调用 `close` 函数并传入一个评估为相同字符串值的表达式。如果 `var` 缺失，则设置 `$0` 和 `NF`；否则，设置 `var`。

当在 `<`（到包含 `getline` 的表达式结束）右侧存在不在括号内的二元运算符（包括连接符）时，`getline` 运算符可能会形成歧义结构。评估此类结构的结果是不指定的，所有可移植应用程序的使用都必须正确放在括号内。

`system(expression)`

以等同于 `system(S)` 函数的方式执行 `expression` 给出的命令，并返回命令的退出状态。
