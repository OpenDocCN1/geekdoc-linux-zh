
在亚瑟·凯莱门下学习的学者中，阿尔弗雷德·布雷·坎普（1849–1922）也试图解决四色问题。坎普解决这个问题的方法涉及在地图 `M` 中定位一个区域 `R`，使得 `R` 被五个或更少的相邻区域包围。这样的区域 `R` 的存在是推论 10.5 的一个结果。一旦找到 `R`，坎普随后表明，对于 `M`（减去区域 `R`）的每一种四色着色，都存在对整张地图 `M` 的一种四色着色。这样的论证将表明 `M` 不可能是一个最小反例（即一个不能用四种颜色着色的、区域数量最少的地图）。

例如，最小反例 `M` 不可能包含一个被三个区域 `R1`、`R2` 和 `R3` 包围的区域 `R`，如 图 16.1(a) 所示。在这种情况下，我们可以将区域 `R` 缩小到一个点，产生一张新地图 `M′`，其区域比原来少一个。地图 `M′` 然后可以用四种颜色着色，其中只有三种颜色被用来着色 `R1`、`R2` 和 `R3`，如 图 16.1(b) 所示。回到原地图 `M`，我们可以看到现在有一个可用的颜色可以给 `R`，如 图 16.1(c) 所示，这意味着 `M` 最终可以用四种颜色着色，从而产生矛盾。当然，如果地图 `M` 包含一个被少于三个区域包围的区域，可以用类似的方式获得矛盾。

## 坎普链

然而，假设地图 `M` 没有包含被三个或更少区域包围的区域，但确实包含一个被四个区域包围的区域 `R`，比如 `R1`、`R2`、`R3` 和 `R4`，如 图 16.2(a) 所示。如果再次将区域 `R` 缩小到一个点，产生一张少一个区域的地图 `M′`，那么我们知道 `M′` 可以用四种颜色着色。如果用两种或三种颜色对 `R1`、`R2`、`R3` 和 `R4` 进行着色，那么我们可以回到 `M`，并且有一个颜色可供 `R` 使用。然而，如果区域 `R1`、`R2`、`R3` 和 `R4` 用四种不同的颜色着色，如 图 16.2(b) 所示，这种技术将不适用。

在这种情况下，我们可以做的是确定地图 `M′` 是否有一条由区域组成的链，从 `R1` 开始到 `R3` 结束，所有区域均被着色为红色或绿色。如果不存在这样的链，那么可以从 `R1` 开始的所有红-绿区域链中的两种颜色互换。然后我们可以回到地图 `M`，此时红色可供 `R` 使用。也就是说，地图 `M` 可以用四种颜色着色，产生矛盾。但如果地图包含一条从 `R1` 开始到 `R3` 结束的红-绿区域链会怎样？（参见 图 16.3，其中 r, b, g, y 分别代表红色、蓝色、绿色、黄色。）那么互换红色和绿色对我们没有好处。然而，在这种情况下，不可能存在一条从 `R2` 开始到 `R4` 结束的蓝-黄区域链。在这种情况下，可以从 `R2` 开始的所有蓝-黄区域链中的颜色可以互换。回到 `M`，我们看到蓝色现在可供 `R` 使用，这再次表明 `M` 可以用四种颜色着色并产生矛盾。

因此，如果 `R` 被四个或更少的相邻区域包围，坎普的证明涉及使用在两种颜色之间交替着色的区域链，然后在适当时候互换这些颜色，从而得到 `M`（减去 `R`）区域的四色着色，使得 `R` 的相邻区域最多使用这三种颜色中的三种，从而为 `R` 留出一个可用的颜色。事实上，这些区域链后来被称为坎普链。

然而，仍有一个案例需要解决，即地图中没有区域被四个或更少的相邻区域包围的情况。正如我们指出的，此时地图必须包含某个被……包围的区域 `R`

恰好有五个相邻区域。至少必须使用四种颜色中的三种来为围绕 `R` 的五个相邻区域着色。如果只使用三种颜色来为这五个区域着色，那么 `R` 将有一种可用的颜色。因此，我们只剩下这种情况：所有四种颜色都被用来为围绕 `R` 的五个相邻区域着色（参见图 16.4），其中 `r`、`b`、`g`、`y` 再次分别代表红色、蓝色、绿色和黄色。在这种情况下，`R` 的两个相邻区域被染成了蓝色。

![](img/598a6ae3fd44120830ada34717906f29_431_0.png)

坎普按照以下步骤处理这一最后情况。在 `R` 的相邻区域中，只有区域 `R1` 是黄色的。考虑地图 `M` 中所有被染成黄色或红色，且从 `R1` 开始可以通过交替的相邻黄色和红色区域（即通过黄-红坎普链）到达的区域。如果区域 `R3`（即被染成红色的 `R` 的相邻区域）无法通过从 `R1` 开始的黄-红坎普链到达，那么我们可以交换 `M` 中所有能通过从 `R1` 开始的黄-红坎普链到达的区域内黄色和红色的颜色。这将导致 `M` 中所有区域（除 `R` 外）的一种着色方案，其中相邻区域颜色不同，且 `R` 的每个相邻区域都被染成红色、蓝色或绿色。然后我们可以将 `R` 染成黄色，从而得到整个地图 `M` 的四色着色。由此，我们可以假设区域 `R3` 可以通过从 `R1` 开始的黄-红坎普链到达。（参见图 16.5。）

![](img/598a6ae3fd44120830ada34717906f29_432_0.png)

图 16.5：地图 `M` 中的黄-红坎普链

考虑被染成绿色的区域 `R5`。我们考虑 `M` 中所有被染成绿色或红色，且从 `R5` 开始可以通过绿-红坎普链到达的区域。如果区域 `R3` 无法通过从 `R5` 开始的绿-红坎普链到达，那么我们可以交换 `M` 中所有能通过从 `R5` 开始的绿-红坎普链到达的区域内绿色和红色的颜色。执行此操作后，可以得到 `M` 中所有区域（除 `R` 外）的一种四色着色，其中 `R` 的每个相邻区域都被染成红色、蓝色或黄色。然后我们可以将 `R` 染成绿色，从而得到整个地图 `M` 的四色着色。因此，我们可以假设 `R3` 可以通过从 `R5` 开始的绿-红坎普链到达。

（参见图 16.6。）

![](img/598a6ae3fd44120830ada34717906f29_432_1.png)

图 16.6：地图 `M` 中的黄-红和绿-红坎普链

由于存在由 `R` 和一条绿-红坎普链组成的区域环，因此 `M` 中不存在一条从 `R4` 开始并终止于 `R1` 的蓝-黄坎普链。此外，由于存在由 `R` 和一条黄-红坎普链组成的区域环，因此 `M` 中也不存在一条从 `R2` 开始并终止于 `R5` 的蓝-绿坎普链。因此，我们交换 `M` 中所有能通过从 `R4` 开始的蓝-黄坎普链到达的区域内蓝色和黄色的颜色，并交换 `M` 中所有能通过从 `R2` 开始的蓝-绿坎普链到达的区域内蓝色和绿色的颜色。完成这两次颜色交换后，`R` 的五个相邻区域每一个都被染成红色、黄色或绿色。然后可以将 `R` 染成蓝色，从而得到地图 `M` 的四色着色，证明完毕。

结果证明，坎普给出的这个证明包含了一个致命缺陷，但这一缺陷在十年间都未被察觉。尽管坎普对四色问题的尝试证明是错误的，但他在文章中做出了一些有趣的观察。他注意到，如果在地图上放置一张描图纸，在地图上每个区域的上方标记一个点，并在相应区域具有共同边界时用一条线段连接两个点，那么就会生成一个“链接”（linkage）的图。此外，确定地图的区域是否能用四种颜色着色使得相邻区域颜色不同的问题，等同于确定链接中的点是否能用四种颜色着色使得由线段连接的每两个点颜色不同的问题。（参见图 16.7。）

![](img/598a6ae3fd44120830ada34717906f29_433_0.png)

1878年，James Joseph Sylvester 将链接称为图（graph），这一术语后来成为标准用语。后来，人们通常将链接中的点和线称为图的顶点和边。由于以这种方式从地图构建的图（被称为地图的平面对偶或对偶图）本身可以在平面内绘制且没有两条边（线段）相交，因此生成的图是平面图。在图的术语下，四色猜想可以重新表述。

### 四色猜想
每个平面图都是可四色着色的。

### Percy John Heawood

四色问题历史中的下一位重要人物是 Percy John Heawood（1861–1955），他在 1887–1939 年间在英国杜伦学院担任讲师、教授和副校长。当 Heawood 于 1880 年在牛津大学就读时，他的老师之一是 Henry Smith 教授，后者经常谈论四色问题。Heawood 阅读了坎普的论文，正是他发现了证明中严重的错误。

1889年，Heawood [125] 撰写了一篇自己的论文，该论文于 1890 年发表，其中展示了图 16.8 中所示的地图。
