## 语言处理

尽管许多广泛使用的编程语言被编译成机器指令，但某些语言是解释执行的。当计算机程序被解释时，它直接由另一个称为解释器的程序执行，而不需要被翻译成低级的机器可执行指令。某些语言同时通过两种方式处理；例如，`Java` 程序首先编译成中间语言的等效程序，然后由解释器执行。

## 实现

在此阶段，在问题解决阶段开发的伪代码将用编程语言表示。编程语言分为：低级语言，人类易于理解但物理计算机无法直接识别；以及高级语言，物理计算机易于识别。目前大多数程序是用高级语言编写，然后翻译成低级语言的等效程序。计算机执行这些指令。翻译器本身是一个复杂的计算机程序，称为编译器。参见数字计算机，`[S.C.H.]`。

## 计算机安全

确保计算机及其程序、硬件和数据的机密性、完整性和可用性的过程。安全的缺失源于这些属性中一个或多个的失效。机密性缺失会导致数据未经授权的泄露，完整性会导致计算系统未经授权的修改或损坏。计算资源可用被称为拒绝服务。

> /*函数 `god` 计算两个整数的最大公约数，并将结果作为其输入值返回*/

```
int god(int x, int y) {

    while (x > 0 && y > 0) {

        if (x > y)

            x = x % y;

        else

            y = y % x;

    }

    return y;

}
```
