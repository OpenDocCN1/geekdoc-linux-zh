以下是实现过程的描述:

SAR算术右移[11]，算术右移31是带符号的操作。有符号的最高有效位MSB就是符号位。也就是说，如果MSB的值为1（原始数是负数），那么右移31位后，不管原来的数是什么，得到的结果都是`0xffffffff`。如果MSB的值为0（原始数是正数或零），那么最后的结果就会零。执行完SAR，返回被存储在`EDX`寄存器中。`XOR`指令（寄存器），`.0xffffffff`，相当于位求非的逻辑或运算；由于这条指令就变成了完成补码法（加一）运算；由于SUB的指令就是减一（加一）运算，得到绝对值，因为此时`EDX`寄存器的值是`0xffffff`——十进制的“-1”。有两个操作的逻辑运算和递减运算，请参阅本书第30章。

因此，当操作是负数的时候，最后两条运算指令会对源操作进行处理。在符号位的值为零、零零和正数的情况下，最后两条指令不会调整源操作的值。

有关于本例的详细细节，请调查参考书籍[War02, pp. 2-4]的相关介绍。GCC或许鉴了现有的成熟算法，或许这它是自己推演的计算结果。

## 第46章 变长参数函数

像`printf()`和`scanf()`类的函数可以处理不同数量的输入参数。这种函数又是如何访问参数的呢？

### 46.1 计算术平均值

如果编写一个计算术平均值的函数，那么就需要函数的参数声明部分指定所有的外部参数。但是C/C++的变长参数函数却无法先知道外部参数的数量。为了方便起见，我们用“-1”作为最后一个参数其他参数的结束符。

C语言标准函数的头文件`stdarg.h`定义了变长参数的处理方法（宏）。刚才提到的`printf`函数和`scanf()`函数都使用了这个文件提供的宏。

```c
#include <stdio.h>
#include <stdarg.h>
int arith_mean(int v, ...)
{
    va_list args;
    int sum=0, count=1, i;
    va_start(args, v);
    while(1)
    {
        i=va_arg(args, int);
        if (i==-1) // terminator
            break;
        sum=sum+i;
    }
```

```c
count++;
}
    va_end(args);
    return sum/count;
};
int main()
{
    printf("%d\n", arith_mean (1, 2, 7, 10, 15, -1 /* terminator*/));
}
```

变长参数函数按照常规函数参数的方法从外部传来的第一个参数。后，借助`stdarg.h`提供的`var_arg`宏调用其剩余参数，依次求得各参数之和，最终计算其平均值。
