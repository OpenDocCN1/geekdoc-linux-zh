## 第 17 章 在 `VIZ` 中使用其他 `Autodesk` 应用程序

在完成首次链接后，可以在此下拉列表中设置选项。如果您不想费心命名保存预设设置，只想按照上次的方式链接 `DWG` 或 `DXF` 文件，则可以选择“上次使用的设置”（`Last Used Settings`）。

“选择层包含”（`Select Layers Include`）会打开“选择层”对话框，允许您选择或取消勾选可能包含或排除在链接中的层。

“附加文件”（`Attach File`）按钮允许您将 `AutoCAD DWG` 或 `DXF` 文件附加到 `VIZ` 场景中。可以从 `12` 到 `2008` 版本的 `AutoCAD`、`AutoCAD Architecture`、`AutoCAD Mechanical` 和 `Revit` 文件。如果您使用的是 `AutoCAD` 以外的 `CAD` 程序，可以使用 `DXF` 文件格式代替 `DWG` 格式，尽管许多 `CAD` 程序已直接支持 `DXF` 文件格式。

## 使用对象启用器（`OBJECT ENABLERS`）

许多 `Autodesk` 产品（包括 `AutoCAD Architecture` 和 `AutoCAD Mechanical`）需要安装“对象启用器”（`Object Enablers`）才能正确导入对象。要找到需要安装的正确启用器，请访问 `www.autodesk.com` 并搜索“`Object Enabler`”。在尝试导入或链接相关文件时，如果缺少对象启用器，会出现“检测到代理对象”（`Proxy Object detected`）对话框。在存在启用器的情况下，您仍然可以使用图纸；但相关的几何结构可能无法正确进入 `VIZ`。

## 文件选项卡（`THE FILES TAB`）

“文件”选项卡允许您控制文件如何链接到 `VIZ` 文件。

正如您在之前的练习中看到的，“重新加载”（`Reload`）选项允许您手动重新加载已重链的 `AutoCAD` 文件。如果您勾选了“显示重载选项”（`Show Reload Options`）复选框，点击此按钮时会显示“文件链接设置”对话框。

“分离”（`Detach`）会从当前 `VIZ` 场景中移除链接的文件。请谨慎使用此选项，因为即使对象在 `VIZ` 中经过了修改，它也会删除场景中所有链接对象。

“绑定”（`Bind`）选项会移除与源 `AutoCAD` 文件的任何链接，同时保留当前 `VIZ` 场景中的对象。`VIZ` 场景将变成一个独立的场景文件，不再受源 `AutoCAD` 文件的影响。

### 绑定链接文件消除互操作性

绑定之前的链接会增加您的文件大小，因为当它们之间的链接断开时，数据将从 `CAD` 迁移到 `VIZ`。此操作需谨慎进行，因为在 `CAD` 文件中进行的更改将不再影响 `VIZ` 场景。

最后，“文件”选项卡显示当前链接到 `VIZ` 场景文件的 `AutoCAD DWG` 和 `DXF` 文件列表。文件名旁边的图标指示了链接文件的状态：

- 回形针表示源文件未更改，且链接无错误。
- 问号表示找不到文件。
- 红色旗帜表示文件自导入以来已发生更改，必须使用“重新加载”按钮重新加载。
- 灰色的页面表示通过其他路径选择了不同的文件。
- 弯箭头表示该文件已开启“动态”（`Dynamic`）选项。

## 预设选项卡（`THE PRESETS TAB`）

您在之前的练习中已经看到了如何创建预设，预设决定了文件链接时的设置。“预设”选项卡还允许您通过“修改”（`Modify`）按钮修改现有预设，或重命名或删除现有预设。当您创建预设时，它将作为“附加”（`Attach`）选项卡中预设下拉列表中的选项出现。您将在下一节中学习更多关于实际预设设置的信息。

## 理解文件链接设置

当您导入链接的 `AutoCAD` 文件时，您可以通过“文件链接设置”对话框控制文件的导入方式。当您选择文件进行链接时，此对话框默认显示，但您可以通过取消勾选“文件链接管理器”对话框“文件”选项卡中的“显示重载选项”复选框来设置 `VIZ` 避免出现。

正如您在之前的练习中所看到的，在“文件链接设置”对话框中选择的选项对结果有巨大影响。由于 `AutoCAD` 和 `VIZ` 使用不同的数据组织方式，因此此对话框对于理解 `DWG` 文件如何转换是必要的。所有链接的 `AutoCAD` 对象都会转换为链接几何体（`Linked Geometry`）或 `VIZ blocks`，只有当您选择通过“层”、“实体”、“颜色”或“单个对象”派生 `AutoCAD` 原型时才会发生这种情况。

例如，`AutoCAD` 文件中位于层 `0` 的对象会被收集到单个 `VBlock` 中。`VBlock` 的名称取决于您在“文件链接设置”对话框中选择的设置。在较早的练习中，您在“文件链接设置”框的“通过...派生 AutoCAD 原型”下拉列表中选择了“层”选项。然后，您可以通过层、厚度和颜色的组合来细化 `VIZ` 组合对象的方式，或者让 `VIZ` 将每个 `AutoCAD` 对象作为 `VIZ` 中的单个对象导入。

在大多数情况下，您可能会选择使用“文件链接设置”对话框中的其中一个“块”（`Blocks`）作为节点级结构对象来派生您的 `AutoCAD` 原型，因为使用这些选项可以让您处理这些块的方式得到改进。因此，`VIZ` 中的对象通常是“链接几何体”节点。

链接几何体节点在命令面板的“修改”选项卡上只有一个参数：“重置位置”（`Reset Position`）按钮。当您想将节点恢复到其在链接 `DWG` 或 `DXF` 文件中的位置时，点击“重置位置”。您应用到链接几何体节点的任何变换都仅存储在 `VIZ` 中，`VIZ` 绝不会覆盖您的 `AutoCAD` 文件。

## 避免系统不稳定

由于链接几何体与外部文件连接，您在处理链接几何体时可能需要避免几种情况。如果将链接几何体包含在组或装集中、将其附加到可编辑网格或可编辑多边形、更改动画控制器、创建层级链接或创建链接几何体的实例克隆，可能会发生系统不稳定。然而，您可以放心地复制许多克隆并对链接几何体应用变换和材质，而不会出现问题。
