## 密码未导出的测试示例

```bash
密码为 bonehead

```

> **警告** 正如你所见，极其重要的是千万不要导出密码变量

要将此变量替换到你的 shell 脚本中，你只需要使用唯一的变量名将密码添加到环境变量文件中。然后在需要密码的 shell 脚本内部执行密码文件（在本例中为 `setpasswd.ksh`）。密码文件执行后，密码变量（们）可以使用。

> **注意** 前述将此技术用于密码；然而，这种做法也适用于用户名、主机名和应用程序变量。

## 自动化 FTP 操作 457

点符号（dot）表示执行其其后的文件名。现在让我们设置密码环境变量文件。此示例假设用户为 `root`。

```bash
echo "RANDY=mypassword" >> /usr/sbin/setlink.ksh

chown 400 /usr/sbin/setlink.ksh
```

现在，在我们的每个脚本中，我们需要点运行 `/usr/sbin/setlink.ksh` 文件，并将硬编码的密码替换为外部文件 `/usr/sbin/setlink.ksh` 中的密码变量，在我们例中该变量是 `$RANDY`。
列表 17.11、17.12 和 17.13 显示了修改后的硬编码密码后的 shell 脚本。

```bash
#!/bin/ksh

#
# 脚本: get_remote_dir_listing_pw_var.ksh
## 作者: Randy Michael
# 日期:2002年7月15日
# 版本: 1.1.P
#
# 平台:不依赖平台
# 目的：此 shell 脚本使用 FTP 获取远程目录列表
# 并将列表保存在本地文件中。此 shell 脚本使用了
# 远程定义的密码。
# set -n # 取消注释以检查脚本语法而不执行
# set -x # 取消注释以调试此 shell 脚本
############################################################################
################在此定义变量 #################
############################################################################

RNODE="wilma"
USER="randy"
LOCALDIR="/scripts/download"
DIRLISTFILE="$LOCALDIR/$($RNODE).$(basename $REMOTEDIR)).dirlist.out"
cat /dev/null >$DIRLISTFILE
############################################################################
################ 主程序开始 #################################################
############################################################################
## 获取密码
```

在列表 17.11 中，我们对原始 shell 脚本的唯一修改包括更改脚本名称、删除硬编码密码、添加执行 `/usr/sbin/setlink.ksh` shell 脚本，以及添加远程定义的密码变量 `$RANDY$`。
