反射定律规定了辐射的平面波。反射定律涉及入射光和反射光（例如手电筒的光束，或更准确地说，入射波和反射波的法线）。该定律规定入射光和反射光垂直于反射面，且反射角等于入射角，如等式（1）所示（见图）。

```
θ_i = θ_r
```

θ_i 和 θ_r 分在表面与入射光、反射光之间测量。反射（在上述示例中镜面的反射）是光滑的，表面不规则程度小于辐射的波长。相比之下，当表面粗糙时，反射是漫反射的。一个例子是屏幕或白墙的漫反射散射，光通过一系列角度进行反射。

表面的反射率是反射的辐射量。它定义为入射辐射和反射辐射强度之比。反射率取决于入射角、入射辐射的偏振以及构成边界面的材料的电磁性质。反射性质通常随辐射波长的而改变。

抛光金属表面的反射率通常很高。银和铝可以反射高达 90% 的可见光。在普通镜子中，反射面是金属与玻璃之间的界面，它受到氧化、污垢和其他形式退化的保护。

# 再生（生物学）

动物恢复其丢失身体部位的方式。身体可以经历伤口愈合、组织修复和许多活动。系统中的大多数再生涉及通过一系列事件替换复杂结构或器官的主要部分，从而产生一个完美复制缺失部分的结构。

最为人知且研究最充分的再生例子是后生再生（epimorphosis），在整个动物界中通过增殖细胞的爆发直接复制丢失的结构。对再生系统的研究提供了有关动物发育机制的信息，以及控制结构发育（如脊椎动物）中模式形成的因素。

哺乳动物、鸟类和爬行动物不像两栖动物和鱼类那样具有再生复杂的能力，但在器官部分移除后仍形成组织并修复。例如，如果切除肝，剩余细胞将生长以补偿丢失的组织并恢复器官的正常功能。肝脏再生的过程涉及触发肝细胞（cell cells）的生长，这些细胞在正常肝脏中通常处于静止状态。这些细胞的增殖及其不同的分化导致了丢失肝质量的恢复和充足的肝功能。
