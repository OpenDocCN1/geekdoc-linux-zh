## 9.3 FastCGI

FastCGI 是通用网接口（CGI）的扩展，适用于应用服务器和 Web 服务器。Web Server 7.0 中的 FastCGI 是通过插件实现的。以下内容描述了 FastCGI 的主要方面：

- FastCGI 消除了像 CGI 为每个请求创建进程的开销。FastCGI 应用独立于 Web 服务器运行。
- FastCGI 允许在 Web 服务器上维护状态，如缓存。
- FastCGI 使用 TCP 套接字或 UNIX 套接字连接远程计算机。Web 服务器与 FastCGI 应用之间使用单向连接，而不是像 CGI 那样使用独立的管道（标准输入、输出和标准错误）。
- FastCGI 应用可分为三个定义的角色：响应者（Responder）、授权者（Authorizer）和过滤器（Filter）。响应者接收 HTTP 请求并生成 HTTP 响应。授权者根据 HTTP 请求信息生成 HTTP 授权响应。过滤器应用使用存储在 Web 服务器上的文件作为 HTTP 请求数据，并生成过滤后的数据。

有关 FastCGI 的更多信息，请参考《FastCGI 规范 1.0》。

### 9.3.1 FastCGI 配置

Web Server 7.0 对 FastCGI 的支持通过 NSAPI 插件实现。FastCGI 插件位于 Web Server 7.0 安装目录 `plugins/fastcgi`。该目录下还包含一个名为 `fastcgi` 的可执行文件，插件使用它来管理 FastCGI 应用的生命周期。配置 Web Server 的 FastCGI 插件包括：

- 配置 Web Server 加载插件
- 指定与 FastCGI 应用关联的扩展
- 配置虚拟服务器的 URI 空间以启用 FastCGI 请求处理
