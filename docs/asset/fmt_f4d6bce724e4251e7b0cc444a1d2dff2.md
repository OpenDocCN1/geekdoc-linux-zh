## 使用 less 查看文件内容

在整个 Linux 系统中，许多文件以文本格式存储，并且有许多 Linux 工具可以处理文本文件。即使 Windows 也意识到这种格式的重要性。著名的 `NOTEPAD.EXE` 程序是纯文本的编辑器。

一旦启动，`less` 程序允许我们向前和向后滚动文本文件。例如，要查看定义所有系统用户账户的文件，输入以下命令：

```
[linuxbox] less /etc/passwd
```

## 什么是“文本”？

有很多方法可以表示信息。计算机终究只理解数字。

有些表示方法是复杂的（例如压缩视频文件），而另一些是简单的。`ASCII`（读作 "as-key"）是美国标准交换代码的缩写。这是一种最初用于电字机的编码方案，用于将字符转换为数字。

文本是字符与数字的简单一一映射。五十个字符对应对应 50 个字节的数据。重要的是，文本只包含简单的数字映射。它与 Microsoft Word 或 LibreOffice Writer 创建的文字文档不同。相反，后者包含许多用于描述结构和格式的非文本元素。纯文本只包含字符本身以及一些基本的控制代码，如制表符、回车和换行符。

在整个 Linux 系统中，许多文件以文本格式存储，并且有许多 Linux 工具可以处理文本文件。即使 Windows 也意识到这种格式的重要性。

在普通配置下，每个用户都会获得一个 `/home` 下的目录。普通用户只能在自己的家目录下写入文件。这种限制保护了系统免受误操作用户活动的影响。

- `/lib` 包含核心系统程序使用的共享库文件。这些文件类似于 Windows 中的动态链接库 (`DLLs`)。在现代发行版中，该目录已被废弃，取而代之的是 `/usr/lib`。
- `/lost+found` 每一个使用传统 Linux 文件系统（如 `ext4`）的格式化分区或设备都会有这个目录。它用于在文件系统损坏事件发生后进行部分恢复。除非我们的系统发生了非常糟糕的问题，否则此目录将保持为空。
- `/media` 在现代 Linux 系统上，`/media` 目录将包含可移动介质（如 USB 驱动器、CD-ROM 等）的挂载点，这些介质在插入时会自动挂载。
- `/mnt` 在旧版本的 Linux 系统上，`/mnt` 目录包含手动挂载的设备挂载点。
- `/opt` `/opt` 目录用于安装“可选”软件。这些软件可能被安装在系统中。
- `/proc` 是特殊的。它并不是意义上存储在硬盘上的文件的真实文件系统。相反，它是由 Linux 内核维护的虚拟文件系统。它包含的“文件”是窥视内核的窗口。这些文件是可读的，并将向我们展示内核的视角。浏览此目录可以揭示关于计算机硬件的许多细节。
- `/root` 这是 `root` 账户的家目录。
- `/run` 这是传统 `/tmp` 目录的现代替代品（参见 `/tmp` 条目）。与 `/tmp` 不同，`/run` 目录使用 `tmpfs` 文件系统挂载，将其内容存储在内存而非物理磁盘上。
- `/sbin` 此目录包含“系统”二进制文件。这些程序用于执行关键任务，通常预留给超级用户。请注意，现代 Linux 发行版已废弃 `/sbin`，改用 `/usr/sbin`（参见 `/usr/bin` 条目）。
- `/sys` `/sys` 目录包含内核检测到的设备信息。这与 `/dev` 目录的内容相似，但更详细，包含了实际的硬件地址等信息。
- `/tmp` `/tmp` 目录用于存储各种程序创建的临时、瞬态文件。某些发行版每次系统重启时都会清空此目录。
- `/usr` 目录树可能是 Linux 系统上最大的一个。它包含了普通用户使用的所有程序和支持文件。
- `/usr/bin` 包含由 Linux 发行版安装的可执行程序。该目录包含成千上万个程序并不罕见。
- `/usr/bin` 中程序的共享库。
- `/usr/local` 树用于安装未包含在发行版中但供系统使用的程序。从源代码编译的程序通常安装在 `/usr/local/bin` 中。在新安装的 Linux 系统上，此树存在，但在系统管理员向其中放入内容之前，它将是空状态。
- 包含更多系统管理程序。
- `/usr/share` 包含 `/usr/bin` 中程序使用的所有共享数据。这包括默认配置文件、图标、屏幕背景、声音文件等。
- 系统中的大多数软件包都会包含某种类型的文档。在 `/usr/share/doc` 中，我们可以找到按包组织的的文档文件。

除了 `/tmp` 和 `/home`，我们目前观察过的目录仍然保持相对静态；也就是说，它们的内容不会改变。`/var` 目录树是可能存储变化数据的地方。各种数据库、打印池文件、用户邮件等都位于此处。

- `/var/log` 包含各种系统活动的记录文件。这些文件非常重要，应该定期进行监控。最有用的是 `/var/log/messages` 和 `/var/log/syslog`，尽管这些在所有系统中并不可用。请注意，出于安全考虑，某些系统只允许 `root` 查看日志文件。
- 这些目录位于每个桌面用户的家目录下。它们被用于存储特定的配置。

## 符号链接 (Symbolic Links)

当我们查看时，可能会看到符号链接（例如在 `/usr/lib` 目录中），如下所示：

```
lrwxrwxrx 1 root root 12 May 1 12:00 libc.so.6 -> libc.so.6
```

注意权限位中的 `l` 表示这是一个符号链接。符号 `->` 指明它指向的文件。符号链接是可读的，并将向我们展示内核的视角。浏览此目录可以揭示关于计算机硬件的许多细节。

符号链接也被称为软链接 (`softlink`)。在大多数 Linux 系统中，符号链接允许文件拥有多个名称，但它们的实现方式不同。

当我们讨论链接的主题时，我们需要提到还有另一种类型的链接叫做硬链接 (`hard link`)。硬链接也允许文件有多个名称，但它们的操作方式不同。我们将在下一章详细介绍符号链接和硬链接之间的区别。

## 通配符

在我们开始使用命令之前，我们需要讨论一种让这些命令如此强大的 Shell 特性。由于 Shell 频繁使用文件名，它提供了一些特殊字符来帮助我们快速指定一组文件名。这些特殊字符被称为通配符（wildcards）。使用通配符（也称为 `globbing`）允许我们根据字符模式来选择文件名。表 4-1 列出了通配符及其它们选择的内容。

| `?` | 匹配任意单个字符 |
| `[characters]` | 匹配属于 `characters` 集合的任意字符 |
| `[characters]` 或 `[^characters]` | 匹配不属于 `characters` 集合的任意字符 |
| `[[:class:]]` | 匹配属于指定类中的任意字符 |

## 通配符在 GUI 工具中工作

通配符之所以非常有价值，不仅是因为它们在命令行中被频繁使用，还因为某些图形化文件管理器支持它们。

- 在 `Nautilus`（GNOME 管理器）中，你可以通过按下 `CTRL-S` 并输入带有通配符的文件选择以及当前目录中的文件来选择文件。
- 在某些版本的 `Dolphin` 和 `Konqueror`（KDE 的文件管理器）中，你可以直接在位置栏输入通配符。例如，如果你想查看 `/usr/bin` 目录下所有以小写字母 `u` 开头的文件，在位置栏输入 `/usr/bin/u*`，它将显示结果。
- 在 `Dolphin`（KDE 文件管理器）中，有一个 `Filter`（过滤器）选项可以使用通配符选择。例如，如果你想查看 `/usr/bin` 目录下所有以小写字母 `u` 开头的文件，在过滤器提示符中输入 `/usr/bin/u*`，它将显示结果。

许多最初在命令行界面中的想法也进入了图形界面。这是让 Linux 桌面如此强大的因素之一。

通配符可以用于任何接受文件名作为参数的命令，但我们将在第 7 章中详细讨论。

## 隐藏文件

如果我们使用 `ls -a` 选项查看主目录，我们会注意到有很多以点（`.`）开头的文件和目录。正如讨论过的，这些文件是隐藏的。这并不是文件的特殊属性；它意味着除非包含 `-a` 或 `-A` 选项，否则该文件不会出现在 `ls` 的输出中。这种隐藏特性也适用于通配符。除非我们使用如 `*.` 这样的通配符模式，否则隐藏文件不会出现。然而，在某些情况下（取决于 shell 的配置），我们可能在结果中同时看到 `.`（当前目录）和 `..`（上级目录）。为了排除它们，可以使用模式 `..{1}*` 或 `..?`。

## 字符范围

如果你来自其他 Unix 类环境或读过关于此主题的其他书籍，你可能会遇到 `[A-Z]` 和 `[a-z]` 字符范围表示。这些是传统的 Unix 表示，在旧版本的 Linux 中也有效。它们仍然可以工作，但你必须非常小心，因为除非配置得当，否则它们不会产生预期的结果。目前，你应该避免使用它们并改用字符类。

## mkdir—创建目录

`mkdir` 命令用于创建目录。它的用法如下：

```
mkdir directory...
```

注意，当命令描述（此处所示）中的参数后面跟着三个点时，意味着该参数可以重复。因此，以下命令将创建一个名为 `dir1` 的目录：

```
mkdir dir1
```

而以下命令将创建三个名为 `dir1`、`dir2` 和 `dir3` 的目录：

```
mkdir dir1 dir2 dir3
```

## cp—复制文件和目录

`cp` 复制文件或目录。它有两种用法。以下命令将单个文件或目录 `item1` 复制到文件或目录 `item2`：

```
cp item1 item2
```

而以下命令将多个项目（文件或目录）复制到一个目录：

```
cp item... directory
```

## mv—移动和重命名文件

`mv` 命令执行文件的移动和重命名，取决于它的使用方式。在任何情况下，操作后原始文件名都不再存在。`mv` 的用法与 `cp` 相似，如下所示，将文件或目录 `item1` 移动或重命名为 `item2`：

```
mv item1 item2
```

或将多个项目从一个目录移动到另一个目录：

```
mv item... directory
```
