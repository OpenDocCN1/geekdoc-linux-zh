## 基于磁盘的劫持

劫持服务的第二变体涉及替换磁盘上的服务二进制文件。在这种情况下，注册表的 `ServiceDll` 仍然指向相同的路径，但文件内容已经更改。这通常按以下步骤发生：

- 1. 查询注册表获取目标服务二进制文件的路径。
- 2. 移动或删除原始文件。
- 3. 在原始文件的相同路径创建一个新文件。
- 4. 重启服务（或等待重启）。
