
# 术语表

## PS/2 鼠标
PS/2 鼠标（用于较新的 PC 和大多数笔记本电脑）具有自己的端口，并使用 IRQ 12。PS/2 鼠标使用 6 针迷你 DIN 接器，并使用 PS/2 协议进行通信。PS/2 鼠标的设备文件为 `/dev/psaux`。

## QNX
一种来自 QNX Software Systems 的操作系统，使用的内存更少，响应速度更快。

## 查询模式
通过使用 RPM（红帽软件包管理器）查询模式，你可以确定系统上安装了哪些软件包，或者哪个文件属于特定的软件包。如果你想找到属于某个软件包的文件，这会有很大帮助。查询模式还可以用于在安装 RPM 文件之前识别其中包含哪些文件。这让你在文件实际写入系统之前就能看到哪些文件将安装到系统中。

## rc.sysinit
`rc.sysinit` 脚本运行几乎所有关键的依赖系统的启动操作。

## rdate
`rdate` 使用 TCP 通过端口 13 获取另一台机器的当前时间 (`ctime`)，如 RFC 868 所示。每个系统的时间以 `ctime` 格式返回（Sun Oct 17 20:36:19 1999）。`rdate` 的默认模式只是打印从请求服务器获取的日期。命令 `rdate www` 将返回本地子网中名为 `www` 的服务器的日期。

## 红帽硬件列表
红帽硬件列表针对所有在运行红帽 Linux 的系统上测试过的硬件。红帽将为任何列为“已支持”的硬件提供安装支持。还有一个“不支持”列表。这并不意味着指定的硬件将无法在 Linux 上运行；它只是意味着红帽不会为该硬件提供安装支持。

## 红帽软件包管理器 (RPM)
通过 RPM，软件以离散的“软件包”进行管理，软件包是构成软件的文件集合，以及添加、删除和升级这些文件的指令。RPM 还通过在覆盖现有文件之前备份现有文件，确保你永远不会丢失配置文件。RPM 还跟踪你的系统中当前安装了哪个版本的应用程序。RPM 的一个关键特性是可以使用统一资源定位符 (URL) 格式指定文件名。你可以在 RPM 调用文件名的任何地方使用这些格式。

## 廉价磁盘冗余阵列 (RAID)
一种常见于网络服务器的方法，使用软件配合几块硬盘工作，以确保数据的冗余和安全。

## 廉价磁盘冗余阵列零级 (RAID-0)
RAID-0 对硬盘的读写操作是并行进行的，这提高了性能，并在所有硬盘上填充相同的数据。此级别没有冗余性，因为任何一个驱动器的故障都会导致数据丢失。此级别用于提高速度。如果一个磁盘正忙碌，可以从另一个磁盘访问数据。RAID-0 系统的速度限制是连接到磁盘的总线速度。RAID-0 也称为“条带模式”。

## 廉价磁盘冗余阵列四级 (RAID-4)
此级别需要三个或更多块磁盘。与 RAID-0 类似，数据的读写是并行进行的，但必须有一个额外的磁盘来保存所有数据的校验位信息。如果一个驱动器故障，则可以使用校验信息来重建数据。可靠性得到了提高，但由于每次写入操作都会更新校验信息，校验磁盘可能会成为系统的瓶颈。

## 廉价磁盘冗余阵列五级 (RAID-5)
RAID-5 工作在三个或更多磁盘上，并带有可选的备用磁盘。通过此级别，多个磁盘可以同时提高性能和可靠性。与 RAID-4 类似，会记录数据的校验信息。然而，并不是专用一个磁盘来存储校验信息，而是将其均匀地分布在所有磁盘上。如果一个磁盘故障，可以将数据重建到备用磁盘上。

## 刷新率
这是屏幕上显示的图像重绘率。刷新率以赫兹 (`Hz`) 表示。60 Hz 的刷新率意味着图像每秒重绘 60 次。计算机显示器同时具有垂直和水平刷新率。某些被称为多同步显示器支持多个垂直和水平刷新率。

## 远程过程调用 (RPC)
由制造商联盟开发的软件工具，用于创建分布式应用的开发者，它可以自动为客户端和服务器生成代码。

## 反向区域
DNS 能够从地址转换为名称的区域。

## 路由器
根据发送站提供的地址，决定如何将消息从一个站传输到另一个站的最佳节点。与桥器不同，路由器处理包含特定协议的数据包或帧，并同时处理多个协议栈。路由器可以连接使用不同拓扑和协议的网络。

## 路由表
任何使用 Internet 系统的系统使用的规则列表。路由表用于确定将数据包发送到哪里。路由表中的每个项目至少包含三个字段。第一个字段是目标地址。如果数据包的目标地址与此匹配，第二个字段是发送数据包的接口。第三字段是可选的，包含路由器的地址。

## 服务器
为其他网络站提供打印机和通信服务的计算机。

## 服务器消息块 (SMB)
由微软开发并被许多供应商采用的网络协议，允许一台计算机像本地一样使用另一台计算机的文件。

## 会话感知
应用程序记住上次工作文档位置并在重启应用程序时将光标定位在该点的能力。

## 简单互联网协议+ (SIPP)
交换式兆比特数据服务 (SMDS) 接口协议，三个 Internet Protocol (Ip) 候选方案之一。

## 简单邮件传输协议 (SMTP)
美国国防部电子邮件系统标准，具有主机和用户选择。用户软件通常包含在传输控制协议/网际 (TCP/IP) 软件包中；主机软件可用于与专有系统交换 SMTP。

## Samba
从 Windows 3.11 开始，`Samba` 提供了 Windows 客户端和 Linux 系统之间的互操作性。系统提供基于 TCP/IP 的 SMB。

## 小型计算机系统接口 (SCSI)
`SCSI` 是一种完整的总线接口，接受硬盘、CD-ROM、磁盘驱动器、打印机或扫描仪。`SCSI` 比 (E)IDE 更快、更灵活，支持 7 或 15 个设备。数据传输速度为每秒 5 到 80MB。

## 软限制
这是用户在分区上允许的最大空间。如果你设置了宽限，这将作为界限阈值。用户将收到通知他们违反了配额。

## Sendmail
`Sendmail` 是由 Eric Allman 在 1979 年编写的免费程序。

## 顺序数据包交换 (SPX)
控制网络传输的 NetWare 通信协议。

## 线路协议 (SLIP)
工作站或个人电脑拨号建立 Internet 链路的标准，它定义了通过异步线路传输数据包的方式，使得不属于局域网 (LAN) 的计算机能够完全连接到互联网。

## 安全网络文件系统 (NFS)
自 1990 年以来，Sun 和其他供应商一直支持基于公密钥的强身份验证的 NFS 版本。Secure NFS 被证明管理非常繁琐且复杂，仍然不足以在敌对环境中保护数据。因此，Secure NFS 很少用于专门的政府机构。

Spec file
`spec` 文件控制软件包的构建方式，以及在从系统中安装或删除该包时执行的操作。`spec` 文件包含八个不同的部分。`spec` 文件存储在 `/usr/src/redhat/SPECS/<packagename>.spec`。

Squid
`Squid` 是一个高性能的 HTTP 和 FTP 缓存代理服务器。

startX
`startx` 命令用于从命令行提示符手动启动 X-Window 界面。

Static routes
静态路由是你手动输入到路由表中的条目。如果你的网络较小、网络配置不经常变更改，或者你的系统是静态的，那么静态路由足以管理你的路由配置。你使用 `route` 命令来管理静态路由。

Stripe mode
也称为独立独立磁盘冗余阵列零级 (RAID-0)。

Super Video Graphics Array VGA (SVGA)
`SVGA` 是 IBM 个人电脑视频图形显示标准 (VGA) 的增强版本，可以显示至少 800 像素水平和 600 行垂直，以及高达 1024 像素乘 768 行，并支持 16 色或 256 色；它可以使用多达 1MB 的显存。

Swap file
交换文件用于存储无法放入随机存储器 (RAM) 的指令和数据的文件。

swatch
`swatch` 工具监控日志文件中的特定类型消息，并在特定事件发生时采取行动。你可以配置监控器和要采取的操作类型。该操作可以是简单的向你的终端发送消息，也可以是更复杂的，如拨呼寻机号码。默认情况下，`swatch` 在你主目录下的隐藏文件 `.swatchre` 中查找配置信息。`swatch` 工具的包文件为 `swatch-2.2.7.rpm`。

switchdesk
`switchdesk` 是一个轻松将你的默认桌面从一个环境切换到另一个环境的实用。

Tape Archive (TAR)
一种用于归档文件的 Unix 工具，通常与 `compress` 工具配合使用。

TELNET
`TELNET` 是美国国防部的一种虚拟终端协议，用于终端设备和面向终端的进程之间的接口交互 (MIL-STD-1782)。

timeconfig
`timeconfig` 工具允许你设置时区。

Tmpwatch command
`tmpwatch` 命令 (`/usr/sbin/tmpwatch`) 用于删除删除在指定小时数内未被访问过的文件。正如其名所示，你通常在如 `/tmp` 和 `/var/tmp` 等目录上运行它。`tmpwatch` 命令是递归工作的，因此如果你在树中指定了顶层目录，`tmpwatch` 将搜索整个目录树寻找要删除的文件。

Token Ring
环形令牌是一种局域网 (LAN) 技术，在网络节点之间循环特殊消息（令牌），赋予它们传输权限。
