
# UNIX 命令与 Shell 编程

## 常用命令

### `uname` → 打印系统信息
```bash
uname          # 打印内核名称
uname -a       # 打印所有信息
uname -s       # 打印内核名称
uname -v       # 打印内核版本
uname -n       # 打印网络主机名
uname -r       # 打印内核版本
```

### `lock` → 锁定终端（Linux 2.0 内核中未实现）
```bash
lock           # 锁定 30 分钟
lock -50       # 锁定 50 分钟（锁定时间不超过 60 分钟）
```

### `script` → 将登录会话记录在文件中
```bash
script         # 记录到默认文件 "typescript"
exit           # 结束记录
script -a      # 追加到现有文件 "typescript"
script anoop   # 记录到文件 "anoop"
```

### `spell` 和 `ispell` → 拼写检查
```bash
spell <filename>    # 显示错误单词
ispell <filename>   # 显示错误并交互式纠正
```

### `factor` → 质因数分解
```bash
factor 30    # 输出: 2 3 5
```

### Vi 编辑器中的模式搜索
- `/unix` → 向后搜索 "unix"
- `?unix` → 向前搜索 "unix"

### `split` → 将文件分割成多个文件
默认每 1000 行分割一次。
```bash
split -5 f     # 每个文件 5 行，生成 xaa, xab ... 等文件
```

## 文件比较

### `cmp` → 比较两个文件
```bash
cmp f1 f2      # 显示第一处差异：字节编号和行号
cmp -l f1 f2   # 列出所有不同字符的字节编号和八进制值
```

### `comm` → 查找共同部分
```bash
comm f1 f2                 # 三列输出：仅在 f1、仅在 f2、两者共有
comm -1 f1 f2              # 抑制仅在 f1 中的行
comm -2 f1 f2              # 抑制仅在 f2 中的行
comm -3 f1 f2              # 抑制两者共有的行
comm -12 f1 f2             # 仅显示共有行
```

### `diff` → 查找差异
```bash
diff f1 f2                 # 默认格式
diff -a f1 f2              # 视为文本比较
diff -B f1 f2              # 忽略空行插入/删除
diff -b f1 f2              # 忽略空白字符数量变化
```

**diff 输出格式说明：**
- `0a1`     → 在第 0 行后追加内容 `>abc`
- `2c3,4`   → 修改第 2 行，替换为第 3-4 行 `<c` `>cde` `>dfg`
- `4d5`     → 删除第 4 行 `<ceo`

## 模式匹配（通配符）
| 符号 | 含义 |
|------|------|
| `*`  | 零或多个字符 |
| `?`  | 单个字符 |
| `[abc]` | 匹配 a、b、c 中任一字符 |
| `[a-z]` | 匹配 a 到 z 任一字符 |
| `[!abc]` | 匹配非 a、b、c 的字符 |

## 重定向

### 标准流
| 编号 | 名称 | 默认设备 | 重定向符号 |
|------|------|----------|------------|
| 0    | 标准输入 (stdin) | 键盘 | `<` |
| 1    | 标准输出 (stdout) | 终端 | `>` / `1>` |
| 2    | 标准错误 (stderr) | 终端 | `2>` |

### 示例
```bash
cat aa > fl           # 标准输出重定向到 fl
cat aa 2> fl          # 标准错误重定向到 fl
cat aa 2>/dev/null    # 丢弃错误信息
cat aa 2>/dev/tty     # 错误信息输出到终端
```

### 管道 (`|`)
将左侧命令的标准输出连接到右侧命令的标准输入。
```bash
cmd1 | cmd2
```

### `tee` → 同时输出到文件和标准输出
```bash
cmd | tee file        # 输出到文件和屏幕
cmd | tee -a file     # 追加模式
```

```bash

```

## 文本处理命令

### `tail` → 显示文件尾部
```bash
tail -n 10 file       # 最后 10 行
tail -c 20 file       # 最后 20 字节
tail -f file          # 实时跟踪（日志常用）
tail +5 file          # 从第 5 行开始显示
tail -v file          # 显示文件名头部
tail -q file          # 不显示文件名头部
```

### `cut` → 垂直切割（按列/字段）
```bash
cut -c 1-4,5,17- file     # 按字符位置切割
cut -d '|' -f 1,3- file   # 按分隔符切割字段
cut -b 1-10 file          # 按字节切割
```

### `paste` → 合并文件行
```bash
paste file1 file2         # 制表符合并
paste -d ':' file1 file2  # 指定分隔符
paste -s file1 file2      # 串行合并（先文件1所有行，再文件2）
```

### `sort` → 排序
```bash
sort file                 # 默认字典序
sort -r file              # 逆序
sort -f file              # 忽略大小写
sort -n file              # 数值排序
sort -t ':' -k 3 file     # 按第 3 字段排序
sort -u file              # 去重
sort -m file1 file2       # 合并已排序文件
sort -c file              # 检查是否已排序
```

## 正则表达式与 Grep 家族

### 基本正则表达式 (BRE)
| 元字符 | 含义 |
|--------|------|
| `.`    | 任意单字符 |
| `*`    | 前项 0 次或多次 |
| `^`    | 行首 |
| `$`    | 行尾 |
| `[abc]` | 字符集合 |
| `[^abc]` | 非字符集合 |
| `\(...\)` | 分组 |

### 扩展正则表达式 (ERE) - `egrep` / `grep -E`
| 元字符 | 含义 |
|--------|------|
| `+`    | 前项 1 次或多次 |
| `?`    | 前项 0 次或 1 次 |
| `|`    | 或 |
| `(...)` | 分组（无需转义） |

### `grep` 常用选项
| 选项 | 说明 |
|------|------|
| `-i` | 忽略大小写 |
| `-v` | 反向匹配（不匹配行） |
| `-n` | 显示行号 |
| `-c` | 仅计数 |
| `-l` | 仅列出匹配文件名 |
| `-r` / `-R` | 递归搜索目录 |
| `-A N` | 匹配后显示 N 行 |
| `-B N` | 匹配前显示 N 行 |
| `-C N` | 匹配前后各 N 行 |
| `-f file` | 从文件读取模式 |
| `-x` | 整行匹配 |
| `-e pattern` | 指定多个模式 |

### 示例
```bash
grep "Anoop" f1
grep -e "ANOOP" -e "AMIT" -e "KUMAR" fl
grep "[aA]gg[ar][ar]wal" fl
grep "7...$" fl              # 7000-7999
egrep "ch+" file             # ch 出现 1 次或多次
egrep "ch?" file             # ch 出现 0 次或 1 次
egrep "EXP1|EXP2" file       # 匹配 EXP1 或 EXP2
egrep "(x1|x2)x3" file       # 匹配 x1x3 或 x2x3
grep -f pattern_file target  # 多模式搜索（固定字符串）
```

## Shell 脚本编程

### 执行脚本
```bash
sh script.sh          # 解释执行
chmod +x script.sh    # 添加执行权限
./script.sh           # 直接执行
```

### 示例 1：显示三年日历
```bash
# a1.sh
echo "The Calendar is"
cal -3
```

### 示例 2：交互式搜索模式
```bash
# a3.sh
echo -e "\nEnter the pattern: "
read pname
echo -e "\nEnter the filename: "
read fname
grep "$pname" "$fname"
echo -e "\nThe selected pattern is given above"
```

### 位置参数与特殊变量
| 变量 | 含义 |
|------|------|
| `$0` | 脚本名称 |
| `$1` ... `$9` | 第 1-9 个参数 |
| `${10}` ... | 第 10 个及以上参数 |
| `$#` | 参数个数 |
| `$*` | 所有参数作为单字符串 `"$1 $2 ..."` |
| `$@` | 所有参数作为独立字符串 `"$1" "$2" ...` |
| `$?` | 上一命令退出状态（0 成功） |
| `$$` | 当前 Shell PID |
| `$!` | 最后一个后台作业 PID |

### 逻辑操作符
```bash
cmd1 && cmd2    # cmd1 成功则执行 cmd2（逻辑与）
cmd1 || cmd2    # cmd1 失败则执行 cmd2（逻辑或）
```

### 练习：打印 X1 到 X2 之间的质数
```bash
#!/bin/bash
# prime.sh - 打印范围内的质数

read -p "Enter X1: " x1
read -p "Enter X2: " x2

for ((num=x1; num<=x2; num++)); do
    if [ $num -lt 2 ]; then
        continue
    fi
    is_prime=1
    for ((i=2; i*i<=num; i++)); do
        if [ $((num % i)) -eq 0 ]; then
            is_prime=0
            break
        fi
    done
    if [ $is_prime -eq 1 ]; then
        echo $num
    fi
done
```

**运行方式：**
```bash
chmod +x prime.sh
./prime.sh
```
