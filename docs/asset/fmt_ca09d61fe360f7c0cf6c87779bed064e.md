## 数组

Korn 支持一维数组。数组元素的最大数量为 1024。当定义数组时，它会自动设置维度为 1024 个元素。一个一维数组包含一系列数组元素，就像在铁轨上连接在一起的火车厢一样。数组元素可以是任何内容，除了另一个数组。我知道你可能在想可以使用数组来访问数组，以创建二维和三维数组。如果可以实现，那将超出本书的涉及范围。

## 加载数组

数组可以通过两种方式加载。你可以使用 `set -A` 命令一次性定义并加载数组，也可以一次加载一个数组元素。这里展示了两种技术。

```
set -A MY_ARRAY alpha beta gamma

X=0 # 初始化计数器为零。
## 加载包含 alpha, beta 和 gamma 字符串的数组
for ELEMENT in alpha beta gamma
do
  MY_ARRAY[$X]=$ELEMENT
  ((X = X + 1))
done
```

第一个元素通过 0 引用。访问数组元素使用以下语法：

```
echo ${MY_ARRAY[2]} # 显示第三个数组元素
gamma

echo ${MY_ARRAY[*]} # 显示所有数组元素
alpha beta gamma

echo ${MY_ARRAY[@]} # 显示所有数组元素
alpha beta gamma
```

```
echo ${#MY_ARRAY[*]} # 显示数组元素的总数
3
```

```
echo ${#MY_ARRAY[@]} # 显示数组元素的总数
3
```

```
echo ${MY_ARRAY[0]} # 显示数组元素 0（第一个元素）
alpha
```

我们将在本书的两个章节在 shell 脚本中使用数组。

## 使用文件描述符

在 Unix 操作系统的底层，文件通过被称为“文件描述符”`file descriptors`的唯一数字进行引用、复制和移动。你已经知道这三个文件描述符了：

- `stdin`
- `stdout`
- `stderr`

在本书的其他脚本中，我们已经使用 `stdout`（标准输出）和 `stderr`（标准错误）重定向了输出。这是我们第一次使用 `stdin`（标准输入）文件描述符。关于这些每一项的简短定义，我们可以谈谈计算机上的设备。标准输入通常从键盘或鼠标进入计算机。标准输出通常输出到屏幕或文件。标准错误是命令、程序和脚本路由错误信息的地方。我们曾使用 `stderr` 将错误信息发送到“垃圾桶”或 `/dev/null`，更常见的是将其同时发送到 `stdout` 和 `stderr` 输出。你应该记忆过类似下面的命令：

```
some_command 2>&1
```

上一个命令将所有错误信息发送到与标准输出相同的输出设备，即终端。我们也可以使用其他文件描述符。在大多数操作系统上，有效的描述符范围是从 0 到 19。当你使用较大的值时，必须进行大量测试，确保它们没有由于某种原因被系统预留。我们将在后续的代码列表中看到更多关于使用文件描述符的内容。
