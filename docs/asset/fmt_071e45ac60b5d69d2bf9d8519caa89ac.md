# 致管理人员

## MySQL 版本、许可与支持

MySQL 是一个开源软件包，这意味着数据库及相关工具的源代码是免费提供的。出于许多原因，这是极其强大的。原因之一是，如果数据库出现任何问题，只要有干练的开发者，就可能修复它们。开源软件也在不断更新。这为用户带来了数据库最新、最强大的功能，但也可能增加额外的管理负担。在支持环境中跟进最新且相关的库和工具版本有时会非常困难。尽管版本在不断变化，但你不必一直升级。一旦你在服务器上启动并运行了一个发行版，不需要在下一个版本出现时立即升级，特别是如果你的应用程序所需的所有功能已经存在时。最好在下一个主版本发布后等待几个修订。关注正在添加的最新功能；如果该功能对应用程序是必要的，可能值得立即升级。此外，如果你当前使用的功能存在 bug 或相关问题，建议尽早升级以缓解问题。

MySQL 使用不需要许可，即使在商业应用程序中也是如此。如果你将服务器与其他服务一起出售、对 MySQL 安装收费，或将 MySQL 包含在收费使用的发行版中，你将需要许可。许可按每个 CPU 请求。更多信息可以在 `http://www.mysql.com/Manual/Licensing_and_Support.html` 找到。

下一步将安装并设置数据库及相关表。进入新的 `mysql` 目录并运行以下命令：

```
shell$ scripts/mysql_install_db

Creating db table

Creating host table

Creating user table

Creating func table

Creating tables_priv

Creating columns_priv
```

若要在系统启动时自动启动 `mysqld`，你必须将 `supportfiles/mysql.server` 复制到适用于你系统的正确位置

请记住为 MySQL root 用户设置密码！通过以下命令完成：
`./bin/mysqladmin -u root password 'new-password'`
更多指令请参阅手册。

如果使用 `./bin/mysqlbug` 脚本遇到任何问题，请予以报告！

有关 MySQL 的最新信息可以访问网站：`http://www.mysql.com`
通过购买支持/许可来支持 MySQL：`http://www.tcx.se/license.htmy`。

可以在同一目录下启动数据库：

```
shell /bin/safe_mysqld &
```

你现在已经准备好配置数据库了。

## RPM 发发版的安装

这种类型的安装需要 root 权限，但它将为你完成所有的配置和设置。确保你下载了之前列出的至少包含客户端和服务器 RPM，并确保它们的版本相同。对于无需自定义客户端的最小安装，你只需要以下文件：

```
MySQL-3.22.X-1.PLATFORM.rpm

MySQL-client-3.22-X-1.PLATFORM.rpm
```

你还需要最新的 `rpm` 工具，它随 RedHat Linux 发行版一起提供。如果你的安装没有安装此工具，请参阅你的 RedHat 文档进行安装。然后可以按照如下方式一起安装所有数据库文件：

```
shell$ rpm -vi MySQL-3.22.X-1.PLATFORM.rpm MySQL-client-3.22-X-x.PLATFORM.rpm
```

你可以验证其是否已安装：

```
shell$ rpm -q MySQL

MySQL-3.22.X-1
```

这将安装所有必要文件并启动数据库。它还会在 `/etc` 中设置必要的脚本，以便在每次机器启动时都启动数据库。该发行版还会创建一个名为 `mysql` 的用户来运行数据库。文件也将由该用户所有，以防止篡改。数据库甚至会自动为你启动。下一步是配置你的数据库。

## 源码发行版的安装

除了这些工具，你还需要 GNU 工具 `gcc` 和 `make`。你可以通过以下命令判断你是否拥有这些工具：

```
shell$ which gcc

usr/bin/gcc

shell$ which make

usr/bin/make
```

安装的 `gcc` 必须是 2.81 或更高版本。你可以通过以下命令确定版本：

```
shell$ gcc -v

Reading specs from /usr/lib/gcc-lib/i386-redhat-linux/egcs

2.91.66/specs

gcc version egcs-2.91.66 19990314/Linux (egcs-1.1.2 release)
```

如果这不是正确的版本，请参阅你的 Linux 发行版文档查找如何升级。此外，请访问先前的 GNU 网站获取安装这些工具的帮助。
要解压发行版，请在移动文件的目录下执行以下命令。

```
shell$ gunzip -c mysql-3.22.X.tar.gz | tar -xvf -
```

这将创建 `mysql-3.22.X` 目录。进入该目录并运行 `configure` 以确定环境信息并准备编译。你可以向 `configure` 传递一些选项以包含其他系统变量来覆盖默认的 `[/usr/local/mysql]`：

- `prefix=/path`（文件安装路径）
- `localestadir=/path`（数据库文件安装路径）
- `with-charset=CHARSET`（要安装的语言）

你可以在文档中参考更多选项：

```
shell $ ./configure --prefix=/my/home/
```

现在使用 `make` 编译所有内容：

```
shell $ ./make
```

将所有文件安装到 prefix 目录：

```
shell $ ./make install
```

进入你安装文件的目录并设置必要的表：

```
shell $ ./scripts/mysql_install_db

Creating db table

Creating host table

Creating user table

Creating func table

Creating tables_priv table

Creating columns_priv table
```

若要在系统启动时自动启动 `mysqld`，你必须将 `support-files/mysql.server` 复制到适用于你系统的正确位置

请记住为 MySQL root 用户设置密码！
通过以下命令完成：
`/usr/local/mysql/bin/mysqladmin -u root password 'new-password'`
更多指令请参阅手册。

如果使用 `/usr/local/mysql/bin/mysqlbug` 脚本遇到任何问题，请予以报告！

有关 MySQL 的最新信息可以访问网站：`http://www.mysql.com`
通过购买支持/许可来支持 MySQL：`http://www.tcx.se/license.htmy`。

你现在可以启动数据库服务器了：

```
shell$ my/home/mysql/bin/safe_mysqld &
```

你可以按照如下检查检查数据库是否正在运行：

```
shell$ ps -aux | grep mysql | grep -v grep

mysql 1877 0.1 0.70636 1004 ttya2 SN 17:14 0:00

/usr/sbin/mysql

mysql 1879 0.0 0.70636 1004 ttya2 SN 17:14 0:00

/usr/sbin/mysql

mysql 1880 0.0 0.70636 1004 ttya2 SN 17:14 0:00

/usr/sbin/mysql
```

这些行显示了数据库正在运行、以哪个用户运行以及进程系统信息。如果这些行没有显示数据库正在运行，请检查你之前的步骤并确保你可以启动数据库。对于大多数配置，添加用户和权限等操作只能在数据库运行时进行。
