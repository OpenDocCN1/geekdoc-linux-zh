
## 证明

我们关于 `k` 进行归纳。对于 `k = 1`，结果显然成立，因为 `K_1` 是每个图的子图；对于 `k = 2`，因为 `K_2` 是每个非空图的子图。

假设对于所有阶数为 `k - 1`（`k ≥ 3`）的树 `T'` 以及所有满足 `δ(G') ≥ k - 2` 的图 `G'`，`G'` 都包含一个与 `T'` 同构的子图。

设 `T` 是一棵阶数为 `k` 的树，`G` 是一个满足 `δ(G) ≥ k - 1` 的图。我们要证明 `G` 包含一个与 `T` 同构的子图。

设 `v` 是 `T` 的一个叶顶点，`u` 是 `T` 中与 `v` 相邻的顶点。那么 `T-v` 是一棵阶数为 `k-1` 的树。由于 `δ(G) ≥ k-1 > k-2`，根据归纳假设，`G` 包含一个与 `T-v` 同构的子图 `T'`。设 `u'` 是 `T'` 中对应于 `T-v` 中 `u` 的顶点。由于 `deg_G u' ≥ k-1` 且 `T'` 的阶数为 `k-1`，顶点 `u'` 与一个不属于 `T'` 的顶点 `v'` 相邻。通过向 `T'` 添加 `v'` 并将其与 `u'` 连接所得到的树与 `T` 同构，证毕。

## 3.3 生成树

尽管不存在用于计算固定阶数下非同构树数量的闭合公式，但对于阶数为 `n` 的不同标记树（其顶点来自固定基为 `n` 的集合）的数量确实存在公式。

如果同一图的两种标记使用相同的标记集但产生不同的边集，则它们被认为是**不同的标记**。图 3.10 展示了一个阶数为 9 的图从集合 `{1, 2, …, 9}` 出发的三种标记。由于前两种标记产生了相同的边集，因此这两种标记被认为是相同的。然而，第三种标记与前两种不同，因为在前两种标记中 26 不是边，而在第三种标记中 26 是一条边。

![](img/598a6ae3fd44120830ada34717906f29_81_0.png)

阶数为 3 的标记树（其顶点来自相同的三个标记集合）有 3 个，阶数为 4 的标记树（其顶点来自四个标记的集合）有 16 个。这 19 棵树如图 3.11 所示，其中顶点集分别为 `{1, 2, 3}` 和 `{1, 2, 3, 4}`。

![](img/598a6ae3fd44120830ada34717906f29_82_0.png)

我们将看到，阶数为 `n` 且顶点来自相同 `n` 个标记集合的不同标记树的数量为 `n^{n-2}`。因此，如上所述，阶数为 3 的标记树的数量为 `3^{1}=3`，阶数为 4 的标记树的数量为 `4^{2}=16`。这个关于阶数为 `n` 的标记树数量的公式出自著名的英国数学家阿瑟·凯莱（Arthur Cayley），我们之前遇到过他，稍后还将再次遇到。虽然凯莱在 1889 年发现了这一结果，但我们在这里呈现的证明是由德国数学家海因茨·普吕弗（Heinz Prüfer）[19] 在 1918 年给出的，他因其在阿贝尔群方面的研究而闻名。

### 普吕弗代码

普吕弗对凯莱结果（通常称为凯莱树公式）的证明在于建立阶数为 `n` 且具有相同顶点集（例如 `{1, 2, …, n}`）的树与长度 `n - 2` 的序列（称为普吕弗代码）之间的一一对应关系，其中序列的元素来自集合 `{1, 2, …, n}`。由于这样的序列数量为 `n^{n-2}`，一旦验证了一一对应关系，证明即可完成。

在给出凯莱树公式的证明之前，我们举一个例子来说明所采用的技术。考虑图 3.12 中阶数为 `n = 8` 的树 `T`，其顶点用集合 `{1, 2, …, 8}` 中的元素标记。`T_1 = T` 的普吕弗代码的第一项是 `T_1` 中具有最小标签的叶顶点的邻居。然后删除该叶顶点，生成一棵新树 `T_2`。`T` 的普吕弗代码的第二项是 `T_2` 中具有最小标签的叶顶点的邻居。我们以此类推，直到得到 `T_{n-2} = K_2`。得到的长度 `n - 2` 的序列即为 `T` 的普吕弗代码，在本题中为 `(1, 8, 1, 5, 2, 5)`。

![](img/598a6ae3fd44120830ada34717906f29_83_0.png)

在这个例子中，`T` 的每个顶点 `v` 在其 Prüfer 序列中出现 `deg v - 1` 次。这在一般情况下也是成立的。因此，`T` 的叶子顶点不会出现在 `T` 的 Prüfer 序列中。所以，如果 `T` 是一个阶为 `n` 且度为 `m` 的树，那么其 Prüfer 序列中项的个数为

$$ \sum_{v \in V(T)}(\deg v - 1) = 2m - n = 2(n-1) - n = n-2 . $$

我们现在考虑逆问题。假设 `s=(a_1, a_2, …, a_{n-2})` 是一个长度为 `n-2` 的序列，其中对于每个 `i(1 ≤ i ≤ n-2)`，都有 `a_i ∈ {1,2,…,n}`。我们构造一个阶为 `n`、顶点集为 `{1,2,…,n}` 的带标签树 `T`，使得给定的序列 `s` 成为 `T` 的 Prüfer 序列。例如，假设给定的序列是 `s=(1,8,1,5,2,5)`。该序列的长度为 `n-2=6`，因此 `n=8`。`{1,2,…, 8}` 中未在该序列中出现的最小元素是 3。我们将顶点 3 连接到序列的第一项（顶点），即将顶点 3 连接到顶点 1。然后删除序列的第一项，得到缩减序列 `(8,1,5,2,5)`。同时，元素 3 从集合 `{1,2,…,8}` 中移除。缩减后的集合 `{1,2,4,5,6,7,8}` 中未出现在 `(8,1,5,2,5)` 中的最小元素是 4，它连接到序列 `(8,1,5,2,5)` 的第一项，即顶点 8。此过程继续，直到最后缩减集合中只剩下两个元素。这两个顶点（在此例中为 5 和 8）被连接，从而构造出一棵树 `T`，其 Prüfer 序列为 `s`。这如 [图 3.13](#) 所示。

因此，一般来说，为了构造阶为 `n`、顶点用集合 `{1,2,…,n}` 中标签标记的树 `T=T_1` 的 Prüfer 序列 `(a_1, a_2, …, a_{n-2})`，我们应用以下算法。

![](img/598a6ae3fd44120830ada34717906f29_84_0.png)

### 算法 3.21：构造顶点集为 `{1, 2, …, n}` 的带标签树的 Prüfer 序列。

**输入**：一个整数 `n ≥ 3` 和一个顶点集为 `{1, 2, …, n}` 的树 `T = T_1`。

**输出**：`T` 的 Prüfer 序列 `(a_1, a_2, …, a_{n-2})`。

- 1. 对于 `i = 1` 到 `n - 2`
  - 1.1. 找到 `T_i` 中最小的叶子节点 `v_i`，并设 `a_i` 为 `v_i` 在 `T_i` 中的邻接点。
  - 1.2. 设 `T_{i+1} = T_i - v_i`。
- 2. 输出 `(a_1, a_2, …, a_{n-2})`。

对于固定的由 `n` 个正整数组成的集合 `S_1`，以及一个由属于 `S_1` 的项组成的长度为 `n - 2` 的序列 `s = s_1`，通过遵循以下算法构造一个阶为 `n` 且 `V(G) = S_1` 的图 `G`。我们可以假设 `S_1 = {1, 2, …, n}` 且 `s_1 = (a_1, a_2, …, a_{n-2})`，其中对于 `1 ≤ i ≤ n - 2`，有 `a_i ∈ S_1`。

### 算法 3.22：给定一个长度为 `n-2` 且各项属于集合 `S_1={1,2,…,n}` 的序列 `s_1`，构造一棵顶点集为 `S_1` 且 Prüfer 序列为 `s_1` 的树。

**输入：** 一个整数 `n ≥ 3`，`S_1={1,2,…,n}` 和一个序列 `s_1=(a_1, a_2,…, a_{n-2})`，其中对于 `1 ≤ i ≤ n-2`，有 `a_i ∈ {1,2,…,n}`。

**输出：** 一个顶点集为 `{1,2,…,n}` 的图 `G`。

- 1. 对于 `i = 1` 到 `n-2`：
  - 1.1. 设 `k_i` 为 `S_i` 中未出现在 `s_i` 中的最小元素，并设边 `e_i = k_i a_i`。
  - 1.2. 设 `S_{i+1} = S_i - {k_i}`。
  - 1.3. 对于 `i ≤ n-3`，设 `s_{i+1} = (a_{i+1}, a_{i+2}, …, a_{n-2})`。
- 2. 对于 `S_{n-1}` 中的两个元素 `x, y`，设边 `e_{n-1} = xy`。
- 3. 输出 `E(G)={e_1, e_2,…,e_{n-2}}`。
