## 中文、日语和韩语输入

对于大多数欧洲语言（以及许多基于字母的语言），按下键盘上的字母会将字母打印到屏幕上。然而，中文、日语和韩语需要一种由称为输入法编辑器（IME）的特殊应用程序处理的转换过程。当然，这是一个 Windows 术语，但无论如何，这些语言都有自己的 IME，而且由于文字系统的不同，它们各不相同。

### 中文

大多数人（至少是那些了解语言学的人）认为中文是最复杂的系统，因为其文字系统由成千上万字符组成，但实际上是最简单的。中文 IME 仅接收罗马化的键盘输入，即拼音（pinyin），并将其转换为汉字（Hanzi）。对于 IME 来说，这本质上是一个简单的字典查询任务。如果一个拼音输入对应多个字符，将出现一个可能的候选列表，用户可以从该列表中选择合适的字符。

### 日语

日语 IME 需要执行的任务要复杂得多，因为它需要处理三种文字系统：汉字（Kanji，很久以前从中国借用的表意文字）、平假名（hiragana，主要用于语法结尾的音标字母系统）和片假名（katakana，主要用于从其他语言借用的词汇）。尽管如此，日语的标准输入法主要通过标准的罗马字母键盘布局，加上几个额外的功能键。因此，用日语输入是一个两步的过程：IME 在输入时首先将罗马化文本转换为平假名，并在按下空格键时将其转换为相应的汉字、片假名或平假名元素。

你可以从图 12-6 中看到这些步骤的示例。在第一行中，IME 已经对流中的罗马化输入进行了转换。它将 "Linux"你也可以在 Linux 中输入日语）转换成了平假名。该行带有下划线意味着它尚未转换。然而，在第二行中，用户随后按了空格键，导致 IME 将平假名字符串转换为相应的汉字、平假名和片假名元素。第一个单词 Linux 被转换成了片假名，因为它是一个外来词；而日语输入被转换成了汉字；其余部分保持平假名。

### 韩语

韩语 IME 的工作再次与中文和日语 IME 非常不同，因为这种语言本身的编写方式完全不同。韩语完全用字母编写，称为韩文（Hangul），或者将韩文与从中国和日本借用的表意文字汉字（Hanja）相结合。虽然汉字本质上与它们的中文和日语对应词（Hanzi 和 Kenji）相同，但韩语音标字母韩文有其独特的形状，正如你在图 12-7 的韩语单词“韩国”（Hanguk）所示。

# 项目 12：为 SCIM 安装亚洲语言输入支持

实际上有几种方法可以实现这一点，但最简单直接的方法是智能通用输入法（SCIM），它是 Ubuntu 预装的底层组件。SCIM 支持包括中文、日语和韩语在内的多种亚洲语言，并为其中的许多种语言提供了多种输入法。

## 12-1: 下载并安装 SCIM 输入法模块

尽管 SCIM 预装在 Ubuntu 中，但在开箱即用状态下并无法为你提供任何帮助。为了启用 SCIM 并能够输入 CJK 及其他类型的字符，你需要安装一个名为 `im-switch` 的包。然后，你需要为你想要输入的语言安装相应的输入法。

获取这些包最简单且问题最少的方法是通过“语言支持”（Language Support）实用程序。只需进入系统菜单，选择“管理 > 语言支持”，然后安装你所需的语言支持。

语言支持安装完成后，还剩下一个简单的步骤：注销账户，然后在回到登录界面后重新登录。顶部面板右侧会出现一个 SCIM 图标，告知你 SCIM 已经准备就绪。

## 12-2: 使用 SCIM 输入亚洲语言

为了感受 SCIM 的工作原理，请尝试在 Gedit（应用程序 ▸ 辅助工具 文本编辑器）中使用它。

当 Gedit 出现后，点击 SCIM 面板小组件。下拉菜单中将出现 SCIM 可以处理的语言列表（图 12-9）。但请记住，菜单中出现的语言数量取决于你安装了多少语言。

![](img/ba6b82a7869bba748202d57c97336dca_228_0.png)

从该列表中选择你想要使用的语言，对于那些提供选择的语言，选择你偏好的输入法。SCIM 面板小组件的图标会反映这一变化，显示你所选语言的图标。然后你就可以开始输入了。

此时，屏幕右下角会出现一个类似图 12-10 所示的小输入调面板。在这个调面板中，除了显示当前使用的语言和输入法外，还允许你轻松地在英语和当前输入语言之间切换，或者从当前输入的语言切换到另一种语言。通过点击面板最右侧的红色按钮，你还可以查看当前使用的输入法的热键。

![](img/ba6b82a7869bba748202d57c97336dca_229_0.png)

图 12-10：SCIM 输入调面板

无论你处理的是哪种输入法，你可能最需要的热键组合是 `SHIFT-spacebar`，它可以在英语和你在 SCIM 中选择的语言之间来回。

> 注意：你必须在一个接受文本输入的文档或应用程序中操作，否则当你点击 SCIM 小组件时不会出现菜单。

## 12-3: 安装额外的输入法

你可能会发现，为你已安装语言提供的输入法中可能包含一些你不熟悉的类型。例如，默认的韩语字体不是基于标准键盘的（我唯一熟悉的键盘），而且它不具备韩字到汉字的转换功能（而日语模块中默认包含了了平假名到汉字的转换功能）。幸运的是，通过使用 Synaptic 安装额外的输入模块可以轻松解决这个问题。当然，下载哪个包取决于涉及的语言。要为韩语添加额外模块，请安装 `scim-tables-ko`。要添加额外的日语输入法，请安装 `scim-tables-ja`。最后，要为中文添加额外的模块，请安装 `scim-tables-zh`。

你还可以使用 SCIM 方便地输入其他不需要特殊转换程序的亚洲语言，如泰语、印地语、泰卢固语、孟加拉语和旁遮普语。要获得这些语言的输入支持，请安装 `scim-tables-additional`。
