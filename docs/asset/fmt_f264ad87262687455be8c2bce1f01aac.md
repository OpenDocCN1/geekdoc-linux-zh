## DNS Over TLS

访问官方 [DNS Over TLS](https://www.cloudflare.com/en-gb/learning/dns/dns-over-tls/) 了解有关 DNS Over TLS 的所有信息。

在终端通过 APT 安装 DNS Over TLS：

直接输入这些命令：

```bash
sudo apt update
sudo apt install systemd-resolved
cd /etc/systemd
sudo gedit resolved.conf
```

接下来，将 `#DNS=` 行更新为：

`DNS=9.9.9.9#dns.quad9.net 2620:fe::fe#dns.quad9.net`

将 `FallbackDNS=` 行更改为：

`FallbackDNS=149.112.112.112#dns.quad9.net 2620:fe::9#dns.quad9.net`

对于 `#DNSSEC=no`，将其修改为：

`DNSSEC=yes`
`DNSOverTLS=yes`

并将 `#ReadEtchHosts=yes` 更新为：

要保存更改，点击“保存”（Save）。你可以直接点击“保存”按钮、转到“文件”并选择“保存”，或者点击 ≡ 图标选择“另存为”，然后点击“保存”。保存后，关闭编辑器。

继续在终端中执行这些命令：

```bash
sudo systemctl daemon-reload
sudo systemctl restart systemd-resolved
sudo systemctl restart NetworkManager
```
