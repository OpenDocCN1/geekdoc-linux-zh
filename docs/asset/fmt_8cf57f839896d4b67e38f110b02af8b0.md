## 15.6 新用户

现在，让我们创建一个“用户账户”。

如果你熟悉 MS-DOS 或在某种程度上熟悉 Windows 98，你可能会对创建用户账户的要求感到有些困惑。

毕竟，如果你可以在 `root` 账户中导航系统并使用程序，你可能会认为在单机上拥有账户是多余的。
