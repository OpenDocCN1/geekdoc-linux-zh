## 技巧 65. 使用 `fdisk` 分区

在服务器上安装了新磁盘后，你必须使用 `fdisk` 等工具对其进行相应分区。

以下是你可以在 `fdisk` 内部执行的 5 个典型操作（命令）。

- `n`: 创建新分区

- `d`: 删除现有分区

- `p`: 打印分区表

- `w`: 将更改写入分区表。即保存。

- `q`: 退出 `fdisk` 工具

## 技巧 67. 挂载分区

在创建分区并格式化后，你可以将其挂载到挂载点。

首先创建一个应该挂载分区的目录。

```bash
# mkdir /home/database
```

挂载文件系统。

```bash
# mount /dev/sda1 /home/database
```

为了在重启后自动挂载文件系统，请在 `/etc/fstab` 中添加以下目：

```text
dev/sda1 /home/database ext3 defaults 0 2
```
