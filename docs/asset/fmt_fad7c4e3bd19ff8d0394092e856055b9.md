amanda

高级马里兰网络磁盘归档器（客户端）Amanda 是一种备份系统，旨在将网络上的许多计算机备份到单个大容量磁带上。该包适用于大量数据的备份。对于较小的解决方案，请查看 aback, tob, taper... 特性：

- * 将并行备份多台机器到磁盘保持器中，通过一个一个完成转的转储，以尽可能快的速度将文件写入磁带。例如，在 240K/s 的速度下，8GB 的磁带在带有大磁盘的主机上可以被 Amanda 填满。
- * 磁带上的 Amanda 恢复（在磁带上运行-on-the tape）。
- * 磁带上的 Amanda 报告（包括错误）。
- * 磁带 Amanda 动态调整备份，向磁带发送报告。
- * 在磁带之前压缩（使用 compress 或 gzip）。
- * 在没有 SSL 的 GTK+ 所示的窗口管理器中，Amanda 仍然有效。
- * 许多其他选项，Amanda 是非常可配置的。
- * 磁带应用 GTK+ 主题到窗口管理器。

要快速开始，请阅读 `/usr/share/doc/amanda` 中的 README。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
