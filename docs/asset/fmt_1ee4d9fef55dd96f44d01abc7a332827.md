## 9.6 会话和进程组

在 Linux 中，与其他 Unix 系统一样，用户通常与一组相关的进程进行交互。尽管他们最初登录到单个终端并使用单个进程（他们的 shell，提供了命令行界面），但用户通常会由于某些操作而运行许多进程，例如：

- 在后台运行非交互式任务
- 通过作业控制在交互式任务之间切换（这在第 14 章有更详细的讨论）
- 启动通过管道协同运行的多个进程
- 运行窗口系统，例如 X Window 系统，它允许打开多个终端窗口
