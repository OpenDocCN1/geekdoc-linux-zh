
# 项目 5-2

在这个项目中，你将编写一个脚本来计算作为位置参数传递的五个值的平均值。

1. 以用户身份登录 Linux 系统，然后打开一个终端模拟。
2. 在 `$HOME/bin` 目录下创建一个名为 `Project5-2` 的脚本。
3. 插入对 bash shell 的引用、适当的注释以及你的名字作为作者。
4. 从命令行接受五个位置参数。
5. 在屏幕上显示所有五个值。
6. 如果输入的值数量不对，则显示用法说明。
7. 显示五个值的平均值。
8. 保存脚本，关闭编辑器，使脚本具有可执行权限，然后执行你的脚本。
9. 记录输出。
10. 关闭窗口，然后注销。
