# 恒星演化

## 早期演化

赫罗斯格-拉勒（HR）图上的主序是恒星在初始引力收缩后缓慢形成的。质量越大，内部压力、温度越高，恒星越亮。氢聚变对温度非常敏感；质量增加意味着更快的聚变速率。大质量恒星具有更快的核聚变和更多的燃料供应；在主序上生存 $10^{10}$ 年，太阳质量恒星仅用 $2.5 \times 10^9$ 年就会耗尽核心。

演化分为三个部分。低质量恒星（G 类）没有壳层燃烧。在八倍到十倍太阳质量之间（G 类到 B 类），它们作为白矮星演化。作为 O 和 B 类，它们发生爆炸。燃烧从未结束恒星的生命。
