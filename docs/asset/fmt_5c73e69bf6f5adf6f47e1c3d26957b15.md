
# 变色晕

变色晕是直径达40微米的圆形或椭圆形区域，在照相显微镜下观察，其颜色与周围矿物发生变化。变色晕发现于放射性矿物的小包体周围——例如锆石、独铁矿、稀土、钛矿和磷灰石——以及岩石矿物角闪石和辉石。在科罗拉多高原的炭化木中也发现了这种晕。参见碳质；岩石学分析；地质射线成像。

颜色的变化是α粒子在铀-238、铀-235和其他同位素链矿物放射性衰变期间引起的。可以通过考虑颜色的效应来估计晕的年龄。晕具有清晰的环，其着色程度在晕中增加，最终减小。金属成矿。

早期的变色晕被用于通过α粒子强度估计包围矿物的年龄。不同年龄和同位素之间环的恒定表明，用于定年的铀衰变常数在整个地质时间内保持恒定。变色晕的热退火被用于模拟岩石单元。参见地质年代学。

## 钚 1729

中新世海平面上升导致了许多哺乳动物类群的地理隔离以及特有种的增加。但晚中新世-更新世的低海平面限制了联系，允许南北美之间长时间的哺乳动物迁移和交换。后来的北方哺乳动物导致了竞争压力增加以及南美类群的扩散。

一个表面温度为 38 K (°F)，这与地球上 10⁻¹ 大气的气压一致。

与冥王星形成显著差异的是，卡洛表面似乎几乎没有冰冻海洋，而是表现出水冰的光谱特征。卡洛的轨道独特之处在于该卫星的旋转周期；它是冥王星相应半球的居民，而冥王星一直在绕着这个卫星移动。

第四新世还出现了几种被认为与现代祖先相关的物种。最早的形式发现于肯尼亚的巴万戈，可以追溯到中新世。此后，一系列南方人猿物种在第四新世出现。

岩体。由熔岩（岩浆）冷却和结晶形成的固体岩石体。在地球上，岩入体是由地壳深处的岩浆结晶产生的。岩入体要么作为外露岩或火山岩形成，要么通过其他过程形成。

指上述任何灌木或小树。许多广泛分布在北区的所有区域，适应了不同的气候和条件。

岩体以近乎无限的形状和大小出现，排列可以是任意的。通常，可以从围地岩识别出许多侵入方式。岩入体插入在层状岩层之间，而更不整合的岩入体则切断了地中的岩层。岩入体的主要类型有岩床、岩丘和岩席；典型的岩入体类型有岩脉、岩塞、岩石和岩基。

有四类：(1) 欧洲梅（Prunus domestica）或欧洲梅 (2) 日本梅和中国李梅（Prunus spinosa） (4) 美国梅（P. itifolia 和 P. hortiana）。家用梅是大大的、多肉的、干果类型的梅。梅是一种不经过结果而存在的果实。

已知几种方法可以产生某些同位素，例如钚，这些元素通过主动或被动迁移进入裂隙形成。大型岩入体可能沿岩浆通道水形成，或通过岩浆穿过地壳形成。火山口可能由强制注入、停止（岩浆室岩块破碎时岩浆上升的过程）以及岩脉破裂引起，后者绕着向外的岩浆核心流动。

开花植物植物，属于木兰目（被子植物）中的木兰科（双子叶植物）。花是两性的。植物是草本或灌木。花小而多，并显示出（每朵花有许多花瓣；每个子房的每个室内有一个胚）。马鞭科及其许多科的特征是雄蕊融合、花被持久以及渗透花瓣的芳香色素持久。这些科包含了亚美尼亚植物、石竹或海景植物的各种物种。

钚，原子序数 94。钚是锕系元素中的一种放射性金属。该元素的主要同位素是 ²239，半期为 24,111 年。它在核反应通过以下序列过程形成：

```
$^{239}\text{U}_{23.5 \text{ d}} \rightarrow ^{239}\text{Np}_{2.3 \text{ d}} \rightarrow ^{239}\text{Pu}_{23.1 \text{ y}}$
```

钚的半期为 87.7 年，它用于太空探索中的热源，且 Pu-239 用于生产核武器的燃料。

冥王星曾被认为是最外层的行星，现在是矮星行星。亮度的变化表明冥王星的表面覆盖着冰，其旋转周期为 6.4 天。

冥王星有一个小卫星。冥王星的半径是 1188 ± 20 km，比月球（半径为 1737 ± 20 km）小得多。如果冥王星是致密的，这意味着它主要由岩石组成，密度可能低于地球。它们的密度约为 2.0025 g/cm³。钚在溶液和固态下表现出高电正性。已知许多钚合金，它们是活性的。金属的反应产生氧化物。红外光谱揭示了氮（N2）、二氧化碳（CO2）和水蒸气。从这些得出结论，氧化物是在 150 °C (300 °F) 的温度下形成的。

胶板。已知。其中包括氯化物、硅酸盐和硒化物，除了它们的性质外还特别受关注。由于其放射性，钚及其化合物需要特殊技术来防止吸入。胶板是由胶合在一起的薄木板制成的产品。胶板的等级分为：防水胶板被指定为外型；耐水胶板被指定为内型；带有结节的胶板。胶板由道花杉、落欧落叶松、长叶松或其他木材制成。由于木纹取向不同，其力学性能较差。常用的厚度从 1/4 (0.6 cm) 英寸或 1/8 (0.3 cm) 英寸到 1/2 (1.3 cm) 英寸不等。最常见的面板尺寸是 4 x 8 (1.2 m) 英尺；用于运输箱。完成的胶板可以是未打磨、打磨或上漆的，用于装饰和特殊用途。在许多应用中如家具、墙面和地板。参见，地板。

热液作用。火山喷发期间，气体（通常称为来自岩浆源的流体）对岩石或矿物的改变。岩浆流体含有二氧化碳、二氧化硫、硫化氢、氯、化物以及许多其他挥发性化合物的氧化物。参见岩浆；变质；变质；挥发物。

热液作用描述了矿物分解、孔隙作用或岩浆流体变质的过程。例如，熔岩和喷出物可能含有保留岩浆流体的岩块，形成硫酸盐、硫、化物和多种金属氧化物。火山通道周围的岩石可能被岩浆降解为绿帘石、泥石、高岭土和其他矿物。罕见的金、银、贱金属硫化物和砷化物由流体沉积，形成价值矿石。参见，变质；变质岩；升华；茜；硫化物。

肺炎球菌。肺的主要微生物（肺炎链球菌）。肺炎可能以圆形或梭形细胞成对或短链的形式出现，横跨 0.05-1.25 微米，一端扁平，另一端尖锐。多糖囊包裹每个细胞。生物通过细胞二分裂分裂。

肺炎球菌已从人类、马、猴子和狗的上呼吸道中分离出来。肺炎感染的病因学在人类、豚鼠和鼠身上已有描述，但它们不是人类感染的原因。肺炎球菌可以在所有人的上呼吸道中发现，但它只在另一种疾病之后引起感染。

在另一种疾病之后，肺炎球菌可能侵入肺上皮。除了流感外，细菌性肺炎的主要并发症是硬膜外、脑膜炎、关节炎、咽炎和中耳感染。伴随肺炎球菌引起的肺炎病例可能会发生血症症。

未治疗肺炎的高死亡率通过抗生素治疗显著降低。此外，对一种或多种抗生素药物耐药的肺炎球菌分离物一直在增加。由于这些原因，建议老年人接种。

肺炎球菌疫苗包含纯化的 23 型胶多糖，这些类型负责 85% 的细菌性肺炎病例以及 65-70% 病例中的任何类型感染。

肺炎。肺的急性或慢性炎症。当炎症由感染剂引起时，这种状态称为肺炎；当肺损伤与任何感染无关时，称为肺炎症。

估计美国每年发生 4500 万例肺炎，每年有多达 50,000 人死亡。肺炎是各种疾病成人的主要死亡原因。随着使用免疫抑制剂和化疗药物治疗癌症和其他患者，通常发生的肺炎变得更加常见。

在机会性感染患者中，例如由巨细胞病毒引起的肺炎。参见获得性免疫缺陷综合征（AIDS）；机会性感染。

# 蹄藻目

细菌作为一个整体，是肺炎最常见的原因，流感病毒以肺炎球菌（双球肺炎球菌）作为最常见的单一病原体。某些细菌是人体内的常驻，仅在特定条件下引起疾病；另一些则被认为是机会性的。

大多数肺炎在肺部有两种主要的炎症形式。肺炎球菌引起肺炎，导致一侧肺或其大部分区域发生实变。液体和急性炎症细胞的继性炎症会对细菌产生反应。这种类型的肺炎在今天并不常见，除非是发高热的人群。如果治疗得当，炎症过程可能会消失，尽管在某些情况下它会变成一个被称为炎症组织组织的过程。

另一种由大多数细菌引起的肺炎是支气管肺肺炎。在这种形式中，实变涉及气管和支气管，大部分再次位于下叶。如果治疗得当，这种类型的肺炎也可能完全恢复，尽管很少如此。

病毒性肺炎通常由肺部直接感染引起，其产生的炎症类型与细菌性肺炎不同。

肺炎由多种其他真菌引起，特别是在癌症或艾滋病患者中。结核分杆菌（细菌性肺炎的病原体）产生的产物可以引起真菌生物。

肺炎及肺炎的治疗取决于病因。如果肺部可以通风，可以针对特定细菌用药物。病毒性肺炎对症状进行治疗。肺炎的治疗取决于其病因；许多病例使用皮质激素类药物治疗。

# 足蹼目

包含单单行的科，足蹼目（鸱），在全球范围内发现 20 种。它们是中等鸟类，专为水生生活而化，能够熟练地游泳和潜水。它们的肢位置靠后以便移动——带有蹼趾——用于推动鸟类在水中移动。它们的翅膀很小，很少飞行；它们进行远距离迁徙并殖了许多岛屿。身体紧凑，具有防水羽毛。颈部大且短至中等，呈蹼状。鸱有蹼，以水下捕猎的鱼类和其他水生动物为食。鸱是群居的，有复杂的求偶行为和强大的配偶关系。

参见鸟纲。[W.B.]

# 介壳亚

由介壳目的两个亚目组成。两者有许多特征，但存在显著差异。共同特征包括具有光滑边缘的壳（壳）和融合的眼睛；壳缺口处没有触角；没有侧眼，且额前器官（钟形器官）很小（长度 7 毫米）。壳不对称，略短且可能高度铰合。铰合处源于三对足；第二对足适应于挖掘、清洁或作为腿部的爪子。
