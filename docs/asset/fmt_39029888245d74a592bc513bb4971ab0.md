## 6.1. 目录缓存

### d_invalidate

**名称**
`d_invalidate` — 使一个 dentry（目录项）失效

**概要**
```c
int d_invalidate (struct dentry * dentry);
```

**参数**
`dentry`  
要使失效的 dentry

**描述**
如果可行，尝试使该 dentry 失效。如果可以通过该 dentry 访问其他 dentry，则我们无法删除它并返回 `-EBUSY`。成功时返回 0。

不使用 dcache 锁。
