### 总结

在本节课程中，你学习了 Linux 系统中程序及其配置文件的位置。需要记住的重要事实有：

- 基本上，程序分布在三级目录结构中：`/`、`/usr`、`/usr/local`。每个层级都可能包含 `bin` 和 `sbin` 目录。
- 配置文件存储在 `/etc` 和 `~` 中。
- 点文件是以点（`.`）开头的隐藏文件。

我们还讨论了 Linux 内核。重要的事实有：

- 对于 Linux 来说，一切皆文件。
- Linux 内核与其他启动相关文件一起存放在 `/boot`。
- 为了让进程开始执行，内核必须加载到内存的受保护区域。
- 内核的任务是为进程分配系统资源。
- `/proc` 虚拟（或伪）文件系统在易性 RAM 中存储重要的内核和系统数据。

同样，我们探索了硬件设备并学习了以下内容：

- `/dev` 目录存储了所有连接硬件设备的特殊文件（又节点）：块设备或字符设备。前者按块传输数据；后者一次一次处理一个字符。
- `/dev` 目录还包含其他特殊文件，如 `/dev/zero`、`/dev/null` 或 `/dev/random`。
- `/sys` 目录存储了分类排列的硬件设备信息。

### 进程

每当用户发布命令时，程序就会运行并产生一个或多个进程。进程以层级结构存在。内核加载到内存后，第一个进程被启动——随后启动其他进程。每个进程都有唯一的标识符（PID）和父进程标识符（PPID）。这些按顺序分配整数。
