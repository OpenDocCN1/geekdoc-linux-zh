# 从 BackupPC 恢复备份

得益于 BackupPC 的 Web 界面以及备份存储在备份服务器上的事实，任何在 `/etc/backuppc/hosts` 文件中与主机关联的授权用户都可以在线恢复文件。BackupPC 允许你在线恢复、交互式地选择要恢复的文件和目录，并以各种方式进行恢复。

要开始恢复文件或目录，点击它们所在的全量或增量备份名称。会出现一个如图 B-4 所示的屏幕。
