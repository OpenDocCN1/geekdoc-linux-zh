
## Licq
支持不同的接口和功能插件（viplains）。对于 X 窗口系统和控制台都有许多插件。此包包含了 Jacq（Licq 守护进程）和 Qt 插件的文件，后者是使用 Qt 组件集编写的。该 GUI 插件拥有大多数 ICQ 功能。此 Qt 插件默认启动，要运行其他插件，你必须执行命令“`liq -p <plugin>`”。要返回 Qt 插件，你需要运行一次“`liq -p qgui`”。或者，如果你的插件支持，你可能可以在插件对话框中进行操作。此版本的 liq 为支持 SSL 的插件提供了 SSL 支持。源自 Mandrake 9.0 RPM `http://www.tdlp.org/LDP/Linux-Dictionary/html.index`

## lice
用于 Lice 的 IRC（网络中继频道）。它构建在一个在 Emacs 内部运行的简单 IRC 客户端之上，尽管它与 irchat-2ip 毫无关系（后者由日本贡献者添加了各种功能，例如模块、支持的通道）。我们将进行完全替换以进行彻底重新设计，并再次使用它来扩展协议后端。该程序的最新版本已从 Irchat 几乎被完全重写。源自 Debian 3.0rt APT `http://www.tdlp.org/LDP/Linux-Dictionary/html.index`

## lifelines
基于文本的软件 Lifelines 是一种在文本模式下运行于 UNIX 系统上的谱系/家谱程序。它在数据库中维护家谱记录（父母、家庭、来源、事件及其他），并根据记录生成报告。Lifelines 数据库可以存储的记录数量没有实际限制，记录中可以保留的数据量也没有限制。Lifelines 不包含内置报告。相反，它提供了一个编程子系统，你可以用它生成报告和图表。某些报告文件包含在 lifelines-包中。编程子系统还允许你查询数据库并以任何方式处理数据。它利用 Linux 的终端功能提供屏幕和菜单用户界面。源自 Debian 3.0 APT `http://ldp/LDP/Linux-Dictionary/html.index`

lifelines 软件的报告。Lifelines 拥有非常强大的报告语言。此包包含了官方发行版附带的所有“标准”报告。源自 Debian 3.0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html.index`

## lightlab
使用 OpenGL 模型的实验 lightlab 让你能够设置几个灯的颜色和位置，然后查看它对简单场景的影响。你可以使用它在 OpenGL 中创建一个立方体、球体或圆圆环。此工具不包含纹理。你可以使用它在 OpenGL 中创建一个 3D 场景。对于在 OpenGL 中设置光照的人，这个工具可能很有帮助。源自 Debian 3.0 `http://www.ldp.org/LDP/Linux-Dictionary/html.index`

## lightspeed
显示光速下的效果。lightspeed 是一个基于 OpenGL 的程序，展示了相对论效应。当一个物体接近光速移动时，这些效应会变得明显。这种效应是取决于光的。在默认情况下，它会显示相对论效应。源自 Debian 3.0 `http://www.ldp.org/`

# Linux 词典

- LIMEMS Lotus – 微软扩展内存规范（Lotus, Intel, MS, EMS），"LIM EMS" 源自 Vera `http://www.tld.org/LDP/Linux-Dictionary/index.html`

- lim 以自定义方式列出文件，是 `ls` 的替代品并带有一些节点。默认情况下，它同时安装了 limbo 和 ls。它试图比 `ls` 对输出格式有得多的控制力，并提供更简单直接（尽管更详细）的选项。它还具有 -l 和 -s 选项，功能与 `ls` 类似。来自 Debian 3.0r `http://www.tld.org/LDP/Linux-Dictionary/index.html`

- linbot WWW 网站检查器，linbot 是一个 python 程序，允许网站管理员：

  - 查看网站结构；
  - 跟踪损坏的 HTML 页面链接；
  - 指向外部的链接；
  - 维护自己的在线图片库；并且在无需用户干预的情况下定期执行所有操作。

结果显示在一系列 HTML 页面中。来自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`
