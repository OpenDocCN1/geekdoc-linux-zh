# 引言

Linux 操作系统从 1991 年左右就开始持续开发，当时 Linus Torvalds 开始为 Intel PC 环境编写一种基于 UNIX 的操作系统。原始的 Linux 内核非常紧凑，只有最基本的功能。利用当时处于婴儿阶段的开源社区，Linus 向世界发布了 Linux。

近十年后，Linux 操作系统开始在商业界找到自己的位置，成为许多其他服务器和桌面操作系统的可行且通常更优的替代品。Linux 已进入并精通了一个新领域——数据库服务器，这从各种 Linux 供应商与 Oracle、DB 等大型数据库供应商之间建立的许多联盟中得到了证明。本书将 Linux 介绍为一个卓越的替代性数据库服务器平台，分析了几种数据库解决方案的优缺点，并介绍了一些真实世界的应用示例。

## Linux 简史

Linux 是由一个名为林斯·托瓦尔斯（Linus Torvalds）的学生在赫尔辛基的一所学校工作时作为一个个人项目发起的。他在接触 Minix 之后开始了这个个人项目，Minix 是另一种运行在 Intel 芯片 PC 上的类 Unix 操作系统。

为什么会有人承担重写操作系统这样一项艰巨的任务呢？作为一名研究生，与基础 PC 作为桌面系统的优势相比，哑终端（dumb terminals）的高昂成本正变得显而易见。但桌面软件和所需的桌面操作系统的成本，让普通学生和用户无法负担一台配备所有必要软件产品的 PC。为了缓解这一状况并扩展他所工作学校的资源，Linux 决定重新开发 Minix 是一项值得的项目，即使这意味着该学校可以使用一些旧 PC 作为哑终端连接到主服务器。

Linux 在 1992 年初向互联网社区开放了该项目，以寻求开发想法和额外的开发资源。互联网社区迅速锁定了这个项目，并以任何软件开发公司都会嫉妒的方式帮助支持其开发——在许多语言中提供免费且无限制的支持。

这种互联网开发允许成百上千的人以他们喜欢的方式进行协作或以自己的方式成长。这提供了非常快的开发速度，有许多“眼睛”来调试和测试代码。

在工具的开发方面，不存在某种工具的“最佳设计”。任何人都可以贡献他们认为有用的任何工具。这一点体现在有几个工具执行相同的相同功能上；它们被包含进来是因为如果你已经熟悉了某个特定工具，Linux 会为你提供一个克隆版本。例如，在文本界面和 X Windows 版本中提供了十几个或更多文件编辑器。

自此以后，Linux 移除了所有 Minix 代码，并使用自己的代码完全重写了内核。

## Linux 内核是免费的

Linux 的开发是为了乐趣和免费。Linux 内核及相关的源代码免费提供给所有人，且就 Linux 而言，它们将保持免费。Linux 由林斯·托瓦尔斯根据通用公共许可许可证（GPL）条款拥有版权。GPL 允许任何人自由分发完整源代码、制作其副本，并按照其意愿销售或分发它（有少数例外）；GPL 许可证随 Linux 内核一起提供（Linux 光盘上的 `usr/src/linux/COPYING/` 目录，或者可以在互联网上的许多网站下载和查看）。

## 引擎

Linux 内核只是被称为 Linux 的整体中的一小部分——它恰好是最重要的部分。你可以把普通的 PC 想象成发动机的底盘，可以从任何底盘供应商处购买，而且有很多供应商。下一个重要的部分是引擎——对于你的 PC 来说，这就是 Linux 内核。内核“让一切运行”。内核处理 IO、进行内存管理，并基本上“运行”程序。所以，你有一个底盘和一个引擎，但没有方向盘、轮子、门、座椅和动力“东西”。这些是你也可以选择的额外物品（参见“自选”）或让别人为你选择的（Linux 发行版）。
