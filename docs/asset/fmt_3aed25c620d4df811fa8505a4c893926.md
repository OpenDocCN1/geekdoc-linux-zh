## 活性中间体
不稳定的化合物在化学反应过程中作为中间阶段形成。如果反应通过 `C` 将 `A` 转换为 `B`，那么 `C` 就是反应的中间体 (`A → C → B`)。该反应进一步快速完成。活性中间体在特定条件下通常是不稳定的，关于活性中间体及其性质的大部分信息来自实验经验。
