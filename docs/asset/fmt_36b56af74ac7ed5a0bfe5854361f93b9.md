
## 10.9 内置 Shell 命令

### Tru64 UNIX (C shell)

示例：

```
% time
0.03u 0.07s 0.01 90% O+3k 0+3io ipf+0w
```

### Linux (C shell)

示例：

```
% time is
0.070u 0.11s 0:00.44 4.0%
O+ik O+0io 178pf+0w
```

第一个示例源自 HP-UX 系统，展示了 `time myscript` 如何返回执行脚本文件 `myscript` 所的时间，如下：

`0.2u`

0 分钟 2 秒用户 CPU 时间

`0.1s`

0:22

0 分钟 1 秒系统 CPU 时间

0 分钟 22 秒挂钟时间（wall-clock time）

`33%`

33% 的可用 CPU 资源
