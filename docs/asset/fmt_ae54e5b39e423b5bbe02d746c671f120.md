
# 2.5 运行程序：多任务与会话

使用 Linux 的主要原因之一是它是多任务操作系统——它能同时运行多个程序（从以后称为进程）。你可以在后台启动进程并继续工作。此外，Linux 允许多个会话：这就像同时拥有多台电脑工作一样！

- 切换到会话 1.6：
  `$ ALT-F1 ALT-F6`
- 在不离开当前会话的情况下启动新会话：
  `$ su - <loginname>`
- 结束会话：
  `$ exit`

这非常用，例如你需要挂载磁盘（第 4 节）：通常只有 `root` 才能做到。
