
# 抗凝血灭鼠剂

作为一个整体，抗凝血灭鼠剂主导了市场，并以多种商标名称出售。按开发顺序排列，它们分别是：华法林、吲哚酮（Phyll）、二法辛酮和氯法辛酮。当少量这些抗凝血剂在几天内被摄入时，会导致内部出血而死。较新的第二代抗凝血灭鼠剂，如溴敌隆、溴甲环素和甲硝基茚满酮，是为了对抗老鼠和家鼠对早期抗凝血剂（尤其是华法林）日益增长的遗传耐药性而开发的。第二代化合物效力更强，且单次夜间喂食即可致死，尽管死亡通常会在几天后发生。不属于抗凝血剂的灭鼠剂包括磷化锌、溴甲酚和胆钙化醇（维生素 D3）。它们的喂食特性和致死特性各不相同。急性毒性的士的宁毒饵也可获得，但限制于地下施用，主要用于更格卢鼠和鼹鼠。几种致命的熏蒸剂或产生有毒气体的物质用于杀死穴居和其他封闭区域（如未占用的铁路车厢或建筑物）内的啮齿动物。致命熏蒸剂包括磷化铝、二氧化碳、氯乙醛和烟雾或气体弹，点燃后会产生一氧化碳和其他窒息性气体。

由于高毒性，灭鼠剂对人员、家畜和野生动物天生具有危害性。它们受到严格监管，就像某些其他类型的农药一样。一些灭鼠剂只能由经过培训、认证或持牌的害虫控制人员购买和使用，而其他一些安全性较高的灭鼠剂可供公众使用。所有灭鼠剂必须按照标签说明使用，并且在可能危害某些濒危物种的地方可能被禁止使用。参见农药、啮齿目。[R.E.M.A]

## 辊磨机

一系列以不同速度运行的辊子，用于研磨油漆或轧制铁。在油漆研磨中，糊状物被送入两个以不同速度相对运行（彼此靠近）的慢速辊之间。由于磨坊中下一个辊子转得更快，它会在糊状物中产生剪切力，并将糊状物拉过磨坊。薄膜从最后一个高速辊上刮下。对于研磨面粉，辊子成对操作，每对中的辊子以不同速度相对运行。粗磨辊压碎谷物；光辊将面粉研磨至所需的细度。参见研磨机。[R.M.H.J]

## 滚动接触

两个物体之间的接触，使得两个接触表面在接触点处的相对速度为零。滚动接触的常见应用包括留声机唱盘、变速器和道路车轮的摩擦齿轮。一般来说，滚动接触机构是凸轮机构的一种特殊变体。滚动接触的概念用于研究摩擦轴承和齿形齿轮的行为。参见摩擦轴承；凸轮机构；齿轮。

## 罗马尼奇矿

一种含钡的二氧化锰矿物，其理想化学式为 $(Ba,H_2O)_n(Mn^{4+}, Mn^{2+})_nO_{2n}$。罗马尼奇矿是一组二氧化锰矿物中的碱性成员，它们在外观上相似且结构密切相关。它是锰的矿石，存在于各种广泛分布的地点。其名称来源于其在法国索恩-卢瓦尔省 Romanèche 地区的发现。参见锰；二氧化锰矿物。

罗马尼奇矿呈黑色至钢灰色，不透明，细粒状。它主要呈硬壳状，形态为葡萄状或肾状，但也呈罕见的柔软粉状样本。许多葡萄状样本在其表面平行方向上具有细粒的条带或层理。晶体罕见。报告的罗马尼奇矿比重约为 4.4 至 4.8，莫氏硬度范围为 5 至 6（粉状品种较低）。罗马尼奇矿通常与其他二氧化锰矿物紧密共生，不使用 X 射线衍射或电子显微镜等分析技术很难识别。参见硬度标尺。[S.T.]

## 屋顶结构

为住宅、建筑以及商业、工业和娱乐区提供遮盖的集合体。屋顶以不同的形式和形状，使用各种材料建造。设计和建造良好的屋顶保护其下方的结构免受外部天气条件的影响，为叠加荷载提供结构支撑，提供隔板强度以维持下方结构的形状，抑制火灾蔓延，并满足期望的审美标准。

现代屋顶结构通常由一个外层屋面组件组成，该组件固定在屋面板或衬板表面之上，而后者又由主要框架（如梁、桁架或拱的一系列结构）支撑。屋顶的形状和屋顶结构类型通常由下方主要结构的材料和屋面板决定，并与其保持一致。参见拱；梁；桁架。

屋顶形状包括：平屋顶；坡屋顶，其中两个倾斜的屋面板表面相交形成一条线，即屋脊或斜脊；金字塔形，涉及三个或更多倾斜平面；圆顶形，或其他三维表面，如球形、抛物线形或双曲面壳体；以及帐篷形，即悬挂的织物或膜表面。

屋面组件是位于屋面板上并固定在其上的一系列不同材料的层。每种屋面组件——与防止雨水、雪或冰进入的保护以及温度变化、火灾蔓延、风升力和水分迁移的隔热相关——都有其自身的设计要求和构造及固定方法。

屋顶是从下方结构向上建造的。框架，即主要结构部件，支撑在结构的墙体和柱子上，这些部件支撑屋面板或衬板，而后者又承载屋面组件。墙体和柱子可能有嵌入其中的梁。梁支撑在梁上或与梁连接。屋面板或衬板，即提供屋面组件基本支撑的部件，跨接在主要结构框架之间并固定在其上。

大跨度屋顶使用空间桁架，通常为钢制，但也可能使用钢筋混凝土圆顶或其他壳体形状，包括折板。在索承屋顶中，主要框架由张力索组成，这些索悬挂在独立的柱子之间或从周围建筑周长顶部垂下。帐篷形或膜屋顶是索承屋顶的特殊应用。气承屋顶利用防水涂层织物，通过在结构内部产生并维持正气压使其充气成刚性形状，从而保持屋顶表面处于张紧状态。网球场的“气泡”使用了这种设计。参见建筑物；钢筋混凝土；结构钢。[M.A.]

## 根（植物学）

维管植物的吸收和锚定器官。根是简单的轴向器官，产生侧根，有时产生芽，但不着生叶或花。伸长发生在根尖。根尖的较老部分，即根尖后方的部分，可能通过形成层活动而增粗。一些根，例如草的根，几乎不增粗，但树根在靠近茎部处的直径可达 4 英寸（10 厘米）或更大。根可以非常长。最长的枫树（*Acer*）根通常与树一样高，但大多数根只有几英寸长。最长的根可以存活很多年，而小根可能只存活几周或几个月。

根尖及其表面的根毛从土壤中吸收水和矿物质。它们还合成氨基酸和生长调节剂（赤霉素和细胞分裂素）。这些物质向上通过木质的根部基部进入茎。增粗的根部基部将植物锚固在土壤中。增粗的根，如胡萝卜，可以储存食物，稍后用于茎的生长。参见细胞分裂素；赤霉素。

根通常生长在土壤不太密实（不会阻碍根尖快速伸长）且有足够水分允许根生长的地方；温度足够高（高于 39°F 或 4°C）以允许根生长，但不至于太高以致杀死根（高于 104°F 或 40°C）。在温带地区，大多数根位于地表以上 4 英寸（10 厘米）的土层中；随着深度增加，根的数量迅速减少，因此在地表以下 6 英尺（2 米）处很少有根。在土壤炎热干燥的地区，根长得更深；沙漠灌木的根曾在地下 230 英尺（70 米）深的矿井中发现。在水位高的沼泽中，氧气缺乏将根限制在表土层。根也可以在空气中生长。毒常春藤的藤蔓形成许多小型气生根，将其锚固在树皮或其他表面上。

主根起源于种子的胚，通常是第一个生长的轴向器官。它向下生长进入土壤，并在根尖后方以直角产生二级侧根。有时它持续存在并增粗形成直根。二级侧根产生三级侧根，依此类推，直到成熟的树木根系中有数百万条根。与主根相比，大多数侧根水平甚至向上生长。在许多植物中，少数水平的侧根增粗形成直根。在主根中，所以成熟根系中没有直根。

不定根起源于茎或叶，而不是胚或其他根。它们可能形成于切茎的基部，如园艺实践中扦插生根所见。[B.F.W.]

## 根（数学）

若函数 $f(x)$ 在 $x = a$ 处的值为 0，则 $a$ 是方程 $f(x) = 0$ 的一个根。代数基本定理指出，任何形式为 $ax^n + a_1x^{n-1} + a_2x^{n-2} + \ldots + a_{n-1}x + a_n = 0$ 的代数方程（其中 $a_i$ 为实数），至少有一个根。由此可轻易推导出，此类方程拥有与 $x$ 的最高幂指数（此处为 $n$）数量相等的根（实根或复根）。

此外，若 $a + ib$（其中 $i = \sqrt{-1}$）是给定方程的一个复根，则 $a - ib$（即 $a + ib$ 的共轭）也是该方程的根。四次及以下的方程可以通过代数方法求解。这意味着根可以表示为系数的函数。这些函数涉及加法和乘法等基本算术运算，或将一个数提升到某次幂，或求给定数的某次方根。H. Abel 和 G. Galois 已证明，*高于四次的通用代数方程* 无法通过代数方法求解。然而，可以将代数方程的实根确定到任意所需的近似程度。参见：微积分；方程理论；数值分析。[A.N.L.,S.Bo.]

## 蔷薇科

最大的科是蔷薇科（Rosaceae），拥有近 3000 个物种。该科中包含大量具有经济重要性的树木、灌木和草本植物，包括苹果（*Malus*）、梨（*Pyrus*）、杏仁、樱桃、李子和西梅（*Prunus*）、草莓（*Fragaria*）、黑莓、树莓及其近亲（*Rubus*），以及许多次要的玫瑰种类。许多植物被种植作为观赏植物，包括玫瑰（*Rosa*）、路边青（*Geum*）、委陵菜（*Potentilla*）、火棘（*Pyracantha*）、石楠（*Photinia*）和绣线菊（*Spirea*）。参见：杏仁；苹果；黑莓；樱桃；梨；李子；树莓；草莓。

第二大的科是鼠李科（Rhamnaceae，含 900 个物种），包括大多数木质物种（灌木和树木），它们与蔷薇科的区别在于具有合蕊柱（fused carpels）且仅有五个花药（而非许多）位于与花瓣相同的位置。
