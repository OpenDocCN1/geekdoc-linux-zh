## 管理进程

你可以在终端窗口中使用 `kill` 命令来结束进程。`kill` 命令以进程 ID 作为参数。请确保获取了正确的 ID。输入错误的进程 ID 也会导致系统瘫痪。使用 `ps` 命令显示进程 ID。带有 `-C` 选项的 `ps` 命令搜索特定的应用程序名称。`-o pid=` 只显示进程 ID，而不是进程 ID、时间、应用程序名称和尝试（try）。一旦获取了进程，就可以使用进程 ID 作为参数使用 `kill` 命令来结束进程。

```
$ ps -C firefox -o pid=
5555
$ kill 5555
```
