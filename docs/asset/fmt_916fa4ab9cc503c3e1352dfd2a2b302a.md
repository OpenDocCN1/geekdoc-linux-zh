## 参数

`file[.zip]` 压缩包的路径。如果你对 `file` 指定了通配符，则按照操作系统的顺序处理每个匹配的文件。只有文件名可以是通配符；路径本身不能。通配符表达式类似于 Unix `grep(1)` `regular` 表达式，可以包含：

- `*` 匹配零或多个字符
- `?` 匹配任意一个字符
- `[...]` 匹配括号内的任何单个字符；具有起始字符、连字符和结束字符的范围。如果左括号后跟着感叹号 `!` 或脱字符 `^`，则括号内的字符范围将取反（即括号内以外的任何字符都被视为匹配）。

## 选项

- `- -1` 仅列出文件名，每行一个。此选项排除了所有其他内容。从不打印头、总计行或文件注释。此选项用于 UNIX Shell 脚本。
- `- -2` 仅列出文件名，每行一个，并显示头 `(-h)`、总计行 `(-t)` 和文件注释 `(-z)`。当存储的文件特别长时，此选项非常有用。
- `- -s` 以短的 UNIX `ls -1` 格式列出文件信息（默认）。
- `- -m` 以中等的 UNIX `ls -1` 格式列出文件信息。与 `-s` 输出相同，但还会列出以百分比表示的压缩率。
- `- -l` 以长的 UNIX `ls -1` 格式列出文件信息。与 `-m` 输出相同，但显示压缩大小（字节）而不是压缩率。
- `- -v` 以详细的、多页格式列出文件信息。
- `- -h` 列出头信息。打印归档名称、实际大小（字节）和文件总数。
- `- -M` 将所有输出通过类似于 UNIX `more(1)` 命令的内部分页器进行处理。在屏幕输出的末尾，带有 `--More--` 提示暂停。要查看下一页，按 Enter（回车）键或空格键。你可以按 `q` 键退出 `zipinfo`，在某些系统上按 Enter/Return 键退出。与 `more(1)` 不同，`zipinfo` 不允许向前搜索或编辑。`zipinfo` 不会注意行是否在边缘换行，导致实际上打印了两行或多行。某些文本在查看之前可能会超出屏幕顶部。

在某些系统中，无法检测屏幕可用行数，此时 `zipinfo` 假设高度为 24 行。

- `- -t` 列出文件数量、压缩前和后的总大小以及整体压缩率。或者，如果只打印总计行，则列出整个归档的值。注意，总压缩（数据）大小永远不会等于实际文件大小，因为后者包含了添加到压缩数据中的所有内部文件头。
- `- -T` 以可排序的数字格式打印文件日期时间 `yyymmdd.hhmmss`。默认日期格式是更标准、人类易读的版本，带有缩短的月份名。
- `- -z` 在列列表中包含归档注释（如果有）。
- `- -Z` 如果命令行上的第一个选项是 `-z`，则将剩余选项解释为 `zipinfo(1)` 选项。

注意 - 当你单独使用或结合使用 `-h` 或 `-t` 选项时，它们会覆盖归档中文件的任何默认列表。只显示头和/或总计行。当你配合通配符文件规范使用 `zipinfo` 时，这种行为非常有用；可以使用单个命令汇总所有文件的内容。

## 详细说明

`zipinfo` 有多种模式，如果你不熟悉 UNIX `ls(1)` 命令，它的行为可能难以理解。默认行为是以如下所示格式列出文件。

```
-rw-rw--- 1.9 un 2802 t- defX 11-Aug-91 13:48 perms.2660
```

此示例是一个在 UNIX 系统上生成的 ZIP 文件。由于它源自 UNIX，示例中文件开头的格式以 UNIX 格式打印。

第二和第三字段表示该文件是在 UNIX 下使用 1.9 版本的 `zip` 压缩的。第四个字段显示未压缩的文件大小（示例中为 2802）。

第五个字段由两个字符组成，其中任何一个都有多个值。第一个字符可能是 `t` 或 `b`，表示 `zipinfo` 认为文件是文本或二进制文件。如果文件已加密，字母将大写。第二个字符可以显示四个值，取决于是否存在与文件相关的扩展本地头和/或额外字段。（这些值在 `PKWARE.TXT` 中有详细解释，但基本上类似于 ANSI C 中的程序——即它们提供了一种在归档中包含非标准信息的标准方法。）

第二个字符的值总结如下：

- 既没有头，也没有额外字段。
- `l` 文件有扩展本地头，但没有额外字段。
- `x` 文件有额外字段，但没有扩展本地头。
- `X` 文件既有额外字段，也有扩展本地头。

因此，示例中的文件（可能）是一个文本文件，未加密，且没有关联的额外字段或扩展本地头。第六个字段表示所使用的压缩方法和可能的子方法。目前已知六种方法：

- `Storing`（存储，不压缩）
- `Reducing`（减少）
- `Shrinking`（收缩）
- `Imploding`（内爆）
- `Tokenizing`（标记化）
- `Deflating`（Def胀压缩）

## 环境变量选项

使用环境变量中的选项来修改 `zipinfo` 的默认行为，解释起来可能有点复杂，因为 `zipinfo` 试图以一种直观的、类 UNIX 的方式处理各种默认值（试着别笑）。`zipinfo` 有三个优先级的选项。

- *默认选项*。
- 环境变量选项，可以覆盖或添加默认选项。
- 命令行上显式指定的选项，可以覆盖或添加上述任一种。

默认变量名在 VMS 中为 `ZIPINFO_OPTS`（在该情况下，用于将 `zipinfo` 安装为外部命令的符号否则会与环境变量混淆），在所有其他操作系统中为 `ZIPINFO`。为了兼容 `zip`，也接受 `ZIPINFOOPT`（别问为什么）。如果你同时定义了 `ZIPINFO` 和 `ZIPINFOOPT`，则 `ZIPINFO` 优先。。你可以使用 `unzip` 诊断选项（不带文件名的 `-v`）来检查四个可能的 `unzip` 和 `zipinfo` 环境变量的值。

默认列表格式大致对应 `zipinfo -hst` 命令（当你指定单个文件除外）。如果你更倾向于长格式列表 `(-1)`，可以通过 `ZIPINFO` 环境变量来更改默认设置，如下所示。

```
ZIPINFO=-1; export ZIPINFO

UNIX Bourne shell

setenv ZIPINFO -1

UNIX C shell

set ZIPINFO=-1

OS/2 or MS-DOS
```
