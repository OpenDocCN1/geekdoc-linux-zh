
# 波浪号

波浪号 (ASCII 11110,)，也称为 'squiggle'、'squiggle' (此处如此误 — 发音为 /skig/l)、'twiddle'，但 twiddle 是最常用的术语。对程序进行微小但重大的改变。通常修复一个 bug 并产生几个新 bug（也称为软调试）。

以某种方式改变事物。例如，比特位（Bits）经常被 twiddled。转动开关或旋钮比 tweaking 或 itaking 更有目的性；谈论 twaddling a bit 意味着漫无目的，充其量没有说明你对比特做了什么；拥有一个 bit 有更具体的含义（bit twiddle, toggle）。旋转鹦鹉的非常用名称。来自《术语词典》 `http://www.ldp.org/LDP/Linux-Dictionary/html.index`

# twin

一个文本模式环境。一个具有鼠标支持、窗口管理器终端模拟器和网络客户端的窗口环境，所有内容都以文本形式显示。它支持多种显示方式：纯文本终端（任何 termcap/ncurses 终端、Linux、twin 终端模拟器）；* X11，在其中它可以作为多窗口 xterm 使用（你可以在另一个地方显示一个 twin）；* twiddly，一个通用的网络透明显示客户端，用于动态附加/断开更多显示器。来自 Debian 3.0r0 APT
