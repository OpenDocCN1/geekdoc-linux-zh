`ls -F` 的输出显示目录后面带有斜杠 (`/`)。普通文件名按原样显示。在名为 `X` 的文件后面附加的 `@` 符号表示，该文件是指向另一个文件的链接（换句话说，这个文件名指向另一个文件；它是一个快捷方式）。可执行文件后面会附加星号 (`*`)（例如查看列表中的 `prefdm` 文件）。`shell` 可以运行任何可执行文件。

你可以通过 `-l` 选项查看有关文件和目录的更详细信息：

```
ls -l
```
