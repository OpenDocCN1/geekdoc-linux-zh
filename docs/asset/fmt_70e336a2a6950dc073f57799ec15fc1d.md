
# 鴷形目鸟类

鴷形目鸟类为小型至中型的营巢于洞穴的陆禽。喙短至中等长，直且强壮，翅膀中等长度且呈圆形。腿短而强壮，强壮的脚趾排列成对趾型（轭型）模式，即两个脚趾向前，两个脚趾向后。尾部可能具有僵硬的羽毛。羽毛颜色变化很大，通常色彩鲜艳且图案大胆。鴷形目鸟类擅长飞行，可以轻松栖息和攀爬，但行走能力较差。大多数物种以昆虫为食。卵由双亲共同孵化，双亲共同照顾未长羽毛的雏鸟，雏鸟留在巢中。除少数种类的啄木鸟外，鴷形目鸟类非迁徙性。参见鸟类；雀形目。 (W.J.B.)

# 小核 RNA 病毒科

小核 RNA 病毒科是由小型（18-30纳米）对乙醚敏感、无包膜且具有核糖核酸（RNA）基因组的病毒组成的病毒科。名称源自“pico”（意为非常小）和表示核酸类型的RNA。源自人类的小核 RNA 病毒包括以下亚群：肠道病毒（脊髓灰质炎病毒、柯萨奇病毒和埃可病毒）和鼻病毒。还有来自较低等动物的小核 RNA 病毒（例如，牛口蹄疫病毒，一种鼻病毒）。参见动物病毒；柯萨奇病毒；埃可病毒；肠道病毒；口蹄疫；脊髓灰质炎；鼻病毒。 [J.L.Me.]

# 辉长岩（橄榄辉长岩）

辉长岩（Picrite）这一术语曾被赋予几种不同的含义。它通常被认为包括主要由橄榄石组成，并含有少量辉石、角闪石和斜长石（拉布拉多石）的中等至细粒火成岩。其长石含量略高于橄榄岩，但低于辉长岩。某些含有钙铁榴石（analcite）的类型，常与特申岩（teschenite）共生，也被归入辉长岩术语之下。辉长岩很罕见，见于小型侵入体（岩床和岩墙）中。参见辉长岩；火成岩；橄榄岩。 (C.A.C.)

# 透视图

透视图是观察者沿着选定方向或从选定视角观察物体（实际或想象中的物体）时看到的物体视图。透视图草图通常比物体的前视图、顶视图和侧视图更容易绘制且更易于理解。工程师和建筑师经常使用自由手绘图或用绘图仪器绘制的透视图，向他们的助手和传达想法。参见投影几何；工程制图。

在制作透视图时，会选择最能展示物体及其细节优势的观察方向。如果将视线视为平行线，所得到的绘图就是正交投视图；如果将视线视为汇聚于观察者眼睛，则为透视绘图。与其他类型的透视图相比，透视绘图提供了最逼真且通常最悦目的相似性。

可以草绘或用仪器绘制几种类型的非透视透视图。在轴测图中，其轴的方向以及沿这些轴的所有测量都使用同一比例（图 1）。斜投影透视图虽然不是真正的正交投视图，但提供了一种绘制圆形和其他曲线真实形状的便捷方法（图 2）。

# 显像管

用作电视显像管的阴极射线管。电视显像管使用大型玻璃外壳，其内表面沉积有发光的荧光材料层。经过调制的快速电子流以一系列水平线扫描该荧光层，从而重现图像元素（亮区和暗区）。

在彩色显像管（见插图）中，玻璃泡由两部分组成：前面板和漏斗颈区域。分离的前面板允许制造分段磷光屏并安装荫蔽栅。两个玻璃部件通过特殊的配合密封在一起，以提供强大的真空密封。

分段屏上的发光彩色磷光体可以是点阵，或者更常见的是线阵。通常，三组垂直磷光线的间距为 0.6–0.8 mm。大多数管子使用黑色矩阵屏，其中磷光线之间由不透明的黑线分隔。这种黑色矩阵减少了反射光，从而提供更好的对比度，并为电子束与磷光线的光栅套准提供容差。

荫蔽栅由薄（0.10–0.17 mm）钢板制成，其中通过光刻法制作了细长的狭缝（每个磷光线组对应一行狭缝）。它被成形为类似玻璃面板的轮廓，并以精确的距离安装在玻璃上。狭缝的宽度及其与磷光线的相对位置使得三个电子枪之一的电子束只能击中一组彩色磷光线。荫蔽栅“遮挡”了来自其他两组磷光线的电子束。

彩色的电子枪与单色电子枪类似，除了有三个电子枪，通常并排或直线排列外。这种三枪结构具有公共的结构元件，但每个束使用三个独立的阴极以及独立的束形成和聚焦。

电磁偏转线圈使电子束偏转或弯曲，类似于单色管那样，在电视光栅中扫描屏幕。此外，线圈的磁场被整形，使得三个电子束以这样的方式偏转，使它们同时落在屏幕上的同一磷光三组上。这种电子束会聚产生三个图像，分别是红色、绿色和蓝色，它们叠加在一起形成全彩图像。参见阴极射线管；电视。 [A.M.G.]

# 压电性

压电性是指施加机械压力于介电晶体上产生的电力或电极性。施加机械应力会在某些介电（不导电）晶体中产生与其成正比的电极化（每立方米的电偶极矩）。如果晶体是孤立的，这种极化表现为晶体两端的电压；如果晶体短路，则可以在加载期间观察到电荷流动。反之，在晶体的某些面之间施加电压会产生材料的机械形变。这种相互关系被称为压电效应。在机械应力下产生电压的现象称为直接压电效应，而在电应力下晶体中产生的机械应变称为逆压电效应。参见介电极化。

压电效应的必要条件是晶体结构中缺乏对称中心。在 32 个晶体晶类中，有 21 个缺乏对称中心，除一个晶类外，这些晶类均为压电性的。静水压会在显示热释电性（除了压电性之外）的那 10 个晶类的晶体中产生压电极化。参见晶体学；热释电性。

## 分子理论

基于详细晶体结构的定量理论非常复杂。然而，从定性角度来看，对于简单的晶体结构，压电效应很容易理解。插图展示了这种立方晶系晶体——闪锌矿（ZnS）的情况。每个锌离子带正电，位于规则四面体 ABCD 的中心，四面体的顶点是带负电的硫离子的中心。当该系统在 xy 平面受到剪切应力时，例如边 AB 被拉长，而四面体的边 CD 变短。因此，这些边不再等效，锌离子将沿 z 轴位移，从而产生电偶极矩。源自不同八面体的偶极矩相互叠加，因为它们相对于 x、y 和 z 轴具有相同的取向。

# 应用

压电谐振器的尖锐共振曲线使其成为无线电振荡器频率稳定器的有用组件。石英晶体几乎专用于此应用。在真空管振荡器中，晶体通常是反馈电路的一部分。通过使用压电谐振器作为电路元件，可以构建具有低损耗的选择性带通滤波器。一种常用作石英替代品的合成压电晶体是酒石酸乙二胺。参见石英钟。

压电材料被广泛用于换能器，将机械应变转换为电信号。此类设备包括麦克风、唱针、振动传感元件等。相反的效果，即从电信号输入中产生机械输出，也广泛适用于声波和超声波换能器、耳机、扬声器以及磁盘录音切割头。参见麦克风；超声学。

# 压电材料

商业上使用的主要压电材料是晶体石英和罗谢尔盐，尽管后者正被其他材料（如钛酸钡）所取代。石英的重要特性在于它是一种完全氧化的化合物（二氧化硅），且几乎不溶于水。因此，它对随时间发生的化学变化具有稳定性。当用作振动器时，它的内部损耗也很低。罗谢尔盐具有较大的压电效应，因此在需要高灵敏度的声学和振动装置中非常有用，但它在高温下（$131^\circ$ F 或 $55^\circ$ C）会分解，并且需要防潮保护。钛酸钡提供的灵敏度较低，但对温度和湿度效应的免疫力更强。其他用于压电器件的水晶包括电气石、磷酸二氢铵（ADP）和酒石酸乙二胺（EDT）。参见石英。

# 斜长石（Pigeonite）

单斜辉石，通式为 $(Mg,Fe)_2SiO_3$，含有一定量的固溶体透闪石（augite）。斜长石与正辉石（orthopyroxenes）的关系，类似于透闪石与透闪石-钙铁辉石（diopside-hedenbergite）系列的关系。斜长石是火山岩中的单斜辉石等价物。参见透闪石；闪长岩；正辉石；辉石。

# 颜料

一种细粒材料，赋予涂料、清漆和涂层以光学及其他特性。颜料不溶于涂层材料，而染料则溶解并赋予涂层颜色。颜料与涂层进行机械混合，并在涂层干燥时沉积下来。通常，颜料在结合到介质（vehicle）中及从中沉积时，其物理性质不会发生改变。颜料可以根据成分（无机或有机）或来源（天然或合成）进行分类。然而，最实用的分类是按颜色（白色、透明或有色）和功能。特殊颜料包括防腐蚀颜料、金属颜料和发光颜料。参见染料；发光涂料；涂料。

# 色素/着色

生物材料在所有部位着色的一种特性。因此，色素决定了反射可见光的质量和数量。活体物质反射回来的光的特性是其化学和物理性质的函数，因此不仅源于色素本身，而且可能源于结构原因（例如，由于反射、散射或干涉）。

色素是生命世界必不可少的组成部分。它们在生命及其多样表达形式的演化和维持中的作用，在某些细菌和大多数植物中叶绿素及相关类胡萝卜素的 role 中表现得最为明显。这些色素收集太阳能光能，用于将无机前体光合合成有机材料。参见类胡萝卜素；叶绿素；光合作用。

动物皮肤的最外层结构因多种原因而着色，例如，使生物体在有色背景下可见，或向其他性别或其他物种提供光学信号。显著着色的花朵吸引传粉者，而彩色水果容易被动物发现，动物吃掉它们后分散未消化的种子。
