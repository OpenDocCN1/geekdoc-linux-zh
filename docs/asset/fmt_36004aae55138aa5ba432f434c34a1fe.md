
这些基本命令行操作是高效导航和管理 `Linux` 系统的基础。当你越来越熟悉这些命令时，你将能够更好地从终端执行广泛的任务，包括文件操作、文本编辑、进程管理等。

## 3.3. 文件管理与导航

有效的文件管理和导航是使用 `Linux` 命令行时至关重要的技能。在本节中，我们将探索处理文件和目录的基本命令和技术，让你能够高效地组织、定位和操作你的数据。

### 列出文件和目录

`ls` 命令是列出目录内容的基础。默认情况下，它显示当前目录下的文件和目录：

```
$ ls
```

要显示以点（`.`）开头的隐藏文件和目录，请使用 `-a` 选项：

```
$ ls -a
```

你还可以配合 `ls` 使用其他各种选项来定制输出。例如，`ls -l` 提供详细列表，包括文件权限、所有者、用户组、大小和修改日期：

```
$ ls -l
```

### 目录导航

`cd` 命令用于更改当前工作目录。要移动到特定目录，请将该路径作为 `cd` 的参数提供：

```
$ cd /path/to/directory
```

要返回上一级目录，可以使用 `cd ..`：

```
$ cd ..
```

要快速返回家目录，请直接使用不带任何参数的 `cd`：

```
$ cd
```

### 创建和删除文件及目录

### 创建目录

`mkdir` 命令允许你创建新目录。只需将所需的目录名称作为参数提供：

```
$ mkdir mydirectory
```

你可以使用 `-p` 选项在创建目标目录的同时创建父目录：

```
$ mkdir -p parent/child/grandchild
```

### 创建文件

要创建一个空文件，可以使用 `touch` 命令后跟所需的文件名：

```
$ touch myfile.txt
```

### 删除文件和目录

使用 `rm` 命令时要小心，因为它会永久删除文件和目录。要删除一个文件：

```
$ rm myfile.txt
```

要删除一个空目录，请使用 `rmdir`：

```
$ rmdir mydirectory
```

如果你想删除一个目录及其内容，可以使用 `rm` 配合 `-r`（递归）选项。使用此命令时请务必极其小心，因为它不会提示确认信息：

```
$ rm -r mydirectory
```

### 复制和移动文件

`cp` 命令用于复制文件和目录。要将文件复制到新位置，请指定源文件和目标目录：

```
$ cp sourcefile destination
```

例如，要将名为 `file.txt` 的文件复制到名为 `backup` 的目录，可以使用：

```
$ cp file.txt backup/
```

`mv` 命令允许你将文件和目录移动到新位置或对其重命名。要移动文件：

```
$ mv sourcefile destination
```

要重命名文件：

```
$ mv oldname newname
```

### 查找文件

`find` 命令是一个强大的工具，可以根据各种准则定位文件和目录。例如，要查找当前目录及其子目录中所有包含“linux”单词的文本文件，可以使用：

```
$ find -type f -name "*.txt" -exec grep -l "linux" {} \;
```

该命令从当前目录（`.`）开始搜索。

### 结论

有效的文件管理和导航是使用 `Linux` 命令行时的基本技能。通过掌握 `ls`、`cd`、`mkdir`、`touch`、`rm`、`cp`、`mv` 和 `find` 等命令，你将能够高效地组织、定位和操作文件和目录。这些技能对于系统管理、软件开发以及其他需要与文件系统进行直接交互的任务尤为有价值。随着经验的积累和对更高级技术的探索，你将更加熟练地处理 `Linux` 环境下的文件和目录。

## 3.4. 用户与权限：安全入门

用户管理和权限是 `Linux` 安全至关重要的方面。理解用户账户如何工作以及如何分配权限，对于维护系统的完整性至关重要。在本节中，我们将探索 `Linux` 中用户管理和权限的基础。

### 用户账户

在 `Linux` 中，每个使用系统的人都有一个用户账户。用户账户用于登录、访问资源以及在系统上执行操作。用户账户的相关关键概念包括：

- 用户名 (`Usernames`)：每个用户都有一个唯一的用户名，用于在系统中识别其身份。用户名对大小写敏感。
- 用户 ID (`UIDs`)：在后台，每个用户都会被分配一个数字用户 ID (`UID`)。`root` 用户通常拥有 `UID 0`，其他用户的 `UID` 从 `1000` 开始递增分配。
- 组组 (`Groups`)：用户可以属于一个或多个组，这提供了一种更高效的管理权限的方法。每个组也有一个组 ID (`GID`)。

### 用户管理命令

### 创建用户

要创建一个新用户，可以使用 `useradd` 命令后跟所需的用户名：

```
$ sudo useradd newUser
```

### 设置密码

要为用户设置密码，使用 `passwd` 命令：

```
$ sudo passwd newuser
```

### 删除用户

要删除一个用户及其家目录，可以使用 `userdel` 命令：

```
$ sudo userdel -r olduser
```

### 用户权限

`Linux` 使用权限系统来控制谁可以访问和修改文件及目录。权限被分配给三类用户：文件的所有者（`user`）、与文件关联的组（`group`）以及所有其他用户（`others`）。基本权限包括：

- `读取 (r)`：允许读取/查看文件或列出目录内容。
- `写入 (w)`：允许修改文件或目录。
- `执行 (x)`：允许执行文件或进入目录。

可以使用 `ls -l` 命令查看权限，它会显示文件和目录的信息，包括权限、所有者、大小和修改日期：

```
$ ls -l myfile.txt
```

### 更改权限

你可以使用 `chmod` 命令更改权限。例如，赋予所有者读取和写入权限：

```
$ chmod u+rw myfile.txt
```

从其他用户移除写入权限：

```
$ chmod o-w myfile.txt
```

### 所有权与组

`chown` 命令允许你更改文件的所有者和组。例如，将文件的所有者更改为某个用户和组：

```
$ sudo chown owner:group myfile.txt
```

### 特殊权限

还有一些特殊的权限和设置，例如 `setuid (suid)`、`setgid (sgid)` 和粘滞位 (`sticky bit`)，它们可以应用于文件和目录，用于权限提升以及防止共享目录中的文件被特定目的。

### 结论

理解 `Linux` 用户管理和权限对于维护系统安全和控制资源访问至关重要。通过使用用户账户、管理组和分配权限，管理员可以确保用户拥有适当的访问级别，并根据系统要求限制其操作。`Linux` 健的权限系统提供了对谁可以操作文件和目录的细粒度控制，是系统安全的强大工具。

## 3.5. 探索进程管理

进程管理是操作 `Linux` 系统的关键方面。理解进程如何工作、监控它们以及控制其行为，对于系统管理员和用户来说都是重要的。在本节中，我们将深入研究 `Linux` 中的进程管理。

### 什么是进程？

`Linux` 中的进程代表一个正在执行的程序或任务。当你运行一个程序时，它作为一个新进程启动。每个进程都会被分配一个唯一的进程 ID (`PID`)。进程可以在前台运行（与用户交互），也可以在后台运行（无需用户干预即可执行任务）。

### 查看运行中的进程

`ps` 命令用于列出系统中运行的进程。默认情况下，它显示与当前终端会话相关的进程。要列出所有进程（包括其他用户的系统进程），可以使用 `ps aux` 命令：

```
$ ps aux
```

该命令提供了每个进程的详细信息，包括用户、`PID`、`CPU` 和内存使用情况等。

`Linux` 提供了几个用于进程管理的命令：

- `top` 和 `htop`:
  
  这些命令显示系统进程的动态、实时视图，并按 `CPU` 使用率等各种标准进行排序。它们对于监控系统性能非常有用。

  ```
  $ top
  ```

- `kill`:
  
  `kill` 命令用于向进程发送信号。最常用的信号是 `SIGTERM`，它礼貌地请求进程终止。要终止一个特定 `PID` 的进程：

  ```
  $ kill PID
  ```

  若要进行更强制的终止，可以使用 `SIGKILL`：

  ```
  $ kill -9 PID
  ```

- `pkill`:
  
  `pkill` 允许你根据进程名称终止进程，简化了进程终止流程。例如，要终止所有名为“myprocess”的进程：

  ```
  $ pkill myprocess
  ```

- `killall`:
  
  与 `pkill` 类似，`killall` 通过名称终止进程。例如，终止所有名为“myprocess”的进程：

  ```
  $ killall myprocess
  ```

- `bg` 和 `fg`:
  
  这些命令用于管理在后台运行（`bg`）的进程，或将后台进程带到前台（`fg`）。例如，如果你有一个挂起的的进程，可以通过以下命令将其带回前台：

  ```
  $ fg
  ```
