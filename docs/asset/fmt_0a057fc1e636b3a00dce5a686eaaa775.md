
| `${name#pattern}` | 从 `name` 中删除开头的模式。如果 `name` 不以 `pattern` 开头，则表达式替换为 `name` 的值；第一种形式删除最小后缀，第二种形式删除最大的匹配。 |

| `${name%%pattern}` | 从 `name` 中删除末尾的模式。如果 `name` 不以 `pattern` 结尾，则表达式替换为 `name` 的值；如果是剩余前缀。第一种形式删除最小的匹配模式，第二种形式删除最大的匹配模式。 |
