
循环标签（labels）必须以字母开头，可以包含任意数量的字母、数字和下划线。唯一的限制是，你不能使用与 Perl 中具有特殊含义的单词相同的标签名：

```
if: while ($x == 0) { # this is an error in perl
...
}
```

当 Perl 看到 `if` 时，它不知道你是指标签 `if` 还是 `if` 语句的开始。

像 `if` 这样在 Perl 中具有特殊含义的单词被称为*保留字*（reserved words）或*关键字*（keywords）。

## 使用 `die` 终止执行

正如你所看到的，`last`语句终止循环。要完全终止程序执行，请使用 `die()` 函数。

为了说明 `die()` 的用法，请参阅本书光盘 上的文件 `LIST 5_6`，这是一个简单的程序，用于除法单行提供的两个数字。`die()` 将其参数写入标准错误文件 `STDERR`，然后立即退出。在这个示例中，当输入行中没有恰好两个数字，或者第二个数字为零时，就会调用 `die()`。

如果你愿意，可以告诉 `die()` 在程序终止时打印 Perl 程序名和正在执行的行号。要做到这一点，请不要在消息中留下结尾的换行符：

`die("This prints the filename and line number");`

如果包含了结尾的换行符，则不包含文件名和行号：

`die("This does not print the filename and line number\n");`

## 从文件读取和写入文件

到目前为止，所有的示例都是从标准输入文件 `STDIN` 读取，并写入到标准输出文件 `STDOUT` 以及标准错误文件 `STDERR`。你也可以对任意数量的其他文件进行读取和写入。

要在 Perl 程序内部访问 UNIX 文件系统上的文件，你必须执行以下步骤：

1. 你的程序必须打开该文件。这告诉系统你的 Perl 程序想要访问该文件。
2. 程序可以从文件读取或写入文件，取决于你是如何打开该文件的。
3. 程序可以关闭该文件。这告诉系统你的程序不再需要访问该文件。

接下来的章节将描述这些操作，告诉你如何从命令行指定的的文件文件中读取内容，并描述内置的文件测试操作。

### 打开文件

要打开一个文件，请调用内置函数 `open()`：

`open(MYFILE, "/u/jqpublic/myfile");`

第二个参数是你想要打开的文件名。你可以提供完整的 UNIX 路径（如 `/u/jqpublic/myfile`），也可以只提供文件名（如 `myfile`）。如果只提供文件名，则假设该文件位于当前工作目录。

第一个参数是文件句柄（file handle）的示例。文件打开后，你的 Perl 程序通过引用此句柄来访问文件。你的文件句柄名必须以字母或下划线开头，可以包含任意数量的字母、下划线和数字。（但是，你必须确保你的文件句柄名与保留字相同，例如 `if`。有关保留字的更多信息，请参见“使用标签块进行多级跳转”章节中的注释。）

默认情况下，Perl 假设你想读取你打开的任何文件。要为了写入打开文件，请在文件名前面加上一个 `>`（大于）字符：

`open(MYFILE, ">/u/jqpublic/myfile");`

当你打开一个文件进行写入时，任何现有内容都会被破坏。你不能同时对同一个文件进行读取和写入。

要向现有文件追加内容，请在文件名前面加上两个 `>` 字符：

`open(MYFILE, ">>/u/jqpublic/myfile");`

你仍然不能从正在追加的文件中读取，但现有内容不会被破坏。

### 检查打开是否成功

`open()` 函数返回两个值之一：

- 如果打开成功，`open()` 返回真（非零值）。
- 如果发生错误（即：文件不存在或你没有权限访问该文件），`open()` 返回假（零）。

你可以使用 `open()` 的返回值来测试文件是否实际上可用，如果不可用，则调用 `die()`：

```
unless (open(MYFILE, "/u/jqpublic/myfile")) {
 die("unable to open /u/jqpublic/myfile for reading\n");
}
```

这确保了你的程序不会尝试从一个不存在的文件中读取内容。

你也可以使用 `||`（逻辑或）运算符来代替 `unless`：

```
open(MYFILE, "/u/jqpublic/myfile") ||
 die("unable to open /u/jqpublic/myfile for reading\n");
```

这之所以有效，是因为只有当左侧为假时，才会执行 `||` 运算符的右侧。关于 `||` 运算符的更多信息，请参见“执行比较”章节。

### 从文件中读取

从文件中读取，将文件名放在尖括号内：

`$line = <MYFILE>;`

这从 `MYFILE` 读取一行并存储在 `$line` 中。

### 写入文件

向文件写入，请在字符串后面指定文件句柄：

`print "This is another line\n", MYFILE;`

### 关闭文件

当你完成时，可以通过调用 `close()` 告诉系统你已完成：

`close(MYFILE);`

### 确定文件的状态

如果你想测试文件是否存在，可以使用 `-e` 运算符：

```
if (-e "/u/jqpublic/myfile") {
 die("unable to open /u/jqpublic/myfile for reading\n");
}
```

这确保了你的程序不会尝试从不存在的文件中读取。

你也可以使用 `||`（逻辑或）运算符来代替 `unless`：

```
open(MYFILE, "/u/jqpublic/myfile") ||
 die("unable to open /u/jqpublic/myfile for reading\n");
```

### 从一系列文件中读取

许多 UNIX 命令的形式为 `command file1 file2 ...`。这些命令操作所有指定的文件。你可以在 Perl 中模拟这种行为。使用 `<>` 运算符。

本书光盘上的 `LIST 5_7` 统计所有文件中“the”出现的次数。假设这个示例存储在一个名为 `thecount` 的文件中。如果命令行输入 `thecount myfile1 myfile2 myfile`，程序从 `myfile1` 读取一行到标变量 `$inputline`。该行被分成单词，并测试每个单词是否为“the”。处理完该行后，程序从 `myfile1` 读取另一行。

当 `myfile1` 结束后，程序开始读取 `myfile2`，然后 `myfile3`。当 `myfile3` 结束后，程序打印三个文件中“the”出现的总次数。

## 使用子函数

某些程序重复执行任务。如果你正在编写这样的程序，可能会厌倦反复编写相同的代码。Perl 提供了一种解决问题的方法：经常使用的代码段可以存储在独立的部分中，称为子函数。接下来的章节将描述子函数如何工作、如何向子函数传递值并从它们接收值，以及如何定义仅存在于子内部的变量。

**表 5.3. 文件状态运算符。**

| 运算符 | 条件 |
| :--- | :--- |
| -d | 是否为目录？ |
| -e | 文件是否存在？ |
| -f | 是否实际上是文件？ |
| -l | 是否为符号链接？ |
| -o | 是否由运行程序所有？ |
| -r | 是否可由运行程序读取？ |
| -s | 是否是非空文件？ |
| -w | 是否可由运行程序写入？ |
| -x | 是否可由运行程序执行？ |
| -z | 是否为空文件？ |
| -B | 是否为二进制文件？ |
| -T | 是否为文本文件？ |

Perl 的一项常见任务是从文件中读取一行输入并将其拆分为单词。这是一个执行此任务的子程序示例。请注意，它使用了“从文件序列中读取”章节中描述的 `<>` 运算符。

```
sub getwords {
 $inputline = <>;
 @words = split(/\s+/, $inputline);
}
```

所有的子程序都遵循这种简单的格式：保留字 `sub`、子程序的名称（在本例中为 `getwords`）、一个 `{`（左大括号字符）、一个或多个 Perl 语句（也称为子程序的体），以及一个闭合的 `}`（右大括号）。

子程序名称必须以字母或下划线开始，然后由任意数量的字母、数字和下划线组成。（与一常一样，你必须确保你的变量名不是保留字。有关保留关键字的更多信息，请参见“使用标签块进行多级跳转”章节中的注释。）

子程序可以出现在 Perl 程序的任何位置——如果你愿意，甚至可以放在正中间。然而，如果所有子程序都放在末尾，程序通常会更容易理解。

### 使用子程序

写完子程序后，你可以通过指定它的名称来使用它。这是一个简单的示例，使用子程序 `getwords` 来统计单词 "the" 出现的次数：

```
#!/usr/bin/perl
$thecount = 0;
&getwords;
while ($words[0] ne "") { # 当行空时停止
 for ($index = 0; $words[$index] ne ""; $index += 1) {
 $thecount += 1 if $words[$index] eq "the";
 }
 &getwords;
}
print ("Total number of occurrences of the: $thecount\n");
```

语句 `&getwords;` 告诉 Perl 调用子程序 `getwords`。当 Perl 调用子程序 `getwords` 时，它会执行子程序包含的语句，即：

```
$inputline = <>;
@words = split(/\s+/, $inputline);
```

在执行这些语句后，Perl 会执行 `&getwords` 语句之后的后续语句。

在 Perl 5 中，如果子程序的调用出现在其定义之后，则可以省略调用中的 `&` 字符。

### 从子程序返回数值

之前定义的 `getwords` 子程序很有用，但它有一个严重的局限性：它假设输入行中的单词始终会被存储在数组变量 `@words` 中。这可能会导致问题：

```
@words = ("These", "are", "some", "words");
&getwords;
```

在这里，调用 `getwords` 会破坏 `@words` 的现有内容。

为了解决这个问题，请考虑你之前看到的过的 `getwords` 子程序：

```
sub getwords {
 $inputline = <>;
 @words = split(/\s+/, $inputline);
}
```

在 Perl 子程序中，子程序最后看到的值将成为子程序的返回值。在这个例子中，最后看到的值是赋值给 `@words` 的单词列表。在调用 `getwords` 时，此值可以赋值给数组变量：

`@words2 = &getwords;`

注意，这还没有解决问题，因为 `@words` 仍然会被 `getwords` 子程序覆盖。但是，现在你不需要在 `getwords` 中使用 `@words` 了，因为你正在通过返回值来分配单词列表。你现在可以将 `getwords` 修改为使用不同的变量：

```
sub getwords {
 $inputline = <>;
 @subwords = split(/s+/, $inputline);
}
```

现在，语句

```
@words = ("These", "are", "some", "words");
@words2 = &getwords;
```
可以正常工作了：当调用 `getwords` 时，`@words` 不会被破坏。（关于此问题的更好解决方案，请参见下一节“使用局部变量”。）

由于子程序的返回值是其最后看到的值，返回值可能并不总是你预期的那样。考虑以下简单的程序，它可以累加输入行中提供的数字：

```
#!/usr/bin/perl
$total = &get_total;
print("The total is $total\n");
sub get_total {
 $value = 0;
 $inputline = <STDIN>;
 @subwords = split(/\s+/, $inputline);
 $index = 0;
 while ($subwords[$index] ne "") {
 $value += $subwords[$index++];
 }
}
```

乍一看，你可能认为子程序 `get_total` 的返回值是存储在 `$value` 中的值。然而，这并不是子程序中最后看到的值！

注意，当 `$subwords[index]` 为空字符串时，循环退出。由于循环退出后没有处理任何语句，子程序中最后看到的值实际上是空字符串。因此，空字符串就是返回值。为了解决这个问题，请始终让你想要返回的值放在最后：

```
sub get_total {
 $value = 0;
 $inputline = <STDIN>;
 @subwords = split(/\s+/, $inputline);
 $index = 0;
 while ($subwords[$index] ne "") {
 $value += $subwords[$index++];
 }
 $value;
}
```

### 使用局部变量

正如你在“从子程序返回数值”中所看到的，使用 `local()` 可以确保变量只在子程序内部已知。如果你使用的是 Perl 5，可以使用 `my()` 语句来定义仅在定义块中已知的变量：`my($inputline, @subwords);`。`my()` 的语法与 `local()` 。

### 向子程序传递值

通过允许子程序接收值，可以让它们变得更加灵活。作为一个示例，这里是修改后的 `getwords` 子程序，它使用传递它的模式来拆分输入行：

```
sub getwords {
 local($pattern) = @ARGV;
 local($inputline, @subwords);
 $inputline = <>;
 @subwords = split($pattern, $inputline);
}
```

数组变量 `@_` 是一个特殊的系统变量，包含了传递给子程序的副本。语句 `local($pattern) = @_;` 创建了一个名为 `$pattern` 的局部标量变量，并将数组 `@_` 的第一个值赋值给它。数组变量 `@_` 的行为与其他任何数组变量相同。特别是它的分量可以作为标量值使用：

`$x = $_[0];`

通常，将 `@_` 赋值给局部变量是最好的方法，因为这会让你的子程序更容易理解。

你可以让一个子程序调用你写的另一个子程序。例如，这里有一个计算输入行中单词数的子程序：
