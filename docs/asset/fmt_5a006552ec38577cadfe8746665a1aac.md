# 1386 微气象学

作为母彗星或小行星，取决于尺寸，其寿命仅为几十年到一千年，随后它们会被破坏或与粒子碰撞。粒子受到来自太空辐射的撞击，微小颗粒吸收了太阳风赋予的大量动量，然后由于辐射压力作为太阳粒子被发射。参见小行星（`ASTEROID`）；彗星（`COMET`）；宇宙射线（`COSMIC RAYS`）；太阳风（`SOLAR WIND`）；风（`WIND`）。

微气象学的收集与分析为大气内部光和辐射的性质提供了重要信息源。通过 `UZ` 在平流层中收集微流体，其飞行高度为 `12` 英里（`20` 公里），在该高度，陆地颗粒非常稀少。微流体通过直接撞击从飞机窗伸出到环境大气的石质板从平流层中收集。在暴露数小时后，这些颗粒被送回实验室，在其上安装针头和销，然后用电子显微镜、质谱仪和其他仪器进行检查。其尺寸范围通常限制在直径 `2` 到 `100 μm` 之间。超过此限制的多数粒子形成宇宙球。

微气象学：研究与大气与地球土壤或水体边界条件相互相关的小尺度气象过程，这些取决于边界层内部的相互作用。动量、热量、水蒸气、气体和颗粒通过大气边界层的湍流和地面的平流进行垂直传输。这些相互作用对于向大气提供通量至关重要，决定了大规模天气和气候模式。微气象学还包括大气如何影响边界层以及颗粒在表面的沉积。

在许多情况下，时间尺度在 `15` 分钟到 `1` 小时之间的大气运动范围很广。微气象学与其他气象学领域之间有特殊的区别。微气象学处理尺度短于天气尺度（时间尺度小于 `15` 分钟）与空间尺度（空间尺度小于 `2` 到 `10` 公里 [`1-6` 米]）之间时间隙的现象。微气象学研究的现象包括尘卷、流星、露水和霜形成、蒸发和云漂。参见污染（`POLLUTION`）；大气（`ATMOSPHERE`）。

气象学的大部分理解是通过研究局部、平坦、均匀区域的状况获得的，这些区域并不代表更大的区域。这些研究将注意力限制在对地球表面具有显著代表意义的尺度上。复杂地形（即丘陵、山脉）的微气象学对于预测塔和飞机的行为以及风力发电器的规划至关重要。另一个兴趣是研究表面条件变化的区域（如森林、湖泊和河流）的微气象学。在这些情况下，理解与每个表面相关的微气象学如何相互作用以产生对局部大气水分的观测效应至关重要。参见气候学（`CLIMOLOGY`）；山区气象学（`MOUNTAIN METEOROLOGY`）；天气预报与预测（`WEATHER FORECAST AND PREDICTION`）。

微尺度气象特征太小，无法通过正常和国际观测网络观测。微气象现象必须通过使用设计仪器的特殊实验进行研究。仪器必须能够测量湍流波动。必须测量具有快速波动的速度，并使用高质量计表以减少误差。其他仪器使用风速或测量加热空气的温度。它们的设计确保了时间常数的正确。
