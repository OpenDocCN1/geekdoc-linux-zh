
`XSetFillStyle` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

要设置给定 GC 的填充规则，请使用 `XSetFillRule`。

```
XSetFillRule(display, gc, fill_rule);
```

`display` 指定到 X 服务器的连接。

`gc` 指定 GC。

`fill_rule` 指定要为指定的 GC 设置的填充规则。你可以传递 `EvenOddRule` 或 `WindingRule`。

`XSetFillRule` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

# 设置填充瓦和点彩

某些显示器具有硬件支持，可以使用特定尺寸的模式进行填充或点彩。限制在特定尺寸的填充和点彩操作比具有任意尺寸模式的操作快得多。你可以使用 Xlib 函数来确定显示器的最佳尺寸、瓦或点彩，以及设置瓦或点彩的大小和起点。

要获取瓦、点彩或光标的最佳尺寸，请使用 `XQueryBestSize`。

```
Status XQueryBestSize(display, class, which_screen, width, height, width_return, height_return);
```

`display` 指定到 X 服务器的连接。

`class` 指定你感兴趣的类。你可以传递 `TileShape`、`CursorShape` 或 `StippleShape`。

`which_screen` 指定屏幕上的任何可绘制区域。

`width` 指定宽度和高度。

`height`

`width_return` 返回显示器硬件支持的对象宽度和高度。

`height_return`

`XQueryBestSize` 函数返回与指定尺寸的最佳或最接近的尺寸。对于 `CursorShape`，这是在 `which_screen` 指定屏幕上可以完全显示的最大尺寸。对于 `TileShape`，这是填充速度最快的尺寸。对于 `Stipple`，这是可以点彩的尺寸。对于 `CursorShape`，可绘制区域表示所需的屏幕。对于 `TileShape` 和 `Stipple`，可绘制区域表示屏幕以及可能存在的窗口类和深度。`InputWindow` 不能作为 `TileShape` 或 `Stipple` 的可绘制区域，否则会发生 `BadMatch` 错误。

`XQueryBestSize` 可能会产生 `BadDrawable`、`BadMatch` 和 `BadValue` 错误。

要获取最佳瓦尺寸，请使用 `XQueryBestTile`。

```
Status XQueryBestTile(display, which_screen, width, height, width_return, height_return);
```

`display` 指定到 X 服务器的连接。

`which_screen` 指定屏幕上的任何可绘制区域。

`width` 指定宽度和高度。

`height`

`width_return` 返回显示器硬件支持的对象宽度和高度。
