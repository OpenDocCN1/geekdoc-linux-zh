# 图 15.24 被动进程打开连接

被动进程等待连接。它创建一个 `socket` 在其上监听请求并阻塞在 `accept()` 调用上。当活动端调用 `connect()` 时，`accept()` 调用与远程同步以建立连接（这与图 15.19 代码序列相同）。在进程完成使用该连接后，它通过 `close()` 系统调用删除 `socket`。
