对于低电阻电路的故障定位，图 2 显示了带有测试接地电路的 Murray 回（Murray loop）。使用一个“良好”导体在故障点之外的方便位置通过测试连接连接到故障点处。通过调整蜂鸣器直到其变为静音来确定故障，如图 2 中的检测器所示所示。比率 `R_A/R_B` 是线路与接地壳之间电容的比值。由于每个电容与连接到桥路的线路长度成正比，因此故障位置与长度直接正比。因此，一旦确定了比例，根据公式 (1)-(3) 给出的积以及电路总长度的知识，即可确定故障位置。

```
$R_C \alpha (1-x) = R_O \alpha x$
$R_A/R_B = R_C/R_D = (2-x)/x$
$x = 2/(1+R_A/R_B)$
```

# 代谢与循环

代谢物质从一个器官运输到另一个器官的循环。最终，代谢产生的气体、营养物质和废物跨细胞膜进行交换。扩散是分子从高浓度到低浓度的运动。从一个地方移动到另一个地方的物质量取决于点之间的浓度和距离。梯度越大，在给定持续时间内单位时间内移动的物质就越多。因此，在所有微小生物中，细胞的对流（或循环）必须被扩散取代。

原生扩散发生在细胞间水平。在多细胞生物中，每个细胞都由液体或血液包围。在海绵和腔体动物中，水通过肌肉活动或衬在通道的细胞上的纤毛泵入身体。腔体动物由两个细胞层形成。外胚由非胶质物质（基质）从身体内部形成。所有高等动物都有三层细胞，内胚由中胚层形成。中胚渗透并为充满液体的腔体提供支持。腔体由内胚（内层）与外层隔开。腔体通过身体运动或肌肉活动移动，用于向全身运输营养物质。

当血液位于空间（细胞外液）中时，血管系统被称为循环系统。此类系统的主要成分是心脏和血管。在这种系统中，血液由心脏泵出，通过特殊通道（血管），与毛细血管中的组织相关，以及只有一端是血管的纤维。在某些情况下，环节动物（节段虫和水蛭）、腔体动物（软体动物和八足类）、棘皮（海胆）和脊椎动物中可以发现闭式血管系统。参见血管；心脏（脊椎动物）。

# 464 藤壶目

肝硬化的征象和症状缺乏特异性，通常与并发症有关。肝脏发生纤维化，通过肝的血流受阻。这导致门静脉高血压，即门静脉压力增加。血流阻塞还导致脾大（splenomegaly）。此外，大多数肝硬化患者会出现腹腔积水（ascites），且自发性失禁的风险增加。此外，胆管经常被结缔组织部分阻塞。这导致黄疸（即皮肤和脏器变黄），并可能导致肾衰竭。此外，患者肝细胞癌的发生率增加，虽然可能稍早，但随着疾病进展会变得不可控制。肝硬化的治疗目前尚不确定。

肝硬化的治疗主要旨在减少并发症。静脉瘤出血（侧支静脉通道）是肝硬化的常见症状。采用多种技术来控制出血。在严重高血压的情况下，通过建立血管分流以绕过肝脏来降低门静脉压力。最常见的方法是将门静脉通过手术连接到下腔静脉，使门静脉中的血液不通过肝脏。肝硬化全身性疾病。

许多商业盐是钠和钾盐，也有钙盐、双铵和铁盐（配合物）。柠檬酸是较强的有机酸，易溶于水。柠檬酸及其盐被广泛使用，因为它们无毒、安全且易生物降解。柠檬酸大量存在于柑类水果中。也出现在其他水果、蔬菜以及动物和液体中。柠檬酸循环（三羧）调节大多数生物碳水化合物、脂肪和蛋白质的代谢转化。参见柠檬酸。

今天所有的商业柠檬酸都是通过发酵产生的。通过霉菌（黑曲根菌）和深层发酵（醋酸酵母）的过程使用多种底物，包括蔗糖、蜜糖、酶处理的淀粉和普通淀粉。柠檬酸通过溶剂提取或通过与硫酸处理并以钙盐的形式沉淀，从发酵液中回收，得到硫酸钙和柠檬酸。钙盐通过过滤除去，柠檬酸溶液通过从热水溶液中结晶柠檬酸进行纯化（转变温度为 36.6 C 或 97.9 F）产生无水酸；从冷溶液中结晶得到一水合物。尽管尝试过化学合成，但从未在商业上取得成功。参见发酵；微生物学。

柠檬酸在食品和制药行业被广泛。它被用于产生酸味，并用于调味饮料、水果味饮料、果冻、果酱、糖果、浆果、水茶和葡萄酒。它还被用于某些罐头食品以使处理更有效，并与抗氧化剂一起螯合金属并延缓酶活性。参见食品制造。

# 柠檬 465

在药物领域，柠檬酸为泡腾片提供了调节 pH 值、酸味和清洁牙齿来源。它还用作抗凝剂。

柠檬酸由于其毒性低、生物降解性相对较低，也用于保持使用酸强度的应用。化学化学。

在物质中的作用包括对锅炉、反应器和加热器中的氧化铜进行准备和操作性清洁；通过金属钢储罐和管道；清洁混凝土地面。它还用于延缓二氧化钛结垢的沉积，并作为工业中的螯剂和 pH 控制剂。纺织化学。

异柠檬酸，被氧化为五碳的 α-酮二酸和二氧化碳 (`CO2`)。在第二次脱羧基反应中，在 CoA 的存在下，转化为 α-酮二酸和 CoA 分子。在随后形成四碳化合物琥珀酸的过程中，该反应的能量通过从鸟苷磷酸 (`GDP`) 和无机磷酸形成鸟苷三酸 (`GTP`) 来保存。从琥珀酸中去除两个原子形成丙酸。

# 柠檬酸循环

在其他物种的有氧细胞中，完成乙酰辅酶 (`A`) 的途径也称为克雷布循环或三羧酸循环。循环中产生还原的电子载体，并被转运载体烟酰胺核苷二核酰酸 (`NAD+`) 和黄素腺嘌核酸二磷酸 (`FAD`) 中的氧气氧化，产生 `NADH` 和 `FADH2`。一系列电子载体用于再生 `NAD+` 和 `FAD`，位于线粒体膜，能量通过名为氧化磷酸化的过程部分转化为 `ATP` 和无机磷酸。氧化产生的能量导致 `ATP` 的形成，每分子乙酰 CoA 最大产生 11 个 `ATP`。通过琥珀酸步骤磷酸化的 `GTP` 易于转化为 `ATP`，每个分子乙酰 CoA 产生 12 个 `ATP`。

循环的第一步涉及乙酰辅酶 (`A`) 与草乙酸缩合形成柠檬酸，一种六碳三羧酸化合物 (`B`)。羟基转移到相邻碳键形成 D-异柠檬酸。

乙酰辅酶由碳水化合物、脂肪和柠檬酸碳骨架形成。来源的起源和利用程度取决于特定类型的代谢能力以及有机体的生理状态。例如，大多数哺乳动物组织具有通过反应将糖转化为丙酮酸的能力，丙酮酸随后从细胞质质进入线粒体，并通过丙酮酸脱氢酶脱羧产生乙酰辅酶和二氧化碳。乙酰辅酶也是线粒体中脂肪酸氧化的终产物。柠檬酸循环在线粒体中进行，在某些细胞中缺失。例如，红细胞没有线粒体，因此不存在柠檬酸循环。`ATP` 是通过葡萄糖无氧转化为丙酮酸的糖酵解产生的。磷酸代谢。

## 香柠檬

香柠檬与所有柑橘类一样，是常绿植物，且怕霜。它多刺、芬芳、呈灌木状，且寿命较短。

果实可食用，皮厚，果肉多汁且持久。然而，它非常芳香，在古代备受重视，其果皮被用作食品和糖品的调味剂。外壳通常位于进口国；出口的果实位于出口国。

香柠檬油主要从叶子中提取，在美国用作小剂的驱虫剂，在法国则用作柠檬（citron）。参见水果（FRUIT）。
