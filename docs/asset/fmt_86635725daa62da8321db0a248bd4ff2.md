## 选项

- `-I include-file` 包含文件列表，每行一个，并将其视为每个文件都单独出现在命令行中。注意末尾的空格。当你也指定了排除的文件（`x` 函数修饰符）时，它们将优先于所有包含的文件。如果文件同时在 `exclude-file` 和 `include-file`（或命令行上）中被指定，则排除它。

- `-C directory` 对目录执行切换目录（参阅 `cd(1)`）操作，并对文件执行 `c`（创建）或 `r`（替换）操作。对文件使用短相对路径名。如果文件是点 `.`，则归档目录中的所有文件。此选项允许从多个没有密切共同父目录的目录中归档文件。

### 操作数

- `file` 要归档（当你指定 `c`、`r` 或 `u` 函数时）、提取 (`x`) 或列出 (`t`) 的普通文件或目录的路径。当文件是目录时，将操作应用于所有文件和（递归）子目录。目录部分不支持超过 255 字符。在未指定修饰符的情况下，不支持归档时，目录部分不能超过 155 字符。

- `file` 归档时，如果未指定 `tarfile` 且文件名超过 255 字符。在未指定 `E` 修饰符的情况下，不支持归档时，文件名部分不能超过 100 字符。

## 函数修饰符

你可以将这些字符与选择所需函数的字母结合使用：

- `b` 块因子。在读取或写入原始归档 (`f`) 时，`block` 参数指定每次读取或写入操作中包含的 512 字节块。最小值为 1，默认值为 20。最大值取决于可用内存和特定设备的块要求（详情请参阅 `mtio(7)`）。

- `B` 强制 `tar` 执行多次读取（如有），以读取足够填充块的字节。此函数修饰符使 `tar` 能够在以太网上工作，因为管道和套接字返回部分块。从标准输入读取时，默认选择 `B` 修饰符，以确保 `tar` 可以从短读中恢复。

- `e` 如果发生任何意外错误，立即报错并返回正退出状态。`SYS3` 环境变量会覆盖默认行为。

- `E` 使用扩展头写入 `tarfile`。与 `c`、`r` 或 `u` 选项配合使用；`x` 选项忽略。当使用扩展头写入 `tarfile` 时，维护修改时间的粒度为微秒而非秒。此外，支持超过 `PATH_MAX` 字符的文件名以及大于 8GB 的文件大小。在归档大文件、长文件名文件、UID/GID 扩展 2097151 或需要微秒级精度时，使用 `E` 修饰符。

- `f` 使用 `tarfile` 参数作为 `tarfile` 的名称。如果你指定 `f`，不要搜索 `/etc/default/tar`。如果你省略 `f`，使用环境变量 `TAPE` 指定的设备；否则使用 `/etc/default/tar` 中定义的默认值。如果 `tarfile` 的名称为 `-`，则写入标准输出或从标准输入读取。

# Examples

以下示例使用 `tar` 在挂载于 `/dev/rmt/0` 的磁带上创建家主目录的存档。

```
$% cd
$% tar cvf /dev/rmt/0 .
messages from tar
```

`c` 函数字母表示创建存档；`v` 函数修符输出 `tar` 正在操作的消息；`f` 函数修符指定指定的 `tar` 包（在本例中为 `/dev/rmt/0`）。命令行末尾的点 `.` 表示当前目录，是 `f` 函数修符的参数。

以下示例显示 `tar` 包的目录。显示的是 POSIX 区域的输出。

```
castle tar tvf /dev/rmt/0
rw-r--r-- 1677/04 2123 Mar 7 18:15 1999 /test.c...
castle$
```

列具有以下含义：

- 第 1 列是 `/.test.c` 的访问权限。

- 第 2 列是 `./test.c` 的用户 ID/组 ID。

- 第 3 列是 `./test.c` 的大小。

- 第 4 列是 `./test.c` 的修改日期。

- 第 5 列是 `./test.c` 的名称。

以下示例从存档中提取文件。

```
castle% xvf /dev/rmt/0
messages from tar
castle$
castle% xvf /dev/rmt/0
messages from tar
castle$
castle% xvf /dev/rmt/0
messages from tar
```

如果磁带有多个存档，每个存档由文件结束标记分隔。注意——在较早的版本中，上述场景无法正常工作，需要在每次 `tar` 调用之间干预 `mt(1)`。为了模拟旧行为，请使用非回绕设备名称。请查看 `mtio(7)` 手页的“关闭操作”部分。
