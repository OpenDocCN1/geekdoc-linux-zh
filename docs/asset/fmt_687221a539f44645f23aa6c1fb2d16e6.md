
# FTP 服务器配置选项

## 日志与系统日志

### `log security [keyword-list]`
允许将 FTP 用户违反系统安全规则的任何行为记录下来以供后续分析。`keyword-list` 参数是一个逗号分隔的关键字列表，允许为特定类型的 FTP 用户定义日志记录。支持 `anonymous`、`guest` 和 `real` 关键字。`anonymous` 关键字使此命令字符串仅适用于匿名 FTP 登录，`guest` 参数仅适用于访客账户，而 `real` 参数适用于登录 FTP 服务器的实际系统用户。

### `log syslog`
将文件传输日志消息重定向到 `syslog` 设施而不是 `xferlog` 文件。这在尝试进行集中式日志存储以及将日志信息用作基于主机的入侵检测系统的输入时很有用。

FTP 服务器上的用户访问级别和站点权限可以使用 `ftpaccess` 文件支持的选项进行控制。这些选项可用于创建用户类，每个用户类都有自己的可定义访问权限、受限文件/目录，甚至受限命令。

## 文件访问控制

### `allowretrieve absolute;relative class=[class-name] [...] [file-name] [...]`
允许在原本会被标记为不可检索时，将 FTP 服务器上的文件指定为可由特定用户检索。此选项可用于允许用户下载特定文件，或与给定 `file-name` 参数匹配的所有文件。它会覆盖任何会导致指定文件无法访问的先前 `noretrieve` 语句。此命令字符串中可以指定多个 `file-name` 参数，格式如下：

- `filename`—指定服务器上名称与 `filename` 匹配的任何文件。
- `/path/filename`—使用目录和文件名说明符指定服务器上的特定文件。
- `/path/`—指定服务器上特定目录的内容。

此命令字符串中的 `absolute|relative` 参数是可选设置，可用于指定指定的路径名应被视为绝对路径，还是相对于连接 FTP 客户端的 `chroot` 文件系统的路径。

此命令字符串中的 `class=` 参数也是可选设置，可用于将文件下载访问权限授予特定用户类，而不是 FTP 服务器上的所有用户。可以给出多个 `class=` 参数，也可以不给出任何参数（导致所有用户都受 `allowretrieve` 命令字符串影响）。

### `noretrieve absolute|relative class=[class-name] [...] [file-name] [...]`
允许将 FTP 服务器上的文件指定为对特定用户不可检索。此选项可防止用户下载特定文件或与给定文件名参数匹配的所有文件。可以在此命令字符串中指定多个文件名参数，格式如下：

- `filename`—指定服务器上名称与 `filename` 匹配的任何文件。
- `/path/filename`—使用目录和文件名说明符指定服务器上的特定文件。
- `/path/`—指定服务器上特定目录的内容。

此命令字符串中的 `absolute|relative` 参数是可选设置，可用于指定指定的路径名应被视为绝对路径，还是相对于连接 FTP 客户端的 `chroot` 文件系统路径。

此命令字符串中的 `class=` 参数也是可选设置，可用于撤销特定用户类别的文件下载访问权限，而不是 FTP 服务器上的所有用户。可以给出多个 `class=` 参数，也可以不给出任何参数（导致所有用户都受 `noretrieve` 命令字符串影响）。

## 用户类与根目录

### `anonymous-root [directory] [user-class] [...]`
允许为特定用户类指定根目录。与此命令字符串中列出的任何类匹配的用户在登录 FTP 服务器时将自动被 `chroot` 到 `directory`。如果未指定用户类，则命令字符串用于指定未被赋予显式根目录指定的匿名用户的根目录。

### `autogroup [group-name] [class-name] [...]`
允许在此命令字符串中指定的任何访问类中的用户自动将其有效组 ID 设置为与 `group-name` 参数匹配的 GID。这在基于组 ID 限制匿名用户的文件访问时很有用。

### `class [class-name] [type-list] [address-data] [...]`
允许根据登录 FTP 服务器的用户类型和用户的源 IP 地址指定特定用户类。这在定义用户访问级别和权限时提供了高度的可配置性。此命令字符串中的 `class-name` 参数是用于标识用户类以便进一步应用选项的字母数字文本标识符。`keyword-list` 参数是一个逗号分隔的关键字列表可将此类语句限制为特定类型的 FTP 用户。支持 `anonymous`、`guest` 和 `real` 关键字。`anonymous` 关键字使此命令字符串仅适用于匿名 FTP 登录，`guest` 参数仅适用于访客账户，而 `real` 参数适用于登录 FTP 服务器的实际系统用户。`address-data` 参数指定只有从特定源主机连接的用户才会被考虑在给定的用户类别中。可以提供多个 `address-data` 参数，格式如下：

- `[ip_address]`—单个 IP 地址。
- `[ip_address]:[netmask]`—带网络掩码的 IP 地址。
- `[ip_address]/[cidr]`—带 CIDR 数据的 IP 地址。
- `![address-data]`—否定标识符，指定不匹配给定地址参数的主机将被评估为真。
- `/[file-name]`—包含更多 `address-data` 参数的文本文件的绝对路径；每行一个。

### `guestgroup [group-name] [...]`
允许任何其组与此命令字符串中指定的组名之一匹配的用户作为访客用户进行身份验证。

### `guestuser [user-name] [...]`
允许 FTP 服务器将特定用户或用户组归类为访客用户，而他们本应作为真实用户进行身份验证。

## 传输限制

### `byte-limit raw|in|out|total [max-bytes] [class-name]`
对 `user-class` 中的用户可传输的字节数应用限制。此限制可以设置为应用于发送的字节、接收的字节或两者。`raw` 参数是可选设置，允许使用此命令字符串限制原始流量而不是仅发送/接收的数据文件。如果未指定 `user-class` 参数，此设置将适用于未明确指定 `byte-limit` 配置设置的所有用户类。

### `file-limit [raw] [in|out|total] [files-count] [class-name]`
限制 `class-name` 中用户可传输的文件数量。此限制可设置为适用于发送、接收或两者文件。`raw` 参数是可选设置，允许使用此命令字符串限制原始流量而不是发送/接收的数据文件数量。如果未指定 `class-name` 参数，此设置将适用于尚未明确赋予 `file-limit` 配置设置的全部用户类别。

### `limit-time * |anonymous|guest [minutes]`
允许限制用户会话连接到 FTP 服务器的时间。此选项不影响系统上的 `real` 用户，您可以使用此选项限制匿名或访客用户在单次会话期间连接到 FTP 服务器的时间。需要注意的是，任何用户在新会话中重新连接到服务器后，其全部分配时间将被恢复。

## 命令权限

### `chmod yes|no [keyword-list]`
允许为特定用户类或用户类组授予或撤销 `chmod` 命令权限。`keyword-list` 是一个逗号分隔的关键字列表，允许为特定类型的 FTP 用户控制 `chmod` 访问。支持 `anonymous`、`guest` 和 `real` 关键字。`anonymous` 关键字使此命令字符串仅适用于匿名 FTP 登录，`guest` 参数仅适用于访客账户，而 `real` 关键字适用于登录 FTP 服务器的实际系统用户。

### `compress yes|no [class-name] [...]`
允许为特定用户类别或用户类别组授予或撤销文件压缩权限。可以在命令字符串中指定多个类别。

### `delete yes|no [keyword-list]`
允许为特定用户类别或用户类别组授予或撤销删除命令权限。`keyword-list` 是逗号分隔的关键字列表，可用于控制特定类型 FTP 用户的删除访问。支持 `anonymous`、`guest` 和 `real` 关键字。`anonymous` 关键字使此命令字符串仅适用于匿名 FTP 登录，`guest` 参数仅适用于访客账户，而 `real` 关键字适用于登录 FTP 服务器的实际系统用户。

### `overwrite yes|no [keyword-list]`
允许为特定用户类别或用户类别组授予或撤销文件覆盖权限。`keyword-list` 是逗号分隔的关键字列表，可用于控制特定类型 FTP 用户的删除访问。支持 `anonymous`、`guest` 和 `real` 关键字。`anonymous` 关键字使此命令字符串仅适用于匿名 FTP 登录，`guest` 参数仅适用于访客账户，而 `real` 关键字适用于登录 FTP 服务器的实际系统用户。
