## SoundConverter

访问 SoundConverter 官方网站 https://soundconverter.org/ 了解有关 SoundConverter 的一切。

通过软件管理器安装 DEB/FLATPAK 软件包：

打开软件管理器并搜索 SoundConverter。

点击 SoundConverter，然后点击源选择框。

选择系统包或 Flatpak 并点击安装。

在终端中通过 APT 安装 SoundConverter：

输入以下命令：

```
sudo apt update
```

```
sudo apt install soundconverter
```

在终端中通过 Flatpak 安装 SoundConverter：

输入此命令：

```
flatpak install flathub org.soundconverter
```
