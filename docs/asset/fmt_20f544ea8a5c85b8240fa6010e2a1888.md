
`Prompt('Text description')`

该命令接受三个输入参数：

- 一个要被复制的用户配置文件
- 一个要创建的用户配置文件
- 为新创建的用户配置文件提供的文本描述

文本描述外，新创建的用户配置文件的属性均取自被复制的用户配置文件。

图 3.9B 显示了 `CpyUsr` 的 CL 处理程序 `CpyUsr001`。

## 图 3.9B

### CpyUsr001 CL 源

```
/* ============================================ */
/*/ Program...... CpyUsr001 = * /
/*/ Description...... Copy user = * /
/*/ = Command processing program for CpyUsr = * /
/*/ ============================================ */
```

```
Pgm Parm(
  &FromUser +
&ToUser +
&Text +
 )
```

```
/*/ ============================================ */
/*/ = Variable definitions = * /
/*/ ------------------------------------------- * /
```

```
/*/ ------------------------------------------- * /
/* - Input parameters - * /
```

```
Dcl &FromUser *Char ( 10 ) 
Dcl &ToUser *Char ( 10 ) 
Dcl &Text *Char ( 50 )
```
