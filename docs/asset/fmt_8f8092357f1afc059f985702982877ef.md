
另一个有趣的例子是椭圆曲线，通常由像方程 (2) 这样的方程定义，其中 `$A$` 和 `$B$` 是常数。像这样的对象被称为仿射代数集。我们存在于仿射 `n` 维空间中，记为 `$A^n$`，其定义为具有坐标 `x_1, ..., x_n` 的坐标空间。仿射代数集 `V` 的坐标环 `K[V]` 是通过从环境仿射空间上的多项式函数限制得到的 `V` 上的函数集。这些函数可以相加、相减和相乘（即它们形成一个环）。例如，抛物线的坐标环是满足 `y = x^2` 的 `x` 和 `y` 的函数。可以利用这种关系消除所有对 `y` 的引用，从而使抛物线的坐标环等同于 `x` 的多项式环。参见 [解析几何](https://example.org/analytic_geometry)；[环论](https://example.org/ring_theory)。

通过多项式的零集几何地研究问题，或通过坐标环的代数代数地研究问题，赋予了该学科许多力量和韵味。这导致了向其他学科应用的惊人增长。例如，整数 ..., -2, -1, 0, 1, 2, ... 形成一个在代数上类似于仿射直线坐标环的环，代数几何方法在数论中开始发挥核心作用。在研究字符串的路径空间和配分函数时，现代物理学家将曲线的模空间作为研究的核心对象。最后，工程和物理学中的许多微分方程最好通过代数几何来研究，尽管它们的解不是代数函数。参见 微分方程；数论。

## 藻酸盐

褐藻细胞壁的主要成分之一（干重的10–47%）。因其具有悬浮、乳化和凝胶特性而被提取，它是三种具有重大经济价值的藻类多糖之一，另外两种是琼脂和卡拉胶。藻酸的主要来源是 Fuaceae 科（石莼类）成员和 Laminariales 目（海带类），这些藻类自然生长在大西洋北部和太平洋北部的海岸上。

由于其胶体性质，藻酸盐在许多工业领域都有应用，特别是在食品、纺织、造纸、印刷、涂料、化妆品和制药行业。大约一半的消费量用于制造冰淇淋和其他乳制品，其中藻酸盐可防止粗大冰晶的形成并提供光滑的口感。作为涂料的添加剂，它能使颜料保持悬浮状态并最大限度地减少刷痕。藻酸盐凝胶用于制作牙科印模。参见 琼脂；卡拉胶；冰淇淋；牛奶；褐藻门。[C.S.R; R.L.Mo.e]

## 算法

算法研究是计算机科学的一个基本领域。在编写计算机程序以解决问题时，程序员使用计算机语言表达出一个能解决该问题的算法，从而将算法转化为计算机程序。参见 计算机编程。

### 操作

一个算法通常接受一些输入，在有限时间内执行一系列有效步骤，并产生一些输出。一个有效步骤是一种基本操作，至少原则上可以使用纸和笔来完成。在计算机科学理论中，如果一个步骤在图灵机或其任何等价物上是可行的，则被认为是有效的。图灵机是用于可计算性研究领域的一种计算机数学模型，该领域研究诸如哪些任务可以算法化执行，哪些不能等问题。参见 自动机理论；递归函数。

许多计算机程序处理大量数据。在此类应用中，以适当的结构组织数据以使数据处理更容易或更快是非常重要的。在计算机编程中，算法的开发者和适当数据结构的选择是紧密交织在一起的，关于一个的决策往往依赖于另一个的了解。因此，计算机科学中数据结构的研究通常与相关算法的研究齐头并进。常用的基本数据结构包括记录、数组、链表、栈、队列、树和图。

### 应用

许多算法在广泛的计算机应用中都很有用。这些基本算法被广泛研究，并被视为计算机科学的重要组成部分。它们包括用于排序、搜索、文本处理、解决图问题、解决基本几何问题、显示图形以及执行常见数学计算的算法。

- 排序将数据对象按特定顺序排列，例如按数值升序或降序排列。内部排序是对存储在计算机内存内部的数据进行排序。通过选择、交换或插入进行排序的简单算法易于理解且编码直接。但是，当要排序的对象数量很大时，简单算法通常太慢，可以使用更复杂的算法（如堆排序或快速排序）以获得可接受的性能。外部排序是对存储的数据记录进行排序。

- 搜索是在数据对象集合中寻找所需的数据对象。基本搜索算法包括线性搜索和二分搜索。线性搜索逐个检查数据对象序列。二分搜索采用更复杂的策略，在搜索大型数组时比线性搜索更快。

- 需要频繁搜索的数据对象集合可以存储为树。如果这样的树结构得当，搜索树将非常高效。

- 文本字符串是字符序列。处理文本字符串的高效算法（如将文本数据组织成行和段落的算法，以及在文档中查找给定模式出现的算法）是文字处理系统中必不可少的。高级编程语言中的源程序是一个文本字符串，文本处理是编译器的必要任务。编译器需要使用高效的算法进行词法分析（将单个字符分组为有意义的单词或符号）和语法分析（识别源程序的语法结构）。参见 软件工程；文字处理。

- 图对于建模相互连接的对象组非常有用，例如通过路线连接的地点集合。图算法适用于解决涉及对象及其连接的问题——例如，确定是否所有地点都相互连接，访问从给定位置可达的所有位置，或寻找从一个位置到另一个位置的最短路径。

- 数学算法在科学与工程中具有广泛应用。数学计算的基本算法包括生成随机数、执行矩阵运算、求解联立方程组和数值积分。现代编程语言通常为许多常见计算提供预定义函数，如随机数生成、对数、乘法和三角函数。

- 在许多应用中，计算机程序需要适应其环境的变化并保持良好的性能。使计算机程序具有自适应能力的一种方法是使用自组织结构，例如定期重组，使最可能被访问的组件放置在可以最有效地访问的位置。也可以设想一种能自我适应的自发育算法。在开发自适应计算机程序方面，生物进化一直是灵感的来源，并启发了进化计算方法，如遗传算法。参见 遗传算法。

- 某些应用需要大量计算，且需要按时执行。节省时间的一种方法是开发并行算法，通过同时使用多个处理器来解决给定问题。基本思想是将给定问题分解为子问题，并使用每个处理器解决一个子问题。处理器通常需要在彼此之间通信，以便合作。处理器可以共享内存，通过它进行通信，或者通过通信链路连接成某种类型的网络，如超立方体。参见 并发处理；多处理；超级计算机。[C.S.C.h]

### 成环反应

已经设计出若干种可生成脂环族环的有用方法。这些反应属于三种类型：开链前体中原子之间的 C-C 键形成、环加成或环异构化，以及更易获得的环的扩大或缩小。在环加成中，两个分子反应并形成两个键；在环异构化中，三个或更多分子结合形成三个或更多键。

两种脂环族化合物以大规模生产；两者都是石油工业的产品。环戊二烯 **(12)** 是在精炼过程中由石脑油馏分中的各种烷基双环戊烷形成的。它是一种高度活泼的二烯烃，自发地通过 `4 + 2` 环加成二聚化 [见下方反应]；它用作几种树脂中的共聚物。
