### scrollkeeper

一个用于文档的免费电子编目系统。它存储了由 `http://www.biblio.org/orf/omt/`（开源元数据框架 (`OMF`)）指定的元数据，以及从文档（目录）中提取的某些元数据。它提供了与元数据相关的各种功能以帮助浏览器，例如对注册的文档进行排序，或搜索元数据以找到符合一组标准的文档。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### scrollkeeper

ScrollKeeper 是一个文档编目系统。它管理元数据（如由开源元数据框架 (`OMF`) 指定），并提供了一个简单的 API 来帮助浏览器查找、排序和搜索文档目录。它还可以与网络上的目录服务器通信，以搜索不在本地系统上的文档。来自 Redhat 8.0 RPM

高级基于 IRC 的 IRC 客户端 ScrollZ 是一个基于 irc 代码的高级 IRC 客户端。它添加了通常在 irc 脚本中找到的功能，如 Toolz、PhoEnix、Gargoyle 和 Lice。这些脚本与 ScrollZ 之间的主要区别在于代码。irc 脚本占用大量的天数和内存空间且运行缓慢，而 ScrollZ 仅比 irc 多出几 KB 的空间，但运行比任何 irc 脚本都快。这是通过 C 代码而不是 irc 脚本语言实现的。这减少了内存和 CPU 的使用，并且运行得更快。来自 Debian 3.0r
