## Slack

访问 Slack 官方网站 `https://slack.com/intl/en-gb/` 了解关于 Slack 的所有信息。

通过软件管理器安装 DEB/FLATPAK 软件包：

- 打开软件管理器并搜索 `Slack`。
- 点击 `Slack`，然后点击“源选择框”。
- 选择系统软件包或 `Flatpak` 并点击安装。

通过 Snap Store 安装 Snap 软件包：

- 在 `Snap Store` 中查找 `Slack`。
- 点击 `Slack`，然后点击“源选择框”。
- 选择 `Snap` 下的最新/稳定版本并点击安装。

在终端中通过 `Snap` 安装 `Slack`：

输入此命令：

```
sudo snap install slack
```

在终端中通过 `Flatpak` 安装 `Slack`：

输入此命令：

```
flatpak install flathub com.slack.Slack
```
