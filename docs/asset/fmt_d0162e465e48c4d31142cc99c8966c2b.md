
### 文件格式

- `HDR` 文件（`*.pic`, `*.hdr`）也称为高动态图像（HDR），辐射图像文件捕捉了比显示器显示的更大的范围。HDRI 通常用作背景。
- `OpenEXR` 文件（`*.exr`）与 `HDR` 文件类似，`OpenEXR` 图像文件包含比显示器显示的更多信息。`OpenEXR` 由工业光魔公司（Industrial Light & Magic）开发，并用于所有电影的制作。

## 动画的文件命名

当你选择 `AVI` 或 `MOV` 以外的任何文件格式时，`VIZ` 会为动画的每一帧生成一个单独的文件。每个文件都赋予了一个数字，以便 `Adobe Premiere` 或 `Autodesk Combustion` 等视频编辑软件能够轻松确定它们的顺序。`VIZ` 将使用你在“渲染输出文件”（`Render Output File`）框中提供的名称。对于名称的其余部分，`VIZ` 将添加一个数字。例如，如果你使用 `Targa` 文件格式并将动画输出命名为 `Savoye`，`VIZ` 将创建一组名为 `Savoye0000.TGA`、`Savoye0001.TGA` 等的文件。

## 选择图像尺寸

静态图像的大小取决于展示的介质。例如，8x10 英寸打印的最小分辨率为 1024x768。较大的海报尺寸打印需要高得多的分辨率。然而，视频动画不会超过 752x480。分辨率将取决于你用于录像的设备尺寸。如果你使用过时的逐帧（`step-frame`）录制方法直接逐帧录制到录像带，你通常记录的是 512x486 的图像尺寸。实时视频播放设备可以使用看似奇异的尺寸，如 320x244 或 352x240。水平分辨率会被拉伸以适应屏幕尺寸，因此你使用的分辨率越高，最终输出中的细节就越多。动画的宽高比保持不变。你应该检查视频录制卡随附的文档，获取可用于录带的具体尺寸。

你可以使用图 14.17 所示的“打印尺寸向导”（`Print Size Wizard`），在最终目标是打印介质时快速确定合适的分辨率。打开对话框的方法：`Rendering` > `Print Size Wizard`。

## AVI 编码器

在本章前面的部分，你必须为动画文件选择一种视频压缩方法。有许多方法可用，但它们都会在某种程度上降低视频质量。某些方法旨在仅在计算机上演示视频，而另一些则专为电视显示器设计。

如果你的动画目标是计算机演示，很可能会使用 `AVI` 文件格式。`AVI` 允许你从多种压缩/解压缩方法（称为编码器）中进行选择。你已经接触了其中几种，但作为提醒，这里是常用编码器及其用途：

### 第三方编码器

第三方编码器可以免费或购买；最流行的是 `DivX` 编码器。当你使用 Windows 未自带的编码器时，请记住，想要查看你动画的人其系统中也必须安装该编码器。

- `cinepak`：专为计算机高质量视频播放设计。这种编码器被认为质量最好。
- `Intel Video`：专为高压缩率设计，最适用于多媒体。
- `RAW`：对视频不进行压缩。使用此方法可以在传输文件到 `Adobe Premiere` 等程序时保持最高的图像质量。
- `Microsoft RLE`：通过降低色彩深度来保持文件尺寸。主要为 8 位和 16 位动画设计。
- `Microsoft Video`：与 `RLE` 类似，降低文件的色彩深度。专为 8 位和 16 位动画及视频设计。
- `None`：对你的文件不进行任何压缩。像 `RAW` 一样牺牲了存储空间。

## 将动画写入 DVD

你可以渲染大型动画并将其刻录到 4.7GB 的廉价 `DVD-ROM` 中。你可以使用低于 100 美元的 `DVD` 刻录机，许多新电脑配备了这些用于制作 `DVD` 的设备。

## 总结

动画通常可以给观众尺寸和组成的感觉。能够制作高质量的动画意味着项目被接受或被拒绝的区别。

- `Master It`：在建筑上方和左侧渲染一段 10 秒的相机动画。
- `Output a still`：静态图像的处是可以允许花时间检查特定的视角。通常的分辨率比动画高，以便创建更好的图像。
- `Master It`：使用打印尺寸向导和渲染场景对话框处理从上一个练习创建的图像。图像应为 300 `dpi`，位于边界区域。
- `Render a shadow`：影子研究可以帮助确定植被或光影模式的需求。当项目涉及独立结构时，通常需要制作影子。
- `Master It`：使用 `Shadowmax` 更改建筑的位置，并创建从 6:00 到 9:00 间隔的图像。
- `Create a walkthrough`：穿行动画是特殊的动画，从个人穿过结构的视角定义动画。
- `Master It`：将相机分配到从正面接近、通过入口然后左转的路径。
- `Choose an animation file output`：`VIZ` 输出的文件在质量和大小上差异很大，你必须在两者之间找到一个折中方案。一个 60 秒长的、1280x1024 且无压缩的 `AVI` 可能高质量的选择，但它在大多数系统中无法播放的。选择正确的文件类型和设置是输出可用动画的关键。
- `Master It`：渲染四次同一个动画，保存为不同的 `AVI` 文件。每次重复更改编码器和或设置；然后比较输出质量和文件大小。所有动画保持相同的分辨率。
