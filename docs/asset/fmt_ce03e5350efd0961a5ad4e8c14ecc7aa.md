
# 混合计算机

在计算过程中的任何阶段，用户与计算机之间进行交互，并能在计算机运行期间改变参数，这是计算机使用中非常有益且能产生洞察力的部分。这种对计算响应的亲自动手交互在模拟计算机上很容易实现。对于数字计算机，交互通常通过计算机键盘终端在运行之间或在线停止-启动模式下进行。一种常用的系统将模拟计算机的速度和交互可能性与数字计算机的精度和编程灵活性结合起来。这种组合专门设计为混合计算机。

在现代模拟-混合控制台集成中，积分器的模式开关与数字计算机接口，以便在数字计算机控制下进行快速的动态运行迭代。数据以多种形式在拥有快速并行电路的模拟计算机和拥有顺序逻辑控制程序的数字计算机之间流动。特殊的高速模数转换器和数模转换器将模拟域中变量的连续信号表示与数字计算机的数值表示进行转换。控制和逻辑信号更直接兼容，只需要电平和时序兼容性。参见模数转换器；布尔代数；数模转换器。

混合模型的编程比上述描述的更为复杂的挑战，要求用户考虑模拟计算机的并行操作与数字计算机中逐步计算交织的情况。例如，在模拟太空飞行器的任务时，舱体控制动力学通常以连续形式在模拟计算机上处理，但与计算导航轨道的数字计算机交织在一起。参见计算机。

## 模拟态

具有相同总角动量、宇称和同位旋的邻近核同量异位素中的态。除了将一个或多个中子变换为占据与中子相同的单粒子态的等效数量质子的变换外，它们还具有几乎相同的核结构波函数。模拟态（或同位旋模拟态，IAS）已在整个元素周期表中观察到，表明同位旋是一个良好的量子数。参见角动量；L-自旋；核结构；宇称（量子力学）。

由于发现核子-核子相互作用近似为电荷无关，可以将质子和中子视为单个粒子——即核子——的不同电荷态。因此，含有 Z 个质子和 N 个中子的原子核中的一个能级（通常称为母态）可以预期在具有 Z + 1 个质子和 N − 1 个中子（且总核子数相同，A = Z + N）的邻近同量异位素中存在模拟态，其中质子可以预期占据与母态中相同的轨道。母态和模拟态之间的能量差主要源于模拟态中额外质子导致的静电库仑相互作用对总能量的贡献增加。从这个数值 `$M_u e_e` [静电能] 中减去中子-质子质量差 0.782 MeV（能量以原子质量标度给出）。这种计算的模拟态能量与其测量值之间的吻合通常相当精确，但不完全。原因是小的附加因素会影响能级能量，例如电磁效应、小电荷依赖的核相互作用、同位旋混合以及核结构效应。

对模拟态的研究提供了用于检验核理论的重要信息。例如，双电荷交换反应 `($\pi^+, \pi^-)$` [其中 `$\pi^+$` 和 `$\pi^-$` 分别代表带正电和负电的π介子] 已被用于识别双重同量异位素模拟态，即相差 2 个电荷单位的同量异位素中的模拟态。这些数据对于检验预测同量异位素多重体相对质量的各个公式非常有用。入射π介子束后的单电荷和双电荷交换反应也被用于研究建立在模拟态之上的共振。通过观察当衰变剩余核子处于核连续区时模拟态的粒子衰变，可以研究母态的单粒子结构。对模拟态宽度的测量提供了关于其碎裂的信息，例如与具有相同自旋和宇称但总同位旋低一个单位的态混合。[D.J.Ho]

## 模数转换器

一种将输入信号的某个特征值或幅度的信息（与标准或参考值比较）转换为信号离散状态形式的信息的装置，通常会给这些离散状态的各种组合赋予数值。

模数（A/D）转换器用于将模拟信息（例如音频信号或物理变量如温度、力或轴旋转的测量值）转换为适合数字处理的形式，这可能涉及以下任一操作：(1) 由计算机或逻辑电路进行处理，包括算术运算、比较、排序、定序和码转换；(2) 存储以供进一步处理；(3) 以数值或图形形式显示；以及 (4) 传输。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_119_0.png)

如果宽范围的模拟信号能够以足够的频率转换为适当数量的二进位数字（即比特），则该信号的数字表示形式可以通过嘈杂介质传输，而原始信号的精细结构不会发生太大退化。参见计算机图形学；数据通信；数字计算机。

转换涉及量化和编码。量化是指将模拟信号范围划分为若干离散量子，并确定输入信号属于哪个量子。编码是指为每个量子分配唯一的数字代码，并确定与输入信号对应的代码。最常见的系统是二进制系统，其中有 `$2^n$` 个量子（其中 `n` 为某个整数），按顺序编号；代码是一组 `n` 个物理二值电平或比特（1 或 0），对应于与该信号编号相关联的二进制数。

插图展示了输入信号范围的典型三比特二进制表示形式，被划分为八个量子。例如，位于满量程 3/8 附近（介于 5/16 和 7/16 之间）的信号将被编码为 011（二进制 3）。参见数制系统。[D.H.S.]

## 方差分析

方差分析将实验数据中的总变异分配给可归因于特定原因的分量。这种统计技术适用于满足以下条件的数据：(1) 来源效应是可加的，(2) 非受控或无法解释的实验变异（归类为实验误差）与其他变异来源独立，(3) 实验误差的方差是均匀的，以及 (4) 实验误差服从正态分布。当数据偏离这些假设时，解释方差分析结果时必须格外小心。统计检验表明各分量对观测变异的贡献。参见贡献, [R.L.Bir]

## 解析几何

数学的一个分支，其中应用代数来研究几何学；该学科也称为笛卡尔几何。几何学代数处理的基础是由有向直线 `g` 的元素“点”与构成所有实数集合的元素“数”之间存在一一对应关系所提供的。这种对应关系在 `g` 上建立了一个坐标系，`g` 上点 `P` 对应的数被称为其坐标。`g` 上坐标为零的点 `O` 是坐标系的原点。如果对于 `g` 上的每个点 `P`，其坐标是有向距离 `OP`，则 `g` 上的坐标系是笛卡尔的。那么，`g` 上 `O` 一侧的所有点都具有正坐标（构成 `g` 的正半部分），另一侧的所有点都具有负坐标。坐标为 1 的点称为单位点。由于关系 `OP + PQ = OQ` 对于有向直线 `g` 上任意两点 `P, Q` 显然是有效的，那么 `PQ = OQ - OP = q - p`，其中 `p` 和 `q` 分别是 `P` 和 `Q` 的坐标。

在平面上任选两条相交直线 `g_1, g_2`，在每条直线上选择笛卡尔坐标系，使得交点在两个系统中的坐标均为 0。对于平面上的每个点 `P`，都附加一个有序数对 `(x,y)` 作为其坐标，其中 `x` 是 `g_1` 与过 `P` 且平行于 `g_2` 的直线交点的坐标，`y` 是 `g_2` 与过 `P` 且平行于 `g_1` 的直线交点的坐标。直线 `g_1` 和 `g_2` 分别称为 x 轴和 y 轴。通常为了方便起见，两个轴取相同的比例尺；即连接两个轴上的单位点到原点的线段是全等的。记号 `P(x,y)` 表示具有坐标 `(x,y)` 的点 `P`。如果 `ω` 表示两个轴正半部分形成的角，`d` 表示点 `P_1(x_1,y_1)` 和 `P_2(x_2,y_2)` 之间的距离，应用余弦定律得出

```
d = \left[ (x_1 - x_2)^2 + (y_1 - y_2)^2 + 2(x_1 - x_2)(y_1 - y_2) \cos \omega \right]^{1/2}
```

由于 `$\cos 90^\circ = 0$`，取轴相互垂直可以简化此公式。虽然偶尔使用斜轴（`$\omega \neq 90^\circ$`）是有用的，但由矩形笛卡尔坐标系带来的简化使其成为通常的选择。随后的推导中假定使用了这种笛卡尔坐标系。因此，`P_1(x_1,y_1)` 和 `P_2(x_2,y_2)` 之间的距离 `d` 由 `$\left[ (x_1 - x_2)^2 + (y_1 - y_2)^2 \right]^{1/2}$` 给出。

平面解析几何基于几何实体“点”与算术实体“实数对”之间的对应关系，这导致将满足组成轨迹的所有（且仅那些）点的坐标的一个或多个方程与每个几何轨迹相关联（轨迹方程），并将由满足方程的数对确定的点与变量 `x, y` 的每个方程系统（方程的图形）相关联。因此，研究几何的代数方法与代数的几何解释相互平衡。解析几何中的一个中心问题是寻找曲线和曲面中某些重要图形的方程。参见曲线拟合。

利用两点距离公式和圆的定义，可以找到中心为 `C(x_0,y_0)` 且半径为 `r` (`r >= 0`) 的圆的方程为 `$(x - x_0)^2 + (y - y_0)^2 = r^2$`。

平面解析几何的很大一部分涉及一类曲线，它们（根据最初研究它们的方式）被称为圆锥曲线或二次曲线。圆锥曲线是点 `P` 的轨迹，该点移动时其到定点 `F`（焦点）的距离与到定直线（准线）（不经过 `F`）的距离之比恒为一个正常数 `e`（离心率）。设 `F` 的坐标为 `C(0)`，`c > 0`，取 y 轴为准线。则 `P(x,y)` 满足方程 `$(x - c)^2 + y^2 = ex$`；即 `$(1-e^2)x^2 + y^2 - 2cx + c^2 = 0$`，可以很容易看出，每个满足此方程的坐标的点都在该圆锥曲线上。因此，每个圆锥曲线都由笛卡尔坐标 `$(x,y)$` 的二次方程表示。根据 `e = 1, e < 1, e > 1`，圆锥曲线分别称为抛物线、椭圆或双曲线。参见圆锥曲线。
