
输入输出的最简单方法是使用 C 库的 `scanf` 和 `printf` 函数。这些函数可以处理几乎所有形式的文本输入输出，并在整数和浮点格式之间进行转换。

现代程序员可能熟悉 C++ I/O 而不熟悉 C。调用 C++ I/O 并不简单，而调用 C 函数非常简单。因此，可能需要对 C I/O 的两个基本支柱 `scanf` 和 `printf` 进行简要介绍。这些对于学习汇编语言的 I/O 需求已经足够。汇编语言的实际应用可能是编写不需要 I/O 的计算或位操作函数。因此，本附录将坚持基础知识，以便在学习汇编编程的同时便于编写完整的程序。

## 附录 B. 使用 SCANF 和 PRINTF

### B.1 scanf

解释如何使用 `scanf` 的简单方法是展示 C 调用，随后是其对应的汇编代码。`scanf` 的第一个参数是格式字符串。根据格式字符串的不同，可以有任意数量的额外参数。格式字符串内部包含一系列转换说明符。每个说明符都是一个百分号 `%` 后面跟着一个或多个定义要转换数据类型的字母。以下是基本的格式说明符：

| 格式 | 数据类型 |
| :--- | :--- |
| `%d` | 4 字节整数 |
| `%hd` | 2 字节整数 |
| `%ld` | 8 字节整数 |
| `%f` | 4 字节浮点数 |
| `%lf` | 8 字节浮点数 |
| `%s` | 字符数组（C 字符串） |

如果我们想读取一个 `double` 紧跟一个字符字符串，可以使用格式字符串 `"%lf %s"`。

`scanf` 的每个额外参数都是用于接收 `scanf` 读取并转换后的数据位置的地址。这里是一个 C 调用示例：

```c
double x;
char s[100];
scanf("%lf %s", &x, s);
```

`scanf` 将返回转换的项目数。在上面的调用中，如果成功输入了一个数字和一个字符串，它将返回 2。字符串将被放在数组 `s` 中，并在字符串末尾有一个 `0`。

以下是在汇编语言中实现相同的方法：

```assembly
segment .data
x dq 0.0
n dd 0
s times 100 db 0
fmt db "%lf %s",0
segment .text
lea rdi, [fmt]
lea rsi, [x]
lea rdx, [s]
xor eax, eax ; 没有浮点参数
call scanf
mov [n], eax
```

这里有几个陷阱。首先，格式字符串末尾需要一个 `0`，且不能包含在双引号内。其次，没有浮点参数——`&x` 是一个地址参数，并存储在 `rsi` 中，因此在调用之前必须将 `rax` 设置为 0。

### B.2 printf

`printf` 允许以多种格式进行打印。像 `scanf` 一样，它的第一个参数是格式字符串。格式字符串包含要打印的字符以及类似于 `scanf` 的转换说明符。用 `printf` 打印的数据可能被存储在缓冲区中，直到打印出换行符。在 C 中，换行符可以表示为格式字符串结尾的 `\n`。yasm 不支持字符串中的转义字符，因此必须显式地添加换行符（0x0a）和 0 字节。这里有一个 C `printf` 调用：

```c
char name[64];
int value;
printf("The value of %s is %d\n", name, value);
```

以下是汇编语言中的 `printf` 调用：

```assembly
segment .data
value dd 0
name times 64 db 0
fmt db "The value of %s is %d",0x0a,0
segment .text
lea rdi, [fmt]
lea rsi, [name]
mov rdx, [value]
xor eax, eax
call printf
```

`printf` 可以有浮点参数，所以要留心计数并恰当地设置 `rax`。

## 附录 C 在 yasm 中使用宏

yasm 提供了单行宏和多行宏。这两种宏都可以用于为常用指令提供具有意义的名称的缩写。虽然在学习语言时这些宏可能会掩盖汇编语言的机制，但在实际情况下它们具有重大的实用价值。

### C.1 单行宏

单行宏使用 `%define` 预处理器。假设你已经厌倦了看到换行符为 `0xa`。你可以定义一个宏：

```assembly
%define newline 0xa
```
