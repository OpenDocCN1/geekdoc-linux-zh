可用于安装操作系统。最常用的安装选项有：

- 使用硬盘安装操作系统。
- 借助 Kali Linux 启动 USB 启动盘安装操作系统。
- 借助 `VMware` 或 `VirtualBox` 安装操作系统。
- 借助双引导安装操作系统。

在所有可以在您的系统上安装 Kali Linux 的可用选项中，借助 `VirtualBox` 并使用启动 USB 启动盘安装操作系统是最常见的方法。如果您想使用 `VMware` 或 `VirtualBox` 安装操作系统，您的系统至少需要 20GB 的空闲硬盘空间以及至少 4GB 的内存。

- 在开始安装过程之前，您需要安装像 `VMware` 这样的虚拟化软件。您也可以选择其他选项，例如 Oracle 产品的 `VirtualBox`。完成虚拟化软件的安装后，从应用程序文件夹启动该软件。
- 您需要下载操作系统的安装文件，可以从官方网站轻松获取该文件。之后，启动虚拟机。为此，请打开您在系统上安装的虚拟化软件的主页，然后从选项中选择“`Create Virtual Machine`”。
- 创建新虚拟机后，选择 Kali Linux way系统的 `iso` 文件或镜像，随后选择客体操作系统。您还需要配置与虚拟机相关的每一个细节，例如 Kali Linux。在选择好 Kali Linux 虚拟机后，您可以轻松地启动与 Kali Linux 相关的虚拟机。选择虚拟机后，点击绿色的电源按钮。
- 虚拟机启动后立即，您将看到一个弹出的菜单，您需要在 `GRUB` 菜单中选择所需的所需的安装模式。选择“`Graphical Installation`”，然后选择“`Continue`”。
- 随后的屏幕将要求您确定与区域相关的信息，例如您想用于 Kali Linux 的语言、位置、键盘布局等。
- 完成所有这些操作后，您需要为 Kali Linux 虚拟机设置一个强密码。之后，安装程序将要求您选择时区，然后在分区步骤暂停。您可以选择“`Entire Disk Space`”或为虚拟机“`Create Separate Partition`”。
您需要保存所有更改，但不要继续过程，因为这将完全删除磁盘上的所有数据。因此，在继续之前，请务必先确认设置。
- 之后，系统将要求安装 `GRUB` 引导加载程序。选择“`Yes`”，然后选择用于保存引导加载程序信息的设备，这对于启动 Kali Linux 虚拟机是必要的。
- 点击“`Finish`”，安装程序将完成最终阶段程序。
- 也可以通过启动 USB 启动盘安装操作系统。

在渗透测试和伦理黑客方面，Kali Linux 已证明是一个相当可靠的软件。但系统有时会故障，重新安装变成一项乏味的工作。Kali Linux 安装失败背后可能有多种原因。这可能包括 `iso` 下载不完整或损坏、目标机器磁盘空间不足等许多问题。

Kali Linux 的安装程序确实可靠，但遇到错误或外部问题（如镜像源、网络问题等）是非常常见的。因此，在这些情况下，您只需要对安装过程进行故障排除以便继续进行。

每当 Kali Linux 安装程序失败时，都会出现显示“安装步骤失败（Installation Step Failed）”的屏幕。此时，您需要知道 Kali Linux 安装程序在多个虚拟控制台上运行：您可以在第五个控制台上看到主界面（对于图形界面安装程序使用 `CTRL+Alt+F5`），也可以在第一个控制台上看到主界面（对于文本安装程序使用 `Shift+F4`）。

在这两种情况下，通过 `CTRL+Shift+F4` 的第四个控制台将帮助显示安装程序内部确切正在发生的所有相关日志。您可以通过更详细的错误信息轻松地评估安装程序问题的原因，例如“安装程序日志屏幕（the log screen of installer）”，这表明目标机器空间不足，安装程序无法继续该步骤。

第三个和第二个控制台（分别为 `CTRL+Shift+F3` 和 `CTRL+Shift+F2`）托管了 `shell`，可以使用它们对当前状况进行更详细的调查。大多数命令行工具都由 `BusyBox` 提供，因此功能set较有限。但它们足够解决您在安装 Kali Linux 过程中可能遇到的大多数问题。

当您点击“安装失败（Installation Failure）”主界面上的“`Continue`”时，安装程序将带您回到一个在正常情况下不会看到的屏幕——Kali Linux 安装程序的主菜单（Main Menu）。此屏幕将让您能够逐个启动安装步骤。如果您能够借助安装程序 `shell` 访问解决问题，就可以轻松地从失败的步骤重新开始。

通过安装程序 `shell`，您可以使用命令 `debconf-get` 和 `debconf-set` 轻松地检查并修改 `debconf` 数据库。这些命令用于测试先前的值。可以使用 `more` 或 `cat` 检查任何文件，如位于 `/var/log/syslog` 的完整安装日志。您还可以使用 `nano` 编辑系统上安装的任何文件。

如果您仍然无法解决安装问题，可以提交 bug 报告。bug 报告需要包含安装程序的日志，可以通过主菜单中的“`Save Debug Logs`”轻松检索。

通过这种方式，您可以用多种方式导出日志，例如挂载的文件系统、软磁盘或 Web 上。保存调试日志最方便的方法是让 Kali Linux 安装程序启动一个用于托管日志文件的 Web 服务器。您可以从位于同一网络中的任何其他计算机上启动 Web 浏览器，然后下载所有可用日志文件。

还有其他各种简单的方法可以排除 Kali Linux 安装的故障。让我们来看看这些：

- 下载官方格式的 Kali Linux 镜像：确保您已从官方网站下载了 Kali Linux 的 ISO 文件。镜像文件有多种格式，如 ISO 文件、ARM 镜像和 VMware 镜像。ISO 文件有两种格式：32 位和 64 位。VMware 镜像预装了 VMware 虚拟机。VMware 镜像格式为 32 位 PAE。在 ARM 镜像的情况下，并非所有格式的镜像都能适用于所有 ARM 设备。在 Kali Linux 网站上，您可以找到各种设备的 ARM 镜像，如 rk3306 mk/ss808、`ODROID-U2/X2`、`Samsung Chromebook`、树莓派等。
- 验证下载镜像的 SHA1 校验：在下载 Kali Linux 镜像时，请确保检查了下载镜像旁提供的 `SHA1SUMS.gpg` 和 `SHA1SUMS` 文件。在验证镜像之前校验和，请确保 `SHA1SUMS` 文件是唯一一个由 Kali 生成的文件。
