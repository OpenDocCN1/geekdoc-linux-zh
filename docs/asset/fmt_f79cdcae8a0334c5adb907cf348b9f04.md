
如果你的驱动器最终锁定在一个你没有多少 DVD 的区域编码上，有一个好消息。那就是来自 Videolan 的 `libvdcss2`，这是与你在项目 15A 中安装的解码器包绑定的库，它允许你播放加密 DVD。除了基本功能外，即使你的驱动器已经锁定在一个区域，它还允许你播放多个区域的 DVD。它是通过对你的驱动器进行“加密攻击”（使用 Videolan 的术语）直到找到光盘密钥来实现的。当然，这个加密轰炸的过程可能需要几分钟，因此它不是绕过问题的最佳方法。这种绕过区域编码的过程是否合法仍然是一个争论的话题，所以如果你对此担心，应该做一些研究。

# Totem 视频播放器

Ubuntu 的默认视频播放器是 Totem，如图 17-3 所示，它的界面非常简单，使用起来也同样简单。你可以通过进入应用程序菜单并选择“音频和视频播放器”来运行 Totem。你也可以简单地将 DVD 放入驱动器来运行它，因为 Ubuntu 设置为每次这样做时都会运行 Totem。如果你手头没有 DVD 但想看 Totem 的运行情况，也可以通过双击系统示例文件夹中带的那个 Ubuntu 视频（`Experience Ubuntu.ogg`）来启动它。

## 切换 Totem

在继续之前，我应该提到，如果你在项目 15a 中安装了那两个解码器包，你使用的 Totem 与你第一次安装系统时使用的并不是同一个。你问这怎么可能呢？嗯，尽管我提到了所有简单性，Totem 有时也会让你非常头疼。你可能是幸运儿之一，但对我和其他许多人来说，Totem 就像被系在绳上的猫一样不听话（当然，不包括我的）。问题实际上不在于 Totem 本身，而是执行其视频处理的 gstreamer 后端。

![](img/ba6b82a7869bba748202d57c97336dca_303_0.png)

图 17-3：Totem 视频播放器

你看，Totem 仅仅是一个图形前端，为你提供了一种简单使用后台运行软件的方法——在这种情况下，后端是 gstreamer。当你安装了多媒体和 DVD 解码包时，gstreamer 版本的 Totem 被一个使用 Xine 后端的 Totem 版本取代了。它自动执行切换的原因是，设计者知道 Xine 在处理视频方面要配合得多。

如果你还没有切换并发现当前的 Totem 有问题，请尝试安装 Xine 版本以及其他多媒体解码器。此操作的说明在项目 15a 中，但为了节省你的精力，我在这里重复一遍步骤。只需 Automatik（应用程序 -> 系统工具 -> Automatik），一旦窗口打开，点击左窗的“插件（Plugins）”，然后点击右窗的“DVD 和多媒体解码器（DVD and Multimedia Codecs）”。点击“开始（Start）”按钮完成。

一旦完成，你不会在 Totem 前端发现任何变化，但你可能会开心得多，因为 Totem 现在按它应该的方式工作了。除了这些，你将体验到更好的音频（至少是音量）、更可靠的 DVD 播放，以及更少异常的 Windows Media Video（WMV）。如果之后仍然遇到问题，请尝试其他的。

## 使用 Kino 录制视频

图 17-6：使用 Kino 使用你的数字摄像机

要开始录制视频，你可以使用播放窗下方的播放控制按钮。这些控制按钮实际上控制着你相机本身的功能。首先点击回放按钮，直到到达你想要录制的视频段的开头。到达那里后，点击播放按钮，你相机上的视频就会在 Kino 窗口中播放。当你到达想要开始录制点时，点击 Kino 窗口播放控制按钮上方的 Capture（录制）按钮。随后，K 将开始将你的视频录制到磁盘（默认情况下在你的主目录下）。为了方便管理，录制的视频流将被拆分成几个文件，文件的数量取决于所播放视频的长度。

你会发现，在点击 Capture（录制）按钮后，播放窗中的视频播放将停止移动。在这种情况下，你需要查看相机视口中的动作，以确定你处于录制过程的哪个位置。当你到达想要开始录制的位置时，点击 Stop（停止）按钮。然后，你可以通过点击 Edit（编辑）按钮，并使用播放窗底部的播放控制按钮来查看录制的视频。你也可以在 Timeline（时间线）视图中（如图 17-7 所示）查看视频，以便在视频的不同片段之间进行导航；点击 Timeline 标签页，点击你想查看的片段，然后使用播放窗下方的播放控制按钮。

如果你想玩点艺术的，你还可以尝试 Kino 中提供的效果（部分示例见图 17-8），只需点击 FX 标签页，然后在 Video Filter（视频滤镜）下方的下拉菜单中尝试各种效果。做出选择后，通过在 Override（覆盖）单词下方的框中输入起始和结束帧数来指定你想要转换（或至少进行实验）的片段，然后点击 Preview（预览）按钮查看结果，而不将更改保存到磁盘。如果你想转换该片段以保留效果，请点击 Render（渲染）按钮，Kino 将创建一个仅包含该片段的新文件。这些文件以及原始录制文件都可以通过简单的双击文件在 Totem 中查看，Totem 是一个用于视频查看的应用程序。

# 其他视频应用

我已经涵盖了 Ubuntu 中主要的视频应用程序，但还有其他你可能想要考虑的程序。例如，一个非常流行的替代视频/DVD 播放器是 MPlayer，你可以通过在 Synaptic 中搜索 `mplayer` 来下载并安装。请确保不仅下载了 `mplayer`，还下载了 `mplayer-fonts` 以避免烦恼的错误信息。Mplayer 也可以通过 Automix 获取。

跨平台播放器 VLC Media Player 是另一个拥有大量支持者的播放器。它以良好地处理多种视频格式以及界面简单易用而闻名。你可以通过 Automix 获取它（点击左侧窗格中的 Media Players and Editors，点击右侧窗格中的 VLC Media Player，然后点击 Start）。

另一个你可能想要考虑的视频/DVD 播放器是 gxine，它在许多方面与 Totem 相似，但它带给你更多的控制权。同样，你可以通过 Synaptic 搜索 `gxine` 来下载并安装 `gxine`。

如果你不仅是一个视频观众，还是一个初涩的视频艺术家，那么你可能想要考虑几个实用的视频/DVD 审核和编辑工具：多平台视频编辑器 Avidemux（图 17-9）；QDVD-Author，一种类似于 iDVD 风格的 DVD 制作工具（尽管没有苹果产品那种浅面的修饰）；以及 DVD:Rip，正如你所想象的，它允许你将 DVD 内容刻录到硬盘上。你也可以通过 Synaptic 搜索 `avidemux`、`qdvauthor` 和 `dvdrip` 来获取这些应用程序。Avidemux 和 DVD:Rip 也可以通过 Automix 获取。

# 守卫巢穴

## 安全

许多 Windows 用户在经历了 Windows 世界中**恶意软件**的一系列糟糕经历后，进入了 Linux 的怀抱——病毒、间谍软件以及各种无法想象的无数恶意软件代码。Windows 还饱受了似乎无穷无尽的漏洞的困扰，使得系统很容易成为那些意图不轨的入侵者的易受猎物。每次进入网络空间都变得像是在医院的传染病房里穿行。对于 Windows 用户来说，有时感觉花费在对付病毒害虫系统和防御入侵者者身上的上的时间，似乎比实际完成工作的时间还要多。

幸运的是，Linux 并不受这类问题的严重困扰，这导致了广为人知的说法：Linux 几乎是免费的且非常安全。有许多理由来解释 Linux 抵抗恶意软件和漏洞的特性。其中一个原因仅仅是普及程度——或缺乏普及。由于 Linux 不像 Windows 系统那样广泛，因此它对于数字恶作者来说也是一个不那么吸引人的目标，这些恶作者通常受到创建一个真正的全球性病毒或发现一个此前未知的后门所带来的挑战和头条新闻式的光荣的驱动。

另一个原因是，通常情况下，Linux 用户在非特权模式下运行工作，在这种模式下，用户没有权利在没有密码的情况下安装软件。在 Windows 中，情况并非如此，至少默认情况下不是。因此，附加在电子邮件中或寄生在另一个文件或程序上的病毒或其他形式的恶意软件，会在你的 Linux 系统中安装自己而……嗯，理论上来说，这一点有一点问题。

还有结构性设计的问题。世界上每个系统都有可以被数字和人类敌人利用的安全性漏洞。在这方面，Windows 完全可以被称为操作系统中的“瑞士奶酪”。当然，Linux 也有漏洞，尽管比 Windows 少得多；而且 Linux 通过下载更新来修复它们。
