#### Linux 文件总结

- Linux 支持三种类型的文件。目录和普通文件是你最常处理的类型。
- 文件名长度最多可达 255 个字符。
- 非字母数字字符可用于文件名的任何位置。
- 以点号开头的文件名在列出目录时通常隐藏。使用 `ls -a` 列出隐藏文件。
- Linux 识别 `*` 和 `?` 通配符。
- `cp` 是复制文件的命令。
- `rm` 是删除文件的命令。
- `rm -i` 允许你在删除一组文件时，对每个文件选择“是”或“否”。
- `mv` 在文件操作中有两个功能：
  - (1) 重命名文件；
  - (2) 将文件移动到不同的目录。
- `[ ]` 方括号允许你指定受命令影响的一组文件。
- `ln` 允许你在文件之间创建链接。这使得可以访问实际位于其他目录中的文件。
- `cat` 有两种用途：
  - (1) 查看文本文件；
  - (2) 将两个或更多文本文件合并为一个文件（连接）。
- `find` 用于定位文件。
- `grep` 用于定位文本。
- `lpr` 将你的文件发送到打印机。
- `sync` 指示 Linux 确保所有文件都已正确存储在硬盘上。
