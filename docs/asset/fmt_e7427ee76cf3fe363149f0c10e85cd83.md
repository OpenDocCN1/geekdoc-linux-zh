### 6.16 程序安装

`sudo /sbin/shutdown -h now`
（作为普通用户，系统会提示你输入用户密码）运行 `shutdown` 命令（或你的系统管理员允许运行的其他命令）。通过 `sudo`，管理员可以赋予选定用户运行特定命令的权限，而无需分发 `root` 密码。`/etc/sudoers` 文件必须配置为包含类似以下的内容：

```bash
my_login my_computer_name = /sbin/shutdown
```

```bash
pwck

grpck
```
（作为 `root` 用户，执行两个命令）。验证密码文件和组文件的完整性。

```bash
pwconv

grpconv
```
（作为 `root` 用户）与你不同，你需要这些命令。它们会将旧式的密码文件和组文件转换为更安全的 "shadow"（阴影）文件。

```bash
rpm --ivh package_name-version.rpm
```
（作为 `root` 用户）安装软件包（选项 "i"，必须是横字符后的第一个字母），同时向我详细输出信息（选项 "v" 详细模式）并解析 "hashing" 以显示安装进度（选项 "h"）。`rpm` 代表 "Redhat Package Manager" 红帽软件包管理器。

```bash
rpm -Uvh package_name-version.rpm
```
（作为 `root` 用户）升级软件包（选项 "U"，必须是横字符后的第一个字母），同时保持详细输出（选项 "v"）并显示哈希值（"h"）。

```bash
rpm -ivh --force --nodeps package_name-version.rpm
```
（作为 `root` 用户）安装软件包，忽略任何潜在的冲突和软件包依赖问题。

```bash
rpm -e package_name
```
（作为 `root` 用户）卸载软件包（选项 "e-erase" 删除）包名。请注意包名末尾没有 `*.version.rpm`（包名与安装该软件包的文件名相同，但不包含横杠、版本、平台和 "rpm"）。

```bash
rpm -qip package_name-version.rpm
```
查询（选项 "q"，必须是横字符后的第一个字母）尚未安装的软件包（选项 "p"），以便显示该软件包所包含的信息（选项 "i"）。

```bash
rpm -ql package_name-version.rpm
```
查询（选项 "q"，必须是横字符后的第一个字母）尚未安装的软件包（选项 "p"），以便显示其包含的所有文件列表（选项 "l"）。

```bash
rpm -q file
```
查找某个“文件”所属的已安装软件包名称。如果我不小心删除了某个包，现在需要找到正确的包并重新安装，这个命令非常有用。

```bash
rpm -qi package_name
```
查询已安装的软件包以显示其信息。请注意包名末尾没有 "-version.rpm"。
查询我系统中安装的所有软件包以显示其信息。在我的这个简易系统中，我安装了约 600 个软件包，显然，我有大量的时间阅读完它们。要统计你的软件包数量，可以尝试：

`rpm -qa | grep -c .`

要查找特定的软件包，可以尝试：

`rpm -qa | grep the_string_to_find`

```bash
rpm -qa | grep . 

rpm -qa | grep the_string_to_find

（选项 "i" 让 rpm 忽略字符的大小写，因此大写或小写字母都会匹配；）
```

```bash
rpm -Va
```
验证（选项 "V"）我系统中安装的所有（"a"）软件包。这将列出自安装以来被修改的文件。以下是输出的图例：

- `T`: 通过
- `C`: 这是一个配置文件
- `M`: 校验和失败
- `S`: 文件大小不同
- `L`: 符号链接已更改
- `T`: 文件修改时间已更改
- `D`: 设备文件被修改
- `U`: 文件的用户已更改

`/etc/rc.d/init.d/network restart`

使用其标准初始化脚本重启网络（与启动时使用的脚本相同）。如果你刚刚手动更改了网络配置，此命令非常有用。脚本中的任何其他服务都可以以类似的方式停止、启动或重启（通过带选项 `stop`、`start` 或 `restart` 调用脚本）。

```
ifdown interface_name
```

`/sbin/ifdown` （以用户身份运行）。关闭网络接口。例如：`ifdown ppp0`。另请参阅上一个命令。

```
netstat -i
```

显示关于你的网络状态的大量（或者是不是太多了？）信息。
