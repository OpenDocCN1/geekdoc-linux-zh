# 4.1.3.7 确保收集未失败的文件访问尝试（自动）：

## 策略概适用性：

- 等级 2 - 服务器
- 等级 2 - 工作站

## 描述：

监控访问文件的失败尝试。以下参数与控制文件的系统调用相关联：

- 创建 - `creat`
- 打开 - `open`, `openat`
- 截断 - `truncate`, `ftruncate`

只有当用户尝试访问文件并满足以下所有标准时，才会写入审计日志记录：

- 非特权用户 (`aud>=UID_MIN`)
- 不是 守护进程事件 (`audit=4294967295/unset/-1`)
- 如果系统调用返回 `EACCES`（权限被拒绝）或 `EPERM`（与特定系统调用相关的其他永久性错误）

## 理由：

打开、创建或截断文件的失败尝试可能表明个人或进程正试图获得对系统的未授权访问。
