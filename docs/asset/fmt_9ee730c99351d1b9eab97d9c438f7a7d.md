
NIS 服务器必须运行几个守护程序过程才能作为 NIS 服务器工作。Red Hat Linux 提供了几个 run-level 脚本，您可以配置它们以启动 NIS 服务器守护程序过程。这些脚本位于 `/etc/init.d` 目录中，包括以下内容：

- `ypserv` — 此脚本启动 `ypserv`（`/usr/sbin/ypserv`）守护程序。它从 `/etc/ypserv.conf` 文件读取信息以确定要执行的操作。然后它监听来自网络上 NIS 客户端计算机的请求。

- `ypasswdd` — 此脚本启动 `rpc.ypasswdd`（`/usr/sbin/rpc.ypasswdd`）守护程序。此守护程序处理来自 NIS 客户端计算机上想要更改其用户密码的用户的请求。

除非您在安装 Red Hat Linux 时请求配置这些脚本在启动时启动，否则它们不会自动启动。您可以使用以下 `chkconfig` 命令设置 `ypserv` 和 `ypasswdd` 脚本在启动时自动启动。

```
# chkconfig ypserv on
# chkconfig ypasswdd on
```

如果您想立即启动服务，可以输入以下内容：

```
# /etc/init.d/ypserv start
# /etc/init.d/ypasswdd start
```

NIS 主服务器应该已经启动并运行。如果有任何 NIS 从服务器，您现在应该配置它们。

## 设置 Red Hat Linux 作为 NIS 从服务器

要设置一个 NIS 从服务器，您必须像配置 NIS 主服务器一样配置它，但有一个例外：您不是创建 NIS 映射，而是运行 `ypinit` 命令，以便从服务器复制 NIS 映射。您给 `ypinit` 的选项是 `-s` *主服务器*（master）选项，其中*主服务器*会被替换为你的 NIS 主服务器的名称。以下是在 NIS 主服务器命名为 maple 的情况下运行 `ypinit` 的一个示例：

```
# /usr/lib/yp/ypinit -s maple
```

只要 NIS 从服务器被允许访问，映射（maps）就会从 NIS 主服务器复制到你的计算机上。如果 NIS 主服务器宕机，该从计算机应该能够处理来自网络的 NIS 请求。

此时，你可以回到设置 NIS 作为客户端的章节，以确保你的 NIS 服务器正常运行并将映射分发给其客户端。

## 摘要

DHCP 和 NIS 都提供了一种集中管理网络中计算机的机制。DHCP 可以提供信息，帮助客户端计算机快速在网络上运行起来。NIS 让你能够在 Linux 和 UNIX 系统之间分发广泛的配置信息。

DHCP 用于向网络中的 Windows、Linux、Mac 或其他客户端计算机提供有关网络的信息。IP地址可以 `动态` 分配，这意味着它们从 IP 地址池中分发。或者，可以基于特定的以太网硬件地址将特定的地址分配给客户端。

你可以将 Red Hat Linux 配置为 NIS 客户端、NIS 主服务器或 NIS 从服务器。NIS 客户端可以利用来自 NIS 服务器的共享信息。NIS 主服务器构建信息数据库（称为映射）并使网络中的其他系统能够访问这些映射。可选的 NIS 从服务器可用于维护 NIS 映射的副本，从而在 NIS 主服务器宕机的情况下，确保网络上的 NIS 服务能够继续运行。

# 第24章：设置 MySQL 数据库服务器

## 本章内容

- 显示 MySQL 数据库
- 修改表和记录

- 检查和修复数据库

MySQL 是一个流行的结构化查询语言（SQL）数据库服务器。与其他 SQL 服务器一样，MySQL 提供了访问和管理 SQL 数据库的手段。然而，MySQL 还提供了用于创建数据库结构的工具，以及向这些结构中添加、修改和删除数据的工具。由于 MySQL 是一个关系型数据库，数据可以存储和管理在小的、易于管理的表中。这些表可以组合使用以创建灵活且复杂的数据结构。

一家名为 MySQL AB 的瑞典公司负责开发 MySQL（www.mysql.com）。MySQL AB 已将其作为开源产品发布，并通过提供多种 MySQL 支持套餐来获得收入。该公司还支持几种应用程序编程接口（API），以帮助应用程序开发人员和 Web 内容创作者访问 MySQL 内容。

由于 MySQL 是一个开源产品，它已被移植到几种不同的操作系统（主要是 UNIX 和 Linux 系统，但也有 Windows 版本）。如你所料，这些包括在 Red Hat Linux 上运行的 MySQL 二进制版本。本章包含对 Red Hat Linux 发行版中包含的 MySQL 版本的描述和操作流程。

### 查找 MySQL 软件包

要在 Red Hat Linux 中使用 MySQL，你可以安装几个软件包。你需要至少安装 `mysql` 和 `mysql-server` 软件包，才能按照本章描述的流程设置 MySQL。以下 MySQL 软件包随 Red Hat Linux 发行版一起提供：

1. `mysql` — 此软件包含许多 MySQL 客户端程序（位于 `/usr/bin/` 中）、几个客户端共享库、默认的 MySQL 配置文件（`/etc/my.cnf`）、几个示例配置文件、支持不同语言的通用 SQL 文件以及文档。

2. `mysql-server` — 此软件包含 MySQL 服务器守护进程（`mysqld`）和 `mysqld` 启动脚本（`/etc/init.d/mysqld`）。该包还创建设置 MySQL 数据库所需的各个管理文件和目录。

3. `mysql-devel` — 此软件包含开发 MySQL 应用程序所需的库和头文件。

4. `mysqlclient9` — 此软件是运行针对早期版本 Red Hat Linux 编写的某些 MySQL 应用程序所必需的。

5. `php-mysql` — 此软件包含一个允许 PHP 应用程序访问 MySQL 数据库的共享库。这基本上允许你在 Web 页面中添加能够访问 MySQL 数据库的 PHP 脚本。

在当前的 Red Hat Linux 版本中，主要的 mysql 软件包位于 CD #1，而其他 mysql 软件包位于 CD #2。如果尚未安装这些软件包，你可以通过对 CD #1 和 CD #2 重复以下步骤来安装它们：

1. 将 Red Hat Linux CD 插入 CD-ROM 驱动器。

2. 如果 CD 没有自动挂载，请在终端窗口中以 root 用户身份键入以下内容：

```
# mount /mnt/cdrom
```

3. 键入以下内容以安装必要的 mysql 软件包：

```
# rpm -i /mnt/cdrom/RedHat/RPMS/*mysql*
```

4. 此时，你可以开始配置你的 MySQL 数据库服务器。

## 配置 MySQL 服务器

与 Red Hat Linux 中的大多数服务器软件一样，MySQL 服务器依赖一个启动脚本和一个配置文件来提供服务。服务器活动记录在 `/var/log` 目录下的一个文件中。此外，还有用于管理 MySQL 活动的 `mysql` 用户和组账户。以下部分描述了这些组件如何协同工作。

> **提示：** 对于本节中描述的许多步骤，MySQL 服务器守护进程必须正在运行。本章稍后详细描述了如何启动服务器。目前，你可以通过键入以下内容临时启动服务器：`/etc/init.d/mysqld start`

### 使用 mysql 用户/组账户

安装 MySQL 软件时，它会自动创建一个 mysql 用户和一个 mysql 组。这些用户和组账户被分配给 MySQL 文件和活动。这样，某人可以在不需要拥有计算机 root 权限的情况下管理 MySQL 服务器。

`mysql` 用户条目在 `/etc/passwd` 文件中显示如下：

```
mysql:x:27:27:MySQL Server:/var/lib/mysql:/bin/bash
```

上面显示的 mysql 条目表明，mysql 用户的 UID 和 GID 均为 27。识别此用户账户的文本字符串为 "MySQL Server"。主目录是 `/var/lib/mysql`，用户使用的默认 Shell 是 `/bin/bash`。所标识的主目录将包含保存你为 MySQL 服务器定义的每个数据表的目录。

mysql 的组条目更简单。`/etc/group` 文件中的以下条目表明 mysql 组的组 ID（GID）为 27。

```
mysql:x:27:
```

如果你想检查与 MySQL 相关的文件的所有权，你会发现这些文件中的大多数都分配了 mysql 作为拥有每个文件的用户账户和组账户。这允许由 mysql 用户运行的守护进程访问数据库文件。

### 添加管理员用户

要管理 MySQL，你需要创建至少一个管理员账户。你可以使用 `mysqladmin` 命令来完成此操作。要将 root 用户添加为 MySQL 管理员，请以 root 用户身份登录，并从终端窗口键入以下内容：

```
# mysqladmin -u root password my47gmc
```

你需要输入自己的密码，而不是上面显示的 `my47gmc`。运行此命令后，root 用户可以通过在提示时输入密码来运行任何 MySQL 管理命令。
