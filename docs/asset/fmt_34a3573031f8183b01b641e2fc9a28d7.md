## 管理进程

当你需要停止一个异常进程时，进程 ID 或进程号很有用。查看 `ps` 输出并注意 `PID`。然后，使用 `kill` 命令该进程。要停止 2850 号进程，输入以下命令：

```
kill -9 2850
```
