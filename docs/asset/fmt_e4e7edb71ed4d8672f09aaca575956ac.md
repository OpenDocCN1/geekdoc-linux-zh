# 360 碳

无机碳，数量远小于有机碳。参见“有机化学：热解”。

单质碳以两种定义的同素体形式存在：金刚石和石墨。这两种形式以及结晶度发育不良的木炭、焦炭和黑碳，都是有机物质分解而成的。碳的化学和物理性质取决于元素的结构。其密度从石墨的 2.25 g/cm³ 到金刚石的 3.5 g/cm³ 不等。

石墨形成于3500 °C (6332 °F)，升华点为 3825 °C (6917 °F)。碳是一种软物质。它不溶于水、稀酸和碱，但能与氧气结合形成一氧化碳或二氧化碳。对于氧化剂（如硝酸和次氯酸钠），它仅与单质碳反应。许多金属在高温下与该元素结合形成化物。

### 碳的形式

碳有三种气态化合物：一氧化碳、二氧化碳、氧化碳和硫化碳。前两种在工业用途中最重要。碳也通过燃烧形成，但气态形式为 CO；其通式为 CX₄，其中 X 是氯、溴、碘或氮。四氧化碳是四氯化碳，另外两种是碳过氧化物。这些物质极不稳定。参见“碳过氧化物”。

碳及其化合物在宇宙中广泛分布。估计碳占地球地壳的0.02%。游离碳以煤的形式存在于沉积物中，在岩石中以碳氢化合物、碳氮化合物的形式存在。结晶碳以金刚石和石墨的形式存在。

单质碳也以化合物的形式存在。在大气中，碳以二氧化碳的形式存在，体积最高0.03%。石灰岩、白镁石、大理石和粉笔等各种矿物含有碳。所有植物都含有含有氢、氧、氮和其他元素的有机化合物。植物和动物生命的遗存在石油、沥青和煤的沉积中，它们由碳和氢组成。参见“碳酸盐”。

游离元素有许多用途，从金刚石的装饰性应用到汽车轮胎和印刷墨水中的黑色色素。石墨用作润滑剂、干电池、电极和铅笔芯。木炭是碳的无定形形式，用作气体吸附剂和干燥剂。参见“碳黑：木炭”。

碳化合物有许多用途。二氧化碳用于饮料碳化，并以固体状态作为制冷剂（干冰）。二氧化碳还用于许多其他化学过程。四氯化碳和二硫化碳是工业的重要溶剂。燃料用于制冷装置。二氧化碳用于制酸，酸用于金属的焊接和切割以及制其他有机化合物。其他金属化物用于切割。

# 碳黑

通过热分解或氧气分解制造工艺产生的无定形碳可分为接触式、炉式或热式。在通道中，天然气通过完全燃烧分解。火焰来自煤炉通道上的燃烧器，碳沉积通过刮刀片去除。在炉内，碳烃和空气经过分解，使未燃烧的碳烃分解为碳。水喷将温度冷却至 3000–3000 °F (1100–1700 °C)，导致碳和产物的脱水。最终材料通过旋风器分离并按加热分段进行分级。

# 二氧化碳

CO2无色无味，作为气体时，其体积约为空气的1.5部分。在正常条件下，它是稳定且无毒的。所有有机化合物的缓慢氧化都会产生 CO2。新鲜空气中 CO2 体积分占0.03%。燃料燃烧时会产生 CO2。它被植物和动物吸收。在动物和人类的呼吸中，它被排出。

二氧化碳在固体后可以液化。二氧化碳来源于多种来源：气井、燃料、碳燃料燃烧以及化学过程的副产物。应用包括作为制冷剂（固体或液态）、灭火器和增压剂。

大部分 CO2 是氨和汽油生产副发酵产生的；其他来源包括糖发酵、气厂和水燃料的直接生产。源气 CO2（纯度至少98%）以气态或液态收集，净化，冷凝成液态并存放在绝热容器中。二氧化碳有三种分布方式：气瓶装；作为冰冻车厢或轨道车中的低压液体；以及在绝热罐或箱体中。

> [J.L.]
