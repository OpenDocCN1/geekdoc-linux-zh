
如果存在一个双射函数 `φ: V(G) → V(H)`，使得两个顶点 `u` 和 `v` 在 `G` 中相邻当且仅当 `φ(u)` 和 `φ(v)` 在 `H` 中相邻，则称图 `G` 和 `H` 是`同构`的（isomorphic）。函数 `φ` 称为从 `G` 到 `H` 的`同构映射`（isomorphism）。如果 `φ: V(G) → V(H)` 是一个同构映射，则其逆函数 `φ^{-1}: V(H) → V(G)` 是从 `H` 到 `G` 的同构映射。如果 `G` 和 `H` 同构，我们写作 `G ≅ H`。如果不存在上述描述的函数 `φ`，则 `G` 和 `H` 是`非同构图`（non-isomorphic graphs），我们写作 `G ≇ H`。

图 1.8 中的图 `G` 和 `H`（阶均为 7，大小均为 8）是同构的，定义如下：

```
φ(u₁) = v₄,  φ(u₂) = v₅,  φ(u₃) = v₁,
φ(u₄) = v₆,  φ(u₅) = v₂,  φ(u₆) = v₃,
φ(u₇) = v₇
```

的函数 `φ: V(G) → V(H)` 是一个同构映射，尽管还有其他三个同构映射。然而，图 1.8 中的图 `F₁` 和 `F₂`（阶均为 7，大小均为 10）不是同构的。对此的解释将稍后给出。

图 1.9 中的图 `G₁` 和 `G₂` 是同构的，而 `G₁` 和 `G₃` 不是同构的。例如，定义如下：

```

φ(u₄) = v₂,  φ(u₅) = v₄,  φ(u₆) = v₆
```

的函数 `φ: V(G₁) → V(G₂)` 是一个同构映射。图 1.9 中的图 `G₃` 包含三个两两相邻的顶点 `w₁, w₂, w₆`。如果 `G₁` 和 `G₃` 同构，则对于任一同构映射

假设两个图 `G` 和 `H` 是同构的。那么存在一个同构映射 `φ : V(G) → V(H)`。由于 `φ` 是一个双射函数，故 `|V(G)| = |V(H)|`。此外，由于 `G` 中顶点 `u` 和 `v` 相邻当且仅当 `H` 中 `φ(u)` 和 `φ(v)` 相邻，因此 `|E(G)| = |E(H)|`。下面总结了这些事实，并补充了另外两个图同构的一个必要条件。

> **定理 1.6** *如果两个图 `G` 和 `H` 是同构的，则它们具有相同的阶数和相同的规模，且 `G` 中顶点的度与 `H` 中顶点的度相同。*

## 1.3 同构图

**证明。** 我们已经观察到同构图具有相同的阶数和规模。设 `v` 是 `G` 的一个顶点，假设 `deg v = k`。那么 `v` 与 `k` 个顶点相邻，记为 `v₁, v₂, ..., vₖ`。假设 `v` 不与 `u₁, u₂, ..., uℓ` 相邻。如果 `φ: V(G) → V(H)` 是一个同构映射，那么 `φ(v)` 与 `φ(v₁), φ(v₂), ..., φ(vₖ)` 相邻，而 `φ(v)` 不与 `φ(u₁), φ(u₂), ..., φ(uℓ)` 相邻。因此，`φ(v)` 在 `H` 中的度为 `k`。

定理 1.6 的证明还表明，从图 `G` 到图 `H` 的每个同构映射都将 `G` 的每个顶点映射到 `H` 中具有相同度的顶点。

因此，由定理 1.6 可知，如果 `G` 和 `H` 是两个图，且满足以下任一条件：(1) `G` 和 `H` 的阶数不同，或 (2) `G` 和 `H` 的规模不同，或 (3) `G` 的顶点度与 `H` 的顶点度不同，那么 `G` 和 `H` 不同构。由于图 1.8 中的图 `F₂` 包含一个度为 5 的顶点，而 `F₁` 中没有度为 5 的顶点，根据定理 1.6 可知 `F₁ ≇ F₂`。

定理 1.6 中描述的条件是两个图同构的严格必要条件——它们并不充分。确实，图 1.9 中的图 `G₁` 和 `G₃` 具有相同的阶数、相同的规模，且 `G₁` 和 `G₃` 的顶点度也相同；然而 `G₁` 和 `G₃` 并不同构。

接下来，考虑图 1.10 中显示的四个图 `H₁, H₂, H₃` 和 `H₄`。图 `H₁` 和 `H₂` 的阶数为 7，规模为 7，且这两个图的顶点度相同。此外，每个图都包含一个唯一的三角形。然而，`H₁ ≇ H₂`。假设存在一个从 `H₁` 到 `H₂` 的同构映射 `φ`。由于每个图只有一个度为 3 的顶点和一个度为 4 的顶点，`φ(u₁) = v₂` 且 `φ(y₁) = x₂`。由于 `v₁` 与 `u₁` 和 `y₁` 相邻，因此 `φ(v₁)` 应与 `v₂` 和 `x₂` 相邻。然而，`H₂` 中不存在同时与 `v₂` 和 `x₂` 相邻的顶点。因此，`H₁ ≇ H₂`。

图 1.10：非同构图

图 1.10 中的图 `H₃` 和 `H₄` 的阶数为 9，规模为 8，且这两个图的顶点度相同；然而这两个图并不同构。假设存在一个从 `H₃` 到 `H₄` 的同构映射 `φ`。考虑顶点 `v₃`。由于 `deg_{H₃} v₃ = 2`，因此 `φ(v₃)` 在 `H₄` 中的度为 2。由于 `v₃` 与 `w₃` 和 `w₅` 相邻，我们必须有 `φ(v₃)` 与 `φ(w₃)` 和 `φ(w₅)` 相邻。由于 `deg_{H₄} w₃ = deg_{H₄} w₅ = 2`，因此 `φ(w₃)` 和 `φ(w₅)` 在 `H₄` 中的度为 2。但是，`H₄` 中没有度为 2 的顶点与两个度为 2 的顶点都相邻。因此，`H₃ ≇ H₄`。

### 子图

如果图 `H` 的顶点集满足 `V(H) ⊆ V(G)` 且边集满足 `E(H) ⊆ E(G)`，则称图 `H` 是图 `G` 的`子图`，此时我们记作 `H ⊆ G`。如果 `H` 是 `G` 的子图，则 `G` 是 `H` 的`超图`。如果 `V(H) = V(G)`，则 `H` 是 `G` 的`生成子图`。如果 `H` 是图 `G` 的子图且 `H ≇ G`，则 `H` 是 `G` 的`真子图`。因此，如果 `H` 是 `G` 的真子图，则 `V(H)` 是 `V(G)` 的真子集或 `E(H)` 是 `E(G)` 的真子集。

图 1.11 展示了六个图，即 `G` 和图 `G_i`（其中 `i = 1, 2, ..., 5`）。这六个图中，除了 `G` 本身和 `G₁` 外，其余都是 `G` 的真子图。虽然 `G` 是其自身的子图，但它不是其自身的真子图。图 `G₁` 包含边 `u₂`（此处原文可能指顶点 `u₂` 相关的边或笔误，依原文译为 edge `u₂`），这不是 `G` 的边，因此 `G₁` 甚至不是 `G` 的子图。图 `G₃` 是 `G` 的生成子图，因为 `V(G₃) = V(G)`。
