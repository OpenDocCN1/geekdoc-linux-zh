## 第 9 章：高级内存主题

### 计算机如何看待内存

让我们复习计算机内部内存的工作原理。你可能也想重读第 2 章。

计算机将内存看作一长串带有编号的存储位置。一个数百万个编号存储位置的序列。一切都存储在这些位置中。你的程序存储在这里，你的数据存储在那里，一切都是。每个存储位置看起来都和其他位置一样。存放你程序的位置与存放你数据的位置是一样的。事实上，计算机并不知道哪个是哪一个，除非可执行文件告诉它从何处开始执行。

这些存储位置被称为字节（byte）。计算机可以将多四个字节组合成一个字（word）。通常情况下，数值数据是一次处理一个字。正如我们提到过的，指令也存储在这一段内存中。每条指令的长度都不同。大多数指令本身占用一个或两个存储位置（用于指令本身），再加上用于指令参数的存储位置。例如，指令

```assembly
movl data_items(,edi,4), %ebx
```

占用了 7 个存储位置。前两个持有指令，第三个告诉要使用哪些寄存器，接下来的四个持有 `data_items` 的存储位置。在内存中，指令看起来和所有其他数字一样，而指令本身可以像数字一样移动到寄存器中或取出，因为它们本身就是数字。

本章重点关注计算机内存的细节。为了开始，让我们复习一些在本章中将用的基础术语：

### 字节 (Byte)

这是存储位置的大小。在 x86 处理器上，一个字节可以存储 0 到 255 之间的数字。

### 字 (Word)

普通寄存器的大小。在 x86 处理器上，一个字是四个字节长。大多数计算机操作一次处理一个字。

### 地址 (Address)

地址是一个指向内存中某个字节的数字。例如，计算机上第一个字节的地址为 0，第二个的地址为 1，依此类推¹。计算机上任何不在寄存器中的每条数据都有地址。跨越多个字节的数据的地址与其第一个字节的地址相同。

通常，我们永远不会输入任何东西的数值地址，而是我们让汇编器为我们完成。当我们在代码中使用标签（labels）时，标签使用的符号将等同于它所标记的地址。汇编器将在你程序中使用该符号的任何地方将其替换为地址。例如，假设你有以下代码：

```assembly
.section .data
my_data:
.long 2, 3, 4
```

现在，程序中任何使用 `my_data` 的地方，它将被替换为 `.long` 指令中第一个值的地址。

### 指针 (Pointer)

指针是一个寄存器或内存字，其值为地址。在我们的程序中，我们使用 `%ebp` 作为指向当前栈帧的指针。所有基指针寻址涉及指针。编程使用大量指针，因此这是一个需要掌握的重要概念。

#### Linux 程序的内存布局

当你的程序加载到内存中时，每个 `.section` 被加载到它所属的内存区域。每个段中声明的所有代码和数据都被聚集在一起，即使它们在你的源代码中是分开的。

实际指令（`.text` 段）加载在地址 `0x08048000` 处（以 `0x` 开头的数字是十六进制，将在第 10 章中讨论²）。`.data` 段紧随其后，然后是 `.bss` 段。

最后一个字节位于 Linux 位置 `0xbfffffff`。Linux 启动栈并向下增长。在它们之间有一个巨大的间隙。栈的初始布局如下：在栈的底部（栈的顶部地址，见第 4 章），有一个全零内存。之后是使用 ASCII 字符的程序名。程序名之后是程序的环境变量（这些在我们的书中并不重要）。然后是程序的命令行参数。这些是用户运行此程序时在命令行输入的值。例如，当我们运行 `as` 时，我们给了它几个参数——`as`、`sourcefile.s`、`-o` 和 `objectfile`。之后是参数的数量。栈指针 `%esp` 指向的地方。栈的操作会让 `%esp` 向移动。例如，指令

```assembly
pushl %ebax
```

等同于

```assembly
movl %eax, (%esp)
subl $4, %esp
```

同样，指令

```assembly
popl %eax
```

相当于

```assembly
mvl (%esp), %eax
addl $4, %esp
```

你的程序数据区域从内存底部开始向上。栈从内存顶部开始，并随着每次推送向下移动。栈和你的程序数据段之间的中间部分是不可访问的内存——在你告诉内核你需要它之前，是不允许访问它的¹。如果你尝试，将得到一个错误（错误消息通常是“段错误”）。如果你尝试访问程序开始之前的数据（`0x08048000`），也会发生同样的情况。程序的最后一个访问内存地址被称为系统断（system break，也称为当前断或简单的 break）。

¹ 你实际上从不使用那么低的地址，但为了讨论可以这样做。
² 栈可以在它向下增长时访问它，你可以通过 `%esp` 访问栈区域。然而，你的程序数据段并不是那样增长的。增长方式稍后会解释。

```
0xffffffff
```
