## 将光子图保存为文件

在动画中，通过将光子图保存为文件可以节省大量时间（仅当场景中的光照发生变化时）。这样，光子图无需为每一帧重新计算。保存和加载光子图文件（`*.pmap`）的控件位于渲染场景对话框中间接照明（`Indirect Illumination`）选项卡上的 `Photon Map` 组中。

在本节中，你学习了如何使用 `Final Gather`（`FG`）来提高渲染质量。`FG` 是全局照明（`GI`）中的一个可选步骤，有助于平滑光子图产生的伪影。有了 `FG`，你不需要非常精确的光子图，因此减少此参数可以节省一些处理时间。

## Final Gather

`Final gathering`（`FG`）是全局照明（`GI`）中的一个可选步骤，有助于平滑光子图产生的伪影。有了 `FG`，你不需要非常精确的光子图，因此减少此参数可以节省一些处理时间。

## 在不生成光子图的情况下使用 `FG`

1. 打开 `MentalRayGI.max`。

2. 如果渲染场景（`Render Scene`）未打开，请打开它。

3. 在测试 `FG` 时禁用 `Caustics`（焦散）。

4. 确保全局照明（`GI`）设置为 `Enable`（启用）。

# 抗锯齿减少锯齿边缘

数字图像中没有曲线，只有由不同颜色像素组成的矩阵。抗锯齿算法可以平滑出现在像素网格中的锯齿边缘。

`mental ray` 中的采样（`Sampling`）等同于 `VIZ` 材质中的超采样（`Supersampling`）功能。在 `mental ray` 中，采样是在场景级别进行的，因此你不需要在任何材质中运行超采样。

1. 点击场景渲染（`Scene render`）对话框中的 `Renderer`（渲染器）选项卡。在 `Minimum`（最小）下拉菜单中选择 `4`。然后将 `Maximum`（最大）下拉列表更改为 `16`。现在每个像素将产生许多额外的样本，这很可能消除渲染中的任何锯齿现象。

## 设置每像素采样值

抗锯齿由子像素采样设置控制。你应该始终将 `Maximum samples per pixel`（每像素最大采样）设置为比 `Minimum`（最小）更高的值。对于测试渲染，将 `Minimum` 设置为 `1/4`，`Maximum` 设置为 `1`，这样渲染速度会快得多。

2. 回到 `Illumination`（照明）选项卡。勾选 `Caustics`（焦散）组中的 `Enable`（启用）。最终输出还将渲染你在上一次话中测试的焦散效果。

3. 取消勾选 `Final Gather` 卷组中的 `Draft Mode (No Precalculations)`（草稿模式）。

4. 在 `Final Gather` 卷组的顶部，展开 `Preset`（预设）下拉列表并选择 `High`（高）选项。`Final Gather` 卷组中的几个参数被更改，以增加 `FG` 解决方案的质量。

| Final Gather | |
| :--- | :--- |
| Preset: | Custom |
| Basic | Custom |
| Enable FG | Low |
| Initial FG Post | Medium |
| Rays per FG | High |
| Interpolate Diff Num. FG Points: | 30 |
| Diffuse Bounds: 0 | Weight: 1.0 |

5. 点击场景渲染对话框底部的 `Render` 按钮进行下一次迭代。准备好为此过程等待几分钟。在 `RFW` 中，在第一个过程中会计算 `Final Gather` 点，在第二个过程中将完成实际渲染。

6. 将你的工作保存为 `MyMentalRayFG.max`。为了方便起见，书籍网站也提供了该文件。

# 查看基础 mental ray 工作流

现在你已经体验了 `mental ray` 中的整个渲染工作流，在我们进入更专业的课题之前，让我们花一点时间总结一下在 `mental ray` 中制作最终输出通常采用的步骤。首先要为场景中的对象分配 `mental ray` 材质。接下来，添加光度照明或 `mental ray` 灯光。前两个步骤都不是严格必要的，因为大多数 `VIZ` 材质会被渲染器自动转换为 `mental ray` 版本，但为了获得最可靠的结果，你应该手动添加或转换光子。

尝试使用较少量的 `GI` 光子进行测试渲染。调整光子的大小和数量，直到获得可以接受的结果。如果你预计它们将在图像中起作用，请对较少的焦散光子进行更多测试，并根据进一步测试调整它们的大小和数量。如果你觉得光子图质量可以接受，那么你就完成了。

然而，如果你注意到几何体的角落出现阴影、色彩噪声、过度模糊、光照斑块状或其他渲染伪影，则你需要执行最终汇集（`final gathering`）。如果你选择 `FG` 路线，请先进行预览，以确保值得花费时间进行长度计算，而无需进行进一步调整。如果你发现有锯齿，请调整采样，然后处理最终输出。

如果可以，请并行渲染你的作业以节省时间。`mental ray` 非常适合渲染农场（`render farming`）。如果你计划专业化，可能会考虑雇佣人来搭建渲染网络，以确保你在截止日期前完成工作。

# 轮廓渲染（Contour Renderings）

`mental ray` 轮廓渲染类似于 3D 几何体的线条图。不要与显示所有对象的线框（`wireframe`）渲染混淆，轮廓渲染只显示对象的轮廓，通常非常吸引人。它们的优点之一是设置或处理它们不需要花费长时间。
