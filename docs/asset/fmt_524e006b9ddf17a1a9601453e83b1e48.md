# 第48章 `toupper()` 函数

本章讨论的是将小写字符转换成大写字母的 `toupper()` 函数。这是一个比较常见的函数。

```c
char toupper(char c)
{
    if(c>='a' && c<='z')
        return c-'a'+'A';
    else
        return c;
}
```

这里的程序代码中，我们可以看到`'a'+'A'`这种表达式是为了增强的可读性。在程序的实际编译过程中，它会被优化为相应的指令。

我们知道，小写的英文字字母 `a` 的 ASCII码十六进制是61，就是十进制的97；而大写的 `A` 的 ASCII码十六进制则是41，相当于十进制的65。很明显，在 ASCII码表中，两者的差值是 32（0x20）。

这里的变量`tmp`应该是一个有符号数。这里的转换处理了两个减法指令以及一个比较指令。原来的算法是通过两个比较指令加一个减法指令来实现。优化的`GCC`编译器更好，它不用跳转指令`JUMP`，转而采用`CMOVcc`指令（参见33.1节）。`x64`下的`GCC 4.9`优化程序

```assembly
toupper:
    lea     edx,[edi-97] ; 0x61
    lea     eax,[edi-32] ; 0x20
    cmp     dl,25
    cmov   eax,edx
    ret
```

第三行的代码首先准备了要减的值`0x20`（十六进制的20，十进制的32），这会给出相似的结果，好像执行减法会发生似的。而第五行的指令，在不在进行转换（不执行减法）的时候，原始的输入数据复制给`EAX`寄存器。可见它在条件不成立的情况下舍弃的值。也就是说，编译器为了避免使用条件转移指令而预进行了减法运算。
