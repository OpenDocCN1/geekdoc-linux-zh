
# 程序流程

`start`

`perform getInputAverage()`

`perform calculateAverage()`

`perform printResult()`

`stop`

## `getInput()`

```
print "Enter a number"
read firstNumber
print "Enter another number"
read secondNumber
return
```

## `calculateAverage()`

```
average = (firstNumber + secondNumber) / 2
return
```

## `printResult()`

```
print average
print "Thank you"
return
```
