
Linux 管理员通常使用权限来控制用户与系统文件及目录的交互。通常有三种权限，即：读（read）、写（write）和执行（execute）。

### A) 读取 (read)

这是仅读取文件的权限。你不能对其进行任何修改或删除。这些权限通常授予企业的入门用户。在 Linux 命令术语中，它表示为“`r`”。

### B) 写 (write)

这种权限允许用户写入文件。写入意味着修改文件内容。然而，写入文件后，不能保证你能够执行新写入的文件。例如，git 分支的贡献者被授予了仓库中文件的写入权限，但只有在被 git 分支管理员接受后才能执行。在 Linux 命令术语中，它表示为“`w`”。

### C) 执行 (Execute)

这是 root 用户拥有的高级权限。如果用户获得了权限，他不仅可以读写文件，还可以执行它们来更改系统文件和目录。当黑客试图攻击系统时，他通常期望获得执行权限。然而，请记住，有时 root 管理员只提供权限而不给予读和写权限。根据 Linux 命令术语，它表示为“`x`”。

至此，我们完成了对权限的简要介绍。在下一节中，我们将讨论如何从命令行为用户授予权限。

## 如何授予用户权限？

当你向用户授予权限时，他就可以错误地与文件或目录交互。

`chown` 命令用于在 Linux 中为用户授予权限。

这里有一个命令：

```
root@server : chown sample /home
```

在上述命令中，“`chown`”是告诉 Linux 内核提供权限的默认命令。“`sample`”代表用户名称，而“`/home/pictures`”是被授予的目录。

## 如何授予组权限？

就像 root 用户为个人用户分配权限一样，他也可以为组分配。

`chgroup` 命令是 Linux 中用于为特定组分配权限的命令。在企业中，创建和管理组是绝对必要的。在进行项目时，分配权限可以解决很多问题。

这里有一个命令：

```
root@server : chgroup hackers /home
```

在上述命令中，`chgroup` 是允许组分配权限的默认标识符。`hackers` 是组名，而 `/home` 是被授予的目录。

在下一节中，我们将学习如何查看文件或目录的当前权限。

## 如何在 Linux 中检查权限？

如果你不清楚当前持有哪些权限，可以使用 Linux 中的以下命令进行检查：

```
root@server : ls -l /var/games
```

该命令将显示输出信息，说明你当前的用户状态以及你是否有访问该目录。你还将获得有关文件所有者的信息。另一个重要的选项是关于修改时间的详细信息。如果你是系统管理员，你应该不断检查文件修改状态，以防范不计代价试图获取系统权限窃取敏感信息的攻击者。

如果你是一个试图获得系统控制黑客，你应该知道如何在 Linux 中修改权限。这就是 `chmod` 命令派场的地方 # 如何修改权限？

权限通常在 Linux 中使用 `chmod` 命令更改。你所需要做的就是作为 root 用户使用 `chmod` 添加你想要更改的权限。

例如：

```

// 这将赋予当前用户执行该镜像文件的权限
```

高级黑客使用 SUID 为他们将要执行的文件授予临时权限。学习这些内容超出了本书的范围。如果你感兴趣，我们建议在尝试之前先学习 SUID 和 Umask。

## 在 LINUX 中保持安全

在 20 世纪 90 年代，追踪那些使用拨号破解（phreaking）技术通过电话服务拨打免费电话的黑客几乎可能的。然而，随着互联网的快速发展及其盈利潜力，ISP（互联网服务提供商）开始限制用户并追踪他们。如今，政府也限制用户访问根据其规则违法的网站。例如，印度、中国等许多国家限制了 Torrent 网站。中国甚至审查了 Google、Facebook 等网站，因为他们认为这些网站忽视了用户隐私。

虽然禁止网站通常是他们破坏竞争对手经济增长的一种手段，但现在用户隐私也是一个受到重视的重大问题。最近，美国政府决定限制公民下载 Tiktok（一个著名的视频共享平台），因为有指控称其滥用用户数据。虽然这些指控中可能存在争议，但试图攻击那些拥有高质量入侵检测系统的企业的黑客应该意识到，他们并不是没有被追踪。本章将尝试为你提供一些有价值的信息。让我们开始吧！

### ISP 能够追踪什么？

这听起来可能很可怕，但事实是你的 ISP 会将你访问过的每一个网站都记录在他们的系统日志中。一些不道德的 ISP 甚至试图将这些数据卖给跨国公司，这些公司需要创建机器学习算法来进一步针对你的兴趣，甚至可以改变你的政治观点。

那么，我们应该做什么来停止被政府和 ISP 追踪呢？许多网络爱好者和关注隐私的工程师与这个问题斗争了多年。在花费了数百小时的研究后，一组网络专家创建了被称为 TOR 网络的东西。

在首先理解 TOR 之前，我们需要通过一个例子来讨论 IP 地址是如何被追踪我们的。

### IP 地址如何追踪我们？

明确来说，IP 地址就像是你的设备（如手机/路由器，有时甚至是无线连接）的收地址盒。

例如，假设你给朋友发送了一条 WhatsApp 消息。当你点击发送按钮时，消息内容将以数据包的形式发送到最近的路由器。数据包包含源地址信息，并包含目的地址。网络数据包的传输就像发送到特定地址的邮件。当目的地接收到消息状态后，消息平台中的消息状态将会改变。

通常，一个正常的网络数据包在到达目的地之前会在 20 个数据包之间跳跃（hop）。对于普通用户来说，这一切在几秒钟内完成，甚至并不重要。但对于黑客和安全爱好者来说，这些数据包可以提供大量的未加密信息。ISP 和政府的追踪也可以通过这些网络数据包的帮助获取大量敏感信息。

### 如何找到数据包的传输路径？

Linux 提供了一个特殊的命令来帮助你理解数据包的传输路径。它被称为路由追踪（trace route）命令命令。

```
root@server : traceroute yahoo.com
```

这将显示你提供的 URL 地址的路由追踪。它将显示到达目的地所需的跳跃次数，并提供网络数据包的大小。

有了这些充分的信息，你现在已经准备好理解洋葱网络（Onion network）的哲学了。让我们进一步了解它。

### TOR 网络是如何运作的？

在通常的网络通信中，所有通过路由器的数据包都会被特定的 ISP 追踪和控制。每当法律机构或政府要求访问这些传输的数据包时，他们担心通过这些路由器传输的措施可能会损害他们的企业。我的工作会感觉良好（注：此处原文可能有笔误，此处按语境理解为：由于担心通过这些路由器传输的措施可能会损害其企业，法律机构或政府会请求访问这些数据包）。

TOR 网络通过中间人接收并发送数据，这些数据是加密的，无法被追踪。虽然 TOR 不提供完全的匿名性，我们在暗网中可以找到 `.onion` 网站，那里充满了非法活动。

如果你觉得想尝试 TOR 网络，你应该安装由 Mozilla 开发的 TOR 浏览器。它是快速的并会自动连接到 TOR 中继。

### TOR 完全安全吗？

虽然绝对认为 TOR 是获得最大隐私的可靠方式，但它仍然存在漏洞。年前曾有泄露显示，美国政府拥有用作 TOR 服务器的列表。另一个问题是，Google 和 Facebook 等流行网站通过不断的安全检查来阻止用户使用 TOR 网络。如果你希望将 TOR 作为你与互联网交互的方式，那么作为黑客你应该意识到这些缺点。

在下一节中，我们将讨论代理服务器，它是另一种隐藏身份以防止政府/ISP 追踪的方法。

### 什么是代理服务器？

用通俗的话说，代理是作为源和目的之间的中间人。它们是中间节点，允许来自源和目的的所有流量通过它们通过。

如果你好奇代理服务器是如何工作的，请遵循这个简单的解释。

假设你想用网络浏览器访问一个网站。在这种情况下，你的 IP 地址被称为主机地址，你要访问的网站的 IP 地址被称为目的地址。当你使用网络浏览器向该网站发送请求时，你的 ISP 会记录这些请求。

然而，现在假设当你向网站发送请求时，而不是直接访问网站，所有流量将首先发送到代理服务器。当流量到达代理服务器时，前往目的地的流量将更改其 IP 地址。在这种情况下，由于存在中间节点，很难追踪流量的来源。同样，目标网站也将响应发送给数据（即代理），现在代理会将数据发送到源地址。

### 有哪些缺点？

就像所有的解决方案一样，匿名代理也有一些缺点。最重要的一点是，由于涉及到接收并为你发送数据的中间人，速度将显著降低。

此外，代理绝对不是完全安全的。虽然它们在访问被封的网站或涉及黑客程序的活动方面可能是安全的，但你不应该完全依赖它们。特别是使用免费代理时。经验丰富的黑客使用如 Sock5 等安全的代理。如果你做了一些琐碎的事情，并且有搜查令搜查代理日志，那么由于法律执法部门的压力，代理提供商可能会提供你的详情。

### 如何在 LINUX 中完美利用代理？

Linux 用户热爱代理。代理不仅能帮助他们保持匿名性，还能显著提升他们的网络访问性能。Kali Linux 作为一个著名的黑客发行版，它带有一个名为 `proxychains` 的代理实用工具，它将两个或多个代理地址组合在一起，向操作系统发送和接收数据。这不仅能让你完全匿名，而且非常安全，追踪你的踪对于追踪者来说将是一场噩梦。

# LINUX 中的什么是虚拟专用网络（VPN）？

# 第五章

## LINUX 中的日志系统

在上一个章节中，我们讨论了在互联网上保持安全和匿名的方法。作为一个黑客，隐藏在黑暗中并获取敏感信息通常是你的主准则。作为同类的安全爱好者，我建议你对 Linux 发行版中不同的日志系统保持良好的掌握，以帮助你理解你尝试访问的系统中到底发生了什么。此外，删除可能泄露你身份的敏感日志文件也是黑客需要掌握的一项任务。为了帮助你理解组成日志文件的不同日志系统守护进程（daemons），我们通过大量的示例介绍了本章。跟随操作！

### 什么是日志文件？

日志文件是关于操作系统中发生的所有重要事件的信息。像 Windows 和 macOS 等传统操作系统除非你有特殊的管理员权限，否则无法访问日志文件。Linux 提供了系统中存在的所有错误和警告的详细信息。某些日志文件即使没有 root 权限也可以访问。然而，所有创建的日志文件只有在你拥有 root 权限的情况下才能被修改或删除。

### 日志如何帮助黑客？

想象日志文件通往目的地（你的 IP 地址/其他敏感信息）的路径。每当新用户访问系统时，Linux 系统会自动注册其所有信息，并在程序之后才会建立连接。这一安全功能对于黑客来说可能是一场噩梦，因为取证爱好者可以提取所有信息/代理地址并进行进一步调查。

为了确保你每次访问系统时都不会被追踪，你应该前往日志位置并永久删除它们。管理员可以发现日志文件缺失，但永远不知道是谁干的。删除日志文件会引起怀疑，但不会有确认。

### 日志如何帮助系统管理员？

系统管理员和数据库专家经常在职业生活中对不同的 Linux 系统进行故障排除。一些管理员使用远程解决问题。为了让管理员理解问题是什么，他需要对日志文件的确定访问权限。日志文件将帮助他们理解问题所在。如果没有日志文件，手动检查问题所在之处将是一项艰巨的任务。

日志是如何创建的？

Linux 中的日志文件通常使用名为 `syslogd` 的特定守护进程创建。

但是，什么是守护进程（daemon）？

守护进程是一种在系统重启时自动启动的系统服务。它们是无论安装了什么软件都会运行的首批进程。它们被称为默认系统进程。`syslogd` 是一个为运行中的每个事件创建日志文件的特定系统进程。

此外，重要的是记住每个 Linux 发行版都有它自己的方式创建日志文件。例如，Debian 系统使用 'syslog' 创建日志文件。其他操作系统如 Arch 和 Redhat 根据用例使用不同的日志系统。日志系统的选择取决于使用的发行版。Debian 系统是 Linux 世界的窗口，因此轻量级且可以作为日常驱动。这就是为什么 Debian 使用简单的日志系统如 'rsyslog' 的原因。

复杂的操作系统如用于服务器管理的 Red Linux 在日志方面需要许多额外因素，因为它们经常用于故障排除。

### 如何理解和分析日志文件？

在本节中，我们将提供一个简单的程序来分析 Debian 系统中 syslog 守护进程创建的日志文件。你唯一需要的准备工作是安装你喜欢的文本编辑器来读取日志文件。

安装文本编辑器后，进入终端并输入以下命令。

```
root@server : locate rsyslog own
```

此默认命令搜索 Linux 系统中的所有文件。确保你已经使用 `su` 命令获得了 root 权限，这样命令将搜索所有系统文件。几秒钟后输出信息将显示日志文件所在的所有位置。

例如：

```
/etc/ home/example.rsyslog
```

这就是我们通过上述命令找到的文件格式。选择要分析的日志文件后，前往该位置并使用你喜欢的文本编辑器打开它。

现在，你将看到每当使用 `rsyslog` 守护进程创建日志文件时存在的默认代码。不要编辑任何内容，直接进入日志末尾，你会发现一个标题为“RULES”的区域，如下所示。

格式如下：

#### RULES

#### 在此处输入规则

#### 日志文件结束

现在，你需要在此处输入你偏好的规则。但首先，分析已有的规则，以理解 Linux 中日志系统是如何工作的。

你将看到如下格式的规则列表：

```
facility.priority action
```

这些单独标识符代表什么？

#### A) facility（设施）

这是一个标识符，我们通过它选择用于创建日志文件的服务。此外，它明确指出了正在与 Linux 系统日志系统的哪个部分进行交互。

这里是一些示例：

Cron, daemon, kern 和 user。也可以通过在它们之间使用逗号来使用其中任何一个。

#### b) priority（优先级）

这是一个标识符，说明使用正在运行的守护进程创建什么类型的日志文件。有不同的优先级操作，例如根据你的喜创建调试文件、错误文件或警报文件。

注意：

如果你使用 `*` 则所有可用优先级选项将被记录在日志文件中。记住，最低优先级是 `debug`，最高优先级是 `panic`。

#### C) action（动作）

这是一个标识符，提供了日志文件需要保存在目录中的位置。

这是一个示例规则：

```
Kern.error /etc/home/sample.syslog
```

在这里，`kern` 代表 facility，`error` 代表 priority。

`/etc/home/sample.syslog` 是自动创建日志文件的位置。
