
```
if (expression) statement [else statement]
while (expression) statement
do statement while (expression)
for (expression; expression; expression) statement
for (var in array) statement
break
continue
{[statement];}
expression # 通常为变量 = expression
print [expression-list] [expression]
printf format, [expression-list] [expression]
next # 跳过此输入行的剩余模式
ext [expr] # 跳过剩余输入；退出状态为 expr
```

使用分号、换行符或右括号终止语句。空的 `expression-list` 代表整行输入。表达式根据需要取布尔或数值，并使用运算符 `+`、`-`、`*`、 `/`、`%`、`^`、`=` 以及连接（由空格表示）构建。表达式中还可以用运算符 `++`、`--`、`+=`、`-=`、`*=`、 `/=`、`=`、`>=`、`<=`、`==`、`!=` 和 `?`。

变量可以是标量、数组元素（表示为 `x[i]`）和字段。变量初始化为空字符串或 `0`。数组下标可以是任何字符串，但必须是数字；这种语法允许一种关联内存的形式。字符串常量用引号（`""`）引起，内部识别常见的转义字符。

`print` 语句在标准输出上格式化其参数，如果存在 `?expression` 则在文件中，如果存在 `|cmd` 则在管道中。`print` 语句产生的输出由输出记录分隔符决定，每个参数之间用当前输出字段分隔符分隔。`printf` 语句根据 `fmt` 描述的格式格式化表达式列表（参见 `printf(3)`）。

## 内置函数

算术函数如下：

- `cos(x)` 返回 `x` 的余弦，其中 `x` 为弧度。
- `sin(x)` 返回 `x` 的正弦，其中 `x` 为弧度。
- `exp(x)` 返回 `x` 的指数函数。
- `log(x)` 返回 `x` 的自然对数。
- `sqrt(x)` 返回 `x` 的平方根。
- `int(x)` 将参数截断为整数。如果 `nx>0`，则向 0 截断。

字符串函数如下：

- `index(s, t)` 返回字符串 `s` 中字符串 `t` 首次出现的位置，如果没有出现则返回 0。
- `int(s)` 将 `s` 截断为整数。如果没有指定 `s`，则使用 `$0`。
- `length(s)` 返回作为字符串处理的参数长度，如果没有参数则返回整行的长度。
- `match(s, re)` 返回正则表达式在字符串 `s` 中出现的位置，如果没有出现则返回 0。
- `split(s, a, fs)` 将字符串 `s` 拆分为数组元素 `a[1]`、`a[2]`、`a[n]` 并返回 `n`。分离通过正则表达式 `fs` 或在未给出 `fs` 的情况下使用字段分隔符 `FS` 完成。
- `printf(fmt, expr, expr...)` 根据 `fmt` 给出的 `printf` 格式格式化表达式并返回生成的字符串。
- `substr(s, m, n)` 返回 `s` 中从位置 `m` 开始的长度为 `n` 的子字符串。

输入/输出函数如下：

`getline` 将 `$0` 设置为当前输入文件的下一个输入记录。`getline` 输入成功返回 1，文件结束返回 0，错误返回 -1。

## awk 83

`expression relop expression`

`expression matchop regular-expression`

其中 `relop` 是 C 语言中的六种关系运算符之一，而 `matchop` 是（包含）或 `!=!=`（不包含）。表达式可以是算术表达式、关系表达式、数组中的特殊表达式 `var`，或者这些者的布尔组合。

正则表达式用斜杠 `/` 指定。模式中孤立的正则表达式适用于整行。你也可以在关系表达式中使用正则表达式。一个模式可以由两个用逗号分隔的模式组成；在这种情况下，操作将在第一个模式出现的位置到第二个模式出现的位置的所有行上执行。

你可以使用特殊模式 `BEGIN` 和 `END` 来在读取第一行输入之前和读取最后一行输入之后捕获控制。这些关键字与任何其他模式都不冲突。

## 内置变量

内置变量包括：

- `FILENAME` 当前输入文件的名称。
- `FS` 输入字段分隔符正则表达式（默认为空格和制表符）。
- `NF` 当前记录的字段数。
- `NR` 当前记录的行号。
- `OFMT` 数字的输出格式（默认为 `%6g`）。
- `OFS` 输出字段分隔符（默认为空格）。
- `ORS` 输出记录分隔符（默认为换行符）。
- `RS` 输入记录分隔符（默认为换行符）。
