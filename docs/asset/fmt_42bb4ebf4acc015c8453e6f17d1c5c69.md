## 1.3 安装 SuSE 8.0

在本节中，我们将向您展示如何在您的服务器上安装 SuSE Linux 8.0。

**注意：** 安装过程将破坏硬盘上存储的任何现有数据。

# 欢迎使用 SuSE Linux！

要开始安装，只需按下 `<Enter>` 键。可用的启动选项：

- `linux` - 开始安装（默认选项）
- `manual` - 手动安装
- `failsafe` - 在复杂的硬件上带有某些选项安装（等同于 `"linux ide=... apm=off acpi=off"`）
- `apic` - 开始安装，使用支持 APIC 的内核
- `rescue` - 启动救援系统
- `disk` - 启动已安装系统
