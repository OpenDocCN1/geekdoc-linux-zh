
`tee` 命令类似于管道中的 `tee`，将标准输入分成两个或多个输出流，将一个发送到标准输出，其余发送到你指定的。。你可以使用 `tee` 命令来监控它是否正在执行你想的操作或保存管道中的中间步骤。`tee` 不缓冲其输出。选项决定指定的文件是被覆盖还是追加。

## 选项

- `-a` 将输出追加到文件而不是覆盖。
- `-i` 忽略中断。

## 操作

- `file` 输出文件的路径名。你可以处理至少一个。

## 示例

以下示例使用 `file` 命令显示当前目录的文件信息，并将信息保存到名为 `filetypes` 的文件中。

```
temp: data
aa: English text
castle%
```

## `telnet` — 使用 TELNET 协议访问远程系统的用户界面

### 概要

```
/usr/bin/telnet [-8Elcdr][-e escape-char][-l user] [-n tracefile] [host port]
```

## 描述

使用 `telnet` 命令远程登录到运行其他操作系统或不同版本 UNIX 的系统。`telnet` 使用 TELNET 协议与另一个主机通信。如果你在不带参数的情况下调用 `telnet`，它将进入命令模式并显示 `telnet>` 提示符。在此模式下，它接受并执行其相关的命令（参见第 1326 页的“`telnet` 命令”）。如果你调用 `telnet` 时带了参数，它将使用这些参数执行一个打开命令。

一旦建立连接，`telnet` 将进入输入模式。在此模式下，输入的文本将发送到远程主机。输入模式取决于远程系统的支持情况。三种输入模式为：

- *行模式（Line mode）*：字符处理在远程系统的控制下于本地系统进行。当禁用输入编辑或字符回显时，远程系统会转发远程系统发生的任何特殊字符的变化，以便这些更改在本地系统中生效。
- *逐字符模式（Character-at-a-time mode）*：大多数输入的文本会立即发送到远程主机进行处理。
- *旧逐行模式（Old-line-by-line mode）*：所有文本都在本地回显，（通常）只有完整的行会被发送到远程主机。你可以使用“本地回显”（初始为 `^`）来关闭和开启本地回显。（使用此功能可以在不回显密码的情况下输入密码。）

注意 — 在“旧逐行”模式（或 LINEMODE）中，终端的 结束符只有当它是该行的第一个字符时才会被识别（并发送到远程系统）。

如果启用了行模式，或者 `localchars` 切换为真（这是“旧逐行模式”的默认值），则你的 `quit`、`intr` 和 `flush` 字符将在本地被捕获，并作为 TELNET 协议序列发送到远程系统。如果曾经启用过“行模式”，那么你的 `susp` 和 `eof` 也会作为 TELNET 协议序列发送。`quit` 将作为 TELNET ABORT 发送而不是 BREAK。`autoflush` 和 `autosynch` 切换选项会将后续输出刷新到终端（直到远程主机确认 TELNET 序列），并在 `quit` 和 `intr` 的情况下刷新之前的终端输入。

在连接到远程主机时，你可以通过输入 `telnet` 转义字符（初始为 `^`）来进入 `telnet` 命令模式。在命令模式下，可以使用标准的终端编辑连接。在 `telnet` 提示符处处按回车键（Return）可退出命令模式。

## 选项

- `-8` 指定 8 位数据路径。对输入和输出尝试协商 BINARY 选项。
- `-c` 禁用读取用户的 `telnetrc` 文件。（参见切换 `skiprc` 命令。）
- `-d` 将 `debug` 切换的初始值设置为真（true）。
- `-e escape-char` 将初始字符设置为 `escape-char`。`escape-char` 也可以是一个由 `^` 后后跟一个字符组成的双字符序列。如果第二个字符是 `?`，则选择 DEL 字符。否则，将第二个字符转换为控制字符并用作转义字符。如果转义字符为空字符串（即 `e - ' '`），则禁用它。
- `-E` 停止任何字符被识别为转义字符。
- `-l user` 当连接到理解 ENVIRONMENT 选项的远程系统时，将 `user` 发送到远程系统作为变量 `USER` 的值。
- `-L` 在输出时指定 8 位数据路径。这会在输出上协商 BINARY 选项。
- `-n tracefile` 打开跟踪文件以记录跟踪信息。参见 `set tracefile` 命令。
- `-r` 指定类似于 `login` 的用户界面。在此模式下，除非被 `-e` 选项修改，否则将转义字符设置为波浪号（`~`）。`rlogin` 转义字符只有在跟跟一个回车键（Return）时才被识别。在此模式下，你必须在 `telnet` 命令之前置入 `login` 转义字符，通常为 `~`。你也可以跟随 `rlogin` 转义字符，像 `rlogin(1)` 一样使用 `\r` 或 `^z` 来关闭或挂起连接。此选项是一个未提交的接口，未来可能会发生变化。

## 使用

### `telnet` 命令

本节描述的命令可以在 `telnet` 中可用。你只需要输入每个命令的足够内容以唯一标识它。（这对于 `set`、`toggle`、`unset`、`environ` 和 `display` 命令的参数也是如此。）

- `close` 关闭任何打开的 TELNET 会话并退出 `telnet`。在命令模式下，文件结束（EOF）也会关闭会话并退出。
- `display [argument...]`
- 显示所有或部分 `set` 和 `toggle` 值（参见 `toggle` 参数）。
- `environ arguments...` 使用 `environ` 命令处理可以通过 ENV 选项发送的变量。从你的环境中获取初始变量集。默认只导出 `DISPLAY` 和 `PRINTER` 变量。`environ` 命令的有效参数如下：
- `define variable value`
- 定义变量值为 `value`。自动导出此命令定义的任何变量。你可以用单引号或双引号包裹 `value` 以包含制表符和空格。
- `export variable`
- 列出当前设置的变量。
- `logout variable`
- `set variable`
- `toggle variable`
- `undefined variable`
- `unexport variable`
- `mode`
