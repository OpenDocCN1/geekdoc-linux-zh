# find

`find` - 递归地遍历目录结构并查找列出的文件。

以下是一些常用的选项：

- `-f` 指定供 `find` 遍历的文件层次结构。
- `-s` 当遇到符号链接时，使用链接引用的文件而不是链接本身。
- `-x` 不进入设备号与起始遍历的文件不同的不同的目录。
- `-print` 将路径名打印到标准输出。
- `-size n` 如果文件大小为 `n`，则为真。

## ls

`ls` - 列出目录内容。

一些常用的选项：

- `-a` 列出所有条目。
- `-c` 使用文件最后修改时间进行文件列表的排序。
- `-d` 仅列出目录名，不列其内容。
- `-g` 在输出中包含组。
- `-i` 在报告的第一列打印 inode 节点号。
- `-q` 非打印字符用 "" 表示。
- `-r` 反转文件打印的顺序。
