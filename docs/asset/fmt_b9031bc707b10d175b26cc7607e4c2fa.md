
# 第 8 章 图形函数

`XQueryBestStipple` 函数返回与指定尺寸的最佳或最接近的尺寸。对于 `CursorShape`，这是在 `which_screen` 指定屏幕上可以完全显示的最大尺寸。对于 `TileShape`，这是填充速度最快的尺寸。对于 `Stipple`，这是可以点彩的尺寸。对于 `CursorShape`，可绘制区域表示所需的屏幕。对于 `TileShape` 和 `Stipple`，可绘制区域表示屏幕以及可能存在的窗口类和深度。`InputWindow` 不能作为 `TileShape` 或 `Stipple` 的可绘制区域，否则会发生 `BadMatch` 错误。

## `XSetClipMask(display, gc, pixmap);`

- `display` 指定与 X 服务器的连接。
- `gc` 指定指定的 `GC`。
- `pixmap` 指定 `pixmap` 或 `None`。

如果裁剪掩罩（clip-mask）被设置为 `None`，则像素将始终被绘制（无论裁剪起点 clip-origin 何在）。

`XSetClipMask` 可能会产生 `BadAlloc`、`BadGC`、`BadMatch` 和 `BadPixmap` 错误。

若要将给定 `GC` 的裁剪掩罩设置为指定的矩形列表，请使用 `XSetClipRectangles`。

## `XSetClipRectangles(display, gc, clip_x_origin, clip_y_origin, rectangles[],], n, ordering);`

- `display` 指定与 X 服务器的连接。
- `gc` 指定指定的 `GC`。
- `clip_x_origin` 和 `clip_y_origin` 指定裁剪起点（clip-origin）的 `x` 和 `y` 坐标。
- `rectangles` 指定一个定义裁剪掩罩的矩形数组。
- `n` 指定矩形的数量。
- `ordering` 指定矩形之间的排序关系。你可以传递 `Unsorted`、`YSorted`、`YXSorted` 或 `XYBanded`。

`XSetClipRectangles` 将给定 `GC` 中的裁剪掩罩更改为指定的矩形列表并设置裁剪起点。裁剪起点相对于图形接口中所指定的任何绘图对象（`drawable`）的起点进行解释。请求坐标相对于裁剪起点解释。除非矩形互不相交，否则图形结果将未定义。注意，矩形列表可以是空的，这与在 `XCreateGC`、`XChangeGC` 和 `XSetClipMask` 中传递 `None` 作为裁剪掩罩是相反的。

如果已知，可以通过 `ordering` 参数指定矩形的排序关系。如果指定了错误的排序，X 服务器可能会产生 `BadMatch` 错误，但并非强制要求这样做。如果没有生成任何错误，则图形结果是未定义的。`Unsorted` 表示矩形以任意顺序排列。`YSorted` 排序意味着所有 Y 起点相同的矩形在它们的 X 起点上是非递增的。`XYBanded` 则在 `YSorted` 的基础上额外限制为：对于每一条 Y 扫描线（scanline），包含该扫描线的所有矩形都具有相同的 Y 起点和 Y 跨度（Y extents）。

`XSetRectangles` 可能会产生 `BadAlloc`、`BadGC`、`BadMatch` 和 `BadValue` 错误。

Xlib 提供了一系列用于区域运算的基础函数。有关这些函数的信息，请参阅第 16.5 节。

## 设置弧模式、子窗口模式和图形暴露

若要设置给定 `GC` 的弧模式，请使用 `XSetArcMode(arc_mode)`。

```
XSetArcMode(display, gc, arc_mode);
```

- `display`: 指定与 X 服务器的连接。
- `gc`: 指定指定的 `GC`。
- `arc_mode`: 指定弧模式。你可以传递 `ArcChord` 或 `ArcSlice`。

`XSetArcMode` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

若要设置给定 `GC` 的子窗口模式，请使用 `XSetSubwindowMode(display, gc, subwindow_mode)`。

```
XSetSubwindowMode(display, gc, subwindow_mode);
```

- `display`: 指定与 X 服务器的连接。
- `gc`: 指定指定的 `GC`。
- `subwindow_mode`: 指定子窗口模式。你可以传递 `ClipByChild` 或 `IncludeInferiors`。

`XSetSubwindowMode` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

若要设置给定 `GC` 的图形暴露标志（graphics exposure flag），请使用 `XSetGraphicsExposures(graphics_exposures)`。

```
XSetGraphicsExposures(display, gc, graphics_exposures);
```

- `display`: 指定与 X 服务器的连接。
- `gc`: 指定指定的 `GC`。
- `graphics_exposures`: 指定一个布尔值，表示在用此 `GC` 调用 `XCopyArea` 和 `XCopyPlane` 时，是否想要报告 `GraphicsExpose` 和 `NoExposure` 事件。

`XSetGraphicsExposures` 可能会产生 `BadAlloc`、`BadGC` 和 `BadValue` 错误。

一旦你建立了与显示器的连接，你就可以使用 Xlib 图形函数来：

- 清除并复制副本
- 绘制点、线、矩形和弧形
- 填充区域
- 操作字体
- 绘制文本

如果每次调用都使用相同的绘图对象（`drawable`）和 `GC`，Xlib 会对连续的 `XDrawPoint`、`XDrawLine`、`XDrawRectangle`、`XFillArc` 和 `XFillRectangle` 进行批量处理。注意，这减少了发送到服务器的请求总数。

## 清除区域

Xlib 提供了你可以用于清除区域或整个窗口的函数。由于 `pixmap` 没有定义的边界，因此无法使用本节描述的函数进行填充。相反，为了对 `pixmap` 执行类似的操作，你应该使用 `XFillRectangle`，它会将 `pixmap` 设置为已知值。

若要清除给定窗口的矩形区域，请使用 `XClearArea`。

```
XClearArea(display, w, x, y, width, height, exposures);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `x` 指定 `x` 和 `y` 坐标，相对于窗口的起点，指定矩形的左上角。
- `width` 和 `height` 指定宽度和高度，即矩形的尺寸。
- `exposures` 指定一个布尔值，表示要生成 `Expos` 事件。

`XClearArea` 函数使用窗口的背景像素或 `pixmap` 绘制指定尺寸的矩形区域。其子窗口模式实际上是 `ClipByChildren`。如果 `width` 为 0，则将其替换为窗口当前宽度减去 `x`。如果 `height` 为 0，则将其替换为窗口当前高度减去 `y`。如果窗口有定义的背景，则窗口的内容将进行平铺。如果窗口背景为 `None`，则窗口的内容将保持不变。无论是否平铺或当目标是窗口，如果 `exposures` 为 `True`，就会生成 `expose` 事件。如果你指定了一个类为 `InputOnly` 的窗口，将发生 `BadMatch` 错误。`XClearArea` 可能会产生 `BadMatch`、`BadValue` 和 `BadWindow` 错误。

若要清除给定窗口的区域，请使用 `XClearWindow`。

```
XClearWindow(display, w);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。

`XClearWindow` 函数清除指定尺寸的区域。如果窗口有定义的背景，则窗口的内容将进行平铺。如果窗口背景为 `None`，则窗口的内容将保持不变。无论是否平铺，`XClearWindow` 可能会产生 `BadMatch` 和 `BadWindow` 错误。

## 复制区域

Xlib 提供了你可以用于复制区域或位（bit plane）的函数。

若要在根和深度绘图对象之间复制区域，请使用 `XCopyArea`。

```
XCopyArea(display, src, dest, gc, src_x, src_y, width, height, dest_x, dest_y);
```

- `display` 指定与 X 服务器的连接。
- `src` 指定源和目标矩形。
- `gc` 指定指定的 `GC`。
- `src_x` `src_y` 指定 `x` 和 `y` 坐标，相对于源矩形的起点，指定其左上角。
- `width` `height` 指定宽度和高度，即源和目标矩形的尺寸。
- `dest_x` `dest_y` 指定 `x` 和 `y` 坐标，相对于目标矩形的起点，指定其左上角。
