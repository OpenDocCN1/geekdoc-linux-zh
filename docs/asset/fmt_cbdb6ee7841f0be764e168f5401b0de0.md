### 26.8 调试 SAMBA

Samba 通常运行得不需要太多关注。然而，如果你遇到问题，可以参考两个主要的调试信息源：客户端日志文件和 `smbstatus` 命令。确保你的配置文件中有适当的日志文件设置：

```ini
[global]
%m 为每个客户端写入一个单独的文件。
log file = /var/log/samba.log.%m
max log size = 1000
# 记录多少信息。你也可以为系统的组件
; 组件指定日志级别（这里通常为 3，身份验证级别为 10）。
log level = 3:auth10
```

级别越高，产生的信息越多。记录日志需要时间，除非你正在调试，否则不要请求过多信息。操作速度可能会被显著降低。
