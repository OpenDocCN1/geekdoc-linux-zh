标准错误被重定向到 `/dev/null`。如果不这样做，`tar` 会为未更改的文件打印一条消息，告诉该文件不会被提取。

这种工作方式的缺点是它查看文件的时间戳。假设你将一个归档下载到包含备份的目录，而该归档包含两年前创建的文件。当将这些文件的时间戳与初始归档的时间戳进行对比时，新文件实际上看起来是新的，并且不会包含在使用 `-N` 选项创建的增量备份中。

更好的选择是使用 `-g` 选项，它将创建一个备份的文件列表。在进行增量备份时，会根据此列表检查文件。其工作原理如下：

```
jimmy:> tar cvpf work-20030121.tar -g snapshot-20030121 work/
work/
work/file1
work/file2
work/file3
```

```
jimmy:> file snapshot-20030121:ASCII text
```

次日，用户 jimmy 处理了 file3。

```
jimmy:> tar cvpf work-20030121.tar -g snapshot-20030121 work/
work/
work/file1
work/file2
work/file3
```

## 使用 dd 命令转储数据

`dd` 命令可以将数据写入磁盘，或从磁盘提取数据，取决于给定的输入和输出设备。例如：

```
gaby-> dd if=images-without-dir.tar.gz of=/dev/fd0H1440
98+1 records in
98+1 records out
```

```
gaby-> dd if=/dev/fd0H1440 of=/var/tmp/images.tar.gz
2880+0 records in
2880+0 records out
```

```
gaby-> ls /var/tmp/images*
/var/tmp/images.tar.gz
```

注意，转储是在未挂载的设备上进行的。使用此方法创建的软盘无法文件系统中挂载，但这正是创建启动盘或救援磁盘的方法。有关 `dd` 功能的更多信息，请阅读 man 页。
