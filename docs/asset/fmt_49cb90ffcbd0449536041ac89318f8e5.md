## 互联网应用程序和命令概述

早期的 Linux 多年来为 Web、邮件、FTP 和其他互联网服务提供了高质量的服务器，而这些桌面应用程序的当前版本变得既稳定又内容丰富。如果 Web 浏览和电子邮件是你桌面系统的主要需求，Fedora 和 RHEL 已经准备好让你放弃 Windows 桌面系统。
