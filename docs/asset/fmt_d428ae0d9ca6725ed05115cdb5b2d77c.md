# 自动化事件通知

为了主动解决问题，预警至关重要。在本章中，我们将观察在系统事件发生时通过自动化通知传播消息的技术。当我们编写监控 shell 脚本遇到失败、成功或请求时，我们需要一种将消息传递给正确的人的方法。shell 脚本中真正的三个通知策略：第一是向用户发送电子邮件。我们还可以通过电子邮件向用户发送字母数字页面，以便对传呼机进行即时通知。第三是通过拨号调制器向服务商发送文本页面。我们主要查看前两种方法，但我们还会列一些良好的软件产品，它们通过拨号调制器发送文本页面并将消息传输给传呼供应商。

在某些地方，电子邮件受到严格限制，以至于你必须使用小技巧或绕过一些限制。我们也会涵盖这些情况。

## 自动化事件通知的基础

在 shell 脚本中，某些时刻你想发送自动化通知。例如，如果你正在监控文件系统，且脚本发现某个文件系统超过了最大阈值，那么你可能希望被告知这种情况。我总是喜欢在备份完成时收到电子邮件通知。

每晚都完成备份——不仅仅是在备份出现错误时，备份成功时也是如此。这样一来，我每天早上只需通过检查电子邮件就能知道昨晚备份的状态。如果完全没有发送任何邮件，我就知道发生了严重的备份问题。通知方法有几种，但最常见的是通过电子邮件发送到呼叫机（转短信）或通过电子邮件账户。在接下来的几个章节中，我们将查看获取发送消息的技术，即使只有一台服务器可以访问邮件。

### 使用 mail 和 mailx 命令

最常用的通知方法是使用 `mail` 和 `mailx` 命令。这两个命令的基本语法如如下代码所示：

```
mail -s "This is the subject" $MAILOUT_LIST < $MAIL_FILE

OR

cat $MAIL_FILE | mail -s "This is the subject" $MAILOUT_LIST

mailx -s "This is the subject" $MAILOUT_LIST < $MAIL_FILE

OR

cat $MAIL_FILE | mailx -s "This is the subject" $MAILOUT_LIST
```

并不是所有系统都支持 `mail` 命令，但支持的系统使用的语法与 `mail` 命令相同。为了处理多个 Unix 平台时安全起见，请始终使用 `mail` 命令。
注意 `mail` 和 `mailx` 命令中使用了 `MAILOUT_LIST` 和 `MAIL_FILE` 变量。`MAILOUT_LIST` 变量包含一个要发送消息的电子邮件地址列表或邮件别名列表。`MAIL_FILE` 变量指向一个包含要发送消息的文件。让我们逐一查看这些变量。

假设我们正在监控某机器上的文件系统，且 `/var` 文件系统的使用率已达到 98%，这超过了文件系统视为满的 85% 阈值。系统管理员需要快速获得有关此情况的通知，否则当 `/var` 满时会导致机器崩溃。在监控 shell 脚本中定义了一个 `MAIL_FILE` 变量指向文件名 `/tmp/mailfile.out`，即 `$MAIL_FILE=/tmp/mailfile.out`。我们使用 `cat /dev/null > $MAIL_FILE` 创建一个零大小的邮件文件。当发现错误时（在本例中是 `/var` 达到 98%），消息会被追加到 `$MAIL_FILE` 中以供稍后发送。如果发现了更多错误，当 shell 脚本处理每个任务时，它们也会追加到文件中。在 shell 脚本结束时，我们可以测试 `$MAIL_FILE` 的大小。如果 `$MAIL_FILE` 中有任何数据，则文件大小将大于 0 字节。如果文件有数据，我们就发送该文件。如果文件为空且大小为 0 字节，我们什么都不做。

为了说明这个想法，让我们研究列表 3.1 中的代码段。

## 自动事件通知

```

cat /dev/null > $MAIL_FILE

MAIL_LIST=-randy@my.domain.com 1234567890@mypage_somebody.net

check_filesystems # 此函数检查文件系统的百分比

if [ -s $MAIL_FILE ]

then

    mail -s "Filesystem Full" $MAIL_LIST < $MAIL_FILE

列表 3.1 典型代码段列表。

在 3.1 中，我们看到一个定义了 `mail` 命令中使用的 `MAIL_FILE` 和 `MAIL_LIST` 变量的代码段。在定义之后，此代码段执行查找超过阈值文件系统的函数。如果超过了阈值，将如下面的代码段所示的消息追加到 `$MAIL_FILE` 文件：

THISTHOST=$THISTHOST=$(uname -n)

echo "$THISTHOST: $FS is $PERCENT" | tee -a $MAIL_FILE
```

此代码段来自 `check_filesystems` 函数。对于我的机器，此 `echo` 语句将向屏幕显示以下消息，并将其追加到 `$MAIL_FILE` 文件中：

```

```主机机名为 yogi，文件系统为 /var，用用空间百分比为 98%。注意 `echo` 语句管道 `()` 之后的 `tee` 命令。在这种情况下，我们希望在屏幕上显示结果，并发送一个带有相同数据的电子邮件。当我们把输出重定向到 `| tee -a $FILENAME` 时，`tee -a` 命令起到了双重作用。

在 `check_filesystems` 函数完成后，我们测试 `$MAIL_FILE` 的大小。如果大小大于 0 字节，我们使用 `mail` 命令发送邮件消息。消息将发送到 `randy@my.domain.com` 和 `1234567890@mypage_somebody.net` 电子邮件地址：
