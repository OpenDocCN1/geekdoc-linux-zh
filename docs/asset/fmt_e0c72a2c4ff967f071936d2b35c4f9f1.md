# 第 10 章 同步串行接口

## 温度传感与显示

工程师需要一种廉价、准确且覆盖广泛温度范围的传感技术。国家半导体 `LM70` (national.com)。

飞利浦半导体专门设计的 `SAA1064` 具有 `I2C` 驱动四段数码管显示器的功能。`I2C` 接口允许将四个 `SAA1064` 连接到单个同步串口。一个连接到四个 `SAA1064` 的板可以显示升降道顶部和底部的温度，单位为华氏和摄氏。例如，一个单路温度显示可以显示升降道顶部温度为 10°F 和 -12°C，底部温度为 44°F 和 6°C。每个 `SAA1064` 价格约为 $4。

Project Trailblazer 的工程师需要将 `LM70` 连接到 x86 并口并开发 `SPI` 同步通信算法用于驱动程序。嵌入式开发者将同步串行算法称为“位操作”程序。然后工程师需要将 `LM70` 连接到 MediaEngine 的 ARM 处理器。ARM 处理器的串口 4 是一个同步串口 (`SPI`)，简化了与外部 `SPI` 设备的通信。接下来，工程师需要将 `SAA1064` 连接到 x86 并口并使用现有的 `I2C` 设备驱动软件。最后，工程师需要为 PowerPC 开发一个 `I2C` 位操作程序，以使 `RPX-CLLF` 开发温度 LED 显示。本章概述了表 10.1 中列出设备的连接和快速开发。

## 表 10.1 温度设备连接与驱动类型

| 平台 | 软件类型 |
| --- | --- |
| LM70 温度传感器 (SPI) | 位操作算法 |
| x86，并口 SA-1110，SPI | 节点控制器 |
| SAA1064 LED 驱动器 (I2C) | 开源设备驱动 |
