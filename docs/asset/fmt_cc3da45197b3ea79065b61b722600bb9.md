`awk` 命令按照我们使用的方式，被用于提取我们想要处理的字段，即第一个字段，队列名称。通过将上一步的输出作为我们 `awk` 语句的输入，我们使用以下语法提取第一个字段：

command | awk '{print $1}'
```

你也可以使用 `awk` 提取任何有效字段，也可以同时提取多个字段。例如，如果我们想提取第 1 和 3 字段（由 `$1` 和 `$3` 指定），以下 `awk` 语句将完成此任务。

command | awk '{print $1, $3}'
```

注意，我在 `$1` 和 `$3` 之间添加了一个逗号。如果省略了逗号，输出将*不会*是两个没有空格连接在一起的字符串。

**列表 16.3** 用于启用“经典型”AIX 队列的 for 循环。（续）

在 `for` 循环内部，我们尝试单独启用每个队列。如果 `enable` 命令的返回码不是 0，我们就会打印一条错误消息，指示该队列无法启用。列表 16.3 中高亮的行即是如此。我们使用了由 `(( math test ))` 指定的数学测试。在使用这种数学方法时，你不需要在数字变量前添加美元符号 `$`。当变量由系统产生（如 `$?`）时，则需要美元符号。测试等价性也需要使用双等号 `==`，因为单等号 `=` 是赋值，而不是测试。

在测试返回码是否为 0 之后，我们使用双管道 `||` 指定的逻辑或（OR）。这个逻辑或只有在 `enable` 命令的返回码非零时才会执行下一条命令；命令语句中还使用了通过双放大符号 `&&` 指定的逻辑与（AND）。逻辑与的作用恰相反；如果测试为真，它将执行后续的命令，而不是如果为假。逻辑或和逻辑与都用于替换 `if..then..else` 语句。

我们也可以通过使用单个复合命令语句来完成此任务。正如我们在 `for` 循环中使用命令替换一样，我们可以使用命令替换来产生命令参数。例如，我们可以使用 `for` 循环命令为 `enable` 命令创建命令参数。为了更清楚地看到这一点，请以下命令。

```
enable $(enq -AW | tail +3 | grep DOWN | awk '{print $1}') 2>/dev/null

enable $(lpstat -W | tail +3 | grep DOWN | awk '{print $1}') 2>/dev/null
```

之前的两个复合命令语句产生相同的结果：启用系统上所有的打印队列。使用这种技术唯一的问题是，如果你执行此命令且所有打印机已经启用，你将从标准错误中得到以下输出：

```
usage: enable PrinterName ...
Enables or activates printers.
```

如你所示，通过在语句末尾添加 `2>/dev/null` 我将其发送到了空设备，但如果所有打印机都已启用，返回码仍然是非零。除非你想创建一个关于打印机启用失败的通知，否则这不是问题。在列表 16.3 的 `for` 循环中，我们使用 `enable` 命令的返回码产生通知。使用哪种技术由你决定。如果你不想看到任何输出，可以将单个复合语句作为 cron 条目，或者在脚本中使用 `for` 循环技术将失败通知重定向到日志文件。如果你使用日志文件，可能希望添加时间戳。
