## File (文件)

存储在磁盘上的文档或其他信息集合，并通过唯一名称标识。当你保存文件时，磁盘可能会将数据存储在几十或数百个非连续的簇中。文件分配表 (`FAT`) 是这些簇链接到文件的顺序索引。然而，对用户而言，文件显示为单元目录，并作为单元被检索和复制。来自 QCD http://www.ldp.org/LDP/Linux–Dictionary/html/index.html

## file (文件数据)

存储在文件系统中作为单个可寻对象的数据文件。它可以是可执行的、文本或基于二进制的，也可以代表由操作系统控制的系统硬件。来自 RedHat–9–Gloss http://www.ldp.org/LDP/linux–Dictionary/html/index.html

## File compression utility (文件压缩工具)

实用程序，如 `PKZIP`、`Stuff` 或 `DriveSpace`，用于压缩和解压缩不常用的文件，可以节省 40 到 90% 的硬盘磁盘空间。你可以使用另一个工具来压缩文件。还有用于压缩特定类型文件（如下载文件）的专用压缩工具。这些程序使用留在内存中的特殊驱动程序来根据需要解压缩和压缩文件。参见归档、板系统 (BSBs) 和压缩文件。来自 QUECID http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# 文件传输协议 (FTP)

一种用于在局域网（`LAN`）和互联网等网络设备之间传输文件的协议。在典型的 FTP 会话中，客户端登录到 FTP 服务器，访问目录列表并从服务器下载文件。FTP 会话可以是匿名的，也可以需要身份验证才能访问。源自 Redhat9–Glossary http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
