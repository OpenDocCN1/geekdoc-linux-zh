```
# nmap -sU 10.0.2.50
```

执行后会产生以下输出：

正如任何优秀的端口扫描器一样，扫描特定端口的能力至关重要。判断网络上所有系统是否拥有一组标准网络服务或某项特定服务的一个好方法是，针对特定端口号扫描该网络。例如，假设我们想确定`10.0.2.0`网络上的所有系统是否支持某种SNMP代理。命令：

```
$ nmap -p 161 -sU -o results 10.0.2.0/24
```
