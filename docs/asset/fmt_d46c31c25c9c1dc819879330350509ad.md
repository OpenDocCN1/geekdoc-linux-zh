
计算机数控提供了对机器工具非常灵活和多功能的控制。大多数加工操作要求切削工具在工件的某个选定位置进给。例如，在 conventional 车床中，车刀安装在带有手动进给和横进给滑块的滑座上。操作员手动转动曲柄，将切削工具进给到工件（进给）以达到所需的直径。另一个曲柄然后沿机器的纵向轴移动车刀，沿工件产生圆柱形切削。车刀的进给率有时由选定的进给齿轮控制。这些齿轮使轴滑块以所需的进给速度移动。CNC 机器用伺服电机系统取代了手摇曲柄和进给齿轮。参见 [伺服机构](https://example.org/servo-mechanism)。

计算机数控允许将所需的切削深度和进给率“拨入”，而不是由曲柄、凸轮和齿轮控制。这提供了精确、可重复的机器运动，可以编程以实现最佳速度、进给和机器循环。所有切削工具的应用，无论是车床、钻床还是加工中心，都有最佳速度和进给，这是通过仔细权衡刀具寿命、所需生产率和操作员注意力来确定的。通过计算机数控，这些参数设置一次，然后在每个后续机器循环中精确重复。

在计算机辅助制造（CAM）中，计算机用于协助编程 CNC 机器。在先进的 CNC 制造操作中，机器零件首先在计算机辅助设计（CAD）设备上设计。相同的电子图纸然后用于自动创建 CAM 零件程序。CAM 的较不先进版本是使用高级零件编程语言编写零件程序。参见 [计算机辅助设计与制造](https://example.org/computer-aided-design-and-manufacturing)。

计算机数控机床主要用于需要灵活性或必须创建可变和复杂零件几何形状的情况。它们用于生产从几件到几千件的批量零件。极大的制造批量通常需要更具产品特定性的机器，这些机器可以为大批量生产运行进行优化。[J.R.C.B]

## 外围设备

被称为外围设备的设备，也称为输入/输出（I/O）设备。一些外围设备，如键盘，仅是输入设备；其他外围设备，如打印机，仅是输出设备；还有一些则兼具两者功能。参见数字计算机；微型计算机。

显示器是操作员生成的图像或由程序生成的图像在阴极射线管（CRT）上显示的设备。电子枪——单色显示器有一个，彩色显示器有三个——在屏幕内侧发射光子，使其发光。大多数便携式计算机上的平板显示器，被称为液晶显示器（LCD），使用两片偏振滤光片，中间夹着液晶来生成图像。参见电子显示；液晶。

计算机键盘基于打字机键盘，包含用于输入字母、数字和标点符号的按键，以及改变其他按键含义的按键。功能键执行的任务因程序而异。参见打字机。

鼠标是在桌面上滚动以移动屏幕上光标的设备。鼠标底部的一个球将设备的运动传递给鼠标内的传感器，然后通过连接端口传输到计算机。还有一些鼠标用光学装置代替机械球，也有鼠标使用红外线而非物理连接。

轨迹球基本上是一个倒置的鼠标，用于移动光标的球位于顶部而不是底部。

操纵杆主要用于游戏的指向设备。

光笔执行与鼠标或轨迹球相同的功能，但它被举到屏幕上方，其传感器检测像素的存在，并通过电缆向计算机发送信号。

图形或数字化平板是一种表面下带有电子元件的垫子，使用一种称为触笔的尖头设备在其上绘制。绘制的形状会显示在监视器屏幕上。

个人计算机或工作站中最常见的输入或存储设备是硬盘驱动器，它是一叠磁化盘片，信息通过生成代表二进制数系统中1或0的电流的磁头存储在盘片上。该设备之所以称为“硬”盘，是因为盘片是坚硬的，之所以称为“驱动器”，是因为它在密封外壳内以每分钟3600转的速度旋转。软盘由类似录音带使用的柔性薄膜制成，通常存储在一个硬质外壳中，并由其驱动器以约每分钟3600转的速度旋转。参见计算机存储技术。

数据也可以用光来存储和检索，激光束读取光盘上的坑模式。最常见的光盘类型是只读光盘（CD-ROM）。另一种光盘类型是一次写入多次读出光盘（WORM）。参见光盘；多媒体技术；光盘记录。

由于效率和速度更高，磁盘驱动器迅速取代磁带驱动器，成为数据和程序存储的主要方式。磁带驱动器仍用于备份存储，复制硬盘内容作为对机械故障或人为错误的保险。参见磁记录。

扫描仪将计算机外部的图像，如文本、绘图或照片，转换为数字图像，并将其发送到计算机进行显示或进一步处理。图像被视为图形图像而非文本图像，因此可以用图形程序进行修改，但不能用文字处理程序进行编辑，除非扫描仪是字符识别系统的一部分。为了将照片数字化，扫描仪可能会修改图像（使点之间变化的空间间隔），或者使用标签图像文件格式（TIFF），将图像存储为16个灰度值。一些扫描仪可以使用标准视频摄像机捕获图像供计算机使用。参见字符识别。

打印机将计算机生成的文本或其他图像输出到纸张或其他表面上。打印机分为击打式或非击打式设备。

菊轮或顶针打印机因其承载凸起的字符图像元件的形状而得名。其速度，可能为每秒30个字符，现在被认为慢得不可接受。点阵打印机通过击打一系列钢丝针（通常是9、18或24根），形成必要的模式，通过色带形成字母、数字、线条或其他字符的图像。

喷墨打印机在墨仓中携带墨水，通过加热或振动将其变成雾状，并通过小孔喷射形成纸上的字符模式。激光打印机类似于复印机。激光打印机输出的质量通常是目前可获得的最高质量。参见复印工艺；印刷。

调制解调器将一台计算机连接到另一台计算机，通常通过电话线交换信息。参见调制解调器。[L.R.S.]

## 计算机编程

设计和编写计算机程序，即由计算机执行的一系列指令。计算机只有执行计算机程序才能执行有用的任务。编程语言或计算机语言是用于表达计算机程序中指令的专用语言。

**问题解决。** 在这个阶段，程序员全面理解正在开发的计算机程序所要解决的问题，并设计一个逐步的过程（算法），当遵循该过程时，可以解决问题。这种过程随后用一种相当精确但易于理解的不言自明的符号表示，例如伪代码，它使用英语语句和类似编程语言的关键词和结构来概述计算机程序的基本内容。参见算法。

一个有用的例子涉及寻找两个给定正整数的最大公约数（gcd）的问题。在对问题进行分析后，程序员可能会选择通过以下伪代码描述的过程来解决这个问题。（在伪代码中，模运算符产生一个整数除以另一个整数的余数；例如，15 模 6 的结果为 3。）

- 1. 设 `x` 和 `y` 为两个给定的整数
- 2. 当 `x` 和 `y` 都大于 0 时，重复第 3-5 行
- 3. 如果 `x` 大于 `y`
  - 4. 则用 `y` 模 `x` 的值替换 `y`
- 5. 否则用 `x` 模 `y` 的值替换 `x`
- 6. 如果 `x` 是 0
  - 7. 则 `x` 是 `gcd`
  - 8. 否则 `x` 是 `gcd`

参见数论。

第 3-5 行和第 6-8 行是选择控制结构的示例，它指定了备选指令，使计算机能够选择一个备选进行执行，而忽略另一个。第 2-5 行形成一个重复控制结构（通常称为循环），它使计算机重复执行某些指令（第 3-5 行）。

程序员使用缩进来显示语句之间的结构关系，并增强程序的可读性。在示例中，缩进清楚地表明第 4 行和第 5 行是从第 3 行开始的选择结构的一部分，第 3-5 行是从第 2 行开始的循环的一部分，第 7 行和第 8 行是从第 6 行开始的选择结构的一部分。

为了解决给定问题而开发的算法必须经过验证，以确保其功能正确。以下列表展示了上述过程如何通过依次修改 `x` 和 `y` 的值来推导 48 和 18 的最大公约数。

```
/**********************************************
*The function findgcd computes the greatest
*"common divisor of two integers, and
*"returns the result as an int value."*/
**********************************************/
int findgcd (int x, int y)
{
while (x > 0 && y > 0)
{
if (x > y)
x = x % y;
else
y = y % x;
if (x == 0)
return y;
else
return x;
}}
```

以 `//` 开始并以 `/*` 结尾的文本（上述前五行）是程序注释。程序注释是不可执行的指令，在任何方面都不影响计算机程序的功能，但旨在作为记录计算机程序的一种方式。适当的程序注释增强了程序的可读性，并被认为是计算机程序的重要组成部分。当随后出现此类需求时，可读性更强的程序通常更容易增强或修改。上述文本的其余部分是 C++ 代码（C++ 语言中的指令），用于计算两个给定整数的最大公约数。C++ 代码中的缩进与伪代码具有相同的目的。显然，上述 C++ 代码与先前开发的伪代码紧密平行，因为它们都表达了相同的抽象过程。
