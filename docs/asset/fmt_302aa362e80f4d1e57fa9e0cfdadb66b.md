## 发热
**发热**（Fever）由于体调节机制功能异常导致温暖血液中心体温升高。发热影响多种疾病，包括感染性和非感染性疾病，在大多数情况下是由于中枢神经系统调节异常引起的。见体调节。

关于发热原因的实验研究表明，白细胞、固定的巨噬细胞可以被各种刺激激活，产生发热物质——内源性丙——`EP`。内源性丙被描述为一种分子量较低（13,000）的蛋白质，对……具有亲和力。导致体温升高的机制包括：通过外周血管收缩减少散热；交感神经增加代谢率；通过胆碱神经系统性抑制颤抖和产热；以及通过运动神经的不自主运动颤抖增加产热。

目前没有明确证据表明体温升高是由大多数对微生物无直接伤害的感染引起的。在伴有炎症的情况下，体温升高可能是宿主在对抗感染时的化学反应引起的。见炎症；[A]

## 费曼积分
**费曼积分**（Feynman integral）技术，也称为历史之和，是理解和分析量子系统动力学的基础。费曼公式给出了时间 `t` 从粒子 `p` 到点 `q` 的探测概率密度，表达式如下（其中路径是经典路径）：

```
exp[i Spath]/j(dpath)
```

轨迹路径的机械光学，且 `ħ` 是约化的普朗克常数。该积分是对时间 `t` 内从 `q` 到 `q` 的所有路径的无限求和。费曼通过使用分段线性路径的极限过程定义了它。

基底是 `M`。纤维被称为向量去纤维化群的纤维丛。见纤维丛（数学）。

费曼的思想在量子场论中特别重要，在那里它们是分析扰动级数的有用工具，也是少数几个扰动工具之一。见量子场论。

物理定律在相应群的变换下是不变的。在当这种群作为内部或局部对称性出现的情况下，纤维丛；群对称性是群对称。见群论；对称性物理。

量子动力学路径积分公式的替代方案是上述表达式的止相法，该方法认为对于 `ħ` 的小值，路径将是经典的。在作用量量形式中可以恢复经典力学。见最小作用原理。

纤维丛在数学中有许多应用。这些应用中的许多基于拓扑学和向量丛。流形的几何是通过切丛的不变性来研究的。

纤维作物生长是因为它们由纤维素或纤维状材料组成，这些材料用于商业产品和工业。

纤维分解是将空间分解为完全相同的子空间（基底）。这些子空间被称为基底。纤维丛在物理情况下自然产生。纤维丛理论已应用于规范理论，且在很大程度上，这些思想集中在这些这些丛上，这些思想促进了各个领域的专门发展。纤维丛的数学发展始于20世纪30年代。

### 883 光纤
光纤允许光从一个系统传输到另一个系统，光通过光纤传输以满足系统的一个或多个性能需求。光纤用于数据传输，当光信号通过光纤传输时。光纤带宽积比电气传输高数千倍。

光纤还用于照明，需要光以使能量不通过波导流失。光纤传输中的数据免受损坏或对环境干扰敏感的影响。电信光纤的直径非常小，5-10微米（0.0025–0.010 mm），使得光缆可以以更高的密度制造。光纤常用的材料有玻璃、硅和塑料，比铜密，使得光纤更轻。最后，光纤可以用需要高电绝缘的环境。见电磁干扰：光纤。

莫比乌带是纤维丛最简单的非平凡例子。它是通过旋转条带的一端并将两端粘合而成的。纤维是线，这些线的空间是一个圆。映射 `π` 将纤维中的所有点映射到一个点。

切丛出现在纤维丛的最早例子。对于流形（`M`），切空间（`TM`）由点 `(x, v)`组成，其中 `x` 是 `M` 中的点，`v` 是 `M` 的切空间中的向量，构成纤维映射到。

来自光纤的光聚焦在反向偏置的`pn`结上，电子-空穴对在其区域附近产生光子。另一种电路，或单集成电路，放大信号并将其转换为适合接收端的光的光平。见光伏效应。

发射器将计算机集成电路的电电压转换为电流，然后转换为光脉冲。反之，驱动驱动光发射二极管（`LED`）。见集成电路。

## 光纤成像
光纤在传输中的应用，利用精密光纤束将图像从光纤的一端传输到另一端的能力。

每根光纤传输一个端的图像，完整图像由点阵列（像素）组成，这些点可以重构为可读的图像。

光通过光纤壁的全反射在光纤中传输。每根光纤都有包层（一层低折射率层——通常为玻璃），由玻璃（或塑料）制成。包层引导光进入和离开光纤，将其保持在光纤内部。光纤束可以被弯曲或扭转。

**光纤。波的折射。**

柔性光纤束广泛应用于工业和医学领域，将光从物镜传输到控制手柄末端。长度 3 到 8 米的光纤电缆用于各种医疗应用，如内窥镜、血管检查。较长的工业光纤用于管道和水质检查，这些检查位于核腔内。
