
# 说明

在编写脚本时，你经常需要测试条件。最简单的测试是判断一个条件为真还是假。如果表达式为真，则执行任何后续命令；否则，继续执行脚本。

## `/usr/bin/test`

`test`命令评估条件并通过其退出状态指示评估结果。退出状态为 0 表示条件评估为真，退出状态为 1 表示条件评估为假。

该命令的第二种形式使用方括号（`[]`）代替`test`命令；方括号必须分隔参数，且条件是可选的。

## Bourne Shell

`if`后面的条件被执行，如果它返回 0 退出状态，则执行第一个后面的`action`。否则，执行`elif`后面的`condition2`，如果其值为 0，则执行接下来的`action2`。如果`if`和`elif`条件均失败，则执行`else action3`，命令返回 0 退出状态。允许任意数量的`elif ... then`分支对，但只能有一个`else`。

`test`评估条件`condition`，如果其值为真，则将状态置为 0；否则，它将设置非零（假）退出状态；如果没有参数，`test`也会设置非零退出状态。当测试权限时，使用进程的有效用户 ID。

在第二个概要列表中所示的所有操作符、标志位和括号（括号）必须是`test`命令的独立参数；通常这些项目项通过空格隔开。

## 原语

你可以使用以下原语来构建条件：

- `-r filename`
如果`filename`存在且可读，则为真。

- `-w filename`
如果`filename`存在且可写，则为真。

- `-x filename`
如果`filename`存在且可执行，则为真。

- `-f filename`
如果`filename`存在是普通文件，则为真。或者，如果`/usr/bin/sh`用户在`PATH`环境变量中指定了`/usr/bin/bin`，那么如果`filename`存在且不是目录，`test`返回真。这种行为也是`/usr/bin/csh`用户的默认行为。`-f`选项的非目录替代方案用于 BSD 应用程序的过渡，可能在未来的发行中不再支持。

- `-d filename`
如果`filename`存在且是目录，则为真。

- `-h filename`
如果`filename`存在且是符号链接，则为真。对于所有其他原语（`-L filename`除外），将跟踪符号链接。

- `-c filename`
如果`filename`存在且是字符特殊文件，则为真。

- `-b filename`
如果`filename`存在且是块特殊文件，则为真。

- `-p filename`
如果`filename`存在且是命名管道 (`fifo`)，则为真。

- `-u filename`
如果`filename`存在且设置用户-ID 位已设置，则为真。

- `-g filename`
如果`filename`存在且设置组-ID 位已设置，则为真。

- `-k filename`
如果`filename`存在且设置粘滞位已设置，则为真。

## if,

- `-s filename`

- `-t [fildes]`

- `-s1 != s2`

- `-ne`

- `-ge`

## C Shell

多行形式的`if`，如果`condition`为真，则执行到`else`为止的`action`。否则，如果`condition2`为真，则执行`else`后面的`action2`。否则，执行`else`和`endif`之间的`action3`。`if`必须单独出现在输入行中，或者出现在`else`之后。只有一个`endif`，但它是必须的。

单行形式的`if`，没有`else`、`then`或`endif`关键字：指定的条件评估为真，带参数的单个`action`是执行的。`action`上的变量替换发生得很早，与命令的其他部分同时发生。`action`必须是单个命令，而不是管道、命令列表或参数化命令列表。

> 注意 — 如果`condition`为假，未执行`when`会发生 I/O 递归（这是一个 bug）。

## Korn Shell

`if`后面的条件被执行，如果它返回 0 退出状态，则执行第一个`then`后面的`action`。否则，执行`else if condition2`，如果其值为 0，则执行接下来的`then`后面的`action2`。如果失败，则执行`else action3`。如果没有执行`else action`或`then`，命令返回 0 退出状态。

关于`test`内置命令的描述，请参见`ksh(1)`章节条件表达式和算术评估以及 (`sh`) Bourne 的`test`内置命令。

```
[ condition ]
```
评估文件属性、字符串比较和复合与或或条件。
