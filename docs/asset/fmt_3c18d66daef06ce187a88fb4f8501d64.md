## 内置变量

|---|---|
| `$0` | 正在执行的命令或脚本名称。作为位置参数传递（例如 `n` 是 1 到 9 之间的数字），指示从命令行传递给脚本的值。如果括在花括号中，参数可以超过 9——例如，`${14}` 表示第 14 个位置参数。 |
| `$#` | 从命令行作为参数传递给脚本的位置参数数量。 |
| `$*` | 所有命令行参数的列表。 |
| `$@` | 所有命令行参数的单独双引号的列表。 |
| `$!` | 上一个后台命令的 PID（进程 ID）。 |
| `$$` | 当前进程的 PID（进程 ID）。 |
| `$?` | 表示上一个执行命令退出状态的数值值。 |
