# vtun

# vulnerability (vulnerable)

在社区安全领域，“漏洞”（vulnerability）一词描述了诸如程序错误或常见的配置错误等会导致系统被攻击或入侵的问题。文化：发现漏洞是黑客/信息安全文化的一部分。发现漏洞是证明你是“精英”的手段。这种亚文化与科学社区相似。例如，有许多人（通常是商业公司）增加了了自己的微小贡献，但以一种方式宣传结果，让人们认为他们对该发现之前的研究负责。对比：利用程序（exploit）和漏洞（vulnerability）这两个词紧密结合。通常，一个脚本/程序会利用特定的漏洞。大多数漏洞被脚本小子（script kiddies）利用，漏洞通常以最流行的利用它的脚本命名。关键点：这里存在广泛的漏洞扫描器/评估工具，可以扫描系统的常见漏洞。这些工具用于加固系统。另见：风险黑客词表 http://tld.org/LDP/linux-Dictionary/
