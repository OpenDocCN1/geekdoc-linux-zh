## sem_wait 函数

图 48 显示的 `sem_wait` 等信号量值超过 0。

```c
#include "unipc.h"
#include "semaphore.h"

int
sem_wait(sem_t *sem)
{
    int n;
    if (sem->sem_magic != SEM_MAGIC) {
        errno = EINVAL;
        return (-1);
    }
    if (n = pthread_mutex_lock(&sem->mutex)) != 0) {
        errno = n;
        return (-1);
    }
    while (sem->sem_count == 0)
        pthread_cond_wait(&sem->cond, &sem->mutex);
    sem->sem_count--;
    pthread_mutex_unlock(&sem->mutex);
    return (0);
}
```

我们必须在操作值之前获取信号量的锁。如果信号量值为 0，我们通过调用 `pthread_cond_wait` 进入睡眠，直到有人调用 `pthread_cond_signal` 释放信号。

## sem_trywait 函数

图 49 显示了 `sem_trywait` 函数，它是 `sem_wait` 的非阻塞版本。

```c
#include "unipc.h"
#include "semaphore.h"

int
sem_trywait(sem_t *sem)
{
    int n, rc;
    if (sem->sem_magic != SEM_MAGIC) {
        errno = EINVAL;
        return (-1);
    }
    if (n = pthread_mutex_lock(&sem->mutex)) != 0) {
        errno = n;
        return (-1);
    }
    if (sem->sem_count > 0) {
        sem->sem_count--;
        rc = 0;
    } else {
        rc = -1;
        errno = EAGAIN;
    }
    pthread_mutex_unlock(&sem->mutex);
    return (rc);
}
```

## sem_getvalue 函数

图 50 显示了我们的 `getvalue` 函数，它返回信号量的当前值。我们可以从这种实现中看到信号量比互斥锁和条件变量更简单。

```c
#include "unipc.h"
#include "semaphore.h"

int
sem_getvalue(sem_t *sem, int *pvalue)
{
    int n;
    if (sem->sem_magic != SEM_MAGIC) {
        errno = EINVAL;
        return (-1);
    }
    if (n = pthread_mutex_lock(&sem->mutex)) != 0) {
        errno = n;
        return (-1);
    }

    pthread_mutex_unlock(&sem->mutex);
    return (0);
}
```
