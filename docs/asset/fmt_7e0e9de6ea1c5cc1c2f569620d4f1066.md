
支持复制的数据库系统仍然需要备份。复制无法防止对所需数据的意外或蓄意删除。此外，复制系统之间的网络连接可能会失败，导致数据不一致。其他类型的故障往往会在这种情况下发生。

数据库的备份策略应该与数据库管理员（DBA）合作制定。允许 DBA 手动启动备份和恢复可能是可以的，也可能需要涉及系统管理员。这在很大程度上取决于人员的技能组合。

## 系统与数据

在本节中，我们讨论了尝试恢复完整系统时可能出现的一些问题。这样做是为了强调我们在第 3 章“恢复规划”中提出的建议，即系统的恢复计划应该从一个良好的模板重新构建它们。我们要求系统管理员不要对数据以外的任何内容依赖备份。相反，我们建议通过第 15 章“自动化安装与升级”中描述的方法通过重建系统来恢复系统。

从概念上讲，做备份非常简单——只需复制你可能想要恢复的所有内容。然而，这存在复杂性。让我们考虑以下场景：

- 使用以下命令将完整系统备份到 SCSI 模板中：

```bash

```

假设整个系统都装装在单块磁带上。使用以下命令验证磁带是读性：

```bash

```

或者通过以下命令进行更彻底的检查：

```bash

```

在一种的情况下，可以确保磁带驱动器可以从该驱动器读取，尽管我们得到的只是备份磁带上的文件名列表。在后一种情况下，我们得到了磁带上的数据与系统当前状态之间的差异列表。

如何进行全恢复？如果根文件系统今晚被损坏了，明天早晨让文件恢复运行的确切程序是什么？假设你已经创建并测试了救急软盘，并且它包含了所有所需的模块、驱动程序和工具以：

- 启动系统
- 访问磁带驱动器

## 测试的风险

测试恢复程序有其自身的风险。尝试将文件恢复到不同的应用程序时，可能会意外覆盖甚至损坏正在使用的使用的文件。

执行恢复演练最安全的方法是在备用工作站上而不是生产服务器上。留出额外的磁盘或额外的分区可能是一个更合理的预防措施。为了此目的争取“额外”设备可能会带来压力——但请考虑由于备份程序不当或对恢复过程误解而导致丢失文件的压力。

## 系统特定扩展

于此为止，GNU `tar` 和 `cpio` 并不存储特定 `ext2` 文件系统的“非标准”元数据。系统特定的功能，如 `ext2` 属性（不可变、可转储、压缩和位）以及 BSD UFS 标志都没有从标准 `tar` 和 `cpio` 文件中存储或恢复。

随着对更多此类功能（访问控制列表或 ACLs、权限位或能力集等）的支持添加到 LINUX（以及其他 UNIX 实现）中，必须增强工具以解决这些问题。

## 使用 tar

`tar` 是最老且最常用的归档工具之一。它是 FTP 站点等分发文件最常见的格式。由于大多数 UNIX 用户熟悉 `tar`，我们将所有其他工具与 `tar` 进行比较。

旧版本的 `tar` 在最大文件名长度（通常为 100 个字符）和设备节点（特殊文件）方面存在限制。这些限制在 GNU 版本中已大部分消除。然而，最好通过依赖这些功能来测试你的假设。过去几年中的一个 GNU `tar` 版本在空目录时恢复了错误的权限。

我们在这里并不是在针对 `tar`。类似的问题可能适用于你可能使用的任何工具（包括商业软件包）。测试是确保问题的唯一方法。

## 备份：本地磁带驱动器

假设你在给定系统上安装了磁带驱动器，`tar` 备份的最简单的调用方式只是

```bash
tar c /
```

这假设 `tar` 版本默认在磁带驱动器上创建存档（在某些系统上为 `/dev/rmt`）。然而，这个示例有几个问题。首先，它可能不会默认到安装的相同类型的磁带驱动器，或者根本不会默认到磁带驱动器。在未指定 `f` 参数的情况下，某些版本的 `tar` 将编译到 `stdout`。此外，这将遍历整个文件系统树，包括 `/proc` 文件系统和任何挂载的 CD-ROM、NFS、Samba 或其他共享文件系统。

此示例还有几个潜在问题。通过此命令，GNU `tar` 既不保留稀疏文件中的“空洞”，也不进行任何压缩。

这是一个更好的示例：

```bash
tar c5l2f - $(bakdirs) | buffer -o /dev/sto
```

## 第 12 章 备份

此示例创建了 `(c)` 一个保留文件稀疏性 `(s)`、保持在“本地”文件系统 `(1)`、压缩数据 `(z)` 并将归档写入文件 `(f)` `stdout`（使用 `-` 连字符约定表示）。

然后将此归档文件传递给 McLoughlin 的 `buffer`，它将其写入 `(-)` 第一个 SCSI 磁带设备。每当通过压缩程序或网络备份备份时，都应该使用这种方法。

我们使用首选的命令替换操作符形式引用了 `bakdir` 命令。更常用的反引号 `(()` 更容易输入和阅读——而且它们不能嵌套。这是一个假设的脚本，列出了你想要在备份中的目录和文件；`bakdir` 可以只是一个简单的 `echo` 命令，列出所有本地文件系统的挂载点（包括 `/proc` `/tmp` 目录、CD-ROM 挂载点或 NFS 等网络目录）。基本上，`bakdir` 解析并过滤 `mount` 命令的输出，以动态仅包含所需的内容。

在任何一种情况下，我们都可以使用这些算术技巧使脚本更健壮。
