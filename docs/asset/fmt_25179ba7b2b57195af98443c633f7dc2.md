## 10.9 Socket 层接收

当用户被 open socket 有数据等待时，调用 open socket 的 `receive` 或 `read` 系统调用。这些函数在套接层翻译为 `linux/net/ipv4/tcp.c` 中的 `tcp_recvmsg`。`tcp_recvmsg` 从打开 socket 拷贝数据到用户缓冲区。在内核版本 2.3 中，socket 是锁定的。
