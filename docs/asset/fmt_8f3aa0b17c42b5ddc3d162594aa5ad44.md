要确定触发了什么种事件，你需要检查类型成员`GdkEventType`。`GdkEventType`如下所示：

```
typedef enum
{
    GDK_NOTHING = -1,
    GDK_DELETE = 0,
    GDK_DESTROY = 1,
    GDK_EXPOSE = 2,
    GDK_MOTION_NOTIFY = 3,
    GDK_BUTTON_PRESS = 4,
    GDK_BUTTON_PRESS = 5,
    GDK_BUTTON_PRESS = 6,
    GDK_BUTTON_RELEASE = 7,
    GDK_KEY_PRESS = 8,
    GDK_KEY_RELEASE = 9,
    GDK_ENTER_NOTIFY = 10,
    GDK_LEAVE_NOTIF = 11,
    GDK_FOCUS_CHANGE = 12,
    GDK_CONFIGURE = 13,
    GDK_MAP = 14,
    GDK_PROPERTY_NOTIFY = 16,
    GDK_SELECTION_CLEAR = 17,
    GDK_SELECTION_REQUEST = 18,
    GDK_SELECTION_NOTIFY = 19,
    GDK_PROXIMITY_IN = 20,
    GDK_PROXIMITY_OUT = 21,
    GDK_DRAG_ENTER = 22,
    GDK_DRAG_LEAVE = 23,
    GDK_DRAG_MOTION = 24,
    GDK_DRAG_STATUS = 25,
    GDK_DROP_START = 26,
    GDK_DROP_FINISHED = 27,
    GDK_CLIENT_EVENT = 28,
    GDK_VISIBILITY_NOTIFY = 29,
    GDK_NO_EXPOSE = 30
} GdkEventType;
```

因此，要判断发生的事件是否为键事件，你的代码如下：

```
if ( event->type == GDK_KEY_PRESS )
{
```

所有事件处理程序都有一个布尔值，用于指示你的代码是否处理了该事件。如果你的代码没有表示这是一个事件，那么返回`FALSE`是重要的。如果你处理了该事件，请返回`TRUE`。例如，处理`delete_event`的事件处理程序允许 GTK+ 继续操作。

## GdkEvent 结构

确定触发了什么类型的事件，通过检查`type`成员。关于事件的更多信息可以通过将指针转换为`GdkEvent`获得。处理事件时，需要你的代码将指针转换为特定类型。一旦确定了事件类型，就可以使用`GdkEvent`结构。请查阅 gtk 以了解更多信息。

```
struct GdkEventAny {
    GdkEventType type;
    GtkWindow *window;
    int8 send_event;
}
```

```
struct GdkEventExpose {
    GdkEventType type;
    GtkWindow *window;
    int8 send_event;
    GdkRectangle area;
    int count;
}
```

```
struct GdkEventNoExpose {
    GdkEventType type;
    GtkWindow *window;
    int8 send_event;
}
```

```
typedef enum {
    GDK_NOT_VISIBLE,
    GDK_FULL_VISIBLE
} GdkVisibility;
```

```
struct GdkEventMotion {
    GdkEventType type;
    GtkWindow *window;
    int8 send_event;
    uint32 time;
    double x;
    double y;
    double x_root;
    double y_root;
}
```

```
struct GdkEventButton {
    GdkEventType type;
    GtkWindow *window;
    int8 send_event;
    uint32 time;
    double x;
    double y;
    double x_root;
    double y_root;
    gint button;
    gint state;
}
```

```
struct GdkEventKey {
    GdkEventType type;
    GtkWindow *window;
    int8 send_event;
    uint32 time;
    gint keyval;
    gint length;
    gchar *string;
}
```

```

    double x_root;

    int state;
}
```

## GnomeAppBar

GNOME 应用程序放在窗口底部的栏，用于显示状态、进度、菜单项提示或用于某种响应的最小缓冲区。这在第 11 章中首次描述。

## gnome_app_appbar_new

```c
GtkWidget * gnome_appbar_new ( gboolean has_progress, gboolean has_status
, GnomePreferencesType interactivity );
```

创建一个新的 GNOME 应用程序状态栏。

```c
void gnome_appbar_set_default ( GnomeAppBar * appbar, const gchar * default_status );
```

这设置了没有其他内容时显示的内容。默认为空。换句话说，这规定了当没有向小部件传递应该显示什么的信息时，"AppBar"上显示的是什么。

## gnome_appbar_push

```c
void gnome_appbar_push ( GnomeAppBar * appbar, const gchar * status );
```

将一个新的状态消息推入状态栏栈中并显示它。

## gnome_appbar_pop

```c
void gnome_appbar_pop ( GnomeAppBar * appbar );
```

移除当前的状态消息，并显示之前的状态消息（如果有）。在空栈上调用此函数是安全的。

```c
void gnome_appbar_clear_stack ( GnomeAppBar * appbar );
```
