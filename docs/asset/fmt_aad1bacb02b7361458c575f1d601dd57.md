
一些常见的特殊变量是 `SHELL`、`PATH`、`PS1`、`PS2` 和 `MAIL`。`SHELL` 变量保存你登录的 shell 类型的程序的路径。`PATH` 变量列出了搜索 Linux 命令的不同目录。`PS1` 和 `PS2` 变量持有提示符。`MAIL` 变量保存你的邮箱文件的路径。你可以修改其中任何一个的值来自定义你的 shell。

`PATH` 变量包含一系列由冒号分隔的目录路径。每当执行命令时，都会逐一搜索 `PATH` 变量中列出的路径。例如，`cp` 命令位于系统的 `/usr/bin` 目录。该路径是 `PATH` 变量列出的目录之一。每当你执行 `cp` 命令时，系统都会搜索该路径，`cp` 命令定义了一个初始路径集。由于原因，`PATH` 变量也可以引用你的工作目录；如果你想在工作目录执行自己的脚本或程序，shell 可以找到它。字符串中的路径之间不允许有空格。路径末尾一个未指定路径的单个冒号表示指定工作目录的空条。通常，单个冒号放在路径末尾。例如，路径 `/usr/bin:/usr/sbin:` 引用你当前的工作目录。

```
$ echo $PATH
/usr/bin:usr/sbin:
```

就像 TCSH shell 一样，BASH shell 为了一组预定义的代码，你可以使用它们来配置提示符。通过这些代码，你可以将时间、用户名或目录路径成为提示符的一部分。你甚至可以拥有即将进入的命令的历史事件编号。每个代码前面都有一个反斜杠 `\`。`\w` 表示当前工作目录，`\t` 表示时间，`\u` 表示用户名。`\l` 将显示下一个历史事件编号。在下一个示例中，用户将当前工作目录添加到提示符中：

$ PS1="\w \$ "

$ PS1="\t !-\>"

## 配置你的登录 Shell：.bash_profile

`.bash_profile` 文件是 Bash shell 初始化文件，也可以命名为 `.profile`（如 SU Linux 中）。它是一个每当用户登录时自动执行的脚本。该文件包含 shell 命令，用于定义管理你的 shell 的特殊环境变量。它们可能是系统定义特殊变量的重新定义，也用户定义特殊变量的定义。例如，当登录时，你的 shell 需要知道哪些目录存有 Linux 命令。它将引用 `PATH` 变量来查找这些目录的路径名。然而，首先必须为 `PATH` 变量分配这些路径名。在 `.bash_profile` 文件中，赋值并不因为在 `.bash_profile` 文件中而存在，赋值是在用户登录时自动执行的。

特殊变量还需要使用 `export` 命令进行导出，以便你可能进入的任何 shell 都能访问它们。你可以通过将它们列为参数，在一条 `export` 命令中导出多个变量。通常，在 `.bash_profile` 文件的末尾有一个 `export` 命令，列出了文件中定义的所有变量。如果此列表中缺少某个变量，你可能无法访问它。注意：

在接下一个描述的示例的 `.profile` 文件末尾有 `export` 命令。你也可以将赋值和 `export` 命令合并为一个操作，如下所示 `NNTPSERVER` 所示：

```
export NNTPSERVER=nntp.myservice.com
```

接下来的示例显示了在你账户创建时标准的 `.bash_profile` 文件的副本。注意 `PATH` 是如何赋值的， `$HOME` 的值也是。`PATH` 和 `HOME` 都是系统已经定义的系统变量。`PATH` 持有输入任何命令时搜索的目录路径名，`HOME` 持有家目录的路径名。赋值 `PATH=$PATH:$bin` 将你的 `bin` 目录包含在家目录中。因此你的 `bin` 目录也将用于搜索任何命令，包括你自己创建的，例如脚本或程序。注意 `PATH` 随后被导出并搜索，你可以使用任何文本编辑器修改 `.bash_profile` 文件中的此行改为 `PATH=$PATH:$HOME:$bin`，在末尾添加 `+=$HOME`。事实上，你可以更改此条目以添加你想要的任意目录。
