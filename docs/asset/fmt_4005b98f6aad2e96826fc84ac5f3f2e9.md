要获取特定服务的状态，请执行以下命令，并将 `<service>` 替换为服务的名称：

```bash
-]# systemctl status <service>
```

## 4. 启动和停止 systemd 服务

要停止 systemd 服务，请执行以下命令，并将 `<service>` 替换为服务的名称：

```bash
-]# systemctl stop <service>
```
