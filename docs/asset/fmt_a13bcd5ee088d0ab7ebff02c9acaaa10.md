# GIMP 的功能

GIMP 的各种功能有：

- 提供各种绘画工具，如画刷、铅笔、喷气笔和墨水工具。

## 识别工具箱

图 9-10 显示的 GIMP 窗口也称为工具箱。它由四个主要区域组成：
