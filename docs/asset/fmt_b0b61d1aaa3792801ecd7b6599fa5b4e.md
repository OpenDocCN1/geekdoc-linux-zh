# C++ 注释

在 C++ 中注释涉及使用双斜杠 `//` 或斜杠加星号 `/*`。你已经看到过简短的示例，但这是它的工作原理。

- 步骤1 使用 Hello World 为例，你可以使用双斜杠对代码的不同部分进行注释：

```cpp
// 我的第一个 C++ 程序
cout << "Hello, world!"
helloworld.cpp
#include <iostream>
using namespace std;
int main() {
    // 我的第一个 C++ 程序
    cout << "Hello, world!"
    cout << "And Greetings from C++!"
}
```

- 步骤4 注释时要小心，特别是块注释。很容易忘记添加结束的星号和斜杠，从而抵消注释块内的任何代码。

```cpp
helloworld.cpp
#include <iostream>
using namespace std;
int main() {
    // 第一个 C++ 程序
    cout << "Hello, world!"; // 这行输出单词 'hello, world'
    // 这个注释
    注释行
```
