## 网络编程与套字

本章描述了用于实现底层网络服务器和客户端的模块。Python 提供了广泛的网络层支持，范围从直接使用 `socket` 编程到处理 `HTTP` 等高层应用协议。首先，将对网络编程进行一个非常简短（诚然是有些简略）的介绍。建议读者查阅 W. Richard Stevens 编写的 *UNIX Network Programming, Volume 1: Networking APIs: Sockets and XTI*（Prentice Hall, 1997, ISBN 0-13-490012-X）等书籍以获取许多高级细节。第 22 节“互联网编程”描述了与应用层协议相关的模块。

### 网络编程基础

Python 的网络模块主要支持两种网络协议：`TCP` 和 `UDP`。`TCP` 协议是一种可靠的面向连接的协议，用于在机器之间建立双向通信流。`UDP` 是一种底层的基于包的协议（无连接），机器可以在不建立连接的情况下发送和接收离散的数据包。与 `TCP` 不同，`UDP` 通信是不不可靠的，因此在需要可靠通信的应用程序中管理起来更加复杂。因此，大多数互联网应用程序都使用 `TCP` 连接。

两种网络协议都通过称为 `socket`（套接字）的编程抽象进行处理。`socket` 是类似于文件的对象，允许程序接受传入连接、建立传连接以及发送和接收数据。在两台机器通信之前，它们都必须创建一个 `socket` 对象。

接收连接的机器（服务器）必须将其 `socket` 对象绑定到已知端口。端口是 0-65535 范围内的 16 位数字，由操作系统管理并供客户端用于唯一标识服务器。端口 0-1023 被系统保留并用于常用的网络协议。下表显示了一些常用协议的端口分配（更完整的列表可以在 http://www.iana.org/assignments/port-numbers 查看）：

| 服务 | 端口号 |
|---|---|
| FTP-Data | 20 |
| FTP-Control | 21 |
| SSH | 22 |
| Telnet | 23 |
| SMTP (Mail) | 25 |
| HTTP (WWW) | 80 |
| POP3 | 110 |
| IMAP | 143 |
| HTTPS (Secure WWW) | 443 |

下面的示例说明了使用 `socket` 模块编写的客户端和服务器 `TCP` 协议。在这种情况下，服务器仅将当前时间作为字符串返回给客户端。

```python
# 时间服务器程序
from socket import *
import time
s = socket(AF_INET, SOCK_STREAM)  # 创建一个 TCP socket
s.bind(('', 8888))               # 绑定到端口 8888
s.listen(5)                      # 监听，但允许最多
                                 # 5 个等待的连接。
while True:
    client, addr = s.accept()      # 获取连接
    print("Got a connection from %s" % str(addr))
    timestr = time.ctime(time.time()) + "\r\n"
    client.send(timestr.encode('ascii'))
    client.close()
```

`aschat` 模块通过封装 `asyncore` 模块简化了异步网络编程的实现。`aschat` 的基类继承自 `asyncore.Dispatcher`，提供了以下方法：

- `close_when_done()`：通过向生产者队列推送 `None` 来指示传出流的结束结束。
- `discard_buffers()`：丢弃输入/输出缓冲区和生产者队列中的所有数据。
- `found_terminator()`：当 `set_terminator()` 设置的终止条件成立时调用。此方法必须由用户实现。
- `collect_incoming_data(data)`：当通道上接收数据时，通常会将数据存储起来。
- `get_terminator()`：返回通道的终止符。
- `push(data)`：将数据推送到通道的传出生产者队列。`data` 是包含要发送数据的字符串。
- `push_with_producer(producer)`：将生产者对象 `producer` 推送到生产者队列。`producer` 可以是任何具有简单方法 `more()` 的对象。
- `set_terminator(term)`：设置通道上的条件。如果 `term` 是字符串，每当输入流中出现该字符串时，就会调用 `found_terminator()`。如果 `term` 是整数，它指定了字节数。如果 `term` 是 `None`，则永久收集数据。
- `simple_producer(data, buffer_size)`：创建一个从字节数据产生块的生产者对象。`buffer_size` 指定块的大小，默认为 512。
