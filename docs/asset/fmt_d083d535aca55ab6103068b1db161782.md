
WWW 是客户/服务器范式的另一个例子。你使用 WWW 客户应用程序，即浏览器，来检索和显示存储在服务器上的信息，该服务器可能位于你的本地网络或互联网的任何位置。WWW 客户端可以与许多类型的服务器交互。例如，你可以使用 WWW 客户端联系远程 `FTP` 服务器，并显示其提供的匿名 `FTP` 文件列表。最常见的做法是使用 WWW 客户端联系 WWW 服务器，该服务器支持在本章其余部分描述的万维网特殊功能。

Web 的强大功能源于其使用超文本，这是一种通过遵循交叉引用（称为链接）从一个信息片段导航到另一个信息片段的方式。要有效地使用 Web，你需要运行交互式网络应用程序。第一个用于浏览 Web 的 GUI 是一个名为 `Mosaic` 的工具，于 1993 年 2 月发布。该工具设计于伊利诺伊大学国家超级计算应用中心，其推出引发了万维网用户数量的戏剧性增长。参与伊利诺伊大学 `Mosaic` 项目的马克·安德森（Marc Andreessen）后来与 Silicon Graphics 的创始人吉姆·克拉克（Jim Clark）共同创立了 `Netscape Communications`。这对搭档创建了 `Netscape Navigator`，一个旨在比 `Mosaic` 浏览器性能更好并支持更多功能的 Web 客户端程序。`Netscape Navigator` 取得了巨大成功，并成为探索万维网的首选流行选择。对 Linux 用户重要的是，Netscape 从一开始就提供可在 Linux 上运行的工具版本。此外，Netscape 创建了 `Mozilla`（`mozilla.org`）作为一个开源浏览器项目。

这些浏览器提供 GUI，允许你听声音、观看 Web 事件或实时新闻报道，并显示图片以及文本，使你能够访问超媒体。屏幕上的图片可能是指向更多详细、非语言信息的链接，例如同一图片的高分辨率副本或短动画。如果你的系统能产生音频输出，你可以收听链接到文档的音频片段。

## URL：统一资源定位器

考虑 URL `http://www.w3.org/Consortium/siteindex`。URL 中的第一个组件指示资源类型，在此情况下为 `http`（HTTP——超文本传输协议）。其他有效的资源名称，如 `https`（HTTPS——安全 HTTP）和 `ftp`（FTP——文件传输协议），代表使用其他协议在 Web 上可用的信息。接下来是冒号和双斜杠（`://`）。在印刷中，URL 中的 `http://` 字符串经常被省略，因为你很少需要输入它来访问 URL。下一个元素是作为信息服务器的完整主机名（`www.w3.org/`）。URL 的其余部分是由指向包含信息的文件的路径名（`Consortium/siteindex`）组成的相对路径。如果你在 Web 浏览器的位置栏中输入 URL，Web 服务器将返回该页面，通常是一个由该 URL 指向的 `HTML`（第 1152 页）文件。

按照惯例，许多站点通过在主机或域名名前加 `www` 前缀来识别其 WWW 服务器。例如，你可以通过 `www.njit.edu` 访问新泽西理工学院的 Web 服务器。当你使用浏览器探索万维网时，你可能永远不需要输入 URL。然而，随着更多信息以超文本形式发布，你不可避免地会在各处发现 URL——不仅是在电子邮件消息和 `Usenet` 文章中在线出现，也在报纸、广告和产品标签上。

## 浏览器

`Mozilla`（`www.mozilla.org`）是 `Netscape` 的开源对应物。`Mozilla` 最早于 1998 年 3 月发布，基于 `Netscape 4` 代码。自那时起，`Mozilla` 由 `Netscape`（现为 `AOL` 的一个部门）和其他公司的员工以及社区贡献者持续开发。`Firefox` 是 `Mozilla` 的 Web 浏览器组件。`KDE` 提供 `Konqueror`，这是一个通用的文件管理器和 Web 浏览器。其他浏览器包括 `Epiphany`（`projects.gnome.org/epiphany`）和 `Opera`（`www.opera.com`）。虽然每个 Web 浏览器都是独特的，但它们都允许你在互联网上浏览，查看 `HTML` 文档，收听声音，并检索文件。如果你不使用 X 窗口系统，尝试一个文本浏览器，例如 `lynx` 或 `links`。`lynx` 浏览器在盲文终端上运行良好。

## 搜索引擎

搜索引擎是一个术语，用于描述一组帮助您查找包含特定信息的万维网站点的硬件和软件工具。搜索引擎依赖于由 Web爬虫收集的信息数据库，而Web爬虫是一种定期浏览构成万维网的数百万个页面的程序。搜索引擎还必须有一种方法来收集Web爬虫所收集的信息，以便您可以快速、轻松地访问这些信息，并以对您最有用方式呈现。搜索引擎的这一部分被称为索引，它允许您搜索一个单词、一组单词或一个概念；它会返回与您所搜索内容相关的Web页面的URL。互联网上提供各种不同类型的搜索引擎，每个搜索引擎都有各自的优势和劣势。

### 章节摘要

连接到网络的Linux系统可能正在以太网（`Ethernet`）上进行通信，而以太网可能进一步与其他局域网（`LAN`）和广域网（`WAN`）相连。局域网与广域网之间的通信需要使用网关和路由器。网关将本地数据转换为适合广域网的格式，而路由器则决定数据沿途的最优路由。迄今使用最广泛的网络是互联网。

基本网络工具允许Linux用户登录到远程系统并运行命令（`ssh`、`telnet`），以及快速地在不同系统之间复制文件（`scp`、`ftp`）。许多最初旨在支持单主机计算机通信的工具（例如`finger`和`talk`）后来已被扩展以识别网络地址，从而使不同系统上的用户能够彼此交互。其他功能，如网络文件系统（`NFS`），旨在扩展基本的UNIX模型并简化信息共享。

人们越来越担心我们保护连接到网络的机器以及通过网络传输的数据的安全性和隐私的能力。为此，已创建了许多新的工具和协议：`ssh`、`scp`、`HTTPS`、`IPv6`、防火墙硬件和软件、`VPN`等。这些工具中的许多利用了较新的、更具可实施性的加密技术。此外，一些较弱的概念（如受信任主机）和一些工具（如`finger`和`who`）正在以安全为由被废弃。

计算机网络与其他计算机连接方式相比具有两大主要优势：它们使系统能够以高速通信，且需要较少的物理互连（通常每个系统只需一个，常常是共享电缆）。互联网协议（`IP`），作为互联网的通用语言，使世界各地不同的计算机系统能够轻松地进行通信。技术进步持续改善计算机系统的性能以及连接它们的网络性能。

在互联网上获取信息的一种方式是通过`Usenet`。许多Linux用户经常浏览`Usenet`新闻（`netnews`）以了解其系统可用的最新资源。`Usenet`新闻被组织成涵盖广泛主题的新闻组，包括计算机相关及其他主题。要阅读`Usenet`新闻，您需要能够访问新闻服务器和适当的客户端软件。许多现代电子邮件程序，如`Mozilla`和`Netscape`，都可以显示`netnews`。

近年来网络通信速度的快速增长促进了许多新应用和服务的发展。万维网（World Wide Web）提供了对互联网上庞大信息库的访问，并大量使用超文本链接以促进在相关文档间的高效搜索。它遵循在网络中非常普遍的客户端/服务器模型。通常，WWW客户端位于本地站点或通过互联网服务提供商提供。WWW服务器负责向其众多客户端提供所需信息。

`Mozilla`/`Firefox`是一个具有巨大受欢迎度的WWW客户端程序。`Firefox`和其他浏览器使用图形用户界面（`GUI`）为您提供访问文本、图像和音频信息的能力：大量使用这些超媒体简化了对信息的访问并增强了信息的呈现。

### 以 root 权限运行命令

某些命令可能会损坏文件系统或导致操作系统崩溃。其他命令可能会侵犯用户隐私或降低系统安全性。为了确保 Linux 系统正常运行且安全，Ubuntu 被配置为不允许普通用户执行某些命令和访问特定文件。Linux 提供了多种方式，让受信任的用户执行这些命令并访问这些文件。拥有这些系统级权限的受信任用户的默认用户名是 `root`；拥有这些权限的用户有时也被称为*超级用户*。正如本节所述，Ubuntu 允许指定的普通用户在自己登录身份下以 `root` 权限运行命令。

以 `root` 权限运行的用户具有以下权力——以及更多：

- 某些命令，如添加新用户、分区硬盘和更改系统配置的命令，只能由具有 `root` 权限的用户执行。该用户可以配置工具，如 `sudo`，以授予特定用户执行通常保留给 `root` 权限用户任务的权利。
- 读取、写入和执行文件访问权限以及目录访问权限不影响具有 `root` 权限的用户。具有 `root` 权限的用户可以读取、写入和执行所有文件，并检查和操作所有目录。
- 某些内置于一些命令中的限制和安全措施不适用于具有 `root` 权限的用户。例如，具有 `root` 权限的用户可以在不知道旧密码的情况下更改任何用户的密码。

### 控制台安全

Ubuntu Linux 对拥有计算机物理访问权限的人员并不安全。额外的安全措施，如设置引导加载程序和 `BIOS` 密码，可以帮助保护计算机。然而，如果有人拥有对硬件的物理访问权限（系统控制台用户通常如此），则很难从该用户那里保护系统。

### 最小权限

当您在任何计算机系统上工作时，特别是当您作为系统管理员（拥有 `root` 权限）工作时，请在使用尽可能小的权限的情况下执行任何任务。当您能以普通用户身份登录执行任务时，请这样做。当您必须以 `root` 权限运行命令时，尽可能多地以普通用户身份操作，使用 `sudo` 获得 `root` 权限，完成必须以 `root` 权限执行的任务部分，并尽快恢复为普通用户。因为您在匆忙时更有可能犯错，所以在应用此概念时，时间越少，其重要性就越高。

当您在命令行环境中以 `root` 权限运行时，按照惯例，Shell 会显示特殊的提示符以提醒您当前的状态。默认情况下，此提示符为（或以）井号 (#) 结尾。您可以通过多种方式获得或授予 `root` 权限：

- 当您以恢复模式启动系统（第 445 页）时，您将以名为 `root` 的用户身份登录。
- `sudo` 工具允许指定用户在以自身身份登录时，以 `root` 权限运行选定命令。您可以设置 `sudo`，允许特定用户执行需要 `root` 权限的特定任务，而不授予他们系统级的 `root` 权限。有关 `sudo` 的更多信息，请参见第 421 页。
- 某些程序在启动时会询问*您*的密码。如果 `sudo` 已配置为授予您 `root` 权限，当您提供密码时，程序将以 `root` 权限运行。当程序在启动时请求密码时，当您停止使用程序时，您就停止了以特权用户身份运行。这种设置可防止在您不需要或没有意图时，保持以 `root` 权限登录。
