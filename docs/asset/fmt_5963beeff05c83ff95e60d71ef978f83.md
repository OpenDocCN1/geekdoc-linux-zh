反转运算符 `!=` 和 `<=`（例如 `!=`）是语法错误。

缩进 `if` 语句的主体使其突出并增强程序的可读性。

> **良好的编程实践 2.16**
>
> 程序中每行只放置一个语句。这种格式可以增强程序的可读性。

注意，每个 `if` 语句的第一行末尾没有分号（`;`）。这种分号会在执行执行时导致逻辑错误。例如：

```java
if ( number1 == number2 ); // 逻辑错误
System.out.printf("%d = %d\n", number1, number2 );
```

这实际上会被 Java 解析为：

```java
if ( number1 == number2 )
    // 空语句
```

```java
System.out.printf("%d == %d\n", number1, number2 );
```

其中条件后的分号——称为空语句——是条件为真时执行的 `if` 语句。输出语句不是它的一部分。
