
# 工业微生物学

细菌反应已用于在金属提取之前改变金属。利用微生物将金属转化为可溶形式的操作过程与通常在废物堆场上运行的过程相比，可以提高提取率。生物化学在矿业中的大规模商业应用限于铜和银，增强了从矿石中回收金属价值。细菌被用于积累或分离金属。这种被称为生物富集的过程通常涉及细菌吸收金属离子，然后进行收获和转化。

工业微生物学最可见的产品是用于人类健康的治疗药物。微生物合成是大多数具有复杂结构的健康药物的首选生产方法。微生物具有产生新抗生素（药物中最大的类别）以及天然存在于人体但通过微生物发酵大规模生产的蛋白质和多肽的非凡能力。

参见 另：抗生素。

微生物活动长期以来用于污水处理、工业和废水处理。原生细菌被用于降解石油产品、氯代烃和有毒生物固体。

工业微生物学最古老、最成熟的领域之一是食品和饮料，特别是啤酒和酿酒母的生产。食品行业使用许多通过发酵产生的微生物。特别是在欧洲，通常含有产生蛋白质的微生物（蛋白质）。在食品行业中，酶将葡萄糖转化为葡萄酸。

参见 另：废物处理；饲养；食品制造。

食品饮料和饮料品的生产也是工业微生物学的应用。现在，矿产回收、环境保护以及食品农业领域正在使用此类方法。

# 惰性气体

`惰性气体`表中列出的惰性气体属于元素周期表的第 18 族。它们是广为人知的稀性气体，是 x 的稳定化合物。稀性气体均为单原子分子。

# 惰性腹泻

`惰性腹泻`腹泻及其并发症是发展中国家最主要的死亡原因。该疾病的原因从完全饮食到到强度不等。最具传染性的病因是急性性的，特别是贾毛虫（引起腹泻）和沙门菌菌（托儿所爆发的常见原因）的出现。母乳喂减少了腹泻的发生，是预防发展中国家婴儿腹泻的主要手段。

# 呼吸窘迫综合征

`呼吸窘迫综合征`常见疾病（早产），由呼吸困难引起（呼吸加快、肋骨费力、呼气时呻吟或哮鸣，通常需要氧气，且特征性的胸 X 光显示由于通气不良导致肺部弥漫性模糊）。它是婴儿在新生重症监护室需要长期治疗的主要结果。呼吸窘迫综合征的发生率随早产周周的增加以及由于糖尿病的发生而增加。

预防和给药通用治疗减少了出生前婴儿呼吸窘迫综合征的发生。早产风险是降低呼吸窘迫综合征发生率的成熟疗法的公认风险；这种治疗涉及婴儿的类固醇管理。

# 惯性

`惯性`物质对物体运动的任何变化产生抵抗的性质。当没有力作用时，物体保持静止或保持直线运动状态，除非有新的力作用（牛顿第一运动定律）。物体的质量是其惯性的量。

# 惰性焊接

`惰性焊接`一种用于高速连接不同金属的焊接工艺。因此，它是一种制造高质量连接的极高速工艺。异种材料的连接为组件设计提供了进一步的灵活性。汽车和卡车行业是其用户。惰性焊接也用于航空航天工业。

# 梗死

`梗死`急性组织损伤的原因。该问题由血栓形成、栓塞或严重的动脉粥硬化引起。梗死取决于侧支循环。如果血供被阻塞，或者该血管是该区域唯一的血液来源，就会导致梗死。梗死常见于肺、心（见间性疾病）。心脏的常见原因包括脾和肾。冠状动脉也可以导致血栓形成。
