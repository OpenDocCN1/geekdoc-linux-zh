# 安装

## 快速安装

在理想情况下，只需点击几次即可在您的计算机上安装 SUSE LINUX。如果您的计算机之前没有安装过 Linux 系统，将进行分区、选择软件选择并自动配置硬件。如果您不喜欢系统助手 YaST（Yet another Tool）的建议，请按照第 11 页所示进行手动单独安装。

## 1.1 第一步：启动屏幕

启动计算机及所有连接的硬件组件，并立即将 CD 1 或 DVD 插入相应的驱动器。在启动屏幕上，选择安装模式或启动已安装的系统。安装成功后，只需偶尔插入 CD 以安装额外软件。安装过程中可能会忘记 CD，因此预选择了启动已安装的系统。

> 如果计算机未从 CD 或 DVD 启动，请阅读第 13 页的第 2 节。

## 1.2 第二步：接受建议

从 CD 或 DVD 启动后，启动 SUSE 系统助手 YaST。首先选择系统语言。语言设置将应用于键盘布局。然后 YaST 将检查您的系统。如果您的计算机之前已安装过 SUSE LINUX，下一个对话将询问您是从头安装 SUSE LINUX 还是更新之前的系统。

- 分区：建议一个合适的分区。如果硬盘上存在 Windows 9x 或 ME（FAT32 文件系统），将显示调整比例。
- 软件 A：预设了带有办公应用程序的默认系统。
- 启动：确定 SUSE LINUX 安装引导加载程序的位置。默认设置为第一块硬盘的主引导记录 (MBR)。
- 时区：根据所选的语言设置，将选择相应国家的时区。请检查此设置，因为许多语言在多个国家使用。
- 语言：显示语言设置。

可以随时点击相应的标题来修改 YaST 建议。显示的对话框允许进行详细设置。具体步骤请参阅第 2 章第 11 页。更改后，您将返回到概述界面，并可以点击“接受”使用修改后的值继续安装。

> 警告
> 如果硬件检测正确，则您不需要更改任何内容。除非您清楚自己在做什么，否则请勿更改引导加载程序、分区或硬件设置。

### 1.3 第三步：安装

在开始安装之前，YaST 会在一个绿色窗口中询问是否按照当前设置进行安装。确认“是”以开始安装。根据您的计算机性能，安装带有大量应用程序包的系统大约需要十五分钟。

### 1.4 配置

安装完成后，在开始使用 SUSE LINUX 之前进行一些重要设置（详细说明请参阅第 34 页第 2.6 节）。

首先，为系统管理员（用户 `root`）设置密码。此特殊用户由 YaST 配置，用于系统维护任务。

> 警告
> 请记住 root密码，因为您可以使用 `root` 身份修改系统或安装程序。

> 警告
> 如果在安装过程中发现网卡或其他通信硬件（如调制解调器或 ISDN 卡），现在可以对其进行配置，并与互联网或局域网（LAN）连接。这允许在过程的剩余部分使用各种服务。

例如，如果您配置了 Internet 连接，可以立即进行在线更新。通过这种方式，可以包含系统的最新更新。

## 自定义安装

上一章介绍了快速安装程序。本章提供了详细信息，说明您可以通过从建议窗口启动相关模块来修改的设置。这提供了对安装的完全控制。

### 2.1 从 CD-ROM 启动系统

将第一张 SUSE LINUX CD 或 DVD 插入驱动器。然后重启计算机，以从驱动器中的介质启动安装程序。

#### 2.1.1 从 CD/DVD 启动时可能的问题

如果您在从 CD 1 启动时遇到问题，可能是以下项目之一引起的。请按照描述解决问题。

- CD-ROM 驱动器无法读取第一张 CD 上的引导镜像。在这种情况下，使用 CD 2 启动系统。CD 2 包含传统的 2.88 MB 引导镜像，即使是较旧的驱动器也能读取。
- BIOS（基本输入输出系统）中的启动顺序错误。BIOS 是用于激活计算机基础功能的软件。主板厂商提供适配于硬件的 BIOS。有关更改 BIOS 设置的信息请参阅相关文档。

通常，在启动时的特定时间可以访问 BIOS 设置。在这一初始化阶段，计算机会执行若干诊断测试。按 `Del`、`F1` 或 `Esc` 键进入 BIOS 设置界面。在 AWARD BIOS 中，查找“BOOT SEQUENCE”项。其他制造商对其有不同的名称，如“ADVANCED CMOS SETUP”。找到该项后，按回车键确认。

启动顺序通常设置为 C, A 或类似。在前一种情况下，计算机首先搜索硬盘 (C)，然后是软盘 (A)。通过按 `Page up` 或 `Page down` 将其改为 A, CDROM, C。按 Esc 退出 BIOS 设置界面。要保存更改，选择“SAVE & EXIT SETUP”或按 F10。确认要保存设置时按 Y。
