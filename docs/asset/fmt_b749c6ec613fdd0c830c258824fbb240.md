# SSH：安全外壳 (SECURE SHELL)

## 什么是 SSH？

SSH 是一种用于安全服务的加密网络协议

## 用途

- 它用于远程登录
- 安全文件传输 (SFTP/SCP)
- 用于通过加密代理进行浏览的 SOCKS 协议
- 通过 SSHFS 进行安全远程挂载

## 什么是短语（Passphrase）？

有时你会使用 SSH 连接，有时又不会。例如，你可以创建一个 cron 任务（定时任务）自动连接到服务器进行数据备份。当你仅手动使用 SSH 时，使用短语是一个好主意。但对于自动化任务，你不应该使用它，因为没有人会输入短语。当你使用脚本自动连接到服务器时，请使用任何短语。
