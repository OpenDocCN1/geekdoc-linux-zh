以下示例显示了一个涉及末尾空格和保留字的问题。如果你输入以下命令：

```
$ alias foo="/bin/ls "

$ alias while="/ "
```

那么执行以下命令的结果将是无休止的 Hello, World 字符串序列。

```
$ while true
> do
> echo "Hello, World"
> done
```

然而，如果你输入以下命令，结果是 `/` 目录的 `ls` 列出：
`$ alias foo`

由于 `foo` 的别名替换以空格字符结束，系统会检查下一个单词是否也需要别名替换。下一个单词 `while` 也被设置了别名，因此也会被替换。由于它不在命令词的正确位置，因此不会被识别为保留字。

如果你输入

```
$ foo; while
```

此时 `while` 保留了其正常的保留字属性。

## 波浪号替换 (Tilde Substitution)

在执行别名替换后，每个单词都会被检查是否以未加引号的波浪号 (`~`) 开头。如果是，则检查直到 `/` 之前的单词是否匹配用户名。如果找到匹配，并将 `~` 和匹配的登录名替换为匹配用户的登录目录。此操作称为波浪号替换。如果没有找到匹配，则保持原始文本不变。`+` 或 `-` 分别替换为 `$PWD` 和 `$OLDPWD`。此外，当变量赋值的值以 `-` 开头也会尝试波浪号替换。

## 作业控制 (Job Control)

作业控制允许你将执行中的命令移动到前台或后台，并根据需要停止、暂停或重启它们。前台始终有一个作业，即接受你键盘输入的作业。前台作业可以是 `shell` 或另一个接受键盘输入的命令（如编辑器）。

当你执行一条命令行或在前台启动一个作业时，终端的输入会被阻塞，在 `true` 作业完成之前，你无法输入额外的命令。你可以使用 `job` 命令将该作业推入后台。同样，你可以将后台作业带回前台，以便你控制它或从终端窗口输入数据。作业控制允许你在当前层级或窗口内执行这些操作。

当监控器设置（`monitor set`）开启时，交互式 `shell` 会将每个作业与每个管道关联。你在终端输入的每个命令或管道都会被分配一个数字作业 ID（`job-id`）。`shell` 会跟踪当前和之前的作业。当前作业是最近启动或重启的作业。上一个作业是第一个非当前作业。

当使用 `&` 异步启动作业时，`shell` 会打印一行类似于 `[1] 567` 的内容，表示异步启动的作业是作业号 1，并且有一个（顶层）进程 ID 为 567。所有作业都处于以下状态之一：

- 前台作业对控制终端具有读写权限。
- 后台作业被拒绝读取权限，并对控制终端具有有条件的写入权限（参见 `stty(1)`）。
