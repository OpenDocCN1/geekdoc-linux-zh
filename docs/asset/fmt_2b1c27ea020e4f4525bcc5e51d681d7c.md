得益于 Matt Dew 的努力，本文档以 HTML 和 PDF 等现代格式提供给您。他将原始的 troff 源代码转换为了 DocBook/XML，并对其进行了润色和编辑；此外还有 Gaetan Nadon 和 Alan Coopersmith，他们在 libX11 构建中设置了格式化机制，并对 DocBook 标记进行了进一步编辑。

X 窗口系统是一个在 MIT 设计的网络透明型窗口系统。X 显示服务器运行在具有单色或彩色位图（Bitmap）硬件的计算机上。服务器负责分发用户输入，并接受来自同一台机器或网络其他地方各种客户端程序的输出请求。Xlib 是一个 C 语言子程序库，应用程序（客户端）通过流式连接与窗口系统进行交互。虽然客户端通常运行与其通信的 X 服务器在同一台机器上，但情况并非总是如此。

《Xlib – C 语言接口》是底层 C 语言接口的参考指南。它既不是编程 X 窗口系统的教程，也不是用户指南。相反，它提供了该库中每个函数的详细描述，并对背景信息进行了讨论。《Xlib – C 语言接口》假设读者对图形窗口系统和 C 语言编程有基本的理解。其他高级别的抽象（例如由工具包提供的抽象）是构建在 X 库之上的。关于这些高级别库的更多信息，请参阅相应的工具包文档。X 窗口系统协议提供了 X 行为的权威定义。尽管这里包含了额外信息，但协议文件具有判定依据。
