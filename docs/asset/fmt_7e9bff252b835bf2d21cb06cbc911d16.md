
虽然 IDE 确实简化了 PC 领域，但带有无法处理 540M 以上磁盘的限制。人们想出了许多技巧来规避这一点，但干净的解决方案随处可见。被称为 IDE（增强 IDE），它能够支持高达 8GB 的磁盘，并在一个通道上支持最多 4 个设备。

在 PC 环境中权衡 IDE 与 SCSI 的成本时，不要忘记考虑效益比。在单人工作站中使用一个大型 SCSI 控制器可能并不像用户认为的那么必要，随着磁盘以 2GB 以上的配置发布，典型的 IDE 磁盘上有充足的空间。

一旦你决定了要安装的磁盘子系统，请阅读随机器提供的文档，获取将磁盘连接到系统的说明。

## 什么是分区？我为什么需要它们？

分区是 UNIX 将磁盘划分为可用部分的方法。UNIX 要求至少有一个分区；你经常发现创建多个具有特定功能的分区通常是必要的。

创建分区的最实际的理由是保护系统免受用户的影响。前面提到的那个强制分区被称为根分区（`root partition`）。这里的关键软件和配置文件（内核和表）必须经过仔细监控，以确保它们永远不会溢出。如果它满了，在系统崩溃时你的系统可能无法启动。因为根分区不是用于存储用户数据的，你必须为用户家目录、临时文件等创建单独的分区。这允许他们的文件增长而不必担心挤掉关键系统文件。

双启动配置是分区的另一个常见原因，特别是随着 Linux 日益流行。你可能会发现用户希望能够启动 Windows 或 Linux；因此，你需要保留至少两个分区以便他们实现这一点。

最后，但同样重要的，分区磁盘的理由是备份问题。备份软件通过将整个分区备份到磁带上工作。通过将不同类型的数据保留在单独的分区上，你可以轻松控制哪些需要备份，哪些不需要。例如，没有必要每天备份系统软件，通过保留单独的分区，你可以控制哪些需要备份，哪些不需要。

## 应该创建哪些分区

如前所述，创建分区的目的是分离数据。以下是你可能创建的一些常见分区：

- `root` (`/`)：这是强制性分区。它包含操作系统和基本文件。
- `/home`：这里是存储用户数据的地方。将其保留在单独的分区上允许你备份用户数据而不必备份整个系统。
- `/var`：此分区存放大小不断增长的文件，如日志、邮件池和数据库。
- `/tmp`：这用于临时文件。
- `swap`：这不是一个文件系统，而是磁盘上作为虚拟内存使用的区域。
- `/boot`：此分区包含启动系统所需的引导程序和内核。

根分区和交换分区应该有自己的空间。这使你能够更有效地管理所有空间。

## 设备条目

大多数 UNIX 实现会在连接新驱动器并启动时自动创建正确的设备条目。一旦创建了该条目，你就可以检查其权限。只有 `root` 应该具有读写权限。如果你的备份程序是 `root` 用户，你可能需要赋予备份组组权限。确保没有其他人属于备份组。

Linux IDE 下的设备条目使用以下方案命名硬盘：

```
/dev/hd[drive][partition]
```

每个 IDE 驱动器都从 `a` 开始字母。第一条链上的主盘是 `a`；第一条链上的从盘是 `b`；第二条链上的主盘是 `c`；以此此类推。每个磁盘的分区通过数字引用。例如，第一条链驱动器的第三个分区是 `/dev/hdb3`。

SCSI 磁盘使用相同的方案，只是使用的前缀不是 `/dev/hd` 而是 `/dev/sd`。要引用 SCSI 链上第一个磁盘的第二个分区，你将使用 `/dev/sda2`。若要引用整个磁盘，请指定所有信息。例如，要引用第一个 IDE 上的主盘，将使用 `/dev/hda`。

IRIX 磁盘下的设备项在 `/dev/dsk` 或 `/dev/rdsk` 目录下引用。格式如下：

```
/dev/CsdP
```

其中 `C` 是控制器，`S` 是 SCSI 地址，`P` 是分区号（`s0`, `s1`, `s2` 等）。分区名称可以是 `vh`（表示卷）或直接引用整个磁盘。

Solaris 磁盘下的设备项在 `/dev/dsk` 或 `/dev/rdsk` 目录下引用。格式如下：

```
/dev/Cs0P
```

其中 `C` 是控制器，`S` 是 SCSI 地址，`P` 是分区号。分区 1 通常用于交换分区（`swap`）。

SunOS 磁盘下的设备项在 `/dev` 目录下引用。格式如下：

```
/dev/sdTP
```

其中 `T` 是目标数，`P` 是分区。通常，根分区是 `a`，交换分区是 `b`，整个磁盘被称为 `c`。你可以拥有从 `a` 到 `f` 的分区。单元编号的一个重要方面是：设备通常需要被命名为零。

## 关于磁盘格式化的说明

在过去，磁盘需要进行格式化并检查坏道。该过程是在磁盘的每个扇区的导言（`preamble`）中写入磁头号、磁道和扇区号。同时，任何由于磁盘表面缺陷而无法使用的扇区会被标记，并根据磁盘类型将备用扇映射到该位置。

SCSI 和 IDE 磁盘现在从出厂起就经过了格式化。更好的是，它们可以在不需要操作系统帮助的情况下，透明地处理磁盘上的坏道。

警告：你**绝对不要**尝试对 IDE 进行低格式化（`low format`）。这样做会迅速让你自己的驱动器报废。请做好随时可能需要对其进行低格式化的心理准备。

## 分区磁盘与创建文件系统

在本节中，我们将逐步介绍在 Linux、IRIX、SunOS 和 Solaris 下进行磁盘分区的步骤。由于所有平台的原理相似，每个平台还将涵盖如何根据预期用途确定如何对磁盘进行分区的方法。

为了演示如何在 Linux 下创建分区，我们将设置一个带有单用户的磁盘。它不仅为系统软件提供空间，还为应用程序和用户目录提供空间。例如，我们将在位于 `/dev/hda` 的 1.6 GB IDE 磁盘上创建分区。我们将创建 `boot`、`/usr`、`/var`、`/home` 和 `swap` 分区。在实际的分区过程中，我们不为分区命名。分区挂载的位置在 `/etc/stab` 中指定。我们稍后选择将它们挂载到不同的位置，在保持每个分区功能的同时，我们能更好地判断如何分配它们的大小。

## 在 Linux 中创建文件系统

创建分区本身通常没有用处。为了使用它，我们需要在其之上创建一个文件系统。在 Linux 下，我们使用 `mk2fs` 命令和 `mkswap` 命令。

要创建文件系统，请使用以下命令：

```
mk2fs /dev/hda1
```

对所有分区（交换分区外）执行此操作。

要创建交换分区的文件系统，你需要如下使用 `mkswap` 命令：

```
mkswap /dev/hda2
```

将 `/dev/hda2` 替换为你选择的作为交换空间的分区。

该命令的结果将类似于：

```

```

交换空间已就绪。

要使根文件系统变得可启动，你需要安装 `lilo` 引导管理器。这是所有标准 Linux 发行版的一部分，因此你不需要在互联网上寻找它。

只需修改 `/etc/lilo.conf` 文件，将 `/dev/hda1` 设置为启动磁盘，然后运行：

```
lilo
```

结果输出应该看起来像这样：

```
Added linux *
```

其中 `linux` 是要启动的内核名称，由 `/etc/lilo.conf` 中的 `name-field` 字段指定。

## SunOS

在本例中，我们将准备一个希捷 ST32550N 磁盘作为现有系统的辅助磁盘。该磁盘将被分为三个分区：一个用作邮件邮件池（`mail spool`），一个用作 `/usr/local`，第三个作为额外的交换分区。

## 创建分区

> **注意**：SunOS 和 Solaris 的磁盘格式化步骤不相同。请阅读每个章节以注意差异。

一旦磁盘连接到机器，你应该通过从 PROM 监视器运行 `probe-scsi` 命令来验证其连接和 SCSI 地址（如果磁盘是连接到内部通道），或者运行 `probe-scsi-all` 命令查看系统上所有的 SCSI 设备。当你确定驱动器已正确连接后，在机器启动后运行 `dmesg` 命令收集系统信息。你可能希望将输出通过管道传给 `grep` 以找到磁盘的任何信息。例如：

```
dmesg | grep sd
```

此系统生成了以下输出：

```
sd0: <SUN0 cyl 125 alt 36> esp0 target lun 0
sdl: corrupt label wrong magic number
sdl: Vendor 'SEAGATE', product 'ST32550N', 41945 byte blocks
root on fda type 4
swap on sd0 ftype size 32K
dump on sd0 ftype size 32K
```

这告诉我们发现了一个磁盘。来自 `sdl` 的信息告诉我们发现了磁盘，但由于标签损坏（`corrupt label`）而无法使用。在格式化磁盘并在上面创建分区之前，系统不知道如何处理它，因此报错。如果你使用的是 SCSI 地址 0 或 3，请记住设备 0 需要引用为 3，设备 3 需要引用为 0。即使我们实际上还没有格式化磁盘，我们需要使用 SunOS 自带的 `format` 程序因为它还会创建分区并向磁盘写入标签。要调用 `format` 程序，只需运行：

```
format sdl
```

其中 `sdl` 是我们要分区的磁盘名称。`format` 程序显示如下：
