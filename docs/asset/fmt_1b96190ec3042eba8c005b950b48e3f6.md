# 4.16 Digital / DEC

## DEPCA, DE100/1, DE200/1/2, DE210, DE422

状态：已支持，驱动名称：`depca`

`depca` 源文件中包含了如何在一个机器中使用多个网卡的文档。注意 DE422 是基于 EISA 卡的。这些网卡都基于 AMD LANCE 芯片。最多可以使用两块 ISA 卡，因为它们只能设置为 `0x300` 和 `0x200` I/O 地址。如果你打算这样做，请阅读标准内核中的驱动文件 `depca`。此驱动也支持 Alpha CPU，并且用户可以进行各种 `ioctl()`。

## Digital EtherWorks (DE203, DE204, DE205)

状态：已支持，驱动名称：`ewkr3`

这些网卡使用 DEC 的专用芯片，而不是 DE200 等早期网卡使用的 LANCE 芯片。这些网卡支持共享内存或程序化 IO，尽管如果你使用 PIO 模式会损失 50% 的性能。共享内存可以设置为 2KB、32KB 或 64KB，且只有 2 和 32 经过了测试。David 表示性能与 2KB 和 32KB 模式几乎相同。更多信息在驱动文件 `ewkr3.c` 顶部以及 `README.ewkr3` 中。这两个文件都随标准内核分发。此驱动像 `depca` 一样支持 Alpha CPU。标准驱动具有多种有趣的 `ioctl()`，可清除数据统计、读写 EEPROM、更改硬件地址和链接。黑客可以查看源码以获取更多信息。David 还为此卡编写了配置工具（类似于 DOS 程序 NICSETUP.EXE）。可以在 Linux FTP 站的 `/pub/linux/system/Network/management` 目录下找到 `ewkr3tools-X.XX.tar.gz`。

## DE425 EISA, DE434, DE435, DE500

状态：支持，驱动名称：`de4x5`, `tulip`

这些卡基于上述 21040 芯片。DE500 使用 2140 提供 10/100Mbps 连接。请阅读下面的 2140 部分以获取额外信息。该驱动为非 DEC 网卡提供了一些编译选项。详情查看 `README.de4x5`。所有 Digital 网卡都支持自动补丁（由于专利问题，DE500 暂不支持）。

## DEC 21040, 21041, 2114x, Tulip

状态：已支持，驱动名称：`de45x`, `tulip`

DEC 21040 是 Digital 的一种总线主单芯片解决方案，类似于 AMD 的 PCnet 芯片。21040 专为 PCI 总线架构设计。显然这些芯片已不再生产，因为英特尔收购了 DEC 的半导体部门并倾向于自己的芯片。

对于此芯片的网卡你有两种驱动可选：上述的 DE425 驱动和通用的 21040 'tulip' 驱动。

警告：尽管你的网卡可能基于此芯片，驱动可能对你无效。此驱动也支持 Alpha CPU 并支持作为模块加载。用户可以通过 `ioctl()` 调用访问内部结构——请查看 'ew3' 代码和 `de45x.c` 源码获取有关如何操作的信息。

警告：尽管你的网卡可能基于此芯片，驱动可能对你无效。没有保证 `tulip.c` 或 `de45x.c` 能够运行任何 DC214x 网卡。为什么？？你问。因为有一个寄存器，通用寄存器 (`CSR12`)，它 (1) 在 DC2140a 中由每个厂商编程，且方法各不相同；(2) 在 SIA 控制寄存器中。唯一的微小希望是我们可以解码驱动程序设置的 SROM。用非技术术语来说，这意味着如果你不确定带有 DC214x 芯片的未知网卡是否与 tulip 驱动工作，请确保在付款前可以退网卡。

21041 芯片也出现在后期 SMC EtherPower 网卡的 21040 系列中。21140 用于支持 100Base-T，并与 2140 芯片的 Linux 驱动兼容。对于非 DEC 网卡使用 David 的 `de45x` 驱动，请查看该部分。

如果你在使用 tulip 驱动时遇到问题，可以尝试 Donald 网站上的最新版本。
