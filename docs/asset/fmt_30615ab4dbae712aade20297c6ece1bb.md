## 虚拟桌面

现在是时候讨论 Linux 一个独特且方便的特性了：虚拟桌面。与其听我唠叨这些虚拟桌面业务，可能通过亲自尝试来学习是最好的。

在你的 GNOME 面板中，点击 Wanda、OpenOffice Writer 和 Firefox 启动器。你会在当前的桌面工作区中打开三个窗口。现在看底部面板右侧的工作空间切换器。会有四个框，其中左侧的一个（即你当前的工作空间）显示为棕色。点击其他灰色框之一，你所有的窗口都会突然消失。

实际上并没有什么真的消失——你只是在查看一个新的桌面。你的所有窗口仍在当前桌面运行。在第二个桌面上，你可以打开其他内容：前往**应用程序**菜单，选择**办公 ▸ 纸龙**。纸龙游戏将会出现。

你现在两个不同的桌面上都有窗口，并可以在它们之间切换。要这样做，只需回到面板的工作空间切换器并点击第一个灰色框，这将带你回到原始桌面。一旦回到，你所在的框将变为灰色，然后你点击它即可回到游戏桌面。

## 不仅仅是蹼足

### Linux 风格的互联网

![](img/ba6b82aa7869bba748202d57c97336dca_68_0.png)

如今，普通家庭用户花费在冲浪网页和写电子邮件的时间比做任何其他事情都要多。即使你不是一个经常冲浪的人，还有许多其他应用程序它们本身并不是真正的互联网应用程序，但仍然以某种方式利用互联网，例如在将音频 CD 刻录成 MP3 文件时收集歌曲和专辑信息。拥有一台没有连接互联网的电脑，就像买了一辆马赛蒂，却拒绝把它开出车库。

当然，你如何连接到互联网取决于你的硬件和提供商。这个领域有许多可能性，包括高速局域网（LAN）、电缆调制解调器以及电话公司提供的 ADSL 连接。大多数电脑还带有内部 56Kb/s 调制解调器，或者可以连接外部拨号调制解调器以通过普通电话进行较慢的连接。根据你拥有的设备，在系统上进行设置，局域网连接以及任何使用你以太网端口（如电缆调制解调器）的连接应该是轻而易举的；无线连接可能稍微困难一点，而涉及到老式的拨号连接时有时会是一个挑战。在本章中，你将学习如何设置这些连接，并了解一下 Linux 在最常用的互联网应用程序——你的浏览器和电子邮件客户端方面提供哪些功能。

## 设置高速连接

如果你从你的电缆电视公司拥有高速互联网连接，或者你通过办公室的局域网连接到互联网，那么你真的非常幸运了，因为这些设置已经是最容易处理的。大多数情况下，你只需要将以太网线从墙上（如果你使用局域网）或从电缆调制解调器连接到机器上网卡的端口即可。如果你使用无线路由器，那么以太网线将连接到无线路由器的广域网（WAN）端口。之后，一旦你启动机器，你就可以直接使用了，无需任何进一步的设置。如果你愿意，可以打开 Firefox 查看你是否已连接（点击顶部菜单中的 Firefox 启动器，在系统菜单右侧），然后它会启动并尝试导航到一个网站，例如 yahoo.com。如果网站打开了，你就一切大好了。

如果你在上线时遇到问题，并且正尝试通过局域网或电缆调制解调器连接，那么问题很可能是你的网卡不支持 Linux。这相对罕见，但幸运的是，很容易解决（通过更换）。

问题也可能是你的网络或服务提供商没有通过动态主机配置协议（DHCP）自动分配地址。`DHCP` 是你的互联网提供商自动（动态地）为你的系统提供连接互联网所需的配置信息的方法。如果你的提供商没有利用 DHCP，你必须从网络管理员或服务提供商那里获取必要的设置信息，然后手动输入设置。

## 设置不利用 DHCP 的电缆或以太网连接

要输入网络或以太网设置，首先从你的网络管理员或提供商处获取设置，然后执行以下操作：

1. 从**系统**选择**网络**。
2. 系统提示你输入密码，输入它并点击**继续**。
3. 网络窗口将出现，出现时选择**有线连接**。
4. 在设置窗口中，将“自动 (DHCP)”更改为**静态地址**。
5. 图 4-2 所示的三个框将变为激活状态。一旦输入了信息，点击**确定**。
6. 你的系统将尝试连接互联网。一旦连接建立，关闭网络窗口。

笔记本电脑让电脑变成了一种更多功能的工具。有了正确的硬件，你现在可以在任何可以“捕捉波浪”的地方冲浪。无论你是在餐桌旁、后院露台、大学图书馆，还是当地的星巴克或甜甜圈，你现在无需物理连接到任何设备即可上网。幸运的是，在 Ubuntu 中设置无线连接非常简单——与你刚刚在第 50 页的“设置高速连接”中读的内容不同。
