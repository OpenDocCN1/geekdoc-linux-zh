
用户执行了一个组合两个命令的新操作；我们将在第 5 章“IO 重定向、定向与输出”中学习这种实践。

```
steven@home:~ at 0237
warning: commands will be executed using (in order) a) $SHELL
b) login shell c) /bin/sh
at> cd new-programs
at> /configure; make
at> <EOT>
job 2 2001-06-14 02:00
```

`-m` 会在任务完成后向用户发送邮件，或者在任务无法执行时解释原因。`at` 命令在提交任务前会按顺序列出任务，以防止它们同时运行（这会减慢系统速度而不是让系统流畅运行）。为了防止任务同时运行，如果你改变了主意，可以使用 `atm` 命令删除任务。

选择冷门的执行时间是一个好主意，因为系统任务通常在“Cron 和 crontab”时间运行，正如你可以在下一节“Cron 和 crontab”部分看到的那样。例如，任务通常在凌晨1 点运行（例如，系统索引以更新标准数据库），输入时间 `0100` 很容易减慢系统速度，而不是让系统流畅运行。为了防止任务同时运行，你还可以使用 `batch` 命令，它会将进程排队并以平衡的方式将队列中的工作输入系统，防止系统资源使用的激增。更多信息请参见相关页面。

## Cron 和 crontab

系统由 `cron` 守护进程管理。它从用户的 `crontab` 条目中获取哪些程序以及何时应该运行的信息。`root` 用户有权访问所有 `crontab`，每个用户应该只能访问自己的 `crontab`。在某些系统中，某些用户可能无法访问 `crontab`。

在启动时，`crontab` 会搜索 `/var/spool/cron` 以查找与 `/etc/passwd` 中的账户同名的条目，它会搜索 `/etc/cron` 并搜索 `/etc/crontab`，然后每分钟使用这些信息检查是否有任务要做。它以拥有 `crontab` 的用户身份执行命令，并将命令的任何输出发送给所有者。

在使用 Vixie 的系统中，每小时、每天、每周和每月任务保存在 `/etc` 中不同的目录中以便概览，这与标准的 UNIX cron 功能不同，后者所有任务都输入到一个文件中。

Vixie `crontab` 示例：

```
[root@blob /etc]# more crontab
SHELL=/bin/bash
PATH=/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=root
HOME=/
```

```
# run-parts
# 每小时执行的命令
01 * * * root-parts /etc/cron.hourly
# 每天执行的命令
02 4 * * root-parts /etc/cron.daily
# 每周执行的命令
22 4 * * 0 root-parts /etc/cron.weekly
# 每月执行的命令
42 4 1 * * root-parts /etc/cron.monthly
```

## 备选方案

设置了一些变量，之后是调度，每行一个任务，带有时间和日期字段。第一个字段包含分钟（0 到 59），第二个字段是执行的小时（0-23），第三个字段是月份的几天（1-31），月份（1-12），第四个字段是星期几（0-7，0 和 7 都是星期日）。这些字段中的星号代表该字段的可接受范围。允许使用列表：在最后一个文件中从周一到周五（1-5）执行任务，或者在周一、三、五每隔 1、5 天执行任务。

接着是应该运行 `list` 命令中列出的进程的用户。上面的示例来自 Vixie cron 配置，其中 `root` 程序 `run-parts` 以固定的间隔运行，并有相应的目录。在这些目录中，在计划时间执行的实际任务以 shell 脚本的形式存储，这个小脚本每天运行一次，以更新 `locate` 命令使用的数据库：

```
billy@ahost cron.daily]$ cat slocate.cron
!/bin/sh
renice +19 -p $$ /dev/null 2>&1
/usr/updatedbdb -f "*fs,nfs,ncpfs,proc,devpts" -e \ \
"*/var/tmp,/usr/tmp,*afs,*net"
```

用户应该使用 `crontab -e` 命令以安全的方式编辑他们的 `crontab`。这可以防止用户不小心打开其 cron 文件的多个副本。默认编辑器是 `vi`（请参见第 6 章“文本编辑器”，如果你对图形界面感到更舒服，可以使用任何文本编辑器，如 `vim` 或 `gedit`）。

当你退出时，系统会告诉你它已安装。
