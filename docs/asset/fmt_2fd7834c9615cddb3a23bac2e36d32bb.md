# troff

`/Trof/` n. Unix 文本的“幕后核心”（gray eminence）：一种格式化和照字程序，最初编写在 PDP-11 上，然后用结构极其松散的早期 C 语言。由 Late Ossana 命名，源自更早的 ROFF，而 ROFF 被 Jerry Salter 改造了用于 Multics 和 CTSS 的 RUNOFF（该名字源于“expression to run off a copy”）。其配套程序 `roff` 为终端和行打印机格式化输出。1979 年，Brian Kernighan 修改了它，使其能够驱动 Graphic Systems CAT 以外的照字机。他描述该项工作的论文（《A Typesetter-independent troff》，AT&T CSR #897）解释了 `troff` 的耐用性。在讨论了该程序的明显缺陷——对计算机资源利用极不当；在某些领域具有神秘且未记录的属性，以及对资源的贪婪需求——并注意到代码和内部逻辑的丑陋和极度细碎后，Kernigan 得出结论：这些言论都不应被视为对 Ossana TROFF 成就的否定。它证明是一个极其健壮的工具，经受了各种预处理器的不可思议的滥用，并被强制用于原始设计从未设想过的用途，且在压力下始终表现得极有优雅。`TeX` 和桌面出版系统的成功降低了 `troff` 的相对重要性，但这段致意完美捕捉了让 `troff` 在黑客传说中占据一席地的优点；事实上，它可以更通泛地被称为黑客长期以来推崇的程序特质的指示。源自 Jargon Dictionary http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# trojan

一种恶意软件，单词 `trojan` 指的是《伊利亚特》中经典的特洛伊木马。在希腊放弃围攻特洛伊城后，他们留下了一份礼物。礼物包括一匹留放在镇外的大木马。在看到希腊人航行后，他们把马带进了城。马里藏着战士，他们跳出来杀了一批人并打开大门，让已经离去又返回的希腊军队进入了城市。如果你从聊天室甚至从不受自控的邮件中下载了一个程序，那么该程序就带入了某种破坏目的的 `trojan`（程序）。它可能包含病毒、密码窃取器，或者由旨在允许控制你机器的远程木马组成。限制：泛指该词指代任何恶意软件，技术上不是病毒的木马。通常情况下，木马程序不会传播到其他程序。关键点：该词可以作动词用。对程序进行 `trojan` 处理意味着在现有程序中添加主观性。例如，一个被 `trojan` 化的登录程序被设计为接受任何用户账户的密码。Rootkits 经常包含一组 `trojan` 化的命令（如它们自己的目录）。如果你将程序拷贝到 `/tmp` 目录，而其他人执行了 `cd` 进入，那么该用户将用他们自己的权限运行你的程序。这是危险的访问，这就是为什么本地目录不应是搜索路径的一部分。特洛伊木马是一个看起来像游戏或图像文件但执行其他功能的程序。“特洛伊木马”一词源于一个希腊人在公元前 1500 年至 1200 年间使用的可能神话化的战争故事。

### trust（信任）

“trust”一词在信息安全社区中具有巨大的意义。最直接的联系是使用这个词代替“secure”（安全）。关于受信系统（Trusted Systems）的标准取决于你可以在哪里信任系统。这是看待安全性的一种。主要问题在于，如果你在计算机上存储机密信息，你就对该计算机投入了信任。更重要的是，你信任运行该系统的个人/组织。来自 Hacking-linux http://www.tldp.org/LDP/Linux-Dictionary/index.html

### trustees（受托人）

适用于 Linux 的高级权限管理系统。Linux trustees 项目的主要目标是为 Linux 创建一个高级的权限管理系统。事实上，UNIX 权限系统并不适用于许多常见任务。例如，让系统管理员创建一个目录，允许某些组以写模式访问，而其他组仅以读模式访问。目录及其子目录中的文件继承父目录的行为，除非另有说明。通常来说，使用标准（以及 UNIX）安全模型无法实现不同组具有不同读/写和只读权限的情况。这个问题可以通过 `ext2-fs` ACL 项目解决，但问题是无人可以通过或使用特殊脚本从父目录复制权限掩码或 ACL。使用 `trustees`，你只需输入 `[/device]/path+group:REB` 即可解决这个问题。该解决方案的灵感主要源于 Novell Spectre 方法和 Java API。特殊对象（即 `trustees`）可以绑定到每个文件或目录。受托对象（Trustee object）意味着向特定用户或组（或排除特定用户或组）授予（或拒绝）对文件及其子目录的访问权限。该包提供了 `trustee` 实用程序，允许从 `trustee.conf` 新的权限。来自 Debian 3.0 http://www.tldp.org/LDP/Linux-Dictionary/index.html

### Truscus

Trustee Linux 是一个高度重视安全性的服务器在线发行版。Trustee 为 Trustee Linux 的用户提供了几种服务器替代方案。名为 Forecast 的 Trustee Linux 2.0 技术预览版于 2003 年 2 月 18 日发布。Trustees Linux 2.0 release 1 (Thunder) 于 2003 年 6 月 23 日发布。一个“安全的”发行版。来自 LW Distribution List http://www.tldp.org/LDP/Linux-Dictionary/index.html

### TrX

TrX 是一个旨在由 Knoppix 一个基于 GNU/Linux 的桌面路由器和防火墙包的项目。该系统将直接从 CD-ROM 启动，因此不需要安装到硬盘。TRX 的初始 Forecast 版本 3.2 于 2003 年 3 月 1 日发布。一种基于 CD 的发行版。来自 LW Distribution List http://www.tldp.org/LDP/Linux-Dictionary/index.html
