
一种通过加热将化合物转化为一种或多种产物的化学过程。根据这一定义，在催化剂存在下加热发生，或在空气存在下（氧化通常同时发生反应）的反应被排除在外。热解或热反应一词在与热解基本相同的意义上被使用。热解的一个简单例子是加热氧化汞首次制备氧气的经典实验 [反应 (1)]。

```
HgO → Hg + 1/2 O₂
```

类似反应也发生在许多其他金属氧化物和盐中。石灰石（碳酸钙）的热分解或煅烧是生产石灰的基本步骤 [反应 (2)]。

```
CaCO₃ → CaO + CO₂
```

参见`石灰（工业）`。

热解一词最常与有机化合物的热反应联系在一起。植物和动物来源材料的热解提供了一些关于结构组成的最初线索，例如橡胶热分解形成异戊二烯。从煤焦油（煤的热解产物）中获得了一系列物质，包括苯、萘、吡啶和许多其他芳香化合物。所有这些热解过程导致形成特征于来源的挥发性产物以及高碳含量的焦炭残留物。

热解反应已被用作制备方法和生成瞬态中间体的手段，这些中间体可以被捕获或光谱观察，或通过进一步反应淬灭。出于制备目的，热解通常通过流动过程进行，其中反应物通过惰性气流通过加热管汽化，有时在减压下进行。在闪光真空热解中，反应物置于非常低的压力下，待热解材料通过分子蒸馏汽化。参见`化学动力学`。

### 反应类型

在 600–800°C（1100–1500°F）的温度下，大多数有机化合物获得足够的热能以导致键断裂并形成自由基。烷烃发生碳-氢（C-H）和碳-碳（C-C）键断裂，形成两个自由基，然后反应生成低分子量的烷烃、烯烃、氢气以及更高分子量的

由它们复合产生的化合物（反应 (3)）。

$\mathrm{CH}_{3} \mathrm{CH}_{2} \mathrm{CH}_{2} \mathrm{CH}_{3} \stackrel{(1300^{\circ} \mathrm{F})}{\longrightarrow} \mathrm{CH}_{3} \mathrm{CH}_{2}{-} \mathrm{CH}_{3}+\mathrm{H}_{2} \mathrm{C}=\mathrm{CH}_{2}$

(3a)

$\mathrm{CH}_{3} \mathrm{CH}_{2} \mathrm{CH}_{2} \mathrm{CH}_{3} \stackrel{700^{\circ} \mathrm{C} \ (1300^{\circ} \mathrm{F})}{\longrightarrow} \mathrm{CH}_{3} \mathrm{CH}_{2}{-}\mathrm{CH}_{3}+\mathrm{CH}_{3} \mathrm{CH}_{2} \mathrm{CH}=\mathrm{CH}_{2}+\mathrm{H}_{2}$

(3b)

# 火法冶金，有色

许多热反应涉及异构化而不伴随消除或碎片化。这些过程可以通过双自由基等中间体发生，如松节油的热解，或者是协同的周环反应。后者的一个例子是苯基或乙烯基醚以及其他 1,5-二烯体系的 Claisen-Cope 重排。这些反应可以通过相对温和的加热进行，并且在合成中非常有用。参见`有机合成`；`周环反应`。

**分析应用。** 复杂结构的热降解导致来自并发解离、消除和键断裂的非常复杂的产品混合物。分离这些混合物会产生特征性的热解谱图，这在分析方法中很有价值，特别是对于生物来源和合成来源的高分子材料。在此应用中，将小样品在热线丝上或通过激光加热。然后通过气相色谱、质谱或两种技术的组合来分析热解产物。参见`气相色谱`；`质谱`。

已开发出具有适当接口和数据处理系统的仪器，以便快速灵敏地检测热解产物，用于多种应用。一个例子是优化石油裂化条件，以便从各种原油中生产所需产品。聚合物热解碎片的分布也可用于检测杂质。 [J.A.M.J.]

# 火法冶金

提取冶金的一个分支，其中使用高温下的化学反应过程从原料（如矿石和精矿）中提取金属，并处理回收废金属。

对于金属生产，火法冶金操作始于通过采矿及随后的矿物和矿石加工步骤获得的原料以生产精矿，或回收材料，如来自报废汽车、机器或计算机的分离材料。

火法冶金准备过程将原料转化为适合未来加工的形式。还原过程将金属氧化物和化合物还原为金属。氧化过程将进料氧化为中间或半金属产品。精炼过程从粗金属中去除最后残留的杂质。参见`电冶金`；`铁冶金`；`冶金`；`火法冶金，有色`。 [P.J.M.I.]

# 火法冶金，有色

提取冶金的一个分支，其中使用高温下的化学反应过程从矿石、精矿和回收材料中提取和精炼有色金属。

从进料到最终金属的整个过程都可以是火法冶金的，或者火法冶金步骤可以与其他技术结合使用。越来越多地，混合工艺最大限度地提高了整体操作的效率和优势。

火法冶金中的过程通常可分为准备、还原、氧化和金属精炼。对特定原料或金属的处理可能涉及所有这些步骤，或者其中一些步骤可能构成整个处理系统的一部分，该系统可能包括非火法冶金操作。

在准备过程中，精矿或升级矿石或其他进料通过化学反应转化为适合进一步加工的形式。最常见的子过程是干燥和煅烧、热解和水解、焙烧、烧结和氯化。虽然干燥期间实际上没有发生化学反应，但由于它通常是后续高温操作（如熔炼）的一部分，因此包含此子过程。在某些情况下，准备过程是为了生产适合水法冶金处理的材料，如锌精矿的焙烧以生产锌焙砂（基本上是氧化锌中间体），该中间体通过硫酸溶液浸出以生产锌，或是在氧化铝准备过程中的浸出步骤，用于铝熔炼。

还原过程实现金属化合物在金属及其与残渣分离的高温反应，如下反应所示，其中 MX 是金属化合物，R 是反应或还原剂，M 是金属。

$MX + R \rightarrow M + RX$

还原剂和反应条件（温度和压力）以及反应物和产物的浓度被选择以实现快速或自发反应。这些反应通常需要能量输入。

相对于所生产金属的价值，所使用的还原剂数量应较少且廉价，同时产物 RX 应易于从金属中分离。在有色火法冶金中常用的还原剂包括碳（通常作为焦炭）、一氧化碳气体（来自焦炭）、天然气、铁和硅铁（用于镁生产）、铝（用于钙生产）以及镁（用于钛、锆和铪生产）。
