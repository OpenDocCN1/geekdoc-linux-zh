## 启动 Web 服务器

Django 包含内置的 Web 服务器，用于调试和测试 Django 应用程序。让我们看看我们的管理界面是如何工作的……启动 Web 服务器：

```
$ manage.py runserver
```

如果你的代码没有错误，服务器应该在 8000 端口可用。要启动管理界面，请在浏览器中访问 `http://localhost:8000`。将被要求登录。输入用户名和密码。你没有超级用户。你想创建一个吗？(yes/no)

```
$ manage.py createsuperuser
```
