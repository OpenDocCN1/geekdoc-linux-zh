## langdrill

语言训练是一个测试外语词汇的辅助工具。它的 GTK+ 工具包和 VDK（真正的 C++ 封装）看起来与 JavaDrill 相似（JavaDrill 记忆了训练应该像的样子）。包含了对日语字符的有限支持。为了这一点，必须在系统中安装日语文字体。来自 Debian 3.0r0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## language-env

语言环境的简单配置工具。此工具将原生语言环境的基本设置（如 LAN 变量、函数输入、方法等）添加到用户的配置文件（如bashrc 和 .emacs）中。此版本的 language–env 支持白俄罗斯语、保加利亚语、丹麦语、法语、德语、韩语、马其顿语、波兰语、俄语、塞尔维语、泰国语和乌克兰语。日语支持来自软件包‘user-ja’。泰国支持由 Canon Silpa–Anan 编写。德语支持来自 user-de 包。俄语支持由 Peter Novodovsky petya@logic.ru> 支持。白俄罗斯语、马其顿语、塞尔维语和乌克兰语用户由 Anton Zininov <zininov@debian.org> ，白俄罗斯语翻译由 Alexander Mikhail 完成。

# Laonux

Laonux 是一个小型 Linux 发行版，包含了你在 Linux 系统中预期的大部分基础功能，仅此此。它具有 gcc-2.9.5、glibc 2.1 和内核 2.2.14。它并不容易安装，但提供了一个完整的系统。它非常适合从基础内核构建个性化 Linux 的用户。来自 LWN 分发列表

# lapack

线性代数例程库 – PIC LAPACK 版本 3.0 是一个全面的 FORTRAN 库，执行线性代数运算，包括矩阵求逆、方程组的最小二乘解、特征值分析、奇异值分解。非常全面且声誉良好的软件包，在科学界有广泛应用。通常人们会使用非 PIC 代码进行静态链接。在这种情况下，请安装 lapack-dev。lapack 对象在自己的包中。来自 Debian 3.0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# lapack-test

线性代数例程库 – 测试 LAPACK 版本 3.0，这是一个全面的 FORTRAN 库，执行线性代数运算，包括矩阵求逆、方程组的最小二乘解、特征值分析、奇异值分解。这是一个全面且声誉良好的软件包，在科学界有广泛应用。这些测试程序已经在共享库上运行。结果收集在 `test_results` 和 `timing_results` 文件中。单独提供这些程序，以便用户测试和比较由 atlas 提供的其他版本的 lapack 库。来自 Debian 3.0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
