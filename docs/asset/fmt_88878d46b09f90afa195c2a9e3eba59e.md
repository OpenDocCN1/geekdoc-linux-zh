### 指令清单22.3 Optimizing GCC 4.6.3 (IDA)

```
float_rand

STMFD SP!, (R3,LR)
BL      my_rand
; R0=伪随机值
FLDS    S0, =1.0
; S0=1.0
BIC     R3, R0, #0xFF00000
BIC     R3, R3, #0x800000
ORR     R3, R3, #0x3F800000
; R3=伪随机值 & 0x007ffff | 0x3f800000
; 将 R3 拷贝到 FPU (寄存器 S15)。
; 它的行为类似于位拷贝，没有转换：
FMSR    S15, R3
; 减去 1.0并将结果留在 S0:
FSUBS   S0, S15, S0
LDMFD SP!, (R3,PC)
```
