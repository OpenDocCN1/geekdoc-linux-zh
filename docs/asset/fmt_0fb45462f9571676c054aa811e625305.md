## 6.3.10 自增和自减运算符

自增和自减运算符直接取自C语言。自增运算符将变量的值加1，自减运算符将变量的值减1。当与单个变量一起使用时，这些运算符只是传统的加减1方法的快捷方式。然而，如果在赋值语句中使用，或者与其他运算符结合使用，最终结果取决于运算符的位置，见表6.11。考虑以下示例：

```perl
$i = 4;

printf "%d\n", $i++;
```

```perl
printf "%d\n", ++$i;
```

第一个示例是后自增操作；也就是说，`$i`在其值被打印之前不会增加，导致打印4。
现在如果我们把`$i`重置为4并转到第二个示例，`$i`在打印之前预先自增，导致结果为5。

除非您知道预期的结果，否则不要使用这些运算符。例如，以下语句是轻率的，其结果基于`printf`函数内部如何评估其参数：

```perl
$x = 5;

printf "%d %d %d %d\n", $x++, --$x, $x--, ++$x;
```

| 示例 | 描述 | 等价形式 | 结果 |
| :--- | :--- | :--- | :--- |
| 如果 `$y` 为 0 且 `$x` 为 0: `$y = $x++;` | 将 `$x` 的值分配给 `$y`，然后增加 `$x` | `$y = $x; $x = $x + 1;` | `$y` 为 0, `$x` 为 1 |
| 如果 `$y` 为 0 且 `$x` 为 0: `$y = ++$x;` | 增加 `$x`，然后将 `$x` 分配给 `$y` | `$x = $x + 1; $y = $x;` | `$x` 为 1, `$y` 为 1 |
| 如果 `$y` 为 0 且 `$x` 为 0: `$y = $x--;` | 将 `$x` 的值分配给 `$y`，然后减少 `$x` | `$y = $x; $x = $x - 1;` | `$y` 为 0, `$x` 为 -1 |
| 如果 `$y` 为 0 且 `$x` 为 0: `$y = --$x;` | 减少 `$x`，然后将 `$x` 分配给 `$y` | `$x = $x - 1; $y = $x;` | `$x` 为 -1, `$y` 为 -1 |

这些运算符最常见的用法是在循环内。这是一种快速地向值加1或减1的方法。参见示例6.23。

### 示例 6.23

```perl
use warnings; 

my $n = 0; 

# 第 1 行

while ($n < 10) { 

    print "$n "; 

    $n++; 

} 

print "\n\n"; 

# 第 2 行

for (my $i = 20; $i >= 0; $i--) { 

    print "$i"; 

} 

print "\n"; 
```
