### `blacklist` 节示例：
### 名称：`blacklist`
### 范围：`multipath & multipathd`
# 描述：不作为多路径候选的设备列表。
# 设备可以通过其设备名称 "`devnode`",
# 它们的 WWID "`wwid`", 或其设备字符串 "`device`" 来识别。
# 默认：`fd, hd, dm, sc, st, ram, loop, dcsblk`
```
blacklist {
  wwid 2625390002799679
  devnode "[ram|loop|fd|md|dm-][sr|scd|st] [0-9]*"
  devnode "hd[a-z]*"
  devnode "*dcsblk[0-9]*"
  device {
    vendor "DEC"
    product MSA1500
  }
}
```
