## 纺织品印刷

在纺织品印刷中，通过机械手段将染料或颜料块应用于织物上以形成设计。然后将设计转移或传递到织物本身，保持设计的锐利度、完整性、色彩方案以及与其他元素的相对位置。这种设计是纺织品操作中最复杂的类型之一。参阅

设计可以通过几种方式实现：通过烘干将设计转移到平整表面（模板或刻版印花）；以及通过平整板切割设计（纸张或塑料上的丝网或模板印刷）。这些方法涉及手工印刷和转轮印刷机。在现代，这些已通过更换版和滚筒转化为转轮印刷。每种印刷方法都利用颜色并用于在织物上绘制设计。

每种印刷方法都需要特殊的特性。厚度不仅取决于织物的类型，还取决于所使用的印刷机类型，通常取决于使用的水平。大多数水印使用助剂将染料固定在织物和胶上。使用的增稠剂通常是高分子聚合物，能够在较低浓度下实现极高的粘度。

下一个操作是压光，可能类似于染色。在压光之前，设计保持在热水排水槽中。在此过程中，染料吸收大部分水分，通过从其他纤维中吸收水分形成水染浴。张力保持了织物上的设计。

印花通常很容易彻底去除增稠剂、化学品和未固定的染料。洗后物品的干燥是印刷的最后操作。参阅纺织技术。

```

```

```

```
