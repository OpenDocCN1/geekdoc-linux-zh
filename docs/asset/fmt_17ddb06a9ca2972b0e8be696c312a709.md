
`bill = Account("Bill", 10.00)`

在 `__init__` 内部，通过赋值给 `self` 将属性保存到实例中。例如，`self.name` 是实例中的属性。新创建的实例被返回给用户，类的属性如下通过点运算符 (`.`) 访问：

```python
a.deposit(100.00)      # 调用 Account.deposit(a,100.00)

b.withdraw(50.00)         # 调用 Account.withdraw(b,50.00)

name = a.name               # 获取账户名称
```

点运算符 (`.`) 负责属性绑定。当你访问属性时，结果可能来自多个地方。例如，上一个示例中的 `a.deposit` 返回的是 `Account` 类的属性（方法）。当你访问属性时，首先检查实例，如果未找到，搜索将移动到实例的类。这是类将其属性与所有实例共享的底层机制。

## 作用域规则

虽然类定义了命名空间，但类并没有为方法体内使用的名称创建作用域。因此，在实现类时，对属性和方法的引用必须完全限定。例如，在方法中，你始终通过 `self` 引用实例属性。因此，在实例中使用中使用 `self.balance` 而不是 `balance`。如果你想从另一个方法调用一个方法，情况也如此，如下例所示：

```python
class Foo(object):
    def bar(self):
        print("bar")
    def spam(self):
        bar(self)            # 错误！'bar' 会产生 NameError
        self.bar(self)      # 这有效
        Foo.bar(self)       # 这也有效
```

语言缺乏作用域是 Python 与 C++ 或 Java 的不同之处。如果你用过这些语言，Python 中的 `self` 参数等同于 `this` 指针。显式使用 `self` 是必要的，因为 Python 没有提供显式声明变量的方法（类似于 C语言中声明为 `int` 或 `float`）。如果没有这一点，无法知道方法中对变量的赋值是想要作为局部变量，还是想要被保存为实例属性。显式使用 `self` 解决了这个问题——存储在 `self` 上的所有值都是实例的一部分，而其他赋值都是局部变量。

## 继承

继承是一种创建类来特化或修改现有类行为的机制。原始类被称为基类或超类。新类通过派生类或子类创建。当通过继承创建类时，它会继承其基类定义的属性。然而，派生类可以重新定义它的任何属性，并添加自己的新属性。

继承在类语句中通过用逗号分隔的基类列表来指定。如果没有逻辑上的基类，则类将继承自 `object`，正如之前的示例所示。`object` 是所有 Python 对象的根类，并提供了某些常用方法的默认实现，例如 `__str__`，该方法用于创建一个用于打印的字符串。

继承通常被用于重新定义现有方法的行为。例如，这里这里 `Account` 的特化版本重新定义了 `inquiry()` 方法，以便定期更新当前余额，希望用户如果不注意，在支付其抵押贷款贷款时会导致账户被扣款并产生账单。

```python
import random
EvilAccount(Account):
    def inquiry(self):
        if random.random(0.4) == 1:
            return self.balance * 1.10  # 注意：专利申请的想法
        else:
            return self.balance
```

```python
c = EvilAccount("George", 1000.00)
c.deposit(10.0)          # 调用 Account.deposit(c,10.0)
available = c.inquiry()      # 调用 EvilAccount.inquiry(c)
```

在这个示例中，`EvilAccount` 的实例与 `Account` 的实例相同，除了重新定义的 `inquiry()` 方法外。

继承是通过对点 (`.`) 运算符的细微增强实现的。具体来说，如果属性搜索在实例或实例类中没有找到匹配项，搜索将移动到基类。这个过程一直持续，直到没有更多基类可以搜索为止。在之前的示例中，这解释了为什么 `.deposit()` 调用了在 `Account` 类中定义的 `deposit()` 实现。
