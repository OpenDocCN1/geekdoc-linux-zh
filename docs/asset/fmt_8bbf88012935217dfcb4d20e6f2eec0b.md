
# Linux 词典

## w3m

`w3m` 的简单 Emacs 接口包含一个 `w3m` 程序接口，具备 WWW 功能。它可以作为 Emacs 上的轻量级网页浏览器。它也被称为 `emacs-w3m`：http://emacs-w3m.namazu.org/ 源自 Debian 3.0rt0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html

## w3m-img

`w3m` 的行内图像支持工具。`w3m-img` 提供一些工具，用于在 X Window 终端模拟器上的 `w3m` 显示行内图像。源自 Debian 3.0rt0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## w3m SSL

支持 SSL 的 WWW 浏览器 `w3m` 是一个支持 IPv6 的文本网页浏览器。它对表格和帧有很好的支持。
- 也可以作为独立文件使用。
- 你可以跟踪链接或查看 HTML 图像。
- 互联网消息预览模式，你可以浏览 HTML 邮件。
- 如果包含 URL 表单，可以在纯文中跟踪链接。
- `w3m-img` 软件包支持 SSL。
更多信息请参阅：http://sourceforge.net/projects/w3m 源自 Debian 3.0rt0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## w3mir

`w3mir` 是一个通用的 HTTP 复制和镜像工具。`w3mir` 可以创建并维护一个或多个 网站的可视副本。它可以保持镜像文档内部链接的完整性以及镜像外部链接的完整性。源自 Debian 3.0rt0 APT

## wait state

`wait state`（等待状态）：处理器时钟周期内无操作。等待状态被程序到计算机系统的所有组件中，如随机存存储器（RAM），以匹配中央处理器（CPU）。等待状态取决于处理器相对于内存的速度。通过使用快速（突发缓存）内存、接口化内存或静态芯片，可以消除等待状态。源自 QUICK http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## wajig

简化的 Debian 软件包管理框架。它是 `apt`、`apt-cache`、`dpkg`、`etc/init` 脚本的封装器，用于提供其所有功能的文档。在合适的 `sudo(1)` 配置下，所有的安装（以及任务）都可以从 shell 完成。

## wall

向用户写入消息。源自 https://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### wall time

`n.`（也称为 `wall clock time`）1. 真实世界时间（墙上时钟显示的时间），与系统时钟的概念相反。2. 程序的实际运行时间，与执行程序所需的时钟周期（ticks）相反（在分时系统中，这两者总是不同的，因为没有程序能获得时钟周期；而在支持线程的多处理器系统中，程序获取的处理器时间可能超过实际时间）。来自 Jargon Dictionary http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### wall art

`a` 一种带有集成公头插座的小号电源盒，设计用于直接插入插座；当安装在电源线上时称为 `wall art`，它会占用比其使用的至少一个额外的插座。这些通常与调制解器和其他电子设备相关，如果这些设备带有板载电源，就会变得笨大到无法接受（此外还有其他原因，与 UL 认证成本有关）。来自 Jargon Dictionary http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### wallp

基于 GTK+ 和 Imlib，通过更新 X WallP 的根，任何由 Imlib 渲染的图像格式都可以与 Wallp 配合。用户控制更改间隔，单位为分钟。使用 GTK+ 作为工具包。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### wallpaper

1. 一个包含列表（例如汇装列表）或转录文件的文件，特别是包含登录会话全部或部分的文件。（其想法是，此类列表的解析器本质上非常适合做壁纸，在斯坦福大学，那里曾用它来覆盖屏幕。）现在已很罕见，因为其他系统已经为此开发了其他工具（例如 PHOTO ON TWENEX）。然而，Unix 世界还没有同等术语，所以也许 wallpaper 在那里会保留。该术语可能源于 ITS，那里的命令和结束转录文件分别是 `:WALBEG` 和 `:WALEND`。2. 图形工作站上使用的背景图案（这是 MS-DOS 下 'Windows' 图形界面的底层技术规范）。3. `wallpaper` 文件——在实际打印到屏幕之前包含壁纸信息的文件。（如果你打算制作该文件的真实纸质副本，它仍被称为 wallpaper 文件）。来自 Jargon Dictionary http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## wanpipe

## Warewolf

`Warewolf` 是一个用于集群节点的字典。它为所有节点提供了中心化管理模型，以及构建配置文件、监控和控制节点所需的工具。它是完全可定制的，可以调整适用于任何类型的集群。节点分布从主节点上的虚拟节点系统构建，通过以太网或 CDROM 镜像传输到节点。管理具有扩展性且易于操作。它最初为 Bewulf 设计，也可以用于其他环境。初始版本 0.3 于 2003 年 3 月 15 日发布。
