## 设置这些路由

`route - show` 命令操作内核的 IP 路由表。它的主要用途是通过 `ifconfig` (`$8`) 程序配置接口后，为特定的主机或网络设置静态路由。

```
route [-CFVnee]
route [-v] [-A family] add [-net-host] target [netmask Nm] [gw Gw] [metric M] [mss M] [window W] [irtt J] [reject] [mod] [dyn] [reinstate] [dev] If
```
