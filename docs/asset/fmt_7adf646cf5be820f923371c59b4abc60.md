如你通过这两个 `/etc/sudoers` 文件所看到的，你可以获取你所需的任何详细信息。在查看这些文件时，有四种别名：`User_Alias`（用户别名）、`Runas_Alias`（运行别名）、`Host_Alias`（主机别名）和 `Cmd_Alias`（命令别名）。每种别名类型列列如下：

- `User_Alias` 是一个列表，可以包含用户名的任何组合、带有 `"#"` 前缀的 UID、网络组（带有 `"+"` 前缀）以及其他用户定义的别名。这些条目中的任何一个都可以使用 NOT 操作符 `"!"` 作为前缀，以对该条目取反。

- `Runas_Alias` 可以包含与 `User_Alias` 相同的任何元素；唯一的区别是你在配置中使用 `Runas_Alias` 代替 `User_Alias`。`Runas_Alias` 允许以 root 以外的用户身份执行命令。

- `Host_Alias` 是主机名、IP 地址或网络组（带有 `"+"` 前缀）的列表。`Host_Alias` 也支持 NOT 操作符 `"!"` 来对条目取反。你需要使用完全限定的 DNS 名称，`hostname` 命令在任何机器上返回的名称都是完全限定 DNS 格式的机器名称。`visudo` 编辑器不会捕获这个“错误”。

- `Cmd_Alias` 是由完整路径或仅文件名的文件指定的一个或多个命令的列表。仅提供文件名将允许为命令传递参数，但你可以使用双引号（`"`）禁用命令参数。如果指定了目录，用户可以执行该目录内的任何命令，但不能执行任何子目录。允许通配符，但请务必小心确保通配符的作用符合预期。

## 使用 sudo

我们通过在想要运行的命令前加上 `sudo` 字来使用 sudo。例如，如果我的 ID 是 `rmichael` 且我想首次获得 root 权限，我将遵循以下步骤：

```bash
PATH=$PATH:/usr/local/bin
export PATH
sudo su - root
```
