## 玻色-爱因斯坦统计

当对粒子分布在可用能级上没有限制时，对量子力学系统进行统计描述是必要的。这种描述适用于粒子具有对称波函数的情况。

假设通过给出每个状态 `i` 的粒子数来描述一个系统，其中 `n_i` 计数数量，`i` 标记状态。能级 `epsilon_i` 与 `g_i` 个简并（非简并）量子态相关。粒子在单个能级上的任何排列都是允许的，其特定分布的概率由公式 `(1)` 给出。在玻色-爱因斯坦统计中，该概率将写为：

```
$W = \prod \frac{(n_i + g_i - 1)!}{n_i!(g_i - 1)!} (1a)
```

平衡态被定义为系统的最概率态。为了获得它，必须在公式 `(2a)` 和 `(2b)` 给出的条件下最大化公式 `(1)`，这些公式表示：

```
$$\sum n_i = N (2a)
```

```
$$\sum \epsilon_i n_i = E (2b)
```

这考虑了粒子总数 `N` 和总能量。

在大多数诱导流中，物体近侧或背风侧的分离和尾流由于前端压力较高，导致了作用于所有钝体、过滤器和旋转器上的离离力，同时也作用于气流和湍流-边界流，其壁面剪切力成比例地增大。它们对分离的抵抗能力明显低于不可压缩流。

所有的层流边界流，如果它们变得肥厚并具有足够的速度，无论是自然还是诱导的，都会发生轻微扰动，并于在有限的长度范围内增长。增长始于一组特定的周期性扰动，称为托尔尔曼-施尔特格波，它们沿流向生长并最终演变为称为湍流的随机涨落。关键参数是雷诺数。从层流变为湍流的过程被称为转变为。

湍流的特征是随机性，叠加在平均场压力和速度之上的三维波动。这些波动通常是平均值的 3-6%，且与分子级厚度相比，相差了几个数量级。它们包含了尺寸与边界层厚度相当的大涡流。

将宽谱涡流叠加在表面上的影响是大大增加了动量、热量和单质的传递。湍流边界层比层流层厚得多，且热量距离壁面更远。平均速度分布在路径处更粗糙，具有巨大的波动，这使得非线性外流与湍流边界层在厚度上分离。这种层的厚度在湍流和湍流流中进行度量。

随着流速 `U` 增大，其动能 `U^2` 与焓 `c_pT` 成正比；其中 `c_p` 是比热常数，`T` 是绝对温度。温度和密度的变化变得重要，该定律不再能视为不可压缩的。由时间时间和压力引起的可压缩流通常是自由的。见气体；G标记。

在具有足够速度的流中，无滑条件仍然有效，但壁面附近的边界层处于缓慢或速度。流体进入边界层并丢失大部分动能。压力梯度部分转化为热量。高度可压缩边界层的尾流非常热，即使壁面是凉的并正在带走热量。

在低速（不可压缩）边界层中，流体非常薄，以至于温度低于主流温度。从高温向低温的热流是进入进去的。对于非绝缘壁面，边界层由流体加热；然而，绝缘壁面由于层内的粘性耗散能量交换而具有较高的表面温度。

除了需要考虑压力和密度的复杂性外，可压缩边界层与那些低速计数具有相似的特征。它们通过在较高的雷诺边界层从层流转变为湍流。边界层往往比不可压缩边界层厚，具有成比例增大的壁面剪切力。它们对分离的抵抗能力明显低于不可压缩流。

在超音速外流中，激波发生在边界层或气泡中，或者它们可能形成并冲击物体。如果是如此，压力在物体后方剧剧上升，形成反梯度，这往往导致分离和气动性能损失。在气动表面上需要特别注意，以避免在转变为超音速流中形成激波。见 FLOW。
