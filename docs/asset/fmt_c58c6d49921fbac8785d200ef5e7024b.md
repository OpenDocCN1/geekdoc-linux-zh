
### 解释

- 1. 声明了 `package House`。因为它包含一个将祝福引用的方法，所以可以称其为类。
- 2. 子程序 `new` 在面向对象术语中被称为 **构造函数** 方法。构造函数的主要任务是创建和初始化对象。在 Perl 中，它并没有特殊的语法。这被称为类方法，因为它的第一个参数是从 `@_` 数组中移出的类名。参见示例 14.4 以了解如何调用此方法。它是一个将引用的“事物”对象祝福到类中并返回其引用的子程序。该子程序被称为 **方法**，它祝福的“事物”是一个 **对象**。**包** 被称为 **类**。
- 3. 此类子程序接收的第一个参数是包或类的名称，在此情况下为 `House`。这是方法与子程序之间的另一个区别。方法的第一个参数是类或对象的名称。
- 4. 引用 `$house_obj` 被分配了一个匿名哈希对象 的地址。有三个键带有值。`Payment` 的值被分配为 `undef`，意味着此时的值是未定义的，稍后将被定义。这些键/值对作为房屋对象的默认属性/特征。你可以让哈希保持为空，稍后设置属性，例如 `$house_obj = {}`。它们可以由示例 14.3 中定义的实例方法设置或修改。
- 5. 引用 `$house_obj` 是 `bless()` 函数的第一个参数，类名是第二个参数。祝福并不祝福引用本身。它祝福引用指向的位置，称为被引用者。它用类名标记该位置，将普通引用转换为对象的引用。
- 6. 将对象的引用返回给调用者。

### 创建实例方法

除了构造函数方法之外，还可以定义其他方法。在面向对象世界中，这些方法被称为公有方法，它们是你访问对象的方式，但只有在其实例存在之后才有效。它们通常描述对象的行为，意思是它能做什么或可以对它做什么。事实上，方法应该是访问对象的唯一途径。

对于我们的房屋对象，访问房屋的一个方法可能是搬进去，另一个是清理它，另一个是展示它，等等。Perl 中的方法只是被美化了的子程序。在下面的示例中，我们向 `House` 类添加了三个实例变更器或 setter 方法。这些方法 `set_owner()`、`set_color()` 和 `set_price()` 都假设对象的实例已经创建；换句话说，如果房子不存在，你就不能拥有它、粉刷它或支付它的款项。实例方法始终将对象的引用作为其第一个参数。一旦方法拥有对象的地址并知道它所属的类祝福，它就会前往该地址并执行其编程执行的任务，例如设置值、返回值、更改默认值，例如计算抵押贷款、添加车库、清洁厨房、拆除等。

#### 示例 14.3

```perl
package House;    # 类的名称

sub new{

   my $class=shift;

   my $house_obj={  "Owner"=>"Planet Bank",      # 默认属性

                   "Color"=>"Beige",

                   "Payment"=>undef,

                  };

   return bless($house_obj, $class);

}

#------------------------

# 创建将操纵对象的实例方法

# Setter 方法

sub set_owner{    # 访问器或实例方法

    my ($self, $owner) = @_;

# 第一个参数是指向房屋对象的指针

    $self->{"Owner"}=$owner;    # 设置新所有者

}

sub set_color{    # Setter 方法

    my ($self,$color) = @_;

# 第一个参数是指向房屋对象的指针。

    $self->{"Color"}=$color;

}

sub set_payment{

    my ($self, $payment) = @_;

# 第一个参数是指向房屋对象的指针

    $self->{"Payment"}=$payment;

}

# Getter 方法

sub get_owner{

    my $self=shift;

        return $self->{"Owner"};

}

sub get_color{

    my $self=shift;

        return $self->{"Color"};

}

sub get_payment{

    my $self=shift;

        return $self->{"Payment"};

}
```

### 解释

- 1. 类是 `House`。
- 2. 定义了带有默认属性的构造函数。
- 3. 在此处定义了实例方法。这是 `set_owner` 方法，称为“setter”变更器。它存储对象中的数据。
- 4. `set_owner` 方法接收的第一个参数是对象的引用。它被称为 `$self`。`$self` 常被使用，但该方法可以使用任何有效的变量名。第二个参数是对象 `Owner` 属性的值。当用户调用该方法时，Perl 首先隐式发送对象的引用，然后发送用户发送的其他参数。
- 5. 对象的引用存储在 `$self` 中。`Owner` 属性的值通过此引用分配给对象。
- 6. 该方法被称为“getter”。它从对象中检索获取信息。第一个参数是对象的地址，`$self`。
- 7. 检索 `Owner` 属性的值并将其返回给用户。
