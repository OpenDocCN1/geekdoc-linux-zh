
修订号（如 `1.1`）被用作文件版本的名称（在某些情况下也可以使用实际名称，参见本章后尾的“符号名称”部分）。最左侧的数字通常表示产品的重大发布。如果我们正在开发现有产品的新版本，我们可能会根据版本号的内部策略将此数字覆盖为 `2` 或 `3`。第二个数字代表次要版本，例如 `2.5` 可能代表该文件在版本 `2` 内部的第 `5` 次修订（修订（自 RCS 和 SCCS 早期以来，修订号已经有了了自己的生命力，实际上不再像以前那么重要了）。

版本控制系统将文件的任何剩余副本都标记为只读，这一点具有重要意义。版本控制系统的准确性完全取决于它所察觉到的更改，因此注册更改非常重要。从表面上看，文件的权限起着提醒我们保持文件与版本控制系统同步的作用。更重要的是，当有多人参与项目工作时，文件权限起着至关重要的作用。

如果文件被标记为只读，则无法保存对文件的编辑，文件的权限只能由所有者（或超级用户）更改。编辑文件的正确方法是从控制系统中检出文件，这会将文件标记为仅由检出者可写。因此，如果一个用户检出了文件，在文件被检回（`check in`）之前，其他人将无法修改它。这是所谓的*文件锁定*中最基础的操作。

**注意：** 当小组一起工作时（例如创建一个 Web 页面集、应用程序开发项目或任何其他非系统管理相关的项目），所有用户都应该拥有适当账户并使用它。不应以 `root` 身份工作，因为当用户可以随意覆盖时，文件锁定基本上变得失效。

版本控制系统将对象的系列更改存储在控制文件中。（每个系统都有不同的选项并以不同的方式存储这些文件。RCS 文件的详情见第 `24` 章，SCCS 文件的详情见第 `26` 章。第 `25` 章介绍的 CVS 使用 RCS 文件。）这些文件包含了项目的完整历史，使其既可以作为备份，也可以作为审计轨迹。事实上，只要历史文件可用，其实没有必要保留文件的当前副本。许多编程实用程序（如 `make` 和 `emacs`）都能感知版本控制，并可以自动检索文件的最新版本。

注册 `hello.html` 启动了版本控制过程。该过程本质上对在该项目工作的用户强制执行了一种纪律。除非检出文件，否则无法更改文件；除非检回文件，否则其他人无法对它们进行操作。如果你不检回文件，你的同事很可能会要求你这样做。此外，正如你在下一节中看到的，当文件被检回时，系统允许你对你所所的更改添加注释。如果注释缺失或不完整，经常会引发麻烦，特别是当更改涉及某个问题时。

## 创建新修订

`hello.html` 第 `9` 行的电子邮件地址对于外部系统无法用，因为域名不完整，所以我们必须更新该文件。（否则，人们如何告诉我们他们对这件杰作的看法呢？）

该文件自我们将其注册到版本控制系统以来就一直被标记为只读。为了编辑它，我们需要检出 `hello.html` 的最新版本。

检出文件（在 SCCS 术语中称为*get*）为我们提供了一个可修改的文件工作副本。它还在版本控制系统内将文件标记为正在编辑，锁定其他用户检入可能与我们冲突的修订版本。（文件也可以以只读方式检出，因此可以随时查看文件，但一次时间只能有一个用户锁定）。

检出文件后，对该行进行了修改：

```
<address><a href=mailto:eric@niftydomain.com>Eric Goebelbecker</a></address>
```

然后我们检回（或 `delta`）文件。作为检回过程的一部分，系统会提示我们输入注释。（显示了 SCCS 的请求提示。）

`comments? Fixed e-mail address.`

该项目现在有了第二个修订版本，由于我们没有覆盖默认值，它被编号为版本 `1.2`。

## 单个文件或项目的多个版本

在之前的示例中，你只需要一个单一路径（主干）的修订树。让我们看看一个需要高级解决方案的情况。

一家小型 *ISP*（互联网服务供应商）为其客户提供两种服务。一种是 *shell 账户*，客户可以拨入并登录 UNIX 主机。另一种是 *PPP 账户*，客户拨入建立连接，但从未登录 ISP 的任何系统。（注意细节的人：PPP 登录由终端服务器处理。）

然而，所有用户都需要在 *POP 邮件服务器*上拥有账户，因为他们都会收到邮件，邮件必须以正确的所有权文件权限保存，直到用户通过 shell 账户的邮件代理或其家中的系统检索它们。因此，ISP 需要维护两个 UNIX `passwd` 文件，一个仅供 shell 用户，另一个包含所有用户。（第二个注意细节的人：是的，如果终端服务器使用 `passwd` 文件，我们需要三个。这只是个例子！）

在 ISP 提供 PPP 账户之前，`passwd` 文件的初始修订可能像这样：

```
abe:x:200:200:Abraham Lincolni:/export/home/abe:/bin/sh
ben:x:201:200:Benjamin Franklin:/export/home/ben:/bin/ksh
sue:x:202:200:Susan B Anthony:/export/home/sue:/bin/ksh
ike:x:203:200:Dwight D Eisenhower:/export/home/ike:/bin/ksh
fdr:x:204:200:Franklin D Roosevelt:/export/home/fdr:/bin/ksh
harry:205:200:Harry S Truman:/export/home/harry:/bin/sh
john:x:206:200:John Galt:/export/home/john:/bin/csh
```

```

ben:x:201:200:Benjamin Franklin:/export/home/ben:/bin/ksh
```
