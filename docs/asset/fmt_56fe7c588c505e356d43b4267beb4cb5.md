
# 声场控制与适应概念

通过简单地增加用于控制声场的次级声源的数量，可以克服该技术的一些物理限制。例如，如果使用10个扬声器来控制纯音声场，原则上可以在声场中产生10个静默点。当然，根据初级和次级声源的几何布置以及声学环境，在其他位置可能会产生声压级的增加。另一种策略是驱动次级声源，以最小化数量多于次级声源数量的若干误差麦克风处的声压级。在这些情况下，可以产生广泛的声压级降低。只需要检测初级声源的频率；该参考信号随后被采样并通过与每个次级声源相关的数字滤波器。（该信号不会受到次级声源输出反馈的干扰。）然后，使用通用算法的多通道推广，根据误差麦克风处采样的信号自适应地调整这些滤波器的系数。这确保了误差麦克风输出平方和的最小化，从而抑制声场。

许多实际感兴趣的声学波形具有高度的不可预测性。例子包括由于汽车内气流经过乘客舱以及轮胎与路面接触产生的振动而产生的噪音波形。此外，可能存在多个此类不想要声音的初级声源。在这些情况下，很难找到在声学压力波动到达乘客耳朵之前很久就能给出先前指示的参考信号。然而，可以找到一个最优的数字滤波器矩阵，确保若干误差麦克风时间平均信号之和的最小化。参见“声学噪声”；“自适应信号处理”；“控制系统”；“声音”。

## 适应（生物学）

**该物质的化学势。活动性与浓度的度量密切相关，例如分压和摩尔分数。化学平衡和相平衡中成立的条件可以用所涉及物种的活度来表示。**

热力学系统中某一相（均匀部分）中化学物种 $i$ 的活度 $a_i$ 由公式 (1) 定义，其中

$$a_i = \exp[ (\mu_i - \mu_i^\circ) / RT ]\tag{1}$$

$\mu_i$ 是物种 $i$ 在标准状态下的化学势，$\mu_i^\circ$ 是物种 $i$ 在标准状态下的化学势，$R$ 是气体常数，$T$ 是绝对温度。公式 (1) 表明活度 $a_i$ 取决于物种 $i$ 标准状态的选择。由于 $\mu_i$ 是一个取决于相的温度、压力和组成的强度量，$a_i$ 是这些变量的强度函数，$a_i$ 是无量纲的。当 $\mu_i = \mu_i^\circ$ 时，$a_i = 1$。$a_i$ 偏离 1 的程度衡量了化学势偏离其标准状态值的程度。

化学势定义为 $\mu_i \equiv \partial G/\partial n_i$，其中 $G$ 是相的吉布斯自由能，$n_i$ 是相中物质 $i$ 的摩尔数，且偏导数是在恒定温度、压力以及除 $i$ 以外所有物质的量不变的条件下取的。参见“自由能”。

根据公式 (1)，$\mu_i$ 由公式 (2) 给出。化学势 $\mu_i$ 是相的关键热力学量，因为如果已知相中化学势作为温度、压力和组成的函数，就可以找到相的所有热力学性质。与化学势相比，活度更方便处理，因为物质在相中的化学势随着该物质在相中的量趋于零而趋于负无穷大；此外，只能确定 $\mu_i$ 相对于其他某个状态的值，而可以确定每个 $a_i$ 的实际值。

$$\mu_i = \mu_i^\circ + RT \ln a_i\tag{2}$$

## 酰化

一个有机化合物中的氢原子被酰基（$\text{R-CO}$，其中 $\text{R} = \text{有机基团}$）取代的过程。该反应涉及在羧酸衍生物的亲电羰基（C=O）处对亲核试剂（电子供体）的取代。取代通常通过加成-消除序列进行。上述两种常见的具有通用结构的酰化试剂是酰卤（X = Cl, Br）和酸酐（X = OCOR）。还有其他酰化试剂。羧酸（X = OH）本身在通过强酸催化剂质子化时也可以作为酰化剂，如醇的直接酯化。酰化反应中典型的亲核试剂是醇（ROH）或酚（ArOH），两者都生成酯，以及胺或酰胺（$\text{R}^{\prime}\text{N}-$），生成酰胺。参见“酸酐”；“酰卤”；“酰胺”；“胺”。

## 生物适应

生物体使其适应其环境或其特定生活方式的特征。例如，北极狐（*Vulpes lagopus*）非常适应在极冷的气候中生活。大约来说，它与温暖地区类似体型的哺乳动物相比，毛发要厚得多，通过对毛发样本热流的测量表明，北极狐和其他北极哺乳动物比热带物种具有更好的隔热性能。因此，在低温下，北极野兔不需要像热带哺乳动物那样大幅提高其新陈代谢率。隔热效果如此有效，以至于北极狐即使在环境温度降至 -112°F（-80°C）时，也能维持其正常的 100°F（38°C）体温。因此，它们厚厚的毛发显然是对寒冷环境生活的适应。参见“体温调节”。

适应快速且经济的高效游泳方式。其身体具有近乎理想的流线型形状。然而，一些外观上不如流线型的其他鱼类，在同等体型下也能达到同等速度。目前尚无对鲭科鱼类游泳能量消耗的直接测量数据，但对其他物种的测量显示，能量消耗与流线化程度之间并无明确的关联。

自然选择驱动的进化倾向于提高适应度，使生物体更好地适应其环境与生活方式。虽然人们可能推断这会最终导致完美适应，但事实并非如此。必须牢记，进化是通过小步渐进实现的。例如，乌贼的游泳能力不及鱼类。如果乌贼进化出类似鱼类的尾部而非其喷射推进机制，其在游泳方面的适应性会更好，但进化无法实现这一转变，因为这要求先离开较低适应度峰值再攀登更高的适应度峰值。

## 自适应控制

一种特殊的非线性控制系统，能够改变自身参数以适应环境变化。环境变化可代表过程动态特性的变化或扰动特征的变化。参见非线性控制理论。

常规反馈控制系统能够应对过程动态特性的适度变化。事实上，存在这种变化正是引入反馈控制的原因之一。然而，在许多情况下，过程动态特性的变化幅度极大，使得恒定线性反馈控制器无法有效工作。例如，超音速飞机的动态特性随马赫数和动压发生剧烈变化，恒定参数飞行控制系统将无法良好运行。参见飞行控制。

自适应控制同样适用于工业过程控制。由于延迟和滞留时间取决于生产状况，当生产发生变化时，重新调节调节器是必要的。自适应控制还可用于补偿因老化与磨损导致的性能变化。参见过程控制。

## 适应性管理

一种自然资源管理方法，强调对生态系统动态性的已知信息极为有限，并认为随着知识积累，管理策略将不断演进与优化。自然系统极其复杂且动态变化，而人类对自然过程的观察具有片段性与不精确性。因此，可持续利用现有资源的最佳方式仍待确定。此外，影响自然种群的大量变异性不可预测且超出人类控制范围。这种无知与不可预测性的组合意味着生态系统对人类干预的反应方式是未知的，只能用概率术语进行描述。尽管如此，管理决策仍需作出。适应性管理流程通过将自然系统的人类干预视为大规模实验以强调这种不确定性，从中获取更多信息，从而促进未来管理水平的提升。

开发适应性管理计划的关键第一步是问题评估。在此阶段，需通过开发系统的动态模型，将现有知识与跨学科经验进行综合与正式整合。这种建模活动有助于识别关键信息缺口，并基于现有信息提出关于系统可能对人类干预作出何种反应的假设。需筛选不同的管理政策，将备选方案缩小至几个可行候选项。

第二阶段涉及管理与监测计划的正式设计。在能够带来未来管理改进的新信息范围内，适应性管理计划可包含刻意设计以加速学习的大规模实验。某些管理行动在填补相关信息缺口方面可能比其他行动更有效。在可实现空间重复的情况下（如小型湖泊、森林斑块和珊瑚礁），为不同管理单元提供对比的政策比在所有区域应用相同规则的政策能更有效地揭示系统动态特性。实施大规模管理实验还面临其他障碍。实验通常伴随成本；因此，为了价值所在，学习带来的收益必须能够补偿短期损失。选择可能受社会关切或生物限制约束，也可能伴随不可接受的高风险。

一旦选定行动方案，下一阶段是在实地实施该计划。这是最困难的步骤之一，因为它涉及所有参与自然资源使用、评估和管理的各方部门共同努力并持续投入。除了实施具体初始行动外，建立适应性管理计划还要求长期承诺：监测计划执行合规性、评估管理干预效果并据此调整管理策略。

无论初始评估与设计多么周详完整，系统总可能以规划阶段无法预见的方式作出反应。生态系统在数十年和世纪的时间尺度上表现出长期持久变化；因此，近期经验未必是预测未来行为的可靠基础。全球气候变化对生态系统动态的影响在很大程度上不可预测，将带来诸多此类管理挑战。适应性管理计划必须包含评估与调整阶段。过往管理决策的结果需与最初预测进行对比，模型需根据新理解加以完善，管理计划需相应修订。新信息可能揭示新的不确定性与创新性管理方法，从而引发新一轮评估、设计、实施与评估循环。

## 自适应光学

研究通过可控光学元件（通常是可变形镜面）优化系统性能的光学系统学科，例如在有波前像差存在的情况下保持图像清晰聚焦。需区分主动光学与自适应光学：前者通过外部控制修改或调整光学部件以补偿缓慢变化的干扰，后者适用于采用传感器与数据处理器、运行频率更高的闭环反馈系统。参见控制光学系统。

在一个典型的自适应光学系统中（见图），待补偿的畸变光束从可变形镜面反射并被分束器取样。光样本在波前传感器中分析，确定光束各部分误差。所需校正量计算后应用于可变形镜面，其表面形成使反射波面展平所需形状。结果是去除采样点处的光学误差，使通过分束器的光聚焦为清晰图像。非线性光学器件也能执行某些自适应光学功能；这些器件在高光学功率水平下工作。参见光学；几何光学；非线性光学器件。
