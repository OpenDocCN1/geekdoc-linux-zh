
## 描述

`javah` 命令生成实现本地方法所需的 C 头文件和源文件。生成的头文件和源文件供 C 程序用于从本地源代码引用对象的实例变量。`h` 文件包含一个结构定义，其布局与相应的类并行。结构中的字段与类中的实例变量对应。

头文件的名称以及其中声明的结构源于类名。如果传递给 `javah` 的类是一个包，则包名将附加在头文件名和结构名前之前。使用下划线 (`_`) 作为名称分隔符。

默认情况下，`javah` 会为命令行上列出的每个类创建一个头文件，并将文件放在当前目录中。使用 `-stubs` 选项创建源文件。使用 `-o` 选项将所有列出类的结果合并到一个文件中。新的本地方法接口——Java Native接口（JNI）不需要头文件信息或存根文件。你仍然可以使用带有 `-jni` 选项的 `javah` 命令来生成 JNI 风格本地方法所需的方法原型。结果存放在 `.h` 文件中。

`javah_g` 版本是 `javah` 的非优化版本，适用于 `jdb` 等调试器。

## 选项

- `-classpath path`: 指定 `javah` 用于查找类的路径。如果设置了 `CLSPATH` 环境变量，则覆盖其默认值。目录之间用冒号分隔。因此，路径的通用格式为：
- `-`: `your-path`: 例如：`:/home/avh/classes:/usr/local/java/classes`
- `-d directory`: 指定 `javah` 保存头文件或存根文件的目录。
- `-help`: 打印帮助信息。
- `-jni`: 创建一个包含 JNI 风格本地方法原型的输出文件。
- `-o outputfile`: 将命令行列出的所有类的生成的头文件或源文件合并到 `output`。
- `-stubs`: 从 Java 对象文件生成 C 声明。
- `-td directory`: 覆盖 `javah` 存储临时文件的默认目录。默认为 `/tmp`。
- `-trace`: 向输出添加跟踪信息。
- `-v`: 打印关于生成状态的消息。
- `-version`: 打印版本。

# javald

## javald

相对路径被视为相对于包装器安装目录的路径，而不是当前目录。

这种行为旨在支持由目录层次组成的应用程序。使用相对路径允许你轻松地移动此目录层次（即应用程序）到不同的文件系统。

如果没有使用 `-C` 选项，包装器创建的默认 `CLSPATH` 等于

```
$JAVA_HOME/bin/javald
```

## 选项

- `-C path`: 将路径添加到运行时 `CLSPATH`，指定 `java(1)` 搜索 Java 类。你可以重复 `-C` 选项。

```
castle% javald -C /usr/class -C /optjava...
```
- `-H dir`: 将 `JAVA_HOME` 设置为 `dir`。
- `-j option-list`: 指定传递给 `java(1)` 调用 的选项列表。如果你指定了多个选项，必须加引号以确保它们传递到包装器。
- `-o outfile`: 将包装器放在 `outfile` 中。
- `-R path`: 将路径添加到运行时 `LD_LIBRARY_PATH`，指定 `java(1)` 搜索本地方法。

## 示例

在以下示例中，在 `/opt/acme/bin` 创建了一个名为 `appl` 的包装器。

```
castle% javald -o /opt/acme/bin/appl -C /opt/acme/classes acmeapp
```

它包含以下环境变量。

```
JAVA_HOME=$(JAVA_HOME:-/usr/java)

CLASSP=/opt/acme/classes
```

当你运行 `appl` 时，`java(1)` 尝试调用 `acmeApp` 类的 `main` 方法。`java(1)` 解释器在 `/opt/acme/classes` 中搜索 `acmeApp`，然后在默认的系统类目录 `${JAVA_HOME}/lib/classes` 中搜索。

以下命令创建一个名为 `myapp` 的脚本。

```
castle% javald -o myapp -j '-noverify -ms8m' myapp
```

## javap

它包含以下对 `java(1)` 解释器的调用：
`exec ${JAVA_HOME}/bin/java -noverify -ms8m myapp`

- `JAVA_HOME`: 指定 `java(1)` 运行时。

## 文件

- `/usr/java/lib/classes.zip`: Java 运行时类的归包。请注意你不需要解压该归包。

## javap — Java 类文件反汇编器

### 概要

```
/usr/java/bin/javap [-b] [-c] [-classpath] [-h] [-flag] [-1] [-package] [-private] [-protected] [-public] [-s] [-verbose] [-verify] [-version] class...
```

## 描述

使用 `javap` 命令反汇编 Java 类文件。选项决定了输出。如果你未指定任何选项，`javap` 将显示传递给它的类的公共字段和方法。`javap` 命令将其输出显示到标准输出。例如，编译以下类声明：

```java
import java.awt.*;

import java.applet.*;

public class DocFooter extends Applet {

  String date;

  String email;

  public void init() {

    resize(500,100);

    date = getParameter("LAST_UPDATED");

    email = getParameter("EMAIL");

  }

  public void paint(Graphics g) {

    g.drawString(date + " * by", 100, 15);

    g.drawString(email,290, 15);

  }

}
```

`javap DocFooter` 的输出产生：

```
Compiled from DocFooter.java

public class DocFooter extends java.applet.Applet {

  java.lang.String date;

  java.lang.String email;

  public void init();

  public void paint(java.awt.Graphics);

  public DocFooter();

}
```

## 选项

- `-b` 确保与 JDK 1.1 中的 `javap` 向后兼容。
- `-c` 打印反汇编代码，即类中每个方法所组成 Java 字节码的指令。
- `-classpath path`: 指定 `javap` 用于查找类的路径。如果设置了默认值或 `CLSPATH` 环境变量，则对其进行覆盖。用冒号分隔目录。因此，路径的通用格式为：
`:your-path`
例如：
`.home/avh/classes:/usr/local/java/classes`

- `-h` 生成可以放入 C 头文件中的代码。
- `-J flag` 将标志直接传递给运行时系统。
- `-l` 显示行号和局部变量表。
- `-package` 仅显示包、保护和公共类及成员（默认值）。
- `-private` 显示所有类和成员。
- `-protected` 仅显示保护和公共类及成员。
- `-public` 仅显示公共类和成员。
- `-s` 显示内部类型签名。
- `-verbose` 打印方法的栈大小、局部变量数量和参数。
- `-verify` 运行验证器。
- `-version` 打印 `javap` 版本字符串。

## 环境变量

`CLASPATH`: 为系统提供用户定义类的路径。用冒号分隔目录。例如：`:/home/avh/classes:/usr/local/java/classes`
