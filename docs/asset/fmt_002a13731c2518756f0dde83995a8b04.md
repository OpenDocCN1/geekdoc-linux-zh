
```c
20: x1 = fix_x + rx;
21: x2 = fix_x - rx;
22: y1 = fix_y + ry;
23: y2 = fix_y - ry;
```

使用这些点，将每对中较小的值赋予 `ARC` 结构中的 `x` 和 `y` 原点：

```c
25: arc.x = min(x1, x2);
26: arc.y = min(y1, y2);
```

并将较大的值赋予水平和垂直跨度：

```c
28: arc.width = max(x1, x2) - arc.x;
29: arc.height = max(y1, y2) - arc.y;
```

当 `Arc` 的交互模式产生用户所需的对象时，她松开鼠标按钮并结束创建过程。当发生这种情况时，实际的 `Arc` 对象通过调用列表 23.3 中引入的 `create_arc` 函数来创建。
