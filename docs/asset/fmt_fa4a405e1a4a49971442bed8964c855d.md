
# join

```
/usr/bin/join [-a filename] | -v filename] [-1 fieldnumber]

[-2 fieldnumber] [-o list] [-e string] [-t char] file1 file2

/usr/bin/join [-a filename] [-j fieldnumber] [-j1 fieldnumber]

[-j2 fieldnumber] [-o list] [-e string] [-t char] file1 file2
```

## 描述

`join` 命令对 `file1` 和 `file2` 指定两个关系进行连接（join），并将结果输出到标准输出。
对于 `file1` 和 `file2` 中具有相同连接字段的每对行，输出有一行。输出行通常由公共字段组成，然后是文件中行的其余部分。你可以使用 `-o` 选项更改此格式。使用 `-a` 选项将未匹配的行添加到输出中。使用 `-v` 选项仅输出未匹配的行。
默认的输入字段分隔符是空白符、制表符或换行符。
默认输出分隔符是空格。
如果输入文件不在适当的顺序，结果将未定义。
注意 — 使用默认分隔符时，排序顺序类似于 `sort -b`；使用 `-t` 时，顺序为普通 `sort`。
`join`、`sort` 和 `awk` 命令的约定是不一致的。

## 选项

下面的某些选项使用参数 `fieldnumber`。该参数应该是 1 或 2，分别引用 `file1` 或 `file2`。

- `-a fieldnumber` 除了常规输出外，为 `fieldnumber` 中的每个未匹配的行生成一行，`fieldnumber` 为 1 或 2。如果你同时指定 `-a 1` 和 `-a 2`，则输出所有行。
- `-e string` 将空字段替换为 `string`。
- `-j fieldnumber` 等于 `-1 fieldnumber -2 fieldnumber`。
- `-j1 fieldnumber` 等于 `-1 fieldnumber`。
- `-j2 fieldnumber` 等于 `-2 fieldnumber`。字段从 1 开始编号。
- `-o list` 在每行输出中包含指定的字段。列表中选择的未出现的字段为空（参见 `-e` 选项）。每个元素的形式为 `fieldnumber`，`fieldnumber.0` 表示连接字段。除非特别请求，否则不打印公共字段。
- `-t char` 使用字符 `char` 作为分隔符。行中 `char` 的每次出现都是。使用字符 `char` 作为输入输出的字段分隔符。指定此选项时，排序顺序将与没有 `b` 选项的 `sort` 相同。
- `-v fieldnumber` 代替输出，仅为 `fieldnumber` 中的每个未匹配行生成一行，`fieldnumber` 为 1 或 2。如果你同时指定 `-v1` 和 `-v2`，则输出所有未匹配行。
- `-1 fieldnumber` 在 `file1` 的第 `fieldnumber` 个字段上连接。字段是从 1 开始的整数。
- `-2 fieldnumber` 在 `file2` 的第 `fieldnumber` 个字段上连接。字段是从 1 开始的整数。

## 参数

`file1` 要连接的文件路径名。如果 `file1` 或 `file2` 参数之一为 `-`，则用标准输入代替它。

`file1` 和 `file2` 必须根据 `LC_COLLATE` 确定的排序顺序对连接字段排序，通常为每行的第一个字段（参见 `sort(1)`）。

## 用

查看 `largefile(5)` 以了解 `join` 在遇到大于或等于 2 GB 文件时的行为。

## 示例

下面的命令行连接密码文件和组文件，根据数字组 ID 进行匹配，并输出登录名、组名登录目录。假设文件已按 ASCII 排序顺序对组 ID 字段进行了排序。

```
$ join -j4 -j2 3 -o 1.1 2.1 1.6 -t: /etc/passwd /etc/group

root:other:

daemon:other:
```

```
bin:bin:/usr/bin

sys:sys/

adm:adm:/var/adm

lp:lp:/usr/spool/lp

nuuc:nuuc:/var/spool/uucpublic
```

`-o` 字段本质上选择了 `join` 字段的并集。例如，给定文件 `phone`：

| 名称 | 电话号码 |
| --- | --- |
| Don | +1 123-456-7890 |
| Hal | +1 234-567-8901 |
| Yasushi | +2 345-678-9012 |

以及文件 `fax`：

| 名称 | 传真号码 |
| --- | --- |
| Don | +1 123-456-7899 |
| Keith | +1 456-789-0122 |
| Yasushi | +2 345-678-9011 |

（其中较大的空白扩展代表单个 Tab 字符），命令示例 `join -t "tab" a 1 -a 2 -e '(unknown)' o 0,1,2,2.2 phone ax`

## 产生

| 名称 | 电话号码 | 传真号码 |
| --- | --- | --- |
| Don | +1 123-456-7890 | +1 456-7889 |
| Hal | +1 234-567-8901 | (unknown) |
| Keith | (unknown) | +1 456-789-0122 |
| Yasushi | +2 345-678-9012 | +2 345-678-9011 |

## 环境变量

参见 `environ(5)` 以获取影响 `join` 执行的以下环境变量的描述：`LC_TYPE`、`LC_MESSAGES`、`LC_COLLATE` 和 `NLPATH`。

## 退出状态

```
0 所有输入文件均已成功输出。

>0 发生错误。
```

参见 `attributes(5)` 以获取以下属性的描述：

| --- | --- |

# jre — Java 运行时解释器

### 概要

```
/usr/java/bin/jre [-classpath path(s)] [-cp path(s)] [-DpropertyName=newValue] [-help] [-msx] [-mxx] [-noasyncgc] [-noclassgc] [-nojit] [-nofverify] [-ossx] [-v | verbose] [-verbexec] [-verify] [-verifyremote] classname args
```

`jre` 命令执行类文件。`classname` 参数是要要执行的类的名称。传递给类的任何参数都必须放在命令行中 `classname` 之后。

## 选项

- `-classpath path(s)`
指定 `jre` 用于查找类的路径或路径。如果设置了默认或 `CLSPATH` 环境变量，则覆盖它。如果指定了多个路径，请用冒号分隔路径。每个路径应以包含要执行的类文件的目录结尾。然而，如果要执行的文件是 `zip` 或 `jar(1)` 文件，则该文件的路径必须文件名结尾。以下是 `-classpath` 参数的示例，指定了包含当前目录和两个额外路径三个路径。

```
:/home/xyz/classes:/usr/local/java/classes/MyClasses.jar
```

- `-cp path(s)`
将指定的路径或路径置于基本类路径或 `CLSPATH` 环境变量提供的路径之前。如果指定了多个路径，请用冒号分隔。每个路径应以包含要执行的类文件的目录结尾。然而，如果要执行的文件是 `zip` 或 `jar` 文件，则该文件的路径必须文件名结尾。以下是 `-cp` 参数的示例，指定了包含当前目录和两个额外路径三个路径。

```
:/home/xyz/classes:/usr/local/java/MyClasses.jar
```

- `-DpropertyName=newValue`
定义属性值。`propertyName` 是您想要更改的属性名称，`newValue` 是要更改的值。例如，以下命令行将 `aw.button.color` 属性的值设置为绿色。

```
java jre -Dawt.button.color=green ...
```
