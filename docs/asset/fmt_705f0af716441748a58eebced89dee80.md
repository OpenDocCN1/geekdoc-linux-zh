
# fprintf

此函数向流写入一个格式化字符串。格式化后的字符串基于 `Format` 参数与额外的变长参数（`varargs`）的组合。使用此函数可以方便地将字符串的内容与格式化字符串的结果隔离开。

## 参数

- **Stream**: 这是将接收格式化字符串的流。
- **Format**: 这是信息呈现的格式，并使用写入输出值的简单约定。每当在 `Format` 字符串中发现百分比符号 (`%`) 时，下一个字符将决定插入该字符位置的数据类型。

符号分隔符的常见类型包括表 3.6 中列出的那些。

## 表 3.6 - fprintf 函数的常用标记

| 分隔符 | 数据类型 | 示例 |
|---|---|---|
| `%d` `%i` | 整数 | ```pascal\n//写入一个数字\nfprintf(dataFile, 'The number is %d', 130, 1097);\n``` |
| `%x` `%X` | 无符号整数 | ```pascal\n//写入十六进制值\nSomeIntegerValue := 237;\nfprintf(dataFile, 'The hex number for %d is\n%x', 130, SomeIntegerValue, SomeIntegerValue);\n``` |
| `%e` `%E` | 双精度浮点 | ```pascal\n//写入扩展数字\nSomeDoubleValue := pi;\nfprintf(dataFile, 'An extended value is\n%E', 130, SomeDoubleValue);\n``` |
| `%f` `%F` | 双精度浮点 | ```pascal\n//写入浮点值\nSomeDoubleValue := pi * 9 * 9;\nfprintf(datafile, 'The circumference is %f\n=%3.14', SomeDoubleValue);\n``` |
| `%s` | `PChar` | ```pascal\n//写入字符串到文件\nStrCopy(SomePChar, 'Hello from a string');\nfprintf(datafile, 'The message is %s', SomePChar);\n``` |
| `%%` | | ```pascal\n//写入百分比符号\nSomeDoubleValue := 2950 * 0.10;\nfprintf(datafile, '10%% of 2950 is %%%#13.0\n', SomeDoubleValue);\n``` |

- **varargs**: 变长列表包含了从格式字符串中读取的对应值。例如，如果格式字符串中有三个符号，则 `varargs` 列表中应该有三个项目，且 `varargs` 列表的数据类型应与传入 `Format` 字符串的数据类型匹配。

## 返回值

执行成功时，此函数返回成功写入流的字符数。如果函数失败，返回值为 -1。

## 另请参阅

- `fputs`

# fputc, fputc_unlocked, putc (LibC.pas)

## 语法

```pascal
function fputc(
  C: Integer;
  Stream: PIFILE
): Integer;

function fputc_unlocked(
  C: Integer;
  Stream: PIFILE
): Integer;

function putc(
  C: Integer;
  Stream: PIFILE
): Integer;
```

## 描述

`fputc` 函数向打开的流写入单个字符。

## 参数

- **C**: 这是一个整数值，代表写入流的字符的序数值。你应当使用 Pascal 的 `ord` 函数获取单个字符。
- **Stream**: 这是被写入的输入/输出流。

## 返回值

此函数返回写入流的字符的序数值。如果函数执行失败，文件将返回整数值 `EOF`。

## 另请参阅

- `getc`
- `fputs`

## 示例

### 列表 3.49 - 使用 fputc 函数

```pascal
procedure WriteChar(Stream: PIFILE; C: char);
begin
  fputc(ord(C), Stream);
end;

var
  Stream: PIFILE;
begin
  Stream := fopen(PChar('test.txt'), 'w');
  WriteChar(Stream, 'H');
  WriteChar(Stream, 'e');
  WriteChar(Stream, 'l');
  WriteChar(Stream, 'l');
  WriteChar(Stream, 'o');
  fclose(Stream);
end;
```

# freopen (LibC.pas)

## 语法

```pascal
function freopen(
  FileName: PChar;
  Mode: PChar;
  Stream: PIOFile
): PIOFile;
```

## 描述

`freopen` 函数将现有的流与一个新的文件关联起来。

## 参数

- **FileName**: 这是要关联的文件名。
- **Mode**: 这是文件打开模式。
- **Stream**: 这是要重新关联的流。

## 返回值

函数在成功时返回一个有效流，如果函数失败则返回 `nil`。

## 另请参阅

- `fopen`
- `fclose`

## 示例

### 列表 3.52 - 使用 freopen 函数

```pascal
procedure TfrmMain.btnRedirectOutputClick(Sender: TObject);

  if SaveDialog1.Execute then
  begin
    //将标准输出重定向到文件
    dataFile := freopen(PChar(SaveDialog1.Filename), 'w+',

end;
```

# fseek, fseeko, fseek64 (LibC.pas)

## 语法

```pascal
function fseek(
  Stream: PIOFile;
  Off: Integer;
  Whence: Integer
): Integer;

function fseeko(
  Stream: PIOFile;
  Off: Integer;
  Whence: Integer
): Integer;

function fseek64(
  Stream: PIOFile;
  Off: Int64;
  Whence: Integer
): Integer;
```

## 描述

`fseek` 函数将重新定位流的输入/输出位置，以便下一次数据读取或写入将从该位置开始。

`fseeko` 函数在功能上与 `fseek` 函数等效，但 `Off` 参数的值是 `off_t` 数据类型的整数类型转换，用于兼容较旧的 GLibc 库。在测试的 Linux 系统上，`fseeko` 函数返回的值与 `fseek` 函数相同。

## 参数

- **Stream**: 这是要重新定位的流。在此参数中使用无效的流将导致函数失败，并会将 `errno` 设置为 `EBADF`。
- **Off**: 这是要移动到的位置。此参数与 `Whence` 参数配合使用，确定流的位置。
- **Whence**: 此参数为常量值 `SEEK_SET`、`SEEK_CUR` 或 `SEEK_END` 之一。使用 `SEEK_SET` 将流的内部位置重新定位为距离文件开始的偏移量。`SEEK_CUR` 将根据流的读/写位置偏移指定的字节数重新定位流的位置。`SEEK_END` 将流的读/写位置重新定位为距离文件末尾的偏移量。使用任何非 `SEEK_SET`、`SEEK_CUR` 或 `SEEK_END` 的值都将导致失败，并将 `errno` 值设置为 `EINVAL`。

## 返回值

成功时，函数返回 0。如果函数执行失败，返回值为 -1，并将相应的错误存储在 `errno` 中。

## 另请参阅

- `ftell`
- `fseek`

## 示例

### 列表 3.53 - 使用 fseek 函数

```pascal
// 移动到数据所在的位置
// 位于头部记录之后
fseek(dBaseFile, FhFileHeader.BytesInTheHeader, SEEK_SET);
```

# fsetpos, fsetpos64 (LibC.pas)

## 语法

```pascal
function fsetpos(
  Stream: PIofile;
  const Pos: PFPos
): Integer;

function fsetpos64(
  Stream: PIofile;
  const Pos: PFPos64
): Integer;
```

## 描述

`fsetpos` 将流的读/写位置设置为距离流开始的固定字节数。此函数等同于使用 `SEEK_SET` 作为模式的 `fseek` 函数。处理大于 $2^{32}-1$ 字节的文件时使用 `fsetpos64`。

## 参数

- **Stream**: 这是将移动其读/写位置的流。如果此参数指向无效的流，函数将失败且 `errno` 将设置为 `EBADF`。
- **Pos**: 这是一个指向变量的指针，告诉从流开始移动多少字节。调用函数后，该位置引用的值将是流的实际位置，这可能与你意图移动的位置不同。

## 返回值

成功后，函数返回 0。如果函数失败，将返回 -1。

## 另请参阅

- `fseek`
- `ftell`
- `fgetello`
- `ftell64`

## 示例

### 列表 3.54 - 使用 fsetpos 函数

```pascal
var
  dataFile: POFile;
  dataFile_bookmark: TFPos;

procedure TFrmMain.btnGotoBookmarkClick(Sender: TObject);
begin
  //跳转到书签位置
  fsetpos(dataFile, @dataFile_bookmark);
end;
```

# fstat, fstat64 (LibC.pas)

## 语法

```pascal
function fstat(
  FileDes: Integer;
  var StatBuffer: TStatBuf
): Integer;

function fstat64(
  FileDes: Integer;
  var StatBuffer: TStatBuf
): Integer;
```

## 描述

`fstat` 函数返回关于给定文件的信息。这类似于 `stat` 函数，但它不是通过文件名获取文件信息，而是通过传递打开的文件描述符获取信息。

## 参数

- **FileDes**: 这是一个通过 `open` 函数或其他返回有效文件描述符的函数打开的有效文件描述符。
- **StatBuffer**: 这是一个包含文件详细信息的 `TStatBuf` 变量。

## 返回值

此函数在成功时返回 0。`fstat` 失败最可能的原因是 `FileDes` 不是有效的文件描述符。

## 另请参阅

- `open`
- `stat`

## 示例

### 列表 3.55 - 使用 fstat 函数

```pascal
procedure TForm1.ButtonClick(Sender: TObject);
var
  fd: Integer;
  buf: TStatBuf;
begin
  if OpenDialog1.Execute then
  begin
    fd := open(PChar(OpenDialog1.Filename), O_RDONLY);
    fstat(fd, buf);
    close(fd);
  end;
end;
```

# fwrite, write_unlocked (LibC.pas)

## 语法

```pascal
function fwrite(
  const ptr: Pointer;
  Size: LongWord;
  N: LongWord;
  Stream: PIOFile
): LongWord;

function write_unlocked(
  const Ptr: Pointer;
  Size: Integer;
  N: LongWord;
  Stream: PIOFile

```

## 描述

`fwrite` 向打开的流写入指定大小的块。

## 参数

- **ptr**: 指向写入文件流的数据指针。

- **Stream**: 这是打开的流。

## 返回值

此函数返回 `N` 参数中定义的成功写入文件流的块数。如果函数失败，则返回 -1，并在下一次调用 `errno` 时将返回相应的错误代码。
