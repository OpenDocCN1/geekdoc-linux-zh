# 杀真菌

菌丝是无隔的、多核的，具有分支的菌丝，每个细胞含有一个到少数几个核。菌隔由几丁细胞壁组成，位于侧分裂的细胞中。大多数菌丝是无色的，尽管可以分泌多种色素到培养基或菌丝内。菌丝密度随类型而异并保持变化。

每个菌丝通过繁殖产生没有有性融合元素。最常见和重要的无性繁殖方式是各种类型的孢子掉落、飘散或从母菌丝分离。

有性繁殖发生在大多数物种中。繁殖和细胞融合通过不同的有性机制实现，涉及分化细胞（配子）、未分化细胞（配子）和减数分裂。

真菌从环境中获得有机食物。真菌是异营养的，无法制造自己的食物。它们通过向环境释放酶来消化食物。营养被真菌体吸收运输到各个位置，在那里通过化学反应转化为新细胞或其他用途。真菌生长的副产物也释放到环境中。

真菌可能用于医学、食品生产和提供植物原料，但少数是致病性的。真菌在维持真菌功能起着至关重要的作用，因为它们的腐烂将营养释放到周围的生态系统中，包括人类在内的其他生物可以重新利用。生物学：生态学。许多真菌是腐生的。真菌在死植物的分解中起着至关重要的作用，并可能导致小麦腐或玉米腐等疾病。见真菌生态学。

真菌可以生长在木材和土壤上，以及经济重要的植物上。某些真菌可以生长在玉米和水果上。真菌产生的毒素会导致人类动物的过敏反应或中毒。许多真菌具有从皮肤或猫、狗和人类等活体获取食物的能力。疾病真菌可以生长在虫的神经系统中，虫具有利用皮肤或头发成分作为食物源的生理能力。人类常见的疾病真菌是少数通常与人类相关的真菌之一（白色念珠菌）。见病理学：医学真菌学；植物病理学。见生物学：工业微生物学：YAST。
