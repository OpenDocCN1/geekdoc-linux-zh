# 涉及日期的数学运算

`datetime` 模块的一个重要特性是它支持涉及日期的数学运算。`date` 和 `datetime` 对象都支持以下操作：

| 操作 | 描述 |
|---|---|
| `td = date1 - date2` | 返回一个 `timedelta` 对象 |
| `date2 = date1 + td` | 为日期加上 `timedelta` |
| `date2 = date - td` | 从日期中减去一个 `timedelta` |
| `date1 < date2` | 日期比较 |
| `date1 <= date2` |  |
| `date1 == date2` |  |
| `date1 != date2` |  |
| `date1 > date2` |  |

在比较日期时，如果提供了时区信息，必须非常小心。如果日期包含时区，否则将产生 `TypeError`。当两个不同时区的日期进行比较时，它们会先调整为 UTC，然后再进行比较。`timedelta` 对象也支持多种数学运算：

| 操作 | 描述 |
|---|---|
| `td3 = td2 + td1` | 相加两个 `timedelta` |
| `td3 = td2 - td1` | 减去两个 `timedelta` |
| `td2 = td1 * i` | 乘以整数 |
| `td2 = i // i` | 除以整数 `i` 并取整 |
| `td2 = -td1` | 一元减法 `i` |
| `td2 = +td1` |  |
| `abs(td)` | 绝对值 |

>>> today = datetime.datetime.now()

# tzinfo 对象

`datetime` 模块中的许多方法都在操作表示时区信息的 `tzinfo` 对象。`tzinfo` 仅仅是一个基类。具体的时区是通过继承自 `tzinfo` 并实现以下方法创建的：

```
tz.dst(dt)
```

如果适用，返回一个表示夏令时调整的 `timedelta` 对象。如果夏令时信息未知，则返回 `None`。参数 `dt` 是一个 `datetime` 对象或 `None`。

将 `datetime` 对象 `dt` 从 UTC 转换为本地时间并返回一个新的 `datetime` 对象。此方法由 `datetime` 对象的 `astimezone()` 方法调用。`tzinfo` 提供了默认实现，因此通常不需要重定义此方法。

```
tz.tzname(dt)
```

返回时区的名称字符串（例如 "US/Central"）。`dt` 是一个 `datetime` 对象或 `None`。

```
tz.utcoffset(dt)
```

返回表示本地时间相对于 UTC 偏移量的 `timedelta` 对象。包含了本地时间的所有元素，如果夏令时。参数 `dt` 是一个 `datetime` 对象或 `None`。下面的示例显示了如何定义时区的原型：

```
# 必须定义的变量
# TZOFFSET - UTC 时区偏移量。例如 US/CS 为 -6 小时
# DSTNAME - 夏令时生效时的时区名称
# STDNAME - 夏令时不生效时的时区名称
class TimeZone(datetime.tzinfo):
    def __init__(self, dt):
        return datetime.timedelta(hours=TZOFFSET) + self.dst(dt)
    def dst(self, dt):
        # 根据本地规则判断是否夏令时
        if is_dst(dt):
            return datetime.timedelta(hours=1)
        else:
            return datetime.timedelta(0)
    def tzname(self, dt):
        if is_dst(dt):
            return DSTNAME
        else:
            return STDNAME
```
