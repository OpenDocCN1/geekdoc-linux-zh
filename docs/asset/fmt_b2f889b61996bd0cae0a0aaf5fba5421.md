### 3.4.2 偏航模型识别

遥控无人水器偏航模型的简化描述定义为

```
$N_r\dot{r} + N_{|r|}|r|\dot{r} + N_p\mathbf{r} = N$
```

```
$$\dot{\psi} = r$$
```

其中 `$N_p$` 是偏航方向的附加惯量（`$I = I_r + N_p$`），`$N_r$` 是偏航方向阻力的线性分量，`$N_{|r|}$` 是偏航方向阻力的二次项分量。此外，`r` 是航向速度，`$\dot{r}$` 是航向加速度，`N` 是由于推进器（T1、T2、T5 和 T6）作用于遥控无人水器的力矩，`$\psi$` 是航向角。
