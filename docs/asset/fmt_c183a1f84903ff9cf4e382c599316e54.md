## 简单格式化工具

我们先看一些简单的格式化工具。这些大多数是单用途程序，在功能上并不复杂，但它们可以用于简单任务，并作为流水线和脚本的一部分。

## 行号

`n1` 程序是一个相当晦奥的工具，用于执行一个简单的任务：行号。在最简单的形式下，它类似于 `-n`。

```bash
me@linuxbox]$ $ n1 distros.txt | head
1 SUSE 10.2 12/07/2006
2 Fedora 10 11/25/2008
3 SUSE 11.0 06/19/2008
4 Ubuntu 8.04 04/24/2008
5 Fedora 8 11/08/2007
6 SUSE 10.3 10/04/2007
7 Ubuntu 6.10 10/26/2006
8 Fedora 7 05/31/2007
9 Ubuntu 7.10 10/18/2007
10 Ubuntu 7.04 04/19/2007
```

像 `cat` 一样，`n1` 可以接受多个文件作为命令行参数或标准输入。然而，`n1` 有一个支持原始形式标记的数字，允许更多类型的编号。`n1` 支持一个名为“逻辑页”的概念。这允许 `n1` 在编号时重置（重叠）数字序列。通过选项，可以将数字设置为特定值，并在有限的范围内设置其格式。逻辑页进一步细分为页眉、正文和页脚。在编号时，可以使用选项来重置数字序列。如果给定的 `n1` 多个文件，它将它们视为单个流。文本中的节是由标记的存在指示的，如表 21-1 所示。

### 表 21-1：标记

| 标记 | 含义 |
| :--- | :--- |
| :- | 页眉 |
| :- | 正文 |
| :- | 页脚 |

表 21-1 中列出的每个标记必须单独出现。在处理后，`n1` 将其从文本流中删除。

### 表 21-2：选项

| 选项 | 含义 |
| :--- | :--- |
| -b | 设置样式，样式有以下之一：a = 所有行，t = 非空行。这是默认值。 |
| -f | 设置页脚。默认值为无。 |
| -h | 设置页眉。默认值为无。 |
| -n | 设置编号。默认值为 1。 |
| -o | 设置格式，格式有以下之一：l = 左对齐，r = 右对齐。这是默认值。 |
| -p | 不在页首处重置编号。 |
| -s | 在行尾添加字符串。默认值为分隔符。 |
| -v | 设置逻辑页的第一行数字。 |
| -w | 设置行的宽度。默认值为 6。 |

诚然，我们可能不会经常使用 `n1` 来构建，但我们将通过我们的文本编辑器修改脚本并将其保存为 `distros-n1`。

```sed
# 用于生成 Linux 发行版的脚本
1
:-
Linux Distributions
Name    Ver.    Released
:-
s/\([0-9]\{2\}\)\([0-9]\{2\}\)/\1
End Of Report
```

脚本现在了 `n1` 逻辑页标记并在结尾添加了页脚。我们需要双写反斜杠，因为它们会被 `sed` 解释为转义字符。

接下来，我们将结合 `sort`、`sed` 和 `nl` 生成我们的增强报告。

```bash
me@linux ~]$ sort -k 1,1 -k 2 distros.txt | sed -f distros-nl.sed | nl
```

# fold–将每行折叠到指定的长度

折叠是在指定的宽度折断文本行。与我们的其他命令一样，`fold` 接受一个或多个文件或标准输入。

```bash
me@linuxbox ~$ echo "The quick brown fox jumped over the lazy dog." | fold -w 12
The quick br
own fox jump
ed over the
lazy dog.
```

在这里我们看到了 `fold` 的动作。`echo` 命令发送的文本按照 `-w` 选项指定的段进行折叠。在这个示例中，我们指定了 12 个字符的行宽。如果不指定宽度，默认为 80 个字符。注意无论是否跨单词边界，行是如何折断的。添加 `-s` 选项将使 `fold` 在达到行宽之前的最后一个可用空格处断行。
