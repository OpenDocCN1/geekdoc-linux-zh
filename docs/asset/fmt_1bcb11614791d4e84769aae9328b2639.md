在确定电极电位时，有几个复杂因素。首先，根据能恩斯特方程（Nernst equation），这两个参数之间的差异很少恒定。

对于具有价态 `z` 离子的金属，电势差 `E` 用标准电位表示，该电位通过能恩斯特方程（1）取决于这些离子在溶液中的活性和浓度，其中 `R` 是气体常数，`T` 是温度，`F` 是法拉电量。

其次，电势差的测量可能涉及比测量本身更多。由于此类测量涉及差异，可能对该差异没有可靠的信息；即电势差是由溶液引起的、另一方引起的，还是单独引起的。这是一个令人关注的问题。问题通常以氧化电位的形式表述。

```
E = E' + (RT/zF)ln c
```

当金属离子处于溶液盐中时，通过沉积与阴离子（负离子）浓度成正比的阳离子（正离子），可以将盐转化为电极。典型的示例是基于氯化银（AgCl）溶解性的银电极，以及基于氯化汞（Hg2）低溶解性的甘汞电极。

测量电极电位四种方法：(1) 建立系统的氧化和还原电位；(2) 使用电极的自电化学法；(3) 作为平衡数据的来源；(4) 电极研究中的主要（独立）变量。

金属与电解质之间可以建立电化学电位，当金属包含一个偶对，即一对通过增加或提取电子（还原或氧化）可以相互转换的化学成分。在这种情况下，金属通常充当电子的供应者或接收者。当金属溶解在电极上时，溶液从金属中提取电子，还原物对被氧化。电荷分离的积累产生了电势差，它会反对电化学电位，直到系统达到电势差恰好等于还原速率的状态。电化学电位的平衡取决于氧化物种（ox）的浓度和转移的电子数（n）。

```
E = E' + (RT/nF)ln [ox/red]
```

在反应 `Ox + e^- → Red` 中转移了氧化物种（Ox）和还原物种（Red）。一个典型的例子是氢离子 `H^+` 还原为氢气 `2H^+ + 2e^- → H_2`，其能恩斯特方程为：

```
E = E' + (RT/2F)ln (H2/[H+]2)
```
