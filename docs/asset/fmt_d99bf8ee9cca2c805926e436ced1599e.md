2.4.x 及更高版本的内核包含了对专用 `/dev` 文件系统的支持，这消除了基于磁盘的 `/dev` 目录存放文件的需求；因此，从某种意义上说，`dev` 可以位于独立的文件系统中，而不是独立的分区。在最近版本的 Linux 中，`udev` 工具控制着 `/dev` 文件系统。

# 创建分区和文件系统

如果你在计算机上安装 Linux，很可能会有一个工具向你，引导你完成分区过程。这些安装工具将创建你要求它们创建的分区，或者创建发行版维护者认为合适的尺寸的分区。但是，如果你需要对添加的新硬盘进行分区，或者你想使用标准的 Linux 工具而不是依赖发行版的安装工具来创建分区，你必须了解完成此任务的 Linux 程序。分区涉及两个任务：创建分区和准备分区以供使用。在 Linux 中，这两个任务通常使用不同的工具完成，尽管某些工具可以同时处理这两个任务。

# 现实场景

## 何时创建多个分区

拆分许多独立分区的一个问题，特别是对于新管理员来说，是很难确定合适的分区大小。如表 3.4 所示，各种分区的合适尺寸在不同系统之间可能大不相同。例如，工作站可能需要一个较小的 `/var` 分区（例如 100MiB），但邮件服务器或新闻服务器可能需要一个几 GB 大的 `/var` 分区。猜测并不是致命的，但它很烦人。你可能需要调整分区大小（这是枯燥又危险的），或者在分区之间建立符号链接，以便一个分区上的子目录可以存储在其他分区上。`LVM` 可以简化事后的更改，但如之前所述，`LVM` 增加了自身的复杂性。

出于这个原因，我们通常建议新的 Linux 管理员尝试简单的分区布局。根（`/`）分区是必须的，`swap`（交换分区）是一个非常好的主意。除此之外，在大于 8GiB 的硬盘上，其他发行版或 BIOS 上的 `/boot` 可能有所帮助，但自 2000 年以来，计算机或发行版很少需要它。除了用户数据（`/home` 或其他地方），大多数 Linux 安装需要 5 到 25GiB，将根（`/`）设置为该范围内的值是有意义的。`/home` 的合适大小对于新管理员来说通常容易猜测，或者你可以在创建根（`/`）和交换分区之后，将所有磁盘空间留给 `/home`。在这些分区之外，我们建议新管理员谨慎进行。

随着你对 Linux 经验的增加，你可能想在随后的安装或升级磁盘硬件时，将其他目录拆分为它们自己的分区。你可以使用 `du` 命令来学习任何给定目录下的文件使用了多少空间。

# 磁盘分区

用于 MBR 磁盘分区传统的 Linux 工具称为 `fdisk`。该工具的名字是“fixed disk”（固定磁盘）的缩写，且与完成相同任务的 Windows 工具名称相同。（当我们指的是 Windows 工具时，会将名称大写，例如 `FDISK`。Linux 工具的名称始终全小写。）Windows 的 `FDISK` 和 Linux 的 `fdisk` 都是用于实现类似目标的的文本模式工具，但两者在操作细节上非常不同。

尽管 `fdisk` 是传统工具，但也存在其他工具。其中之一是 GNU `Parted`，它可以处理多种不同的分区表类型，而不仅仅是 `fdisk` 能够处理的 MBR。如果你倾向于使用 `fdisk` 而不是 GNU `Parted` 但使用 GPT，你可以使用 GPT `fdisk` ([http://www.rodsbooks.com/gdisk/](http://www.rodsbooks.com/gdisk/))；此包的 `gdisk` 程序工作方式与 `fdisk` 非常相似，但针对 GPT 磁盘。

# 使用 `fdisk`

要使用 Linux 的 `fdisk`，输入命令名后跟要分区的磁盘设备名称。例如，输入命令 `fdisk /dev/hda` 为主 PATA 磁盘分区。结果是一个 `fdisk` 提示符：

```
# fdisk /dev/hda
```

`Command (m for help):`

在 `Command (m for help):` 提示符提示 处，你可以输入命令来实现各种目标：

## 显示当前分区表

你可能想从显示当前分区表开始。为此，输入 `p`。如果只想显示当前分区表，可以在主提示符处输入 `fdisk -l /dev/hda`（或任何设备标识符）。此命令显示分区表并退出。

## 创建分区

要创建一个分区，输入 `n`。结果是一系列提示符，询问有关分区的信息——是主、扩展还是逻辑；分区的起始磁道；分区的结束磁道等等。如果已经存在扩展分区，`fdisk` 不会要求创建一个扩展分区。旧版本的 `fdisk` 以磁道为单位，而不是兆字节。新版本的 `fdisk` 使用扇区作为默认单位，尽管你可以通过加号、数字和后缀指定分区大小，例如使用 `+20G` 创建一个 20GB 的分区。

![](img/f74c2c51e1985d4d3a6804ba2887d2f4_296_0.png)

过去，分区对齐在 CHS 磁道上。这对于 80 年代的硬件是有益的，但在今天是有害的。许多现代磁盘要求分区对齐在 8 扇区或更大的边界以获得最佳性能。由于这个原因，最近的分区程序从 1MiB（2048 扇区）边界开始。未能正确对齐分区会导致严重的性能下降。更多此主题的信息

```
www.ibm.com/developerworks/library/4kb-sector-disks/index.html
```

## 删除分区

要删除分区，输入 `d`。如果存在多个分区，程序将询问分区编号，你必须输入。

## 更改分区类型

当你创建一个分区时，`fdisk` 为其分配类型代码 0x83，这对应于 Linux 文件系统。如果你想创建一个 Linux 交换分区或用于其他操作系统的分区，可以输入 `t` 来更改分区类型代码。程序随后提示输入分区编号和类型代码。

## 列出分区类型

存在多种分区类型代码，因此很容易忘记它们是什么。在主 `fdisk` 提示符处输入 `l`（那是小写的 L）可以查看常见列表。你也可以在更改分区类型提示分区类型时输入 `l` 获取此列表。

## 标记分区为可启动

某些操作系统（如 Windows）依赖其分区具有特殊的启动标志才能启动。你可以通过输入 `a` 来设置此标志，随后 `fdisk` 会询问分区编号。

# 获取帮助

输入 `m` 查看 `fdisk` 主命令的菜单。

# 退出

Linux 的 `fdisk` 支持两种退出模式。首先，你可以输入 `q` 退出程序而不保存任何更改；你在程序中进行的所有操作都将丢失。如果你犯了错误，这个选项将特别有用。其次，输入 `w` 会将你的更改写入磁盘并退出程序。
