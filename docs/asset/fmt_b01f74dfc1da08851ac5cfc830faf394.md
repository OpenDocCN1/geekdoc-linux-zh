
# 遗传性状的孟德尔规律由奥古斯特·孟德尔于 1856 年发现。孟德尔在豌豆植物上进行了首次杂交实验。这些植物很容易杂交，并在一个季节内成熟。纯种植物种子从当地市场获得。对于他的实验，孟德尔选择了某些性状。纯种高（70 cm 或以上）和矮（18 cm 或以下）植物也被用于其他六种性状，涉及种子的高度和颜色、花的位置。

孟德尔最简单的杂交涉及一对性状；每个实验被称为单杂交。作为这些实验父母的植物被称为 `P1`（第一代）。当高矮植物杂交时，后代（`F1` 或第一代）都是高。当 `F1` 代的成员自交时，1064 个 `F2` 代中有 787 个高。高性在 `F1` 中表达，但在 `F2` 中重新出现。而隐性在 `F1` 中表达，但在 `F2` 中重新出现。

分离定律。在单杂交实验中，每个性状最初被一个因子（现在称为基因）主导。隐性因子在一个代中被掩盖，并在 `F2` 代中重新出现。孟德尔发现隐性植物育纯，而显性植物中产生了纯系和隐性类型。

如果将隐性与显性因子杂交，那么产生的因子数量将减少。`F1` 产生两种类型的配子，一个包含所有性状的因子，另一个包含矮性。在受精时，这些基因的随机组合解释了 `F2` 代中重新出现的类型和比例（见图）。参见代（GENERATION）。

单杂交的示意图。纯种高系和矮系被杂交，在第二代产生典型的 3:1 的高矮比例。因子（基因）的随机组合解释了结果。（参考 W. S. Klug 和 R. M. Cummins, 《遗传学概念》，Charles E. Merrill, 1983）

## 1354 含义

**自由组合**：孟德尔胆于同时观察性状遗传。这种杂交涉及两对对立性状，例如，孟德尔将高茎植物与矮茎植物杂交，产生的后代全是高茎且全是圆叶。在对 `F1` 代进行后续观察时，产生了以下结果：9/16 高茎，3/16 皱叶；3/16 矮茎，1/16 圆叶。根据其他结果，孟德尔提出在配子形成过程中，因子对相互独立组合。由于自由组合的结果，每个性状按一定的频率遗传。

细菌性脑膜炎因其持续性、严重性和高发病率，成为人类最常见的传染性疾病之一。大多数脑膜炎病例涉及大脑损伤，且通常发病急性。常见症状包括发热、头痛、呕吐、颈硬、嗜睡和昏迷。脑功能障碍症状是由细菌毒素进入脑脊液并破坏脑血管炎症引起的。

可以将双双杂交看作是两个同时且独立的孟德尔杂交。在这种情况下，结果为 3/4、1/4、3/4、1/4，这与观察到的比例一致。表型的数量可以通过结合两者来预测：

| 比例 | 计算方法 |
| :--- | :--- |
| 3/4 | (3/4)(3/4) = 9/16 高茎、圆叶 |
| 1/4 | (3/4)(1/4) = 3/16 皱叶 |
| 1/4 | (1/4)(3/4) = 3/16 矮茎、圆叶 |
| 1/4 | (1/4)(1/4) = 1/16 矮茎、皱叶 |

大多数类型的细菌脑膜炎是血源性的，或者是当细菌进入脑组织（菌血症、败血症）时发生。脑膜炎由原发性细菌脑膜炎引起。继发性脑膜炎发生在细菌进入中枢神经系统之后，可能发生在神经外科手术、外伤或外部环境与脑液之间的异常交通中。

这种 9:3:3:1 的比例是分离、自由组合和随机受化的结果。见 遗传学（GENETICS）。

许多病毒可引起脑膜炎症，这种被称为病毒性脑膜炎。最常见的病毒原体是肠道病毒、通过叮咬传播的病毒、I 型人类免疫缺陷病毒（HIV）和腮腺病毒。如果病毒影响脊髓硬膜，则称为脑炎。见 脑炎（ENCEPHALITIS）；炎（ERITIS）；疱疹（HERPES）。

真菌、寄生虫和结核性脑膜炎比细菌和病毒感染常见。与细菌或病毒脑膜炎相比，这些更有可能是亚急性或慢性的。急性脑膜炎炎症也可能影响蛛网膜腔。见 （LIFE DISEASE）；莱姆病（Ly disease）；医学（MEDICAL）；梅毒（SYPHILIS）。

## 脑膜

覆盖大脑和脊髓的三层膜是硬膜、蛛网膜和软膜。硬膜是一种坚韧的纤维性双层结构，附着在颅骨上。硬膜的内层向大脑和脊髓发出脑片。这些脑片位于蛛网膜和软膜之间。这个空间是蛛网膜腔，内含有脑脊液。内层是软膜，是一个血管层，顺着硬膜的每个轮廓延伸。脑膜为大脑提供保护、血液供应、引流通道。见 脊椎动物神经系统（NERVOUS SYSTEM (VERTEBRATE)）。

## 脑膜炎菌

属于奈瑟菌属（*Neisseria*）的主要病原体，是脑膜炎菌脑膜炎的病因。正式名称为脑膜炎球菌（*Neisseria meningitidis*）。

脑膜炎菌是一种革兰阴性、需氧、双球菌，发现于人类鼻咽，对物理和化学条件非常敏感。

人类是脑膜炎菌唯一的天然宿主。传播主要通过人与人之间的飞沫发生。女性和成年人在这种传播中可能不利。最常见的宿主寄生关系是人体无症状携带。

脑膜炎最常见的临床综合征特征为发热、头痛、恶心、呕吐和颈硬。婴儿和成年人中占 15%。意识状态可能紊乱，导致昏迷。许多病例还有典型的出血皮疹或紫癜斑点。

## 绝经

女性规律子宫出血的不可逆性停止，标志着其怀孕能力的结束。

绝经通常发生在 47 岁，通常在 45 到 55 岁之间。它极可能是因为卵巢耗尽了卵子，旨在准备子宫退缩且不再怀孕的大脑和卵巢激素循环不再发生。

绝经是周期性时间段中的一个事件，期间生殖机制减慢并最终停止。其生物化学标志是雌激素产生的减少。由于全身脂肪组织的正常下降会继续产生一些雌激素，但这种水平维持在绝经后水平。雌激素对生殖系统和外部系统都有广泛影响，而雌激素的撤退会导致许多压力信号和社会因素。许多心理问题被归因于雌激素缺乏，但缺乏这些关系的详尽证明。

虽然绝经可能提早发生上述描述的许多身体变化，但它不能防止衰老或恢复能力。绝经症状的治疗应根据个体进行，并仔细考虑涉及的风险和收益。见 绝经（MENOPAUSE）。

## 硫醇 (Mercaptan)

硫醇是一类有机硫化合物，也称为硫醇或硫化合物，具有通式结构。它们包括烷基硫醇和芳香烃，并通常指具有溶解性的硫醇。硫醇等挥发性化合物的难闻气味使其带有臭味味，但许多溶解硫化物的气味并不难闻。硫醇 (1) 与碱成盐，易于被氧化为磺酸，(2) 与氯（或溴）反应，以及 (3) 在还原下形成硫化合物，如亚硫醚、醛和酮类。硫醇的不溶性使其难以被鉴定。有机化合物。

## 商船 (Merchant ship)

一种在海洋及五湖等大型内陆水域作业的动力船。用于水路运输的小型船舶通常被称为岸运船。这些船运载散装、单元箱货物（液体或干货）。通常，水路货物运输的每吨里程成本低于航空或陆路；美国约 90% 的出口是通过水路进行的。岸运船。

## 汞（元素）

一种化学元素，Hg。原子序数 80，原子量 200.9。汞在室温下为白色液体（熔点 -38.9°C 或 -37.4°F）；在大气压力下在 357.25°C（675.0°F）沸腾。它不是一种溶于氧化性酸的金属。汞金属及其化合物具有剧毒。与许多金属（例如金、银、铀、铜、铅、钠、钾）结合时，汞称为合金。见合金。周期表元素。

在它的化合物中，汞以 2+ 和 +1 氧化态存在，例如 Hg2、HgCl2 或 Hg。原子间呈双共价键，例如 Cl-Hg-Cl 或 Cl-Hg-Hg-Cl。汞（II）盐（如 HgCl 或 HgI）也溶于水，但在溶液中只有少量分子解离。汞原子与碳或氮原子结合，例如 H-C-Hg-CH3 或 H2C-NO-Hg-NO-CH2H。在这些化合物中，汞通常具有三个或四个键。

金属汞用作电气开关的液体接触金属，在真空技术中作为扩散泵的工作流体，用于制造汞蒸温度计、温度计、恒温器以及制造汞蒸灯。它还用于汞合金充齿。它在电化学中的重要性在于标准甘汞电极（用作电位测量和电位滴定的参考电极）以及威斯顿电极。
