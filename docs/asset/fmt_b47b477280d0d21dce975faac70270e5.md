`GtkFrame` 是一种容器控件，用于使子控件的显示更具吸引力，因为它提供了一个装饰性边框和一个可选标签。图 19.2 显示了一个简单框架控件的示例。

使用 `gtk_frame_new()` 创建框架控件。返回新的框架控件。`gtk_frame_new()` 的参数如下：

| 参数 | 描述 |
|---|---|
| `label` | 显示在框架上的标签。可以为 NULL。 |
| `xalign` | 标签的对齐方式（在 0.0 到 1.0 之间，包含边界）。值 0.5 将标签置在轴线中间。 |
| `yalign` | 在发布中未实现。 |
