# ExtendedStatus 配置

`ExtendedStatus`：控制 Apache 在调用 `server-status` 处理程序时生成“完整”状态信息（`ExtendedStatus On`）还是仅生成基本信息（`ExtendedStatus Off`）。默认为 `Off`。

`#ExtendedStatus On`

## 第 2 节：'主' 服务器配置

此部分中的指令用于设置由 '主' 服务器使用的值，该服务器响应那些未被 `<VirtualHost>` 定义处理的任何请求。这些值也为文件中后续定义的 `<VirtualHost>` 容器提供默认值。

所有这些指令都可以出现在 `<VirtualHost>` 容器中，在这种情况下，将为正在定义的虚拟主机覆盖这些默认设置。

如果你的 `ServerType` 指令（在'全局环境'部分中稍早设置）设置为 `"inetd"`，接下来的几个指令没有任何效果，因为它们的设置由 `inetd` 配置定义。直接跳到 `ServerAdmin` 指令。

### Port

独立服务器监听的端口。对于小于 1023 的端口，最初需要以 root 身份运行 `httpd`。

`Port 80`

如果你希望 `httpd` 以不同的用户或组运行，你必须最初以 root 身份运行 `httpd`，然后它会进行切换。

### User/Group

用于以 `httpd` 身份运行的用户/组的名称（或数字）。

`. 在 SCO (ODT 3) 上使用 "User nouuser" 和 "Group nogroup"。`

`. 在 HP-UX 上，你可能无法使用 nobody 作为共享内存，并且建议的变通方法是创建一个用户 www 并使用该用户。`

请注意，某些内核拒绝在 `(unsigned)Group` 的值大于 60000 时设置 `setgid(Group)` 或 `semctl(IPC_SET,`，在这些系统上不要使用 `Group nobody`！

`User apache`

`Group apache`

### ServerAdmin

你的地址，服务器有问题时应发送电子邮件的地方。此地址会出现在某些服务器生成的页面上，例如错误文档。

`ServerAdmin webmaster@gnulix.org`

### ServerName

允许你设置一个主机名，如果它与程序获取的主机名不同（即，使用 `"www"` 而不是主机的真实名称），服务器会将其发送回给客户端。

注意：你不能只是凭空发明主机名并希望它们能工作。你在这里定义的名字必须是你主机的有效 DNS 名称。如果你不理解这一点，请咨询你的网络管理员。

如果你的主机没有注册的 DNS 名称，请在此处输入其 IP 地址。你将不得不通过其地址访问它（例如，`http://123.45.67.89/`）无论如何，这将使重定向以合理的方式工作。

`#ServerName localhost`

### DocumentRoot

你提供文档的目录。默认情况下，所有请求都取自此目录，但可以使用符号链接和别名指向其他位置。

`DocumentRoot "/var/www/html"`

Apache 可访问的每个目录，都可以根据该目录（及其子目录）中允许和/或禁用的服务和功能进行配置。

首先，我们将“默认值”配置为非常严格的权限集。

```
<Directory />
    Options FollowSymLinks
    AllowOverride None
</Directory>
```
