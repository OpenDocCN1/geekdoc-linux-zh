
# 脂质

脂质存在于所有活细胞中，但在不同组织中的比例不同。三酰甘油积聚在某些脂肪细胞中，如人体和植物种子中的脂肪组织，在那里它们代表一种能量储存形式。更复杂的脂质与蛋白质紧密结合，存在于细胞和亚细胞颗粒的膜中。活性更高的组织通常含有更高含量的复合脂质；例如，在哺乳动物中，大脑、肝脏、肾脏、肺和血液含有最高浓度的磷脂。参见 [脂肪和油](https://example.org/fat-and-oil)；[脂肪和油（食品）](https://example.org/fat-and-oil-food)；[糖脂](https://example.org/glycolipid)；[鞘脂](https://example.org/sphingolipid)；[类固醇](https://example.org/steroid)；[萜类](https://example.org/terpene)；[三酰甘油](https://example.org/triglyceride)；[维生素](https://example.org/vitamin)；[动物和植物蜡](https://example.org/wax-animal-and-vegetable)。 [R.H.G.J]

## 脂质代谢

膳食脂质的吸收以及脂质的合成和降解；本文限于哺乳动物。

主要的膳食脂肪是三酰甘油。这种物质不在胃中被消化，而是进入十二指肠，在那里它引起肠促胰液素的释放，这是一种抑制胃运动的激素。因此，膳食中脂肪的含量调节着肠促胰液素释放到肠道的速率。脂肪与其他部分消化的食物一起，引起激素从十二指肠壁释放到血液中，这些激素包括促胰液素、胰酶素和胆囊收缩素。

促胰液素引起富含碳酸氢根离子的碱性胰液的分泌，而胰酶素引起胰酶的分泌。其中一种对脂肪消化很重要的酶是脂肪酶。胆囊收缩素是一种化学上可与胰酶素分离的蛋白质物质，它刺激胆囊将胆汁释放到十二指肠。胆汁由肝脏分泌并在胆囊中浓缩，含有两种胆汁盐，均由胆固醇衍生而来：牛磺胆酸和甘氨胆酸。这些盐通过乳化肠道中的三酰甘油起去污剂的作用，从而使脂肪更容易受到胰脂肪酶的攻击。在这个反应中，其在胰液提供的碱性介质中效果最好，每个三酰甘油分裂成三个脂肪酸链，形成单甘酯。脂肪酸穿过肠黏膜（衬里）细胞的膜。膜中的酶将单甘酯分解为甘油和脂肪酸，但三酰甘油会在黏膜细胞内由甘油和链长大于八个碳的脂肪酸重新形成：短链和中链脂肪酸一旦穿过肠黏膜，就直接被吸收到血液中。参见 [胆固醇](https://example.org/cholesterol)；[消化系统](https://example.org/digestive-system)；[胆囊](https://example.org/gallbladder)；[肝脏](https://example.org/liver)；[胰腺](https://example.org/pancreas)；[三酰甘油](https://example.org/triglyceride)。

肥胖是一种脂肪在脂肪组织中过度积累的状态。导致这种情况的一个因素是热量摄入过多。在饥饿、未控制的糖尿病和许多全身性疾病中，情况相反，脂肪组织中的脂质明显耗竭。参见 [脂肪组织](https://example.org/adipose-tissue)；[糖尿病](https://example.org/diabetes)；[脂质](https://example.org/lipid)；[代谢障碍](https://example.org/metabolic-disorders)；[肥胖](https://example.org/obesity)。 [M.A.J]

## 脂蛋白

由蛋白质与脂质结合形成的结合蛋白的一类。高等生物的正常功能需要在组织间移动不溶性脂质，如胆固醇、固醇激素、胆汁和三酰甘油。为了实现这种移动，脂质被结合到称为脂蛋白的大分子复合物中。

所有主要类型的脂蛋白都共享一种通用结构。这些球形颗粒的核心主要含有胆固醇酯和三酰甘油。这些不溶性分子被一层蛋白质和磷脂包裹，它们具有两亲性；也就是说，它们既有极性区域也有非极性区域。脂蛋白的大小和密度各异。最大的脂蛋白乳糜微粒直径可达 500 纳米，由于主要含有三酰甘油，它们的浮力很大，以至于在血浆中会漂浮。极低密度脂蛋白（VLDL）也主要运输三酰甘油。低密度脂蛋白（LDL）和最小、密度最高的脂蛋白高密度脂蛋白（HDL）则运输胆固醇。这些颗粒与细胞表面受体以及代谢酶之间的相互作用由颗粒的蛋白质成分介导，这些成分被称为载脂蛋白。参见 [胆固醇](https://example.org/cholesterol)；[三酰甘油](https://example.org/triglyceride)。

乳糜微粒含有来自膳食的三酰甘油（脂肪）。此外，它们还将脂溶性维生素（如维生素 A 和 E）带入循环系统。乳糜微粒在肠道中产生，通过淋巴系统进入体内，然后进入血液。

极低密度脂蛋白在肝脏中合成，含有三酰甘油，这些三酰甘油要么由过量的碳水化合物或热量来源合成，要么由进入肝脏并重新组装成三酰甘油的脂肪酸合成。脂蛋白脂肪酶（LpL）是一种存在于血管表面的酶，负责分解脂蛋白中的三酰甘油。部分降解的脂蛋白被称为残粒。它们最终由肝脏从循环中清除。

低密度脂蛋白是在极低密度脂蛋白去除了三酰甘油后形成的。这留下了一种更小、更致密的颗粒，其核心脂质主要含有胆固醇酯，以及一种称为 apB 的单一蛋白质。全身各处的细胞都含有识别 apB 的 LDL 受体。这使得低密度脂蛋白能够被细胞摄取，从而为细胞提供胆固醇。当低密度脂蛋白和胆固醇供应充足时，细胞会优先使用它们，而不是从头合成新的胆固醇。相比之下，高密度脂蛋白既将胆固醇输送到组织，又从组织中移除胆固醇。

血液中的脂蛋白水平是调节冠状动脉微循环发展风险的主要因素。通过未知的机制，低密度脂蛋白和残粒脂蛋白渗入动脉并附着在细胞外基质分子上。一些脂蛋白被巨噬细胞和平滑肌细胞内化。这首先可能触发化学修饰，如脂质氧化。由此产生的病理学发现是胆固醇沉积在血管壁内的细胞和基质中，导致动脉直径减小。

相比之下，高密度脂蛋白似乎能防止动脉粥样硬化的形成。其原因尚未完全理解。最有可能的是，高密度脂蛋白移除了积聚在动脉中的过量胆固醇，或者防止了低密度脂蛋白的氧化。参见 [动脉粥样硬化](https://example.org/arteriosclerosis)。 [LJ.Go]

## 脂质体

脂质体是由脂质双分子层膜包围的隔室。脂质体也被称为脂质小体。磷脂分子由一个细长的脂质（疏水）结构组成，其一端具有极性（亲水）结构。当分散在水中时，它们自发地形成双分子层膜，也称为层状结构，由两层脂质分子单层组成，其非极性（疏水）表面相对，而极性（亲水）表面朝向水相介质。膜包围了一部分水相，就像包围细胞的细胞膜一样；事实上，双分子层膜基本上就是没有蛋白质成分的细胞膜。

脂质体常被用于研究脂质双分子层的特性。脂质体的特性已通过多种技术表征：通过 X 射线衍射、核磁共振参数、电阻率和拉曼光谱法研究分子排列；通过量热法研究熔化行为（即晶体到液晶的转变）；通过微电泳法研究净表面电荷；通过光散射和电子显微镜研究尺寸。参见 [脂质](https://example.org/lipid)。

脂质体作为生化和生物物理工具有许多用途：(1) 作为向细胞递送水溶性和脂溶性物质的载体；(2) 作为免疫佐剂；(3) 作为研究膜特性（如膜平面内的旋转或平移扩散）的替代物；以及 (4) 作为构建足够大的双分子层以研究膜电学特性的中间体。参见 [细胞膜](https://example.org/cell-membranes)。 [RC.Mad, RIMacD]

## 气体液化

将气体冷却至低于其临界温度的过程，以便在合适的（同样低于临界压力的）压力下形成液体。

气体液化是气体制冷的一个特例。气体首先在环境温度压缩机中被压缩到较高的压力。这种高压气体通过逆流换热器流向节流阀或膨胀机。在膨胀到较低压力时，可能会发生冷却，并形成一些液体。冷却后的低压气体返回压缩机入口以重复该循环。逆流换热器的目的是在压缩前加热低压气体，同时尽可能冷却高压气体直到扩张前的最低温度。制冷机和液化器都基于这一基本原理运行。参见 [压缩机](https://example.org/compressor)；[临界现象](https://example.org/critical-phenomena)；[气体](https://example.org/gas)；[换热器](https://example.org/heat-exchanger)；[制冷机](https://example.org/refrigerator)。

制冷机和液化器之间的一个重要区别在于，在连续制冷过程中，系统的任何部分都没有制冷剂的积累。这与气体液化系统形成对比，在后者中液体会积累并被取出。因此，在液化系统中，在逆流换热器中被加热的总气体量比被冷却的气体少，差值即为被液化的部分，从而在换热器中产生不平衡流动。在制冷机中，热气体和冷却气体在换热器中的流动是相等的。这导致平衡流动状态。制冷和液化的热力学原理是相同的。然而，由于制冷机中的平衡流动条件和液化器系统中的不平衡流动条件，这两种系统的分析和设计是相当不同的。
