# 安装 LINUX MINT 21.3 的分步指南：从键盘选择到最终重启

使用基于 `ubiquity` 的安装程序安装 Linux Mint 21.3 时，过程涉及几个关键步骤。这包括选择键盘布局、决定是否包含多媒体解码器、选择安装类型、配置时区、创建用户账户，以及最后在安装完成后重启电脑。本摘要提供了该过程的层级概览，不涉及详细操作说明。

## 在 Linux Mint 中选择正确的键盘布局

### 安装：步骤与意义

要开始安装 Linux Mint 程序，请遵循以下详细步骤：

1. 双击“Install Linux Mint”选项启动安装过程。
2. 当系统提示选择键盘布局时，导航到屏幕左侧并选择合适的布局。例如，你可能会选择“English (UK)”。
3. 接下来，在屏幕右侧选择相应的键盘子布局。在这种情况下，你也将选择“English (UK)”。
4. 一旦键盘布局和子布局被正确选择，点击“Continue”（继续）按钮继续安装过程。

### 关于安装多媒体解码器做出明智决策

请勾选标记为“Install multimedia codecs”（安装多媒体解码器）的复框，然后点击“Continue”按钮继续。

### 探索安装选项：Linux Mint 21.3 'VIRGINIA' 设置指南

在基于 `ubiquity` 的 Linux Mint 21 安装中，有三种安装选项：

- **与现有操作系统一起安装 (Install alongside existing operating system)**：此选项允许你快速方便地在同一块磁盘上的另一个操作系统旁安装 Linux Mint 21。它不需要删除任何数据或修改分区。
- **清除磁盘并安装 Linux Mint (Erase disk and install Linux Mint)**：通过选择此选项，将完全删除磁盘上的所有数据，并以预定的分区大小安装 Linux Mint 21.3 'VIRGINIA'。此选项适用于希望全新安装且不保留现有数据的用户。
- **其他（Something else）**：此选项为磁盘管理提供了更高级的功能。它允许在所选磁盘上创建、调整大小和修改分区。通过此选项，你对分区过程有更多的控制权，包括指定卷大小和类型的能力。建议对磁盘管理有更深理解并希望创建自定义功能性系统的用户使用。

虽然前两个选项（与现有操作系统一起安装和清除磁盘）提供了更简单的安装过程，但本文讨论将重点放在“其他”选项。该选项对磁盘管理、分区和卷配置提供了更全面的理解，这些是创建一个功能完整的 Linux Mint 21 系统的必要条件。

### 选择“一起安装”和“清除磁盘”：全面指南

要完成安装，请遵循以下步骤：

1. 找到并点击“Install Now”（现在安装）。
2. 检查将对磁盘所做的更改。
3. 检查更改后，点击“Continue”（继续）。

### 选择“其他”替代方案：详细指南

要在 1TB NVME SSD 上设置分区，请遵循以下步骤：

- 创建一个 EFI 分区（512 MB）。
- 分配 7160 MB 用于 SWAP 分区。
- 使用剩余空间作为根分区。

### 创建分区表

选择要分区的磁盘。如果所选磁盘没有分区表，点击“New Partition Table”（新建分区表），然后点击“Continue”。选择空空间。

### 设置 EFI 分区

点击 `+` 创建新分区。在“Size”字段中输入 1024 MB。将“Primary”切换为开启。将“Beginning of this space”开启。在“Use as”字段中选择“EFI”。点击“OK”确认。

### 配置 SWAP 分区

点击 `+` 添加另一个分区。在“Size”字段中输入 7160 MB。将“Primary”切换为开启。将“Beginning of this space”开启。在“Use as”字段中选择“swap area”（交换区域）。点击“OK”确认。

### 根分区分区 (/)

点击 `+` 创建新分区。对于“Size”，使用剩余空空间。将“Primary”切换为开启。将“Beginning of this space”开启。在“Use as”字段中选择 `Ext4` 日志文件系统。在“Mount point”字段中输入 `/`。点击“OK”确认。

### 完成安装

点击“Install Now”。检查磁盘更改以确保符合预期。点击“Continue”继续。通过遵循这些步骤，你可以有效地利用你的 1TB NVME SSD 以获得最佳性能和组织。

### 创建用户配置文件

要创建用户配置文件，点击标有“您的名称”（Your name）的框并输入您的姓名。

当你在“您的名称”旁边的框中输入时，“您的计算机名称”（Your computer's name）旁框将自动填充。

接下来，点击带有“选择用户名”（Pick a username）的框并输入您选择的用户名。

然后，点击带有“选择密码”（Choose a password）的框，选择一个高安全且易记的密码。

开启“登录时需要密码”（Require my password to log in）旁开关。

最后，点击“继续/安装”（Continue/Install）按钮继续。

### 完成安装

耐心等待安装过程完成。

安装完成后，点击“立即重启”（Restart Now）按钮。

重启后，请确保在主板 BIOS 标志出现之前移除 USB 驱动器。

## 配置启动序列

要在 MSI MAG B550 TOMAHAWK 主板上选择启动项，请遵循以下详细说明：

1. 移除 USB 驱动器后，在主板 BIOS 标志出现之前，一次、多次或连续按下指定的键（`F10` 或其他键）以进入主板 BIOS。这将允许你进入 BIOS。
2. 进入 BIOS 后，导航到启动菜单选项。
3. 在启动队列中找到 USB 驱动器并将其移动到列表末尾。这将确保系统在尝试从 USB 驱动器启动之前优先考虑其他启动选项。
4. 在 BIOS 设置中切换到高级模式（Advanced Mode）。
5. 在高级模式下，找到并选择设置（Settings）选项。
6. 从设置菜单中找到并选择启动（Boot）选项。
7. 在启动菜单中，搜索 UEFI 硬盘优先级（UEFI Hard Disk Drive Priorities）。
8. 选择 UEFI 硬盘优先级中的第一项。
9. 使用方向键导航并高亮 Ubuntu 选项。
10. 按回车键确认选择 Ubuntu 为所需的启动项。
11. 保存 BIOS 设置中所做的更改。

退出 BIOS 并让系统重启。
