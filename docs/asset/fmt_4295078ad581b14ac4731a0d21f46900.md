## 使用 Nautilus 文件管理器

Nautilus 文件管理器是 GNOME 的图形外壳。您不仅可以使用 Nautilus 管理系统文件和目录，还可以执行许多 GNOME 和系统配置。通过 Nautilus，您可以访问系统应用程序。

使用以下任一方法启动 Nautilus 文件管理器：

- Enterprise Linux 从应用程序菜单选择“文件浏览器”。在 Fedora 中选择“系统工具”>“文件浏览器”。
