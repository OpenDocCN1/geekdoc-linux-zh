## 用户账户

Linux 安装过程会创建 root 用户账户。在安装期间，你必须为 root 账户指定一个密码。仔细选择此密码并防止任何人发现它。因为 root 账户功能强大，所以你应该只使用它来完成系统管理工作。在安装 Linux 期间或安装后立即，您还应为非系统管理工作创建一个普通用户账户。您需要选择一个简短的用户名（例如 thomasj、jane 或 rms）。您还必须输入该用户账户的全名和密码。
