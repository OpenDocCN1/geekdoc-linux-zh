## 整数比较测试汇总

```
TESTING: if ((int 40 == int 5)) || ["Sales Quota Met == "Y"]
THEN: 至少满足了 OR 条件中的之一。
################
TESTING: if [$int 5 -ne int 40]
THEN: 5 IS NOT equal to 40
################
TESTING: if ((int 5 = int 40))
THEN: 5 IS NOT equal to 40
################
TESTING: if [$int 5 -gt int 40]
ELSE: 5 IS NOT greater than 40
################
TESTING: if ((int 5 > int 40))
ELSE: 5 IS NOT greater than 40
################
TESTING: if [$int 5 -ge 5]
THEN: 5 is greater than OR EQUAL TO 5
################
TESTING: if ((int 5 >= 5))
THEN: 5 is greater than OR EQUAL TO 5
################
TESTING: if [$int 5 -lt 6]
THEN: 5 is less than 6
################
TESTING: if ((int 5 < 6))
THEN: 5 is less than 6
################
TESTING: if [$int 5 -le int 5]
THEN: 5 is less than OR EQUAL TO 5
################
TESTING: if ((int 5 <= int 5))
THEN: 5 is less than OR EQUAL TO 5
################
TESTING: if [$(date +H) -eq 12]
ELSE: 当前小时是 15
################
```
