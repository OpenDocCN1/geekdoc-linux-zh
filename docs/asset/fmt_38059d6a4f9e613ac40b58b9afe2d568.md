
# 癌症生物学的研究

癌症生物学的研究接在癌症病因学的后面，即在肿瘤已发展成自主增殖细胞的克隆簇这一点上。这一阶段肿瘤发展的病理学对应物是原位癌（carcinoma in situ）：一种没有明显组织破坏的情况，但在其起源部位存在外观异常的癌细胞。从原位癌到局部侵袭性癌症的过渡伴随着基底膜的溶解、肿瘤细胞穿过膜进入支持组织，以及支持组织层的破坏。侵入性癌原发肿瘤的扩大总是伴随着新血管的发展。肿瘤细胞还可以侵袭区域性血管和淋巴管，并在全身循环，附着于远处器官部位的 endothelium（内皮），诱导内皮收缩，并附着于内皮基底膜。一旦附着于基底膜，肿瘤细胞被内皮细胞覆盖，并主动与血流分离。然后发生基底膜的局部溶解，允许肿瘤完全扩散到组织中，并在受损血管中重新建立血流。随着肿瘤的生长，更多的血管发育滋养增大的肿瘤。

在转移过程中，肿瘤细胞必须克服宿主防御。它们有各种机制来实现这一点。例如，它们产生新的细胞表面受体以促进基底膜和基质结合；制造新的酶，如胶原酶、丝氨酸蛋白酶、金属蛋白酶、半胱氨酸蛋白酶和端糖苷酶，以促进其侵袭性；并分泌运动因子，使它们能够穿过由这些酶产生的孔和通道移动。它们通过多种技术避免被免疫系统检测。与动物肿瘤不同，大多数人类肿瘤免疫原性较差。肿瘤细胞通常产生免疫抑制因子。参见“细胞免疫学”；“肿瘤”。

转移的一个未解释特征是某些肿瘤类型向特定器官传播的倾向。

## 肿瘤检测

有两种主要策略可以在癌症历史的最早阶段检测肿瘤：对癌症的七个警示信号做出反应，以及对高风险人群进行筛查。癌症的七个危险信号是：(1) 异常出血或分泌物；(2) 乳房或其他部位的肿块或增厚；(3) 不愈合的溃疡；(4) 排便或排尿习惯的改变；(5) 持续的嘶哑或咳嗽；(6) 持续的消化不良或吞咽困难；以及 (7) 疣或痣的改变。

## 诊断

癌症的诊断依赖于对活检材料的仔细检查。起源于外胚层或内胚层组织的癌症通常称为癌（carcinomas）；来源于腺体的称为腺癌（adenocarcinomas）。起源于中胚层衍生组织的癌症称为肉瘤（sarcomas）；起源于淋巴造血系统的称为淋巴瘤和白血病。恶性的主要微观特征是多形性（anaplasia）、侵袭和转移。

一旦做出癌症诊断，确定疾病扩散的程度至关重要。这被称为分期（staging）。它与分级（grading）不同，分级是用显微镜进行的组织学异型性评估。分期涉及进行仔细的体格检查、各种放射学研究，以及可能的手术程序（活检、内窥镜检查），以检查特定肿瘤类型最可能传播的部位。例如，乳腺癌患者通常会对肝脏、大脑和骨骼进行评估以寻找转移性病变，而淋巴瘤患者通常需要评估淋巴结组、骨髓和肝脏。通常，这类分期检查的结果决定了治疗的性质和范围。

## 治疗

癌症治疗有四种主要方法：手术、放射治疗、化疗和生物治疗。这些方法通常一起使用，产生加性或协同效果。手术和放射治疗在治愈局部肿瘤方面最有效，共同治愈了约40%的新诊断病例。一旦癌症扩散到区域淋巴结或远处部位，仅使用局部疗法通常无法治愈。系统联合使用化疗药物可能治愈另外10-15%的患者。参见“化疗”；“放射学”。

# 洋葱

一种冷季型二年生植物，*Allium cepa*（洋葱），起源于亚洲，属于单子叶植物纲百合目（Liliales）。洋葱因其可食用的球茎而种植。

相关物种包括大葱（*A. porrum*）、大蒜（*A. sativum*）、分葱（*A. fistulosum*）、红葱头（*A. ascalonicum*）和韭菜（*A. schoenoprasum*）。

洋葱品种（栽培种）主要根据辛辣程度（温和或辛辣）和用途（干球或绿色束葱）进行分类。球茎可能是白色、红色或黄色。不同品种在储存品质和光周期反应上存在显著差异。具有更高抗病性、更长储存期和更优品质的杂交品种正在迅速取代旧品种。德克萨斯州、纽约州和加利福尼亚州是重要的生产州。参见百合科（LILIACES）。[H.J.C.]

# 潮虫目（Oniscoidea）

等足目（Isopoda）下的一个亚目，包含该类甲壳动物的陆生成员。它们俗称潮虫、slaters、wood lice（木虱），或者对于能卷成球状的种类则称为鼠妇（pill bugs）。陆生等足类通常出现在岩石、松动的树皮、落叶堆和类似的潮湿地方。它们在潮湿的热带和暖温带地区大量分布，特别是在旧大陆（欧亚非）。少数几种几乎遍布全球，可能是随着人类通过植物、土壤或建筑材料无意中传播的。当在花园或温室中数量过多时，它们有时会因啃食植物而造成相当大的损害。

其身体要么背腹扁平，要么像甲虫一样在鼠妇中高度隆起（vaulted）。其三个部分——头部、胸部和腹部——广泛连接（参见插图）。侧缘通常形成一个连续的椭圆形轮廓，除非是腹部突然比胸部窄的类型。表面可能是光滑的，或具有各种由结节、脊或刺组成的雕刻纹理。性别二态性很少见。

# 个体发育（Ontogeny）

指有机体从起源到成熟的发育历史。它始于受精，止于达到成年状态，通常以最大体尺寸和性成熟度来表示。受精是单倍体配子（一个精子和一个卵，各携带该物种典型染色体数的一半）的结合，形成二倍体受精卵（具有完整染色体数），这是一个将通过一系列无性繁殖生长而来的新型单细胞生物。配子是一代与下一代之间的纽带：雄性和雌性配子的融合标志着新个体发育周期的开始。许多生物在性繁殖后不久死亡，而其他生物寿命较长，世代出现重叠。物种通常被理解为成年人，但在大多数情况下，它们在环境中的主要存在形式处于中间的个体发育阶段。参见受精（FERTILIZATION）；繁殖（动物）（REPRODUCTION (ANIMAL)）。

在单细胞生物中，每次无性繁殖导致新个体的形成，由第一个有性来源的个体分裂出的细胞形成具有遗传相同性的克隆。在多细胞生物中，从受精卵第一次分裂开始的无性繁殖产物保持连接，它们形成的克隆是一个个体。甚至在人类中也会发生个体克隆，当受精卵无性繁殖的早期结果彼此分离时，导致双胞胎的形成。

多细胞生物体的个体发育涉及裂体（或卵裂）：受精卵分裂成两个、四个等细胞，这些细胞继续分裂。这些细胞最初与受精卵相似，但体积较小。它们很快开始与祖先细胞分化，获得特殊特征，形成特定的组织层，最终形成器官。这些过程导致胚胎的形成和生长。胚胎可以自由发育，在蛋壳内发育，或在其中一个亲代的体内发育，在那里它们直接长成幼体（如人类）或幼虫（具有间接发育，如昆虫）。

幼体与成体相似，但体型较小且未性成熟。它们的个体发育继续直到达到最大尺寸和繁殖能力。幼虫在形态、生理和生态上与成体不同；它们通过变态（即突然的变化）变成幼体。通常个体发育在成年期中断，但有些生物可以终身生长，因此个体发育以它们的死亡而告终。参见生态学（ECOLOGY）。[E.V.B.]

# 栉蚕门（Onychophora）

唯一拥有真正扇形足（annulate, scalelike legs with internal musculature，带环、鳞片状腿，具有内部肌肉）的现生动物门。已知现生物种约70种，分为两个科：Peripatopsidae（栉蚕科）和 Peripatidae（地蜈蚣科）。这些陆生动物常被称为*Peripatus*（栉蚕属）。栉蚕门包含一个与其同名的纲或目。它们曾被认为是环节动物和节肢动物之间的缺失环节，但最好被视为与节肢动物并列。

它们具有圆柱形身体，长0.5–6英寸（1.4–15厘米），具有一对触角、一个前腹口，以及14–43对短粗、不分节的腿，腿末端有步足垫和成对的爪。颚（Mandibles）存在，表现为附肢对的第一端改造。体表面有灵活的几丁质表皮。

体壁有三层平滑肌，如环节动物一样，但体腔减少为腺体和肾管腔；体腔具有节肢动物式的分节血窦；心脏为管状，具有体节开口；肾管分节。气体交换通过气管进行；气管小节微小且众多，位于皮肤褶皱之间。缓慢的运动由腿和身体收缩完成；动物可以挤入非常狭窄的空间。眼睛位于触角基部，是直接型，具有几丁质晶状体和视网膜层。性别分离；睾丸和卵巢成对；生殖道通过后腹孔开口。栉蚕卵生、卵胎生或胎生。

栉蚕是捕食性的，以小型无脊椎动物为食。它们主要是夜行性的，出现在森林中的潮湿栖息地。

[B. P.]
