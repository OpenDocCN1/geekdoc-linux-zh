
如果路径指向现有路径，则返回 True。如果路径指向损坏的符号链接，则返回 False。

## os.path 397

### expander(path)

将形式为 `-user` 的路径名替换为用户主目录。如果扩展失败或路径不以 `-` 开头，则返回未修改的路径。

### expandvars(path)

扩展路径中形式为 `'$name'` 或 `'${name}'` 的环境变量。格式错误或不存在的变量名将保持不变。

### getctime(path)

返回自从 epoch（纪元）以来的秒数访问时间（参见 `time` 模块）。如果 `os.stat_float_times()` 返回 `True`，则返回值可能是一个浮点数。

### getctime(path)

在 UNIX 上返回自从 epoch 以来的秒数作为最后修改时间（参见 `time` 模块）。在某些情况下，返回值可能是一个浮点数（参见 `getatime()`）。

### getmtime(path)

返回自从 epoch 以来的秒数作为最后修改时间（参见 `time` 模块）。在某些情况下，返回值可能是一个浮点数（参见 `getatime()`）。

### getsize(path)

返回以字节为单位的文件大小。

### isabs(path)

如果路径是绝对路径名（以斜杠开头），则返回 `True`。

### isfile(path)

如果路径是普通文件，则返回 `True`。此函数会遵循符号链接，因此 `islink()` 和 `isfile()` 对同一路径都可以返回 `True`。

### isdir(path)

如果路径是目录，则返回 `True`。遵循符号链接。

### islink(path)

如果路径指向符号链接，则返回 `True`。如果不支持符号链接，则返回 `False`。

### ismount(path)

如果路径是挂载点，则返回 `True`。

### join(path2, path2 [, ...]])

智能地将一个或多个组件组合成路径。例如 `join('home', 'beazley', 'Python')` 返回 'home/beazley/Python'。

### exists(path)

如果路径存在则返回 `True`。对于所有符号链接都返回 `True`，即使该链接是断的。

### normcase(path)

规范化路径的大小写。在不区分大小敏感的文件系统上，这将路径转换为小写。在 Windows 上，正斜杠也会转换为反斜杠。

### normpath(path)

规范化路径名。它会合并冗余的分隔符和上级引用，使得 'A/B'、'/A../B' 和 'A/foo/.../B' 都变成 'A/B'。在 Windows 上，正斜杠会被转换为反斜杠。

### realpath(path)

返回路径的真实路径，消除任何符号链接（UNIX）。

### relpath({path, start})

返回从当前目录到路径的相对路径。`start` 可用于指定不同的起始目录。

### samefile(path1,path2)

如果 `path1` 和 `path2` 指向同一个文件或目录，则返回 `True`（UNIX）。

### sameopen(fpl,fp2)

如果打开的文件 `fpl` 和 `fp2` 指向同一个文件，则返回 `True`（UNIX）。

### samest(stat1,stat2)

如果由 `fstat()`、`lstat()` 或 `stat()` 返回的元组 `stat1` 和 `stat2` 指向同一个文件，则返回 `True`（UNIX）。

### split(path)

将路径拆分为元对 `(head, tail)`，其中 `tail` 是最后一个组件，`head` 是其前面的部分。例如，`'/home/user/foo'` 被拆分为 `'/home/user'` 和 `'foo'`。这与 `(dirname(), basename())` 返回的结果相同。

### splitdrive(path)

将路径拆分为元对 `(drive, filename)`，其中 `drive` 是驱动器规范字符串或空字符串。在没有驱动器规范的机器上，`drive` 始终为空字符串。

### splittext(path)

将路径名拆分为基本名和后缀。例如，`splitext('foo.txt')` 返回 `('foo', '.txt')`。

### splitunc(path)

将路径名拆分为元对 `(unc, rest)`，其中 `unc` 是 UNC（通用命名规范）挂载点，`rest` 是路径的剩余部分（Windows）。

### supports_unicode_filenames

如果文件系统允许 Unicode 文件名，则该变量设置为 `True`。

## Note

在 Windows 上，处理包含驱动器号的文件名（例如 `'C:spam.txt'`）需要格外。在大多数情况下，文件名是相对于当前工作目录解释的。例如，如果当前目录是 `C:\Foo\`，那么文件 `C:spam.txt` 被解释为文件 `C:\Foo\C:spam.txt`，而不是计划中的文件。

## signal

`signal` 模块用于在 Python 中编写信号处理器。信号通常对应于由于定时器过期、输入数据到达或用户执行某些操作发送给程序的异步事件。该接口模拟了 UNIX，尽管该模块的部分在其他平台上也支持。

### alarm(time)

```
alarm(time)
```

如果 `time` 不为零，则计划在时间内向程序发送 `SIGALRM`；任何之前计划的闹钟都会取消。如果 `time` 为零，则不安排闹钟并取消任何之前设置的闹钟。返回在任何之前计划的闹钟发生前（如果没有计划的闹钟）剩余的信号数（UNIX）。

### getsignal(signalnum)

```
getsignal(signalnum)
```
