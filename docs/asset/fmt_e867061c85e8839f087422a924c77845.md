
- 脚本化：网络命令可以用于脚本以自动执行网络任务。这对于管理大型网络或执行重复性任务特别有用。
- 命令行界面：网络命令通常从命令行运行，对于某些任务，这比使用图形用户界面（GUI）更高效。

总的来说，网络命令是管理系统网络配置及连接的强大工具。

## 网络命令示例

- `ifconfig`：此命令用于配置网络参数。通过它，你可以查看并设置网络接口的 IP 地址、掩码，并可以启用或禁用接口。
- `ping`：此命令用于测试网络上两个设备之间的连接性。它通过向远程设备发送小型数据包并测量其返回的时间来工作。
- `traceroute`：此命令用于追踪数据包在 IP 网络上经过的路径。它对排排除连接问题非常有用。
- `netstat`：此命令用于显示活动网络连接、路由表和正在使用的套接字。
- `route`：此命令用于查看和操作 IP 路由表。通过它，你可以添加、删除或修改路由表项。
- `nslookup`：此命令用于查询域名系统（DNS）以获取域名与 IP 地址的映射，或查找负责特定域名的服务器。

### 使用 `ifconfig`

`ifconfig` 命令用于配置 Linux 中的网络接口。以下是使用方法的示例：

打开终端窗口。

输入 `ifconfig` 并回车。这将显示系统网络接口列表及其当前配置。

要查看特定接口的配置，可以使用以下语法：

```
ifconfig <interface>
```

例如，要查看 `eth0` 接口的配置，输入：

```
ifconfig eth0
```

这将显示 `eth0` 接口的当前配置，包括 IP 地址、掩码和广播地址。

要设置接口的 IP 地址，可以使用以下语法：

```
ifconfig <interface> <IP address>
```

例如，要将 `eth0` 接口的 IP 地址设置为 `192.168.1.100`，输入：

```
ifconfig eth0 192.168.1.100
```

要设置接口的子网掩码，可以使用以下语法：

```
ifconfig <interface> netmask <netmask>
```

例如，要将 `eth0` 接口的子网掩码设置为 `255.255.255.255`，输入：

```
ifconfig eth0 netmask 255.255.255.255
```

### 使用 `iwconfig`

`iwconfig` 命令用于配置 Kali Linux 中的无线网络接口。以下是使用方法的示例：

打开终端窗口。

输入 `iwconfig` 并按回车。这将显示你系统无线接口的列表及其当前配置。

要查看特定无线接口的配置，可以使用以下语法：

```
iwconfig <interface>
```

例如，要查看 `wlan0` 接口的配置，你将输入：

```
iwconfig wlan0
```

这将显示 `wlan0` 接口的当前配置，包括无线模式、通道和 ESSID。

要设置接口的无线模式，可以使用以下语法：

```
iwconfig <interface> mode <mode>
```

例如，要将 `wlan0` 接口的无线模式设置为托管（managed），你将输入：

```
iwconfig wlan0 mode managed
```

要设置接口的无线通道，可以使用以下语法：

```
iwconfig <interface> channel <channel>
```

例如，要将 `wlan0` 接口的无线通道设置为 `6`，你将输入：

```
iwconfig wlan0 channel 6
```

要设置接口的 ESSID（网络名称），可以使用以下语法：

```
iwconfig <interface> essid <ESSID>
```

例如，要将 `wlan0` 接口的 ESSID 设置为 `MyNetwork`，你将输入：

```
iwconfig wlan0 ssid MyNetwork
```

## 使用 `dig`

`dig` 命令是 Kali Linux 中查询域名系统（DNS）的工具。以下是其用法示例：

打开终端窗口。

输入 `dig` 后紧跟你想查询的域名，然后按回车。例如，要查询 `example.com` 域名的 IP 地址，你将输入：

```
dig example.com
```

这将返回与域名 `example.com` 关联的 IP 地址。

你还可以使用 `dig` 命令执行特定类型的 DNS 查询。例如，要执行反向 DNS 查询（将 IP 地址映射到域名），可以使用以下语法：

```
dig -x <IP address>
```

例如，要对 IP 地址 `192.0.2.1` 执行反向 DNS 查询，你将输入：

```
dig -x 192.0.2.1
```

这将返回与 IP 地址 `192.0.2.1` 关联的域名。

你还可以使用 `@` 符号指定用于查询时使用的 DNS 服务器，如下所示：

```
dig <domain> @<server>
```

例如，要使用 DNS 服务器 `8.8.8.8` 对 `example.com` 域名进行 DNS 查询，你将输入：

```
dig example.com @8.8.8.8
```

## 使用 `traceroute`

`traceroute` 命令是 Kali Linux 中追踪数据包在 IP 网络上路径的工具。以下是其用法示例：

打开终端窗口。

输入 `traceroute` 后紧跟你想追踪路径的域名或 IP 地址，然后按回车。例如，要追踪到 `example.com` 域名的路径，你将输入：

```
traceroute example.com
```

这将显示数据包到达目的地经过的跳数列表，以及每个跳跃的往返时间（RTT）。

你还可以使用 `-m` 选项指定追踪的最大跳数，如下所示：

```
traceroute -m <hops> <destination>
```

例如，要以最大 `10` 跳数追踪到 `example.com` 域名的路径，你将输入：

```
traceroute -m 10 example.com
```

你还可以使用 `-p` 选项指定用于追踪时使用的端口号，如下所示：

```
traceroute -p <port> <destination>
```

例如，要使用端口 `80` 追踪到 `example.com` 域的路径，你将输入：

```
traceroute -p 80 example.com
```

## 使用 `netstat`

`netstat` 命令是用于显示 Kali Linux 中活动连接和路由表的工具。以下是其用法示例：

打开终端窗口。

输入 `netstat` 并按回车。这将显示活动连接列表、本地和远程地址以及与连接相关的进程 ID。

你还可以使用 `-a` 选项显示所有连接，包括监听状态的连接：

```
netstat -a
```

要显示特定协议的连接，可以使用 `-p` 选项后跟协议名称，如下：

```
netstat -p <protocol>
```

例如，要显示 TCP 连接，你可以输入：

```
netstat -p tcp
```

你还可以使用 `-r` 选项显示内核路由表：

```
netstat -r
```

## 使用 `nslookup`

`nslookup` 命令是 Kali Linux 中查询域名系统（DNS）的工具。以下是其用法示例：

打开终端窗口。

输入 `nslookup` 后紧跟你想查询的域名，然后按回车。例如，要查询 `example.com` 域名的 IP 地址，你将输入：

```
nslookup example.com
```

这将返回与域名 `example.com` 关联的 IP 地址。

在网络内部。网络前缀和主机标识符中的位数取决于用于网络所的子网掩码。

IPv4 地址是分层结构，这意味着它们被组织成网络和子网络的层级结构。这允许不同网络上的设备通过路由器相互通信，路由器在网络之间进行数据包转发。

IPv4 地址正在被 IPv6 地址取代，IPv6 地址更长，并提供了大得多的地址空间。然而，IPv4 地址仍然被广泛使用，并且可能还会继续使用一段时间。

## 常用 IPv4 相关命令

以下是在 Linux 中用于处理 IPv4 地址的一些常用命令列表：

- `ifconfig` - 此命令用于查看和设置网络接口的 IP 地址、子网掩码和广播地址。
- `ip` - 此命令是一个较新的工具，提供了与 `ifconfig` 类似的功能，但语法更灵活。
- `route` - 此命令用于查看和操作 IP 路由表，该表决定了哪些数据包在网络之间进行转发。
- `netstat` - 此命令用于显示活动网络连接的信息以及各种网络协议的状态。
- `ping` - 此命令用于通过发送 ICMP 请求并等待回复来测试网络上两个设备之间的连通性。
- `traceroute` - 此命令用于追踪数据包在 IP 网络上经过的路径。
- `nslookup` - 此命令用于查询域名系统 (DNS) 以将域名解析解析为 IP 地址。
- `dig` - 此命令与 `nslookup` 类似，但功能更强大且语法更灵活。
