## Solaris 打印控制命令

Solaris 使用 System V 的 `lpc`（行打印机控制）命令来控制打印机和打印队列，与 System V 一致。我们对 Solaris 队列和打印感兴趣的主要命令包括表 16.4 所示的 `lpc` 命令的选项和参数。

如表 16.4 所示，打印控制的粒度非常出色，这为创建 shell 脚本提供了多种选择。要一次性控制所有的打印和队列，你实际上不需要 shell 脚本。以下两条命令可以同时启动和停止所有队列上的打印和队列。

```bash
# 禁用所有打印和队列
lpc down
# 启用所有打印和队列
lpc up
```

为了保持所有打印机持续打印和队列，你只需要在 cron 作业中输入 `lpc up` 命令。我在 root cron 中放置了一个条目，每 10 分钟执行一次该命令。我的 cron 条目如下所示：

```bash
5,15,25,35,45,55 * * * * /usr/sbin/lpc up >/dev/null 2>&1
```

### 表 16.4 Solaris Lpc 命令选项

| LPC 命令 | 命令结果 | 描述 |
| --- | --- | --- |
| disable(printer[@host]) | all | 禁用队列 |
| stop(printer[@host]) | all | 停止打印 |
| down(printer[@host]) | all | 禁用打印和队列 |
| enable(printer[@host]) | all | 启用队列 |
| start(printer[@host]) | all | 启动打印 |
| up(printer[@host]) | all | 启用打印和队列 |

此 cron 表每天 24 小时、每周 7 天每隔 10 分钟对所有打印机执行所有打印和队列。

这里的情况很好，因为我们可以在 Solaris 上使用之前用于 AIX System V 打印的同一个 shell 脚本。与 Linux 不同（Linux 需要的所有数据都在单行输出中），在 Solaris 和 AIX System V 打印中，我们感兴趣的数据被分为三行输出。你可以看到输出上的差异。

### AIX SYSTEM V 输出

```bash
# lpc status all
hp4V:
	queueing is enabled
	printing is disabled
	5 entries in spool
```

### LINUX SYSTEM V 输出

```bash
# lpc status
Printing Spooling Jobs	Server Subserver Redirect
Printer Status/(Debug)
hp4@localhost				enabled	disabled	0	none	none
```

### SOLARIS SYSTEM V 输出

```bash
# lpc status all
bambam_hp4:
	queueing is enabled
	printing is enabled
	no entries
```

在这三个输出中，Linux 是唯一不同的一个。由于 Solaris 中每个队列的感兴趣数据位于三个独立的行上，我们需要一种不同的策略来获取所需的精确数据。首先，队列名称段落（stanza）的开头是一个冒号（`:`），附加在队列名称之后。由于这个字符只出现在队列名称中，我们可以使用冒号字符作为 grep 语句的标签。紧随队列名称之后的两行包含了有关队列和打印状态的数据。

由于我们每个条目都有唯一的标签，因此使用扩展 grep（即 `egrep`）语句可以很轻松地提取出我们感兴趣的数据行，如下所示：

```bash
lpc status all | egrep ':|printing|queueing' | while read LINE
```

`egrep` 命令的工作方式与 `grep` 命令相同，不同在于你可以指定多个匹配模式。每个模式之间用管道符（`|`）隔开，且不能有任何空格！

如果你在搜索模式的两侧添加空格，`egrep` 语句将无法匹配。整个模式列表被包含在单引号内，`'pattern1|pattern2|pattern3'`。产生的输出的第一行是队列名，第二行是打印状态，第三行是队列状态。

上一个命令的最后部分是将输出管道到 `while` 循环中。在每次读取时，整行数据都会加载到 `LINE` 变量中。在 `while` 循环内部，我们使用 `case` 语句将数据分配给相应的变量。

```bash
case $LINE in
  *:)
    Q=$(echo $LINE | cut -d':' -f1)
    ;;
  printing*)
    PSTATUS=$(echo $LINE | awk '{print $3}')
    ;;
  queuing*)
    QSTATUS=$(echo $LINE | awk '{print $3}')
    ;;
esac
```
