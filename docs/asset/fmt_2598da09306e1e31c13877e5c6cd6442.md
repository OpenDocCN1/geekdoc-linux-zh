你将从获取分配给 `INT-WALLS.05` 对象的材质开始：

1. 点击主工具栏上的 `Material Editor`（材质编辑器）按钮打开材质编辑器。
2. 点击一个包含未使用的默认 `Standard`（标准）材质的槽位。
3. 点击材质工具栏上的 `Get Material`（获取材质）按钮。
4. 在 `Material/Map Browser`（材质/贴浏览器）中，点击 `Browse From`（浏览）组中的 `Selected`（已选择）单选按钮。你将在列表中看到分配给 `INT-WALLS.05` 对象的材质。
5. 双击列表中的 `Wall`（墙体）材质；关闭材质/地图浏览器。

墙体材质现在出现在选中的样本槽位中。这是你之前在书中分配给别墅墙壁的材质。在本次练习中，你将以现有的 `Wall` 材质为起点创建一个新的 `Multi/Sub-Object`（多子对象）材质。

下一步是将材质从 `Standard` 改为 `Multi/Sub-Object` 材质：

1. 在 `Material Name`（材质名称）输入框中输入 `Wall Second Floor`。这将为活动槽位中的材质分配一个新名称。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_457_1.png)

2. 在 `Material Name` 输入框右侧点击标记为 `Standard` 的 `Type`（类型）按钮。
3. 在 `Material/Map Browser` 中，确保 `Browse From` 组中的 `New`（新建）单选按钮被选中；从列表中选择 `Multi/Sub-Object`。点击 `OK`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_457_2.png)

### 4. 显示 `Replace Material`（替换材质）警告。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_458_0.png)

确保选中了 `Keep Old Material as Sub-Material?`（保留旧材质作为子材质？）选项，然后点击 `OK`。你返回材质编辑器，并显示 `Multi/Sub-Object Basic Parameters`（多子对象基础参数）卷。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_458_1.png)

从材质编辑器可以看出，`Multi / Sub-Object` 材质提供了额外材质的列表。每个材质都是主材质的子材质。在本次练习中，你只需要两个材质，因此将可用列表的数量减少到两个：

1. 点击 `Multi/Sub-Object Basic` 卷中的 `Set Number`（设置数量）按钮。
2. 在 `Set Number of Materials`（设置材质数量）对话框中输入 `2`，然后点击 `OK`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_458_2.png)

当你回到材质编辑器时，只能看到两个子材质列表。现有的 `Wall` 材质是 `1` 号，另一个尚未定义的材质是 `2` 号。现在让我们添加将成为二楼地板的材质：

1. 点击 `Multi/Sub-Object Basic` 卷中位置为 `2` 的材质按钮。材质编辑器窗口切换为显示 `Standard` 材质的参数。从窗口的外观来看，很难判断你正在处理一个 `Multi/Sub-Object` 材质，但一个线索是工具栏上的 `Go To Parent`（回到父级）按钮没有变灰。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_458_3.png)

2. 点击标记为 `Standard` 的 `Type` 按钮。出现 `Material/Map Browser`。

### 识别 `MULTI/SUB-OBJECT` 材质

虽然窗口的其他部分看起来像 `Standard` 材质，但 `Go To Parent` 按钮的存在告诉你，你实际上处于多级材质定义的子层级中。

### 为对象的部件分配材质

你将使用花岗岩砖材质作为地板，因此你想要从编辑器打开相应的材质：

- 在 `Material/Map Browser` 中，点击 `Browse From` 组中的 `Mtl Editor`（材质编辑器）按钮。
- 滚动列表并双击 `Stone-Granite Tiles (Standard)`。
- 出现一个小型对话框，提问 `Instance or Copy?`（实例还是拷贝？）。选择 `Copy` 并点击 `OK`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_459_0.png)

你可以像处理几何节点一样实例化材质节点。实例共享参数，而拷贝总是独一无二的。

- 回到材质编辑器窗口，点击工具栏上的 `Go Parent`（回到级）按钮。
- 在 `Multi/Sub-Object` 材质的 `Name` 列中，为子材质输入以下名称：`walls` 和 `floor2`。

| ID | Name | Sub-Material | GV/DF |
|---|---|---|---|
| 1 | walls | Second Floor (Standard) | |
| 2 | floor2 | Material #2 (Standard) | |

点击 `Assignment Selection`（分配选择）按钮将 `Multi/Sub-Object` 材质分配给二楼。新材质已应用到二楼对象，尽管似乎没有任何变化。由于墙体材质与分配给地板的材质相同，别墅的外观没有变化。你还需要几个步骤，花岗岩材质才会出现在地板上。

### 将子材质应用于对象的表面

别墅二楼对象 `INT-WALLS.05` 是从 `AutoCAD` 中的 `3D Solids` 创建的，因此在视图中它是编辑网格（`Editable Mesh`）。要将子材质应用到可编辑网格的多边形，你需要选择多边形。

- 点击命令面板上的 `Modify` 标签。
- 展开 `Editable Mesh` 并点击 `Polygon`（多边形）层。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_459_1.png)

- 如果 `Selection` 尚未设置为 `Window`（窗口），将选择区域类型改为 `Rectangular`（矩形）。你只想完全选择窗口内的边形。
- 4. 点击 `Object` 按钮，如图 8.53 所示，在二楼顶部小心放置一个矩形选择区域。

图 8.53 在区域周围放置矩形选择区域。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_460_0.png)

你现在选择了二楼对象的表面多边形。下一步是将 `2` 号材质分配给该表面。

1. 滚动 `Modify` 标签到 `Surface Properties` 卷。
2. 在 `Material` 组中将 `Set ID` 值改为 `2` 并按下 `OK`。

| Material | Set ID | Select ID |
|---|---|---|
| floor2 (2) | Clear Selection |

记得花岗岩砖材质是 `Multi/Sub-Object Basic` 卷中的 `2` 号，因此通过输入 `Material ID`，你正在将花岗岩砖材质分配给选中的表面。你也可以验证这一点，因为 `Material` 组显示为 `floor2`，这是子材质。

### 使用修改器分配子材质

为对象分配子材质的另一种方法是使用修改器。该修改器提供一个参数——`Material ID`。你还需要几个步骤来完成地板分配。由于花岗岩砖材质使用贴图，你需要为二楼对象应用 `UVW Map` 修改器：

1. 滚动到命令面板顶部；然后点击 `Polygon` 层返回 `Object` 层。或者，你可以右键点击并从菜单选择 `Top`（顶部）。
2. 点击修改器栈顶部的 `UVW Map` 修改器。

### UI 差异

奇怪的是，`Material List` 下拉菜单中的修改器名为 `UVW Map`，而在修改器栈中显示为 `UVW Mapping`。

默认情况下，`Planar`（平面）`UVW` 映射类型应用到二楼对象，并调整以适应轮廓。轮廓不是正方形，你希望调整 `UVW` 图的比例为正方形，以免花岗岩砖图失真：

1. 滚动 `Modify` 标签到 `UVW Map Parameters` 卷。
2. 将 `Length` 和 `Width` 参数改为 `60'`。这将在边长 `60'` 的正方形区域放置一个图案的实例。由于花岗岩砖图是 `4x4` 的图案，这将在整个视图地板区域放置 `4x4` 的瓷块阵列。如果你查看透视视图，你会发现地板包含一组可能也失真和像素化的大砖。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_461_0.png)
