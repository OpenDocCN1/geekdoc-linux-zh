## 总结

UNIX 是最先进的开箱即用网络化操作系统之一。UNIX 为 TCP/IP 协议的成功和发展做出了巨大贡献，而这些协议构成了被称为互联网的全球通信网络的基础。

本章涵盖了管理 TCP/IP 通信的概念。涵盖的内容旨在配置网络上的 UNIX。

本章首先提供了对 TCP/IP 协议栈的介绍性概述。随后，全面涵盖了设置和配置 UNIX 以支持 TCP/IP 所需的概念和工具，包括最相关脚本的详细列表。特别是路由问题是从 UNIX 的视角进行讨论的，并强调了 IP 地址结构以及该结构背后的目标。解释了 DNS 名称服务和 NFS，并突出了常见错误区域以帮助读者避免这些错误。

最后，本章为读者提供了一套全面的工具，并展示了如何在故障排除练习的背景下使用这些工具。
