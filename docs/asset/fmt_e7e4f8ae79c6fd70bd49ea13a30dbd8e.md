
# 汽车悬架

汽车悬架是位于车轮与车架、副车架或承载式车身的侧梁之间的弹簧及相关部件。悬架支撑车辆上部在轴和车轮上的重量，允许车辆在行驶于不平整路面时最小化车身的上下起伏，并允许车辆在转弯时最小侧倾或轮胎与路面之间附着力的丧失。参见[汽车](https://example.org/automobile)；[弹簧（机械）](https://example.org/spring_machines)；[齿轮](https://example.org/gear)。

![前轮驱动汽车，配备麦弗逊式前悬架和支柱式独立后悬架。（Saturn Corp.）](img/2cf7974cd6027baa297e5cd95d3d6d43_239_0.png)

对于前置发动机和前轮驱动车辆的典型悬架系统（见图示），车辆重量对螺旋弹簧施加初始压缩。当轮胎和车轮遇到路面不平时，弹簧进一步压缩或伸展以吸收大部分冲击。后轮的悬架通常比前轮简单，因为前轮需要多点连接，以便车轮能在左右摆动以转向的同时上下移动。

每个车轮的支柱上或内部单独安装有一个伸缩式液压减振器，俗称减震器，用于限制弹簧运动并防止弹簧长时间振荡。减震器内部有一个活塞，随着车轮相对于车身或车架上下运动而在气缸内移动。当活塞移动时，它迫使流体通过孔口，从而对弹簧施加阻力。如果流体压力升高到足够高（例如在车轮快速移动时），弹簧加载的阀门会打开以允许流体更快流动。大多数汽车使用充气式减震器，其中流体上方的空气空间填充有加压气体，如氮气。作用在流体上的气体压力减少了气泡和泡沫的产生。参见[减震器](https://example.org/shock_absorber)。

大多数汽车拥有独立前悬架，通常使用螺旋弹簧作为短臂长臂悬架系统或麦弗逊支柱悬架系统的一部分。麦弗逊支柱悬架（见图示）将螺旋弹簧和减震器与支柱组件结合，该组件仅需一个梁式下控制臂。

一些具有短臂长臂前悬架的车辆在前弹簧上使用纵向或横向扭杆。

扭杆的一端附着在下控制臂上，另一端锚固在车身或车架上。当轮胎和车轮上下移动时，扭杆通过绕其长轴扭转提供弹簧作用。旋转扭杆一端的调整螺栓可提高或降低车辆的行驶高度。参见[扭杆](https://example.org/torsion_bar)。

大多数汽车和许多轻型卡车在后部使用螺旋弹簧。这些弹簧可能安装在后驱动轴、支柱上，或独立悬架系统中的各种控制臂或悬架臂上。一些后驱车辆在后部使用叶片弹簧。其他车辆则使用横向扭杆。[D.L.A.N.]

## 汽车变速器

汽车变速器是汽车传动系统中的装置，它在发动机和驱动轮之间提供不同的齿轮比，同时提供空挡和倒挡。内燃机在低速时产生相对较小的扭矩，且仅在某一特定速度下达到最大扭矩，曲轴始终朝同一方向旋转。为了满足车辆的牵引力需求，变速器将发动机转速和扭矩转换为选定方向的最终驱动输出转速和扭矩。这种结构允许较小的发动机在车辆从静止加速到最高速度的过程中提供可接受的性能和燃油经济性。变速器可以是独立单元，如前置发动机后轮驱动车辆中那样；或者可以与驱动轴结合形成变速箱，如大多数前轮驱动车辆中那样。参见[汽车](https://example.org/automobile)；[汽车驱动轴](https://example.org/automotive_drive_axle)；[差速器](https://example.org/differential)。

两个主要类别是手动变速器，驾驶员在断开脚踩离合器后手动换挡；以及自动变速器，无需驾驶员操作即可换挡。然而，手动变速器可以配备自动脱开机构，当驾驶员移动换挡杆时，该机构会自动断开离合器；自动变速器也可以具备手动换挡功能，允许驾驶员通过移动换挡杆选择换入下一个较低或较高的齿轮比。参见[离合器](https://example.org/clutch)。

手动变速器是一个包含在部分填充润滑剂的金属壳体或变速箱中的齿轮、轴及相关部件的组件。变速器输入轴通过离合器和飞轮连接到发动机曲轴（见图示）。变速器输出轴通过传动轴连接到驱动轴中的最终传动齿轮。为了使车辆开始运动，变速器中的减速或欠驱动齿轮组允许发动机曲轴高速旋转，而驱动轮则以慢得多但扭矩大大增加的速度旋转。随着车辆加速，所需扭矩减少而速度增加，驾驶员将变速器依次换入数值更小的齿轮比，即较高的档位。在一个典型的五速手动变速器中，齿轮比大约为：一档 3.35:1，二档 2.1，三档 1.35:1，四档 1:1（直接驱动），五档 0.75:1（超速挡）。大多数具有四个或更多前进挡的变速器由地板式换挡杆操作。参见[齿轮](https://example.org/gear)；[齿轮系](https://example.org/gear_train)。

## 自动诊断

自动变速箱通过四档或五档前进挡位，对起步、传动比和换挡进行自动控制。典型的汽车自动变速箱包括带有锁止离合器的液动三元件液力变矩器、在第四挡或更高挡位提供超速档的行星齿轮系统，以及液压或电液控制系统。换挡过程不会损失牵引力。参见“液压”、“液动”、“行星齿轮系”、“液力变矩器”。

### 自主神经系统

神经系统的一部分，负责支配平滑肌和心肌以及腺体，并调节内脏过程，包括与心血管活动、消化、代谢和体温调节相关的过程。自主神经系统主要作为潜意识水平发挥作用。传统上，它根据自主神经起源于脑或脊髓的区域，分为交感神经系统和副交感神经系统。交感神经系统由从脊髓胸段和腰段发出的自主神经纤维定义。副交感神经系统由通过颅神经从脑干发出，或从脊髓骶段发出的自主神经纤维定义。参见“副交感神经系统”、“交感神经系统”。

自主神经系统的定义特征最初仅限于支配腺体和平滑肌及心肌的运动纤维。这一界定将自主神经系统限制在内脏传出纤维，并排除了伴随大多数内脏运动纤维的感觉纤维。尽管该定义常被扩展以包括外周和中枢结构（如丘脑下部），但当代文献仍将继续将自主神经系统仅定义为一个运动系统。然而，从功能角度来看，自主神经系统包括传导内脏器官信息的传入通路，以及解释传入反馈并从运动输出对内脏器官施加控制的脑区（如延髓和丘脑下部）。参见“稳态”。

飞机运动通常由陀螺仪感知，陀螺仪向计算机（见图）传输信号。计算机指令控制伺服机构产生空气动力，以消除感知到的运动。计算机可以是复杂的数字计算机、模拟计算机（电气或机械）或简单的求和放大器，具体取决于自动驾驶仪的复杂度。控制伺服机构可以是液压驱动的致动器或电磁式的表面致动器。可以向计算机添加提供姿态指令或转向指令的信号。对于简单的自动驾驶仪，俯仰回路控制升降舵，滚转回路控制副翼。可以增加一个控制方向舵的方向回路，以提供协调转弯。参见“升降副翼”、“放大器”、“模拟计算机”、“控制系统”、“数字计算机”、“升降副翼”、“制导系统”、“随动系统”。

## 自动驾驶仪

一种用于操控飞机或其他车辆的自动装置。自动驾驶仪（或称自动飞行员）最初用于在巡航模式下为飞行员提供辅助。如今，自动驾驶仪执行功能的速度比人类飞行员更快，精度也更高。根据车辆类型的不同，自动驾驶仪的功能、细节和使用方式差异很大。除了控制各种类型的飞机和航天器外，自动驾驶仪还用于控制船舶或海上车辆，在某些情况下也用于陆基车辆。本文讨论用于飞机和航天器的自动驾驶仪。

自动驾驶仪是一种独特的设备，因为它被期望像受过高度训练、技艺精湛的飞行员那样操控飞机。它必须提供平稳的控制，并避免突然且 erratic 的行为。控制智能必须来自传感器，如陀螺仪、加速度计、高度计、空速指示器、自动导航仪以及各种类型的无线电控制数据链路。自动驾驶仪将必要的信号输入到操纵面指令中，这些指令操作飞机常规的空气动力学操纵机构。参见“加速度计”、“飞机仪表”、“高度计”、“陀螺仪”、“惯性制导系统”。

自动驾驶仪有不同的复杂程度。简单的姿态保持（机翼水平器）勉强配得上“自动驾驶仪”这个名称，而顶级系统能自动将飞机从一个位置移动到另一个位置，超出了正常自动驾驶仪的能力范围。复杂的自动驾驶仪不再局限于军用飞机，现在在商业飞机中也很常见，并且可供通用航空使用。在现代电传操纵飞机中，自动驾驶仪和飞行控制系统通常驻留在同一台数字计算机中，很难将二者分离。
