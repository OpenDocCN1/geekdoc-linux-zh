在我们的下一个程序中，我们将尝试找到一组数字中的最大值。计算机非常注重细节，因此为了编写该程序，我们必须规划许多细节。这些细节包括：

## 第 3 章 你的第一个程序

你可能认为像从列表中找到最大值这样简单的任务不需要大量的规划。你通常可以告诉人们寻找最大值，他们可以很轻松地完成。然而，我们的大脑习惯自动组合复杂任务。而计算机需要通过过程来被指令引导。此外，我们通常可以毫不费力地脑中记住任何事情。我们通常甚至没有意识到自己在这样做。例如，如果你扫描数字列表以寻找最大值，你可能会同时记住到目前为止看到的最高数字，以及你处于列表的哪个位置。虽然你的大脑会自动完成这一点，但在计算机上，你必须显式地设置存储来保存列表的当前位置和当前最大值。你还有其他问题，例如如何知道何时停止。然而，计算机只包含数字，所以它不知道你何时达到了数字的末尾。

在计算机中，你必须规划路径每一步。那么，让我们做一点规划。首先，仅供参考，我们将数字列表开始的地址命名为 `data_items`。假设列表中的最后一个数字将是零，这样我们就知道如何停止。我们还需要一个值来存储列表中的当前位置，一个值来存储正在检查的列表元素，以及列表中的当前最高值。让我们为这些每一个项分配一个寄存器：

- `%edi` 将存储列表中的当前位置。
- `%ebx` 将存储列表中的当前最高值。
- `%eax` 将存储正在检查的元素。

当我们开始程序并查看列表中的第一个项目时，由于我们还没有见过任何其他项目，item 将自动成为列表中的最大元素。此外，我们将列表中的当前位置设置为零——第一个元素。从那时起，我们将遵循以下步骤：

- 1. 检查当前列表元素 (`%eax`) 查看它是否为零（终止元素）。
- 2. 如果是零，退出。
- 3. 增加当前位置 (`%edi`)。
- 4. 将列表中的下一个值加载到当前值寄存器 (`%eax`)。这里可能会使用什么种寻址模式？为什么？
- 5. 将当前值 (`%eax`) 与当前最高值 (`%ebx`) 进行比较。
- 6. 如果当前值大于当前最高值，则用当前值替换当前最高值。
- 7. 重复。

这就是该过程。在该过程中的很多时候，我使用了“if”这个词。这些地方是需要做决策的地方。你看，计算机并不是每次都遵循完全相同的指令序列。取决于哪些“if”是正确的，计算机可能会遵循一组不同的指令。第二次执行时，它可能没有最高值。在这种情况下，它将跳过步骤 6 。在更复杂的程序中，跳跃会大幅增加。除了最后一种情况，每情况下它都会跳过步骤 7 。

这些“if”是一类流控制指令，因为它们告诉计算机遵循哪些步骤以及采取哪些路径。在上一个程序中，我们没有任何流控制指令，因为只有一种可能的出口——这个程序要动态得多，因为它是由数据驱动的。根据它接收的数据，它将遵循不同的指令路径。

在这个程序中，这将通过两个不同的指令来实现：条件跳转根据上一次比较或计算的结果改变路径；无条件跳转无论如何都直接跳转到不同的路径。无条件跳转似乎没用，但它是非常必要的，因为所有指令将排列在一行。如果某路径需要汇回到主路径，它将通过无条件跳转来实现。我们将在下一节中看到更多这两种跳转。

流控制的另一个用途是循环。循环是重复的代码段。在我们的示例中，第一部分（设置位置为 0 并加载当前值）只执行一次，但下一部分会对列表中的每个数字重复执行。只有遇到零时才会离开。这被称为循环。如果我们不小心忘记循环，它将持续运行。

### 第 3 章 你的第一个程序

除了 `.long` 之外，还有几种不同类型的内存位置可以预留。主要的如下：

`.byte`

字节（Bytes）每个数字占用一个存储位置。它们被限制在 0 到 255 之间的数字。

`.int`

整数（Int，与 `int` 指令不同）每个数字占用两个存储位置。它们被限制在 0 到 65535 之间的数字。

`.long`

长整数（Long）占用四个存储位置。这与寄存器的空间相同，这就是为什么在这个程序中使用了它们。它们可以持有 0 到 429496295 之间的数字。

`.ascii`

`.ascii` 指令用于将字符输入内存。每个字符占用一个存储位置（它们被转换为字节）。所以，如果你给出了指令 `.ascii "Hello there\0"`，汇编器将预留 12 个存储位置（字节）。第一个字节包含 H 的数字代码，第二个字节包含 e 的数字代码，以此此类推。最后一个字符由 `\0` 表示，它是终止字符（它永远不会显示，只是告诉程序的其他部分字符结束了）。以反斜杠开头的字母和数字在键盘上无法输入，在屏幕上也不易可见。例如，`\n` 指的是“换行”字符，会导致计算机在下一行开始输出，`\t` 指的是“制表符”字符。`.ascii` 指令中的所有字母都应该放在引号中。

- 9. 注意，汇编语言（或我见过的任何其他计算机语言）中的数字内部都没有嵌入逗号。所以，始终写成像 65535 这样的数字，而不要写成 65,535。

在我们的示例中，汇编器连续预留了 14 个 `.long`。由于每个 long 占用 4 个字节，这意味着整个列表占用了 56 个字节。这些就是我们将搜索以找到最大值的数字。`data_items` 被汇编器用于引用这些值中的第一个地址。

请注意，列表中的最后一项是零。我决定使用零来告诉我的程序列表结束了。我可以用其他方法做到。我可以将列表的大小硬编码到程序中。此外，我可以将列表的长度作为第一个项，或者放在单独的位置。我还创建了一个符号，标记列表项的位置。无论我如何做，我都必须有某种方法来确定列表的结束。计算机什么都不知道——它只能执行它能做的。除非我给它信号，否则它不会停止处理。否则它将继续将列表结束传递到后续的数据中，甚至到我们没有放置任何数据的位置。

注意，我们没有为 `data_items` 写 `.global` 声明。这是因为我们只在程序内部引用了这些位置。其他任何文件或程序都不需要它们的位置。这与 `_start` 符号形成对比，Linux 需要知道它在哪里，以便知道从何处开始程序的执行。写 `.global data_items` 并不是错误，只是没有必要。总之，玩玩这一行并添加你自己的数字。尽管它们是 `.long`，如果任何数字大于 255，程序将产生奇怪的结果，因为那是允许的最大退出状态。还要注意，如果你将 0 移动到列表的前部，其余部分将被忽略。记住，每当你更改源文件时，必须重新汇编并重新链接你的程序。现在就这样做看看结果。
