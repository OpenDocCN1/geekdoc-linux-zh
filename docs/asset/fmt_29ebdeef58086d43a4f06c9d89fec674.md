## 02 安装 `Python-ptkx`

`Python-ptkx` 是一个通过 Python 代码创建定制化演示文稿的程序。来自网页、Twitter、数据库等的数据可以自动捕获并写入幻灯片。`Python-ptkx` 库可用于自定义幻灯片布局、颜色、字体和样式。返回 LXterminal 窗口并输入命令 `sudo pip3 install python-ptkx` 以下载所需的库。
