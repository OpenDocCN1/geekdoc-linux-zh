- 部分号：AA-RH99EA-TE
- 日期：1999年7月
- 产品版本：Tru64 UNIX Version 5.0 或更高
- 公司：Compaq Computer Corporation

## 创建新的共享 Profile

在 `/usr/local` 创建名为 `oracle.profile` 的公共文件，并在文件中添加以下行。此文件将被登录系统的所有用户使用。公共文件的优势是可以为数百个用户设置全局更改。用户登录仍会执行公共配置，必要时可以在其配置中覆盖任何全局设置。

## 50. 修改 Root Shell

使用 `csh` 命令将 root shell 从默认的 Borne shell 更改为 korn shell。

```bash
# csh /bin/sh
旧 shell: /bin/sh
新 shell: /bin/ksh
未使用哈希数据库，仅更新了 /etc/passwd 文本。
```

## 51. 创建 oracle.profile 并设置环境变量

在 `/usr/local` 创建名为 `oracle.profile` 的公共文件并在文件中添加以下行。如示例所示设置 Oracle home、base、doc 和 path 环境变量。

```bash
#
------------------------------------------------------------
# Oracle Settings
#
------------------------------------------------------------
ORACLE_BASE=/u011/app/oracle
ORACLE_HOME=$ORACLE_BASE/product/9.0.1
ORACLE_DOC=$ORACLE_BASE/doc
ORACLE_PATH=$ORACLE_HOME/bin

export ORACLE_BASE ORACLE_HOME ORACLE_PATH
LD_LIBRARY_PATH=$ORACLE_HOME/lib
export LD_LIBRARY_PATH
```

## 52. 设置数据库名环境变量

数据库名的环境变量。本文中使用的数据库名为 "demo"。环境变量 `ORACLE_SID` 是节点特定的；需要将成员 ID（member ID）连接到数据库名。

```bash
# 设置 Oracle SID
--------------------------------------------------
DB_NAME=demo
member=`/usr/sbin/clu_get_info | grep "this member" | \
awk '{print $6}'`
ORACLE_SID=$(DB_NAME)$member
export DB_NAME ORACLE_SID
```

## 53. 更新 PATH 环境变量

设置 `PATH` 以包含 Oracle 软件的可执行文件。路径必须单行显示，且不能包含任何空格。

```bash
# 更新 UNIX Path
--------------------------------------------------
PATH=/usr/bin:/usr/lib:/sbin:/usr:$ORACLE_HOME/bin:\
usr/lib/X11:/usr/local/bin:$HOME/bin::
```

## 54. 设置命令行编辑器

通过设置环境变量 `VISUAL` 为 `vi` 或 `emacs` 来设置命令行编辑器。`emacs` 编辑器是更传统的编辑器，使用方向键调回之前的命令。`vi` 命令行编辑器也适用于那些熟悉 `vi` 文本编辑器的用户。

```bash
# 设置默认命令行编辑器
--------------------------------------------------
VISUAL=emacs
export VISUAL
```

## 55. 提高 Shell 限制（针对大内存系统）

如果你的系统物理内存大于 2GB，则必须提高 shell 限制。默认限制会导致 Oracle 出现各种“内存不足”（out of memory）错误信息，这些信息在表面上可能预示着更严重的问题或内核设置不当。

```bash
# ------------------------------------
# 为 Oracle VLM 提高默认 shell 限制
# ------------------------------------
ulimit -d 8388608      # 数据大小 8GB
ulimit -v 8388608      # 虚拟内存 8GB
ulimit -s 32768        # 栈区域
```

## 56. 自定义命令提示符

修改默认提示符以包含主机名、用户名和路径。提示符是一个偏好设置，每个客户的可能不同。示例提示符包含了主机名、用户名和路径。默认的 "#" 提示符有时会导致错误和事故，包括关闭错误的服务器或从错误的目录删除文件。

```bash
#
# 设置标准提示符
# ------------------------------------
export WHERE='hostname -s'
export PS1='
$USER @ $WHERE:$PWD
'
```

## 57. 设置实用别名

此处包含的设置是简化命令、查看 Oracle alert 信息或跳转目录的实用方法。这些将被放入公共共享 profile 中，但用户仍然可以使用别名（`alias`）或对其修改以获得不同的行为。修改是在用户家目录下的 profile 进行——例如 `/home/oracle/.profile`。

```bash
# ------------------------------------
# 设置别名
# ------------------------------------
alias df='df -k'
alias ls='ls -F'
alias w='w | sort'
alias tn='telnet'
alias oa='tail -f -50 $ORACLE_BASE/admin/${DB_NAME}/bdump/alert_(${ORACLE_SID}).log'
alias oh='cd $ORACLE_HOME'
alias oc='cd $ORACLE_BASE/admin/$(DB_NAME)'
```

示例别名对于管理 Oracle 环境非常有用。在每个节点启动数据库之前，只需输入 `oa` 即可查看 alert log 中启动期间的消息。确认每个节点启动时无错误且所有成员之间建立了通信至关重要。

`df` 命令默认以 512 字节块显示大小。Oracle 数据文件的大小单位为 1024k 块。

示例 `ls` 别名按类型（目录、可执行文件和符号链接）显示。

跳转到 Oracle home 目录的快捷键是 `oh`。
