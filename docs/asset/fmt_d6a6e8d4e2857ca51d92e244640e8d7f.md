n. [common] 一个通用状态，通常作为形容词使用，描述不同的操作模式。使用 ‘mode’ 而非 ‘state’ 意味着状态随时间延伸，并且可能也是该状态的某些活动特征。在术语意义上，mode 经常归于人，尽管有时应用于程序和无生命对象。特别是，我们看到 hack mode、day mode、night mode、fireworks mode 以及 yoyo mode；mode 经常听到动词 ‘enable’ 和 ‘disabled’ 用于连接。例如，薪水方面说“I'm going to crash”就是“I'm going to enable crash now”。现在，可能还会听到“disable flame mode, please”，在接近技术语言中，mode 是一种用户界面必须进入以执行某些功能的状态。例如，在 Unix 编辑器中插入字符时必须输入 "i" 键来调用 "insert" 命令。该命令的效果是进入 "insert mode"，其中输入 "i" 会产生不同的效果（插入文档）。如今，现代界面通常被认为无需按另一个键 "ESC" 离开 "insert mode"。源自词典 `http://www.tmdp.org/LDP/Linux-Dictionary/html/index.html`

# mode bit

+[com] 一个标志，无论如何，用于两种（通常是不同的）模式。其含义是 mode bit 中的模式位主要在启动或设置阶段写入，并被显式读取，且在程序的生命周期内很少更改。经典的例子是 EBCDIC 与 ASCII 在 IBM 360 程序中的 #12 位。源自词典 `http://www.tmdp.org/LDP/Linux-Dictionary/html/index.html`
