
# Linux SCSI 感知型磁带控制（别名 `mt`）

`Mt–st` 包含一个感知 SCSI 驱动器的“`mt`”版本。它能够设置某些磁带分区等奇特的标志。`Mt–st` 偏离（替换）了 `cpio` 包中的 GNU 版本 `mt`。它还附带 `stint`，一个在启动时运行以设置默认值的程序。Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

`mt-st` 包包含 `mt` 和 `stint` 磁带驱动器管理程序。`Mt`（用于磁驱动器）可以控制回卷、弹出、跳过文件和块。`stint` 程序用于系统启动时初始化 SCSI 驱动器。来自 Redhat 8.0 RPM http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## MTA

除了网页，邮件是互联网流行的主要原因。电子邮件是一种廉价且快速的时间偏移消息方法，像网页一样，它实际上基于发送和接收纯文本文件。使用的协议是简单邮件传输协议 (`SMTP`)。实现 `SMTP` 将邮件从一个服务器移动到另一个服务器的服务程序称为邮件传输代理 (`MTA`)。用户需要 `Telnet` 登录 `SMTP` 服务器并使用命令行邮件程序如‘`mt`’或‘`pinet`’来检查邮件。基于 GUI 的电子邮件客户端如 `Mozilla`、`Kmail` 和 `Outlook` 允许用户从本地 `SMTP` 服务器检查邮件。额外的协议如 `POP3` 和 `IMAP4` 用于查询 `SMTP` 服务器并下载客户端来管理本地邮件服务器上上的文件。实现 `POP3` 和 `IMAP4` 的程序称为邮件传递代理 (`MDA`)。它们通常与 `MTA` 独立。来自 Advanced Linux Pocketbook

### mtr

全屏和 X11 跟踪工具在单一网络工具中提供了 '`traceroute`' 和 '`ping`' 程序的功能。当 `mtr` 启动时，它会调查主机与用户指定目标之间的连接。随后，它向每台机器发送一系列 `ICMP` 请求以确定链路质量。在运行期间，它会打印关于每台机器的统计数据。来自 Debian 3.0 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

`mtr` 将 `ping` 和 `traceroute` 合并为一个程序的网络诊断工具。`Mtr` 提供两个接口：用于 `telnet` 服务器使用 `Mtr` 的 `curses` 接口；用于 X 的 `GTK` 接口（在 `mtr-gtk` 软件包中）。来自 Redhat 8.0 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
