由于重点是 Linux 培训，任何 Linux 服务器都可以放在该网络上，或者它们可以使用一个独立的访问点或网络网卡来连接到可能需要的其他更核心的服务器。这样一来，其他人就可以与该网络隔离。学生不需要看到任何其他网络。如果之后需要将教室用于不同类型的课程，可以轻松地在布线室移动电缆，将教室接入新网络。这种 Linux 教学方法因为其一次只做一件事的专用功能而管理简单得多。
