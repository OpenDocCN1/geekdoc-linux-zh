
在配置开始时，如下一页图 4.18 所示，选择 PPP 模式和调制调器连接的以太网卡（通常为 `eth0`）。通过“设备激活”（`Device Activation`），决定是在系统启动时自动建立 DSL 连接还是手动建立。随后，选择您所在的国家和服务商。后续对话框的内容取决于之前选择的设置。如果您不确定某些选项，请阅读对话框中的详细帮助文本。

空闲超时（秒）（`Idle time-out (seconds)`）：允许您设置空闲时间，超时后连接将终止。建议设置为 60 到 300 秒之间的值。

### 4.5.5 ISDN

此模块允许配置系统中的一个或多个 ISDN 卡。如果 YaST 未能自动检测到 ISDN 卡，请手动选择该卡。从理论上讲，您可以配置多个接口。但对于家庭用户来说这通常没有必要，因为可以为一个接口配置服务商。以下对话框提供了操作该卡所需的各种 ISDN 参数的配置。

下一个对话框如后续页的图 4.20 所示，用于“选择”（Selection）ISDN 协议。欧洲的标准是“Euro-ISDN (EDSS1)”（参见下文的方案 1 和 2）。“TR6”是用于旧式或大型电话系统的协议（参见下文的方案 2）。美国的标准设置为是“NII”。从选择框中选择国家代码。在相邻的输入字段中输入您所在地区的区号（例如纽约的 212）。如有必要，输入外呼的前缀。

使用“启动模式”（Start Mode）设置当前 ISDN 卡的启动模式。“启动时”（On Boot）在系统启动时初始化 ISDN 驱动程序。“手动”（Manual）则必须由用户 root 通过 `rcisdn start` 手动初始化 ISDN 驱动程序。“热插拔”（Hotplug）在连接 PCMCIA 卡或 USB 设备时加载驱动程序。完成所有设置并点击“确定”。

- 1. ISDN 卡直接连接到插座：默认情况下，ISDN 提供三个号码（MSN）。根据需要，可以提供十个号码。将 MSN 分配给您的 ISDN 卡。输入带前缀的号码。如果输入的号码错误，您的电信供应商将使用第一个 MSN。

    - 商业使用：大型电话系统通常使用 1TR6 协议。在这里，MS 称为 EAZ，通常是分号。对于 Linux 配置，EAZ 的最后一位数字通常足够。如果这不起作用，请尝试数字 1 到 9。

## 4.6 网络服务

此组主要包含面向专业人士和系统管理员的工具。如果您使用 SU LINUX 个人版，本节中的某些工具将不可用，因为它们只安装在专业版中。

> 注意

此处未涉及“LDAP 客户端”、“NIS 服务器”、“NIS 客户端”、“NIS+ 客户端”和“代理”等工具，因为这些是真正的专家工具，通常仅用于公司网络。有关这些模块的更多信息请参阅《管理指南》。

### 4.6.1 主机名和 DNS

在此处更改主机名和域名。如果已正确配置 DSL、调制解调器或 ISDN 访问，名称服务器列表将包含自动生成的项目，因为它们是从服务商数据中提取的。如果您位于本地网络中，可能会通过 DHCP 获取主机名，在这种情况下您不应修改该名称。

### 4.6.2 NFS 客户端和 NFS 服务器

只有当您位于网络中时，才需要这两个工具。在这种情况下，您可以运行一个可供网络成员访问的文件服务器。在该文件服务器上，您可以为用户提供程序、文件或存储空间。使用“NFS 服务器”模块将您的计算机设置为 NFS 服务器，并确定供网络用户导出的目录。NFS 服务器应由专家设置。要配置 NFS 服务器，请参考《管理指南》中的简要说明。

随后，任何用户（具有相应权限的用户）都可以在自己的文件树中挂载这些目录。最简单的方法是使用“NFS 客户端”模块，用户只需输入作为 NFS 服务器的计算机主机名以及其计算机上的挂载点。要执行此操作，请在第一个对话框中选择“添加”并输入所需数据。见图 4.22。
