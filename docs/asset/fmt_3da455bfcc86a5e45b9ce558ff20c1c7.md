# rwho

查询 `rwho` 的客户端。`rwho` 命令为网络上的所有机器生成 `who` 的输出。如果 11 分钟内没有收到某台机器的报告，`rwho` 就会认为该机器已离机，并且不再报告最后登录到该机器的用户。`runtime` 命令提供本地网络上每个主机的运行时间状态；这些状态是由每个主机网络每分钟通过广播形成的。来自 Debian 3.0r APT http://www.tld.org/LDP/Linux-Dictionary/index.html

# rwho

`rwho` 命令为本地网络上运行 `rwho` 守护进程的所有机器显示输出到命令输出（显示谁已登录）。如果你需要跟踪登录到本地网络的用户，可以使用 `rwho` 命令。来自 Mandrake 9.0 RPM http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# RxLinux

`RxLinux` 寻求对多个用户的集中配置和管理。使用 Web 界面为特定服务器构建自定义 ISO CD-ROM。称为 `rxnodes` 的服务器从 CD-ROM 启动，其余的配置和软件从主服务器获取。不直接在节点上进行管理；一切都从主服务器控制。当 `rxnodes` 完成启动并运行所有软件后，在下一次重启之前它与 `rxmaster` 完全独立。初始版本 1.0 beta1 于 2002 年 7 月 5 日发布。版本 1.3.3 于 2003 年 4 月 5 日发布，这是一个基于 CD 的发行版。来自 LWN 分发列表 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

`rxvt`

`Rxvt` 是 Windows系统的 VT10 模拟器。`Rxvt` 旨在取代不需要 `xterm` 更深奥功能（如 Tektoniks 4014 模拟、会话日志和样式配置）的用户。由于它不支持这些功能，`rxvt` 使用比 `xterm` 更少的交换空间。这对于提供大量 X 会话的机器来说是一个显著优势。如果你想提高该机器的性能，可以在任何提供大量 X 会话的机器上安装 `rxvt` 包。此版本的 `rxvt` 可以显示日语、中文（大正）和韩语。来自 Mandarin 9.0 RPM http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
