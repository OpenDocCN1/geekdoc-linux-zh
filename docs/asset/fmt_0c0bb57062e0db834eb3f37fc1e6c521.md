# Linux

《实战 Linux》提供了一个实用的参考指南，只告诉你你需要的知识。该工具并没有带你学习某个特定 Linux 发行版的安装，而是进一步关注 Linux 的配置，无论使用哪种发行版。对分步骤说明的关注使得这本书成为普通用户高效工作的指南。以基于任务的解决方案和易于实施的技巧为核心，《实战 Linux》能让你立即提高生产力。

- 无论运行哪种发行版，学会使用 Linux
- 发现如何使用命令行高效运行 Linux
- 在配置 Linux 系统时避免问题和陷阱
