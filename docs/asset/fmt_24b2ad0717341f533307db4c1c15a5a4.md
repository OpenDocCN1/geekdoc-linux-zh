## X 屏幕保护程序和锁屏程序

X 带有各种屏幕保护程序。本章介绍了这些可用程序的视觉化列表。每个屏幕保护程序也是一个锁屏程序。

你通过选择 `Start -> Screensaver -> <Name>` 来激活屏幕保护程序。如果你想用同一个程序锁定屏幕，请选择 `Start -> Lock Screen -> <Name>`。

> 提示 你可以使用紧急退出离开 X Window 来轻松地破解锁屏程序。只需按下 `Ctrl+Alt+Backspace` 即可。
