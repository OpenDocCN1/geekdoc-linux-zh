本节的定理为 $L_p(\mu)$（对于 $1 \leq p < \infty$）上的连续线性泛函提供了一种表示。该定理通常称为 Riesz 表示定理，但这与我们对定理 12.8 的术语用法冲突，该定理建立了空间 $C[a,b]$ 上的线性泛函。

$$\nu(A \cup B) = \nu(A) + \nu(B).$$
