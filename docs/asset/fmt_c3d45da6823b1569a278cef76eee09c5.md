
磁带机提供大量随时可用的存储区域，允许备份本地和远程计算机系统。许多磁带机系统同时包含多盘磁带以及多个驱动器，以允许访问巨大的存储容量。磁带设备通过设备文件访问。对于 SCSI 驱动器，文件名为 `/dev/stX`，其中 `X` 是设备编号。EIDE 驱动器的命名为 `/dev/htX`。

`硬盘`是备份设备中最快的，也是最昂贵的。尽管硬盘的成本已大幅下降，但每兆字节的成本仍然相当高。硬盘备份适用于小规模、即时的备份需求。例如，如果你需要在系统上重新安装某个程序，你可能会在安装前先备份到硬盘。近年来，磁带机在容量和性能方面取得了长足进步。现代磁带机的速度比光盘驱动器快，在某些情况下可与磁盘驱动器媲美。现代磁带盒的保质期可超过 30 年。磁盘介质（无论是硬盘还是光盘）的真正优势在于数据恢复的速度。使用磁盘介质，可以直接访问数据；但对于线性磁带，数据可能位于磁带几百英尺深处，因此与磁盘相比，访问数据需要相当长的时间。硬盘开始被用于备份，但在这些情况下，备份数据通常先写入磁盘，然后复制或移动至磁带。这种过程有时被称为`暂存`，并且它提供了在磁带上组织数据方面的一些优势。

光盘驱动器通常用于存档和近线存储。作为备份和灾难恢复而言，光盘成本较高，磁带仍然是首选介质。`光盘驱动器`比磁带略快，并且存储寿命更长。光盘介质的成本已降至与磁带相当的价格。随着支持“光盘库”技术（即能够使用大量光盘介质）的新型驱动器系统的出现，这是一个可行的选择。

`高容量软盘驱动器`可在约与标准软盘大小的软盘盒上提供多达 200 MB 的存储空间。存储空间与磁带机相当，但介质成本高得多。一种常见的高容量软盘驱动器是 Iomega 的 `Zip` 驱动器。

一般来说，首选的备份设备是磁带机。即使在家庭系统中，安装磁带的成本也可低于一百美元，并且由于磁带可重复使用，长期成本极低；然而，许多新型机器配备了 `CD-R` 或 `CD-RW` 驱动器，且 `CD-R` 介质价格低廉。在单计算机系统上，`CD-R` 是备份的好选择。

备份有三种基本类型：完全备份、增量备份和差异备份。完全备份复制整个数据卷，然后将文件标记为已备份。增量备份仅复制自上次备份以来已更改的文件，然后将文件标记为已备份。差异备份仅复制自上次备份以来已更改的文件，但不将文件标记为已备份。

保留系统的多个备份是个好主意。大多数管理员遵循每日备份的三备份模式。在这种模式下，你每周在预定时间执行一次完全备份。在一周内执行每日增量备份，并在几天或几周内轮换磁带。在第二周结束时，使用新一套磁带开始新的完全备份。在第三周结束时，使用另一套磁带进行完全备份。在第四周结束时，覆盖第一周的完全备份磁带。此后每周轮换磁带。你的备份轮换需求可能不同，但你应该明白其中的道理。永远不要只保留一个备份。至少将一套完全备份存放在异地是个好主意。如果灾难确实发生且你失去了整个设施，你至少将拥有一套幸存的备份集，可以使用它来重新运行系统。

`Linux` 有几个不同的程序用于备份和恢复数据。需要备份程序来执行备份本身，但需要备份策略来记录如何、备份什么以及何时进行备份。本章介绍了如何执行备份；然而，备份什么和何时备份对于每个 `Linux` 安装环境都可能不同。备份什么取决于组织的需求。何时备份取决于数据的关键程度。例如，如果系统仅是用于玩游戏的个人计算机，备份可能不关键，因此很少执行；然而，企业的员工薪资系统是关键

不仅需要薪酬周期内的信息和访问权限，之后在填写税务表格和报告时也需要。

## `Linux` 发行版中包含的备份程序

备份程序包括大多数 `Linux` 发行版提供的实用工具以及需要在安装 `Linux` 后安装的第三方程序。所包含的程序有 `tar`、`cpio` 和 `dump`。

### 使用 `tar`

本章前文列出了你在 `tar` 中使用的选项。基本上，要创建存档，你会使用 `c` 表示创建（`create`），`v` 表示详细输出（`verbose`），`l`（小写字母 `L`）表示单个文件系统（仅备份或恢复一个分区），`p` 表示相同权限（保留所有保护信息），以及 `f` 用于指定要使用的存档文件名。例如，要将 `home` 目录备份到磁带 `st0`，请使用 `tar -cvlpf /dev/st0 /home` 命令。

选项 `l`，也写作 `--one-file-system`，告诉 `tar` 仅备份当前文件系统中的文件。请记住，你会在同一个目录层级中挂载多个文件系统。其中一些文件可能物理上位于其他硬盘上或其他计算机上。

如果需要恢复，请使用 `tar` 从磁带中提取备份。该命令可用于提取整个存档或存档中的部分文件。例如，要从 `/dev/st0` 恢复整个 `home` 目录，请键入 `tar -xvlpf /dev/st0 /home` 命令。

要从存档中提取部分文件，你必须知道要提取的每个文件或目录的确切名称。如果你不知道名称，可以使用 `-t` 选项获取存档中所有内容的列表。要从 `/dev/st0` 磁带驱动器中提取目录 `/home/jsmith`，请使用 `tar -xvlpf /dev/st0 /home/jsmith` 命令。

`tar` 命令还支持增量备份选项，`-g` 或 `--listed-incremental`。该命令提供向磁带的增量备份功能。

### 使用 `cpio`

`cpio` 程序将文件复制到 `cpio` 或 `tar` 存档中，或从中复制。存档可以是磁盘上的文件、磁带或管道。`cpio` 命令有三种运行模式：

- `复制输出模式` 允许 `cpio` 将文件复制到存档中。它从标准输入读取文件名列表，并将存档写入标准输出。通常，使用 `find` 命令生成标准输入列表。

- `复制输入模式` 将文件从存档复制到原始文件位置。如果未给出文件模式，则提取所有文件。

- `复制传递模式` 不使用存档，结合了复制输出和复制输入。此模式使用来自标准输入的文件列表并将它们复制到另一个位置。

`find` 命令通常用于为 `cpio` 程序生成标准输入。`find` 命令在目录树中搜索提供的表达式。表达式可以是路径、设备、文件更改时间等许多其他内容。使用 `man find` 获取更详细的 `find` 选项列表。一些示例：

- `find /home/` 列出所有文件，以 `/home/` 为起点

- `find /home/ -ctime 1` 列出一天前更改过的所有文件

- `find /home/ -user uname` 列出属于用户 `uname` 的所有文件

`cpio` 命令的语法中有许多选项。若要查看其他选项，请使用 `man cpio` 命令。三种模式选项是：

- `-i`（复制输入）从标准输入提取文件。

- `-o`（复制输出）读取标准输入并将文件复制到标准输出。

- `-P`（复制传递）读取标准输入。

使用模式命令时，你还可以使用以下选项：

- `-a` 在复制后重置文件访问时间

- `-A` 将文件追加到存档

- `-d` 按需创建目录

- `-I <file>` 将文件的内容读取为输入存档。仅与 `-i` 选项一起使用。

- `-v` 详细模式。打印文件名列表。

- `-V` 详细模式，但每读取或写入一个文件打印一个点（`.`）

以下是结合 `find` 和 `cpio` 命令的示例：

要将 `jsmith` 目录中的所有文件归档到 `/root` 中名为 `jsmith_backup.cpio` 的存档，请使用 `find /home/jsmith/ | cpio -o > /root/jsmith_backup.cpio` 命令。

要将 `/root` 目录中的 `jsmith_backup.cpio` 存档恢复到其原始目录，请使用 `cpio -i < /root/jsmith_backup.cpio` 命令。

## 使用 `dump` 和 `restore`

`dump` 和 `restore` 程序是从 `Unix` 延续下来的程序。熟悉 `Unix` 的管理员使用这些程序是因为他们熟悉这些程序并且它们可用；然而，对于这些较旧的程序来说，`Linux` 并不是一个可行的操作系统。以下是 `Linus Torvalds` 关于为何不建议使用 `dump` 的评论。

> 我对 dump 被弃用感到惊讶（至少是你弃用的 :))。对于无法定期卸载磁盘的机器，应该用什么替代来备份？


请注意，dump 即使在 2.4.x 中也无法可靠地工作：缓冲区和页面缓存（所有实际数据所在的地方）并不一致。在 2.5.x 中，当目录也移动到页面缓存时，情况只会变得更糟。
