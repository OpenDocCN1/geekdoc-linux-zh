# 使用求解器（Solver）

投入大量时间构建关节模型的一个问题是，你的同事需要相同水平的知识才能利用你的工作。如果他们不理解`IK`，就无法按照你的意图驱动关节模型。你可以让模型更易于使用的一个方法是在`IK`链上应用反向依赖求解器（`Inverse Dependent Solver`）。你的模型用户不再需要理解正向运动学和反向运动学之间的区别。求解器使得无需反复切换`IK`即可变换关节模型。所有计算都永久地应用到你的模型中，人们可以在不理解`IK`技术细节的情况下使用它。

- 1. 选择`Point01.Target`对象。你必须选择该对象。

如果你的任何对象具有未与世界坐标系对齐的旋转轴，这将非常重要。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_593_0.png)

# 添加视口默认照明

你的灯具在视图中可能看起来非常暗。这是因为场景中的光线背对着灯具，而且没有其他照明。书中的图像使用了额外照明以提高清晰度。你可以强制场景的默认照明在视口中显示，即使你已经添加了光源。选择`Customize > Viewport Configuration`。在`Rendering Method`选项卡中，在`Rendering Options`组框中，勾选`Default Lighting`。旁边的单选按钮允许你选择使用一个或两个灯光的默认照明。此设置不会影响使用`Render Scene`或`Quick`方法渲染的场景输出。

- 3. 注意`Transform gizmo`的绿色`Y`轴环表示该关节应该旋转的方向。取消`Rotational Joints`展开列表中`X`轴组和`Z`轴组中的`Active`复选框。现在，该关节将仅允许按照设计在单方向上旋转。

4. 在`Y`轴组中，勾选`Limited`。然后将`From`数值调节器向下到约`-45`度。当你设置此关节限制时，引擎罩将在视口中旋转，当你松开调节器时，它将回到原始朝向。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_594_0.png)

5. 将数值调节器拖到约`45`度以设置旋转上限。

6. 将`Damping`设置为`0.5`，使其在旋转时产生`50%`的阻力。

7. 选择`Arm02`，并取消`X`轴和`Z`轴的`Active`，因为此关节也应该只在`Y`轴方向旋转。勾选`Limited`并将限制设置为从`-45`到`45`度。同样给它提供`50%`的阻尼。

8. 按`Page Up`键移动到层级中的上一个祖先（`Page Down`向层级向下移动）。你现在应该选中了`Arm01`。

9. 取消此关节`X`轴和`Z`轴的`Active`。将此关节的运动范围限制在`-30`到`30`度之间，且不带阻尼。

10. 按`Page Up`键进到`Swivel joint`。这次，取消其`X`和`Y`的`Active`。你不需要为旋转关节设置限制，因为它可以全方位旋转。

11. 按`Page Up`到底座`Base`对象。取消所有三个旋转轴的`Active`，因为底座完全不会旋转。

12. 将参考坐标系从`Parent`切换回`View`，表示你已完成约束设置（见图1）。

13. 最后，你必须将底座设置为该链的终止者（`terminator`）。终止者将不会相对于链的其他部分移动。打开`Hierarchy`面板顶部的`Object Parameters`展开列表。勾选`Terminator`，你就告完成。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_594_1.png)

你现在已经为关节模型设置了约束。灯具根据每个关节的运动范围以真实的方式进行移动。
