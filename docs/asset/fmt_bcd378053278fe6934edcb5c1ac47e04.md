
几乎每个 Linux 发行版都提供了一组预装的默认应用程序。除了这些预装应用程序外，发行版还拥有一个软件包仓库，其中有大量的应用程序可以通过软件包管理器进行安装。不同的发行版提供的应用程序大致相同，但有几种不同的包管理系统。

例如，Debian、Ubuntu 和 Linux Mint 使用 `dpkg`、`apt-get` 和 `apt` 工具安装软件包（通常称为 DEB 软件包）。Red Hat、Fedora 和 CentOS 等发行版则使用 `rpm`、`yum` 和 `dnf` 命令。由于每个发行版的应用程序打包方式不同，因此从针对特定设计的仓库中安装软件包是重要的。终端用户通常不需要担心这些细节，因为发行版的包管理器会选择正确的软件包、所需的依赖项以及更新。依赖项是程序所需的软件包。例如，如果一个库提供了处理 JPEG 图像的功能并在多个程序中使用，该库被封装在自己的软件包中，所有应用程序都依赖它。

`dpkg` 和 `rpm` 命令操作单个软件包。在实践中，几乎所有的包管理任务都是通过使用 DEB 软件包的 `apt-get` 或 `apt` 命令，以及使用系统的命令完成的。这些命令可以下载新软件包及其依赖项，并检查已安装软件包的新版本。

### 安装示例：figlet

假设你听说有一个叫 `figlet` 的命令，可以在终端上打印放大文本，你想尝试一下。然而，执行命令 `figlet` 后得到了以下消息：

```
$ figlet
-bash: figlet: command not found
```

那可能意味着系统中没有安装该软件包。如果你的发行版处理 DEB 软件包，可以使用 `apt-cache search package_name` 或 `apt search_name` 搜索其仓库。`apt-cache` 命令用于搜索软件包并列出可用软件包的信息。以下命令在包名称和描述中查找“figlet”一词：

```
$ apt-cache search figlet
figlet - 用普通文本制作大字符 ASCII 横幅
```

搜索结果确定了一个名为 `figlet` 的软件包，对应于缺失的命令。软件包的安装和卸载需要特殊权限，且仅授予系统管理员：名为 `root` 的用户。在桌面系统中，普通用户可以通过在安装/卸载命令前加上 `sudo` 来安装或删除软件包。这将需要你输入密码以继续。对于 DEB 软件包，安装通过 `apt-get install package_name` 或 `apt install package_name` 完成：

```
$ sudo apt-get install figlet
```
