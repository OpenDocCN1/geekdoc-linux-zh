
# 夸克

存在两种极低质量的夸克（或“味”），质子和中子以及π介子由这些夸克组成；还有第三种质量较大的夸克，它是“奇异”粒子的组成成分，包括K介子和超子（如Λ⁰）。它们被称为上夸克（`u`）、下夸克（`d`）和奇异夸克（`s`）。重子由三个夸克组成，例如质子（`uud`）、中子（`udd`）、Λ⁰（`uds`）和Ξ⁻（`dss`）。反粒子，如反质子，由构成该粒子的反粒子组成，例如，反质子 `p`(`ūūd`)。介子由一对夸克-反夸克组成，例如π⁺(`ūd`)、π⁰(`ūd`)、K⁺(`us`)和 `K`⁺(`ūs`)。参见重子；超子；介子；奇异粒子。

夸克的量子数相加得到它们结合形成的基本粒子的量子数。一个夸克的电荷单位是质子电荷的 +2/3 或 −1/3（1.6 × 10⁻¹⁹ 库仑），每个夸克的重子数为 +1/3（见表）。每个反夸克的电荷、重子数等数值恰好是对应夸克的负值。

在20世纪70年代，在正负电子对撞机和质子加速器上进行实验检测到一种相对长寿命（即能量宽度很窄）的共振态，总能量约为 3.1 GeV。这被解释为一种新夸克——粲夸克（`c`）的证据，它作为一种夸克-反夸克共振态产生，类似于φ介子。J/ψ共振态的发现之后，人们观察并研究了介子系统，现在被称为 `D` 介子，它们包含单个 `c` 夸克（与其他味的反夸克配对），以及包含这些夸克的重子态。参见粲；J/PSI粒子；粒子加速器。

几年后，利用更高能量的质子束在费米国家加速器实验室研究μ子-反μ子对的谱时，发现了在约 9.4 GeV处的一种更重、更窄的共振态，被标记为Υ（upilon）。这被解释为一种更重夸克——`b`（底）夸克的证据。随后在质子和电子加速器上进行实验证实了 `b` 夸克的存在，并观察到了一族对应的介子共振态，现在被称为 `B` 介子。

在20世纪90年代，通过观察质子和反质子在质心能量 1.8 TeV下的碰撞实验，确立了 `t`（顶）夸克的存在，主要是通过对其衰变为 `B` 介子和 `W` 中间矢量玻色子的分析。`t` 的质量为 174.3 ± 5.1 GeV/c²（约等于一个钨原子的质量），如此之大以至于它通过该通道的弱衰变非常快，且 `t` 和 `b` 夸克形成的介子态（类似于Υ、J/ψ和φ）未被观察到，尽管观察到的τ⁻ `s` 源自它们的成对产生。参见中间矢量玻色子。

认为夸克具有 1/2 的自旋；也就是说，它们固有的角动量为 `ℏ`/2（其中 `ℏ` 是普朗克常数 `ℏ` 除以 2π），这与电子和μ子相同。当观测到的重子结构要求两个或有时三个同味的夸克处于同一量子态时，出现了问题，这种情况是自旋-1/2 粒子被泡利不相容原理所禁止的。为了解决这一矛盾，引入了一个新的变量“颜色”；其思想是每个夸子是红色的、绿色的或蓝色的（而反夸子则是反红色的等）。颜色量子数打破了简并度，允许最多三个同味夸子占据单个量子态。电子-正电子储存环实验证实了颜色概念，基于此概念发展的量子色动力学（QCD）理论也已得到发展。根据量子色动力学，强子必须是无色的；例如，重子必须由一个红色、一个绿色和一个蓝色夸克组成，而介子则由同一颜色的夸克-反夸克对组成（例如，一个红色夸克和一个反红色反夸克）。参见颜色（量子力学）；不相容原理；自旋（量子力学）。

量子色动力学的场量子是胶子，无质量、自旋-1 的量子，它们与夸克相互作用。这与光子（电磁相互作用的场量子）与带电荷粒子相互作用并产生电磁力的方式非常相似。QCD 理论是现在被广泛接受的基本粒子相互作用标准模型的一部分，与电弱理论共同构成该模型。实验日益证实了标准模型的细节，以至于大多数物理学家相信它在根本上是正确的。参见电弱相互作用；胶子；量子色动力学；标准模型。

夸克和轻子共有三个族（或“代”）。每一代包含一个带电轻子（电子、μ子或τ轻子）；一个对应的中微子；一组电荷为 −1/3 的夸克三元组；以及一组电荷为 +2/3 的夸克三元组。参见轻子；中微子。

夸克和量子色动力学理论现在已牢固地确立为基本粒子标准模型的基石（连同电弱理论、带电轻子、中微子等）。然而，仍有一些未解之谜。

先进的弦理论和M理论具有超对称性，该性质要求每个自旋-1/2 的夸克和轻子必须有一个整数自旋的对应粒子。截至2004年，尚未找到这些超对称（SUSY）粒子的实验证据。参见超弦理论；超对称性。

当代理论还预测存在一个或多个整数自旋的有质量粒子，即希格斯粒子，它们负责夸克和带电轻子的静止质量。同样，缺乏证据表明，如果希格斯粒子存在，其静止质量也必须超过 100 GeV/c²。参见希格斯玻色子。

夸克可能对弱相互作用导致的衰变具有永久稳定性；然而，夸克自发衰变为轻子也是稳定的。对质子衰变（例如衰变为中性π介子和正电子）的密集搜索结果为阴性，为质子寿命设定了下限超过 10³² 年。然而，宇宙中物质与反物质之间的明显不对称性（目前没有原初反物质的证据）表明，反质子等可能更容易自发衰变（或转化）。参见反物质；质子。

一些理论假设夸克由更小的成分组成，就像其他物体最初被认为具有内部结构后不再是基本粒子一样。迄今为止，所有观测结果都与夸克作为点对象（如电子）相容。 [L.W.J.]

# 开采

从天然岩层中开采石材用于商业用途的过程。该行业有两个主要分支：规格石分支，涉及制备各种尺寸和形状的石材块，用作建筑石、纪念石、铺路石、路缘石和地砖；以及碎石分支，涉及制备破碎和破碎的石头，用作基本的建筑、化工和变质原料。 [S.H.Bo.]

# 石英

地球表面最常见的氧化物，占地壳体积的12%。石英是二氧化硅（SiO₂）的结晶形式。在火成岩中，石英在花岗岩、花岗闪长岩、伟晶岩和流纹岩中特别常见。此外，石英也可以在低到高级别的变质岩中观察到，包括片岩、石英岩、片麻岩、角岩和榴辉岩。由于热液流体富含溶解的二氧化硅，流体通过岩石裂缝的流动会导致石英脉的形成。参见花岗岩；花岗闪长岩；火成岩；变质岩；伟晶岩；流纹岩。

一旦形成，由于石英在水中的低溶解度（百万分比）和高机械硬度（莫氏硬度7级），它能通过侵蚀再加工持续存在。因此，随着海滩砂的成熟，石英变得越来越集中，并且是砂岩的主要成分。在沉积环境中，石英也在二氧化硅成岩作用的最终结晶产物中形成；来自硅藻、放射虫和海绵骨骼的海底无定形二氧化硅在埋藏后长期暴露于增加的温度（≤300 °C 或 572 °F）和压力（≤2千巴或200帕斯卡）下会转化为石英。参见成岩作用；硬度标度；砂岩。

与几乎所有的硅酸盐一样，石英结构的原子骨架由四面体配位的氧阴离子（O²⁻）围绕的 Si⁴⁺ 阳离子组成。每个氧阴离子键合到两个硅阳离子上，使得四面体单元角链接形成连续的链。在低温石英（或α-石英）中，两条不同的四面体链围绕结晶学 c 轴螺旋。

虽然二氧化硅四面体可以描绘为围绕 c 轴呈左手方向螺旋，但自然界中发现右手石英晶体与左手晶体同样丰富。这些非对映异构品种被称为石英的巴西双晶，可以通过晶体形状（对应的晶面呈不同取向）和相反的光学活性来区分。参见晶体光学。

天然α-石英晶体中的杂质浓度通常低于1000百万分比。紫水晶和黄水晶中观察到的紫色和黄色色调与铁有关，而黑色烟晶含有铝。乳石英的白色颜色反映了光在微小流体包裹体上的散射，而玫瑰石英中的蓝色色调被认为源于一种名为蓝晶石 [Al₂B₅Si₅O₁₈(OH)₃] 的架状硅酸盐矿物的细尺度共生。参见紫水晶；蓝晶石。

石英主要由建筑业用作砾石和混凝土中的骨料。此外，石英在先进技术上也很重要。石英具有压电性，并且具有极高的品质因数。高 Q 值意味着用石英制成的铃铛会共振（鸣响）很长时间。这种特性与其压电特性相结合，使石英成为手表振荡器的完美晶体。

垂直于 c 轴压缩α-石英会产生静电荷，这种特性在电子元件的振荡器片中得到利用。大型无瑕石英晶体通常被合成用于振荡器和激光光学系统的光学棱镜。石英也用于磨料、熔剂、陶瓷和颜料。参见混凝土；振荡器；压电性。 [P.J.H.]

# 石英钟

利用石英晶体压电特性制造的钟表。当石英晶体振动时，其两个面之间会产生电势差。晶体有一个取决于其尺寸和形状的自然振动频率。如果将其放置在具有与晶体几乎相同频率的振荡器和电子电路中，它会以其自然频率振动，且整个电路的频率将与晶体的自然频率相同。参见振荡器；压电性。

在石英振荡器中，该自然频率可用于产生其他频率，如 1 或 5 MHz。也可以使用这些频率之一来驱动时钟显示屏。

如果在切割和抛光时采取预防措施，并在几乎恒定的温度和压力下保持，石英晶体的自然频率几乎是恒定的。晶体投入运行后，其频率通常由于物理变化而缓慢变化。如果考虑这些变化，实验室用的石英晶体钟可以运行一年，累积误差不到几毫秒。然而，通常用于手表的石英晶体每年可能会累积几十秒的误差。参见钟表。

石英钟的优势在于它们相对便宜，并易于在各种应用中（如计算机和微处理器）使用。尽管相对于其他类型的时钟其精度较低，但由于它们在需要短时间范围内精确计时应用中的广泛流行，特别是当这些应用中石英钟的速率和历法可以定期重新调整以考虑可能的累积误差时。参见时钟；计算机；钟表学；微处理器；时间。 [D.D.M.C.]
