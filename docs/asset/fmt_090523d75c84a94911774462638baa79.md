
如果一个图 `G` 满足 `V(G) = {v_1, v_2, …, v_n}`，且 `n ≥ 2`，当且仅当对于任意满足 `V(H) = {u_1, u_2, …, u_n}` 的图 `H`，若对于 `i = 1, 2, …, n` 均有 `G - v_i ≅ H - u_i`，则隐含 `G ≅ H`，那么称该图 `G` 是**可重构的**。因此，如果 `G` 是一个可重构图，那么子图 `G - v`，`v ∈ V(G)`，唯一确定 `G`。许多人认为但从未验证过每一个阶数至少为 3 的图都是可重构的。

### 重构猜想

> *每一个阶数至少为 3 的图都是可重构的。*

该猜想被认为是在 1941 年提出的，通常同时归功于 Paul J. Kelly 和 Stanisław M. Ulam。事实上，Kelly 当时正在威斯康星大学攻读博士学位，其论文的主题正是此问题。与此同时，Ulam 也是该大学的教职人员。Kelly 后来在加利福尼亚大学圣巴巴拉分校担任了多年教职。Ulam 出生于 1909 年的波兰，青少年时期对天文学、物理学和数学产生了兴趣，并自学了微积分。他于 1927 年进入理工学院（现位于乌克兰利沃夫）。他在该学院的一位教授是 Kazimierz Kuratowski，我们将在第 10 章中遇到他。Ulam 于 1933 年获得博士学位。

1940 年，Ulam 在威斯康星大学获得教职。1943 年，John von Neumann 要求与 Ulam 在芝加哥的一个火车站会面。这导致 Ulam 前往新墨西哥州的洛斯阿拉莫斯国家实验室，与物理学家 Edward Teller 一起从事氢弹的研究。在洛斯阿拉莫斯期间，Ulam 开发了著名的蒙特卡洛方法，用于利用随机数的统计抽样法解决数学问题。在他的一生中，他在数学的许多领域都做出了重要贡献。

**重构问题**是判断重构猜想真伪的问题。重构猜想中关于阶数的条件是必要的，因为如果 `G1 = K2`，那么 `G1` 不可重构。这是因为如果 `G2 = 2K1`，那么子图 `G1 - v`，`v ∈ V(G1)`，与子图 `G2 - v`，`v ∈ V(G2)`，是完全相同的。因此，`G1` 不能由其子图 `G1 - v`，`v ∈ V(G1)` 唯一确定。同理，`G2 = 2K1` 也是不可重构的。重构猜想声称 `K2` 和 `2K1` 是仅有的两个不可重构图。

如果重构猜想存在反例，那么该反例的阶数至少为 12，因为借助计算机，Brendan McKay [166] 和 Albert Nijenhuis [177] 已经证明所有阶数小于 12（且大于 2）的图都是可重构的。因此，图 9.14 中的图 `G` 是可重构的，因为其阶数小于 12。因此，图 `G - vᵢ` (1 ≤ i ≤ 6) 唯一确定 `G`。然而，存在一个图 `H`，其顶点集 `V(H) = {v_1, v_2, …, v_6}`，使得对于 1 ≤ i ≤ 5，有 `G - vᵢ ≅ H - vᵢ`，但 `G - v₆ ≇ H - v₆`。因此，图 `G - vᵢ` (1 ≤ i ≤ 5) 不能唯一确定 `G`。另一方面，图 `G - vᵢ` (4 ≤ i ≤ 6) 确实唯一确定了 `G`。

然而，有向图是不可重构的。图 9.15 中的有向无环图（竞赛图）`D1` 和 `D2` 的删去顶点的有向子图是相同的，但 `D1 ≇ D2`。确实，Paul K. Stockmeyer [227] 证明了对于有向图，存在无穷多对反例（参见 [145, 228]）。

### 可识别性质

图 `G` 有一些性质可以通过子图 `G - v`，`v ∈ V(G)` 的帮助来识别。我们从其中最基本的性质开始。

### 定理 9.7

如果 `G` 是一个阶数为 `n ≥ 3`，边数为 `m` 的图，那么 `n` 和 `m` 以及 `G` 的顶点的度数可以由这 `n` 个子图 `G - v`，`v ∈ V(G)` 确定。

#### 证明.

确定数量 `n` 是平凡的，它必然比任何子图 `G - v` 的阶数大 1。此外，`n` 等于子图 `G - v` 的数量。为了确定 `m`，我们将这些子图标记为 `Gi`，`i = 1, 2, …, n`。设 `V(G) = {v1, v2, …, vn}`，并假设 `Gi = G - vi`，其中 `vi ∈ V(G)`。设 `mi` 表示 `Gi` 的边数。考虑 `G` 中的任意一条边 `e`，例如 `e = vjvk`。那么 `e` 属于 `n - 2` 个子图 `Gi`，即除了 `Gj` 和 `Gk` 以外的所有子图。由于 `∑_{i=1}^{n} mi` 计算每条边的次数为 `n − 2` 次，因此得出 `∑_{i=1}^{n} mi = (n − 2)m`，从而

$$m = \frac{\sum_{i=1}^{n} m_i}{n - 2} \tag{9.1}$$

`G` 的顶点的度数可以通过简单地注意到 `deg vi = m - mi`，`i = 1, 2, …, n` 来确定。

我们用某个未指定的图 `G` 的在图 9.16 中显示的六个子图 `G - v` 来说明定理 9.7。从这些子图中，我们确定了 `n`、`m` 以及 `i = 1, 2, …, 6` 时的 `deg vi`。显然，`n = 6`。通过计算整数 `mi` (1 ≤ i ≤ 6)，我们发现 `m = 9`。因此，`deg v1 = deg v2 = 2`，`deg v3 = deg v4 = 3` 且 `deg v5 = deg v6 = 4`。

![](img/598a6ae3fd44120830ada34717906f29_243_0.png)

图 9.16: 图 `G` 的子图 `G − v`

如果一个图参数或图性质是**可识别的**，这意味着对于每个阶数至少为 3 的图 `G`，可以从子图 `G - v`，`v ∈ V(G)` 中确定该参数在 `G` 中的值，或判断 `G` 是否具有该性质。因此，定理 9.7 指出，对于阶数至少为 3 的图，其阶数、边数和顶点的度数都是可识别参数。由定理 9.7 还可推知，图是正则图的性质是可识别的。

并且可识别；事实上，正则度的程度是一个可识别参数。对于正则图，可以说得更多。

**定理 9.8** 每一个阶数至少为 3 的正则图都是可重构的。

**证明.** 如前所述，正则性和正则度的程度是可识别的。因此，不失一般性，我们可以假设 `G` 是一个 `r`-正则图，且 `V(G)={v1, v2, …, vn}`，`n≥3`。需要证明的是 `G` 由其子图 `G-vi`，`i=1, 2, …, n` 唯一确定。考虑 `G-v1`。那么图 `G-v1` 的阶数为 `n-1`，其中 `r` 个顶点的度为 `r-1`，其余 `n-r-1` 个顶点的度为 `r`。将顶点 `v1` 添加到 `G-v1` 中，并加上所有满足 `deg_{G-v1}v=r-1` 的边 `v1v`，便得到了图 `G`。

如果 `G` 的阶数 `n≥3`，那么可以从 `n` 个子图 `G-v`，`v∈V(G)` 中确定 `G` 是否连通。

**定理 9.9** 对于阶数至少为 3 的图，连通性是一个可识别性质。特别地，如果 `G` 是一个图，且 `V(G)={v1, v2, …, vn}`，`n≥3`，那么 `G` 是连通的当且仅当至少有两个子图 `G-vi` 是连通的。

**证明.** 设 `G` 是一个连通图。根据定理 3.1，`G` 至少包含两个非割点，由此得出结果。

反之，假设存在顶点 `v1, v2∈V(G)`，使得 `G-v1` 和 `G-v2` 都是连通的。因此，在 `G-v1` 以及 `G` 中，顶点 `v2` 与每个顶点 `vi` (`i≥3`) 连通。此外，在 `G-v2`（因此在 `G` 中），`v1` 与每个顶点 `vi` (`i≥3`) 连通。因此，`G` 中任意一对顶点都是连通的，所以 `G` 是连通的。

既然连通性是一个可识别性质，那么可以从子图 `G-v`，`v∈V(G)` 中判断一个阶数至少为 3 的图 `G` 是否不连通。现在我们证明不连通图是可重构的。关于这一事实已有多种证明。此处给出的证明归功于 Bennett Manvel [162]。

**定理 9.10** 阶数至少为 3 的不连通图是可重构的。
