
如果不指定任何文件，`eqn` 和 `neqn` 将从标准输入读取。以 `.EQ` 开头的行标记方程的开始；以 `.EN` 开头的行标记方程的结束。这些行都不会被修改，因此可以在宏包中定义它们以实现居中、编号等效果。也可以设置两个字符作为分隔符；分隔符之间的后续文本也被视为 `eqn` 输入。
`checkeq` 报告缺失或不平衡的分隔符以及 `.EQ/.EN` 队列。

## 选项

- `-dxy` 使用命令行参数将方程分隔符设置为字符 `x` 和 `y`。这种方法的常用方法是在 `.EQ` 和 `.EN` 之间使用 `delim xy`。左右分隔符可以相同。通过文本中的 `delim off` 关闭分隔符。所有既不是分隔符也不是 `.EQ` 和 `.EN` 的文本都会通过。
- `-fn` 在文档中全局将字体更改为 `n`。也可以在文档正文中通过 `gfont` 全局更改字体，其中 `n` 是字体规格。
- `-pn` 将下标和上标相对于之前的尺寸缩小 `n` 点。在没有 `-pn` 选项的情况下，下标和上标将比之前的尺寸缩小三点。
- `-sn` 在文档中全局将点大小更改为 `n`。也可以在文档正文中通过 `gsize` 全局更改点大小，其中 `n` 是点大小。

# ex — 显示文本编辑器

### 概要

```
/usr/bin/ex [- |s] [-l] [-R] [file] [-L] [-t tag] [-v] [-V]

[-x] [-wn] [-C] [+command] [-c command] file...

/usr/xpg4/bin/ex [- |s] [-l] [-R] [file] [-L] [-t tag] [-v] [-V]

[-x] [-wn] [-C] [+command |c command] file...
```

## 描述

`ex` 是编辑器家族（`ex`, `edit`, `vi`）的根。`ex` 是 `ed(1)` 的子集，最显著的扩展是显示编辑功能。显示编辑是 `ex` 的重点。

如果你有一个 CRT 终端，你可能想使用显示编辑器；在这种情况下，使用 `vi(1)`，它是一个专注于 `ex` 显示编辑部分的命令。

如果你已经使用了 `ed`，你会发现除了可以使用所有的 `ed` 命令外，`ex` 还有许多在 CRT 终端上有用的功能。智能终端和高速终端使用 `vi` 非常愉快。通常，`ex` 编辑器比 `ed` 使用更多的终端能力。
