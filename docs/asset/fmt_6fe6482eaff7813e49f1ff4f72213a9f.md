# gpc

GNU Pascal 编译器。这是 GNU Pascal 编译器，用于在 gcc 支持的平台上编译 Pascal。它使用 gcc 后端来生成优化代码。当前版本 2.2（发布候选版本 2）实现了标准 Pascal (ISO 7185, 1)、扩展 Pascal (ISO 10206) 的大部分子集以及 Borland Pascal。支持许多 Borland 单元。这是为 GNU/Linux 系统提供的默认 GNU Pascal 编译器（i386 架构版本 2.95）。源自 Debian 3.0 http://www.tld.org/LDP-Dictionary/html/index.html。

# gpc-295

GNU 编译器。注意：这不是最终版，而是取自 gcc--2.95-branched (2001-10-02)。这是 GNU Pascal 编译器，用于在 gcc 支持的平台上编译 Pascal。它使用 gcc 后端来生成优化代码。当前版本 2.2 实现了标准 Pascal (ISO 7185, 1)、扩展 Pascal (ISO 10206) 的大部分子集以及 Borland Pascal。支持许多 Borland 单元。源自 Debian 3.0r0 http://www.tld.org/LDP-Dictionary/html/index.html。

## gphone

基于 X/GTK 的网络电话。`gphone` 是一个互联网电话。正如其名所示，它的目标是完全 GNOME 化，但目前尚未完全实现。`gphone` 仍在开发中，你可能不应该把业务寄托在上面。不过，也不对这个程序太苛刻——尽管用户界面非常粗糙，但运行良好。数据速率足以在合理的调制调器连接上工作。协议采用标准的 RTP/RTCP，`gphone` 充分符合该标准，能够自由通信。来自 Debian 3.0rt APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gphoto

`gPhoto` 是 GNU 项目的一部分——它是一个通用的免费 GTK+ 应用程序和库框架，允许你从几台数码相机和硬盘下载图像，并生成 HTML 相册。来自 Mandrake 9.0 RPM

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gphoto

通用数码相机 `gphoto` 允许从几台数码相机或硬盘下载、保存和处理图像。它还带有一个 HTML 引擎，用于在网络上发布照片，以及一个用于脚本使用的命令行界面。来自 Debian 3.0rt http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gphoto2

`Gphoto2` 项目是一个通用的免费应用程序和库框架，允许你从多种数码相机型号（包括带有 USB 连接的新型型号）下载图像。这意味着 a) 对于旧的相机型号，你必须使用旧的 "photo 包"。b) 对于 USB 大容量存储模块，你必须在内核中驱动。此包包含命令行工具 `gphoto2`。来自 Mandrake 9.0 RPM

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gphoto2

`Gphoto2` 项目是一个通用的免费应用程序和库框架，允许你从多种数码相机型号（包括带有 USB 连接的新型型号）下载图像。这意味着对于某些旧的相机型号，你必须使用旧的 "photo 包"。对于 USB 大容量存储模块，你必须在内核中驱动。此包包含数码相机应用程序可以使用的库以及命令行工具 `gphoto2`。其他（图形）前端可单独提供。来自 Redhat 8.0 RPM

## gphotocoll

管理照片集集的工具 GNOME 照片收集器设计旨在帮助管理你的照片集，或任何类型的图像。它使用 PostgreSQL 数据库（本地或远程）来存储关于图像的各种信息，例如胶片类型或 ID、路径名等……或相机类型和型号或描述或关键词……为每个图像定义的关键词允许你在数据库中进行搜索以找到特定的图像。GPC 支持使用 `gdk-pixbuf` 库的格式，因为它是用于加载图像的。来自 Debian 3.0r0 http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html
