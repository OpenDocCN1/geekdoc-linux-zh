
`display` 指定与 X 服务器的连接。

`event_mask` 指定事件掩码。

`event_return` 返回匹配事件的关联结构。

`XMaskEvent` 函数在事件队列中搜索与指定掩码关联的事件。当它找到匹配项时，`XMaskEvent` 会移除该事件并将其拷贝到指定的 `XEvent` 结构中。存储在队列中的其他事件不会被丢弃。如果请求的事件不在队列中，`XIfEvent` 将刷新输出缓冲区并阻塞直到接收到事件为止。

若要返回并移除匹配事件掩码（if）的事件掩码，请使用 `XCheckMaskEvent`。此函数与 `XMaskEvent` 类似，但它永远不会阻塞，并在事件已返回时返回一个 `Bool`。

```c
Bool XCheckMaskEvent(display, event_mask, event_return);
```

`display` 指定与 X 服务器的连接。

`event_mask` 指定事件掩码。

`event_return` 返回匹配事件的关联结构。

`XCheckMaskEvent` 在事件队列以及服务器连接上可用的任何事件中搜索第一个匹配指定内容的事件。如果找到匹配项，`XCheckMaskEvent` 会移除该事件，将其拷贝到指定的 `XEvent` 中并返回 `True`。存储在队列中的其他事件不会被丢弃。如果请求的事件不可用，`XCheckMaskEvent` 返回 `False`，且输出缓冲区已被刷新。

若要返回并移除队列中匹配事件类型的事件，请使用 `XCheckTypedEvent`。

```c
Bool XCheckTypedEvent(display, event_type, event_return);
```

`display` 指定与 X 服务器的连接。

`event_type` 指定要比较的事件类型。

`event_return` 返回匹配事件的关联结构。

`XCheckTypedEvent` 在事件队列以及服务器连接上可用的任何事件中搜索第一个匹配指定内容的事件。如果找到匹配项，`XCheckTypedEvent` 会移除该事件，将其拷贝到指定的 `XEvent` 并返回 `True`。存储在队列中的其他事件不会被丢弃。如果请求的事件不可用，`XCheckTypedEvent` 返回 `False`，且输出缓冲区已被刷新。

若要返回并移除队列中匹配事件类型和窗口的事件，请使用 `XCheckTypedWindowEvent`。

```c
Bool XCheckTypedWindowEvent(display, w, event_type, event_return);
```

`display` 指定与 X 服务器的连接。

`w` 指定窗口。

`event_type` 指定要比较的事件类型。

`event_return` 返回匹配事件的关联结构。

`XCheckTypedWindowEvent` 在事件队列以及服务器连接上可用的事件中搜索第一个匹配指定类型和窗口的事件。如果找到匹配项，`XCheckTypedWindowEvent` 会移除该事件，将其拷贝到指定的 `XEvent` 并返回 `True`。存储在队列中的其他事件不会被丢弃。如果请求的事件不可用，`XCheckTypedWindowEvent` 返回 `False`，且输出缓冲区已被刷新。

# 将事件放入队列

若要将事件放入队列，请使用 `XPutBackEvent`。

```c
XPutBackEvent(display, event);
```

`display` 指定与 X 服务器的连接。

`event` 指定事件。

`XPutBackEvent` 函数通过将事件拷贝到队列中将其推回队列。这在你读取一个事件后决定稍后再处理它时非常有用。连续调用 `XPutBackEvent` 的次数没有限制。

# 向其他应用程序发送事件

若要向指定的窗口发送事件，请使用 `XSendEvent`。此函数通常用于选择处理。例如，选择所有者在转换并存储为属性后，应使用 `XSendEvent` 向请求者发送选择通知。

```c
Status XSendEvent(display, w, propagate, event_mask, event_send);
```

`display` 指定到 X 服务器的连接。

`w` 指定发送到的窗口，或 `PointerWindow`、`InputFocus`。

`propagate` 指定一个 `Bool` 值。

`event_mask` 指定事件掩码。

`event_send` 指定要发送的事件。

`XSendEvent` 函数识别目标窗口，确定哪些客户端应该接收指定的事件，并忽略任何活动抢夺。此函数要求传递一个事件掩码。有关事件掩码名称的讨论，请参见第 10.3 节。此函数使用 `w` 参数识别目标窗口的方式：

- 如果 `w` 是 `PointerWindow`，目标窗口是包含指针的窗口。
- 如果 `w` 是 `InputFocus` 且焦点窗口包含指针；否则，目标窗口是焦点窗口。

为了确定哪些客户端应该接收指定的事件，`XSendEvent` 使用 `propagate` 参数如下：

- 如果 `event_mask` 是空集，事件将发送给创建目标窗口的客户端。如果该客户端不再存在，则不发送事件。
- 如果 `propagate` 为 `False`，事件将发送给在目标窗口上选择 `event_mask` 参数中任何事件类型的客户端。
- 如果 `propagate` 为 `True` 且客户端已在目的地选择了 `event_mask` 中的任何事件类型，则将目的地替换为该目的地的最近的祖先，且该祖先有某些客户端选择了 `event_mask` 中的某种类型，且不存在该窗口；或者如果窗口是焦点窗口的祖先且 `InputFocus` 原始被指定为目的地，则该事件不会发送给任何客户端。否则，事件将报告给 `event_mask` 中指定的任何类型的最终终点上的客户端。

X 结构中的事件可能是核心事件之一，或由扩展定义的事件之一（或 `BadValue` 错误），以便 X 服务器可以根据需要交换字节的内容。否则，事件的内容不会被 X 服务器更改或检查，除非转发事件中的 `send` 字段为 `True`，以及正确设置事件中的 `serial` 序列号；因此，这些字段和 `display` 字段会被 `XSendEvent` 忽略。

`XSendEvent` 在与线缆协议连接失败时返回零，并返回非零错误。

`XSendEvent` 可能会产生 `BadValue` 和 `BadWindow` 错误。

# 获取指针移动历史

某些服务器实现维护了比事件通知报告更完整的指针移动历史。每个指针硬件中断时的指针位置可能被存储在缓冲区中供以后检索。此缓冲区被称为移动历史缓冲区。例如，某些应用程序（如绘图程序）希望拥有指针移动轨迹。然而，对于大多数应用程序来说，这些历史信息是非常容易访问的。

要确定移动缓冲区元素的最大数量，使用 `XDisplayMotionBufferSize`。

```c
unsigned long(display);
```

`display` 指定与 X 服务器的连接。

服务器可能会保留指针移动的最近历史，且其粒度比 `MotionNotify` 报告的精细。该函数使这些历史可用。

要获取指定窗口和时间的移动历史，使用：

```c
XTimeCoord *XGetMotionEvents(display, w, start, stop, nevents_return);
```

`display` 指定与 X 服务器的连接。

`w` 指定窗口。

`start`、`stop` 指定从移动历史缓冲区返回事件的时间间隔。你可以传递时间戳或 `CurrentTime`。

`nevents_return` 返回来自移动历史区的事件数量。

该函数返回移动历史缓冲区中指定的 `start` 和 `stop` 时间之间（包含边界）的所有事件，并且其坐标位于其当前位置的指定窗口（包括其边界）。如果服务器不支持移动历史、如果 `start` 时间晚于 `stop` 时间，或者如果 `start` 时间在未来，则不返回任何事件；返回 `NULL`。如果 `stop` 时间在未来，则等同于指定 `CurrentTime`。该函数的返回类型定义如下：

```c
typedef struct {
  Time time;
  short x, y;
} XTimeCoord;
```

`time` 成员设置为毫秒级的时间。`x` 和 `y` 成员设置为指针坐标，并相对于指定窗口的原点报告。要释放从此调用返回的数据，请使用 `XFree`。

产生 `BadWindow` 错误。

# 处理协议错误

`Xlib` 提供了你可以用于启用或禁用同步以及使用默认错误处理程序的函数。

## 启用或禁用同步

在调试 X 应用程序时，通常要求 `Xlib` 以同步方式运行，这样错误在发生时就会报告。以下函数允许你禁用或启用同步行为。注意，当启用同步时，图形处理可能会慢 30 倍或更多。在符合 POSIX 标准的系统中，有一个全局变量 `_Xdebug`，如果在在调试器下启动程序之前将其设置为非零，将强制执行同步库行为。

在完成工作后，所有生成协议请求的 `Xlib` 函数都会调用一个被称为 `function` 的函数。该函数设置要调用的函数。

```c
int(display, (*procedure)());
```
