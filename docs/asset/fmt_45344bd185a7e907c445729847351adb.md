
# 500 Ubuntu 认证专家学习指南

### Freedom Toaster
`Freedom Toaster` 是一种自动贩机式的免费数字产品分发器，包括 Ubuntu Linux。它是 Ubuntu 技术基础设施的一部分。

### Fridge
Ubuntu Fridge 提供“新闻、基层营销、倡导、团队协作和出色的原创内容”。您可以通过 `http://fridge.ubuntu.com` 获取，它本质上是一个社区新闻网站，详细列出了发布公告、会议活动、热门新功能、项目报告等。

### fsck
`fsck` 命令检查 Linux 分区上的文件系统一致性。不应在已挂载的分区上运行该命令。

### FTP (文件传输协议)
FTP 协议是一种用于优化计算机之间文件传输的 TCP/IP 协议。

### gateway（网关）
网关是从一台计算机到另一个网络的路由。默认网关地址是连接局域网与其他网络（如互联网）的计算机或路由器的 IP 地址。

### GConf
GConf 守护进程管理与每个用户 GNOME 桌面环境相关的配置设置。该守护进程为 `gconf-2`。

### gcontool-2
`gcontool-2` 命令可以控制和配置 GConf 设置。

### gconf-editor
`gconf-editor` 命令打开配置编辑器 GUI 工具，我认为它功能上与微软注册表编辑器相似，但影响范围限于 GNOME 桌面环境。

### gdmsetup
`gdmsetup` 命令打开登录窗口偏好工具，用于配置 GNOME 显示器管理器登录界面。

### gNewSense
一种 Ubuntu Linux 衍生发行版，仅使用自由软件；获得自由软件基金会的认可。

# GNOME (GNU 网络对象模型环境)
GNOME 是 Ubuntu Linux 的默认 GUI 桌面。

`gnome-appearance-properties` 命令启动 GNOME 外观偏好窗口。

`gnome-control-center` 命令启动其他 GNOME 工具的前端。

`gnome-cups-printer` 命令在 GNOME 桌面环境中启动 GNOME 打印机配置工具。

`gnome-display-properties` 命令启动 GNOME 屏幕分辨率偏好窗口。

`gnome-font-properties` 命令已过时；其功能现已成为 `gnome-appearance-properties` 工具的一部分。

`gnome-keyboard-properties` 命令启动 GNOME 键盘偏好窗口。

`gnome-keybinding-properties` 命令启动 GNOME 键盘快捷键窗口。

`gnome-language-selector` 命令启动 GNOME 语言支持工具，可以在其中安装和配置额外的语言。

`gnome-mouse-properties` 命令启动 GNOME 管理窗口。

`gnome-sound-properties` 命令启动 GNOME 音偏好窗口。

`gnome-volume-properties` 命令启动 GNOME 移动驱动器和媒体偏好窗口。

`gnome-window-properties` 命令启动 GNOME 窗口偏好窗口。

### Gnoppix
基于 Debian Linux 的 Live CD 发行版；与 Knoppix ，但使用的是 GNOME 桌面。

### Guadalinex
一个基于 Ubuntu Linux 的发行版，由西班牙自治的安达卢西亚社区推广。

### Gobuntu
仅限于开源软件的 Ubuntu Linux 版本。

### GPG (GNU 卫士)
GPG 是 OpenPGP 标准的实现，包含在 Ubuntu Linux 中。

### group ID（组 ID）
每个 Linux 组都有一个组 ID，定义在 `/etc/group` 中。

### groupadd
`groupadd` 命令添加本地组。

### groupdel
`groupdel` 命令删除本地组。

### GRUB (大统一引导加载程序)
Ubuntu Linux 的默认引导加载程序。

### Gutsy Gibbon
Ubuntu Linux 2007 年第二次发布版本 7.10 的代号，于 2007 年 10 月发布。

### Hardware Abstraction Layer (HAL)
概念上与微软的版本不同，Linux 硬件抽象层 (HAL) 提供了一份不断更新的检测组件列表。

### Hardy Heron
Ubuntu Linux 第二个 LTS（长期支持）版本的代号，版本 8.04，于 2008 年 4 月发布。

### hdparm
`hdparm` 命令可以帮助控制 CD/DVD 和硬盘上的许多设置，包括功耗。

### Hoary Hedgehog
Ubuntu Linux 第二次发布版本 5.04 的代号，于 2005 年 4 月发布。

### home directory（家目录）
家目录是 Linux 用户的登录目录。通常，这是 `/home/user`，其中 `user` 是用户的登录名。在任何 Linux 命令中，它也用波浪号 (`~`) 表示。

### htpasswd
`htpasswd` 命令帮助为访问您的本地站点创建密码。

### ICMP (互联网控制消息协议)
一种发送错误消息的协议。与 `ping` 命令相关。

### i386
Ubuntu Linux 中的 i386 架构主要指可以安装在 Intel 32 位 CPU 系统及其仿品机上的包。

### ifconfig
`ifconfig` 命令用于配置和显示网络设备。

### ifdown
`ifdown` 命令用于激活网络设备。

### ifup
`ifup` 命令用于禁用网络设备。

### IMAP (互联网消息访问协议)
IMAP 是一种电子邮件协议。它工作在端口 143 上；可以通过 Evolution-mail 客户端配置到 IMAP 服务器的连接。IMAP 是 IMAP 服务器当前的标准。IMAP 连接可以加密（如果服务器支持）。

### ImpliLinux
一个基于 Ubuntu Linux 的发行版，由 Canonical 的所有者发布。

### init
`init` 进程是内核调用的第一个 Linux 进程。它启动组成工作系统的其他进程。

### Initial RAM Disk（初始内存磁盘）
许多发行版在启动过程中使用初始内存磁盘；它存储在 `initrd.img-uname -r-generic` 中，其中 `uname -r` 是内核版本，`-generic` 或 `-server` 指定内核的用途。

# 术语表 501

### Internet Print Protocol (互联网打印协议)
互联网打印协议 (IPP) 是网络共享打印机的演进标准。所有主流操作系统都在适配它；Linux 的实现是 CUPS。

### IP forwarding（IP 转发）
当数据通过您的计算机在计算机或网络之间转发时发生。

### IPv4 (互联网协议版本4), IPv6 (互联网协议版本6)
IPv4 和 IPv6 是不同的 IP 地址系统。版本 4 是我们现在使用的，基于 32 位地址；版本 6 正在上线，基于 128 位地址。

### IrDA 红外数据协会
IrDA 指的是红外数据协会的基本标准。它是一种基于红外光传输的数据交换协议。

### ISO
ISO 在 Ubuntu Linux 中至少有两个含义。ISO 文件与 ISO 镜像相关，并基于国际标准组织发布的磁盘镜像标准，可以刻录到 CD 或 DVD 上。ISO 编码也与语言选项相关。

### iwconfig
`iwconfig` 命令可以显示当前的无线设置，并配置特定的网卡的网络特性，如 ID、通道、加密、传输功率等。

### iwevent
`ievent` 命令监控系统的其他无线事件。

### iwgetid
`iwgetid` 命令识别无线网络 ID，也称为扩展服务集标识 (ESSID)。

### iwlist
`iwlist` 命令列出无线接口数据，如通道、传输功率和授权密钥。

### iwpriv
`iwpriv` 命令配置与无线网相关的详细参数。

### iwspy
`iwspy` 命令测量无线链路信息的质量。

### KDE

### Kerberos 5
Kerberos 5 是一种计算机网络认证协议，提供客户端和服务器之间的相互认证。它由马萨诸理工学院开发。
