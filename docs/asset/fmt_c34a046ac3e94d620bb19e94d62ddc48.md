
一个 `Port` 基本上是一个用于构建相关程序的配方。浏览各个子文件夹，你会开始看到一些老朋友，例如 `X11-wm` 文件夹中的桌面，`/www` 中的 `Firefox` 浏览器，以及（万岁！）`/editors` 中的 `Emacs`。为了搜索应用程序，我们需要首先对系统中所有的端口进行索引：

```
cd /usr/ports
make index
```

使用以下命令搜索某物：

```
make quicksearch name=[name_of_your_search_target]
```

这将显示结果名称、位置和简短描述。如果你找到了你想要的并希望安装它，可以使用下面的命令。只需记住你将在编译，而不仅仅是安装应用程序及其所有依赖项：

要构建和安装程序，导航到其 `Port` 目录并发出以下命令。请注意 `clean` 参数将确保任何临时构建文件在完成后被删除。

```
make install clean
```

坐下来看着信息滚动，几分钟后/几小时后/几天后（取决于应用程序的大小），你刚出炉的程序将准备就绪。卸载也同样简单（再次，从 `Port` 目录）：

```
make deinstall
```

有时安装二进制软件包是获取你想要软件的最快和最简单方式。并且像 Linux 软件包管理器一样，它是依赖项感知的。

## 我们的测试方法……

本*综述*中的许多操作系统都建议用户首先在一个安全的虚拟机环境中进行实验。我们听从了它们的建议，先将所有操作系统运行在按照各自网站规格说明配置的虚拟机中，然后再将其应用于物理硬件。

我们的目的是寻找一个替代操作系统，使我们能够高效地使用计算机。当然，我们并不指望能通过这些系统通过 `Steam` 玩云游戏或 `Netflix` 看电影，但如果它们能播放多媒体、浏览网页、进行文字处理等，且不会抛出意外错误，那么它们就会给我们留下好印象。我们将测试安装和应用支持等各种参数，唯一目的是帮助我们锁定一个让我们走出熟悉舒适区、同时又在舒适度上妥协最少的替代操作系统。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_27_0.png)

作为一位老读者，你肯定很清楚，`Linux` 并不是你唯一能从互联网免费获取的开源操作系统。

尽管我们热爱 `Linux`，但我们确实也会定期评测其他开源操作系统，特别是 `BSD` 家族。许多非 `Linux` 的开源操作系统专为特定领域设计，在专业环境之外可能用处不大。虽然它们可能不具备 `Linux` 那样从上网本到服务器集群皆可伸缩的灵活性，但其中一些在包括桌面在内的多种环境中表现相当出色。本*综述*将向你介绍一些适合日常桌面任务的最佳选择。

尽管这些替代操作系统已经开发超过二十年，但其中许多实际上仍处于开发的早期阶段！这主要是因为它们无法像大多数 `Linux` 发行版那样获得开源生态系统的同等关注。本*综述*中的许多操作系统核心开发者数量非常有限（专门用户群体更是极小），而且它们没有跨国/盈利企业的背书来加速开发——但它们仍在持续增长。

## 安装

将操作系统固定在机器上需要做什么？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_28_0.png)

综述中的几乎所有操作系统都配备了图形化安装程序。但不幸的是，这并不意味着你下载操作系统后就能立即将其暴露在生产机器的物理磁盘上。你应该意识到，并非所有系统的测试程度都与 `Linux` 安装程序相同——正如我们提到的，首先通过虚拟机进行测试始终是个好主意。

唯一的例外是 `OpenIndiana`。`Linux` 用户不会在导航其安装程序时遇到任何困难，该安装程序非常精致且流畅，类似于典型的 `Linux` 安装程序。你可以使用安装程序内置的分区工具为操作系统划分空间，或者使用在 `Live` 环境中可用的熟悉工具 `Gparted`。还有 `ReactOS`，它是综述中唯一提供专用可安装版本的操作系统。还有一个 `Live ISO` 镜像，旨在帮助你在硬件上测试操作系统。一旦你确信一切正常，就可以使用仅安装版本将 `ReactOS` 固定到计算机上。该操作系统的安装程序让人回想起旧版 `Windows` 安装程序，使用起来并不特别困难。与许多 `Linux` 发行版一样，`ReactOS` 在首次启动时运行配置工具，帮助你创建用户并选择桌面主题。

`Haiku` 和 `Visoprys` 都有简单直观的安装程序。你只需将 `Haiku` 指向一个 `BeFS` 文件系统分区，它就会相当快地复制文件并安装引导加载程序。安装程序现在可以从 `GPT` 分区启动，且 64 位镜像附带 `EFI` 引导加载程序，以便 `Haiku` 可以在 `EFI` 计算机上启动。

`Haiku` 等许多操作系统包含分区工具，帮助你为操作系统创建专用分区。

`Visoprys` 的安装程序也包含分区工具，帮助你为操作系统创建一个切片。你被强制以管理员用户使用系统，但安装程序允许你为其设置密码。如果你在新建的虚拟磁盘上安装 `Visoprys`，请务必选择将基本 `MBR` 写入磁盘的选项，以便进入安装过程。

那个让你摆脱安装循环的操作系统是 `KolibriOS`，它没有明确的安装过程。你只需通过修改 `/etc/grub.d/` 下的 `40_custom` 文件中的条目，将 `GRUB` 指向 `kolibri.img` 文件即可大功告成。

## 默认应用

开箱即用吗？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_28_1.png)

正如它所模拟的操作系统一样，`ReactOS` 包含一些应用。除了包括 `Paint`、记事本和 `WordPad` 在内的许多实用程序外，该操作系统还包含三款大家喜欢的 `Windows` 纸牌游戏。

`Visoprys` 好不了多少，自带极简化的应用套件，因为该操作系统的目标是为计算机科学学生和像我们这样的替代操作系统爱好者创建一个功能完整的操作系统。除了磁盘管理器和安装程序外，还有一个基本的文本编辑器、图像编辑器、虚拟键盘应用、几款游戏和一些管理实用程序。相比之下，`KolibriOS` 自带数十款应用。有音频播放器、视频播放器、`VNC` 查看器、文本编辑器、一个简单的网页浏览器等。该操作系统还有许多开发工具，特别是用于 `FASM` 汇编的，以及多个游戏机模拟器。`Haiku` 也包含大量巧妙但必备的应用，典型用户可能需要它们在桌面上。有电子邮件客户端、网页浏览器、媒体播放器、图像查看器和文本编辑器，以及活动监视器、十六进制编辑器、磁盘分区工具、简单的 `Web` 服务器等管理工具。`OpenIndiana` 附带了非常熟悉的 `MATE` 桌面，大部分应用也来自 `MATE` 的稳定版。除此之外，还有一些主流生产力应用，如 `Firefox`、`Thunderbird` 和 `Pidgin`。开箱即用的 `OpenIndiana` 安装功能有限，你需要使用其包管理系统来丰富它。

对于复古游戏爱好者来说，`KolibriOS` 绝对是一座宝库。

## 易用性和性能

需要花费多少精力才能习惯它们？

本综述包含的操作系统之所以被称为“替代”是有原因的。它们与日常桌面发行版不同，事实上，期望它们看起来、感觉上和行为上与其他主流操作系统一样是不合理的。尽管开发者已经在其中一些系统上工作了十多年，但其中许多仍处于开发的萌芽阶段。早期的开发阶段反映了操作系统基础的不稳定性，这将直接影响其易用性和性能。即使是对于主流发行版，易用性也是重要的考量因素。如果一个发行版不可用，拥有一长串功能也毫无用处。对于替代操作系统也是如此。这就是为什么除了比较影响其易用性的各个具体方面外，我们还将评估其整体用户体验，帮助你找到那个在桌面上最能物有所值的选择。
