也许一个非常有用的示例是交换键盘上的 Caps Lock 和 Ctrl 键。某些用户可能会发现如果交换位置，打字会话会舒服一点。交换它们有很多方法。对于你基于控制台的 Red Hat 会话，使用 `loadkeys` 命令读取包含按键反转值的文件：

你随后可以使用 `loadkeys` 读取文件来立即交换按键，如下：

remove Lock = Caps_Lock

## 在 Red Hat Linux 中配置指针设备

本节介绍了 Red Hat 的指针设备配置。你将看到如何使用 `mouseconfig` 命令从文本控制台配置鼠标，或用于桌面的图形化 `redhat-config-mouse` 客户端。

## 注意

许多指针设备在 Red Hat Linux 上运行良好。然而，如果你使用 joystick 或 Synaptics TouchPad、Cirque GlidePoint 以及无线或红外 IrDA 指针，你可能需要尝试不同的配置设置或使用制造商提供的驱动程序。

Red Hat 还通过 `jsdev`、`joystick` 和 `jtest` 命令包含了 joystick 支持。你可以使用这些命令支持、校准和测试某些。

Red Hat 安装程序通常会识别并正确配置计算机的指针设备，如果你安装了新的指针设备，你需要重新配置系统。

使用 PS/2 指针设备时，名为 `/dev/mouse` 的文件指向 `/dev/psaux`；使用 USB 指针设备时，`/dev/mouse` 指向 `/dev/input/mice`。串口鼠标将使 `/dev/mouse` 指向特定的串口，可能是 `/dev/tty0`。`/dev/mouse` 文件是一个符号链接，方便许多 Linux 应用程序使用。

USB 服务通过系统模块配置文件 `/etc/modules.conf` 中的条目在引导过程中启动：

```
alias usb-controller usb-hci
```

### Red Linux 与 KVM

鼠标 KVM 提供了通过单个显示器、键盘和指针在计算机组之间快速切换显示和控制的能力。

使用 KVM 可以节省成本。消除对某些显示器的需求减少了系统的存储需求以及运行和冷却所需的能量。

Red Linux 管理员在实施 KVM 之前应仔细研究任何兼容性问题。无论使用何种操作系统和应用程序，都需要相应的键盘和指针设备。某些 KVM 开关带有某种形式的嵌入操作系统；这些开关会有电源需求。

其他需要考虑的问题包括电缆结构、兼容性和距离限制、硬件或软件开关配置、安全性以及可扩展性。

如果你使用 X 并控制网络远程主机的图形桌面，可以使用 `x2x` 和 `x2nc` 客户端。虽然它们未包含在 Red Hat 中，但你可以在此处找到这些客户端：
