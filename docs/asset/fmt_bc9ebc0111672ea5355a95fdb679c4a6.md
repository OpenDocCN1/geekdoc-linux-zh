
# 触发电路

一种电子电路，用于生成或修改现有波形，以产生具有快速上升前沿的短脉冲。该波形或触发信号通常用于引发某种弛豫器件（如多谐振荡器）的状态变化。触发电路生成的波形最重要的特征通常是快速前沿。波形的下降部分的确切形状往往次要，但重要的是总弛豫时间不宜过大。诸如阻塞振荡器之类的脉冲发生器，如果生成足够短的脉冲，也可被使用并识别为触发电路。参见阻塞振荡器；脉冲发生器。

峰值电路接收脉冲波形的高频分量，导致尖锐的上升和下降沿，因此用作触发电路。最简单的峰值电路形式是图中所示的简单 `RC` 和 `RL` 网络。如果对这两个电路中的任意一个施加幅度为 `Vs` 的陡峭波形前沿，输出将是突然上升后跟随指数衰减。这些电路通常称为微分电路，因为如果 `RC` 或 `R/L` 时间常数足够小，输出是输入波形导数的粗略近似。

高度欠阻尼或振荡的电路，当提供阶梯或脉冲输入时，常被称为振铃电路。当用于场效应管或双极型晶体管的输出时，该电路可作为触发电路使用。参见波形整形电路。

## 甘油三酯

一种简单脂质。甘油三酯是脂肪酸的三酯，由三羟醇甘油酯化而成，存在于植物和动物组织中，特别是在食物储存库中，既可以是所有脂肪酸都相同的简单酯，也可以是脂肪酸不同的混合酯。甘油三酯构成天然脂肪和油的主要成分。

甘油三酯的通用公式如下所示，其中 `RCO₂H`, `R'CO₂H` 和 `R''CO₂H` 代表相同或不同脂肪酸的分子，如丁酸或己酸（短链），棕榈酸或硬脂酸（长链），或油酸、亚油酸或亚麻酸（不饱和）。用碱皂化可释放甘油和脂肪酸的碱金属盐（肥皂）。食物储存库中的甘油三酯代表一种集中的能量来源，

```
CH₂—OOC—R'  
CH—OOC—R  
CH₂—OOC—R''
```

### 三角函数的性质

基于公式 `(2)` 以及上述关于 `sin θ` 和 `cos θ` 的几何构造（图 1），`θ` 可以是任意角，因此正弦和余弦函数的定义域是所有实数。在公式 `(3)` 中，若 `a = 0`，则正切和正割函数未定义，因此这些函数的定义域是所有实数，除了 `π/2` (90°) 的奇数倍。在公式 `(4)` 中，若 `b = 0`，则余切和余割函数未定义，因此这些函数的定义域是所有实数，除了 `π` (180°) 的整数倍。此外，由于 `|a| ≤ 1` 且 `|b| ≤ 1`，正弦和余弦函数的值域是 −1 到 1（包含端点）。由于 `|b| = |sin θ| ≤ 1` 且 `|a| = |cos θ| ≤ 1`，可得 `|csc θ| = 1/|b| ≥ 1` 且 `|sec θ| = 1/|a| ≥ 1`。因此，正割和余割函数的值域由所有小于或等于 −1 或大于或等于 1 的实数组成。正切和余切函数的值域均为所有实数。公式 `(2)`、` (3)` 和 `(4)` 还揭示了倒数恒等式，即公式 `(6)`。另外两个有用的恒等式，即公式 `(7)`，也随之成立。

```
csc θ = 1/sin θ  sec θ = 1/cos θ  cot θ = 1/tan θ  (6)

tan θ = sin θ/cos θ  cot θ = cos θ/sin θ  (7)
```

由于 `(a,b)` 位于单位圆上，故 `a² + b² = 1`，因此 `(sin θ)² + (cos θ)² = 1`。这被称为毕达哥拉斯恒等式，写作公式 `(8)`。

```
sin² θ + cos² θ = 1  (8)
```

### 和差公式

余弦函数的和差公式给出在公式 `(9)` 和 `(10)`，正弦函数的和差公式给出在公式 `(11)` 和 `(12)`。

```
cos (α + β) = cos α cos β − sin α sin β  (9)

cos (α − β) = cos α cos β + sin α sin β  (10)

sin (α + β) = sin α cos β + cos α sin β  (11)

sin (α − β) = sin α cos β − cos α sin β  (12)
```

### 反三角函数

在方程 `x = sin y` 中，若限制 `y` 使得 `−π/2 ≤ y ≤ π/2`，则方程关于 `y` 的解是唯一的，记为 `y = sin⁻¹x`（读作“y 是 x 的反正弦”）。有时 `y = sin⁻¹x` 写作 `y = Arcsin x`。因此，`y = sin⁻¹x` 是一个定义域为 `−1 ≤ x ≤ 1`，值域为 `−π/2 ≤ y ≤ π/2` 的函数。例如，`sin⁻¹(1/2) = π/6`，`sin⁻¹(-1) = -π/2`。

同样，在方程 `x = cos y` 中，若限制 `y` 使得 `0 ≤ y < π`，则方程关于 `y` 的解是唯一的，记为 `y = cos⁻¹x`（读作“y 是 x 的反余弦”）。因此，`y = cos⁻¹x` 是一个定义域为 `−1 ≤ x ≤ 1`，值域为 `0 ≤ y < π` 的函数。最后，在方程 `x = tan y` 中，若限制 `y` 使得 `−π/2 < y < π/2`，则方程关于 `y` 的解是唯一的，记为 `y = tan⁻¹x`（读作“y 是 x 的反正切”）。因此，`y = tan⁻¹x` 是一个定义域为 `−∞ < x < ∞`，值域为 `−π/2 < y < π/2` 的函数。

### 直角三角形的解法

三角函数可以表示为直角三角形边长的比值。确实，根据公式 `(6)`、` (7)` 和 `(8)`，可得 `sin β = b/c`，`cos β = a/c`，`tan β = b/a` 等，其中 `a` 和 `b` 是直角相邻的边（直角边），`c` 是斜边，`α` 和 `β` 分别是对应于边 `a` 和 `b` 的角（图 2）。如果已知直角三角形的一个角和一条边，或者两条边，则可求出剩余的角和边。
