
# 安装与配置

```bash
[root@server/root]# mount /mnt/cdrom
```

[root@server/root]# - -

## 1. 解压配置文件

1. 切换目录。
2. 输入命令。

```bash
[root@server]# cd /etc
```

```bash
[root@server /etc]# tar xzvf /mnt/cdrom/dekiru/conf/namedb.tar.gz
```

`namedb.conf`

`namedb/localhost`

`namedb/localhost.rev`

`namedb/named.conf`

`namedb/named.root`

[root@server /etc]# -

文件已解锁。

## 2. 打开配置文件

切换目录。

```bash
[root@server /etc]# cd namedb
```

```bash
[root@server namedb]# vi named.conf
```

输入命令。

## 3. 编辑配置文件

输入你注册的域名名。

```conf
// secondary

zone "dekiru.gr.jp" {

  type slave;

  file "dekiru.gr.jp.rev";

  masters {

    210.248.12.98;

  };

}
```

输入域名名。

```conf
zone "96.12.248.210.in-addr.arpa" {

  type slave;

  file "dekiru.gr.jp.rev";

  masters {

    210.248.12.98;

  };

}
```

输入主 DNS 服务器的 IP 地址。

输入倒序排列数字的网络地址。

输入域名名后附加“rev”的名称。

输入主 DNS 服务器的 IP 地址。

保存修改后的文件并退出。

## 4. 重新加载 BIND

你已完成重新配置。
重新加载 BIND。

输入命令。

```bash
[root@server namedb]# ndc reload
```

[root@server namedb]# -
