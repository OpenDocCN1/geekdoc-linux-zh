# 用于净化的膜分离

膜分离通过利用两相之间的差异作为跨膜驱动力（例如浓度差或压力差），导致一种或或组进料组分发生选择性传输。

膜分离基于待分离物和驱动力：(1) **过滤**，液体和低分子溶质穿过多孔膜，而较大的颗粒被保留。(2) **透析**，低分子溶质和离子穿过胶体颗粒，而分子量大于 1000 的溶质被保留。(3) **渗透、反渗透和电渗**基于化学势。其驱动力是压力差。

(4) **渗透**，由于电压差，颗粒向所有方向穿过膜；以及 (5) **纳滤**，液体和悬浮颗粒被保留，且膜是液态。对于气体和液体，反蒸是分离的一种特殊情况，其中进料处于液态，通常在亚膜条件下驱动，处于气态。

由于化学反应和分离类型的不同，可以获得高选择性和渗透率。参见：透析（DIALYSIS）；电膜与电渗析（ELECTROMEMBRANES AND ELECTROFILYSIS）；渗透（OSMOSIS）；传输（TRANSPORT）。

# 记忆

通过经验获取和存储信息的能力。记忆是人类思维各个层面的复杂过程，包括感知、学习和解决问题。参见：感知（PERCEPTION）；心理学（PSYCHOLOGY）。

## 阶段

记忆获取的过程分为三个阶段：短期记忆、中期记忆和长期记忆。短期记忆是指在感知到某物后短时间内满足的记忆。

短期记忆涉及当前短期可用的所有信息。它与中枢神经系统中感觉感受体水平以下的神经元有关，并与感觉记忆中可以表示的注意力量有关。

尽管感觉记忆的功能尚不完全清楚，但其最重要的目的之一是为人们提供额外的时间，以确定什么应该转移到记忆系统的下一个阶段，即短期记忆。

从感觉记忆或长期记忆中获得的信息在短期记忆中进行处理，以便人们实现目标。在某些情况下，短期记忆涉及对信息的临时维护，例如记住一个电话号码直到足够拨号。在其他时候，短期记忆涉及信息的阐述以产生想法。

例如，当有时按顺序呈现 27 个符号时，记忆必须产生一个有用的功能。一种有效的方法是将信息组织成类别。例如，一次性将字母 SKCAUCDEHIT 分组。然而，如果它们在短期记忆中被重新排列，那么在回想它们时，这可以减少到一个块（chunk）。

短期记忆每次仅限于七秒钟。然而，每个块中包含的信息量仅受短期记忆中可以保留的信息量的限制，或者取决于人们需要开发策略将信息编码成块。在许多研究中，当信息具有意义时，从短期记忆到长期记忆的转换（此处原文为 transfer，通常意为转移/转化）要大得多。

通常情况下，从长期记忆的回忆涉及记忆被归档时的规律。许多检索长期记忆的技巧涉及将其与记忆线索相关联。

少量信息可以触发与指示标签相关的长期记忆。

有些人发现利用联想来回想与彼此距离很的联想相关的记忆。存在相关的记忆可以触发其他记忆。

通常，人们在回想它们时会发现它们与其他记忆相关。定位一个长期记忆是记住它被存储时的般情况。因此，促进检索的技术……
