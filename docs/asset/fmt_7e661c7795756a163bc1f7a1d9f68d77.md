
# 血型与血液学基础

## 抗体与凝血

大多数血型不在血清或血浆中产生抗体，除非宿主直接暴露于外源红细胞。最常见的刺激是输血。凝固过程取决于凝血因子的功能，特别是经典的白血病和圣诞节病，这些是标记性细胞的疾病。各种缺乏症与出血倾向有关，但有一个不可逾越的例外。

凝血因子缺乏会导致输输富含特定物质的血液或血浆。见“人类”。

## 血小板与血清

血小板不是真正的细胞，而是从骨髓细胞——巨核板细胞中脱落的血液碎片。

血小板的浓度取决于血小板的寿命以及凝固持续的时间（即到第二个血块出现为止的时间）。

血清是凝固的结果，是在移除细胞成分后留下的。血清是在血液出血并移除血块后形成的。血清和血浆的区别在于其纤维蛋白和其他蛋白的含量，这些蛋白在血浆中大量存在。

血浆的主要成分是蛋白质和水。蛋白质浓度约为 7 g/l。

许多许多物质以微量存在。通过各种方法可以证明，血清是多种成分的混合物。目前仅已鉴定并表征了 60 种蛋白成分。

白蛋白占总蛋白的一半以上，分子量为 69,000。在高浓度下，白蛋白贡献了血浆渗透压的 75-90%。

免疫球蛋白是 γ 球蛋白组分，构成了循环循环的抗体，也被称为体液抗体。

它们在防御某些感染病体以及其他外物物质方面具有重要意义。

除了蛋白质外，许多其他类化合物在血液中循环。其中大部分是水。

肝素是一种多糖磺酸化合物，特别存在于细胞中。它在正常血液中不存在。

## 白细胞分类

单核细胞比中性粒细胞大，具有染色质细胞核。颗粒比细胞大。白细胞可能表现为一个或多个簇。颗粒中等细细，可被碱性染料染色，且是水溶性。

血小板在凝固过程中起形成作用，通过在受损血管部位聚集形成血栓。血小板是血块中的细胞碎片或细胞部分，释放血清。

循环在血液中的白细胞数量未知。当它们离开血液进入结缔组织时，它们会转化为组织免疫细胞。许多细胞是噬细胞，会吞噬碎片和细菌。

淋巴细胞是小小的梭形或圆形体，长度约 3 微米，在循环血液中数量较多。它们有一个圆形中心核（染色质），嵌入在高度透明的膜中。

颗粒性细胞有多种类型：中性粒细胞、嗜酸性粒细胞和碱性粒细胞。它们的结构在不同物种之间不同，在人类中也是如此。中性粒细胞占白细胞的 60-70%，许多具有高度多变的细胞核，由染色质细丝连接的三到五个叶片组成。

## 蓝离聚星 307

一种在电气开关设备中产生磁场的灭弧器（Blowout call），其目的是延长和扩展开关设备的触点以中断电流。产生的磁场使 A 型血型转化为预先形成的碳水化合物链 H。该基因编码一种 α-半乳糖基转移酶，它能连接 α-半乳糖并赋予抗原 B 型血型特性。在这两种情况下，H 均保持不变。O 基因没有可检测到的 H 抗原，保持不变，且仅在红细胞上表达。这些差异解释了四种常见表型的遗传：A、B、AB 和 O 血型是最常见的，AB 最少。A 和 B 基因是共显遗传的；只要存在其中一种，就可以检测到抗原。如果无法检测到抗原，则 O 基因为缺失产物。
