## GUID (全局唯一标识符)

Microsoft Windows 概念，GUID 是一个大的唯一数字。每个 Windows 计算机都有自己的 GUID 来标识它。同样，每当用户创建一个帐户时，都会为该用户分配一个 GUID。关键点：微软在 1999 年因在注册过程中自动发送 GUID 而引起了麻烦。关键点：GUID 有时被放置 Microsoft 文档（Word, Excel）的隐藏字段中，允许识别原始作者。这被用于追踪“Melissa”病毒的作者。关键点：GUID 是由机器上的其他“唯一”值生成的，例如以太网适配器的 MAC 地址。它保证是绝对唯一的，但世界上任何 GUID 相同的概率微乎其微。来自 Hacking-Lexicon `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
