## DirectoryIndex

用作预写 HTML 目录

索引的文件或文件名称。多个条目用空格隔开。

`DirectoryIndex index.htm index.cgi`

## AccessFileName

在每个目录中查找用于访问控制信息的文件名。

`AccessFileName .htaccess`

以下行防止 `.htaccess` 文件被 Web 客户端查看。由于 `.htaccess` 文件通常包含授权信息，出于安全考虑，禁止访问。如果你让 Web 访问者看到 `.htaccess` 文件的内容，请注释这些行。如果你更改了上面的 `AccessFileName` 指令，请务必在此处进行相应的更改。

```
<Files .htaccess>
```

## CacheNegotiatedDocs

默认情况下，Apache 会对每个根据内容协商的文档发送 Pragma 'no-cache'。这要求代理服务器不要缓存该文档。取消以下行注释将禁用此行为，允许代理缓存文档。

`# CacheNegotiatedDocs`

## UseCanonicalName

`1.3` 版本新增功能。当开启此设置时，无论 Apache 需要构建自引用 URL，即指向响应来源服务器的 URL，它都将使用 `ServerName` 和端口来形成“规范”名称。当此设置关闭时，Apache 将尽可能使用客户端提供的主机:端口。这也会影响 CGI 脚本中的 `SERVER_NAME` 和 `SERVER_PORT`。

`UseCanonicalName On`

## TypesConfig

描述 `mime.types` 文件位置。

`TypesConfig conf/mime.types`

## DefaultType

是服务器无法确定类型时使用的默认 MIME 类型。如果你的内容主要是 HTML，你可能想使用 `"text/html"`。如果你的内容是二进制的，你可以使用 `"application/octet-stream"` 代替。

`DefaultType text/html`

## ServerSignature

可选将包含服务器版本和虚拟主机名称添加到服务器生成的页面，错误文档、FTP 目录列表、`mod_status` 和 `mod_info` 输出等，但不包括 CGI 生成文档。设置为 `"Email"` 还会包含指向 `ServerAdmin` 的 mailto 链接。设置为：`On | Off | Email`

`ServerSignature On`

## Aliases

根据需要添加任意别名，无限制。格式为 `Alias`

注意，如果包含末尾的 `/` 则服务器将要求在 URL 中存在它。因此在此示例中没有映射 `"icons"`，只有 `"icons/"`。

`Alias /icons/ "/etc/httpd/icons/"`

```
<Directory "/etc/httpd/icons">
Options Indexes MultiViews
AllowOverride None
Order allow,deny
Allow from all
</Directory>
```

## ScriptAlias

这控制哪些目录包含服务器脚本。`ScriptAliases` 基本上与 `Aliases` 相同，只是真实目录中的文档被视为程序，并在请求时由服务器运行，而不是作为文档发送给客户端。

`client`。关于末尾 `"/"` 的相同规则适用于 `ScriptAlias` 指令以及 `Alias`。

`ScriptAlias /cgi-bin/ "/home/httpd/cgi-bin/"`

如果你配置了对应的 CGI 目录，应将 `"/home/httpd/cgi-bin"` 修改为实际存在的该目录路径。

## Redirect

允许你告知客户端曾经存在于服务器命名空间中但现在已不存在的文档。这允许你告诉去哪里寻找重定向后的文档。格式：`Redirect old-URI new-URL`

## IndexOptions

控制服务器生成的目录列表显示的直接指令。

`FancyIndexing` 决定了你是想使用高级目录索引还是标准索引。

`IndexOptions FancyIndexing`

## AddIcon

指令告诉服务器为不同的文件或文件名扩展名显示哪个图标。这些图标仅在 `FancyIndexed` 目录中显示。

```
AddIconByEncoding (CMP, /icons/compressed.gif) x-compress x-gzip
AddByByType (TXT, /icons/text.gif) text/*
AddByByType (IMG, /icons/image2.gif) image/*
AddByByType (SND, /icons/sound2.gif) audio/*
AddByByType (VID, /icons/movie.gif) video/*
AddIcon /icons/binary.gif .bin .exe
AddIcon /icons/binhex.gif .hqx
AddIcon /icons/tar.gif .tar
AddIcon /icons/world.2.gif .wrl .wrl.gz .vrm .vrm .iv
```

## DefaultIcon

是对于没有显式设置图标的文件显示的图标。

`DefaultIcon /icons/unknown.gif`

## AddDescription

允许你在服务器生成的索引中文件之后放置一个简短描述。这些描述仅在 `FancyIndexed` 目录中显示。

格式：`AddDescription "description" filename`

`#AddDescription "GZIP compressed document" .gz`

`#AddDescription "tar archive" .tar`

`#AddDescription "GZIP compressed tar archive" .tgz`
