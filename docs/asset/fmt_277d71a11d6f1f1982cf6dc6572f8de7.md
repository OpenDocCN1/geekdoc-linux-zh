
```bash
        if [ $($INT % 2)) -eq 0 ]; then

            echo "INT is even."

        else

            echo "INT is odd."

        fi

    fi
```

该脚本有趣的部分是它是如何判断一个整数是偶数还是奇数的。通过对数字进行模 2 运算并返回余数，它可以告诉我们数字是奇是偶。

## 更现代的 `test` 版本

现代版本的 bash 包含一个作为 `test` 增强替代品的复合命令 `[[`。它使用以下语法：

```
[[ expression ]]
```

其中，与 `test` 类似，`expression` 是一个返回真或假的表达式。`[[ ]]` 命令与 `test` 类似（它支持所有的表达式），但增加了字符串表达式。

```
string1 =~ regex
```

如果 `string1` 被正则表达式匹配，则返回真。这为执行数据验证等任务开启了许多可能性。在我们之前的表达式示例中，如果常量 `INT` 包含了整数以外的内容，脚本将会失败。脚本需要一种方法验证常量包含整数。使用 `[[ ]]` 配合 `=~` 运算符，可以通过这种方式改进脚本：

```bash
#!/bin/bash

# test-integer2: 评估整数的值。

INT=5

if [[ "$INT" =~ ^[0-9]+$ ]]; then

  if [ "$INT" -eq 0 ]; then

    echo "INT is zero."

  else

    if [ "$INT" -lt 0 ]; then

      echo "INT is negative."

    else

      echo "INT is positive."

    fi

    if [ $((INT % 2)) -eq 0 ]; then

      echo "INT is even."

    else

      echo "INT is odd."

    fi

else

  echo "INT is not an integer." >&2

  exit 1

fi
```

通过正则表达式，我们将 `INT` 的值限制为以可选负号开头、后跟一个或多个数字的字符串。这种表达式消除了空值的可能性。

`[[ ]]` 的另一个新增功能是 `==` 运算符支持模式匹配，与路径扩展也是如此。这里有一个例子：

```
FILE=foo.bar

if [[ $FILE == foo.* ]]; then

 echo "FILE matches pattern 'foo.*'"

fi

foo.bar
```

这使得 `[[ ]]` 对于评估文件名非常有用。

## `(( ))` 设计整数

除了 `[[ ]]` 命令外，bash 还提供了 `(( ))` 命令，它适用于整数操作。它支持全套算术评估，我们将在第 34 章详细介绍。`(( ))` 用于执行算术测试。如果算术评估的结果非零，则算术测试为真。

```
if ((1)); then echo "It is true."; fi
```

使用 `(( ))`，我们可以像这样稍微简化 `test-integer2` 脚本：

```bash
#!/bin/bash

# test-integer2a: 评估整数的值。

INT=-5

if [[ "$INT" =~ ^?[0-9]+$ ]]; then

  if ((INT == 0)); then

    echo "INT is zero."

  else

    if ((INT < 0)); then

      echo "INT is negative."

    else

      if (((INT % 2)) == 0)); then

        echo "INT is even."

      else

        echo "INT is odd."

      fi

    fi

  fi

else

  echo "INT is not an integer." >&2

  exit 1

fi
```

注意我们使用了 `<` 和 `>` 符号，并且 `==` 用于测试等价。对于整数来说这是一个更自然的语法。此外，由于复合命令 `(( ))` 是 shell 语法而不是普通命令并且只处理整数，它可以通过名称识别变量而不需要执行算术扩展。我们将在第 34 章进一步讨论 `(( ))` 和相关的算术扩展。

## 组合表达式

还可以组合表达式以创建复杂的评估。表达式使用逻辑运算符组合。我们在学习 `[[ ]]` 时在第 17 章见过这些。`test` 和 `[[ ]]` 有三种逻辑操作。`test` 和 `[[ ]]` 使用不同的运算符表示这些操作，如表 27-4 所示。

### 表 27-4：逻辑运算符

| 操作 | `test` | `[[ ]]` |
|---|---|---|
| AND | `-a` | `&&` |
| OR | `-o` | `||` |
| NOT | `!` | `!` |

这是一个 AND 操作的示例。以下脚本判断一个整数是否在某个范围内：

```bash
#!/bin/bash

# test-integer: 判断一个整数是否在一个数值范围内。

MIN_VAL=1

MAX_VAL=100

if [[ "$INT" =~ ^[0-9]+$ ]]; then

    if [ "$INT" -ge "$MIN_VAL" ] && [ "$INT" -le "$MAX_VAL" ]; then

        echo "$INT is within $MIN_VAL to $MAX_VAL"

    else

        echo "$INT is out of range."

    fi

else

    echo "$INT is not an integer." >&2

    exit 1

fi
```

在这个脚本中，我们判断 `INT` 的值是否在 `MIN_VAL` 和 `MAX_VAL` 之间。这是通过单次使用 `[[ ]]` 完成的，它包含了由 `&&` 运算符隔开的表达式。我们也使用 `test` 编写了代码：

```bash
if [ "$INT" -ge "$MIN_VAL" ] - [ "$INT" -le "$MAX_VAL" ]; then

    echo "$INT is within $MIN_VAL to $MAX_VAL"

else

    echo "$INT is out of range"

fi
```

取反运算符会反转表达式的结果。如果表达式为假，它返回真；如果表达式为真，它返回假。在以下脚本中，我们修改了评估逻辑以寻找指定范围外的 `INT` 值：

```bash
#!/bin/bash

# test-integer4: 判断一个整数是否在一个数值范围之外。

MIN_VAL=1

MAX_VAL=50

if [[ "$INT" =~ ^[0-9]+$ ]]; then

    if [ "$INT" -ge "$MIN_VAL" ] || [ "$INT" -le "$MAX_VAL" ]; then

        echo "$INT is within $MIN_VAL to $MAX_VAL"

    else

        echo "$INT is out of range."

    fi

else

  echo "INT is not an integer." >&2

  exit 1

fi
```

通过正则表达式，我们将 `INT` 的值限制为以可选负号开头、后跟一个或多个数字的字符串。这种表达式消除了空值的可能性。`[[ ]]` 的另一个新增功能是 `==` 运算符支持模式匹配，与路径扩展也是如此。这使得 `[[ ]]` 对于评估文件名非常有用。

可移植性是小人的绊脚石

在实际操作中，这意味着我们可以执行如下操作：

```
[me@linuxbox ~]$ mkdir temp && cd temp
```

这将创建一个名为 `temp` 的目录，如果执行成功，当前工作目录将切换到 `temp`。只有在 `mkdir` 命令执行成功时，才会尝试执行第二个命令。同样，像这样的命令：

```
[me@linuxbox ~]$ [[ -d temp ]] || mkdir temp
```

将测试目录 `temp` 是否存在，只有在测试失败时才会创建该目录。这种结构对于处理脚本中的错误非常有用，我们将在稍后的章节中详细讨论这个主题。例如，我们可以在脚本中这样做：

```bash
[[ -d temp ]] || exit 1
```
