# 监控系统性能

当你担任系统管理员时，必须密切关注 Red Hat Linux 系统的运行情况。你可以通过查看以下信息来监控系统的整体性能：

- 中央处理器 (CPU) 使用率
- 物理内存使用率
- 虚拟内存（交换空间）使用率
- 硬盘使用率

Red Hat Linux 带有许多此类性能参数。在这里，我将介绍其中一些工具以及如何理解这些工具所提供的信息。
