- `home`

- `opt`

- `srv`
- `sys`
- `tmp`

这些目录中的大部分在所有 Linux 系统中都是一致的。从服务器到超级计算机再到微型嵌入式系统，丰富的 Linux 用户可以放心地使用 `/bin` 内的 `ls` 命令，通过修改 `/etc` 中的文件来更改系统配置，并在 `/var` 中读取系统日志。这些文件和目录的标准位置由文件系统层级标准 (FHS) 定义，我们将在后的课程中进行讨论。随着你继续学习 Linux，你将了解到更多关于这些目录的内容，但目前请记住：
- 你在根文件系统中所做的的更改将影响所有用户，并且
- 在根文件系统中更改文件需要管理员权限。

这意味着普通用户被禁止修改这些文件，也被禁止读取这些文件。我们将在后的部分介绍权限的主题。

现在，我们将关注 `/home` 目录，到目前你应该对它有些熟悉：

```
$ tree -L 1 /home
/home
  user
    michael
  lara
```

我们的示例系统有三个普通用户，每个用户都有自己的专有位置，他们可以在那里创建和修改文件及目录，而不影响邻居。例如，在上一节中，我们处理的是以下文件结构：

```
$ tree /home/user
user
└ Documents
  ├ Mission-Statement
  └ Reports
    └ report2018.txt
```

实际上，真实的文件系统可能像这样：

```
$ tree /home
/home
└ user
  └ Documents
    ├ Mission-Statement
    └ Reports
      └ report2018.txt
└ michael
  └ Documents
    └ presentation-for-clients.odep
  └ Music
```

...对于 `lara` 也是如此。

在 Linux 中，`/home` 类似于公寓楼。许多用户在这里拥有自己的空间，被分成独立的公寓。楼本身的实用和维护由管理员用户 `root` 负责。

### Home 的特殊关系路径

当你在 Linux 中启动一个新的终端会话时，你会看到这样的提示符：

```
user@hostname~$
```

波浪号 (`~`) 代表你的家目录。如果你运行 `ls` 命令，你会看到：

```
$ ls ~
```

### 探索性练习答案

1. 假设用户输入了以下命令：

```bash
$ mkdir "this is a test"
$ ls
this is a test
```

哪个 `cd` 命令允许你进入此目录？

```bash
$ cd this\is\ a\ test
```

2. 再次尝试，但在输入 `cd this_` 后按下 TAB 键。现在提示符上显示了什么？

```bash
$ cd this\is\ a\ test
```

这是自动补全的示例，它不仅是一个节省时间、还能防止拼写错误的宝贵工具。

3. 尝试创建一个包含 `\` 字符的目录。使用 `ls` 显示目录名称并删除该目录。

你可以使用另一个反斜杠 (`\\`) 来转义反斜杠，或者在整个目录名称周围使用双引号：

```bash
$ mkdir my\dir
$ ls
'my\dir'
$ rmdir 'my\dir'
```

### 引言

Unix 操作系统最初是为 20 世纪 60 年代的主机设计的。这些计算机由许多用户共享，他们通过终端访问系统资源。这些基本理念延续到了今天的 Linux 系统。我们仍然谈论使用“终端”在 `shell` 中输入命令，而且每个 Linux 系统的组织方式都使得在单个系统上创建许多用户变得很容易。
