
### 2.4.5 MAXPGIO

`maxpgio`参数规定了系统每秒调度的分页输出操作数量。在Solaris中，旧系统的默认值为每秒40页，Sun4系统为每秒60页。默认值是基于3600转的磁盘驱动。然而，大多数新磁盘驱动都是7200转或10000转。因此，你可以根据磁盘驱动的速度增加`maxpgio`的值。避免`maxpgio`过大，以免磁盘被分页I/O请求饱和。在Solaris中，`maxpgio`的公式为磁盘速率（每秒转数）乘以2/3。如果你的交换磁盘是7200转，则设置`maxpgio = 120 rpm x 2/3 = 80`。

### 2.4.6 PRIORITY PAGING

优先级分页（Priority Paging）是Solaris 7中的一项新功能，它改进了文件系统型系统的内存利用。优先级分页有助于解决普通文件系统活动影响应用程序利用的性能问题。由于Solaris将文件系统页面作为虚拟内存池的一部分，如果应用程序在大工作集上频繁执行文件系统I/O，可能会有大量内存被文件页面占用。例如，考虑一个数据库服务器

## 2.4 调优分页

数据库文件基于文件系统文件，且系统上存在大量并发用户。对于具有许多数据文件的大型数据库，数据工作集（working set）可能会很大，因为用户将在不同的数据集上进行操作（随机I/O）。在这种情况下，缓存每个文件系统页面可能会干扰数据库服务器的内存组件，并导致应用程序内存页被换出。通过使用优先级分页（priority paging），系统管理员可以对文件系统缓存设置上限，以确保页面不会从应用程序内存工作集中被有效“偷走”。大范围的文件系统I/O会导致内存中充斥着文件系统页面，当可用内存下降到`lotsfree`定义的阈值时，将触发页面扫描器（page scanner）。扫描器随后将尝试换出最近未引用的页面。由于正在发生大量的随机I/O，文件系统页面很可能是“热的”（最近被引用过）。因此，页面扫描器可能会决定换出应用程序的堆和栈空间。如果系统运行的是Oracle数据库，这可能导致SGA或PGA部分换出。

优先级分页定义了一个新的可调优参数`cachefree`，默认值为`2 × lotsfree`。如果启用优先级分页，系统会尝试维持由`cachefree`定义的页面数。此外，只有当空闲内存量在`cachefree`和`lotsfree`之间时，才会释放文件系统页面。优先级分页算法引入了新的页面扫描阈值`cachefree`。当可用内存低于`cachefree`时，页面扫描器将尝试仅释放文件系统页面，排除共享库和可执行文件。通过尝试避免换出相关的内存页，提高了内存利用率。如果禁用优先级分页且可用内存下降到`lotsfree`，即使文件系统I/O量极小，匿名内存（anonymous memory）也可能被换出。

优先级分页在Solaris 7和Solaris 2.6中作为内核补丁105181-09（或更高版本）可用。你可以通过在`/etc/system`文件设置设置`priority_paging`参数来启用优先级分页：

```
set priority_paging=1
```

### 2.4.7 分页参数检查

在调优内核分页参数时，必须维护以下范围检查：

```
cachefree > lotsfree > desfree > minfree
```
