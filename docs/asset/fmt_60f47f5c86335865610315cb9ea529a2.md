
## 描述

调试器 `jdb` 是一个类似 `dbx` 的命令行调试器，用于对 Java 类进行检查。

### 启动 jdb 会话

像 `dbx` 一样，`jdb` 有两种启动方式。最常用的方法是 `jdb` 挂载到运行中的 Java 解释器。当发生任何没有 catch 语句的异常时，Java 程序通常会转储异常跟踪并退出。但在运行 `jdb` 时，该异常被视为一个不可恢复的断点，`jdb` 会在出错指令处停止。

另一种方法是使用 `-debug` 选项启动 `jdb`。当你使用 `-debug` 选项启动时，可以捕获特定的异常。例如：

```
jdb -host hostname
```

当 `jdb` 启动后，可以使用 `catch` 命令捕获特定的异常。例如，捕获特定的异常如下：

```
jdb -debug INSTALL_DIR/classes
```
```
catch FileNotFoundException
```

### 基础 jdb 命令

以下列表描述了 `jdb` 命令：

- `help`: 显示识别命令列表。
- `print`: 浏览实例变量。注意-目前不支持该方法。
- `dump`: 转储（栈）变量。
- `up` / `down`: 选择当前的栈帧。
- `suspend`: 挂起执行。
- `continue`: 继续执行。如果请求线程挂起（因为在断点处或使用 `suspend` 命令），你可以使用 `print` 和 `dump` 查看局部和实例变量。
- `stop`: 在类中设置断点。通过其对象 ID 或名称指定类。如果类已经加载，你可以使用字符串（`t@index`）。
- `threads`: 列出当前线程，按线程组组织。线程通过其对象 ID 引用（`t@index`）。
- `where`: 无参数时，转储当前线程的栈。使用 `all` 子命令转储线程组中所有线程的栈。使用 `threadid` 子命令转储指定线程的栈（`t@index`）。

### 断点命令

按如下方式在类中设置断点：

- `clear at:line`: 断点，语法与 `stop` 类似。
- `cont`: 继续执行。
- `step`: 单步执行。
- `stop at class:line`: 指定源文件编号或方法名（断点将设置在该方法的第一条指令处）。例如，`at MyClass:45`

### 异常命令

当发生任何地方都没有 catch 语句的异常时，Java 程序通常会导出异常跟踪并退出。但在运行 `jdb` 时，该异常被视为不可恢复的断点，`jdb` 会在故障指令处停止。如果该类是用 `-g` 选项编译的，你可以打印实例和局部变量来确定异常原因。

- `catch`: 为特定异常设置断点。你可以使用 `catch` 命令捕获特定异常；例如，`catch FileNotFoundException` 或 `catch packagename.BigTroubleException`。
- `ignore`: 从此列表中移除异常类。注意，只有调试器会忽略特定异常。Java 解释器不会。

## 选项

当在命令行中使用 `jdb` 代 Java 解释器时，`jdb` 接受与 `java(1)` 命令相同的选项。
当使用 `jdb` 附加到正在运行的 Java 解释器会话时，`jdb` 接受以下选项。

- `-host hostname`
设置运行时要附加的解释器主机的名称。

- `-password password`
登录活跃的解释器会话。这是 Java 解释器在带有 `-debug` 选项调用时打印的密码。

## 环境变量

- `CLASSPATH` 提供指向用户定义类的路径。用冒号分隔目录；例如，
`:/home/avh/classes:/usr/local/java/classes`

## jobs, fg, bg, stop, notify — 控制进程执行

### 语法概要

```
jsh

jobs [-p | -1] [%job-id ...]

jobs -x command [arguments]

fg [%job-id ...]

bg [%job-id ...]

stop %job-id ...

stop pid ...
```

```
csh

jobs [-1]

fg [%job-id]

bg [%job-id] ...

notify [%job-id] ...

stop %job-id ...

stop pid ...
```

```
sh

jobs [-lnp] [%job-id ...]

fg [%job-id] ...]

bg [%job-id] ...]

stop %job-id ...

stop pid ...
```
