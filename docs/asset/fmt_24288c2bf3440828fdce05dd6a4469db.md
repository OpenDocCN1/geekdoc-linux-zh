
# Linux 词典

## pcscd
`pcscd` 某些与智能卡和 PC/SC 架构配合，包含一些对 PC/SC 服务器用户有用的工具。提供的工具包括：`pcsc_scan(1)` 扫描可用的读卡器并打印检测到的事件：带有 ATR 的卡片插入、读卡器；`scriptor(1)` 使用文件向智能卡发送命令的 Perl 脚本，或其理念与 `scriptor(1)` 相同，它是带有 Perl-Gk GUI 的 `scriptor.pl(1)` 的相同执行者。来自 Debian 3.0.0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## PCSD
`PCSD` PC Lite 资源守护进程。`PCSC` Lite 的目的是提供一个极小的 Windows(R) SCard 接口，用于与智能卡和读卡器进行通信。`PCSC` 守护进程用于在运行时动态分配/释放读卡器并管理与读卡器的连接。来自 Debian 3.0 apt `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## pd
- 实时音乐和图形系统。用于音频和图形分析的实时图形编程。`Pd` 的音频功能内置的；图形计算需要 `GEM`（“媒体环境”）。`Pd` 和 `GEM` 适用于 SGI 机器、兼容的 PC（运行 NT 或 W95）。来自 Debian 3.0。

## PDC
- 电源磁盘控制器 (`ECMA`)来自 Vera
`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
- 主域控制器。这是存储域的服务器和用户账户。它管理用户/域的所有方面。一个域有一个 `PDC` 并可以有多个 `DC`。`DC` 持有 `PDC` 信息的备份，并偶尔与 `PDC` 同步。两个 `DC` 可以执行认证等任务。通常，一个站点有一个 `PDC` 和一个 `DC`（可以缓存某些任务的 `PDC`），远程站点本地处理某些任务。来自 Linux Guide @First
`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
