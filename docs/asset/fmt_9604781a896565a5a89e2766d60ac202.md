
## 7. 使用 `/home/podmgr/http` 目录下的容器在生产网络中创建 `http-app01` 离容器（detached）。容器镜像必须是带有 `9.0` 标签的 `http-client`。将本地机器的 `8080` 端口映射到容器的 `8080` 端口。

### 7.1. 使用文件 `/home/podmgr/http-directory` 中的容器创建 `http-client:9.0` 镜像。

```bash
[podmgr@server ~$] podman build -t http-client:9.0 http-dev/
STEP 1/7: FROM registry.example.com/rhel8/php-74-1:63
...output omitted...
```

### 7.2. 在生产网络中创建 `http-app01` 离容器。将本地机器的 `8080` 端口映射到容器的 `8080` 端口。

```bash
[podmgr@server ~$] podman run -d --name http-app01 \
--network production -p 8080:8080 localhost/http-client:9.0
[podmgr@server ~$] podman ps -a
```
