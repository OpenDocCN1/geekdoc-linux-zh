
# GRUB

```
grub> find /boot/grub/stage1

(hd0,5)

grub> root (hd0,5)

grub> setup (hd0)

grub> quit
```

`find` 命令定位内核所在的分区。如果它返回“file not found”错误，请尝试省略路径开头的 `/boot`；GRUB 搜索的是分区，而不是你完全挂载的目录树；如果 `/boot` 是独立分区，你必须省略 `/boot` 标识符。返回的值 `(hd0,5)` 在 Linux 语境中通常是 `/dev/sda5`。第二个数字 `(5)` 是分区号，从 0 开始。Linux 分区从 1 开始，所以 `hd0,5` 指的是 `/dev/hda6`。GRUB 文件通常位于 `/boot` 中，因此如果你知道目录所在位置，可以跳过 `find` 命令；然而，即使在这种情况下使用 `find` 也是很有用的双重检查。

## 第 10 章 使用多个操作系统

`root` 命令设置 GRUB 的根设备。注意，GRUB 根设备可能与 Linux 根分区不同；GRUB 根设备是 GRUB 文件所在的分区。如果 `/boot` 目录是独立分区，GRUB 根设备可能与你的 Linux 根分区不同。指向 GRUB 根设备的指针设置 GRUB 根设备。`setup` 命令将引导加载器安装到 MBR 或分区引导扇区。

`find` 命令定位内核所在的分区。如果它返回“file not found”错误，请尝试省略路径中的 `/boot`；GRUB 搜索的是分区，而不是你完全挂载的目录树；如果 `/boot` 是独立分区，你必须省略 `/boot` 标识符。返回的值 `(hd0,5)` 在 Linux 语境中通常是 `/dev/sda5`。第二个数字 `(5)` 是分区号，从 0 开始。Linux 分区从 1 开始，所以 `hd0,5` 指的是 `/dev/hda6`。GRUB 文件通常位于 `/boot` 中，因此如果你知道目录所在位置，可以跳过 `find` 命令；然而，即使在这种情况下使用 `find` 也是很有用的双重检查。

## 第 10 章 使用多个操作系统

LILO 启动默认操作系统之前的超时时间，单位为十分之一秒（`timeout=100`）；安装引导加载程序的设备（`/dev/hda`）——LILO 安装在 MBR 中，而不是分区引导扇区（如 `/dev/hda6`）；以及一个使用线性（或逻辑）块寻址（LBA）模式的选项（`lba32`）。接下来的八行（`change-rules` 部分）定义了分区类型代码，这些代码将用于 DOS 和 Windows 的设置。列表 10.2 定义了 DOS-16 和 DOS-32 分区类型，每种类型都有普通和隐藏变体。

### 列表 10.2：典型的 LILO.CONF LILO 配置文件

```
prompt

timeout=100

default=linux

boot=/dev/hda

map=/boot/map

install=/boot/boot.b

message=/boot/message

lba32

change-rules

  reset

    type=DOS016

      normal=0x06

      hidden=0x16

    type=DOS32

      normal=0x0b

      hidden=0x1b

image=/boot/bzImage-2.4.19

  label=linux

  root=/dev/hda7

  read-only

  other=/dev/hda2

    label=windows

    change

      partition=/dev/hda2

        activate

          set=DOS32_normal

      partition=/dev/hda1

        set=DOS16_hidden

        deactivate

other=/dev/hda1

  label=dos

  change

    partition=/dev/hda1

      set=DOS16_normal

      activate

    partition=/dev/hda2

      set=DOS32_hidden

      deactivate
```
