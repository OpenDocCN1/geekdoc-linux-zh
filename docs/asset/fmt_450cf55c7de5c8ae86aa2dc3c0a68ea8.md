## 确定你的 iPod 格式

你怎么知道你的 iPod 是 HFS+ 还是 FAT32 格式？嗯，我想说，这基本上取决于你目前为止一直在使用哪种系统来操作 iPod。当你第一次将崭新拆封的 iPod 插入电脑时，它实际上实际上什么都做不了。那时，你的 Windows 或 Mac 系统会提示你运行 iPod Updater 工具。该工具主要是一个格式化程序，用于对你的设备进行格式化。

如果你是一个双系统用户，一直同时在 Mac 和 Windows 电脑上愉快地使用你的 iPod，那么你可以确定你的 iPod 是使用 FAT32 格式格式化的，因为 Windows 在尝试处理任何非微软官方创建的内容时都会“束手无策”。换句话说，Windows 无法读取 HFS+ 格式的驱动器，而 Mac 可以同时读取 HFS+ 和 FAT32 驱动器。如果你也完全确定它是 FAT32 格式，因为所有的 iPod Shuffle 都是如此——不此例外。

当然，如果你是一个“凡事都要证据”的人，你可以将 iPod 插入你配置好的 Mac 或 Windows 电脑上，通过事实寻求真相，查看 iTunes 窗口右侧“Format”（格式）字样旁显示的内容。如果显示为 Windows，你就可以用了。

如果你手头没有 Mac 或 Windows 电脑，可以从 Ubuntu 的“应用程序”（Applications）菜单中选择“附件”（Accessories）> “文本编辑器”（Text Editor）。在左侧格中打开“文件系统”（File System），双击右侧格中的 `etc`，选择文件选项卡，然后点击“打开”（Open）按钮即可查看你的 iPod 格式。只需寻找类似 `/dev/sda2 /media/ipod` 或 `/dev/sdb1 /media/ipod` 的行，并查看右侧列出的内容。如果显示为 `vfat`，你就知道你的设备是 FAT32 格式。如果显示 `hfsplus`，那么……你只需要把它改掉。

## 重新格式化 iPod

如何将你的 iPod 从 HFS+ 格式更改为 FAT32 格式呢？最简单的方法是找一台运行 Windows 2000 或更高版本以及最新版 iTunes 的机器。但在继续之前，请确保已经备份了 iPod 上的所有内容，因为你将对其进行重新格式化，这意味着将其清空。

一旦你准备好确保 Windows 电脑已连接互联网，启动 iTunes，然后将 iPod 插入 Windows 电脑的 USB 端口。会出现一个窗口，提示你有一个 Mac 格式的 iPod，在 Windows Windows 中使用它之前必须对其进行恢复。点击“OK”。

为了让你的 iPod 达到 Linux 下的舒适可用状态，请点击 iTunes 窗口右侧格中的“恢复”（Restore）按钮。会出现一个警告窗口，提示你 iPod 上的所有内容都将被删除（这就是我之前警告先备份所有内容的原因）。点击“恢复并更新”（Restore and Update）按钮，然后按照简短的向导操作。向导完成后，静静等待 iPod 恢复（到 Windows 格式）。这需要几分钟时间，请享受这段短暂的休息。

进程完成后，会出现一个新窗口要求你为 iPod 命名，并询问你是否希望 iTunes 自动将 iPod 与你的照片和音乐收藏同步（图 16-2）。给 iPod 起什么名字随你决定（短名称在 GNOME 桌面显示效果更好），但我强烈建议勾选两个自动同步复选框；否则以后可能会导致意想不到的异常。完成后，点击**OK**。

**图 16-2：** 完成你的 iPod 从 HFS+ 到 FAT32 的转换过程

一旦整个过程完成，你将拥有一个配置正确、FAT32 格式且完全空的 iPod，它已准备好在 Linux、Windows 和 Mac OS 上使用。你现在甚至可以在所有系统上交替查看你的 iPod，尽管我只会在禁用自动更新功能的情况下才会这样做。

## （不）自动更新你的 iPod

当你通过 iTunes 启用 iPod 的自动更新时，该功能是设置在 iPod 内部的。对于 FAT32 格式的 iPod，你可以在 Windows 电脑、Mac 或 Linux 电脑上使用它——或者在所有设备之间交替使用。如果你将 iPod 设置为自动更新歌曲和播放列表，除非你在 Linux、Mac 和 Windows 机器上拥有完全相同的收藏，否则你将会自找麻烦。

其原因很简单。虽然 iTunes 允许你向 iPod 添加文件，但不允许你从 iPod 拷贝文件。自动更新功能是严格的单行道。这意味着每当你将开启了自动更新的 iPod 连接到支持 iTunes 的电脑时，iTunes 都会自动将其库中的曲目添加到你的 iPod 中，更可怕的是，它会移除 iPod 上任何库中不存在的曲目。我是通过一次惨痛的经历学到这一点的：我把妻子装满歌曲的 iPod 带到公司，插入了我 iTunes 库完全空的办公室 Windows 电脑上。当我把那个空空如也的小 Podster 带回给她时，场面可真难看。

如果你的 iPod 已经是 FAT32 格式，在将 iPod 引入 Linux 世界之前，最好在连接 Windows 电脑时禁用 iPod 自动更新功能。要这样做，开始将 iPod 连接到机器。在 iTunes 窗口的左侧格中，选择你的 iPod。在右侧格中，点击“通用”（General）选项卡并取消勾选自动更新框。点击“OK”。

为了让你的 iPod 达到 Linux 下的舒适可用状态，请点击 iTunes 窗口右侧格中的“恢复”（Restore）按钮。会出现一个警告窗口，提示你 iPod 上的所有内容都将被删除（这就是我之前警告先备份所有内容的原因）。点击“恢复并更新”（Restore and Update）按钮，然后按照简短的向导操作。向导完成后，静静等待 iPod 恢复（到 Windows 格式）。这需要几分钟时间，请享受这段短暂的休息。

进程完成后，会出现一个新窗口要求你为 iPod 命名，并询问你是否希望 iTunes 自动将 iPod 与你的照片和音乐收藏同步（图 16-2）。给 iPod 起什么名字随你决定（短名称在 GNOME 桌面显示效果更好），但我强烈建议勾选两个自动同步复选框；否则以后可能会导致意想不到的异常。完成后，点击**OK**。
