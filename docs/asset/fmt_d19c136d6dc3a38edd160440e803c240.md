# 热键

某些客户端需要保证无论输入法状态如何，哪些键可以用于退出输入；例如，客户端特定的“帮助”键或移动输入焦点的按键。热键机制允许客户端为此目的指定一组按键。然而，输入法可能不允许客户端指定热键。因此，客户端必须通过检查使用 `XIMValues` 配合 `XQueryICList` IM 值所支持的 XIC 值来查询对热键的支持情况。当热键与输入法的键绑定冲突时，热键的优先级高于输入法的键绑定。

# 预编辑状态操作

取决于其实现和区域，输入法可能有多个内部状态。然而，有一个独立于区域和实现的状态，即输入法当前是否正在执行预编辑（preediting）操作。Xlib 提供了应用程序程序化管理预编辑状态的能力。提供了两种方法获取输入上下文的预编辑状态。一种是通过调用 `XGetICValues` 并使用 `XNPreditState` XIC 值来查询状态；另一种是在预编辑状态发生变化时接收通知。要接收此类通知，应用程序需要通过调用 `XSetICValues` 并使用 `XNPreditStateNotifyCallback` XIC 值来注册回调。要程序化更改预编辑状态，应用程序需要调用 `XSetICValues` 并使用 `XNPreditState`。

预编辑状态的可用取决于输入法。输入法可能不提供设置或检索预编辑状态的功能。因此，客户端必须通过调用 `XGetIMValues` 配合 `XNoQueryValuesList` IM 检查支持的 XIC 值来查询预编辑操作的可用性。

# 输入法函数

要建立连接，请使用 `XOpenIM`。

```
XIM XOpenIM(display, db, res_name, res_class);
```

`display` 指定到 X 服务器的连接。

`db` 指定资源数据库的指针。

`res_class` 指定应用程序的全类名。

`OpenIM` 函数打开一个匹配当前区域和修饰符指定的输入法。当前区域和修饰符在打开时绑定到输入法。与输入法关联的区域不能动态更改。对于关联输入法的输入上下文，`XmbLookup8String` 或 `XwcLookupString` 返回的字符串应在输入法打开时按当前区域编码。

此调用将根据当前区域路由到特定的输入法。`OpenIM` 识别一个与当前区域对应的默认输入法。可以使用 `XSetModifiers` 修改该默认值。

`db` 参数是输入法使用的资源数据库。它是输入法用于查找输入法私属性的数据库。如果 `db` 为 `NULL`，则不向输入法传递数据库。

`res_name` 和 `res_class` 指定应用程序的资源名和类。它们旨在作为输入法在为该输入法创建的所有输入上下文查找资源的前缀。使用的字符必须是便字符集。如果 `res_name` 或 `res_class` 为空，则加载的资源不完整。

`res_name` 和 `res_class` 参数假设在调用 `OpenIM` 之后存在。指定的资源数据库假设在输入法的生命周期内存在。

`OpenIM` 在无法打开输入法时返回 `NULL`。

要关闭连接，请使用 `XCloseIM`。

```
Status XCloseIM(im);
```

`im` 指定输入法。

`XCloseIM` 函数关闭指定的输入法。

要设置输入法属性，请使用 `XSetIMValues`。

```
char *XSetIMValues(im);
```

`im` 指定输入法。

...

指定设置 XIM 值的变长参数列表。

`XSetIMValues` 函数提供了设置输入法属性的可变参数编程接口。如果成功，返回 `NULL`；否则返回失败参数的名称。`Xlib` 不使用列表中的后续参数；失败参数之前的所有参数已正确设置。

要查询输入法，请使用 `XGetIMValues`。

```
char *XGetIMValues(im);
```

`im` 指定输入法。

...

指定获取 XIM 值的变长参数列表。

`XGetIMValues` 函数提供了查询指定输入法属性或特征的可变参数列表。如果成功，返回 `NULL`；否则返回无法获取的参数名称。每个 XIM 值（位于名称之后）必须指向要存储 XIM 值的位置。也就是说，如果参数类型为 `*`，`XGetIMValues` 会分配内存存储实际数据，客户端负责通过调用 `XFree` 的指针释放这些数据。

实际上 `XDisplayOfIM` 返回与指定输入法关联的显示。

要获取与输入法关联的区域，请使用 `XLocaleOfIM`。

```
char *XLocaleOfIM(im);
```

`im` 指定输入法。

`XLocaleOfIM` 函数返回与指定输入法关联的区域。

## 查询输入样式

客户端应始终查询输入法以确定支持哪些输入样式。然后，客户端应该找到一个它可以支持的输入样式，并应与用户协商程序的继续执行（退出、选择另一种输入法等）。

参数值可能是一个指向返回值存储位置的指针。返回值是一个指向类型为 `XIMStyles` 的结构的指针。客户端负责释放 `XIMStyles`。请使用 `XFree` 进行释放。

`XIMStyles` 结构定义如下：

```c
typedef unsigned long XIMStyle;

#define XIMPreeditArea 0x0001L

#define XIMPreeditCallbacks 0x0002L

#define XIMPreeditPosition 0x0004L

#define XIMPreeditNothing 0x0008L

#define XIMPreeditNone 0x0010L

#define XIMStatusArea 0x0100L

#define XIMStatusCallbacks 0x0200L

#define XIMStatusNothing 0x0400L

#define XIMStatusNone 0x0800L

typedef struct {
    unsigned short count_styles;
    XIMStyle * supported_styles;
} XIMStyles;
```
