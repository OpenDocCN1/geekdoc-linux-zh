文件测试运算符 `-nt` 测试第一个文件是否比第二个文件新，而 `-ot` 测试第一个文件是否比第二个文件旧。

```bash
if [ ! -d $file1 ]
then
  echo "File is not a directory"
fi
```

一个需要注意的特殊情况是，根据给定测试结构的成功执行单个命令。考虑以下内容：

```bash
[ -r myfile.txt ] && echo "the file is readable."
```
