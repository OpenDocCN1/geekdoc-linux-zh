
返回给 `font_struct_list` 的一组指向 `XFontStruct` 结构的指针列表。返回给 `font_name_list` 的一组在输出上下文区域内以 null 终止的完全指定的字体名称字符串的指针列表。名称列表顺序与 `font_struct` 列表对应。`XFontStruct` 结构和字体名称的数量返回给 `num_font`。

由于无法保证某个字符会使用单个字体字形（glyph）进行成像，因此没有提供根据字符或默认字符串的字体属性、ID 或微调（hint）进行测量的规定。客户端可以访问 `XFontStruct` 列表以获取当前正在使用的所有字体这些值。

`XLib` 不保证在创建 `XOC` 时已从服务器加载字体。`XLib` 可能会缓存字体数据，仅在需要绘制文本或文本尺寸时才加载。`XFontSet` 中 `XFontStruct` 结构中的 `per_char` 指标的存在未定义。此外，请注意 `XFontStruct` 结构中的属性是 `STRING` 编码。

客户端不得释放 `XOMFontInfo` 本身；它将在 `XOC` 关闭时被释放。

## OM 自动 (OM Automatic)

`XOMAutomatic` 参数返回输出上下文是否由 `XCreateFontSet` 创建。由于 `XFreeFontSet` 函数不仅销毁输出上下文还会关闭与其关联的隐式方法，因此对于任何由 `XCreateFontSet` 创建的输出上下文，都应该使用 `XFreeFontSet`。然而，客户端可能不知道输出上下文是如何创建的。在客户端销毁输出上下文之前，它可以查询 `XOMAutomatic` 是否被设置为 true，以决定应该使用 `XFreeFontSet` 还是 `XDestroyOC` 来销毁输出上下文。

## 创建和释放字体集

`Xlib` 文本绘制是使用一个或多个字体完成的，这取决于文本区域设置（locale）的需求。字体根据客户端提供的基础字体列表和区域设置所需的字符表列表进行加载。`XFontSet` 是一个不透明类型，表示特定输出线程的状态，等同于 `XOC`。

`XFreeFontSet` 函数是一个仅使用默认值创建输出上下文的便利函数。返回的 `XFontSet` 具有一个隐式创建的 `XOM`。该 `OM` 值 `XOMAutomatic` 被设置为 `True`，以便输出上下文能够指示它是由 `XCreateOC` 还是 `XFreeFontSet` 创建的。

```
XFontSet XFreeFontSet(display, base_font_name_list,
missing_charset_list_return, missing_charset_count_return,
def_string_return);
```

指定与 `X` 服务器的连接。

- `base_font_name_list` 指定基础字体名称。
- `missing_charset_return` 返回缺失的字符集。
- `missing_charset_count_return` 返回缺失字符集的数量。
- `def_string_return` 返回为缺失字符集所绘制的字符串。

`XCreateFontSet` 函数为指定的显示器创建一个字体集。当调用 `XCreateFontSet` 时，字体集会绑定到当前的区域设置。该字体集可以在随后的调用用于获取字体和字符信息，并在字体集所在的区域设置内成像文本。

基础字体名称参数是一个字体名称列表，`Xlib` 借此加载区域设置所需的字体。基础字体名称是一个逗号分隔的列表。该字符串以 null 终止，并假设为主机可移植字符编码（Host Portable Character Encoding）；否则，结果取决于实现。分隔逗号两侧相邻的空格将被忽略。

使用 `XLFD` 字体名称允许 `Xlib` 从单个不依赖区域设置的字体名称中获取各种区域设置所需的字体。单个基础字体名称应命名一个字体族，该族族的成员在感兴趣的区域设置所需的各种字符集中编码。

`XLFD` 字体名称可以显式指定区域设置所需的字符集。这允许用户指定精确的字体以与区域设置所需的字符集配合使用，从而完全控制字体选择。

如果字体名称不是 `XLFD` 名称，`XLib` 将尝试从该字体的字体属性中获取一个 `XLFD` 名称。如果此操作成功获取了 `XLFD` 名称，则 `XBaseFontNameListOffFont` 将返回该 `XLFD` 名称或客户端提供的名称。

# 语言区域与国际化文本函数

`XFontStruct` 中的 `XFontStruct` 结构是未定义的。此外，请注意 `XFontStruct` 结构中的所有属性均为 `STRING` 编码。

`XFontStruct` 和字体名称由 `Xlib` 列出，客户端不应对其进行修改或释放。它们将通过与 `XFontSet` 关联 `XFreeFontSet` 释放。在释放之前，`Xlib` 不会修改其内容。

要获取由 `XFontSet` 提供的基础字体名称和选定字体列表，请使用 `XBaseNameListOffsetSet`。

```
char *XBaseNameListOffsetSet(font_set);
```

指定字体集。

`XBaseNameListOffsetSet` 函数返回客户端在创建 `XFontSet` 时提供的原始基础字体名称列表。返回值为一个包含逗号分隔字体名称列表的空终止字符串。逗号两侧可能紧挨空格。

如果 `XCreateFontSet` 从指定为非 `XLFD` 基础名称的字体属性中获取了名称，则 `XBaseNameListGetOffset` 函数将返回 `XLFD` 名称而非 `XLFD` 基础名称。

基础字体名称由 `Xlib` 拥有，客户端不应对其进行修改或释放。它将通过与 `XFontSet` 关联 `XFreeFontSet` 释放。在释放之前，`Xlib` 不会修改其内容。

要根据 `XFontSet` 获取语言区域名称，请使用 `XLocaleGetOffsetSet`。

```
char *XLocaleGetOffsetSet(font_set);
```

指定字体集。

`XLocaleGetOffset` 函数返回绑定到 `XFontSet` 的语言区域名称，格式为空终止字符串。

返回的语言区域字符串由 `Xlib` 拥有，客户端不应对其进行修改或释放。它将通过与 `XFontSet` 关联 `XFreeFontSet` 释放。在释放之前，`Xlib` 不会修改它。

`XFreeFontSet` 函数是释放输出的以便方法。如果输出上下文是由 `XCreateFontSet` 创建的，`XFreeFontSet` 也会释放其关联的 `XOM`。

```
void XFreeFontSet(display, font_set);
```
