如何编写一个简单的 `Python` 程序？
编辑一个包含你的 `Python` 程序的文本文件。当你使用 "kate" 编辑器进行操作时（在 `X` 环境下）时：

输入一些简单的 `python` 代码来测试它是否运行：

```python
#!/usr/bin/env python

print "2x"
```

第一行（带有“pound-bang”符号 `#!`）告诉 shell 执行此文本文件——它必须存在（且始终位于第一行），`Linux` 才能知道这个特定的文本文件是一个 `Python` 脚本。
第二行是一个简单的 `Python` 表达式。

保存文件后，我赋予了它可执行权限：

```bash
chmod +x try_python.py
```

之后我可以通过以下命令运行它：

```bash
./try_python.py
```

如何编写一个简单的 GUI 程序（使用 `Tk`）？
`Tk` 是非常强大的 `tcl` 编程语言的 GUI 扩展。例如，我可以使用 `pico` 创建一个包含一个简单 `tk` 程序的文本文件：

```wish
#!/usr/bin/wish

Button .my_Button -text "Hello World" -command exit

pack .my_Button
```

第一行（以 "#!" pound-bang 开头）告诉 shell 工具使用来执行我的文本文件。接下来的两行是一个简单程序的示例。我创建了一个名为 "my button" 的按钮，并将其放置在类层次结构的根节点（"my button" 前面的 /）。对于该按钮，我绑定了文本 "Hello World" 和一个执行程序的命令（当按钮被按下时执行）。最后一行让我的程序窗口调整大小，大足以容纳我的按钮。

保存文件后，我赋予了它可执行权限：

```bash
chmod +x try_tk
```

之后我可以通过输入运行它（在 `X` 终端中，因为需要 `X` 窗口运行）：`./try_tk`

`Tk` 在构建 GUI 前端方面非常流行。

要在 `ruby` 中编写一个简单的程序，我打开我喜欢的编辑器，并以以下第一行启动程序：

```ruby
#!/usr/bin/ruby

# 这是一个程序示例，帮助我理解 ruby 语言的基础知识：

# 这是一个注释

a = Array.new

i = 0

print "Please enter a few words (EXIT to stop):\n"

while enterWord = STDIN.gets

  enterWord.chop!

  if enterWord == "EXIT"

    break

  end

  a[i] = enterWord

  i += 1

end

# 对数组排序

for i in 0..a.length-1 do

  for j in i+1..a.length do

    if a[j] < a[i]

      tmp = a[i]

      a[i] = a[j]

      a[j] = tmp

    end

  end
```
