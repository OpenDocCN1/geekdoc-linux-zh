下一步是安装 Azure PowerShell 模块。使用 PowerShell 命令 `Install-Module` 来完成模块安装及相关依赖的工作。要安装 PowerShell，请在你的 PowerShell 会话中执行以下命令：

Install-Module Azure.Net
