# DNS (域名系统)

类比：通过电话查找某人时，你会在电话簿查找号码。`DNS` 是一项服务。当互联网很小时，每个机器都有 IP 地址。历史：`DNS` 相对较新。当时人们会背记 IP 地址。关键点：`DNS` 对于通信至关重要。如果 `DNS` 服务器宕机，网络会被认为坏了。黑客经常通过原始 IP 地址绕过 `DNS`。`DNS` 的层级结构从“顶级域名”开始，如 `.com`, `.org`, `.edu`, `.mil` 以及两位国家代码（例如 `.jp` 代表日本）。误解：但 IP 地址和域名之间的一一对应关系是错误的（例如“com” = 192.”）。类比：如果你被问到这个问题，你可以给他们你的手机号。`DNS` 可以访问每一个。以相同的方式，像 `http://www.yahoo.com/` 这样的域名可能有多个 IP 地址。每次访问网站时，可能会访问不同的 IP 地址。你可以自己测试这个。去命令行输入 `ping yahoo.com`。看它返回哪个 IP 地址。之后再次尝试。注意看第二次返回的是不同的 IP 地址。详情：`DNS` 提供多种资源记录 (`RR`)：

- `A` 正常记录，包含名称到 IP 地址的映射。
- `LOC` 地理位置，包含经纬度、高度和大小。高度是海平面以上的高度。大小是体积单位的的指数。黑客利用这些记录找到你的物理位置。幽默：该记录的原始名称是 `ICBM`。`HOST` 记录可以包含机器的信息，因为它是 Windows 或 Unix 机器。管理员不填写它们；它们是危险的。`PTR`。自 [黑客词典](http://www.tldp.org/LDP/Linux-Dictionary/html/index.html)

# DNS (域名系统)

该系统将主机映射到 IP 地址。`DNS` 是域名系统。`DNS` 将机器名称转换为地址。它翻译（用术语说为映射）从地址到名称以及名称到地址，以及其他内容。这是如何使用 Unix 定义映射，并包含一些 Linux 特有的内容。映射是两个事物之间的关联，在这种情况下是像 `ftp.org` 这样的名称与机器的 IP 号（或地址）`192.249.150.4` 也可以反过来映射，从 IP 号映射到机器名称；这被称为“反向映射”。`DNS` 是为初学者（你）准备的。
