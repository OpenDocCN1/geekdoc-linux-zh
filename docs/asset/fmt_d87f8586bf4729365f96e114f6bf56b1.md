# 1096 人机系统

结合人类和机器组件的系统。人机系统通过此类系统的分析、建模和设计进行工程化。它与更广泛的人机交互领域以及人机交互的相关因素、工程心理学和社会技术系统区分开来。人机系统的工程需要关注复杂的动态控制系统，这些系统通常是部分或全自动（例如驾驶飞机、监控电厂或监督制造系统）。

## 未来研究
遗传组织的重点现在必须转向人类如何与机器以及人类相互互动。人机系统所做的及其对人类健康的影响也必须予以关注。此外，人机系统面临着整合控制和人类系统所带来的独特挑战。这一历史源于控制工程、信息技术、工程心理学和理论领域的工作。随后，专注于人机交互（人类与机器共同工作）的研究人员也被认知工程或认知系统工程。
