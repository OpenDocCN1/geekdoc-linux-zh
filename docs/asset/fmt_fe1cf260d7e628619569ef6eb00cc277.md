### 使用 `time` 分析命令

如果您有特定的命令想要深入了解，可以使用 `time`，它会报告在执行您指定的任何命令时花费的经过时间、用户时间和系统时间。

`time` 是一个用户友好的命令，因为它能让你了解执行命令时消耗的系统资源。以下两个示例展示了不带选项执行 `time` 以获取已消耗 CPU 量的简短输出；第二个示例展示了在 Solaris 系统上执行 `time -s` 以报告“总”系统活动：

```
marvyp $ time listing

real    0.02
user    0.00
sys     0.02
```

```
marvyp $ time -s listing

real    0.02
user    0.00
sys     0.01
```
