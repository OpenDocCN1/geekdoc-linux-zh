## dirs


## echo

`eval argument ...`

`eval` 将参数视为 shell 的输入，并在当前 shell 的上下文中执行生成的命令。这通常用于执行作为命令或变量替换结果生成的命令，因为解析发生在替换之前。

`exec command`

`exec` 替换当前 shell 执行指定的命令。

## exit

`exit [expression]`

shell 将带有指定表达式的值退出，或者如果没有包含表达式，则带有状态变量的值退出。

## fg

`fg [%job ...]`

`fg` 将指定的作业（或在不带参数的情况下，将当前作业）带入前台，如果该作业处于停止状态，则继续执行。

作业参数是使用作业号或以下字符串之一的作业引用：`:`、`%`、`+` 或 `-`。对于数字，将作业号放在 `%` 之后，例如作业 2 使用 `%2`。在命令行上仅使用作业引用将隐含使用 `fg` 命令。（例如，`%2` 将将作业 2 置于前台。相反，`%2&` 将其置于后台，隐含使用 `bg` 命令）。

除了作业号，你可以使用无歧义的字符串。（例如，`%lp` 将引用打印作业，前提是它是唯一的打印作业。）通过前面的 问号（`?`），你可以引用包含字符串的作业，而不仅仅是以字符串开头的作业。例如，`%7myfile` 引用任何包含字符串 `myfile` 的作业。）你可以使用 `%`、`#` 和 `%` 运算符来引用当前作业，并使用 `%-` 引用上一个作业。

## foreach

```
foreach variable ( list of values )
commands
end
```

`foreach` 结构设计用于顺序引用值列表。它与 BASH shell 的 `for-in` 结构非常相似。`foreach` 结构接受两个操作数——变量和一个括在括号内的值列表。列表中的每个值都被分配给 `foreach` 结构中的变量。与 `while` 结构一样，`foreach` 结构是一个循环。每次循环时，列表中的下一个值被分配给变量。当到达列表结束时，循环停止。与 `while` 循环一样，`foreach` 循环以关键字 `end` 结束。
