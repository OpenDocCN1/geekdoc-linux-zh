## 更改用户 Web 页面使用的目录名称

### 修改 httpd.conf 文件

输入命令。

```
[root@server]# vi /usr/local/etc/apache/httpd.conf
```

如果 `UserDir` 行中编写的目录名称在用户的家目录中存在，则该目录将用于用户的 Web 页面。

```apache
# UserDir: 当接收到用户请求时，附加用户家目录的目录名称。
# UserDir WWW
```

1. 输入为用户 Web 页面设置的目录名称。
2. 保存修改文件并退出。

> 注意：关于 `vi` 文本编辑器的信息请参阅第 95 页。

```

```
