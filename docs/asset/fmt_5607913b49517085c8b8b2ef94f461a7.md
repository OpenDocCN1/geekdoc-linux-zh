### `wu-ftpdpd`
一个强大且广泛使用的 FTP 服务器守护进程，最初来自圣路易斯华盛顿大学，是 Unix 系统中强大且广泛使用的 FTP 服务器替代方案。FTP 协议是网络和/或互联网之间传输文件的方法。除了完全支持 RFC 950 和 1579（其他）中定义的 FTP 协议外，它还具有以下功能：传输日志、登录日志、压缩和归档、按类型和位置对用户进行分类、每类限制、每个目录上传权限、受限访客账户、操作系统和目录消息、目录别名、`cdpath`、文件名过滤，由 `WU-FTPD` 守护小组作为公共服务向互联网发布。来自 Debian 3.0rt APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### `wv`
转换和预览 Microsoft Word 文档（以前称为 wordsoft）是一个允许访问 Microsoft Word 文件的库。它可以加载并解析 Word 2000、97、95 和文件格式。（Word 用于支持读取早期的格式，如：* wwWord: Word 2 文档被转换为纯文本。）在提供的程序包括：

* `wwHtoHTML`: 转换为 HTML 和 LaTeX。用于一小部分辅助脚本来审查 Word 文档并转换为其他格式（如 PostScript、PDF、DVI 等）。
* `wwKRT`: 转换为 Microsoft 的右格式 (Right Format)。
* `wwSummary`: 显示所有 OLE 2 文件的信息流，即 Excel、PowerPoint、Visio、Access 等。
* `wwVersion`: 输出 Word 格式存储的版本。来自 Debian 3.0rt APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### `wwdial`
内置智能功能的 Wav。Wavdial 满足了某些灵活性形式（如“chat”），以便你的拨号配置更简单。当你安装此包时，系统会自动检测到你的型号，你需要指定三个参数：电话号码、用户名和密码。Wavdial 知道根据大多数需求进行拨号并在无需其他帮助的情况下登录大多数服务器。特别是，你不再需要通过“chat”来处理最常见的情况。来自 Debian 3.0rt APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### `wvdial`
Wavdial 自动配置和管理，并可以登录几乎任何 ISP 的服务器，而无需特殊配置。你需要输入用户名、密码、电话号码，然后 Wavdial 将使用任何需要的机制协商 PPP 连接。来自 Debian 8.0 Rapid http://www.tld.org/LDP/Linux-Dictionary/html/index.html

### `WWW`
