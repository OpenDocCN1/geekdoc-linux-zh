
## 大气化学反应

### 光解反应

**O₂ + hν → 2O**

在 50 英里（90 公里）以上，氧气开始转化为分子氧而非臭氧。如果加入氧气，则通过反应（2）和（3）产生臭氧：

**O₃ + hν → O₂ + O**

### 平流层化学循环

平流层中的主要化学循环。臭氧的破坏是由光解和源气体氧化产生的自由基引起的。化学储层是稳定的，但通过输运从平流层中移除并产生 `Cl`、`HOCl` 和 `ONO₂`，随后是由平流层底部的氯通过催化循环（5–7）破坏引起的。这些过程的发生需要太阳辐射。

#### 催化循环反应

```
Cl + O3 -> ClO + O2 (5)

ClO + O -> Cl + O2 (6)

ClO + hnu -> Cl + O (7)
```
