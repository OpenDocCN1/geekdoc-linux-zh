
当然，许多广播机构还提供未出现在 SHOUTcast 列表上的直播互联网源。例如法国电台 (Radio France)，它提供多个流。你尝试的流是 Fip，这是一个极其酷炫的各种流派音乐集合；他们播放的内容将不断令你惊喜。如果你担心听不懂语言，别担心；他们很少说话，大约 80% 的音乐是用英语播放的。除了 *je suis fatigé*（我累了），我并不会说任何法语，但我完全没有问题。

如果你想泛泛尝试流媒体（特别是法国电台），在 Rhythmbox“新建互联网电台”窗口的 URL 框中输入 `http://http.yacast.net/v4/radiofrance/fip`. 并点击添加。假设你已经连接到互联网，双击列表中的新增项目，Fip 应在几秒钟预缓冲后开始播放。

## Rhythmbox 中的其他功能

Exile 有许多值得注意的酷功能。你无法不注意到，它提供了正在播放曲目或流的屏幕显示，不仅显示歌曲标题和艺术家，还显示了专辑封面。这在隐藏模式下使用 Exile 时特别方便，你可以通过 Exile 面板作为切换开关来实现这一点。

如果你不喜欢这个屏幕上的显示（或它的外观），可以通过进入“工具”（Tools）菜单并选择“偏好”（Preferences）来更改它。当“偏好”窗口出现时，点击左侧窗格中的 OSD，窗口右半部分将出现一个你可使用的选项列表。要更改显示的位置，只需在“偏好”窗口打开时，将其拖动到你喜欢的位置即可。完成更改后，点击“应用”（Apply）使更改立即生效，然后点击“确定”（OK）关闭“偏好”窗口并大搞定。

正如我已经提到的，Exile 还会像 Rhythmbox 对你正在播放的曲目那样，下载并显示你正在播放曲目的专辑封面。像 Rhythmbox 一样，它还可以下载并显示你正在播放曲目的歌词。要查看歌词，只需进入“视图”（View）菜单并选择“信息”（Information） > 歌词”（Lyrics）（如果可以，只需右键点击正在播放的曲目并在弹出菜单中选择“信息”）。将出现一组“信息”标签页，其中包含“歌词”标签。通过点击“艺术家”（Artist），你还可以显示对当前播放艺术家的信息的 Wikipedia 搜索结果（图 15-10），包括正在显示的 Wikipedia 页面的 URL。当然，这并不愚蠢。例如，当尝试英国乐队的歌曲《Sing》时，显示的是一个关于纽约 Sing 监狱的 Wikipedia 页面。我想，这非常有趣……

## 制作音频 CD

关于在电脑上编码和收听 MP3 以及 Ogg Vorbis 文件的这些讨论都很好，但毫无疑问，你会有想把歌曲放在普通的音频 CD 上，这样你可以在新泽西收费公路或文图拉高速公路上奔波时播放它们。坦率地说，这很容易做到，而且有几种方法。

## 使用 Rhythmbox 刻录音频 CD

对于 Rhythmbox 用户来说，最简单的方法是在 Rhythmbox 中完成所有操作。要做到这一点，首先创建一个包含你想刻录的歌曲的播放列表，然后点击**创建音频 CD**（Create Audio CD）按钮。会出现一个确认窗口，询问你是否想要创建你刚刚打算创建的 CD。你毫无疑问，所以点击“创建”（Create）按钮，你的曲目将以 WAV 格式创建。当该过程完成后，系统会提示你插入一张空白 CD，将其插入驱动器，点击**确定**（OK），刻录过程将开始。完成后，进度窗口将消失，你的新 CD 应该会从驱动器中弹出。简单。

## 使用 Serpentine 刻录音频 CD

另一种从你提取的 MP3 和 Ogg Vorbis 文件播放随处可用的音频 CD 的方法是 *Serpentine 音频 CD 刻录器*，这是一个与你的系统捆带的应用程序。要采用此路线，进入**应用程序**（Applications）菜单并选择**音频与视频**（Sound & Video > Serpentine Audio CD Creator）。当 Serpentine 出现时，点击**添加**（Add）按钮并导航到你想添加的歌曲，将歌曲添加到主窗格。你可以添加任何混合的歌曲以及任何混合的音频格式。你也可以通过**文件**（File）菜单并选择**打开播放列表**（Open Playlist）或**打开 Rhythmbox 播放列表**（Open Rhythmbox Playlist，取决于列表类型），添加已保存到播放列表的歌曲。如果你是一个喜欢拖放的人，也可以直接从 Nautilus 窗口或 Rhythmbox 内的播放列表将音频文件图标拖到 Serpentine 窗口的主窗格。

当你向 Serpentine 窗口添加内容时，CD 图像将显示你在磁盘上的可用空间（默认磁盘大小为**15-11**）。74 分钟是 650MB CD 的标准，所以如果你使用的是 700MB 的 CD，请点击**磁盘容量**（Disc Capacity）旁边的下拉菜单并进行相应选择，将设置更改为80 分钟。

当你添加所有想要刻录到 CD 的歌曲后，点击**写入光盘**（Write to Disc）按钮。Serpentine 将开始准备要刻录磁盘的曲目。当准备就绪，它会在新窗口中提示你向驱动器插入空白 CD，只需操作即可，一旦驱动器上的 LED 灯开始闪烁，点击**确定**（OK）。Serpentine 将开始刻录光盘，完成后，它会自动弹出光盘并在另一个窗口中通知你任务已完成。你就可以取出光盘，将其放入车里或任何你想播放的地方，享受结果。
