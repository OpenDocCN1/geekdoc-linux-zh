# jython

与 Java 平台无缝集成的 Python。Jython 是高级、动态、面向对象的语言 Python 的一种实现，它与 Java 平台无缝集成。Jython 的前身 JPython 经认证为 100% 纯 Java 开发。Jython 接近 Java，允许两种语言自由混合。它特别适用于嵌入式脚本、交互式实验和快速应用开发，并可以与 Java 包或正在运行的 Java 程序进行交互。源自 Debian 3.0r0 APT
