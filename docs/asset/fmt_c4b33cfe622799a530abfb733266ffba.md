
## giotto
`giotto` 是一个轻量级 Linux 系统，是一个附带了 Linux 操作系统必要部分的可启动软盘。`giotto` 从软盘启动（也可以安装在硬盘上），并完全在内存中运行。通常不需要硬盘。分发开发并不活跃。源自 LWN 列表 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## GIS
地理信息系统。有很多描述 GIS 的方法：它是一种用于获取、存储、检查、分析和显示地球表面所有类型地理引用数据的硬件/软件系统。GIS 将地图和数据与强大的分析相结合。基于网络的地理信息系统 (`Web-GIS`) 是一个框架，允许用户通过互联网获取、存储、检查、分析和显示地球表面所有类型的地理引用数据。`Web-GIS` 可用于多种用途，包括地图制作、数据分析和决策支持。`Web-GIS` 的一些应用包括城市规划、环境管理、应急响应和营销。`Web-GIS` 是理解数据点之间空间关系的强大工具。

## glade
`GTK+` 用户界面构建器是一个 RAD（快速应用开发）工具，用于为 `GTK+` 工具包快速、方便地开发用户界面。它还包含对生成重建界面所需的 C 语言源码的内置支持。如果你需要支持 Gnome 库的 Glade，请安装 `glade-package`。在 Glade 中设计的用户界面 存储在著名的 `XML` 格式中，便于与外部工具集成。已经有的工具可以将 `XML` 文件转换为 `C++`、`Perl` 和 `Python` 等其他语言。其他工具如 `libade` 则在运行时加载 `XML` 文件并创建界面。来自 Debian 3.0r4 APT http://www.tdlp.org/LDP/Linux-Dictionary/index.html

## glame
一个多功能的音频处理器。`GLAME` 为音频文件处理提供了一个强大且扩展的框架，类似于 `GIMP` 在图形领域提供的功能。目前，`GLAME` 具有一个图形化前端，用于设置过滤器和执行基础音频编辑任务。一个灵活的、基于 `Scheme` 的命令行编辑器，提供了处理脚本的低级访问。来自 Debian 3.0r4 APT http://www.tdlp.org/LDP/Linux-Dictionary/index.html

## glibff
