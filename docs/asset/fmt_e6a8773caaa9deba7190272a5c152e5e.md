# 设置脚注位置和间距

默认情况下，Word 将脚注放在页面底部（通过“脚注区域的选项”对话框中的“将注释置于页面底部”选项）。如果你希望脚注紧接在文本下方，可以点击“将注释置于其下方”单选按钮。此选项对文本较少的页面有显著影响。在内容饱满的页面上，这两个选项产生的结果相似。

WordPerfect 在脚注条目之间留了一定的空间，有助于视觉上的分离。这种效果类似于文本段落之间的双倍行距。你可以使用“脚注之间的间距”区域的数值调节框增大或缩小间距。

要设置正文与脚注之间分隔线周围的间距，点击“分隔符”并在生成的对话框中调整此选项。我稍后会讨论分隔线选项。

你可以通过点击“注中”并在样式编辑器对话框中设置相应选项来调整脚注内部行的间距。
