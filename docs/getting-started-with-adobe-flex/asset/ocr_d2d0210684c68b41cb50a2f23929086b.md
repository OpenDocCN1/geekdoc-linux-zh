# **Chapter 2**

+   1. Flex applications are, by nature, Flash applications. That means upon building the Flex application the output produced is .swf (swiff) format and that is executed by Flash Player.
+   2. Flash player is not very good at displaying HTML contents. Diaplauing capabilities of Flash Player are limited to the boundaries of the player’s scope Within a web page. Since Flex applications are run on Flash Player, for the obvious reason, Flex applications deployed on web server are not good at displaying HTML content either. On the other hand AIR ( Adobe Integrated Runtime ) applications support AIR player wherein a full built-in browser displays HTML content nicely. Moreover, unlike HTML files, there is a delay in loading .swf files.
+   3. Since Flex applications produce .swf files those are run on top of Flash Player, Flex provides cross platform support that is not dependent on web browser’s environment. Most of the today’s web browsers provide seamless support for Flash Player plug-in.
