# ### 5.4.3 AdvancedDataGrid control

**AdvancedDataGrid** is a new feature in Adobe Flex 3 and is only offered with Flex Builder Professional. The **AdvancedDataGrid** control has built-in support for aggregation and formatting. It can also be used to create summary rows. We can create an **AdvancedDataGrid** control in a Flex Application by using the `<mx:AdvancedDataGrid />` MXML Tag. An **AdvancedDataGrid** takes a special data object for its **DataProvider**.
