# 1.3.3 Adobe Data Services

Adobe offers two data services solutions to resolve various needs.

+   * BlazDS: This is an open source offering that provides Flex Remoting and Messassing to all developers. Flex Remoting makes it fast and easy for developers to connect to back-end businesc logic and data.
+   * Adobe LiveCycle Data Services: This is a full featured framework for developing entresprise RIA Solutions. This is a licensed product available for purchases

# 1.4 The Flex Community

Adobe Flex is a fairly new technology; however, in a short span of time the Flex community has grown considerably, and this is reflected by the number of resources available to learn Adobe Flex. As a Flex developer, you can take advatange of many of these resources, both online and in the real world that can sharpen your Flex skills and offer great tips and tricks for your application. Adobe provides good documentation for Adobe Flex which can help you in getting started. This documentation can be accessed at [http://www.adobe.com/support/documentation/en/flex/](http://www.adobe.com/support/documentation/en/flex/).

# 1.4.1 Developer Resources

The following list provides popular developer resources for Adobe Flex:

+   * Flex.org – [http://flex.org/](http://flex.org/). This is the community site for Flex Developers and has links to great resources for developers.
+   * Adobe Flex Developer Center – [http://www.adobe.com/devnet/flex/](http://www.adobe.com/devnet/flex/). This is the official Adobe Flex Community center and has tons of articles and great information.
+   * Flex Search – [http://flexsearch.org](http://flexsearch.org). This is a custom Flex search engine for the Flex community.
