You Will not Need Expensive Computers

 

Don't buy the latest whiz-bang, slim, light, ultrabook for $1000 or more. There are much better deals that may not be as slim or light or fashionable, but will save you as much as $1000. Installing a free operating system like Linux will also save money compared to upgrading to the newest version of other operating systems. Linux will read Microsoft Office documents so you will be able to keep all of those files. However, many used or new computers already have the latest version of Windows installed. So you may keep Windows if you want to and install Linux by creating a dual boot system.

The four basic parts of computers that determine their performance are the CPU, memory, hard drive and the bus. The bus/chipset, which is part of the motherboard and cannot be replaced, connects the CPU, memory and hard drive, so the bus/chipset speed could be a limiting factor. Upgrading the CPU, memory and hard drive will have little effect if the bus speed is slow. A basic computer block diagram is shown on the next page.

 

Computer Block Diagram

Note that the I/O block is the Input/Output subsystem or chip. The BIOS or UEFI contains the computer initial boot code. Memory is short term volatile storage and the hard drive is long term permanent storage. The thick vertical line is a classic symbol that represents the bus/chipset. More information may be found in the Definitions section at the end of this book.

Mechanical hard drives are significantly slower than solid state drives (SSDs.) Many computers today, like the MacBook Air and other ultrabooks, have solid state drives. The one upgrade that should always result in faster performance is the replacement of a mechanical hard drive with a SSD. Unless you are playing some intense games, you will not need the fastest motherboard and processor or 8 Gb of memory. Most users will get by fine with a core i3 processor, 2 Gb of memory and a 128 Gb solid state drive. Linux does not require as much memory as other operating systems so most users will not need more than 2 Gb of memory.

 

Managing Your Computers

 

Some operating systems or application software programs are continually accessing the computer hard drive. If your hard drive light is always on, then this is the case. It will shorten the life of your hard drive, even if it is a solid state drive. You should try to find what is causing this problem or install another operating system on your computer. A thrashing hard drive could be an indication that your computer does not have enough memory, so installing more memory could solve the problem. The hard drive light on my Linux computers are rarely on, but they do blink occasionally. Hard drives will last much longer with Linux thus saving you time and money. Do a web search for "thrashing hard drive" and you will find many examples.

Does your laptop have a user replaceable battery and hard drive? If not, then it could cost as much as $300 to replace the battery and maybe the same or more to replace the hard drive. There are many laptops available which have batteries that may be replaced for as little as $10 and hard drives that could be replaced for under $100. These are important considerations when buying any laptop if you want to save money on maintenance.

You should power off your computers if you are not using them. This is especially true for laptops, regardless of what operating system is installed, because laptops may overheat very easily. There just is not enough space or cooling fan power in some laptops to adequately cool them. Leaving your computer running 24/7 accomplishes nothing other than shortening the life of the computer. It will last longer if you power it off when you are not using it. Using screensavers may also cause your laptop to overheat and it is an unnecessary use of electricity.

Lithium Ion batteries that are used in practically all personal electronic devices today will have a much longer useful life if they are continually charged and their life will be shortened if they are discharged below 40%. Ignore any advice or instructions to fully discharge Lithium Ion batteries. That is wrong and it will shorten the life of your batteries. Do not discharge your Lithium Ion batteries below 40%.

 

About Linux

 

The development of Linux began in 1969 when AT&T Bell Labs created the Unix operating system. Linux, which was created in 1991 by Linus Torvalds, is based on Unix. Unix was designed to operate on practically any computer and has the best architecture of any modern operating system. For more detailed information about Unix and Linux, try Wikipedia or The Linux Foundation. This book is just a quick introduction to Linux and will not go into a lot of the fine details about the operating system.

Linux has a modern desktop and it has modern application software that is just as functional and just as easy to use as any other software. If fact, modern Linux is much easier to use than some other popular operating systems. Linux has word processing, spreadsheet, database, and slide show software and it is all free to use, free to customize, and free to update. The only downsides are that Linux does not come installed on many computers and it is not well documented. So get one of your geek friends to install it for you if you don't want to do it yourself. She will gladly do it for a smile, a cup of coffee, a piece of cake or a glass of wine. While she is installing Linux, ask her to check the hard drive and battery and replace them if necessary.

Linux is in more devices than any other operating system. Linux powers everything from watches to the International Space Station. It's in your car, your tv, your toaster, your radio, and maybe even in your refrigerator. Linux powers 98% of the worlds supercomputers, it is in Navy Submarines, Air Force Drones, it is in every Android phone and tablet, it powers servers on the internet, it is used by Google, HP, IBM, Intel, Oracle, the New York Stock Exchange and numerous other organizations. Linux is used by more people and more organizations every year and it represents the future of computing.

More about Linux Distributions

 

There are more than 600 flavors of Linux called distributions. Each Linux distribution has a different purpose and they have different functionality. The most popular Linux distributions are Linux Mint and Ubuntu. There are many Ubuntu based distributions. Some of them are Ubuntu Unity, Ubuntu Gnome, Lubuntu, Xubuntu, elementaryOS, LXLE and Peppermint.

Each distribution has versions or releases that are made available to the public periodically. Many releases are identified by the release date, like 14.04 which would be the April, 2014 release. Some releases just have a number like Linux Mint 17 or Peppermint 5. Finally some releases are LTS, Long Term Support, which may be supported for three or five years. The best choice for any Linux distribution would be the LTS release which is supported for a longer time than other periodic releases.

The easiest Linux distributions to install and use, in my opinion, are Linux Mint and elementary OS followed by, Ubuntu Unity, Lubuntu, LXLE and Peppermint. LXLE and Linux Mint have a Windows like desktop and menu system and Ubuntu Unity has a Mac like desktop and menu system. Lubuntu, LXLE and Peppermint, because they are lightweight distributions, will run at blazing speed on older computers, and they both have a simple menu system which is similar to Windows.

Linux Mint and Ubuntu are designed to run on relatively modern computers with faster processors. They require at least a Core 2 Duo processor, about 1 Gb of ram, and 8 Gb of hard drive space. However, I would recommend using Ubuntu Unity and Linux Mint on at least a core i3 computer for better performance. Lighter weight distributions like Lubuntu and Peppermint will run on relatively older processors and may only require 512 mb of memory. However, 1 Gb of memory is recommended. The lighter weight distributions will run exceptionally fast on computers that formerly had Windows XP installed. The lighter weight distros like Lubuntu and Peppermint are highly customizable where Mint and Ubuntu are not as easily customized.

GNU/Linux

 

One of the best features of Linux distributions is that they are free open source GNU/Linux software. This means that the software may be freely used, copied, modified and redistributed. Open source software is developed, maintained and distributed by a worldwide community of people. The software is owned by the community and the development process is transparent. This makes for more stable and reliable code that is practically malware free, easy to install and easy to use.

GNU is a set of Unix like programs which provide basic functionality for the Linux system. Linux would not exist without the GNU tools and applications. This is why some people refer to the GNU/Linux operating system as opposed to just Linux. GNU is an acronym for GNU's Not Unix. GNU is a FOSS (Free Open Source Software) implementation of basic Unix programs.

GNU/Linux has been under development for over twenty years and is a very mature operating system. The Linux kernel was designed by Linus Torvalds in 1991. The GNU system was designed by Richard Stallman. GNU/Linux is now maintained by The Free Software Foundation. The design of GNU/Linux is based on Unix which was created by AT&T Bell Labs starting in 1969. So the heritage of GNU/Linux spans more than forty years. Unix and GNU/Linux have a well defined file system and a simple modular software design which translates to smaller, simpler and faster software. We are all the beneficiaries of this elegant design concept.

The popular Linux logo, Tux the penguin, was created by Larry Ewing and it may be found on numerous stickers, decals, pins, tee shirts and toys.
