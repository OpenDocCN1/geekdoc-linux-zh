Next, dpkg --search file (or -S), finds any packages containing the file or path passed in the argument. For example, to find the package containing /bin/date:

```
$ dpkg -S /bin/date
coreutils: /bin/date
```

The dpkg --status package (or -s) command displays the headers of an installed package. For example, to search for the headers for the coreutils package:

```
$ dpkg -s coreutils
Package: coreutils
Essential: yes
Status: install ok installed
```
