		}
	} else {

		print field[1] " has the same UID as "name : UID = ""
		dup = 1 # set duplicate flag
	if (dup) # same as as: if (dup == 0)

## Error Messages

The following examples show some of the more common causes of gawk's infamous error messages (and nonmessages). The examples are run under bash. (When using gawk with other shells, the error message you get may be different).

The first example leaves the single quotation marks off the command line, so the shell interprets $3 and $1 as shell variables. Another problem is that there are no single quotation marks, the shell passes gawk four arguments instead of two:

```bash
$ awk {print $3, $1} cars
gawk: cmd. line:2: (END OF FILE)
gawk: cmd. line:2: parse error
```

The next command line includes a typo (prinnt) that awk catches. Instead of issuing an error message, gawk simply does not do anything useful:

```bash
$ awk '$$3 >= 83 {print $1}' cars
```

The next example has no braces around the action:

```bash
$ gawk '/chevy/ print $3, $1' cars
gawk: cmd. line:1: /chevy/ print $3, $1
gawk: cmd. line:1: ^ parse error
```

There is no problem with the next example; gawk just did what you asked it to (none of the lines in the file contained a z).

```bash
$ gawk '/$z/' cars
```

The following program contains a useless action (the print command is missing):

```bash
$ gawk '{$3}' cars
gawk: illegal statement 56250
record number 1
```

The next example shows an improper action which generates no error message:

```bash
$ gawk "$3" made by "$1" cars
```

The heading in the following example is not displayed, because there is no backslash after the print command in the BEGIN block. The backslash is needed to quote the following newline so that the line can be continued. Without it, gawk sees two separate statements; the second does nothing:

```bash
$ cat print_cars
BEGIN {
Model Year Price
/chevy/ {printf("%s\t%d\t%d\n", $2, $3, $5}
```

```text
nova 79 3000
nova 80 3500
impala 65 1550
```

You must use double quotation marks, not single ones, to delimit strings.

```bash
$ cat print_cars2
BEGIN {FS="\t"}
~ /$/ {print $3, $1, "$" $5}
```

```bash
$ gawk -F="\t" cars
```
