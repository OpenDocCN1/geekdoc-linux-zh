+   - b Block special file

- l Symbolic link

-links± The file evaluated meets this criterion if it has the number of links specified by
±n.

-userame The file evaluated meets this criterion if it belongs to the user with the speci-
ied login name, name. You can use a numeric ID in place of name.

-groupname The file evaluated meets this criterion if it belongs to the group with the spec-
ified group name, name. You can use a numeric ID in place of name.

-perm [±] The file evaluated meets this criterion if it has the access permissions given by
mode. If mode is preceded by a minus sign (-), the file access permissions must include
all the bits in mode. If mode is preceded by a plus sign (+), the file access permissions
must include at least one of the bits in mode. If no plus or minus sign precedes mode,
the mode of the file must exactly match mode. Use symbolic or octal represen-
tation mode (see chmod on page 1103).

-inum The file evaluated meets this criterion if its inode number is n.

-size±n c[k] The file evaluated meets this criterion if it is the size specified by ±n, measured
in 512-byte blocks. Follow with n with the letter c to measure files in characters or k to
measure in kilobytes.

-atime±n The file evaluated meets this criterion if it was last accessed the number of
days specified by ±n. When you use this option, find changes the access times of
directories it searches.

-mtime±n The file evaluated meets this criterion if it was last modified the number of
days specified by ±n.

-newer filename The file evaluated meets this criterion if it was modified more recently than
filename.
