Controls the size of your history list. As a rule of thumb, its value should be kept around 100. Refer to “History” on page 686.

HOME THE environment variable is part of the shell's environment when it starts and is used to initialize the home local variable HOME has the value of the pathname of the home directory of the user. The cd builtin refers to this-variable, as the filename substitution of ~. Refer to “~ Tilde Expansion” on page 609.

owd The shell keeps your previous (old) working directory in this variable. This is equivalent to -- in bash and zsh.

path and PATH THE environment variable is part of the shell's environment when it is started. The path local variable is an array set by the shell from the value of PATH (or to a default value if PATH is not set). The directories in the path array are searched for executable commands. If path is empty or unset, you can execute commands only by giving them full pathnames. You can set your path variable directly with a command such as the following:

```
tcsh $ set path = ( /usr/bin /bin /usr/local/bin /usr/bin/X11 ~/bin )
```

Refer to “PATH: Where the Shell Looks for Programs” on page 577.

prompt Holds the primary prompt, similar to the variable (page 579); if it is not set, the prompt is >, or # for root (Superuser). The shell expands an exclamation point in the prompt string to the current event number. (Just as the shell replaces a variable in a shell script with its value, the shell replaces an exclamation point in the prompt string with the current number.) The following is a typical line from a .tcshrc file that sets the value of prompt:

```
set prompt = '! $ '
```
