Users can review their usage and limits with the quota command. Superuser can
use quota to obtain information about any user.

First, you must decide which filesystems to limit and how to allocate space
among users. Typically, only filesystems that contain users' home directories, as
as/home, are limited. Use edquota to set the quotas, and then use
quota to start the quota system. You will probably want to use the quota com-
mand run command script so that the quota system will be en-
abled when you bring up the system (page 964). Unmounting a filesystem
automatically disables the quota system for that.

# Getting Help

Your distribution comes with extensive documentation (page 42). Red Hat main-
tains a page that points toward many useful support documents:
www.redhat.com/apps/support. You can also find help on the System Administra-
t's Guild site (www.sage.org). In addition, the Internet is a rich source of informa-
ton on managing a GNU/Linux system, refer to Appendix B and to the author's
home page (www.sobell.com) for pointers to many useful sites.

You do not need to act as a Red Hat system administrator in isolation; the
community of GNU/Linux/Red Hat experts is willing to assist you in getting the
out of your system, although you will get better help if you have already
tried to solve a problem by reading the available documentation. If you
are unable to solve a problem through the documentation, a well-thought-out
question to the appropriate newsgroup, as comp.os.linux.misc, or mailing list
 often provide useful information. Be sure you describe the problem and iden-
tify your system carefully. Include information about your version of Red Hat and
any software packages and hardware that you relate to the problem. The
newswire comp.os.linux.answers contains postings of solutions to common
problems and periodic postings of the most up-to-date versions of the FAQ and
HOW documents.

Red Hat provides many types and levels of support for a fee. Refer to
www.redhat.com/apps/support/programs.html.
