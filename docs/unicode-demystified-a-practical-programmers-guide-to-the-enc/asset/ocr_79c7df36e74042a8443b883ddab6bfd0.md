# Editing the Command Line

The tesh command line editing feature is similar to that of bash (and zsh, you will see in the next chapter). You can use GNU emacs-style commands or vi-style commands. The default is emacs, but you can change this easily with the bindkey builtin. If you are using emacs-style bindings, you can change to the vi commands with bindkey-v. Similarly, if you are using vi-style bindings, you can change to emacs with bindkey-e. The ARROW keys are bound to the motion commands, so you can move back and forth (up and down) through your history list as well as left and right in the current command.

The bindkey builtin, without an argument, displays the current mappings-tween editor commands and the key sequences you can enter at the keyboard:

```
tesh $ bindkey | less
```

The less utility is handy because it lets you move and search back and forth through this long list as you read. If you are familiar with emacs or vi, you will recognize some of the commands listed by bindkey.

# Correcting Spelling

You can have tesh attempt to do spelling correction on command names, filenames, and variables (but only using emacs-style key bindings). Spelling correction can take place only at two times: before and after you press RETURN.

# Before You Press RETURN

In order for tesh to correct a word or line before you press RETURN, for this purpose you must give it an indication that what you want to do. The two functions for this are spellword and spell-line. Each of these functions is bound to a key sequence: META- and META-s, respectively. To correct the spelling of the word to the left of the cursor, enter META-s. Entering META-$s invokes the spell-line function, which attempts to correct all words on a command line. The following command lines illustrate the use of these functions:

+   2. On many keyboards the ALT key replaces the META key: Use ALTs in place of META-s and ALFs for META-s. If these substitutions do not work, try ESCAPE followed by s in place of META-s and ESCAPE in place of META-s. See "Moving the Cursor by Words" on page 478 for more information on the META key.
