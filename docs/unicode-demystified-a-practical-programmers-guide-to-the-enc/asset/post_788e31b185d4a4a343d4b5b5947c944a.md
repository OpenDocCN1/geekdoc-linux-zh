# Tear-Awl Bars

One handy feature of Nautilus is the ability to reposition, or tear away, the toolbar or the location bar. You can move each control bar onto the root window or position it at the top or bottom of the Nautilus window. You can also move the toolbar so that it is vertical on either side of the Nautilus window. Drag the striped vertical bar (marked Toolbar Handles in Figure 7-6 on page 217) to the left or end of the control bars, and you will drag the bar. To position the toolbar on one of the vertical sides of the window, drag the toolbar handle toward the middle of the side you want it, and it snaps into place. Once the toolbar is vertical, you can move it to the root window and it will remain vertical. Figure 7-7 shows the toolbar at the bottom of the Nautilus window. To return a bar to the window, drag it back and it snaps into place.

# Properties

You can view information about a file, such as ownership, permission, size, and so on, by right clicking any filename or icon (except icons on a panel; see page 247 (for those)) and selecting Properties from the drop-down menu. The Properties window initially displays basic information; click the tabs at the top of the window to see additional information. Different types of files display different sets of tabs, depending on what is appropriate for the file (context menu). You can modify settings in this window only if you have permission to do so.

# Basic

The Basic tab displays information about the file and enables you to select a custom icon for the file or change its name. To change the name of the file, make your changes in the text box and press `RETURN`.

# Emblems

The Emblems tab (Figure 7-11, left) allows you to add or remove emblems associated with the file by placing/removing a check mark next to an emblem in the Emblems tab.

# Permissions

The Permissions tab (Figure 7-11, right) allows you to change file permissions (page 118). When the Read button in the Owner row (User elsewhere, see the tip “chmod: o for Other, u for Owner” on page 120) has a check mark in, the owner has permission to read from the file. When you click all the buttons in the Owner row so that they contain check marks, the owner has read, write, and execute permission. The owner of a file can change the group the file is associated with to any other group the owner is associated with. When you run as Superuser, you can change the name of the user who owns the file and the group associated with the file. Directory permissions work as explained on page 121.

# GNOME Utilities

GNOME comes with many utilities that make your work on the desktop easier and more productive. This section covers several of the tools that are integral to the use of GNOME.

# Search Tool

Display the GNOME Search tool (gnome-search-tool) by selecting GNOME menu: Search for Files (Figure 7-13). This tool is a front end for the find, grep, and locate utilities. The Simple tab is generally associated with locate; the Advanced tab with find. You can display the command either query generates by selecting from the menu bar Search: Show Command after you have filled out the text boxes.

# Simple Search

Enter a filename in the Find files named text box, Enter an absolute pathname of a folder in the Starting in folder text box, and click Find. A string with no wildcard characters match string anywhere in the absolute pathname of a file. A string that includes a wildcard character must match the absolute pathname of a file.

Although locate is usually executed, /usr/bin/locate is a link to socalled secure version of locate. Because it searches a prebuilt, compressed database of filenames, the locate utility performs more quickly than find. By default the updateddb command in

# Advanced Search

A minimal Advanced Search command requires the name of a directory that you want to start the search from (the root of the search) and a filename to search for. Figure 7-14 shows the Start in text box as /usr/; the Advanced Search tool enters your home directory by default. Change the Start in folder as you like, and enter a filename in the Finds file named text box (you can use wildcard characters). You can click Find at this point, and the results of your search will be appended to any existing Search Results window, which opens automatically if it is not already open.

You can add search criteria to a basic search by clicking the pop-up menu at Add Rule, selecting a criterion, and clicking Add. A new criterion line appears. Fill in text boxes on the new criterion line as appropriate (just you entered the name of the file to search for in the File name text box), and, necessary, enable the checkbox so that a check mark appears. Turn off a criterion line by removing the Enable check mark; remove a criterion by clicking the associated Remove button. Each of the criteria you specify is ANDed with the next so that a file must meet criteria to appear in the Search Results window. Refer to find on page 1165 for more information on search criteria and how find works.
