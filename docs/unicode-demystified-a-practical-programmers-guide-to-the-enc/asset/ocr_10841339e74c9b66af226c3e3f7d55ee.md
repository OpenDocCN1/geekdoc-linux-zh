# aspell Options and Leading Hyphens

The you specify options differs, depending on whether you are specifying them on the command
line or in the ASPELL_CONF variable or a configuration file.

On the command line: Prefix long options with two hyphens (for example, --ignore-case or
--ignore-case). Short options are always prefixed with a single hyphen and are allowed only on
the command line.

In ASPELL_CONF or a configuration file: Drop the leading hyphens (for example, ignore-case or
ignore-case).
