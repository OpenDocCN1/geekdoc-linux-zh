# emacs and the X Window System

With Version 19, GNU emacs fully embraced the X Window System environment and can manage multiple X-level windows (called *frames* to avoid confusion with emacs windows). Each frame can contain multiple emacs windows, as well as a menubar. See Figure 11-8.

# Start emacs on X

Start the graphical version of emacs under a GUI by giving the command emacs from a terminal emuator or by selecting *Run Command* from a menu and entering emacs.
The graphical version of emacs is not emacs (www.emacs.org). The emacs program is not a GNU project.

The usual mouse-oriented actions, including cut and paste with other X clients, are supported. Besides selecting a frame, the mouse can select, split, or delete emacs windows within a frame. Each window can have its own scrollbar.
