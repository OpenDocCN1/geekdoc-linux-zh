# URLs (Web Addresses)

Web addresses, or URLs, have an implicit http:// prefix unless ftp:// or https://: is shown. You do not normally need to specify a prefix when the prefix is http://, but you must use a prefix from a browser when you specify an FTP or secure HTTP site. The result is that you can specify a URL in a browser exactly as this book specifies it.

As an example, the following sentence appears later in this chapter: “Red Hat has many mailing lists that you can subscribe to (https://listman.redhat.com) and mailing list archives that you can review (www.redhat.com/mailing-lists).” You must enter the https:// prefix before the name of the Web page in the first URL but there is no need to enter a prefix with the second URL.
