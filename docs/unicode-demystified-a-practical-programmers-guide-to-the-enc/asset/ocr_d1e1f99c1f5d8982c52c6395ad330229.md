# Informing Users

One of your primary responsibilities as the system administrator is communicating with your system users. You need to make announcements, such as when the system will be down for maintenance, when a class on some new software will be held, and how users can access the new system printer. You can even start to fill the role of a small local newspaper, letting users know about new employees, RIFs, births, the company picnic, and so on.

Different communications have different priorities. Information about the company picnic in two months is not as sensitive as the fact that you are bringing the system down in 5 minutes. To meet these differing needs GNU/Linux provides different ways of communicating. The most common methods are described and contrasted in the following list. All these methods are generally available to everyone, except for the message of the day, which is typically reserved for Superuser.

write Use write to communicate with any user who is logged in your machine. You might use it to ask a user to stop running a program that is bogging down your system. The user might reply that he will be done in 3 minutes. Users can also use write to ask the system administrator to mount a tape or restore a file.

talk The talk utility performs the same function as write but is more advanced. Although talk uses a character-based interface, it has a graphical appearance, showing what each user is typing as it is being typed. Unlike write, you can use talk to have a discussion with someone on another machine on the network.
