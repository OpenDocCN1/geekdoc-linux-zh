You can use time commands when you are concerned about system performance. If many of your commands show a lot of page faults and swaps, your system is prob-memory starve, and you should consider adding more memory to the system. You can use the information that time reports to compare performances of various system configurations and program algorithms.

period Set this variable to control how often, in minutes, the shell executes the special peri-odic aliases (page 689).

user The shell sets this variable to your login name.

version The shell sets this variable to contain detailed information about the version of tsh that you are using. See the tcsh variable (page 709) for less detail.

watch Set this to an array of user and terminal pairs to watch for logins and logouts. The word any means any user or any terminal, (so any) monitors all logins and lo-gouts on all terminals, and (scott ty1 any user Suser) watches for scott on tty1, any user who accesses the system console, and any logins and logouts that will your account (presumably to catch intruders). By default, logins and logouts are checked every 10 minutes, but you can change this by beginning the array with a numeric value giving the number of minutes between checks. If you set watch to (1 console), logins and logouts by any user will be checked once a minute. Reports are displayed only just before a new shell prompt is issued. Also, the log builtin forces an immediate check whenever it is executed. You can control the for-mat of the watch messages; see who.
