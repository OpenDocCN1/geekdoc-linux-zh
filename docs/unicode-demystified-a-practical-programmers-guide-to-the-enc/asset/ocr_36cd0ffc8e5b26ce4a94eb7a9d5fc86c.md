# menu

A list from which the user may select an operation to be performed. This often done with a mouse or other pointing device under a GUI but may also be controlled from the keyboard. Very convenient for beginners, menus show how commands are available and make experimenting with a new program easy, of reducing the need for user documentation. Experienced users, however, usally prefer keyboard commands, especially for frequently used operations, because they are faster to use.

# merge

To combine two ordered lists so that the resulting list is still in order. The sort utility can merge files.

# META key

On the keyboard, a key that is labeled META or ALT. Use this key as you would SHIFT key. While holding it, press another. The emacs editor makes extensive use of the META key.

# metacharacter

A character that has a special meaning to the shell or another program in a particular context. Metacharacters are used in the ambiguous file references recognized by the shell and in the regular expressions recognized by several utilities. You must quote a metacharacter if you want to use it without invoking its special meaning. See regular character (page 1489) and special character (page 1493).

# metadata

Data about data. In data processing metadata is definitional data that provides information about documentation of other data managed within an application or environment.

For example, metadata can document data about data elements and attributes (name, fields, columns, and so on), or data structures (page 1463) (length, fields, and so on), and data itself (where it is located, how it is associated, who owns it, and so on). Metadata can include descriptive information about the context, quality and condition, or characteristics of the data.

# metropolitan area network

See MAN on page 1478.

# MIME

Multipurpose Internet Mail Extension. Originally used to describe how specific types of files that were attached to e-mail were to be handled. Today MIME types describe how a file is to be opened or worked with, based on its filename extension.
