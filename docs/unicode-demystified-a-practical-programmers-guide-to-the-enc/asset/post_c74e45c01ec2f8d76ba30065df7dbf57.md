The function starts by getting a list of subject directories, using the ls command. The call to ls is preceded by the reserved word command to ensure that if an alias or function is named ls, it will not be used. Next, the select structure (page 770) presents the user with a list of subjects (the directories found by ls) and chooses the directory name in Subject. Finally the function writes the name of the subject directory to standard output. The main program uses command substitution to assign this value to the variable subject=$(choose_subj).

Be prepared for the cd command! The directory may be unsearchable, or conceivably another user may have removed the directory in between ls and cd command.
The scramble function presents a number of difficulties. In this solution it uses an array variable (questions) to hold the names of the questions and scrambles the various entries in an array using the RANDOM variable

```bash
function scramble
{
  typeset -i index quescount
  set -A questions=${questions}
  quescount=${#questions} # Number of elements
  (index=quescount-1)
  while [[ $index > 0 ]]; do
    ((target=RANDOM % index))
    exchange $target $index
    ((index -=1))
  done
}
```

This function initializes the array variable questions to the list of filenames (questions) in the working directory. The variable quescount is set to the number of such files. Then the following algorithm is used: Let the variable index count from quescount - 1 (the index of the last entry in the array variable). For each value of index, the function chooses a random value between 0 and index, inclusive. The command

```bash
((target=RANDOM % index))
```

produces a random value between 0 and index - 1 by taking the remainder (the %) operator when $RANDOM is divided by index. The function then changes elements of questions at positions target and index. It is convenient to do this in another function, named exchange:

```bash
function exchange
{
  temp_value=${questions[1]}
  questions[1]=${questions[2]}
  questions[2]=${temp_value}
}
```

Function ask also uses the select structure. This function named in its argument and use the contents of that file to present the question, accept the answer, and determine whether the answer is correct; see the code that follows.

This function uses descriptor 3 to read successive lines from the question file, whose name was passed as an argument to the function. It reads the question into the variable ques by initializing it to the null string, and then successively appending the next choice. It then sets PS3 to the value of ques and uses the select structure, which prompts the user with ques. The select structure places the user's answer in answer, and the function checks it against the correct answer from file. If the user does not make a valid choice, select continues to issue the prompt and wait for a response.

The construction of the choices variable is done with an eye to avoiding a potential problem. Suppose that one of the answers has some whitespace in it. Then it might appear as two or more arguments in choices. To avoid this problem, make sure that choices is an array. Be careful to remove the leading colon in choices.
