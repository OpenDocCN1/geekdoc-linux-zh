Next, Alex wants to bring some files from the remote system back to the local system. He makes the working directory on the remote system (cd ..), makes sure that he is in the directory that he wants to be in (pwd), and lists the files in the working directory (ls). As a matter of fact, Alex makes that ftp is set up for a binary transfer (bin) and uses mget to transfer all the files whose end in .rm from the working directory

ftp cd ..
