# Keyword Variables

The Z Shell automatically inherits, and defines a number of variables, including most of the keyword shell variables from bash (page 576), when you start a session. Some have values that are set and changed during your session. Others are variables that you can assign values to and that have special meaning for the shell. Some are readonly variables that you cannot assign values to. See Table 15-5.

| Keyword Variables | table 15-5 |
| --- | --- |
| $# | The number of command line arguments (page 586). |
| $* | All the command line arguments as a single argument (page 586). |
| @@ | All the command line arguments as individual arguments (page 586). |
| $_ | All the last of the previous simple command in the current instance of the shell. This is similar but not identical to \
zsh % cat file1 file2 file3 > all123files\nzsh % echo _\nfile3\n you had issued these commands using !$ from bash, tsh, or zsh instead of $_ from zsh, the output would have been all123files. The Z Shell underscore specifically refers to arguments, not arbitrary symbols on the command line. Use $! to refer to the last symbol on the command line. |
