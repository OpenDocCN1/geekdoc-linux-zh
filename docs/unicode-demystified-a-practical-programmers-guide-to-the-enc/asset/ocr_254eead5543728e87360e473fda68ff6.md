# tar: Packs and Unpacks Files

The tar utility performs many functions. Its name is short for tape archive, as its original function was to create and read archive tapes. Today it is used both to create a single file (called a tar file) from multiple files or directories containing any level of subdirectories and files to extract from a tar file.

In the following example first shows the existence and sizes of the files g, b, and d. Next, tar uses -c (create), -v (verbose), and -f (write to or read from a file) options³ to create an archive named all.tar from these files. Each line of the output from tar starts starts with a letter to indicate that it is appending to the archive. This letter is followed by the name of the file.

The tar utility does overhead when it creates the archive. The next command shows that the archive file, all.tar, is about 9,700 bytes, whereas the sum of the three files is about 6,000 bytes. This overhead is more appreciable on smaller files, as the ones in this example:

```
$ -ls g b d
-rw-r-- 1 jenny jenny 1302 Aug 20 14:16 g
-rw-r-- 1 jenny other 1178 Aug 20 14:16 b
-rw-r-- 1 jenny jenny 3783 Aug 20 14:17 d
$ tar -cvf all.tar b d
a
b
d
$ls -l 1 all.tar
-rw-r-- 1 jenny jenny 9728 Aug 20 14:17 all.tar
$ tar -tvf all.tar
-rw-r-- jenny/jenny 1302 2003-08-20 14:16 2003 g
-rw-r-- jenny/other 1178 2003-08-20 14:16 2003 b
-rw-r-- jenny/jenny 3783 2003-08-20 14:17 2003 d
```

The final command in the preceding example uses the -t option to display the contents of the archive. Use -x in place of -t to extract files from a tar archive. Omit the -v option if you want tar to do its work silently.

You can use gzip to compress files and make them easier to store and handle. Many files you download from the Internet are in one of these formats. Files that have been processed by tar and compressed by gzip frequently have a file extension of .tgz or .tar.gz. Those processed by tar and compress use .tar.Z.
