# The TC Shell

The TC Shell (tesh) performs the same function as the Bourne Again Shell, the Z Shell, and other shells: It provides an interface between you and the GNU/Linux operating system. The TC Shell is an interactive command interpreter as well as a high-level programming language. Although you use only one shell at any given time, you should be able to switch back and forth comfortably between them the need arises (you may want to run different shells in different windows). Because many of the concepts covered in Chapters 12 and 13 apply to tesh as well as bash and zsh, those chapters provide a good background for this chapter, as well as for use in general. This chapter highlights features of tesh that differ from those of bash, or are absent from bash altogether, or are traditional tesh features that have not taken a strong hold in bash.

The TC Shell is an expanded version of the C Shell (ksh), which originated on Berkeley UNIX and is now included with System V UNIX. The T in TC Shell comes from the names of TENEX and TOPS-2 operating systems, which inspired the command completion (and other) features in the TC Shell. The TC Shell comes with Red Hat Linux. A number of features not found in csh, including file and user name completion, command line editing, and spelling correction. As with csh, you can customize shell to make it more tolerant of mistakes and easier to use.
