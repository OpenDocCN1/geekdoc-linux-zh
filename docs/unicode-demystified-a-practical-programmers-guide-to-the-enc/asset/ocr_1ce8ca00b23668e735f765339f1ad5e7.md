Options for sources are files, nis, and dns. To construct DNS when your request for a host is not resolved by local files, add dns to the hosts line as follows:

hosts: files dns

The next line contains another example of how the hosts database can be configured:

hosts: dns nis [NOTFOUND=return] files

The square brackets [] specify criteria that modify how the search is performed. This example first the dns source. If dns has the answer, no further searching takes place. If dns does not provide an answer, nis is checked. When nis returns NOTFOUND (indicating that it could not find an answer), the process stops ([NOTFOUND=return]), and no answer is returned. Only when nis does not return an answer and does not return NOTFOUND are the local files (/etc/hosts) consulted. In other words, NIS provides an authoritative answer; when NIS is not available the system consult local files. Refer to the nsswitch.conf page, the NIS-HOWTO, and the DNS-HOWTO for more information.
