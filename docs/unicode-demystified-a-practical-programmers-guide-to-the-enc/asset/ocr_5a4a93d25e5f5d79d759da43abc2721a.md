variable expansion. You specify these flags by enclosing within parentheses immediately following the opening brace. The Z Shell includes support for the flags listed in Table 15-8. For other flags, see the zshepn man page.

| Flag | table 15-8 |
|---|---|
| O | Sorts the words resulting from the expansion in ascending order |
| O | Sort the words resulting from the expansion in descending order |
| L | Converts all uppercase letters to lowercase |
| U | Converts all lowercase letters to uppercase |
| C | Capitalizes the first letter of each word |
| C | When used with ${(name)}, counts number of characters in the array, as if it were a string instead of an array |
| W | When used with ${(name)}, counts the number of words in the name, whether this value is a string or an array (the current value of IFS is used to find word boundaries in strings)

The following example demonstrates most of these flags:

```
zsh % WORDS=(This is an array of words)
zsh % echo \{(o)WORDS}
an array is of This words
zsh % echo \${{(O)WORDS}
words This Of is an array
zsh % echo \${{(L)WORDS}
this is an array of words
zsh % echo \${{(U)WORDS}
THIS IS AN ARRAY OF WORDS
zsh % echo \${{(C)WORDS}
This Is An Array Of Words
zsh % echo \${{(c)WORDS}
This is an array of words
zsh % echo \${{(c)#WORDS}
25
zsh % WORDS='This is a string of words'
zsh % echo \${{(w)WORDS}
6
```
