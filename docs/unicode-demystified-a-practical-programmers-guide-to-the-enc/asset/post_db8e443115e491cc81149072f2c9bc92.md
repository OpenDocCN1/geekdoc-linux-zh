
## Chapter 3 Introduction to the GNU/Linux Utilities

```bash
$ ls -l mak*
-rw-r--r-- 1 sam sam 634226 Oct 17 15:01 make-3.76.1.tar.gz
$ gunzip mak*
$ ls -l mak*
-rw-r--r-- 1 sam sam 2344960 Oct 17 15:01 make-3.76.1.tar.gz
$ tar -xvf mak*
x make-3.76.1/, 0 bytes, tape blocks
x make-3.76.1/Makefile.info, 19129 bytes, 38 tape blocks
x make-3.76.1/AUTHORS, 13193 bytes, 3 tape blocks
x make-3.76.1/make.info-8, 42472 bytes, 83 tape blocks
x make-3.76.1/make.info-9, 10289 bytes, 21 tape blocks
```

The first of the preceding lists lists the downloaded tarred and gzipped file: make-3.76.1.tar.gz (about 0.6 megabytes). The asterisk (*) in the filename matches any characters in filenames (page 158), so you end up with a list of files whose names begin with mak—in this case only one. Using an asterisk saves typing and can improve accuracy with long filenames. The gunzip command decompresses the file and yields make-3.76.1.tar (.gz extension), which is about 2.3 megabytes. The tar command creates the make-3.76.1 directory in the working directory and unpacks the files into:

```bash
$ ls -ld mak*
drwx-xr-x 4 sam sam 2048 Sep 29 2003 make-3.76.1
-rw-r--r-- 1 sam sam 2344960 Oct 17 15:01 make-3.76.1.tar.gz
$ ls -l make-3.76.1
total 4196
-rw-r--r-- 1 sam sam 1391 Aug 27 2003 AUTHORS
-rw-r--r-- 1 sam sam 18043 Dec 10 2002 COPYING
-rw-r--r-- 1 sam sam 153710 Sep 19 2003 ChangeLog
-rw-r--r-- 1 sam sam 5586 Jul 25 2002 vmsfunctions.c
-rw-r--r-- 1 sam sam 16563 Aug 27 2003 vmsify.c
-rw-r--r-- 1 sam sam 16320 Aug 27 2003 vpath.c
drwx-xr-x 5 sam sam 512 Sep 19 2003 w32
```

After tar extracts the files from the archive, the working directory contains two files whose names start with mak: make-3.76.1.tar and make-3.76.1. The -d option allows ls to display only directory names, not the contents of directories, which it normally does. The final ls command shows the files and directories in the make-3.76.1 directory.

You can combine the gunzip and tar commands on one line with a pipe (|), which redirects the output of gunzip so that it becomes the input to tar:

```bash
$ gunzip -c make-3.76.1.tar.gz | tar -xvf -
```

## tar -x Option Extract a Lot of Files

Some tar archives contain many files. Run tar with the -t option and the name of the tar file to list the files in the archive without unpacking them. In some cases you may want to create a new directory (mkdir page 106), move the tar file into that directory, and expand it. That way the unpacked files do not mingle with your existing files, and there is no confusion. It makes it easier to delete the extracted files if you choose to do so. Some tar files automatically create a new directory and put the files into it. Refer to the preceding example.

## tar -x Option Can Overwrite Files

The -x option to tar overwrites a file that has the same filename as a file you are extracting. Follow the suggestion in the preceding caution box to avoid overwriting a file.

- -c option causes gunzip to send its output through the pipe instead of creating a file. Refer to “Pipes” (page 151), gzip (page 1219), and tar (page 1343) for more information about how this command line works.

A simpler solution is to use the -z option to tar. This option causes tar to call gunzip (or gzip when you are creating an archive) directly and simplifies the preceding command line to

```bash
$ tar -xvzf make-3.76.1.tar.gz
```

In a similar manner the -j option calls bzip2 or bunzip2.
