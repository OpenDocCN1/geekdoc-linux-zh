# Customizing KDE 317

# Login Photo

The Login Photo section of the Control Center sets up an identification photo that you can click on, instead of typing your name, to log in the system. GDM (GNOME Display Manager) must be set up in order to use this option.

# Look & Feel

The Look & Feel section of the Control Center (Table 8-16) controls how information is presented to the user, including all the elements on the desktop.

# KDE Control Center Look & Feel table 8-15

| Background | Sets up one background for all workspaces or a different background for each. You can specify a Mode (flat, pattern, vertical gradient, and so on) and Color 1. Refer to "color-orchooser: Selects a Color" on page 281 for the Select Color window. When you specify a Mode with a Gradient, you can choose Color 2. The Wallpaper allows you to specify one or more wallpapers, each remaining on the window for a period of time; the Adjusted tab lets specify the balance and blending of wallpapers. You can specify a maximum amount of memory (cache) KDE will use to store the image. | | Colors | Specifies a color scheme for the windows and desktop. Select the component as labeled at the top of the window and specify a color for that component by clicking the color bar. When you click the color bar Conquer displays the Select Color window (page 281). Click a color and then click OK. Save scheme in the Color Scheme tab to give the scheme a name.
