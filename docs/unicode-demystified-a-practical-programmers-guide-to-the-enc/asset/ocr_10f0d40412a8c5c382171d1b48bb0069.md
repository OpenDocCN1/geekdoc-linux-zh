# Commands That Are Symbols

The Z Shell uses the symbols ( ), [, ], and $ in various ways to identify builtin commands. To minimize confusion Table 15-2 lists the most common use of each of these commands, even though some of them are not introduced until later in the chapter.

| Builtin | table 15-2 |
|---|---|
| ) | Subshell (page 550) |
| $() | Command substitution (page 803) |
| (()) | Assignment operator (use when the enclosed value contains an equal sign [page 761]) |
| $(() ) | Expression evaluation (not for use with an enclosed equal sign [page 762]) |
