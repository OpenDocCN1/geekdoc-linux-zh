# .vimrc Startup File

Instead of setting vim parameters in your .login or .profile file, you can create a .vimrc file and set them there. If you set the parameters in a .vimrc file, you use the following format:

```
set param1 param2...
```

Following are examples of .vimrc files that perform the same function as EXINIT described previously:

```
$ .vimrc
set ignorecase
set number
set shell=/bin/tcsh
set wrapmargin=15
```

```
$ .vimrc
set ic
set nu
set sh=/bin/tcsh
set wm-15
```

When you start, vim looks for a .vimrc file that you own in your home directory and in your working directory. If it finds such a file, vim uses the values that it contains. If you set parameters in your .profile or .login file, parameters in .vimrc take precedence because .vimrc is executed later than .profile and .login. Parameters set in .vimrc also take precedence over those from the EXINIT shell variable.
