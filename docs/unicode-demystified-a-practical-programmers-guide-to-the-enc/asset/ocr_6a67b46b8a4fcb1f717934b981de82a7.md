# # History

The use of history in tsh is similar to its use in bash. (See page 588 for a complete description of the history mechanism.) In both shells. For example, !! refers to the previous event in tsh, as it does in bash. The command `!328` means to execute event number 328 and `!?text` means to execute the most recent event containing the string text. Table 14-1 lists the few extra word modifiers in tsh not found in zsh or bash.

# ## Word Modifiers table 14-1

| | | |
|---|---||
| u | Converts the first lowercase letter into uppercase |
| l | Converts the first uppercase letter into lowercase |
| a | Applies the next modifier globally within a single word |

It is possible to use more than one word modifier in a command. For instance, the modifier, in combination with the u or l modifier, is handy for changing the case of an entire word.

tctsh $ echo $VERSION
VERSION: Undefined variable.
tctsh $ echo !!:al
echo $version

The variables that set to control history in tsh are different from those in bash. Where bash uses HISTSIZE and HISTFILESIZE to determine the number of events that are preserved during and between sessions (page 590), tsh uses history and savehist (Table 14-2).

# ## History Variables table 14-2

| Function | Variable | Default |
|---|---|---|
| Maximum number of events saved during a session | history | 100 events |
| Location of the history file | histfile | ~/.history |
| Maximum number of events saved between sessions | savehist | |
