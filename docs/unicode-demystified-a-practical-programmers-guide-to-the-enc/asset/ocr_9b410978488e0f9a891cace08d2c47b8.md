# Links

symbolic link is an indirect pointer to a file. A symbolic link is a directory entry that contains the pathname of the pointed-to file (a pointer to the hard link to).

Symbolic links were developed because of the limitations of hard links. No one can create a hard link to a directory; anyone can create a symbolic link to directory. Also, a symbolic link can point to any file, regardless of where it is located in the file structure, but a hard link must be in the same filesystem as the other hard link(s) to the file.

Often the GNU/Linux file hierarchy is composed of several filesystems. Because each filesystem separate control information (that is, separate inode tables) for the files, it is not possible to create hard links between files in different filesystems. When you create links only files in your own directories, you will not notice these limitations.

One of its advantages over hard link is that a symbolic link can point to a nonexistent file. This ability is useful if you need to link to a file that periodically gets removed and recreated. A hard link would keep pointing to the removed file, which the hard link would keep alive of being a hard link, even after a new file was created. A symbolic link would always point to the newly created file and not interfere with deleting the old file. For example, a file that gets checked in and out the Source Code Control System, a o file that is recreated by the C compiler each time you run make, or a log file that is periodically archived.

Although they are more general than hard links, symbolic links have some disadvantages. Whereas all hard links to have equal status, symbolic links do not have the same status as hard links. When a file has multiple hard links, it is like a person having multiple full legal names, as married women do. In contrast, symbolic links are like nicknames. Anyone can have one or more nicknames, but nicknames have a lesser status than legal names. Some of the peculiarities of symbolic links are described in the following sections.

# In: Creates a Symbolic Link

Use in it --symbolic (or -s) option to create a symbolic link. The following example creates a symbolic link,/tmp/s3, to the file sum in Alex's home directory. When you use ls -l command to create the symbolic link, l displays the name of the link and the name of the file points to. The first character of the listing is l(for):

```
$ ln --symbolic /home/alex/sum /tmp/s3
$ ls -l /home/alex/sum /tmp/s3
-rw-rw-rwx 1 alex alex 38 Jun 12 09:51 /home/alex/sum
lrwxrwxr-wx 1 alex alex 14 Jun 12 10:09 /tmp/s3 ->
$ cat /tmp/s3
This is sum.
```
