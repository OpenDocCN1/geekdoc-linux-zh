# KDE Control Center Personalization (Continued)

# Konsole

General

| Default Terminal | Specifies that konsole is called as the default terminal application, as when you click the terminal icon on the control panel. When you want to use another program, remove the mark from this check box, and put the name of the program that you want to use in the Default Terminal text box. |
| Use Konsole as default terminal application |

Misc

| Show Terminal when Resizing | Displays a small rectangle that shows the dimension, in columns and rows, of the terminal window as you resize it. |

| Show Frame | Displays an inner frame (line) around the inside of the Konsole window. |

| Warn for Open Sessions on Quit | Displays a warning dialog box when you attempt to drag Konsole while you have more than one session (other shells, consoles, and so on). |

| Blinking Cursor | Causes the Konsole cursor to blink. |

| Require Ctrl key for drag and drop | Prevents normal drag-and-drop of text unless you hold the CONTROL key down during the action. |

| Line Spacing | Specifies the spacing between lines of text on Konsole. **Normal** and 1 show single spacing (no blank lines). |

| Double Click | Double-clicking highlights a word. The characters in the text box are considered part of that word. |

| Schema | Specifies what the Konsole window looks like. You can choose any of the schema in the Frame from any Konsole window (**Konsole menubar**→→ **Schema**). When you want Konsole windows to come up with a specific schema automatically, you must specify that as the default schema in the Schema frame. |

| Colors | Displays the title of the schema you are working with as shown in the Schema frame. Enter a new title in this text box when you want to create a new schema. |

| Schema | Specifies the colors that the schema named in Title uses. |

| Set as default schema | Chooses an existing schema to work with. Changes the name in the Title text box. |

| Save Schema | Sets the highlighted schema under the name in the Title text box. |
