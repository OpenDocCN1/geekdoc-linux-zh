```
$ find ~-name memo -print > memo.out &\n[1] 3343
```

Next, ps confirms the PID number of the background task. If you did not al-ready know this number, using ps would be the only way to find it out:

```
$ ps
PID TTY             TIME CMD
3308 pts/1          00:00:00 bash
3343 pts/1          00:00:00 find
3344 pts/1          00:00:00 ps
```

Finally, kill (page 1224) terminates the process:

```
$ kill 3343
$ RETURN          find ~-name memo -print >memo.out
[1]+ Terminated$
```
