# HOWTOs

![](bbox=[0.318, 0.061, 0.755, 0.313])

A HOWTO document explains in detail how to do something related to performing system GNU/Linux, from setting up a specialized piece of hardware to administration setting up specific networking software. Mini-HOWTOs offer shorter explanations. As GNU/Linux software, one person or a few people generally are responsible for a HOWTO document, yet many people contribute to it.
The Linux Documentation Project (LDP) site hosts all the HOWTO and miniHOWTO documents. From a GUI, use your browser to go to www.ldp.org, click HOWTOs, and pick the index you want to use to find a HOWTO or mini-HOWTO. Or use the LDP search feature on its home page to find HOWTOs and More. From a character-based interface, use ftp to open ftp:ibiblio.org and go to 
/pub/Linux/docs/HOWTO to download character-based versions of the HOWTOs.
