A subnet mask (or address mask) is a bit mask that identifies parts of an IP address correspond to the network address and subnet portion of the address. This mask has in positions corresponding to the network and subnet numbers and 0s in the host number positions. When you perform a bitwise AND on an IP address and a subnet mask (Table 9-3), the result is an address that contains everything but the host address (hostid) portion.
