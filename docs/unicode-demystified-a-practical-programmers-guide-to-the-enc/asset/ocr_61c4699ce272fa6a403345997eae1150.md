# Asterisk

| Regular Expression | Matches | Examples |
| --- | --- | --- |
| /ab\*/ | a followed by zero or more b followed by a c | ac, abc, abbc, debbcabc |
| /ab\.\*\/ | ab followed by zero or morecharacters followed by c | abc, abxc, abc45c, xab 756_34 x cat |
| /t.\*/ | t followed by zero or more characters followed by ing | thing, thing, I thought of |
| /[a-zA-Z ]*/ | A string composed only of letters and SPACES | 1. any string without numbers or punctuation! |
| /\.\*/ | As long as a string as possible between ( and | Get (this) and (that): |
| /([^\]\*)*/ | The shortest string possible that starts with ( and ends with ) | (this), Get (this and that) |

An asterisk can follow a regular expression that represents a single character (Table A-4). The asterisk represents zero or more occurrences of a match of the regular expression. An asterisk following a period matches any string of characters.(A period matches any character, and an asterisk matches zero or more occurrences of the preceding expression.) A character class definition followed by an asterisk matches any string of characters that are members of the character class.
