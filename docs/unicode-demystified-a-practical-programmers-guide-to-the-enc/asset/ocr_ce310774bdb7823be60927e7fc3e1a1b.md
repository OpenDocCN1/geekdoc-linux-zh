# Peripherals

The Peripherals section of the Control Center (Table 8-17) controls an optional digital camera, the system keyboard, and the system mouse.

# KDE Control Center ↔ Peripherals

| Digital Camera | Allows you to work with a digital camera from within Konqueror or other KDE applications. Click the icon of the camera, and set it up as required. Go to camera/ in Konqueror to view and download pictures. This is an interface to gphoto2 (w.gphoto.org). |
| Keyboard | |
| Layout | |
| Configuration | Turns on the Configuration frame so that you can configure your keyboard layout. |
| Keyboard Model | Specifies the physical model of the keyboard you are using. |
| Primary Layout | Specifies which keys generate characters, based on the language you are working in. |
| Primary Variant | Defines the keyboard. |
| Additional layouts | Specifies one or more additional layouts. You can choose from these layouts or make further changes to the list of layouts by right clicking the flag icon in the system tray (in the panel). |
| Options | |
| Switching Policy | Specifies whether the keyboard layout switches on a Global, Window Class, or Windows basis. |
| Xkb Options | Specifies various options about the X keyboard. |
| Advanced Keyboard repeat | Allows you to hold a key down for a period of time instead of repeatedly pressing the key to generate multiple keystrokes. |
