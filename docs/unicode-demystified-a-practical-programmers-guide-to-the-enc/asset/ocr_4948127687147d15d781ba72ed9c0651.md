# Setting and Unsetting Options

Set an option, such as NO_GLOB, by using the set builtin and preceding the option name with -o:

```
zsh % set -o NO_GLOB
```

The Z Shell strips underscores when it processes a command like this; it also ignores case. The next command is equivalent to the previous one:

```
zsh % set -o noglob
```

Use a plus sign in place of the minus sign to unset an option:

```
zsh % set +NO_GLOB
```

In addition, you can drop the NO so that set +o glob turns off glob, and -o glob turns it on (its initial state).

Another way of setting/unsetting options is with the setopt/unsetopt builtins. The following commands turn on off globbing:

```
zsh % setopt glob
zsh % unsetopt glob_glob
```

These commands turn off globbing:

```
zsh % setopt noglob
zsh % unsetopt noglob
```

# Options That Control Filename Pattern Matching

| NO_GLOB | Turns off all pattern matching; no characters have special meaning when specifying filenames to the shell. If NO_GLOB is not set, the characters *, |, <, and ? have special meaning when specifying filenames. |
| EXTENDED_GLOB | Adds the characters ^, ~, and # as special pattern-matching characters. |
| NULL_GLOB | Removes patterns from the command line if no filenames are found to match. If this option is not set, zsh displays an error message if no filenames match the pattern. |
| NO_NOMATCH | Causes zsh to leave the pattern intact on the command line, if no filenames match the pattern (for example, if no files match *.c, pass the string *.c to the command). |
