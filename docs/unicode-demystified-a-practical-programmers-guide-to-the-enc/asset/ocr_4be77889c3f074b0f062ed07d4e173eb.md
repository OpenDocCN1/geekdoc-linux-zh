Formerly Xconfig, the redhat-config-xf86 utility generates the file name
/etc/X11/XF86Config,¹¹ X (XF86 version 4) uses to initialize itself. The
redhat-config-xf86 utility runs as part of the Red Hat Linux, and you can
run it when you want to regenerate the XF86Config file (such as you
get a new monitor, want to add an additional screen resolution, and so on).
m the existing configuration file to XF86Config.backup before generating a
ew one. You can also write or modify XF86Config with an editor. Always make a
ackup copy of a system file such as this one before you make changes to it. Even
with a backup copy it is nice to comment out the code you want to remove and an-
note the code you add so you can remember what you did when you come back to
t in the file.

The deeper color (millions of colors, generated by a 24-bit color depth, is
the deepest) and the higher the resolution (1600x1200 is the highest resolution of
many monitors), the more resources the system uses displaying the video and the
slower an order will run. Video resource versus system speed should not
en an issue in a modern system.

Once X is running, you can switch between yours by pressing CONTROL-ALT-
+ or CONTROL-ALT—(use the plus or minus on the numeric keypad).
The redhat-config-xf86 utility run from a command line; it opens a win-
