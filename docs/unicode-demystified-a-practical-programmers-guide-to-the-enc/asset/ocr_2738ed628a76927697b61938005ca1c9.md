# The cvs-commands

The common cvs-commands follow, along with a brief description of each. The only cvs-commands that modify the source repository are import and commit; all others copies of files belonging to individuals users.

**add file-list** One or more directory or ordinary files for addition to the source repository. The addition of a marked file is reflected in the source repository only when the filename is given as an argument to a commit command. This can occur anytime after the file has been marked with add.

Files marked for addition to the source repository must reside in a module that has been checked out from the source repository; the new file fills the same position in the repository hierarchy as its counterpart in the user's copy of the module.

To add, you must be in the directory containing the file that you want to add. The add command is not recursive, the name of each file you want to add must appear in the file-list of an add command. Without the -m option, add uses an empty description.

**checkout module-list** Checks out a module or modules from the source repository. By default, checkout recursively creates all subdirectories and files in the working directory. All names in module-list must be relative to CVSROOT unless -d to specify another source repository.

A synonym for checkout, co, is usually called with a single nonoption argument.

**commit [file-list]** Mod the source repository. This option adds files that have been marked for addition with the add command, removes files that have been marked for removal with the remove command, and incorporates the changes in your working copies into the source repository. The file-list is optional; without it commit looks at all the files in the working directory, committing only those that have been marked for addition or marked for removal (provided they have been physically removed) and those that have undergone changes. The commit command aborts if your copy of the source repository needs updating; in this case you must first execute an update command with the commit command to make your copies current. Unless you give a -m option with the commit command, you are put into the editor to enter a log message.

A synonym for commit is ci.

**diff [file-list]** With compares each file in the working directory with the revision in the source repository used during checkout of the file. Giving a file in file-list tells diff to compare that file with the copy in the source repository used during checkout. The diff command is based on the RCS command rsdiff, which itself calls the GNU/Linux diff utility. See rsdiff (page 878) for more information about other options that you can use with the cv diff command.
