# session

When you execute a file that has setgid (set group ID) permission, the process executing the file takes on the privileges of the group file belongs to. The utility shows setgid permission as an s in the group's executable position. Also setuid.

# setgid

When you execute a file that has setuid (set user ID) permission, the process executing the file takes the privileges of the owner of the file. As an example, if you run a setuid program that removes all files in a directory, you can remove files in any file of the owner's directories even if you do not normally have permission to do so. When the program is owned by root, you can remove files in any directory root can remove files from. The utility shows setuid permission as an s in the owner's executable position. Also see setgid.
