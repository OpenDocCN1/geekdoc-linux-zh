The display at the bottom of the screen shows that all the commands require you to use the CONTROL key; the command Get Help, for instance, is CONTROL-G. Using CONTROL keys for commands to distinguish commands from text that you type to fill in the header fields and the mail message itself. There are a few other places in pine where commands are control characters, such as when you edit the address book (see the Main Help screen).

Alex's email sending mail to himself, he types his login name after the To: prompt, followed by RETURN:

As soon as Alex presses RETURN, pine replaces his login name with his full name and his e-mail address, inside angle brackets:

To: Alex Watson <alex@example>



Alex's email address allows others to send him e-mail. Alex can send mail to any user on his system by using user's login name, but to send to users on other systems requires more complex addresses. If you CONTROL-G when the To: prompt is highlighted, pine gives you help on addresses.

You can use the next line of the header, the Cc: line, to send copies of a message to other users. In response to this, you can enter the names of users to receive copies of the message. Separate the names in the list with commas and terminate the list by pressing RETURN or DOWN AR. Because Alex wants to send mail only to himself, he presses RETURN to highlight the next line of the header.

The third line displays the Attachmnt: (Attachment) prompt. In response to this, you can give the name of a file or files (either text or binary) that you want attached to the mail message. Alex skips this line by pressing RETURN.

The last line of the header contains the Subject: prompt. Alex types in the sub-ject of his mail message and presses RETURN:

When he is finished typing his message, Alex presses CONTROL-X to send it. With many pine commands, Alex is prompted to confirm his intention. Alex may remain in the mailer, perhaps to compose a message to someone else or to select another command from the Main menu. Because Alex is done for now, he enters Q to return to the shell.
