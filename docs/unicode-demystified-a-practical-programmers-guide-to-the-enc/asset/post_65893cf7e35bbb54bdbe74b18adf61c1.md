## Initializing Databases

After booting the system, in as or so root, run makewhatis to update the whatis database so that whatis (page 79) and apropos (page 79) work properly; then run updatedb to update the locate database so that locate works properly. The best way to use these utilities is to run the cron scripts that run daily. Working as root, give the following commands:

```bash
# /etc/cron.daily/makewhatis.cron
# /etc/cron.daily/locate.cron
```

These utilities run for up several minutes and may complain about not being able to find a file or two. When you get the prompt back, your whatis and locate databases are up-to-date.

## redhat-config-firewall: Sets up a Firewall

A firewall helps protect your computer against malicious users. The redhat-config-firewall utility offers three levels of protection:

- High Security: Allows only DNS and DHCP (page 1029).
- Low Security: Allows FTP, SSH, TELNET, HTTP, and all connections to ports lower than 1023.
- Disable Firewall: Creates no security rules. This choice is not recommended for systems that are connected to the Internet.

## A Firewall Can Prevent Network Services from Working

Depending on its level of protection and how you set it up, a firewall can prevent network services from working. Test for this condition by turning the firewall off, running the service to see it works, and resetting the firewall to the options you desire, and whether the service still works.
