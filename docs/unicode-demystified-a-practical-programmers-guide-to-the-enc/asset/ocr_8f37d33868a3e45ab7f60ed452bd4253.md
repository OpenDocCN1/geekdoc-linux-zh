In the next example, after setting the correct variable, mistype the name of the tsh command, and tsh prompts for a correct command name. Because the command tsh has offered as a replacement is not, you choose to edit the command line and fix the mistake:

```
tsh $ set correct=cmd
tsh $ lx -l
CORRECT=? lex -l (y|n|e|a)? edit \
tsh $ lx -l|
```

```
tsh $ set correct = complete
tsh $ upturn
Ambiguous command
tsh $ upturn -> uptime
4:55pm up 5 days, 9:54, 5 users, load average: 1.62, 0.83, 0.33
tsh $ echo "hi there"
Ambiguous command
tsh $ echo "hi there" -> RETURN
hi there
```

The preceding two commands show that completion works with arguments. The command is ambiguous, but both commands start with echo, so the shell gives you a message and displays the command line with much as common to them. (The utilities are echo and echot, so echo is common to them.) The shell places the prompt so you can complete the command if you want to. In this case the user wanted to use echo and simply pressed RETURN.

# Variables

Although tsh stores variable values as strings, you can work with these variables as numbers. Expressions in tsh can use arithmetic, logical, and conditional operators. The @ builtin can also evaluate arithmetic expressions but can work only with integers.

This section uses the term numeric variable to describe a string variable that contains a number that tsh uses in arithmetic or logical computations. However, no true numeric variables exist in tsh.

A variable name consists of 1 to 20 characters, which can be letters, digits, and underscores (_). The first character cannot be a digit but can be an underscore.
