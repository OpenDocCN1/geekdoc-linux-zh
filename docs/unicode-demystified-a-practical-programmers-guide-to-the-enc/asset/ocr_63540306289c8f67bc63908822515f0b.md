# # What is a Desktop?

In KDE documentation the term *desktop* refers to a single division of a larger area. This book, in conformance with the GNOME 2 documentation, refers to everything that usually occupies your display monitor as a workspace. A desktop is divided into workspaces.

# # Getting Started

This section gives you a quick overview of the desktop: help and where to get it; the K menu, from which you can start almost any program (analogous to the GNOME menu); the title and scrollbars and how they differ from; mouse clicks and which do what; the input focus and different ways of changing it; the Main panel, which is the key to the desktop; and menus.
