A message displayed by a command when you call the command using incorrect line arguments.

# user mode

The designation for the state of the system while it is doing user work, such as running a user program (but not the system calls made by the program). Contrast to system mode (page 1496).

# UTC

Coordinated Universal Time. UTC is equivalent to the mean solar time at the prime meridian (0 degrees longitude). Also called Zulu time (Z stands for longitude) and GMT (Greenwich Mean Time).

# utility

A program included as a standard part of GNU/Linux. You typically invoke a utility by giving a command in response to a prompt or by calling it from within a shell script. Utilities are often referred to as commands. Contrast to builtin (page 1458).

# variable

A name and an associated value. The shell allows you to create variables and use them in shell scripts. Also, the shell inherits several variables when it is invoked, and maintains those and other variables while it is running. Some shell variables establish characteristics of the shell environment, whereas others values that reflect different aspects of your ongoing interaction with the shell.

# viewport

Same as workspace (page 1502).

# virtual console

Additional consoles, or displays, that you can view on the system, or physical console. See page 36 for more information.

# virus

A cracker (page 1462) program that searches out other programs and “infects” them by embedding a copy of itself in them, so that they become Trojan horses (page 1498). When these programs are executed, the embedded virus executes too, propagating the “infection,” usually with the user's knowledge. By analogy with biological viruses.

# VLAN

A logical grouping of two or more nodes that are not necessarily on the same physical network segment that share the same network number. A VLAN is often associated with switched Ethernet.
