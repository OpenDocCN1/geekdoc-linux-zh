## Control Structures

If the three words are not the same, the structure passes control to the first elf, which begins a series of tests to see if any pair of words is the same. As the nesting continues, if any one of the if statements is satisfied, the structure passes control to the next then and subsequently to the statement after fi. Each time an if statement is not satisfied, the structure passes control to the next elf element. In the if3 script the double quotation marks around echo to contain ampersands (&) prevent the shell from interpreting the ampersands as special characters.
