The p (print) flag causes sed to send all lines on which it makes substitutions to
standard output. This flag overrides the -n option on the command line.

The w (write) flag is similar to the p flag but sends the output to a specified file.
A single SPACE and the name of a file must follow the write flag.

+   p print The Print instruction selects the lines to standard output, writing the
lines immediately, and does not reflect the effects of subsequent instructions.
This instruction overrides the -n option on the command line.

+   w write This instruction is similar to the Print instruction but sends the output to a
sified file. A single SPACE and the name of a file (file) must follow the Write instru-
tion.

+   r file The Read reads the contents of the specified file and appends it to
the selected line. You cannot proceed Read instruction with two addresses. A sin-\gle SPACE and the name of a file must follow a Read instruction.

+   q quit The Quit instruction causes sed to stop processing.

# Control Structures

! NOT The NOT structure causes sed to apply the following instruction, located
s the same line, to each of the lines not selected by the address portion of the in-
struction.

{ } group instructions When you enclose a group of instructions within a pair
braces, a single address (or address pair) selects the lines on which the group of in-
structions operates.

# Examples

The following examples use the input file new:

```
$ cat new
Line one.
The second line.
The third.
This is line four.
Five.
This is the sixth sentence.
This is line seventh.
Eighth and last.
```

When you use the -n option on the command line, sed copies only selected lines.
