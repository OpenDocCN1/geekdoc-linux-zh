+   - **focus-follows-mouse** (sloppy focus, point to give focus, or enter-only) Gives the input focus to a window when you move the mouse pointer onto the window. That window maintains the input focus until you move the mouse pointer onto another window, at which point the new window gets the focus. Specifically, when you move the mouse pointer off a window and onto the root window, the window that had the focus does not lose.
- **focus-under-mouse** Same as focus-follows-mouse (KDE).
- **focus-strictly-under-mouse** (enter-exit) Gives the input focus to a window when you move the mouse pointer onto the window. That window maintains the input focus until you move the mouse pointer off the window with, at which point no window has the focus. Specifically, when you move the mouse pointer off a window and onto the root window, the window that had the focus loses it, and any input from the key-lost.

Under GNOME, use main menu: Preferences⇨Window to change the focus policy; under KDE, use main menu: Preferences⇨Look & Feel⇨Window Behavior (page 323).

To determine which window has the input focus compare the window borders; the border color of the active window is different from the others or is darker on a mono-display. Another indication that a window is active is that the keyboard cursor is a solid rectangle; in windows that are not active, it is an outline of a rectangle.

Which keyboard method are you using? If you position the mouse pointer in a window and window does not get the input focus, your window manager is configured to use the click-to-focus method. If the border changes, you are using the focus-follows-mouse/focus-under-mouse or focus-strictly-under-mouse method. To determine which of these methods you are using, start typing something, with the mouse pointer on a window, and then move the mouse pointer over the root window and continue typing. If characters continue to appear within the window, you are using focus-follows-mouse/focus-under-mouse. Otherwise, you are using focus-strictly-under-mouse.
