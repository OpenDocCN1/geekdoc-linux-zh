The Kill Ring is organized as a fixed-length FIFO list, with each new entry causing the eldest to be discarded (once you build up to 30 entries in the Kill Ring). Simple cut-and-paste operations use only the newest entry. The older entries are kept to give you time to change your mind about a delete. If you do change it is possible to "mine" the Kill Ring like an archaeological dig, working backward through time and down the strata of killed material to copy a specific item back into your buffer.

To view every entry in the Kill Ring, begin a yanking session with CONTROL-Y. This copies the youngest entry to your buffer at the current cursor position. If this is not the item you want, continue the yanking session by typing META-Y. This erases the yank and copies the next youngest entry to the buffer at the current position. If this is still not the item you wanted, META-Y to erase it and retrieve a copy of the next entry, and so on. You can continue all the way back to the oldest entry. If you type META-Y, you wrap back to the youngest entry. In this manner you can examine each entry as many times as you wish.

The sequence CONTROL-Y followed by any mixture of CONTROL-Y and META-Y, the sequence is broken, and you must give the CONTROL-Y command again to start another yanking session.

As work backward in the Kill Ring, it is useful to think of advancing a Last Yank pointer backward through history to older and older entries. The position is not set to the youngest entry until you get a new kill command. Using this technique, you can work backward part way through the Kill Ring with CONTROL-Y and a few META-Y's, give some commands that do not kill, and then pick up where you left off with another CONTROL-Y and a succession of META-Y's.

It is also possible to position the Last Yank pointer with positive or negative arguments to META-Y. Refer to the online documentation for more information.

# Inserting Special Characters

As stated earlier, emacs inserts everything that is not a command that would ordinarily insert into the buffer at the current cursor position. To insert characters that are emacs commands, you can use the emacs escape character, CONTROL-Q. There are two ways of using this character.

+   - CONTROL-Q followed by any other character inserts that character in the buffer, no matter what command interpretation it was supposed to have.
- CONTROL-Q followed by three octal digits inserts a byte with that value in the buffer.
