The cont (continue) command causes the process to continue running from where it left off. The testtab contains only one line; the process finishes executing, and the results appear on the screen. The debugger reports the exit code of the program. A cont command given after a program has finished executing reminds you that execution of the program has completed. Following, the debugging session ends with a quit command:

```
(gdb) cont
Continuing.
  abc xyz
Program exited normally.
(gdb) cont
The program is not being run.
(gdb) quit
$ 
```
