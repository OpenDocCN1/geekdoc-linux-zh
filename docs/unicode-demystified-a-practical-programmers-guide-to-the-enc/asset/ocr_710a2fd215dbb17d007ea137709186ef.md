# Parameters (Continued)

| Flash |
| flash, fl | The vim editor normally causes the terminal to beep when you give an invalid command or press ESCAPE when you are in Command mode. Setting the parameter flash causes the terminal to flash in stead of beep. Set noflash to cause it to beep. Not all terminals/emulators support this parameter.
| Ignore case in searches |
| ignorecase(ic/nocic) | The vim editor normally performs case-sensitive searches, differentiating between upper- and lowercase letters. It performs case-sensitive searches when you set the ignorecase parameter. Set noignorecase to restore sensitivity.
| Allow special characters in searches |
| magic | Refer to "Special Characters in Search Strings" on page 439. The following characters have special meanings when used in a search string:
* [ ] *
When you set the nomagic parameter, these characters no longer have special meanings. The magic parameter gives them back their special meanings.
The ^ and $ characters have a special meaning within search strings, regardless of how you set this parameter.
| Invisible Characters |
| list | To cause vim to display TAB as as^ and to mark the end of each line with a $, set the list parameter. To display TABs as whitespace and not mark ends of lines, set list.
| Wrap Scan |
| wrapscan, ws | Normally when a search for the next occurrence of a search reaches the end of the Work buffer, vim continues the search at the beginning of the Work buffer. The reverse is true of a previous occurrence of a search string. The nowrapscan parameter stops the search at either the end of the Work buffer. The wrapscan parameter if you want to wrap once around the ends of the Work.
| Automatic Indention |
| autoindent, ai | The automatic indention works with the shiftwidth parameter to provide a regular set of indentions for programs or tabular material. This is normally off. You can turn it off by setting autoindent and turn it off by setting noautoindent.
When automatic indentation is on and vim in input mode, CONTROL-T moves the cursor from the left margin (or an indentation) to the next indentation position, RETURN moves the cursor to the left side of the next line under the first character of the previous line, and CONTROL-D backs up over indentation positions. The CONTROL-T and CONTROL-D work only before text is placed on a line.
