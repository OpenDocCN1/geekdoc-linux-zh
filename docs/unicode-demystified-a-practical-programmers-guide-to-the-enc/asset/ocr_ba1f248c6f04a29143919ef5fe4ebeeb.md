# Nautilus Menubar (Continued)

| Preferences | |
| --- | --- |
| View | Displays the Nautilus Preferences window. Refer to ""Nautilus Menubar. Edit⇒Preferences" on page 244. |
| Stop | Stops loading information. Generally used to stop downloading a Web page. |
| Reload | Redraw everything in the Nautilus side pane and subwindow. The refresh reflects changes in any of the underling data (for example, a new file in a directory that is displayed). Also available as a button on the Nautilus toolbar. |
| Side Pane Toolbar | A check mark appears to the left of each control bar that is displayed. Click a choice to change the state of the corresponding control bar. |
| Location Bar | |
| Reset View to Defaults | Resets Default View, Icon View Defaults, and List View Defaults as defined in Nautilus menubar: Edit⇒Preferences⇒Views (page 244). |
| Arrange Items | Gives you a choice of how to lay out and drag objects in the Nautilus subwindow. Manually enables you to drag objects as you please within the subwindow. Name, Size, Type, Modification Date, and Emblems (page 226) sort the objects accordingly. Tighter Layout brings the objects together whereas Reversed Order reverses the order you selected to (for example, when you select By Name and Reversed Order the objects appear by name in alphabetical order). |
| Clean Up by Name | Same as Arrange Items⇒By Name when you have previously selected Arrange Items⇒Manually. |
| Zoom In Zoom Out | Adjusts the magnification of the objects in the Nautilus subwindow. Also available by clicking the (+), minus (-), or number in the middle of the magnifying glass on location bar. |
| View as Icons | Specifies the way you want to view the contents of the Nautilus subwindow. Also available from the pop-up menu at the right end of location bar. |
| View as List | |
| View as Music | |
| View as | Brings the Open with Other Viewer window. |
