# Quick Copy & Move Plugin

Configures the Quickcopy and the Move plugin for Konqueror. These frames affect the Copy To and Move submenus that are displayed when you right click an icon in a Konqueror window and some icons in the root window. After making a change, you must bring up a new Konqueror window to see the results.

# Login Photo

The Login Photo section of the Control Center sets up an identification photo that you can click on, instead of typing your name, to log in the system. GDM (GNOME Display Manager) must be set up in order to use this option.
