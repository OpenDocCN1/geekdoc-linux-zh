# # Default device. The dj-filter script handles postscript and
# other formats automatically in black and white.
|lps:lp=/dev/lpd1:sd=/usr/spool/lpd1:sh:mx#0=\n:if=/usr/bin/dj-filter:\n:if=/var/log/lpd-errors.

# # Color postscript
cps:lp=/dev/lpd1:sd=/usr/lpd1:sh:mx#0:
:if=/usr/local/bin/start-daemon.jpcps:
:if=/var/log/lpd-errors.

The fields in each entry describe the printer for the lpd printer. For example, the
first field gives the names that can be used to reference printer. You print color
PostScript files by using lpr with the argument -Ppcs, which tells lpd to use the sec-
of these two entries. The first has two possible names: lp and ps. The lp
name is special to lpd and identifies this as the default entry when lpr is called
without the -P option. The remaining fields give the device (/dev/lp1), the directory
to queue in files while waiting for the device to become available (/usr/spool/lp1),
instructions to lpd not to print a banner page (sh), the maximum number of blocks
to allow in a single job (mx#0, where 0 means nothing), the input filter ap-
y to the job (the entries have different input filters), and the name of the log file
for errors (/var/log/lpd-errors). More fields are possible; see the printcap man page for
details.

# Do Not Edit /etc/printcap by Hand

Each time the lpd daemon starts, it recreates the /etc/printcap file, and you will lose manual
changes. Use printconf-gui to edit this file. You can manually add an entry to /etc/printcap.local.
Although printconf-gui does not display entries in /etc/printcap.local, the lpd daemon reads it.

The lpd daemon can also forward jobs to another computer. If you have a
printer that you would like to share on a network, you need to have a printcap en-
try similar to those shown previously on the system that is directly connected to the
printer. On other systems, you need printcap entries that identify the remote ma-\chine with the printer. For example, the following entry on a remote machine in-
struct lpd to send files for the printer named bravo for printing:

+   # remote printer on bravo (600 dpi, postscript, and duplex)
hires:
- :lp=rm=bravo:sd=/usr/spool/lp4si:if=/var/log/lpd-errors.

The -Phires argument to lpr on a remote machine to cause lpd to forward the
print job to bravo for printing.
