To get started, configure your local machine as a primary mail server by defining the default configuration files:/etc/mail/sendmail.mc, which is processed by m4 to generate /etc/mail/sendmail.cf. First, save backup copy of both files. The -p flag causes cp to preserve permissions as well as access and modification times so that you have accurate records:

```
# cp -p /etc/mail/sendmail.cf /etc/mail/sendmail.cf
# cp -p /etc/mail/sendmail.mc /etc/mail/sendmail.mc
```

By default, sendmail listens only on the local loopback address of the machine so that sendmail does not accept network SMTP requests. To cause sendmail to accept SMTP requests addressed to your local domain, comment out the following line in the sendmail.mc file:

```
DAEMON_OPTIONS('Port=smtp,Addr=127.0.0.1, Name=MTA')
```

by putting the characters dn!41 at the beginning of the line so that it looks like this:

```
dn1_DAEMON_OPTIONS('Port=smtp,Addr=127.0.0.1, Name=MTA')
```

Next, find the following line (towards the end of the file):

Clocalhost.localdomain.
Replace localhost.localdomain with the name of your domain. If your domain is tcorporp.com, the line becomes

Cwtcorp.com

You can receive e-mail for additional domains by adding lines, with the letters Cw followed by a domain name. When you are done making changes, save the file.

To generate sendmail.cf, give the following command:

```
# m4 /etc/mail/sendmail.mc > /etc/mail/sendmail.cf
```

The sendmail utility reads /etc/sendmail.cf when it starts; restart sendmail with the following command:

```
# sh /etc/rc.d/init.d/sendmail restart
```

or

```
# service sendmail restart
```

41. Because this file is processed by the m4 macro processor, you cannot use the traditional pound sign to comment out a line. The dn1 at the start of a line defines a macro that m4 ignores. A dn1 at the end of a line does nothing.
