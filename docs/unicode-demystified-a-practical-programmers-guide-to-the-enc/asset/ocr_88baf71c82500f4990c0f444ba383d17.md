$ at -f pr_tonight 2am
warning: commands will be executed using (in order) a) $SHELL login shell c)/bin/sh
job 9 2003-08-17 02:00

$ at 2am < pr_tonight
warning: commands will be executed using (in order) a) $SHELL login shell c)/bin/sh
job 10 2003-08-17 02:00

If you execute the command directly from the command line, you must signal the
 of the list of commands by pressing CTRL-D at the beginning of a line. The line
that begins with Job contains the job number and the time at will execute the job.
If you run atq after the preceding commands, it displays a list of jobs in its
queue:

| atq |
|---|---|
| 7 | 2003-08-17 02:00 a |
| 9 | 2003-08-17 02:00 a |
| 10 | 2003-08-17 02:00 a |

The following command removes one of the jobs from the queue:

| atmr 9 |
| atq |
|---|---|
| 7 | 2003-08-17 02:00 a |
| 10 | 2003-08-17 02:00 a |

The next example executes cmdfile at 3:30 P.M. (1530 hours) one week from to-
day:

$ at -f cmdfile 1530 +1 week
warning: commands will be executed using (in order) a) $SHELL login shell c)/bin/sh
job 12 2003-08-23 15:30

The final example executes a find job at 7 P.M. on Friday. It creates an intermedi-
file, redirects the output to standard error, and prints the file:

```
$ at 7pm Friday
warning: commands will be executed using (in order) a) $SHELL login shell c)/bin/sh
at> find -name "core" -print >report.out 2>report.err
at> 1pr report.out
at>CONTROL-<EOT>
job 13 2003-08-18 19:00
```
