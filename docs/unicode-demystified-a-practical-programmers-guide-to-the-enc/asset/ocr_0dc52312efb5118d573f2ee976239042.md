# Subnets

Each host on a network must process each broadcast to determine the information in the broadcast packet is useful to that. If a lot of hosts are on a network, each host must process many packets. To maintain efficiency, most networks, particularly shared media networks, such as Ethernet, now be split into subnetworks, or subnets. The hosts on the network, the more dramatically performance is impacted. Organizations use router and switch technology called VLANs (virtual local area network) to group similar hosts into broadcast domains (subnets based on function. It's not uncommon to see a switch with different ports part of different subnets.
