# Directory at ftp.redhat.com (Continued)

| pub/redhat/linux/8.0/en | Holds the English-language components of Red Hat Linux. |
| pub/redhat/linux/8.0/doc | Holds the English-language documentation for Red Hat Linux. |
| pub/redhat/linux/8.0/iso | Holds the English-language CD-ROM images of Red Hat Linux. |
| pub/redhat/linux/8.0/os | Holds architecture-specific directories, such as i386 for Pentium processors. Each of these architecture directories includes everything you need to install Red Hat Linux, including boot-disk image files, DOS utilities, and rpm packages; packages in RPMS are compiled, and packages in SRPMs (the first S stands for source) are in source format and must be compiled.|

The following pathnames point to the files that you need to order in to make CD-ROMs for installing a Red System. Change the 8.0 and the word psyche as appropriate. These pathnames point to the three software CD-ROM ISO files and a short MD5SUM file that verifies the files downloaded. (See MD5 on page 1478.) In the same directory are images of disks 4 and 5 that hold the source code in the form of RPM files, which you do not need to install Red Hat Linux:

```
pub/redhat/linux/8.0/en/i386/MD5SUM
pub/redhat/linux/8.0/en/i386/psyche-i386-disc1.iso
pub/redhat/linux/8.0/en/i386/psyche-i386-disc2.iso
pub/redhat/linux/8.0/en/i386/psyche-i386-disc3.iso
```

Rename the MD5 file to MD5SUM.discs so that when you download other MD5 files they do not overwrite this one.
Next, download the Red Hat Documentation CD-ROM ISO file along with its MD5 file which you can rename MD5SUM.docs. Finally, the contents of the directory that hold the boot image files, one of which will need if your computer cannot boot from a CD-ROM and you cannot copy the boot image off the CD-ROM, (refer to "Beginning Installation") on page 921:

```
pub/redhat/linux/8.0/en/doc/psyche-docs.iso
pub/redhat/linux/8.0/en/os/i386/images/*
```

Run the following commands to check your psyche-i386-disc1.iso:

```
$ md5sum *disc1.iso; grep disc1 MD5SUM
```
