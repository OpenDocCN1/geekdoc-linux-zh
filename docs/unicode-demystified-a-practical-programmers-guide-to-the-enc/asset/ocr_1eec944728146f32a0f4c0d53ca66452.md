# Process Substitution

A special feature of The Z Shell is the ability to replace filename arguments with pro-\ cesses. An argument with the syntax <command> causes command to be executed, writing to a named pipe (FIFO). The Z Shell replaces that argument with the name of
t pipe. If that is used as the name of an input file during processing,
t output of command is used. Similarly, an argument with the syntax >command)
is replaced by the name of a pipe that command reads as standard input.

In the following example sort is used with the -m (merge) option to combine
two word lists into a single list. Each list is generated by a pipe that extracts
words matching a pattern and sorts the words in that list:

```
sort -m f <grep "[A-Z].." memo1 | sort <grep \.*aba.* memo2|
(The -m option to sort works correctly only if the files are already sorted.)
```

Because process substitution passes the name of a pipe in place of a file on
disk, the command needs to be able to do random access
to the "file". If your command needs to be able to do random access on the input
file named the file, you can still do process substitution by replacing the
left angle bracket < with an equal sign (=). The Z Shell runs the process
argument to completion, putting any output into a temporary file. The name of this
temporary file is used in place of process argument. In the following example,
line produces a random line that starts with Alice the file names (page 777):

```
zsh % cat rline
!/bin/zsh
integer z
z=$(wc -l < $1)
sed n "${RANDOM % z + 1}" $1
zsh % rline =(grep "Alice*" names)
Alice Jones
```

The second line of this script gives the variable z an integer attribute; the third
line assigns it a value using command substitution. The arithmetic expression
${RANDOM % z + 1} produces a random number between 1 and the number of lines
selected from the file (z). The zsh variable RANDOM produces a random number
between 0 and 32,767 each time it is called. The rest of the expression, including
t remainder operator (%) is identical to the C language for extracting
a value between 1 and z from the value of RANDOM. The value that results from
this expression is then passed to the sed utility as the number of line to print
from the file. The -n instructs sed not to print any output unless explicitly requested
to do so, and the p prints the line whose name precedes it.

Because the rline script reads the file first to determine the number-
of lines and then select one randomly—it does not work if given a named
pipe. The =(command) form of process substitution allows you to use a command
to produce the input data.
