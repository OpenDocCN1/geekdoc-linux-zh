# Chapter 17 Red Hat Linux System Administration

This entry allows any user²² to reboot the computer safely by pressing the key sequence CTRL-ALT-DEL on the console (also referred to as the three-finger salute, or the Vulcan death grip). Because of its hooks into the keyboard driver, this key sequence sends a SIGINT to the input process, which in response runs shutdown. Because it runs as root, it causes shutdown to run as root, even if the sequence is initiated by an ordinary user. You can control CTRL-ALT-DEL by deleting the preceding line from /etc/initab (or putting a # at the end of the line) and then sending it a HUP signal (kill -HUP 1), which causes it to reread the /etc/initab file.

# consolehelper: Allows an Ordinary User to Run a Privileged Command

```
$ file /sbin/halt /usr/bin/halt
/sbin/halt ELF 32-bit LSB executable, Intel 80386, version 1 (SYS)...
/usr/bin/halt symbolic link to consolehelper
```

The one in /sbin runs the halt utility whereas the one in /usr/bin is a link to consolehelper (page 901). In root's PATH variable normally precedes /usr/bin so when someone runs root as a halt command, the shell begins the execution of /sbin/halt (the halt utility). Normally /sbin does not appear in a regular user's PATH; when a regular user has a halt command, the shell follows the link from /usr/bin/halt and execution of /usr/bin/consolehelper.

What consolehelper depends on is how PAM is set (refer to /etc/pam.d for the modules it calls and /usr/share/doc/pam/* for descriptions of the modules). Refer to "PAM" on page 104 for more information.

The consolehelper utility prompts for your password; when you supply it and are logged in the console, consolehelper proceeds to shut the system down. While you are logged in as Superuser with the default PATH, typing halt runs /sbin/halt, which is the halt utility.

# Going Single-user

Because going from multiuser to single-user mode can affect others, you must be Superuser to make this change. Make sure that you give others enough warning before going to single-user mode; otherwise, they may lose whatever they were working on.

Following is a method of manually bringing the system down to single-user mode—the point where it is safe to turn the power off. You must be running as Superuser to perform these tasks.

When you include the -a option in the shutdown command in /etc/initab and the /etc/shutdown.allow file exists, one of the users whose name appears in this file (or root) must be logged in one of the virtual consoles in order for a non-root user to run shutdown from a virtual console.
