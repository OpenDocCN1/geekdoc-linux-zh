| Most Often Visited | Displays a list of the Web sites you have visited the most.

| Edit Bookmarks | Displays your bookmarks for editing. Bookmarks are stored in ~/.kde/share/apps/konkorer/bookmarks.xml. |

| Netscape Bookmarks | Displays bookmarks created in or transferred to Netscape. Appears only after you have run Netscape.
(history list) The last few lines of the Bookmarks menu list the bookmarked locations that you have visited with Konkorer most recently. |

| Open Terminal | Opens a konsole terminal emulator (page 278) by default in a separate window with the directory shown in the location bar as its working directory (if possible). |
