LINENO

Before the shell executes a script or function, it sets the value of LINENO to the line number of the command it is about to execute. The following script begins with #!/bin/zsh to ensure that the script runs under zsh:

```
zsh % cat showline
!/bin/zsh
date
echo "Script $0: at line LINENO"
echo "Script $0: at line LINENO"
echo "Script $0: at line LINENO"
zsh % showline
Fri May 3 11:08:39 PDT 2002
Script showline: at line 3
Script showline: at line 4
Script showline: at line 5
```
