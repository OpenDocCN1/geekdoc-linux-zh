| e2label | Label a Filesystem | Displays or creates a volume label on ext2 or ext3 partition. Give
the command

# e2label device [newlabel]

where device is the name of the device (/dev/hda2/dev/sdb1/dev/td0,
and so on) you want to work with. When you include the optional new-
bel parameter, e2label changes the label on device to newlabel. Without
this parameter, e2label displays the label. You can also create a volume
with the -L option of tune2fs. |
| kbdconfig | Configure Keyboard | A utility with a character-based/pseudographical interface that specifies
the type of keyboard you are using. |
| mkfs | Make a New Filesystem | A front end for many utilities, each of which builds a different type of
filesystem. By default mkfs creates an ext2 filesystem and works on
either a hard disk partition or a floppy disk. Although it can take many
options and arguments, you can use mkfs as simply

# mkfs -t ext3 device

where device is the name of the device (/dev/hda2/dev/sdb1/dev/fd,
and so on) you want to make a filesystem. Use the -t option to specify
type of filesystem. The following command creates an ext3 filesystem
on device: |
