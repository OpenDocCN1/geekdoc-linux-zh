# which versus whereas

tip

Give it a program you want to run, and which looks through the directories in your search path, in order, and locates the program. If more than one program with the name you specify is in your search path, which displays the name of only the first (the one you will execute).
The whereas looks through a list of standard directories and works independently of your search path. Use whereas to locate a binary (executable) file, any manual pages, and source code for a program you specify.

# which, whereas: Locate a Utility

When you type the name of the utility on the command line (that is when you give GNU/Linux a command), the shell (Chapter 5) searches a list of directories for your program. This list of directories is called a search path; the chapters that describe each explain how to change this path. If you do not change the search path, the shell searches only a standard set of directories and stops searching. There are other directories on your system that contain useful utilities.

The which utility helps locate utilities (commands) by displaying the pathname to the file for the utility. (Chapter 4 contains more information on names and structure of the GNU/Linux filesystem). There may be multiple commands that have the same name on your system. When you type the name of a command, the shell searches for the command in your search path and runs the first one it finds. You can find which code of the program the shell runs using which. In the following example which reports the location of the tar command:

+   $ which tar
/bin/tar

The which can be helpful when a command seems to be working in unexpected ways. By running which, you may discover that you are running a socalled version of a tool or a different one than you expected. (Refer to "Important Standard Directories and Files" on page 112 for a list of standard locations for executable files.) For example, if tar is not working properly and you find that you are running /usr/local/bin/tar instead of /bin/tar, you might suspect that the local version is broken.

The whereas utility also searches for copies of a utility by looking in a few standard locations instead of using your search path. For example, you can find the locations for versions of the tar command:

```
$ whereas tar
tar: /bin/tar /usr/include/tar.h /usr/share/man/man1/tar.1.gz
```
