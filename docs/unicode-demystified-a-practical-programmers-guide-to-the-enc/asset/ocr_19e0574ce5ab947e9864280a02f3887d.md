Emacs was developed as a series of editors, including Emacs Editor and Correspondent. The ironic name, Editor and Correspondent, has had many reinterpretations, including MECHA ALT, TECO, and Icon Basic. Each version added windblind translation and Constantin Swapping.

Since then it has grown and evolved into more than 20 versions along the line. It fully supports the Windows system and many other platforms, and was introduced by Stallman. The original TECO macros are long gone, and emacs is a work still very much in progress.

# Moving the Cursor

You can position the cursor over any character in the emacs window and move the window so it displays any portion of the buffer. You can move the cursor forward or backward through the text (see Figure 10-8 on page 428) by various textual units (for example, characters, words, sentences, lines, paragraphs). Any of the cursor-movement commands can be preceded by a repetition count (CONTROL-U followed by a numeric argument), which causes the cursor to move that number of textual units through the text. Refer to page 484 for discussion of numeric arguments.

# Moving the Cursor by Characters

Pressing CONTROL-F moves the cursor forward one character. If the cursor is at the end of a line, the command wraps it to the beginning of the next line. The command CONTROL-U7 CONTROL-F moves the cursor seven characters forward (to the right).

Pressing CONTROL-B moves the cursor backward one character. The command CONTROL-U7 CONTROL-B moves the cursor seven characters backward (to the left). CONTROL-B works in a manner similar to CONTROL-F (Figure 11-3).
