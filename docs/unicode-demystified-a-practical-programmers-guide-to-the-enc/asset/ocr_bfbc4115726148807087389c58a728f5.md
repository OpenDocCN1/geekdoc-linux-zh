The most common types of point-to-point links are the ones used to connect to the Internet. When you use DSL^1 (digital subscriber), you are using a point-to-point link to connect to the Internet. Serial lines, such as T-1, T-3, ATM links, and ISDN, are all point to point. # Switched

A switch is a device that establishes a virtual path between source and destination hosts such that each path appears to be a point-to-point link, like a railroad roundhouse. The telephone network is a giant switched network. The switch brings up and tears down virtual paths as hosts need to communicate with each other. Each host thinks that it has a direct point-to-point path to the host it is talking to. In contrast with a mesh network, each host also sees traffic for other hosts. The advantage of a switched network over a pure point-to-point network is that each host requires only one connection: the connection to the switch. Using pure point-to-point connections, each host must have a connection to every other host. Scalability is provided by further linking switches.

# LAN: Local Area Network

Local networks (LANs) are confined to a relatively small area—a computer facility, building, or campus. Today most LANs run over copper or fiberoptic cable, but other, wireless technologies, such as infrared (similar to most television remote control devices) and radio wave, are becoming more popular.

If its destination address is not on the local network, a packet must be passed on to another network by a router (page 357). A router may be a general-purpose computer or a special-purpose device attached to multiple networks as a gateway way among them.

# Ethernet

A GNU/Linux system connected to a LAN usually connects to the network using Ethernet. A typical Ethernet connection can support data transfer rates from 10 megabits per second to 1 gigabit per second, with speed enhancements planned.
