An important feature of POSIX.2 locales is that they are fragmented into categories. The standard specifies six locale categories and defines six environment variables corresponding to these categories (Table D-2).

# ## Environment Variable Table D-2

| Environment Variable | Description |
|---|---|
| LC_TYPE | Describes which characters are considered alphabetic, numeric, punctuation, blank, and so on, and describes the mapping of uppercase to lowercase and versa |
| LC_COLLATE | Describes the order of characters for sorting |
| LC_TIME | Describes abbreviated and full names for months and days of the week, local equivalents of A.M. and P.M., appropriate date representation, and appropriate 12- and 24-hour representation |
| LC_NUMERIC | Describes the character to use as a decimal point, the character to separate groups of digits (such as the comma in 65,536), and the number of digits in a group |
| LC_MONETARY | Describes the currency symbol, where it is positioned, negative values are written, the currency decimal-point character, the number of fractional digits, and other details of how currency values are written |
| LC_MESSAGES | Describes the formats of informative and diagnostic messages and interactive responses, and expressions to be interpreted as yes and no responses for those who use the query

Two more environment variables (LC_ALL and LANG) interact with these six to provide overrides and defaults. If LC_ALL is set, then its value is used in place of any of the other six LC_* variables. If LANG is set, then its value is used in place of any LC_* variable that is not set.

Each of these environment variables can be set to a value that will cause features of the shell and some utilities to change behavior. For example, here is a fragment of a shell session on a system with POSIX.2 inter-

```
$ LC_TIME=POSIX
$ date
Thu Aug 21 21:21:03 2003
$ LC_TIME=Fr_FR # French
$ date
Jeu Ao 21 21:21:12 PDT 2003
```
