# Alternative Syntax for Control Structures

Unlike the other shells, the Z Shell provides several different syntaxes for many commands, often to provide a form similar to tsh/esc. The forms of control structures that match the syntax of tsh/esc follow.

The for structure has the following alternative syntaxes:

```
foreach name ( word ... )
  commands
end
```

or

```
for name (word ... ) {
  commands
}
```

The while structure can be written as follows:

```
while ( command ) {
  commands
}
```

# Option Processing

The way that a utility interprets its command line is up to the specific utility. However, most GNU/Linux utilities conform to certain conventions. Refer to “The Command Line” on page 137. In particular, any option the utility takes is indicated by a letter preceded by a hyphen:

```
zsh % 1s -l -r -t
```

(Refer to page 1235 in Part III for more information on ls.). The options usually must precede other arguments, such as filenames. Most utilities accept options that are combined behind a single hyphen. The previous command can also be written as

```
zsh % 1s -lrt
```

Some utilities have options that themselves require arguments. The cc and gcc utilities have a -o option that must be followed by the name you want to give the executable file that is being generated. Typically, an argument to an option is separated from its option letter by a SPACE:

```
zsh % gcc -o prog prog.c
```

In the same manner the -o option to the set builtin takes an argument. The next command turns on the EXTENDED_GLOB option, which treats #, ~, and ^
