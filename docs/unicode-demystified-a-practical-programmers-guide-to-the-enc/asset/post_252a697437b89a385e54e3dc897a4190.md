page 618. The expansions take place in a specific order. The common expansions, in the order in which they occur, are parameter expansion, variable expansion, command substitution, and pathname expansion. Surrounding a word with double quotation suppresses all parameter and variable expansion. Single quotation marks suppress all types of expansion, as does quoting (escaping) a special character by preceding it with a backslash.

## Exercises

1. The following script adds entries to a file named journal in your home directory. The script can help you track of conversations and meetings:

```
# journal
file=$HOME/journal
date >> $file
echo -n "Enter name: "
read name
echo "$name" >> $file
cat $file
```

a. What do you have to do to the script in order to be able to execute it?
b. Why does it use the read builtin the first time and cat utility the second time?

2. What are two ways you can execute a script when you do not have execute permission? Can you execute if you have read access?

3. What is the purpose of the PATH variable?

a. Set up your PATH variable so that it causes the shell to search the following directories:
- /usr/local/bin
- /usr/bin/X11
- /usr/bin
- /bin
- /usr/openwin/bin

b. If a file named whereis in /usr/bin and also in ~/bin, which one does whereis indicate will be executed? (Assume you have execute permission for both of the files.)
c. If your PATH variable is not set to search the working directory, how can you execute a program located there?
d. What command can you use to add the directory /usr/games to the end of the list of directories in PATH?
