# Files That Grow Quickly

Some files, as log files and temporary files, grow automatically over time. Core
dump files take up space and are rarely needed. Also, users occasionally run pro-
grams that accidentally generate huge files. As the system administrator, you must
review these files periodically so that they do not get out of hand.

If a filesystem is running out of space (that is, over a period of an hour
rather than weeks or months), first figure out why it is running out of space. Use a
sp -ef command to determine whether a user has created a runaway process that is
creating a huge file. In the output of ps, look for a process that has used
large amount of CPU time. If such a process is running and creating a large file,
t file will continue to grow as you free space. If you remove the huge file, the\yspace occupied will not be freed until the process terminates, so you need to kill
t process. Try to contact the user running the process, and ask the user to kill it.
you cannot contact the user, log in as root and kill the process. Refer to kill in Part
III for more information.
