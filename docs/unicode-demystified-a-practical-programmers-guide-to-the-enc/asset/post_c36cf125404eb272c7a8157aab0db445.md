
# Expressions

You can use an arithmetic expression as an argument to a command or in place of any numeric value. An arithmetic expression is enclosed between $(( )) and does not need to be enclosed in quotation marks, as the Z Shell does not perform filename expansion within the $(( and)). This feature makes it easier for you to use an asterisk (*) for multiplication, as the following example shows:

```zsh
zsh % echo There are $((60*60+24*365)) seconds in a non-leap year.
There are 31536000 seconds in a non-leap year.
```

You can use $[ and ] in place of $(()):

```zsh
zsh % echo There are $[60*60*24*366] seconds in a leap year.
There are 31622400 seconds in a leap year.
```

# Fewer Dollar Signs ($)

When you use variables within $(( and )), the dollar signs preceding individual variable references are optional:

```zsh
zsh % x=23 y=37
zsh % echo $((2*$x + 3*$y))
157
zsh % echo $((2*x + 3*y))
157
```

The preincrement, postincrement, decrement, and postdecrement operators work with the variables. The pre-- operators, which appear in front of the variable name, as in ++COUNT and --VALUE, first change the value of variable (++) adds one; subtracts one and then provide the result for use in the expression. The post-- operators appear after the variable name, as in COUNT++ and VALUE--, provide the unchanged value of the variable for use in the expression and then change the value of the variable:

```zsh
zsh % ((N=10))
zsh % echo "$N"
10
zsh % echo "$((-N+3))"
12
zsh % echo "$N"
9
zsh % echo "$(N++ - 3))"
6
zsh % echo "$N"
10
```

The && (AND) and || Boolean operators are called short-circuiting operators. If the result of using one of these operators can be decided by looking only at the left operand, the right operand is not evaluated. The && operator causes the Z Shell to test the exit status of the command preceding it. If the command succeeds, zsh executes the next command; otherwise it skips the remaining commands on the command line. You can use this construct to execute commands conditionally:

```zsh
zsh % mkdir bkup && cp -r src bkup
```

This compound command creates the directory bkup. If mkdir succeeds, the contents of directory src is copied recursively to bkup.

The || separator causes the Z Shell to test the exit status of the first command but has the opposite effect: The remaining command(s) are executed only if the first one failed (that is, exited with nonzero status):

```zsh
zsh % mkdir bkup || echo "mkdir of bkup failed" >> /tmp/log
```

The exit status of a command is the exit status of the last command executed. You can group lists with parentheses. For example, you can combine the previous two examples as

```zsh
zsh % mkdir bkup && -r src bkup || echo "mkdir failed" >> /tmp/log
```

In the absence of parentheses, && and || have equal precedence and are grouped left to right. The following two commands yield an exit status of 1 (false):

```zsh
zsh % true || false && false
zsh % echo $?
1
zsh % (true || false) && false
zsh % echo $?
1
```

Similarly the next two commands yield an exit status of 0 (true):

```zsh
zsh % false && false || true
zsh % echo $?
0
zsh % (false && false) || true
zsh % echo $?
0
```

See page 588 for a description of the $ variable.
Because the expression on the right side of a short-circuiting operator may never get executed, you must be careful with assignment statements in that location. The following example demonstrates what can happen:

```zsh
zsh % ((N=10))
zsh % ((Z=0))
zsh % echo $((N || (Z+=1)))
1
zsh % echo $Z
```

Because the value of N is nonzero, the result of the || (OR) operation is 1 (true), no matter the value of the right side is, so the ((Z+=1)) is never evaluated, and Z is not incremented.

The pipe symbol has highest precedence of all operators. You can use pipes anywhere in a command that you can use simple commands. The command line

```zsh
zsh % cmd1 | cmd2 || cmd4 && cmd5 && cmd6
```

is interpreted as if you had typed

```zsh
zsh % ((cmd1 | cmd2 || cmd4 && cmd5 && cmd6))
```
