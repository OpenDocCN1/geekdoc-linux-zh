On the two lines, each command is represented by a single highlighted character, displayed to the left of the command's name.

You can execute a pine command in two ways. You can press the key corresponding to the character to the left of the command you want to execute. For the general commands appearing in the middle of the screen, you can use the ARROW keys (or N for next and P for previous) to position the cursor over the command you want and then RETURN to execute the command.

Because the Main menu has many commands to fit in the display at the bottom of the screen, the O (other) command provides a way to view the additional entries. Enter O to view another two-line display. These two-line displays comprise the full set of commands that are active for the Main menu; the O command also takes you back to the original two-line display.

The basic format of the Main menu appears throughout the pine screens: a status line at the top and a two-line display at the bottom of the screen. The O command is available, if necessary, to view additional commands, and help text is available at strategic points along the way. In most screens the M command puts you back in the Main menu, and Q closes (quits) pine.
