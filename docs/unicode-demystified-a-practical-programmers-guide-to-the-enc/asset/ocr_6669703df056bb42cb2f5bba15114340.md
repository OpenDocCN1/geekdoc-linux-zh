remote system prompts Alex to enter a password because he is logging in using a user name different from the one he uses on the local system.

```
$ who am i
alex tty06      Oct 14 13:26
$ rlogin -l watson bravo
Password:
```

If the local computer is named hurrah, a .rhosts file on bravo like the following allows the user alex to log in as the user watson without entering a password:

```
$ cat /home/watson/.rhosts
hurrah alex
```
