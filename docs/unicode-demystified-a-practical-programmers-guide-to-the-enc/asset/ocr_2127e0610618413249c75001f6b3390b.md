Most options for tar can be given either in a short form (a single letter) or as a descriptive word. Descriptive-word options are preceded by two dashes, as --help. Single-letter options can be combined into a single command line and do not need to be preceded by a dash (for consistency with other utilities, it is good practice to use the dash anyway).

Although the following two commands look quite different, they specify the same options in the same order. The first version combines single-letter options into a single command line argument, whereas the second version uses descriptive words for the options:

```
# tar -ztvf /dev/st0
# tar --gzip --list --verbose --file /dev/st0
```

Both commands use tar to generate a (v, verbose) table of contents (t, list) from the tape or /dev/st0 (f, file), using gzip (z, gzip) to decompress the files. Unlike the original UNIX tar, the GNU version strips the leading / from absolute pathname. The options in Table 17-14 tell the tar program what you want it to. You must include exactly one of these options whenever you use tar.

| tar Option | |
| --- | --- |
| --append (-r) | Appends files to an archive |
| --catenate (-A) | Adds one or more archives to the end of an existing archive |
| --create (-c) | Creates a new archive |
| --delete | Deletes files in an archive (not on tapes) |
| --dereference (-h) | Follows symbolic links |
| --diff (-d) | Compares files in an archive with disk files |
| --extract (-x) | Extracts files from an archive |
| --help | Displays a help list of tar options |
| --list (-t) | Lists the files in the archive |
| --update (-u) | Like the -r option, but the file is not appended if a newer version is already in the archive |
