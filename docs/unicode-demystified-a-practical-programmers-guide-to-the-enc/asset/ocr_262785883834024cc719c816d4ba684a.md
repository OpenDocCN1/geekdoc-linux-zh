Very brief description of what the utility does
Following the syntax-line is one or more paragraphs that describe the utility. The syntax-line shows how to run the utility from a command line. Options and arguments enclosed in brackets [] are not required. Type words that appear in this sans serif italic typeface as. Words that you must substitute when you type, appear in this bold sans italic typeface. Hyphenated words listed as arguments identify single arguments (for example, source-file) or groups of arguments (for example, directory-list). As an example, file-list means a list of one or more files.

Arguments This section describes the arguments that you can use when you run the utility. The argument itself, as shown in the preceding syntax-line, is printed in this bold sans italic typeface.

Options This section lists the common options you can use with the command. Unlike otherwise, you must precede options with a hyphen. Most commands accept a single hyphen before multiple options (page 139). The following are some sample options:

+   - toc This is an example of a simple option preceded by a single dash and not followed by any arguments. The toc appearing as the first word of the description is a cue, a suggestion of what the option stands for. It stands for toc, or of table of contents.

+   - program-file Includes an argument. The argument is set in bold sans italic type in both the heading to the left and the description to the right. You substitute another word (filename, string of characters, or other value) for any arguments you use in this typeface. Type characters that are in bold sans serif type (such as the -f to the left) as is, letter for letter.

+   - make-directories This is an example of an option that has a long and a short version. You can tell that the -d at the beginning of the description is not a cue to what the option means because it is preceded by a hyphen and does not look like a cue. In addition, the long option clearly spells out the meaning of the option—there is no need for a cue.
