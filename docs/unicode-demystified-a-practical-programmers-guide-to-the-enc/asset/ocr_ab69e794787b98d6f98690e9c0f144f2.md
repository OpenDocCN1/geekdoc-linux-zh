# 1346 tar

--modification-time -m Sets the modification time to the time of extraction. Without this option tar at- tempt to maintain the modification time of the original file.

--one-file-system -I When a directory name appears in file-list while reading files for an archive, tar recursively processes the files and directories below the named directory. With this option tar stays the filesystem the named directory is in does not read files and directories that exist on other filesystems.

--sparse -S GNU/Linux allows you to have sparse files on disk. These are large, mostly empty files. The empty sections of sparse files do not take up any disk space. When tar copies one of these sparse files out of an archive, it normally expands to its full size. When you restore a sparse file from a tar backup, the file takes up its full space and may no longer fit in the same disk space as the original. option causes tar to handle sparse files efficiently so that they do not take un- cess space in the archive or when they are extracted.

--tape-length n -L As for a new tape after writing n*1,024 bytes to the current tape. This fea ture is useful when building archives that are too big to fit on a single tape. When combined with the -t option, -v causes tar to display a more detailed list of the files, showing ownership, permis- size, and other useful information for files in the archive.

# Notes

The GNU/Linux version of tar was developed by the GNU project and includes a large number of options and modifiers. Only the most commonly used options and modifiers are presented here. The --help option displays all the options and modi- ers. The info page on tar is extensive, including a tutorial.

You can use ambiguous file references when you write files but not when you read them.

The name of a directory file within the file-list references all files and subdirect- ries within that directory.

The file that tar sends its output to by default is compilation specific; typically it goes to standard output. Use the -f option to specify a different filename or device to hold the archive.

If you write a file using a simple filename, the file appears in the working dir- tory when you read it. If you write a file using a relative pathname, the file ap- pears with that relative pathname, starting from the working directory when you read it. If you use the -P option and an absolute pathname to write a file, tar reads it back in the same pathname.

As you read and write files, tar attempts to preserve links between files. Unless you use the -h option, tar does not inform you when it fails to maintain a link.
