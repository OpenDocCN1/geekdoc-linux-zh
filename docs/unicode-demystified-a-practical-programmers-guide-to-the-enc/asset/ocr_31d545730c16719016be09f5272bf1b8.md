# Delete Command Examples (Continued)

| | |
| d4 | Deletes to end of fourth sentence |
| d( | Deletes to beginning of sentence |
| d) | Deletes to end of paragraph |
| dl | Deletes to beginning of paragraph |
| d7( | Deletes to seventh paragraph preceding beginning of paragraph |
| dd | Deletes the current line |
| d/text | Deletes forward in text up to but not including the next occurrence of word text |
| dfc | Deletes forward on current line up to and including next occurrence of character c |
| dtc | Deletes on current line up to the next occurrence of c |
| D | Deletes to the end of line |
| d$ | Deletes to the end of line |
| 5dd | Deletes five lines starting with the current line |
| dL | Deletes through last line on screen |
| dH | Deletes through first line on screen |
| d1G | Deletes through beginning of Work buffer |

# Exchange Characters and Lines

If two characters are out of order, position the cursor on the first character, and give the commands xp. If two lines are out of order, position the cursor on the first line, and give the commands ddp.
