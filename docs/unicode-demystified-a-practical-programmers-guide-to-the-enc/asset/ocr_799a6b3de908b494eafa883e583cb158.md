# The mail Environment

You can establish your mail environment by assigning values to mail variables by using the set command in ~/.mailrc. The set command has the following format:

```
set [name=value]|
```

The name is the name of the mail variable that you are setting, and the value is the optional value you are assigning to the variable. The value may be a string or a number. If you use set without a value, mail assigns the variable null (the values of some mail variables are not relevant; it is important only that they are set).

The following is a list of some of the more important mail variables.

+   ask Prompts for the subject of each message.

+   askcc Prompts for the names of people to receive copies of messages you send.

+   crit-number Assign number to this variable if you mail messages containing number or more lines be piped through the variable PAGER. If you are using a standard ASCII terminal, set number to 24. See the following.

+   dot If set, you can terminate mail messages by entering a period (.) on a line by itself. Unless ignoreoreof is also set, entering CONTROL-D on a line by itself still serves to terminate mail messages.

+   ignore Ignores interrupts while you are composing and sending messages. Setting ignore can make your job easier if you are working on a noisy telephone line.

+   record=filename Copies outgoing messages to filename.

+   ignoreoreof Causes mail not to save your messages in dead.letter when you quit mail while composing a message.

+   PAGER=pathname Sets the location to pathname for the pager you want mail to use for messages that do not fit on your screen. The default pager is.

+   VISUAL=editor Sets the editor you want mail to use when you give the ~ command while composing a message. The default editor is vi.
