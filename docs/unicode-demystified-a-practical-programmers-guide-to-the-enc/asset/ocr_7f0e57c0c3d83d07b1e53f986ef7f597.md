# Glossary

# RAM disk

RAM that is made to look like a (floppy) disk. RAM disk is frequently used as part of the boot (page 1457) process.

# RAS

Remote access server. In a network, a computer provides access to remote users via analog modem or ISDN connections. RAS includes the dial-up protocols and access control (authentication) and may be a regular file server with remote access software or a proprietary system, such as Shiva's LANRover. The modems may be internal or external to the device.

# RDF

Resource Description Framework. Developed by W3C (the main bodies for the World Wide Web), a standard that specifies a mechanism for encoding and transferring metadata (page 1479). RDF does not specify what the metadata should be or be. RDF can integrate many kinds of applications and data, using XML as an interchange syntax. Some examples of the kind of data that can be integrated are library catalogs and worldwide directories, synchronization and aggregation of news, software, and content, and collections of music and photographs. Go to w3.org/RDF for more information.

# redirection

The process of directing standard input for a program to come from a file rather than from the keyboard. Also, directing standard output or error to go to a file rather than the screen.

# reentrant

Code that can have simultaneous, interleaved, or nested invocations that do not interfere with one another. Noninterference is important for parallel processing, recursive programming, and interrupt handling.

It is usually easy to arrange for multiple invocations (that is, calls to a subroutine) to share one copy of the code and any readily data. But for the code to be reentrant, each invocation must use its own copy of any modifiable data. This is often achieved by using a stack and allocating local variables in a new stack frame for each invocation. Alternatively the caller may pass in a pointer to a block of memory that the invocation can use (usually for output), or the code may allocate some memory on a heap, especially if the data must survive the routine returns.
