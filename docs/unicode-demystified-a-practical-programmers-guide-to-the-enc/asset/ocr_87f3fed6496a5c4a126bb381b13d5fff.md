internally is converted into a number, manipulated, and then converted back to a string. A variable with the integer attribute is stored as an integer. This makes arithmetic much faster. Assign the integer attribute as follows:

```
zsh % typeset -i COUNT
```

The integer builtin is almost identical to typeset -i, the preceding example is the same as

```
zsh % integer COUNT
```

You can assign a base other than 10 to an integer variable. The Z Shell then uses this base to display the variable. The syntax is

```
typeset -i base variable
```

where base is the base you want to use to display the value. If the base is not 10, the value is displayed as base#value (in base 2 the 20 is written as 10100):

```
zsh % COUNT=20
zsh % typeset -i2 BCOUNT
zsh % BCOUNT=$COUNT
zsh % echo $COUNT $BCOUNT
20 #10100
```

The export attribute is similar to the export builtin (page 571). If a variable has this attribute, a copy of it is inherited by all child processes. The Z Shell exports the attribute and also provides typeset -X to set the export attribute. You can set the export attribute for functions as well as for variables; an export function is available in all subshells.

The Z Shell supports several variable attributes that are useful for formatting output. You can assign a particular width (number of columns) to a variable and specify that it is left- or right-justified within that width. Leading zeros can be added or suppressed.
