The following command outputs permissions of the files in the working directory. The utility with the -c option specifies that characters 2 through 10 are selected from each input line. The characters in this range are written to standard output:

```
$ ls -1 | cut -c2-10
total 148
rw-r--r--
rw-rw--r--
rw-rw--r--
rw-r--r--
-rw-rw--r--
rw-rw--r--
rw-rw--r--
```

The next command outputs the size and name of each file in the working directory. This time the -f option selects the fifth and ninth fields of the input lines. The -d option tells that SPACES, not TABS, delimit fields in the input. The tr command (page 1362) with the --s option counts sequences of more than one SPACE character into a single SPACE; otherwise, counts the extra SPACE characters as separate fields:

```
$ ls -1 | tr -s ' ' | cut -f5,9 -d ''
123 count
206 headers
72 memo
715 memos_save
14 tmp1
14 tmp2
218 typescript
```

The last example displays a list of full names stored in the fifth field of the /etc/passwd file. The -d option specifies that the colon character be used as the delimiter:
