The next example uses the numbers file and sums each of the columns in a file you specify on the command line. The example performs error checking, reporting and discarding rows that contain nonnumeric entries. The next command (thirteenth line) causes gawk to skip the rest of the current record and to read in another. At the end of the program, gawk displays a grand total for the file::

# $ cat numbers

| 10 | 20 | 30.3 | 40.5 |
| 20 | 30 | 45.7 | 66.1 |
| 30 | xyz | 50 | 70 |
| 40 | 75 | 107.2 | 55.6 |
| 50 | 20 | 30.3 | 40.5 |
| 60 | 30 | 45.0 | 66.1 |
| 70 | | 1134.5 | 70 |
| 80 | 75 | 107.2 | 55.6 |
| 90 | 176 | 30.3 | 40.5 |
| 100 | 1027.4 | 45.7 | 66.1 |
| 110 | 123 | 50 | 57a.5 |
| 120 | 75 | 107.2 | 55.6 |

# $ cat tally

  print "\nRecord " NR " skipped:\n"\n"
  print $0 "\n"
}
else {
  for (count = 1; count <= nfields; count++) {
    printf "%10.2f", $count > "tally.out"
    sum[count] += $count
    gtotal += $count
  }
