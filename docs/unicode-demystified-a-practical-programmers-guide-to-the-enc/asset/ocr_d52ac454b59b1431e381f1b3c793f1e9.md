# Deleting Text

The d command removes text from the Work buffer. The amount of text that d removes depends on the Repeat Factor and the Unit of Measure (page 460) you enter after the d. After the text is deleted, vim is still in Command mode.

> De dd to Delete a Single Line

The d command deletes two lines: the current line and the following one. Use the dd command to delete the current line, or precede dd by a Repeat Factor (page 463) to delete several lines.

You can delete from the current cursor position up to a specific character on the same line. To delete to the next semicolon (;), give the command dt; If you want to delete the remainder of the current line, use D or dS. Table 10-1 lists some Delete commands. Each command, except the last group that starts with dd, deletes from the current character.

| Delete Command Examples |
|---||
| dl | Deletes current character (same as the x command) |
| d0 | Deletes to beginning of line |
| d^ | Deletes to the first character of the line (not including spaces or tabs) |
| dw | Deletes to end of word |
| d3w | Deletes to end of third word |
| db | Deletes to beginning of word |
| dW | Deletes to end of blank-delimited word |
| dB | Deletes to beginning of blank-delimited word |
| d7B | Deletes to seventh previous beginning of blank-delimited word |
| d) | Deletes to end of sentence |
