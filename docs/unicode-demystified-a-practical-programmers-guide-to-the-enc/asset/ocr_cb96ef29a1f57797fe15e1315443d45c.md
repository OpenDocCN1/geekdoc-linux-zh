If the two are not already linked, click one of the view's link indicator until the small piece of chain link appears in both views. In the left view scroll (the right view will not move), and click the name of the section you want to look at. At this tutorial uses No boxed Set? No Problem! in Chapter 1 of the Installation Guide. The manual appears in both views: not too confusing.

Now lock the left view by clicking within the left view to make it active (do not click a link) and selecting Konqueror menubar: View>Lock to current location. Locking prevents this from changing, preventing the view from displaying the manual page when you click a link.

Now click the manual in the left window again. What happens this time? The left view is forced to stay the same, but the (linked) right view changes to display the manual page (Figure 8-19). Now you can search the table of contents for the Installation Guide in the left view; and when you want to view another section, you simply click it in the left view. This type of link is useful in many situations. You can work with your Web site by bringing up the directory structure, via ftp, in the locked view while the Web pages are displayed in the other view.

When you Konqueror set up the view you want for a particular purpose, you can put an icon on a panel that will open Konqueror that way.

+   1. Click Window>Configure View Profiles and enter the name of your profile Entering Profile Name to save the setup. For this tutorial enter your name newprofile. Make sure that Save Save URLs in profile and Save window size in profile both have check marks next to them. Click Save.

+   2. Attach this new profile name to a panel icon: Drag the Home icon from the K menu to a clear space on the panel. If there is no clear space, see page 339. The dragged icon is a copy; the original icon is still on the K menu.
