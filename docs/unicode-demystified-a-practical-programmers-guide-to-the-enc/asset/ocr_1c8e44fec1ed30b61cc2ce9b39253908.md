# Examples

The following example makes a copy of the /home/alex directory and all files and subdirectories within that directory onto a floppy tape device. The v modifier the command to list all the files it writes to tape as it proceeds. This command erases anything that was already on the tape. The message tar explains that the default action is to store all pathnames as relative paths instead of absolute paths, allowing you to extract the files into a different place on your disks:

```
$ tar -cvf /dev/ftape /home/alex
tar: Removing leading / from absolute path names in the archive.
home/alex/
home/alex/.zhenv
```

In the next example, the same directory is saved on the tape device /dev/st0 with a blocking factor of 100. Without the v modifier, tar does not display the list of files it is writing to the tape. The command runs in the background and displays any messages after a new prompt:

```
$ tar -cb 100 -f /dev/st0 /home/alex &\n[1] 4298
tar: Removing leading / from absolute path names in the archive.
```

The next command displays the table of contents of the archive on tape device /dev/ftape:

```
$ tar -tvf /dev/ftape
drwxrxr-x alex/group Jun 30 21:39 2004 home/alex/
-rw-r-- alex/group 678 Aug 6 14:06 2003 home/alex/.zhenv
-rw-r-- alex/group 571 Aug 6 14:12 2003 home/alex/mail/
drw------ alex/group 0 Nov 6 22:34 2003 home/alex/mail/
-rw------ alex/group 2799 Nov 6 22:34 2003 home/alex/mail/sent-mail
```

In the last example, Alex creates a gzipped archive in /tmp/alex.tgz. This is a common way to bundle files that you want to transfer over a network or otherwise share with others. Ending a filename with .tgz is a common convention for identifying gzipped archives. Another common convention is to end the file name with .tar.gz.

```
$ tar -czf /tmp/alex.tgz literature
```

The next command lists the files in the compressed archive alex.tgz:

```
$ tar -tzvf /tmp/alex.tgz
...
```
