# fdisk: Reports on and Partitions a Disk

The fdisk utility can report on and change partitions on a disk. When you first install Red Hat or when you add a new disk drive to a Red Hat system, you can let the installer partition the disk automatically, semiautom with your input, or manually by running fdisk (or Disk Druid, page 918) to divide the disk into partitions and to identify the type of each partition. The system normally generates the disk configuration information (number of cylinders, tracks, sectors/track, and more) automatically by querying the disk.

Partitions can be of two types: primary and extended. A hard drive can have up to four partitions or three primary partitions and an extended partition, which can have any number of partitions encapsulated within it. MS Windows must boot from a primary partition. GNU/Linux can boot from an extended partition by using a boot loader (page 1039); however, the /boot partition must usually reside completely below cylinder 1023 of the disk.
