The cron utility provides an easy-to-use GUI for cron, allowing you to create and modify your crontab file or a crontab file for any user who are Superuser. Scheduling tasks with cron is a matter of clicking buttons (Figure 17-15).
Run cron when you are logged in as yourself to view and modify your personal crontab file. When you run cron as root, you can modify any crontab file on the system. To start with, cron displays a window that lists Users (when you are running as root), Tasks, and Variables. This description of this window is wide and will probably not fit entirely on your screen. The right-left scroll bar to view its contents. To create a new crontab entry, highlight Tasks, and select New from Edit on the menus. To modify an entry, highlight the entry, and select Modify from Edit on the menus. From the resulting window enter the name of the program you want to run in the Program text box, and press buttons or check marks corresponding to the dates and times you want to run the program. Unless you redirect it, from the program that cron runs is mailed to you.
