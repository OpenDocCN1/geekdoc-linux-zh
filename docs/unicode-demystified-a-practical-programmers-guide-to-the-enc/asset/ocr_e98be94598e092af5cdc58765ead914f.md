The next example shows how the man utility can be used to find the man pages
that pertain to a certain topic. In this case -k7 displays man page headers co-
taining the string latex:

# $ -k latex

+   Pod::LaTeX (3pm) - Convert Pod data to formatted Latex
einitex [latex] (1) - extended Tex
elatex [latex] (1) - structured text formatting and typesetting
etatex [latex] (1) - extended Tex
evirtex [latex] (1) - extended Tex
lambda [latex] (1) - structured text formatting and typesetting
latex (1) - structured text formatting and typesetting

The search for the keyword entered with the -k option is not sensitive. Al-
ough keyword entered on the command line is all lowercase, it matches the
first header, which contains the string LaTeX (upper- and lowercase). The 3pm on the
first line indicates that the man page is from Section 3 (Subroutines) of the
GNU/Linux System Manual and comes from the Perl Programmers Reference
Guide (it is a Perl8 subroutine).
