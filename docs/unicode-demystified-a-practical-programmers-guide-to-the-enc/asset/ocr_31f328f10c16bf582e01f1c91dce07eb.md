# Run Command

To run a character-based program display the Run Command window by selecting Run Command from the K menu or from any of several other menus or pressing ALT-F2. Enter the name of the program in the Command text box, click Options, put a check mark in the Run in terminal box, and click Run. KDE runs the program in a Terminal Emulator window. When you run telnet in this manner, you see the telnet- prompt in a new window. Enter quit, telnet finishes, and the window closes.
