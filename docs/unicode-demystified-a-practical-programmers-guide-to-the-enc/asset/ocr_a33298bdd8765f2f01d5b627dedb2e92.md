function mycp
{
  case $# in
    0)    exec 3<&4 &&1 ;;
    1)    exec 3<$ $1 &&4 ;;
    2)    exec 3<$ $4 >$2 ;;
    *)   print "Usage: mycp [source] [dest]"
        exit 1;
  esac
```

The real work of this function is done in the line that begins with `cat`. The rest of the script arranges for file descriptors 3 and 4, which are the input and output of the cat command, to be associated with the right file.

The next program takes two filenames on the command line and sorts both to temporary files. The program merges the sorted files to standard output, preceding each by a number that indicates which file it came from.

The Z Shell does not have string comparison operators for less than or equal to greater than or equal to. You can not greater than, as in this example ([[ "$Line1" > "$Line2 ]] in the if statement), as an equivalent for less than or equal to:

```
zsh % cat sortmerge
!/bin/zsh
usage()
{
if [[ $# -ne 2 ]];
then
print -u2 "Usage: $0 file1 file2"
exit 1
fi
# Default temporary directory
: ${TMPDIR:=/tmp}
# Check argument count
uage "$@"
# Set temporary files for sorting
file1=$TMPDIR/file1.$
file2=$TMPDIR/file2.$
# Sort
sort $1 > $file1
sort $2 > $file2
# Open files $file1 and $file2 for reading. Use FD's 3 and 4.
exec 3<$file1
exec 4<$file2
# Read the first line of each file to figure out how to start.
read -u3 Line1
Status1=$?
read -u4 Line2
Status2=$?
