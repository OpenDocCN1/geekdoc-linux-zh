# Shading a Window

When you double-click the titlebar (page 181) or click Shade in the Window Operations menu, the window rolls up like a window shade, with only the titlebar visible. Double-click the titlebar or click Shade in the Window Operations menu again to restore the window.

KDE offers shade-hover mode which keeps shaded windows that you want shaded unless the mouse pointer is over that window. In this mode few windows clutter your desktop; there are just shaded windows. When the mouse hovers over the titlebar of a shaded window for a short time, such as one-quarter second, the window unshades. When you move the mouse pointer over the window, it immediately shades. In order to put a window in shade-hover mode, you must shade it manually. After that, the shading and unshading are automatic. This mode is controlled by K Menu: Preferences⇨Look & Feel⇨Window Behavior⇨Enable Hover (page 325).

# Session Manager

A session starts when you log in and ends when you log out or reset the session. With a fully compliant GNOME or KDE application, these desktop managers manage your data. When you run a managed session, the desktop looks pretty much the same when it did when you logged out the previous time. The data in this case includes not only the data that the application manipulates but also the state of the application when you end your session: what windows were open and where they were located, what each of the applications was doing, and so forth.

If you want to start an application each time you log in, regardless of whether it was running when you logged out, refer to “Autostart” on page 346 (KDE).
