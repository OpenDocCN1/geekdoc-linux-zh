# Value of n

| | |
| b | The file is a block special file. |
| c | The file is a character special file. |
| d | The file is a directory file. |
| e | The file exists. |
| f | The file is an ordinary file. |
| g | The file has the set-group-ID bit set. |
| k | The file has the sticky bit set. |
| l | The file is a symbolic link. |
| o | The user owns the file. |
| p | The file is a named pipe (FIFO). |
| r | The user has read access to the file. |
| s | The file is not empty (has nonzero size). |
| S | The file is a socket special file. |
| t | The file descriptor (a single digit) is open and connected to a terminal. |
| u | The file has the set-user-ID bit set. |
| w | The user has write access to the file. |
| x | The user has execute access to the file. |
| X | The file is either a builtin or an executable found by searching the directories in Spath. |
| z | The file is 0 bytes long. |

If the specified file does not exist or is not accessible, test evaluates the expression as 0. If the result of the test is true, the expression has a value of 1; if it is false, the expression has a value of 0.
