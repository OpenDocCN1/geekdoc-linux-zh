# Moving the Cursor by Lines

Pressing CONTROL-A moves the cursor to the beginning of the line it is on; CONTROL-E moves it to the end. Pressing CONTROL-P moves the cursor up one line to the position directly above where cursor started; CONTROL-N moves it down. With the other cursor-movement keys, you can precede CONTROL-P and CONTROL-N with CONTROL-U and a numeric argument to move up or down multiple lines. You can use pairs of these commands to move the cursor up to the beginning of the previous line, down to the end of the following line, and so on (Figure 11-5).

# Moving the Cursor by Sentences, Paragraphs, and Window Position

Pressing META-A moves the cursor to the beginning of the sentence cursor is on; META-E moves the cursor to the end. META-U moves the cursor to the beginning of the paragraph cursor is on; META-L moves it to the end. You can precede any of these commands by a repetition count (CONTROL-U and a numeric argument) to move the cursor that many sentences or paragraphs.
