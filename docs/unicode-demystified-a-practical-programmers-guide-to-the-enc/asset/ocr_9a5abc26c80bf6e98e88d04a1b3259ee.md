# A Bad .xinitrc or .xession File Can Hang Your System || caution

Be careful when experimenting with your .xinitrc or .xession file; if the file contains an error (example, leaving the & off a command line), the X server may not start properly. If this happens, terminate the X server by pressing CTRL-ALT-BACKSPACE, and fix the problem.

# .Xdefaults

Although is convenient to specify command line attributes for a few applications in a .xinitrc or .xession file, it is awkward to type complicated option specifications on a command line each time you start a new session during the course of your. You may also find that you always want to run certain applications with the same options such as xterm without a scrollbar. To run utilities/programs with the same options consistently, you can store your preferences in ~/.Xdefaults. The format of each line of .Xdefaults is

```
name-of-application*name-of-resource: value
```
