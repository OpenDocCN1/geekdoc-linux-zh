# Panels

The KDE Main panel (kicker) and extension panels were introduced on page 276. A panel (Main or extension) houses buttons (icons with no handles) and applets (with handles). Left click a button to start the program associated with it. Right click a button to bring up a menu that includes the Panel menu (following) and other choices.
