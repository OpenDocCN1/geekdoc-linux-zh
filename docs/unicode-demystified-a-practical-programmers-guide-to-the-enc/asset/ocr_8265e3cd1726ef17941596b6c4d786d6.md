This change affects all runlevels and will stay in effect through changes in runlevels and reboots unless you change it again.

+   - Controls future execution of independent services in runlevels 3, 4, and 5. Select the runlevel you want to affect, using the Edit Runlevel selection from the menubar. Highlight an independent service, and click the box next to it indicate whether you want the service on or off the runlevel specified. Click the Save button. When you enter that runlevel in the future, the service will be on or off as you specified. The current state of the service is not changed. Select the first item in this list when you want to change the current state of the service.

# chkconfig: Config Services III

The chkconfig character-based utility duplicates much of what redhat-config-services does: it makes easier for a system administrator to maintain the /etc/rc.d directory hierarchy. This utility can add, remove, start-up information, and check the state of system services. To see a list of all services, give the following command:

```
# chkconfig --list
hcrelay  0:off  2:off  3:off  4:off  5:off  6:off
dhcpd   0:off  1:off  2:off  3:off  4:off  5:off
syslog   0:off  1:off  2:on  3:on  4:on  5:off
atd     0:off  1:off  2:off  3:on  4:on  5:off
gpm     0:off  1:off  2:off  3:on  4:on  5:off
```

```
xineted based services:
charger:     off
rsync:      off
charger:     off
daytime-udp: off
daytime:     off
```

All the services that run their own daemons are listed, one to a line, followed by their configured state for each runlevel. Following that, chkconfig displays each of the xineted-based services and their current status. You can check on a specific daemon by adding its name to the previous command:

```
# chkconfig --list ssh
sshd     0:off  1:off  2:on  3:on  4:off  5:on  6:off
```

In the next example, chkconfig configures the /etc/rc.d hierarchy so that sshd will be off in runlevels 2, 3, 4, and 5 and confirms the change.

```
# chkconfig --level 2345 sshd off
# chkconfig --list sshd
sshd     0:off  1:off  2:off  3:off  4:off  5:off  6:off
```
