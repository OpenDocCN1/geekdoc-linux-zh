The lines after the comment and blank lines define symbolic names for many
modules. For example, the following line defines the name world to be an alias for
the root of the CVS repository:

```
world -a
```

You can use such names in CVS commands as the names of modules, so the-
command checks out the entire repository (probably not a good idea):

```
$ cvs checkout world
```

In the sample modules file shown, the administrative files have been given def-
itions that attach a symbolic name to the file and an action (-i mkmodules)
to take when each file is checked into the repository. The -i mkmodules action
causes CVS to run the mkmodules program when the file is checked in. This pro-
gram ensures that a copy of the checked-in file exists in a location where CVS can
locate it.

Following the action is the name of the subdirector in CVSROOT the
file (or files) associated with the symbolic name are located. Any remaining argu-
ments on the line are the names of specific files within directory.

The following line identifies the name CVSROOT as the module name for the
module in the directory $CVSROOT/CVSROOT; that is, all of the administrative files
for CVS:

```
CVSROOT -i mkmodules CVSROOT
```

Similarly, the following line associates the module named modules with the modules
file within the CVSROOT directory:

```
modules -i mkmodules CVSROOT modules
```

This line allows the following command to find and check out the modules file:

```
$ cvs checkout modules
```

The last set of lines in the sample modules file associate symbolic module names
with directories and files in the repository.

# Using tkcvs

The CVS utility is useful enough that an X System interface, tkcvs, has
written for it, using the Tk extension to the Tcl programming language
(tcl.sourceforge.net). This utility provides a convenient point-and-click interface to
CVS (Figure 16-8). After you have downloaded and installed tkcvs, start it by us-
ing cd change to the directory you want to work in and entering the following
command:

```
$ tkcvs &
```
