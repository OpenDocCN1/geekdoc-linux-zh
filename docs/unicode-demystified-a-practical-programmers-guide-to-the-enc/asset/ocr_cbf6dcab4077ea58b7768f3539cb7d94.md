When you are writing a longer gawk program, it is convenient to put the program in a file and reference the file on the command line. Use the -f option, followed by the name of the file containing the gawk program.

The following gawk program, named pr_header, has two actions and uses the BEGIN pattern. The gawk utility performs the action associated with BEGIN before processing any of the data lines: It prints a header. The second action, {print}, has no pattern part and prints all the lines in the file:

```
$ cat pr_header
{print "Make Model Year Miles Price"}
{print}
```

In the previous and following examples, the whitespace is composed of single TABs, so that the titles line with the columns of data:

```
$ cat pr_header2
BEGIN {
  print "Make Model Year Miles Price --"
  print "--------------------------"
}
{print}
```
