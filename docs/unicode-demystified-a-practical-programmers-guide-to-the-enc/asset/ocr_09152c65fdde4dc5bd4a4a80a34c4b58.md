This use of keys had some problems. Many keyboards had no META key, and some operating systems discarded the META bit. The emacs character set clashes with XON-XOFF flow control, which also uses CONTROL-S and CONTROL-O and continues to do so today.

The flow-control problem still exists, the META key was resolved by making it an optional two-key sequence with ESCAPE. For instance, you can type ESCAPE-a in place of META-a or ESCAPE CONTROL-a to get CONTROL-a. If your keyboard does not have a META or ALT key, you can use the two-key ESCAPE sequence by pressing the ESCAPE key, releasing it, and then pressing the META key in this book. For example, when this book says press META-r you can either press the META or ALT key while you press r or release ESCAPE and press r.

An aside on notation: This book uses an uppercase letter following the CONTROL key and a lowercase letter following the META key. In either case you not ever have to hold down the SHIFT key while entering CONTROL or META character. The META uppercase character (that is, META-A) is a different character, it is usually set up to cause no action or the same effect as its lowercase counterpart.

# Key Sequences and Commands

In the relationship between key sequences (one or more keys that are pressed together or in sequence to issue an emacs command) and commands is very flexible, and there is considerable opportunity for exercising your personal preference. You can translate and remap key sequences to other commands and replace or reprogram commands themselves.

Most emacs documentation glosses over all the details and talks about keystrokes as though they were the commands, it is important to know that the underlying machinery is separate from the key sequences and to understand that the behavior of the key sequences and the commands can be changed (page 515).

# META-x: Running a Command without a Key Binding

The emacs keymaps (the tables, or vectors, that emacs uses to translate sequences to commands [page 517]) are very crowded, and often it is not possible to bind every single command to a key sequence. You can execute any command by name by preceding it with META-x. The emacs editor prompts you for a command in the Echo Area and executes the command after you enter, the command name and press the return key.
