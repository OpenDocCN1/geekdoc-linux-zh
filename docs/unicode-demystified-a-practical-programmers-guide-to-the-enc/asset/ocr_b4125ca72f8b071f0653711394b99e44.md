# tty

Displays the terminal pathname

tty [option]

The tty utility displays the pathname of standard input if it is a terminal and displays a tty if it is not. The exit status is 0 if standard input is a terminal and 1 if it is not.

# Arguments

There are no arguments.

# Options

+   --silent or -s Causes tty not to print anything. The exit status of tty is still set, however.
--quiet

# Notes

The term tty is short for teletypewriter, the terminal device that UNIX was first run from. This command appears in UNIX, and GNU/Linux has kept it for the sake of consistency and tradition.

# Example

```
$ tty
/dev/tty1
$ echo $?
0
$ tty < memo
not a tty
$ echo $?
1
```
