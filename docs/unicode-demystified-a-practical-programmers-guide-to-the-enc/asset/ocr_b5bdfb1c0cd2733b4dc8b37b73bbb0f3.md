You can pass this information to grub by using the command line or menu interface. When you boot the system, grub displays a menu of choices that is generated by the /boot/grub/grub.conf file or your symbolic link,/etc/grub.conf. At this point you can modify the menu, choose which operating system to boot, or do nothing and allow grub to boot the default system.

When you install a Red Hat Linux system, you have the choice of using grub or lilo. Whichever you choose, the installer installs both programs, allowing you to switch boot loaders without loading any new software. With lilo, you in-stall grub at the time you install GNU/Linux on your machine, the installation program configures and you do not have to.

The /boot/grub/grub.conf file is the default grub configuration file and is similar to /etc/lilo.conf. The grub file following is a system that has its kernel replaced using RHN (page 936). The system has a separate boot partition that all kernel and initrd (for systems usingable modules, page 1038) image paths are relative to /boot/ (see the NOTICE in the file). Without a separate boot partition, the boot files resides in the root partition (/) that kernel and initrd paths are relative to /. (Thus you would specify the kernel as vmlinuz-version replacing kernel with your system's kernel name and version with your version number.)

The file starts with comments that Anaconda, the graphical installer, puts there, followed by two assignments. The default is the section of the default boot specification. The numbering starts with 0. The following example includes two boot specifications. The first, numbered 0, is for the 2.4.9-13 kernel, the second, numbered 1, is for the 2.4.7-10 kernel. The timeout is the number of seconds that grub waits after it prompted you for a boot specification before it boots the system with the default boot specification. The splashimage is the grub menu interface background you see when you boot the system.

```
$ /etc/grub/grub.conf
# grub.conf generated by anaconda
#
# Note: you do not have to rerun grub after making changes to this file
# NOTICE:
# You have a /boot partition. This means that
# all kernel and initrd paths are relative to /boot/, eg.
# root (hd0,0)
# kernel=/vmlinuz-version ro root=/dev/hda9
# initrd=/initrd-version.img

default=0
timeout=10
splashimage=(hd0,0)/grub/splash.xpm.gz
```
