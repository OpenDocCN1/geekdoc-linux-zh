You can use printf (page 1991) to refine the output format. The following example uses a backslash at the end of a program line to make the newline from gawk. You can use this technique to continue a long line over one or more lines without affecting the outcome of the program.

# $ cat printf_demo

```
BEGIN {
    print ""
    print "Make          Model      Year      (000)     Price"
    print "\"
    if ($1 ~ /ply/) $1 = "plymouth"
    if ($1 ~ /chev/) $1 = "chevrolet"
    printf "-%10s %8s   %192d %5d   $ %8.2f\n", \
	           $1, $2, $3, $4, $5
}
```
