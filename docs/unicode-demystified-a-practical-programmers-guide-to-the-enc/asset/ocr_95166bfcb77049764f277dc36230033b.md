# Which Shells Does This Chapter Cover?

This chapter is slanted towards the Bourne Again Shell, with notes and page references where the TC or Z Shell differs. Specifically, "Writing a Simple Shell Script" (page 544), "Separating and Grouping Commands" (page 547), and "Processes" (page 560) apply to the three major shells.

Always make the Bourne Again Shell your primary root shell in single-user mode. All shell scripts are written to run under the Bourne Again Shell; if you will be working in single-user mode as you boot your system or system maintenance, administration, or repair work, it is a good idea to be familiar with this shell.

Without repeating the material in "Filename Generation/Pathname" on page 157 of Chapter 5, this chapter expands on the interactive features of the shell described in Chapter 5, explains how to create and run simple shell scripts, introduces the basic aspects of shell programming, and describes command line expansion. Chapter 14 covers interactive use of the TC and Z Shell programming, and Chapter 15 explores some of the Z Shell features that are absent from the Bourne Again Shell and presents more challenging shell-problems.

All the advanced shell chapters (12–15) discuss each of the shells as appropriate, giving page references for more details of a topic within a specific shell. The symbol indicates which a particular utility, built-in, or variable is a part of.

# If You Are New to All This

You may want to postpone reading the "Job Control" section (page 554) of this chapter and the sections beyond until you are comfortable creating and running simple shell scripts. However, you should read "Parameters and Variables" (page 566). Besides user-created variables, the shell maintains several keyvariables that control important characteristics of the shell.
