# nice

Changes the priority of a command

nice [option] [command line]

The nice utility reports the priority of the shell or alters the priority of a command line. An ordinary user can decrease the priority of a command. Only Superuser can increase the priority of a command. The TC Shell has a nice builtin that has a different syntax. Refer to “Notes."

The command line is the command line you want to execute at a different priority. Without any options or arguments, nice reports the priority of the shell running the nice command.

# Arguments

# Options

Without an option, nice defaults to an adjustment of 10, typically from 0 to 10. (As you raise the priority value, the nice command runs at a lower priority.)

+   - n value Changes the priority by an adjustment of value. The range of priorities is from -20 (the highest priority) to 19 (the lowest priority). A positive value lowers the priority, whereas a negative value raises the priority. Only Superuser can specify a negative value. When you specify a value past either end of this range, the priority is set to the limit of the range.

# Notes

The TC Shell has a nice builtin. Under test, nice ±value command line changes the priority at which command line is run. You must include the plus sign for positive values.

Higher (more positive) priority values means that the kernel schedules a job less often, whereas (more negative) values causes the job to be scheduled more often.

When Superuser schedules a job to run at the highest priority, it can impact the performance of the system for all other jobs, including the operating system itself. For this reason use nice with negative values carefully.

# Example

The following command executes find in the background at the lowest possible priority. The ps -l command displays the nice value of the command in the NI column:

```
# nice -n 19 find / -name core -print corefiles.out &
[1] 2610
# ps -l
F UID PID PPID C PRI NI ADDR SZ WCHAN TTY TIME CMD
100 S 0 1099 1097 0 75 0 605 wait4 pts/0 00:00:00 bash
100 R 0 2610 1099 0 99 19 634 - pts/0 00:00:03 find
100 R 0 2611 1099 0 76 0 747 - pts/0 00:00:00 ps
```
