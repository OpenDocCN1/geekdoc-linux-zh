# Help Menu Selection

When you click the Help selection on a menu, a drop-down menu similar to the one shown in Figure 8-3 appears. Different application windows show different menus. Typically, a Contents selection displays the manual for the application or utility that you are running. The What's This? selection is explained on page 269. The KWord Help menu (Figure 8-3) also gives you the options of reporting a bug or getting version information and more about KWord or KDE.

# Tooltips

Refer to page 182 for an explanation of tooltips and the “Tooltips Not Working?” tip to turn them on.

> Tooltips Not Working?

When tooltips that should appear on objects on panels do not appear, make sure that K menu: Control Center⇒Look & Feel⇒Panel⇒Look & Feel⇒General⇒Show tooltips (page 320) has a check mark in it.

# Context Menus

Try right clicking on a window's titlebar and other places on the workspace; the program that opened the window or kwin frequently displays a context menu (page 184).
