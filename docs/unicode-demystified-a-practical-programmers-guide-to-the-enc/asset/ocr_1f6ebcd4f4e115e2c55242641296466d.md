You can use either method to switch back to Metacity by substituting metacity for sawfish in the relevant steps of the method. Give the command rpm -q sawfish to make sure Sawfish is-stalled on your system before proceeding.

+   - Method 1
- Give the following command from a terminal emulator or text-based command line to remove your session file:
  `rm ~/.gnome2/session`
- Add the following line to your ~/.bashrc file to set the WINDOW_MANAGER variable:
  `export WINDOW_MANAGER=sawfish`
- If you are using a command-line interface, give the following command to execute the command you just put into ~/.bashrc:
  `source ~/.bashrc`
- Bring up GN. You are now running Sawfish under GNOME.
- Verify that you are running Sawfish by giving the command:
  `ps -e | grep saw`

+   - Method 2
- Bring up GNOME.
- To open the Sessions window, select GNOME menu: Run Program and enter
  gnome-session-properties
- Click the Current Session tab in the Sessions window.
- Click metacity in the Program column to highlight the row that holds metastability.
- Click the Remove button near the top of the window.
- Click the Apply button near the top of the window. You are no longer running with a window manager; all the decoration is gone from your windows.
