Set up your RHN system profile. When you do not have a profile, any call to up2date, the primary RHN tool on your system, opens the RHN Update Agent Configuration window, which starts the registration process.

Left click the Red Hat Network Alert Notification Tool (a blue icon with a check mark or a red icon with an exclamation point on the panel), or select the K or GNOME menu: System Tools⇒Red Hat Network to open the configuration window. Refer to **up2date-config: Configures the RHN Update Agent** on page 940 for help with this window.

When you choose the configuration window, the Red Hat Update Agent window opens.

+   - Read the information in the first window, and click *Forward.*
- The Step 1: Review the Red Hat Privacy Statement window opens. If you are comfortable with the information in this window, click Forward.
- The Step 2: Register or Update a User Account window opens. Fill in the information in the Required Information frame. RHN will recognize your information if you are already registered with RHN or establish an account for you if you are not already registered. Fill in the Org info frame if you are registering as part of a registered organization. Click Forward.
- The Step 3: Register a System Profile - Hardware window opens. This window establishes a profile name for your computer. The default name is your node (machine) name. You can put any information to help you identify this in this text box. The window also confirms that you want to include the hardware and network information in the profile information that you will send to RHN at the end of this process. When you click Forward, the program compiles a list of all the rpm packages that are installed on your machine.
- The Step 3: Register a System Profile - Packages window opens (there are two Step 3 windows). This window confirms that you want to include your installed rpm packages as part of your system profile and gives you the option of removing packages from your profile so they do not get updated. Click Forward.
- Click Forward to send your profile to RHN, or click Cancel and not be sent.

Entitle your system. The error: Not enabled for server profile: "profile" means that your system is not entitled. If you get this message, go to rhn.redhat.com, and log in with the user name and password you set up in Step 2, preceding.
