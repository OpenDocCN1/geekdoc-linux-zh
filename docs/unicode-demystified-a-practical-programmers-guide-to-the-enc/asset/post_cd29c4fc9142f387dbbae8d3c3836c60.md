
# Chapter 9 Networking and the Internet

The traceroute utility can help you solve routing configuration problems and routing paths failures. When you cannot reach a host, use traceroute to see what packet follows, how far it gets, and what the delay is.

The next example is the output of traceroute following a route from a local computer to www.linux.org. The first line tells you the IP address of the route, the maximum number of hops that will be traced, and the size of the packets that will be used. Each numbered line contains the name and IP address of the intermediate destination, followed by the time it takes a packet to make a round-trip to that destination and back. The traceroute utility shows three packets per destination; thus there are three times on each line. Line 1 shows the statistics when a packet is sent to the local gateway (under 3 ms). Lines 4-6 show it bouncing around Mountain View (California) before it goes to San Jose. Between hops 13 and 14 the packet travels across the United States (San Francisco to somewhere in the East). By hop 18 the packet has found www.linux.org. The traceroute utility displays asterisk when it does not receive a response. Each asterisk indicates it waited three seconds.

# host and Generic: Queries

The host utility helps look up an IP address by name or versa. This utility is to use and replace nslookup in its simplest case. For example shows how to use host to look up the domain of a machine, given an IP address:

```
$ host 140.174.164.2
2.174.170.4 pointer=meer.net.
```

# Network Utilities

The dig utility queries DNS servers for information about a domain. A powerful utility, dig has many features that you may use. It is more involved than host and replaces complex cases. The following dig uses the keyword to get any:

```
$ dig any update
;; DIG 9.1.3 >> update
;; global options: print
;; Got answer:
;; HEADER: opcode: QUERY, id: 30224; flags: qr ra; QUERY: 1; ANSWER: 1, AUTHORITY: 7
;; QUESTION SECTION
update.edu. IN ANY

;; ANSWER SECTION
update.edu. 74567 NS dns.update.edu.
update.edu. 74567 NS dns.eng.edu.
update.edu. 74567 NS dns.acesag.update.edu.
update.edu. 74567 NS nr01.netmtgt.update.edu.
update.edu. 83413 SOA dns.update.edu. 20002106 3600 900 25920 86400
update.edu. 83438 MX 10 ducs6v.update.edu.
update.edu. 83438 MX 10 dserv3c.update.edu.
update.edu. 83438 MX 10 dserv6b.update.edu.
update.edu. 83438 MX 20 dserv3b.update.edu.
update.edu. 83438 MX 20 dserv3b.update.edu.

;; AUTHORITY SECTION
update.edu. 74567 NS dns.update.edu.
update.edu. 74567 NS dns.eng.edu.
update.edu. 74567 NS dns.acesag.update.edu.
update.edu. 74567 NS nr01.netmtgt.update.edu.

;; ADDITIONAL SECTION
dns.update.edu. 2867 IN A 192.168.2.10
dns.eng.update.edu. 68182 IN A 192.168.1.10
dns.acesag.update.edu. 132867 IN A 192.168.4.50
dns.update.edu. 160958 IN A 192.168.41.3
nr01.netmtgt.update.edu. 74567 IN A 192.168.251
ucs6v.update.edu. 83438 IN A 192.168.2.27
dserv3c.update.edu. 83438 IN A 192.168.2.148

;; Query time: 29 msec
;; SERVER: 140.174.162.4#53(140.174.162.4)
;; WHEN: Thu Feb 28 15:54:33 2002
;; MSG SIZE rcvd: 499
```

The dig utility displays a lot of information.

- The Authority Section specifies the primary name servers, and the Additional Section specifies the IP addresses that correspond to the names in the Authority Section.
- The SERVER line (toward the end) specifies the name and IP address of the DNS server that the local system uses: This is where dig gets its information.
- The second column specifies the TTL (page 1499) in seconds.
- IN in the third column is the query class and indicates that this is an Internet class query.
- SOA, MX, NS, or A in the fourth column specifies the type of information (DNS query type) that the row holds:
    - The NS (name server) record(s) specify name servers that upstate.edu uses. An NS record is meaningful only when you query a domain.
    - The MX (mail exchanger) record(s) specify a mail server for the domain you are querying. The upstate.edu domain has several mail. The lower preference value is the mail priority. The upstate.edu domain has several mail.
    - The SOA (zone of authority) for a given domain.
    - Controls the TTL for the domain.
    - Controls how often another server will.
    - Controls when another server will timeout.
    - The A (record) specifies the IP-address in the last column.
