# Keyboard Shortcuts

Text editing shortcuts | Specifies the type of shortcut you want to use: emacs or GNOME Default.

Desktop shortcuts | The scrolling text box displays a list of the commands that could/have a key bound to it. Click the action/shortcut you want to change; the shortcut changes to Type new accelerator. Press the key or key combination you want to use as a shortcut. Press BACKSPACE to disable a shortcut.

# Login Photo

Sets up an identification photo that you can click, instead of typing your name, to log in the system. GDM (GNOME Display Manager) must be set up in order to use this option.

| | |

# Mouse

| | |
| --- | --- |
| Buttons | Specifies a mouse for a left-handed person and adjusts the double-click delay. You can test the delay by double-clicking the light bulb to the right.
| Cursors | Specifies a mouse pointer style. Log out and back on to change a new pointer style to effect. Check a mark in the Show position of cursor when the Control key is pressed box to help you find the mouse pointer when you press the CONTROL key.
| Motion | Sets the speed and acceleration of the mouse pointer as well as the distance you need to move the mouse pointer before it starts to drag an item.|
