# Properties

You can view information about a file, such as ownership, permission, size, and so on, by right clicking any filename or icon (except icons on a panel; see page 247 (for those) and selecting Properties from the drop-down menu. The Properties window initially displays basic information; click the tabs at the top of the window to see additional information. Different types of files display different sets of tabs, depending on what is appropriate for the file (context menu). You can modify settings in this window only if you have permission to do so.

# Basic

The Basic tab displays information about the file and enables you to select a custom icon for the file or change its name. To change the name of the file, make your changes in the text box and press `RETURN`.
