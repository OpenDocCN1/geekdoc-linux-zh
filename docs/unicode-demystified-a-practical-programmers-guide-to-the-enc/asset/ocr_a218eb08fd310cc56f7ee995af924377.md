# Other Menus

KDE bounds with menus. Table 8-2 lists all the common menus, their basic functions, and where to find information on each.

| KDE Menus | |
| --- | --- |
| (Window) Operations menu | Works with the window you click on: moves, resizes, shades (page 185), changes decoration (page 325), moves to other workspace, and more. Right click any titlebar (page 273). |
| Desktop menu | Two Desktop menus (page 308) create files, directories, and links; works with bookmarks, icons, and desktop configuration; locks the screen; and logs out. |
| Panel menu | Allows you to add items to a panel, change the size or settings of a panel, get help, or edit the K menu. Right click an applet or a button, including a Hide button, or click an empty space on a panel and select Panel (page 339). |
| Toolbar menu | Allows you to change the properties of the toolbar. Right click anywhere on a toolbar that has handles (page 342). |
| Window List menu | Makes any workspace or window active. Click the Window List button on the Taskbar on a panel, or click the root window (page 312). |
| Window menubar | A menubar found in most windows. Refer to "Terminal Emulator (console) Menubar" on page 279, "Menubar" on page 293, and "Desktop Menus" on page 308. |
