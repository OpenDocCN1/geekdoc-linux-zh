# Start Here: Preferences/Control Center

You can configure many aspects of the user interface of the GNOME desktop manager and the Metacity window manager by using GNOME menu: Preferences-Control Center or start-here: Preferences. You can also type preferences: in the location text box or select the aspect of the Control Center that you want from GNOME menu: Preferences. These entries to the GNOME Control Center present identical information (Figure 7-20) and enable you to set up a screensaver; establish or modify keyboard shortcuts; modify keyboard, mouse, and dialog preferences, and so on, using small programs called applets to work. (An applet is a small portable program written in Java; Control Center applets are sometimes called capplets.) Table 7-10 describes in detail each of the selections you can make from this window.
