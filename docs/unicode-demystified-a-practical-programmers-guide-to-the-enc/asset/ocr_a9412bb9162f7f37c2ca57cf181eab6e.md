# chsh: Changes Your Login Shell

The person who sets up your account determines which shell you will use when you first log in the system or when you open a terminal emulator window in a GUI environment. You can run any shell you like once you are logged in. Enter the name of the shell you want to use (**bash, tsch, or zsh**) and press *RETURN*; the next prompt will be that of the new shell. Experiment with the shell as you like and give an *exit* command to return to your previous shell. Because shells you call are nested (one runs on top of the other), you will have nested several shells until you are back to your original shell. Then you will be able to log out.

Use the **chsh** utility when you want to change your login shell permanently: Give the command chsh. Then, in response to the prompts, enter your password and the absolute pathname of the shell (/bin/bash, /bin/tcsh, or /bin/zsh).

# The Screen as a File

Chapter 4 introduced ordinary files, directory files, and hard and soft links. GNU/Linux has an additional type of file: a *device file*. A device file resides in the GNU/Linux file structure, usually in the */dev* directory, and represents a peripheral device, such as a terminal emulator window, screen, printer, or disk drive.

The device name that the who displays after your login name is the name of your screen/window. When who displays the device name *pts/4*, the pathname of your screen/window is */dev/pts/4*. When you work with multiple windows, each has its own device name you give the command the. Although you would not normally have occasion, you can use the tty utility to display the name of the screen you read and write to this file as if it were a text file. Writing to it displays what you wrote on the screen; reading from it shows what you entered on the keyboard.
