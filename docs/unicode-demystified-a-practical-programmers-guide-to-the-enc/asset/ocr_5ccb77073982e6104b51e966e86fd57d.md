# Sending Mail to a Remote User

Given a user's login on a remote system and the name of the remote system or its domain, you can use an e-mail program, such as pine (page 87), to send a message over the network or the Internet, using the @ form of an address:

jenny@bravo

or

jenny@tcorp.com
Although the @ form of a network address is recognized by many GNU/Linux utilities, you may find that you can reach more computers with e-mail than the other networking utilities described in this chapter. The reason for this disparity is that the mail system can deliver a message to a host that not run IP, even though it appears to have an Internet address. The message may be routed over the network, for example, until it reaches a remote system that has a point-to-point, dial-up connection to the destination system. Other utilities, such as talk, rely on IP between networked hosts.

# Mailing List Servers

A mailing list server (listserv¹⁴⁾) allows you to create, manage, and administer an e-mail list. An electronic mailing list provides a means for people interested in a topic to participate in an electronic discussion and for a person to disseminate information to a potentially large mailing list. One of the most powerful features of most list servers is the ability to archive e-mail postings to the list, create an archive index, and allow users to retrieve postings from the archive based on words or discussion threads. Typically you can subscribe and unsubscribe from the list or without human intervention. The owner of the list can restrict who can subscribe, unsubscribe, and post messages to the list. Popular list servers include LISTSERV (www.isoft.com), Lyris (www.lyris.com), Majordomo (www.wikimedia.com/majordomo), Mailman (www.list.org), and ListProc (www.listproc.com). Red Hat maintains several mailing lists (https://redhat.com/mailing-lists) and archives (www.redhat.com/mailing-lists). Use a browser to search on linux mailing to find (many) other lists.

> Although the term listserv is sometimes used generically to include many different list server programs, it is a specific product and a registered trademark of I-soft International, Inc.: LISTSERV (www.isoft.com).
