# Operating on a Region (Continued)

| META-x append-to-buffer | Prompts for a buffer and appends Region between Point and Mark to that buffer |
| META-x append-to-file | Prompts for a filename and appends Region between Point and Mark to that file |
| CONTROL-X CONTROL-U | Converts Region between Point and Mark to uppercase |
| CONTROL-X CONTROL-L | Converts Region between Point and Mark to \lowercase |

Each time you set the Mark in the buffer, you are also pushing the Mark's former location to the buffer's Mark Ring. The Mark Ring is organized as a FIFO (first-in-out) list and holds the 16 most recent locations where the Mark was set. Each buffer has its own Mark Ring. This record of recent Mark history is useful because it often holds locations that you want to jump back to. Jumping to a location pointed by the Mark Ring can be faster and easier than scrolling or searching your way through the buffer to find the site of a previous change.

To work your way backward along the trail of former locations, each time you give the command CONTROL-U CONTROL-@ one or more times. Each time you give the command, emacs

+   * Moves Point (and the cursor) to the current Mark location
* Saves the current Mark location at the oldest end of the Mark Ring
* Pops off the youngest (most recent) Mark Ring entry and sets Mark

Each additional CONTROL-U CONTROL-@ command causes emacs to move Point and the cursor to the previous one on the Mark Ring.

Although this process may seem complex, it is really just a jump's starting point which is recirculated back through the Mark Ring, it is safe because if you jump, it is easy to find it again. You can jump to all the previous locations on the Mark Ring (it may be fewer than 16) by giving the command CONTROL-U CONTROL-@ again. You can go around the ring as many times as you like and stop whenever you want to.

Some commands set Mark automatically: The idea is to leave a bookmark before moving Point a long distance. One example is META--, which sets Mark before jumping to the end of the buffer. You can then go back to your starting position with CONTROL-U CONTROL-@. Searches behave similarly. To avoid surprises the message Set appears in the Echo Area whenever Mark is set, either explicitly or implicitly.
