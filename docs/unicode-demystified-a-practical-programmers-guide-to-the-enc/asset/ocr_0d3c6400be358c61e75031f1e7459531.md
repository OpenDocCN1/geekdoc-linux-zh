You can give the readonly attribute to a variable to prevent its value from being changed. You must assign values to variables before you give them this attribute:

```
sh % PATH=/usr/bin:/usr/bin:/usr/local/bin:/usr/games
sh % types -r PATH
sh % PATH=/usr/bin:usr/ucb:/usr/local/bin:/usr/games
sh: read-only variable: PATH
```

You can readonly the builtin in place of types -r:

```
sh % readonly TMP=/tmp
```

Without any arguments types displays a list of variables with their attributes and values. To see the value of a variable, use types name:

```
sh % types DAY
DAY=2
```

Use types followed by an option to see which variables have a certain attribute

```
sh % types -Z
DAY=2
```
