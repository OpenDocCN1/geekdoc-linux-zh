forward Scrolls forward. If the end of the input file is reached, for more input and then continues scrolling. This option allows you to use less in a manner similar to tail -f (page 1340), except that less paginates the output as it appears.

Skips to the next file in file-list. If n is given, skips to the nth file in file-list.

changes the current file into an editor with the cursor on the current line. The utility uses the editor specified in the EDITOR environment variable. if EDITOR is unset, less uses vi.

Executes command line under the shell specified by the SHELL environment variable, or sh (usually linked to bash) by default. A percent sign (%) in command line is replaced by the name of the current file. If command line is omitted, less starts an interactive shell.

q or :q Terminates less.

# Examples

The following example displays the file memo.txt. To see more of the file, the user presses the SPACE in response to the less prompt at the bottom left of the screen:

```
$ less memo.txt
```

```
. memo.txt SPACE
```

In the next example the user has changed the prompt to a more meaningful message and has used the -N option to display line numbers. Finally, the user has instructed less to skip forward to the first line containing the string procedure:

28 procedure main(args)
29 local filelist, arg, fields, delim
30
