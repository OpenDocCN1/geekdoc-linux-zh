If you use the x option without specifying a file or directory name to extract, the dumped filesystem is extracted. Use the r option to restore an entire-system without having to go through the interactive interface. The following command restores the myfile from the tape on /dev/st0 into the working directory without interaction:

```
# restore -rf /dev/st0
```

You can also use dump and restore to access a tape drive on another system over the network (specify the file/directory as host:file, where host is the hostname of the machine that the tape drive is on) and file is the file/directory you want to dump/restore.

Occasionally restore may prompt you with

+   You have not read any volumes yet.
Unless you know which volume your file(s) are on you should with the last volume and work towards the first.
Specify next volume:

Enter 1 (one) in response to this prompt. If the filesystem spans more than one tape disk, this prompt allows you to switch tapes.
At the end of the dump, you will receive another prompt:

> set owner/mode for '.?' [yn]

Answer y to prompt when restoring filesystems or files that have been accidentally removed. Doing so will restore the appropriate permissions to the files and directories being restored. Answer n if you are restoring a dump to a directory other than the one it was dumped from; the working directory permissions and owner will be set to those of the person doing the restore (typically root).

Various devices can access the /dev/st0 device. Each name accesses a different device number that controls some how the tape drive is used. After you complete a dump when you use /dev/st0, the tape drive automatically rewinds the tape to the beginning. Use the nonrewinding SCSI device (/dev/nst0) to keep the tape from rewinding on completion. This feature allows you to back up multiple filesystems to one volume. Following is an example of backing up a system with the /home, /usr, and var directories on different systems:

```
# dump -ouf /dev/nst0 /home
# dump -ouf /dev/nst0 /usr
# dump -ouf /dev/st0 /var
```

The preceding example uses the nonrewinding device for the first two dumps. If you are using the rewinding device, the tape rewinds after each dump, and you are left with only the last dump on the tape. For more information refer to the mt (magnetic tape) and st (SCSI tape) man pages.
