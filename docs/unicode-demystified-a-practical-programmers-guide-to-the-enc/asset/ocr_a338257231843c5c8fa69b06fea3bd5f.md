When you give an absolute pathname on the command line or a relative pathname that is not a simple filename (that is, any pathname that includes at least one slash), the shell looks in the specified directory (/bin in this case) for a file that has the name Is and that you have permission to execute. When you give a simple filename, the shell searches through a list of directories for a filename that matches the name you specified and that you have execute permission for. The shell does not look through all directories but rather the ones specified by the shell variable named PATH. Refer to page 577 or 708 for more information on PATH. Also refer to the discussion of which and wherein on page 78.

When it cannot find the executable file, the Bourne Again Shell displays a message such as the following:

+   One reason the shell may not be able to find the executable file is that it is not in a directory in your PATH. Under the following command bash adds the working directory (.) to your PATH temporarily:

```
$ PATH=$SPATH:
```

For reasons of security, you may not want to add the working directory to your PATH permanently; see the tip "PATH and Security" on page 578.
