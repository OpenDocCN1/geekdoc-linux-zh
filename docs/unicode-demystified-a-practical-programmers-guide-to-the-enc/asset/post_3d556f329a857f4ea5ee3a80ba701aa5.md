# Broadcast

On a broadcast network, such as Ethernet, any of the systems attached to the network cable can send a message at any time; each system examines the address in each message and responds only to messages addressed to it. A problem occurs when multiple systems send data at the same time, resulting in a collision of the messages on the cable. When messages collide, they become garbled. The sending system notices the garbled message and resends after waiting a short but random amount of time. Waiting a random amount of time helps prevent those systems from resending the data at the same moment and experiencing another collision. The extra traffic that results from collisions can put quite a load on the network; if the collision rate gets too high, the retransmissions result in more collisions, and the network becomes unusable.

# Point-to-Point

A point-to-point link does not seem like much of a network at all because only two endpoints are involved. However, most connections to WANs are through point-to-point links, using wire cable, radio, or satellite links. The advantage of point-to-point link is that because only two systems are involved, the traffic on the link is limited and well understood. A disadvantage is that each system typically be equipped for a small number of such links, and it is impractical and costly to establish point-to-point links that connect each computer to all the rest.

Point-to-point links often use serial lines and modems but can use computer parallel ports for faster links between GNU/Linux systems. The use of a modem with a point-to-point link allows an isolated system to connect inexpensively into a larger network.

The most common types of point-to-point links are the ones used to connect to the Internet. When you use DSL^1 (digital subscriber), you are using a point-to-point link to connect to the Internet. Serial lines, such as T-1, T-3, ATM links, and ISDN, are all point to point. Although it might seem like a point-to-point link, a cable modem is based on broadcast technology and in that way is similar to Ethernet.

# Switched

A switch is a device that establishes a virtual path between source and destination hosts such that each path appears to be a point-to-point link, like a railroad roundhouse. The telephone network is a giant switched network. The switch brings up and tears down virtual paths as hosts need to communicate with each other. Each host thinks that it has a direct point-to-point path to the host it is talking to. In contrast with a mesh network, each host also sees traffic for other hosts. The advantage of a switched network over a pure point-to-point network is that each host requires only one connection: the connection to the switch. Using pure point-to-point connections, each host must have a connection to every other host. Scalability is provided by further linking switches.

# LAN: Local Area Network

Local networks (LANs) are confined to a relatively small area—a computer facility, building, or campus. Today most LANs run over copper or fiberoptic cable, but other, wireless technologies, such as infrared (similar to most television remote control devices) and radio wave, are becoming more popular.

If its destination address is not on the local network, a packet must be passed on to another network by a router (page 357). A router may be a general-purpose computer or a special-purpose device attached to multiple networks as a gateway way among them.

# Ethernet

A GNU/Linux system connected to a LAN usually connects to the network using Ethernet. A typical Ethernet connection can support data transfer rates from 10 megabits per second to 1 gigabit per second, with speed enhancements planned.

Owing to computer load, competing network traffic, and network overhead, file transfer rates on an Ethernet are always slower than the maximum, theoretical transfer rate.

An Ethernet network transfers data by using copper or fiberoptic (glass) cable or wireless transmitters and receivers. Originally each computer was attached to a thick coaxial cable (called *thicket*) at tap points spaced at six-foot intervals along the cable. The thick cable was awkward to deal with, so other solutions, including a thinner coaxial cable known as *thinnet*, or Base2, were developed. Today most Ethernet connections are either wireless or more unshielded twisted pair—referred as UTP, Category 3 (cat 3), Category 5 (cat 5), Category 5e (cat 5e) 10BaseT, or 100BaseT—similar to the type of wire used for telephone lines and serial data communications.

A switched *Ethernet* network is a special case of a broadcast network that works with a *network switch*, or just switch, which is a special class of hub that has intelligence. Instead of having a dumb repeater (hub) that broadcasts every message, a switch learns which devices are connected to which ports and sends messages only to the intended recipient. This reduces collisions and improves overall network performance.

# Wireless

Wireless networks are becoming increasingly common. They use radio waves to transmit data, allowing for mobility and reduced need for physical cabling. Common wireless technologies include Wi-Fi, Bluetooth, and cellular networks. These networks use access points or base stations to connect wireless devices to a wired network, such as the Internet.

# WAN: Wide Area Network

A wide area network (WAN) covers a large geographic area. The technologies (such as Ethernet) were designed for limited distances. Major Internet service providers rely on WANs to connect customers. Some networks do not fit either the LAN or the WAN designation: A MAN (metropolitan area network) is one that is contained in a smaller area, such as a city. Like WANs, MANs are typically used to interconnect LANs.

# Interworking through Gateways and Routers

A LAN connects to a WAN through a gateway, a generic term for a computer or special device with multiple network connections that passes data from one network to another. The purpose of the gateway is to convert the data from the format used on the LAN to that used on the WAN. Data that crosses from Ethernet to another over a WAN, for example, is repackaged from the Ethernet format to a different format that can be processed by the communications equipment that makes up the WAN. When it reaches the end of its journey over the WAN, the data is converted by another gateway to the appropriate format for the receiving network. For the most part these details are of concern only network administrators; the end user does not need to know anything about how the transfer is carried out.

A router is the most common form of a gateway. Routers play an important role in interworking. Just as you might study a map to plan your route when you need to drive to an unfamiliar place, a computer needs to know how to deliver a message to a system attached to a distant network by passing through intermediary systems and networks along the way. You can imagine using a giant network map to choose the route that your data should follow, but a static map of computer routes is usually a poor choice for a large data network. Computers and networks along the route may be overloaded or down, without providing a detour for your message.

Routers communicate with one another dynamically, keeping one another informed about which routes are open for use. To extend the analogy, this would be like heading out on a car trip without consulting a map to find a route to your destination; instead you would head for a nearby gas station and ask directions. Throughout the journey, you would continue to stop at one gas station after another, getting directions at each to find the next one.
