always to select a file. Together, they make it practical to use long, descriptive
filenames.

To use filename completion when you are entering a filename on the command
line, type enough of the name to identify the file in the directory and then
press TAB; tsh fills in the name and adds a SPACE, leaving the cursor so that you can
enter additional arguments or press RETURN. The following example shows the user
typing the command cat trig1A and pressing TAB; the system fills in the rest of the
filename that begins with trig1:

```
42 $ cat trig1A → TAB cat trig1A.302488 ■
```

If two or more filenames match the prefix that you have typed, tsh cannot
complete the filename without more information from you. The shell attempts to
maximize the length of the prefix by adding characters, if possible, and then beeps
to signify that additional input is needed to resolve the ambiguity:

```
43 $ ls h*
help.text help.trig01
44 $ cat h → TAB cat help. (BEEP)
```

You can fill in enough characters to resolve the ambiguity and then press TAB again.
Alternatively, you can press CONTROL-0 and tsh presents a list of matching filenames:

```
45 $ cat help. → CONTROL-0 → cat help.
help.trig01help.text
```

Then tsh redraws the command line you have typed so that you can disambiguate the
filename (and press TAB again) or finish typing the rest of the name.

# Tilde Completion

The TC Shell parses a tilde (~) appearing as the first character of a word and at-
temps to expand it to a user name when you enter a TAB:

```
tsh $ cd ~al → TAB cd ~alex/RETURN
tsh $ pwd
/home/alex
```

By appending a slash (/), tsh lets you know that the completed word is a directory.
The slash also makes it easy to continue specifying the pathname.
