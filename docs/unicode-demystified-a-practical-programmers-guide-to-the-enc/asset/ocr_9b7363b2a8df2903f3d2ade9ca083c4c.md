# cksum

The cksum utility computes a checksum for a file. This utility is useful when you are sending or receiving a file and want to ensure that it is not corrupted in transmission. The cksum utility replaces a utility named sum that was present in both BSD and SVR4. The POSIX.2 committee did not use sum; BSD and System V had different, incompatible implementations. The algorithm used by cksum is based on a cyclic redundancy check from the Ethernet standard ISO 8802-3.
