# Pattern (Continued)

| [...] | Defines a character class. Any characters enclosed within brackets are tried, one at a time, in an attempt to match a single character. hyphen between two characters specifies a range of characters. |
| | Separates alternative choices that satisfy a particular branch of the case structure. |

The next script accepts upper- and lowercase letters:

```
$ cat case2
echo -n "Enter A, B, or C: "
read letter
case $letter in
  a|A)
    echo "You entered A"
    ;;
  b|B)
    echo "You entered B"
    ;;
  c|C)
    echo "You entered C"
    ;;
  *)
    echo "You did not enter A, B, or C"
    ;;
```

esac
$ case2
Enter A, B, or C: b
You entered B
$
