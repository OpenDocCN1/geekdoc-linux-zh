# History

The Z Shell keeps a history of recently executed commands in a file, which means that the history can persist from one shell session to the next. You can select, edit, and reexecute any command in the history list from the current or a login session. The shells' history mechanisms have an important difference. The Z Shell remembers multiline commands in their entirety and allows you to edit them. In bash each line of a multiline command is treated as a separate command (unless you set the variable command_oriented_history—refer to the bash page for more information), whereas tsh remembers only the first line of multiline commands.

Although several of the history variables are the same as used by bash (page 589), there are some important differences (Table 15-20). If it is set, the HISTSIZE variable determines the number of commands that are kept in the history list. If it is not set, only two commands are kept. The HISTFILE variable determines how much of the history gets saved to HISTFILE. If any commands are saved in HISTFILE, the Z Shell reads them in when the shell starts, so the commands become part of the history list for the current session. The SAVEHIST variable determines whether. If HISTFILE or SAVEHIST is not set, the Z Shell does not save any commands when terminating. Refer to “History Expansion” on page 799.
