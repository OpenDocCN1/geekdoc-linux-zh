
# lpr

Prints files

- lpr [options] | [file-list]
- lpq [options] | [job-identifiers]
- lprm [options] | [job-identifiers]

The lpr utility allows to add or remove files into a print queue, providing orderly access to printers for several users or processes. The utility can work with printers attached to remote systems. You can use the lprm utility to remove files from the print queues and the lpq utility to check the status of the queues. Refer to the "Notes" section.

The lpr utility takes its input from files you specify on the command line or from standard input and adds them to the print queue as print jobs. The utility assigns a unique identification number to each print job. You can use the lprm utility to remove a print job from the print queue; the lpq utility displays the job numbers of the jobs that lpr set up.

## Arguments

The file-list is a list of one or more filenames for lpr to print. Often these files are text files, but many systems are configured so that lpr can accept and properly print a variety of file types.

The job-identifiers is a list of job numbers or user names. If you don't know a printer job number, use lpq to display it.

## Options

Some of the following options depend on the type of file being printed, as well as how your system is configured for printing. To see which options are available, check with the person who set up lpr.

- -p Prints the job to the queue for the printer named *printer*. If you do not use this option, print jobs are routed to the default printer. The acceptable values for printer are found in the file /etc/printcap and vary from system to system.
- -h Suppresses the printing of the header and page number. This is useful for identifying the output in a multiuser setup, but saves paper.
- -m Sends mail to *user* (for example, alex@example.com) when print jobs complete successfully. This option is useful on systems that have many people sharing the same printer or when the printer is not local.
- -n Prints *n* copies of each file. Depending on your shell, you may need to escape the filename with a backslash to pass it to lpr.

## Discussion

The lpr utility works with the lpd daemon and is generally part of the printing system. The lpd daemon manages the print queues and routes jobs to the printers when they become available.

The lpq utility displays information about jobs in a print queue. When called without any arguments, it lists all the jobs queued for the default printer. The -Pprinter option (see the description in the preceding "Options" section) allows lpq to look at other queues for printers connected to other computers. With the -l option lpq displays more information about each job. If you give the name of a user as an argument, it displays only the print jobs belonging to that user.

One of the items displayed by lpq is the job number for each print job. To remove a job from the print queue, use the job number as an argument to lprm. Unless you are Superuser, you can remove your own jobs. You can remove all jobs from a selected queue with lprm -all. If you do not give any arguments to lprm it removes the currently active job (the job that is now printing) from the queue, if you own that job. You can remove all print jobs by using your login name or the word all as the argument. Using a login name is a useful way for Superuser to remove all print jobs that belong to a particular user.

## Notes

If you normally use a printer other than the system default, you can use lpr to use another printer as your personal default by assigning the name of this printer to the environment variable PRINTER. For example, if you use bash, you can add the following line to ~/.profile to set your default printer to the printer named sp:

```
export PRINTER=sp
```

## Examples

The first command sends the file named memo2 to the default printer:

```
$ lpr memo2
```

Next, a pipe sends the output of lpr to the printer named deskjet:

```
$ ls | lpr -Pdeskjet
```

The next example paginate and sends the file memo to the printer:

```
$ pr -h "Today's memo" "memo" | lpr
```

The next example shows a number of print jobs queued for the default printer. All the jobs are owned by Alex, and the first one is currently being printed (active). Jobs 635 and 639 were created by sending input to lpr standard input, whereas job 638 was created by giving ncut.icn as an argument to the lpr command. The last column gives the size of each print job:

```
$ lpr is ready and printing
Rank Owner Job Files Total Size
active alex 635 (standard input) 38128 bytes
1st alex 638 ncut.icn 3587 bytes
2nd alex 639 (standard input) 3960 bytes
```

The next command removes job 638 from the default queue. The lpr command responds by identifying the data file and control file that lpd uses to keep track of the print job. The data file contains the data to send to the printer, and the control file contains any special information (such as the number of copies to make) required when printing the file:

```
$ lprm 638
dfa638Aa28156 dequeued
cfa638Aa28156 dequeued
```

Finally, Alex removes all jobs from the print queue by giving all as an argument to lprm:

```
$ lprm all
dfa635Aa28141 dequeued
cfa635Aa28141 dequeued
dfa639Aa28159 dequeued
cfa639Aa28159 dequeued
```

# ls

Displays information about one or more files
ls [options] [file-list]

The utility displays information about one or more files. It lists the information alphabetically by filename unless you use an option to change the order.

## Arguments

When you do not use an argument, ls displays the names of the visible files in the working directory (those whose filenames do not begin with a period [.]).

The file-list contains one or more pathnames of files. You can use the pathname of any ordinary, directory, or device file. These pathnames can include ambiguous file references.

When you specify a directory, ls displays the contents of the directory. Normally this option displays ordinary files in the directory you are displaying, as well as directory files.

## Options

The options determine the type of information ls displays, how it displays it, and when you do not use an option, it displays the names of the files.

- -a The same as --all includes invisible files (those with filenames that begin with a period .).
- -A The same as --all but does not list . and .. entries.
- -b Displays nonprinting characters in a filename using escape sequences similar to those used in C language strings.
- -d Displays the names of directories without displaying their contents.
- -F Displays a slash after each directory, an asterisk after each executable file, and at sign (@) after symbolic links.
- --color=[when] The ls can display various types of files in different colors but normally does not use colors (same as using never for when).
- --hide-control-chars -q Displays nonprinting characters in a filename as question marks. When output is going to the screen, this is the default behavior.
- -human-readable -h Displays file sizes using K, M, and G as appropriate. Uses powers of 1,024; --si for powers of 1,000.
- -inode -i Displays the number about each file. With the -i option displays the number in column 1 and shifts all other items one column to the right.
- --format=long -l ("--l") Lists more information about each file. Use with -h to make file sizes readable.
- --dereference -L Lists information about the file referenced by each symbolic link rather than information about the link itself.
- --reverse -r Displays the list of filenames in reverse sorted order.
- --recursive -R Recursively lists subdirectories.

## Discussion

The utility displays information about one or more files. It lists the information alphabetically by filename unless you use an option to change the order.

## Notes

If you normally use a printer other than the system default, you can use lpr to use another printer as your personal default by assigning the name of this printer to the environment variable PRINTER. See "Notes."
