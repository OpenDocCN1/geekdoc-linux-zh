The mount utility uses /etc/fstab to get the necessary information and then unmounts the appropriate filesystem from its server. When a process has a file open on the filesystem that you are trying to unmount, mount displays a message similar to

```
mount: /home: device is busy
```

# When You Cannot Unmount a Device Because It Is In

When a process has a file open on a device you need to unmount, use fuser to determine which process has the file open and to kill it. For example, when you want to unmount the floppy, the command fuser -ki /mnt/floppy, which, after checking with you, kills the process using the floppy.

You can mount all filesystems using the -a option to unmount, and you can combine that option with the -t option to unmount filesystems of a given type (ext3, nfs, or others). For example, use the following command to unmount all mounted nfs filesystems that are not being used:

```
mount -at nfs
```

# fstab: Keeps Track of Filesystems

The system administrator maintains the /etc/fstab file, which lists local and remote filesystems, most of which the system mounts automatically when it boots. The fstab file has six columns; a dash keeps the place of a column that has no value. The six columns are

+   1. **Name:** The name of the block device (page 971) or remote filesystem. A remote filesystem appears as *hostname:pathname*, where *hostname* is the name of the host that houses the filesystem, and *pathname* of the directory that is to be mounted. You can substitute the volume label of the filesystem by using the form LABEL=xx, where xx is the volume label. Refer to elabel page 1057.
2. **Mount point:** The name of a directory that the filesystem is to be mounted over. If it does not exist, create this directory with mkdir.
3. **Type:** The type of filesystem that is to be mounted. Local filesystems are generally ext2 or ext3, and remote ones are *nfs*. See Table 17-8 on page 973 for a list of filesystem types.
4. **Mount options:** A comma-separated list of mount options, such as whether the filesystem is mounted for reading and writing (rw, the default) or readonly (ro). Refer to the mount man page for a list of options.
