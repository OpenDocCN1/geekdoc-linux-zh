# Invisible Filenames

A filename that begins with a period is called an invisible filename (or invisible file or sometimes hidden file) because it does not normally display it. The command ls -displays all filenames, even invisible ones. Startup files (page 109) are usually invis-ible so that they do not clutter a directory. The .plan file (page 82) is also invis-ible. Two special invisible entries—a single and double period (. and ..)—appear in every directory (page 112).
