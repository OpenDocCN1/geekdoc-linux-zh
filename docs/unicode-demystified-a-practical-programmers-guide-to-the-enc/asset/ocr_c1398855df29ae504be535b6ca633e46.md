| Home URL | The URL is the address of the directory or URL Konqueror displays when you click the home icon (house and folder), frequently your home directory (-). |

| Minimize memory usage | Konqueror tries to free memory. When you have enough memory, conserving memory slows Konqueror. When you do not have enough memory, it speed things up. When you are working with the File Manager of Konqueror, For local browsing is the recommended choice; Always is not recommended unless you have very little memory. |
| Appearance | Specifies the font family, size, and color for the file manager. You can also specify that you want the text under the icons to be word-wrapped (it is truncated if you do not check this box) and that the filenames are underlined (may make them more readable). Display file sizes in bytes affects the nonicon views of Konqueror the File Manager. |
| Trash | Specifies whether you have to confirm when you move a file to the trash, delete it, or shred a file. |
| Previews | Replaces desktop icons for HTML, image, PostScript/PDF, text, and many other types of files, with small preview images showing the contents of the file. The sound is played when the mouse pointer hovers over the icon representing a sound. Select the types of files (protocols) that you want to see for previews. Set the Maximum file size to the largest size that you want to see a preview for. Files over this size will not display previews. |

# Quick Copy & Move Plugin

Configures the Quickcopy and the Move plugin for Konqueror. These frames affect the Copy To and Move submenus that are displayed when you right click an icon in a Konqueror window and some icons in the root window. After making a change, you must bring up a new Konqueror window to see the results.
