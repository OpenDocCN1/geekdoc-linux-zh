The problem of how to sort by name within zip code is solved by a second pass covering the last-name field. Although the second element in the pair of points is not necessary (you already know from the first pass that the zip codes match), it is included for its instructional value. A third pass, in case zip code and name are the same, is also not required. After the second pass, sort compares entries lines, so it automatically sorts on first name within last name:

```
$ sort -fb +2.3 +1 -2
Tom Winstrop 94201
Richard MacDonald 95110
Janet Dempsey 94111
David Mack 94114
Alice Macleod 94114
Toni Barnett 95020
Jack Cooper 94072
```
