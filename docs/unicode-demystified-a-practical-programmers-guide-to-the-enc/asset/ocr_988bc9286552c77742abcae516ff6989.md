| Language | | When you want to change the language of the window titles, prompts, error messages, and so on, select the language you want by first selecting the range containing the letter it starts with and then the language itself.

Bringing a GUI up from a Character-Based Display
Once you have logged in on a virtual console, you can start a graphical display by giving the following command to bring up your default desktop manager:

```
$ startx
```
