# Desktop Files

Desktop files have a .desktop filename extension, store information about how they should be displayed, and a URL that specifies where they point to. The URL can be a local file or directory, an Internet URL, or an FTP address. The following abbreviated filename name home.desktop, resides in SKDEHOME/share/apps/konqsidebart/entries, displays in the Konqueror Navigation panel toolbar as a house icon, and links to the HOME directory:

Type=Link
URL=file:$HOME

Name=Home gids
