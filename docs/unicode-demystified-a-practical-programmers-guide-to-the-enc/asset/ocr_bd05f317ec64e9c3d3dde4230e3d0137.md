# Loadable kernel modules

+   /mnt Mount point for temporary mounting of filesystems
/opt Add-on software packages (optional packages)
/proc Kernel and process information virtual filesystem
/root Home directory for root
/sbin Essential system binaries Utilities used for system administration are stored in /bin and /usr/sbin. The /sbin directory holds those utilities needed during the process, and after the system is up and running. In older versions of GNU/Linux, many system administration utilities were scattered throughout several directories that often included other file systems (/etc, /usr/bin, /usr/adm, /usr/include).
/tmp Temporary files Many programs use this directory to hold temporary files.
/usr Second major hierarchy This directory traditionally includes subdirectories that contain information used by the system. In /usr subdirectories do not change often and may be shared by multiple systems.
/usr/bin Most commands This directory contains the standard GNU/Linux utility programs: binaries that are not needed in single-mode use (page 949).
/usr/bin/X11 Symbolic link to /usr/X11R/bin
/usr/games Games and educational programs
/usr/include Header files included by C programs
/usr/include/X11 Symbolic link to /usr/X11R/include/X11
/usr/lib Libraries
/usr/lib/X11 Symbolic link to /usr/X11R/lib/X11
/usr/local Local hierarchy This directory holds locally important files and directories that are often added to Red Hat. Subdirectories of /usr/local include bin, games, include, lib, shin, share, and src.
/usr/man Online manuals
/usr/sbin Nonvolatile system administration-independent data binaries See /sbin.
/usr/share Architecture-independent data Subdirectories of /usr/share include dict, doc, games, info, local, man, misc, terminfo, and zoneinfo.
/usr/doc Miscellaneous documentation
/usr/share/info GNU info system's primary directory
/usr/src Source code
