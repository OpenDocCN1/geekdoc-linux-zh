The it criterion checks whether the process running test is sending output to a terminal. If it is, the test utility returns a value of true (0). Following is a listing of the shell script term that runs test:

```
$ cat term
test -t 1
echo "This program is (=0) or is not (=1)
sending its output to a terminal:" $
```

First, term is run with the output going to the terminal, that is, the output is not redirected to a file. The test utility returns a 0. The shell stores this value in the shell variable that records the condition code of the last process, $?. The echo utility displays this value:

```
$ term
This program is (=0) or is not (=1)
sending its output to a terminal: 0
```

The next example runs term and redirects the output to a file. The contents of the file temp show that test returned a 1, indicating that its output was not going to a terminal:

```
$ term > temp
$ cat temp
This program is (=0) or is not (=1)
sending its output to a terminal: 1
```
