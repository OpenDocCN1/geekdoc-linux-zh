# Broadcast

On a broadcast network, such as Ethernet, any of the systems attached to the network cable can send a message at any time; each system examines the address in each message and responds only to messages addressed to it. A problem occurs when multiple systems send data at the same time, resulting in a collision of the messages on the cable. When messages collide, they become garbled. The sending system notices the garbled message and resends after waiting a short but random amount of time. Waiting a random amount of time helps prevent those systems from resending the data at the same moment and experiencing another collision. The extra traffic that results from collisions can put quite a load on the network; if the collision rate gets too high, the retransmissions result in more collisions, and the network becomes unusable.

# Point-to-Point

A point-to-point link does not seem like much of a network at all because only two endpoints are involved. However, most connections to WANs are through point-to-point links, using wire cable, radio, or satellite links. The advantage of point-to-point link is that because only two systems are involved, the traffic on the link is limited and well understood. A disadvantage is that each system typically be equipped for a small number of such links, and it is impractical and costly to establish point-to-point links that connect each computer to all the rest.
