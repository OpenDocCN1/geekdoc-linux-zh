string2. In this case the GNU version of tr departs from the POSIX standard,
does not define a result.

If you use the --delete and --squeeze-repeats options at the same time, tr de-\letes the characters in string1 and reduces multiple sequential occurrences of
characters in string2.

You can use a hyphen to represent a range of characters in string1 or string2. The two
command lines in the following example produce the same result:

```
$ echo abcdef | tr 'abcdef' 'xyzabc'
xyzabc
$ echo abcdef | tr 'a-f' 'x-za-c'
xyzabc
```

The next example demonstrates a popular method for disguising text, often
called rotate 13 because it replaces the first letter of the alphabet with the th-	eenth, with the fourteenth, and so forth:

```
$ Echo punchline of the joke is ... |
> tr '[A-M][N-Z][a-m]' '[N-Z][A-M][n-z][a-m]'
Gu chapavuy bus gr bxxr vf
```

To make the text intelligible again, reverse the order of the characters to:

```
$ echo Gur chapavuy bus gr bxxr vf ... |
> tr '[N-Z][A-M][n-z][a-m]' '[A-M][N-Z][a-m]
The punchline of the joke is ...
```

--delete option causes tr to delete selected characters:

```
$ echo If you can read this, you can spot the missing vowels! |
> tr --delete 'aetou'
If y cn rd th, y cn spt mssng wvls!
```

In the following example tr replaces characters and reduces pairs of identical
characters to single:

```
$ echo tennesse | tr -s 'tnse' 'srne'
serene
```

The following example replaces each sequence of nonalphabetic characters (the
complement of all the alphabetic characters as specified by the class al-\pha) in the file draft1 with a single NEWLINE character. The output is a list of words,
one per line:

```
$ tr --complement --squeeze-repeats '[:alpha:]' '\n' < draft1
```

The next example uses character classes to upshift the string hi there:

```
$ echo hi here | tr '[:lower:]' '[:upper:]'
HI THERE
```
