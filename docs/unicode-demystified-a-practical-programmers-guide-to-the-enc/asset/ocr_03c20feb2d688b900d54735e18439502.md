# Buildins (Continued)

Moves a job to the foreground. Refer to "Job Control" on page 554.

Takes one of the file inquiry operators, followed by one or more filenames, and applies the operator to each filename. Returns the results as a space-separated list (page 717).

Like echo, but does not display SPACE between its arguments and does not follow its display with a NEWLINE.

Reports on the efficiency of tc's hash mechanism. The hash mechanism speeds the process of searching through the directories in your search path. See also rehash (page 727) and unhash

Displays a list of recent commands. Refer to "History" on page 686.

Identifies the current jobs, or commands running in the background. Refer to "Job Control" on page 554.

Terminates a job or process. Refer to "kill: Aborts a Process" on page 788.

Limits the resources that the current process and any processes it creates use. You can put limits on the number of seconds of CPU time the process can use, the size of files that the process can create, and so forth.

Immediately produces the report that the watch variable (page 711) would normally produce every 10 minutes (unless you have changed the default).

Logs in a user. Can be followed by a username.

Ends a session if you are using your original (login) shell.

Similar to ls -F faster. (This builtin is the characters 1-F in sequence without an intervening SPACE. The command it is similar to is the ls utility with the -F option.)
