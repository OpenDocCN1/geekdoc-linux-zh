Try logging in, making sure that you enter your login name as it was specified when your account was set up; the routine that verifies your login name and password is case sensitive.

Next, the shell prompt (or just prompt) appears, indicating that you have successfully logged in; it indicates that the system is ready for you to give it a command. The shell prompt line may be preceded by one or two short messages the message of the day, or *motd* (page 961) and issue. These messages generally identify the version of Red Hat Linux that is running, along with any local messages placed in either the /etc/motd or the /etc/issue file.
