+   * Works with printers. You can add, remove, and modify printers and their properties.
* Works with multiple printing systems. KDEPrint works with CUPS, LPRng, RLPR, PDQ, and other printing systems.

A network can be as big as the Internet, connecting millions of machines with backbones running around the globe, or as small as a home network connecting two machines in the same room. The software to connect a machine to a network can be set up in three ways: install time, by responding to prompts; after the system is up, by running a program and responding to prompts; and manually, by editing files.
