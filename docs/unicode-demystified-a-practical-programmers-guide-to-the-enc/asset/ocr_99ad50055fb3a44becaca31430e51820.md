# Exercises

| :n | Edits the next file when vim is started with multiple name arguments. It requires you to write out changes to the current file (with :w or autowrite) before editing the next file. Use :n! to discard changes to current file and edit the next file |
| :rew | Rewinds the filename list when vim is started with multiple filename arguments and starts editing with the current file. It requires you to write out changes before editing the first file. Use :rew (with :w or autowrite) to discard changes to current file and edit the first file. |
| :sh | Starts a shell. |
| !command | Starts a shell and executes command. |
| !!command | Starts a shell, executes command, places output in file placing the current line. |

# Exercises

+   1. How can you cause vim to enter Input mode? How can you make vim revert to Command mode?

+   2. What is the Work buffer? Name two ways of writing the contents of the Work buffer to the disk.

+   3. Suppose you are editing a file that contains the following paragraph and the cursor is on the second tilde (~):

> The vim editor has a command, tilde (~),
changes lowercase letters to
uercase and versa.
The ~ works with a Unit of Measure or a Repeat Factor, so you can change the case of more one character at a time.

How can you you

+   a. Move the cursor to the end of the paragraph?
b. Move the cursor to the beginning of the word Unit?
c. Change the word character to letter?
