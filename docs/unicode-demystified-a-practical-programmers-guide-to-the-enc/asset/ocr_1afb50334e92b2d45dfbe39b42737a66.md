Linux and GNU software are distributed under the terms of the GNU General Public License (GPL, we www.gnu.org/licenses/licenses.html). The GPL says that you have the right to copy, modify, and redistribute the code covered by the agreement, but when you redistribute the code, you must also redistribute the same license with the code, making the code and the license invariable. If you get the source code for an accounting program that is under the GPL off the Internet and modify it and redistribute an executable version of the program, you must also distribute the modified source code and the GPL agreement with it. Because this is the reverse of a normal copyright (it gives rights instead of limiting them), it has been termed copyleft. # Have Fun!

Two keys for GNU/Linux are, “Have Fun!” These words pop up in prompts and documentation. The UNIX—now the GNU/Linux—culture is steeped in humor throughout the system. For example, less is more—GNU has replaced the UNIX paging utility named more with an improved utility named less. The utility to view PostScript documents is named ghostscript, and one of several replacements for the vi editor is named elvis. While machines with Intel processors have “Intel Inside” logos on their outside, some GNU/Linux machines sport “Linux Inside” logos. And Torvalds himself has been seen wearing a T-shirt bearing a “Linux Inside” logo.
