The following for...in structure assigns apples to the user-created variable fruit and then displays the value of fruit, which is apples. The next structure assigns- anges to fruit and repeats the process. When it exhausts the argument list, the stru- transfers control to the statement done, which displays a message:

```
$ cat fruit
for fruit in apples oranges pears bananas
do
  echo "$fruit"
done
echo "Task complete."
```

The next script lists the names of the directory files in the working directory looping over all the files, using test to determine which are directory files:

```
$ cat dirfiles
for i in *
do
  if [ -d "$i"]
    then
      echo "$i"
fi
done
```

The ambiguous file reference character * stands for all files (except invisible files) in the working directory. Prior to executing the for loop, the shell expands * and uses the resulting list to assign successive values to the index variable i.

# for

The for control structure has the following format:

```
for loop-index
do\  commands
done
```

In the for structure the loop-index automatically takes on the value of each of the command line arguments, one at a time. It performs a sequence of commands, usu- ally involving each argument in turn.
