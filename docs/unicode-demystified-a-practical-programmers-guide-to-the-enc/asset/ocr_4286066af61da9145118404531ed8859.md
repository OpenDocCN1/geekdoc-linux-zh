Options that enable this stricter compiler behave all with the uppercase -W (Warning).

Among the -W options are a class of warnings that typically result from grammer carelessness or inexperience. The constructs causing these warnings are generally easy to fix and easy to avoid. Table 16-2 lists some of these options.

Get warnings about all the preceding errors, along with others in this class, use the -Wall option.
