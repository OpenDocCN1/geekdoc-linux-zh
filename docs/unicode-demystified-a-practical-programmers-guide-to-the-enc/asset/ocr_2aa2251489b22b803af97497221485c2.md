The second major use of exec is to redirect standard input, output, or error from within a script. Following the next command in a script, all the input to the script is redirected from the file named infile:

```
exec < infile
```

Similarly, the following command redirects standard output and error to outfile and errfile, respectively:

```
exec > outfile 2> outfile
```

When you use exec in this manner, the current process is not replaced with a new process, and exec can be followed by other commands in the script. When a script prompts the user for input, it is useful to redirect the output from within the script to go to the terminal. This redirection ensures that your prompt appears on the user's terminal, even if you have redirected the output from the script. When redirecting the output in a script, you can use /dev/tty as a synonym for the user's terminal. The /dev/tty is a pseudonym the system maintains for the terminal or window the user is using. This pseudonym allows you to refer to the user's terminal without knowing which device it is. By redirecting the output from a script to /dev/tty, you ensure that prompts go to the user's terminal, regardless of which terminal the user is logged in. The following command redirects the output from a script to the terminal the user is on:

```
exec > /dev/tty
```
