# Editing at the Cursor Position

You can type in new text and push the existing text to the right. Entering new text
requires no special commands once the cursor is positioned. If you type in such
that a line goes past the edge of the window, emacs puts a backslash
(\) in column 80 and then wraps the remainder of the text to the next line. The
backslash appears on the screen but is never printed out. Although you can create
an arbitrarily long line, some UNIX tools have problems with text files containing
very long lines. You can split a line at any point by positioning the cursor and
pressing RETURN.
