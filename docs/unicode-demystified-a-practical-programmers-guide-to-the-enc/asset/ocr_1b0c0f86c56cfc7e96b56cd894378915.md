# Static versus Dynamic IP addresses

A static IP address is one that remains the same. A dynamic IP address is one that can change each time you connect to your ISP. A dynamic address remains the same during a single login session. Any server (mail, Web, and so) must have a static address so that clients can find the machine that is the server. End machines usually work well with dynamic addresses. During a given login session, they can function as a client (your Web browser, for example) because they have a constant IP address. When you log out and log in, it does not matter that you have a new IP address, because your computer, acting as a client, establishes a new connection with a server. The advantage of dynamic addressing is that allows inactive addresses to be reused, reducing the total number of IP addresses needed. # IP Classes

To facilitate routing on the Internet, IP addresses are divided into classes. Classes, labeled class A through E, allow the Internet address space to be broken into blocks of small, medium, and large networks that are designed to be assigned on the number of hosts within a network.

When you need to send a message to an address outside your network, your system looks up the address block/class in its routing table and sends the message to the next router on the way to the final destination. Every router along the way does a similar lookup to forward the message. At the destination, local routers directs the message to the specific address. Without classes and blocks, your host would have to know every network and subnetwork address on the Internet before it could send a message. This would be impractical because of the number of addresses on the Internet.
