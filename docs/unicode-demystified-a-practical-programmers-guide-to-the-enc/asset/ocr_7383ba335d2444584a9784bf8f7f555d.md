# $VARIABLE Variable Expansion

Variable expansion takes place when the shell processes a token consisting of a dollar sign $ followed by a variable name (user-defined or keyword), as in $VARIABLE, the token, where VARIABLE is the name of a variable that replaces with the value of the variable.

# Optional

 $VARIABLE syntax is a special case of the more general syntax ${VARIABLE}, in which the variable name is enclosed by ${}. The braces insulate the name from what surrounds it. Braces are necessary when concatenating a variable value with a string:

```
$ PREF=counter
$ WAY=$PREclockwise
$ FAKE=$PREffeit
$ echo $WAY $FAKE
$
```

The preceding example does not work as planned. Only a blank line is output. The reason is that the symbols PREFclockwise and PREffeit are valid variable names, but they are not set. By default the shell generates an unset variable as (null) string and displays this value or generates an error message. To achieve the intent of these statements, refer to the PREF variable using:

```
$ PREF=counter
$ WAY=${PREF}clockwise
$ FAKE=${PREF}ffeit
$ echo $WAY $FAKE
counterclockwise counterfeit
```
