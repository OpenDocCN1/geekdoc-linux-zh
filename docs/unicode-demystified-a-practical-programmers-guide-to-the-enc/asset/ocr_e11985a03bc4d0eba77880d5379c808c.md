# Did You Log in Last?

The line following the password line gives you information about the last login on account, showing when it took place and where it originated. In Figure 2-1 the last access came from a machine named lightning. You can use this information to see whether anyone else may have accessed this account since you used it. If someone has, perhaps an unauthorized user has learned your password and logged on as you. In the interest of security, advise your system administrator of the circumstances that made you suspicious, and change your password (page 40).

When user is your login name, host is the name of your computer, and directory is the name of the directory you are working in. For information on how to change your prompt, refer to page 579, page 749, or page 708.

# GUI: Graphical User Interface

When your system is set up that you log in directly on a GUI (Figure 2-2), you will, by default, log in on the GNOME desktop manager. The welcome message can be set locally so your message will differ from the illustration.) To log in on a different desktop manager, see “Choosing a Desktop Manager” following.
