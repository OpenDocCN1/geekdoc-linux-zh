When cmp displays the bytes that are different in the two files (either the
--print-chars or the --verbose option), the byte from file1 is shown first, followed
by the byte from file2.

# Examples

The examples use the files a and b shown following. These files have two differ-
ences. The first difference is that the word lazy in file a is replaced by lazy in file b.
The second difference is more subtle; a TAB character is just before the NEWLINE charac-
ter file b:

```
$ cat a
The quick brown fox jumped over the lazy dog's back.
$ cat b
The quick brown fox jumped over the lazy dog's back.TAB
```

The first example uses cmp without any options to compare the two files. The
cmp utility reports the files are different and identifies the offset from the start
of the files where the first difference is found:

```
$ cmp a b
b differ: char 39, line 1
```

You can see the values of the bytes at that location by adding the --print-chars
option:

```
$ cmp --print-chars a b
b differ: char 39, line 1 is 172 z 163 s
```

The -l option displays all the bytes that differ in the two files. (Because this op-
t creates a lot of output if the files have many differences, you may want to redi-
 to a file.) Following, the two differences are shown. The -c option displays
the values for the bytes as well. Where a file has a CONTROL-J (NEWLINE), file b has a CON-
tROL-I (TAB). Then cmp displays a message saying that it has reached the end of file on
file a, indicating that file b is longer than file a:

```
$ cmp -1lc a b
39 172 z 163 s
53 12 ^J 11 ^I
cmp: EOF on a
```

In the final example, the --ignore-initial option is used to skip over the first
difference in the files. The cmp utility now reports on the second difference:

```
$ cmp --ignore-initial=39 a b
b differ: char 53, line 1
```
