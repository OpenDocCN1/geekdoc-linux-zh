# Z Shell Options

The Shell has a number of options that you can use to alter the behavior of the shell. Table 15-25 describes many of the available options. Refer to the zsh options page (zoptions) for a complete list.

Z shell names are not case sensitive and ignore underscores. The following-names refer to the same option: ignoreeof, IGNORE_EOF, Ignore_Eof, IGNORE_EOF, IgnN__ore_EoF. (The last name would not be a good choice because it is difficult both to read and to type.) This book uses all uppercase letters to show option names.

The set builtin sets and unsets options. Use set -o to set, turn on, an option and set +o to unset it, or turn off.

```zsh
zsh % set -o IGNORE_EOF
zsh % set +o MARK_DIRS
```

These commands turn on the IGNORE_EOF option and turn off the MARK_DIRS option. MARK_DIRS causes the shell to display a slash (/) following directory names generated by ambiguous file references.

You can also use setopt and unsetopt as alternatives to set -o and set +o, respectively. The following commands perform the same functions as the preceding:

```zsh
zsh % setopt IGNOREEOF
zsh % unsetopt MARK_DIRS
```

You can determine whether an option is on or off with the [...] command (refer to "Control Structures" on page 768). Because [...] generates only a return status, you must check the return status ($?) after you issue the command (0 = true and 1 = false). In the example MARKDIRS is initially off (1), then it is turned on (0), then turned off again:

```zsh
zsh % [[ -o MARKDIRS ]] ; echo $?
1
zsh % set MARKDIRS
zsh % [[ -o MARKDIRS ]] ; echo $?
0
zsh % unsetopt MARKDIRS
zsh % [[ -o MARKDIRS ]] ; echo $?
1
```

Some options have abbreviations that you can use to set or unset them quickly. The XTRACE option has an abbreviation of x, so that you can use XTRACE with the following command (do not use +o with an abbreviated option):

```zsh
zsh % set -x
```

This command turns on the debugging trace. You can set and unset several options with the same command. The following command turns on XTRACE (-x) while turning off IGNORE_EOF and NO_UNSET (+u):

```zsh
zsh % set -x +o ignoreeof +u
```
