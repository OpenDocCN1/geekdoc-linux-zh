# Options

Options marked with an asterisk (*) are set by default in a login shell.

| | |
|---|---|
| ALL_EXPORT (-a) | Causes all subsequently defined variables to be automatically exported. |
| APPEND_HISTORY | Appends history lists to the history file instead of overwriting it. |
| AUTO_LIST (-9) | Automatically lists all choices (/) a completion attempt produces more than one alternative. |
| AUTO_PARAM_SLASH | Appends a slash (/) to directory filenames created by filename completion. |
| BAD_PATTERN (+2) | Displays an error message on badly formed file generation patterns. When unset, no error is displayed. |
| BANG_HIST (+K) | Allows history substitutions using ! |
| BEEP (+B) | Produces audible warnings (beeps) on errors in the Z Shell commands. |
| BG_NICE (-6) | Runs background jobs at a lower priority (default). |
| BRACE_CCL | Permits brace expansion of the form {A-Za-z}. If this option is not set, {A-Z} is expanded, {A-Za-z} is left as is. |
| BSD_ECHO | Causes the echo builtin to mimic the version of echo with BSD Unix. Setting this option disable escape sequences in the arguments to echo unless you give the -option. |
| CLOBBER (+C) | Allows > to overwrite an existing file and >> to create a new file. If this option is not set, you use ! and >> instead. Frequently used by setting NO_CLOBBER. |
| CORRECT (-0) | Attempts spelling correction on command names. |
| CORRECT_ALL (-0) | Attempts spelling correction on all the command line arguments. |
| ERR_EXIT (-e) | Executes the ZERR trap (if set) and exits from the shell if a command terminates with a nonzero exit status. |
| EXEC (+n) | Executes commands. When unset, the shell checks commands for errors but does not run them. |
