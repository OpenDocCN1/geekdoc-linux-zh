# Chapter 12 The Shell II: The Bourne Again Shell

| | |
|---||
| SHELL | Pathname of the invoked shell. |
| status | Exit status of the last task executed by the shell (page 588). |
| $0 | Name of the calling program (page 581). |
| $/ | Value of the $n^{th}$ command line argument (can be changed by set) (page 582). |
| $* | All command line arguments (can be changed by set in bash and tcsh (page 586)). |
| $$ | All command line arguments (can be changed by set in bash and tcsh (page 586)). |
| $# | Count of the command line arguments (page 582). |
| $$ | PID number of the current process (page 586). |
| $1 | PID number of the most recent background task (page 586). |
| $7 | Exit status of the last task executed by the Bourne Again or Z Shell (page 588). |

# Special Characters (Unless Noted)

| | |
|---||
| NEWLINE | Initiates execution of a command (page 547) |
| ; | Separates commands (page 547) |
| ( ) | Groups commands for execution by a subshell or identifies a function (page 550) |
| & | Executes a command in the background (pages 154 and 547) |
| | | Pipe (page 547) |
| > | Redirects standard output (page 145) |
| >> | Appends standard output (page 149) |
