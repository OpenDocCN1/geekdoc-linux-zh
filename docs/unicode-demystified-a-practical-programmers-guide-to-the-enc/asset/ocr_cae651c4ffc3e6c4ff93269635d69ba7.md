# 92 Chapter 17 Red Hat Linux Administration

The following example assumes that you have downloaded GNU chess (www.gnu.org/software/chess/chess.html) in the working directory. First, you need to unpack and decompress it cd to the new directory:

```
$ tar -xvzf chess*
gnuchess-5.03/
gnuchess-5.03/book/
gnuchess-5.03/book/README
...
$ cd gnuchess-
```

After reading the README and INSTALL files, proceed to the first of the two steps: Run the configure script, which finds out about your system and generates the Makefile:

```
$ ./configure
checking for a BSD compatible install... /usr/bin/install -c
checking whether build environment is sane... yes
checking for mawk... make
checking whether make sets ${MAKE}... yes
checking for gcc... gcc
checking for C compiler default output... aout
checking whether the C compiler works... yes
```

Refer to page 1120 in Part III for more information on configure, specifically the --prefix option, which causes the install process to place the source in a directory other than /usr/local. The second step is to run make.
