## print: Displays Output

The syntax for the print built-in which is a replacement for echo print [-cDilnNoOpPrRs] [-un] [string...]

By default, print writes the strings to standard output and recognizes both syntaxes at the end of a string and the -n option for suppressing the trailing NEWLINE. You can embed escape sequences within string to display special characters (Table 15-16). Because each of these sequences starts with a backslash (\), which is a special character to the shell, you must quote each backslash, or escape it, within a print statement. Here is an example of the use of escape sequences within a print statement:

```bash
zsh % print "Columbus' ships:\n\tThe Nina\n\tThe Pinta\n\tThe Santa Maria"
Columbus' ships:
The Nina
The Pinta
The Santa Maria
```

## Escape

| \ | The backslash character |
|---|---|
| \nnn | The ASCII character whose octal value is nnn—you can omit leading zeros |
| \a | The alert character (typically makes the display beep or flash) |

## Escape (Continued)

| | |
|---|---|
| \b | The backspace character |
| \c | Suppresses a trailing NEWLINE |
| \e | ESCAPE character |
| \f | Form feed—puts a CONTROL-L character in the output stream |
| \n | NEWLINE—allows a single call to print write multiple lines |
| \r | RETURN—puts a CONTROL-M character in the output stream |
| \t | TAB character |
| \w | The vertical tab character |
| \nnnn | The ASCII character whose hexadecimal value is nnn |

Some of the options to print (Table 15-17) have the same mean as the corresponding options to read.

## print Options

| | |
|---|---|
| -c (columns) | Displays output in columns. |
| -n (newline) | Suppresses trailing NEWLINES. |
| -o (output) | Sorts the arguments in ascending order before printing. |
| -O (output) | Sorts the arguments in descending order before printing. |
| -p | The command print -p... directs its output line to standard input of the coprocess. Refer to "The Coprocess" (page 806). |
| -r (raw input) | Ignores the special meaning of the escapes; displays them as ordinary characters. |

## print Options (Continued)

| | |
|---|---|
| -R (raw input) | Ignores the special meaning of the escapes; displays as ordinary characters. Also treats any fields as string arguments, even if they start with a hyphen (except for -n). |
| -D (directory) | Treats arguments as directory names. Replaces prefixes with ~expressions where appropriate. |
| -i (insensitive) | Performs case-insensitive sorts. Use the -o or -O option. |
| -l (line) | Outputs the arguments separated by NEWLINES instead of SPACES. Using the -l option, the example on page 778 can be written as |

```bash
zsh % print -l "Columbus" ships: "\tThe Nina" \n"The Pinta" "\tThe Santa Maria"
```
| -N (null) | Outputs the arguments separated by NEWLINES. Terminates the final argument with a null. |
| -P (prompt) | Allows you to use the escape sequences available when setting the PS1 prompt (page 749). |
| -S | Directs output to history file. |
| -U | Sends output to file descriptor n. For more information, refer to "File Descriptors" on page 781. |

The following example demonstrates the effect of several print options:

```bash
zsh % print -R -n -p "NEWLINE \will not be recognized"; ; echo "done"
-p NEWLINE \will not be recognized done
zsh % print "NEWLINE \will not be recognized"; echo "done"
NEWLINE
will not be recognized
done
```

You must (almost) always double quotation marks around the arguments to print and echo. Without the quotation marks a \n will be displayed as n. In the preceding example the second command on the first command line to show that the -n option suppresses the trailing NEWLINE. The -R option causes the -p and the \n not to be interpreted as or special characters. The second command line shows what happens without these options. Because the shell quickly erases the command line before displaying another prompt -n if it is the only command on the command line.
