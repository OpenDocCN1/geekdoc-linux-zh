# EXTRAVERSION Number

To prevent overwriting existing kernel files and identify various compilations of the kernel, you can use the EXTRAVERSION variable in Makefile. This variable is initially set to a dash and the release number, followed by the word custom (for example -14custom). Whatever value you assign to this variable is placed at the end of the kernel name. It is a good idea to keep the original release number, but you can append the date or time to ensure a unique name for the kernel.
