or or H Displays a summary of all available commands. The summary is displayed ing less, as the list of commands extends across several screens of a typical display.

SPACE Displays the next n lines of text. Because the value of n defaults to the size of the screen, SPACE by itself displays the next screen of text.

n Works like SPACE except the value of n, if present, becomes the new default for the z and SPACE commands.

RETURN or n Scrolls forward n lines. The default value of n is 1.

nd or CONTROL-D down Scrolls n lines. The default value of n is one-half the screen size. When you specify n, it becomes the new value for this command.

nb or CONTROL-B Scrolls backward n lines. The default value of n is the size of the screen.

nw Scrolls backward as in the previous command, except that the value of n becomes the new default value for this command.

my or nk Scrolls backward n lines. The default value of n is 1.

mu or CONTROL-L Scrolls backward n lines. The default value of n is half the screen size. When you specify n, it becomes the default value for this command.

/regular-expression Keeps forward in the file, looking for strings matching regular-expression. If you begin regular-expression with an exclamation point (!), this command looks for strings that do not match regular-expression. If regular-expression begins with an asterisk (*), this command continues the search through file-list. If regular-expression begins with an an (@), this command begins the search at the start of file-list and continues to the end of file-list.

?regular-expression This command is similar to the previous one searches backward through the file (and file-list). An asterisk (*) as the first character in regular-expression causes the search to continue backward, through file-list, through the first file. At an sign (@) causes the search to start with the last line of the last file in file-list and progress toward the first line of the first.

{ or or( One of these characters appears in the top line of the display, this command scrolls forward to the matching right brace, parenthesis, or bracket (that is, typing { causes less to the matching }).

) or or) Similar to the preceding commands, these commands move you backward to the matching left brace, parenthesis, or bracket.

CONTROL-L Redraws the screen. This command is useful if the text on the screen becomes garbled.
