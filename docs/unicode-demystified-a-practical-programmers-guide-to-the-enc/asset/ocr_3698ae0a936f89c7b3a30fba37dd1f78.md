You can use pipes to send the output from one task to the next and an imper-sand(&) to run the whole job as a background task. Again the prompt comes immediately. The shell regards the commands joined by a pipe as a single job. The shell treats all pipes as single jobs, no matter how many tasks are connected with the pipe (|) symbol or how complex they are. The TC Shell shows three processes (all belonging to job 1) placed in the background. The Bourne Again and Z Shell show only one process:

```
$ x | y | z
[1] 14302 14304 14306
%
```
