You can run mail commands while mail is in Input mode—all Input commands start with a tilde (∼). They are called tilde escapes because they temporarily escape from Input mode so that you can give a command. The tilde will appear as the first character on a line.

The following list describes some of the more tilde escapes.

+   -command Gives the shell command as a command line while you are composing escapes.

+   -? Displays a list of all tilde escapes.

+   -command replaces the message you are composing with the result of piping the message through command.

+   -b name-list Sends blind copies (Bcc) to name-list. The users who receive blind copies are not listed on the copy of the message that goes to the addressee; the people who receive regular copies (Cc) are, ~c following.

+   -c name-list sends copies (Cc) to name-list.

+   -d dead letter retrieves ~/dead.letter so you can continue writing it, or you can modify it. This file is created when you quit while composing a message.

+   -h header prompts you for the Subject, To, Cc, and Bcc fields. Each prompt includes the current entries for that field; you can use the erase and line keys to back up over and edit the entries.

+   -m [msg-list] message includes the messages specified by the msg-list in a message you are composing, placing a TAB at the beginning of each line. (Refer to “Reading Messages,” which follows, for a description of msg-list.) You can use ~m only when you are sending a message while reading your messages (see the m and r commands, also in “Reading Messages”).

+   -p print displays the message you are currently composing.

+   -q quits, saving the message you are composing in the file dead.letter in your home directory. ~d for retrieving this file.

+   -filename reads filename into the message you are composing.

+   -s subject sets the subject field for the message you are composing to subject, replacing the current subject if there is one.

+   -t name-list adds name-list to the list of recipients.

+   -v vi calls the vi editor so that you can edit the message you are composing.
