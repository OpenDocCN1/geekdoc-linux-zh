Desktop shortcuts | The scrolling text box displays a list of the commands that could/have a key bound to it. Click the action/shortcut you want to change; the shortcut changes to Type new accelerator. Press the key or key combination you want to use as a shortcut. Press BACKSPACE to disable a shortcut.

## Login Photo

Sets up an identification photo that you can click, instead of typing your name, to log in the system. GDM (GNOME Display Manager) must be set up in order to use this option.
