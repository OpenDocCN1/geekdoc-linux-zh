The next example again shows that, unless instruct it, order sorts a file starting with the field you specify and continuing to the end of the line. It does not make a second pass unless two of the first fields are the same. Although this example sorts the cars by years, it does not sort the cars by manufacturer within years:

| sort +2 +0 cars | | | |
|---|---|---|--|
| fiat | 600 | 65 | 115 | 450 |
| ford mustang | 65 | 45 | 10000 |
| chevy impala | 65 | 85 | 1550 |
| plym fury | 77 | 73 | 2500 |
| volvo g1 | 78 | 102 | 9850 |
| chevy nova | 79 | 60 | 3000 |

| ford ltd | 83 | 15 | 10500 |
| ford bronco | 83 | 25 | 9500 |
| ford thundbd | 84 | 10 | 17000 |
