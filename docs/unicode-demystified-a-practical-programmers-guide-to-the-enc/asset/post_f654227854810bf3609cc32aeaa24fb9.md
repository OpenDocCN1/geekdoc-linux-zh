# Receiving Mail

In order to read his mail, Alex starts pine by giving the following command to enter the Main menu:

# $ pine

He selects the highlighted item Folder List for a list of viewing message folders—files that pine use to store mail messages.

| INBOX | sent-mail | saved-messages |

The first time you run pine, the utility creates folders named INBOX, sent-mail, and saved-messages. INBOX stores messages before you read them and messages that you have read. The sent-mail folder stores copies of all mail you send, and the saved-messages folder stores messages you want to save. You can also use pine to create and delete folders, transfer messages from one folder to another, and organize folders.
