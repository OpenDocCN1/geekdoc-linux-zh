--help Displays a detailed list of all the options available for use with configure. The tents of this list depends on the software distribution being configured.

# Discussion

The configure script determines which C compiler to use (usually gcc) and speci a set of flags to pass to that compiler. You can set the environment variables CC and CFLAGS to override these values with your own choices. See the “Examples” section.

# Notes

Each package that uses the GNU autoconfiguration utility provides its own copy of configure, which the software developer created using the GNU autoconf utility. The README and INSTALL files are provided with these pack ages for detailed information about the options that are available.

The configure scripts are self-contained and run correctly on a wide variety of systems. You need no special system resources to configure.

# Examples

The simplest way to call configure is to cd to the base directory for the software distrib tion you want to configure and run the following command:

```
$ ./configure
```

The ./ is prepended to the command name to ensure that you are running the config ure script that was supplied with the software distribution. To cause configure to build makefiles that pass the flags -Wall and -O2 to gcc, use the following com mand from either bash or zsh:

```
$ CFLAGS="-Wall -O2" ./configure
```

If you are using tcsh, use the following command:

```
> env CFLAGS="-Wall -O2" ./configure
```
