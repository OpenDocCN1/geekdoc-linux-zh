When you are writing a longer gawk program, it is convenient to put the program in
a file and reference the file on the command line. Use the -f option, followed by
the name of the file containing the gawk program.

The following gawk program, named pr_header, has two actions and uses the BEGIN
pattern. The gawk utility performs the action associated with BEGIN before processing
any of the data lines: It prints a header. The second action, {print}, has no
pattern part and prints all the lines in the file:

```
$ cat pr_header
{print "Make Model Year Miles Price"}
{print}
```

When you call the length function without an argument, it returns the $0 variable
always contains characters in the current line, including the value of the current line.
In the next example gawk prepends the output from gawk to sort so that the lines of
the cars appear in order of length:

```
$ gawk 'print length, $0' cars | sort
19 fiat 600 115 450
20 ford ltd 83 15 10500
20 plum fury 77 73 2500
21 volvo gl 78 102 9850
21 chevy nova 79 60 3000
22 chevy nova 80 50 3500
23 ford bronco 83 25 1550
23 chevy impala 65 85
24 ford mustang 65 45 10000
24 ford thunder 84 10 17000
24 toyota tercel 82 180 750
```

The formatting of this report depends on TABs for horizontal alignment. The three
extra characters at the beginning of each line throw off the format of several lines,
including the last. A remedy for this situation is covered shortly.

The NR variable contains the record (line) number of the current line. The following
pattern selects all lines that contain more than 23 characters. The action prints the
line number of all the selected:

```
$ gawk 'length > 23 {print NR}' cars
3
9
10
```

You can combine the range operator (,) and the NR variable to display a group of lines of a
based on their line numbers. The next example displays lines 2 through 4:

```
$ gawk 'NR == 2, NR == 4' cars
chevy nova 79 60 3000
ford mustang 65 45 10000
volvo gl 78 102 9850
```

# END

The END pattern works in a manner similar to the BEGIN pattern, except that gawk takes
the actions associated with it after it has processed the last input lines. The following
report displays information after it has processed the data. The NR variable retains its
value after gawk finished the data, so that an action with an END pattern can use it:

```
$ gawk 'END {print NR}' cars
```

The next example uses if commands to change the values of some fields. As long as gawk
does not make any changes to a record, it leaves the entire record, including separators,
intact. Once it makes a change to a record, gawk changes all separators in that record to the
value of the output field. The default output separator is a SPACE:

```
$ gawk -f ods_demo cars
plymouth fury 77 73 2500
chevrolet nova 79 60 3000
ford mustang 65 45 10000
volvo gl 78 102 9850
ford ltd 83 15 10500
chevrolet nova 80 50 3500
fiat 600 65 450
honda accord 81 30 6000
ford thunder 84 10 17000
toyota tercel 82 180 750
chevrolet impala 65 85 1550
ford bronco 83 25 9500
```

You can change the default value of the output separator by assigning a value to the OFS
variable. This example assigns a TAB character to OFS, using a common notation. This fix
improves the appearance of the report but does not properly up the columns:

```
$ cat of_demo
BEGIN
OFS = "\t"
{
if ($1 ~ /ply/) $1 = "plymouth"
if ($1 ~ /chev/) $1 = "chevrolet"
print
}
```

You can use printf (page 1991) to refine the output format. The following example uses a
backslash at the end of a program line to make the newline from gawk. You can use this
technique to continue a long line over one or more lines without affecting the outcome of
the program.

# $ cat printf_demo

```
BEGIN {
    print ""
    print "Make          Model      Year      (000)     Price"
    print "\""
    if ($1 ~ /ply/) $1 = "plymouth"
    if ($1 ~ /chev/) $1 = "chevrolet"
    printf "-%10s %8s   %12d %5d   $ %8.2f\n", \
           $1, $2, $3, $4, $5
}
```
