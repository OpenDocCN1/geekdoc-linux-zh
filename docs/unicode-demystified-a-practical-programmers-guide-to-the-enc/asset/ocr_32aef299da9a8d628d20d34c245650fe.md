The shell provides a feature called noclber (page 554) that stops you from inadvertently overwriting an existing file using redirection. When you enable this feature by setting the noclber variable and you attempt to redirect output to an existing file, the shell presents an error message and does not execute the command. If the preceding examples result in one message of the following messages, the noclber feature is in effect. The following examples set noclber, attempt to redirect the output from `echo` into an existing file, and then unset noclber in each of the major shells:

```
bash
bash $ set -noclber
bash $ echo "hi there" > tmp
bash: tmp: Cannot overwrite existing file
bash $ set +noclber
```
