```
$ co -l thesis
RCS/thesis,v --> thesis
revision 1.4 (locked)
done
```

The next command displays revision 1.3 of thesis (without storing it in a new file):

```
$ co -rl1.3 -p thesis
RCS/thesis,v --> stdout
revision 1.3
.
```

The last command retrieves the latest revision of thesis that was checked in at or before the specified time:

```
$ co -d'Thu Jul 14 2 pm 1lt' thesis
```
