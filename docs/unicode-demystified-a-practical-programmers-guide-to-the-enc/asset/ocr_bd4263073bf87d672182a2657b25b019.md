# GNU/Linux Can Support Many Users

Depending on the hardware and what types of tasks the computer performs, GNU/Linux system can support from 1 to 1000 users, concurrently running a different set of programs. The cost of a computer that can be used by many people at the same time is less per user than that of a computer that can be used by only a single person at a time. The cost is less because one person cannot use all the resources a computer has to. No one can keep the printers going constantly, keep all system memory in use, keep the disks busy reading and writing, keep the modems in use. A multiuser operating system allows many people to use all the resources almost simultaneously. The use of costly resources can be maximized, and the cost per user can be minimized. These are the primary objectives of a multiuser operating system.

# GNU/Linux Can Run Many Tasks

GNU/Linux is a fully protected multitasking operating system, allowing each user to run more than one job at a time. Although processes can communicate with one another, they are also fully protected from one another, just as the kernel protects from all processes. You can run several jobs in the background while giving all your attention to the job being displayed on your screen, and can switch back and forth between jobs. If you are running the X Window System (page 17), you can run different programs in different windows on the same screen and watch all of them. With this capability, users can be more productive.

# GNU/Linux Provides a Secure Hierarchical Filesystem

A file is a collection of information, as text for a memo or report, an accumulation of sales figures, an image, or an executable program created by a compiler. Each file is stored under a unique identifier on a storage device, such as a hard disk. The GNU/Linux filesystem provides a structure where files are arranged under directories, which are like folders, or boxes. Each directory has a name and can hold other files and directories. Directories in turn are arranged under directories, and so forth, in a treelike organization. This structure helps users keep track of large numbers of files by grouping related files into directories. Each user has one primary directory and as many subdirectories as required (Figure 1-2).
