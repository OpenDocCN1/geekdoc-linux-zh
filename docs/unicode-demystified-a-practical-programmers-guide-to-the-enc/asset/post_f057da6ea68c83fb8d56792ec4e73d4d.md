# Red Hat Linux System Administration

The job of a system administrator is to keep one or more systems useful and convenient for users.

A well-maintained system:

- Runs quickly enough so that users do not get too frustrated waiting for the system to complete.
- Has enough storage to accommodate users' needs.
- Provides a working environment appropriate to each user.
- Is secure from malicious and accidental acts altering its performance or the security of the data holds.
- Is backed up regularly with.
- Has recent copies of the software that users need.
- Is easier to administer than a poorly maintained system.

In addition, a system administrator should be available help users with all types of system-related problems: from logging in to obtaining and installing software-updates to tracking down obscure network issues.

This chapter familiarizes you with the concepts you need to understand and the tools you need to maintain a Hat Linux System. Where it is not possible to go deep into a subject, the chapter provides references to other sources.

GNU/Linux systems are increasingly easy to set up and maintain. If you are not running an installed copy of Red Hat Linux and need to install it, the process is much easier than it used to be. Red Hat has a lot to improve and simplify installation. One tool that Red Hat developed is the rpm (Red Hat package manager) utility, which makes installing/upgrading system and application software much easier. Because Red Hat it the GNU GPL (page 7), rpm has been improved by engineers outside of Red Hat, and it appears in other distributions of GNU/Linux. A more recent development is RHN (Red Hat Network), which allows Red Hat to keep your system up-to-date with little or no interaction.¹ With the Kickstart Configurator, you can design a simple script that allows you to install the same configuration of Red Hat Linux on multiple machines with little effort. Finally, all these tools, as well as other administration utilities, are available with GUIs, making each easier to set up and use.

Because GNU/Linux is configurable and runs on various platforms (Sun SPARC, DEC/Compaq Alpha, Intel x86, AMD, PowerPC, and more), this chapter cannot discuss every system configuration or every action you will have to take as a system administrator.
