After defining a partition k m kilobytes or megabytes, run p to check for the ending cylinder. Do this before defining the next contiguous partition that do not have space or any overlap. After setting up all the partitions and exiting fdisk with a w command, make a filesystem (mkfs, page 1057) on each partition that is to hold a filesystem (not swap). Use mkswap to create a swap partition (page 967). You can use elabel to label partitions (page 1057).

# ## Disk Druid: Partitioning a Disk

Disk Druid, a graphical disk-partitioning program that can add, delete, and modify partitions on a hard drive, is part of the Red Hat installation system, so you can use Disk Druid only while you are installing a system: It cannot be run on its own. You must use fdisk to install or modify disks after you have installed Red Hat Linux.

When you start a base of partitions you can allow Disk Druid to partition the hard drive automatically. You can also use Disk Druid to partition the hard drive manually with steps that are similar to fdisk. Click Show Help to display instructions. Follow the instructions on the side panel as you may proceed. Make your files-type ext3 unless you have reason to do otherwise.

With the introduction of Red Hat version 8.0, Disk Druid includes Clone, a tool that copies the partitioning scheme from a single drive to as many other drives as needed. The Clone tool is useful for making multiple copies of a RAID device when you are creating a large RAID array of partitioned drives. Click the RAID button to access the Clone tool, which is active only when at least one unallocated RAID partition exists.
