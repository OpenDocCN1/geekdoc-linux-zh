# Windows and Mouselicks

It is important to know where to position the mouse pointer and which mouse buttons to use to accomplish various tasks. Table 7-1 describes the default values for selected mouse clicks under the Metacity window manager with the Bluecurve frame style (both are defaults under GNOME as shipped by Red Hat).

| Mouse Clicks and Results | table 7-1 |

The symbol [M] indicates that the feature is available only in Metacity; [S] indicates Šawish. The absence of a symbol indicates that the feature is available from both window managers. Under Metacity, right clicks not listed display the Window Operations menu.
