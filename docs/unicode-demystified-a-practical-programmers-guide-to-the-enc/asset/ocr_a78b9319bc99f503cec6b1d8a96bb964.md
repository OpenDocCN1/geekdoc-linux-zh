```
$ gawk 'print length, $0' cars | sort
```

The formatting of this report depends on TABs for horizontal alignment. The three extra characters at the beginning of each line throw off the format of several lines, including the last. A remedy for this situation is covered shortly.

The NR variable contains the record (line) number of the current line. The following pattern selects all lines that contain more than 23 characters. The action prints the line number of all the selected:

```
$ gawk 'length > 23 {print NR}' cars
3
9
10
```

You can combine the range operator (,) and the NR variable to display a group of lines of a file, based on their line numbers. The next example displays lines 2 through 4:

```
$ gawk 'NR == 2, NR == 4' cars
chevy nova 79 60 3000
ford mustang 65 45 10000
volvo gl 78 102 9850
```
