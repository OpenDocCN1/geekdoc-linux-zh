# Empty Regular Expressions

Within some utilities, such as vi and less, but not grep, an empty regular expression represents the last regular expression that you used. For example, if you give vi the following Substitute command:

```
:s/mike/robert/
```

and then want to make the same substitution again, you can use the following command:

```
:s//robert/
```

Alternatively, you can use the following commands to search for the string mike and then make the substitution

```
/mike/
```

```
:s//robert/
```

The empty regular expression (//) represents the last regular expression you used (/mike/).
