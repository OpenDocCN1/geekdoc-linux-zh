# Examples

The first example demonstrates the use of the ci utility to create a new RCS file:

$ ci thesis
RCS/thesis,v <-- thesis
enter description, terminated with a single '.' or end of file:
NOTE: This is NOT the log message!
>> Master copy of this thesis.
>>
initial revision: 1.1
done
$

The following examples illustrate the use of the ci utility after co has used
with the -l option to retrieve the highest revision on the trunk. In this example, the
user enters comments directly on the command line with the -m option and uses the
-l option to retrieve the new revision for editing:

```
$ ci -l -m"first pass at chapter one" thesis
RCS/thesis,v <-- thesis
new revision: 1.2; previous revision: 1.1
done
```

The next example starts a new revision level, using the -r option:

```
$ ci -r2 thesis
RCS/thesis,v <-- thesis
new revision: 2.1; previous revision: 1.2
enter log message, terminated with a single '.' or end of file:
>> major reorganization
done
```

The following example is identical to the preceding one, except that the new re-
vision is available for reading (only) after it is checked in:

```
$ ci -u2 thesis
RCS/thesis,v <-- thesis
new revision: 2.1; previous revision: 1.2
enter log message, terminated with single '.' ' or end of file:
>> major reorganization
done
```
