Internet Superviser

Listens for service requests on network connections and starts up the appropriate daemon to respond to any particular request. Because of xinetd, your system does not have to have all the daemons running all the time in order to handle various network requests. The configuration for xinetd is /etc/xinetd.conf, which frequently includes all the files in the /etc/xinetd.d directory with the line

```
includedir /etc/xinetd.d
```

Each of the files in xinetd.d is named after a service that it controls. Each file contains a line that starts with disable= and finishes with yes or no. This line determines whether the service can run.

# Proxy Server

A proxy is a network service that is authorized to act for a system while not being part of that system. A proxy server or proxy gateway provides proxy services; it is a transparent intermediary, relaying communications back and forth for an application, such as a browser and a server, usually outside of your LAN and frequently on the Internet. When more than one process uses proxy gateway/server, it must keep track of which processes are connecting to hosts/servers or that it can return the return messages to the proper process. The most common proxies that a user encounters are e-mail and Web proxies.

A proxy/gateway isolates the local computer from all other computers or from specified domains using at least two IP addresses: one to communicate with your local computer and one to communicate with a server. The proxy server/gateway examines and changes the header information on all packets that it can encode, route, and decode them properly.
