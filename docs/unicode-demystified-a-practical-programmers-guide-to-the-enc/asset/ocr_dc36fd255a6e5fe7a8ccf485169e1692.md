# Discussion

In the following description, a field is a sequence of characters on a line in an input file. These sequences are bounded by blanks or a blank and the beginning or end of line. These fields are used to define sort fields.

A sort field is a sequence of characters that sort uses to put lines in order. A sort field can contain part or all of one or more fields in the input file. Refer to Figure III-1.

The field-specifier-list contains pairs of pointers that define subsections of each line (sort fields) for comparison. A pointer is in the form ±f.c. The first of each pair pointers begins with a plus sign, and the second begins with a hyphen or minus sign.

You can make a pointer to any character on a line. Pointers having the form ±c f and c characters. The plus sign that precedes the first of each pair of pointers indicates that all characters to the right of the pointer, up to the other pointer in the pair, are to be included in the sort field. If there is no second pointer in the pair, all characters up to the end of the line are included. The hyphen or minus sign that precedes the second pointer in the pair indicates that all characters to the left of the pointer, back to the first pointer in the pair, are to be included in the sort field.
