# 面板

KDE 主面板（kicker）和扩展面板于第 276 页引入。面板（主或扩展）包含按钮（无句柄图标）和小部件（带句柄）。左点击按钮启动与其关联的程序。右点击按钮将显示包含面板菜单（跟随）和其他选项的菜单。左点击小部件启动该部件执行的任何操作。右点击小部件将弹出上下文菜单。 |
