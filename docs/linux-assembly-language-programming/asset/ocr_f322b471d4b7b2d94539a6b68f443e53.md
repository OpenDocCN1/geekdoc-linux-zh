# 11.4.2 Scalex Interrupt Handler

One vital link between the interrupt handler, which is written in assembler, and the rest of the program is the definition of the scalex device memory area. Since the assembly code does not have access to the labels used in the C compiler, it is important to count off the offset bytes from the beginning of the structure. These are used to access the device memory. Hence scalex_area + 4 is used instead of scalex_area.readin. Since all the components of this structure are four bytes in size, there are no tricks in the counting.
