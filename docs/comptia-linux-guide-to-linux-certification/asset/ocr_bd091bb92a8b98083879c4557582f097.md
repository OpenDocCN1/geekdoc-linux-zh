> Unlike hard disks that use a MBR, GPT hard disks don't need to adhere to the limitation of 4 primary partitions. Instead, you can create as many as 128 primary partitions $(/dev/sda1$ to /dev/sda128). Consequently, there is no need for extended partitions or logical drives on a hard disk that uses a GPT.
