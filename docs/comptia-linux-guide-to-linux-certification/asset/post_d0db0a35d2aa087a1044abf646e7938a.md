
## Project 5-2

In this hands-on project, you create a filesystem on a floppy disk and practice mounting it to the directory tree.

- 1. Switch to a command-line terminal (tty2) by pressing **Ctrl+Alt+F2**. Log in to the terminal using the user name of **root** and the password of LNXrocks!. At the command prompt, type **poweroff** and press **Enter** to shut down your virtual machine. In your virtualization software, create a new virtual floppy disk and attach it to your virtual machine. Next, boot your virtual machine. After your Linux system has loaded, switch to a command-line terminal (tty2) by pressing **Ctrl+Alt+F2**. Log in to the terminal using the user name of **root** and the password of LNXrocks!. At the command prompt, type **fdformat /dev/fd0** and press **Enter**. This will format your new virtual floppy disk. At the command prompt, type **mformat -i /dev/fd0 floppy** and press **Enter** to create a new FAT filesystem on the floppy disk. The `floppy` parameter is the name of the new filesystem.
- 2. After your Linux system has loaded, switch to a command-line terminal (tty2) by pressing **Ctrl+Alt+F2**. Log in to the terminal using the user name of **root** and the password of LNXrocks!. At the command prompt, type **poweroff** and press **Enter** to shut down your virtual machine.
- 3. In your virtualization software, create a new virtual floppy disk and attach it to your virtual machine. Next, boot your virtual machine. After your Linux system has loaded, switch to a command-line terminal (tty2) by pressing **Ctrl+Alt+F2**. Log in to the terminal using the user name of **root** and the password of LNXrocks!.
- 4. At the command prompt, type **fdformat /dev/fd0** and press **Enter**. This will format your new virtual floppy disk. At the command prompt, type **mformat -i /dev/fd0 floppy** and press **Enter** to create a new FAT filesystem on the floppy disk. The `floppy` parameter is the name of the new filesystem.
- 5. At the command prompt, type **mount -t vfat /dev/fd0 /mnt** and press **Enter** to mount the new filesystem on the /mnt directory. At the command prompt, type **ls /mnt** and press **Enter**. What files do you see? Why? Next, type **cd /mnt** and press **Enter**. Type **mkdir newdir** and press **Enter** to create a new directory. At the command prompt, type **ls /mnt** and press **Enter**. What files do you see now? Why?
- 6. At the command prompt, type **mkdir /mnt/newdir1** and press **Enter** to create a new directory. Next, type **touch /mnt/newdir1/file1** and press **Enter** to create a new file. At the command prompt, type **ls -a /mnt/newdir1** and press **Enter**. What files do you see? Why?
- 7. At the command prompt, type **umount /mnt** and press **Enter** to unmount the filesystem. Next, type **ls /mnt** and press **Enter**. What files do you see now? Why?
- 8. At the command prompt, type **fdformat /dev/fd0** and press **Enter**. This will format your new virtual floppy disk again. At the command prompt, type **mformat -i /dev/fd0 floppy** and press **Enter** to create a new FAT filesystem on the floppy disk. The `floppy` parameter is the name of the new filesystem.
- 9. At the command prompt, type **mount -t vfat /dev/fd0 /mnt** and press **Enter** to mount the new filesystem on the /mnt directory. At the command prompt, type **ls /mnt** and press **Enter**. What files do you see? Why? Next, type **cd /mnt** and press **Enter**. Type **mkdir newdir2** and press **Enter** to create a new directory. At the command prompt, type **ls /mnt** and press **Enter**. What files do you see now? Why?
- 10. At the command prompt, type **mkdir /mnt/newdir2/next** and press **Enter** to create a new subdirectory. Next, type **touch /mnt/newdir2/next/file2** and press **Enter** to create a new file. At the command prompt, type **ls -a /mnt/newdir2/next** and press **Enter**. What files do you see? Why?
- 11. At the command prompt, type **cd /mnt/newdir2/next** and press **Enter**. At the command prompt, type **ls** and press **Enter**. What files do you see? Why? Next, type **cat file2** and press **Enter**. What is displayed on the screen? Why?
- 12. At the command prompt, type **cd /mnt** and press **Enter**. At the command prompt, type **ls** and press **Enter**. What files do you see? Why? Next, type **ls -l** and press **Enter**. What additional information is displayed on the screen? Why?
- 13. At the command prompt, type **du -sh** and press **Enter**. What is displayed on the screen? Why? Next, type **du -sh /mnt** and press **Enter**. What is displayed on the screen? Why?
- 14. At the command prompt, type **df -h** and press **Enter**. What is displayed on the screen? Why? Next, type **df -h /mnt** and press **Enter**. What is displayed on the screen? Why?
- 15. At the command prompt, type **umount /mnt** and press **Enter** to unmount the filesystem. Next, type **ls /mnt** and press **Enter**. What files do you see now? Why?
- 16. At the command prompt, type **fdformat /dev/fd0** and press **Enter**. This will format your new virtual floppy disk for the last time. At the command prompt, type **mformat -i /dev/fd0 floppy** and press **Enter** to create a new FAT filesystem on the floppy disk. The `floppy` parameter is the name of the new filesystem.
- 17. At the command prompt, type **mount -t vfat /dev/fd0 /mnt** and press **Enter** to mount the new filesystem on the /mnt directory. At the command prompt, type **ls /mnt** and press **Enter**. What files do you see? Why?
- 18. At the command prompt, type **umount /mnt** and press **Enter** to unmount the filesystem. Next, type **ls /mnt** and press **Enter**. What files do you see now? Why?
- 19. At the command prompt, type **poweroff** and press **Enter** to shut down your virtual machine. After your virtual machine has shut down, disconnect your new virtual floppy disk and detach it from your virtual machine.

## Project 5-3

In this hands-on project, you mount DVDs to the directory tree and view their contents.

- 1. Switch to a graphical terminal (tty1) by pressing **Ctrl+Alt+F1** and log in to the GNOME desktop using the user name of *user1* and the password of *LNXrocks!*.
- 2. Click the **Activities** menu and select the **Files** icon to open the Files application.
- 3. In your virtualization software, attach the DVD ISO image for Fedora Linux (Fedora-Live-Desktop-x86_64-20-1.iso) to the DVD drive for the virtual machine. After you have completed this action, view your Files application. Is there an icon that represents your Fedora Live Desktop DVD in the left pane? Place your mouse over this icon to view the mount point directory. Which directory was your DVD automatically mounted to?
- 4. Take a few moments to explore the contents of the DVD within the Files application. When finished, click the eject button next to the Fedora Live Desktop DVD icon to eject the DVD.
- 5. Switch to a command-line terminal (tty2) by pressing **Ctrl+Alt+F2** and log in to the GNOME desktop using the user name of *root* and the password of *LNXrocks!*.
- 6. In your virtualization software, attach the DVD ISO image for Fedora Linux (Fedora-Live-Desktop-x86_64-20-1.iso) to the DVD drive for the virtual machine. After you have completed this action, type `mount` and press `Enter`. Is the DVD automatically mounted?
- 7. Next, type `mount /dev/cdrom /mymount` at the command prompt, and press `Enter`. What warning did you receive? Was the DVD successfully mounted to the /mymount directory?
- 8. At the command prompt, type `ls -F /mymount` and press `Enter`. Do you see the same files as you did in Step 4? Why?
- 9. At the command prompt, type `ls -l /dev/cdrom` and press `Enter`. What target file does the /dev/cdrom symbolic link point to?
- 10. At the command prompt, type `mount` and press `Enter`. Note the line at the bottom that lists your mounted DVD. What filesystem was automatically detected earlier when you mounted your DVD? Is the device file identical to the target file shown in Step 9?
- 11. Next, type `umount /mymount` at the command prompt and press `Enter`. Was the DVD successfully unmounted from the /mymount directory? Type the `mount` command at a command prompt and press `Enter` to verify this.
- 12. In your virtualization software, detach the DVD ISO image for Fedora Linux (Fedora-Live-Desktop-x86_64-20-1.iso) to the DVD drive for the virtual machine. This performs the same action as ejecting the DVD from the physical DVD drive.
- 13. Type `exit` and press `Enter` to log out of your shell.
