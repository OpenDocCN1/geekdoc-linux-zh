

- 在虚拟化软件中，创建一个新的名为 **Ubuntu Server Linux** 的虚拟机，其具有以下特性：
  - 2GB 内存
  - 通过 PC 的网卡建立互联网连接（建议使用桥接模式）
  - 20GB 虚拟硬盘
  - 虚拟机的 DVD 光驱连接到 Ubuntu Server 14.04 安装介质的 ISO 文件（ubuntu-14.04.1-server-amd64.iso）

启动并通过虚拟化软件连接到你的 Ubuntu Server Linux 虚拟机。

![](img/c27875544958897d817484d558c208c8_316_0.png)

**Ubuntu Server Linux** 安装程序不使用图形化桌面。因此，你必须使用 **Tab** 键在屏幕上的按钮之间切换，并按下 **Enter** 键进行选项选择。

- 在语言屏幕，确保选中 **English**，然后按 **Enter**。
- 在 Ubuntu 欢迎屏幕，检查选项。是否有选项允许你检查安装介质是否有缺陷以及使用 memtest86 测试 RAM 是否有缺陷？确保选中 **Install Ubuntu Server**，然后按 **Enter**。
- 在“选择语言”页面，确保选中 **English**，然后按 **Enter**。
- 在“选择您的位置”屏幕，确保选中 **United States**，然后按 **Enter**。
- 在“配置键盘”屏幕，选择 **Yes** 并按 **Enter**。按照提示完成检测。当检测过程发现 “us” 键盘布局时，选择 **Continue** 并按 **Enter**。
- 在“配置网络”屏幕，输入主机名 **UbuntuXX**（其中 XX 是课程设置期间分配给你的唯一编号），选择 **Continue** 并按 **Enter**。
- 在“设置用户和密码”页面，输入 **user1** 作为完整用户名，选择 **Continue** 并按 **Enter**。当提示简单用户名时，确保显示 **user1**，选择 **Continue** 并按 **Enter**。当提示 user1 的密码时，输入 **LNxrocksl**，选择 **Continue** 并按 **Enter**。当提示重复密码时，再次输入 **LNxrocksl**，选择 **Continue** 并按 **Enter**。当提示加密 user1 的主目录时，确保选中 **No** 并按 **Enter**。
- 在“配置时钟”屏幕，确保显示正确时区，选择 **Yes** 并按 **Enter**。或者，如果显示错误时区，选择 **No**，按 **Enter**，选择你的时区，然后按 **Enter**。
- 在“划分磁盘”屏幕，注意默认选择是 **Guided – use entire disk and set up LVM**，按 **Enter**。再次按 **Enter** 选择你的磁盘（sda 或 hda），然后选择 **Yes** 并按 **Enter** 将分区更改写入磁盘。注意卷组使用了全部大小（约 20GB），选择 **Continue** 并按 **Enter**。

- 12. 在摘要屏幕，注意 Ubuntu 将为根文件系统创建一个使用 ext4 文件系统的 LV，并为 swap 创建一个 LV。选择 **Yes** 并按 **Enter** 将更改写入磁盘并启动核心系统软件包的安装。
- 13. 在“配置包管理器”屏幕，可选地提供你课堂代理的 URL 地址（如果课堂使用代理），选择 **Continue** 并按 **Enter**。
- 14. 在“配置 taskel”，确保选中 **No automatic updates** 并按 **Enter**。为什么生产服务器通常禁用自动更新？
- 15. 在“软件选择”屏幕，使用空格键单独选择所有软件包（除了“手动软件包选择”），选择 **Continue** 并按 **Enter**。
- 16. 在“配置 mysql-server-5.5”屏幕，提供密码 **LNXrocks1**，选择 **Continue** 并按 **Enter**。当提示确认密码时，输入 **LNXrocks1**，选择 **Continue** 并按 **Enter**。
- 17. 在“Postfix 配置”屏幕，确保选中 **Internet Site** 并按 **Enter**。当提示系统邮件名称时，确保列出 **UbuntuXX**（其中 XX 是课程设置期间分配给你的唯一编号），选择 **Continue** 并按 **Enter**。
- 18. 在“配置 devcert-core”屏幕，确保选中 **Yes** 并按 **Enter** 创建 SSL 加密证书。当提示证书中使用的 host name 时，在 localhost 位置输入 **UbuntuXX**（其中 XX 是课程设置期间分配给你的唯一编号），选择 **Continue** 并按 **Enter**。
- 19. 在“在硬盘上安装 GRUB 引导加载器”屏幕，确保选中 **Yes** 并按 **Enter**。
- 20. 在“完成安装”屏幕，确保选中 **Continue** 并按 **Enter** 重启到新系统。
- 21. 系统启动后，注意没有图形化登录可用。使用密码 **LNXrocks1** 以 user1 身份登录。在命令提示符下，输入 `who` 并按 **Enter**。你正在使用什么终端？
- 22. Ubuntu Server 安装过程中未设置 root 用户密码。相反，安装过程中配置的用户（user1）在安装后有能力配置 root 用户密码。在命令提示符下，输入 `sudo passwd root` 并按 **Enter**。当提示时提供 user1 的密码 **LNXrocks1** 并按 **Enter**。当提示时为 root 用户输入密码 **LNXrocks1** 并按 **Enter**。通过输入 **LNXrocks1** 确认 root 用户密码并按 **Enter**。
- 23. 在命令提示符下，输入 `su - root` 并提供密码 **LNXrocks1** 切换到 root 用户。
- 24. 在命令提示符下，输入 `df` 并按 **Enter**。检查 `df` 命令的输出。为什么在你的硬盘上创建了一个 /boot 分区？/ (root) 文件系统是否是由 LVM 管理的卷？
- 25. 在命令提示符下，输入 `fdisk -l` 并按 **Enter**。注意驱动器剩余部分是一个扩展分区（`/dev/sda2` 或 `/dev/hda2`），其中包含一个专用于 LVM 的逻辑驱动器（`/dev/sda5` 或 `/dev/hda5`）。
- 26. 在命令提示符下，输入 `lvdisplay` 并按 **Enter**。注意在 Ubuntu-XX-vg 卷组中为根文件系统和交换分区创建的逻辑卷。
- 27. 输入 `exit` 并按 **Enter** 退出你的 shell。

## 项目 6-2

在这个动手项目中，你将检查 Fedora Linux 和 Ubuntu Server Linux 上的安装日志文件和系统信息。

- 1. 在你的 Ubuntu Server Linux 虚拟机上，使用用户名 root 和密码 `LNXrocks1` 登录命令行终端（`tty1`）。
- 2. 在命令提示符下，输入 `ls /var/log/installer` 并按 **Enter**。这个目录中有哪些常规日志文件？从它们的名称来看，这些文件中哪些可能包含系统信息，哪些包含安装过程中发生的事件？
- 3. 在命令提示符下，输入 `egrep -i "(error|warn)" /var/log/installer/syslog` 并按 **Enter**。查看安装过程中发生的任何警告或错误。
- 4. 在命令提示符下，输入 `ls -F /proc` 并按 **Enter** 查看 proc 文件系统的内容和目录。
- 5. 在命令提示符下，输入 `less /proc/cpuinfo` 并按 **Enter**。安装是否正确检测了你的 CPU？输入 `q` 退出 less 工具。
- 6. 在命令提示符下，输入 `less /proc/modules` 并按 **Enter**。显示的是什么？每个条目代表什么？输入 `q` 退出 less 工具。
- 7. 在命令提示符下，输入 `less /proc/meminfo` 并按 **Enter**。你的 Linux 系统是否识别了电脑中的所有内存？如果没有，你可以怎么做？输入 `q` 退出 less 工具。
- 8. 在命令提示符下，输入 `dmesg | less` 并按 **Enter**。观察条目。它们与前三个步骤中看到的硬件信息如何对应？输入 `q` 退出 less 工具。
- 9. 在命令提示符下，输入 `less /var/log/boot.log` 并按 **Enter**。每个条目代表什么？输入 `q` 退出 less 工具。
- 10. 在命令提示符下，输入 `less /var/log/syslog` 并按 **Enter**。每个条目代表什么？这些行与前两个步骤中显示的信息如何对应？输入 `q` 退出 less 工具。
- 11. 在命令提示符下，输入 `poweroff` 并按 **Enter** 关闭你的 Ubuntu Server Linux 虚拟机。
- 12. 在命令提示符下，输入 `poweroff` 并按 **Enter** 关闭你的 Ubuntu Server Linux 虚拟机。
