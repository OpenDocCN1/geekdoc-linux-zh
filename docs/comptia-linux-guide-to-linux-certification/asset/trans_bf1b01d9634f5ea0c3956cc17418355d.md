
## 项目 6-3

在这个动手实践中，你将安装 Ubuntu Server 的 ZFS 支持并配置 ZFS 文件系统。

- 1. 启动你的 Ubuntu Server Linux 虚拟机。Linux 系统加载完成后，使用用户名 root 和密码 LNXrok5! 登录到命令行终端（tty1）。
- 2. 在命令提示符下，输入 `apt-get -y install build-essential gawk zlib1g-dev uuid-dev vim-nox python-software-properties` 并按 Enter 键，以下载并安装 ZFS 的前置依赖包。

![](img/c27875544958897d817484d558c208c8_319_0.png)

**注意**

Ubuntu Server Linux 使用的包管理器与 Fedora Linux 不同。`apt-get` 命令的功能等同于你在前几章中用于从互联网仓库下载和安装软件的 yum 命令。`apt-get` 和 yum 都在第 11 章中有讨论。

- 3. 在命令提示符下，输入 `add-apt-repository ppa:zfs-native/stable`，按 Enter 键，然后再次按 Enter 键，将互联网上 ZFS 软件仓库的位置添加到 Ubuntu 安装源中。接下来，输入 `apt-get update` 并按 Enter 键，使用新的仓库信息更新 Ubuntu 安装源。
- 4. 在命令提示符下，输入 `apt-get install ubuntu-zfs` 并按 Enter 键，在你的 Ubuntu Server Linux 系统上安装 ZFS。
- 5. 编辑 `/etc/modules` 文件（`vi /etc/modules`），并在文件末尾添加以下行。完成后，保存更改并退出 vi 编辑器。

```
spl
zavl
znvpair
znunicode
zcommon
zfs
```

- 6. 在命令提示符下，输入 `update-initramfs -u` 并按 Enter 键，以更新启动时用于加载内核模块的镜像的磁盘和模块支持。
- 7. 尽管 ZFS 通常与额外磁盘设备的设备文件（例如 `/dev/sdb1`、`/dev/sdc1`、`/dev/sdd1` 等）配合使用，但 ZFS 几乎可以工作于任何可用于存储数据的设备或文件。因此，我们将使用 `dd` 命令创建四个空文件，并将它们视为四个独立的磁盘，以练习 ZFS 命令。运行以下命令创建四个 128MB 的文件，命名为 `/disk1`、`/disk2`、`/disk3` 和 `/disk4`：

```
dd if=/dev/zero of=disk1 bs=1024k count=128
dd if=/dev/zero of=disk2 bs=1024k count=128
dd if=/dev/zero of=disk3 bs=1024k count=128
dd if=/dev/zero of=disk4 bs=1024k count=128
```

- 8. 在命令提示符下，输入 `zpool create webstorage /disk1` 并按 Enter 键，使用 `/disk1` 上的空间创建一个名为 webstorage 的简单 ZFS 卷。接下来，在命令提示符下输入 `zpool list` 并按 Enter 键，以查看你的配置。
- 9. 在命令提示符下，输入 `cp /etc/hosts /webstorage` 将 `/etc/hosts` 文件复制到新的 ZFS 文件系统中。接下来，在命令提示符下输入 `ls -l /webstorage` 并按 Enter 键，以查看文件系统的内容。`/etc/hosts` 文件是否复制成功？
- 10. 在命令提示符下，输入 `zpool destroy webstorage` 并按 Enter 键，以删除 webstorage 卷。
- 11. 在命令提示符下，输入 `zpool create webstorage mirror /disk1 /disk2` 并按 Enter 键，使用 `/disk1` 和 `/disk2` 上的空间创建一个名为 webstorage 的镜像 ZFS 卷。接下来，在命令提示符下输入 `zpool list` 并按 Enter 键，以查看你的配置。然后，在命令提示符下输入 `zpool status webstorage` 并按 Enter 键。你的镜像是否列出了任何问题？
- 12. 在命令提示符下，输入 `dd if=/dev/random of=/disk1 bs=512 count=1` 并按 Enter 键，使用 `dd` 命令覆盖 `/disk1` 的一部分，模拟磁盘损坏。接下来，在命令提示符下输入 `zpool scrub webstorage` 并按 Enter 键，以更新 ZFS 文件系统的状态，然后在命令提示符下输入 `zpool status webstorage` 并按 Enter 键。你的镜像是否列出了任何问题？
- 13. 在命令提示符下，输入 `zpool detach webstorage /disk1` 并按 Enter 键，从镜像中移除损坏的磁盘（/disk1），然后在命令提示符下输入 `zpool status webstorage` 并按 Enter 键，以验证它不再被列出。
- 14. 在命令提示符下，输入 `zpool attach webstorage /disk2 /disk3` 并按 Enter 键，将 /disk2 上的数据镜像到新磁盘（/disk3），然后在命令提示符下输入 `zpool status webstorage` 并按 Enter 键。使用 /disk2 和 /disk3 的镜像是否完全可用？
- 15. 在命令提示符下，输入 `zpool iostat -v webstorage` 并按 Enter 键，以查看你的镜像的输入和输出统计数据。接下来，输入 `zpool destroy webstorage` 并按 Enter 键，以删除 webstorage 镜像。
- 16. 在命令提示符下，输入 `zpool create webstorage raidz /disk2 /disk3 /disk4` 并按 Enter 键，使用 /disk2、/disk3 和 /disk4 创建一个名为 webstorage 的 RAID-Z 卷，然后在命令提示符下输入 `zpool status webstorage` 并按 Enter 键，以验证结果。接下来，输入 `zpool iostat -v webstorage` 并按 Enter 键，以查看你的 RAID-Z 卷的输入和输出统计数据。
- 17. 在命令提示符下，依次输入以下每个命令并按 Enter 键，在 /webstorage 下创建三个子目录：

```
mkdir /webstorage/site1
mkdir /webstorage/site2
mkdir /webstorage/site3
```

- 18. 在命令提示符下，输入 `zfs list` 并按 Enter 键。site1、site2 和 site3 目录是否被列出？为什么？接下来，依次输入以下每个命令并按 Enter 键，为 site1、site2 和 site3 创建三个文件系统：

```
zfs create webstorage/site1
zfs create webstorage/site2
zfs create webstorage/site3
```

- 19. 在命令提示符下，输入 `zfs list` 并按 Enter 键。site1、site2 和 site3 目录是否被列出？为什么？
- 20. 在命令提示符下，输入 `zfs get all webstorage/site1` 并按 Enter 键，以查看 site1 子系统的可用选项。接下来，在命令提示符下输入 `zfs set quota=10G webstorage/site1` 并按 Enter 键，为该子系统设置 10GB 的配额。然后，输入 `zfs get all webstorage/site1` 并按 Enter 键。你的配额是否被列出？为什么这个配额永远不会应用到 webstorage/site1 子系统？（提示：考虑 webstorage 卷的总大小）
- 21. 在命令提示符下，输入 `poweroff` 并按 Enter 键，以关闭你的 Ubuntu Server Linux 虚拟机。

## 项目 6-4

在这个动手实践中，你将使用系统救援功能在 Fedora Linux 和 Ubuntu Server Linux 上检查根文件系统中的错误，并更改 root 用户的密码。

- 1. 在你的虚拟化软件中，确保你的 Fedora Linux 虚拟机的 DVD 已挂载到 Fedora 20 Live 的 ISO 镜像（Fedora-Live-Desktop-x86_64-20-1.iso）。接下来，使用你的虚拟化软件启动并连接到你的 Fedora Linux 虚拟机。
- 2. 在 Fedora Live 欢迎屏幕上，按 Enter 键以启动 Fedora Live。
- 3. 当图形桌面和“欢迎使用 Fedora”屏幕加载完成后，选择“试用 Fedora”选项，并在提示时单击“关闭”。
- 4. 在 GNOME 桌面中，导航至“活动” -> “显示应用程序” -> “实用程序” -> “终端”，以打开 BASH 终端。
- 5. 在命令提示符下，输入 `su - root` 并按 Enter 键，切换到 root 用户。
- 6. 在命令提示符下，输入 `df` 并按 Enter 键，以查看已挂载的文件系统。你硬盘上的根文件系统是否已挂载？
- 7. 在命令提示符下，输入 `fsck -f /dev/sda3`（或 `fsck -f /dev/hda3`）并按 Enter 键，以检查你的根文件系统中的错误。
- 8. 在命令提示符下，输入 `mount /dev/sda3 /mnt`（或 `mount /dev/hda3 /mnt`）并按 Enter 键，将你硬盘上的根文件系统挂载到 Fedora live 系统上的 /mnt 目录。接下来，输入 `mount /dev/sda1 /boot`（或 `mount /dev/hda1 /mnt/boot`）并按 Enter 键，将你硬盘上的 /boot 文件系统挂载到 Fedora live 系统上的 /mnt/boot 目录。
- 9. 在命令提示符下，输入 `chroot /mnt` 并按 Enter 键，从你 Live Fedora 系统上的根文件系统切换到你硬盘上的根文件系统。接下来，输入 `ls /root` 并按 Enter 键。你认得这些文件吗？
- 10. 在命令提示符下，输入 `passwd root` 并按 Enter 键。提供一个新的 root 用户密码 Secret123，并在提示时（两次）按 Enter 键。
- 11. 单击右上角的电源图标，选择出现的电源图标，并单击“关机”以关闭你的 Fedora Live 安装镜像。
- 12. 在你的虚拟化软件中，进入你的虚拟机的设置，确保 DVD 驱动器不再挂载到 Fedora ISO 镜像。
- 13. 最后，使用你的虚拟化软件启动你的 Fedora Linux 虚拟机。系统加载后，按 Ctrl+Alt+F2 切换到命令行终端（tty2），并使用用户名 root 和密码 Secret123 登录到终端。你成功了吗？
- 14. 在命令提示符下，输入 `passwd root` 并按 Enter 键。提供一个新的 root 用户密码 LNXrock5!，并在提示时（两次）按 Enter 键。
- 15. 在命令提示符下，输入 `poweroff` 并按 Enter 键，以关闭你的 Fedora Linux 虚拟机。
