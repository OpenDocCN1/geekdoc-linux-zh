Suppose, for example, that you download the source code for rdesktop (Remote Desktop Protocol client) version 1.8.2 from the Internet at www.sourceforge.net:

```
[root@server1 ~]# ls -f
Desktop/ rdesktop-1.8.2.tar.gz
[root@server1 ~]# _
```

The first step to installing this program is to uncompress and extract the tarball, as shown in the following output. This creates a directory called rdesktop-1.8.2 containing the source code and supporting files.

