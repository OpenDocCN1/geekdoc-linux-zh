# 打印机管理

在 Linux 系统上，大多数用户通常需要打印工作文件，而在系统故障情况下，打印日志文件和系统配置信息也是良好的规程。因此，对于设置和管理 Linux 服务器的人员来说，牢固理解如何设置、管理和打印到打印机至关重要。

# 通用 UNIX 打印系统

如今，在 Linux 计算机上最常用的打印系统是 **通用 UNIX 打印系统** (CUPS)。在 Linux 系统上使用 CUPS 的基础是理解信息被发送到打印机的过程。同时发送到打印机的一组信息称为**打印作业**。打印作业可以包括一个文件、多个文件或命令的输出。要将打印作业发送到打印机，您必须首先使用 **lp 命令**并指定要打印的内容。

接下来，CUPS **守护进程 (cupsd)** 将打印作业分配一个唯一的 **打印作业 ID**，并将打印作业的副本放入文件系统中称为**打印队列**的临时目录，前提是打印机正在接受请求。如果打印机拒绝请求，CUPS 守护进程会打印一条错误消息，指出打印机未接受打印作业。

![](img/c27875544958897d817484d558c208c8_455_0.png)

将打印作业接收进打印队列通常被称为**假脱机**或**排队**。

![](img/c27875544958897d817484d558c208c8_455_1.png)

打印机的打印队列通常是 `/var/spool/cups`。无论您在 Linux 系统上有多少台打印机，所有打印作业都发送到同一目录。

当打印作业进入打印队列后，它就准备好被打印了。如果打印机已启用并准备好接受打印作业，CUPS 守护进程然后将打印作业从打印队列发送到打印机，并删除打印队列中打印作业的副本。相反，如果打印机已禁用，打印作业将保留在打印队列中。

![](img/c27875544958897d817484d558c208c8_455_2.png)

将打印作业从打印队列发送到打印机通常称为打印。
