```
[root@server1 ~]# **pvdisplay**
"/dev/sda4" is a new physical volume of "32.00 GiB"

Allocatable                 NO

Total PE                    0
Free PE                     0
Allocated PE                0
PV UUID                     YZDmIG-0qFU-54AT-i0B6-bjKa-sHCc-i8IJo0
[root@server1 ~]#_
```
