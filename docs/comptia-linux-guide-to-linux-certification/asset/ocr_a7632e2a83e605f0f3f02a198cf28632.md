```
printer1 accepting requests since hu 26 Aug 2015 08:51:21 AM EDT
```

# ## Managing Print Jobs

Recall that you create a print job by using the lp command. To print a copy of the /etc/inittab file to the printer printerl shown in earlier examples, you can use the following command, which returns a print job ID that you can use to manipulate the print job afterward:

```
[root@serverl ~]# lp -d printerl /etc/inittab
request id is printerl-1 (1 file(s))
[root@serverl ~]#
```

The lp command uses the -d option to specify the destination printer name. If this option is omitted, the lp command assumes the default printer on the system. Because printerl is the only printer on the system and, hence, is the default printer, the command lp /etc/inittab is equivalent to the one used in the preceding output.

![](bbox=[0.14, 0.59, 0.33, 0.65])

You can set the default printer for all users on your system by using the lpoptions -d printername command, where printername is the name of the default printer. This information is stored in the /etc/cups/lpoptions file.

![](bbox=[0.14, 0.65, 0.33, 0.72])

Alternatively, each user on a Linux system can specify his own default printer by adding the line default printername to the .lpoptions file in her home directory, where printername is the name of the default printer. Alternatively, you can use the PRINTER or LPrinter2 variables to set the default printer. For example, to specify printer2 as the default printer, you can add either the line export PRINTER=printer2 or the line export LPrinter2=printer2 to an environment file in your home directory, such as .bash_profile.

You can also specify several files to be printed using a single lp command by specifying the files as arguments. In this case, only one print job is created to print all of the files. To print the /hosts and /etc/issue to the printer printerl, you can execute the following command:

```
[root@serverl ~]# lp -d printerl /etc/hosts /etc/issue
request id is printerl-2 (2 file(s))
[root@serverl ~]#
```
