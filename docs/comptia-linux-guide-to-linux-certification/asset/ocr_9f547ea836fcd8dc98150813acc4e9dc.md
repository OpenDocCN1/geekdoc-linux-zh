The minimum height of a rackmount server is 1.75 inches; this is called a 1U server. Most 1U servers have up to two hard drives (or SSDs) and up to two CPUs. Other rackmount servers take up more than one spot on the rack and have a height that is a multiple of a 1U server. For example, a 2U server is twice as high as a 1U server and often contains up to four CPUs and eight hard disks (or SSDs). Rackmount servers rarely exceed 4U.
