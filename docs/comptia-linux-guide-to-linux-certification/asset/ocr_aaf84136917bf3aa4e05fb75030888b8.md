# Other Common Text Editors

Although the vi editor is the most common text editor used on Linux and UNIX systems, there are other text editors that are easier to use.

An alternative to the vi editor that offers an equal set of functionality is the GNU Emacs (Editor MACros) editor. Emacs is not installed by default in Fedora 20. To install it, you can run the command `yum install emacs` at a command prompt to obtain Emacs from a free software repository on the Internet. Next, to open the `project4` file in the Emacs editor in a command-line terminal, simply type `emacs project4` and the following is displayed on the terminal screen:
