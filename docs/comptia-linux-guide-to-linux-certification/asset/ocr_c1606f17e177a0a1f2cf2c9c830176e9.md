# Working with the Red Hat Package Manager (RPM)

RPM is the most widely used format for Linux software distributed via the Internet. RPM packages have filenames that indicate the hardware architecture for which the software was compiled and end with the .rpm extension. The following output indicates that the bluefish RPM package (a Web page editor) version 2.2.6-3 was compiled for Fedora 20 (fc20) on the Intel x86_64 platform:

```
[root@server1 ~]# **ls -F**

desktop/    bluefish-2.2.6-3.fc20.x86_64.rpm

[root@server1 ~]#
```

To install an RPM package, you can use the -i option to the rpm command. In addition, you can use the -v and -h options to print the verbose information and hash marks, respectively, during installation.
