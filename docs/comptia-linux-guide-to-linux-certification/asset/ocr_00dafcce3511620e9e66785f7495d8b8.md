You must use the -f option to the sar command to view files in the /var/log/sa (or /var/log/sysstat) directory with the aforementioned filenames because they contain binary information. A sar text report is also written to the /var/log/sa/sa* file (or /var/log/sysstat/sa* file) at the end of each day, where # represents the day of the month. To view a sar report file, you can use any text command, such as less.
