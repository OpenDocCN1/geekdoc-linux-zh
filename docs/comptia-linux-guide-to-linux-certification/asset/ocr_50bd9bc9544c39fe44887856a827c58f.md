If a hardware device is not working with Linux, first consult the hardware vendor's Web site to determine the name of the kernel module. You can then search for this module in the /proc/modules file; if the module isn't present, the driver for that hardware is not loaded into the Linux kernel, and you need to add the module manually, as discussed in Chapter 12.
