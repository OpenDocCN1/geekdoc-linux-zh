Until recently, X Windows was governed by a separate license than the GPL, which restricted the usage of X Windows and its source code. As a result, open source developers created an open source version of X Windows in the 1990s. This freely available version of X Windows is used in many Linux distributions and is called XFree86 because it was originally intended for the Intel x86 platform.

![](bbox=[0.15, 0.21, 0.36, 0.27])

To find out more about XFree86, visit The XFree86 Project at www.xfree86.org.

Today, Linux distributions offer either X Windows or the XFree86 implementation of X Windows because they are both Open Source Software. Fedora 20 and Ubuntu 14.04 use X Windows instead of XFree86.

# **Window Managers and Desktop Environments** To modify the look and feel of X Windows, you can use a window manager. For example, the dimensions and color of windows that are drawn on a graphical screen, as well as the method used to move windows around on a graphical screen, are functions of a window manager.

Many different window managers are available for Linux, including those listed in Table 8-4.

| Window Manager | Description |
