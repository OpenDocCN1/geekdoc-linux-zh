After changing the /etc/lilo.conf file, LILO must be reinstalled using the new information in /etc/lilo.conf for those changes to take effect. To do this, you can use the `lilo` command:

```
[root@server1 ~]# lilo
  Added linux *
[root@server1 ~]# _
```
