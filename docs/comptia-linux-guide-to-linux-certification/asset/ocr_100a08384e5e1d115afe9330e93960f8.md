As with RPM, most DPM packages are hosted on Internet software repositories for free download. To download and install DPM packages, including any dependency packages, you can use the **apt-get (Advanced Package Tool)** command.

![](bbox=[0.13, 0.32, 0.95, 0.41])

The apt-get command is as easy to use as the yum command with the RPM. For example, to install the conky DPM package (a system monitoring tool) from an Internet software repository, you could run the following command:


To remove the conky DPM package, excluding any conky configuration files, you could use the **apt-get remove conky** command. Alternatively, you could use the **apt-get purge conky** command to remove the conky DPM package, including all conky configuration files. You can also use the **apt-get update** command to update the list of available DPM packages from Internet software repositories, as well as the **apt-get upgrade** command to upgrade the DPM packages on your system to the latest versions, based on the updated package list.
