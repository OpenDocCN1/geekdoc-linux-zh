1. 桌面条目编辑器打开。
2. 打开“图标”选项卡，然后单击图标本身。将打开一个新的对话框，允许您导航到所选的图标。
3. 在左侧窗格中单击“根目录”，然后在右侧窗格中导航至 `/USR/SHARE/ICONS/MAXO-REMIX/APPS`
4. 向下滚动到 `NAUTILUS.PNG` 并单击“确定”。
5. 回到桌面条目编辑器，单击“应用”。
6. 关闭 Nautilus。

桌面上的图标应该已经更改为更令人愉悦的图片。

## 2.9 隐藏文件

就像宇宙中的大多数物质是不可见的暗物质一样，您的 Home 目录中的大多数目录和文件也是隐藏的。要查看这些内容，请双击您新的桌面图标以运行 Nautilus，然后按 Ctrl + H，或者打开“视图”菜单并单击“显示隐藏文件”。您会看到您的 Home 目录中有相当多的隐藏文件夹，并且当您完成下一章中各种应用程序的安装后，还会有更多。请注意，这些隐藏文件和目录都以 `.` 为前缀。

个人应用程序启动器存储在您 Home 目录的这个隐藏部分中，位于 `LOCAL/SHARE/APPLICATIONS` 文件夹里。看看它：

1. 现在导航到该文件夹，并打开终端。
2. 输入 `LS` 以列出文件夹中的文件。其中一个是 `NAUTILUS_AS_ROOT.DESKTOP`。
3. 输入 `leafpad Nautilus_as Root.desktop`（请记住，您可以将文件名复制并粘贴到此命令中）。
4. 启动器的文本应该会显示出来。
5. 关闭 Leafpad，并关闭终端。
6. 在 Nautilus 中，返回您的 Home 目录（通过单击工具栏中的“主目录”），并再次按 Ctrl + H 以关闭隐藏文件视图。
7. 最后关闭 Nautilus。

# 3 为您的桌面加速

如果您已经对在不断扩展的菜单系统导航中感到厌烦，那么这一章就是为您准备的。阅读完本章后，您应该能够充分欣赏增强型 Windows 桌面系统的完整灵活性和速度。您将设置好它，只需一两次鼠标点击即可运行应用程序和更改设置。您甚至还会加快并简化使用鼠标最大化、最小化、关闭以及操作窗口的方式。过去那种为了精确点击标题栏右侧的小按钮而感到痛苦的日子将一去不复返！

您将通过设置和填充架子（shelves）和 iBars 来实现这一切，并设置装饰绑定。这里涵盖的其他主题包括使用“运行所有”、加载模块（包括“位置”模块）和使用小工具。这将为您准备下一章节的桌面环境，在那里您将下载处理办公工作、操作照片、播放媒体文件等所需的应用程序。

> 提示：在通过此指南操作时，您将打开许多窗口和对话框。如果其中一个超出了屏幕边缘，您想将其拉回视野中，请在用鼠标拖动时按住 Alt 键。（当然，如果窗口有可见的标题栏，您也可以直接拖动它。）

## 3.1 首次查看架子（Shelves）和 I BARS

我们将首先自定义桌面左侧现有的架子。

1. 在架子空白区域右击，并选择上下文菜单中的第一个选项“内容”。
2. 打开架子内容对话框，列出可用的小工具。（这些之外还有更多小工具，您很快就会发现如何加载它们。）
3. 确保选中了以下三个小工具：“设置”、“Everything Starter”和“iBar”。（要选中一个小工具，请将其高亮并单击“添加小工具”。）
4. 通过高亮其他已选中的小工具并单击“移除小工具”来取消选中它们。（其中一些，如混合器和系统托盘，您很快会将它们添加到另一个架子上。）
5. 您的架子上将只剩下三个图标，即“iBar”（当前托管着 Mitori）、“设置”和“运行所有”。关闭对话框。
6. 现在右击架子上的 Mitori 图标，鼠标悬停在“iBar”上，然后选择“内容”。打开 iBar 应用程序对话框。您可能希望拖动其上下边框使其变大。
7. 按照上述（3）中描述的过程，将以下应用程序添加到 iBAR：FIREFOX、NAUTILUS、SYNAPTIC、TERMINAL 和 THUNDERBIRD。移除 MIDORI。
8. 单击“顺序”选项卡（位于框顶部），并在列表中向下移动 FIREFOX 和 SYNAPTIC，使顺序变为：NAUTILUS、TERMINAL、FIREFOX、THUNDERBIRD、SYNAPTIC。
9. 单击“应用”，然后关闭。您的 iBAR 现在应包含这五个应用程序的图标。
10. 再次在架子空白区域右击，并从菜单中选择“设置”。打开架子设置对话框。
11. 在“堆叠”选项卡中，选择“窗口下方”（这确保如果您希望全屏运行应用程序，架子将不可见。）
12. 单击“位置”，在此选项卡中选择左侧的第二个选项（即位于屏幕左边缘、顶部的架子）。
13. 在“大小”选项卡中，将大小保留为 40 像素，但选择“收缩至内容宽度”。
14. 单击右箭头到达“样式”选项卡，在这里您应该选择“不可见”。
15. 单击“应用”，然后关闭。

您架子上的图标现在应聚集在屏幕左边缘、顶部位置，且架子本身应不可见。现在您只需单击即可访问放置在上面的所有小工具和应用。其中之一——“设置”小工具——您将在下一节中使用。

**注意：** 系统（电源开关）小工具不再位于架子上。因此要关闭计算机，您要么按计算机的电源按钮，要么使用菜单系统（主菜单 > 系统 > 关机）。在本章稍后，您将创建一个按键绑定来关机。

## 3.2 隐藏桌面启动器

既然您现在可以通过单击其 iBAR 图标来启动 Nautilus，就没有必要同时在桌面上保留其启动器了。事实上，正如我们稍后所见，在桌面上放置任何此类启动器都没有意义，因为我们可以在那里放置 iBARS 作为替代。

要隐藏桌面启动器：

1. 单击面板上的“设置”小工具。打开设置窗口，您可能希望将其最大化。现在，您以前需要通过在菜单系统中费力寻找才能访问的所有不同设置选项现在都触手可及。
2. 桌面图标由 EnLightenment 文件管理器控制，要访问其设置，您需要单击设置窗口右上角的箭头横向滚动到“文件”。选择“文件管理器”，然后在 Fileman 设置对话框中，单击“显示”选项卡并关闭“桌面图标”。
   应用，然后关闭，并关闭设置窗口。

## 3.3 第二个架子

我们将混合器（Mixer）和系统托盘（Systray）小工具放在第二个架子上，该架子同样位于屏幕左侧，但在底部。系统托盘要求此架子可见。

1. 前往主菜单 > 设置 > 架子，在架子设置对话框中单击“添加”。
2. 给您的新架子起一个有意义的名称，以便稍后识别它（例如“底部”）。
3. 打开架子内容对话框，在此处您应添加混合器和系统托盘小工具。单击关闭，返回架子设置对话框。
4. 高亮您的架子（“底部”），并单击“设置”。打开架子设置对话框，并在各个选项卡中确保以下设置：堆叠 - “窗口下方”；位置 - “第四项”（即左边缘，底部）；大小 - 确保选中“收缩至内容宽度”；样式 - 保持为“默认”。
5. 单击应用，然后关闭，再关闭架子设置对话框。

若要更改此架子上小工具的顺序（使混合器位于底部，在系统托盘下方），右击混合器并选择“开始移动小工具”。现在您可以将小工具拖动到所需位置。再次右击混合器并选择“停止移动小工具”。

提示：如果某个应用程序已打开并最大化，除了为架子保留的左侧窄条外，它填满了整个桌面，您可以单击两个架子之间暴露的桌面部分来打开 EnLightenment 菜单系统。

## 3.4 弹出式架子

现在您将创建一个位于屏幕底部、平时隐藏在视线之外，只有在鼠标悬停时才会显示的架子。

1. 如果您使用的是笔记本电脑，在此架子上取消“电池”小工具的固定可能很有帮助，但其模块不属于基础部分（Composer 配置文件）。要解决此问题，请前往主菜单 > 设置 > 模块。出现模块设置对话框。在此处您应单击“系统”选项卡，高亮“电池”，并单击“加载”。
