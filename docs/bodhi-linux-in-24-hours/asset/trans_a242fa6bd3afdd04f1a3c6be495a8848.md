**以类似的方式，广播节目也可以被下载，唯一的区别是在步骤 (3) 中，你应该输入 `GET-PLAYER RUNE "RADIO PROGRAMNAME"`。**

### 4.10 其他应用程序

当然，你的电脑上还会有其他你想安装的应用程序。查看热门选择的好地方是 AppCenter，在那里你可以找到游戏、教育软件、通信软件以及更多内容。以下是一些建议。

1.  如果你想阅读 PDF 格式的文件，你需要一个合适的阅读器。有 Adobe PDF 阅读器，或者你可能更喜欢 Evince，它可以阅读各种格式的文件。请在 AppCenter 的 Office 部分查找 PDF 阅读器。
2.  如果你想编辑音频文件，你需要 Audacity，可在 AppCenter 获取。
3.  如果你想将计算机连接到投影仪以进行演示，或者连接到电视，你需要使用 xrandr。这随 Bpodii 系统附带，但它是一个命令行实用程序，意味着你必须使用适当的 Terminal 命令进行配置。不过，有一个友好的图形前端可供选择，它允许你从菜单中进行配置选择。这个前端被称为 aRandR，你可以从 Synaptic 下载它。下载后，它会显示在你的 Preferences 菜单中。

> *注意：如何使用 aRandR*
> - a) 将你的计算机连接到投影仪并打开所有设备。
> - b) 运行 aRandR，打开 Outputs 菜单，并将计算机的分辨率（LVDS）与投影仪的分辨率（可能是 VGA1）匹配。
> - c) 单击 Apply。

4.  如果你对电子书感兴趣，你很可能需要 Calibre，可在 AppCenter 获取。
5.  甚至可以使用 Windows 模拟器（如 Wine，可在 AppCenter 获取）来运行一些 Windows 应用程序。通过访问 Wine HQ（http://appdb.winehq.org/），你可以查看在 Wine 下可以完美运行（主要是游戏）的列表。如果你在读电子书，值得注意的是 Adobe Digital Editions 也可以在 Wine 下运行。但是，你应该知道 Wine 是一个庞大的软件包，会给你的系统带来很多额外负担。

### 4.11 卸载应用程序

任何从 AppCenter 或 Synaptic 安装的内容都可以通过运行 Synaptic，搜索应用程序名称并勾选其复选框来卸载。（如果应用程序已安装在你的系统上，该复选框会被填充颜色而非空白。）从菜单中选择 ‘Mark for Complete Removal’，然后单击 Apply。应用程序及其依赖项将被移除。

尽管如此，你的系统上仍会留下一些不需要的文件，你可以通过打开 Terminal 并输入以下命令来清除它们：

```
sudo apt-get autoremove
```

你的系统已经积累了一些杂乱的文件，因此现在运行此命令是值得的。

## 5 为你的桌面提供更多功能

在本章中，你将组织你的桌面及其菜单，以便上一章安装的应用程序触手可及，你将了解虚拟桌面，为你的应用程序窗口应用 GTK 主题，并尝试不同的 E17 主题。然后，你可以通过创建新的配置文件来实践所学内容。

### 5.1 更新你的 iBar

让我们通过更新你的 iBar 以反映上一章添加的应用程序开始。

- 在 shelf 的 iBar 区域上右键单击，鼠标悬停在 iBar 上，然后选择 Contents。
- 在 iBar Applications 对话框中，你可能希望添加 LibreOffice（选择第一个 LibreOffice 条目）和 Osmo，我建议移除 Synaptic（你很快会将此添加到 Favorites 菜单中）。如果你不想要这些，请选择一些你经常使用且可能需要的其他应用程序。
- 单击 Order 选项卡，将顺序更改为你想要的顺序，然后单击 OK。

你的 iBar 将根据这些更改进行更新。

### 5.2 桌面上的 iBar

如果你遵循了上一章的建议，你应该已经在系统中添加了多个媒体应用程序。你可能发现将它们在另一个 iBar 上分组会很有帮助。

- 转到 Main menu > Settings > Gadgets。Desktop Gadgets 对话框打开，你应该突出显示 'Background'，然后单击 'Configure Layer'。
- 小工具列表出现。突出显示 iBar 并单击 Close，然后再次单击 Close。iBar 出现在你的桌面上，带有白色边框。它还包含你原始 iBar 中的应用图标；我们稍后会更改这些。
- 使用鼠标将新 iBar 移动到桌面上合适的位置，并拖动其垂直边框之一以加宽它。（你稍后会完善这些调整。）
- 在 iBar 上右键单击，然后鼠标悬停在 'iBar' 上并选择 'Settings'。
- 在 iBar Settings 对话框中，单击 Add，然后为源输入一个合适的名称。你可以将其命名为 media。单击 OK。
- 在源列表中突出显示新源的名称，然后单击 Setup。iBar Applications 对话框将出现。（如果此对话框较小且拥挤，请记住你在第 3 章中设置的快捷键以修复此问题：按 Win + m 垂直最大化它。）
- 删除当前填充此 iBar 的应用图标（依次单击橙色按钮和 ‘Remove’），并添加你已安装的媒体应用程序：Audacious、Audio Recorder 和 VLC。你可能希望在这里也添加 Brasero 光盘刻录程序。
- 单击 Order 选项卡，按你想要的顺序排列这些图标，然后单击 OK，再单击一次 OK。你选择的包的图标将显示在你的新 iBar 中。
- 右键单击其中一个图标，鼠标悬停在 ‘iBar’ 上，然后选择 ‘Begin move/resize’。现在你可以拖动垂直边框使其紧密围绕图标，并将其移动到桌面上你想要的确切位置。完成后再次右键单击。
- 你的新 iBar 周围有一个边框。要移除它，再次右键单击它，鼠标悬停在 ‘iBar’ 上，鼠标悬停在 ‘Appearance’ 上，然后选择 ‘Plain’。

如果你愿意，可以通过重复此过程在桌面上设置更多的 iBar。

由于进行了此类更改，shelf 上的小工具可能已经重新排列。请记住，你可以通过右键单击小工具并选择 ‘Begin moving gadgets’ 来重新排序它们。完成后再次右键单击并选择 ‘Stop moving gadgets’。

注意：如果以后你想修改此第二个 iBar 的内容，右键单击其中一个图标，然后鼠标悬停在 ‘Settings (cst Contents)’ 上，并在列表中突出显示此 iBar 的名称（media）。然后选择 ‘Setup.’（选择 ‘Settings’ 而不是 ‘Settings (cst Contents)’ 将修改 shelf 上的默认 iBar。）

### 5.3 收藏夹菜单

现在让我们设置收藏夹菜单。这将允许你通过在桌面任何位置右键单击来访问收藏夹应用程序。

1.  单击 Settings 图标（顶部 shelf），然后最大化出现的 Settings 窗口（通过单击屏幕顶部 – 记住你的鼠标绑定！）。
2.  单击 Apps，然后单击 ‘Favourite Applications’。Favourite Applications 对话框打开。你可能希望使用 Win + m 快捷键垂直最大化此框。
3.  你应该添加 Synaptic，以及你希望随时使用的其他应用程序，除了那些可以从 shelf iBar 运行的应用程序。
4.  单击 Order 选项卡并设置顺序，然后单击 OK。
5.  保持 Settings 窗口打开，为下一节做准备，但通过在 shelf 下方的裸露桌面区域右键单击来测试你的新菜单。
