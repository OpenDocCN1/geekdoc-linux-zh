THE FOLLOWING SEQUENCE OF COMMANDS INTO TERMINAL:

```
SUDO  ADD-APT-REPOSITORY PPA:JON-HEDGERS/GET+PLAYER
SUDO APT-GET UPDATE
SUDO APT-GET INSTALL GET+iPLAYER
```
