
遗憾的是，Firefox 并不总能播放 iPlayer 节目，尤其是广播节目，因此访问 iPlayer 时，我更喜欢使用 Google Chrome（而非 Chromium），因为它在这方面的表现更好。（Flash 是内置于 Chrome 中的，而它在 Firefox 中只是一个插件。）

如果你打算下载并使用 Firefox，我建议这样做（因为它相比 Chrome 有诸多优势，包括更好的视频下载功能），请先下载 FLASH PLAYER（闪存播放器）。要获取 Flash，请向下滚动到应用中心的网络部分，并选择“其他插件”。你会在下一个屏幕中看到 Flash 的列表，点击它。在下一个屏幕中，点击“立即安装”，在没有任何看似活动发生且等待相当长一段时间后，下载将进行，随后自动安装该软件包。

同样地安装 Firefox，通过返回主应用中心屏幕，并在网络部分选择“网络浏览器”。最终，下载和安装将完成，你可以选择 Midori。从现在开始，我们将使用 Firefox。（我将在第 4 章中介绍 Chrome 的安装。）现在启动 Firefox：

1.  前往 **主菜单 > 应用程序 > 网络**。你应该能看到列出的 **Firefox 网络浏览器**。如果没有，这意味着由于某种原因，Enlightenment 尚未用其最新添加项更新其菜单。如果发生这种情况，再次打开主菜单并选择 **Enlightenment > 重启**。这将更新所有 Enlightenment 菜单和挂件。（非常偶尔地，挂件图标可能会从架上消失，重启 Enlightenment 会解决此问题。）
2.  **运行 Firefox**。你可能注意到它的加载时间比 Midori 稍长；这是因为它是一个更重量级的产品，功能更多。打开 **工具** 菜单；选择 **附加组件**，然后是 **插件**。你应该会在那里看到 Flash 被列出。
3.  现在点击“**获取附加组件**”。页面将加载，显示可用于 Firefox 的一些附加组件。在此页面的右下角，有一个链接“**浏览所有附加组件**”。点击它。许多页面中的第一页出现，列出了某些附加组件。我们要安装的附加组件名为 Flash Video Downloader。开始将此输入到页面右上角的搜索框中，然后点击出现的链接。在此附加组件打开的下载页面，点击“**添加到 Firefox**”按钮，然后在下一个对话框中点击“**立即安装**”。
4.  此附加组件安装后，你将受邀重启 Firefox，但暂不这样做。相反，在搜索框中输入“**LUXION**”。然后点击出现的 Luxion 链接。再次将此添加到 Firefox。在这个相对较新的附加组件安装后，你将受邀重启 Firefox——现在这样做；然后点击 **附加组件** 选项卡并选择 **扩展**。你将看到 Flash Video Downloader 和 Luxion 已添加到你的系统中。这意味着你现在可以下载 YouTube 视频（例如）。

    安装 **Flash Video Downloader** 后，当播放可下载视频时，地址栏右侧出现的**大箭头**将变为蓝色。这意味着你可以点击它以下载视频。

    **警告：** Firefox 设置为将任何下载保存到你主目录中的下载文件夹。该文件夹尚不存在，但你很快将在 2.6 节中创建它。

    **注：** “目录”和“文件夹”意思相同。
5.  安装 **Lucifox** 后，工具菜单中会增加一个“Lucifox”项，从这里你可以访问 **Lucifox** 手册以及 **目录浏览器**。请注意，当你下载 EPUB 书籍时，它将在 Lucifox 窗口中显示，但不会保存到你的硬盘。要保存它，你应该在书籍文本的任何位置右键点击并选择“另存为”。

    **注：** 如果你希望的话，删除或禁用这些任何附加组件都很简单。打开 Firefox 的工具菜单，选择附加组件以打开附加组件管理器，然后选择扩展并选择你要禁用的那些。
6.  现在就试试这些功能。前往 **YouTube**，并选择一个视频播放。如果你听不到任何声音，这意味着你需要调整扬声器音量：点击架下方部分的扬声器挂件并向上拖动两个滑块。观察地址栏右侧的下载箭头已变为蓝色。
7.  现在前往 **Bodhi Linux** 网站 (www.bodhilinux.com) 并将其加入书签（通过打开书签菜单并选择书签）。现在鼠标悬停在 **资源** 上并选择 **AppCenter**。我们要安装一个邮件客户端，因此前往 **AppCenter** 的网络部分并点击 Email。列出了三个邮件客户端，选择权在你。我建议使用 Thunderbird，它是 **Firefox** 的配套软件。做出你的选择，然后在下一个屏幕上点击立即安装。启动应用程序对话框打开，要求你告诉 Firefox 如何处理此 AppCenter 任务。你只需要告知它一次，请按照以下步骤进行：
    - a) 点击“选择”，在下一个屏幕上点击“文件系统”。
    - b) 向下滚动到“usr”目录并双击它。
    - c) 双击 bin 目录。
    - d) 向下滚动到“apturl”并点击它。
    - e) 点击“确定”。
    - f) 启动应用程序对话框再次出现，apturl 为所选应用程序。
    - g) 勾选“记住所有链接的选择”左侧的复选框，然后点击“确定”。

Thunderbird（或你选择的任何邮件客户端）现在将被安装。当然，它需要为你的特定电子邮件账户进行配置，为此你可以使用 Thunderbird 自己的帮助系统：运行 **Thunderbird**，打开帮助菜单，选择帮助内容，然后选择自动账户配置。

**注：** 在未来，我会将类似于步骤 (a) 到 (d) 中的指令简单写为“导航至 /usr/bin/apturl”（第一个“/”表示根（文件系统）目录。Linux 像互联网一样，使用正斜杠表示目录。Windows 本身使用反斜杠。）

## 2.4 安装 Nautilus 和 Gnome Terminal

Windows 只有一个广泛使用的文件管理器，即 Windows 资源管理器。然而，在 Linux 中，你有很多选择。正如选择软件时总是那样，你必须在功能和易用性之间取得平衡，而这个平衡因人而异，取决于你的需求。Bodhi Linux 附带的 Enlightenment 文件管理器 (EFM) 轻量、美观且足够易用，但缺乏功能。许多 Bodhi Linux 用户更喜欢使用功能更强大的东西，如 PeManFM 或 SpaceFM。后者功能非常强大但相当令人望而生畏，且对初学者来说太复杂，但 PeManFM 是个不错的选择。

我个人的最爱是 Nautilus，它结合了良好的功能和易用性，如果你在 Bodhi 软件仓库中安装 Dropbox，你需要系统中安装 Nautilus（稍后会有更多相关内容）。Nautilus 的轻微缺点在于它是为 Gnome 桌面设计的，这意味着它需要配置才能在 Enlightenment 上正常运行。

为了充分利用 Nautilus 的功能，你还需要安装 Gnome Terminal - 无论如何，这都是个不错的选择，因为它比 Terminology 功能更多。（Terminology 是 Bodhi Linux 附带的终端 - 你在 2.1 节执行初步的清理任务时使用过它。）

如果在使用了 Nautilus 和 Gnome Terminal 后，你决定它们不适合你，那么你可以轻松卸载它们并切换到替代方案。如果你正在旧且缓慢的计算机上安装 Bodhi Linux，你可能会决定坚持使用轻量级的 Enlightenment 文件管理器和 Terminology，但在这种情况下，你应该意识到，Nautilus 提供并在下文描述的一些功能对你将不可用。

**注：** 本章其余部分致力于 Nautilus 和 Terminal。你不需要通读这里描述的所有功能，我已标记了那些可选的部分，你可以稍后再回来查看。这对于本章的最后一部分（2.7）尤其如此，它仅面向高级用户，其他所有人可以完全省略。
