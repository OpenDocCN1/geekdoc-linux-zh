
## 1.4 安装 Bodhi Linux

  第一步是制作一张包含 Bodhi Linux 系统的 CD。为此，你需要一张空白可录制 CD 和一台能够向其写入数据的计算机。假设你拥有这些条件，请按照以下步骤操作：

- 1) 访问 Bodhi Linux 官方网站 (http://www.bodhilinux.com)，你会在右侧看到两个下载链接，一个针对 32 位计算机，另一个针对 64 位计算机。建议你选择 32 位版本，因为它适用于所有计算机。（即使你的计算机是最新的 64 位机器，选择 64 位版本所获得的提升也微乎其微。）
- 2) 下一个界面会提供另外两个下载选项，一个是针对 PAE（物理地址扩展）计算机的，另一个是针对非 PAE 计算机的。同样，非 PAE 版本适用于所有机器。然而，在这种情况下，如果你的计算机支持 PAE，安装 PAE 版本是值得的，而且很可能你的计算机是支持的。2004 年后的所有计算机都支持 PAE，1995 年后的大多数机器也支持。因此，点击顶部（pae）的下载按钮，几秒钟后下载就会开始。这将是一个 .iso 文件，意味着它是一个光盘镜像。Bodhi 的 ISO 镜像足够小，可以容纳在 CD 上，而不是 DVD。
- 3) 你会注意到在 Bodhi 下载按钮下方有一个标有‘sum’的按钮。这会引导你进行进一步的下载，从而允许你检查下载的 ISO 镜像中是否存在错误。我从未在这些镜像中遇到过错误，但如果你想检查，可以使用一些免费的 Windows 实用工具配合 md5sum 下载——在网络上搜索‘md5sum on Windows’即可。
- 4) 现在将你的 ISO 文件刻录到 CD 上。在 Windows 7 中，如果你双击 ISO 文件，Windows 磁盘映像刻录程序应该会打开，你可以用它来刻录映像。否则，你可以使用 Windows（以及 Linux）上可用的免费 CD 刻录程序之一。我使用 CDBurnerXP，它适用于 Windows XP 以及 Vista 和 7，可在 https://cdburnerxp.se/ 下载。运行 CDBurnerXP 时，其中一个选项是刻录 ISO 映像。只需将一张空白可录制 CD 插入驱动器，选择此选项，浏览到你保存的 Bodhi ISO 文件，然后点击“Burn disc”按钮。几分钟后，你的 CD 就准备好了。
- 5) 现在到了关键时刻。启动你打算安装 Bodhi 的计算机，并立即按住 F12 键，直到启动菜单打开。将 CD 插入光驱，并在菜单中选择从此处启动的选项。（如果 F12 无法带你进入启动菜单，请查阅计算机手册了解应使用的方法。请注意，在计算机刚启动时，屏幕上应会显示一个你可以使用的启动按键列表。）
- 6) 一两秒后，光盘启动菜单会出现。选择顶部选项以运行实时系统。Bodhi 的欢迎屏幕会出现几秒，然后屏幕会变暗，可能有一分钟的时间似乎没有任何动静，除了 CD 驱动器工作的声音。然后，一切正常，一个配置文件选择菜单将出现。你可以松了一口气！
- 7) 如果几分钟后仍无反应，且光盘停止工作，这意味着一切并不顺利。如果你的计算机较旧，那么它很可能是非 PAE 机器，在这种情况下，你将不得不下载非 PAE 版本的 Bodhi。如果这样做了之后 Bodhi 仍然无法运行，这意味着 Linux 遇到了一些硬件不兼容问题。旧笔记本电脑上常见的问题与 ACPI（高级配置和电源接口）有关，要克服这一点，你必须关闭 ACPI；当光盘启动菜单出现时（步骤 6），按 Tab 键显示启动选项，并在该列表末尾添加命令 `acpi-off`。当然，你还应检查 md5sum（见上文步骤 3）。
- 8) 选择 Composite（组合）配置文件，点击 Next（下一步），然后在下一个屏幕中选择任何你喜欢的主题，再次点击 Next。Enlightenment 桌面将出现，左侧有一个面板（称为 shelf，搁架），上面有一些小工具，桌面上还有更多小工具，包括一个时钟。暂时不用在意这些。
- 9) 在实时系统中，网络小工具不会自动运行（在安装系统中它会运行），要连接互联网，你必须手动启动它。为此，打开主菜单（点击桌面的任何位置，或点击搁架顶部的图标），选择 'Run Everything'（运行所有程序）。在其对话框中输入 `network` 的前几个字母。蓝色的网络小部件将出现在对话框中并被高亮显示，现在你可以按 Enter 键运行它。网络图标将出现在搁架上。如果你有有线网络（即你的计算机通过电缆连接到路由器），连接将立即建立；如果你是通过无线连接，应点击图标，选择你的路由器，并输入其密码。

> **延伸阅读。** 有关连接互联网的更多信息，请访问 Bodhi 帮助系统的相关部分。点击桌面的任何位置以打开主菜单，选择 Bodhi Linux 然后选择 Quick Start（快速入门），然后点击第一个项目，'Connecting to the Internet'（连接互联网）。

- 10) 如果需要，你可以在此时试用 Bodhi，以确保在安装到硬盘之前你对它感到满意。要运行 CD 中包含的网页浏览器（Midori），点击搁架上从上往下数的第二个图标。
- 11) 当你准备好在计算机上安装 Bodhi Linux 时，双击 Install Bodhi（安装 Bodhi）图标。几秒后，语言选择对话框打开 - 选择适当的选项并点击 Continue（继续）。在下一个屏幕按 Continue（这是一个硬件检查 - 不用担心互联网连接被划掉），然后在下一个对话框中点击 Yes（是）以卸载分区。接下来，你必须决定是否希望将现有的操作系统与 Bodhi 一起保留在系统中。如果不需要，点击替换 Microsoft Windows 的框，然后点击 Continue。在下一个屏幕点击你在地图上的位置，之后接受适当的键盘布局（你可以使用默认选项）。接下来，你必须输入你的姓名，然后输入你想给计算机起的用户名（如果你愿意，可以保持为 Bodhi132）以及密码。选择 'Log in automatically'（自动登录）（除非你的计算机将在工作场所环境中使用），然后点击 Continue。最后，当计算机完成系统安装（这需要相当长的时间），你可以点击 Restart（重启）。
- 12) 重启后，在配置文件对话框中，再次选择 Composite 配置文件，然后在主题对话框中选择 'Bodhi-Theme'，如果列出了该主题；否则选择其他主题。（安装光盘上可用的主题选择因 Bodhi Linux 的版本而异。我将基于 Bodhi-Theme 来描述本指南第一部分内容，如果它不在你的安装光盘上，不用担心：你很快就会安装它）。这就完成了你的第一部分工作 - 你已成功安装了 Bodhi Linux。

  请注意，网络图标已自动出现在搁架上。如果你与路由器之间是有线连接，这将已被激活。如果你是通过无线连接，应点击网络图标以选择你的路由器并输入其密码。

## 2.1 初步的整理任务

  在进入有趣的部分之前，即让一切看起来和运作起来符合你的喜好，以及安装你想使用的软件应用程序之前，有一些相当琐碎的任务需要执行。首先，你需要更新你的系统。为了正常工作，你必须连接到互联网。

- 1) 在桌面任何位置左键单击以打开主菜单，然后选择 Applications（应用程序），然后 System Tools（系统工具），然后 Terminology。一个终端窗口会打开，你可以在其中输入 Linux 命令。

> **注意：** 将来我会将这样的序列写作 `menu > Applications > System Tools > Terminology`。如果桌面不可见，因为你有最大化的窗口打开，你可以改为点击面板顶部的图标打开主菜单，或者按键盘上的 Menu 键（这个键通常在底行，靠近空格键）。像这样的序列中每个菜单都会在前一个菜单的右侧打开，有时可能会消失在屏幕右侧。如果发生这种情况，只需将鼠标指针移到屏幕右边缘，菜单就会向左移动。

- 2) 你应该做的第一件事是将系统中存储的包索引与在线软件库同步。在终端中输入 `sudo apt-get update`，按 Enter，然后在询问时输入你的密码。现在将开始更新。
- 3) 接下来，你必须用系统中存储的软件的最新版本升级你的系统。输入 `sudo apt-get dist-upgrade`，当被询问时输入 `y` 以继续，按 `y`。
- 4) 每次想要对系统进行管理更改或安装软件时都要输入密码有点麻烦，所以你接下来的任务是禁用此要求。（但在工作场所环境中，或者如果你不完全信任的人将使用你的计算机时，**不要**这样做。没有这个要求，他们可能会毁掉你的系统！）
  - A) 在终端中，输入 `gedit /etc/sudoers`。输入密码后，sudoers 文件（位于 etc 目录中）将在 gedit（文本编辑器）中出现。
  - B) 向下滚动到此文件底部，并输入以下两行：

```
# Turn off requirement for password

bodhi32 ALL=(ALL) NOPASSWD: ALL
```

  第一行是注释（注释以 # 开头），并非必不可少。第二行必须完全照抄，并用你输入的 'bodhi32' 替换为你实际的用户名。（你的用户名显示在终端窗口顶部，在 (_) 符号之前。）注意此命令中的空格 - 用户名后有一个空格；(ALL) 和 NOPASSWD 之间有一个空格；最后一个 ALL 前有一个空格。
