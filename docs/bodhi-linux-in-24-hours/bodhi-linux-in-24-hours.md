# 1 引言

## 1.1 关于本指南

本指南介绍了如何在您的计算机上安装 Bodhi Linux 操作系统，如何自定义它，以及如何安装您希望使用的软件应用程序（网络浏览器、邮件客户端、办公应用程序、照片软件、媒体播放器等）。这是一份实用的逐步指南，而非对 Bodhi 系统的学术性描述，但在相关节点会提供指向网络上解释性材料的链接。

它源于为英国“第三龄大学”（U3A）计算机小组准备的笔记，该小组中的一些成员在微软决定停止支持 Windows XP 后，希望从 Windows 迁移到 Linux。不过，我希望它也能对更广泛的受众有用，包括那些初次接触 Bodhi 的现有 Linux 用户。

Bodhi Linux 高度可自定义，并可以通过多种方式进行微调。然而，像这样一份逐步指南必然是规定性的，因此遵循它最终会让您得到一个非常特定的桌面配置文件。请不要担心这一点。重点在于，一旦学会了如何创建和保存该配置文件，您就有能力设置您自己的配置文件，无论是通过摆弄已经生成的内容，还是从头开始。如果您搞砸了，您可以轻松地恢复已保存的配置文件。至于您在阅读本指南过程中将要安装的各种应用程序，它们也可以轻松地被移除并替换为其他替代品。

我应该强调，这不是官方的 Bodhi Linux 出版物，我与 Bodhi Linux 开发人员没有任何联系。就像 Bodhi 本身（实际上大多数 Linux 产品也是如此），它是免费提供的。但是，如果您发现它有帮助，更重要的是，如果您喜欢 Bodhi 并继续使用它，我鼓励您向 Bodhi Linux 捐款以支持其进一步开发。捐款链接位于 Bodhi Linux 主页 www.bodhilinux.com 上。

## 1.2 什么是 Bodhi Linux？

Bodhi（读音同 Jodie）是一种被称为 Linux 发行版或“distro”的东西，意味着它是 Linux 的一个变体，打包了窗口管理器或桌面。所有 Linux 变体都构建在相同的 Linux“内核”基础上，因此它们共享一个共同的核心。可能最流行的变体是 Ubuntu，Bodhi Linux 就是由此衍生的。Linux 有多种不同的桌面（即带有额外功能的窗口管理器），标准 Ubuntu 发行版打包的那个叫做 Unity。然而，Bodhi Linux 使用的是 Enlightenment 窗口管理器，简称 E17（17 是其当前版本号）。

Enlightenment 可以与其他发行版一起使用，它已成为许多 Linux 用户（显然包括我）的坚实首选，因为它敏捷、优雅且非常可自定义。

然而，只有 Bodhi Linux 将 Enlightenment 置于其设计哲学的核心。Enlightenment 的缺点是它非常可自定义，以至于用户面临相当陡峭的学习曲线，但 Bodhi 的帮助系统——“Tibodhi Enlightenment 指南”——提供了出色的指导。希望这份逐步指南能帮助您掌握它。

虽然 Bodhi 基于 Ubuntu 且非常接近 Ubuntu，但它不是 Ubuntu。特别是，它没有相同的软件存储库。同样，它的存储库基于 Ubuntu 存储库，但它保持更新状态，这意味着 Bodhi 开发人员试图提供您想要安装的各种软件应用程序的最新版本。

Bodhi Linux 目前处于版本 2，最新发布的版本是 2.4。

**延伸阅读：** 如果您想更多地了解 Bodhi 及其 Enlightenment 窗口管理器，请前往 Bodhi 指南的简介部分。您可以在 Bodhi 网站（www.bodhilinux.com）上找到它——在主页上，将鼠标指针移到“文档”上，选择“Enlightenment 指南”，然后选择“简介”。

## 1.3 开始之前需要了解有关 Bodhi Linux 的哪些知识

幸运的是，您不需要了解太多关于 Linux 本身的知识就可以使用 Bodhi 及其 Enlightenment 桌面，而您需要知道的知识可以在过程中逐步掌握。然而，有 Enlightenment 使用的两个概念我需要现在就向您介绍。这些是“E17 主题”和“配置文件”。我在此提及它们，是因为您在计算机上安装 Bodhi 时会遇到它们。

- **E17 主题：** 这些控制桌面的外观，包括背景、字体以及各种小部件，如时钟。要查看一些可用主题的示例，请前往 Bodhi 网站（http://www.bodhilinux.com/），将鼠标悬停在“资源”上，选择“艺术维基”（Art Wiki），然后选择“Enlightenment”。

- **配置文件：** 这些控制桌面的所有内容，包括您选择的主题、其元素的定位、加载的模块以及您可能设置的按键绑定和鼠标绑定。配置文件非常强大，因为它们存储了您的所有自定义设置，这意味着您可以尝试不同的配置文件，使用不同的主题和自定义设置，并确信您随时都可以返回到原始保存的配置文件。Bodhi 附带多个标准配置文件供选择，以适应您的特定硬件和偏好。

- **GTK 主题：** 也称为“主题”，这些不是 Enlightenment 的一部分，但我在此提及以免您稍后将它们与 E17 主题混淆。GTK 主题控制正在运行的应用程序内窗口的外观，即它们的颜色方案以及滚动条等常见元素的外观。要查看示例，请前往 Bodhi 网站上的艺术维基并选择 GTK 主题。

**注：** 我不会用 GTK 等术语的解释来 clutter 这份指南。如果您想知道它们的含义，请搜索网络，如有必要，在搜索短语中包含“linux”或“ubuntu”。




## 1.4 安装 Bodhi Linux

  第一步是制作一张包含 Bodhi Linux 系统的 CD。为此，你需要一张空白可录制 CD 和一台能够向其写入数据的计算机。假设你拥有这些条件，请按照以下步骤操作：

- 1) 访问 Bodhi Linux 官方网站 (http://www.bodhilinux.com)，你会在右侧看到两个下载链接，一个针对 32 位计算机，另一个针对 64 位计算机。建议你选择 32 位版本，因为它适用于所有计算机。（即使你的计算机是最新的 64 位机器，选择 64 位版本所获得的提升也微乎其微。）
- 2) 下一个界面会提供另外两个下载选项，一个是针对 PAE（物理地址扩展）计算机的，另一个是针对非 PAE 计算机的。同样，非 PAE 版本适用于所有机器。然而，在这种情况下，如果你的计算机支持 PAE，安装 PAE 版本是值得的，而且很可能你的计算机是支持的。2004 年后的所有计算机都支持 PAE，1995 年后的大多数机器也支持。因此，点击顶部（pae）的下载按钮，几秒钟后下载就会开始。这将是一个 .iso 文件，意味着它是一个光盘镜像。Bodhi 的 ISO 镜像足够小，可以容纳在 CD 上，而不是 DVD。
- 3) 你会注意到在 Bodhi 下载按钮下方有一个标有‘sum’的按钮。这会引导你进行进一步的下载，从而允许你检查下载的 ISO 镜像中是否存在错误。我从未在这些镜像中遇到过错误，但如果你想检查，可以使用一些免费的 Windows 实用工具配合 md5sum 下载——在网络上搜索‘md5sum on Windows’即可。
- 4) 现在将你的 ISO 文件刻录到 CD 上。在 Windows 7 中，如果你双击 ISO 文件，Windows 磁盘映像刻录程序应该会打开，你可以用它来刻录映像。否则，你可以使用 Windows（以及 Linux）上可用的免费 CD 刻录程序之一。我使用 CDBurnerXP，它适用于 Windows XP 以及 Vista 和 7，可在 https://cdburnerxp.se/ 下载。运行 CDBurnerXP 时，其中一个选项是刻录 ISO 映像。只需将一张空白可录制 CD 插入驱动器，选择此选项，浏览到你保存的 Bodhi ISO 文件，然后点击“Burn disc”按钮。几分钟后，你的 CD 就准备好了。
- 5) 现在到了关键时刻。启动你打算安装 Bodhi 的计算机，并立即按住 F12 键，直到启动菜单打开。将 CD 插入光驱，并在菜单中选择从此处启动的选项。（如果 F12 无法带你进入启动菜单，请查阅计算机手册了解应使用的方法。请注意，在计算机刚启动时，屏幕上应会显示一个你可以使用的启动按键列表。）
- 6) 一两秒后，光盘启动菜单会出现。选择顶部选项以运行实时系统。Bodhi 的欢迎屏幕会出现几秒，然后屏幕会变暗，可能有一分钟的时间似乎没有任何动静，除了 CD 驱动器工作的声音。然后，一切正常，一个配置文件选择菜单将出现。你可以松了一口气！
- 7) 如果几分钟后仍无反应，且光盘停止工作，这意味着一切并不顺利。如果你的计算机较旧，那么它很可能是非 PAE 机器，在这种情况下，你将不得不下载非 PAE 版本的 Bodhi。如果这样做了之后 Bodhi 仍然无法运行，这意味着 Linux 遇到了一些硬件不兼容问题。旧笔记本电脑上常见的问题与 ACPI（高级配置和电源接口）有关，要克服这一点，你必须关闭 ACPI；当光盘启动菜单出现时（步骤 6），按 Tab 键显示启动选项，并在该列表末尾添加命令 `acpi-off`。当然，你还应检查 md5sum（见上文步骤 3）。
- 8) 选择 Composite（组合）配置文件，点击 Next（下一步），然后在下一个屏幕中选择任何你喜欢的主题，再次点击 Next。Enlightenment 桌面将出现，左侧有一个面板（称为 shelf，搁架），上面有一些小工具，桌面上还有更多小工具，包括一个时钟。暂时不用在意这些。
- 9) 在实时系统中，网络小工具不会自动运行（在安装系统中它会运行），要连接互联网，你必须手动启动它。为此，打开主菜单（点击桌面的任何位置，或点击搁架顶部的图标），选择 'Run Everything'（运行所有程序）。在其对话框中输入 `network` 的前几个字母。蓝色的网络小部件将出现在对话框中并被高亮显示，现在你可以按 Enter 键运行它。网络图标将出现在搁架上。如果你有有线网络（即你的计算机通过电缆连接到路由器），连接将立即建立；如果你是通过无线连接，应点击图标，选择你的路由器，并输入其密码。

> **延伸阅读。** 有关连接互联网的更多信息，请访问 Bodhi 帮助系统的相关部分。点击桌面的任何位置以打开主菜单，选择 Bodhi Linux 然后选择 Quick Start（快速入门），然后点击第一个项目，'Connecting to the Internet'（连接互联网）。

- 10) 如果需要，你可以在此时试用 Bodhi，以确保在安装到硬盘之前你对它感到满意。要运行 CD 中包含的网页浏览器（Midori），点击搁架上从上往下数的第二个图标。
- 11) 当你准备好在计算机上安装 Bodhi Linux 时，双击 Install Bodhi（安装 Bodhi）图标。几秒后，语言选择对话框打开 - 选择适当的选项并点击 Continue（继续）。在下一个屏幕按 Continue（这是一个硬件检查 - 不用担心互联网连接被划掉），然后在下一个对话框中点击 Yes（是）以卸载分区。接下来，你必须决定是否希望将现有的操作系统与 Bodhi 一起保留在系统中。如果不需要，点击替换 Microsoft Windows 的框，然后点击 Continue。在下一个屏幕点击你在地图上的位置，之后接受适当的键盘布局（你可以使用默认选项）。接下来，你必须输入你的姓名，然后输入你想给计算机起的用户名（如果你愿意，可以保持为 Bodhi132）以及密码。选择 'Log in automatically'（自动登录）（除非你的计算机将在工作场所环境中使用），然后点击 Continue。最后，当计算机完成系统安装（这需要相当长的时间），你可以点击 Restart（重启）。
- 12) 重启后，在配置文件对话框中，再次选择 Composite 配置文件，然后在主题对话框中选择 'Bodhi-Theme'，如果列出了该主题；否则选择其他主题。（安装光盘上可用的主题选择因 Bodhi Linux 的版本而异。我将基于 Bodhi-Theme 来描述本指南第一部分内容，如果它不在你的安装光盘上，不用担心：你很快就会安装它）。这就完成了你的第一部分工作 - 你已成功安装了 Bodhi Linux。

  请注意，网络图标已自动出现在搁架上。如果你与路由器之间是有线连接，这将已被激活。如果你是通过无线连接，应点击网络图标以选择你的路由器并输入其密码。

## 2.1 初步的整理任务

  在进入有趣的部分之前，即让一切看起来和运作起来符合你的喜好，以及安装你想使用的软件应用程序之前，有一些相当琐碎的任务需要执行。首先，你需要更新你的系统。为了正常工作，你必须连接到互联网。

- 1) 在桌面任何位置左键单击以打开主菜单，然后选择 Applications（应用程序），然后 System Tools（系统工具），然后 Terminology。一个终端窗口会打开，你可以在其中输入 Linux 命令。

> **注意：** 将来我会将这样的序列写作 `menu > Applications > System Tools > Terminology`。如果桌面不可见，因为你有最大化的窗口打开，你可以改为点击面板顶部的图标打开主菜单，或者按键盘上的 Menu 键（这个键通常在底行，靠近空格键）。像这样的序列中每个菜单都会在前一个菜单的右侧打开，有时可能会消失在屏幕右侧。如果发生这种情况，只需将鼠标指针移到屏幕右边缘，菜单就会向左移动。

- 2) 你应该做的第一件事是将系统中存储的包索引与在线软件库同步。在终端中输入 `sudo apt-get update`，按 Enter，然后在询问时输入你的密码。现在将开始更新。
- 3) 接下来，你必须用系统中存储的软件的最新版本升级你的系统。输入 `sudo apt-get dist-upgrade`，当被询问时输入 `y` 以继续，按 `y`。
- 4) 每次想要对系统进行管理更改或安装软件时都要输入密码有点麻烦，所以你接下来的任务是禁用此要求。（但在工作场所环境中，或者如果你不完全信任的人将使用你的计算机时，**不要**这样做。没有这个要求，他们可能会毁掉你的系统！）
  - A) 在终端中，输入 `gedit /etc/sudoers`。输入密码后，sudoers 文件（位于 etc 目录中）将在 gedit（文本编辑器）中出现。
  - B) 向下滚动到此文件底部，并输入以下两行：

```
# Turn off requirement for password

bodhi32 ALL=(ALL) NOPASSWD: ALL
```

  第一行是注释（注释以 # 开头），并非必不可少。第二行必须完全照抄，并用你输入的 'bodhi32' 替换为你实际的用户名。（你的用户名显示在终端窗口顶部，在 (_) 符号之前。）注意此命令中的空格 - 用户名后有一个空格；(ALL) 和 NOPASSWD 之间有一个空格；最后一个 ALL 前有一个空格。




## 2.2 一些初步调整

现在，你将对该系统的外观和感觉进行几处修改。后续还会进行更多的更改。

- 1) 首先，如果你是英国人，请将系统设置为英式英语。在桌面任意位置点击以打开主菜单，然后选择“设置 > 全部 > 语言 > 语言设置”。（请记住：如果这个长序列中的最后一个菜单消失在了屏幕右侧，只需将鼠标指针移至屏幕边缘即可使其显示出来。）在打开的语言设置对话框中，高亮显示“英式英语”并点击“应用”，然后点击“关闭”。

- 2) 接下来，你很可能希望窗口像 Microsoft Windows 的窗口那样行为。前往主菜单 > 设置 > 全部 > 窗口 > 窗口焦点。在焦点设置对话框中，选择第一个选项（“点击窗口以聚焦”），然后点击“确定”。

- 3) 如果在上一章末尾选择主题时 Bodhi-Theme 不可用，请立即安装它。前往 Bodhi Linux 网站（www.bodhilinux.com），高亮显示“资源”并选择“艺术维基”，然后，在“主题”下，点击左侧第二个（绿色和白色）主题（称为 `bodhi_e17_bodhi`）。在下一个安装屏幕上，选择“立即安装”。安装大约需要几分钟，请保持耐心！完成后，你应该应用此主题（主菜单 > 设置 > 主题）。

- 4) 另一个你可能想要做的修改是设置菜单系统中使用的字体，以便让年长的眼睛更容易阅读。（这些笔记是为 U3A 的退休人员撰写的！）
点击桌面打开主菜单，然后选择“设置 > 全部 > 外观 > 字体”。然后，在字体设置对话框中：
- a) 点击“高级”。
- b) 在字体类别列中点击“菜单项”，然后在该列底部点击“启用字体类别”。
- c) 在字体列中选择“Nimbus Sans”，在样式列中选择“粗体”，然后在大小列中向下滚动至 12 像素并点击它。
- d) 点击“应用”，然后在桌面任意位置点击以查看你的菜单外观。
如果你对其外观满意，那就很好；否则，请尝试其他设置。为下一个练习保留对话框打开状态。

- 5) 现在更改窗口标题栏中使用的字体。要查看当前标题栏中使用的字体外观，请打开 Leafpad（主菜单 > 应用程序 > 附件 > Leafpad），并观察顶部橙色区域显示的内容（未命名）。要更改此字体，回到字体设置对话框，在字体类别列中点击“标题栏”，然后点击“启用字体类别”，然后在字体列中选择“Ubuntu”，样式列中选择“粗体”，大小列中选择“12 像素”。点击“应用”，并观察 Leafpad 标题栏中使用的字体如何变化。如果你对这些更改满意，请关闭 Leafpad 和字体设置对话框；否则，请尝试不同的字体。

- 6) 此时你可能想要做的另一个调整是关闭复合配置文件的一部分弹性效果（你可能在上述打开或关闭对话框时观察到了此效果）。打开主菜单并选择“设置 > 全部 > 外观 > 复合”，然后在复合设置对话框中的默认样式部分，向下滚动并高亮显示标记为“无”的最后一个选项。点击“确定”。（当然，你可能喜欢弹性效果，或者想尝试其他效果，在这种情况下你可以忽略此步骤。不要让个人喜好限制你的风格！）

到此为止，你应该已经意识到，你可以应用到你的 Enlightenment 桌面及其各个组件的设置数量多到令人眼花缭乱，我们稍后将探索这些设置中的更多内容。目前，我们将通过更改桌面壁纸来完成这次对可能性的初步探索。与 Microsoft Windows 一样，你可以几乎选择任何图片作为壁纸，包括你自己的照片，但让我们坚持使用 Bodhi 网站提供的内容。

  - a) 打开 Midori 网络浏览器（点击搁板上从顶部数第二个图标），并在地址栏中输入 Bodhi 网站地址（www.bodhilinux.com）。将鼠标悬停在资源上（页面顶部中央）并选择艺术维基。

注意：你可以使用 `killall` 命令以这种方式关闭任何行为异常且拒绝关闭的应用程序。但是，你通常应输入 `killall -9` 后跟应用程序名称。'-9' 确保运行应用程序涉及的所有进程（可能不止一个）都被终止。

这些是 Enlightenment 窗口管理系统的核心。它们控制着（除其他事项外）应用程序出现在哪个菜单中（如果有的话），以及如何运行，还可以用于控制应用程序是否作为图标出现在桌面上。应用程序启动器也被称为桌面配置文件，它们的扩展名是 '.desktop'。因此，Nautilus 启动器的文件名为 'NAUTILUS.DESKTOP'。我们现在将编辑它，不是直接编辑，而是通过 Enlightenment 提供的一个小巧工具。

- 1) 再次运行 Nautilus（主菜单 > 应用程序 > 附件 > 文件），不要担心其后显示的蓝色窗口。（也不要担心你需要通过菜单系统导航那种冗长的方式来启动 Nautilus。很快我们将为你的桌面加速，届时像这样的任务只需单击一下即可完成！）

- 4) 点击“确定”，然后关闭 Nautilus，并结束其后面的蓝色桌面（通过按下 Win + Space 运行任何程序，然后输入 `killall nautilus`）。
- 5) 现在再次运行 Nautilus，一切应该恢复正常。

## 2.6 使用 Nautilus 和 Gnome Terminal

在本节中，你将熟悉 Nautilus 和 Linux 文件系统。你将在主目录中创建所需的文件夹。你还将使用 Gnome Terminal，我们首先自定义其外观。

### 自定义终端

- 1) 打开 Gnome Terminal（主菜单 > 应用程序 > 附件 > 终端）。
- 2) 迎接你的配色方案可以改进，为此你应该打开“编辑”菜单并选择“个人资料偏好设置”。
- 3) 在对话框中，点击“颜色”选项卡。
- 4) 在“颜色”对话框中，取消勾选“使用系统主题颜色”框。然后在“内置方案”框中选择“白底黑字”。
- 5) 点击“关闭”，你将返回到终端窗口，现在应该更容易阅读了。如果你满意于此更改，请关闭终端。否则，返回“个人资料偏好设置”并进行更多微调。

### 使用 Nautilus

现在以通常的方式运行 Nautilus（即，从菜单系统）。它将在你的主目录中打开，显示一个文件夹（称为 Desktop/桌面），以及你之前下载的壁纸文件。主目录是你存储所有个人文件的地方。

- 1. 首先最大化 Nautilus，然后打开 Desktop 文件夹（通过双击它）。你会发现它是空的。但是，如果我们把任何桌面启动器复制到该文件夹中，它们将作为图标显示在桌面上。让我们现在把我们的 Nautilus 桌面文件复制到这里。
- 2. 按 F3 键在 Nautilus 中打开另一个窗格，然后点击侧边栏（左侧）中的“文件系统”。现在导航到 /usr/share/Applications（即，双击 usr 文件夹，然后在下一个屏幕上双击 share 文件夹，再双击 Applications 文件夹）。显示该文件夹中文件的图标将出现在这里。这些文件都是应用程序启动器，如果你愿意，可以通过双击其图标从这里启动应用程序。你还可以从此屏幕编辑启动器。
- 3. 你将来可能需要返回此目录，所以你记得到达该目录的路径的可能性很小，所以让我们将其加入书签：打开“书签”菜单并点击“添加书签”。Applications 目录被添加到侧边栏的顶部，可以通过单击一次访问。
- 4. 让我们检查一下我们的 Nautilus 启动器。在图标之间的空白处右键单击，并从上下文菜单中选择“在终端中打开”。（或者你可以从“文件”菜单中选择此选项。）终端在 /usr/share/Applications 目录中打开。
- 5. 最大化终端，然后输入命令 `ls`。该目录中文件的列表将显示，其中包含 ‘Nautilus.Desktop’。
- 6. 要编辑此文件：
    - A) 用鼠标拖动其文件名使其高亮显示，然后在终端窗口内的任何位置右键单击并从上下文菜单中选择“复制”。
    - B) 输入命令 `gksu leafpad` 后跟一个空格，然后再次在终端窗口内右键单击并选择“粘贴”。文件名将添加到命令末尾。
    - C) 按 Enter，桌面文件的内容将显示在 Leafpad 中。
- 7. 你可以在 Leafpad 中看到你在上一节所做的更改：几行下面有一个命令 ‘Exec=nautilus %U --no-desktop’。该文件下方的条目与 Enlightenment 无关，可以忽略，尽管你可能希望将它们注释掉。为此，只需在每行开头插入 #，使它们读起来像：

```
#### [DESKTOP ACTION WINDOW] 
#### Name="Open a New Window 
#### Exec=NAUTILUS 
#### OnlyShown=Unity;
```

## 2.7 以超级用户身份运行 NAUTILUS

有时，如下节所示，以“超级用户”身份运行 NAUTILUS 并拥有管理权限非常方便，因为这允许您对受保护的系统目录进行更改。为此，您必须以“root”身份运行 NAUTILUS。不用说，以这种方式运行 NAUTILUS 时必须非常小心，因为您可能会破坏您的系统。

以超级用户身份运行 NAUTILUS 最方便的方式将通过菜单系统，为此您必须为其创建个人应用程序启动器。

1) 前往主菜单 > 设置 > 所有 > 应用程序 > 个人应用程序启动器。
2) 在“个人应用程序启动器”对话框中点击“添加”。
3) 在下一个对话框的名称栏中输入 Nautilus as Root
4) 在应用程序栏中输入 gksudo "nautilus %U --no-desktop"（注意引号 - 它们是必不可少的。）
5) 点击“常规”选项卡，并在“类别”字段中输入 Utility... 这告诉 Enlightenment

在哪里定位此启动器的菜单条目。

5) 点击**应用**，然后**关闭**。

现在前往**主菜单 > 应用程序 > 附件**，您会看到“**Nautilus as Root**”已添加到菜单中。点击此条目，Nautilus 将运行，但它与之前的 Nautilus 并不完全相同。例如，您之前创建的书签已消失，如果您设置了任何首选项（在*编辑 > 首选项*中），这些也会消失。事实上，它是 Nautilus 的一个不同实例。

您可以从这里运行的 (**ROOT**) 终端也将是终端的不同实例，具有不同的首选项。现在测试一下：

1) 在 Nautilus 窗口中的空白处右键点击，并选择“**在终端中打开**”。终端以**Root**身份打开，但颜色设置不便。
2) 要修复这些颜色，打开终端的*编辑菜单*并选择“**配置个人资料**”。打开*颜色*选项卡，然后取消勾选“**使用系统主题颜色**”框。在“**内置方案**”处，选择**自定义**。现在将背景颜色设置为类似深红色；这将作为警告，表明您处于此终端实例的超级用户模式。
3) 点击**关闭**，然后关闭终端，但保持 Nautilus 以 **Root** 身份打开，为下一节做准备。

# 3 为您的桌面加速

如果您已经对在不断扩展的菜单系统导航中感到厌烦，那么这一章就是为您准备的。阅读完本章后，您应该能够充分欣赏增强型 Windows 桌面系统的完整灵活性和速度。您将设置好它，只需一两次鼠标点击即可运行应用程序和更改设置。您甚至还会加快并简化使用鼠标最大化、最小化、关闭以及操作窗口的方式。过去那种为了精确点击标题栏右侧的小按钮而感到痛苦的日子将一去不复返！

您将通过设置和填充架子（shelves）和 iBars 来实现这一切，并设置装饰绑定。这里涵盖的其他主题包括使用“运行所有”、加载模块（包括“位置”模块）和使用小工具。这将为您准备下一章节的桌面环境，在那里您将下载处理办公工作、操作照片、播放媒体文件等所需的应用程序。

> 提示：在通过此指南操作时，您将打开许多窗口和对话框。如果其中一个超出了屏幕边缘，您想将其拉回视野中，请在用鼠标拖动时按住 Alt 键。（当然，如果窗口有可见的标题栏，您也可以直接拖动它。）

## 3.1 首次查看架子（Shelves）和 I BARS

我们将首先自定义桌面左侧现有的架子。

1. 在架子空白区域右击，并选择上下文菜单中的第一个选项“内容”。

4. 通过高亮其他已选中的小工具并单击“移除小工具”来取消选中它们。（其中一些，如混合器和系统托盘，您很快会将它们添加到另一个架子上。）
5. 您的架子上将只剩下三个图标，即“iBar”（当前托管着 Mitori）、“设置”和“运行所有”。关闭对话框。
6. 现在右击架子上的 Mitori 图标，鼠标悬停在“iBar”上，然后选择“内容”。打开 iBar 应用程序对话框。您可能希望拖动其上下边框使其变大。

8. 单击“顺序”选项卡（位于框顶部），并在列表中向下移动 FIREFOX 和 SYNAPTIC，使顺序变为：NAUTILUS、TERMINAL、FIREFOX、THUNDERBIRD、SYNAPTIC。

10. 再次在架子空白区域右击，并从菜单中选择“设置”。打开架子设置对话框。
11. 在“堆叠”选项卡中，选择“窗口下方”（这确保如果您希望全屏运行应用程序，架子将不可见。）
12. 单击“位置”，在此选项卡中选择左侧的第二个选项（即位于屏幕左边缘、顶部的架子）。
13. 在“大小”选项卡中，将大小保留为 40 像素，但选择“收缩至内容宽度”。
14. 单击右箭头到达“样式”选项卡，在这里您应该选择“不可见”。
15. 单击“应用”，然后关闭。

您架子上的图标现在应聚集在屏幕左边缘、顶部位置，且架子本身应不可见。现在您只需单击即可访问放置在上面的所有小工具和应用。其中之一——“设置”小工具——您将在下一节中使用。

**注意：** 系统（电源开关）小工具不再位于架子上。因此要关闭计算机，您要么按计算机的电源按钮，要么使用菜单系统（主菜单 > 系统 > 关机）。在本章稍后，您将创建一个按键绑定来关机。

## 3.3 第二个架子

我们将混合器（Mixer）和系统托盘（Systray）小工具放在第二个架子上，该架子同样位于屏幕左侧，但在底部。系统托盘要求此架子可见。

若要更改此架子上小工具的顺序（使混合器位于底部，在系统托盘下方），右击混合器并选择“开始移动小工具”。现在您可以将小工具拖动到所需位置。再次右击混合器并选择“停止移动小工具”。

提示：如果某个应用程序已打开并最大化，除了为架子保留的左侧窄条外，它填满了整个桌面，您可以单击两个架子之间暴露的桌面部分来打开 EnLightenment 菜单系统。

## 3.6 运行一切 (Run Everything)

你可以看到，iBars 提供了一种通过单击即可启动应用程序的绝佳方式，但那些带有对话框的设置工具（你一直在使用的那些）该怎么办？它们必须从菜单系统内部深处启动。即使使用“设置”小部件来访问这些对话框也需要大量的导航。解决方案是使用“运行一切”（Run Everything）模块。

你可以通过点击第一个 iStrip 中的“运行一切”图标来启动它（如果你已将其叶子设置为白色背景）。你也可以通过按下 Alt + Esc（即按住 Alt 键并按下 Esc 键）、Win + Space（即按住 Windows 键并按下空格键），或从主菜单中选择它来直接运行。

1) 现在点击“运行一切”图标。其对话框打开，底部列出了标签页，分别标记为“所有”（All）、“应用程序”（Applications）、“窗口”（Windows）、“执行”（Execute），以及另外两个（“设置”和“插件”），你只有滑动过去才能看到它们。依次点击每个标签页，你会看到“运行一切”如何组织计算机上的程序。

2) 如果你知道某个程序的名称，运行它的最简单方法不是通过这些标签页，而是直接在此对话框中输入该程序名称的前几个字母。例如，要运行终端（Terminal），你可以输入 TERMINAL 的前两个或三个字母，然后按下回车键。

你将在本章剩余部分的练习中使用“运行一切”。请注意，在这些练习中，我将仅指示你“运行一切”，这意味着你应该点击搁架上的“运行一切”图标，或者按下 Alt - Esc，或者按下 Win - Space，或者从主菜单中选择它。

延伸阅读：前往**Booh Guide to Enlightenment**（主菜单 -> Booh Linux -> 快速入门，将鼠标悬停在“Enlightenment”上并选择“Booh Guide”），阅读“Everything Module”（所有模块）部分。为准备接下来的练习，你还应阅读“Bindings”（绑定）部分。

## 3.7 边缘绑定

边缘绑定指定了当你在屏幕边缘的不同部分点击鼠标时触发的操作。设置方法如下：

1) 运行“一切”（Run Everything），输入*edge bindings*（边缘绑定）的前三个字母。“边缘绑定”图标会被高亮显示。按下回车键，“边缘绑定设置”对话框将打开。

2) 点击**添加**（Add），你将进入“边缘绑定序列”对话框。你将从为屏幕右上角创建绑定开始，因此点击此角落处的棕色框。

3) 点击*clickable edge*（可点击边缘），然后点击**应用**（Apply）。

4) 现在你需要将此绑定分配给一个操作。在右侧的操作窗格中，向下滚动至“Window : Actions”（窗口 : 操作）部分（位于巨大列表的约三分之二处），并高亮显示“Close”（关闭）。

5) 点击**应用**（Apply）。现在，每当你在屏幕的右上角点击时，当前聚焦的窗口将关闭。这等同于点击标题栏右上角的“x”按钮。（那些微小的标题栏按钮很难点击，将鼠标快速移动到屏幕右上角要容易得多）。

6) 再次点击**添加**（Add），现在，在“边缘绑定序列”对话框中，点击屏幕图片的顶部边缘。“可点击边缘”选项应该已被自动选中，因此点击**应用**（Apply）。

7) 在右侧窗格中向下滚动至“Window : State”（窗口 : 状态）部分，高亮显示“Maximize”（最大化），然后点击**应用**（Apply）。现在，每当你在屏幕的顶部边缘点击时，当前聚焦的窗口将最大化。这等同于点击标题栏右侧的“+”按钮，但操作更简单。请注意，若要取消最大化窗口，只需再次点击屏幕的顶部边缘即可。

8) 再次点击**添加**（Add），在“边缘绑定序列”框中点击底部边缘，然后应用（APPLY）。

9) **高亮** *‘Iconic Mode Toggle’*（图标模式切换）（位于 ‘Window : State’ 部分），然后点击应用。现在，无论你在屏幕底部边缘点击什么，当前聚焦的窗口将被最小化。这等同于点击标题栏上的‘↓’按钮。

10) 现在你应该创建绑定来执行当前无法通过鼠标点击完成的其他操作。我建议如下：

- A) 左上边缘 - ‘**Fullscreen** Mode Toggle’（全屏模式切换）（位于 ‘Window : State’ 部分）。点击此处将切换到全屏。再次点击将恢复。

- B) 左边缘 - ‘**Maximize** Left’（最大化左侧）（位于 ‘Window : State’ 部分）。

- C) 右边缘 - ‘**Maximize** Right’（最大化右侧）（位于 ‘Window : State’）。当你想要并排打开两个窗口时，此绑定和上一条都极其实用。

- D) 右下边缘 - ‘**Show The Desktop**’（显示桌面）（位于 ‘Desktop’ 部分，在右侧窗格的顶部）。这将最小化所有打开的窗口并显示桌面。

- E) 这样就只剩下左下角没有绑定了。我稍后会对这里提出建议。

11) 现在打开一个应用程序，并使用其窗口测试这些绑定。请注意，对于大多数这些绑定，第二次点击会将窗口恢复其先前状态。

**注意：** 你不需要最小化应用程序来将其从视野中隐藏。相反，你可以双击其标题栏将其窗口卷起至标题栏下方。再次双击标题栏将展开它。试一试。

## 3.8 按键绑定

让我们现在创建一些按键绑定。步骤与上一节描述的类似。

1) 运行*一切*（Everything），并在**运行一切**（Run Everything）对话框中输入*key bindings*（按键绑定）的前几个字母。“按键绑定”图标将会被高亮显示；按下**Enter**（回车键），**按键绑定**设置对话框将打开。

2) 如果你在左侧（很长的）列表中的任何项上点击，其绑定的操作将在右侧的“操作”窗格中高亮显示。例如，如果你点击“Menu”（代表菜单键），“Show Main Menu”（显示主菜单）将在右侧高亮显示。花几分钟时间探索已有的许多按键组合的绑定是值得的。例如，Win + Left（即 Windows 键加上左箭头键）将**最大化左侧**（Maximize Left），而 Win + Right 将最大化右侧。

**注意：** 在设置你自己的按键绑定时，你应该避免被应用程序使用的按键组合。例如，Ctrl + s 通常用于保存，而 Ctrl + c 和 Ctrl + a 用于复制和粘贴。Win（Windows 键）组合在其他地方未被使用，因此是很好的选择。

3) 让我们现在设置一个按键绑定。点击**添加**（Add），系统将提示你按下按键组合。



按 Win + m（即按住 Windows 键并轻按 m）。

-   4) 在右侧“操作”窗格中，向下滚动到“窗口：状态”部分，高亮显示“垂直最大化”。点击“应用”，绑定设置即完成。
-   5) 要测试您的绑定，现在请按下 Win + m。“按键绑定设置”对话框应当垂直最大化，使其使用体验更佳。今后，如果像这样对话框在垂直方向上过于拥挤，您可以按 Win + m 来立即放大它。
-   6) 再次点击“添加”以创建另一个绑定。按下 Win + End，然后在右侧“操作”窗格中向下滚动到“系统”部分，高亮显示“立即关机”。然后点击“应用”。现在，当您想关闭计算机时，只需按 Win + End 即可。
-   7) 如果您的键盘没有音量控制键且希望拥有它们，请设置 Win + 上箭头（即 Windows 键加向上箭头键）和 Win + 下箭头，分别作为“增大音量”和“减小音量”。您可以在“操作”窗格的“混合器”部分找到这些操作。要测试这些按键，请打开 Firefox 并播放一些视频材料，例如来自 YouTube 的内容。
-   8) 点击“关闭”以退出。当您继续使用 Bodhi 时，您会想到其他的按键组合，而“运行一切”（Run Everything）让返回“按键绑定”对话框变得非常容易。

如果您读到此章末尾并希望关闭计算机，请记住您的快捷键：按 Win + End。

# 4. 增强您的系统

当您读完本章时，您应该已经安装了大多数可能需要的应用程序。如果您是 Linux 新手，问题将是：在众多可能性中，您应该选择哪一个？有时选择很明确，而在许多情况下，您可能之前在 Windows 下使用过的首选软件也有 Linux 版本。

例如，VLC 是标准的公共领域（即免费）媒体播放器，在 Windows 和 Linux 中都是如此；LibreOffice 则是 Windows 和 Linux 的标准公共领域办公套件。其他选择并不那么明确，而且我推荐的某些软件可能并不最适合您。另外，如果您的计算机较旧且性能不足，这将把您的选择限制在轻量级应用程序上。

您最好的策略是试用一到两个替代方案；卸载您不想要的并安装其他软件是很简单的。（与 Windows 类似，卸载应用程序后可能会留下一些残留；您将在第 6 章中学习如何删除这些残留并整理您的系统。）

只要可能，您应从 Bodhi 应用中心（AppCenter）而非 Synaptic 安装应用程序。要卸载应用程序，请使用 Synaptic。

## 4.1 办公应用程序

LibreOffice 是一个不错的替代品，尽管包括 Microsoft Office 在内的微软产品无法在 Linux 中运行，但它在许多学校、政府机构和企业中都被使用（尽管通常是在 Windows 计算机上）。它包含替代 Word 的 Writer、替代 Excel 的 Calc、替代 PowerPoint 的 Impress 以及替代 Access 的 Base。它还包含 Draw，这是一个绘图程序。我可以读取任何以 Microsoft Office 格式保存的文档，并且可以将文档导出为该格式。我正使用 LibreOffice Writer（运行在 Bodhi Linux 上）来撰写这本书。

当然，如果您在办公方面的唯一需求只是偶尔写一封信，那么安装像 LibreOffice 这样重量级的软件并没有太大意义。Abiword 文字处理软件包要合适得多。

Cups 是提供打印选项的应用程序所使用的打印包，如果您想从计算机打印，就需要安装它。

LibreOffice 和 Cups 必须从 AppCenter 安装；否则您将无法下载运行它们所需的所有组件。Abiword 可以从 AppCenter 或 Synaptic 安装。

-   1) 前往 Bodhi Linux 网站 (www.bodhilinux.com) 并导航至 AppCenter。
-   2) 在“办公”部分选择“办公套件”，然后选择 LibreOffice。点击“立即安装”。安装将花费一两分钟。如果您选择安装 Abiword 而不是 LibreOffice，您将在“办公”部分的“文字处理器”下找到它。
-   3) 要安装 Cups，返回 AppCenter，从“办公”部分选择“打印和扫描”，然后选择“打印”，点击“立即安装”。
-   4) LibreOffice 和 Cups 将被添加到您的菜单系统中，前者位于“主菜单 > 应用程序 > 办公”，后者位于“主菜单 > 应用程序 > 偏好设置”。请注意，您不会看到以名称列出的 Cups，而是被称为“打印”。

现在您可以安装您的打印机：

-   1) 确保您的打印机已打开并连接，无论是直接连接到您的计算机还是连接到网络。例如，它可能连接到一个本身连接到网络的 Windows 计算机。
-   2) 从菜单系统或通过“运行一切”运行“打印”（输入 printing 的前几个字母并按 Enter）。打开打印窗口，您可以在其中点击“添加”来添加您的打印机。
-   3) 打开“选择设备”对话框，您可以选择相应的选项。例如，如果打印机连接到网络上的另一台 Windows 计算机，请选择“网络打印机”，然后选择“通过 SAMBA 的 Windows 打印机”。然后点击“浏览”并双击出现的条目（例如 WORKGROUP，然后是 Windows 计算机的名称）。您的打印机应显示在对话框中：高亮显示它并点击“确定”。
-   4) 点击“下一步”，然后从列表中选择合适的打印机制造商，再次点击“下一步”并选择型号。选择推荐的驱动程序，点击“下一步”，然后“应用”。
-   5) 您将受邀打印测试页。假设效果令人满意，点击“确定”，然后关闭打印窗口。
-   6) 现在运行 LibreOffice Writer（或 Abiword），打开“文件”菜单，选择“打印”。您应该看到打印机在“打印机”对话框中被高亮显示。如果是这样，一切正常，您可以点击“取消”，然后关闭 Writer。

## 4.2 媒体播放器

VLC 是播放媒体文件，尤其是视频文件的标准应用程序，因为它能处理许多不同的文件类型，并且能够在不同类型之间进行转换（如果您希望这样做）。如果您希望播放 DVD，还需要下载一个名为“VLC”的插件，该插件在 AppCenter 中均可获得（后者在“DVD 播放”列表下）。

## 4.7 OSMOMA 音频录音机

**这允许你录制通过电脑扬声器播放的任何内容，包括广播节目。你不会在 AppCenter 或 Synaptic 中找到此应用程序，而是必须从 PPA 安装它。**

**PPA 是针对特定软件包的 unofficial 仓库，它们不一定可靠。因此，如果你从 PPA 安装，后果自负；话虽如此，我在本指南中提到的 PPA 上没有遇到过任何问题。**

**OSMOMA 音频录音机在 HTTP://IT’SF OSS.COM/RECORD-STREAMING-AUDIO... 有描述。要安装它，你必须打开终端并输入以下命令：**

```bash
SUDO ADD-APT-REPOSITORY PPA:OSMOMA/AUDIO-RECORDER
SUDO APT-GET UPDATE
SUDO APT-GET INSTALL AUDIO-RECORDER
```

**（这些命令在上述网页上提供，你可能会发现直接从那里复制并粘贴到终端中最方便。）**

**音频录音机可以录制多种文件格式，但不支持 MP3。如果你想添加 MP3 功能，你还必须安装一个名为“10-PLUGINS-UGLY”的插件（请使用 Synaptic 完成此操作）。**

**要测试音频录音机，运行它（你可以在“应用程序 > 声音与视频”中找到它），打开后：**

- 1) 在格式字段中选择一个合适的格式（例如，如果你已经下载了上述 GStreamer 插件，则选择 MP3）。
- 2) 通过电脑播放一些音频内容并按下“开始录音”按钮。录音按钮旁边应出现一条蓝色音频可视化条，表明音频正在被录制。
- 3) 按下“停止录音”，录制的文件将保存在音频文件夹中。（该文件夹将在安装过程中创建；如果它尚未出现在你的主目录中。）
- 4) 通过打开 Audacious（如果你在 4.2 节中安装了它）来测试录音，将新文件添加到播放列表中，然后播放它。或者，你也可以在 VLC 中播放它。

请注意，如果你静音扬声器（使用混合器小工具中的静音选项），音频录音机将无法录制到声音。要录制而不实时收听内容，例如你稍后想在车上回放的广播节目，请将耳机插头插入电脑的耳机插座以切断扬声器声音。

另外请注意你可以在音频录音机的计时器部分使用的命令。# 符号用于注释命令，因此请删除你希望激活的命令前的 #。如果你在此部分进行更改，必须点击“保存”按钮才能使其生效。

另外请注意文件字段旁边的“添加”按钮。只有当你希望将新录音追加到之前录制的文件中时，才应点击此按钮。

## 4.8 eDeB 和 Chrome

如果你住在英国并希望观看或收听 BBC iPlayer 上的节目，最好使用 Google Chrome 网络浏览器。不幸的是，你不能从 AppCenter 或 Synaptic 下载此软件，而是必须将其作为 .deb 文件下载。

处理 .deb 文件的最简单方法是使用 eDeB 包安装程序。Bodhi 2.4 版中已包含此程序（你可以在主菜单 > 应用程序 > 系统工具中找到它），但如果你运行的是早期版本的 Bodhi，你必须先通过 Synaptic 下载它（在过滤字段中搜索 eDeB）。

假设你的系统上已有 eDeB，你可以下载并安装 Chrome：

- 1) 打开 Firefox 并搜索 Google Chrome。第一个结果应该是 Google Chrome 的官方网页，顶部附近有一个蓝色的“下载 Chrome”按钮。
- 2) 点击此按钮，在下一个屏幕接受“32 位 .deb（适用于 Debian/Ubuntu）”选项。点击“接受并安装（Accept and Install）”。
- 3) 在下一个对话框框中点击“确定（Ok）”以保存文件。将出现一条消息，显示文件已保存到你的下载目录（即你的 Downloads 文件夹）。
- 4) 前往主菜单 > 应用程序 > 系统工具并运行 eDeB。点击“选择 .deb 文件（Select .deb file）”按钮。
- 5) 在下一个屏幕中点击“下载（Downloads）”文件夹，然后高亮显示 google-chrome_deb 文件并点击“确定（Ok）”。
- 6) 在下一个屏幕上，你需要等待大约 30 秒，直到 eDeB 下载软件包信息。然后点击“确定（Ok）”。
- 7) 系统提示你在安装前运行检查，因此点击“检查（Checks）”按钮。希望这能确认你可以继续安装。
- 8) 点击“确定”然后点击“安装（INSTALL）”。
- 9) 输入你的密码，然后点击“确定（OK）”。安装将进行，稍后会显示一条警告消息，提示缺少依赖项。
- 10) eDeB 的一大优点是它可以为你解决此类问题。点击“安装缺失的依赖项（INSTALL MISSING DEPENDENCIES）”，点击“抓取（GRAB）”，然后输入你的密码并点击“确定（OK）”。
- 11) 当 eDeB 完成所有安装后，你可以点击“完成（DONE）”，然后关闭它。

现在，如果你愿意，可以运行 Google Chrome（主菜单 > 应用程序 > Internet）。在初始欢迎屏幕上，取消勾选邀请你将 Chrome 设为默认浏览器的复选框，然后点击“开始（START）”。

## 4.9 Get+PLAYER

**如果你想以 MP4 格式（电视节目）或 MP3 格式（广播节目）从 BBC iPLAYER 下载内容，以便在支持这些格式的任何设备上无限制地播放，那么 Get+iPLAYER 是必需品。它是一个命令行程序，意味着你必须在终端中输入命令才能使用它。不要因此却步，因为命令相当简单（或者当我们稍作调整后就会很简单——但这后话）。**

**你必须从 PPA 下载 Get+iPLAYER，为此你应该在终端中输入以下命令序列：**

```bash
SUDO ADD-APT-REPOSITORY PPA:JON-HEDGERS/GET+PLAYER
SUDO APT-GET UPDATE
SUDO APT-GET INSTALL GET+iPLAYER
```

**要使用 Get+iPLAYER 下载电视节目：**

- 1) 使用 Nautilus 导航到你希望保存节目的文件夹，然后在文件夹窗格的空白处右键单击并选择“打开终端（OPEN TERMINAL）”。
- 2) 在终端中，输入 GET+iPLAYER "节目名称"。你可以使用下划线或连字符连接“GET”和“iPLAYER”，并且显然你必须将“节目名称”替换为你要查找的节目名称，并且应该包含引号。例如，如果你输入 RAILWAY，将显示所有名称中包含“RAILWAY”的节目列表。
- 3) 每个结果都会编号。假设你想要的那个编号为 #456，你应输入 GET+iPLAYER -GET #456。（注意“GET”前面有两个短横线）。Get+iPLAYER 将继续把第 456 号节目下载到你步骤 (1) 中打开的文件夹。根据节目的时长


该程序，这需要相当长的时间，在此期间你需要做点别的来打发时间，因为此过程会在后台继续运行。

4.  完成后，你可以使用 VLC 等媒体播放器来播放该程序。

**以类似的方式，广播节目也可以被下载，唯一的区别是在步骤 (3) 中，你应该输入 `GET-PLAYER RUNE "RADIO PROGRAMNAME"`。**

> *注意：与电视节目不同，使用播放器下载的广播节目会包含两到三分钟的不需要的内容：开头是上一个节目的片段，结尾是下一个节目的片段。如果你打算在车里收听这些节目，这会是个麻烦。我的做法是使用 Chrome 网络浏览器来播放这些节目，并使用 Audio Recorder 从正确的起点开始录制它们。*

**可以添加到命令中的 `-GET` 和 `-TYPE` 等选项被称为参数或开关。** **`GET-PLAYER` 有许多可用的参数，若要获取比此处更详尽的说明，你应该在网络上搜索 `GET-PLAYER INSTRUCTIONS`。**

**请注意 `-HELP` 参数：这将列出该命令可用的所有参数，并对每个参数进行简要说明。因此，要列出可用于 `GET-PLAYER` 的所有参数，请在终端中输入 `GET-PLAYER -HELP`。**

## 4.11 卸载应用程序

任何从 AppCenter 或 Synaptic 安装的内容都可以通过运行 Synaptic，搜索应用程序名称并勾选其复选框来卸载。（如果应用程序已安装在你的系统上，该复选框会被填充颜色而非空白。）从菜单中选择 ‘Mark for Complete Removal’，然后单击 Apply。应用程序及其依赖项将被移除。

尽管如此，你的系统上仍会留下一些不需要的文件，你可以通过打开 Terminal 并输入以下命令来清除它们：

```
sudo apt-get autoremove
```

你的系统已经积累了一些杂乱的文件，因此现在运行此命令是值得的。

- 删除当前填充此 iBar 的应用图标（依次单击橙色按钮和 ‘Remove’），并添加你已安装的媒体应用程序：Audacious、Audio Recorder 和 VLC。你可能希望在这里也添加 Brasero 光盘刻录程序。
- 单击 Order 选项卡，按你想要的顺序排列这些图标，然后单击 OK，再单击一次 OK。你选择的包的图标将显示在你的新 iBar 中。
- 右键单击其中一个图标，鼠标悬停在 ‘iBar’ 上，然后选择 ‘Begin move/resize’。现在你可以拖动垂直边框使其紧密围绕图标，并将其移动到桌面上你想要的确切位置。完成后再次右键单击。
- 你的新 iBar 周围有一个边框。要移除它，再次右键单击它，鼠标悬停在 ‘iBar’ 上，鼠标悬停在 ‘Appearance’ 上，然后选择 ‘Plain’。

如果你愿意，可以通过重复此过程在桌面上设置更多的 iBar。

由于进行了此类更改，shelf 上的小工具可能已经重新排列。请记住，你可以通过右键单击小工具并选择 ‘Begin moving gadgets’ 来重新排序它们。完成后再次右键单击并选择 ‘Stop moving gadgets’。

注意：如果以后你想修改此第二个 iBar 的内容，右键单击其中一个图标，然后鼠标悬停在 ‘Settings (cst Contents)’ 上，并在列表中突出显示此 iBar 的名称（media）。然后选择 ‘Setup.’（选择 ‘Settings’ 而不是 ‘Settings (cst Contents)’ 将修改 shelf 上的默认 iBar。）

## 5.3 收藏夹菜单

现在让我们设置收藏夹菜单。这将允许你通过在桌面任何位置右键单击来访问收藏夹应用程序。

1.  单击 Settings 图标（顶部 shelf），然后最大化出现的 Settings 窗口（通过单击屏幕顶部 – 记住你的鼠标绑定！）。
2.  单击 Apps，然后单击 ‘Favourite Applications’。Favourite Applications 对话框打开。你可能希望使用 Win + m 快捷键垂直最大化此框。
3.  你应该添加 Synaptic，以及你希望随时使用的其他应用程序，除了那些可以从 shelf iBar 运行的应用程序。
4.  单击 Order 选项卡并设置顺序，然后单击 OK。
5.  保持 Settings 窗口打开，为下一节做准备，但通过在 shelf 下方的裸露桌面区域右键单击来测试你的新菜单。

## 5.4 应用程序名称显示

菜单系统中显示的应用程序名称相当长，因为它们不仅给出名称，还在括号中给出应用程序类型。例如：Synaptic Package


Manager 显示为“Synaptic 软件包管理器（软件包管理器）”。对于 Linux 初学者来说，这并没什么问题，但随后你可能会觉得有点烦人。你可以在此设置窗口中更改：

- 1) 点击“菜单”，然后选择“菜单设置”。
- 2) 在“菜单设置”对话框中，关闭“通用（Generic）”，然后按“确定”。保持设置窗口打开，但在 shell 下方右键点击桌面以测试你的操作。通用（括号内的）注释应该已经消失。

## 5.5 启动应用程序

你可能希望某些应用程序在启动计算机时自动运行，以便它们可以毫不费力且立即使用。例如，我喜欢以这种方式运行 Osmo。你设置的个人应用程序启动器也可以在启动时自动运行。例如，我设置了一个启动器，用于在启动时执行一条命令以关闭我笔记本电脑上的触摸板（我使用鼠标）。

设置启动应用程序的方法：

- 1) 在设置窗口中，选择“应用程序”，然后选择“启动应用程序”。
- 2) 在“启动应用程序”对话框中，点击“应用程序”，然后，如果愿意，选择一个或两个应用程序。点击“确定”。

当然，你需要重启计算机才能测试此功能。否则，请保持设置窗口打开，以便进入下一节。

## 5.6 虚拟桌面

你不仅有一个，而是有五个可用的桌面，如果你愿意，还可以添加更多。目前，这些虚拟桌面是相同的，具有相同的壁纸、架子和 iBar，但这是可以更改的，例如，你可以拥有一个将媒体应用程序分组的桌面，以及另一个用于照片应用程序的桌面。更好的是，你可以拥有一个按照你工作方式设置的桌面，另一个为你伴侣设置。就我而言，我可以将本指南放在 1) 我在一个桌面上写作，然后我所需参考的内容，如对话框，打开在另一个桌面上。

让我们现在设置一些类似的内容。

- 1) 在设置窗口中点击“屏幕”，然后选择“虚拟桌面”。打开“虚拟桌面设置”对话框。在这里你可以看到你有五个相同的桌面；你可以增加或减少这个数字，并且可以垂直堆叠以及水平堆叠。
- 2) 让我们通过将桌面数量减少到两个来简化事情：将底部滑块向左拖动，直到出现“2”作为数字。
- 3) 现在点击第二个桌面，将“名称”更改为有意义的名称，然后点击“设置”。你会被带到“壁纸设置”对话框。点击“使用主题壁纸”（或者，最好地，获取另一个壁纸，例如，通过使用 Firefox 从 Bodhi Linux 网站下载一个）。
- 4) 点击“确定”，然后再次点击“确定”。回到“虚拟桌面设置”对话框，点击第一个桌面并给它一个有意义的名称。点击“确定”，然后点击“关闭”以返回设置窗口。
- 5) 点击“翻转动画”选项卡，并将其设置为“关闭”。点击“应用”，然后点击“关闭”。
- 6) 要转到第二个桌面，按 Alt + F2，要返回第一个按 Alt + F1。如果你有第三个桌面，Alt + F3 将切换到该桌面，Alt + F4 切换到第四个，依此类推。在桌面之间切换的一种更简单的方法是将“页面导航器”小工具放在架子或桌面上并点击它。你还可以通过按 Ctrl + Alt + 右箭头键在你的两个桌面之间切换。

但为了让切换真正变得容易，让我们设置一个边缘绑定：

1) 转到“边缘绑定”对话框（通过“运行一切”）。

2) 点击“添加”，选择左下角，然后选择“可点击边缘”，然后点击“应用”。

3) 在左侧窗格中突出显示“左下边缘”，在右侧窗格中选择“线性翻转桌面...”。

4) 该命令末尾的三个点表示需要进一步的信息，一个“操作参数” - 在这种情况下，是一个表示要翻转多少个桌面的参数。在“操作参数”框中输入“1”，然后点击“应用”。

5) 通过点击屏幕的左下角来测试此绑定。每次重复点击将在桌面之间切换。

## 5.7 不同桌面的不同架子

要在第二个桌面上创建不同的架子，我们首先需要修改现有架子的设置，使其仅在第一个桌面上显示：

1) 右键点击顶部架子上的一个图标，鼠标悬停在“架子”上，然后选择“设置”。

2) 在“架子设置”对话框中，不断点击右箭头，直到到达“桌面”。点击“在指定桌面上显示”，突出显示第一个桌面的名称，然后点击“确定”。

3) 按 Alt + F2 检查它是否已从第二个桌面消失。

现在让我们在这个第二个桌面上添加一个架子：

- 1) 转到“主菜单 > 设置 > 架子”，然后点击“添加”。
- 2) 给你的新架子起一个有意义的名称，例如你给第二个桌面起的名称。点击“确定”。
- 3) 现在，在“架子内容”对话框中，添加一些小工具。这可能包括“一切启动器”以及 iBar。点击“关闭”。
- 4) 这个架子上的 iBar 填满了默认 iBar 的图标。要更改这一点，右键点击它，鼠标悬停在“iBar”上，然后选择“设置”。现在点击“添加”以添加另一个源，并给它一个合适的名称。点击“确定”。
- 5) 在源列表中突出显示此名称，然后点击“设置”。如果你希望垂直最大化对话框，请按 Win+m，然后移除已经存在的其他应用程序并添加其他应用程序。然后点击“顺序”选项卡以调整顺序，然后点击“确定”，并再次点击“确定”以关闭这些对话框。
- 6) 现在右键点击你的新架子，鼠标悬停在它的名称上，然后选择“设置”。进行以下设置：堆叠 - “窗口下方”；位置 - 右侧，顶部；样式 - “不可见”；桌面 - “在指定桌面上显示”以及你第二个桌面的名称。点击“确定”。

你现在有两个具有不同架子的桌面。请注意，桌面小工具（时钟、桌面 iBar 和“位置”小工具）在两者上都是相同的。

## 5.8 GTK 主题

这些是应用程序主题，它们允许你自定义应用程序运行的窗口的外观。这是一个非常简单的任务，因为它只需要下载并尝试一些主题。

- 1) 打开 Firefox 并转到 Bodhi 主页 (http://www.bodhilinux.com/) 并导航到“资源 > 艺术 Wiki > GTK 主题”。
- 2) 向下滚动到 bodhi_gtk_countryy_oak（右侧第五个）并点击它。你会被带到这个主题的安装页面。
- 3) 最好在开始安装之前执行 `sudo apt-get update`，一个简单的执行方法是点击“开始前”标题下方那一行的链接。几秒后，系统会询问你是否要安装一个小更新程序。接受它。
- 4) 现在点击“立即安装”，打开一个对话框询问你是否确认安装。确认。（如果 Firefox 此时表现异常并且未显示框，请重启并再试一次。）
- 5) 现在回到主题库，点击右侧第八个主题，bodhi_gtk_gold。在其安装页面，点击“立即安装”，然后在对话框中再次点击“安装”。
- 6) 再次回到主题库，点击下一个主题，`bodhi_gtk_kiwi`。安装这个。
- 7) 保持 Firefox 打开并最大化。点击工具栏上的“设置”小工具，并在设置窗口中点击“外观”，然后选择“应用程序主题”。打开“应用程序主题设置”对话框。现在最小化设置窗口，以便你可以看到尽可能多的 Firefox 窗口。
- 8) 在“主题设置”对话框中突出显示 *Kiwi* 并点击 *应用*。Firefox 窗口将采用不同的配色方案，并且它将具有不同的滚动条。
- 9) 现在尝试 E17-GTK 主题（这是我们上面在 (5) 中下载的“Gold”主题）。
- 10) 尝试其他的，挑选你喜欢的并且与你在第 2 章中应用的 E17 主题（Bodhi-Theme）相匹配的主题。我的最爱之一是 Country Oak。

如果你愿意，可以更改应用程序主题使用的图标。这里不会涵盖这一点。但你可以在 Bodhi 艺术 Wiki 上找到替代的图标集，并可以通过点击“应用程序主题设置”对话框中的 `loons` 选项卡（上面第 7 步）来应用它们。

## 5.9 配置文件

你对你首次安装 Bodhi Linux 时选择的“合成（Compositing）”配置文件进行了许多更改。所有这些设置都已存储在此配置文件中。它们包括你选择的主题、你设置的架子，以及你创建的任何边缘和按键绑定。如果你现在应用不同的配置文件，它不会有这些设置（尽管它会保留你的 *ibar* 内容和系统，以及你的 *收藏夹* 菜单）。

这并不意味着你丢失了你费力创建的所有那些设置。通过返回“合成”配置文件，你的桌面将返回到其先前状态，所有设置都就位。

在下一节中，你将对你的“合成”配置文件进行一些根本性的更改，你可能不想保留这些更改。那么，如何返回到你现在的配置文件呢？答案是将其保存为具有不同名称的新配置文件，然后返回到该新配置文件。所以现在让我们保存你的配置文件。

1) 转到“配置文件选择器”对话框。为此，使用“运行一切”，然后输入 *profile* 的前几个字母并按 *Enter*。

2) 在此对话框中点击 *添加*。然后输入你配置文件的名称 - 像 *Mycompositing* 这样的名称即可。

3) 点击 *确定*，然后点击 *关闭*。你的配置文件，包括其主题、壁纸、架子、绑定和其他设置，已被存储。

请注意，你*没有*使用你的新配置文件。“合成”配置文件仍然在



对话框。你此刻所做的任何更改都将存储在其中。这也意味着，如果你想修改你的新配置，必须首先在此处选择该配置。

**延伸阅读：** 请前往《Bodhi 开悟指南》中的“Profiles（配置）”章节。

## 5.10 E17 主题

你的电脑上已经预装了一些 E17 主题，并且 Bodhi Art Wiki 上还有更多主题可供下载。要查看这些主题，请打开 Bodhi 主页，点击“Resources（资源）”，然后选择“Art Wiki（艺术 Wiki）”，再选择“Enlightenment Themes（Enlightenment 主题）”。安装步骤与上述 GTK 主题的安装步骤相同。

Bodhi 软件库中还有更多主题（实际上约有 80 个），我建议你现在尝试其中一个：

- 1) 打开 Synaptic，在“Quick Filter（快速过滤）”中输入 'bodhi-theme'。会出现一长串列表，但只有标记为 2.0 版本或更高版本的才能与最新版的（v.2）Bodhi Linux 正常配合使用。不过，通过简单的调整，很容易让其他主题也能工作。
- 2) 找到 Crema 主题（即 *bodhi-theme-crema* - 如果找不到，请在快速过滤中输入名称）并安装它。这是一个较旧（0.5 版本）的主题，因此你需要对其进行调整。
- 3) 安装完成后，关闭 Synaptic，然后点击板上的“Settings（设置）”小部件以打开设置对话框。为下一步做准备，点击“Wallpaper（壁纸）”（在 Look 菜单中），点击“Use Theme Wallpaper（使用主题壁纸）”，然后点击确定（OK）。
- 4) 现在点击“Theme（主题）”（在 Look 菜单中）：主题选择器对话框将打开。你的电脑上存储的主题显示在这里，包括你刚刚下载的 A-crema 主题。高亮显示该主题，然后点击应用（Apply）。你的主题已更改，桌面也随之焕然一新。
- 5) 现在点击主题选择器对话框中的“Advanced（高级）”按钮。在左侧窗格（“Theme Categories（主题类别）”）中向下滚动并点击“widgets（小部件）”。由于 A-crema 的小部件部分无法与 Bodhi 的 2 版本兼容，因此我们需要使用其他主题的小部件。
- 6) 在“widgets”处于高亮状态时，在“Themes（主题）”面板中点击“Bodhi-Theme”，然后点击“Assign（分配）”按钮（位于左侧，主题类别面板下方）。如果我们愿意，也可以用同样的方式更改新主题的其他元素。
- 7) 让我们也更改“modules/everything”。（这是为了改善“Run Everything（运行一切）”对话框的外观。）在“Theme Categories（主题类别）”面板中高亮显示“modules/everything”，然后在“Themes（主题）”面板中高亮显示“A-Egypt”，最后点击“Assign”。
- 8) 点击“Apply（应用）”，然后点击关闭（Close），最后关闭设置对话框。
- 9) 你的桌面外观已经焕然一新。小部件看起来不同，如果你点击桌面打开菜单，你会发现它们看起来也不同于之前。（如果小部件上缺少一些图标，请重启 Enlightenment。）
- 10) 运行 Run Everything，然后输入 *application theme*（应用主题）的前几个字母以打开应用主题设置对话框。观察其外观，它在你应用 Crema 主题之前是完全一样的：这是因为你正在使用 Bodhi-Theme 的小部件。
- 11) 现在你需要选择一个与你的 Crema 主题相匹配的 GTK 主题。在你刚刚打开的对话框中，高亮显示 Country Oak 主题并点击确定（OK）。要检查该主题的外观，请打开一个应用程序 - Osmo 是一个不错的选择。
- 12) 你可能希望调整一些字体以适配你的新主题。若要这样做，请运行 Run Everything 并输入 *font*，然后在字体设置对话框中点击 Advanced（高级）。
    - a) 在字体类别窗格中高亮显示“Menu Item（菜单项）”，并确保选中“Enable Font Class（启用字体类别）”。
    - b) 选择“Nimbus Sans”作为字体，“Bold（粗体）”作为 *style（样式）*，“14 pixels（14 像素）”作为大小。
    - c) 高亮显示“Menu Title（菜单标题）”，勾选“Enable Font Class（启用字体类别）”，并进行相同的设置（Nimbus Sans, Bold, 14 pixels）。
    - d) 高亮显示“Title Bar（标题栏）”，选择“Ubuntu”作为字体，“Bold（粗体）”作为 *style（样式）*，“14 pixels（14 像素）”作为大小。点击应用（Apply）并观察对话框标题栏现在的外观，然后关闭该对话框。
- 13) 点击桌面以 *observe（观察）* 菜单现在的外观。
- 14) 你可能想要做的最后一个更改是针对新桌面上的时钟小部件。如果是数字时钟，现在将其改为模拟时钟，观察其外观，并视需要调整大小和移动位置。

所有这些更改都已存储在 Compositing 配置中。如果你希望恢复你的 Mycompositing 配置，请在配置选择器对话框中高亮显示它并点击 *Apply（应用）*。

## 5.11 重新开始

至此，我们已经完成了对 Enlightenment 桌面的探索。你当然还可以进行更多微调，但如果包含这些内容，本指南将变得过长。你最好花点时间巩固所学内容，通过从一个不同的配置开始并对其进行 *customizing（自定义）*，来创建属于你自己的个人桌面。请记住，你随时都可以通过打开配置选择器并应用 Compositing（返回带有 Crema 主题的配置）或 Mycompositing（返回带有 Bodhi-Theme 主题早期配置）来回到你之前设置好的配置。

要应用并自定义另一个配置：

- 1) 返回配置选择器对话框并选择 Laptop/Netbook 配置。（当然，你也可以从列表中选择不使用其他配置；这将为你提供不同的板（shelf）小部件选择。）会出现一个新的桌面，带有不同的板（位于顶部）和不同的主题。你之前的所有桌面设置都已消失 - 板、鼠标和按键绑定，所有东西都变了。不过，你的 iBar 已保留（它位于屏幕底部的弹出式板上），当然，你仍然拥有菜单系统，包括你的“Favorites（收藏夹）”菜单。
- 2) 在对这个配置进行任何更改之前，可能值得向板上添加“Run Everything”小部件：右键点击板的空白区域，选择 Contents（内容），然后在板内容对话框中添加该小部件。移除“Start（开始）”小部件也可能很有帮助，因为它使用的是与 Run Everything 相同的图标。
- 3) 现在通过 Run Everything 前往主题选择器对话框，并尝试那里可用的一个或两个主题。如果你不喜欢这些中的任何一个，请访问 Bodhi 网站上的 Art Wiki 并安装其中一个。当你找到喜欢的主题并应用后，开始自定义板。你希望有不同的板小部件，可能希望它在不同的位置，也可能希望将其缩小以适应内容。
- 4) 决定你想在桌面上放置什么小部件（如果有的话）。你可能想把时钟移过去，也可能想把“Places（位置）”小部件放在那里。
- 5) 应用适当的 GTK 主题，然后根据需要更改字体，例如让菜单更易读。应用不同的壁纸。
- 6) 创建边缘绑定和按键绑定，使操作更轻松。

当你完成对杰作的完美打磨后，回到你的 Mycompositing 配置，将建议的桌面与你的桌面进行比较。希望你会更喜欢你的！

# 6 维护和复制你的系统

最后这一章涵盖了你应该定期执行以刷新系统的任务。这些任务并不繁重，只需占用你几分钟的时间。

我们还讨论了如何在光盘或 U 盘上复制你的系统，以便它可以运行在其他计算机上，甚至可以安装在这些计算机上。

## 6.1 别名（Aliases）

这些维护任务中的一两个涉及在终端中输入一些冗长的命令，例如使用 `sudo apt-get dist-upgrade` 升级过时的软件。输入这些命令很痛苦，记住它们更是如此。如果可以直接输入简单的 `upgrade` 不是更好吗？通过设置别名，我们完全可以做到这一点。

别名存储在你主目录下的 .bashrc 文件中。若要创建别名，必须使用 Leafpad 打开此文件。

**提示：** 在设置别名之前，你应该先检查你提议的单词是否不是现有命令。通过在终端中输入该单词来检查；如果响应是 `command not found`，你就可以放心使用了。

- 1) 打开终端，然后输入 `gksudo leafpad .bashrc`。（注意文件名的开头有一个 `.`：这是一个隐藏文件。）
- 2) 在 Leafpad 中显示此文件后，向下滚动到接近文件底部，并在标题为 `# some more ls aliases` 的部分之后插入以下内容：

```
### My aliases
alias leaf='gksudo leafpad'
alias upgrade='sudo apt-get dist-upgrade'
alias upgrade='sudo apt-get dist-upgrade -y'
alias remove='sudo apt-get autoremove'
```

（注意第三个命令末尾的 `-y`。这免除了你需要输入 'y' 的需求，因为在运行 `dist-upgrade` 命令后，当你被询问是否要替换任何过时文件时确认。）

如果你在第四章中安装了 Get-i-Player，你可能希望向此列表添加以下别名：

```
alias get='get-i-player'
```

- 3) 保存文件，关闭 Leafpad，并关闭终端。

要激活这些别名，你需要重启计算机。现在就重启，因为你将在下一节中试用其中一些。





## 6.2 更新你的系统

你应该每个月左右更新一次系统，以保持其中的所有内容都是最新的。借助你在上面设置的别名，这非常容易：

- 1) 打开终端，并输入 `update`。你系统上的数据库将与存储库同步。
- 2) 输入 `upgrade`。你系统上任何过时的文件都将升级到最新版本。
- 3) 完成后，清除系统中积累的一些垃圾文件可能也是很有价值的。输入 `purge`，然后在提示符处按 'y'。

## 6.3 清理你的系统

每隔几个月，你应该彻底清理一次你的系统。可以使用一个名为 Bleachbit 的应用程序来完成。Bleachbit 不在你的系统中，但你可以通过 Synaptic 安装它。请现在这样做。

安装完成后，你的菜单系统的“系统工具”部分将添加两个条目：

- “Bleachbit”，用于清理用户文件。
- “Bleachbit as root”（以 root 身份运行 Bleachbit），用于清理系统文件。

- 1) 现在运行 Bleachbit（主菜单 > 应用程序 > 系统工具，或使用 Run Everything）。它的窗口打开，左侧列出了各种需要清理的文件类别。选择它们，但排除以下各项：
    - 深度扫描选项（这些速度较慢）；
    - 密码（在 Firefox 部分中）；
    - 系统部分中的释放磁盘空间、本地化和内存（前两者速度较慢，且内存是实验性功能）。
- 2) 点击预览，会出现一个（很长的）将被删除的文件列表。
- 3) 点击清理，片刻后任务即完成。

“Bleachbit as root” 的使用方式相同。

## 6.4 使用 Remastersys 进行备份

当然，你应该将重要的文档和照片备份到外部存储设备或 Dropbox 上。Nautilus 具有双窗格和“复制到另一窗格”功能，这使得操作变得容易。

然而，备份你的整个系统是另一回事，而做到这一点的一种方法是使用一个名为 Remastersys 的程序。这允许你创建你系统的映像（ISO 文件），包括你所有的自定义设置以及（如果你愿意）你的文档、照片和其他数据文件，然后你可以将其安装到光盘（可刻录 DVD）或 USB 内存棒（U 盘）上。使用此 DVD 或 USB 棒，你可以在任何计算机上运行，并在必要时安装你的系统。

Remastersys 已经存在于你的系统中，可以从终端运行，但如果你为它设置一个个人应用程序启动器，未来的操作会更简单。

- 1) 运行 Run Everything 并输入 *personal* 的前四个字母。个人应用程序启动器对话框将打开。
- 2) 点击添加以添加个人启动器；然后在桌面条目编辑器中，在名称字段中输入 **Remastersys**，在 *应用程序* 字段中输入 *remastersys-gtk*。
- 3) 如果你想为启动器设置图标，点击图标选项卡，然后点击图标框并导航到：/usr/share/icons/MaXo-ReMix/apps，然后在列表中滚动寻找合适的图标。点击确定。
- 4) 在常规选项卡中，在通用名称字段中输入 REMASTERSYS，在类别中在 SYSTEM。
- 5) 在选项选项卡中，确保选中了“在菜单中显示”。其他两个选项不应选中。
- 6) 点击应用；然后关闭。Remastersys 将出现在系统菜单中，位于系统工具下方（如果没有，请重启 Enlightenment）。

在使用 REMASTERSYS 备份你的系统之前，你应该首先运行 BLEACHBIT 和 BLEACHBIT AS ROOT 以删除不必要的文件。你应该包括“释放磁盘空间”选项，以使映像尽可能紧凑。（这将花费很长时间来执行，因为它涉及在硬盘上移动文件。）

使用 REMASTERSYS 创建系统映像的说明如下：

- 1) 关闭所有打开的应用程序，运行 Remastersys，并在其对话框中选择设置选项卡。在这里，你可以输入你希望从映像中排除的任何文件或目录。例如，如果你想排除你的电影和图片文件夹，你会输入 `/home/bobhj32/Movies:/home/bobhj32/Pictures`（将 **bobhj32** 替换为你的用户名）。
- 2) 点击操作选项卡，关闭所有打开的窗口（除了 Remastersys 窗口），然后点击备份。Remastersys 将开始工作，创建你系统的 ISO 映像，这个过程大约需要一个小时。

ISO 文件将位于 `/home/remastersys/remastersys` 目录中。要查看它，运行 Nautilus，点击工具栏左侧的框（在“主目录”左侧的框，框上标有一个小的左指向箭头），点击 ‘home’（不是 ‘Home’），然后导航到 remastersys > remastersys。（换句话说，ISO 位于 /home/remastersys/remastersys 文件夹中。）

如果你排除了可能已添加到系统上的个人数据文件，如照片、音乐或其他文档，此文件的大小可能约为 1 GB（吉字节）。（这包括你添加到系统上的所有应用程序。）这将导致安装大小明显超过 2 GB。

你现在可以使用 Brasero（你可以在菜单系统的“声音与视频”部分找到它）将此映像安装到可刻录 DVD 上。或者，你可以将其安装到 USB 内存棒上——这可能是你的最佳选择，因为 USB 棒可以容纳比 DVD 大得多的映像，并且你可以更改或添加其中存储的文件。（不过请注意，较旧的计算机可能无法从 USB 棒启动——请参阅下面第 6.6 节。）

## 6.5 UNETBOOTIN

要将 ISO 映像安装到 USB 棒上，你需要一个名为 Unetbootin 的应用程序。它不在你的系统中，因此请运行 Synaptic 来安装它。与 Remastersys 一样，Unetbootin 将出现在菜单系统的“系统工具”部分中。

- 1) 在运行之前，你应该将 USB 棒插入 USB 端口，并挂载它。（要挂载它，只需点击 Places 小部件中的图标，使 Nautilus 打开它，然后关闭 Nautilus。或者，以正常方式打开 Nautilus，并点击其左窗格中的 USB 棒。）
- 2) 运行 Unetbootin，并在其对话框中选择 DiskImage 选项（在左下角）。然后浏览到你上一节保存的 ISO——浏览按钮在右侧。当浏览对话框打开时，点击顶部的向上箭头，双击列表中的 ‘home’，然后是 ‘remastersys’，再次是 ‘remastersys’。
- 3) 如果你认为你之后想向即将创建的 USB 系统添加文件，那么你必须为此分配空间。该数量受你 USB 棒容量的限制。对于 4 GB 的 USB 棒，你最好限制在约 1500 MB 左右。
- 4) 点击确定，你系统的映像将被安装到你的 USB 棒上。这个过程将花费几分钟。

## 6.6 从 USB 驱动器运行 Bodhi Linux

你可以将在 USB 棒上安装的系统副本在任何能够从 USB 驱动器启动的计算机上运行。要在你的计算机上尝试这样做：

- 1) 关机。
- 2) 确保 USB 棒已插入 USB 端口。
- 3) 开机，并在计算机启动时按住 F12 键。应该会出现一个启动菜单。（假设你的计算机使用 F12 来执行此操作——在计算机启动时，屏幕上应出现可用于启动的按键列表。）
- 4) 其中一个选项应该是从 USB 驱动器启动。如果没有该选项，则无法从该驱动器启动。在这种情况下，你必须使用 Brasero 将 ISO 映像写入 **DVD** 并从该 DVD 启动。
    - *提示：* 你可以通过在 USB 端口插入 *任何* USB 棒并执行上述步骤，在创建可安装 USB 棒之前检查你的计算机是否有此选项。
- 5) 如果存在 USB 选项，请选择‘从 Live System 启动’。你的计算机将运行你的 Bodhi 系统，几分钟后你的桌面将出现。
- 6) 架子上的一些图标可能缺失。这似乎总是在你第一次使用 USB 安装时发生。解决方法是*重启 Enlightenment*（主菜单 > Enlightenment > 重启），这将修复问题。
- 7) 当从 USB 驱动器或光盘运行 Bodhi 时，它不会自动连接到 Internet。要连接，运行 Run Everything 并输入 *network* 的前几个字母。按 Enter，*network* 小部件将运行。点击其图标（底部架子），从列表中选择你的网络，并输入密码。
- 8) 现在你可以像从硬盘*运行*系统一样完全相同地使用该系统，包括能够向其保存文件（假设你在之前的练习中为此分配了空间）。
- 9) 你还可以轻松访问计算机硬盘上的文件，使用桌面上的 Places 小部件（假设你在之前的练习中将该小部件放在了那里）。你会注意到此小部件上出现多个驱动器，包括硬盘。点击硬盘图标以在 Nautilus 中显示其内容。
- 10) 如果你愿意，你可以使用此 USB 棒将你的 Bodhi 系统安装到计算机的硬盘上。如果你的计算机硬盘已损坏，或者你想将你的 Bodhi 系统安装到另一台计算机上，你可能希望这样做。为此，运行 Run Everything 并输入 *Install RELEASE* 的前几个字母。如果你的 USB 棒上存在 Install RELEASE 小部件，其图标将出现在对话框中，你可以按 Enter 运行它。如果你喜欢，可以现在尝试——通过选择第一个对话框中的 *Quit* 来中止安装过程。
    - *注意：* 如果 *Install RELEASE* 不在你的 USB 棒上，你可以从 `http://packages.bodhinux.com/bodhi/tools/testing/ubuntuquirky` 下载它。选择名为 `ubuntuquirky-frontend-gtk_3.12.17-1386.deb` 的下载。由于这是一个 `.deb` 文件，你必须使用第 4.8 节中描述的 *eDeb* 实用工具来安装它。
- 11) 要关机，请按 *Win - End*，就像平常一样——你之前设置的所有快捷方式都可以使用。




## 6.7 Bodhi Linux 的未来版本

与 Windows 类似，诸如 Ubuntu 和 Bodhi Linux 等发行版每隔几年就会发布一个新版本。下一个主要的 Ubuntu 版本计划在 2014 年 4 月发布，而新的 Bodhi 版本（3.0 版）将在其发布后的一到两个月内推出。

您将无法将现有的 Bodhi 安装升级到版本 3，而是需要进行全新安装——也就是说，您需要下载新的光盘映像，将其安装到计算机上，并重复本指南中执行的所有步骤。好消息是，这件事并不紧迫：Bodhi 版本 2 将在之后继续获得支持几年。

当您确实决定切换时，显然必须先备份所有重要的数据文件，因为计算机上的硬盘将被重新格式化。此外，正如上文所述，将您的整个系统备份到外部硬盘或（大容量）U 盘上也是个好主意，以防您需要出于任何原因再次运行它。

在那之后，Bodhi 发行版的小型修订版大约每年发布三次，但当您执行 `sudo apt-get dist-upgrade` 时，这些修订版将自动整合到您的安装中。

## 本 Bodhi Linux 安装版本的快速入门指南

这台计算机上的所有应用程序都可以通过菜单系统访问，您可以通过将鼠标指向桌面的任何暴露区域并单击左键来打开它。

此安装程序包含若干快捷方式，以简化生活：

- 常用的应用程序（如网络浏览器）位于左侧的架子（shelf）上。只需单击相应的图标即可运行这些应用程序。
- 其他收藏夹应用程序可以在“收藏夹”菜单中找到，该菜单通过将鼠标指向桌面的空白区域并单击右键来访问。
- 键盘快捷键，例如 Win + End 用于关闭计算机（即按住 Windows 键并轻按 End 键）。
- 用于操作窗口的鼠标动作：
  - 单击屏幕右上角以关闭当前（聚焦）窗口。
  - 单击屏幕顶边缘以最大化窗口（再次单击以撤销此操作）。
  - 单击屏幕底边缘以最小化窗口。
  - 单击左上角以将窗口设置为全屏（再次单击以撤销）。
  - 单击屏幕左边缘以向左最大化窗口（再次单击以撤销）。
  - 单击屏幕右边缘以向右最大化窗口（再次单击以撤销）。
  - 单击屏幕右下角以显示桌面。

此安装程序包含 Nautilus 文件管理器。其图标位于架子顶部。当 Nautilus 打开时，您可以按 F3 键显示第二面板；这简化了从一个位置复制或移动文件到另一个位置的任务（右键单击文件并选择例如“复制到另一面板”）。Nautilus 还使访问连接到您的网络的其他计算机变得轻松——在其左侧面板中选择“浏览网络”。

安装在此系统上的应用程序包括 Firefox 网络浏览器、Thunderbird 邮件客户端、LibreOffice 办公套件（Microsoft Office 的 Linux 替代方案）、Osmo 个人信息管理器（日历、日记、笔记、联系人、待办事项列表）、VLC 视频播放器、Audacious 音乐播放器、音频录音机、用于照片的 Mirage，以及 Skype 和 Dropbox。您可以通过访问 Bodhi Linux 网站上的 AppCenter（[http://appcenter.bodhilinux.com/](http://appcenter.bodhilinux.com/)）添加其他应用程序。如果您想要的软件包没有在这里列出，请使用 Synaptic 包管理器（在收藏夹菜单中）进行搜索。

终端是架子上第二个图标。使用它输入任何命令；特别是用于保持您的系统及其软件更新的命令。为了简化操作，这些命令在此系统上已简化，因此您只需：

1. 输入 `update` 以将您的系统文件索引与在线数据库同步（对于此命令和下一个命令有效，您必须已连接到互联网）。
2. 然后输入 `upgrade` 以替换任何过时的系统文件。

要了解有关 Bodhi Linux 系统的更多信息，包括如何访问互联网，请单击桌面任何位置以打开菜单系统，然后突出显示“Bodhi Linux”并选择“快速入门”。
