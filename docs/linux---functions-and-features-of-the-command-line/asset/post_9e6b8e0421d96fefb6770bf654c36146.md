## Editing

So we have taken some time to open up the file that you want to use with Vim, and now it is time to learn how to make some modifications to the file that you want. The first thing you should notice when you try to edit a file is when you use the arrow keys to move the cursor and to type in order to edit the file. This may seem frustrating to the person who is not used to this kind of system, but all you need to do is enter Insert mode.

To get to Insert mode, you just need to type the letter "i". Once this is done, you can make all the modifications that you want to the file. Once you feel that the modifications are all done, you will need to get out of Insert mode. Simply hit the ESC key.

Most of the documents that you want to change are really long. If you want to make changes, you will be able to use commands to make this easier. First, you need to check that you are out of Insert mode. Now bring up the command to write out the code. This command is to look at all the places that you want to change until you are at the end of the document. This will help you to get the information that you are looking for.

Some of who are working in this language find that it is best to do this differently. Instead of going and writing the code that was above, you would write out `:filename`. This one is good because it shows that you want to find anything that has a special character in front of it. Now, with the forward slash that we are using in this syntax, you will notice that the cursor goes from your current location and then down.

But what happens if you were searching through the document and you already reach the bottom, and you still can't find what you want? It isn't going to do you much good to use that syntax. A better solution is to use the command:

```
/:filename
```

With this one, the cursor is going to go from your current location and head up the document so that you are able to go back and forth with this one, looking for different keywords that you would like to find no matter where your current spot is.

## Exiting and Saving Your Changes

Once you are done going through and making the edits that you would like, it is time to open a file along with saving the files that you are using within the Vim system. We took some time to open from the command prompt, now we are going to discuss how you can open up more files when you are already inside of Vim.

So, when you need to open up a file when you are inside the Vim program, you will just need to switch to another file by typing in the following command:

```
:filename
```

Of course you need to make sure that you are not in Insert mode when you go through this, else the Vim program is going to just type that new command into the document, and it won't be seen as a command to open up a file. Just sure to get out of the Insert mode and then type in the command to set up a new file for you. This is all that you will need to do for more than one file when you are inside the Vim program.

Now it is time to learn how to get out of the file. If you open up a file and find that it is not the one you would like to work with, or you see that the changes are already done inside this document, you may want to close out of the file. All that you would need to do to close the document without making any changes is to type in:

```
:q
```

Type this in and then press Enter to get the system to execute. In addition when working on closing the program when you would like, there are also times when the Vim program stops working or won't work with the quit command it should, and you still want to get out of the program. For these times, you may want to force the Vim program close down. In order to force the program down, you will just need to put in the following syntax:

```
:q!
```

This is the command that you should work any time that you want to get out of the program, and it is not allowing you to do the things that you would like. Keep in mind that if you use these options, none of your work is going to be saved when you are editing unless you had gone through and saved them before. You should always make sure that you save the information that you are working before continuing or you will lose all the work.

So, at some times you are going to want to make changes to the file and then you want it save for you so that the changes are there and you won't lose them. In order to save changes to the documents like you want, you will just need to type in the following command:

```
:wq
```

This is first going to save the changes that you are making to the file and the second part is going to close down the program that you are using. This makes it the perfect choice to use when you are just doing a few changes and then want to get out of your program when you are done.

In some cases, you may want to make some changes to the file but you don't want to save them. This is when you want to find out how to use the forward slash. This is when you want to find how to save the file, you will just need to type out the following command:

