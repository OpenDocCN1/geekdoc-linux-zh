The syntax that you will be able to use in order to send the computer out to find the program that you want to use includes:

```
$ sudo apt-get install <name of program>
```

Just hit enter and the computer will go out and find whichever program that you are looking at the time. The computer can then download this for you, and you can do this step as many times as you would like in order to get the programs onto your computer as you would like.

Now you have used the program for some time and you decide that you no longer want to use it. Perhaps the program is not working the way that you would like, or you are done with using it and don't want to take up too much space on your computer. You will then be able to take the program off your computer by using the simple syntax

```
$ sudo apt-get remove <name of program>
```

When you type this into your program, you will find that whatever you want to get rid of is going to be uninstalled. You will need to give it some time to get off the computer, but this simple command is going to tell the computer that you want to get rid of that particular app and it will slowly start to take it away for you.
