## 显示和列出你的文件

一旦你进入了想要使用的目录，你就应该花些时间确定该目录里有什么。幸运的是，这是一个你能够完成的简单过程。为了列出 Linux 系统中的文件，你只需要使用以下命令：

```bash
$ ls
```

在列出文件时，你有几个可以使用的参数，它们将取决于你想要系统做什么。例如，如果你执行了以下操作： 

```bash
$ ls -l
```

你将能够获得系统上列出的所有文件夹和文件。除了列出这些内容外，你还可以看到所有这些文件夹和文件的权限、最后修改的日期、这些项目的所属组所有权，以及在你的系统中谁拥有这些项目的个人所有权。这有时会变成一个非常大的文件，因为它包含了很多信息。如果你想学习某些信息，而不想列出这么多内容并占用这么多空间，你可以使用这种语法：

```bash
$ ls -m
```

使用这种语法，你将获得以块形式输入的所有内容，而不是使用之前的语法显示的冗长列表。它将以更整洁的格式将它们放在一起，比之前占用更空间，但仍然会为你提供了解文件夹所需的信息。

现在，你可以用此做的另一件事是当你想要编辑其中一个文件，但又难以确定它位于何处。Linux 确实有选项可以帮助你，帮助那些不知道想要处理的文件位于哪里的人。如果你想搜索该文件以便找到它所在的目录，你只需要输入以下语法：

```bash
$ sudo find -iname <file/folder>
```

在 Linux 上工作时，使用 `-iname` 函数真的非常重要。在大多数情况下，Linux 系统对你使用的大小写非常敏感。你必须区分你使用的大写字母和小写字母。但当你使用 `-iname` 函数时，你使用的大小写就没了。

这可以帮助你遍历所有可用目录，无论它们内部使用的是大写还是小写字母。如果你不确定要搜索的文件名称，这将为你节省大量的时间和麻烦。

此外，在使用此选项时，你需要确保在该语法中使用了 `sudo` 命令。如果你不把它放进去，你甚至看不到命令失败的消息，它只会保持一个空白屏幕，你可以将其解释为系统根本没有该文件。确保你添加了 `sudo` 命令，以便你能够找到文件是否存在。

现在，会有某些时候你想寻找一个文件，但不确定它叫什么，并且你想要查找你想要的文件的某些变体。假设你想调出以 `.conf` 为后缀的文件；你可以输入以下语法来使其工作。

```bash
$ sudo find -iname *.conf
```

当使用此命令时，你能够查找任何以 `.conf` 部分开头或以 `.conf` 部分结尾的文件夹或文件，所有这些都会显示出来，让你查看所有选项。现在，假设你需要知道文件名对应的后缀，而你已经知道了文件名。对于这些文件，你需要输入以下代码：

```bash
$ sudo find -name php*
```

当你使用此命令时，你能够查找所有以 `php` 开头的文件夹和文件，无论它们以什么结尾。当然，你可以根据你使用的名称在开头更改你使用的名称，但这让你对它的整个工作原理有一个良好的了解。

## 你可以对文件所做的其他事情

到为止，我们已经讨论了在 Linux 系统中进行导航时可以做的几件事。现在，我们将讨论一些其他事情，包括重命名文件、复制、移动、删除，甚至创建你想要使用的文件。我们首先讨论这些中的第一个：创建新文件夹。这非常容易，因为你只需要在其中添加以下语法：

```bash
$ sudo mkdir <name of directory/folder>
```

关于这一点需要记住的一点是，如果不包含目录的完整路径，命令将在你当前所在的目录中创建该目录。如果你想去其他地方，你需要确保包含完整的目录路径以获取它。

列表中的下一项是如何删除你正在操作的一些文件或文件夹。为了删除系统上的文件，你需要使用以下语法：

```bash
$ sudo rm <file or folder name>
```

`rm` 关键字代表 remove（删除）。（注：原文此处存在大量重复的 "rm keyword is going to be for remove"，译文已根据要求去重并保留核心含义）。
