# 前言

Webmin 是一个由 Jamie Cameron 用 Perl 编程语言编写的基于 Web 的图形化 UNIX 系统管理工具，其设计目标是轻量、功能齐全且易于扩展。截至本书撰写时，Webmin 已被翻译成 20 多种语言和方言，并被众多硬件和操作系统厂商采纳为其默认的系统管理工具。它具有极强的可移植性，支持超过 35 种不同的类 UNIX 操作系统和 Linux 发行版。而且由于其开放且文档完善的 API，很容易扩展以支持新功能和选项。

Webmin 同时也是一个快速且易于使用的通用 UNIX 系统管理工具。本文件旨在向您介绍使用 Webmin 维护 UNIX 系统时需要了解的许多概念。虽然单卷书籍无法涵盖 UNIX 系统管理的各个方面，但我们确实努力在提供对许多重要任务的扎实介绍的同时，也提供对典型 UNIX 服务器及其各部分的近乎全面的参考。我希望仅凭这本书、一份 Webmin 副本以及随服务器提供的文档，您就能配置系统以提供最流行的服务、制定合理的<|message|>
