# Figure 13-3: Network Interfaces

The Interfaces Active Now section is a list of interfaces that are currently up. The same data could be gathered by running ifconfig -a from the command line. The section below that, Interfaces Activated at Boot Time, is the list of interfaces that are configured permanently on the system. These can optionally be brought up on boot.

To edit an interface, either Active or Boot, simply click the name of the interface. You will be presented with a page similar to Figure 13-4.

# Figure 13-4: Editing a bootup interface

Here it is possible to specify the IP address for the system or to choose DHCP or BOOTP to auto-configure the IP. Also editable from this page are Netmask and Broadcast settings.
