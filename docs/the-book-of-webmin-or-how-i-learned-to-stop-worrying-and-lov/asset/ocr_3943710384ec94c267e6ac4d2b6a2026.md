# NETWORKING CONFIGURATION

![](bbox=[0.18, 0.46, 0.32, 0.64])

The fourth category tab in Webmin is for **Networking**-related configuration. Specifically, this is where you’ll find the modules to configure netbr xinetd, iptables, NFS exports, NIS client and server and network interfaces. The Networking category was introduced in Webmin version 1.0, so if for some reason you are using an earlier Webmin revision (upgrade already; it’s free!), these modules will be found under other category tabs.
