# Formatting and Creating a Filesystem on a Floppy Disk

**Scenario:**
A user wanted to transfer files from one system to another, without getting into the hassle of setting up network shares and sending the data over the network. You decide to show the user how to format a floppy disk to transfer the files.

| What You Do | How You Do It |
| :--- | :--- |
| **1.** Determine the size of the floppy disk and the correct `fdformat` command to use. | a. Enter `man fdformat`<br>b. Find the `fd0h1440` entry. |
| **2.** Format the floppy disk. | a. Insert a blank floppy disk in the floppy disk drive.<br>b. Enter `fdformat /media/floppy` to format the floppy disk. |
| **3.** Create a filesystem on the floppy disk. | a. Enter `mkfs /media/floppy`<br>b. Enter `mount /media/floppy` to mount the floppy disk.<br>c. Enter `ls /media/floppy` to verify that the filesystem was created.<br>d. Verify that there is a lost+found directory listed. |
