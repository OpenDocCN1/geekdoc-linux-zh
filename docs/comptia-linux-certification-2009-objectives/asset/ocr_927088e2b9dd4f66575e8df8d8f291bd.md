3. Create users who can access your website.

a. Navigate to the /var/www/html directory.

b. Enter

**httpasswd -mc**
**/var/www/html/.htpasswd webuser**

to create the webuser user.

c. Enter **@webuser1** as the password.

d. When prompted, retype **@webuser1**

e. Observe that the password for webuser is added.

f. Enter **chgrp apache .htpasswd** to specify that apache is the group owner of the password file.

g. Enter **chmod g+r .htpasswd** to provide group read permission for the password file.
