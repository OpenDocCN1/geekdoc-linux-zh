# mysqld

The *mysqld* or MySQL daemon is also the MySQL server. It allows you to manage the MySQL server service. After installing MySQL, you need to manually start this daemon. You can start, stop, restart, or view the status of the MySQL server. This service needs to be running for clients to connect to and use MySQL.

![](bbox=[0.27, 0.19, 0.41, 0.21])

```
<pre>[root@localhost ~]# service mysqld startStarting MySQL[ OK ][root@localhost ~]#</pre>
```

*Figure 4-24: Starting the mysqld service.*

# MySQL Commands

Clients use MySQL commands to interact with the MySQL server.

<table><thead><tr><th>MySQL Command</th><th>Allows You To</th></tr></thead><tbody><tr><td>select</td><td>Retrieve all records or records that match a specific criteria.</td></tr><tr><td>create</td><td>Create objects, such as a database, a table, or indexes, inside an RDBMS.</td></tr><tr><td>alter</td><td>Modify the existing table or database.</td></tr><tr><td>update</td><td>Update the values in a table.</td></tr><tr><td>use</td><td>Make a particular database as the current database so that you can modify the objects of that database.</td></tr><tr><td>show</td><td>Display the tables that are available in the current database.</td></tr><tr><td>insert</td><td>Enter values into a row or record of the table.</td></tr><tr><td>describe</td><td>Display the structure of the table.</td></tr></tbody></table>
