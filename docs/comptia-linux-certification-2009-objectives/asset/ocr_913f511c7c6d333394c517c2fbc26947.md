+   5. Print install.log file on the remote printer.
a. On the desktop, double-click the **root's Home** folder.
b. In the **root - File Browser** window, double-click the install.log file.
c. Choose **File→Print** to print the file.
d. In the **Printer** dialog box, observe that the remote printer, printer@srvA, is selected. Click **Print**.
e. Switch to srvA.
f. On the task bar, click the **Web Browser** icon to launch the Firefox web browser.
g. In the address bar, select the existing address and enter http://localhost:631/jobs to view the jobs in the print queue.
h. Click **Show Completed Jobs**.
i. Observe that the install.log file is displayed in the print queue.
j. Close the **Jobs CUPS 1.3.7 - Mozilla Firefox** window and the terminal window.
k. Switch to srvB.
l. Close the **gedit** window and the **File Browser** window.
