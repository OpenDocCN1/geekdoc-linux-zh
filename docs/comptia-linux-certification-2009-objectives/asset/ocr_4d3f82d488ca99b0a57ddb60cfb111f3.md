# How You Do It

1. Schedule a cron job to email a reminder everyday at a specified time.

+   a. Enter **usradd user1** to create the **user1** user account.

+   b. Enter **passwd user1** to set the password for **user1**.

+   c. At the **New UNIX password** prompt, enter **mypy\$Sword**

+   d. At the **Retype new UNIX password** prompt, enter **mypy\$Sword**

+   e. Enter **date** to view the system time.

+   f. Enter **crontab -u user1 -e** to specify a cron job for **user1**.

+   g. Observe that the text editor opens a temporary file automatically.

+   h. Press **I** to switch to the insert mode.

+   i. Type **\#\#\# \*\*\* /bin/echo-> "Please fill out your time sheet"** to schedule the cron job.

+   j. Press **Esc** to switch to the command mode.

+   k. Save and close the file.

+   l. Enter **logout**

2. Check whether **user1** received the reminder for the scheduled job.

+   a. After the specified time, log in as **user1** in the CLI.

+   b. Enter **mail** to open the mailbox.

+   c. Enter **1** to read the contents of the first email message.

+   d. Observe that the mail contains a reminder to fill in the timecard.

+   e. Enter **d** to delete the email message.

+   f. Enter **q** to quit the mail service.

+   g. Enter **logout** to log out of the **user1** account.
