# Syntax

The syntax of the ScriptAlias directive is: `ScriptAlias /cgi-bin//Directory path/cgi-bin/`, where the resource request beginning with `/cgi-bin/` will be retrieved from the CGI directory.

# Execute CGI From Non-ScriptAliased Directories

In the httpd.conf file specify the following settings:

+   1. Activate the cgi-script handler with the AddHandler directive.
2. In the Directory statement, specify ExecCGI in the Options directive.

# How to Implement Apache Access Control

# Procedure Reference: Configure Virtual Hosts

To configure virtual hosts:

+   1. Log in as root.
2. Using the vi editor, open the /etc/httpd/conf/httpd.conf file.
3. If necessary, enter NameVirtualHost {IP address}:port number to specify the IP address of the web server.
4. Add a VirtualHost directive for each virtual host you want to define.
   1. Begin the VirtualHost declaration with the IP address or the hostname. The lesser than (<) and greater than (>) symbols at the beginning and end of the VirtualHost keyword are mandatory.
   2. Specify the email address of the administrator in the ServerAdmin directive.
   3. Specify the IP address of the server in the ServerName parameter.
   4. Specify the directory where the HTML files will be stored using the DocumentRoot parameter.
   5. Specify the file name with its absolute or relative path where the errors will be logged using the ErrorLog parameter.
   6. Specify the access log file name with its absolute or relative path using the CustomLog parameter.
   7. Complete the VirtualHost declaration.

```
<VirtualHost {IP address/hostname}:port number>
 ServerAdmin {User name}@{Domain name}
 DocumentRoot {DocumentRoot location}
 ServerName {IP address/FQDN}
 ErrorLog (Path of the error log file)
 CustomLog (Path of the access log file) (Log level)
 </VirtualHost>
```

+   5. Save and close the file.
6. Enter service httpd configtest to check whether the httpd.conf file is configured correctly.
7. Enter service httpd restart to restart the httpd service.
