
# tail 命令

`tail` 命令用于从文件中检索数据。默认情况下，它显示文件的最后十行。`tail` 命令具有多种选项。下表列出了其中一些常用选项。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_462_0.png)

| 选项 | 功能 |
| :--- | :--- |
| `--retry` | 强制 `tail` 命令打开无法打开的文件。 |
| `-c` _(总字节数)_ | 从文件末尾打印指定数量的字节。 |
| `-f` | 如果对文件进行了更改，则更新 `tail` 命令的输出。 |

![](img/477ccb2f05b6ba1b2d563ea74f18c197_462_1.png)

## 语法

`tail` 命令的语法为 `tail [选项] {文件名}`。

# awk 命令

`awk` 命令是一个执行模式匹配的命令。GNU 版本的 `awk` 被称为 `gawk`。`awk` 关键字后面跟随模式、要执行的操作以及文件名。要执行的操作在大括号内给出。模式和要执行的操作应使用单引号括起来。如果未指定模式，则对所有输入数据执行操作；然而，如果未指定操作，则打印整行。可以从命令行或在 `awk` 脚本文件中执行 `awk` 命令。

## 语法

`awk` 命令的语法为 `awk [选项] {文件}`。

## 模式

在 `awk` 脚本中，您可以提供模式以及代码块。如果模式匹配输入文件中的任何一行，脚本中的代码块将被执行。下表列出了使用的模式类型。

| 模式 | 描述 |
| :------------------- | :--------------------------------------------------- |
| `/regular_expression/` | 检索以 "a"、"b" 或 "c" 开头的所有记录。 |
| | 示例：`/abc/` |
| `relational_expression` | 检索第一个字段包含值 "abc" 的所有记录。 |
| | 示例：`$1 == "abc"` |
| `pattern_1 && pattern_2` | 检索第一个字段包含值 "abc" 且第二个字段包含值 "01" 的所有记录。 |
| | 示例：`($1 == "abc") && ($2 == "01")` |
| `pattern_1 \|\| pattern_2` | 检索第一个字段包含值 "abc" 的记录，以及第二个字段包含值 "01" 的记录。 |
| | 示例：`($1 == "abc") \|\| ($2 == "01")` |
| `pattern_1 ? pattern_2 : pattern_3` | 如果记录的第一个字段包含值 "10"，则测试第五个字段的值。如果第五个记录包含值 "20"，则打印该记录。如果记录的第一个字段不包含值 "10"，则评估记录的第九个字段。如果第九个记录包含值 "30"，则打印该记录。 |
| | 示例：`$1 == "10" ? $5 == "20" : $9 == "30"` |
| `pattern_1, pattern_2` | 打印一段记录范围，从第一个字段包含值 "01" 的记录开始。`awk` 命令会继续打印记录，直到它找到一个第一个字段包含值 "02" 的记录为止。 |
| | 示例：`$1 == "01", $1 == "02"` |

# sed 命令

`sed` 命令是一个命令行程序，可根据命令行参数修改日志文件或文本文件。`sed` 命令可用于全局搜索和替换操作。它具有多种选项。下表给出了一些常见的 `sed` 命令选项及其用途。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_464_0.png)

| 选项 | 用途 |
| --- | --- |
| `d` | 删除指定的行。 |
| `-n, p` | 仅打印修改后的行。 |
| `s` | 替换行中的第一次出现。 |
| `s,g` | 全局替换行中每次出现的内容。 |

## 语法

`sed` 命令的一般语法为 `sed '地址/模式/操作' 文件名`。如果有地址，它跟在命令名称之后。用户形成的模式接下来是找到匹配时要执行的操作。最后一个参数是输入文件的名称。地址、模式和操作参数用单引号括起来。

## 如何监控系统日志

### 程序参考：配置系统日志

配置系统日志：

1. 以 root 身份登录。
2. 输入 `gedit /etc/syslog.conf` 以打开配置文件。
3. 输入 `Facility.Level of severity /({存储日志消息的文件位置})` 以设置要在指定文件中记录的类型和严重程度级别。
4. 保存并关闭文件。
5. 输入 `service syslog restart` 以重启系统日志服务并应用更改。

配置 syslogd 将日志输出发送到中央日志服务器：

1. 以 root 身份登录。
2. 输入 `gedit /etc/syslog.conf` 以打开系统日志配置文件。
3. 输入 `({Facility}) ({Level of severity}) @({日志服务器的 IP 或 FQDN})` 以将日志输出发送到远程日志服务器。
4. 保存并关闭文件。
5. 输入 `service syslog restart` 以重启系统日志服务并应用更改。

### 程序参考：搜索和替换字符串

搜索和替换字符串：

1. 在 CLI 中以用户身份登录。
2. 搜索和替换字符串。
   - 输入 `sed 's/{旧字符串}/{新字符串}/g' {文件名}` 以将旧字符串替换为新字符串，即使在一行中找到多个旧字符串的实例。
   - 输入 `sed 's/{旧字符串}/{新字符串}' {文件名}` 以仅将旧字符串的第一次出现替换为新字符串，即使在一行中找到多个旧字符串的实例。

### 程序参考：手动从日志文件中提取信息

手动从日志文件中提取信息：

1. 输入 `ls /var/log` 以查看当前系统日志文件列表。
2. 使用合适的命令从日志文件中提取信息。
   - 输入 `awk '{print $(列名) $(列名)}' 文件名)` 以打印所选文件中特定列的输出。
   - 输入 `grep -x "(d)"` 以手动扫描日志文件并提取匹配特定活动的值。

# 活动 11-2
## 配置系统日志设置

**开始前：**
1. 您已在 CLI 中以 root 身份登录。
2. 切换到 GUI。

**场景：**
作为系统管理员，您正在对网络系统进行例行维护检查。您发现日志中有一些错误，因为它们未正确输入。您希望日志中仅显示警告和警报。因此，您决定配置 syslog 的设置。

| 你要做的 | 怎么做 |
| :--- | :--- |
| 1. 打开 /etc/syslog.conf 文件。 | a. 选择 **应用程序**→**实用程序**→**终端** 以打开终端窗口。 |
| | b. 输入 `gedit /etc/syslog.conf` 以在 gedit 程序中打开 syslog.conf 文件。 |
| | c. 按 **Ctrl+End** 以移动到文件的最后一行。 |
| 2. 配置 syslog 设置。 | a. 输入 `mail 4 /var/log/test.log` 以设置要为邮件消息记录的错误严重程度。 |
| | b. 选择 **文件**→**保存** 以保存文件。 |
| | c. 选择 **文件**→**退出** 以关闭文件并退出 `gedit` 编辑器。 |
| | d. 在终端窗口中，输入 `service syslog restart` 以重启 syslog 服务。 |
| | e. 输入 `clear` 以清除终端窗口。 |

# 活动 11-3
## 配置 Syslogd

**开始前：**
1. 您已在 GUI 中以 root 身份登录。
2. 显示终端窗口。

**场景：**
作为系统管理员，您希望您的系统作为中央服务器存储所有系统日志，以便轻松跟踪活动。为了实现这一点，您将额外用户连接到您的系统。然而，您希望消息自动发送到您的系统，而不想单独监控每个系统。因此，您决定配置系统日志以完成您的任务。

| 你要做的 | 怎么做 |
| :--- | :--- |
| **1. 配置 syslogd 作为中央网络日志服务器。** | a. 输入 `gedit /etc/sysconfig/syslog` 以在 gedit 程序中打开 syslog 文件。 |
| | b. 选择 **搜索-->转到行** 以指定要导航到的行号。 |
| | c. 在文本框中，输入 `6` 以导航到包含 `SYSLOGD_OPTIONS="-m 0"` 的第六行。 |
| **2. 修改 /etc/sysconfig/syslog 文件中的设置。** | a. 将光标定位在 `SYSLOGD_OPTIONS="-m 0"` 中的 `"` 和 `-m` 之间。 |
| | b. 在 `SYSLOGD_OPTIONS` 参数中添加 `-r` 选项，将其设置为 `SYSLOGD_OPTIONS="-r -m 0"`。 |
| | c. 选择 **文件-->保存** 以保存文件。 |
| | d. 选择 **文件-->退出** 以关闭文件并退出 gedit 编辑器。 |
| **3. 重启 syslog 服务。** | a. 输入 `service syslog restart` 以重启 syslog 服务。 |
| | b. 输入 `clear` 以清除终端窗口。 |
