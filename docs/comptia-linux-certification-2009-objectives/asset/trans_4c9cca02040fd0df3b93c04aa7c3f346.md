
故障排查可能是一个艰难的过程。不太可能有人能开发出一套完整且准确的故障排查方法，因为故障排查通常是通过基于经验的直觉猜测来完成的。

## Linux 救援环境

Linux 救援环境是一个独立的 Linux 程序，用于排查损坏的 Linux 安装问题。它作为一个外部环境，允许在现有安装文件的帮助下修复 Linux 系统中的错误。救援环境将标准的 Linux 系统目录挂载在 `/mnt/sysimage` 目录下。根据问题类型，这些目录以读写模式或只读模式挂载。

在某些情况下，当系统目录无法挂载到 `/mnt/sysimage` 目录时，提示符将可用于故障排查。

## chroot 模式

chroot 模式将 `/root` 目录转移到一个不同的位置以便恢复。它也被称为“监狱模式”，因为用户除了该目录及其子目录外，无法访问任何其他文件或目录。

## 环境配置问题

配置问题可能会阻止用户登录系统并访问服务器提供的服务。其他问题也可能是由系统变量或用户和组账户引起的。常见配置问题的症状、原因和解决方案如下表所示。

环境配置问题

| **症状** | **原因和解决方案** |
| :--- | :--- |
| 用户无法创建用户或组账户。 | **原因：** 用户没有管理员权限；或者由于内存不足，系统无法为用户账户分配内存。**解决方案：** 检查是否已授予用户所需权限。此外，检查内存中是否有可供用户账户分配的可用空间。 |
| 用户无法登录。 | **原因：** 用户账户或组账户中的设置可能错误。**解决方案：** 检查用户或组账户设置，包括登录系统的权限、Shell 以及主目录的路径。 |
| 用户无法访问文件和目录。 | **原因：** 未向用户授予所需权限。**解决方案：** 检查用户或组的配额以及授予用户的权限。 |
| 用户无法执行基本命令或应用程序。 | **原因：** 环境变量未正确设置。**解决方案：** 检查环境变量和应用程序的库文件。 |
| 计划任务未被执行。 | **原因：** `crond` 守护进程未启动，或由于配置无效而停止。**解决方案：** 检查 `crond` 守护进程是否正在运行。如果没有，检查 crontab 文件中设置的配置是否正确。 |
| 用户无法在运行级别之间切换。 | **原因：** `PATH` 变量未正确设置，或者未向用户授予在运行级别之间切换的权限。**解决方案：** 检查是否已授予用户更改运行级别所需的必要权限，或者 `sbin` 目录的路径是否设置在 `PATH` 变量中。 |

## 单用户模式

Linux 中的单用户模式可以通过将运行级别更改为 1 来初始化。当系统在启动后不允许登录时，会使用此模式。单用户模式下网络功能被禁用，使其成为排查网络问题的理想模式。它甚至可以用来恢复 root 密码。由于在运行级别 1 下，大多数分区都未挂载，单用户模式可用于文件系统检查。

## 启动磁盘

**定义：**

启动磁盘是包含操作系统文件（如 `init`、`klogd` 和 `syslogd`）以启动系统的磁盘。它可以是硬盘、软盘、CD-ROM、DVD-ROM 或 USB 驱动器。启动磁盘包含配置文件、启动文件和程序。在硬盘故障后，使用启动磁盘来启动系统。某些发行版使用安装集中的第一张 CD 作为启动磁盘。其他发行版允许你创建一个可用于启动系统的软盘。

## 内存盘 (Ramdisk)

内存盘是分配并用作分区的一部分内存。作为内存盘分配的内存被视为一个硬盘。频繁访问的文件可以放在内存盘中，从而增加系统的性能。

## Ramdisk Word 关键字

Ramdisk word 关键字是一个指定根文件系统位置的关键字。可以使用 `rdrev` 命令设置和访问 ramdisk word。

## boot.iso 文件

`boot.iso` 文件是用于创建可引导 CD- 或 DVD-ROM 的 ISO-9660 映像。可以将此映像文件刻录到 CD-ROM 上，然后用于安装 Linux，就像原始安装介质本身一样。CD-ROM 的启动速度也是一个额外优势。

## diskboot.img 文件

`diskboot.img` 文件是用于创建可引导 USB 闪存驱动器的 VFAT 文件系统映像。一旦映像写入 USB，即可用作 Linux 安装介质。但是，使用 USB 启动系统取决于 BIOS 设置。应使用 `dd` 命令将 `diskboot.img` 映像文件写入 USB。

## 根磁盘

**定义：**

*根磁盘*是包含目录（如 `etc`、`bin`、`home` 等）的磁盘，这些目录包含运行 Linux 系统所需的文件。它不需要包含内核或引导加载程序。在内核启动后，根磁盘可以运行系统，而无需依赖其他任何磁盘。

## 零填充文件

你需要创建一个不包含任何数据或分区表的文件系统来构建压缩的根文件系统。为此，你需要创建一个零填充的文件、分区或内存盘。可以使用 `dd` 命令创建零填充的文件或分区。此命令会擦除数据（如果有）和分区表。它用零填充指定数量的块。通过创建零填充的文件或分区，你可以将文件系统压缩到最大。
