+   a.  Enter **vi /etc/syslog.conf** to open the syslog.conf file.

+   b.  Press **Shift+G** to go to the end of the file.

+   c.  Press **O** to switch to the insert mode and move to a new line.

+   d.  Enter **#Log iptables results to iptables log** to specify a description about directing iptable results to the log file.

+   e.  Type **kern.3** and press the **Tab** key and then type **/var/log/iptables** to direct the results to the log file.

![](bbox=[0.38, 0.34, 0.74, 0.4])

+   f.  Press **Esc** and enter **:wq** to save and close the file.

+   g.  Enter **touch /var/log/iptables** to create the /var/log/iptables file.

+   h.  Enter **service syslog restart** to restart the syslog service.
