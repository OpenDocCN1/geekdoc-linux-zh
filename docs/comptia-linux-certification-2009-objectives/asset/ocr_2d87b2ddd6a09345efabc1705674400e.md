# # How to Implement iptables

# **Procedure Reference: Configure iptables**

To configure iptables:

+   1. Log in as root.

+   2. Enter `service iptables start` to start the `iptables` service.

+   3. Enter `chkconfig iptables on` to automatically start the `iptables` service at the system startup.

+   4. Manage the rules using `iptables`.

+       - Enter the `iptables -A forward -p icmp -j ACCEPT` to add a rule.

+       - Enter the `iptables -D forward -p icmp -j ACCEPT` to remove a rule.
