# **ACTIVITY 9-4**
# Displaying Directory Content and Time Using Scripts

**Before You Begin:**

1. You have logged in as root in the CLI.
2. The first terminal is displayed.

**Scenario:**

You want to remove the unused files on your system. Before proceeding with the cleanup, you want to list the contents of the current working directory. Therefore, you decide to write a script to list directory contents and display the current time simultaneously, to maintain a record of the time of listing.

**What You Do** | **How You Do It**
--- | ---
1. Write a simple Bash shell script. | a. Enter `vi helloworld` to open the script file in the vi editor.
   | b. Press `i` to switch to the insert mode.
   | c. Enter `#!/bin/bash` to specify the shell.
   | d. Enter `echo "Hello World"`
   | e. Enter `echo "The current date and time is : '`date'"`
   | <div style="background-color: #f0f0f0; border: 1px solid black; padding: 5px; text-align: left;"><span style="font-size: 1.2em; vertical-align: middle;">ℹ️</span> **Ensure that you use back quotes (`'`') while typing the date command.**</div>
   | f. Type `echo "The files in the current directory are $(ls 'pwd')"`
   | g. Press `Esc` to switch to the command mode.
   | h. Enter `:wq` to save the script.
   | i. Clear the terminal screen.
