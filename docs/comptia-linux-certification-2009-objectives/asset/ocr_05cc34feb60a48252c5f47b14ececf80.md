# ACTIVITY 18-1
Configuring X Font Servers

**Data Files:**
MalOtt.ttf

+   **Before You Begin:**
1. You have logged in as root in the GUI of srvA.
2. The terminal window is displayed.
3. On the terminal window, enter `rpm -qi libFS` to check if the libFS-1.0.0-3.1.i386.rpm package is installed.
4. Enter `rpm -qi xorg-x11-xfs` to check if the xorg-x11-xfs-1.0.2.4.i386.rpm package is installed.
5. Enter `rpm -qi chkfontpath` to check if the chkfontpath-1.10.1-1.1.i386.rpm package is installed.
6. Copy the MalOtt.ttf file from /085039Data/Graphical_User_Interface to the /root directory.
7. Enter `clear` to clear the terminal window.

**Scenario:**
You are setting up computers for new employees in various divisions of your organization. A new employee in the graphics department requires Linux GUI with high resolution and color settings. The employee also wants the MalOtt.ttf font installed in the system.
