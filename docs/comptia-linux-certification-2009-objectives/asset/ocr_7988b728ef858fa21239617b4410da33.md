# ### Managing Packages Using YUM

**Before You Begin:**

+   1. You have logged in as root in the GUI
2. The terminal window is displayed.
3. Enter `cd /root` to change to the root directory.
4. Enter `clear` to clear the terminal window.

**Scenario:**

A meeting is scheduled at your company. You are required to install the ypbind service on the systems in the conference room, to enable network communication. You are also asked to brief users on the installed ypbind packages. You decide to install the packages and generate a description using the details displayed in the YUM output.

![](bbox=[0.76, 0.15, 0.83, 0.2])

> The activity **Configuring NIS Services** in Lesson 12 is dependent on this activity. Therefore, be sure to perform this activity along with your students.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Install the ypbind package using yum. | a. Enter<br>`yum localinstall`<br>`/rhelsource/Server/yp*` to install the package.<br>b. At the **Is this ok [y/N]:** prompt, enter `y` to confirm download.<br>c. Observe that the dependencies are updated and the **Complete!** message is displayed.<br>d. Enter `clear` to clear the terminal window. |
| 2. Check the status of the package. | a. Enter `yum list ypbind` to view the status of the ypbind package.<br>b. Observe that **ypbind.i386** is listed under **Installed Packages**.<br>c. Enter `yum info ypbind` to view the description of the ypbind package.<br>d. Observe that the package version is `1.19` and the release is `11.el5`.<br>e. Enter `clear` to clear the terminal window. |
