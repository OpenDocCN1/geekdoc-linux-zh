# # ACTIVITY 14-1
## Configuring Encryption

**Before You Begin:**

1.  On srvA, you have logged in as root in the CLI.
2.  The first terminal is displayed.

**Scenario:**

While analyzing log files, you detect failed attempts to access the SSH service. You decide to configure the Linux server so that it encrypts the information with Blowfish before transmitting data using SSH.

| What You Do | How You Do It |
| :--- | :--- |
| **1.** Edit the `/etc/ssh/ssh_config` file. | a. Enter `vi /etc/ssh/ssh_config` to open the file.<br>b. Locate the text "Cipher:"<br>c. Uncomment the line "# Cipher 3des."<br>d. On the same line, delete "3des."<br>e. Press `I` to switch to the insert mode.<br>f. Press the Spacebar and type `blowfish`<br>g. Press `Esc` and enter `:wq` to save and close the file. |
| **2.** Restart the `sshd` service. | a. Enter `service sshd restart`<br>b. Enter `service sshd status` to check whether the service is started.<br>c. Verify that the openssh-daemon is running.<br>d. Enter `clear` to clear the terminal screen. |
