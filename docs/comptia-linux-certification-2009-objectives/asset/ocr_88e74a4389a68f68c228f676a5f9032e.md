# ACTIVITY 4-1

# Creating Text Files Using Vim

**Before You Begin:**

+   1. You have logged in as root in the CLI.
2. The first terminal is displayed.

**Scenario:**

As a junior system administrator who recently joined OGC, you have several tasks to be completed in a day. Because you are just getting used to your routine tasks, you decide to record the tasks by creating a file named Checklist.txt.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Create a text file named Checklist.txt. | a. Enter **vim Checklist.txt** to create a file named Checklist.txt.<br>b. Press **I** to switch to the insert mode.<br>c. Observe that the text “INSERT” is displayed at the bottom-left of the screen. |
| 2. Enter data into the file. | a. Enter **Update Antivirus** as the first entry in the file.<br>b. Enter **Install New Printer** as the second entry.<br>c. Enter **Fix keyboard issues** as the third entry.<br>d. Type **Install New Monitor** as the fourth and last entry. |
| 3. Save the file in execute mode and exit. | a. Press **Esc** to return to command mode.<br>b. Enter **:wq** to save the file and quit the text editor.<br>c. Enter **clear** to clear the terminal screen. |
