# # ACTIVITY 16-3
## Troubleshooting Runlevels

**Before You Begin:**

+   1. On srvB, you logged have logged in as root in the GUI.
2. Switch to the CLI terminal.
3. Log in as root in the CLI.
4. Enter vi /etc/inittab to access the inittab file containing runlevel information.
5. Comment the line that starts with “si:sysinit:/etc/rc.d/rc.sysinit.”
6. Save and close the file.
7. Enter reboot to apply the settings.

**Scenario:**

You are requested to troubleshoot a system that is unable to boot and throws an error message: “/etc/rc5.d/S00microcode_ctl: microcode device /dev/cpu microcode does not exist.” You identify that there is a system initialization error with the rc.d settings.
