# # How to Identify Common Hardware Components and Resources

# ## Procedure Reference: Identify Hardware Components and Resources

To identify hardware components and resources:

+   1. Log in as root.
2. Switch to the /proc directory.
3. Document the hardware components for future reference.

+   - Display CPU information using the cat cpuinfo command.
- Display device information using the cat devices command.
- Display partition information using the cat partitions command.
- Display current hard disk size and usage using the df -h command.
- Display current IRQ resources using the cat interrupts command.
