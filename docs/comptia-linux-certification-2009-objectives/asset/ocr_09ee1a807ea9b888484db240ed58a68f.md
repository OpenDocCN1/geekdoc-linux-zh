# ACTIVITY 12-5

Configuring an Anonymous vsftpd Server

**Before You Begin:**
1. On **srvA**, you have logged in as *root* in the CLI.
2. At the command line, change directory to the root directory.
3. Enter `clear` to clear the terminal screen.

**Scenario:**
You are a network administrator for a software development company that has branches in many countries. The teams at various locations frequently exchange large files through email. However, sharing large files using email affects mail server performance. So, you want to create a common directory on a server where users can upload and download files.

| **What You Do** | **How You Do It** |
|:---|:---|
| 1. Install FTP. | a. On the server labeled **srvA**, navigate to the */rhelsource/Server* directory. |
| | b. Enter `rpm -ivh ==> vsftpd-2.0.5-12.el5.i386.rpm` to install the *vsftpd* package. |
| | c. Enter `rpm -qi vsftpd` to display information about the installed FTP version. |
| | d. Clear the terminal screen. |
