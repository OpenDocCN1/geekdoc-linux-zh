
## 查看硬件详情

以下表格列出了常用于查看硬件详情的一些命令。

| 命令 | 用途 |
| :--- | :--- |
| dmesg | 查看启动信息。 |
| /bin/lsPCI | 查看 PCI 卡的信息。 |
| /bin/lsdev | 查看已安装硬件的信息。 |
| /bin/lsmod | 查看已加载模块的列表。 |
| /bin/uname | 查看系统信息，例如内核名称、发行版和版本号、硬件平台以及操作系统。 |

## 如何排查硬件问题

### 程序参考：排查声卡问题

1. 验证扬声器已连接、已开启并且工作正常。
2. 如果扬声器工作正常但问题仍然存在，请在启动时验证声卡是否被检测到。
   - a. 验证声卡是否列在 `lsPCI` 命令的输出中。
   - b. 如果未检测到声卡，请联系您的硬件工程师解决声卡问题。
3. 如果检测到声卡但问题仍然存在，请验证声卡模块是否已加载。
   - a. 验证声卡模块详细信息是否列在 `lsmod` 命令的输出中。
     lsmod module name
   - b. 如果声卡模块未加载，请在 /etc/modprobe.conf 文件中为声卡添加条目。要在文件中添加条目，您需要知道声卡使用的插槽号和模块名称。
     alias sound-slot-{slot number} {module name}

![](img/477ccb2f05b6ba1b2d563ea74f18c197_807_0.png)

/lib/modules/(kernel version)/kernel/sound 目录包含声卡的模块。

   - c. 重启系统以自动加载模块。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_807_1.png)

您也可以使用 modprobe 或 insmod 命令加载模块。如果您想使用 modprobe 命令，请运行 depmod 命令来构建或更新模块数据库。

### 程序参考：排查调制解调器问题

要排查调制解调器问题：

1. 验证调制解调器已正确连接到系统并已通电。
2. 检查您的电话线，并验证其是否已正确连接到调制解调器。
3. 验证调制解调器速度是否已正确设置。
   - a. 验证 /etc/mgetty+sendfax/mgetty.config 文件中指定的调制解调器速度等于或小于您的调制解调器速度。
   - b. 如果未设置调制解调器速度，请修改文件中的速度参数。

```
speed speed in bps
```

4. 验证串行端口设置是否正确。
   - a. 验证 `setserial -a /dev/ttyS0` 命令输出中列出的设置是否与您的调制解调器规格相匹配。
   - b. 如果串行端口设置不正确，请更改它们。

```
setserial /dev/ttyS{port number} {spd_normal | spd_hi | spd_vhi}
setserial /dev/ttyS{port number} baud_base {baud rate}
```

5. 如果您仍无法使用调制解调器拨号，则问题是与硬件相关的。请联系您的硬件工程师解决该问题。

### 程序参考：排查 LCD 面板问题

要排查 LCD 面板问题：

1. 验证 LCD 面板已正确连接到系统并已通电。
2. 验证 VGA 卡模块是否已正确配置。
   - a. 验证 /etc/X11/xorg.conf 文件中 Screen 部分的所有参数是否输入正确。
   - b. 如有必要，根据您的 LCD 面板规格修改参数。
3. 验证监视器参数（如 DefaultDepth、Viewport 和 Depth）是否已正确配置。
   - a. 在 /etc/X11/xorg.conf 文件中，验证 DefaultDepth、Viewport 和 Depth 参数是否已正确设置。
   - b. 如有必要，根据您的 LCD 面板规格修改参数。
4. 如果 LCD 监视器仍未正常工作，则问题是与硬件相关的。请联系您的硬件工程师解决该问题。

### 程序参考：排查哑终端问题

要排查哑终端问题：

1. 验证哑终端设备已正确连接到服务器。
2. 验证串行端口是否已正确配置。
   - a. 验证 `setserial -a /dev/ttyS0` 命令输出中列出的设置是否与您的设备规格相匹配。
   - b. 如有必要，请更改串行端口设置。

```
setserial /dev/ttyS{port number} {spd_normal | spd_hi | spd_vhi}
setserial /dev/ttyS{port number} baud_base {baud rate}
```

3. 如果哑终端仍未正常工作，则问题是与硬件相关的。请联系您的硬件工程师解决该问题。

### 程序参考：排查 UPS 设备相关问题

要排查与 UPS 设备相关的问题：

1. 验证 UPS 设备已正确连接到服务器。
2. 验证串行端口是否已正确配置。
   - a. 验证 `setserial -a /dev/ttyS0` 命令输出中列出的设置是否与您的设备规格相匹配。
   - b. 如有必要，请更改串行端口设置。

```
setserial /dev/ttyS{port number} {spd_normal | spd_hi | spd_vhi}
setserial /dev/ttyS{port number} baud_base {baud rate}
```

3. 如果 UPS 设备仍未正常工作，则问题是与硬件相关的。请联系您的硬件工程师解决该问题。

### 程序参考：排查鼠标问题

要排查鼠标问题：

1. 验证鼠标已正确连接到系统。
2. 重启系统。
3. 如果鼠标仍未工作，则问题是与硬件相关的。请联系您的硬件工程师解决该问题。

### 程序参考：排查软盘问题

要排查软盘问题：

1. 验证软盘驱动器的电源连接线是否良好。
   - 如果连接未通电，则电源连接线存在问题。
   - a. 验证读写指示灯是否亮起。
   - b. 如果没有亮起，需要检查并更换电源连接线。
2. 如果电源连接线工作正常但软盘问题仍然存在，则软盘驱动器或软盘存在问题。
   - a. 在硬件工程师的帮助下，验证软盘驱动器是否工作正常。
   - b. 如果软盘驱动器功能正常，请验证您的软盘是否工作正常。

### 程序参考：排查 X 问题

要排查 X 问题：

1. 切换到运行级别 3。
2. 检查是否满足 X 所需的标准。
   - 确保用户的配额值未达到上限。
   - 输入 `service xfs status` 检查 xfs 字体服务器是否正在运行。
   - 输入 `X -probeonly` 以收集更多信息。
   - 确保系统的主机名已正确配置。
   - 输入 `system-config-display` 检查显示设置是否已正确配置。
