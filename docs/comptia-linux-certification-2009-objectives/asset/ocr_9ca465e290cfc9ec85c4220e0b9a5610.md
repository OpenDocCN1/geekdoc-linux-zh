# How You Do It

+   1. Customize the Tripwire configuration and policy files.

+   a. Navigate to the /etc/tripwire directory.

+   b. Open the twpol.txt file.

+   c. Locate the line beginning with “HOSTNAME.”

+   d. Press O to switch to the insert mode and move to a new line.

+   e. Type SIG_HI = 100; to define a new variable and assign a value to it.

+   f. Press Esc to switch to the command mode.

+   g. Search for the text rulename = “Tripwire Data Files”

+   h. Press O to switch to the insert mode and move to a new line.

+   i. On the new line, enter severity = $(SIG_HI),

+   j. Type emailto = root ,

+   k. Press Esc to switch to the command mode.

+   l. Save and close the file.

+   m. Clear the screen.
