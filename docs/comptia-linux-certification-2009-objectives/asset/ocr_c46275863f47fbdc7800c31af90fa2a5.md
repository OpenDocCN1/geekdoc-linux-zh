# The w Command

The w command is primarily used to display the details of users who are currently logged in to a system and their transactions. The first line of the output displays the status of the system.

The second line of the output displays a table with the first column listing the users logged in to the system and the last column indicating the current activities of the users. The remaining columns of the table show different attributes associated with the users.

# The last Command

The last command displays the history of user log in and log out, along with the actual time and date. It also has options that enable you to filter users who have logged in through a specific terminal. For example, last 1 will display the details of users who logged in using the first terminal. The last command retrieves the information from the /var/log/wtmp file.
