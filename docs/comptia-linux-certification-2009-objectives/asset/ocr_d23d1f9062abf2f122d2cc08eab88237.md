+   4. Troubleshoot inittab settings.

+   a. At the **sh** prompt, enter **chroot /mnt/sysimage** to mount the rescue environment files.

+   b. Enter **vi /etc/inittab** to go to the inittab file.

+   c. Enter **/^si** to go to the sysinit line.

+   d. Press **I** to switch to the insert mode.

+   e. Observe that the cursor is at the beginning of the line # **si::sysinit:/etc/rc.d/rc.sysinit**.

+   f. Delete the # symbol at the beginning of the line to remove the comment declaration.

+   g. Press **Esc** to exit to the command mode.

+   h. Save and close the file.

![](bbox=[0.61, 0.43, 0.96, 0.5])

+   i. Enter **exit** to exit the chroot environment.

+   j. Enter **reboot** to reboot the system.

+   k. Observe that the system boots correctly and the login prompt is displayed.

+   l. Log in as **root** in the GUI.
