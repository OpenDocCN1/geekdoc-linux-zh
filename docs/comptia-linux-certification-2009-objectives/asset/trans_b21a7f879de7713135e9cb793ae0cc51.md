### 通配符

*通配符* 是用于替代字符串部分的特殊字符。通过将通配符与适当的参数结合使用，你可以在系统中搜索和定位文件。通配符用于缩小搜索条件并获得准确的搜索结果。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_355_1.png)

*图 9-2：在命令中使用通配符。*

下表列出了一些常用的通配符。

| 通配符 | 用途 |
|---|---|
| `*` | 匹配文件名中零个或多个字符。 |
| `?` | 匹配文件名中的单个字符。 |
| `[abcde]` | 匹配列表中任意一个字符。 |
| `[a-e]` | 匹配范围内的任意字符。 |
| `[!abcde]` | 匹配不在列表中的任意字符。 |
| `[!a-e]` | 匹配不在范围内的任意字符。 |
| `{linux, shell}` | 匹配给定选项中的任意单词。 |
| `#` | 列出以 # 符号前字符结尾的文件名。 |

### 复杂通配符

复杂通配符是单个通配符的组合。例如，输入 `[a-z]?[1-9]` 可以搜索三个字符——第一个字符是字母，最后一个字符是数字，中间字符可以是字母、数字或特殊字符。

### 通配扩展（Globbing）

*通配扩展（Globbing）* 是一种利用模式匹配行为展开文件名（通配符）的功能。通配扩展解释的通配符包括 `*` 符号、`?` 符号、包含在括号内的字符集以及 `^` 符号等特殊字符。

### Tab 补全

*Tab 补全* 方便命令和文件名的自动补全。按下 **Tab** 键可以补全命令、文件、目录、用户和主机的名称。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_356_0.png)

```bash
[root@localhost ~]# his
hisaxctrl history
[root@localhost ~]# his
```

*图 9-3：* 文本 "his" 的 Tab 补全条目。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_356_1.png)

连续按两次 **Tab** 键将显示所有以你输入的字符串开头的文件和目录。

### history 命令

*history 命令* 用于查看之前输入的命令。它从 `~/.bash_history` 文件中检索指定数量的命令。你可以使用 **向上箭头** 或 **向下箭头** 键来选择所需的命令。同时按下 **Alt** 和 **加号 (+)**，可以回忆之前执行命令中使用过的参数。

按下 **向上箭头** 键允许你回忆在终端上运行过的命令。先按 `Esc` 然后按 **句点** (`.`) 是回忆参数的另一种方式。

## 如何执行基本的 Bash Shell 操作

### 操作参考：使用通配符进行搜索

要使用通配符进行搜索：

- 1. 在 CLI 中作为用户登录。
- 2. 执行基本操作。
    - 输入 `ls [wildcard]` 以列出匹配给定模式的所有内容。
    - 输入 `rm [wildcard]` 以删除匹配给定模式的所有内容。
    - 输入 `echo [wildcard]` 以打印匹配给定模式的所有内容。

### 操作参考：使用 Tab 补全检测文件名

要使用 Tab 补全检测文件名：

- 1. 在 CLI 中作为用户登录。
- 2. 输入命令的唯一字符并按下 **Tab** 键以补全命令。
- 3. 输入 `_{unique character of the file name}_` 并按下 **Tab** 键以补全文件名。

### 操作参考：使用 history 命令查看最近使用的命令

要使用 history 命令查看最近使用的命令：

- 1. 在 CLI 中作为用户登录。
- 2. 查看已执行命令的历史记录。
    - 输入 `history` 以列出所有之前使用的命令。
    - 输入 `!{history number}` 以从命令历史中执行特定命令。
    - 输入 `!!` 以重复之前执行的命令。

### 操作参考：执行基本的命令行扩展

要执行基本的命令行扩展：

- 1. 在 CLI 中作为用户登录。
- 2. 执行基本的命令行扩展。
    - 当文件或目录名称包含公共字符串时，输入 `{command} {common string}{ {unique part of file 1}, {unique part of file 2} }`。
    - 输入 `{command} "string"` 以打印字符串。
    - 输入 `{command 2} '{command 1}'` 以一个命令的输出作为另一个命令的输入。
