+   2. Enter echo {value} > /proc/{file location whose value in the kernel needs to be changed} to configure the kernel parameters.
3. Save and close the file.

# Procedure Reference: Configure the Kernel Using the sysctl Command

To configure the kernel using the sysctl command:

+   1. Log in as root in the CLI.
2. Enter sysctl [command options] {kernel parameter}={value} to configure the kernel parameters.
