## RAID 级别

RAID 可以根据系统要求以不同的级别实现。常用的 RAID 级别包括 0、1 和 5。

| **RAID 级别** | **描述** |
| :--- | :--- |
| RAID 0 | RAID 0 通常被称为数据条带化。RAID 0 通过避免数据冗余，将数据存储在多个设备中。实现 RAID 0 的操作系统会将多个磁盘视为单个设备。RAID 0 的优点是提高了数据访问速度。建议在实现 RAID 0 时，磁盘大小应相等。RAID 0 的缺点是如果任何一块硬盘崩溃，所有数据都会丢失。 |
| RAID 1 | RAID 1 通常被称为磁盘镜像。RAID 1 在多个磁盘上存储相同数据的副本。服务器必须将相同的数据写入多于一块磁盘，这可能会使数据总线饱和并增加 CPU 利用率。RAID 1 导致数据冗余，但不会加快数据访问速度。 |
| RAID 5 | RAID 5 是 RAID 4 的改进级别。RAID 5 将奇偶校验数据条带化存储在 RAID 组中的所有磁盘中。RAID 5 有很多优点。它加速了多次小写入操作。由于数据分布在阵列中的所有驱动器上，因此多次小读取操作也更快。可以让所有驱动器都参与读取操作。RAID 5 是最常用的 RAID 级别。 |

## 软件 RAID

**定义：**

*软件 RAID* 是应用于内核磁盘代码并使用软件实现的 RAID。它依赖于服务器处理器的性能和负载。软件 RAID 成本较低，因为它即使使用较便宜的磁盘（如 IDE 和 SCSI）也能正常工作。此外，软件 RAID 具有更高的容错级别，使您可以轻松诊断和修复系统问题。软件 RAID 提供了一些功能，例如基于内核的配置、线程化 OS 重建、在 Linux 机器之间无需重建即可移植阵列、使用空闲系统资源进行阵列重建、自动 CPU 检测以及支持热插拔驱动器。

**硬件 RAID 与软件 RAID**

硬件 RAID 系统是使用磁盘控制器卡实现的。连接到 RAID 磁盘控制器的硬盘被配置为 RAID 阵列的一部分。磁盘控制器会隐藏磁盘阵列，并将其作为单个逻辑存储单元或驱动器呈现给系统。操作系统将无法识别硬件之间的差异。

软件 RAID 是实现 RAID 的一种经济实惠的方式。它应用于内核磁盘代码，并且可以在所有类型的硬盘上实现。基于软件的阵列依赖于服务器 CPU 的性能和负载。

## mdadm 工具

mdadm 工具用于管理 RAID 设备。该工具用于创建、删除和监控 RAID 设备。它在多种模式下运行，例如 build（构建）、create（创建）、assemble（组装）、monitor（监控）和 manage（管理）。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_764_0.png)

> mdadm 工具也被称为多磁盘管理工具（multiple disk administration tool）。

mdadm 工具有各种选项。其中一些列于下方。

| 选项 | 用途 |
| :----- | :----- |
| -A | 组装之前创建的阵列的组件。 |
| -B | 构建无超级块的阵列。 |
| -C | 创建 RAID 阵列。 |
| -F | 切换到监控模式以跟踪阵列。 |
| -G | 增加或减少活动阵列的大小或形状。 |
| -h | 打印帮助选项。 |

![](img/477ccb2f05b6ba1b2d563ea74f18c197_765_0.png)

*图 15-6：使用 mdadm 工具创建 RAID 设备。*

### 语法

mdadm 工具的语法为 mdadm *{模式} {RAID 设备} [选项] {组件设备}*。

### mdadm 操作模式

mdadm 实用程序有几种操作模式。

| **模式** | **功能** |
| :--- | :--- |
| Create（创建） | 创建并配置新阵列。 |
| Assemble（组装） | 启动并激活现有阵列。 |
| Manage（管理） | 在活动阵列中添加或移除磁盘，或将磁盘标记为故障。 |
| Follow 或 Monitor（跟踪或监控） | 配置 mdadm 在出现阵列错误或磁盘故障时发送警报，并允许共享备用磁盘。 |
| Build（构建） | 构建无超级块的旧式阵列。 |
| Misc（其他） | 对阵列执行其他任何操作，从获取设备信息到移除旧超级块和停止活动阵列。 |

## 如何配置大容量存储设备

### 操作参考：配置软件 RAID

要配置软件 RAID：

1. 在 CLI 中以 root 身份登录。
2. 输入 `rpm -qi mdadm` 以确保已安装 RAID 软件包。
3. 创建软件 RAID。
    a. 创建 RAID 0 阵列。
        - 输入 `mdadm --create --verbose /dev/md{device_number} --level=0 --raid-devices=2 /dev/{device_name}{device_number} /dev/{device_name}{device_number}` 以创建 RAID 0 阵列。
        - 或者，输入 `mdadm -Cv /dev/md{device_number} -10 -n2 /dev/{device_name}{device_number} /dev/{device_name}{device_number}`。
    b. 创建 RAID 1 阵列。
        - 输入 `mdadm --create --verbose /dev/md{device_number} --level=1 --raid-devices=2 /dev/{device_name}{device_number} /dev/{device_name}{device_number}` 以创建 RAID 1 阵列。
    c. 创建 RAID 5 阵列。
        - 输入 `mdadm --create --verbose /dev/md{device_number} --level=5 --raid-devices=3 /dev/{device_name}{device_number} /dev/{device_name}{device_number} /dev/{device_name}{device_number}` 以创建 RAID 5 阵列。
        - 或者，输入 `mdadm -Cv /dev/md{device_number} -15 -n3 /dev/{device_name}{device_number} /dev/{device_name}{device_number} /dev/{device_name}{device_number}`。
4. 输入 `mdadm --detail --scan > /etc/mdadm.conf` 以创建包含 RAID 阵列信息的 RAID 配置文件。
5. 输入 `vi /etc/mdadm.conf` 以打开 /etc/mdadm.conf 文件并指定设备信息。
6. 输入 `mkfs -t {filesystem_type} /dev/md{device_number}` 以在 RAID 磁盘上创建文件系统。
7. 创建挂载点并挂载 RAID 磁盘。
8. 输入 `cat /proc/mdstat` 以验证 RAID 磁盘是否已创建。
9. 输入 `mdadm -S /dev/md{device_number}` 以停止或停用 RAID 服务。
10. 输入 `mdadm -AS /dev/md{device_number}` 以启动或激活 RAID 服务。
11. 输入 `mdadm -E /dev/{device_name}{device_number}` 以检查设备名称信息。

**场景：**

您在系统上分配了 3 GB 内存来存储敏感的详细信息。您希望有效利用空间并在硬盘中建立容错机制，以便在硬盘崩溃时能够恢复数据。

*在实际场景中，为了以容错方式实现 RAID 5，需要在单独的磁盘上创建逻辑分区。然而，为了演示目的，此活动是在同一磁盘上通过定义逻辑分区来完成的。*

**操作内容**

1. 在硬盘中创建三个逻辑分区。

**操作步骤**

h. 创建两个大小为 1 GB、类型为 `fd` 的逻辑分区。
i. 输入 `w` 将更改写入分区表。
j. 输入 `reboot` 重启系统。
