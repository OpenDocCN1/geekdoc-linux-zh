+   4. Create a Nessus user.
    1. Enter `/opt/nessus/sbin/nessus-adduser` to create a Nessus user.
    2. At the **Login** prompt, enter a user name.
    3. At the **Authentication** prompt, press **Enter**.
    4. At the **Login password** prompt, enter a password.
    5. At the **Login password** prompt, retype the password to confirm it.
    6. Press **Ctrl+D** to exit the prompt.
    7. Enter **y** to confirm and exit.

+   5. If necessary, make changes to the `/opt/nessus/sbin/nessus/nessus.conf` file to configure Nessus.

+   6. Start the Nessus service.
    \- Enter `service nessud start`
    \- Or, enter `/opt/nessus/sbin/nessud/ -D`
