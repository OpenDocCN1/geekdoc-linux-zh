# # Printing Files

Lesson Time: 1 hour(s), 30 minutes

# ## Lesson Objectives:

In this lesson, you will print files.

You will:

+   * Configure a local printer.
* Format text in a file and print it.
* Manage print jobs and queues.
* Configure remote printing.

# ## Introduction

You worked with files in Linux. Now, you may want to print files containing essential information. In this lesson, you will work with printer hardware and software.

Like all standard operating systems, Linux allows its users to print files. You may have trouble viewing lengthy files continuously on a monitor and may consider printing them on paper. Linux includes effective printing utilities that allow you to print configuration files and any other text documents you create.
