## 登录 Shell 与非登录 Shell

登录 Shell 是在用户登录期间创建的 Shell。另一方面，非登录 Shell 是您可以从登录 Shell 内部调用的 Shell。例如，在登录 Shell 中运行 `su` 命令会调用非登录 Shell。然而，可以使用 `su -` 命令在登录 Shell 中运行命令。GNOME 终端和执行的脚本都是非登录 Shell。`logout` 命令只能运行在登录 Shell 中，而 `exit` 命令可以运行在登录和非登录 Shell 中。

## id 命令

您可以使用 `id` 命令查看用户身份。这允许您识别当前登录会话的所有者。

## sudo 命令

超级用户 do (sudo) 命令允许用户以 root 用户的安全权限运行程序。`sudo` 命令通过允许用户以 root 用户身份运行指定命令来完成其任务。必须配置用户以使用指定命令（或所有命令）。它会提示您输入密码，并通过检查一个名为 `sudoers` 的文件来确认您执行命令的请求。该文件由系统管理员配置。这允许系统管理员在某些用户或组不知道 root 密码的情况下，让他们访问部分或所有命令。它还创建所有使用的命令和参数的日志，以保持记录。

### 语法

`sudo` 命令的语法是 *sudo command-name command-options*。例如，如果用户有权通过 *sudo* 访问 `shutdown` 命令，那么 *sudo shutdown -h now* 将开始系统关机。

执行 *sudo* 命令后，用户将被提示输入其密码。这是一种额外的安全措施，以确保未经授权的用户无法在授权用户不知情的情况下，通过授权用户的登录会话访问 *sudo* 命令。

### 密码策略

*密码策略* 是一组指导原则，有助于形成有效的密码。密码策略将系统用户划分为具有不同资源访问级别的不同类别。

### 指南

密码策略可能具有以下规则：

- 密码长度至少需要七个字符。
- 密码必须由数字、大写字母、小写字母和标点等特殊字符组成。
- 密码不得是可识别的英文单词。
- 密码必须每三个月更换一次。
- 密码策略鼓励用户避免写下其密码。
- 密码策略也可以通过培训来强制执行。

**示例：良好的密码策略**

Rudison 技术公司遵循严格的密码策略。员工被指示选择至少八个字符长的密码，包含数字、大写字母、小写字母和标点等特殊字符的组合。系统会提示员工每月更改密码。这有助于增强公司数据的安全性。

## 如何保护用户账户

**操作参考：以超级用户身份执行命令**

要以超级用户身份执行命令：

1. 以非 root 用户身份登录。
2. 输入 *sudo* (*需要 root 访问权限的命令*) 以超级用户身份运行该命令。
3. 输入超级用户或该用户的密码。
4. 观察命令已被执行。

**操作参考：禁用 Telnet 和 FTP 服务的 Root 访问**

要禁用 Telnet 和 FTP 服务的 root 访问：

1. 以 root 身份登录。
2. 禁用 Telnet 服务的 root 访问。
   - 在任何编辑器中打开 *etc/security* 文件。
   - 删除 *tty0*–*tty9* 条目。
   - 保存文件。
   - 如有必要，重启 Telnet 服务。
3. 禁用 FTP 服务的 root 访问。
   - 在任何编辑器中打开 *etc/vsftpd/ftpusers* 文件。
   - 删除 root 条目。
   - 保存文件。
   - 如有必要，重启 vsftpd 服务。

## 防火墙

**定义：**
防火墙是一种软件程序或硬件设备，通过阻挡未经请求的流量来保护系统或网络免受未授权访问。防火墙允许管理员明确允许的入站或出站流量。它还允许作为对内部主机请求的响应而发送的入站流量。防火墙通常提供日志记录和警报功能，以跟踪安全问题并向管理员报告。防火墙使用数据包过滤和代理服务器在网络中实施安全。

### 软件防火墙

“防火墙”一词通常用于指基于软件的防火墙。软件防火墙对小型家庭办公室和企业非常有用。防火墙提供许多功能，可以根据各种计算需求进行配置。一些功能包括：

- 启用或禁用某些端口的端口安全。
- 过滤入站和出站通信。用户可以在防火墙设置中设置规则或例外，以限制对 web 的访问。
- 报告并记录活动。
- 保护系统免受恶意软件间谍软件的攻击。
