要更改 NIS 用户的密码：

   ```text
   ypasswd -p NIS user name
   ```

   ```text
   rpcinfo localhost
   ```

## 配置 NIS 服务器

### 开始之前：

1. 在 *srvA* 上，切换到 CLI（命令行界面）。
2. 在 CLI 中作为 root 登录。
3. 显示第一个终端。
4. 在命令行中，切换到 `/rhelsource/Server` 目录。
5. 输入 `rpm -ivh ypserv-2.19-5.el5.i386.rpm` 以安装 `ypserv-2.19-5.el5.i386.rpm` 软件包。
6. 输入 `cd /root` 以切换到根目录。
7. 清除终端屏幕。

### 场景：

你负责管理一个大型网络，该网络有许多服务器来提供不同的网络服务。为了方便管理网络，你希望在一个中心位置维护用户和系统信息。

### 你做什么 / 如何做

1. 命名你要创建的 NIS 域。
   - a. 在标记为 **srvA** 的服务器上，打开 `/etc/sysconfig/network` 文件。
   - b. 在新行中，输入 `NISDOMAIN=srvADomain`
   - c. 按 **Esc** 切换到命令模式。
   - d. 保存并关闭文件。
   - e. 清除终端屏幕。

2. 将 NIS 服务器信息添加到 `yp.conf` 文件。
   - a. 使用 **vi** 编辑器，打开 **/etc/yp.conf** 文件。
   - b. 要指定域名和服务器名，在文件末尾输入：
     ```text
     domain srvA.ourglobalcompany.com
     server srvA.ourglobalcompany.com
     ```
   - c. 按 **Esc** 切换到命令模式。
   - d. 保存并关闭文件。
   - e. 清除终端屏幕。

3. 启动除 `ypbind` 守护进程以外的所有 NIS 守护进程。
   - a. 输入 **`service portmap restart`** 以重启 `portmap` 守护进程。
   - b. 输入 **`service yppasswdd start`** 以启动 `yppasswdd` 守护进程。
   - c. 输入 **`service ypserv start`** 以启动 `ypserv` 守护进程。
   - d. 输入 **`chkconfig yppasswdd on`** 以设置 `yppasswdd` 守护进程在系统启动时运行。
   - e. 输入 **`chkconfig ypserv on`** 以设置 `ypserv` 服务在系统启动时运行。

4. 初始化 NIS 域。
   - a. 输入 **`/usr/lib/yp/ypinit -m`**
   - b. 按 **Ctrl+D** 表示只设置一个服务器。
   - c. 输入 **`y`** 以确认服务器名称。
   - d. 清除终端屏幕。
   - e. 输入 **`service ypbind start`** 以启动 `ypbind` 守护进程。
   - f. 输入 **`chkconfig ypbind on`** 以设置 `ypbind` 服务在系统启动时运行。
   - g. 输入 **`rpcinfo -p localhost`** 以验证所有 NIS 守护进程是否正在运行。
   - h. 清除终端屏幕。

5. 创建 NIS 映射。
   - a. 导航到 `/var/yp` 目录。
   - b. 输入 **`make`** 以创建映射。
   - c. 输入 **`ypmatch jsmith passwd`** 以验证 NIS 用户信息已更新。
   - d. 清除终端屏幕。

## Secure Shell（安全外壳）

![](img/477ccb2f05b6ba1b2d563ea74f18c197_604_0.png)

**定义：**
*Secure Shell (SSH)* 是一种控制网络上计算机之间数据安全流动的网络协议。SSH 架构包含传输层、用户身份验证层和连接层。客户端发出请求，该请求由用户身份验证层进行身份验证。这通过连接层将请求传输到服务器，服务器由传输层进行身份验证。通过使用公钥密码学来加密数据，该架构使 SSH 既灵活又安全。SSH 有许多版本，例如 SSH1 和 SSH2。

### OpenSSH

![](img/477ccb2f05b6ba1b2d563ea74f18c197_605_0.png)

OpenSSH 是 SSH 协议的一个免费版本，包含在大多数 Linux 发行版中。要传输的数据通过两个系统之间形成的安全隧道传输。Telnet 传输的数据（包括密码）可以被网络上的任何系统轻松拦截。OpenSSH 为 Telnet 和类似应用传输的数据提供强大的客户端-服务器身份验证方法。
