# ## ACTIVITY 4-8
### Working with MySQL

**Before You Begin:**
1. Switch to the GUI.
2. Navigate to the /rhelsource/Server folder.

**Scenario:**
A junior database administrator joined your organization. As a Linux administrator, you are required to help the junior administrator install a web-based database on the Linux system. In addition, you need to ensure that clients are able to connect to the database.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Select MySQL files. | a. In the **Server - File Browser** window, type *m* to navigate to MySQL packages.<br><br>b. Observe that a text box is displayed at the bottom-left of the window.<br><br>c. In the text box, type *y*<br><br>d. Observe that the **mysql-5.0.45-7.el5.i386.rpm** file is automatically selected.<br><br>e. Press **Page Down** to view the other files.<br><br>f. Press **Ctrl** and click **mysql-server-5.0.45-7.el5.i386.rpm** to select it. |
| 2. Select the other files. | a. Scroll down till you locate the **perl-DBD** package.<br><br>b. Press **Ctrl** and click **perl-DBD-MySQL-3.0007-2.el5.i386.rpm** to select it.<br><br>c. Press **Ctrl** and click **perl-DBI-1.52-2.el5.i386.rpm** to select it.<br><br>d. Verify that the status bar displays the message “4 items selected (14.6 MB).” |
