# Lesson 12 Follow-up

In this lesson, you configured and managed various network services and remote network systems. You will now be able to disseminate information, administer systems remotely, enable communication through mail or chat systems, facilitate technology sharing, manage software licenses, and control unauthorized access.

+   1. **What are the advantages of managing IP addresses centrally on a network?**

   *Answers will vary, but may include: to avoid assigning the same IP address to different systems, and to ease the process of assigning IP addresses to systems on a large network.*

+   2. **Discuss the points that must be considered before you enable DNS on a network.**

   *Answers will vary, but may include:*

+   1. *The size of the network and the number of servers and clients must be taken into account. Accordingly, the name servers and zones must be defined.*

+   2. *The security measures that have to be enforced on the network must also be considered. Accordingly, servers that have access to the Internet must be linked to various domains after enforcing firewalls. DNS servers must be maintained separately to prevent unauthorized access over the Internet.*
