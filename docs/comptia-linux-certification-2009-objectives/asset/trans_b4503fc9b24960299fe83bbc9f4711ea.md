
1. 输入 `lvcreate -L {逻辑卷大小} {卷组名称} -n {逻辑卷名称}`，在您创建的卷组中创建逻辑卷。
2. 输入 `reboot` 重启系统。
3. 输入 `mkfs -t {文件系统类型} /dev/{卷组名称}/{逻辑卷名称}`，为您创建逻辑卷分配文件系统。

## 操作参考：使用 LVM 工具调整逻辑卷大小

若要使用 LVM 工具调整逻辑卷大小：

1. 以 root 身份登录。
2. 输入 `pvcreate /dev/{设备名称}(设备编号)` 创建物理卷。
3. 输入 `vgextend {卷组名称} /dev/{设备名称}(设备编号)`，将分区添加到现有卷组。
4. 输入 `lvextend -L +{大小} /dev/{卷组名称}/{逻辑卷名称}` 扩展文件系统。
5. 输入 `resize2fs /dev/{卷组名称}/{逻辑卷名称}` 调整文件系统大小。
6. 查看您所做的更改。
    - 输入 `vgdisplay` 查看卷组信息。
    - 输入 `pvdisplay` 查看物理卷信息。
    - 输入 `lvdisplay` 查看逻辑卷信息。

## 操作参考：管理 LVM 快照

若要管理 LVM 快照：

1. 以 root 身份登录。
2. 输入 `lvcreate -L {大小} -s {快照卷名称} /dev/{卷组名称}/{逻辑卷名称}` 创建卷的快照。
3. 输入 `mount /dev/{卷组名称}/{快照卷名称} {挂载点}` 挂载快照卷。
4. 删除快照卷。
    a. 输入 `umount {挂载点}` 卸载快照卷。
    b. 输入 `lvremove /dev/{卷组名称}/{快照卷名称}` 删除快照卷。

#### 使用 LVM 管理磁盘空间

开始之前：

1. 在 srvA 上，您已在 CLI 中以 root 身份登录。
2. 显示第一个终端。

场景：

在计划组织中设置文件服务器时，您决定根据以下要求分配磁盘空间：

- 开发团队 - 1 GB
- 市场营销团队 - 1 GB
- 硬件团队 - 1 GB

您被提供了一个容量为 80 GB 的硬盘。

执行操作

操作方法

1. 在硬盘上创建三个逻辑分区。
    a. 输入 `fdisk /dev/sdb` 以调用 `/dev/sdb` 设备的 fdisk 实用程序。
    b. 输入 `n` 创建新分区。
    c. 按 Enter 键接受默认的第一个柱面大小。
    d. 输入 `+1024M` 设置分区大小。
    e. 输入 `t` 更改分区类型。
    f. 输入 `10` 设置分区编号。
    g. 在 Hex code (type L to list codes): 提示符下，输入 `8e` 将分区类型从 `83` 更改为 `8e`。
    h. 观察分区 10 的系统类型已更改为 `8e`（Linux LVM）。
    i. 输入 `w` 将更改写入分区表。
    j. 观察系统显示消息，指示新的分区表仅在重启系统时应用。
    k. 创建两个大小为 1 GB 且分区类型为 `8e` 的逻辑分区。
    l. 输入 `reboot` 重启系统。

2. 在 LVM 分区上创建物理卷。
    a. 按 Ctrl+Alt+F1 切换到 CLI。
    b. 在 CLI 中以 root 身份登录。
    c. 输入 `vgscan` 使 LVM 能够定位 Linux LVM 类型的分区。
    d. 输入 `pvcreate /dev/sdb10 /dev/sdb11 /dev/sdb12` 为 LVM 分区上的每个硬盘创建物理卷。
    e. 观察系统已创建三个物理卷。

3. 在硬盘上创建逻辑卷。
    a. 输入 `vgcreate Myvolume /dev/sdb10 /dev/sdb11 /dev/sdb12` 在 `/dev/sdb` 设备上创建名为 `Myvolume` 的卷组。
    b. 观察系统已创建 `Myvolume` 卷组。
    c. 在 `Myvolume` 卷组中，输入 `lvcreate -L 1024 Myvolume -n Development` 为开发团队创建一个大小为 1 GB 的逻辑卷。
    d. 观察系统已创建名为 `Development` 的逻辑卷。
    e. 输入 `lvcreate -L 1024 Myvolume -n Hardware` 为 `Hardware` 创建一个大小为 1 GB 的逻辑卷。
    f. 输入 `lvcreate -L 1024 Myvolume -n Marketing` 为 `Marketing` 创建一个大小为 1 GB 的逻辑卷。
    g. 输入 `mkfs -t ext3 /dev/Myvolume/Development` 为您创建的逻辑卷分配 ext3 文件系统。
    h. 观察 inode 表已写入且日志已创建。
    i. 输入 `mkfs -t ext3 /dev/Myvolume/Hardware` 为您创建的逻辑卷分配 ext3 文件系统。
    j. 观察 inode 表已写入且日志已创建。
    k. 输入 `mkfs -t ext3 /dev/Myvolume/Marketing` 为您创建的逻辑卷分配 ext3 文件系统。
    l. 观察 inode 表已写入且日志已创建。

4. 为 LVM 分区创建挂载点。
    a. 输入 `mkdir /Development` 创建 Development 目录。
    b. 输入 `mount /dev/MyVolume/Development /Development` 将卷组挂载在 /Development 挂载点上。
    c. 为 **Hardware** 和 **Marketing** 组创建挂载点。
    d. 输入 `mount /dev/MyVolume/Hardware /Hardware` 将卷组挂载在 /Hardware 挂载点上。
    e. 输入 `mount /dev/MyVolume/Marketing /Marketing` 将卷组挂载在 /Marketing 挂载点上。
    f. 输入 `mount` 验证卷组是否已挂载。
    g. 观察卷组已挂载在 /Development、/Hardware 和 /Marketing 挂载点上。
    h. 输入 `clear` 清除终端屏幕。

## 主题 F

## 配置磁盘配额

您已管理了文件服务器上的磁盘空间。您还需要确保所有用户都有权限访问文件服务器上用于存储个人文件的磁盘空间。在本主题中，您将配置磁盘配额。

系统管理员必须执行的任务之一是限制磁盘空间的使用。用户可能需要在一个共同位置存储文件和数据。通过配置磁盘配额，您可以确保所有用户在该共同位置都有足够的存储空间。

### 磁盘配额

**定义：**

*磁盘配额* 是为计算机上用户文件存储分配的磁盘空间。需要为每个用户配置磁盘配额。每个实施磁盘配额的文件系统都将有七天的默认宽限期。这意味着当用户达到软限制时，宽限期功能将被激活。软限制是指允许在宽限期内使用超出该值的磁盘配额的极限值。一旦宽限期过期，软限制将作为硬限制强制执行，或者在磁盘使用上设定最大限制，用户不能超过此限制。

### 配额管理命令

配额管理是对所有用户配额的有效分配和监控。配额应以此种方式分配，使用户能够在没有数据溢出的情况下最大化磁盘资源的利用。Linux 有各种命令有助于减轻系统管理员的配额管理工作。

| 命令 | 用于 |
| :--- | :--- |
| edquota -u (用户名) | 编辑特定用户的配额。 |
| edquota -g (组名) | 编辑特定组的配额。 |
| setquota -u (用户名) | 设置特定用户的配额。 |
| setquota -g (组名) | 设置特定组的配额。 |

![](img/477ccb2f05b6ba1b2d563ea74f18c197_781_1.png)

### 配额报告

配额报告是由系统创建用于查看每个用户的磁盘空间使用情况的。这些报告使系统管理员能够检查哪个用户占用了最大磁盘空间。有两种类型的配额报告：用户配额报告和组配额报告。配额报告包含以下详细信息：

- 用户名。
- 用户在分区上使用的总块数（以千字节为单位）。
- 软限制，它是配额用户在分区上的最大磁盘使用量。
- 硬限制，它是配额用户在分区上的绝对磁盘使用限制。
- 宽限期，它是在启用配额的文件系统中执行软限制之前的时间限制。
- 用户在分区上使用的 inode 总数。
- inode 的软限制。
- inode 的硬限制。

### quotacheck 命令

quotacheck 命令检查启用了配额的文件系统，构建当前磁盘使用表，并更新 aquota.user 文件。quotacheck 命令具有各种选项。

| 选项 | 用于 |
| :--- | :--- |
| -g | 创建组配额。 |
| -u | 创建用户账户。 |
| -a | 指定所有启用了 usrquota 挂载选项的文件系统。 |
