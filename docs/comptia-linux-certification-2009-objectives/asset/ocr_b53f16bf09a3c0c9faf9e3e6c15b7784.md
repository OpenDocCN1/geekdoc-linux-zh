# ## Root Hints

Root hints are files in DNS servers that contain host information including names and addresses of the root DNS servers. It is used to locate authoritative DNS servers and resolve names outside authoritative DNS domains.

# ## Namespace

*Namespace* is the part of the name that must be unique for DNS to function. For any given domain, the subdomain must not contain two hosts or subdomains of the same name.

# ## Syntax for Zone Files

The syntax for writing a zone file is:

$TTL time to live in seconds
$ORIGIN domain name
$INCLUDE file name
@ IN SOA master server name
  email address of the domain administrator
  (
    serial number
    time in seconds to refresh
    time in seconds to retry
    minimum TTL in seconds
  )
  IN DNS Record
  DNS server name
  IN DNS Record
  preference value
  mail server name
  hostname IN A IP address
  alias name IN CNAME real name of the host
