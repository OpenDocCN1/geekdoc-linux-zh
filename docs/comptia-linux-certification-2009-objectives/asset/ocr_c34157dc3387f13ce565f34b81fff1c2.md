# ## Managing Packages Using the Debian Package Manager

**Data Files:**
Training_Policy.txt

**Before You Begin:**

+   1.  Reboot srvA and start Debian Linux on the system.
2.  Login as root in the GUI.
3.  Insert the **Debian 5.0.0 i386 Bin-1** disc in the CD drive.
4.  Launch the terminal window.
5.  On the terminal window, enter `cd /media/cdrom/debian/pool/main/l/less` to navigate to the less directory.
6.  Enter `cp less_418-1_i386.deb /root` to copy the less package to the /root directory.
7.  Enter `clear` to clear the terminal window.
