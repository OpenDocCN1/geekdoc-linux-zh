# The who Command Options

The -i option can be used to see how long users have been idle. A dot indicates that the users were active up to the last minute, old indicates that the users were inactive for over 24 hours, and anything between 2 minutes and 23 hours 59 minutes shows the length of time they have been idle. The am i option displays information only for the user who runs the com-mand. The output is preceded by the host name.

# The whoami Command

The whoami command is used to display the user name with which you are currently logged in to the system. Sometimes, you may need to log in to a system and switch among different users, and you may not be sure with which user you are currently logged in. In such instances, you can use the whoami command to know your current user name.
