# # How to Verify Packages

# ## Procedure Reference: Verify Packages

To verify packages:

+   1.  Login as root.
2.  Verify installed packages.

+   -   Verify all the `rpm` packages by using the `rpm -Va` command.
-   Verify an individual `rpm` package by using the `rpm -Vv [package name]` command.
-   Verify a specific file in the package by using the `rpm -V {file name} {package_name}` command.
