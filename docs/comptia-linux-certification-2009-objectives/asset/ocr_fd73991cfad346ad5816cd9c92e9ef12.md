# # Managing Packages

Lesson Time: 2 hour(s)

# ## Lesson Objectives:

In this lesson, you will manage packages.

You will:

+   - Manage packages using the RPM package manager.
- Verify packages.
- Upgrade and refresh packages.
- Configure repositories.
- Install packages using the YUM package manager.
- Manage packages using the Debian package manager.
- Work with source files.

# ## Introduction

You explored the basic Linux environment, worked with files, and printed them. Now, you are ready to install software on your system. Packages facilitate the functioning of software. In this lesson, you will manage packages.

You will need to install software on your system to perform required tasks effectively. To do this, you need to learn about packages and package managers and how to install them on your system. Unless the packages are fully installed, the software will not function.
