# Linking files

**Data Files:**
Audit_File_09, Software_List.txt, New_Policies.txt

**Before You Begin:**
1. You have logged in as root in the GUI.
2. Switch to the CLI.

**Scenario:**
You have been assigned the task of reviewing an updated employee policy document for casing errors, making a word count of the document, and creating links of the document as a backup in your local system. You also want to clean up your system by removing unused files from your current working directory and back up the policy document.

| What You Do | How You Do It |
| :--- | :--- |
| 1. List the files in the current working directory. | a. Enter `cd /root` to change the directory.<br><br>b. Enter `ls -l` to list the files in the directory.<br><br>c. Observe that all files in the current working directory are listed. |
| 2. Move the Audit_File_09 file to the /jsmith directory and remove the Software_List.txt file. | a. Enter `mv -v Audit_File_09 /home/jsmith` to move the audit file to the /jsmith directory.<br><br>b. Enter `ls -l /home/jsmith` to verify that the file transfer is complete.<br><br>c. Enter `rm Software_List.txt` to remove the software file from the /root directory.<br><br>d. Type `y` to confirm the deletion and press `Enter`.<br><br>e. Enter `ls` to check whether the file is deleted.<br><br>f. Observe that the Software_List.txt file has been deleted. |
