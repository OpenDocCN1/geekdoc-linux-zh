# Syntax

The syntax of the `echo` command is `echo {"string"}`.

# The sleep Command

The `sleep` command is used to pause system activities for a specified time. The `sleep (time)` command hangs up the prompt for the number of seconds specified by the value of the variable *time*.

![](bbox=[0.78, 0.15, 0.92, 0.21])

# The sleep command

```
root@localhost:~
[root@localhost ~]$ sleep 65
```

# The cat Command

The `cat` command displays, combines, and creates text files. This command is frequently used to read small text files.

![](bbox=[0.78, 0.62, 0.92, 0.675])

The name of the `cat` command is a short form of the word *concatenate*.
