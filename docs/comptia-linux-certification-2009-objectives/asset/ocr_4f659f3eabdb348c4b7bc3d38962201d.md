# ## Asymmetric Encryption

*Asymmetric encryption* is carried out using two keys in the form of key pairs. While one key is used for encryption, another key is used for decryption.

![](bbox=[0.78, 0.54, 0.91, 0.59])

![](bbox=[0.15, 0.61, 0.62, 0.79])

There are two main protocols involved in asymmetric encryption: protocol 1 and protocol 2. Only one protocol can be implemented at a time.
