# ACTIVITY 5-3
### Modifying Default Permissions

**Before You Begin:**

+   1. You have logged as root in the GUI.
2. The user account for chris already exists on the system.

**Scenario:**
Your colleague, Chris, creates large number of documentation files that are used by other users on the system. Your manager would like all files created by her, from now on, to be readable and modifiable by all users.

Account details of the user:

+   - User name: chris
- Password: myp@$S$w0rd

| What You Do | How You Do It |
| :--- | :--- |
| 1. Change the umask value on Chris' system to 0000. | a. Switch to the fourth terminal.<br>b. Log in as **chris** on Chris' system.<br>c. Enter `umask` to view the current umask value.<br>d. Observe that the umask value is displayed as **0002**.<br>e. Enter `touch newfile1` to create a test file with existing permissions.<br>f. Enter `umask 0000` to alter the umask value. |
| 2. Check whether the umask value has been changed. | a. Enter `umask` to view the new umask value.<br>b. Observe that the umask value is now displayed as **0000**. |
