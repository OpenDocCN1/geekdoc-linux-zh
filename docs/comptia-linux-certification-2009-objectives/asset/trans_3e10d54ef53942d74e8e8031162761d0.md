

## 术语表

- **PRNG**（伪随机数生成） 控制随机数生成的算法。
- **进程管理层** 内核中的一层，通过为处理器分配独立的执行空间来处理不同的进程，并确保一个进程的运行不会干扰其他进程。
- **进程监控** 一种跟踪系统上正在运行的进程的模式，以确定系统的性能和可靠性。
- **进程表** 一个汇总当前系统上正在运行的进程的记录。
- **进程** 执行数据处理任务的运行中程序的实例。
- **配置文件** 一个包含命令的文件，用于根据用户要求定制用户的登录会话。
- **程序** 描述如何执行任务的一组指令。
- **代理服务器** 作为网络浏览器和包含用户需要访问的数据的 Web 服务器之间中介的服务器。
- **公钥** 随请求一起传输到目标服务器的密钥。
- **pwd 命令** 用于显示相对于根目录的当前工作目录的命令。
- **配额报告** 由系统创建的报告，用于查看每个用户的磁盘空间使用情况。
- **RADIUS**（远程认证拨号用户服务） 一种促进通过网络进行集中式认证、授权和计费的网络协议。
- **RAID**（独立磁盘冗余阵列） 一种将相同数据存储到服务器或独立磁盘存储系统的多个硬盘的不同位置上的方法。
- **随机数生成** 一种数据加密方法，其中使用内核生成随机数，并在传输前分配给文件。
- **RDBMS**（关系型数据库管理系统） 一种允许存储和组织逻辑相关数据的系统。
- **重定向符** 用于重新定义标准输入或标准输出的操作符。
- **关系型数据库** 以相关表的形式一致地存储逻辑相关数据的数据库。
- **相对路径** 相对于当前工作目录的路径。
- **远程 X 会话** 远程工作站上的用户可以查看主机 X 窗口的会话。
- **renice 命令** 允许更改正在运行的进程的调度优先级的命令。
- **repomd** 基于 rpm 的 XML 元数据。
- **仓库** 保存源代码和编译结果的数据库的名称。
- **解析器** 基于客户端的软件，向 DNS 名称服务器发送请求，以将域名转换为其 IP 地址，或反之。
- **restore 命令** 允许从使用 dump 命令创建的备份中恢复文件或文件系统的命令。
- **反向区域** 用于将 IP 地址映射到主机名的 DNS 区域。
- **RMON**（远程监控） 一种允许在单个工作站上收集网络信息的网络管理协议。
- **rndc 实用工具** 一种 BIND 实用工具，允许从本地或远程主机对 named 守护进程进行命令行管理。
- **根磁盘** 包含目录的磁盘，这些目录包含运行 Linux 系统所需的文件。
- **root 用户** 对系统上所有文件和资源拥有访问权限的用户。
- **路由器** 将多个网络连接在一起的联网设备。
- **路由表** 路由器用于在网络间转发数据包的网络地址表。
- **路由** 在网络上为数据包从源到目的地的传输选择最佳路由的过程。
- **RPC**（远程过程调用） 包含一组工具和库函数的软件包。
- **RPM**（RPM 包管理器） 用于维护包的工具。
- **rsync 实用工具** 用于在系统之间同步文件的实用工具。
- **RTC**（实时时钟或硬件时钟） 当系统关闭时记录时间的时钟，而不是系统开启时。
- **运行级别** 指定在系统上运行哪一组进程的设置。级别包括单用户、多用户、重启和关机等等。
- **Samba** 一套帮助在异构网络（由运行不同操作系统的计算机组成）上共享文件和打印机的网络共享工具集。
- **SASL**（简单认证和安全层） 一种为互联网协议提供认证和数据安全的框架。
- **SCI 层**（系统调用接口） 处理从用户应用程序发送到内核的功能调用的抽象层。
- **SCSI**（小型计算机系统接口） 将外围设备连接到计算机的一组标准。
- **搜索路径** Shell 用于定位文件的各个目录路径序列。
- **扇区** 写入或读取出磁盘的最小的存储单元。
- **sed 命令** 一个可以根据命令行参数修改文本文件的命令行程序。
- **自签名证书** 由用户生成的证书，包含用户的公钥作为签名。
- **SELinux**（安全增强型 Linux） 在 Linux 操作系统上实施各种安全策略的安全增强功能。
- **服务访问控制** 用于限制对某些重要服务的访问的守护进程。
- **服务** 在后台执行任务的应用程序集合。
- **sfdisk 实用工具** 用于操作分区的实用工具。
- **Shell** 直接与用户交互并作为 Linux 系统命令解释器的组件。
- **shutdown 命令** 用于关闭或重启系统的命令。这会关闭文件并执行安全关闭系统所必需的其他任务。
- **信号** 发送给进程以执行特定操作的消息。
- **skel 目录** 存储需要复制到新用户主目录的默认文件和目录的位置。
- **slapd**（独立 LDAP 守护进程） 一个 LDAP 目录服务，允许用户创建和提供自己的目录服务，该服务可以连接到全局 LDAP 目录服务。
- **SMBFS**（Samba 文件系统） 用于挂载和访问异构网络上可用共享资源的标准 Linux 文件系统。
- **SMTP** 定义一套规则的协议，使发送电子邮件消息到服务器的程序与从客户端接收电子邮件消息的程序之间能够进行交互。
- **SNMP**（简单网络管理协议） 一种允许远程监控和配置网桥、路由器、网卡和交换机等网络组件的网络管理协议。
- **snort** 监控网络流量的网络入侵检测系统（IDS）。
- **软限制** 配额用户在分区上的最大磁盘使用量。
- **软件 RAID** 使用应用于内核磁盘代码的软件实现的 RAID。
- **空间模式** Nautilus 浏览器的默认模式。
- **预印区** 等待打印文件的临时存储空间。
- **预印管理器** 临时存储等待打印文件的组件。
- **预印** 打印作业可以临时存储的过程。
- **Squid** 用于缓存互联网数据的代理服务器。
- **ssh-keygen 命令** 生成、管理和转换认证密钥的命令。
- **SSH**（安全外壳协议） 控制网络中计算机之间数据安全流动的网络协议。
- **SSL**（安全套接层） 确保 Web 服务器和浏览器之间安全事务的协议。
- **标准错误** Linux 中用作错误消息目的地的流。
- **标准输入** 命令输入的源。
- **标准输出** 命令输出的目的地。
- **语句** 定义域名设置的选项集合。
- **静态主机** 从 DHCP 服务器接收相同 IP 地址的主机。
- **STDERR** 用于指代标准错误文件的符号。
- **STDIN** 用于指代标准输入文件的符号。
- **STDOUT** 用于指代标准输出文件的符号。
- **粘滞位** 为目录中的文件提供保护的权限位。
- **su 命令**（替换或切换用户命令） 允许在不注销的情况下更改登录会话所有权的命令。
- **子网掩码** 告知服务器 IP 地址是在本地网络还是远程网络的过滤器。
- **子网** 单个大型网络的逻辑子部分。
- **sudo 命令**（超级用户执行命令） 允许用户以 root 用户的安全权限运行程序的命令。
- **超级块** 存储在磁盘上并包含文件系统控制信息的数据结构。
- **交换空间** 当 Linux 物理内存不足且需要更多内存时使用的硬盘的一部分。
- **符号链接** 对文件或目录的引用，允许从不同的目录访问已挂载的文件系统。
- **对称加密** 一种加密类型，在加密和解密过程中仅使用单个密钥来授权信息。
- **syslog 实用工具** 跟踪系统日志的实用工具。
- **系统初始化** 系统启动时开始的第一项进程。
- **系统负载** 计算机在给定时间内所做工作量的度量。
- **系统日志** syslog 实用工具记录的系统活动记录。
- **系统时间** 由计算机内部时钟维护的时间。
- **Tab 补全** 通过按下 Tab 键促进命令和文件名自动补全的功能。
- **tar 命令** 创建数据归档的命令。
