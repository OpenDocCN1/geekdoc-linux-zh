+   3. Renice the copy process by using the `top` command.

+   a. Enter `top` to open the process management tool.

+   b. Press **R** to renice the process.

+   c. Enter {PID} to specify a process to renice.

+   d. Enter **\u002d15** to specify the nice value.

+   e. Press **q** to exit the process list.

+   f. Enter `ls /opt/Server` to view the files in the directory.

+   g. Observe that the files from the source CD are listed, which indicates that the copy process was successful.

+   h. Clear the terminal screen.
