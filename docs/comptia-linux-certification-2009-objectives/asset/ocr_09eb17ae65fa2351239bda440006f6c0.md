+   4. Modify the partition entries in the fstab file to mount the ext3 filesystems on when the system boots.

+   a. Enter vi /etc/fstab to open the fstab file.
b. Navigate to the line containing the "/dev/sdb5" entry and place the cursor on the number 2 in "ext2."
c. Press I to switch to the insert mode.
d. Type 3 and press Delete.
e. Press the Down Arrow key and the Left Arrow key to navigate to the line containing the "/dev/sdb6" entry and place the cursor after the number 2 in "ext2."
f. Type 3 and press Delete.
g. Press Esc.
h. Save and close the file.
i. Enter clear to clear the terminal screen.
j. Enter mount -a to update fstab entries.
k. Enter reboot to reboot the system.
