# What You Do

+   1. Create a subnet declaration.

# How You Do It

+   a. Navigate to the /etc directory.

+   b. Using the vi editor, open the dhcpd.conf file.

+   c. Navigate to the last line in the file.

+   d. On a new line, enter `ddns-update-style none;` to specify that DNS has not been implemented.

+   e. Enter `subnet 192.168.0.0 netmask 255.255.255.0 {` to begin the subnet declaration.

+   f. Enter `range 192.168.0.25 192.168.0.200;` to specify the range of IP addresses for your network.

+   g. Enter `default-lease-time 1200;` to specify the default lease time for the IP addresses assigned to the subnet.

+   h. Enter `max-lease-time 1200;` to specify the maximum lease time for the IP addresses assigned to the subnet.

+   i. Enter `}` to close the subnet declaration. See Code Sample 1.

+   j. Press **Esc** to switch to the command mode.

+   k. Save and close the file.

+   l. Clear the terminal screen.

# Code Sample 1

```
ddns-update-style none;
subnet 192.168.0.0 netmask 255.255.255.0 {
range 192.168.0.25 192.168.0.200;
default-lease-time 1200;
max-lease-time 1200;
}
```
