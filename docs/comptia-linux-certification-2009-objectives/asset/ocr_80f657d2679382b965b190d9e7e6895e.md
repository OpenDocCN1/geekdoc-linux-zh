# ACTIVITY 3-2
Changing Directories

Before You Begin:
You have logged in as root in the CLI.

Scenario:
You have been hired as a junior administrator in an organization and provided administrative access to your Linux system. However, as the supervisor, you do not have a specified directory in /home to work in. You therefore decide to switch to the home directory and work with files.

+   1. Switch from the /root directory to the /home directory.

   a. Enter pwd to view the current working directory.

   b. Observe that the current working directory is /root.

   c. Enter cd /home to change to the home directory.

   d. Enter pwd to view the current working directory.

   e. Observe that the current working directory is now changed to /home.

+   2. List the files in the directory.

   a. Enter ls -a to list all the files in the /home directory.

   b. Observe the listed files in the directory.

   c. Enter clear to clear the terminal screen.
