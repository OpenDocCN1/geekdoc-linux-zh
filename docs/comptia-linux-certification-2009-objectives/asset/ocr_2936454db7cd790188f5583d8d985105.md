# How to Link Files

# Procedure Reference: View the Inode Number of a File or Directory

To view the inode number of a file or directory:

+   1. Log in as a user in the CLI.
2. Enter ls -i (file or directory name) to view the inode details.

# Procedure Reference: Link Files

To link files:

+   1. Log in as a user in the CLI.
2. Create file links.
	* Enter ln {source file} {destination file} to create a hard link.
	* Enter ln -s {source file} {destination file} to create a soft link.
3. Enter ls -i {source file} {destination file} to view the inodes of the file.
