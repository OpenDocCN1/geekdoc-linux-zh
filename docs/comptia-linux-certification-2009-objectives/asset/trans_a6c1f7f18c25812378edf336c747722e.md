## 硬件防火墙

硬件防火墙是一种硬件设备，可以是独立设备，也可以集成在大多数路由器中，用于保护私有网络中的计算机免受未经授权流量的侵害。它们被部署在私有网络和公共网络之间，以管理入站和出站流量以及网络访问。

## 防火墙定位

防火墙可以逻辑上放置在内部网络与外部世界之间。此外，它可以放置在内部公司网络之间，以及位于单个服务器上。建议根据安全管理员分配的规则配置防火墙，以拒绝或授予访问权限。

### 数据包过滤

*数据包过滤*是在检查每个数据包的预定义内容（例如 IP 地址）后，传递或阻止入站和出站数据包的过程。它是第一种用于通过读取数据包头部来保护网络的防火墙类型。数据包过滤的限制在于它被设计为仅查看数据包头部信息。*Netfilter* 是一个在 Linux 中实现数据包过滤的框架，用于管理防火墙和保护数据。它包含许多模块，用于检查数据包头部并过滤具有不规范头部的数据包。数据包在发送到目的地之前会经过各个阶段。数据包在特定点被过滤，被过滤的数据包会被发送到下一个阶段。根据用户需求，可以配置 netfilter 活动。

## 代理服务器实现

代理服务器，也称为应用网关，是一种比纯数据包过滤器更安全且更灵活的防火墙解决方案。代理软件可以配置为拦截网络流量。代理识别请求并将请求发送到服务器。通过这种方式，内部客户端从不直接连接到外部服务器；因此，代理充当中介，与客户端和服务器双方进行通信。主要优势在于，代理软件可以根据数据包中的实际数据进行允许或拒绝流量的操作，而不仅仅是根据头部信息。

### ipchains 程序

*ipchains* 程序是一个用于在 Linux 服务器上管理数据包过滤的 Linux 工具。对 *ipchains* 的支持直接编译在 Linux 内核中，*ipchains* 工具从 *iptables* 中插入和删除规则。这些规则定义了数据包是被允许还是被拒绝发送给或接收自 Linux 系统。

## iptables 和 ipchains

*ipchains* 和 *iptables* 之间的一个区别在于，*iptables* 可以配置为有状态数据包过滤器。在使用 *iptables* 时，数据包内的头部会根据一组已知的规则（链）按顺序进行检查。如果数据包匹配某条规则，则根据指定内容（目标）对该数据包做出决定。如果未找到匹配项，则根据序列中的下一条规则检查该数据包。这一过程持续进行，直到所有规则都被处理完毕。此时，*iptables* 会查看 *ipchains* 来做出默认策略决定。

每个 *iptables* 表包含特定的链。filter 表包含 INPUT、OUTPUT 和 FORWARD 链。*nat* 表包含 PREROUTING、POSTROUTING 和 OUTPUT 链，用于只需过滤出站数据包的网络。*mangle* 表包含 INPUT、OUTPUT、FORWARD、PREROUTING 和 POSTROUTING 链，用于需要同时过滤入站和出站数据包的大型网络。

## ipchains 的使用

*ipchains* 用于阻止对 Linux 服务器特权端口的访问。通过阻止对所有入站流量的访问，管理员可以防止网络访问连接到网络的 Linux 工作站。

## 如何实施 iptables

### 程序参考：配置 iptables

要配置 iptables：

1. 以 root 身份登录。
2. 输入 `service iptables start` 以启动 `iptables` 服务。

4. 使用 `iptables` 管理规则。

# 实施安全审计

你已实施 iptables 以使 Linux 工作环境对用户更安全。你需要设置文件和身份验证审计，以便识别和追踪可能的安全漏洞。在本主题中，你将实施安全审计。
