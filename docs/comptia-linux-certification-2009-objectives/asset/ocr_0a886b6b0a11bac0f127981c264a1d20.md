# Configuring XOrg Server

**Before You Begin:**

+   1. You logged in as root in the GUI.
2. The terminal window is displayed.

**Scenario:**
Kevin, a user on your network wants to view the X Window of his system on the environment system, which is on the same network. You are assigned the task of setting up his system. You decide to configure the X server and check if it is in the proper runlevel. You decide to export the X session to the environment system.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Configure the boot runlevel. | a. Enter `vi /etc/inittab` to open the inittab file. |
| | b. Verify that the line **id:[runlevel]:initdefault:** reads **id:5:initdefault:** to boot in runlevel 5. |
| | c. Close the file. |
| 2. Export X sessions. | a. Enter **DISPLAY=192.168.0.2:0.0** to export the X session. |
| | b. Enter **exit** to close the terminal window. |
| | c. Choose **System→Log Out root** to log out of the system. |
| | d. In the message box, click **Log Out** to log out of the system. |
