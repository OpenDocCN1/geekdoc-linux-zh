# The syslogd Utility

The `syslogd` utility tracks remote and local system logs. Logs are characterized by their host name and program field. The settings for `syslogd` are configured using the `/etc/syslog.conf` file.

The `syslogd` utility provides a number of options to manage specific functions. Some of the frequently used options are listed in the table.

| Option | Used To |
| :----- | :------- |
| `-d` | Turn on the debug mode. |
| `-f file name` | Specify a new configuration file instead of `/etc/syslog.conf`. |
| `-m interval` | Specify a time interval between two lines. |
| `-r` | Enable the `syslogd` utility to receive messages from a network. |


# Syntax

The syntax of the `syslogd` utility is `syslogd [options]`.
