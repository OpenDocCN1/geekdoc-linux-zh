# # ACTIVITY 7-2
## Verifying Packages

# ### Before You Begin:

+   1. You have logged in as root in the GUI.
2. The terminal window is displayed.

# ### Scenario:

Your manager requested you to convert the previously used DOS and Mac files to UNIX format and ensure that the clients are able to access the Samba man pages. After ensuring that the applications are installed, you decide to verify that the packages are ready for use.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Check whether the dos2unix and samba-client packages are installed. | a. Enter `rpm -q dos2unix` to check whether the `dos2unix` package is installed.
<br>b. Observe that the `dos2unix - 3.1 - 27.1` package is installed.
<br>c. Enter `rpm -q samba-client` to check whether the `samba-client` package is installed.
<br>d. Observe that the `samba - client - 3.0.33 - 3.7.el5` package is installed. |
| 2. Verify the dos2unix package. | a. Enter `rpm -Vv dos2unix`
<br>b. Observe that there are no errors and six lines are displayed. |
| 3. Verify the samba-client package. | a. Enter `rpm -Vv samba-client`
<br>b. Observe that there are no errors and the files are listed followed by the directories.
<br>c. Enter `rpm -Vv samba-client \| wc -1` to count the number of lines.
<br>d. Observe that the command displays a total of 26 lines.
<br>e. Enter `clear` to clear the terminal screen. |
