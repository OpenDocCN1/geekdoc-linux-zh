# Disadvantages of Telnet

Telnet is not a very secure protocol because it transmits passwords as plain text. Telnet has largely been replaced by SSH because it offers better security.

# The /etc/xinetd.conf File

The /etc/xinetd.conf file is the configuration file for the xinetd daemon. It contains a list of services that are managed by the xinetd daemon. It is referenced by the daemon each time a request is sent for a service to be started or stopped. The file is divided into parts, with one part for each service containing the service settings. Services can be single threaded or multithreaded.
