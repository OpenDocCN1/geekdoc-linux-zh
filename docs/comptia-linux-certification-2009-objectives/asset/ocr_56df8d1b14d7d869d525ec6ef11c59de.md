+   2. Configure the web source using the source code.

+   a. Enter `cd httpd-2.2.11` to change the directory.

+   b. Enter
```
./configure --prefix=/etc/apache
```
to configure the httpd source file.

+   c. Enter `clear` to clear the terminal window.

+   d. Enter `make` to build the executable program.

+   e. Enter `clear` to clear the terminal window.

+   f. Enter `make install` to install the packages.

+   g. Enter `clear` to clear the terminal window.

+   3. Start the web server service and verify that the home page is displayed.

+   a. Enter `./httpd -d /etc/apache/ -k start` to start the httpd service.

+   b. Observe that the httpd service has started successfully.

+   c. Enter `firefox http://localhost` to launch the web browser from the terminal.

+   d. In the **Test Page for Apache Installation - Mozilla Firefox** window, observe that the message "It works" is displayed.

+   e. Close the **Test Page for Apache Installation - Mozilla Firefox** window.

+   f. On the terminal window, enter `clear` to clear the screen.
