+   4.  Enter  
    `swapon (device name)`  
    to activate the swap partition.

+   5.  Enter  
    `swapoff (device name)`  
    to deactivate the swap partition and convert it into a standard Linux filesystem.

# Procedure Reference: Format a Partition with a Filesystem

To format a partition with a filesystem:

+   1.  Log in as root in the CLI.  
    2.  Format a partition with a filesystem.  
    *   Enter `mkfs -t (filesystem type) /dev/(device name)(Partition number)` to create the specified filesystem on the specified partition of the device.  
    *   Or, enter `mke2fs [command options] /dev/(device name)(Partition number)` to create an ext2 filesystem on the specified partition of the device.
