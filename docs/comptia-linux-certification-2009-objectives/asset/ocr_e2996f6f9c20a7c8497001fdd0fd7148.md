# ## TOPIC B
# Verify Packages

In the previous topic, you managed packages using the RPM package manager. As a Linux+ system administrator you may have to verify and repair corrupt packages. In this topic, you will verify packages.

You will save time troubleshooting package installation and software problems if you know how to verify packages. You should also be able to verify the integrity of packages installed on your system.

# ### RPM Verification

RPM verification compares the existing packages with the RPM package database and returns missing or corrupt packages. Various options allow you to verify specific information in the package.

![](bbox=[0.12, 0.5, 0.66, 0.78])

*Figure 7-6: RPM is used to verify the state of the Samba package.*

RPM verification options are listed below.

| Option | Enables You To |
| :--- | :--- |
| `rpm -Va` | Verify all installed packages. |
| `rpm -V package name` | Verify a specific package. |
| `rpm -V (file name) (package_name)` | Verify a specific file in the package. |

# ### Syntax

The syntax for RPM verification is `rpm -V package_name`.
