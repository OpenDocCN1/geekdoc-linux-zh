
### 固定文件更新

每当插入或弹出卡片，或者当 `cardmgr` 工具接收到信号时，`stab` 文件都会由 `cardmgr` 工具进行更新。通常，`stab` 文件会创建在 `/var/state/pcmcia` 或 `/var/lib/pcmcia` 目录中，但如果这两个目录均不可用，则会在 `/var/run` 目录中找到它。

### pccardctl 工具

![](img/477ccb2f05b6ba1b2d563ea74f18c197_757_0.png)

`pccardctl` 工具取代了 `cardctl` 工具。它用于监控和控制 PCMCIA 插槽的状态。如果由 root 用户执行 `pccardctl`，则所有命令均可用。如果由受限权限的用户执行，则只能访问信息性命令。卡片控制命令列于下表。

| 命令 | 描述 |
| :--- | :--- |
| `status` | 显示当前插槽的状态标志。 |
| `config` | 显示插槽配置，包括电源设置、中断和 I/O 窗口设置以及配置寄存器。 |
| `ident` | 显示卡片识别信息，包括产品识别字符串、制造商 ID 代码和功能代码。 |
| `suspend` | 关闭插槽电源并随后禁用其电源。 |
| `resume` | 恢复插槽电源并重新配置以供使用。 |
| `eject` | 通知所有客户端驱动程序 PC 卡即将弹出，然后切断插槽电源。 |
| `insert` | 通知所有客户端驱动程序 PC 卡刚刚已插入。 |

> 如果命令仅应用于单个插槽，则应指定插槽编号；否则，所有插槽都会受到影响。

### 选择 PCMCIA 配置方案

你可以使用 `cardctl` 工具从多个 PCMCIA 配置方案中进行选择。当前方案名称作为设备地址的一部分传递给设备选项脚本，以便脚本可以据此选择不同的设置。

### USB

![](img/477ccb2f05b6ba1b2d563ea74f18c197_757_1.png)

通用串行总线 (USB) 是一种硬件接口标准，旨在为众多外设提供连接。USB 设备是与主机计算机通信的外设。常见的 USB 设备包括闪存盘、存储卡读卡器和数码相机。

### USB 标准

USB 2.0 是最常用的标准，其通信速率最高可达 480 Mbps。原始的 USB 1.1 标准仍然广泛存在于设备和系统中，其通信速率最高可达 12 Mbps。连接在 USB 1.1 集线器或端口上的 USB 2.0 设备，即使具备更快的速度，也只能以 USB 1.1 的速度进行通信。通常，在连接设备时操作系统会通知用户这一点。

USB 3.0，也称为 SuperSpeed USB，是最新发布的 USB 标准，其最大传输速率为 5.0 Gbit/s。它比 USB 2.0 标准快 10 倍，具有更高的电源效率，并且与当前使用的启用 USB 的设备向后兼容。

USB 电缆在性能下降前有一个最大距离限制。为了绕过此限制，可以使用一个或多个集线器创建链式连接，以达到所需的电缆长度。USB 1.1 的最大电缆长度为 3 米，而 USB 2.0 的最大长度为 5 米。在每种情况下，最多可以使用五个集线器来延长电缆长度。

### USB 即插即用功能

USB 设备还集成了即插即用技术，该技术允许设备在连接建立后立即进行自配置。

### 内核支持

在使用 USB 设备时，请确保你拥有包含 USB 支持的内核。内核 2.2.18 添加了对 USB 的有限支持，但最好运行 2.4.0 测试内核以及适用于下一个内核的相关补丁。请密切关注新版本并及时更新，因为它们经常发生变化。

### Linux 中的 USB

Linux 将 USB 设备视为 SCSI 磁盘，将第一个设备注册为 `/dev/sda`，其中“sda”表示第一个设备的第一个分区。

### FireWire

*FireWire* 是符合 IEEE 1394 标准的高速串行总线，类似于 USB，其速度最高可达 USB 的 30 倍。FireWire 更高的带宽使其非常适合数码相机和高速硬盘驱动器等设备。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_758_0.png)

### FireWire 电缆

在 FireWire 电缆中，电气触点位于 IEEE 1394 电缆连接器的结构内部。这有助于保护用户免受电击。这些电缆易于且安全使用。用户可以盲目地将它们插入系统。无需终端器，也无需设置手动 ID。

### 1394 子系统核心

1394 子系统的核心是一个模块，它管理高级和低级驱动程序，处理事务并触发事件。子系统的高级驱动程序（或例程）通过调用函数 `hpsb_register_highlevel` 向 IEEE 1394 模块注册自己。

### 回环设备

Linux 系统中的回环设备允许你将文件或一组文件作为块设备访问。它允许你将文件系统映像（如 ISO、CD 映像和软盘映像）挂载到硬盘上。你可以在 Linux 文件系统上创建一个包含文件系统和文件的软盘或 CD，而无需实际将其复制或刻录到介质上。之后可以获取软盘或 CD 的副本。回环设备也用于文件系统加密。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_758_1.png)

### 如何配置可移动硬件

**步骤参考：配置 USB 硬件**

要配置 USB 硬件：

- 2. 验证已创建 `/proc/bus/usb` 目录。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_759_0.png)

`/proc/bus/usb` 目录包含有关连接到系统的 USB 设备信息的子目录。

- 3. 安装设备的驱动程序。
- 4. 插入设备。

**步骤参考：配置 PCMCIA 硬件**

要配置 PCMCIA 硬件：

- 1. 检查内核中是否已编译 PCMCIA 模块。
- 2. 验证已创建 `/etc/pcmcia/config.opts` 文件。
- 3. 安装该设备所需的任何驱动程序。
- 4. 插入设备。
- 5. 使用 `cardmgr` 工具配置设备。

### 配置大容量存储设备

你已为 Linux 系统添加了可移动硬件。作为 Linux 管理员，你可能需要添加能够存储大量数据的存储设备。在本主题中，你将配置大容量存储设备。

在大型组织中，访问文件服务器的用户数量稳步增加。由于这种过载，性能下降且服务器挂起。如果服务器因某些问题突然关闭，系统会崩溃且数据丢失。如果使用多个大容量存储硬盘来维护数据，可以防止数据丢失。

### 大容量存储设备

硬盘或固定磁盘是一种存储设备，它们能在一个小而相对可靠的物理包中提供对大量数据的快速访问。

| 设备 | 描述 |

| | DVD-R 是一种可记录 DVD 格式，只能记录一次数据，一旦记录便在光盘上永久化。 |

### ATAPI

*AT 附加包接口 (ATAPI)* 是一种用于控制大容量存储设备的协议。ATAPI 提供用于硬盘、CD-ROM 驱动器、磁带驱动器和其他设备的命令。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_761_1.png)

### RAID

**定义：**

*独立磁盘冗余阵列 (RAID)* 是一种方法，用于在服务器或独立磁盘存储系统的多个硬盘的不同位置存储相同的数据。通过实施 RAID，磁盘阵列具有容错能力。在硬盘上启用 RAID 会提高其性能和可靠性。RAID 使用数据条带化和磁盘镜像技术来防止因硬盘崩溃而导致的数据丢失。它将数据分解为大小相等的块，然后根据 RAID 级别将每个块写入硬盘。RAID 可以由操作系统或 RAID 磁盘控制器卡实现。
