
## 身份验证

*身份验证*用于核实用户是否确实是其声称的身份。在数据通信中，对发送方进行身份验证是必要的，以确认数据来自正确的来源。接收方同样会经过身份验证，以确认数据发送到了正确的目的地。

确保身份验证的方法有几种。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_692_0.png)

| 方法 | 描述 |
|---|---|
| *已知主机文件 (known_hosts file)* | 当您连接到远程主机时，该主机会发送其公钥的主机和服务器密钥用于身份验证。您的系统会查找 known_hosts 文件以定位该主机密钥的条目，如果找到条目，您将获得访问权限。 |
| *SSH 服务器* | SSH 服务器会自动生成用于身份验证的公钥的主机和服务器密钥。为确保安全性，服务器密钥每小时会自动重新生成。 |
| *挑战握手认证协议 (CHAP)* | 一种安全身份验证协议，使用密钥对用户和密码信息进行加密并通过网络传输。支持使用点对点协议 (PPP) 封装的线路使用 CHAP。 |
| *密码认证协议 (PAP)* | 用于登录网络的安全身份验证协议。在使用 PAP 时，未加密的用户名和密码通过网络传输到服务器。此信息将与包含网络上所有用户和密码对的表进行核对。PAP 仅支持 PPP 线路。 |
| *Kerberos* | 一种由客户端/服务器应用程序使用的网络身份验证服务。Kerberos 为每个登录网络的用户创建一个密钥或票据。这些票据与消息一起嵌入，以标识发送者。 |

![](img/477ccb2f05b6ba1b2d563ea74f18c197_692_1.png)

### 身份验证要素

通过身份验证展示用户身份所使用的要素数量，决定了身份验证的有效性。三种类型如下：

- 单因素身份验证，提供你“知道”的内容，例如密码或 PIN。它基于从记忆中回忆信息或将其写下来。这种类型的身份验证效果最差。
- 双因素身份验证，将你“拥有”的内容与你“知道”的内容相结合。例如，你的 ATM 卡加上 PIN 码即可访问你的银行账户。
- 三因素身份验证，还通过生物特征识别来证明用户身份。它使用生理识别特征，如指纹、语音识别或签名识别。这是最佳类型的身份验证。

## 生物特征身份验证

为了提高系统的可靠性和用户的易用性（超越密码身份验证），可以引入生物特征身份验证。当这种类型的系统被添加到身份验证方案中时，它被视为强身份验证。之所以赋予“强”这一称号，是因为用户不仅通过数字方式被识别，还通过其生理特征被识别，例如通过指纹扫描、虹膜扫描或手部几何特征。

## sshd_config 文件

sshd_config 文件包含用于在不可靠网络上启用主机之间加密通信的选项。SSH 是通过 sshd 守护进程实现的。

## 加密

![](img/477ccb2f05b6ba1b2d563ea74f18c197_693_0.png)

加密是一种通过配置数据使其表现为未经授权用户无法解读的代码，从而控制用户访问信息的方法。对于授权用户而言，这些数据则以原始形式呈现。密码也可以与加密一起用于保护数据。有许多协议，如 SSH、SSL 和 SECURENET，可用于在网络上实施加密。

### 加密解决方案

加密计算机数据的授权用户必须拥有用于加密数据的密钥，才能对其进行解密。使用特定算法加密数据有不同的解决方案。下表描述了一些算法。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_694_0.png)

| 解决方案 | 描述 |
| :--- | :--- |
| **Blowfish** | Blowfish 是一种对称分组密码，提供强大的加密，并使用最大 56 字节（448 位密钥）的密钥大小。其特点包括：• 强大的密钥支持、处理和密码学功能。• 擦除文件和清除空闲磁盘空间的安全性。 |
| **3DES** | 3DES（发音为“triple dez”）是一种分组密码算法，可以使用单个秘密密钥加密和解密数据。3DES 使用三个阶段的 DES（数据加密标准），使其成为一个非常安全的选择。使用 DES 加密的任何内容都有 72,000,000,000,000,000（即 72 千万亿）种可能的密钥。 |
| **MD5** | **消息摘要算法 5 (MD5)** 是一个命令行实用程序，使用 MD5 算法生成和验证消息摘要（数字签名）。MD5 算法旨在用于数字签名应用，其中大文件必须以安全方式压缩，然后在公钥密码体制下使用私（秘密）钥进行加密。MD5 还用于检查文件的完整性。 |

### 随机数生成

**随机数生成**是一种加密方法，其中内核用于在传输之前为文件生成分配随机数。仅当接收方匹配这些数字时，传输才算完成。管理随机数生成的算法是伪随机数生成 (PRNG) 算法。在 Red Hat Linux 中，内核文件 /dev/random 和 /dev/urandom 充当随机数生成器。利用排列和组合的概念，这些内核能够从一个源数字生成具有数百万位数字的随机数。

## 加密散列

加密散列用于一种加密方法，其中任意数据被封装在指纹中，该指纹附加到文件上。指纹是一个固定的字符串，称为散列值、校验和或消息摘要。通过验证散列值可以检查文件中数据的真实性。当对文件进行任何修改时，其散列值也会随之改变。有各种算法，如 md2、md5、sha 和 sha1，实现了加密散列函数。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_695_1.png)

图 14-5：使用加密散列方法保护数据。

使用各种实用程序来检查文件的散列值。

| 实用程序 | 允许你 |
| :--- | :--- |
| sha1sum | 检查文件是否有不正确的 sha1 校验和。此实用程序的语法为 sha1sum --check {文件名} 。 |
| md5sum | 检查文件是否有不正确的 md5 校验和。此实用程序的语法为 md5sum --check {文件名} 。 |

## 对称加密

对称加密仅使用单个密钥进行，该密钥用于加密和解密。有各种执行对称加密的实用程序。

| 实用程序 | 功能 |
| :--- | :--- |
| passwd | 用于更改登录密码。当前登录的用户只能更改自己的登录密码，而不能更改其他用户的密码。但这不适用于 root 用户。在命令提示符下输入 passwd 命令时，系统会要求你输入当前密码，然后输入你想要设置的新密码。新密码在你下次登录系统时生效。 |
| gpg | 用于使用 GNU 隐私卫士 (GnuPG) 加密系统加密消息。该实用程序具有各种命令和选项。此实用程序的语法为 gpg {选项} {命令} {参数} 。 |
