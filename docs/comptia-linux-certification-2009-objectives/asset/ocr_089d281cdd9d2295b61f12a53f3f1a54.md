# Implementing Security Auditing

**Before You Begin:**
1. On *srvA*, you have logged in as root in the CLI.
2. The first CLI terminal is displayed.
3. Enter `cd /root` to navigate to the root directory.
4. Enter `clear` to clear the terminal screen.

**Scenario:**
Your need to implement security auditing on your network. You decide to output the dropped packets from the iptables firewall to a log file where it can be reviewed for possible intrusion attempts.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Set iptables to send possible intrusions to a log file. | a. Enter `iptables -N LOG_DROP` to create a chain named LOG_DROP.<br><br>b. Enter `iptables -A LOG_DROP -j LOG --log-tcp-options --log-level 3 --log-ip-options --log-prefix "[Dropped Packet] :"` to append a new rule to the LOG_DROP chain.<br><br>c. Enter `iptables -L` to view the rules.<br><br>d. Observe that the LOG rule is listed in the rules of the LOG_DROP chain.<br><br>e. Enter `iptables -A LOG_DROP -j DROP` to append a new rule to the LOG_DROP chain.<br><br>f. Enter `iptables -L` to view the rules.<br><br>g. Observe that the DROP rule is listed in the rules of the LOG_DROP chain.<br><br>h. Enter `service iptables save` to save the iptables rules. |
