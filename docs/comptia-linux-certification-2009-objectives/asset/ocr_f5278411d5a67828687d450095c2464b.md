+   4. Check the integrity of your system files using Tripwire.
a. Run the `tripwire` program with the `--check` option to create a report.
b. Enter `ls /var/lib/tripwire/report` to check if the report has been created.
c. Observe that file with extension `twr` is displayed.
d. Enter `/usr/sbin/twprint -m ⇒ r --twrfile /var/lib/tripwire⇒ /report/srvA-<yyyymmdd>⇒ -<hhmmss>.twr | less` to view the report.
e. After viewing two pages, press `q` to return to the command line.
f. Clear the screen.
