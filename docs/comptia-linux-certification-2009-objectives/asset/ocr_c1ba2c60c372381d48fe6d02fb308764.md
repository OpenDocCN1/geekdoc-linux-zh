# ## The switchdesk Command

The `switchdesk` command provides a simple method of switching among various desktop environments. To enable the `switchdesk` command, the packages `switchdesk-4.0.8-6.noarch.rpm` and `switchdesk-gui-4.0.8-6.noarch.rpm` have to be installed after the installation of the Linux operating system is complete. On running the `switchdesk` command from the terminal, the **Desktop Switcher** dialog box is displayed.
