# Configuring Routes

**Before You Begin:**
1. On srvB, you logged in as root in the CLI.
2. The first terminal is displayed.

**Scenario:**
You configured network connectivity and IP addresses on a new system. Now, you need to configure the router settings to connect to other computers on the network.

| What You Do | How You Do It |
| :--- | :--- |
| 1. Specify the router settings for automatic configuration of routes. | a. Enter `ifdown eth0` to stop the network interface service. |
| | b. Enter `cd /etc/sysconfig` to configure the default gateway. |
| | c. Enter `vi network` to open the file. |
| | d. Press Shift+G to go to the last line. |
| | e. Press O to switch to the insert mode and move to a new line. |
| | f. On the new line, type `GATEWAY=192.168.0.2` |
| | g. Press Esc to switch to the command mode. |
| | h. Save and close the file. |
