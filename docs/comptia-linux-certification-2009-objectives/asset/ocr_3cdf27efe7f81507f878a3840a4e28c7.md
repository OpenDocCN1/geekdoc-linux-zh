The `uniq` command provides various options that allow you to specify the nature of the output.

| Option | Description |
| :--- | :--- |
| -u | Displays only unique lines. |
| -d | Displays only duplicated lines. |
| -c | Displays lines prefixed by the number of occurrences. |

# ### Syntax

The syntax of the `uniq` command is `uniq` `[command options]` `{file name}`.

# ## Input and Output Redirection

When you want to redirect the contents of an existing file to another command for processing, the input and output redirection symbols can be used. The output redirection symbol > tells the shell to redefine standard output as a file. If the file does not exist, the shell creates it. The input redirection symbol < tells the shell to redefine standard input as something other than the keyboard input, usually a file.

For example, the `ls >list` command causes the shell to send the output of the `ls` command to a file named “list.”
