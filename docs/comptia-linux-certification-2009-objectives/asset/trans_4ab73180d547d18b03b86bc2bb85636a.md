

# apcupsd 包

apcupsd 包是一个提供 UPS 电源管理功能的软件包。在停电期间，在 UPS 的支持下，它允许计算机运行特定的时间段。但是，用户应在指定时间段到期前保存所有对文件所做的更改并关闭系统。如果时间到期，该包会自动执行系统的受控关闭。

# apcupsd.conf 文件

apcupsd.conf 文件是 apcupsd 包与 UPS 通信所需的配置文件。它包含有关添加到系统的 UPS 配置详情的指令。以下表格中列出的所有指令都应在配置文件中指定。

| 指令 | 描述 |
| :--- | :--- |
| UPSTYPE <i><UPS 类型></i> | 指定驱动程序的名称。值可以是 dumb、apcsmart、net、usb、snmp 或 test。 |
| UPSCABLE <i><UPS 电缆类型></i> | 指定系统使用的电缆类型。 |
| DEVICE <i><设备名称></i> | 指定用于 UPS 通信的设备。通常使用串行端口或 USB 设备进行通信。 |
| LOCKFILE <i><锁定文件的路径></i> | 指定需要为 USB 或串行端口创建锁定文件的目录路径。 |

# 系统电源状态

Linux 系统可能支持多种电源状态。部分电源状态列于以下表格中。

| 电源状态 | 描述 |
| :--- | :--- |
| 运行 (Working) | 系统完全可用。 |
| 睡眠 (Sleeping) | 系统看起来已关闭。电源消耗量根据系统电源的分配方式而减少。 |
| 软关机 (Soft Off) | 系统看起来已关闭，且电源消耗量极低。 |
| 机械关机 (Mechanical Off) | 系统已断电，没有电源消耗。系统需要完全重启才能完全可用。 |

# 如何配置电源管理

**操作步骤参考：配置 CPU 电源管理**

要配置 CPU 电源管理：

1. 切换到 `/proc/acpi/processor/CPU{CPU 编号}` 目录。
2. 使用 `cat info` 命令验证电源管理和降频功能是否已开启。
3. 使用 `cat power` 命令显示当前电源设置。
4. 验证您的机器是否有适当的可用状态。
    - 如果您使用的是台式电脑，请验证前两个 C1 和 C2 状态是否可用。
    - 如果您使用的是笔记本电脑，请验证所有三个状态是否可用。
5. 使用 `cat throttling` 命令显示当前降频设置。
6. 输入 `echo -n [throttle_state] > throttling` 命令以调整降频级别。

> 告知学生，您只能在具有多处理器的系统上配置电源。诸如降频和电源等某些选项无法在仅具有单处理器的系统中调整。

# PC 卡

PC 卡， formerly 被称为 PCMCIA，尺寸与信用卡相当，可用于存储、网卡、调制解调器以及其他用途。其标准和规范由个人计算机内存卡国际协会（PCMCIA）定义。

# PCMCIA 组织

PCMCIA 组织是一个成员联盟，旨在促进便携式计算机之间的互换性和兼容性。该联盟定义了 PC 卡的标准。

# 卡和插槽服务

当便携式计算机启动时，卡和插槽服务会被加载到内存中。此软件随 PC 和卡片一起提供。这两个软件层在 PC 卡插入便携式计算机时检测和提供支持。它们还管理热交换，并将事件更改传递给为特定卡编写的高层驱动程序。

插槽服务与 BIOS 交互以识别可用的插槽数量。它可以内置于 BIOS 中，也可以通过软件添加。当系统开启时，它检测到 PC 卡插入或移除的时刻。插槽服务与其上的卡服务协同工作，并直接与 PC 卡的控制器芯片通信。

当插槽服务识别出 PC 卡已插入时，卡服务会自动分配系统资源。卡服务管理 PC 卡所需的系统资源，例如中断请求（IRQs）、内存和 I/O 地址。此软件管理接口还与可能需要加载以配合 PC 卡工作的高层软件（如硬件驱动程序）协同工作。

# cardmgr 实用工具

cardmgr 实用工具监控 PCMCIA 插槽中的卡片插入和移除事件。当卡片插入时，该实用工具会在已知卡片数据库中查找该卡片。如果识别出该卡片，相应的设备驱动程序将被加载并与该卡片绑定。当卡片弹出时，如果可能，卡片的驱动程序将被卸载。

/var/run/stab 文件包含 PCMCIA 卡片的识别信息和设备驱动程序信息。它由 cardmgr 实用工具创建。设备驱动程序行由一系列制表符分隔的字段组成。这些字段在以下表格中进行了描述。

| 字段 | 描述 |
| :--- | :--- |
| 1 | 插槽编号 |
| 2 | 设备类（确定使用 /etc/pcmcia 中的哪个脚本来配置或关闭设备） |
| 3 | 驱动程序名称 |
| 4 | 当单个卡与同一驱动程序关联多个设备时，用于对设备进行编号 |
| 5 | 设备名称 |
| 6 | 主设备号（如果需要） |
| 7 | 次设备号（如果需要） |

## 任意命令

基于 PCMCIA 卡片配置数据库的内容，cardmgr 实用工具在适当卡片插入或移除时也可能执行任意命令。所有插入和移除事件、设备驱动程序加载和卸载、启动和关闭命令以及警告和错误都会记录在系统日志文件中。每个插槽的当前卡片和设备信息记录在 /var/state/pcmcia/stab 或 /var/lib/pcmcia/stab 文件中。

通常，当识别出卡片时，cardmgr 实用工具会向控制台发送哔声。当卡片成功配置时，也会生成哔声。如果这些步骤中任一步骤失败，则会生成音调较低的哔声。弹出卡片会产生单个哔声。当 cardmgr 实用工具收到 SIGHUP 信号时，它会重新加载其配置文件。当 cardmgr 实用工具收到 SIGTERM 信号时，它会关闭所有未忙状态的插槽并退出，但忙状态插槽的驱动程序将保持加载状态。如果设置了 PCMCIA_OPTS 环境变量，在读取主要的卡片配置文件后，将解析其内容。

## pcmcia 文件

存储在 /etc/pcmcia/config 目录中的 pcmcia 文件是一个卡片配置数据库。它在启动时由 cardmgr 实用工具读取。它定义了可供卡服务使用的资源，说明了如何加载和初始化设备驱动程序，并描述了特定的 PCMCIA 卡片。
