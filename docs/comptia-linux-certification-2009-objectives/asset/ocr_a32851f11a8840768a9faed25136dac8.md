# The grep Command

The grep command searches a file or list of files for a string and prints the lines that match the search string. For example, you could search the file hardware.txt for all instances of the word "motherboard." The `grep` command has various options that allow you to specify search criteria.

The following table lists the options of the `grep` command.

| Option | Used To |
| --- | --- |
| -h | Print matching lines without file names. |
| -w | Restrict the search to whole words only. |
| -c | Display a count of the number of matching lines and not the lines themselves. |
| -i | Ignore case while searching. |
| -l | List the file names that contain matching lines. |
| -n | Precede each line with the line number where it was found. |
| -s | Suppress the display of any error messages. |
| -e | Specify one or more patterns for searching. |

# Syntax

The syntax of the grep command is `grep [command options] {keyword} {file name}`.
