| Option | Enables You To |
|---|---|
| `rpm -ql package_name` | List the files in the package. |
| `rpm -qR package_name` | List the package dependencies. |
| `rpm -qa \| grep package_name` | Send the results of the rpm query command to the grep command to search the results for a specific package. |

# Syntax

The syntax of an RPM query is `rpm -q {what_packages} {what_information}`.

# How to Manage Packages Using RPM

# Procedure Reference: Install Packages

To install packages:

+   1. Download the rpm file you would like to install.
2. Install the package using the `rpm -ivh [file name.rpm]` command.
3. If necessary, download the dependency packages.

# Procedure Reference: Uninstall Packages

To uninstall packages:

+   1. Search for the rpm package you would like to uninstall using the `rpm -qi [package_name]` command.
2. Uninstall the rpm package using the `rpm -e [package_name]` command.
