+   4. Select the printer driver and set the remote printer as the default printer.

+   a. In the **Makes** list box, ensure that **Generic** is selected and click **Forward**.

+   b. In the **Models** list box, scroll down and select **PostScript Printer**.

+   c. In the **Drivers** list box, select the **foomatic: Generic - Postscript.ppd (recommended)** option and click **Forward**.

+   d. On the confirmation page, observe that a message "Going to create a new printer printer at smb://MYGROUP/SRVA/printer." is displayed.

+   e. Click **Apply** to add the printer.

+   f. Observe that in the **Remote Printers** section, a new printer, **printer@srva**, is added.

+   g. In the right pane, click **Make Default Printer** to make the printer as the default printer.

+   h. Close the **Printer configuration - localhost** window.
