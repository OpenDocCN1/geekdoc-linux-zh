## 如何配置磁盘配额

### 操作参考：为文件系统设置磁盘配额

要为文件系统设置磁盘配额：

1. 以 root 身份登录到 CLI。
2. 指定您要分配给用户的分区的用户配额。
   1. 输入 `vi /etc/fstab`。
   2. 在分区条目的第四列中，更改默认值。
      - 将 `defaults` 更改为 `defaults,usrquota` 以定义指定分区的用户配额。
      - 将 `defaults` 更改为 `defaults,grpquota` 以定义指定分组的组配额。
      - 将 `defaults` 更改为 `defaults,usrquota,grpquota` 以定义指定分区的用户和组配额。
   3. 保存并关闭文件。
3. 输入 `mount -o remount {挂载点}` 以重新挂载该分区。
4. 输入 `quotacheck -c {分区挂载点}` 以扫描磁盘使用情况并创建配额文件。

### 操作参考：管理系统中的配额服务

要管理系统中的配额服务：

1. 以 root 身份登录到 CLI。
2. 管理系统中的配额服务。
   - 输入 `quotaon [命令选项] {挂载点}` 以开启配额。
   - 输入 `quotaoff [命令选项] {挂载点}` 以关闭配额。

### 操作参考：为用户设置配额

要为使用者设置配额：

1. 以 root 身份登录到 CLI。
2. 为用户设置配额。
   - 使用 `edquota` 命令设置用户配额。
     1. 输入 `edquota [命令选项] {用户或组名}`。
     2. 指定块和 inode 的软限制和硬限制。
     3. 保存并关闭文件。
   - 输入 `setquota [命令选项] {用户或组名} {软块限制} (硬块限制) {软inode} (硬inode) [命令选项] /dev/{设备名称}{分区号}` 以使用 `setquota` 命令为用户设置配额。

### 操作参考：查看配额报告

要查看配额报告：

1. 以 root 身份登录到 CLI。
2. 查看配额报告。
   - 输入 `quota [命令选项] {用户或组名}` 以显示用户或组的配额报告。
   - 输入 `repquota [命令选项] {挂载点}` 以显示指定挂载点的配额报告。
   - 输入 `warnquota [命令选项] (挂载点)` 以根据 `/etc/warnquota.conf` 中的配置将配额报告作为邮件消息发送给用户。

## 故障排除策略

![](img/477ccb2f05b6ba1b2d563ea74f18c197_789_0.png)

故障排除策略是识别系统相关问题原因并解决其影响的行动计划。在故障排除过程中需要考虑各种准则。

| 准则 | 描述 |
| --- | --- |
| 分析问题 | 在尝试排除问题之前，尝试通过其症状（如错误消息）以及其他可用信息（如日志文件和配置文件）来识别问题。此外，检查相关服务是否正常工作。 |
| 备份数据 | 在实验配置文件、日志文件或其他重要数据的问题之前，建议进行备份，以避免信息丢失和问题的进一步复杂化。 |
| 排除可能的原因 | 观察问题是否与硬件、应用程序、进程或其他服务有关。尝试选择一个或多个症状并深入挖掘根本原因。消除根本原因将解决所有相关问题。 |
| 采用基本的解决问题的方法 | 在确定潜在原因后，在进行复杂的故障排除程序之前，先尝试解决该问题的基本方法。 |

### 基本故障排除模型

一些公司开发了系统且合乎逻辑的故障排除流程。遵循这些准则将帮助您快速高效地在网络上发现并纠正问题。一种故障排除模型将故障排除过程分为四个步骤：

1. 收集基本信息。
2. 制定行动计划。
3. 执行计划并隔离问题。
4. 记录解决方案。
