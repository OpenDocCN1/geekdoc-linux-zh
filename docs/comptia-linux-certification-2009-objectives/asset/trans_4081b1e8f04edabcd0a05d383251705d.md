
### 生成数字证书

1. 使用 openssl 命令生成数字证书。
    - A. 输入 `openssl req -newkey rsa:2048 -keyout {密钥文件的绝对或相对路径}` 以生成公钥或私钥对。
    - B. 输入 `openssl req -new {密钥文件的绝对或相对路径} -out {证书请求文件的绝对或相对路径}` 以生成证书签名请求。
        - C. 输入必要的信息，如国家名称、州、城市、组织名称、组织单位名称、服务器名称、电子邮件，如有必要，还包括挑战密码和可选的公司名称。
    - D. 输入 `openssl req -new -key {密钥文件的绝对或相对路径} -out {证书文件的绝对或相对路径} -x509` 以生成自签名证书。
        - E. 输入必要的信息，如国家名称、州、城市、组织名称、组织单位名称、服务器名称、电子邮件，如有必要，还包括挑战密码和可选的公司名称。

2. 使用 make 命令生成数字证书。
    - A. 输入 `make -C /etc/pki/tls/certs {文件名}.key` 以生成公钥或私钥对。
    - B. 输入 `make -C /etc/pki/tls/certs {文件名}.csr` 以生成证书签名请求。
    - C. 输入 `make -C /etc/pki/tls/certs {文件名}.crt` 以生成证书。
    - D. 输入 `make -C /etc/pki/tls/certs {文件名}.pem` 以在一个文件中生成密钥和证书。

## 主题 B：保护用户账户

你现在已熟悉加密和基础系统安全。你需要为用户提供安全的计算环境。在本主题中，你将保护用户账户。

鉴于 Linux 作为安全操作系统的声誉，人们可能会倾向于对用户安全采取随意的态度。然而，作为 Linux+ 管理员，重要的是要制定有助于在 Linux 用户社区中建立最佳实践的组织政策。这样做可以限制灾难的可能性，尤其是当你的公司用户群增长时。

### 环境文件

在 Linux 中，有几个可以自定义的环境文件。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_708_0.png)

| 文件 | 描述 |
| :--- | :--- |
| /etc/hosts.allow | 允许访问某些服务和主机。 |
| /etc/hosts.deny | 拒绝访问某些服务和主机。 |
| /etc/limits | 当系统安装了影子密码时，限制用户的资源。 |
| /etc/login.defs | 在具有影子密码的系统上设置用户登录功能。 |
| /etc/passwd | 显示用户的用户名、真实姓名、主目录、加密密码和其他信息。 |
| /etc/security | 标识 root 用户允许从中登录的安全终端。 |
| /var/log/secure | 跟踪用户登录。建议定期检查此文件。 |

### /etc/login.defs 文件

* /etc/login.defs* 文件与影子密码一起使用，用于设置初始路径和其他参数，包括用户必须更改密码的频率以及可接受的密码标准。

### 登录级别

在 Linux 中，你可以提供 root 级别或用户级别对资源的访问权限。默认情况下，root 用户具有系统中所有信息的登录权限，而其他用户的登录权限有限。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_708_1.png)

| 登录级别 | 描述 |
| :--- | :--- |
| Root 登录 | root 用户被视为一个特定的用户账户，其 UID 为 0。它具有系统中其他任何用户都不具有的权限。 <br> 具体而言，root 用户可以在系统中导航到任何位置，更改任何文件，并操纵系统控制，包括用户账户、存储设备和内核参数。 <br> 系统管理员通常拥有具有普通用户权限和 root 账户的自有用户账户。作为一般规则，你应该在从 root 用户账户工作之前，尽可能使用你自己的 UID 进行操作。 |
| 用户登录 | 创建用户账户时必须考虑到安全性。用户名或登录 ID 和密码存储在两个不同的文件中，/etc/passwd 和 /etc/shadow，并设置了受限的访问权限以增加安全性。 <br> 用户账户文件 /etc/passwd 被设置为除 root 用户外每个人都只读。 |

### Root 用户的别名

如果你使用的是 Bash shell，你可以将 root 创建为一个别名，作为一种预防措施。在这种情况下，别名是 `.bashrc` 文件中的一个条目，你可以在其中为特定的默认命令定义额外的操作。例如，用于删除或清除文件的 `rm` 命令可以赋予一个别名，该别名会根据你设定的标准提示你提供额外信息。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_709_0.png)

### su 命令

*替代或切换用户* 命令 (*su*) 用于更改登录会话的所有权，而无需注销。它通常用于在普通用户和 root 用户之间切换所有权，以更改管理工作的访问权限。
