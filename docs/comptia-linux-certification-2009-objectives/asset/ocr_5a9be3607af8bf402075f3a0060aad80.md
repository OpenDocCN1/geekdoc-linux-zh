3. Enable password protection for GRUB.

+   a. Enter `cd /boot/grub` to navigate to the `/boot/grub` directory.

+   b. Enter `vi grub.conf` to open the grub.conf file.

+   c. Enter `/hid` to go to the **hiddenmenu** line.

+   d. Press **O** to switch to the insert mode and move to a new line.

+   e. On the line below the **hiddenmenu** option, type `password --md5 password`

![](bbox=[0.39, 0.35, 0.75, 0.41])

+   f. Press **Esc** to switch to the command mode.

+   g. Save and close the file.

4. Check whether password protection is enabled for GRUB.

+   a. Enter `reboot` to restart the system.

+   b. On the **GRUB** graphical splash screen, press **A**.

![](bbox=[0.39, 0.6, 0.75, 0.68])

+   c. Press **P** to enter the password, to edit the GRUB configuration.

+   d. At the **Password** prompt, enter `p@ssw0rd`

+   e. Press **E** to edit the GRUB configuration.

+   f. Press **B** to boot with the default setup.
