# **Scenario:**

An employee, Pat, asked your manager, John, to make his password more secure. John requests you to make Pat’s password more secure and add additional rules to the firewall to allow Samba to communicate with the system. Update Pat’s password and adjust the firewall rules.

+   1.  Using the `passwd` command, update the password of **Pat**.

+   2.  View the existing rules and add three new rules to the iptables firewall.

```
iptables -A INPUT  -p udp  -s 192.168.0.0/255.255.255.0 -d 192.168.0.1/32 --dport 137 -j ACCEPT
iptables -A INPUT  -p udp  -s 192.168.0.0/255.255.255.0 -d 192.168.0.1/32 --dport 138 -j ACCEPT
iptables -A INPUT  -p tcp  -s 192.168.0.0/255.255.255.0 -d 192.168.0.1/32 --dport 139 -j ACCEPT
```
