# ## ACTIVITY 8-4
### Accessing Drivers Through /dev

# **Before You Begin:**
On *srvA*, the GUI login screen is displayed.

# **Scenario:**
Your company has a server to which many users log in with their user account to carry out their day-to-day operations. Due to the unscheduled emergency maintenance on the server, you may need to reboot the system if necessary. You now need to send a message to all the logged in users using the device node, so that they can save their data, complete their tasks, and log out of their systems.

| What You Do | How You Do It |
|---|---|
| 1. View information about users who have currently logged in. | a. Log in as **root** in the GUI.<br>b. Choose **Applications→Accessories→Terminal** to open the terminal.<br>c. Enter `who` to check who is logged in to which terminal.<br>d. Observe the list of current users displayed as the output. |
| 2. Send messages using the device node in the `/dev` directory. | a. Enter `echo "Please save your work, the system will be down for⇒maintenance in 30 minutes" > /dev/tty1` to alert all current users using the specified device node.<br>b. Enter `clear` to clear the terminal window.<br>c. Switch to the CLI.<br>d. Observe that the echoed message is displayed on the screen. Press **Enter** to return to the login prompt.<br>e. Enter `clear` to clear the terminal screen. |
