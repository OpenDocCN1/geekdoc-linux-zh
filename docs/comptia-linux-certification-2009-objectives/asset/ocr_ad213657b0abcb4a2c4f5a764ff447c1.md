# Procedure Reference: Scan Ports Using nmap

To scan ports using nmap:

+   1. Install the nmap RPM file.  
```rpm -ivh nmap-(version),(release).rpm```
2. Use the nmap command to view information about open ports.
```nmap IP address```

# Options for the nmap Command

Some frequently used nmap command options are given in the following table.

| Use This Option | To Do This |
|---|---|
| sT | Scan TCP ports |
| sU | Scan UDP ports |
| p range of ports | Scan specific ports |
| F | Search only in the nmap-services file, which contains infor-mation about ports |
