
## SCSI ID

每个 SCSI 设备都有一个唯一的 SCSI ID（也称为 SCSI 地址）分配给它，以便主适配器能够识别正在与其通信的设备。最低的 SCSI ID 为 0，最高为 7 或 15；窄 SCSI 的范围是 0 到 7，宽 SCSI 的范围是 0 到 15。优先级基于驱动器 ID 分配，7 为最高优先级。

通常情况下，提供系统与 SCSI 之间接口的**主总线适配器（HBA）**被分配 ID 为 7。较慢的设备应分配较高的优先级 ID，以防止较快的设备独占总线。因此，主硬盘应分配较低的编号，而慢速设备（如磁带驱动器）应分配较高的 ID 编号。窄 SCSI 的优先级顺序为 7, 6, 5, 4, 3, 2, 1, 0；宽 SCSI 的优先级顺序为 7, 6, 5, 4, 3, 2, 1, 0, 15, 14, 13, 12, 11, 10, 9, 8。SCSI ID 通过 SCSI 设备上的跳线或 DIP 开关设置。

## 如何识别常见的硬件组件和资源

### 操作参考：识别硬件组件和资源

要识别硬件组件和资源：

- 以 root 身份登录。
- 切换到 /proc 目录。
- 记录硬件组件以供将来参考。
  - 使用 `cat cpuinfo` 命令显示 CPU 信息。
  - 使用 `cat devices` 命令显示设备信息。
  - 使用 `cat partitions` 命令显示分区信息。
  - 使用 `df -h` 命令显示当前硬盘大小和使用情况。
  - 使用 `cat interrupts` 命令显示当前 IRQ 资源。

## 主题 B
### 配置电源管理

您已识别出可用于 Linux 系统的硬件组件和资源。拥有必要的硬件并不能确保系统完全正常工作。您需要保持硬件组件处于运行状态，并确保在停电时安全关机。在本主题中，您将配置电源管理选项。

电压下降或突然断电都可能导致系统崩溃。虽然意外断电的风险比以前小，但确保正常关机对于任何系统管理员的安心来说都是很有价值的贡献。

### 电源管理

高效的电源管理需要硬件和软件解决方案的结合。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_749_0.png)

| 解决方案 | 描述 |
| :--- | :--- |
| **高级电源管理 (APM)** | APM 读取 `/proc/apm` 文件，其中提供了电池状态信息。APM 允许机器处于*待机*或*挂起*模式。它适用于 APM BIOS 笔记本电脑。可以安装 *apmd* 包以启用用户友好的输出。 |
| **高级配置与电源接口 (ACPI)** | ACPI 规范为 APM 提供了替代方案。它是一个基于 BIOS 的电源管理系统，为 CPU 和设备提供电源。ACPI 在笔记本电脑、台式机和服务器的上建立了行业标准电源管理。ACPI 规范是操作系统定向电源管理 (OSPM) 的关键组件。ACPI 操作系统接管电源管理和即插即用功能，取代了传统 BIOS 接口。 |
| **不间断电源 (UPS)** | UPS 执行三项主要功能：<br> 1. 它充当电源滤波器，平滑电压波动，如可能具有破坏性的尖峰。<br> 2. 在突然的短暂断电事件（如电压暂降）发生时，它提供有限的滞留时间。<br> 3. 它通过允许您以正确的方式关闭计算机，从而防止或最大限度地减少文件系统损坏。 |

**apmd**

高级电源管理守护进程（apmd）是一个监控守护进程，用于控制 APM 系统。

### ACPI 功能领域

ACPI 规范涵盖了各种功能领域。其中一些在下表中列出。

![](img/477ccb2f05b6ba1b2d563ea74f18c197_750_0.png)

![](img/477ccb2f05b6ba1b2d563ea74f18c197_750_1.png)

| **功能领域** | **描述** |
| :--- | :--- |
| 系统电源管理 | ACPI 定义将计算机设置进入和退出系统睡眠状态的机制。它还提供了任何设备唤醒计算机的通用机制。 |
| 设备电源管理 | ACPI 表描述主板设备、其电源状态、设备连接的电源平面以及将设备设置在不同电源状态的控件。这使操作系统能够根据应用程序使用情况将设备设置为低功率状态。 |
| 处理器电源管理 | 当操作系统空闲但未睡眠时，它将使用 ACPI 描述的命令将处理器设置为低功率状态。 |
| 系统事件 | ACPI 提供了一种通用事件机制，可用于系统事件，例如热事件、电源管理事件、对接、设备插入和移除等。该机制非常灵活，并不专门定义如何将事件路由到核心逻辑芯片组。 |

### ACPI 电池管理

电池管理策略涵盖 APM BIOS 和 ACPI 操作系统。ACPI 兼容的电池设备需要智能电池子系统接口（由操作系统通过嵌入式控制器接口直接控制）或控制方法电池接口。控制方法电池接口完全由 ACPI 机器语言 (AML) 控制方法定义，允许 OEM 选择任何类型的电池和任何由 ACPI 支持的通信接口。电池必须符合其接口的要求，这些要求在接口中或其他适用标准中描述。

### 改变电池行为

操作系统可能会选择改变电池的行为，例如，通过调整低电量或电池警告触发点。当存在多个电池时，电池子系统不需要从单独电池的数据中执行复合电池的综合。在电池子系统未从单独电池的数据中综合出复合电池的情况下，操作系统必须提供这种综合。
