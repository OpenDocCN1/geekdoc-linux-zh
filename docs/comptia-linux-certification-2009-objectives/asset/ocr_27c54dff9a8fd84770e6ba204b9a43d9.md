# ## The X Protocol

The *X protocol* is the standard protocol used by clients and servers in the X Window system. Using this protocol, requests for window operations can be exchanged.

# ## X Clients

**Definition:**

An *X client* is an application that is written with the aid of the Xlib library, which gives programs access to any X server. An X client sends requests to the X server for a certain action to take place, for instance, to create a window. The X server sends the event that the X client is expecting, in response to the request. An X client also receives errors in requests from the server. There can be more than one X client sending requests to the X server.
