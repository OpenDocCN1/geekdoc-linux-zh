## 2. 非对称加密
*非对称加密*是通过对密钥对中的两个密钥进行操作来实现的。其中一个密钥用于加密，另一个密钥用于解密。

![img/477ccb2f05b6ba1b2d563ea74f18c197_696_1.png](img/477ccb2f05b6ba1b2d563ea74f18c197_696_1.png)

![img/477ccb2f05b6ba1b2d563ea74f18c197_696_2.png](img/477ccb2f05b6ba1b2d563ea74f18c197_696_2.png)

非对称加密涉及两个主要协议：协议 1 和协议 2。一次只能实现一个协议。

### 3. 协议说明
| 协议 | 说明 |
| :--- | :--- |
| 协议 1 | 在协议 1 中，发送方和接收方之间仅交换一个密钥。 |
| | 1. 接收方首先生成一个密钥对，该密钥对包含公钥和私钥。 |
| | 2. 然后，请求以加密形式发送给发送方，并附带接收方的公钥。私钥由接收方保留。 |
| | 3. 发送方收到请求后，验证接收方发送的公钥，然后以加密形式返回所需信息，并附带接收方的公钥。 |
| | 4. 接收方收到其公钥附带的信息，并通过用其私钥验证公钥来解密信息。 |
| 协议 2 | 在协议 2 中，数字签名与密钥加密一起使用。数字签名是在发送方的消息摘要被加密时创建的 unique ID。 |
| | 1. 发送方首先生成一个密钥对，该密钥对包含公钥和私钥。使用私钥和消息摘要，发送方生成一个数字签名。 |
| | 2. 公钥传输到网络上的所有系统。然后由接收方向发送方发送请求。 |
| | 3. 发送方收到请求后，以加密形式返回信息，并附带其数字签名。 |
| | 4. 接收方收到信息后，通过用其公钥验证发送方的数字签名来解密信息。 |

### 4. 非法公钥
非法公钥是由未经授权的用户生成的，用于绕过公钥密码学。这些密钥被用于解密他们本不应访问的信息。可以通过使用公钥指纹、组建信任组以及通过受信任的证书颁发机构发行数字证书来防止生成非法密钥。

### 5. 数字证书类型
数字证书是一种对称加密方法。数字证书主要有两种类型。

![img/477ccb2f05b6ba1b2d563ea74f18c197_698_0.png](img/477ccb2f05b6ba1b2d563ea74f18c197_698_0.png)

| 证书类型 | 说明 |
| :--- | :--- |
| 证书颁发机构 | *证书颁发机构证书* 是由共同且受信任的证书颁发机构（CA）在收到证书签名请求（`csr`）后生成的。使用此方法的优点是可以防止生成非法数字证书。 |
| 自签名 | *自签名证书* 由用户自己生成，并将用户的公钥作为签名者包含在内。因此，任何用户都可以创建自签名证书。但是，此证书并不保证用户或组织的身份。 |

### 6. 软件包完整性
Linux 中的每个软件包都被分配一个公钥，该公钥随软件包一起安装。*软件包完整性*是指检查软件包中这些公钥的方法，以确保软件包来源于受信任的供应商。在安装软件包之前必须执行软件包完整性测试，因为从不可靠来源安装软件包可能导致安装不当和病毒攻击。`yum` 命令始终从 Red Hat 在线存储库安装软件包及其公钥。

![img/477ccb2f05b6ba1b2d563ea74f18c197_698_2.png](img/477ccb2f05b6ba1b2d563ea74f18c197_698_2.png)

可以使用 `rpm` 命令来检查文件完整性。

| 命令 | 允许你执行的操作 |
| :--- | :--- |
| `rpm --verify` *package name* | 验证软件包是否已安装。 |
| `gpg --import */etc/pki/rpm-gpg/RPM-GPG-KEY-redhat*` | 将公钥导入到 rpm 数据库中。 |
| `rpm --checksig` *package name* | 检查软件包是否具有有效签名。 |
| `rpm --addsig` *package name* | 为软件包分配有效签名。 |

### 7. RADIUS
远程认证拨号用户服务（RADIUS）是一种客户机/服务器协议，用于促进通过网络进行集中式的认证、授权和计费。用户信息存储在一个中央数据库中，该数据库由所有远程服务器共享。当用户发送请求访问服务或资源时，RADIUS 使远程访问服务器能够与中央服务器通信，以验证用户的真实性。它通常利用存储在服务器 `/etc/passwd` 文件中的用户登录名和密码来验证用户的凭证。它允许通过 MD5 算法加密密码来安全地传输密码。RADIUS 服务器被互联网服务提供商（ISPs）广泛使用。

### 8. RADIUS
远程认证拨号用户服务（RADIUS）是一种客户机/服务器协议，用于促进通过网络进行集中式的认证、授权和计费。用户信息存储在一个中央数据库中，该数据库由所有远程服务器共享。当用户发送请求访问服务或资源时，RADIUS 使远程访问服务器能够与中央服务器通信，以验证用户的真实性。它通常利用存储在服务器 `/etc/passwd` 文件中的用户登录名和密码来验证用户的凭证。它允许通过 MD5 算法加密密码来安全地传输密码。RADIUS 服务器被互联网服务提供商（ISPs）广泛使用。

### 9. 作为网络访问服务器的 RADIUS 服务器
当网络中包含多个远程访问服务器时，你可以将其中一个服务器配置为 RADIUS 服务器，并将所有其他服务器配置为 RADIUS 客户端。RADIUS 客户端将所有认证请求传递给 RADIUS 服务器进行验证。用户配置、远程访问策略和使用日志记录可以集中在 RADIUS 服务器上。在此配置中，远程访问服务器通常被称为网络访问服务器（NAS）。

### 10. 如何实现加密服务

#### 10.1 操作参考：配置加密
要配置加密：

1.  以 root 身份登录。
2.  输入 `vi /etc/{application}/{configuration file}` 打开文件。
3.  定位包含加密详情的行。
4.  如有必要，取消该行的注释。
5.  修改该行以更改加密类型。
6.  保存文件并退出编辑器。
7.  重新启动应用程序或设备的服务，以使更改生效。

#### 10.2 操作参考：实施密码服务
要实施密码服务：

1.  以 root 身份登录。
2.  实施密码服务。
    -   输入 `openssl rand` *Options* *Number of pseudo-random bytes* 生成一个随机数。
    -   或者，生成一个消息摘要。
    -   输入 `sha1sum [command options] {File Name}` 计算并检查 SHA1 消息摘要。
    -   输入 `md5sum [command options] {File Name}` 计算并检查 MD5 消息摘要。
    -   输入 `openssl dgst {Message digest options} {File Name}` 输出所提供文件的消息摘要。
    -   使用 `gpg` 命令实施对称加密。
    -   输入 `gpg --symmetric {File Name}` 使用对称加密对文件进行加密。
    -   输入 `gpg -d {File Name}` 使用 `gpg` 命令解密加密文件。
    -   使用 `openssl` 命令实施加密。
        -   a. 输入 `openssl enc -e -salt -{bf|des3|cast5-cbc} -in {Absolute or relative path of file to be encrypted} -out {Absolute or relative path of encrypted file}` 对文件进行加密，并将输出存储在另一个文件中。
        -   b. 在提示时输入对称加密密码。
        -   c. 输入 `openssl enc -d -{bf|des3|cast5-cbc} -in {Absolute or relative path of encrypted file} -out {Absolute or relative path of decrypted file}` 对文件进行解密，并将解密的数据存储在另一个文件中。
        -   d. 在提示时输入加密密码。

#### 10.3 操作参考：使用 rpm 命令验证软件包完整性
要使用 `rpm` 命令验证文件完整性：

1.  以 root 身份登录。
2.  验证软件包完整性。
    -   输入 `rpm --verify {Package Name}` 报告与原始 rpm 版本不同的文件。
    -   输入 `rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-*` 导入 GPG 密钥以将其添加到软件包中。
    -   输入 `rpm --checksig {Package Name}` 验证 rpm 软件包是否由 Red Hat 打包。

#### 10.4 操作参考：生成数字证书
要生成数字证书：

1.  以 root 身份登录。
2.  使用 `openssl` 命令生成密钥。
    -   A. 输入 `openssl genrsa -out {Absolute or relative path of key file} {Key size}` 生成公钥或私钥对。
    -   B. 输入 `openssl req -new -key {Absolute or relative path of...`
