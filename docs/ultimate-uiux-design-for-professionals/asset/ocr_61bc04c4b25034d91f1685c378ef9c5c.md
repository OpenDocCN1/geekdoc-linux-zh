# Example:

Here are some code samples for Fluid Grid Layouts:

```
.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
}
.column {
  float: left;
  width: 50%; /* Each column takes up half of the container’s width */
  padding: 10px;
}
```
