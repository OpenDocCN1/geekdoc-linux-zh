# Example:

Here are the code snippets for creating adaptive layouts:

```
.nav-menu {
  display: none; /* Hide menu by default */
}
@media (min-width: 768px) {
  .nav-menu {
    display: block; /* Show menu on larger screens */
  }
}
```

In this illustration, the .nav-menu is visible on larger screens and hidden on screens that are smaller than 768 pixels. By using an adaptable strategy, you can improve usability and accessibility for various user scenarios by providing distinct navigation options dependent on the size of the device.
