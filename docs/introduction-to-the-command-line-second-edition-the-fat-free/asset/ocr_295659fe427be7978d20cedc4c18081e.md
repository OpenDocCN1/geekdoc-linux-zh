**Purpose:** Clear the contents of the current screen.

**Usage syntax:** `clear`

The **clear** command clears the contents of the terminal screen. This is useful for uncluttering the display after you have executed several commands and are preparing to move to the next task. The example above demonstrates the before and after effects of the **clear** command. While clearing the screen after each command isn't necessary, it does make it easier to read the information on the display.

> > CTRL + L is a keyboard shortcut to clear the screen in the Bash shell. See Appendix A for more information about Bash shortcut keys.
