# 1 lsd

**Purpose:** List hardware on AIX systems.

**Usage syntax:** `lsdev [OPTIONS]`

```
# lsdev

et1           Defined       1J-08       IEEE 802.3 Ethernet Network Interface
fd0           Available     01-D1-00-00 Diskette Drive
```

Listing devices on AIX with Isdev

**1sdev** displays information about hardware installed on AIX systems. The above example displays the typical output of this command which includes information about hardware installed on the local system.

**Common usage examples:**

+   - `1sdev` \| Display a simple hardware listing
