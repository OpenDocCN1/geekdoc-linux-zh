# dmidecode

Purpose: Display detailed information about devices on the system.

Usage syntax: dmidecode [OPTIONS]

```
# dmidecode

    ROM Size: 64 KB

        PNP is supported

    Manufacturer: VMware, Inc.

```

![](bbox=[0.34, 0.62, 0.66, 0.65])

dmidecode displays a detailed list of devices on the system. The above example demonstrates the typical output of this command which includes verbose information about the system's hardware.

> **Tip** *The output of the dmidecode command can be quite lengthy. Typing dmidecode|more will display the output one page at a time.*

Common usage examples:

dmidecode  | Display detailed information about devices on the system
