# pgrep

**Purpose**: Find processes by name.

**Usage syntax**: pgrep [OPTIONS] [NAME]

```
$ pgrep apache
3952
4075
4076
4077
4078
4079
```

![](bbox=[0.25, 0.31, 0.83, 0.32])

The pgrep command displays all processes matching the specified name. In the above example the PIDs for the apache web server are displayed. This is the equivalent of typing ps -el|grep apache and is provided as a shortcut to produce the same results.

The -l option can be used with pgrep to display the full process name for each PID as demonstrated in the next example.

```
$ pgrep -l apache
3952 apache2
4075 apache2
4076 apache2
4077 apache2
4078 apache2
4079 apache2
```

![](bbox=[0.25, 0.68, 0.83, 0.69])

**Note** Some systems may use the pidof command in place of the pgrep command.

Common usage examples:

+   1. pgrep [NAME]
+   2. pgrep -1 [NAME]
+   3. pgrep -P [PPID]
+   4. pgrep -c [NAME]

+   1. Display PIDs matching the specified name
+   2. Display the process name in addition to the PID
+   3. Display all child processes of the specified PPID
+   4. Display the total number of matching processes
