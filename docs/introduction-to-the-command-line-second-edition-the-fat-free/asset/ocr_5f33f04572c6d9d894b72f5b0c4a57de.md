# inmod / rmmod

**Purpose:** Install/remove kernel modules.

**Usage syntax:** insmod [MODULE]

```
# insmod /lib/modules/2.6.24-7-server/kernel/drivers/block/floppy.ko
# 1smod | grep floppy
floppy 59332 0
```

Loading a module into the kernel

The **insmod** command is used install to kernel modules on Linux systems. The above example demonstrates using **insmod** to install the `floppy.ko` module, which adds support to the system for floppy disk drives.

The **rmmod** command unloads modules from the kernel. The next example demonstrates removing the previously loaded `floppy.ko` module using the **rmmod** command.

**Usage syntax:** rmmod [MODULE]

```
# rmmod floppy
```
