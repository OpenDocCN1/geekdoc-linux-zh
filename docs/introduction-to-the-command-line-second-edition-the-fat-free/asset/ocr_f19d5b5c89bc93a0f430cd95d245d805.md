# # killall

**Purpose:** Terminate all processes with the specified name.

**Usage syntax:** `killall [OPTIONS] [NAME]`

```
```
# pgrep -l apache2
3952 apache2
4075 apache2
4076 apache2
4077 apache2
4078 apache2
4079 apache2
# killall apache2
```
```

Terminating processes by name using the killall command

The `killall` command terminates all processes that match the specified name. This can be helpful if you have several processes with the same name that you need to kill. In the above example, multiple processes related to the *apache2* service are terminated using `killall`.

> **Tip**
> *The *-i* parameter can be used with `killall` to prompt for confirmation before terminating each process. This is recommended as it helps prevent killing the wrong process due to typos.*

**Common usage examples:**

+   - `killall [NAME]` Terminate all processes with the specified name
+   - `killall -i [NAME]` Prompt for confirmation before killing processes
