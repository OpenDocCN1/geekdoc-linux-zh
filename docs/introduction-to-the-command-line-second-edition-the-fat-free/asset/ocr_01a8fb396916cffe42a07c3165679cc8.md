# mksysb

Purpose: Create a backup image of an AIX system.

Usage syntax: mksysb [OPTIONS] [DEVICE/FILE]

```
# mksysb -i /dev/rmt0

Creating information file (/image.data) for rootvg.

Creating list of files to back up.

Backing up 64981 files....................................... 51767 of 64981 files (79%)..

64981 of 64981 files (100%) 0512-038 mksysb: Backup Completed Successfully.

Creating a mksysb backup on AIX
```

The **mksysb** command creates a backup image of an AIX system. This image can be used to restore the base operating system in the event of system failure.

In the above example a **mksysb** system image is written to the `/dev/rmt0` tape device.

> **Note**
> **mksysb** is not a substitute for a traditional backup as is does not include files outside of the base operating system. Databases, 3rd party software, etc. are not backed up in a **mksysb** image. These files should be backed up separately using another method (such as the **tar** command.)

**Common usage examples:**
`mksysb -i [DEVICE/FILE]` | Create a system image backup
