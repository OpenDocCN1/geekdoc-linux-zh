Purpose: Install/remove Solaris packages.

```
**Usage syntax:** `pkadd [OPTIONS] [PATH]`

Installing a software package on Solaris
```

The `pkadd` command installs software packages on Solaris systems. The example above demonstrates using `pkadd` to install packages from the Solaris installation media.

The `pkgrem` command removes packages on Solaris systems. The next example demonstrates removing a package using `pkgrem`.

```
**Usage syntax:** `pkgrem [OPTIONS] [PACKAGE]`
```
# pkgrem SUNWapch2r
The following package is currently installed:
SUNWapch2r Apache Web Server V2 (root)
(i386) 11.10.0,REV=2005.01.08.01.09
Do you want to remove this package? [y,n,?,q]
...
Removal of <SUNWapch2r> was successful.
```
Removing a package on Solaris
```

Common usage examples:

| `pkadd -d [PATH]` | Install packages from the specified location |
|---|---|
| `pkgrem [PACKAGE]` | Remove the specified package |
