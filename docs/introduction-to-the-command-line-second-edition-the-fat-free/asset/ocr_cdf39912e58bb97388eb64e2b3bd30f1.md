# nfsstat

Purpose: Display NFS statistics.

Usage syntax: nfsstat [OPTIONS]

![](bbox=[0.1, 0.19, 0.9, 0.69])

nfsstat displays NFS utilization statistics. This can be helpful for monitoring performance of NFS services. The above example shows various utilization indicators for the NFS client and server running on the local system
