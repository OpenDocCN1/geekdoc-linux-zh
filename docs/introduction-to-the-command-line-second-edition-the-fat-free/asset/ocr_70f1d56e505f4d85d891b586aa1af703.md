# iostat

**Purpose:** Display network interface statistics.

**Usage syntax:** `iostat` `[DELAY]` `[COUNT]`

![](bbox=[0.09, 0.18, 0.89, 0.41])

`iostat` displays network interface statistics. It can be used to monitor network interface activity over a period of time. In the above example, executing `iostat 2 10` displays interface statistics every two seconds for ten iterations.

**Note**  
If no arguments are specified, `iostat` will continuously display network utilization until interrupted (by pressing **CTRL + C**).

**Common usage examples:**

| `iostat` | Continuously display network utilization |
| --- | --- |
| `iostat` `[DELAY]` | Update results at the specified interval |
| `iostat` `[DELAY]` `[COUNT]` | End after reaching the specified count |
