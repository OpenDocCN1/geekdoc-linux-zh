# ## vmstat

**Purpose:** Display virtual memory usage information.

**Usage syntax:** vmstat [OPTIONS] [DELAY] [COUNT]

```
    # vmstat 2 10
    r b swpd     free    buff cache  si so bi bo in cs us sy id wa
    0 0 88 79260 149184 7400704  0  0  0  93  1  4 0 2 97  0

    0 0 88 78872 149184 7400704  0  0  0  1828 259 3275 0  3 97  0
    0 0 88 78872 149184 7400704  0  0  0  62 145 3031 0  4 96  0
    0 0 88 78748 149184 7400704  0  0  0  0 114 2965 0  2 98  0
    0 0 88 78452 149184 7400704  0  0  0  438 150 3170 0  3 97  0
    0 0 88 78004 149184 7400704  0  0  0  0 114 3073 0  3 97  0
    0 0 88 77762 149184 7400704  0  0  0  130 306 4469 0  5 95  0
    0 0 88 77260 149184 7400708  0  0  0  52 130 2864 0  3 97  0
```

The **vmstat** command displays virtual memory statistics. In the above example, executing **vmstat 2 10** instructs the program to display results in two second intervals and exit after displaying 10 lines. If the delay and count parameters are omitted, **vmstat** will display one line of results and then terminate.

> > **Tip** The -Sm option can be used with the *vmstat* command on some systems to display the memory totals in meabytes instead of kilobytes.

**Common usage examples:**

vmstat | Display memory utilization once and exit  
vmstat [DELAY] | Update results at the specified interval  
vmstat [DELAY] [COUNT] | End after reaching the specified count  
vmstat -s | Display a table of memory statistics  
vmstat -Sm | Display utilization in meabytes
