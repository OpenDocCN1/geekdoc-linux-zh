# **Purpose: Performance monitor for AIX systems.**

# **Usage syntax:  topas  [OPTIONS]**

![](bbox=[0.08, 0.15, 0.92, 0.46])

**topas** is the performance monitor for AIX systems. Executing **topas** with no options shows an overview of all areas of system utilization, as shown in the above example.

**topas** also has several options to monitor specific aspects of the system. For example, the **-D** option displays disk utilization information for each disk on the system as shown in the next example.

![](bbox=[0.08, 0.65, 0.92, 0.75])

**Common usage examples:**

+   * **topas**
+   Display the topas monitor
+   * **topas -D**
+   Monitor disk activity
+   * **topas -P**
+   Monitor processes
+   * **topas -V**
+   Monitor volume group activity
+   * **topas -F**
+   Monitor file system activity
+   * **topas -E**
+   Monitor ethernet activity
