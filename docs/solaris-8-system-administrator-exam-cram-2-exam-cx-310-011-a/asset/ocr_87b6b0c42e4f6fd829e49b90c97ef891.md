# Question 8

Answers a, b, and c are correct. **nosuid**, **atime**, and **nolargefiles** are all **-o** command-line arguments. **-o nosuid** disables setuid permissions on any files (**-o suid** allows it). **-o atime** allows access times on files to be updated (**-o noatime** prevents it). **-o nolargefiles** causes the mount command to fail if any files on the file system are 2GB or larger (**-o largefiles** allow large files). **nmonntab** does not exist. Therefore, answer d is incorrect. To prevent a mounted file from being added to the /etc/mnttab file, use the **-m** command-line argument.
