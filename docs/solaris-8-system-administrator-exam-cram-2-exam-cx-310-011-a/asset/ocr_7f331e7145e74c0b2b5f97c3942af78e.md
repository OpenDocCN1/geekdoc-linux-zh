|---|---|
| **Sequence** | **Description** |
| `<up arrow>` | Moves the cursor up one line |
| `<down arrow>` | Moves the cursor down one line |
| `<left arrow>` | Moves the cursor left one character |
| `<right arrow>` | Moves the cursor right one character |
| `<h>` | Moves the cursor left one character |

Note that there are two sets of single character/line cursor-positioning commands. One set uses the dedicated cursor (arrow) keys, and the other uses lowercase alphabet keys. These dual commands allow the vi text editor to be used with keyboards that do not have cursor keys or for some reason have cursor keys not recognized by the vi text editor. Also note that you can enter a number before each cursor-positioning command to position the cursor by multiple lines or characters at a time. For example, **20j** moves the cursor down 20 lines and **10<right arrow>** moves the cursor 10 characters to the right.
