# Changing File Permissions

You can modify the access mode of existing files and directories with the **chmod**(1) command, which can use absolute mode or symbolic mode.

Absolute mode is straightforward, as shown in the following example:

```
```text
# ls -l file1
-rwxrwxr-x  1 dla      other          636 Jan 24 12:39 file1
# chmod 645 file1
# ls -l file1
-rw-r--r-x   1 dla      other          636 Jan 24 12:39 file1
#
```
```

When you use symbolic mode, the class of system account (user, group, or other) is defined by using the letters *u*, *g*, and *o*. Permissions are added by using the plus (+) character and removed by using the minus (-) character. To specify multiple changes, separate them with commas. The following example shows using the **chmod** command with symbolic mode:

```
```text
# ls -l file1
-rwxrwxr-x  1 dla      other          636 Jan 24 12:40 file1
# chmod u-w,g-w,o-x,+w file1
# ls -l file1
-rw-r--r-x   1 dla      other          636 Jan 24 12:40 file1
#
```
```

# Special Permissions

Several special permissions can be set on files and directories:

+   - **Set User ID (setuid)**—Sets the effective UID to owner on execution
+   - **Set Group ID (setgid)**—Sets the effective GID to group on execution
+   - **Mandatory locking**—Prevents reading or writing a file while a program has the file open
