+   - Root password
+   - System locale
+   - Terminal (keyboard, mouse, monitor, and graphics card type)
+   - Time zone (timezone and timeserver)

# Using NIS

For the name service method, entries for each system are added to the NIS or NIS+ database. Name services are described in Chapter 19, “Name Services.”

The following system definition information can be defined by using NIS/NIS+:

+   - Name service (implied)
+   - Hostname and IP address
+   - System locale
+   - Time zone (timezone and timeserver)

![](bbox=[0.122, 0.503, 0.226, 0.571])

> A lot of information can be defined in the sysidcfg file that cannot be defined in a name service, including the domain name, most of the network interface parameters (netmask, DHCP usage, and IPv6 usage), the root password, and terminal information (monitor, keyboard, mouse, and so on).

The system locale (specific language and region) is stored in the /etc/locale file and can be specified for the system name or the domain name. For NIS, you can build a locale.byname map by modifying and executing the NIS makefile. The /etc/locale file is used as a source of information for the local.byname map. For NIS+, you use the **nיסtbladm**(1M) command to build the locale table and add entries.
