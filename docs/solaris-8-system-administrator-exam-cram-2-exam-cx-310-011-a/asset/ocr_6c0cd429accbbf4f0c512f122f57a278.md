# Deleting Files by Using the rm Command

The **rm(1)** command deletes one or more files specified as command-line arguments. The files to be deleted can be complete filenames, multiple files selected with metacharacters, or any combination. Multiple filenames must be separated by spaces. The **-i** command-line argument provides interactive control over the remove command. Normally, if the **rm** command encounters a write-protected file, it prompts to confirm the file’s removal. However, if you specify the **-f** command-line argument, write-protected files are removed with confirmation. The **-f** command-line argument cannot be specified with the **-i** command-line argument, as shown in this example:

```
```text
# ls
file1  file2  xfile

# rm xfile file*

# ls
#
```
```
