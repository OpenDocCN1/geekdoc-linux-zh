
您可以使用OpenBoot **printenv**命令查看这些参数的值。要设置和修改它们，请使用OpenBoot **setenv**命令。


## 设备别名

OpenBoot使用完整的设备路径名来标识系统硬件，该路径名表示设备的类型及其在系统中的位置。设备路径名由系统总线、地址以及可能的驱动程序名称组成。以下是SCSI磁盘驱动器某个分区的完整设备名称示例：

```
/bus@1f,0/SUNW,fas@e,8800000/sd@3,0:a
```

有关设备名称的更多详细信息，请参阅第8章“磁盘管理”。由于设备名称通常较长、复杂且难以输入，OpenBoot允许您为完整设备名称分配一个设备别名；该别名是一个简短、容易记住和输入的名称。

### 创建设备别名

您可以通过两种方式创建设备别名。第一种方法使用**devalias**命令。使用此命令创建的别名在系统重新引导后会丢失。第二种方法使用**nvalias**命令创建的别名存储在非易失性存储器中，并一直保留在那里，直到您使用其他OpenBoot命令将其删除。两个命令使用相同的语法。

例如，以下两个命令都在OpenBoot ok提示符下输入，将别名disk2分配给名为/sbus/esp/sd@2,0（一个SCSI磁盘）的设备：

```
ok devalias disk2 /sbus/esp/sd@2,0
ok nvalias disk2 /sbus/esp/sd@2,0
ok
```

在OpenBoot环境中需要设备名称时，您可以使用别名代替。当您输入**nvalias**命令时，它会存储在非易失性存储器中。这部分内存被视为一个名为**nvramrc**的OpenBoot参数。**nvramrc**参数的内容称为*脚本*。除了存储用户自定义命令外，该参数还用于设备驱动程序保存启动配置变量、修补设备驱动程序代码，以及存储错误修补程序或其他特定于安装的设备配置信息。

如果OpenBoot **use-nvramrc**参数设置为**true**，则在系统引导期间执行脚本。使用**nvalias**命令在**nvramrc**中定义的任何别名都将被设置，然后这些别名可以在脚本的后面部分使用，或作为其他一个或多个OpenBoot参数的值。

### 显示设备别名

您还可以使用**devalias**命令显示已定义的设备别名。如果在不带任何命令行参数的情况下输入该命令，将列出所有已定义的设备别名。如果将某个设备别名作为命令行参数列出，则**devalias**命令仅显示该指定的设备别名。以下示例展示了在SPARCstation 20工作站的OpenBoot ok提示符下使用**devalias**命令的情况：

### 删除设备别名

由**nvalias**命令定义的别名存储在脚本中，并一直保留在那里，直到您使用**nvunalias**命令将其删除，或使用**set-defaults**命令将系统配置恢复为原始默认值。请注意，使用**devalias**命令定义的别名*不*存储在脚本中，系统重新引导时会丢失。

要删除非易失性设备别名（存储在脚本中的别名）disk2，请在OpenBoot ok提示符下输入以下命令：

```
ok nvunalias disk2
ok
```

## 从Solaris查看和修改NVRAM参数

通常，您使用OpenBoot命令查看和修改NVRAM参数。也可以使用**eeprom**(1M)命令从Solaris 8环境中查看和修改NVRAM参数。但是，只有超级用户才能使用**eeprom**命令修改NVRAM参数。

要查看**auto-boot?** NVRAM参数的值，请在系统提示符下输入以下**eeprom**命令：

```
$ /usr/sbin/eeprom 'auto-boot?'
auto-boot?=true
$
```

要查看所有NVRAM参数，请在无任何命令行参数的情况下输入**eeprom**命令。

您还可以使用**eeprom**命令修改NVRAM参数。要将**auto-boot?**的值设置为**false**，请在系统提示符下输入以下命令：

```
# eeprom auto-boot?=false
#
```

## 引导问题排查

当复位或加电时，SPARC系统通常会运行POST。之后，系统自动引导（如果**auto-boot?**为**true**）或进入Forth监视器。

引导过程或OpenBoot初始化序列会执行各种检查并加载相应的模块。系统成功加载并启动操作系统后，您可以在/var/adm/messages文件中查看有关此初始化序列的状态消息。

但是，如果出现引导问题，Solaris 8系统将无法启动，您也就无法查看这些消息。为了解决这种情况，OpenBoot具有将初始化序列消息发送到tty串行端口A（TTYA）的功能。您可以通过在启动系统引导之前将**diag-switch?** OpenBoot参数设置为true并使用**setenv**命令来实现，如下例所示：

```
ok setenv diag-switch? true
ok
```

通过将终端或PC连接到TTYA，您可以观察OpenBoot初始化序列生成的消息，并识别引导问题。
