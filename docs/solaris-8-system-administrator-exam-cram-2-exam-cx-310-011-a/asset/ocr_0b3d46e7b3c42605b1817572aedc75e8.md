# The Rules File

The rules file is a text file containing an entry, or rule, for each system or group of systems to be automatically installed. Each rule identifies the system (or group of systems) based on one or more attributes and identifies a unique profile file that provides configuration details for that system or group of systems.

Each rule consists of one or more keywords and values followed by the name of a begin script, the profile file, and the finish script (all separated by tabs or spaces). Keywords (and associated values) include the following:

+   - **any**
+   - **arch** (followed by a processor-type value)
+   - **disksize** (followed by a disk name value)
+   - **hostaddress** (followed by an IP address value)
+   - **hostname** (followed by a hostname value)
+   - **memsize** (followed by a physical memory value)
+   - **model** (followed by a platform name value)

One or more of these keywords and associated values are specified per rule to uniquely identify a system or group of systems.

Following the keywords and values is the name of a begin script. This is a Bourne shell script that executes before installation begins. If a begin script is not required, a hyphen should be used instead. Next is the name of a profile file in the JumpStart configuration directory that provides configuration details for that system or group of systems. Following the profile file is the name of the finish script, which is a Bourne shell script executed after installation is complete. If a finish script is not required, a hyphen should be used instead.

The following example shows several entries from a rules file:

```
hostname sample_host    -          host_class   set_root_pw
network 924.22.43.0 & \\
        karch sun4c    -          net924_sun4c  -
arch i386              -          x86-class     -
any  -                 -          any_machine   -
```

The first entry lists the JumpStart installation for the host named sample_host. No begin script is specified, the host_class file is used as the profile or class file, and the finish script set_root_pw is called after installation to set the root account’s password.
