# # Practice Questions

# ## Question 1

Match each pseudo file system with its use.

| Option | Pseudo file system | Use |
|---|---|---|
| a. | CacheFS | 1. Temporary files |
| b. | PROCFS | 2. Alternative pathnames |
| c. | TMPFS | 3. Process information |
| d. | LOFS | 4. Local caching of data |

Answers a-4, b-3, c-1, and d-2 are correct. CacheFS is used for local caching of data from remote file systems. PROCFS provides status and other information for active processes. TMPFS provides a storage area for fast access to temporary files. LOFS provides access to existing data using alternative pathnames.

# ## Question 2

+   Which swap command-line argument adds a swap file to the system swap space?
+   
+   - a. `-a`
+   - b. `-d`
+   - c. `-l`
+   - d. `-s`

Answer a is correct. The swap command’s -a command-line argument adds a swap file to the system swap space. -d deletes a swap file from the system swap space. Therefore, answer b is incorrect. -l lists the swap space partition and any swap files. Therefore, answer c is incorrect. -s lists statistics about swap space use. Therefore, answer d is incorrect.
