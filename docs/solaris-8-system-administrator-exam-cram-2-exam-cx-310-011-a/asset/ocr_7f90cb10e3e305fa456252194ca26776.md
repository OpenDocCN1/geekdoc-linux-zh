# ## Directories

Several commands enable you to create, move, and delete directories:

+   - `mkdir(1)`—Creates a directory.
+   - `mv(1)`—Moves a file or directory.
+   - `rmdir(1)` or `rm(1)`—Removes a directory.

# ### Creating Directories by Using the mkdir Command

The mkdir(1) command creates the directory specified as a command-line argument. The command-line argument can be an absolute (from /) pathname or a pathname relative to the current directory. The directory will be owned by the user account used to create the directory and by the owner's group. It will be created with access permissions based on the current umask or the access permissions specified by the -m mode command-line argument; mode is a set of permissions defined by using absolute mode format. To create multiple directories, specify them as command-line arguments (separated by spaces).
