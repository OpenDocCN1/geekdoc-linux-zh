For more details on device names, see Chapter 8, “Disk Administration.” Because device names are typically long, complex, and awkward to enter, OpenBoot lets you assign a device alias to a full device name; this alias is a name that’s short and easy to remember and type.

# Creating a Device Alias

You can create a device alias in two ways. The first method uses the **devalias** command. Aliases created with this command are lost when the system is rebooted. Aliases created with the second method, the **nvalias** command, are stored in nonvolatile memory and remain there until you remove them by using other OpenBoot commands. Both commands use the same syntax.

For example, both of the following commands, entered at the OpenBoot ok prompt, assign the alias disk2 to the device named /sbus/esp/sd@2,0 (a SCSI disk):

```
ok devalias disk2 /sbus/esp/sd@2,0
ok nvalias disk2 /sbus/esp/sd@2,0
ok
```

Whenever the device name is required in the OpenBoot environment, you can use the alias instead. When you enter the **nvalias** command, it’s stored in nonvolatile memory. This portion of memory is treated as an OpenBoot parameter called **nvramrc**. The contents of the **nvramrc** parameter are called the *script*. In addition to storing user-defined commands, this parameter is used by device drivers to save startup configuration variables, to patch device driver code, and to store bug patches or other installation-specific device configuration information.

If the OpenBoot **use-nvramrc** parameter is set to **true**, the script is executed during system boot. Any aliases defined in **nvramrc** with the **nvalias** command will be set, and then the aliases can be used in a later part of the script or as the value of one or more other OpenBoot parameters.

# Displaying a Device Alias

You can also use the **devalias** command to display defined device aliases. If you enter the command without any command-line arguments, all defined device aliases are listed. If you list a device alias as a command-line argument, the **devalias** command displays only the named device alias. The following example shows using the **devalias** command from the OpenBoot ok prompt of a SPARC 20 workstation:

```
ok devalias
screen        /iommu@f,e0000000/sbus@f,e0010000/cgsix@2,0
ttyb          /obio/zs@0,100000:b
ttya          /obio/zs@0,100000:a
keyboard      /obio/zs@0,0
```
