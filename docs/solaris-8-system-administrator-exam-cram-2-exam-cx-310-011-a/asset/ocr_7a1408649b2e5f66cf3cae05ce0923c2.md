# Directory Tree Navigation

When a user logs in to the system, he or she is positioned somewhere in the Unix directory tree—typically in the user account’s home directory. The current directory, referred to as the *current working directory*, can be displayed by using the pwd(1) command.

The user can move around the directory tree by using the cd(1) command. When used without any command-line arguments, cd relocates the user to the directory specified by the HOME environment variable (typically the user account’s home directory). A new directory can be specified as a command-line argument. If the directory exists and the user has execution permission for that directory, he or she is relocated to that directory. The new directory can be specified by using a complete directory name, a partial directory name and metacharacters, or (in a few cases) all metacharacters.

The new directory can also be specified as a *full or absolute pathname* starting with the root (/) directory, or a *partial or relative pathname* starting at the current working directory. You can reference the current directory by using a single dot (.) and the directory above the current directory (the *parent directory*) by using two dots (..), as shown in this example:

```
```sh
$ pwd
/export/home/dla
$ cd ..
$ pwd
/export/home
$ cd .
$ pwd
/export/home
$ cd /export/home
$ pwd
/export
$ cd dla
$ pwd
/export/home/dla
$
```
```

You can also reference multiple parents in the same path by using (..), as shown in this example:

```
```sh
$ pwd
/export/home/dla
$ cd ../../..
$ pwd
/export
$
```
