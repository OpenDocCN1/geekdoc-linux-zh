# ## Hands-On Experience

Another important key to success on all the Solaris tests is hands-on experience. If I leave you with only one realization after taking this Self-Assessment, it should be that there’s no substitute for time spent installing, configuring, and using the various Solaris command and tools on which you’ll be tested repeatedly and in depth.

+   5. Have you installed, configured, and worked with Solaris 8? (Yes or No)

If yes, make sure you understand the basic concepts covered in Exam CX-310-011.

If you haven’t worked with Solaris 8, you must obtain a copy of it for either SPARC or Intel x86 compatible platforms. Then learn about the installation and administration.

![](bbox=[0.115, 0.386, 0.862, 0.469])

Before you even think about taking any Solaris exam, make sure you’ve spent enough time with Solaris 8 to understand how it can be installed and configured, how to maintain such an installation, and how to troubleshoot software when things go wrong. This will help you in the exam—as well as in real life.
