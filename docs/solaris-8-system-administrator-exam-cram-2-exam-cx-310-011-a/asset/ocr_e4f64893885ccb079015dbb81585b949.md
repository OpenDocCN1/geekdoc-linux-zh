| Sequence | Description |
|---|---|
| `/text/` | Searches forward for *text* (trailing slash optional) |
| `?text?` | Searches backward for *text* (trailing question mark optional) |

If the text is found, the cursor is positioned at the beginning of the specified text. When the end (or beginning) of the file is encountered, the search continues at the beginning (or end) of the file contents. Press `</>` or `<?>` followed by `<Enter>` to repeat the last search.

# Text Search and Replace

The vi editor supports text search-and-replace functions. They combine the ability to search for text and replace the located text into a single operation. Table 10.7 lists the text search-and-replace keyboard sequences.

| Sequence | Description |
|---|---|
| `:<x>s/<old>/<new>/` | Searches the current line for the first occurrence of *old* and replaces it with *new* (trailing slash optional) |
| `:<x>s/<old>/<new>/g` | Searches the current line for all occurrences of *old* and replaces them with *new* |
| `:<x>1,.,$s/<old>/<new>/` | Searches for the first occurrence of *old* on all lines and replaces them with *new* (trailing slash optional) |
| `:<x>1,.,$s/<old>/<new>/g` | Searches for all occurrences of *old* on all lines and replaces them with *new* |
| `:<x>g/old/s//new/` | Searches for the first occurrence of *old* on all lines and replaces them with *new* (trailing slash optional) |
| `:<x>g/old/s//new/g` | Searches for all occurrences of *old* on all lines and replaces them with *new* |

Note that `g` denotes a global search and that there are two meanings of “global.” The first refers to the current line, meaning the global replacement affects all occurrences on the current line as opposed to just the first occurrence. Therefore, the `g` at the end of the keyboard sequence refers to all occurrences on the current line. The second meaning of “global” refers to all lines.
