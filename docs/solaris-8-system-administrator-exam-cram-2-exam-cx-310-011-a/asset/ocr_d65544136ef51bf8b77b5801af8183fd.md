# Auditing Login Accounts and Processes

Several commands are available to monitor the use of system and user login accounts. In addition, you can use several commands to identify the processes currently running on the system and the associated login accounts.

# The who Command

You can use the who(1) command to determine which system and user accounts are currently logged in to the local system. Without arguments, the who command lists the login account name, terminal device, login date/time, and optionally an indication of X Window System terminal (:0.0):

```
```text
$ who
root        console      Apr  4 18:57   (:0)
root        pts/5        Apr  8 22:13   (:0.0)
dla         pts/6        Apr 11 21:06   (winnt40)
$
```
```

When the -q command-line argument is specified, only the login account names and number of users currently logged on are displayed, as shown in the following example:

```
```text
$ who -q
root    root    dla
# users=3
$
```
```

# The whodo Command

The whodo(1M) command determines the processes that each login account is executing. The following example shows (among other things) that the user dla is using the vi(1) command:

```
```text
# whodo
Thu Apr 19 02:22:25 EDT 2001
solaris8

    console       root    16:16
        ?         423    0:00 xsession
      pts/2       467    0:00 sdt_shell
      pts/2       483    0:00 ttsession
      pts/2       484    0:01 dtsession
        ?        1091    0:00 dtcscreen
        ?         491    0:04 dtwm
        ?         507    0:00 dtaction
        ?         492    0:01 sdtperf-meter
      pts/2       470    0:00 sh
```
