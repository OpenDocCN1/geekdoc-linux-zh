# Easy Access to Online Pointers and References

The Suggested Reading section at the end of each chapter in this Exam Cram contains numerous pointers to Web sites, newsgroups, mailing lists, and other online resources. To make this material as easy to use as possible, we include all this information in an HTML document entitled “Online Pointers” on the CD. Open this document in your favorite Web browser to find links you can follow through any Internet connection to access these resources directly.
