# Adding More Swap Space

The mkfile(1M) command can configure additional swap space by using available space from mounted partitions. This command creates a file of a specified size that internally has the appropriate layout. You can then use the swap(1M) command to add the file to the system swap space.

The mkfile command expects at least two command-line arguments. The first is a number specifying the file size. The size should be followed by k or K for kilobytes, b or B for blocks, or m or M for megabytes, to identify the appropriate scale for the size. Be sure you do not place a space between the size and the scale. If a scale is not specified, the size is assumed to be in bytes. The second command-line argument is the filename. You can create more than one file of the specified size by listing multiple filenames as command-line arguments, separated by spaces. Two other command-line arguments are supported: -n, which indicates that the disk space should be allocated as needed up to the specified size instead of all being allocated when the file is created), and -v, which specifies verbose reporting mode (filenames and sizes are listed).

You can add a swap space file (or swap file) to the system swap space by using the **swap -a** command. At a minimum, the filename must be specified as a command-line argument. Be sure to use the full (absolute) pathname for the file. To activate swap space files when the system is rebooted, list them in the /etc/vfstab file. The /etc/vfstab entry should contain the full pathname to the swap file and be identified as a swap file system. The /sbin/swapadd script is executed for each swap file system listed in the /etc/vfstab file during system reboot.

# Administering Swap Space

In addition to being used to add swap space, the **swap** command supports command-line arguments to list swap space (-l), list swap statistics (-s), and delete swap files (-d). The following example creates a 32MB swap file, adds to the system swap space, and uses the **swap** command to administer the swap space:

```
```text
# swap -l
swapfile             dev  swaplo blocks   free
/dev/dsk/c0d0s1      102,1      8 1049320 1049320
