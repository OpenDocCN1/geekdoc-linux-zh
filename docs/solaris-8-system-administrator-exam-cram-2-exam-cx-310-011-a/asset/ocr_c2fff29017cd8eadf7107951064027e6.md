# Table 9.9 — Selected cpio Command-Line Arguments

| Argument | Description |
|---|---|
| `-a` | Resets file access times (used with `-i`) |
| `-A` | Appends to an archive (used with `-o`) |
| `-d` | Creates directories as needed (used with `-i` and `-p`) |
| `-i` | Copies in (extracts from an archive) |
| `-I file` | Reads the contents of *file* as an input archive (used with `-i`) |
| `-L` | Follows symbolic links (used with `-o` and `-p`) |
| `-m` | Retains modification times (used with `-i` and `-p`) |
| `-o` | Creates out (creates an archive) |
| `-O file` | Uses *file* as an output archive (used with `-o`) |
| `-p` | Passes input to output |
| `-t` | Prints an archive table of contents; no files are created (used with `-i`) |
| `-u` | Copies files unconditionally; older files overwrite newer files (used with `-i` and `-p`) |
| `-v` | Prints filenames (verbose mode) |

The following example shows some typical uses of the cpio command. The first cpio command uses the output of the ls command to generate a list of files to place in the file named “archive.” The second cpio command lists the contents of archive. The third cpio command extracts files from archive:

```
```text
# ls
file1  file2  file3  file4

# ls | cpio -ov -o archive
file1
file2
file3
file4
272 blocks

# cpio -ivt -I archive
-rw-r--r--   1 root     other          27 Apr  6 03:04 2001, file1
-rw-r--r--   1 root     other         389 Apr  6 03:04 2001, file2
-rw-r--r--   1 root     other       34341 Apr  6 03:04 2001, file3
-rw-r--r--   1 root     other      103306 Apr  6 03:04 2001, file4
272 blocks

# cpio -ivum -I archive
file1
file2
file3
file4
272 blocks
#
```
