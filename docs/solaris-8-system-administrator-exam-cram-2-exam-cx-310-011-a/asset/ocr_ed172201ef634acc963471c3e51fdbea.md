# Modifying an Account by Using the admintool Command

To modify a user account, start the **admintool** command if it is not already active. Choose Browse, Users from the menu (shown previously in Figure 6.1) to open the Users dialog box.

Click the account entry to highlight it, and then choose Edit, Modify from the menu to open the Modify User dialog box, which is similar to the Add User dialog box (shown previously in Figure 6.2). The fields in this dialog box are filled in with information about the selected user. Change the fields as needed and click Apply to save the changes.

# Deleting an Account by Using the admintool Command

To delete a user account, start the **admintool** command if it is not already active, and choose Browse, Users from the menu. In the Users dialog box, click the account entry to highlight it, and then choose Edit, Delete from the menu to open the Warning dialog box (see Figure 6.3). Click Delete to delete the user account.
