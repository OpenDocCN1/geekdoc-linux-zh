The more important command-line options are **-a, -d, -F, -l, -r, -R, -t,** and **-1**. Be certain to understand the effect of these command-line arguments on the information the **ls** command displays.

When you’re using one of the long listing formats (**-g, -l, -n,** or **-o**), the file permissions and additional information are displayed in the first 11 characters of each directory/file.
