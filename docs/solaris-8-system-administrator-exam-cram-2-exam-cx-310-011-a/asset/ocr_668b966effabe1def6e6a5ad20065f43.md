# Question 6

Name the OpenBoot command to boot a system from the CD-ROM.

The correct answer is **boot cdrom**.

# Question 7

+   Which of the following is the last phase in the Solaris boot process?
+   
+   ○ a. init
+   ○ b. Boot PROM
+   ○ c. BIOS
+   ○ d. Kernel initialization
+   ○ e. Boot programs

Answer a is correct. The init phase is last in the Solaris boot process. All the answers are phases of the SPARC or Intel x86 boot process. The Boot PROM and BIOS phases test hardware, the Boot programs phase locates and loads boot programs, and the Kernel initialization phase loads the kernel. Only then can the init phase occur to initialize the operating system services. Therefore, answers b, c, d, and e are incorrect.

# Question 8

Give the full pathname of the file that determines whether the keyboard abort sequence is enabled or disabled.

The correct answer is **/etc/default/kbd**.
