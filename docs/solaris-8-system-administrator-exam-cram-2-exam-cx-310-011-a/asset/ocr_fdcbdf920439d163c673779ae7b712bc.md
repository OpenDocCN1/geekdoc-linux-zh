# Deleting a Device Alias

An alias defined by the **nvAlias** command is stored in the script and remains there until you remove it by using the **nvunialias** command, or until you restore the system configuration to its original defaults by using the **set-defaults** command. Keep in mind that an alias defined with the **devalias** command is *not* stored in the script and is lost when the system reboots.

To delete the nonvolatile device alias (an alias stored in the script) disk2, enter the following command at the OpenBoot ok prompt:

```
```text
ok nvunalias disk2
ok
