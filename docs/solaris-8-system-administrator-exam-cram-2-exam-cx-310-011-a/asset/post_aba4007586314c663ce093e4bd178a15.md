## Last Line Mode

Last Line mode is used to perform searches and enter commands associated with the **ed** and **ex** line-oriented text editors. You enter Last Line mode from Command mode by pressing any of the following three keyboard characters:

- **Colon <:>**—Specifies **ed** or **ex** commands, which are mainly file control commands (such as writing the file) or executing a shell command.
- **Forward slash </>**—Performs a search for a text pattern in the file, starting from the current position and searching toward the end of the file.
- **Question mark <?>**—Performs a search for a text pattern in the file starting from the current position and searching toward the beginning of the file.

In Last Line mode, you can specify the operation you want. When you press <Enter>, the specified operation is performed and the **vi** editor returns to Command mode.

### File Control and Execution

Table 10.5 lists some of the common Last Line mode keyboard sequences used for file control and command execution. See the vi(1) manual page for more information.

| Sequence | Description |
|---|---|
| `:e name` | Edits the named file |
| `:e!` | Discards changes and re-edits |
| `:w` | Writes changes to a file |
| `:w!` | Writes changes regardless of file permission |
| `:q` | Quits |
| `:q!` | Discards changes and quits |
| `:cmd` | Executes the specified **ed** or **ex** command specified by *cmd* |

### Text Search

Table 10.6 lists some of the common Last Line mode keyboard sequences for performing text searches. See the vi(1) manual page for more information.

| Sequence | Description |
|---|---|
| `/text/` | Searches forward for *text* (trailing slash optional) |
| `?text?` | Searches backward for *text* (trailing question mark optional) |

If the text is found, the cursor is positioned at the beginning of the specified text. When the end (or beginning) of the file is encountered, the search continues at the beginning (or end) of the file contents. Press `</>` or `<?>` followed by `<Enter>` to repeat the last search.

### Text Search and Replace

The vi editor supports text search-and-replace functions. They combine the ability to search for text and replace the located text into a single operation. Table 10.7 lists the text search-and-replace keyboard sequences.

| Sequence | Description |
|---|---|
| `:s/<old>/<new>/` | Searches the current line for the first occurrence of *old* and replaces it with *new* (trailing slash optional) |
| `:s/<old>/<new>/g` | Searches the current line for all occurrences of *old* and replaces them with *new* |
| `:1,$s/<old>/<new>/` | Searches for the first occurrence of *old* on all lines and replaces them with *new* (trailing slash optional) |
| `:1,$s/<old>/<new>/g` | Searches for all occurrences of *old* on all lines and replaces them with *new* |
| `:g/old/s//new/` | Searches for the first occurrence of *old* on all lines and replaces them with *new* (trailing slash optional) |
| `:g/old/s//new/g` | Searches for all occurrences of *old* on all lines and replaces them with *new* |

Note that `g` denotes a global search and that there are two meanings of “global.” The first refers to the current line, meaning the global replacement affects all occurrences on the current line as opposed to just the first occurrence. Therefore, the `g` at the end of the keyboard sequence refers to all occurrences on the current line. The second meaning of “global” refers to all lines.

Two mechanisms address all lines. The first uses the **1,$** sequence to indicate all lines. When this sequence is used with the **s///** sequence, vi attempts search-and-replace on all lines in the file. The second mechanism uses the **g/old/** sequence to locate all lines containing the phrase **old**. When this sequence is used with the **s///** sequence to perform a replacement, the **old** text does not need to be specified in the first field of the **s///** sequence. Although both **1,$s/old/new/** and **g/old/s//new/** use different approaches, the results are the same. That is, the first occurrence of **old** in every line is replaced with **new**. Note that you can add a **<g>** to the end of both commands to affect all occurrences of **old**.

## Accessing Remote Systems

Solaris 8 provides several commands to perform remote login, remote copy, and remote execution of commands:

- **telnet(1)**—Remote Network Terminal utility
- **ftp(1)**—File Transfer Protocol utility
- **rlogin(1)**—Remote login
- **rcp(1)**—Remote copy
- **rsh(1)**—Remote shell execution

The **ftp** and **telnet** commands require the user to log in to the remote system using a valid user account name and password set up on the remote system. The **rlogin**, **rcp**, and **rsh** commands are collectively referred to as the “r commands,” and all can use the remote authentication database in place of requiring a user account name and password to validate the user.

### Remote Login

Two commands provide the ability to log in to a remote system as a local user over the network: the **telnet** command and the **rlogin** command.
