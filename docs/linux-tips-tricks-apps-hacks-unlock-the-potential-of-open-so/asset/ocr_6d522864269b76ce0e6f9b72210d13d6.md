For the rest of the controls, use your mouse and keyboard - for example, to swipe across the screen, simply click and drag your mouse. Once it's installed and run for the first time, an extension will create a menu entry and will soon display in your start menu. Entries like this are perfectly supported by all desktop environments in Linux. Doing a cold start of an application from the menu does evoke a lot of Chrome stuff, but everything runs quietly in the background without showing you any browser windows, and it feels like you're using a desktop-class application at the same time.
