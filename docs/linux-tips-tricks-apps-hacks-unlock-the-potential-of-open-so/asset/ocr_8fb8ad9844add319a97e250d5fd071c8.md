# **15 Work with the NOTE style**

Before talking about the NOTE style you should first download the picins.style file and put it where your \LaTeX{} files are:

```
$ wget http://tug.ctan.org/ tex-archive/macrocs/latex209/contrib/picins/picins.sty
```

The NOTE style can be defined as follows:

```
\usepackage{picins}\\\n\usepackage{amsmth}\\\n\newcommand{\NOTE}{\llength{1mm}\parspice{14mm,5mm}{sl1[NOTE]\noindent}
```

You can now add a note as follows:

```
\NOTE{A small note doesn't look very elegant}
```

The only drawback of the style is that it needs to have at least two lines of text to look pleasant on the page.

# **11 Format figures**

You can easily alter the existing format of a picture caption by using the following \LaTeX{} commands:

```
\usepackage{caption}\\\n\DeclareCaptionLabelSeparator{par}{\par}\\\n\DeclareCaptionFormat{dashedlabel}{\\\n\textbf{--\#1 \textbf{--\#2\#3}\\\n\captionsetup{format=dashedlabel, margin=1cm, singlelinecheck=true, font=small, label={sc,bf,}, labelfont=it, justification=centerlast, labelsep=par}
```

Now you will be able to add a specific figure in your book as follows:

```
\begin{figure}[tb]\\\n\centering\\\n\fbox{\scscalebox{0.45}{\\\n\includegraphics{figures/ch1/f801.jpeg}}}\\\n\caption{Adding a figure}\\\n\label{ch9:f91}\\\n\end{figure}
```
