You'd be forgiven for not knowing what LVM stands for, but it's a useful thing to know. Logical volume management, as it's properly designated, acts as a sort of container to manage your data – the benefit of this is that you can start adding and extending space while the LVM is still online and working. This is great for server farms because you can swap out and add storage very quickly,

and on your desktop its particularly good for managing the size of different partitions if you weren't sure how they should have been during installation.

In this tutorial, we'll look at how you can create an LVM filesystem and then how you can go about maintaining and modifying it. We will also look into how some distros install using LVM.
