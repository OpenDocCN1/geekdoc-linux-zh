
# Glossary of Key Terms

Access vector cache (AVC) | An access permission associated with SELinUX.

Access control lists (ACLs) | In Linux, access control lists allow authorized users to set the permissions with a file or directory. These permissions can supersede standard discretionary access controls.

Access vector | In security, an access permission represented by a bitmap; commonly stored for SELinux security in an access vector cache.

Advanced Encryption Standard (AES) | An encryption standard configured by the National Institute of Standards and Technology (NIST).

Advanced Intrusion Detection Engine (AIDE) | An intrusion detection system; available in both Red Hat and Ubuntu repositories.

Anaconda | The Red Hat installation program.

Andrew Filesystems | A distributed filesystem, sometimes with Kerberos tokens.

Andrew Tannebaum | See Tannebaum, Andrew.

Apache | A web server used primarily on Linux. is currently the most popular web server on the Internet.

Application Armor (AppArmor) | A mandatory access control system used to create security profiles for different programs. It uses Linux modules in the kernel. Not compatible with SELinux.

Architecture | In the context of computing, a reference to the type of CPU, such as i86 for 32-bit Intel and AMD systems.

Asterisk | The open source private branch exchange (PBX) VoIP service.

Authentication Header (AH) protocol | A protocol that guarantees integrity and data-authentication of network packets.

Authenticity | A Ker head concept related to the CIA triad of integrity. Authenticity can help users verify that important communications, such as messages, are genuine.

Availability | A CIA triad concept in which users have access to their data when they want it.

AVG | A company that creates anti-malware systems for Linux and other operating systems.

Backport | A feature from a future version of a software-component that is incorporated into an update of an earlier release. Backports are commonly applied to kernels with a certain version number to incorporate additional features without overriding any sort of certification of third-party software related to the kernel.

Backport | In the context of the kernel, an incorporated feature from a later kernel.

BackTrack | A Linux distribution currently based on Ubuntu with penetration testing tools loaded in CD and USB format. Available from http://backtrack-linux.org.

Backup Domain Controller (BDC) | A backup for a PC on Microsoft Windows domain: Linux with Samba can be configured as a BDC.

Base management controller (BMC) | An interface embedded in the motherboard. In some cases, it may be configured to allow access to the system boot menu.

Basic Input/Output System (BIOS) | The first thing that runs when you power up an older computer. The BIOS identifies and tests hardware to a point where an operating system can be loaded from media such as a hard drive.

Bastion server | A secured host dedicated for a specific purpose. It is configured with a minimum number of services to limit its exposure to attacks.

Berkeley Internet Name Domain (BIND) | A common DNS server on the Internet, originally created at the University of California at Berkeley, maintained by the Internet Systems Consortium.

Berkeley Software Distribution (BSD) | A clone of UNIX, similar to Linux, released under different licenses.

Binary kernel | When the source of a kernel is installed in a package, it is changed from a human-readable format to a binary format readable by a computer.

Biometric controls | Identification controls based on unique characteristics of authorized personnel. May be used for authentication to secure a secure location as a server room.

Black-hacker | A user who wants to break into computer systems and networks with malicious purposes in mind.

Bootstrap Protocol (BOOT) | A protocol of the Transmission Control Protocol/Internet Protocol (TCP/IP) suite associated with automatic assignment of IP addresses may also be used for the acquisition of IP addresses from a Dynamic Host Configuration Protocol (DHCP) over a remote network. Associated with UDP port 68.

Bugzilla | A Web-based bug-tracking tool commonly used on open source projects from Red Hat to the GNOME desktop environment.

Challenge-response authentication mechanism (CRAM) | A group of protocols where a service as open server presents a challenge as a request for a username and password.

Chroot jail | One type of operating-system-level virtualization. When a program or service routes clients to a directory, a chroot jail limits the view of system. In some cases, a chroot jail limits all of the binaries, libraries, configuration files, and executables required to run a service that is contained.

CIA triad | The CIA triad secures three goals of information security: confidentiality, integrity, and availability.

Cache poisoning | A frequently malicious insertion of non-authoritative data in DNS as it were unauthorized. May be used by black-hat hackers to redirect users to malicious sites.

ClAntivirus (ClamAV) | A cross-platform antivirus toolkit developed for and used on Linux, and derivatives of UNIX.

Cobbler project | An open source project for network-based installations of Linux distributions.

CAINE | Short for Computer Augmented Environment, a bootstrap live CD distribution available from http://www.caine.net/

Common UNIX Printing System (CUPS) | The default print server for modern Linux distributions. By default CUPS uses the Internet Protocol (IP), it can also manage printers in a number of other protocols.

Canonical | The company that provides the rate breaker of the Ubuntu.

CentOS | Short for the Community Enterprise Operating System. CentOS is sometimes known as a rebuild. This is because it is a distribution built by third parties, based on code released for the Red Hat Linux distribution.

Common Vulnerabilities and Exposures (CVE) list | A list of operating-system security issues maintained by the MITRE corporation and sponsored by the National Security Division of the U.S. Department of Homeland.

Certificate Authority | An entity that issues digital certificates for use by other parties. Secure sites without an official CA return an error message.

Communications Security (COMSEC) | COMSEC is one of the ISO standards for security audits.

Certified Professional (CISSP) | A vendor-neutral certification for information security created by (ISC)² that requires professional experience in security domains.

Confidentiality | A CIA triad concept associated with keeping private information private. It is often regulated by law.

Chain of trust | A sequence of programs that may be verified by the TPM. One Linux program in the chain of trust is GRUB.

Content Scramble System (CSS) | A Digital Rights Management (DRM) scheme used to encrypt commercial DVDs.

Cracker | In the open source community, a cracker is a malicious user who wants to break into a computer system.

Cyrus | An e-mail server developed by Carnegie Mellon University, primarily for IMAP version 4 e-mail delivery.

Challenge-Handshake Authentication Protocol (CHAP) | A protocol for validating users before allowing access, which includes a challenge to verify the identity of a user.

Daniel J Bernstein's DNS (djdbns) | A relatively light-weight DNS server.

Default runlevel | The group of services started by default. Two major DNS services on Linux are BIND and djbinds.

Dovecot | An open source email service, designed for regular and secure versions of the POP and IMAP protocols.

DSA | For Digital Signature Algorithm. used by the U.S. government for digital services.

Electronic Frontier Foundation (EFF) | The Electronic Frontier Foundation (EFF) is a self-described-nonprofit created to protect the digital rights of consumers.

Algama | A probabilistic encryption scheme developed by Taher Elgam (also spelled Elgam)

Encapsulating Security Payload (ESP) | An encryption protocol that normally provides authenticity, integrity, and confidentiality protection of network packets.

enterprise cryptographic filesystem (ecryptfs) | A system developed by Ubuntu to encrypt directories: uses the ecryptfs command.

Eric Raymond | Eric Raymond.

Exim | The open source SMTP server developed by the University of Cambridge. The default MTA for Debian systems.

Extended internet server server | A server that listens for requests on multiple ports or hosts multiple services. As a single daemon, it saves resources. The term “internet” is normally used in lowercase, as it refers to an interconnected set of networks, not the Internet. Its configuration file is /etc/inetd.conf . That file normally refers to service files in the /etc/inetd.
