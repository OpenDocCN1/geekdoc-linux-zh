password=option2password
label=windows

By default, LILO does include the noted prompt directive, which allows administrators to boot into a system in single-user mode. Also known as runlevel 1, single-user mode automatically boots a system into the root administrative account. The user is not prompted for the root password.

In this configuration, the image and initrd point to links from the top-level root directory to the actual locations of the Linux kernel and RAM disk files. It's equally valid to point these to the full path to the actual files.

> NOTE: if you choose LILO, it should be installed on the MBR of one of the first hard drives on a system. If you configured a different boot loader on the MBR, you can set up LILO on the partition with the /boot directory. If it's the first partition of the first SATA drive, the associated command is lilo /dev/sda.

Other versions of LILO are available; the version created for HP Antarctica 64-bit systems is designed for Extensive Firmware Interface (EFI)-based hardware. However, the last version of LILO for standard PCs and servers was released in 2007. Most work from Linux developers on the boot loader now focuses on GRUB.
