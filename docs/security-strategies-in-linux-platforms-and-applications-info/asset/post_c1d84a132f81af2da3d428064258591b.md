
## 482 Glossary Key Terms

Live CD | May refer to a CD or DVD with a bootable operating system. That same data may also be loaded on a USB drive. Several Linux distributions are available in live CD format. When loaded, it provides password-free root access to the system.

Lucid Lynx (10.04) | The name of the Ubuntu distribution released in April of 2010 with long-term support.

Lyon, Gordon "Fyodor" | A prominent white-hat hacker. The developer of nmap command. In the open source security community by the single name "Fyodor".

Mail delivery agent (MDA) | Related to servers such as Dovecot that facilitate the delivery of e-mail to users.

Mail retrieval (MDA) | Associated with servers that collect e-mail from networks, such as fetchmail.

Mail submission agent (MSA) | Related to servers that authenticate user connections to e-mail services. Frequently integrated into MTAs as sendmail and Postfix.

Mail transfer agent (MTA) | Associated with servers that transmit e-mail, such as sendmail and Postfix.

Mail user agent (MUA) | Associated with e-mail applications such as Evolution and Thunderbird.

Main repository | A reference to the Ubuntu repositories of supported open source software.

Mandatory access control | A security system that limits access to objects such as files and directories to specified users and groups. Mandatory access control may be modified only by authorized administrators. Examples of systems implementing mandatory access control include SELux and AppArmor.

Mandriva | A Linux distribution based in France and Brazil.

Mangled | Describes a network packet with corrupted headers.

Martian packet | A packet with an impossible source or destination address. For example, a packet from the Internet with a source address of a private Internet Protocol (IP) address network would be a Martian packet.

Masquerading | A reference to network translation when private Internet Protocol (IP) addresses on a network with a public IP address, of the gateway to the network.

Master browser | A system assigned to maintain a database of network entries and their services such as domain or workshop membership.

Master Linux | A live CD distribution that incorporates the tools associated with the Sleuth Kit.

Message Digest (MD5) | A cryptographic function with a 128-bit hash value. Also used to encrypt Linux passwords in the /etc/shadow file.

Meta package | A Linux package that refers to other packages. 1. linux-image is a meta-package that refers to the latest version of the generic kernel built for Ubuntu.

Modular kernel | A kernel with components that are loaded during the boot process. Components depend on detected hardware, configuration files, and more.

Monolithic kernel | A kernel with components that are loaded during the boot process. Components depend on detected hardware, configuration files, and more.

Multicast Domain Name Service (mDNS) protocol | Supports automated Internet Protocol (IP) addressing a Dynamic Host Configuration Protocol (DHCP) server. Microsoft's private IP addressing and Apple's Bonjour protocols. Communicates using both TCP and UDP over port 5353.

Multi-Processing Modules (MPMs) | Modules used to add functionality to the Apache web server.

Multiverse repository | A reference to the Ubuntu repositories of unsupported software under restricted licenses.

MySQL | The open source database program, currently owned by Oracle.

## Glossary of Key Terms

Nessus | A vulnerability scanning program with a Web-based interface, based on code that was previously released under open source licenses.

netcat | A utility that can read TCP and UDP packets. normally associated with the nc command.

Network Address Translation (NAT) | A method of assigning IPSec-protected IP addresses to paths through network address translation.

Network attached storage (NAS) | A storage system connected to a network, normally using file-sharing protocols such as NFS and Samba.

Network Basic Input/Output System (NetBIOS) | A name for a system, commonly assigned to Microsoft-style networks; associated with the session layer of the OSI model.

Network File System (NFS) | A file-sharing service originally developed for UNIX.

Network Information Service (NIS) | A directory service for network-authentication. Its database can be created from the files of the shadow password suite.

Network Security Toolkit (NST) | A Linux distribution based on Fedora with a variety of security testing tools, including many of those listed at http://secools.org/. Released in CD format.

Network Time Protocol (NTP) | A protocol for synchronizing clocks over a network.

Privileged user | an account with standard end-user operating system permissions. This type of user does not have administrative permissions that would be found with a superuser, root, or administrative account.

Open source | A development practice in which source code is released publicly. Open source licenses allows others to use and improve upon that same code, as long as they give credit to the original developers. The General Public License (GPL) is one open source license.

Open Systems Interconnection (OSI) | A model of networking similar to the Transmission Control Protocol/Internet (TCP/IP) protocol suite. While the OSI model has seven layers, the TCP/IP protocol has four layers.

Open Trusted Computing (OpenTC) | A consortium of security professionals and organizations sponsored by the European Union. ISECOM is working through OpenTC to modify standards for the TPM chip.

OSTMM Professional Analyst (OPA) | A certification sponsored by ISECOM for professionals who can assess legal requirements, design security tests, and manage controls in the context of the scientific method.

OSTMM Professional Security Expert (OSPE) | A certification sponsored by ISECOM for entry-level security professionals.

OSTMM Professional Security Tester (OSTP) | A certification sponsored by ISECOM for Linux professionals qualified to use various security programs.

OSTMM Professional Wireless Security Expert (OWSE) | A certification sponsored by ISECOM for professionals who can audit a network infrastructure.

Owner feature | A feature requested by the FEC for inclusion in TPM chips that would enable fine-grained control over its use.

Online Certificate Status Protocol (OCSP) | A protocol and server to check revoked digital certificates.

Paravirtualization | A reference to paravirtualization, a software interface that is similar to the underlying hardware. May require a special kernel.

Parkerian hexad | Supplements the CIA triad of confidentiality, integrity, and availability with three more goals: possession or control, authenticity, and utility.

Open Source Security Testing Methodology (OSSTMM) | A manual for security audits, testing, and analysis, created through ISECOM.

Passphrase | A sequence of characters used to control access, frequently used to verify connections to encrypted services such as SSH. Unlike passwords, passphrases can include spaces. The best passrases consists of a sequence of words and numbers with upper and lower case characters along punctuation.

PostgreSQL | An open source database program, sponsored by a variety of open source and other IT companies.

Password Authentication Protocol (PAP) | A protocol for validating users.

Pre-boot Execution Environment (PXE) | A feature of a network card that gives the system ability to boot from a remote location.

Patch | In the context of the Linux kernel, a patch is an incremental update to the Linux kernel.

Pretty Good Privacy (PGP) | A program that encrypts messages based on private and public keys.

Perl | A dynamic scripting language developed by Larry Wall; frequently used with Web sites.

Primary Domain Controller (PDC) | A master server on a Windows domain that controls access to resources. Samba can be configured as a PDC.

Phishing | An attempt to get users to reveal sensitive information such as usernames, credit-card numbers, and more, through a spoofing attack.

File Transfer Protocol daemon (ProFTPD) | A popular FTP server with a basic configuration similar to Apache.

PHP | Hypertext Preprocessor (PHP) | A scripting language associated with Web sites.

Process Identifier (PID) | A number associated with the process running on a system. The PID of currently running processes can be found with the ps command.

Physical Security (PHYSSEC) | A configuration of ISECOM for audits.

Protocol analyzer | Colloquially known as a sniffer, a protocol analyzer can listen in messages monitored on a network. One protocol analyzer is Wireshark.

Ping of death | A malicious packet of ICMP data to a system that may be used to crash a computer system.

Ping storm | A condition where a flood of ICMP packets to a server. May be created with the ping -f command.

pSeries | The IBM RISC server and workstation line for UNIX systems; some Red Enterprise Linux releases are built for pSeries.

Pluggable authentication modules (PAM) | For Linux, PAM is a set of configuration files that provide dynamic authentication for administrative and other services.

Public switched data network (PSDN) | A reference to the current digital telephone network.

PolicyKit | Supports fine-grained administration tools from regular accounts. The focus of the PolicyKit is on the GNOME desktop.

Public switched telephone network (PSTN) | A reference to the regular telephone network for voice communications.

Possession or control | A Parkerian hexad for control of confidential information.

Pure File Transfer daemon (Pure-FTPD) | An actively supported server that can run 100 percent with non-root accounts.

Post Office version 3 (POP3) | An application layer e-mail protocol that supports e-mail downloads of incoming messages.

Python | A multi-paradigm programming language frequently used with Web sites.
