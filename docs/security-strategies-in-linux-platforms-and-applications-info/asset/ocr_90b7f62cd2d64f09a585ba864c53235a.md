# 488 Glossary of Key Terms

Unified Extensible Firmware Interface (UEFI)
The UEFI is the first thing that's run when you power up a new computer. It identifies and tests hardware to a point where an operating system can be loaded from media such as a hard drive.

Virtual host | The operating system that hosts virtual machine software.

Virtual LAN (VLAN) | A LAN created on the same physical network as another LAN. Because both lanes are separate and distinct, they are virtual.

Virtual network computing (VNC) | A system for sharing views of graphical desktop environments over a network.

Universe repository | A reference to the Ubuntu repositories of unsupported software under open license.

Upstart | A system designed to replace /sbin/init command and the V system of runlevels. Related configuration files can be found in /etc/event.d/ directory.

Virus | In computing, a program that can copy itself and infect a computer with malware.

User Datagram Protocol (UDP) | A member of the Transmission Control Protocol/Internet Protocol (TCP/IP) protocol that supports connectionless best-effort communications

VMware | A family of virtual machine software that works with everything from software-based virtualization programs like VMware Player to bare metal virtualization with programs like vSphere.

Voice over IP (VoIP) | A general term for voice-messaging protocols on Transmission Control Protocol/Internet Protocol (TCP/IP) networks.

User ID (UID) | The number associated with a user name in Linux, as defined in /etc/passwd.

User group | The standard in Linux where a group is created for every user. By default, the user and group names (along with the UID and GID numbers) are identical. The user is the only standard member that group.

Washington File Transfer Protocol (W-FTP) | A popular FTP server is no longer supported and is reported to have security flaws.

White-hat hacker | In the Linux community, a hacker is a who wants to create better software. In the non-linux security community, a white-hat hacker is an authorized user who runs security diagnostic tools to test the security features of a system or network. In this book, a white-hat hacker has both ports.

User-space | Refers to tools that do not depend on the Linux kernel.

Utility | A Perak hexad related to the CIA concept of availability. For example, encrypted data is not useful if the encryption key is.

Winbind | A component of the Samba file server that supports integration of Linux/Unix and Microsoft authentication information.

Windows Internet Name Service (WINS) | A Windows server includes a database of NetBIOS names and Internet Protocol (IP) addresses.

Wireless intrusion detection system (WIDS) | Software that can help detect unauthorized attacks on a wireless network; one example is available from the crack-ng package.

Van Eck phishing | A method for interpreting the emissions from computer displays to recover the associated image.

very secure File Transfer daemon (vsftpd) | The one open FTP server which was developed by Red Hat, SUSE, and Debian to share their distributions.

Wireshark | A protocol analyzer. Previously known as Ethereal.

Virtio block device | A virtualized device in a hardware-virtualized machine, designed for faster hard drives.

Virtual guest | The operating system installed inside a host's virtual machine software.

Worm | A self-replicating malware program; different from a Trojan horse, which is not self-replicating.
