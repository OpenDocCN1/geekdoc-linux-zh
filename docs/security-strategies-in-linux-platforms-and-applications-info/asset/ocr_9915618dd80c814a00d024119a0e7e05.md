# CHAPTER 14 | Detecting and Responding to Security Breaches

There are several excellent Linux-based forensics tools for Microsoft operating systems. Some can be used directly on compromised systems to recover dynamic data. These tools include Digital Evidence & Forensic Toolkit (DEFT) and Computer Aided Investigative Environment (CAINE). While these systems are configured on live CD media (built from Ubuntu), they include Microsoft executable commands that can help directly recover dynamic data from active Microsoft systems. For more information, see http://www.deftlinux.net/ and http://www.caine-live.net.

# Media to Recover Dynamic Data from Compromised Systems

Perhaps the most common option for recovering dynamic data from compromised systems is known as the Sleuth Kit. Another option that is no longer freely available is the distribution formerly known as Helix, now owned by Access Data. Which is the right option depends on cost and the amount of effort you are willing to put into the process. One option that incorporates the commands associated with the Sleuth Kit is the Master Key Linux, developed at Coventry University in the United Kingdom.

While there is a substantial number of organizations that offer 'forensic' software for Linux, very few options support the recovery of dynamic data, especially from specific files in the /proc/ directory. For similar tools, search for Memory Analysis tools. Other related tools under development Second Look from http://pikeworks.com/ and the Forensic Analysis Toolkit from http://4pthi.net/fatkit/. Neither of these tools is currently as advanced as the others.

If none of the previous options are suitable, you can create your own tool. Helix is open source, uncompiled tools are available online. With a little effort, you can compile the latest version of these tools into a custom system, ready to recover dynamic data from compromised systems. After reviewing the options, you may want to use two or more of the tools on a compromised system.

# Helix Live Response

Perhaps the most popular suggestion for compromised Linux systems is Helix Knoppies. No option longer exists in the open source sphere, however. Perhaps the popularity of Helix Knoppies encouraged its developers to commercialize this Linux distribution. By the name, it was formerly created from the Knoppies live CD. While it could be booted like the Knoppies live CD, it could also be mounted on a suspect system. Key commands were available from the mount point.

Since Helix was acquired by Access Data, the developers have moved to a different model. It is now built on Ubuntu Linux. The forensic acquisition do not directly access files from the /proc/ directory. Helix products are no longer available under any sort of GNU General Public License (GPL). Support and purchasing is available from e-fence, with more information at http://www.accessdata.com/ and http://www.e-fense.com.
