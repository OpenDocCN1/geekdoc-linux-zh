# Glossary of Key Terms

# 475

**required | A PAM flag that labels a configuration line that must work for the authentication attempt to succeed. However, if the line fails, PAM continues to check the other lines in the file.

**sufficient | A PAM flag that labels a configuration line. If the line works, PAM immediately returns a success message in the authentication attempt.

**requisite | A PAM flag that labels a configuration line that must work to succeed. However, if the line fails, PAM immediately returns a failure in the authentication attempt.

**syslog | The system log message service, associated with the syslog daemon. When known as klog. It is sometimes shown as the syslog daemon.

**root | By itself, root is the name of the standard Linux administrative user. The top-level root directory is symbolized by the forward slash (/). In contrast, the directory of the root is /root, which is a subdirectory of the top-level root directory (/).

**sysstat | A package that tracks the RAM and CPU usage on a system, with the help of the cron service.

**rsync | A command that synchronizes files from one location to another; may be used in conjunction with SSH.

**pm-tools | The Linux package with management tools for the tracers package. associated with the Trusted Computing Software Stack and the TPM chip.

**secon | A SELinux command that sets the contexts of a specified file or directory.

**passwd | The Linux package associated with the Trusted Computing Software Stack, in support of the TPM team.

**session | A PAM module that can control monitoring and logging. Also known as session management.

**update-rc.d | A command that manages the scripts that start and stop in different runlevels. Normally associated with the Ubuntu and Debian Linux distributions.

**setatus | A SELinux command that returns the overall status of SELinux on the local system.

**useradd | A command that can add a user.

**setfacl | The command to create or modify ACLs

**userdel | A command that can delete a user.

**passwd | A command that can modify the settings of a user in the shadow password file.

**sg | A command that can connect with the privileges of another user. Requires a group password in /etc/shadow.

**usquota | The mount option that sets user quotas; often found in /etc/fstab.

**smb.conf | The configuration file for the Samba/CIFS file server.

**vsftpd.conf | The configuration file for the very secure FTP daemon.

**sshd | The daemon for the SSH service.

**w | A command that lists currently logged in users and the process currently running by that user.

**trace | A command that traces the system calls by another command; primarily used for troubleshooting.

**warn | A log priority that provides warning messages; may also be shown as warning.

**su | A command that can connect with the privileges of another user. When no target user is specified, the root administrative user is assumed.

**who | A command that lists currently logged in users.

**sudo | A command that can connect as the administrative user if authorization is configured in /etc/sudoers.

**xfs | The Linux filesystem developed by Silicon Graphics to support larger files.

**yum | Short for Yellowdog Updater. Modified. A command that can install packages with all dependent packages.
