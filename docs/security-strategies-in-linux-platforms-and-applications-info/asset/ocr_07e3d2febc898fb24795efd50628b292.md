# The iptables Service

On Red Hat systems, there is an iptables service in the /etc/init.d/ directory normally started during the boot process. It reads options from /etc/sysconfig/iptables configuration file. On Ubuntu systems, when an iptables firewall is configured, additional configuration may be required to make sure the firewall starts during the boot process. The results may be similar. For example, the aforementioned u package also installs a ufw script in /etc/init.d/ directory.

If you prefer to create a custom firewall, you can use the iptables-save and iptables-restore commands. When applied to a specific file, these commands can save current rules and restore them from a given file. Such commands can be added to appropriate network configuration scripts to make sure the firewall is started during the boot process.
