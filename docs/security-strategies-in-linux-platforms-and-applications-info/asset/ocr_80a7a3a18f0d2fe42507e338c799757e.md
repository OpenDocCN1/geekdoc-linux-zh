# The Apache Web Server

Administrators who run the Apache Web server can stay up to date with security issues through the Apache Server Announcements list. To sign up, send an e-mail to announce-subscribe@http.apache.org. For a current list of vulnerabilities, navigate to http://http.apache.org/security_report.html.

The developers behind Apache maintain several versions of its Web server in a manner similar to the developers behind the Linux kernel. As of this writing, they still maintain version 1.3 and 2.0. They release security updates to these versions of their Web server on a regular basis.

Apache has an excellent guide to keeping Web sites on its servers. For more information, see http://http.apache.org/docs/2.misc/security_tips.html. These tips are updated with each new version; if version 2.4 is active when you read this, replace 2.2 with 2.4 in the URL.

If you've discovered a security issue that has yet to be reported, the Apache team encourages reports on their private mailing lists. For more information on the procedures, see http://www.apache.org/security/.
