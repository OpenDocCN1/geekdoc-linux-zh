# CHAPTER 7 | Networks, Firewalls, and More

| TABLE 7-2 Basic SELINUX control commands |
| COMMAND | DESCRIPTION |
| audit2allow | Reviews cited logs and returns options that would allow actions that violate current SELINUX policies. To see how it works, run the audit2allow < /var/log/audit/audit.log command. |
| audit2why | Translates SELINUX audit messages into more understandable reasons for a SELINUX violation. To see how it works, run the audit2why < /var/log/audit/audit.log command. |
| avstat | Displays AVC statistics related to SELINUX activity. |
| chcat | Specifies categories for SELinux security. Configured in /etc/selinux/targeted/setrefs.conf; to see current categories, run the chcat -L command. |
| fixfiles | Relabs specified files; do not apply to a system except by rebooting to avoid instability; for example, the fixfiles -R packlename restores the original contexts of files from the noted packlename. |
| genhomedir | Generates contexts from home directories of valid regular users. For example, the genhomedir command by itself uses the file_contexts homedir configuration in the /etc/selinux/targeted/contexts/ directory. |
| getenforce | Returns the current mode of SELinux: enforcing, permissive, or disabled. |
| getsebool | Finds the value of the noted SELinux boolean. For the complete list, run the getsebool -a command; values are stored in the /selinux/booleans/ |
| load_policy | Loads the currently configured policy into the kernel; activates configured changes. |
| matchpath | Identifies the original SELinux security context for a specific directory. |
| open_init_pty | Opens and runs a program in a pseudo-terminal. |
| restorecon | Restores the original SELinux security contexts. When used with -r, the command, works recursively. |
| restorecond | Specifies the daemon with the original SELINux contexts on a file. When run by itself, it focuses on files listed in the /etc/selinux/restorecond.conf file. |
| run_init | Runs an init script in SELINux contexts, based on the /etc/selinux/targeted/contexts/initrc_context file. |
