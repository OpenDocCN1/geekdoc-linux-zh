While Red Hat and Ubuntu are moving away from the PolicyKit GUI configuration tool, it is still for those who might be more familiar with GUI tools. It's available on slightly older releases as Ubuntu Hardy Heron and Fedora 11. An example is shown in Figure 4-4.
You can configure PolicyKit options to regulate access from regular users to a number of systems, as described in Table 4-9. You can find the associated configuration in the file /etc/dbus-1/system/ directory. These files regulate the interface between the dbus system and the PolicyKit.
The list of PolicyKit subjects is evolving, so what you see in Table 4-9 is just a partial list.

# More on the PolicyKit Configuration

The actual PolicyKit configuration directives, once processed from their locations in the /etc/ directory, can be found in /var/lib/polkit-1/ or /var/lib/PolicyKit/) subdirectories. Perhaps the most interesting work can be found on the Fedora project.
Once a regular or administrative user is properly authenticated, future PolicyKit configuration files likely mean that a regular user won't have to constantly enter a password for regular desktop tasks such as changing the time zone on the local clock.
