# CHAPTER SUMMARY

The focus of this chapter was user security. It started with the files of the shadow password suite. Within that structure, Linux administrators can assign standard and administrative privileges based on group memberships. You can further customize administrative privileges based on the /etc/sudoers file. The SUID, SGID, and sticky bits may be used to set up specialized privileges for executable files and shared directories. Login access can be tracked through logs in the /var/log/ directory. PAM modules can further customize user access to key administrative tools. The PolicyKit can go even further to customize user access within the GNOME desktop environment. Two Linux-based options are available for network-based authentication: NIS and LDAP.
