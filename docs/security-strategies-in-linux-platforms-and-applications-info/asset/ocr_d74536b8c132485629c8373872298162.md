# Glossary of Key Terms

Black-hacker | A user who wants to break into computer systems and networks with malicious purposes in mind.

Bootstrap Protocol (BOOT) | A protocol of the Transmission Control Protocol/Internet Protocol (TCP/IP) suite associated with automatic assignment of IP addresses may also be used for the acquisition of IP addresses from a Dynamic Host Configuration Protocol (DHCP) over a remote network. Associated with UDP port 68.

Bugzilla | A Web-based bug-tracking tool commonly used on open source projects from Red Hat to the GNOME desktop environment.

Challenge-response authentication mechanism (CRAM) | A group of protocols where a service as open server presents a challenge as a request for a username and password.

Chroot jail | One type of operating-system-level virtualization. When a program or service routes clients to a directory, a chroot jail limits the view of system. In some cases, a chroot jail limits all of the binaries, libraries, configuration files, and executables required to run a service that is contained.

CIA triad | The CIA triad secures three goals of information security: confidentiality, integrity, and availability.

Cache poisoning | A frequently malicious insertion of non-authoritative data in DNS as it were unauthorized. May be used by black-hat hackers to redirect users to malicious sites.

ClAntivirus (ClamAV) | A cross-platform antivirus toolkit developed for and used on Linux, and derivatives of UNIX.

Cobbler project | An open source project for network-based installations of Linux distributions.

CAINE | Short for Computer Augmented Environment, a bootstrap live CD distribution available from http://www.caine.net/

Common UNIX Printing System (CUPS) | The default print server for modern Linux distributions. By default CUPS uses the Internet Protocol (IP), it can also manage printers in a number of other protocols.

Canonical | The company that provides the rate breaker of the Ubuntu.

CentOS | Short for the Community Enterprise Operating System. CentOS is sometimes known as a rebuild. This is because it is a distribution built by third parties, based on code released for the Red Hat Linux distribution.

Common Vulnerabilities and Exposures (CVE) list | A list of operating-system security issues maintained by the MITRE corporation and sponsored by the National Security Division of the U.S. Department of Homeland.

Certificate Authority | An entity that issues digital certificates for use by other parties. Secure sites without an official CA return an error message.

Communications Security (COMSEC) | COMSEC is one of the ISO standards for security audits.

Certified Professional (CISSP) | A vendor-neutral certification for information security created by (ISC)² that requires professional experience in security domains.

Confidentiality | A CIA triad concept associated with keeping private information private. It is often regulated by law.

Chain of trust | A sequence of programs that may be verified by the TPM. One Linux program in the chain of trust is GRUB.

Content Scramble System (CSS) | A Digital Rights Management (DRM) scheme used to encrypt commercial DVDs.

Cracker | In the open source community, a cracker is a malicious user who wants to break into a computer system.

Cyrus | An e-mail server developed by Carnegie Mellon University, primarily for IMAP version 4 e-mail delivery.

Challenge-Handshake Authentication Protocol (CHAP) | A protocol for validating users before allowing access, which includes a challenge to verify the identity of a user.
