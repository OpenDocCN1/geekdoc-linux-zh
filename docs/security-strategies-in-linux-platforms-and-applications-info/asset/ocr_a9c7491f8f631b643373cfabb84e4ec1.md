# Glossary of Key Terms

Access vector cache (AVC) | An access permission associated with SELinUX.

Access control lists (ACLs) | In Linux, access control lists allow authorized users to set the permissions with a file or directory. These permissions can supersede standard discretionary access controls.

Access vector | In security, an access permission represented by a bitmap; commonly stored for SELinux security in an access vector cache.

Advanced Encryption Standard (AES) | An encryption standard configured by the National Institute of Standards and Technology (NIST).

Advanced Intrusion Detection Engine (AIDE) | An intrusion detection system; available in both Red Hat and Ubuntu repositories.

Anaconda | The Red Hat installation program.\ Andrew Filesystems | A distributed filesystem, sometimes with Kerberos tokens.

Andrew Tannebaum | See Tannebaum, Andrew. Apache | A web server used primarily on Linux. is currently the most popular web server on the Internet.

Application Armor (AppArmor) | A mandatory access control system used to create security profiles for different programs. It uses Linux modules in the kernel. Not compatible with SELinux.

Architecture | In the context of computing, a reference to the type of CPU, such as i86 for 32-bit Intel and AMD systems.

Asterisk | The open source private branch exchange (PBX) VoIP service.

Authentication Header (AH) protocol | A protocol that guarantees integrity and data-authentication of network packets.

Authenticity | A Kerian head concept related to the CIA triad of integrity. Authenticity can help users verify that important communications, such as messages, are genuine.

Availability | A CIA triad concept in which users have access to their data when they want it.

AVG | A company that creates anti-malware systems for Linux and other operating systems.

Backport | A feature from a future version of a software-component that is incorporated into an update of an earlier release. Backports are commonly applied to kernels with a certain version number to incorporate additional features without overriding any sort of certification of third-party software related to the kernel.

Backport | In the context of the kernel, an incorporated feature from a later kernel.

BackTrack | A Linux distribution currently based on Ubuntu with penetration testing tools loaded in CD and USB format. Available from http://backtrack-linux.org.

Backup Domain Controller (BDC) | A backup for a PC on Microsoft Windows domain: Linux with Samba can be configured as a BDC.

Base management controller (BMC) | An interface embedded in the motherboard. In some cases, it may be configured to allow access to the system boot menu.

Basic Input/Output System (BIOS) | The first thing that runs when you power up an older computer. The BIOS identifies and tests hardware to a point where an operating system can be loaded from media such as a hard drive.

Bastion server | A secured host dedicated for a specific purpose. It is configured with a minimum number of services to limit its exposure to attacks.

Berkeley Internet Name Domain (BIND) | A common DNS server on the Internet, originally created at the University of California at Berkeley, maintained by the Internet Systems Consortium.

Berkeley Software Distribution (BSD) | A clone of UNIX, similar to Linux, released under different licenses.

Binary kernel | When the source of a kernel is installed in an package, it is changed from a human-readable format to a binary format readable by a computer.

Biometric controls | Identification controls based on unique characteristics of authorized personnel. May be used for authentication to secure a secure location as a server room.
