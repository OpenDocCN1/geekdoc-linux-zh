# Authorization Log Files

The aforementioned log files are important tools to keep a secure system. Courtesy of the /etc/logrotate.conf file and a regular cron script, logs are rotated on a weekly basis. Linux systems configured in this way typically contain several weeks of logs. Logs from previous versions have a ? where the ? is a number. (The ? is a standard Linux alphanumeric wildcard).

The size of these logs may be important. A jump in the size of any log file indicates increased activity. While this increased activity may just be a result of user-based cron jobs running more frequently

The log excerpt in Figure 4-2 displays messages associated with an attempt to log into a system named RHELserver, first as user test and then as user test1. It provides information on the protocol, the IP address of the attacker, and the result.

# Pluggable Authentication Modules

PAM is used primarily to regulate access to administrative tools and commands. It works as an additional layer of security for users. A substantial number of services and systems are PAM-aware. In other words, with the right modules, access to those services and systems can be regulated by rules defined in PAM configuration files in the /etc/pam.d/directory.

To review PAM modules for your distribution, search the applicable applications. On a Red Hat-based system, you can search with the yum search command. On an Ubuntu system, you can search with the apt-cache search libpamcommand. Just the titles in the output shown in Figure 4-3 may provide a full feel for the full capabilities of PAM.
