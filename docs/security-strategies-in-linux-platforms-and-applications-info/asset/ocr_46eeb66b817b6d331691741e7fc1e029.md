# Service Reviews

Once you've configured the distribution, you should check currently active and installed services. Active services can typically be found in one of locations: the scripts in the /etc/init.d/ directory or the files in the /etc/xinetd.d/ directory. Figure 6-2 shows the list of /etc/init.d/ services for a minimal installation of Red Hat Enterprise 5.

The services that are actually active during the boot process are listed in the relative directory associated with the default runlevel for the distribution. Debian-style systems including Ubuntu is runlevel 2. The default runlevel for Red Hat-style distributions generally depends on whether a GUI was included in the installation process. If so, the Red Hat kernel is 5. The default boot runlevel for such systems is 3.

Now take a look at Figure 6-3 for the services that are active in a Hat runlevel 3. The figure displays the contents of the /etc/rc.3/ directory. The services that start with an S are started in the runlevel, followed by those that start with K, which are shut down when entering this runlevel. Even though this is a minimal installation, you should already sense that some work is required to pair this down. You'll see more detail later in the chapter.

> NOTE
Through Red Hat Enterprise 5, the default runlevel and associated parts of the boot process were configured in the /etc/initabb configuration file. While that file is based on the originally designed configuration of UNIX System V, or SysV for short, it is in the process of changing. Starting with the Ubuntu 8.04 release, Ubuntu is moving toward a system as Upstart, where the information is contained in the files of the /etc/event/ directory. The companies behind other major Linux distributions, including Red Hat and Nov, have indicated that they will move future services toward Upstart.
