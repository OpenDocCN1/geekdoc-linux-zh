# Glossary of Key Terms

# 483

Nessus | A vulnerability scanning program with a Web-based interface, based on code that was previously released under open source licenses.

netcat | A utility that can read TCP and UDP packets. normally associated with the nc command.

Network Address Translation (NAT) | A method of assigning IPSec-protected IP addresses to paths through network address translation.

Network attached storage (NAS) | A storage system connected to a network, normally using file-sharing protocols such as NFS and Samba.

Network Basic Input/Output System (NetBIOS) | A name for a system, commonly assigned to Microsoft-style networks; associated with the session layer of the OSI model.

Network File System (NFS) | A file-sharing service originally developed for UNIX.

Network Information Service (NIS) | A directory service for network-authentication. Its database can be created from the files of the shadow password suite.

Network Security Toolkit (NST) | A Linux distribution based on Fedora with a variety of security testing tools, including many of those listed at http://secools.org/. Released in CD format.

Network Time Protocol (NTP) | A protocol for synchronizing clocks over a network. Privileged user | An account with standard end-user operating system permissions. This type of user does not have administrative permissions that would be found with a superuser, root , or administrative account.

Open source | A development practice in which source code is released publicly. Open source licenses allows others to use and improve upon that same code, as long as they give credit to the original developers. The General Public License (GPL) is one open source license.

Open Systems Interconnection (OSI) | A model of networking similar to the Transmission Control Protocol/Internet (TCP/IP) protocol suite. While the OSI model has seven layers, the TCP/IP protocol has four layers.

Open Trusted Computing (OpenTC) | A consortium of security professionals and organizations sponsored by the European Union. ISECOM is working through OpenTC to modify standards for the TPM chip.

OSTMM Professional Analyst (OPA) | A certification sponsored by ISECOM for professionals who can assess legal requirements, design security tests, and manage controls in the context of the scientific method.

OSTMM Professional Security Expert (OSPE) | A certification sponsored by ISECOM for entry-level security professionals.

OSTMM Professional Security Tester (OSTP) | A certification sponsored by ISECOM for Linux professionals qualified to use various security programs.

OSTMM Professional Wireless Security Expert (OWSE) | A certification sponsored by ISECOM for professionals who can audit a network infrastructure.

Owner feature | A feature requested by the FEC for inclusion in TPM chips that would enable fine-grained control over its use.

Online Certificate Status Protocol (OCSP) | A protocol and server to check revoked digital certificates.

Paravirtualization | A reference to paravirtualization, a software interface that is similar to the underlying hardware. May require a special kernel.

Parkerian hexad | Supplements the CIA triad of confidentiality, integrity, and availability with three more goals: possession or control, authenticity, and utility.

Open Source Security Testing Methodology (OSSTMM) | A manual for security audits, testing, and analysis, created through ISECOM.
