
## CHAPTER 11 | Managing Security Alerts and Updates

While Apache 2.4 may not be officially released for some time, unstable versions of this software are available. Normally, production systems should not include beta versions of critical service applications as Apache. However, Apache 2.4 includes several enhanced security features, including the ability to check an Online Status Protocol (OCSP) server for the current status of a digital certificate. If a black-hat hacker is able to get his or her official certificate through nefarious neighbors, OCSP access can protect users.

For your convenience, Apache makes its software available in binary packages for Red Hat and Ubuntu systems (in formats suitable for deb and pkg commands). However, such packages may not have been tested by the developers behind these distributions.

## Samba File Server

Administrators who run the Samba file server can stay up to date with the Samba Security Web page at http://www.samba.org/samba/history/security.html. Updates are provided in patch format. To incorporate these updates, you'll need the Samba source code. You can then apply the noted patch in a similar manner to applying a patch to the Linux kernel source code as described in Chapter 10.

Alternatively, you can wait until the developers build a distribution process to patch them into your own binary files. Once updated, you can use the applicable package management tool to download and upgrade the new Samba software.

The patch release as described on the Samba Web site is different from the release made by the developers of a distribution. Such developers may have to do additional work to incorporate the newly released patches in a manner compatible with other packages associated with the distribution.

The developers behind Samba maintain several versions of its file software in a manner similar to the Linux kernel. As of writing, they will maintain versions 3.3 through 3.5. The developers behind Linux distributions may incorporate the code for patches in earlier versions of Samba. For example, Ubuntu would take the patch associated with Samba version 3.5, and incorporate the associated code in Samba 3.0. That is also known as backport.

If you've discovered a significant security issue in Samba, encourage e-mail reports to security@samba.org.

## Antivirus Systems

Antivirus systems, loosely defined, include systems that can detect all types of malware. While not all malware affects an operating system, it can be transmitted by e-mail and carried by files with common formats. On any computer system, malware falls into several categories, which include:

- Rootkit—A rootkit is malware that can help a black-hat hacker gain administrative control over a computer system.
- Spyware—Spyware is malware that collects user information; may include keystroke logging.
- Trojan horse—A Trojan horse is a type of malware that hides as a desirable program that facilitates unauthorized access.
- Virus—Strictly speaking, a computer virus is a program that can copy itself and infect a computer.
- Worms—Self-replicating malware can send itself to other systems. A worm is different from a virus in that it does not require direct user involvement to spread.

Responsible Linux administrators include antivirus software on their systems. While there are fewer targeted at Linux than Windows operating systems, the number of users who run it with administrative privileges is configured to discourage running commands with administrative privileges; it is possible to configure Linux with only the root account. So Linux is not immune. While Linux may be a more difficult target for black-hat hackers, it is still a target. Some Linux applications such as the Apache Web server have a dominant market share.

Even though black-hat hackers create malware components for Linux systems, Linux can still act as a carrier. In other words, Linux services such as e-mail servers, FTP servers, file servers, may carry malware that remains dormant until exposed to Microsoft or an Apple operating system.

Perhaps the most common malware for Linux systems is based on the rootkit, software that allows a black-hat hacker to take over a system with root administrative privileges. Related to the rootkit is any malware that supports easy access for unauthorized users.

Be aware, only some of the tools described in this section are released under the GNU Public License (GPL).

## The Clam Antivirus System

The Clam Antivirus (ClamAV) system is an open source (GPL) antivirus toolkit for UNIX, designed especially for e-mail scanning on mail gateways (http://www.clamav.net/lang/en/). In fact, it is designed to work with e-mail servers such as sendmail, Postfix, and Exim. It works on UNIX-type operating systems Solaris, Berkeley Standard Distribution (BSD), and Linux.

It searches archives, compressed files, and more. It's updated on a regular basis. If you use ClamAV, it may be in your best interest to subscribe to the associated mailing lists at http://clamav.net/. As noted on that page, mailing lists are available in several languages.

Just beware, ClamAV is not supported by Red Hat or Canonical. While it can be installed from Ubuntu repositories, packages from such repositories are not officially supported by Canonical. Repositories for installing ClamAV are maintained by third parties. For more information, see http://www.clamav.net/lang/en/download/packages/packages-linux/.

Commercial support is available from Sourcefire, Inc., which also provides commercial intrusion-detection solutions at http://www.sourcefire.com.

## AVG Antivirus Option

While AVG is focused on the Microsoft antivirus market, the group also makes anti-malware tools for Linux. The cost and degree of support varies. These are as follows:

- AVG Anti-Virus for Linux—AVG makes a freely downloadable antivirus tool targeted primarily for Linux clients. It makes software available in a number of formats, including those based on Red Hat and Ubuntu (Debian) package-management systems. As noted by AVG, this software is available for private and non-commercial use. While AVG does maintain message boards for this software, few messages on that board relate Linux.

- AVG Server Edition for Linux—AVG makes a commercial antivirus tool as well: this edition includes antivirus, spyware, and anti-spam tools.
