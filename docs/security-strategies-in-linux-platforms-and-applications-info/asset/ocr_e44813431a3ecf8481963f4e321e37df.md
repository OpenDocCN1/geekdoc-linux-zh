# CHAPTER 3 | Basic Security: Facilities Through the Boot Process

# CHAPTER SUMMARY

The focus of this chapter is on the boot process—from the moment a system is powered up to the time you can log into a Linux system. It covered basic security issues related to physical and virtual servers. To that end, it described how you can lock down Linux boot loaders. This chapter also covered how obscurity can help, from the BIOS/UEFI menu through options with four different boot loader menus. It also covered basic security in the context of the five process controls as defined by the OSSTMM.
