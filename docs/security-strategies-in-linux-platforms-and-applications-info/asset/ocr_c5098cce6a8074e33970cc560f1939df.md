The permissions may appear too generous. You don't want everyone to be able to

actual file, /boot/grub.conf. On Red Hat systems, permissions are read-write
for the user owner of the file.

# Changing File Permissions

The focus of this section is the chmod command. The most efficient way to use chmod
is based on an octal representation of the permissions of the user owner, group owner, and
other users. Each type may or may not have read, and execute permissions. That's
three bits. In a binary system, 2^3 = 8, which is why such permissions can be represented
octally, as described in Table 5-3.

For example, a file with read, write, and execute permissions is given a value of 7,
obtained by simply adding together the numerical representations of the desired permiss-
sions (4 + 2 + 1 = 7).

| TABLE 5-3 Permissions represented in octal format |
| PERMISSION | NUMERICAL REPRESENTATION |
|--- |--- |
| r | 4 |
| w | 2 |
| x | 1 |
