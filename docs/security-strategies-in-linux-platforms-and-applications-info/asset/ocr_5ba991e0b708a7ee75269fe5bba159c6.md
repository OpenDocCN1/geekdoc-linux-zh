# CHAPTER 6 | Every Service Is a Potential Risk

The minimal installations of many distributions, including RHEL 5, include many more services than is desirable on a bastion host. Ideally, you should uninstall unneeded services. But that is not always realistic, as critical software may not work unless some services that appear to be unnecessary are also installed. But you can at least make sure unnecessary service is not active. Opinions vary on some software; for example Red Hat and the NSA have varying conclusions on some services.

When bastions are configured on a virtual machine, generally you should set up something other than a bridged network. A combination of NAT and port forwarding can be used to direct desired traffic to bastion servers.

In general, administrators will take care to remove development tools from every active system. If a black-hat hacker breaks into a system with development tools, then black-hat hacker could use those tools to build more dangerous malware.

Other services are controlled through the regular and extended internet servers. Some services may be made more secure with the use of a chroot jail.

You should avoid the installation of a GUI where possible. Many users will require up a GUI, however. Most Linux distributions have disabled the xauth and xhost commands because of security risks. If possible, you should also disable access via the XDMCP protocol.

Most Linux administrators work without a GUI. That is made possible courtesy of some important and sometimes using tools. Surprisingly, the ssh service ensures remote administration. The telnet command with the right port number can be used to verify activity in a number of services. Other text tools such as elinks, mutt, and mail can be used to test various services.

When you do need to configure a GUI, it's best to limit available choices of productivity tools. Because Linux is all about choice, many options are available for browsers, office suites, and e-mail clients. To reduce the risks to a network and to reduce the load on a network connection to the Internet, you want to limit those choices.
