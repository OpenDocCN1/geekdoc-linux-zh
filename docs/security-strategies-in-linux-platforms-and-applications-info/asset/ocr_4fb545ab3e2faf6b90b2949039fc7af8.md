# CHAPTER 5 | Filesystems, Volumes, and Encryption

+   - Elgamal—A probabilistic encryption scheme developed by Taher Elgamal. When running the gpg command, this scheme is paired with DSA for digital signatures.
- DSA—Digital Signature Algorithm, used by the U.S. government for digital signatures.
- RSA—A public-key algorithm, named for its developers, Rivest, Shamir, and Adleman.

Despite the available options, the documentation from the developers of GPG suggests that you should choose the first option because the other options provide digital signatures. The latest version of Ubuntu includes a fourth option, which includes RSA-based encryption and digital signatures. If it is the first time you are using the gpg --gen-key command, you will see the following messages:

```
gpg: directory `/home/michael/.gpgup` created
gpg: new configuration file `/home/michael/.gpgup/gpg.conf` created
gpg: WARNING: options in `/home/michael/.gpgup/gpg.conf` 
are are not active during this run
gpg: keyring `/home/michael/.gpgup/secring.gpg` created
gpg: keyring `/home/michael/.gpgup/pubring.gpg` created
```

After selecting a key, be prepared to select the following:

+   - An encryption-key size between 1,024 and 4,096 bits
- A lifetime in days, weeks, months, or years; alternatively; choose the default of 0, which means the key does not expire
- A name, e-mail address, and comment
- A passphrase

The key depends in part on a random number generator. If you get a "not enough bytes available message", you'll need to run a command that reads or writes a lot. One simple method is to open up a second terminal and run the command a few times:

```
$ cat /boot/initrd* > /dev/null
```

To confirm the creation of a private and public key pair, run the gpg --list-keys command. This assumes you've set up the gpg command on both local and remote systems. The first two steps export and copy public-private key on system A. The user on system B can encrypt a file and then send it to user A. Finally, user A can use or her private key to decrypt the file.
