# Glossary of Key Terms

# 485

Qmail | The self-declared replacement for sendmail, developed by Daniel J. Bernstein, who also developed djdbns.

Restricted repository | A reference to the Ubuntu repositories of software released under restricted licenses.

Richard Stallman | See Stalin, Richard.

Root Trust for Measurement (RTM) | Part of a Trusted Computing concept, known as the roots of trust. The core RTM may reside in the first boot program, by BIOS or UEFI.

RainbowCrack | A password tool to identify passwords that are too simple for a secure system.

Raymond, Eric | A leader of the open source movement. Author of The Cathedral and the Bazaar. As cofounder of the open source initiative at http://www.opensource.org.

Root Trust for Reporting (RTR) | Part of a Trusted Computing concept, known as the roots of trust. The RTR reports the integrity of a software component using SHA-1.

Real-time Transport Protocol (RTP) | A standard packet format for VoIP and video communications.

Root Trust for Storage (RTS) | Part of a Trusted Computing concept, known as the roots of trust. The RTS uses an endorsement key to verify the FTM data implicitly operated by the operating system.

Rebuild | A Linux distribution built from source code released by another distribution. For example, CentOS uses Red Hat core. CentOS Linux is a replica of Red Hat Enterprise Linux.

Rootkit | A specialized type of malware that enables a black-hacker to take root access of a Linux system.

Recursive query | A search of a DNS database is sent to other DNS servers if the information is not available locally.

RSA | A public-key encryption algorithm, named for its developers. Rivest, Shamir and Adleman.

Red Flag Linux | A Linux distribution deployed in China.

Rsyslog | The latest system for system and kernel logs; also supports secure transmission of log information to a central logging server.

Red Hat | The company behind the leading Linux distribution in the marketplace.

Runlevel | A mode of operation in Linux with a group of services and daemons. Specified services and daemons are started or killed when a particular runlevel

Red Hat Network (RHN) | A group of management services to manage packages, scripts, and more. Such services may be applied to subscribed clients and servers on a network.

Samba | A file and printer sharing service compatible with Microsoft's Common Internet File System.

Red Hat Proxy Server | A proxy server dedicated to downloading packages from the Red Hat Network.

Sarbanes-Oxley (SOX) Act | A law that specifies financial disclosure requirements for public companies.

Red Satellite Server | A version of the Red Hat Network designed for local use on an enterprise network: includes an embedded Oracle database.

Secure Hash Algorithm (SHA) | A set of cryptographic hash functions developed by the U.S. National Security Agency.

Red security advisories (RHAS) | Announcements of security issues from the Red Hat Security Team.

Secure Hash Algorithm 1 (SHA-1) | A set of cryptographic functions generated by the U.S. National Security Agency (NSA). Because of a weakness In the National Institute of Science and Technology (NIST) has sponsored a competition for the development of SHA-3.

Remote Authentication Dial In Service (RADIUS) | A system for user authentication, frequently used to authenticate connections over telephone modems.
