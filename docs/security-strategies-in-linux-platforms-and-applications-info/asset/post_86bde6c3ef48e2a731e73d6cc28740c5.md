
# Glossary of Key Terms

# 479

Extra Packages for Enterprise Linux (EPEL) | An open source project to create packages over and those available for Red Hat Linux; may include functional backports from later versions of Linux.

Gordon "Fyodor" Lyon | See Lyon, Gordon "Fyodor".

Gramm-Leach-Biley Act (GLBA) | U.S. law that specifies confidentiality requirements for personal financial data.

Fedora Linux | The Linux operating system developed by the Fedora Project and sponsored by Red Hat.

Grand Unified Bootloader (GRUB) | The default boot loader for Ubuntu, Red Hat, and many other Linux distributions. Versions of GRUB are in common, with different options for security.

File Transfer Protocol (FTP) | A standard protocol and service for exchanging files.

Graphical desktop environment | In Linux, the graphical desktop environment is separate from but requires the use of an X Window Server. It may also include a window manager to control the placement of windows within GUI. Common Linux desktop environments are GNOME and KDE.

Filesystem | A protocol for organizing and storing files. Most filesystems require a format; typical formats include ext2, ext3, ext4, refs, and xfs.

Graphical login manager | A service for graphical logins to Linux. Three standard Linux graphical managers are GDM, KDM, and XDM.

Filesystem Hierarchy (FHS) | The ways files and directories are organized in Linux. The FHS includes a list of standard directories and the types of files normally stored in those directories.

Greg Kroah-Hartman | See Kroah-Hart.

Group ID (GID) | The number associated with a group name in Linux, as defined in /etc/group and /etc/shadow.

Free Software Foundation (FSF) | The organization behind the GNU project.

GRUB 2.0 | A new version of the Grand Bootloader (GRUB), yet not in use by many Linux distributions.

Generic services application interface (SSAPI) | An application programming interface that communicates between Kerberos and services as NFS.

H.264 | A professional video-compression standard licensed by Canon for use in the Lucid Lynx release of Ubuntu.

GNOME Desktop Manager (GDM) | A graphical login manager built by the developers of the GNOME environment. May be used to log into graphical desktop environments other than GNOME.

Hacker | In the open community, hacker just wants to create better software. The open source community of hacker is to white-hat hacker. Do not confuse this definition with the non-open source security community of hacker, which is closer to black-hat hacker.

GNU Compiler collection (GCC) | An open source compiler suite that supports a variety of programming languages, including C, Java, and Fortran.

Hardy (8.04) | The name of the Ubuntu distribution released in April 2008 with long-term support.

GNU General Public License (GPL) | One of several open source licenses used to share the source code for software.

Hash function | A one-way function that converts a large amount of data to a single (length) number in an irreversible manner.

GNU Privacy Guard (GPG) | The open source implementation of PGP, developed by the GNU Foundation.

Health Insurance Portability and Accountability Act (HIPAA) | A U.S. law that specifies security requirements for personal health data.

GNU Not Unix (GNU) | A recursive of the GNU Foundation, including the clones of UNIX tools and libraries found in current Linux distributions.

# 480 Glossary of Key Terms

Honeypot | A honeypot is a computer system designed to detect attacks by black-hat hackers to break into a network. It includes data that appears to be of value. It is carefully monitored, and isolated from other systems on the local network.

Internet Key Exchange (IKE) protocol | A protocol for key exchange used to set up a user association between systems.

Johnpper | A password tool designed to identify passwords that are too simple for a secure system.

Internet Message Access Protocol 4 (IMAP4) | An application e-mail protocol that supports client access to remote servers.

Internet Protocol Security (IPSec) | A member of the Transmission Control Protocol/Internet Protocol (TCP/IP) protocol that supports encrypted connections.

Inode | A data structure associated with a file.

Institute for Security and Open Methodologies (ISECOM) | The organization associated with open source security certification and testing. ISECOM qualifies security professionals with four certifications: OSPA, OSPE, OSPT, and OWPE.

Internet Protocol version 4 (IPv4) | A version of the Internet Protocol still in use today. IPv4 addresses use 32 bits.

Institute of Electrical and Electronics Engineers (IEEE) | A professional organization of electrical and electronics engineers; also the group bound standards as 802.11 for wireless communication.

Internet Protocol version 6 (IPv6) | A more recent version of the Internet Protocol in use today. IPv6 addresses use 128 bits.

Integrated Services Digital Network (ISDN) | A group of standards for digital transmission of voice and data over the public telephone network.

Internet server | A server that listens for requests on multiple ports behalf of multiple services. As a single daemon, it saves resources. The term "internet" is normally shown in lower case, as it refers to an interconnected set of networks, not the Internet. Its configuration file is /etc/inetd or in inetils, and it is obsolete on most distributions. It is still used by some third-party software.

Integrity Measurement Architecture (IMA) | A Linux security module developed by IBM to check the integrity of executables files before they're loaded during the boot process.

ISER | An IBM system that uses IBM Performance Optimization With Enhanced RISC (POWER) CPUs. A family of 64-bit CPUs developed by Intel. Red has supported Itanium CPUs through Red Enterprise Line 5, but without support in later releases.

Integrity | A CIA triad of trust, verified by means such as GPG keys.

Inter-Cache Protocol (ICP) | A protocol used for communications with Web proxy servers such as Squid.

Java Cryptography Extension (JCE) | A framework for encryption associated with the programming language; may also be used with open source sendmail.

International Information Systems Certification Consortium (ISC)² | An organization for security professionals. qualifies professionals through the SSCP and CISSP certifications.

Internet Assigned Names Authority (IANA) | The organization for domain names, IP addresses, and Transmission Control Protocol/(TCP/IP) protocols on the Internet.

Journaled files | A filesystem that keeps track of changes to be written. Recovery tools can use the journal to quickly find data on files to be written.

# 506 Glossary of Key Terms

Kaspersky | A company that creates anti-malware for Linux.

KDE Display Manager (KDM) | A graphical login manager built by the developers of the KDE environment. May be used to log into graphical desktop environments other than GNOME.

Kernel-based Virtual Machine (KVM) | A virtual machine monitor. In Linux, it requires a specialized kernel. Supports hardware virtualization and paravirtualization.

Kernel-space | Tools that depend on drivers and modules with the kernel.

Kickstart | A network-based installation system first created for Red Hat.

Knoppix | A Linux distribution well known for its CDs and DVDs.

Koah-Hartman, Greg | The Linux kernel developer responsible for the release of stable kernels.

Kubuntu | A release of the Ubuntu distribution that includes the KDE desktop environment as the default GUI
