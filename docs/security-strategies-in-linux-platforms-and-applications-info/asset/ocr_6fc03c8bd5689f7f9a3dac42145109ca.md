# Glossary of Key Terms

**Stock kernel** | A reference to the kernel developed and released by the Linux Kernel Organization.

**Storage area network (SAN)** | A storage system that may consist of one or more NAS or DAS systems.

**Root Key (SRK)** | An RTS key used to encrypt keys stored outside the TPM chip.

**Subversion** | A system for version control used by many open source projects, including kerap.

**SUSE** | A Linux distribution originally developed in Germany, now owned by Novel.

**System Administrators Integrated Network Tool (SAINT)** | A vulnerability scanning program with a Web-based interface, based on code that was previously released under SATAN open source licenses.

**Systems Security Certified Practitioner (SSCP)** | A vendor-neutral certification for information security created by (ISC)². Suited to candidates working towards becoming security professionals.

**Tannenbaum, Andrew** | The main developer behind the Minix distro, one of the first clones of UNIX. A proponent of micro kernel, in opposition to Torvalds' use of a modular kernel.

**Tarball** | A collection of a (normally compressed) archive of files, managed with the tar command.

**TCG Software Stack** | An open source software stack of programs to work with the TPM chip. May be downloaded and installed as the truss package.

**TCP Wrappers** | An access control list system for services accessed by the internet server. It can also protect services linked to the library.

**Telephone modem** | A modulator-demodulator for translating data bits into the sine waves of the PSTN. Cable modems and DSL modems are not modems, as they do not modulate or demodulate data.

**Telnet** | A protocol and service that uses clear-text authentication.

**TOMY** | A Linux security module for mandatory access control; functionally similar to SELinux.

**Torvalds, Lin** | The developer of the first Linux kernel. The leader of Linux kernel developers.

**Transition Signature (TSIG)** | A protocol used to authenticate data exchanges between DNS servers.

**Transmission Control Protocol (TCP)** | A member of the Transmission Control Protocol/Internet Protocol (TCP/IP) suite that supports reliable connections.

**Tripwire** | An intrusion detection system; open and commercial versions are available.

**Trivial File Protocol (FTP)** | A protocol and service that uses a simplified form of FTP.

**Trojan horse** | A kind of malware that disguises itself as a useful program or command.

**Trusted Computing Group (TCG)** | An industry consortium for security. The TCG defines standards in a number of areas, including networks, PC clients, a software stack, and trusted networks. The TCG is the group behind standards for the TPM.

**Trusted Platform Module (TPM)** | A chip that can be installed as a motherboard. May be used for password protection, software license protection, digital rights management, and disk encryption. Controversial with some in the open source community, including the Free Software Foundation (FSF) and the Electronic Frontier Foundation (EFF).

**TrustedGRUB** | A specialized version of GRUB that can work with the TPM in a chain of trust.

**Ubuntu** | A Linux distribution based on Debian. The name is a word taken from the Zulu and Xhosa languages that roughly translates as "humanity toward others."

**Ubuntu security notices (USNs)** | Alerts based on security issues that affect different releases of the Ubuntu distribution.
