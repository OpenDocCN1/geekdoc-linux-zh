FYI

Third-party repositories designed for Ubuntu and even Red Hat Enterprise Linux are frequently located in countries where copyright laws hold less sway. For example, some third-party repositories include video players that may bypass legal requirements such as the Digital Millennium Copyright Act (DMCA).

While such packages are popular among Linux users, the presence of such packages that you administer may expose your organization to legal liability.

# Configure a Local Repository

It's easy to use the remote repositories already configured for most Linux distributions. The connections to such repositories have already been tested. If a problem arises with such systems, many administrators are likely to complain, and the problem is likely to get fixed quickly without any additional intervention.

However, there are advantages to maintaining a local repository. At minimum, a local repository reduces the load on a core Internet connection. If you want to keep it simple, you could use an rsync command to join a mirror repository or use a service available for that purpose as Red Hat's Proxy or Satellite Servers. The commercial options are described in the next section.

Just a few mirrors support sync connections. Those that do understand that the rsync command is used to synchronize local and remote systems. To review the repositories that are mirrored on the servers of the Linux Kernel Organization, run the following command:

```
$ rsync mirrors.kernel.org:
```

Be aware: Mirrors, especially if they involve multiple architectures, can occupy dozens of gigabytes of space. So you need available space, and you should run the command at a time when demand on the Internet connection is relatively low. To explore the Ubuntu-based mirrored repositories, run the following command:

```
$ rsync mirrors.kernel.org::ubuntu/dists/
```

You then select a repository subdirectory, such as lucid-updates/ for update packages for the Ubuntu Lucid Lynx release. The following command includes all update packages in the main, restricted, universe, and multiverse repositories and synchronizes them to the local /updates/ directory:

```
$ rsync -avz
```

```
mirrors.kernel.org::ubuntu/dists/lucid-updates/. /updates/
```

The switches synchronize files in archive (-a) mode, with verbose (-v) output, using compression (-z) in the data-transfer stream. You can repeat the process for other repositories, such as backports in the lucid-backports/subdirectory.
