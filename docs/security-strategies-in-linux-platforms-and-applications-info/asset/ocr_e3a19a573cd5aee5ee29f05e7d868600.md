# Glossary of Key Terms

Daniel J Bernstein's DNS (djdbns) | A relatively light-weight DNS server alternative to BIND. It is released under a public-domain license, which is not open source.

Default runlevel | The group of services and daemons started by default when Linux is booted. Other services and daemons are started in other runlevels. If Linux is already running, moving to the default runlevel may also stop other services and daemons.

DEFT | Built upon Linux, DEFT contains a number of live tools for recovering data from Microsoft operating systems, available from http://www.delinux.net/

Demilitarized zone (DMZ) | An area of network that is protected from the Internet by one layer of firewalls. The main network is further protected from this area by a second layer of firewalls.

Denial of service (DoS) | An attack by overloading a network service, denying access to regular users. All DOS attacks are malicious, as they can be accidental results of certain types of connection attempts. Nevertheless, they may be blocked or slowed down as if they were attacks.

Dependency hell | a colloquial description of one type of error related to the installation of a package with the rpm or dpk command. The installation is not completed because the package depends on another. Dependency hell occurs when dependencies descend to another level.

Digital Millennium Copyright Act (DMCA) | A U.S. copyright law associated with digital intellectual property. Contrary in particular cases of prosecution by researchers looking for better forms of encryption. One intent is to prevent the decryption of systems enabled with DRM schemes.

Direct attached storage (DAS) | A storage system connected directly to one or more computer systems using cables; unlike NAS, DAS systems do not use network protocols to share data.

Discretionary access control | A security control system that limits access to objects such as files and directories to specified users and groups.

Discretionary access control may be modified by authorized users.

Disk encryption subsystem | The system used to encrypt partitions and data. Part of the device mapper associated with the loadable dm_crypt module.

Domain Name System (DNS) | A hierarchical data-base of domain names and Internet Protocol (IP) addresses. Two major DNS services on Linux are BIND and djbinds.

Dovecot | An open source email service, designed for regular and secure versions of the POP and IMAP protocols.

DSA | For Digital Signature Algorithm. used by the U.S. government for digital services.

Electronic Frontier Foundation (EFF) | The Electronic Frontier Foundation (EFF) is a self-described-nonprofit created to protect the digital rights of consumers.

Algama | A probabilistic encryption scheme developed by Taher Elgam (also spelled Elgam)

Encapsulating Security Payload (ESP) | An encryption protocol that normally provides authenticity, integrity, and confidentiality protection of network packets.

enterprise cryptographic filesystem (ecryptfs) | A system developed by Ubuntu to encrypt directories: uses the ecryptfs command.

Eric Raymond | Eric Raymond.

Exim | The open source SMTP server developed by the University of Cambridge. The default MTA for Debian systems.

Extended internet server server | A server that listens for requests on multiple ports or hosts multiple services. As a single daemon, it saves resources. The term “internet” is normally used in lowercase, as it refers to an interconnected set of networks, not the Internet. Its configuration file is /etc/inetd.conf . That file normally refers to service files in the /etc/inetd.
