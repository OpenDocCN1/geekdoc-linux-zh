# Glossary of Key Terms

# COMMANDS

**chgrp** | The command that assigns a new group owner to a file.

**account** | A PAM module that can verify account validity based on expiration dates, time limits, or configuration files with restricted users. Also known as account management | A command that manages scripts that start and stop in different levels. Normally associated with the Red Hat and SUSE distributions.
**chmod** | The command that modifies permissions to a file.

**chown** | The command that assigns a new user owner to a file.

**alert** | A log priority that specifies problems that require immediate attention. | **cdrestart** | An command frequently available in the /etc/init/ directory. When used, it restarts a service only if it is already running. It is in contrast to the restart option, which restarts a service even if it's not already running.

**apparmor** | An AppArmor command loads the configured profiles of various commands and services.| **cron** | A service for running administrative jobs on a regular basis; protected by the /etc/cron.allow and /etc/cron.deny files.

**apt-cache** | A command that searches the cache of package information. Normally associated with the Ubuntu and Debian distributions. | **cryptsetup** | The command used to encrypt partitions using the device mapper.

**apt-get** | A command normally used to install a package with all dependent packages. Normally associated with the Ubuntu and Debian distributions.| **dbus** | A message bus system for interprocess communication between a variety of applications and devices.

**quota.group** | The group quota management file., **quota.user** | The user quota management file. | **dd_rescue** | A variation on the dd command that reads data from back to front on a specified partition, volume, or drive. It is more error tolerant than dd.

**at** | A service for running administrative jobs on a one-time basis; protected by the /etc/at.allow and /etc/at.deny files.| **dd** | Known as the disk command, it supports a full copy of all data on a partition, volume, or drive.

**auth** | A PAM module that can verify passwords, group memberships, and Kerberos tickets. Also known as authentication method.| **desums** | A command on Ubuntu and Debian systems that uses the MD5 checksums to see if changes have been made to files relative to their original status as part of installed packages.

/boot/grub/grub.conf | **debug** | The lowest log priority; also provides the greatest detail.

**chage** | A command that can modify related information for a user, such as the pass-word expiration date.

**chcon** | A SELinux command that can be used to change the AVC contexts associated with a file.
