# CHAPTER 4 | User Privileges and Permissions

If you select one of the options in Figure 4-1, the User Settings tool applies the usermod command to the subject user member of the noted group. Of course, as a Linux administrator, you may choose to apply the usermod command directly. Alternatively, you can add desired users to the noted groups more directly by editing the /etc/group and /etc/shadow files. After, all these files can be modified in any text editor.

Table 4-7 may help you identify groups associated with the descriptions in Figure 4-1. The groups in the table are group names found in the /etc/group and /etc/shadow files. Some descriptions in the User Settings window may be less than perfect. For example, "ethernet" should not be lowercase, and sharing files with the local network should not be limited to Samba. As development proceeds, the descriptions in the User Settings window in Figure 4-1 may change.

> TIP Don't modify a text configuration file with a binary editor as OpenOffice.org Changes written to those files are likely to render them unusable. Changes to key configuration files may lead to unstable systems. If you want to edit the files of the shadow password suite, use the vip and vigr commands. Commands override the read-only permissions of the /etc/shadow and /etc/shadow files.
