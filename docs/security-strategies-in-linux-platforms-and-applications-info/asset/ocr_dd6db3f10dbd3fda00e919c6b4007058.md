# The Right Place to Install Security Testing Tools

If a system has been compromised, it's too late to install security testing tools on that machine. Issues such as backdoors or Trojan horses could provide opportunities for black-hat hackers who might want to mislead you about what they are doing. On the other hand, if you know a good baseline system is secure, it's a candidate for the installation of security testing tools as those described in this chapter.

The number of security testing tools that are available on live media such as CDs, DVDs, and USB keys suggests the excellence of such media as a secure location for security testing tools.

# Hint: Not Where Crackers Can Use Against You

Ideally, security testing tools should be installed only on secure systems. But that leads to a bit of a loop. How do you know if a system is secure until security testing tools have been used to check it? As strange as it sounds, there is a small element of faith involved. You can start with a reputable Linux distribution released by a company like Red Hat or Canonical. You can work from standard installation programs as discussed in earlier chapters. Once those systems are up to date, you should have a reasonable baseline system.
