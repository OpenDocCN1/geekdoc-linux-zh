# 482 Glossary Key Terms

Live CD | May refer to a CD or DVD with a bootable operating system. That same data may also be loaded on a USB drive. Several Linux distributions are available in live CD format. When loaded, it provides password-free root access to the system.

Lucid Lynx (10.04) | The name of the Ubuntu distribution released in April of 2010 with long-term support.

Lyon, Gordon "Fyodor" | A prominent white-hat hacker. The developer of nmap command. In the open source security community by the single name "Fyodor".

Mail delivery agent (MDA) | Related to servers such as Dovecot that facilitate the delivery of e-mail to users.

Mail retrieval (MDA) | Associated with servers that collect e-mail from networks, such as fetchmail.

Mail submission agent (MSA) | Related to servers that authenticate user connections to e-mail services. Frequently integrated into MTAs as sendmail and Postfix.

Mail transfer agent (MTA) | Associated with servers that transmit e-mail, such as sendmail and Postfix.

Mail user agent (MUA) | Associated with e-mail applications such as Evolution and Thunderbird.

Main repository | A reference to the Ubuntu repositories of supported open source software.

Mandatory access control | A security system that limits access to objects such as files and directories to specified users and groups. Mandatory access control may be modified only by authorized administrators. Examples of systems implementing mandatory access control include SELux and AppArmor.

Mandriva | A Linux distribution based in France and Brazil.

Mangled | Describes a network packet with rhodified headers.

Martian packet | A packet with an impossible source or destination address. For example, a packet from the Internet with a source address of a private Internet Protocol (IP) address network would be a Martian packet.

Masquerading | A reference to network translation when private Internet Protocol (IP) addresses on a network with a public IP address, of the gateway to the network.

Master browser | A system assigned to maintain a database of network entries and their services such as domain or workshop membership.

Master Linux | A live CD distribution that incorporates the tools associated with the Sleuth Kit.

Message Digest (MD5) | A cryptographic function with a 128-bit hash value. Also used to encrypt Linux passwords in the /etc/shadow file.

Meta package | A Linux package that refers to other packages.1 linux-image is a meta-package that refers to the latest version of the generic kernel built for Ubuntu.

Modular kernel | A kernel with components that are loaded during the boot process. Components depend on detected hardware, configuration files, and more.

Monolithic kernel | A kernel with components that are loaded during the boot process. Components depend on detected hardware, configuration files, and more.

Multicast Domain Name Service (mDNS) protocol | Supports automated Internet Protocol (IP) addressing a Dynamic Host Configuration Protocol (DHCP) server. Microsoft's private IP addressing and Apple's Bonjour protocols. Communicates using both TCP and UDP over port 5353.

Multi-Processing Modules (MPMs) | Modules used to add functionality to the Apache web server.

Multiverse repository | A reference to the Ubuntu repositories of unsupported software under restricted licenses.

MySQL | The open source database program, currently owned by Oracle.
