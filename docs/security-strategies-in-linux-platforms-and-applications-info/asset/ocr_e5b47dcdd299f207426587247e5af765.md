# Glossary of Key Terms

Secure Hash Algorithm 3 (SHA-3) | A set of cryptographic functions developed through a competition sponsored by the National Institute of Science and Technology (NIST).

Sleuth Kit | A package of tools that can be used to save volatile data: intended for use on read-only media as commands on compromised systems.

Snort | An intrusion detection system (IDS)Snort | An intrusion detection system (IDS) with modes for packet analysis, logging, and interaction with iptables firewall; rules are updated on a regular basis.

Software RAID | A version of redundant array (RAID) of independent disks that partitions instead of disks as components of the array.

Solaris | A variant of UNIX originally developed by the Sun Microsystems.

Security Administrator Tool for Analyzing Networks (SATAN) | An older open source network analyzer. Later versions were released under proprietary licenses as of SANT.

SELinux | A mandatory access control system that uses Linux modules in the kernel. Developed by the U. National Security Agency. Not compatible with AppArmor.

sendmail | The open source SMTP server maintained by The Sendmail Corp. Do not confuse this with the commercial SMTP server known as sendmail.

Source code | Human-readable computer language that can be collected and compiled into a program, library, or application.

Sendmail | A commercial SMTP server maintained by Sendmail, Inc. Do not confuse this with the open source SMTP server known as sendmail.

SourceForge | A Web-based software service, available at http://sourceforge.net.

Session Initiation Protocol (SIP) | An Internet network protocol frequently used in VoIP communications.

Spacewalk | An open source systems management server on the source code of the Red Hat Satellite Server.

Set Group ID (SGID) bit | A special permission applied to a directory. With the SGID bit, users who are members of the group that owns the directory have permission to read and write to all files in that directory. The SGID bit assigns the group owner of the directory the group owner of all files copied to it.

Spamassin | A program for filtering unwanted e-mail.

Set User ID (SUID) bit | A special permission that allows others to execute the file with the rights of the user owner of the file.

Spectrum Security (SPESEC) | SPESEC is one of the ISECOM channels for security audits, to non-physical communications over the electromagnetic spectrum.

Shadow password suite | The files of the shadow password suite make up the local Linux password authentication database. The files are /etc/passwd,/etc/shadow, /etc/group, and /etc/passwd. As originally developed, it also includes the Linux login.in, and pass commands.

Spoofed | A reference to network transactions with a false source address.

Spoofing | An attack where a malicious user assumes the identity of another user or organization.

Spyware | A type of malware that collects information on users without their knowledge.

Simple Mail Transfer Protocol (SMTP) | An application-layer e-mail protocol primarily used for sending outgoing messages from clients.

Squid | A service that caches Internet data to speed response times that can also track the sites visited by users.

Stallman, Richard | President of the Free Software Foundation (FSF), the organization that founded the GNU project. Leading opponent of the TPM chip.

Simplified mandatory access control kernel (SMACK) | A Linux security module for mandatory access control; functionally similar to SELinux and AppArmor.

Sticky bit | A special permission applied to a directory. With the sticky bit and full permissions, all users can write to the associated directory. However, ownership is retained, so users won't be able to overwrite files by other users.
