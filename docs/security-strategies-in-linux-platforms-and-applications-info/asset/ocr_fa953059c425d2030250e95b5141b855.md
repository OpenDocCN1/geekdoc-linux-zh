# PolicyKit Concepts

The PolicyKit assumes privileged tools are associated with two distinct processes: policies and mechanisms. In this context, a policy defines rules for executing an administrative tool. A mechanism runs in privileged mode.

The mechanism includes three parts: the subject, the object, and the action. The subject is the administrative tool in question. The object is the device or file to be modified. That object may be a device or a configuration file. The action specifies how the device or configuration file is to be modified. For example, PolicyKit may act a USB key through its object configuration file, using a formatting administrative tool.

Because the PolicyKit is relatively new, it is a work in progress. Early versions of the PolicyKit were configured in part in /etc/PolicyKit/ directory. The PolicyKit also includes rules on /etc/dbus-1/system d. Once, you will find in in /var/lib/policykit/ or /var/lib/polkit/polkit-1/ directory.

Later versions of the PolicyKit replace the PolicyKit/ subdirectory with the polkit-1/ subdirectory.
