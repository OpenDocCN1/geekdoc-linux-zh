(troubled system) # /media/cdrom/dd < /proc/kcore
~/media/cdrom/nc diagnostic_ip_address 11111 -w 3

## Have Live CDs for Forensics Purposes

> TIP
Some Linux CDs may also be used to monitor and obtain data from suspect systems over a network. Basic techniques depend on the tcpdump command and Wireshark protocol analyzer.

As suggested in the previous section, you should have two different types of CDs (or similar media) available for forensics purposes. Some are suitable for mounting on a compromised system, to help the investigator download and save dynamic data from areas like RAM. Others are suitable as forensic live media. As such, they can be used for booting diagnostic systems. Once booted, such media can be used to save a copy of the partitions and volumes configured on compromised systems.

There are several excellent Linux-based forensics tools for operating systems. Some can be used directly on compromised systems to recover dynamic data. These tools include Digital Evidence & Forensic Toolkit (DEFT) and Computer Aided Investigative Environment (CAINE). While these systems are configured on live CD media (built from Ubuntu), they include executable commands that can help recover dynamic data from active systems. For more information, see http://www.deftlinux.net/ and http://www.caine-live.net.

> FYI
## Media to Recover Dynamic Data from Compromised Systems

The most common option for recovering dynamic data from compromised systems is known as the Sleuth Kit. Another option that is no longer freely available is the distribution formerly known as Helix, now owned by Access Data. Which the right option depends on cost and the amount of effort you are willing to put into the process. One option that incorporates the commands associated with the Sleuth Kit is Miles Linux, developed at Coventry University in the United Kingdom.

While there is a substantial number of organizations that offer 'forensic' software for Linux, very few options support the recovery of dynamic data, especially from specific files in the /proc/ directory. For similar tools, search for Memory Analysis tools. Other related tools under development are Second Look from http://pikeworks.com/ and the Forensic Analysis Toolkit from http://4the.net/fatkit/. Neither of these tools is currently as advanced as the others.

If none of the previous options are suitable, you can create your own tool. Helix is open source, uncompiled tools are available online. With a little effort, you can compile the latest version of these tools into a custom system, ready to recover dynamic data from compromised systems. After reviewing the options, you may want to use two or more of the tools on a compromised system.

## Helix Live Response

The most popular suggestion for compromised Linux systems is Helix Knppies. No option longer exists in the open source sphere, however. Perhaps the popularity of Helix Knppies encouraged its developers to commercialize this Linux distribution. By the name, it was formerly created from the Knppies live CD. While it could be booted like the Knppies live CD, it could also be mounted on a suspect system. Key commands were available from the mount point.

Since Helix was acquired by Access Data, the developers have moved to a different model. It is now built on Ubuntu. The forensic acquisition is not available under any sort of General Public License (GPL).
