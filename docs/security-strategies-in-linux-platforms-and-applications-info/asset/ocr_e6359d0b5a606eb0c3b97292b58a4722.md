# CHAPTER 9 | Networked Application Security

This is the minimum configuration required to set up Squid on a local area network (LAN). The next step is to create cache directories in the /var/spool/squid/directory with the following command:

```
# squid -z
```

Once the Squid service is running, you should be able to set client browsers on the local network to connect through the Squid service on port 3128. Of course, you'll also have to make sure that port is open in any applicable firewalls.

If you want to configure additional ports, examine the acl SSL_ports and acl Safe_ports directives. In the default squid.conf file, these directives are used to specify ports for security and other connections. These directives are often coupled with the following directives:

```
http_access deny !Safe_ports
http_access deny !SSL_ports
```

The exclamation point (!) is also known as a bang. In code, it's a reference to "anything but.". In other words, the directives show deny access to all configured Safe_ports and SSL_ports. Of course, with more than 4000 lines, Squid can do a lot more. The sections that follow scratch the surface of what Squid can do.

# Security-Related Squid Directives

Squid can do a lot more. This section scratches the surface of security-related squid directives. This section is based on the default squid.conf configuration file for version 2.6. These directives include the:

+   * auth_param—A directive that can be configured with a basic, digest, or an NT LAN Manager (NTLM) authentication scheme.
* authenticate-*A series of directives that provides a timeout for connections from clients.
* acl—Basic Squid-related acl control list directives were described earlier in this chapter.
* http_access—Basic Squid-related http_access directives were described earlier in this chapter.
* http_reply_access—Specifies systems allowed to answer replies. While the default is http_reply_access allow all, limits can regulate what your users can access online.
* icp_param—Access should be limited to other Squid servers.
* htcp_access—Based on the Hypertext Caching Protocol (HTCP), it sets ACLs to discover other caching servers.
