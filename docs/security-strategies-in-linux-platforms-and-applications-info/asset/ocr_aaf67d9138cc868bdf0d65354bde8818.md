# Persuaders To Convert to SSH

Ideally, you'll be able to persuade local users to connect to the SSH service earlier in this chapter using passphrases. You might even turn off Telnet servers and use SSH as the only available alternative. SSH is the most secure option available for remote access. One possibility is to present the steps associated with the two remote access options, by side. One example is shown in Figure 8-3, where a login to a regular Telnet server is compared to an SSH server using a passphrase. If you can convince appropriate that the SSH connection is no more difficult than the Telnet connection—and is more secure—you will have done an excellent job selling the secure remote access option.

# Install More Secure Telnet Servers and Clients

Unfortunately, not all users are easily convinced. You may need to consider alternatives—specifically, more secure versions of Telnet. Packages are available with SSL and Kerberos. Unfortunately, if the client is not using SSL or Kerberos-based Telnet clients, the default configuration of each Telnet server accepts regular clear-text Telnet.
