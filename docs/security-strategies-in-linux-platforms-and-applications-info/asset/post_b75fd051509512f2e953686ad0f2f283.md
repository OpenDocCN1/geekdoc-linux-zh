
# Glossary of Key Terms

## COMMANDS

- **chgrp** | The command that assigns a new group owner to a file.
- **account** | A PAM module that can verify account validity based on expiration dates, time limits, or configuration files with restricted users. Also known as account management.
- **chmod** | The command that modifies permissions to a file.
- **chown** | The command that assigns a new user owner to a file.
- **alert** | A log priority that specifies problems that require immediate attention.
- **cdrestart** | An command frequently available in the /etc/init/ directory. When used, it restarts a service only if it is already running. It is in contrast to the restart option, which restarts a service even if it's not already running.
- **apparmor** | An AppArmor command loads the configured profiles of various commands and services.
- **cron** | A service for running administrative jobs on a regular basis; protected by the /etc/cron.allow and /etc/cron.deny files.
- **apt-cache** | A command that searches the cache of package information. Normally associated with the Ubuntu and Debian distributions.
- **cryptsetup** | The command used to encrypt partitions using the device mapper.
- **apt-get** | A command normally used to install a package with all dependent packages. Normally associated with the Ubuntu and Debian distributions.
- **dbus** | A message bus system for interprocess communication between a variety of applications and devices.
- **quota.group** | The group quota management file.
- **quota.user** | The user quota management file.
- **dd_rescue** | A variation on the dd command that reads data from back to front on a specified partition, volume, or drive. It is more error tolerant than dd.
- **at** | A service for running administrative jobs on a one-time basis; protected by the /etc/at.allow and /etc/at.deny files.
- **dd** | Known as the disk command, it supports a full copy of all data on a partition, volume, or drive.
- **auth** | A PAM module that can verify passwords, group memberships, and Kerberos tickets. Also known as authentication method.
- **desums** | A command on Ubuntu and Debian systems that uses the MD5 checksums to see if changes have been made to files relative to their original status as part of installed packages.
- /boot/grub/grub.conf | **debug** | The lowest log priority; also provides the greatest detail.
- **chage** | A command that can modify related information for a user, such as the pass-word expiration date.
- **chcon** | A SELinux command that can be used to change the AVC contexts associated with a file.
- **ecryptfs** | The command associated with the enterprise cryptographic filesystem.
- **edquot** | The command to check and edit user quotas.
- **emg** | A log priority that specifies very important messages; may also be shown as panic or critic.
- **err** | A log priority that adds error messages; may also be shown as error.
- /etc/fstab | The configuration file for Linux systems.
- /etc/lilo | The main configuration file for the Linux Loader (LILO).
- /etc/services | The configuration file that associates Internet services with Transmission Control Protocol/Internet Protocol (TCP/IP) port numbers and protocols.
- **ext2** | The second extended filesystem.
- **ext3** | The third extended filesystem; includes journaling.
- **ext4** | The fourth extended filesystem; includes journaling and support for larger files.
- **fdisk** | One Linux partition configuration tool.
- **getfile** | The command to review ACL settings for a file.
- **gpg** | The command that can encrypt and add digital signatures to a file.
- **groupadd** | A command that can add a group.
- **groupdel** | A command that can delete a group.
- **groupmod** | A command that can modify the settings of a group in the files of the shadow password suite.
- **grquota** | The mount option that sets user quotas; often found in /etc/fstab.
- **info** | A log priority that adds notes at the information level.
- **iptables** | The Linux packet filtering command for firewalls and masquerading. While it is the primary command used for packet filtering, it can be used in network address translation.
- **ld** | A command that lists libraries used by a specific command; its use requires the full path to the target command.
- **lsof** | A command to list files: the lsof ni opens files related to networking, in numeric format.
- **mkfs** | The Linux command to format and bind a Linux filesystem. it's also root for filesystem commands such as mkfs.ext3 and mkfs.reiser, which set up a filesystem to the given format.
- **nc** | The implementation of the netcat command, which can test and communicate over TCP and UDP connections.
- **netstat** | A command used to verify connections by port, routing tables by Internet Protocol (IP) address, and more.
- **nfsnobody** | The default account for unauthorized users who connect to the NFS file-sharing server.
- **nftables** | A command used to replace iptables as a firewall configuration tool.
- **nmap** | A flexible command that can scan Transmission Control Protocol/Internet Protocol (TCP/IP) network communication by protocol and port.
- **nobody** | The default account for users on configured file-sharing servers.
- **notice** | A log priority that includes messages that might require attention.
- **optional** | A PAM flag that labels a configuration line is ignored ignored unless there are no other PAM flags in the file.
- **password** | A PAM module that can control changes to user passwords and limit the number of login attempts. Also known as password management.
- **portmap** | The RPC port number mapper. commonly used for services such as NFS and NIS.
- /proc/core | A file that dynamically represents the contents of RAM on the local system.
- **quotacheck** | A command that creates, checks, and repairs quota files such as quota.user and quota.group.
- **reiserfs** | The Linux filesystem based on trees, used for groups of large and small files.
- **required** | A PAM flag that labels a configuration line that must work for the authentication attempt to succeed. However, if the line fails, PAM continues to check the other lines in the file.
- **sufficient** | A PAM flag that labels a configuration line. If the line works, PAM immediately returns a success message in the authentication attempt.
- **requisite** | A PAM flag that labels a configuration line that must work to succeed. However, if the line fails, PAM immediately returns a failure in the authentication attempt.
- **syslog** | The system log message service, associated with the syslog daemon. When known as klog. It is sometimes shown as the syslog daemon.
- **root** | By itself, root is the name of the standard Linux administrative user. The top-level root directory is symbolized by the forward slash (/). In contrast, the directory of the root is /root, which is a subdirectory of the top-level root directory (/).
- **sysstat** | A package that tracks the RAM and CPU usage on a system, with the help of the cron service.
- **rsync** | A command that synchronizes files from one location to another; may be used in conjunction with SSH.
- **pm-tools** | The Linux package with management tools for the tracers package. associated with the Trusted Computing Software Stack and the TPM chip.
- **secon** | A SELinux command that sets the contexts of a specified file or directory.
- **passwd** | The Linux package associated with the Trusted Computing Software Stack, in support of the TPM team.
- **session** | A PAM module that can control monitoring and logging. Also known as session management.
- **update-rc.d** | A command that manages the scripts that start and stop in different runlevels. Normally associated with the Ubuntu and Debian Linux distributions.
- **setatus** | A SELinux command that returns the overall status of SELinux on the local system.
- **useradd** | A command that can add a user.
- **setfacl** | The command to create or modify ACLs.
- **userdel** | A command that can delete a user.
- **passwd** | A command that can modify the settings of a user in the shadow password file.
- **sg** | A command that can connect with the privileges of another user. Requires a group password in /etc/shadow.
- **usquota** | The mount option that sets user quotas; often found in /etc/fstab.
- **smb.conf** | The configuration file for the Samba/CIFS file server.
- **vsftpd.conf** | The configuration file for the very secure FTP daemon.
- **sshd** | The daemon for the SSH service.
- **w** | A command that lists currently logged in users and the process currently running by that user.
- **trace** | A command that traces the system calls by another command; primarily used for troubleshooting.
- **warn** | A log priority that provides warning messages; may also be shown as warning.
- **su** | A command that can connect with the privileges of another user. When no target user is specified, the root administrative user is assumed.
- **who** | A command that lists currently logged in users.
- **sudo** | A command that can connect as the administrative user if authorization is configured in /etc/sudoers.
- **xfs** | The Linux filesystem developed by Silicon Graphics to support larger files.
- **yum** | Short for Yellowdog Updater. Modified. A command that can install packages with all dependent packages.
