# A Minimal Ubuntu Installation

A minimal installation is a straightforward process for Ubuntu Server Edition. Since release 8.04, Ubuntu has included a minimal installation option from its boot media. The installation is compact; excluding swap space, it requires less than 400 MB of space on a hard drive and a minimum of just 128 MB of RAM. A minimal installation does not include a GUI, any service that you may configure on a bastion, or even the SSH service. Before you set up a minimal Ubuntu baseline, you'll want to install an administrative service like SSH. Of course, you'll also want to set up at basic IPv4 networking. If your Dynamic Host Configuration Protocol (DHCP) server supports hostname assignments, get otherwise. Otherwise, when you copy the partitions from the baseline system. Once configured, you'll be able to copy the partitions or even the virtual disk files to create additional Ubuntu installations.

Once the minimal installation is copied, you can verify the new installation, assign a new hostname, and install the necessary software packages based on the desired function-packages to see what the current list of services and packages can offer. Then you'll want to install the service that fits the function of the specific host. While that function may be any of the services associated with Linux, you shouldn't install more than one service on any single bastion.

# A Minimal Red Hat Installation

A minimal installation is a straightforward process for Red Hat. If you accept the defaults, however, Red Enterprise Linux 5 (RHEL) includes extra software such as a GUI, the OpenOffice.org site, and even games. None of these software packages are required for a Red Hat bastion. As long as you avoid these GUI-based packages, it's possible to use RHEL 5 with a relatively small amount of RAM. While 192 MB is frequently adequate, some trial and error may be required to find an optimal amount of RAM for your bastion system.

When creating a Red Hat prototype for a bastion, you'll need to deselect these options during the installation process. But even when these options are selected, the minimal Red Hat installation includes a number of services that aren't needed on most bastion servers.
