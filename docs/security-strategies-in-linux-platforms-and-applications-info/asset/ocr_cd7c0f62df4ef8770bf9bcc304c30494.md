# The Threat of the Live CD

> NOTE

While the live CD is an excellent option for some system rescues, many distributions leave options known as rescue or recovery mode through their installation CDs. Generally, it's best to solve boot problems with the rescue mode from that distribution's installation CD. On the other hand, some live CDs even include security tools that can be used by white-hat hackers to test or by black-hat hackers to break into a system. For more information, see Chapter 13.

It's not enough to set up usernames and passwords on your systems. A black-hat hacker with physical access may be able to boot a live Linux distribution such as Knoppix, Ubuntu, or CentOS directly on your servers. It doesn't matter if the Linux distribution differs from that on the hard drive. It also doesn't matter if the Linux kernel on the CD has a different version number. Many live CDs provide a graphical interface (GUI), making it relatively easy for less-experienced black-hat hackers to break into your system.

All that's needed is boot access from a CD/DVD drive or USB port. Once booted, a live CD provides-free administrative access to any system. At that point, it's easy to access hard drives on the local system.

# Boot Process Security

> NOTE

Of course, a black-hat hacker could disable BIOS/UEFI passwords by removing the associated battery. That's one reason many servers can and should be padlock.

Anyone with physical access to your systems may be able to access boot menus, such as those available through a BIOS or UEFI menu. These menus should be passwordprotected. Network access to the UEFI menu should be disabled. If possible, these menus should be used to exclude all options but the hard drive with the operating system from the boot process.

Boot process security extends to the boot menu for the operating system. Linux includes two options for boot loaders: the Unified Bootloader (GRUB) and the Linux Loader (LILO). Both loaders include their own boot menus. Both boot menus can be used to start other operating systems, as other versions of Linux or even Microsoft Windows. Both boot loaders also include a number of security risks.

In fact, unless password protected, boot loaders can be used to boot a system into single-user mode, with full administrative privileges. On Linux distributions, an administrative password isn't required to access this method.

Other boot loaders can be installed on most systems, including Microsoft options such as NLDR and bootmgr, as well as third-party options like Boot and Partition Magic. Each of these boot loaders can be used to start a Linux operating system. Because this is a book of securing Linux platforms and applications, Chapter 3 will focus on securing the Linux options.
