# Glossary of Key Terms

Passphrase | A sequence of characters used to control access, frequently used to verify connections to encrypted services such as SSH. Unlike passwords, passphrases can include spaces. The best passrases consists of a sequence of words and numbers with upper and lower case characters along punctuation.

PostgreSQL | An open source database program, sponsored by a variety of open source and other IT companies.

Password Authentication Protocol (PAP) | A protocol for validating users before allowing access.

Pre-boot Execution Environment (PXE) | A feature of a network card and a BIOS/UEFI system that gives the system ability to boot an operating system from a remote location.

Patch | In the context of the Linux kernel, a patch is an incremental update to the Linux kernel.

Pretty Good Privacy (PGP) | A program that encrypts messages and with digital signatures based on private and public encryption keys. First, the sender can use a unique PGP key to encrypt a message; then the recipient(s) can use a PGP key to decrypt that message.

Perl | A dynamic scripting language developed by Larry Wall; frequently used with Web sites.

Primary Domain Controller (PDC) | A master server on a Windows NT domain that controls and can grant access to a number of resources based on the usernames and passwords in its database. Linux with Samba can be configured as a PDC.

Phishing | An attempt to get users to reveal sensitive information such as usernames, credit-card numbers, and more, other through a spoofing attack.

File Transfer Protocol daemon (ProFTPD) | A popular FTP server with a basic configuration file similar to Apache Web server; supports multiple FTP servers.

PHP | Hypertext Preprocessor (PHP) | A scripting language associated with dynamic Web sites; frequently used with Apache.

Process Identifier (PID) | A number associated with the process running on a Linux system. The PID of currently running processes can be found with the ps command.

Physical Security (PHYSSEC) | A configuration of the ISECOM for security audits.

Protocol analyzer | Colloquially known as a sniffer, a protocol analyzer can listen in messages monitored on a network. One protocol analyzer is Wireshark.

Ping of death | A malicious packet of ICMP data to a system that may be used to crash a computer system.

Ping storm | A condition where a flood of ICMP packets to a server. May be created with the ping -f command.

pSeries | The IBM Reduced Instruction Set (RISC) server and workstation line for UNIX systems; some Red Enterprise Linux releases are built for pSeries.

Pluggable authentication modules (PAM) | For Linux, PAM is a set of configuration files that provide dynamic authentication for administrative and other services.

Public switched data network (PSDN) | A reference to the current digital telephone network.

PolicyKit | Supports free-grained administration tools from regular accounts. The focus of the PolicyKit is on the GNOME desktop.

Public switched telephone network (PSTN) | A reference to the regular telephone network for voice communications.

Possession or control | A Parkerian hext for control of confidential information.

Pure File Transfer Protocol daemon (Pure-FTPD) | An actively supported server that can run 100 percent with non-root accounts.

Post Office version 3 (POP3) | An application layer e-mail protocol that supports e-mail downloads of incoming messages.

Postfix | An open source SMTP server developed at IBM. It's designed to be simpler than sendmail.

Python | A multi-paradigm programming language frequently used with Web sites.
