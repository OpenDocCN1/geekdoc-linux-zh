Updates on Red Hat Enterprise Linux

Updates on Red Hat Enterprise Linux systems are done through connections to the Red Hat Network. It's a powerful tool that enables an administrator to pull updates with the yum command or push them directly from a Web-based interface to one or more systems. The Red Hat Network is discussed later in this chapter. The connection to the Red Hat Network is based on configuration files in the /etc/sysconfig/rhn/ directory. Specifically, registration information is stored in systemid file.

Alternatively, you can convert Red Hat Enterprise Linux systems to pull updates from a local repository. However, that choice means required updates will not be tracked on a Red Hat Network account and may invalidate any support contract you have with Red Hat. Alternatives for locally updates through Red Hat are by a Proxy and a Satellite server.

As of writing, Red Hat is working on an open source product that can manage updates to Red Hat Enterprise Linux, CentOS, Fedora, and related systems, known as Spacewalk. For more information, see http://www.redhat.com/spacewalk/.

# Standard apt - * Updates

The apt-* commands uses repositories configured through the /etc/apt/sources.list configuration file. The default version of this file includes a number of repositories. The deb and deb-src directives in this file connect separately to for binary and source code packages. So the following directives for the Ubuntu Lucid Lynx (10.04) allow specify connections to the main and restricted repositories:

```
deb http://archive.ubuntu.com/ubuntu/ lucid main restricted
deb-src http://archive.ubuntu.com/ubuntu/ lucid main restricted
```

While these directives specify the default repository for Ubuntu-based systems, the associated IP address suggests the server is located in the United Kingdom. For faster updates, you may want to replace the http://archive.ubuntu.com/ubuntu/ URL with one of the official mirror sites at https://launchpad.net/ubuntu/mirrors/. As shown on that page, Ubuntu mirrors may use the Hypertext Transfer Protocol (HTTP), the FTP protocol or rsync protocol, with a bandwidth and location more suited to your network.

But as shown in the following directives, security updates come from a different URL. Because of the time-sensitive nature of security updates, it may be best to accept the default, even if your systems are not located in Europe. If desired, you can add universe and multiverse to the end of these directives.

```
deb http://security.ubuntu.com/ubuntu lucid main restricted
deb-src http://security.ubuntu.com/ubuntu lucid main restricted
```
