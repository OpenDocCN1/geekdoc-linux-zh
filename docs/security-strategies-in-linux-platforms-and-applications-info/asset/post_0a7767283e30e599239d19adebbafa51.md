
# Glossary of Key Terms

# 485

Qmail | The self-declared replacement for sendmail, developed by Daniel J. Bernstein, who also developed djb-bindns.

Restricted repository | A reference to the Ubuntu repositories of software released under restricted licenses.

Richard Stallman | See Stalin, Richard.

Root Trust for Measurement (RTM) | Part of a Trusted Computing concept, known as the roots of trust. The core RTM may reside in the first boot program, by BIOS or UEFI.

RainbowCrack | A password tool to identify passwords that are too simple for a secure system.

Raymond, Eric | A leader of the open source movement. Author of The Cathedral and the Bazaar. As cofounder of the open source initiative at http://www.opensource.org.

Root Trust for Reporting (RTR) | Part of a Trusted Computing concept, known as the roots of trust. The RTR reports the integrity of a software component using SHA-1.

Real-time Transport Protocol (RTP) | A standard packet format for VoIP and video communications.

Root Trust for Storage (RTS) | Part of a Trusted Computing concept, known as the roots of trust. The RTS uses an endorsement key to verify the FTM data implicitly operated by the operating system.

Rebuild | A Linux distribution built from source code released by another distribution. For example, CentOS uses Red Hat core. CentOS Linux is a replica of Red Hat Enterprise Linux.

Rootkit | A specialized type of malware that enables a black-hacker to take root access of a Linux system.

Recursive query | A search of a DNS database is sent to other DNS servers if the information is not available locally.

RSA | A public-key encryption algorithm, named for its developers. Rivest, Shamir and Adleman.

Red Flag Linux | A Linux distribution deployed in China.

Rsyslog | The latest system for system and kernel logs; also supports secure transmission of log information to a central logging server.

Red Hat | The company behind the leading Linux distribution in the marketplace.

Runlevel | A mode of operation in Linux with a group of services and daemons. Specified services and daemons are started or killed when a particular runlevel.

Red Hat Network (RHN) | A group of management services to manage packages, scripts, and more. Such services may be applied to subscribed clients and servers on a network.

Samba | A file and printer sharing service compatible with Microsoft's Common Internet File System.

Red Hat Proxy Server | A proxy server dedicated to downloading packages from the Red Hat Network.

Sarbanes-Oxley (SOX) Act | A law that specifies financial disclosure requirements for public companies.

Red Satellite Server | A version of the Red Hat Network designed for local use on an enterprise network: includes an embedded Oracle database.

Secure Hash Algorithm (SHA) | A set of cryptographic hash functions developed by the U.S. National Security Agency.

Red security advisories (RHAS) | Announcements of security issues from the Red Hat Security Team.

Secure Hash Algorithm 1 (SHA-1) | A set of cryptographic functions generated by the U.S. National Security Agency (NSA). Because of a weakness, the National Institute of Science and Technology (NIST) has sponsored a competition for the development of SHA-3.

Remote Authentication Dial In Service (RADIUS) | A system for user authentication, frequently used to authenticate connections over telephone modems.

# Glossary of Key Terms

Secure Hash Algorithm 3 (SHA-3) | A set of cryptographic functions developed through a competition sponsored by the National Institute of Science and Technology (NIST).

Sleuth Kit | A package of tools that can be used to save volatile data: intended for use on read-only media as commands on compromised systems.

Snort | An intrusion detection system (IDS) with modes for packet analysis, logging, and interaction with iptables firewall; rules are updated on a regular basis.

Software RAID | A version of redundant array (RAID) of independent disks that partitions instead of disks as components of the array.

Solaris | A variant of UNIX originally developed by the Sun Microsystems.

Security Administrator Tool for Analyzing Networks (SATAN) | An older open source network analyzer. Later versions were released under proprietary licenses as of SAT.

SELinux | A mandatory access control system that uses Linux modules in the kernel. Developed by the U.S. National Security Agency. Not compatible with AppArmor.

sendmail | The open source SMTP server maintained by The Sendmail Corp. Do not confuse this with the commercial SMTP server known as sendmail.

Source code | Human-readable computer language that can be collected and compiled into a program, library, or application.

Sendmail | A commercial SMTP server maintained by Sendmail, Inc. Do not confuse this with the open source SMTP server known as sendmail.

SourceForge | A Web-based software service, available at http://sourceforge.net.

Session Initiation Protocol (SIP) | An Internet network protocol frequently used in VoIP communications.

Spacewalk | An open source systems management server on the source code of the Red Hat Satellite Server.

Set Group ID (SGID) bit | A special permission applied to a directory. With the SGID bit, users who are members of the group that owns the directory have permission to read and write to all files in that directory. The SGID bit assigns the group owner of the directory the group owner of all files copied to it.

Spamassin | A program for filtering unwanted e-mail.

Set User ID (SUID) bit | A special permission that allows others to execute the file with the rights of the user owner of the file.

Spectrum Security (SPESEC) | SPESEC is one of the ISECOM channels for security audits, to non-physical communications over the electromagnetic spectrum.

Shadow password suite | The files of the shadow password suite make up the local Linux password authentication database. The files are /etc/passwd, /etc/shadow, /etc/group, and /etc/passwd. As originally developed, it also includes the Linux login.in, and pass commands.

Spoofed | A reference to network transactions with a false source address.

Spoofing | An attack where a malicious user assumes the identity of another user or organization.

Spyware | A type of malware that collects information on users without their knowledge.

Simple Mail Transfer Protocol (SMTP) | An application-layer e-mail protocol primarily used for sending outgoing messages from clients.

Squid | A service that caches Internet data to speed response times that can also track the sites visited by users.

Stallman, Richard | President of the Free Software Foundation (FSF), the organization that founded the GNU project. Leading opponent of the TPM chip.

Simplified mandatory access control kernel (SMACK) | A Linux security module for mandatory access control; functionally similar to SELinux and AppArmor.

Sticky bit | A special permission applied to a directory. With the sticky bit and full permissions, all users can write to the associated directory. However, ownership is retained, so users won't be able to overwrite files by other users.

# Glossary of Key Terms

Stock kernel | A kernel

Storage area network (SAN) | A storage system

Root Key (SRK) | A key

Subversion | A version control system

SUSE | A Linux distribution developed in Germany

System Administrators Integrated Tool (SAINT) | A vulnerability scanning program

Systems Security Certified Practitioner (SSCP) | A vendor-neutral certification

Tannenbaum, Andrew | The main developer of Minix, one of the first clones of UNIX

Tarball | A collection of a (normally compressed) archive of files

TCG Software Stack | A software stack

TCP Wrappers | An access control system for services

Telephone modem | A modulator-demodulator for translating data bits into the sine waves of the PSTN

Telnet | A protocol and service that uses clear-text authentication

TOMY | A Linux security module for mandatory access control; functionally similar to SELinux

Torvalds, Lin | The developer of the first Linux kernel. The leader of Linux developers.

Transition Signature (TSIG) | A protocol used to authenticate data exchanges between DNS servers.

Transmission Control Protocol (TCP) | A member of the Transmission Control Protocol/Internet Protocol (TCP/IP) suite that supports reliable connections.

Tripwire | An intrusion detection system

Trivial File Protocol (FTP) | A protocol and service that uses a simplified form of FTP

Trojan horse | A kind of malware that disguises itself as a useful program or command

Trusted Computing Group (TCG) | An industry consortium for security. The TCG defines standards in a number of areas, including networks, PC clients, a software stack, and trusted networks. The TCG is the group behind the TPM.

Trusted Platform Module (TPM) | A chip that can be installed as a motherboard. May be used for password protection, software license protection, digital rights management, and disk encryption. Controversial with some in the open source community, including the Free Software Foundation (FSF) and the Electronic Frontier Foundation (EFF).

TrustedGRUB | A specialized version of GRUB that can work with the TPM in a chain of trust.

Ubuntu | A Linux distribution based on Debian. The name is a word taken from the Zulu and Xhosa languages that roughly translates as "humanity toward others."

Ubuntu security notices (USNs) | Alerts based on security issues that affect different releases of the Ubuntu distribution.
