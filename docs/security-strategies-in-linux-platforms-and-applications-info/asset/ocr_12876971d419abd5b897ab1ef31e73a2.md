# CHAPTER 4 | User Privileges and Permissions

# Securing Groups of Users

Administrators need to be able to set up users in special groups, with dedicated directories. Administrators can give those users rights and privileges on dedicated directories. The noted directories can be shared by groups of workers. Before configuring groups, you need to understand how the user private group scheme works in Linux.

# User Private Group Scheme

Linux users are typically assigned to at least one group, which is based on that user's account. For example, most current Linux systems with user kim also have a group named kim. Of course, user kim may be a member of other groups with access to hardware, administrative privileges, and more.

Every user has a primary group. To identify group, review the third and fourth fields in the /etc/passed file. For most user accounts, the numbers in these fields are the same. To verify the group name associated with each number, check the /etc/group file. Linux distributions that don't implement the user group scheme may assign all users to the group. That group is typically named users, with a GID of 100.

# Create a Special Group

If you're creating a group for a special set of users, you'll probably want to set up a directory for your exclusive use. The following instructions describe how to set up a /home/special directory for some series of users in a group named project. Assume the user members of that group are larry, kim, mike1, and mike2. Assume those user accounts have already been created. Further assume there is a user with a privileged UID.

+   1. Run a command like mkdir /home/special to create the directory for the special group.

+   2. Create the group named project. Make sure to assign that group a GID that can't otherwise be assigned. To be sure, check the /etc/login.defs file and make sure the GID is greater than the GID_MAX setting. If the local system uses network authentication, make sure the GID number isn't assignable in any of those systems.

+   3. For example, create a group named project with a GID of 100000, run the following command:
# groupadd -g 100000 project

+   4. Assign the noted users to that group. While you can do so using the usermod command, one user at a time, you can also edit the /etc/group and /etc/shadow files to add the noted users. Given a GID of 100000, the applicable lines in these files would be:

```
project:x:100000:larry,kim,mike1,mike2
project:::larry,kim,mike1,mike2
```
