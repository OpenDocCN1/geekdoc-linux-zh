The protocol directive can help define the IP address of the network card to connect to Dovecot listeners, with any nonstandard port numbers. The following examples use nonstandard port numbers for the four addressed protocols on the noted IP address:

```
protocol imap
{ listen = 192.168.0.10:10143 ssl_listen = *=10993 }
protocol pop3
{ listen = 192.168.0.10:10110 ssl_listen = *=10995 }
```

# If You Asterisk

Asterisk is the open source software implementation of a private branch exchange (PBX) program for telephone networks. As such, it is a VoIP solution for telephone communications. While Much of Asterisk is released under an open source license, some Asterisk software is proprietary. The software is available from http://www.asterisk.org/ it is developed by a group known as the Open Source Telephony Project. The project is sponsored by Digium, known as the Asterisk Company. The software available from Digium includes proprietary components. For more information on proprietary options, see http://digium.com/en/

This section is on security issues related to the open source Asterisk software available from http://www.asterisk.org/ or already loaded on Linux repositories for major distributions including Ubuntu and Fedora. With more than 60 configuration files, detailed options for Asterisk are beyond what can be covered in this book. See the References section for a couple of excellent books on Asterisk.

When considering it, be aware that an occasional dropped packet may not be a big deal, reliably speedy packet flow is important to keep conversations from becoming jump. Based on the characteristics of various protocols in the Transmission Control Protocol/Internet Protocol (TCP/IP) suite, the best fit for such communications is the User Datum Protocol (UDP). Asterisk communications, like other VoIP communications, use the Session Initiation Protocol (SIP) and the Real-time Transport Protocol (RTP) to send data through UDP packets. If this seems like a bunch of alphabet soup, read the noted in the References section.
