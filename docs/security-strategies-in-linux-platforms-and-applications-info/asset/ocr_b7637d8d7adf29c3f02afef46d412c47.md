# Read-Only or a Live Bootable Operating System

One of the risks from black-hat hackers is that they'll write something you don't want to one of the filesystems on your network. Perhaps the most straightforward way to prevent such writes is to mount many filesystems as possible in read-only mode.

The other way to preserve an operating system is to store it on read-only media such as a DVD drive. Linux includes a wide variety of distributions that can be booted directly from CD and DVD drives.
