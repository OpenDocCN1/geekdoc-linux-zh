# The Shadow Password Suite

The configuration of users and groups on a Linux system used to be a simple matter. Users were configured in /etc/passwd and groups configured in /etc/group. As users on Linux systems could be trusted, it didn't matter that those files were readable by any user.
Such configuration is not realistic with the current state of computer security. Even when encrypted, it's not a good practice to store passwords in a world-readable file. Additional restrictions on passwords can also enhance security. Those are some of the reasons for the development of the shadow password suite, which add the /etc/shadow and /etc/groupshadow files to the database.

> NOTE
Strictly speaking, the Message Digest 5 (MDS) cryptographic hash function associated with the shadow password suite is not encryption.

> NOTE
Technically, the shadow password suite as originally developed also includes the current functionality of the login, passwd, and su commands.

The files of the shadow password suite are fundamental to Linux. You may have read about them in other texts. Because those files are the foundation of Linux user and group security, you'll read about them again here. Before you can understand the basics of network authentication schemes as NIS and LDAP, you need to understand these files. It is possible to use these files from one system as the starting point for these network authentication databases.
