# Standard yum Updates

The predecessor to the yum command was originally built for a Linux distribution known as Yellowdog Linux. When it was adopted by developers at Duke University for the Red Hat distribution, it became known as the Yellowdog updater, modified, or yum for short.

The yum command uses repositories configured through the /etc/yum.conf configuration file. Normally, file includes repositories defined in the /etc/yum.repos/ directory. The formats of the yum configuration files differ slightly between Fedora and Red Hat Enterprise Linux.

# Updates on Fedora

For the Fedora distribution, the update repository is defined with the stanza in fedora-repo file. In the first directive, the release version is substituted for $releasever, and the basic architecture is substituted for $basearch variables.

> For an example of the list associated with the mirrorlist directive, navigate to https://mirrors.fedoraproject.org/mirror-13&arch=386. It should download a file of mirrors in a file named metalink. The file will list available Fedora mirrors in Extensible Markup Language format.

```
[updates]
name=Fedora $releasever - $basearch - Updates
```

The directives that support a rotating set of repository mirrors, as defined by the file associated with the noted mirrorlist directive. The failover directive starts with the first line in the text file.

Alternatively, you could set a single URL for updates. In fact, to set up a local update repository, you'd use the baseurl directive to point to a local Web or FTP server with update packages:

```
#baseurl=http://download.fedoraproject.org/pub/fedora/linux/
```

The final three directives in the stanza activate the repository, support checks of the packages with a GNU Privacy Guard (GPG) key, and identify the location of the GPG key on the local system:

```
enabled=1
gpgcheck=1
gpgkey=file:///etc/pki/rpm/RPM-GPG-KEY-fedora-$basearch
```

While the mirrors and packages differ, the basic format for updates on rebuild distributions such as the Community Enterprise Operating System version 5 (CentOS 5) is essentially the same as it is for Fedora Linux.

```
failovermethod-priority
updates/$releasever/
mirrorlist-httpsrors.fedoraproject.org/metalink/repo=
updates-released-f$releasever&arch=$basearch
```
