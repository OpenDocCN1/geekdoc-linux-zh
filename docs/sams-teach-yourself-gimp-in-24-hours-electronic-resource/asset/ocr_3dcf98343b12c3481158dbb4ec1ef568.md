> Reminder: By right-clicking on the image and selecting View, New View, you will open a duplicate image window that will show the same changes you make to the first window. This is convenient to open so that you can see how the changes you are applying to a magnified area will look when not magnified without having to zoom in and out.

In actuality you can greatly repair this photo with the use of just one tool: the Clone tool. As you might remember from Hour 3, "Basic GIMP Tools," the Clone tool is capable of picking up an exact duplicate or clone of an image area, pattern, or color, which can then be placed elsewhere.
