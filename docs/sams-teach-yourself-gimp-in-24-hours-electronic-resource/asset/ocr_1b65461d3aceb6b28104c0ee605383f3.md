# Q&A

Q I run Windows 95/98/NT. Am I just out of luck?

A Not necessarily. There is not a full GIMP port available for Windows; although a Windows port is in the works, it is not ready for prime time just yet, but running the GIMP is out of reach. You can either wait for a full Windows version (you might be waiting quite a while... but who knows?) or, you can partition your hard disk for a dual-boot Linux solution, which is much more fun anyway. And the good news is that installing Linux shouldn't in any way interfere with the software that is already installed. It can happily coexist with any other operating system you might be running now.
