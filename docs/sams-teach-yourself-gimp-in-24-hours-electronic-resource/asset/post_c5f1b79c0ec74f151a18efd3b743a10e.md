# Q&A

- If I use the Mask to Selection option, which part of the mask becomes the selection? The opaque (white) portion of the mask is the part that will become your area. If you want the transparent (black) area to be selected, you can perform Mask to Selection and then use the Select menu to choose Invert.
- I made a pretty cool mask. Can I save it to use in another image? You can, but it's a little tricky. First, add a new layer and place it directly below the masked layer. Turn off visibility in all layers except the masked layer so that you see only the mask in the image window and select Edit, Copy. Create a new image window with the same dimensions and select Paste. Paste it into the new image’s layer. If your new image is a different size, you might want to rescale the mask image to match before move it.
