# Source Installation for RPM-Enabled Systems

If you are running an RPM-enabled system, you might still want to compile the source tree from scratch. This can be handy in situations where your system might be employing idiosyncratic directory tree, or where system libraries might be slightly customized or customized. Sometimes there's nothing better than have something custom built for your system.

If you are installing from the CD-ROM, you will want to install the GIMP sources via RPM from the /gimp/RPM/src directory like:

```
rpm -ivh gimp-1.0.2-1.src.rpm
rpm -ivh gimp-data-extras-1.0.2-1.src.rpm
rpm -ivh gimp-plugins-unstable-1.src.rpm
```

This decomposes the source files into the /usr/src/redhat/ directory, under which the source and spec files (building parameters) are unloaded into the /SOURCES and SPECS directories, respectively.
