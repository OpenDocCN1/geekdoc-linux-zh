# The GIMP Interface

Before beginning on an image, one of the first things you will want to do is familiarize yourself with the basic interface.

The GIMP toolbox dialog, as pictured in Figure 2.5, is the single most important element in the entire program. From it, you will gain access to all your graphics files and the most essential controls. The first thing you will notice, if you've used other popular applications, is that this toolbox works in the same way you expect. The GIMP toolbox contains the controls for 21 of the most basic and essential of graphics editing tools, as well as the two main menus (File and Xns) and the Foreground/Background Selection box.

# Creating a New File

Obviously, the most common task in dealing with graphics is to create, open, and edit files. In fact, the GIMP doesn't even automatically open a new blank image for you; it assumes that you will primarily be altering existing graphics. This is where the first thing you will do is to go to the File menu and click New. You will then be greeted with the New Image dialog box, as shown in Figure 2.6.
