Another reason for the popularity of the GIF format is that you can make animations (moving images). You're going to learn more about creating animations in Hour 23

The down side to GIFs is that they do not support millions of colors, but just a mere 256 or less, and therefore any image you create in high color must have the color depth reduced before saving as a GIF. Because of this, the images are most likely to turn into GIFs are simple items such as logs, navigational buttons, divider bars, and so forth.

To reduce the colors and save an image in GIF format from the GIMP, right-click on the image and choose Image, Indexed. This brings up the Options window where you have several choices of color reduction methods, including 256 color, Web safe, and customized palettes.

In the same Options box, you have the choice to save the GIF as interlaced. This means that when your Web page containing the image is accessed, the image will load in levels, first appearing fuzzy and slowly sharpening to its final stage. It's a good idea to interlace your Web images so that people can have something to look at while the page finishes loading.

 JPEGs, GIFs use a lossless compression scheme, meaning that no image quality is lost when it is compressed into the GIF format.

> There is one more promising file format that is edging its way into Web. PNG (Portable Network Graphics) possesses not only transparency capabilities, but also full color and relatively small file size without loss of quality. At this time, however, PNGs are only supported by the latest browser versions (Netscape and Internet Explorer 4.0 and up) and therefore cannot be viewed by any of the older browsers. As time passes and more people upgrade browsers, you will no doubt begin to see PNGs as one of the major Web file formats.
