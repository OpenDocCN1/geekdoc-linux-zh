It's getting there, but let's add a little texture to the glass panes. Add another new parent layer and call it Texture. Lower it to just under the Color layer. Right-click'on the image and choose Select, All. (The reason to select the entire layer is because you are going to use the Bucket Fill tool. Remember that the Bucket Fill must have either a selection or an area to fill. Because the layer is transparent, it must be selected.) Now open the Pattern dialog box and choose a pattern that has a good rough texture to it. (Here I've chosen one Green 3D.) Use the Bucket Fill tool (set to Pattern fill) to fill the new layer with the pattern. Because you want to use the texture from this pattern, but not the green color, right-click and select Image, Colors, Desaturate.
