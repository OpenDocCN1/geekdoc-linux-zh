# Script-Fu

Now that you know little about Script-Fu, you can start using some scripts. By default, GIMP comes with a plethora of great scripts to start messing with right, but of course you will need to download and try new ones. The first thing to know is that Script-Fu scripts are stored in simple text files with an S extension. Therefore, installing a new script is as easy as downloading one into your ~/.gimp/scripts directory. Depending on what the script is supposed to do, it should be categorized somewhere under Xtns. Script-Fu in the tool box (or Script-Fu from the right-click menu). The general rule of thumb is that scripts that alter an existing image are usually stored under the right-click menu, whereas scripts that generate new graphics from scratch are stored in the Xtns menu. If you are wondering where to acquire more of these scripts, gimp.org has references to many Scriptmaster's resources.
