# SAMS Teach Yourself

# GIMP in 24 Hours

| HOUR | TITLE | CONTENT |
|---|---|--|
| 1 | Installation and Configuration | Install the GIMP and get it running smoothly |
| 2 | Getting Started | Begin learning to use the GIMP effectively |
| 3 | Basic GIMP Tools | Learn how to use the basic tool set in the GIMP |
| 4 | Using Brushes and Patterns in Depth | Concentrate on the GIMP's wide array of brushes and patterns |
| 5 | Working with Selections | Utilize the various selections to select a portion of an image |
| 6 | Transformations | Move, zoom/magnify, transform, and flip images |
| 7 | Working with Color | Work with color effectively in digital format |
| 8 | Introduction to Layers | Learn the fundamental steps of layering |
| 9 | Hands-on Layering | Combine layering with blend modes |
| 10 | Using Masks | Apply and edit images with masks |
| 11 | Special Effects | Make your own special effects |
| 12 | Using Filters to Improve or Distort Images | Use filters to enhance and modify images |
| 13 | Artistic Filters | Explore eccentric and exciting effects with filters |
| 14 | Cool Text Effects | Turn simple text into works of art |
| 15 | Web Graphics | Create images optimized for the Web |
| 16 | Photo Compositing | Turn photographs into a collage or photo-montage |
| 17 | Photo Restoration and Enhancement | Correct flaws and mistakes in photographs |
| 18 | Digital Painting | Create similar to watercolor and oil paintings |
| 19 | About Plug-ins | Learn about plug-ins and how the GIMP uses them |
| 20 | Using Plug-ins and Extensions | Become familiar with more complex plug-ins for the GIMP |
| 21 | What the Heck is Script-Fu? | Add functionality to the GIMP by writing custom scripts with Script-Fu |
| 22 | More with Script-Fu | Explore more specialized uses of Script-Fu |
| 23 | Animation | Learn techniques for creating animation |
| 24 | Using Peripherals with Linux | Add goodies as digital scanners, digital cameras, color printers, and pointing devices |
