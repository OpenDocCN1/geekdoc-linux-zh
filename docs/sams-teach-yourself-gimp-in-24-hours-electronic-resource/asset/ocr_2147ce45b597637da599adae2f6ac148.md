# Add a new transparent layer; name it paintball.

Set the foreground color to a color you would like to see on the car. I've chosen a pale blue here.

With the paintball layer active, use the Bucket Fill tool to fill the selected area with the chosen color (see Figure 9.11).

# FIGURE 9.11

The selected area becomes filled with color.

![](bbox=[0.346, 0.26135, 0.816, 0.44935])

Now you can get somewhat of an idea of what the car will look like with the lighter color, but you can't really see the details. This is a situation where you can use a blend mode to help out.

Most of the blend modes will still let the dark original color of the car come through. Because you want the car to be lighter, apply the Screen mode from the blend mode menu. Voilà! Check out the results in Figure 9.12.

# FIGURE 9.12

A virtual paint job can happen in a matter of moments by choosing the right blend mode.
