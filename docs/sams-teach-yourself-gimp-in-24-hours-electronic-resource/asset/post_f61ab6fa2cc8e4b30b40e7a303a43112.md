# Using the Text Tool

Clicking on the Text Tool icon will change the cursor over the image into an I-beam. To insert some text, click the mouse with the I-beam over the image. This brings up the Text dialog box, as in Figure 3.16.

FIGURE 3.16

The Text dialog box.

![](img/0183f053b347a6407a2381be231d0345_58_1.png)

Near the bottom of the Text Tool dialog box, you will see a blank text space. This is where you need to type in your text. After this has been done, look toward the left side of the dialog box to see a listing of the fonts that are available to the X Window System. By clicking on any one of these, your text will be previewed, in that font, right where you typed it.

# Hour 3

At the top of the dialog box, you will see an option for text size. The implication here is obvious. In any text size, click Enter, and your preview will be updated.

Foundry refers to the maker of the font. This can be important when dealing with fonts that have the same name but are made by different individuals or companies.

Other Options are Available on the dialog box as well, such as Slant (Italics), Weight (Bold), Set Width (Spacing), and so forth.

After your text appears how you want it, click OK, and your text will appear on the image canvas, as an active selection. The color of the text will be the active foreground color in the Foreground/Background Color Select box in the toolbox. You can now move it using your cursor to any position in the page. Or, because it is an active selection, you can apply any pattern, fill, gradient, or effect to it. You will practice many of these effects as you continue throughout the hours in this book.

# Using X Fonts with the GIMP

X supports many styles of fonts. In using the GIMP, you will likely want to increase the volume of fonts available to your system (The fonts that come with pretty dull). On the CD-ROM, in the Fonts directory, there are two font packages: sharefonts.tar.gz and freefonts.tar.gz. You should look into installing these. Uncompress them into `/usr/X11R6/include/X11/fonts` directory, read the READMEs, and follow the directions. (These font packages can also be downloaded from any Linux FTP repositories, or Red Hat's contrib directory).

You will find that your native X Fonts are located in subdirectories of `/usr/X11R/libX11/fonts` (or variant thereof, on different systems). If you ever want to add or remove fonts in the future, you'll know where to go. I've also found it helpful to remove extraneous fonts by deleting certain fonts and editing out the reference to them in the fontsdir. The Far Eastern ones are good candidates for deletion (unless you really need them), and they tend to take a long time to render.

Although these fonts are pretty good, I still itchin to utilize my vast collection of TrueType fonts with the GIMP. Frankly, they can be supportive of those—with a little assistance. In order to use TrueType, you need to install and run a TrueType Font Server either. This isn't too difficult, all you need to do is acquire the xfsft TrueType Font Server application and install it. It, too, is available on the CD-ROM in the font directory as xfsft.tar.gz. Unzip it into your directory, compile and install it as follows:

```bash
make install
```

Create the directory /usr/ttf, and copy your favorite TrueType TTF files. Then run xfsft sync to the fonts.

Start xfstst as a background process:

Tell the running X11 server about the new font server:

```bash
xset +fp unix::/7100
```

Add the new font path to the X11 config file (probably /etc/X11/xF86Config):

```text
FontPath "unix:/7100"
```

You should now be able to bring up the GIMP Text dialog box and see your TrueType fonts. After installing xfstst, you might want to get it to start automatically every time Linux boots (not that Linux ever rebooting) by adding a reference to it in /etc/rc.local. This keeps you from having to start the TrueType Font Server every you start X.
