# Seamless Tiling

After you have a pattern that you are satisfied with, you should make it tileable, meaning that when you use it as a background or pattern fill on a large area, the seams or edges blend smoothly together with no visible lines.

This is relatively easy to achieve with a function called Make Seamless. Right-click the image you want to tile and go to Filters, Map, Make Seamless. Your pattern unites with no seams showing when saved and tiled. See Figure 4.13 and notice how the edges have been changed so that the patterns tile correctly.
