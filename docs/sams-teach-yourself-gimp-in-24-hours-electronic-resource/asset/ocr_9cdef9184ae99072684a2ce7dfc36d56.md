# Magnify

Although the Magnify (Zoom) tool does not actually alter an image in a permanent way, I want to cover it in this hour because it can alter the way you view an image while you work on it.

The premise is simple. You can magnify or zoom in an area to get a closer look at it. This is very handy for work such repairing old photos where you need to pixel-by-pixel. With the Zoom tool activated, you merely click the image to zoom in and Shift-click to zoom out. You can also zoom in and out by using the plus (+) minus (-) keys on the keyboard. To zoom in a particular area of an image, click and drag that area.

If you pull up the Zoom tool dialog box, you can see that it has only one option, Allow Window Resizing. If this option is unchecked, your image window keeps its original size, no matter how much you zoom. Checking the option enables the window to reduce or enlarge to fit the amount of zoom applied.

A few other features are enabled in the menu. Right-click an image and go to View. Most of the features are pretty self-explanatory. You can zoom in, zoom out, or zoom to a certain amount among nine choices. You can look at the information to see window size, scale ratio, and so on and toggle certain window functions on and off.
