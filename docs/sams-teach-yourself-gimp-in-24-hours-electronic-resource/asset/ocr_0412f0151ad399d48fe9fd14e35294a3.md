# Q&A

+   Q When I paint using the Airbrush tool, it sometimes comes out too faint. What I am doing wrong?
Q Remember, the Airbrush functions just as a real live spray would. The slower you paint or the longer you hold it in one spot, the more paint is deposited there.
Q I want to achieve a brush stroke that appears to run out of paint, just as a real one would. Can I do this?
A You can if you are using the Paintbrush tool. Double-click the tool and set the Fade Out Out option. (Refer to Hour 4, “Using Brushes and Patterns in Depth,” to refresh your memory on how this option works).
