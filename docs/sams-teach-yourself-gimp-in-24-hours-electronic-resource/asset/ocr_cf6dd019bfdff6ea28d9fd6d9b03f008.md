# The Layer Dialog Menu

In the Layers & Channels dialog, right-click on the thumbnail image or name of the layer to bring up the Layer dialog menu, as in Figure 8.4.

Figure 8.4

The Layer dialog menu has a few options to consider.

![](bbox=[0.233, 0.453, 0.423, 0.663])

The New, Raise, Lower, Duplicate, Delete, and Anchor Layer buttons just perform the same if it is activated or if using the dialog box icon symbols for these functions.

Scale and Resize function in the same capacity as the Scaling and Resizing options you learned about in Chapter 6, “Transformations.” The only difference is that here, the scaling or resizing is applied to one or more layers.
