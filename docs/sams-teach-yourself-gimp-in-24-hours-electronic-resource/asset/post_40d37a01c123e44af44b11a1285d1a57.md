## Gradient Editor

Now you've come to the good stuff—the Gradient Editor (see Figure 7.28). This tool makes it all worthwhile. It enables you to move beyond one color and make custom gradient using any combination of colors you choose. Using these gradients makes it possible to generate photo-realistic lighting and shadow effects, landscape effects, and a plethora of other things.

To get to the Gradient Editor, go to File, Dialogs, Gradient Editor in the toolbox menus.
