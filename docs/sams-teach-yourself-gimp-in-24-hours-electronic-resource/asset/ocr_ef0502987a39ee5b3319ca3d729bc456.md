To clarify, these filters are a certain type of filter used in Photoshop, so this does not mean that the GIMP can include all Photoshop plug-ins, such as the many commercially available offerings from Kai, Alien Skin, Ulead, and the like. But it can run User Filters, which come in .8bf format.

In order to install these filters, you must first install the GIMP User Filter plug-in (available on the CD-ROM under Plug-ins), and then acquire the Filter Factory filters. Due to licensing restrictions, I cannot include filters on the CD-ROM, but you can download them from http://www.netnets.net/showcase/wolf359/plugins.htm.

Note that many of these filters are stored in PiCo format. PiCo is a file converter that archives and converts different Photoshop filters. Unfortunately, many Filter filters are stored in FFL archives, which need to be converted to .8bf format before GIMP can use them. I know of no PiCo-compatible application for UNIX, in order to use these filters from GIMP you will need to decompress them using your Windows boxes. You can copy them to your machine. You can get PiCo at http://pico.i-us.com/.

After you use the User Filter .8bf uncompressed and copied over UNIX, you can put them in /usr/local/share/gimp/userfilter. You can now start using these filters. If you have Windows machines on your network, this is even easier for you. Save hard drive space by creating a symlink to the directory on the PC containing these filters.

Using these filters is easy. Open an image, find User Filters in the Filters menu and click the Filter Manager tab (see Figure 13.21). Here, you will see a list of all User Filters installed on your system. Scroll through the list until you come to a name that interests you. Then click the Preview tab and watch the action.
