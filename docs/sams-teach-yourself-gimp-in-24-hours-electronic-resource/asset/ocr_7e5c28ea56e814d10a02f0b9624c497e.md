# Binary Installation for RPM Enabled Systems

You can find GIMP binaries on the CD-ROM in the RPM format under the /gimp/RPM/ directory. As root, simply change into the directory reflecting your form of choice (that is, /mnm/gimp/RPM/) and type the following at:

```
-Uhvh gimp-1.0.2.i386.rpm
-Uhvh gimp-devel-1.0.2.i386.rpm
-Uhvh gimp-data-extras.1.0.2.i386.rpm
-Uhvh gimp-plugins-uninstall.-1.0.2.i386.rpm
```

This will be followed by a success of hashes (#) indicating the installation is in progress. Pending no error messages, you should be ready to run the GIMP. Nice and simple, won't you see?

# RPM Troubleshooting Quick Reference

+   I need a dependency not found error.

A This means that the installing package was looking for a required file or library that was not there. You will need to install/upgrade any packages containing the files you need. This might require a little investigation on your part. if the error says libjpeg.so.1 - dependency not found, you can deduce from this there is a problem with the libjpeg package. It's probably misplaced, not installed, or is an outdated version. You should go to any one of Linux FTP sites to download/install the latest libjpeg package to reconcile the problem.

Although most of the time these dependency issues are pretty to resolve, sometimes it is not quite so to deduce what package contains the missing file at merely firstly glance. But, not to worry; most of the time you can find out where the file belongs by way of a little research. After checking the newsgroups or mailing lists, someone will have run into the same thing and can tell you what are missing. These resources are always timely, accurate, and quick to respond. (You'll be surprised.)
