# Q&A

+   Can I use the Move tool to move a selection from one image to another?

+   No. The Move tool is used to move selections within an image. To move a area from one image to another, you have to use the copy and paste functions. Activate the image containing the selection, right-click it to bring up the menu, or go to Edit, Copy. The selection is now in the clipboard. Now activate the image you want to paste the selection into and click Edit.

+   Is there a way I can enter the amount of rotation I want my image to have?

+   No, but you usually can get fairly precise to a desired amount by watching the dialog box containing the angle information while you rotate.
