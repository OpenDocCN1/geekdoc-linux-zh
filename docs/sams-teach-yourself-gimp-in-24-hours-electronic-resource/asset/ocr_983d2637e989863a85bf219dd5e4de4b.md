# GUASH

GUASH is a simple file previewer program to run within GIMP. It enables you to preview your images by way of ordered thumbnails and open selected files accordingly in the GIMP, if you choose. Using GUASH is a very convenient feature when dealing with directories that contain many graphics files, which in saves time by eliminating the need for hide and seek when you can't see to remember exactly what you named that particular image you're looking for.

Starting and using GUASH is simple: select Xtns, GUASH, and you're ready to go. You will see the initialization screen, and then a directory listing of the directory you're in (see Figure 20.6). Navigating GUASH is as straightforward as any modern graphical file manager. You can also move, rename, and delete files from within GUASH.
