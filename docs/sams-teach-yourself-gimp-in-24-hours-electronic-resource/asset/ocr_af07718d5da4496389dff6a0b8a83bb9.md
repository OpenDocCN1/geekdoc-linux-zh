For a good, real-life example of Net-Fu in action in an application, check out http://www.cooltext.com/.

It is possible to set Net-Fu to accept remote commands and create a Web-based, Java-based, or a native front end to Net-Fu (see Figure 22.8). Be warned, however, this is not an easy task to achieve, and is definitely not for the faint of heart! To quote the Net-Fu README. "Installing this stuff is not fun!" But if you do to set up your machine as a Net-Fu server and do some experimenting with the possible client/server applications GIMP can handle, there are some good resources at text.com to help you get started.

# Summary

Using Script-Fu as a tool in combination with your own graphics techniques is something that will just kind of bump into you when you're looking to create certain effect and a script seems to fit that purpose perfectly. Keep at it! Don't forget to check up with gimp.org often to keep track of any new scripts that might be out for you to devour.

# Q&A

+   - Can I get a script to run from the command line without X?

+   - Yes. Of course, this is a difficult task; it is really good for scripted tasks and requires a coder's touch (for now). Read the Net-Fu documentation for details. If you're looking for a way to convert image formats in batch mode, for a number of unattended files, a better way is to use the ImageMagick suite of utilities, which complement GIMP nicely. The Imagemagick man pages can point you in the right direction.
