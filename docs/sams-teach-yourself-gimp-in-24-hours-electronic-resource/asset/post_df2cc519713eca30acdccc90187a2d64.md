This image has only two basic elements: the dog and the grass in the background. What you need to accomplish here is a greater differentiation between the two.

First of all, use either the Lasso or Bézier tool to select the area around the dog. Now, right-click and go to Image > Color Balance. By playing with the sliders, increase the red hue to make the dog a slightly darker, richer shade of brown.

Next, right-click and choose Select > Invert to switch the selection area to the background. Once again, go to Image > Color Balance but this time adjust the sliders so that the grass looks green as if it were spring. With just these two adjustments, the washed out picture will gain enough contrast to make it into a pretty photo.

## Edge Effects

In some of the previous hours you’ve learned many ways to apply edge effects to images using masks, gradients, feathering, and so forth. Wrap up this hour, you’ll learn to create more simple yet interesting edges to add to photos. To start, you’ll need to open an image. What you will do here is create a look that resembles a torn and burned edge. The first step is to use the Lasso tool to select an uneven area around the image so that it will appear as if is ripped along the edges (see Figure 17.14).

## Photo Restoration and Enhancement

Now, once again, right-click and choose Select > Invert to reverse the selection back to how it originally was. Add a drop shadow by right-clicking and going to Script-Fu > Shadows > Drop Shadow. Make sure the Allow resizing option is unchecked.

Now for the finishing touch, give the edges a burned appearance using the Gradient editor. Double-click the Gradient tool to bring up the options. Change the shape option to Angular and choose the Custom (from editor) Gradient. Open the Gradient dialog box (File > Dialogs > Gradients) and choose Coffee. This is a gradient that goes from transparent to a dark brown. Apply the gradient to the selected area of the image by starting in the center and dragging to the edge in any direction. Deactivate the selection and presto! Your picture will have a ripped and burned edge, as in Figure 17.16.

## Q&A

I want a photo to appear just barely visible (as if in a fog) so I can use it for a background. How can I do that?

Add a new layer in white and adjust the opacity until you get the effect you want.

What is the best file format to save my photos?

That depends on what you are planning to do with them. For Web use, JPEG is the format of choice for photos. If you want to view them on your own computer and maybe do some editing, any format that supports full color will do (BMP, PNG, TIFF). If you recall from Hour 15, “Web Graphics,” the JPEG format loses image quality each time it is edited and then saved with the changes, so if you plan on doing anything to the images besides simple viewing, you'll want to choose something other than JPEG.
