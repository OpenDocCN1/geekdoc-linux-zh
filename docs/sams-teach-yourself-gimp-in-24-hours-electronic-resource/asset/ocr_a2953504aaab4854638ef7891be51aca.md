Here's a quick Web I whipped up using Script-Fu and a text editor. It's not the best I've ever done, but it's not bad for being put together in 10 minutes flat. By using a little trick of HTML I was able to create a page with a matching set of buttons, icons, and little with ease.

Script-Fu in concert with other techniques can help you turn some pretty nice sites, and save you a bit of time in the process.

+   * I scripted out by rendering the graphics by one with Script-FU using the "Beveled Pattern"
* Then I created a quick background using image using the same pattern.
* I set up the webpage in Netscape Composer.
* I used Vim to write the HTML until it was a little more to my liking.

You can also draft some quick buttons for the Web site, as shown in Figure 21.9—Script-Fu has covered this well. Under Xtns, Script-Fu, Buttons, a script can be found that will generate a beveled button with text according to any specifications you choose. You can even make matching pressed buttons if you like, which is great for those JavaScript mouse-overs. Be careful, though—this filter do require pretty thorough font information.
