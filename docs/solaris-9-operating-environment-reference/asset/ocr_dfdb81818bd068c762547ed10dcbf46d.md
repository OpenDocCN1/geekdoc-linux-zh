# test — Evaluate Conditions

# Synopsis

```
/usr/bin/test [condition]
[condition]

csh, ksh, sh
test condition
[condition] ]
```

# Description

The test command evaluates the condition and indicates the result of the evaluation by its exit status. An exit status of 0 indicates that the condition evaluated as true, and an exit status of 1 indicates that the condition evaluated as false.

In the test [condition] syntax, the square brackets denote that the condition is an optional operand. Do not enter the brackets on the command line.

In the [ condition ] form of the command, the first open square bracket is the required command name. condition optional, denoted by the inner pair of square brackets. The final close bracket is a required operand.

See datafile(5) for the description of the behavior of test when encountering files larger than or equal to 2 Gigbytes (*33 binary lines)

The test and commands evaluate the conditioncondition, and if value is true, they set exit status to 0. Otherwise a nonzero (false) exit status is set. test and [ set a nonzero exit status when no arguments are given. When permissions are tested, the effective user ID of the process is used.

All operators, flags, and brackets (used as shown in the last Synopsis list) must be separate arguments to these commands. You normally separate these arguments with spaces.

# Operands

The primaries listed below are as unary primitives. Unary primaries have the following form.

```
-primary_operator primary_operand
```

Primaries with three elements are known as binary primitives and have the following form.

```
primary_operand -primary_operator primary_operand
primary_operand primary_operand primary_operand
```

If any operand except the -h and -L refer to symbolic links, the symbolic link is expanded and the test is performed on the resulting file.
