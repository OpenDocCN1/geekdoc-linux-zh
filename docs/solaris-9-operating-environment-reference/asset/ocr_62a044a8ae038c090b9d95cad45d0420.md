# dpost

# 273

+   - o list
- -p mode
- -T name
- -w num
- -x num
- -y num

Print those pages for which numbers are given in the comma-separated list. The list contains single numbers Ni-N2. A missing Ni means the lowest numbered page, a missing N2 means the highest. The page range is an expression of logical pages instead of physical sheets of paper. For example, if you are printing two logical pages to a sheet and you specify a range of 4, two sheets of paper print, containing four page layouts. If you specified a range of 3-4 when requesting two logical pages to a sheet, then page 3 and page 4 layouts print on one physical sheet of paper.

Print files in either p (portrait) or l (landscape). Only the character of mode is significant. The default mode is portrait.

Use font for size name as the best description of available PostScript fonts. By default, name is set to post, and dpost reads binary files from /usr/lib/font/devpost.

Set the line width to implement troff graphics commands to num points, where a point is approximately 1/72 of an inch. By default, num is set to 0.3 points.

Translate the origin inches along the positive x axis. The default coordinate system has the origin fixed near the upper-left corner of the page, with positive x to the right and y down the page. Positive num moves everything. The default offset is 0 inches.

Translate the origin inches along the positive y axis. Positive num moves text up the page. The default offset is 0.

Examples
If the versions of egn and pic are installed on your system, you can obtain the best-looking output possible by issuing a command as the following.

```
castle pic -T720 file | tbl | egn -r720 | troff -mm -Tpost dpost
```

Otherwise, the following command should give the best results.
castle pic file | tbl | egn | troff -mm -Tpost dpost
