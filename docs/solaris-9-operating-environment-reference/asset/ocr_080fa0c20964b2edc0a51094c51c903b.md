The form of access control provides different levels of protection, enabling the server to grant access for certain containers and/entries. You specify access control in the form of access control lists (ACLs). Each ACL specifies one or more directory objects (for example, the cn attribute in a specific container), one or more clients to which you grant or deny access, and one or more access rights determines what the clients can do with the objects. Clients can be users or applications. You can specify access rights as read and write, refer to the System Administration Guide: Naming and Directory Services (DNS, NIS, and LDAP) for restrictions on ACLs using LDAP as a naming repository.

# The Network Switch File

A nswitch.conf(4) file named nswitch.ldap is available in the /etc directory. This file is copied to /etc/nswitch.conf by the ldclient(1M) command. The nswitch.ldap file uses ldap for the different databases in the nswitch.conf file. The default nswitch.ldap is shown below.

```
# /etc/nswitch.ldap

# An example file that could be copied over to /etc/nswitch.conf; it
# uses LDAP in conjunction with files.

# "hosts": and "services": in this file are used only if
# /etc/netconfig file has a "-" for nametoaddr_libs of "inet" transports.

# The two lines obligate the "*" entry in /etc/passwd and /etc/group.
passwd: files ldap
group: files ldap

# consult /etc "files" only if ldap is down.
hosts: ldap [NOTFOUND]=return files
ipodes: files

# Uncomment the following line and comment out the to resolve
# Both IPv4 and IPv6 addresses from the ipnodes databases. Note that
# IPv4 addresses are searched in all of the ipnodes databases before
# searching the hosts databases. Before turning this option on, consult
# The Network Administration Guide for more details on using IPv6.
```
