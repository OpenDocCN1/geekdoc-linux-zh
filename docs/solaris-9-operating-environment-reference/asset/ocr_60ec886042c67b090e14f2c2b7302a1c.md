If -k option is set, all variable assignment arguments are placed in the environment, even if they occur after the command name. The following example prints a=b c and then c:

```
$ echo a=b c
a=b c
$ set -k
$ echo a=b c
c
```

> Note - Because this feature is intended for use with scripts written for early versions of the shell, its use in new scripts is strongly discouraged. The feature is likely to disappear someday.

# Functions

Use the function reserved to define shell functions. Shell functions are read and stored internally. Alias are resolved when the function is read. Functions are executed commands with the arguments passed as positional parameters.

Functions execute in the same process as the caller and share all files and working directory with the caller. Traps caught by the caller are reset to their default action inside the function. A trap condition that is not caught or ignored by the function terminates the function and passes the condition to the caller. Ordinarily, variables are shared between the caller and the function. However, the typeset special command used within a function defines local variables whose scope includes the current function and all functions calls.

Use the special command to return from function. Errors within functions return to the caller.

+   + types -f lists the names of all functions. typeset -f lists all function names as well as the type of all functions. You can undef functions with the -f option of an unset command.

Ordinarily, functions are unset when the shell executes a script. The -xf option of the typeset command enables you to export a function to scripts that are executed without a separate invocation of the shell. Specify functions that need to be defined across separate invocations of the shell in the ENV file with the -xf option of types.

