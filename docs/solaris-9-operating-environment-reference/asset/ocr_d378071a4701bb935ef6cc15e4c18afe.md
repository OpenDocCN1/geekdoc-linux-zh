# 103

```
# convert binary to decimal - obase is already set to 10
ibase=2
10 # binary 10 is decimal 2
2
# Now set input base back to decimal - NOT!
# Because bc is still interpreting your input as base 2, the next line is read as
# ibase=(binary) 10 = (decimal) 2, so all numbers you input are still interpreted
# as binary.
ibase=10
2 # What?
# To get back to decimal input mode, you have to enter the binary
# equivalent of decimal 10: 1010
ibase=1010
10
10 # decimal 10 = decimal 10
```
