# New rpm2cpio — Convert Red Hat Package (RPM) to cpio Archive

# Synopsis

```
/bin/rpm2cpio [file.rpm]
```

# Description

Use the rpm2cpio command, new in the Solaris 9 Operating Environment, to convert the .rpm file specified as its sole argument to a cpio archive on standard output. In both cases, specify no argument, an rpm stream is read from standard input. rpm2cpio fails and prints a usage message if the standard output is a terminal. Therefore, you usually redirect output to a file or pipe through cpio(1) command.

Note — The rpm2cpio command handles versions 3 and 4 RPM files.

# Examples

The following example converts an rpm-2 file to a cpio archive.

```
example% rpm2cpio Device3Dfx-1.1-2.src.rpm | cpio -itv
CPIO archive found:
-rw-r--r-- 1 root root 2635 Sep 13 16:39 1998, 3dfx.gif
-rw-r--r-- 1 root root 11339 Sep 27 16:03 1998, Dev3Dfx.tar.gz
-rw-r--r-- 1 root root 1387 Sep 27 16:04 1998, Device3Dfx-1.1-2.spec
31 blocks
example%
```

The following example converts from standard input.

```
example% rpm2cpio < Device3Dfx-1.1-2.src.rpm | cpio -itv
CPIO archive found:
-rw-r--r-- 1 root root 2635 Sep 13 16:39 1998, 3dfx.gif
-rw-r--r-- 1 root root 11339 Sep 27 16:03 1998, Dev3Dfx.tar.gz
-rw-r--r-- 1 root root 1387 Sep 27 16:04 1998, Device3Dfx-1.1-2.spec
31 blocks
example%
```
