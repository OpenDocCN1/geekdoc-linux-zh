# stty

strap (-strap)
Disable (enable) truncation of lines longer than 79 characters on a syncronous line.

topstop (-topstop)
Send (do not send) SIGTOU when background processes write to the terminal.

echoctl (-echoctl)
Echo (do not echo) control characters as ^char; delete as ^?.

echoprt (-echoprt)
Echo (do not echo) erase character as character is erased.

echoke (-echoke)
BS-SP-BS erase (do not BS-SP-BS erase) entire line on line kill.

flush (-flush)
Output is (is not) flushed.

pendin (-pendin)
Retype (do not retry) pending input at next read or input character.

iext (-iext)
Enable (disable) special control characters not currently controlled by icanon, isig, icon or ixoff: VEOLZ, VSWT, VPRPRINT, VDISCARD, VDSUP, WERASE, and VLNEXT.

stflush (-stflush)
Enable (disable) flush on a synchronous line after every write(2).

stappl (-stappl)
Use application mode (use line mode) on a synchronous line.

# Hardware Flow Control Modes

rtsxoff (-rtsxoff)
Enable (disable) RTS hardware flow control on input.

ctsxon (-ctsxon)
Enable (disable) CTS hardware flow control on output.

dtrxoff (-dtrxoff)
Enable (disable) DTR hardware flow control on input.

cdxon (-cdxon)
Enable (disable) CD hardware flow control on output.

isoff (-isoff)
Enable (disable) isochronous hardware flow control on input.
