# wc — Display a Count of Lines, Words, and Characters in a File

# Synopsis

```
/usr/bin/wc [-c | -m | -C] [-lw] [file...]
```

# Description

Use the wc command to display a count of the lines, words, and characters in a file.
wc command reads one or more input files, and by default, writes the number of newline
characters, and bytes contained in each input file to the standard output.

The command also writes a total count for all named files if you specify more than one
input file.
 considers a word to be a non-zero-length string of characters delimited by white
space such as space or Tab (isspace(3C) or isspace(3C)).
