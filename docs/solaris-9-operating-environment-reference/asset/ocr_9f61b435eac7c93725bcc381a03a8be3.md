| Max. No. of Addresses | Command | Description |
|---|---|---|
| 2 | t label | Test by branching to the command bearing the label if any substitutions have been made since the most recent reading of an input line or execution of at. If label is empty, branch to the end of the script. |
| 2 | w wfile | Write by appending the pattern space to wfile. The first occurrence of w clears wfile. Subsequent invocations of w append. Each time you use the sed command, wfile is overwritten. |
| 2 | x | Exchange the contents of the pattern and hold spaces. |
| 2 | ! command | Apply the (or group, if command is) only to lines not selected by the address(es). |
| 0 | : label | Hold a label for b and t commands to branch to. Put the current line number to the standard output as a line. |
| 2 | (command-list) | Execute command-list only when the pattern space is selected. |
| 0 | # | Ignore an empty command. If a # is the first character on a line of script file, then treat the entire line as a comment with one exception: if a # is an n, then suppress the default output. Also, ignore the rest of the line after #n. A script file must contain at least one noncomment line.|

The following list describes the maximum command, using strings.

s/regular expression/replacement/flags

Substitute the replacement string for the regular expression in the pattern space. You can use any character other than backslash or newline instead of a slash to delimit the replacement. Within the RE replacement, you can use the RE delimiter as a literal character if you precede it with a backslash.

Replace an ampersand (&) appearing in the replacement string with the RE You can suppress the special meaning of & in this context by replacing it with a backslash. Replace the characters \n where n is a digit, with the text matched by the corresponding backreference expression. For each backslash (\) encountered in scanning replacement loses its special meaning (if any). It is unspecified what special meaning is to give to any character other than &, \ or digits.
