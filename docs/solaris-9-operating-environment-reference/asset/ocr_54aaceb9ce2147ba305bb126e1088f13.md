full path names. An option to the aliasing facility enables the value of the alias to be automatically set to the full path name of the corresponding command. These aliases are called tracked aliases. The value of a tracked alias is defined the first time the corresponding command is looked up and becomes undefined each time the PATH variable is reset. Aliases remain tracked so that the subsequent reference redefines the value. Several tracked aliases are compiled into the shell. The -h option of the set command makes each referenced command name into a tracked alias. The following exported aliases are compiled into (and built into) the shell, but you can unset or redefine them.

```
autoload='typeset -fu'
alse='let 0'
functions='typeset -f'
hash='-t'
history='fc -1'
integer='typeset -i'
nohup='nohup'
r='fc -e -'
true=':'
type='whence -v'
```

The following example shows a problem involving trailing blank characters and reserved words. If you type the command

```
$ alias foo="/bin/ls"
$ alias while="/"
```

the effect of executing the following commands is a never-ending sequence of Hello, World strings.

+   $ while true
> do
> echo "Hello, World"
> done

If, however, you type the command, the result is an listing of /.

```
$ foo while
```

Because the alias substitution for foo ends in a space character, the next word is checked for alias substitution. The next word, while, has also been aliased, so it is substituted as well. Because it is not in the proper position as a command word, it is not recognized as a reserved word.
If you type

```
$ foo; while
```

while retains its normal reserved-word properties.
