# passwd — Change Login Password and Password Attributes

# Synopsis

```
/usr/bin/passwd [-r nis] [-r nisplus] [name]
/usr/bin/passwd [-r files] [-r ldap] [-r nis] [-r nisplus] [name]
/usr/bin/passwd [-r files] [-egh] [name]
/usr/bin/passwd [-r files] -s [-a]
/usr/bin/passwd [-r nis] -s [-a]
/usr/bin/passwd [-r files] [-d | -1] [-f] [-min] [-w warn] [-x max] name
/usr/bin/passwd -r ldap [-egh] [name]
/usr/bin/passwd [-egh] [-D domainname]
/usr/bin/passwd -r nis -s [-a]
/usr/bin/passwd -r nisplus [-D domainname] -s [name]
/usr/bin/passwd -r nisplus [-1] [-f] [-n min] [-w warn] [-x max]
[-D domainname] name
```

# Description

> The passwd command replaces the passwd and ypasswd commands and should be used in their place.

Use passwd to change the password or list password attributes associated with the user's login name. Additionally, super can use passwd to install or change passwords and attributes associated with any login name.

When used to change a password, passwd prompts for the old password if any. Then it prompts again for the new password. When you type the password, passwd checks to see if it has aged sufficiently. If aging is insufficient, passwd terminates. pwcmd(1), nlistdb(1), and shadow(4) for additional information.

When LDAP is in the Solaris 8 release, or NIS+ is in effect on a system, LDAP, NIS, or NIS+ password can be different from the local machine. If NIS or NIS+ is running, use passwd -r to change password information on the local machine.

The command updates /etc/shadow with information from /etc/passwd relies on a special value of x in the password field of the /etc/passwd file. The value of x indicates that the password for the user is already in /etc/shadow and should not be modified.
