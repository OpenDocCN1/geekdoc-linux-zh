# troff — Typeset or Format Documents

# Synopsis

```
/usr/bin/troff [-a] [-f] [-Fdir] [-i] [-name] [-nM] [-olist] [-ram]
[-sM] [-Tdest] [-uM] [-z] [filename]...
```

# Description

The troff command is a programming language that manipulates text and drives an output device. You create text in a text editor such as vi or emacs, including formatting commands and macros within the text to produce an ASCII file that contains both the form and the contents of the document. Use the troff command to format or compile the program to produce the final output.

If no filename argument, troff reads a dash (-) as a file name indicates that standard input should be read at that point in the list of input files. The output of troff is usually piped through dscript(1) to create a printable PostScript file.
