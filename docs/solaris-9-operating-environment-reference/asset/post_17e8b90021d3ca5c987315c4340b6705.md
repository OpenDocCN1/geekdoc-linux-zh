# sccs-prt, prt — Display Delta Table Information from an SCCS File

## Synopsis

```
/usr/ccs/bin/prt [-abdefistu] [-c date-time] [-r date-time] [-y sid]
s.filename...
```

## Description

Use SCCS prt (print) command to print selected portions of an SCCS file.
default, prt prints the delta table (version log).

If you use a directory name in the place of s. filename argument, the prt command
applies to all s. files in directory. Unreadable s. files produce an error; processing
continues with the next file (if any). The use of a dash (-) as s. filename argument
indicates that the names of files are to be read from the standard input, one s. file per line.

## Options

If you supply any option other than -y, -c, or -r, the name of each file being processed
(preceded by one newline and followed by two newline characters) appears above his contents.

If you use none of the -u, -f, -t, or -b options, -d is assumed. -s and -i are mutually
exclusive, as are -c and -r.

- -a
Display log entries for all deltas, including those marked as removed.

- -b
Print the body of the s. file.

- -c date-time
Exclude delta table entries that have passed the specified cutoff date and time.
Print each entry as a single line preceded by the name of the SCCS file.
This format (also produced by -r and -y) makes easy to sort multiple
deltas in chronological order. When you supply both -y and -c both -y and -r, stop printing when the first of the two conditions is met.

- -d
Print delta table entries (the default).

- -e
Do everything. This option implies -d, -i, -u, -f, and -t.

- -f
Print the flags of each named s. file.

- -i
Print the serial numbers of included, excluded, and ignored deltas.

- -r date-time exclude delta table entries that are newer than the specified cutoff date and time.

- -s print only the first line of the delta table entries; that is, only up to the statistics.

- -t print the descriptive text contained in the s. file.

- -u print the user names and/or numerical group IDs of users allowed to make deltas.

- -y sid exclude delta table entries made before the specified sid. If no delta in the table has the specified sid print the entire table. If you specify no sid print the most recent delta.

## Usage

## Output Format

The following format is used to print those portions of the s. file that are specified by the various options.

- * Newline.
* Type of delta (D or R).
* Space.
* SCCS delta ID (sid).
* Tab.
* Date and time of creation in the format yy/mm/dd hh/mm/ss.
* Space.
* User name of the delta's creator.
* Tab.
* Serial number of the delta.
* Space.
* Predecessor delta's serial number.
* Tab.
* Line-by-line change statistics in the format inserted/deleted/unchanged.
* Newline.
* List of included deltas by a newline (only if there were such deltas and you used -i option).
* List of excluded deltas by a newline (only if there were such deltas and you used -i option).
* List of ignored deltas by a newline (only if there were such deltas and you used -i option).
* List of Modification Requests (MRs) by a newline (only if you supplied any MR).
* Lines of the delta commentary (if any) by a newline.

## Examples

The following example produces a one-line display of the delta table for the most recent version.

```
castle@ /usr/ccs/bin/prt -y program.c
s.program.c: D 1.6 88/07/06 21:39 username 5 4 005/08/06...
```

# sccs-rmdel, rmdel — Remove a Delta from an SCCS File

## Synopsis

```
/usr/ccs/bin/rmdel -rsid filename...
```

## Description

Use the rmdel command to remove the delta specified by the SCCS delta ID (sid) supplied with the -r option. The delta to be removed must be the most recent (leaf) delta in its branch. In addition, the sid must not be that a version checked out for editing: it must not appear in any entry of the version lock file (file).

If you created the delta or if you own the file and directory and have write permission, you can remove it with rmdel.

If you use a directory in place of the filename argument, the rmdel command applies to all files in that directory. Unreadable files produce an error: processing
continues with the next file (if any). The use of a dash (-) as the filename argument indicates that the names of files are to be read from the standard input, one file per line.

## Options

- -rsid Remove the version corresponding to the indicated sid(delta).

## Files

- -file Permissions file.
file History file.

# sccs-sact, sact — Show Editing Activity Status of an SCCS File

## Synopsis

/usr/ccs/bin/sact filename...

## Description

Use the SCCS command to list any SCCS files that are checked out for editing.
The output for each named file consists of the following five fields separated by characters.

- sid of a delta that currently exists in the SCCS file to which changes are made to create the new delta.
- sid for the new delta to be created.
- User name of the person who has the file checked out for editing.
- Date on which the version was checked out.
- Time at which the version was checked out.

If you use a directory name in place of the filename argument, the command applies to all files in that directory. Unreadable files produces an error; processing continues with the next file (if any). The use of a dash (-) as the filename argument indicates that the names of files are to be read from the standard input, one file line.

# sccs-sccdiff, sccdiff — Compare Two Versions of an SCCS File

## Synopsis

```
/usr/ccs/bin/sccdiff [-p] -r sid -r sid [diff-options] filename
```

## Description

Use the SCCS sccdiff command to compare two versions of an SCCS file and display the differences between the two versions. You can specify any number of SCCS files; the options specified applied to all files.

## Options

- -p Pipe output for each file through pr(1).
-r sid Specify a version corresponding to the indicated SCCS delta ID (sid) for comparison. Versions are passed to diff(1) in the order given.

```
diff-options Pass options to diff(1), including -b, -c, -C number, -D string-e, -f, -w
-h, -u, and -U number.
```
