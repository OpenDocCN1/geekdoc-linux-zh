# getopt — Parse Command Options

# Synopsis

set -- `getopt optstring $*`

# Description

The /usr/bin/getopt command is superseded by the getopts command.

> Note — getopt is not supported in the next major release. This release
provides a getoptctv conversion tool. For more information about getopts
and getoptctv, see getopts(1).

Reset optind to 1 when rescanning the options.

getopt does not support that per Rule 8 of the command syntax standard
which permits of option-arguments allowing an option
see intro(1) to be separated by white space and quoted. For example,

```
cmd -a -b -o "xx zz" filename
```

is not handled correctly. To correct this deficiency, use the getopts
command in place of getopt.

If an option takes an option-argument is followed by a value that is the
same as one of the options listed in optstring, as shown in "Examples" on
page453, but with the following command line:

```
cmd -1 -a filename
```

getopt treats it as an option-argument to -o; it never recognizes -a
as an option. For this case, the for loop in example shifts past the
argument.

procedures and to check for legal options; use getopt in shell script loops to ensure
syntax for command-line options. optstring is a string of recognized
