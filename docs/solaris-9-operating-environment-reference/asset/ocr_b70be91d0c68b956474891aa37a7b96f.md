# bc — Binary Calculator

# Synopsis

```
/usr/bin/bc [-c] [-1] [file...]
```

# Description

bc is both a calculator and a C-like language that you can use to write numerical programs. bc is actually a preprocessor for the dc desktop calculator and uses the dc command to do its work. However, bc contains many functions than does dc, including named functions, logical operators, and mathematical functions such as sqrt (square root). It uses infix notation, where you place operators between the numbers on which they operate. For example, 2 + 2 = 4.

You execute bc from a command line. It can take input from a command line or directly from a file and then from the command. When you use a file name as an argument, bc reads the file, processes its commands, and switches to the command line for its input. In this way you can store complex commands and functions in a file and use them directly from a command line.

bc automatically displays the results of its calculations for every line. All of the information for a single calculation must be on one line. To exit from bc, type quit or press Control-D to signal end-of-file. The bc command language resembles the C language.

# Notes

The bc command does not recognize the logical operators && and ||. For the statement must have all three expressions.

# Options

+   -c Compile only. Only the bc command output to the standard output.

+   -1 Define the math functions, and initialize scale to 20 instead of the default 0.

# Operands

+   file A name of a text file containing bc program statements. After all cases of file have been read, bc reads the standard input.
