# postio — Serial Interface for PostScript Printers

# Synopsis

```
/usr/lib/lp/postio -l line [-i] [-q] [-t] [-S] [-B speed] [-B num]
[-L file] [-P string] [-R num] [file...]
/usr/lib/lp/postscript/postio
```

# Description

The postio sends commands to the PostScript printer attached to line. If you
specify no flags, the standard input is sent.

# Notes

The input files are handled as a single Postscript job. Sending several different jobs,
each with its own end-of-job mark (*D) is not guaranteed to work properly.
postio can quit before all the jobs have completed and can be restarted before the last
finishes.

All the capabilities described below may not be available on every machine or
across the different versions of the UNIX system that are currently supported by the
program.

There may be no default line, using the -l option is strongly recommended. If you
it the -l option, postio may try to connect to the printer using the standard output.
If Datuk is involved, the -b option may be ineffective and attempts by postio to
impose control over data in both directions may not work. The -q option can help
the printer is connected to RADIAN. The -s option is not generally recommended and
be used only if all other attempts to establish a reliable connection fail.

# Options

The following group of options should be sufficient for most applications.

+   -b speed Transmit data over line at baud rate Recognized baud rates are
1200, 2400, 4800, 9600, and 19200. The default speed is 9600.

+   -B num The internal buffer size for reading and writing files to numbytes. By
default, num is 2048 bytes.

+   -D Enable debug mode. Guarantee that everything on line is added
to the log file (standard error by default).
