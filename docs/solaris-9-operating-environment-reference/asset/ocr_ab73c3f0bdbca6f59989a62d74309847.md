# newform

# 921

Expand Tabs to spaces according to the Tab specifications given.	abspec recognizes all Tab specification forms described in tabspec(1). In addition, tabspec can be --, in which case, newform assumes that the Tab specification is to be found in the first line read from the input (see fspec(4)). If you specify no tabspec, tabspec defaults to -8.
A tabspec of -0 affects Tabs; if any are found, they are treated

as.

Set the effective line length to n characters. If you do not specify n, -1 defaults to 72. The default line length without the -1 option is 80 characters. Note that Tabs and backspaces are considered to be one character (use -i to expand Tabs). You must use -11 to set the effective line length shorter than any existing line in the file so that the -b is option.

Replace spaces with Tabs according to the Tab specifications given. The Tab specifications are the same as for -i tabspec. If you specify no tabspec, tabspec_defaults to -8. A tabspec of -0 means that no spaces are converted to Tabs on output.

Prefix n characters (see -cchaz) to the beginning of a line when the length is less than the effective line length. Default is to prefix the number of characters necessary to obtain the effective line length.

Shear leading characters on each line up to the first Tab, and put to eight of the sheared characters at the end of the line. If more than eight characters (not counting the first Tab) are sheared, replace the eighth character with an * and discard any characters to the right of it. Always discard the first Tab.

Save the characters sheared internally until all other options are applied to that line. Then, add the characters at the end of the processed line.

For example, you have a file with leading digits, one or more Tabs, and on each line. You want to convert that file to a file beginning with the text, all after the first expanded to spaces, padded with spaces up to column 72 (or truncated to column 72), and the leading digits placed at column 73. The command is:

```
newform -s -i -1 -a -e filename
```

If you use this option on a file without a Tab on each line, newform displays an error message and exits.
