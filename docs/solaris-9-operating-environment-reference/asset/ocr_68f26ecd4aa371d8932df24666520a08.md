# 506

# iconv

# Options

-f fromcode

Identify the input code set.

-t tocode Identify the output code set.

# Operands

file A path name of the input file to be translated. If you omit file, use the standard input.

# Examples

The following example converts the contents of file mail from code set 8859 to 646fr and stores the results in the file mail.local.

```
$castle iconv -f 8859 -t 646fr mail1 > mail.local
$castle$
```
