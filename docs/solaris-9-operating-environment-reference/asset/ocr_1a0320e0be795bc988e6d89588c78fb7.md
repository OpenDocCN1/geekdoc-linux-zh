# xargs — Construct Argument Lists and Invoke Command

# Synopsis

```
/usr/bin/xargs [-t] [-p] [-e[ofstr]] [-E eofstr] [-I replstr
[-i[replstr]] [-L number] [-l[number]] [-n number [-x]
[command [argument...]]
```

# Description

xargs is a shell programming tool that enables you to use the output of one command to define the arguments for another. The xargs command constructs a line consisting of the specified command and argument operands followed by as many arguments in sequence from standard input as fit in the length and number constraints specified by the options. The xargs command invokes the constructed command line and waits for it. This sequence is repeated until an end-of-file line is detected on standard input or an invocation of a constructed command line returns an exit status of 255.

Separate arguments to the standard input by unquoted blank characters, unescaped blank characters, or newline characters. You can quote a string of zero or more non-double-quote characters by enclosing them in double quotes. You can quote a string of zero or more nonapostrophe ('') and non-newline characters by enclosing them in apostrophes. You can escape any unquoted character by preceding it with a backslash (\). The command is executed one or more times until the end-of-file is reached. If the command tries to read from its standard input, the results are unspecified.
