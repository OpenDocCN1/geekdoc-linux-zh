# Command Language

Set Creation and Set Listing

```
create $set_name selector_list
list      sets              # list the defined sets
```

You can use to define a set that contains probes that match the selector_list. The set all is predefined as /.*/ It matches all the probes.

Function Listing

```
list      fcnls              # list the available fcn_handle
```

You can list the different functions that can be connected to probes. Currently, Probes.
only the &debug function is available.

Commands to Connect and Disconnect Probe Functions

```
connect &fcn_handle $set_name
connect &fcn_handle selector_list
clear $set_name
clear selector_list
```

Use the command to connect probe functions (which must be prefixed by &)
to probes. You specify the probes either as a single set (with a $) or by explicitly listing
t probe selectors in the command. The probe function has to be one that listed by the
list fcn command. This command does not enable the probes.

Use the clear to disconnect all connected probe functions from the\specified probes.

Commands to Toggle the Tracing Mode

```
trace $set_name
trace selector_list
untrace $set_name
untrace selector_list
```

Use the trace and untrace commands to toggle the tracing action of a probe point
(that is, whether or not a probe emits a trace record if it is). This command does not
enable the probes specified. Probes have tracing on default. The most efficient way to
turn tracing is by using the disable command. untrace is useful if you want debug
out but no tracing. If so, set the state of the probe to enabled, untraced, and
debug function to connected.

Commands to Enable and Disable Probes

```
enable $set_name
enable selector_list
disable $set_name
disable selector_list
```

Use the enable and disable commands to control whether the probes perform the
action for which they have been set up. To trace a probe, you must both enable and trace
(using the trace command) the probe. Probes are disabled by default. Use the list
history command to list the probe control commands issued: connect, clear, trace,
untrace, enable, and disable. These commands are executed whenever a new
object is brought into the target program by dlopen(3DL). See "dlopen Libraries" on page 110 for more information.
