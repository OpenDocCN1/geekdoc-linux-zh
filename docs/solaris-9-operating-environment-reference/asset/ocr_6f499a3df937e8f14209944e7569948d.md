```

done
```

Repeatedly execute the while list and, if the exit status of the last
command in the list is 0, execute the do list; otherwise, the loop
terminates. If no commands in the do list are executed, then the
while command returns a 0 status. You can use until in place of
while to negate the loop termination test.
