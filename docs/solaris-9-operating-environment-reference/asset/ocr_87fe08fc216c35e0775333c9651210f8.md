# localedef — Define Locale Environment

Synopsis
localedef [-c] [-C compiler-options] [-f charmap] [-i sourcefile]
[-L linker-options] [-m model] [-W cc, arg] [-x extensions-file]
localedef

Description
localedef command converts source definitions for locale categories into a format usable by the functions and whose operational behavior is determined by the setting of the locale environment variable (see environ(5)).
The command reads definitions for one or more locale categories belonging to the same locale from the file named in the -i option (if specified) or from standard input.
Each category source definition is identified by the corresponding environment variable name and terminated by an END category-name statement. The following categories are supported.

+   LC_TYPE Define character classification and case conversion.
LC_COLLATE Define collation rules.
LC_MONETARY Define the format and symbols used in the formatting of monetary information.
LC_NUMERIC Define the decimal delimiter, grouping, and grouping symbol for nonmonetary numeric editing.
LC_TIME Define the format and content of data and information.

LC_MESSAGES Define the format and values of affirmative and negative responses.
