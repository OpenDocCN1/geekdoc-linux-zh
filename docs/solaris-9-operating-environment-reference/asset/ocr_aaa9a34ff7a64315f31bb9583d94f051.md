This mapping can be expressed as a replacement function with the following syntax.
principal.domain ->[cname=principal.domain],cred.org_dir.domain

This replacement name is an NIS+ name that can be presented to the nis_list(3NSL)
for relation. NIS+ principal names are administered with the
nisadded(1) command.

The cred table contains five names cname, auth_name, auth_type,
public_data, and private_data. This table contains one record for each identity
mapping an NIS+ principal. The current service supports three types of mappings.

Map from the UID of a given process to the NIS+ principal name
associated with that UID. If no mapping exists, return the name
nbody. When the effective UID of the process is 0 (for example, the
superuser), return the NIS+ name with the host. Note that
UIDs are sensitive to the context of the machine on which the process is
executing.

Map to and from Secure RPC name into an NIS+ principal name.
See secure_rpc(3NSL) for more information on netnames. Note that
netnames contain the notion of a domain, they span NIS+
directories.

Map netnames and principal names for extended Diffie-Hellman
keys, for example, DH640-0, DH024-0. See nisautoconconf(1M)
for further information.

The NIS+ client library function nis_local(3NSL) uses the
cred.org_dir table to map the UNIX union of an identity, a UID, into an NIS+
principal name. Shell programs can use the program nisdefault(1) with the -option
to return this information.

Mapping UIDs to an NIS+ principal name is accomplished by constructing a
query of the following:
[auth_type=LOCAL, auth_name=uid],cred.org_dir.defaultdomain.

This query returns a record containing the NIS+ principal name associated with this
UID, in the machine's default domain.

The NIS service uses the Data Encryption Standard (DES) mapping to map the
names associated with Secure RPC requests into NIS+ principal names. RPC requests
that Secure RPC include the netname of the client making the request in the RPC
header. This netname has the following form.

uid.domain
The service constructs a query using this name of the following form where the
domain is extracted from the netname instead of being the default domain.
[auth_type=DES, auth_name=hostname],cred.org_dir.domain.

This query looks up the mapping of this netname into an NIS+ principal name in the
domain it was created.
