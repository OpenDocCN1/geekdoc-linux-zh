# telnet — User Interface to a Remote System, using the TELNET Protocol

# Synopsis

/usr/bin/telnet [-8Elcdr] [-e escape-char] [-1 user] [-n tracefile] [[!]@hop1@hop2...] @hop1 [port]

# Description

Use the telnet command to log in to a system running some other operating system or a different version of UNIX. telnet communicates with another host, using the TELNET protocol. If you invoke telnet without arguments, it command mode and displays the telnet> prompt. (See 'telnet Commands' on page 1390.) If you invoke telnet with arguments, it performs an open command with those arguments.

If, for you specify a host as @hop1@hop2@host, the connection goes through hop1 and hop2, using source routing to end at host. If you use a '!', the connection follows strict source routing.

Note — When telnet enters IPv6, it can use only source source routing and the connection ignores the !.
