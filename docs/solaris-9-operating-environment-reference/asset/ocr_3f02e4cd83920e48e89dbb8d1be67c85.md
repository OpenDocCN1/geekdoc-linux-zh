A description is included for all probes that are encountered during execution. The description is one line prefixed by the keyword tnf_name. The description of the probe is in double quotes after the keyword tnf_string.

A heading is printed before all the descriptions of the probes are printed. The first column shows the time in milliseconds since the first event. The second column shows the time in milliseconds since the previous event. The next four columns are the process, LWP ID, thread ID, and CPU name. The next column is the name of the probe that generated this event. You can match the probe name to the probe described above. The last column is the data that the event contains, formatted as arg_name (see tnf_PROBE3X) followed by a colon and the value of the argument formatted in hexadecimal. All other integers are printed in decimal. Strings are printed in double quotes and user-defined values are enclosed in braces { }. The first field of a user-defined record indicates its TNF type (see TNF_DECLARE_RECORD_3X), and the rest of the fields are the members of the record.
