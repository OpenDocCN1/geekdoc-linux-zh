# bc 101

You can use a minus sign to indicate negative numbers. In the following examples, subtracting by a negative number adds it. Adding a negative number subtracts.

```
castle% bc
1 + 2 + 3 - -3.12195
9.12195
1 + 2 + 3 + -2.14197
3.85803
Control-D
castle%
```

You can use the scale operator to specify how many digits to the right of the decimal point are retained in your calculations. The scale setting remains in effect for the current session.

```
castle% bc
scale = 3
1.2345/.9876
1.250
Control-D
castle%
```

You can define and use variables by assigning the value to a single letter. In the following example, x is set to 7 and used in the subsequent calculation.

```
castle% bc
x=7
5*7
35
Control-D
castle%
```

In the shell, the following assigns an approximation of the first 10 digits of -? to the variable x.

```
x=5(printf "%s\n" 'scale = 10; 104348/33215' | bc);
```

The following example.dc defines a function to compute an approximate value of the exponential function and prints approximate values of the exponential function of the first 10 integers.

```
scale = 20
define e(x){
auto a, b, c, i, s
a = 1
b = 1
s = 1
for(i=1; i<=1; i++){
a = a*x
b = b*i
c = a/b
if (c == 0) return(s)
s = s+c
}
for(i=1; i<=10; i++) e(i);
```
