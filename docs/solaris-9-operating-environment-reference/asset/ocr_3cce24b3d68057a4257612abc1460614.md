# Sizes and Fonts

Change sizes and fonts with size nor size +-n, roman, italic, bold, and font n
Change sizes and fonts globally in a document by gsize and gfont nor by the
command-line arguments -sn and -fn.

# Successive Display Arguments

You can line up successive display arguments by placing mark before the desired lineup
point in the first equation; apiece at the place that is to line vertically in
subsequent equations.

# Shorthands

Define shorthands or redefine existing keywords with define. The following statement
defines a new token called thing that is replaced by replacement whenever it appears
thereafter. The % can be any character that does not occur in replacement.
define thing % replacement %

# Keywords and Shorthands

Keywords are sure (SIGMA is not reproducible in nroff), int (integral sign
is not reproducible in nroff), inf (infinity sign is not reproducible in nroff), and
shorthands like >= (greater than or equal to is not reproducible in nroff) -> (->),
!= (not equal to not reproducible in nroff).

# Greek Letters

Greek letters are spelled out in the desired case, as in alpha or GAMMA.

# Mathematical Words

Mathematical words use sin, cos, and log are Roman automatically.
You can use troff(1) four-character escapes like \(bu (o) anywhere. Strings enclosed
double quotes "..." are passed untouched to permit keywords to be entered
text. You can use them to communicate with troff when else fails.
