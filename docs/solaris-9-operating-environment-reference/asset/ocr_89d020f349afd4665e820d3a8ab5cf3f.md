# strchg, strconf

If the file fileconf contains the following lines

```
ttcompat
ldterm
pterm
```

the following command configures the standard input stream so that the module
pterm is pushed over the driver, followed by ldterm and ttcompat closest to the stream
head.

```
castle@ strchg -f fileconf
```

the strconf command with no arguments lists the modules and topmost driver on
t stream; for a stream that has only the module ldterm pushed above the zs driver,
you would get the following output.

```
castle@ strconf
ldterm
z
castle@
```

the following command asks if ldterm is on the stream and returns an exit status
0.

```
castle@ strconf -m ldterm
yes
castle@
```

# Diagnostics

strchg 0 on success. It prints an error message and returns non-zero status for
various error conditions, including usage error, bad module name, too many modules to
push, failure of an ioctl on the stream, or failure to open filename from the -f option.
strconf 0 on success (for the -m -t option, success means the named or
topmost module is present). It returns a non-zero status if invoked with the -m -t
option and the module is not present. It prints an error message and returns non-zero
status for various error conditions, including usage error or failure of an ioctl on the
stream.
