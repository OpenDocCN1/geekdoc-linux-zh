# Examples

In the if commands, three conditions are tested, and if all three evaluate true or successful, then their validities are written to the screen.

The three tests are:

+   - If a variable set to 1 is greater than 0.
- If a variable set to 2 is equal to 2.
- The we root is included in the text file /etc/passwd.

/usr/bin/test

The following example performs a mkdir if a directory does not exist.

```
test ! -d tempdir && mkdir temp
```

The following example waits for a file to become nonreadable.

```
while test -r thefile
do
  sleep 30
done
  echo "thefile" is no longer readable
```

The following example performs a command if the argument is one of three strings (two variations).

```
if [ "$1" = "pear" ] || [ "$1" = "grape" ] || [ "$1" = "apple" ]
then
  command
fi
case "$1" in
  pear|grape|apple) command ;;
esac
```

For the two forms of the test built-in command, see the Bourne shell if example.
