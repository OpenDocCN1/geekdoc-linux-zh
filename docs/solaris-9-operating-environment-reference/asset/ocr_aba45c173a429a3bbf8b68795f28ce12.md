# Command line:

crle -1 /usr/lib:/local/lib:/usr/local/lib
example%

In the above example, the default configuration file initially did not exist, and thus the new search path /local/lib is appended to the system default. The next update appends the search path /usr/local/lib to those already established in the configuration file.

The following example creates and displays a new default search path and trusted directory for ELF objects.

```
crle -1 /local/lib -1 /usr/lib -s /local/lib
example% crle
```

```
Configuration file [2]: /var/ld/ld.config
Default Library Path (ELF): /local/lib:/usr/lib
Trusted Directories (ELF): /local/lib
```

Command line:

```
crle -1 /local/lib:/usr/lib -s /local/lib
example%
```

With this configuration, you can install third-party applications in /local/bin and their associated dependencies in /local/lib. The default search path enables the applications to load their dependencies without needing to set LD_LIBRARY_PATH.

> Note — This example replaces the system default cache for ELF objects.

The following example creates a directory cache for ELF objects.

```
crle -i /usr/dt/lib -i /usr/openwin/lib -i /usr/lib -c config
example% ldd -s /main
find object=libc.so.1; required by ./main
search path=/usr/dt/lib:/usr/openwin/lib (RPATH ./main)
trying path=/usr/dt/lib/libc.so.1
trying path=/usr/openwin/lib/libc.so.1
search path=/usr/lib (default)
trying path=/usr/lib/libc.so.1
libc.so.1 = /usr/lib/libc.so.1
```

```
example% LD_CONFIG=config ldd -s /main
```

With this configuration, the cache reflects the system library libc.so.1 does not exist in the directories /usr/dt/lib or /usr/openwin/lib. The search for this system file ignores these directories unless the application's runpath indicates they should be searched.
