# B

# banner — Make Posters

# Synopsis

/usr/bin/banner strings

# Description

banner prints its arguments in large letters on the standard output, one argument line, up to a maximum of 10 characters.

# Examples

The following example prints happy birthday.

```
castle% banner happy birthday

 #      #  #    #  #  #      # 
 #######  #    #  #  #  ###### #
 #      #  #    #  #  #      # 
 #      #  #    #  #      # 
```
