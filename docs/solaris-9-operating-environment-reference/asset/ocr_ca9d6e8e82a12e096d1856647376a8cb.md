rule to build an executable named file from a C source file named file.c. If a target with a null suffix has an explicit dependency, make omits the search for a suffix rule.

The following table lists the standard implicit (suffix) rules.

| Use | Implicit Rule Name | Command Line |
|---|---||
| Assembly files | .s-o | $(COMPILE.s) -o $ %$
| | .s-a | $(COMPILE.s) -o $ %$
| | | $(AR) (ARFLAGS) $ %$
| | | $(RM) $ %$
| | .s~o | $(-s1GFLAGS) -p $ > *.s$
| | | $(-s1COMPILE.s) -o $ > *.s$
| | .S.o | $(COMPILE.S) -o $ %$
| | .S.a | $(COMPILE.S) -o $ %$
| | | $(AR) (ARFLAGS) $ %$
| | | $(RM) $ %$
| | .S-.o | $(GET) (GFLAGS) -p $ > *.S$
| | | $(COMPILE.S) -o $ *.S$
| | .S-.a | $(GET) (GFLAGS) -p $ > *.S$
| | | $(COMPILE.S) -o $ *.S$
| | | $(AR) (ARFLAGS) $ %$
| | | $(RM) $ %$
| C files | .c | $(LINK.c) -o $ $ $(LDLIBS)
| | .c.ln | $(INT.c) $(OUTPUT_OPTION) -i $$
| | .c.o | $(COMPILE.c) $(OUTPUT_OPTION) $$
| | .c.a | $(COMPILE.c) -o $ $ %$
| | | $(AR) (ARFLAGS) $ %$
| | | $(RM) $ %$
| | .c~ | $(GET) (GFLAGS) -p $ > *.c$
| | | $(CC) (CFLAGS) (LDFLAGS) -o $ %$
| | .c~.o | $(GET) (GFLAGS) -p $ > *.c$
| | | $(CC) (CFLAGS) -c $ *.c$
| | .c~.ln | $(GET) (GFLAGS) -p $ > *.c$
| | | $(INT.c) $(OUTPUT_OPTION) -c $ *.c$
| | .c~.a | $(GET) (GFLAGS) -p $ > *.c$
