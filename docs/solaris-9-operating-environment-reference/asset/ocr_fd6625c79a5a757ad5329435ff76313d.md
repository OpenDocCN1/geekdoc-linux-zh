# Undo, Redo, Retrieve

+   u Undo last change.

+   U Restore current change.

+   . Repeat last change.

+   "ↄ Retrieve-th last delete.

# Usage

See largefile(5) for the description of behavior of vi and view when encountering files greater than or equal to 2 Gbytes (**31 bytes).

# Environment Variables

See environ(5) for descriptions of the following environment variables that affect the execution of vi: LC_TYPE, LC_TIME, LC_MESSAGES, and LC_PATH.
The editing defaults tries to read certain configuration options. When you initiate an editing session, vi tries to read the ENVIRONMENT environment variable. If it exists, the editor uses the values defined in EXINIT; otherwise, it uses the sets in $HOME/.exrc. If .exrc does not exist, the default values are used.
Use a copy of .exrc located in the current directory other than $HOME, set the exrc option in EXINIT or $HOME/.exrc. You can turn off options set in EXINIT in a local exrc if exrc is set in EXINIT or $HOME/.exrc.
