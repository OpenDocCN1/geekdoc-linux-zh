# tip 1417

framesize (num) The amount of data (in bytes) buffer between file-system writes when receiving files; abbreviated fr. If the fs capability is present, initially set framesize to the value of that capability; otherwise, set framesize to 1024.

halfduplex (bool) Do local echoing because the host is halfduplex; abbreviated hdx. If the hd capability is present, initially set halfduplex to on; otherwise, initially set halfduplex to off.

hardwareflow (bool) Do hardware flow control; abbreviated if. If the h capability is present, initially set hardwareflow to on; otherwise, initially set hardwareflow

host (str) The name of the host to which you are connected; abbreviated ho. Set host permanently to the name given on the command line or in the HOST environment variable.

locale (bool) A synonym for halfduplex; abbreviated le.

log (str) The name of the file used to log information about outgoing phone calls. Initially set to /var/adm/aculog. log can be inspected or changed only by superuser.

parity (str) The parity to be generated and checked when talking to the remote host; abbreviated par. The possible values are:

+   - none Parity is not checked on input and the parity bit is set to 0 on output.

+   - one Parity is not checked on input and the parity bit is set to 1 on output.

+   - even Even parity is checked for input and generated on output.

+   - odd Parity is checked for input and generated on output.

If the pa capability is present, initially set parity to the value of that capability; otherwise, set parity to none.

phones used to find hidden phone numbers. If the environment variable PHONES is set, set phones to the value of PHONES; otherwise, set phones to /etc/phones. You cannot change the value of phones from within tip.

prompt (char) The character that indicates an end-of-line on the remote host; abbreviated pr. Use this value to synchronize data transfers. The count of lines transferred during a file transfer is based on receipt of this character. If the pr capability is present, initially set prompt to the value of that capability; otherwise, set prompt to \n.
