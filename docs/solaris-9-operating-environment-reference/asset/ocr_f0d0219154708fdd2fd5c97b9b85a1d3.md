# Operands

file The name of the file to be printed. Specify file as a path name. If you do not specify file, use the standard input.

# Usage

largefile(5) for the description of the behavior of lpr when encountering files greater than or equal to 2 Gbytes(**31 bytes).

# Exit Status

+   0 Successful completion.

+   non-zero An error occurred.

# Files

/var/spool/print/.seq File containing the sequence numbers for job ID assignment.

/var/spool/print/[cd] f* Spool directories and files.

# Attributes

See attributes(5) for descriptions of the following attributes:

| Attribute Type | Attribute Value |
|---|---|
| Availability CSI | SUNscp Enabled |

> Note — lpr is CSI enabled except for the printer name.

# Diagnostics

```
lpr: destination:| unknown destination
destination was not found in the LP configuration database.
Usually this error results from a typing mistake; however, it may
indicate that the destination does not exist on the system. Use
lstat -p to display information about the status of the printer
service.
```
