# hp7221plot, hpplot

# Description

Use the hostname command to print the name of the current host, as given before the login prompt. The superuser can set the host name by giving an argument.

# Example

The following example uses hostname with no arguments to display the host name.

```
$ hostname
castle
$ 
```

# Attributes

See attributes(5) for descriptions of the following attributes:

| Attribute Type | Attribute Value |
| Availability | SUNMcsu |

# See Also

uname(1), attributes(5)
