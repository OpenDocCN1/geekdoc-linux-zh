wait Wait for background jobs to finish (or for an interrupt) before prompting.

```
while (expr)
...
end
```

While expris true (evaluates to non-zero), repeat commands between the while and the matching statement. You can use break and continue to terminate or continue the loop prematurely. The while and end must appear alone on their input lines. If the shell's input is a terminal, it prompts for commands with a question mark until the end command is entered and performs the commands in the loop.

```
%[job] [&]
@ [var=expr]
@ var[n]=expr
```

Bring the current or indicated job to the foreground. With the optional ampersand, continue running job in the background.

With no arguments, display the values for all shell variables. With arguments, set the variable var, or the nth word in the value of var to the value that expr evaluates to (if both var and nth component must already exist).

If the expression contains the characters >, <, &, |, then at least this expr must be placed within parentheses.

The operators, += and so forth, are available as in C. The space separating the name from the assignment operator is optional. Spaces are, however, mandatory in separating components of expr that would otherwise be single words.

# Environment Variables and Predefined Shell Variables

Unlike the Bourne, the C shell maintains a distinction between environment variables and shell variables. Environment variables are automatically exported to the processes it invokes. Shell variables are not. Both types of variables are treated similarly under variable substitution. The shell sets the variables argv, cwd, home, path, prompt, and status on initialization. The shell copies the environment USER into the shell variable, TERM into HOME into, and copies each back into the respective environment variable whenever the shell variables are reset. PATH and path are handled similarly. You need set path only once in the .cshrc or .login file. The environment variable PWD is set cwd whenever the latter changes. The shell variables shown below have predefined meanings.

+   argv The list of command-line arguments supplied to the current invocation of the shell. This variable determines the value of the positional parameters $1, $2, and so on.

+   cwd A list of directories to be searched by the cd, cd, and popd commands if the directory argument each accepts is not a subdirectory of the current directory.

+   cwd The full path of the current directory.
