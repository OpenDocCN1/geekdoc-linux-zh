# fastboot, fasthalt

# fastboot, fasthalt — Reboot/Halt the System Without
Checking the Disks

# Synopsis

```
/usr/ucb/fastboot [boot-options]
/usr/ucb/fasthalt [halt-options]
```

# Description

fastboot and fasthalt are shell scripts that invoke reboot and halt with the proper
arguments.

> Note — These commands are provided for BSD compatibility only.

# Attributes

See attributes(5) for descriptions of the following attributes:

| Attribute Type | Attribute Value |
| Availability | SUNwcpu |
