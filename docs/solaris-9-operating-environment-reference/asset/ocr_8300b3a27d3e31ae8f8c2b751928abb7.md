# ksh, rksh — Korn Shell, a Standard/Restricted Command
Programming Language

# Synopsis

```
/usr/bin/ksh [+pm abcefhikmnoprustux] [+ o option] ... [arg...]
usr/bin/ksh -c [+pm abcefhikmnoprustux] [+ o option] ... command-string
[command-name [arg...]]
usr/xpg4/bin/sh [+pm abcefhikmnoprustux] [+ o option] ... [arg...]
usr/xpg4/bin/sh -c [+pm abcefhikmnoprustux] [+ o option] ...
command-name [arg...]]
usr/bin/ksh [+pm abcefhikmnoprustux] [+ o option] ... [arg...]
usr/bin/ksh -c [+pm abcefhikmnoprustux] [+ o option] ... command-string
[command-name [arg...]]
```

The shell, written by David Korn of AT&T Bell Laboratories, was designed to
compatible with the Bourne shell and to offer interactive features comparable to the C
shell. The Korn shell includes convenient programming features such as built-in integer
arithmetic, arrays, and string-manipulation facilities. The Korn runs faster than
the C shell and virtually all scripts that are written for the Bourne shell.

The Korn shell command is /usr/bin/ksh or /usr/xpg4/bin/ksh. These two
ksh are identical.

+   /usr/bin/ksh is a restricted version of the command interpreter ksh; it is used to
set login names and execution environments whose capabilities are more controlled
than those of the standard shell.

The default prompt for the Korn shell is a dollar sign ($). The root prompt is a pound
s (#).

The Korn shell discusses the following definitions:

+   * A metacharacter is one of the characters: ; & ( ) | > newline space
Tab.
* A blank is a Tab or a space.
* An identifier is a sequence of letters, digits, or underscores starting with a letter or
underscore. Identifiers are used as names for functions and variables.
* A word is a sequence of characters separated by one or more nonquoted
metacharacters.
* A command is a sequence of characters in the syntax of the shell language. The
shell reads and carries out the desired action directly or by
invoking separate commands.
* A special command is a command that is carried out by the shell without creating
a separate process. For documented side effects, most special commands
can be implemented as separate commands.
