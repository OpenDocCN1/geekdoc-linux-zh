# ruptime — Show Host Status of Local Systems

# Synopsis

```
/usr/bin/ruptime [-ar] [-l | -t | -u]
```

# Description

Use the uptime command to view a status line like uptime for each system on the local network; these statistics are formed from packets broadcast by each host on the network once a minute.

Systems for which no status report has been received for 5 minutes are shown as being down.

Normally, the listing is sorted by host name, but you can change this order by specifying one of the options listed below.

# Options

+   -a Count even those users who have been idle for an hour or more.

+   -l Sort the display by load average.

+   -r Reverse the sorting order.

+   -t Sort the display by uptime.

+   -u Sort the display by number of users.

The -l | -t | -u options are mutually exclusive. The use of one overrides the previous one(s).
