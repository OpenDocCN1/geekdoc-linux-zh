# Notes

The CD writing process requires data to be supplied at a constant rate to the drive. It is advised to keep I/O activity to a minimum and shut down the related applications while writing CDs.

When making copies or extracting audio tracks, it is better to use an MMC compliant source CD-ROM drive. The CD writing device can be used for this purpose.

Before writing a CD, ensure it is blank by using the -n option and then use the -S simulation mode to test the system to make sure it provide data at the required rate. In case the system is not able to provide data at the required rate, try simulation with a slower write speed with the -p option. You can also try to cdrw with a higher priority with the priorityncl(1) command.

The -p option is for users who are aware of the CD-R/W drive and its capabilities to operate at different speeds. Some commercially available drives handle the drive speed setting differently, so use this option optionally.
Most commercially available drives allow writing beyond 74 minutes as long as the media has the capacity (such as 80-minute disc). However, capability of writing beyond 74 minutes might not be supported by the drive. If the drive supports such capacity, use the -c option to indicate that the tool should rely on the capacity indicated by the CD.

cdrw command uses rbac(5) to control user access to the devices. By default, cdrw is accessible to all users but can be restricted to individual users. Please refer to "Administering CD-R/W Devices" in the System Administration Guide: Basic Administration for more information.

# Options

+   -a Create an audio disc. You must specify at least one audio-file name. Because a CD cannot have more than 99 audio tracks, you can specify no more than 99 audio files. The maximum audio data that can be written to the CD by default is 74 minutes unless you specify the -C option.

+   -b all session Blank a CD-RW disc. You must specify the type of erasing by specifying the all or session argument.

+   -c Copy a CD. If you specify no other argument, the default CD writing is assumed to be the source device as well. In this case, the copying operation reads the source CD into a temporary directory and prompts you to put a blank CD into the drive for copying to proceed.

+   -C Use the stated capacity: Without this option, cdrw uses a default value for writable discs, which is 74 minutes for an audio CD or 681984000 bytes for a data CD.

+   -d Specify CD writing device.

+   -h Help. Print usage message.
