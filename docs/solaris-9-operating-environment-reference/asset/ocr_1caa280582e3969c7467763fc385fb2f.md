For example, you can define the shaping sequences.

# A simple shaping sequence.

```
( + 0x21 ->
 ([0x0021], [0], [0:0], [0x80]) + 0x22 ->
 ([0x0021;0x0022], [0,1], [0:0;1;1], [0x80;0x80]) +
0xc2a0 ->
 ([0x0021;0x0022;0x0e30], [0;1;2], [0;0;1;1;2;2],
[0x80;0x80;0x80])
```

# A repeating shaping sequence.

```
( + 0x21 ->
 {
 ([0x0021], [0], [0:0], [0x80]) + 0x22 ->
 ([0x0021;0x0022], [0,1], [0;0;1;1], [0x80;0x80]) +
0xc2a2
} repeat+
```

The first example shows a shaping sequence, when 0x21, 0x22, and 0xc2a0 are the input buffer, the sequence is converted into an output buffer containing 0x0021, 0x0022, and 0x0e30; an input to the output buffer containing 0, 1, and 2; an output to the input buffer containing 0, 0, 1, 1, and 2; and a property buffer containing 0x80, 0x80, and 0x80.

The second example shows a repeating shaping sequence, where the first input code element is 0x21, the second and third input code elements are 0x22 and 0xc2a2.
