# uustat — uucp Status Inquiry and Job Control

# Synopsis

/usr/bin/uustat [-m] [-p] [-q] [-kjobit [-n]] [-rjobid [-n]
/usr/bin/uustat [-a] [-system [-j]] [-user] [-Sqric]
/usr/bin/uustat -tsystem [-c] [-number]

# Description

uustat functions in the following three areas:

+   * Displays the general status of, or cancels, previously specified uucp commands.
* Provides remote system performance information, such as average transfer rates or average queue times.
