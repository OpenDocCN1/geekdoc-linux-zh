# sccs-comb, comb — Combine SCCS Deltas

# Synopsis

```
/usr/ccs/bin/comb [-os] [-csid-list] [-psid] s.filename ...
```

# Description

Use the SCCS command to generate a shell script sh(1) that you can use to
reconstruct the indicated s. files. This script is written to the standard output.

If you use a directory name in place of s.filename argument, the comb command
lies to all s. files in directory. Unreadable s. files produce an error, processing
continues with the next file (if any). The use of a dash (-) as the s.filename argument
indicates that the names of files are to be read from the standard input, s. file per
line.

If you specify no options, comb preserves only the most recent (leaf) delta in a branch
and the minimal number of ancestors needed to preserve the history.
