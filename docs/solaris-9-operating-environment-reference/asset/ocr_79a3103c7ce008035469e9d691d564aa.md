# extstr 343

Assume that the file example.c contains two strings.
main()
{
    printf("This is an example\n");
    printf("Hello world!\n");
}

The following example invokes the extrstr command with the argument example.c to extract strings from the named file and print them on the standard output.
castle% extrstr example.c
example.c:This is an example\n
example.c:Hello world!\n
castle%

Next, use the -e option to extract the strings and redirect the output to a file named example.string.
castle% -e example.c > example.string
example.c:22::This is an example\n
example.c:42::::Hello world!\n
castle%

You must edit example.string to add the values you want to use for the msgfile and msgnum fields before these strings can be replaced by calls to the retrieval function. The following example uses UX as the name of the message file and the numbers 1 and 2 as the sequence number of the strings in the file to produce a file that looks like the following.
castle% more example.string
example.c:32:UX:1:This is an example\n
example.c:42:UX:2:Hello world!\n
castle%
