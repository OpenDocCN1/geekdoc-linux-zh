## vi Search Edit Commands

Use these commands to access your command history.

- [count]k Fetch previous command. Each time you enter k, access the previous command back in time.
- [count] - Equivalent to k.
- [count]j Fetch next command. Each time you enter j, access the next command forward in time.
- [count]+ Equivalent to j.
- [count]G Fetch the command number count. The default is the least recent history command.
- /string Search through history for a previous command containing string. Terminate string with a Return or newline. If you precede string with ^, the matched line begins with string. If string is null, use the previous string.
- ?string Same as / except search forward.
- n Search for next match of the last pattern to / ? commands.
- N Search for next match of the last pattern to / ?, but in reverse direction. Search history for the string entered by the previous / command.

## vi Text Modification Edit Commands

Use these commands to modify the line.

- a Enter input mode, and enter text after the current character.
- A Append text to the end of the line. Equivalent to $a.
- [count]cm Delete current character through the character that motion would move the cursor to, and enter input mode. If motion is c, delete the entire line and enter input mode.
- C Delete the current character through the end of the line, and enter input mode. Equivalent to c$.
- [count]s Delete characters, and enter input mode.
- S Delete entire line, and enter input mode. Equivalent to cc.
- [count]dm Delete current character through the character that motion would move to. If motion is d, delete the entire line.
- D Delete the current character through the end of the line. Equivalent to d$.
- i Enter input mode, and insert text before the current character.
- I Insert text before the beginning of the line. Equivalent to 0i.
- [count]P Put the previous text modification before the cursor.
- [count]p Put the previous text modification after the cursor.
- R Enter input mode, and replace, in overlay fashion, characters on the screen with characters you type.
- [count]rc Replace the count character(s) starting at the current cursor position with c, and advance the cursor.
- [count]x Delete preceding character.
- [count] Repeat the previous text modification command.
- [count] Invert the case of the count character(s) starting at the current cursor position, and advance the cursor.
- [count]_ Append the count word of the previous command, and enter input mode. If you omit count, use the last word.
- * Append an asterisk (*) to the current word, and try file-name generation. If no match is found, ring the bell. Otherwise, replace the word with the matching pattern, and enter input mode.
- \ Perform file-name completion by replacing the current word with the longest common prefix of all file names the current word with an asterisk appended. If the match is unique, append a / or if the file is a directory and a space if the file is not a directory.

## Other Edit Commands

Miscellaneous commands.

- [count]ymotion[count]motion
- Y Yank character through character that motion would move the cursor to, and put them into the delete buffer. Leave the text and cursor unchanged.
- Y Yank from current position to end of line. Equivalent to y.
- u Undo the last text-modifying command.
- U Undo all the text-modifying commands performed on the line.
- [count]v Return the command fc=$ {VISUAL}:S-{EDITOR:-vi} count in the input buffer. If you omit count, use the current line.
- ^ Linefeed, and print current line. Has effect only in control mode.
- J (Newline) Execute the current line, regardless of mode.
- M (Return) Execute the current line, regardless of mode.
- If the first character of the command is a #, then delete this # and each # that follows a newline. Otherwise, send the line after inserting a # in front of each line in the command. Useful for inserting the current line in the history as a comment and removing comments from previous comment commands in the history file.
- = List the file names that match the current word if an asterisk is appended to it.
- @letter Search your alias list for an alias by the name _letter, and if an alias of this name is defined, insert its value on the input queue for processing.

## Command History

Commands you enter from a terminal device are saved in a history file. The HTSSIZE environment variable determines the number of commands that are saved. The default is 128. The HISTFILE variable is not set or if the file is not writable, ksh uses the $HOME/.sh_history to store the history list. A shell can access the commands of all interactive shells that use the same name for HISTFILE. Use the special command fc to list or execute a portion of this file. You can specify the portion of the file to edit or listed by the number assigned in the history list or by specifying the first line.

## Aliasing

Aliases are used to create short names for longer commands. An alias is defined using the alias command. The syntax is alias name=command. If the command contains spaces, it must be enclosed in quotes. To remove an alias, use the unalias command. To list all defined aliases, use alias without any arguments. Aliases can also be defined to include arguments by using the special symbol $. The $ in the alias definition is replaced by the first character of the command line when the alias is invoked. Aliases are not expanded in scripts unless the set +A option is used.

The following example shows how to define an alias:

```
$ alias ls='ls -F'
$ alias ll='ls -la'
```

Now, typing ls will execute ls -F, and typing ll will execute ls -la. Aliases can also be used for complex commands with pipes:

```
$ alias grep='grep --color=auto'
```

Another example shows how to use the $ symbol in an alias:

```
$ alias mycd='cd $; ls'
```

When you type mycd directory, it will change to the specified directory and then list the contents. Aliases are a useful tool for saving time and typing effort.

## Functions

Functions in ksh are similar to aliases but can take arguments and return values. They are defined using the function keyword. The syntax for defining a function is:

function name { ...; }

Alternatively, the function can be defined as:

name { ...; }

Arguments passed to a function are accessed using positional parameters $1, $2, etc. The number of arguments is stored in the variable $#. A function can return a value using the return statement.

The following example shows how to define a function:

```
function greet {
    echo "Hello, $1"
}
```

To call the function, you simply use its name:

```
$ greet World
```

The output will be Hello, World.

Functions can also use local variables using the typeset command:

```

function greet {
    typeset local name=$1
    echo "Hello, $name"
}
```

The local variable name is only available within the function and will not affect the global shell environment.

## Variables

Variables in ksh are used to store data. They are created by assigning a value to a name. The syntax is variable=value. To access the value of a variable, use the $ symbol.

Variables can also be created using the set command. The syntax is set variable=value. To change the value of a variable, use the variable=new_value syntax. To delete a variable, use the unset command.

Variables can be of different types, such as integers, strings, and arrays. Integers can be used for arithmetic operations. Strings are used for text. Arrays are used to store a list of values.

The following example shows how to use variables:

```

$ x=10
$ y=20
$ z=$((x + y))
$ echo $z
```

Arrays are defined using parentheses. The syntax is array=(value1 value2 ... valuen). To access a specific element of an array, use the index in parentheses: array[index]. The index is 0-based.

```
$ array=(apple banana cherry)
$ echo ${array[0]}
```

The output will be apple.

The special variable @ can be used to reference all elements of an array:

```
$ echo ${array[@]}
```

The variable # can be used to reference the number of elements in an array:

```
$ echo ${#array[@]}
```
