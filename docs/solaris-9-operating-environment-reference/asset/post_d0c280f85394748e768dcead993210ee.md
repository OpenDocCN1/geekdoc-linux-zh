# PREFACE

The Solaris 9 Operating Environment Reference is your complete guide to all of the manual pages in Section 1, "User Commands," of the online reference documentation (except the FMLI commands).

All documentation references within this guide are to the official Solaris documentation. To access Sun Microsystems, Inc. documentation online, see http://docs.sun.com.

# Audience

This book is for any user of the Solaris Operating Environment who needs to refer to any of the Section 1 User Commands in the online manual pages for quick reference or more detailed information.

# Icons

Within this reference, any material that is new or revised in Solaris 7 is marked with an asterisk. Commands new in Solaris 8 and Solaris 9 releases are marked with a “New!” icon. Any command introduced in Solaris 8 is marked with a “New!” icon.

# How This Book Is Organized

The Introduction chapter provides a quick reference to the contents of this book by functional grouping. The commands are grouped alphabetically within their installation package categories. Within the “Core Solaris (usr)” category, the commands are grouped by function.

The Introduction chapter also provides a list of commands added in Solaris 8 and Solaris 9 releases along with a list of commands removed from each release. This book is a dictionary-style alphabetical reference to the A through Z commands.
