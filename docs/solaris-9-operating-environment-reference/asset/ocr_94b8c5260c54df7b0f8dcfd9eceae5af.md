# R

# ranlib — Convert Archives to Random Libraries

# Synopsis

/usr/ccs/bin/ranlib archive

# Description

> Note — The ranlib command was used in SunOS 4.x to add a table of contents to archive libraries. It converted each archive to a form that could be linked more rapidly. This command is no longer needed because the ar(1) command automatically provides all the functionality of ranlib.

This command is provided as a convenience for software developers who need to maintain makefiles that are portable across a variety of operating systems.

# Exit Status

ranlib has exit status 0.
