# pkgtrans

# 1061

# Options

Copy only the pkginfo(4) and pkgmap(4) files.

+   -i

Create a new instance of the package on the destination device if any instance of this package already exists, up to the number specified by the MAXINST variable in the pkginfo(4) file.

+   -n

Overwrite the same instance on the destination device if it already exists.

+   -o

Write the package to device2 as a datastream instead of as file system. The default behavior is to write a file-system format on devices that support formats.

+   -s

# Operands

+   devicel1

The source device. The package or packages on this device are translated and placed on device2.

+   device2

The destination device. Translated packages are placed on this device.

+   pkginst1

Specify which package instance or instances on device1 should be translated. You can use the token all to indicate all packages. You can use pkginst.* to indicate all instances of a package. If no packages are defined, a prompt shows all packages on the device and asks to translate.

The asterisk (*) is a special character to some shells and may need to be escaped. In the C shell, you must surround * with single quotes ('') or precede it with a backslash (\

# Examples

The following example translates all packages on the diskette drive /dev/diskette and places the translations on /tmp.

```
castle% pkgtrans /dev/diskette /tmp all
```

The following example translates packages pkg1 and pkg2 on /tmp and puts their translations (that, is, datastream) on the 9track1 output device.

```
castle% pkgtrans /tmp /track1 pkg1 pkg2
```

The following example translates pkg1 and pkg2 on /tmp and puts them on the diskette as datastream format.

```
castle% pkgtrans -s /tmp /dev/diskette pkg1 pkg2
```

# Environment Variables

The MAXINST variable is set in the pkginfo(4) file and clears the maximum number of package instances.

# Exit Status

+   0

Successful completion.

+   >

An error occurred.
