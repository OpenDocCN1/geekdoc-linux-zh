# calendar — Reminder Service

# Synopsis

```
/usr/bin/calendar [-]
```

# Description

You can use the calendar command as a simple reminder service to record your appointments. The calendar command consults a file named calendar in the current directory and writes to the standard output any lines that contain today's or tomorrow's date anywhere in the line. calendar recognizes month-day dates as Aug 24, August 24, 8/24. It does not recognize date formats as August 24 or 24/8. On Fridays and weekends, "tomorrow" extends through Monday. You can run calendar regularly by using the crontab(1) or at(1) commands.

When the optional argument - is present, calendar does its job for all users who have a calendar file in their login directory and sends any positive results by mail(1).
