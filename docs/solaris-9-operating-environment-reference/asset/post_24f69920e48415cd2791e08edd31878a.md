# locale — Get Locale-Specific Information

# Synopsis

/usr/bin/locale [-a | -m]
/usr/bin/locale [-ck] name...

# Description

The locale command writes information to standard output about the current locale environment or all public locales. For the purposes of this command, a public locale is one provided by the implementation that is accessible to the application.

When you use the locale command without any arguments, it summarizes the current locale environment for each locale category as determined by the settings of the environment variables. If the LANG environment variable is set with the following format

```
LANG=locale_x LC_COLLATE=locale_y
```

locale displays the results in the following format.
```
LANG=locale_x
LC_CTYPE=locale_x
LC_NUMERIC=locale_x
LC_TIME=locale_x
LC_COLLATE=locale_y
LC_MONETARY=locale_x
LC_MESSAGES=locale_x
LC_ALL=
```

When you specify operands, locale writes values that have been assigned to the keywords in the locale categories, as follows:

- - Specifying a keyword name selects the named keyword and the category containing that keyword.
- Specifying a category name selects the named category and all keywords in that category.

# 703

Note — If you specify LC_CTYPE or keywords in the category LC_CTYPE, only the values in the range 0x00-0x7f are displayed.

If you specify LC_COLLATE or keywords in the category LC_COLLATE, no actual values are written.

# Options

- -a Write information about all available public locales. The available locales include POSIX, representing the POSIX locale.

- -c Write the names of selected locale categories. The -c option increases readability when you specify more than one category (for example, with more than one keyword name or a category name). It is valid both with and without the -k option.

- -k Write the names of selected keywords. The implementation can omit values for some keywords.

- -m Write names of available charmaps; see localedef(1).

# Operands

- -name Specify the name of a locale category (such as LC_NUMERIC), the name of a keyword in a locale category (such as decimal_point), or the reserved name charset. The named category or keyword is used for output. If a single name represents both a locale category name and a keyword in the current locale, the results are unspecified; otherwise, you can specify both category and keyword names as name operands, in any sequence.

```
LC_MONETARY=en_AU
LC_MESSAGES=C
LC_ALL=
cast%
```

# localedef — Define Locale Environment

Synopsis

localedef [-c] [-C] [-f charmap] [-i sourcefile] [-L] [-m] [-W cc, arg] [-x extensions-file]

Description
The localedef command converts source definitions for locale categories into a format usable by the functions whose operational behavior is determined by the environment variable (if specified) or from standard input. Each category source definition is identified by the name and terminated by an END statement. The following categories are supported:

LC_TYPE Define character classification and case conversion.
LC_COLLATE Define collation rules.
LC_MONETARY Define the format and symbols used in monetary information.
LC_NUMERIC Define the decimal delimiter, grouping, and symbol for nonetary numeric editing.
LC_TIME Define the format and content of data.
LC_MESSAGES Define the format and values of affirmative and negative responses.

# Options

- -c Create permanent output even if warning messages have been issued.

- -C compiler-options Pass the compiler-options to the C compiler (cc). If you specify more than one option, you must enclose all of them in quotes ("*"). This option is starting with the Solaris 8 release. Instead, use the -W cc, option.

- -f charset Specify the path name of a file containing a mapping of character symbols to actual encodings. You must specify this option if you use symbolic names (other than collating symbols). If you do not use the -f option, use the default mapping.

- -i sourcefile Specify the path name of a file containing the source definitions. If you do not use this option, read source definitions from standard input.

- -L linker-options Pass the linker-options to the C compiler (cc) that follows the source file name. If you specify more than one option this option is starting with the Solaris 8 release. Instead, use the -W cc, option.

- -m model Specify whether localedef generates a 64-bit or a 32-bit local object. To generate a 32-bit object, specify model as ip32. To generate a 64-bit local object, specify lp64. The default is -m ip32.

- -W cc, arg Pass arguments to the C compiler separating the preceding with a comma. (You can make a comma part of an argument by immediately preceding it with a backslash character to escape it. The backslash is removed from the resulting argument.)

- -x extensions-file Specify the path name of an extension file where various localedef options are listed. See localedef(5).

If you specify the -c option and warnings occur, permanent output is created. The following conditions issue warning messages:

* Use a symbolic name not found in the charset file for the descriptions of the LC_CTYPE or LC_COLLATE categories (for other categories, this is an error condition).

* If optional keywords not supported by the implementation are present in the source.
