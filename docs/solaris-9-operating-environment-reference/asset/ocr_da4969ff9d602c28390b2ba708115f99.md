# fdformat

# fdformat - Format Diskette or PCMCIA Memory Card

# Synopsis

```
/usr/bin/fdformat [-dDeEfHlMmUqvqx] [-b label] [-B filename] [-t dos]
[-t nec] [devname]
```

# Description

Note — Starting with the 8 release, fdformat has been superseded by rmformat(1), which provides most but not all fdformat functionality.

Use the fdformat command to format the drive to format the diskette. You must format all new, blank diskettes or PCMCIA memory cards before you use them. fdformat formats and verifies the media and indicates whether it encountered any bad sectors. All existing data on the diskette or PCMCIA memory card, if any, is destroyed by formatting. If you specify no device name, fdformat uses the diskette as a default.

By default, fdformat uses the configured capacity of the drive to format the diskette. 3.5-inch, high-density drive uses diskettes with a formatted capacity of 1.44 megabytes. 5.25-inch, high-density drive uses diskettes with a formatted capacity of 1.2 megabytes. In either case, you do not need to specify a density when using a diskette with a lower capacity than that of the drive's. Use the -H option to format high-density disk (1.44-megabyte capacity) in an extra-high-density (ED) drive. Use the -D option to format double-density (or low-density) diskettes (720-kilobyte capacity) in any. To format medium-density diskettes (1.2-megabyte capacity), use the -m option with -t nec (this is the same as using the -m option with -t nec).

Extended density uses double-sided, extended-density (or extra-high) (DS/ED) diskettes. Medium and high densities use the same media: double-sided, high-density (DS/HD) diskettes. Low density uses the media: double-sided, double-density (DS/DD) diskettes.

Note — Substituting one density for diskettes of either higher or lower density generally does not work. Data integrity is assured whenever a diskette is formatted to a capacity matching its density.

You can use the fdformat command to format a PCMCIA memory card with densities from 512-kilobytes to 64-megabytes.

fdformat writes new identification and data fields for each sector on all tracks you specify the -x option. For diskettes, if you specify the -v option, each sector is verified.

After formatting and verifying, fdformat writes an operating-system label on block 0. Use the -t option (same as the -d option) to put an MS-DOS file system on the diskette or PCMCIA memory card after the format is. Use the -t nec option with the -M option (same as the -m option) to put an NEC-DOS file system on a diskette. Otherwise, fdformat writes a SunOS label in block 0.
