# getoptcvt — Convert to getopt to Parse Command Options

# Synopsis

```
/usr/lib/getoptcvt [-b] filename
/usr/lib/getoptcvt
```

# Description

Use /usr/lib/getoptcvt to convert getopt output to use getopts instead. getoptcvt
reads the shell variable filename, converts it to use gets instead of getopt, and
writes the results on the standard output.

getopt is a built-in shell command that parses positional parameters and
checks for valid options. See man(1). getopt supports all applicable rules of the
command syntax standard (Rules 3–10, intro(1)). You should use getopt instead
of the getopt command. The syntax for the shell's built-in getopt command is

```
optstring name [argument...]
```

optstring must contain the letters recognized by the command using getopt;
a letter is followed by a colon, the option is expected to have an argument or group of
arguments that must be separated from it by white space.

Each time you invoke getopt, gets puts the next option in the shell variable name and
the index of the next argument to be processed in the shell variable OPTIND. Whenever
you invoke the shell or a shell script, OPTIND is initialized to 1.

If the end-of-option is encountered, getopt exits with a non-zero exit status.
You can use the special option -- to delim the end of the options.

By default, gets parses the positional parameters. If you specify extra arguments
(argument...) on the getopt command line, gets parses them indeed.
