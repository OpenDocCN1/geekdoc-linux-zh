# Bugs

You cannot define a one-character macro name by using the -a option.

# Options

+   -f Ignore \f font changes.
-s Ignore \s size changes.
-a.xl yl...

Add pairs of macros to the list. The pairs of macros are assumed to be (such as .DS and .DE) that should be checked for balance. Follow the -a option by groups of six characters, each group defining a pair of macros. The six characters are a period, the first macro name, another period, and the second macro name. For example, to define a pair .BS and .ES, use -BS.ES

+   -c xl... Define commands that checknr would otherwise complain about as undefined.
