pushd pushes a directory onto the stack, it exchanges the two elements. You can also use the following arguments for pushd.

popd pops the directory stack and changes to the new top directory. The elements of the stack are numbered from 0, starting at the top. You can use the following arguments for popd.

- + n Discard the n-th entry in the stack.

## Korn Shell

The Korn shell built-in cd command can be either of two forms. In the first form, cd changes the current directory to arg. If arg is the directory is changed to the previous directory. The variable HOME is the default arg. The variable PWD is set to the current directory. The variable PATH defines the search path for the directory containing arg. Separate alternative directory names by a colon (:). The default path is <null> (specifying the current directory). Note that the current directory is specified by a null path, which can appear immediately anywhere in the list. If arg begins with a /, .. or ... then the colon delimiters arg then the search path is not used. Otherwise, each directory in the path is searched for arg.

The second form of cd uses the string new for the string old in the current directory name, PWD, and tries to change to this new directory.

The cd command may not be executed by rsh. Because a new process is created to execute each command, cd is ineffective if it is written as a normal command; therefore, it is recognized as internal to the Korn shell. (See pwd(1), ksh(1), and chdir(2)).

## Operands

directory An absolute or relative path name of the directory that becomes the new working directory. The interpretation of a relative path name by cd depends on the CDPATH environment variable.

## Environment Variables

See environ(5) for descriptions of the following environment variables that affect the execution of cd: LC_TYPE, LC_MESSAGES, and NLPATH.

CDPATH A colon-separated list of path names that refer to directories. If the directory operand does not begin with a slash (/) and the first component is not dot or dot-dot, cd searches for a directory relative to each directory named in the CDPATH variable, in the order listed. The new working directory is set to the first matching directory found. An empty string in place of a directory path represents the current directory. If CDPATH is not set, it is treated as if it were an empty string.

When CDPATH is defined, the cd command for the Korn and Bourne shells displays the absolute path name of the new directory to the standard output. If CDPATH is not set, there is no output.

- * HOME The name of the home directory, used when no directory operand is specified.
- * PWD A path name of the current working directory, set by cd after it has changed to that directory.

## Exit Status

- * 0 The directory was successfully changed.
- * >0 An error occurred.

## Description

Use the cdrw command to create data and audio CDs, cdrw also enables you to extract audio tracks from an audio CD. You can use MMC-compliant CD-R or CD-RW drive with cdrw.

The cdrw command was initially provided starting with the Solaris 8 update 2 (10/00) release on the Software Supplement CD with the Solaris 8 Operating Environment. With the Solaris 9 release, the cdrw command is included with the Solaris 9 release and is available when using the Suncdrw package.
cdrw searches for a CD writer device connected to the system unless you specify a device with the -d option. If cdrw finds one such writer device, it uses that as the default CD writer device for the command.

When more than one CD writer is connected to the system, use the -d option to indicate which device to use. You can specify the device in one of the following

- /dev/rdsk/ctM&nM ctM&nM ctM&nM
- A symbolic name used by volume manager, such as cdrwm or cdrw.

You can use the -l option to display a list of CD writers.

## Creating Data

Typically, you first prepare the media using mkiso(1). When creating data, cdrw uses the session-at-once mode. See the examples on page 2.

## Creating Audio

To create audio CD with the -a option, you can specify single or multiple tracks. Currently approved formats are listed below.

| sun | .au with Red Book data. |
| wav | .wav with Red Book CDDA. |
| cda | .cda with Red Book CDDA. |

## Extracting Audio

You can use cdrw to extract audio data from an audio CD with the -x option. The CD should have tracks in Red Book CDDA form. By default, the output format is based on the file extension. You can specify a sun, wav, or any format with the -T option.

## Copying CDs

You can use cdrw to copy single session CD-ROMs and Red Book audio CDs. For copying a CD, cdrw looks for a specified source device. If you specify no source device with the -c option, the current writing device is assumed to be the source. cdrw extracts the tracks into a temporary file and looks for a blank CD-RW in the current writing device. If no medium is found, you are asked to insert a blank CD in the current writing device. If enough space is not available in the temporary directory, you can specify an alternative directory with the -m option.

## Erasing CD-RWdisc

You have to erase the CD-RWdisc before it can be rewritten. With the -b option, the following flavors of erasing are currently supported.

- session Erase the last session.
- all Erase the entire disc.

If you use the session erasing type, cdrw erases the last session. If only one session is recorded on the CD-RW (for example, a data/audio CD-RW created by this tool), session erasing is useful because it erases only the portion that is recorded, leaving behind a blank disc, which is faster than erasing the entire disc.

Use the all erasing type for a multisession disc, if the last session is not closed or if the disc status is unknown and you want to erase the disc. With this type of erase, cdrw erases the entire disc.

## Checking device-list or media-status

You can display a list of CD writing devices currently present in the system with the -l option. Also, for a particular disc, you can display the blank status and table of contents with the -M option. The -M option prints information about the last session start address and the next writable address. You can use this information, along with the -O option, to create multisession CDs. Please refer to mkis(1) for more information.
