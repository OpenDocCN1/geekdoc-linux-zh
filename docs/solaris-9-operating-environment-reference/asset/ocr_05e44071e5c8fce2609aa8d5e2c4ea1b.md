The ERE anchoring (^ and $) do not appear in the table. With lex expressions, use of these operators is restricted. You can use the ^ operator only at the beginning of an entire regular expression and the $ operator only at the end. The operators apply to the entire regular expression. Thus, for example, the pattern (^abc|def$) is undefined. Instead, you can write it as two separate rules, one with the regular expression ^abc and one with def$, that share a common action via the special |. If you write the pattern ^abc|def$, it would match either abc or def on a line by itself.
