# auto, uupick — Public UNIX-to-UNIX System File Copy

# Synopsis
/usr/bin/uupick [-mp] source-file...destination
/usr/bin/uupick [-s system]

# Description
uuto
sends source-fileto destination uses uucp(C) to send files; it allows the
local system to control the file access. A source-filename is a path name on your
system. Destination has the form:
system[!system]...user

where system is taken from a list of system names that uupick knows about. user is the
name of someone on the specified system.
The files (or subtrees if you specify directories) are sent to PUBDIR on system, where
PUBDIR is a public directory defined in the uucp source. By default, this directory is
/var/spool/receive/user/uucppublic. Specifically, the files are sent to
PUBDIR/receive/user/system-files.

The recipient is notified by mail(1) of the arrival of files.

> Note — To send files that begin with a dot (for instance, .profile), you
include the dot. For example, the following file names are correct:

.profile.prof* ?prof?

The following file names are incorrect:

*prof* ?profile

uupick
uupick accepts or rejects the files transmitted to the user. Specifically, uupick searches
PUBDIR for files destined for the user. For each entry (file or directory) found, the
message is printed on standard output:

from systemname: [file file-name] [dir dirname] ?

+   uupick reads a line from standard input to determine the disposition of the file.
newline Go to next entry.
d Delete the entry.
