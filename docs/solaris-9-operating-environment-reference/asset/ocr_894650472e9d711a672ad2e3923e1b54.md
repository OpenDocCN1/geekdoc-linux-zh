# login

| DISABLETIME | present and greater than zero, specify the number of seconds that login waits after RETRIES failed attempts or the PAM framework returns PAM_ABORT. Another login attempt is permitted provided that RETRIES has not been reached or the PAM framework has not returned PAM_MAXRIES. Default is 4 seconds, Minimum is 0 seconds. Maximum is 5 seconds. New in the Solaris 9 release |

| HZ | Set the HZ environment variable of the shell. |

| PASSREQ | Determine if login requires a password. |

| PATH | Set the initial PATH variable. |

| SLEEPTIME | Removed from the Solaris 9 release. See DISABLETIME. If present, the number of seconds to wait before login failure is printed to the screen and another login attempt is allowed. Default is 4 seconds. Minimum is 0 seconds. Maximum is 5 seconds. |

| SUPATH | Set the initial PATH variable for root. |

| SYSLOG | Determine whether syslog(3C) LOG_AUTH facility should be used to log all log entries at level LOG_NOTICE and multiple failed login attempts at LOG_CRIT. |

| SYSLOG_FAILED_LOGINS | Determine how many login tries are allowed by the system before a failed login message is logged with the syslog(3C) LOG_NOTICE facility. For example, if the variable is set to 0, login logs all failed login attempts. New in the Solaris 8 release. |

| TIMEOUT | Set the number of seconds (between 0 and 900) to wait before abandoning a login session. |

| TIMZONE | Set the TZ environment variable of the shell (see env(5)). |

| ULIMIT | Set the file-size limit for the login. Units are disk blocks. Default is 0 (no limit). |

| UMASK | Set the initial file-creation mode mask. Use umask(1). |
