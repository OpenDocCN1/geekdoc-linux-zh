# vi Search Edit Commands

Use these commands to access your command history.

+   [count]k Fetch previous command. Each time you enter k, access the previous command back in time.

+   [count] - Equivalent to k.

+   [count]j Fetch next command. Each time you enter j, access the next command forward in time.

+   [count]+ Equivalent to j.

+   [count]G Fetch the command number count. The default is the least recent history command.

+   /string Search through history for a previous command containing string. Terminate string with a Return or newline. If you precede string with ^, the matched line begins with string. If string is null, use the previous string.

+   ?string Same as / except search forward.

+   n Search for next match of the last pattern to / ? commands.

+   N Search for next match of the last pattern to / ?, but in reverse direction. Search history for the string entered by the previous / command.

# vi Text Modification Edit Commands

Use these commands to modify the line.

+   a Enter input mode, and enter text after the current character.

+   A Append text to the end of the line. Equivalent to $a.

+   [count]cm Delete current character through the character that motion would move the cursor to, and enter input mode. If motion is c, delete the entire line and enter input mode.

+   C Delete the current character through the end of the line, and enter input mode. Equivalent to c$.

+   [count]s Delete characters, and enter input mode.

+   S Delete entire line, and enter input mode. Equivalent to cc.

+   [count]dm Delete current character through the character that motion would move to. If motion is d, delete the entire line.

+   D Delete the current character through the end of the line. Equivalent to d$
