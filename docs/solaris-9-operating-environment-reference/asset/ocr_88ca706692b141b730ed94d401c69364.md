# egrep

```
file5.doc: The following are numbers 1234567
file7.doc: 1 2 3 4 5 6
castle%
```

The following example searches file1.doc for lines that contain either the strings bill, tom, or any number that is enclosed in :

```
castle% egrep "\((bill)|(tom)|(0-9)\\" file1.doc
(1)
(5)
(bill)
(tom)
castle%"
```

The search does not match the following strings.

```
(123)
(bill123)
```

# Exit Status

+   -0 If any matches are found.
-1 If no matches are found.
-2 For syntax errors or inaccessible files (even if matches were found).
