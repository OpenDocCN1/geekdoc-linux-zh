# login — Sign On to the System

# Synopsis

```
/usr/bin/login [-p] [-d device] [-h hostname [terminal] | -r hostname
[name [environ...]]
```

# Description

Use the login command at the beginning of each terminal session to identify yourself to the system. The login is invoked by the system when a connection is first established and after the previous user has terminated the login shell by issuing the exit command.

If you invoke login as a command, it must replace the initial command interpreter.
To invoke login in this, from the initial shell, type:

```
exec login
```

> C shell and Korn shell have their own built-in login commands. See ksh(1) and csh(1) for descriptions of login built-ins and usage.

> login asks for your user name if it is not supplied as an argument and for your password if appropriate. Where possible, echoing is turned off while you type your password so that it does not appear on the written record of the session.

> If you make any mistake in the login procedure, the following message is displayed\and a new login prompt is displayed.

Login incorrect

If you make incorrect login attempts, all five may be logged in
/var/admlogin if it exists. The TTY line is dropped.
If password aging is turned on and the password has aged (see passwd(1) for more
information), you are forced to change the password. In this case,
/etc/nswitch.conf file is consulted to determine password repositories
switch.conf(4). The password update configurations are limited to the
following five cases.

+   - passwd: files
- passwd: nis
- passwd: nisplus
- passwd: compat (==> files nis)
- passwd: compat (==> files nis) passwd_compat: nisplus

Failure to comply with these configurations prevents you from logging in to the
system because passwd(1) fails. If you do not complete the login successfully within a
period of time, it is likely that you will be silently disconnected.

After a successful login, accounting files are updated. Device owner, group, and
permissions are set according to the contents of the /etc/logindexperm file, and
time you logged in is printed (see logindexperm(4)).

The user ID, group ID, supplementary group list, and working directory are
initialized, and the command interpreter specified in your file is started. *
