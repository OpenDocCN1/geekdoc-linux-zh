# as

+   -b
Generate extra symbol table information for the Sun Source Browser.

+   -Dname
When the -P option is in effect, pass these options to the cpp(1)
preprocessor without interpretation by the as command; otherwise,
ignore them.

+   -Ipath
When the -P option is in effect, pass this option to the cpp(1) C
preprocessor without interpretation by the as command; otherwise,
ignore it.

+   -K PIC
Generate position-independent code.

+   -L
Save all symbols in the ELF symbol table, including temporary labels
that are normally discarded to save space.

+   -m
Run the m(1) max processor on the input to the assembler.
-n
Suppress all warnings while assembling.

+   -o output
Put the output of the assembly in outfile. By default, format the output
file name by removing the .s suffix, if there is one, from the input file
name and appending an .o suffix.

+   -P
Run cpp(1), the C preprocessor, on the files being assembled.
preprocessor is run separately on each input file, not on
concatenation. Pass the preprocessor output to the assembler.

+   Q y | n
If you specify the n option, produce the assembler version information
in the comment section of the object object file. If you specify the y
option, suppress the information.

+   -s
Place all st in the .stabs section. By default, put st in
stabs.ex sections, which are stripped out by the static linker, ld(1)
during final execution. When you use the -s option, st remain in the
final executable because .stabs sections are not stripped by the static
linker.

+   -S [ a | b | c | 1 | A | B | C | L]
Produce a disassembly of the emitted code to the standard output.
Adding each of the following characters to the -s option produces:

+   a\ Disassemble with address.
b\ Disassemble with .bof.
c\ Disassemble with comments.
1\ Disassemble with line numbers.

+   -T
Capital letters turn the switch off for the corresponding option.
Interpret symbol names in 4.x assembly files as 5.x symbol names. This
option is for 4.x assembly files to be assembled on 5.x systems.

+   -Uname
When the -P option is in effect, pass this option to the cpp(1)
preprocessor without interpretation by the as command; otherwise,
ignore it.
