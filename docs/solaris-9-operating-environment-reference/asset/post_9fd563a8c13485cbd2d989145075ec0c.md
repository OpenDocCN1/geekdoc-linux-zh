The following notation defines a key field that begins at field-start and ends at field-end-inclusive, unless field-start falls beyond the end of the line or field-end in which case the key field is empty.

```
-k field-start[type] [,field-end[type]]
```

A missing field-end means the last character of the line.

A field comprises a maximal sequence of nonseparating characters, and in the absence of -t, any preceding separator.

The field-start portion of the keydef option has the form:
field-number{.first-character}

Fields and characters within fields are numbered with 1. field-number and first-character, interpreted as positive integers, specify the first character to be used as part of the sort key. If you omit .first-character; the default is the first character of the field.

The field-end-portion of the keydef option has the form
field-start{.last-character}

The field-number as described above field-start, last-character; is interpreted as a nonnegative decimal integer and specifies the last character to be used as part of the sort key. If last-character evaluates to 0 or you omit .last-character; the default is the last character of the field specified by field-number.

If the -o or b type modifier is in effect, characters within a field counted from the first nonblank character in the field. (This applies separately to first-character and last-character.)

The following syntax is obsolete:
+pos1[-pos2]

It provides functionality equivalent to the -k keydef.

pos and pos2 have the form m optionally followed by one or more of the n+1 character in the m-th field. A starting position specified by +m.n is interpreted to mean the n+1st character of the m-th field. If the b option is in effect, n is counted from the first nonblank character in the m-th field; +m.0b refers to the first nonblank character in the m-th field.

A last position specified by -m.n is interpreted to mean the n-th character (including separators) as the last character of the m-th field. A -m means 0, indicating the last character of the m-th field. If the b option is in effect, n is counted from the last blank blank in the m-1st field; -m.lb refers to the first nonblank in the m-1st field.
