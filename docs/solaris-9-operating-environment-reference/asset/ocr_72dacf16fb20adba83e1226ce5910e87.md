# Options

You can specify the following options in any order, but they all must appear before the first name.

+   -a Send ASCII approximation of formatted output to standard output.

+   -f Do not print a trailer after the final page of output or relinquish the postprocessor control of the device.

+   -Fdir Search directory for font width or terminal tables instead of searching the system default directory.

+   -i Read standard input after all input files are exhausted.

+   -mname Prepend the macro file /usr/share/lib/tmac/name to the input file names. Note that most references to macro packages include the leading part of the name. The man(5) macro resides in /usr/share/lib/tmac/. You can change the macro directory by setting the TROFFACS variable to a specific path. Be certain to include the trailer / at the end of the path.

+   -nN Number the first generated page N
-olist Print pages whose page numbers appear in the comma-separated list of numbers and ranges. A range N-M means N through M an initial -N means from the beginning to page N and a final N- means to the end.

+   -q Quiet mode in roff; ignored in troff.
-raN Set a register (a one-character names only) to N

+   -sN Stop the typesetter a trailer every N pages. On some devices, troff produces a trailer so you can change cassettes; resume by pressing the typesetter's start button.
