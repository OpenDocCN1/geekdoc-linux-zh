# sag

1. As root, type xterm -t and press Return to run xterm as a Tektron terminal.
2. In the xterm window, type sag -T tek options and press Return.

# Options

The following options are passed through to sar.

+   - e time Choose data up to time. Default is 18:00.
- f file Use file as the data source for sar. Default is the current daily data file /usr/adm/sa/sadd.
- i sec Choose data at intervals as close as possible to sec seconds.
- s time Choose data later time in the form [hh:mm]. Default is 08:00.

Other options:

+   - T term Produce output suitable for terminal term See tplot(1) for known terminals. Default for term seis.
- x spec Specify the x axis with spec in the form: name(op name)...[lo hi]

name is a string that matches a column header in the sar report with an optional device name in square brackets, for example, r+w/s[disk-1], * or surrounded by blank spaces. You can specify up to five names. Parentheses are not recognized. To comma, + and - have precedence over * and /. Evaluation is left-to-right. Thus, A / B * 100 is evaluated as (A/B)*100, and A + B / C - Dis is (A+B)/(C-D). D and hi are optional scale limits. If unspecified, they are deduced from the data.

Enclose in double quotes ("") if it includes space.

+   - y spec Specify the y axis with spec the same form for -x. If unspecified, you can specify up to five spec arguments separated by a semicolon (;). The default is:
- y "usr 0 100; %usr + %sys 0 100; %usr + %sys + %wio 0 100

# Examples

The following example shows today's CPU use.

```
castle sag
The following example shows activity of all disk drives over 15 minutes.
$ TS -date +%H:%M
$ sar -o /tmp/tempfile 60 15
```
