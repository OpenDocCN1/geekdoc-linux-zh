# Operands

A group name from the group database or a numeric group ID. Either specifies a group ID to be given to file named by one of the file operands. If a numeric group operand exists in the group database as a group name, the group ID number associated with that group name is used as the group ID.

group

file

A path name of a file whose group ID is to be modified.

# Usage

large(5) for the description of the behavior of chgrp when encountering files greater than or equal to 2 Gbytes (**31 bytes).

# Examples

In the following example, the owner of the file, changes the group for the file named try to other.

```
chgrp% chgrp other try
chgrp% ls -1 try
-rw-rw-rw- 1 winsor other 18 Aug 27 17:45 try
chgrp%
```

In the following example, user ray tries to change the group for the file named try to staff but does not own the file. An error message is displayed.

```
chgrp% whoami
ray
chgrp% chgrp staff try
chgrp: try: Not owner
chgrp%
```

In the following example, superuser changes the group for the file named try back to staff.

```
chgrp% su
Password:
chgrp% chgrp staff try
chgrp% ls -1 try
-rw-rw-rw- 1 winsor staff 18 Aug 27 17:45 try
chgrp%
```

# Exit Status

0

The command executed successfully, and all requested changes were made.

>0

An error occurred.
