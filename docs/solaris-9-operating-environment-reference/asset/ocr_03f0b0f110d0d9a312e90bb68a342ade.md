The following example adds 1 to the shell variable a.
a=0
a=\`expr $a + 1`

The following example emulates basename(1). It returns the last segment of the path name S. For $a equal to either /usr/abc/file or just file, the example returns file.
Watch out for / alone as an argument: expr takes it as the division operator.

```
a=\`/etc/dfs/dstab`
expr $a : '.*\(.*)\\'' | $a
```

The example returns dstab.
The following example is a better version of the previous example. The addition of the // characters eliminates any ambiguity about the division operator and simplifies the whole expression.

```
a=\`/etc/dfs/dstab`
expr $/a : '.*\(.*)\''
```

# /usr/bin/expr

The following example returns the number of bytes in $VAR.
VAR=bill
expr "\$VAR" : '.\*'

The example returns 4.

# /usr/xpg4/bin/expr

The following example returns the number of characters in $VAR.
VAR=bill
expr "\$VAR" : '.\*'

# Environment Variables

See environ(5) for descriptions of the environment variables that affect the execution of expr: LC_COLLATE, LC_CTYPE, LC_MESSAGES, and NLPATH.

# Exit Status

As a side effect of expression evaluation, expr returns the following exit values:

+   0 The expression is neither null 0.
1 The expression is either null or 0.

+   2 Invalid expression.
2 An error occurred.
