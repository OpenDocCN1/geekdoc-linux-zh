# ypppasswd — Change Your Network Password in the NIS Database

# Synopsis

```
/usr/bin/ypppasswd [username]
```

# Description

> Note — The use of ypppasswd is discouraged, as it is now only a link to the passwd(1) command, which you should use instead. Use passwd(1) with the -r nis option to achieve the same results, and be consistent across all available services.

ypppasswd changes the network password associated with the username in the Network Information Service (NIS) database. If the user has done a keylogin(1) and a publickey/secretkey pair exists for the user in the NIS publickey.mapname passwd also reencrypts the secret key with the new password. The NIS password may be different from your local one. Use passwd(1) to change the password information on the local machine, and nippasswd(1) to change the password information stored in Network Information Service, Version 3 (NIS+).

ypppasswd prompts for the old NIS password and then the new one. You must type the old password correctly for the change to take effect. You must type the new password twice for verification.

New passwords must be at least four characters long if they use a sufficiently rich alphabet, and at least six characters long if mostly. These rules are relaxed if you are inconsistent enough. Only the owner of the user name or the superuser can change a password: supper on the root master is not prompted for the old password and does not need to follow passwd construction requirements.

The NIS daemon, rpc.ypppasswd, must be running on your NIS server for the new password to take effect.
