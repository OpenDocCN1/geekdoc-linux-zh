# priocntl 1117

The valid class-specific options for setting interactive parameters:

+   -m iauprilim

Set the user priority limit of the specified process(es) to iauprilim

+   -p iaupri

Set the user priority limit of the specified process(es) to iaupri

The valid class-specific options for setting fair-share parameters—new in the Solaris 9 release—are shown below.!

+   -m fssuprilim

Set the user priority limit of the specified process(es) to fssuprilim

+   -p fssupri

Set the user priority limit of the specified process(es) to fssupri

The valid class-specific options for setting fixed-priority parameters—new in the Solaris 9 release—are shown below.!

+   -m fxuprilim

Set the user priority limit of the specified process(es) to fxuprilim

+   -p fxupri

Set the user priority limit of the specified process(es) to fxupri

+   -t tqntm [-r res]

Set the quantum of the specified process(es) to tqntm You can optionally specify a resolution.

# Examples

The following real-time class example sets the class of any non-real-time processes selected by itype and idist to real-time and sets their real-time priority to the default value of 0.

```
castle% priocntl -s -c RT -t 1 -r 10 -i itype idist
```

The real-time priorities of any processes currently in the real-time class are unaffected. The quantum of all the specified processes are set to 1/10 second.

The following example executes command in the real-time class with a real-time priority of 15 and a quantum of 20 milliseconds.

```
castle% priocntl -e -c RT -p 15 -t 20 command
```

The following example executes a command in real time with a real-time priority of 11 and a quantum of 250 milliseconds specifies the real-time signal as SIGXCPU.!

```
mypoke% priocntl -e -c RT -p 11 -t 250 -qa XCPU command
```

The following timesaring class example sets the class of any non-timesaring processes selected by itype and idist to timesaring and sets both their priority limit and user priority to 0. Processes already in the timesaring class are unaffected.

```
castle% priocntl -s -c TS -i itype idist
```
