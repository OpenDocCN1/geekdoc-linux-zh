# Options

If you do not use the -c, -k, or -s options, the SHELL environment variable determines which shell is used.

+   -c Use C shell, csh(1), to execute the at-job.

+   -k Use Korn shell, ksh(1), to execute the at-job.

+   -s Use Bourne shell, sh(1), to execute the at-job.

+   -f file Specify the path of a file to be used as the source of the at-job, instead of standard input.

+   -1 Report all jobs scheduled for the invoking user if you specify no at-job-operands. If you specify at-job-ids, report information only for these jobs.

+   -m Send mail to the invoking user after the at-job has run, announcing its completion. Mail standard output and standard error produced by the at-job to the user unless redirected. Send mail even if the job produces output. If you do not use -m, the job's output and standard error are mailed to the user unless they are redirected; if there is no output to, the user is not notified of the job's completion.

+   -p project Starting with the Solaris 8 release, specify under which project the at batch job is run. When with the -l option, limit the search to that particular project. Values for project are interpreted as a first project name and as a possible project ID if numeric. By default, the user's current project is used.

+   -q queuename Specify the queue to schedule a job for submission. When with the -l option, limit the search to that particular queue. Values for queuename are limited to the lowercase letters a z. By default, at-jobs are scheduled in queue a. In contrast, queue b is reserved for batch jobs. Because queue c is reserved for cron jobs, you cannot use it with the -q option.

+   -r at-job-id Remove the jobs with the time specified at-job-operands that were previously scheduled by the at command.

+   -t time Submit the job to be run at the time specified by the time option argument, which has the decimal [[CC] YYYY MMDDHHmm[.SS]], where each two-digit represents the following:

+   MM The month of the year [01-12].

+   DD The day of the month [01-31].

+   hh The hour of the day [00-23].

+   mm The minute of the hour [00-59].

+   CC The first two digits of the year.
