# from — Display the Sender and Date of Newly Arrived Messages

Synopsis
/usr/ucb/from [-s sender] [username]

Description
from prints out mail header lines in your mailbox file to show who your mail is.
If you specify username, username's mailbox is examined instead of your own.

Options
-s sender Display headers only for mail sent by sender.

Examples
The following example displays the header lines for the current user.
castle@from
From <IMAP4.psudo.sims> Fri Aug 28 12:30:14 1998
From winsor Fri Aug 28 12:15:01 1998
From winsor Fri Aug 28 12:30:01 1998
From winsor Fri Aug 28 12:30:02 1998
From winsor Fri Aug 28 12:55:01 1998
From winsor Fri Aug 28 12:56:53 1998
From winsor Fri Aug 28 13:04:41 1998
From winsor Fri Aug 28 13:04:53 1998
From winsor Fri Aug 28 13:05:37 1998
From winsor Fri Aug 28 13:06:24 1998
From lp Tue Sep 29 13:11:29 1998
From lp Thu Oct 1 10:38:46 1998
castle@

In the following example, someone tries to use the from command to display the header lines for a different user.
castle@ray
Can't open /var/mail/ray
castle@

In the following example, superuser examines the header lines for user ray.
castle@su
Password:
# /usr/ucb/from from ray
From winsor@castle Wed Nov 12 16:37:58 1997
