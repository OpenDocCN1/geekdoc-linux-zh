# genmsg 443

The following command PRE generates messages for testing.

With the following input,

```
castle@ cat example.c
#include <nl_types.h>

#define MSG1   "message1"
#define MSG2   "message2"
#define MSG3   "message3"
```

```
#define MSG(n) catgets(catd, 1, n, MSG ## n)
```

the following command parses the MSG macros and writes the extracted messages in example.msg.

```
castle@ genmsg -p "cc -E" -o example.msg example.c
```

Suppose that you have the following header, source, and project files:

```
castle@ ../inc/msg.h
#define WARN_SET  1
#define ERR_SET    2
```

```
example % proj
10
10
```
