# mdb 857

-y

Send explicit terminal initialization sequences for TTY mode. Some terminals, such as cmdtool(1), require explicit initialization sequences to switch into a TTY mode. Without this initialization sequence, terminal features as standpoint mode may not be available to mdb.

# Operands

object

Specify an ELF object file to examine. With mdb you can examine and edit ELF formats (ET_EXEC), ELF dynamic library files (ET_DYN), ELF relocatable executables (ET_REL), and operating system unix.x symbol table files.

core

Specify an ELF corefile (ET_CORE) or an operating system crash dump vmcore.x. If you provide an ELF core operand without a corresponding objectfile, mdb tries to infer the name of the executable file produced by the core with different algorithms. If mdb finds no executable, it executes but some symbol information may be unavailable.

suffix

Specify the numerical suffix representing a pair of operating system crash dump files. For example, if the suffix is 3, mdb infers that it should examine the files unix.3 and vmcore.3. The string of digits is not interpreted as a suffix if an actual file of the same name is present in the current directory.

# Exit Status

0

Debugger completed execution successfully.

1

A fatal error occurred.

2

Invalid command-line options were specified.

# Environment Variables

HISTSIZE

Determine the maximum length of the command history list. If this variable is not present, the default length is 128.

HOME

Determine the path name of the user's home directory, where a .mdbrc file can reside. If this variable is not present, no .mdbrc processing is done.

SHELL

Determine the path name of the shell used to process shell escapes requested by the ! metacharacter. If this variable is not present, /bin/sh is used.

# Files

$HOME/.mdbrc

The mdb initialization file. The .mdbrc file, if present, is processed after the debug target has been initialized file before module autoloading is performed or before any commands have been read from standard.
