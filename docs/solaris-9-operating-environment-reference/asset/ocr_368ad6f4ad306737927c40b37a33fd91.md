# nischown — Change the Owner of an NIS+ Object

# Synopsis

/usr/bin/nischown [-AfLP] owner name...

# Description

Use the nischown command to change the owner of the NIS+ objects or entries specified by owner name: Specify entries, using indexed names (see nismatch(1)). If owner is not a fully qualified NIS+ principal (see nisaddcred(1M)), the default domain (nisdefaults(1)) is appended to it.
The only restriction on changing an object's owner is that you must have modify permissions for the object.

> Note — If you are the current owner of an object and you change ownership, you may not be able to regain ownership unless you have modify access to the new object.

The NIS+ server checks the validity of the name before making the modification. The nischown command fails if the master NIS+ server is not running.

# Options

+   -A Modify all entries in all tables in the concatenation path that match the search criteria specified in name. This option implies the -P option.
-f Force the operation, and fail silently if it does not succeed.
