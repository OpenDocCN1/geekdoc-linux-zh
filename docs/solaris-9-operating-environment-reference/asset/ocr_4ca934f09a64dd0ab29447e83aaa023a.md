When you test a file you own (the -r,-w,or -x tests),but the permission does not have the owner bit set, a non-zero (false) exit status is returned even though the file may have the group or other bit set for that permission.

The = and ! primaries have a higher precedence than the unary primaries. The = and ! primaries always except arguments; therefore, you cannot use = and ! as an argument to unary primaries.

You can use the following primaries to construct condition.

+   - a file true if exists.
- b file true if exists and is a block special file.
- c file true if exists and is a character special file.
- d file true if exists and is a directory.
- e file true if exists.
- f file true if exists and is a regular file.

Alternatively, if /usr/bin/sh users specify /usr/ucb before /usr/bin in your PATH environment variable, then test returns true if file exists and is (not-a-directory). The csh test and [built-ins always use this behavior.

The not-directory alternative is a transition aid for BSD applications and may not be supported in future releases.

+   - g file true if exists and its set-group-ID flag is set.
- G file true if exists and its group matches the effective group ID of this process. (Not available in sh).
- h true if exists and is a symbolic link. New in the Solaris 9 release.
- k file true if exists and its sticky bit is set.
- L file true if exists and is a symbolic link.
- n string true if the length of string is non-zero.
- o option true if named option is on. (Not available in csh or sh).
- O file true if exists and is owned by the effective user ID of this process. (Not available in sh).

+   - p file true if is a named pipe (FIFO).
- r file true if exists and is readable.
- s file true if exists and has a size greater than 0.
- S file true if exists and is a socket. (Not available in sh).
- t file-descriptor

true if the file descriptor number is file-descriptor open and is associated with a terminal. If you do not specify file-descriptor, the default value is 1.

+   - u file true if exists and its set-user-ID flag is set.
