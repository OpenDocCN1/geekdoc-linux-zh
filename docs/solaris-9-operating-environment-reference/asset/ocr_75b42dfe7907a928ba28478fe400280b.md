# nawk 901

```
[statement] ... \
expression # commonly, variable = expression\
print [expression-list] [<expression]\nprintf format [, expression-list] [<expression]\nnext # skip remaining patterns on this input line\
exit [expr] # skip the rest of the input; exit status is expr\
return [expr]
```

You can replace any statement with a statement list enclosed in braces. Terminate statements with newline characters or semicolons. Statements are executed sequentially in the order in which they appear.
The next statement abandons all further processing of the current input record. The behavior is undefined if a next statement appears or is invoked in a BEGIN or END action.
The exit statement invokes all END actions in the order in which they occur in the program source and terminates the program without reading input. An exit statement END terminates the program without further execution END actions. If an expression is specified in an exit statement, its numeric value is the exit status of nawk unless subsequent errors are encountered or a subsequent statement with an expression is executed.

# Output Statements

Both print and printf write to standard output by default. The output is written to the location specified by output redirection if one is supplied, as follows:

+   > expression
>> expression
| expression

In all cases, the expression is evaluated to produce a string that is used as a full path to name into (for or >>) as a command to be executed (|). The first two forms, if the file name is not currently open, it is opened. If necessary, it is created. With the first form, the file is truncated. The output is appended to the file. As long as the file remains open, subsequent calls in expression evaluates to the same value simply append to the file. The file remains open until the close function is called with an expression that evaluates to the same value.
The third form writes output onto a stream piped to the input of a command. The stream is created if no stream is currently open, with the value of expression as the command name. The stream is created with one created by a call to the popen(S), with the value of expression as the command argument and a value of w as the mode argument. As the stream remains open, subsequent calls, in which expression evaluates to the same value, write output to the existing stream. The stream remains open until the close function is called with an expression that evaluates to the same value. At that time, the stream is closed by a call to | close.
The output statements take a comma-separated list of expressions referred to in the grammar by the numerical symbols list_print, print_expr_list, or print_expr_opt. This list is referred to here as the expression list, and each member is referred to as an expression argument.
The print statement writes each expression argument separated by the current output field separator (see variable ORS). All expression arguments are taken as strings, converted if necessary; with the exception that the print format in printf is used instead of conv. An expression list stands for the whole input record (50).
