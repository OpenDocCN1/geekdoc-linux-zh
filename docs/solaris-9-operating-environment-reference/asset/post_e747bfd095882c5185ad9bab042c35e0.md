
# Examples

The following example extracts all items in the archive letters.zip into the current directory and subdirectories below it, creating any subdirectories as necessary.

```
castle@ unzip letters
Archive: letters.zip
inflating: letters.rtf
castle@
```

The following example extracts all items in letters.zip into the current directory.

```
castle@ unzip -j letters
Archive: letters.zip
inflating: letters.rtf
castle@
```

The following example tests letters.zip, printing a summary message indicating whether the archive is OK.

```
castle@ unzip -tq letters
No errors detected in compressed data of letters.zip.
castle@
```

The following example tests all zip files in the current directory, printing only the summaries.

```
castle@ unzip -tq *.zip
No errors detected in compressed data of letters.zip.
castle@
```

> Note — The backslash before the asterisk is required only if the shell expands wildcards, as in UNIX. You can use double quotes.

# unzip

The following example extracts the binary file paper1.dvi to standard output and pipes to a printing program.

```
castle$ unzip -p articles paper1.dvi | lp
request id is sechild-3 (standard input)
caste$
```

The following example extracts all FORTRAN and C source files-*.f, *.c, *.h, and Makefile-into the /tmp directory.

```
castle$ unzip source.zip "*.fch" Makefile -d /tmp
```

Note — The double quotes are needed only in UNIX and only if globbing turned on.

The following example extracts all FORTRAN and C source files, regardless of case (that is, both *.c and *.C, and any makefile, Makefile, Makefile, or similar capitalization form).

```
castle$ unzip -C source.zip "*.fch" make -d /tmp
```

The following example extracts all FORTRAN and C source files, regardless of case (that is, both *.c and *.C, and any makefile, Makefile, Makefile, or similar form), converts any uppercase MS-DOS or VMS names to lower case, and converts the line ends of all the files to the local standard (without respect to any files that might be marked binary).

```
castle$ unzip -aaCl source.zip "*.fch" make -d /tmp
```

The following example extracts only newer versions of the files already in the current directory, without querying.

```
castle$ unzip -fo sources
```

> Note — Be careful of unzipping in one zone a file that was created in another time. ZIP archives other than those created by Zip 2.1 or later contain no time zone information, and a newer file from an Eastern time zone may be, fact, older.

The following example extracts newer versions of the files in the current directory and creates any files not already there (same caveat as the previous example).

```
castle$ unzip -uo sources
```

In the following examples, assume that UNZIP or UNZIP_OPTS is set to -q. The following example does a single zip listing.

```
castle$ setenv -qq
castle$ unzip -1 letters.zip
2003 02-18-99 08:44 letters.rtf
caste$
```

The following example does a double quiet listing.

```
castle$ setenv UNZIP -qq
castle$ unzip -ql letters.zip
2003 02-18-99 08:44 letters.rtf
castle%
```

> Note — You generally don't need to add the .zip suffix.

Use any of the following three commands to do a standard listing. The extra dashes ignored.

```
castle% unzip -ql file.zip
castle% unzip -lq file.zip
castle% unzip -l-q file.zip
```

To unzip more than one archive file with the asterisk metacharacter, you must escape it preceding it with a backslash. The following example unzips three archives that start with the characters 085.

```
castle% unzip 085*
Archive: 085XDOCS.ZIP
inflating: 08X001.DOC
inflating: 08X002.DOC
inflating: 08X003-1.DOC
inflating: 08X042.DOC
inflating: 08X008.DOC
inflating: 08X009.RTF
```

```
Archive: 085FILE.ZIP
inflating: 085X05.DOC
```

```
Archive: 085XINTR.ZIP
inflating: 085X06.DOC
inflating: 085X007.RTF
```

3 archives were successfully processed.
castle%

# Tips

It is worth getting in the habit of testing your archives. To test them, you may find it useful to define an alias as:

```bash
alias tt unzip -t
```
