# ar — Maintain Portable Archive or Library

# Description

The command maintains groups of files combined into a single archive file. Its main use is to create and update library files; however, you can use it for any similar purpose. The magic string and the header used by ar consist of printable ASCII characters. If an archive is composed of printable files, the entire archive is printable.

When creates an archive, it creates headers in a format that is portable across all machines. The archive format and structure are described in detail in art(4).
