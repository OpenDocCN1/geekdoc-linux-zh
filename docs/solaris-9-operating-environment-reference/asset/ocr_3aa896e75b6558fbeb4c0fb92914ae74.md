# 1258

# setfacl — Modify the Access Control List (ACL) for a File or Directory

# Synopsis

```
/usr/bin/setfacl [-r] -s acl-entries file...
/usr/bin/setfacl [-r] -md acl-entries file...
/usr/bin/setfacl [-r] -f acl-file file...
```

# Description

Access Control Lists (ACLs) are extensions to standard UNIX file permissions. The information is stored and associated with each file individually. Use the setfacl tool to set, add, modify, and delete ACL entries. For each file specified, setfacl replaces its entire ACL entry, including the default ACL on a directory, or it adds, modifies, or deletes one or more ACL entries.

Setting an ACL on a file also modifies the file owner permissions. If you do not specify a mask entry, the group modifies the file owner permissions. If you specify a mask entry, the group permission bits of the file are modified, based on the intersection (bitwise AND) of the group and mask entries. The entry modifies the other permissions.

If you use the chmod command to change group permissions on a file with ACL entries, both the group owner permissions and the ACL mask are changed to the new permissions. Be aware that the ACL mask can change the effective permissions for additional users and groups who have ACL entries on the file.

A directory can contain default ACL entries. If you create a file in a directory that contains default ACL entries, the newly created file has permissions generated according to umask(), the default ACL entries, and the permissions requested at creation time. If a default ACL is specified for a specific user (or users), the file has a regular ACL; otherwise, the only mode bits are initialized to the intersection described above. The default ACL should be thought of as the maximum discretionary access permissions that can be granted.

# Syntax for acl-entries

For the -m and -s options, acl-entries is one or more comma-separated ACL entries. An ACL entry consists of the following fields separated by columns.

| entry-type | Type of ACL entry on which to set file permissions. For example, entry-type can be user (the owner of a file) or mask (the ACL mask) |
| uid | gid | User name or user identification number. Group name or group identification number. |
| perms | The permissions that are set on an entry-type. You can indicate perms by the symbolic characters rwx or a number (the same permissions used with chmod(1)) |

The following list describes the valid ACL entries. (You can specify default entries for directories.)

```
u(server):perms
```
