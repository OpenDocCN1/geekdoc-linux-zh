# Options

If you specify neither -d nor -r option, both are enabled.

+   -C Demangle C++ symbol names. New in the Solaris 8 release.

+   -d Print version definition information.

+   - When used with the -s option, any symbols that have been reduced from global binding of versioning. By convention, these symbol entries are located in .symtab section and fall between the FILE symbol representing the output file and the FILE symbol representing the first input file used to generate the output file.

These reduced symbol entries are assigned the fabricated version definition _REDUCED. No symbols are printed if the file has been stripped (see strip(1)) or if the symbol entry cannot be determined.

+   -n Normalize version definition information. By default, display all version definitions within the object. However, version definitions can inherit other version definitions and, under normalization, only the head of each inheritance list is displayed.

+   -Name Print only the information for the given version definition name and any of its inherited version definitions (when used with the -d option) or for the given dependency name (when used with the -r option).

+   -O Create one-line version definition output. By default, file, version definitions, and any symbol output are indented to ease human inspection. This option prefixes each output line with the file and version name and may be more useful for analysis with automated tools.

+   -r Print version dependency (requirements) information.

+   -s Print the symbols associated with each version definition. Accompany any data symbols with the size, in bytes, of the data item.

+   -v Show weak version definitions and any version definition inheritance. When used with the -N and -d options, also show the inheritance of the base version definition. When used with the -s option, show the version symbol definition.

# Operands

+   file The ELF file about internal version information is displayed.
