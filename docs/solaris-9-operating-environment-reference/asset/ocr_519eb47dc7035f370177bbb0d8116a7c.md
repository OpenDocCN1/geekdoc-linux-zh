# ldapdelete — ldap Delete Entry Tool

# Synopsis

```
/usr/bin/ldapdelete [-o] [-v] [-c] [-d debuglevel] [-f file]
[-D binddn] [-w passwd] [-h ldaphost] [-M authentication]
-l ldapport] [dn...]
```

# Description

ldapdelete opens a connection to an LDAP server and deletes one or more
entries. If you specify one or more arguments, entries with those distinguished names
are deleted. If you specify no dn arguments, a list of distinguished names (DNs) is read
from file, if you specify the -f option, or from standard input.
