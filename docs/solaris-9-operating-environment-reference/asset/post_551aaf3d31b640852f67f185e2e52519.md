Each shaping data definition consists of one or more of the shaping sequence definitions. Each shaping sequence definition is a representation of a series of state transitions triggered by an input character and the current state at each transition. The syntax of the shaping sequence definition is shown below.

```
shaping_sequence : initial_state + input ->
next_state_list
;
initial_state : ()
;
input : HEXADECIMAL
;
next_state_list : next_state
| next_state_list + input ->
next_state
| ( next_state_list + input )
repeat+
| ( next_state_list + input )
repeat*
;
next_state : ( out_buffer , in2out , out2in , property list)
;
out_buffer : [ out_char_list ]
;
out_char_list : HEXADECIMAL
| ( HEXADECIMAL ) repeat+
| out_char_list ; HEXADECIMAL
```

# A simple shaping sequence.

```
( + 0x21 ->
 ([0x0021], [0], [0:0], [0x80]) + 0x22 ->
 ([0x0021;0x0022], [0,1], [0:0;1;1], [0x80;0x80]) +
0xc2a0 ->
 ([0x0021;0x0022;0x0e30], [0;1;2], [0;0;1;1;2;2],
[0x80;0x80;0x80])
```

# A repeating shaping sequence.

```
( + 0x21 ->
 {
 ([0x0021], [0], [0:0], [0x80]) + 0x22 ->
 ([0x0021;0x0022], [0,1], [0;0;1;1], [0x80;0x80]) +
0xc2a2
} repeat+
```

The first example shows a shaping sequence, when 0x21, 0x22, and 0xc2a0 are the input buffer, the sequence is converted into an output buffer containing 0x0021, 0x0022, and 0x0e30; an input to the output buffer containing 0, 1, and 2; an output to the input buffer containing 0, 0, 1, 1, and 2; and a property buffer containing 0x80, 0x80, and 0x80.

The second example shows a repeating shaping sequence, where the first input code element is 0x21, the second and third input code elements are 0x22 and 0xc2a2.

# genmsg - Generate a Message File by Extracting Messages from Source Files

# Synopsis

```
/usr/bin/genmsg [-abdfn] [-c message-tag] [-g project-file]
[-l project-file] [-m prefix] [-M suffix] [-o message-file]
[-p preprocessor] [-s set-tags] file...
```

# Description

genmsg extracts message strings with catcats(3) from source files and generates them in a format suitable for input(1).

# Invocation

genmsg reads one or more input files and, by default, generates a message source file whose name is composed of the first input file with a .msg suffix. If you specify the -o option, genmsg uses the argument for its output file.

# Command

# Output File

```
genmsg prog.c                      prog.c.msg
genmsg main.c util.c      main.c.msg
genmsg -o prog.msg main.c  util.c
```

genmsg also enables you to invoke a preprocessor to solve the dependencies of macros and define terms for catcats(3) calls.

# Message Autonumbering

genmsg replaces message numbers with the calculated numbers based on the project file if message numbers are -1. It generates copies of the input files with the new message numbers and a copy of the project file with the new message numbers.

A project file is a database that stores a list of set numbers with their maximum numbers. Each line in project file is composed of a set number and its maximum number:

```
Set_number Maximum_message_number
```

In a project file, a line beginning with a sign (#) or ASCII space is considered a comment and ignored. genmsg has the reverse option to replace all message numbers with -1.

# Comment Extraction

genmsg enables you to comment messages and sets to inform the translator to translate the messages. It extracts the comment, which is surrounded by comment indicators and has the specified tag inside the comment, with a dollar ($) prefix in the output file, and writes it with an asterisk (*) genmsg supports C and C++ comment indicators, /*, // and it.

# Testing

genmsg generates two kinds of messages for testing.

- Prefixed messages enable you to check that your program is retrieving the messages from the message catalog.
- Long messages enable you to check the appearance of your program's initial size and position.

# Notes

genmsg does not handle pointers or variables in catcats(3) call. For example:

```
const int set_num = 1;
extern int msg_num(const char *);
const char *msg = "Hello";
```

```
catcats(3, set_num, msg_num(msg), msg);
```

When the message autonumber is turned on in catcats(3) line, genmsg replaces all of -1s in the line with a calculated number. If there are multiple -1s in the line, for example, given the input:

```
#define genmsg(id, msg) catcats(3, 1, (id), (msg));
```

# Options

- -a Append the output into the message file message-file that is specified by the -o option. If two messages have the same set and message number found, keep the message in the specified message file and discard the other message in the input file.
- -b Place the extracted comment after the corresponding message in the output file. This option changes the placement behavior of the -s or -c option.
- -c message-tag Extract message comments having message-tag inside them from the input files, and write them with a $ prefix as a comment in the output file.

# genmsg

- -d Include an original text of a message as a comment to be preserved along with its translations. With this option, the translator can see the original messages even after replaced with their translations.
- -f Overwrite the input files and the project file when using the -l or -r option. With the -r option, overwrite only the input files.
- -g project-file Generate project-file that has a list of set numbers and their maximum message numbers in the input files.
- -1 project-file Replace message numbers with the calculated numbers based on project-file if the message numbers are -1 in the input files, generate copies of the input files with the new maximum message numbers and a copy of project-file if not found, use the maximum message number in the input file as a base and generate project-file.
- -m prefix Fill in the message with prefix This option is useful for testing.
- -M suffix Fill in the message with suffix This option is useful for testing.
- -n Add comment to the output file indicating the file name and line number in the input files where each extracted string is encountered.
- -o message-file Write the output to message-file.
- -p processor Invoke the preprocessor to preprocess macros and define statements for the catcats(3) calls. genmsg first invokes the option argument as a preprocessor and then starts the normal process against the output from the preprocessor. genmsg initiates this process for all the input files.
- -r Replace message numbers with -1. This operation is the reverse of the -1 option.
- -s set-tag Extract set comments having set-tag inside them the input files and write them with a $ prefix as a comment in the output file. If you specify multiple comments for one set number, extract the first one and discard the rest of them.
- -t Generate a message that is three times as long as the original message. This option is useful for testing.
- -x Suppress warnings about message, set number range checks, and conflicts.
