# SCCS

Do not report version numbers or statistics.

```
-s
-cdate-time (/usr/ccs/bin/sccs)
-c date-time | -cdate-time (/usr/xpg4/bin/sccs)
```

Retrieve the latest version checked in before the date and time indicated by the date-time argument. date-time takes the form yy[mm[[dd mmss]]]]

Retrieve the version corresponding to the indicated sid if you specify no sid, retrieve the latest sid for the specified file.

```
-r[sid]
-r sid | -rsid
```

Retrieve the version corresponding to the indicated sid

```
help message-code sccs-command
help stuck
```

Supply more information about SCCS diagnostics. help displays a brief explanation of the error when the code displayed by an SCCS diagnostic message. if you supply the name of an SCCS command, help prints a usage hint. help also recognizes the keyword stuck. see sccs-help(1).

```
info [-b] [-username] (/usr/ccs/bin/sccs)
info [-b] [-username] (/usr/xpg4/bin/sccs)
```

Display a list of files being edited, including the version number checked out, the version to be checked in, the name of the user who holds the lock, the date and time the file was checked out.

```
-b
Ignore branches.
-u{username} (/usr/ccs/bin/sccs)
-u {username} | -U (/usr/xpg4/bin/sccs)
```

List only files checked out by you. When you specify username, list only files checked out by that. /usr/xpg4/bin/sccs, the -U option is equivalent to current-user.

```
prs
prs [-el] [-cdate-time] [-rsid] (/usr/ccs/bin/sccs)
prs [-el] [-c date-time | -cdate-time] [-r r sid | -rsid]
(/usr/xpg4/bin/sccs)
```

Retrieve the entire history of each named file. Equivalent to sccs pr get -m.

Peruse (display) the delta table or other portion of an s-file. See sccs-prs(1).

```
-e
```

Display delta table information for all deltas earlier than the one specified with -r (or all deltas if you specify none)
