
从名为 file.c 的 C 源文件构建名为 file 的可执行文件的规则。如果一个具有空后缀的目标具有显式依赖关系，make 将跳过对后缀规则的搜索。

下表列出了标准的隐式（后缀）规则。

| 用 | 隐式规则名称 | 命令行 |
|---|---|---|
| 汇编文件 | .s-o | $(COMPILE.s) -o $* $@ |
| | .s-a | $(COMPILE.s) -o $* $@ |
| | | $(AR) (ARFLAGS) $* $@ |
| | | $(RM) $* $@ |
| | .s~o | $(-s1GFLAGS) -p $@ > *.s$ |
| | | $(-s1COMPILE.s) -o $@ > *.s$ |
| | .S.o | $(COMPILE.S) -o $* $@ |
| | .S.a | $(COMPILE.S) -o $* $@ |
| | | $(AR) (ARFLAGS) $* $@ |
| | | $(RM) $* $@ |
| | .S-.o | $(GET) (GFLAGS) -p $@ > *.S$ |
| | | $(COMPILE.S) -o $@ *.S$ |
| | .S-.a | $(GET) (GFLAGS) -p $@ > *.S$ |
| | | $(COMPILE.S) -o $@ *.S$ |
| | | $(AR) (ARFLAGS) $* $@ |
| | | $(RM) $* $@ |
| C 文件 | .c | $(LINK.c) -o $* $@ $(LDLIBS) |
| | .c.ln | $(INT.c) $(OUTPUT_OPTION) -i $$ |
| | .c.o | $(COMPILE.c) $(OUTPUT_OPTION) $$ |
| | .c.a | $(COMPILE.c) -o $* $* $@ |
| | | $(AR) (ARFLAGS) $* $@ |
| | | $(RM) $* $@ |
| | .c~ | $(GET) (GFLAGS) -p $@ > *.c$ |
| | | $(CC) (CFLAGS) (LDFLAGS) -o $* $@ |
| | .c~.o | $(GET) (GFLAGS) -p $@ > *.c$ |
| | | $(CC) (CFLAGS) -c $@ *.c$ |
| | .c~.ln | $(GET) (GFLAGS) -p $@ > *.c$ |
| | | $(INT.c) $(OUTPUT_OPTION) -c $@ *.c$ |
| | .c~.a | $(GET) (GFLAGS) -p $@ > *.c$ |
