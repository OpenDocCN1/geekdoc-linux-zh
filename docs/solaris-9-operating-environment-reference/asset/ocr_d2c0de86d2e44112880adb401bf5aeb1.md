The example filters reverse linefeeds from input to print a manual page without the formatting.
castle% man od | col -b lpr

Without the use of the col command, the output looks like this:
NAME
od - octal dump

SYNOPSIS

```
/usr/bin/od [ -bcCDdFfOsvXx ] [- ] [ _f_i_l_e ]
[ _o_f_f_s_e_t__s_t_r_i_n_g ]
/usr/bin/od [ -bcCDdFfOsvXx ] [ -A_a_d_d_r_e_s_s__b_a_s_e ]
[ -j_s_k_i_p ] [ -N_c_o_u_n_t ] [ -t_t_y_p_e ]
[ -t ] [ _f_i_l_e ]
```

```
/usr/xpg4/bin/od [ -bcCDdFfOsvXx ] [- ] [ _f_i_l_e ]
[ _o_f_f_s_e_t__s_t_r_i_n_g ]
/usr/xpg4/bin/od [ -bcCDdFfOsvXx ] [ -A_a_d_d_r_e_s_s__b_a_s_e ]
[ -j_s_k_i_p ] [ -N_c_o_u_n_t ] [ -t_t_y_p_e ]
[ -t ] [ _f_i_l_e ]
```

The col strips out the formatting so that the output is a normal text file like this:
NAME
od - octal dump

SYNOPSIS

```
/usr/bin/od [ -bcCDdFfOsvXx ] [- ] [ file ]
```
