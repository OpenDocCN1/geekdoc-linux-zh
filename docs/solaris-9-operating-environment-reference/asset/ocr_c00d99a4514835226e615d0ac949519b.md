The following options exist for finer-grained control of the -remote commands.

-id X_window_ID

If more than one Netscape window is open, select the window
to control. If you do not use this option, the first window is found
controlled.

+   -raise
Control whether the -remote command raises/does not raise the
Netscape window to the top. The default is -raise. You can use -raise
and -noraise options with the addBookmark and openURL arguments.

+   -noraise

+   -session-management

Enable session management. Session management is enabled by
default. See -no-session-management.

+   -version
Display the version number and build date.

+   -visual
id-or-number

Used the specified server visual.

+   -xrm resource-spec

Set the specified X resource.

# Remote Actions

When you invoke Netscape Navigator with the -remote argument, it does not open a
window. Instead, it connects to an already existing process. The argument
of-remote is to invoke an Xt with optional options. Remote control is
implemented with Properties, so the two processes need not be running on the
system and need not share a file system. For more information, see
http://netscape.com/newref/std/x-remote.html.

All of Netscape's action names are the same as its resource names. For example,
you want to know the name of the action that corresponds to the Bookmark menu
item, you could look in Netscape for Add Bookmark and see that the resource is set
to that string is addBookmark. That file is also the name of the action.

> Note — To find the path, use the full default path:
/usr/dt/appconfig/netscape/lib/local/C/appdefaults/Netscape

You can use actions in Translation tables in the usual Xt manner, and you can also
invoice them directly with the remote option, as shown in the following example.

```
netscape -remote 'addBookmark()'
```

This command adds the current URL to bookmarks for the existing Netscape Navigator
process just if you had selected that menu item.
Using the following command to open a document.

```
netscape -remote 'openURL(http://home.netscape.com)'
```
