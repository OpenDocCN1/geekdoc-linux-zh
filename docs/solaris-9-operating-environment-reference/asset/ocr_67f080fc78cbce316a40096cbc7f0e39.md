# Environment

Environment uses the terminfo(4) entry for the terminal to determine its
characteristics. more in the environment variable MORE for any preset options. For instance,
page through files using the -c mode by default, set the value of this variable to -c.
(Normally, the command sequence to set up this environment variable is in the
.login or .profile files).

# Commands

The commands take effect immediately. It is not necessary to press Return unless the
command requires a file, command, tagstring, or pattern. Up to the time you type the
command character itself, you can type the line-kill character to cancel the numerical
argument. In addition, you can erase the character to redisplay the
--More--( or file message.

In the following commands, i is a numerical argument (1 by default).
