(.)i
text

Insert zero or more lines of text before the addressed line in the buffer.
Leave the current line (.) at the last inserted line, or, if there was none,
at the addressed line. This command differs from a command only
in the placement of the input text. Address 0 is not legal for this
command. The maximum number of characters that you can enter
from a terminal is 256 per line (including the newline character).

(..1)j

Join contiguous lines by removing the appropriate characters.
If you have exactly one line, do nothing. If lines are joined, set
the current line to the address of the joined line; otherwise, the
current line remains unchanged.

(..)kx

Mark the addressed line with name x, which be an ASCII
lowercase letter (a-z). The address x' then addresses this line; the
current line (.) is unchanged.

Print the addressed lines to standard output. Leave the current line ()

P

Prompt with an asterisk(*) (or if you specify the -p option) for
all subsequent commands. Enter the P command to exit this
mode. By default, the prompt mode is off unless you specify the -p
option which is unchanged.

Q

was written, displaying a warning message.
