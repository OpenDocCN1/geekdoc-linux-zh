# Authors

The primary Info-ZIP authors (current simultaneous members of the Zip-Bugs work group) are: Greg "Cave New" Roelofs (UnZip); Onno van der Linden (Zip); Jean-Louis Gaily (compression); Mark Adler (decompression, funZip); Harald Spieler (VMS, MS-DOS; Windows 95, NT, shared code. general zip and UnZip integration and optimization); Mike White (Windows GUI, Windows DLLs); Kai Uwe Rolle (OS/2); Paul Kienitz (Amiga, Windows); Chris Herbirth (BeOS, QNX, Atari); Jonathan Hudson (SMS/QDS); Sergio Monesi (Acorn RISC) Harald Denker (Atari, MVS); John Bush (Solaris, Amiga) Steve Goatley (VMS); Steve Miller (Windows CE GUI), Johnny Lee (MS-DOS, Windows 95, NT); and Dave Smith (Tandem NS)

The author of the original unzip code on which Info-ZIP is based is Samuel H. Smith; Carl Mascott did the first UNIX port; and David P. Kirchbaum organized and led Info-ZIP in its early days, with Keith Petersen hosting the original mailing list at WSMR-Tel20. The full list of contributors to UnZip has grown quite large; please refer to the CONTRIES file in the UnZip source distribution for a relatively complete version.
