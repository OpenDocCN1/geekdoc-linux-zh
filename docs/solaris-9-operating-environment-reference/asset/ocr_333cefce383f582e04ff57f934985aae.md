# lprm — Remove Print Requests from the Print Queue

# Synopsis

```
/usr/ucb/lprm [-P destination] [-] [request-ID...] [user...]
```

# Description

The lprm command to remove remove print requests (request-ID) from the print queue. Without arguments, lprm deletes the current print request. lprm reports the name of the file associated with print requests that it removes. lprm is silent if there are no applicable requests to remove.

You can only remove print requests associated with your own user name. If a superuser executes lprm and specifies the user operand, lprm removes all requests belonging to the specified user.

The print client can remove print requests in a specific order. See nswitch.conf(4), printers(4), and printers.conf(4) for details.

> Note — You can only remove print requests associated with your user name. By default, you can only remove print requests from the host on which the print request was submitted. If a superuser has set user-equivalence=true in /etc/printers.conf on the print server, you can remove print requests associated with your user name on any host. Superusers can remove print requests from the host on which the request was submitted. Superusers can also remove print requests from the print server.

# Options

+   -P destination

Specify the name of the printer or class of printers (see lpadmin(1M)) from which to remove print requests. Specify destination, using atomic, POSIX-style (server:destination) or Federated Naming Service (FNS) names. See printers.conf(4) for information regarding the naming conventions for FNS names, and standards(5) for information regarding POSIX.

+   - Remove all print requests owned by the user. If a superuser specifies this option, remove all requests in the print queue. Job ownership is determined by the user's login name and host name on the system from which lpr was executed.

# Operands

+   user Remove print requests associated with a specific user. Specify user as a valid user name. Only superuser can use this option.

+   request-ID Remove a specific print request. Specify request-IDs as the job number associated with a print request and reported by lpq. See lpq(1B).
