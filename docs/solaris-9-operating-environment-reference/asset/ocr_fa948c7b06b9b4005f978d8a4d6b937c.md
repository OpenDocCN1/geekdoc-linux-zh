# cdrw — CD Read and Write

```
/bin/cdrw -i [-vSCO] [-d device] [-p speed] [imagefile]
/bin/cdrw -a [-vSCO] [-d device] [-p speed] [-T audio-type] audio-file
[audio-file2...]
/bin/cdrw -x [-v] [-d device] [-T audio-type] track-number out-file
/bin/cdrw -c [-vSCO] [-d device] [-p speed] [-m tmp-dir] [-s src-device]
/bin/cdrw -b [-v] [-d device] all| session
/bin/cdrw -M [-v] [-d device]
/bin/cdrw -1 [-v]
/bin/cdrw -h
```

# Description

Use the cdrw command to create data and audio CDs, cdrw also enables you to extract audio tracks from an audio CD. You can use MMC-compliant CD-R or CD-RW drive with cdrw.

The cdrw command was initially provided starting with the Solaris 8 update 2 (10/00) release on the Software Supplement CD with the Solaris 8 Operating Environment. With the Solaris 9 release, the cdrw command is included with the Solaris 9 release and is available when using the Suncdrw package.
cdrw searches for a CD writer device connected to the system unless you specify a device with the -d option. If cdrw finds one such writer device, it uses that as the default CD writer device for the command.

When more than one CD writer is connected to the system, use the -d option to indicate which device to use. You can specify the device in one of the following

+   - /dev/rdsk/ctM&nM ctM&nM ctM&nM
- A symbolic name used by volume manager, such as cdrwm or cdrw.

You can use the -l option to display a list of CD writers.
For instructions on adding to your system a CD-RW that connects with the USB mass-storage class, use scsa2usb(7D).

# Creating Data CDs

Typically, you first prepare the data using the mkisofs(1M) command to convert the file and information into the High Sierra format used on CDs. See the examples that include of this command in "Examples" on page 132.

When creating CDs, cdrw uses the track-at-once mode of writing. Use the -i option to specify a file that contains the data to write on CD media. In the absence of such a file, cdrw reads data from standard input.

# Creating Audio CDs

To create an audio CD with the -a option, you can specify single or multiple audio files. All of the audio files should be supported in the listed audio formats. Currently approved formats are listed below.

| sun | .au with data in Red Book CDDA form. |
| wav | RIFF (.wav) files with data in Red Book CDDA form. |
