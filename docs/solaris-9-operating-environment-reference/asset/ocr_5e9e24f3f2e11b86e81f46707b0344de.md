# genlayayouttbi 431

The check_mode value pair specifies the level of checking of the elements in the input buffer for shaping and reordering purposes. The possible values are shown below.

MODE_STREAM

The string in the input buffer is expected to have valid combinations of characters or element elements.

MODE_EDIT

The shaping of input text may vary depending on locale-specific validation or assumption. When you specify no value or value pair, the default value is MODE_STREAM.
