# Attributes

See attributes(5) for descriptions of the following attributes:

| Attribute Type | Attribute Value |
|---|---|
| Availability | SUMdoc |
| CSI | Enabled |

> Note - The man command is CSI capable. However, some commands invoked by the man command, namely, troff, eqn, neqn, refer, tbl, and vgrind, are not verified to be CSI capable. Because of this, the man command with the -t option may not handle non-EUC data. Also, if the man command is used to display manual pages that require special processing through eqn, neqn, refer, tbl, or vgrind, may not be CSI capable.
