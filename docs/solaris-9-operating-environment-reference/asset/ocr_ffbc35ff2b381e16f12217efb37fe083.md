# pcat

The following example copies the olddier directory hierarchy to newdir.

```
castle% mkdir newdir
caste% pax -rw olddier newdir
caste%
```

The following example reads the archive a.pax with all files rooted in /usr in the archived extracted relative to the current directory.

```
castle% pax -r -s '^/usr//,' -f a.pax
caste%
```
