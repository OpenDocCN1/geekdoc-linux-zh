# Description

The keylogout command is part of the set of Secure RPC commands, keylogout deletes the key stored by the key server keyserv(1M). Further access to the key is revoked; however, current session keys may remain valid until they expire or are refreshed.

When you delete the keys stored by keyserv, any background jobs or scheduled at(1) jobs that need secure RPC services fail. Because only one copy of the key is kept on a system, it is a bad idea to place a call to this command in your .logout file because it affects others sections on the same machine.

# Options

+   -f keylogout to delete the secret key for superuser. By default, keylogout by superuser is disallowed because it would break all RPC services, such as NFS, that are started by superuser.

# kill — Terminate or Signal Processes

# Synopsis

```
/usr/bin/kill -s signal pid...
/usr/bin/kill -1 [exit-status]
/usr/bin/kill [-signal_name] pid...
/usr/bin/kill [-signal_number] pid...
sh, csh, and ksh
kill [-sig] [pid] [%job]...
kill -1
```

# Description

At times, you may need to eliminate a process entirely because you want to stop a large job before it completes or you detect a process that is hung or working properly. To delete a process, use the kill command. The kill command sends a signal to the process or processes specified by each operand. Use the ps(1) command to find the process ID for the process you want to kill.

When you kill a process, you are actually telling the system to send the process a signal. There are 36 numbered signals and 4 unnumbered ones. Refer to the signal(5)n page for the complete list.
