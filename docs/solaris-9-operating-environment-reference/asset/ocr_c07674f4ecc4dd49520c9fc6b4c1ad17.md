# Examples

# C Shell

The following C shell examples show various ways to use the history event designators.

```
castle% history
1 cd /etc
2 vi passwd
3 date
4 cd
5 du
6 ls -t
7 history
castle% !da
date
Mon Jan 18 17:53:28 WST 1999
castle% !!
date
Mon Jan 18 17:53:34 WST 1999
castle% !5
du
262 ./SCCS
336
castle% !ls ma*
ls -t malloc.c
malloc.o
malloc.c
```

# Korn Shell

The following example shows the various ways to use the fc event designators.

```
$ fc -l
1 cd /etc
2 vi passwd
3 date
4 cd
5 du
6 ls -t
7 $ fc -e - d
du
262 ./SCCS
336
$ fc -e - da
date
Mon Jan 18 17:59:52 WST 1999
$ !!
ksh:!: not found
$ alias !=-fc -e -
$ !
alias='fc -e -'
$ !5: not found
du .
```
