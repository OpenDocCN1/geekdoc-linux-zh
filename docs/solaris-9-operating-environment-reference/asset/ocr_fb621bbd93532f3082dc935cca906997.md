# zip, zipcloak, zipnote, zipsplit

-q
Quiet mode; eliminate informational messages and comment prompts.
(Useful, for example, in shell scripts and background tasks.)

-Qn
[QDOS] Store information about the file in the header with n
defined as follows: bit 0—Don add headers for file; bit 1—Add
headers for all files; bit 2—Don't wait for key press on.

-r
Travel the directory structure recursively. In the following, all
tiles and directories in foo are saved in a zip archive named
foo.zip, including files with names starting with . because the
recursion does not use the shell's file-name substitution mechanism.

-r foo
If you want to include only a specific subset of files in directory foo
and its subdirectories, use the -i option to specify the pattern of files to
is included. Do not use -r with the name "* because that matches
... tries to zip the parent directory (probably not was intended).

-R
Travel the directory structure recursively starting at the current
directory. In the following, all the files matching *.c in the tree
starting at the current directory are stored in a zip archive named
foo.zip.

```
zip -R foo '*.c'
For PKZIP users, the equivalent command is shown below.
pzip -rP foo *.c
```

[MS-DOS, OS2, WIN32 and ATARI] Include system and hidden files.
[MacOS] Include finder files, which are ignored otherwise.

Do not operate on files modified before the specified date, where mm is
t month (0–12), dd is the day of the month (1–31), and yyyy is the
year. The ISO 8601 date format yyyy-mm-dd is also accepted.
The following example adds to the infamy.zip archive all the files in foo
and its subdirectories that were last modified on or after 7 2001.

```
zip -rt 12072001 infamy foo
zip -rt 2001-12-07 infamy foo
```

Do not operate on files modified after or at the specified date, where mm
is the month (0–12), dd is the day of the month (1–31), and yyyy is the
year. The ISO 8601 date format yyyy-mm-dd is also accepted.
The following example adds to the infamy.zip archive all the files in foo
and its subdirectories that were last modified before 10 November
2001.

```
zip -rtt 11102001 infamy foo
zip -rtt 2001-11-10 infamy foo
```
