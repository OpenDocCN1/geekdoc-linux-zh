# limit, ulimit, unlimit — Set or Get Limitations on Available System Resources

# Synopsis

```
/usr/bin/ulimit [-f] [blocks]

sh
ulimit [-HS] [a | cdfnstv]
ulimit [-HSJ] c | d | f | n | s | t | v] limit

csh
limit [-h] [resource [limit]]
unlimit [-h] [resource]

sh
ulimit [-HSacdfnstv] [limit]
```

# Description

/usr/bin/ulimit
The ulimit command sets or reports the file-size writing limit imposed on files by the shell and its child processes (files of any size can be read). Only a process with appropriate privileges can increase the limit.

# Bourne Shell

The Bourne shell built-in function, ulimit, prints or sets hard or soft resource limits. These limits are defined in getlimit(2).

If you specify limit, ulimit prints the specified limits. You can print any number of limits at one time. The -a option prints all limits, as shown in the example:

```
$ -a
time(seconds) unlisted
file(blocks) unlisted
data(kobytes) unlisted
stack(kobytes) 8192
coredump(blocks) unlisted
ofiles(descriptors) 64
memory(kobytes) unlisted
$
```

If is present, ulimit sets the limit to limit. The string unlisted requests the largest valid limit. You can set limits for one resource at a time. Any user can set a soft limit to any value below the hard limit. Any user can lower a hard limit. Superuser can raise a hard limit, see limit(1).

The -H option specifies a hard limit. The -S option specifies a soft limit. If you specify neither option, ulimit sets both limits and the soft limit.

The following options specify the resource whose limits are printed or set. If you specify no option, the file size limit is printed or set.

+   -c Maximum corefile size (in 512 bytes).
-d Maximum size of data segment or heap (in kilobytes).
