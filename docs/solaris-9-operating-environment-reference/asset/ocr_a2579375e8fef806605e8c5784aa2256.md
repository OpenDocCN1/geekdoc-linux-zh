# acctcom — Search and Print Process Accounting Files

# Synopsis

/usr/bin/acctcom [-abfhikmqrtv] [-C sec] [-e time] [-E time] [-g group]
[-H factor] [-I chars] [-l line] [-n pattern] [-o output-file]
[-O sec] [-s time] [-S time] [-u user] [-filename...]

# Description

acctcom is one of the suite of commands that you use with the structured set of tools to build accounting systems. Use the acctcom command to search process accounting files created by acct(4) and to display selected records to standard output.

acctcom reads files, the standard input, or /var/adm/pacct in the form described by acct and writes selected records to standard output. Each record represents the execution of one process. The output shows the COMMAND, USER, TTY, START TIME, END TIME, CPU (SEC), MEAN SIZE (K), and optionally, F (the fork()/exec() flag:1 for fork() without exec), STAT (the system exit status), HOG FACTOR, KCORE, CPU FACTOR, CHARS TRANSFERS, and BLOCKS (total records read and written)

When execute the command with supervisor privileges, a pound sign (#) is prepended to the command name. When a process is not associated with a terminal, a ? is displayed in the TTY field.

/var/adm/pacct is read when you do not specify a file name and when the standard input is associated with a terminal or /dev/null (as is the case when using & in the shell). Otherwise, the standard input is read.
