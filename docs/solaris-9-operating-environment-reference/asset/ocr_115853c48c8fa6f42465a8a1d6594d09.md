# yacc

# 1571

Use sym-prefix instead of yy the prefix for all external names
produced by yacc. The names affected include the functions
yyparse(), yylex(), yyerror(), and the variables yylal, yychar,
and yydebug. (In the remainder of this section, the six symbols cited are
referenced with their default names only as a notational convenience.)
Local names may also be affected by the -p option; however, the -p
option does not affect #define symbols generated by yacc.

-p sym-prefix

-Q[y|n]

Put the version stamping information in y, tab.c. This option enables
you to know what version of yacc built the file. The -Q option (the
default) writes no version information.

-t

Compile runtime debugging code by default. The size and execution
time of a program produced without the runtime debugging code is
saller and slightly faster. Runtime debugging code is always
gener in y, tab.c under conditional control. By
default, code is not included when y.tab.c is compiled. The
runtime debugging code is always under the control of YYDEBUG,
preprocess symbol. If YYDEBUG has a non-zero value, include the
debugging code. If its value is 0, do not include the code.

-v

Prepare the y.output, which contains a description of the ambiguities in the parsing
tables and a report on conflicts generated by ambiguities
grammar.

-V

Print on the standard error output the version information for yacc.

# Operands

file

A path name of a file containing instructions for which a parser is to be
created.

# Examples

Access to the yacc library is obtained with library search operands to cc. The following
example uses the yacc library main.

```
castle% cc y.tab.c -ly
```

Both the lex library and the yacc library contain main. The following example
access the yacc main and ensures that the yacc library is searched first so that its
 is used.

```
example% cc y.tab.c lex.yy.c -ly -11
```

The historical yacc libraries have contained two simple functions that are normally
coded by the application programmer. These library functions are similar to the
following code.

```
#include <locale.h>
int main(void)
{
    extern int yyparse();
    setlocale(LC_ALL, "");
}
```
