The commands are listed below.

| Command | Description |
|---|-|
| C | Forced encryption |
| X | Heuristic encryption |
| & | Resubstitute. |
| CR | Print next. |
| > | Right shift. |
| < | Left shift. |
| ^D | Scroll. |
| z | Window. |
| ! | Shell escape. |

> Note — The z command prints the number of logical instead of physical lines. More than one screen of output may result if long lines are present.

The ex command addresses are listed below.

| Address | Description |
|---|-|
| n | Line n. |
| . | Current. |
| $ | Last. |
| + | Next. |
| - | Previous. |
| +n | n forward. |
| /pat | Next with pat. |
| ?pat | Previous with pat. |
| x-n | n before x. |
| x,y | through y. |
| 'x | Marked with x. |
| ' | Previous context. |
