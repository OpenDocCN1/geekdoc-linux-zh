# Environment Variables

The environment variables MSGVERB and SEV_LEVEL control the behavior of fmtmsg. MSGVERB is set by the administrator in /etc/profile for the system. You can override the value of MSGVERB set by the system by resetting MSGVERB in your own .profile files or by changing the value in the current shell session. You can use the SEV_LEVEL environment variable in shells.

MSGVERB tells fmtmsg which components to select when writing messages to standard error. The value of MSGVERB is a colon-separated list of optional keywords. You can set MSGVERB as [keyword:keyword:...] for the Bourne and Korn shell.

```
$ MSGVERB=[keyword:keyword:...]
$ export MSGVERB
```

You can set MSGVERB as follows for the C shell.

```
castle% setenv MSGVERB [keyword:keyword:...]
```

Valid keywords are label, severity, text, action, and tag. If MSGVERB contains a keyword for a component and the component's value is not the component's null value, fmtmsg includes that component in the message when writing the message to stderr. MSGVERB does not include a keyword for a message component, that component is not included in the display of the message. You can specify the keywords in any order. If MSGVERB is not defined, if it is the null string, which is not of the correct format, or if it contains keywords other than the value listed above, fmtmsg selects all components.

MSGVERB affects the selection of message components for display on stderr. All message components are included in console messages.

SEV_LEVEL defines severity levels and associates print strings with them for use by fmtmsg. You cannot modify the standard severity levels shown below. You can define, redefine, and remove additional severity levels.

+   0 (No severity used)
1 HALT.
2 ERROR.
3 WARNING.
4 INFO.
