## fnattr — Update and Examine Attributes Associated with an FNS Named Object

## Synopsis

```bash
/usr/bin/fnattr [-AL] composite-name [[-O |U] identifier...
/usr/bin/fnattr [-L] composite-name [[ -a [-s] [-O |U] identifier [value...]} | { -d [[-O |U] identifier [value...]]} | {-m [-O -U] identifier old-value new-value...}}
```

## Description

The fnattr command to update and examine attributes associated with a Federated N Service (FNS) named object. This command has four uses:
* Add an attribute or value.
* Delete an attribute or value.
* Modify an attribute's value.
* List the contents of an attribute.

> Note — You cannot update built-in attributes, such as onc_unix_passwd users, using the fnattr command. Their commands are affected by updates to the underlying naming service, such as NIS+ or NIS.

## Options

You can combine the options for adding, modifying, and deleting attributes and their values in the same command line. The modifications are executed in the order in which you specify them.
Any unsuccessful modification halts all subsequent modifications specified in the command line; any modifications already carried out. The unsuccessful modifications are displayed as output of fnattr.

+   -a Add an attribute or a value to an attribute associated with object by composite-name, identifier is the identifier of the attribute to manipulate; its format is FN_ID_STRING unless you use the -O or -U value. ... represents the attribute values to add. The attribute syntax for storing value is fn_attr_syntax.ascii.
+   -A Consult the authoritative source to get attribute information.
+   -d Delete attributes associated with object name by composite-name. If you do not specify identifier, delete all attributes with the named object. If you specify identifier without accompanying values (value...), remove the entire attribute identified by identifier. If you specify individual attribute values (value...), then remove only these from the attribute. Removal of the last value of an attribute entails the removal of the attribute as well. The format of identifier is FN_ID_STRING unless you use the -O or -U option.

## fnattr

If the composite name is bound to an X/Open Federated Naming (XFN) link, manipulate the attributes associated with the object pointed to the link. If you do not specify -L, manipulate the attributes associated with the XFN link.

-L

Modify the values of the attribute identified by identifier with the object named by composite-name. old-value is replaced by new-value in the specified attribute. Leave other attributes and values associated with composite-name unaffected. The format of identifier is FN_ID_STRING unless you use the -0 or -U option.

-m

The format of identifier is FN_ID_ISO_OID_STRING, as ASN.1, dot-separated, integer list string.

-O

Add supersede mode. If an attribute with the same identifier as already exists, remove all its values and replace with value. If you omit this option, the resulting values for the specified attribute are a union of the existing values and value.

-S

The format of identifier is FN_ID_DCE_UUID, a DCE UUID in string form.

-U

## Operands

composite-name

An FSN named object.

identifier  The identifier of the attribute to manipulate.

## Examples

### Adding

Use the -a for adding attributes and values. The following command replaces the value of the shoesize attribute of user/jane with the value 7.5.

```bash
castle% fnattr user/jane -as shoesize 7.5
```

The following command adds the value Chameleon to the projects attribute of user/jane.

```bash
castle% fnattr user/jane -as projects Chameleon
```

### Deleting

Use the -d for deleting attributes and values. The following command deletes the shoesize attribute from user/jane.

```bash
castle% fnattr user/jane -d shoesize
```

The following command deletes the projects attribute from user/jane.

```bash
castle% fnattr user/jane -d projects
```

### Modifying

Use the -m for modifying attributes and values. The following command replaces the value of the shoesize attribute of user/jane with 8.0.

```bash
castle% fnattr user/jane -m shoesize 7.5 8.0
```

The following command modifies the projects attribute of user/jane with Chameleon.

```bash
castle% fnattr user/jane -m projects old-value Chameleon
```

### Listing

Use the -l for listing attributes. The following command lists the shoesize attribute of user/jane.

```bash
castle% fnattr user/jane -l shoesize
```

The following command lists the projects attribute of user/jane.

```bash
castle% fnattr user/jane -l projects
```

#### fnbind — Bind a Reference to an FNS

## Synopsis

```bash
/usr/bin/fnbind [-s] [-L] name [[-O |U] identifier...
/usr/bin/fnbind [-s] [-L] name [[ -a [-s] [-O |U] identifier [value...]} | { -d ...}}
```

## Description

fnbind binds the Federated Naming Service (FNS) reference named name to new-name. The second synopsis of fnbind (using the -r option) enables the binding of new-name, using arguments in the command line.

## Options

+   -C Store addr-contents in the given form; do not use XDR encoding.
+   -L Create an X/Open Federated Naming (XFN) link using name and bind it to new-name.
+   -O Specify the identifier format as FN_ID_ISO_OID_STRING, an ASN.1 dot-separated list string.
+   -R Create a reference using ref-type as the reference's type and one or more pairs of addr-type and addr-contents as the reference's list of addresses, and bind this reference to new-name. Unless you use -O or U options, use FN_ID_STRING as the identifier format for ref-type and addr-contents. Unless you use -c or -x options, store addr-contents as an XDR-encoded string.
+   -S Bind to new-name if it is already bound. If you omit this option, fnbind fails if new-name is already bound.
+   -U Specify the identifier format as FN_ID_DCE_UUID, a DCE UUID in string form.
+   -V Display the reference bound to new-name
+   -X Specify addr-contents as a hexadecimal string. Convert it to its hexadecimal representation and store it; do not use XDR encoding.

## Examples

The following command binds the name thisorgunit/service/printer to the reference named by thisorgunit/service/printer.

```bash
castle% fnbind -s thisorgunit/service/printer thisorgunit/service/pr
```

The following example binds the name thisorgunit/service/pr to the XFN link constructed using the name thisorgunit/service/printer.

```bash
castle% fnbind -L thisorgunit/service/printer thisorgunit/service/pr
```

The following command binds the name thisorgunit/service/calendar to the reference with reference type SUNW_cal, address type SUNW_cal_deskset_onc, and address contents of staff@exodus.

```bash
castle% fnbind -r thisorgunit/service/calendar SUNW_cal
SUNW_cal_deskset_onc staff@exodus
```
