# dpost — troff Postprocessor for PostScript Printers

# Synopsis

```
/usr/lib/lp/postscript/dpost [-c num] [-e num] [-m num] [-n num]
[-o list] [-p mode] [-w num] [-x num] [-y num] [-F dir] [-H dir]
[-L file] [-O] [-T name] [file...]
/usr/lib/lp/postscript/dpost
```

# Description

dpost translates files created by scoff(1) into PostScript and writes the results on
standard output. If you specify no file or if - is one of the input files, the standard input
is read.

The files should be prepared by troff. The default font in
/usr/lib/font/devpost produces the best and most efficient output. They assume a
resolution of 720 dpi, and you can use them to format files by adding -Tpost option
to the call. Older versions of the eng and pic preprocessors need to know the
resolution that troff is using. If the versions installed on
your use the -lt20 option with eng and -TT20 with pic,
dpost makes no assumptions about resolutions. The first x res command sets the
resolution used to translate the input files, the DESC out file usually
/usr/lib/font/devpost/DESC out defines the resolution in the binary files,
and the PostScript prologue is responsible for setting up an appropriate coordinate
system.

The output does not conform to the file structuring conventions of Adobe. Piping
out of dpost through postverse(1) should produce a minimally conforming
PostScript file.
