# ex — Display-Based Text Editor

# Synopsis

```
/usr/bin/ex [- | -s] [-1] [-L] [-R] [-r [file]] [-t tag] [-v] [-V] [-x]
[-wm] [+command] [-c command] file...
/usr/xpg4/bin/ex [- | -s] [-L] [-R] [-r [file]] [-t tag] [-v] [-V]
[-X] [-wm] [+command] [-c command] file...
```

# Description

The ex command is the root of a family of editors: ex, edit, and vi is a superset of
ed(1), with the most notable extension being a display-editing facility. Display-based is the focus of vi.

If you have used a terminal, you may want to use a display-based editor; in this case,
see vi(1), which is a command that focuses on the display-editing portion of ex.

If you have used ed, you will find that, in addition having all of the ed commands
available, ex has a number of additional features useful with CRT terminals. Intelligent
terminals and high-speed terminals are very pleasant to use; the editor uses
more of the capabilities of terminals than ed does. The editor uses the	erminal capability database (terminfo(4)) and the type of terminal you are
using from the environment variable TERM to determine how to drive your terminal
efficiently. The editor makes use of such features as "insert and delete character and
line" in its visual command (the vi command).
