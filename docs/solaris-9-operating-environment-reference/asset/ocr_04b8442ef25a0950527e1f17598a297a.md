# mailx, mail

conv=conversion

Convert uucp addresses to the specified address style, which can be either of the following values:

+   internet: Require a mail delivery program conforming to the RFC822 standard for electronic mail addressing.

+   optimize: Remove loops in uucp(1C) address paths (typically generated by the reply command). Perform no rerouting; mail has no knowledge of UUCP routes or connections.

Conversion is disabled by default. Also see sendmail(1M) and the -U command-line option.

crt=[number]

Pipe messages having more than number lines through the command specified by the value of the PAGER variable (pg(1) or more(1)) by default. If you do not specify number, use the current window size. Disabled by default.

debug

Enable verbose diagnostics for debugging. Do not deliver messages. Disabled by default.

dot

Take a period on a line by itself, or EOF during input from a terminal, as end-of-file. Disabled by default, but dot is set in the startup file (which you can suppress with the -n command line option).

escape=c

Substitute c for the escape character. Effects take with the next message sent.

flrip

Reverse the effect of the followup/Followup and reply/Reply command pairs. If both flrip and replyall are set, the effect is as if neither was set.

folder=directory

The directory for saving standard mail files. Expand user-specified file beginning with a plus (+) by preceding the file name with this directory to obtain the real name. If directorydoes not start with a slash (/), prepend HOME to. There is no default for the directory variable. Also see outfile.

header

Enable printing of the header summary when entering mailx. Enabled by default.

hold

Preserve all messages that are read in the mailbox instead of putting them in the standard file. Disabled by default.

ignore

Ignore interrupts while entering messages. Handy for noisy dial-up lines. Disabled by default.

ignoreeof

Ignore end-of-file during message input. Input must be terminated by a period (.) on a line by itself or by the ~, command. See also dot above.
