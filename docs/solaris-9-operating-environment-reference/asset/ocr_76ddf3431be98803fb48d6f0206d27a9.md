After the file is processed, you are still in bc and can perform additional computations, or you can press Control-D, or type quit and Return to exit.
nThe following examples show bc's ability to perform base conversion on input and output separately. The ibase=(input base) command can change the ways numbers input are interpreted, and the obase=(output base) command can change the way numbers output by bc are interpreted. The comments in italic are not part of the screen

![](bbox=[0.078, 0.366, 0.138, 0.383])

```
$ bc
obase=16
255 # I input 255, which is converted to hex FF.
10 # I input 10.
# Decimal to octal conversion.
obase=8
10 # Decimal 10 is octal 12.
8 # Decimal 8 is octal 10.
7 # Decimal 7 is octal 7.
# Decimal to binary conversion.
obase=2
8 # Decimal 8 is binary 1000.
255 # Decimal 255 is binary 11111111.
11111111
1 # Decimal 1 is binary 1.

```

The ibase command can be useful and can also trip you up because you enter it, all subsequent numbers you enter are interpreted in that base, as shown in the following example.

```
2 # Decimal 2 is binary 10.
10
Control-D
$
```
