# Examples

An example of a single m4 input file capable of generating two output files follows.
filel1.m4 could contain lines such as the following.

```
if (VER, 1, do_something)
if (VER, 2, do_something)
```

The Makefile for the program could include the following lines:

```
filel1.c :
    filel1.m4
    m4 -D VER=1 filel1.m4 > filel1.c...
filel2.c :
    filel2.m4
    m4 -D VER=2 filel2.m4 > filel2.c
```

You can use the -U option to define VER. If file1.m4 contains the following statements,

```
if (VER, 1, do_something)
if (VER, 2, do_something)
ifndef (VER, do_something)
```

then the we would contain

```
filel1.0.c :
    filel1.m4
    m4 -U VER filel1.m4 > filel1.0.c
filel1.1.c :
    filel1.m4
    m4 -D VER=1 filel1.m4 > filel1.c
filel2.2.c :
    filel2.m4
    m4 -D VER=2 filel2.m4 > filel2.2.c
```

# Exit Status

+   0
Successful completion.
>0
An error occurred.

If you use the m4 exit macro, the exit value can be specified by the input file.
