# m4

ifelse

This macro has three or more arguments. If the first argument is the same string as the second, use the value of the third argument. If not and if there are more than four arguments, repeat the process with arguments 4, 5, 6, and 7. Otherwise, the value is the fourth string, or if it is not present, null.

include

Return the contents of the file named in the argument.

incr

Return the value of the argument incremented by 1. The value of the argument is calculated by interpretation of an initial digit-string as a decimal number.

index

Return the position in the first argument where the second argument begins (0), or -1 if there is no second argument.

len

Return the number of characters in the argument.

m4exit

Exit from m4. Argument, if specified, it is the exit code; the default is 0.

m4wrap

Push back argument 1 at final EOF; for example, m4wrap('cleanup').

maketemp

Fill in a string of X characters in the argument with the current ID.

popdef

Remove current definition of the argument(s), exposing the previous one, if any.

pushdef

Like define, but save any previous definition.

shift

Return all the first argument. Quote and push back the other arguments with commas in between. The quoting nullifies the effect of the extra scan that is subsequently performed.

sincludd

Identical to include, except saying nothing if the file is inaccessible.

substr

Return a substring of the first argument. The second argument is a 0-origin number selecting the first character; the third argument specifies the length of the substring. A missing third argument is taken to be large enough to extend to the end of the first string.

syscmd

Execute the command given in the first argument. Return no value. Return the return code from the last call to syscmd.

sysval

Transliterate the characters in the first argument from the set given by the second argument or the set given by it. No abbreviations.

traceon

Turn on tracing for all macros (including built-ins) with no arguments. Otherwise, turn on tracing for named macros.

traceoff

Globally turn off trace for any macros specified. Macros specifically traced by traceoff can be traced only by specific calls to traceoff.

undefined

Remove the definition of the macro named in the argument.

undivert

Immediately output the text from diversions named as arguments, or all diversions if you specify no argument. Text can be diverted into another diversion. Undiverting discards the diverted text.
