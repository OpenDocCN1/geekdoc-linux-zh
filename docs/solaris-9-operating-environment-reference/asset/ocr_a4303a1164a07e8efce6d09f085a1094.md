# join — Relational Database Operator

# Synopsis

```
/usr/bin/join [-a filename] [-v filename] [-1 fieldnumber]
[-2 fieldnumber] [-o list] [-t char] file file2
/usr/bin/join [-a filename] [-j fieldnumber] [-jl fieldnumber]
[-j2 fieldnumber] [-o list] [-e string] [-t char] file file2
```

# Description

The command forms a join of the two relations specified by the lines of file1 and
file2 and displays the results on standard output.
The output has one line for each pair of fields in file1 and file2 that have identical
join fields. The output line normally consists of the common field, then the rest of the line
from file1, then the rest of the line from file2. You can change this format with the -
option. Use the -a option to add unmatched lines to the output. Use the -v option
to output only unmatched lines.
The default input field separators are blank, Tab, or newline. Multiple separators
count as one field separator, and leading separators are ignored. The default output field
separator is a blank.
If the input files are not in the appropriate collation sequence, the results are
unspecified.

> Note — With default field separation, the collating sequence is that of
sort -b; with -t, the sequence is that of a plain sort.

The conventions of the join, sort, comm, uniq, and awk commands are
wildly incongruous.
