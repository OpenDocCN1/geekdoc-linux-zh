# cp — Copy Files

Synopsis

```
/usr/bin/cp [-fip@] source_file target_file
/usr/bin/cp [-fip@] source_file... target
/usr/bin/cp -r [-R [-fip@] source_dir... target
/usr/xpg4/bin/cp [-fip@] source_file target_file
/usr/xpg4/bin/cp [-fip@] source_file... target
/usr/xpg4/bin/cp -r | -R [-fip@] source_dir... target
```

Description

With the command, you can do the following actions:

+   * Make copies of individual files and assign new names to them.
* Copy one or more files into a different directory, keeping the existing file names.
* Recursively copy an entire directory structure to another directory.
* Copy extended file attributes.
