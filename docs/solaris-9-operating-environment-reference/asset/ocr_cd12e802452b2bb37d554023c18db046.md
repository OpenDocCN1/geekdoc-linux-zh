# Source Format

Reference manual pages are marked up with either nroff(1) or sgml(5) (Standard Generalized Markup Language) tags. The man recognizes the type of markup and processes the file accordingly. The various source files are kept in separate directories depending on the type of markup.

# Location of Manual Pages

The online reference man page directories are conventionally located in /usr/share/man, man The nroff sources are located in the /usr/share/man/man* directories. Each directory corresponds to a section of the manual. Because these directories are optionally installed, man may not reside on your host; you may have to move /usr/share/man/from a host on which to reside.

If there are preformatted, up-to-date versions in the formatted cat or fmt*, man displays or prints these versions. If the preformatted version is out-of-date or missing, man reformats before displaying it and stores the preformatted version if cat or fmt* is writable. The windex database is not updated. See catman(1). If directories for the preformatted versions are not provided, man reformats whenever it is requested; it uses a temporary file to store the formatted text during display.

If the standard output is not a terminal or if you specify the option, man pipes its output through cat(1); otherwise, man pipes its output through more(1) to handle paging and underlining on the screen.

# Options

+   - Pipe output through cat(1) instead of more(1).
- Show all manual pages in the order found matching name within the MANPATH search path.
- Display what a section-specifier evaluates to, method used for searching, and paths searched by man.
- Locate manual pages related to any of the given files. Strip the path-name components from each file and print one-line summaries containing the resulting basename or names. This option uses the windex database.
- Force man to search all directories specified by MANPATH or the man.cf file instead of using the windex lookup database. This option is useful if the database is not up-to-date. If the windex database does not exist, this option is assumed.
- Print one-line summaries from the windex database (table of contents) that contain any of the given keywords. The windex database is created with catman(1M).
- List all manual pages found matching name within the search path.
