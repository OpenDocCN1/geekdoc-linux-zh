# Arithmetic Evaluation

The let command provides the capability of performing integer arithmetic.
Evaluations are performed using long arithmetic. Constants are of the form [$base] n
where base is a decimal number between 2 and 36 representing the arithmetic base and
n is a number in that base. If you omit base, then base 10 is used. An arithmetic
expression uses the same syntax, precedence, and associativity of expression as the C
language. All the integral operators, other than +, -, ?, and are supported. You can
reference variables by name within an arithmetic expression without using the
parameter substitution. When you refer a variable, its value is evaluated as
an arithmetic expression.

You can specify an integer representation of a variable with the -i option of
typeset command. Arithmetic evaluation is performed on the value of each
assignment to a variable with the -attribute. If you do not specify an arithmetic base,
the first assignment to the variable determines the arithmetic base. This base is used
when parameter substitution occurs. Many of the arithmetic operators require
quoting, an alternative form of the let command is provided. For any command that
begins with a ((, all the characters until a matching )) are treated as a quoted
expression. More precisely, (()) is equivalent to let "*.

# Conditional Expressions

Use conditional expressions with the [[ compound command to test attributes of
and to compare strings.

+   - Word splitting and file-name generation are not performed on the words between [
and ]]. Each expression can be constructed from one or more of the following unary or
binary expressions.
-a file true if exists.
-b file true if exists and is a block special file.
-c file true if exists and is a character special file.
-d file true if exists and is a directory.
-e file true if exists.
-f file true if exists and is an ordinary file.
-g file true if exists and has its setgid bit.
-k file true if exists and has its sticky bit set.
-n string if length of string is non-zero.
-o option true if named option is on.
-p file true if exists and is a fifo file or a pipe.
-r file true if exists and is readable by current process.
