# dispuid — Display a List of All Valid User Names

# Synopsis

/usr/bin/dispuid

# Description

dispuid displays a list of all user names on the system (one line per name).

# Examples

The following example displays the user names for the system castle.

```
castle% dispuid
root
daemon
bin
sys
adm
lpl
smtp
uucp
nuuc
listen
nobody
noaccess
nobody4
winsor
ray
des
rob
castle%
```

# Exit Status

|0 Successful execution.
1 Cannot read the password file.|
