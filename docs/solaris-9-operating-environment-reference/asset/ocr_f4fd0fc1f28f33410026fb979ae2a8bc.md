indentprefix=string Use string to mark indented lines from messages included with -m.
The default is a Tab character.

iprompt=string Display the specified prompt string before each line on input whennsending a message.

keep When the mailbox is empty, truncate it to 0 length instead of removingnit. Disabled by default.

keepsave Keep messages that have been saved in other files in the mailboxnstead of deleting them. Disabled by default.

makeremote When replying to all recipients of a message, if an address does notninclude a name, assume it is relative to the sender of the supportnmessage. Normally not needed when dealing with hosts that supportnFC 822.

metoo If your login appears as a recipient, do not delete it from the list.
Disabled by default.

mustbang Force all mail addresses to be bang format.

onehop Disable alteration of the recipients' addresses, improving efficiency in annnetwork where all machines can send directly to all other machinesn(that is, there are one hop away).When responding to a messagenthat was originally sent to several recipients, the other recipientnaddresses are normally forced to be relative to the originating author's
machine for the response. Disabled by default.

outfolder Locate the files used to record outgoing messages in the directorynsspecified by the folder variable unless the path name is absolute.
Disabled by default. See folder and the Save, Copy, followup, andnFollowup commands.

page Use the pipe command to insert a feedmember after each messagensent through the pipe. Disabled by default.

pipeignore Omit header when outputting to the pipe command. Althoughndabled by default, pipeignore is frequently set in the system startupnfile. See “Starting Mail” on page 769.
