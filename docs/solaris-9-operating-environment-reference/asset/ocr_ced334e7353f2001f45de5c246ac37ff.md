# ssh-keygen

# Examples

The following example uses the ssh-keygen command with no options to create a key with a 1024-bit with a passphrase in the default location.

```
$mopoke$ ssh-keygen
ter file in which to save the key(/home/winsor/.ssh/id_rsa):
Created directory '/home/winsor/.ssh'.
Generating public/private rsa key pair.
Enter passphrase(empty for no passphrase): Passphrase
Enter passphrase again: Passphrase
Your identification has been saved in /home/winsor/.ssh/id_rsa.
Your public key has been saved in /home/winsor/.ssh/id_rsa.pub.
The key fingerprint is:
md5 1024 c6:b8:17:33:e5:d9:77:ef:bb:2fc:25:5a:07:72 winsor@mopoke
```

```

ter passphrase again: Enter passphrase again.

Your public key has been saved in /home/gmarler/.ssh/identity.pub.
The key fingerprint is:
md5 1024 b3:eb:07:01:0d:af:1e:29:8e:f9:2a:c6:a1:04:8b:9a A default SSH
v1 RSA keypair
```
