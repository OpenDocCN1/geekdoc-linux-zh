# cksum — Write File Checksums and Sizes

# Synopsis

```
/usr/bin/cksum [file...]
```

# Description

The cksum command calculates and writes to standard output a cyclic redundancy check (CRC) for each input file and also writes to standard output the redundancy of octets in each file.

For each file processed successfully, cksum writes in the following format:
"%u %d %s\n" checksum, # of octets, pathname

> If you do not specify a file operand, the path and leading space are omitted. The CRC is based on the polynomial used for CRC error checking in the referenced Ethernet standard.

The encoding for the CRC checksum is defined by the generating polynomial

```
G(x) = x32 + x26 + x23 + x22 + x16 + x12 + x11 + x10 + x8 + x7 + x4
+ x2 + x + 1
```

# cksum

Mathematically, the CRC value corresponding to a given file is defined by the following procedure.

1. The $n$ bits to be evaluated are considered to be the coefficients of a mod 2 polynomial M(x) of degree n-1. These $n$ bits are the bits from the file; the most significant bit is the most significant of the first octet, and the last is the least significant bit of the last octet, padded with zero bits (if necessary) to achieve an integral number of octets by one or more octets representing the length of the file as a binary value, with least significant octet first. The smallest number of octets capable of representing this integer is used.
2. M(x) is multiplied by 32 (that is, shifted left 32 bits) and divided by G(x) mod 2 division, producing a remainder R(x) of degree < 31.
3. The coefficients of R(x) are considered to be a 32-bit sequence.
4. The bit sequence is complemented, and the result is the CRC.

# clear — Clear the Terminal Screen

# Synopsis


# Description

The clear command clears your screen or the current shell window if it can. It looks in the environment for the terminal type and then in the terminfo database to figure out how to clear the screen.

# cmp — Compare Two Files

# Synopsis

```
/usr/bin/cmp [-l] [-s] file1 file2 [skip1]
```

# Description

Use cmp to compare two files. If the files are identical, cmp writes no output. Under default, cmp writes the first line on which the files differ, the byte number of the line and the differing characters. If you use the -l option, cmp prints only the line numbers where the files differ. If you use the -s option, cmp compares the files but produces no output. If you use the -n skip1 option, cmp skips the first skip1 bytes. 

# Options

- -l Print only the line numbers where the files differ.
- -s Compare the files but produce no output.
- -n skip1 Skip the first skip1 bytes.
- -y Compare files line-by-line.

# Operands

- file1 The first file to compare.
- file2 The second file to compare.
- [skip1] Skip the first skip1 bytes.

# Usage

cmp [-l] [-s] [-n skip1] [-y] file1 file2 [skip1]
