# Introduction

# Localization Commands

+   - dumpps: Show codaset table for the current locale.
- geniconvbtbl: Generate iconv code-conversion tables.
- gettext: Retrieve text string from message database.
- iconv: Code set conversion utility.
- isalist: Display the native instruction sets for this platform.
- localedef: Define locale environment.
- xstr: Extract strings from C programs.

See also "System Localization (SUNWloc)" on page 20.

# Miscellaneous

+   - Intro, intro: Introduction to commands and application programs.
- newgrp: Log in to a new group.
- passwd: Change login password and password attributes.
- pwck, grpck: Password and group file checkers.
- rpcgen: RPC protocol compiler.
- script: Make record of a terminal session.
- tplot, t300, t30s, t4014, t450, tek: Graphics filters for various plotters.

# NIS+/Secure RPC Commands

+   - chkey: Change user's secret RPC key pair.
- keylogin: Decrypt and store secret key with keyserv.
- logout: Delete stored secret key with keyserv.

# Package Commands

+   - pkginfo: Display software package information.
- pkgmk: Produce an installable package.
- pkgparam: Display package parameter values.
- pkgproto: Generate prototype file entries for input to pkgmk.
- pkgtrans: Translate package format.

# Platform Resource Commands

+   - arch: Display the architecture of the current host.
- hostid: Print the numeric identifier of the current host.
- hostname: Set or print name of current host system.
