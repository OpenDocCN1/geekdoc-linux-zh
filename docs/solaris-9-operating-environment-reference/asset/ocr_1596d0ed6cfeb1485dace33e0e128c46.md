# line — Read One Line

# Synopsis

/usr/bin/line

# Description

The line command copies one line (up to and including a newline) from the standard input and writes it to the standard output. It returns an exit status of 1 on end-of-file and always prints at least a newline. It is often used within shell files to read from the user's terminal.

# Examples

When you invoke the line command, it enters a newline and waits for a line. When you press Return, the line is echoed to standard output, as shown in the following example.

```
castle% line
This is a line
This is a line
castle%
```

# Exit Status

| | |
| --- | --- |
| 0 | Successful completion. |
| >0 | End-of-file on input. |
