-p Disable processing of the $HOME/.profile file, and use the file /etc/suid_profile instead of the ENV file. This mode is whenever the effective UID is not equal to the real UID, or when the effective GID is not equal to the real GID. Turning this option sets the effective UID and GID to the real UID and GID.
