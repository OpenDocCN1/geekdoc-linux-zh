# uucp, uulog, uuname

For security reasons, the domain of remotely accessible files may be severely restricted. You probably cannot access files by path name; ask a responsible person on the remote system to send them to you. For the same reasons, you probably cannot send files to arbitrary path names. As distributed, the remotely accessible files are those whose begin /var/spool/uupublic (equivalent to ~).
All files are received by uucp.

Protected files and files that are in protected directories are owned by the requester can be sent by uucp. However, if the requester is root and the directory is not searchable by other or the file is not readable by other, the request fails.
Strings that are passed to remote systems may not be evaluated in the same locale as the one in by the process that invoked uucp on the local system.
Configuration files must be treated as C- (or POSIX-) text files.

# Options

# uucp

+   -c
  - Do not copy local files to the spool directory for transfer to the system (default).
  - Force the copy of local files to the spool directory for transfer.
  - Make all necessary directories for the file copy (default).
  - Do not make intermediate directories for the file copy.
-grade
  - Specify the grade as a single letter, number, or a string of alphanumeric characters defining a service grade. The uuglist command to determine whether it is appropriate to use the single letter, number, or a string of alphanumeric characters as a service grade. The output from the uulist command is a list of service grades that are available or a message that says to use a single letter or number as a grade of service.
-j
  - Print the uucp job identification string on standard output. This job identification can be viewed by uustat to obtain the status of a uucp job or to terminate a uucp job. The uucp job is valid as long as the job remains on the local system.
m
  - Send mail to the requester when the copy is complete. The -m option works only when sending files or receiving a single file. Receiving multiple files specified by shell characters ?, &, and [...] does not activate the -m option.
-n
  - Notify user on the remote system that a file was sent.
-r
  - Do not start the file transfer, just queue the job.
-sfile
  - Report status of transfer to file This option is accepted for compatibility but is ignored because it is insecure.
-xdebug-level
  - Debugging output on standard output, debug-level is a number between 0 and 9; as it increases to 9, show more detailed debugging information. This option may not be available on all systems.
