# print — Shell Built-in Function to Output Characters to the Screen or Window

# Synopsis

```
ksh
print [-Rmprsu [n]] [arg...]
```

# Description

Korn Shell built-in function is the mechanism used by the Shell to display arg. With no options or with - --, the arguments are printed on standard output as described by echo(1). The exit status is 0 unless the output file is not open for writing.

# Options

+   -n Suppress newline from being added to the output.
-R -r Ignore the escape conventions of echo. The -R option prints all subsequent arguments and options other than -n.
-p Write the arguments onto the pipe of the process spawned with | instead of standard output.
-s Write the arguments into the history file instead of standard output.
-u [n] Use the n argument to specify a one-digit file descriptor unit on which the output is placed. The default is 1.
