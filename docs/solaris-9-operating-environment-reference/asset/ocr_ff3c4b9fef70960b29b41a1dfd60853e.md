# Examples

The following example configures preferred page sizes with MPSSCFILE.

The following Bourne shell commands (see sh(1)) configure the preferred page sizes to a select set of applications with exec names that begin with foo, using the MPSSCFILE environment variable. The MPSS configuration file, mpsscfg, is assumed to have been previously created with a text editor such as vi(1). The cat command(1) is only dumping the contents

```
example$ LD_PRELOAD=$LD_PRELOAD:mpss.so.1
example$ MPSSCFILE=mpsscfg
example$ export LD_PRELOAD MPSSCFILE
example$ cat $MPSSCFILE
foo*:512K:64K
example$
```

Once the application has been started, you can use pmap (see proc(1)) to view the actual page sizes configured.

```
example$ foobar &
example$ pmap -s `pgrep foobar`
```

If the desired page size is not configured (shown in the pmap output), it may be because of errors in the MPSS configuration file or environment variables. Check the error log (default: /var/adm/messages) for errors.

If no errors are found, resource or alignment constraints may be responsible.

The following example configures preferred page sizes with MPSSHEAP and MPSSSTACK.

The following Bourne shell commands configure 512K heap and 64K stack preferred page sizes for all applications with the MPSSHEAP and MPSSSTACK environment variables.

```
example$ LD_PRELOAD=$LD_PRELOAD:mpss.so.1
example$ MPSSHEAP=512K
example$ MPSSSTACK=64K
example$ export LD_PRELOAD MPSSHEAP MPSSSTACK
example$
```

The preferred page size configuration in MPSSCFILE overrides MPSSHEAP and MPSSSTACK. Following the following commands to those in the previous example would configure all applications with 512K heap and 64K stack preferred page sizes with the exception of the ls ls command and all applications beginning with ora, in the configuration file.

```
example$ MPSSCFILE=mpsscfg2
example$ export MPSSCFILE
example$ cat $MPSSCFILE
ls::
ora*:4m:4m
example$
```
