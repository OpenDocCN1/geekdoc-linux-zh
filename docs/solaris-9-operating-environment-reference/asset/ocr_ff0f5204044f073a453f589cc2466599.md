# jobs, fg, bg, stop, notify — Control Process Execution

# Synopsis

```
jsh
jobs [-p | -l] [%job-id...]
jobs -x command {arguments}
fg [%job-id...]
bg [%job-id...]
stop %job-id...
stop pid...
```

```
csh
jobs [-1]
fg [%job-id...]
bg [%job-id...]
notify %job-id...
stop %job-id...
stop pid...
```

```
ksh
jobs [-lnp] [%job-id...]
fg [%job-id...]
bg [%job-id...]
stop %job-id...
stop pid...
```
