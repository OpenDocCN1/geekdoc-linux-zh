# Diagnostics

Exit status is normally 0; if an error occurs, exit status is 1. If a warning occurs, exit status is 2.

```
Usage: gzip [-cdfhlnNrtvV19] [-S suffix] [file ...]
```

Invalid options were specified on the command line.

file: not in gzip format

The file specified to gzip has not been compressed. Use gcat to recover some data.

file: Corrupt input. The compressed file has been damaged. The data up to the point of failure can be recovered by gczat file > recover.

file: compressed with xx bits, can only handle yy bits

File was compressed (LZW) by a program that could deal with more bits than the decompression code on this machine. Recompress the file with gzip, which compresses better and uses less memory.

file: already has .gz suffix no change

The file is assumed to be already compressed. Rename the file and try again.

file already exists; do you wish to overwrite (y or n)?

Respond if you want the output file to be replaced; n if not.

gzip: corrupt input

A SIGSEGV violation was detected, which usually means the input file has been corrupted.

xx.x% Percentage of the input saved by compression. (Relevant only for -v and -1.)

-- not a regular file or directory: ignored

When the input file is not a regular file or directory (for example, a symbolic link, socket, FIFO, or device file), it is left unaltered.
