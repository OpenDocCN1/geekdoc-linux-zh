# pkgptrans — Translate Package Format

# Synopsis

/usr/bin/pkgptrans [-inos] device1 device2 [pkginst...]

# Description

The pkgptrans command translates an installable package from one format to another. It performs the following translations:

+   - A File-system format to a datastream
- A datastream to a file-system format.
- One file-system format to another file-system format.

Device specifications can be either the node name (for example, /dev/diskette) or a device alias (for example, diskettel). The device specify indicates the default pool directory. Source and destination devices cannot be the same.
By default, pkgptrans does not translate any instance of a package if any instance of that package already exists on the destination device. Using the -n option creates a new instance if an instance of this package already exists. Using the -o option overwrites an instance of this package if it already exists. Neither of these options is useful if the destination device is a datastream.
