When a archive is being read, its actual blocking factor is automatically detected provided that it is less than equal to the nominal blocking factor (the value of the block argument or the default value if you do not specify the modifier). If the actual blocking factor is greater than the nominal blocking factor, a read error occurs.

Block. Force tar to perform multiple reads (if necessary) to read exactly enough bytes to fill a block. This function modifier enables tar to work across the Ethernet because pipes and sockets return partial blocks even when more data is coming. When reading from standard input, the b modifier is selected by default to ensure that tar can recover from short reads.

Error. Exit immediately with a positive status if any unexpected errors occur. The SYSV3 environment variable overrides the default behavior.

Write with extended headers. (Used with c, r, or options; ignored with t x options). When tar is written with extended headers, maintain the modification time with a granularity of microseconds instead of seconds. In addition, support file names longer than TAR_MAX characters that could not be archived without E and file sizes greater than 8 gigabytes. Require the E modifier whenever archiving files, files with longer names, files whose UID/GID exceeds 2097151, or if you want time granularity of microseconds.

File. Use the tarfile as the name of the tarfile. If you specify f, do not search /etc/dev/tar. If you omit f, use the device indicated by the TAPE environment variable set; otherwise, use the default values defined in /etc/dev/tar.

The matching number of archive/string is the output device with the blocking and space specifications for the archive. The following example writes the output to the devices specified as archive2 in /etc/dev/tar. New in the Solaris 9 release.

```
tar -c 2 /tmp/*
```

If the tarfile is -, write to the standard output or read from the standard input, whichever is appropriate. You can use tar as the head or tail of a pipeline. You can also use tar to move hierarchies with the following command.

```
% cd fromdir; tar cf - . (cd todir; tar xfBp -)
```

With one argument, exclude all directories SCCS and RCS from tarfile. With two arguments, exclude all directories SCCS and RCS, all files with .o as their suffix, and all files named core, and a.out. The SYSV3 environment variable overrides the default behavior.
