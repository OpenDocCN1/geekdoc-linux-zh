In the following example, using the fdfformat -U command, fdfformat detects a formatting error, as indicated by the e, and exits.

```
castle% fdfformat -U
Formatting 1.44 MB in /vol/dev/rdiskette0/unnamed_floppy
Press return to start formatting floppy. .................................................................
```

```
fdfformat: can't read format data, I/O error
caste% eject
```

The following example uses fdfformat with no arguments (on a new diskette) to successfully create a SunOS file system on the diskette.

```
castle% fdfformat
Formatting 1.44 MB in /vol/dev/rdiskette0/untitled
Press return to start formatting floppy. .................................................................
```

```
castle%
```

The following example uses the -d option to successfully create a DOS file system on a diskette.

```
castle% fdfformat -d
Formatting 1.44 MB in /vol/dev/rdiskette0/untitled
Press return to start formatting floppy. .................................................................
```

```
castle%
```
