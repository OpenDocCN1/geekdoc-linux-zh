# csh 217

The list of directories to search for commands. path is initialized from the environment variable PATH, which the C shell updates whenever path changes. A null word specifies the current directory. The default is typically (/usr/bin .). If path becomes unset, execute only full names. An interactive C shell normally hashes the contents of the directories listed after reading .cshrc and whenever path is reset. If new commands are added, use the rehash command to update the table.

path

The string an interactive C shell prompts with. Noninteractive shells leave the prompt variable unset. Aliases and other commands in the .csh file are used only interactively can be placed after the following: 'if ($prompt == 0) exit'; to reduce startup time for noninteractive shells. A ! in the prompt string is replaced by the current event number. The default prompt is hostname# for mortals, or hostname for supervisor.

prompt

The file in which the C shell resides. This variable is used in forking shells to interpret files that have execute bits set but are not executable by the system.

shell

The status returned by the most recent command. If that command terminated abnormally, 0200 is added to the status. Built-in commands that fail exit status 1; all other built-in commands set status to 0.

status

Control automatic timing of commands. Can be supplied with one or two values. The first is the reporting threshold in CPU seconds. The second is a string of tags text indicating which resources to report on. A tag is a percent sign (%) followed by a single, uppercase letter (unrecognized tags will print as text):

time

+   - %D
Average amount, in kilobytes, of unshared data space used.
- %E
Elapsed (wall clock) time for the command.
- %F
Page faults.
- %I
Number of block input operations.
