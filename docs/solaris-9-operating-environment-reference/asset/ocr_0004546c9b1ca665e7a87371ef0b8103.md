# Environment Variables

The default environment variable name is UNZIP for all operating systems except VMS. For VMS systems, the environment variable is UNZIP_OPTS because the symbol used to install unzip as a foreign command would otherwise be confused with the environment variable. For compatibility with zip, UNZIPOPTS is also accepted (don't ask). If both UNZIP and UNZIPOPT are defined, UNZIP takes precedence. You can use the unzip diagnostic option (-v with no file name) to check the values of all unzip and zipinfo variables, as shown in the following

```
castle$ -v
Unzip 5.32 of 3 November 1997, by Info-Zip. Maintained by Greg Roelofs. Send bug reports to the authors at Zip-Bugs@wku.edu; see README for details.
```

Latest sources and executables are at http://cdrom.com/pub/infozip/, as of above date; see http://www.cdrom.com/pub/infozip/Unzip.html for other sites.

Set the time variable (TZ) according to the local time so that the -f and -u options operate correctly. This variable may also be needed to correct timestamps on extracted files. Under Windows 95/NT, unzip should know the correct time zone even if TZ is unset, assuming the time zone is correctly set in the Control Panel.

You can modify unzip default by putting options in the UNZIP environment variable. You can use any option; however, this feature is most useful with the following modifiers to perform the following modifications.

+   - Autoconvert text files by default (-).
- Convert file names from uppercase to lower case (-L).
- Match cases insensitively (-C).
- Make unzip quieter (-q).
- Always overwrite or never overwrite files as they are extracted (-o or -n).
