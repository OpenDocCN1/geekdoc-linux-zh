# nm — Print Name List of an Object File

# Synopsis

```
/usr/ccs/bin/nm [-ACDhlnPprRsTuVv] [-efof] [-g] [-u] [-t format] file...
/usr/xpg4/bin/nm [-ACDhlnPprRsTuVv] [-efof] [-g] [-u] [-t format]
file...
```

# Description

The nm command displays the symbol table of each ELF file that is specified by file.
If no symbolic information is available for a valid input file, the nm command reports that fact but does not consider it an error condition.

# Options

You can specify options in any order, either single or in combination, and you can put them anywhere on the command line. When specifying conflicting options (such as -v and -n; and -o and -x) the first is taken and the second ignored with a warning message. (See -R for exception.)

+   -A Write the full path name or library name of an object on each line.
-C Demangle C++ symbol names before printing.
