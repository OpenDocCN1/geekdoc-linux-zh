Note — Following this command, the file permission bits are set to
rwx-----

Even though the file-owning group has only read permission, the maximum permissions available to all additional user ACL entries and all group ACL entries are read and write because the mask entry specifies these permissions.

The following example sets the same ACL on file bar as the file foo.

```
castle% getfac foo | setfacl -f - bar
castle% getfac bar
```

```
# file: bar
# owner: winsor
# group: staff
user::rwx
user:ray:rw-
group::r--nmask:rw-
other----\castle::
```

```
#effective:rw-
#effective:r--
```

# New setpgrp — Set Process Group ID

# Synopsis

```
/bin/setpgrp command [arg...]
```

# Description

Use the setgrp command, new in the Solaris 9 Operating Environment, to set the
process ID. If the current process is not already a session leader, the setpgrp
command sets the process group ID and session ID to the current process ID and does an
exec() of command and its argument(s) if any.
