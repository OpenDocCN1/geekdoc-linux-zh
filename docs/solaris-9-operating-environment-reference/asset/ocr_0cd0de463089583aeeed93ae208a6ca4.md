# nistbladm — Administer NIS+ Tables

# Synopsis

```
/usr/bin/nistbladm -a|-A [-D defaults] colname=value... tablename
/usr/bin/nistbladm -a -A [-D defaults] indexname
/usr/bin/nistbladm -c [-D defaults] [-p path] [-s sep] type
classname=[flags] [access...] tablename
/usr/bin/nistbladm -d tablename
/usr/bin/nistbladm -e|E colname=value... indexname
/usr/bin/nistbladm -m colname=value... indexname
/usr/bin/nistbladm -r -R [colname=value...] tablename
/usr/bin/nistbladm -r -R indexname
/usr/bin/nistbladm -u [-p path] [-s sep] [-t type] [colname=access...]
tablename
```

# Description

Use the nistbladm command to administer NIS+ tables. It performs five operations:

+   * Creating tables.
* Deleting tables.
* Adding entries to tables.
* Modifying entries within tables.
* Removing entries from tables.

Although NIS+ does not place restrictions on the size of tables or entries, the size of data has an impact on the performance and the disk space requirements of NIS+ server. NIS+ is not designed to store huge pieces of data as files.

NIS design is optimized to support 10,000 objects with a total size of 10 megabytes. If the requirements exceed the above, it is suggested that you create the domain hierarchy or store pointers to the data in the tables instead of storing the data itself.

When creating tables, you must specify a table type, type=, and a list of column definitions.
