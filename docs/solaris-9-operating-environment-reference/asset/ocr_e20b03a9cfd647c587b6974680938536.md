# Examples

The following example converts colons in the passwd file to Tabs. Notice that you enclose the Tab character in single quotes to prevent the shell from treating it as white space. In this example, the Tab character is represented as the word Tab. When you type the command line, simply press the Tab key. Also notice that you use the < redirection symbol to specify the file name as to input to the tr command.

```
castle tr : 'Tab' < passwd
root      x 0          Super-User             / /sbin/sh
daemon   x 1                               /usr/bin
bin      x 2
sys      x 3
adm      x 4          Admin       /var/adm
l       x 71 8      Line Printer Admin      /usr/spool/lp
uuccp   x 5          uucp Admin             /usr/lib/uucp
uuccp   x 9          uucp Admin             /var/spool/uucpublic
/usr/lib/uucp
listen   x 37         Network Admin           /usr/net/nls
nobody   x 60001 60001 Nobody             / No Access User /
nobody4  x 65534 65534 SunOS 4.x Nobody. /
winsor   x 1001                   /export/home/winsor /bin/csh
ray      x 1002                   /export/home/ray /bin/csh
des      x 1003                   /export/home/des /bin/csh
rob      x 1004                   /export/home/rob /bin/csh
castle$
```

The following example creates a list of all words in kookaburra-1, one per line, in kook.out where a word is taken to be a maximal string of letters.

```
castle tr -cs "[:alpha:]" "[\n]*" < kookaburra-1 > kook.out
castle@ cat kook.out

sits
in
old
gum
tree
Merry

king
of
the
bush
is
he
... (More lines not shown here)
castle$
```

The following example translates all lowercase characters in fileto to upper case and writes to standard output.

```
castle@ tr "[:lower:]" "[:upper:]" < kookaburra-1
KOOKABURRA SITS IN THE OLD GUM TREE
```
