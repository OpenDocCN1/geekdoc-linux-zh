# Pattern Matching

This section applies only to UNIX for details on MS-DOS and VMS operation.

The UNIX shells (sh(1) and csh(1)) do file-name substitution on command arguments. The special characters are listed below:

+   ? Match any character.
* Match any number of characters (including none).
[] Match any character in the range indicated within the brackets (example: [a-z], [0-9]).

When characters are encountered (without being escaped with a backslash or quotes), the shell looks for files that match the pattern and replaces the argument with a list of the names that matched.

The zip program does the same matching on names that are in the zip archive being modified or, in the case of the -x (exclude) or -i (include) options, on the list of files to be operated on, using backslashes or quotes to tell the shell not to do the name expansion.

In general, when zip encounters a name in a list of files to, zip first looks for the name in the file system. If it finds the name, the name is added to the list of files. If zip does not find the name, it looks for the name in the zip archive being modified (if the archive exists), for each match, zip adds name to the list of files to be processed unless this name matches one with the -x option or does not match any name specified with the -i option.

The pattern matching encounters the path, patterns like \*.o matches names that in .o, no matter what the path prefix is. Note that before special character (for example, ?) you must enclose the entire name in double quotes ("). In general, use backslash to make zip the pattern matching with the -f (freshen) and -d (delete) options and sometimes after the -x (exclude) option, used with an appropriate option (add, -f, -d).

# Environment Variables

| ZIP | Contains default options that are used when running zip. |
| ZIP | [Not on RISC OS and VMS] See ZIPOPT. |
| ZipOptions | [RISC] See ZIPOPT. |
| ZipExts | [RISC] Contains extensions separated by a : that add native file names with one of the specified extensions to the zip file with basename and extension swapped.
| ZIP_OPTS | [VMS] See ZIPOPT. |
