If you specify no audio format, cdw tries to understand the audio file format based on the file extension. The case of the characters in the extension is ignored. If you specify a format with the -T option, it is assumed as the audio file type for all the files specified. Also, cdr closes the session after writing the audio tracks. Therefore, you should specify the tracks to be written in a single command line.

# Extracting Audio

You can use cdw to extract audio data from an audio CD with the -x option. The CD should have tracks in Red Book CDDA form. By default, the output format is based on the file extension. You can specify a sun, wav, cda, or any output format with the -T option.

# Copying CDs

You can use cdw to copy single session CD-ROMs and Red Book audio CDs. For copying a CD, cdw looks for a specified source device. If you specify no source device with the -c option, the current CD writing device is assumed to be the source. cdw extracts the track or tracks into a temporary file and looks for a blank writable CD-R/RW in the current CD writing device. If no medium is found, you are asked to insert a blank writable CD in the current CD writing device. If enough space is not available in the default temporary directory, you can specify an alternative directory with the -m option.

# Erasing CD-RWdisc

You have to erase the CD-RWdisc before it can be rewritten. With the -b option, the following flavors of erasing are currently supported.

+   - session Erase the last session.
- all Erase the entire CD.

If you use the session erasing type, cdw erases the last session. If only one session is recorded on the CD-RW (for example, a data/audio CD-RW created by this tool), session erasing is useful because it erases only the portion that is recorded, leaving behind a blank disc, which is faster than erasing the entire disc.

Use the all erasing type for a multisession disc, if the last session is not closed or if the disc status is unknown and you want to erase the disc. With this type of erase, cdw erases the entire disc.

# Checking device-list or media-status

You can display a list of CD writing devices currently present in the system with the -l option. Also, for a particular disc, you can display the blanking status and table of contents with the -M option. The -M option prints information about the last session start address and the next writable address. You can use this information, along with the -O option, to create multisession CDs. Please refer to mkis(1) for more information.
