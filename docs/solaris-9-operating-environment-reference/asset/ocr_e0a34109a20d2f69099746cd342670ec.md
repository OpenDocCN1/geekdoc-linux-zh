Pop the top of the stack, and use that value as a nonnegative scale factor: print the appropriate number of places on output, and maintain during multiplication, division, and exponentiation. The interaction of scale factor, input base, and output base are reasonable if all are changed together.

Push the current scale factor on the top of the stack.

The stack level is pushed on the stack.

Replace the number on the top of the stack with its length.

Take a line of input from the input source (usually the terminal) and execute it.

Display dc debugging information.

Used by bc(1) for array operations.

# Examples

The following example prints the first ten values of n!. First we create a file named examples that contains the following three lines.

```
[al+dsa*pla10>y]
s0sal
lyx
```

When you run the command, the first ten values of n! are displayed.
