# pgrep, pkill — Find or Signal Processes

# Synopsis

```
/usr/bin/pgrep [-fnvx] [-d delim] [-P ppid] [-g pgreplist]
-s sidlist [-u euid] [-U uidlist] [-G gidlist] [-J projidlist]
-t termlist [-T tasklist] [pattern]
/usr/bin/pkill [-signal] [-fnvx] [-P ppid] [-g pgreplist]
-s sidlist [-u euid] [-U uidlist] [-G gidlist] [-J projidlist]
-t termlist [-T tasklist] [pattern]
```

# Description

The pgrep command examines the active processes on the system and reports the process IDs of the processes which matches the criteria specified on the command line. Each PID is printed as a decimal and is separated from the next ID by a delimiter string, which is a newline by default.
