(s)r Read the contents of file into the buffer. If you do not specify file, use the currently remembered file name if any (see the e and f commands). Leave the currently remembered file name unchanged unless file is the very first file name mentioned since it was invoked. Address 0 is legal for r and reads the file at the beginning of the buffer. If the read is successful and you did not specify the -s option, write to output the number of characters read in the following format.

%d\n, <number of bytes read>
Set the current line (.) to the last line. If you replace file with !, take the rest of the line to be a shell command (see sh(1)) whose output is to be read. For example, sr !! appends the current directory to the end of the file being edited. A shell command is not remembered as the current name.

(...) s/RE replacement/q
(...) s/RE replacement/1
(...) s/RE replacement/n
(...) s/RE replacement/

Substitute by searching each addressed line for an occurrence of the specified RE You can specify zero or more substitution commands. In each line in which a match is found, replace all (nonoverlapping) matched strings by the replacement if you use the global replacement indicator g after If you do not use the global indicator, replace only the first occurrence of the matched string. If you specify a count after the command, replace only the count-th occurrence if the substitution fails on all addressed lines. You can use any character other than space or newline instead of the slash/) to delimit the RE and the replacement. Leave the current line (.) at the last line where a substitution occurs. Within the RE you can use the RE itself as a literal character preceding it with a backslash.

Replace the ampersand (&) in the replacement with the string matching the RE on the current line. You can escape the meaning of & in this context by preceding it with a backslash. As a more general feature, replace the characters \n where n is the nth regular expression of the specified RE enclosed within \( and \). When you nested parenthesized subexpressions, n is determined by counting occurrences of \( starting from the left. When the character % is the only character in the replacement, use the replacement used in the most recent substitute command as the replacement in the current substitute command; if there was no previous command, the use of % in this manner is an error. The % loses its special meaning
