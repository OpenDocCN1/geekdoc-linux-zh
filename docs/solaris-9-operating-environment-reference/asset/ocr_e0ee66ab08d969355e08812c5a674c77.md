# unzip

The following example extracts the binary file paper1.dvi to standard output and
pipes to a printing program.

```
castle$ unzip -p articles paper1.dvi | lp
request id is sechild-3 (standard input)
caste$
```

The following example extracts all FORTRAN and C source files-*.f, *.c, *.h, and
Makefile-into the /tmp directory.

```
castle$ unzip source.zip "*.fch" Makefile -d /tmp
```

Note — The double quotes are needed only in UNIX and only if globbing
turned on.

The following example extracts all FORTRAN and C source files, regardless of case
(that is, both *.c and *.C, and any makefile, Makefile, Makefile, or similar
capitalization form).

```
castle$ unzip -C source.zip "*.fch" make -d /tmp
```

The following example extracts all FORTRAN and C source files, regardless of case
(that is, both *.c and *.C, and any makefile, Makefile, Makefile, or similar form),
converts any uppercase MS-DOS or VMS names to lower case, and converts the line
ends of all the files to the local standard (without respect to any files that might be
marked binary).

```
castle$ unzip -aaCl source.zip "*.fch" make -d /tmp
```

The following example extracts only newer versions of the files already in the current
directory, without querying.

```
castle$ unzip -fo sources
```

> Note — Be careful of unzipping in one zone a file that was created in
another time. ZIP archives other than those created by Zip 2.1 or later
contain no time zone information, and a newer file from an Eastern time
zone may be, fact, older.

The following example extracts newer versions of the files in the current
directory and creates any files not already there (same caveat as the previous
example).

```
castle$ unzip -uo sources
```

In the following examples, assume that UNZIP or UNZIP_OPTS is set to -q. The
following example does a single zip listing.

```
castle$ setenv -qq
castle$ unzip -1 letters.zip
2003 02-18-99 08:44 letters.rtf
caste$
```

The following example does a double quiet listing.

```
castle$ setenv UNZIP -qq
castle$ unzip -ql letters.zip
```
