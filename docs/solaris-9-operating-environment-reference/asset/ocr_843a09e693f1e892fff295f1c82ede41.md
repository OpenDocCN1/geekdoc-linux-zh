# cu — Call Another UNIX System

# Synopsis

```
/usr/bin/cu [-c device | -1 line] [-s speed] [-b bits] [-h] [-n] [-t]
[-o] | -e] [-L] [-C] [-H] telno|systemname [local-cmd]
```

# Description

cu calls up another UNIX system, a terminal, and possibly a non-UNIX system. It manages an interactive conversation with possible transfers of files. It is convenient to think of cu as operating in two phases. The first phase is the connection phase in which the connection is established. cu then enters the conversation phase. The -d option is the only one that applies to both phases.
