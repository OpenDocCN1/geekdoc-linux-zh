# function — Shell Built-in Command to Define a Shell Function

# Synopsis

```
ksh
function identifier { list; }
identifier() { list; }
```

# Description

# Korn Shell

function defines a function that is referenced by identifier. The body of the function is the list of commands within the curly braces {}.

Alternatively, you can define a function by omitting the function keyword and appending the identifier with a set of enclosed parentheses.

# Examples

The following example creates a function called status() that returns the name of your current working directory and then lists it.

```
$ status() { cd $*; pwd;ls; }
$
$ functions
function status
{
cd $*; pwd;ls; }
$
$ status /home
/home
TT_DB bill last+found
$ 
```

The following example creates a function called scp() for safe copy. It prevents from overwriting an existing file. When you issue the same command twice, the second command is not executed and the scp() function displays an error message.

```
$ scp()
>
> if test ! -s "$2"
```
