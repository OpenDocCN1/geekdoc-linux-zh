# Examples

The following example displays the version definitions of libelf.so.1.

```
castelf pvs -d /usr/lib/libelf.so.1
libelf.so.1;
SUNW_1.2;
SUNW_1.1;
SUNW_0.7;
SUNW_private.1.1;
```

```
castelf
```

The following example uses the -n and -o options to produce a normalized, one-line display suitable for creating a mapfile version-control directive.

```
castelf pvs -don /usr/lib/libelf.so.1
/usr/lib/libelf.so.1 - SUNW_1.2; /usr/lib/libelf.so.1 -
SUNW_private_1.1;
```

```
castelf
```

The following example displays the version requirements of ldd and pvs.

```
castelf pvs -r /usr/bin/ldd /usr/bin/pvs
/usr/bin/ldd:
libelf.so.1 (SUNW_1.2);
ibc.so.1 (SUNW_1.1);
```

```
libelf.so.1 (SUNW_1.2);
ibc.so.1 (SUNW_1.1);
```

```
castelf
```

# Exit Status

If the requested version information is not found, a non-zero value is returned,
otherwise, a 0 value is returned.

Version information is not found when any of the following is true:

+   * You select the -d option, and no version definitions are found.
* You specify the -r option, and no version requirements are found.
* You specify neither the -d nor -r option, and no version definitions or requirements are found.
