# plot — Graphics Filters for Various Plotters

# Synopsis

```
/usr/ucb/plot [-Terminal]
```

# Description

The plot command reads plotting instructions (see plot(4B)) from the standard input and produces on the standard output plotting instructions suitable for a particular terminal.

If you do not specify a terminal, the environment variable TERM is used. The default terminal is tek.
