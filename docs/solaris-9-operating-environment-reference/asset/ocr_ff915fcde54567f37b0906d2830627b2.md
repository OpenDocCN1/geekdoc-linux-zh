Done (code) The job completed normally and it exited with the specified non-zero exit status, code, expressed as a decimal number.

Stopped (SIGTSTP)

Stopped (SIGSTOP)

The job was suspended by the SIGSTOP signal.

Stopped (SIGTIN)

The job was suspended by the SIGTIN signal.

Stopped (SIGTTO)

The job was suspended by the SIGTTO signal.

The implementation may substitute the string Suspended in place of Stopped. If the job was terminated by a signal, the format of state is unspecified, but it is visibly distinct from all the other state formats shown here and indicates the name or description of the signal that terminated the job.

command The associated command that was given to the shell.

If you specify the -l option, a field containing the process group ID is inserted before the state field. Also, more processes in a process group may be output on separate lines, using only the process ID and command fields.

For jsh and ksh, if you specify the -p option, the output consists of one line for process ID. The following jsh example lists two jobs.

```
$ jobs
[1] - Running spider
[2] + Done (0) find -name core -print
$ 
```

Bourne Job Control Shell
The Bourne job control jsh provides all of the functionality of sh in addition to the built-in job commands. Typically, you use jsh only as an interactive shell; noninteractive shells typically do not benefit from the additional functionality of job control.

The jsh built-in command reports all jobs that are stopped or executing in the background. If you use %job-id the jsh command reports reports all jobs that are stopped or running in the background. The following options modify or enhance the output of jobs.

+   -1 Report the process group ID and the working directory of the jobs.

+   -p Report only the process group ID of the jobs.

+   -x Replace any job-id in command or arguments with the corresponding process group ID, and execute command, passing its arguments.
