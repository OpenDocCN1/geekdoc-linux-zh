# cc 125

-Ldir Add dir to the list of directories searched for libraries by
/usr/ccs/bin/ubcc. Pass this option to /usr/ccs/bin/ld and
/usr/ccs/lib. Search directories specified with this option before
/usr/ucblib and /usr/lib.

-Y P, dir Change the default directory used for finding libraries. Note that this
option may have unexpected results and should not be used.

# Exit Status

+   0 Successful compilation or link-edit.
>0 An error occurred.
