+   -f Follow all children created by fork(), and print output on each child process. This option also outputs a PID on each trace output.
-F bindfromlist Specify a colon-separated list of libraries that are to be traced. Trace only calls from these libraries. The default is to trace calls from the main executable only.
-o outputfile Direct output to the outputfile. If you combine this option with the -f, then the PID of the executing program is put at the end of the file name. By default, output goes to standard error.
