# pkginfo — Display Software Package Information

# Synopsis

```
/usr/bin/pkginfo [-q | -x | -l] [-p] [-i] [-r] [-a arch] [-v version]
[-c category ...] [pkginst...]
/usr/bin/pkginfo [-d device] [-R root-path] [-q | -x | -l] [-a arch]
[-v version] [-c category...] [pkginst...]
```

# Description

Use the pkginfo command to check which packages are installed on a system (with the first synopsis). By default, pkginfo displays information about currently installed packages. You can also use the pkginfo command to display packages that are mounted distribution media or that reside in a particular directory (with the second synopsis).

Without options, pkginfo lists the primary category, package instance, and names of all completely installed and partially installed packages. It displays one for each package selected.

# Options

> Note - The -p and -i options are meaningless if used in conjunction with the -d option. The options -q, -x, and -l are mutually exclusive.

- - arch Specify the architecture of the package as.
- -c category Display packages that match category. Categories are defined with the CATEGORY parameter in the pkginfo(4) file. If you supply more than one category; the package needs to match only one category in the list. The list is not case specific.
- -d device Define a device, device, on which the software resides. device can be an absolute directory path name or the identifiers for tape, diskette, removable disk, and so forth. You can use the special token spool to indicate the default installation spool directory (/var/spool/pkg).
- -i Display information only for fully installed packages.
- -l Specify long format, which includes all available information about the designated package(s).
- -p Display information only for partially packages.
- -q Do not list any information. Use from a program to check whether or not a package has been installed.
- -r List the installation base for relocatable packages.
- -R root-path Define the full name of a directory to use as the root-path. All files, including package system information files, are relocated to a directory tree starting in the specified root-path.
- -v version Specify the version of the package. You define the version with the VERSION parameter in the pkginfo(4) file. You can request all compatible versions by preceding the version with a tilde (-). Replace multiple white spaces with one white space during version comparison.
- -x Designate an extracted listing of package information. The listing contains the package abbreviation, package name, package architecture (if available), and package version (if available).

# Operands

- pkginst Specify a package designation by its instance. An instance can be the package abbreviation or a specific instance (for example, inst.1 or inst.2). You can request all instances of a package with inst.*

The asterisk (*) is a special character to some shells and may need to be escaped. In the C shell, * must be surrounded by single quotes ('''') or preceded by a backslash (\).

# pkginfo — Produce an Installable Package

# Synopsis

```
/usr/bin/pkginfo [-o] [-a arch] [-b base_dir] [-d device] [-f prototype] [-l limit] [-p] [-r root-path] [-v version]
[-c category ...] [pkginst...]
```

# Description

Use the pkginfo command to produce an installable package from a prototype file. The command uses the prototype(4) file as input. If the output file is a directory or a mountable device, pkgmk uses the df(1M) command to dynamically calculate the amount of available space on the output device. This option is useful in conjunction with pkgtrans(1) to create a package with a datastream format.

> Note - If you create your prototype with the following, the following conditions apply:
> 1. If you specify -b nor -r, pkgmk expects to find in /base_dir.
> 2. If you specify -r as a relative path, then base_dir is prepended.
> 3. If you specify -r as an absolute path (with a leading /), then base_dir is not used.
> 4. If you specify -b as an absolute path, then root_path is the base_dir.
> 5. If you do not specify base_dir, the default is "".

# Options

- -a arch Override the architecture information provided in the pkginfo(4) file with arch.
- -b base_dir Prepend the indicated base_dir to the relative paths in the prototype file. Use this option to search for all objects in the prototype file.
- -d device Create the package on device, device can be an absolute directory path name or the identifiers for a diskette or removable disk (for example., /dev/diskette). The default device is the installation pool directory (/var/spool/pkg).
- -f prototype Use the file prototype as input. The default prototype name is Prototype.
- -l limit Specify the maximum size in 512-blocks of the output device as limit. If the output file is a directory or a mountable device, pkgmk uses the df(1M) command to dynamically calculate the amount of available space on the output device.
- -o Overwrite the same instance of the package if it already exists.
- -p pstamp Override the production stamp definition in the pkginfo(4) file with pstamp.
- -r root-path Ignore destination paths in the prototype(4) file. Instead, use the indicated root-path with the source path name appended to locate objects on the source machine.
- -v version Override the version information provided in the pkginfo(4) file with version.

variable=value Place the indicated variable in the packaging environment. (See prototype(4) for definitions of variable specifications.)
