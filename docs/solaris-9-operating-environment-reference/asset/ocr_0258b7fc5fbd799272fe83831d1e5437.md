in the middle or at the bottom of the window from now on. Use the t suffix to restore the
original situation.

You can modify the perusal environment with the following commands:

+   - Begin perusing the f-th next file in the command line. The f is an
unigned number; default is 1.

+   - Begin perusing the f-th previous file in the command line. If f is
unsigned number; default is 1.

+   - Display another window of text. If f is present, the window size to f.
- Save the input in the named file. Save only the current file being
perused. The white space between the s and filename is optional. You
always terminate this command with a newline, even if you
specify the -n option.

+   - Help by displaying an abbreviated summary of available commands.

+   - Quit.
- Pass command to the shell specified in the SHELL environment variable.
If this is not available, use the default shell. You must always
terminate this command with a newline, even if you specify the -n
option.

You can use the quit key (normally Control-\) or the interrupt (BREAK) key at anynto stop sending output and display the prompt. You can then enter one of the above
commands in the normal manner. Unfortunately, some output is lost when this is done
because any characters waiting in the terminal's output queue are flushed when the quit
s occurs.

If the standard output is not a terminal, then pg acts just like cat(1), except that
header is printed before each file (if there is more than one).

# Environment Variables

See environ(5) for descriptions of the following environment variables that affect the
execution of pg: LC_TYPE, LC_MESSAGES, and NLSPATH.

The following environment variables also affect the execution of pg.

+   - COLUMNS Determine the horizontal screen size. If unset or null, use the value of
TERM, the window size, baud rate, or some combination of these, to
indicate the terminal type for the screen size calculation.

+   - LINES Determine the number of lines to be displayed on the screen. If unset or
null, use the value of TERM, the window size, baud rate, or some
combination of these, to indicate the terminal type for the screen size
calculation.
