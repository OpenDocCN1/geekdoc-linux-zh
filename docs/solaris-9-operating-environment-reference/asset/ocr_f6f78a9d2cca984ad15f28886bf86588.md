# tset, reset

The following example includes calls made to functions in the C library from within
The C library itself.

```
example$ truss -u libc:...
```

The following example traces all user-level calls made to any library other than the C
library.

```
$ truss -u '*' -u libc...
```

The following example traces all user-level calls to functions in the printf and scanf
family contained in the C library.

```
$ truss -u libc:*printf, scanf*...
```

The following example traces every user-level function call from anywhere to
anwhere.

```
$ truss -u a.out -u ld:- -u :...
```

The following example verbely traces the system call activity of process #1,
init(1) (if you are superuser).

```
# truss -p -v all 1
```

Interrupting truss returns init to normal operation.
