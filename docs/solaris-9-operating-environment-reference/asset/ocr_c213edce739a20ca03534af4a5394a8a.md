# sccs-rmdel, rmdel — Remove a Delta from an SCCS File

# Synopsis

```
/usr/sccs/bin/rmdel -rsid .filename...
```

# Description

Use the rmdel command to remove the delta specified by the SCCS delta ID (sid) supplied with the -r option. The delta to be removed must be the most recent (leaf) delta in its branch. In addition, the sid must not be that of a version checked out for editing: it must not appear in any entry of the version lock file (p.file).

If you created the delta or if you own the file and directory and have write permission, you can remove it with rmdel.

If you use a directory in place of the .filename argument, the rmdel command applies to all s. files in that directory. Unreadable s. files produce an error: processing continues with the next file (if any). The use of a dash (-) as the s.filename argument indicates that the names of files are to be read from the standard input, one s. file per line.

# Options

+   -rsid Remove the version corresponding to read the indicated sid(delta).

# Files

+   p.file Permissions file.
s.file History file.
