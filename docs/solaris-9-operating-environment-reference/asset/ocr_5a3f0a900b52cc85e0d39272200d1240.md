# Command- and File-name Substitutions

Command- and file-name substitutions are applied selectively to the arguments of built-in commands. Portions of expressions that are not evaluated are not expanded. For non-built-commands, file-name expansion of the command name is done separately from that of the argument list; expansion occurs in a subshell if I/O redirection is performed.

# Command Substitution

A command enclosed by backquotes (`...`) is performed by a subshell. Its standard output is broken into separate words at each space character. Tab, and newline; null words are discarded. This text replaces the backquoted string on the current command line. Within double quotes, only newline characters force new words; space and Tab characters are preserved. However, a final newline is ignored. It is therefore, for a command substitution to yield a partial word.

# File-name Substitution

Unquoted words containing any of the characters *, ?, [, or ( that begin with ~ are expanded (also known as globbing) in an alphabetically sorted list of file names, as follows:

+   * Match (0 or more) characters.
? Match any single character.
[...] Match any single character in the enclosed list(s) or range(s). A list is a string of characters. A range is two characters separated by a dash (-) and includes all the characters in the ASCII collating sequence (see ascii5).

```
$ str, str, { ... } Expand to each string (or file-name-matching pattern) expressions above, the comma-separated list. Unlike the expansion of this is not sorted. For instance, {b,a} expands to b,a (not a b). As special cases, the characters { and ), with the string {}, are passed undisturbed.
```

```
~user] Your home directory, indicated by the value of the variable home, or that of user; as indicated by the password entry for user.
```

Only the patterns *, ?, and [...] allow pattern matching; an error results if no file matches a pattern that contains them. The dot character (.) must be matched explicitly when it is the first character in a file-name or pattern-name component. The slash/) must also be matched explicitly.
