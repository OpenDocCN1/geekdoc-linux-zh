-z filename
true if filename is 0 length (empty).

-f filename
true if filename is a plain file.

-d filename
true if filename is a directory.

If filename does not exist or is inaccessible, then all inquiries return false.
An inquiry as the success of a command is also available:

+   (command) command runs successfully, the expression evaluates to true, 1.
Otherwise, it evaluates to false, 0. (Note: Conversely, command itself
typically returns 0 when it runs successfully, or some other value if
entounters a problem. If you want to get the status directly, use the
value of the status variable instead of this.)

# Control Flow

The shell contains a number of commands to regulate the flow of control in scripts and,
within limits, from the terminal. These commands operate by forcing the shell either
eread input (to loop) or skip input under certain conditions (to branch).
Each occurrence of a foreach, switch, while, if...then, or else built-in command
must as the first word on its input line.

If the shell's input is not seekable and a loop is being buffered, the input is buffered.
The shell performs seeks within the buffer to accomplish the rereading implied
the loop. (To the extent that this action allows, backward goto succeeds on
onseekable inputs.)

> Note — Commands within loops, prompted for ?, are not placed in the
history list.

# Command Execution

If the command is a C shell built-command, the shell executes it directly. Otherwise,
thell searches for a file by name with execute access. If the command
contains /, the shell takes it as a path name and searches for it. If the command
does not contain /, the shell attempts to resolve it to a path name, searching
directory in the path for the command. To speed the search, the shell uses its
hash table (the rehash-command) to eliminate directories that have no
applicable files. You can disable this hashing with the -c or -t options or by using the\unset built-command.

As a special case, if there is no / in the name of the script and there is an alias for
word, the expansion of the shell alias is prepended (without modification) to
tcommand line. The system tries to execute the first word of this special (late-occurring)
alias, which should be a full path name. Remaining words of the alias's definition,
with the text of the input line, are treated as arguments.
