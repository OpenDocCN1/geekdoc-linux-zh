# Environment Variables

See environ(5) for descriptions of the following environment variables that affect the execution of direcmp: LC_COLLATE, LC_TYPE, LC_MESSAGES, and NLPATH.

# Exit Status

+   * 0 Successful completion.
* >0 An error occurred. (Differences in directory contents are not considered errors.)
