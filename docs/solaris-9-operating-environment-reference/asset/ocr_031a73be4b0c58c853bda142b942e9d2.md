# Diagnostics

On termination, each command returns two bytes of status, one supplied by the system and giving the cause for termination, and (in the case of "normal" termination) one supplied by the program [see wait(3B) and exit(2)]. The former byte is 0 for termination; the latter is customarily 0 for successful execution and non-zero to indicate troubles such as erroneous parameters, or bad or inaccessible data. It is called variously "exit code,"exit status," or "return code," and is described only when special conventions are involved. In this book, the Exit Status section for each command describes the values returned on command termination.

# Warnings

Some commands produce unexpected results when processes containing null characters. These commands often treat text input as strings and therefore become confused on encountering a null character (the string terminator) within a line.
