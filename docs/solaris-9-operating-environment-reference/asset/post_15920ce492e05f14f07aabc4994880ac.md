# cancel — Cancel Print Request

## Synopsis

```
/usr/bin/cancel [request-ID...] [destination...]
/usr/bin/cancel -u username... [destination...]
```

## Description

The cancel command to cancel print requests while they are in the queue or while they are printing. To cancel a specific print request, you need to know the request ID for the print job. The request ID always includes the name of the printer, a dash, and the number of the print request. When a request is submitted from standard input, the request ID is displayed. To find the request ID, type lstat and press Return. Only the user who submitted the request or someone logged in as root or ip can cancel a print request.

You can also use the cancel command in the following ways:

- Cancel a specific print job on a specific printer by specifying the request-ID and destination arguments.
- Cancel all jobs on a specific destination by specifying a destination argument.
- Cancel all requests for a specific user by specifying the -u username option.
- Cancel all requests for a specific user on specific printer by specifying the -u username and destination arguments. Users can cancel only their own print requests. By default, users can only cancel print requests from the host from which the request was submitted. If a superuser has set-equivalence=true in /etc/printers.conf on the print server, users can cancel print requests associated with their username on any host. Supers can also cancel print requests from the host where the request was submitted. The print client commands locate destination information in the printers database name switch file. See nswitch.conf(4), printers(4), and printers.conf(4) for details.![](img/185d23104c385df6a62d4cc96b9)

## Options

- -u username Specify the name of the user for whom print requests are to canceled.

## Operands

- destination Specify the destination on which print requests are to canceled. destination is the name of a printer or class of printers. If you do not specify destination, cancel cancels the requested print using POSIX-style (server:destination), oraming (FNS) (...service/printer/..) The print client commands locate destination information in a specific order. See printers.conf(4) and printers(4) for details. POSIX-style destination names (server:destination) are treated as print requests if destination has the same format as LP-style request-ID.
- request-ID Specify the ID for the print request to be canceled, using LP-style IDs (destination).

## Examples

The following example lists jobs in the print queue and cancels them, using the different options and operands. In the first example, user tries to cancel print jobs owned by ray. The prompt is returned but the jobs are not removed from the queue. Notice that when you do not have permission to cancel a job, the cancel command does not display an error message.

```
castle% lpstat
castle-77      castle|winsor  Sep 29 030
castle-78      castle|winsor  Sep 29 032
castle-79      castle|winsor  Sep 29 033
castle-80      castle|ray    Sep 29 036
castle-81      castle|ray    Sep 29 037
castle-82      castle|root   Sep 29 040
castle% whoami
winsor
castle% cancel -u ray
```

Still as user root, the next example removes winsor's print jobs from the printer destination. Then, user tries to remove a print job owned by root with the request ID.

```
castle% cancel -u winsor seild
castle-77: canceled
castle-78: canceled
castle-79: canceled
castle-80      castle|ray  Sep 29 036
castle-81      castle|ray    Sep 29 037
castle-82      castle|root   Sep 29 040
castle% su
Password:
castle cancel-82: canceled
castle childish
```

In the following example, root removes a print job owned by root and then removes all jobs from the printer destination seild. Notice that when you cancel all of the print jobs for a destination printer, no list of the canceled is displayed, even when there are listed in the queue.

- 0 Successful completion.
- non-zero An error occurred.

# cat — Concatenate and Display Files

## Synopsis

```
/usr/bin/cat [-nbssuvet] [file...]
```

## Description

Use the cat command to create short files, to concatenate two files into a third one, to append one file to the end of another, or to display the contents of file in sequence on the standard output.

The following syntax creates a new named file. Everything that is written to file sends one line at a time to the file after you press Return. You can use the backspace to correct typos on the current line, but you cannot back across lines. When you are finished, type Control-D on a line by itself to terminate the session and close the file. If the file does not exist, it is created. If it already exists, the contents are overwritten with no warning.

```
cat > file
```

The following syntax displays the contents of file on your terminal.

```
cat * file
```

# 121

The following syntax concatenates file1 and file2 and writes the results into file3. If you give no input file, cat reads from the standard input file.
```
cat file1 file2 >file3
```

The following syntax appends the contents of file1 to the end of file2.
```
cat file1 >> file2
```

The following syntax displays the contents of file1, file2, and file3 in sequence y terminal.

> Note — Redirecting the output of cat onto one of the files being read overwrites the data originally in the file without any warning.

## Options

- -n Precede each line output with its line number.
- -b Number the lines, as -n, but omit the line numbers from blank lines.
- -s Be silent about nonexistent files.
- -u Do not buffer the output. (The default is buffered output.)
- -v Display nonprinting (with the exception of Tabs, newlines, and feeds). ASCII control characters (octal 000–037) are printed as ^n, where n is the corresponding ASCII character in the range octal 100–137 (@ A, B, C, ..., X, Y, Z, [, \], ^, and _); the DEL character (octal 0177) is printed ?. Other nonprintable characters are printed as M-x where x is the ASCII character specified by the low-order seven bits.

You can combine the following options with the -v option.

- -e Print a $ character at the end of each line (before the newline).
- -t Print Tabs as ^I and feeds as ^L.

-e and -t options are ignored if you do not specify the -v option.

## Operands

- file A path name of an input file. If no file is specified, use the standard input. If file is -, read from the standard input at that point in the sequence. cat does not close and reopen standard input when it is referenced in this way.

## Usage

See largefile(5) for the description of the behavior of cat when encountering files gre than or equal to 2 Gbytes(**33 bytes).
