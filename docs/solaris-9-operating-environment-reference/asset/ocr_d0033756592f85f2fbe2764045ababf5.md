If the result is an erroneous path name for the remote system, the copy fails. If the destination-file is a directory, the last part of the source-file name is used.

Invoking uucp with shell wild-card characters invokes the uucp command on the remote system. The remote uucp command spools the files on the remote system. After the first session terminates, if the remote system is configured to transfer spoiled files to the local system, the remote system initiates a call and receives the files; the user must "call" the remote system to transfer the files from the directory to the local system. This call can be done manually with utry(IM) or as a side effect of another uux(IC) or uucp call.

Note that the local system must have permission to execute the uucp command on the remote system so that the remote system can send the spoiled files. uucp execute permissions across the transmission and gives 0666 read and write permissions (chmod(2)).
