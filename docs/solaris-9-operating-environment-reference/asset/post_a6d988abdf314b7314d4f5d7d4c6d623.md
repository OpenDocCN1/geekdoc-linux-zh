## Operands

- filename: The name of the file to be read.

## Environment Variables

- XPDISLAY: Used with option -D or -P to determine the X Print Display to which the client connects.
- MP_PROLOGUE: Used to determine the directory in which the page formatting files (.xpr or .ps) are kept. These files determine characteristics such as page decorations, number of logical pages per physical page, and landscape or portrait format. In the absence of MP_PROLOGUE, the default location of the directory is /usr/lib/lp/locale/C/mp.
- MP_LANG: If you specify neither the -D nor -P option, a prologue file called as /usr/openwin/lib/local/locename/print/prolog.ps or /usr/lib/lp/locale/locename/mp/prolog.ps, where locename is the value of the MP_LANG environment variable, if present, is prepended to the output to be printed. If both are present, then prolog.ps is given preference for backward compatibility. If either of these files is not present and you do not specify the -D option, a configuration file of the locale called /usr/lib/lp/locale/locename/mp/mp.conf is used as the source of the configuration information that substitutes the prologue for printing. The prolog.ps disables mp.conf for backward compatibility.

- 0 Successful completion.
- 1 An error occurred.

# mpss.so.1 — Shared Object for Setting Page Size

## Synopsis

```
/usr/lib/lp/locale/C/mp/mpss.so.1
```

## Description

Use mpss.so.1 shared object, new in Solaris Operating Environment, to selectively configure the preferred stack/or heap size for launched processes and their descendants. For mpss.so.1 to be enabled, the following string must be present in the environment along with more MPSS (Multiple Page Support) environment variables:

```
LD_PRELOAD=$LD_PRELOAD:mpss.so.1
```

## Notes

Because of resource constraints, setting the preferred page size does not guarantee that the target processes get the preferred size. Large pages are required to be mapped at addresses that are multiples of the large page. When the heap is typically not large-page aligned, starting portions of heap—below the first large-page address—are mapped with the system page size. The heap and preferred page sizes are inherited. A child process has the same page sizes as its parent. Page sizes are set back to the default system size unless a preferred page size has been configured through mpss shared object. You cannot selectively configure the page size for descendants on the basis of name matches.

## Environment Variables

```
MPSSHEAP=size
MPSTACK=size
```

MPSSHEAP and MPSTACK specify the preferred page sizes for the heap and stack. The specified page size(s) are applied to all created processes. The size must be a supported page size or 0, in which the system selects an appropriate page size. Size can be qualified with K, M, G, or T to convert kilobytes, megabytes, or terabytes.

```
MPSSCFILE=config-file
```

config-file is a file that contains one or more MPSS configuration entries of the following form:

```
exec-name:heap-size:stack-size
```

exec-name specifies the name of an application or executable. The corresponding page size(s) are set for newly created processes that match the first exec-name found in the file. exec-name can be a full path name, a base name, or a pattern string. If heap-size andor stack-size are not specified, corresponding preferred page size(s) are not set. MPSSCFILE takes precedence over MPSSHEAP and MPSTACK.

## Examples

The following example configures preferred page sizes with MPSSCFILE.

```
example$ LD_PRELOAD=$LD_PRELOAD:mpss.so.1
example$ MPSSCFILE=mpsscfg
example$ export LD_PRELOAD MPSSCFILE
example$ cat $MPSSCFILE
foo*:512K:64K
example$
```

Once the application has been started, you can use pmap (see proc(1)) to view the actual page sizes configured.

```
example$ foobar &
example$ pmap -s `pgrep foobar`
```

If the desired page size is not configured (shown in the pmap output), it may be because of errors in the MPSS configuration file or environment variables. Check the error log (default: /var/adm/messages) for errors. If no errors are found, resource or alignment constraints may be responsible.

The following example configures preferred page sizes with MPSSHEAP and MPSSSTACK.

The following Bourne shell commands configure 512K heap and 64K stack preferred page sizes for all applications with the MPSSHEAP and MPSSSTACK environment variables.

```
example$ LD_PRELOAD=$LD_PRELOAD:mpss.so.1
example$ MPSSHEAP=512K
example$ MPSSSTACK=64K
example$ export LD_PRELOAD MPSSHEAP MPSSSTACK
example$
```

The preferred page size configuration in MPSSCFILE overrides MPSSHEAP and MPSSSTACK. Following the following commands to those in the previous example would configure all applications with 512K heap and 64K stack preferred page sizes with the exception of the ls command and all applications beginning with ora, in the configuration file.

```
example$ MPSSCFILE=mpsscfg2
example$ export MPSSCFILE
example$ cat $MPSSCFILE
ls::
ora*:4m:4m
example$
```
