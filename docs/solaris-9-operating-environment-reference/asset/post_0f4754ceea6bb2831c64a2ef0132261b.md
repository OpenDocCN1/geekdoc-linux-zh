# Description

The projects command was introduced in Solaris 8. Starting with the Solaris 9 release, it provides the same functionality as the ps command, but it allows you to manage system resources. When you type the command without options, ps reports all processes associated with the terminal. The output contains only the PID, terminal identifier, cumulative time, and the command name. If you use no options, ps reports all processes associated with the terminal. If there is no controlling terminal, only the headers are printed.

# Options

The most frequently used options for the ps command are listed below.

+ -a List information about all processes except process group leaders and processes not associated with a terminal.

+ -e Report information about all processes now running.

+ -f Show the owner of the process, by name instead of UID, in the first column. This option turns off -1, -t, -s, and -r and turns on -a.
