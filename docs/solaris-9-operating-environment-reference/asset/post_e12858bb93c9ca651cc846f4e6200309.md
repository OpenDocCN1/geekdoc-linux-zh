# sag — System Activity Graph

Synopsis

```
/usr/sbin/sag [-e time] [-f file] [-i sec] [-s time] [-T term] [-x spec]
[-y spec]
```

Description

Use the sag command to graphically display the system activity data stored in a binary data file by a previous sar(1) run. You can plot any of the sar data items singly or in combination, as cross-plots or versus time. You can specify simple arithmetic combinations of data. sag invokes sar and finds the desired data by string-matching the data column header (run sar to see what is available). The sag command requires a graphic terminal to draw the graph, and uses tplot(1) to produce its output. When running Solaris 2.3 and OpenWindows, perform the following steps:

# 1200

# sag

1. As root, type xterm -t and press Return to run xterm as a Tektron terminal.
2. In the xterm window, type sag -T tek options and press Return.

# Options

The following options are passed through to sar.

- -e time Choose data up to time. Default is 18:00.
- - f file Use file as the data source for sar. Default is the current daily data file /usr/adm/sa/sadd.
- - i sec Choose data at intervals as close as possible to sec seconds.
- - s time Choose data later time in the form [hh:mm]. Default is 08:00.

Other options:

- - T term Produce output suitable for terminal term See tplot(1) for known terminals. Default for term seis.
- - x spec Specify the x axis with spec in the form: name(op name)...[lo hi]

name is a string that matches a column header in the sar report with an optional device name in square brackets, for example, r+w/s[disk-1], * or surrounded by blank spaces. You can specify up to five names. Parentheses are not recognized. To comma, + and - have precedence over * and /. Evaluation is left-to-right. Thus, A / B * 100 is evaluated as (A/B)*100, and A + B / C - D is (A+B)/(C-D). D and hi are optional scale limits. If unspecified, they are deduced from the data.

Enclose in double quotes ("") if it includes space.

- - y spec Specify the y axis with spec the same form for -x. If unspecified, you can specify up to five spec arguments separated by a semicolon (;). The default is:
- - y "usr 0 100; %usr + %sys 0 100; %usr + %sys + %wio 0 100

# sar — System Activity Reporter

Synopsis

```
/usr/bin/sar [-aabcdkgmpqruvwy] [-o filename] t [n]
/usr/bin/sar [-aabcdkgmpqruvwy] [-e time] [-f filename] [-i sec]
[-s time]
```

# Description

Use the sar command to view a complete profile of all system activity during an interval. In the first synopsis format, sar samples cumulative activity counters in the operating system at n intervals of t seconds, where t should be 5 or greater. If you specify t with more than one option, all headers are printed and the output can be difficult to read. (If the sampling interval is less than 5, the activity of sar itself may affect the sample.) If you specify the -o option, sar saves the samples in filename binary format. The default value of n is 1.

In the second synopsis format, you specify no sampling interval. Instead, sar extracts the data from a previously recorded file, either specified by the -f option or, by default, the current data file /usr/adm/sa/sadd. You can specify the starting and ending times with the -s and -e options in the format [hh:mm]. The -i option selects the interval in seconds. If unspecified, the default is 10 seconds. The -n option specifies the number of samples to collect; if unspecified, sar reports until the end of the day.

# Options

The following options are passed through to sar.

- - e time Choose data up to time. Default is 18:00.
- - f file Use file as the data source for sar. Default is the current daily data file /usr/adm/sa/sadd.
- - i sec Choose data at intervals as close as possible to sec seconds.
- - s time Choose data later time in the form [hh:mm]. Default is 08:00.

Other options:

- - T term Produce output suitable for terminal term See tplot(1) for known terminals. Default for term seis.
- - x spec Specify the x axis with spec in the form: name(op name)...[lo hi]

name is a string that matches a column header in the sar report with an optional device name in square brackets, for example, r+w/s[disk-1], * or surrounded by blank spaces. You can specify up to five names. Parentheses are not recognized. To comma, + and - have precedence over * and /. Evaluation is left-to-right. Thus, A / B * 100 is evaluated as (A/B)*100, and A + B / C - Dis is (A+B)/(C-D). D and hi are optional scale limits. If unspecified, they are deduced from the data.

Enclose in double quotes ("") if it includes space.

- - y spec Specify the y axis with spec the same form for -x. If unspecified, you can specify up to five spec arguments separated by a semicolon (;). The default is:
- - y "usr 0 100; %usr + %sys 0 100; %usr + %sys + %wio 0 100

# sar — System Activity Reporter

Synopsis

```
/usr/bin/sar [-aabcdkgmpqruvwy] [-o filename] t [n]
/usr/bin/sar [-aabcdkgmpqruvwy] [-e time] [-f filename] [-i sec]
[-s time]
```

# Description

Use the sar command to view a complete profile of all system activity during an interval. In the first synopsis format, sar samples cumulative activity counters in the operating system at n intervals of t seconds, where t should be 5 or greater. If you specify t with more than one option, all headers are printed and the output can be difficult to read. (If the sampling interval is less than 5, the activity of sar itself may affect the sample.) If you specify the -o option, sar saves the samples in filename binary format. The default value of n is 1.

In the second synopsis format, you specify no sampling interval. Instead, sar extracts the data from a previously recorded file, either specified by the -f option or, by default, the current data file /usr/adm/sa/sadd. You can specify the starting and ending times with the -s and -e options in the format [hh:mm]. The -i option selects the interval in seconds. If unspecified, the default is 10 seconds. The -n option specifies the number of samples to collect; if unspecified, sar reports until the end of the day.
