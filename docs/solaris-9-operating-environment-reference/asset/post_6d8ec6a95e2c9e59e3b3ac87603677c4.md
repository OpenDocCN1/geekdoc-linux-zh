The following example removes all files in your home directory named a.out or *.o

```bash
castle$ find $HOME -name a.out -name '*.o' -atime +7 -exec rm {} \;
```

The descriptions of -atime, -ctime, and -mtime use the terminology 24-hour
periods. The midnight boundary between days does not affect the 24-hour calculation.
-atime looks for files that have been accessed, which means files that have been read or
changed or directories that have been listed or indexed. -mtime looks for files that
have been modified, or revised. -ctime looks for files that have been altered in some way, such as being
edited, moved, renamed, -ctime looks for files that have a change in file
status such as a change of owner or a change of group.

The example looks for a file that has been accessed no more than one day
ago.

```bash
find . -atime -1 -print
```

Suppose your disk has been filled up recently and you want to find large files that are less
three days old. With the following example, you search your home directory for files
that are 200c or larger. The c specifies the size in bytes. Without the c, you would be
specifying blocks of 512 kilobytes.

```bash
find $HOME -size 200c -mtime -3 -user winsor -print
```

-mtime -3 option for files modified less than three days ago. To look for files
modified more than three days ago, use -mtime +3. To look for files modified exactly
three days ago, use -mtime 3.

The following example looks for files older than three days but less than six days.

```bash
find $HOME -size 200c -mtime -6 -user winsor -print
```

The following example looks for files owned by winsor not accessed for three or more
days and not modified within 14 days.

```bash
find $HOME (-atime +3 -o -mtime +14) -user winsor -print
```

The following example looks for core files older than seven days and prompts
y to verify that it is OK to remove them.

```bash
find / -name core -mtime +7 -exec rm {} \;
```

In the following example, suppose you have just compiled a package from source code

## finger — Display Information About Local and Remote Users

## Synopsis

```
/usr/bin/finger [-l] [username...]
/usr/bin/finger [-l] [username@hostname...]
/usr/bin/finger [-l] [@hostname...]
```

## Description

By default, the finger command displays in multiline format, the following information about each logged-in user:

- User name.
- User's full name.
- Terminal name (prepended with an asterisk if you write permission is denied).
- Idle time.
- Login time.
- Host name if remotely.

The following example shows the output from the finger command with no arguments.

```
castle% finger
Login             Name            TTY      Idle    Where
winsor             console  Thu 15:38  :0
```

Idle time is displayed in minutes if it is a single integer, in hours and if a colon (:) is present, or in days if present. When you specify one or more username arguments, more detailed information is shown for each user, whether the user is logged in or not. username must be that of a local user and can be first or last name. Information is presented in multiline format follows:

- The user's full name.
- The user's home directory and login shell.
- The terminal from which the user logged in.
- Last time the user received mail and the last time user read mail.
- The first line of the $HOME/.project file if it exists.
- The contents of the $HOME/.plan file if it exists.

 When the comment (GECOS) field in /etc/passwd includes a comma, finger does not display the information following the comma.

The following example shows the output from the finger command with three users specified. None of these users were logged in at the time the command was invoked.

```
castle% finger ray des rob
Login name: ray
Directory: /export/home/ray          Shell: /bin/csh
Last login Nov 25, 1997 on pts/6 from castle
Unread mail since Nov 13 08:37:58 1997
No Plan.
```

```
Login name: des
Directory: /export/home/des          Shell: /bin/csh
Last login Oct 9, 1997 on console from :0
Unread mail
No Plan.
```

```
Login name: rob
Directory: /export/home/rob          Shell: /bin/csh
Never logged in.
Unread mail
No Plan.
castle%
```

If you specify the arguments username@hostname or @hostname, the request is sent to hostname and forwarded through each hostname- to hostname. The program uses the finger information protocol (see RFC 1288) to query the remote host for information about the named user (if you specify a username) or each logged-in user. The information is delivered by server.

As required by RFC 1288, finger passes only printable, 7-bit ASCII data. A system administrator can modify this behavior by using the PASS option in /etc/default/finger. Specifying PASS=low enables all characters less than decimal 32 ASCII. Specifying PASS=high enables all characters greater than decimal 126 ASCII. PASS=low, high or PASS=high, enables both characters less than 32 and greater than 126 to pass.

Note - The finger user information protocol limits the options that can be used with the remote format of this command.

```
castle% finger winsor@castle
Login       Name    TTY      Idle When    Where
winsor      ???     console  Thu 15:38  :0
winsor      ???     pts/3     2 Thu 15:39  :0.0
winsor      ???     pts/4     9 Thu 15:39  :0.0
winsor      ???     pts/5     25 Thu 15:42  :0.0
castle%
```

## Options

- -b Suppress printing of the user's home directory and shell in a short format print.
- -f Suppress printing of the header that is normally printed in a short format print.
- -h Suppress printing of the .project file in a long format print.
- -i Force idle output format, which is similar to short format except print only the login name, terminal, login time, and idle time.
- -l Force long output format.
- -m Match arguments only on user name (not first or last name).
- -p Suppress printing of the .plan file in a long format print.
- -q Force quick output format, which is similar to short format except print only the login name, terminal, and login time.
- -s Force short output format.
- -w Suppress printing of the full name in a short format print.
