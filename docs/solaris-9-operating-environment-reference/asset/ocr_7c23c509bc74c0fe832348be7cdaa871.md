The first number is the offset of the record. The record is enclosed in braces { }. The first column in a record is the slot name (for records whose fields do not have names, it is the name). The second column in a record is the value of slot if it is a scalar (only scalars that are of type tnf_opaque are printed in hexadecimal) or the offset of the record if it is a reference to another.
The third column in a record is index. It does not exist for scalar slots of records. If it exists, the third is a type with or without angle metatag or a string in double quotes. Unnamed names refer to the name of the metatag (that is, a reference to a reference to that name with the tnf_name field). Type names in angle brackets are a reference to that name with the tnf_tag field). The content of strings are printed in double quotes at the reference site.
For records that arrays, their array elements follow the header slots and are numbered 1, 2, ..., except where strings are written as characters (the shown)
For records that events (generated by TNF_PROBES()), the second field has a name of tnf_tag_arg, which is a reference to the schedule record. Records describe more information about the event, such as the thread ID, process ID, and the time_base. You can add the time_delta of an event to the time_base of the schedule record of event to give an absolute value. This time is expressed in nanoseconds since some arbitrary time in the past (see gettime(3)).nThe example presents TNT unsigned arguments in hexadecimal for the file /tmp/trace-2192.
