# 712

login session required /usr/lib/security/pam_unix.so.1
login password required /usr/lib/security/pam_unix.so.1

If the login service has no entries, the entries for the other service are used. If
mult authentication modules are listed, then the user will be prompted for multiple
words.
When login is invoked through rlogind or telnetd, the service name used by PAM
is login or telnet.

# Warnings

Users with a UID greater than 7665844 are not subject to password aging and the
system does not record their last login time.

If you use the CONSOLE setting to disable root logins, you should arrange that remote
command execution by root is also disabled. See rsh(1), rcmnd(3), and hosts.equiv(4)
for further details.

# Options

+   -d device Specify the path name of the TTY login is to operate on. The device
option can improve login performance because login does not need to
call tytname(3C). The -d option is available only to users whose UID
effect UID are root. Any other attempt to use -d exits quietly.

+   -h hostname [terminal]

Pass information about the remote host and terminal type from
telnetd(1M).

+   -p

+   -r hostname

Pass environment variables to the login shell.
Pass information about the remote host from in.rlogind(1M).

# Exit Status

+   0 Successful operation.

+   non-zero Error.
