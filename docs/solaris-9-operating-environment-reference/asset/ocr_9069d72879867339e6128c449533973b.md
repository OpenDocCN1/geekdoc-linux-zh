# hostid — Print the Numeric Identifier of the Current Host

# Synopsis

/usr/bin/hostid

# Description

Use the hostid command to print the identifier of the current host in hexadecimal.

# Example

The following example displays the host ID for the system castle.

```
castle$ hostid
727014d0
castle$ 
```
