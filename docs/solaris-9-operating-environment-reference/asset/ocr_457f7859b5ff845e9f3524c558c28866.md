# ssh-add

The following example examines the private keys currently loaded into the agent.

```
$ ssh-add -l
md5 1024 36:60:93:ee:6e:9a:31:9a:8b:0d:2b:aa:4a:d0:12:83
/home/gmarler/.ssh/work-keypair (DSA)
$
```

The following example loads into the SSH agent all of the default private keys that exist. In this case, the user has the same passphrase for each private key, so they can all be loaded though the passphrase for the first private key is entered.

```
$ ssh-add
```

```
Enter passphrase for A Default RSA key: Enter passphrase.
Identity added: /home/gmarler/.ssh/identity (A Default RSA key)
Identity added: /home/gmarler/.ssh/id_rsa (/home/gmarler/.ssh/id_rsa)
Identity added: /home/gmarler/.ssh/id_d (/home/gmarler/.ssh/id_d)
$
```

The following example examines the private keys currently loaded into the agent.

```
$ ssh-add -l
md5 1024 b3eb:07:01:0d:af:1e:29:8e:f9:2a:6e:01:4a:8b:9a default SSH v1 RSA key (RSA)
md5 1024 36:60:93:ee:6e:9a:31:9a:8b:0d:2b:aa:4a:d0:12:83
/home/gmarler/.ssh/work-keypair (DSA)
md5 1024 d2:03:d0:1a:99:f6:c1:d9:e4:f8:32:58:e6:2b:4b:4a
/home/gmarler/.ssh/id_rsa (RSA)
md5 1024 49:14:1b:ad:bf:f5:01:d1:ae:f3:7c:c6:ae:f6:db3:a0:02
/home/gmarler$.
```

The following example removes all of the default identities from the agent. These private keys are associated with the following files (if you created them with ssh-keygen).

```
$HOME/.ssh/identity (for SSH v1 RSA private key)
$HOME/.ssh/id_rsa (for SSH v2 RSA private key)
$HOME/.ssh/id_dsa (for SSH v2 DSA private key)
```

```
$ ssh-add -d
Identity removed: /home/gmarler/.ssh/identity (A Default SSH v1 RSA key)
Identity removed: /home/gmarler/.ssh/id_rsa (/home/gmarler/.ssh/id_rsa.pub)
Identity removed: /home/gmarler/.ssh/id_dsa (/home/gmarler/.ssh/id_dsa.pub)
$
```

Note that only the default private keys (if they existed and were loaded into the agent) are removed by the -d option; any other private keys that were loaded are still inside the agent, as shown in the following example.

```
$ ssh-add -1
md5 1024 36:60:93:ee:6e:9a:31:9a:8b:0d:2b:aa:4a:d0:12:83
/home/gmarler/.ssh/work-keypair (DSA)
$
```
