```
search criteria ::= (attribute-list)
attribute list ::= attribute | attribute, attribute-list
attribute ::= string = string
string ::= ISO Latin-1 character set except the character slash ().
The initial character cannot be a terminal character or
t characters at (@), plus (+), or dash (-).
```

Terminals that appear in strings must be quoted with double quote ("). You can quote
the character by quoting it with itself ("").

# Name Expansion

The NIS+ service accepts only fully qualified names. However, because such names can
unwind, the+ names in section 1 use a set of standard expansion rules
try to fulfill a partially qualified name. This expansion is actually done by the\NIS+ library function nis_getnames(3NSL), which generates a list of names by using
the directory search path or the NIS_PATH environment variable.
The NIS+ directory search path includes all the names in its path.nis_getnames ()
is invoked by the functions nis_lookup(3NSL) and nis_list(3NSL) when the
EXP_NAME flag is used.

The NIS_PATH variable contains an ordered list of simple names. The
names are separated by the colon (:). If any name in the list contains colons,
the should be quoted as described in the Grammar section. When the list is
exthausted, the resolution function returns the error NIS_NOTFOUND. This error messagenmmask the fact that the name existed but for it was unreachable. If the
present to the list or lookup interface is fully qualified, the EXPAND_NAME flag is
ignored. In the list of names from the NIS_PATH environment variable, the dollar sign ($)
character is treated specially. Simple names that end with the label $ has this
character replaced by the default directory (nis_local_directory(3NSL)). Using $
asame in this list results in name being replaced by the list of directories
