# Intro, intro 523

more(1) Browse or page through a text file.

mp(1) Text to PDL pretty print filter. New in the Solaris 8 release.

mpss.so.1(1) Shared object for setting preferred page size. New in the Solaris 9 release.

msgfmt(1) Create a message object from a message file.

mt(1) Control magnetic tapes.

mv(1) Move files.

nawk(1) Pattern scanning and processing language.

anca(1) The Solaris network cache and accelerator (NCA). New in the Solaris 8 release.

ncab2clf(1) Convert binary log file to common log file format. New in the Solaris 8 release.

ncakmod(1) Start or stop the NCA kernel module. New in the Solaris 8 release.

neqn(1) See eq(1).

netscape(1) Start Netscape Communicator for Solaris. New in the Solaris 8 release.

newalases(1) Rebuild the database for the mail aliases

newform(1) Change the format of a text file.

newgrp(1) Log in to a new group.

news(1) Print news items.

newsp(1) See mailp(1).

newtask(1) Create new task. New in the Solaris 9 release.

nice(1) Invoke a command with an altered scheduling priority.

nis+(1) A new version of the Network Information Name Service.

nis(1) See nis+(1).

niscat(1) Display NIS+ tables and objects.

nischgrp(1) Change the group owner of an NIS+ object.

nismod(1) Change access rights on an NIS+ object.

nisown(1) Change the owner of an NIS+ object.

nischtl(1) Change the time-to-live value of an NIS+ object.

nisdefaults(1) Display NIS+ default values.

niserror(1) Display NIS+ error messages.

nisgrep(1) See nismatch(1).

nisgrpradm(1) NIS+ group administration command.

nislnn(1) Symbolically link NIS+ objects.

nisls(1) List the contents of an NIS+ directory.
