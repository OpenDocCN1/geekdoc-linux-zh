# cat — Concatenate and Display Files

# Synopsis

```
/usr/bin/cat [-nbssuvet] [file...]
```

# Description

Use the cat command to create short files, to concatenate two files into a third one,
to append one file to the end of another, or to display the contents of file in sequence on the
standard output.

The following syntax creates a new named file Everything that you is
written to file sends one line at a time to the file after you press Return. You can
use the backspace to correct typos on the current line, but you cannot back across
lines. When you are finished, type Control-D on a line by itself to terminate the session
and close the file. If the file does not exist, it is created. If it already exists, the contents
are overwritten with no warning.

```
cat > file
```

The following syntax displays the contents of file on your terminal.

```
cat * file
```
