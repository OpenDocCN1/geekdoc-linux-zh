# sccs-help, help — Ask for Help Regarding SCCS Error or Warning Messages

# Synopsis

```
/usr/ccs/bin/help {argument}...
```

# Description

Use the SCCS help command to retrieve information to further explain errors, messages, and warnings from SCCS commands. help also provides some information about SCCS command usage. If you specify no arguments, help prompts for one.
