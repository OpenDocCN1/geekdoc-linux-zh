# Restricted Korn Shell

Use the restricted shell, rksh, to set login names and execution environments
with more controlled capabilities than those of the standard shell. The actions of rksh
are identical to those of ksh, except that the following actions are not enabled.

+   - Changing directory (see cd(1)).n- Setting the value of SHELL, ENV, or PATH.
- Specifying path or command names containing /
- Redirecting output (>, |, <, >>).
- Changing group (see newgrp(1)).

The restrictions above are enforced after the .profile and ENV files are interpreted.
When a command to be executed is found to be a shell procedure, rksh invokes ksh to
execute it. Then, you can provide procedures that have access to the full power of
the standard shell while imposing a limited menu of commands; this scheme assumes
that the user does not have write and execute permissions in the same directory.

The effect of these rules is that the .profile has complete control
over user actions, performing guaranteed setup actions and leaving the user in an
appropriate directory (probably not the login directory).

The system administrator often sets up a directory of commands (that is, /usr/sbin)
that can be safely invoked by rksh.
