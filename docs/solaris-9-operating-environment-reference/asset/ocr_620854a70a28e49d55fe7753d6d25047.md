# sysV-make

# Environment_SVR4_MAKE

USE_SVR4_MAKE

If this environment variable is set, then the make command invokes the System V version of make. If this variable is not set, then the default version of make(1) is invoked.

You can set USE_SVR4_MAKE as follows (Bourne shell).

```
$ USE_SVR4_MAKE=""; export USE_SVR4_MAKE
```

The C shell syntax is as follows.

```
% setenv USE_SVR4_MAKE
```
