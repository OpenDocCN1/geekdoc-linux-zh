# User Commands

The user commands related to ldap are listed below.

+   idsconfig(1M)

Prepare an iPlanet directory server to be ready to support Solaris
LDAP commands.

+   ldapaddent(1M)

Initialize LDAP entries from corresponding /etc files.

+   ldapclient(1M)

Initialize ldap clients.

+   ldaplist (1)

The entries of the ldap naming space.

# Files

```
/var/ldap/ldap_client_cred
/var/ldap/ldap_client_file
```

Files that contain the LDAP configuration of them. Do not manually modify these files. Their content is not guaranteed to be human readable. The ldapclient(1M) command to update them.
