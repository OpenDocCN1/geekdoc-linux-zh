+   - make tries to derive values for the dynamic macros $, <, and $ while processing explicit targets. It uses the same method for implicit rules; in some cases, this can lead either to unexpected values or to an empty value assigned. (Actually, this was true for earlier versions as well, even though the documentation stated otherwise.)

+   - make no longer searches for SCCS history (s.) files.

There is no guarantee that makefiles created for this version of make work with earlier versions. If there is no make.rules in the current directory and the /usr/share/lib/make/make.rules is missing, make stops before processing any targets. To force run make, create an empty make.rules in the current directory.

Once a dependency is made, make assumes the dependency file is present for the remainder of the run. If a rule subsequently removes that file and future targets depend unexpected errors may result. When dependency checking is in effect, the $? value includes the names of hidden dependencies. This can lead to improper file-name arguments to commands when $7 is used in a rule.

+   - Pattern-match references cannot be used in the dependency list of a pattern-matching rule. Unlike previous versions, this version of make strips a leading ./ from the value of the $8 dynamic macro.

+   With automatic SCCS retrieval, this version of make does not support suffix rules. The only dynamic macro whose value is strictly determined when used in a dependency list is $0 (takes the form $0). make invokes the shell with the -e argument, which cannot be inferred from the syntax of the rule alone.

# man — Find and Display Reference Manual Pages

# Synopsis

```
/usr/bin/man [-adFlrt] [-M path] [-T macro-package] [-s section] name...
/usr/bin/man [-M path] -k keyword...
/usr/bin/man [-M path] -f file...
```

# Description

Use the man command to display information from the online reference manuals. man displays complete manual pages that you specify by name or one-line summaries that you specify with keyword (-k) or with the name of an associated line summary (-f). If no manual page is located, man prints an error message.
