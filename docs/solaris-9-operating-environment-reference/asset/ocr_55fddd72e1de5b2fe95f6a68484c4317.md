# mdb

```
[base] $d
```

Get or set the default output radix. If the dcm is preceded by an explicit expression, the default output radix is set to the given base; otherwise, the current radix is printed in base 10 (decimal). The default radix is 16 (hexadecimal).

```
$e
```

Print a list of all known external (global) symbols of type object function, the value of the symbol, and the first four (32-bit mdb) or eight (64-bit mdb) bytes stored at this location in the target's virtual address space. The ::nm dcm provides more flexible options for displaying symbol tables.

```
$P prompt-string
```

Set the prompt to the specified prompt-string. The default prompt is. You can also set the prompt with ::set -Por or with the P-command line.

```
distance $s
```

Get or set the symbol matching distance for address-to-symbol-name conversions. The symbol-matching distance modes are discussed along with the -s command-line option in "Options" on page 852. You can also modify the symbol-matching distance with the ::set -s option. You can specify no distance, display the current distance.

```
$v
```

Print a list of the named variables that have non-zero values. ::vars dcm provides other options for listing variables.

```
width $w
```

Set the output page width to the specified value. Typically, you do not need this command because mdb queries the terminal for its width and handles resize events.

```
$W
```

Reopen the target for writing as mdb had been executed with the -w option on the command line. You can also enable write with ::set -w option.

```
[pid] ::attach [core | pid]
[pid] :A [core | pid]
```

If the process target is active, attach to and debug the process-ID or corefile. You specify the corefile path as a string argument. You can specify the process-ID as the string argument or as the value of the expression preceding the dcm. The default base is hexadecimal, so precede decimal PIDs obtained with pgrep(1) or ps(1) when you specify them as expressions.

```
[address] ::bp [-c dcm] [-n count]...
address :b [cdmd...]
```

Set a breakpoint at the specified locations. The ::bp dcm sets a breakpoint at each address or symbol specified, including an optional address specified by an explicit expression preceding the dcm and demand string or immediate value following the dcm.
