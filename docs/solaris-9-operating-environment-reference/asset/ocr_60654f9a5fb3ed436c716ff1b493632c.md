# scp - Secure Copy (Remote File Copy Program)

# Synopsis

```
/bin/scp [-BpqvrC46] [-S program] [-P port] [-c cipher]
[-i identity_file] [-o option] [user@host1:] file1 [user2@nhost2:] file2 [...]
```

# Description

Use scp command, new in the Solaris 9 Operating Environment, to copy files between hosts on a network. The command uses ssh(1) for data transfer and uses the same authentication and provides the same security as ssh(1). Unlike rcp(1), scp asks for passwords or passphrases if they are needed for authentication.

Any file name can contain a host and user specification to indicate that the file is to be copied to or from that host. Copies between two remote hosts are permitted.

# Options

+   -4 IPv4 addresses only.

+   -6 IPv6 addresses only.

+   -B Select batch mode. (Prevents asking for passwords or passphrases).

+   -c cipher Specify the cipher to use for encrypting the data transfer. This option is passed directly to ssh(1).

+   -C Enable compression. Passes the -C option to ssh(1) to enable compression.

+   -i identity_file Specify the file from which to read the identity (private key) for RSA authentication. This option is passed directly to ssh(1).

+   -o option Pass the given option directly to ssh(1).

+   -p Preserve modification times, access times, and modes from the original file.

+   -P port Specify the port to connect to on the remote host.

+   -q Disable the progress meter.

+   -r Recursively copy every directory.

+   -S program Specify the name of the program to use for the encrypted connection. The program must understand ssh(1) options.
