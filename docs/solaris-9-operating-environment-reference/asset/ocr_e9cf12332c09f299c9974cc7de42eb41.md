~%divert Allow/disallow unsolicited diversions not specified by ~%take.

~%ifc Toggle DC3/DC1 input control protocol and no input control. This command is useful when the remote system does not respond properly to the DC3 and DC1 characters (can also be specified as ~%nostop).

~l Print the values of the termio structure variables for the remote communication line (useful for debugging).

~~line Send the line ~ to the remote system.

~%nostop Same as ~%ifc.

~%fc Toggle the output flow control setting. When enabled, outgoing data may be flow-controlled by the remote host (can also be specified as ~%nostop).

~%old Allow/disallow-old-syntax for received diversions.

~%put from [to] Copy file from(on local system) to to to remote system. If you omit ta, use the fromargument in both places.

~t Print the values of the termio structure variables for the user's terminal (useful for debugging).

~%take from [to] Copy file(on the remote system) to to the local system. If you omit ta, use the fromargument in both places.

The process normally copies data from the remote system to the standard output of the local system. It may also direct the output to local files.

The use of ~%put requires sty(1) and cat(1) on the remote side. It requires that the current erase and kill characters on the remote system be identical to these current control characters on the local system. Backslashes are inserted at appropriate places.

The use of ~%take requires the existence of echo(1) and cat(1) on the remote system and also requires that the remote system be using the Bourne sh, as Tabs mode (set sty(1)) should be set on the remote system if Tabs to be copied without expansion spaces.

When c is used on system X to connect to system Y and subsequently used on system Z, commands on system Y can be executed by --. Executing a tide command reminds the user of the local system uname. For example, uname can be

+   Z
~{[X]!uname
X
~{[Y]}!

In general, ~ executes the command on the original machine. ~ executes the command on the next machine in the chain.
