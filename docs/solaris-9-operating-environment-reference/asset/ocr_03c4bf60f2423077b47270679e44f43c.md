To save the file, we use the w (write) command. The text is written to the buffer, and the number of characters is displayed. Then we use the q (quit) command to quit ed.

```
w
240
castle%
```

Now let's open the file again by typing ed and the file name. The contents of the file are written into the ed buffer, and the number of characters in the file is displayed.

```
castle% edfile
240
```

To display the last line of the file, we use the p (print) command.

```
p
Leave some there for me.
```

To display the first line of the file, we use 1p.

```
1p
Kookaburra sits in the old gum tree
```

To display the first five lines of the file, we use 1,5p.

```
1,5p
Kookaburra sits in the old gum tree
Merry merry king of the bush is he
Laugh, kookaburra, laugh
Gay your life must be.
```

To display everything in the buffer, we use 1,$p.

```
$p
Kookaburra sits in the old gum tree
Merry merry king of the bush is he
Laugh, kookaburra, laugh
Gay your life must be.
```

```
Kookaburra sits in the old gum tree
Eating all the gumdrops he can see
Laugh, kookaburra, laugh
Leave some there for me.
```

Because ed is a line-oriented text editor, it has a great deal to know what line you want to edit. The n (number) command is like the p (print) command except that it displays a line number at the beginning of each line. The n command uses the same syntax as the p command. In this example, we print the contents of the file
 line numbers.

```
1,$p
Kookaburra sits in the old gum tree
```
