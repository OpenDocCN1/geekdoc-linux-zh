# cpio

+   -f Copy in all files except those in patterns.

+   -H header Read or write header information in header format. Always use this option or the -c option when the origin and the destination machines are different types (mutually exclusive with -c and -6). Available header formats are listed below.

+   -bar Bar head and format. Use only with the -i option (read-only)

+   -crc|CRC ASCII header with expanded device numbers and an additional per file checksum. No UID or GID restrictions are associated with this header format.

+   -od ASCII header with small device numbers. This is the IEEE/P1003 Data Interchange Standard cpio header and format. It has the widest range of portability of any of the header formats. It is the official format for transferring files between POSIX-conforming systems (see standards(5)). Use this format to communicate with Solaris 1.x and INTERACTIVE UNIX. This header enables UIDs and GIDs up to 262143 to be stored in the header.

+   -tar|TAR tar header and format. This header enables UIDs and GIDs up to 2097151 to be stored in the header.

+   -ustar|USTAR IEEE/P1003 Data Interchange Standard tar header and format. This header enables UIDs and GIDs up to 2097151 to be stored in the header.

Files with UIDs and GIDs greater than the limit stated above are archived with the UID and GID of 60001.

To transfer a file (8 GB-1 byte), the header format can be tar | TAR, ustar | USTAR, or odc.

+   -file Read the contents of files as an input archive. If file a character special device and the current medium has been completely read, you should replace the medium and press Return to continue to the next medium. Use this option only with the -i option.

+   -k Try to skip corrupted file headers and I/O errors that may be encountered. If you want to copy files from a medium that is corrupted or out of sequence, this option lets you read only those files with good headers. (For cpio archives that contain other cpio archives, if an error is encountered, cpio may terminate prematurely, find the next good header, which may be one for a smaller archive, and terminates when the smaller archive's trailer is encountered.) Use only with the -i option
