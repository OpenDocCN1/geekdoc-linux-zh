# awk — Pattern Scanning and Processing Language

## Synopsis

```
/usr/bin/awk [-f profile] [-Fc] ['prog'] [parameters] [filename...]
/usr/xp4/bin/awk [-F ERE] [-v assignment...] 'program' | -f profile...
[argument...]
```

## Description

The awk command is a programming language that is very useful for computation and pattern matching. The name awk is an acronym composed of the initials of its developers of the language: Aw, Weiner, and Kernighan. The /usr/xp4/bin/awk command is described on the awk(1) manual page. The awk is a greatly enhanced and optimized version of awk.

The /usr/bin/awk command scans a list of input files for lines that match any set of patterns specified in prog. The programming must be enclosed in single quotes ('') to protect it from the shell. For each pattern in prog there may be an associated action performed when a line of file matches the pattern. The set of pattern-action statements may appear literally as prog in a file specified with the -f profile input. Input files are read in order; if there are no files, the standard input is read. The file-name dash (—) means the standard input.

## Notes

Input space is not preserved on output if fields are involved.
There are no explicit conversions between numbers and strings. To force an expression to be treated as a number, add 0 to it; to force it to be treated as a string, concatenate the null string ("") to it.

## Options

- -f progfile
  Read the set of patterns from progfile.
- -Fc
  Use the character c as the field separator (FS) character. See the discussion of FS below.

## Usage

### Input Lines

Each input line is matched against the pattern portion of every pattern-action statement; the associated action is performed for each matched pattern. Any file name of the form var=value is treated as an assignment, not a file, and is executed at the time it would have been opened if it were a file name. Variables assigned in this manner are not available inside a BEGIN rule and are assigned after previously specified files have been read.
An input line is normally made of fields separated by spaces. You can change this using the built-in field variable, FS, or -Fc. The default is to ignore leading blanks and to separate fields by blanks/or Tab characters. However, if FS is assigned a value that does not include any of the white spaces, leading blanks are not ignored. The fields are denoted $1, $2...

### Pattern-Action Statements

A pattern-action statement has the form:

```
pattern {action}
```

You can omit the action. If there is no action, the default action is to print the entire line ($0). Pattern-action statements are separated by newlines. Patterns can consist of regular expressions, Boolean combinations (&&, ||, !), and comparisons (==, !=, <, <=, >, >=). Patterns are executed in the order they appear in the file. If multiple patterns match a line, their associated actions are executed in order.

### Built-in Variables

Built-in variables include:
- FILENAME Name of the current file.
- FS Input separator
- NF Number of fields in the current record
- NR Ordinal number of the record
- OFMT Output format
- ORS Output separator
- RS Record separator

### Control Structures

Control structures can use the following:

- if (expression) {action} else {action}
- while (expression) {action}
- for (init; expression; step) {action}
- break
- continue
- next
- exit [status]

### Built-in Functions

The arithmetic functions are as follows:

- cos(x) Return cosine of $x$, where $x$ is in radians.
- sin(x) Return sine of $x$, where $x$ is in radians.
- exp(x) Return the exponential function of $x$.
- log(x) Return the natural logarithm of $x$.
- sqrt(x) Return the square root of $x$.
- int(x) Truncate its argument to an integer. It is truncated toward 0.

The string functions are as follows:

- index(s, t) Return the position in string $s$ where string $t$ first occurs, or 0 if it does not occur at all.
- int(s) Truncate $s$ to an integer value. If $s$ is not specified, use 0.
- length(s) Return the length of its argument taken as a string, or of the whole line if there is no argument.
- split(s, a, fs) Split the string $s$ into array elements $a[1], a[2], ..., a[n]$, and return $n$. The separation is done with the regular expression $fs$ or with the field separator $FS$ if $fs$ is not given.
- sprintf(fmt, expr, ...) Format the expressions into the printf(S) format given by $fmt$ and return the resulting string.

The input/output function is:

- getline Set $0 to the next input record from the current input file. return 1 for successful input, 0 for end of file, and -1 for an error.
