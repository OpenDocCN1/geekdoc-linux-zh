The -z nodes option permits undefined symbols. For historic reasons, this option is the default when a shared object is built. When used with executables, the behavior of references to undefined symbols is unspecified. Use of the -z nodes option is not recommended. New in the Solaris 8 release.

+   -z endfileter

Mark a filter so that, when processed by a filter, it terminates any further searches by the filter. New in the Solaris 8 release.

+   -z finiarray=function

Append an entry to the .finiarray section of the object being built. If no.finiarray section is present, create one. The new entry is initialized to point to the function. See Linker and Libraries Guide for more information. New in the Solaris 8 release.

+   -z groupp | nogroupp

Assign or deassign each dependency that follows to a unique group. Assigning a dependency to a group has the same effect as if the dependency was built with the -B group option. New in the Solaris 8 release.

+   -z ignore | record

Ignore or record dynamic dependencies that are not referenced as part of the link-edit.-z record is the default.

+   -z initarray=function

Append an entry to the .initarray section of the object being built. If no.initarray section is present, create one. The new entry is initialized to point to the function. See Linker and Libraries Guide for more information. New in the Solaris 8 release.
