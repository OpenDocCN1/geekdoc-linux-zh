# Built-in Functions

The arithmetic functions are as follows:

+   - cos(x) Return cosine of $x$, where $x$ is in radians.

+   - sin(x) Return sine of $x$, where $x$ is in radians.

+   - exp(x) Return the exponential function of $x$

+   - log(x) Return the natural logarithm of $x$.

+   - sqrt(x) Return the square root of $x$.

+   - int(x) Truncate its argument to an integer. It is truncated toward 0 if $x > 0$.

The string functions are as follows:

+   - index(s, t) Return the position in string $s$ where string $t$ first occurs, or 0 if it does not occur at all.

+   - int(s) Truncate $s$ to an integer value. If $s$ is not specified, use $0$.

+   - length(s) Return the length of its argument taken as a string, or of the whole line if there is no argument.

+   - split(s, a, fs) Split the string $s$ into array elements $a[1], a[2], ..., a[n]$, and return $n$. The separation is done with the regular expression $fs$ or with the field separator $FS$ if $fs$ is not given.

+   - sprintf(fmt, expr, expr, ...) Format the expressions into the printf(S) format given by $fmt$ and return the resulting string.

The input/output function is:

+   - getline Set $0 to the next input record from the current input file. return 1 for successful input, 0 for end of file, and -1 for an error.

# Large File Behavior

See large(5) for the description of the behavior of awk when encountering files greater than or equal to 2 Gbytes (**31 bytes).
