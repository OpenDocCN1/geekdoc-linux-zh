# llc2_stats

```
xidRspRcvd = 0x00000000
testCmdSnd = 0x00000000
testCmdRcvd = 0x00000000
testRspSent = 0x00000000
testRspRcvd = 0x00000000
uiSent = 0x00000000
uiRcvd = 0x00000000
outOfState = 0x00000000
allocFail = 0x00000000
protocolError = 0x00000000
example%
```

The fields in the output are described below.

+   * **ppa**: The logical number used to address the adapter.

+   * **clearFlag**: Whether the statistics are reset to zero after reading (set to 1) or if the statistics are read-only (set to 0).

+   * **sap**: The specified Service Access Point (SAP) logical interface value for the station.

+   * **state**: A number indicating the current state of the SAP component (0 = inactive, 1 = active).

+   * **of cons**: The number of active connections on this SAP.

+   * connections: The array of active connection indexes.

+   * **xidCmdSnd**: The number of XID command PDUs sent (Source SAP = SAP).

+   * **xidCmdRcvd**: The number of XID command PDUs received (Destination SAP = SAP).

+   * **xidRspSent**: The number of XID response PDUs sent (Source SAP = SAP).

+   * **xidRspRcvd**: The number of XID response PDUs received (Source SAP = SAP).

+   * **testCmdSnd**: The number of TEST command PDUs sent (Source SAP = SAP).

+   * **testCmdRcvd**: The number of TEST command PDUs received (Destination SAP = SAP).

+   * **testRspSent**: The number of TEST response PDUs sent (Source SAP = SAP).

+   * **testRspRcvd**: The number of TEST response PDUs received (Source SAP = SAP).
