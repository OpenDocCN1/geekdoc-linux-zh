# Files

/tmp/bd?????
Temporary file used for comparison.

While biff is comparing files, it creates temporary files in the /tmp directory. When the
comparison is done, the files are automatically removed. The following example shows
two temporary files.

```
caste% ls /tmp/bd*
bdcG4GX bdowl1VW
caste%
```
