# ipcs

# 537

The permissions are indicated as follows:

+   - r Read permission is granted.
- w Write permission is granted.
- a Alter permission is granted.
- - The indicated permission is not granted.
- (all) The login name of the owner of the facility entry.
- (all) The group name of the group of the owner of the facility entry.
- (a, A, c) The login name of the creator of the facility entry.
- (a, A, c) The group name of the group of the creator of the facility entry.
- (a, A, o) The number of bytes in messages currently outstanding on the associated message queue.
- (a, A, o) The number of messages currently outstanding on the associated message queue.
- (a, A, b) The maximum number of bytes allowed in messages outstanding on the associated message queue.
- (a, p) The process ID of the last process to send a message to the associated queue.
- (a, A, p) The process ID of the last process to receive a message from the associated queue.
- (a, A, t) The time the last message was sent to the associated queue.
- (a, A, t) The time the last message was received from the associated queue.
- (a, A, t) The time when the associated entry was created or changed.
- (a, i) The number of ISM attachments to the associated shared memory segments.
- (a, A, o) The number of processes attached to the associated shared memory segment.
- (a, b) The size of the associated shared memory segment.
- (a, A, p) The process ID of the creator of the shared memory entry.
- (a, A, p) The process ID of the last process to attach or detach the memory segment.
- (a, A, t) The time the last attach to the associated shared memory segment was completed.
- (a, A, t) The time the last detach on the shared memory segment was completed.
- (a, A, b) The number of semaphores in the set associated with the semaphore entry.
- (a, A, t) The time the last semaphore operation on the set associated with the semaphore entry was completed.
