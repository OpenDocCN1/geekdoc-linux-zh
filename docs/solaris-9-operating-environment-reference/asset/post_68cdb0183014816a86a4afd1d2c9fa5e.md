# shutdown — Close Down the System at a Given Time

# Synopsis

```
/usr/ucb/shutdown [-fhknr] time [warning-message...]
```

# Description

Use the /usr/ucb/shutdown command as root when shutting down a system with multiple users. The shutdown command sends a warning message to all users who are logged in, waits 60 seconds (the default), and then shuts down the system to single-user state. You can choose a different wait time and specify a different warning message.

> Note — The default /usr/sbin/shutdown(1M) command has different options.

The shutdown command provides an automated procedure to notify users when the system is to shut down. time specifies when shutdown brings the system down; you can specify the word now (indicating an immediate shutdown) or a future time in either the format +number or hour:min. The first form brings the system down in minutes, and the second brings the system down at the time of day, indicated in 24-hour notation.

At intervals that get closer to the shutdown time approaches, warning messages are displayed at terminals of all logged-in users and users who have remote mounts on that machine.

At shutdown, a message is written to the system log daemon, syslog(1M), containing the time of shutdown, the instigator of the shutdown, and the reason. Then, a terminate signal is sent to init; this action brings the system down to single-user mode.

# size — Print Section Sizes of Object Files in Bytes

# Synopsis

```
/usr/ccs/bin/size [-f] [-P] [-n] [-o] [-V] [-x] filename...
```

# Description

The size command produces section or size information in bytes for each loaded section in ELF object files, size prints out the size of the text, data, and bss (uninitialized data) segments (or sections) and their total.
an archive file name is input to the size command, the information for each object file in the archive is displayed.

When calculating segment information, the size command prints the total file size of the nonwritable segments, the total file size of the writable segments, and the total memory size of the writable segments minus the total file size of the writable segments.

If it cannot calculate segment information, size calculates section information.
When calculating segment information, size prints out the size of sections that are allocatable, writable, and not NOBITS; the total size of the sections that are alloc alloc, writable, and not NOBITS; and the total size of the writable sections of type NOBITS. NOBITS do not actually take up space in the file name.

If size cannot calculate either segment or section information, it prints an error
message and stops processing the file.

> Note — Because the size of bss sections is not known until link-edit time,
the size command does not give the true size of prelinked objects.

# Options

- -f Print the size of each allocatable section, the name of the section, and
total) of the section sizes. If there is no section data, print an error
message and stop processing the file.

- -F Print the size of each loadable segment, the permission options of the
segment, and the total of the loadable segment sizes. If there is no
segment data, print an error message and stop processing the file.

- -n Print nonloadable segment or nonallocatable section sizes. If segment
data exists, the memory size of each loadable segment or file size
of nonloadable segment, the permission options, and the total size
of the segments. If there is no segment or section data, then for each allocatable
and nonallocatable section, print the memory size, the section name,
the total size of the sections. If there is no segment or section data,
print an error message and stop processing.

- -o Print numbers in octal.

- -V Print the version information for the size command to the standard

- -x Print numbers in hexadecimal.

# sleep — Suspend Execution for an Interval

# Synopsis

```
/usr/bin/sleep time
```

# Description

The sleep command suspends execution for at least the integral number of seconds specified by the operand.

If the sleep command receives SIGALRM, one of the following actions is taken:

- Terminate normally with 0 exit status.
- Ignore the signal.

The sleep command takes the default action for other signals.

# Operands

time A nonnegative decimal integer specifying the number of seconds to suspend.

# Examples

The following example executes a command after 105 seconds.
castle% sleep 105; find . -print

The following example executes a command every
while true
do  sleep 37

# Environment Variables

environ(5) for descriptions of the following environment variables that affect the execution of sleep: LC_CTYPE, LC_MESSAGES, and NLSPATH.

# Exit Status

- 0 The execution was successfully suspended for time seconds, or SIGALRM was received.
- 1 An error has occurred.

# soelim — Resolve and Eliminate .so Requests from nroff or
troff

# Synopsis

```
/usr/bin/soelim [filename...]
```

# Description

The soelim command is a preprocessor(1) that reads nroff/troff input and performs the textual inclusion implied by the nroff(1) directives of the .so somefile when they appear at the beginning of input lines. This command is useful programs such as tbl(1) do not normally do this preprocessing. With the soelim command, you can place individual tables in separate files to be run as a part of a large document.
An argument consisting of a dash (-) is taken to be a file name corresponding to standard input.

> Note — You can suppress inclusion by using ' ' in place of ,, for example ,
/usr/share/lib/tmac/tmac.s

# Examples

The following example shows a typical use of soelim.
caste$ soelim exum.n | tbl | nroff -ms | col | 1pr

# solregis — Solaris User Registration

# Synopsis

```
/usr/dt/bin/solregis [-cd]
```

# Description

The solregis command initiates the Solaris user registration procedure, which enables you to register with Sun Microsystems and receive information about Solaris. Normally, solregis is executed in conditional mode as a part of desktop login so that you are prompted at desktop startup time to register unless you have already done so.
