# Environment Variables

See environ(5) for descriptions of the following environment variables that affect the execution of awk: LC_CTYPE and LC_MESSAGES.

LC_NUMERIC Determine the radix character used when interpreting numeric input, performing conversions between numeric and string values, formatting numeric output. Regardless of locale, the period character (the decimal-point character of the POSIX locale) is the decimal-point character recognized in processing awk programs including assignments in command-line arguments. New in the Solaris 8 release.
