# Bugs

prex:should issue a notification when a process ID has been automatically deleted
the filter set.
A known bug in prex can result in the message:
Tracing shut down target program due to an internal
error - Please restart prex and target

When you run prex as root, the target process is not root and you put the tracefile in
a directory where it cannot be removed and recreated (such as a directory /tmp with
the sticky bit on), then the target process is not able to open the tracefile when it needs
disabling tracing.

Changing any of the circumstances listed above fix the problem. Either doesn't
run prex as root, the target process as root, or specify the tracefile in a directory
other than /tmp.
