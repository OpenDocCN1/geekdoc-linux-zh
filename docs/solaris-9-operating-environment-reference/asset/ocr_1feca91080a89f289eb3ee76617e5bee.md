# GNU-Compatible Message Files

Use one of the following formats for comments for a GNU-compatible message file (the
msfmt command ignores these comments when processing Solaris message files).

```
# translator-comments
# automatic-comments
# reference...
# flag
```

The #: comments indicate the location of the msgstr string in the source files in
filename: line format. The #, #., and #, comments are informative only and
silent ignored by the msfmt command. The #, comments require one or more flags
separated by the comma. You can specify the following flags.

fuzzy

The translator can insert fuzzy to show that the msgstr string might
be a correct translation. Only the translator can judge if
t translation requires further modification or is acceptable as is.
Once satisfied with the translation, the translator removes the fuzzy
flag. If this flag is specified, msfmt does not generate the entry for the
immediately following msgstr in the output message catalog.

c-format

no-c-format

> The c-format flag indicates that the msgid string is used as a format
string by printf-like functions. The c-format flag is given for a
string, the msfmt command does some more tests to check the validity
of the translation.

In the GNU-compatible message file, the msgid with empty string (**) is called
the header entry and treated specially. If the message string for the header entry
contains plural=value, the value indicates the number of plural forms. For example,
plural=4 means there are four plural forms. If plural is defined, the
line should contain plural-expression, separated by a semicolon character.
The expression is a C language expression to determine which version of msgstr[n] is to be
used, based on the value of n; the last argument of gettext(), gettext(), or
dgettext(). For example.

```
n=2; plural = n == 1 ? 0 : 1
```

indicates that there are two plural forms in the language. msgstr[0] is used if n == 1;
oror msgstr[1] is used if n == 2. In another example,

```
n=3; plural = n == 1 ? 0 : 2
```

indicates that there are three plural forms in the language. msgstr[0] is used if n == 1,
and msgstr[1] is used if n == 2; msgstr[2] is used.
