# crle

-1 dir

Specify a new default search directory dir for ELF or AOUT.
You can specify this option multiple times. The type of object applicable to the search is either specified by the preceding -t option or defaults to ELF.

The system default search path for ELF is /usr/lib/64 for 64-bit objects. The system default search paths for AOUT objects is /usr/41b, /usr/lib, and /usr/local/lib.

This option replaces the default search path, and you must normally use an -1 option to specify the original system default in relation to any new paths being applied. However, if you specify the -u option and a configuration file does not exist, the system defaults are added to the new configuration file before the new paths specified with -1.

-o dir

Specify the directory dir in which alternate objects are created. Without this option alternate objects are created in the directory which the configuration file is created. You can specify this option multiple times; the directory dir is used to locate alternates for any following command-line options. Alternate objects are not permitted to override their associated originals.

-s dir

Specify a new trusted dir for secure ELF or AOUT objects. See “Security” on page 665 in ld.so(1) for a definition of secure objects.

You can specify this option multiple times. The type of object applicable to the search is either specified by the preceding -t option or defaults to ELF.

The system default trusted directory for secure ELF is /usr/lib/secure for 32-bit objects and /usr/lib/secure/64 for 64-bit objects. The system default trusted directories for secure AOUT objects are /usr/41b, /usr/lib, /usr/ucblib, and /usr/local/lib.

Because this option replaces the system default trusted directories, you are normally required to use the -s option to specify the original system default in relation to any new directories being applied. However, if you specify the -u option and a configuration file does not exist, the system defaults are added to the new configuration file before the new directories specified with the -s.

-t ELF | AOUT

Toggle the object type applicable to any -l or -s options that follow. The default object type is ELF.

-u

Update a configuration file, possibly with the addition of new information. Without other options, any existing configuration file is inspected and its contents recomputed. Additional arguments allow information to be appended to the recomputed contents.

The -u option version 2 of crle contains the version level. You can display it with the crle command.
