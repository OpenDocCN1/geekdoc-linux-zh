# ldapmodrdn — LDAP Modify Entry RDN Tool

# Synopsis

```
/usr/bin/ldapmodrdn [-r] [-v] [-c] [-d debuglevel] [-D binddn]
[-w password] [-h ldaphost] [-M authentication] [-p ldpport] [-f file]
[- rdn]
```

# Description

ldapmodrdn opens a connection to an LDAP server and binds and modifies the relative distinguished name (RDN) of entries. The entry information is read from standard input, from file with the -f option, or from command-line pair and rdn.

# Options

+   - c Continuous operation mode. Report errors and continue with modifications. The default is to exit after reporting an error.
