# /usr/xpg4/bin/od

The following operands are supported for /usr/xpg4/bin/od only.

| file | Same as /usr/bin/od, except only one of the first two conditions be true. |
| --- | --- |
| [+] [offset] [.] [b]B | |
| [+] [0x] {offset} | |
| [+] [0x] offset[B] | |
|+x [offset] | |

Description of offset-string is the same as for /usr/bin/od.
