# csh

switch

Successively match each `label` against the specified `string`, which is first command- and file-name expanded. You can use the `case label:` metacharacters `*`, `?`, and `[...]` in the case labels, which are variable expanded. If none of the labels match before a `default` label is found, `break` begin execution after the default `label`. Each case statement must appear at the beginning of a line. The default command `break` continues execution after the `endsw`. Otherwise, control flows through subsequent case and default statements as `C`. If no `label` matches and there is no default, execution continues after the `endsw`.

(string)

breaksw

default:

breaksw

endsw

time [command]

With no argument, print a summary of the time used by this shell and its children. With an optional `command`, execute `command` and print a summary of the time uses.

As of writing, the `time` built-in command does not compute the last six fields of output, erroneously reporting the value for these fields.

```
example$ time
```

```
9.0u 11.0s 3:32 10% 0k+0:1o 0Pf+0Ow
```

umask [value]

Display the file creation mask. With an optional `value`, set the file creation mask. With `value` given in, you can turn off any bits, but you cannot turn on bits to allow new permissions. Common values include 077, restricting all permissions from everyone else; 022, giving complete access to the group and read (and directory search) access to others; or 022, give read (and directory search) but not write permission to the group and others.

unalias pattern

+   Discard aliases that match (file-name substitution) `pattern`. unalias* removes all aliases.

unhash

Disable the hash tables for the `path` and `cdpath` variables.

unlimit [-h]

[resource]

Remove a limitation on `resource`. If you specify no resource, remove all resource limitations. See the description of the `limit` command for the list of resource names. Only superuser can use the -h option to remove corresponding hard limits.

unset pattern

Remove variables whose name match (file-name substitution) `pattern unset` removes all variables, which has noticeably distasteful side effects.

unset variable

Remove `variable` from the environment. As with unset, pattern matching is not performed.
