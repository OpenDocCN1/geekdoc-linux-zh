# Description

roffbib command to print all records in a bibliographic database in bibliography format instead of footnotes or endnotes. Generally, roffbib is used in conjunction with sortbib(1).

castle% sortbib database | roffbib

# Options

roffbib accepts all options understood by nroff(1) except -i and -q. Use final resolution.

+   -e
Produce equally spaced words in aligned lines,

+   -h
Use output Tabs during horizontal spacing to speed output and reduce output character count. Tab settings are assumed to be 8 nominal character widths.

+   -m filename
Prepend the macro file /usr/share/lib/tmac/tmac.name to the input files. Leave a space between the -m and macro filename. This set of macros replaces the ones defined in /usr/share/lib/tmac/tmac.bib.

+   -np
Number the first generated page p.

+   -olist
Print only page numbers that appear in the comma-separated list of numbers and ranges. Range M-N means through M an initial -M from the beginning to page M a final M from page N to end.

+   -Q
Queue output for the typesetetter. Set page offset to 1 inch.

+   -raN
Set register (single character) to M The command-line argument -rM numbers the references starting at 1.

Four-line registers formatting style of the bibliography, much like the register registers of ms(5). The flag -rv2 double-spaces the bibliography, whereas -rv1 double-spaces and single-space annotation programs. You can change the line length from the default 6.5 inches to 6 inches with the -rl6i argument, and you can set the page offset from the default of 0 to 1 inch by specifying -r0li (capital 0, not zero).

+   -sN
Halt every Npages for paper loading or changing (default N=1). To resume, press newline or Return.

+   -Tterm
Specify term as terminal type.

+   -V
Send output to the Versatec printer. Set page offset to 1 inch.

+   -x
If abstracts or comments are entered following the %x field, roffbib formats them into paragraphs for an annotated bibliography. You can use several %x fields if you want several annotation
