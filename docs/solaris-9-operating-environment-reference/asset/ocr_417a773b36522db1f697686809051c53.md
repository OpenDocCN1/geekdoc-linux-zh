# -P destination

Print file on a specific printer or class of printers (see lpadmin(1M)).
Specify destination using atomic, POSIX-style
(server:destination) or Federated Naming Service (FNS)
(/service/printer/...) names. See printers.conf(4) for
information regarding the naming conventions for atomic and FNS
names, and standards(5) for information POSIX.

-s Use full path (as symbolic links) to file instead of
trying to copy them. File should not be modified or removed until it has
completed printing. -s prevents only copies of local files from being
made on the local system. -s works only with specified files. If the lpr
command is at the end of a pipeline, file copies to the spool.

-T title Print a title on the banner page of the output. Enclose title double
quotes if it contains blanks. If you do not specify title, print file name
ant the banner page.

-w cols Print file pages with a specific width. cols indicates the number of\columns

-f-options Notify the printer spooler that fileis is not a standard text file. Enable the
spooling daemon to use the appropriate filters to print file.
filter-options offers a standard user interface. All options may not
 available for, or applicable to, all printers. Specify filter-options
as a single character. If you do not specify filter-options and the
printer can interpret PostScriptO, inserting %! as the first two
characters of file interprets the file as PostScript. The following
filter-options are supported.

+   c File contains data produced by ciflot.
d File contains tex data from DVI format from
Stanford.
f Interpret the first character of each line as a standard
FORTRAN carriage control character.
g File contains standard plot data produced by plot(1B)
routines.
l Print control characters and suppress page breaks.
n File contains ditroff data from device-independent
troff.
p Use pr to format the files.
t File contains troff (cat photypesetter) binary data.
v File contains a raster image. printer must support an
appropriate imaging model such as PostScript to print
t image.
