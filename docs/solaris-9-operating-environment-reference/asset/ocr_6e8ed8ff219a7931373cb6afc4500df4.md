# Options

+   -d

Display the reasons why make chooses to rebuild a target. Display any and all dependencies that are newer. In addition, display options read in from the MAKEFLAGS environment variable.

+   -dd

Display the dependency check and processing in vast detail.

+   -D

Display the text of the makefiles read in.

+   -DD

Display the text of the makefiles, make.rulesfile, the state file, and all dependency reports.

+   -e

Specify that environment variables override assignments within makefiles.

+   -f makefile

Use the description file makefile. A - as the makefile argument denotes the standard input. The contents of makefile, when it is present, override the standard set of implicit rules and predefined macros. When you specify more than one -f makefile argument pair, use the concatenation of those files in order of appearance.

When you specify no makefile/usr/ccs/bin/make tries the following in sequence, except in POSIX mode (see the "Special-Function Targets" on page 793).

+   * If there is a named makefile in the working directory, use that file. If an SCCS history file (SCCS/makefile) is newer, try to retrieve and use the most recent version.
* In the absence of the above file(s), if a named Makefile is present in the working directory, try to use it. If an SCCS history file (SCCS/s.Makefile) is newer, try to retrieve and use the most recent version.

When you specify no makefile/usr/ccs/bin/make try the following files in sequence:
and /usr/xpg4/bin/make

+   * .makefile, .Makefiles
* .makefile, SCCS/s.makefile
* s.Makefile, SCCS/s.Makefile

+   -i

Ignore error codes returned by commands. Equivalent to the special-function target. IGNORE:

+   -k

When a non-zero error status is returned by a rule or make cannot find a rule, abandon work on the current target but continue with other dependency branches that do not depend on it.
