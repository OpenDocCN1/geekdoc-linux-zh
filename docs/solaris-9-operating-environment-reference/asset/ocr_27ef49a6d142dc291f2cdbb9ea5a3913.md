# ar 59

file
A path name. Only the last component is used when comparing against the names of files in the archive. If two or more operands have the same last path-name component (basename1), the results are unspecified. The implementation's archive format does not truncate valid names of files added to or replaced in the archive.

posename
The name of a file in the archive, used for relative positioning; options -m and -r.

# Examples
The following example shows how to find which modules make up the libexample.archive.

```
castle$ ar t libexample.a
```

The following example shows how to extract a module from a shared object. If module.o is part of the archive library libexample.a, you can extract the module with the following command.

```
castle$ ar x libexample.a module.o
```

The ranlib command in Solaris 4.X was used to add a table of contents to archive libraries. The ranlib command is now incorporated into /usr/ccs/bin/ar. When ar is archiving object files, it automatically creates a symbol table, as shown in the example.

```
castle$ ar rcv libfoo.a foo bar.o
```

The following command forces a rebuild of the symbol table in an archive library.

```
castle$ ar ts libfoo.a
```
