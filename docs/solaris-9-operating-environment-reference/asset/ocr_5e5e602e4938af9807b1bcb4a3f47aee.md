# pg — File Perusal Filter

# Synopsis

```
/usr/bin/pg [-number] [-p string] [-cefnrs] [+linenumber] [/pattern/]
[filename...]
```

# Description

The pg command is a filter that enables you to examine files one screen at a time. If you
press Return, another page is displayed; other possibilities are listed below.
This command is different from previous paginators in that it enables you to back up
 review something that has already moved off the screen. The method for backing up
is explained below.
