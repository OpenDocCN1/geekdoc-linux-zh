# vi, view, edit

+   I Insert before first nonblank.
O Open line below.
O Open above.
rx Replace single char with x.
RetESC Replace characters.

# Operators

Operators are followed by a cursor motion and affect all text that would have been moved over. For example, because w moves a word, dw deletes the word that would have been moved over. Double the operator (for example, dd) to affect entire lines.

+   d Delete.
C Change.
y Yank lines to buffer.
< Left-shift.
> Right-shift.
! Filter through command.

# Miscellaneous Operations

+   C Change rest of line (cS).
D Delete rest of line (dS).
s Substitute characters (c1).
S Substitute lines (cc).
J Join lines.
x Delete characters (d1).
X Delete characters before cursor (dh).
Y Yank lines (yy).

# Yank and Put

Put inserts the text most recently deleted or yanked; however, if a buffer is named (using the ASCII lowercase letters a-z), the text in that buffer is inserted instead.

+   3yy Yank three lines.
3y1 Yank three characters.
P Put back after cursor.
P Put back text before cursor.
"xp Put from buffer x.
"xy Yank to buffer x.
"xd Delete into buffer x.
