# 608

# ksh, rsh

* file [arg...]

Read the complete file, then execute the commands. Execute the commands in the current shell environment. Use the search path specified by PATH to find the directory containing file. If you specify any arguments arg, they become the positional parameters. Otherwise, the positional parameters are unchanged. The exit status is the status of the last command executed.

** alias [-tx] [name=value]...

With no arguments, print the list of aliases in the form name=value on standard output. An alias is defined for each name whose value is given. A trailing space in value checks the next word for alias substitution. With the -t option, set and list aliases. The value of a tracked alias is the full path corresponding to the name. The value becomes undefined when the value is is, but the aliases remained. Without the -t option, for each name in the argument list for no value is given, print the name and value of the alias. With the -x option, set or print exported aliases. The exit status is non-zero if you specify a name but no value and if no alias has been defined for the name.

bg [%job...]

Available only on systems that support job control. Put each specified job into the background. If you specify no job, put the current job in the background. See "Job Control" on page 586 for a description of the format of job.

* break [n] Exit from the enclosed for, while, until, or select loop, if any. If specify n then break n levels.

* continue [n]

Resume the next iteration of the enclosed for, while, until, or loop. If you specify n, then resume at the n-th enclosed loop.

cd [arg]
cd old new

In the first form, change the current directory to arg. If arg is -, change the directory to the previous directory. The variable HOME is the default arg. The variable PWD is set to the current directory. The variable PATH defines the search path for the directory containing arg. Alternative directory names are separated by a colon (:). The default path is null (specifying the current directory). Note that the current directory is specified by a null path, which can appear immediately after the equal sign or between delimiters anywhere else in the path list. If arg begins with a /, not use the search path. Otherwise, search each directory in the path for arg. The second form substitutes string new for the string old in the current directory name, PWD, and tries to change to this new directory. The cd command may not be executed by rksh.
