# list_devices — List Allocatable Devices

# Synopsis

```
/usr/sbin/list_devices [-s][-U uid] -1 [device]
/usr/sbin/list_devices [-s][-U uid] -n [device]
/usr/sbin/list_devices [-s][-U uid] -u [device]
```

# Description

The list_devices command, new in the Solaris 9 Operating Environment, to list the allocatable devices in the system according to specified qualifications

> Note — The functionality in this manual page is available only if the Basic Security Module (BSM) has been enabled. See bsmconv(1) for more information.

The Solaris 9 Operating Environment provides a device-allocation method—that the allocate(1), deallocate(1), dminf(1M), and list_devices(1)—that fulfils the Trusted Computer System Evaluation Criteria (TCSEC) object-reuse requirement for computing systems at C2 level and above. The device allocation mechanism prevents simultaneous access to a device, prevents one user from reading media written by another user, and prevents one user from accessing any information from the device or internal storage after another user is finished with the device.
