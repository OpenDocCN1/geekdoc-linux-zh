# 637

LD_RUN_PATH An alternative mechanism for specifying a run path to the link-editor
(see -R option). If both LD_RUN_PATH and the -R option are specified, -R
supedes.

SGS_SUPPORT Provide a colon-separated list of shared objects that are loaded with the
link-editor and given information regarding the linking process.

You can specify this environment variable with a _32 or _64 suffix,
which makes the environment variable specific to either the 32-or
64-bit class of ld and overrides any unsuffixed version of the
environment variable that may be in.

See also the -s option. New in the Solaris 8 release.

Note — Environment-variable names beginning with the characters LD_
reserved for possible future enhancements to ld and ld.so(1).
