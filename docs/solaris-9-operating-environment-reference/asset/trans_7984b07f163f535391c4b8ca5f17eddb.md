

# 简介

ed, red 文本编辑器。

edit 文本编辑器（适用于普通用户的 ex 变体）。

ex 基于显示器的文本编辑器。

fmt 简单的文本格式化工具。

fold 用于折叠行的过滤器。

join 关系数据库操作符。

line 读取一行。

m4 宏处理器。

awk 模式扫描和处理语言。

patch 对文件应用更改。

pr 打印文件。

sed 流式编辑器。

tr 翻译字符。

vi, view, vedit 基于 ex 的面向屏幕的视觉显示编辑器。

wc 显示文件中单词数、列表数和字符数。

xargs 构建参数列表并调用命令。
