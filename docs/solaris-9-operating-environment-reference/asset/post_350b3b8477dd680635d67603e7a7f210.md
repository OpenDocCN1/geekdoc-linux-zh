
-d Display all processes that have expired and have not been respawned by init. The EXIT field for dead processes contains the termination and exit values (as returned by wait(UCB)) of the dead process. This information can be useful in determining why a process terminated.

-H Output column headings at the regular output.

-1 List only lines on which the system is waiting for someone to log in. The NAME field is LOGIN in such cases. Other fields are the same as for user entries except that the STATE field does not exist.

-m Output only information about the current terminal.

-n Take a numeric argument, x which specifies the number of users to display per line. x must be at least 1. You can use the -n option with -q.

-p List any process that is currently active and was previously spawned by init. The NAME field is the name of the process executed by init as found in /sbin/utmp. The STATE, LINE, and IDLE fields have no meaning. The COMMENT field shows the ID of the line from /sbin/utmp that spawned this process.

-q Display the names and the number of users logged in. Ignore all other options.

-r Indicate the current level of init process.

-s List only the NAME, LINE, and TIME fields (the default).

-T Same as the -s option, also write the STATE, IDLE, PID, and COMMENT fields. STATE is one of the following characters:
+ Allow write access to other users.
+ Deny write access to other users.
+ Cannot determine the terminal write access.

-t Indicate the last change to the system clock (using the date command) by root. See date(1).

-T Same as the -s option, also write the STATE field. STATE is one of the characters listed under /bin/who version of this option. If you use the -u option with -T, add the idle time to the end of the format.

-u List only those users who are currently logged in. The name is the user's login name. The LINE is the name of the line as found in /dev/pts. The IDLE column contains the number of hours and minutes since activity last occurred on that particular line. If more than 24 hours have elapsed or the line has not been used since boot time, mark the entry as old. The IDLE field is useful for determining whether a person is working at the terminal. The PID is the process ID of the user's shell. The COMMENT is the field associated with this line found in /sbin/utmp. The COMMENT field can contain information such as the location of the terminal, the telephone number of the data, and type of terminal if hardwired.

-m Output describing the invoking user, equivalent to the -m option. You must separate the am arguments with a space.

-file Specify a path name of a file to substitute for the database of logged-in users by default.

# whoami — Display the Effective User Name

# Synopsis
```
/usr/ucb/whoami
```

# Description
whoami displays the login name corresponding to the current effective user ID. If you have used su to temporarily adopt another user identity, whoami reports the login name associated with that user ID. whoami gets its information from the getuid and getpw library routines (see getuid(2) and getpwnam(3)).

# Examples
The following examples show the current effective user ID. Because root does not have /usr/ucb in the search path, the full path name is required to execute the command as root.

```
castle% whoami
winsor
castle% su
# whoami
whoami: not found
# /usr/ucb/whoami
root
# exit
castle% su ray
castle% whoami
ray
castle%
```
