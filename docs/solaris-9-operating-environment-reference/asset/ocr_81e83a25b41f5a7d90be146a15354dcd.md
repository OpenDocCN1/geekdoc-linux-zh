In the following example, user gmarler in the Kerberos realm gmarler wants to use his gmarler/admin principal to administer some aspect of the Kerberos KDC. To do this, he needs to obtain the TGT for the principal gmarler/admin.

```
$ kinit garner/admin
Password for gmarler/admin@GMARLER.COM: <password>
$ klist
Ticket cache: /tmp/krb5cc_1067
Default principal: gmarler/admin@GMARLER.COM
```
