# Command Substitution

The standard output of a command enclosed in parentheses preceded by a dollar sign $(command) or a pair of grave accents (*) can be used as part or all of a word; trailing newlines are removed. In the second (aic) form, the string between the quotes is processed for special quoting characters before the command is executed. ( "Quoting Characters" on page 602). The command substitution $(cat file) can be replaced by the equivalent $(file). Command substitution of most special commands that do not perform input/output redirection are carried out without creating a separate process. Command substitution enables the output of a command to be substituted in place of the command name itself. Command substitution occurs when the command is enclosed as follows:

```
$(command)
```

or (backquoted version):

```
command
```

The shell expands the command substitution by executing command in a subshell environment and replacing the command substitution (the text of command$( ) or backquotes) with the standard output of command, removing sequences of one or more newlines at the end of the substitution. not removed; however, they can be treated as delimiters and eliminated during field splitting, depending on the value of IFS and quoting that is in effect.

Within the backquoted form of substitution, backslash retains its literal meaning, except followed by $(dollar sign, quote, backslash). The search for the matching backquote is justified by the first backquote without a preceding backslash; during this, if an uned backquote is encountered within a shell command, a here-document, an embedded command substitution of the $(command) form, or a quoted string, then undefined results occur. A single- or double-quoted string that begins but does not end within the ` sequence produces undefined results.
