# stty

```
hupcl (-hupcl)
Hang up (do not hang up) connection on last close.
hup (-hup) Same as hupcl (-hupcl).
cstopb (-cstopb)
Use two (one) stop bits per character.
read (-creat)
Enable (disable) the receiver.
crtscts (-crtscts)
Enable output hardware flow control. Raise the RTS (Request to Send)
em control line. Suspend output until the CTS (Clear to Send) line
is raised.
crtsoff (-crtssoff)
Enable (disable) input hardware flow control. Raise the RTS (Request)
to Send) modem control line to receive data. Suspend input when RTS
is low.
clocal (-clocal)
Assume a line without (with) modem control.
lk (-loblk)
Block (do not block) output from a nonconcurrent layer.
defeucw
Set the widths of multibyte Extended Unit Code (EUC) characters in
struct to default values for the current locale specified by
LC_CTYPE; width is expressed in terms of bytes per character, and
screen or display columns per character (see getwidth(3C) and
ldterm(7M).
```

# Input Modes

```
ignbrk (-ignbrk)
Ignore (do not ignore) break on input.
brkind (-brkint)
Signal (do not signal) interrupt (INTR) on break.
ignpar (-ignpar)
Ignore (do not ignore) parity errors.
parmark (-parmark)
Mark (do not mark) parity errors (see termio(7I)).
inpeck (-inpck)
Enable (disable) input parity checking.
istrip (-istrip)
Strip (do not strip) input characters to seven bits.
```
