Specify the range of collating elements between the range endpoints, inclusive, as defined by the current setting of the LC_COLLATE locale category. The starting endpoint must precede the second endpoint in the current order. Put the characters or collating elements in the range in ascending collation sequence.

```
[:class:]
```

Represent all characters belonging to the defined class, as defined by the current setting of the LC_CTYPE locale category. The following class names are accepted when using string2:alnum alpha beta cntrl digit graph print punct space xdigit.

In addition, character class expressions of the form [:name:] are recognized in those locales where the name keyword has been in the LC_CTYPE category.

When you specify the -d and -s options, any of the character class names are accepted in string2. Otherwise, only character class names lower or upper are valid in string2 and then if the corresponding character class lower is specified in the same relative position in string1. Such a specification is interpreted as a request for case conversion. When [:lower:] appears in string1 and [:upper:] appears in string2, the array contains characters from the lower mapping in the LC_CTYPE category of the current locale. When [:upper:] appears in string1 and [:lower:] appears in string2, the array contains characters from the lower mapping in the current locale. The first character from each mapping pair is in the string1, and the second character from each mapping pair is in string2 in the same relative position.

Except for case conversion, the characters specified by a character class expression are placed in the array in an unspecified order.

If the name for Class does not define a valid character class in the locale, the behavior is undefined.

```
[:equiv:]
```

Represent all characters or collating elements belonging to the same equivalence class as equiv, as defined by the current setting of the LC_COLLATE category. An equivalence class expression is allowed only in string1 or string2 when it is being used by the -d and -s options. The characters belonging to the equivalence class in the array in an unspecified order.

```
[:xn:]
```

Represent repeated occurrences of the character x Because this expression is used to map multiple characters to one, it is valid only when it occurs in string2. If you omit n it is zero, interpret it as large enough to extend the string2-based sequence to the length of the string1-based sequence. If n has a leading zero interpret it as an octal value. Otherwise, interpret it as a decimal value.
