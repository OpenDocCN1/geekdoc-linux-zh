# 751

decr

Return the value of the argument decremented by 1.

define

The second argument is installed as the value of the macro whose name is the first argument. Replace each occurrence of $n$ in the replacement text, where $n$ is a digit, with the $n$th argument. Argument 0 is the name of the macro. Replace missing arguments with the null string. Replace $^*$ with a list of all the arguments separated by commas. $s$ is like $s^*$ but quotes each argument with the current quotes.

defn

Return the quoted definition of the argument(s). This macro is useful for renaming macros, especially built-ins.

divert

Change the current output stream to the (digit-string) argument. m4 maintains 10 output streams, 0–9. The final output is the concatenation of the streams in numerical order; initially, stream 0 is the current stream. Output diverted to a stream other than 0 through 9 is discarded.

divnum

Return the value of the current output stream.

drl

Read and discard characters up to and including the next newline.

dumpdef

Print current names and definitions for the named items or for all you specify no arguments.

errprint

Print the argument on the diagnostic output file.

# /usr/ccs/bin/m4

eval

Evaluate the argument as an arithmetic expression, using 32-bit signed-integer arithmetic. The following operators are supported: parentheses, unary -, unary +, !, *, /, +, -, relational, bitwise &, && ||. You can specify octal and hex numbers as C. The second argument specifies the radix for the result; the default is 10. You can use the third argument to specify the minimum number of digits in the result.

# /usr/xpg4/bin/m4

eval

Evaluate the argument as an arithmetic expression using 32-bit signed-integer arithmetic. The following operators are supported: parentheses, unary -, unary +, !, *, /, +, -, <<, >>, relational, bitwise &, &&, and ||. Precedence and associativity are as in C. The second argument specifies the radix for the result; the default is 10. You can use the third argument to specify the minimum number of digits in the result.

ifdef

If the first argument is defined, use the value of the second argument; otherwise, use the third. If there is no third argument, the value is null. The word unix is predefined.

ifelse

This macro has three or more arguments. If the first argument is the same string as the second, use the value of the third argument. If not and if there are more than four arguments, repeat the process with arguments 4, 5, 6, and 7. Otherwise, the value is the fourth string, or if it is not present, null.

include

Return the contents of the file named in the argument.

incr

Return the value of the argument incremented by 1. The value of the argument is calculated by interpretation of an initial digit-string as a decimal number.

index

Return the position in the first argument where the second argument begins (0), or -1 if there is no second argument.

len

Return the number of characters in the argument.

m4exit

Exit from m4. Argument, if specified, it is the exit code; the default is 0.

m4wrap

Push back argument 1 at final EOF; for example, m44('cleanup').

maketemp

Fill in a string of X characters in the argument with the current ID.

popdef

Remove current definition of the argument(s), exposing the previous one, if any.

pushdef

Like define, but save any previous definition.

shift

Return all the first argument. Quote and push back the other arguments with commas in between. The quoting nullifies the effect of the extra scan that is subsequently performed.

sincludd

Identical to include, except saying nothing if the file is inaccessible.

substr

Return a substring of the first argument. The second argument is a 0-origin number selecting the first character; the third argument specifies the length of the substring. A missing third argument is taken to be large enough to extend to the end of the first string.

syscmd

Execute the command given in the first argument. Return no value. Return the return code from the last call to syscmd.

sysval

Transliterate the characters in the first argument from the set given by the second argument or the set given by it. No abbreviations.

traceon

Turn on tracing for all macros (including built-ins) with no arguments. Otherwise, turn on tracing for named macros.

traceoff

Globally turn off trace for any macros specified. Macros specifically traced by traceoff can be traced only by specific calls to traceoff.

undefined

Remove the definition of the macro named in the argument.

undivert

Immediately output the text from diversions named as arguments, or all diversions if you specify no argument. Text can be diverted into another diversion. Undiverting discards the diverted text.

# Examples

An example of a single m4 input file capable of generating two output files follows.
filel1.m4 could contain lines such as the following.

```
if (VER, 1, do_something)
if (VER, 2, do_something)
```

The Makefile for the program could include the following lines:

```
filel1.c :
    filel1.m4
    m4 -D VER=1 filel1.m4 > filel1.c...
filel2.c :
    filel2.m4
    m4 -D VER=2 filel2.m4 > filel2.c
```

You can use the -U option to define VER. If file1.m4 contains the following statements,

```
if (VER, 1, do_something)
if (VER, 2, do_something)
ifndef (VER, do_something)
```

then the we would contain

```
filel1.0.c :
    filel1.m4
    m4 -U VER filel1.m4 > filel1.0.c
filel1.1.c :
    filel1.m4
    m4 -D VER=1 filel1.m4 > filel1.c
filel2.2.c :
    filel2.m4
    m4 -D VER=2 filel2.m4 > filel2.2.c
```

# mach — Display Processor Type of Current Host

# Synopsis

/usr/bin/mach

# Description

The mach command displays the processor type of the current host.

Note — mach and uname -p return equivalent values. Independent software vendors and others who need to ascertain processor type are encouraged to use uname -p instead of the mach command.

# machid — Get Processor Type Truth Value

# Synopsis

/usr/bin/sun
/usr/bin/pdp11
/usr/bin/sparc
/usr/bin/u3b
/usr/bin/u32
/usr/bin/u35
/usr/bin/u3b15
/usr/bin/vax
/usr/bin/u370

# Description

Note — The machid family of commands is obsolete. Use uname -p and uname -m instead. The following commands return a true value (exit code of 0) if you are using an instruction that set the command name indicates.

- sun true if you are on a Sun system.
- dp11 true if you are on a PDP-11/45 or PDP-11/70.
- sparc true if you are on a computer using a SPARC processor.
- u3b true if you are on a 3B20 computer.
- ub2 true if you are on a 3B2 computer.
- ub5 true if you are on a 3B5 computer.
- u3b15 true if you are on a 3B15 computer.
- vax true if you are on a VAX-11/750 or VAX11/780.
- u370 true if you are on an IBM (Reg.) System/370 computer.

The commands that do not apply return a false (non-zero) value. These commands are often used within make files (see make(1)) and shell scripts (see sh(1)) to increase portability.
