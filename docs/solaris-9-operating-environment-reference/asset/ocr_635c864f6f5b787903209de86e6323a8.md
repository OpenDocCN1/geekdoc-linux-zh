# mailx, mail, Mail 781

Internal Variables Internal variables are internal variables. You can import them from the execution environment or set them by using the set command at any time. You can use the unset command to erase variables.

Note - You cannot unset internal variables that are imported from the environment.

+   - allnet Treat all network names whose last component (login name) matches as identical. The message-list message specifications behave similarly. Disabled by default. Also see the alternates command and the metavar variable.
