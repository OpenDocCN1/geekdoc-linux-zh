# sar — System Activity Reporter

# Synopsis

```
/usr/bin/sar [-aabcdkgmpqruvwy] [-o filename] t [n]
/usr/bin/sar [-aabcdkgmpqruvwy] [-e time] [-f filename] [-i sec]
[-s time]
```

# Description

Use the sar command to view a complete profile of all system activity during an interval. In the first synopsis format, sar samples cumulative activity counters in the operating system at n intervals of t seconds, where t should be 5 or greater.
