+   - LD_NOAUDIT When to any non-null value, the runtime linker ignores any local auditing libraries. Local auditing libraries can be defined within applications and shared objects. See the -p and -P options of ld(1). New in the Solaris 8 release.

+   - LD_NOAUXFL Set to any non-null value to disable alternative shared lookup. Auxiliary filters are a form of shared object. They enable an alternative shared object to be selected at runtime and provide the implementation for any symbols defined within the filter. See the -f option of ld(1).

+   - LD_NCONFIG When to any non-null value, the runtime linker disables configuration file processing. By default, the runtime linker tries to open and process a configuration file. New in the Solaris 8 release.

+   - LD_NODCONFIG A subset of LD_NCONFIG that ignores any directory cache information provided in a configuration file. New in the Solaris 8 release.

+   - LD_NODRECT When to any non-null value, the runtime linker ignores any binding information. Direct binding information instructs the runtime linker to search directly for a symbol in an associated object instead of using the default symbol model. The -B direct option of ld(1). New in the Solaris 8 release.

+   - LD_NOENVCONFIG Provide a subset of LD_NCONFIG in that any environment variables provided in a configuration file are ignored. New in the Solaris 9 release.

+   - LD_LAZYLOAD When to LD_LAZYLOAD to any non-null value, the runtime linker ignores a dependency's lazy loading load and loads it immediately. Dependencies labeled for lazy loading are not loaded into memory without explicit references have been made to them. See the -z lazyload option of ld(1). New in the Solaris 8 release.

+   - LD_NOBJALTER A subset of LD_NCONFIG that ignores any alternative object dependencies provided in a configuration file. New in the Solaris 8 release.
