# sar 1205

proc-sz, inod-sz, file-sz, lock-sz

Entries/size for each table, evaluated once at sampling point.

ov Overflows that occur between sampling points for each table.

-w Report system swapping and switching activity.
swpin/s, swot/s, bswin/s, bswot/s

Number of transfers and number of 512-byte units transferred for swap-ins and swap-outs (including initial loading of some programs).

- pswch/s Process switches.

-y Report TTY device activity.
rawch/s, canch/s, outch/s

Input character rate, input character rate processed by canon, output character rate.

rcvin/s, xtmintin/s, mdim/s
Receive, transmit, and modem interrupt rates.
