# Examples

Given file foo, with an ACL six entries long, the command
castle@ getfacl foo

```
prints
# file: foo
# owner: shea
# group: staff
user::rwx
user:spy::-
user:mookie:r--
group::r-
mask::rw-
other::---
```

Continuing with the above example, after issuing the chmod 700 foo command:
castle@ getfacl foo

```
prints
# file: foo
# owner: shea
# group: staff
user::rwx
user:spy::-
user:mookie:r-- #effective::--
group::r-- #effective::--
mask::-
other::---
```

Given directory doo, with an ACL containing default entries, the command
castle@ getfacl -d doo

```
prints
# file: doo
# owner: shea
# group: staff
default:user::rwx-
default:user:spy::-
default:user:mookie:r--
default:group::r--
default:mask::-
default:other::---
```
