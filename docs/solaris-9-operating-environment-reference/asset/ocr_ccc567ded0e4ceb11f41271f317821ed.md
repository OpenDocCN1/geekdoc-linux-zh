# postmd

Print pages whose numbers are given in the comma-separated list list contains single numbers and ranges N1-N2. A missing N1 means the lowest-numbered page, a missing N2 means the highest. The page range is an expression of logical pages instead of physical sheets of paper. For example, if you are printing two logical pages to a sheet and you specified a range of 4, two sheets of paper containing four page layouts would print. If you specified a range of 3-4 when requesting two logical pages to a sheet, then only 3 and 4 layouts would print and they would appear on one physical sheet of paper.

-o list

Print files in either p (portrait) or l (landscape) mode. Only the first character of mode is significant. The default mode is portrait.

-w window

Use window, comma-, or space-separated list of four positive integers, to choose the upper-left and lower-right corners of a submatrix from each of the input files. Row and column indices start at 1 in the upper-left corner and the numbers in the input files are assumed to be written in row order. By default, the matrix is displayed.

-x num

Translate the origin inches along the positive x axis. The default coordinate system is the origin fixed at the center of the page with x to the right and y up the page. Positive num moves everything up the page. The default offset is 0 inches.

-y num

One matrix only is displayed on each logical page, and each of the input files makes complete descriptions of exactly one matrix. Matrix elements are floating-numbers arranged in row order in each input file. White space, including newlines, is not used to determine matrix dimensions. By default, postmd assumes the matrix is square and sets the set of rows and columns to the square root of the number of elements in the input file. Supplying default dimensions on the command line with the -d option overrides this behavior, and in that case, the dimensions apply to all input files.

You can supply an optional header with each input file to set the matrix dimensions, the partition of the real line, the grayscale mode, and a window into the header. The header contains keyword/value pairs, each on a separate line. It begins on the first line of each input file and ends with the first unrecognized string, which should be the first matrix element. Values in the header take precedence but apply only to the current input file. Recognized keywords are dimension, interval, grayscale, and window. The syntax of the value string that follows keyword parallels what is accepted by the -d, -i, and -w options.
