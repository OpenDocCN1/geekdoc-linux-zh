# Options

+   -c
Dump section header information.
-C
Demangle C++ symbol names. New in the Solaris 8 release.
-d
Dump the contents of the .dynamic section.
-e
Dump the ELF header.
-G
Dump the contents of the .got section.
-h
Dump the contents of the .hash section.
-i
Dump the contents of the .interp section.
-k
Calculate the elf checksum. New in the Solaris 8 release: elf_checksum(3ELF).
-m
Dump the contents of the .note section. New in the Solaris 8 release.
-n
Dump the contents of the .note section.
-N name
Qualify an option with a specific name. For example, in a file that contains more than one symbol table, you can display the .dynym table with the following command:
% elfdump -s -N .dynym filename
-p
-r
Dump the contents of the relocation sections (that is, .rel[a]).
-s
Dump the contents of the symbol table sections (that is, .dynym and/or .symtab).

In the cases above, dump the archive symbol table. You can specify individual sections with the -N option or you can specify an archive symbol table with the special section name -N AR. In addition to the standard symbol table information, the version index of the symbol is also provided under the ver heading. New in the Solaris 8 release.

Dump the contents of the sections (that is, .SUNW_version). If you also use the -s option, then the st_other entry reported for symbols from the .dynym section are their version index.

+   -v file
Write the contents of a specified section to the named file. This option is useful for extracting an individual's section data for additional processing.

For example, you can extract the .text section of a file with the following syntax:

```
% elfdump -w textout -N .text filename
```

+   -y
Dump the contents of the .SUNW_syminfo section. New in the Solaris 9 release.
