
# tip 1417

framesize (num) The amount of data (in bytes) buffer between file-system writes when receiving files; abbreviated fr. If the fs capability is present, initially set framesize to the value of that capability; otherwise, set framesize to 1024.

halfduplex (bool) Do local echoing because the host is halfduplex; abbreviated hdx. If the hd capability is present, initially set halfduplex to on; otherwise, initially set halfduplex to off.

hardwareflow (bool) Do hardware flow control; abbreviated if. If the h capability is present, initially set hardwareflow to on; otherwise, initially set hardwareflow.

host (str) The name of the host to which you are connected; abbreviated ho. Set host permanently to the name given on the command line or in the HOST environment variable.

locale (bool) A synonym for halfduplex; abbreviated le.

log (str) The name of the file used to log information about outgoing phone calls. Initially set to /var/adm/aculog. log can be inspected or changed only by superuser.

parity (str) The parity to be generated and checked when talking to the remote host; abbreviated par. The possible values are:

- none Parity is not checked on input and the parity bit is set to 0 on output.
- one Parity is not checked on input and the parity bit is set to 1 on output.
- even Even parity is checked for input and generated on output.
- odd Parity is checked for input and generated on output.

If the pa capability is present, initially set parity to the value of that capability; otherwise, set parity to none.

phones (str) phones used to find hidden phone numbers. If the environment variable PHONES is set, set phones to the value of PHONES; otherwise, set phones to /etc/phones. You cannot change the value of phones from within tip.

prompt (char) The character that indicates an end-of-line on the remote host; abbreviated pr. Use this value to synchronize data transfers. The count of lines transferred during a file transfer is based on receipt of this character. If the pr capability is present, initially set prompt to the value of that capability; otherwise, set prompt to \n.

# tip

raise (bool) Uppercase mapping mode; abbreviated ra. When this mode is enabled, map all lowercase letters to upper case for transmission to the remote system. If the ra capability is present, initially set raise to on; otherwise, initially set raise to off.

raisechar (char) The input character used to toggle uppercase mapping mode; abbreviated rc. If the recipability is present, initially set raisechar to the value of that capability; otherwise, set raisechar to \377 (which disables it).

rawftp (bool) Send all characters during file transfers; do not nonprintable characters, and do not translate like \n to \r. Annotated raw. If the rw capability is present, initially set rawftp to on; otherwise, initially set rawftp to off.

record (str) The name of the file used to record a session script; abbreviated rec. If the capability is present, initially set record to the value of that capability; otherwise, set record to tip.

remote (str) The file used to find descriptions of remote systems. If the environment variable REMOTE is set, set remote to REMOTE, otherwise, set remote to /etc/remote. You can change the value of remote from within tip.

script (bool) Session scripting mode; abbreviated sc. When everything transmitted by the remote system in the script file is recorded. If the beautify switch is on, include only printable ASCII characters in the script file (those characters between 040 and 0177). Use the variable exceptions to indicate characters that are an exception to the normal beautification rules. If the sc capability is present, initially set script to on; otherwise, initially set script to off.

tabexpand (bool) Expand Tab characters to space characters during file transfers; abbreviated tab. When tabexpand is on, expand each Tab to eight characters. If the tb capability is present, initially set tabexpand to on; otherwise, initially set tabexpand to off.

tandem (bool) Use XON/XOFF flow control to limit the rate at which data is sent by the remote host; abbreviated ta. If the nt capability is present, initially set tandem to off; otherwise, initially set tandem to on.

verbose (bool) Verbose mode; When Verbose mode is enabled, print messages while dialing, show the current number of lines transferred during a file operation, and if the nv capability is present, initially set verbose to off; otherwise, initially set verbose to on.

SHELL (str) The name of the shell to use for the ~ command; default value is /bin/sh; otherwise, take the value from the environment.

HOME (str) The home directory to use for the ~c command; take the default value from the environment.

```
castle@ tip monet

monet@nmonet@ - Filename: reply.c
List command for remote host: cat reply.c
65 lines transferred in 2 minutes
monet@n... (or, equivalently)
monet@ -p sylvester.c
(actually echoes as ~[put sylvester.c)
32 lines transferred in 1 minute 3 seconds
monet@nmonet@ -t reply.c
(actually echoes as ~[take reply.c)

monet@n... (to print a file)
monet@ -Local command: pr -h sylvester.c
List command for remote host: cat sylvester.c
```

# tnfump - Convert Binary Trace Form (TNF) to ASCII

# Synopsis

The tnfump command to convert the specified binary Trace Form (TNF) files to ASCII. You can use the ASCII output to do analysis. The default mode (without the -r option) prints all the records (that generated by TNF_PROBE(3)) and orders the events by time.

# Options

- -r Do raw conversion of TNF to ASCII. Translate the output as a literal translation of the binary file and include all records in the file. This output is useful if you have a good understanding of TNF.
- -x Print all unsigned argument value in hexadecimal format instead of decimal.

# Examples

The following example converts the /tmp/trace-2130 into ASCII. The output uses long lines; they are wrapped in this example.

```
$ tnfump /tmp/trace-2130

tnf_name: "end" tnf_string: "keys main end:file cookie2.c4:line11:sundebug executing program"
```
