# pkgproto 1059

# pkgproto — Generate Prototype File Entries for Input to pkgmkm Command

# Synopsis

/usr/bin/pkgproto [-i] [-c class] [path1]
/usr/bin/pkgproto [-i] [-c class] [path1=path2...]

# Description

The pkgproto scans the indicated paths and generates prototype(4) file entries that can be used as input to the pkgmk(1) command.

If you specify no paths on the command line, standard input is assumed to be a list of paths. If the path name listed on the command line is a directory, the contents of the directory are searched. However, if input is read from the standard input, a directory specified as a path name is not used.

By default, pkgproto creates symbolic link for any symbolic link encountered (ftime). When you use the -i option, pkgproto creates a file for symbolic links (ftime). You would have to edit the prototype(4) file to assign file types as v (volatile), e (editable), or x (exclusive directory). pkgproto detects linked files. If multiple files are linked together, the first path encountered is considered the source of the link.

By default, pkgproto prints prototype entries to the standard output. However, you should save the output in a file (named Prototype or prototype) to be used as input to the pkgmk(1) command.

# Options

+   -i Ignore symbolic links, and record the paths as ftype=f (a file) or ftypes (a symbolic link).
-c class Map the class of all paths to class.

# Operands

+   path1 Path name where objects are located.
path2 Path name that should be substituted on output for path1.

# Examples

The following examples show uses of pkgproto and a partial listing of the produced:

```
castle% pkgproto /bin=bin /usr/bin=usr /etc=etc
f none bin/sed=/bin/sed 0775 bin bin
f none bin/sh=/bin/sh 0775 bin daemon
f none bin/sort=/bin/sort 0775 bin bin
f none usbin/sdb=/usr/bin/sdb 0775 bin bin
f none usbin/sh=/usr/bin/sh 0775 bin bin
d none etc/master.d 0755 root daemon
f none etc/master.d/kernel=/etc/master.d/kernel 0644 root daemon
f none etc/rc=/etc/rc 0744 root daemon
```
