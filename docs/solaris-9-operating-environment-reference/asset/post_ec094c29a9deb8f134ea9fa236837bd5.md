
# printf 1105

## Description

Use the printfenv command to print the values of the variables in the environment. If a variable is specified, only its value is printed.

## Examples

The following example displays the value for the EDITOR environment variable.

```
castle% printfenv EDITOR
/usr/bin/dtpad
castle%
```

## Attributes

See attributes(5) for descriptions of the following attributes:

| Attribute Type | Attribute Value |
|---|---|
| Availability | SUM/scpu |

## See Also

csh(1), echo(1), sh(1), stty(1), tset(1B), attributes(5), environ

## Diagnostics

If a variable is specified and it is not defined in the environment, printfenv returns an exit status of 1.

# printf — Write Formatted Output

## Synopsis

```
/usr/bin/printf format [argument...]
```

## Description

The printf command writes formatted operands to the standard output. The argument operands are formatted under control of the format operand.

## Operands

```
format
```

A string describing the format used to write the remaining operands. Use the format operand as the format string described on the formats(5) manual page, with the following exceptions.

- In any context other than a flag of a conversion specification, treat a space character in the format string as an ordinary character that is copied to the output.
- Treat a delta character in the format string as a delta character, treat as a space character.

## printf

- In addition to the escape sequences described on the formats(5) manual page (\, \a, \b, \f, \n, \r, \t, \v), write \o where o is a one-, two- or three-digit octal number, as a byte with the numeric value specified by the octal number.

- Do not precede or follow output from the d or u conversion specifications with blank characters not specified by the format operand.

- Do not precede output from the o conversion specification with os not specified by the format operand.

- An additional conversion character, b, is supported as follows. Take the argument to be a string that can contain backslash-escape sequences. The following backslash-escape sequences are supported.

- Convert the escape sequences in the formats(5) manual page (\, \a, \b, \f, \n, \r, \t, \v) to the characters they represent.

- Convert \ddd where ddd is a zero-, one-, or three-digit octal number to a byte with the numeric value specified by the number.

- Write \c and ignore any remaining characters in the string operand containing it, any remaining string operands, and any additional characters in the format operand.

The interpretation of a backslash followed by any other sequence of characters is unspecified.

Write bytes from the converted string until reaching the end of the string or the number of bytes indicated by the precision specification. If the precision is omitted, it is to be infinite, write all bytes up to the end of the converted string. For each specification that consumes an argument, evaluate the next argument operand and convert it to the appropriate type for the conversion, as specified below. Reuse the format operand as often as needed to satisfy the argument operands. Evaluate any c or s conversion specifications as if a null argument were supplied; evaluate extra conversion specifications as if a argument were supplied. If the format operand contains no conversion specifications and argument operands are present, the results are unspecified. If a character sequence in the format operand begins with a % character does not form a valid conversion specification, the behavior is unspecified.

Specify the strings to be written to standard output under the control of format. Treat the argument operands as strings if the corresponding conversion character is b, c, or s; otherwise, evaluate it as a c constant, as described by the ISO C standard, with the following extensions.

- Allow a leading + or - sign.

If the leading character is a single or double quote, the value is the numeric value in the underlying codet of the character following the single or double quote.

An argument operand cannot be completely converted into an internal value appropriate to the corresponding conversion specification, write a diagnostic message to standard error, do not exit with a 0 exit status, continuing any remaining operands, and write to output the value accumulated at the time the error was detected.

## Usage

Note that the printf command, like the printf() function on which it is based, makes no special provision for dealing with multibyte characters when using the %c conversion specification or when a precision is specified in %b or %s conversion specification. Application programmers should be extremely cautious about using either of these features when there are multibyte characters in the character set.

You cannot specify field widths and precisions as *.

For compatibility with previous versions of SunOS 5.x, the $ format specifier is supported for formats containing only % signs.

The %b conversion is not part of the ISO standard; it has been added as a portable way to process backslash escapes expanded in string operands provided by the echo command. see the echo(1) manual page for ways to use printf as a replacement for all the traditional versions of the echo command.

If an argument cannot be parsed correctly for the corresponding conversion specification, printf command reports an error, overflow and extraneous characters at the end of an argument being used for a numeric conversion are reported as error.

It is not considered an error if an argument operand is not completely used for a %c conversion or if a string operand's first or second character is used to get the numeric value of a character.

## Examples

The following example alerts the user and then prints and reads a series of prompts.

```
printf("Please fill in the following: %sName: %s"
read name
printf("Phone number: %s"
read phone
```

The following example reads a list of right and wrong answers from a file, calculates the percentages correctly, and prints them out. The numbers are right-justified and separated by a single Tab character. The percentage is written to one decimal place of accuracy.

```
while read right wrong; do
percent=$(echo "%scale=1;($right*100)/($right+$wrong)" | bc)
printf("%2d right\t%2d wrong\t(%%s%%)\n", $right, $wrong, $percent)
done < database_file
```

The printf command tells the user when conversion errors are detected while producing numeric output; thus, the following results would be expected on an implementation with 32-bit two-complement integers when %d is specified as the format operand.

Standard Output | Diagnostic Output
---|---
5a | 5 printf: 5a not completely converted
999999999 | 2147483647 printf: 9999999999: Results too large
-999999999 | -2147483648 printf: -9999999999: Results too large
ABC | 0 printf: ABC expected numeric value

Note that the value shown on standard output is what would be expected as the return value from the function strtol(3C). A similar correspondence exists between %u and strtol(3C), and %e, %f, %g and strtod(3C).
In a locale using ISO/IEC 646:1991 standard as the underlying codet, the command

```
printf "%d\n" 3 -3 \\'+3 "'-3"
```

produces

```
3 Numeric of constant 3.
3 Numeric value of constant 3.
-3 Numeric value of constant -3.
51 Numeric value of the character 3 in the ISO/IEC 646:1991 standard codyset.
43 Numeric value of the character + in the ISO/IEC 646:1991 standard codyset.
45 Numeric value of the character - in the SO/IEC 646:1991 standard multibyte.
```

> Note — In a locale with multibyte characters, the value of a character is intended to be the value of the equivalent of the wchar_t representation of the character.
