# tnfdump — Convert Binary Trace Normal Form (TNF) File to ASCII

# Synopsis

/usr/bin/tnfdump [-r] [-x] tnf-file...

# Description

The tnfdump command to convert the specified binary Trace Normal Form (TNF) trace files to ASCII. You can use the ASCII output to do performance analysis. The default mode (without the -r option) prints all the records (that were generated by TNF_PROBE(3TNF)) and the event descriptor nodes. It also orders the events by time.

# Options

+   -r
Do a raw conversion of TNF to ASCII. Translate the output as a literal translation of the binary TNF file and include all the records in the file. This output is useful only if you have a good understanding of TNF.

+   -x
Print all TNF unsigned argument value in hexadecimal format instead of decimal format. New in the Solaris 9 release

# Examples

The following example converts the file /tmp/trace-2130 into ASCII. The output uses very long lines; they are wrapped in this example.

```
$ tnfdump /tmp/trace-2130
probe tnf_name: "inloop" tnf_string: "keys cookie main loop:file
cookie2.c1:line50:sunwdebug in the loop"
probe tnf_name: "end" tnf_string: "keys cookie main end:file
cookie2.c4:line11:sunwdebug executing program"
```
