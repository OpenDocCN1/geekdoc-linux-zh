# Input/Output

Before a command is executed, you can redirect its input and output by using a special
notation interpreted by the shell. The following syntax can be used anywhere in a simple
command or precede a command without being passed on the invoked
command. Command and parameter substitution occur before word digit is used
except as noted below. File-name generation occurs if the patterns matches a single
file, and blank interpretation is not performed.

```
<word
```

Use word as standard output (file descriptor 1). If the file does
not exist, then create it. If the file exists and the noclobber option
is on, an error occurs; otherwise, truncate it to length 0.

```
>word
```

Same as >, except override the noclobber option.

```
|word
```

Use word as standard output. If the file exists, then seek to
EOF and append to it; otherwise, create the file.

```
>>word
```

Open file word for reading and writing as standard input.

```
<>word
```

If one of the above is preceded by a digit, then the file descriptor referred to
is specified by the digit (instead of the default 0 or 1). For example, ... 2&>1 means
file descriptor 2 is to be opened for writing as a duplicate of file descriptor 1.
