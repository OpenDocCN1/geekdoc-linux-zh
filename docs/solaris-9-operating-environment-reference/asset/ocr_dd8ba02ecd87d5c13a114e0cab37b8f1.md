# graph

The following example displays the data in a shell tool using the graph command.

```
castle% graph < data + plot -Tctrt
castle% ************************
```

![](bbox=[0.208, 0.233, 0.941, 0.693])

graph clears the screen and displays the graph positioning the prompt at the top of the screen. Any subsequent commands you type are displayed on top of the graph. Use the clear command to clear the screen after you display the plot.
