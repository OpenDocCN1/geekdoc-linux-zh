# sccs-get-get

# Options

+   -asequence sccs-comb(1); -r is an easier way for you to specify a version. -a supersedes -r when both are used.

+   -b Create a new branch. With the -e option to indicate that the delta should have a sid checked in a new branch. Instead of incrementing the level for the version to be checked in, indicate in p: file for the delta to be checked to either initialize a new branch and sequence (if there is no existing branch at the current level) or to increment the branch component of the sid if the b flag is not set in the s, file, ignore this option.

+   -c date-time Retrieve the latest version checked before the date and time indicated by the date-time argument. date-time takes the form yy[mm[dd[[hh:mm[ss]]]]]]. Units omitted default to maximum possible values; that, -c7502 is equivalent to -c750228325959. Any number of nonnumeric characters can separate the 2-digit components. If white-space characters occur, you must quote the date-time specification.

+   -e Retrieve a version for editing. Put a lock on the s file so that no one else can change in the version you have checked out. If the j flag is set in the file, the lock is advisory: get issues a warning message. Concurrent use of get -e for different sid is allowed; however, get does not check out a version of the file if a writable version is present in the directory. All SCCS file protections stored in the s file, including the releasing cycle, floor, and authorized user list, are honored

+   -g Get the SCCS version ID without retrieving the version itself. Use to verify the existence of a particular sid

+   -G g-file Use g-file as the name of the retrieved version.

+   -i sid-list |isid-list Specify a list of deltas to include in the retrieved version. The included deltas are noted in the standard output message. comma-separated list of sids. To specify a range of deltas, use a hyphen (-) separator instead of ID between two sids in the list.

+   -k Suppress expansion of ID keywords. -k is implied by -e.

+   -l[p] Retrieve a summary of the delta table (version log), and write it to a listing file with the l. prefix (called 1. file). When you use -lp, write write the summary to the standard output.

+   -m Precede each retrieved line with the sid of the delta in which it was added to the file. The sids separated from the line with a Tab.
