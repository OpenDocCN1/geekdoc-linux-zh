# Examples

The following example uses the paste command to list the files in a directory in one column, using a space character as the delimiter.

```
castle ls | paste -d" " -
085X01.DOC
085X02.DOC
085X03-1.DOC
085X042.DOC
085X08.DOC
085X09.RTF
085XD.ZIP
085XFILE.ZIP
085XINTR.ZIP
a.out
ibliography
bibliography.ig
C.str
DeadLetters
examples
file
kookaburra-1
ltr
Mail
new
castle%
```

The following example lists the contents of a directory in four columns, using the default table delimiter.

```
castle ls | paste - - -
085X01.DOC      085X02.DOC      085X03-1.DOC    085X042.DOC
085X08.DOC      085X09.RTF      085XDOCS.ZIP    085XFILE.ZIP
085XINTR.ZIP    a.out           bibliography    bibliography.ig
C.str           DeadLetters     examples        file
kookaburra-1    ltr             Mail            new
castle%
```

The following example combines lines from one file into single lines. The lines in the file are numbered to make it easier for you to see the results.

```
castle -s -d"\t" kookaburra-1

of the bush is he.

must be.

kookaburra, stop, kookaburra
9 Leave some there for me.               10

of the bush is he.

must be.
```
