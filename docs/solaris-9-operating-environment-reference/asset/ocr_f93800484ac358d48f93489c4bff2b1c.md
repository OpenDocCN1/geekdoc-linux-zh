# set, unset, setenv, unsetenv, export 1255

For each name, unset removes the corresponding variable or function value. You
unset the variables PATH, PS1, PS2, MAILCHECK, and IF.

With the export built-in, given names are marked for export to the
environment of successfully executed commands. If you specify no arguments, variable
names that have been marked for export during the current shell's execution are listed.
Function names are not exported.

# C Shell

With no arguments, set displays the values of all shell variables. Multiword values
dis as a parenthesized list. With the var argument alone, set assigns an empty
(null) value to the variable var. With arguments of the form var=value, set assigns
to value var, where value is one of the following.

```
word
(wordlist) space-separated list of words enclosed in parentheses.
```

Values are command- and file-name-expanded before being assigned. The set
var[in]=replaces the word in a multiword variable with word. Pattern
unset removes names whose match (file substitution) pattern.
variables are removed by unset; this command has noticeably disastrous effects.

With arguments, setenv displays all environment variables. With the VAR
argument, setenv sets the environment variable to var (or null). When
specify both the VAR and argument, setenv sets VAR to which must be a
single word or a quoted string. The PATH variable can take multiple arguments,
separated by commas. The most commonly used environment variables are USER, TERM,
and path. Use setenv if you need to change these variables. In addition, the shell sets
tWD environment variable from the csh variable when the latter changes.

The environment variables LC_TYPE, LC_MESS, LC_TIME, LC_COLLATE,
LC_NUMERIC, and LC_MONETARY take immediate effect when changed within the C shell.
See environ(5) for descriptions of these environment variables.

unset removes variable from the environment. As with unset, pattern
matching is not performed.

# K Shell

The options for the set built-in command have the following meanings.

+   -A Unset the variable name, and assign values sequentially from the list
  arg. If you use +A, do not unset the variable name.
-a Automatically export all subsequent variables that are defined.
-e If a command has a non-zero exit status, execute the ERR trap if set, and
  this exit is disabled while profiles are being run.
-f Disable file-name generation.
-h Interpret command as a tracked alias when first encountered.
-k Put all variable assignment arguments in the environment for a
  command, not just those that precede the command name.
-m Run background jobs in a process group, and print a line on
  completion. Return the exit status of background jobs in a completion
  message. On with job control, this option is turned on
  automatically for interactive shells.
