# calendar

Normally, this action is done daily by facilities in the UNIX operating system (see cron(1M)).

If the environment variable DATEMSK is set, calendar uses its value as the full path of a template file containing format strings. The strings consist of conversion specifications and text characters and can provide a richer set of allowable date formats in different languages by appropriate settings of the environment variable LANG or LC_TIME; see environ(5). See str(3C) for the list of all allowable conversion specifications.

# Notes

Appropriate lines being public may information for you to get reminder service. Your calendar's extended date of tomorrow does not account for holidays.

The argument works only on calendar files that are local; calendar is intended to work on calendar files that are mounted remotely with NFS. Thus, you should run calendar - only on disk machines where home directories exist; running it with a diskless client has no effect.

calendar is no longer in the root crontab. Because of the network burden, it is advisable to run calendar - in an environment running ybind(1M) with a passed name map. If, however, the usefulness of calendar outweighs the network impact, the superuser can run crontab -e to edit the root crontab. Otherwise, individual users can use crontab -e to edit their crontab to have cron invoke calendar without the argument - piping output to mail addressed to themselves.

# Examples

If there is no calendar file in the current directory, an error message is displayed.

```
castle% calendar
/bin/calendar: /export/home/winsor/calendar not found
castle%
```

In the following example, the calendar file in the user's home directory has three entries in it for today, for tomorrow, and for a few weeks from now. As you can see from the example, only the current calendar entries are displayed.

```
castle% cat calendar
Sep 15 - Dentist, 4:30
Chiropractic appointment, Sept 16 at 10:00 AM
Monday, September 28. Start new contract
castle%
castle% calendar
Sep 15 - Dentist, 4:30
Chiropractic appointment, Sept 16 at 10:00 AM
castle%
```

You can extend formats that are recognized by the calendar using the DATEMSK environment variable. First, create a template file named datemark. In that file, put the following template format:

```
%B eth of the year %Y
```

%B represents the full name,%e the day of the month, and %Y a four-digit year. This template recognizes dates of the calendar format:

March 7th of the year 1999 <Reminder>
