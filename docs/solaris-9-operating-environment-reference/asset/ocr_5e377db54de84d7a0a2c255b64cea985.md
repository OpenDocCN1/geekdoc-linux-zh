# ldapsearch — ldap Search Tool

# Synopsis

```
/usr/bin/ldapsearch [-n] [-v] [-t] [-A] [-B] [-L] [-R]
[-d debuglevel] [-f sep] [-S attribute] [-f file] [-D binddn]
[-w passwd] [-h ldaphost] [-M authentication] [-p ldaport]
[-b searchbase] [-s scope] [-a deref] [-l time limit] [-z size limit]
filter attrs...
```

# Description

ldapsearch opens a connection to an LDAP server and performs a search by
using the filter.

If ldapsearch finds one or more entries, the attributes specified by attrs
retrieved and the entries and values are printed to standard output. If no attrs
listed, all attributes are returned.

# Options

+   -a deref Specify what aliases dereferencing is. The possible values for
deref are never, always, search, or to find that aliases are
never dereferenced, always dereferenced, dereferenced when
searching. The finding the base object for the
search. The default is to never dereference aliases.
