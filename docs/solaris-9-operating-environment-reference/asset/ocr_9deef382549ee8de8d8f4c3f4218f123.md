The following example uses the -b option to display line numbers, omitting any
numbers for blank lines. Compare the results with those for the -n command.
caste% cat -b kookaburra

+   1 Kookaburra sits in in the old gum tree
2 Merry merry king of the bush is he
3 Laugh, kookaburra, laugh, kookaburra
4 Gay your life must be.

+   5 Kookaburra sits in the old gum tree
6 Eating all the gumdrops he can see
7 Stop, kookaburra, stop, kookaburra
8 Leave some for me.

The following example uses the -vet option to display all nonprinting characters in
the file kookaburra. The only nonprinting characters in this file are the newlines at the
ofof each line, which are displayed as a dollar sign ($).
caste% cat -vet kookaburra

Kookaburra sits in the old gum tree$
Merry merry king of the bush is he$
Laugh, kookaburra, laugh, kookaburra$
Gay your life must be.$
$

Kookaburra sits in the old gum tree$
Eating all the gumdrops he can see$
Stop, kookaburra, stop, kookaburra$
Leave some for me.$
