(1,$V/RE Make interactive global changes with the g command except, the first step, mark the lines that do not match the RE

(1,$w file Write the addressed lines into file If file does not exist, create it your file with mode 666 (readable and writable by everyone), unless your file creation mask dictates otherwise; see the description of the mask special command on sh(1). The currently referred filename unchanged unless is the very first file name mentioned since invoked. If you specify no file, use the currently referred filename if any (see the e and f commands). The current line (. unchanged, unless you specify format="%dn", number-of-bytes-written

If you replace with !, take the rest of the line to be a command with sh(1) whose standard input is the addressed lines. Such a command is not remembered as the current path name. This usage of the write command with ! is considered as last w command that wrote the buffer.

(1,$W file Write the addressed lines into file as the command above append the addressed lines to the end of fileif it exists. If file does not exist, create it as described for the write

Determine whether text for the e and r commands is encrypted. A null key turns off encryption. Subsequent e, r, and w commands use this key to encrypt or decrypt the text. An explicitly empty key turns off encryption. Also, see the -x option of ed.

=$ Write the addressed line to standard output in the following format: "%dn" line-number The current line number is unchanged.

!shell command Remainder the remainder after the line after to the UNIX system shell sh(1) to be interpreted as a command. In the text of the command, replace the unescaped character % with the referred filename; if you use a as the first character of the shell command, replace it with the text of the previous shell command. Thus, !! repeats the last shell command. If any replacements of % or ! are performed, modify the line to the standard output executed. The ! command writes ! to standard output on completion, unless you specify the -s option. The current line number is unchanged. Note that a command cannot be subject to a g or v command. You cannot use the ! command and the escape from the e, r, and w commands if you invoke ed from a restricted shell (sh(1)).

(.+1)newline Write the addressed line. A newline alone, equivalent to +1lp, is useful for stepping forward through the buffer. Set the current line number to the address of the written line.
