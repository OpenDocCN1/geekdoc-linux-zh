# spline — Interpolate Smooth Curve

# Synopsis

```
/usr/bin/spline [-akmnx]...
```

# Description

The spline command takes pairs of numbers from the standard input as abscissas and ordin of a function. It produces a similar set, which is approximately equally spaced and includes the input set, to the standard output. The cubic spline output has two continuous derivatives, and sufficient points to look smooth when plotted, for example, by graph(1).

# Options

- -a Supply abscissas automatically (they are missing from the input); specifying space by the next argument, or assume it is 1 if the next argument is not a number.

- -k Use the constant k in the boundary value computation. (2nd derivative at end) is k^(2nd derivative next to end) is set by the next argument. By default, k=0.

- -n Space output points so that approximately n intervals occur between the lower and upper x limits. (By default, n = 100.0.

- -p Make output periodic, that is, default, match derivatives at ends. First and last input values should normally agree.

- -x Next 1 (or 2) arguments are lower (and upper) x limits. Normally, these limits are calculated from the data. Automatic abscissas start at the lower limit (default, 0).

# split — Split a File into Pieces

```
/usr/bin/split [-linecount] [-l linecount] [-a suffixlength] [file
[name]]
/usr/bin/split [-b n |rk] [-a suffixlength] [file name]]
```

# Description

The split command reads file and writes it in linecount-pieces into a set of output files. The name of the first output file is name with aa appended, and so on lexicographically, up to zz (maximum 676 files). The maximum length of name is two characters less than the maximum file-name allowed by the file system. If you specify no output name, x is used as the default. Output files are named xaa, xab, and so forth.

# Options

- -linecount | -1 linecount
Specify the number of lines in each piece. Default is 1000.

- -a suffixlength
Use suffixlength letters to form the suffix portion of the file names of the split file. If you do not specify -a, the default suffix length is 2. If the sum of the operand and the suffixlengthargument would create a file name exceeding NAME_MAX, an error results; split exits with a diagnostic message and creates no files.

- -b n
Split a file into pieces bytes in size.
-b rk
Split a file into pieces n1024 bytes in size.
-b rm
Split a file into pieces n1048576 bytes in size.

# Operands

- file
The path name of the ordinary file to be split. If you specify no input file or isfile - use the standard input.

- name
The prefix to use for each of the files resulting from the split operation. If you specify no argument, use x as the prefix of the output files. The combined length of the basename of the prefix and suffixlength cannot exceed NAME_MAX bytes.

# Example

```
The following example splits a file into 50-line pieces.
castle$ ls -1 testfile
-rw-r--r-- 1 winner staff 6452 Mar 3 08:58:testfile testfile
```
