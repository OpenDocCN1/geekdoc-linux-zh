# srchtxt — Display Contents of, or Search for, a Text String in, Message Databases

# Synopsis

```
/usr/bin/srchtxt [-s] [-1 locale] [-m msgfile, ...] [text]
```

# Description

Use the srchtxt command to display all the text strings in message databases or search for a text string in message databases (see mkmgs(1)). These databases are files in the directory /usr/lib/local/locale/LC_MESSAGES (see setlocale(3C)), unless a file name given with the -m option creates a /. The locale is the name of the language in which the text strings are written.
