# tar 1381

The following example extracts all files in the include directory

```
castle$ tar xv include
x include/ , 0 bytes, 0 tape blocks
```

and all files under include...

The following example uses tar to transfer files across the Ethernet. First, you archive files from the local system (castle) to a tape on a remote system (host).

```
castle$ tar cvfb - 20 files | rsh host dd=/dev/rmt/0 obs=20b
messages from tar
castle$
```

The previous example creates a tarfile with the c letter, asks for verbose output from tar with the v modifier, specifies the name of the output tarfilewith the f modifier (the standard output is where the tarfile appears, as indicated by the sign), and uses the b modifier to specify the blocksize (20). If you want to change the blocksize, you must change the blocksize arguments both on the tar command and on the dd command.

The following example uses tar to retrieve files from a tape on the remote system back to the local system.

```
castle$ rsh -n host dd=/dev/rmt/0 bs=20b | tar xvBf - 20 files
messages from tar
castle$
```

The previous example extracts from the tarfile with the x letter, asks for verbose output from tar with the v modifier, tells it is reading from a pipe with the B function modifier, specifies the name of the input tarfile with the f function modifier (the standard input is where the tarfile appears, as indicated by the sign), and specifies the blocksize (20) with the b function modifier.

The following example creates an archive of the home directory on /dev/rmt/0 with an actual blocking factor of 19.

```
castle$ tar cvfb /dev/rmt/0 19 $HOME
```

The following example recognizes the archive's actual blocking factor without the b function modifier.

```
castle$ tar tvf /dev/rmt/0
tar: blocksize = 19
...
```

The following example recognizes the archive's actual blocking factor, using a large nominal blocking factor.

```
castle$ tar tvf /dev/rmt/0 30
tar: blocksize = 19
...
```
