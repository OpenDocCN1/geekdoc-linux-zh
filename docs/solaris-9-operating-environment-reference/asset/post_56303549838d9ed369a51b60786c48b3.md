
## mdb :: fpregs

[thread] $x, $X, $Y

Print the floating-point register set of the representative thread. When you specify thread-new in the Solaris 9 release—the floating-point registers of that thread are displayed. The thread expression should be one of the thread identifiers described in “Thread Support” on page 834.

- ::formats: List the available output format characters for use with the /, \, ?, and = formatting dcmds. The formats and their use are described in “Formatting dcmds” on page 830.
- ::grep command: Evaluate the specified command string and print the old value of dot if the new value of dot is non-zero. When the command contains whitespace or metacharacters, you must quote it. You can use :grep dcmd in pipelines to filter a list of addresses.
- ::help [dcmd-name]: With no arguments, the :help dcmd provides a brief overview of the facilities available in mdb. When you specify dcmd-name, mdb prints a usage summary for dcmd.
- ::signal :i: If the target is a live process, ignore the specified signal and allow it to be delivered transparently to the target. Delete all event specifiers that are tracing delivery of the specified signal from the list of traced events. By default, the set of ignored signals is initialized to the complement of the signals that dump by default (SIGCORE), except SIGINT, which is traced by default. New in the Solaris 9 release.
- $I: Display the list of signals that are ignored by the debugger and handled by the target. You can obtain more information on traced signals with :events dcmd.
- ::kill: Forcibly terminate the target if it is a live process. The target is also forcibly terminated when the debugger exits if it was created by :run. New in the Solaris 9 release.
- $L: Print the LWP of the representative thread if the target is a user process.
- $L: Print the LWP of each SP in the target if the target is a user process.
- ::load [-s] module-name: Load the specified dcmd. You can specify the module name as an absolute or relative path. If module-name is a simple name (that is, does not contain /), mdb searches for it in the library path. You cannot load with conflicting names; you must first unload the existing module. When you specify the -s option—new in the Solaris 9 release—mdb remains silent and does not issue any error messages if the module is not found or could not be loaded.

## ::log [-d | -e filename]

Enable disable the output log. mdb provides an interactive facility where you can log both the input commands and standard output to a file while the debugger is still interacting with you. The -e option enables logging to the specified file, or reopens logging to the previous log if you specify no file. The -d option disables logging. mdb enables logging if you specify a filename; otherwise, logging is disabled. If the specified log file already exists, mdb appends new log output to the file.

## ::map command

Map the value of dot to a corresponding value with the command and print the new value of dot. When the command contains whitespace or metacharacters, you must quote it. You can use ::map dcmd in pipelines to transform the list of addresses to a new list of addresses.

## ::mappings [name]
::sm [name]

Print a list of each mapping in the target's virtual address space, including the address, size, and description of each mapping. If you precede the dcmd by an address, mdb shows only the mapping that contains the given address.

## ::next [SIG]
::ie [SIG]

Step the target program one instruction, but over subroutine calls. If you specify an optional signal name or number (see signal), the signal is immediately delivered to the target part of resuming its execution. If no target is currently running, :next starts a new program as by :run and stops it at the first instruction. New in the Solaris 9 release.

## ::nm [-DP] [object]

Print the symbols associated with the current target. When you specify an optional address, mdb displays the symbol table entry for the symbol corresponding to the address. The symbol table for this object is displayed. ::nm recognizes the following options:
- -d: Print size in decimals.
- -D: Print .dyn (dynamic symbol table) instead of .symtab.
- -P: Print the private symbol table of .symtab.
- -g: Print only global symbols.
- -h: Suppress the header line.
- -n: Sort symbols by name.
- -o: Print value and size fields in octal.
- -p: Print symbols as a series of nm commands.
- -u: Print only undefined symbols.
- -v: Sort symbols by value.
- -x: Print value and size fields in hexadecimal.

## ::nm [-f] [-e] [-s] name

Add the specified symbol name to the private symbol table. mdb provides a private, configurable symbol table that can be used to interpose on the target symbol table, described in "Symbol Name Resolution" on page 826. ::nm also recognizes the following options:
- -e: Set the symbol to the value.
- -f: Set the type of the symbol to STT_FUNC.
- -o: Set the type of the symbol to STT_OBJECT.
- -s: Set the symbol of the symbol.

## ::nodel name

Delete the specified symbol name from the private symbol table.

## ::objects

Print a map of the target's address space, showing only those mappings that correspond to the primary mapping (usually the text section) of each of the known objects.

## ::offset type member

Print the offset of the specified member of the specified type. The type should be the name of a C structure. The offset is printed in bytes, unless the member is a bit field, in which case the offset is printed in bytes. The output is always suffixed with the appropriate units for clarity. The type name can use the '' scoping operator described in "Symbol Name Resolution" on page 826. You can use ::offset dcmd only with objects that contain debugging information designed for use with mdb. See "Symbolic Debugging Information" on page 852 for more. New in the Solaris 9 release.

Print the data structure at the specified virtual address, using the given type information. The type parameter can name a C struct, union, enum, fundamental integer type, or a pointer to any of these. If the type is a structured type, the ::print dcmd recursively prints each member of the struct or union. If the type argument is not present and a static or global STT_OBJECT symbol matches the address, ::print infers the appropriate type automatically. You can use ::print only with objects that contain symbolic debugging information designed for mdb. Refer to "Symbolic Debugging Information" on page 852 for more information.

- -a: Display the address of each member.
- -c: Limit the number of characters in a character array that are read and displayed as a string.
- -C: Enforce no limit on the number of characters in a character array that are read and displayed as a string.
- -L: Limit the number of elements in a standard array that are read and displayed.
- -L: Enforce no limit on the number of elements in a standard array that are read and displayed.
- -t: Display the type of each member.
- -x: Display all integers in hexadecimal. By default, a heuristic is used to determine if the value should be displayed in decimal or hexadecimal.

You can modify the default values for -c and -l with ::set or the command-line option as described in "Options" on page 852. New in the Solaris 9 release.

## ::quit

[thread] ::regs
[thread] $r

Print the general-purpose register set of the representative thread. When you specify thread-new in the Solaris 9 release—the general-purpose register of that thread is displayed. The thread expression should be one of the thread described in "Thread Support" on page 834.

## ::release [-a]
::R [-a]

Release the previously attached process or corefile. When you specify the -a option in the Solaris 9 release—the process is released and left stopped and abandoned. You can subsequently continue it with pr(see proc(1)) or resume it by applying mdb or another debugger. By default, a released process is forcibly terminated if it was created with mdb with ::run, or it is released and running if it was attached to mdb with the -p option or with the ::attach :Adcmds.
