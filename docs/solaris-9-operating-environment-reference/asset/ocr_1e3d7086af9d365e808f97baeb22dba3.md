# stty — Set the Options for a Terminal

# Synopsis

```
/usr/bin/stty [-a] [-g]
/usr/bin/stty [modes]
/usr/xpg4/bin/stty [-a | -g]
/usr/xpg4/bin/stty [modes]
```

# Description

The stty command sets certain terminal I/O options for the device that is the current standard input; without arguments, it reports the settings of certain options.
in this section, if a character is preceded by a caret (^), then the value of that
is the corresponding control character (for example, ^h is Control-H: Control-H is
as the backspace key). The sequence ~ means that an option has a null value.
