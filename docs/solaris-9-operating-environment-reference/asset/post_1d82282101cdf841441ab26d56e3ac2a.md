i/pattern

Search forward for the i-th occurrence of the regular expression pattern. Display the screen, starting two lines before the line that contains the i-th match for the regular expression pattern or the end of a pipe, whichever comes first. If more is displaying a line and there is no match, its position in the file remains unchanged. You can edit regular expressions using the erase and kill characters. Erasing back the first column cancels the search.

!command

Invoke a shell to execute command. Replace the characters % and t; when used within command, with the current file name and the previous shell command. If there is no current file name, do not expand %. Prepend a backslash to these characters to escape expression.

:f

Display the current file name and line number.

i:n

Skip to the i-th next file name in the command line or to the last file name in the list if i is out of range.

:p

Skip to the i-th previous file name in the command line or to the first file name if i is out of range. If used more is positioned within file, go to the beginning of the file. If more is reading from a pipe, ring the bell.

:q, :Q

Exit more (same as q or Q).

## mp — Text to PDL Pretty Print Filter

## Synopsis

## Description

The mp program runs in the Solaris 8 Operating Environment. When you call with -D or -O option, it reads each file in sequence and shows a prettied version of the contents in PostScript format to standard output. If you specify no filename argument, mp reads the standard input. If the standard input is a terminal, input is terminated by an EOF signal, usually Control-D.

- -D and -P options require the target printer name as an argument and produce the Printer Description Language (PDL) of the target printer. The -D option outputs the PDL to standard output. The -P option sends the PDL directly to the printer. In the absence of these options, mp produces PostScript output.

mp program accepts international text files of various Solaris locales and produces the output that is proper for the specified location. The output also contains proper text layout. For example, the complex text layout (CTL) is supported in mp, the output may contain bidirectional text rendering and shaping.

Mail items, news articles, ordinary ASCII files, complete flyers, and digests are all acceptable input formats for mp. The output format includes grayscale lozenges or the outline of the same dimensions as the lozenges, containing banner information at the top and bottom of every page.

## Options

- -a Format the file as a news article. The top banner contains the text Article from newsgroup, where newsgroup is the first news found on the Newsgroups: line.
- -A4 Use A4 paper size (8.26 x 11.69 inches).
- -c Specify the maximum number of characters to extract to the gecos field of the user's /etc/passwd entry. The default is 18.
- -C Instead of using From to denote the start of new mail messages, look for (and use) the value of the Content-Length mail header. If the Content-Length doesn't take you to the next From, then it is wrong, and mp looks for the next From in the mail folder.
- -d Format the file as a digest.
- -D target_printer Produce the PDL for the target printer. Requires X Server connection.
- -e Assume the ELM format. When printing tagged messages (with the p command), you must specify this in your ELM option.
- -ff Format the file for use with Filofax organizer.
- -fp Format the file for use with Franklin Planner.
- -F Instead of replacing the name of the recipient of the mail article, the top header displays the sender of the mail article. A useful option for people with their own printer.
- -1 Format output in landscape mode. Two pages of text are printed per sheet of paper.

## mp

-L localename Provide the locale of the file to be printed. If this command-line option is not present, mp looks for the MP_LANG environment variable. If that is not present, then the LANG environment variable is used. If none of these are are present then mp tries to determine the locale it is running in, and if it cannot, then it assumes it is running in the C locale.
-m Format the file as a mail folder, printing multiple messages.
- -o Format the file as an ordinary ASCII file.
- -p prologue Provide the prologue as the PostScript/Xpr file, overriding any previously defined file names. This file specifies the format of the print output. For PostScript output, the prologue file has a .ps extension; for Xpr clients (when you specify the -D option), this file has an .xpr extension. These files are defined in "Supplied Prologue Files" on page 876.
- -target_spool_printer Spool the PDL to the target printer. No output is sent to standard output. Requires X Print Server connection.
- -PS If the mail or digest message has PostScript as the text of the message, this is normally just straight through. Specifying this option prints PostScript as text.
- -s subject Use subject as the new subject for the printout. If you are printing ordinary ASCII files that have been specified on the command line, the subject defaults to the name of each of these files.
- -tm Format the file for use with the Time Manager organizer. Format the file for use with the Time/System International organizer.
- -US Use U.S. paper size (8.5 x 11 inches). U.S. is the default paper size.
-u config_file_path Specify an alternative configuration file to the default file /usr/lib/lp/locale_name/mp/mp.conf. You must use the absolute file path.
- -v Print the version of this release of mp.
- -w words The maximum number of words to extract from the gecos field of the user's /etc/passwd entry. The default is 3.
- -? Print the usage line for mp (notice that the ? character must be escaped if you use csh(1)).
