# gettext — Retrieve Text String from Message Database

Synopsis

```
/usr/bin/gettext [-d textdomain] [--domain=textdomain] [textdomain]
msgid
/usr/bin/gettext [-s] [-e] [-n] [-d textdomain | --domain=textdomain]
msgid
```

# Description

gettext retrieves a translated string corresponding to string msgid from message object generated with msgid(). The message object is derived from the optional argument textdomain if present; otherwise

Ordinarily gettext looks for its message object in
/usr/lib/local/lang/LC_MESSAGES, where lang is the language. If present, the TEXTDOMAIN environment variable replaces the path-name component up to lang. This command interprets escape sequences such as \t for Tab. Use \n to print a backlash. To produce a message on a line of its own, either put a \n at the end of msgid or use this in conjunction with printf(1).

When with the -s option, gettext behaves like echo (1). However, it does not simply copy its arguments to standard output. Instead, these messages found in the selected category are translated. The -s option is new in the Solaris 9 release.

> Note — This command is the equivalent of the library routine gettext(3C).

# Options

```
-d textdomain
--domain=textdomain
```

+   Retrieve translated messages from the domain textdomain, if
textdomain is not specified as an operand. New in the Solaris 9 release.

+   -e
Expansion of some escape sequences if used with the -s option.
New in the Solaris 9 release.

+   -n
Suppress printing trailing newline if used with the -s option. New in the Solaris 9 release.
