# diffmk — Mark Differences between Versions of a troff Input File

# Synopsis

/usr/bin/diffmk oldfile newfile

# Description

diffmk compares two versions of a file and creates a third version that includes "change mark"(.mc) commands for nroff(1) and troff(1), oldfile and newfile the old and new versions of the file. diffmk generates markedfile, which contains the text from newfilewithdiff(1) change-requests (.mc) inserted where newfilediffers from oldfile. Formatted, or inserted text in markedfiles shows a | at the right margin of each line. The position of deleted text is shown by a single .
