# iconv — Code Set Conversion Utility

## Synopsis

```
/usr/bin/iconv -f fromcode -t tocode [file...]
```

## Description

The iconv command converts the characters or sequences of characters in file from one code to another and writes the results to standard output. Should no conversion exist for a particular character, then it is converted to the underscore (_) in the target code set.

The list of supported conversions and the locations of the associated conversion tables are provided in the iconv (5) manual page.

The iconv command can use conversion modules (/usr/lib/iconv/*.so) or conversion tables (/usr/lib/iconv/*.tbc). If both a conversion module and a conversion table exist for a particular set conversion, iconv uses the conversion module.

Refer to the /usr/share/man/man5/iconv_locale.5 manual page in the Asian localized releases for information on supported code sets. For example, the following command displays the manual page describing the code set conversions that are supported for the Japanese locale page.

```
man -s 5 iconv_ja
```

Note — The iconv_locale.5 manual page may not exist in every localized release. Also, the iconv_locale.5 manual page does not exist in the U. S. (localized) release. 505

# indxbib — Create Inverted Index to Bibliographic Database

## Synopsis

```
/usr/bin/indxbib database-file...
```

## Description

A bibliographic reference is a set of lines constituting fields of bibliographic information. Each field starts on a line beginning with %, followed by a key letter, then a blank, and finally the contents of the field that may continue until the next line starting with %. A contains contains references (or other kinds of information) separated by blank lines.

indxbib makes an entry to the named database-file(that must reside within the current directory), typically for use by lookbib(1) and refer(1). As output, indxbib creates an entry file (with a .ia suffix), a posting file (.ic), in the working directory.
indxbib is a shell script that calls two programs: /usr/lib/refer/mkey and /usr/lib/refer/mkey, truncates words to 6 characters, and maps upper case to lower case. It also discards words shorter than 3 characters, words among the 100 most common English words, and numbers (dates) < 1000 or > 2099. You can change these parameters.

## Bugs

All dates should probably be indexed because many disciplines refer to literature in the 1800s or earlier.
indxbib does not recognize path names.

## Examples

The following example runs the indxbib command on a bibliographic database named bibliography and shows the contents of the output files.

```
castle$ indxbib bibliography
castle$ more bibliography.*
:::::::::
ibliography.ia
:::::::::
((((((((((((((((((<<<<<<<<<<<<<<<<<<<<PPPPPPPPPPPP
PPPPPPPPPTdddddddddddd*
```
