```
stack_size Specify the preferred page size for the stack of the
process(es). The preferred stack page size is set for the
existing stack and newly allocated parts of the stack as it
expands.
size must be a supported page size (see pagesize(1)) or 0, in which case
the system selects an appropriate page size (see memcntl(2)).nsize defaults to bytes and can be specified in octal (0o), decimal, or
hexadecimal (0xl). You can qualify the numeric value with K, M, G, or T
specify kilobytes, megabytes, gigabytes or terabytes. For example, you
specify 4 Megabytes as 4194304. 0x400000, 0x1000K, or 4M.
```

# Examples

The following example sets the preferred heap page size to 4M and the preferred stack
page size to 512K for all ora-owned processes commands that begin with ora.
example% ppgsz -o heap=4M, stack=512K -p `pgrep -u ora ^ora`
