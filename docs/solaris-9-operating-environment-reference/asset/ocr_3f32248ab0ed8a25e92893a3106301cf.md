# sortbib

two styles cannot be mixed together. This command reads through each database and pulls out each key fields, which are sorted separately. The sorted key fields contain the file pointer, byte offset, and length of corresponding records. These records are delivered by disk seeks, so sortbib cannot be used in a pipeline to read standard input.
The most common key letters and their meanings are given below.

+   %A Author's name.
%B Book containing article referenced.
%C City (place of publication).
%D Date of publication.
%E Editor of book containing article referenced.
%F Footnote number or label (supplied by refer).
%G Government order number.
%H Header commentary, printed before reference.
%I Issuer (publisher).
%J Journal containing article.
%K Keywords to use in locating reference.
%L Label used by -k option of refer.
%M Bell Labs memorandum (undefined).
%N Number within volume.
%O Other commentary printed at end of reference.
%P Page number(s).
%Q Corporate or foreign author (unreversed)
%R Report, paper, or thesis (unpublished).
%S Series title.
%T Title of article or book.
%V Volume number.
%X Abstract. Used by robib, not by refer.
%Y,Z Ignored by refer.

By default, sortbib alphabetizes by the first %A and the %D fields, which contain the senior author and date.
sortbib sorts on the last word of the %A line which is assumed to be the author's last name. A word in the final position, such as jr., or ed., is ignored if the name before it ends with a comma. Authors with two-word names or unusual constructions can be sorted correctly with the convention ' in place of a blank. A % field is considered to be the same as %A except that begins with the first, not the last word. sortbib sorts the last word of the %D line, usually the year. It also ignores leading letters (like A or The) when titles in the %T or %J fields; it ignores articles of any modern European language. If a sort-field is absent from a record, %T puts that before other records contains that field.
No more than 16 databases can be sorted together at one time. Records longer than 4,096 characters are truncated.
