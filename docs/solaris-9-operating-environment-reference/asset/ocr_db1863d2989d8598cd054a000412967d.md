In the following example, the word congratulations is 14 characters, so only the 10 characters are displayed.

```
castle$ banner congratulations
#### #### #### #### ## #### # # # ##
# # # # # # # # # # # # # # #
# # # # # # # ###### ###### # # ######
# # # # # # # # #
#### #### #### #### #### ###### #
```

If you want to print the banner, you can pipe the output to a printer, as shown in the following example.

```
castle$ banner happy birthday | 1p
castle$
```
