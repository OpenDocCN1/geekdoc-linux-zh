# volmmount — Call rmount to Mount or Unmount Medium

# Synopsis

```
/usr/bin/volmmount [-i][-e] [name | nickname]
/usr/bin/volmmount [-d]
```

# Description

volmmount calls rmount(1M) to simulate insertion (-i) or ejection (-e) of media. Simulating insertion means that rmount mounts the medium. Conversely, simulating ejection means that rmount unmounts the medium. However these actions can vary, depending on the rmount configuration and media type (see rmount.conf(4)).

For example, if you use the default /etc/rmount.conf and insert a music CD, it won't be mounted. However, you can configure rmount so that it calls workman workman whenever you insert a music CD.

The volmmount command enables you to override Volume Management's usual handling of media.
