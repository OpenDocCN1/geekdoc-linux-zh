# pre

"process filter mode." By default, process filter mode is off, and all processes generate trace records when they hit an enabled probe.

Some kernel events as interrupts cannot be associated with a particular user process. By convention, these events are considered to be generated by process ID 0. prev provides commands to turn process filter mode on and of off, to get the current status of the process filter mode switch, to add and delete processes (by process ID) from the process filter set, and to list the current filter set.

The process filter set is maintained when process filter mode is off but has no unless process filter mode is on.

When a process in the process filter set exits, its process ID is automatically deleted from the process filter set.

The following command controls the process filter switch and process filter set membership.

```
pfil {on | off | add pidlist | delete pidlist}
```

With no arguments, pfil prints the current process filter set and the state of the process filter mode switch. on or off sets the state of the process filter mode switch.

```
add pidlist
delete pidlist
```

add or delete processes from the process filter set. pidlist is a comma-separated list of one or more process IDs.

# Examples

See tracing(TNF) for complete examples showing, among other things, the use of perf for simple probe control.

When the process or kernel is started, all probes are disabled.

```
# Set the current and list setting
create sout name=/out/
# Sout = probes with "out" in
# value of "name" attribute
create sfoo /page/name-blionode # sfoo = union of
# probes with "page" in value of keys attribute
# probes with "page" as value of "name" attribute
# list the defined sets
list sets # list the defined sets
list fcns # list the defined probe fcns
```

```
# Commands to trace and connect probes
trace foobar='on'
# exact match on foobar
trace $all
# trace all probes (defined set $all)
connect &debug $foo
# connect debug func to probes $foo
```

```
# Commands to enable and disable probes
enable $all # enable all probes
enable /vm/ name-alloc # enable the specified probes
disable $sfoo # disable probes in set $foo
list history # list probe control commands
```

```
# Process control
continue # resumes the target process
```
