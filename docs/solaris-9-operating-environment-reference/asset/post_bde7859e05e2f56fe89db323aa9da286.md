# sccs-get, get — Retrieve a Version of an SCCS File

# Synopsis

```
/usr/ccs/bin/get [-begkmpst] [-p] [-sequence] [-c date-time |
[-date-time] [-G-file] [-i sid-list] [-isid-list] -r[sid]
-x sid-list [-xid-list] s.filename...
/usr/pg4/bin/get [-begkmpst] [-p] [-a sequence] [-c date-time |
[-date-time] [-G-file] [-i sid-list] [-isid-list] -r sid [-rsid]
-x sid-list [-xid-list] s.filename ...
```

# Description

Use the SCCS get to retrieve a working copy from the SCCS history file, using the specified options.

For each s.filename argument, get displays the SCCS delta ID (sid) and number of lines retrieved. If you use a directory name in place of s.filename, the get command applies to all files in directory. Unreadable files produce an error; processing continues with the next file (if any). A dash (-) as s.filename indicates that the names of files to be read from the standard input, one per line. The retrieved file normally has the same name as s.filename, less the prefix, and is referred to as g-file. For each file processed, get responds (to the standard output) with the sid and the number of lines retrieved.

# sccs-get, get

# Options

-a sccs-get(1); -r is an easier way for you to specify a version. -a supersedes -r when both are used.

-b Create a new branch. With the -e option to indicate that the delta should be checked in a new branch. Instead of incrementing the level for the version to be checked, initialize a new branch (if there is no existing branch at the current level) or increment the branch component of the sid if b flag is not set in s.file, ignore this option.

-c date-time Retrieve the latest version checked before the date and time indicated by the date-time argument. date-time takes the form yy[mm[dd[[hh:mm[ss]]]]. Units omitted default to maximum possible values; -c is equivalent to -c. Any number of non-numeric characters can separate the date-time specification.

-e Retrieve a version for editing. Put a lock on s.file so that no one else can change the version you have checked out. If e flag is set in the file, the lock is advisory: get issues a warning message. Concurrent use of get -e for different sids is allowed; however, get does not check out a version of the file if a writable version is present in the directory. All SCCS protections stored in the file, including the releasing cycle, and authorized user list, are honored.

-g Get the SCCS version ID without retrieving the version itself. Use to verify the existence of a particular sid.

-G-file Use g-file as the name of the retrieved version.

-i sid-list |isid-list Specify a list of deltas to include in the retrieved version. The included deltas are noted in the standard output comma-separated list of sids. To specify a range of deltas, use a hyphen (-) separator between two sids in the list.

-k Suppress expansion of ID keywords. -k is implied by -e.

-l[p] Retrieve a summary of the delta table (version log), and write it to a listing file with the l prefix (called l.file). When you use -lp, write the summary to the standard output.

-m Precede each retrieved line with the sid of the delta in which it was added to the file. The sid separated from the line with a Tab.

-n Precede each line with the n ID keyword and a Tab. When you use both the -m and -n options, the ID keyword precedes the sid and the line of text.

-p Write the text of the retrieved version to the standard output. Write all messages that normally go to the standard output to the standard error instead.

-s Suppress all output normally written to the standard output. However, fatal error messages (which always go to the standard error) are unaffected.

-t Retrieve the most recently created (top) delta in a given release, for example -rl.

# /usr/ccs/bin/get

-r[sid] Retrieve the version corresponding to the indicated sid(delta).

The sid for a given delta is a number, in Decimal format, composed of two fields: the release and level fields, and for branch deltas, the branch and sequence fields. For instance, if 1.2 is the sid, 1 is the release and 2 is the level number. If 1.2.3.4 is the sid, 3 is the branch and 4 is the sequence number.

You need not specify the sid to retrieve a version with get. When you omit -r or when you omit both release and level, get retrieves the highest release and level. If the flag is set to a sid in the s.file and you omit the sid get retrieves the default version indicated by that flag.

When you specify a release but omit the level, get retrieves the highest level in that release. If that release does not exist, get retrieves the highest level from the next-highest existing release.

Similarly with branches, if you specify a release, level, and branch, get retrieves the highest sequence in that branch.

# Usage

# ID Keywords

In the absence of -e or -k, get expands the following ID keywords by replacing them with the indicated values in the text of the source:

- %A Shorthand notation for an ID line with data forwhat(1) in the format %Y%Y %m%m %d%d.
- %B branch component.
- %C Current line number. Intended for messages output by the program as "this shouldn't happened" errors. It is not intended to be used on line to produce sequence numbers.
- %D Current date, in the format yy/mm/dd.
- %E Date newest delta was created, in the format yy/mm/dd.
- %F SCCS. file name.
- %G Date newest delta was created, in the format mm/dd/yy.
- %H Current date, in the format mm/dd/yy.
- %I sid of the retrieved version, in the format %R%.%L%.%B%.%S.
- %L sid component.
- %M Module name, either the value of the m flag in the file (see sccs-admin(1) or the name of the s.file less the prefix).
- %P Fully qualified s. file name.
- %Q Value of the q flag in the s.file.
- %R release component.
- %S sidsequence component.
- %T Current time, in the format hh:mm:ss.
- %U Time newest delta was created, in the format hh:mm:ss.
- %W Shorthand notation for an ID line with data forwhat, in the format %Z%Y%M %I.
- %Y Module type value of the t flag in the s.file.
- %Z Four-character string: # (# recognized by what.

# ID String

The table below explains how the SCCS identification string is determined for retrieving and creating deltas.

| SID(1) Specified | Option (2) | Other Conditions | SID Retrieved | SID of Delta to Be Created |
|---|---|---|---|---|
| none(3) | No | R defaults to mR | mR.mL | mR.(mL+1) |
| none(3) | Yes | R defaults to mR | mR.mL | mR.(mL.(bB+1) |
