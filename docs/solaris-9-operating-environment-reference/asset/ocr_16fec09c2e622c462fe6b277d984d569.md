# projects — Print Project Membership of User

# Synopsis

```
/bin/projects [-dv] [user]
```

# Description

The projects command was introduced in the Solaris 8 Operating Environment. Starting with the Solaris 9 Operating Environment, the projects provides the same functionality as the Sun Resource Manager, which it replaces. The projects command is a part of the Solaris 9 project management capability that you can administer with the Solaris Management Console (SMC) 2.1 projects tool. The projects management tools enable you to track and manage system resource use with /etc/projects database in a files environment or the project tables in a NIS or LDAP environment.
