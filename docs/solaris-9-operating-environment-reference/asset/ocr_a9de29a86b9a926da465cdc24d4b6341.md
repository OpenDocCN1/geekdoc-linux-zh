# atrm — Remove Jobs Spooled by at or batch

# Synopsis
/usr/bin/atrm [-afi] [[job #] [user]]...

# Description
Use the atrm command to remove delayed-execution jobs with the at(1) command that have not yet executed. You can display a list of these jobs and associated job numbers by using atq(1).
atrm removes each job you specify and/or all jobs belonging to the user specify, provided that you have the indicated jobs.
 in the Solaris 8 release, you can remove jobs belonging to other users only if you have solaris.jobs.admin privileges.

# Options
-a Remove all unexecuted jobs that were created by the current user. If invoked by superuser, flush the queue.
-f Force suppression of all information regarding the removal of the specified jobs.
-i Interactively ask if a job should be removed. If you respond with a y, remove the job.
