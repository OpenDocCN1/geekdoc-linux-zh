# ssh-http-proxy-connect — Secure Shell Proxy for HTTP

# Synopsis

```
/user/lib/ssh/ssh-http-proxy-connect [-h http_proxy_host]
[-p http_proxy_port] connect_host connect_port
```

# Description

Use the ssh-http-proxy-connect command, new in the 9 Operating
Environment, as a proxy command for ssh(1) that uses HTTP CONNECT. Typical use is for
connections external to a network that are allowed only through a proxy Web server.

# Options

+   -h http_proxy_host
Specify the proxy Web server through which to connect. Override the
HTTPPROXY and http_proxy environment variables if they are set.
