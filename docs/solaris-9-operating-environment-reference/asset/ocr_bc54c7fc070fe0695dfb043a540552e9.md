# spell, hashmake, spell, hashcheck - Report Spelling Errors

# Synopsis

```
/usr/bin/spell [-blvx] [+ local-file] [file]...
/usr/lib/spell/hashmake
/usr/lib/spell/spellin n
/usr/lib/spell/hashcheck spelling-list
```

# Description

Use spell command to check spelling in one or more files. The spell command collects words from the named files and looks them up in a spelling list. Words that neither occur nor are derivable (by applying inflections, prefixes, or suffixes) from words in the spelling list are returned to the standard output.

If you specify no arguments, words are checked from the standard input. spell ignores most coff(1), tbl(1), and egml constructs. Copies of all output are accumulated in the history file (spellhist), and a stop list filters out misspellings (for example, their-thy-user) that would otherwise pass.
By default, spell (like alloc) follows chains of included files (.so and .nx) and requests them unless such linked files are built with /usr/lib.
