The text argument consists of one or more lines, but all the last of which end with hide the newline. You must precede each embedded newline character in the text with a backslash. Other backslashes in text are removed and the following character is treated literally. Backslashes in text are treated like backslashes in the replacement string of s command can be used to protect initial lines and Tabs against the stripping that is done on every script. The rfile argument must terminate the command line and use of the file parameter creates that file if it does not exist or replaces the contents of an existing file. There can be at most ten distinct arguments.

Regular expressions match entire, not just individual lines, but a newline \n in a sed RE newline character is not allowed in a RE Also that you cannot use \n to match a newline character at the end of an input line; newline characters appear in the pattern space as a result of RE editing command.

Two of the commands take a command list that is a list of sed commands separated by newline characters, as follows:

```
{ command
command
}
```

You can precede the ( with blank characters and follow it with white space. You must precede the terminating ) with a newline character and follow it with blanks. You can precede or follow the braces with blanks. You can precede the command with blanks but cannot follow it with blanks.

The following table lists the editing commands.

| Max. of Addresses | Command | Description |
|---|---|---|
| 2 | {command-list} | Execute command-list only when the pattern space is selected. |
| 1 | a\ text | Append by executing N command or beginning a new cycle. Place text on the output before reading the next input line. |
| 2 | b label | Branch to the : bearing the label. If label is empty, branch to the end of the script. Labels are recognized as unique up to eight characters. |
| 2 | c\ text | Change by deleting the pattern space. Put text on the output. Start the next cycle. |
| 2 | d | Delete the pattern space. Start the next cycle. |
| 2 | D | Delete the initial segment of the pattern space through the first newline. Start the next cycle. (See the N command). |
| 2 | g | Replace the contents of the pattern space with the contents of the hold space. |
| 2 | g | Append the contents of the hold space to the pattern space. |
