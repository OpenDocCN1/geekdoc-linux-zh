# Environment Variables

AUDIODEV If you do not specify the -d and -a options, the AUDIODEV environment is consulted. If set, AUDIODEV contains the full path name of the user's default audio device. The default audio device is converted into a control device and used. If the AUDIODEV variable is not set, /dev/audioctl is used.
