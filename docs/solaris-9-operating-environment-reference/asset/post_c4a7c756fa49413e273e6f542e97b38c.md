# Notes

The CD writing process requires data to be supplied at a constant rate to the drive. It is advised to keep I/O activity to a minimum and shut down the related applications while writing CDs.

When making copies or extracting audio tracks, it is better to use an MMC compliant source CD-ROM drive. The CD writing device can be used for this purpose.

Before writing a CD, ensure it is blank by using the -n option and then use the -S simulation mode to test the system to make sure it provide data at the required rate. In case the system is not able to provide data at the required rate, try simulation with a slower write speed with the -p option. You can also try a cdrw with a higher priority with the priorityncl(1) command.

The -p option is for users who are aware of the CD-R/W drive and its capabilities to operate at different speeds. Some commercially available drives handle the drive speed setting differently, so use this option optionally.
Most commercially available drives allow writing beyond 74 minutes as long as the media has the capacity (such as 80-minute disc). However, capability of writing beyond 74 minutes might not be supported by the drive. If the drive supports such capacity, use the -c option to indicate that the tool should rely on the capacity indicated by the CD.

cdrw command uses rbac(5) to control user access to the devices. By default, cdrw is accessible to all users but can be restricted to individual users. Please refer to "Administering CD-R/W Devices" in the System Administration Guide: Basic Administration for more information.

# Options

- -a Create an audio disc. You must specify at least one audio-file name. Because a CD cannot have more than 99 audio tracks, you can specify no more than 99 audio files. The maximum audio data that can be written to the CD by default is 74 minutes unless you specify the -C option.

- -b all session Blank a CD-RW disc. You must specify the type of erasing by specifying the all or session argument.

- -c Copy a CD. If you specify no other argument, the default CD writing is assumed to be the source device as well. In this case, the copying operation reads the source CD into a temporary directory and prompts you to put a blank CD into the drive for copying to proceed.

- -C Use the stated capacity: Without this option, cdrw uses a default value for writable discs, which is 74 minutes for an audio CD or 681984000 bytes for a data CD.

- -d Specify CD writing device.

- -h Help. Print usage message.

# cdrw

132

Specify an image file for creating CDs. The file size should be less than can be written on a CD-R or CD-RW disc, which is 681984000 bytes by default or the CD stated capacity when you use the -C option. Also, it is better to have the file locally available instead of having it on an NFS-mounted filesystem, because the CD writing process expects data to be available continuously without interruptions.

- -i List all the cdrw functions in system default

- -m Use an alternate temporary directory of system default temporary directory for storing track data while copying a CD. You might use an alternate temporary directory because the amount of data on a CD can be huge (as much 800 Mbytes for an 80-minute audio CD) and the system default temporary directory might not have that space.

- -M Report CD status. cdrw reports whether the CD is blank, its table of contents, the last session's start address, and the next writable address if the disc is open.

- -O Keep the disc open. cdrw closes the session, but it keeps the disc open so that another session can be added later to create a multession disc.

- -p Set the CD writing speed. For example, -p 4 sets the speed to 4X. If you do not specify this option, cdrw uses the default speed of the CD writer. If you specify this, cdrw tries to set the drive speed to this value, but there is no guarantee of the speed actually used by the drive.

- -s Specify the source device for copying to the CD.

- -S Simulation mode. In this mode, cdrw does everything with the drive turned off, so nothing is written to the CD. You can use this to verify if the system can provide data at a rate good enough for CD writing.

- -T Specify the audio format to use extracting audio files or reading audio creation. The audio-type can be sun, wav, cda, or aur.

- -v Verbose mode.

- -x Extract audio data from an audio track.

# Examples

The following example creates a CD data.

```
example% cdrw -i /local/iso_image
```

The following example creates a CD from the directory tree /home/foo.

```
example% mkisofs -r /home/foo 2>/dev/null | cdrw -i -p 1
```

The following example extracts an audio track number 1 to /home/foo/song1.wav.

```
example% cdrw -x -T wav 1 /home/foo/song1.wav
```

The following example creates an audio CD from wav files on disc.

```
example% cdrw -a song1.wav song2.wav song3.wav song4.wav
```

The following example erases all data from a CD-RW disc in a CD-RW drive.

```
example% cdrw -b all
```

The following example creates a data CD on a system with multiple CD-R/RW drives.

```
example% cdrw -d cl6d0s2 -i /home/foo/iso-image
```

The following example checks whether the system can provide data to a CD-RW disc at a rate sufficient for the write operation.

```
example% cdrw -S -i /home/foo/iso-image
```

The following example runs cdrw at a higher priority (for root user only).

```
example# priocntl -e -p 60 cdrw -i /home/foo/iso-image
```

The following example creates the first session image in a multissection disc and records it onto the disc without closing it.

```
example% cdrw -0 -i /home/foo/iso-image
```

You can then add sessions to an open disc by creating an image with mkisofs(1M), using the session start and next writable address reported by cdrw.

```
example# cdrw -M
Track No. |Type |Start address
----------|------|-----------------
Leadout Data | 166564 | Data | 0nLast session start address: 162140
Next writable address: 173464
```

```
example% mkisofs -o /tmp/image2 -r -C 0,173464 -M /dev/rdsk/c0t2d0s2 /home/
```

# checknr — Check nroff and troff Input Files for Errors

Synopsis

```
/usr/bin/checknr [-fs] [-a .x1 .y1] .x1 .y2 .x3 .xn .ym] [filename]
```

Description

checknr checks a list of nroff(1) or troff(1) input files for certain kinds of errors involving mismatched opening and closing delimiters and unknown commands. checknr knows about the ms(5) and met(5) macro packages. You cannot define a one-character macro name by using the -a option.

# Options

- -f Ignore font changes.
- -s Ignore size changes.
- -a.xl yl... Add pairs of macros to the list. The pairs of macros are assumed to be (such as .DS and .DE) that should be checked for balance. Follow the -a option by groups of six characters, each group defining a pair of macros. The six characters are a period, the first macro name, another period, and the second macro name. For example, to define a pair .BS and .ES, use -BS.ES

- -c xl... Define commands that checknr would otherwise complain about as undefined.
