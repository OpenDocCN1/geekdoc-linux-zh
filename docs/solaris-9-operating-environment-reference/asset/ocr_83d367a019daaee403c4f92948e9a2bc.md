file2 A path name of the second file to be compared. If file2 is - , use the standard input.

If both file1 and file2 refer to standard input or refer to the same FIFO special, block special, or character special file, an error results.

# Usage

See largefile(5) for the description of the behavior of cmp when encountering greater than or equal to 2 Gbytes(**31 bytes).

# Examples

The following example does a byte-for-byte comparison of kookaburral kookaburra2.

```
castle cmp kookaburral kookaburra2
kookaburra2 differ: char 110, line 4
caste%
```

The following example does a byte-for-byte comparison of kookaburral kookaburra2 and skips the first 64 bytes in kookaburra2 before starting the comparison. Notice that the line and character numbers differ because of the skip offset.

```
castle cmp kookaburral kookaburra2 0 64
kookaburra kookaburra2 differ: char 1, line 1
kookaburra kookaburra2 differ: char 1, line 1
caste%
```

# Environment Variables

See environ(5) for descriptions of the following environment variables that affect the execution of cmp: LC_TYPE, LC_MESSAGE, and NLPATH.

# Exit Status

+   - 0 The files are identical.
- 1 The files are different; this includes the case where one file is identical to the first part of the other.
- >1 An error occurred.
