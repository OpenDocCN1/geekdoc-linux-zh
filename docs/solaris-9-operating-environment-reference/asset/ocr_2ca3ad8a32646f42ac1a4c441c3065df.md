Determine a path name commanding command history file. If the HISTFILE variable is not set, the shell may try to access or create a file .sh_history in the user's home directory. If the shell cannot obtain both read and write access to, or create, the history file, it uses an unspecified mechanism that enables the history file to operate properly. (References to history file in this section are understood to mean this unspecified mechanism in such cases.) fc may choose to access this variable only when initializing the history file. This initialization occurs when fc or sh first tries to retrieve entries from, or add entries to, the file as the result of commands issued by the user, by the ENV variable, or a system startup file such as /etc/profile. (The initialization process for the history file can depend on the system startup files that in contain commands that effectively preempt the user's settings of HISTFILE and HISTSIZE. For example, function definition commands are recorded in the history file unless you set the -nolog option. If the system administrator includes function definitions in some system startup file before the ENV file, the history file is initialized before the user gets a chance to influence its characteristics.) The variable HISTFILE is accessed initially when the shell is invoked. Any changes to HISTFILE do not take effect until another shell is invoked.
