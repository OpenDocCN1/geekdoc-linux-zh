Force encoding of binary data. Files that contain ASCII null or other control characters or do not end with a newline are recognized as binary data files. Store the contents of such files in the history file in encoded format. See uuencode(1C) for details about the encoding. This option is normally used in conjunction with -i to force admin to encode initial versions not recognized as containing binary data.
