# C Shell

The C shell limit built-in function limits the consumption by the current process or any process spawns, each not to exceed limit on the specified resource. If you omit limit, the current limit is displayed. If you omit resource, all limits are displayed. (Run the sysdef(IM) command to obtain the possible limits for your system. The values reported are in hexadecimal, which you can translate into decimal numbers with the bc(1) command).

+   -h Use hard limits instead of the current limits. Hard limits impose a ceiling on the values of the current limits. Only superuser can raise the hard limits.

resource is one of the following:

+   cpuptime Maximum CPU seconds per process.
filesize Largest single file allowed; limited to the size of the file system df(IM)).

+   datasize The maximum size of a process's heap in bytes.
stacksize Maximum stack size for the process (see swap(IM)).

+   coredumpsize Maximum size of a core dump (file). This value is limited to the size of the file system.

+   descriptors Maximum number of file descriptors. (Run sysdef()).
memoryize Maximum size of virtual memory.

+   limit is a number, with an optional scaling factor, as follows:
nh Hours (for cptime).
nk kilobytes (the default for all cptime).
nm megabytes and minutes (for cptime).
mm:ss Minutes and seconds (for cptime).

ulimit removes a limitation on resources. If you specify no resource, all resource limitations are removed. See the description of the limit command for the list of resource names.

+   -h Remove hard limits. Only superuser can use this option.
