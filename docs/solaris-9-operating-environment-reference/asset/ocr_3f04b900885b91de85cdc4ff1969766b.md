+   82 No files were found because of bad decryption password(s). If one file is successfully processed, however, the exit status is 1.

VMS interprets UNIX (or PC) return values as other, scarier-looking things, so unzip instead maps them into VMS-style status codes. The current mapping is as follows:

```
1 (success) Normal exit.
```

```
0x7ffff000 + 16*normal_unzip_exit_status
```

All others, where the ? is 2 (error) for unzip values 2, 9-11, and 80-82, and 4 (fatal error) for the remaining ones (3-8, 50, 51).

In addition, a compilation option expands on this behavior: defining RETURN_CODES results in a human-readable explanation of what the error status means.
