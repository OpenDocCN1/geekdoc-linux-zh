(s)r Read the contents of file into the buffer. If you do not specify file, use the currently remembered file name if any (see the e and f commands). Leave the currently remembered file name unchanged unless file is the very first file name mentioned since it was invoked. Address 0 is legal for r and reads the file at the beginning of the buffer. If the read is successful and you did not specify the -s option, write to output the number of characters read in the following format.

%d\n, <number of bytes read>
Set the current line (.) to the last line. If you replace file with !, take the rest of the line to be a shell command (see sh(1)) whose output is to be read. For example, sr !! appends the current directory to the end of the file being edited. A shell command is not remembered as the current name.

- (...) s/RE replacement/n
- (...) s/RE replacement/

Substitute by searching each addressed line for an occurrence of the specified RE You can specify zero or more substitution commands. In each line in which a match is found, replace all (nonoverlapping) matched strings by the replacement if you use the global replacement indicator g after If you do not use the global indicator, replace only the first occurrence of the matched string. If you specify a count after the command, replace only the count-th occurrence if the substitution fails on all addressed lines. You can use any character other than space or newline instead of the slash/) to delimit the RE and the replacement. Leave the current line (.) at the last line where a substitution occurs. Within the RE you can use the RE itself as a literal character preceding it with a backslash.

Replace the ampersand (&) in the replacement with the string matching the RE on the current line. You can escape the meaning of & in this context by preceding it with a backslash. As a more general feature, replace the characters \n where n is the nth regular expression of the specified RE enclosed within \( and \). When you nested parenthesized subexpressions, n is determined by counting occurrences of \( starting from the left. When the character % is the only character in the replacement, use the replacement used in the most recent substitute command as the replacement in the current substitute command; if there was no previous command, the use of % in this manner is an error. The % loses its special meaning

when it is in a replacement string of more than one character or is preceded by a backslash. For each backslash encountered in scanning replacement from beginning to end, the character following loses its special meaning (if any). It is unspecified what special meaning is given to any other than &, \, %, or digits.

You can split a line by substituting a newline into it. You must escape the newline in the replacement by preceding it with a backslash. You cannot do such substitution as part of a g or v command list. Set the current line number to the address of the last line on which a substitution is performed. If no substitution is performed, the current line number is unchanged. If a line is split, a substitution is considered to have been performed on each of the new lines for the purpose of determining the new current line number. A substitution is considered to have been performed even if the replacement string is identical to the string that it replaces.

The substitute command supports the following indicators:

- **count**: Substitute for the count-th occurrence only on each addressed line. count must be between 1 and 512, inclusive.
- **g**: Globally substitute for all nonoverlapping instances of the addressed line. count must be between 1 and 512, inclusive.
- **1**: Write to standard output the final line in which a substitution made. The line is written for the 1 command.
- **n**: Write to standard output the final line in which a substitution made. The line is written for the n command.
- **p**: Write to standard output the final line in which a substitution made. The line is written for the p command.
- **t**: Copy the addressed lines after (which line copied). The current line is unchanged. This command is similar to the m command.
- **u**: Undo the most recent change that modified the buffer. Set the current line number to the value it had immediately before the command.
- **v**: Substitute for the count-th occurrence only on each addressed line if the substitution fails.

(1,$)V/RE Make global changes with the g command except, the first step, the lines that do not match

- **w**: Write the addressed lines into file If file does not exist, create it with mode 666 (readable and writable by everyone), unless your file creation mask dictates otherwise; see the description of the mask
- **W**: Write the addressed lines into file as the command above append the addressed lines to the end of fileif it exists. If file does not exist, create it as described for the write
- **x**: Determine whether text for the e and r commands is encrypted. A null key turns off encryption. Subsequent e, r, and w commands use this key to encrypt or decrypt the text. An explicitly empty key turns off encryption. Also, see the -x option of ed.
- **=$**: Write the addressed line to standard output in the following format: "%dn" line-number The current line number is unchanged.
- **!shell command**: Remainder the remainder after the line to the UNIX system shell sh(1) to be interpreted as a command. In the text of the command, replace the unescaped character % with the referred filename; if you use a as the first character of the shell command, replace it with the text of the previous shell command. Thus, !! repeats the last shell command. If any replacements of % or ! are performed, modify the line to the standard output executed. The ! command writes ! to standard output on completion, unless you specify the -s option. The current line number is unchanged. Note that a command cannot be subject to a g or v command. You cannot use the ! command and the escape from the e, r, and w commands if you invoke ed from a restricted shell (sh(1)).

(.+1)newline Write the addressed line. A newline alone, equivalent to +1lp, is useful for stepping forward through the buffer. Set the current line number to the address of the written line.
