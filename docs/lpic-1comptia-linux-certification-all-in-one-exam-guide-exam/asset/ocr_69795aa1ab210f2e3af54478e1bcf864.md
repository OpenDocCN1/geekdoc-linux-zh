In addition to the command-line utilities discussed here, most Linux distributions provide some kind of graphical interface you can use to configure your network interfaces. For example, on SUSE Linux, you can use the Network Settings YaST module to configure your network board as well as the IP address information assigned to it. This module is shown in Figure 15-12.
