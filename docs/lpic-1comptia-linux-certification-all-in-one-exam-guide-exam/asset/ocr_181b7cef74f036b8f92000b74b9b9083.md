# ### Proper Use of the root User Account

One of the key mistakes made by new Linux users is excessive use of the root user account. There’s a time and a place when the root user account should be used. However, most of your work on a Linux system should be done as a non-root user account. The rule of thumb that you should follow is this: only use root when absolutely necessary. If a task can be completed as a non-root user, then it should be done so.

Why is the proper use of the root user account of concern? A few pages back, we discussed the risks of leaving a logged-in system unattended.
