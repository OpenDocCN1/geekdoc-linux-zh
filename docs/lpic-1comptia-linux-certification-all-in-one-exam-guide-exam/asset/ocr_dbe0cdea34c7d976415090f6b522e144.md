Whenever you delete a file from within the desktop environment, it is moved to the 
Trash. You can empty the *Trash* by right-clicking it and selecting **Empty Trash Bin**. You 
can also restore deleted files by doing the following:

+   1. Double-click the *Trash* icon on the desktop.
+   2. Right-click the *file or directory* you want to restore.
+   3. Select **Restore** in the pop-up menu shown in Figure 7-3.

You can browse other computers on the network by selecting **Network**. A screen 
similar to that shown in Figure 7-4 is displayed.
