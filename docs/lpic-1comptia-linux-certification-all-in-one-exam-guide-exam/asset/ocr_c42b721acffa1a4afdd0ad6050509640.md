# ### Using find

The *find* utility is fantastic tool that you can use to search the Linux file system. To use *find*, simply enter **find** path -name "*filename*" at the shell prompt. Replace *path* with the place in the file system where you want to start looking. Replace *filename* with the name of the file you want to search for.
