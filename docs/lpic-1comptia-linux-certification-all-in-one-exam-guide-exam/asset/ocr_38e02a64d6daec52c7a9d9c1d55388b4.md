However, also notice in Figure 12-10 that /proc contains a number of other files. Some of the more useful files include the following:

+   • cpuinfo  Contains details about the CPU installed in the system. You can use cat, less, more, or any text editor to view the contents of this file. An example from this file is shown here:

```
```text
processor          : 0
vendor_id          : AuthenticAMD
cpu family         : 16
model              : 2
model name         : AMD Phenom(tm) 8450e Triple-Core Processor
stepping           : 3
cpu MHz            : 2095.579
cache size         : 512 KB
fpu                : yes
...```
```

+   • devices  Contains a list of devices installed in the system.
+   • dma  Contains a list of dma channel assignments in the system.
+   • interrupts  Contains a list of IRQ assignments in the system. A sample is shown here:
