Linus Torvalds first developed Linux in the early 1990s.

Linux is licensed under the GPL.

Anyone can download and modify the Linux kernel source code.

Different software companies develop unique Linux flavors called distributions.

Linux can function as a server, desktop system, or firewall in a computer network.
