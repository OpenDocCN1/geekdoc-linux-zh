# Linux User Accounts

One of the key problems in the employment situation I described at the beginning of this chapter is the fact that my Windows 3.1 system didn’t implement individual user accounts. Whoever sat down in front of the computer and turned it on had full access to all of the data on the hard drive without a password. It didn’t matter if it was myself, my coworker, my boss, the custodian, or (of more concern) a corporate spy from a competitor. This was a great weakness of this particular operating system.

To remedy this problem, I needed a workstation operating system that used true user accounts. Fortunately, the days of the “userless” operating system are all but gone. Most modern operating systems include some type of user authentication system based on user accounts. Linux in particular performs this function very well.
