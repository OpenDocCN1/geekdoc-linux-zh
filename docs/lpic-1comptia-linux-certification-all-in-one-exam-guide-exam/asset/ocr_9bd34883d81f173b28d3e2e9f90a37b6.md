**CAUTION** The /boot partition must be created within the first 1024 cylinders of the hard disk. To be safe, I always create this partition such that it begins with cylinder 0.

Using these recommended partitions will add a degree of stability to your system. Unfortunately, this partitioning scheme doesn't use disk space efficiently. For example, your /home partition may run out of space and users won't be able to save additional data, even though there may be plenty of extra space available in other partitions on the disk. However, the added stability is worth the inefficiency. I've often heard it said that hard disks are cheap while data is priceless, and I believe this is true.

Once you've planned out your partitions, the next task you need to complete is to specify the software you want to install on your Linux system. Let's discuss how this is done next.

# # Selecting Software Packages

One of the things that I absolutely love about Linux is the wide array of open source software available. Your Linux distribution probably includes a fairly extensive sampling of packages that you can specify to installed along with the operating system. In fact, it's the inclusion of this extra software that makes your installation set so big. Most distributions require 6–8 CD's or a full DVD to store all the packages that you can install.

You'll be mesmerized the first time you see the list of available software. For example, openSUSE offers about 30 different games alone that you can install, as shown in Figure 5-11.

As a newbie, you may be tempted to install just about everything. Free software! However, you should not do this. You will install really powerful software that you probably don't want your end users to have access to. For example, you probably don't want your end users hosting their own web site from their desktop because you installed the Apache web server on your system. In addition, installing excess software on these systems could potentially open up hidden avenues of access, creating security issues.
