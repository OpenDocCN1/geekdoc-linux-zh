# Configuring xinetd and inetd

In this part of this chapter, you learn how to configure Linux super-daemons. Most Linux
distributions install a wide variety of network services during the system installation pro-
cess. Most of these services, such as Telnet, are very handy and provide a valuable service.
However, they aren’t needed most of the time. We need a way to provide these ser-
ices when requested but then unload them when they aren’t needed, saving memory,
reducing CPU utilization, and increasing the overall security of the system.
