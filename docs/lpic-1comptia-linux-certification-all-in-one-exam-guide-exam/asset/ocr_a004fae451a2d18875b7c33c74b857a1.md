**NOTE** A login shell is what you are using if your system boots to runlevel 3. We'll discuss runlevels in detail later in this book.

Even if your system is configured to boot into a graphical environment (runlevel 5), a login shell is still created at boot; you just don't see it. However, if you open a terminal window within your desktop environment, you are *not* using a login shell. Instead, you are running a non-login shell. This is shown in Figure 2-6.

This distinction is important because the type of shell you're using dictates what configuration files are used to customize your shell environment. These files are really text-based shell scripts that contain specific commands to be run. When the configuration file is run, all of the commands in the file are run in the order they appear in the file.
