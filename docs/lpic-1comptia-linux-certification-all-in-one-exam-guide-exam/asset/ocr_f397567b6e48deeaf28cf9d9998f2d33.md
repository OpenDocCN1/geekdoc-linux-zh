> **NOTE** The files shown in Table 17-5 are the log files used on a SUSE Linux system. Other distributions may use different files by default. You can customize your logging using the syslog.conf file, discussed next.

Logging on a Linux system is handled by the syslogd daemon. Instead of each daemon maintaining its own individual log file, most of your Linux services are configured to write log entries to /dev/log by default. This device file is maintained by the syslogd daemon. When a service writes to this socket, the input is captured by syslogd. The syslogd daemon then uses the entries in the /etc/syslog.conf file, shown in Figure 17-17, to determine where the information should go.

> **NOTE** Some Linux distributions use syslog-ng or rsyslogd instead of syslogd to manage logging. The logging daemon your system uses is configured in /etc/sysconfig/syslog by the SYSLOG_DAEMON= directive.

The syntax for the syslog.conf file is

```
facility.priority   file
```

A *facility* refers to a subsystem that provides a message. Each process on your Linux system that uses syslog for logging is assigned to one of the following facilities:
