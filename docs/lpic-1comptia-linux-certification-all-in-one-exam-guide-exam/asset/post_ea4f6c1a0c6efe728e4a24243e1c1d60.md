## Installing Linux

It’s finally time to start installing a Linux system! After spending hours creating a Linux deployment plan, most techies breathe a sigh of relief when they finally get their hands on their new software and start installing. This is of what we live for!

When installing new systems, I strongly recommend that you set up an isolated lab environment and install your systems there. This will give you a chance to observe the systems and ensure that everything is working properly before turning your users loose with them.

Once you’re sure everything is working correctly, you can move them from the lab environment to your users’ production environment.

As I mentioned at the beginning of this chapter, there are simply too many different Linux distributions available to include them all on the LPIC-1/CompTIA Linux+ exam or in this chapter. In this chapter, we’re going to review how to perform an installation of openSUSE 11.3. To complete this exercise, I strongly recommend that you choose one of the following options:

- Secure a lab system that you can experiment with. This should be a system with no important data on it. The exercises in this chapter will require you to wipe your hard drive clean and install Linux on top of it. Don’t do this without backing up any important data first! If you don’t, the data will be gone forever.
- Download a copy of VMware Workstation from www.vmware.com. This will allow you install multiple virtual Linux systems on top of your existing Linux or Windows system without repartitioning your hard drive. VMware Workstation offers a 30-day free evaluation period, but if its price tag is too steep beyond that, you can also download a copy of VMware Server. This version of VMware is free. It isn’t officially supported on nonserver systems, but I’ve used it successfully on many such systems.

Once you have a system prepared to install Linux on, you’re ready to get started. Let’s begin by discussing how to install SUSE Linux.

### Exercise 5-1: Installing a Linux System

![](img/fb5404b3ce1e1e1d707f5abc39814a4a_199_0.png)

**VIDEO** For more information watch Exercise 5-1.

In this exercise, we’re going to install an openSUSE workstation. At the time this book was written, SUSE Linux 11.3 was the most current version available. By the time you read this, a newer version may have been released, so you may need to adjust the steps presented here to accommodate the updated software.

To complete these exercises, you'll need a physical system or a virtual machine running within VMware Workstation that meets the following requirements:

- **CPU** Pentium III 500 MHz or faster processor (Pentium 4 2.4 GHz or higher or any AMD/64 or Intel EM64T processor recommended)
- **Memory** 512MB RAM (1GB recommended)
- **Hard disk** 16GB or larger
- **Optical drive** DVD
- **Display** 800 × 600 display resolution (1024 × 768 or higher recommended)
- **Mouse and keyboard**
- **Sound board** (optional)
- **Network board** (optional but strongly recommended)

![](img/fb5404b3ce1e1e1d707f5abc39814a4a_200_0.png)

> **CAUTION** If the system has already has an operating system installed, be sure to back up any important data before you install!

1. On a workstation with DVD burner, open a web browser and navigate to www.opensuse.org/ and select Get It.
2. Follow the instructions on the web page to download the latest SUSE Linux release appropriate for your CPU architecture.
3. Using your burning software, burn your image file to disc. Follow the directions in your burning software documentation for burning ISO images.
4. Insert your installation DVD into your target system's optical drive.
5. Configure your target system to boot from the CD/DVD drive first.
    a. Boot your target system and access the CMOS setup program. Your startup screen should display a message indicating which keystroke is required to access the setup program.
    b. Use your CMOS setup program to configure your system to boot from the optical drive first.
    c. Save your changes and reboot the system. The computer should now boot from the SUSE Linux installation disc. The screen in Figure 5-22 is displayed.
6. Select Installation. Wait while the YaST installer starts.
7. In the Language screen, select your *language*.
8. Read the license agreement; then select **Next**.
9. Verify that **New Installation** is marked.

**Figure 5-22**
Starting the SUSE Linux installation

![](img/fb5404b3ce1e1e1d707f5abc39814a4a_201_0.png)

10. **Deselect Use Automatic Configuration**; then select **Next**.
11. In the **Clock and Time Zone** screen, select your *region* and your *time zone*.
12. **Deselect Hardware Clock Set To UTC** (because your hardware clock probably isn’t).
13. If the current date and time displayed in the lower-right corner of the screen are not correct, select **Change** and make the necessary adjustments; then select **Apply**.
14. Select **Next**. The Desktop Selection screen is displayed, as shown in Figure 5-23.

**Figure 5-23**
Selecting your desktop

![](img/fb5404b3ce1e1e1d707f5abc39814a4a_201_1.png)

15. In the Desktop Selection screen, select GNOME Desktop. If you don't like using GNOME, you can also choose from the following desktop options:
    - **KDE** KDE is a graphical desktop environment similar to GNOME.
    - **Other** This option allows you to configure either a minimal graphical system or a text-only system.
16. Select Next.
17. Customize your disk partitioning by completing the following:
    a. Select Create Partition Setup.
    b. Select Custom Partitioning; then select Next. The Expert Partitioner screen is displayed, as shown in Figure 5-24.
    c. Browse to and select your hard disk drive in the device list under System View. Notice that Linux refers to the first hard drive in your system as /dev/sda. If you had two hard disks, the second one would be labeled /dev/sdb.
    d. Select Add.
    e. Select Primary Partition; then select Next.
    f. Mark Custom Size.
    g. In the Size field, enter 100 MB; then select Next.
