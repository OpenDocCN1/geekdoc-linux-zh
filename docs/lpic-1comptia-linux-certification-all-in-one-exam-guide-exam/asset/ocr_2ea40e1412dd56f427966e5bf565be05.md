# Managing Disk Partitions

When you initially installed your Linux system, you defined a series of partitions on your hard disk drives to host your file system. Depending on which distribution you installed, you probably used some kind of graphical or menu-driven partitioning utility to accomplish this.

After the system has been in use for a while, it’s likely that you will need to add more storage space at some point. If you install a new hard disk in the system, you will need to partition it and create a file system on it. To do this, most distributions provide you with some type of graphical partitioning utility.
