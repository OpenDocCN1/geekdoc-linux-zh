+   - **Speak Child Position** Speak the position of the current item if it is in a menu or a list.

+   - **Speak Tutorial Messages** Speak tutorial messages.

+   10. Select **Apply** to save your changes.

+   11. Select the **Magnifier** tab to configure how Orca magnifies the screen. The screen shown in Figure 7-22 is displayed.

+   12. If you want to enable the Orca magnifier, mark **Enable Magnifier**; then configure the following magnification options:

+   - **Zoomer Settings** The level of magnification Orca should use.

+   - **Border Settings** Enables if a window border for the magnifier and its size in pixels.

+   - **Cursor Settings** The size and color of the magnifier's cursor.

+   - **Cross-Hair Settings** The magnifier's area-targeting cursor.

+   - **Color Settings** The color of the magnified region.

+   - **Tracking and Alignment Settings** Mouse cursor tracking.

+   13. Select **Apply** to save your changes.

+   14. When you're done, select **OK**.
