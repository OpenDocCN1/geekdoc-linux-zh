# Chapter 8: Managing Linux Software

For example, to see if the 3dchess package we were working with previously is installed on the system, you could enter `apt-cache pgnames 3dchess` at the shell prompt, as shown in this example:

```
root@Ubuntu-Desktop:~# apt-cache pgnames 3dchess
3dchess
root@Ubuntu-Desktop:~#
```

To view information about the 3dchess package, you could enter `apt-cache show-pkg 3dchess` at the shell prompt, as shown next:
