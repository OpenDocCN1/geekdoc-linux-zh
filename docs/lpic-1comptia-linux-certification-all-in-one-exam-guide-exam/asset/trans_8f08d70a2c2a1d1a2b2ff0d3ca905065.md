既然你已经了解了本书的组织结构，现在是时候让你熟悉 LPI C-I/CompTIA Linux+ 认证计划及其相关考试了。让我们回顾以下内容：

- 考试补考

### 关于 LPI C-I/CompTIA Linux+ 认证

LPI C-I/CompTIA Linux+ 认证是一个绝佳的计划！这是一个由计算机技术工业协会（Computing Technology Industry Association，亲切地被称为 CompTIA）设计和管理的**厂商中立**认证。当前版本是通过合并两个非常流行且备受尊敬的 Linux 认证而来的：LPI 的 LPI C-I 认证和 CompTIA 的 Linux+ 认证。由于它们基本上是同一个认证，因此你会看到我在整本书中都使用“LPI C-I/CompTIA Linux+ 认证”这一术语。事实上，如果你通过了 Linux+ 考试，你只需将成绩提交给 LPI，就可以同时获得 LPI C-I 认证。

LPI C-I/CompTIA Linux+ 认证之所以被认为是厂商中立的，是因为其考试不基于任何特定厂商的硬件或软件。这在信息技术行业中 somewhat 独特。许多 IT 认证计划都围绕某个特定厂商的硬件或软件，例如微软的认证系统工程师（MCSE）认证、Novell 的认证 Linux 工程师（CLE）认证，或红帽（Red Hat）的认证工程师（RHCE）认证。

另一方面，LPI C-I/CompTIA Linux+ 认证旨在验证你对 Linux 操作系统的通用知识和技能，而不是针对任何特定的发行版。根据 CompTIA 的说法：

> *“由 LPI 支持的 CompTIA Linux+ 是一项高风险、厂商中立的认证，旨在验证初级 Linux 管理员所需的基础知识和技能……候选人的职位名称包括初级 Linux 管理员、初级网络管理员、系统管理员、Linux 数据库管理员和 Web 管理员。戴尔（Dell）、惠普（HP）、IBM、联想（Lenovo）和施乐（Xerox）等公司推荐或要求持有 CompTIA Linux+ 认证。”*

为了验证你的知识，CompTIA 要求你参加两门考试才能获得认证：LX0-101 和 LX0-102。LX0-101 考试涵盖以下一般知识领域：

- Linux 系统架构
- Linux 安装和包管理
- GNU 和 UNIX 命令
- 硬件设备
- Linux 文件系统和文件系统层次标准（Filesystem Hierarchy Standard）。

LX0-102 考试涵盖以下一般知识领域：

- Shell
- 脚本编写和数据管理
- 用户界面和桌面
- 管理任务
- 基本系统服务
- 网络基础
- 安全

CompTIA 已经发布了这两门考试的目标集，这些目标共同定义了 LPIC-1/CompTIA Linux+ 认证。这些目标规定了初级 Linux 系统管理员应该知道并能够执行的内容。你可以在 [http://certification.comptia.org/](http://certification.comptia.org/) 查看 LPIC-1/CompTIA Linux+ 的目标。Linux+ 考试中的所有题目都基于这些目标。如果你要获得 LPIC-1/CompTIA Linux+ 认证，那么你必须能够完成这些目标中包含的任务。随着我们深入阅读本书，你会发现完整的 LPIC-1/CompTIA Linux+ 目标列表非常详尽。

在最新版 LPIC-1/CompTIA Linux+ 认证中，你可以选择将考试成绩转发给 Linux 专业协会（Linux Professional Institute，简称 LPI）。同时通过 LX0-101 和 LX0-102 考试，你不仅可以获得 Linux+ 认证，还可以获得 LPIC 1 级认证。

让我们详细谈谈这些考试。

### 参加 LPIC-1/CompTIA Linux+ 考试

LPIC-1/CompTIA Linux+ 考试是定时考试，通过电子方式在计算机上交付。每门考试由 60 道题目组成，每门考试你有 90 分钟的时间完成。

> **注意** 你可能会看到多于 60 道题目。如果出现这种情况，是因为 CompTIA 在考试中混入了一些 beta 测试项目以进行评估。在这种情况下，你应该自动获得额外的考试时间来适应这些额外项目。

![](img/fb5404b3ce1e1e1d707f5abc39814a4a_36_0.png)

考试界面相当简单明了。题目在屏幕上逐条显示。你会看到一道问题以及一系列选项。你标记相应的选项，然后进入下一题。

每门考试主要由选择题组成。这种测试形式会给你一个问题，并要求你从选项列表中选出正确答案。大多数选择题只需要一个答案；然而，有些问题要求你从显示的列表中选择一个或多个正确答案。如果是这种情况，测试题目将以文本 “(Choose x.)” 结尾，其中 x 是你应该标记的选项数量。

完成考试后，电脑会立即进行评估，并打印出你的分数。要通过考试，你至少需要得到 800 分中的 500 分。希望你第一次就能通过考试。但是，如果没有通过，你的分数打印件将列出你答错题的目标领域。你可以利用这些信息复习并准备重考。

为了使考试在全球范围内可用，CompTIA 通过两家测试合作伙伴管理 LPIC-1/CompTIA Linux+ 考试：

- Prometric www.prometric.com
- Pearson VUE www.vue.com

要报名参加 LPIC-1/ Linux+ 考试，请选择其中一家测试合作伙伴并访问其网站。在那里，你会找到一个链接，帮助你找到附近的测试中心。大多数社区学院和技术学院都是授权的测试中心。只需指定你要参加的考试和你所在地的信息。然后，你会收到附近测试中心的列表，如图 1 所示。

然后，你可以使用 Prometric 或 VUE 的网站来安排考试并支付费用。你也可以直接拨打任一提供商的电话，通过电话安排考试。请注意，在他们给你报名之前需要验证你的身份，因此准备好在你致电或登录时提供你的社会安全号码。测试提供商会发送一封确认电子邮件，列出你考试的日期、时间和地点。

在考试当天，请确保预留足够的通勤时间。你永远不知道什么时候会遇到交通拥堵。此外，你应尽早到达，以便找到停车位并步行到测试中心。如果你在某个社区大学参加测试，你可能会发现从停车场到举行考试的建筑物有很长的距离要走。你在考试前最需要的不是感到匆忙和紧张！
