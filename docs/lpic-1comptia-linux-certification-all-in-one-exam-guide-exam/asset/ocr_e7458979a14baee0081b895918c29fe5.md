# Exercise 2-1: Working with Linux Shells

> **VIDEO** For more information watch *Exercise 2-1*.

In this exercise, you learn how to access the shell prompt, change shells, and alternate console screens. Complete the following:

+   1. Boot your Linux system to a shell prompt.
+   2. At your login prompt, authenticate to the system.
+   3. View your default shell by entering `echo $SHELL` at the prompt. Your default shell is displayed. On most systems, this will be `/bin/bash`.
+   4. Open an alternate console window by pressing `ALT+F2`. A new login prompt is displayed.
+   5. Authenticate again to the system.
+   6. Return to the first console screen by selecting `ALT+F1`.
+   7. Load the sh shell by entering `sh` at the prompt.
+   8. Return to your default shell by entering `exit` at the prompt.

> **NOTE** If your system booted into a graphical system, log in and then press CTRL+ALT+F1.

Now that you know how to access your bash shell, let's talk about how you configure it.
