Just as you can search for information using the man utility, you can also search for information using info. If you want to search for information within the node displayed, press Ctrl-s. When you do, the i-search prompt is displayed, as shown in Figure 2-16. At the i-search prompt, enter the text you want to search for and press ENTER. The first instance of the text you entered after your current cursor location is displayed. Pressing Ctrl-s again will jump to the next instance of the string you entered.
