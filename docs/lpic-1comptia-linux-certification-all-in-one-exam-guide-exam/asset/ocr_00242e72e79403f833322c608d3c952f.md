+   7. Press ESC; then enter :exit to save your changes to the file.
+   8. Restart the xinetd daemon by entering `service xinetd restart` at the shell prompt.
+   9. Configure the host firewall on your system to allow traffic on UDP port 37. Use the steps appropriate for the firewall software used by your Linux distribution.
+   10. At the shell prompt, enter `ifconfig` and note the IP address assigned to your system.
+   11. Boot your second Linux system and log in as a standard user.
+   12. Open a terminal session on the second system.
+   13. Switch to your root user account on the second system by entering `su` – followed by your root user’s password.
+   14. Verify that network communications exist between both Linux systems by entering `ping IP_address_of_first_system` from the shell prompt of the second Linux system.
