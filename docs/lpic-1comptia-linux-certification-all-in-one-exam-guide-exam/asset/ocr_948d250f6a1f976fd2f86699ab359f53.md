Other distributions, such as Fedora, use other utilities and commands to configure the X server system. Here is a sampling of utilities:

+   - system-config-display Runs the Display Settings utility that you can use to configure your video board, monitor type, resolution, and color depth

+   - system-config-keyboard Runs the Keyboard utility, which allows you to select your keyboard layout

+   - system-config-mouse Runs the Mouse utility, which allows you to configure your mouse

Be aware that the tools just mentioned tend to be distribution specific. They may be available on one distribution, but not another. To provide cross-distribution functionality, X.org (and XFree86) provides several generic configuration utilities that you can use to configure your X server settings. On X.org, you can use the xorgconf utility in a text-based environment to configure your video board, monitor, resolution, color depth, and so on. This utility is shown in Figure 7-11.

The great thing about xorgconf is that it tries to automatically detect your hardware for you (just as the SaX2 utility does). If you’re a little hazy about what exactly is installed in the system, this can be a real lifesaver. In fact, if you enter X —configure at the shell prompt, this utility will automatically detect all of your hardware and create a configuration file named /root/xorg.conf.new for you. You can then test the configuration before committing it by entering X -config /root/xorg.conf.new at the shell prompt. If everything looks to be correct, rename the file to /etc/X11/X11.xorg.conf to start using the new configuration.
