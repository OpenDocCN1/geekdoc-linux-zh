+   - All of the services managed by inetd are configured using this single configuration file.
+   - Each line in this file configures a single service to be managed by inetd.
+   - You can use TCP wrappers with inetd just as you did with xinetd, allowing you to control access to the network services running on the host using the /etc/hosts.allow and /etc/hosts.deny files.
