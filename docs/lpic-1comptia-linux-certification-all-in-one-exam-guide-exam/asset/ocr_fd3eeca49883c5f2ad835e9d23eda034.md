The Orca utility we’ve been working with can be used to support Braille devices. Select the Braille tab in the Orca preferences. The screen shown in Figure 7-23 is displayed.

Configure the following Braille options, as appropriate for your preferences and for your Braille devices:

+   - **Enable Braille Support** Configure Orca to use a Braille display.
+   - **Enable Braille Monitor** Configure a Braille monitor on the regular display, which allows you to visually observe what’s happening on the Braille display device.
+   - **Enable Contracted Braille** Use contracted Braille.
+   - **Abbreviated Role Names** Abbreviate role names on the Braille display.
+   - **Disable End of Line Symbol** Do not send the $! end-of-line characters to the Braille display.
+   - **Verbosity** Controls the level of information to be sent to the Braille display
+   - **Selection Indicator** How selected text on screen will be underlined on the Braille display
+   - **Hyperlink Indicator** How hypertext on screen will be underlined on the Braille display

Select OK to save your changes to the Orca Braille configuration.

# High-Contrast, Large-Text Themes

The last visibility accessibility option we’re going to look at here involves high-contrast, large-text desktop themes. The way you do this depends on the distribution you are using. For example, on a Fedora system you would select System | Preferences | Appearance. On an openSUSE system, you would select Computer | Control Center | Look and Feel | Appearance. Scroll down through the list and identify themes that use high-contrast or large print. Several examples are shown in Figure 7-24. Select the theme you want to use; then select Close.
