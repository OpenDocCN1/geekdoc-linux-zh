In this example, the cd . . command has been issued, changing from /var/log to the /var directory. To go up two directories, you can enter the cd ../.. command at the shell prompt:

```code
rtcracy@fs2:/var/log> cd ../..
rtcracy@fs2:/>
```

> **TIP** You can also use the .. alias to move up one level in the hierarchy and the ... alias to move up two levels. Most distributions define these aliases automatically for you in one of your bash configuration files.

Let's next look at the `ls` command.

# ## Viewing Directory Contents

To this point, you've learned how to view the current directory and change to other directories in the file system. Now you need to learn how to list the files and subdirectories that may exist within a directory. This is done using the `ls` command. If you enter `ls` at the shell prompt, the contents of the current directory are listed on the screen, as shown here:

```code
rtcracy@fs2:~> ls
bin Documents Music Public Templates test.txt words
Desktop Downloads Pictures public_html test2.txt Videos yourfile.txt
rtcracy@fs2:~>
```

As with the `cd` command, you can also provide an absolute path when using `ls`. This will cause `ls` to display the contents of the directory you specify. Consider this example:

```code
rtcracy@fs2:~> ls /var/log
cups mail ntp Xorg.0.log.old
apparmor faillog mail.err pk_backend.zypp YaST2
audit firewal1 mail.info pm-powersave.log zypp
boot.log gdm mail.warn samba zypper.log
boot.msg krb5 messages warn
boot.msgx lastlog NetWorkManager wtmp
ConsoleKit localmessages news Xorg.0.log
rtcracy@fs2:~>
```

In this example, the `ls /var/log` command has been issued, causing the contents of /var/log to be displayed. When working with `ls`, you can use a variety of options to customize how it works. Some of these options include the following:

+   * -a Displays all files, including hidden files. In the next example, the `ls -a` command has been issued in the `/home` directory:
+   
+   ```code
+   rtcracy@fs2:~> ls -a
+   . .xsd_auth .inputrc .test2.txt
+   .. .fontconfig .local test.txt
+   .bash_history .fonts .mozilla .themes
+   ```
+   
+   * -h Displays file sizes in human readable format, such as 1 K instead of 1024 bytes. It is useful when combined with the -l option.
+   * -l Displays files in long format (includes permissions, owner, size, date).
+   * -t Sorts files by modification time, newest first.
+   * -u Displays or sorts by user access time.
+   * -n List using numerical user and group IDs instead of names.
+   * -r Reverse the order when sorting.
+   * -R Recurse into subdirectories.
+   * -s Display the allocated amount of space for each file. This includes the disk blocks used, which may be greater than the actual file size.
+   * -i Print the inode number (a unique ID) for each file.
+   * -d List the directory itself, not the contents of the directory.
+   * -S Sort by file size, largest first.
+   * -a All files including hidden files (those starting with a dot).
