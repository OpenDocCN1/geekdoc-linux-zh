# Checking Partition and File Usage

One of the key problems you need to avoid when maintaining Linux file systems is running out of disk space. Linux provides the **df** and **du** utilities to help you keep track of how much space is used on a partition and which files are using that space.

The **df** utility shows you where your hard drive partitions, optical drives, and other storage devices (such as USB drives) are mounted in the file system. It also shows the total size of the device and how much of that space is used. Running **df** without any options shows information about all mounted file systems, as shown here:

```
ws1:~ # df
Filesystem              1K-blocks     Used Available Use% Mounted on
/dev/sda3               8254904    4399540   3436036  57% /
devtmpfs                 250408        208    250200   1% /dev
tmpfs                    251048       232    251612   1% /dev/shm
/dev/sda1                100184     25217    69760  27% /boot
/dev/sda4               3099352    199767    2742152   7% /var
/dev/sdb1               6321524    143608    5856620   3% /mnt/extraspace
ws1:~ #
```

You can also enter **df _filename_** at the shell prompt. This causes **df** to display information about the partition the specified file resides on, as in this example:

```
ws1:~ # df /mnt/extraspace/myfile.txt
Filesystem              1K-blocks     Used Available Use% Mounted on
/dev/sdb1               6321524    143608    5856620   3% /mnt/extraspace
ws1:~ #
```

Notice in the preceding examples that, by default, **df** displays space statistics in blocks. This is fine if you are a bit-head and like to calculate available disk space from the number of blocks. I don't. Therefore, I always use the **-h** option with the **df** command. This causes **df** to display space statistics in human-readable format, such as KB, MB, and GB. An example of the same information in the preceding examples is shown next using the **-h** option:

```
ws1:~ # df -h
Filesystem              Size     Used Avail Use% Mounted on
/dev/sda3               7.9G     4.2G  3.3G  57% /
devtmpfs                245M     208K  245M   1% /dev
tmpfs                   240M     232K  240M   1% /dev/shm
/dev/sda1               98M      25M   69M  27% /boot
/dev/sda4               3.0G     196M  2.7G   7% /var
/dev/sdb1               6.1G     141M  5.6G   3% /mnt/extraspace
ws1:~ #
```

Much better! If you want to view the type of file system used on each partition, you can add the **-T** option as well, as shown here:

```
ws1:~ # df -hT
Filesystem     Type         Size     Used Avail Use% Mounted on
/dev/sda3      ext4         7.9G     4.2G  3.3G  57% /
devtmpfs       devtmpfs     245M     208K  245M   1% /dev
```
