# Exercise 7-1: Working with Accessibility Settings

> **VIDEO** For more information watch *Exercise 7-1*.

Enable Accessibility Settings on your Linux system by doing the following:

+   1. Boot your Linux system and log in as a standard user. If you used the lab exercise in the previous chapter to install your system, you can log in as `tux` with a password of `M31inux273`.
+   2. If you installed an openSUSE system, select **Computer | Control Center | Personal | Assistive Technologies**.
+   3. Mark **Enable Assistive Technologies**.
+   4. Select **Keyboard Accessibility**.
+   5. Under Sticky Keys, mark **Simultaneous Keystrokes**; then select **Close**.
+   6. In the **Assistive Technologies Preferences** window, select **Close** and **Log Out**.
+   7. Log back in as `tux` with a password of `M31inux273`.
+   8. Open a terminal window and select the **View** menu. Notice that the keystroke combination to increase the size of the text in the window is `CTRL+`.
+   9. Click in the terminal window to close the View menu.
+   10. Press the `CTRL` key and release it; then press `SHIFT+`. Notice that the text size increased even though you weren’t holding down the `CTRL` key.
