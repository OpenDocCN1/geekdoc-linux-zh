1. **To configure how Orca reads text on the screen**, select the Speech tab. The screen shown in Figure 7-21 is displayed.

2. **To enable speech functionality**, mark Enable Speech.

3. **Configure the following speech options:**

+   * **Speech System** The speech system Orca will use. GNOME Speech Services is commonly used.

+   * **Speech Synthesizer** The speech synthesizer Orca will use, such as the Festival GNOME Speech Driver

+   * **Voice Settings** The voice to be used to identify hyperlinks or uppercase text

+   * **Punctuation Level** Punctuation to be spoken by the synthesizer

+   * **Verbosity** The level of information to be spoken

+   * **Table Rows** How Orca is to read table information (by cell or by row)

+   * **Progress Bar Updates** Speak progress bar updates

+   * **Speak Multicase Strings As Words** Break multicase words into individual words.

+   * **Break Speech Into Chunks Between Pauses** Insert brief pauses between spoken pieces of information.

+   * **Speak Blank Lines** Blank lines should be spoken.

+   * **Speak Indentation and Justification** Speak justification and indentation information
