> **NOTE** For example, Linux-based VMware ESX and ESXi hypervisors both require very specific network boards and disk controllers to be installed before they can be installed themselves.

In addition, the security requirements used by some organizations (especially governmental organizations) may dictate that some types of peripherals must be disabled. A good example is the USB interface. While the USB interface can be very handy, it also represents a security nightmare for high-security organizations. Imagine the data that could be carted off if someone with a thumb drive were to gain access to an unattended system!

The good news is that you’re not stuck with your integrated peripherals in an enabled state. They can be enabled or disabled quite easily. Once one is disabled, you can install whatever replacement peripheral you want to use in an expansion slot or USB port. On older systems, this was typically done using jumpers and shunts on the motherboard itself. Today, however, this is almost always done using the CMOS Setup program in the BIOS. How this is done varies from system to system, as there are many BIOS manufacturers using a wide variety of setup programs on the market today.

![](bbox=[0.15, 0.52, 0.22, 0.6])

> **NOTE** We’ll look at the role of the CMOS Setup program in more detail later in this chapter.

Usually, when you boot a system, you’ll see a message indicating which keystroke combination can be used to access the Setup program. In the example shown in Figure 12-5, you press the F2 key to enter Setup.

Once in the Setup program, you next need to locate the appropriate menu option to access the integrated peripherals menu. Again, because of the wide variety of Setup programs in use, this menu may be found in a variety of places. In the example shown in Figure 12-6, the options used to enable or disable the I/O devices integrated into the system are found under the Advanced menu.

After making the appropriate changes, press the appropriate key indicated (or select the appropriate menu option) to save your changes to the BIOS. In the example shown in Figure 12-6, you press the F10 key to do this. Once you are done, the peripherals you modified will be enabled or disabled on the motherboard accordingly.
