| Option | Description | Other Possible Values |
|:---|:---|:---|
| BOOTPROTO="static" | This option specifies that the interface use a static IP address assignment. | Set to dhcp to dynamically assign an address. |
| STARTMODE="auto" | This option specifies that the interface be brought online when the system is booted. | Set to manual to manually start the interface. Some distributions use onboot instead of auto. |
| IPADDR="192.168.1.81/24" | Assigns an IP address of 192.168.1.10 to the interface with a subnet mask of 255.255.255.0. | |
| NETMASK="subnet_mask" | If the netmask isn't assigned in the IPADDR parameter, you can use NETMASK= to assign a subnet mask to the interface. | |
| NETWORK="192.168.1.0" | Specifies the network address of the segment that the interface is connected to. | |
| BROADCAST="192.168.1.255" | Specifies the broadcast address of the segment the interface is connected to. | |
| REMOTE_IPADDR= | Specifies the IP address of the remote node in a peer-to-peer-type connection. | |
| MTU= | Specifies the size of the Maximum Transmission Unit (which is 1500 by default on an Ethernet network). | If your network uses jumbo frames, you can set this parameter to 9000. |
| ETHTOOL_OPTIONS= | Specifies command arguments used by the ethtool utility. | |
| LABEL_0='0' IPADDR_0='2607:f0d0:1002:0011:0000-0000:0000-0003' PREFIXLEN_0='64' | These parameters are used to assign an IPv6 address to the eth0 interface. | |
