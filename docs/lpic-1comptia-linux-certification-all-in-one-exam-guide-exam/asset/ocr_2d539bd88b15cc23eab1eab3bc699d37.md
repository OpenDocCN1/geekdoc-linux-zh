• Use the traceroute utility to trace the route your packets follow to reach a remote system. The syntax is `traceroute destination_host`.

• Use the route command or the netstat -r command to view your system's route table.

• Use the route command to add or remove routes from the route table.

• You can use the dig and host commands to test DNS name resolution.
