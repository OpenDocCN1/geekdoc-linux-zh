With this file created, I can specify that it be used as an input with the sort command. This is done by entering sort < words at the shell prompt. The sorted output is then displayed on the screen, as shown here:

```
rtracy@fs2:~> sort < words
How
What
Where
Who
Why
rtracy@fs2:~>
```
