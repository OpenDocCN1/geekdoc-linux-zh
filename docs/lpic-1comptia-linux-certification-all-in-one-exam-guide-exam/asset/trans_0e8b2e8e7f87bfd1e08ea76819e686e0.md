
项目范围包括项目时间表、分配给项目的资源以及需要完成的任务范围。我指出，任何项目都涉及在进度、资源和规模三者之间进行三向平衡。这些因素中任何一项的变化都会导致另外两项的变化。

部署计划中的下一个组成部分是选择要安装的 Linux 发行版。我强调，你必须评估系统的角色以确定最佳发行版。如果系统将为客户端系统提供网络服务，那么优化为服务器功能的 Linux 发行版将是最佳选择。如果系统将用作桌面系统，那么优化为工作站功能的发行版将是最佳选择。我还强调了技术支持的重要性。不受支持的发行版可能是实验实验室系统的绝佳选择，但对于将在生产环境中使用的系统，受支持的发行版是更好的选择。

部署计划中的下一个组成部分是验证您的硬件与您所选的 Linux 发行版是否兼容。我指出，大多数发行版都包含某种形式的硬件兼容性列表。您应该对照此列表检查您的硬件。您还应该验证您的硬件是否满足您发行版的最小系统要求。我强调，您必须为您的 CPU 架构下载正确版本的发行版。

验证硬件后，接下来应该规划您的文件系统。我强调，Linux 文件系统需要比其他操作系统中的文件系统更多的深思熟虑和规划。我指出，在实施 Linux 系统时，您可以从 ext2、ext3、Reiser 或 ext4 文件系统中进行选择。我讨论了每种文件的优点和缺点。我还指出，Linux 系统中的硬盘应该有多个分区。我讨论了交换分区的尺寸指南。我还强调，您应该考虑为 /, /boot, /home, /opt, /tmp, /usr, 和 /var 目录创建单独的分区。

接下来，您需要指定将安装在您的 Linux 系统上的软件。我强调，在实施 Linux 系统时，有许多软件包供您选择。但是，您应该只安装系统所需的软件。我还指出，大多数软件包都有依赖项，在安装 Linux 系统时必须考虑这些依赖项。

指定软件后，您的部署计划接下来应该指定需要在系统上创建哪些用户帐户。我指出，所有 Linux 系统都有一个名为 root 的超级用户帐户。我强调，root 应仅用于管理任务。您应该创建一个额外的标准用户帐户来完成日常任务。其他将使用系统的人员也将需要用户帐户。

接下来，您需要收集系统的网络信息。您首先需要指定系统是使用静态还是动态 IP 地址。如果系统使用静态寻址，则需要收集网络相应的 IP 地址、子网掩码、路由器地址和 DNS 服务器地址。您还需要定义系统将使用的主机名以及系统将驻留的 DNS 域。我还指出，大多数发行版都包含基于主机的防火墙，用于防止网络上的其他系统连接到您的系统。如果系统作为服务器运行，您需要确定需要在主机防火墙中打开哪些 IP 端口，以允许网络客户端连接到系统提供的服务。

接下来，您需要在部署计划中识别安装源。我指出，大多数系统管理员使用 DVD 安装 Linux。我讨论了如何从 Linux 供应商的网站下载 ISO 镜像并将其刻录到光盘上。我还指出，可以将安装文件复制到网络服务器上，从而允许您使用 SMB、NFS、HTTP 或 FTP 协议通过有线网络完成安装。此策略还允许您直接从互联网上的安装仓库安装 Linux 系统。我还指出，您可以使用 VNC 从运行在另一台计算机上的 Web 浏览器远程安装 Linux。

收集了这些信息后，您的部署计划就完成了。我强调，在手边保留这些文档在系统后期需要维护时可能非常有价值。手持部署计划，您就准备好安装 Linux 系统了。

## 加速复习

- 安装 Linux 需要比其他操作系统更多的规划。
- 系统管理员不喜欢规划或记录他们的工作。
- 正确规划和记录 Linux 部署从长远来看将节省时间和金钱。
- Linux 部署计划中的第一个组成部分是需求评估。
- 在需求评估中，您应该问以下问题：
  - 项目的目标是什么？
  - 利益相关者是谁？
  - 项目的范围是什么？
- 项目范围由三个必须保持平衡的因素组成：
  - 进度
  - 资源
  - 规模
- 使用项目管理软件可以帮助您规划和管理部署。
- 您的部署计划应指定您将使用哪个发行版。
- 在选择发行版之前，您应该确定系统的角色。
- 用于生产环境的系统应提供技术支持。
- 在部署之前，您应该验证您的软件是否能在您选择的发行版上运行。
- 您应该检查发行版的 HCL 以确定您的硬件是否兼容。
- 您应该验证您的硬件是否满足发行版的最小系统要求。
- 在下载发行版之前，您需要确定您的 CPU 架构。
- 您需要在部署计划中规划您的文件系统。
- 您应该选择以下文件系统之一：
  - ext2
  - ext3
  - Reiser
  - ext4
- 您应该为文件系统中的不同目录创建单独的分区，以确保系统稳定性。
- 交换分区的最佳尺寸取决于系统的用途。
- 您的实施计划应指定您打算在系统上安装的软件包。
- 您应该只安装所需的软件包。
- 安装软件时，您需要记住软件包依赖项。
- 您的部署计划应指定将在系统上创建哪些用户帐户。
- root 用户帐户是超级用户。
- 您应该仅将 root 用于管理任务。
- 您应该创建一个标准用户帐户用于日常任务。
- 您的部署计划应包括网络参数。
- 系统的 IP 地址信息可以动态或静态分配。
- 您需要确定在部署计划中如何配置基于主机的防火墙。
- 您的部署计划应指定将使用什么安装源来安装 Linux。
- 您可以从 Linux 供应商的网站下载 ISO 镜像并将其刻录到 DVD 上。
- 您可以将 Linux 安装文件复制到网络服务器，并使用 SMB、NFS、HTTP 或 FTP 协议跨网络安装。
- 您可以使用 HTTP 或 FTP 协议直接从互联网安装。
- 您可以配置 VNC，以使用 Web 浏览器从远程工作站完成安装。
- 为了练习安装 Linux，您应该购买一个实验室系统或使用 VMware。
