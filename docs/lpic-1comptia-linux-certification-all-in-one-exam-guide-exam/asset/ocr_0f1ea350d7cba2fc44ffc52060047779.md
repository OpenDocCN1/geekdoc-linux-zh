3. If you want to edit the menu item, press E. When you do, the screen in Figure 6-9 is displayed.

In this screen, you can arrow up or down to select the appropriate line and then press E again to edit. If you want to add a new line, press O. Press D to delete a line. Press B when you're ready to start the boot process. You can also press ESC to go back to the GRUB menu.

4. You can also access a GRUB prompt by pressing c. When you do, the screen shown in Figure 6-10 is displayed.

You can enter help at the grub> prompt to display information about creating GRUB menu lines from the grub> prompt. You can also press TAB to see a list of commands that you can enter at the grub> prompt. You can also press ESC to return to the GRUB menu.
