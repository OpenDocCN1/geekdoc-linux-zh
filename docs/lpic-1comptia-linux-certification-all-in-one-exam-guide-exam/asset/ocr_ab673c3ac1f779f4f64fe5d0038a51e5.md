To use locate, you must first install the findutils-locate package on your system. This process is shown on an openSUSE Linux system using the YaST utility in Figure 4-8.

> **NOTE** We'll discuss how to install packages in more detail in a later chapter in this book.

With the package installed, an index (named locate.db) of all the files in your file system will be create in /var/log. This index will be updated each day with the latest changes to the file system. However, you can also manually update the index using the updatedb command from the shell prompt. Be aware that updatedb does all the legwork for the locate utility; it can take some time to complete and will use up a lot of system resources in the process.

With the index updated, you can search for files by simply entering locate filename at the shell prompt. For example, if you wanted to search for a file named snmp.conf, you could enter locate snmp.conf. This is shown here:

```
fsg2:1: $ locate snmp.conf
/etc/cups/snmp.conf
/usr/share/man/man5/cups-snmp.conf.5.gz
fsg2:1: $
```

Notice that locate found two files that had the text string snmp.conf somewhere in the filename.
