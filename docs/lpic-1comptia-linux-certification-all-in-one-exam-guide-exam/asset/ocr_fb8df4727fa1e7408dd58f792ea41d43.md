# Exercise 18-4: Using GPG to Encrypt Files

![](bbox=[0.15, 0.12, 0.23, 0.2])

**VIDEO** For more information watch *Exercise 18-4*.

In this exercise, you will use GPG to encrypt a file and send it to a second Linux system. You will then export your public key, copy it to the second Linux system, and then use that key to decrypt the file that was sent. Complete the following:

+   1. Generate your GPG key pair by doing these things:
+      a. Boot your first Linux system and log in as a standard user.
+      b. Open a terminal session
+      c. Enter `gpg --gen-key` at the shell prompt.
+      d. When prompted to select the type of key you want to create, press ENTER to use the default option (1), which uses DSA and Elgamal.
+      e. When prompted to specify the size of the key, press ENTER to use the default size of 2048 bits.
+      f. When prompted to specify when the key will expire, press ENTER to select the default option (0), which specifies that the key never expire.
+      g. Enter y when prompted to confirm this selection.

![](bbox=[0.15, 0.52, 0.24, 0.6])

> **NOTE** We're doing this for demonstration purposes. In the real world, you should configure your keys to expire after a certain length of time. That way, if your key ever gets compromised, it will become invalid after a period of time.

+      h. Construct the user ID for the key by first specifying a username that is at least five characters long. Write down the username you entered, as you will need it later.
+      i. When prompted, enter your e-mail address.
+      j. When prompted, enter a comment of your choosing.
+      k. When prompted to confirm the user ID you created for the key, enter O to confirm it.
+      l. When prompted to enter a passphrase for the key, enter a unique passphrase.
+      m. When prompted, move the mouse, type characters on your keyboard, or open and close your optical disc drive door. When complete, your key pair has been generated!

+   2. Encrypt a file with GPG by doing the following:
+      a. At the shell prompt, enter `gpg -e -r key_user_name mystxtfile.txt`. Replace `key_user_name` with the real name you entered when creating your key.
+      b. You created the mystxtfile.txt file in Exercise 18-1. If you don't have this file, create a new one with this name.
