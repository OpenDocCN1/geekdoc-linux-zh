+   - cups-libs
+   - libgnomecups (optional)

After the packages are installed, the binary that provides the CUPS service is the cupsd executable located in /usr/sbin. The service is started and stopped using the cups init script in /etc/init.d or /etc/rc.d/init.d, shown in Figure 16-3.
