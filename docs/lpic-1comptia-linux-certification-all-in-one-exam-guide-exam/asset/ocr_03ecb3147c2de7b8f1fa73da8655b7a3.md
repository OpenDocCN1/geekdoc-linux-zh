However, if you're like me, your fingers don't always do what you tell them to do. When I do, the bash shell looks at the files in the `/tmp` directory that begin with `twm` and determines that I probably am referring to the `vmware-linux-tools.tar.gz` file. It then tacks this filename on to the end of the command. All I then have to do is press ENTER. Command completion is great!
