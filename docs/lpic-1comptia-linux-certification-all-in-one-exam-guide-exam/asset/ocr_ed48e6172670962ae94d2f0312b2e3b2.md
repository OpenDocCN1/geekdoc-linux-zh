# Chapter Review

In this chapter, you learned how to manage Linux processes. We began this chapter by reviewing what a process is. We established that whenever you run a command from the shell prompt or when a daemon is run by init, a process is created on the system as the associated program's code is loaded into RAM and the code is executed by the CPU. I pointed out that Linux is a multitasking operating system. Even though the CPU can only run one process at a time, Linux continually switches CPU time among many processes loaded into RAM, making it appear that the CPU is processing many processes concurrently.

I also pointed out that when the init process loads a daemon using an init script, a system process is created. When an end user enters a command at the shell prompt, a user process is created. User processes are associated with a shell session; system processes are not.
