You use the Assistive Technologies applet to configure on-screen keyboards. On a Fedora system, you would select System | Preferences | Assistive Technologies | Preferred Applications. The screen shown in Figure 7-17 is displayed. In the Mobility drop-down list, select the on-screen keyboard application you user wants to use. Mark Run At Start, and then select Close.
