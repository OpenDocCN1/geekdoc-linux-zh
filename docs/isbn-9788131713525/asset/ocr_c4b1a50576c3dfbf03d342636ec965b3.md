When your server and target kernel are configured, you need to provide your target Ethernet configuration via one of the methods described earlier. If your boot- loader supports a kernel command line, that is the easiest method. Here is what a kernel command line might look like to support NFS root mount:

```
console=ttyS0,115200 root=/dev/nfs rw ip=dhcp \
nfsroot=192.168.1.9:/home/chris/sandbox/pdna-target
```

# 12.3.5 U-Boot NFS Root Mount Example

U-Boot is a good example of a bootloader that supports a configurable kernel com- mand line. Using U-Boot's nonvolatile environment feature, we can store our ker- nel command line in a parameter specially named for this purpose. To enable the NFS command line in U-Boot, we do the following (all on one line in our serial terminal):

```
setenv bootargs console=ttyS0,115200 root=/dev/nfs rw \
ip=dhcp nfsroot=192.168.1.9:/home/chris/sandbox/pdna-target
```
