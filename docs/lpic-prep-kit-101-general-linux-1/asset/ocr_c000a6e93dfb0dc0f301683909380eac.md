8. What would be an equivalent command to apropos sort?

+   a. man sort
+   b. man -K sort
+   c. man -k sort
+   d. man -f sort

Answer a is incorrect; this would display the first man page on sort. Answer b is incorrect; this would search the content of all man pages for the word sort. **Answer c is correct; like apropos, man -k searches the header of the man pages for the search string.** Answer d is incorrect; man -f would search for only a complete command name.
