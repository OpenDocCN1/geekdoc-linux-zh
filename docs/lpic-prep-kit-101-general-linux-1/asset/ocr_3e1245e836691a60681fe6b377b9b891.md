5. Use File Permissions to Control Access to Files 210-215
Set permissions on files, directories, and special files; use special permission modes such as suid and sticky bit; use the group field to grant file access to workgroups; and change default file creation mode. Includes the chmod and umask commands. Requires an understanding of symbolic and numeric permissions.

6. Manage File Ownership Change the owner or group 208-210
for a file and control what group is assigned to new
files created in a directory. Includes the chown and
gtgrp commands.

7. Create and Change Hard and Symbolic Links 139-142
Create hard and symbolic links, identify the hard
links to a file, copy files by following or not following
symbolic links, and use hard and symbolic links for
efficient system administration.

8. Find System Files and Place Files in the Correct
Location Understand the filesystem hierarchy standard,
know standard file locations, know the purpose of
various system directories, and find commands and
files. Involves using the find, locate, which, and
updatedb commands. Involves editing the
/etc/updatedb.conf file.

6. Boot,
Initialization,
Shutdown,
Runlevels

1. Boot the System Guide the system through the 28-37
booting process, including giving options to the
kernel at boot time, and check the events in the
log files. Involves using the dmesg (LILIO) command.
Involves reviewing the /var/log/messages,
/etclilo.conf, /etc/conf.modules, and
/etc/modules.conf files.

2: Change Runlevels and Shut Down or Reboot System 30-40
Securely change the runlevel of the system, specifically
to single-user mode; halt (shut down) the system; or
reboot the system. Make sure to alert users beforehand
and properly terminate processes. Involves using
the shutdown and init commands.
