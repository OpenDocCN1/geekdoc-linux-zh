处理文件将是 Python 语言中会出现的一个话题。当您在 Python 中工作时，有时我们希望将正在处理的一些数据存储起来，使您以后需要数据时可以使用。您可以选择以稍后能找到并看到它在您正在处理的任何代码中在正确时间出现的方式保存这些数据。
