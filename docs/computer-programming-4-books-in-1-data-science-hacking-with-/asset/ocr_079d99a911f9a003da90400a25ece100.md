# **Array Indexing**

The important thing to remember is that indexing in Python starts at zero.

```
```python
x1 = np.array([4, 3, 4, 4, 8, 4])
x1
array([4, 3, 4, 4, 8, 4])
```
```

```
```python
#assess value to index zero
x1[0]
4
```
```

```
```python
#assess fifth value
x1[4]
8
```
```

```
```python
#get the last value
x1[-1]
4
```
```

```
```python
#get the second last value
x1[-2]
```
