## 为什么数据分析正在兴起？

导致数据科学兴起的因素有以下几点：

首先，数据收集量正以指数级速度增长。根据某项 IBM Marketing Cloud 的研究，每天产生的数据量约为 2.5 千万亿字节。虽然这相当于 25 亿字节（注：此处原文逻辑可能存在单位换算上的笔误，此处保留原文数值表述但调整了语境使其更通顺，原文 "2.5 billion bytes" 与 "2.5 quintillion" 数值差异巨大，通常 2.5 quintillion bytes 约为 2.5 exabytes。鉴于翻译原则，我将直译数值，但请注意原文可能存在的科学计数法混淆。为了忠实原文，我将直译其表述）：这大约是 25 亿字节，但这部分数据中只有极少一部分真正被分析过，导致大量机遇被搁置在一旁。

其次，我们正在经历一场始于数年前的认知革命。几乎每个行业都在追求人工智能技术，其中包括自然语言处理（NLP）和机器学习。虽然这些领域存在已久，但最近它们重新受到了广泛关注，以至于如今已成为大学里的热门课程。如今很明显，如果公司想要生存，就需要变得更加敏捷、行动更快，并转型为数字业务；随着决策可用时间的减少，它们必须完全以数据为驱动。

如果你还考虑到人工智能算法需要高质量的数据，你就不难理解数据科学家所扮演的关键角色了。

另一个原因是，随着云计算技术的发展以及平台即服务（PaaS）的兴起，访问计算引擎和存储变得前所未有地容易。如今，较小的组织甚至任何持有信用卡的人都可以运行大数据工作负载。反过来，这也推动了全方位的创新增长。

基于上述原因，毫无疑问，数据科学已经伴随我们而来，并且其发展将在很长一段时间内持续下去。然而，我们不能忽视这样一个事实：数据科学尚未发挥其全部潜力，也未能产生应有的结果，尤其是在推动公司转型为数据驱动型组织方面。在大多数情况下，问题在于未能实现下一步，即将数据科学和分析转化为一项关键的商业活动，从而提供洞察力和智能的商业决策。

## 数据科学流程概述

在数据科学中遵循结构化的方法，有助于你在成本最低的情况下提高数据科学项目的成功率。它还使得团队能够协作处理项目，每位团队成员专注于自己最擅长的领域。然而，这种程序可能并非适用于所有类型的项目，也不一定是实施正确数据科学的唯一手段。

典型的数据科学流程由六个步骤组成，你需要在这些步骤之间进行迭代。

以下是每个步骤的简要介绍。

1.  第一步是设定研究目标。这里的重点在于确保所有利益相关者都了解项目的“什么”、“如何”以及“为什么”。
2.  下一步是数据获取。你需要为分析准备好数据，因此接下来的步骤涉及寻找最佳数据并从数据所有者那里获得访问权限。结果是，原始数据在可用之前通常需要经过打磨和转换。
3.  一旦你拥有了原始数据，下一步就是准备这些数据。这涉及将数据从原始类型转换为可以直接用于模型的数据。为了实现这一目标，你需要识别并纠正数据中的各种类型的错误，整合来自不同来源的数据，并对其进行转换。如果你成功完成了这一步，就可以进入数据可视化和建模阶段。
4.  第四步是数据探索。此步骤的目的是深入理解数据。你将借助可视化和描述性技术来寻找模式、偏差和相关性。从这一步中获得的洞察力将使你能够开始建模。
5.  最后，你将进入最有趣的部分，即数据建模。此时你尝试实现项目章程中概述的洞察力或预测。现在是时候祭出“重兵”了，但请记住，研究表明，简单模型的组合往往能胜过复杂模型。如果你完成了这个阶段，你就快做完了。
6.  数据科学模型的最后一步是结果展示和分析自动化。项目的重点之一是改变流程或做出更好的决策。你可能仍然需要说服业务方，你的发现确实会改变业务流程。这是你发挥影响力角色的时刻。这一步骤在战略和战术层面的重要性显而易见。一些项目要求你反复完成业务流程。因此，自动化项目可以节省时间。

现实情况是，这不会是一个直接的过程。在大多数情况下，你会在各个阶段之间回归和迭代。

遵循上述六个步骤会有所回报，表现为更高的项目成功率以及研究结果影响力的增加。这个过程帮助你在开始查看数据之前，获得明确定义的研究计划、对业务问题的深刻理解以及清晰的交付物。最初的步骤让你能够专注于为模型提供高质量的输入数据。这样，你的模型在后续阶段表现会更好。

坚持结构化方法的另一个优势是，在寻找最佳模型时，你会更多地工作在原型模型上。在创建原型时，你可能会尝试多种模型，而不会过分关注程序速度或代码编写标准等问题。这使得你能够专注于产生商业价值。

并非每个项目都由业务部门自行创建。在分析过程中获得的洞察或新数据的到来都可能催生新项目。当数据科学团队提出一个想法时，通常已经完成了展示提案和确定业务赞助人的工作。

将项目划分为较小的阶段将使员工能够作为团队协作工作。不可能成为所有领域专家。你不需要学习如何将所有数据上传到所有不同的数据库，确定不仅适用于你的应用程序也适用于公司内其他项目最优数据方案，以及监控所有的统计和数据挖掘技术。

## 先决条件与提醒

至此，你需要熟悉 Python 语法以及其他 Python 基础知识。你需要掌握的一些基础知识包括函数、变量、循环和列表。你不需要成为专家，但具备正确的知识很重要，这样后续工作会更加顺畅。

你不必让这件事变得复杂，因为编程的核心在于告诉计算机应该做什么。然后，计算机应该能够理解并成功执行你的指令。你可能只需要编写几行代码来适应你的应用程序。

此外，你在 Python 中实现数据分析的许多功能已经是预构建好的。因此，你可能只需要复制并运行代码。但请记住，精通 Python 编程仍然很重要。这也会给你信心，因为你了解某事物是如何运作的。

## 你需要具备数学专业知识吗？

数据分析意味着处理数字并从中挖掘有用的洞察力。但你真的需要在数字和数学方面成为专家吗？

使用 Python 进行成功的数据分析始终需要在数学、编程和你所工作的领域具备出色的技能和知识。这意味着你不必在任何其中一项上成为专家。

不要让许多所谓的专家迷惑了你，因为他们中的许多是虚假的或仅仅是缺乏经验。你真正需要知道的是下一步该做什么，以便你能够成功完成项目。即使你读完了这里的所有章节，你也不会成为任何领域的专家。但这足以让你对 Python 和数据分析有更好的了解。

就数学专业知识而言，熟悉均值、标准差以及其他统计学术语可能是正确的。在进一步深入数据分析时，你可能会遇到微积分和线性代数。如果你有时间并有兴趣探索它们，你可以随时或稍后去做。这可能有助于也可能无助于你当前正在进行的具体数据分析项目。

再次，请记住，关键在于解决问题。主要关注点应放在如何处理挑战并成功克服它上。这一点应适用于商业和科学的所有领域。不要让神话分散你的注意力。专注于核心概念，你就会没事的。
