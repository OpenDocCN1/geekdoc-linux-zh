# Hour 6

# Account Management

The last hour explored the steps involved in adding a new user to a Unix system, whether through NetInfo or with additions to `/etc/passwd` and `/etc/shadow`. This hour will present the additional tools needed for complete account management, tools that will let you suspend user accounts and delete them.

Additionally, if you are running with shadow passwords, there are some interesting techniques you can use to enable password aging on your Unix system.

In this hour you will learn about

+   - Suspending user accounts
+   - Deleting user accounts
+   - Linux account management tools
+   - Solaris account management tools
+   - Password aging
