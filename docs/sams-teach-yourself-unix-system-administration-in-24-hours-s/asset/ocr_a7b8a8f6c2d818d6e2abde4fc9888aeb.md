# Virtual Hosts with Apache

In this last hour, we're going to explore a specific capability of Apache—virtual hosting—then wrap up with some discussion of Unix system security.

If you have a Web site—and odds are that you do—you know that there are two basic approaches to hosting Web sites: Each site gets its own computer, or, somehow, multiple Web sites (for example, multiple domain names) resolve to a single shared server. Because Unix is the original shared multi-user resource, it should be no surprise that sharing a Web server is easy and well within the capabilities of even the lowliest Unix box.
