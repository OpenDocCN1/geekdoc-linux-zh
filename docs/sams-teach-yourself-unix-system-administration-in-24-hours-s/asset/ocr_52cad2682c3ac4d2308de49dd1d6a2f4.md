4. To unpack the archive on the Darwin box, let's start by checking its contents with the -t flag, and let's also specify a pattern against which the filenames will be matched:

```
$ tar -tzf *gz DEMO
DEMO
DEMO/testfile
DEMO/Src
DEMO/Src/cribbage.c
DEMO/snapshot.sh
DEMO/sourcefiles.cpio
DEMO/testdir
```

This shows all the files and directories that match the specified pattern DEMO. Another quick example lists all the C program source files:

```
$ tar -tzf *gz *.c
DEMO/Src/cribbage.c
bin/fixit.c
elance/filter.c
```
