# Answers

+   1. Your login shell doesn't matter, as long as you remember to always specify `#/bin/sh` as the first line of your scripts.
+   2. Running a shell script as `sh -x script` offers lots of useful output for debugging any problems.
+   3. The `test` command is also known as `[`, but if you use the square bracket, you need to include a trailing `]` as well, or it'll be an error.
+   4. You can invoke `expr length $variable`, or you could use the `${#variable}` notation to ascertain the number of characters in `$variable`.
+   5. Typically, you'd use `var=`expr $var + 3`.
+   6. The notation `$#` indicates the number of arguments given to the script when invoked.
