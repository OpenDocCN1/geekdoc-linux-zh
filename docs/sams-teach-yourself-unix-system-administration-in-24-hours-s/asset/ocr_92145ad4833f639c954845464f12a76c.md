# File Ownership

After you’ve wrestled with how to figure out how much disk space you have and how to manage it (Hour 3, “Disk Usage”), the next logical topic is how to change the ownership of files and directories. Although this might seem like a simple topic, this hour demonstrates some of the nuances of file management necessary for a Unix file and system administrator.

In this hour, you will learn

+   - To use commands like ls and chmod to work with file and directory ownership
+   - The intricacies of the /etc/passwd file
+   - The concepts of Unix groups and /etc/group
