> As a reminder, the Unix man pages are broken into eight main categories: 1=user commands, 2=system maintenance commands, 3=system calls (for programmers), 4=administration files, 5=miscellaneous, 6=games, 7=special file formats, and 8=administrative commands.

Oftentimes you only want to see the interactive commands rather than the system maintenance commands, and so on. One simple way to do that is to use egrep:

```
$ apropos help | egrep '(1)'
consolehelper        (8)   - A wrapper that helps console users run
```
