# Task 11.4: Learning About Virtual Machines

The most popular solution for running virtual machines on the Intel platform is VMware, from VMware Corporation (www.vmware.com). With this program installed, you can create virtual Unix-operating environments, and even have multiple Windows operating systems installed for testing. Performance is roughly 80–90% of what you'd have with a native load, so it's not quite as fast. It's worth noting that you can also install VMware on your Linux system, enabling you to run Windows within Linux.

On the Macintosh, Virtual PC from Connectix Corporation (www.connectix.com) offers a similar capability, albeit with a higher performance penalty because of the need to emulate the Intel hardware architecture (including CPU). On a very fast Mac OS X system Virtual PC runs like a slightly sluggish PC.
