# Answers

+   1. `init` level 0 halts, and `init` level 6 reboots. But use shutdown instead, of course.
+   2. There are no starting options to `init`. All the `init` configuration is stored in `/etc/inittab`.
+   3. The sysboot action is not defined.
+   4. A multiuser + graphical environment is run level 5.
+   5. To return to multiuser mode from single-user mode, simply exit the single-user command shell.
