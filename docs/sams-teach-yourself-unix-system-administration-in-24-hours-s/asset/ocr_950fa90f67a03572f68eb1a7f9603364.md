6. When you type init 1, nothing seems to happen: The shell prompts for another command as if you'd typed echo or ls, but behind the scenes things are starting to close down, and within a minute or so the system should log out remote terminals, close xterms, log out of X Windows System, and end up with just a command shell prompt on the console.
