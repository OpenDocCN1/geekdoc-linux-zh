# Working with User Accounts

One of the most common tasks facing a Unix system administrator is the management of user accounts. Whether it’s helping someone change a login shell, adding new users, or promptly closing an account when someone is given "walking papers," you’ll constantly find yourself fiddling and tweaking these settings. That’s what this hour and the next are all about: working with user accounts. This hour focuses specifically on adding new users, which is more involved than you might think....

In this hour, you learn about

+   - Exploring the /etc/passwd file
+   - Using NetInfo to manage user accounts in Mac OS X
+   - Adding users and the adduser script
+   - Adding users in an NIS world
