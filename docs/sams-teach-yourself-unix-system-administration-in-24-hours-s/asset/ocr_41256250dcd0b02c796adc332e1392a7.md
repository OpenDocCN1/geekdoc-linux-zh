4. There are hundreds of different shell scripts on your system, and you can find them with a script:

```
# cat findscripts
#!/bin/sh

for match in `find / -type f -perm +0111 -print`
do
if [ "`file $match | grep -i 'shell script:'`" != "" ]; then
echo $match is a shell script
fi
done
```
