The format of the Apache log file is actually specified in the httpd.conf file:

```
# grep combined /etc/httpd/conf/httpd.conf | grep -vE '^#'
LogFormat "%h %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\"" combined
CustomLog logs/access_log combined
```

The second matching line shows that logs/access_log is a "combined" format log file, and the first line uses the LogFormat directive to define exactly what fields should be output, in what order, in a "combined" log file. The format and fields of this file can be changed, but do so with extreme caution, as you'll break all third-party log file analysis software.
