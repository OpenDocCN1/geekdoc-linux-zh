# milter-sender:

www.snert.com/Software/milter-sender

milter-sender is a Sendmail milter plugin that connects back to the sender of a message as it’s being received. Basically, if the sender doesn’t exist on the sender’s alleged primary mail server, the message is almost certainly spam and is rejected. This plugin has reduced my spam significantly. And, although the arms race isn’t over, I always can add more milter plugins. I’m now running milter-sender and SpamAssassin via milter. Requires: Berkeley DB, Sendmail with milter, libsnert and glibc.

> —DAVID A. BANDEL
