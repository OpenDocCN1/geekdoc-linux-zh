Notice that the data itself is not important here. What this MSG\_PEEK operation accomplishes is that it returns the client’s IP address (in the example, this is placed into adr\_clnt). The wrapper program can determine from the variable adr\_clnt whether this datagram should be processed by the server or not.

So far, you have digested the theory behind the TCP wrapper concept. Next, you’ll see this idea illustrated in the concrete form of example programs.
