Listing 5.5 shows some code that will explicitly indicate that any interface will do.

```
**Listing 5.5: Specifying Any Interface Using `bind(2)`**
```C
int z;
int sock_inet;              /* Socket */
struct sockaddr_in adr_inet; /* AF_INET */
int len_inet;               /* length */

sock_inet = socket(AF_INET,SOCK_STREAM,0);

if ( sock_inet == -1 )
    abort(); /* Failed */

/* Establish address */
memset(&adr_inet,0,sizeof adr_inet);
adr_inet.sin_family = AF_INET;
adr_inet.sin_port = htons(9000);

adr_inet.sin_addr.s_addr = htonl(INADDR_ANY);

if ( adr_inet.sin_addr.s_addr == INADDR_NONE )
    abort(); /* Failed */

len_inet = sizeof adr_inet;

z = bind(sock_inet,(struct sockaddr *)&adr_inet, len_inet);
```
```

Listing 5.5 is functionally identical to Listing 5.4, with the exception that the address value assigned is `htonl(INADDR_ANY)` instead of a specific IP address. A socket bound in this way can accept connections from any interface. It can also connect to a remote socket going out from any interface (this is automatically determined by routing tables).

> **NOTE**
> The value `INADDR_ANY` is also known as a *wildcard* address.
