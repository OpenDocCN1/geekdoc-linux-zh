# Introducing the cmgs(3) Macros

Due to the complexity of structuring the ancillary data, a number of C macros were provided to make this easier for you. Additionally, these macros enable much greater portability between different UNIX platforms and provide some insulation against changes that might occur in the future. These macros are described by the man page cmgs(3) and the synopsis for them are as follows:

```
#include <sys/socket.h>
struct cmgsdr *CMGS\_FIRSTHDR(struct msghdr *msg);
struct cmgsdr *CMGS\_NXTHDR(struct msghdr *msg, struct cmgsdr *cmgsdr);
size\_t CMGS\_ALIGN(size\_t length);
size\_t CMGS\_SPACE(size\_t length);
size\_t CMGS\_LEN(size\_t length);
void *CMGS\_DATA(struct cmgsdr *cmgsdr);
```

> **TIP**
> 
> Some of the macros presented in this chapter are not available on other UNIX platforms. For example, FreeBSD UNIX lacks the CMGS\_ALIGN(), CMGS\_SPACE(), and CMGS\_LEN() macros. This should be borne in mind if you are writing code that must compile on other UNIX platforms in addition to Linux.
