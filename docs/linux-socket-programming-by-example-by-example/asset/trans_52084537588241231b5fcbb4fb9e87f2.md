
## 从服务器进行广播

本章将展示一个简单的广播服务器程序以及相应的客户端程序。服务器程序将首先被呈现并解释。

为了让人了解广播功能可以实现什么，所展示的服务器将提供股票指数模拟。服务器程序将代表一个从外部报价供应商获取数据馈送，然后将股票指数报价重新广播给所有感兴趣客户端的程序。清单 13.1 中的示例展示了 stksrv.c 服务器程序。

本章节不重复列出 maddr.c。如果你想要使用 255.255.255.255 通用广播地址进行实验，请务必进行上一节中描述的微小调整。否则，maddr.c 的列表与第 11 章“并发客户端服务器”中使用的相同。

### 清单 13.1: stksrv.c—股票指数广播服务器

```c
/* stksrv.c: * * 股票指数广播示例: */
#include <stdio.h>
#include <unistd.h>
#include <stdlib.h>
#include <errno.h>
#include <string.h>
#include <time.h>
#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

#define TRUE
#define TRUE 1
#define FALSE 0

extern int maddr(
    void *addr,
    int *addrlen,
    char *str_addr,
    char *protocol);
#define MAXQ 4

static struct {
    char *index;
    int start;
    int vol;
    int current;
} quotes[] = {
    { "DJIA", 1030330, 375 },
    { "NASDAQ", 276175, 125 },
    { "S&P 500", 120331, 50 },
    { "TSE 300", 689572, 75 },
};

/*
 * 初始化:
 */
static void
initialize(void) {
    short x;
    time_t td;

    /*
     * 初始化随机数生成器:
     */
    time(&td);
    srand((int)td);

    for ( x=0; x < MAXQ; ++x )
        quotes[x].current =
            quotes[x].start;
}

/*
 * 随机更改某个指数报价:
 */
static void
gen_quote(void) {
    short x;     /* 指数 */
    short v;     /* 指数的波动性 */
    short h;     /* v 的一半 */
    short r;     /* 随机变化 */

    x = rand() % MAXQ;
    v = quotes[x].vol;
    h = (v / 2) - 2;
    r = rand() % v;

    if ( r < h )
        r = -r;
    quotes[x].current += r;
}

/*
 * 此函数报告错误并
 * 返回到 shell:
 */
static void
bail(const char *on_what) {
    fputs(strerror(errno), stderr);
    fputs(" : ", stderr);
    fputs(on_what, stderr);
    fputc('\n', stderr);
    exit(1);
}

int
main(int argc, char **argv) {
    short x;        /* 股票指数索引 */
    double i0;      /* 初始指数值 */
    double i;       /* 指数值 */
    char bcbufr[512], *bp;/* 缓冲区和指针 */
    int z;          /* 状态返回码 */
    int s;          /* 套接字 */
    struct sockaddr_in adr_srvr;/* AF_INET */
    int len_srvr;   /* 长度 */
    struct sockaddr_in adr_bc; /* AF_INET */
    int len_bc;     /* 长度 */
    static int so_broadcast = TRUE;
    static char
    *sv_addr = "127.0.0.1:9099",
    *bc_addr = "127.255.255.255:9099";

    /*
     * 形成服务器地址:
     */
    if ( argc > 2 )
    {
        /* 服务器地址: */
        sv_addr = argv[2];
    }
    if ( argc > 1 )
    {
        /* 广播地址: */
        bc_addr = argv[1];
    }

    /*
     * 形成服务器地址:
     */
    len_srvr = sizeof adr_srvr;

    z = maddr(
            &adr_srvr,  /* 返回的地址 */
            &len_srvr,  /* 返回的长度 */
            sv_addr,    /* 输入的字符串地址 */
            "udp");     /* UDP 协议 */

    if ( z == -1 )
        bail("无效的服务器地址");

    /*
     * 形成广播地址:
     */
    len_bc = sizeof adr_bc;

    z = maddr(
            &adr_bc,    /* 返回的地址 */
            &len_bc,    /* 返回的长度 */
            bc_addr,    /* 输入的字符串地址 */
            "udp");     /* UDP 协议 */

    if ( z == -1 )
        bail("无效的广播地址");

    /*
     * 创建一个要使用的 UDP 套接字:
     */
    s = socket(AF_INET, SOCK_DGRAM, 0);
    if ( s == -1 )
        bail("socket()");

    /*
     * 允许广播:
     */
    z = setsockopt(s,
                SOL_SOCKET,
                SO_BROADCAST,
                &so_broadcast,
                sizeof so_broadcast);

    if ( z == -1 )
        bail("setsockopt(SO_BROADCAST)");

    /*
     * 将一个地址绑定到我们的套接字，以便
     * 客户端程序可以侦听此
     * 服务器:
     */
    z = bind(s,
            (struct sockaddr *)&adr_srvr,
            len_srvr);

    if ( z == -1 )
        bail("bind()");

    /*
     * 现在开始提供报价:
     */
    initialize();

    for (;;) {
        /*
         * 更新列表中的一个报价:
         */
        gen_quote();

        /*
         * 形成一个要发送的数据包:
         */
        bp = bcbufr;
        for ( x=0; x<MAXQ; ++x ) {
            i0 = quotes[x].start / 100.0;
            i = quotes[x].current / 100.0;
            sprintf(bp,
                    "%-7.7s %8.2f %+.2f\n",
                    quotes[x].index,
                    i,
                    i - i0);
            bp += strlen(bp);
        }

        /*
         * 广播更新的信息:
         */
        z = sendto(s,
                    bcbufr,
                    strlen(bcbufr),
                    0,
                    (struct sockaddr *)&adr_bc,
                    len_bc);

        if ( z == -1 )
            bail("sendto()");

        sleep(4);
    }

    return 0;
}
```

清单 13.1 中显示的服务器在功能上分为以下几个部分：

- 股票指数表在第 27 到 39 行中声明。定义了四个指数，带有起始值和粗糙的波动性值形式，用于模拟。
- 第 44 到 58 行的函数 initialize() 被调用一次以初始化模拟。
- 调用函数 gen_quote() 随机更改随机选择的股票指数的模拟值（第 63 到 77 行）。
- 构成服务器基础的 main() 程序包含在第 92 到 222 行中。

这个股票市场服务器的基本操作如下：

- 默认地址在第 106 和 107 行中声明。当没有提供命令行参数时，使用这些地址。
- 如果提供了两个命令行参数，则服务器地址从第二个参数获取地址（第 114 行）。
- 如果提供一个或多个命令行参数，则广播参数从参数一获取（第 118 行）。
- 形成服务器地址（第 123 到 132 行）。
- 形成广播地址（第 137 到 146 行）。
- 创建一个套接字（第 151 到 153 行）。
- 在套接字上启用 SO_BROADCAST 选项（第 158 到 165 行）。
- 绑定服务器地址（第 172 到 177 行）。
- 初始化股票指数（第 182 行）。
- 服务器循环从第 184 行开始。

服务器无限循环。你需要终止它才能结束其执行。
服务器循环使用以下步骤：

- 通过调用 gen_quote() 更新随机选择的指数（第 188 行）。
- 提取所有指数的报价并格式化到缓冲区中（第 193 到 203 行）。这创建了一个包含四行文本的字符串，对应每个股票指数。
- 使用 sendto(2) 函数发送格式化字符串（第 208 到 216 行）。此调用执行广播，因为地址 adr_bc 包含一个广播地址。
- 进行四秒钟的 sleep(3) 调用，以模拟报价更新之间合理的时间延迟。
- 循环从步骤 1 重复。

这里有几个要点值得回顾：

- 套接字必须启用 SO_BROADCAST 选项。否则，不允许从此套接字进行广播。
- sendto(2) 调用执行了广播，因为目标地址是一个广播地址。

这两个条件都是广播的先决条件。套接字必须启用广播，并且目标地址必须是一个广播 IP 地址。

要编译此程序，使用以下命令：

```
$ make stksrv
gcc -c -D_GNU_SOURCE -Wall -Wreturn-type -g stksrv.c
gcc -c -D_GNU_SOURCE -Wall -Wreturn-type -g mkaddr.c
gcc -g stksrv.o mkaddr.o -o stksrv
$
```
