# ## What's Next

In this chapter, you have briefly seen how sockets can be used to communicate between two different processes. When the socketpair(2) function was introduced, it was noted that a socket domain, socket type, and a socket protocol had to be specified. The next chapter teaches you how to choose the socket domain and how to adorn a socket with an address. You will cover anonymous and addressed sockets and how to initialize address structures for each domain.
