### recv(2)

```c
#include <sys/types.h>
#include <sys/socket.h>

int recv(int s, void *buf, int len, unsigned int flags);
```

### recvfrom(2)

```c
#include <sys/types.h>
#include <sys/socket.h>

int recvfrom(int s,
    void *buf,
    int len,
    unsigned flags,
    struct sockaddr *from,
    int *fromlen);
```

**flags:**
- MSG_OOB Process out-of-band data.
- MSG_PEEK Peek at a datagram.
- MSG_WAITALL Requests that the operation block until the full request has been satisfied (with some exceptions).
- MSG_ERRQUEUE Receive from the error queue.
- MSG_NOSIGNAL Turn off the raising of SIGPIPE.

### recvmsg(2)

```c
#include <sys/types.h>
#include <sys/socket.h>

int recvmsg(int s, struct msghdr *msg, unsigned int flags);
```

```c
struct msghdr {
    void    *msg_name;
    socklen_t msg_namelen;
    struct iovec *msg_iov;
    size_t    msg_iovlen;
    void    *msg_control;
    size_t    msg_controllen;
    int     msg_flags;
};
```

```c
struct cmsghdr {
    socklen_t cmsg_len;
    int     cmsg_level;
    int     cmsg_type;
    /*  u_char    cmsg_data[]; */
};
```

**flags:**
- MSG_EOR End of a record received.
- MSG_TRUNC Datagram was truncated.
- MSG_CTRUNC Control data was truncated.
- MSG_OOB Out-of-band data was received.
- MSG_ERRQUEUE Extended error info was returned.

### fcntl(2) Using F_SETOWN

```c

#include <fcntl.h>

```

The cmd value F_SETOWN allows ownership of the socket to be established, for the process ID given in arg.

### ioctl(2) to Test for Mark

```c
#include <sys/ioctl.h>
int z;   /* Status */
int s;   /* Socket */
int flag; /* True when at mark */

z = ioctl(s, SIOCGETMARK, &flag);
if ( z == -1 )
    abort();           /* Error */
if ( flag != 0 )
    puts("At Mark");
else
    puts("Not at mark.");
```
