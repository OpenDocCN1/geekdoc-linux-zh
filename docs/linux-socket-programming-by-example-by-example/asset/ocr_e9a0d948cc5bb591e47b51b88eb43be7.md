The program might look a little intimidating, but the basic steps are easily understood. They can be described simply as follows:

+   1. Create a socket, using socket(2).
+   2. Establish a server address and bind(2) it.
+   3. Wait for a datagram by calling recvfrom(2).
+   4. Process the request (format a date string).
+   5. Send the result back to the client using sendto(2).
+   6. Repeat step 3, until it is time to exit.

Step 2 is necessary so that the client program is able to contact the server. This is like giving a telephone a number. Step 2 gives a nameless socket an address, so that datagrams can be directed to it by the client program.
