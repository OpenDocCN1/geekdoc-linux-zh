## We Made Assumptions About You

A book on Linux socket programming isn’t truly a book on networking theory. In order to teach you the most about socket programming, we stuck to the topic at hand in order to allow you the greatest learning curve without wasting your time or money.

### What We Assume You Know

- The C programming language and how to link these programs under Linux.
- A little bit about programming under Linux (or UNIX)—such as `open(2)`, `read(2)`, and `write(2)`, for example.
- A basic understanding of catching and handling signals under Linux. The `signal(2)` function is used in some demonstration programs.
- The rudimentary concepts about TCP/IP networking.

### What We Expect You’ll Learn

- How to use the `socketpair(2)` and `shutdown(2)` functions, with an introduction to performing I/O on sockets.
- Address families and how to form and initialize socket address structures.
- How to use the connectionless mode of communications with the UDP datagram. The advantages and disadvantages are covered, complete with examples of how to perform datagram I/O.
- Using the `listen(2)` and `accept(2)` functions through a discussion about the kernel listening queue. Diagrams and example programs also show you about server design.
- How to handle the challenges of serving multiple client connections. You’ll learn to use the `fork(2)` and `select(2)` approaches as solutions.
- How and when to use the inetd daemon and manage the configuration file `/etc/inetd.conf`.
- How servers obtain credentials about clients, and how file descriptors are passed to a client program when using local sockets.
