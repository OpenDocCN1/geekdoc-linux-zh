| Item | Description |
| :--- | :--- |
| $\overline{x}_i; \overline{c}_{jk}$ | The complex conjugate of the complex vector element $x_j$, where: **if** $x_i = \langle a_i, b_i \rangle$, **then** $\overline{x}_i = \langle a_i, -b_i \rangle$ |
| | The complex conjugate of the complex matrix element $c_{jk}$ |
| $\mathbf{x}^{*t}$; $\mathbf{A}^{*t}$ | The complex conjugate transpose of vector $\mathbf{x}$; the complex conjugate transpose of matrix $\mathbf{A}$ |
| $\sum_{i=1}^{n} x_i$ | The sum of elements $x_1$ to $x_n$ |
| $\sqrt{a+b}$ | The square root of $a+b$ |
| $\int_{a}^{b} f(x)\ dx$ | The integral from $a$ to $b$ of $f(x)\ dx$ |
| $\|\mathbf{x}\|_2$ | The Euclidean norm of vector $\mathbf{x}$, defined as: $\sqrt{\sum_{j=1}^{n} |\mathbf{x}_j|^2}$ |
| $\|\mathbf{A}\|_1$ | The one norm of matrix $\mathbf{A}$, defined as: $\max \left\{ \sum_{i=1}^{m} |a_{ij}|,\ 1 \le j \le n \right\}$ |
| $\|\mathbf{A}\|_2$ | The spectral norm of matrix $\mathbf{A}$, defined as: $\max\{\|\mathbf{A}\mathbf{x}\|_2\ :\ \|\mathbf{x}\|_2 = 1\}$ |
| $\|\mathbf{A}\|_F$ | The Frobenius norm of matrix $\mathbf{A}$, defined as: $\sqrt{\sum_{i=1}^{m}\sum_{j=1}^{n} |a_{ij}|^2}$ |
| $\mathbf{A}^{-1}$ | The inverse of matrix $\mathbf{A}$ |
| $\mathbf{A}^{-T}$ | The transpose of $\mathbf{A}$ inverse |
| $|\mathbf{A}|$ | The determinant of matrix $\mathbf{A}$ |
| $m$ by $n$ matrix $\mathbf{A}$ | Matrix $\mathbf{A}$ has $m$ rows and $n$ columns |
| $\sin a$ | The sine of $a$ |
| $\cos b$ | The cosine of $b$ |
| SIGN ($a$) | The sign of $a$; the result is either $+$ or $-$ |
| address $\{a\}$ | The storage address of $a$ |
| $\mathbf{max}(\mathbf{x})$ | The maximum element in vector $\mathbf{x}$ |
| $\mathbf{min}(\mathbf{x})$ | The minimum element in vector $\mathbf{x}$ |
| $\mathbf{ceiling}(x)$ | The smallest integer that is greater than or equal to $x$ |
| $\mathbf{floor}(x)$ | The largest integer that is not greater than $x$ |
