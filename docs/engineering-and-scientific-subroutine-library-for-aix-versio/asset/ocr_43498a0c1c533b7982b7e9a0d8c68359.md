# Call Statement and Input:

```
```TRANSA TRANSB L N M ALPHA A LDA B LDB BETA C LDC
CALL SGEMM( 'N', 'T', 3, 3, 2, 1.0, A, 4, B, 3, 2.0, C, 5 )```
