# STREC and DTREC—Time-Varying Recursive Filter

These subroutines implement the first-order time-varying recursive equation, using initial value $s$, target vectors $\boldsymbol{u}$ and $\boldsymbol{x}$, and output vector $\boldsymbol{y}$.

Table 152. Data Types

| $s$, $\boldsymbol{u}$, $\boldsymbol{x}$, $\boldsymbol{y}$ | Subroutine |
| :---------------------- | :---------- |
| Short-precision real | STREC |
| Long-precision real | DTREC |

# Syntax

| Fortran | CALL STREC \| DTREC ($s$, $u$, $incu$, $x$, $incx$, $y$, $incy$, $n$, $iopt$) |
| :-------- | :-------------------------------------------------------------------------------- |
| C and C++ | strec \| dtrec ($s$, $u$, $incu$, $x$, $incx$, $y$, $incy$, $n$, $iopt$); |

On Entry:

$s$  is the scalar $s$ used in the initial computation for $y_{1}$.

Specified as: a number of the data type indicated in Table 152.

$u$  is the target vector $\boldsymbol{u}$ of length $n$.

Specified as: a one-dimensional array of (at least) length $1+(n-1)|incu|$, containing numbers of the data type indicated in Table 152.

$incu$  is the stride for target vector $\boldsymbol{u}$.

Specified as: a fullword integer. It can have any value.

$x$  is the target vector $\boldsymbol{x}$ of length $n$.

Specified as: a one-dimensional array of (at least) length $1+(n-1)|incx|$, containing numbers of the data type indicated in Table 152.

$incx$  is the stride for target vector $\boldsymbol{x}$.

Specified as: a fullword integer. It can have any value.

$y$  See “On Return.”

$incy$  is the stride for output vector $\boldsymbol{y}$. Specified as: a fullword integer; $incy>0$ or $incy<0$.

$n$  is the number of elements in vectors $\boldsymbol{u}$ and $\boldsymbol{x}$ and the number of resulting elements in output vector $\boldsymbol{y}$.

Specified as: a fullword integer; $n \geq 0$.

$i$opt$  this argument has no effect on the performance of the computation, but still must be specified as: a fullword integer; $i$opt$ = 0 or 1.

On Return:

$y$  is the vector $\boldsymbol{y}$ of length $n$, containing the results of the implementation of the first-order time-varying recursive equation. Returned as: a one-dimensional array of (at least) length $1+(n-1)|incy|$, containing numbers of the data type indicated in Table 152.

Note

Vectors $\boldsymbol{u}$, $\boldsymbol{x}$, and $\boldsymbol{y}$ must have no common elements; otherwise, results are unpredictable. See “Concepts” on page 55.
