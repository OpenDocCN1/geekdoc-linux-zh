# **DSDGC**

$naux1$\nis the size of the work area specified by $aux1$—that is, the number of elements in $aux1$.\n\nSpecified as: a fullword integer, where:\n\nIf $naux1 = 0$ and error 2015 is unrecoverable, DSDGC dynamically allocates the work area used by this subroutine. The work area is deallocated before control is returned to the calling program.\n\nOtherwise, $naux1 > 0$ and must have at least the following value, where:\n\nIf $IPARM(2) = 0$, use $naux1 \ge 7m$.\n\nIf $IPARM(2) > 0$, use $naux1 \ge (k+2)m+(k(k+4)+1)$, where $k = PARM(2)$.

$aux2$\nis a storage work area used by this subroutine. If $IPARM(3) = -10$, $aux2$ must contain the incomplete LU factorization of matrix $A$, computed in an earlier call to DSDGC. The size of $aux2$ is specified by $naux2$.\n\nSpecified as: an area of storage, containing long-precision real numbers.

$naux2$\nis the size of the work area specified by $aux2$—that is, the number of elements in $aux2$.\n\nSpecified as: a fullword integer. When $IPARM(3) = 10$ or $-10$, $naux2$ must have at least the following value: $naux2 \ge 3+2m+1.5nd(m)$.

# On Return:

$x$\nis the vector $\mathbf{x}$ of length $m$, containing the solution of the system $A\mathbf{x} = \mathbf{b}$.\n\nReturned as: a one-dimensional array of (at least) length $m$, containing long-precision real numbers.

$iparm$\nis an array of parameters, $IPARM(i)$, where:\n\n$IPARM(1)$ is unchanged.\n\n$IPARM(2)$ is unchanged.\n\n$IPARM(3)$ is unchanged.\n\n$IPARM(4)$ contains the number of iterations performed by this subroutine.\n\nReturned as: a one-dimensional array of length 4, containing fullword integers.

$rparm$\nis an array of parameters, $RPARM(i)$, where:\n\n$RPARM(1)$ is unchanged.\n\n$RPARM(2)$ is reserved.\n\n$RPARM(3)$ contains the estimate of the error of the solution. If the process converged, $RPARM(3) \le RPARM(1)$.\n\nReturned as: a one-dimensional array of length 3, containing long-precision real numbers.

$aux2$\nis the storage work area used by this subroutine.\n\nIf $IPARM(3) = 10$, $aux2$ contains the incomplete LU factorization of matrix $A$.\n\nIf $IPARM(3) = -10$, $aux2$ is unchanged.\n\nSee “Notes” on page 671 for additional information on $aux2$. Returned as: an area of storage, containing long-precision real numbers.
