# ## Example 4

This example shows a vector, *x*, with a negative stride. Processing begins at element $x(15)$, which is 2.0.

**Function Reference and Input:**

```
    N     X     INCX
     |     |      |
IMAX = ISAMAX( 8, X, -2   )
X          = (3.0, ., 5.0, ., -8.0, ., 6.0, ., 8.0, .,
           4.0, ., 8.0, ., 2.0)
```

**Output:**

```
IMAX = 7
```

# ## Example 5

```
    N     X     INCX

IMAX = ICAMAX( 5, X, 1   )
X          = ((9.0, 2.0), (7.0, -8.0), (-5.0, -10.0), (-4.0, 10.0),

```
