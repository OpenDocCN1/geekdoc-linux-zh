# Notes

+   1. In your C program, argument *seed* must be passed by reference.
+   2. Vector *x* must have no common elements with the storage area specified for *aux*; otherwise, results are unpredictable.
+   3. You have the option of having the minimum required value for *naux* dynamically returned to your program. For details, see “Using Auxiliary Storage in ESSLR” on page 32.

# Function

The normally distributed pseudo-random numbers, with a mean of 0 and a standard deviation of 1, are generated as follows, using Polar methods with a user-specified seed. The Polar method, which this technique is based on, was developed by G. E. P. Box, M. E. Muller, and G. Marsaglia and is described in reference [78].

+   1. Using *seed*, a vector of uniform (0,1) pseudo-random numbers, *uᵢ* for *i* = 1, *n* is generated by calling SURAND or DURAND, respectively. These *uᵢ* values are then used in the subsequent steps.
+   2. All (*yⱼ*, *zⱼ*) for *j* = 1, *n*/2 are set as follows, where each (*yⱼ*, *zⱼ*) is a point in the square −1 to 1:
+      *yⱼ* = 2*nuⱼ*−1
+      *zⱼ* = 2*n*uⱼ*′−1
+   3. All *pⱼ* for *j* = 1, *n*/2 are set as follows, where each *p* measures the square of the radius of (*yⱼ*, *zⱼ*):

*pⱼ* = *yⱼ*² + *zⱼ*²

+   If *pⱼ* ≉ 1, then *pⱼ* is discarded, and steps 1 through 3 are repeated until *pⱼ* < 1.
+   
+   4. All *xᵢ* for *i* = 1, *n* are set as follows to produce the normally distributed random numbers:
+      *x₂ⱼ₋₁* = *yⱼ*(−2 ln *pⱼ*) / *pⱼ*⁰·⁵
+      *x₂ⱼ* = *zⱼ*(−2 ln *pⱼ*) / *pⱼ*⁰·⁵
+      for *j* = 1, *n*/2

If *n* is 0, no computation is performed, and the initial seed is unchanged.

# Error Conditions

**Resource Errors:** Error 15 is unrecoverable, *naux* = 0, and unable to allocate work area.

**Computational Errors:** None

**Input-Argument Errors:**

1. *n* < 0 or *n* is an odd number
2. *seed* < 1.0 or *seed* ≥ 2147483647.0
3. Error 15 is recoverable or *naux*≠0, and *naux* is too small—that is, less than the minimum required value. Return code 1 is returned if error 15 is recoverable.
