# SACOR

*naux1* is no longer used in the computation, but must still be specified as a dummy argument (for migration purposes from Version 1 of ESL). It can have any value.

*aux2* is no longer used in the computation, but must still be specified as a dummy argument (for migration purposes from Version 1 of ESL). It can have any value.

*naux2* is no longer used in the computation, but must still be specified as a dummy argument (for migration purposes from Version 1 of ESL). It can have any value.

# On Return:

*y* is array *Y*, consisting of *m* output sequences of length *N_y* that are the autocorrelation functions of the sequences in array *X*. Returned as: an array of (at least) length 1 + (*N_y* -1) *int2*y* + (*m* -1) *int2*y*, containing short-precision real numbers.

# Notes

+   1.  Output should not overwrite input; that is, input arrays *X* and *H* must have no common elements with output array *Y*. Otherwise, results are unpredictable. See "Concepts" on page 55.
+   2.  When using the ESL SMP library, for optimal performance, the number of threads specified should be the same for *init* ≠ 0 and *init* = 0.
+   3.  Auxiliary storage is not needed, but the arguments *aux1*, *naux1*, *aux2*, and *naux2* must still be specified. You can assign any values to these arguments.

# Function

The autocorrelations of the sequences in array *X* are expressed as follows:

![](bbox=[0.28, 0.72, 0.48, 0.77])

for:

![](bbox=[0.28, 0.82, 0.44, 0.86])

where:

*y_{ki}* are elements of the *m* sequences of length *N_y* in array *Y*.
*x_{j}* and *x_{j+k,j}* are elements of the *m* sequences of length *N_x* in array *X*.

See references [19] and [87].

Only one invocation of this subroutine is needed:

+   1.  You do not need to invoke the subroutine with *init* ≠ 0. If you do, however, the subroutine performs error checking, exits back to the calling program, and no computation is performed.
+   2.  With *init* = 0, the subroutine performs the calculation of the convolutions or correlations.
