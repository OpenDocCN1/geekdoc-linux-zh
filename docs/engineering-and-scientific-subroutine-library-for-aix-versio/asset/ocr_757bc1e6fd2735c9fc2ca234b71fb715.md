# ## EINFO—ESSL Error Information-Handler Subroutine

This subroutine returns information to your program about the data involved in a computational error that occurred in an ESS L subroutine. This is the same information that is provided in the ESSL messages; however, it allows you to check the information in your program at run time and continue processing. You pass the computational error code of interest to this subroutine in $icode$, and it passes back one or more pieces of information in the output arguments $infl$ and, optionally, $inf2$, as defined in Table 179. **You should use this subroutine only for those computational errors listed in the table. It does not apply to computational errors that do not return information.**

For multithreaded application programs, if you want the error handling capabilities that this subroutine provides to be implemented on each thread created by your program, this subroutine must be called from each thread. If your application creates multiple threads, the action performed by a call to this subroutine applies to the thread that this subroutine was invoked from. For an example, see "Example of Handling Errors in a Multithreaded Application Program" on page 122.

Table 179. Computational Error Information Returned by EINFO

| Error Code | Receiver | Type of Information |
| :--- | :--- | :--- |
| 2100 | *infl* | Lower range of a vector |
| | *inf2* | Upper range of a vector |
| 2101 | *infl* | Index of the eigenvalue that failed to converge |
| | *inf2* | Number of iterations after which it failed to converge |
| 2102 | *infl* | Index of the last eigenvector that failed to converge |
| | *inf2* | Number of iterations after which it failed to converge |
| 2103 | *infl* | Index of the pivot with zero value |
| 2104 | *infl* | Index of the last pivot with nonpositive value |
| 2105 | *infl* | Index of the pivot element near zero causing factorization to fail |
| 2107 | *infl* | Index of the singular value that failed to converge |
| | *inf2* | Number of iterations after which it failed to converge |
| 2109 | *infl* | Iteration count when it was determined that the matrix was not definite |
| 2114 | *infl* | Index of the last eigenvalue that failed to converge |
| | *inf2* | Number of iterations after which it failed to converge |
| 2115 | *infl* | Order of the leading minor that was discovered to have a nonpositive determinant |
| 2117 | *infl* | Column number for which pivot value was near zero |
| 2118 | *infl* | Row number for which pivot value was near zero |
| 2120 | *infl* | Row number of empty row where factorization failed |
| 2121 | *infl* | Column number of empty column where factorization failed |
| 2126 | *infl* | Row number for which pivot value was unacceptable |
| 2145 | *infl* | First diagonal element with zero value |
