# Example 5

This example shows the computation $C = \alpha BA + \beta C$, where $A$ is a complex symmetric matrix of order 3, stored in upper storage mode, and $B$ and $C$ are 2 by 3 rectangular matrices.

Call Statement and Input:

```
SIDE UPLO M N ALPHA A LDA B LDB BETA C LDC
|
CALL CSYMM('R', 'U', 2 , 3 , ALPHA , A , 4 , B , 3 , BETA , C , 5 )
ALPHA = ( 2.0 , 3.0 )
BETA = ( 1.0 , 6.0 )
```
