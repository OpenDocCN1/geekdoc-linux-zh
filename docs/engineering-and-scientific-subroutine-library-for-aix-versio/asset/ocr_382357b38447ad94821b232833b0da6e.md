# **ESSL for AIX—Installation and Customization Products**

The ESSL for AIX licensed program is distributed on a CD. The *ESSL Installation Guide* provides the detailed information you need to install ESSL.

The ESSL for AIX product is packaged according to the AIX guidelines, as described in the *AIX General Programming Concepts: Writing and Debugging Programs* manual. The product can be installed using the smit command, as described in the *AIX System Management Guide: Operating System and Devices* manual.

# **ESSL for Linux—Hardware and Software**

This section describes the hardware and software products you can use with ESSL for Linux.

# **ESSL for Linux—Hardware**

ESSL for Linux runs on the IBM *@server pSeries* and RS/6000 processors supported by the Linux operating system.

64-bit applications require 64-bit hardware.

# **ESSL for Linux—Operating Systems**

ESSL for Linux is supported in the following operating system environment:

+   SuSE Linux Enterprise Server 8 for pSeries (SLES8)
