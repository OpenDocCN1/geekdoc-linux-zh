# SDOT, DDOT, CDOTU, ZDOTU, CDOTC, ZDOTC

**Function**

SDOT, DDOT, CDOTU, and ZDOTU compute the dot product of the vectors $x$ and $y$, which is expressed as follows:

$$x \bullet y = x_1 y_1 + x_2 y_2 + \dots + x_n y_n$$

CDOTC and ZDOTC compute the dot product of the complex conjugate of vector $x$ with vector $y$, which is expressed as follows:

$$\bar{x} \bullet y = \overline{x_1} y_1 + \overline{x_2} y_2 + \dots + \overline{x_n} y_n$$

See reference [81]. The result is returned as a function value. If $n$ is 0, then zero is returned as the value of the function.

For SDOT, CDOTU, and CDOTC, intermediate results are accumulated in long precision.

**Error Conditions**

-   Computational Errors: None
-   Input-Argument Errors: $n < 0$

# SNAXPY and DNAXPY—Compute SAXPY or DAXPY N Times

These subprograms compute SAXPY or DAXPY, respectively, $n$ times:

$$y_{i} \leftarrow y_{i} + \alpha x_{i} \quad \text{for} \ i = 1, \dots, n$$

where each $\alpha_{i}$ is a scalar value, contained in the vector $\boldsymbol{a}$, and each $\boldsymbol{x}_{i}$ and $\boldsymbol{y}_{i}$ are vectors, contained in vectors (or matrices) $\boldsymbol{x}$ and $\boldsymbol{y}$, respectively. For an explanation of the SAXPY and DAXPY computations, see “SAXPY, DAXPY, CAXPY, and ZAXPY—Multiply a Vector X by a Scalar, Add to a Vector Y, and Store in the Vector Y” on page 210.
