where:

* **D** is a diagonal matrix.
* **L** is a lower triangular matrix.

The transformed matrix **A**, factored into its $LDL^T$ form, is stored in packed format in array Λ, such that the inverse of the diagonal matrix **D** is stored in the corresponding elements of array Λ. The off-diagonal elements of the unit upper triangular matrix $L^T$ are stored in the corresponding off-diagonal elements of array Λ.

For Cholesky decomposition, matrix **A** is factored into the following form using specified pivot processing:

$A = R^T R$

where **R** is an upper triangular matrix

The transformed matrix **A**, factored into its $R^TR$ form, is stored in packed format in array Λ, such that the inverse of the diagonal elements of the upper triangular matrix **R** is stored in the corresponding elements of array Λ. The off-diagonal elements of matrix **R** are stored in the corresponding off-diagonal elements of array Λ.

The partial factorization of matrix **A**, which you can do when you specify the factor-only option, assumes that the first I**PARAM**(3) rows and columns are already factored in the input matrix. It factors the remaining $n-\text{IPARM}(3)$ rows and columns in matrix **A**. (See “Notes” on page 626 for an illustration.) It updates only the elements in array **A** corresponding to the part of matrix **A** that is factored.

The determinant can be computed with any of the factorization computations. With a full factorization, you get the determinant for the whole matrix. With a partial factorization, you get the determinant for only that part of the matrix factored in this computation.

The system $\pmb{A}\pmb{x} = \pmb{b}$, having multiple right-hand sides, is solved for $\pmb{x}$ using the transformed matrix **A** produced by this call or a subsequent call to this subroutine.

See references [11], [14], [27], [49], [73]. If $n$ is 0, no computation is performed. If $mbx$ is 0, no solve is performed.
