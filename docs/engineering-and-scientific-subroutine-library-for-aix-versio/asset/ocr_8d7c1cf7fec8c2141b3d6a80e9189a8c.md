# # SCON and SCOR

$$ y_{ki} = \sum_{j = \max(0, k - N_{x} + 1)}^{\min(N_{x} - 1, k)} h_{j}x_{k - j, i} $$

Correlations for SCOR:

$$ y_{ki} = \sum_{j = \max(0, -k)}^{\min(N_{h} - 1, N_{x} - 1 - k)} h_{j}x_{k + j, i} $$

for:

$k = iy0, iy0 + 1, ..., iy0 + N_{y} - 1$

$i = 1, 2, ..., m$

where:

$y_{ki}$ are elements of the $m$ sequences of length $N_{y}$ in array $\mathsf{Y}$.

$x_{ki}$ are elements of the $m$ sequences of length $N_{x}$ in array $\mathsf{X}$.

$h_{j}$ are elements of the sequence of length $N_{h}$ in array $\mathsf{H}$.

$i y 0$ is the convolution or correlation index of the element to be stored in the first position of each sequence in array $\mathsf{Y}$.

min and max select the minimum and maximum values, respectively.

It is assumed that elements outside the range of definition are zero. See references [19] and [87].

Only one invocation of this subroutine is needed:

+   1.  You do not need to invoke the subroutine with $init \ne 0$. If you do, however, the subroutine performs error checking, exits back to the calling program, and no computation is performed.
+   2.  With $init = 0$, the subroutine performs the calculation of the convolutions or correlations.

# ## Error Conditions

Computational Errors: None

**Input-Argument Errors:**

1. $nh$, $nx$, $ny$, or $m \le 0$
2. $inc1h$, $inc1x$, $inc2x$, $inc1y$, or $inc2y \le 0$

# ## Example 1

This example shows how to compute a convolution of a sequence in $\mathsf{H}$, which is a ramp function, and three sequences in $\mathsf{X}$, a triangular function and its cyclic translates. It computes the full range of nonzero values of the convolution plus two extra points, which are set to 0. The arrays are declared as follows:

```
REAL*4 H(0:4999), X(0:49999), Y(0:49999)
REAL*8 AUX1, AUX2
```

Call Statement and Input:

```
INIT H INC1H X INC1X INC2X Y INC1Y INC2Y NH NX NY M IY0 NY AUX1 Naux1 AUX2 Naux2
CALL SCON(INIT, H, 1, X, 1, 1, Y, 1, 15, 4, 10, 3, 0, 15, AUX1, 0, AUX2, 0)
```
