# # IESSL—Determine the Level of ESSSL Installed

This function returns the level of ESSSL installed on your system, where the level consists of a version number, release number, and modification number, plus the fix number of the most recent PTF installed.

# Syntax

| Fortran | IESSL () |
| --- | --- |
| C and C++ | iessI (); |

# On Return:

*Function value*

is the level of ESSSL installed on your system. It is provided as a fullword integer in the form *vwrrmmff*, where each two digits represents a part of the level:

+   - *vw* is the version number.
+   - *rr* is the release number.
+   - *mm* is the modification number.
+   - *ff* is the fix number of the most recent PTF installed.

Returned as: a fullword integer; *vwrrmmff* > 0.

# Notes

+   1. To use IESSL effectively, you must install your ESSSL PTFs in their proper sequential order. As part of the result, IESSL returns the value *ff* of the **most recent** PTF installed, rather than the **highest number** PTF installed. Therefore, if you do not install your PTFs sequentially, the *ff* value returned by IESSL does not reflect the actual level of ESSSL.
+   2. Declare the IESSL function in your program as returning a fullword integer value.

# Function

The IESSL function enables you to determine the current level of ESSSL installed on your system. It is useful to you in those instances where your program is using a subroutine or feature that exists only in certain levels of ESSSL. It is also useful when your program is dependent upon certain PTFs being applied to ESSSL.

# Example

This example shows several ways to use the IESSL function. Most typically, you use IESSL for checking the version and release level of ESSSL. Suppose you are dependent on a new capability in ESSSL, such as a new subroutine or feature, provided for the first time in ESSSL Version 3. You can add the following check in your program before using the new capability:

```
IF IESSL() > 3010000
```

By specifying 0000 for *mmff*, the modification and fix level, you are independent of the order in which your modifications and PTFs are installed.
