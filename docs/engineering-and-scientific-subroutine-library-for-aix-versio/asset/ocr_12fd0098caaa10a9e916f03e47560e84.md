**Example 1**
This example shows a sequence $\mathbf{x}$ with a positive stride.

**Call Statement and Input:**

```
CALL ISORT( $\mathbf{x}, 2, 5$ )
$\mathbf{x} = (2, \cdots, -1, \cdots, 5, \cdots, 4, \cdots, -2)$
```

**Output:**

```
$\mathbf{x} = (-2, \cdots, -1, \cdots, 2, \cdots, 4, \cdots, 5)$
```

**Example 2**
This example shows a sequence $\mathbf{x}$ with a negative stride.

**Call Statement and Input:**

```
CALL ISORT( $\mathbf{x}, -1, 5$ )
$\mathbf{x} = (2, -1, 5, 4, -2)$
```

**Output:**

```
$\mathbf{x} = (5, 4, 2, -1, -2)$
```
