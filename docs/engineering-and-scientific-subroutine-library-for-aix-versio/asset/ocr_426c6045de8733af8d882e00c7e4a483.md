# SGESV, DGESV, CGESV, ZGESV—General Matrix Factorization and Multiple Right-Hand Side Solve

These subroutines solve the system of linear equations $AX = B$ for $X$, where $A, B,$ and $X$ are general matrices.

The matrix $A$ is factored using Gaussian elimination with partial pivoting.

Table 91. Data Types
| A, B | Subroutine |
| Short-precision real | SGESV$^\triangle$ |
| Long-precision real | DGESV$^\triangle$ |
| Short-precision complex | CGESV$^\triangle$ |
| Long-precision complex | ZGESV$^\triangle$ |
$^\triangle$ LAPACK

# Syntax

| Fortran | CALL SGESV \| DGESV \| CGESV \| ZGESV (n, nrhs, a, lda, iptv, bx, ldb, info) |
| C and C++ | sgesv \| dgesv \| cgesv \| zgesv (n, nrhs, a, lda, iptv, bx, ldb, info); |

On Entry:

$n$ is the order $n$ of matrix $A$ and the number of rows of matrix $B$.  
Specified as: a fullword integer; $n \ge 0$, $n \le \text{lda}$, and $n \le \text{ldb}$.

$nrhs$ is the number of right-hand sides; that is, the number of columns of matrix $B$.  
Specified as: a fullword integer; $nrhs \ge 0$.

$a$ is the general matrix $A$ to be factored.  
Specified as: an $\text{lda}$ by (at least) $n$ array, containing numbers of the data type indicated in Table 91.

$\text{lda}$ is the leading dimension of the array specified for A.  
Specified as: a fullword integer; $\text{lda} > 0$ and $\text{lda} \ge n$.

$\text{iptv}$ See “On Return.”

$\text{bx}$ is the general matrix $B$, containing the $nrhs$ right-hand sides of the system. The right-hand sides, each of length $n$, reside in the columns of matrix $B$.  
Specified as: an $\text{ldb}$ by (at least) $nrhs$ array, containing numbers of the data type indicated in Table 91.

$\text{ldb}$ is the leading dimension of the array specified for $B$.  
Specified as: a fullword integer; $\text{ldb} > 0$ and $\text{ldb} \ge n$.

$\text{info}$ See “On Return.”

On Return:

$a$ is the transformed matrix $A$ of order $n$, containing the results of the factorization.
