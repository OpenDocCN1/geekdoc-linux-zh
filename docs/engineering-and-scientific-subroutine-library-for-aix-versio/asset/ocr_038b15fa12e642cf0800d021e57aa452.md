# SGESVS and DGESVS—Linear Least Squares Solution for a General Matrix Using the Singular Value Decomposition

These subroutines compute the minimal norm linear least squares solution of AX= B, where A is a general matrix, using the singular value decomposition computed by SGESVF or DGESVF.

**Table 125. Data Types**

| V, UUB, X, S, T | Subroutine |
| :-------------- | :--------- |
| Short-precision real | SGESVS |
| Long-precision real | DGESVS |
