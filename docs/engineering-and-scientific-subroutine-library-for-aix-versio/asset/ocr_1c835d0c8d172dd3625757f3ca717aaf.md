# SCFT3 and DCFT3

Returned as: an array, containing numbers of the data type indicated in Table 146 on page 807. This array must be aligned on a doubleword boundary. If the array is dimensioned \( (\mathrm{LDA1}, \mathrm{LDA2}, \mathrm{LDA3}) \), then $\mathrm{LDA}1 = inc2y$ , $(\mathrm{LDA}1)(\mathrm{LDA}2) = inc3y$ , and $\mathrm{LDA}3 = n3$. For information on how to set up this array, see “Setting Up Your Data” on page 746. For more details, see “Notes.”

# Notes

+   1.  If you specify the same array for $X$ and $Y$, then inc2x must be greater than or equal to inc2y , and inc3x must be greater than or equal to inc3y . In this case, output overwrites input. When using the ESSL SMP library in a multithreaded environment, if inc2x > inc2y or inc3x > inc3y , these subroutines run on a single thread and issue an attention message.
+   2.  If you specify different arrays $X$ and $Y$, they must have no common elements; otherwise, results are unpredictable. See “Concepts” on page 55.

+   2.  You should use “STRIDE—Determine the Stride Value for Optimal Performance in Specified Fourier Transform Subroutines” on page 963 to determine the optimal values for the strides inc2y and inc3y for your output array. The strides for your input array do not affect performance. Example 7 in the STRIDE subroutine description explains how it is used for these subroutines. For additional information on how to set up your data, see “Setting Up Your Data” on page 746.

# Processor-Independent Formulas for SCFT3 for NAUX

Use the following formulas for calculating $nax$:

+   1.  If $\operatorname{max}(n2,n3)<252$ and:
+   *   If $n1 \leqslant 8192$, use $nax=60000$.
+   *   If $n1 > 8192$, use $nax=60000+2.28n1$.
+   2.  If $n2 \geqslant 252, n3 < 252$, and:
+   *   If $n1 \leqslant 8192$, use $nax=60000 + \lambda$,
+   *   If $n1 > 8192$, use $nax=60000+2.28n1 + \lambda$,
+   *   where $\lambda = ((n2+256)(s+2.28)$
+   *   and $s=\min(64,n1)$.
+   3.  If $n2 < 252, n3 \geqslant 252$, and:
+   *   If $n1 \leqslant 8192$, use $nax=60000+\psi$.
+   *   If $n1 > 8192$, use $nax=60000+2.28n1 + \psi$,
+   *   where $\psi = ((n3+256)(s+2.28)$
+   *   and $s = \min(64, (n1)(n2))$.
+   4.  If $n2 \geqslant 252$ and $n3 \geqslant 252$, use the larger of the values calculated for cases 2 and 3 above.
