# SPTNQ and DPTNQ—Numerical Quadrature Performed on a Set of Points

These subroutines approximate the integral of a real valued function specified in tabular form, $(x_{i}, y_{i})$ for $i=1, n$. For more than four points, an error estimate is returned along with the resulting value.

**Table 167. Data Types**

| *x, y, xjint, est* | *Subroutine* |
| :--- | :--- |
| Short-precision real | SPTNQ |
| Long-precision real | DPTNQ |


# **Syntax**

| | |
| :--- | :--- |
| **Fortran** | CALL SPTNQ \| DPTNQ $(x, y, n, xjint, est)$ |
| **C and C++** | sptnq \| dptnq $(x, y, n, xjint, est)$; |


**On Entry:**

$x$ is the vector **x** of length $n$, containing the abscissas of the data points to be integrated. The elements of $\mathbf{x}$ must be distinct and sorted into ascending or descending order.

Specified as: a one-dimensional array of (at least) length $n$, containing numbers of the data type indicated in Table 167.

$y$ is the vector **y** of length $n$, containing the ordinates of the data points to be integrated.

Specified as: a one-dimensional array of (at least) length $n$, containing numbers of the data type indicated in Table 167.

$n$ is the number of elements in vectors $\mathbf{x}$ and $\mathbf{y}$—that is, the number of data points. The value of $n$ determines the algorithm used by this subroutine. For details, see “Function” on page 918.

Specified as: a *fullword* integer; $n \ge 2$.

$xjint$ See “On Return.”

$est$ See “On Return.”

**On Return:**

$xjint$ is the approximation $xjint$ of the integral. Returned as: a number of the data type indicated in Table 167.

$est$ has the following meaning, where:

If $n<5$, it is undefined and is set to 0.

If $n \ge 5$, it is an estimate, $est$, of the error in the integral, where $xjint + est$ tends to give a better approximation to the integral than $xjint$. For details, see references [28] and [63].

Returned as: a number of the data type indicated in Table 167.

# **Notes**

+   1. In your C program, arguments $xjint$ and $est$ must be passed by reference.
