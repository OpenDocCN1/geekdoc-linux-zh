# **SQINT and DQINT**—Quadratic Interpolation

These subroutines perform a quadratic interpolation at specified points in the vector $x$, using initial linear displacement in the samples $s$, sample interval $g$, output scaling parameter $\Omega$, and sample reflection times in vector $t$. The result is returned in vector $y$.

*Table 153. Data Types*

| $x, s, g, \mathbf{0}, t, y$ | Subroutine |
| :---: | :---: |
| Short-precision real | SQINT |
| Long-precision real | DQINT |

# **Syntax**

| Fortran | CALL.SQINT I DQINT $(s, g, \text{omega}, x, incx, n, t, inct, y, incy, m)$ |
| :--- | :--- |
| C and C++ | sqint ! dqint $(s, g, \text{omega}, x, incx, n, t, inct, y, incy, m);$ |

# **On Entry:**

+   - $s$ is the scalar $s$, containing the initial linear displacement in samples.
+   	- Specified as: a number of the data type indicated in Table 153.
+   - $g$ is the scalar $g$, containing the sample interval.
+   	- Specified as: a number of the data type indicated in Table 153; $g > 0.0$.
+   - $\text{omega}$ is the output scaling parameter $\Omega$.
+   	- Specified as: a number of the data type indicated in Table 153.
+   - $x$ is the vector $x$ of length $n$, containing the trace data.
+   	- Specified as: a one-dimensional array of (at least) length $1+(n-1)\lvert incx\rvert$, containing numbers of the data type indicated in Table 153.
+   - $incx$ is the stride for vector $x$.
+   	- Specified as: a fullword integer; $incx > 0$ or $incx < 0$.
+   - $n$ is the number of elements in vector $x$.
+   	- Specified as: a fullword integer; $n \geq 3$.
+   - $t$ is the vector $t$ of length $m$, containing the sample reflection times to be processed.
+   	- Specified as: a one-dimensional array of (at least) length $1+(m-1)\lvert inct\rvert$, containing numbers of the data type indicated in Table 153.
+   - $inct$ is the stride for vector $t$.
+   	- Specified as: a fullword integer; $inct > 0$ or $inct < 0$.
+   - $y$ See “On Return” on page 868.
+   - $incy$ is the stride for output vector $y$.
+   	- Specified as: a fullword integer; $incy > 0$ or $incy < 0$.
+   - $m$ is the number of elements in vector $t$ and the number of elements in output vector $y$.
+   	- Specified as: a fullword integer; $m \geq 0$.
