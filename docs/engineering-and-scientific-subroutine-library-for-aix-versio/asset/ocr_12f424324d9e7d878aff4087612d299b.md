# SROTG, DROTG, CROTG, and ZROTG

```
r = \Psi\sqrt{|a|^{2}+|b|^{2}} \quad \text{if } |a| \neq 0
```

```
r = b \qquad \text{if } |a| = 0
```

where:

```
\Psi = a/|a|
```

Returned as: a number of the data type indicated in Table 52 on page 236.

*b* is the value computed for *z*.

For SROTG and DROTG:

```
z = s \qquad \text{if } |a| > |b|
```

```
z = 1/c \qquad \text{if } |a| \leq |b| \text{ and } c \neq 0 \text{ and } r \neq 0
```

```
z = 1 \qquad \text{if } |a| \leq |b| \text{ and } c = 0 \text{ and } r \neq 0
```

```
z = 0 \qquad \text{if } r = 0
```

For CROTG and ZROTG: no value is returned, and the input value is not changed.

Returned as: a number of the data type indicated in Table 52 on page 236.

*c* is the cosine *c* of the angle of (Givens) rotation. For SROTG and DROTG:

```
c = a/r \qquad \text{if } r \neq 0
```

```
c = 1 \qquad \text{if } r = 0
```

For CROTG and ZROTG:

```
c = \frac{|a|}{\sqrt{|a|^{2}+|b|^{2}}} \qquad \text{if } |a| \neq 0
```

```
c = 0 \qquad \text{if } |a| = 0
```

Returned as: a number of the data type indicated in Table 52 on page 236.

*s* is the sine *s* of the angle of (Givens) rotation.

For SROTG and DROTG:

```
s = b/r \qquad \text{if } r \neq 0
```

```
s = 0 \qquad \text{if } r = 0
```

For CROTG and ZROTG:

```
s = \frac{\Psi\bar{b}}{\sqrt{|a|^{2}+|b|^{2}}} \qquad \text{if } |a| \neq 0
```

```
s = (1.0,0.0) \qquad \text{if } |a| = 0
```

where \Psi = a/|a|
