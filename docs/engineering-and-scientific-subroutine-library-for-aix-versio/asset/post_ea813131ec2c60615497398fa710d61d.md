
## Specified as: a fullword *integer*; *ldb* $\gg$ 0 and *ldb* $\ge$ *n*.

*nsinfo* is the number of elements in array, *AP*.

If *n* $\le$ *nco*, *nsinfo* = *n*( *n* + 1 ) / 2

Where:

$$nco = \sqrt{2.0(ics)}$$

*ics* is the size in doublewords of the data cache. The data cache size can be obtained by utilizing the following C language code fragment:

```c
#include <sys/systemcfg.h>
int ics;
...
ics = _system_configuration.dcache_size/8;
```

Otherwise, to determine a sufficient amount of storage, use the following processor-independent formula:

```c
n0 = 100
ns = (n + n0)( n + n0 + 1) / 2 + n(n0)
For uplo = ‘L’,
       nsinfo >= ns
For uplo = ‘U’,
       n1 = (n + 1) / 2
       nt = n((n + 1) / 2)
       nt1 = n1(n1 + 1)
       ns1 = nt + nt1
       nsinfo >= max(ns, ns1)
```

To determine the minimal amount of storage see “Notes” on page 506.

Specified as: a fullword *integer*; *nsinfo* $>$ 0.

### On Return:

*   *ap* is the transformed matrix $A$ of order *n*, containing the results of the factorization.
*   If *nsinfo* $\ge$ 0 and *n* $>$ *nco*, additional information that can be used to obtain a minimum *nsinfo* is stored in *AP*(1). See “Notes” on page 506 and “Function” on page 506.
*   Returned as: a one-dimensional array, containing numbers of the data type indicated in Table 104 on page 504.
*   *ipvt* is an integer vector of length *n*, containing the pivot information necessary to construct the factored form of $A$.
*   Returned as: a one-dimensional array of (at least) length *n*, containing numbers of the data type indicated in Table 104 on page 504.
*   *bx* is the matrix **X**, containing the *nrhs* solutions to the system. The solutions, each of length *n*, reside in the columns of **X**.
*   Returned as: an *ldb* by (at least) *nrhs* array, containing numbers of the data type indicated in Table 104 on page 504.
*   *nsinfo* indicates the result of the computation.
    *   If ninfo = 0, the subroutine completed successfully.
    *   If ninfo > 0, factorization was unsuccessful and array B was not updated. ninfo is set to i where d_i is exactly zero.
    *   If ninfo < 0, factorization did not take place and the arrays, AP and B, remain unchanged. |ninfo| is the minimal storage required for factorization to take place. Error message 2200 is issued and execution terminates, unless you have used ERRSET to make error code 2200 recoverable. See “What Can You Do about ESSL Input-Argument Errors?” on page 46.
    *   Specified as: a fullword integer.

## Notes

- This subroutine accepts lowercase letters for the uplo argument.
- In your C program, argument ninfo must be passed by reference.
- In the input array specified for ap, first n(n+1)/2 elements are matrix elements. The additional locations, required in the array, are used for working storage.
- The vectors and matrices used in this computation must have no common elements; otherwise, results are unpredictable. See “Concepts” on page 55.
- On return, if ninfo $\ge$ 0 and n > nco, ap contains additional information in AP(1) that can be used to obtain the minimal required ninfo. This information can be accessed using the following code fragment:

```fortran
REAL*8 AP(NSINFO)
INTEGER AP1(2)
EQUIVALENCE(AP1, AP)
...
NSINFOMIN = AP1(2)
```

- For a description of how a symmetric matrix is stored in upper- or lower-packed storage mode in an array, see “Symmetric Matrix” on page 64.

## Function

The system AX = B is solved for X, where A is a real symmetric indefinite matrix, and X and B are real general matrices.

The matrix A, stored in upper- or lower-packed storage mode, is factored using the Bunch-Kaufman diagonal pivoting method, where A is expressed as:
A = UDUT or
A = LDLT

where:

- U is a product of permutation and unit upper triangular matrices.
- L is a product of permutation and unit lower triangular matrices.
- D is a symmetric block diagonal matrix, consisting of 1 × 1 and 2 × 2 diagonal blocks.

If n is 0, no computation is performed and the subroutine returns after doing some parameter checking. If n > 0 and nrhs is 0, no solutions are computed and the subroutine returns after factoring the matrix.

See references [8] and [67].

## Error Conditions

### Resource Errors
None.

### Computational Errors
- Matrix A is singular.
- The factorization completed but the block diagonal matrix D is exactly singular. *nsinfo* is set to i, where d_i is exactly zero. This diagonal element is identified in the computational error message.
- The computational error message may occur multiple times with processing continuing after each error, because the default for the number of allowable errors for error code 2147 is set to be unlimited in the ESSL error option table. For details, see “What Can You Do about ESSL Computational Errors?” on page 47.

### Input-Argument Errors
1. *uplo* $\neq$ 'U' or 'L'
2. *n* < 0
3. *n* > *ldb*
4. *ldb* $\le$ 0
5. *nrhs* < 0
6. *nsinfo* < (minimum value).

* For the minimum value, see the *nsinfo* argument description.
* Return code 1 is returned if error 2200 is recoverable.

## Example 1

This example shows how to solve the system AX = B, for three right-hand sides, where matrix A is a real symmetric indefinite matrix of order 8, stored in lower-packed storage mode, and X and B are real general matrices.

On input, matrix A is:

$$
A = \begin{array}{cccccccc}
3.0 & 5.0 & -2.0 & 2.0 & 3.0 & -5.0 & -2.0 & -3.0 \\
5.0 & 3.0 & 2.0 & -2.0 & 5.0 & -3.0 & 2.0 & -5.0 \\
-2.0 & 2.0 & 0.0 & 0.0 & -2.0 & 2.0 & 0.0 & 6.0 \\
2.0 & -2.0 & 0.0 & 8.0 & -6.0 & -10.0 & -8.0 & -14.0 \\
3.0 & 5.0 & -2.0 & -6.0 & 12.0 & 6.0 & 8.0 & 6.0 \\
-5.0 & -3.0 & 2.0 & -10.0 & 6.0 & 16.0 & 8.0 & 20.0 \\
-2.0 & 2.0 & 0.0 & -8.0 & 8.0 & 8.0 & 6.0 & 18.0 \\
-3.0 & -5.0 & 6.0 & -14.0 & 6.0 & 20.0 & 18.0 & 34.0
\end{array}
$$

**Note:** The AP array is formatted in a triangular arrangement for readability; however, it is stored in lower-packed storage mode.

### Call Statement and Input

```fortran
CALL DBSSV ( 'L', 8, 3, AP, IPVT, BX, 8, 36 )
AP = ( 3.0, 5.0, -2.0, 2.0, 3.0, -5.0, -2.0, -3.0,
3.0, 2.0, -2.0, 5.0, -3.0, 2.0, -5.0,
0.0, 0.0, -2.0, 2.0, 0.0, 6.0,
8.0, -6.0, -10.0, -8.0, -14.0,
12.0, 6.0, 8.0, 6.0,
16.0, 8.0, 20.0,
6.0, 18.0,
34.0 )
BX = ( 1.0, -38.0, 47.0,
       7.0, -10.0, 73.0 )
```

### Output

$$
BX = \begin{array}{rrr}
1.0 & 1.0 & 8.0 \\
1.0 & 2.0 & 7.0 \\
1.0 & 3.0 & 6.0 \\
1.0 & 4.0 & 5.0 \\
1.0 & 5.0 & 4.0 \\
1.0 & 6.0 & 3.0 \\
1.0 & 7.0 & 2.0 \\
1.0 & 8.0 & 1.0
\end{array}
$$

NSINFO = 0

**Note:** AP and IPVT are stored in an internal format.

## Example 2

This example shows how to solve the system $AX = B$, for three right-hand sides, where matrix $A$ is a real symmetric indefinite matrix of order 8, stored in upper-packed storage mode, and $X$ and $B$ are real general matrices.

On input, matrix $A$ is:

$$
A = \begin{array}{rrrrrrrr}
34.0 & 18.0 & 17.0 & 6.0 & -14.0 & 6.0 & -5.0 & -3.0 \\
18.0 & 6.0 & 6.0 & 8.0 & -8.0 & 0.0 & 2.0 & -2.0 \\
17.0 & 6.0 & 9.0 & 9.0 & -8.0 & 0.0 & 2.0 & -2.0 \\
6.0 & 8.0 & 9.0 & 12.0 & -6.0 & -2.0 & 5.0 & 3.0 \\
-14.0 & -8.0 & -8.0 & -6.0 & 8.0 & 0.0 & -2.0 & 2.0 \\
6.0 & 0.0 & 0.0 & -2.0 & 0.0 & 0.0 & 2.0 & -2.0 \\
-5.0 & 2.0 & 2.0 & 5.0 & -2.0 & 2.0 & 3.0 & 5.0 \\
-3.0 & -2.0 & -2.0 & 3.0 & 2.0 & -2.0 & 5.0 & 3.0
\end{array}
$$

**Note:** The AP array is formatted in a triangular arrangement for readability; however, it is stored in upper-packed storage mode.

### Call Statement and Input

```fortran
UPLO N NRHS AP IPVT BX LDBX NSINFO
CALL DBSSV ( 'U', 8, 3,  AP,  IPVT, BX,  8,   36 )

      18.0,  6.0,
      17.0,  6.0,  9.0,

      -5.0,  2.0,  2.0,  5.0, -2.0,  2.0,  3.0,
      -3.0, -2.0, -2.0,  3.0,  2.0, -2.0,  5.0,  3.0 )
BX = ( 59.0,  52.0, 479.0,
       30.0,  38.0, 232.0,
       33.0,  50.0, 247.0,
       35.0, 114.0, 201.0,
      -28.0, -36.0,-216.0 )
```
