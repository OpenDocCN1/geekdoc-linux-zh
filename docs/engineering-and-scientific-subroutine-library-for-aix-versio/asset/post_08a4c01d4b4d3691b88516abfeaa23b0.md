
# SSPR2, DSPR2, CHPR2, ZHPR2, SSYR2, DSYR2, CHER2, ZHER2, SSLR2, and DSLR2

- $ap$ is the matrix $A$ of order $n$, containing the results of the computation. Returned as: a one-dimensional array, containing numbers of the data type indicated in Table 70 on page 319.

- $a$ is the matrix $A$ of order $n$, containing the results of the computation. Returned as: a two-dimensional array, containing numbers of the data type indicated in Table 70 on page 319.

# Notes

1. All subroutines accept lowercase letters for the $uplo$ argument.
2. The vectors $\mathbf{x}$ and $\mathbf{y}$ must have no common elements with matrix $A$; otherwise, results are unpredictable. See "Concepts" on page 55.
3. On input, the imaginary parts of the diagonal elements of the complex Hermitian matrix $A$ are assumed to be zero, so you do not have to set these values. On output, if $\alpha \neq$ zero, the imaginary parts of the diagonal elements are set to zero.
4. For a description of how symmetric matrices are stored in upper- or lower-packed storage mode and upper or lower storage mode, see "Symmetric Matrix" on page 64. For a description of how complex Hermitian matrices are stored in upper- or lower-packed storage mode and upper or lower storage mode, see "Complex Hermitian Matrix" on page 69.

# Function

These subroutines perform the computation described in the two sections below. See references [36], [37], and [81]. If $n$ or $\alpha$ is zero, no computation is performed.

For SSPR2, SSYR2, SSLR2, CHPR2, and CHER2, intermediate results are accumulated in long precision.

**SSPR2, DSPR2, SSYR2, DSYR2, SSLR2, and DSLR2:** These subroutines compute the rank-two update of a real symmetric matrix:

$$A \leftarrow A + \alpha x y^T + \alpha y x^T$$

where:
- $A$ is a real symmetric matrix of order $n$.
- $\alpha$ is a scalar.
- $\mathbf{x}$ is a vector of length $n$.
- $\mathbf{x}^{\mathrm{T}}$ is the transpose of vector $\mathbf{x}$.
- $\mathbf{y}$ is a vector of length $n$.
- $\mathbf{y}^{\mathrm{T}}$ is the transpose of vector $\mathbf{y}$.

It is expressed as follows:

$$\begin{bmatrix} a_{11} & \cdots & a_{1n} \\ \vdots & \vdots & \\ \vdots & \vdots & \\ a_{n1} & \cdots & a_{mn} \end{bmatrix} \leftarrow \begin{bmatrix} a_{11} & \cdots & a_{1n} \\ \vdots & \vdots & \\ \vdots & \vdots & \\ a_{n1} & \cdots & a_{mn} \end{bmatrix} + \alpha \begin{bmatrix} x_1 \\ \vdots \\ x_n \end{bmatrix} \begin{bmatrix} y_1 & \cdots & y_n \end{bmatrix} + \alpha \begin{bmatrix} y_1 \\ \vdots \\ y_n \end{bmatrix} \begin{bmatrix} x_1 & \cdots & x_n \end{bmatrix}$$

CHPR2, ZHPR2, CHER2, and ZHER2: These subroutines compute the rank-two update of a complex Hermitian matrix:

$$\boldsymbol{A} \leftarrow \boldsymbol{A} + \alpha \boldsymbol{x} \boldsymbol{y}^\mathrm{H} + \bar{\alpha} \boldsymbol{y} \boldsymbol{x}^\mathrm{H}$$

where:
- $A$ is a complex Hermitian matrix of order $n$.
- $\alpha$ is a scalar.
- $\mathbf{x}$ is a vector of length $n$.
- $\mathbf{x}^\mathrm{H}$ is the conjugate transpose of vector $\mathbf{x}$.
- $\mathbf{y}$ is a vector of length $n$.
- $\mathbf{y}^\mathrm{H}$ is the conjugate transpose of vector $\mathbf{y}$.

It is expressed as follows:

$$\begin{bmatrix} a_{11} & \cdots & a_{1n} \\ \vdots & \vdots & \\ \vdots & \vdots & \\ a_{n1} & \cdots & a_{mn} \end{bmatrix} \leftarrow \begin{bmatrix} a_{11} & \cdots & a_{1n} \\ \vdots & \vdots & \\ \vdots & \vdots & \\ a_{n1} & \cdots & a_{mn} \end{bmatrix} + \alpha \begin{bmatrix} x_1 \\ \vdots \\ x_n \end{bmatrix} \begin{bmatrix} \bar{y}_1 & \cdots & \bar{y}_n \end{bmatrix} + \bar{\alpha} \begin{bmatrix} y_1 \\ \vdots \\ y_n \end{bmatrix} \begin{bmatrix} \bar{x}_1 & \cdots & \bar{x}_n \end{bmatrix}$$

## Error Condition

**Computational Errors:** None

**Input-Argument Errors:**

1. $uplo$ ≠ 'L' or 'U'
2. $n$ < 0
3. $incx$ = 0
4. $incy$ = 0
5. $lda$ ≤ 0
6. $lda$ < $n$

# Example 1

This example shows vectors $\mathit{x}$ and $\mathit{y}$ with positive strides and a real symmetric matrix $A$ of order 3, stored in lower-packed storage mode. Matrix $A$ is:

$$\left[ \begin{array}{c c c} 8.0 & 4.0 & 2.0 \\ 4.0 & 6.0 & 7.0 \\ 2.0 & 7.0 & 3.0 \end{array} \right]$$

Call Statement and Input:

```
             UPLO N ALPHA X INCX Y INCY AP
                |   |   |   |  |   |   |
CALL SSPR2(  'L' , 3 , 1.0, X , 1 ,  Y , 2 , AP  )
X            =  (3.0, 2.0, 1.0)
Y            =  (5.0, . , 3.0, . , 2.0)
AP           =  (8.0, 4.0, 2.0, 6.0, 7.0, 3.0)
```

Output:

```
AP =  (38.0, 23.0, 13.0, 18.0, 14.0, 7.0)
```

# Example 2

This example shows vector $\mathit{x}$ and $\mathit{y}$ having strides of opposite signs. For $\mathit{x}$, which has negative stride, processing begins at element $X(5)$, which is 3.0. The real symmetric matrix $A$ of order 3 is stored in upper-packed storage mode. It uses the same input matrix $A$ as in Example 1.

Call Statement and Input:

```
             UPLO N ALPHA X INCX Y INCY AP
                |   |   |   |   |   |   |
CALL SSPR2(  'U', 3 , 1.0, X , -2 , Y , 2 , AP  )
X            =  (1.0, . , 2.0, . , 3.0)
Y            =  (5.0, . , 3.0, . , 2.0)
AP           =  (8.0, 4.0, 6.0, 2.0, 7.0, 3.0)
```

Output:

```
AP =  (38.0, 23.0, 18.0, 13.0, 14.0, 7.0)
```

# Example 3

This example shows vector $\mathit{x}$ and $\mathit{y}$ with positive stride and a complex Hermitian matrix $A$ of order 3, stored in lower-packed storage mode. Matrix $A$ is:

$$\left[ \begin{array}{c c c} \left(1.0, 0.0\right) & \left(3.0, 5.0\right) & \left(2.0, -3.0\right) \\ \left(3.0, -5.0\right) & \left(7.0, 0.0\right) & \left(4.0, -8.0\right) \\ \left(2.0, 3.0\right) & \left(4.0, 8.0\right) & \left(6.0, 0.0\right) \end{array} \right]$$

**Note:** On input, the imaginary parts of the diagonal elements of the complex Hermitian matrix $A$ are assumed to be zero, so you do not have to set these values. On output, if $\alpha \neq$ zero, the imaginary parts of the diagonal elements are set to zero.

Call Statement and Input:

```
             UPLO N ALPHA X INCX Y INCY AP
                |   |   |   |   |   |   |
CALL CHPR2(  'L' , 3 , ALPHA , X , 1 , Y , 2 , AP  )
```

ALPHA = (1.0, 0.0)
X = ((1.0, 2.0), (4.0, 0.0), (3.0, 4.0))
Y = ((1.0, 0.0), . , (2.0, -1.0), . , (2.0, 1.0))
AP = ((1.0, . ), (3.0, -5.0), (2.0, 3.0), (7.0, . ),
(4.0, 8.0), (6.0, . ))

**Output:**
AP = ((3.0, 0.0), (7.0, -10.0), (9.0, 4.0), (23.0, 0.0),
(14.0, 23.0), (26.0, 0.0))

# Example 4

This example shows vector x and y having strides of opposite signs. For x, which has negative stride, processing begins at element X(5), which is (1.0,2.0). The complex Hermitian matrix A of order 3 is stored in upper-packed storage mode. It uses the same input matrix A as in Example 3.

**Note:** On input, the imaginary parts of the diagonal elements of the complex Hermitian matrix A are assumed to be zero, so you do not have to set these values. On output, if $\alpha \neq$ zero, the imaginary parts of the diagonal elements are set to zero.

**Call Statement and Input:**

```
UPLO N ALPHA X INCX Y INCY AP
|
CALL CHPR2 ('U' , 3 , ALPHA , X , -2 , Y , 2 , AP )
```

ALPHA = (1.0, 0.0)
X = ((3.0, 4.0), . , (4.0, 0.0), . , (1.0, 2.0))
Y = ((1.0, 0.0), . , (2.0, -1.0), . , (2.0, 1.0))
AP = ((1.0, . ), (3.0, 5.0), (7.0, . ), . , (2.0, -3.0),
(4.0, -8.0), (6.0, . ))

**Output:**
AP = ((3.0, 0.0), (7.0, 10.0), (23.0, 0.0), (9.0, -4.0),
(14.0, -23.0), (26.0, 0.0))
