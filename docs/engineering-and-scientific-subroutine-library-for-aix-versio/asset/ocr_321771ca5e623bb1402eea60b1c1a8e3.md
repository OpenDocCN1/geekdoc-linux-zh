# Function

These subroutines can perform the following matrix-matrix product computations using matrix A, which is real symmetric for SSYMM and DSYMM, complex symmetric for CSYMM and ZSYMM, and complex Hermitian for CHEMM and ZHEMM:

+   1.  *C*←α*AB*+β*C*
+   2.  *C*←α*BA*+β*C*
+   
+   where:
+   
+   *α* and *β* are scalars.
+   *A* is a matrix of the type indicated above, stored in upper or lower storage mode. It is order *m* for equation 1 and order *n* for equation 2.
+   *B* and *C* are *m* by *n* rectangular matrices.

See references [34] and [40]. In the following two cases, no computation is performed:
*   *n* or *m* is 0.
*   *β* is one and *α* is zero.

# Error Conditions

Resource Errors: Unable to allocate internal work area.

Computational Errors: None

+   Input-Argument Errors:
+   1.  *m* < 0
+   2.  *m* > *ldb*
+   3.  *m* > *ldc*
+   4.  *n* < 0
+   5.  *lda, ldb, ldc* ≤ 0
+   6.  *side* ≠ ‘L’ or ‘R’
+   7.  *uplo* ≠ ‘L’ or ‘U’
+   8.  *side* = ‘L’ and *m* > *lda*
+   9.  *side* = ‘R’ and *n* > *lda*

# Example 1

This example shows the computation *C*←α*AB*+β*C*, where *A* is a real symmetric matrix of order 5, stored in upper storage mode, and *B* and *C* are 5 by 4 rectangular matrices.

```
Call Statement and Input:
SIDE  UPLO  M   N   ALPHA   A   LDA   B   LDB   BETA   C   LDC
 |     |     |   |     |     |   |   |     |   |     |   |   |   |   |   |
CALL SSYMM( 'L' , 'U' , 5 , 4 , 2.0 , A , 8 , B , 6 , 1.0 , C , 5 )
```
