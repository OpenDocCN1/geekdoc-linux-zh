# Function

**SROTG and DROTG:**  A real Givens plane rotation is constructed for values $a$ and $b$ by computing values for $r$, $c$, $s$, and $z$, where:

$r = \sigma \sqrt{a^2 + b^2}$

where:

$\sigma = \mathrm{SIGN}(a) \qquad \mathrm{if} |a| > |b|$

$\sigma = \mathrm{SIGN}(b) \qquad \mathrm{if} |a| \le |b|$

$c = a/r \qquad \mathrm{if} r \ne 0$ $c = 1 \qquad \mathrm{if} r = 0$ $s = b/r \qquad \mathrm{if} r \ne 0$ $s = 0 \qquad \mathrm{if} r = 0$ $z = s \qquad \mathrm{if} |a| > |b|$ $z = 1/c \qquad \mathrm{if} |a| \le |b| \mathrm{and} c \ne 0 \mathrm{and} r \ne 0$ $z = 1 \qquad \mathrm{if} |a| \le |b| \mathrm{and} c = 0 \mathrm{and} r \ne 0$ $z = 0 \qquad \mathrm{if} r = 0$

See reference [81].

Following are some important points about the computation:

+   1.  The numbers for $c$, $s$, and $r$ satisfy:
+   
+   $$
+   \begin{bmatrix}
+   c & s \\
+   -s & c
+   \end{bmatrix}
+   \begin{bmatrix}
+   a \\ b
+   \end{bmatrix}
+   =
+   \begin{bmatrix}
+   r \\ 0
+   \end{bmatrix}
+   $$
+   
+   2.  Where necessary, scaling is used to avoid overflow and destructive underflow in the computation of $r$, which is expressed as follows:
+   
+   $$
+   r = \sigma \big( |a| + |b| \big)
+   \sqrt{
+   \left( \frac{a}{|a|+|b|} \right)^2 +
+   \left( \frac{b}{|a|+|b|} \right)^2
+   }
+   $$
+
