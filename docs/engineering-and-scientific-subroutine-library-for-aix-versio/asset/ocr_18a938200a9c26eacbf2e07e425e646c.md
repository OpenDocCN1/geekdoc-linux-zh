# Special Usage

**Equivalence Rules:** The equivalence rules, defined for matrix multiplication of $A$ and $B$ in “Special Usage” on page 380, also apply to the matrix multiplication part of the computation performed by this subroutine. You should use the equivalent rules when you want to transpose or conjugate transpose the multiplication part of the computation. When coding the calling sequences for these cases, be careful to code your matrix arguments and dimension arguments in the order indicated by the rule. Also, be careful that your input and output array C has dimensions large enough to hold the resulting matrix. See “Example 4” on page 397.
