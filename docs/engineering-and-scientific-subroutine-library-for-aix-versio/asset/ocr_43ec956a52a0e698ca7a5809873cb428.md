# Example 8

This example shows vector $\boldsymbol{x}$ and $\boldsymbol{y}$ having strides of opposite signs. For $\boldsymbol{x}$, which has negative stride, processing begins at element $\boldsymbol{X}(5)$, which is (1.0, 2.0). The complex Hermitian matrix $\boldsymbol{A}$ of order 3 is stored in upper storage mode. It uses the same input matrix $\boldsymbol{A}$ as in Example 3.

> Note: On input, the imaginary parts of the diagonal elements of the complex Hermitian matrix $\boldsymbol{A}$ are assumed to be zero, so you do not have to set these values. On output, if $\boldsymbol{\alpha}$ \neq zero, the imaginary parts of the diagonal elements are set to zero.

Call Statement and Input:

```
```
               UPL0 N ALPHA X INCX Y INCY A LDA
                  |  |  |    |  |    |   |  |  |
CALL CHER2( 'U' , 3 , ALPHA , X , -2 , Y , 2 , A , 3 )

ALPHA = (1.0, 0.0)
X    = ((3.0, 4.0) , . , (4.0, 0.0) , . , (1.0, 2.0))
Y    = ((1.0, 0.0), . , (2.0, -1.0), . , (2.0, 1.0))

A = [  (1.0, .) (3.0, 5.0) (2.0, -3.0)
      .        (7.0, .)    (4.0, -8.0)
      .        .           (6.0, .)  ]
```
```

A = [  (3.0, 0.0) (7.0, 10.0) (9.0, -4.0)
      .          (23.0, 0.0) (14.0, -23.0)
      .          .           (26.0, 0.0)  ]

# Example 9

This example shows vectors $\boldsymbol{x}$ and $\boldsymbol{y}$ with positive strides and a real symmetric matrix $\boldsymbol{A}$ of order 3, stored in lower-packed storage mode. It uses the same input matrix $\boldsymbol{A}$ as in Example 1.

Call Statement and Input:

```
```
             N ALPHA X INCX Y INCY AP
                |  |    |  |    |  |  |
CALL SSLR2( 3 , 1.0 , X , 1 , Y , 2 , AP )

X = (3.0, 2.0, 1.0)
Y = (5.0, . , 3.0, . , 2.0)
AP = (8.0, 4.0, 2.0, 6.0, 7.0, 3.0)
```
```

Output:

```
```
AP = (38.0, 23.0, 13.0, 18.0, 14.0, 7.0)
