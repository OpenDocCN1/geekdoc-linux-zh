# DGSS—General Sparse Matrix or Its Transpose Solve Using Storage by Indices, Rows, or Columns

This subroutine solves either of the following systems:

$A\mathbf{x}=\mathbf{b}$  
$A^{T} \mathbf{x}=\mathbf{b}$

where $\mathbf{A}$ is a sparse matrix, $A^{T}$ is the transpose of sparse matrix $A$, and $\mathbf{x}$ and $\mathbf{b}$ are vectors. DGSS uses the results of the factorization of matrix $A$, produced by a preceding call to DGSE.

> **Note:** The input to this solve subroutine must be the output from the factorization subroutine, DGSE.

# Syntax

| Fortran | CALL DGSS (i o p t , n , a , i a , j a , l n a , b x , a u x , n a u x ) |
| C and C++ | d g s s ( i o p t , n , a , i a , j a , l n a , b x , a u x , n a u x ); |

# On Entry:

+   iopt
+       indicates the type of computation to be performed, where:
+       - If iopt = 0, A x = b is solved, where the right-hand side is not sparse.
+       - If iopt = 1, A^T x = b is solved, where the right-hand side is not sparse.
+       - If iopt = 10, A x = b is solved, where the right-hand side is sparse.
+       - If iopt = 11, A^T x = b is solved, where the right-hand side is sparse.
+       - Specified as: a fullword integer; iopt = 0, 1, 10, or 11.

+   n    is the order n of sparse matrix A. Specified as: a fullword integer; n ≥ 0.

+   a    is the factorization of sparse matrix A, stored in array a, produced by a preceding call to DGSE.
+       Specified as: an array of length lna, containing long-precision real numbers.

+   ia    is the array, referred to as IA, produced by a preceding call to DGSE.
+       Specified as: an array of length lna, containing fullword integers.

+   ja    is the array, referred to as JA, produced by a preceding call to DGSE.
+       Specified as: an array of length lna, containing fullword integers.

+   lna    is the length of the arrays a, IA, and JA. In DGSS, lna must be identical to the value specified in DGSE; otherwise, results are unpredictable.
+       Specified as: a fullword integer; lna > 0.

+   bx    is the vector b of length n, containing the right-hand side of the system.
+       Specified as: a one-dimensional array of (at least) length n, containing long-precision real numbers.

+   aux    is the storage work area passed to this subroutine by a preceding call to DGSE. Its size is specified by naux.
+       Specified as: an area of storage, containing long-precision real numbers.

+   naux    is the size of the work area specified by aux—that is, the number of elements in aux.
