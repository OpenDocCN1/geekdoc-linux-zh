# SGETMI, DGETMI, CGETMI, and ZGETMI

![](bbox=[0.25, 0.09, 0.45, 0.17])

the in-place matrix transpose operation $A \leftarrow A^{T}$ is expressed as:

![](bbox=[0.25, 0.24, 0.55, 0.32])

If $n$ is 0, no computation is performed.

# Error Conditions

Computational Errors: None

Input-Argument Errors:

+   1. $n < 0$ or $n > \mathbf{l d a}$
+   2. $\mathbf{l d a} \leq 0$

# Example

This example shows an in-place matrix transpose of matrix $A$ having 5 rows and 5 columns.

**Call Statement and Input:**

```
 A LDA N
|
CALL SGETMI( A(2,3) , 10 , 5 )
```
