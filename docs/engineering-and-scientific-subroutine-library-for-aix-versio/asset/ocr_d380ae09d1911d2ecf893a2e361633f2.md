# Example 2

This example shows another transform computation with different data using the same initialized array AUX1 as in Example 1. The input is also a set of four cosine sequences \(\cos(2 \pi j k / n), j = 0, 1, \ldots, 15\) with the single frequencies \(k = 8, 9, 10, 11\), thus including the middle frequency \(k = 8\). The middle frequency has the value 1.0. For other frequencies, the transform has zeros, except for frequencies \(k\) and \(n - k\). Only the values for \(j = n - k\) are given in the output.

Call Statement and Input:

```
```
        INC2X   Y   INC2Y N  M ISIGN SCALE AUX1  NAUX1  AUX2  NAUX2  AUX3  NAUX3

          |
CALL  SRCFT( O , X , 16 , Y , 9 , 16 , 4 , 1 , SCALE, AUX1 , 41928 , AUX2 , 35344 , AUX3 , 0 )

SCALE         = 1.0/16
