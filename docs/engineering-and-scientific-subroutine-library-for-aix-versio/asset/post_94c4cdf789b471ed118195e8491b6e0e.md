## SPOTRS, DPOTRS, CPOTRS, ZPOTRS, SPOSM, DPOSM, CPOSM, ZPOSM, SPITRS, and DPPITRS

### SPOTRS, DPOTRS, CPOTRS, ZPOTRS, SPOSM, DPOSM, CPOSM, ZPOSM, SPITRS, and DPPITRS — Positive Definite Real Symmetric or Complex Hermitian Matrix Multiple Right-Hand Side Solve

These subroutines solve the system AX = B for X, where X and B are general matrices and:

- For SPOTRS, DPOTRS, SPITRS, DPPITRS, SPOSM, and DPOSM, A is a positive definite real symmetric matrix.
- For CPOTRS, ZPOTRS, CPOSM, and ZPOSM, A is a positive definite complex Hermitian matrix.

SPOTRS, DPOTRS, CPOTRS, and ZPOTRS use the results of the factorization of matrix A, produced by a preceding call to SPOTRE, DPOTRE, CPOTRE, or ZPOTRE, respectively.

SPOSM, DPOSM, CPOSM, and ZPOSM use the results of the factorization of matrix A, produced by a preceding call to SPOF/SPOFCD, DPOF/DPOFCD, CPOF, or ZPOF, respectively.

SPITRS and DPPITRS use the results of the factorization of matrix A, produced by a preceding call to SPITRF or DPITRF, respectively.

### Table 101. Data Types

| A, B, X | Subroutine |
|---|---|
| Short-precision real | SPOTRS^⧄, SPOSM, and SPITRS^⧄ |
| Long-precision real | DPOTRS^⧄, DPOSM, and DPPITRS^⧄ |
| Short-precision complex | CPOTRS^⧄ and CPOSM |
| Long-precision complex | ZPOTRS^⧄ and ZPOSM |

^⧄LAPACK

**Note:** The input to these solve subroutines must be the output from the corresponding factorization subroutines.

### Syntax

Fortran
```
CALL SPOTRS | DPOTRS | CPOTRS | ZPOTRS (uplo, n, nrhs, a, lda, bx, ldb, info)
CALL SPOSM | DPOSM | CPOSM | ZPOSM (uplo, a, lda, n, bx, ldb, nrhs)
CALL SPITRS | DPPITRS (uplo, n, nrhs, ap, bx, ldb, info)
```

C and C++
```
spotrs | dpotrs | cspotrs | zspotrs (uplo, n, nrhs, a, lda, bx, ldb, info);
sposm | dpdsm | cpdsm | zpdsm (uplo, a, lda, n, bx, ldb, nrhs);
spptrs | dpdtrs (uplo, n, nrhs, ap, bx, ldb, info);
```

### On Entry:

*uplo* indicates whether the original matrix A is stored in upper or lower storage mode, where:

- If *uplo* = 'U', A is stored in upper storage mode.
- If *uplo* = 'L', A is stored in lower storage mode.

SPOTRS, DPOTRS, CPOTRS, ZPOTRS, SPOSM, DPOSM, CPOSM, ZPOSM, SPITRS, and DPPTRS

*Specified as*: a single character. It must be ' U' or 'L'.

***a_*** is the factorization of positive definite matrix **A**, produced by a preceding call to SPOTRE, DPOTRE, CPOTRE, ZPOTRE, SPOF/SPOFCD, DPOF/DPOFCD, CPOF, or ZPOF.

*Specified as*: an *lda* by (at least) *n* array, containing numbers of the data type indicated in Table 101 on page 488.

***ap_*** is an array, referred to as *AP*, in which the factorization of positive definite real symmetric matrix **A**, produced by a preceding call to SPPT RF or DPPT RF, is stored in upper-packed or lower-packed storage mode.

*Specified as*: a one-dimensional array, containing numbers of the data type indicated in Table 101 on page 488.

***lda_*** is the leading dimension of the array specified for *a*.

*Specified as*: a fullword integer; *lda* > 0 and *lda* > *n*.

***n_*** is the order of matrix **A** and the number of rows of matrix **B**.

*Specified as*: a fullword integer; *n* > 0, *n* < *lda*, and *n* < *ldb*.

***bx_*** is the general matrix **B**, containing the *nrhs* right-hand sides of the system. The right-hand sides, each of length *n*, reside in the columns of **B**.

*Specified as*: an *ldb* by (at least) *nrhs* array, containing numbers of the data type indicated in Table 101 on page 488.

***ldb_*** is the leading dimension of the array specified for *b*.

*Specified as*: a fullword integer; *ldb* > 0 and *ldb* > *n*.

***nrhs_*** is the number of right-hand sides; that is, the number of columns of matrix **B**.

*Specified as*: a fullword integer; *nrhs* > 0.

***info_*** See "On Return." 

### **On Return:**

***bx_*** is the general matrix **X**, containing the *nrhs* solutions to the system. The solutions, each of length *n*, reside in the columns of **X**.

*Returned as*: an *ldb* by (at least) *nrhs* array, containing numbers of the data type indicated in Table 101 on page 488.

***info_*** *info* has the following meaning:

If *info* = 0, the solve completed successfully.

### **Notes**

- 1. In your C program, argument *info* must be passed by reference.
- 2. All subroutines accept lowercase letters for the *uplo* argument.
- 3. The scalar data specified for input arguments *uplo*, *lda*, and *n* for these subroutines must be the same as the corresponding input arguments specified for SPOTRF/SPOF/SPOFCD/SPOTRE, DPOTRF/DPOF/DPOFCD/DPTRE, CPOTRF/CPOF, and ZPOTRF/ZPOE, respectively.
- 4. The array data specified for input argument *a* for these subroutines must be the same as the corresponding output arguments for SPOTF/SPOF/SPOFCD, DPOTF/DPOF/DPOFCD, CPOTF/CPOF, and ZPOTF/ZPOF, respectively.
