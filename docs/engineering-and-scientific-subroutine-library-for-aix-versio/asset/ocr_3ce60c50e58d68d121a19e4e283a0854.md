# STRMV, DTRMV, CTRMV, ZTRMV, STPMV, DTPMV, CTPMV, and ZTPMV

# Example 2

This example shows the computation $\mathbf{x} * A^{T} * \mathbf{x}$. Matrix $A$ is a real 4 by 4 upper triangular matrix that is unit triangular, stored in upper-triangular storage mode. Vector $\mathbf{x}$ is a vector of length 4. Matrix $A$ is:

![](bbox=[0.4, 0.15, 0.65, 0.22])

Note: Because matrix $A$ is unit triangular, the diagonal elements are not referenced. ESSL assumes a value of 1.0 for the diagonal elements.

# Call Statement and Input:

```
      UPLO TRANSA DIAG    N   A   LDA X   INDX
         |    |     |     |   |   |   |    |
CALL STRMV( 'U', 'T', 'U', 4, A, 4, X, 1 )
```

![](bbox=[0.28, 0.37, 0.5, 0.44])

$\mathbf{X} = (5.0, 4.0, 3.0, 2.0)$

# Output:

$\mathbf{X} = (5.0, 14.0, 26.0, 41.0)$

# Example 3

This example shows the computation $\mathbf{x} * A^{H} * \mathbf{x}$. Matrix $A$ is a complex 4 by 4 upper triangular matrix that is unit triangular, stored in upper-triangular storage mode. Vector $\mathbf{x}$ is a vector of length 4. Matrix $A$ is:

![](bbox=[0.4, 0.62, 0.75, 0.68])

Note: Because matrix $A$ is unit triangular, the diagonal elements are not referenced. ESSL assumes a value of (1.0, 0.0) for the diagonal elements.

# Call Statement and Input:

```
      UPLO TRANSA DIAG    N   A   LDA X   INDX
         |    |     |     |   |   |   |    |
CALL CTRMV( 'U', 'C', 'U', 4, A, 4, X, 1 )
```

![](bbox=[0.28, 0.82, 0.65, 0.89])

$\mathbf{X} = ((5.0, 5.0), (4.0, 4.0), (3.0, 3.0), (2.0, 2.0))$

# Output:

$\mathbf{X} = ((5.0, 5.0), (24.0, 4.0), (49.0, 3.0), (80.0, 2.0))$
