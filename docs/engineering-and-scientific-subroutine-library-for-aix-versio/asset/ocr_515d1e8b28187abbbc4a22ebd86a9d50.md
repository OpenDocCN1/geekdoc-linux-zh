# **Notes**

+   1. *aux1* should **not** be used by the calling program between calls to this subroutine with *init* ≠ 0 and *init* = 0. However, it can be reused after intervening calls to this subroutine with different arguments.

+   2. When using the ESSL SMP library, for optimal performance, the number of threads specified should be the same for *init* ≠ 0 and *init* = 0.

+   3. If you specify the same array for X and Y, then *inc1x* and *inc1y* must be equal, and *inc2x* and *inc2y* must be equal. In this case, output overwrites input.

+   4. If you specify different arrays for X and Y, they must have no common elements; otherwise, results are unpredictable. See "Concepts" on page 55.

+   5. If *iy0* and *ny* are such that output outside the basic range is needed, the subroutine stores zeros. These ranges are: 0 ≤ k ≤ Ny+Nh−2 for SCONF and 1−Nh ≤ k ≤ Ny−1 for SCORF.

# **Formulas for the length of the Fourier Transform**

Before calculating the necessary sizes of *aux1* and *aux2*, you must determine the length *n* of the Fourier transform. The value of *n* is based on *nf*. You can use one of two techniques to determine *nf*:

+   - Use the simple overestimate of nf = nx+nh−1. (If iy0 = 0 and ny > nh+nx, this is the actual value, not an overestimate.)

+   - Use the values of the arguments iy0, nh, nx, and ny inserted into the following formulas to get a value for the variable nf:

```
iyp = max(iy0, 0)  
    ix0 = max((iyp+1)−nh, 0)  
    i10 = max((iyp+1)−nx, 0)  
    nd = ix0+i10  
    n1 = iyo+ny  
    nxx = min(n1, nx−ix0)  
    nh1 = min(n1, nh−i10)  
    ntt = nxx+nh1−1  
    nn1 = n1−nd  
    iyl0 = iyp−nd  
    n1left = max(0, nh1−iyl0−1)  
    nzr1 = min(nn1, ntt)−nxx  
    nf = max(12, nxx+max(n1left, nzr1))
```
