# SCOPY, DCOPY, CCOPY, and ZCOPY—Copy a Vector

These subroutines copy vector $\mathbf{x}$ to another vector $\mathbf{y}$:

**Table 46. Data Types**
| x, y | Subprogram |
| :--- | :--- |
| Short-precision real | SCOPY |
| Long-precision real | DCOPY |
| Short-precision complex | CCOPY |
| Long-precision complex | ZCOPY |

# Syntax

| Fortran | CALL SCOPY $\mid$ DCOPY $\mid$ CCOPY $\mid$ ZCOPY ($n$, $x$, $incx$, $y$, $incy$) |
| :--- | :--- |
| C and C++ | scopy $\mid$ dcopy $\mid$ ccopy $\mid$ zcopy ($n$, $x$, $incx$, $y$, $incy$); |

**On Entry:**

- $n$ is the number of elements in vectors $\mathbf{x}$ and $\mathbf{y}$.
- Specified as: a fullword integer; $n \geq 0$.
- $\mathbf{x}$ is the vector $\mathbf{x}$ of length $n$. Specified as: a one-dimensional array of of (at least) length $1+(n-1) \mid incx \mid$, containing numbers of the data type indicated in Table 46.
- $incx$ is the stride for vector $\mathbf{x}$.
- Specified as: a fullword integer. It can have any value.
- $\mathbf{y}$ See “On Return.”
- $incy$ is the stride for vector $\mathbf{y}$. Specified as: a fullword integer. It can have any value.

**On Return:**

- $\mathbf{y}$ is the vector $\mathbf{y}$ of length $n$. Returned as: a one-dimensional array of of (at least) length $1+(n-1) \mid incy \mid$, containing numbers of the data type indicated in Table 46.

**Notes**

1. If you specify the same vector for $\mathbf{x}$ and $\mathbf{y}$, $incx$ and $incy$ must be equal; otherwise, results are unpredictable.
2. If you specify different vectors for $\mathbf{x}$ and $\mathbf{y}$, they must have no common elements; otherwise, results are unpredictable. See “Concepts” on page 55.
