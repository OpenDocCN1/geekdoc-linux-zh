# **Example 3**

This example shows a polynomial evaluation, using a stride $INCX$ of 0 for input vector $x$.

**Call Statement and Input:**

```
U INCU K X INCX Y INCY N
|
|
|
|
|
|
|
CALL SPOLY( U , 1 , 3 , X , 0 , Y , 1 , 3 )

U = (4.0, 3.0, 2.0, 1.0)
X = (2.0, . . .)
```

**Output:**
Y = (26.0, 26.0, 26.0)

U INCU K X INCX Y INCY N
|
|
|
|
|
|
|
CALL SPOLY( U , 1 , 3 , X , 2 , Y , -2 , 3 )
