# SGELLS and DGE LLS

# Example 2

This example solves the overdetermined system $AX=B$. On output, $A$ and $B$ are overwritten. $DUMMY$ is used as a placeholder for argument $rn$, which is not used in the computation.

Call Statement and Input:

```
```
              I OPT  A  LDA  B  LDB  X  LDX  RN  TAU  M  N  NB  K  AUX  NAUX
                   |  |     |  |    |  |     |  |    |  |  |  |   |  |
               CALL DGELLS( 0,  A, 3 , B, 3 , X, 2, DUMMY, TAU, 3, 2 , 2 ,  K,  AUX,  7  )
```
```

```
```
     A    =
              [ 1.0  4.0  ]
              [ 2.0  5.0  ]
              [ 3.0  6.0  ]

     B    =
              [  7.0  10.0  ]
              [  8.0  11.0  ]
              [  9.0  12.0  ]

     TAU  =   0.0
```
```

Output:

```
```
     X    =
              [ -1.000  -2.000  ]
              [  2.000   3.000  ]

     K    =   2
```
```

# Example 3

This example solves the overdetermined system $AX=B$ and computes the Euclidean Norms of the residual vectors. On output, $A$ and $B$ are overwritten.

Call Statement and Input:

```
```
              I OPT  A  LDA  B  LDB  X  LDX  RN  TAU  M  N  NB  K  AUX  NAUX
                   |  |     |  |    |  |     |  |    |  |  |  |   |  |
               CALL DGELLS( 1,  A, 3 , B, 3 , X, 2,  RN , TAU, 3, 2 , 2 ,  K,  AUX,  7  )
```
```

```
```
     A    =
              [  1.1  -4.3  ]
              [  2.0  -5.0  ]
              [  3.0  -6.0  ]

     B    =
              [ -7.0  10.0  ]
              [ -8.0  11.0  ]
              [ -9.0  12.0  ]

     TAU  =   0.0
```
```

Output:

```
```
     X    =
              [  0.543  -1.360  ]
              [  1.785  -2.699  ]
```
```
