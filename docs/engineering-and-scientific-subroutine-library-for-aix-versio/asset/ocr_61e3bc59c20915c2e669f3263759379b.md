AP(2n-1) = $a_{n2}$

AP(2n) = $a_{33}$ (start the third column and so forth)

AP(2n+1) = $a_{43}$

AP(n(n+1)/2) = $a_{nn}$

Following is an example of how to transform your symmetric matrix to lower-packed storage mode:

```
K = 0  
DO 1 J=1,N  
DO 2 I=J,N  
K = K+1  
AP(K)=A(I,J)  
2 CONTINUE  
1 CONTINUE
```

**Upper-Packed Storage Mode:** When a symmetric matrix is stored in upper-packed storage mode, the upper triangular part of the symmetric matrix is stored, including the diagonal, in a one-dimensional array. The upper triangle is packed by columns. (This is equivalent to packing the lower triangle by rows.) The matrix is packed sequentially column by column by $n(n+1)/2$ elements of a one-dimensional array. To calculate the location of each element $a_{ij}$ of matrix A in an array AP using the upper triangular packed technique, use the following formula:

$AP(+(j(j-1))/2)) = a_{ij} \quad \text{where } j \geq i$
