

## SSPR、DSPR、CHPR、ZHPR、SSYR、DSYR、CHER、ZHER、SSLR1 和 DSLR1

指定为：全字整数；$n \geq 0$。

$\alpha$ 是缩放常数 $\alpha$。

指定为：数据类型如第 312 页表 69 中所示的数值。

$\mathbf{x}$ 是长度为 $n$ 的向量 $\mathbf{x}$。

指定为：一维数组，长度（至少）为 $1 + (n-1) \times incx$，包含数据类型如第 312 页表 69 中所示的数值。

$incx$ 是向量 $\mathbf{x}$ 的步长。

指定为：全字整数，其中：

- 对于 SSPR、DSPR、CHPR、ZHPR、SSYR、DSYR、CHER 和 ZHER，$incx < 0$ 或 $incx > 0$。
- 对于 SSLR1 和 DSLR1，$incx$ 可以取任意值。

$ap$ 具有以下含义：

- 对于 SSPR 和 DSPR，$ap$ 是阶数为 $n$ 的实对称矩阵 $\mathbf{A}$，存储在上或下打包存储模式中。
- 对于 CHPR 和 ZHPR，$ap$ 是阶数为 $n$ 的复埃尔米特矩阵 $\mathbf{A}$，存储在上或下打包存储模式中。
- 对于 SSLR1 和 DSLR1，$ap$ 是阶数为 $n$ 的实对称矩阵 $\mathbf{A}$，存储在下打包存储模式中。

指定为：一维数组，长度（至少）为 $n(n+1)/2$，包含数据类型如第 312 页表 69 中所示的数值。

$a$ 具有以下含义：

- 对于 SSYR 和 DSYR，$a$ 是阶数为 $n$ 的实对称矩阵 $\mathbf{A}$，存储在上或下存储模式中。
- 对于 CHER 和 ZHER，$a$ 是阶数为 $n$ 的复埃尔米特矩阵 $\mathbf{A}$，存储在上或下存储模式中。
- 指定为：$lda$ 乘（至少）$n$ 的数组，包含数据类型如第 312 页表 69 中所示的数值。

$lda$ 是为 $a$ 指定的数组的前导维度。

指定为：全字整数；$lda > 0$ 且 $lda \geq n$。

### 返回

$ap$ 是阶数为 $n$ 的矩阵 $\mathbf{A}$，包含计算结果。返回为：一维数组，包含数据类型如第 312 页表 69 中所示的数值。

$a$ 是阶数为 $n$ 的矩阵 $\mathbf{A}$，包含计算结果。返回为：二维数组，包含数据类型如第 312 页表 69 中所示的数值。

### 注释

- 所有子程序都接受小写字母作为 $uplo$ 参数。
- 向量 $\mathbf{x}$ 必须与矩阵 $\mathbf{A}$ 没有公共元素；否则，结果不可预测。请参阅第 55 页的“概念”。
- 在输入时，复埃尔米特矩阵 $\mathbf{A}$ 的对角线元素的虚部假设为零，因此您不需要设置这些值。在输出时，如果 $\alpha \neq 0.0$，它们被设置为零。
- 关于对称矩阵如何存储在上或下打包存储模式以及上或下存储模式中的描述，请参阅第 64 页的“对称矩阵”。关于复埃尔米特矩阵如何存储在上或下打包存储模式以及上或下存储模式中的描述，请参阅第 69 页的“复埃尔米特矩阵”。

### 功能

这些子程序执行下面两个部分中描述的运算。参见参考文献 [36]、[37] 和 [81]。如果 *n* 或 *a* 为 0，则不执行任何计算。

对于 CHPR 和 CHER，中间结果以长精度累加。对于 SSPR、SSYR 和 SSLR1，在某些平台上中间结果以长精度累加。

- **对于 SSPR、DSPR、SSYR、DSYR、SSLR1 和 DSLR1：** 这些子程序计算实对称矩阵的秩一更新：$A \gets A + \alpha xx^T$，其中：
    - $A$ 是阶数为 $n$ 的实对称矩阵。
    - $\alpha$ 是一个标量。
    - $x$ 是长度为 $n$ 的向量。
    - $x^T$ 是向量 $x$ 的转置。

    其表达式如下：

    ![](img/5b0f44f3be6048723819b26aed7f6f03_337_0.png)

- **对于 CHPR、ZHPR、CHER 和 ZHER：** 这些子程序计算复埃尔米特矩阵的秩一更新：$A \gets A + \alpha xx^{H}$，其中：
    - $A$ 是阶数为 $n$ 的复埃尔米特矩阵。
    - $\alpha$ 是一个标量。
    - $x$ 是长度为 $n$ 的向量。
    - $x^{H}$ 是向量 $x$ 的共轭转置。

### 错误条件

**计算错误：** 无

**输入参数错误：**

- $uplo \ne$ 'L' 或 'U'
- $n < 0$
- $incx = 0$
- $lda \leq 0$
- $lda < n$

### 示例 1

此示例展示了一个具有正步长的向量 $\mathbf{x}$ 和一个阶数为 3 的实对称矩阵 $A$，存储在下打包存储模式中。矩阵 $A$ 为：

![](img/5b0f44f3be6048723819b26aed7f6f03_338_0.png)

**调用语句和输入：**

```
          UPLO      N       ALPHA X       INCX    AP
                 |       |       |       |       |
CALL SSPR( 'L' , 3 , 1.0 , X , 1 , AP )

X             = (3.0, 2.0, 1.0)
AP            = (8.0, 4.0, 2.0, 6.0, 7.0, 3.0)
```

**输出：**

```
AP            = (17.0, 10.0, 5.0, 10.0, 9.0, 4.0)
```

### 示例 2

此示例展示了一个具有负步长的向量 $\mathbf{x}$ 和一个阶数为 3 的实对称矩阵 $A$，存储在上打包存储模式中。它使用与示例 1 相同的输入矩阵 $A$。

**调用语句和输入：**

```
          UPLO      N       ALPHA X       INCX    AP
                 |       |       |       |       |
CALL SSPR( 'U' , 3 , 1.0 , X , -2 , AP )

X             = (1.0, . , 2.0, . , 3.0)
AP            = (8.0, 4.0, 6.0, 2.0, 7.0, 3.0)
```

**输出：**

```
AP            = (17.0, 10.0, 10.0, 5.0, 9.0, 4.0)
```

### 示例 3

此示例展示了一个具有正步长的向量 $\mathbf{x}$ 和一个阶数为 3 的复埃尔米特矩阵 $A$，存储在下打包存储模式中。矩阵 $A$ 为：

![](img/5b0f44f3be6048723819b26aed7f6f03_338_1.png)

> **注意：** 在输入时，复埃尔米特矩阵 $A$ 的对角线元素的虚部假设为零，因此您不需要设置这些值。在输出时，如果 $\alpha \ne 0.0$，它们被设置为零。

**调用语句和输入：**

```
UPLO    N      ALPHA    X      INCX     AP
   |     |      |      |      |       |
CALL CHPR( 'L', 3, 1.0, X, 1, AP )

X      = ((1.0, 2.0), (4.0, 0.0), (3.0, 4.0))

         (4.0, 8.0), (6.0,  . ))
```

**输出：**

```
AP     = ((6.0, 0.0), (7.0, -13.0), (13.0, 1.0), (23.0, 0.0),
         (16.0, 24.0), (31.0, 0.0))
```

### 示例 4

此示例展示了一个具有负步长的向量 *x* 和一个阶数为 3 的复埃尔米特矩阵 *A*，存储在上打包存储模式中。它使用与示例 3 相同的输入矩阵 *A*。

**注意：** 在输入时，复埃尔米特矩阵 *A* 的对角线元素的虚部假设为零，因此您不需要设置这些值。在输出时，如果 *α* ≠ 0.0，它们被设置为零。

**调用语句和输入：**

```
UPLO    N      ALPHA    X      INCX     AP
   |     |      |      |      |       |
CALL CHPR( 'U', 3, 1.0, X, -2, AP )

X      = ((3.0, 4.0), . , (4.0, 0.0), . , (1.0, 2.0))
AP     = ((1.0,  . ), (3.0, 5.0), (7.0,  . ), (2.0, -3.0),
         (4.0, -8.0), (6.0,  . ))
```

**输出：**

```
AP     = ((6.0, 0.0), (7.0, 13.0), (23.0, 0.0), (13.0, -1.0),
         (16.0, -24.0), (31.0, 0.0))
```

### 示例 5

此示例展示了一个具有正步长的向量 *x* 和一个阶数为 3 的实对称矩阵 *A*，存储在下存储模式中。它使用与示例 1 相同的输入矩阵 *A*。

**调用语句和输入：**

```

   |     |      |      |      |       |      |

X      = (3.0, 2.0, 1.0)

A      = [ 8.0  .    .  ]
         [ 4.0  6.0  .  ]
         [ 2.0  7.0  3.0]
```

**输出：**

```
A      = [ 17.0  .    .   ]
         [ 10.0 10.0  .   ]
         [ 5.0  9.0  4.0 ]
```
