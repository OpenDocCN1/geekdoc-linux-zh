# SURXOR and DURXOR—Generate a Vector of Long Period Uniformly Distributed Random Numbers

These subroutines generate a vector x of uniform [0,1) pseudo-random numbers, using thetausworthe exclusive-or algorithm.

Table 177. Data Types

| x, vseed | iseed | Subroutine |
|---|---|---|
| Short-precision real | Integer | SURXOR |
| Long-precision real | Integer | DURXOR |

# Syntax

| | |
|---|---|
| Fortran | CALL SURXOR \| DURXOR (iseed, n, x, vseed) |
| C and C++ | surxor \| durxor (iseed, n, x, vseed); |

**On Entry:**

*   `iseed` has the following meaning, where:
    *   If iseed ≠ 0, iseed is the initial value used to generate the random numbers. You specify iseed ≠ 0 when you call this subroutine for the first time or when you changed iseed between calls to this subroutine.
    *   If iseed = 0, vseed is used to generate the random numbers, where vseed was initialized by an earlier call to this subroutine. ESSL assumes you have not changed vseed between calls to this subroutine, when you specify iseed = 0.
    *   Specified as: a fullword integer, as indicated in Table 177.
*   `n` is the number of random numbers to be generated.
    *   Specified as: a fullword integer; n ≥ 0.
*   `x` See “On Return.”
*   `vseed` is the work area used by this subroutine and has the following meaning, where:
    *   If iseed ≠ 0, vseed is not used for input. The work area can contain anything.
    *   If iseed = 0, vseed contains the seed vector generated by a preceding call to this subroutine. vseed is used in this computation to generate the new random numbers. It should not be changed between calls to this subroutine.
    *   Specified as: a one-dimensional array of (at least) length 10000, containing numbers of the data type indicated in Table 177.

**On Return:**

*   `iseed` is set to 0 for subsequent calls to SURXOR or DURXOR. Returned as: a fullword integer, as indicated in Table 177.
*   `x` is a vector of length n, containing the uniform pseudo-random numbers with the following values: 0 ≤ x < 1. Returned as: a one-dimensional array of (at least) length n, containing numbers of the data type indicated in Table 177.
