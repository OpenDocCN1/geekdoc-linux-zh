6. $\mathit{l}da < n$

# Example 1

This example shows vectors $\mathit{x}$ and $\mathit{y}$ with positive strides and a real symmetric matrix $A$ of order 3, stored in lower-packed storage mode. Matrix $A$ is:

```
$$\left[ \begin{array}{c c c c} 8.0 & 4.0 & 2.0 \\ 4.0 & 6.0 & 7.0 \\ 2.0 & 7.0 & 3.0 \end{array} \right]$$
```

Call Statement and Input:

```

```
             UPLO N ALPHA X INCX Y INCY AP
                |   |   |   |  |   |   |
CALL SSPR2(  'L' , 3 , 1.0, X , 1 ,  Y , 2 , AP  )
X            =  (3.0, 2.0, 1.0)
Y            =  (5.0, . , 3.0, . , 2.0)
AP           =  (8.0, 4.0, 2.0, 6.0, 7.0, 3.0)
```

```

Output:

```
AP =  (38.0, 23.0, 13.0, 18.0, 14.0, 7.0)
```

```

```

                |   |   |   |   |   |   |
CALL CHPR2(  'L' , 3 , ALPHA , X , 1 , Y , 2 , AP  )
