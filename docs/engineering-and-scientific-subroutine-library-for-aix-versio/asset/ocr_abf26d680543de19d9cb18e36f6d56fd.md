# **SGETRI, DGETRI, CGETRI, ZGETRI, SGEICD, and DGEICD—General Matrix Inverse, Condition Number Reciprocal, and Determinant**

These subroutines find the inverse of general matrix *A*.

Subroutines **SGEICD** and **DGEICD** also find the reciprocal of the condition number and the determinant of general matrix *A*.

*Table 107. Data Types*

| **A**, **aux**, **rcond**, **det**, **work** | Subroutine |
|:----------------------------------|:---------------------------------------------|
| Short-precision real | SGETRI$^\wedge$ and SGEICD |
| Long-precision real | DGETRI$^\wedge$ and DGEICD |
| Short-precision complex | CGETRI$^\wedge$ |
| Long-precision complex | ZGETRI$^\wedge$ |
| $^\wedge$ LAPACK | |

**Note:** The input to **SGETRI**, **DGETRI**, **CGETRI**, and **ZGETRI** must be the output from the factorization subroutines **SGTRE**, **DGTTRE**, **CGTRE**, and **ZGTRE**, respectively.

If you call subroutines **SGEICD** and **DGEICD** with *iopt* = 4, the input must be the output from the factorization subroutines **SGEF**/**SGEFCD**/**SGTRE** or **DGEF**/**DGEFCD**/**DGTEF**/**DGTE**, respectively.

# **Syntax**

| Fortran | CALL **SGETRI** \| **DGETRI** \| **CGETRI** \| **ZGETRI** (*n, lda, ipvt, work, lwork, info*) |
| C and C++ | CALL **SGEICD** \| **DGEICD** (*a, lda, n, iopt, rcond, det, aux, naux*) |
| | **sgtri** \| **dgtri** \| **cgetri** \| **zgetri** (*n, lda, ipvt, work, lwork, info*); |
| | **sgiecd** \| **dgeicd** (*lda, n, iopt, rcond, det, aux, naux*); |

**On Entry:**

*a* has the following meaning, where:

**For subroutines SGETRI, DGETRI, CGETRI, and ZGETRI:**

It is the transformed matrix *A* of order *n*, resulting from the factorization performed in a previous call to **SGTRE**, **DGTTRE**, **CGTRE**, or **ZGTRE**, respectively, whose inverse is computed.

**For subroutines SGEICD and DGEICD:**

If *iopt* = 0, 1, 2, or 3, it is matrix *A* of order *n*, whose inverse, reciprocal of condition number, and determinant are computed.

If *iopt* = 4, it is the transformed matrix *A* of order *n*, resulting from the factorization performed in a previous call to **SGEF**/**SGEFCD** or **DGEF**/**DGEFCD**/**DGTE**, respectively, whose inverse is computed.

Specified as: an *lda* by (at least) *n* array, containing numbers of the data type indicated in Table 107.

*lda* is the leading dimension of the array specified for *a*.
