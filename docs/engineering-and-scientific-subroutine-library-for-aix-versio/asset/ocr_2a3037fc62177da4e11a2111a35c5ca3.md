# Notes

+   1.  **V**, **X**, **s**, and **U**<sup>T</sup>**B** can have no common elements; otherwise the results are unpredictable.
+   2.  In problems involving experimental data, τ should reflect the absolute accuracy of the matrix elements:
+       τ ≥ max(|Δ<sub>ij</sub>)
+       where Δ<sub>ij</sub> are the errors in *a*<sub>ij</sub>. In problems where the matrix elements are known exactly or are only affected by roundoff errors:
+       [τ ≥ ε (√*mn*)] max(s<sub>j</sub>) for j = (1, … , n)
+       where:
+       ε is equal to 0.11920E−06 for SGESVS and 0.22204D−15 for DGESVS.
+       **s** is a vector containing the singular values of matrix **A**.
+       For more information, see references [15], [60], [80], and pages 134 to 151 in reference [102].

# Function

The minimal norm linear least squares solution of AX=B, where **A** is a real general matrix, is computed using the singular value decomposition, produced by a preceding call to SGESVF or DGESVF. From SGESVF or DGESVF, the singular value decomposition of **A** is given by the following:

A = UΣV<sup>T</sup>

The linear least squares of solution **X**, for AX=B, is given by the following formula:

X = VΣ<sup>+</sup> U<sup>T</sup>B

where:

Σ<sup>+</sup> is the diagonal matrix with elements σ<sub>j</sub><sup>+</sup>, where:
σ<sub>j</sub><sup>+</sup> = 1.0 / σ<sub>j</sub> if σ<sub>j</sub> ≥ τ and σ<sub>j</sub> ≠ 0
σ<sub>j</sub><sup>+</sup> = 0 for all other cases
