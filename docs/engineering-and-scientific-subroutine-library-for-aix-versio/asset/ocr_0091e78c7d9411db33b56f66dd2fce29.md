# **Error Conditions**

Input-Argument Errors:  None

# **Example 1**

This example shows the construction of a real Givens plane rotation, where *r* is 0.

```
Call Statement and Input:

    A     B     C     S
    |     |     |     |
    |     |     |     |
    +--------------------------------+
    CALL SROTG( 0.0 , 0.0 , C , S )
```

```
Output:

A        =  0.0
B        =  0.0
C        =  1.0
S        =  0.0
```
