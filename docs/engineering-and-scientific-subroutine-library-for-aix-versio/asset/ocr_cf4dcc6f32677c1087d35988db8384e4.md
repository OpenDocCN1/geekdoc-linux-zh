# SNAXPY and DNAXPY—Compute SAXPY or DAXPY N Times

These subprograms compute SAXPY or DAXPY, respectively, $n$ times:
$y_{i} \leftarrow y_{i} + \alpha x_{i} \quad \text{for} \ i = 1, n$

where each $\alpha_{i}$ is a scalar value, contained in the vector $\boldsymbol{a}$, and each $\boldsymbol{x}_{i}$ and $\boldsymbol{y}_{i}$ are vectors, contained in vectors (or matrices) $\boldsymbol{x}$ and $\boldsymbol{y}$, respectively. For an explanation of the SAXPY and DAXPY computations, see “SAXPY, DAXPY, CAXPY, and ZAXPY—Multiply a Vector X by a Scalar, Add to a Vector Y, and Store in the Vector Y” on page 210.

Table 48. Data Types

| $\boldsymbol{a}, \boldsymbol{x}, \boldsymbol{y}$ | Subprogram |
| :--- | :--- |
| Short-precision real | SNAXPY |
| Long-precision real | DNAXPY |

# Syntax

| Fortran | CALL SNAXPY \| DNAXPY ($n$, $m$, $\mathbf{a}$, inca, $\mathbf{x}$, incx, incxo, $\mathbf{y}$, incy, incey) |
| :--- | :--- |
| C and C++ | snaxpy \| dnaxpy ($n$, $m$, $\mathbf{a}$, inca, $\mathbf{x}$, incx, incxo, $\mathbf{y}$, incy, incey); |

On Entry:

+   *   **$n$** is the number of SAXPY or DAXPY computations to be performed and the number of elements in vector $\boldsymbol{a}$. 
+       Specified as: a fullword integer; $n \geq 0$.
+   *   **$m$** is the number of elements in vectors $\boldsymbol{x}_{i}$ and $\boldsymbol{y}_{i}$ for each SAXPY or DAXPY computation. 
+       Specified as: a fullword integer; $m \geq 0$.
+   *   **$\boldsymbol{a}$** is the vector $\boldsymbol{a}$ of length $n$, containing the scalar values $\alpha_{i}$ used in each computation of $\boldsymbol{y}_{i}+\alpha \boldsymbol{x}_{i}$. 
+       Specified as: a one-dimensional array of (at least) length $1+(n-1)|$inca$|$, containing numbers of the data type indicated in Table 48.
+   *   **$\text{inca}$** is the stride for vector $\boldsymbol{a}$. 
+       Specified as: a fullword integer. It can have any value.
+   *   **$\boldsymbol{x}$** is the vector (or matrix) $\boldsymbol{x}$, containing the $\boldsymbol{x}_{i}$ vectors of length $m$, used in the $n$ computations of $\boldsymbol{y}_{i}+\alpha \boldsymbol{x}_{i}$. Specified as: a one- or two-dimensional array of (at least) length $(1+(n-1)|$incx$|)+(m-1)|$incxo$|$, containing numbers of the data type indicated in Table 48.
+   *   **$\text{incx}_{i}$** is the stride for $\boldsymbol{x}$ in the inner loop—that is, the stride identifying the elements in each vector $\boldsymbol{x}_{i}$. 
+       Specified as: a fullword integer. It can have any value.
+   *   **$\text{incx}_{o}$** is the stride for $\boldsymbol{x}$ in the outer loop—that is, the stride identifying each vector $\boldsymbol{x}_{i}$ in $\boldsymbol{x}$. 
+       Specified as: a fullword integer; $\text{incx}_{o} \geq 0$.
