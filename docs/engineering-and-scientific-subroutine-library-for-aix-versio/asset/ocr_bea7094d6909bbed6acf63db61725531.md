# SPOTRS, DPOTRS, CPOTRS, ZPOTRS, SPOSM, DPOSM, CPOSM, ZPOSM, SPITRS, and DPPITRS

# SPOTRS, DPOTRS, CPOTRS, ZPOTRS, SPOSM, DPOSM, CPOSM, ZPOSM, SPITRS, and DPPITRS —Positive Definite Real Symmetric or Complex Hermitian Matrix Multiple Right-Hand Side Solve

These subroutines solve the system AX = B for X, where X and B are general matrices and:

+   • For SPOTRS, DPOTRS, SPITRS, DPPITRS, SPOSM, and DPOSM, A is a positive definite real symmetric matrix.

+   • For CPOTRS, ZPOTRS, CPOSM, and ZPOSM, A is a positive definite complex Hermitian matrix.

SPOTRS, DPOTRS, CPOTRS, and ZPOTRS use the results of the factorization of matrix A, produced by a preceding call to SPOTRE, DPOTRE, CPOTRE, or ZPOTRE, respectively.

SPOSM, DPOSM, CPOSM, and ZPOSM use the results of the factorization of matrix A, produced by a preceding call to SPOF/SPOFCD, DPOF/DPOFCD, CPOF, or ZPOF, respectively.

SPITRS and DPPITRS use the results of the factorization of matrix A, produced by a preceding call to SPITRF or DPITRF, respectively.

# Table 101. Data Types

| A, B, X | Subroutine |
|---|---|
| Short-precision real | SPOTRS^⧄, SPOSM, and SPITRS^⧄ |
| Long-precision real | DPOTRS^⧄, DPOSM, and DPPITRS^⧄ |
| Short-precision complex | CPOTRS^⧄ and CPOSM |
| Long-precision complex | ZPOTRS^⧄ and ZPOSM |
^⧄LAPACK

**Note:** The input to these solve subroutines must be the output from the corresponding factorization subroutines.

# Syntax

```
Fortran
    CALL SPOTRS | DPOTRS | CPOTRS | ZPOTRS (uplo, n, nrhs, a, lda, bx, ldb, info)

    CALL SPOSM | DPOSM | CPOSM | ZPOSM (uplo, a, lda, n, bx, ldb, nrhs)

    CALL SPITRS | DPPITRS (uplo, n, nrhs, ap, bx, ldb, info)
```

```
C and C++
    spotrs | dpotrs | cspotrs | zspotrs (uplo, n, nrhs, a, lda, bx, ldb, info);

    sposm | dpdsm | cpdsm | zpdsm (uplo, a, lda, n, bx, ldb, nrhs);

    spptrs | dpdtrs (uplo, n, nrhs, ap, bx, ldb, info);
```

# On Entry:

*uplo* indicates whether the original matrix A is stored in upper or lower storage mode, where:

+   - If *uplo* = 'U', A is stored in upper storage mode.

+   - If *uplo* = 'L', A is stored in lower storage mode.
