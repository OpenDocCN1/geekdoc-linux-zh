On Return:

+   * *s* is the vector *s* of length *n*, containing the results of the *n* dot product computations. The type of dot product computation depends on the value specified for *isw*.
+     * If *isw* = 1,  *s_i*  *x_i* ** *y_i*
+     * If *isw* = 2,  *s_i* *-x_i* ** *y_i*
+     * If *isw* = 3,  *s_i* + *s_i* *x_i* ** *y_i*
+     * If *isw* = 4,  *s_i* + *s_i* - *x_i* ** *y_i*
+     where *i* = 1, *n*
+     Returned as: a one-dimensional array, containing numbers of the data type indicated in Table 49 on page 225.

Function
The four possible computations that can be performed by these subprograms are:

+   * *s_i* *x_i* ** *y_i*    Store positive dot product
+   * *s_i* *-x_i* ** *y_i*    Store negative dot product
+   * *s_i* + *s_i* *x_i* ** *y_i*    Accumulate positive dot product
+   * *s_i* + *s_i* - *x_i* ** *y_i*    Accumulate negative dot product
+   * for *i* = 1, *n*

where each *s_i* is a scalar element in the vector *s* of length *n*, and each of the *n* *x_i* and *y_i* vectors of length *m* are contained in vectors (or matrices) *x* and *y*, respectively. Each computation uses the dot product, which is expressed:
*x_i* ** *y_i* = *u_1v_1* + *u_2v_2* + ... + *u_mv_m*
