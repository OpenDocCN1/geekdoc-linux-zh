# **Example 4**

This example shows how to solve the system $AX = B$, where:
Matrix $A$ is the same used as input in “Example 4” on page 484 for CPOTFRE.
Matrix $BX$ is the same used as input in “Example 4” on page 492 for CPOTRS.

**Call Statement and Input:**

```
          UPLO N NRHS A LDA  BX  LDB   INFO
CALL CPOSV( 'U', 3 , 2 ,  A , 3 , BX , 3 , INFO)

 A  =    [ (9.0,  0.0) ( 3.0,  3.0) (  3.0, -3.0) ]
       [ (3.0, -3.0) (18.0,  0.0) ( 8.0, -6.0) ]
       [ (3.0,  3.0) ( 8.0,  6.0) (43.0,  0.0) ]

 BX =    [ ( 33.0, -18.0) (15.0,  -3.0) ]
       [ ( 45.0, -45.0) ( 8.0,  -2.0) ]
       [ (152.0,   1.0) (43.0, -29.0) ]
```
