# Sves, Dves, CVES, and ZVES

# SVES, DVES, CVES, and ZVES—Subtract a Vector Y from a Vector X and Store in a Vector Z

These subprograms perform the following computation, using vectors $x, y,$ and $z$:  
$$z\leftarrow x-y$$

**Table 57. Data Types**
| x, y, z | Subprogram |
| --- | --- |
| Short-precision real | SVES |
| Long-precision real | DVES |
| Short-precision complex | CVES |
| Long-precision complex | ZVES |


# Syntax

```
Fortran:

CALL SVES | DVES | CVES | ZVES (n, x, incx, y, incy, z, incz)

C and C++:

sves | dves | cves | zves (n, x, incx, y, incy, z, incz);
```

# On Entry:

+   1.  **n**  
+       is the number of elements in vectors $x, y,$ and $z$.  
+       Specified as: a fullword integer; $n \geq 0$.
+   2.  **x**  
+       is the vector $x$ of length $n$. Specified as: a one-dimensional array of (at least) length $1 + (n-1)|incx|$, containing numbers of the data type indicated in Table 57.
+   3.  **incx**  
+       is the stride for vector $x$.  
+       Specified as: a fullword integer. It can have any value.
+   4.  **y**  
+       is the vector $y$ of length $n$. Specified as: a one-dimensional array of (at least) length $1 + (n-1)|incy|$, containing numbers of the data type indicated in Table 57.
+   5.  **incy**  
+       is the stride for vector $y$.  
+       Specified as: a fullword integer. It can have any value.
+   6.  **z**  
+       See On Return.
+   7.  **incz**  
+       is the stride for vector $z$.  
+       Specified as: a fullword integer. It can have any value.

# On Return:

+   1.  **z**  
+       is the vector $z$ of length $n$, containing the result of the computation.  
+       Returned as: a one-dimensional array of (at least) length $1 + (n-1)|incz|$, containing numbers of the data type indicated in Table 57.

# Notes

+   1.  If you specify the same vector for $x$ and $z$, then $incx$ and $incz$ must be equal; otherwise, results are unpredictable. The same is true for $y$ and $z$.
+   2.  If you specify different vectors for $x$ and $z$, they must have no common elements; otherwise, results are unpredictable. The same is true for $y$ and $z$. See “Concepts” on page 55.
