# SCFT2 and DCFT2—Complex Fourier Transform in Two Dimensions

These subroutines compute the two-dimensional discrete Fourier transform of complex data.

Table 143. Data Types

| x, y | scale | Subroutine | 
|---|---|---| 
| Short-precision complex | Short-precision real | SCFT2 | 
| Long-precision complex | Long-precision real | DCFT2 |

Note: Two invocations of this subroutine are necessary: one to prepare the working storage for the subroutine, and the other to perform the computations.

# Syntax

| | | 
|---|---| 
| Fortran | CALL SCFT2 \| DCFT2 (init, x, incIx, inc2x, y, incly, inc2y, n1, n2, isign, scale, aux1, naux1, aux2, naux2) | 
| C and C++ | scf2 \| dcf2 (init, x, incIx, inc2x, y, incly, inc2y, n1, n2, isign, scale, aux1, naux1, aux2, naux2); |

# On Entry:

+   *   $init$ is a flag, where:

+       *   If $init \neq 0$, trigonometric functions and other parameters, depending on arguments other than $x$, are computed and saved in $aux1$. The contents of $x$ and $y$ are not used or changed.

+       *   If $init = 0$, the discrete Fourier transform of the given array is computed. The only arguments that may change after initialization are $x$, $y$, and $aux2$. All scalar arguments must be the same as when the subroutine was called for initialization with $init \neq 0$.

+   *   $x$ is the array $X$, containing the two-dimensional data to be transformed, where each element $X_{j1,j2}$, using zero-based indexing, is stored in $X(j1(incIx)+j2(inc2x))$ for $j1 = 0, 1, \dots, n1-1$ and $j2 = 0, 1, \dots, n2-1$.

Specified as: a fullword integer. It can have any value.

Specified as: an array of (at least) length $1+(n1-1)incIx+(n2-1)inc2x$, containing numbers of the data type indicated in Table 143. This array must be aligned on a doubleword boundary, and:

+       *   If $incIx = 1$, the input array is stored in normal form, and $inc2x \geq n1$.

+       *   If $inc2x = 1$, the input array is stored in transposed form, and $incIx \geq n2$.

See “Notes” on page 789 for more details.

+   *   $incIx$ is the stride between the elements in array $X$ for the first dimension.

+       *   If the array is stored in the normal form, $incIx = 1$.

+       *   If the array is stored in the transposed form, $incIx$ is the leading dimension of the array and $incIx \geq n2$.

Specified as: a fullword integer; $incIx > 0$. If $inc2x = 1$, then $incIx \geq n2$.

+   *   $inc2x$ is the stride between the elements in array $X$ for the second dimension.

+       *   If the array is stored in the transposed form, $inc2x = 1$.
