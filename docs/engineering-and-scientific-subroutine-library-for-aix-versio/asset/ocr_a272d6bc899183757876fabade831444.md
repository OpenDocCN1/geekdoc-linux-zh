# ## SACOR—Autocorrelation of One or More Sequences

This subroutine computes the autocorrelations of one or more sequences using a direct method. The input and output sequences contain short-precision real numbers.

**Note:** This subroutine is considered obsolete. It is provided in ESSL only for compatibility with earlier releases. You should use SCORD, SDCOR, SCORF and SACORF instead, because they provide **better performance**. For further details, see reference [4].

# ### Syntax

| Language | Syntax |
| :------- | :----- |
| **Fortran** | CALL SACOR (init, x, inc1x, inc2x, y, inc1y, inc2y, nx, m, ny, aux1, naux1, aux2, naux2) |
| **C and C++** | sacor (init, x, inc1x, inc2x, y, inc1y, inc2y, nx, m, ny, aux1, naux1, aux2, naux2); |

# #### On Entry:

+   1.  `init` \( * \) is a flag, where:
+       1.  If `init ≠ 0`, no computation is performed, error checking is performed, and the subroutine exits back to the calling program.
+       2.  If `init = 0`, the autocorrelations of the sequence in x are computed.
+       3.  Specified as: a fullword integer. It can have any value.
+   2.  `x` \( * \) is the array X, consisting of m input sequences of length N_x, to be autocorrelated. Specified as: an array of (at least) length 1+(N_{x}-1)inc1x+(m-1)inc2x, containing short-precision real numbers.
+   3.  `inc1x` is the stride between the elements within each sequence in array X.
+       1.  Specified as: a fullword integer; inc1x > 0.
+   4.  `inc2x` is the stride between the first elements of the sequences in array X.
+       1.  Specified as: a fullword integer; inc2x > 0.
+   5.  `y` \( * \) See "On Return" on page 849.
+   6.  `inc1y` is the stride between the elements within each sequence in output array Y.
+       1.  Specified as: a fullword integer; inc1y > 0.
+   7.  `inc2y` is the stride between the first elements of each sequence in output array Y.
+       1.  Specified as: a fullword integer; inc2y > 0.
+   8.  `nx` is the number of elements, N_x, in each sequence in array X.
+       1.  Specified as: a fullword integer; N_x > 0.
+   9.  `m` is the number of sequences in array X to be correlated.
+       1.  Specified as: a fullword integer; m > 0.
+   10. `ny` is the number of elements, N_y, in each sequence in array Y.
+       1.  Specified as: a fullword integer; N_y > 0.
+   11. `aux1` is no longer used in the computation, but must still be specified as a dummy argument (for migration purposes from Version 1 of ESSL). It can have any value.
