# **ESSL for Linux—Installation and Customization Products**

The ESSL for Linux licensed program is distributed on a CD. The *ESSL for Linux Installation Guide* provides the detailed information you need to install ESSL for Linux.

The ESSL for Linux product is packaged as RPM packages. The product can be installed using the **rpm** command, as described at the following URL:
`http://www.rpm.org/`
