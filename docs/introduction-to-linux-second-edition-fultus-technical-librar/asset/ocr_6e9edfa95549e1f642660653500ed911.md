# ### 2.5.2 Passwords

Log in again with your user name and password.

+   - Change your password into $PpP3,aa!$ and hit the **Enter** key.
+       -> What happens?
+   - Try again, this time enter a password that is ridiculously easy, like 123 or aaa.
+       -> What happens?
+   - Try again, this time don't enter a password but just hit the **Enter** key.
+       -> What happens?
+   - Try the command **psswd** instead of **passwd**
+       -> What happens?

# **New password**

Unless you change your password back again to what it was before this exercise, it will be "PpP3,aa!". Change your password after this exercise!

Note that some systems might not allow you to recycle passwords, i.e. restore the original one within a certain amount of time or a certain amount of password changes, or both.
