Fortunately, HTML was designed as a cross-platform tool. Unfortunately, HTML editors—especially flashy WYSIWYG editors and word processors—often produce HTML that’s not very portable. Such documents may include errors (misordered tags, say) that cause some browsers to misbehave. Other problems occur because of a design that makes too many assumptions about the browser’s configuration.
