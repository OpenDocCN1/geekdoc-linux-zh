# ## Creating a Firewall Script

To create a proxy-filter firewall, you must run the proxy filter tool, feeding it a configuration file, or create a script that calls the tool multiple times with options to add various specific rules. This section describes this process, beginning with preliminaries such as kernel options and deciding what types of policies you want to implement, and moving on to creating the rules and configuring your system to use them automatically.
