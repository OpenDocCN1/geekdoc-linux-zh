# Command-Line Audio Playback and Recording Tools

One of the most basic tasks of audio handling is the ability to record and play back sound files. Among the most basic tools to perform this task is p1ay, which plays back or records a sound file, depending upon how it’s called. (A symbolic link called rec is used to record; the program knows which name you used to call it, and adjusts its actions accordingly.) A syntax for this command is

```
play [options] filename [effect]
```
