
**ICMP** *Internet Control Message Protocol*（互联网控制消息协议）是一种在 TCP/IP 网络上的计算机之间发送非常简单的控制和错误数据包的方法。

**inode** 在 FFS 及其他一些文件系统中使用的磁盘结构。Inode 与文件相关联，每个文件对应一个 inode。目录项指向 inode，而 inode 包含文件的大小、文件在磁盘上的存储位置等信息。

**internet/Internet** 当未大写时，指任何由路由器连接的网络网络，通常是多个网络的互联。(2) 当首字母大写时，指那个在全球范围内迅速扩展并在 1990 年代迅速发展的网络，它使个人能够全球发送电子邮件、阅读世界各地的网页等。

**interpreter** 一种按行解释*源代码*文件的程序。解释器运行程序较慢，但解释型语言使用简单，因为它们不需要编译过程。*脚本*是用解释型语言编写的程序。

**IP address** TCP/IP 网络上计算机的 4 字节（32 位）地址。IP 地址通常表示为四个由点分隔的十进制数，例如 172.19.65.11。

**IRC** *Internet Relay Chat*（互联网中继聊天）是一种用于多人群组间实时通信的协议。它用于娱乐以及在计算机问题解决中获取或提供帮助。

**ISA bus** 一种将调制解调器和声卡等附加卡连接到主板的硬件标准。ISA 总线正在变得罕见，因为它在很大程度上已被*PCI 总线*取代。

**KDE** *K Desktop Environment*（K 桌面环境），是 FreeBSD 上流行的桌面环境。另见*GNOME*。

**Kerberos** 一种网络认证和安全协议。Kerberos 允许用户在会话中只需输入一次密码，即可在网络上任何支持 Kerberos 的服务器上使用该服务。其网页为 http://web.mit.edu/kerberos/www/ 。

**kernel** 操作系统的核心软件组件。内核控制硬件访问、磁盘文件系统、内存访问等。

**kernel mode** 描述作为内核一部分运行的进程的术语。此类进程对硬件和其他内核模式进程拥有特权访问权限，因此如果包含漏洞，可能会具有潜在的危险。另见*user mode*。

**LAN** *local area network*（局域网）是覆盖小物理区域的网络，如办公室、单栋建筑或小型建筑群。局域网可以相互连接，也可以连接到整个互联网。

**LBA mode** 线性（或*Logical*）块寻址是一种对硬盘进行寻址的模式，它使用单个线性数字来唯一标识数据扇区（通常为 512 字节）。SCSI 磁盘一直使用 LBA 模式，现代 EIDE 磁盘也支持此模式。该系统与用于旧磁盘和某些低级磁盘数据结构中的*CHS 几何*寻址形成对比。

**link** 指向与另一个文件相关联的文件的目录项。链接有两种类型：*hard links*（硬链接）和*symbolic links*（符号链接，也称为*soft links*（软链接））。

**load average** 衡量 CPU 使用情况的指标。负载平均值 1.0 代表对 CPU 100% 时间的需求。更高的负载平均值表明有比 CPU 能服务的更多程序的需求，因此大多数进程必须使用比最优值更少的 CPU 时间。

**log file** 服务器和其他系统进程记录其活动信息以供将来参考的文件。大多数 FreeBSD 日志文件位于 `/var/log` 目录中，`/var/log/messages` 是最常被访问的日志文件。

**machine code** 另见*machine language*。

**machine language** 计算机理解的底层代码。机器语言对大多数人来说，包括大多数计算机程序员，看起来都像胡言乱语。

**machine name** *hostname*（主机名）中唯一标识域内（另见*domain name*（域名））计算机的部分。

**mail relay** 接受来自一个系统的邮件并将其投递到另一个系统的计算机。如果配置过于宽松，邮件中继被称为*open mail relay*（开放邮件中继），这可能被滥用于投递*spam*（垃圾邮件）。

**MBR** *Master Boot Record*（主引导记录），是 x86 硬盘上的第一个扇区。MBR 包括引导加载器代码和主分区表。

**memory leak** 导致程序请求其不需要的内存的漏洞，通常反复发生。严重的内存泄漏会导致计算机的可用内存减少，直到整个计算机出现问题。

**MIME** *Multipurpose Internet Mail Extension*（多用途互联网邮件扩展）是一种用于标识文件类型的代码——例如，AbiWord 文档或特定的音频文件类型。MIME 类型用于编码特定类型的邮件附件、网页检索和文件浏览器。

**mount point** 用作文件系统（定义 2）接口的目录。文件系统中的文件和目录可以像存在于挂载点目录内一样被访问。

**netmask** 另见*network mask*。

**network mask** 指定 IP 地址中代表网络部分和代表网络上机器部分的数字。也称为*netmask*（网络掩码）。

**network stack** 一组允许计算机在网络上相互通信的协议。2002 年最常见的网络堆栈是 TCP/IP。

**NIC** *A network interface card*（网卡）插入计算机中以添加网络接口（通常是*Ethernet*（以太网）接口）。

**office suite** 执行常见办公计算任务的程序集合。办公套件通常包括以下程序类别中的至少三种或更多：文字处理器、电子表格、数据库、演示文稿和商业图形。

**open mail relay** 配置为允许任何计算机中继邮件，或者至少允许比应该允许的多得多的计算机中继邮件的*mail relay*（邮件中继）。

**open source** 一种软件开发和分发理念，要求发布源代码、自由修改和重新分发该代码以及其他各种想法。FreeBSD 是 2002 年主要的开源操作系统之一。

**outline font** 另见*scalable font*。

**packet filter** 一种*firewall*（防火墙），对单个 TCP/IP 数据包进行操作。此类防火墙基于源和目标 IP 地址、端口号、接口和类似的低级标准来允许或拒绝流量。

**packet sniffer** 一种监控并可选记录低层网络流量（数据包）的程序。数据包嗅探器可以是有用的网络诊断工具，也可以是黑客用来窃取密码或其他敏感数据的武器。

**pager** 一种一次显示一屏文本文件的程序类型。FreeBSD 中两个常见的分页器是*more*和*less*。

**PAM** *The Pluggable Authentication Module*（可插拔认证模块）是 FreeBSD 上处理用户名和密码的系统。不是让每个程序直接读取 `/etc/passwd` 来验证用户密码是否有效，而是程序调用 PAM 工具，以标准化的方式完成工作。

**parent** 在 FreeBSD 进程的上下文中，*parent*（父进程）是一个相对术语，指启动该被讨论进程的进程。每个进程恰好有一个父进程。另见*child*（子进程）。

**partition** 硬盘上独立于其他区域访问的区域。分区通常容纳文件系统，但也可能容纳其他分区或交换空间。(2) 用作动词时，指创建分区的操作。

**partition table** 描述硬盘上分区布局的数据结构。在 x86 世界中，主分区表是 MBR 的一部分，但扩展分区和 FreeBSD 切片有关联的补充分区信息。

**PCI bus** 一种将 SCSI 主机适配器和网络卡等附加卡连接到主板的硬件标准。PCI 总线在 2002 年非常流行。另见 ISA 总线和 AGP 总线。

**PID** Process ID（进程 ID）。这是唯一标识单个进程的数字。某些管理命令在 PID 上操作。

**piping** 将程序在虚拟链中连接起来；每个程序运行，处理链中前一个程序的输出，并将输出发送到链中的下一个程序。另见*redirection*（重定向）。

**playlist** 你希望在一个会话中播放的音频文件或音频 CD 音轨列表。播放列表通常由 MP3 播放器和 CD 播放器维护。

**port** 程序从一个操作系统到另一个操作系统的移植。(2) 在网络中，由网络堆栈创建的资源，支持网络功能的程序连接到该资源以独立于其他程序发送或接收数据。

**ports system** 提供有关获取和编译各种 FreeBSD 程序信息的文件集合。ports 系统为 FreeBSD 的许多程序提供半自动化安装功能。

**PostScript** Adobe 开发的页面描述语言。PostScript 常用于高端打印机（特别是激光打印机、打样机等）。它是 UNIX（因此也是 FreeBSD）程序的*de facto*（事实上的）打印命令语言。另见*Ghostscript*。

**preemptive multitasking** 一种多任务处理方法，其中操作系统控制每个程序获得的 CPU 时间。该系统与*cooperative multitasking*（协作式多任务处理）形成对比。

**print queue** 等待打印文件的虚拟暂存区域。

**process** 正在运行的程序。另见*PID*。

**proxy server** 一种*firewall*（防火墙），使用部分处理请求的服务器，生成针对原始目标的新请求，并将返回的数据传递给原始客户端。代理服务器可以缓存或修改数据，从而导致速度提升以及过滤数据的能力，例如从网站中移除广告或成人内容。
