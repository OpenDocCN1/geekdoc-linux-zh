
**公钥加密** 一种数据编码方法，其中一个参与者向任何人公开密钥。该密钥可用于加密数据，而这些数据只能由接收方的“私钥”解密；或者用于解密用私钥加密的数据。

**拉取协议** 客户端获取消息或文档的协议。此术语常用于指代如 POP 或 IMAP 等电子邮件协议。

**推送协议** 客户端发送消息或文档的协议。此术语常用于指代如 SMTP 等电子邮件协议。

**重定向** 将程序的输出发送到文件或通过另一个程序，或将文件内容或另一个程序的输出作为输入发送到程序。通常用于让程序协同工作。

**解析** 将主机名转换为 IP 地址，或反之，例如“www.threeromco.com 解析到什么地址？”。

**root** 与系统管理员关联的用户名。（实际上，此人也应拥有一个非 root 账户。）

**路由器** 从接收一个网络的网络流量并将其转发到另一个网络的计算机。

**Samba** 使用 *SMB/CIFS* 协议的文件和打印服务器，这些协议最常用于 Windows 的文件和打印共享。Samba 允许 FreeBSD 系统作为 Windows 系统的文件或打印服务器运行。

**可缩放字体** 一种用数学术语描述的字体，每个字母被定义为一组线条和曲线。这些描述可以缩放，以便在任何分辨率的设备上以任意大小正常显示，因此与更简单的位图字体技术相比，它们相当灵活。

**脚本** 一种用不需要编译的计算机语言编写的程序类型。与编译后的程序相比，脚本通常比较简单，并且通常用于配置或将多个编译后的程序组合成一个更灵活的整体。

**脚本小子** 相对缺乏技能的破坏者，几乎完全依赖他人编写的入侵工具包（*脚本*）工作。有些人倾向于将 *cracker* 一词保留给技能高于脚本小子所展示技能的个人。

**SCSI** *小型计算机系统接口*，一种将硬盘和类似设备连接到计算机的硬件标准。与竞争的 *ATA* 标准相比，它普及度较低，价格更高，但功能更强大。

**服务器** 响应网络数据传输请求的程序。示例包括 Web 服务器、邮件服务器和文件服务器。（2）主要目的是运行一个或多个服务器程序的计算机。

**Shell** 接受用户命令的程序。通常用于指文本型程序，您可以在其中输入程序文件名以启动这些程序等。许多 FreeBSD shell 包含脚本功能，以帮助您自动化常规或繁琐的任务。

**shell 脚本** 用 shell 语言（如 *sh*、*bash* 或 *csh*）编写的脚本。shell 脚本通常用作系统启动脚本，并执行各种管理任务。另见 *script*。

**信号** 一种可以发送给进程以影响其运行方式的代码。一些常见的信号类型用于终止无法以其他方式终止的进程。

**slice** FreeBSD 的主要 x86 分区。

**SMB/CIFS** *服务器消息块*（又称 *通用互联网文件系统*）协议，由 Windows 系统用于文件和打印共享。参见 *Samba*。

**社会工程学** 一种对计算机的攻击，其中个人被欺骗从而泄露敏感信息，如密码。

**软链接** 参见 *symbolic link*（符号链接）。

**源代码** 由计算机程序员编写且最容易由其修改的计算机程序形式。源代码文件必须要么由计算机使用*解释器*程序直接处理，要么转换为*二进制*格式并直接运行。

**垃圾邮件** 未经请求的大批量电子邮件。

**stage n 引导加载器** FreeBSD 使用三阶段引导加载器过程。第一阶段驻留在硬盘的主引导记录（MBR）中，允许您选择要启动的操作系统。第二阶段和第三阶段驻留在 FreeBSD slice 中，允许您输入内核参数或启动 FreeBSD。

**星型拓扑** 一种网络拓扑，所有计算机都连接到一个中心点（*集线器*或*交换机*）。现代 100 Mbps 以太网使用星型拓扑。

**粘滞位** 一种特殊的权限位，通常用于共享用户目录，如 */tmp*。此位表示只有文件的拥有者才能删除目录中的文件。

**超级服务器** 一个监听指向其他多个服务器连接，并在连接出现时启动相应服务器的服务器。超级服务器可以通过对所有处理的服务器应用统一的安全检查来提供一定程度的额外安全性，并且在某些情况下可以减少内存消耗。标准的 FreeBSD 超级服务器称为 `inetd`。

**超级用户** 参见 *system administrator*（系统管理员）。

**交换空间** FreeBSD 视为 RAM 扩展的磁盘空间。交换空间使计算机能够运行比正常情况下更多的程序，但速度比拥有等量额外 RAM 时更慢。

**交换机** 连接多台计算机的网络设备。*集线器*与*交换机*的区别在于，交换机试图仅将数据从源回显给收件人，而不是其他连接的计算机。这一特性有助于提高性能。

**符号链接** 一种*链接*类型，其中链接指向另一个文件的目录项。这些链接可以跨越不同的*分区*，因此访问速度略慢于*硬链接*。

**系统管理** 涉及操作系统整体或其运行硬件的安装或维护的操作。典型的系统管理任务包括添加、更新或删除程序；添加或删除用户账户；以及更改服务器选项。

**系统管理员** 负责配置计算机的个人，包括添加或删除程序、创建用户账户等。也称为*超级用户*，系统管理员使用 *root* 账户。

**标签** 嵌入在文件或数据结构中以携带特殊含义的代码。例如，*HTML* 文件中的标签指示链接、粗体文本、标题等的开始和结束位置。

**tarball** 一个 `tar` 文件，通常用 `gzip` 压缩。Tarball 的文件名以 `.tar.gz` 或 `.tgz` 结尾。

**TCP** *传输控制协议* 是一种网络协议类型，是常见的 *TCP/IP 协议栈* 的主要组成部分。TCP 数据包将数据封装在较大的数据传输中。大多数常见的互联网协议，如 *SMTP*、*HTTP*、*Telnet* 和 *FTP*，都使用 TCP 数据包。

**TCP/IP 协议栈** *传输控制协议/互联网协议栈* 是 2002 年最流行的网络协议集。使用 TCP/IP 协议栈的两台计算机可以通过网络相互通信，前提是他们拥有兼容的高级程序（如 *Telnet* 服务器和 *Telnet* 客户端）。

**终端程序** 一种允许计算机模拟*哑终端*的程序。常用作通过串行端口或调制解调器访问 UNIX 或 FreeBSD 系统的最低公分母方法。

**特洛伊木马** 一种广告宣传做一件事，但实际上执行恶意行为（作为替代或附加声称功能）的程序。特洛伊木马是恶霸用于获取他人计算机访问权限的几种方法之一。

**UDP** *用户数据报协议* 是在 *TCP/IP* 网络上交换数据的一种方式。UDP 数据包比 *ICMP* 数据包更复杂，但比 *TCP* 数据包更简单。它们被一些简单的 *TCP/IP* 协议（如 *DNS* 和 *DHCP*）以及少数更复杂的协议（如 *NFS*）使用。

**UID** *用户 ID* 是标识特定账户的数字。我们作为人类使用的用户名与 UID 关联。

**USB** *通用串行总线*，一种将调制解调器、鼠标、键盘、打印机、扫描仪和其他低速外部设备连接到计算机的硬件标准。FreeBSD 包含有限的 USB 支持，其范围和品质正在改进中。

**用户模式** 描述在*内核模式*之外运行的进程术语。此类进程由*内核*管理；它们依赖*内核*访问内存、硬件和其他资源。

**矢量图形** 一种用线条、曲线和其他形状描述图像的方法。与*位图图形*不同，矢量图形能够良好地缩放到任何分辨率的输出设备。

**虚拟控制台** 使用单个控制台独立维护的控制台会话。在 FreeBSD 中，您可以按功能键（F1 到 F8；如果运行 X，请同时按 ALT）在不同的虚拟控制台会话之间切换。此功能允许您运行多个程序并轻松地在它们之间切换。

**虚拟桌面** 由窗口管理器或*桌面环境*操作的一个或多个*显示*中的其中一个，每个都可以托管自己的窗口集。您可以通过点击按钮或从菜单中选择选项在不同的虚拟桌面之间切换。当您处理许多基于 X 的程序时，虚拟桌面有助于减少杂乱。

**VNC** *虚拟网络计算* 是一个客户端/服务器包，允许远程访问运行 XFree86、Windows、Mac OS 或其他环境的计算机的 *GUI*。

**X 窗口系统** FreeBSD 的 *GUI* 环境，通常被称为 *X*。

**僵尸** 一台已被入侵以执行*DDoS 攻击*的计算机。（2）FreeBSD 系统中未被正确关闭的进程。
