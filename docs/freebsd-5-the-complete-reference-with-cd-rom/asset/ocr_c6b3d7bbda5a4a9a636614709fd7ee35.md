# # User-Level X Options

The previous section, “Reconfiguring X,” was concerned with global X configuration—features you’re likely to set as a system administrator to handle the overall X features. Other X options can be set on a user-by-user basis, though, and this section describes these features. Two major user-configurable changes are picking a window manager and picking a desktop environment. Two more detail-oriented changes are setting the mouse tracking speed and the keyboard repeat rate. All of these are settings that fall squarely in the category of user preferences—users are likely to have very different (and often very strong) preferences concerning these features. As a system administrator, you can set global defaults for all of these items, but individual users may want to override these global defaults.
