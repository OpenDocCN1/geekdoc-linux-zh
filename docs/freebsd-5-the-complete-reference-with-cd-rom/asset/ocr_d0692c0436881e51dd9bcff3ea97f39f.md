# FTP in Action: Transferring Files

Actually transferring files with FTP involves establishing a connection, locating the files, issuing transfer commands, and then breaking the connection. The exact details differ between programs, but the basic steps remain the same with most programs. This section describes using ftp and gFTP to download a binary file (sample.tgz) from and upload a text file (report.txt) to a fictitious FTP site (ftp.threerooco.com).
