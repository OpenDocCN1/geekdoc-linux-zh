+   * **Signature** An email *signature* is a short element at the end of a message that you can use to list your e-mail address, home page, employer, or other information. Keep your signature under 4–6 lines at most.

+   * **Outgoing mail server** Many FreeBSD mail programs (especially text-based programs) default to using `sendmail` running on the local computer for handling outgoing mail. Others, including many GUI programs, require you to explicitly specify an outgoing mail server. This may be `localhost` if you’re running a mail server that can handle the job, as described in Chapter 19; or it can be a mail server on another computer.
