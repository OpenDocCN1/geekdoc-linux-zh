# ### Pros and Cons of Compiled and Interpreted Code

The main difference between compiled and interpreted languages is one of where CPU time is invested. In a compiled program, the compiler spends considerable CPU time creating a binary file, which the CPU can then execute. With the compiler and coding practices are efficient, the CPU can run the program very efficiently. With an interpreted language, by contrast, no CPU time is spent compiling the program, but the interpreter spends considerable time handling each line of the program file. Thus, the program executes more slowly than does a compiled program.
