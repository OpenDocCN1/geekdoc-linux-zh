In broad terms, the PDF-only viewers work much like the PostScript viewers, but some details differ. The most important of these is that Acrobat Reader can display some PDF files that Xpdf and the Ghostscript-based viewers can't handle. These problem files are often created by the latest versions of Adobe's Acrobat Distiller program, which creates PDF files. PDF files created with Ghostscript seldom pose problems for any PDF viewer. Some advanced PDF options, such as tables of contents and some types of embedded elements, also don't display properly (if at all) in anything but Acrobat Reader. For these reasons, if you need to read PDF files very often, and especially if these files come from many sources, you may need to install the acroread4 package and the Linux compatibility libraries upon which it relies.
