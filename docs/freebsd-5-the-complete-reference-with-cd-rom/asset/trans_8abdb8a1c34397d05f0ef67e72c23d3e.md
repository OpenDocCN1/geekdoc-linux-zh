
## 术语表

- **位图字体** 一种字体文件格式，将字体中的每个字符描述为位图。位图显示时占用的 CPU 资源较少，但缩放效果不佳，因此为了支持多种尺寸或具有不同分辨率的输出设备，每个字体家族需要许多字体文件。

- **引导加载程序** 一个指导引导过程的程序。某些引导加载程序允许启动多台计算机，或者可以将引导过程引导至*次要引导加载程序*，由后者进一步指导引导过程。

- **广播** 在计算机网络中，一种定向发送至网络段内所有计算机的流量类型。计算机使用*广播*来帮助定位其他计算机，某些协议（如*DHCP*）在正常运行时也使用*广播*。

- **BSD** *伯克利软件发行版*（Berkeley Software Distribution）是原始 AT&T UNIX 补丁包的名称，后来也成为一种独立的完整操作系统，FreeBSD 即由此衍生而来。*BSD* 这一缩略语也应用于 BSD 操作系统中的各种特性，例如其启动脚本系统和许可证。

- **BSD 许可证** FreeBSD 的大部分代码依据此软件许可证进行分发。该许可证允许修改后的代码在 BSD 许可证或任何其他许可证下进行分发。另见*开源*和*GPL*。

- **总线拓扑结构** 一种网络配置类型，其中一台计算机连接到另一台，该计算机又连接到另一台，依此类推，形成计算机的逻辑“线路”。早期的细同轴电缆和粗同轴电缆以太网硬件使用的就是总线拓扑结构。

- **子进程** 在 FreeBSD 进程的语境下，*子进程*是一个相对术语，指由另一个程序启动的程序。一个程序可以有多个子进程。另见*父进程*。

- **CHS 几何结构** *柱面/磁头/扇区几何结构*是用于唯一标识硬盘上数据扇区（通常为 512 字节）的三个数值组成的三元组。*EIDE* 磁盘和 x86 分区数据结构使用 CHS 几何结构。在现代硬盘中，这些数值仅仅是方便使用的虚构概念；它们与真实的硬盘几何结构没有相似之处。此系统与*LBA 模式*形成对比。

- **CIFS** *通用互联网文件系统*（Common Internet File System）。参见 SMB/CIFS。

- **客户端** 一个发起网络数据传输请求的程序。示例包括 FTP 客户端、邮件阅读器和网络浏览器。（2）一台运行网络客户端程序但几乎没有或不运行网络服务器程序的计算机。

- **编译器** 将*源代码*转换为计算机可用的*二进制*（定义 3）表示形式的程序。

- **控制台** 连接到计算机的键盘、显示器以及可能的鼠标。通常情况下，这个词指的是直接连接到计算机的一组用户输入/输出设备，相对于远程终端而言。

- **协作式多任务处理** 一种多任务处理方法，每个进程使用 CPU 时间，直到它不再需要为止。然后，该程序将计算机的控制权移交给其他进程。这与 FreeBSD 使用的*抢先式多任务处理*方法相比更简单。

- **破解者** 入侵或以其他方式干扰计算机运行的人。破解者的动机可能多种多样，包括好奇心、贪婪或报复。大众媒体通常将破解者称为*黑客*，但该术语的含义更为模糊。另见*脚本小子*。

- **CSS** *内容加扰系统*（Content Scrambling System）是一种用于商用视频 DVD 的数据加密方法。

- **守护进程** 一个在后台运行以提供必要服务的程序。大多数服务器程序都以守护进程方式运行。

- **数据结构** 定义数据在文件或内存中如何排列（结构化）以服务于特定目的的定义。通常可以设计多种数据结构来解决相同的问题，但必须编写程序来理解它们所要使用的任何数据结构。

- **DDoS 攻击** *分布式拒绝服务攻击*是拒绝服务攻击的一种类型，攻击者使用多台计算机（可能本身就是被入侵的系统）来攻击另一台计算机。

- **默认路由** 指定如何处理那些在计算机路由表中没有定义更明确路由的网络流量的说明。通常，默认路由指向本地网络的*路由器*。

- **设备文件** 一种特殊类型的文件，为用户提供访问计算机硬件的用户模式程序接口。这些文件传统上位于 */dev* 目录中。

- **DHCP** *动态主机配置协议*使服务器能够向 DHCP 客户端提供 TCP/IP 配置信息，从而简化客户端计算机上的 TCP/IP 配置。

- **域名** 一个标识互联网某部分的名称，通常由单个组织或个人拥有或运营。另见*主机名*和*机器名*。

- **DoS 攻击** *拒绝服务攻击*是一种旨在剥夺受害者使用其计算机或其网络连接能力的计算机化攻击类型。

- **点文件** 文件名以点（.）开头的程序。除非使用显示点文件的选项（如 `ls` 命令的 `-a` 选项），否则这些文件不会出现在通过 `ls` 或许多其他工具创建的文件列表中。许多用户配置文件都是点文件，以防止它们杂乱普通的目录列表。

- **哑终端** 通过串行端口或类似方式连接到计算机的键盘和显示器。在 20 世纪 70 年代和 80 年代，哑终端是访问 UNIX 系统的常见方法，FreeBSD 仍然支持其使用。另见*终端程序*。

- **EIDE** *增强型集成驱动电子*（Enhanced Integrated Drive Electronics）标准。参见 *ATA*。

- **环境变量** 一种可被任何程序读取的设置。常用于设置搜索可执行程序的目录路径，或设置特定程序使用的全球选项。

- **以太网** 一种常见的局域网硬件类型，根据类型不同，其最高速度范围从 10 Mbps 到 1 Gbps 不等。

- **漏洞利用** 在安全语境中作为名词使用时，这个词指破解者用于入侵计算机的特定 bug 或攻击方法，例如“破解者使用了一个著名的漏洞利用来入侵 ISP 的 web 服务器。”

- **文件系统** 存储在分区或硬盘上的一组低级数据结构，使操作系统能够在磁盘上存储数据。（2）由文件和子目录组成的目录结构。

- **防火墙** 根据 IP 地址、数据包类型或其他标准限制传入和/或传出网络访问的计算机、程序或配置。另见*数据包过滤器*和*代理服务器*。

- **字体** 特定风格下的一组字符（通常为字母表、数字和标点符号）。

- **字体平滑** 参见*抗锯齿*。

- **FQDN** *完全限定域名*是包含其域名的完整主机名，例如 `www.whitehouse.gov`。

- **网关** 参见*路由器*。

- **Ghostscript** 一个将*PostScript* 转换为各种其他图形文件格式的程序，包括许多常见打印机使用的格式。Ghostscript 通常作为 FreeBSD *打印队列* 的一部分由过滤器调用。

- **GID** *组 ID* 是一个标识用户组的数字。组名称与 GID 相关联。

- **GNOME** *GNU 网络对象模型环境*，FreeBSD 的一个流行桌面环境。另见 *KDE*。

- **GPL** *GNU 通用公共许可证* 是随 FreeBSD 一起分发的某些软件使用的软件许可证。GPL 要求衍生作品也必须根据 GPL 进行分发。另见 *BSD 许可证* 和 *开源*。

- **组** 一组账户的集合。每个账户至少属于一个组。组可用于为一组用户提供对某些文件的访问权限，同时排除其他用户。

- **黑客** 一个精通并享受使用计算机，特别是计算机编程的人，并使用这些技能为生产性目的服务。许多创建 FreeBSD 的个人在这个意义上都是黑客。（2）*破解者*。这种用法在大众媒体中很常见，但在开源社区的大多数成员中并不受欢迎，早在大众媒体重新定义该术语之前，他们就已经在使用 *hacker* 的第一个含义。

- **硬链接** 一种*链接*类型，其中两个文件的目录项指向单个* inode*。从某种意义上说，没有哪个文件链接到另一个文件；它们都直接指向同一个文件。

- **哈希** 一种只能单向运算的*加密*类型。哈希常用于存储密码，因为从哈希值解密密码在理论上是可能的。（在实践中，通过加密随机或目标可能的密码并将其与哈希值进行比较，有时可以得出密码。）

- **主机名** 分配给计算机的字母数字名称。在 TCP/IP 中，主机名由两部分组成：*机器名*和*域名*。

- **HTML** *超文本标记语言*是一种为要在支持 HTML 的程序中显示的纯文本文件提供格式化的方法。HTML 最常用于网页的文件格式。

- **HTTP** *超文本传输协议*是 web 浏览器和 web 服务器用于交付 web 页面的协议。

- **集线器** 一种将多台计算机连接在一起的网络设备。集线器与*交换机*的区别在于，集线器将数据包回显到所有连接的设备，而交换机仅将数据发送到目标设备。如果两个设备同时通过集线器发送数据，这种设计会导致“冲突”，两个数据包会相互损坏。结果是，当发送方必须暂停并重试发送时，性能会下降。
