When you first create an Impress document, the program presents a series of dialog boxes asking you for information such as whether you want to create a new presentation or edit an existing one, what format the presentation will take (overhead slides, on-screen display, and so on), and what type of effect you want to accompany transitions from one slide to another (which is meaningful for on-screen presentations only). Once you've answered these questions, you'll see the main Impress window (Figure 25-7) and, in front of it, the Modify Slide dialog box (Figure 25-8). You select the type of slide you want to create in this dialog box. When you click OK, you'll see the elements appear in the main Impress window: You can then double-click an object to edit it or insert the object type. You can then edit the object as you would its original type. For instance, if you tell Impress to insert a spreadsheet, you can edit the spreadsheet cells as described earlier, in "Performing Computations." You can cut-and-paste from another document or import another document.
