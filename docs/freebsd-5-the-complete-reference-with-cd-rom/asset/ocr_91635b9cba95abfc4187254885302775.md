In addition to TCP and UDP, there are other TCP/IP protocols, such as the Internet Control Message Protocol (ICMP). These don't have assignments in /etc/services, and most don't use port numbers *per se*. ICMP, for instance, is used for low-level network stack messages. There are different types of ICMP messages, but there's no need to create port numbers because few programs use this packet type. (The ping utility described in Chapter 14 is one exception.)

Some of the transactions described here may also involve several back-and-forth data transfers, although this fact may not be apparent to the end user.
