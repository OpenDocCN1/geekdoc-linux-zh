+   1. If necessary, install the `cvsup-without-gui` package, using either package tools or the ports system itself. +   2. Type `cd /usr/ports/net/cvsup4it`.
+   3. Type `make; make install`. This command installs and configures some updating software and runs an updater (Figure 11-3).
+   4. Select the version of FreeBSD you’re running from the list. This action produces the Source Selection Menu.
