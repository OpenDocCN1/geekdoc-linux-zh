# Using ftp

Because `ftp` is a ubiquitous program, this section describes an FTP transfer using this program. To perform the specified transfer, follow these steps:

+   Enter the directory in which you want to store the downloaded file (`sample.tgz`).

+   Type `ftp.threeroomco.com`. This command initiates a connection with the FTP server.

+   The remote server prompts for a username. Type your username on the remote server, or `anonymous` if you're performing an anonymous transfer.

+   The remote server prompts for a password. Type your password, or your e-mail address if you're performing an anonymous transfer.

+   Use `cd` to change into the directory in which `sample.tgz` resides. For instance, you might type `cd tarballs/samples`. If you don't know the exact directory, you may need to hunt for it by using `ls` to locate promising-sounding directories. Some sites provide files called `index`, `00index`, or something similar. These files contain information on all the files on the FTP site, so you can retrieve and study these files to locate the ones in which you're interested.

+   Type `binary` to be sure `ftp` is set for binary file transfers.

+   Type `get sample.tgz` to retrieve the file. You should see progress information appear, followed by a summary of transfer information, such as the transfer speed and file size.

+   Use `cd` to change into the directory on the server in which you want to store `report.txt`. For instance, you might type `cd ~/uploads`.

+   Use `lcd` to change into the local directory in which `report.txt` is stored. For instance, you might type `lcd ~/reports`.

+   Type `ascii` to tell the system you want to perform end-of-line or other necessary conversions for text-only data.

+   Type `put report.txt` to transfer the file. As with the download, you should see a progress bar. This step will not work with most anonymous sites or if you don't have write permissions in the target directory on the server.

+   Type `quit` to close the connection and exit from the `ftp` program.
