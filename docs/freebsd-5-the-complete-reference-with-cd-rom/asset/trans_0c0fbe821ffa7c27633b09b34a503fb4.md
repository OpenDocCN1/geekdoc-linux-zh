如果在超出其设计允许范围（分辨率或刷新率更高）的条件下运行，较旧的监视器可能会受损。因此，在输入监视器信息时必须非常谨慎。不要选择支持比您已知监视器能力更高分辨率或刷新率的监视器类型。幸运的是，大多数自 20 世纪 90 年代后期制造的监视器都会忽略超出范围的信号，因此不会因此受损，但如果您尝试使用此类设置，您将看不到显示画面（或者会出现一条提示，表明监视器无法处理该信号）。

-   **Screen**（屏幕）在 X 配置术语中，屏幕是指针对特定显卡和监视器的一组具体设置。您将视频模式（如 800x600 或 1280x1024）设置为屏幕。在 x86cfg 显示界面的顶部附近，有一个名为 Configure Layout（配置布局）的条（参见图 2-12）。点击它并选择 Configure Screen（配置屏幕）。此时会出现一个大型监视器图形；右键点击它并选择 Configure（配置）。然后，您可以在右侧列表中添加或删除分辨率和颜色深度；列表中的这些项是 X 将尝试使用的分辨率。从实际角度来看，800x600 是 X 的最小可用显示尺寸，因为许多程序假设显示至少为此大小。如果您的监视器能支持，1024x768 是更佳的尺寸。当然，如果您的硬件能轻松支持更大尺寸，更大的显示效果会更好。

您可以按自己的意愿在各个选项之间来回切换，因此可以按方便的顺序完成设置。完成后，点击屏幕底部的 Quit（退出）按钮。然后，您可以选择返回继续配置，或者测试您的设置。当所有操作结束后，X 将退出。

## X 桌面配置

配置完 XFree86 后，xinstall 允许您配置 X 桌面环境。您有几种选择：

-   **KDE** KDE 桌面环境是 FreeBSD 上常见的两大集成桌面环境之一。不过，大多数 KDE 文件在一张 CD 的 FreeBSD 软件包中是缺失的，因此，除非您拥有多张 CD 的软件包或正在进行网络安装，否则您可能想放弃此选项。

-   **GNOME + Sawfish 和 GNOME + Enlightenment** GNU 网络对象模型环境（GNOME）是 FreeBSD 的第二个主要集成桌面环境。有两个可用的 GNOME 选项，它们的区别在于默认使用的窗口管理器——Sawfish 或 Enlightenment。（窗口管理器控制窗口定位、拖动条以及类似工具。）Sawfish 窗口管理器比 Enlightenment 更轻量，因此在低内存系统上或如果您希望获得稍快反应速度的桌面环境时，它是更好的选择。Enlightenment 在外观自定义选项方面更为丰富，因此，如果您喜欢大量的“视觉享受”（eye candy），这可能是一个不错的选择。

-   **Afterstep** Afterstep 是一个受旧版 NeXT 操作系统所使用窗口环境模型启发的窗口管理器。

-   **Windowmaker** 此窗口管理器借鉴了许多其他管理器的理念。它也是 GNUstep (http://gnustep.org) 的核心，后者旨在实现 NeXT 使用的 OpenStep 规范。FreeBSD 安装中提供的 Windowmaker 选项并不会安装完整的 GNUstep，但如果您喜欢，可以稍后再添加它。

-   **fvwm** fvwm 是最古老的传统窗口管理器之一，您可以将其作为 X 桌面的选项进行挑选。

最后三个选项是“极简”的窗口管理器。它们在运行时对内存要求极低，因此可能是精简系统的好选择。KDE 和 GNOME 都是庞大的环境，仅它们自身就会消耗数兆字节内存，但它们包含更完整的桌面环境，包括文件管理器、配置工具等。如果您或您的用户习惯使用 Windows 或 Mac OS 并希望获得类似功能，那么其中任何一个都是不错的选择。

需要注意的是，您在此处设置的是默认环境。您可以安装多个窗口管理器和桌面环境，唯一的限制是磁盘空间。用户随后可以配置他们的账户以启动任何已安装的窗口管理器或桌面环境，即使它与系统默认环境不同。此类选项在第 13 章中有详细描述。当然，要使用某个环境，首先必须安装它。您可以在安装系统的其余部分后，使用 sysinstall 来完成此操作。

另一个需要了解的重要点是，各种工具和实用程序，包括 GNOME 和 KDE 环境中自带的许多工具，都可以在任何环境中运行；例如，您并不局限于在 KDE 中仅运行 KDE 程序。尽管每个环境都收集了各种各样的程序，其中一些程序在与匹配环境的其他程序配合时效果最佳。例如，您可能可以为环境中的程序设置默认字体集，并且该环境的所有程序都会使用该字体集。为另一个环境编写的程序可能不会遵守这些字体设置。

您应该使用哪种环境？这完全是个人偏好问题。对于拥有大量 RAM（128MB 或更多）的新用户，GNOME 是一个良好的起点，但您可能更偏好 KDE。如果您的 RAM 较少或偏好更简约的环境，那么三个独立窗口管理器中的任何一个都应能很好地工作。最终，窗口管理器和桌面环境的选择主要取决于个人偏好。您可以随机选择一个；然后随着您对 FreeBSD 了解的深入，去探索其他选项。

## FreeBSD 软件包配置

配置完 X 环境后，sysinstall 允许您浏览 FreeBSD 软件包集合。有几种可用的类别，例如 afterstep 和 audio。每个类别都包含一些您可能想要安装的程序。如果您现在不想花时间浏览这些选项，也没关系；您稍后可以启动 sysinstall 来安装程序。不过，您现在可能希望浏览一下集合，特别是如果您知道某些特定程序是您想要安装的。

### 提示

有一类特别重要的程序是编辑器组。FreeBSD 默认仅安装少数几个非常基础的编辑器，例如 ee 和 vi。ee 编辑器是您在安装期间用于编辑少量配置文件（如 /etc/inetd.conf）的工具。vi 编辑器在某些用户中很流行，但对于新手来说使用起来非常奇怪。emacs 编辑器广受欢迎且功能极其强大，但它体积庞大，可能会让人望而生畏。较小的类 emacs 编辑器包括 uemacs、jed 和 pico。您可能需要考虑安装的两个基于 X 的编辑器是 gxedit 和 xedit。不过，并非所有这些编辑器都能在单张 CD 的安装中可用。

## 用户配置

安装额外的软件包后，FreeBSD 允许您设置初始用户账户。在详细描述这是如何操作之前，我先简要说明 FreeBSD 为何使用账户以及您可能希望如何配置它们。

### 用户账户的作用

较旧的 x86 PC 操作系统，如 DOS 和 Windows 9x/Me，主要被设计为单用户操作系统。其假设是只有一个人通过键盘和监视器使用计算机，或者可能是少数彼此熟悉且互相信任的人共享计算机。任何用户都可以轻松地查看或修改计算机上的任何文件，包括属于其他个人的个人数据文件（如果多人使用计算机）或系统文件，如字体、驱动文件、程序文件等。
