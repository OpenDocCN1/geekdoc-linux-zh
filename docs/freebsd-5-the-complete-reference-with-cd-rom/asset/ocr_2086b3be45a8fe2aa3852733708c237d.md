# **Preventing and Correcting Problems**

Preventing and correcting memory problems consists of three main actions:

+   ■ **Installing enough RAM** If a system has insufficient RAM for its duties, you'll see memory-related slowdowns or even program crashes. Most x86 computers available today accept hundreds of megabytes, if not gigabytes, of physical memory, and memory has been coming down in price for decades, so adding more memory is seldom a serious problem

+   ■ **Configuring enough swap space** Insufficient swap space is likely to cause problems when RAM is also inadequate or when a system experiences an unusual spike in memory demand. Prevention involves configuring the computer with enough swap space, as described in the next section, “Adding Swap Space.”

+   ■ **Reducing memory demand** If you can't add RAM or swap space to a computer, you can head off some problems by reducing the demand for memory. One potentially big step is to use a slim desktop environment rather than a large one such as KDE or GNOME. (Chapter 23 describes these environments in detail.) Other notorious memory hogs include the Mozilla web browser and the OpenOffice.org office suite. On a server, shutting down X can help reduce the memory load.

# **Adding Swap Space**

If you didn't create enough swap space when you installed FreeBSD, or if your memory needs have gone up, you may want to add more swap space. Two practical ways to do this are to add a swap partition or add a swap file.
