# CHAPTER 5 Designing Experiments

#  5.4.4 PHORONIX RESOURCES

Table 5.2 Schema of user-config.xml (Larabel, 2012)

| PhoronixTestSuite Options | | |
|---|---|-|
| OpenBenchmarking AnonymousUsageReporting | bool | Enable anonymous reporting of usage, as test installations and durations |
| AnonymousSoftwareReporting | bool | Enable anonymous reporting of software configuration |
| AnonymousHardwareReporting | bool | Enable anonymous reporting of hardware configuration |
| IndexCacheTTL | int | The number of days to consider cached data from OpenBenchmarking.valid |
| AlwaysUploadSystemLogs | bool | Upload system logs without prompting |
| General DefaultBrowser | str | The default web browser used for displaying results |
| UsePodeviCache | bool | Enable the Podevi smart cache for caching hardware and software configurations |
| DefaultDisplayName | str | Controls command-line text brevity [DEFAULT, CONCISE] |
| Modules LoadModules | str | Comma-separated list of modules to load |
| Installation RemoveDownloadFiles | bool | Conserve disk by deleting downloaded files after installation. Will break tests that rely on downloaded files at runtime |
| SearchMediaForCache | bool | Search for a download cache on removable media (under /media) |
| SymLinkFilesFromCache | bool | Conserve disk space by using symbolic links into the download-cache to avoid duplicates |
| PromptForDownloadMirror | bool | If FALSE, a mirror is selected at random
