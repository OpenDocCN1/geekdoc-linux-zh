In 64-bit mode, the memory address space and the long integer size is increased
from 32-bit to 64-bit. While pointers are 64, and are therefore theoretically
c of addressing up to 16 exabytes, such a large address space
introduces extra complexity for little gain. As a result, at the time of this, 64-
bit processors that support a full 64-bit address space are uncommon. These
cessors support a more manageable subset of the full address space. The size of
the physical and linear address space supported by the processor can be accessed through
/proc/cpuinfo. For example:

```
$ /proc/cpuinfo | grep "address sizes" | head -n 1
address sizes : 36 physical, 48 bits virtual
```

In this example, the processor supports a physical address space of 64-GB, and a
linear address space of 256-TB. At the time of this writing, 36 physical address pins
are common for consumer hardware. On the other hand, hardware, often support a significantly larger physical address space,
Intel® Xeon processors, for example, 46 physical address pins. In order to prevent a 64-bit memory address
