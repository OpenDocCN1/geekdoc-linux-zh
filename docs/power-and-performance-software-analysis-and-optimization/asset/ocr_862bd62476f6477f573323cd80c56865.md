# 12.4.2 USING THE APPROPRIATE TYPES AND QUALIFIERS

As shown in Section 12.4.1, providing the proper hints to the compiler can aid in optimization. In many cases, these are handled by the compiler through types and their qualifiers.

# Signed versus unsigned

Types come in two flavors, signed and unsigned, as specified by the corresponding signed and unsigned qualifiers. If no qualifier is given, a signed type is assumed. As the reader is properly aware, signed types reserve a bit, the most significant, to store whether the value is positive or negative. Integers on int Architecture are stored in two's complement format. On the other hand, unsigned types do not reserve a sign bit, but are instead treated as positive, increasing the potential range of values that can be stored and also providing defined behavior in case of overflow and underflow. Adding these stronger constraints allows the compiler to optimize these types more aggressively in some situations.
