Additionally, data collection requires that the kernel's NMI watchdog and kernel
pointer finding functionality is disabled. The NMI, nonmaskable interrupt, watchdog
timer programs a reoccurring APIC timer in order to detect if the kernel has
become unresponsive. From the generation of the interrupt, the kernel has a certain
time threshold to handle the interrupt. If this threshold is exceeded, the kernel is
deaded to deadlock, and the system is rebooted. The NMI watchdog\uses the PMU to measure the PMU. This feature can be disabled by enabling nmi_watchdog=0 to the
kernel command-line, by writing a zero character to the file /proc/sys/kernel/
nmi_watchdog, or by setting the kernel.nmi_watchdog sysctl property to zero.

The kernel pointer functionality controls how the kernel prints addresses,
both in logs and system files. With this feature enabled, unless the user has
necessary privileges, all kernel pointer addresses are printed as NULL. This is designed
to improve security by hiding the exact location of some of the kernel's data struc-
ts. At the same time, this makes it difficult to correlate the collected instructionnpointers to kernel functions. This feature can be disabled by either setting the
kernel.kptr_restrict sysctl property to zero, or by writing a zero character to the
file /proc/sys/kernel/kptr_restrict. For example:

```
# echo 0 /proc/sys/kernel/kptr_restrict
# grep __do_page_fault /proc/kallsyms
ffff8ff64e780 t __do_page_fault
# echo 2 /proc/sys/kernel/kptr_restrict
# grep __do_page_fault /proc/kallsyms
0000000000000000 t __do_page_fault
```

The status of these of features can be quickly queried with the sysctl
command:

```
# sysctl -a | grep "nmi_watchdog|kptr"
kernel.kptr_restrict = 0
kernel.nmi_watchdog = 0
```

The final step of configuration is to modify the system's environment variables to
reflect the new binaries, maps, and so on. This step is automated by the amplxe-
vars.sh and amplxe-vars.csh scripts, which should be sourced from the shell's startup
file. The amplxe-vars.sh script is designed for shells POSIX shell,
including the popular bash shell. The amplxe-vars.csh script is designed for shells
based on the C shell, such as tcsch.
