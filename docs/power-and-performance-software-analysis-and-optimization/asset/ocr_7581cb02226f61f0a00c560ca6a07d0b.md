Each benchmark in the Phorix Test Suite is represented by a corresponding test profile. This profile is responsible for defining how the benchmark will be installed, how the benchmark will be run, how the results will be parsed, and the metadata describing what the results mean. Multiple test profiles can be grouped together to form a test suite.

Included with the framework is a multitude of predefined tests and test suites, providing access to popular benchmarks. Table 5.1 samples of the available benchmarks and their descriptions.
