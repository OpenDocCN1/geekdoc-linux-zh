# CHAPTER 2 Intel® Pentium® Processors

# Register Renaming

From the instruction perspective, Intel processors have eight general purpose registers in 32-bit mode, and sixteen general purpose registers in 64-bit mode, however, from the internal hardware perspective, Intel processors have many more registers. For example, the Pentium Pro has forty registers, organized in a structure referred to as a Physical Register File.

While this many extra registers might seem like a performance boon, especially if the reader is familiar with the performance gain received from the extra registers in 64-bit mode, these registers serve a different purpose. Rather than providing the process with more registers, these extra registers handle data dependencies in the out-of-order execution engine.

When a value is stored into a register, a new register entry is assigned to contain that value. Another value is stored into that register, a different register entry is assigned to this new value. Internal to the processor core, each data dependency on the first value will reference the first entry, and each data dependency on the second value will reference the second entry. Therefore, the out-of-order engine is able to execute instructions in an order that would otherwise be impossible due to false dependencies.

# 2.3 INTEL® PENTIUM®4

The P6 microarchitecture was used as the basis for the Intel® Pentium® Pro, Intel® Pentium® II, and Intel® Pentium® III processor families. As a result, each of these generations focused on improving the performance of the previous generation while adding new instructions. On the other hand, the Pentium 4, shown in Figure 2.3, was based on the NetBurst architecture. This new architecture adds features including IA-32e mode, which extends the processor from 32-bits to 64-bits, and Intel® Hyper-Threading.

# 2.3.1 IA-32e mode

The IA-32e mode extends Intel Architecture from 32-bit to 64-bit. In enter IA-32e mode, the processor must be in protected mode with PAE enabled. Paging is also requirement for IA-32e mode, so the 64-bit page tables must be constructed before transitioning to the new mode. In IA-32e mode, a fourth level is added to the paging hierarchy, the page level 4 (PML4) table. This 4-level table contains 512 entries that point to PDPTs. Each PDPT is extended from 4 entries to 512 entries. Unlike, 32-bit paging, a PDPTE could only reference a page directory table, a PDPTE can map a 1-GB page. The CR3 register holds the physical base address of the PML4 entry, the LME IA32_EFER MSR is set and then paging is enabled.
