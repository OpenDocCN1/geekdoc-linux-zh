Additionally, there are two status registers, the instruction pointer and the flags register.

The instruction pointer, IP, is often referred to as the program counter. This register contains the address of the next instruction to be executed. Until 64-bit mode, the instruction pointer was not directly accessible to the programmer, that is, it wasn't possible to access it the other general purposes. Despite this, the instruction pointer was indirectly accessible. Whereas the instruction pointer could not be modified by a MOV instruction, it could be modified by any instruction that alters the program flow, such as the CALL or JMP instructions.

Reading the contents of the instruction pointer was also possible by taking advantage of how x86 handles function calls. Transfer from one function to another occurs through the CALL and RET instructions. The CALL preserves the current value of the instruction pointer, pushing it onto the stack in order to support nested function calls, and then loads the instruction pointer with the new address, provided as an operand to the instruction. This value on stack is referred to as the return address. Whenever the function finishes executing, the RET instruction pops the address off the stack and restores it into the instruction pointer, thus transferring back to the function that initiated the function call. Leveraging this, the programmer can create a special function that would simply copy the return value of the stack, load it into one of registers, and then return. For example, when using Position-Independent-Code (PIC), which is discussed in Chapter 12, the compiler will automatically add functions that use this technique to obtain the instruction pointer. These functions are called _x86.get_pc_thunk_bx(), _x86.get_pc_thunk_dx(), and so on, depending on which register instruction pointer is loaded.

The second status register, the EFLAGS register, is comprised of 1-bit status and control flags. These bits are set by various instructions, typically arithmetic or logic instructions, to signal certain conditions. These condition flags can then be checked in order to make decisions.
