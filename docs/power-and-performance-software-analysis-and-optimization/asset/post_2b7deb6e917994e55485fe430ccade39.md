### 7.2.2 FINALIZE ACTION

Once data collection has finished, there is an intermediate step required before the results can be translated into a human readable report. First, the results must be finalized or, in the parlance of the GUI, resolved.

During this time, the raw data that was collected is cooked, attributing data samples to ELF symbols and collecting the associated metrics for the report phase. Typically, this is selected automatically at the end of the collect action, unless the no-auto-finalize argument was provided. Regardless, there are situations where it may be desirable to reinitialize the results manually. The most common of these situations is case where the previous finalization did not have the symbol information, leading to a less optimal result.

Because finalization happens automatically after the collect action, most of the collect algorithms relating to or reporting data are also supported by the finalize command. These include the search-dir and source-search-dir for choosing the source and binary files for analysis. Additionally, arguments like inline-mode and call-stack can be selected in order to filter the data results.

```
The result-dir argument specifies the directory to finalize. If this argument is omitted, the latest result is selected. For example, if the result r000bw needed to be redefined to add the source directory /src/, the command would look like ample-cl -finalize-result-dir r000bw -source-search-dir src/
```

### 7.2.3 REPORT ACTION

Once the results have been collected and finalized, they are ready to be converted into a human readable format. While reporting is an area where the graphical interface excels greatly with advanced features, both the graphical and command-line interfaces are sufficient for conducting analysis on results.

#### Command-line interface

With the command-line interface, the various result metrics are viewed with text reports. Each of these reports utilize a predefined set of metrics, and they are only useful when applied to the results of an analysis type that collects metrics. Just like the finalize command, a specific result can be specified with the result-dir argument. If multiple, the results are compared, and each report, along with their deltas, are reported. The reports that can be found in $(VTUNE_INSTALL)/config/report, and custom user reports can be created in $(HOME)/.intel/amplex/report. The list of currently available reports can be found with the built-in help command, as in Listing 7.2.
