# 11.3.4 DEVICE STATS

As mentioned earlier, PowerTOP can aggregate power consumption data from a variety of sources, including actual power meters, the RAPL interface introduced in the Second Generation Intel Core processor, and software modeling.
The software models provided with PowerTOP are based on actual data collected with a power meter. This power information shows how different devices' power consumption scales with utilization, which is another aspect of the system monitored by PowerTOP. By combining these two aspects, PowerTOP is able to estimate the actual power drain per device. It is important to recognize that these are estimates, and measuring consumption precisely requires a hardware meter.

# 11.3.5 TUNABLES

PowerTOP automatically checks the system configuration in order to detect any misconfigurations that might hurt power efficiency. Using the Up and Down Arrow keys, it is possible to scroll through each item. With an item marked highlighted, pressing the Enter key calls PowerTOP to attempt to modify the misconfigured item to a more appropriate value. This is accomplished by writing to files in sysfs and is not a persistent modification. This functionality is for testing the impact of various configurations, since PowerTOP is not designed for configuring system settings each boot. Instead, a daemon called tuned can be used to automatically set the desired configuration at boot. The tuned daemon is packaged with a tool powertop2tuned that runs PowerTOP and then translates its suggestions into a custom tuned profile.
