# CHAPTER 7 Intel® VTune™ Amplifier XE

# 7.2 DATA COLLECTION AND REPORTING

Once the kernel drivers are installed and the system has been configured accordingly, data collection and reporting are now possible. There are two primary interfaces for interacting with the VTune data collection drivers, a command-line interface, amplxe-cl, and the GTK GUI, amplxe-gui. Both of these are fully functional, as typically the GUI invokes the command-line interface for data collection anyway, although data reporting with the command-line interface is more Spartan and the GUI provides guidance when interpreting results.

For the graphical interface, all configurations are controlled through a XML project file, suffixed with .xml When a new project is created, a dialog box prompts the user with the available configuration options. These results are saved in the project XML file and then utilized across each analysis session. Figure 7.1 is a screenshot of this dialog box. These configuration can be changed at any time by right-clicking the project name in the Project Navigator window and selecting the Properties context menu. Any change made to the project configuration will not be reflected in the preexisting analyses until those results are reanalyzed. In the GUI, this is performed by right-clicking the analysis name in the Project Navigator and selecting the Re-resolve action context

menu item.
