# CHAPTER 12 Toolchain Primer

A toolchain is a set of tools for building, inspecting, and modifying software. All of the optimization techniques explained in this book, in one way or another, rely on support from the toolchain. As such, despite the fact that the majority of developers are intimately familiar with the toolchains they frequently use, the author feels compelled to ensure all readers are on the same page. The major components of a toolchain include, but aren't limited to, a compiler, assembler, and a linker.

The compiler is responsible for parsing source files written in a high-level programming language, such as C. The files are first translated into an intermediate language, used internally to the compiler. This intermediate language allows for the compiler to analyze program flow and optimize accordingly. After the optimization phase, the compiler outputs assembly code, which is passed directly to the assembler.

The assembler is responsible for translating instruction mnemonics, into human-readable assembly, into binary opcodes expected by the processor. Unlike the compiler, the assembler's output typically has a one-to-one relationship with the assembly source, except in the case of pseudo-instructions, which may translate to multiple, or zero, instructions. The output produced by the assembler is a binary file.

Finally, the linker is responsible for combining the sections from each binary object file, resolving symbol references, and producing the final output, whether an executable or library. The exact layout of the output can be controlled by a linker script, which, for each section, defines the ordering, offsets, and virtual memory addresses.

While these tools are used every time source code is built into an executable or library, there are many other pieces of the toolchain. Some tools for inspection of object files, such as nm and objdump, which display the information encoded in the object file in a human-readable form. Other tools allow for the modification of object files, such as strip and objcopy.

In Linux, there are three major toolchains: the GNU compiler toolchain (GCC), the Low Level Virtual Machine toolchain (LLVM), and the Intel® C and C++ Toolchains (ICC).

GCC is the most common toolchain, without a doubt, consisting of projects including creating and modifying binary objects, the GNU compiler collection, which provides the compiler and frontends for multiple programming languages, the GNU debugger , as well as other build tools, such as GCC autotools, and GNU Make. In fact, many open source projects, such as the Linux kernel, rely on many GCC-specific behaviors and extensions, that most of the other toolchains strive to maintain at least some level of compatibility with GCC.

Another common toolchain present on Linux is LLVM. While a younger project than GCC, LLVM has been progressing rapidly and has attracted attention for its modular design and static analysis capabilities.
