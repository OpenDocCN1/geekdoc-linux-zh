In an ideal world, all data could be stored in the fastest memory available to the system, providing uniform performance to all segments of data. Unfortunately, currently isn't feasible, forcing the developer to make tradeoffs with which data elements are prioritized for faster access. Giving preference to one chunk of data comes with the opportunity cost of potentially having given preference to a different data block.

Section 1.1 in Chapter introduced the fundamentals of a tiered storage hierarchy. This hierarchy is organized such that each level is faster, but more expensive and less dense, the level below it. This concept is illustrated in Figure 14.1.

If data are uniformly distributed, the probability of a data access to every address or block was equal, then performance would suffer immensely. Luckily, the principle of temporal data locality observes that previously accessed data is likely to be accessed soon after. Leveraging this observation, which is not a law, it is possible to improve performance by caching recently used data from a slower medium in a faster medium.

The effectiveness of such a cache is typically measured by the percentage of cache hits. A cache hit is a data access that was satisfied by the cache. A cache miss is a data access that was not satisfied from the cache, and therefore had to access one or more tiers of storage.
