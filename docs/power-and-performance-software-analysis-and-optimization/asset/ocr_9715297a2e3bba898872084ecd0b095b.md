# Installing tests

Before any benchmarks can be run, they must first be installed. This operation is performed by executing:

```
$ phoronix-test-suite install <test reference>
```

For example, to install the three test profiles that measure boot time with Systemd:

```
$ ./phoronix-test-suite install systemd-boot-kernel \
> pts/systemd-boot-userspace \
> systemd-boot-total
```

Second, the test profile's support_check.sh script runs to determine whether the benchmark is appropriate for the current system. For instance, in the previous example, the boot time test profiles, this script checks whether the system uses systemd as its init system. If not, there is no point in attempting to install the test, since it has no meaning on this system. The exit status from the script is used to communicate whether the features needed by the test are supported.
