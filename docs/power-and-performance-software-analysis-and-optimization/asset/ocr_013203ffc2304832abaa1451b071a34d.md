A Tracer is selected by writing its name into the current_tracer file. This file is also writable, to set the current tracer, and readable, to get the currently selected tracer. For example:

```
# cat available_tracers
blk function_graph wakeup_dl wakeup_rt wakeup function nop
# cat current_tracer
op
# echo function > current_tracer
# cat current_tracer
```

One tracer has been selected, data collection can now begin. The file tracing_on controls whether the results of the tracer are being recorded. Note that this is not the same as disabling or enabling the tracers, and their overhead, but merely whether the results are recorded.

The results of data collection are available in the trace and trace_pipe files. The trace file is used for processing all the data at once, whereas the trace_pipe file is used for processing the data piecemeal. As a result, the end of the file is marked with EOF marker, whereas the trace_pipe is not. More importantly, data read from the trace_pipe is consumed, that is removed from the tracing ring buffer. On the other hand, read(2)s to the trace file are destructive. In order to clear the contents of the trace file, perform a write(2) operation, such as using echo(1), on the file. The contents of the writer don't matter.

# Available tracers

The tracing subsystem has been receiving a significant amount of attention recently. As a result, it tends to advance quickly, adding new features and new tracepoints. Such, rather than trying to provide a comprehensive list of the available tracers and their usage, this section introduces a couple of the most commonly used.

Despite this rapid change to the infrastructure, the files exported through debugfs by trace fall under the kernel ABI. Therefore, in order to avoid breaking user space applications that depend on formatting and behavior, this content should not change.

# function and function_graph

The function and function_graph tracers record every function call that occurs in kernel space. Function calls from user space are omitted. In these function tracers to be enabled, the kernel must be configured with CONFIG_FUNCTION_TRACER and CONFIG_FUNCTION_GRAPH_TRACER, respectively.
