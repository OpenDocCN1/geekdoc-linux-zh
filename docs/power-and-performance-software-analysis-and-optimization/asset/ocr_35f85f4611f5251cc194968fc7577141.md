# 14.1 PROCESSOR CACHE ORGANIZATION

nThe overarching storage hierarchy can also be seen in the organization of the processor cache. The cache is divided into multiple levels, with the highest tier providing the fastest access and the smallest density and with the lowest tier providing the slowest access and the largest density. The lowest cache tier the processor supports is referred to as the Last Level Cache (LLC). A miss results in access to physical memory. The number of cache levels and their capacities depends not only on the microarchitecture, but also on the specific processor model.
