# 3.2 SECOND GENERATION INTEL® CORE™ PROCESSOR FAMILY

Launched in early 2011, the Second Generation Intel® Core processor family, shown in Figure 3.1, introduced significant improvements to a wide range of components. For example, the Front End was updated with a new cache for storing decoded µops. The instruction set was updated with the introduction of Intel® Advanced Vector Extensions (Intel® AVX), which extended the SIMD register width.
