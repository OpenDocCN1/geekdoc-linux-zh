# 15.1 SIMD 269

```
#include <inttypes.h>
void foo(char *x, size_t x_sz)
{
    /* Single-Step until aligned address */
    while ((uintptr_t)x) && (16 - 1) && x_sz) {
        /* Nonvectorized byte-by-byte algorithm */
        x_sz--;
        x++;
    }
    /* Bulk of operations w/ aligned data */
    while (x_sz >= 16) {
        /* Vectorized SSE algorithm */
        x_sz -= 16;
    }
    /* Finish up leftovers */
    while (x_sz) {
        /* Nonvectorized byte-by-byte algorithm */
        x_sz--;
        x++;
    }
}
```

# 15.1.2 SIMD OPERATIONS

All SIMD operations, those responsible for moving data, can be classified as either operating horizontally or vertically. Operations that are performed vertically occur between the corresponding positions of two separate registers. On the other hand, operations are performed horizontally occur between all the positions of one register. These two concepts are illustrated in Figures 15.1 and 15.2. The majority of SIMD operations are performed vertically, as vertical operations provide more parallelism and better performance. When possible, avoid organizing data in a manner that yields itself to vertical operations.

In order to design data structures, programmers typically organize memory by grouping all the fields needed for describing a single logical unit. In other words, a struct is organized to contain all of the attributes needed to describe a single instance of the data structure. If multiple instances are required, an array of structures is created.

For example, the situation where an array of structures exists for a series of data points, each represented by struct aos. The function foo() in this example iterates over this array and for each element floating point addition between the two elements, aos.x and aos.y, storing the result into a different array.
