# 8.2.4 PER TIMEART

Perf timechart is a tool to graphically describe the interactions on the system. Interactions include those between the processes, cores, and sleep states. Timechart commands are multiplexed through the perf timechart command. First, events are collected using the record command, which takes a command to run, similar to perf record. Next, perf timechart is run without any arguments. This generates a SVG timeline, named output.svg, of system events. That is,

```
$ perf timechart record <command>
$ perf timechart
```

For example, running perf timechart on a gzip compression workload:

```
$ perf timechart gzip -c -6 /dev/shm/linux-31.5.tar /\dev/null
[ perf record: Woken up 3 times to write data ]
[ perf record: Captured and wrote 0.883 MB perf.data (-38600 samples) ]
$ perfchart
```

Written 16.2 seconds of trace to output.svg

The output for this example can be seen in Figure 8.4.

The advantage of using a vector image format is the ability to provide scalable detail. Viewing the graph at different sizes, is, zooming in and out, shows different levels of detail. For instance, zooming on the CPU bars shows different color bars representing the transitions in CPU state, as the idle state. In properly utilize the zoomable levels of detail, make sure to view the SVG in an SVG editor or viewer, as inkscape, and not one that converts the vector image to a bitmap for viewing.

The downside to the zoomable detail is the size of both the file and timeline. In order to keep the results manageable, the author recommends avoiding the use of timechart on running processes.

The timeline highlights the interactions between various processes. At the top of the graph is a series of bars representing CPU state. At a high level of detail, these bars show what the CPU is doing at that moment in time. These include Running, Idle, Deeper Idle, Deep Sleep, Waiting for CPU, and Blocked on IO. Increasing the level of detail, is, zooming into the image, reveals more information about the state. This is shown in Figure 8.5.

Below the CPU state are bars representing processes on the system at the given time. Similar to the CPU bars, these bars also show the individual process state with the same color-coded categories.
