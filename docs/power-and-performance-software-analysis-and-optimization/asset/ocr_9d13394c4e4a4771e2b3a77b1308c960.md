QT interface for Apitrace profiling.

OpenGL state and surfaces at each call can be obtained by opening the Trace menubar item and selecting the Lookup State entry. This will cause the trace to be retraced, either for the whole trace or up until the highlighted frame or call. Once this has completed, a sidebar will appear on the right-hand side of the screen containing the data.

Apart from reconstructing the OpenGL state, trace can also be profiled by opening the Trace menubar and selecting the Profile entry. This will again cause the trace to be retraced, and a window containing a timeline of CPU and GPU times will utilize open. By highlighting over the entries, the relevant OpenGL information will be displayed. An example of this can be seen in Figure 10.2. Since retracing runs all of the OpenGL commands, this profiling information for a trace can be collected on multiple systems or configurations, in order to determine changes in performance.
