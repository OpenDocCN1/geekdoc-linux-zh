By default, Phorix stores all of the test profiles, test suites, and test results
in $${HOME}/.phorix-test-suite/. Tests are also typically installed and
execute from this directory. Inside ${HOME}/.phorix-test-suite/, the following
directories exist:

+   - download-cache Contains local copies of downloaded files for testing
- installed-tests Contains the installed benchmark executables and at runtime
files required for testing
- modules Contains available modules
- openbenchmarking Contains any resources downloaded from the
Openmarking website
- test-profiles Contains the test profile definitions which are responsible for
describing each test and performing the installation
- test-suites Contains the test suite definitions
- xsl Contains the Extensible Stylesheet Language (XSL)

# Configuration

Before installing and running benchmarks, it is necessary to configure the framework.
Almost all of the configuration options exposed by the Phorix framework, as
oposed to the individual tests, are controlled by the ${HOME}/.phorix-test-
suite/user-config.xml file. For reference, Table 5.2 documents all of the options
exposed via this XML file.
Changes can be made by directly editing the file, or by executing:

```
$ phorix-test-suite user-config set key-value
```

If no user-config.xml exists, the phorix-test-suite script will create one with
t default values. At any time, the configuration can be restored to the default
values by deleting the user-config.xml file, and letting the phorix-test-suite
script regenerate, or by executing:

```
$ phorix-test-suite user-config-set
```

The basic formatting, colors, and watermarks for the result graphs can be
customized by editing the style fields in ${HOME}/.phorix-test-suite/graph-
config.json.

Aside from these configuration files, there are about twenty environmental vari-
ables that can modify the behavior of the tests, result output, and so on.

For convenience, there is also an interactive command for configuring

```
$ phorix-test-suite network-setup
```
