# Handling unknown alignment

In many situations, the programmer will be unable to guarantee the alignment of an unaligned address at complete time. Since the additional overhead of performing unaligned loads can be significant enough to negate any performance benefits from vectorization, it may be beneficial to use a hybrid approach consisting of both vectorized and non-vectorized implementations. In this approach, the nonvectorized implementation of the algorithm is used to "single-step" until an aligned address is found. For an alignment of $n$, any address is either a multiple of $n$ and meets the requirement, or is anywhere from 1 to $n-1$ bytes away from the next aligned address. This technique relies on the nonvectorized code incrementing the address in a manner that is aligned. Once the aligned address is reached, the vectorized code can be utilized.

Assuming that the desired alignment is a power of two, which is a safe assumption for Intel processors, checking for alignment can be performed quickly with a logical instruction. This takes advantage of the property of an integer's binary representation, where a power of two is represented by a single bit, and a power of two minus one is represented as every bit prior to the power of two's bit set. For example, 16 is represented as $10000_2$ and 15 is represented as $01111_2$. Using this knowledge, checking whether a number is a multiple of a power of two is as simple as checking whether any of the bits below the power of two's corresponding bit set.

Consider the following example, where this hybrid approach is used to combine byte-by-byte nonvectorized and SSE vectorized implementation.

## 15.1 SIMD

```c
#include <inttypes.h>
void foo(char *x, size_t x_sz)
{
    /* Single-Step until aligned address */
    while ((uintptr_t)x) && (16 - 1) && x_sz) {
        /* Nonvectorized byte-by-byte algorithm */
        x_sz--;
        x++;
    }
    /* Bulk of operations w/ aligned data */
    while (x_sz >= 16) {
        /* Vectorized SSE algorithm */
        x_sz -= 16;
    }
    /* Finish up leftovers */
    while (x_sz) {
        /* Nonvectorized byte-by-byte algorithm */
        x_sz--;
        x++;
    }
}
```

## 15.1.2 SIMD OPERATIONS

All SIMD operations, those responsible for moving data, can be classified as either operating horizontally or vertically. Operations that are performed vertically occur between the corresponding positions of two separate registers. On the other hand, operations are performed horizontally occur between all the positions of one register. These two concepts are illustrated in Figures 15.1 and 15.2. The majority of SIMD operations are performed vertically, as vertical operations provide more parallelism and better performance. When possible, avoid organizing data in a manner that yields itself to vertical operations.

In order to design data structures, programmers typically organize memory by grouping all the fields needed for describing a single logical unit. In other words, a struct is organized to contain all of the attributes needed to describe a single instance of the data structure. If multiple instances are required, an array of structures is created.

For example, the situation where an array of structures exists for a series of data points, each represented by struct `aos`. The function `foo()` in this example iterates over this array and for each element floating point addition between the two elements, `aos.x` and `aos.y`, storing the result into a different array.

```c
#include <inttypes.h>
#include <immintrin.h>

struct soa {
    double x;
    double y;
    size_t len;
};

void foo_avx(struct soa *in, double *out) {
    size_t sz = in->len;
    double *x = in->x;
    double *y = in->y;

    while ((uintptr_t)x) && (32 - 1) && sz) {
        sz--;
        x++;
        y++;
    }

    while (sz >= 4) {
        __m256d vx = _mm256_load_pd(x);
        __m256d vy = _mm256_load_pd(y);
        __m256d vr = _mm256_add_pd(vx, vy);
        _mm256_store_pd(out, vr);
        x += 4;
        y += 4;
        out += 4;
        sz -= 4;
    }

    while (sz--) {
        *out = *x + *y;
        x++;
        y++;
        out++;
    }
}
```
