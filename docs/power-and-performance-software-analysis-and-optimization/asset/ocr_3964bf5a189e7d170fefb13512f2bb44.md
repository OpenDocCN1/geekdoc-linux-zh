# 12.4.4 LOOP UNROLLING

Loop unrolling is a technique for attempting to minimize the cost of loop overhead,
as as branching on the termination condition and updating counter variables. This
curs by manually adding the necessary code for the loop to occur multiple times
within the loop body and updating the conditions and counters correctly. The
pot for performance improvement comes from the reduced loop overhead, since
less iterations are required to perform the same work, and also, depending on the code,
pibility for better instruction pipelining

While loop unrolling can be beneficial, excessive unrolling degrades performance.
Because modern processors execute instruction out-of-order in many
loops unrolling effectively occurs in hardware, with a better scheduling of
resources can be performed at compile time. Additionally, the compiler may
automatically perform loop unrolling.

Since loop unrolling is a tradeoff between code size and speed, the effectiveness
of loop unrolling is highly dependent on the loop unrolling factor, that is, the number
of times the loop is unrolled. As the factors increase, code size increases, leading to
pot issues with the front end, such as icache misses. The only way to determine
tbest unrolling factor is through measurement.
