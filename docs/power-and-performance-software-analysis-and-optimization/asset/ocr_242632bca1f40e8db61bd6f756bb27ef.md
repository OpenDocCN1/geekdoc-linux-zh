Listing12.2 demonstrates how to use __get_cpuid() to check for SSE4.2, Intel AVX, and Intel AVX2.

Notice that the feature checks at 17, 20, and 27 are wrapped with preprocessor checks for whether the bit masks are defined. This is because older toolchain versions that lack support for these features won't have these masks, leading to compilation errors. The downside of this approach is that the feature checks will only be performed if the compiler supports the feature. This could be resolved by checking for what the bit mask preprocessor defines, and manually defining them in the case they aren't already defined.

GCC the leaf number against the maximum supported leaf and returns false in the case where the request leaf is unavailable. By this type of writing, Clang provides the same functionality as GCC, but does not perform the maximum leaf check.

```
#include <cpuid.h>
static int has_sse42;
static int has_avx;
static int has_avx2;
#define BASIC_LEAF 0x1
#define EXTENDED_LEAF 0x7
void x86_feature_check(void)
{
    int ret;
    unsigned eax, ebx, ecx, edx;
    ret = __get_cpuid(BASIC_LEAF, &eax, &ebx, &ecx, &edx);
    if (ret) {
        #ifdef bit_SSE42
        has_sse42 = ecx & bit_SSE42;
        #endif
        #ifdef bit_AVX
        has_avx = ecx & bit_AVX;
        #endif
    }
    #ifdef bit_AVX2
    ret = __get_cpuid(EXTENDED_LEAF, &eax, &ebx, &ecx, &edx);
    if (ret) {
        has_avx2 = ebx & bit_AVX2;
    }
    #endif
}
```
