The energy status capability, controlled through the registers named with the MSR_x_ENERGY_STATUS pattern, provides the total energy consumption, in joules.
Because the RAPL interface is exposed through MSRs, any application with sufficient privileges can utilize this interface without any kernel support. For example, the PowerTop tool, described in further detail in Section 11.3, manually accesses the power consumption data from RAPL for its power estimates. By manually accessing the MSR registers, the Intel® RAPL powercap Linux kernel driver, CONFIG_INTEL_RAPL, exposes the MSRs through sys filesystems. This interface is utilized by the Linux Thermal Daemon, thermald. By default, the daemon monitors the system's temperatures and uses RAPL capping, with the Intel P state driver, CONFIG_X86_INTEL_PSTATE, in order to prevent thermal throttling with T states. More information on the Linux Thermal Daemon can be found at https://01.org/linux-thermal-daemon.
