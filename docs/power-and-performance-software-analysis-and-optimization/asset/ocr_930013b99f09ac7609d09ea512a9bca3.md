# 12.5.2 INLINE ASSEMBLY

While standalone assembly provides the most control, sometimes it is more desirable to write the function in C, with only a small subset of the code in assembly. To accomplish this, most compilers support some level of inline assembly, that is, embedding of assembly instructions directly into C source files.

GCC, along with LLVM and ICC, support an extended inline assembly syntax, that allows for C variables to be utilized in the assembly, while the compiler handles moving the variables into the proper format. This syntax takes the following:

```
__asm__ volatilevolatile (
    ""INSTRUCTIONS\n\t"
    ""INSTRUCTIONS\n\t"
    ...
    : Input Variables
    : Output Variables
    : List of Clobbered Resources
    );
```
