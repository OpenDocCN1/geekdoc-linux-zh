## 20 后续去向？

对于对内核编程深感兴趣的人，[kernelnewbies.org](https://kernelnewbies.org)以及内核源代码中的 Documentation 子目录是强烈推荐的。虽然后者可能并不总是直截了当，但它作为进一步探索的宝贵第一步。呼应林纳斯·托瓦兹的观点，理解内核最有效的方法是通过个人审阅源代码。
