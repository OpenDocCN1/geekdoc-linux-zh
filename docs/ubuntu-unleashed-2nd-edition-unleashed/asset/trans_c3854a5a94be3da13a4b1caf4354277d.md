## NOTE

Procmail 或 Spamassassin 是 MTA 的示例；两者都向 MTA 提供过滤服务，同时将邮件存储在本地，然后使邮件可供 MUA 或电子邮件客户端供用户阅读。

MDA 使用 POP3 或 IMAP 协议进行此过程。以邮局的邮政信箱方式，POP3 和 IMAP 实现了一种“存储和转发”过程，从而消除了如果您只想阅读邮件则维护本地邮件服务器的需求。例如，拨号上网用户可以间歇性地连接到其 ISP 的邮件服务器，使用 Fetchmail 检索邮件——Ubuntu 推荐的 MDA（见本章后面的“使用 Fetchmail 检索邮件”部分）。

## The Mail User Agent

邮件用户代理，或 MUA，是电子邮件系统中的另一个必要部分。MUA 是一种邮件客户端，或邮件阅读器，允许用户阅读和撰写电子邮件并提供用户界面。（它就是大多数用户熟悉的“电子邮件”本身的电子邮件应用程序。）一些流行的 UNIX 命令行 MUA 有 elm、pine 和 mutt。Ubuntu 还提供现代的 GUI MUA：Evolution、Thunderbird、Mozilla Mail、Balsa、Sylpheed 和 KMail。相比之下，常见的非 UNIX MUA 有 Microsoft Outlook、Outlook Express、Pegasus、Eudora 和 Netscape Messenger。

Microsoft Windows 和 Macintosh 的 MUA 通常包含一些 MTA 功能；UNIX 则不然。例如，Microsoft Outlook 可以连接到您的 Internet 提供商的邮件服务器以发送消息。另一方面，UNIX MUA 通常依赖于外部 MTA，例如 Sendmail。这看起来像是连接单个用户到其 ISP 的不必要复杂的方式，如果用于此目的，确实如此。然而，对于任何其他情况，使用外部 MTA 可以让您获得更大的灵活性，因为您可以使用任意数量的外部程序来处理和处理您的电子邮件功能并自定义服务。由不同应用程序处理该过程，可以让您在为网络上的用户以及个人和小型办公/家庭办公（SOHO）用户提供电子邮件服务的方式上拥有极大的控制权。

例如，您可以执行以下操作：

- 使用 Evolution 阅读和撰写邮件
- 使用 Sendmail 发送您的邮件
- 使用 xbiff 在您有新邮件时通知您
- 使用 Fetchmail 从远程邮件服务器检索您的邮件
- 使用 Procmail 根据发件人、主题或其他许多变量自动对传入邮件进行分类
- 使用 Spamassassin 在您阅读之前消除不需要的消息

## Basic Postfix Configuration and Operation

由于 Postfix 是 Ubuntu 推荐的 MTA，以下部分提供了配置和操作您的电子邮件系统的简要说明和示例。如前所述，Postfix 是一个极其复杂的程序，具有许多配置选项。因此，本章仅涵盖一些基础知识。有关 Postfix 以及其他 MTA 的更多信息，请参阅本章末尾的“Reference”部分。

Postfix 配置由 /etc/postfix 目录中的文件处理，其中大部分配置由文件 main.cf 处理。配置文件 main.cf 的实际语法相当容易阅读（见以下示例）：

```
# See /usr/share/postfix/main.cf.dist for a commented, more complete version
# Debian specific: Specifying a file name will cause the first
# line of that file to be used as the name. The Debian default
# is /etc/mailname.
#myorigin = /etc/mailname

smtpd_banner = $myhostname ESMTP $mail_name (Ubuntu)
biff = no

# appending .domain is the MUA's job.
append_dot_mydomain = no

# Uncomment the next line to generate "delayed mail" warnings
#delay_warning_time = 4h

# TLS parameters
smtpd_tls_cert_file=/etc/ssl/certs/ssl-cert-snakeoil.pem
smtpd_tls_key_file=/etc/ssl/private/ssl-cert-snakeoil.key
smtpd_use_tls=yes
smtpd_tls_session_cache_database = btree:${queue_directory}/smtp_scache
smtpd_tls_session_cache_database = btree:${queue_directory}/smtp_scache

# See /usr/share/doc/postfix/TLS_README.gz in the postfix-doc package for
# information on enabling SSL in the smtp client.

myhostname = optimus
alias_maps = hash:/etc/aliases
alias_database = hash:/etc/aliases
```
