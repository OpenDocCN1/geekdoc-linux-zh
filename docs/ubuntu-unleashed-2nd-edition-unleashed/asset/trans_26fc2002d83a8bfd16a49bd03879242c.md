## Ubuntu
## UNLEASHED
## Second Edition

*Ubuntu Unleashed* 对流行的 Ubuntu Linux 发行版进行了全面介绍。Windows 用户、Mac 用户和 Linux 爱好者纷纷转向 Ubuntu，寻求一个用户友好、易于使用的 Linux 发行版。

本书提供了有关安装、使用和管理 Ubuntu 的详细信息。你将学习如何设置工作站或服务器，并会找到有关 Ubuntu 易于使用的桌面和生产力软件的完整细节。

*Ubuntu Unleashed* 涵盖范围广泛：从你在日常工作中需要的软件，例如 OpenOffice.org 生产力套件，到如何配置你的 Linux 桌面以使用多台打印机、shell 脚本等顺畅运行。

对于资深 Linux 爱好者，书中完整介绍了 X Window 系统、Linux 编程、Web 服务器管理和网络管理。

Andrew Hudson 是 *Linux Format* 杂志的常驻自由撰稿人，该杂志是英国最大的 Linux 杂志。他是 *Fedora Unleashed* 的合著者。

Paul Hudson 是一名专业开发者，也是 Future Publishing 的全职记者。他的文章曾发表于 *Mac Format*、*PC Answers*、*PC Format*、*PC Plus* 和 *Linux Format*。他是 *Fedora Unleashed* 的合著者。
