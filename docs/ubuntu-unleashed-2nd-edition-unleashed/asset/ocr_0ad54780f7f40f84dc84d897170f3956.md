# The Glade Client for Developing in GNOME

If you prefer to use GNOME and its development tools, the Glade GTK+ GUI builder (the glade-3 client) can help you save time and effort when building a basic skeleton for a program. You launch glade-3 from the desktop panel's Programming menu or from the command line of a terminal window, like this:

```
$ glade-3 &
```
