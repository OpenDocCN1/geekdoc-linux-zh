

综合Perl归档网络（CPAN），它是Perl代码仓库的镜像网络。

CPAN的大部分由*模块*组成，模块是可重用的代码块，用于完成有用的功能，类似于包含C程序员所需函数的软件库。这些模块有助于加快Perl程序的开发速度，使Perl黑客不必在构建程序时反复重新发明轮子。

Perl自带一组已安装的标准模块。这些模块应包含你最初使用Perl时所需的大部分功能。如果你需要使用未随Ubuntu安装的模块，可以使用CPAN模块（它是标准模块之一）将其他模块下载并安装到你的系统上。在http://www.perl.com/CPAN，你会找到CPAN多路复用调度器，它会尝试将你引导到离你最近的CPAN站点。

输入以下命令将进入一个交互式shell，使你可以访问CPAN。你可以在提示符下输入`help`以获取有关如何使用CPAN程序的更多信息：

```
$ perl -MCPAN -e shell
```

从CPAN安装模块（或自己编写模块）后，你可以将该模块加载到内存中，并使用use函数使用它：

```perl
use Time::CTime;
```

`use`会在变量`@INC`列出的目录中查找模块。在此示例中，`use`查找名为Time的目录，该目录包含名为CTime.pm的文件，而该文件又被假定包含名为Time::CTime的包。每个模块的发行版都应包含有关使用该模块的文档。

有关所有标准Perl模块（安装Perl时附带的模块）的列表，请参阅Perl文档中的`perlmodlib`。你可以在命令提示符下输入**`perldoc perlmodlib`**来阅读本文档。

## 代码示例

以下各节包含一些你可能想用Perl完成的操作示例。

### 发送邮件

你可以通过多种方式让Perl发送电子邮件。一种常见的方法是打开到sendmail命令的管道并向其发送数据（如清单27.5所示）。另一种方法是使用Mail::Sendmail模块（可通过CPAN获得），该模块直接使用套接字连接发送邮件（如清单27.6所示）。后一种方法更快，因为它无需启动外部进程。请注意，清单27.5中的Perl程序要正常工作，你的系统上必须运行sendmail。

#### 清单27.5 使用Sendmail发送邮件

```perl
#!/usr/bin/perl
open (MAIL, '| /usr/sbin/sendmail -t'); # Use -t to protect from users
print MAIL <<EndMail;
To: dpitts\@mk.net
From: rbowen\@mk.net
Subject: Email notification

David,
  Sending email from Perl is easy!
Rich
.
EndMail
close MAIL;
```

#### 注意

请注意，电子邮件地址中的@符号必须进行转义，以免Perl尝试求值该名称的数组。也就是说，`dpitts@mk.net`会引起问题，所以你需要使用`dpitts\@mk.net`。

用于打印邮件消息的语法称为*here document*（嵌入文档）。语法如下：

```perl
print <<EndText;
.....
EndText
```

EndText值在块的开始和结束处必须完全一致，包括任何空白字符。

#### 清单27.6 使用Mail::Sendmail模块发送邮件

```perl
#!/usr/bin/perl
use Mail::Sendmail;
%mail = ('To' => 'dpitts@mk.net',
         'From' => 'rbowen@mk.net',
         'Subject' => 'Email notification',
         'Message' => 'Sending email from Perl is easy!',
);
sendmail(%mail);
```

Perl会忽略哈希中最后一个元素后的逗号。将其保留在那里很方便；如果你想向哈希中添加项目，就不需要添加逗号。这纯粹是风格上的决定。

### 使用Perl安装CPAN模块

你可以使用Perl的-M和-e命令以交互方式从CPAN归档中下载并安装Perl模块。像这样使用Perl来启动该过程：

```
# perl -MCPAN -e shell
```

按Enter键后，你将看到一些介绍性信息，并被要求选择初始的自动或手动配置，这是在任何下载或安装之前所必需的。输入no并按Enter键，让Perl自动配置下载和安装过程；或者，如果需要，直接按Enter键手动配置下载和安装。如果使用手动配置，你必须回答一系列关于路径、缓存、终端设置、程序位置等问题。设置将保存在当前目录中名为`.cpan`的目录中。

完成后，你将看到CPAN提示符：

```
cpan>
```

要让Perl检查你的系统，然后下载并安装大量模块，请在提示符下使用install关键字，指定Bundle，然后按Enter键，如下所示：

```
cpan> install Bundle::CPAN
```

要下载所需模块（使用清单27.6中的示例），请使用get关键字，如下所示：

```
cpan> get Mail::Sendmail
```

模块的源代码将被下载到`.cpan`目录中。然后你可以使用install关键字构建并安装该模块，如下所示：

```
cpan> install Mail::Sendmail
```

检索、构建和安装模块的整个过程也可以使用Perl的-e选项在命令行完成，如下所示：

```
# perl -MCPAN -e "install Mail::Sendmail"
```

另请注意，@符号在单引号（' '）内无需转义。Perl不会在单引号内进行插值（求值变量），但在双引号和here字符串中会进行插值（类似于`<<` shell操作）。

### 清理日志

许多程序会维护各种日志。通常，日志中的大量信息是冗余的或毫无用处的。清单27.7中显示的程序会从文件中删除包含特定单词或短语的所有行，因此你可以清除那些已知不重要的行。例如，你可能希望删除Apache错误日志中来自测试客户端计算机的所有行，因为你已知这些错误消息是在测试期间产生的。
