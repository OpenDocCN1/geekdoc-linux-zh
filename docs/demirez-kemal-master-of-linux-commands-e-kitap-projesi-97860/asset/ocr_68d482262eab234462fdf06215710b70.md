Linux Komut Satırı.1

To open this compressed archive.tar.gz command, we must use tar xzvf bzip2 command to archive the file this time. For example, we can use tar cjvf archive.tar.bz sample test command.

```
root@kemal:~/zeyno# ls
example sample test
root@kemal:~/zeyno# tar cjvf archive.tar.bz2 sample test
sample test
root@kemal:~/zeyno# ls
archive.tar.bz2 example sample test
root@kemal:~/zeyno# _
```

In this way we can use tar xjvf archive.tar.bz2 command to open the file archived by bzip2 command.

```
root@kemal:~/zeyno# ls
archive.tar.bz2
root@kemal:~/zeyno# tar xjvf archive.tar.bz2
sample test
root@kemal:~/zeyno# ls
archive.tar.bz2 sample test
root@kemal:~/zeyno# _
```
