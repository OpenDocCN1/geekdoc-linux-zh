## History

In fact, this topic could be described in the following sections. But it would be more appropriate here to mention. Linux system used commands are kept in memory (by writing a file for a certain number allocated) then the investigation which commands used and we want to retroactively allow us to use it again. Yes, the command used in the command line is saved in the .bash_history file. We can use the history command to list the commands that have been used before. This command will reference the .bash_history file.

```
root@kemal:~# history
1 nano /etc/hostname
2 ls
3 tar -zxvf LibreOffice_5.0.0_Linux_x86_deb.tar.gz
4 ls
5 tar -zxvf LibreOffice_5.0.0_Linux_x86_deb_helpack_tr.tar.gz
6 tar -zxvf LibreOffice_5.0.0_Linux_x86_deb_langpack_tr.tar.gz
7 ls
8 cd LibreOffice_5.0.5_Linux_x86_deb
9 ls
10 cd DEBS/
11 ls
12 dpkg -i *.deb
13 ls
14 cd LibreOffice_5.0.5_Linux_x86_deb -h
15 cd LibreOffice_5.0.5_Linux_x86_deb_helpack_tr/
```

To use a command listed in these commands from the terminal again, its sufficient that we can put ! sign to the left of the command. For example, I listed my screen commands from the terminal number 215: cd /home command, to use it again I have to give !215 command.

```
root@kemal:~# !215
cd /home
root@kemal:/home# 
```

If you want to reuse the command that you use the latest, you must give the command !! for that

```
root@kemal:~# !!
cd
root@kemal:~#
```
