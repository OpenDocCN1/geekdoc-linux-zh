# Tac

To view toward the beginning of the end of the contents of a text file, we can use the tac command.

```
root@kemal:~zeyno# cat hacker
Linux users
Network
Computer
root@kemal:~zeyno# tac hacker
Computer
Network
Linux users
root@kemal:~zeyno#
```
