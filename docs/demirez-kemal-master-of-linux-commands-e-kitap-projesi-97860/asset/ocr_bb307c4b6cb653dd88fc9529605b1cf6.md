# Master of Linux Commands

chmod o-wx <file_name> (To remove all the rights of to read and write from the other users)

chmod u+rw,g+r,o+r <file_name> (give all rights to owner, reading rights to groups, reading rights to other users)

chmod go-rwx <file_name> (remove rwxr authority from group and others)

chmod +x <file_name> (give everyone permission to execute)

Let's see a simple example how to change the permissions. We have a file named users.txt. Let look at the file permissions with ls -l users.txt.

```
root@kemal:~# ls -l users.txt
-rw-r--r-- 1 root 144 Eyl 18 02:09 users.txt
```

Allow state seems to be -rw-r--r--. Initial - mark, as we mentioned earlier, indicates that this is a file. If that was d letter we would understand that it was a directory. According to this allowing status, the owner has read and write authority. In all other users we want to give the group and other users write access, we must use chmod go+w users.txt command.

```
root@kemal:~# chmod go+w users.txt
root@kemal:~# ls -l users.txt
-rw-rw-rw- 1 root 144 Eyl 18 02:09 users.txt
```

For example, to remove read permission users in this group, and also to remove other users writeite permission we use chmod g-r,o-w users.txt command.
