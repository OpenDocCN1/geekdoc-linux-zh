While in Debian RedHat systems has package manager called dpkg, rpm manager. For example, let's say you are using a Linux distribution Fedora which uses the rpm packages and you downloaded google-chrome-stable-current_i386.rpm package (which is for Chrome web browser When you need to use rpm -iv google-chrome stable_current_i386.rpm command. ivh here means that:

+   * i : installed the package
* v : show the process on the screen
* h : show the installation levels

To remove/uninstall the package/program from the system rpm-ev <package_name> command can be used. Now lets list rpm commands for Linux users who use RedHat / derivative Linux distribution:

+   * rpm -i <program_package.rpm>: establishing the basic package command
