要列出文件中第 3 行之后的行，必须使用 `NR > 3` 表达式。

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk 'NR>3 {print}' test
CentOS
RedHat System Mng.
root@kemal:~# _ _
```

现在让我们看看如何列出文件的行数。例如，要找到 `/etc/shadow` 文件有多少行，我们使用 `awk 'END {print NR}' /etc/shadow` 命令。我们使用了 `-F:` 来处理以冒号 `:` 分隔的行。

```
root@kemal:~# awk -F: 'END {print NR}' /etc/shadow
52
root@kemal:~# _ _
```

当我们想要按照文件行号显示内容时（例如 test 文件中的行），我们 应该使用 `awk '{print NR " " $0}' test`。

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk '{print NR " " $0}' test
1 Linux BackTrack 5
2 Kali Linux 2.0
3 Ethical Hacking
4 CentOS
5 RedHat System Mng.
root@kemal:~# _ _
```

以下三个命令执行相同的操作：给出命令后列出的文件的总大小。

- `ls -l | awk '{sum += $5} END {print sum}'`
- `ls -l | grep -v '^total' | awk '{sum += $5} END {print sum}'`
- `ls -l | awk '^total/(getline) {sum += $5} END {print sum}'`

```
root@kernel:~ ls -l | awk '{sum += $5} END {print sum}'
45608
root@kernel:~ ls -l | grep -v '^total' | awk '{sum += $5} END {print sum}'
45608
root@kernel:~ ls -l | awk '^total/(getline) {sum += $5} END {print sum}'
45608
root@kernel:-#
```

# Vim 编辑器

# Vi-Vim

Linux 最著名且功能最强大的编辑器是 Vim。

```
root@kemal:~zeyno# ls
file1 file2 file3 file4 file5
root@kemal:~zeyno# ls | awk '{print mv "$1" "$1.txt"}' | sh
root@kemal:~zeyno# ls
file1.txt file2.txt file3.txt file4.txt file5.txt
root@kemal:~zeyno# _
```

在 Vim 中，有不同的模式：

- **普通模式 (Normal Mode)**：这是默认模式，用于执行命令、移动光标等。
- **插入模式 (Insert Mode)**：用于输入文本。可以通过按 `i`、`a`、`o` 等键进入，按 `Esc` 退出普通模式。
- **命令行模式 (Command Line Mode)**：通过 `:` 进入，用于执行复杂的编辑命令。
- **视觉模式 (Visual Mode)**：通过 `v`、`V` 等进入，用于选择文本块。

是一些常用的快捷命令：

- `:w`：保存文件。
- `:q`：退出编辑器。
- `:q!`：强制退出，不保存。
- `:wq` 或 `:x`：保存并退出。
- `:u`：撤销上一次操作。
- `Ctrl + r`：重做操作。
- `dd`：删除当前行。
- `yy`：复制当前行。
- `p`：粘贴到光标后。
- `/pattern`：搜索特定模式。

通过掌握这些基础知识，你可以高效地在 Linux 环境下进行文本编辑。
