In rpm distribution, storages are located in under
/etc/yum.repos.d.

To install a program, we will use basic commands which is
apt-get install <program_name>. For RedHat and similar
distributions yum install <program_name> command should
be used for file installation. After using this command, if the
programs are in the store, they will be downloaded and
installed automatically. If you get the information about the prog-
ram and if it is in the store the apt-cache search <prog-
name> command can be used.

```
root@kemal:~# apt-cache search bleachbit
bleachbit - delete unnecessary files from the system
root@kemal:~#
```

In the above example we use BleachBit (program for
cleaning junk files like Cleaner in Windows), in the storages.
Now to install this program to our system, we can use apt-get
install bleachbit command.

