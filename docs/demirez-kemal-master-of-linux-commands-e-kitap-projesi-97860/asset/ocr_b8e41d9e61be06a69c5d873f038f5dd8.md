# Linux has a strong security system for files and directories.

The most important element of this security system is, well established design on the user authority permissions on files and directories. As known, the top authorized users in the system is called root and there are no restrictions for this user. Therefore, if you're working with root user rights on the system operation its better to pay attention.

# Access Privileges

Each user on the system can process within the framework of the authority delegated to him. The users can have three different series of actions on file or directory.

+   - read (r): Can he/she see the file content? (For folders) can he/she get the file list?

+   - write (w): Permission of writing to the file and also delete the file. (For folders) Can he/she create files or subfolders within this folder?

+   - execute (x): Can she/he execute the files? (For folders) Can she/he get in to the folder?
