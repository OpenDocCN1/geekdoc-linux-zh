# Vi-Vim

The most famous and most capable editor in Linux which you can use with the commands from the terminal is Vi editor. Today, there are also type of Vi editors which also have visual interface (gvim), but users generally prefer to use the commands from the terminal. The old name of this tool is Vi, however it's chaged to current name of VIM (Vi improved). Vi is a symbol of the UNIX tradition. VIM is an improved version of the Vi's.

To open the editor in a normal way, we need to use the vim command. With this command, our editor, terminal/console will be opened and be as follows:

```
[No Name] - Vim
Dosya Düzenle Görünüm Ara Üçbir Yardım

nVIM - Vi IMproved
version 7.4.576
By Bram Maelenaar et al.
Modified by pkg-vim-maintainers@lists.debian.org
Vim is open source and freely distributable

Become a registered Vim user!
type :help register<Enter>      for information

type :q<Enter>                   to exit
type :help<Enter> or <F1>      for on-line help
type :help version7?<Enter>     for version info

0,-1                           All
```

We must press the i (insert) key to start work with our editor. After we press the i key, there will be INSERT prompt at the left bottom corner which means the editor is ready to take the datas. Now we can create the content we want.
