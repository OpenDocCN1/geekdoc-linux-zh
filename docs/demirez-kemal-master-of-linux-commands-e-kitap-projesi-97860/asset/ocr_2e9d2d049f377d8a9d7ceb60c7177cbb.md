We can wish to see not all of the process example, to get the information about the process we want. For to get information about processes related to the SSH service, we can use ps aux | grep 'ssh' ' command.

```
root@kemal:~# ps aux | grep [s]sh
root      819  0.0  0 -6412 24 7  Ss 23:07   0:00 /usr/bin/ssh-agent /usr/bin/dbus-la
unch --exit-with-session gnome-session-classic
root     1367  0.0  0.3 -4360 3532 5+ 23:43   0:00 grep ssh
```

If you pay attention to the command output in the example above, we have to look at the process of most recently command used in the list. To avoid this, we can try using the following command.

```
root@kemal:~# ps aux | grep [s]sh
root      819  0.0  0 -6412 24 7  Ss 23:07   0:00 /usr/bin/ssh-agent /usr/bin/dbus-la
unch --exit-with-session gnome-session-classic
```

# Ptree

To view the system processes into a hierarchical list, we can use ptree or ps -forest commands.

```
root@kemal:~# ptree
systemd--ModemManager--{gdbus}
               |--{gmain}
           -NetworkManager--{NetworkManager}
                               |--{gdbus}
                               |--{gmain}
           -accounts-daemon--{gdbus}
                               |--{gmain}
               -agetty
               -at-spi-bus-laun--dbus-daemon
                               |--dconf worker
                               |--{gdbus}
                               |--{gmain}
```

If you want to see the processes with the PID numbers we can use pstree -p command.
