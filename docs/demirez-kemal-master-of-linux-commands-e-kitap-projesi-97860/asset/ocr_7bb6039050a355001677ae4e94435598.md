Linux systems has two connection types: hard link (connection) and symbolic link. The difference between these connection types: established a connection file with hard link, the other file is a copy literally. Even if the original file deleted the file created with solid link remain created. Connection files created by symbolic links (soft-link) are used for a shortcut in a real term. Function of this file is only redirecting to the original file.

# Inode

What we call the inode is a structure that contains meta data about the file like the access number, etc. as. Normally, each inode is unique. But the inodes of the files created with solid link are the same. df -i command is used to view the inode table. Now we see the example that explains all. We said, each inode number is unique. To examine this inode (node) of the numbers, we use the ls -li command.
