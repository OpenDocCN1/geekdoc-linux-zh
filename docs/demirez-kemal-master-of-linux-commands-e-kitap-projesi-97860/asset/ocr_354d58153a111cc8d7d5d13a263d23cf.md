# Service Command

To run-stop-restart the services in the system we use service command. Usage pattern of the command is essentially as follows:

service apache2 start | stop | status | restart

Example for Apache is similar to all services. As you can see, to start the service start, stop to stop, to see the status and to restart the restart. Now let use service command in a different way, and look at the situation of all the services in the system. The command we will use service --status-all command.

```
root@kemal:~# service --status-all
[ - ] anacron
[ - ] apache2
[ ? ] arpwatch
[ + ] atd
[ - ] atftpd
[ + ] avahi-daemon
[ - ] beef-xss
[ + ] bfinmt-support
[ - ] bluetooth
[ - ] bootlogs
[ - ] bootmisc.sh
[ - ] checkfs.sh
[ - ] checkroot-bootclean.sh
```
