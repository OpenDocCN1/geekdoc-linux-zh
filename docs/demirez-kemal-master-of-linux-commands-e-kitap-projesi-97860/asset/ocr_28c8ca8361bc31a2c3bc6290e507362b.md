Here, the way, lets talk about uid (user id) and gid (group id) issues. In Linux systems, there is a specific identification number issued to the user. These numbers are as follows according to the user type.

+   - root user: UID=0, GID=0

+   - system users: UID=1-499, GID=1-499

+   - normal users: UID=500<, GID=500<

Lets check the uid numbers by id command.

```
root@kemal:~# id
uid=0(root) grupl=0(root)
root@kemal:~# id zeynep
uid=1000(zeynep) gid=1001(zeynep) grupl=1001(zeynep)
root@kemal:~#
```

Information about the users that we added automatically written into /etc/passwd and /etc/shadow files.

```
root@kemal:~# cat /etc/passwd | grep zeynep
zeynep:x000:1001::/home/zeynep:/bin/bash
root@kemal:~# cat /etc/shadow | grep zeynep
zeynep:!YSTKDDla.IIfdakZD0QNONQ7Y1X1OcY.ZahmWEFA0yGda6//USIRDSynk.tTOIRYz2CS0ZW0klz00mWWktl.:16658:9999:::
root@kemal:~#
```

To create a user account we can use useradd, to create a user named zeynep we can use useradd -m zeynep command. Wherein the m parameter, added user-owned home that of personal home directory we will ensure that its automatically generated. If we do not use this parameter, we can create this directory manually. After that we can add a password to this user as password zeynep command.
