### Shell

Shell is taking place between the user and kernel tasks, interprets commands from the user to communicate with the kernel. Kernel and shell's interaction happens through with the system calls.

There are many shells are used in Linux systems but the most preferred programs are BASH shell program. To learn using shell program in our system, we can use the echo $SHELL command.

```bash
root@kemal:~# echo $SHELL
/bin/bash
root@kemal:~# 
```

The console commented our order and sent us an outcome. We said it would also reviewed the commands issued from the console, but it will be interpreted according to what? That point, environmental variables come play into concept.

# Environment Variables

We will use the following command and check what command try to explain to us to get the subject. The command we will use is echo $ PATH command

```bash
root@kemal:~# echo PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/bin
root@kemal:~# 
```

What does this command output tell us? What it wants to say is: I need to look at some index respectively for operating a command entered from the console. If the executable file is under the command of these directories, I can run it. If that path (PATH) is attached than ":" sign to the structure formed by the divided statement seperated by that statement (PATH) it is called environment variables.

We can use the printenv or env commands to see the environment variables for working environment at any time.

```bash
root@kemal:~# env
XDG_VTNR=7
SSH_AGENT_PID=922
XDG_SESSION_ID=1
GPG_AGENT_INFO=/run/user/0/keyring/gpg:0:1
TERM=xterm

XDG_MENU_PREFIX=gnome-
VTE_VERSION=3801
GJS_DEBUG_OUTPUT=stderr
WINDOWID=29360139
GJS_DEBUG_TOPICS=JS ERROR; JS LOG
USER=root
```

Now, let's see what the command output is also seen in medium / environment or shell variables means:

- PATH: When a command is given, searches the directories of the files that make up the command program.
- HOME: Contains the variable name of user's personal directory (home directory).
- TERM: The variables associated with the X server which the graphic screen images to be sent.

# Bash Shortcuts

When using the bash shell (writing the script) some shortcuts can simplifies our work. Most of these shortcuts are listed below. You can be more practical with exercising them.

- ctrl+A: Move the cursor to the beginning of the line.
- ctrl+E: Move the cursor to the end of the line.
- ctrl+B: The cursor goes one character back.
- ctrl+F: The cursor goes one character further.
- alt+B: The cursor goes one word back.
- alt+F: The cursor goes one word further.
- ctrl+XX: The cursor goes and returns from its location to beginning.
- ctrl+L: Clears the screen and the cursor goes all the way to top (same as clear command)
- ctrl+U: Everything left of the cursor will be deleted.

- ctrl+K: Everything right of the cursor will be deleted.
- esc+T: Cursor replaces the previous two words.
- ctrl+C: Cuts the command.
- ctrl+Z: Assigns running applications to the background. With bg command, the process will continue working in the background, it can be taken forward with the **fg** command.
- ctrl+D: Stops the terminal (same as **exit** command)
- Tab: It provides auto-completion. In this case, both the file / directory is available for commands. For example, you may not remember exactly the command you want to use, and you type the first few letters. Once you press the Tab key it will complete that command. If you press the Tab key in a row, it will show all the possible commands starting with letters that you wrote.
- ctrl+H: As Backspace key deletes characters to the left.
- ctrl+R: Search through previously used commands and lets you perform actions as re-use that command.

You can learn these shortcuts we listed above by doing lots of practicing than they become permanat habit.
