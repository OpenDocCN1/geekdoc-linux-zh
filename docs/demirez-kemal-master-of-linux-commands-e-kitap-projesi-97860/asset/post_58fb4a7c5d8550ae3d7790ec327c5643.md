# Whereis

To find the location of the resource files and help files the whereis command should be used. When used without parameters, it gives the location of the executable files and data as output to the help page. If we give the command with the -b parameter, it shows only the location of the executable file, with -m with only the location of the man page, with -s gives the location information of it exists.

```
root@kemal:~# whereis ls
ls: /bin/ls /usr/share/man/man1/ls.1.gz
root@kemal:~# whereis -b ls
ls: /bin/ls
root@kemal:~# whereis -m ls
ls: /usr/share/man/man1/ls.1.gz
root@kemal:~# whereis -s ls
ls:
```

# Didecode

The system hardware components to view information about the BIOS can use dmidecode command. This information, obtained by reading system "DMI" (Desktop Management Interface), general usage patterns of the command is as follows with -t parameter:

- system
- baseboard
- chassis
- processor
- memory
- cache
- connector
- slot

For example dmidecode -t system:

```
root@kemal:~# dmidecode -t system
SMBIOS 2.4
Handle 0x0001, DMI type 1, 25 bytes
System Information
Manufacturer: Hewlett-Packard
Product Name: Compaq nx6110
Version: F484
Serial Number: CNU0010
UUID: ECC5280-CA62-DA90-A106129
Wake-up Type: Power Switch
Status: No errors detected
```

If you want to see CPU information, you should use dmidecode -t 4.

```
root@kemal:~# dmidecode -t 4
SMBIOS 2.4
Handle 0x0004, DMI type 4, 35 bytes
Processor Information
Socket Designation: CPU1
Type: Central Processor
Family: Pentium M
Manufacturer: Intel (R)
ID: 06 00 FF E9
Signature: Type 0, Family 6
```

# Du

To find out the size of the space the subdirectory occupies under a directory, or folder of files on the disk is utilized by du command. It can be used with various parameters to give the result we want the command output.

```
root@kemal:~# du -h --max-depth=1 /
367M    /home
52K     /tmp
11M     /bin
16K     /media
4,0K    /mnt
8,0K    /srv
```

# Hdparm

Get information about the hard disk, **hdparm** command is used. At its most basic **hdparm <drive>** is listed with information about your disk.

```
root@kemal:~# hdparm /dev/sda
/dev/sda:
multcount = 16 (on)
I0support = 1 (32-bit)
readonly = 0 (off)
readahead = 256 (on)
geometry = 4864/255/63, sectors = 78140160, start = 0
```
