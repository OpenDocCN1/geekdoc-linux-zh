We also have another operator which is || operator. If we put this operator between two commands we are using, second command runs if the first command fails. For example, lets try abc || cd /home command:

```
root@kemal:-# abc || cd /home
bash: abc: komut yok
root@kemal:/home#
```

As you see, it runs the second command.

# Bash Shell Configuration Files

There are some configuration files of bash itself. Each user can make some special arrangements with these settings files in their shell. These files are:

+   - /bin/bash (shell itself)
- /etc/profile (the settings file that contains the public profile of the shell)

```
root@kemal:~# cat profile

fi
export PATH

if [ "$BASH" != "bin/sh" ]; then
```
