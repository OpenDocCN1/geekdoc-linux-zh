# Umask

In a linux system, the default access privileges to be assigned to newly created files and directories are determined by the **umask** command. To determine the umask value, we use the **umask command**.

```
root@kemal:~# umask
0022
root@kemal:~# _
```

Generally, this value is 022 in all linux distributions. When you create a file or directory, the default permissions will be as follows according to the umask:

+   - for directories rwx-xr-x (755)
- for files rw-r--r-- (644)

To change the umask value, we use **umask <new_value>** command.
