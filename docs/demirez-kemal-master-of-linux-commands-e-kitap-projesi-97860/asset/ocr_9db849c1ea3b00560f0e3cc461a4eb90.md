We can create an encrypted file with **vim -x <file>** command when we write the file, this will ask a password to the user when he/she try to open the file. Let’s give an example, we have a file named **hacker**. To get the information about our file we use **file hacker** and to see the contents we use **cat hacker** command.

```
root@kemal:-# file hacker
hacker: ASCII text
root@kemal:-# cat hacker
Linux
Windows
Network
Android
Voip
APT
Reverse
root@kemal:-# _
```

Now we encrypt the file with **vim -x hacker** and create a password.

```
Enter same key again: **** _
```
