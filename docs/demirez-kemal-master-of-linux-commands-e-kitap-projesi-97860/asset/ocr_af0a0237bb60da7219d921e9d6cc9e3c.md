Now let's do the opposite, and open the file that we compressed by gzip with gunzip, and the file that we compressed by bzip2 with bunzip2.

```
root@kemal:~/zeyno# ls
example.gz sample.bz2 test
root@kemal:~/zeyno# gunzip example.gz
root@kemal:~/zeyno# bunzip2 sample.bz2
root@kemal:~/zeyno# ls
example sample test
root@kemal:~/zeyno# -
```

We can use both commands at the same time by putting a semicolon between them. Our command would be: gzip example.gz; bzip2 sample.bz2

```
root@kemal:~/zeyno# ls
example.gz sample.bz2 test
root@kemal:~/zeyno# gunzip example.gz ; bzip2 sample.bz2
root@kemal:~/zeyno# ls
example sample test
root@kemal:~/zeyno# -
```
