```
root@kemal:~# cat distro
Kali Debian Whezy
BackTrack Debian Ubuntu
RedHat RPM
root@kemal:~# awk '{print toupper($0)}' distro
KALI DEBIAN WHEEZY
BACKTRACK DEBIAN UBUNTU
REDHAT RPM
root@kemal:~# _
```

Awk not only be used in text files, only can also be used to arrange the command outputs. For example, to list the 1st and 9th areas of the ls -l command output we use ls -l | awk '{print $1,$9}'command.
