::ls

As you can see in the image, pressing enter after use the :ls command there will be a console screen as shown below.

```
root@kemal:~# vim
Belgeler file_B Müzik Videolar zeyno
Downloads Genel Resimler vimtest
file_A Masaüstü Şablonlar vim_usage
```

Here you can return vim editor by pressing enter.

As seen on the example console commands used after “!” symbol. We have given the example of the ls command here, but other commands can be used in this way too. The add the output of the ls command-we used earlier to the location of the cursor in vim editor, we can use :r ls command.
