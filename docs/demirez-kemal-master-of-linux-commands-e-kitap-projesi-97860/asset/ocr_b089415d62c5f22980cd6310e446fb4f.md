To list the lines after 3rd line in a file NR> 3 expression must be.

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk 'NR>3 {print}' test
CentOS
RedHat System Mng.
root@kemal:~#_ _
```

Now let's see how to list the number of lines in a file. For example to find how many record lines in /etc/shadow file, we use awk -'END {print NR}' /etc/shadow command. and we used -F: for lines in file separated by ":".

```
root@kemal:~# awk -F: 'END {print NR}' /etc/shadow
52
root@kemal:~#_ _
```

When we want to see the lines in order with the numbers of the file, for example lines in the test file, we shouduld use awk '{print NR " " $0}' test

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk '{print NR " " $0}' test
1 Linux BackTrack 5
2 Kali Linux 2.0
3 Ethical Hacking
4 CentOS
5 RedHat System Mng.
root@kemal:~#_ _
```
