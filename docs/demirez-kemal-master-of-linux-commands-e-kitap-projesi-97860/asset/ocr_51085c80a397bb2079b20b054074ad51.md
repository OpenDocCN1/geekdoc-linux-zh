With the file command we can also get information about files.

```
root@kemal:~/zeyno# file example
example: empty
root@kemal:~/zeyno# file exampleSYM
exampleSYM: symbolic link to example
root@kemal:~/zeyno#
```

We will end this chapter by mentioning symbolic links (shortcuts) can not be create for only normal files, also can be created for program files, directories.
