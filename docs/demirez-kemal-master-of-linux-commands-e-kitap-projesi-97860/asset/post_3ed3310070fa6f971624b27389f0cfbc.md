# Ping

The ping command is used to see if there is an active address in local network or a remote network. Ping command is used to send ECHO_REQUEST via ICMP protocol.

When the server receives this request it answers, the elapsed time is calculated and displayed to the user. The ping command is generally used to check if the questioned machine is working. If it does not respond to ping requests that means the machine connected remotely may not be working. Ping will also be used to get an estimate of transfer speed between the machines. The communication from the quick responded machine will be faster than the slow responded machine.

When you use the ping command without parameters, it continues to send packages to the target system until you cut the command with CTRL + C. To prevent this you should use the `-c` parameter. For example, with the `ping -c 3 <target_address>` command only 3 question packets will be sent to the destination.

# 242 | nslookup

This command is used to make DNS queries via a DNS server. The simplest query format is checking the IP address with the hostname. Basic usage pattern is as follows: `nslookup [options] [query]`.

When using nslookup without parameters it starts operating in interactive mode. Any queries can be performed in interactive mode too. By default, record queries make straight and reverse process. So if the hostname given IP address of the machine will be queried, the command shows the names of the machine.

```
root@kemal:~# nslookup
> facebook.com
Server:         192.168.1.1
Address:        192.168.1.153

Non-authoritative answer:
Name:             facebook.com
Address:        173.252.120.68
> 173.252.120.68

b.ns.facebook.com internet = 69.171.255.132
> has AAAA 2a63:2888:ffff:face:b00c.35
```

On above example, we make an IP address query from the name first, then the name from the IP address. We use our command without any parameters as nslookup and the `>` mark showed us that the command starts in interactive mode. Then we did our queries. While questioning in interactive mode, you can change the type of questioning at any time. For example:

# 214 | Master of Linux Commands

- NS: Used to view the list of authorized DNS servers for a given area.
- MX: Used to see servers that accept sent-emails for a given domain and server.
- ANY: Used all types of queries to retrieve the required information.
- SOA: Used for getting the information about the person responsible for the domain, the TTL time is used to retrieve information, the serial number of domain etc.

To change the query type in interactive mode "set query query_type" or "set type = query_type" commands should be given.

For example:

```
set query=NS
set query=SOA
set query=ANY
```
