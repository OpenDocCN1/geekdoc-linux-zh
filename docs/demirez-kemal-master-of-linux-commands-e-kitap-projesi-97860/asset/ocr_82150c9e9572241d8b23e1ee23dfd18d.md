Let's do another example of deleting certain lines. This time, for example let's delete 2nd, 3rd and 4th lines. For this we used sed -e "2,4d" test command

```
root@kemal:-# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:-# sed -e "2,4d" test
Linux BackTrack 5
RedHat System Mng.
root@kemal:-#
```

There is a small detail in the examples we have done so far to keep in mind. If we talk how to delete a row that we have done over the last example, the original file has not been a change. Only projected output on console / terminal screen is reflected in the format we use. If you want to make permanent changes, you can direct the command output to another file. For example, if we use commonly used sed -e "2,4d" test > test1, changes we done in test files will be saved by writing in to the file.

```
root@kemal:-# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:-# sed -e "2,4d" test
Linux BackTrack 5
RedHat System Mng.
root@kemal:-# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:-# sed -e "2,4d" test > test1
root@kemal:-# cat test1
Linux BackTrack 5
RedHat System Mng.
root@kemal:-#
```
