```
root@kemal:~# echo $HISTSIZE
1000
root@kemal:~# _
```

As we have seen, there are 1000 commands saved. We can change this value, if we want to. For this in .bashrc file it is sufficient to arrange HISTSIZE = 1000 expression.

We have a method that show us the commands we use earlier and reouse them again, its called reverse search. To use reverse search we must use CTRL + R key combination. When the console is turned on, press these buttons, the display shows (reverse-i-search)': expression. The commands last use is shown on the display with typing these characters and you can use that command again if you want to.

```
(reverse-i-search)'cat': /proc/meminfo
```
