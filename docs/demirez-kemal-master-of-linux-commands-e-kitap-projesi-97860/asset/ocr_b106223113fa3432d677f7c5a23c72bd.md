This command is not only used for to display the user information. For example, the chage command is used to change the user's password expiration date. If we want to end the validity of zeynep's password on November 16, 2015, we must use chage -E 2015/11/16 zeynep command.

# To Make The User Active Or Inactive

To lock a user account or reactivate a locked account we basically use usermod [-L-U] <user> command mold. For example, to lock user account, named deneme, usermod -L deneme, to reactive the account usermod -U deneme must be used. To passive the user account, in /etc/shadow file in encrypted password area, we add exclamation mark (!) at the beginning of the password.

Additional information, if you want to delete the password area belongs to /etc/shadow file, you must use passwd -d <user> command. This process does not deactivate the user. The user can remote connect to the system without asked as password. Therefore, this method is known as rapid user disable method. Or use this if you can prefer account for lists.
