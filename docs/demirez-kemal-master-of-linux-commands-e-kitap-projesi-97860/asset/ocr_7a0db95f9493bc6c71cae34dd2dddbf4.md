After installing the FileZilla program we run the program. We fill the areas (server, user name, password, and port number) on the main screen. We write the connecting system ip number in lieu of the server address. We put 22 as the port number. Ofcourse this should be running SSH service in the system we will connect, means service can listen port with number 22. For this SSH service should be active on the system. (service ssh start) At the same time, we need to know the ip number of the system we will connect to put in as we explained above.
