For example, to change your ip address and subnet mask (netmask) value, you can use the command like ifconfig eth0 192.168.1.12 netmask 255.255.255.0

# Ip Command

We can also use one of the Linux networking commands, the ip command, for making various arrangements. Learning the ip number, to view the routing table, listing the arp cache etc. are some of them.

When we use ip command alone, a help screen about ip commands does

```
root@kem:~ # ip
Usage: ip [ OPTIONS ] OBJECT { COMMAND | help }
ip [ -force ] [-batch file] ...
where OBJECT := { link | add | deladdr | route | rule | neigh | ntable |
tunnel | tuntap | mroute | mrule | monitor | xfrm |
nets | l2tp | tcp metrics | tokens | netconf }
OPTIONS := { -version} [-statistics] [-details] | [-resolve] |
(family) { ipv4 | ipv6 } dnet | bridge | link } |
-4 | -6 | -I | -D | -B | -0 |
-loops | maximum-addr-flush-attempts |
-selline | -t[timestamp] | -b[atch] [filename] |
-rcvbuf [size]
```
