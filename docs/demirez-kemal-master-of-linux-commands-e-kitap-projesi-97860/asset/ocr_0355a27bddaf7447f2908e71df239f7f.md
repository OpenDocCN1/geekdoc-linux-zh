Disk related procedures; transactions with partitioning,

# # Fdisk

Fdisk tool can be used when using disk partitioning tools. Your data
may be accidentally lost. First to see the disk partitions we must
use a command like fdisk -l or fdisk -l /dev/sda.

```
root@kemal:~# fdisk -l
/dev/sda: 31.3 GiB, 3368761920 bytes, 6580160 sectors
Units of sector 1 * 512 = 512 bytes
Sector size (logical/physical): 512 bytes / 512 bytes
/O size (minimum/optimal): 512 bytes / 512 bytes
Disklabel identifier: dos 0x73f4fd4d5
```

| Device | Boot | Start | End | Sectors | Size | Id Type |
| /dev/sda | * | 2948 | 70681151 | 70671964 | 36.6G | 83 | Linux |
| /dev/sdb | | 70681152 | 71399391 | 718239 | 350.194M | 5 | Extended |

If we use the command as fdisk /dev/sda without any
parameters, we will see a screen waiting for command.

```
root@kemal:~# fdisk /dev/sda

Welcome to fdisk (util-linux 2.25.2).
Changes will remain in memory only, until you decide to write them.
Be careful before using the write command.
```

Command (m for help): m

Help:

+   DOS (MBR) toggle a boot flag
a edit nested BSD disklabel
b toggle the dos compatibility flag

+   Generic d delete a partition
l list known partition types
