SHELL: It is the name of the current running shell scripts locations.

For example, you want to program to operate with a command which given directly from the console. Means you don't want to run the command under the directory, you want to add PATH on the line so the appropriate command would work directly. For this you must add the directory to the path. If your program is in /usr/local/prog directory, you can add it to the path by giving the following command:

# PATH=$PATH:usr/local/prog

We said we can also learn the name of the environment variable with the command echo $ PARAMETER_NAME. But let's say we want to change the value of an environment variable. To do this, we use the following command pattern.

```
export PARAMETER_NAME =value
```

If you want to make this change to be permanent in system, you need to include this statement in the .bashre file. Because when the system starts it will open the file and operate by the values of the file.
