# 172 | Master of Linux Commands

Let's give a little info here. To determine the version of Debian, cat /etc/debian_version command can be used.

```
root@kemal:-# cat /etc/debian_version
Kali Linux 2.0
root@kemal:-# _
```

In manual setup, you need to locate and install the appropriate package for your system. So, for software package (package) installed to function properly, your system may need some other packages. This is called dependency (depends). If the program does not work, dependent package of programs must be installed. If these packages already in your system, they will run without problems. To get more information about a package, dpkg --status <package_name> command is used. Let's use dpkg --status opera command to get information about opera browser example we. If you want the command dpkg -s opera can be used as well.
