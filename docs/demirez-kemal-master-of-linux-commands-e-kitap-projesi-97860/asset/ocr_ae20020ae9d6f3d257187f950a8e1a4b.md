# 120 | Master of Linux Commands

```
root@kemal:~# chattr +i users.txt
root@kemal:~# rm users.txt
rm: `users.txt` silinemedi: İşleme izin verilmedi
root@kemal:~# _
```

To list the blocked files like this in the system, we use the lsattr command. If you want to check all files under a directory, you must use lsattr -R <directory> command.

```
root@kemal:~# lsattr
-------e-- /deneme
-------e-- /Downloads
----i----e-- /users.txt
-------e-- /dwhelper
-------e-- /Masaüstü
-------e-- /Belgeler
-------e-- /Genel
-------e-- /Resimler
-------e-- /Şablonlar
-------e-- /Müzik
-------e-- /Videolarn
```

When you pay attention to the list, you will see the letter i in line with users.txt file.

To bring the protected file to previous form we use chattr -i users.txt command.

```
root@kemal:~# chattr -i users.txt
root@kemal:~# _
```
