# Add a New User To the System

When we want to add a new user to the system, there are two scripts that we will use as a base. These commands are adduser and useradd. Basic usage of our first command adduser command is as follows: For example, we want to add a new user named zeynep in the system. We give adduser zeynep command to do this, and we create our user entering information respectively. When we created our users, as previously mentioned, the user of the home directory occurs as /home/zeynep form automatically.

```
root@kemal:~# adduser zeynep
Adding new group `zeynep` (1001) ...
Adding new user `zeynep` (1000) with group `zeynep` ...
Creating home directory `/home/zeynep` ...
Copying files from `/etc/skel` ...
Yeni parolayı girin: 
Yeni parolayı tekrar girin:
password: şifre başarıyla güncellendi
zeynep için kullanıcı bilgileri değiştiriliyor
Yeni değeri girin, veya varsayılan değer için ENTER'a basın
Tam Isim []:
Oda Numarası []:
İş Telefonu []:
Ev Telefonu []:
Diğer []:
Is the information correct? [Y/n] y
root@kemal:~# _
```

As you can see the user's home directory created and the user is included in `zeynep` group.

```
root@kemal:~# cd /home
root@kemal:/home# ls
zeynep
root@kemal:/home# groups zeynep
zeynep : zeynep
root@kemal:/home# _
```
