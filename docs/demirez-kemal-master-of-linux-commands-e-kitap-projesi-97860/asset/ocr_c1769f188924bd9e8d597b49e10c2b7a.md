```
root@kemal:/home# pushd /etc
etc /home
root@kemal:/etc# pushd
/home /etc
root@kemal:/home# pushd
/etc /home
root@kemal:/etc# pushd
/home /etc
root@kemal:/home# _
```

We have two simple examples above. The transition can be made between permanent directory with the command pushd, with popd we can switch the other directories for once and work on them.

```
root@kemal:~# cd /home
root@kemal:/home# pushd /etc
etc /home
root@kemal:/etc# pushd /var
/var /etc /home
root@kemal:/var# popd
/etc /home
root@kemal:/etc# popd
/home
```

To list the open directories, we can use dirs -v command.
