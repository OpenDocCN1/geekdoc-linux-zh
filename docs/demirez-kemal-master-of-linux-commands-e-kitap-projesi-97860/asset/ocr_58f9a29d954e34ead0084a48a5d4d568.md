Above, we talked about something called salt. Now let's see what it is. In linux systems, passwords storages in hash-salt formats. Hash means cryptographic summary. That value determines the user's password, encrypted according to various algorithms, created a new encrypted. This created expression is what we call hash. Now if we come back to the salt, statements that identify a user's password by adding salt value generated randomly, so this new expression is encrypted and written to the shadow file safely. Because this salt value is randomly generated by the system and cannot be estimated by the user, the job of an attacker who wants to crack passwords would be difficult.

Again, let's examine the crypt function mentioned above. Giving man 3 crypt command from the terminal, we can learn about the types of encryption. The output of this command is as follows.

| If salt is a character string starting with the characters "$id$" followed by a string terminated by "$": |
|$id$salt$encrypted |
then instead of using the DES machine, it identifies the encryption method used and this determines how the rest of the password string is interpreted. The following values of id are supported:
| ID | Method |
|---||
| 1 | MDS |
| 2a | Blowfish (not in mainline glibc; in some Linux distributions) |
| 5 | SHA-256 (since glibc 2.7) |
| 6 | SHA-512 (since glibc 2.7) |
So $5$salt$encrypted is an SHA-256 encoded password and $6$salt$encrypted is SHA-512 encoded one. |
