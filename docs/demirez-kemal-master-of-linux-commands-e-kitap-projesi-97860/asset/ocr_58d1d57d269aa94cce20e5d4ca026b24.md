This is the basic way to create a file/document previously saved, Using Vim. If
y want to open a document you have previously saved, this
be done with vim <file> command. Let's create sample file
and open our file with vim.

```
root@kemal:-# man vim > vim_usage
root@kemal:-# ls
Belgeler Genel Müzik Şablonlar vimtest zeyno
Downloads Masaüstü Resimler Videolar vim_usage_
root@kemal:-# vim vim_usage _
```
