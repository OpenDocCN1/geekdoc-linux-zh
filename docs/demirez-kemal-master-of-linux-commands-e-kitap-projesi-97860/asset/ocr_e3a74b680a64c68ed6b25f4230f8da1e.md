# Sftp

File transfers can be done by connecting to a remote server via sftp. Of course it is possible to transfer the files in the local network. File transfer can be made with sftp via secured connection in the systems where SSH connection used. We have seen how to make a ssh connection in the previous topic, and then we talked about copying files with scp. Now, assuming that ssh connection made, let's see how to use sftp.

Basic command usage is sftp user@host (for example, sftp root@kemal) or sftp user@ip_address (sftp root@192.168.43.2).

```
root@porteus:~# sftp root@192.168.43.2
root@192.168.43.2 password:
Connected to 192.168.43.2.
sftp> _
```

As you can see, we need to enter the password first, after that the screen comes up showing that the connection has been made. We can get information about sftp command usage with the help command.
