After you have finished typing you can pass to command mode by pressing the ESC key. INSERT warning in command mode will dissappear and become ready to get the commands we will enter. To give the command, you must use the ":"symbol. Some of the command we can use are:

+   - :q: exit the vim editor this command can be used, but will alert you if you don't save the work.
- :q!: Used to exit without saving the document.
- :wq: used to save the document (saves and remains in vim editor, it does not return to the console)
- :wq: belgeyi Used to exit and save the document. If you did not give a name, for example with :wq test command, it saves your files with the name of test and exits.
