Here's a little reminder. If you are wondering why we use cd
../ cd the above example, we work with root as
home directory (ie /root), with root (/) are very different from
each other. When our home directory zeyno under
home directory we work, /home directory a root directory is
under the root directory (ie/).

```
root@kemal:~# pwd
/root
root@kemal:~# cd /
root@kemal:/# pwd
/
root@kemal:/# cd _
root@kemal:~# _
```

You can not just copy files but you can also copy
directories. To copy a directory we use -r (recursive) parameter.
So we also copy everything under the directory. For example, it
is used as a command cp -r dir1 dir2. We talked about copy
the directory in this section, deleting the indexing and also
would like to explain in the next section.

```
root@kemal:~# cp -r zeyno /home/zeynep
root@kemal:~# cd /home/zeynep
root@kemal:/home/zeynep# ls
KS MATERYAL sample test testA zeyno
root@kemal:/home/zeynep# _
```
