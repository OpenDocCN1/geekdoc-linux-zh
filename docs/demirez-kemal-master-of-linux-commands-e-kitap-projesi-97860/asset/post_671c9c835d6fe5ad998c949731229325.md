- h : show the installation levels

To remove/uninstall the package/program from the system, `rpm -e <package_name>` command can be used. Now lets list rpm commands for Linux users who use RedHat / derivative Linux distribution:

- `rpm -i <program_package.rpm>`: establishing the basic package command
- `rpm -U <program_package.rpm>`: Using the package to update the system
- `rpm -e <program_name>`: To remove package
- `rpm -qa`: To list all packages in the system
- `rpm -qpl <program_package.rpm>`: to list the files in the program package which has not been installed in the system yet
- `rpm -qi <program_name>`: To get information about a package installed in your system

# Apt-Get

We learned how to manually install a program and uninstall it. Now let's see how we can make this process automatically. There are some systems beside the ones we learned so far, which can download programs with all required files and attachments from the program storage and install them in the system automatically. We will talk about apt used by Debian based distributions and the various yum package management system used by Red Hat distributions.

These package management systems download and install the desired programs automatically through internet from the program storages which is called repository or briefly called repos. To find out the storage name where the packages will be downloaded in Debian systems we can use `/etc/apt/sources.list`.

In rpm distribution, storages are located in `/etc/yum.repos.d`.

To install a program, we will use basic commands which is `apt-get install <program_name>`. For RedHat and similar distributions `yum install <program_name>` command should be used for file installation. After using this command, if the programs are in the store, they will be downloaded and installed automatically. If you get the information about the program and if it is in the store the `apt-cache search <prog-name>` command can be used.

```bash
root@kemal:~# apt-cache search bleachbit
bleachbit - delete unnecessary files from the system
root@kemal:~#
```

In the above example we use BleachBit (program for cleaning junk files like Cleaner in Windows), in the storages. Now to install this program to our system, we can use `apt-get install bleachbit` command.
