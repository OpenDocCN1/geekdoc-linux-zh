PID (process id), is the numbers of the processes and provides a kind of communication between the processes in the system.

To see the process associated with a user, pstree <user> command is used. To see a process with sub-processes (child processes), we use pstree <PID> command.

```
root@kemal:~# pstree 968
tracker-store--{dconf worker}
               |--{gdbus}
               |--{gmain}
               |--4*[pool]}
```

# Top

To get an information anout the processes, there is another command which is called top. Despite ps tool, this tool watches the process within sudden changes on them. Working applications in system demands sources depends on their work load, that is why there might be sudden changes. The most basic use of this command is top form. If we use the command top -d 10 than it updates the result every 10 seconds (default value is 3 seconds). To exit, you can press q key.
