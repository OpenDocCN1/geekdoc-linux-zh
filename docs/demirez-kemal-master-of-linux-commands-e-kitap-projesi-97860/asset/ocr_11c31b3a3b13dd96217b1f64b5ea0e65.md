To see the status of ethernet interfaces (link) you can use the ip link command (our system has one).

```
root@kemal:~# ip link
1: <DUPBACK,UP,LOWER,UP> mtu 65536 qdisc noqueue state UNKNOWN mode DEFAULT
    group default
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
2: eth0:<NO-CARRIER,BROADCAST,MULTICAST,UP> mtu 1500 qdisc pfifo fast state DOWN
    mode DEFAULT group default
    link/eth0:5e:6f:95:f1:6c:77 brd ff:ff:ff:ff:ff:ff
3: wlan0:<BROADCAST,MULTICAST,LOWER,UP> mtu 1500 qdisc none state UP DORMANT
    group default qlen 1000
    link/wlan0:5e:6f:fc:e1:ec:ff brd ff:ff:ff:ff:ff:ff
```

route command can be used to view the routing table in the system. A similar command is route command which will be discussed in following chapters.

```
root@kemal:~# ip route
dault via 192.168.43.1/24 wlan0 proto static metric 1024
192.168.43.2/24 wlan0 proto kernel scope link src 192.168.43.2
root@kemal:~# route
Kernel IP routing table
Destination Gateway Genmask Flags Metric Ref Use Iface
default * 192.168.43.1 255.255.255.0 UG 1024 0 0 wlan0
192.168.43.0 * 0 0 0 _
```

If you want to see the arp cache, you can use the command ip neigh.

```
root@kemal:~# ip neigh
192.168.43.8 dev wlan0 lladdr 00:ee:e6:ae:ed:6e STALE
192.168.43.9 dev wlan0 lladdr 00:ee:e6:ae:ed:6e STALE
192.168.43.1 dev wlan0 lladdr 2a:cc:01:ef:17:08 STALE
root@kemal:~#
```
