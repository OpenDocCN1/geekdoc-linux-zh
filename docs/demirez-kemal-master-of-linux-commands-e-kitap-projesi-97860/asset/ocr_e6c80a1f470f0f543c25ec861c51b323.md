# ## Reboot-Halt

We talked about these work level on the linux system, and some of the worrk levels such as **reboot**, **halt** etc. When turning off or restarting our system we can use commands on the operating level, also we can use different commands for these jobs. For example, to turn off the system we can use the **init 0** command. Our system will pass to run level 0 this command and because there is none working service in this level the system will shutdown.

This is not the only command to shut down our system. We can shut down our system using the following commands:

+   - **shutdown -h now** (shuts down directly)
- **shutdown -h now+10** (shuts down 10 minutes later)
- **halt** (shut down begins)

We can use the commands below when we want to restart the system

+   - **reboot**
- **init 6** (passing the 6th working level)
