
# Zcat-Zgrep-Bzcat-Bzgrep

Now let's talk about commands we can use for reading the contents of the compressed file and searching in the contents. As you know we use cat command to read the contents of text files on screen, and grep command to search the contents. Just like this, we use zcat and zgrep commands for compressed files. For example, we can use zcat sample.gz command to read the contents of sample.gz.

```
root@kemal:~zeyno# cat sample
Linux
Kali
Debian
root@kemal:~zeyno# gzip sample
root@kemal:~zeyno# ls
sample.gz test
root@kemal:~zeyno# zcat sample.gz
Linux
Kali
Debian
root@kemal:~zeyno# _
```

We can use a command such as zgrep Ka* sample.gz. to search based on specific criteria of contents of a compressed file,

```
root@kemal:~zeyno# ls
sample.gz test
root@kemal:~zeyno# zgrep Ka* sample.gz
Kali
root@kemal:~zeyno# _
```

These examples for the compressed files that gzip used. If the files compressed by using bzip2 we should use bzcat and bgrep commands.

```
root@kemal:~/zeyno# ls
sample.bz2 test
root@kemal:~/zeyno# bcat sample.bz2
Linux
Kali
Debian
root@kemal:~/zeyno# bzgrep De* sample.bz2
Debian
root@kemal:~/zeyno# _
```

# Unrar-Unzip

Finally let's talk about how to open rar and zip extended files in linux systems. As we know we usually see rar extension files in windows systems and to open these files we usually use winrar program. We have unrar tool in linux system to open this kind of file and usage of this command is very simple. The other zip file can be decompress can be done by unzip tool. Now let's see how to use these commands. Lets open the rar file.

```
root@kemal:~/zeyno# ls
sample test ultrasurface.rar
root@kemal:~/zeyno# unrar x ultrasurface.rar
UNRAR 5.21 freeware Copyright (c) 1993-2015 Alexander Roshal

Extracting ultrasurface.rar
Extracting ultrasurface.exe
All OK
root@kemal:~/zeyno# ls
sample test ultrasurface.exe ultrasurface.rar
root@kemal:~/zeyno# _
```

Now let's create a .zip extension file, to compress it we will use the zip and to open we will use unzip command.

```
root@kemal:~/zeyno# ls
sample test
root@kemal:~/zeyno# zip test.zip test
adding: test (stored 0%)
root@kemal:~/zeyno# ls
sample test test.zip
root@kemal:~/zeyno# unzip test.zip
Archive: test.zip
replace test? [y]es, [n][A]ll, [N]one, [r]ename: r
new name: testA
extracting: testA
root@kemal:~/zeyno# ls
sample test test.zip
root@kemal:~/zeyno#
```

As you can see, the program asked if I wanted to overwrite on existing file and I choose to save the file with the name testA.

# Access Privileges to File and Directory

# Linux has a strong security system for files and directories.

The most important element of this security system is, well established design on the user authority permissions on files and directories. As known, the top authorized users in the system is called root and there are no restrictions for this user. Therefore, if you're working with root user rights on the system operation its better to pay attention.

# Access Privileges

Each user on the system can process within the framework of the authority delegated to him. The users can have three different series of actions on file or directory.

- read (r): Can he/she see the file content? (For folders) can he/she get the file list?
- write (w): Permission of writing to the file and also delete the file. (For folders) Can he/she create files or subfolders within this folder?
- execute (x): Can she/he execute the files? (For folders) Can she/he get in to the folder?

When we examine the list, we see **drwx-xr-x** and **rw-r--** expressions. This encoding, the listed files / directories are showing the current access for users. A directory that you see at the beginning **d**, says it is a directory, - says it is a file. And let's sort the remaining codes, which consists of **rwx-xr-x** and **rw-r--** in three groups.

- rwx-xr-x = rwx r-x
- rw-r-- = rw-r--

First of group (rwx) files / directories with the owners of the second group (r-x), the third group (r--) and other represents the authority of the user. Of course, this applies to the above. For the owner, for the same group as owner r-- and other users will also be shaped to r- as well. Let's do a little summary:

- r: (read) Read permission
- w: (write) Write permission
- x: (execute) execute permission

Now let's look again rwxr-xr-x expression. Then

- rwx: Owner of the file has read, write and execute privileges.
- r-x: The group members where the owner belong read and execute privileges.
- r-- Other users have read and execute privileges.

# Changing Privileges

The process of replacing a file or directory can be made only by the root user. We can do modification of access privileges with chmod command. Usage patterns of this command is as follows: chmod <ugo> <file/directory>

- u: File or directory's owner
- g: Users in the same group with the file or directory (group)
- o: Other users (others)
- a: All
- + : adding authorization
- - : removing authorization
- = : synchronizing authorization
- r: Reading authorization
- w: Writing authorization
- x: operating authorization
- s: Suid bit
- t: Sticky bit

Let's look at a few examples of use.
chmod +r <file_name> (give everyone reading authorization)
chmod +rwx <file_name> (all rights given the owner of the file)

# Master of Linux Commands

chmod o-wx <file_name> (To remove all the rights to read and write from the other users)
chmod u+rw,g+r,o+r <file_name> (give all rights to owner, reading rights to groups, reading rights to other users)
chmod go-rwx <file_name> (remove rwxr authority from group and others)
chmod +x <file_name> (give everyone permission to execute)

Let's see a simple example how to change the permissions. We have a file named users.txt. Let look at the file permissions with ls -l users.txt.

```
root@kemal:~# ls -l users.txt
-rw-r---- 1 root 144 Eyl 18 02:09 users.txt
```

Allow state seems to be -rw-r--. Initial - mark, as we mentioned earlier, indicates that this is a file. If that was d letter we would understand that it was a directory. According to this allowing status, the owner has read and write authority. In all other users we want to give the group and other users write access, we must use chmod go+w users.txt command.

```
root@kemal:~# chmod go+w users.txt
root@kemal:~# ls -l users.txt
-rw-rw-rw- 1 root 144 Eyl 18 02:09 users.txt
```

For example, to remove read permission in this group, and also to remove other users write permission we use chmod g-r,o-w users.txt command.

```
root@kemal:-# ls -l users.txt
-rw-rw-rw-- 1 root root 144 Eyl 18 02:09 users.txt
root@kemal:-# chmod g-r,o-w users.txt
root@kemal:-# ls -l users.txt
-rw-rw-r-- 1 root root 144 Eyl 18 02:09 users.txt
```

We use the chmod command to edit authorization, we may use it for more practical format. We do this process with express the authorities in numerical mode. Digital equivalents of authorization showing the mold situation are like below.

# file owner groupmates with the file owner other users

| owner | groupmates | other users |
|---|---|---|
| r = 4 | r = 4 | r = 4 |
| w = 2 | w = 2 | w = 2 |
| x = 1 | x = 1 | x = 1 |

According to matching above we can use 7 (4+2+1) instead of rwx. Just like this, we can use 777 instead of rwxrwxrx, 700 instead of rwx------, 755 instead of rwx-xr-x. (r-x=4+0+1, rw-=4+2+0, r=-4+0+0)

For example, we have a file named deneme, and lets give all the permissions on this file (rwx). For this, we use chmod 777 deneme command.

```
root@kemal:-# ls -l deneme
-rw-r-r-- 1 root root 144 Eyl 21 00:27 deneme
root@kemal:-# chmod 777 deneme
root@kemal:-# ls -l deneme
-rwxrwxwx 1 root root 0 Eyl 21 00:27 deneme
```
