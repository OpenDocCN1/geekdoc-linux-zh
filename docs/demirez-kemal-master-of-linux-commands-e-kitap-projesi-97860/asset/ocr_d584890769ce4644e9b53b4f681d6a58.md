Because of datas were written randomly, datas terminated in a safe manner. Now you can format your usb disc to work more efficient.

Lets say you have a CD and you want to copy it in iso format. For this, you need to use dd if=/dev/cdrom of=/mycd.iso command. I insert Porteus Linux to my system and I want to copy the contents with iso and name porteus.iso. I must use dd if=/dev/cdrom of=/porteus.iso command for this.

```
root@kemal:~# cd /media/cdrom
root@kemal:/media/cdrom# ls
boot porteus USB INSTALLATION.txt
root@kemal:/media/cdrom# _
```

```
root@kemal:~# dd if=/dev/cdrom of=/porteus.iso
d dd: /dev/cdrom'i okunurken hata: Girdi/Çıktı hatası
514640+0 records in
514640+0 records out
263495680 bytes (23 MB) copied, 128,791 s, 2,0 MB/
```

Now, check our porteus.iso file.

```
root@kemal:~# ls -l /porteus.iso
-rw-r--r-- 1 root root 263495680 Kas 26 20:56 /porteus.iso
root@kemal:~# file /porteus.iso
/porteus.iso: ISO 9660 CD-ROM files data 'Porteus' (bootable)
root@kemal:~# _
```
