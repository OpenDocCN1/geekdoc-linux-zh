To examine the contents of the one program’s package installed in the system dpkg -L <program_name> command should be used.

```
root@kemal:~# dpkg -L gedit
./n/usr/lib
```

When we need to modify the configuration settings for one pack we need to use dpkg-reconfigure command.

We learned how we can install programs from packages manually. Now let's see, how to uninstall a program from the system. The most basic way to uninstall a program from your system, using dpkg --purge remove <program_name> command, dpkg --purge <program_name> can be used as well. In this way, the program will be removed with all the files in it. Now let's remove Opera browser from the system which we installed earlier. We are using dpkg -P opera command.
