There are some operators and indicators that we can use awk in text files. Example, && operator means and, || operator means or. Let's say, we want to see the lines with Kali Debian in distro files from previous examples, we should use awk '/Kali/ && /Debian/' command for this. If we want to bring the lines using Ubuntu or Red Hat in, we will use awk '/Ubuntu/ || /RedHat/' distro command.

```
root@kemal:-# cat distro
Kali Debian Whezy
BackTrack Debian Ubuntu
RedHat RPM
root@kemal:-# awk '/Kali/ && /Debian/' distro
Kali Debian Whezy
root@kemal:-# awk '/Ubuntu/ || /RedHat/' distro
BackTrack Debian Ubuntu
RedHat RPM
root@kemal:-# _
```

In order to get the records without Debian, we use awk '!/Debian/' distro command.

```
root@kemal:-# cat distro
Kali Debian Whezy
BackTrack Debian Ubuntu
RedHat RPM
root@kemal:-# awk '!/Debian/' distro
RedHat RPM
root@kemal:-# _
```

If we want to change our characters to uppercase characters in our file we use awk '{print toupper($0)} mold.
