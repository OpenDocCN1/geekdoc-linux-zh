# Alt+F2

Using Alt + F2 to open a box allowing us to run programs and commands and typing gnome-terminal in the box we can also open the command line. In fact, the shortcut we assigned Ctrl + Alt + T key is a shortcut of this command.

# Bash Shell Shortcuts

When using the bash shell (writing the script) some shortcuts can simplifies our work. Most of these shortcuts are listed below. You can be more practical with exercising them frequently.

+   - ctrl+A: Move the cursor to the beginning of the line.
- ctrl+E: Move the cursor to the end of the line.
- ctrl+B: The cursor goes one character back.
- ctrl+F: The cursor goes one character further.
- alt+B: The cursor goes one word back.
- alt+F: The cursor goes one word further.
- ctrl+XX: The cursor goes and returns from its location to beginning of the line.
- ctrl+L: Clears the screen and the cursor goes all the way to the top (same as clear command)
- ctrl+U: Everything left of the cursor will be deleted.
