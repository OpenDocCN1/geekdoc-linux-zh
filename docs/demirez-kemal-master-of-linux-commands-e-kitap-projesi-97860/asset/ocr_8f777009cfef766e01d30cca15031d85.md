# Hard Link

In command is used for hard link connectivity. Now let's create one file and make a hard link to this file.

```
root@kemal:~/zeyno# ls
root@kemal:~/zeyno# touch test
root@kemal:~/zeyno# ls
test
root@kemal:~/zeyno# ln test testlink
root@kemal:~/zeyno# ls
test testlink
root@kemal:~/zeyno# ls -i test testlink
1975922 test 1975922 testlink
root@kemal:~/zeyno# _
```

As is seen in the above example, first we create a file called test with touch test command. After that we created a hard link called testlink with In testlink command.. Then we look at the inode of the file with ls - test testlink command and we saw the same inode number. We acually said files created by hard link are the same files. When any data added to a file's contents, this data must be added to the other files automatically. Let's try. Now let's write some expressions into test file and check other files made two hard link.

```
root@kemal:~/zeyno# test testlink
root@kemal:~/zeyno# echo "linux commands" > test
root@kemal:~/zeyno# cat test
linux commands
root@kemal:~/zeyno# cat testlink
linux commands
root@kemal:~/zeyno# _
```
