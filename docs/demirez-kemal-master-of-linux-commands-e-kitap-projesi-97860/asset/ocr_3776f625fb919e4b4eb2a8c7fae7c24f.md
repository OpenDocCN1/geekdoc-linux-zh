# Chattr

Sometimes you can delete a file by mistake. Or you can edit the configuration file, but when the system is restored, you will see that you edited settings disappear. To avoid situations like these chatter command is available. Lets explain it with an example. For example, we have a file called users.txt, and do not want to make any changes on this file. Even as the root user if we try to make a change by mistake, you will be blocking. For this, we use chattr +i users.txt command.
