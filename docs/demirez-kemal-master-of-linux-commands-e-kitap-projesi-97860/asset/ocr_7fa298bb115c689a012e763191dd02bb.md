If you want to know the use of previously used commands, statements about the need to write about the terminal command "<Command>:p" must be maintained. Thus, it will be printed to form display command that was previously used.

```
root@kemal:~# !cat:p
cat /proc/meminfo
root@kemal:~# _
```

If you do not want to list all of the commands, but use for example last 5 of them, you should use history 5 command.

```
root@kemal:~# history 5
255 cd
256 ls && /etc
257 cd
258 cat /proc/meminfo
259 history 5
root@kemal:~# _
```
