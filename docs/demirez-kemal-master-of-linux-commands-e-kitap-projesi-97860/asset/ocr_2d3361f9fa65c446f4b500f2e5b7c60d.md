The dot (.) As indicated by the point would be stated that there can be any character.

```
root@kemal:~# cat test
adana
ankara
konya
izmir
root@kemal:~# grep a.a test
adana
ankara
root@kemal:~#
```

The asterisk (*) Refers to any character in any number.

^ : It corresponds to the beginning of the line.
$ : It refers to the last row.

```
root@kemal:~# cat /etc/passwd | grep bash$
root:x:0:0:root:/bin/bash
postgresql:x:122:122:PostgreSQL administrator,,,/var/lib/postgresql:/bin/bash
zeynep:x:1000:1001,,,/home/zeynep:/bin/bash
root@kemal:~#
```

[^.] With the exception of the characters in the cluster corresponds to any character.

```
root@kemal:~# cat test
adana
ankara
konya
izmir
123
456
789
root@kemal:~# cat test | grep [^0-9]
adana
ankara
konya
izmir
root@kemal:~# ~
```
