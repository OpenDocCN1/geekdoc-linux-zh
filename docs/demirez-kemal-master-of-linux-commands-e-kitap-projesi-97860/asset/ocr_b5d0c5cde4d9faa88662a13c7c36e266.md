# Changing the Privileges

The process of replacing a file or directory can be made only by the root user. We can do the modification of access privileges with chmod command. Usage patterns of this command is as follows: chmod <ugo> +--> <rwx> <file/directory>

+   - u: File or directory's owner
- g: Users in the same group with the file or directory owner(group)
- o: Other users (others)
- a: All
- + : adding authorization
- - : removing authorization
- = : synchronizing authorization
- r: Reading authorization
- w: Writing authorization
- x: operating authorization
- s: Suid bit
- t: Sticky bit

Let's look at a few examples of use.
chmod +r <file_name> (give everyone reading authorization)
chmod u+rwx <file_name> (all rights given the owner of the file)
