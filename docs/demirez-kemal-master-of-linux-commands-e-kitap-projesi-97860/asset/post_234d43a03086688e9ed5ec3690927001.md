One of the important file is messages file. A lot of records about system events are kept in this file. To see the records live written on messages files, you can use tail -f /var/log/messages command.


## Dmesg

The system sends notes to the kernel. These notes are written in kernel log buffer. To see these kernel log messages we use dmesg.

```
root@kemma:~# dmesg
000000 Initializing cgroup subsystems cgroup
000000 Initializing cgroup subsystems cpuset
000000 Initializing cgroup subsystems cpuacct
000000 Linux version 4.4.0-111-x86 (debian-kernel-lists@debian.org)
(gcc version 4.9.3-10ubuntu1) (gcc 4.9.0) SMP 4.4.0-111+li2 (2015-06-03)

000000 Disabled fast startup probe
000000 BIOS-e820: mem 0x0000000000000000-0x00000000ffffffff usable
000000 BIOS-e820: mem 0x0000000100000000-0x00000001ffffffff reserved
000000 BIOS-e820: mem 0x0000000200000000-0x00000002ffffffff reserved
000000 BIOS-e820: mem 0x0000000300000000-0x00000003ffffffff usable
```

Of course, if you want to list the kernel messages based on any criteria you can use dmesg. For example dmesg | grep fail. You can also use dmesg -c to delete kernel log records.

```
root@kemal:~# dmesg -c
root@kemal:~# dmesg
root@kemal:~# _
```

## Last

To list the users who open the last session in the system, you can use last command.

```
root@kemal:~# last
root pts/0          :0 Mon Nov 23 00:01 still logged in
root pts/1          :0 Sun Nov 22 21:49 - 00:03 (02:14)
root pts/0          :0 Sun Nov 22 20:58 - 22:09 (01:11)
root pts/0          :0 Sun Nov 22 20:57 - 20:58 (00:01)
root pts/1          :0 Sun Nov 22 18:26 - 20:58 (02:31)
root                 :0 Sun Nov 22 18:24 still logged in
(unknown)            :0 Sun Nov 22 18:23 - 18:23 (00:00)
reboot system boot  4.0.0-kalil-686- Sun Nov 22 18:23 - 00:19 (05:56)
root pts/0          :0 Sun Nov 22 12:09 - 12:10 (00:00)
```

For example, you want to see the list of last 3 users who login to the system last last -3 command can be used,

```
root@kemal:~# last -3
root pts/0          :0
root pts/1          :0
root pts/0          :0
```

wtmp begins Sun Nov 22 11:07:09 2015

To view the last login information about any user last <user_name> can be used.

## Btmp

The error log file entries are kept in btmp file. This file is a data file, we can use printable list of the contents in the file by using strings btmp command.

![](img/aa6ce54dbb8ffe5b9d7befb8c6764064_276_0.png)

```
root@kemal:/var/log# file btmp
btmp: dBase III DBT, version number 0, next free block index 7
root@kemal:/var/log# strings btmp
root
uuARVeY
guest
root@kemal:/var/log# _
```

## Lastlog

See the addresses when users open sessions we can use lastlog command. Of course, those users could be people who use the system services. That shows the information about the users run the services and address information. For any user’s information lastlog <user_name> can be used.

## Utmp

The utmp file contains information about users currently logged into the system. To view this information we can use the last command.

```
root@kemal:~# last
```

The wtmp file contains information about users who logged in the past. To view this information we can use the last command.

The btmp file contains information about failed login attempts. To view this information we can use the last -f command.

The lastlog file contains the last time each user logged in. To view this information we can use the lastlog command.
