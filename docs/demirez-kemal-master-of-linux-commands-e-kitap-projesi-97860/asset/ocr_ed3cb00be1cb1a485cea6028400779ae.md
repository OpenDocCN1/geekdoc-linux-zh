There are several commands to get the relevant information with files stored in our system about processes, users, etc. Let's see what are those commands.

# Lsb Release

To find out the Linux distribution name that we have, we use lsb_release -a command.

```
root@kemal:-# lsb_release -a
No LSB modules are available.
Distributor ID: Kali
Description: Kali GNU/Linux 2.0
Release: 2.0
Codename: sana
```

A similar command is cat /etc/*release command. With this we can get a little more information about our system.

```
root@kemal:-# cat /etc/*release
DISTRIB_ID=Kali
DISTRIB_RELEASE=2.0
DISTRIB_DENAME=sana
DISTRIB_DESCRIPTION="Kali GNU/Linux 2.0"
PRETTY_NAME="Kali GNU/Linux 2.0 (sana)"
NAME="Kali GNU/Linux"
ID=kali
VERSION="2.0 (sana)"
VERSION_ID="2.0"
ID_LIKE=debian
ANSI_COLOR="1;31"
HOME_URL="http://www.kali.org/"
SUPPORT_URL="http://forums.kali.org/"
BUG_REPORT_URL="http://bugs.kali.org/"
root@kemal:-# _
```
