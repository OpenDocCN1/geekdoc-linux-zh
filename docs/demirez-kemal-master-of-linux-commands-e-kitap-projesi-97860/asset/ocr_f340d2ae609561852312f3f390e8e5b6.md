First, we can create a shortcut key combination to open the terminal. This is the menu for the system settings (Kali 2.0) keyboard and we choose the keyboard and open the shortcut menu.

| Yazma | Kısayollar | |
|---|---|---|
| Başlatıcılar | Yardım çalıştır | Kapalı |
| Ekran Görüntüleri | Ayarlar | Tool |
| Evsel Erişim | Hesap makinesini çalıştır | Calculator |
| Geinti | E-posta istemcisini çalıştır | Mail |
| Pencereler | Web tarayıcısını çalıştır | WWW |
| Ses ve Ortam | Ev Klasörü | Explorer |
| Sistem | Arama | Search |
| Yazma | | |
| Özel Kısayollar | + | |

Bir kısayolu düzenlemek için, ilgili satıra tıklayın ve tuşlara da temizlemek için Backspace tuşuna basın.

To fix the new shortcut, click on the + sign on the bottom side. We organize pop-up box as below.

![](bbox=[0.196, 0.573, 0.636, 0.715])

After editing this way, we press the Add button. The main screen opens after this and we see a line with Terminal Closed written. After right-click on this line, New accelerator.. warning appears, we use the ctrl + alt + T on keyboard as we assigned terminal shortcut to these keys. We can now easily open a Linux terminal using this key combination.
