NS: Used to view the list of authorized DNS servers for a given area.

MX: Used to see servers that accept sent e-mails for a given domain and server.

ANY: Used all types of queries to retrieve the required information.

SOA: Used for getting the information about the person responsible for the domain, the TTL time is used to retrieve information, the serial number of domain etc.

To change the qerry type in interactive mode "set query query_type" or "set type = query_type" commands should be given.

For example:

set query=NS
set query=SOA
set query=ANY

```
root@kemal:~# nslookup
> set type=mx
> twitter.com           192.168.1.1
```
