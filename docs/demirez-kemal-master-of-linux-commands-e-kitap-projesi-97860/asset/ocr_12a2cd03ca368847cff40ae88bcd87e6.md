# Rm

Command used in the deletion of files and directories is the rm command. With this command, as we can delete a single file, we also can delete many files at a time.

```
root@kemal:~/zyno# ls
deneme issue sample.txt test testA
root@kemal:~/zyno# rm issue sample.txt testA
root@kemal:~/zyno# ls
deneme program test zyno#nroot@kemal:~/zyno# _
```

I will explain directory deletion in the next section that is why not mention here. You can also use wildcards with this command to do different things. For example, you can use the rm /directory/*.txt command to delete the file with .txt extension under a directory.

# Shred

To delete files in a secure manner, we can use shred command. With this command, we want to delete the destination file by writing random bits are trying to prevent the rescue. Without using parameters, it writes randomly on the target file 3 times, but with -n parameter on the file, we can specify how many times it will be written. If we use -u, the target file is deleted at the end of the process. To see the transaction detailed output on the terminal, -v is used. Basically, this is how it works. Now let's do some examples. For example, the file named deneme, writing random data on it with shred, try to block the rescue. If we want to the writing process works for 10 times, we can use shred -n 10 -v deneme command.
