# FileZilla

If both systems are Linux it's very easy and safe to transfer files with sftp between them. But if you want to transfer files from a Windows system to Linux system using a visual interface, you can use the **FileZilla ftp client** software program.

You can download appropriate version of filezilla client program from **www.filezilla-project.org** address.
