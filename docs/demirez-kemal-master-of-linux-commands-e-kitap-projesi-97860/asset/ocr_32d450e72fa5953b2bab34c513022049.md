We use the chmod command to edit authorization, we may use it for more practical format. We do this process with express the authorities in numerical mode. Digital equivalents of authorization showing the mold situation are like below.

# file owner groupmates with the file owner other users

| r = 4 | r = 4 | r = 4 |
|---|---|--|
| w = 2 | w = 2 | w = 2 |
| x = 1 | x = 1 | x = 1 |

According to matching above we can use 7 (4+2+1) instead of rwx. Just like this, we can use 777 instead of rwxrwxrx, 700 instead of rwx------, 755 instead of rwx-xr-x. (r-x=4+0+1, rw-=4+2+0, r=-4+0+0, --x=0+0+1)

For example, we have a file named deneme, and lets give all the permissions on this file (rwx). For this, we use chmod 777 deneme command.

```
root@kemal:-# ls -l deneme
-rw-r-r-- 1 root root 0 Eyl 21 00:27 deneme
root@kemal:-# chmod 777 deneme
root@kemal:-# ls -l deneme
-rwxrwxwx 1 root root 0 Eyl 21 00:27 deneme
```
