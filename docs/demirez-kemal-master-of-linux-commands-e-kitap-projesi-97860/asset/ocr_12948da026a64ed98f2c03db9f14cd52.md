# Lsof

We can use the lsof command to list the files opened by processes. It will show a long list when using without a parametr. If you use -Pni parameter (list of active connections and not to do port and hostname resolutions) you get similar to the following.

```
root@kemal:~# lsof -Pni
COMMAND PID USER TYPE DEVICE SIZE/DEF MODE NAME
inetd 517 root IPv4 12948 0t8 UDP *:69
avahi-dae 721 avahi 12u IPv4 15706 0t8 UDP *:53553
avahi-dae 721 avahi 13u IPv6 15787 0t8 UDP *:53553
avahi-dae 721 avahi 14u IPv4 15788 0t8 UDP *:37768
avahi-dae 721 avahi 15u IPv6 15789 0t8 UDP *:33841
mysqld 4962 mysql 10u IPv4 62092 0t8 TCP 127.0.0.1:3306 (LISTEN)
root@kemal:~# _
```
