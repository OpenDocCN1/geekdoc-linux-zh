In the above, the MySQL service is active and seems to listen to port information. Now, stop the MySQL service and examine again.

```
root@kemal:~# service mysql stop
root@kemal:~# lsof -Pni
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
inet 517 root 4u IPv4 12940 0to UDP :69
avaahi-dei 721 avahi 12u IPv4 15786 0to UDP :5353
avaahi-dei 721 avahi 13u IPv4 15787 0to UDP :5353
avaahi-dei 721 avahi 14u IPv4 15788 0to UDP :37708
avaahi-dei 721 avahi 15u IPv4 15789 0to UDP :33841
root@kemal:~#
```

As we have seen MySQL service that stop, the service no longer appears in the list. To see the activity on a specific port instead of all ports and connections lsof -i:<port_num>command can be used. Lsof -i: 20-200 command can be used to list service activities in particular part. (Here we mean between 20. and 200, ports)

```
root@kemal:~# service mysql start
root@kemal:~# lsof -i :3306
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
ysqld 576 mysql 10u IPv4 72157 0to TCP localhost:mysql(LISTEN)
root@kemal:~#
```

To see the users and process that can access the specified directory, for example to see the access files under /var/log directory, we use lsof +d /var/log command.

```
root@kemal:~# lsof +d /var/log
```
