We see that Apache is not working. Lets check it out with de-service apache2 status command.

```
root@kemal:~# service apache2 status
● apache2.service - LSB: Apache2 web server
Loaded: loaded (/etc/init.d/apache2)
Active: inactive (dead)
root@kemal:~#
```

Now run the Apache service.

```
root@kemal:~# service apache2 start
root@kemal:~# service apache2 status
● apache2.service - LSB: Apache2 web server
Loaded: loaded (/etc/init.d/apache2)
Active: active (running) since Pr 2015-08-27 02:10:45 I
Process: 5705 ExecStart=/etc/init.d/apache2 start (code=\SS)
Group: /system.slice/apache2.service
-5719 /usr/sbin/apache2 -k start
-5723 /usr/sbin/apache2 -k start
-5724 /usr/sbin/apache2 -k start
-5726 /usr/sbin/apache2 -k start
```

We ran our service, we check the sign on the screen that lists all the services again with service --status-all command.

```
root@kemal:~# service --status-all
[ ] anacron
[ + ] apache2
```
