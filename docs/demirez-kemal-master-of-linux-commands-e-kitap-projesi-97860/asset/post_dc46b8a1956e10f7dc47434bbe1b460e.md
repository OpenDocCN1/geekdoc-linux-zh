# Authorized Keys

There is an arrangement we can make which will allow us to connect to Kali system without password. We have created an encrypted key in Porteus and save this under .ssh in Kali. Now we're going to .ssh directory with cat id_rsa.pub > authorized_keys we will copy this key in authorized_keys file (File will be created with this command if it is not kind of file in your system, be sure to use routing operator as to prevent overwrite on existing data).

```
root@kemal:~# cd .ssh
root@kemal/.ssh ls id_rsa.pub known hosts
root@kemal/.ssh cat id_rsa.pub > authorized_keys
root@kemal/.ssh cd

# Sftp

File transfers can be done by connecting to a remote server via sftp. Of course it is possible to transfer the files in the local network. File transfer can be made with sftp via secured connection in the systems where SSH used. We have seen how to make a ssh connection in the previous topic, and then talked about copying files with scp. Now, assuming that ssh connection made, let's see how to use sftp. Basic command usage is sftp user@host (for example, sftp root@kemal) or sftp user@ip_address (sftp root@192.168.43.2).

```
root@porteus:~# sftp root@192.168.43.2
root@192.168.43.2's password:
Connected to 192.168.43.2.
