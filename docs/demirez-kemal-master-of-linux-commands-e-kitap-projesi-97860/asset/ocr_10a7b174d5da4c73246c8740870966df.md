To use a command listed in these commands from the terminal again, its sufficient that we can put ! sign to the left of the command. For example, I listed my screen commands from the terminal number 215 cd /home command, to use it again I have to give !215 command.

```
root@kemal:~# !215
cd /home
root@kemal:/home# _
```

If you want to reuse the command that you use the latest, you must give the command !! for that

```
root@kemal:~# !!
cd
root@kemal:~# _
```

For use in the same way a command that used before, ! sign should be placed to the left of the command. For example, if you want to use the cat command in the same way, you have to give the !cat command.
