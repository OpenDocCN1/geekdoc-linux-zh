# 260 | Master of Linux Commands

As soon as the connection is established it means we are working on remote system. When we use ls command we list the files on the connected system, with lls command we list the files in our system.

```
sftp ls
Desktop Documents Downloads
sftp ls
Belgeler General Masallı
Downloads Resimer Videoolar VirtualBox VMs
Muriza fotololar.tar.gz test
deneme Şablonlar
sftp |
```

Two commands used for file transfer. These commands are put and get commands. To copy the file on connected system we use put command and copy a file in our system we get command. For example, to copy important.txt file we have in our computer to connected computer we use put /root/Desktop/important.txt /root command.

```
sftp> put /root/Desktop/important.txt /root
Uploading /root/Desktop/important.txt to /root/important.txt
/root/Desktop/important.txt 100% 0 0.0KB/s 00:00
sftp> |
```

When we use ls command to check the list, we can see important.txt file is in the list.

```
sftp> ls Downloads Genel
Belgeler Resimer Videoolar
Müzik fotololar.tar.gz important.txt
deneme
Şablonlar
sftp> |
```

To copy the test file (which is saved on connected computer) to our computer we should use get /root/test /root/Desktop command.
