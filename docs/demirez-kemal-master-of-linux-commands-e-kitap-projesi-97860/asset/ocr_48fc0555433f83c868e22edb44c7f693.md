In the linux world, everything (programs, files, devices) is located in the sub-directories / files under a directory view. All directories, hierarchically connected in the **root directory**. This is expressed as root directory / (slash). Each users have their own **home** directories, including linux system root. **Console / terminal** starts to work on the user's own directory by default. Root's home directory is **/root** directory. When a new user is added to the system, the home directory of the user will place under (personal directory) / **home** directory as /home/user1, /home/user2.

Navigating between directories, to list their contents, see which directory we are working on there are some commands. Let's see these commands.

# # Pwd

To view the directory in which we work, we use `pwd` command. If you ask why we would want to know, if you use a linux system as personel, then yes, no need to worry which you work with. But if you are a system administrator which has many users, sometimes you may need to use the **pwd** command. 

```
root@kemal:~# pwd
/root
root@kemal:~# cd /home
root@kemal:/home# pwd
/home
```
