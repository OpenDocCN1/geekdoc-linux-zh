The number between the first $ character and second $ charater shows which encryption algorithm used.

+   - If it is 1 algorithm is MDF
- If it is 2 algorithm is Blowfish
- If it is 5 algorithm is SHA-256
- If it is 6 algorithm is SHA-512

It indicates that encryption algorithm.

If the MD5 algorithm is used, the salt value of the second $ with third $ mark only the incoming password, the length of the string representing the encrypted version of 22 characters, if SHA-256 is used than 43 character, if SHA-512 is used than 86 characters.
