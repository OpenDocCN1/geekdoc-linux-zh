You can work on two the files in the Vim editor at the same time. For example, using vim <file_1> <file_2> command, you first start working with a file file_1. When you are want to work with other file you can use ": next (n)" command and start working on second file. To switch back to the previous file, you can use ":previous" command. For example, let's open file_A and file_B together with vim file_A file_B.

You can use /search-word command directly in the file to find a word. The cursor goes over the words you searched for.

```
VIEW
gvim gview
evim eview
rvim rview
rgvim rgview
```

DESCRIPTION
Vim is a text editor that it can be used to edit all especially useful for edit /gvim

When you search the text, to eliminate small/upper case sensitivity use :set command.

Finally, vim editor configuration file is vimrc File. The “ symbol at the beginning of the line shows it is a comment line. If you remove “ symbol the setting in this file will be activated. Any arrangement can be made easily accordingly.

```

" set ignorecase Do case insensitive matching

" setsearch Incremental search
" set autowrite Automatically before commands like :next
and :make
" set hidden Hide buffers when they are abandoned
" set mouse Enable mouse usage (all modes)
" Source a global configuration file if available
if filereadable("/etc/vim/vimrc.local")
" source /etc/vim/vimrc.local
defif
```
