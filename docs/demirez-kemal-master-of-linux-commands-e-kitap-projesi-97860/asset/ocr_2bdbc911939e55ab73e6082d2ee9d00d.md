For example with ^ B. * x S, we can find expressions starts the line with B and ends with x.

```
root@kemal:~# cat test
Zeynep
kemal
Ceren
cenK
Zengin
Best of Linux
root@kemal:~# grep ^B.*x$ test
Best of Linux
root@kemal:~# _
```
