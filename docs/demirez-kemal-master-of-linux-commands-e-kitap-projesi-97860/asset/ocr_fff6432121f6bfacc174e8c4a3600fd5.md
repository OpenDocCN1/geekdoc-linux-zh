return to the session X, Ctrl + Alt + F7 is used. Yes, we can open 6 virtual terminal from F1-F6. If the system is in use, <ctrl + alt + Fn>(n = 7, ..., 12) can also switch between X servers.

# Simultaneous Use of MultiplenCommands On the Command Line

In terminal / console, you can use multiple commands simultaneously. To do this, simply use semicolon to separate the commands. For example, ls /etc output of the command will be as follows:

```
root@kemal:-# ls /etc
Belgeler dhelper Masaüstü Resimler Videolar
Downloads Genel Müzik Şablonlar
adduser.conf ImageMagick-6 iceweasel
adjime profile.d
alias idmapd.conf proxychains.conf
alternatives ifplugd intd.conf all
amap purple
anfforontab initsim python
apache2 init python2.7
apg.conf init.d
apm init.d-initramfs-tools python3
```

To run multiple commands, && operator can be used as well. This operator used a lot during system update operator. For example, when apt-get update && apt-get upgrade commands are given executing commands and systems will be updated. Now let's ls && cd /etc make an example, and look at the output of the command.

```
root@kemal:-# ls && cd /etc
Belgeler dhelper Masaüstü Resimler Videolar
Downloads Genel Müzik Şablonlar
root@kemal:/etc# -
```
