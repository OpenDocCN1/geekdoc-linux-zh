At the same time, all the things you can do with apt-get you can also do with aptitude command. Like aptitude update, aptitude upgrade, aptitude install. Aptitude carries more advanced features the apt-get, When doing an installation package in the default settings aptitude also installs the recommended packages. By changing the settings Aptitude, It also can download the usefull packages for that program.
