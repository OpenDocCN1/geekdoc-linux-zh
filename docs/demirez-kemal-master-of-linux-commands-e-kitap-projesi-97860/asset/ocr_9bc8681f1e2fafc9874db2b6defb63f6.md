# 26 | Master of Linux Commands

Linux systems have very strong support system. There is a large help documentation which includes using the parameters of the command arguments on the command line and/or how to use an application. Usually help subjects come with applications which are already installed or newly set up. There are some options that you can get help while using the commands. You can use these help documents when you struggle with commands.

# Help

You can get information about how to use Is command using Is --help that we will explain later.

```
root@kernel:~# ls --help
Kullan: ls [SECKEN] [DOSYA]...
List information about the FILES (the current directory by default).
Sort entries alphabetically if none of -ctftux nor --sort is specified.
Mandatory arguments to long options are mandatory for short options .
-a, --all do not ignore entries starting with .
-A, --almost-all do not list implied . and .
--author with -l, print the author of each file
-b, --escape print-style=escapes for nongraphic characters
scale size=SIZE before printing them; e.g.,
--block-size=SIZE prints sizes in units of 
1,048,576 bytes; see SIZE format below
-B, --ignore-backups do not list implied entries ending with ~
```

You can get help either this or like help <command>
