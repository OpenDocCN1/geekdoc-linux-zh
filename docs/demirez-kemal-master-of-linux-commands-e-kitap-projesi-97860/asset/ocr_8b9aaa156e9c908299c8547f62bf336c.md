# Tcpdump

To view the connections made to our system and/or connections made from our system tcpdump command can be used. By using this command, connection requests should be taken and will be displayed on the console. So it captures and shows the packages on the network. You can also review recorded packages. The below example shows the command usage with n parameter which capture packets without making address resolution.
