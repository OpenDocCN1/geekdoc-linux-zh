# Suid Bit

Each user can perform actions on the extent of their authority in the system. Sometimes it may be necessary for a normal user with root user rights temporarily. So normally the root user is able to run the program, if suid bit is set up, when other users want to use this program, as long as the program works, it runs with owners authorities. With a clearer expression, a user who wants to use the program but not have the authority, will need suid bit to run the program temporarily.

To set SUID bit, chmod u+s <file_name> command is used. To find the files which have suid bit, we use find / -perm -4000 command.
