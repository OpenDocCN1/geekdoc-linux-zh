# Fsck

Bad blocks-areas on a disc are tried to be fixed by fsck tool.
When our system is first open this tool works at background and
automatically checks its disk.

For example to fix errors in our usb memory stick we can use
fdisk -p /dev/sdb commands. We will see in the upcoming
issue, when using such tools we must first take the disk apart
from the system.

```
root@kemal:-# fsck -p /dev/sdb
fsck from util-linux 2.25.2
fsck.fat 3.0.27 (2014-11-12)
/dev/sdb: 506 files, 175330/244127 clusters
```
