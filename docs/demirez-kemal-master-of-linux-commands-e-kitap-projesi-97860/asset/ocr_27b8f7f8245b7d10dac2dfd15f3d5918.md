```
root@kemal:-# mount -t vfat /dev/sdb /media/usb

```

On some places, you may see as fsck -t ext3 /dev/sda or fsck -t vfat /dev/sdb instead of fsck /dev/sdb commands.We do not need to use -t to identify he file system because fsck automatically does this.

A little reminder; to see which disc section mount and with which file system, we can use mount -l command. I use mount -l | grep KML command to learn about my usb memory disk information.

```
root@kemal:-# mount -l | grep KML
/dev/sdb on /media/usb type vfat (rw,relative,fmask=0022,dmask=0022,epage=437,charset=utf8,shortname=mixed,errors=remount-ro) [KML]
rootkemal:-# _
```

I could also use mount -l | grep dsb command to have the same output.

# Dd Command

Lets also talk about a command/tool about copying a disc section, getting image and doing backup in different formats. This command called dd command. The basic usage of this command like dd if=/dev/sda of=/dev/sdb means sda disk will be copied in dd disk. To erase the contents of disc partition by writing random bits we should use dd if=/dev/urandom of=/dev/sdb (in this line /dev/sdb refers usb flash disk contents)
