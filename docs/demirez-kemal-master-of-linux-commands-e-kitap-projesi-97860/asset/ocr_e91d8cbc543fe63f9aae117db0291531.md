# Ssh Service

SSH is a protocol that provides secure connections, to be made in the local network or remote connection between the two systems. All network traffic is encrypted, data security connection is provided between the two systems.

User information sent as encrypted to the server while connection made. Also, while the data transfer made with special encryption between the client and the server, the data transfer performed. SSH services have to be running on both systems which will be connected thru SSH connection. prefered Porteux Linux distribution as it is a lightweight Linux distribution and Kali 2.0 system(which I have been using already) on my examples.

Let's see how to set up SSH connection by step. First we are using service ssh start command to start ssh service in Kali system.

```
root@kimal:~# service ssh start
root@kimal:~# service status
ssh.service - OpenBSD Secure Shell server
Loaded: Loaded (/lib/systemd/system/ssh.service; enabled)
Active: active (running) since Cum 2015-11-27 23:47:07 EET; 8s ago
```
