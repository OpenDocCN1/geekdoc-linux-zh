# Sed (Stream Editor)

We can make some changes in to the text documents using
the sed program. We can do this process by entering
commands directly from the console or ensure the commands
get from a file. The operators/parameters we can use when
performing tasks / parameters are as follows:

+   -n: Just make application to the specified lines only.

+   -e: The next command is a modify command

+   -f: The next statement is a file name (that is to take input from
(file))

+   p: Print

+   d: It means delete

+   s/before/after/g : This operation, phrases within a text file
can be changed. If g at the and not added, it will be the first
mold base in each row instead of the entire file.

When using sed regular expressions can also be used. Below are
some examples:

+   5d: 5: delete the 5th line

+   /^$/d: delete all empty lines
