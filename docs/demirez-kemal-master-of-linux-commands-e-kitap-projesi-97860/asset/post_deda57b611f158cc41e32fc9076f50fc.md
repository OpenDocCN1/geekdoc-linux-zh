## Network Commands

There are many scripts on Linux systems for the network.
But we will talk about the use of commands useful for us.
We will not discuss concepts of Networks in detail. Those who want to obtain information from the network and can get more detailed information from network books and from the web.

### Ifconfig

Ifconfig command is used to view the settings related to IP configuration on Linux systems.

```
root@local:~# ifconfig HWaddr 00:15:60:b2:71:77

```

In above example eth0 shows our ethernet card (network interface card). If there are any other in the system they will also be shown as, eth1, eth2. The computer itself is shown by lo (localhost). Another phrase wlan0 refers to the wireless network and provides information about our network configuration (IP address, MAC address, broadcast address, etc.)

We can configure our network in two ways. First can be done automatically with a DHCP server. Second way is to configure the network by entering manually. If you want to make manual adjustments, let's say to set your local address as 192.168.1.12, you should use ifconfig eth0 192.168.1.12 netmask 255.255.255.0.

```
root@kemal:~# ifconfig wlan0 192.168.1.12
root@kemal:~# ifconfig
wlan0 Link enc:Ethernet HWaddr 54:e6:fc:95:fc:ec
net addr:192.168.1.12 Bcast:192.168.1.255
inet6 addr:fe80::56e6:fc:fe95/64 Scope
```

We can also use one of the Linux networking commands, the ip command for making various arrangements. Learning the ip number to view the routing table, listing the arp cache etc are some of them. When we use ip command alone, a help screen about ip commands does

```
root@kem:~ # ip
Usage: ip [ OPTIONS ] OBJECT { COMMAND | help }
ip [ -force ] [-batch file] ...
where OBJECT := { link | add | deladdr | route | neigh | ntable |
tunnel | tuntap | mroute | mrule | monitor | xfrm |
nets | l2tp | tcp metrics | tokens | netconf }
OPTIONS := { -version} [-statistics] [-details] | [-resolve] |
(family) { ipv4 | ipv6 } dnet | bridge | link } |
-4 | -6 | -I | -D | -B | -0 |
-loops | maximum-addr-flush-attempts |
-line | -t[timestamp] | -batch [filename] |
-rcvbuf [size]
```

To see the status of ethernet interfaces (link) you can use the ip link command.

route command can be used to view the routing table in the system. A similar command is route command which will be discussed in following chapters.
