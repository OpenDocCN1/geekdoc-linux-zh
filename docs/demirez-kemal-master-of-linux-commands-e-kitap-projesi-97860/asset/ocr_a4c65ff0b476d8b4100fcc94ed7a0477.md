```
root@kemal:~/zeyno# ls
root@kemal:~/zeyno# touch example
root@kemal:~/zeyno# ln -s exampleSYM
root@kemal:~/zeyno# ls
exampleSYM
root@kemal:~/zeyno# ls -i
1975924 example 1975924 exampleSYM
root@kemal:~/zeyno# _
```

As you can see exampleSYM is a shortcut link of example-file. So we've created the shortcut file example, and gave the name of the exampleSYM. You may notice that the inode numbers of the output are different. Also the color of the file name seems to be different. When we check the output of the ls -l command which we use to list of files we will see I at lrwxrwrwx expression at the beginning of the line about link file. This character indicates that this is a shortcut link file. In addition, you may notice that the location of the display, the original files/programs, etc. is marked by the arrow (->) mark.
