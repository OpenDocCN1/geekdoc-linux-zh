# Ping

The ping command is used to see if there is an active address in local network or a remote network. Ping command is used to send ECHO_REQUEST via ICMP protocol.

When the server recives this request it's answers it, elapsed time is calculated and displayed to the user. The ping command is generally used to check if the questioned machine is working. If it does not respond to ping requests that means the machine connected remotely may not be working. Ping will also be used to get estimate of transfer speed between the machines. The communication from the quick responded machine will be faster than the slow responded machine.

When you use the ping command without parameters, it continues to send packages to the target system until you cut the command with CTRL + C. To prevent this you should use c parameter. For example, with ping -c 3 <target_address> command only 3 question packets will be sent to the destination.
