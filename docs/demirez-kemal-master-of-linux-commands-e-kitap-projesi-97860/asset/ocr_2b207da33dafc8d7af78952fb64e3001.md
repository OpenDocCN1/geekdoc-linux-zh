If you want to see CPU information, you should use dmidecode -t 4 command.

```
root@kemal:~# dmidecode -t 4
# dmidecode 2.12
SMBIOS 2.3 present.
nHandle 0x0004, DMI type 4, 35 bytes
Processor Information
  Socket Designation: JP12
  Type: Central Processor
  Family: Pentium M
  Manufacturer: Intel (R)
  ID: D8 06 00 00 FF FB E9 AF
  Signature: Type 0, Family 6, Model 13,
  Flags:
```

DMI type 4 command can be used to find information about other components

+   0 BIOS
1 System
2 Base board
3 frame
4 processor
5 Memory controller
6 Memory module
7 Cache
8 Connector
9 System Slots
10 On Board Units
