When we examine the list, we see **drwx-xr-x** and **rw-r--r--** expressions. This encoding statements, the listed files / directories are showing the current access rights for users. A directory that you see at the beginning of the expression **d**, says it is a directory, - sign says it is a file. And let's sort the remaining codes, which consists of 9 characters **rwxr-xr-x** and **rw-r--r--** in three groups.

+   - **rwx-xr-x = rwx r-x r-x**
- **rw-r--r-- = rw- r-- r--**

First of the group (rwx) files / directories with the owners of the second group (r-x), the owner of the file users privileges in the same group, the third group (r-x) and the other (general) represents the authority of the user. Of course, this applies to the above coding. For the following rw- for the owner, for the same group as the owner r-- and other users will also be shaped to r- as as well. Let's do a little summary:

+   - **r: (read)** Read permission
- **w: (write)** Write permission
- **x: (execute)** execute permission

Now let's look again rwxr-xr-x expression. Let's take first expression to form of three goups as rx rwx groups in the form of three groups. Then examine:

+   - **rwx**: Owner of the file has read, write and execute privileges there.
- **r-x**: The group members where the owner is belong read and execute privileges same as the owner.
- **r-x**: Other users have read and execute privileges.
