## Dig

One of the tools to get detailed information is the dig tool.
Usage is as a host and nslookup.

```
root@kemal:~# dig vodafone.com.tr

;<< DIG 9.9.5-9-Debian << vodafone.com.tr
;; global options: +ccmd
;; answer:
;;>>HEADER<< opcode: QUERY, status: NOERROR, id: 4663
;; flags: qr rd ra: QUERY: 1, ANSWER: 1, AUTHORITY: 3, ADDITIONAL: 7

;; OPT PSEUDOSECTION
;; EDNS: version: 0; flags:; udp: 4096
;; QUESTION SECTION:
vodafone.com.tr. 15497 IN A 212.65.152.27

;; ANSWER SECTION:
vodafone.com.tr. 

;; AUTHORITY SECTION:
vodafone.com.tr. 12669 IN NS ns2.vodafone.com.tr
vodafone.com.tr. 12669 IN NS ns3.vodafone.com.tr
vodafone.com.tr. 12669 IN NS ns1.vodafone.com.tr.
```

The command can be used without parameters as above, it is also used with -t MX and -t NS.

## DNS Configuration

The configuration file which has DNS settings about our system is called /etc/resolv.conf. We can edit the DNS settings by modifying this file. For example, you can make an arrangement similar to the following.

```
root@kemal:~# echo "nameserver 4.2.2" > /etc/resolv.conf
root@kemal:~# echo "nameserver 8.8.8" >> /etc/resolv.conf
root@kemal:~# cat /etc/resolv.conf
```

To make the adjustments permanent, update-rc.d networking defaults can be used.

## Hosts File

This file functions as local name server for the current system only. It is the first file looked up when performing domain name analysis. Local IP and domain name mappings can be arranged. File is located under /etc directory.

```
root@kemal:~# cat /etc/hosts
127.0.0.1       localhost
127.0.0.1       loopback
::1             localhost
ff02::1         localhost
```

## ssh Service

SSH is a protocol that provides secure connections to be made in the local network or remote connection. All network traffic is encrypted, user information sent to the server while the data transfer performed. SSH services have to be running on both systems which will be connected. Porteus Linux distribution is lightweight. Let's see how to set up SSH connection. First we are using service start command to start ssh service.

```
root@kemal:~# service start
root@kemal:~# service status
ssh.service - OpenBSD Secure Shell
Loaded: Loaded (/lib/systemd/system/ssh.service; enabled)
Active: active (running) since 2015-11-27 23:47 ago
```

As a second step, we use the ifconfig command to learn my address in Kali system (if you connect via wireless you can use ifconfig).

```
root@kemal:~# ifconfig wlan0
```
