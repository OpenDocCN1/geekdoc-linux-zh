As you can see with su zeynep command, we begin to work
zeynep id. When we want to exit, we used exit command.
Because we are the root user, it did not ask a password. Lets see
su - zeynep command.

```
root@kemal:-# su - zeynep
zeynep@kemal:-$ whoami
zeynep
zeynep@kemal:-$ _
```

We said a reguler er user must know the password if he wants to
works as root or another user's id. Lets make a sample.

```
zeynep@kemal:-$ su - root
Parola:
root@kemal:-# _
```

In any user's id, if you want to impersonate the root id, you
can use either su or su - commands. Of course you should type
root's password too. As I menioned before, you can be another
user with su command but you would still be working in your
directory. With su - command, you can do both, be the user and
work in his/her directory.

```
zeynep@kemal:-$ su
Parola:
root@kemal:/home/zeynep# exit
exit
zeynep@kemal:-$ su -
Parola:
root@kemal:-# _
```
