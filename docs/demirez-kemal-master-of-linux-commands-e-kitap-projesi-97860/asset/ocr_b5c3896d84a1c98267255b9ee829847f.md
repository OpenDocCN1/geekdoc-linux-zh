```
root@kemal:~# cat personal
Ali:312:Ankara
Veli:212:İstanbul
Kemal:232:İzmir
root@kemal:~# awk -F: '{print "city: " $3}' personal
city: Ankara
city: Istanbul
city: Izmir
root@kemal:~#
```

With this command we display the phares on 3rd area with city: infront of them.

To see all lines in with particular phrase in a file we can use awk, for example to see the records who have Kali in 1st area's of them in distro file, we should use awk '$1 = "Kali" {print $0}' distro command.

```
root@kemal:~# cat distro
Kali Debian Wheezy
BackTrack Debian Ubuntu
RedHat RPM
root@kemal:~# awk '$1 == "Kali" {print $0}' distro
Kali Debian Wheeezy
root@kemal:~#
```

"" has been used as the separator instead of a space than we would use our command with -F: Previous example was for the lines who have Kali on 1st area of them. If you want to see the lines which have Debian on 2nd area, this time we should use the command as awk '$2 == "Debian" {print $0}' distro

```
root@kemal:~# cat distro
Kali Debian Wheezy
BackTrack Debian Ubuntu
RedHat RPM
root@kemal:~# awk '$2 == "Debian" {print $0}' distro
Kali Debian Wheezy
BackTrack Debian Ubuntu
root@kemal:~#
```
