+   - ' Commands are written within quotation marks, then the performed file will specify

+   - $ Refers the columns in the file (which will be processed). If there is no change made, columns accepted divided with spaces. $0 shows total rows (corresponding to the entire line for each line), $1 the first column of the row, S2 2nd column of the line.

+   - NR: Total records (line number)

+   - NF: Column / field number

+   - -F: To specify the field separator sign.

+   - ../: Regular expressions used between two /

+   - FS: Field separator.

Mathematical operators (+, +, =, ++, -, -, *, *, /, /= = As) can be used in awk. As a comparison expressions <, <=, >= =, != can be used.

Now let's do some practice. For example, to show the contents of the file as it is we awk '{print $0}' <file> command.

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk '{print $0}' test
Linux BackTrack 5
```
