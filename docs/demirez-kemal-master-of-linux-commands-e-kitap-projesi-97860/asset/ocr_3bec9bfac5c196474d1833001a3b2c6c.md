# Vinstat

We can use the vmstat command to view the overall status of the system.

```
root@kemal:~# vmstat
procs    memory------swap------system------cpu----
  r b swpd free buff cache  si bo in in cs us sy id wa st
  0 0 263432 11796 15652 232344   0  17  62 27 88 227  4  1 193  2  0
root@kemal:~#_
```

If the command called with no parameters, once the information will be listed and be terminated. With certain time intervals vmstat command to refresh the information, vmstat delay [renewal_number] should be used.

```
root@kemal:~# vmstat 3 4
procs    memory------swap------system------cpu----
  r b swpd free buff cache  si bo in in cs us sy id wa st
  0 0 20568 10580 16528 234484   5 17 62 27 89 231  4  1 193  2  0
  0 0 20568 10324 16628 234804   0  0  0  0 66 163  1 196  2  0
  0 0 20568 10324 16636 234768   0  0  0 13 61 142  1 295  2  0
  0 0 20568 10332 16636 234768   0  0  0  0 178 415  6 9 84  1  0
root@kemal:~#_
```

# History

In fact, this topic could be described in the following sections. But it would be more appropriate here to mention. Linux system used commands are kept in memory (by writing a file for a certain number allocated) then the investigation which commands used and we want to retroactively allow us to use it again. Yes, the command used in the command line is saved in the .bash_history file. We can use the history command to list the commands that have been used before. This command will reference the .bash_history file.
