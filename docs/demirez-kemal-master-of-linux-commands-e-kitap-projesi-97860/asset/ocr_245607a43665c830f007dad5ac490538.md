We can also save the file we moved with a different name.

```
root@kemal:~# mv sample zeyno/deneme
root@kemal:~# cd zeyno
root@kemal:~/zeyno# ls
deneme issue sample test testA
root@kemal:~/zeyno#
```

Moving directory/folder is the same process as moving a file. For example, dwhelper folder in the directory we are in, to move in zeyno folder as program name, we use mv dwhelper zeyno/program command.

```
root@kemal:~# ls
Belgeler dwhelper Masaüstü Resimler Videolar
Downloads Genel Müzik Şablonlar zeyno
root@kemal:~# mv dwhelper zeyno/program
root@kemal:~# cd zeyno
root@kemal:~/zeyno# ls
deneme issue program sample testAA
root@kemal:~/zeyno#
```

We can also use mv command which is a file moving comando to change the file name or extension. For example, we can use the mv command to change sample file as sample.txt by using mv sample sample.txt command.

```
root@kemal:~/zeyno# ls
deneme issue program sample test testA
root@kemal:~/zeyno# mv sample sample.txt
root@kemal:~/zeyno# ls
deneme issue program sample.txt test testA
root@kemal:~/zeyno#
```
