# Master of Linux Commands

# Cd

As you can see cd (change directory) command is able to switch between directories. For example: we can go to /share with cd/usr/share command. To return to our main directory we can use cd command.

```
root@kemal:/usr/share/apps# cd
root@kemal:~#
```

If we want to move to the parent directory from a subid, we can use the command .. (or cd ../). If we want to get in the top two directories of the directory, we should use cd ../../, to move to the top three cd ../../.. commands.

```
root@kemal:/usr/share/sqlmap# cd ../
root@kemal:/usr/share# cd ../../
root@kemal:/#
```

For example, we want to go to the top two directory and also we want to move to another subid of the series that we passed. For this, we should use a command similar to the following.

```
root@kemal:/usr/share/sqlmap# cd ../wpscan
root@kemal:/usr/share/wpscan#
```

With this command from / share/sqlmap directory, we have passed to the /share/wpscan directory.
