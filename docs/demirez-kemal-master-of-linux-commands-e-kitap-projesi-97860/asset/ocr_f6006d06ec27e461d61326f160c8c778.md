# # Pushd-Popd

To open two separate folder / directory, and switch between these directories as we wanted to, we use pushd and popd commands. This process is a kind of directory-doing pull shift as we can say. Let us explain what we mean that the following examples.

```
root@kemal:~# cd /home
root@kemal:/home# pwd
/home
root@kemal:/home# pushd /etc
/etc/home
root@kemal:/etc# pwd
/etc
root@kemal:/etc# popd
/home
```
