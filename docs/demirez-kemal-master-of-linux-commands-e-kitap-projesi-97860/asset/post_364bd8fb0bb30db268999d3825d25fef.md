
## dpkg

Debian/Ubuntu Linux distribution base is a management system which uses deb. The program installed by manually. For example, if you want to install Opera web browser on your system you need to download the debkg package of the Opera browser. The program package has a similar name as such:

```bash
root@kemal:~# ls -l opera_12.16.1860_i386.deb
-rw-r--r-- 1 root root 13063000 Kas 20 15:14 opera_12.16.1860_i386.deb
root@kemal:~#
```

As seen, deb package is ready to be installed. We give the command with specifying the path to the directory which our packet is in. For example, I saved the file in my home directory (home), so I use the command like `dpkg -i <package.deb>`. If you press the tab key by typing the first letters of the name of a deb package, command will automatically be completed. For example, when you are completing typing `dpkg -opera`.

```bash
root@kemal:~# dpkg -i 12.16.1860_i386.deb
Daha önce seçili olan paketler açılıyor.
(Veritabanı hazırlığı ongoing ... opera_12.16.1860_i386.deb ...)
Paket açılıyor ... 329017 dosya ve dizin kuruldu.
Paket açılıyor (opera_12.16.1860)
Alternatifler: /usr/bin/x-browser (x-browser) alternatifini sağlayan
asi-alternatifleri:/usr/bin/google-browser (google-browser) alternatifini sağlayan
işlemi /usr/bin/opera otomatik olarak kullanılıyor
Tetkleyiciçiler: (2.7.8-5)
Tetkleyiciçiler manager (2.17)
Tetkleyiciçiler menu (3.11.3-6)
Tetkleyiciçiler desktop-file-utils (0.22-1)
Tetkleyiciçiler image-support (3.5.10)
Tetkleyiciçiler shared-mime-info (0.13-1)
Tetkleyiciçiler hicolor-icon-theme (0.13-1) \
root@kemal:~# _
```

It is simple to install deb files. For example, if you have more than one deb files in the same folder for installation, you can use `dpkg -i *. command`. With this command all deb files to be installed.

This is called dependency (depends). If the program does not work, dependent package of programs must be installed. If these packages already in your system, they will run without problems. We learned how we can install programs from packages manually. Now let's see, how to uninstall a program from the system. The most basic way to uninstall a program from your system, using `dpkg --purge remove <program_name>` command, `dpkg --purge <program_name>` can be used as well. In this way, the program will be removed with all the files in it. Now let's remove Opera browser from the system which we installed earlier. We are using dpkg -P opera command.
