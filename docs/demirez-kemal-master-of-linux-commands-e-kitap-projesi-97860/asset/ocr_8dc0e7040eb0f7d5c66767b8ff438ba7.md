# Mkfs-Mount-Umount

Lets continue with the sample above. We listed disc sections in parted tool with print. For the first section, if you want to re-create a new file system, you can use a command such as mkfs1 ext4. But you should be carefull with these kind of commands. Creating new file system means to format that disk space. Which means you can loose your data in this section. Let's be sure about the commands what we are using for.

If you want to reformat the partition of any file system according to any pattern, you can use the following command: mkfs.vfat /dev/sdb, mkfs <disc_section> etc
