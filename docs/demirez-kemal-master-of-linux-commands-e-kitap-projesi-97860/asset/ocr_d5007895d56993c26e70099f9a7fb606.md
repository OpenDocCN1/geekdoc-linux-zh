# Zcat-Zgrep-Bzcat-Bzgrep

Now let's talk about commands we can use for reading the contents of the compressed file and searching in the contents. As you know we use cat command to read the contents of text files on screen, and grep command to search the contents. Just like this, we use zcat and zgrep commands for compressed files. For example, we can use zcat sample.gz command to read the contents of sample.gz.

```
root@kemal:~zeyno# cat sample
Linux
Kali
Debian
root@kemal:~zeyno# gzip sample
root@kemal:~zeyno# ls
sample.gz test
root@kemal:~zeyno# zcat sample.gz
Linux
Kali
Debian
root@kemal:~zeyno# _
```

We can use a command such as zgrep Ka* sample.gz. to search based on specific criteria of contents of a compressed file,

```
root@kemal:~zeyno# ls
sample.gz test
root@kemal:~zeyno# zgrep Ka* sample.gz
Kali
root@kemal:~zeyno# _
```

These examples for the compressed files that gzip used. If the files compressed by using bzip2 we should use bzcat and bgrep commands.
