# Ifconfig

Ifconfig command is used to view the settings related to IP configuration on Linux systems.

```
root@local:~# ifconfig HWaddr 00:15:60:b2:71:77
eth0
 Link:Ethernet MULTICAST MTU:1500 Metric:1
RX packets:28 errors:0 dropped:0 overflows:frame:0
TX packets:28 errors:0 dropped:0 overflows:carrier:0
collisions:0 transmitted:0
RX bytes:1680 (1.6 KiB) TX bytes:1680 (1.6 KiB)
Interrupt:16
lo
 Link:Loopback
 inet:127.0.0.1 Mask:255.255.255.0
UP_RUNNING MTU:65536 Metric:1
RX packets:28 errors:0 dropped:0 overflows:frame:0
TX packets:28 errors:0 dropped:0 overflows:carrier:0
collisions:0 transmitted:0
RX bytes:1680 (1.6 KiB) TX bytes:1680 (1.6 KiB)
wlan0
 Link:Ethernet HWaddr 54:e6:fc:95:fc:ec
 inet addr:192.168.1.3 Bcast:192.168.1.255 Mask:255.255.255.250
 inet6 addr:fe80::55e6:fcff:fe64/64 Scope:link
```

In above example eth0 shows our ethernet card (network interface card). If there are any other in the system they will also shown as, eth1, eth2. The computer itself is shown by lo (localhost). Another phrase wlan0 refers the wireless network and provides information about our network configuration (IP address, MAC address, broadcast address, etc.)

If you are connecting via wireless network and you want to see information about this network, you can use the ifconfig command.
