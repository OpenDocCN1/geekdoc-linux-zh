For example, when we use dd if=/dev/sda of=/dev/sdb/sda.img to get disk image, we are getting sda section image and saving it under sdb external disc with sda.img name. To get the image of the sdb, compress with gzip, we can use dd if=/dev/sda | gzip > /dev/sdb/sda.img command.

Lets make a sample about getting image. For example, I want to get my usb disc image namely KML and to save it as kml.img under /home directory. (Here, do not let the disc name, KML fool you. It is a linux feature. Each file/device is shown as directory/file form. USB, CDROM, etc. usually mounted under /media directory. The partitions which states disks are also shown, under /dev directory as a file image. /dev/sdb shows our flash disk.

```
root@kemal:/media/root/KML# ls
process.txt users.txt
root@kemal:/media/root/KML# cd
root@kemal:~# dd if=/dev/sdb of=/home/kml.img
1956864+ records in
1956864+ records out
100191368 bytes (1,0 GB) copied, 56,5523 s, 17,7 MB/s
root@kemal:~#
```

Our image file is saved under /home directory. To restore we use dd if=/home/kml.img of=/dev/sdb command.

