Paket yapılandırması Yazılım seçimi
Önceden tanımlanmış yazılım demlerinden bir veya fazlasını kurmayı seçebilirsiniz.

Kurulacak yazilimlari secin:

+   - Kali's penetration testing Tools
- Debian desktop environment
- GNOME desktop environment
- Xfce desktop environment
- KDE desktop environment
- LXDE desktop environment
- Web server
- SSH server
- Laptop

This tool is also available to use from the terminal.

```
root@kemal:~# tasksel install --list-tasks
i penetration-testing Kali's penetration testing tasks
u desktop Debian desktop environment
u gnome-desktop GNOME desktop environment
u xfce-desktop Xfce desktop environment
u kde-desktop KDE desktop environment
u lxde-desktop LXDE desktop environment
u web-server Web server
u print-server Print server
u ssh-server SSH server
u laptop Laptop
```
