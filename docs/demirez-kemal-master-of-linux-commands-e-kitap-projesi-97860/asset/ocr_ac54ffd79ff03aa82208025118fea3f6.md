# aptitude -i command is given from the console, you can make the program interactive installation-update process from the on-screen menu. You can open the menu by clicking the mouse on the screen and can select the action you want.

Now again, for users of RedHat distributions, let's give yum commands in a list:

+   - yum install <program_name>: basic setup command
- yum remove <program_name>: to remove a program
- yum search <program_name>: To check if the program you want to install is in store
- yum info <program_name> : to get information about program/package
- yum list updates: to list the packages which require update
- yum update and yum upgrade: to update the system
