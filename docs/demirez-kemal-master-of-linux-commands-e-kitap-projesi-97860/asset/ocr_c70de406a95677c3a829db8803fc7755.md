# Ete/Issue

To see linux name that we are using, cat /etc/issue commands can also be used.

```
root@kemal:~# cat /etc/issue
Kali GNU/Linux 2.0 \n \l
```

# Uname

To find out the kernel (core) version of our system uses, uname -a command can be used.

```
root@kemal:~# uname -a
Linux kemal 4.0.0-kali1-686-pae #1 SMP Debian 4.0.4-1+kali2
(2015-06-03) i686 GNU/Linux
root@kemal:~#
```

In fact, with -a parameter we did not only learn kernel-parameter version, we also learn kernel name, hostname, all the information, such as core architecture. Individual query can be done as in the following example.

```
root@kemal:~# uname
Linux
root@kemal:~# uname -n
kemal
root@kemal:~# uname -m
i686
root@kemal:~# uname -r
4.0.0-kali1-686-pae
root@kemal:~# _
```
