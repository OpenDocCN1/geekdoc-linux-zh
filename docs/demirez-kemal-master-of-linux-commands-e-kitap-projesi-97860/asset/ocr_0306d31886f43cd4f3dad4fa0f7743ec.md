# Log Files

Log files are the files where records relating to work done kept on the system. These files are located /var/log index.

```
root@kemal:~# ls /var/log samba
alternatives.log dpkg.log lastlog macchanger.log speech-dispatcher
apache2 dradis stunnel4
apt exim4 messages syslog
auth.log fail2 mysql.sql user.log
bootstrap.log config.log wtmp
btmp mysql.log Wvdialconf.conf
chrootkit gdm3 nptaps Xorg.log
demon.log initsim postgres Xorg.log.old
debug installer redis
kern.log
```

Log files are divided into several categories. While some of them found as files, some of located as subdirectories and folders. In general, a service of the log file is saved with that service name. For example, when we look at the auth.log file see information about the users of the session.

```
root@kemal:~/var/log cat auth.log[524]: New set seat0.
Nov 22 11:07:26 kemal system-log[524]: Watching system buttons on /dev/input
events(Power Button)
Nov 22 11:07:26 kemal system-log[524]: Watching system buttons on /dev/input
event6(Video Button)
Nov 22 11:07:26 kemal system-log[524]: Watching system buttons on /dev/input
event4(Left Switch)
Nov 22 11:07:26 kemal system-log[524]: Watching system buttons on /dev/input
event3(Slee Button)
```
