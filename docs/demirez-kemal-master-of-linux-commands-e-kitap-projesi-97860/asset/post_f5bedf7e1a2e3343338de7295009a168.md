## Wildcards

There are some parameters/methods in Linux which allows us to make our work more convenient and easy when using commands, and working on various operations. They called wildcards, these characters make most of the jobs easier when used in the commands. Functions of these characters are:

- * : Fits all kinds of characters. Especially to select all the files in a particular feature and making transactions with them.
- ? : Matches any single character.
- [a,b,c] Matches to a b or c corresponds to one of the character.
- [abc] : It matches the specified character list.
- [a-c] : Matches between the characters.
- ![abc] : Matches the characters except those in the list.
- ![a-c] : Matches the characters except the characters between them.
- [0-9] : Fits up to 9 characters.
- {falan,filan} : Matches the word on the list.

Now let's make a few examples. For example, we use ls -l /etc/host* command, it lists all files that begin with host under the /etc directory.

```bash
root@kemal:~# ls -l /etc/host*
-rw-r--r-- 1 root 9 Tem 23 09:53 /etc/host.conf
-rw-r--r-- 1 root 6 Aug 22 10:20 /etc/hostname
```

For example just to list hosts.allow and hosts.deny in the /etc directory only, we can use ls -l /etc/hosts.{allow,deny} command.

If there are hosts.allow and hosts.deny files in the directory, and you want to list these files you can use ls -l /etc/hosts.{allow,deny} command.

We say that the wildcard character matches everything. For example, to delete all the files under a directory you can use rm command. You must be careful when using this type of commands. Though you can also use rm * to do so. We delete all files found in our directory, then create new files using the rm * command as asked before deleting.

## Regular Expressions

Regular expressions are used in programming and in some Linux shell process. They provide us easiness in many areas. They often forgot the information we need from such kind, control of user input, etc.. For example, while searching an given template is an easy job, we need to use regular expressions to get the search complex and large files. They are not beneficial in the search process, also we can use them for operations to be applied to search procedures.

Now let's explain some of the regular expressions used by a Linux system and do a few examples:

- Character in the square brackets indicates the desired template to use. For example, to list the phrases beginning with A, and h or l in users.txt file, we use grep A[hl] users.txt command.

```bash
root@kemal:~# cat users.txt
Ali
Ahmet
Aslan
Mehmet
Zeynep
root@kemal:~# grep A[hl] users.txt
Ali
Ahmet
```

To find the phrases starts with A and continue with a character between a-z, we can use grep A[a-z] users.txt command.

```bash
root@kemal:~# grep A[a-z] users.txt
Ali
Ahmet
Aslan
```

The dot (.) As indicated by the point would be stated that there can be any character.

```bash
root@kemal:~# cat test
adana
ankara
konya
izmir
root@kemal:~# grep a.a test
adana
ankara
```

The asterisk (*) refers to any character in any number.

- ^ : It corresponds to the beginning of the line.
- $ : It refers to the last row.

```bash
root@kemal:~# cat /etc/passwd | grep bash$
root:x:0:0:root:/bin/bash
postgresql:x:122:122:PostgreSQL administrator,,,/var/lib/postgresql:/bin/bash
zeynep:x:1000:1001,,,/home/zeynep:/bin/bash
```

[^.] With the exception of the characters in the cluster corresponds to any character.

```bash
root@kemal:~# cat test
adana
ankara
konya
izmir
123
456
789
root@kemal:~# cat test | grep [^0-9]
adana
ankara
konya
izmir
```
