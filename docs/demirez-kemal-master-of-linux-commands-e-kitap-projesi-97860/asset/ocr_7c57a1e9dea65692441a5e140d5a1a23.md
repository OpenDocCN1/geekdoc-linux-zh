# Pgrep

To list the processes working in the memory with some criteria **pgrep** command is used. To de changes on working process, we must first find that process. For example, to find process about **apache**, we can use **pgrep apache2** (apache service must be one for use)

```
root@kemal:~# pgrep apache2
2293
2297
2298
2299
2300
2301
2302
```

With this command, we can see the process numbers (pid) about apache service. If we want to see numbers with process names we must use **-l** parameters. Our command might be like **pgrep -l apache2**

```
root@kemal:~# pgrep -l apache2
2293 apache2
2297 apache2
2298 apache2
2299 apache2
2300 apache2
2301 apache2
2302 apache2
```
