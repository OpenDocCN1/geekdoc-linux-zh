# Echo

Normally with this command, any desired statements sent as output to the terminal screen. Besides this can be used to create a file and write any string into it. Now let's create a new file and expression as well as we want to let you write into the file using the echo command.

```
root@kemal:~/zyno# echo "master of linux" > linuxcmd
root@kemal:~/zyno# ls
linuxcmd test test-1 test-2
root@kemal:~/zyno# cat linuxcmd
master of linux
root@kemal:~/zyno# -
```

As you see with echo "master of the linux" > linuxcmd command file, we created linuxcmd that did not exist before and wrote master of linux. Previously existed an empty file can be written in this way. But if the file is not empty, we can use >> operator as we did in the cat command before

```
root@kemal:~/zyno# cat linuxcmd
master of linux
root@kemal:~/zyno# echo "forever linux" >> linuxcmd
root@kemal:~/zyno# cat linuxcmd
master of linux
forever linux
root@kemal:~/zyno# -
```

I said using the operators command output redirection could lead to a file. By the way, let's also do a small example of this. For example, lets direct ls -l command output to list file that we create. Which means the contents of the command output is written in the file we named list. To do this, use the ls -l> list command is sufficient.
