When Netstat tool/command used with -i it us statical information about the interfaces on the system. The information includes, the number of packets sent between these informations (TX-OK), the number of errors in packets sent (TX-ERR), the number of discarded packets from the sent packates (TX-DRP), the number of occured writing errors in outgoing packets (TX-OVR), etc.
