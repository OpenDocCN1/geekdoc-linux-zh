Directory we created, -m parameter should be used if we want to create permissions on making the arrangements. For example, with mkdir -m 700 blue command, we have created a directory named bluex mkdir with 700 blue permit.

```
root@kemal:-# mkdir -m 700 blue
root@kemal:-# ls -ld blue
drwx------2 root 4096 Eyl 30 09:22 bluex
root@kemal:-# _
```

# Rm

The command that is used to delete directories is rm command. If we want to delete the directory together with its subdirectories and files we should use rm -r, if we want it to ask before we delete we use rm -ri, if we want to delete everything without asking rm -rf command should be used

```
root@kemal:-# rm -ri linux
rm: `linux` dizininin içine inilsin mi?
rm: `linux/examples` dizininin içine inilsin mi?
rm: dizin `linux/examples/` silinsin mi?
rm: dizin `linux/examples` silinsin mi?
rm: dizin `linux` silinsin mi?
root@kemal:-# ls -ld linux
ls: linux'e erişilemedi; Böyle bir dosya ya da dizin yok
root@kemal:-# _
```

If we want to delete several directories at the same time, you must specify the directories side by side typing. For example, like rm -r <dir1> <dir2> <dir3> ... etc.
