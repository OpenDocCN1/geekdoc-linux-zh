# Dpgk

Debian/Ubuntu Linux distribution base is a mangament system which uses deb. The program installed by manually. For example, if you want to install Opera web browser on your system you need to download the debkg package of the Opera browser. The program package has a similar name as such:

```
root@kemal:~# ls -l opera_12.16.1860_i386.deb
-rw-r--r-- 1 root root 13063000 Kas 20 15:14 opera_12.16.1860_i386.deb
root@kemal:~#
```

As seen, deb package is ready to be installed. We give the command with specifying the path to the directory which our packet is in. For example, I saved the file in my home directory (home), so I use the command like dpkg -i <package.deb> If you press the tab key by typing the first letters of the name of a deb package, command will automatically be completed. For example, when you are completing typing dpkg -opera.
