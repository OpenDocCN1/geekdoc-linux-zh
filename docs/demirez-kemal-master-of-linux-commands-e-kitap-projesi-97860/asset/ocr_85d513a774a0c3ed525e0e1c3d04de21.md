# Get Information From The Proc
Virtual Filesystem

For more detailed information about the CPU and RAM, proc virtual file system can be used. For CPU cat /proc/cpuinfo, for memory cat /proc/meminfo return us to the desired information.

```
root@kemal:-# cat /proc/cpuinfo
processor : 0
vendor_id : GenuineIntel
cpu family : 6
model : 13
model name : Intel(R) Celeron(R) M processor
stepping : 8
microcode : 0x20
cpu MHz : 1496.302
cache size : 1024 KB
```

```
root@kemal:-# cat /proc/meminfo
MemTotal: 502812 kB
MemFree: 22784 kB
MemAvailable: 128436 kB
Buffers: 3220 kB
Cached: 180316 kB
SwapCached: 33832 kB
Active: 240760 kB
Inactive: 193188 kB
Active(anon): 166256 kB
```
