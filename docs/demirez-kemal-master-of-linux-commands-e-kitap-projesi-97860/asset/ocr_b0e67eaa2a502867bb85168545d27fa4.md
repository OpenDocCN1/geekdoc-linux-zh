# Gzip-Bzip2-Gunzip-Bunzip2

As mentioned earlier, while archiving files, you can apply compression process. Now first let's see the compression process, then make examples of compressing and archiving. There are two basic tools for compression. These tools are gzip and bzip2. If gzip is used for compressed process, file extension will be gz, if bzip2 is used, file extension will be gz. To open compressed files bzip2 tools are used. Which means the files that have been compressed with gzip is opened with gzip, files have been compressed with bzip2 is opened with bzip2. Now lets see the compression process with a practice. For example, lets compress example file in zeyno directory with gzip, compress sample file with bzip2.

```
root@kemal:~/zeyno# ls
example sample test
root@kemal:~/zeyno# gzip example
root@kemal:~/zeyno# bzip2 sample
root@kemal:~/zeyno# ls
example.gz sample.bz2 test
root@kemal:~/zeyno# _
```
