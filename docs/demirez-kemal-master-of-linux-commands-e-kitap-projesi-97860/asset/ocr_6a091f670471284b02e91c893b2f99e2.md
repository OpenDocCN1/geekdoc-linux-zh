# ls Command

```
root@kemal:~# cd /home
root@kemal:/home# pushd /etc
/etc /home
root@kemal:/etc# dirs -v
0 /etc
1 /home
root@kemal:/etc# 
```

To list subdirectory under the directory, folder and files, use the ls command. We can use this command either with parameters or without parameters. Without parameters will give an out put such as:

```
root@kemal:~# ls
Belgeler dwhelper Masaüst Resimler Videolar
Downloads Genel Müzik Şablonlar
root@kemal:~# -
```

If you use ls -l, we have a more detailed output. In this detailed list provides information such as file access permissions, owner, date of creation.

```
root@kemal:~# ls -l
toplam 36
drwxr-xr-x 2 root 4096 Agu 22 10:10 Belgeler
drwxr-xr-x 2 root 4096 Agu 22 10:10 Downloads
drwxr-xr-x 2 root 4096 Agu 22 12:21 dwhelper
drwxr-xr-x 2 root 4096 Agu 22 10:10 Genel
drwxr-xr-x 2 root 4096 Agu 22 17:34 Masaüstü
drwxr-xr-x 2 root 4096 Agu 22 10:10 Müzik
drwxr-xr-x 2 root 4096 Agu 22 10:10 Resimler
drwxr-xr-x 2 root 4096 Agu 22 10:10 Şablonlar
drwxr-xr-x 2 root 4096 Agu 22 10:10 Videolar
root@kemal:~# 
```
