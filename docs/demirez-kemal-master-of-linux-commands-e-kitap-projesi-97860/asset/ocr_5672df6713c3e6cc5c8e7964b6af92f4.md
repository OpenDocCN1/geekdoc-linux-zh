We use crontab -l command to list the scheduled tasks.

```
# m h dom mon dow command
0 22 + + + tar -zcf /var/backups/Aproce.tgz /root/Masaüstü/Aproce
root@kemal:~# -
```

Crontab -r command is used to delete the scheduled tasks.

```
root@kemal:~# crontab -r
root@kemal:~# crontab -l
no crontab for root
root@kemal:~# -
```

This is a simple way to use of cron service which is very handy and easy to use. You can use this service on diffrent aims based on your needs.
