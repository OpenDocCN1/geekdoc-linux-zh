# Putty

If you want to make connection to Linux command line thru
Windows system you should use putty program on Windows.

![](bbox=[0.189, 0.196, 0.314, 0.279])

The ssh session must be running in Linux system where you
will connect.

```
root@kemal:~# service ssh start
[ ok ] Starting OpenBSD Secure Shell server: sshd.
root@kemal:~#
```

At the same time we must learn the Linux machine's IP
address.

| wlan0 | Link encap:Ethernet HWAddr 54:e6:fc95:6f:ec |
| inet addr:192.168.2.6 Broadcast:192.168.2.255 Mask:255.255.255.0 |
| inet6 addr: fe80::506:ff:fe95:6f/64 Scope:Link |
| UP BROADCAST RUNNING MULTICAST MTU:1500 Metric:1 |
