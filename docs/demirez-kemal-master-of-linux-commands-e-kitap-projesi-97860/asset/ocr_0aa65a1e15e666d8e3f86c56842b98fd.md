In the following example, we will see -F: expression which is used for area seperation works as FS=":"

```
root@kemal:-# cat personal
Ali:312:Ankara
Veli:212:İstanbul
Kemal:232:Izmir
root@kemal:-# awk -F: '{print $3}' personal
Ankara
İstanbul
Izmir
root@kemal:-# awk '{print $3}' FS=":" personal
Ankara
İstanbul
Izmir
root@kemal:-# _
```

You can use the form not only expression FS=":" as FS='':' or FS=:

When viewing desired phrase as an output on the screen, you can see the output with another phrase if you want. For example, awk -F: '{print "city: " $3}' personal command of the output will be as follows.
