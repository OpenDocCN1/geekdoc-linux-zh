# Dmdidecode

The system hardware components and to view information about the BIOS we can use dmdidecode command. This information, obtained by reading system "DMI" (Desktop Management Interface) board. General usage patterns of the command is as follows.

```
dmidecode -t <hardware>
```

With -t parameter:

+   - system
- baseboard
- chassis
- processor
- memory
- cache
- connector
- slot

informations can be learned.

For example dmidecode -t system command loops such as:

```
root@kemal:~# dmidecode -t system
# dmidecode 2.12
SMBIOS 2.3 present.
Handle 0x001, DMI type 1, 25 bytes
System Information
  Manufacturer: Hewlett-Packard
  Product Name: HP Compaq nx6110 (ES484ES#AB8)
  Version: F.14
  Serial Number: CNU00010R
  UUID: ECC5280-CA62-DA11-01A0-6D990C0C6129
  Wake-up Type: Power Switch
Handle 0x0010, DMI type 32, 11 bytes
System Boot Information
  Status: No errors detected
```
