In Linux terminal, a dot (.) sign indicates the directory we are working at the moment. For example when we use “cp /etc/issue.” command, issue file is copied up to the etc directory that we worked at that time.

```
root@kemal:-# ls
Belg dweller Masaüst Resimler Video
Downloads Genel Müzik Sablonlar zeyno
root@kemal:-# cp /etc/issue .
root@kemal:-# ls
Belg dweller issue Müzik Sablonlar zeyno
Downloads Genel Masaüst Resimler Video
root@kemal:-
```

If we want to copy file to the directory at the top of the array that we work, we can use cp file ../ command form.

```
root@kemal:-# cd zeyno
root@kemal:-zeyno# ls
sample test testA
root@kemal:-zeyno# cp sample ../
root@kemal:-zeyno# cd
root@kemal:-# ls
Belg dweller issue Müzik sample Video
Downloads Genel Masaüst Resimler Sablonlar zeyno
root@kemal:-#
```

# Mv

mv command is used to move files. The use of this command same as cp command. For example, we use the mv issue zeyno command to move issue file which is in our directory under zeyno folder where we operate.

```
root@kemal:-# mv issue zeyno
root@kemal:-# cd zeyno
root@kemal:-~/zeyno# ls
issue sample test testA
root@kemal:-~/zeyno#
```
