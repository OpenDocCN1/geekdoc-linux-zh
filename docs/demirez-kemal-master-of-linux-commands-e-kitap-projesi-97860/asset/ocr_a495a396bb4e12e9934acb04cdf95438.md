Installing a program in linux is quite different than windows and is actually very simple. We have several possibilities to set up a Linux program. One of these options is to establish the desired program by compiling from source code. Second option, to install of the software with the package management system in accordance with the distribution we use. Another option is to make automated testing repository installation of storage used by the distribution.

Compiled and become ready to use with package management system files are called packages. Different package files are used for diffrent Linux systems. Today, majority of Linux distribution use two types of package type. While RedHat/CentOS/Fedora and similar distributions use the rpm package, Debian / Ubuntu Linux distributions and similars different package used. Of course, to install this installation packages different package management systems used. Again RedHat/CentOS/Fedora distribution use dpkg package manager. These are manual package management system. As well there are programs downloaded and installed automatically. These are the rpm package for distribution using yum, deb package for distribution the apt package manager..

Now first examine Debian-based Linux distributions how to set up the program, remove the program, the system update process then we will check RedHat based systems works.
