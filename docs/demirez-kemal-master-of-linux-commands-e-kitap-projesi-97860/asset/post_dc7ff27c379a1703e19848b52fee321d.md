## Chapter 7

## Creating and Deleting a Directory

For indexing and deletion there are two commands used: these are `mkdir` and `rm`.

### Mkdir

At its simplest, for example, we can create a directory named `deneme1` with `mkdir deneme1`.

```bash
root@kemal:~/zyno# mkdir deneme1
root@kemal:~/zyno# ls -ld deneme1
drwxr-xr-x 2 root 4096 deneme1
root@kemal:~/zyno# _
```

If you want to create multiple directories, you can use commands like `mkdir deneme1 deneme2 deneme3` etc.

```bash
root@kemal:~/zyno# mkdir deneme2 deneme3
root@kemal:~/zyno# ls -ld deneme2 deneme3
drwxr-xr-x 2 root 4096 deneme2
drwxr-xr-x 2 root 4096 deneme3
```

### -p parameter

To create a directory along with its subdirectories, we use `-p` parameter. For example, with `mkdir -p linux/examples/png`, we have created a directory called `linux`, its subdirectory called `examples` and its subdirectories under `png`.

```bash
root@kemal:~/zyno# mkdir -p linux/examples/png
root@kemal:~/zyno# ls -ld linux
drwxr-xr-x 3 root 4096 linux
root@kemal:~/zyno# cd linux
root@kemal:~/linux# cd examples
root@kemal:~/linux/examples# ls
```

### -m parameter

For directory we created, `-m` parameter should be used if we want to create permissions on making the arrangements. For example, with `mkdir -m 700 blue`, we have created a directory named `blue` with 700 permit.

```bash
root@kemal:~/zyno# mkdir -m 700 blue
root@kemal:~/zyno# ls -ld blue
drwx------ 2 root 4096 blue
root@kemal:~/zyno# _
```

### Rm

The command that is used to delete directories is `rm` command. If we want to delete the directory together with its subdirectories and files we should use `rm -r`, if we want it to ask before we delete we use `rm -ri`, if we want to delete everything without asking `rm -rf` command should be used.

```bash
root@kemal:~/zyno# rm -ri linux
rm: `linux` içine silinsin mi?
rm: `linux/examples` içine silinsin mi?
rm: `linux/examples/` silinsin mi?
rm: `linux/examples` silinsin mi?
rm: `linux` silinsin mi?
root@kemal:~/zyno# ls -ld linux
ls: linux'e erişilemedi; Böyle bir dosya ya dizin yok
root@kemal:~/zyno# _
```

If we want to delete several directories at the same time, you must specify the directories side by side typing. For example, like `rm -r <dir1> <dir2> <dir3>` ... etc.

## Chapter 8

## File Compression Archiving

In Linux system, you can back up desired file or group of files by archive, store and load them again later if required. You may want to make a large-sized file in the archive file. You can archive the files as usual but you can also choose to compress files. There are some commands that we can use for all such transactions. In this section we will talk about the use of these commands.

### Tar

The basic command to create the archive file is `tar` command. Let's see how it is used in a simple example. For example, in `zyno` directory, we want to combine example, sample and test files and create archiving with the name “file.tar”. We use `tar -cf file.tar example sample test` command. (here in instead of `-cf`, you can use without `-` as `cf`).

```bash
root@kemal:~/zyno# tar -cf file.tar example sample test
root@kemal:~/zyno# ls
file.tar
root@kemal:~/zyno# _
```

When we say `c` in command we mean create and with `f` we specify a name archive file that are going to create. We can use `tar xvf file.tar` to open the archive file (`-xf` can also be used). Where `x` means extract, `v` means detailed output (verbose). Now I do not touch the archive file under `zyno` directory, I am deleting the remaining files. Then I use open archive command. That way, use of command will be understood clearly.

```bash
root@kemal:~/zyno# ls
file.tar sample test
root@kemal:~/zyno# rm example sample test
root@kemal:~/zyno# tar xvf file.tar
sample
root@kemal:~/zyno# ls
```

### Gzip-Bzip2-Gunzip-Bunzip2

As mentioned earlier, while archiving files, you can apply compression process. Now first let's see the compression process, there are basic tools for compression: `gzip` and `bzip2`. If `gzip` is used for compressed process, file extension will be `.gz`, if `bzip2` is used, file extension will be `.bz2`. To open compressed files `bzip2` tools are used. Which means the files that have been compressed with `gzip` is opened with `gzip`, files have been compressed with `bzip2` is opened with `bzip2`. Now let's see the compression process with a practice. For example, lets compress example file in `zyno` directory with `gzip`, compress sample file with `bzip2`.

```bash
root@kemal:~/zyno# ls
example sample test
root@kemal:~/zyno# gzip example
root@kemal:~/zyno# bzip2 sample
root@kemal:~/zyno# ls
example.gz sample.bz2
```

Now let's do the opposite, and open the file that compressed by `gzip` with `gunzip`, and the file that compressed by `bzip2` with `bunzip2`.

```bash
root@kemal:~/zyno# ls
example.gz sample.bz2
root@kemal:~/zyno# gunzip example.gz
root@kemal:~/zyno# bunzip2 sample.bz2
root@kemal:~/zyno# ls
example sample test
```

We can use both commands at the same time by putting semicolon between them. Our command would be: `gzip example.gz; bzip2 sample.bz2`.

```bash
root@kemal:~/zyno# ls
example.gz sample.bz2
root@kemal:~/zyno# gunzip example.gz ; bzip2 sample.bz2
root@kemal:~/zyno# ls
example sample test
```

As we learned compression and decompression operations, we can now learn compressing and archiving commands to open the archives. If `gzip` is used the extension is `.tar.gz`. If `bzip2` is used then the extension will be `.tar.bz2`. Something to note, if you want to create bzip2 archive file use `cvf` parameters, to create bzip2 archive file use `cj` parameters. The only difference when opening compressed files, when you open a compressed archive file, instead of `c` parameter, `x` parameters will be used, like `xvzf` and `xjvf`. Now let's see how it is done with a practice. I still want to give samples from the files under the `zyno` directory. For example, lets archive sample and test using gzip. For this we need to use `tar czvf /home/archive.tar.gz sample test` command. With this command, the two files are compressed together, `archive.tar.gz` file will be created under `/home` directory.

```bash
root@kemal:~/zyno# ls
example sample test
root@kemal:~/zyno# tar czvf /home/archive.tar.gz sample test
sample test
root@kemal:~/zyno# cd
root@kemal:~/zyno# cd /home
root@kemal:~/home# ls
archive.tar.gz
```

To open this compressed `archive.tar.gz` command, we must use `tar xzvf` bzip2 command to archive the file this time. For example, we can use `tar cjvf archive.tar.bz2 sample test` command.

```bash
root@kemal:~/zyno# ls
example sample test
root@kemal:~/zyno# tar cjvf archive.tar.bz2 sample test
sample test
root@kemal:~/zyno# ls
archive.tar.bz2 example sample test
root@kemal:~/zyno# _
```

In this way we can use `tar xjvf archive.tar.bz2` command to open the file archived by bzip2 command.

```bash
root@kemal:~/zyno# ls
archive.tar.bz2
root@kemal:~/zyno# tar xjvf archive.tar.bz2
sample test
root@kemal:~/zyno# ls
archive.tar.bz2 sample test
root@kemal:~/zyno# _
```
