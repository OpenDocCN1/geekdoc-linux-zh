+   - ~/.bashrc (the settings file that contains initialization bash parameters)

```
root@local:~# cat .bashrc
# ~/.bashrc: executed by bash(1) for non-login shells.
# see /usr/share/doc/bash/examples/startup-files (in the package bash-doc)
# for examples

# If not running interactively, don't do anything
case $-
n  +i))
    return;
nesac

# don't duplicate lines or lines starting with space in the history
# See(1) for more options
HISTCONTROL=ignoreboth

# append to the history file, don't overwrite it
shopt -s histoptappend

# for setting history length size HISTSIZE and HISTFILESIZE in bash(1)
HISTSIZE=1000
HISTIFILIZE=2000
```

# Ignoreeof Configuration

There are many features of the bash shell. One of them is that CTRL + D keypad is used to exit the shell. When we press keys and we're out of the shell it terminates shell itself. There is a regulation that can be done to prevent accidental exit from the shell. We do this arrangement with ignoreeof. Ignoreeof arrangement prevents to exit from the shell through CTRL + D keypads. We can organize this in several different ways. For example, we can use set -o ignoreeof command, to make it back to the old we we use set +o ignoreeof command.

Another command is export IGNOREEOF=2. export IGNOREEOF = 0 can be used to restore. We can make this arrangement permanent by writing this second command on the bottom line of .bashrc (by typing IGNOREEOF = 2) and saving it. Thus, this adjustment would have become permanent.
