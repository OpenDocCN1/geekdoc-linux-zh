# System Update

To update the system we can use apt-get update and apt-get upgrade commands.

```
$root@kemal:~# apt-get upgrade
Paket listeleri okunuyor... Bitti
Bağımlılık ağacı oluşturuluyor
Durum bilgisi alınıyor... Bitti
Yükseltme hesaplanıyor... Aşağıdaki paketler otomatik olarak kurulmuş ve artık bu p pakete gerek duyuluyor:
python-notify
Bu paketi kaldırmak için 'apt-get autoremove' komutunu kullanın.
Bitti
Aşağıdaki paketlerin mevcut durumları korunacak:
openjdk-7-jdk openjdk-7-jre openjdk-7-jre-headless
Aşağıdaki paketler yükeltilecek:
bind9-hostutils gir1.2-libgdk-pixbuf-2.0 host iceweasel krb5-locals
ldap-utils libapache2-mod-php5 libbind9-90 libdns-export100 libdns100
libfreetype6 freetype6-dev libgdk-pixbuf2.0-dev libgdk-pixbuf2.0-common
```

If you want to use commands at the same time, use the apt-get update && apt-get upgrade form. The new version of the distribution we use can be published. The command that we need to upgrade our system to the new version is apt-get-dist-upgrade.

```
$root@kemal:~# apt-get dist-upgrade
Paket listeleri okunuyor... Bitti
Bağımlılık ağacı oluşturuluyor
Durum bilgisi alınıyor... Bitti
Yükseltme hesaplanıyor... Aşağıdaki paketler otomatik olarak kurulmuş ve artık bu p pakete gerek duyuluyor:
python-notify
Bu paketi kaldırmak için 'apt-get autoremove' komutunu kullanın.
Bitti
Aşağıdaki YENİ paketler kurulacak:
libscript libscript-top sysvisnit
Aşağıdaki paketler yükeltilecek:
openjdk-7-jdk openjdk-7-jre openjdk-7-jre-headless
```

We have couple commands to get rid of old and unnecessary debris from previous programs in the system. These are apt-get autoremove and apt-get autoclean commands. With these two commands will be free from trashes.
