# Wget

To download from the console we can use an easy and handy wget tool. Usage format is basic wget <parameter> <file_road>

One of the most important features wget have the ability to continue where it left off. -c parameter is used for this. example wget -c <site.com/file_name> (-c:contuntie)

To download a directory or site completely, wget -r <site_name>(-recursive) command should be used.

When we look, we see that the downloaded site saved.

```
root@kemal:~# cd www.facebook.com/
root@kemal:~~/www.facebook.com# ls
index.html robots xt unsupportedbrowser?_fb_noscript=1
```

You to make multiple downloads, you can create a txt file which has all download addresses in it and you can download all files once. wget -i textfile.txt

To download specific files -A parameter used. For example, if you want to download only jpg and png files from a website you can use wget -r -A jpg.png <site.com> command.
