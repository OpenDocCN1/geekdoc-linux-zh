# Which

The command used to find out the full path as a parameter to a command information is which command.

```
root@kemal:~# which cat
/bin/cat
root@kemal:~# _
```

# Locate

With this command, we can find out where the file is-means under which directory. For example, lets find the system configuration files which are conf files, we are looking the files in the /etc directory. Configuration files are mostly under this directory. For this, we need to use locate conf | grep /etc command.

```
root@kemal:~# locate conf | grep /etc
/etc/adduser.conf
/etc/apg.conf
/etc/arpwatch.conf
/etc/avrdude.conf
/etc/ca-certificates.conf
/etc/chkrootkit.conf
/etc/dconf
/etc/debconf.conf
/etc/deluser.conf
/etc/dyleyna-server-service.conf
/etc/dns2tcpd.conf
/etc/foremost.conf
/etc/fragroute.conf
/etc/fuse.conf
/etc/gai.conf
/etc/gconf
/etc/gssapi_mech.conf
/etc/hdparm.conf
/etc/host.conf
```
