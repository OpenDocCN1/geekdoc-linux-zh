In Linux system, you can back up desired file or group of files by archive, store and load them again later if required. You may want to make a large-sized file in the archive file. You can archive the files as usual but you can also choose to compress files. There are some commands that we can use for all such transactions. In this section we will talk about the use of these commands.

# Tar

The basic command to create the archive file is tar command. Let's see how it is used in a simple example. For example, in zyno directory, we want to combine example, sample and test files and create archiving with the name “file.tar”. We use tar -cf file.tar example sample test command. (here in front instead -cf, you can use without - as cf)

```
root@kemal:~/zyno# tar -cf file.tar example sample test
root@kemal:~/zyno# ls
example file.tar sample test
root@kemal:~/zyno# _
```

When we say c in command we mean create and with f we specify a name archive file that we are going to create. We can use this tar xvf file.tar command to open the archive file. (-xf can also be used). Where x, means extract, we receive detailed output with v (verbose). Now I do not touch the archive file under the zyno directory, I am deleting the remaining files. Then I use the open archive command. That way, use of command will be understood more clearly.
