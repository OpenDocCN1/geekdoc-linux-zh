To examine any statement in the file we must use '../' the mold. The line or lines on the questioned words will be displayed.

```
root@kemal:~# cat test1
Linux BackTrack 5
RedHat System Mng.
root@kemal:~# awk '/Red/' test1
RedHat System Mng.
root@kemal:~# _
```

The area at the beginning of the allocated space from each other with a line that passes the file to view any expression awk '/string/ {print $1}' <file> template must be used.

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS5
RedHat System Mng.
root@kemal:~# awk '/Kali/ {print $1}' test
Kali
root@kemal:~# _
```

If we want to see the head of the field we use awk '{print $1}' test command.
