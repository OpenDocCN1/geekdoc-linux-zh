To list the lines after 3rd line in a file `NR > 3` expression must be.

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk 'NR>3 {print}' test
CentOS
RedHat System Mng.
root@kemal:~# _ _
```

Now let's see how to list the number of lines in a file. For example to find how many record lines in `/etc/shadow` file, we use `awk 'END {print NR}' /etc/shadow` command. and we used `-F:` for lines in file separated by ":".

```
root@kemal:~# awk -F: 'END {print NR}' /etc/shadow
52
root@kemal:~# _ _
```

When we want to see the lines in order with the numbers of the file, for example lines in the test file, we shoulduld use `awk '{print NR " " $0}' test`

```
root@kemal:~# cat test
Linux BackTrack 5
Kali Linux 2.0
Ethical Hacking
CentOS
RedHat System Mng.
root@kemal:~# awk '{print NR " " $0}' test
1 Linux BackTrack 5
2 Kali Linux 2.0
3 Ethical Hacking
4 CentOS
5 RedHat System Mng.
root@kemal:~# _ _
```

The following three commands do the same thing: gives the total size of the files listed after the command.

- `ls -l | awk '{sum += $5} END {print sum}'`
- `ls -l | grep -v '^total' | awk '{sum += $5} END {print sum}'`
- `ls -l | awk '^total/(getline) {sum += $5} END {print sum}'`

```
root@kernel:~ ls -l | awk '{sum += $5} END {print sum}'
45608
root@kernel:~ ls -l | grep -v '^total' | awk '{sum += $5} END {print sum}'
45608
root@kernel:~ ls -l | awk '^total/(getline) {sum += $5} END {print sum}'
45608
root@kernel:-#
```

The most famous and most capable editor in Linux which you can use with commands from terminal is Vi editor. Today, there are also type of Vi editors which also have visual interface (vim), but users generally prefer to use the commands from terminal. The old name of this tool is Vi, however it's changed to current name of VIM (Vi improved). Vi is symbol of the UNIX tradition. VIM is an improved version of the Vi's.

To open the editor in normal way, we need to use vim command. With this command, our editor, terminal/console will be opened and be as follows:

After you have finished typing can pass to command mode by pressing the ESC key. INSERT warning in command mode will disappear and become ready to get the commands. To give the command, you must use ":" symbol. Some of the command we can use are:

- `:q`: exit the vim editor this command can be used, but will alert you if you don't save the work.
- `:q!`: Used to exit without saving the document.
- `:wq`: used to save the document (saves and remains in vim editor, it does not return to the console)
- `:wq`: Used to exit and save the document. If you did not give a name, for example with :wq command, it saves your files with the name of test and exits.

Yes, let us continue our commands after these simple examples.

- `ZZ`: Save and exits the file as current form (ZZ should be used directly, not after the pressing esc key)
- `:x`: Quits from vim, saves if there is any changes made.
- `:r file`: It reads the specified file, and adds after where cursor is located.

Let's make an example about this. We have two files name file_A and file_B. Let's say, we open the file_A with vim file_A command, then worked on it with pressing the "i", then we quit with esc after finishing our work, and we pass on the command mode(Or we did not process any work, we pres the i then esc to get in to command mode). Then, we want to add file_B contents to the file file_A. For this we use :r file_B command, and press "enter". After that we see the contents added to file_A

```
root@kemal:~# cat file_A
```
