Vim editor, allows you to change the strings in the file you are\working on. For example, let's open our file_A and change the kali expression with debian. To do this we use :s/kali/debian/g command.

![](bbox=[0.176, 0.303, 0.823, 0.597])

After using the command, you will see that kali term replaced
with debian. Let's say we have a file named distro, and we\want to change the linux words located in the 2nd and 3rd line
of phrases with LINUX word. We will use
:2,3s/linux/LINUX/g command for this.
