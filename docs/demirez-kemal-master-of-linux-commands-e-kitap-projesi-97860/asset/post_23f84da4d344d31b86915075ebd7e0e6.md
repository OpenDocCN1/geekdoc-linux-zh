
# 260 | Master of Linux Commands

As soon as the connection is established it means we are working on remote system. When we use ls command we list the files on the connected system, with ls command we list the files in our system.

```
sftp ls
Desktop Documents Downloads
sftp ls
Belgeler General Masallı
Downloads Resimer Videoolar VirtualBox VMs
Muriza fotololar.tar.gz test
deneme Şablonlar
sftp> |
```

Two commands used for file transfer. These commands are put and get commands. To copy the file on connected system we use put command and copy a file in our system we get command. For example, to copy important.txt file we have in our computer to connected computer we use put /root/Desktop/important.txt /root command.

```
sftp> put /root/Desktop/important.txt /root
Uploading /root/Desktop/important.txt to /root/important.txt
/root/Desktop/important.txt 100% 0 0.0KB/s 00:00
sftp> |
```

When we use ls command to check the list, we can see important.txt file is in the list.

```
sftp> ls Downloads Genel
Belgeler Resimer Videoolar
Müzik fotololar.tar.gz important.txt
deneme
Şablonlar
sftp> |
```

To copy the test file (which is saved on connected computer) to our computer we should use get /root/test /root/Desktop command.

```
sftp get /root/test /root/Desktop
Fetching /root/test to /root/Desktop/test
sftp > lls
Desktop Documents Downloads
sftp > lls Desktop
Home.desktop System.desktop important.txt test
sftp > _
```

To copy a directory/folder in lieu of file, we can use the -r parameter.

```
sftp get -r Belgerer /root
Fetching /root/Belgerer/ to /root/Belgerer
Retrieving /root/Belgerer
sftp > lls
Belgerer Desktop Documents Downloads
sftp > _
```

Also, the commands we can use on similar ways are:

- **help**: The Help command. It gives lists of all commands and their function list
- **put**: To copy files on to connected computer
- **get**: Copy files from connect computer to our computer
- **cd**: Changes the folder on connected computer.
- **lcd**: It allows us to change folders in our own computer.
- **rm**: delete files on the other computer.
- **rmdir**: delete a folder on the other computer.
- **chmod**: It allows you to change user permissions on the file.
- **ls**: Displays the contents of the folder on the other computer.
- **ls**: Displays the contents of folders on your own computer.
- **rename**: Change the name of the file on the connected computer.
- **mkdir**: create folders on the other computer.
- **lmkdir**: Create folders in your own computer

We can use the **exit** command to quit after finishing our work.

```
sftp> exit
root@porteus:~# 
```

You can download appropriate version of filezilla client program from **www.filezilla-project.org** address.

## File Downloading With Wget

### Wget

To download from the console we can use an easy and handy wget tool. Usage format is basic wget <parameter> <file_road>

One of most important features wget have the ability to continue where it left off. -c parameter is used for this. example wget -c <site.com/file_name> (-c: continue)

To download a directory or site completely, wget -r <site_name> (-recursive) command should be used.

```
root@kemal:~$ wget -r http://www.facebook.com/
--2015-11-21 17:40:56-- http://www.facebook.com/
www.facebook.com (www.facebook.com) çözleniyor... 31.13.93.36, 2a03:2880:f01c:face:b678:25de
www.facebook.com (www.facebook.com) [31.13.93.36:80] bağlantılar kuruldu.
HTTP isteği gönderildi, yanıt bekleniyor... 302 Found
Ver: https://www.facebook.com/ [izlenen]
--2015-11-21 17:40:56-- https://www.facebook.com/
www.facebook.com (www.facebook.com) [31.13.93.36:443] bağlantılar kuruldu.
```

When we look, we see that the downloaded site saved.

```
root@kemal:~# cd www.facebook.com/
root@kemal:~/www.facebook.com# ls
index.html robots xt unsupportedbrowser?_fb_noscript=1
```

You to make multiple downloads, you can create a txt file which has all download addresses in it and you can download all files once. wget -i textfile.txt

To download specific files -A parameter used. For example, if you want to download only jpg and png files from a website you can use wget -r -A .jpg,.png <site.com> command.
