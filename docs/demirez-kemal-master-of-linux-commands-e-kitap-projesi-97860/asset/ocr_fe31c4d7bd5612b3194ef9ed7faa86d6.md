To see the put out on row basis list, we should use the ls -1
command.

```
root@kemal:~# ls -1
Belgeler
Downloads
dwhelper
Genel
Masaüstü
Müzik
Resimler
Şablonlar
Videolar
root@kemal:~#
```

The other parameters we can use are these:

+   - ls -r: Screen output shows the list as reverse.
- ls -S: Sorts by file size.
- ls -F: According to sort by file type sign.

* : The executable file
@ : Symbolic link
/ : directory

+   - ls -i: Lists the inode number that we will mention later
