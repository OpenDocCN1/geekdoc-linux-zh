# Authorized Keys

There is an arrangement we can make which will allow us to connect to Kali system without password-means to stop the system asking for password. We have created an encrypted key in Porteus and save this under .ssh in Kali. Now we're going to .ssh directory and with cat id_rsa.pub > authorized_keys command we will copy this key in authorized_keys file (File will be created with this command if it is not exit). If you have a kind of file in your system, be sure to use the routing operator as >> to prevent over overwrite on the existing data.

```
root@kemal:~# cd .ssh
root@kemal:~/.ssh ls
id_rsa.pub known hosts
root@kemal:~/.ssh cat id_rsa.pub > authorized_keys
root@kemal:~/.ssh cd
root@kemal:~# # service ssh restart
root@kemal:~# _
```

Now try to connect to Kali system again, we will be able to connect without entering a password.
