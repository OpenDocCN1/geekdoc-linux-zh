For indexing and deletion there are two commands used.
These are the mkdir and rm commands.

# Mkdir

At its simplest, for example, we can create a directory named deneme1 with mkdir deneme1 command.

```
root@kemal:-# mkdir deneme1
root@kemal:-# ls -ld deneme1
drwx-xr-x 2 root root 4096 Eyl 30 09:00 deneme1
root@kemal:-# _-
```

If you want to create multiple directories, you can use commands like mkdir <deneme1> <deneme2> <deneme3...> etc.

```
root@kemal:-# mkdir deneme2 deneme3
root@kemal:-# ls -ld deneme2 deneme3
drwx-xr-x 2 root root 4096 Eyl 30 09:03 deneme2
drwx-xr-x 2 root root 4096 Eyl 30 09:03 deneme3
root@kemal:-# _-
```

To create a directory along with its subdirectories, we use -p parameter. For example, with mkdir -p linux/examples/png command, we have created a directory called linux, and its subdirectory called examples and its subdirectories under called png.

```
root@kemal:-# mkdir -p linux/examples/png
root@kemal:-# ls -ld linux
drwx-xr-x 3 root root 4096 Eyl 30 09:12 linux
root@kemal:-# cd linux
examples
root@kemal:-~/linux cd examples
root@kemal:-~/linux/examples# ls
ng
root@kemal:-~/linux/examples# _-
```
