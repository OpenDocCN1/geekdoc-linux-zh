# More

To read files from the terminal one of the commands that we can use is the more command. This command is where command is longer than the output, for more comfort to read. For example, when we give /etc/passwd command, the longer command output appears on the screen and each time you press the enter key will proceed line by line. With pressing space key is to scroll page by page. To return to the previous page, the b key is used. When we want to exit, we can press to q
