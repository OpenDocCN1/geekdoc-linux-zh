# Awk

Awk is a script language that allows us to make changes in the text files with the format we want. So is it an interpreter language. If commands taken from a file, they are executed with the order they taken. Generally awk used in file for searching by the criteria and editing.

Let's see examples of the use awk after this introduction. For example, when we write awk "BEGIN {print \"command line\"}" in command line, the command output will be printed as command line on the screen.

```
root@kemal:-# awk "BEGIN {print \"command line\"}"
command line
root@kemal:-# _
```

If we use awk "{print}" command, the statement we put after the command will be printed on the screen. We can use Ctrl + D to exit.

```
root@kemal:-# awk "{print}"
demirez
demirez
zeynep
zeynep
root@kemal:-# _
```

If you want to use commands taken from the file, you should use awk -f <script_file> command. We can write awk codes in a text file and save it, we can locate this file location with -f parameter. Although there is no need to have the file any extension, it's helpful the remember awk script file when you save it with .awk extension. For small-scale processing it is more logical to use our command line by entering the command. However, it makes sense to use a script file to perform lots of operations in a large file. Now, let's use the example of a small file. Save the following statement by typing into a text file, extension to be .awk.

# BEGIN {print "linux commands"}

I use the command awk -f sample.awk because I gave the file sample.awk name.

```
root@kemal:~# cat sample.awk
BEGIN {
  print "linux commands"
}
root@kemal:~# awk -f sample.awk
linux commands
root@kemal:~#
```

There are different versions of awk. Although the original awk you can also use gawk (GNU awk), nawk. I will give examples with awk but you can use nawk if you wish.
