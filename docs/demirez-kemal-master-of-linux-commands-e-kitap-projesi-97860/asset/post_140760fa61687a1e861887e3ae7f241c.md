The number between the first $ character and second $ character shows which encryption algorithm used.

- If it is 1 algorithm is MD5
- If it is 2 algorithm is Blowfish
- If it is 5 algorithm is SHA-256
- If it is 6 algorithm is SHA-512

It indicates the encryption algorithm.

If the MD5 algorithm is used, the salt value of the second $ with third $ mark only the incoming password, the length of the string representing the encrypted version is 22 characters, if SHA-256 is used then 43 characters, if SHA-512 is used then 86 characters. ## Add a New User To the System

When we want to add a new user to the system, there are two scripts that we will use as a base. These commands are `adduser` and `useradd`. Basic usage of our first command `adduser` is as follows: For example, we want to add a new user named zeynep in the system. We give the `adduser zeynep` command to do this, and we create our user entering information respectively. When we created our users, as previously mentioned, the user's home directory occurs as /home/zeynep automatically.

```bash
root@kemal:~# adduser zeynep
Adding new group `zeynep` (1001) ...
Adding new user `zeynep` (1000) with group `zeynep` ...
Creating home directory `/home/zeynep` ...
Copying files from `/etc/skel` ...
Yeni parolayı girin: 
Yeni parolayı tekrar girin:
password: şifre başarıyla güncellendi
zeynep için kullanıcı bilgileri değiştiriliyor
Yeni değeri girin, veya varsayılan değer için ENTER'a basın
Tam Isim []:
Oda Numarası []:
İş Telefonu []:
Ev Telefonu []:
Diğer []:
Is the information correct? [Y/n] y
root@kemal:~# _
```

As you can see, the user's home directory is created and the user is included in the `zeynep` group.

```bash
root@kemal:~# cd /home
root@kemal:/home# ls
zeynep
root@kemal:/home# groups zeynep
zeynep : zeynep
root@kemal:/home# _
```

Here, let's talk about uid (user id) and gid (group id). In Linux systems, there is a identification number issued to the user. These numbers are as follows according to user type:

- root user: UID=0, GID=0
- system users: UID-499, GID-499
- normal users: UID-500, GID-500

Let's check the uid numbers by `id`.

```bash
root@kemal:~# id
uid=0(root) gid=0(root)
root@kemal:~# id zeynep
uid=1000(zeynep) gid=1001(zeynep) groups=zeynep
root@kemal:~#
```

Information about the users we added is written automatically into /etc/passwd and /etc/shadow.

```bash
root@kemal:~# cat /etc/passwd | grep zeynep
zeynep:x:1000:1001:/home/zeynep:/bin/bash
root@kemal:~# cat /etc/shadow | grep zeynep
zeynep:!YSTKDDla.IIfdak0QNONQ7Y1OcY.ZahmFA0yGz2CS0ZW0klz16658:99999:::
root@kemal:~#
```

To create a user account we can use `useradd`. To create a user named zeynep we can use `useradd -m zeynep`. With the -m parameter, the user-owned home directory is generated automatically. If we do not use this parameter, we can create this directory manually. After that we can add a password to this user using passwd zeynep.

## Deleting a User

We can use two commands to delete a user from the system. If you create a user with `adduser` command, to delete the user along with the home directory (e.g., 'zeynep') we can use `deluser --remove-home zeynep`. If we create the user with `useradd -m` command, to delete it with its home directory we must use `userdel -r zeynep`.

## Add New User Manually

To add users to the system manually we need to make arrangements in passwd, shadow and group files. Using console commands like vim, we can easily edit the passwd and group files. These commands use vim to open passwd and group files. Keep this in mind.

For example, we want to add a user named deneme to the system. For this experiment, when we add `deneme:x:2000:2000::/home/deneme:/bin/false` in the passwd file, we create a user named deneme, its number is 2000 and member of the 2000 group. Currently we write /bin/bash instead of /bin/false. After creating the user completely, to give them the bash shell we will change /bin/false to /bin/bash. We set the personal directory /home/deneme as the main directory. Now you need to make arrangements in the shadow file. For this we will copy a line and add it to the bottom and then change the username as deneme. Then we will set a new password for the new user using passwd deneme from the terminal. Finally, we add `deneme:x:2000` line to /etc/group file and save it. After making these arrangements, we create the deneme folder under /home and arrange permissions ownership:

```bash
- cd /home
- mkdir deneme
- chown deneme:deneme deneme
- chmod 700 deneme
```

With changing /bin/false we wrote at the beginning to /bin/bash, we have created our new user.

## Listing User's Information

To view information about a user, we can use `chage` command. For example, with `chage -l zeynep` command, user zeynep's information will be listed.

![](img/aa6ce54dbb8ffe5b9d7befb8c6764064_128_1.png)

This command is not only used to display user information. For example, the `chage` command is used to change the user's password expiration date. If we want to end the validity of zeynep's password on November 16, 2015, we must use `chage -E 2015/11/16 zeynep`.

## To Make The User Active Or Inactive

To lock a user account or reactivate a locked account we basically use `usermod [-L|-U] <user>` command. For example, to lock a user account named deneme, `usermod -L deneme`; to reactivate the account, `usermod -U deneme` must be used. To deactivate the user account, in /etc/shadow file in the encrypted password area, we add an exclamation mark (!) at the beginning of the password.

Additional information, if you want to delete the password area belonging to /etc/shadow file, you must use `passwd -d <user>` command. This process does not deactivate the user. The user can remote connect to the system without being asked for a password. Therefore, this method is known as the rapid user disable method. Or use this if you prefer account for lists.
