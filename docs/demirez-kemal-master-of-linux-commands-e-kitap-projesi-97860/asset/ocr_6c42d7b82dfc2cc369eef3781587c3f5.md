If there are LISTA, LISTB and LISTC files in the directory, and you want to list these files you can use ls LIST [AC] command.

```
root@kemal:~/zeyno# ls
hacker LIST LISTB LISTC linuxcmd list
root@kemal:~/zeyno# ls LIST[A-C]
LISTA LISTB LISTC
root@kemal:~/zeyno# _
```

We say that the wildcard character matches with everything. For example, to delete all the files under a directory you can use the rm command. You must be careful when using this type of commands. Because you may delete the necessary files. Though You can also use rm -i * command to do so. This way, you will ask before deleting.

```
root@kemal:~/zeyno# ls
hacker LIST LISTB LISTC linuxcmd list NEW_LIST test test-1 test-2
root@kemal:~/zeyno# rm *
root@kemal:~/zeyno# ls
root@kemal:~/zeyno# _
```

We delete all files found in our directory, then create new files and using the rm -i * command as we asked the command to ask us before deleting.

```
root@kemal:~/zeyno# ls
file1 file2 file3 file4 file5
root@kemal:~/zeyno# rm -i *
rm: normal boş dosya `file1' silinsin mi?y
```
