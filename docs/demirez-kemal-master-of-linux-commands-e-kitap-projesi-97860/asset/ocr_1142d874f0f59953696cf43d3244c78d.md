# Deleting a User

We can use the two commands to delete a user from the system. If you create a user with adduser command, to delete the user along with the home directory (eg 'zeynep' user) we can use deluser --remove-home zeynep command. If we create the user with useradd -m command, to delete it with its home directory we must use userdel -r zeynep command.

# Add New User Manually to the System

To add users to the system manually we need to make arrangements in passwd, shadow and group files. Using console / terminal vipw and vigr commands, we can easily edit the passwd and group files. These commands use vim to editor open passwd and group files. Keep this in mind.

For example, we want to add a user named deneme (test) our system. For this experiment, when we add deneme:x:2000:2000:: , /home/deneme/bin/false line in passwd file, we create a user named deneme,its number is 2000 and a member of 2000 numbered group. Currently, we write /bin/bash instead of /bin/false. After creating the user completely, to give them to use them the bash shell we will change /bin/bash statements to the bin/bash. We stated personal directory /home/deneme as the main directory. Now you need to make an arrangement in shadow file. For this we will copy a line and add it to the bottom and then change the user name as deneme. Then we will set a new password for the new user using passwd deneme from the terminal.
