more logical to use our command line by entering the command. However, it makes sense to use a script file to perform lots of operations in a large file. Now, let's use the example of a small file. Save the following statement by typing into a text file, extension to be .awk.

# BEGIN {print "linux commands"}

I use the command awk -f sample.awk because I gave the file sample.awk name.

```
root@kemal:~# cat sample.awk
BEGIN {
  print "linux commands"
}
root@kemal:~# awk -f sample.awk
linux commands
root@kemal:~#
```

There are different versions of awk. Although the original awk you can also use gawk (GNU awk), nawk. I will give examples with awk but you can use nawk if you wish.

```
root@kemal:~# which awk
/usr/bin/awk
root@kemal:~# which nawk
/usr/bin/nawk
root@kemal:~# nawk -f sample.awk
linux commands
root@kemal:~# -
```
