Download all the files except a specific file use **-R (--reject)** parameter. For example, to download everything except jpg and png files, except: **wget -r -R .jpg,.png <site.com>** command should be used

To repeat the download process in case of an error, -t parameter is used. For example **wget -t6 <site.com>**
