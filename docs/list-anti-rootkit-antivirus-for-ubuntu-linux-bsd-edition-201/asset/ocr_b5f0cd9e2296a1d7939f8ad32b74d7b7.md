# 5. F-Secure Linux Security

![](bbox=[0.11815, 0.17335, 0.88185, 0.43935])

F-Secure is the most complete security software for Linux, it has ever feature from Firewall to Cloud Antivirus, to Web Protection. F-Secure Linux Security provides both server and client protection for companies using the Linux environment. It provides a wide varieties of platforms. The following 32-bit Linux distributions are supported:

+   - CentOS 6.0-6.7
- Debian 7.0-7.9
- Oracle Linux 6.6, 6.7 RHCK
- Red Hat Enterprise Linux 6.0-6.7
- SU Linux Enterprise Server 11 SP1, SP3, SP4
- Ubuntu 12.04.(1-5) 14.04.(1-3)

The following 64-bit (AMD64/EM64T) distributions are supported:

+   - CentOS 6.0-6.7, 7.0-7.1
- Debian 7.0-7.9
- Debian 8.0, 8.1
- Oracle Linux 6.6, 6.7 RHCK
- Oracle Linux 7.1 UEK
