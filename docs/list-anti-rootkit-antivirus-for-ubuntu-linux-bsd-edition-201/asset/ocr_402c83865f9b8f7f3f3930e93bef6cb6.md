Kaspersky Endpoint Security for Linux enables cloud-assisted, multi-tenant workstations running on the Linux operating system. It delivers robust protection and performance.

Kaspersky Endpoint Security for Linux is available within a product bundle of Security for Virtualization. Kaspersky provides comprehensive protection for heterogeneous IT environments, protecting the enterprise from various threats.

# Linux threats on the rise

Although the number of threats targeting Linux is growing, attacks against Linux are on the rise, especially targeting public sector and scientific institutions. Protecting these systems is critical.

Kaspersky has long been known as a powerhouse in the antivirus world. In particular, its antimalware software is popular in the Windows world, which gives the company deep knowledge of malware signatures and profiles, including those on Linux servers.

The company splits its product depending on what kind of systems you have: Kaspersky Anti-Virus for Linux Workstations is designed for an interactive system while Kaspersky Anti-Virus for Linux File Servers is designed for file servers. The company also has a product for just few servers.

With many of these solutions, the question is -- always how responsive will the company to be to new attacks and exploits. Kaspersky releases database updates every hour, as needed.
