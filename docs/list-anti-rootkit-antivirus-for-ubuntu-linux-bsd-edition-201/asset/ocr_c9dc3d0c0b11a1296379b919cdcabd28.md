Rootkit Hunter is an excellent choice for Linux rootkit detection. RKH uses the command-line, backdoors, and various exploits. This tool uses SHA-1 hash comparison to detect malicious entities. It's available for Linux and FreeBSD.

Since Rootkit Hunter is written in Bourne shell, it's portable and compatible with most UNIX-based systems.
