# ISPProtect malware and antivirus web scanner

ISPProtect is Malware and Antivirus scanner for web servers. It contains a signature-based scan engine to detect Malware in WordPress, Joomla and other systems like WordPress, Magento, Drupal, and reports their locations on the web server. ISPProtect is developed by the ISP development team. ISPProtect is widely used Web Hosting Control Panel.

# ISPProtect use cases

Do I need to protect my server? Yes, when you run your own web server, you are hosting a company or providing support for servers.

- If you have a high load on your server that does not have the website access use ISPProtect to find malware that your server uses to attack other systems and IRC

If you are an internet service provider (ISP), you have a unique set of challenges when it comes to keeping your servers free of malware and protecting the files that users upload and install. That's ISPProtect is for. It's quite useful whether you've got dozens of users or a small Linux box in the server rack delivering Web pages for allant.

ISPProtect scans and identifies malware in WordPress, Joomla, Drupal, Magento, and can also ensure that all elements of these popular third-party software systems are up-to-date. Outdated installations are a common means of penetrating your secure system.

The program is built around a signature-based scan engine for viruses using a heuristic engine that detects malware in many environments. It can handle lots of scenarios, including spam from your server from an unknown software package, an atypically high server load, or even customers complaining about their individual servers. This will make it easy to quickly identify and isolate problems.

One more thing: ISPProtect is written by the same source development team that created the popular ISPConfig Webhosting Control Panel. An additional part of the package ISPProtectBaDaemon also protects your system against brute force or denial of service (DoS) attacks.
