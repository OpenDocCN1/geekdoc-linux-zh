# 7. Avast Core Security

![](bbox=[0.11815, 0.17335, 0.8798400000000001, 0.49735])

Avast security for linux comes in 3 different package, you can choose to protect your Linux email servers, file servers or the entire network.

+   - Avast Core Security – Basic antivirus that combat the newest threats and malware from infecting your linux server.
- Avast File Server Security – Protect files right on your server and save the precious power of your workstations for creative work.
- Avast Network Security – A Firewall that scan and filter all web (HTTP) and email (POP3, IMAP) traffic on the network, the filter is completely transparent to users on the network, so there’s no impact on your network performance.
