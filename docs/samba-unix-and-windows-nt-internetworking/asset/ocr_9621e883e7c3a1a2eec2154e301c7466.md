# Webmin

Webmin is another Web-based tool for administering Samba configuration. It goes much further than SWAT by supporting a wide range of general UNIX administration tasks (Figure 14.3). Using Webmin you can configure Samba, set up user accounts, manage DNS, and administer file systems, Web servers and more.

Webmin uses a set of Perl 5 CGI programs to update various UNIX configuration tables. The administrator interface requires browser support for forms, frames and Java. To obtain a copy of Webmin or additional information, visit the Webmin Web site: http://www.webmin.com/webmin/.
