# Samba and Browsing

As of release 1.9.17a, Samba has supported the full set of browser functionality including replication and synchronization of browse lists across subnets. Like Samba WINS service, Samba browsing options include hybrid features not found in native Windows implementations.

Table 9.3 lists the set of available global and service level smb.conf parameters that affect browser operation. After reviewing these parameters, we'll look at the specific combinations of parameters required to implement browser support in workgroups, domains, and across one or more subnets.

# Base Parameters
