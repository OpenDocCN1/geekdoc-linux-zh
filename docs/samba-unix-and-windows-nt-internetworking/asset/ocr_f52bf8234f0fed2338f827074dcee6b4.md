# smbpasswd

program has several different functions, depending on whether or not it is run by the root user. When run as a normal user it allows the user to change the password for an SMB session on any machines that store SMB passwords.

# smbmnt

is a helper application used by the f3 smbmount (8) program to do the actual mounting. Smbmnt is meant to be installed setuid root so that normal users can mount their smb shares. It checks whether the user has write permissions on the mount point and then mounts the directory.
