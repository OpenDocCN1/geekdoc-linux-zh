Sites that use NIS managed directory servers can route [homes] connections to the appropriate remote directory server by enabling the nis homedir parameter and identifying the NIS map with the homedir map parameter. The remote directory server must also be running Samba. The home directory will be mounted directly from the directory server:

```
nis homedir = <true, false>
homedir map = <NIS map name>
```
