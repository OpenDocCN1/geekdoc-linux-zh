# Preface

*Samba: UNIX and Windows Internetworking is a text describing how Samba can be used to unify and integrate network based file and print resources in a heterogeneous desktop and server computing environment. Along with a general discussion of how to install, configure and manage Samba, the text will also address how Samba can be used to resolve mobile computing synchronization problems, integrate authentication and access controls in small to large enterprises and interoperate with Windows 2000.*
