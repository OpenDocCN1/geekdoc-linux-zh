# Synopsis by Nicholas Wells

This compact volume assumes that the reader is working as a system administrator, dealing with both UNIX and Windows systems, and needs to integrate them with as little effort and time as possible. Background is provided on both UNIX and NT to give a solid foundation to all readers. The Open Source Samba suite is then described, both its history and its installation. The last half of the book describes how to configure the many options of Samba using either the text-based configuration tools or the SWAT graphical configuration interface. (Several other configuration tools are also described.) Output and sample files from many parts of the UNIX system are included, as well as many screen shots from Windows showing how different Samba configurations affect the network. Specific configuration options for both global and per-share sections are highlighted throughout the book.

# Back Cover

SAMBA, the important new set of tools for accessing UNIX files systems and printers from a Window client via Microsoft's Server Message Block (SMB) is today's hottest technology. This book provides UNIX administrators with all the tools needed to integrate Windows 2000 into corporate networks.

Best-selling author James DeRoost clearly explains the nuts and bolts of the SAMBA toolkit as well as the particular complexities of all the Windows Domain Systems and file system issues. In addition, installation, user interface, security, namespace, and troubleshooting are discussed extensively.

UNIX system administrators and programmers will find SAMBA: UNIX & NT Internetworking to be their best and most up-to-date resource for unlocking the power of UNIX and successfully integrating Windows 2000 operating systems.
