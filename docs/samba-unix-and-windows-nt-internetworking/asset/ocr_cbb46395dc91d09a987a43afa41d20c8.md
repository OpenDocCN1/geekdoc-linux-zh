Now verify that nmbd is responding to queries both locally and from remote clients. From the local server execute the nmblookup command with the local host name as an argument. nmbd should respond with the server's IP address confirming that it is correctly handling name service queries (Example 15.8). You can further exercise nmbd by requesting a name list via broadcast (Example 15.9). Remember that if the workgroup or domain spans multiple subnets, you'll need one or more WINS servers to support cross-subnet name service.
