# Versions

The current production release of Samba is packaged as samba-latest.tar.gz. The package contains everything you need to install and support Samba. Other distributions are labeled with the version number and a suffix indicating the patch level or whether the distribution is an alpha or beta release.

| | |
|---|---|
| samba-latest.tar.gz | Current Production Version |
| samba-<version>.tar.gz | Other Versions |

The package is in compressed tar format. Move the package into your source code maintenance directory or a temporary directory and extract it using GNU zip piped into the tar command. The expanded directory tree will look something like Example 5.2.
