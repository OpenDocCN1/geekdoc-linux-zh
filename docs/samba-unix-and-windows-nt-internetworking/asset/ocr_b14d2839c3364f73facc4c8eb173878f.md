# SMB2WWW

SMB2WWW is a tool that provides a Web interface to the Samba smbclient command. It presents a Network Neighborhood-like view of a workgroup or domain (Figure 14.4). Click on any server listed on the page and a list of available services is displayed. SMB2WWW allows you to do most of the operations provided by smbclient. This includes tar'ing a file share directory for backup and restore purposes. For more information try out the demo page or archive site listed below.

http://us3.samba.org/samba/smb2www/index.html
