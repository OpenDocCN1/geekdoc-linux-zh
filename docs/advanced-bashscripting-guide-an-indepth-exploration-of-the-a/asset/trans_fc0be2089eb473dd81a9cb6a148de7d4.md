# 示例 8–1. 最大公约数

```bash
#!/bin/bash
# gcd.sh 最大公约数
# 使用欧几里得算法

# 两个整数的“最大公约数”(gcd)
+# 是能整除这两个数且无余数的最大整数。

# 欧几里得算法使用连续除法。
# 在每次循环中，
## 被除数 < 除数
## 除数 <- 余数
## 直到 余数 = 0。
# 最后一次通过后，gcd = 极佳结果。

ARGS=2
E_BADARGES=65

if [ "$#" -ne "$ARGS" ];
then
    echo "用法: `basename` 第一个数字 第二个数字"
    exit $E_BADARGES
fi
```

```bash
remainder=1              # 如果在循环中使用未初始化的变量，
# ++ 它会导致错误信息
# + 在循环第一次通过时。

until [ "$remainder" -eq 0 ]
do
    let remainder = $dividend % $divisor
    dividend=$divisor      # 现在对两个最小数重复。
    divisor=$remainder      # 欧几里得算法
done
# 最后的 $dividend 是 gcd。

# 示例 8–2. 使用算术运算

```bash
#!/bin/bash
```

# 以 5 种不同方式 6 计数。

```bash
n=1; echo -n "$n"

let n = $n + 1  # let n = n + 1 也有效。
echo -n "$n"

$((($n + 1)))
# "$(" 是必要的，否则 Bash 会尝试
#+ 将 "$(n = $n + 1)" 解释为命令。
echo -n "$n"

n=$($n + 1)
echo -n "$n"

$: n = $n + 1
# "$" 是必要的，否则 Bash 会尝试
#+ 将 "$(n = $n + 1)" 解释为命令。
# 即使 "n" 被初始化为字符串也有效。
echo -n "$n"

s={ $n + 1 }
# 即使 "n" 被初始化为字符串也有效。
# 避免这种构造类型，因为它是过时且不可移植的。
echo -n "$n"; echo
```

# 感谢 Stephanie Chazelas。

exit 0

Bash 中的整数变量实际上是长整型（32位整数），范围在 -2147483648 到 2147483647 之间。超出这些限制的运算将报错。

| 运算符 | 描述 |
| :--- | :--- |
| << | 位位左移（每次移位乘以 2） |
| >> | 位位右移（每次移位除以 2） |
| & | 位位与 |
| \| | 位位或 |
| ~ | 位位取反 |
| ^ | 位位异或 |
| <<= | 位位左移-赋值 |
| >>= | 位位右移-赋值 |
| &= | 位位与-赋值 |
| \|= | 位位或-赋值 |
| ^= | 位位异或-赋值 |

Bash 不理解浮点运算。它将包含小数点的数字视为字符串。

```bash
a=1.5
let b = $a + 1.3 # 表达式错误（标记为 ".5 + 1.3"）
echo $b
```

在需要浮点计算或数学函数的脚本中使用 `bc`。位运算符在 shell 脚本中很少出现。它们的主要用途似乎是动态处理和测试值，就像 C 和 C++ 中一样。
