Example 12–14. toupper: Transforms a file to all uppercase.

```
#!/bin/bash
# Changes a file to all uppercase.

E_BADARGS=65

if [ -z "$1" ] # Standard check for command line arg.\hen
    echo "Usage: basename $0 filename"
    exit $E_BADARGS
fi

t a-z A-Z <$1"
```

# Same effect as above, but using POSIX character set notation:
# tr '[:lower:]' '[:upper:]' <$1"

```
exit 0
```

Example 12-15. lowercase: Changes all filenames in working directory to lowercase.

```
#!/bin/bash
# Changes every filename in working directory to all lowercase.
# Inspired by a script by John Dubois,
# which was translated into Bash by Chet Ramey,
# and considerably simplified by Mendel Cooper, author of this.

for filename in * # Traverse all files in directory.
do
    name="basename $filename"
    echo "$name" | tr A-Z a-z- # Change name to lowercase.
    if [ "$name" != "$filename" ]; # Rename only files not already lowercase.
then
        mv $filename $name
fi
done

exit 0
```
