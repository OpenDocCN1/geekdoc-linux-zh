# Advanced Bash–Scripting Guide

```
#!/bin/bash

# Check some of the system's environmental variables.
# If, for example, $USER, the name of the person at the console, is not set,
# +the machine will not recognize you.

:${HOSTNAME}? ${USER}? ${HOME}? ${MAIL}
echo
echo Name of the machine is $HOSTNAME
echo "You are $USER"
echo "Your home directory is $HOME."
echo "Your mail INBOX is located in $MAIL"
echo
echo "If you are reading this message,"
echo "critical environmental variables have been set."
echo
echo

#

# The ${variablename} construction can also check
# +for variables within the script.

ThisVariable=Value-of-Variable
# Note, by the way, that string variables may be set
# +to characters disallowed in their names.
:${ThisVariable}
echo "Value of this Variable is $ThisVariable"
echo
echo
```

```
$(Zzy23AB?"Zzy23AB has not been set.)
# If Zzy23AB has not been set,
# +then the script terminates with an error message.
```

> You can specify the error message.
# ${(Zzy23AB?"Zzy23AB has not been set.)

```
# Same result with:
dummy_variable=${Zzy23AB?}
dummy_variable=${Zzy23AB?"Zzy23AB has not been set."

echo ${(Zzy23AB?}> /dev/null
```

You will not see this message, because script terminated above.
