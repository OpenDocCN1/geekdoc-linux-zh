select

The **select** construct, adopted from the Korn Shell, is yet another tool for building menus.

```
select variable[in list]
do
  command...
  break
done
```

This prompts the user to enter one of the choices presented in the variable list. Note that **select** uses the PS3 prompt (#?) by default, but that may be changed.

Example 10–28. Creating menus using select

```
#!/bin/bash
PS3='Choose your favorite vegetable: '  # Sets the prompt string.
echo
select vegetable in "beans" "carrots" "potatoes" "onions" "rutabasagas"
do
  echo
  echo "Your favorite veggie $vegetable."
  echo "Yuck!"
  break # if no 'break' here, keeps looping forever.
done
exit 0
```

If **list** is omitted, **select** uses the list of command line arguments ($@) passed to the script or to the function which the **select** construct is embedded.
