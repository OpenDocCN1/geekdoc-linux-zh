# 示例 4–4. 备份昨天更改的所有文件

```bash
#!/bin/bash

# 将当前目录下在过去 24 小时内修改过的文件
# 备份到“tar 包”（tar 压缩并 gzip 文件）。

NOARGS=0
E_BADARGS=65

if [ $# == $NOARGS ]
then
  echo "Usage: basename $0 filename"
  exit $E_BADARGS
fi

find . -mtime -1 -type f -print > $1.tar
gzip $1.tar

# Stephanie Chalaz 指出，如果找到的文件过多
# 上述代码将会失败
# 如果任何文件名包含空白字符。

# 他建议了以下替代方案：
# find -mtime -1 -type f -print | xargs -0 tar rvf "$1.tar"
# 使用 GNU 版本的 "find"
# find -mtime -1 -type f -exec tar rvf "$1.tar" '{}' \; 
# 可移植到其他 UNIX 变体，但慢得多。

exit 0
```

以 – 开头的文件名与重定向运算符配合时会导致问题。脚本应该检查此并将此类文件名作为变量或 $PWD 传递。如果变量的值以 – 开头，可能也会创建类似的问题。

第 4 章 特殊字符

# 高级 Bash 脚本指南

```
var="-n"
echo $var
# 相当于 "echo -n"，不输出任何内容。
```

**上一个工作目录**。[dash] cd 切换到上一个目录。这使用了 $PWD。不要与 `-` 重定向混淆。`-` 取决于它出现的上下文。

重定向方向：
- `>` 将标准输出重定向到文件。
- `<` 将标准输入从文件重定向。
- `>>` 将标准输出追加到文件。
- `2>` 将标准错误重定向到文件。
- `2>&1` 将标准错误重定向到标准输出。
- `> /dev/null` 将标准输出重定向到空设备。
- `&> /dev/null` 将标准输出和标准错误都重定向。

减号（Minus）。算术运算中的减号。

等号（Equals）。赋值运算符

```
a=28
echo $a
```

在不同的上下文中，“=” 是字符串比较。

加号（Plus）。加法运算。

在不同的上下文中，`+` 是正则表达式运算符。

取模（除法的余数）算术运算。

在不同的上下文中，`%` 是模式匹配运算符。

**主目录。**。[tilde] 这对应于内部变量 $HOME。`~` 是用户的主目录，`ls` 列出内容。`~/` 是当前目录，`ls` 列出内容。

```
echo $HOME
echo ~
```

控制字符：
- Ctrl+C 终止前台作业。
- Ctrl+D 退出 shell（类似于 exit）。它发送 "EOF"（文件结束符）。
- Ctrl+J 回车。
- Ctrl+L 清除终端屏幕。
- Ctrl+M 换行。
- Ctrl+U 擦除输入行。
- Ctrl+Z 暂停前台作业。
- Ctrl+A 行首。
- Ctrl+G 蜂鸣。
- Ctrl+H 退格。

```bash
#!/bin/bash
# 在字符串中嵌入 Ctrl+H。
a="*H" # 两个 Ctrl+H（退格）。
echo -n "abcdef" # 末尾有两个空格。
echo -n "abcdef$a" # abcdef
# 末尾没有空格时不退格（为什么？）。
echo; echo # 结果可能不符合预期。
```

空白字符（Whitespace）：
空白字符由空格或制表符组成。在某些上下文中，空格是不允许的。空行没有影响。

内部字段分隔符（IFS）：IFS 是分隔字段的特殊变量。在某些命令中，它是允许的，有默认值。

变量的赋值。赋值出现在脚本的各个位置。语法错误。变量可以出现在双引号、单引号或不加引号的范围内。引用变量值。使用大括号 `${}` 引用变量。
