It is useful for security purposes, for instance when the administrator wishes to restrict users, such as using telneting, to a secured portion of the filesystem; it is sometimes restricted by confining a user to a 'chroot jail'. Note that after a chroot, the execution path for system binaries is no longer valid.

A chroot /opt would create references to /usr/bin to be translated to /opt/usr/bin. Likewise, chroot /aaa/bbb /bin/ls would restrict future instances of ls to /aaa/bbb as the base directory, that is normally the case. An alias xx='chroot /aaa/bbb' in a user's ~/.bashrc effectively restricts which portion of the filesystem she may run command "XX" on.

The chroot command is also used when running from an empty floppy (chroot to /dev/fd0), or as an option to l when recovering from a system crash. Others use installation from a different filesystem (an rmp option) or running a readonly filesystem from a CD ROM. Invoke only as root, and use with care.

## MAKEDEV

Utility for creating device files. It must be run as root, and in the /dev directory.

```
root# ./MAKEDEV
```

This is a sort of advanced version of mknod.

## Backup

dump, restore

The dump command is an elaborate filesystem backup utility, generally used on larger installations and networks. [42] It reads raw partitions and writes a backup file in a binary format. Files to be backed up by a variety of storage media, including disks and tape drives. The restore command restores backups made with dump.

## System Resources

### ulimit

Sets an upper limit on system resources. Usually invoked with the -f option, which sets a limit on file size (ulimit -f 1000 limits files to 1 meg maximum). The -t option limits the coredump size (ulimit -c 0 eliminates cores). Normally, the value of ulimit would be set in /etc/profile and or ~/.bash_profile (see Chapter 27).

### umask

User file creation MASK. Limit the default file attributes for a particular user. All files created by that user use the attributes specified by umask. (octal) value passed to umask defines the file permissions disabled. Of course, umask 002 ensures that new files have at most 755 permissions (777 NAND and). [43] The user may later change the attributes of particular files with chmod. The usual practice is to set the value of umask in /etc/profile and / ~/.bash_profile (see Chapter 27).

### rdev

Get info about or changes to root device, swap space, or video mode. The functionality of rdev has generally been taken over by lilo, and rdev remains useful for setting up a ram disk. This is another dangerous command, misused.

## Miscellaneous

env

Runs a program or shell with certain environmental variables set or changed (without changing the overall system environment). The [varname=xxx] permits changing the environmental varname for the duration of the script. With no options specified, this command lists all the environmental variables.

> In Bash and other Bourne derivatives, it is possible to set variables in a single command's environment.

```
var1=value var2=value2 commandXXX
#var1 and $var2 set in the environment of 'commandXXX' only.
```
