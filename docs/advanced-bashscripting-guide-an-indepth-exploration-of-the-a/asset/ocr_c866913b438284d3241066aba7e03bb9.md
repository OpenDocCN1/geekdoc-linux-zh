# Chapter 28. /dev and /proc

A Linux or UNIX machine typically has two specialpurpose directories, /dev and /proc.

# 28.1./dev

The /dev directory contains entries for the physical devices that may or may not be present in the hardware.
[57] The hard dev partitions containing the mounted filesystem(s) have entries in /dev, as a simple df shows.

```
bash$ df
1k-blocks Used Available Use%\Filesystem Mounted on
/dev/sda 495876 222748 247527 48% /
/dev/hdb1 50755 3887 44248 9% /boot
/dev/hda8 367013 13262 334803 4% /home
/dev/hda5 171416 112624 503704 70% /usr
```

Among things, the /dev directory also contains loopback devices, such as /dev/loop0. A loopback
device is a gimmick an ordinary file to be accessed as if it were a block device. [158] This enables
mount an entire filesystem within a single large file. See Example 13-6 and Example 13-5.

A few of the pseudo-devices in /dev have other specialized uses, such as /dev/null, /dev/zero and
/dev/urandom.

# 28.2./proc

The /proc directory is actually a pseudo-filesystem. The files in the /proc directory mirror
unning system and kernel processes and contain information and statistics about them.

```
bash$ cat /proc/devices
Character devices:
1 mem
2 pty
3 ttyp
4 tty
5 cua
7 vcs
10 misc
14 sound
29 fb
36 netlink
128 ptm
136 pts

```
