mkfifo

This obscure command creates a named pipe, temporary first-in-first-out buffer for transferring data between processes. [351] Typically, one process writes to the FIFO, and the other reads from it. See Example A-13.

pathchk

This command checks the validity of a filename. If the filename exceeds the maximum allowable length (255 characters) or one or more of the directories in its path is not searchable, then an error message results. Unfortunately, pathchk does not return a recognizable error code, and it is therefore much useless in a script.

dd

This is the somewhat obscure and feared "data duplicator" mincommand. Originally a utility for exchanging data on magnetic tapes between UNIX mincomputers and IBM mainframes, the command still has its uses. The dd command copies a file (or stdin/stdout), with conversions. Possible conversions are ASCII/EBCDIC, [36] upper/lower case, swapping of bytes between input and output, and skipping andor truncating the head or tail of the input file. A dd --help lists the conversion and other options that this powerful utility takes.

```
# Exercising 'dd'.
n=3
p=5
input_file=project.txt
out_file=log.txt

diff if=$input_file of=$output_file bs=1 skip=$((n-1)) count=$((p-n+1)) 2>/dev/null
# Extracts counts n to p from file $input_file.
```
