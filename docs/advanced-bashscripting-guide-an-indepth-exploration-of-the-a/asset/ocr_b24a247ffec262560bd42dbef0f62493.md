# Advanced Bash–Scripting Guide

sdiff

Compare and/edit two files in order to merge them into an output file. Because of its interactive nature, this command would find little use in a script.

cmp

The cmp command is a simpler version of diff, above. Where diff reports the differences between two files, cmp merely shows at what point they differ.

![](bbox=[0.313, 0.241, 0.343, 0.263])

Like diff, cmp returns an exit status of 0 if the compared files are identical, and 1 if they differ. This permits use a test construct within a shell script.

# Example 12–8. Using cmp to compare two files within a script.

```
#!/bin/bash
# Two args to script expected.
ARGS=2 E_BADARGS=65

if [ $# -ne "$ARGS" ];
then
    echo "Usage: basename $0" file1 file2"
    exit $E_BADARGS
fi
```

```
cmp $1 > /dev/null # /dev/null buries the output of the "cmp" command.
# Also works with 'diff', i.e., diff $1 $2 > /dev/null

if [ $? -eq 0 ];
then
    echo "File \$1" is identical to file \$2."
else
    echo "File \$1" differs from file \$2."
fi

exit 0
```
