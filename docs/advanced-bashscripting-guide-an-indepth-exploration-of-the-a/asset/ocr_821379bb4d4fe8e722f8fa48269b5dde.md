Since sed, awk, grep process single lines, will usually not be a newline to match. In those
cases where there is a newline in a multiple line expression, the dot will match the newline.

```
#!/bin/bash
sed -e 'N;s/\n/\' << EOF # Here Document
line1
line2
EOF
# OUTPUT:
# [line1]
# line2

echo
awk '{ $0~"\n" $2; if (./line.1/) (print)' << EOF
line 1
line 2
EOF
# OUTPUT:
# line
#

 Thanks, S.C.
exit 0
```
