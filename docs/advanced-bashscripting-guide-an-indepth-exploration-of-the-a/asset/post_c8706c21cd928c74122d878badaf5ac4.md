# Example 12-3. Deleting a file by its node number

```bash
#!/bin/bash
idelete.sh: Deleting a file by its node number

# This is useful when a filename starts with an illegal character
# such as ? or -
```

```bash
ARGCOUNT=1      # Filename arg must be passed to script.
E_WRONGARGS=70
E_FILE_NOT_EXIST=71
E_CHANGED_MIND=72
```

```bash
if [ $ -ne "$ARGCOUNT" ];
then
  echo "Usage: basename $0 filename"
  echo $E_WRONGARGS
fi
if [ ! -e "$1" ];
then
  echo "File \"$1\" does not exist.
  exit $E_FILE_NOT_EXIST
fi
```

```bash
inum=`ls -i | grep "$1" | awk '{print $1}'
# inum = index (inode) number of file.
# Every file is an index record, a record that has its physical address.
echo; echo -n "Are you absolutely sure you want to delete \"$1\" (y/n)? "
read answer
case "$answer" in
[nN]) echo "Changed your mind, huh?"
    exit $E_CHANGED_MIND
    ;;
*) echo "Deleting file \"$1\".";
esac

find -inum $inum -exec rm {} / \;
echo "File \"$1\" deleted!"
```

# 12.2. Complex Commands

See [Example 12–22], [Example 4–4], and [Example 10–9] for scripts using **find**. Its manpage provides more detail on this complex and powerful command.

xargs

A filter for feeding arguments to a command, and also a tool for assembling the commands themselves. It breaks a data stream into small chunks for filters and commands to process. Consider it as a powerful replacement for backquotes. In situations where backquotes fail with too many arguments error, substituting **xargs** works. Normally, xargs reads from `stdin` or from a pipe, but it can also be seen from the output of a file.

The default command for **xargs** is `echo`. This means input piped to xargs may have linefeeds and other whitespace stripped out.

```bash
bash$ ls -l
total 0
-rw-rw--      1 bozo bozo 0 Jan 29 23:58 file1
-rw-rw--      1 bozo bozo 0 Jan 29 23:58 file2
```

```bash
bash$ ls -1 | xargs
total 0 -rw-rw-- 1 bozo 0 Jan 29 23:58 file1 -rw-rw-- 1 bozo 0 Jan 29 23:58
```

`ls | xargs -p -I gzip gzip {}` every file in current directory, at one time, prompting each operation.

![](img/1ce1edffaa36e4f698a85430e71c6d3b_151_0.png)

An interesting xargs option is `-n NN`, which limits to NN the number of arguments passed.

`ls | xargs -n 8 echo` lists the files in the current directory in 8 columns.

![](img/1ce1edffaa36e4f698a85430e71c6d3b_151_1.png)

Another useful option is `-0`, in combination with `find -print0` or `grep -Z`. This allows handling arguments containing whitespace or quotes.

```bash
find /type f -print0 | xargs
-0 grep -liwZ GUI | xargs -0 rm -f
```

```bash
grep -liwZ GUI | xargs -0 rm -f
```

Either of the above will remove any file containing "GUI". (Thanks, S.C.)

Example 12–4. Logfile using xargs to monitor system log

```bash
#!/bin/bash

# Generates a log file in current directory
# from the tail end of /var/log/messages

# Note: /var/log/messages must be world readable
# if this script invoked by an ordinary user.
# # root chmod 644 /var/log/messages

LINES=5

( date -a ) >> log
# Time and machine
tail -f /var/log/messages | xargs fmt -s >> log
exit 0
```

Example 12–5. copying files in current directory to another, using xargs

```bash
#!/bin/bash

# Copy (verbose) all files in current directory to directory specified on command line.
if [ -z "$1" ]; # Exit if no argument given.
then
  echo "Usage: $0 directory-to-copy"
  exit 1
fi

ls | xargs -i -t cp {} "$1" # This is the exact equivalent of cp unless any filenames has "whitespace".
exit 0
```

All-purpose evaluator: expr evaluates arguments according to operation (must be separated by spaces). Operations may be arithmetic, comparison, or logical.

```bash
expr 3 + 5 returns 8
expr 5 * 3 returns 15
expr 5 % 3 returns 2
```

The multiplication operator * must be escaped when used in arithmetic expression.

```bash
y=`expr $y + 1` # Increment a variable, with the same effect as y=$((y+1))
```

Example 12–6. Using expr for substring

```bash
#!/bin/bash
# Demonstrating some uses of 'expr'
# Extract substring of $string starting at position.
z=`expr substr $string 2 6`
echo "Substring of $a", starting at position 2, and 6 chars long is "$b"

# 'match' operations similarly to 'grep' - uses Regular Expressions
b=`expr match "\$a" '[0-9]*'
echo Number of digits at the beginning of "$a" is $b
b=`expr match "\$a" '\([0-9]*' # Note escaped parentheses.
echo "The digits at the beginning of \"$a\" are "$b"

exit 0
```

The : operator can substitute for match. For example, b=expr $a : [0-9]* is equivalent of b=expr match $a [0-9]* in the above listing.

```bash
#!/bin/bash
echo
echo "String operations using \$expr $string string:\" construct
-----------------
a=1234zipper43231
echo "The string being operated upon is \$a"

# length: length of string
b='expr $a'
echo "Length of \$a is $b."

# index: position of first character in substring that matches a character in string
b='expr index $a 23'
echo "Numerical position of \"2\" in \$a is \$b."

# extract: substring, starting position & length used
b='expr substr $a 2 6"
```
