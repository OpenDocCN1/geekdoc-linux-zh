# Chapter 11. Internal Commands and Builtins

A builtin is a **command** contained within the Bash tool, literally built in. A builtin may be a synonym to a system command of the same name, but Bash reimplements it internally. [23] For example, the Bash **echo** command is not the same as `/bin/echo`, although its behavior is almost identical.

A *keyword* is a reserved word, token or operator. Keywords have a special meaning to the shell, and indeed are the building blocks of the shell's syntax. As examples, "for", "while", and "!" are keywords. Similar to a builtin, a keyword is hard-coded into Bash, but unlike a builtin, a keyword is not by itself a command. [24]

# I/O

echo

prints (to `stdout`) an expression or variable (see Example 5–1).

```
echo Hello
echo $$
```

An **echo** requires the `-e` option to print escaped characters. See Example 6–2.

Normally, each **echo** command prints a terminal newline, but the `-n` option suppresses it.

An **echo** can be used to feed a sequence of commands down a pipe.

```
if echo "$VAR" | grep -q txt; # if [[ $VAR == *txt* ]]
then
    echo "$VAR" contains the substring sequence "\txt\t"
fi
```

An **echo**, in combination with [command substitution] can set a variable.

```
a=``echo "HELLO" | tr A-Z a-z`
```

See Example 12–15, Example 12–2, Example 12–30, and Example 12–31.

Be aware that `echo command` deletes any newlines that the output of `echo` generates.

The **IFS** (internal field separator) normally contains `
` (newline) as one of its whitespace characters. Bash splits the input into arguments by linefeeds. Then `echo` outputs these arguments, separated by spaces.

```
bash ls -l /usr/share/apps/kjerz/sounds
-rw-r-- 1 root root 1407 Nov 7 2000 reflect.au
-rw-r-- 1 root root 362 Nov 7 2000 seconds.au
```
