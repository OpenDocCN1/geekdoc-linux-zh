* [:xdigit] matches hexadecimal characters. This is equivalent to [0-9A-Fa-f].

POSIX character classes generally require or double brackets ([[:).

```
bash$ grep [[[:digit:]]] test.file
ab=723
```

These character classes may be used with globbing, to a limited extent.

```
bash$ ls -1 [[[:digit:]][[:digit:]]?
--rw-r--r-- 1 bozo Aug 21 14:47 a33b
```

# 19.2 Globbing

Bash itself not recognize Regular Expressions. In scripts, commands and utilities, such as sed and awk, interpret RE's.

Bash carries out file expansion, a process known as "globbing", and expands wildcards. Glob interprets the standard wildcard characters, * and ?, list in square brackets, and certain other special characters (such as ^ for negating the sense of a match). There are some limitations on wildcard in globbing, however strings * will not match filenames that start with a dot, for example, .bashrc. [49] Likewise, the ? has a different meaning in globbing than as part of a RE.
