## 17. 在此文档 (Here Documents)

在此文档使用 I/O 重定向的一种特殊形式，将命令脚本传递给交互式程序，例如 telnet 或 ex。通常，该脚本由一组由限制字符串分隔的命令列表组成。特殊符号 << 位于限制字符串之前。这具有将文件输出重定向到程序的效果，类似于 interactive-program < command-file，其中 command-file 包含：

```
command #1
command #2
...
```

“在此文档”的写法如下：

```bash
#!/bin/bash
interactive-program <<LimitString
command #1
command #2
...
LimitString
```

选择一个特殊的限制字符串，使其不会在命令列表中任何地方出现并引起混淆。注意，在此文档有时与非交互式工具和命令结合良好良好。

## 示例 17–1. dummyfile：创建一个 2 行的伪文件

```bash

# 非交互式使用 'vi' 编辑文件。
# 模拟 'sed'。

E_BADARGS=65

if [ -z "$1" ]
then
  echo "用法: $0 <filename>"
  exit $E_BADARGS
fi

TARGETFILE=$1

# 在文件中插入 2 行并保存。
#------在此文档开始------
vi $TARGETFILE <<LimitString
i
这是示例文件的第 1 行。
这是示例文件的第 2 行。
ZZ
LimitString
#------在此文档结束------
```
