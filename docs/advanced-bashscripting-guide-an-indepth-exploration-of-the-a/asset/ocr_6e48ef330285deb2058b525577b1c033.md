character translation filter.

> Must use quoting and/or brackets, as appropriate. Quotes prevent the shell from reinterpreting the special characters in tr command sequences. Brackets should be quoted to prevent expansion by the shell.

Either tr "A-Z" "*" <filename or tr A–Z \ <filename all changes the uppercase letters in filename to asterisks (to stdout). On some systems this may not work, but tr A–Z '[**]' will.

The -d option deletes a range of characters.

```
echo abcdef # abcdef
echo abcdef | tr -d b-d # aef

tr -d 0-9 <filename
# Deletes all digits from the file "filename".
```

The --squeeze-repeats (or -s) deletes all but the first instance of a string of consecutive characters. This option is useful for removing excess whitespace.

```
bash$ echo "XXXX" | tr --squeeze-repeats 'X'
X
```

The -c "complement" option inverts the character set to match. With this option, tr acts only upon those characters not matching the specified set.

```
bash$ echo "acdef123" | tr -c b-d + 
+c+d+b++++
```
