```
old_tty_setting=$($stty) # Save old terminal setting.
echo "Hit a key " # Disable *canonical* mode for terminal.
stty -icanon -echo # Also, disable *local* echo.
key=$(dd bs=count=1 2>/dev/null) # Using 'dd' to get a keypress.
stty $old_tty_setting # Restore old setting.
echo "You hit ${key}" # ${(variable)} = number of characters in $variable

# Hit any key except RETURN, and the output is "You hit 1 key."
# Hit RETURN, and it's "You hit 0 key."
# The newline gets in the command substitution.
```

Using echo to output an unquoted variable with command substitution removes trailing characters from the output of the reassigned command($s). This can cause unpleasant surprises.

```
dir_listing=`ls -l'
echo $dir_listing # unquoted

# Expecting a nicely ordered directory listing.

# However, what you get:
# total 3 -rw-rw-r-- 1 bozo 30 May 13 13:17:15 1.txt -rw-rw-r-- 1 bozo
# bozo 51 May 15 20:57:t2 t.sh -rwxr-xr-x 1 bozo 21 Mar 5 21:23:11 wi.sh
```

```
echo "$dir_listing" # quoted
# -rw-rw-r-- 1 bozo 30 May 13 13:17:15 1.txt
# -rw-rw-r-- 1 bozo 51 May 15 20:57:t2.sh
# -rwxr-xr-x 1 bozo 21 Mar 5 21:23:11 wi.sh
```

```
# The newline disappeared.
```

Command substitution assigns a variable to the contents of a file, using redirection or the cat command.

```
variable1='file' # Set "variable1" to contents of "file"
variable2='cat file2' # Set "variable2" to contents of "file2".
```

```
# Be aware that your variable may contain whitespace,
# or even (horrors), control characters.
```
