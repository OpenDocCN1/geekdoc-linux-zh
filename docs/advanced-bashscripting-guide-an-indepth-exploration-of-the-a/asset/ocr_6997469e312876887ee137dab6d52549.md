command-1 | command-2 || command-3 || ... command-n
Each command executes true for as long as the previous commands false. At the first
true return, the command chain terminates (the first command returning true is the last one to
execute). This is obviously the inverse of the "and" and "list".

Example 25-3. Using "or lists" in combination with an "and list"

```
#!/bin/bash

# "Delete", not-so-coining file deletion utility.
# Usage: delete filename

_BADARGS=65

if [ -z "$1" ]
then
    echo "Usage: `basename $0` filename"
    exit $E_BADARGS
fi
```

```
file=$1 # Set filename

[ -f "$1" ] && echo "File \$1\" not found. \
Cowardly refusing to delete a nonexistent file.
# AND LIST, to give error message if file list not present.
# Note echo message continued on a second line with an escape.

[ -f "$1" ] || (rm -f $1; echo "File \$file\" deleted")
# OR LIST, to delete if present.
# ( command1 ; command2 ) is, in effect, an AND LIST variant.
```

```
# Note logic inversion above.
# AND LIST executes on true, OR LIST on false.

exit 0
```

If the first command in an "and list" or "or list" returns true, it will execute.

The exit status of an and list or or list is the exit status of the last command executed.
