## Example 16–9. Logging events

```bash
#!/bin/bash
# logevents.sh, by Stephanie Chazelas

# Event logging to a file.
# Must be run as root (for write access in /var/log).

ROOT_UID=0          # Users with UID 0 have root privileges.
E_NOTROOT=67       # Non-root exit error.

if [ [ "$UID" -ne "$ROOT_UID" ];
then
    echo "Must be to root to run this script."
    exit $E_NOTROOT
fi

FD_DEBUG1=3
FD_DEBUG2=4
FD_DEBUG3=5

# Uncomment one of the two lines below to activate script.
# LOG_EVENTS=1
# LOG_VARS=1

```

```bash
{
  echo "$(date)  $*&7  # This appends the date to the file.
  # See below.
}
```

```bash
case $LOG_LEVEL in
1) exec $3&2 4> /dev/null 5 >/dev/null;
2) exec $3&2 5 >/dev/null;
3) exec $3&2 4>& 5>&2;
*) exec $3 >/dev/null 4> /dev/null 5 >/dev/null;
esac
```

```bash
FD_LOGARS=6
if [[ $LOG_VARS ]]
then exec 6 >/var/log/vars.log
else exec 6 >/dev/null
# Bury output.
fi
```

```bash
FD_LOGEVENTS=7
if [[ $LOG_EVENTS ]]
then
# exec 7>(exec ' 'print strftime(), $0)' >> /var/log/event.log)

# Append to "event.log".
log
# Write time and date.
else exec 7> /dev/null
# Bury output.
fi
```

```bash

echo "Done"  # command2
```

```

## Chapter 17. Here Documents

A here document uses a special form of I/O redirection to feed a command script to an interactive program, such as | telnet or ex. Typically, the script consists of a command list to the program, delineated by a limit string. The special symbol << precedes the limit string. This has the effect of redirecting the output of a file into the program, similar to interactive-program < command-file, where command-file contains

```
command #1
command #2
...
```

The "here document" alternative looks like this:

```bash
#!/bin/bash
interactive-program <<LimitString
command #1
command #2
...
LimitString
```

Choose a limit sufficiently unusual that it will not occur anywhere in the command list and confuse matters.

Note that here documents may sometimes be used to good effect with non-interactive utilities and commands.

## Chapter 17. Here Documents

A here document uses a special form of I/O redirection to feed a command script to an interactive program, such as | telnet or ex. Typically, the script consists of a command list to the program, delineated by a limit string. The special symbol << precedes the limit string. This has the effect of redirecting the output of a file into the program, similar to interactive-program < command-file, where command-file contains

```
command #1
command #2
...
```

The "here document" alternative looks like this:

```bash
#!/bin/bash
interactive-program <<LimitString
command #1
command #2
...
LimitString
```

Choose a limit sufficiently unusual that it will not occur anywhere in the command list and confuse matters.

Note that here documents may sometimes be used to good effect with non-interactive utilities and commands.
