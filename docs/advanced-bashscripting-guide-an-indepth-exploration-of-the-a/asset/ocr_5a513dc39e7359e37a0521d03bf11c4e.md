# #34.4. Optimizations

Most shell scripts are quick 'dirty solutions to non-complex problems. As such, optimizing them for speed is not much of an issue. The case, though, where a script carries out an important task, does well, but runs too slowly. Rewriting it in a compiled language may not be a palatable option. The simplest fix would be to rewrite the parts of the script that slows it down. It is possible to apply principles of code optimization even to a lo ownly shell script

Consider the loops in the script. Time spent by repetitive operations adds up quickly. Use the time to profile computation–intensive commands. Rewriting time–critical code sections in C, or even in assembler

Try to minimize i/o. Bash is not particularly efficient at handling files, so consider using more appropriate tools for this within the script, such as awk or Perl.

Try to write your scripts in a structured, coherent form, so they can be reorganized and tightened up as necessary. Some of the optimization techniques applicable to high–level languages may work for scripts, but others, such as loop unrolling, are mostly irrelevant. Above all, use common sense.

# #34.5. Associated Tips

+   - To keep a record of which user scripts have run during a particular session or over a number of sessions, add the following lines to each script to keep track of. This will keep a continuing file record of script names and invocations.

```
# Append (>>) following to end of each script tracked.

date >> $SAVE_FILE    #Date and time.
echo >> $SAVE_FILE    #Script name.
echo>> $SAVE_FILE      #Blank line as separator.
```

> # Of course, SAVE_FILE defined and exported as environmental variable in ~/.bash
# (something line ./scripts-run)

+   - The >> appends lines to a file. If you want to prepend a line to an existing file, that is, to paste it in the beginning?

```
file=data.txt
title***This is the title line of data text file****
echo $title | cat $file >$file.new # concatenates stdout to $file.
# Result is\+# to write a new file with $title appended at *beginning*.
```

Of course, sed can do this.
