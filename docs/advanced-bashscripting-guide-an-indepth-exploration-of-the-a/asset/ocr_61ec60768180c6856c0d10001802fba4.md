```
# RANDOM=$$ seeds RANDOM process from id of script.
# It is also possible to seed RANDOM from 'time' or 'date' commands.
# Getting fancy...
SEED=$(head -1 /dev/urandom | od -N1 | awk '{ print $2 }')
# Pseudo-random output fetched
# from /dev/urandom (system pseudo-random device-file),
# then converted to line of printable (octal) numbers by "od"
# finally $SEED retrieves just one number for SEED.
RANDOM=$SEED
random_numbers
```

The /dev/urandom device-file provides a means of generating more $RANDOM variable. dd if=/dev/urandom of=target bs=1 count=XX creates a file of well-scattered pseudorandom numbers. However, assigning these numbers to a variable in a script requires a workaround, such as filtering through od (see above example) or using dd (see Example 12–36).

There are other means of generating pseudorandom numbers in a script. Awk provides a means of generating this.
