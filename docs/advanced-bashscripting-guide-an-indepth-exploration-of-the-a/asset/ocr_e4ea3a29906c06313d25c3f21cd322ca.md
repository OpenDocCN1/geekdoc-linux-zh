Since you may not wish to wipe out the entire system, this variant of the first script keeps the last section of the message log. You will constantly discover ways of refining scripts for increased effectiveness.

The *sha-bang* (#) at the head of a script tells your system this is a set of commands to be fed to the command interpreter. The # is actually a two-byte [magic number", a special marker that designates a file type, or in the case of an executable shell (see **man magic** for details on this fascinating topic). Immediately following the *sha-bang* is a path name. This is the path to the program that interprets the commands, whether it be a shell, a programming language, or a utility. This command interpreter executes the commands in the script, at the top (line 1 of the script), [5]

```
#!/bin/sh

```
