pipe. Passes the output of previous command to the input of the next one, or to the shell. This is a method of chaining commands together.

```
echo ls -1 | sh
# Passes the output of "echo ls -1" to the shell,
# with the same result as a simple "ls -1".
```

```
cat *.lst | sort
# Merges and sorts all ".lst" files, then deletes duplicate lines.
```

A pipe, as a classic method of interprocess communication, sends the stdout of one process to the stdin of another. In a typical case, a command, such as cat or echo, pipes a stream of data to filter.

```
cat $filename | grep $search_word
```

The output of a command or commands may be piped to a script.

```bash
#!/bin/bash
# uppercase.sh : Changes input to uppercase
tr 'a-z' 'A-Z' # Letter ranges must be quoted to prevent filename generation from single-letter filenames.
```

Now, pipe the output of ls -1 /uppercase.sh

```bash
bash ls -1 | /uppercase.sh
```

# Advanced Bash–Scripting Guide

```
variable="initial_value"
echo "new_value" | read variable
echo "$variable" = initial_value
```

The stdout of each process in a pipe must be read as the stdin of the next. If this is not the case, the data stream will block, and the pipe will not behave as expected.

```
cat file2 | ls -1
# The output from "cat file2" appears.
```

A pipe runs a child process, and therefore cannot alter variables.
