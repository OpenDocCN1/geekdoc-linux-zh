As we have seen in the last example, it is best to "reseed" the RANDOM generator each time it is invoked. Using the same seed for RANDOM repeats the same series of numbers. (This mirrors the behavior of random() function in C.)

# Example 9-23. Reseding RANDOM

```
#!/bin/bash
# seeding-random.sh: Seeding the RANDOM variable.

MAXCOUNT=25
# How many numbers to generate.
random_numbers() {
  count=0
  while [ "$count" -lt "$MAXCOUNT" ]
  do
    number=$RANDOM
  echo -n "$number "
    let count += 1
  done
  echo
}
```

```bash
RANDOM=1
random_numbers
```
