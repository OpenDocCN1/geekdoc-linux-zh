## 字符串比较

=
等于

```bash
if [ "$a" = "$b" ]
```

==
等于

```bash
if [ "$a" == "$b" ]
```
这是 = 的同义词。

```bash
[[ $a == z* ]] # 如果 $a 以 "z" 开头则为真（模式匹配）
[[ $a == z* ]] # 如果 $a 等于 z* 则为真

[ $a == z* ]   # 会发生通配符展开和单词分割
[ "$a" == z* ] # 如果 $a 等于 z* 则为真
```

- !=
不等于

```bash
if [ "$a" != "$b" ]
```
此运算符在 [...] 结构内部使用模式匹配。

- <
小于，按照 ASCII 字母顺序

```bash
if [ "$a" < "$b" ]
```
```bash
if [ "$a" \< "$b" ]
```
注意在 [ ] 结构内对 "<" 需要进行转义。

- >
大于，按照 ASCII 字母顺序

```bash
if [ "$a" > "$b" ]
```
```bash
if [ "$a" \> "$b" ]
```
注意在 [ ] 结构内对 ">" 需要进行转义。
参见示例 26–4 关于此比较运算符的应用。

- -z
字符串为 "null"，即长度为 0

- -n
字符串不为 "null"。

-n 测试绝对要求字符串在测试括号内加引号。虽然像 -z 那样使用不引号的字符串，或者仅在测试括号内使用不引号字符串（示例 7–5）通常可以运行，但这是一种不安全的做法。始终对测试的字符串加引号。

### 示例 7–4 算术与字符串比较

```bash
#!/bin/bash

a=4
b=5

# 这里 "a" 和 "b" 可以被视为整数或字符串。
# 算术和字符串比较之间存在某些模糊，
# 因为 Bash 变量不是强类型的。

# Bash 允许对由全整数字符组成的变量进行算术运算和比较。
# 请注意。

if [ "$a" -ne "$b" ]
then
    echo "$a is not equal to $b"
    echo "(arithmetic comparison)"
fi

if [ "$a" != "$b" ]
then
    echo "$a is not equal to $b."
    echo "(string comparison)"
fi
```
在此情况下，"-ne" 和 "!=" 均有效。

### 示例 7–5 检查字符串是否为空

```bash
#!/bin/bash
# str-test.sh: 测试空字符串和未加引号字符串，
# 但不测试空字符串以及...

# 使用 if [ ... ]
# 如果字符串没有初始化，则没有值。
# 这种状态被称为 "null"不同于零）。
if [ -n "$1" ]
then
    echo "$1 is not null."
else
    echo "$1 is null."
fi
# 结果错误。
# 显示 $1 不空，尽管它没有被初始化。
```

### 示例 7–6 zmost

```bash
#!/bin/bash
# 使用 'most' 查看压缩文件

NOARGS=65
NOTFOUND=66
NOTZIP=67

if [ $# -eq 0 ]; # 效果等于：if -z "$1" ]
  # $1 可以存在，但为空
then
  echo "Usage: basename $0 filename" >&2
  # 错误信息输出到 stderr
  exit NOARGS
  # 返回 65 作为脚本的退出状态（错误代码）。
fi

filename=$1

if [ ! -f "$filename" ]; # 为 $filename 加引号允许可能存在空格。
then
  echo "File $filename not found!" >&2
  # 错误信息输出到 stderr
  exit NOTFOUND
fi

if [ "${filename#*.}" != "gz" ]; # 在变量替换中使用括号。
then
  echo "File $1 is not a zipped file!"
  exit NOTZIP
fi

zcat $1 | most
```
# 使用文件查看器 'most'（类似于 'less'）。
# 后版本的 'most' 具有文件解压功能。
# 根据需要可以替代 'more' 或 'less'。

exit $? # 脚本返回管道的退出状态。
# 实际上返回 $? 没有必要的，因为脚本无论如何
#都会返回最后一个执行命令的退出状态。

## 复合比较

- -a

如果 expl1 和 exp2 都为真则 expl1 -a exp2 返回真。


## 7.4. 嵌套 if/then 条件测试

使用 if/then 结构的条件测试可以嵌套。其最终结果与使用上述的 && || 比较运算符相同。

```bash
if [ condition1 ]
then
  if [ condition2 ]
  then
    do-something # 但仅当 "condition1" 和 "condition2" 有效时执行。
  fi
fi
```
参见示例 35–4 关于嵌套 if/then 条件测试的示例。

## 7.5. 测试对测试的理解

系统级 xinitrc 文件可用于启动 X 服务器。该文件包含许多 if/then 测试，如下所示所示。

```bash
if -f $HOME/.Xclients ]; then
  exec $HOME/.Xclients
elif [ -f /etc/X11/xinit/Xclients ]; then
  exec /etc/X11/xinit/Xclients
else
  # 故障设置。虽然我们在 Xclients 中也提供了备用方案，但无无益。
  xclock -geometry 100x50+5 &
  xterm -geometry 800x50+150 &
  if [ -f /usr/bin/netscape -a f /usr/share/doc/HTML/index.html ]; then
    netscape /usr/share/doc/HTML/index.html &
  fi
fi
```
解释上述摘录中的 "test" ，然后检查整个文件 /etc/X11/xinitrc 并分析 if/then 测试。你可能需要参考 grep、sed 和正则表达式的讨论。
