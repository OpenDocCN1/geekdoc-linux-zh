# Advanced Bash–Scripting Guide

f1 -nt f2

file $f1 is newer than $f2

f1 -ot f2

file $f1 is older than $f2

f1 -ef f2

files $f1 and $f2 are hard links to the same file

!

"not" — reverses the sense of the tests above (returns true if condition absent).

```
if [ "$a" -ne "$b" ]
```

-gt

```
if ["$a" -gt "$b" ]
```
