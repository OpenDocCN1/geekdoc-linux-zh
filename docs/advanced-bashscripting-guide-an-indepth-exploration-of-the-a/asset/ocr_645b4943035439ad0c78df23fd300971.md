xargs

A filter for feeding arguments to a command, and also a tool for assembling the commands themselves. It breaks a data stream into small chunks for filters and commands to process. Consider it as a powerful replacement for backquotes. In situations where backquotes fail with too many arguments error, substituting **xargs** works. Normally, xargs reads from `stdin` or from a pipe, but it can also be seen from the output of a file.

The default command for **xargs** is `echo`. This means input piped to xargs may have linefeeds and other whitespace stripped out.

```
bash$ ls -l
total 0
-rw-rw--      1 bozo bozo 0 Jan 29 23:58 filel
-rw-rw--      1 bozo bozo 0 Jan 29 23:58 file2
```

```
bash$ ls -1 | xargs
total 0 -rw-rw-- 1 bozo 0 Jan 29 23:58 file -rw-rw-- 1 bozo 0 Jan 29 23:58
```

`ls | xargs -p -I gzip gzip` every file in current directory, at one time, prompting each operation.

![](bbox=[0.308, 0.553, 0.342, 0.583])

An interesting xargs option is `-n NN`, which limits to NN the number of arguments passed.

`ls | xargs -n 8 echo` lists the files in the current directory in 8 columns.

![](bbox=[0.308, 0.673, 0.342, 0.703])

Another useful option is `-0`, in combination with `find -print0` or `grep -Z`. This allows handling arguments containing whitespace or quotes.

```
find /type f -print0 | xargs
-0 grep -liwZ GUI | xargs -0 rm
-f
```

```
grep -liwZ GUI | xargs -0 rm
-f
```

Either of the above will remove any file containing "GUI". (Thanks, S.C.)
