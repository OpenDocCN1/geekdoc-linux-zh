## Chapter 28. /dev and /proc

A Linux or UNIX machine typically has two special-purpose directories, /dev and /proc.

### 28.1./dev

The /dev directory contains entries for the physical devices that may or may not be present in the hardware. [57] The hard dev partitions containing the mounted filesystem(s) have entries in /dev, as a simple df shows.


Among things, the /dev directory also contains loopback devices, such as /dev/loop0. A loopback device is a gimmick an ordinary file to be accessed as if it were a block device. [158] This enables mount an entire filesystem within a single large file. See Example 13-6 and Example 13-5.

A few of the pseudo-devices in /dev have other specialized uses, such as /dev/null, /dev/zero and /dev/urandom.

The /proc directory contains subdirectories with unusual names. Every one of these maps to the process ID of a currently running process. Within each of these subdirectories are files that hold useful information about the corresponding process. The stat and status files keep running statistics, the cmdline file holds the command arguments the process was invoked with, and the exe file is a symbolic link to the complete path of invoking. There are a few more such files, but these seem to be the most interesting from a scripting standpoint.

### Example 28–1. Finding the process associated with PID

```bash
#!/bin/bash
# pid-identifier.sh: Gives path name to process associated with pid

ARGNO=$# Number of arguments the script expects.
E_WRONGARGS=65
E_BADPID=66
E_NOSUCHPROCESS=67
E_NOPERMISSION=68
PROFILE=$

if [ $ARGNO -ne 1 ]; then
    echo "Usage: $0 PID" >&2 # Error message to stderr.
    exit $E_WRONGARGS
fi

pidno=$(ps ax | awk '{ print $1 }' | grep $1)
# Checks for pid in "ps" listing.
# Then makes the actual process invoked by this script, the grep filters out this process.
if [ -z "$pidno" ];
then
    # If, after all filtering, the result is a zero-length string,
    echo "No such process running."
    # The process corresponds to the pid given.
    exit $E_NOSUCHPROCESS
fi

Alternatively:
if ! kill -0 $1 /dev/null 2>&1; then
    # The process corresponds to the pid given.
    echo "No such process running."
    exit $E_NOSUCHPROCESS
fi

# To simplify the entire process, use "pidof"

if [ -r "/proc/$1/$PROFILE" ]; then # Check for read permission.
    echo "Process $1 running, ..."
    echo "Can't read permission on /proc/$1/$PROFILE." # Ordinary user can't access some files in /proc.
# The last two lines may be replaced by:
if ! kill -0 $1 /dev/null 2>&1; # '0' is not a signal, but this will test whether it is possible to send a signal to the process.
then
    echo "PID does not exist or you're not its owner" >&2
    exit $E_BADPID
fi

exe_file=$(ls -1 /proc/$1 | grep "exe" | awk '{ print $1 }')
# Or file=$(ls -l /proc/$1/exe | awk '{print $1 }')

# /proc/$1/exe is a symbolic link to the complete path name of invoking the process.
if [ -e "$exe_file" ]; # If /proc/$1/exe exists...
then
    # The corresponding process exists.
    echo "Process $1 invoked by $exe_file."
else
    echo "No such process running."
fi

# This elaborate script can "almost" be replaced by
# ps ax | grep $1 | awk '{ print $5 }'
# However, this will not work because the fifth field of 'ps' is argv[0] of the process not the executable file path.
# However, either of the following would work:
# find /proc/$1/exe -printf '%l\n'
# lsof -afn -p $1 -d txt sed -ne 's//p'

# Additional commentary by Stephane Chazelas.

exit 0
```

### Example 28–2. Online connect status

```bash
#!/bin/bash
PROCNAME=pppd # p daemon
PROCFILENAME=status # Where to look.
NOTCONNECTED=65
INTERVAL=2

# Update every 2 seconds.
pidno=$(ps ax | grep -v "ps ax" | grep -v grep | grep $PROCNAME | awk '{ print $1 }')
# Finding the process number of 'pppd', # p daemon
# Have to filter out the process lines generated by the search itself.
# However, as Oleg Philon points out, this could have been considerably simplified by using "pidof".
# pidno=$(pidof $PROCNAME)

# Moral of the story:
# When a command sequence gets too complex, look for a shortcut.
if [ -z $pidno ]; # If no pid, then process is not running.
then
    echo "$NOTCONNECTED"
    exit $NOTCONNECTED
else
    echo "Connected."; echo
fi

while [ true ]; # Endless loop, script can be improved here.
do
    if [ ! -e /proc/$pidno/$PROCFILENAME ]; # While process running, then "status" file exists.
    then
        echo "Disconnected."
        exit $NOTCONNECTED
    fi

    netstat -s grep "packets received" # Get some connect statistics.
    netstat -s grep "packets delivered"

    sleep $INTERVAL
    echo; echo
done
exit 0
```
