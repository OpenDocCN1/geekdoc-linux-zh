# Local Network

write

This is a utility for terminal–to–terminal communication. It allows sending lines from your terminal (console or xterm) to that of another user. The msg command may, of course, be used to disable write access to a terminal

Since write is interactive, it would not normally find use in a script.

# Mail

mail

Send an e–mail message to a user.

This stripped–down command–line mail client works as a command embedded in a script.

# Example 1–29. A script that mails itself

```
#!/bin/sh
# self-mailer.sh: Self-mailing script
ARGCOUNT=1      # Need name of addressee.
E_WRONGARGS=6
if [ $# -ne $ARGCOUNT ];
then
  echo "Usage: `basename $0` addressee"
  exit $E_WRONGARGS
fi

cat $0 | mail -s "Script `basename $0` has mailed itself to you." "$1"

# Greetings from the self-mailing script.
# A mischievous person has run this script,
#+ which caused it to mail itself to you.
#+ Apparently, some people have nothing better
#+ to do with their time.
#
\exit 0
```

This utility automatically replies to e–mails that the intended recipient is on vacation and temporarily unavailable. This runs on a network, in conjunction with sendmail, and is not applicable to a dial–up POP account.
