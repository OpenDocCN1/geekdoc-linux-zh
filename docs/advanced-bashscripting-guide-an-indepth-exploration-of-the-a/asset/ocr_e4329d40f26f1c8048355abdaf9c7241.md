# Advanced Bash–Scripting Guide

expr "$string" : '$substring`

$substring is a regular expression.

```
stringZ=abcABC123Ababc
# -----------
echo expr match "$stringZ" 'abc[A-Z].*' # 8
echo expr "$stringZ" : 'abc[A-Z].*' # 8
```

# Index

expr index $string $substring

Numerical position in $string of first character in $substring that matches.

```
stringZ=abcABC123Ababc
echo expr index "$stringZ" C12 # 6
# C position.
```

```
echo expr index "$string" lc # 3
# 'c' (in #3 position) matches before '1'
```

This is the near equivalent of strchr(rt).

# Substring Extraction

$${string:position}:

Extracts substring from $string at $position.

If the string parameter is "*" or "@", then it extracts the positional parameters, [201] starting at position.

$${string:length}:

Extracts $length characters of substring from $string at $position.

```
stringZ=abcABC123Ababc
0123456789....n# 0-based indexing.
```

```
echo $${stringZ:0} # abcABC123Ababc
echo $${stringZ:1} # bcABC123Ababc
echo $${stringZ:7} # 23ABCabc
```

```
echo $${stringZ:7:3} # 23A
# Three characters of substring.
```

If the string parameter is "*" or "@", then it extracts a maximum of length positional parameters, starting at position.

```
echo $${*:2} # Echoes second and following positional parameters.
echo $${@:2} # Same as above.
```
