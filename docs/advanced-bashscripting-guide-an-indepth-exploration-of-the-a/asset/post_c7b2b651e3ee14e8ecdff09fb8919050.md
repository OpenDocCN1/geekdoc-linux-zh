## 34.2. Shell Wrappers

A "wrapper" is a script that wraps a system command or utility, that saves a set of parameters passed to that command. Wrapping a script around a complex command simplifies invoking it. This is especially useful with sed awk.

A sed or awk would normally be invoked from the command line by a sed -e 'commands' or awk 'commands'. Embedding such a script in a Bash script permits calling it simply, and makes it "reusable". This also enables combining functionality of sed and awk, for example piping the output of a set of sed commands to awk. As a saved executable file, you can then invoke it in its original form or modified, without the inconvenience of retyping it on the command line.

Example 34–1. shell wrapper

```bash
#!/bin/bash
# This is a simple script that removes blank lines from a file.
# No argument checking.

# Same as
# sed -e '^$/d' filename
# invoked from the command line.
sed -e '/$/d' "$"
# The '-e' means an "editing" command follows (optional here).
# '^' is the beginning of the line, '$' is the end.
# This match lines with nothing between the beginning and the end,
# blank lines.
# 'd' is the delete command.

# Quoting the command-line arg permits
# whitespace and special characters in the filename.
```

exit 0

# Example 34–2. A slightly more complex shell wrapper

```bash
#!/bin/bash

# "sub", a script that substitutes one pattern for
# another in a file,
# i.e., "Smith Jones letter.txt".

ARGS=3
E_BADARGS=65    # Wrong number of arguments passed to script.

if [ $# -ne "$ARGS" ];
    # Test number of arguments to script (always a good idea).
then
    echo "Usage: basename $0 old-pattern new-pattern filename"
    exit $E_BADARGS
fi

old_pattern=$1
new_pattern=$2

if [ -f "$3" ];
then
    file_name="$3"
else
    echo "File $3 does not exist."
    exit $E_BADARGS
fi

# Here is where the heavy work gets done.
sed -e "s/$old_pattern/$new_pattern/g" "$file_name"
# 's' is, of course, the substitute command in sed,
# and /pattern/ invokes substitution for "every*"
# The "q", or global flag causes substitution for "every*"
# occurrence of $old_pattern each line, not just the first.
# Read the literature on 'sed' for a more in-depth explanation.

exit 0    # Successful invocation of the script returns 0.
```
