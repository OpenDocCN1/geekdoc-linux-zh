# 34.7. Portability Issues

This book deals specifically with scripting on a GNU/Linux system. All the same, users of sh and ksh will find much of value here.

As it happens, many of the various shells and scripting languages seem to be converging toward the POSIX 1003.2 standard. Invoking Bash with the --posix option or inserting a set -o posix at the head of a script causes Bash to conform very closely to this standard. Lacking this measure, most Bash scripts will run as-is under ksh, and vice-versa, since Chet Ratney has been pushing ksh features to the latest versions of Bash.

On a commercial UNIX machine, scripts using GNU-specific features of commands may not work. This has become less of a problem in the last few years, as the GNU utilities pretty displaced their proprietary counterparts even on "big-iron" UNIX. Calder's recent release of the source to many of the original UNIX utilities will only accelerate the trend.
