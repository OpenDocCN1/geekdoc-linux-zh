# Advanced Bash–Scripting Guide

Example 11–4. Using read with file redirection

```
#!/bin/bash

read var1 <data-file
echo var1=$var1
# var1 set to the entire first line of the input file "data-file"

read var2 var3 <data-file
echo var2=$var2 var3=$var3
# Note-non-intuitive behavior of "read" here.
# 1) Rewinds to the beginning of input file.
# 2) Each variable is set to a corresponding string,
# separated by whitespace, rather than to an entire line of text.
# 3) The final variable gets the remainder of the line.
# 4) If there are more variables to be seen as whitespace-terminated strings
# on the first line of the file, then the excess variables remain empty.

echo ""

# How to resolve the above problem with a loop:
while read
echo "line"
done <data-file
# Thanks, Heiner Steven for pointing this out.

echo ""

# Use $IFS (Internal Field Separator) to split a line of input to
# "read", if you do not want the default to be whitespace.

echo "List of all users:"
OIFS=$IFS; IFS=": /etc/passwd uses ":" for field separator.
while read name password uid guid fullname ignore
do
echo "$name" # I/O redirection.
done </etc/passwd
IFS=$OIFS # Restore original $IFS.
# This code snippet also by Heiner Steven.

exit 0
```
