+   The backslash \escapes a special character, which means that character gets interpreted literally.

A "$" reverts to its literal meaning of "$", rather than its RE meaning of end–of–line. Likewise \" has the literal meaning of "\".

+   Extended RESs. Used in egrep, awk, and Perl

The question mark ? matches zero or one of the previous RE. It is generally used for matching single characters.

The plus + matches one or more of the previous RE. It serves a role similar to the *, but does not match zero occurrences.

```
# GNU versions of sed and awk can use "+",
# but it needs to be escaped.

echo allb sed -n '/al+b'
echo allb grep '/al+b'
echo allb awk '/al+b/'
# All above are equivalent.
```

+   Escaped curly brackets \[\\] indicate the number of occurrences of a preceding RE to.

It is necessary to escape the curly brackets because they have their literal character meaning otherwise. This usage is technically not part of the RE set.

\[0-9]\\]" matches exactly five digits (characters in the range of 0 to 9).

> Curly brackets are not available as an RE in the "classic" version of awk. However, awk has the --re-interval option that permits them (without escaping).

```
bash$ echo 2222 | awk --re-interval '/2(3)/'
2222
```

+   Parentheses ( ) enclose groups of REs. They are especially useful with the following "|" operator.
The | OR operator matches any of a set of alternate characters.

```
bash$ egrep 're(a(e)d' misc.txt
People who seem to be better informed than those who do not.
The clarinet pronounces by the vibration of its reed.
```
