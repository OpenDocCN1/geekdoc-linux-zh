
# B.2. Awk

**Awk** is a full-featured text language with a syntax reminiscent of **C**. While it possesses an extensive set of operators and capabilities, we will cover only a couple of these – the ones most useful for shell scripting.

Awk breaks each line of input passed to into *fields*. By default, a field is a string of consecutive characters separated by whitespace; there are options for changing the delimiter. Awk parses and operates on each field. This makes awk ideal for handling structured text files, especially tables, data data organized into chunks, as rows and columns.

Strong quoting (single quotes) and curly brackets enclose segments of awk code within a shell script.

```
awk 'print $3' $filename
# Prints field #3 of $filename to stdout.
```
