# 2.1. Invoking the script

Having written the script, you can invoke it by sh scriptname, [18] or alternately bash scriptname. (Not recommended is using sh <scriptname, since this effectively disables reading from stdin within the script.) More convenient is to make the script itself directly executable with chmod.

Either:

```
chmod 555 scriptname (gives everyone read/execute permission) [9]

chmod +rx scriptname (gives everyone read/execute permission)

chmod u+rx scriptname (gives only the owner read/execute permission)
```

or

Having made the script executable, you may now test it by ./scriptname. [10] If it begins with a "sha-bang" line, the script calls the correct command interpreter to run it.

As a final step, after testing and debugging, you would likely like to move it to /usr/local/bin (as root, of course), to make the script available to yourself and all other users as a system-wide executable. The script could then be invoked by simply typing scriptname [ENTER] from the command line.
