and (logical)

```
if [ $condition1 ] && { $condition2 }
# Same as: if [ $condition1 -a $condition2 )
# Returns true if both condition and condition hold true...
if [[ $condition && $condition2 ]] # Also works.
# Note that && operator not permitted within [ ... ] construct.
```

&& may also, depending on context, be used in
and list to concatenate commands.

or (logical)

```
if [ $condition1 ] || [ $condition2 ]
# Same as: if [ $condition1 -o $condition2 )
# Returns true if either condition or condition2 holds true...
if [[ $condition1 || $condition2 ]] # Also works.
# Note that || operator not permitted within [ ... ] construct.
```

Bash tests the exit status of each statement
linked with a logical operator.

# Example 8–3. Compound Tests Using && and ||

```
#!/bin/bash
a=24
b=47
if [ "$a" -eq 24 ] && [ "$b" -eq 47 ]
then
  echo "Test #1 succeeds."
else
  echo "Test #1 fails."
fi
# ERROR: if [ "$a" -eq 24 ] && [ "$b" -eq 47 ]

if [ \$a -eq 24 ] && \$b -eq 44 ]
# works

```
