```
[j]<filename
# Open file "filename" for reading and writing, and assign file descriptor "j" to it.
# If "filename" does not exist, create it.
# If file descriptor "j" is not specified, default to fd 0, stdin.

# An application of this is writing at a specified place in a file.
echo 1234567890 > File # Write string to "File".
exec 3<4 File # Open "File" and assign fd 3 to it.
read -n 4 <3 # Read only 4 characters.
echo -n . >&3 # Write a decimal point there.
exec 3->4 # Close fd 3.
cat File == 1234.67890
# Random access, by golly.
```

```
|# Pipe.
# General purpose process and command chaining tool.
# Similar to ">", but more general in effect.
# Useful for chaining commands, scripts, files, and programs together.

# Sorts the output of all .txt files and deletes duplicate lines
# finally saves results to "result-file"
```

# Closing File Descriptors

n<&-

Close input file descriptor n.

0<&-, <&-

Close stdin.

n>&-

Close output file descriptor n.

1>&-, >&-

Close stdout.

Child processes inherit open file descriptors. This is how pipes work. To prevent an fd from being inherited, close it.

```
# Redirecting only stderr to a pipe
exec 3>&1                               # Save current "value" of stdout.
ls -l 2>&1 >3 3<&- | grep bad 3>&-  # Close fd 3 for 'grep' (but not 'ls').
----                                     
exec 3>&                               # Now close it for the remainder of the script.
```

## 16.1. Using exec

The exec <filename redirects stdin to a file. From that point on, all stdin comes from file, rather than its normal source (usually keyboard input). This provides a method of reading a file by line and possibly passing line of input using sed and/or awk.

Example 16–1. Redirecting stdin using exec

```bash
#!/bin/bash
# Redirecting stdin using 'exec'
```

```
exec 6<&0               # Link file descriptor #6 with stdin.
exec 6<data-file      # stdin replaced by file "data-file"

read a1               # Reads first line of file "data-file"
read a2               # Reads second line of file "data-file"

echo
echo "Following lines from file."
echo $a1
echo $a2
echo "--------------------"
exec 0<&6 6&- # Now restore stdin from fd #6, where it had been saved,
# and close fd #6 (6<&) to free it for other processes to use.
```

## 16.2. Redirecting Code Blocks

Blocks of code, such as while, until, and for loops, even if/then blocks can also incorporate redirection of stdin. Even a function may use this form of redirection (see Example 16–7). The < operator at the end of code block accomplishes this.

Example 16–2. Redirected while loop

```bash
#!/bin/bash
if [ -z "$1" ]
then
  Filename=names.data   # Default, if no filename specified.
else
  Filename=${1:-names.data} # replace the above test (parameter substitution)
fi
count=0
while [ "$name" != "" ] # Why is variable $name in quotes?
read name      # Reads from $Filename, rather than stdin.
let "count" += 1
done <"$Filename" # Redirects stdin to file.
# Note that in older shell languages, the redirected loop would run as subshell.
# Therefore, $count would return 0, the initialized value outside the loop.
# Bash avoid starting subshell whenever possible, so this script, for example, runs correctly.
```

## Example 16–3. Alternate form of while loop

```bash
#!/bin/bash
# This is an alternate form of the preceding script.
# Suggested by Steven in those situations when redirect loop as subshell, and therefore variables inside the loop do not keep their values upon termination.
if [ -z "$1" ]
then
  Filename=names.data      # Default, if no filename specified.
else
  Filename=$1
fi
exec 3<&      Save stdin to file descriptor 3.
exec 0<"$Filename" # standard input.
count=0
while [ "$name" != "" ]
do
  read name                # Reads from redirected stdin ($Filename)
  echo $name
  let "count" += 1
done <"$Filename"      # Loop reads from file.
exec 0<&      # Restore old stdin.
exec 3>&      # Close temporary fd 3.
```

## Example 16–4. Redirected until loop

```bash
#!/bin/bash
# Same as previous example, but with "until" loop.
if [ -z "$1" ]
then
  Filename=names.data      # Default, if no filename specified.
else
  Filename=$1
fi

while [ "$name" != "" ]
until [ "$name" = "" ]
do
  read name
  echo $name
done="$Filename"        # Redirects stdin to file $Filename
```
Same results as "while" loop in previous example.

## Example 16–5. Redirected for loop

```bash
#!/bin/bash
if [ -z "$1" ]
then
  Filename=names.data      # Default, if no filename specified.
else
  Filename=$1
fi
line_count=$(wc < "$Filename" | awk '{ print $1 }') # Number of lines in target file. # Very converted and kludgy, nevertheless shows that it's possible to redirect stdin within a "for" loop... if you're clever enough. More concise is line_count=$(wc < "$Filename")

for name in `seq line_count`
while [ "$name" != "" ] # Recall that "seq" sequence of numbers. # more complicated than a "while" loop --
do
  read name
  echo $name
  if [ "$name" = "" ]
    # Need all this baggage here.
    break
  fi
  done <"$Filename"        # Redirects stdin to file $Filename
exit
```
We can modify the previous example to also redirect the output of the loop.

## Example 16-6. Redirected for loop (both stdin and stdout redirected)

```bash
#!/bin/bash

if [ -z "$1" ]
then
  Filename=names.data      # Default, if no filename specified.
else
  Filename=$1
fi
SaveFile=$Filename.new  # Filename to save results in.
FinalName=Jonah           # Name to terminate "read" on.

line_count=$(wc $Filename | awk '{ print $1 }') # Number of lines in target file.

for name in $(seq $line_count)
do
  echo "$name"
  if [ "$name" = "$FinalName" ]
  then
    break
  fi
done < "$Filename" > "$Savefile"
# Redirects stdin to file $Filename, and saves it to backup file.
exit
```

## Example 16-7. Redirected if/then test

```bash
#!/bin/bash

if [ -z "$1" ]
then
  Filename=names.data      # Default, if no filename specified.
else
  Filename=$1
fi

TRUE=1

if [ "$TRUE" ] # true and if : also work.
then
  read name
  echo $name
fi <"$Filename"
```
