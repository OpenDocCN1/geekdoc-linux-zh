ldd

Show shared lib dependencies for an executable file.

```
bash$ ldd /bin/ls
libc.so.6 => /lib/libc.so.6 (0x4000c000)
ld-linux.so.2 => /lib/ld-linux.so.2 (0x80000000)
```

strip

Remove the debugging symbolic references from an executable binary. This decreases its size, but making debugging of it impossible.

This command often occurs in a Makefile, but rarely in a shell script.

nm

List symbols in an unstripped compiled binary.

rdist

Remote distribution client: synchronizes, clones, or backs up a file system on a remote server.

Using our knowledge of administrative commands, let us examine a system script. One of the shortest and simplest to understand scripts is killall, to suspend running processes at system shutdown.

Example 13–8. killall, from /etc/rc.d/init.d

```
#!/bin/sh

# Comments added by the author of this document marked by "# -->"

# Bring all unneeded services that are still running (there shouldn't
# be any, so this is just a sanity check

for i in /var/lock/subsys/*; do
# --> Standard for loop, but "do" is on the same line,
# --> it is necessary to add ""
# Check if the script is there.
[ -f $i ] && continue
# --> This is a clear use of "and list", equivalent to:
# --> if [ -f "$i" ]; then continue
```
