The logical "not" qualifier reverses the outcome of a test or command, and this affects its [exit status](exit status).

# Example 3–2. Negating a condition using !

```
true # the "true" builtin. 
echo "exit status of \true\" = \$?  # 0

! true
echo "exit status of \!true\" = \$?  # 1
# Note that the "!" needs a space.
# !true leads to a "command not found" error
# Thanks, S.C.
```

Certain exit status codes have [reserved meanings](reserved meanings) and should not be user-specified in a script.
