$HOME

home directory of the user, usually /home/username (see Example 9–12)

$HOSTNAME

The hostname assigns the system name at bootup in an init script. However, the gethostname () function sets the Bash variable $HOSTNAME. See also Example 9–12.

$HOSTYPE

host type

Like $MACHTYPE, identifies the system hardware.

```
bash$ echo $HOSTTYPE
1686
```

$IFS

input field separator

This defaults to whitespace (space, space, tab, and newline), but may be changed, for example, to parse a comma-separated data file. Note that $* uses the first character in $IFS. See Example 6–1.

```
bash$ echo $IFS | cat -vte
$
bash$ bash -c 'set w x y z; IFS=":;"; echo "$*'
w:x:y:z
```

$IFS does not handle whitespace the same as it does characters.

Example 9–1, $IFS and whitespace

```
#!/bin/bash
# $IFS treats whitespace differently than other characters.

output_args_one_per_line() {
  for arg
    do echo "[$arg]"
    done
}

echo; echo "$IFS=\* *"
echo "----------------"
```
