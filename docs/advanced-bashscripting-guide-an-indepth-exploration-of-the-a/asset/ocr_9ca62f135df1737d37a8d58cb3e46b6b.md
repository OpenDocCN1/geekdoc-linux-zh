# Advanced Bash-Scripting Guide

```
grep Linux file.*{txt,htm}
# Finds all instances of the work "Linux"
# in the files fileA.txt, "file2.txt", "fileR.html", "file-87.htm", etc.
```

A command may accept with a comma-separated list of file specs between braces. [11] Filename expansion (globbing) applies to the file spaces between the braces.

![](bbox=[0.303, 0.183, 0.335, 0.203])

No spaces allowed within the braces unless the spaces are quoted or escaped.

```
echo {file1,file2}\: \A, "B", 'C'
file1 : A file1 : B file : C file2
: A file2 : B file2 : C
```

Block of code. [curly brackets] Also referred to as an "inline group", this construct, in effect, creates an anonymous function. Unlike, a function, the variables in code block remain until the remainder of the script.

```
bash { local a; a=123; }
bash: local: can only be used in a function
```

```
a=123
{ a=321; }
echo "a = $a"    # a = 321    (value inside code block)

# Thanks, S.C.
```

The code block enclosed in braces may have I/O redirected to and from it.

# ### Example 4–1. Code blocks and I/O redirection

```
#!/bin/bash
# Reading lines in /etc/fstab

File=/etc/fstab
{
read line1
read line2
} <$File
echo "First line in $File is:"
echo "$line1"
echo
echo "Second line in $File is:"
echo "$line2"

exit 0
```
