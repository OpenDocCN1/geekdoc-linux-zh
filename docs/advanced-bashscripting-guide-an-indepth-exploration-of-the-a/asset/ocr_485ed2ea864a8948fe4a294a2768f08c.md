Unmount a currently mounted filesystem. Before physically removing a previously mounted floppy or CDROM drive, the device must be unmounted, else filesystem corruption may occur.

```

# You may now press the eject button and safely remove the disk.
```

Forces an immediate write of all updated data to hard drive (synchronize drive with buffers). While not strictly necessary, a sync ensures the sys admin or we that the data just changed will survive a sudden power failure. In the old days, a sync; sync (twice, just to make absolutely sure) was a precautionary measure before a system reboot.

At times, you may wish to force an immediate buffer flush, as when deleting a file (see Example 12–36) or when the lights begin to flicker.

Sets up and config loopback devices.

# Example 13–6. Creating a filesystem in a file

```
SIZE=1000000      # 1 meg

head -c $SIZE < /dev/zero file  # Set up file of designated size.
losetup /dev/loop0          # Set it up as loopback device.
mke2fs /dev/loop0               # Create filesystem.
mount -o loop /dev/loop0 /mnt   # Mount it.

# Thanks, S.C.
```
