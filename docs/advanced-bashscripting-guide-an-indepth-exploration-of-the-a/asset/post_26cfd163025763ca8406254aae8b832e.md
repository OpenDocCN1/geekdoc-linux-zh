# Chapter 19. Regular Expressions

To fully utilize the power of shell scripting, you need to master Regular Expressions. Certain commands and utilities commonly used in scripts, such as expr, sed and awk interpret and use REs.

## 19.1. A Brief Introduction to Regular Expressions

An expression is a string of characters. Those characters that have interpretation above and beyond their literal are called metacharacters. A quote symbol, may denote speech by person, or meaning of the characters. UNIX uses with special features. The main uses for Regular Expressions (RE) are text searches and string manipulation.

- The asterisk matches any number of repeats of the character string or preceding it, including zero.
- The dot matches any character, except a newline.
- The plus matches at least one of any character (including space).
- The caret matches the beginning of a line, but sometimes, depending on context, negates the meaning of a set of characters.
- The dollar at the end of RE matches the end of line.
- Brackets [...] enclose a set of characters to match in a single RE.
- "xyz" matches the characters x, y, or z.
- "[c-n]" matches any of the characters in the range c to n.
- "[B-y]" matches any of the characters in ranges B to y.
- "[a-z]" matches any lowercase letter or digit.
- "[b-d]" matches all characters except in the range b to d. This is negating or inverting the meaning of RE (taking on a different context).
- Combined sequences of bracketed characters match common patterns.
- "[Yy][Ee][Ss]" matches any Security number.
- "[0-9][0-9][0-9][0-9][0-9]" any.
- The backslash escapes a special character, which means that character gets interpreted literally.
- "$" reverts to its literal meaning of "$", rather than its RE meaning of end-line. Likewise "\"" has the literal meaning of "\". Extended REs. Used in egrep, awk, and Perl the question mark ? matches zero or one of the previous RE. It is generally used for matching single characters.
- The plus + matches one more of the previous RE. It serves role similar to the *, but not match zero occurrences.

```
# GNU versions of sed and awk can use "+",
# but it needs to be escaped.

echo sed -n '/al+b'
echo grep '/al+b'
echo awk '/al+b/'
# All above are equivalent.
```

- Escaped curly brackets \[ indicate the number of occurrences of a preceding RE to. It is necessary to escape the curly brackets because they have their literal meaning otherwise. This usage is technically not part of the RE set.
- \[0-9\] matches exactly five digits (characters in the range of 0 to 9). Curly brackets are not available as an RE in the "classic" version of awk. However, awk has the --re-interval option that permits them (without escaping).

```bash
echo 2222 | awk --re-interval '/2(3)/'
2222
```

- Parentheses ( ) enclose groups of REs. They are especially useful with the following "|" operator. The | OR operator matches any of a set of alternate characters.

```bash
egrep 're(a(e))' misc.txt
People who seem to be better informed than those who do not. The clarinet pronounces by the vibration of its reed.

This is an alternate method of [:alnum] matches alphanumeric or numeric characters. This is equivalent to [A-Za0-9].

- [:alpha] matches alphabetic characters. This is equivalent to [A-Za-z].
- [:blank] matches a space or tab.
- [:cntrl] matches control characters.
- [:digit] matches (decimal). This is equivalent to [0-9].
- [:graph] (printable characters). Matches characters in the range of ASCII 33 – 126. This is the same as [:print], below, excluding the space character.
- [:lower] matches lowercase alphabetic characters. This is equivalent to [a-z].
- [:print] (printable characters). Matches characters in the range of ASCII 32 – 126. This is the same as [:graph], above, adding the space character.
- [:space] matches whitespace characters (space and horizontal tab).
- [:upper] matches uppercase alphabetic characters. This is equivalent to [A-Z].
- [:xdigit] matches hexadecimal characters. This is equivalent to [0-9A-Fa-f].

POSIX character classes generally require or double brackets ([[:).

```bash
grep [[[:digit:]]] test.file
ab=723
```

These character classes may be used with globbing, to a limited extent.

```bash
ls -1 [[[:digit:]][[:digit:]]?
--rw-r--r-- 1 bozo Aug 21 14:47 a33b
```
