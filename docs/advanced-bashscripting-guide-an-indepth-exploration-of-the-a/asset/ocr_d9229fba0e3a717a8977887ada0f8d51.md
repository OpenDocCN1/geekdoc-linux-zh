Example A–13. Making daily backups, using named pipes

```
#!/bin/bash
# ==> Script by James R. Van Zandt, and used here with his permission.

# ==> Comments added by author of this document.

HERE=$(uname -n)  ==> hostname
THERE-bilbo
echo "starting remote backup to $(date +%r)"
# ==>  date +%r returns time in 12-hour format, i.e. "08:08:34 PM".

# make sure /pipe really is a pipe and not a plain file
rm -f /pipe
mkfifo /pipe
# ==>  Create a "named pipe", named "pipe"

# ==> 'uyz' runs commands as user "uyz"
# ==> 'ssh' invokes shell commands (remote login client).
su uyz -c "ssh $THEHERE < cat /home/uyz/backup/$HERE-daily.tar.gz>" < /pipe
tar -czf bin bout dev etc home lib main root shin share usr var >/pipe
# ==> Uses named pipe, /pipe, to communicate between processes:
# ==> 'tar/grip' writes to /pipe and 'ssh' reads from /pipe.

# ==> The result is backs up the main directories, from / down.

# ==> What are the advantages of a "named pipe" in this situation,
# as opposed to an "anonymous pipe", with ?
# ==> Will an anonymous pipe even work here?
```

exit 0
