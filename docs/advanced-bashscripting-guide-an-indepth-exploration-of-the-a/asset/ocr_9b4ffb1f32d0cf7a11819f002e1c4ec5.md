cut

A tool for extracting fields from files. It is similar to the print $N command in awk, but more limited. It may be simpler to use cut in a script than awk. Particularly important are the -d (delimiter) and -f (field specifier) options.

Using cut to obtain the list of mounted filesystems:

```
cat /etc/mtab cut -d ' ' -f1,2
```

Using cut to list the OS and kernel version:

```
uname -a | cut -d" " -f1,3,11,12
```

Using cut to extract headers from an e-mail folder:

```
bash grep '^Subject: read-messages | cut -c10-80
Re: Linux suitable for mission-critical apps?
MAKE MILLIONS WORKING AT HOME!!
Spam complaint
Re: Spam complaint
```

Using cut to parse a file:

```
# List all the users in /etc/passwd.
FILENAME=/etc/passwd

for user in $(cut -d: -f1 $FILENAME)
do
echo $user
done
# Thanks, Oleg Philon for suggesting this.
```

paste

Tool for merging together different files into a single, multi-column file. In combination with cut, useful for creating system log files.

join

Consider this a special–purpose cousin of paste. This powerful utility allows merging two files in a meaningful fashion, which essentially creates a simple version of a relational database.
