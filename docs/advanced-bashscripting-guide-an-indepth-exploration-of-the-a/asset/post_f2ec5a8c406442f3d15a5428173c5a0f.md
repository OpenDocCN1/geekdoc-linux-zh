# Utilities

## basename

## 12.5. File and Archiving Commands

Strips the path information from a file name, printing only the name. The construction basename $0 lets the script its name, that is, the name it invoked. This can be used for "usage" messages if, for example, a script is called with missing arguments:

```bash
echo "Usage: basename $0 arg1 arg2 ... argn"
dirname
```

Strips the basename from a filename, printing only the path information.

basename and dirname can operate on any arbitrary string. The argument does not need to refer to an existing file, or even a filename for that matter (Example A–7).

## Example 12–27. basename and dirname

```bash
#!/bin/bash
a=/home/bozo/daily-journal.txt
echo "Basename of /home/bozo/daily-journal.txt = $(basename $a)"
echo "Dirname of /home/bozo/daily-journal.txt = $(dirname $a)"
echo "My own home is $(basename ~)" # Also works with just .
echo "The home of my home is $(dirname ~)" # Also works with just .
exit 0
```

## sum, cksum, md5sum

These are utilities for generating checksums. A cksum is a number mathematically calculated from the contents of a file, for the purpose of checking its integrity. A script might refer to a list of checksums for security purposes, such as checking the contents of key system files have not been altered or corrupted. The md5 command is the most appropriate of these security applications.

Note that cksum also shows the size, in bytes, of the target file.

```bash
bash cksum /boot/mlinuz
1670054224 804083 /boot/mlinuz

bash md5sum /boot/mlinuz
0f43eceea8f09e0a2b5c1cdf333ba /boot/mlinuz
```

# Encoding and Encryption

## uuencode

This utility encodes binary files into ASCII characters, making it suitable for transmission within the body of an e-message or in a newsgroup posting.

## uudecode

This reverses the encoding, decoding uudencoded files back into the original binaries.

## Example 12–28. uucoding encoded files

```bash
#!/bin/bash
lines=35 # Allow 35 lines for the header (very generous).
for File in * # Test all the files in the current working directory...
do
  search1='head "$File" | grep begin | wc -w'
  search2='tail "$File" | grep end | wc -w'
  # Uucoded files have a "begin" near the beginning,
  # and an "end" near the end.
  if [ "$search1" -gt 0 ];
  then
    if [ "$search2" -gt 0 ];
    then
      echo udecoding $File-
      uudecode "$File"
    fi
  fi
done
# Note that running this script upon itself fulfills it
# into thinking it is a uudencoded file,
# because it contains both "begin" and "end".

# Exercise:

exit 0
```

## mmencode, mmencode

The mmencode and mmencode commands process multimedia-encoded e–mail attachments. Although mail user agents (such as pine or km) normally handle this automatically, particular utilities permit manipulating attachments manually from the command line or in a batch by means of a shell script.

## crypt

At one time, this was the standard UNIX file encryption utility. Politically motivated government regulations prohibiting the export of encryption software resulted in the disappearance of crypt from much of the UNIX world, and it is still missing from most Linux distributions.

Fortunately, programmers have come up with it with a number of decent alternatives, among them the author's own cruft (see Example A–7).

## Miscellaneous

## cp

Utility for splitting a file into smaller chunks. Usually used for splitting large files in order to back them up on floppies or preparatory to e-mailing or uploading them.

## install

Special purpose copying, similar to cp, but capable of setting permissions.
