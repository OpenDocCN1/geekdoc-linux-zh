# Example 30–5. Cleaning up after Control–C

```bash
#!/bin/bash
# logon.sh: a quick n dirty script to check whether you are on-line.

TRUE=1
LOGFILE=/var/log/messages
# Note that LOGFILE must be readable (chmod 644 /var/log/messages).
TEMPFILE=tmp.\$
# Create a "unique" temp file name, using process id of the script.
KEYWORD=address
# At logon, the line "remote IP address xxx.xxx.xxx.xxx"
# appended to /var/log/messages.

ONLINE=22
USER_INTERRUPT=13

trap 'rm -f $TEMPFILE; exit $USER_INTERRUPT' TERM INT
# Cleans up the file if script interrupted by control-c.

echo

while [ $TRUE ]; do # Endless loop.

  tail -1 $LOGFILE > $TEMPFILE
  # Saves last line of system log file as temp file.
  search=$(grep $KEYWORD $TEMPFILE)
  # Checks for presence of the "IP address" phrase,
  # indicating a successful login.

  if [ -z "$search" ]; # Quotes necessary because of possible spaces.
  then
    echo "On-line"
    rm -f $TEMPFILE # Clean up temp file.
    exit $ONLINE
  else
    echo -n "." # -n option to echo suppresses newline,
    # so you get continuous rows of dots.
  fi

  sleep 1
done
```

trap '' SIGNAL (two adjacent apostrophes) disables SIGNAL for the remainder of the script. trap SIGNAL restores the functioning of SIGNAL once more.
This is useful to protect a critical portion of a script from an undesirable interrupt.

```bash
trap '' 2 # Signal 2 is Control-C, now disabled.
command
command

```

# Chapter 31. Options

Options are settings that change shell and/or script behavior.

The set command enables options within a script. At the point in the script where you want the options to take effect, use set -option-name or, in short form, set -option-abbrev. These two forms are equivalent.

```bash
#!/bin/bash
set -o Echoes all commands before executing.
```

```bash
#!/bin/bash
set -v
# Exact same effect as above.
```

To disable an option within a script, use **set +option-name** or **set +option-abbrev**.

```bash
#!/bin/bash
set -o verbose
# Command echoing on.
command
...
command
set +o verbose
# Command echoing off.
command
# Not echoed.
set -v
# Command echoing on.
command
...
command
set +v
# Command echoing off.
command
exit 0
```

An alternate method of enabling options in a script is to specify them immediately following the **#! script header.**

```bash
#!/bin/bash -x
#
```

```bash
if [ "$sa" = 273 ]   # Is $sa an integer?
```

```bash
if [ "$sa" = 273 ]
```
