The **od**, octal dump file converts (or files) to text (base-8) or other bases. This is useful for viewing or processing binary data files or otherwise unnamed device files, such as /dev/urandom, and for a binary data search. Example 9–23 and Example 12–10.

# xdump

Performs a hexadecimal, octal, decimal, or ASCII dump of a binary file. This is the rough equivalent of **od**, above, but not nearly as useful.

# m4

A hidden treasure, **m4** is a powerful macro processing filter, [371] virtually a complete language. Although originally written as a pre-processor for Fortran, m4 turned out to be as useful as a stand-alone utility. In fact, m4 combines some of the functionality of eval, tr, and awk, in addition to its extensive macro expansion facilities.

The April, 2002 issue of **Linux Journal** has a very nice article on **m4** and its uses.

# Example 12–37. Using m4

```
#!/bin/bash
# m4.sh: Using the m4 macro processor

# Strings
string=abcdA01
echo len("$string") | m4      # 7
echo substr("$string", 4") | m4  # A01
echo regex("$string", [0-1][\&Z]") | m4  # 01Z

# Arithmetic
echo incr("22") | m4      # 23
echo eval("9 / 3") | m4    # 33

exit 0
```
