
## Chapter 14. Command Substitution

Command substitution reassigns the output of a command [44] or even multiple commands; it literally plugs the command output into another context.

The classic form of command substitution uses backquotes (`...`). Commands within backquotes (backticks) generate command line text.

```bash
script_name=basename $0
echo "The name of this script is $script_name."
```

The output of commands can be used as another command, to set a variable, and even for generating the argument in a loop.

```bash
rm `cat filename` # "filename" contains a list of files to delete.
# S. C. points out that "arg too long" error result.
# Better is
# xargs rm < filename
# ( - covers cases where "filename" begins with a "-")
```

```bash
textfile_listing=ls *.txt
# Variable names of all *.txt files in current working directory.
echo textfile_listing
```

```bash
textfile_listing=$($(*.txt) # The alternative form of command substitution.
echo textfile_listing
# Same result
```

```bash
# A possible problem with putting a list of files into a single string
# is that a newline may creep in.
```

```bash
# A safer way to assign a list of files to a parameter is with an array.
shopt -s nullglob # If no match, filename expands to nothing.
textfile_listing=( *.txt)
```

```bash
# Thanks, S.C.
```

Command substitution may result in word splitting.

```bash
COMMAND "echo a" # 2 args: a and b

COMMAND "echo a b" # 1 arg: "a b"

COMMAND `echo` # no arg

COMMAND `echo*` # one empty arg
```

```bash
# Thanks, S.C.
```

When there is no word splitting, command substitution can remove trailing newlines.

```bash
# cd "$pwd" # This should always work.
# However...
```

```bash
mkdir 'dir with trailing newline'
cd 'dir with trailing newline'
cd "$pwd" # Error message:
# bash: cd /tmp/file with trailing newline: No such file or directory
cd "$PWD" # Works fine
```

```bash
old_tty_setting=$($stty) # Save old terminal setting.
echo "Hit a key " # Disable *canonical* mode for terminal.
stty -icanon -echo # Also, disable *local* echo.
key=$(dd bs=count=1 2>/dev/null) # Using 'dd' to get a keypress.
stty $old_tty_setting # Restore old setting.
echo "You hit ${key}" # ${(variable)} = number of characters in $variable

# Hit any key except RETURN, and the output is "You hit 1 key."
# Hit RETURN, and it's "You hit 0 key."
# The newline gets in the command substitution.
```

Thanks, S.C.

Using echo to output an unquoted variable with command substitution removes trailing characters from the output of the reassigned command($s). This can cause unpleasant surprises.

```bash
dir_listing=`ls -l`
echo $dir_listing # unquoted

# However, what you get:

```

```bash
echo "$dir_listing" # quoted
# -rw-rw-r-- 1 bozo 30 May 13 13:17:15 1.txt
# -rw-rw-r-- 1 bozo 51 May 15 20:57:t2.sh
# -rwxr-xr-x 1 bozo 21 Mar 5 21:23:11 wi.sh
```

```
