[54] Too many levels of recursion may crash a script with segfault.

```
#!/bin/bash
recursive_function ()
{
  (( $1 < $2 )) && f $(( $1 + 1 )) $2;
  # As long 1st parameter is less than 2nd,
  # increment 1 and recurse.
}

recursive_function 1 50000 # Recursion 50,000 levels!
# Segfaults, of course.

# Recursion this deep might cause a C program to segfault
# by using up all the memory allotted to the stack.

# Thanks, S.C.
exit 0 # This script will not exit normally.
```

[57] The entries in /dev provide mount points for physical and virtual devices. These entries are very little drive space.

[58] A block device reads and/or writes data in chunks or blocks, in contrast to a character device, which accesses data in character units. Examples of block devices are a hard drive and CD ROM drive. An example of a character device is a keyboard.
