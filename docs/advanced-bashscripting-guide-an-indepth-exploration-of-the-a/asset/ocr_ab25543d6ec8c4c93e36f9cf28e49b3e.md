Note that certain specialized variable loops, as, for example, a getopts construct, deviate somewhat from the standard template here.

Example 10–14. Simple while loop

```
#!/bin/bash
var0=0
LIMIT=10

while [ "$var0" -lt "$LIMIT" ];
do
    echo -n "$var0 "      # -n suppresses newline.
    var0=$(expr $var0 + 1)  var0=$((var0+1)) also works.
done
echo
exit 0
```

Example 10–15. Another while loop

```
#!/bin/bash
echo
while [ "$varl" != "end" ];  # while test "$varl" != "end"
do
    # also works.
    echo "Input variable #1 (end to exit)"
    read varl                        # Not read '$varl' (why?).
    echo "variable #1 $varl"         # Need quotes because of "#"
    # If input is 'end', echoes it here.
    # Does not test for termination condition until top of loop.
echo
done 0
```

A while loop may have multiple conditions. Only the final condition determines the loop terminates. This necessitates a slightly different loop syntax, however.

Example 10–16. while loop with multiple conditions

```
#!/bin/bash
varl=unset
previous=$varl

while echo "previous-variable = $previous"
    echo
    previous=$varl
```
