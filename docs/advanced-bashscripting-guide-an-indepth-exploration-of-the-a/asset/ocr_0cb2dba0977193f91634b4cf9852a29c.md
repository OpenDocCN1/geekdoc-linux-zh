5. trapping at exit.

The exit command in a script triggers a signal 0, terminating the process, that is, the script itself. [601] It is often useful to trap the exit, forcing a "printout" of variables, for example. The trap must be the first command in the script.

# Trapping signals

trap

Specifies an action on receipt of a signal; also useful for debugging.

A signal is simply a message sent to a process, either by the kernel or other process, to take some specified action (usually to terminate). For example, hitting a Control-C, sends a user interrupt, an INT signal to a running program.

```
trap ' ' 2
# Ignore interrupt 2 (Control-C), with no action specified.
trap 'echo "Control-C disabled.\' 2
# Message when Control-C pressed.
```
