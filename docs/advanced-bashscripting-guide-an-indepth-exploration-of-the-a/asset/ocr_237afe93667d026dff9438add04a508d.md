> The DEBUG argument to trap causes a specified action to execute every command in a script. This permits tracing variables, for example.

Example 30– Tracing a variable

```
#!/bin/bash
trap 'echo "VARIABLE-TRACE = \"$variable\"*' DEBUG
# Echoes the value of $variable after every command.

variable=29
echo "Just initialized \"$variable\" to $variable."

let variable *= 3
echo "Just multiplied \"$variable\" by 3."
```

# The 'trap 'commands'' construct would be more useful
# in the context of a complex script,
# where placing multiple "echo $variable" statements might be
