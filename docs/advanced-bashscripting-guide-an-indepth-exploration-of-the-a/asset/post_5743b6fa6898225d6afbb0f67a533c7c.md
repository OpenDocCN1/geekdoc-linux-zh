
## Chapter 24. Aliases

A Bash alias is essentially nothing more than a keyboard shortcut, an abbreviation, a means of avoiding typing a long command sequence. If, for example, we include **alias im="ls -l | more"** in the ~/.bashrc file, then each **im** at the command line will automatically be replaced by a **ls -l | more**. saving a great deal of time at the command line and avoiding having to remember complex combinations of commands and options. Setting **alias rm="rm -i"** (interactive mode) may save a great deal of grief, if it prevent inadvertently losing important files.

In a script, aliases have very limited versatility. It would be nice if aliases could assume some of the functionality of the C preprocessor, such as macro expansion, but unfortunately Bash does not argue within the alias.[55]. Moreover, a script fails to expand an alias within "compound constructs", such as if/then statements, loops, and functions. An added limitation is that an alias will not expand recursively. Almost invariably, whatever we would like an alias to do could be accomplished more with a function.

Example 24-1. Aliases within a script

```
#!/bin/bash
# May need to be invoked with #!/bin/bash2 on older systems.

set -s expand_aliases
# Must set this option, else script will not expand aliases.

# First, some fun.
alias Jesse_James=echo "*Alias Jesse\" was a 1952 comedy starring Bob Hope."
Jesse_James

echo; echo;

alias ll1="ls -l"
# May use either escaped \" (single \') or double (") quotes to define an alias.
echo "Trying aliased \"*\""
ll1 /usr/X11R6/mk* # Alias works.

echo

directory=/usr/X11R6/bin/
prefix=* # See if wild-card causes problems.
echo "Variables \"directory\" + \"prefix\" = $directoryprefix"
echo

alias ll1="ls -l $directoryprefix"
echo "Trying listing \"*\"" in /usr/X11R6/bin starting with mk.
ll1 # Long listing of all files in /usr/X11R6/bin with mk.
# Alias handles concatenated variables, including wild-card o.k.

TRUE=1
```

## Example 24–2. unalias: setting and unsettling an alias

```
#!/bin/bash

set -s expand_aliases # Enables alias expansion

alias ll='ls -al | more'
ll

echo

unalias ll # Unset alias.
ll
# Error message results, since 'll' no longer recognized.

exit 0
./unalias.sh
```

## Chapter 25. List Constructs

The "and" and "or" constructs provide a mean of processing commands consecutively.
These effectively replace complex nested if/then or case statements.

Chaining together commands

```
command-1 && command-2 && command-3 ... command-n
Each command executes in turn provided that the previous command has given a return value of
(zero). The first false (non-zero) return, the command chain terminates (the first command
returning false is the last one to execute).
```

Example 25–1. Using an "and list" to test for command–line arguments

```bash
#!/bin/bash
# "and list"

if [ ! -z "$1" ] && echo "Argument $1 = $1" && [ ! -z "$2" ] && echo "Argument $2 = $2"
then
    echo "At least 2 arguments passed to script."
    # All chained commands return true.
else
    echo "Less than 2 arguments passed to script."
    # At least one chained commands returns false.
fi

# "if [ -z $1 ]" does not. However, quote fixes this.
```

Chapter 26. Arrays

Newer versions of Bash support one-dimensional arrays. Array elements may be initialized with the **variable[xx]** notation. Alternately, a script may introduce the entire array by an explicit **declare -a variable** statement. To dereference (find the contents of) an array element, use **curly bracket** notation, is, **${variable[xx]}**.

Example 26–1. Simple array usage

```bash
#!/bin/bash

area[11]=23
area[13]=37
area[51]=UFOs

# Array members need not be consecutive or contiguous.

# Some members of the array can be left uninitialized.
# Gaps in the array are o.k.

echo -n "area[11]" = ""
echo ${area[11]}      # (curly brackets) needed

echo -n "area[13]" = ""
echo ${area[13]}

echo "Contents of area[51] is ${area[51]}"

# Contents of uninitialized array variable point blank.
echo -n "area[43]" = ""
echo ${area[43]}
echo "${area[43]} unassigned"

echo

# Sum of two array variables assigned to third
area[5]=expr ${area[11]} + ${area[13]}
echo "area[5] = area[11] + area[13]"
echo -n "area[5]" = ""
echo ${area[5]}

area[6]=expr ${area[11]} + ${area[5]}
echo "area[6] = area[11] + area[5]*"
echo -n "area[6]" = ""
echo ${area[6]}
# This fails because adding an integer to a string is not permitted.

echo; echo; echo
```
