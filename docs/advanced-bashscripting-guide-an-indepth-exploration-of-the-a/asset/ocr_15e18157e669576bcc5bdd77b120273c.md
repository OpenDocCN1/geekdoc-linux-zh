# 12.1. Basic Commands

# Command Listing

The basic file "list" command. It is all too easy to underestimate the power of this humble command. For example, using the -R, recursive option, ls provides a tree-like listing of a directory structure. Other interesting options are -s, sort by file size, -t, sort by modification time, and -i, show file inodes (see [Example 12-3]).

Example 12-1. Using to create a table of contents for burning a CDR

```
#!/bin/bash

SPEED=2                # May use higher speed if your hardware supports it
IMAGEFILE=cdimage.iso
CONTENTSFILE=contents
DEFAULTDIR=/opt       # Make sure this directory exists.

# Script to automate burning a CDR.

# Uses Josef Schilling's "cdrecord" package.
# (http://www.fokus.de/ntyp/employees/schilling/cdrecord.html)

# If this script is invoked as an ordinary user, need to sudo cdrecord
+# chmod u+s /usr/bin/cdrecord, as root.)

if [ -z "$1" ];
then
    IMAGE_DIRECTORY=$DEFAULTDIR
    # Default directory, if not specified on command line.
else
    IMAGE_DIRECTORY=$1
fi

ls -lRF $IMAGE_DIRECTORY > $IMAGE_DIRECTORY/$CONTENTSFILE
# The "l" option gives a "long" file listing.
# The "R" option makes the recursive listing.
# The "F" option marks the file types (directories get a trailing /).
echo "Creating contents of table."

mkkisofs -r -o $IMAGE_DIRECTORY
echo "Creating ISO9660 file system image ($IMAGEFILE)."

cdrecord -v -isosize speed=$SPEED dev=0,0 $IMAGEFILE
```
