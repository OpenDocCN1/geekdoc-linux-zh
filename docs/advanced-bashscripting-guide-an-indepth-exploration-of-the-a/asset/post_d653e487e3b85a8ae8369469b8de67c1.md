```bash
_configure_func ()
{
    case "$2" in
        *) ;;
        *) return ;;
    esac

    case "$1" in
        \*) eval cmd=$1 ;;;
        *) cmd="$1";;
    esac
}
COMPRELY=$( "$cmd" --help | awk '{if ($1 ~ -.*/) print $1}' | grep "^$2" | sort -u)

complete -F _configure_func configure

# cvs (1) completion
_cvs ()
{
    local cur prev
    COMPRELY=()
    cur=$(COMP_WORDS[COMP_CWORD])
    prev=$(COMP_WORDS[COMP_CWORD-1])

    if [ $COMP_CWORD -eq 1 ] || [ "${prev:0:1}" = "-" ]; then
        COMPRELY=($0 compgen -w addin commit diff \
            export history import log diff release rtag status \
            tag update' $cur)
    else
        COMPRELY=($0 compgen -f $cur)
    fi
    return 0
}
complete -F _cvs cvs
```

```bash
_killall ()
{
    local cur prev
    COMPRELY=()
    cur=$(COMP_WORDS[COMP_CWORD])

    # get a list of processes (the first sed evaluation
    # takes care of swapped processes, the second
    # takes care of getting the basename of the process)
    COMPRELY=($0 /usr/bin/ps -u $USER -o comm | \
        sed -e '1,d' -e 's/[#][]//@' -e 's/.*$##' | \
        awk 'if ($0 ~ /^$cur\/) print $0')

    return 0
}
complete -F _killall killall killps
```

# Appendix H. Converting DOS Batch Files to Shell Scripts

Quite a number of programmers learned scripting on a PC running DOS. Even the crippled batch file language allowed writing some fairly powerful scripts and applications, though they often required extensive kludges and workarounds. Occasionally, the need still arises to convert an old DOS batch file to a shell script. This is generally not difficult, as DOS batch file operators are only a limited subset of the equivalent shell scripting options.

Table H–1. Batch file keywords / variables / operators, and their shell equivalents

| Batch File Operator | Shell Script Equivalent | Meaning |
|---|---|---||
| % | $ | command-line parameter prefix |
| / | - | command option flag |
| \ | / | directory path separator |
| == | = | (equal-to) string comparison test |
| ! == | != | (not-equal-to) string comparison test |
| | | | | pipe |
| @ | set +v | do not echo current command |
| * | * | filename "wild card" |
| > | > | file redirection (overwrite) |
| >> | >> | file redirection (append) |
| < | < | redirect stdin |
| %VAR% | $VAR | environmental variable |
| REM | # | comment |
| NOT | ! | negate following |
| NUL | /dev/null | "black hole" for burying output |
| ECHO | echo | echo (many option in Bash) |
| ECHO. | echo | blank line |
| ECHO OFF | set +v | do not echo command following |
| FOR %VAR IN (LIST) | var in [list]; | "for" loop |
| :LABEL | none (unnecessary) | label |
| GOTO | none (use function) | jump to another location in the script |
| PAUSE | sleep | pause or wait interval |
| CHOICE | case or select | menu choice |
| IF | if | if–test |
| IF EXIST FILENAME | if -e filename | test file exists |
| IF !N | if -z "$N" | replaceable parameter "N" not present |
| CALL | source (.dot operator) | "include" another script |
| COMMAND /C | source (.dot operator) | "include" another script (same as CALL) |
| SET | export | set an environmental variable |
| SHIFT | shift | left shift–argument list |
| SGN | -lt or -gt | sign of (integer) |
| ERRORLEVEL | ? | exit status |
| CON | stdin | "console" (stdin) |
| PRN | /dev/lp0 | (generic) printer device |
| LPT1 | /dev/lp0 | first printer device |
| COM1 | /dev/tty | first serial port |

Batch files usually contain DOS commands. These must be translated into their UNIX equivalents in order to convert a batch file into a shell script.

Virtually all UNIX shell operators and commands have many more options and enhancements than their DOS and batch file equivalents. Many DOS batch files rely on auxiliary utilities, such as ask, a crippled counterpart to read.

DOS supports a very limited and incompatible subset of filename wildcard expansion, recognizing only the * and ? characters.

Converting a DOS batch file into a shell script is generally straightforward, and the result oftentimes better than the original.

# Example H–1.VIEWDATA.BAT: Dos Batch File

```batch
REM VIEWDATA

REM INSPIRED BY AN EXAMPLE IN "DOS POWERTOOLS"
REM BY PAUL SOMERSON

@ECHO OFF

IF %1== GOTO VIEWDATA
REM IF NO COMMAND-LINE ARG...
FIND "%1" C:\BOZO\BOOKLIST.TXT
GOTO EXIT
REM PRINT LINE WITH STRING, THEN EXIT.
```

```bash
:VIEWDATA
TYPE C:\BOZO\BOOKLIST.TXT | MORE
REM SHOW ENTIRE FILE, 1 PAGE AT A TIME.

:EXIT0
```

The script conversion is somewhat of an improvement.

# Example H–2. viewdata.sh: Shell Script Conversion of VIEWDATA.BAT

```bash
#!/bin/bash
# Conversion of VIEWDATA.BAT to shell script.

DATAFILE=/home/bozo/datafiles/book-collection.data
ARGNO=1

# @ECHO OFF       Command unnecessary here.

if [ $# -lt "$ARGNO" ]  # IF [ ! $#== ] GOTO VIEWDATA
then
    less $DATAFILE          # TYPE: C:\MYDIR\BOOKLIST.TXT | MORE
else
    grep "$1" $DATAFILE      # FIND "$1" C:\MYDIR\BOOKLIST.TXT
fi

exit 0
# GOTOS, labels, smoke-mirrors, and flimflam unnecessary.
# The converted script is short, sweet, clean,
# which is more than can be said for the original.
```
