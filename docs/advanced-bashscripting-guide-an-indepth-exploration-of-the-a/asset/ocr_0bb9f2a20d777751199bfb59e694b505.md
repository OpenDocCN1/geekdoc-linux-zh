# Advanced Bash–Scripting Guide

```
#!/bin/bash

ENDLESS_LOOP=1
INTERVAL=1

echo "Hit Control-C to exit this script."
echo

while [ [$ENDLESS_LOOP ]
do
    if [ "$SECONDS" -eq 1 ];
    then
        units=second
    else
        units=seconds
    fi
    echo "This script has been running $SECONDS $units"
    sleep $INTERVAL
done

exit 0
```

$SHELLOPTS

the list of enabled shell options, a readonly variable

$SHLVL

Shell level, how deeply Bash is nested. If, at the command line, SSHLVL is 1, in a script it will increment to 2.

$TMOUT

The $TMOUT environmental variable is set to a non–zero value time, then the shell prompt will time out after time seconds. This will cause a logout.

![](bbox=[0.311, 0.643, 0.345, 0.663])

Unfortunately, this only while waiting for input at the shell prompt or in an xterm. While it would be nice to speculate on the uses of this internal variable for timed input, for in combination with read. $TMOUT does not work in that context and is virtually useless for shell scripting. (Reportedly the ksh version of a timed read does work.)
