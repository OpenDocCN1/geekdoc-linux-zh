# Information and Statistics

# uname

Output system specifications (OS, kernel version, etc.) to stdout. Invoked with the -a option, gives verbose system info (see Example 12–4). The -s shows only the OS type.

```
bash$ uname -a
Linux localhost.localdomain 2.2.15-2.5.0 #1 Sat Feb 5 00:13:43 EST 2000 i686 unknown

bash$ uname -s
Linux
```

# arch

Show system architecture. Equivalent to uname -m. See Example 10–25.

```
bash$ arch
1686

bash$ uname -m
1686
```

# lastcomm

Gives information about previous commands, as stored in the /var/account/pacct file. Command name and user name can be specified by options. This is one of the GNU accounting utilities.

# lastlog

Show the last login time of all system users. This references the /var/log/lastlog file.

```
bash$ lastlog
root tty Fri Dec 7 18:43:21 -0700 2001
bin             **Never logged in**
daemon          **Never logged in**
...
bozo            tty             Sat Dec 8 21:14:29 -0700 2001
```

```
bash$ lastlog | grep root
root            tty             Fri Dec 7 18:43:21 -0700 2001
```

![](bbox=[0.303, 0.831, 0.326, 0.849])

This command will fail if the user invoking it does not have permission for the /var/log/lastlog file.
