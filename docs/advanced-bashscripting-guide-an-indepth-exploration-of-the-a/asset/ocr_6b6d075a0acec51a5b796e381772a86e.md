Example A–8. "Game of Life"

```
#!/bin/bash
# life.sh: "Life in the Slow Lane"

######################################################################
# This is the Bash version of John Conway's "Game of Life".
# "Life" is a simple implementation of cellular automata.
######################################################################
# On a rectangular grid, let "cell" be either "living" or "dead".
# Designate a living cell with a dead one with a blank space #.
# Begin with an arbitrarily drawn dot-not-blank grid, "generation 0".
# + let this be the starting generation,
# Determine successive generation by the following rules:
# 1) Each cell has 8 neighbors, the adjoining cells
#    left, right, top, bottom, and the 4 diagonals.
    223
4*5
678
# 2) A living cell with either 2 or 3 neighbors remains alive.
# 3) A dead cell with 3 neighbors becomes alive (a "birth")
SURVIVE=2
BIRTH=3
4) All other cases result in dead cells.
######################################################################
startfile-gen0 # Read the starting generation from the file "gen0".
ALIVE1=
DEAD1=

# Represent living and "dead" cells in the start-up file.

# This script uses a 10 x 10 grid (may be increased),
## but a large grid will cause very slow execution.
ROWS=10
COLS=10

GENERATIONS=10 # How many generations to cycle through.
# Adjust this upwards,
## if you have time on your hands.

NONE_ALIVE=80 # Exit status on premature bailout,
## if no cells left alive.

TRUE=0
FALSE=1
ALIVE=0
DEAD=1

var= # Global; holds current generation.
generation=0 # Initialize generation count.

######################################################################
let "cells" = $ROWS * $COLS
# How many cells.

declare -a initial ## Arrays containing "cells".
declare -a current
```
