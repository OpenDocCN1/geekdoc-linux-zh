Variable expansion / substring replacement.

In combination with the > operator, truncates a file to zero length, without changing its. If the file did not previously exist, it creates it.

```
> data.xxx # File "data.xxx" now empty.
# Same effect as cat /dev/null >data.xxx
# However
```

In combination with the >> operator, updates a file access/modification time (: >> new_file). If the file did not previously exist, it creates it. This is equivalent to touch.

![](bbox=[0.308, 0.377, 0.348, 0.407])

This applies to regular files, pipes, symlinks, and special files.

May be used to begin a comment line, although this is not recommended. Using # for a comment turns off checking for the remainder of that line, so anything may be in a comment. However, this is not the case with :

> : This is a comment that generates an error, ( if $ x -eq 3 ).

The ":" serves as a field separator, in /etc/passwd, and in the PATH variable.

```
bash echo $PATH
/usr/local/bin:/usr/bin:/usr/X11R/bin:/bin:/usr/sbin:/sbin:/usr/games
```

reverse (or negate) the sense of a test or exit status. The ! operator inverts the exit status of the command to it is applied (Example 3–2) meaning a test of operator. This can, change the sense of "equal" (=) to "not-equal" (!). The ! operator is a Bash keyword.

In a different context, the ! also appears in indirect variable references.

wild card. [asterisk] The * character serves as a "wild card" for filename expansion in globbing, as well as representing any number (or zero) characters in a regular expression.

A double asterisk, **, is the exponentiation operator.
