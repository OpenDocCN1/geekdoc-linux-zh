# 手动配置 IBM 安装工具（IBIT）启动服务器

本主题说明了如何手动配置你的机器作为 IBMIT 的启动服务器。此操作允许从网络启动 IBMIT，而不是通过 CD/DVD-ROM 或 USB 密钥。

如果你希望自动完成，请使用第 76 页的“配置启动服务器”。

# 前提条件

在手动配置启动服务器之前，你必须满足以下条件：
- 你的系统中已安装并运行 TFTP 服务器
- 一个 DVD 或 ISO 文件

注意：对于这些指令，适用以下约定：
- `<tftpdir>` 是 TFTP 服务器根目录，通常为 `/tfboot`
- `<mountdir>` 是挂载 IBMIT 镜像或 DVD 的目录
- `<isofile>` 是 ISO 镜像文件

要手动配置 IBMIT 启动服务器，请遵循以下步骤：

1. 挂载 IBMIT ISO 文件（如果使用的是 DVD）：
`$ mount -o loop -t iso <isofile> <mountdir>`

2. 将 IBMIT 镜像拷贝到 TFTP 服务器：
`$ cp <tftpdir>/ppc/`
`$ cp <mountdir>/boot/img1 <tftpdir>/ppc/`
`$ cp <mountdir>/boot/img2 <tftpdir>/ppc/`
`$ cp <mountdir>/boot/img3 <tftpdir>/ppc/`
`$ cp <mountdir>/boot/img4 <tftpdir>/ppc/`

3. 将启动器配置文件拷贝到 TFTP 服务器：
`$ cp <mountdir>/etc/yaboot.conf <tftpdir>/etc/yaboot.conf`
`$ cp <mountdir>/etc/hardware.txt <tftpdir>/etc/hardware.txt`

4. 卸载 介质并完成：
`$ umount <mountdir>`

# 手动为 IBMIT 启动服务器配置客户端机器

本主题说明了如何手动配置 IBMIT 启动服务器，使其有一个客户端机器从中启动。

如果你希望自动完成，请使用第 82 页的“管理启动服务器”。

# 前提条件

在开始之前，你必须满足以下条件：
- 你的系统已配置为 IBMIT 启动服务器
- 系统已安装并运行 DHCP 服务器
- 具备 DHCP 服务器配置文件的基础知识
- 客户端机器的 MAC 地址

你必须将系统配置为 IBMIT 启动服务器，参见第 207 页的“手动配置 IBM 安装工具的启动服务器”。

网络过程如下：客户端向网络广播启动请求。IBMT 启动服务器接收请求。如果其内部 DHCP 服务器 配置为响应该客户端的请求，它将通过发送客户端名称来实现。此文件是客户端必须下载的 TFTP 镜像。客户端接收此文件并从启动服务器上的 TFTP 服务器下载。最后，客户端将镜像加载到内存中并运行，启动过程开始。在此过程中，客户端根据需要从 TFTP 服务器下载其他镜像。

注意：对于实例，适用以下约定：
- `<tftpdir>` 是 TFTP 服务器 chroot，通常为 `/tfboot`
- `<dhcpfile>` 是 DHCP 服务器配置文件，通常为 `/etc/dhcpd.conf`
- `<macaddress>` 是在 `<dhcpfile>` 中标识客户端机器的任意名称
- `<macaddress>` 是客户端机器的 MAC 地址。字母必须小写，组件间用连字符分隔。例如：ae-b3-c0-00-20-04。
- `<ipaddress>` 是绑定到客户端机器的 IP 地址
- `<initscript>` 是启动 DHCP 服务器的脚本，通常为 `/etc/init.d/dhcpd`

要配置 IBMIT 启动服务器让客户端从中启动，请遵循以下步骤：

1. 为客户端机器设置启动器文件：

2. 配置 DHCP 服务器响应该客户端的请求，在 `<dhcpfile>` 中添加以下项：
```
host <macaddress> {
 filename "ppc/img";
 hardware ethernet <macaddress>;
 fixed-address <ipaddress>;
}
```

3. 重启 DHCP 服务器以使配置生效：

```
$ <initscript> restart
```

# 手动创建网络安装存储



如果您希望自动创建网络安装存储库，请使用第95页上的“管理服务器服务器上可用的 Linux 安装存储库”工具。

网络安装存储库是一个可以通过 HTTP、FTP 或 NFS 服务器访问的目录。该目录必须包含执行安装所需的所有文件。实现这一目标的一种简单方法是将发行版 DVD 的所有文件复制到该目录。为了能够访问，该目录必须放置在服务器可以访问的任何地方。存储库创建后，可以通过取决于服务器配置的 URL 进行访问。例如：//192.168.1.54/myrepo

# 先决条件

在开始此任务之前，您必须具备以下项目：

- * 您想要创建存储库的发行版 DVD ISO 镜像
- * 已安装并运行 HTTP、FTP 或 NFS 服务器，以便通过其访问创建的存储库

注意：对于这些说明，适用以下约定：

- * <isofile> 是发行版或 IBMIT 的 ISO 镜像文件
- * <mountdir> 是挂载 ISO 的目录
- * <rootdir> 是可以通过 HTTP、FTP 或 NFS 服务器访问内容的目录
- * <repname> 是 <rootdir> 下包含存储库的子目录名称

要创建 Linux 或 IBMIT 网络安装存储库，请遵循以下步骤：

- 1. 挂载发行版 DVD 的 ISO 镜像文件（如果您愿意，也可以使用磁盘）：
   $ mount -o loop -t iso9660 <isofile> <mountdir>
2. 将所有文件复制到存储库：
   $ rm -rf <rootdir>/<repname>
   $ cp -a <rootdir>/<repname>
3. 卸载 ISO 镜像：
   $ umount <mountdir>

# 其他方法

您也可以使用这种替代方法：

与其将文件复制到磁盘，不如在服务器可以访问的目录直接挂载 DVD 媒体：

- 1. 在服务器可以访问的位置创建一个挂载点：
   $ mkdir -p <rootdir>/<repname>
2. 挂载发行版 DVD 的 ISO 镜像文件（如果您愿意，也可以使用磁盘）：
   $ mount -o loop -t iso9660 <isofile> <rootdir>/<repname>
3. 在使用完存储库后，卸载它：
   $ umount <rootdir>/<repname>
