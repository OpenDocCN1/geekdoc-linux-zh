# ## Adding Repositories

Because I made such a big deal of it, let's start by adding those other repositories. From the Synaptic main window, click Settings on the menu bar, and then select Repositories. A Software Preferences dialog appears (see Figure 8–6). You'll see three tabs, one labeled Installation Media, another labeled Internet Updates, and the other, Authentication. By default, the Installation Media tab should be selected.
