# Ubuntu Preinstalled Games

![](bbox=[0.23, 0.12, 0.77, 0.65])

To play against the computer, make sure you click Settings, then Preferences, and assign a play level to the computer opponent (by selecting either the light or dark side).

This is a great version of the classic game. Still, I think that one of my favorite things about this particular incarnation of Reversi (or Othello) is the author's explanation of why the game is called Iagno and not something else. This is in Section 1.2 of the Iagno manual (click Help on the Iagno menu bar and select Contents).
