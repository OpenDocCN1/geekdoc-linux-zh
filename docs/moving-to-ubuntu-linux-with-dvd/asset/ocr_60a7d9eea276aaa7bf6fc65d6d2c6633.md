By default, there are no locations defined. If you go ahead and configure a network connection without creating a location, those settings are your default. To add a new location, click the drop-down box (it is empty at this point) and click Create Location. A small dialog appears (see Figure 7-3), in which you enter the name of this location (for example, London office). When you have entered the name, click OK.
