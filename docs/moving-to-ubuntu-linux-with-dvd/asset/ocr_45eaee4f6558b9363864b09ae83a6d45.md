# The Simplest Way to Add Applications

![](bbox=[0.15, 0.13, 0.84, 0.54])

**Figure 8–2** By searching the word *game*, the program returns all of the applications it knows about with the word *game* in the title or description.

Select a game from the list and read its accompanying description. If this sounds like a good choice, click the check box next to the program’s name, then click the Apply button at the bottom of the main window. Before things get rolling, you are asked to confirm your list of packages. If you are happy with the choices, click Apply. A dialog appears informing you of the installer’s progress as it downloads, unpacks, and installs the packages you have selected (see Figure 8-3).

> *Note*  *The Ubuntu DVD included with this book includes all of the supported Ubuntu packages, whether installed or not. What this means is that for many packages, you don’t need to download from the Internet if you installed Ubuntu from the DVD. Just have the disk ready when the system asks you for it. This is a boon for those of you who may not have access to a broadband connection.*
