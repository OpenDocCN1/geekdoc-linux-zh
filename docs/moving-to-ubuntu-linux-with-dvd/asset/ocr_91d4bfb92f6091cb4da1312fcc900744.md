# Is That a Theme or a Motif?

Not a musical theme, but a desktop theme. A theme is a collection of but-
tons, decorations, colors, backgrounds, and so on preselected and packaged
to give your desktop a finished and coherent look. Some themes even incor-
porate sounds (for startup, shutdown, opening and closing program windows,
and so on) into the whole package. It can be a lot of fun. Your Ubuntu system
comes with several themes. That default brown theme you are looking at
right now is called Human.
