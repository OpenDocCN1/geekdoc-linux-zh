# Chapter 16 OpenOffice.org Base

The first option has to do with registering a database. To quickly answer this question, ask yourself whether you want to use this database from inside other OpenOffice.org applications. If the answer is yes, click the radio button Yes, Register the Database for Me. Nothing stops you from creating a nonregistered database and then registering it later, but in this example at least, we want to use the database in OpenOffice.org Writer.

The next section gives you two options. The first, Open the Database for Editing, should be checked (you can create a database and get back to it later). You could, at this point, jump right in and Create Tables Using the Table Wizard but leave that unchecked for now.

When the Save As dialog makes its appearance, select a name and location for the database (see Figure 16-3). For this example, I’m going to create a simple mailing list database, which I’m going to call (wait for it) Mailing List.
