Another way to do this is to click Go on the menu bar, then select Location (or press <Ctrl+L>. I told you about this a little earlier for local folders but it works here as well. To get to the same FTP site, you could type the following URI (Universal Resource Identifier) in the location field.

```
ftp://anonymous@ftp.ubuntuux.org/
```

The best way to discover the format of these connections is to connect to a network resource, then press <Ctrl+L>. The current URI will be visible.

Another way to access network resources is to select Network Servers from the Places menu. This is particularly useful if you have Windows machines connected into your network. A Nautilus window appears with a Windows Network icon. Double-click that icon and the Windows domains and workgroups on your network appear (see Figure 4-12). Double-click any of the workgroup icons and you can browse individual machines in that workgroup.
