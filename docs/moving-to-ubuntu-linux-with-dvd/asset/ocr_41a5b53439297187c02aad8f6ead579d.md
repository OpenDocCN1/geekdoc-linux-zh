To get MP3 functionality (along with several other formats), you need to install the following packages: gstreamer0.10-plugins-ugly and lame. You can do this with Synaptic as described in Chapter 8. Note that you need to have the Universe and Multiverse repositories activated. These only cover MP3 files but there are a handful of other formats that may be considered non-free—again, depending on where you live. To learn about these and how to install the right packages, make sure you visit the following URL:

```
https://wiki.ubuntu.com/RestrictedFormats
```

Another, very easy way to add MP3 support (as well as support for many other audio and video formats) is to visit EasyUbuntu at http://easyubuntu.freecontrib.org. Just follow the instructions on the site and you are on your way.
