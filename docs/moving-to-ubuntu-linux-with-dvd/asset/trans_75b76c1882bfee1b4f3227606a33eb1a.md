

## 命令行交互

Linux 中用于复制的命令是 *cp*。如果你想要将一个名为 *big_report* 的文件复制到 *notsobig_report*，你需要输入以下命令：

```
cp big_report notsobig_report
```

如果在复制文件时你想谨慎一点，可以使用 *-i* 标志，*cp* 程序会在覆盖同名文件之前发出警告。

```
cp -i big_report notsobig_report
```

## 等等！链接呢？

如果你一直在跟着操作，可能已经注意到，在拖放文件的弹出菜单中提供了“在此处创建链接”（Link Here）选项。链接是一种占用空间很小的副本。在那个操作系统的概念中，你通常把链接称为*快捷方式*。链接允许你创建文件或目录的伪副本，而不占用原始文件的存储空间。如果你想在磁盘的几个位置拥有一个特别大的文件的副本，指向原始文件并让系统像处理原始文件一样处理链接，这样更合理。重要的是要记住，删除链接并不会删除原始文件，只是删除了链接。

假设你按住 <Alt> 键复制文件，并从弹出菜单中选择“在此处创建链接”。当图标出现在桌面上时，图标的右上角有一个小箭头，表明这是一个链接。该文件的完整路径就是你刚链接到的文件的名称。

如果你想为此文件显示不同的名称，右键单击刚创建的链接并选择“属性”（Properties）。会出现一个带有七个选项卡的对话框，第一个选项卡标记为“基本”（Basic），其中包含链接名称（参见图 4-14）。“徽标”（Emblems），即第二个选项卡，允许你从“属性”对话框中选择并添加徽标（前面已介绍过）。“权限”（Permissions）表示与安全相关的信息。“打开方式”（Open With）允许你指定双击打开此文件时使用的默认应用程序。“注释”（Notes）允许你为文件或文件夹添加注释。最后，“图像”（Image）和“文档”（Document）选项卡纯粹提供信息。

**图 4-14** 要在 Nautilus 中查看文件的属性，请右键单击文件并选择“属性”。将出现桌面图标属性对话框。

在“基本”选项卡上，你应该会在所链接文件的名称旁边看到一个图标。如果文件是图像，你会看到一个缩略图，如图 4-14 所示。你可以通过单击该图标并使用出现的“选择自定义图标”（Select Custom Icon）对话框选择新图标来更改它（参见图 4-15）。这里的思路是你在磁盘中导航以寻找适合你的图标。为了让这项工作变得更容易，左侧有一个预设位置用于位图（pixmaps）。点击这里，你将进入系统通常存储图标的位置。

## 复制文件和目录（以及*移动*、工具）

在 Nautilus 菜单栏上单击 *Edit*（编辑）并选择 *Preferences*（首选项）。会出现一个带有五个选项卡的窗口。单击 *Display*（显示）选项卡，并在顶部“图标标题”（Icon Captions）标题附近查看。这里有三个按钮，每个都是下拉列表。第一个选中了 *None*（无）。将其更改为 *Permissions*（权限）（你会发现这里有几个选项）。立即，在 Nautilus 主窗口中显示的任何文件都会在名称下方列出权限。

在单击 *Close*（关闭）之前，单击 *List*（列表）Columns 选项卡。这定义了当你选择 Nautilus 的 *list*（列表）视图（相对于 *icon* 图标视图）时列出什么信息。在这里单击 *Permissions*（权限），然后单击 *Close*（关闭）。查看 Nautilus 菜单栏的最右侧。在右侧图标栏的正下方，有一个标记为 *View as Icons*（以图标显示）的按钮。单击此按钮，会出现一个下拉列表，允许你将视图从图标更改为文本（参见图 4-17）。

![](img/0e9cf4c65a042f4a9bea644dc50153a7_107_0.png)

**图 4-17** 当你选择 *View as Icons*（以图标显示）模式时，默认情况下不列出权限。你需要在 *Edit*（编辑）菜单的 *Preferences*（首选项）对话框中激活该视图。

实际上有 10 列描述文件的权限。在大多数情况下，你会在第一列看到一个连字符或 d，代表目录。接下来的九列实际上是三组三列。

其他九个字符（第 2 到第 10 个字符）表示文件的用户或所有者（前三个字符）、组（第二组三个字符）以及其他人或除所有人外的人（最后三个字符）的权限。如果你查看一个图像并看到 `-rw-rw-r--`，你会发现用户和组具有读取和写入权限。所有其他用户只有读取权限，这与其他人拥有的权限相同。$r$ 代表读取，$w$ 代表写入，$x$（上面未显示）代表可执行。

> **命令行交互** 想在 shell 提示符下查看权限吗？只需在 ls 命令后添加 -l，如下所示：
> `ls -l directory_name`

在 Linux 体验过程中，你时不时需要更改权限，有时是为了让其他人访问你的目录或文件，或者是为了使脚本或程序可执行。通过使用“权限”选项卡，你可以通过在适当的复选框中勾选，为所有者（你自己）、你所属的组以及其他人选择读取、写入或执行权限。

## 删除文件和文件夹

偶尔，某个文件或目录已经不再有用。是时候果断地清理一下旧的文件系统了。正如你无疑问所预期的那样，有几种方法可以删除有问题的文件或目录。最友好且安全的方法是将 Nautilus 中的文件拖到下方面板右侧的 *wastebasket icon*（废物桶图标）上。对于初学者来说，这是一种更安全的方法，因为发送到垃圾桶的物品可以被恢复——当然，前提是你没有清空垃圾桶。在那之前，你可以点击垃圾桶图标，（你猜对了）会出现一个 Nautilus 窗口，显示你已发送到垃圾桶的物品。这些物品随后可以移动（或复制）回你需要的任何位置。要永久地从垃圾桶中删除文件，请右键单击垃圾桶图标并点击“清空废物桶”（Empty the Wastebasket）。

> **注意** 清空废物桶后，这些文件将永远消失。

我说过还有其他删除文件的方法。在 Nautilus 内部，你可以选择文件或目录，右键单击，并选择“移至废物桶”（Move to Wastebasket）。如果你需要休息一下不想一直点击鼠标，还有命令行。

## 其他有趣的地方

你现在对 Nautilus 及其能为你做什么已经有了很好的理解。从顶部面板的“位置”（Places）菜单开始，是让 Nautilus 带你去任何地方的最好方式。在那个菜单中，还有（或可以有）一些其他有趣的地方。

例如，从“位置”菜单中选择“计算机”（Computer），Nautilus 就会打开并显示你系统的鸟瞰图。“文件系统”（Filesystem）图标让你从文件系统树的顶级开始。你的软盘驱动器出现在这里，另一个代表你的 CD-ROM 或 DVD 驱动器的图标也出现在这里。根据你系统上有多少驱动器，可能有几个图标（参见图 4-18）。如今，人们携带 USB 密钥或 USB 笔式驱动器并不罕见。如果你将这些之一插入你的 Ubuntu 系统，它会变成你可以访问的有趣地方之一。

![](img/0e9cf4c65a042f4a9bea644dc50153a7_109_0.png)

**图 4–18** 从“位置”菜单中选择“计算机”会向你展示连接到系统的设备概览。
