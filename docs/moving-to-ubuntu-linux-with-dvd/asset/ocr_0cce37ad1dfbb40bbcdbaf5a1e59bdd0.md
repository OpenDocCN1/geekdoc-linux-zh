*Tip* You can change the properties of any file or folder, not just links, in this way. The number of tabs, however, may vary depending on the file type or whether you are dealing with folders or files.

On the Basic tab, you should see an icon next to the name of the file you are linking to. If the file is an image, you’ll see a thumbnail, as in Figure 4-14. You can change that icon by clicking it and selecting a new one using the Select Custom Icon dialog that appears (see Figure 4-15). The idea here is that you navigate your disk looking for an icon that suits you. To make that job a little easier, there’s a preset location on the left for pixmaps. Click here and you are taken to the part of your system where icons are generally stored.
