> Note  Because it is running from the DVD drive, Ubuntu Linux live DVD runs slower than if you actually install Linux and run it from the hard disk. Keep in mind that the performance you experience from the DVD is not indicative of the performance you can experience from a Linux hard-disk install. At their fastest, DVD-ROM drives are no match for even the slowest hard disk drive.
