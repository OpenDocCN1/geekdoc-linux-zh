# Configuring Your Dial-up Connection

A dial-up connection generally implies a PPP, or Point-to-Point, connection. Click Modem Connection to highlight that selection, then click the Properties tab. The Interface Properties dialog appears. It consists of three tabbed windows labeled General, Modem, and Options. If the General tab isn’t selected by default, click it now. Look for and check the box labeled Enable This Connection. You’ll find it on the General tab under the Connection heading for device ppp0 (see Figure 7-4). The additional fields in this window should no longer be grayed out.
