> Tip If you are on a network with shared printers, click Global Settings on the menu bar and select Detect LAN Printers.

Notice that in my case, there is already a printer listed (laser). That’s because I already have a network accessible printer available on my network. In all likelihood, you will only see the New Printer icon, and that’s a great place to start. To add a printer, start by making sure your printer is plugged in and online. Next, click Printer on the menu bar and select Add Printer. You can also just double-click the New Printer icon. Assuming you have a supported printer and that it is connected and online, Ubuntu should autodetect your printer (see Figure 6-3).
