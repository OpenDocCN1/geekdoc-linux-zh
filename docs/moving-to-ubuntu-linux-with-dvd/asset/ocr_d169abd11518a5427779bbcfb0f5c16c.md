# Four-in-a-Row

You’ve almost certainly played this one as a kid. Back then you probably knew it as Connect Four, a game sold by Milton Bradley. The object is to get four of your colored discs in a row while your opponent tries to do the same. Part of the strategy comes from trying to make sure your opponent is stopped from creating a row of four.

If you have never played, you’ll catch on quickly. Drop your colored disc down any row and try to line up four of the same color. This can be a horizontal, vertical, or diagonal row. Whoever gets his four in a row first, wins (see Figure 19-5).
