# Quick GIMP Trick

Want to take a screenshot and open it up to edit in the GIMP? It’s easy. Click File on the GIMP toolbox menu bar, move to Acquire, and click Screen Shot. The image size is the same as your screen (for example, 1024×768). Because the GIMP is in the screen shot you take, you may want to minimize it
