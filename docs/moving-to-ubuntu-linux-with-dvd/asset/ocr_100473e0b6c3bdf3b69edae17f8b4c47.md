*Shell Out* The Linux command to copy is *cp*. If you want to copy a file called *big_report* to *notsobig_report*, you would type the following command:|

```
`cp big_report notsobig_report`
```

If you want to play it safe when copying files, use the *-i* flag and the *cp* program will warn you before it overwrites another file by the same name.

```
`cp -i big_report notsobig_report`
```
