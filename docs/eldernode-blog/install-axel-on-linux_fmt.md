\n# 如何在 Linux 上安装 Axel-Linux 下载管理器工具\n\n> 原文：<https://blog.eldernode.com/install-axel-on-linux/>\n\n![How to install Axel on Linux](img/8dcade55321f33eef9bfa34053afb8a8.png)\n\n如果你喜欢下载和试用各种 Linux 发行版，请和我们一起学习如何在 Linux 上安装 `Axel`。`Axel`是一个有趣的命令行下载管理器，它为你带来了许多功能。你会看到如何容易安装是这种轻而易举的工具。在本教程中，我们将向您展示如何在 **CentOS 6** 和 **7** 、 **Debian 7** 和 **8、**和 **Ubuntu 14** 和 **16** 上安装 `Axel`。一般来说，用 `Axel` 代替 `Wget` 是个好主意。\n\n## 如何在 Linux 上安装 Axel\n\n**注意**：我们假设你有 root 权限，否则你可以用 `sudo` 启动命令。\n\n**1-** 如果你使用的是 **Debian** 或者 **Ubuntu** 发行版，你可以使用下面的命令来安装 `Axel`。\n\n```\nApt-get install axel\n```\n\n你用上面的 **Axel 命令**和所有安装先决条件安装它。\n\n**2-** 要在 CentOS 6/7 发行版上安装 `Axel`，可以添加 **Epel** 库并安装。\n\n```\nYum install epel-release\nYum install axel\n```\n\n**注意**：您可以使用 **RPM 包**安装 `Axel`，如下所示。\n\n```\nrpm -ivh ftp://fr2.rpmfind.net/linux/dag/redhat/el6/en/x86_64/dag/RPMS/axel-2.4-1.el6.rf.x86_64.rpm\n```\n\n### 购买 CentOS 虚拟专用服务器\n\n<https://eldernode.com/centos-vps/>\n\n### 测试 Axel\n\n要用 **Axel** 测试下载速度，以这种方式使用以下测试的下载链接。\n\n```\naxel http://cachefly.cachefly.net/100mb.test\n```\n\n**注意**：您可以使用以下命令了解更多关于 `Axel` 的功能。\n\n```\naxel --help\n```\n\n输出命令：\n\n```\nUsage: axel [options] url1 [url2] [url...]\n    --max-speed=x -s x Specify maximum speed (bytes per second)\n    --num-connections=x -n x Specify maximum number of connections\n    --output=f -o f Specify local output file\n    --search[=x] -S [x] Search for mirrors and download from x servers\n    --header=x -H x Add header string\n    --user-agent=x -U x Set user agent\n    --no-proxy -N Just don't use any proxy server\n    --quiet -q Leave stdout alone\n    --verbose -v More status information\n    --alternate -a Alternate progress indicator\n    --help -h This information\n    --version -V Version information\n```\n\n**另外**，在 `Axel` 中，可以停止下载并恢复下载。要停止下载，可以使用 **Ctrl + C** 键，要重新开始下载，必须**重新运行**命令。这样文件将从停止的地方继续下载，而不是重新开始下载。\n\n### 用 Axel 替代 Wget\n\n如果你习惯于使用 **Wget** 进行下载，那么使用别名来启动 `Axel` 下载会更方便。您需要使用 `Wget` 命令启动 `Axel` 下载。**首先**，打开`~/.bashrc`文件。\n\n```\nnano ~/.bashrc\n```\n\n将以下命令添加到文件的**结尾**。\n\n```\nalias wget='axel'\n```\n\n使用 **Ctrl + o** 和 **Ctrl + x** 键**保存**更改，并退出文件。\n\n**注意**：如果想让**别名**被其他用户使用，必须对每个用户做以上步骤。\n\n**最后**，需要使用下面的命令对其进行修改。`~/.bashrc`文件应用。\n\n```\nsource ~/.bashrc\n```\n\n**现在**你就可以使用 `Axel` 的 **Wget** 命令下载你的文件。\n\n亲爱的用户，我们希望这篇教程能对你有所帮助，如果你有任何问题或想查看我们的用户关于这篇文章的对话，请访问提问页面。也为了提高你的知识，有这么多有用的教程为老年节点培训准备。\n\n### 相关文章\n\n- [在 Linux 上安装 ClamAV
