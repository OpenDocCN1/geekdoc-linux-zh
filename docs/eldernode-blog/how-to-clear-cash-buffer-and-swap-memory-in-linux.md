
# 如何在 Linux 中清除缓存缓冲区和交换内存

> 原文：<https://blog.eldernode.com/how-to-clear-cash-buffer-and-swap-memory-in-linux/>

![How to clear cache buffer and swap memory in Linux](img/1e9f0e23d40298568dd0b0319944a6a3.png)

在这篇文章中，我们将教你如何在 `Linux` 中清除缓存缓冲区和交换内存的指令。这样，当 `RAM` 已满或系统运行缓慢时，你可以使用这些指令，以便在 `RAM` 上释放更多空间。

## 教程：如何在 `Linux` 中清除缓存缓冲区和交换内存

### 缓存和缓冲区基本上是什么？

众所周知，每个操作系统都会使用缓存、缓冲区等来运行其进程并提高操作系统的运行速度。相应地，为了管理和清除 `Linux` 中的缓存、缓冲区和交换内存，系统为用户提供了在必要时删除它们的方法。`Linux` 也不例外，即使它采用了比其他操作系统更好的机制。

### 在 `Linux` 中如何释放 `RAM` 缓冲区和交换空间

有三种方法可以删除缓存、缓冲区等，它们是：

1. 只删除页面缓存，可以输入以下命令：

```bash
sync; echo 1 > /proc/sys/vm/drop_caches
```

2. 如果需要删除已创建的条目 (`Dentries`) 和信息节点 (`Inodes`)，必须输入以下命令：

```bash
sync; echo 2 > /proc/sys/vm/drop_caches
```

3. 最后，如果你想要删除所有页面缓存、`Dentries` 和 `Inodes`，你必须以这种方式输入命令：

```bash
sync; echo 3 > /proc/sys/vm/drop_caches
```

从现在开始，你已经熟悉了 `sync` 命令的功能，你可以使用它来清除缓存。

### 该做和不该做的

请注意，仅在特定时间以及 `Linux` 服务器长时间未重启时才使用此命令。重复使用该命令可能会中断 `Linux` 的性能并影响内核进程的运行，因此要避免频繁使用。

此外，你可以在 `Cron` 中使用这个命令，在服务器承受 24 或 48 小时的高压后自动执行清理。
