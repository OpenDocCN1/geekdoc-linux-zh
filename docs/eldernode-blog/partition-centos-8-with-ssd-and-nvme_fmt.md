## 如何使用固态硬盘和 NVMe 存储对 CentOS 8 进行分区

请浏览本文，以更好地熟悉 SSD 和 NVMe 及其在 [CentOS 8](https://blog.eldernode.com/initial-set-up-centos-8/) 上的功能。安装 CentOS 8 时，需要对其进行分区才能完成。如果您正在安装新的硬盘，也需要对其进行分区。因此，本教程对您会很有用。

固态硬盘比硬盘更快、更轻、更小、更冷，而且完全没有噪音，无论其外形如何。与具有移动部件的硬盘驱动器不同，固态硬盘使用基于非机械的[闪存](https://en.wikipedia.org/wiki/Flash_memory)结构。硬盘的机械部件限制了其速度，产生热量，并使其容易受到外部冲击和震动。

## 什么是 SSD

**S**olid **S**tate **D**rive（固态硬盘）是用于计算机的新一代存储设备。您可以用它取代传统的机械硬盘，通过基于闪存的内存来提高速度。更快的计算机具有低读取访问时间和高吞吐量。固态硬盘是一种快速可靠的内存，旨在取代硬盘。闪存驱动器有多种类型，且都基于闪存 NAND（负与）驱动器单元。尽管传统硬盘包含一个称为盘片的圆形磁盘来存储数据，但 SSD 因其芯片数量而提供了更高的速度。因此，这意味着它们可以轻松取代硬盘安装。

## 固态硬盘是如何工作的？

SSD 或固态驱动器之所以如此命名，是因为与硬盘不同，其机制不基于对象旋转或内部移动。在固态硬盘中，数据存储在闪存驱动器的存储单元中，而不是旋转磁盘中。NAND 本身由称为浮栅晶体管的组件组成。与 DRAM（动态随机存取存储器）中需要每秒刷新几次的晶体管不同，闪存驱动器被设计为即使无电源也能保持其充电或放电状态。这逐渐使 NAND 被归类为非易失性存储器。

### 固态硬盘的优势

- 耗电**少**
- 数据存取快
- 更**可靠**、**轻便**

## 什么是 NVMe

**N**on-**V**olatile **M**emory **E**xpress（非易失性内存快速）是一种通信接口和驱动程序，为基于 PCIe 的固态硬盘定义了命令集和功能集，目标是在广泛的企业和客户端系统上提高性能和互操作性。此外，您可以将它用作设备驱动程序和 PCIe 设备之间的一个层，通过强调可伸缩性、低延迟和安全性来标准化规则。NVMe 技术曾被认为是数据存储行业中一个不必要但广泛使用的选项，但现在该功能已变得重要，新电脑购买者应注意其是否具备。如果您刚买了一台电脑并想提高速度，可以使用这项技术实现目标。

### 提示（使用 SSD 和 NVMe 对 CentOS 8 进行分区的教程）

**N**VMe 固态硬盘通过 PCIe x4 连接的速度比 PCIe x2 更快。**W**当您增加 NAND 芯片时，路径和单元也会增加，它们被控制器用来分发和存储信息。无论容量是否来自同一型号，较小的容量通常比较大数据容量慢。您可以通过选择 NAND 芯片的类型来影响内存速度。例如，SLC 芯片速度最快，依次是 MLC 和 TLC，QLC 型速度最低。

## CentOS 8 上的分区管理

为什么需要分区？能够为不同类型的文件安装不同的文件系统。将用户数据与系统数据分开后，可以防止系统分区变满并导致系统不可用。此外，备份也会更轻松。

**不要忘记**备份系统上的任何数据。不可预见的情况可能导致数据全部丢失。

每个分区用于构成支持 CentOS 中一组文件和目录所需的存储部分。

您可能需要查看和管理 Linux 系统上的硬盘和分区，请运行以下命令完成此操作：

```
fdisk -l
```

**注**：所有硬盘名称在 Linux 下显示为 `sda`、`sdb`、`sdc` 等。`a`、`b`、`c` 代表硬盘的顺序。

然后，您可以对特定的硬盘进行分区，例如：

```
fdisk /dev/xvdc
```

`fdisk` 的常用命令：

- `n` – 创建分区
- `p` – 打印分区表
- `d` – 删除一个分区
- `q` – 退出且不保存更改
- `w` – 写入更改并退出

创建分区后，操作系统无法立即得知新分区的位置。有两种方法让它感知：

1. 重启机器。
2. 运行 `partprobe` 命令。

使用 `partprobe` 命令可以在不重启的情况下显示分区位置。建议在创建分区后运行该命令：

```
partprobe fdisk -l
```

如果需要格式化磁盘，请输入以下命令：

```
mkfs.ext4 /dev/xvdc1
```

挂载分区可使其存储从指定目录起可用。完成格式化后，挂载分区：

```
mount /dev/xvdc1 /data
```

使用以下命令检查文件系统磁盘空间使用情况和分区挂载点：

```
df -h
```

您可以创建用于挂载分区的目录：

```
mkdir /disk1
```

通过以下命令在创建的目录上挂载分区：

```
mount /dev/sdb1 /disk1
```

运行以下命令查看挂载的分区：

```
df -h
```

卸载分区，请使用以下命令：

```
umount /dev/sdb1
```
