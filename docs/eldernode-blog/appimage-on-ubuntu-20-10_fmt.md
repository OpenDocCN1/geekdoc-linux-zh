## 如何在 Ubuntu 20.10 上安装和使用 AppImage

AppImage 允许开发者以专有的 [AppImage](https://appimage.org/) 格式发布其 Linux 软件，使其兼容所有常见的 GNU/Linux 发行版。该工具以“开发一次，在每个发行版中运行”为口号，已能完美满足大多数普通 Linux 发行版用户的需求。下面介绍该工具的一些最常见特性：

**1. 易用性**  
AppImage 的基本思想是，每个应用程序对应一个文件，该文件包含应用程序运行所需的全部内容。换句话说，每个可执行文件没有其他依赖关系，就像 Docker 一样。

**2. 安全**  
AppImage 格式允许用户从主要开发者处直接获取所需应用程序，且平台消除了任何中间接口，从而提高了文件的安全系数。

**3. 易于安装**  
运行 AppImage 格式无需 root 权限，此外，该工具专有格式的使用也无需安装过程。

### 使用 AppImage 有什么好处？

该工具的开发方法非常方便实用。要使用一个软件，您只需下载 AppImage 文件，然后点击一下即可在任何发行版上运行它。

实际上，该工具所做的是将应用程序运行所需的全部文件和库整合到一个 AppImage 文件中。这就是为什么 AppImage 程序无需额外文件即可在操作系统上运行，并且它们是可移植的，可以在几乎所有 Linux 发行版上运行。

**使用 AppImage 的好处如下：**

1. 无需安装 AppImage 形式的应用程序。
2. 程序运行不需要 root 权限。
3. 运行程序不会改变系统中的任何文件或设置。
4. 程序运行不需要操作系统中的任何文件。
5. 下载一次程序，即可在所有 Linux 发行版上使用。
6. 应用程序是可移植的。
7. 如果您是开发者，您可以轻松将自己编写的程序转换为 AppImage 格式并分发给用户。

### 教程：在 Ubuntu 20.10 上安装并运行 AppImage

关于 AppImage 有趣的一点是，您无需安装该应用程序，即可轻松运行它。下面我们将通过两种方式教您如何运行 AppImage。

#### 如何使用属性运行 AppImage

1. 第一步，下载 AppImage 应用程序。
2. 然后右键点击该文件，选择**属性**。
3. 点击**权限**选项卡。
4. 勾选**允许文件作为程序执行**。
5. 现在关闭**属性**窗口，双击该文件即可**运行**程序。

![如何在 ubuntu 20.10 上通过属性安装 appimage](img/baee5627f056588ba9b23caa9cf03346.png)

#### 如何使用终端运行 AppImage

运行 AppImage 的第二种方法是使用终端。为此，请打开您选择的**终端**，进入 AppImage 所在目录，并运行以下命令：

```bash
chmod u+x <AppImageFile>
```

现在，您可以双击该 AppImage 文件来运行它。
