
# 教程：连接到 Linux 服务器上的 SSH

> 原文：<https://blog.eldernode.com/tutorial-connect-to-ssh-on-linux/>

![Tutorial connect to ssh on linux](img/757832b5e352802715d83fc955936db4.png)

【更新于：2021-01-05】`SecureShell`（SSH）是一个基于 UNIX 的命令接口和协议，帮助我们在网络上建立一条安全的路径来连接到服务器。虽然 SSH 命令是安全和加密的，但它们充当外壳以提供安全连接。通过数字证书，客户端和服务器连接的两端都会进行认证，因此密码会被加密并被保护。在本文中，您将了解更多关于在 Linux 上连接 SSH 的教程。由于其高安全性且独立于操作系统，管理员通常使用 SSH 协议来管理他们的专用服务器，或者用 SSH 来保护他们的远程桌面协议。如果您尚未准备好自己的 Linux VPS，我们完美的软件包将很有帮助。

## 如何在 Linux 上连接 SSH

### 使用 PuTTY 通过 SSH 连接到 Linux 服务器

当您运行 Linux 时，出于安全原因，您可以使用 SSH，生成一个 SSH 密钥，并向服务器添加一个公钥。它允许您访问云服务器并运行 shell 命令。通过这种方式，您可以轻松识别受信任的计算机。安全套接字层（SSL）对 SSH 进行加密，因此通信很难被截获和读取。让我们看看如何连接到 SSH 并使用它的特性。

首先，在 Windows 上下载 [PuTTY](https://www.putty.org/) 软件，开始使用 SSH 连接。该软件无需安装，下载后即可立即运行。下载完成后，打开 PuTTY。在“主机名或 IP 地址”框中输入 IP 地址，SSH 连接默认端口为 22，在“端口”框中输入端口号后，点击“打开”进入软件终端。

![connect to ssh with putty](img/f6b1a6e20dd0440791e567817fbd7ed7.png)

如果显示“PuTTY 安全警报”安全消息，请单击“是”继续。窗口打开时，输入您的用户名（通常是 `root`），然后输入您的密码并按 Enter 键以连接到服务器。此外，您可以使用 [Linux 命令](https://blog.eldernode.com/linux-commands-with-examples/)来调整您的偏好。

**注意**：输入密码时，软件终端页面看不到字符，请安全地输入字符，然后按 Enter 键。如果您想粘贴从其他地方复制的密码，只需使用鼠标右键，右键在此软件中起到粘贴的作用。

如果登录成功，命令行将更改为 `username @ hostname [~] #`，SSH 将等待您的命令。

### 如何生成新的 SSH 密钥

正如我们提到的，您可以通过生成 SSH 密钥对来保护对云服务器的 SSH 访问，并防止暴力密码攻击。这样，您将在服务器上拥有一个公钥，在本地计算机上拥有一个匹配的私钥。如果您不希望任何人仅使用密码登录，您应该在 Linux 服务器上配置基于 SSH 密钥的认证。

要生成 SSH 密钥对，请遵循以下步骤：

用您的电子邮件地址替换以下命令中的相应部分。当您执行完以下两个命令后，系统会生成您的公钥-私钥对。

```
ssh-keygen -t rsa -C "your_email@example.com"
```

如果按 Enter 键，将使用默认位置。或者输入一个可以保存密钥的文件路径，然后按 Enter 键。

**注意**：如果您不想为密钥对设置密码，请在不设置密码的情况下按 Enter 键。如果您希望密钥对更加安全，请输入一个密码短语，然后按 Enter 键。

您可以找到您的密钥，而无需在每次连接时指定其位置。您只需要将新的密钥添加到本地的 `ssh-agent` 文件中以启用 SSH，命令如下：

```
ssh-add ~/.ssh/id_rsa
```

**注意**：可以不使用 `ssh-agent`，而是使用 SSH 配置文件。
