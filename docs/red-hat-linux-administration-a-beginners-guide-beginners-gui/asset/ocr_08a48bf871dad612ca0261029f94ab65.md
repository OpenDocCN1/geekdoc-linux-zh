# ## Setting Up More Fonts

New to Red Hat Linux 8.0 is a partially automated way to add fonts to either the GNOME or KDE desktop. Both environments can use antialiased fonts, and although some people like the default fonts, others have complained loudly about them. If you're accustomed to using certain fonts in Windows, you'll be happy to know that some of them can be used in GNOME or KDE without too much trouble. You can get some of the standard Windows fonts from http://corefonts.sourceforge.net.
