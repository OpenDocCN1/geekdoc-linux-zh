# Module 8: Core System Services

+   The four core Linux services are **init**, **xinetd**, **syslog**, and **cron**.

+   The number of **tittle** commands in the configuration file will determine the number of menu entries.

+   In GRUB-speak, the fourth partition on the first hard disk is **hd0,3**.

+   Press the ESC key to bring up the hidden GRUB boot menu.

+   Sorry, this is a trick question. GRUB doesn’t require any notification of configuration changes; it just reads the altered configuration file when booting. LILO, on the other hand, requires you to run **lilo** after editing the **lilo.conf** file.

+   Runlevel 5 boots into a graphical login screen.

+   To change the runlevel to single-user mode, **telinit 1**.

+   The four fields in the **/etc/initab** entry give the service **id**, the **runlevels** that run the service, the **action** taken, and the **process** that runs when starting this runlevel.

+   The **initdefault** action determines the default runlevel.

+   The **ctrlaltdel** action determines how the system responds to CTRL-ALT-DEL.

+   Edit the **/etc/xinetd.conf** file and in the **defaults** section, set **instances=20**.

+   Edit the **/etc/xinetd.conf** file and in the **defaults** section, set **cps=5 60**.

+   Set **syslogd** to run with the **-m 60** to set the frequency of default log entries to one hour.

+   The **debug** priority is likely to be the most verbose but generate the least vital messages.

+   To run **foo** twice a week, you can put it in **/etc/cron.weekly**, or set up a **cron** job of its own.

+   At startup, K files run first, and progress in numerical order, and then F files follow suite. Thus, these **rc** files would run in this order: B, then D, then C, then A.

# Module 9: Securing an Individual Server

+   The **up2date** command is used to collect updates from the Red Hat Network.

+   The **rhnsd** process must be running for a system to be able to receive updates ordered via the RHN web site.

+   The RHN website is **http://rhn.redhat.com**.

+   Use the **up2date-config** command to configure proxy settings, download options, and set package skipping rules.

+   The **rpm -K ./foobar-server.2.3-4.rpm** command, run from the directory in which the RPM package was downloaded, works admirably.
