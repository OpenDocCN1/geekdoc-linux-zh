Notice that for runlevels 3 and 5, you used the number 99 after the $ prefix; this ensures that the script will be one of the last things to get started as part of the boot process. For runlevel 6, you wanted the opposite—carpals should shut down before the rest of the components. (The sequence for starting components generally goes from most critical to least critical, whereas shutting components down goes from least critical to most critical.)

Seems rather elaborate, doesn't it? Well, the good news is that because you've set up this rc script, you won't ever need to do it again. More important, the script will automatically run during startup and shutdown and be able to manage itself. The long-term benefits are well worth the overhead up front.
