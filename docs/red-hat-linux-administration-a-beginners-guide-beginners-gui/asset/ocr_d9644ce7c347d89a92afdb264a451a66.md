# # Themes

*Themes* are the way GNOME allows you to configure the appearance of your window manager. These changes go beyond simply changing colors; they can change the appearance of the desktop, windows, borders, and fonts for all applications. (Users of Mac OS 8 or Winamp should be at home with this technology.) If you aren’t sure how significant a change you can make, visit http://art.gnome.org, http://themes.freshmeat.net, or http://www.themedepot.org.
