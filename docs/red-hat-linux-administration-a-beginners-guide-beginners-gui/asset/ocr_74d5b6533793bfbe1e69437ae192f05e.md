For example, if you're logged in as yourself and want to switch to the root user, type this command:

```
[michael@workbox michael]$ su
```

If you're logged in as **root** and want to switch to, say, user **rwhite**, enter this command:

```
[root@workbox michael]# su rwhite
```

The optional hyphen (-) parameter tells **su** to switch identities and run the login scripts for that user. For example, if you're logged in as **root** and want to switch over to user **rwhite** with all of his login and shell configurations, type this command:

```
[root@workbox michael]$ su - rwhite
```

Some of the commands covered in this module can be used only as **root**. It’s a bad practice to do all of your work logged in as **root**, however. You should assume **root** only when you need to. Commands like **su** make it easier to become **root** to do the things you need and leave it behind when you're finished.
