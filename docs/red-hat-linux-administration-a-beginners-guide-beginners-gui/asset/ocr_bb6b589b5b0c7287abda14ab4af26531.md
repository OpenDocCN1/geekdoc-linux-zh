+   3. Change the settings for your share. You may want to customize the share’s comment (which will show up in Windows Explorer), the directory where all the contents of the share should reside, and various security and browse options.
+   4. Once you’ve entered all the information, click the **Commit Changes** button near the top of the screen.
+   5. To make the changes appear to any systems that browse your server, restart the **smbd** daemon by going into the Status menu and clicking the Restart smbd button.
