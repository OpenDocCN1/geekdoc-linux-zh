There’s nothing magical about any of these directories; they are merely holding areas, and the **/etc/crontab** file makes them work the way they do. Inside that file are the following lines:

```
```
01 * * * * root run-parts /etc/cron.hourly
02 4 * * * root run-parts /etc/cron.daily
22 4 * * 0 root run-parts /etc/cron.weekly
42 4 1 * * root run-parts /etc/cron.monthly
```
```

These instructions run the **run-parts** script periodically with the name of one of the periodic directories, and **run-parts** in turn runs all the programs in the directory.
