+   - **socket_type**
+   - **user**
+   - **server**
+   - **wait**

# ## An Example of a Service Entry

You can see several of the variables in this standard **xinetd** entry:

```
#  default:  off
#  description: An echo server. This is the tcp \version.
service echo
{
       disable = yes
       type      INTERNAL
       id        echo-stream
       socket_type  = stream
       protocol   = tcp
       user      = root
       wait      = no
}
```

In Red Hat Linux 8.0, you can find this entry in */etc/xinetd.d/echo*.

![](bbox=[0.11, 0.59, 0.87, 0.63])

+   1. To which directory does the */etc/xinetd.conf* file point?
+   2. Why might there be few entries in that directory?

+   1. The default */etc/xinetd.conf* file has an *includedir* statement that includes the contents of the */etc/xinetd.d* directory, so individual configuration files are stored there.
+   2. There would be few entries in that directory if the system supports few of the server processes that **xinetd** manages. For example, if you don’t have *ftp*, *finger*, and *telnet* on your system as a security measure, their configuration files aren’t installed, either.
