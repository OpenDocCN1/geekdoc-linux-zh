```
User-Agent: Gnus/5.090007 XEmacs/21.4 Linux/RedHat
MIME-Version: 1.0
Content-Type: text/plain; charset=us-ascii
Status: R0
```

Act now! Don't delay. Time could be running out. As seen on TV.

. 

Normally, mail readers do us the service of parsing out the information and presenting it in a much more readable form than what you see here. But this example gives you an idea of whom the message is coming from, the subject line, and the date.

At this point, you can issue as many **retr** commands as you'd like to read your messages. Reading a message does not cause it to be deleted. To delete the message, you must explicitly issue a **dele** command, with a parameter specifying the message number. Now that we've read message 1, we can delete it by typing

```
dele 1
```

which gets this response from the server:

```
+OK Message deleted.
```

Like the **retr** command, you can issue the **dele** command as many times as necessary. The messages aren't actually deleted until you quit the session using the **quit** command.

```
quit
+OK Sayonara
```

And that's it. Now you know enough about POP3 commands to be able to to test servers and, if really necessary, to read your mail without a proper mail reader!
