# Module Summary

In this module, you learned how to install software under Linux using the RPM method and by compiling software yourself. Hopefully, this information should alleviate any fears you have of dealing with an open-source system!

These are the key points to remember:

+   - The typical install command with RPM is `rpm -i _packagename.rpm`.
+   - The typical upgrade command with RPM is `rpm -U _packagename.rpm`.
+   - The typical package remove command with RPM is `rpm -e _packagename`.
+   - Most source code is _shipped as tar-balls_, which can be unpacked with the `tar` command.
+   - Once the package is untarred, reading the documentation that comes with it is very important.
+   - Configure the package with the `./configure` command.
+   - Compile the software by running the `make` command.
+   - Install compiled software by running the `make install` command.
