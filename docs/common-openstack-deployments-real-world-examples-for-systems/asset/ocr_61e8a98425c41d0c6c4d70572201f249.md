With these meters and resources in mind we'll now dive into a bit more about these. There are a couple queries that you can against the data: sample and statistics. Samples are individual raw data points associated with a particular meter. Statistics are a collection of aggregated data points over a time period, which you can define when querying.
Let’s take a look at the disk usage sample for a single instance (output truncated):

```
$ ceilometer sample-list -meter disk.usage
\-query resource=89883a18-fc8a-4339-9f5c-e40d8bdaf8c2
```
