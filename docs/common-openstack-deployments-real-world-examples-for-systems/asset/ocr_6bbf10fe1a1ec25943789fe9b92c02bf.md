You now have your old key pair as well as a new one that I named elizabeth-control to note that it's my key on the Controller node. If you wish to use your own key, you can adjust the --public-key to point to the key you want to load. If you make a mistake, you can use openstack keypair delete to delete an unwanted key pair.

Next we'll add port 443 to our default security group.

```
```
$ openstack security group rule create --proto tcp --src-ip 0.0.0.0/0 --dst-port 443:443 default
