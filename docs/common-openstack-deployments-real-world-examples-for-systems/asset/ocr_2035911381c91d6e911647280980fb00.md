# ## Magnum Concepts

As you can see from Figure 11.2, Magnum has a concept of “Bays” where a specific COE is run from. Beyond Bays, Magnum also has the concept of container and node for all of their containers, and additional ones for Kubernetes. Loosely speaking, you have the following concepts:

+   - **Container**: The container running your process.
+   - **Node**: A member of a bay, this is the bare metal or virtual machine where work actually executes.
+   - **Bay**: A collection of node objects where work is scheduled, this is where your COE lives.

Figure 11.3 illustrates the relationships among the three concepts.
More support is being added regularly. If you’re using Kubernetes, for example, you will also have the concept of a Pod, which is a collection of containers running on one physical or virtual machine that, as a layer, sits between your containers and nodes and can also support a replication controller.
