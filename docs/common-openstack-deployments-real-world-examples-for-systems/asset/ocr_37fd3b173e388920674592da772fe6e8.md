# ### Using an Object

Whether you used the Horizon dashboard or OSC to create your objects, you’ll now want to actually use that object. The first step will be making sure your container is public, and then you’ll want to figure out the address for a particular file in it. In the dashboard, navigate to Object Store, Containers to view the zoo container you created earlier. Click zoo and make sure there is a check mark next to Public Access as shown in Figure 9.8.

Now click the Public Access link, which should bring you to a URL that looks something like the following:

```
http://10.190.0.8:8080/v1/KEY_33a65b0402b047c097d21864b72c06be/zoo
```

The 10.190.0.8 is the address of the server where your Swift proxy server daemon is running. Since both the dashboard and Swift (specifically, the Swift proxy server) are running on the controller in our scenario, this is the same address as your dashboard.
