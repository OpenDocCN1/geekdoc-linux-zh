# # Summary

We have just completed a tour of the key components of OpenStack. It’s unlikely that you’ll remember all of the service names when you’re just starting out, so you can refer back to refresh your memory about the key daemons, plug-ins, agents and other components that support each component. In subsequent chapters we explore many of these in more depth.

OpenStack is an ever-expanding ecosystem of projects, so you are also now familiar with the location of all projects governed by the OpenStack Technical Committee and can explore other projects there. Finally, we’ve covered the support model for the LTS versions of Ubuntu with various versions of OpenStack by way of the Ubuntu Cloud Archive.
