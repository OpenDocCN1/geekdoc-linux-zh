**itotal**

The total number of inodes in the filesystem.

**iused**

The number of used inodes in the filesystem.

**iavail**

The number of available inodes in the filesystem.

**ipcent**

The percentage of used inodes in the filesystem.

# ## Maintaining ext2, ext3 and ext4 Filesystems

To check a filesystem for errors (and hopefully fix them), Linux provides the f `sck` utility (think of “filesystem check” and you will never forget the name). In its most basic form, you can invoke it with f `sck` followed by the filesystem’s location you want to check:

```
# fsck /dev/sdb1
fsck from util-linux 2.33.1
e2fsck 1.44.6 (5-Mar-2019)
DT_2GB: clean, 20/121920 files, 369880/487680 blocks
```

> > **WARNING**  NEVER run f `sck` (or related utilities) on a mounted filesystem. If this is done anyway, data may be lost.
