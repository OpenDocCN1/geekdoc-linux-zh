## 我如何控制要打印的文件份数？

使用 -n 选项。当你需要多于一份时，只需在命令行上加上数字：

```
lp -n 3 notes
```

上述命令将为你提供 notes 的三份副本。Berkeley 使用 #n，其中 n 是你想要的数量。

## UNIX 打印的特殊性

由于 UNIX 被设计为多用户和多任务环境，早期的设计者意识到他们需要一种方法让人们在打印进行时仍能继续在系统上工作。打印是一个缓慢的过程，即使在最快的打印机上也是如此，而且它并不需要太多原始的处理能力。让所有人等待打印机完成其工作将是严重的时间和资源浪费。因此 UNIX 借鉴了大型机世界，将所有打印任务或“作业”发送到排队程序。打印排队程序是一个后台任务，即守护进程，始终存在，等待执行任务。当你将作业发送到打印机时，你实际上是将其发送到打印机守护进程，后者首先将其存储在硬盘上的临时文件中，然后一点一点地将其发送到打印机。这样，你（以及系统上的其他用户）可以继续你的工作，而打印排队程序在不占用主处理器资源的情况下打印你的作业，因为排队程序只需要极少的可用的处理器时间即可完成其工作。

如果一切顺利，你在 WordPerfect 中点击打印按钮，选择要发送更新简历的打印机，然后发送出去。等你走到打印机旁时，作业已经出来了，你在别人看到之前就拿走了它。没问题。

但等等，有人已在该打印机上启动了一个打印作业，完成需要一个小时，而你的打印作业被卡在它后面！嗯。你认为你的老板会介意你只是待在打印机旁边吗？是时候弄清楚如何处理这个问题，以及在共享打印环境中出现的许多其他小问题了。

## 有没有办法让 UNIX 在我的打印作业完成后通知我？

当然可以。让打印排队程序在作业完成后向你发送消息。使用以下命令：

```
lp -m notes
```

这将在作业完成后向你发送邮件消息。使用 -w 可使其在作业完成后直接将消息写入你的终端。使用此选项时请谨慎。许多程序不喜欢在运行时将消息转储到终端。如果你在作业完成时未登录，则消息会被发送邮件。对于 Berkeley 用户，选项相同：-m。

## 我可以控制我的打印作业的外观吗？

当然可以。每种打印机类型或型号都将有一份它支持的可能选项列表。这些范围从点阵打印机可用的相当简单的选项，到典型激光打印机的更复杂的选项。你可以在命令行中添加任意多个选项；只需记住每个选项都需要前面加上 -o。UNIX 系统上的打印由一个脚本控制，该脚本知道特定打印机支持的选项，以及设置每个选项所需的转义序列。此脚本文件可由系统管理员修改，以为单个打印机添加特殊特性，通常位于 /usr/spool/lp/model 目录中。要查看你的打印机支持哪些选项，你可以打印此文件。但通常，这些包括控制字符间距和字体类型，以及打印质量和方向的选项。例如，在典型的点阵打印机上，选项可能包括使用精英体或压缩字体，以及是否以草稿模式或近似信件质量打印。在典型的激光打印机上，这些选项可能包括更改字体的能力，甚至使用不同字体墨盒或纸盘的设置。打印机支持的质量将取决于多种因素，包括 UNIX 修订版本的最新程度。
