# chmod mode files

OBJECTIVE:
Changes the mode of files. A file's mode controls the permissions for access associated with that file. Only the owner of a file (or the superuser) can change its mode.

# OPTIONS AND VARIABLES

Who

+   u User
+   g Group
+   o Others
+   a All (default)

Opcode

+   + Add permission
+   - Remove permission
+   = Set permission to be only what's specified
