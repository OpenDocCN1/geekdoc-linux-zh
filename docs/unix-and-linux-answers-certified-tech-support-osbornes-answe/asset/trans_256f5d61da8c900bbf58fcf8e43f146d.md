

## UNIX 文件系统和目录结构

只要你知道（或能猜到）程序的确切名称，就可以在目录内找到它。

### 什么是 UNIX 目录以及它与其他（子）目录的关系？

UNIX 与几乎所有主要操作系统一样，使用的是所谓的层次目录结构。这有时也被称为树形结构，但在任何名称下，它都是当今大多数操作系统的相同基本结构。有一个“根”目录，在其下有一系列子目录。每个子目录之下又可以有多个子目录，而这些子目录之下又可以有多个子目录，依此类推。这种结构可以有多深取决于 UNIX 的具体版本，但在几乎所有情况下，其深度都足够让你永远不必担心层级用完。

那么什么是目录呢？实际上，它只是一个文件，其中保存了其内部文件和子目录的名称，以及每个文件或目录的 inode 编号。（想知道 inode 是什么？请参阅下面的“真的需要理解 inode 吗？”）

### 什么是 .（点）和 ..（点点）？

这是两个特殊的目录名，使移动变得更容易。点目录是你的当前目录，而点点目录则是你所在位置的上级目录。因此，如果你与一群人合作一个项目，并且将文档文件存储在一个目录中，源代码文件存储在另一个目录中，头文件存储在第三个目录中，等等，使用绝对路径名切换到文档目录会很麻烦。你真的每次都想输入

```
cd /usr/projects/newmodel/docs
```

来更新你刚刚修改的头文件（位于 /usr/projects/newmodel/headers）的文档吗？几乎不可能。因此，要切换到文档目录，只需输入：

```
cd ../docs
```

### 我真的需要理解 inode 吗？

值得庆幸的是，不需要。inode（发音为“EYE-node”）是 UNIX 用于跟踪系统中每个文件位置的数据结构，以及其他重要信息，如其权限、所有权、时间戳等。在这种意义上，它有点（但不是很多）像 DOS 磁盘上的 FAT 表。你可以通过使用带 -i 开关的 ls 命令来查看与文件关联的 inode 编号：

```
$ ls -il
total 4
441315 -rwxr-xr-x 1 crussel users 884 Jan 30 14:47
stanley.cat
```

这对你作为用户意味着什么？没什么。毕竟，我们确实暗示你可以忽略这一节。这是那些被称为系统管理员的神秘人物的领域——那些戴着口袋保护套并带着受迫害表情的人。

### UNIX 文件系统是如何工作的？

如果你对这个主题不感兴趣，可以随意跳过这一节，但对于好奇的人来说，这里就开始了。UNIX 对文件系统的概念与典型的 DOS 甚至 Macintosh 用户所期望的有很大不同。每个 UNIX 机器都必须有一个“根”文件系统，它类似于 DOS 机器上的“C:”驱动器，但 UNIX 与其他文件系统之间的相似之处到此为止。不是为每块新增的硬盘分配额外的驱动器号，而是每块硬盘都有自己的文件系统，然后“挂载”到根文件系统上。因此，在一个拥有大量用户和大量商业程序的大型系统中，你很可能拥有，例如，根文件系统和一个包含所有用户主目录的“/u”文件系统，以及另一个包含大多数商业程序的“/usr”文件系统。而且，如果你在一个分布式工作站环境中工作（而不是一个大型中央服务器），/u 文件系统实际上可能在你登录的任何机器上都相同。在其中一台机器上，它物理上位于该机箱中，但在所有其他机器上，它是远程挂载的。这种设置允许你使用任何可用的工作站，而不必担心它是哪一台。你的主目录始终完全相同。

### 什么是主目录？

这是每个 UNIX 计算机上的每个用户都拥有的、属于他或她自己的目录。对于用户“charlie”来说，这个目录可能是 /u/charlie，或 /users/charlie，或 /home/charlie，或文件系统中的其他几个位置之一，具体取决于 UNIX 的版本和你系统上超级用户的偏好。但结果是一样的——它属于你。你在其中创建的文件和目录归你所有，只有在得到你的许可后，其他人才可以更改和使用它们。总是有一个前提条件，那就是没有任何东西能对超级用户隐藏。

### 典型用户的主目录包含哪些子目录，这些子目录中有哪些文件？

你的主目录是你存储控制环境的文件、启动文件的地方，通常还包括你随着时间推移创建的各种杂乱文件。在这种意义上，它有点像你招待客人时把所有东西都扔进去的壁橱。这使得很难分辨哪个文件是哪个，或者找到你现在绝对需要的那个文件。所以做一点整理。每个用户都应该有几个子目录来分类特定类型的文件，然后使用它们。例如，我的主目录有以下子目录：

- bin 可执行程序和脚本放在这里
- docs 通用的 WordPerfect 文件放在这里
- notes 用于我自己的快速笔记的地方
- wrksheet 电子表格文件放在这里
- source 位于 bin 中的各种可执行程序的源文件
- tmp 临时文件存放处
