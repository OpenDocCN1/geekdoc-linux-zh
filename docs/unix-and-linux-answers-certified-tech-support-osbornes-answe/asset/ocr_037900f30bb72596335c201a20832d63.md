In the above aliases, the ^[ is the escape character. You can enter this by pressing CTRL-V and then ESC. Now, if you want a little blue screen with white text, just type echo blue. You could have included the echo as part of the alias, of course, but this would make the alias less useful. By doing it this way, with the -x parameter to alias, the "blue" is available from within your scripts. This is especially useful for using the revrs and norm aliases for highlighting text.
