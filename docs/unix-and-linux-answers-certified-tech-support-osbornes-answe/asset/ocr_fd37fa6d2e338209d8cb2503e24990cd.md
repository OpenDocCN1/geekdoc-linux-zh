when you go to print the document or view it without setting
its tame, everything gets jumbled up as in Figure 6-4.

Well, here's a simple little shell script to convert tabs to
spaces, lined up with the tabstops every three spaces. You
could spruce this one up to have a variable number of spaces
for your tabstops, add error checking, whatever. It works and
it's simple.

```
### File ~/bin/detab -- removes tabs from a file and
                         converts to spaces
### File name remains the same.
pr -t -e3 $1 > /tmp/tabtmp
cp /tmp/tabtmp $1
```
