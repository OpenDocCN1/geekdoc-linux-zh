# Can you point out some of the differences between awk and perl?

In this section we’ll take the two scripts that we created for awk and "port" them to perl. The end results are the same of course, but you’ll be able to see where the two programs differ.

We’ll bypass the command-line version of the line-counting program and go straight to the version with the minimalist shell wrapper around it. Except now instead of running the awk program, this will run the perl program. Normally, you would have the line

```
#!/usr/bin/perl
```

as the first line of your perl scripts, but ours is in an unusual place, so our first line reads:

```
#!/work/bin/perl
```

The results are the same, however. This line tells the shell program that its sole job is to execute the perl program and just pass the statements in the file directly to perl to deal with.
