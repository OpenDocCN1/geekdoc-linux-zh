## 表13-2 Korn shell中的逻辑或关系运算符

> **警告：** Korn shell只进行整数算术运算。你可以使用浮点数，它会在不报错的情况下接受它们，但它会截断它们，因此你可能得不到预期的答案！例如，考虑以下情况：
> 
> (( 7.2 / 1.8 ))
> 
> 你可能期望它计算为4。但在Korn shell中，答案实际上是7，因为实际计算的是“7除以1的整数除法”。
> 
> 尽管整个表达式都被括在双括号中，你仍然可以在表达式内部使用额外的括号来控制优先级顺序。例如，要计算7乘以(2+4)除以3的结果，你可以使用
> 
> (( 7 * ( (2+4)/3 ) ))
> 
> 请注意，我们在此行中添加的额外空白并不重要。不过，我们发现它使这行内容更容易阅读。

## 字符串运算符

Korn shell特别擅长处理的字符串操作示例是什么？

拼接。要在UNIX中拼接两个字符串，只需将它们放在一起，中间没有空白。如果需要包含空白，将整个内容用引号括起来就可以解决这个问题。如图13-1所示，我们在其中编造了一些示例用于演示。

大多数情况下，我们使用简单的“$strvar”来引用我们创建的字符串变量，其中strvar就是变量。但这实际上是一般语法“${strvar}”的一个特例，该语法在所有情况下都有效。例如，你可以用$9来引用传入脚本的第九个位置参数，一切正常，但你不能用$10来引用。要引用第十个（及以后）位置参数，你需要使用${10}语法来更正式地引用。

## Korn shell是否提供了有用的字符串替换运算符？

是的。这些运算符允许你检查字符串的值，然后替换该值、使用默认值或退出脚本。表13-3显示了这些可能性。
你可以使用这些运算符来检查一个变量是否已被设置，然后根据该测试的结果执行相应的操作。

> 警告：你不能使用${str:=expression}语法来为位置参数赋值。你必须使用一个中间局部变量来完成这项工作。这是Korn shell中的一个令人烦恼之处，我们还没有看到对此好的解释或理由。

| 运算符 | 替换行为 |
|---|---|
| ${str:=expression} | 如果str未设置或为空，则返回expression，同时将expression赋值给str。如果str有值，则返回该值。 |
| ${str:-expression} | 如果str未设置或为空，则返回expression，但不改变str。如果str有值，则返回该值。 |
| ${str:+expression} | 如果str未设置或为空，则返回空值。如果str有值，则返回expression。 |
| ${str:?expression} | 如果str未设置或为空，则将expression的值发送到标准错误，并中止当前命令或脚本。如果str有值，则返回该值。 |
| ${str#pattern} | 如果pattern匹配str的开头，则返回删除了最小匹配部分后的str；否则返回未改变的str。 |
| ${str##pattern} | 如果pattern匹配str的开头，则返回删除了最大匹配部分后的str；否则返回未改变的str。 |
| ${str%pattern} | 如果pattern匹配str的结尾，则返回删除了最小匹配部分后的str；否则返回未改变的str。 |
| ${str%%pattern} | 如果pattern匹配str的结尾，则返回删除了最大匹配部分后的str；否则返回未改变的str。 |
