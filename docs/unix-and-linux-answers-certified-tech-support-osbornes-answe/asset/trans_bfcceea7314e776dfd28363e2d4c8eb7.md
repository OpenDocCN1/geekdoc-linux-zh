## 附录 C

### 术语表

**绝对路径名** 文件的完整名称，包括显示文件在目录树中位置的完整目录路径。绝对路径名以根目录 / 开头。

**地址** 可以是特定机器的名称，也可以是整个 UNIX 系统的名称。电子邮件和通信讨论中会用到这两种含义。

**AIX** IBM 公司制作的一个 UNIX 版本。

**匿名 ftp** 一种不需要密码的远程登录。你输入 **anonymous** 作为用户名，以你的电子邮件地址作为密码，从而可以将文件从另一台计算机复制到你自己的计算机。

**归档文件** 包含其他文件集合的文件。主要用于备份。

**参数** 在命令行中，参数是跟在命令后面的内容。例如，在一行 **cp my.file your.file** 中，命令是 **cp**，**my.file** 是第一个参数，**your.file** 是第二个参数。

**ASCII** 美国信息交换标准代码。通常指文本格式的文件，因此可查看、可打印，且不含二进制（非 ASCII）字符。

**at** 允许你安排任务在未来运行的命令。

**awk** 一种面向文本处理的编程语言。

**后台** 在幕后运行、无需你输入的程序即是在后台运行。可以通过在命令行末尾加上 &（与号）来启动命令，使其在后台运行。

**反斜杠** 字符 \\。在 UNIX 中，它改变（“转义”）下一个字符的解释。

**感叹号** 字符 !。shell 转义字符。也用于表示该命令无论如何都应执行。

**伯克利软件发行版** BSD UNIX 的完整名称，由加州大学伯克利分校开发和发行的一个 UNIX 版本。该版本以其先进的网络功能而著称。

**bin 目录** 用于存储可执行文件的目录。你的主目录中可能有一个名为 bin 的子目录。

**块大小** UNIX 文件系统始终连续分配的最大数据量。换句话说，小于块大小的文件将始终是连续的。较大的文件可能会碎片化。

**Bourne shell** 最初的 shell。由贝尔实验室的史蒂文·伯恩（Steven Bourne）创建。其程序名为 **sh**，提示符为 $。

**BSD** 参见 **伯克利软件发行版**。

**缓冲区** 一种临时存储区域，例如文件或计算机内存中的一块区域。许多东西都有缓冲区，包括打印机和许多文本编辑器。

**C, C++** C 是几乎所有 UNIX 程序的编写语言。UNIX 本身也大部分由 C 编写。C 及其增强版 C++ 均在贝尔实验室开发，并被 UNIX 程序员广泛使用。

**C Shell** 一种尽可能模仿 C 编程语言编写的 shell。它使用 % 作为提示符，其程序名为 csh。

**客户端** 在 X Window 系统中，客户端是应用程序，与管理系统资源并提供显示的服务器相对。在分布式文件系统中，客户端是连接到服务器的终端或工作站。

**命令行** 你在 shell 提示符下键入的文本。一条命令行可以包含一个以上的命令，这些命令相互分隔。
