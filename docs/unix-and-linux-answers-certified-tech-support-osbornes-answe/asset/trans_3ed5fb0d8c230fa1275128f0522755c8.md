
## 当前打印与稍后打印

大多数打印都是这样进行的：完成文档编辑后，你想要将其打印出来。如果你在应用程序（如 WordPerfect 或 IslandCalc 等）中工作，只需按照该程序的相应命令打印文档。指定目标位置，然后在完成时去取输出即可。

在共享打印机环境中工作的一个问题在于，你并不总能按自己的意愿使用打印机，因为这样可能会严重干扰系统上的其他用户。一个典型的例子是大型打印作业，它们可能会长时间占用打印机。多长时间算长？这实际上取决于具体环境。如果你与三四个其他用户共享一台打印机，并且事先征得同意，那么花半小时甚至一小时完成的打印作业或许还能接受。但如果是在一台由25或30个用户共享的集中式打印机上这么做，恐怕会招来一片抱怨。根据系统设置方式，有几种方法可以处理这个问题。也许最简单的办法是在晚上离开时把打印作业发出去，作为当天最后一件事。如果这不可行，下面是一些维持和平的建议。

## 稍后打印

### 有没有命令可以让我稍后再打印作业？

可以。使用 hold 选项可以让文件准备好打印，但不会立即开始，而是等到稍后。如果在打印那个大型作业时使用了 hold 选项，它会一直处于保持状态，直到你告诉它真正发送到打印机。不过，在此期间，它已经被送入假脱机程序（spooler），一切就绪并等待。然后，当打印机在较长一段时间内空闲时，你就可以启动它。要将文件 bigdocument 打印到打印机 netlaser，但先保持直到你发出指示，可以这样尝试：

```
lp -dnetlaser -H hold -m bigdocument
```

然后，当你想开始打印时，使用

```
lp -i requestid -H resume
```

这仍然需要你在一定程度上进行规划和留意，但至少你知道一切已准备就绪并可随时启动。它还有第二个问题：你需要知道要恢复的作业的 requestid。正如你在图 6-1 中看到的，当你首次发出打印命令时，系统会告知你 requestid，所以请把它记下来，并希望在恢复作业时，你还能找到你记在哪里。

### 我如何查看打印作业的状态？

使用 lpstat 命令。该命令会告诉你各种信息。在其最简单的形式下（不带选项），它会告诉你哪些作业在哪些打印机队列中。使用 -u 选项仅显示与你作业相关的信息。（在 HPUX 中，需要使用 -t 选项来显示打印机和作业的状态。）

### 我可以安排稍后打印作业吗？

当然可以。如果系统管理员已授权，你可以使用 at 命令将打印作业安排到稍后执行。我们将在第 7 章更详细地讨论 at 命令，但目前这里有一个简单的示例，用于在下午 5:30 运行一系列打印命令。

```
at 05:30pm < commandfile
```

## 格式化

### UNIX 为我提供了哪些基本格式化选项？

内置的 `pr` 实用程序可以轻松处理各种小型的格式化任务。它可以处理多栏输出、设置制表位、对文件进行双倍行距调整、添加左边距、将制表符展开为空格或将空格转换回制表符，或者为文件添加行号。这里讨论的不是桌面出版，但对于简单任务来说，它快速且容易。

### 使用 UNIX 进行格式化

如果你希望从 UNIX 输出的打印作业不再是平淡无奇的默认 Courier 字体，你就需要采取一些步骤来实现。你*可以*去购买高价位的文字处理器，甚至更高价位的桌面出版软件包，确实有一些优秀的这类程序能在大多数 UNIX 平台上运行。如果你打算进行大量复杂的格式化，并希望在真正打印之前看到文档的外观，那么你很可能需要这些程序之一。但如果你只是想让输出稍微美观一点，或者需要包含一个公式或图形，那么你真的只需要使用系统上可能已有的工具即可。如果你习惯于直接输入命令来以粗体、双倍行距打印，并且相信打印之前无需看到实际效果也会按预期运行，那么你完全可以使用 UNIX 原生工具出版整本书。
