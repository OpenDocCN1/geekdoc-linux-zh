A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

READ through the installation documentation **before you start the process**. Don't be in a hurry. If you want to learn Linux, you will have to be willing to read. For Slack, have a look through the installation chapters of the updated "Slack Book" located at
http://www.slackbook.org/beta. There are detailed instructions if you need step by step help, including partitioning, etc. For a basic understanding of how Slack works and how to use it, the Slack Book should be your first step. Some of it may be a bit outdated, but the majority of it still applies.

Here's some installation advice. Read this, then read the *Installation* section in the Slack Book linked above. As a very general overview:

+   1) Boot the Linux media.
    * Read each screen carefully.
    * Accepting most works.
    * Your hardware will be detected and configured under most circumstances. Online support is extensive if you have problems.
    * Keep in mind that if a piece of hardware causes problems during an install, or is not detected during installation, this does not mean it will not work. Install the operating system and spend some time troubleshooting. When learning Linux, Google is your best friend.
    * The Slack installation for the current version will boot by default using a kernel called huge. It includes support for most hardware. Hit the "F2" key at the initial "boot" prompt for more info.
    * Once the system is booted, you are presented with the keyboard map prompt followed by the "slack login" prompt. READ THE ENTIRE SCREEN as instructed. Login as root, and continue with your install routine.

+   2) Partition and format for Linux
    * You will partition your Slack Linux system using **fdisk or gdisk** (if you prefer a GPT layout).
    * This step is normal part of the installation process, or created in the distribution's documentation. You can partition however you like. I like to have, at least, two partitions
    * Root (/) as type "Linux Native"
    * Swap as type "Linux swap (use 2x system memory as a starting point for swap). The size of a swap partition is largely optional for machines with large amounts of RAM (>3GB). I still opt to use it.
    * You will hear a lot about using multiple partitions for different directories. Don't let that confuse you. There are arguments for and against using multiple partitions for a Linux file system. If you are just starting, use one large root (/) and one swap partition as described above.

+   3) Package installation (system)
    * The main install routine forer is started with the command **setup**. You will need to ensure that you have your disk properly partitioned **before** you enter the setup program.
    * Take the time to read each screen completely as it comes up.
