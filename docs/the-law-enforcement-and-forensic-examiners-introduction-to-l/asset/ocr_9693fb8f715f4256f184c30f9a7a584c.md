Once mounted, we can see the results from the terminal using the mount command:

```
root@forensic1:~# mount
/dev/sda1 on / type ext4 (rw)
proc on /proc type proc (rw)
sysfs on /sys type sysfs (rw)
tmpfs on /dev/shm type tmpfs (rw)
/dev/sdb1 on /run/media/berry/Win10Image type ext4(rw,nodev,nosuid,helper=udisks2)
```

Make sure you know how to control the mounting of disks and volumes within your desktop environment. The XFCE shipped with Slackware does no auto-mounting of any volumes. The icons appear on the desktop, but you are free to mount them as you see fit. There are configuration options available to change this behavior, so be careful (see Illustration 1).
