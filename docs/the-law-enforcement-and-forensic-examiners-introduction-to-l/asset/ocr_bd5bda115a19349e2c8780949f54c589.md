We've already converted similar dates using the python WinTime.py script. Could type each value on the command line, and run the script separately for each value. A better way, however, would be to use the command to give us a bash for loop. We just want the value, and pass one to the WinTime.py script. If you read the main page for xxd, you will see that we can also use different options for xxd to enable us to complete the date conversion without having to copy the hex value out.

Let's look at what happens when we run xxd with -ps (plain hexdump) -s8 (seek to byte 8) -l8 (output is truncated for readability "file" we are viewing):

```
barry@forensic1:~$../000003E8/(values)$ xxd -ps -s8 -l8 F
678e5df7f7c1d21
```

We find the date extracted is exactly the format we need to pass to WinTime.py. To order the output, we'll use command substitution. This is done by using the back-tick (` `) symbols around the xxd command. This substitutes the output of xxd straight to the argument required for WinTime.py:

```
barry@forensic1:~/000003E8/(values)$ python ~/WinTime.py `xxd -ps -s8 -l8 F`
Sun Apr 30 21:23:09 2017
```

This can be taken step further. We have three separate date values to convert here. One is offset 8 (-s8 as we converted). The others are at offset 24 and 40. Sounds like a perfect candidate for our familiar bash for loop. We can use offsets 8, 24 and 40 as our variable, and pass those into our command substitution for WinTime.py. It should look something like this:

```
barry@forensic1:~/000003E8/(values)$ for offset 8 24 40
> do
> python ~/WinTime.py `xxd -ps -s$offset -l8 F`
> done
Sun Apr 30 21:23:09 2017
Thu Apr 6 01:35:34 2017
Sun Apr 30 21:23:01 2017
```
