If you are unsure where to start, will be using this guide as your primary reference, and are interested in forensic applications of Linux, then I would suggest Slackware. The original commercial distribution, Slackware has been around for years and provides a good Standard Linux that remains true to the Unix philosophy. Not-encumbered by GUI configuration tools, Slackware aims to produce the "Unix-like" Linux distribution available. One of my personal favorites, and in my humble opinion, one of the best for a forensic platform. (http://www.slackware.com/). This guide is tailored for you with a Slackware installation.

One to keep in mind: As mentioned earlier, if you are going to use Linux in a forensic capacity, then not to rely on GUI tools too. Most settings and configurations in Linux are maintained in text files (usually in your home directory, or /etc). By learning to edit the files you avoid problems when the X Window system is not available, or when the specific GUI tool you rely on is not on a system you might come across. In addition, knowledge of the text configuration files will give you insight into what is "normal", and what might have been changed when you examine a subject Linux system (though that is not the focus of this document). Learning to interpret configuration files is all part of the experience.

# SLACK and Using this Guide

Because of differences in architecture, the Linux distribution of your choice can cause different results in commands' output and different behavior. Additionally, some sections of this document describing configuration files, startup scripts or software installation, for example, might appear vastly different depending on the distro you select.

If you are selecting a Linux distribution for the sole purpose of learning along with this document, then I would suggest Slackware. Slackware is stable and does not attempt to enrich the user's experience with cutting edge file system hacks or automatic configurations that might hamper forensic work. Detailed sections of this guide on the inner workings of Linux will be written towards a basic Slackware 14.2 64 bit installation (current of this writing).

By default, Slackware's current installation routine leaves disk partitioning to the user. There are no default schemes that result in surprising "volume groups" or other complex disk management techniques. The resulting file system table (also known as fstab) is standard and not requiring edit to provide for a forensically sound environment.
