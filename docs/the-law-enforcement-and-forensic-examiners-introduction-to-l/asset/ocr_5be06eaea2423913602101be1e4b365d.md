# Where's the GUI tools?

As much as possible, the tools represented in this guide are callable and require user interaction through the command line environment. This is not simple sadness. It's a matter of actually learning Linux (and in some ways UNIX is a by-product). This point will be made throughout this document, the goal here is to introduce tools and how to interact through the command line. Reliance on GUI tools is understandable and not being wholly disparaged. If you are making the effort to read and follow along with this guide, then any assumption is being made that you want to learn Linux and follow the command line brings. There are two main points that we can focus on:

The first is that Linux (and UNIX) find their foundation at the command line. Modern Linux and UNIX implementations are still, at their hearts, by system that is accessible from a command line interface. For this, knowing how to interact with the command line provides the widest range of capabilities regardless of the distribution or configuration of Linux encountered. Yes, this is also for forensic tools, but it's also about becoming comfortable with Linux. It is for reason that we continue to learn a command line editor like vi and simple bit copying tools like dd. There's a high probability that any Linux/Unix system you come across have these tools.

Second is that knowing and understanding the command line is, and of itself, a powerful tool. Once you realize the power of command pipes and flow control (using directly on the command line), you will find yourself able to power through problems faster than you previously thought. Learning the proper use and power of utilities like awk, sed, and grep will provide some basic understanding of how those can be used. Once you understand and start to leverage this power, you will find yourself pining for a command line and its utilities when one is not available.

Keep these points in mind as you go through the exercises. Understand why and how the tools work. Don't memorize the commands themselves. That would miss the point.
