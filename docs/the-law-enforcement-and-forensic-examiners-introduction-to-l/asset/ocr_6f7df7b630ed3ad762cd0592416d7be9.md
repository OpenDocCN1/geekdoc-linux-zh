# III. The Linux Boot Sequence (Simplified)

**Booting the kernel**

The first step in the (simplified) boot sequence for Linux is loading the kernel. The kernel image is usually contained in the /boot directory. It can go by several different names... (this can vary greatly by)

+   - bImage
- vmlinuz

Sometimes the kernel image will specify the kernel version contained in the image, i.e. vmlinuz-huge-4.4.19 Very often there a soft link (like a shortcut) to the most current kernel image in the /boot directory. It is normally this link is referenced by the boot loader, LILO (or GRUB). In a Slackware system, the kernel image is /boot/vmlinuz.

Note that Slack uses LILO by default. LILO is an older and simpler system for booting, but is much less flexible.

The boot loader specifies the "root device" (boot drive), along with the kernel version to be booted. This is all controlled by the file /etc/lilo.conf. Each "image=" section represents a choice in the boot sequence.

This is an example of a lilo.conf file:

```
root@conf1:~# cat /etc/lilo.conf
append+=vt.default_utf8=0
boot = /dev/sda
bitmap = /boot/slack.bmp
bmp-colors = 255,0,255,0,255,0
bmp-table = 60,6,1,16
bmp-timer = 65,27,1,6
prompt
timeout = 1200
change-rules
reset
vga = normal
image = /boot/vmlinuz
root = /dev/sda1
label = Linux
read-only
```
