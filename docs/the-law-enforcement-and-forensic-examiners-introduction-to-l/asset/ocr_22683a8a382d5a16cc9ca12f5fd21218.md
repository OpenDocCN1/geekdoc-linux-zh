```
bar@forensic1:~$ echo hello
hello
bar@forensic1:~$ echo hello > wc
bar@forensic1:~$ cat wc
hello
bar@forensic1:~$ echo hello | wc
1 1 6
bar@forensic1:~$ echo hello | wc > outfile.txt
bar@forensic1:~$ cat outfile.txt
1 1 6
```

This is an extremely powerful tool for the command line. Look at the following process list (partial output shown):

```
bar@forensic1:~$ ps ax
PID TTY STAT TIME COMMAND
1 ? S 0:00 init [4]
2 ? S 0:00 [kthread]
3 ? S 0:00 [ksoftirqd/0H]
5 ? S< 0:00 [kworker/0:0H]
6 ? S 0:00 [kworker/u4:0]
7 ? S 0:00 [rcu_sched]
<continues>
```

What if all you wanted to see were those processes ID's that indicated bash? You could `pipe` the output of `ps` to the input of `grep`, specifying bash as the pattern for `grep` to search. The result would give you only the lines of the output from `ps` that contained the pattern bash.

```
bar@forensic1:~$ ps ax | grep bash
1522 pts/0 S 0:00 bash
1714 pts/1 S 0:00 -bash
1729 pts/1 S+ 0:00 grep bash
```

There may be times where you want to see the output of a command displayed on the screen and have it redirect to a file as well. You can do that using the `tee` command.

```
bar@forensic1:~$ ls | tee filelist.txt
```
