The registry file NTUSER.285 is mounted using regfmount on the mount point we created, ntusermnt (in the current directory). When we change to the ntusermnt directory, we see the contents of the registry file in the same sort of hierarchical structure as would be found in any other registry. We can navigate and view using normal command line utilities. So let us navigate to the UserAsset key and view the contents.

barry@forensic1:/ntusermnt$ cd
Software/Microsoft/Windows/CurrentVersion/Explorer/UserAsset/

barry@forensic1:/ntusermnt/Software/Microsoft/Windows/CurrentVersion/Explorer/
UserAsset$ ls
{CEBFF5CD-ACE2-4F4F-9178-9926F41749EA}/
{F4E57C4B-2036-45F0-A9AB-443BCE33D9F}/

You can see once into that directory prompt is quite long! When we run our command, we see two cryptic looking directory (GUID) entries. Directory into {F4E57C4B-2036-45F0-A9AB-443BCE33D9F}32 and the directory Count/(values). Note that when you use the <values> sub directory, you will need to escape the parentheses with \. so you will use \(values).

barry@forensic1:/ntusermnt/Software/Microsoft/Windows/CurrentVersion/Explorer/
UserAsset$ {F4E57C4B-2036-45F0-A9AB-443BCE33D9F}

barry@forensic1:/ntusermnt/Software/Microsoft/Windows/CurrentVersion/Explorer/

barry@forensic1:/ntusermnt/Software/Microsoft/Windows/CurrentVersion/Explorer/
