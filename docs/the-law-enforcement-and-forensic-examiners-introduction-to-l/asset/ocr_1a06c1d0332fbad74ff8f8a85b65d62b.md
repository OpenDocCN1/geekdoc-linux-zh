# v.4.33 A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

Check the contents of the tar archive (tar tzvf), untar the files (tar xzvf),
change into the able_3 directory by cd. You can skip all of this if you already have the
able_3 directory from your previous exercise. Just change into the directory.

```
barry@forensic1:-$ tar tzvf able_tar.gz
drwxr-xr-x barry/users 2017-05-25 12:13 able_3/able_3.0000
--rw-r--r barry/users 1073741824 2017-05-25 12:13 able_3/able_3.0001
--rw-r--r barry/users 1339 2017-05-25 12:14 able_3/able_3.log
--rw-r--r barry/users 1073741824 2017-05-25 12:14 able_3/able_3.0003
--rw-r--r barry/users 1073741824 2017-05-25 12:14 able_3/able_3.0002
```

```
barry@forensic1:-$ tar xzvf able_3.tar.gz
able_3/able_3.0000
able_3/able_3.0001
able_3/able_3.log
able_3/able_3.0003
able_3/able_3.0002
barry@forensic1:-$ cd able_3
```
