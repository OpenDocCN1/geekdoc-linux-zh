We will start by running with a series of Sleuth Kit commands as we would be in any analysis. The structure of the forensic image is viewed using mmls:

```
barry@forensic1:-~/NTFS_Pract_2017$ mmls NTFS_Pract_2017.E01
DOS Partition Table
Offset Sector: 0
Units are in 512-byte sectors
```

The output shows that an NTFS partition (the most likely the file system) begins at sector offset 0048. The offset is what we will use in our Sleuth Kit commands. We now use fsstat to have look at the file system details inside that partition:

```
barry@forensic1:-~/NTFS_Pract_2017$ fsstat -o 2048 NTFS_Pract_2017.E01 | less
```
