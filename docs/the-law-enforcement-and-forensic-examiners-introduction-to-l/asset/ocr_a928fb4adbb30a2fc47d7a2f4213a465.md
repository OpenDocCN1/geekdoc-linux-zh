Now, in its most simple form, we can call gzip and simply provide the name of the file we compressed. This will replace the original file with a compressed file that has a .gz suffix appended.

```
root@forensic:~/testcomp# gzip NTFS_Pract_2017.raw

root@forensic:~/testcomp# ls -lh
total 61M
-rw-r--r-- 1 root 61M May 6 12:10 NTFS_Pract_2017.raw.gz
```

So now we have replaced our original 500M file with a 61M file that has a .gz extension. To decompress the resulting .gz file:

```
root@forensic:~/testcomp# gzip -d NTFS_Pract_2017.raw

root@forensic:~/testcomp# ls -lh
total 500M
-rw-r--r-- 1 root 500M May 6 12:10 NTFS_Pract_2017.raw
```

```
root@forensic:~/testcomp# shasum NTFS_Pract_2017.raw
094123df4792b18a1f64f1e26902869585 NTFS_Pract_2017.raw
```

We decompressed the file and replaced the .gz file with the original image. A check of the hash shows that all is in order.

Suppose we like to compress a file but leave the original intact. We can use the gzip command with the -c option. This writes to stdout instead of a replacement file. When using this option we need to redirect the output to a filename of our choosing here is a sample session using this technique:

```
root@forensic:~/testcomp# ls -lh
total 51M
-rw-r--r-- 1 root 500M May 6 12:10 NTFS_Pract_2017.raw
```

```
root@forensic:~/testcomp# gzip -c NTFS_Pract_2017.raw > NewImage.raw.gz

root@forensic:~/testcomp# ls -lh
total 51M
-rw-r--r-- 1 root 500M May 6 12:10 NTFS_Pract_2017.raw
-rw-r--r-- 1 root root 61M May 6 12:32 NewImage.raw.gz
```

```
root@forensic:~/testcomp# gzip -cd NewImage.raw.gz > NewUncompressed.raw
```
