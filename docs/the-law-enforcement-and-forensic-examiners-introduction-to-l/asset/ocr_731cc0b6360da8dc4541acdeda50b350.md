From the istat output we see that inode 10090 is unallocated (same as blkat told us about the data unit). Note also that the first direct block indicated by our istat output is 5184, just as we calculated.

We can get the data from the direct blocks of the original file using less -r. Pipe the output through less so that we can read it easier. Note that our keyword is right there at the top:
