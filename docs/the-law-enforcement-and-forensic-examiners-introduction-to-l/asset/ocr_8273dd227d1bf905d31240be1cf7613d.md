-r--r--r-- 1 root root 4.0G Dec 31 1969 able_3.000.raw

```
root@forensic1:/able# shaasum /mnt/aff/able_3.000.raw
2ddbfe3d00cc736172c320df88f61afda3502 /mnt/aff/able_3.000.raw
```

In the above session, we create a mount point for our fuse (the name here is arbitrary) with the mkdir command. We use affix with the first segment of our four part and mount it to /mnt/aff. aff creates our single virtual image for us in /mnt/aff and with the image name and the .raw extension. Finally, we check the hash of this new virtual image and it's the same as the hash for the input and output bytes (for the total disk) in our log file.

Now we can use gdisk or fdisk on the image to identify the partition layout of the disk; we can use parted to manage the partitions or we can recover the file systems for further investigation. All as we have learned in preceding sessions when working on complete images:
