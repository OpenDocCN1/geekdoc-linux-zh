# File Permissions

Files in Linux have certain specified permissions. These permissions can be viewed by running the ls -l on a directory or on a particular file. For example:

```
barry@forensic1:-$ ls -l myfile.sh
-rwxr-xr-x 1 barry 3685 Apr 15 11:14 myfile.sh
```

If you look at the first 10 characters, have a dash followed by 9 characters. The first character describes the type of file. A dash (-) indicates a regular file. A "d" would indicate a directory, or "b" a special block device, etc.

+   First character of ls -l:
= regular file
d = directory
b = block device (SCSI or IDE disk)
c = character device (serial port)
l = link (points to another file or directory)

The next 9 characters indicate the file permissions. These are given in groups of three:

| Owner Group Others |
| rwx rwx rwx |

+   The characters indicate
r = read
w = write
x = execute

So for the above myfile.sh we have
-rwx r-x r-x
