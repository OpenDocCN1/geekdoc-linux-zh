You can carve multiple images at once with the -i `<listfile>` option, and there are

In this case, we use an option that allows us to properly parse embedded files (-e).
This allows the proper pairing of headers and footers. Without the -o option, a header
followed by another header (with an embedded header), would result in both files sharing the
same footer.

Finally, we use the -o option to recover our carved files to a directory we are going to
`call_out` and the -o option so the output remains in a single output directory index
of categorized subdirectories. Having the files in single folders makes it easier.
