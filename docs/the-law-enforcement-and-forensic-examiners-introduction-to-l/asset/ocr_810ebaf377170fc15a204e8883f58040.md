While the access count at 0x04 is easy to decipher, the Windows date value is not. I use
a small python script to decode the time value (the number of 100 nanosecond blocks since
January 1, 2001). You can download the python script (winTime) using wget:

```
barry@forensic1:~.../Count/(values)$ wget http://www.linuxleo.com/Files/WinTime
0 ~/WinTime.py
```

Since we are currently in the ntermount point, it is best to use the wget -0
option to write the file to your home directory (~WinTime.py). You don't want to try and
download the file to the current directory (it's our fused registry point).

Once you have the script, you can copy the hex value and provide it as an argument to
WinTime.py. be sure to remove the spaces from the value (we'll use an alternative way of
getting this value from xxd later):

```
barry@forensic1:~.../Count/(values)$ python ~WinTime.py c03ac030f8bed201
Thu Apr 27 01:45:57 2017
```

If you did a full install of Slack, Python should already be on your system. Note
they python commands points to the WinTime.py we previously named with wget -
- indicates the file is in our home directory. This leaves us with a last execution time of
April 27 at approximately 01:45. A complete forensic education regarding registry entries,
interpreting dates and timezone adjustment is far outside the scope of this guide,
but make sure you take time settings, time zones and clock skew into account for any forensic
examination where dates are meaningful. Read file dates and time stamps are one of the pitfalls of
an. Read up on the subject complexity before making any interpretations.

Speaking of times, and how would we be finding the last write time of the
UserAssist sub key itself? We've been looking at and decoding key values, but the last
write time of a key is more akin to a property of the key itself. The registry file
mount through refmount, the keys and sub-keys act as directories. If you run the ls -l
command, you can see a date associated with the keys. Changes up to your script
working directory

/ntermount/Software/Microsoft/Windows/CurrentVersion/Explorer/. This would be
four levels, or to the parent directory [..] times. Then run ls -l:

```
barry@forensic1:/ntermount/Software/Microsoft/Windows/CurrentVersion/Explorer/
UserAssist/{F4E7C4B-2036-45F0-A9AB-443BCE33D9F}/Count/(values)$ cd ../...
$ ls -l
total 0
d-xr-xr-x 2 bary users 0 May 1 12:39 (values)/
```
