By sorting out, the duplicate hashes are listed here. From the output,
we can see that these two files are identical:

110983800a177c146c54b15edce98a photorec_out.1/f0012156.gif
110983800a177c146c54b15edce98a scalp_out2/00000000.jpg

This can be re-duplicated to a file for later processing.

```
barry@forensic1:-~/carve$ mdsum photorec_out.1/f0* scalp_out2/0* | sort >
carvehash.txt
```

Well, this. It might also be nice to actually de-duplicate the files by removing
one of the duplicates. Again, easy enough in our small sample here, but far more challenging
and time consuming if you are dealing with hundreds or thousands of contraband images
need to sort and accurately count.

For this we can use a program called fdupes. fdupes works using both filenames and
hashes to find, report, and if requested - remove duplicate files from specified directories.
It is easy to use and very effective.

```
barry@forensic1:-~/carve$ su
Password:
```

```
root@forensic1:~# sinstall fdupes
FDUP is a program for identifying or deleting duplicate files residing
within specified directories.
```
