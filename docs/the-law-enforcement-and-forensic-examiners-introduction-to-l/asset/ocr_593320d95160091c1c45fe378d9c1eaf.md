Another important when considering the file system is of relative explicit paths. When confusing at first, practice will make the idea second nature. Just remember that when you provide a path name to a command or file, including a “/” in front means an explicit path, and will define the location starting from the top level directory (root). Beginning a path name without “/” indicates that your path starts in the current directory and is referred to as a relative path. On this later.

One useful resource for this topic is the File System Hierarchy Standard (FHS), the purpose of which is to provide a reference for developers and system administrators on file and directory placement. Read more about it at http://www.pathname.com/fhs/
