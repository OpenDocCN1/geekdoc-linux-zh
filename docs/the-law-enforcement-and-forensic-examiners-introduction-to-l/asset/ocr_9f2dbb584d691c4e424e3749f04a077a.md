We can get a hash of every file on the disk using the **find** command and an option that allows us to execute a command on each file found. We can get a very useful list of SHA hashes for every file on our mount point by find to identify all *regular* files on the file system and run a hash on all those files:

```
barry@forensic:/mnt/evid5 find -type f -exec shashum {} \ \
~/analysis/sha.filelist.txt
```

```
barry@forensic:/mnt/evid5 cat ~/analysis/sha.filelist.txt
8608e288fe4a05f5c3dc7c40b3e7947afec11 /Docs/Benchmarks.xml
816e2f9f7633e85b891e250ed190228188 /Docs/Computer_Build.xml
```

We can then look at the hashes by using the **cat** command to stream the file to standard output (in this case, our terminal screen), as in the second command above.

You can also use Linux to verify your (or hash matching). To verify hashes using a hash list created with one of our hashing programs (**shashum, md5sum**, etc.), you can use the **-c** option. If the files match in the hash list, the command will return OK. Making sure you are in a directory where the relative paths in the list will target the correct files, using the following command:

```
barry@forensic:/mnt/evid5 shashum -c ~/analysis/sha.filelist.txt
```
