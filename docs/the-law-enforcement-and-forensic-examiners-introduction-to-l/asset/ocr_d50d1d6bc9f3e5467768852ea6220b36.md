So we use find (find the "inode", or meta-data structure) using -n to find name, the 2048 offset we again find in our NTFS file system by running mmls. The return value we get from find 285, the MFT entry for the Alberte's account NTUSER.DAT file.

Alternatively, if you want to search for all NTUSER.DAT files on a system, you could use fls with the option to recursively list all regular files (-Fr), grepping the output for NTUSER.DAT. In either case, we find the MFT entry for Alberte's NTUSER.DAT is: 285:

```
barry@forensic1:-$ fls -Fr -o 2048 NTFS_Part_2017/NTFS_Part_2017.E01 | grep
NTUSER.DAT
r/r 285-128-2: Users/AlberTE/NTUSER.DAT
r/r 286-128-2: Users/ElsaE/NTUSER.DAT
```

Once you've identified the MFT entry using one of the two methods above, you can simply extract the file with icat, arbitrarily naming the output (we use NTUSER.285 here). Run the command to check the resulting type:

```
barry@forensic1:-$ icat -o 2048 NTFS_Part_2017/NTFS_Part_2017.E01 285 >nNTUSER.285
```
