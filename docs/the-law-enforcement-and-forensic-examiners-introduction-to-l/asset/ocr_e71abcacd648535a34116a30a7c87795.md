Note that we use groupings to group our calculations. We find the offset to the file system (10260*512), subtract that from the offset to the string (10561603) and then divide the whole thing by the data unit size (1024) obtained from fsstat. This (5184) is our data unit (not the inode!) that contains the string we found with **grep**. Very quickly, we can ascertain its allocation status using the Sleuth Kit command **blkstat:**

```
barry@forensic1:-:/able2$ blkstat -o 10260 able2.dd 5184
Fragment: 5184
Not Allocated
Group: 0
```

The command **blkstat** takes a data block from a file system and tells us what it can about its status and where it belongs. We'll cover the **TSK blk** tools in more detail later. So in this case, **blkstat** tells us which word search for the string cybernetic resulted in a match in an unallocated block. Now we use **find** to tell us which inode (meta-data structure) points to data block 5184 in the second partition of our image:

```
barry@forensic1:-:/able2$ find -o 10260 -d 5184 able2.dd
10090
```
