Back to our able2 image. This time we are going to do a search for a single string in able2.dd. In this case we will search the image for the keyword Cybernetic. Change to the directory containing our able2.image and use grep to search for:

```
barry@forensic1:~/2$ grep -abi cybernetic able2.dd
10561603: * updated by Cybernetic for linux rootkit
55306929:Cybernetic proudly presents...
55312943:Email: cybernetic@nym.alias.net
55312975:Finger: cybernetic@nym.alias.net
```

Recall that our grep command is taking the file able2.dd treating as a text file (-a) and searching for the string cybernetic. The search is case-insensitive (-i) and will output the byte offset of any matches (-b).

Our output shows that the first match comes at byte offset 10561603. We like in our first string search, we are going to quickly view the match by our viewer xxd and using the -s option to provide the offset given by grep. We will also use the head command to indicate that we only want to see a specific number of lines, in this case 5 (-n 5). We just want to get a look at the context of the match before proceeding.

```
barry@forensic1:~/2$ xxd -s 10561603 able2.dd | head -n 5
00a2843: 002a 0975 6174 6574 6064 2062 7390 4379 * .updated by Cy
00a2853: 62c6 726e 6574 696b 66f2 206c 696e bernetic for lin
00a2863: 7578 2072 06f6 746b 6974 0a20 2af2 0a0a ux rootkit. /*.
00a2873: 2369 6263 6c75 6475 203c 7379 7372 7479 #include <sys/ty
00a2883: 7065 73e2 6e83 0a23 696e 636c 7564 6520 pes. #include
```

We also have to keep in mind what we find that the offset is to the match in the entire disk (able2.dd is a full disk image), not in a specific file system. In order to use the Sleuth Kit tools, need to have a file system to target.
