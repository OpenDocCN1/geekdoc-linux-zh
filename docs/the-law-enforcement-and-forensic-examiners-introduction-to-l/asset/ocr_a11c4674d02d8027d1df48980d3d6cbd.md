Once you have the subject computer booted with a Linux Boot CD (preferably one that is set up with forensics in mind). You’ll need to ensure that the two computers are configured on the same network, and can communicate.

Checking and configuring network interfaces is accomplished with the ifconfig command (interface configure). If you run ifconfig -a, you will get a list of interfaces and their current (if any) settings. On my collection box, to shorten the output, I’ll run the command on the network interface (eth0):

