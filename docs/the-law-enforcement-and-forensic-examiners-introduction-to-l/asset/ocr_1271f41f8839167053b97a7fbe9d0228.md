The first hash in the output above is the entire input hash for the device that was

```
berry@forensic1~$ cat able_3.0* | shashum
2dddbfe3d00cc7367172ec320df8f61afda3502      -
```

Now we have our image, and we have verified that it is an accurate copy.
in order to check the file system and carve the partitions, we'll need to work on a single raw
image instead of splits. Working from the assumption that we are operating on this system
with basic tools, we'll forgo using tools like affuse and kpartx. Instead, we'll recreate
a raw image using cat to add the files back together and re-direct the raw image:

```
berry@forensic1~$ cat able_3.0* > able_3.raw
```

And now we will work on the contents of able_3.raw image.
