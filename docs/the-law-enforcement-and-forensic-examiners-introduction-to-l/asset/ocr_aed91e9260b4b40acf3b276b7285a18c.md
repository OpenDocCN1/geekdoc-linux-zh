In summary, all means that instead of taking the approach that we might normally with multi-functional Windows forensic software:

Instead of fumbling around the command line, we target our commands to the layer we are currently examining.

# Sleuth Kit

The first of the extremal tools we will cover here is a collection of command line tools called the Sleuth Kit (TSK). This is a suite of tools written by Brian Carrier and maintained at http://www.sleuthkit.org. It is partially based on the Coroner’s Toolkit (TCT) originally written by Dan Farmer and Weiner Sema. TSK adds additional file system support and allows you to analyze any file system regardless of the platform you are currently working on.

Let’s start with a discussion of the tools first. Most of the information is readily available in the Sleuth Kit documentation or on the Sleuth Kit website.

We’ve already discussed the TSK’s organization of tool function by layers. Here’s a list of the tools, and where they fit in (the layers defined here are different from our overall analytical approach).

+   - Media management layer – mmmls, mmcat, mmstat
- File system layer – fsstat
- File name layer (“Human Interface”) – fls, ffind
- Meta data (inode) layer – icat, ifs, ifind, istat
