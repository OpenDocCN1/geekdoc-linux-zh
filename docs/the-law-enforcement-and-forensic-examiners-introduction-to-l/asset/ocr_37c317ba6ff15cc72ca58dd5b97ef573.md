find allows you to search for a file based on any number of criteria, including dates, sizes, name patterns, etc.. To look for your fstab file, you might try:

```
barry@forensic:-$ find -iname fstab
/etc/fstab
```

This "find, starting in the root directory (/), by name, fstab and print the results to the screen". find will allow you to search by file type or even times (actually inode times). The power of the find command should not be underestimated. More on this tool later. Have a look at man find. Can you see the difference between -iname and -name?

pwd presents the working directory to the screen. The following example shows that we are currently in the directory /home/barry.

```
barry@forensic:-$ pwd
/home/barry
```

file categorizes files based on what they contain using a signature, regardless of the name (or extension, if one exists). Compares the file header to the "magic" file in an attempt to ID the file type. For example:

```
barry@forensic:-$ file pic.png
pic.png: PNG image data, 48 x 48, 4-bit colormap, non-interlace
```

+   ps list of current processes. Gives the process ID number (PID), and the terminal on which the process is running.

ps ax shows all processes (a), and all processes without an associated terminal (x). Note the lack of a dash in front of the options. See the man page for info on this departure from our previous convention.

```
barry@forensic:-$ ps ax
STAT TIME COMMAND
1 ? Ss 0:00 init [4]
2 ? S 0:00 [kthreadadd]
3 ? S 0:00 [ksoftirqd/0]
5 ? S< 0:00 [kworker/0:0H]

1597 ? 0:00 [kworker/0:0]
1604 pts/1 Ss+ 0:00 -bash
1645 ? S 0:00 [kworker/1:0]
```
