Using efwmount, we fuse the EWF files to /mnt/ewf, and we must mount the NTFS partition at sector offset 2048 (we know from previous exercises, or you can use fdisk -l of /mnt/ewf to confirm). The command clscan is then run with the -r option for recursive (scan sub directories), and -i to show only infected files. The -i option prevents cluttered output (lists of "OK" files). Finally, we use --log to document our output. The virus signature found is a common anti-virus test file.

View the resulting log with cat:

```
root@forensic1:~~/NTFS_Pract_2017# cat NTFS_AV.txt
```

When you are finished, unmount the NTFS file system and the fuse mounted image.

```
root@forensic1:~~/NTFS_Pract_2017# umount /mnt/analysis/
root@forensic1:~/NTFS_Pract_2017# fusermount -u /mnt/ewf
```

This is a simple example of virus scanning evidence with ClamAV. This is an exceptionally powerful tool, and you should explore the man page and the online documentation.
