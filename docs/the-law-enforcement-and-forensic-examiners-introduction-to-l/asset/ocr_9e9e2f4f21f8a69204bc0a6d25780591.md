Note that the comments and methods for managing modules are largely abstract, but the
locations of files and methods may differ. The process of identifying
modules and hardware should be the same. Man (manual) pages and distribution
documentation should always be relied on for primary problem solving.

Keep in mind that these commands can be run against a subject computer
using Linux forensic boot media. If you have the time, its a great way to inventory a
subject computer either prior to seizure or if you seize the computer (only image it for
whatever reason), but still wish to have a full hardware inventory.
