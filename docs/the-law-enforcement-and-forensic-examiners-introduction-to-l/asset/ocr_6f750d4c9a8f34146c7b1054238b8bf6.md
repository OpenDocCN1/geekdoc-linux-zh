# v.4.33    A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

Remember that the mount command works on file systems, not disks. The file system in this image starts 2048 sectors into the image, so we use mount using an offset. Since we are also examining an EWF image, we'll need to use ewmount to fuse the image file. This all must be done as:

```
barry@forensic1:~/NTFS_Pract_2017$ su -
Password:
root@forensic1:~# cd ~barry/NTFS_Pract_2017
root@forensic1:/home/barry/NTFS_Pract_2017# ewmount NTFS_Pract_2017.E01 /mnt/ewf ewmount 20140608
root@forensic1:/home/barry/NTFS_Pract_2017# mount -o ro,loop,offset=$ ((2048+512)) /mnt/ewf/ewf1 /mnt
root@forensic1:/home/barry/NTFS_Pract_2017# exit logout
barry@forensic1:~/NTFS_Pract_2017$
```

In the above set of commands, we use root, ewmount to mount the EWF image on /mnt/ewf as /mnt/ewf/ewf1. We then mount the data partition (which we know is at 2048 from our previous exercise) and then exit²⁷.

We then obtain a simple list of files using the find command:

```
barry@forensic1:~/NTFS_Pract_2017$ find /mnt/evid/ -type f
/mnt/evid/ProxyLog.log
/mnt/evid/System Volume Information/IndexerVolumeGuid
/mnt/evid/System Volume Information/WPSettings.dat
/mnt/evid/Users/AlberTE/Documents/better_access_unix.txt
/mnt/evid/Users/AlberTE/Documents/books.txt
/mnt/evid/Users/AlberTE/Documents/cable.txt
/mnt/evid/Users/AlberTE/Documents/cablet.txt
/mnt/evid/Users/AlberTE/Documents/hackcabl.txt
...
```

The find command, starts at the mount point (/mnt/evid), looking for all regular files (type -f). The result gives us a very long list of all the allocated regular files on the mount

> ²⁷ Note that you can use ewmount as a normal user, in this case we need to be root anyway for the loop mount.
