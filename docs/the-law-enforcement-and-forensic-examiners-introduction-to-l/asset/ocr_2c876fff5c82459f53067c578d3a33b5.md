# Carving Partitions with DD

Now we can try another useful exercise in carving with dd. Often, you will obtain or be
given a dd image of a full disk. At times you might find desirable to have each separate
partition within the disk available to search or mount. Remember, you cannot simply mount
ent entire image, only the partitions. We've already learned that we can find the structure
of an image and mount the partitions using tools like kpartx and the loop device with
the mount command.

In this case, we will assume we are on a system where we may not have
access to extremely available tools like kpartx. We introduce this technique not to teach
it for practical use (though you may have limited practical use), but to provide another
practical exercise using a number of important command line tools. In any event, for the
beginning Linux forensics student, I still consider this an important skill. It's just good
practice for a number of common and useful commands.

The method we will use in this exercise entails identifying the partitions in a raw
image with fdisk or gdisk. We will then use dd to carve the partitions of the image.
