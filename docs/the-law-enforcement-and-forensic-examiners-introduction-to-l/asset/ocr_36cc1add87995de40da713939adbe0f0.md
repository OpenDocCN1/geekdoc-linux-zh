# VIII. Advanced (Beginner) Forensics

The following sections are more advanced and detailed. New tools are introduced to
help round out some of your knowledge and provide a more solid footing on the capabilities of
t Linux command line. The topics are still at the beginner level, but you should be at least
sewhat comfortable with the command line before tackling the exercises. Although I've
included the commands and much of the output for those who are reading this without the
beneit of a Linux box nearby, it is important that you follow along on your own system as
through the practical exercises. Typing at the keyboard and experimentation is the best
way to learn.

# The Command Line on Steroids

Let's dig a little deeper into the command line. Often there are arguments about
the usefulness of the command line interface (CLI) versus a GUI tool for analysis. I would
argue that in the case of large sets of regimented data, the CLI can be faster and more flexible
an many GUI tools you could use.
As an example, we will look at a set of log files from a single Unix system. We are not
go analyzing them for any sort of evidentiary data. The point here is to illustrate the ability
of commands from the CLI to organize and parse data by using pipes to show a series of
commands together and achieve the desired output. Follow along with the example, and keep in
mind to get anywhere near proficient with this will require a great deal of reading and
payoff. The payoff is enormous.

Create a directory called Logs and download the file logs.v3.tar.gz into that
directory:
