## The File System

Like the Windows file system, the Linux file system is hierarchical. the "top" directory is referred to as "/root" directory and is represented by "/". Note that the following is not a complete list, but provides an introduction to important directories.

- / ("root") not to be confused with "/"
- /bin
  - --<files> ls, chmod, sort, date, cp, dd (user accessible binaries)
- /boot
  - --<files> vmlinuz, system.map
- /dev
  - --<devices> tty, sd*
- /etc
  - --X11
    - |--<files> xorg.conf
- /home
  - --barry (your user's name is in here)
    - |--<files> bashrc, bash_profile, personal files
  - --other users
- /lib[64]
  - --system libraries (32bit in lib64 and 64bit in lib64)

  - --cdrom0
    - |----dvd0

  - --_other temporary mount points

- /root
  - --<root user's home directory (not to be confused with "/" [file system root])

- /sbin
  - --<files> shutdown, cfdisk, fdisk, insmod (system binaries)
- /sys
- /usr
  - --local

    - |--man

  - --log

## The Mount Command

The mount command uses the following syntax:

```
mount -t <filesystem> -o <options> <device> <mountpoint>
```

One of the options we pass to the mount command, using -t, it is the file system type. But if you don't know what file system is on a device you've been? First, we need to know the partition layout of the device. Is there one partition? Two? Once you've selected the partition we want to view, we need to know what file system might be on. We can accomplish this with a series of commands we've already covered in the earlier chapter on disks and disk naming conventions. We use the lsblk command to view our devices that have been detected. We use fdisk to determine the partition layout, and finally we use the file command with the -s option to determine the file system type we will be mounting. For example, if I insert a thumb drive into my system and I manually mount it, I use the following commands to gather the information you need:

```
root@forensic:~# lsblk
[0:0:0] disk ATA INTEL SSDSC2CT12 300i /dev/sda
```

> Actually, modern Linux systems do a pretty job of auto detecting file system types, but being explicit is not a bad thing.
