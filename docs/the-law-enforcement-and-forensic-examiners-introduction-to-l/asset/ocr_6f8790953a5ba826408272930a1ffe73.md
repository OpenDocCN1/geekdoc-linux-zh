# Mounting EWF Files with ewmount

Just as we are bound to come split images we want to browse, we are also likely to come across Expert Witness (E01 or EWF) files that we want to peak without having to restore them and take up more space than we need.

We've already installed libewf as part of our acquisition lessons earlier. If you have not done so, you can install libewf with sbininstall on Slackware or using whichever method your distribution of choice allows. For this section we are interested in the ewf utility that comes with libewf.

Like affuse, ewmount provides a file system. It is called in the same way, and results in the same virtual disk image that can be parsed for partitions and loop mounted for browsing. If you read the prior section on affuse, this will be very familiar. We will use the EWF version of NTFS_Pract_2017.E0* files we used in our earlier exercises.

It would be a good idea to run ewverify (also from the libewf package – recall we we used it in the acquisitions section) to ensure the integrity of the E01 set is still intact.

```
root@forensic1:-/NTFS_Pract_2017# ewverify NTFS_Pract_2017.E01
efwverify 20140608
```
