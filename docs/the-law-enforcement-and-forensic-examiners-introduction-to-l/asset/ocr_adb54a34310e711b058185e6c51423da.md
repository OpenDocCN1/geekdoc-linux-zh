So we have our registry file, NTUSER.DAT, and target key, UserAssist. We need
software to access the data. For this, we install libregf:

```
barry@forensic1:-$ su -
Password: 
```

```
root@forensic1:# sboinstall libregf
...
Cleaning for libregf-20170130...
```

```
root@forensic1:-# exit
```

You can have a look at the utilities that were installed by this package by looking at the
package file in /var/log/packages:

```
barry@forensic1:-$ grep usr/bin /var/log/packages/libregf-20170130-x86_64-1_SBo
usr/bin/
usr/bin/regfexport
usr/bin/reginfo
usr/bin/regfmount
```

We can see that the package with three executable programs placed in /usr/bin.
We will concentrate on using regmount. Like libewf's ewmount (which is also part of
the libyal project) regmount provides a file system interface to a file object, in this case
a registry file. The usage is very similar. First, we will create a mount point in our current
directory, followed by the registry mounted:

```
barry@forensic1:- mkdir ntusermnt
```

```
barry@forensic1:-$ regmount NTUSER.285 ntusermnt/
regmount 20170130
```

```
barry@forensic1:-$ cd ntusermnt
```

```
barry@forensic1:-/ntusermnt$ ls
AppEvents/ EUDC/ Keyboard\ Layout/ Software/
Console/ Environment/ Network/ System/
Control\ Panel/ Identities/ Printers/
```
