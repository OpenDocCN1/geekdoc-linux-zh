```
root@forensic1:~# file -s /dev/sdi
/dev/sdi1: Linux rev 1.0 ext4 file system, UUID=22e4d5cc-7713-4b17-b2df-11b17a73b954, volume name "Win10Image" (extents) (large files)
```

The pertinent output is highlighted in red. In **lsblk** shows us that the drive was detected as /dev/sdi. The **fdisk** output shows a single partition. The **file** command reads the signature of the partition and determines it is an EXT4 file system. We will discuss the **file** command extensively later in this. For now, understand that it determines the type of file by its signature (regardless of extension or name), in this case a file signature.

We can use that information to mount the drive (this command assumes the directory /mnt/analysis exists - if not create it with **mkdir**)

```
root@forensic1:~# mount -t ext4 /dev/sdi1 /mnt/analysis
```

Change to the newly mounted file system:

```
root@forensic1:~# cd /mnt/analysis
```

You should be able to navigate the thumb drive as usual. Essentially, what we have done here is to view the logical contents of the file system on /dev/sdi and make it available to the user through /mnt/analysis. You can now browse the contents of the disk.
