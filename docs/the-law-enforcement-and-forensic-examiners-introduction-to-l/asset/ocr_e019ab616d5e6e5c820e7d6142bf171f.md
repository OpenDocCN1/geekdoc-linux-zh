# Data Carving with DD

In this example, we will use **dd** to carve a JPEG picture file from a chunk of raw data. By itself, this is not a real useful exercise. There are lots of tools out there that will "carve" from forensic images, including a simple cut and paste from a hex editor. However, the purpose of this exercise is to help you become more familiar with **dd** in preparation for the "carving". This will help familiarize you with the Linux toolbox. First you will need to download the raw data chunk and check it's hash:

```
barry@forensic:-$ wget http://www.linuxeu.com/Files/image_carve_2017.raw
```

```
barry@forensic:-$ sha1sum image_carve_2017.raw
ac33d4e9a48f4dc5b827fba6262c295d28d3cecc image_carve_2017.raw
```
