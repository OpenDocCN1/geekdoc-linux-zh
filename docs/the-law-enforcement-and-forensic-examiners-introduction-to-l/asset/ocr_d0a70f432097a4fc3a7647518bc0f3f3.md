Display the contents of a file:

+   cat : The simplest form of file display, **cat** streams the contents of a file to the standard output (usually the terminal). **cat** actually stands for "concatenate".

+   **cat file1 > file2** : Takes the contents of file1 and streams the output which is redirected to a single file, file3. This effectively adds the two files into one single file (the original files remains unchanged).

+   **more filename** : displays the contents of a file one page at a time. Unlike its DOS counter, GNU **more** takes filenames as direct arguments.

+   **less filename** : **less** is better **more** - Supports scrolling in both directions, and a number of other powerful features. **less** is actually the GNU version of **more**, and on many systems you will find that **more** is actually a link to **less**. Use **q** to exit a **less** session.

Note that you can choose several options. For example:

```
barry@forensic1:-$ ls -aF
./../bash_history .xnup/ .xinitrc .xsession*
myscript* textfile12
```

**ls -aF** will give you a list of all files (-a), including hidden files, and file/directory classification (-F), which shows "*/" for directories, "*" for executables, and "@" for links.

# **Additional useful commands**

**grep** searches for patterns.

**grep pattern** filename

**grep** will look for occurrences of pattern within the file filename. **grep** is an extremely powerful tool. It has hundreds of uses given the large number of options it supports. The **man** page for more details. We will use **grep** in our forensic exercises later on.
