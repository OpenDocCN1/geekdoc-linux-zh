Now we'll re-run bulk extractor, without disabling or enabling scanners, using a banner file (-b mybanner.txt) and a file of terms to search for (-F myterms.txt). The output directory will be blk_out_full (-o blk_out_full). With all the scanners, you will see a few more files in the output directory.
