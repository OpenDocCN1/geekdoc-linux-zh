Now that we have an idea of what disks are named, we can look at the partitions
 volumes. The fdisk program can be used to create or list partitions on a supported device.
This is an example of the output of fdisk on a Linux workstation using the "list" option (-l
[dash "el"]):

```
root@forensic1:~# fdisk -l /dev/sda
Disk /dev/sda: 111.8 GiB, 120034123776 bytes, 234441648 sectors
Units of sectors: 1 * 512 = 512 bytes
Size (logical/physical): 512 bytes / 512 bytes
/O size (minimum/optimal): 512 bytes / 512 bytes
label type: gpt
Disk identifier: 6F8042E-B5CF-4C8F-A974-28A65ADC779
```

| Device Start End Sect Size Type |

| /dev/sda3 859545 234441614 225846159 107.7G Linux filesystem |

fdisk -l /dev/sdx shows you list of the partitions available on a particular drive.
Each partition is identified by its Linux name. The beginning and ending sectors for each
partition is displayed. The number of sectors per partition is displayed. Finally, the partition type
is displayed.

Note that the output of fdisk will change depending on the Disklabel type of the media
 queried. The above output shows a disk with a GPT label. If you have a standard DOS
style MBR, the output will show different fields. For native handling of GPT partition
labels, you can use gdisk

Do not confuse fdisk with the older OS fdisk (for those of us old enough to
remember things). They are very different. The Linux version of fdisk provides for
much greater control partitioning.
