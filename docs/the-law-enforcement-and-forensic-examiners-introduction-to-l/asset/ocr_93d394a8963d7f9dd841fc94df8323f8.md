Now back to the chmod command. There are a number of ways to use this command, including explicitly assigning r, w, or x to the file. We will cover the octal method here because the syntax is easiest to remember (and if most flexible):

```
chmod octal filename
```

octal is a three digit numerical value in which the first digit represents the owner, the second digit represents group, and the third digit represents others outside the owner’s group. Each digit is calculated by assigning a value to each permission:

+   read (r) = 4
write (w) = 2
execute (x) = 1

For example, the filename in our original example had an octal permission value of 755 (rw=7, r=5, r=5). If you wanted to change the file so that the owner and the group had read, write and execute permissions, but others would only be allowed to read the file, you would issue the command:

```
chmod 774 filename
(r=4)+(w=2)+(x=1)=7 [owner]
(r=4)+(w=2)+(x=1)=7 [group]
(r=4)+(w=0)+(x=0)=4 [others]
```

Changing permissions and displaying a new list of the file would show:

```
barry@forensic1:-$ ls -l myfile.sh
-rwxr-xr-x 1 users 3685 Apr 15 11:14 myfile.sh
```

```
barry@forensic1:-$ ls -l chmod 774 myfile.sh
-rwxr-xr-- 1 users 3685 Apr 15 11:14 myfile.sh
```

```
rwx = 7, rwx = 7, r-- = 4
```
