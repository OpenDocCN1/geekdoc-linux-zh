If you did any reading on this particular query, you'll find that the above entries (or "files" in our mounted file system) are ROT 13 obfuscated. This means that the characters in each string are swapped a-m or n-Z, so as an "a" becomes an "n" and a "b" becomes an "o", and so on. We can de-obfuscate this with the tr command used previously to replace one character with another. In this case we'll be replacing characters n-za-m with a-z. Let's try this by repeating the string on each of line, yours:

```
barry@forensic1:.../Count/(values)$ echo "." | tr 'n-za-MN-ZA-M' 'a-za-z'.ln
```

We can see that the yax string at the end of each line is actually the .lnk file extension

So what's the best way to run the tr command on all the files in the /Count/(values) directory? We can go back to the short bash loop we introduced in the Viewing section of this code:

```

do do
echo $file | tr 'n-za-MN-ZA-M' 'a-za-z'
```
