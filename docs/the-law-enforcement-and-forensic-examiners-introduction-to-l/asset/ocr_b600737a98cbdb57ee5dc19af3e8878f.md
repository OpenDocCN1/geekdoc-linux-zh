# A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

This build script should build a package that "just works" after install. You will need to specify a two-letter country code (such as "us") as an argument to the COUNTRY variable when running the build script (this will default to "us" if nothing is specified). For
COUNTRY=nl /clamav.SlackBuild

Groupname and Username

You must have the 'clamav' group and user to run this script, for example:

+   groupadd -g 210 clamav
useradd -u 210 -d /dev/null -s /bin/false -g clamav clamav

Configuration
See README.SLACKWARE for configuration help.

And what we have here is a perfect example of why we need README files prior to installing software. In order to make it run correctly, we need to make sure we have a group and user clamav. The commands we need to accomplish are provided right in the README. So we run those and we are ready to install the software. You can even allow sudo to run the commands for you, but I would suggest you run yourself and decline the prompt in the sboinstall command. clamav also has a secondary README.Slackfile with additional instructions for running the program as a mail scanner. You can elect to read that as you like, though we won't be setting that up in this example.

```
root@forensic:-# groupadd -g 210 clamav
root@forensic:-# useradd -u 210 -d /dev/null -s /bin/false -g clamav clamav
root@forensic:-# sboinstall clamav
```

Now sbootools will download, check, unpack, configure, build and finally install the package for us. We will continue to use this method to install software through the rest of the guide. We will cover ClamAV usage later in the document.

Remember we can periodically use sbcheck to see if we have any external software that needs updating (recall that slackpkg update is used for official Slack packages).

We'll also install another package we talked about previously. Back when we did our initial system inventory, we described the lshw command. We can install easily from SlackBuilds.org using sboinstall.
