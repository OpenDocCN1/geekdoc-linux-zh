In the above command, we use -E zip to disable default scanner except the zip scanner. We then re-enable the finder with -e find (so that we can run our search). This is followed by the -F "Uranium-235" search term. This term can be a string or a regular expression. We can also add terms to create a search term file and run it with the -F option. Our output directory is set with -o blk_out.

The command provides some fairly self-explanatory information, including the data processed and the hash of the disk image. Change into the output directory and let's look at the files that were produced.


+   There are basically three different files in the output above. These are:
- Feature files: Files that contain the output of each scanner.
- Histogram files: Files that show the frequency that each item in a feature file is encountered. We discuss the usefulness of these in more detail later.
- The report file: A DFX formatted report of the output and environment.
