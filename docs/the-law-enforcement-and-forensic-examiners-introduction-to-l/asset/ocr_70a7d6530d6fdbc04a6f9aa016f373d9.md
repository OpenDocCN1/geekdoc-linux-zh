Now we will use the grep command to search the image for any instance of an expression or pattern. We will use a number of options to make the output of grep useful. The syntax of grep is normally:

```
grep -options <pattern> <file-to-search>
```

The first thing we do is create a list of keywords to search for. It's rare we ever want to search for a single keyword, after all. For our examples, let us use "ransom,$50000 (the ransom amount), and unleash a virus". These are some keywords and phrase that we have decided to use from the original letter received by the corporation. Make the list of keywords (using vi) and save it as ~/analysis/searchlist.txt. Ensure each string you want to search for is on a different line.

```
$50,000
random
unleash a virus
```

Make sure there are NO BLANK LINES IN THE LIST OR AT THE END OF THE LIST!!
Now run the grep command on our image:

```
barry@forensic1:~$ grep -abif analysis/searchlist.txt fat_fs.raw >
analysis/hits.txt
```

We are asking grep to use the list we created in ./analysis/searchlist.txt for the patterns we are looking for. This is specified with the -f<file> option. We are telling grep to search fat_fs.raw for the patterns, and redirect the output to a file hits.txt in the .analysis directory, where we record the output. The -a option tells grep to ignore upper and lower case. And the -b option tells grep to give us the byte offset of each hit so we can find the line in xxd (our command line viewer). Earlier mentioned the grep man page and the section it has regular expressions. Please take the time to read it and understand it.

Once you run the command above, you should have a new file in your analysis directory called hits.txt. View this file with less or any text viewer. Keep in mind that strings might best for the job.
