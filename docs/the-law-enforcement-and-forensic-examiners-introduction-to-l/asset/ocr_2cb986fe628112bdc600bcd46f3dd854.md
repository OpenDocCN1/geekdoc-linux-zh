Decompress the gptzip file with gpt -d and check the hash of the raw image file:

```
root@forensic:~# gzip -d gptimage.raw.gz
root@forensic:~# shalum gptimage.raw.gz
99b7519cecb9a482fd57c673cbf46274627a84 gptimage.raw
```

Now we can run kpart on the image file and the partitions to check the partitions, and then to map them, only to loop nodes. See the available options, run kpart by itself:

```
root@forensic:~# kpartx
usage: kpart [-a]|[-d]|[-l] [-v] wholedisk
-a add partition devmappings
-r devmappings will be readonly
-d del partition devmappings
-u update partition devmappings
-l list partitions devmappings that would be added by -a
-p set device name-partition number delimiter
-f force GUID partition table (GPT)
-v force devmap create
-v verbose
-s sync mode. Don't return until the partitions are created
```

The first command will list the partitions as they will appear (-l). After that add the mappings in the second command with (-a) and create them with the read only option as well (-r):

```
root@forensic:~# kpartx -l gptimage.raw
loop0p1 : 204800 /dev/loop0 204800
loop0p2 : 2097152 /dev/loop1 206848
```
