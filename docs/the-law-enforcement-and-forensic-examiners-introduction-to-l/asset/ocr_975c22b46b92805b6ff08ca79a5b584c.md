# A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

look at the offset to a partition, normally given in sectors (using the fdisk command), and multiply by 512 (the sector size). This gives us the offset from the start of our image to the first partition we want to mount. This is then passed to the mount command as an option, which essentially triggers the use of an available loop device to mount the specified file system. We can illustrate this by looking at the raw image of the file we exported with fwdiskexport in our earlier acquisitions exercise, the NTFS_Pract_2017.raw file. Go ahead and navigate to where you have saved the file.

Very quickly, lets run through the steps we need to mount this image. First time round, we will determine the offset to the file system using fdisk, and then mount the file system using the command -o loop option.

```
root@forensic1:~ fdisk -l NTFS_Pract_2017.raw
NTFS_Pract_2017.raw: 500 MiB, 524288000 bytes, 102400 sectors
Units: sectors of 1 * 512 = 512 bytes
Sector size (logical/physical): 512 bytes / 512 bytes
I/o size (minimum/optimal): 512 bytes / 512 bytes
Disklabel type: dos
Disk identifier: e0e6dd22
```

| Device Boot Start Sectors Size Id Type |
| NTFS_Pract_2017.raw | 2048 1023999 1021952 499M 7 HPFS/NTFS/exFAT |

```
root@forensic1:~# echo $((2048*512))
1048576
```

```
root@forensic1:~# mount -o ro,loop,offset=1048576 NTFS_Pract_2017.raw /mnt/tmp/
```

```
root@forensic1:~# ls /mnt/tmp
ProxyLog.log* System\Volume\Users\Windows/
```

So here we a full disk image. We run fdisk on the image (image file is not a device file) and find the offset to the partition is 2048 bytes (in red for emphasis). We use arithmetic expansion to calculate the byte offset (2048*512=1048576) and pass that as the offset in our mount command. This effectively "jumps over" the boot sector of the first partition, allowing the mount command to work properly. We will explore this in further detail later.

Note that you can do the calculations for the offset using arithmetic expansion in the mount command if you choose:

```
root@forensic1:~# mount -o ro,loop,offset=$((2048*512)) NTFS_Pract_2017.raw
/mnt/tmp/
```
