The command above is running blklcalc on the file system (-o 10260) on the original able2.dd, passing the data block we calculated from the blkls image (-u 1593). The result is a familiar block 5184 (see Exercise #2A again). The illustration below gives a visual representation of a simple example:

blklcalc -o sfs_offset -u 3 original.dd = 49

In the illustrated example above, the data in block #3 of the blkls image would map to block #49 in the original file system. We would find this with the blklcalc command as shown in Illustration 6.

So, in simple terms, we have extracted the unallocated space, found a string of interest in a data block in the unallocated image, and then found the corresponding data block in the original image.
