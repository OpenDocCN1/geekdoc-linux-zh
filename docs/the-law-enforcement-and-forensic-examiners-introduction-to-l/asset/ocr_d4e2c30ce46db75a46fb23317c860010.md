This command will stream all the log files (each one from bottom to top) and send the output to awk which will print the first field

```
barry@forensic1:~/Log$ tac messages* | awk '{print $1 "$2"}' | uniq | less
Nov 23
Nov 22
Nov 21
Nov 28
Nov 19
```

This removes repeated dates, and shows just those dates with log activity.

CLI Hint: Instead of re-typing the command each time, use the arrow up on your keyboard to scroll through older commands (part of the command history of bash). Hit the arrow once, and you can edit your last command. Very useful when adjusting commands for this sort of parsing.

If a particular date is of interest, I can grep the logs for that particular date (note there are 2 spaces between Nov and 4, one space will not work in your grep command):

```
barry@forensic1:~/Log$ tac messages | grep "Nov 4"
Nov 47:13:27 hostname123 sshd[pam_unix][27630]: session closed for user root
Nov 47:13:27 hostname123 sshd[27630]: Received disconnect from 1xx.183.221.214:
11: Disconnect requested by Windows SSH Client.
Nov 47:13:07 hostname123 sshd[pam_unix][27630]: session opened for user root by
(uid=0)
Nov 47:13:07 hostname123 sshd[27630]: Accepted password for root from
1xx.183.221.204 port 172 ssh2
Nov 47:08:23 hostname123 sshd[27479]: session closed for user root
```

Of course, to keep in mind that this will give us any lines where the string Nov 4 resides, not just in the date. To be more specific, we could say that only lines that start with Nov 4, using the ^ (in our case, this gives essentially the same output):

```
barry@forensic1:~/Log$ tac messages | grep ^"Nov 4"
Nov 47:13:27 hostname123 sshd[pam_unix][27630]: session closed for user root
Nov 47:13:27 hostname123 sshd[27630]: Received disconnect from 1xx.183.221.214:
11: Disconnect requested by Windows SSH Client.
```
