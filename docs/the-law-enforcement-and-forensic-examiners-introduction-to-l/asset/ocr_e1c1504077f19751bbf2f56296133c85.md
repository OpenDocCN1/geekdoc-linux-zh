# Identifying File Systems

Before we jump to mounting a volume for analysis or review, you might want to identify the file system contained in that volume. The mount command is actually very good at identifying file systems, so going a -t option is not always needed (and is often not used). But it is still good practice to check and record the file system prior to mounting, assuming you will do a manual review of the log contents.

For a simple file example, download the following file, and check the hash:

```
root@forensic1:~$ wget http://www.linuxleo.com/Files/fat_fs.raw

Length: 1474560 (1.4M)

```
