# v.4.33
A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

```
root@forensic1:~# mount -t ext4 -o ro,loop ~baby/able_3/able_3.part3.raw
mnt/evid
```

```
root@forensic1:~# mount -t ext4 -o ro,loop ~baby/able_3/able_3.part1.raw
mnt/evid/boot
```

```
root@forensic1:~# mount -t ext4 -o ro,loop ~baby/able_3/able_3.part2.raw
mnt/evid/home
```

We have now recreated the original file system under /mnt/evid:

```
barry@forensic1:~/$ mount | grep evid
/home/barry/able_3/part3.raw on /mnt/evid type ext4 (ro)
/home/barry/able_3/part1.raw on /mnt/evid/boot type ext4 (ro)
/home/barry/able_3/part2.raw on /mnt/evid/home type ext4 (ro)
```

At this point we can run all of our searches and commands just as we did for the previous fat_fs.raw exercise on a complete file system "rooted" at /mnt/evid.

As always, you should know what you are doing when you mount a complete file system on your forensic workstation. Be aware of options for the mount command that you might want to use (check man mount for options nodev and nosuid, noatime, etc.). Take note of where links point to the subject file system. Note that we have mounted the partitions "read only" (ro). Remember to unmount (amount) each partition when you are finished exploring.
