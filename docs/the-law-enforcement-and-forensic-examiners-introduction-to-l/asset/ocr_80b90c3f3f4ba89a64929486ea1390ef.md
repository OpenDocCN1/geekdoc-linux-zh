# # Examining the Physical Media Information

Now we are ready to start collecting information we'll need to effectively acquire evidence from source media. One of the things we'll need to do is re-inventory our system's connected devices to ensure that we identify the correct detect subject. Normally you would have taken notes on the physical markings of the hard drive (or other media) as you would have removed it from the source computer, etc. Some use an enlarged photocopy of the disk label as part of the acquisition notes, providing a reliable record of disk identification.

In this particular case, I will be using a USB to SATA bridge. Because there is some translation going on, I want to make sure I can identify the bridge as well as the disk attached to it. Once the bridge is attached and powered on, I can run llsb to see its information (for emphasis). If you are using a directly attached SATA drive, you will not need to run this command:

```
root@forensic1:~# lsusb
Bus 006 Device 002: ID 8087:0024 Intel Corp. Integrated Rate Matching Hub
```

```
Bus 002 Device 007: ID 2109:0812 VIA Labs, Inc. VL818 Hub
Bus 002 Device 012: ID 174C:0516 ASMedia Technology Inc. ASM1051 SATA 3Gb/s bridge
Bus 002 Device 006: ID 2109:0812 VIA Labs, Inc. VL818 Hub
```

...

So knowing we are dealing with a Seagate 40Gb hard disk (ST340014AS) in annUSB/SATA bridge (ASMedia Technology), we can identify its device node with llsccsi:

```
root@forensic1:~# llsccsi
[0:0:0:0] disk ATA INTEL SSDSC2CT12 3001 /dev/sda
```
