If you read up on Windows accounts, you'll see the system administrator (RID 500), the guest account (RID 501), and a pair of user accounts (1000 and 1001). There are a number of ways to associate the accounts with particular users, but we will simply navigate to the values under the 000003E8/ sub key.

```
barry@forensic1:~/sammt/SAM/Domains/Account/Users$ cd 000003E8/\(values\)
barry@forensic1:~/sammt/SAM/Domains/Account/Users/000003E8/(values)$ ls
F UserPasswordHint V
```

We have three "files" to look at. A very quick peek at the bottom of the v file shows the username associated with this account:

```
barry@forensic1:~/sammt/SAM/Domains/Account/Users/000003E8/(values)$ xxd V

000001b0: 08c4 09f1 61c6 c3a9 0300 0300 0100 ... .I..n.

The highlighted text shows the account associated as of Albert. The UserPasswordHint is fairly obvious. Let's look at the contents of F:

```
