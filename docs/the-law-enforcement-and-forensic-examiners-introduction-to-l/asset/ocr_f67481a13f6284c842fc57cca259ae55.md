We're ready to run our blkat command to find out if our keyword hit is in block
assigned to the allocated inode:

```
barry@forensic1:~/able_3$ blstat -o 571392 able_3.000 327206
Fragment: 327206
Not Allocated
Group: 9
```

So the block is unallocated. Let's see now if we can find what inode this unallocated
block belongs to:

```
barry@forensic1:~/able_3$ ifind -o 571392 -d 327206 able_3.000
Inode not found
```

And there's our answer. The inode cannot be found. Again this is because the inodes in
ext4 that have unallocated have the direct block pointers deleted. The ifind command is
searching for the data unit (-d) 327206.

All is not lost, though. Instead of using icat to extract that data blocks pointed to
inode, we can use blkat to directly stream the contents of a data block. Have a
look below. We'll use blkat and redirect to a file:

```
barry@forensic1:~/able_3$ blkat -o 571392 able_3.000 327206 > blk.327206

bry@forensic1:~/able_3$ ls -l 1 barry users 4096 May 28 13:50 blk.327206
-rw-rw--r--
```
