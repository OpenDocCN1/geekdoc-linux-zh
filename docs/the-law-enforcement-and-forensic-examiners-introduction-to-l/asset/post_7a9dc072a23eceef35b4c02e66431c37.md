- Note the proper command is umount, not un. This cleanly unmounts the file system. DO NOT remove the disk OR SWAP the disk until it is unmounted.

Check all your terminals and virtual terminals and make sure you are no longer in the mounted directory.

Another Example: Reading a CDROM from DVD

- Insert the CDROM:
- We use the ISO9660 system format for mounting CD and DVD disks. You can check again with the file command run on our DVD device (/dev/sr0) with a disk inserted.

```
root@forensic1:~# file -s /dev/sr0
/dev/sr0: ISO 9660 CD-ROM filesystem data 'MY DATA'
```

Now we mount the device and change to the newly mounted file system:

```bash
root@forensic1:~# mount -t iso9660 /dev/sr0 /mnt/cdrom
mount: /dev/sr0 is write-protected, mounting read-only
```

```bash
root@forensic1:~# cd /mnt/cdrom
ls
autorun.inf* document/ installmanager/ menu/ tools/
```

- You should be able to navigate the disk as usual.
- When you are finished, leave the /mnt/cdrom directory (change to your home directory again with cd or cd ~), and unmount the file system with:

```bash
root@forensic1:~# umount /mnt/cdrom
```

> If you want to see a list of file systems that are currently mounted, just use the mount command without any arguments or parameters. It will list the mount point and file system type of each device on system, along with the mount options used (if any). Note in the output below you can see the thumb drive and CD disk I just mounted (and not unmount):

```bash
root@forensic1:-# mount
/dev/sda3 on / type ext4 (rw)
proc on /proc type proc (rw)
sysfs / /sys type sysfs (rw)
tmpfs / /dev/shm type tmpfs (rw)
/dev/sda1 on /boot type ext4 (rw)
/dev/sd1 on /mnt/hd type ext4 (rw)
/dev/sr0 on /mnt/cdrom type iso9660 (ro)
```

Alternatively, you can query /proc/mounts. Where the mount is actually displaying the contents of /etc/mtab, /proc/mounts is actually more up to date. The /proc file system on Linux is a virtual hierarchical storage of system processes and information. Use cat /proc/mounts to view the output.

The ability to mount and unmount file systems is an important skill in Linux. We use it to view the contents of a file system, and use it to mount external storage for collecting evidence files, etc. There are a large number of options that can be used with mount (some we will cover), and a number of ways the mounting can be done easily and automatically. Refer to the mount info or man pages for more information.

In most modern distributions (Slackware), disks will be auto-detected, and an icon will appear on the desktop for it. We'll cover that in an upcoming section.

## The File System Table (/etc/fstab)

It might seem like mount -t iso9660 /dev/cdrom /mnt/cdrom is a lot to every time you want to mount a CD. One way is to edit the file /etc/fstab ("file system table"). This file allows you to provide defaults for your mountable file systems, thereby shortening the commands required to mount them. My /etc/fstab looks like this:

```bash
root@forensic1:-# cat /etc/fstab
/dev/sda2    swap            swap        defaults      0 0
/dev/sda3   /ext4        defaults      1 1
/dev/sda1   /boot          ext4        defaults      2 1
/dev/cdrom  /mnt/cdrom     auto        noauto,owner,ro 0 0
devpts      /dev/pts      devpts      gid=5,mode=620 0 0
proc        /proc          proc        defaults      0 0
tmpfs       /dev/shm      tmpfs       defaults      0 0
```

The columns are:

```
<device>           <mount point>   <fst>          <default options>
```

With this /etc/fstab, I can mount a CD by simply typing:

```bash
root@forensic1:~# mount /mnt/cdrom
```

The above mount commands look incomplete. When not enough information is given, the mount command will look to /etc/fstab to fill in the blanks. If it finds the required information, it will go ahead the mount. To find out more available options for /etc/fstab, enter info fstab at the mount prompt. After installing a new Linux system, have a look at /etc/fstab to see what is available for you. If you need it's not there, add it. In my case I uncommented the entry for the CDROM. Out of habit, I prefer using fstab to mount my CD/DVD media.

## Desktop Mounting

Mounting is often handled by the desktop environment. When you plug in a device, the system will detect it and mount it automatically. You can then access the files through the file manager.

If you want to mount a device manually, you can use the mount command as shown before. This is useful when you need to specify particular mount options or when the desktop environment does not detect the device.
