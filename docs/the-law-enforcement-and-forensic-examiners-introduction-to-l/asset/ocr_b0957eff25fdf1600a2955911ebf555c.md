# v4.33 A Comprehensive Beginner's Guide to Linux as a Digital Forensic Platform

Let's look now at ewinfo and ewfverify. These two tools, also included with libewf, provide information on any properly formatted EWF files you may come across.

ewinfo simply reads the image metadata that was entered during the imaging process. It will work with image files acquired using other software, as long as it is in a proper EWF format. For the files we collected, using ewfacquire, the output would look like this (Note the Operating system used and the Software version used):

```
root@forensic1:-# ewinfo case1.disk2.E01
ewfinfo 20140608
```
