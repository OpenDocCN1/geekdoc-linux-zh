# Over the Wire - ewafquirestream

Last, but not least, we will cover a tool that will allow us to take a stream of input (with the same netcat pipe) and create an EWF file from. ewafquirestream acts much like ewafquire (and is part of the same libwef package we installed previously), which allows for data to be gathered via standard input. The most obvious for this is data passing by our netcat pipe.

In previous examples, once the data reached the destination collection computer, the listening netcat pipe pushed the output to the dd or dc3 command output string, and the file was written exactly as it came across, as a bitstream image.

But by using ewafquirestream, we can create EWF files instead of a bitstream image. We simply pipe the output stream from netcat to ewafquirestream. If we do not wish to have the program use defaults, then we use the command with options that define how we want the image made (sectors, hash algorithms, error handling, etc.) and what information we wanted. The command on the subject machine remains the same. The command on the collection system would look like this (utilizing many of the command defaults):

```
root@forensic:~# nc -l -p 2525 | ewafquirestream -C 111-222 -D 'Subject drive' -e 'BarryGrundy' -E '1' -f encase6 -m fixed -M physical -N 'Imaged via network' -t /mnt/evid/nc_ewf_image
```
