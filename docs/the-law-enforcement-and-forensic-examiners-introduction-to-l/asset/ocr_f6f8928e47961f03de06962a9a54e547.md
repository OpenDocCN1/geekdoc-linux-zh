# Alternative Imaging Tools

Standard Linux is a fine imaging tool. It is robust, well tested, and has a proven track record.

As good as dd is an imaging tool, it has one simple, perceived flaw: It was never actually designed to be for forensic acquisitions. While the word "hash is a little harsh, we need to know that much as the digital forensics community refers to dd as an "imaging tool, that is not what it was designed for. It is very capable, but some practitioners prefer full featured, dedicated imaging tools that do not require external programs to accomplish logging, hashing, and imaging documentation. Additionally, dd is not the best solution for obtaining evidence from damaged or failing media.

There are a number of forensic specific tools out for Linux users who wish to acquire evidence. Some of these tools include:

+   - **dc33d-enhanced dd program for forensic use (based on dd code).**
- **dcfl1dd – enhanced dd program for forensic use (fork of dd code).**
- **ewfwacquire – Provided as part of the libewf project, this tool is used in detail to acquire Expert Witness Format (EWF) images. We will cover it in detail later.
- **GNU dddrescue – An imaging tool specifically designed to recover data from media exhibiting errors (not to be confused with dd_rescue).**
