Once we want to use dd options if conv=noerror,sync bs=x, then you do that on the dd side of the

```
root@bootdisk:-# dd if=/dev/sda bs=4096 | nc 192.168.55.25 2225
```

Once the imaging is complete¹⁵ we will see that the commands at both ends appear to
"hang". After we receive our completion messages from dd on both boxes (records in /
records/), we can call the nc listening on our collection box with a simple ctrl c. This
should return prompts on both sides of the connection. You should check both the
hash of the physical disk that was imaged on the subject computer and the resulting image on
t collection box to see if they match.

```
root@forensic1:-# /mnt/evid/net_img.raw
8f6ce10ae87d6ff4590ba809ba51385679738ed /mnt/evid/net_img.raw
```

Our hashes matches and our network acquisition was successful.

# Over the Wire - dc3dd

As discussed previously, there are a number of tools we can use for imaging that
provide a more forensic oriented approach. dc3dd is a good choice for the wire
imaging as it is on local disks. You also have flexibility with dc3dd that even if your
boot disk does not come with installed, you are still able to use all its features on the
evidence collection computer.

dc3dd does all its imaging on the output side of the acquisition process (unless you are
acquiring from file sets or some other non-standard source). This means we can use dd
on our subject computer (using the boot disk) to acquire the disk and stream the contents
across our netcat pipe, and still use dc3dd on our collection machine to handle hashing,
sitting and logging. Most of dc3dd's options and parameters work on the output stream. So,
while listening on the process system will use dc3dd commands, the subject
system can use the same dd commands we used.

On the collection system, let's set up a listening process that uses dc3dd to split the
incoming data stream into2GB chunks and logs the output to nc.dc3dd.raw. As soon as we
iniate our command, dd will start and waiting for input from the listening port (2525):

```
root@forensic1:-# nc -l -p 2525 | dc3dd of=/mnt/evid/nc.dc3dd.000 ofsz=256
log=/mnt/evid/nc.dc3dd.log
```

> ¹⁵PRO TIP: You can watch the progress of the imaging on your collection system by opening another terminal
and "watching" the size of the file grow. Use watch -lh net_img.raw and ctrl-c when it's complete. watch
ill update the command -lh every two seconds until you stop it.
