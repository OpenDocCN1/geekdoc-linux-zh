Now we'll look at ewexport. This tool allows you to take an EWF file to a bit stream image, essentially removing the meta-data and leaving us in the raw format, with dd. It is interesting to note that ewexport can actually write to standard output, making it suitable for piping to other commands. Here, we use the command with several options that result in the EWF file exported to a raw image.

```
root@forensic:~/NTFS_Pract_2017# ewexport -t NTFS_Pract_2017 -f raw -u
NTFS_Pract_2017.E01
ewfexport 20140608
```

We use the -t option ('target') to write to a file. The -f option with raw indicates that the file format we are writing to is raw, with dd output. We use -u to accept the remaining defaults and prevent an inactive session. This results in a raw file that has the same hash as the original media (see the output of the md5sum command). We also see an XML .info file that contains the hash value¹.

```
root@forensic:~/NTFS_Pract_2017# ls -lh NTFS_Pract_2017.*
-rw-r-- 1 root 128M May 1 18:19 NTFS_Pract_2017.E01
```

> ¹The output of this command might differ greatly depending on the version of libewf you install. Some repositories use versions that do not append the .raw extension or provide an .info file.
