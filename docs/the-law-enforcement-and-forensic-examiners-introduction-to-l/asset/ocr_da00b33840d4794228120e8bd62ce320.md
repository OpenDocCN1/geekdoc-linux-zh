In the above output, we see that the first directory listing shows the image file. We then compress using gzip -c which writes to standard output. We redirect that output to a new file (name of our choice). The second listing shows that the original file remains, and the compressed file is created. We then use gzip -cd to decompress the file, redirecting the output to a new file and this preserving the compressed file.

These are very basic options for the use of gzip. We reason why the -c option allows us to compress a file and pipe the output to a hash algorithm. In a more practical sense, this allows us to create a compressed image and check the hash of that image without writing the file.

If we go back to a single image file in our directory, we can do this action. Remove all the files we just created (using the rm command) and leave the single original dd image. Now we will create a single compressed file from that original image and then check the hash of the compressed file to ensure it's validity:
