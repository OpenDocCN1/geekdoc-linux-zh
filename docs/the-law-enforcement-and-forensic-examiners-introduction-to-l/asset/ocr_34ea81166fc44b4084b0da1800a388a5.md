Since we have no IDE devices, no drive is detected as /dev/hda. But when we look in the /dev directory we use static nodes for all possible disk and partition names for /dev/hda. In modern Linux systems, Udev creates device nodes "on the fly". The nodes are created as the kernel detects the device and the /dev directory is populated in real time. In addition to being more efficient, Udev also runs in user space. One of the benefits of Udev is that it provides "persistent mapping". In other words, you can write a set of rules that will allow Udev to recognize a device based on individual characteristics (serial number, manufacturer, model, etc.). The rule can be used to create a user-defined link in the /dev directory, so for example, my thumb drive can always be accessed through an arbitrary device name of my choice, like /dev/my-thumb, if so choose. This means I don't have to search through USB device nodes to find the correct device name if I have more than one external device connected. I can connect 4 USB devices and instead of searching through /dev/sdc, sdd, sde, and sdf - I just go to /dev/my-thumb. http://activated.net/udev_rules.html

On Slackware, Udev runs as a daemon from the startup script /etc/rc.d/rc.udev. We will discuss these startup scripts in more detail in this document. We will not do any specific configuration for Udev on our forensic computers at this time. We will discuss it simply because it plays a major part in device handling and also is of interest to forensic examiners who want to know what their system is doing. Udev does not involve itself in mounting or otherwise interacting with applications. It provides a hardware to kernel interface.

# Hot Pluggingging Devices and Desktops

One of the considerations when discussing Desktop Environments is whether or not the system will allow for desktop auto-mounting of removable media. KDE and GNOME are designed for a simple user experience and examiners need to be aware of how to control undesired behavior in a forensic environment. Once you've installed your system of choice, make sure you test what happens when "hot plug" a USB or other removable media device. For example, some distributions might edge to auto-mount to the GUI desktop immediately upon insertion.

XFCE is a lighter (read: lighter on resources) desktop. And although XFCE is also capable of automatically hot plugged devices, which allows for easier control of removable media on the desktop. As an example, consider the following snapshot of an XFCE settings dialog for removable media. By default, devices are NOT mounted in the XFCE environment. Not all distributions might be configured this way, however. Be sure to test for yourself. As a forensic examiner, you do NOT want your system automatically mounting devices simply because you plugged them into the system.
