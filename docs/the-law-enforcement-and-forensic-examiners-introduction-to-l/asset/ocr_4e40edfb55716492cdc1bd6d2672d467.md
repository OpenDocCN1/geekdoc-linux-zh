Let's go ahead with step 1: Using xxd, pipe the output of our image_carve.raw file
and look for the start of the JPEG25.

```
barry@forensic1:-$ xxd image_carve_2017.raw | grep ff8d
0000f000: 901d cef7 b848 ac23 24ab 4f44 6d13.......#$.OM.
0001b0a0: e79e a8d6 d7fb8 b357 a5f7 ff8d 85e9 e29d4......3.g......$

000636ac: 1676 761b e3d4 ff8d fe00 0010 4446 4946......JFIF
```

The grep command found four lines that contain the potential header of our picture
file. We are looking for a JPEG image, and we know that following an additional
four bytes after the ff8d we should see the JFIF string. The last line of our output shows,
mining is the correct match. This is shown in red above.

A start of a JPEG file header has been found. The offset (hex) for the
beginning of this line xxd output is 00836ac. Now we can calculate the byte offset by
dec. We will use the bc command. As discussed in an earlier section, bc is a
command "calculator", useful for conversions and calculations. It can be used either
interactively or piped in. In this case we will echo the hex to bc, first telling it
the value is in base 16. bc will return the decimal value.

```
barry@forensic1:-$ echo ibase=16;36AC() | bc
223936
```
