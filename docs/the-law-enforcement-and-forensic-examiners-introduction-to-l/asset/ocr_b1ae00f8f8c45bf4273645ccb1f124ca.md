One goal is to show the Sleuth Kit creates a virtual directory that contains entries for orphan files. As we previously noted, in our discussion of the fls command, these files are the result of an inode file having no file name (directory entry) associated with it. Sleuth Kit organizes these in the $orphan directories. This is a useful feature because it allows us to identify and access orphan files from the output of the fls command.

In this exercise, we determined through our calculations that we were looking for the contents of inode 10090. The Sleuth Kit find can tell us the file name associated with an inode. Here, we are provided with the $orphan entries:

```
barry@forensic:~/able2$ ffind -o 10260 able2.bd 10090
* /$orphanFiles/OrphanFile-10090
```
