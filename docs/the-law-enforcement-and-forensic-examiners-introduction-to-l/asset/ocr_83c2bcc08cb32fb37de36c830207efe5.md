Previously, we were able to determine that the partitions were "Linux" partitions
the output of dfisk. Now file informs us that the file system type is ext4⁵. We can use this
information to manage the partitions. Remember that you will need to root to the mount
partitions, so to root first, mount and mount each partition, until you find the /etc
directory containing the fstab:

```
barry@forensic1:~$ su -
Password:
root@forensic1:~# mount t ext4 -o ro,loop ~berry/able_3/able_3.part1
/mnt/evid
root@forensic1:~# ls /mnt/evid
```
