Now we create our EWF mount point (again this is an arbitrary name). Use the
ewfmount command to provide the first file name
for the image set. ewmount will find the rest of the segments. We can use the ls command on
our mount point to fuse the disk mount image resulted:

```
root@forensic:~/NTFS_Pract_2017# mkdir /mnt/ewf
```

```
root@forensic:~/NTFS_Pract_2017# ewmount NTFS_Pract_2017.E01 /mnt/ewf
ewfmount 20140608
```

```
root@forensic:~/NTFS_Pract_2017# ls /mnt/ewf
ewf1
```

Our disk image is ewf1. Let's hash that and compare it to our ewfverify output
above. As you can see, we get a match:

```
root@forensic:~/NTFS_Pract_2017# md5sum /mnt/ewf/ewf1
eb4393cfcc4fca856e0edbf7722aa7d  /mnt/ewf/ewf1
```
