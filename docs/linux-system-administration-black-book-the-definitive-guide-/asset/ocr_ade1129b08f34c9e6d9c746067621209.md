**Table 7.14 Options for the /etc/pump.conf file (continued).**

| Option | Purpose | Arguments | Example |
|:---|:---|:---|:---|
| **retries** | How many times to try again if any stage of the DHCP setup process fails. | A nonzero integer. | **retry 5** |
| **timeout** | Wait the declared number of seconds before giving up on the DHCP setup process. | A nonzero count of seconds. | **timeout 30** |

A sample configuration file on a machine with only one interface might contain:

retries 5
timeout 15
domainsearch "home.net kitchen.home.net"
