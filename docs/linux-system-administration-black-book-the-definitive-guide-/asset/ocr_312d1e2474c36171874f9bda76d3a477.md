# # Utilizing Windows Printers Under Linux

To set up a Linux box so that it can use Samba to send print jobs to a printer installed on a Windows 98 machine, do the following:

+   1. Set up the printer as shared on the Windows 98 machine.
+   2. On each machine that needs to be able to print over Samba, you need to edit */etc/printcap*. Type “`vi /etc/printcap`” to open the file.
+   3. Create a local print definition that passes the print job to the input filter */usr/bin/smbrprint*. For example:

```
ij|inkjet:1
:sd=/var/spool/lpd/inkjet:1
:sh:\
:if=/usr/bin/smbrprint:
```
