# Removing RPMs With GNOME RPM

To remove an RPM from your system with the GNOME RPM tool, do the following:

+   1. Browse in the left-hand side of the main GNOME RPM dialog box until you locate the package you want to remove.

+   2. Click on the package to select it.

+   3. Click on the Uninstall button (shown earlier in the chapter in Figure 4.1) to open the Continue Removal dialog box shown in Figure 4.5.

+   4. To continue to remove the package, click on the Yes button. The package is now uninstalled.
