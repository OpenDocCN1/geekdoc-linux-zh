# 在客户端上设置 ssh

要在您希望访问受 ssh 保护机器的机器上设置安全外壳客户端，请执行以下操作：

1. 以 root 身份登录。
2. 输入 "vi /etc/ssh_config" 以打开 ssh 客户端配置文件。
3. 您需要按照从最具体到最不具体的顺序设置规则。因此，您应该从引用您打算访问的特定主机的部分开始。要为特定主机或一组主机构建规则，您使用 **host** 关键字。主机按以下方式指定：
   - 确切的主机名
   - 星号表示多个未知字符或所有主机
   - 问号表示一个未知字符

想想您想要为其创建连接规则的特定主机，然后输入 "i" 进入插入模式。
