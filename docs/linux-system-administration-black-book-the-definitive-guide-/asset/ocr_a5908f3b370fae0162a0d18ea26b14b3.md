+   10. Enter a brief, meaningful printer name in the Names text box. Typically, the primary printer on a Linux or Unix system is named "lp" by default, to make life easier for users.

+   11. Alter the Spool Directory to reflect where this printer’s spool files should go. If you are setting up the default printer (lp), then leave the default spool directory as is.

+   12. If you want to limit how large a print job can be, enter the size (in K) in the File Limit text box. The default entry is 0, which means there is no limit on print job size.
