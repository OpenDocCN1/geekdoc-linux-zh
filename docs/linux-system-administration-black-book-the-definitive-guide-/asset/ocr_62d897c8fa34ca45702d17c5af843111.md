**NOTE:** A knowledgeable user can get around this restriction if they need to. Using *lpr* with the *-s* flag creates a symbolic link to line up the file for *printing* instead of copying it to the print queue, thus avoiding the size restriction. If this occurs, you have no control over pausing or removing the print job. It has to be allowed to finish printing out.
