# Configuring A Second Network Interface At The Command Line

To set up Linux to utilize two different network interfaces—for example, two Ethernet cards—while at the command line, do the following:

+   1. The second Ethernet card is typically called eth1. Type "ifconfig eth1 *IPAddress netmask netmask*" to assign the appropriate IP address to this card.
+   2. Type "vi /etc/hosts" to open the host configuration file.
+   3. Move the cursor to where you want to add the host definition.
+   4. Press "o" to open a blank line beneath the current line, and enter Insert mode.
+   5. Enter the host definition. For example:

```
192.168.10.41       cat.animals.org     cat
```
