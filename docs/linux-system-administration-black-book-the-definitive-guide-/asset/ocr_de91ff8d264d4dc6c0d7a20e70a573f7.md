# Grouping Commands

You can group **sed** commands by surrounding them with a pair of braces `[]`. Group-ings can be performed within **sed** script files for formatting reasons or from the command line. If you build a script file, you cannot have any additional com-mands after the opening brace. For example, consider the following beginning for a **sed** statement:

```
sed '/Header/'
```

So far, this just tells **sed** to look for the text "Header". Now, you want to apply multiple commands to this same text. You do this by adding the opening brace at the end of the line, as follows:

```
sed '/Header/{
```
