Not all testing operations are performed on files. You can also use `test` to examine strings. These operators are useful for checking user input, file contents, and more. Table 20.9 provides a list of string `test` operators.

You can compare numbers as well as letters and files. If you have done any programming in the past, this approach is the type of test that you are most familiar with. Table 20.10 lists the operators with which you can compare numerical values. All of these items are used in the following format:

test value1 operator value2
