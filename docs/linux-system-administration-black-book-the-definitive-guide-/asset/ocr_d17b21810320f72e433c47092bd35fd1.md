+   8. Press the Esc key, and then type “ZZ” to save and close the file.
+   9. Proceed to the section “Creating The Initial Cache,” and then return to Step 10.
+   10. Type “/etc/rc.d/init.d/named restart” to stop the name server and restart it with its new configuration.

# Creating The Initial Cache

To build the cache file your name server starts with, do the following:

+   1. Log in as root on the machine that needs the cache.
+   2. Type “more /etc/named.conf” if you need to refresh your memory regarding which file you told the name server its cache is in, and which directory its files go to. The values from the earlier section “Configuring The Master Name Server” are used here, so the cache file is /etc/named/Master.cache.
+   3. Use the following command format to build your cache file:
+   ```d
+   ig @rs.internic.net . ns > cache_path
+   ```
+   For example:
+   ```d
+   ig @rs.internic.net . ns > /etc/named/Master.cache
+   ```
+   4. Type “/etc/rc.d/init.d/named restart” to restart the name server with the new cache file.

> NOTE: You need to regenerate this file on occasion. This is a good use for cron and shell scripting.
