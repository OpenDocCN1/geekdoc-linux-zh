| Option | Purpose | Value(s) | Example |
| :--- | :--- | :--- | :--- |
| **preserve case** | Sets whether to leave file name cases as is or convert them to the **default** case. | **yes or no** | **preserve case = no** |

## Mounting Windows Shares Under Linux

To mount a Windows partition through Samba on a Linux box, do the following:

- Log in to the Linux box as root.
- Make sure the mount point you want to use already exists. For example, type `mkdir /mnt/win` to make a generic mount point for Windows shares.
- If you are unsure of the share you want to mount on a particular host you have two options:
  - If the share is set to be publicly browseable, use the following command to get a list of shares: `smbclient -L host`
  - If the share is not publicly browseable, you will have to look on the machine that hosts it in the `/etc/smb.conf` file to get the name.
- Use the following format to mount the share: `smbclient //NetBIOS_name/share_name`

This program is similar to an FTP client. Type `man smbclient` to get the full option list.

## Offering Linux Printers

To set up Linux partitions so that you can share them with other machines through the SMB protocol, do the following:

- See the section “Configuring Samba” for details on the initial configuration setup.
- If you have not already done so, log in as root to the machine whose partitions you want to offer.
- If you are not already editing the file, type "vi /etc/smb.conf" to open the Samba configuration file.
- Type "printers" and press Enter to jump down to the first statement mentioning printers, and then type "/" and press Enter again to jump down to the following section:

  ```ini
  [printers]
  comment = All Printers
  path = /var/spool/samba
  browsable = no
  guest ok = no
  writable = no
  printable = yes
  ```

- If you want to use a different text statement to define this print share, such as **All Printers On Antelope**, change the `comment` option’s value.
- If you want print jobs sent from Samba clients to be spooled elsewhere locally, then change the value for the `path` option.
- If you want this share to show up in a client’s browse listing, change the `browsable` value to `yes`.
- If you want to allow nonauthenticated users to print to your printers, change the `guest ok` value to `yes`.
- If you want clients to be able to send files directly to the printers via the `cat` command (for example), then change the `writable` value to `yes`.
- If you do not want to allow people to print to any of the printers this machine has access to through SMB, then change the `printable` value to `no`.
- See the following section for information on how to build a print share definition from scratch.

## Building A Print Share Statement

To build a print share statement from scratch, do the following:

- If you have not already done so, log in as root to the machine whose partitions you want to offer.
- If you are not already editing the file, type "vi /etc/smb.conf" to open the Samba configuration file.
- Type "G" to go to the end of the file.
- Type "o" to open a new line at the end of the file and then enter Insert mode.
