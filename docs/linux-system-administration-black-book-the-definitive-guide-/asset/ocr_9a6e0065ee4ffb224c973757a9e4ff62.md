# **Extended grep**

The difference between the **grep** and **egrep** programs is that you can use ex-
tended regular expressions with **egrep**. An extended regular expression is ex-
pressed in this format:

```
[expression]
```

Anything between the brackets is a possible match. For example, if you want to
match the first five lowercase letters in the alphabet, then you would use the
following:

```
[abcde]
```

The most useful aspect of this command is the set of reserved extended expres-
sions listed in Table 23.4. Note that all reserved expressions are written in the
following format:

```
[[:expression:]]
```

> **TIP:** *You can say “not the specified group of characters” by placing a caret between the first two brackets: `[^[`.*

Also available are some characters in extended regular expressions that allow
you to specify repetitions. These characters are outlined in Table 23.5. You add
them at the end of an expression. For example, the following code would match
anything that was a single number, or had no number:

```
[[:digit:]]?
```

| Expression | Matches |
|---|---|
| `[[:alnum:]]` | All numbers and all lower- and uppercase letters |
| `[[:alpha:]]` | All lower- and uppercase letters |
| `[[:cntrl:]]` | Control characters |
| `[[:digit:]]` | Numbers |
| `[[:graph:]]` | All viewable characters except for the space and control characters |
| `[[:lower:]]` | All lowercase letters |
| `[[:print:]]` | All printable characters; no control characters |
| `[[:punct:]]` | All characters used to denote punctuation |
| `[[:space:]]` | All characters that produce empty space |
| `[[:upper:]]` | All uppercase letters |
| `[[:xdigit:]]` | All characters used in hexadecimal values |
