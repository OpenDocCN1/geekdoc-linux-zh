|---|---|---|
| Ctrl+6 | If you have an alternate file open, changes the view to the alternate file | Yes |

| Ctrl+R | Redoes changes that you previously used the undo command to cancel | No |

| < | Starts an operation that indents material to the left | Yes |

| C | Cuts current line into the buffer | Yes |
| dd | Deletes current line | Yes |
