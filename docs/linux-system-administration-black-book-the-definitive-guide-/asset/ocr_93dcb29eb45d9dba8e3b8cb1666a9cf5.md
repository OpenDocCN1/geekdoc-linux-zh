# ## Using KDE's RPM Tool

The KDE desktop environment offers the Kpackage tool for those who prefer to use a GUI program to handle their packages. This section is divided into various tasks you might want to do with the program.

# ### Opening Kpackage

To open Kpackage from within KDE, do the following:

+   1. Click on the K button to open the menu.
+   2. Click on the **Utilities** menu.
+   3. Click on **Kpackage** in the **Utilities** menu to open the **Kpackage** utility, as shown in Figure 4.6.

# ### Installing RPMs With Kpackage

To install an RPM using the Kpackage tool, do the following:

+   1. Click on the **Open Package** button to open the **Select Document To Open** dialog box shown in Figure 4.7.
+   2. Browse to locate the package you want to install.
