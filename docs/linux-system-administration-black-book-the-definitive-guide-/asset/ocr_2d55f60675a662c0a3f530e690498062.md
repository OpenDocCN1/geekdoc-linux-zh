# ### Opening Programs

To open the file system navigator used in the KDE GUI, do the following:

+   1.  Boot the machine.
+   2.  Log into the account containing the GUI settings you want to configure.
+   3.  If the Linux box does not automatically go into the GUI, type "startx" to start it.
+   4.  Look at the taskbar on the bottom of the screen and locate the K icon, shown earlier in Figure 1.9.
+   5.  Click on the K icon to pull up the KDE main menu, shown in Figure 1.12.
