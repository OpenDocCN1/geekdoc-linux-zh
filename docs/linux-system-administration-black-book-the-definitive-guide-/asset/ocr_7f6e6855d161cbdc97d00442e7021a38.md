**Table 15.4 Variables available when creating FTP shutdown text.**

| Variable | Purpose |
| :--- | :--- |
| %d | Specifies when all existing connections will be severed |
| %r | Specifies when all new connections will be refused |
| %s | Specifies when the system will shut down |

+   10. Finally, enter the *message*. This is the text that contains a brief informational message for the FTP server to send regarding the machine’s *shut-down*. Table 15.4 lists three special variables you can use to include additional information in the text. To have the FTP server display the text “This server is going down on *time* for maintenance” at the end of the rest of the information you have already added, you would complete the statement with the following:

```
2001 2 4 19 0 0300 0030 This server is going down on %s for maintenance.
```

+   11. Press the Esc key, and then type “ZZ” to save and close the file.
+   12. Type “/etc/rc.d/init.d/inet restart” to restart the superdaemon.
