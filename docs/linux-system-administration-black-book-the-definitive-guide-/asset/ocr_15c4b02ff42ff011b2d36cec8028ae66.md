# The Linux System Administrator's
Handy Assistant

As more and more people find themselves struggling to get their Linux systems set up and running, they often discover that after they're set up, they have a whole new set of frustrations. There are many things that a system administrator must know how to do. This book aims to ensure that you do not have to flounder through your tasks. Manage user accounts, network servers, printers, and more by using the solutions provided in the enclosed chapters. Examine the shell script and Perl program examples to learn how to better automate your tasks, and then set them up to run on a regular basis without having to start them manually. Learn how to get your C packages properly compiled and installed. Work with text files and know how to search your file system. Including coverage of Red Hat Linux version 6.2, it's all in here!

# *This book will help you:*

+   • Create and manage users and accounts
+   • Understand the workings of the ext2 file system
+   • Understand and manage permissions
+   • Add and remove floppy disks and CD-ROMS from the file system
+   • Set up disk usage quotas
+   • Properly shut down your system
+   • Install gzipped, tarred, and RPM files
+   • Apply essential system security measures
+   • Set up and analyze system logs
+   • Automate installations with KickStart
+   • Set up your master and slave web servers
+   • Set up and maintain a Sendmail mail server, an Apache Web server, a Squid caching server, and more
+   • Set up network integration services such as NIS, NFS, and Samba
+   • Write shell scripts and Perl scripts, and work with downloaded C programs
