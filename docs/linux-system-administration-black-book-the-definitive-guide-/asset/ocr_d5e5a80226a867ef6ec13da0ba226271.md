**Table 18.5 Options available for the name resolve order statement in /etc/smb.conf.**

| Option | Purpose |
| :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| bcast | Specifies to send a broadcast out on all cards listed earlier in **interface**. This broadcast looks for the host needed, and, if successful, the host returns its IP address. |
| host | Specifies to look in the /etc/nsswitch.conf file to determine whether Samba should look in /etc/hosts, or should use NIS or DNS to get the host's IP address. |
| lmhosts | Specifies to look in the file /etc/lmhosts (see the section "Creating A Host Map," later in the chapter, for details on how to set this up) to get the host's IP address. |
| wins | Asks the WINS server at the IP address specified in the **wins server** statement for the host's IP address. |
