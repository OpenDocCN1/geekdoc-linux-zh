Another type of test that you have available is to examine a file's permissions. This test is useful to ensure that files created by your script have their permissions set properly in the end even if you have changed the default permissions on your system since you wrote the script. Table 20.7 lists the permission testing operators that are available. These operators are used in this format:

```
test operator /path/file
```
