+   6. In the Destination text box, enter the network address for the network you are sending to with this definition.
+   7. Enter the netmask for this network in the Netmask text box, or choose it from the drop-down list box.
+   8. Click **Accept** to close the Route Specification dialog box. The new network route now appears in the listing.
+   9. If you have any more networks to add, return to Step 4. Otherwise, click **Quit** to close the Route To Alternate Local Networks dialog box.
