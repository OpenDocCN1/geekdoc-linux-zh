# Removing Modules Manually

To remove a loaded kernel module, do the following:

+   1. See the section "Listing Loaded Modules" for how to get a list of what modules are currently in action.
+   2. Determine which module you want to load.
+   3. Type "rmmod module" to unload the module. If there are active modules that depend on the one you are trying to remove, you will get a dependency error.
