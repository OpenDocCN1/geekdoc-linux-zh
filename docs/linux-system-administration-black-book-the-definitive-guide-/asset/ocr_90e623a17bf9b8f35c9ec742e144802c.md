# Building A CW File

To build the proper contents for your /etc/sendmail.cw file, do the following:

+   1. Log in as root on your mail server.
+   2. Type “vi /etc/sendmail.cw” to open the file for editing.
+   3. Type “i” to enter Insert mode.
+   4. Enter the alternate names for your host, one name per line. For example,
+   you might use the following for smtp.animals.org:
+   5. Press the Esc key, and then type “ZZ” to save and close the file.
+   6. Type “/etc/rc.d/init.d/sendmail restart” to restart the mail daemon.

```

pop.animals.org
stork.animals.org
```
