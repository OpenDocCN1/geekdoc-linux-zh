```
23. Within the loop, you now must test each package to see whether it is already installed. You can do this with a simple **grep** command in an **if** conditional, such as this:

```
```bash
loaded=""
loaded=`grep -c $package loadedrpms`
if [ $loaded != "" ]
    then

fi
```

```
25. Automatically loading packages just because they are available isn't recommended. Even letting the script download is suspect, because it could be a huge waste of bandwidth if you have a metered Internet connection.
```
