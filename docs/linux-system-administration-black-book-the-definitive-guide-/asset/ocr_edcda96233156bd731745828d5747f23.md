# ## Installation Issues

There are a number of items you need to keep in mind as a system administrator when it comes to system installation. These concerns boil down to the purpose the machine is meant to serve. A machine meant to be a workstation for an end user’s word processing has vastly different needs than a server meant to handle a bunch of Web sites and nothing else.

# ### Choosing Partitions

You can choose to partition your system in a number of ways. For a basic end-user system, I would usually just create a 16MB or so/boot partition, a 120MB or so swap partition, and give the rest to a root ( / ) partition. Another commonly chosen item is a /home partition, which allows you to reinstall the system later without having to wipe out everything saved in the user’s home directory.

On the other end of the spectrum are servers, whether dedicated or otherwise.
