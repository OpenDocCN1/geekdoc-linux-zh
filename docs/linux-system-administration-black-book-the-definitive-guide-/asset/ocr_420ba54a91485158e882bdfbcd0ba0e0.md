# # Building A Virtual Addressing Table

To build your virtual addressing table, do the following:

+   Log in as root on your mail server.
+   Type “vi /etc/virtualtable” to open the file for editing.
+   Type “i” to enter Insert mode.
+   Add your entries to the table in this format:

```
from:to
```

The format for the from items must be an email address (user@domain.extension) or a wildcarded full domain (@domain.extension).

+   When you are finished, press the Esc key, and then type “ZZ” to save and close the file.
+   Type “/etc/rc.d/init.d/sendmail restart” to restart the mail daemon.

# # Building An Access Database

To build your access database, do the following:

+   Log in as root on your mail server.
+   Type “vi /etc/mail/access” to open the file for editing.
+   Type “i” to enter Insert mode.
+   Add your entries in this format:

```
from      result
```

The from portion has two different sets of formats:

+   For the access_db option, you might use user@domain.extension, domain.extension, or the network portion of an IP address—for example, 192.168.15.
+   For the blacklist_recipients option, you might use user, host.domain.extension, or user@host.domain.extension.
