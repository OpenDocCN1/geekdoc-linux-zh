# 1.4.1 The Basics

To date, the Internet community has studiously avoided defining its own link protocols, and has endeavored merrily to operate one level above this, but to port the Internet Protocol software to every new link layer within hours of the technology available.

The IP protocol is therefore the global glue that keeps the Internet alive.
