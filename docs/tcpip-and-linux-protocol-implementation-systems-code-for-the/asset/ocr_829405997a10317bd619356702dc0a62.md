The forwarding table data structures in Linux are pretty sophisticated, as well as being close to state-of-the-art in efficiency.

# 8.3.4 FIB Interface

In the rtattr data structure (see Figure 8.4), we can see the generality of information that could be added in the FIB. In principle, we have source- and destination-based routing, input and output interfaces, priority, multipath, protocol-based information, and so on.

The fields are typically added into a FIB entry by a call via the RTNetlink socket, from a routing daemon, or from the superuser running the IP command, which we look at later.
