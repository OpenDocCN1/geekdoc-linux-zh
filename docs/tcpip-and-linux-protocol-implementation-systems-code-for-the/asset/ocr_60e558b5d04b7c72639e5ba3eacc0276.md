# Selective Acknowledgment–SACK

Modern TCP/IP implementations such as the one described in this book employ a selective acknowledgment mechanism known as SACK (RFC 2018). SACK employs TCP options to indicate received segments that cannot be ACked, as there would be gaps in the ACKed stream. The tcp_opt structure uses the following variables in SACK:

+   - eff_sacks—to indicate the number of sacks to send with the next packet.
- select_acks—an array of sack blocks (each sack block is simply the sequence number of the beginning and end of the block).
- dsack_sack—information about this D-SACK.

These are set by the TCP receive data functions (see Figures 7.57–7.59) and used to add options to generated packets (see Figure 7.60).
