# Window Scaling

The TCP header allows for 16 bits to decode the received window size. With ever-increasing bandwidth and distance this is no longer sufficient to keep efficiency. The TCP window scale option on synchronization allows for this value to be scaled. defined in RFC 1323. The option is only sent in SYN packets, as it is only these can be guaranteed to be carried to the receiver (see Figures 7.66–7.67).
