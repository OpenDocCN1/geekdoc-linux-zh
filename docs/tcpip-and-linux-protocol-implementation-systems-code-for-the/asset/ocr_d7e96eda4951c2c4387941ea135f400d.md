# RFCs Cited in Code

RFCs are the famous Request for Comments series of documents about the Internet protocol suite. Some are standards and some are purely informational (and some are historical or just mere entertainment). There are many points in the Linux kernel code (and elsewhere) that implementors refer to the relevant RFC. Here we give the list. See http://www.ietf.org for availability and status information about these documents and the protocols and services they describe.
