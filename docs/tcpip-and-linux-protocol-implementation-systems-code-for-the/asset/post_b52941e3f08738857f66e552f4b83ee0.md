## Deriving an IPv6 Address

Multicast address management is not so different from IPv4. There are also addresses for tunnels. Typically we build an address from a LAN interface's MAC address and a route prefix.

**Figure 6.338** Deriving EU64 bits of IPv6 address: linux/net/ipv6/addrconf.c.

```
static int ipv6_generate_ui64(struct ui *eui, struct net_dev *dev)
{
    switch (dev->type) {
        case ARPHD_FDI1:
        case ARPHD_EE8E02_TR:
            if (dev->addr_len != ETH_ALEN)
                return -1;
            memcpy(eui, dev->addr, 3);
            memcpy(eui + 5, dev->addr+3, 3);
            eui[3] = 0xFF;
            eui[4] = 0xFE;
            eui[0] |= 2;
            return 0;
    }
    return -1;
}
