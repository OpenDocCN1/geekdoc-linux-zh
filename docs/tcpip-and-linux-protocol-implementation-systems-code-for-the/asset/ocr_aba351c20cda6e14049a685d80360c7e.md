# Congestion Control

The sender's congestion window is stored in the tcp_opt structure as snd_cwnd. This is initialized in tcp_init_metrics either on receipt of a SYN segment (for a host receiving a connection) in tcp_rcv_state_process, or on acknowledgement of a sent SYN segment (for a host initiating a connection) in tcp_rcv_state_process.

The congestion window is checked, with other things, as a buffer is sent.

If the connection window is smaller than the slow-start threshold (sstresh), the connection is in slow start state. If larger, it is in congestion avoidance. The size of the congestion window increases in different ways depending on this state. Figure 7.56 shows the increase in the congestion window. This is called once per ACK from tcp_ack.
