IP addresses therefore currently identify points of connection in the Internet. The usual term used is an interface. Any interface can have (and even more than one) IP address. IP routing is the function of getting a packet from one interface across a sequence of other interfaces to a destination interface. The method is somewhat generalized in IPv6, which we discuss in Chapter 6.
