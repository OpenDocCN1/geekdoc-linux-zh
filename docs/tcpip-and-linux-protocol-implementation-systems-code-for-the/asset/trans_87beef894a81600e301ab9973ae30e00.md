# 5.4.3 特定设备驱动–3c01

这是一个来自 Linux 2.4 的 3Com 以太网驱动。这是一个非常老的设备，但它具有足够的智能来显示某些功能。事实上，它的局限性意味着驱动程序必须进行一些工作。

基本上，我们通常映射 I/O 地址，然后网卡有一些用于控制和状态的寄存器——在这种情况下我们可以从网卡读取所有地址（例如）。
