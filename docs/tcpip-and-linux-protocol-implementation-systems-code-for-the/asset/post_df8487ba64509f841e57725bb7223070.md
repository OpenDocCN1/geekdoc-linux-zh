{
    struct tc_u_common *tp_c = tp->data;
    struct tc_u_node *ht;
    struct tc_u_node *n;
    unsigned h;
    if (arg->stop)
        return;
    for (ht = tp_c->hlist; ht; ht = ht->next)
        if (arg->count >= arg->skip)
            if (arg->fn(ht, (unsigned long)ht, arg) < 0) {
                arg->stop = 1;
                return;
            }
    arg->count++;
    for (h = 0; h < ht->divisor; h++)

            if (arg->count >= arg->skip)

* mask may be exact, or wildcard, so that we can keep a hash table one entry.
* source port (or flow label) is important if src is given.

IMPLEMENTATION.
We use two level hash table: The top level is keyed by destination address and protocol, every bucket contains a list of "RSVP sessions", identified by destination address, protocol and "Destination Port ID": (key, mask, offset).

Every bucket has a small hash table keyed by source address (RSVP flows) and one entry for reservations. Every bucket is again a list of "RSVP flows", selected by source address and "Source Port ID" here than "security parameter index": (key, mask, offset).

NOTE 1. All the packets with IPv6 extension headers (but AH and ESP) and all fragmented packets go to the best-effort class.

NOTE 2. Two "port id" seems, rfc2207 requires only "Generalized Port Identifier". So that for esp (and udp) both could coincide or one of them should be wildcard.

NOTE 3. One complication is the case of tunneled. We implement it as follows: if the first lookup matches a special session with "tunnelhdr" value not zero, doesn't contain the true ID, but the tunnel (1...256). In this case, we pull tunnelhdr by restart with tunnel ID added to the list of keys. Simple and stupid for IP.
