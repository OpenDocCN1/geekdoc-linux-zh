As described, the lookup in the FIB essentially returns one or more
ext hops—the case for multiple next hops is generally currently only when we
have multipath routing operating, when traffic is balanced over more than
one link. We can see the different metrics and other parameters that need to be
 for some types of lookup, such as protocol, preference, and priority;
and then there are a number of internal management fields, as the tree
reference, client reference, liveness (fib_dead), and flags fields.
