Then we need the inverse of this to deal with tearing things down (either explicitly or after process exits).

# Figure 5.70 Socket glue–shutdown: linux/net/socket.c.

```
/*
 * Shutdown a socket.
 */

asmlinkage long sys_shutdown(int fd, int how)
{
    int err;
    struct socket *sock;

    if ((sock = sockfd_lookup(fd, err))!=NULL)
    {
        err = sock->ops->shutdown(sock, how);
        sockfd_put(sock);
    }

    return err;
}
```
