IPC (interprocess communication). Mechanism such as sockets.

IPSec (Internet protocol security). Term for both architecture and mechanisms.

IPX. Novell network layer 3 protocol.

IPv4, IPv6. Main two versions of IP extant.

IRQ (interrupt request). Logical channel for interrupt from a device on PC hardware.

ISP (Internet service provider). Generic term for organizations and companies that provide carriage for IP.

ISR (interrupt service routing). Software handler for dealing with interrupts.

ITU (International Telecommunication Union). Standards body for telecommunications.

Killer reservation problem. The killer reservation problem describes a case where a receiver attempting and failing to make a large QoS reservation prevents smaller QoS reservations from being established.

LAN. Local area network.

LIH (Logical Interface Handle). The LIH is used to deal with non-RSVP clouds.

LILO (Linux Loader). The first disk bootstrap program for Linux.

Linux. Linux is not UNIX, fairly.

Local repair. Allows RSVP to rapidly adapt its reservations to changes in routing.

LRU (last-recently used). Cache replacement strategy.
