# 8.4.1 Dense Mode, Data-Driven Multicast Routing

The routers comprise to deliver packets to sites where there are members. In the simplest approach, not used much nowadays, but illustrative of a neat idea, the path from sender to receivers is built in a *data-driven* manner. As soon someone sends an IP destined packet, the routers deliver it out all interfaces except the shortest path back towards the sender (i.e., the interface it came in, although an RPF check be performed to eliminate loops for packets that traverse a network while the routing is settling down after a change). In this approach, the packets would flood everywhere in the Internet, which is big nowadays. If there were more than a very modest number of multicast sources, this would be a very bad idea indeed.
