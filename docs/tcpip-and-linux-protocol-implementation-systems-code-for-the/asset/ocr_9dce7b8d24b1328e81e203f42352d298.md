Table 4.5 TCP Sysctls
| TCP | PURPOSE |
| tcp_window_scaling | enable RFC 1323 TCP window scaling |
| tcp_sack | enable RFC 2018 TCP SACK |
| tcp_timestamps | enable RFC 1323 TCP timestamps |
| tcp_fin_timeout | dally before FIN, before forcing socket closed |
| tcp_keepalive_probes | maximum TCP keep-alive probes |
| tcp_keepalive_time | seconds before sending probe on idle connection |
| tcp_max_ka_probes | how many keep-alive probes are sent |
| tcp_stdurg | enable the strict RFC 793 interpretation of the TCP urgent-pointer field |
| tcp_synccookies | enable TCP cookies-thekernel must be compiled with CONFIG.SYN_COOKIES—Chapter 10 |
| tcp_max_syn_backlog | length of the per-socket backlog queue |
| tcp_retries1 | max count of SYN ACK retransmit |
| tcp_retries2 | max count for retransmit data packet in established connection |
| tcp_syn_retries | max count for SYN (re)tries |
| tcp_retrans.collapse | try to send full-size packets during retransmission |

Also, there are socket-level parameters. See Table 4.6.

Table 4.6 TCP socksock Options
| TCP-SPECIFIC SETSOCKOPT | PURPOSE |
| TCP_NODELAY | disable the Nagle algorithm packets are always sent as soon as possible |
| TCP_MAXSEG | confire the MSS for a connection |
| TCP_CORK | toggle sending of partial frames–almost opposite of Nagle |
