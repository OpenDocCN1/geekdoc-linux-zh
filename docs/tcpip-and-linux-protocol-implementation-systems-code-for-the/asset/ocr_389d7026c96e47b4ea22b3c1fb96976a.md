tcp_transmit_skb is the function that builds the TCP header, including any option fields, eventually checksuming the packet via the tp->af_specific->send_check() call, which maps to tcp_v4_send_check, and transmitting the buffer with tp->af_specific->queue_xmit(skb), which is actually ip_queue_xmit.
