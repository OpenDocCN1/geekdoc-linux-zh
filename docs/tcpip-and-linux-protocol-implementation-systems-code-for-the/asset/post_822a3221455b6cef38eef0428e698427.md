int sock_wake_async(struct socket *sock, int how, int band)
{
    if (!sock || !sock->fsasync_list) {
        return -1;
    }

        case 1:

## Bind, Listen, Accept

All of these functions are associated with the process of binding one or the other end of a connection to an identifier (effectively an IP address) or an active protocol association (i.e., transport-level connection). bind() takes the socket and associates the local end of it with an address (typically, the IPv4 or IPv6 address).

 * Bind a name to a socket. Nothing much to do here since it's

 * the protocol layer (having also checked the address is ok).

asmlink sys_bind_int(int fd, struct sockaddr *ummaddr, int addlen) {
    struct socket *sock;
    char address[MAX_SOCKDR_ADDR];

    int err;
