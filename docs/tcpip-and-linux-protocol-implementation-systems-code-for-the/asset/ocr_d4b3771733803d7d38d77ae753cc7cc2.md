# 9.6.2 Class-Based Queuing

As well as organizing scheduling with a traffic class, we need to have a way of
managing a set of different traffic classes, potentially with a range of different,
appropriate scheduling algorithms. There are two specific approaches to this
commonly today, and Linux supports both within a more general framework, as
we will see later. One is class-based queuing (CBQ), and the other is the so-called
Clark/Shenker/Zhang architecture (after the three well-known researchers who
devised it).
