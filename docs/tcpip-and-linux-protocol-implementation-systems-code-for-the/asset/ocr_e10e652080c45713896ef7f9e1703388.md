As described before, the final result after the long smart haul of looking up a forwarding information base entry is the next hop. This data structure (see Figure 8.5) is relatively simple; either we are told the IP address of the next hop gateway, or output device—the output device is all that is needed we have a point-to-point link, for example, where the actual IP address of the next hop is irrelevant. Linux also supports multipath routing, where we can load balance traffic across several links. It also indicates the distance (scope) to the destination.
