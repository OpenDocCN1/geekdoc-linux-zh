# # 4.4.1 Polling a Socket

It is often useful to check if data is available on an interface without actually waiting until it is. This is known as polling. The way it is done from the UNIX filesystem and socket API is via the select() system call. This takes a mask parameter that allows one to poll several file descriptors simultaneously. This is very useful for programs that wish to provide the appearance of concurrent user interface and network I/O, for example, network management programs, or networked graphics.
