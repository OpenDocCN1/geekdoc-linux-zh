# # 1.5 Security

Security concerns discussed above briefly can be expanded on a little, although, as we said, it really is important to be well educated about cyber-crime-prevention. Typical questions to ask yourself before hooking up a machine to the Net include:

+   - Who can use your computer?
- Who can use your network?
- Whose computer can you use?
- Whose network can you use?
- Access control, privacy, depend on protocols.
- Authentication protocols plus encryption techniques.

This course still leaves denial-of-service and traffic pattern analysis. The best defense against these may be to invoke a different model of costs, such as performance management through pricing. We will look at this next.

# # 1.6 Performance
