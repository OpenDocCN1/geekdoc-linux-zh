# # 9.14 Managing Forwarding Treatment / Information–the TC Command

Linux now has sophisticated (and complex) traffic control facilities—these could be managed through some distributed resource reservation or traffic engineering algorithm, or manually set up at each site. The TC command is an application that lets you configure the facilities on a specific Linux system.

# # 9.14.1 Traffic Control–Using the Tool

```
#!/bin/sh
TC=/src/iproute2/tc
DEV="deveth0"
efrate="2Mbit"
```
