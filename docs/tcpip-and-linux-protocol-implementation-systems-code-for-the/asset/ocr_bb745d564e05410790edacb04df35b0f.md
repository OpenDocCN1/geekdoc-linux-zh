# 7.2 Introduction

Transport protocols handle the end-to-end transfer of data between two IP-connected hosts. Each packet created by the transport layer is addressed to the destination host, and transported by the network layer. Higher-layer protocols and services will make use of the transport layer to transport their protocols. Recall from Chapter 6 that the network layer (and below) devices, such as switches and routers, store state about connections established or flows traversing through them. So any state information needed to maintain communication must be stored by the end system hosts.

# 7.3 UDP–User Datagram Protocol

UDP is much simpler than TCP, so we will discuss its operation first.

# 7.3.1 Introduction

UDP is a connectionless, unreliable datagram service. This means that there is no connection information maintained and therefore each packet carries its own addressing information. By unreliable we mean:

+   - There is no guarantee that the data will be received by the destination process.
- If it is received it may contain errors.
- That packets arrive out of sequence, i.e., in a different order from the one in which they were transmitted.

UDP provides a multiplexing service over the basic IP functionality, and a simple form of error detection.
