As explained in Chapter 2, the socket code is yet another variant of the virtual filesystem API, it must provide the mappings for the generic functions therein. These are wrapped up in the file_operations structure.

Figure 5.51 Socket interface code-file operation mappings, and so on: linux/net/socket.c.

