# Bind, Listen, Accept

All of these functions are associated with the process of binding one or the other end of a connection to an identifier (effectively an IP address) or an active protocol protocol association (i.e., transport-level connection).

bind() takes the socket and associates the local end of it with an address (typically, the IPv4 or IPv6 address).
