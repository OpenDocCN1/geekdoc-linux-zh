Figure 5.152 Inline functions for socket reference management: linux/include/net/sock.h.

```
static inline void sock_hold(struct sock *sk)
{
    atomic_inc(sk->refcnt);
}
/* Ungrab socket in the context, which assumes that socket reference
cannot hit zero, f.e. it is true in context of any socketcall. */
static inline void _sock_put(struct sock *sk)
{
    atomic_dec(sk->refcnt);
}
/* Ungrab socket and destroy it, if it was the last reference. */
static inline void sock_put(struct sock *sk)
{
    if (atomic_dec_and_test(sk->refcnt))
        sk_free(sk);
}
```
