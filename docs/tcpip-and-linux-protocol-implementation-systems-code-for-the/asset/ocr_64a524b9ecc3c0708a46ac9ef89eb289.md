However, the vast bulk of the hardware-specific code is in the device support, which is where things are necessary processor-, bus-, and I/O architecture-dependent in any case, so this is not of any concern.

There are some parts of the low-level memory management, time management, and scheduler that have some assembler and a few C code routines that need attention when moving to another hardware platform.
