# 2.2.3 MultiDevice

Modern computers support a massive range of devices. As well as traditional keyboards, screens, and storage devices, we have a range of network interface types, including fixed and wireless, and a number of multimedia devices (audio, video capture, 3D, and so on).

At the lowest level, the operating system needs to manage input and output from and to these devices. There is a surprising amount of commonality in the functions required to match the OS to the different hardware.

A large percentage of the code associated with any operating system is so-device driver code. Device drivers hide the specifics of a piece of hardware to control an I/O device, and provide the standard systems and application programming interfaces to the device, translating between the generic model and any idiosyncrasies of a specific device may possess. Of course, particular hardware configuration only needs drivers for the devices it possesses. Linux supports the concept of modules, which allows on-demand dynamic loading of code for operating system components as device drivers, which makes it more economical on memory.

All UNIX systems identify the kind of device by a unique number called the major number and its minor number. Major numbers are allocated by an authority, although free ones can be used by configuration or as needed, while minor numbers are allocated as needed by the system or by configuration (e.g., through knmod).

Linux devices divide into three basic classes:

Character. These devices are typically serial lines (traditionally for keyboard-type input), but also parallel interfaces, mouse, sound cards, frame buffers, and so on. The main emphasis here is on interaction with humans and external machines.

Block. These are for storage-type devices (floppy, hard, and optical disks). Most importantly, these support file systems.

Network. This special case where Linux differs from other UNIX-like systems in its treatment of these distinct device type, and as networking is the main topic of this book, this is discussed in detail later. What makes devices similar? The ability to read and write data to a device is the common strand. What makes devices different? A number of things, ranging from performance (data rate, latency, and so on), through intelligence (dumb keyboards, smart audio, and network cards, and so on), and most importantly management and control complexity.
