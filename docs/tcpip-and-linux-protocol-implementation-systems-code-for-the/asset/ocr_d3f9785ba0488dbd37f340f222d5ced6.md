# 3.4 RTP/UDP (Multicast) Example

For multicast, higher-level protocols are built on top of UDP, so we again
need to look in udp.c.

Sending is the same as for unicast, the receiver case has to handle the
chance that there is more than one process waiting for copies of a multi-
cast packet, is receiving a tail different, as we can see in udp.v4_mcast_
deliver().

Figure 3.15 UDP receive multicast: linux/net/ipv4/udp.c.

```
read_lock(&udp_hash_lock);
sk = __udp_hash[ntoh(uh->dest) & (UDP_HTABLE_SIZE - 1)];
dif = skb->dev->ifindex;
skb = udp_v4_mcast_next(sk, uh->dest, uh->source, saddr, dif);
if (skb) {
    struct sock *skb = NULL;
    do {
        struct skb *skb1 = skb;
        next = udp_v4_mcast_next(sk, uh->dest, daddr, dif);
        uh->source, saddr, dif);
        if (skb1) {
            skb = skb_clone(skb, GFP_ATOMIC);
            udp_queue_rcv_sk(sk, skb1);
            skb = next;
    } while (next);
} else
free_skb(skb);
read_unlock(&udp_hash_lock);
```
