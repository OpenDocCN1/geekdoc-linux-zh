# rtnetlink API

rtnetlink messages consist of a netlink message header and appended attributes. There is a set of convenient macros for accessing the attributes.

```
rtnetlink_socket = =
    socket(PF_NETLINK, int socket_type, NETLINK_ROUTE);

    int RTA_OK(struct rtattr *rta, int rtabuflen);
    void RTA_DATA(struct rtattr *rta);
    unsigned int RTA_PAYLOAD(struct rtattr *rta);
    struct rtattr RTA_NEXT(struct rtattr *rta, unsigned int
    rtabuflen);
    unsigned int RTA_LENGTH(unsigned int length);
    unsigned int RTA_SPACE(unsigned int length);
```

Here is an example of the use of creating a rtnetlink message to set an MTU of a device:

```

    struct ifinfomsg if;
```

Some rtnetlink messages have optional attributes after the initial header:

```
struct rtattr {
    unsigned short rta_len; /* Length of option */
    unsigned short rta_type; /* Type of option */
    /* Data follows */
\};
```
