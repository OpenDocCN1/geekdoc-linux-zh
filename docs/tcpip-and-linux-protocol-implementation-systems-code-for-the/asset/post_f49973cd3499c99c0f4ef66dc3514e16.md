Random early detection is one of several scalable queue management techniques.

47 /* Random Early Detection (RED) algorithm.
48
50
51 Source: Sally Floyd and Van Jacobson, "Random Early Detection Gateways
52 for Congestion Avoidance", 1993, IEEE Transactions on Networking.
53
54 This file codes a "dimensionless" version of RED algorithm
55 as written down in Fig.17 of the paper.

57 Short description.
58
59
60 When a new packet arrives we calculate the average queue length:
61
62 avg = (1-W)*avg + W*current_queue_len,

# 816 TCP/IP and Linux Protocol Implementation

Figure 9.250 RED queue-behavior: linux/net/sched/sch_red.c.

```c
if (avg > th_max) -> packet marked (dropped).
if (avg < th_min) -> packet passes.
if (th_min < avg < th_max) we calculate probability:
Pb = max_P (avg - th_min)/(th_max-th_min)

and mark (drop) packet with this probability.
Pb changes from 0 (at avg=th_min) to max_P (avg=th_max).
max_P should be small (not 1), 0.01..0.02 is good value.

max_P is chosen as a number, so that max_P/(th_max-th_min)
is a negative power of two in order arithmetics to contain
only shifts.

Parameters, settable by user:

limit - bytes (must be > qth_max + burst)

Hard limit on queue length, should be chosen >qth_max to allow packet bursts. This parameter does not
affect the algorithms behaviour and can be chosen
arbitrarily high (well, less than ram size)
Really, this limit will never be reached
if RED works correctly.
```

Figure 9.251 RED queue-parameters: linux/net/sched/sch_red.c.

```c
qth_min - bytes (should be < qth_max/2)
qth_max - bytes (should be at least 2*qth_max and minimum limit)
Wlog - bits (<32) log(1/W).
Plog - bits (<32)
Plog is related to max_P by formula:

max_P = (qth_max-qth_min)/Plog;

e.g. if qth_max=128K and qth_min=32K, then Plog=32
corresponds to max_P=0.02.

Scell_log Lookup table for log((1-W)^(t/avg)).
```

If you want to allow bursts of L packets of size S, you should choose W:
th_min/S < (1-W)^L/log(W)
