# 9.2.2 Admission Test for Integrated Services Guaranteed Service

$d = \frac{b}{g} + (N-1)\frac{P_F}{g} + N\frac{P_N}{r} \quad (9.1)$

One example of this requirement is illustrated in Figure 9.1, which plots the capacity needed for typical 64 Kbps PCM-coded voice calls packetized using RTP and a range of typical Internet line speeds, a delay bound as needed for interactive voice, and the over-allocation needed. Note the presence of hop count as part of the equation.

Table 9.1 Terms in the Parekh TCP Equation

| $d$ | worst-case delay |
| $b$ | token bucket size |
| $g$ | allocated rate |
| $N$ | hopcount |
| $P_F$ | this flow maximum packet size |
| $P_N$ | network's maximum packet size |
| $r$ | link speed |
