33 /* This code is NOT INTENDED to be used for statistics collection,
34    its purpose is to provide a base for statistical multiplexing
35    for controlled load service.
37    If you need only statistics, run a user level daemon which
38    periodically reads bytes counters.

40 Unfortunately, rate estimation is not a very easy task.
41 F. I did not find a simple way to estimate the current peak rate
42 and even failed to formulate the problem 8)8

44 So I preferred not to build an estimator into the scheduler,
45 but run this task separately.

46 Ideally, it should be kernel thread(s), but for now it runs
47 from timers, which puts apparent top bounds on the number of rated
48 flows has minimal overhead on small, and is enough
50 to handle controlled load service, sets of aggregates.

52 We measure rate over A=(1<<1) seconds and evaluate EWMA:

```
54 avrate = avrate*(1-W)+ rate=W
```

56 where W is chosen as negative power of 2: W = 2^(-ewma_log)

58 The resulting time constant is:

```
59 T = A/-ln(1-W)
```
