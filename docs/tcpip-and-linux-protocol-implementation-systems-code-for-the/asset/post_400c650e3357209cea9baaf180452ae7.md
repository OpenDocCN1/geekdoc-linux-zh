Note: we do not use gettimeofday.
The reason is that, when it is not the same as gettimeofday, it returns invalid timestamp, which is not updated, when net_hb is active.

So, use PSCHED_CLOCK_SOURCE = PSCHED_CPU on alpha and pentiums with rtsc. And PSCHED_JIFFIES on all other architectures, including x86 and pentiums without rtsc.

You can use PSCHED_GETTIMOFDAY on another architectures, which have fast and precise clock source, but it is too expensive.
