address. Configure or list address(es) of an interface/device.

This can be used by ip address add { [dev <name>| local <address>] | peer <address> [default] | broadcast <address> | label <name> | scope <scope value> }

Here the only new scope is scope, which can be global, site, or host.

neighbor. Setup or examine an ARP entry or neighbor cache information.

For example, ip neighbor add {to <address> | dev <name> | nud <state> }. Here the only non-obvious parameter is nud, which refers to a "neighbor unreachable detection" and allows you to configure the way in which the system decides (or doesn't decide) a neighbor has become unreachable.
