# **IP Reference Table and Subnetting Charts**

The IP reference table and subnetting charts in Tables A.1–A.4 can be used for quick stats and calculation values. Subnet numbers and hosts can be obtained quickly via subnet mask bit count. For your convenience, the major IP Address classes have been categorized.
