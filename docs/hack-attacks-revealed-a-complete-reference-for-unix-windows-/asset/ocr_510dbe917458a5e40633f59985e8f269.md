# Covering Keylogging Trails

Hackers commonly use cloaking software to completely cover their tracks from a successful intrusion. Programs in this category are designed to seek out and destroy logs, logger files, stam ps, and temp files. One example is cloaker.c, originally by hacker guru Wintermute.
