# Liabilities

Complete Denial-of-Service Attack

**Synopsis:** The firewall crashes when it detects packets coming from a different MAC address with the same IP address as itself.

**Hack State:** System crash.

**Vulnerabilities:** 3x, 4x

**Breaching:** The firewall crashes when it detects packets coming from a different MAC address with the same IP address as itself. With *Checkout.c* by hacker guru lore, the program simply sends a few spoofed UDP packets to the target firewall interface.
