## Reboot

**Synopsis:** Remote attack that reboots almost any Linux x86 machine.

**Hack State:** System halt/reboot.

**Vulnerabilities:** All flavors.

**Breach:** Reboot.asm.

    int $0x80

    movb $0x01,%al
