# Vulnerabilities: Version 5.5.

**Breach:** If an attacker knows an IP address that will be routed through a Gauntlet Firewall, he or she can remotely lock up the firewall so that one packet will disable progression on Spares, and three to five packets will disable Ctrl-Alt-Del on BSDI.
