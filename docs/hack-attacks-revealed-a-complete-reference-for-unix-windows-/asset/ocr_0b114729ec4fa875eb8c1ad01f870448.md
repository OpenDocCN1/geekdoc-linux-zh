Port: 1170, 1509

Service: Psyber Stream Server, Streaming Audio Trojan

Hacker's Strategy: These daemons were designed for a unique particular purpose: to send streaming audio to the victim. An attacker with a successful implementation and connection can, essentially, say or play anything through the target's speakers.

Port: 1234

Service: Ultors Trojan

Hacker's Strategy: Ultors is another telnet daemon designed to remotely execute programs and shell commands, to control running processes, and to reboot or halt the target system. Over time, features have been added that give the attacker the ability to send messages and display common error notices.
