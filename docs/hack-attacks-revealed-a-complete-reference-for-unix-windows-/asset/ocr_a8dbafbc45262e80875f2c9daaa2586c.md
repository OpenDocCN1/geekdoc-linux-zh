+   1.  **ls** List the files in a directory.  
+   2.  **mail** Send/receive mail.  
+   3.  **mkdir** Make directory.  
+   4.  **more** Display data file.  
+   5.  **mv** Move or rename a file.  
+   6.  **nohup** Continue running a command after logging out.  
+   7.  **nroff** Format text.  
+   8.  **passwd** Change password.  
+   9.  **pkgadd** Install a new program.  
+   10. **ps** Lists the current running processes.  
+   11. ***pwd*** Display the name of the working directory.  
+   12. ***rm*** Remove file.  
+   13. ***rmdir*** Remove directory.  
+   14. ***set*** List shell variables.  
+   15. ***setenv*** Set environment variables.  
+   16. ***sleep*** Pause a process.  
+   17. ***source*** Refresh and execute a file.  
+   18. ***sort*** Sort files.  
+   19. ***spell*** Check for spelling errors.  
+   20. ***split*** Divide a file.  
+   21. ***stty*** Set terminal options.  
+   22. ***tail*** Display the end of a file.  
+   23. ***tar*** Compress all specified files into one file.  
+   24. ***touch*** Create an empty file.  
+   25. ***troff*** Format output.  
+   26. ***tset*** Set terminal type.  
+   27. ***umask*** Specify new creation mask.  
+   28. ***uniq*** Compare two files.  
+   29. ***uucp*** UNIX to UNIX copy/execute.  
+   30. ***vi*** Full-screen text editor.  
+   31. ***volcheck*** Check for mounted floppy.  
+   32. ***wc*** Displays detail.  
+   33. ***who*** Show current users.  
+   34. ***write*** Send a message to another user.
