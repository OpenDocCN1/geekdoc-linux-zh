# **Remote Controllers**

With advanced collaboration such as email, chat, FTP, and HTTP downloads, several programs in circulation make any virus seen to date seem like harmless child's play. These programs allow anyone on the Internet to remotely control a network server or personal computer. They can collect all passwords, access all accounts (including email), modify all documents, share a hard drive, record keystrokes, look at a screen, and even listen to conversations on a computer's microphone. The icing on the cake is that the victim never knows it's happening.

# **Sniffers**

Sniffers are software programs that unobtrusively monitor network traffic on a computer, picking out whatever type of data they're programmed to intercept, such as any chunk containing the word "password."
