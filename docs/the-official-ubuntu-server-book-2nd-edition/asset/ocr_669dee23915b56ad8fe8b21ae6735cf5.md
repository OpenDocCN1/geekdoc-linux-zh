The first step is to set up a default preseed.cfg file. Below is a basic preseed file that describes a default Ubuntu server install for a system in the United States. Copy these settings into a file named preseed.cfg:

```
## Options to set on the command line
d-1 debian-installer/locale string en_US
d-1 console-setup/ask_detect boolean false
d-1 console-setup/layoutcode string us
d-1 netcfg/get_hostname string unassigned-hostname
d-1 netcfg/get_domain string unassigned-domain

d-1 netcfg/choose_interface select auto
d-1 netcfg/wireless_wep string

d-1 base-installer/kernel/override-image string linux-server
d-1 clock-setup/utc-auto boolean true
d-1 clock-setup/utc boolean true
d-1 time/zone string US/Pacific
d-1 clock-setup/ntp boolean true

d-1 mirror/country string US
d-1 mirror/http/proxy string
d-1 pkgsel/install-language-support boolean false
d-1 pkgsel/update-policy select none
tasksel tasksel/first multiselect standard, ubuntu-server

d-1 partman-auto/method string regular
d-1 partman-auto/purge_lvm_from_device boolean true
d-1 partman-lvm/confirm boolean true
d-1 partman-auto/choose_recipe select atomic
d-1 partman/confirm_write_new_label boolean true
d-1 partman/choose_partition select finish
d-1 partman/confirm boolean true
d-1 passwd/user-fullname string Ubuntu User
d-1 passwd/username string ubuntu
d-1 passwd/user-password password insecure
d-1 passwd/user-password-again password insecure
user-setup/udeb user-setup/encrypt-home boolean false

d-1 grub-installer/only_debian boolean true
d-1 grub-installer/with_other_os boolean true
d-1 finish-install/reboot_in_progress note
```
