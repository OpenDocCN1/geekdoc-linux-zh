# Summary

Switching to a new system can be overwhelming. Using an established system is not a guarantee that you will never have questions. In each instance, there are times when support is needed. This chapter described several wonderful options. For further information, check the official Ubuntu Web site for the most up-to-date list of support options at www.ubuntu.com/support.
