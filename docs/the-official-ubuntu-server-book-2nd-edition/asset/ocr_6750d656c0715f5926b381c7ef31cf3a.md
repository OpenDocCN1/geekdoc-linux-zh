# ## Avoid That grep Command in grep Output

One of the main ways I use grep is when I am looking for a particular process on the system. The problem is that the grep command itself always seems to match and shows up in the output:

```
```bash
$ ps -ef | grep bash
kyle  982  2077  0 19:50 pts/2    00:00:00 grep bash
kyle  2077  6668  0 Apr06 pts/2    00:00:01 bash
kyle  6859  6668  0 Apr03 pts/1    00:00:00 bash
```
```

As you can see here, I have two valid bash processes running, but I get the grep command in my output as well. That can be annoying if you want to count the number of Apache processes on the system, for instance, as you always have to subtract one for the grep command—that is, unless you surround the first character of your keyword with brackets:

```
```bash
$ ps -ef | grep [b]ash
kyle  2077  6668  0 Apr06 pts/2    00:00:01 bash
kyle  6859  6668  0 Apr03 pts/1    00:00:00 bash
```
