# Tip

Seeing "Find codec" dialog on your Ubuntu system generally means that you didn't install the ubuntu-restricted extras package and all of the GStreamer plugin-ins that I recommended earlier in this chapter. You may want to do that before proceeding, especially if you're trying to burn CDs from audio files in a variety of formats.
