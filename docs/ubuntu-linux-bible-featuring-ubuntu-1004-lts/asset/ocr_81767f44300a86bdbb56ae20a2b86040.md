# Chapter 30: Setting Up a Mail Server

+   - postfix: Documentation for the Postfix mailer, installed in /usr/share/doc/ postfix and /usr/share/doc/postfix
- postgrey: A greylisting implementation for with Postfix. Greylisting causes incoming mail requests to be rejected the first time that they arrive, but accepted when the remote mail system deliver them a second. Many spammers try to deliver mail only once, so this simple utility can significantly reduce the amount of spam that your site receives.
- qpopper: A package that enables users to read their mail remotely, using the POP/POP3 protocol that is used by most MUAs

You don't have to install all of these, of course, but I'm going to assume that these are all installed in subsequent sections of this chapter.

Although the way in which you install applications is up to you, I suggest that you use Aptitude to take advantage of its ability to install packages as well as the basic packages required to run and support the Postfix mail server and related applications on your Ubuntu system. System and Aptitude will install all required packages but not get all of the bells and whistles associated with some of the recommended packages for Postfix. To install the Postfix mail server and related applications from the command line using Aptitude, execute the following command:

```
$ sudo aptitude -y -r install postfix postfix-doc postgrey \
mailscanner longterm qpopper clamav
```

Installing all of these packages, their dependencies, and recommended packages will require around 65 MB of disk space. After being prompted for your password, installation will begin without confirmation (because of the -y option), and away we go!

# Built-In Postfix Configuration Models

Regardless of whether you are installing Postfix and friends from the command line or graphically, you will be required to select a default configuration model during the installation process. Five different configuration models are built into the Postfix package, each of which sets up the Postfix configuration files in a certain basic way. The following are the configuration models:

+   - Internet site: Mail will be sent and received directly from this machine using SMTP Postfix. This is the default choice, and is probably the right choice if you are configuring an incoming and outgoing mail server for your domain and have a direct connection to the Internet.
- Internet site smarthost: This machine either receives mail directly from the Internet or from another machine using a utility as fetchmail, but sends mail through another mail server.
