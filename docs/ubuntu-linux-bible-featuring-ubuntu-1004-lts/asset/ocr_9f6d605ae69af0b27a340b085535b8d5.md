# Chapter 8: Surfing the Web with Firefox

The search dialog enables you to search for one or more words in the titles and descriptions of available add-ons. You can restrict your search to a specific category by selecting that category from the dropdown category menu in the search bar. For example, Figure 8-24 shows a search for add-ons containing the word Theme in the "Themes" category. (I searched for the word Theme because this category also contains appearance-related extensions.)

You can scroll through this list to see the available add-ons that match your search term. A deactivated add-on at the right displays if a given add-on is incompatible with your version of Firefox. A green "Add to Firefox" button displays to the right of any add-on that you can install in your version of Firefox.
