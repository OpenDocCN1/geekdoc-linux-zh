# Getting a Different Install CD

If your x86 system boots from the hard drive even the correct CD is present, you'll need to modify the boot order in BIOS settings. The boot order is the sequence in which available devices are searched for bootable disks when your system is powered on. To do this, turn your computer on, and press the key on your keyboard that gives you access to the BIOS. This is typically the Delete or F2 key for most systems, but the key that you need to press is usually identified at the bottom left of your screen.

Depending on the type of BIOS your computer uses, boot order are usually stored in an Advanced Settings or Boot menu, which you can navigate using the arrow keys on your keyboard. Press Return to display this screen once the "First Boot Device or CD Drive" is highlighted, and see the Help messages at the right of the screen for information about how to make your CD the first boot device. You can then press the Esc (Escape) key to exit this screen, and press F10 to save the new settings, exit the BIOS settings, and reboot.

# Booting from a Server or Alternate CD

Booting from an Ubuntu Server or Alternate CD is as easy as inserting the appropriate CD into your system, restarting your system, and telling the system to boot from the CD drive instead of the hard drive.

# Install Options on the Server Install CD

As you might guess, the Ubuntu Server Install CD is intended for installing Ubuntu on a system that may be rack-mounted systems that use a system console rather than a graphical monitor, Ubuntu Server installations do not include a graphical user interface such as a Windows system manager or desktop as GNOME. Not installing these graphical-related packages by default reduces the amount of disk space required for a basic installation and also reduces the amount of software that you have to keep up-to-date.
