# Burning CDs Using Basero

GNOME's Basero application makes it easy to create audio CDs from selected audio files on your system or create data CDs that contain files and directories from your system for backup or portability purposes. This section focuses on creating audio — the steps for creating data CDs are much the same, although you must specify that you are creating a data CD using the Project ☮ New Project ☮ New Data Project item.

# Creating Audio CDs with Basero

Basero is one of the options that Ubuntu provides in the dialog shown in Figure 16-5 when you insert a blank CD. If you don not see this dialog, you can start Basero by right-clicking on the "Blank CD-R Disk" icon and selecting "Open with Basero Disc Burning," or by selecting the Applications Sound & Video ☮ Basero Disc menu item.

Basero initially displays a main screen that enables you to specify the type of audio or video CD that you want to create. To create an audio CD, click "Audio project" (or select the Project ☮ New Project ☮ New Audio Project menu command). This displays the dialog shown in Figure 16-16.

To add files to your new audio CD, click the Add icon (plus sign) to browse a directory that enables you to navigate to the location where your audio files are stored. You can easily add them to the CD by selecting one or more files and clicking Add. As with other graphical applications, you can select multiple tracks at time using Ctrl+leftclick or Ctrl+Shift to select a range of songs.

As you add tracks to your Basero, Basero checks each track to ensure that it knows how to convert a track in a format that the raw audio format is used on CDs. If it does not recognize the format of a track or doesnt have a codec to handle that audio format, Basero displays an error log that says Gstreamer not know how to handle the specified file format, and displays another dialog that offers to look for a suitable codec for you, as shown in Figure 16-17.
