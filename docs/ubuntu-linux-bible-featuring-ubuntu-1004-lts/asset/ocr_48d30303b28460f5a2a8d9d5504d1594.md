# Alternate DHCP Servers.

The Ubuntu repositories provide several DHCP servers in addition to the one that I suggested installing. One or the other of these may be better suited to your network configuration. Also, thanks to the fact that DHCP is, indeed, a standard, all DHCP servers use the same configuration commands. They may use different configuration files, but the commands that these files contain are the same across all DHCP servers. The following are optional DHCP servers available for Ubuntu users:

+   - dnsmasq: A small-footprint DNS server (and proxy) that can also act as a DHCP server. I don't recommend this package as your primary DHCP server unless you have a specific reason not to BIND, BIND is the standard, and most popular, DNS server. However, with its DHCP server support, dnsmasq can be quite useful on laptops because of its DHCP caching capabilities. See Chapter 32 for more information about BIND.
- udhcpc: A very small-footprint DHCP server designed for primary use in embedded systems. You may want to install this DHCP server if memory or storage resource minimization is critical.
- wide-dhcp6-servers: A DHCP server for IPv6 hosts, this DHCP server requires that you use an IPv6 DHCP client such as wide-dhcp6-client on any IPv6 systems that you want to configure.

The DHCP server that you want to use is up to you. I suggest the dhcp3-server package because it corresponds to the latest and greatest DHCP server available from the ISC. Your mileage may vary (or your environment may suggest or mandate a different DHCP server).

When running a DHCP server on a system that is itself a client of some other DHCP server, you must make sure that your new DHCP server hands out a different range of IP addresses from the existing DHCP server (and I hope you are the sysadmin of that network!), is restricted to a different Ethernet interface from the one that your system uses to obtain its IP address, is restricted to specific hardware addresses, or all of the. It's somewhat unusual to run a DHCP server on a system that gets its address via DHCP unless system has multiple Ethernet interfaces and serves as a gateway or router between multiple networks. Servers have fixed IP addresses so that you can always contact them even if services such as DNS are unavailable. As mentioned previously, setting up a DHCP server that hands out addresses on a network you are not responsible for is usually bad form, at best.
