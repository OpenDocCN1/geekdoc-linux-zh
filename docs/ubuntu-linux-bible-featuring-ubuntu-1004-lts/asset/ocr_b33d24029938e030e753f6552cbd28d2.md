# Tip

When using the Synaptic utility to install software without having configured Synaptic to always display configuration status in a terminal window, it is useful to display a Terminal to see information about the status of software installation on your system. You may occasionally have to display additional, configuration-related information during the installation process. In this case, the Synaptic utility displays some sort of information requests as displayed by the apt and aptitude utilities, as shown earlier in Figure 19-8. Whenever you see this screen, you must answer any questions that it asks and supply any requested information before the installation of your package can complete. The Synaptic utility displays this information in the dialog that you see only when you expand the software Terminal window, so it's a good idea to monitor this window. If you choose not to notice and Synaptic seems to have stopped installing, expand this window to see if Synaptic is waiting for additional information.

If you selected the "Apply changes" in a Terminal window item in Synaptic's Preferences dialog, Synaptic displays a single large Terminal window during its installation and configuration phases, shown in Figure 19-25, instead of the dialogs shown in Figures 19-23 and 19-24.

Regardless of which of the dialogs you see when package installation and configuration complete, click Close to close that dialog and return to Synaptic's main dialog.

Once you have finished installing any packages that you are interested in, you can exit Synaptic by selecting the File menu's Quit command (or pressing the Ctrl+Q key sequence).
