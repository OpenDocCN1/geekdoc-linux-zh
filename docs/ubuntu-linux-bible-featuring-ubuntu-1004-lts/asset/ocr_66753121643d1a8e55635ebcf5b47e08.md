# # Finding command line That Do Specific Things

The command line is a pretty friendly place to execute commands if you know what you're doing and know what command to do it with. Unfortunately, the Linux tendency to avoid long command names by dropping extra characters from their names, it's often hard to figure out what command you want to use for a specific task.

Luckily, the Linux online manual, man, provides a truly convenient keyword search option (-k) that automatically searches for a specified keyword or phrase in the description fields of each man page. For example, suppose you didn't know about the chmod command and wanted to see a list of commands that have something to do with file permissions. For appropriate commands using the following command:

```
man -k permissions
chmod (1) - change file access permissions
```

Note that this can be tricky just like a Web search, when you have to look for the right phrase. However, at least the possibility is always there. You can search for single words or quoted strings to refine the list of commands that match what you're looking for.

If your man -k output lists a command but you can't seem to execute that command (you the message "command not found" when you try to execute it), this means that the directory where command is stored isn't one of the directories listed in your PATH variable. In that case, you can try using whereis to locate that command, in the following example:

+   - man "physical volume" - change attributes of a physical volume
pchange (8) - display attributes of a physical volume
pvdisplay (8) - remove a physical volume
premove (8) - report information about physical volumes
pvs (8) - scan all disks for physical volumes
pvscan (8) - add physical volumes to a volume group

```
$ pvscan
bash: pvscan: command not found
```

```
$ whereis pvscan
pvscan: /sbin/pvscan /usr/share/man/man8/pvscan.8.gz
```

The where command tells you where the command is located (and where its documentation is found). You can then execute that command by specifying the full pathname of the executable, which in this case is /sbin/pvscan.
