# Tip

One of the few audio formats that isn't somehow supported by the GStreamer framework is Shorten (SHN), a free, lossless audio codec that is popular in live recording circles. To work with files of this type, you can use your favorite Package Management software to install the shntool package, a command-line utility that can convert them to WAV files so that Sound Converter can convert them to your favorite output format.

# Would You Like to Play a Game?

Games on UNIX-like systems such as Linux have come a long way from "Hunt the Wumpus", a text-oriented adventure and exploration game I spent an hour playing in 1982 on a PDP-1. Today, as you'd hope, Linux games are sophisticated graphical applications with plenty of performance and eye candy. One thing you'll see in many of the games discussed in this chapter is that Linux games also have a sense of humor, which I find refreshing. Losing and laughing is almost as good as winning (at least, that's what I tell myself).

As emphasized throughout this book, Ubuntu is a Linux distribution for people, who are supposed to relax and have fun at times. Ubuntu comes with a small number of games preinstalled as part of your desktop, but you can easily install an even better selection by installing the gnome-games package. A huge number of Linux games are available in the repositories and in source form across the Internet. This chapter discusses a good selection of games that are available for Ubuntu, highlighting that you can get work done and have fun with the same machine. The first section of the chapter explores the default games that are pre-installed on an Ubuntu system, those that are part the gnome-games package; the second section discusses classic games such as Chess, Go, Scrabble, Monopoly and how to play these (or similar games) on an Ubuntu system; the last section discusses some great arcade-style games that you really shouldn't miss.

# Tali

Tali is an online version of a deck game that emulates a card game (pocket). If you're familiar with a popular analog game called Yaht from Hasbro, Inc., Tali may not be a shock to you or may instead find it familiar. By default, Tali is configured to enable one player (you) to take on four computer-generated opponents, but you can easily configure your preferences to support multiple players and reduce or eliminate the computer-generated opponents. I especially like the default prompt at the bottom of the screen when it's my turn: "Human!—You're up."
