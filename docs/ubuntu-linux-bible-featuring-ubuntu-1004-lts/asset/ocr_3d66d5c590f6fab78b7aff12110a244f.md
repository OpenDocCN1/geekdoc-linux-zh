11. Once you have allocated all of the available free space on your system to partitions, your screen should look something like the one shown in Figure 3-30. This screen displays a summary of the partitions that you have defined for your system. Remember that there must be one partition mounted at / and one swap partition. To accept the values shown on this screen, use the arrow keys to select the "Finish partitioning and write changes to disk" option, and press Return to display the screen shown in Figure 3-31.
