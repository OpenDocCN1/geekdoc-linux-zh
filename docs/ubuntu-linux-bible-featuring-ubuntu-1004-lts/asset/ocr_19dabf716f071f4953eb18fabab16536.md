```
$ cp -r include_test backup
```

After the command completed, the new backup directory would be an exact copy of the include_test directory. If you're from Missouri and need proof that the right thing is happening, you can add a -v (verbose option) to the cp command to list each part of the copy command. This command and its output would look like the following:

```
$ cp -rv include_test
'include_test_' -> 'backup'
'include_test/libxml2' -> 'backup/libxml2'
'include_test/libxml2/xmlops.h' -> 'backup/libxml2/xmlops.h'
'include_test/netdev' -> 'backup/netdev'
'include_test/devname.h' -> 'backup/netdev/devname.h'
'include_test/system' -> 'backup/system'
'include_test/system/libxml2' -> 'backup/system/libxml2'
'include_test/system/libxml2/xmlops.h' -> \
'backup/system/libxml2/xmlops.h' -> 'backup/system/netdev'
'include_test/system/netdev/devname.h' -> \
'backup/system/netdev/devname.h'
```

As you'd hoped, a recursive cp command also recursively copies all subdirectories and any files that they contain.

I mentioned earlier that specifying the name of a directory as the target when copying a file creates a file with the same name as the original in the target directory. The same is true when specifying the name of a directory as the target for a recursive cp command. This can initially be confusing if you're trying to copy a directory to a directory with a new name and a directory that already exists. In case, the cp command creates a directory with the same name as your original directory as a subdirectory of the target directory.

Moving and renaming files from the command line is similarly easy. Linux systems don't actually provide a separate rename command—on a Linux system, the mv command moves both files and directories to a new location and also renames them as part of the move operation. For example, to rename the file.txt to the new name newfile.txt, you would do the following:

```
$ mv file.txt newfile.txt
```

The mv command follows the same conventions as the cp command in terms of specifying full pathnames and when specifying a directory as the name of the location to which you want to move a file. For example, the following command moves the file /home/wvh/file.txt to the /tmp directory and renames it newfile.txt:
  

```
$ mv /home/wvh/file.txt /tmp/newfile.txt
```
