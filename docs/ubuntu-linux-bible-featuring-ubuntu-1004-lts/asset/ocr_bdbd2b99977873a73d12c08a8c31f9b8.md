# # Backing Up Your Bookmarks

Because your evolving collection of bookmarks is one of the most precious things that you build up as you surf the Net, making sure that you don't accidentally lose them is critical. The Library dialog's Import and Backup dropdown menu provides both Export and Backup commands that enable you to save a copy of your current bookmarks in a separate file. This is especially important for the latest versions of Firefox, which store bookmarks and history in SQLite database using an interface like *Places*. Places are convenient for searching, but removes some of the ease-of-use of backing up bookmarks in previous versions of Firefox, where you could simply copy a flat HTML file called your personal preferences directory in ~/.mozilla/firefox in your home directory to back up your bookmarks. This flat file still exists but is only kept in sync with SQLite bookmarks in certain cases, and there's no guarantee that this will continue in the future. Use the Library's Export command to save an HTML copy of your bookmarks, or the Backup command to save your bookmarks in JSON (JavaScript Object Notation) format.

When creating JSON backups, you can easily restore them using the Choose File command from the Restore menu on the Library's "Import and Backup" dropdown menu. This enables you to restore a JSON backup file you've saved. The Restore menu also lists dates for internal Firefox bookmarks are available.

I tend to save my bookmarks in HTML every week or two, giving them names containing the current date, like bookmarks-27-Oct-06.html, from the other. This makes it easy to find a specific bookmark in one of these files if you've accidentally deleted the bookmark but have some idea of the last time that you saw it. JSON is a fine format, but it's not supported in other browsers or in older versions of Firefox, and I also like to put a copy of recent bookmarks on my web site to help me find my favorite locations when I'm not in front of my primary machine.

# # Creating Live Bookmarks

The Live Bookmarks feature is one of the latest — and most useful — enhancements to Web surfing that have been introduced by the Firefox team. Live Bookmarks exploits a popular technology called RSS, which for "Really Simple Syndication," or "Rich Site," depending on whom you ask. Many websites use RSS to publish a summary of recent changes to their site, which other sites can read and display links to those changes. A *live bookmark* to a site is essentially a special type of bookmark that points to the RSS feed on that site, more usable by the fact that Live Bookmarks displays the headings in an RSS feed as menu items.
