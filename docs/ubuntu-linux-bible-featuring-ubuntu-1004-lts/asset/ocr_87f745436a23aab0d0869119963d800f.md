# Panel Menus

Menus are displayed in the panels when you left-click the menu name in the panel. Menus either contain entries for specific tasks or locations on your system, or contain other menus. Menus located on other menus are known as submenus. As an example, Figure 5-3 shows the default contents of the Application menu's Internet submenu, which I will discuss later in this section.
