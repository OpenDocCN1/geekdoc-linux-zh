# Instant Messaging on Ubuntu with Pidgin

Pidgin (www.pidgin.im) is the new name of a popular instant messaging application for Linux that was originally known as GAIM (GTK+ AOL Instant Messenger). This name was changed to Gain due to pressure from AOL, which was still not good enough once AOL marked the term AIM, so there you go—Pidgin it is. The name is double clever, referring both to a simplified language used to communicate with groups who do not have an entire language in common (i.e., Pidgin English) and also referring to the pigeon, a bird that historically used to send messages.

Until the arrival of Empathy, Pidgin was the most popular multi-protocol instant messaging client on GNOME-based systems and was installed as part of a default Ubuntu Desktop system.
