# Getting to a Shell

Assuming, I've hyped the value of the Linux command line sufficiently and that your Ubuntu
shell boots correctly in graphical mode, you're probably wondering how to start a shell so that
you can experiment with a bit. Ubuntu provides two applications that are the most common mecha-
s for starting a shell, one that is a standard part of the X Window distribution, and
another is a standard part of any GNOME distribution. Both of these are referred to as term-
al applications, not because they imply an end to life as we know it but because they are reminis-
cent of the user experience on systems with bitmapped graphical displays, when most users
accessed their computer systems through terminals that couldn't do much more than display the
input and output of a command interpreter.
