# Tip

A common Compiz problem is that the title bars of newly created windows display under the GNOME panel at the top of the screen. If this occurs, first make sure that the Place Windows plug-in is enabled. This plug-in uses a smarter algorithm that takes title bars into account when placing new windows on the screen. You can also move windows so that their title bars are visible by holding down the Alt key and holding the left mouse button in the window that you want to move. The standard window move icon displays, and you can drag the window until its title is visible. ■

# These Are a Few of My Favorite Things.

Some of the plug-ins that I typically activate by the default set are as follows:

- **Desktop Cube/Rotate Cube**: Discussed in the previous section, quickly cycling through available viewports and rotating a cube with those viewports on its sides is not only attractive but eminently. Although I realize I'm using more of the CPU's resources, this is such a cool effect that I can't resist activating it.
- **Ring Switch**: This plug-in adds the Super+Tab command to display available windows in a circular ring that spins around them, with the title of the selected window displayed in the center. It's similar to the standard Alt+Tab application switcher but much more fun.
- **Water Effect**: Sure to amuse and amaze the neighbors, this plug-in lets toggle raindrops with Shift+F9. This wastes computing power only when the raindrops are active, but it's quite visually impressive when you're showing Compiz to someone.
- **Wobbly Windows**: Discussed in the section of this chapter on using the GNOME configuration tools to configure Compiz effects, Wobbly Windows provide a jiggly, gelatinous view as you move windows. The Desktop Cube/Rotate Cube plug-in provides one of the classic Compiz effects.

As mentioned earlier in this chapter, see http://wiki.compiz-fusion.org/Plugins for a complete listing of available Compiz and Compiz Fusion plug-ins and their configuration. The Compiz plug-ins at www.compiz.org/Plugins lists the default plug-ins that are bundled with Compiz and also provides links to additional, external plug-ins that you may find useful.

# Installing and Using the Avant Window Navigator

If you've ever seen or Mac OS X, you're probably familiar with its dock, which is the panelike application at the bottom of the screen (by default), and in when you see for your favorite applications as well as icons representing running applications and the Trash Can. Although Gnome has its Panels and Microsoft Windows its Taskbar, it's hard to deny that the Mac OS Dock is the most active of these entities with similar functionality. Perhaps until now. The Avant Window Navigator (AWN) is an open source dock application for composing window managers that provides an attractive, powerful, extensible, and fully customizable dock for use with Compiz. The Avant Window Navigator was developed by Neil Patel and currently has its home page on the Ubuntu Launchpad site at https://launchpad.net/awn. Figure 6-13 shows the default appearance of an Ubuntu desktop running both the Avant Window Navigator and its configuration utility.

The Avant Window Navigator is not installed by default on Ubuntu systems, but you can easily install it using your favorite package management utility, as explained in Chapter 19. Installing the Avant Window Navigator will also install the library that it uses, some Python modules that it required, and its configuration manager.

**Tip** To get the latest version of the Avant Window Navigator and its plug-ins, you should add http://ppa:launchpad.net/awn-testing/ubuntu to the sources listed in /etc/apt/sources.list. See Chapter 19 for information about enabling other sources for use with Ubuntu's package management system.

After installing AWN, you can start manually from any command-line application, such as xterm or the GNOME Terminal. To configure AWN to start automatically when you log in, you can enable it in the Awn Settings application (discussed later in this) or add it to your standard startup application settings. For the latter, select the System Preferences Startup Applications tools. On the Startup Programs tab, click Add, and enter information about the Avant Window Navigator, as shown in Figure 6-14.
