# Chapter 1: The Ubuntu Linux Project

Uuntu offers an impressive array of support opportunities, ranging from community resources to pay support from Ubuntu's sponsor company, Canonical, Ltd., and several other companies located all over the world. The next few sections highlight the various ways in which you can ask questions, get answers, request pay support, and hire experts to help with custom Ubuntu programming and support tasks.

# Community Support and Information

Because Linux software depends on the community development model, getting timely, free help for problems often relies on a similar community approach. Ubuntu shines mailing lists, blogs, and interactive forums are all excellent sources of up-to-date information about Ubuntu. Forums and mailing lists enable you to post specific questions and receive responses from other Ubuntu users who have already solved the issue that you are experiencing. These online resources also serve as excellent feeders for the Ubuntu project, helping the project identify and common problems that should be addressed in future Ubuntu releases.

# Blogs

Blog (from the term Web log) is a popular buzzword, and it often seems as though almost every one has. The Ubuntu blog, known as Planet Ubuntu (http://planet.ubuntux.org), is a bit different because it's not a continuous stream of consciousness from a single individual. Instead, Planet Ubuntu is a place where Ubuntu developers and community members can share various musings, insights, complaints, and successes.

If you're enough of a blog or Ubuntu fan to subscribe to it rather than simply visit its web page, Planet Ubuntu is also available in the following PDF (Resource Description Framework) and general markup formats:

+   - FOAF: Friend of Friend, available at http://planet.ubuntux.org/foafroll.xml
- OPML: Outline Processor Markup Language, available at http://planet.ubuntux.org/opml.xml
- RSS: Really Simple Syndication or Rich Site Summary, depending on whom you ask. Planet Ubuntu feeds are available in RSS 1.0 (http://planet.ubuntux.org/rss10.xml) or RSS 2.0 (http://planet.ubuntux.org/rss20.xml) formats. You should use the appropriate format for your RSS reader.
