5. Enter the name for your new template and click OK. Figure 13-17 shows the creation of a new style called Book Chapter.

Congratulations, you've created a document template! Once you've created a template, you can easily create new documents based on that template by doing the following:

+   1. Select File ✜ New ✜ Templates and Documents to display the dialog shown in Figure 13-18.

+   2. To create a document from a specific template, click the Templates icon at the left and select the location where you saved your template (usually “My Templates”). You will see your templates in the window to the right of the icons. Figure 13-18 shows this dialog, which includes the template that I created in the previous step.

+   3. Select the template that you want to use, and either click Open or double-click on its name to create a new document from this template.

Once you are finished editing your document, save it by the standard File ✜ Save command.

Creating and using templates is a great way to standardize the documents that you or your organization is creating.

# Tip

Modifying or otherwise updating a template does not mean that any documents that have been created from it are automatically updated. When updating a template, opening any document that was created from it will prompt you as to whether or not you want to update the document to reflect the updated template. That's usually a good idea, but it's nice that Writer is kind enough to ask you about it.
