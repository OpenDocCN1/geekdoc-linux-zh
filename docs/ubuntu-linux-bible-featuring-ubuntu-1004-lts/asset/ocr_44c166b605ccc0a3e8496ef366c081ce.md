By default, your system automatically checks for updates on a daily basis, displaying an "Available Updates" icon in the GNOME panel at top of your screen when updates are available. If you are using a laptop or other system that only connects to the Internet frequently, you may want to decrease the frequency with which your system checks for updates by selecting another value from the "Check for updates automatically" entry dropdown menu, or disable this item entirely. If you disable this item, you can always check for updates manually using Ubuntu Update Manager, which is discussed later in this chapter in the section. "Using the Ubuntu Update Manager." If you are performing regular checks for updates and are using a system that is often (or always) connected to the Internet, you may want to select the "Download updates in the background, but not install them" option to make sure that packages are already available on your local system when you actually execute the update process. You may want to select the "Install security updates without confirmation" option if you want to automatically retrieve security updates and install them so that your system is always secure against any known attacks or software exploits.
