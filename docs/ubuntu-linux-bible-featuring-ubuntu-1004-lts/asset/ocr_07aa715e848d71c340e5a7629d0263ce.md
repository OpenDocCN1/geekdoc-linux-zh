# Part III: Ubuntu for System Administrators

# Tip

When using backuppc to back up Microsoft Windows systems, you should create a Windows user that will only use for backups and add this user to the standard Windows Backup Operators group. This prevents you from having to put your Windows administrator password in the backuppc configuration files. Even though you'll protect those files that randoms can't read them, the fewer places you write a password, the better, especially with the keys to your entire Windows kingdom.

Next, change the ownership and group of the /var/lib/backuppc/pc/win2k directory to backuppc and change the protection of the configuration file /var/lib/backuppc/pc/win2k/config.pl so that it is not publicly readable (because it contains password information) using the following commands:

```
sudo chmod -R backuppc:/var/lib/backuppc/pc/win2k
sudo chmod 600 /var/lib/backuppc/pc/win2k/config.pl
```

The last step in creating a host-specific backup definition for backuppc is because the backuppc process to reread its configuration data, which you can do by explicitly reloading the configuration file, by explicitly restarting the backuppc process, or by sending the associated process hang-up (HUP) signal. You can force BackupPC to reload its configuration file by using the following command:

```
sudo /etc/init.d/backuppc reload
```

The definition for your host has now been selected via the backuppc Web Interface. At this point, you can follow the instructions in the section "Starting Backups in "backuppc" to back up this host.

The example in this section only backs up shares that correspond to the home directories of selected users on the remote machine. As mentioned earlier in this chapter, package backups do not support bare-metal restores of Windows systems, and I therefore don't back up shares as C:, which is a default Windows share that represents your system's boot drive. You find it useful to make sure you have backup copies of drivers, the registry, and so on, but I find simpler to start from scratch when reinstalling Windows. Windows systems accumulate so much crap in their files over time that a fresh installation from your distribution media often frees up a surprising amount of space. If you have several images created with Norton Ghost or the Linux partition or g4u utilities is always the fastest way to rebuild a Windows system without having to locate the drivers for every device that you will ever to use with your reboot system and reinstall all of your favorite applications.

# Tip

The backuppc program reads the configuration settings in /etc/backuppc/config.pl first and then loads host-specific configuration settings, which enables the /etc/backuppc/config.pl file to provide default settings for all. After you have used backuppc for a while and are comfortable with various settings, you may want to consider modifying the default settings in the /etc/backuppc/config.pl file for configuration variables, as $Conf(CompressLevel), to minimize the number of entries that you have to create in each of your host-specific configuration files.
