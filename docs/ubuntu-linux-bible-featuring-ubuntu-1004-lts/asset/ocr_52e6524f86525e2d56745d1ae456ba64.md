# Chapter 1: The Ubuntu Linux Project

Of course, getting a CD or DVD that just contains a bunch of software would be next useless without some easy way of installing it and configuring it so that it works with your particular computer system (identifying peripherals, setting it up to communicate over your network or with your ISP, creating user accounts, etc.). Therefore, anyone puts together a Linux distribution provides a tool for installing and configuring the system, which is generally what you run boot from a Linux CD or DVD for the first time. This installation tool generally leverages a package management system that makes it easy to add or remove sets of related applications, identifying dependencies between different software components to ensure that the applications you install will actually execute correctly.

Linux distributions are the key to understanding how Linux can be free and sold at the same time. The source code for the Linux kernel and open source applications are, indeed, freely available from thousands of sites on the Internet. Anyone who wants can get it, but putting it all together in an easily installable, usable form is another thing entirely. When people sell a Linux distribution, they are basically charging you for the media it comes on, on the time and effort they invested in putting it all together, and (in some cases) "charging in advance" for any customer support that you might need if you encounter installation or initial problems.

Developing Linux distributions and making them widely available have been critical to the adoption of Linux as an operating system because these distributions have made possible for people to actually install and use Linux, the GNU utilities, and so.

# Introducing Ubuntu Linux

Ubuntu is a Linux distribution founded in 2004. Originally focused on the needs of desktop and laptop users, Ubuntu has branched out since then and now offers distributions focused on the needs of commercial users with their Ubuntu Server distribution, Ubuntu JeOS for virtualization platforms, and Ubuntu Mobile for mobile and embedded devices such as smartphones, Internet tablets, and so on. All of these flavors are of the Ubuntu project sponsored by Canonical (www.canonical.com), a company founded by Mark Shuttlesworth, a successful African entrepreneur, long-time Debian developer, and open source advocate. Ubuntu is a Debian-based Linux distribution (more about that later in this chapter) that uses a graphical user interface known as GNOME as its desktop environment. (GNOME is discussed in detail in Chapter 5, "Using the GNOME Desktop.") Sister projects (officially known as Ubuntu Editions) to Desktop Ubuntu include:

+   - Ubuntu: A version of Ubuntu that uses the KDE desktop environment instead of GNOME

+   - Ubuntu: A version of Ubuntu that uses the lighter-weight Xfce desktop

+   - Gobuntu: A version of Ubuntu that uses completely open source software

+   - Eduntu: A version of Ubuntu that focuses on educational applications and popular-using it of Linux in schools
