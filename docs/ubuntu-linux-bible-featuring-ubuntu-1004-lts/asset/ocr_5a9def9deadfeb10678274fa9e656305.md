# Chapter 27: Managing Users, Groups, and Authentication

You may want to create your own groups to do things like identify members, to limit access to a group, or use a group to limit the people who can execute selected binaries. Ubuntu's Users and Groups tool provides a graphical interface to simplify both group creation and group management (the latter is discussed in the next section). To start this tool, select the System Administration Users and Groups menu to execute this tool. The dialog shown in Figure 27-1 appears. To access the group-oriented portions of this tool, click the Manage Groups button, which displays a dialog like the one shown in Figure 27-5.
