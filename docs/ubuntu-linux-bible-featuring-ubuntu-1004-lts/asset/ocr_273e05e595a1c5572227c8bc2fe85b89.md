The three options in this dialog do the following:

+   * **Save the machine state**: Saves the memory and disk state of the virtual machine to a file that will be used the next time you start the virtual machine. Starting from a saved state is much faster than booting a virtual machine. You cannot edit the settings for a virtual machine if you have a saved state file because the state information depends on the settings that were active when the machine's state was saved. In order to modify any settings for a virtual machine that has a saved state file, you must either start the virtual machine from the saved state file and then shut it down normally, or you discard the saved state information by right-clicking on the virtual machine in the left pane of the main VirtualBox window and selecting the Discard command from the context-sensitive menu. If you discard saved state information, you will lose any changes that were not written to your virtual machine. If you have the time, it's definitely a better idea to start the virtual machine and shut it down normally than simply saving the virtual machine's file.

+   * **Send the shutdown signal**: Begins a standard shutdown in the virtual machine's operating system. This option is provided if you accidentally clicked Close but have the time to do an orderly shutdown.
