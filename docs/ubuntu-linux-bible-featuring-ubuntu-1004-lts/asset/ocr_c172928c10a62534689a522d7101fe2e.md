# Working with Partitions and Filesystems

Like Ubuntu, most Linux systems automatically identify the disks in your system and propose a reasonable partitioning scheme as part of the installation process. Similarly, when you attach a new disk to your system or add one internally, Ubuntu displays a box asking if you want to configure disk. Partitioning in the installation process is explained in Chapter 2, "Installing Ubuntu", using graphical partitioning utilities after your system is already running is explained in detail in Chapter 20, "Adding Hardware and Attaching Peripherals."

Even after you partition and format a disk, or you attach a disk that has already been partitioned, you can't access it until you mount it. This section discusses how to temporarily mount a disk using the Linux mount command, the most popular options available for that command, and how to mount a specific disk as part of your system's startup process by adding it to your filesystem configuration file, /etc/fstab.

# Mounting Filesystems

Once you have attached a disk, you can query the filesystems that it contains using the Linux fdisk utility's -l (list) option, as in the following example:

```
$ sudo fdisk -l
```
