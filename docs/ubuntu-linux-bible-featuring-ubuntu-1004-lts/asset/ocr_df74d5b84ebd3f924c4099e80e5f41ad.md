# Part II: Ubuntu Desktop Users

Unfortunately, not everyone is lucky. I've worked with clients who did their backups before using Thunderbird to generate portable versions of their mail files, managed to avoiding exporting Outlook Express mail files into Thunderbird, or needed to restore mail from older Windows backups and import those restored folders. I don't even know how people manage to do these things, but these are all cases in which you can't use the traditional Thunderbird-to-Whatever mail method.

Likely for, the open source community is large enough that somebody has had to do these sorts of things, and therefore has written tools to do these things. Migrating mail folders manually requires a bit more work than clicking a few buttons and letting Thunderbird the heavy lifting, but it works just as well.

The next two sections describe how to use the command-line readdbx reread utilities to manually create mbox files from DBX files (Outlook Express mail) and PST files (Outlook mail). I hope that you will never need this information, but better safe than sorry, really.

# Mitigating Outlook Express Mail with readdbx

Outlook Express stores its folders in files that are in DBX format, a database format of sorts. Ideally, the libdbx package provides two utilities to convert files into these formats to the standard mbox format. The readdbx utility, which converts DBX files, and the reread utility, which will take a directory of DBX files (such as the directory where Outlook Express stores its mail) and will convert all of the files in this directory into mbox-format files in another directory.

The libdbx project is actually a part of the ol2mbox (Outlook to mbox) project on SourceForge-sourceforge.net/projects/ol2mbox). There hasn't been a new release of libdbx for a while, the current version "just works". (The libpst package for reading Outlook mail from PST files is a different story, as discussed in the next section.) For all of Ubuntu users, the bad news is that the libdbx package is not available in the Ubuntu repository, so you'll have to download the source code and build it yourself if you need to use it.

I won't go into the details of building and installing the package here—Chapter 2 explains how to install the tools necessary to compile source code that is written in the C programming language. A quick overview:

+   1. Download the source code from the SourceForge project by clicking the Download link and retrieving the libdbx_1.0.3.gz compressed archive.
2. Uncompress the archive using a command such as tar xvzf filename, where filename is the name of the file that you downloaded.
3. Change the directory to the directory to which the software was extracted (probably libdbx_1.0.3), and configure the software using the command ./configure.
4. Use the make program to build and install the readdbx and reread utilities executing the command make install.
