When you're composing e-mail, Evolution initially displays only the "From" and "To" fields in the message header to save space. In many cases, you'll want to send a copy of your mail to someone else (or perhaps to another e-mail address of). To display the fields of the mail header that support such additional recipients, click the Menu view and select the other fields that you want to see as CC (Carbon Copy), BCC (Blind Carbon Copy) — one or more e-mail addresses that are not listed in the mail that is actually sent to the other recipients), and so on.
