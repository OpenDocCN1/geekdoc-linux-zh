4. The screen shown in Figure 3-5 prompts you as to whether you want to try to automatically detect or manually specify the type of keyboard that you are using:

+   - Press Return to accept the default value of No, displays two dialogs that contain lists from which you can verify or modify the type of keyboard that you are using.
- Press Tab twice, selecting Yes, and pressing Return displays a few additional screens that prompt you to press specific keys on your keyboard or ask if certain keys exist on your system.

In most cases, you should accept the default value of No and select your keyboard from the subsequent screens. The first screen lets you identify of the country of origin of your keyboard; if your keyboard is not listed on these dialogs or you cannot determine the type of keyboard to select, you can always select "Go Back" on the list of dialogs to return to the screen shown in Figure 3-5 and use the installer's keyboard layout detection dials to determine your keyboard type and layout based on the keys that are available on your keyboard.
