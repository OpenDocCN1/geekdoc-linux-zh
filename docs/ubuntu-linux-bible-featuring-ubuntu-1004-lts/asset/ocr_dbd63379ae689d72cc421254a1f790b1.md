# Listing Windows Shares

If you're unsure of the shared directories and associated servers that are available on your local network, you can quickly list them all using the smbtree command, which will prompt you for your Windows password, as in the following example:


If you're unsure of the shares that a specific Windows (or Samba) server offers, you can also list them using the smclient command, which will prompt you for your Windows password, as in the following example:

```
$ smclient -L 192.168.6.2
Password:
Domain=[WINSERVER] OS=[Windows 5.1] Server=[Windows 2000 LAN Mgr]
Sharename       Type            Comment
IPC$            Disk            Remote IPC
print$          Disk            Printer Drivers
wwh             Disk            Home Directory
office         Disk            Shared Enterprise Data
Domain=[WINSERVER] OS=[Windows 5.1] Server=[Windows 2000 LAN Mgr]
```
