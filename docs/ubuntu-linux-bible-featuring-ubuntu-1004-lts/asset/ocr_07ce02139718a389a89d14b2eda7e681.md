+   * Sidebars: Provide easy navigation through a list of web pages. Firefox provides two different sidebars, one displaying your bookmarks and a second provides a list of the web pages that you have visited recently (Known as a history sidebar). These aren't turned on by default in Firefox, but you can easily activate whatever you prefer by using Bookmarks or History from the View menu. Figure 8-5 shows Firefox with the' sidebar displayed.
