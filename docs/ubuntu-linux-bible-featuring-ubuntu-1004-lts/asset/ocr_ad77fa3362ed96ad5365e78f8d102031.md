# Using the GNOME Partition Editor to Examine and Format Drives

The GNOME Partition Editor is a graphical front-end to the command-line parted tool, and is a great tool for use on Ubuntu systems of any type. This tool is not installed by default, but you can resolve this shortcut by using your Package Management tool of choice, discussed in Chapter 19, to install the package. Once installed, the GNOME Partition Editor provides a visual view of all the storage devices that are currently installed on your system and makes it easy for you to determine basic information about their capacity, any partitions that they contain, and the Linux nodes associated with the device and each partition. It also enables you to add, remove, and format hard disk partitions.
