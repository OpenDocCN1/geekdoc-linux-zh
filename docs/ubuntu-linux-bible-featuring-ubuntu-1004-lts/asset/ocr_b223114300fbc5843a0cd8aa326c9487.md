# Part II: Ubuntu for Desktop Users

If you are just generally interested in virtualization and would like to obtain additional information, there are a variety of sites that provide general-purpose information about virtualization and emulation on commodity hardware. The following are some of my favorites:

+   - IBM developerWorks: "Virtual Linux: An Overview of Virtualization Methods, Architectures, and Implementations" (http://www.ibm.com/developerworks/linux/library-linuxvirt/). This is a great article if you are interested in general information about virtualization on Linux. IBM's developerWorks always provides a huge amount of detail, technically accurate information. This article provides a good overview and explanation of virtualization on Linux, with links to many other sites.
- Linux Virtualization Wiki (http://virt.kernelnewbies.org): A site that provides a good overview of virtualization on Linux and more detailed discussions of various virtualization technologies. It also provides a good introduction to various tools that are available for managing Xen virtual machines, and a good overview of the Xen (and other) virtualization support that is available in various x86 Linux distributions and other operating systems, such as OpenSolar.
- SearchVirtualization.com (http://searchvirtualization.techtarget.com): A great TechTarget site provides a tremendous amount of information about server virtualization, related storage topics, and so on. One of the advantages of this is that many vendors make papers and commercial announcements available, which make it quite useful for keeping track of the pulse of commercial offerings.
- TheFreeCountry.com (www.thefreecountry.com/emulators/index.html): "Free Emulators and Virtual Machines" is a nice summary of free emulation and virtualization software for Intel x86-based (and compatible) machines. This is a great resource, but remember that free does not necessarily mean open source.
- Wikipedia (.www.wikipedia.com): Big surprise! Wikipedia has extensive articles about Xen (http://en.wikipedia.org/wiki/Xen), virtualization in general (http://en.wikipedia.org/wiki/virtualization), emulation (http://en.wikipedia.org/wiki/Emulation), and most of the other terms and players in today's virtualization market. The Wikipedia is a great source of information, as always—although you should always corroborate anything you read because it is publicly editable, and anyone can add anything that they want.
