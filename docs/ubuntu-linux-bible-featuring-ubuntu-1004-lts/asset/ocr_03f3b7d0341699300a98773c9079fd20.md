# Part II: Ubuntu for Desktop Users

download the zip archive of their game from the URL www.isc.ro/linux/WordBiz181in.zip and extract its contents using the unzip command. This will create a directory named WordBiz. Use the cd command to change directory to this directory and start the WordBiz application using the following command:

```
java -jar wordbiz.jar
```

This will start the WordBiz application in its own window, shown in Figure 17-12, and will also display "Open connection" dialog in which you must supply the handle (login name) and password that you registered on the Internet Scrabble Club site.

![](bbox=[0.089, 0.319, 0.756, 0.768])

Once you have logged in, select the Game Seek Game menu command to find another person who wants to play Scrabble over the Internet, and away you go!
