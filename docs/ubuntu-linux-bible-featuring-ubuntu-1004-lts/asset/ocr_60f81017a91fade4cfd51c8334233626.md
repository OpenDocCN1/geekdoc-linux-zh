# Part I: Getting Started with Ubuntu

Linux provides several ways to enable copying files to other systems over the network. Two of the most common and popular of these are as follows:

+   * The `ftp` (file transfer protocol) utility, which establishes a connection to another machine and enables you to interactively transfer files in either direction
* The `scp` (secure copy) utility, which enables you to quickly transfer files to other machines over a secure, encrypted connection

These commands are explained in detail in Chapter 25, "Connecting to Other Systems." They're summarized here so that you know that there are ways to save any work you've done from an Ubuntu Desktop CD that do not involve local storage. This can be very useful, for example, if you are using an Ubuntu Desktop CD to recover data from a crashed system or one that can't boot on its own for some reason.

# Using Desktop CD Persistence

Live CDs like the Ubuntu Desktop CD provide an easy way to temporarily run any compatible computer system into an Ubuntu Linux system. However, the fact that most Live CDs don't provide any sort of persistent storage for configuration data, custom applications, and so on (on manually copying files to other local or networked storage) traditionally limited the practical usability of Live CDs to simple demonstrations, one-time experimentation, and general system repair and recovery efforts. Luckily, things are better now—thanks to really clever people, it's fairly easy to automate changes you make when running from the equivalent of an Ubuntu Desktop CD—and without having to deal with manually mounting and unmounting filesystems, saving your work, and so on.

Earlier Ubuntu introduced a mechanism for associating persistent storage with the Live CD boot process. This mechanism enabled you to format an external storage device with a special name (casper-rw) and use it at boot time (in conjunction with the Desktop CD), adding a kernel boot option (persistent) to tell the boot process use the contents of that device to restore settings, personal data, and even installed applications. This approach had a few problems, the most significant of which was that it required an external storage device (typically a USB flash memory stick) and an Ubuntu Desktop CD. Aside from the hassle of carrying around of these, my particular complaint was that my Desktop CD kept breaking when I put them in my back pocket and sat them on.

Luckily, improvements in flash drive size, price reductions for flash drives, and software improvements have made being able to do work from an Ubuntu Desktop even easier. Ubuntu systems include an easy-to-use command for creating a bootable USB flash drive (generally referred to as a stick) that works like the Desktop CD but provides persistent storage when using the "Try Ubuntu without any change to your computer" option. This gives you a portable system from which you can run Ubuntu or install it on another computer system without requiring the use of a CD drive. All you need nowadays for this type of portable Ubuntu system is a USB flash drive that is at least 2 GB in size.
