# Working with Files and Directories

A file is nothing more than a collection of information that programs and your operating system can locate and deal with a single unit. Files are containers for some sort of data, whether they contain a letter to your mother or parole board, a copy of your favorite songs (legitimate, of course), a digital photograph, or the data used by a spreadsheet to calculate the health of your personal finances. Providing the general concept of a file as a container for related data makes it easy for applications and Linux to locate and use that information—hence the File menu is present in most graphical applications today. This menu contains the commands that you use to open files, create new ones, and save changes that you have made to any file that you are working with.

Files are mandatory on a computer system—the operating system has a a way to identify and access your data, the applications that it needs to run, any configuration files used by those applications, and so on. Similarly, when you turn it on, your computer system needs to find how the operating system and related configuration information that it boots. However, as more and more files were required, for different purposes, and created by different users, it didn't take long for an intermediate mechanism for organizing files, Directories are simply containers for groups of related files, and they also contain directories (subdirectories). This is what is known as a hierarchical collection of files—the location of any specific file is identified by describing the series of directories that eventually contains the file you're looking for. The directory that all searches with on Linux systems is known as the root directory because it is the starting point for the description of how to navigate to any file that is stored locally (i.e., on your computer).

The standard analogy for files and directories is a filing cabinet—you can find any file in the filing cabinet by following a process like this: Start at the filing cabinet, open the first drawer, the hanging folder labeled Personnel, select the manila folder with your name on it, and check your healthcare enrollment form. On a computer, the process for finding the location of an analogous file might be something like this: Go to the filesystem (/) to the home directory, go to the vwh directory (my login name), and look for the file named health_enrollment.txt.

Linux systems use the "/" character as both the name of the top-level directory on your system and to separate file and directory names, so this is often more expressed as, "The file /home/vwh/health_enrollment.txt." The series of directories leading to a given file is often referred to as the path to that file.

Linux systems provide a graphical user interface, such as GNOME, provide graphical ways of navigating through directories, typically by clicking on them to open and opening a window that displays graphical icons corresponding to the files that they contain. As explained in more detail in Chapter 11, "Using Command-Line Tools," any Linux-environment uses a command known as cd (which stands for "change directory") to navigate through a sequence of directories.
