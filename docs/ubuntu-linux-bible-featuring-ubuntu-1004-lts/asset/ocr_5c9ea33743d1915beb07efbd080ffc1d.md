Click "Subscribe Now." The standard "Add Bookmark" dialog displays, enabling you to specify where you want to create the live bookmark. The "Add Bookmark" dialog closes, and the Live Bookmarks menu displays. After a few seconds (the time it takes for Firefox to read the RSS feed and create the live bookmark), you can access the Live Bookmarks menu like any other menu in Firefox, as shown in Figure 8-19.

# Tip

Your Bookmarks toolbar is a group of frequently used bookmarks that Firefox displays above the web page that you are viewing. This is the most common location for creating live bookmarks because they represent an up-to-date summary of a site that you're presumably interested in.
