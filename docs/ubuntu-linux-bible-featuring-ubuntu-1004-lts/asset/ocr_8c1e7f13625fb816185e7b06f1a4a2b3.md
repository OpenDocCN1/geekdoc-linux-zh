Similarly, if you want mail headers to announce that your mail is coming from a specific organization, you can specify the name of that organization in the Organization field. This is invisible to most recipients, but it can be handy for filtering e-mail messages (explained later in this chapter) if you use this field to uniquely identify that this mail is coming from a specific location. When you first see the panel shown in Figure 7-4, it will be largely empty and the "Server Type" field will display a default value. Click the "Server Type" field to display a list of the different types of mail servers Evolution can talk to, and select the one that corresponds to the primary e-mail protocol supported by the mail server at the location that hosts your e-mail, which is typically your ISP. Most mail servers nowadays speak POP (Post Office Protocol) or a special version of POP known as POP3, which adds some extensions to the standard POP server capabilities. The second most popular protocol nowadays is IMAP, which also includes Microsoft Exchange mailers, because they speak a variant (of course) of IMAP.
