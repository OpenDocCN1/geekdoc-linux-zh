# Chapter 19: Adding, Removing, and Updating Software

Synaptic was originally developed by the folks at Connectiva Linux, a Latin Linux distribution was eventually acquired by Mandrake Linux, which then changed its name to Mandriva to highlight that it wasn't your father's Mandrake Linux distribution anymore. Synaptic was originally written using the WINGS toolkit by the Window Maker X System manager (www.windowmaker.info), which attempted to provide a look and feel familiar to users of NeXT computer systems. Today, Synaptic is built with the standard GTK+ toolkit by GNOME. Interestingly, Connectiva was an RPM-based distribution, but Synaptic is now more commonly associated with the DEB packages provided by distributions such as Ubuntu and Debian.

The Synaptic Package Management utility is installed by default as part of any Ubuntu installation. Select the System Administration Synaptic Package Manager menu item to start the Synaptic tool.
