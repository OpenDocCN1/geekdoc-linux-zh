When this dialog first displays, it won't contain any sites. To add the update site for CDT, click Add and enter CDT in the name field and the following URL as the location:

http://download.eclipse.org/tools/cdt/releases/galileo

The Galileo release of Eclipse was current when this book was updated; if your system displays the name of another release in the initial Eclipse splash screen, replace galileo with the name of your release of Eclipse. Click OK to save the new entry.

# Tip

If Eclipse reports that the site could not be found or you see similar error messages, exit Eclipse and install the official JDK that you can use Sun's version of Java rather than the one provided by OpenJDK, which is the default JDK that you have on Ubuntu. To install Sun's JDK, you must first enable the partner repository in the System ↻ Software Sources application. You can then install the sun-java6-jdk package, and use the update-alternatives --config java command to set Sun's JDK as the default version of Java used by your applications. You will then be able to start Eclipse and activate the CDT update.
