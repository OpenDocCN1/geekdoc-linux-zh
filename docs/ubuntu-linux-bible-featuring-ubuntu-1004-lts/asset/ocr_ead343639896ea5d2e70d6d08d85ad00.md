# Tip

If you do not want Pidgin to add an icon for itself in the system tray and continue running in the background once the Buddy List is closed, selects the Preferences menu option to display the Preferences dialog, select the Interface tab, and Select from the "Show system tray icon" dropdown list. As a compromise, you can select "On unused message" to choose the notification area icon to continue to be displayed after closing the Buddy List only if there are unused messages pending.

To terminate Pidgin, you must right-click on Pidgin in the notification portion of the GNOME panel (located at the far right of the top panel, by default) and Select Quit from the content-sensitive menu, a Buddy List window will be displayed the next time that you start Pidgin. If you Quit while a Buddy List window is displayed on the screen, the Buddy List window displays the next time that you start Pidgin. whether the Buddy List window depends on whether you've disabled the notification/system tray icon. If it is enabled (which is the default), only the notification/system tray icon is displayed the next time that you start Pidgin. If it is disabled, the Buddy List window will always display when you start Pidgin.

# Getting More Information about Pidgin

As with all GNOME applications, you can get online help in multiple ways while using Pidgin:

+   - Pressing the F1 key or selecting the Help Online Help menu option takes you to, the Pidgin FAQ on the Pidgin web, which may already contain the answer to your question.
- Selecting the Help Get Online Help menu option takes you to the section of Ubuntu's Launchpad site that provides help for Pidgin in the release of Ubuntu that you're running. You can post a question or review questions that others have already asked. This page also provides links to the IRC channel where Ubuntu is discussed and to the Web-based Ubuntu forums. See the section of this chapter entitled "Using IRC" for more information about IRC.

As you might expect, the Pidgin web site, www.pidgin.im, also provides a good deal of information about Pidgin, primarily in the Support and Development section that is located at http://developer.pidgin.im.
