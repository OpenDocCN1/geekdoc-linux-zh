# # Types of Virtual Machines

Virtual machines can work in many different ways. The differences between these approaches to virtualization can be subtle, but are always significant in terms of the capabilities that they provide and the hardware and software requirements for the underlying system. The most common approaches to virtual machines today are the following:

+   * Guest OS: Virtual server runs as a separate operating system instance within a virtualization application that itself runs on an instance of a specific operating system. Parallels Workstation, VirtualBox, VMware Workstation, and VMware GSX are the most common examples of this approach to virtualization. The Ubuntu repositories include packages for the open source version of VirtualBox and also include the packages for Sun's version of VirtualBox, which is free for personal or individual use. A free version of VMware Server, VMware Player, and ESXI are all available for free download from the VMware web site.
* System-level or operating system virtualization: Multiple, distinct environments are running on a single instance of an operating kernel. System-level virtualization is based on the change root (chroot) concept that is available on all modern UNIX-like systems, and gives each virtual machine a portion of the parent system's root filesystem as the root filesystem for the virtual machine, as well as its own set of processes that execute relative to that root filesystem. Linux virtualization solutions such as FreeVPS, Linux Server, OpenVZ, and Virtuoso are all examples of system-level virtualization. The kernel and user-space administrative utilities are provided in the Ubuntu repositories.
* Parallel virtual machine: Some physical or virtual systems are organized into a single virtual machine using clustering software such as PVM (..osm.org/pvm/pvm_home.html). The resulting cluster is capable of performing complex CPU and data-intensive calculations in a cooperative fashion. The PVM packages are available from the Ubuntu repositories, but are not discussed in detail in this chapter because clustering is an advanced, specialized technology that requires its own book.
* Paravirtualization: Drivers in the virtual machines are modified so that they know they are running in a virtual machine environment and optimize device access for that. This can significantly reduce overhead and increase disk and network I/O. Paravirtualization is typically used in virtualization environments that also use a virtual machine monitor (known as a hypervisor), which runs on top of your machine's hardware, manages protected or privileged CPU operations that are requested by any virtual machine, and manages the hardware access requests that are made by any virtual machine. The most popular examples of hypervisor-based virtualization in use today are Citrix Xen, Microsoft's Hyper-V, and VMware's ESXi
