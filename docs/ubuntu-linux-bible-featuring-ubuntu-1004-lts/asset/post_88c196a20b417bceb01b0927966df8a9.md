Understanding exactly what people mean when they say “Linux” is the key to understanding how so many different versions of the same thing can be available, but requires a little insight into how personal computers actually work in terms of software.

When you install an operating system such as Linux, Microsoft Windows, or Apple's Mac OS X your computer system, you are installing some amount of software that is invisible to any regular user because it runs behind the scenes. This software handles handling, starting, and stopping different programs, communicating with your computer's hardware, communicating with peripherals such as your printer; and so on. This is generally known as system software because regular users do not directly interact with it, but it needs to be present and providing the services that application software relies on. The core piece of this system is usually referred to as a kernel because it is the central piece of the operating system and everything else builds on the fundamental features of it.

By itself, a kernel isn't very interesting—people don't want to run a kernel; they want to run applications. These applications depend on services that are provided by both the kernel and by other system software. For example, if you want to print a file, whatever you're needs to create a version of the file that is formatted in a way that your printer understands, and schedule it for printing. Another piece of software handles the formatted file to printer, making sure that the file prints correctly, and so on.

In popular, Linux is the collective name for an operating system and its associated applications. In reality, Linux is technically the name of the just kernel—most of the applications that anyone uses with Linux come from other free software projects. A Linux distribution is the correct term for a Linux kernel, a set of applications that can run on top of it (regardless of where they come), and a tool to install everything and configure your system. Each company or organization provides a distribution taking advantage of the open source nature of the Linux kernel and the applications run on top of it by putting together the “right” collection of applications that anyone want to run on top of it.

## Chapter 1: The Ubuntu Linux Project

Of course, getting a CD or DVD that just contains a bunch of software would be next useless without some easy way of installing it and configuring it so that it works with your particular computer system (identifying peripherals, setting it up to communicate over your network or with your ISP, creating user accounts, etc.). Therefore, anyone puts together a Linux distribution provides a tool for installing and configuring the system, which is generally what you run boot from a Linux CD or DVD for the first time. This installation tool generally leverages a package management system that makes it easy to add or remove sets of related applications, identifying dependencies between different software components to ensure that the applications you install will actually execute correctly.

Linux distributions are the key to understanding how Linux can be free and sold at the same time. The source code for the Linux kernel and open source applications are, indeed, freely available from thousands of sites on the Internet. Anyone who wants can get it, but putting it all together in an easily installable, usable form is another thing entirely. When people sell a Linux distribution, they are basically charging you for the media it comes on, on the time and effort they invested in putting it all together, and (in some cases) "charging in advance" for any customer support that you might need if you encounter installation or initial problems.

Developing Linux distributions and making them widely available have been critical to the adoption of Linux as an operating system because these distributions have made possible for people to actually install and use Linux, the GNU utilities, and so.

## Introducing Ubuntu Linux

Ubuntu is a Linux distribution founded in 2004. Originally focused on the needs of desktop and laptop users, Ubuntu has branched out since then and now offers distributions focused on the needs of commercial users with their Ubuntu Server distribution, Ubuntu JeOS for virtualization platforms, and Ubuntu Mobile for mobile and embedded devices such as smartphones, Internet tablets, and so on. All of these flavors are of the Ubuntu project sponsored by Canonical (www.canonical.com), a company founded by Mark Shuttleworth, a successful African entrepreneur, long-time Debian developer, and open source advocate. Ubuntu is a Debian-based Linux distribution (more about that later in this chapter) that uses a graphical user interface known as GNOME as its desktop environment. (GNOME is discussed in detail in Chapter 5, "Using the GNOME Desktop.") Sister projects (officially known as Ubuntu Editions) to Desktop Ubuntu include:

- Kubuntu: A version of Ubuntu that uses the KDE desktop environment instead of GNOME
- Xubuntu: A version of Ubuntu that uses the lighter-weight Xfce desktop
- Gobuntu: A version of Ubuntu that uses completely open source software
- Eduntu: A version of Ubuntu that focuses on educational applications and popular-using it of Linux in schools

## The Ubuntu Manifesto

The Ubuntu Manifesto is a statement phrased in the classic manifesto form beloved of artistic and political movements. The Ubuntu Manifesto is summarized online as the Philosophy section of the Ubuntu web site (www.ubuntu.org/ubuntu/philosophy). Its core ideas are as follows:

- Every user user have the freedom to run, copy, distribute, share, change, and improve his software for any purpose without licensing fees.
- Every computer user should be able to use her software in the language of her choice.
- Every computer user should be given every opportunity to use software, even if the user works under a disability.

The first bullet is largely a restatement of the goals of open source software in general, but the second and third bullets are two of the big drivers for the success of Ubuntu.
