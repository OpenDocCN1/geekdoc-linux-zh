# Chapter 6: Using the Compiz Window Manager

Modern underlying window managers like Compiz use separate applications to handle window decorations (window borders, buttons, frames, etc.), while the window manager focuses on window placement, movement, and special effects. This provides a flexible environment that follows the traditional UNIX philosophy of writing smaller applications that do one thing, do it well, and can work together to perform complex tasks.

Compiz, which is all the rage in Linux circles nowadays, provides a nice blend of the best possible use of high-performance graphics hardware, providing attractive window effects for fans of eye candy and a flexible window management environment that is easily modified and extended.

# Compiz History: Compiz, Emerald, Beryl, and Friends

This section discusses the history of composing window managers on Linux and the window managers that led to Compiz and Compiz Fusion. Not everyone wants a history lesson, so if you're not interested, feel free to skip ahead. This section will provide a handy reference after you've heard terms such as Beryl, Emerald, Compiz, and Compiz Fusion over and over what they mean.

Like all graphics components on Linux systems, compositing window managers depend on the capabilities of the underlying X Window System. To provide high-performance special effects, compositing window managers require especially tight integration between graphics and the window manager. Compiz is not the first compositing window manager—composite has been supported for a while in window managers as Metacity, the window manager that was traditionally associated with GNOME 2.2 (and on Ubuntu releases prior to 7.10), and Xfwm, the window manager introduced by the Xfce desktop (http://xfce.org).

# Tip

If you find that Compiz is too resource-intensive for your tastes, or if you simply want to run another window manager, you may want to experiment with running the Xcompmgr composition manager with that window manager. Xcompmgr is designed to provide the graphical eye candy with compositing for any X window manager. To experiment with this tool, install the xcompmgr package, switch to your favorite window manager, and then start Xcompmgr. If you like it, you can add it to your startup applications after customizing your system to start a window manager other than Compiz, as explained in the section of Chapter 5 entitled “Using a Window Manager."
