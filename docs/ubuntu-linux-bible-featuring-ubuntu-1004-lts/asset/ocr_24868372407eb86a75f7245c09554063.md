When you connect to an FTP server from the command line, you see some information about the FTP server and the system that it is running, and the remote system eventually prompts you for the login that you want to connect to it. (How much information an FTP server displays about itself depends on the specific FTP server software that is running and how the FTP server was configured.)

As you'll see from the last line of the previous example, an FTP server's login prompt usually tries to provide some defaults. In this case, I was logged in as the v on the system which I initiated the FTP connection. If that is the login name that you want to connect to the remote FTP server, you can simply press Return to accept the default. If you want to connect as another user, use that user's login name and press Return, as in the following example which I specify the username vonhagen:

Name (192.168.6.64:vwh): vonhagen
331 User vonhagen OK. Password required
Password:

# Tip

You can usually log in on an anonymous FTP server from the command line by entering the login name and supplying your e-mail address as the password. ■

After entering your login name, the remote FTP server prompts you for the password for the specified user on the FTP server. Enter password and press Return. If you've entered a valid username and password, you'll see a confirmation message, some optional information about the remote FTP server, and the ftp> prompt from the remote machine, telling you that it's ready to do something, as in the following example:

```
230 Login successful
Remote system type is UNIX.
Using binary mode to transfer files.
ftp>
```

All FTP servers support numerous commands, which you can see at any time by typing a question mark and pressing Return, as in the following example:

```
ftp ?
Commands may be abbreviated. Commands are:
! debug mdir qc send
$ mget sendport site
account disconnect mls put size
append exit pwd status
ascii mode quit struct
bell get modify quote system
```
