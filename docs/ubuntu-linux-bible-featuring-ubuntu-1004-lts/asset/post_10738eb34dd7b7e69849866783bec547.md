## Using GIMP

GIMP stands for "GNU Image Manipulation program," the premiere open source graphics for Linux systems. GIMP originally stood for "General Image Manipulation Program" and was created by Spencer Kimbill and Peter Mathis. From the beginning, GIMP was designed to be incredibly extensible by the addition of plugins that could be written, compiled, and separated, yet would work seamlessly within the GIMP framework. Like any other open source package, GIMP has substantially benefited from the contributions of others, especially in terms of plugin-development. GIMP is a shining example of a powerful and successful open source package, also having been ported to Microsoft Windows and Apple's Mac OS and used extensively on those platforms. For all of the details of GIMP history, see www.gimp.org/about/ancient_history.html.

Prior to Ubuntu 10.04, GIMP was automatically installed as part of a default Ubuntu desktop installation. With Ubuntu 10.04, you will have to install the GIMP application yourself using any of the package management tools discussed in Chapter 19, "Adding, Removing, and Updating Software." The OpenOffice.org Draw package, discussed later in this chapter, is the default graphics application on an Ubuntu 10.04 system, but if you really want to do serious graphics work, you'll want to install GIMP.

GIMP is legendary among GNU software packages, especially as the GNOME desktop environment became, the toolkit upon which most of the GNOME user interface is based is GTK, the GIMP Tool Kit. Without repeating everything on the GIMP Ancient History page, let's just say that GIMP started out using another X System toolkit, but authors decided to create their own, which was full-featured enough to be adopted by many other projects. Bibically, GIMP beat GTK, which begat GTK+, which begat GNOME, which now supports GIMP. I hope that clear—there will be a quiz later.

### Starting GIMP

Once GIMP is installed on your system, you can start it manually in a variety of different ways, the most basic of which are:

- By selecting GIMP Image Editor from the Applications Graphics menu
- By typing the gimp command in a GNOME Terminal or xterm window and pressing Return

When you start GIMP for the first time, the default display that you depends on the version of GIMP that you are running. ## A Quick Tour of GIMP

The first thing that most people do when using GIMP is to customize the various panels and dialogs that display each GIMP is launched.

As you can see from Figure 15-1, GIMP initially displays multiple windows. A single window can actually contain multiple dialogs that are combined into one dialog—such dialogs are known as dockable dialogs. To make things even more flexible, dialogs can be docked together or combined as tabs within a single dialog. The default screen in Figure 15-1 displays the following windows. Each window description includes a list of the dialogs contained within that:

- Main GIMP window: Provides the GIMP menus and what that you are editing. Opening another graphic at the same time displays graphic in a copy of this window.
- Toolbox window: The window at the left contains two dialogs: at the top, the Toolbox and below it, the Tool Options. The Toolbox dialog shows the editing or selection tool that is currently selected and provides access to all editing and selection tools. The Tool Options dialog provides access to the configurable aspects of the GIMP that is currently selected in the Main Toolbox dialog.
- Layers and Branches window: The window at the right contains two dialogs: at the top, the "Layers, Channels, and Paths" dialog; and below it, the "Brushes, Patterns, and Gradients" dialog. The interesting thing about this window is that each of the dialogs that contains actually consists of multiple dialogs that have docked together as tabs. The top dialog consists of the "Layers, Channels, and Paths" and the Undo dialogs docked together, the bottom dialog consists of Brushes, Palettes, and Gradients docked together.

## Tip

GIMP's main window dialog must always be active in any version of GIMP, even if it is minimized—actually closing this dialog causes GIMP to exit. Similarly, most GIMP users find it extremely useful to have the Layers dialog available so that they have easy access to the portions of an image that are on different layers. ■

Docking or undocking dialogs is a fairly simple process. To unlock dialogs, select the header for that dialog (the header inside the window, not the title bar for the window itself), and drag it out of the window in which it is currently displayed. For example, to undock the “Toolbox Options” dialog from the Toolbox window, left-click and hold on the header of the “Toolbox Options” dialog (which initially says “Paintbrush” because the paintbrush is the tool that is initially selected when you start GIMP, and drag the header out of the Toolbox window.
