# GNOME Games on Ubuntu

Figure 17-1 shows the games that are available on your Ubuntu system after installing the gnome-games package. This package plus the default games that are provided on an Ubuntu system gives you a variety of different games across the gaming spectrum, which I classify as board games, card games, and video games.

FIGURE 17-1
The Games menu in a default Ubuntu installation

![](bbox=[0.088, 0.313, 0.545, 0.553])

As you can see from this figure, these games are organized into a single main menu and a sub- that contains logic-related games.

The rest of this section discusses the games shown on these menus, providing an overview of each game. I have organized these into logical sections rather following the layout of the Games menu because most people tend to find a specific game or certain type of game—at least I do! Because these are all either part of a default Desktop installation or are easily installed as part of the gnome-games package, and everyone enjoys different types of games, you'll quickly be able to figure out which games appeal to you and try them out yourself.
