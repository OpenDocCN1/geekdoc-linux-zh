# FIGURE 2-7

Specifying your keyboard type

+   2. The dialog shown in Figure 2-7 prompts you to specify the type of keyboard attached to your computer. The default value is based on your settings on previous screens — if this is incorrect, click “Choose your own” and select your keyboard type from the full list of supported keyboard types. You can enter sample text into the text area at the bottom of the screen to verify that the correct symbols are being displayed as you type. Once you are sure that the correct keyboard is set, click Forward to proceed.
