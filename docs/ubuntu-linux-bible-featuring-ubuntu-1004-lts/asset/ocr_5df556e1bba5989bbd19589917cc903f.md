# Chapter 16: Working with Multimedia

# Converting Audio File Formats

It's almost inevitable that you'll eventually get some great music from free downloads, off the Internet, or ripping it from your CDs, only to find that it isn't "the right" format for some other purpose. The best examples of these are things like:

+   - Ripping CDs into Ogg Vorbis format and wanting to play them on an iPod, which can't play OGG files
- Downloading live concert recordings in FLAC format, only to find that this format is not usable with today's iPod (and probably never be because of the size of the FLAC files)
- Wanting create "greatest hits" CD for your car, only to find that you can't create a playable CD from MP3, OGG, or FLAC files

Regardless of which you find yourself in, it's irritating to have music that you can play on your desktop system but you can't use in portable players, to burn CDs, and so on. The problem that these examples expose is that specific devices and types of media require specific audio formats. Apple's iPod can only play files in MP3 or Apple's owns; audio CDs must contain WAV files and so on. CD-burning applications like Brasero and k3b will automatically convert files to the WAV format when required when burning CDs, but they so on the fly. If you actually want to convert audio files that you already have so that you can permanently use them in some other format?

Luckily, Ubuntu provides a great solution to these sorts of problems through the Sound Converter application. As the name imply, this application's sole function is to convert digital audio files from one format to another.

Because not everyone will be using Ubuntu system for serious audio work, Sound Converter isn't installed by default. You must install Sound Converter yourself from the soundconverter package, using your favorite Package Management application as discussed in Chapter 19.

# Tip

Sound Converter uses the Gstreamer framework discussed earlier in this chapter in the section on "Configuring the Gstreamer Framework and Plug-Ins." You must follow the instructions in that section trying to use Sound Converter—well, at least before trying to successfully use Sound Converter.

Once you've installed Sound Converter, you can execute it by selecting the Applications Sound & Video Sound Converter menu command. Sound Converter's primary dialog displays, as shown in Figure 16-48.

To add the files you want to convert, click "Add File" to display a dialog that enables you to navigate and select the files that you want to convert to another format. Once you've selected those files, click Open to add the selected files to the list of files you want to convert and close the Navigation dialog. The files that you selected display in the main Sound Converter dialog, as shown in Figure 16-49. (You can also click "Add Directory" to select and add an entire directory of files.)
