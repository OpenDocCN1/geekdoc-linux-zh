# Getting Information about Commands

As you can see from the final example in this section, many command-line utilities provide a --help option, which displays what is known as a usage message. A usage message is a short summary of how to use a command, summarizing available options and their meanings. Unfortunately, not all commands offer a --help option, and those that can't display all possible information about those options are discussed in Chapters 5, "Using the GNOME Desktop," and 6, "Using the Compiz Window Manager," where the graphical environments used on Ubuntu systems provide a huge assortment of online help that makes it easy for you to get information about how to use graphical commands. Luckily, the Ubuntu command-line environment also provides a similar amount of online help in the form of man and info commands.

The man command is your best friend when using or experimenting with command-line programs. The man command displays manual pages, formatted for your screen. In Linux/UNIX fashion, the man command paginates its output using the Linux version of UNIX more known as less—to make easy to scroll forward or backward in your output. Because the online reference information displayed by the man command is displayed screen/page at a time and corresponds to the documentation you traditionally find in a printed reference manual, the documentation displayed by man is generally referred to as a man page or as man pages.

As an example of using the man command, you can type man for additional information on the man command itself. The first part of the man page looks like the following:

man(1)
Manual pager utils man(1)

# NAME

man - an interface to the on-line reference manuals

# SYNOPSIS

```
man [-c|-w]-tzHT device] [-adhu7V] [-i|[-i]]
[-m system...]] [-L Locale] [-p string] [-M Path]
[-P pager] [-r prompt] [-S list] [-e extension]
[section page] ...
man -l [-7] [-tzHI device] [-p string] [-P pager]
[-r prompt file...
man -k [apropos options] regex ...
man -f [what options] page ...
```

# DESCRIPTION

man is the system's manual page. Each page argument given to man is normally the name of a program, utility or function. The manual page associated with each of these arguments is found and displayed. A section, if provided, will direct man to look only in that section of the manual. The default action is to search in all of the available sections, following a predefined order and to show only the first page found, even if page exists in several sections.
