Most of us are used to working with text files in various applications, often specified by their file extension. However, the files produced by graphical word processors such as Microsoft Word (.doc) or .ppt files produced by PowerPoint, are not plain text. While it is possible to use these files, it often makes them hard to use with any application other than the one created them.

At the end of the day you may have application-specific files that are the lowest-denominator file format (like text files, or .txt). The advantage is that they can represent every symbol you find on a keyboard. The nice thing about these files is that they are easy to read, and easy to work with.

If you are using a modern Ubuntu Linux system, you will find it quite easy to edit a text file of these days. If you write code, this provides the lowest-common format that can be processed by any compiler or interpreter. It is a safe way to store text files that you can work on your Ubuntu Linux system as you can on your Mac or Windows.

# Moving Around in Emacs

There are many different keys for moving the insertion cursor in Emacs:

+   - Ctrl+a: Go to the beginning of the current line.
- Ctrl+e: Go to the end of the current line.
- Ctrl+f: Move forward one character.
- Ctrl+b: Move backward one character.
- Ctrl+p: Move to the previous line.
- Ctrl+n: Move to the next line.
- Ctrl+v: Scroll down one screen.
- Esc+b: Move backward one word.
- Esc+f: Move forward one word.
- Esc+v: Scroll up one screen.
