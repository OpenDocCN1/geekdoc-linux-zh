# You Say URL, I Say URI…

As you have noticed in the other chapters of this book, Web-aware applications often use different terms from what you and I might simply think of "web addresses." URL (Uniform Resource Locator) is the traditional acronym and term for a web address, but the acronym and term URI (Uniform Resource Identifier) is more technically correct. Another acronym and term that you may come across is URN (Universal Resource Name).

he relationship between these acronyms is the following: a URI is any way to identify a web resource. A URL is a URI that explicitly provides the location of a resource and the protocol used to retrieve it. A URN is a URI that simply provides the name of a resource and may not tell you how to retrieve it or where it is located.

The bottom line is that most people think of and use the terms URI, URL, and web address interchange. If you want to pick one to use, URI is the right term to use.
