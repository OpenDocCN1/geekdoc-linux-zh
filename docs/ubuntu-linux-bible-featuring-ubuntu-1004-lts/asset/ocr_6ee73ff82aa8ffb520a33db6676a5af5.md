# # Installing Ubuntu

This chapter discusses how to install or simply experiment with Ubuntu Linux on a new or existing 32-bit or 64-bit PC system. This book includes an Ubuntu 10.04 Desktop CD from which you can either install permanently on your system or simply test-drive Ubuntu 10.04 without making any changes to your current system. Test-driving Ubuntu provides a great way to experiment with preconfigured Ubuntu installation without actually modifying your hard drive or going through the installation process. You can also use a Live CD as a portable computer to take with you, temporarily converting other computers to Ubuntu Linux systems regardless of the machine is currently running Windows. The Live CDs also offer an impressive Live CD Persistence that enables you to work and save configuration when using the Desktop CD to removable media that you can reuse the next time you boot from the CD. In most cases, you can access your existing disk storage after booting from the Ubuntu CD, so that you can even do work while using the Live CDs and save to a USB stick or to the disk used by your operating system(s).

The Ubuntu Desktop CD takes the traditional Live concept one step further by enabling you to quickly install Ubuntu Linux using an easy-to-use installer that is available by clicking an icon on the desktop that you see booting from the Live CD. Ubuntu installer can automatically reduce the size of existing Microsoft Windows or Linux partitions to free up space in which you can install Ubuntu (assuming that your existing partitions are not full, of course).
