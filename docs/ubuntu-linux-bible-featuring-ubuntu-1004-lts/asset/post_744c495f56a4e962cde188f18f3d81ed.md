## Using Empathy

Empathy's main dialog is the "Contact List" dialog, shown in Figure 10-9. From top to bottom, this dialog shows your current status, public entities that are supported by any of the instant messaging services that are associated with your accounts, and the status of any available contacts (generally known in IM-speak as buddies).

You can initiate a conversation with an existing contact in one of two ways:

- Double-click on that contact's name in the bottom portion of the "Contact List" dialog.
- Select the "Contact List" dialog's Chat ↻ New Conversation menu command, and enter the name of the contact that you want to converse with. This is the only way to initiate a conversation with a contact that you did not include in a group in the "Contact List" dialog.

Doing either of these displays a Conversation window like the one shown in Figure 10-10.

## Adding Contacts in Empathy

Over time, you will probably want to exchange instant messages with more and more people. To simplify this, you'll want to add them as contacts (commonly referred to as buddies) so that they show up in the bottom portion of the “Contact List” dialog and you can easily initiate conversations (chats) with them.

To add a contact in Empathy, select the “Contact List” Chat Add Contact menu command. This displays the dialog shown in Figure 10-11.

The top field of this dialog is a dropdown that enables you to identify which of your Empathy accounts is associated with the new contact. The instant messaging service (and associated protocol) must be the same as used by the person that you want to contact. The identifier field is the name of your instant messaging account, and the Alias field enables you to specify a more memorable name for your contact. Any alias that you set will be the name that is shown for that contact in the “Contact List” dialog. For example, if you have problems remembering that the contact name for a college friend is robotlander66, you can enter your friend's real name as an alias, and you'll have an easier time distinguishing them from all your other contacts who have instant messaging accounts with the string robotoverland. If you don't specify an alias, Empathy will set the Alias to be the same as the Identifier for the account.

Once you enter the name of your new contact, the dialog shown in Figure 10-11 expands to look like the dialog shown in Figure 10-12.

This expanded dialog lets you specify which (if any) of the groups in your Contact List that the new contact will be added to. Groups are essentially section headings in the contact window that can be expanded or collapsed, making it easy for you to organize your contacts. You can also define a new group by entering its name in the text above the group list and clicking “Add Group.” Being able to define your groups makes it easy for you, like “Work Friends,” “Poker Night,” and “Family,” to organize your contacts into logical sets. On the other hand, you may not want to add someone whom you rarely chat to a specific group, which will mean that their Identifier or Alias will not be displayed in the “Contact List” dialog. As described earlier, you can still initiate a conversation with unlisted contacts by using the “Contact List” dialog’s Chat New Conversation menu command and manually entering the name of the contact that you want to converse with.

## Reviewing Past Conversations

Empathy automatically keeps a record of your conversations and provides a convenient calendar-driven dialog that enables you to locate previous conversations that you've had with any of your contacts, as shown in Figure 10-13.

To display this, select the Selection window's Contact ❖ Past Conversations command. You can then select specific dates from the calendar at the upper left to see a record of any conversation that you had with that contact on the specified date. This can be especially convenient if you've made promises that you've forgotten or your contact is no longer speaking to you and you're wondering just what you said.

## Exiting Empathy

To exit Empathy, select the "Contact List" dialog's Chat ❖ Quit menu command or use the "Close Window" control to close the "Contact List" dialog.

## Instant Messaging on Ubuntu with Pidgin

Pidgin (www.pidgin.im) is the new name of a popular instant messaging application for Linux that was originally known as GAIM (GTK+ AOL Instant Messenger). This name was changed to Gain due to pressure from AOL, which was still not good enough once AOL marked the term AIM, so there you go—Pidgin it is.

Pidgin supports a huge number of instant messaging protocols, enables you to set up chat rooms, and even supports file transfers. Although Empathy is now the default GNOME client, Pidgin is still very popular—the next few sections discuss how to configure and use.

To start Pidgin on an Ubuntu Desktop system, select the Applications Internet Pidgin Messenger menu item. Click the icon for Pidgin displays in your system's tray/notification area, and either Pidgin's Buddy window or an account configuration dialog.

## Configuring Messaging Accounts in Pidgin

The first time you start Pidgin, it displays a dialog letting you know that you have configured any instant messaging accounts, and offering to to configure your first one. Click Add to proceed. The "Add Account" dialog displays, as shown in Figure 10-14.

If you already defined an IM account in Pidgin and want to add another one, you can do so any time from Pidgin's Accounts dialog, which you can display by selecting the Accounts Manage menu from the Pidgin List window. Click Add to define a new Pidgin account from this dialog.

- Click the Protocol dropdown menu to select the instant messaging protocol that you want to use, which essentially means the instant messaging service where you have an instant messaging account.
- After selecting the protocol/service where you have an instant messaging account, enter your Screen Name (the name of your IM account at a given service), Password, and (optionally) a local alias that you want to use for this account.
- If your computer is secure, you can click the "Remember password" checkbox, which will prevent you from having to enter your password each time you start Pidgin, but which will also store your password in plaintext in Pidgin's configuration file.
- Next, you can optionally select the "New Mail notifications" checkbox to cause Pidgin to notify whenever you have new e-mail (see Figure 10-15). You can also customize the icon that you want to associate with this account by selecting the "Use this buddy icon" checkbox and clicking on the icon to display a dialog that lets you navigate to a directory where the custom icons you want to use are located.
