+   * **Serial Port #2:** A printer that is connected to the second serial port on your system
* **Other:** A local printer that you can access through a Universal Resource Identifier (URI) that uniquely identifies its connection mechanism
* **Network Printer:** Lists any existing network printers that can be located automatically, and provides several generic types of communicating with a networked printer:
* **AppSocket/HP JetDirect:** A printer that you can print directly over the network by using a specific IP address and port. This is a common way of printing modern-standalone, network-aware printers from manufacturers such as Brother, HP, Epson, and so. After selecting this option, you will need to provide information about your new printer. Enter the name or IP address of the printer in the Host field. You can leave the default port (9100) unchanged unless you use a different port for JetDirect connections.
* **Internet Printing Protocol (IPP):** A printer whose queue is managed by a specific host. IPP is a common alternative to JetDirect but supports capabilities such as authentication, access control, and host-side formatting, and you will need to know the name or IP address of the host that manages the printer and the name of the queue for the specified printer on that host. You can use the "Find Queue" button to list all of the publicly available queues on a specified host.
* **LPD/LPR printer:** A printer whose queue is managed by a specific host (including the host) using the traditional UNIX Line Printer Daemon (LPD) protocol. You will need to know the name or IP address of the host that manages the printer, and the name of the queue for the specified printer on that host. You can use the Probe button to list all of the publicly available queues on a specified host.
* **Windows printer via SAMBA:** A printer that is managed by a host located on a Microsoft Windows network. Such hosts are typically Windows servers, but can also include Samba servers running on other UNIX or Linux systems on your network. You will need to know the name of your local workgroup or domain, or the IP address of the host that manages the printer, and the name of the queue for the specified printer on that host. You can use the Browse button to navigate through your local workgroup/domain to locate the publicly available queues on a specified host.
