+   If you've made any changes to the default letter settings and are going to be reusing them, the final Letter Wizard dialog enables you to update the Wizard's default set- or save your modifications as a new template. To update your default settings, enter a name to associate with your new settings. If you want to create a new template from these settings and continue writing your letter, click the Browse button and enter a new filename for the new template. This file will still be used the next time you use the Letter Wizard, but you can easily create documents from different templates as described later in this chapter in the section "Creating and Using Templates."
