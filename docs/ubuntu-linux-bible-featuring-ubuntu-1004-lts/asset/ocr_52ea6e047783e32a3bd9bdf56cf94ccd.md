Although this output is somewhat ugly, it is easy enough to scan to determine if your new card has been detected. If it has, you should proceed to the configuration utility associated with the capability or type of device that the PCI card provides.

# Examining and Troubleshooting Devices Graphically

This utility isn't installed by default, but you can install it using your favorite Package Management software (as discussed in Chapter 19) the gnome-device-manager package on an Ubuntu system.
