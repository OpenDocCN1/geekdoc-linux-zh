# Using the Ubuntu Update Manager

Ubuntu's Update Manager checks the active repositories you listed in /etc/apt/sources.list and notifies you if any installed packages are available. The Update Manager uses an associated panel applet to let you know which updates are available by displaying a small orange icon and a pop-up dialog when updates are first found. If you see this icon, you can move the cursor over it to display a tooltip that summarizes available updates.

Clicking on this icon starts the Update Manager itself, which is shown in Figure 19-28. You can also start the Update Manager manually at any time by selecting the System Administration Update menu command.
