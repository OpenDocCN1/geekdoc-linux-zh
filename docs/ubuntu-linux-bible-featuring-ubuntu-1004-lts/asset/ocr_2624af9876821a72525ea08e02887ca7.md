# Part III: Ubuntu System Administrators

Note
Most Linux systems use an Internet service manager as inet or xinetd to manage incoming requests for on-demand services as ftp, tftp, rsync, and vnc. These Internet service managers automatically start the daemon when an incoming request is received. Although these service managers are available in the Ubuntu repositories, they are not installed by default. On Ubuntu systems, a specific system startup file that starts rsync daemon is provided as /etc/init.d/rsync. If you install xinetd and want to use it to manage rsync requests, you will want to disable this file and create the file /etc/defaults/rsync.conf to make sure that the rsync service is enabled on your system.

The /etc/defaults/rsync file just determines whether rsync is enabled or not. The actual configuration information for rsync itself is stored in the file /etc/rsyncd.conf, which does not exist by default on an Ubuntu system. To create this file, use your favorite text editor and a command like the following:

```
$ sudo emacs /etc/rsyncd.conf
```

A minimal rsync configuration file that contains a definition remotely synchronizing the directories or on your system would look something like the following:

```
uid = root
transfer logging = true
log format = %h %o %f %l %
log file = /var/log/rsyncd.log
host allow = 192.168.6.255/3

[homes]
path = /home
comment = Home Directories
auth users = vwh
secrets file = /etc/rsyncd.secrets
```

The first section of this file sets parameters for how the rsync daemon runs. In order, the rsync daemon runs as root (uid), logs all transfers (transfer logging), a specific log file format (log format) and log file (log file), allows access from any host whose IP address is on the 192.168.6.x subnet (hosts allow). The second section of this file identifies a synchronizable entity known as home that maps to the directory /home on that system. Synchronization to this directory is done as the user vwh, password must be supplied in the file /etc/rsyncd.secrets.

After saving this file, use your favorite text editor to create the file /etc/rsyncd.secrets, with a command like the following:

```
$ sudo emacs /etc/rsyncd.secrets
```

This file should contain an entry for each auth users entry in the /etc/rsyncd.conf file, in this case, vwh. Each entry in this file contains the name of a user, a colon, and the plaintext password for your user, as in the following example:

```
vwh:hellothere
```
