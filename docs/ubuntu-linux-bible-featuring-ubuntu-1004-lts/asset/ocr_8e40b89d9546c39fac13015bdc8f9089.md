The other is e-mail that is formatted as HTML, which lets you use different fonts, special characters for bullets, and so on. Many people prefer one or the other, and whether or not you can read mail delivered in HTML format is up to the e-mail client that you're using (although most can, now-days—Evolution certainly can).

# Note

Whether or not an e-mail client can send mail in HTML format is a different question from whether you should send e-mail as HTML. Many people, some government and military sites, and specific recipients as mailing lists, do not want to receive or will not accept e-mail formatted as HTML. I'm not a fan,—always send text mail.

As shown in Figure 7-12, when you first compose messages in Evolution, it use standard format for your messages by default. If you want to switch to using HTML mail, you can do this in one of two ways:

+   * If you want to send just the current message in HTML format, select the HTML command from the Format menu in the window where you're composing your message. 7-13 shows the same mail composition window as in Figure 7-12, but displayed as HTML. Additional formatting buttons are active when sending an HTML message, enabling you to use different fonts, different justification formats for the graphs in your message, and so on.
* If you want to send all of your mail as HTML, you must set that as your preference in Evolution's Preferences dialog.
