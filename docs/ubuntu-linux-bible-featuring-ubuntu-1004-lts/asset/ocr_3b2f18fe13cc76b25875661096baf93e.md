Locating the file to import in Evolution's Import Wizard

Click the filename button to display a dialog that enables you to navigate and select the file that you want to import. The mail files you converted using Thunderbird should be located on the CD, DVD, or network location to which you backed up the C:\Documents and Settings\USERNAME\Application Data\Thunderbird\Profiles or C:\Users\USERNAME\AppData\Thunderbird\Profiles directory. They will be located in a subdirectory of this directory that has a name like xxxxxxx.default/Mail/Local Folders, where xxxxxxx is a random string that was generated when you first Thunderbird.

Click Open to open the navigation dialog and open the file you want to import. The File type entry on the "Import a File" dialog should display "Berkeley Mailbox (mbox)" because this is the format of mail files that have been created by Thunderbird. (It is also the format of mail files used by Evolution.) Click Forward to proceed. The dialog shown in Figure 9-7 displays.
