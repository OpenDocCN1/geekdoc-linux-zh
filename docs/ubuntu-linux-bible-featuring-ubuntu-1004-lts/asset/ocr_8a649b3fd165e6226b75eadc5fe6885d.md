# Introduction to Linux Text Editors

The first versions of UNIX for the PDP-11 were distributed by Bell Telephone Laboratories included a small, line-oriented text editor called ed, which was written by Ken Thompson (who is still there, most recently working on the Go programming language at Google). Various people enhanced ed, most notably George Coulours at Queen Mary College (QMC) in the United Kingdom, who added interactive support for editing single lines as part of his for editors (editor), which he brought with him to the University of California at Berkeley (UCB) in 1976. At the same time, Ken Thompson had to go to UCB for a year or so, and while there had begun with Bill Joy and Chuk Haley on the UNIX enhancements that would eventually make up the Berkeley Standard Distribution (BSD).

Haley Joy hacked em for a while, revising it into and then a bunch of others, working their way through the alphabet "visual" they arrived at, which was still line-oriented. In 1976, Joy created vi (which stands for "visual") a screen-oriented editor that shared the command set, thanks to motivation provided by severalADM-3A terminals that were donated to UCB. The flexibility provided by vi in terms of using the entire screen, thanks to the /etc/termcap (terminal capabilities) file, was a huge step in diverging detailed knowledge about the hardware from editor. Around the same time, on the other side of the country, a bunch of Lisp and ITS/TOPS-20 TWENAKS at the MIT Artificial Intelligence (AI) Lab were enhancing an aging line editor for their PDP-10 systems as Text Editor and Corrector (TECO). With inspiration from graphical editing work being done at Stanford's AI Lab, Richard Stallman (leader of GNU and FSF fame) and Guy Steele created a version of TECO which users could add their own commands. They also created and aggregated a set of TECO commands into a single package that provided support for screen-oriented editing using TECO. The TECO commands consisted of a set of macros (sequences of commands that executed together), so the set of macros became known as MACRO, or more, EMACS.
