Modify the rule that is used when devices associated with KVM are created during your system boot process, adding a rule that specifies the TUN/TAP virtual network device /dev/net/tun will be writable by anyone in the kvm group. You will want to add the following entry to the end of the /etc/udev/rules.d/45-kvm.rules file. With no :

```
KERNEL="tun", NAME="%k", OWNER="root", \ \
GROUP="kvm", MODE="0660"
```

# Note

I've seen problems with udev correctly setting ownership and permissions on tun/tap devices. To eliminate the chance of that, you can add the following entries to your /etc/rc.local file (before the "exit" entry):

```
chown root:kvm /dev/net/tun
chmod 0660 /dev/net/tun
```
