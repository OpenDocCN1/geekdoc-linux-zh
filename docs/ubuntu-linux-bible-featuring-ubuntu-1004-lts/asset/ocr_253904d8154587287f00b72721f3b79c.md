# Mounting NFS Directories on Clients

Many different export options are available for entries in an /etc/exports file specification on an NFS server, but their number pales the number of mount options that you can specify when mounting an NFS filesystem from a client system. Mounting a directory from an NFS server can be done in several ways:

+   - By using the mount command from the command line, as in the following example, which mounts the entire pseudo-filesystem that is exported from the NFS server on the directory /mnt, using the mount options specified in mount-options.
This pseudo-filesystem includes all of the entries that were mounted within it:

```
sudo mount -t nfs4 -o mount-options server://mnt
```

+   - By using the mount command from the command line, as in the following example, which mounts the /home subdirectory that is exported from the NFS server on the directory /mnt, using the mount options specified in mount-options:

```
sudo mount -t nfs4 -o mount-options server://home /mnt
```

+   - By creating an entry for a filesystem in the file /etc/fstab, and then mounting it by executing the mount command for that filesystem. This is a sample /etc/fstab entry for the entire pseudo-filesystem that is being exported from the NFS server on the directory /mnt, using the mount options specified in mount-options:

```
server:/ /mnt nfs4 mount-options 0 0
```
