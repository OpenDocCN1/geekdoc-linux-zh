Being able to identify the files provided by a package that is installed on your system can be handy if you are considering removing a package to make sure that doing so does not delete a file that you wish to preserve. The next section describes how to find out what package provides a specific file.

# Tip

You can list the files that are provided by packages that are not yet installed by the apt-file utility with a command as apt-file list package, where package is the name of the package that you are interested in. The apt-file utility is described in more detail in "Determining What Package Provides a Missing File" later in this chapter. 

# Determining What Package Provides an Existing File

After working with Ubuntu for a while and installing, updating, and removing some number of packages, you may be curious about which package provides a certain file on your system. This is easy to determine using the dpkg command's --search option, as in the following example, I'm curious about which package provides the /usr/bin/ar archiving utility:

```
$ dpkg --search /usr/bin/ar
binutils:/usr/bin/ar
```
