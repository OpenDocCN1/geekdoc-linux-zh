# Automatically Checking for Junk Mail

Evolution's ability to filter e-mail messages based on criteria that you define could require a potentially huge number of rules to catch all of the spam and junk mail you may receive. Luckily, Evolution supports the integration of external applications that can analyze messages and identify them as junk if that's the case. Popular examples of this sort of junk e-mail filter application are SpamAssassin (http://spamassin.apache.org/) and Bogofilter (http://bogofilter.sourceforge.net/).

Evolution includes plugins for both SpamAssassin and Bogofilter, which will automatically execute the specified program and apply it to incoming mail. Bogofilter is installed by default on Ubuntu systems, so unless Evolution is not working well enough for you. In my experience, SpamAssassin is more powerful and accurate than Bogofilter, but it is also slower because it does more SPAM checks than Bogofilter.

# Tip

If you want to install SpamAssassin, you must use your favorite software installation tool to install SpamAssassin, as described in Chapter 19, "Adding, Removing, and Updating Software.\ You should check Evolution's plugin-in list to make sure that SpamAssassin is active. To do this, select Plugins from the Edit menu to display the "Plugin Manager" dialog. Once this dialog displays, scroll down to the SpamAssassin plugin-in and make sure it is enabled. Click OK after verifying and enabling this plug-in, necessary.

If you have problems installing or using SpamAssassin, make sure that Evolution's Bogofilter plug-in is not enabled on the Edit menu. This conflicts with SpamAssassin and can cause problems.

Regardless of which SPAM filtering package you use, clicking the Junk button in the Evolution toolbar will identify the currently selected message as junk and move it to your Junk folder.
