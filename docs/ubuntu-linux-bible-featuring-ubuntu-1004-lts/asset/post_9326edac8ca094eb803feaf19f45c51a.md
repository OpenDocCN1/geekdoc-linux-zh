This is a message rather than a true rejection—you will still appear in their Buddy List, and they can subsequently send you a message to clarify why you wanted to add.

## Organizing Buddies in Pidgin

As you accumulate more and more IM contacts, your Buddy List window will fill up and you'll have to scroll further and further to actually find someone screen name you don't remember off. As mentioned in the previous section, you can use groups in the Buddy List window to organize your contacts. This usually feels like overkill when you only have a few buddies, but once you have a few zillion of them, you'll wish you'd organized them into groups from the beginning. Luckily, you can organize buddies into groups almost as easily as you can add them to groups defining them in the first place.

By default, Pidgin provides the following groups which you can organize your buddies:

- Buddies
- Co-workers
- Family
- Friends
- Recent Buddies
- Top Level

To change the group that a buddy is located in, right-click on that buddy, select the "Move To" menu item, and select the group to which you want to move that buddy. you want to move that buddy.

You can create custom groups by selecting the Buddies Add Group command, which displays a dialog in which you can define the name of the new group. You can also rename an existing group by right-clicking on the name of that group and selecting the Rename command.

## Viewing Buddies in Pidgin

By default, Pidgin only shows buddies who are online, which can be confusing after adding a buddy and not seeing their name. You can change which offline buddies are displayed in one of two ways:

- By selecting the Buddies Show command and selecting Offline Buddies. This will display all of your buddies, regardless of whether they are online or offline. Offline buddies will be shown as grayed-out entries with the word Offline shown below their identities. If you are using the default icons for this buddy, the standard green (online) icon will be replaced by a circle with an "x" in the middle when they are offline.
- By right-clicking on the name of a specific buddy in the Buddy List and selecting "Show offline" from the context-sensitive menu that displays. This buddy will be shown in your Buddy List, regardless of their status or whether offline buddies are displayed in general.

Using the Buddies Show Offline Buddies command can be very handy if you aren't sure if you've added someone as a buddy or not, or when reorganizing your contacts into different groups. Selecting this command temporarily will enable you to see all of the buddies that you have defined so far and will also enable you to move existing buddies to other groups, as explained in the previous section.

## Exiting Pidgin

To terminate Pidgin, you must right-click on Pidgin in the notification portion of the GNOME panel (located at the far right of the top panel, by default) and Select Quit from the content-sensitive menu, a Buddy List window will be displayed the next time that you start Pidgin. If you Quit while a Buddy List window is displayed on the screen, the Buddy List window depends on whether you've disabled the notification/system tray icon. If it is enabled (which is the default), only the notification/system tray icon is displayed the next time that you start Pidgin. If it is disabled, the Buddy List window will always display when you start Pidgin.

## Tip

If you don't want Pidgin to add an icon for itself in the system tray and continue running in the background once the Buddy List is closed, selects the Preferences option, select the Interface tab, and Select from the "Show system tray icon" list.

You can post a question or review questions that others have already asked. This page also provides links to the IRC channel where Ubuntu is discussed and to the Web-based Ubuntu forums.
