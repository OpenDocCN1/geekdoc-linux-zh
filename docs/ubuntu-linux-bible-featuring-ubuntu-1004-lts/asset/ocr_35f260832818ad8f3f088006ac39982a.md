13. The extra space available in the document provides a good location for a new frame. First, draw the image frame by clicking and holding the left mouse button on the frame, and then dragging the frame to its new location. To add a new frame, click the "Insert Text Frame" icon from the toolbar (it looks like a small document) and click-and-drag to insert the new frame. For the purposes of this example, I'll insert sample text into the new frame. From the pop-up menu. Select the language for the sample text by right-clicking on the frame and selecting "Sample Text" from the dialog that displays, and click OK. It may seem odd to have a command that inserts random text into a frame, but this is useful when laying out a document before the final content is ready, and it saves you the trouble of having to locate some random text, copy it to the Clipboard, and paste it after.
