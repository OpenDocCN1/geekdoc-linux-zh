# Part II: Ubuntu Desktop Users

Copying files and directories from CDs, DVDs, external drives, or network storage locations that contain your backups is a simple command-line or drag-drop operation once your Ubuntu system has mounted the CD, DVD, or networked storage device. CDs and DVDs should automount when inserted into your Ubuntu system unless you disable automount, you will probably have to use the command line or a graphical utility such as Ubuntu's Connect to Server dialog to mount networked backups so that you can access via Samba or NFS.

Copying files and directories is one thing—being able to actually work with them is another. Although I am a LIFENIX fanatic and have been a Ubuntu devotee since the first time I reviewed it years ago, here are the harsh truths about using any Linux system to work with files that have been created by Windows or Mac OS applications. Depending on the type of file and the version of the application that you chose, it may:

+   - Not able to display, print, or edit your existing files in any way
- Not able to do as good as a job of displaying, printing, or editing your existing files
- Be able to do everything you could, but before using Linux or Web-based applications
- Need to install your Windows software on your Linux system and run it using emulation, virtualization, or a similar solution

The first two of these are horror stories that can happen. The applications developed by most software vendors traditionally use their own data file formats. If software vendor does not support Linux, whether or not Linux software exists that can read and write the data files produced by that vendor's applications depends on whether the data file format used by that application is well-known, or depends on whether Linux developers of similar applications care enough to support reading and writing files in that format.

As much as it pains to say it, if you are doing critical work in a Windows or Mac OS application, you should use the Ubuntu Live CD or a scratch Ubuntu system to test if or how you can work with your existing files on a Linux system. Most of the chapters in the first part of this book are organized by common types of tasks and the Linux applications that you can use to accomplish this—writing documents, working with spreadsheets, creating presentations, and so on.

The following are a few commonly encountered types of files beyond those discussed in earlier chapters and the Linux applications that you can use with them:

+   - AVI, MPG, SWF: My favorite Linux player for all of these is the mplayer, but applications such as Totem on Ubuntu are popular and improving with each release.
- MP3 files: You can use the EasyTAG to edit the ID tags for MP3 files. The mpg123 and mpg321 applications are command-line utilities for playing MP3 files, which you can also play in graphical applications such as Rhythmbox and Helix Player under GNOME, and many more. You can encode various formats to MP3 using the graphical Sound Converter or command-line applications on Ubuntu.
