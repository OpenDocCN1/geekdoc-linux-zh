# Configuring the svnserver Server

As mentioned earlier, Subversion's svnserver enables Subversion clients to use URLs that use the svn protocol directly rather than the HTTP protocol. The svnserver is installed as a part of the basic Subversion package.

You can start the svnserver serve manually or through an Internet services daemon such as inetd or xinetd. The svnserver doesn't require any special configuration because you identify the root of your Subversion repository on the command line or in the configuration files for any Internet services daemon that you want to use. To start the svnserver daemon from the command line to provide access to the repository you created earlier in this chapter, you would simply execute the following command:

```
$ sudo -u www-data /usr/bin/svnserver -r /var -d
```

This starts the svnserver serve as the user over /var, and uses the -d option to identify the root of the Subversion repository and start the svnserver process as a daemon in the background.

As mentioned previously, you can configure an Internet services daemon to handle incoming requests for svn: URLs on demand, rather than starting the svnserver manually each time you log in or explicitly add it to your Ubuntu system's startup files. Internet daemons wait for incoming requests for services on certain ports and start associated daemons on demand, rather than having the daemons always running. Ubuntu provides two Internet services, inetd and xinetd. The inetd daemon is the original Internet, while the xinetd daemon is a more modern and flexible Internet services. Neither of these is installed by default on a basic Ubuntu, so you will have to manually install whichever you choose (I suggest xinetd) using the Synaptic Package Manager or apt-get.

If you install the xinetd Internet daemon, you will also have to create the file /etc/xinetd.d/svn, which is the configuration file that tells the xinetd daemon what to do when an incoming svn request is received on port 3690, as defined in /etc/services. An /etc/xinetd.d/svn file that provides access to the repository you created earlier in this chapter would look like the following:

```
service svn {
 disable = no
socket_type = stream
protocol = tcp
wait = no
user = www-data
server = /usr/bin/svnserver
server_args = -1 -r /var
}
```

After creating this file, you must restart the xinetd daemon using a command like the following:

```
$ sudo /etc/init.d/xinetd restart
```
