# About the Author

William von Hagen (Bill) has been a UNIX system administrator for more than 20 years, and a Linux fanatic since the early 1990s. He has worked as a Linux product manager, systems programmer, system administrator, writer, application developer, drummer, and content manager. Bill has written numerous books on such topics as Linux server hacks, GCC, Xen virtualization, Linux filesystems, SUSE Linux, Red Hat Linux, SGML, Mac OS X, and hacking the TiVo. He has also written numerous articles on Linux, embedded computing, Mac OS X, UNIX, and various open source topics. An avid computer collector specializing in workstations, he owns more than 200 computer systems but is not compulsive at all. You can reach him at wv@vonhagen.org.
