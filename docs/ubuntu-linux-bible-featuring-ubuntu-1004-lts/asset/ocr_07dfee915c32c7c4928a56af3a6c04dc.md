# Part II: Ubuntu for Desktop Users

From the output of this command, you can see that the "." and ".." are both directories (actually, they are hard links to the current and parent directories), and the mysterious .run_me_now file is actually an executable command. The name of the .my_music_directory file is followed by an @" symbol. What's up with that?

I used the term links in passing previously, and this is a good time to explain the usage. Links are essentially just pointers to other files and directories in the Linux system (which unlike shortcuts on Microsoft Windows systems or aliases on Mac OS X). Linux supports two types of links: hard links, which are actual connections to files or directories, and symbolic links, which contain the name of some other file or directory that you want to refer to. Because hard links are actual connections to a data structure, the thing that you're linking must actually exist and be within the same disk partition as the file you're linking to. Because symbolic links, unlike hard links, just contain the name of something, they can point to any file or directory on your machine. As you may now suspect, an @symbol following the name of a file or directory indicates that this file or directory is a symbolic link to another file or directory somewhere on your system. Let's combine the ls -a and -1 options to get some detailed information about everything in the current directory:

This actually shows you a fair amount of information about every directory, especially in terms of links. Remember that the second column in a directory listing identifies the number of hard links to each object. For the second column, the "." entry shows that there are three hard links to the current directory—the ". itself, in the parent directory, and the hard link to "." in the test subdirectory because the current directory is the parent of the test directory. The "..", which is a hard link to the parent directory of the current directory, seems to be very popular because there are 13 links to it. This means that the parent directory of the current directory probably contains several other directories. Looking at the .my_music file, you can see that it is a symbolic link whose name in the long listing shows another object that it is a symbolic link to.
