$ ssh laptop

To continue connecting to this system, type yes and press Return. The ssh utility adds the RSA key for the remote system to its list of known hosts (to prevent another machine from impersonating the remote machine in the future) and prompts you for your password, or in the following example:

```
Warning: Permanently added 'laptop' (RSA) to the list of known hosts.
wwh@laptop's password:
```

### Note

If you're curious, RSA stands for Rivest, Shamir, and Adleman, the developers of public key encryption technology that is used by the OpenSSH implementation of the ssh. For more information about public key infrastructure (PKI) and related encryption technologies, see a web site as Wikipedia's PKI information at http://en.wikipedia.org/wiki/Public_key_infrastructure.

Once you've established an ssh connection to a remote machine, you can do anything from a physical connection to that machine, including starting graphical applications that display on your local system if you use the DISPLAY environment variable correctly, as discussed in the Chapter 5, "Using the GNOME Desktop," entitled, "What's a Desktop? Graphical Environments for Linux". When you're working on the remote system, you can log out by pressing Ctrl+D or by typing the exit command.

All of this is well assuming that you have the same login name on all of the systems that you want to connect to, or that you always want to connect as yourself. Luckily, the ssh command provides an easy way to connect to another system as another user by using a command such as ssh@host, where user is the name of the user you want to log in, and host is the name of the host to which you want to connect as that user. For example, the command ssh joeuser@laptop will use ssh to connect to the remote host as the user joeser.

## Enabling Incoming SSH Connections to Your System

As mentioned previously in this chapter, an ssh daemon must be running on your system if you want to be able to connect to it remotely using any command that requires the SSH protocol. The standard version of the SSH server that is available for Ubuntu systems is the OpenSSH server (www.openssh.org), an open source SSH server that is actively maintained by the people who also support the OpenBSD project (www.openbsd.org), an open source UNIX-like distributions is well known for its focus on system security. The OpenSSH server is not installed by default as a standard Ubuntu installation (but everything in Ubuntu) is easy enough to add using any of the package management tools described in Chapter 19.

To install the OpenSSH server, use your favorite installation package to install the openssh-server package. I prefer using the graphical Synaptic Package Manager on Ubuntu systems, but free to use the command-line package managers if you prefer.

As part of installing the OpenSSH server, Ubuntu adds script to the system startup process that can automatically start when you boot your system. Older versions of Ubuntu provided a graphical System Administration Services made it easy to see the services that were installed on your system and the system run levels at which they are. To see this in a Ubuntu 10.04 system, you must install such a package such as the Boot-Up Manager application (by installing the bum package) or my favourite, sysv-rc-conf (from a package with the same name) which provides a simple interface for activating or deactivating services at system startup and various run levels. Figure 25-1 shows sysv-rc-conf in a GNOME Terminal window, after activating SSH to run levels 2 and above.

Should you want to enable remote logins to your system via SSH, you can simply run sysv-rc-conf again, scroll down to the SSH entry in Figure 25-1, and select the checkboxes for run levels such as 2, the main run levels.

### VNC (Virtual Network Computing)

VNC is a graphical desktop sharing system that allows you to remotely control another computer over a network. It is based on the Remote Framebuffer (RFB) protocol. There are many different VNC implementations, including TightVNC, RealVNC, and UltraVNC.

VNC can be used for many purposes:
- Accessing your computer from a distance.
- Sharing your screen with others.
- Providing technical support.
- Accessing your desktop from a mobile device.
