# Note

The flip side of flexibility is the ease with which the wrong thing can happen. For example, DHCP servers that are misconfigured or started by accident may provide DHCP clients with completely incorrect information. In my experience, the most common cause of DHCP problems is “randoms” invalidating DHCP servers on networks that already have an official DHCP server. In enterprise environments, few things can make a system crankier than someone starting a misconfigured DHCP server on their network(s). This is easy enough to do, especially on multi-homed systems (systems with multiple Ethernet interfaces) where you might have forgotten to identify the Interface that you wanted your DHCP server to listen on.

Now we're all one with the concept of DHCP servers and the types of information that they provide, let's install and configure one.

# Installing a DHCP Server

Most server processes are not installed as part of a default Ubuntu installation because noteverybody needs (or wants) to run servers. However, with all software packages on Ubuntu systems, the Package Management software discussed in Chapter 19, “Adding, Removing, and Updating Software,” makes it easy to install a DHCP server. The DHCP server that I suggest installing is the Institutional Service Component's (ISC) v3 server, which is found in the package dhcp3-server. This is the latest and greatest DHCP server available and is certainly the one that provides most functionality.

If your system has a GUI, I also suggest that you install the admin-dhcp package, which provides an easy-to-use graphical interface that simplifies configuring and customizing a DHCP server. Installing a graphical DHCP server configuration tool is, of course, optional, but these tools can be quite convenient if you are new to DHCP configuration: prevent many syntax errors because they create the DHCP configuration file based on fields that you fill in. They can also be useful if you are not a fan of using a text editor for editing. Another solution is to install a Web-based system configuration tool such as webmin if you are also running a Web server on the system on your DHCP server is running. see Chapter 29, “Setting Up a Web Server.”

If your system obtains an address through DHCP, packages as dhcp3-client and dhcp3-common will be installed on your system. The former contains the DHCP client that enables a system to get a DHCP address and related files, and the latter documentation, sample files, and utilities that are shared by all of the ISC packages. Be very careful when installing a new DHCP server in this scenario this means that another DHCP must already be running somewhere on your network. Your system will get its IP address in the earlier startup process than when your DHCP server is started, but this is still a potentially dangerous thing to do.

# Tip

If you are running a DNS server, you may also want to install the autodns-dhcp package, which can automatically update a DNS server with about systems whose IP information was newly assigned via DHCP.
