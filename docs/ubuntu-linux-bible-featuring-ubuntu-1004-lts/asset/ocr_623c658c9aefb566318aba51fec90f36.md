Next, to import the tarball you prepared earlier, right-click on the name of the project and select Import. This displays the dialog shown in Figure 23-14.

Because you're importing from a tarball, expand the General section, select the Archive File entry, and click Next. The dialog shown in Figure 23-15 displays, in which you've browsed for and selected the tarball that you prepared earlier.

You'll note that this dialog shows an expanded view of the tarball, which enables you to verify that it contains everything you need and that Eclipse can open it successfully. Click Finish to begin the import process. Once the import completes, the contents of the imported tarball are added to the selected project, as shown in Figure 23-16.
