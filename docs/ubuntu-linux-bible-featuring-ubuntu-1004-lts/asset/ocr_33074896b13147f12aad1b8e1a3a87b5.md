You may note that there is no equivalent to line 34 of the original server configuration file in the new entry that we created. This is because there was no need to provide these directory browsing options which I found that I know that the directory contains HTML files, so that the following options were not necessary:

+   - **Indexes**: Shows index of the directory if no index.html file is present.
- **MultiViews**: Enables content negotiation, where the browser tries to find the best match for a request. In my case, I only want to see the docs in my default language, locale, and character set, so no negotiation is necessary.
- **FollowSymlinks**: Enables the web server to follow symbolic links. Because I know that there are no symbolic links in this directory, there's no need to specify that they should be followed.

The Apache documentation is quite good and explains all of the site configuration directives that I don't have space to describe here.
