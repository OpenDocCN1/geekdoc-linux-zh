# Personalizing Writer

The first thing that you'll want to do when getting started with Writer is to enter some information about yourself into your User data fields. This is primarily useful because Writer will use this information in various places when filling out fields in documents that you create using the OpenOffice.org Wizards (as explained in the next section).

Select the Tools Options menu item to display the Options dialog's "User Data" form, as shown in Figure 13-7. Fill out the fields in this form and Click OK to return to Writer and your document.
