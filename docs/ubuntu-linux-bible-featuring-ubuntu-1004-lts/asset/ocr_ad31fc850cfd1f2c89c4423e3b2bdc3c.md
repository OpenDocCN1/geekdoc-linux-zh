The Folder field of this dialog identifies where the bookmark will be saved. You can click on entry to see a list of the folders that already exist in your bookmarks, or you can click the down arrow to the right of this dialog to display a browseable dialog that enables you to select a folder within those folders, as shown in Figure 8-13, or you can click on the New Folder button to create a new folder in which to store your new bookmark.

The dialog shown in Figure 8-12 also provides a field that enables you to add tags to your bookmarks. Tags are a type of metadata, which means "information about information." In this case, tags enable you to associate keywords with specific bookmarks so that later you can search for related items. To add tags to a bookmarked entry, enter them as comma-separated keywords in the Tags field on the bookmarks dialog, as shown in Figure 8-14.
