By default, the fdisk command lists all partitions on all disks that it detects in your system. You can also use the fdisk command to list the partitions on a specific device, as shown in the following example:

```
$ fdisk -l /dev/sda
```

Note that the first argument of command is the name of the disk that you want to query, not that of a specific partition. You can get similar information, although in a slightly less usable form, by examining the file /proc/partitions, which a running system uses to track all disks and partitions that are currently in use on your system. The contents of this file are formatted in the same as from which the previous example was taken:

```
$ cat /proc/partitions

8 1 10494013 sda1
```
