# Summary

This chapter covered a lot of ground, explaining some basic concepts required to successfully install Ubuntu Linux as a server operating system on an existing machine or as the only operating system on a system using various specialized installation configurations via the quasi-graphical Debian installer. Regardless of the type of system that you installed or are using, by the end of this chapter, you have Ubuntu Linux installed and running on your computer system.

Chapter 4 discusses basic Linux concepts that may be new to you if this is the first Linux or UNIX-like system that you have used. Chapters 5 and 6 discuss the basics of Ubuntu with its standard graphical interface (GNOME) and window manager (Compiz), respectively.
