Calc provides extensive online help, available by selecting OpenOffice.org Help from the Help menu, or by pressing the F1 key on your keyboard at any time.

Tip
If you are having problems viewing the text for Calc’s online help and OpenOffice.org Writer is not installed on your system for some reason, try installing Writer. This will force an update to the components that control online help in the OpenOffice.org suite and usually resolves the problem. ■
