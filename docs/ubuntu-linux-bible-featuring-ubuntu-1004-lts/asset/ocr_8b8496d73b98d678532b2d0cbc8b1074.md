# Changing File and Directory Permissions

Chapter 4 introduced the idea of Linux users and groups and also provided an initial explanation of how file and directory permissions are represented when listing the contents of files and directories. You saw the same thing earlier in this chapter when exploring the ls command -l option. Being able to protect files so that only certain users or groups can execute them is handy, but it begs the question, "How do I do that?" You can easily change file and directory permissions from graphical file managers such as GNOME's Nautilus by right-clicking, selecting Properties, and selecting the Permissions tab, as shown in Nautilus in Figure 11-8. Fortunately, changing file and directory permissions from the command line is similarly easy, and may even be easier.

The chmod (change mode) command enables you to change any of the permissions associated with files and directories that you own. The chmod command supports two ways of setting permissions:

+   - Using octal values that actually represent the bits in the permission field of a file or directory
- Using friendly letters to represent permissions for the user who owns a file or directory (u), the group with that file or directory is associated (g), other users on the system (o), or all users on the system (a), and using the plus and minus signs to add or subtract permissions. This is known as changing permissions in symbolic mode.
