# Introduction to Spreadsheets

This section provides background information on what a spreadsheet is, how it works, and how to use one. If you're already familiar with spreadsheets, you can skip this section. However, if you're not, this section is for you.

In paper terms, a spreadsheet is a sheet of paper divided into rows and columns that break down financial transactions into separate entities that a business person can examine and analyze. The first computerized spreadsheet was created for a mainframe computer in the early 1960s by a professor named Richard Mattess, then at the University of California at Berkeley. As a mainframe application, this had a somewhat limited audience—for you and me, spreadsheets were one of the original killer applications for personal computers, going all way back to VisiCalc on misty dawn-of-time systems like the Apple II. Then, like now, the power of the personal computer gave people the ability to enter and manipulate financial data on their own systems. Spreadsheets are not only good for calculations of expenses and other financial transactions, but also provide an excellent mechanism for "what if" calculations. What if we bought a car now—could we afford the payments based on our monthly income? What if I paid something extra on my mortgage—how long before it would be paid off?

In a spreadsheet, each rectangle in the spreadsheet is referred to as a cell. Each row in a spreadsheet typically provides a variety of information about a specific transaction or other entity, while the columns are used to visually compare, mathematically summarize, or perform other mathematical operation on the value for each row that appears in that column. The following is an example:

| Meal | Cost | Tax | Tip |
|---|---|---||}{
| Breakfast | 5.79 | 0.41 | 1.25 |
| Lunch | 8.48 | 0.60 | 1.75 |
| Dinner | 13.23 | 0.93 | 2.75 |

This simple table reflects my meals for a (fictitious) day. The first row is a set of headings that identify the meaning of the entries in each column. Each row provides the details of each of the meals for that day in ways—either by adding to the end a summary column that contains the total cost of each meal and then adding all of the values in that column together, or by inserting a new row that contains the totals of all type of item for the day, and then adding all of the value in that row together. I prefer the first approach, a summary column, so's go with that approach for the remainder of this section. There's nothing preventing you from calculating your daily totals the other way if you prefer (or do both ways, for that matter)—the ability of spreadsheet applications to automatically perform these calculations is one of their coolest features.

Manually performing these calculations is fine if you don't have a computer or if you're far better than I am, but I prefer to use the appropriate tool whenever one is available—and spreadsheets come to the rescue in this case.
