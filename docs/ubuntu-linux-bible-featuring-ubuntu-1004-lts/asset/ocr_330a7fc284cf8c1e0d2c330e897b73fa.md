# # Chapter 11: Using Command-Line Tools

Each xterm configuration menu provides access to different xterm configuration commands:

+   * **Ctrl+left-click:** The Main Options menu, which primarily enables you to send various signals and special key sequences to the selected xterm
* **Ctrl+middle-click:** The VT Options enables you to set various characteristics of the terminal emulation provided by the selected xterm. The name VT Options comes from the name of the default type of terminal that is emulated by an xterm, which is a DEC-VT-100. 11-6 shows the VT Options menu. If you only have a two-button mouse, but it has a roller wheel, the roller wheel typically acts as a middle button if. you have a two-button mouse without a roller, pressing both buttons simultaneously enables a middle-mouse click.
* **Ctrl+right-click:** The VT Fonts menu enables you to control the size of the fonts used in the selected xterm. 11-7 shows the VT Fonts menu.
