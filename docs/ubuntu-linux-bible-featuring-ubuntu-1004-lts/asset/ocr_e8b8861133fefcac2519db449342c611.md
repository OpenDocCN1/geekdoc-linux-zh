+   * Library Structure: Enables you to specify the audio files that you extract from CDs will be organized in your music library. This section provides the following settings:
* Folder Hierarchy: Enables you to specify the folder hierarchy in which Sound Juicer creates the audio files that it extracts. By default, the tracks of each CD are written in a folder with the name of the CD, which is itself a subdirectory of a folder with the artist's name.
* File Name: Enables to specify the format for the filename for each audio track. The default value, "Number - Title," is a good setting to use, because this makes it easy for you to create playlists that follow the original track order of your CDs.
* Preferred Format: Enables you to specify the format in which extracted audio files are written. Your choices are "CD Quality, Lossless" (using the FLAC codec), "CD Quality, Lossless" (using the Ogg container and Vorbis codec), "Voice, Lossless" (using the standard WAV file format), and "Voice, Lossy" (using the Ogg container and Vorbis codec, but at a lower quality).

I typically change the location of my music folder and, unfortunately, the Preferred format for any tracks that I extract from my audio CDs. You will note that the default formats in which you can extract CD audio do not include MP3. This option will be present if you installed the gstreamer0.10-plugins-multiverse package, the gstreamer0.10-fluendo-mp3 package, (or purchased and installed the commercial Fluendo codecs) as in Configuring the Gstreamer Framework and Plug-Ins section of this chapter. If you see an entry for MP3 audio on this menu, thanks for following along. If not, install any of the gstreamer0.10-plugins-multiverse package, or the commercial Fluendo codecs and restart Rhythmbox to see an entry for extracting audio files in MP3 format, which you will probably want to make your default if you want users of other operating systems to be able to play your extracted audio files. The OGG format is far superior to MP3 (and is free of licensing issues), but unfortunately, most people and portable music players can only deal with the MP3 format.

Once you've customized the location of your music files or the format in which they will be extracted, click Close to the Preferences dialog. You can then click the Copy tracks to the library icon in Rhythmbox toolbar to ripping a CD. While Rhythmbox is extracting the contents of an audio CD and converting each track to a file, it displays progress information in the Status bar at the bottom of the Rhythmbox dialog.
