# What Is Compositing? Why All the Fuss

Most current graphics cards provide at least 128 MB of onboard video RAM, while most of the video controllers integrated into today's motherboards enable you to allocate at least a similar amount of system memory to the graphics controller. Having a significant amount of memory available the video cards themselves to do substantial onboard graphics processing. Not only today's video cards provide high-performance, built-in graphics processors, but offloading graphics calculations from the CPU and window manager to the video card improves overall performance and responsiveness.

As discussed in Chapter 5, "Using the GNOME Desktop," Linux systems use the Window System (also known as XI or simply X) as the graphical framework that underlies most Linux desktop environments and window managers. A window manager handles creating, moving and managing windows on high-resolution monitors that are managed by an X Server, and they can be either stand-alone or components of a desktop environment that provides higher-level capabilities such as drag-and-drop. The X Window System uses high resolution monitors as a bitmap display, which means every bit (pixel) on the screen is actually mapped to a memory location. This enables fast graphics operations to be done by manipulating memory, and the result of that is immediately displayed on your monitor.

The term compositing refers to the combination of graphical or visual elements from separate sources into single images. In Linux systems, a compositing manager is an X Window System client that redraws windows and other parts of the bitmap display to video memory, tracks changes to that off-screen memory, and handles merging the updated images into the system's bitmap display when changes occur and the screen has to be redrawn. An X Window System compositing window manager is therefore a unified window manager and compositing system that performs conventional window management functions while integrating and displaying high-quality, high-performance graphics being created and managed in your system's video memory, including special effects such as transparency and transparency. Traditional window managers (as discussed in the "Using a Window Manager" at the end of Chapter 5) are referred to as tiling or stacking managers—tiling window managers display side-by-side with no overlap, while stacking window managers display windows on top of overlapping one another, with no transparency. # Tip

Although the terms transparency and translucency are often used interchangeably, they actually have different meanings for truly hardcore graphics fans. A transparent physical material shows objects that are behind it and does not reflect light off its surface. A translucent physical material reflects some of the light that hits it. See the OpenGL FAQ (www.opengl.org/resources/faq/technical/transparency.html) for a more verbose explanation.
