# Chapter 13: Creating and Publishing Documents

+   * Styles and Formatting window: Although it is not displayed by default, you can display this window at any time by selecting the Format -> Styles and Formatting menu. The Styles and Formatting window provide easy access to various sets of styles that are available for the current document and is especially convenient if you choose not to display the formatting toolbar. The dropdown menu enables you to display specific sets of styles in this window, such as Character Styles, List Styles, and so on. You can dock this window by holding down the Ctrl key and double-clicking on the gray portion of the window heading (beside the icons), making it part of the default Writer interface rather than a floating window. Figure 13-5 shows Writer with the Styles docked. You can undock a docked window by repeating this process.
