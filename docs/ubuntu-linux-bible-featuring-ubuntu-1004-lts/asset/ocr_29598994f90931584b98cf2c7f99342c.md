The -R option tells gconftool-2 to recursively retrieve hierarchical settings below the speci-
fied repository key. Information about whether a plug-in is stored in the /apps/
compiz/general/allscreens/options/active_plugins repository entry, as shown in this
example:

```

[svg,imgjpeg,text,file,png,neg,workarounds,dbus,video,rehex,

wall,animation,expo.zoom,fade,scale,scaldefilter]
```
