# About the Author

William von Hagen (Bill) has been a UNIX system administrator for than 20 years, and a Linux fanatic since the early 1990s. He has worked as a Linux product manager, system administrator, writer, application developer, drummer, and content manager. Bill has written numerous books on such topics as Linux hacks, GCC, virtualization, filesystems, Red Hat Linux, SGML, Mac OS X, and hacking. He has also written numerous articles on embedded computing, Mac OS X, and various open source topics. An avid collector specializing in workstations, he owns more than 200 systems but is compulsive at all. You can reach him at vonhagen.org.
