# # Chapter 1: The Ubuntu Linux Project

following lists the complete Ubuntu-based distributions for desktop users that I am most familiar with, what differentiates them from other flavors of Ubuntu, and where to get them:

+   - **Edubuntu**: An official edition of Ubuntu that focuses on educational applications and popularizing the use of Linux in schools. Ubuntu uses GNOME as its default desktop environment and provides several different desktop-themes that are designed to be attractive (useful) for users of different age groups. Ubuntu provides an incredibly rich set of educational applications, such as the KDE Edutainment suite (paint, math, and typing applications), GCompris for kindergarten, Ubuntu4Kids and the OpenOffice suite of desktop applications. You can find out more about Edubuntu or download a copy from the Ubuntu web site at www.ubuntu.org. A Live CD version of Edubuntu is available if you want to experiment with it before permanently installing an Ubuntu distribution.

+   - Fluxubuntu: An extremely lightweight Linux distribution that is based on Ubuntu and targets machines with limited amounts of memory, relatively small disks, and so on. It refers to itself as a LPAE (Lightweight, Productive, Efficient) Linux distribution, which is both accurate and a fine addition to your collection of computer-related abbreviations. Fluxubuntu's official memory requirements are less than 64 MB, making it ideal for older or inexpensive machines that you don't want to invest in additional hardware. Fluxubuntu is not limited to or low-power hardware—for example, a 64-bit version of Fluxubuntu is available. Fluxubuntu uses the window manager as its primary word processing application, Gnumeric as its spreadsheet application, and lightweight web applications such as Kakehaaze (Web browser, http://kakehaaze.sourceforge.jp), Claws (e-mail client, www.claws-mail.org), and Pidgin (instant messaging, discussed later in this book). Any Ubuntu-based distribution, many other packages are available. You can find out more about Fluxubuntu or download a copy from the Fluxubuntu web site at.

+   - **Geubuntu**: Another lightweight Linux distribution that is based on Ubuntu. Unlike Fluxubuntu, Geubuntu uses E17, which is the window manager formerly known as *Enlightenment* (www.enlightenment.org), which now includes various desktop features and the Xcompr compositing manager. Enlightenment has always been known as one of the most attractive and configurable window managers, and this Ubuntu-based distribution is an excellent choice for lower-power machines or on systems for which you prefer to devote as much of your CPU and memory as possible to the processes you're running versus the desktop environment. The founder of Geubuntu is an Italian designer, the aesthetics of Geubuntu are attractive and compelling. Geubuntu is available both as a live/install CD and via a script that enables you to install its packages to an existing Ubuntu installation. For more information about Geubuntu or to download a copy, see the Geubuntu web site at http://geubuntu.linux.com/Home.
