# Chapter 2: Installing Ubuntu

## Reformatting a USB Flash Drive.

The Ubuntu "Create a USB startup disk" application will try to reuse any existing FAT32 (VFAT) partition on your USB stick. If you've reformated the USB stick to contain multiple partitions, changed the filesystem type of any of your partitions, or already have multiple partitions on the stick but don't need to use them, this sidebar explains how to reformat your flash drive so that it contains a single FAT32 partition that the "Create a USB startup disk" option can make the most of. As you might expect, this will delete any information that is currently present on the USB stick, so make sure you've copied anything you ever want to see elsewhere following the instructions in this sidebar.

To reformat a USB stick, do the following:

+ 1. Select the Applications <-- Terminal command to start a GNOME terminal.
2. Enter the `sudo` command and your password to become the root user.
3. Use the `df` command to see the mounted partitions on your system. If any of partitions from your USB stick are mounted, unmount each of them using the `umount` command.
4. Execute the `fdisk` command with the device corresponding to your USB stick as an argument. You must specify the name of the device, not a partition on that device. For example, if your USB stick was `/dev/sdb`, you would execute the command `fdisk /dev/sdb`.
5. Press `p` and Enter/Return to see a list of all the partitions on the USB stick. Use the `d` command to delete each of them, where `number` is the number of the partition in device names in the first column of the output displayed by `p`. When you're done, press `p` to list the partition table—you should not see any partitions listed.
6. Use the `n` command to begin creating a new partition on the flash drive. Enter `p` to create this as a primary partition, and enter `1` as the partition number. Press Return when prompted for the starting block of the new partition to accept the default value of 1. When prompted for end of the partition, press Enter/Return again to use the entire disk.
7. Type 7 and press Enter/Return to begin changing the type of the first partition on the drive. Enter 1 to identify the partition you want to change, and enter `c` (Windows 95 FAT32 LBA) as the type of the partition.
8. Type `a` and press Enter/Return to set your new partition as active (i.e., bootable). When prompted for the partition number, enter 1 and press Enter/Return.
9. Type `w` to write your updated partition table to the USB stick. Type `q` to exit the `fdisk` application.

After re-partitioning your USB stick, you must remove and reattach it to your system to read the new partition table. After re-attaching the drive, use the `dmesg` command to display the few kernel messages, one of which identify the device name and available partitions on the USB stick that you just reattached. You can use the `fdisk /dev/DEVICE` command to list the partitions on the device named `DEVICE` to verify that you know the device name of the re-attached drive—it is not necessarily the same device name that it had before. Once you are absolutely sure that you know the device name of the re-attached USB stick, you can format it using a command like the following:

`mkfs.vfat -F 32 -n NAME /dev/PARTITION`

Replace NAME with the name that you want to assign to your USB stick, replace PARTITION with the name of the partition on the device, which would be like sdb1, sdc1, and so on. You're now ready to create a bootable Ubuntu system on your USB stick.

+ 5. Click “Make Startup Disk” to begin creating the bootable USB stick. This takes a few minutes. A dialog displays when the bootable system has been successfully created in the selected USB device partition. Click OK to close this dialog and the startup disk creation process.

At this point, you can remove the USB stick from your system and test it on another system, or you can reboot your current system to rebooting from the USB stick. Make sure that you have activated booting from USB devices in any system that you use to test the USB stick, and that the USB device has a higher priority than your system’s CD, DVD, or hard drives.

## Wubi Installing Ubuntu on Windows

Versions of the Ubuntu Desktop CD for version 8.04 provided a variety of open source software packages that were compiled for Microsoft Windows systems, enabling Ubuntu users to try some of the amazing software they could see and use after booting from the Desktop CDs in Live CD mode. These packages included Mozilla Firefox, Mozilla Thunderbird, the GIMP image creation and editing package, and several others.

Versions 8.04 and later of the Ubuntu CDs stopped offering the Windows versions of these packages, providing an even better option for Windows users: the option to install Ubuntu onto any existing system without re-partitioning your system, adding a boot option to your system that enables you to boot either Ubuntu or your existing Windows system. This capability is provided by an impressive package called Wubi (Wubi-based Ubuntu Installer—wubi-installer.org). Installing Ubuntu onto an existing Windows system requires a minimum of 4 GB of disk space (5 GB better is recommended), but gives you a complete Ubuntu system that is installed into a new directory on your Windows system. On the Windows side, a Wubi-based installation looks like any other Windows application and can even be removed using the traditional “Add/Remove Applications” Control Panel.

A Wubi installation works by creating an Ubuntu directory at the top level of your system’s hard drive and populating it with the files that Wubi requires to boot Ubuntu, including a filesystem image for distribution. The installation process adds an Ubuntu option to your Windows boot menu (which you may never have even seen before your system only ran Windows), and then installs the boot loader—the wubldr (boot loader) that it uses to mount and access the filesystem image as the application that is executed when the Ubuntu boot option is selected.

To take advantage of this installation option, insert an Ubuntu Desktop CD into the CD/DVD drive of an existing Windows system. After any dialog that your Windows system confirms that you want to run the Wubi.exe software from the CD, the dialog shown in Figure 2-18 displays.
