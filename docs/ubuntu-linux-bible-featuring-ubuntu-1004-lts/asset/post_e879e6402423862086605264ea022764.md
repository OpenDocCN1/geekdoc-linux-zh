# Tip

When creating match rules, the most important control to set is whether a message must match only one (or more) of the specified criteria, or whether the associated operations will be performed only if the message matches all of the specified criteria. This can be the difference between a successful rule and one that doesn't work as you intended. This is controlled by the "Find Items" control, shown in the upper-right corner of any message filter dialog, which you can set to either "If any criteria are met" or "If all criteria are met."

# Automatically Checking for Junk Mail

Evolution's ability to filter e-mail messages based on criteria that you define could require a potentially huge number of rules to catch all of the spam and junk mail you may receive. Luckily, Evolution supports the integration of external applications that can analyze messages and identify them as junk if that's the case. Popular examples of this sort of junk e-mail filter application are SpamAssassin (http://spamassin.apache.org/) and Bogofilter (http://bogofilter.sourceforge.net/).

Evolution includes plugins for both SpamAssassin and Bogofilter, which will automatically execute the specified program and apply it to incoming mail. Bogofilter is installed by default on Ubuntu systems, so unless Evolution is not working well enough for you. In my experience, SpamAssassin is more powerful and accurate than Bogofilter, but it is also slower because it does more SPAM checks than Bogofilter.

# Tip

If you want to install SpamAssassin, you must use your favorite software installation tool to install SpamAssassin, as described in Chapter 19, "Adding, Removing, and Updating Software." You should check Evolution's plugin-in list to make sure that SpamAssassin is active. To do this, select Plugins from the Edit menu to display the "Plugin Manager" dialog. Once this dialog displays, scroll down to the SpamAssassin plugin-in and make sure it is enabled. Click OK after verifying and enabling this plug-in, necessary.

If you have problems installing or using SpamAssassin, make sure that Evolution's Bogofilter plug-in is not enabled on the Edit menu. This conflicts with SpamAssassin and can cause problems.

Regardless of which SPAM filtering package you use, clicking the Junk button in the Evolution toolbar will identify the currently selected message as junk and move it to your Junk folder. # Accessing Free and Web-Based E-Mail

The broadband or dial-up connection you use to connect to the Internet from your home is generally supported by an academic or commercial Internet service provider (ISP) that provides you with an e-mail address. Such e-mail addresses are inherently transient—once you finish with a class, graduate, and cannot keep your address, or change commercial ISPs, your e-mail account is usually deleted. This may cause some of your more-strung family and members, used to regularly exchanging mail with bigaddy@some-random-isp.com to panic and begin.

As an alternative, companies such as AOL, Google, Microsoft, and Yahoo!, as well as hundreds of specialized web sites, provide free e-mail accounts that you can use regardless of your ISP and that you can access via any browser. Of course, these accounts are basically free advertising for these companies, driving traffic to their web sites (gmail.com, hotmail.com, or yahoo.com, respectively), displaying advertisements in some cases, and so on.

With the exception of Gmail, you can read and send mail at these sites only by using a Web browser. This is a pain if you would like to use a single e-mail application, such as Evolution, to read and manage all of your e-mail. However, Gmail offers both POP and IMAP access, and you can at least read and archive your Web-based e-mail from any mailer that supports POP3 by installing and configuring software using FreePOP. The next sections explain each of these.
