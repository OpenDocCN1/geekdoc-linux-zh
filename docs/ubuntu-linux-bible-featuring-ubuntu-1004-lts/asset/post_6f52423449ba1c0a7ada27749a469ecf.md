# Tip

Note that the playlist files created by k3b are located in the directory where the directory that holds the extracted audio for a CD is located, not in the same directory with the extracted audio files. This can be confusing if you copy the files to any of your machines, so. Since the default filenames for each track of an extracted CD begin with the track numbers, I use a few aliases to enable me to quickly create playlist files for CDs. But the ones I use are (in my ~/.bashrc file):

```
alias ftoc="ls *.[Ff][Ll][Aa][Cc] * > playlist.m3u"
alias mtoc="ls *.[Mm][Pp][P] * > playlist.m3u"
alias otoc="ls *.[Oo][Gg][Gg] * > playlist.m3u"
alias stoc="ls *.[Ss][Hn][Nn] * > playlist.m3u"
```

# Backing Up DVDs from the Command Line

Ripping CDs is almost a necessity because most people want to be able to play their music files on portable mobile devices that don't have CD drives. Many fewer people want to extract the contents of DVDs, although anyone in his right mind would probably want to make backup copies of them. As a long-time UNIX/Linux geek dog lover, my primary desire in copying DVDs is to back them up so that I still have a copy after our dogs finish using the original and its case as a chew toy.

Although variety of different applications are available in the Ubuntu repositories and on the Internet, most of them have a GUI and a fair number of mouse clicks to copy the DVD. Therefore, my favorite candidate to back up most DVDs is the following:

```
$ dd if=/dev/dvd out=name_of_output_file.iso
```

You can clone a CD if you want by executing a simple command, replacing /dev/dvd with /dev/cdrom, or whatever the appropriate device name is your system.

This command is simple, works on every Linux and UNIX system in the known universe, and produces an output file that is an exact image of the original DVD. You can mount the output file just like an actual DVD if you are interested, using commands like the following:

- sudo mkdir /mnt/dvd
- sudo mount -o loop -t iso9660 name_of_output_file.iso /mnt/dvd

The first of these commands creates a directory upon which to mount the ISO image; the second actually mounts it and makes it available like any other mounted filesystem.

Once you create an ISO image of a DVD with the dd command, you can also immediately burn the image to a blank DVD-R, as explained later in this chapter.

# Burning CDs Using Basero

GNOME's Basero application makes it easy to create audio CDs from selected audio files on your system or create data CDs that contain files and directories from your system for backup or portability purposes. This section focuses on creating audio — the steps for creating data CDs are much the same, although you must specify that you are creating a data CD using the Project ☮ New Project ☮ New Data Project item.

# Creating Audio CDs with Basero

Basero is one of the options that Ubuntu provides in the dialog shown in Figure 16-5 when you insert a blank CD. If you do not see this dialog, you can start Basero by right-clicking on the "Blank CD-R Disk" icon and selecting "Open with Basero Disc Burning," or by selecting the Applications Sound & Video ☮ Basero Disc menu item.

Basero initially displays a main screen that enables you to specify the type of audio or video CD that you want to create. To create an audio CD, click "Audio project" (or select the Project ☮ New Project ☮ New Audio Project menu command). This displays the dialog shown in Figure 16-16.

To add files to your new audio CD, click the Add icon (plus sign) to browse a directory that enables you to navigate to the location where your audio files are stored. You can easily add them to the CD by selecting one or more files and clicking Add. As with other graphical applications, you can select multiple tracks at time using Ctrl+leftclick or Ctrl+Shift to select a range of songs.

As you add tracks to your Basero, it checks each track to ensure that it knows how to convert a track in a format that the raw audio format is used on CDs. If it does not recognize the format of a track or lacks a codec to handle that audio format, Basero displays an error log that says Gstreamer not know how to handle the specified file format, and displays another dialog that offers to look for a suitable codec for you, as shown in Figure 16-17. It doesn't get much more user-friendly than that!
