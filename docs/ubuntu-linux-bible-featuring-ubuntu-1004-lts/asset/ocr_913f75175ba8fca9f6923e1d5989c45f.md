# Tip

When using BackupPC to automated backups, the system logs show which user requested a remote sync operation. To do this, you would add this user (I usually use backuppc) to the auth users in the remote host's /etc/rsynccd.conf file and create an appropriate username/password pair in the remote host's /etc/rsynccd.secrets file. You would then modify the host-specific backuppc configuration file to use this username and password. I didn't do this here for simplicity's sake, but doing would provide more accurate log data on the client system. ■

If the system uses an rsync binary other than the default /usr/bin/rsync or the rsync program is listening on a port other than the standard port (873), you should add configuration definitions for these to the host-specific configuration file. The default settings for the associated configuration parameters are:

```
$Conf(RsyncdClientPort) = 873;
$Conf(RsyncdClientPath) = '/usr/bin/rsync*';
```

Next, change the ownership and group of the /var/lib/backuppc/pc/64bit directory to backuppc and change the protection of the configuration file /var/lib/backuppc/pc/64bit/config.pl so that it is not publicly readable (because it contains password information) using the following commands:

```
sudo chmod -Rv backuppc:/var/lib/backuppc/pc/64bit
sudo chmod 600 /var/lib/backuppc/pc/64bit/config.pl
```
