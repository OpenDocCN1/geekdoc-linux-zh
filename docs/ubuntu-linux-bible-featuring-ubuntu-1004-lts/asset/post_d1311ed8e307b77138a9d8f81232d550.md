### Other Word Processors and Office Suites

This chapter focused on the most popular, open source command-line and graphical applications for word processing and page layout. There are certain others—this is open source, after all, where anything worth doing is worth several times because of different perspectives on the task at hand. The following are two other popular word processors for Linux:

- AbiWord: The AbiWord word processor is part of the GNOME Office Suite (http://live.gnome.org/GnomeOffice). AbiWord is a powerful and popular word processor for Linux, with excellent capabilities for importing and working with existing documents in formats such as Microsoft Word. AbiWord is available in the Ubuntu repositories and can be easily installed on your Ubuntu system using the appropriate Package Manager for your system.
- Applixware: Applixware is an office suite that includes a powerful word processor, but has had an on-again, off-again relationship with Linux. Originally marked as an end-user package that was a direct competitor to StarDivision's original StarOffice Suite, Applixware has morphed into more of a toolkit for developing real-time and analytical applications. For more information about Applixware, see www.vistource.com/vs2/en/index.php. For an article on installing Applixware on Ubuntu, visit the Applixware group at http://groups.google.com/group/Applixware and search for Ubuntu.

Both of these word processors are quite easy to use and have their own circle of devotees. If you find something that you don't like about OpenOffice.org Writer, installing and experimenting with either of these is well worth your time.

# Introduction to Spreadsheets

This section provides background information on what a spreadsheet is, how it works, and how to use one. If you're already familiar with spreadsheets, you can skip this section. However, if you're not, this section is for you.

In paper terms, a spreadsheet is a sheet of paper divided into rows and columns that break down financial transactions into separate entities. The first computerized spreadsheet was created for a mainframe in the early 1960s by a professor named Richard Mattess, then at the University of California at Berkeley. Then, like now, the power of the personal computer gave people the ability to enter and manipulate financial data VisiCalc on the Apple II. Spreadsheets are not only good for calculations of expenses and other financial transactions, but also provide an excellent mechanism for "what if" calculations. What if we bought a car—could we afford the payments? What if I paid extra on my mortgage—how long before it would be paid off

In a spreadsheet, each rectangle in the spreadsheet is referred to as a cell. Each row in a spreadsheet typically provides a variety of information about a specific transaction or other entity, while the columns are used to visually compare, mathematically summarize, or perform mathematical operation on the value for each row. The following is an example:

| Meal | Cost | Tax | Tip |
|---|---|---|---|
| Breakfast | 5.79 | 0.41 | 1.25 |
| Lunch | 8.48 | 0.60 | 1.75 |
| Dinner | 13.23 | 0.93 | 2.75 |

This simple table reflects my meals for a (fictitious) day. The first row is a set of headings that identify the meaning of the entries in each column. Each row provides the details of each of the meals for that day in ways—either by adding to the end a summary column that contains the total cost of each meal and then adding all of the values in that column, or by inserting a new row that contains the totals of all type of item for the day, and then adding all of the value in that row together. I prefer the first approach, a summary column, so's go with that approach for the remainder of this section. There's nothing preventing you from calculating your daily totals the other way if you prefer (or do both ways, for that matter)—the ability of spreadsheet applications to automatically perform these calculations is one of their coolest features.

Manually performing these calculations is fine if you don't have a computer or if you're far better than I am, but I prefer to use the appropriate tool whenever one is available—and spreadsheets come to the rescue in this case.
