# # Installing and Using QEMU

QEMU (http://bellard.org/qemu) is an amazingly powerful source CPU emulator by
Fabrice Bellard and a host of others. QEMU can emulate a huge variety of architectures, process-
sors, and related peripheral hardware. QEMU can run operating systems and software that are
compiled for platforms including 32- and 64-bit x86, 32- and 64-bit PowerPC, Motorola 68000,
32- and 64-bit SPARC, MIPS, and ARM. QEMU virtualizes a complete hardware environ-
ment for each of these processors/architectures, including the CPU and peripheral devices like
one one or more ports, network interfaces, a PCI bus, VGA graphics adapters, sound hardware,
disk drives, USB components, and more. This enables you to run unmodified guest operating
systems for any of these architectures/processors in QEMU. For example, Figure 24-24 shows an
term window in which QEMU has booted a kernel and is therefore also running operating
system binaries that have been compiled for the ARM platform.

If you are only planning to use QEMU to emulate a 32-bit or 64-bit x86 system, QEMU is
installed as part fo the qemu-kvm package that was discussed in the previous section. If you did
 install KVM, you must install the qemu-kvm package in order to install the QEMU applica-
t. If you want to use QEMU to emulate any other processor or architecture, you must also
install the qemu-kvm-extras package.
