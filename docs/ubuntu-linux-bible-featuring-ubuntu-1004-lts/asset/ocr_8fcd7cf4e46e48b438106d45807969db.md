+   - Getting to Grips with LaTeX (www.andy-roberts.net/misc/latex/index.html) is a great series of tutorials on using LaTeX from Andrew Roberts.

- The TeX HOWTO (www.tdlp.org/HOWTO/TeX-HOWTO.html) discusses the previous version of TeX/LaTeX that was used on Ubuntu systems. This HOWTO was written a few years ago, but one of the nice things about stable software TeX and LaTeX is that things do not change much. This document provides a good deal of general information about creating TeX and LaTeX documents, but you should ignore any specific information about creating the tex implementation.

Several books dedicated to TeX and LaTeX are available, and a quick search on Amazon.com will provide an assortment of options. However, no discussion of TeX and LaTeX would be complete without identifying the two seminal texts for each of these:

+   - Tebook by Donald E. Knuth (Addison-Wesley Professional, 1984, ISBN: 0201134489)
- LaTeX: A Document Preparation System, 2nd ed. by Leslie Lamport (Addison-Wesley Professional, 1994, ISBN: 0201529831)

As these books are by authors of their respective systems, you can consider them definitive. Some changes have recently been made to LaTeX since its creation by Lamport long ago, but these are still the bibles for both of these document preparation systems.
