# Burning CDs and DVDs Using k3b

k3b is the KDE tool of choice for burning CDs and DVDs on KDE-based systems such as Kubuntu, but is also a great package for use on GNOME-based Ubuntu systems. Once you've installed k3b, you can start it by selecting the Applications Sound & Video k3b menu command. k3b starts and initializes, it displays a splash screen and then eventually displays the main k3b window, shown in Figure 16-30.
