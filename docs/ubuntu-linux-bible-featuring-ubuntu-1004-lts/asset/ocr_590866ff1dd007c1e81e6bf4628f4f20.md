# # Summary

This chapter explained how to install and set up a Samba server to enable your Ubuntu system to export directories so that they can be accessed by users who are still stuck on Microsoft Windows systems. The combination of Samba utilities and the SMB/CIFS support that is built into the Linux kernel also provides the ability to access Shares from Ubuntu systems, all of which is available by default on those systems, as explained in Chapter 26.

Samba is probably the best example of the value that open source software can bring to modern computing, enabling seamless data sharing between UNIX and Microsoft Windows systems thanks to a fantastic combination of reverse engineering and insightful development.
