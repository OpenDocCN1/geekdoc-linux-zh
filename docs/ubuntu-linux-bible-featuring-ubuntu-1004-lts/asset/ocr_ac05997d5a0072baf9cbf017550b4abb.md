# Part II: Ubuntu for Desktop Users

Evolution provides two Preferences panels for setting how it sends and interacts with incoming mail that is formatted as HTML. These are located on the Preferences dialog's Mail Preferences and Composer Preferences panels. To display Evolution's Preferences dialog, select the Edit menu's Preferences.

To configure Evolution so that it always sends HTML mail, click "Composer Preferences" in the panel on the left. The panel shown in Figure 7-14 displays.

To always send HTML mail, click the checkbox beside "Format messages in HTML." When you close Evolution's Preferences dialog, this will become the default format for all new messages that you create.

To set the options for how Evolution handles HTML-formatted mail that you receive, click "Mail Preferences" in the panel on the left, and click the HTML Mail tab. The panel shown in Figure 7-15 displays.
