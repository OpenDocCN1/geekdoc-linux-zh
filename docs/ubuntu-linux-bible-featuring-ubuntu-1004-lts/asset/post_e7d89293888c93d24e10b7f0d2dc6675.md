## Starting and Exiting vi

The core tasks for any application are starting and getting out of it. As mentioned previously, getting out of vi the first time can be tricky because of its modal nature, but after that, it becomes second nature.

Because vi is a command-line application, you usually start by typing the vi command in a GNOME Terminal or xterm window. You can optionally provide the name of the file that you want to edit on the command line, and vi will automatically open and display that file for you. ## Part II: Ubuntu for Desktop Users

You can exit vi and return to the command prompt in several ways, but you first have to be in Normal mode to do so. If you are editing a file and want to return to Normal mode, simply press the Esc key ("Escape"). If the key sequence ^ displays in the file that you are editing, press Esc. You can then exit vi from several different ways:

- To exit unconditionally without saving any changes, type :q or zQ command. The :q command is the standard quit command, which will complain if you have made changes to the current file and have not saved them. The :q command essentially means "Yes, I want to quit, and I know what I'm doing."
- To save any changes you've made to the current file and exit, type the :x or :wq command. The :x command is specific to vi, while the :wq command is the traditional exit mechanism (stands for "write and quit"). You can also write any changes to the current file and exit by typing the ZZ command (no colon required).
- To specify name the file you want to save your changes, type the :w filename command, where *filename* is the name of the file you want to edit. If the file already exists, you will have to use the :w!filename command, which loosely translates, means "Yes, I want to write this file, and I know what I'm doing."

## Inserting Text in vi

Once you've started vi

To begin inserting, type the i command. This causes vi to enter Insert mode. Any characters that you type will be inserted into the file that you are editing until you exit Insert mode. As a reminder, the easiest way to exit from Insert mode is by pressing the Esc key (Escape) on your keyboard. If you're not sure what mode you're in—if it doesn't beep, you've just exited Insert mode and are now in Normal mode. If it beeps, you're already (and still) in Normal mode.

## Note

All commands in vi and its clones are case-sensitive.

Using the i command begins inserting text at the current cursor position, which can be awkward. If you want to begin adding text immediately after the current cursor position, use the A command. To begin appending text after the end of the current line, use the a command. The a and A commands are just specialized commands for entering Insert mode at a specific point—exit Insert mode after using these commands, press the Esc key.

## Moving Around in vi

The editor is knee-deep in cursor movement commands. The most common are as follows:

- h or left-arrow: Move the cursor backward one character in the current line.
- l or right-arrow: Move the cursor forward one character in the current line.
- j or down-arrow: Move the cursor down one line, maintaining the current column position in the new line when possible.
- k or up-arrow: Move the cursor up one line, maintaining the current column position in the new line when possible.

Cursor movement commands as h, j, k, and l may initially seem pretty strange or at least counterintuitive, remember that vi was originally designed to be used on terminals, some of which didn't have the arrow keys. Ask your grandfather.

## Note

When in Insert mode, the old-time vi movement commands (h, j, k, and l) insert those letters rather than moving the cursor (vi is a modal editor, remember?). However, the arrow cursor movements "do the right thing" when you're in Insert mode — they simply move the cursor but leave you in Insert mode.

As mentioned previously, you can repeat these simple cursor movement commands any number of times by prefixing them with a numeric argument. For example, you can move the cursor forward five lines by typing 5l, up five lines by typing 5k, and so on. This is handy, but requires you to count how far you want to move the cursor first. That seems somewhat tedious when you really want to do things like move to the next word, move to the previous word, or (commonly) go to some local place in the current file. To simplify things, it provides handy cursor movement commands like the following:

- b: Move backward one word.
- w: Move forward one word.
- ^: Move to the beginning of the current line.
- $: Move to the end of the current line.
- (: Move to the beginning of the current sentence.
- ): Move to the end of the current sentence.
- [: Move to the beginning of the current paragraph.
- ]: Move to the end of the current paragraph.
- 1G: Go to the first line in the current file.
- 0G: Go to the last line of the current file. Just pressing G in vim does the same thing, but may not work in all versions of vi.

The last two commands are actually examples of the standard vi commands to go to a specific line, and they highlight how nicely vi commands work with numeric arguments. For example, you could move to the 14th line in your file by typing the 14G command. Similarly, you could move to the end of the third paragraph from your current position by typing 3) command.

## Part II: Ubuntu Desktop Users

In addition to these cursor movement commands, vi also provides several commands to enable you to scroll the screen without moving the current cursor position (unless you want to, of, course). These screen movement commands are as follows:

- **Ctrl+d**: (Hold down the Ctrl key and press the letter d.) Scroll down one screen in the current file.
- **Ctrl+e**: (Hold down the Ctrl key and press the letter e.) Scroll down one line in the current file.
- **Ctrl+u**: (Hold down the Ctrl key and press the letter u.) Scroll up one screen in the current file.
- **Ctrl+y**: (Hold down the Ctrl key and press the letter y.) Scroll up one line in the current file.

Ctrl+d and Ctrl+u commands scroll the screen but leave the cursor at the same position (although the text underneath has changed). Ctrl+e and Ctrl+y commands keep the cursor at the same position in your text until that line scrolls off the screen, at which point the position is preserved.

## Deleting and Changing Text in vi

As with operations, you can delete text in vi with several different commands. To delete the character at the current cursor position, press the letter x. You can, of course, delete a specific number of characters by preceding the x command with a numeric argument. For example, x14 deletes 14 characters from the current character position.

Although the x command is handy when deleting a few characters, most people prefer deleting in terms like "delete the current word,"delete everything to the end of the current line," or "delete the rest of the paragraph." To perform these sorts of actions, use the d command, followed by a movement command that deletes the end of the area that should be affected. For example, the command dw deletes all of the text from the current cursor position to the end of the current line, and dd deletes everything from the current cursor position to the end of the current paragraph. If you remember, the second character of each of these commands is one of the movement commands described in the previous section.

When you're editing a file, it is common to delete some text and then immediately replace it with new text. You can do that with a combination of one of the delete commands, followed by an insert or append command. To save typing, vi provides the c (change) command to do both of things (deleting a delimited portion of your text and entering Insert mode) in time. For example, you could use the cw command to change the text from the current cursor position to the end of the current word, the c$ command to change the text from the current cursor position to the end of the current line, and so on. When using vi's change command, you are placed in Insert mode, so you must use the Esc key to return to Normal mode when you're done entering text.
