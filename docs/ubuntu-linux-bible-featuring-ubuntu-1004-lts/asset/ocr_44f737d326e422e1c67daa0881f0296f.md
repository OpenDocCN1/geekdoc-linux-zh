Now the fun begins! To create a cell that contains the sum of selected values from each row, the cell where you want to create the value, and enter the value sum(). The equals tell the spreadsheet that you are using a function, sum is the name of the function that you want to perform, and the opening parenthesis identifies the fact that this will be followed by a list of the cells that you want to be involved in the function. (You can also do this with the mouse, I'll explain later, by typing the function operator is easier for the purposes of this example.)
