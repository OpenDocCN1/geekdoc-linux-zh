# # Linux and UNIX Printing History

The evolution of multiple printing systems for UNIX led to incompatibilities between the different printing systems, requiring recompilation of the filters for specific different UNIX systems (if Software could get the source code at) and so on. Eventually, a company as Easy Software Products developed a more generalized printing system for UNIX, Linux, and other UNIX-like systems as the Common UNIX Printing System (CUPS). The original version of CUPS used the standard networked LPD protocol, but quickly switched to a new standard, the Internet Printing Protocol (IPP), which non-UNIX/Linux systems such as Windows can use to print papers. Easy Software Products also had the foresight to make the CUPS source code freely available under the GPL so it could be compiled for multiple operating systems and thus become a true, cross-system standard popularized by billions of users and system administrators. This strategy has worked — today, CUPS is used in every major Linux distribution and most other UNIX-like systems.

Most distributions, including Ubuntu, provide their own utilities for setting up printers and doing some basic configuration of the printing subsystem. Ubuntu uses the GNOME printer configuration tool, which was described in the section "Adding a Printer" in Chapter 20. However, in standardizing how printing works across many Linux systems, CUPS added one especially nice gift for system administrators: a built-in administrative tool for CUPS configuration that is easily accessed through any Web browser via port 631. In this chapter, however, I am focusing on using the standard Ubuntu/GNOME printer configuration tools as much as much as possible.
