# Part II: Ubuntu for Desktop Users

In the List name field, enter the name of the list that you want to create. You can then add e-mail addresses to the new list in any of the following ways:

+   - Click Select to display the dialog shown in Figure 7-30, in which you can select existing Contact entries and click Add to add to the current Contact List. When you're done, you can click OK to return to the dialog shown in Figure 7-29.

![](bbox=[0.08, 0.24, 0.952, 0.61])

+   - Drag-and-drop entries into the Members area from the pane in which your contacts are listed.
- Manually enter e-mail addresses that you want to add to the list, pressing Return after each address.

Once you've created and populated a Contact List, you can configure whether or not the e-mail that you send to the list contains all of the e-mail addresses of its members. The "Hide addresses when sending mail to this list" checkbox is selected by default. For a mailing list, the recipients of your messages will see Undisclosed Recipients as the name to which the message was sent and will not be able to reply to anyone other than you (because the names of the other list members are hidden). If you deselect this checkbox, all of the e-mail addresses of the list members will be shown in the "To: field of your mail message, and any recipient can therefore reply to every recipient by selecting the "Reply to All" command.
