That's a lot of typing for a repetitive series of operations! Luckily, the chmod enables you to group multiple permission operations. Suppose I wanted to remove the ability for anyone other than myself to execute this script. I could do this with the following single command:

```
$ chmod go-x hello.sh
$ ls -l hello.sh
-rwxr-xr-- 1 wwh 36 2006-03-18 16:30 hello
```

Note that I used 0, which means anyone who is not in the group vwh, rather than a, which means all users on the system, because all users on the system would include me.

You can add or remove write for any supported permission group using the chmod command and similar operations. Files and permissions have the same meanings for directories as they do for files, with the exception of the executable bit, which for directories grants permission to search that directory. For example, you can create a directory that no one but you can read, but still enable people to execute programs or shell scripts that it contains by removing read permission (r), making sure that search permission (x) is still set. People won't be able to see what's in the directory, but they can execute programs or that if it contains their exact names.

# When Creating Permissions Files and Directories

A umask (user mask) is the UNIX mechanism for setting the default protections of files and directories that you create. By default, the umask is a four-digit octal number that is logically ANDed with the generic permissions of 0666 (ironically) when you create a file, or 0777 when you create a directory. These octal numbers are representations of the file/directory permission field that was discussed in Chapter 4. The default umask value on Linux distributions is 0002, meaning that any file you create is created with theal protection 0664—both the owner and group can read and write to any file you create, but others can only read the file. Similarly, any directory that you create with the octal protection 0755—both the owner and group can create files in that directory, and anyone can list the contents of the directory and search for files in it. You can set a user's default umask by setting the umask command from any Linux command-line prompt.

Most people set their umask to 0022 in their shell configuration file (typically ~/.bashrc) so that files can only be written by their owners (i.e., are created with an octal protection of 0644) and directories can only be written to by their owners (i.e., are created with an oct protection of 0755).
