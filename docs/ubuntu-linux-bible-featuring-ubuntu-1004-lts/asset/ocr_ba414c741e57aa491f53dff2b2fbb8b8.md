# Getting a 64-Bit Desktop CD

The Ubuntu Desktop CD provided with this book will boot on any x86 PC system. If you want
to install or experiment with Ubuntu on a 64-bit computer system, you will need to obtain a di-
fer, equivalent Desktop CD. If you have a reasonably fast Internet connection (or plenty
of time) and a CD burner, the easiest way to get a different Desktop CD is to download an ISO
image. An ISO image is a file containing an exact copy of the CD-ROM or DVD that is in the format
mandated by the International Standards Organization 9660 specification.) To get a 64-bit Ubuntu
Desktop CD, go to Ubuntu's web page at www.ubuntu.com/download, select the version of
Ubuntu that you want a CD, select your country or the one that's closest to you in
general, and select an ISO of the 64-bit Desktop CD. Save the downloaded ISO image to a
file, burn it to CD once the download completes, and you're ready to go!

If you have a slow Internet connection or do not have a CD burner, panic! As mentioned in the
Introduction for this book, the Ubuntu folks will ship you Ubuntu CDs, although they
take a few weeks because they're shipped from the Netherlands. This isn't the right solution for
of us who are instante instant gratification, but it might work for you. To request CDs directly
from Ubuntu, go to the Ubuntu web page at https://shipit.ubuntu.com, create an account
by entering your e-mail address and a password, and request one or more sets of Ubuntu CDs for
the current release. You can order free CDs system types at the same time.

# Booting from a Desktop CD

Booting from an Ubuntu Desktop CD is as easy as inserting the appropriate Desktop CD into
your system's drive, restarting your system, and making sure that the system boots from the
CD drive before booting from a hard partition.
