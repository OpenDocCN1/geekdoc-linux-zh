# Tux Racer

Tux Racer is a 3D action game that features Tux, the penguin mascot of Linux, in various downhill racing scenarios, collecting herrings for extra points as he goes. You can increase Tux's speed by navigating so that you are sliding on ice, and you must avoid obstacles such as trees and rocks.

Tux Racer has an interesting history because it began as GPL software, was marketed as a product containing closed-source enhancements, and then came back to life through multiple forks of the last versions of the original GPL code. For this reason, several versions of Tux Racer are available, including SuperTux (a 2D version, in the supertax package), Planet Penguin Racer (in the planetpenguin-racer package), and Extreme Tux Racer (in the extremetuxracer package). Tux Racer is fast moving, attractive, and fun. The Extreme Tux Racer variant (www.extremetuxracer.com) is the only version that is still actively developed and supported.
