# Creating a New Source Project in Eclipse

After starting Eclipse you create new projects or projects by selecting File New, and selecting the appropriate item from this menu. To create and work with an application in Eclipse, you must first create a project to hold your source code. Eclipse provides wizards to simplify projects of different types. Wizards are sets of graphical screens that walk you through the process of creating a specific type of project, making sure that you don't miss any of the steps in the process
