+   - **Ignored Files**: Enables you to identify directories and wildcard patterns for filenames
that it will not index. For example, you can disable anything under your music
by entering `/home/username/music` in the "Ignored Paths" text area (you
would, of course, replace username with your login name), and you can disable-
ingindexing MP3 files by pattern `*.mp3` in the "Ignored Files Patterns" textbox. To add a
new path or file pattern to ignore, click Add beside the appropriate text area, enter the
path of the file pattern, and press Return. To remove an existing one, highlight it in the
appropriate text area and Remove.
- **Email**: Enables you to specify indexing of e-mail stored in the mbox format used
by mail clients such as Evolution, which is not located under your home directory.
- **Performance**: Enables you to configure how the Tracker daemon operates on your sys-
t to minimize its impact on the system. Options include Throttling (which would prevent me from
reducing the amount of CPU that the Tracker can use), Resource Usage (the
amount of memory that the Tracker daemon uses—reduced memory causes slower
indexing but leaves more memory available to other applications), and Index Limits
(per file) (how the Tracker daemon handles merging existing entries with index entries
for new files, and the maximum amount of text and words that should be
 in each file).

The most commonly used of these tabs are the Files and Ignored Files tabs. The tab is es-
cially useful if you store information that you want to index in directories other than your home
directory. The Ignored Files tab is especially useful if you do not want to index specific types of
files or files in certain directories. For example, I use a network-attached storage (NAS) device at
home to archive old files that I want to be able to access from multiple systems, which I can do
mount its filesystem on any machine. Aside from archived personnel and research data,
al also store my collection on this system. I therefore add the mountpoint for this
to the Files tab's list of directories that I want to index and watch, and add the subdire-
tory of my mountpoint to the Ignored Files tab's list of Ignored Paths. I could also do the latter
by adding the file extensions for the file formats that I store (`*.ogg, *.flac, *.shn, and
`*.mp3`) to the Ignored Files tab's "Ignored File Patterns", but which would prevent me from
locating any music files that are in any other directories (such as a specific system), which I
personally don't want to.
