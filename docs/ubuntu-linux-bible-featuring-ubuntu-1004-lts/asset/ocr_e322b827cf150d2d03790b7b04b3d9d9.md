# Basic Operations in Nautilus

Like other graphical file managers, Nautilus makes it easy to manage and manipulate files and directories. Most of the commands related to working with files and directories are located on the Edit menu, and are also accessible from the context-sensitive menu displayed when you rightclick on any object in the Nautilus Display pane. Figure 5-30 shows the context-sensitive menu displayed when right-clicking on a file with the .txt extension in my home directory.

As you can see, this menu provides the standard actions that you would expect to find in any file manager, enabling you to do the following:

+   * Open the file with the default application associated with that type of file.
* Open the file with the other applications associated with that type of file.
* Cut or copy the file, enabling you to paste the file (or a copy of it) into another location to move or copy the file.
* Create a symbolic link to or rename the selected file.
* Rename the file.
* Copy the file to a specific location (only available in the version of GNOME used in Ubuntu 10.04 and later).
