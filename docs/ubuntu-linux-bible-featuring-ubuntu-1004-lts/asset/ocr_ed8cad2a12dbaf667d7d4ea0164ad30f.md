Once you download an AWN theme, you install it by selecting the Awn Manager’s Themes tab, clicking Add, and navigating to the location where your themes are stored. (I tend to keep them in ~/ART/AWN so that I know to look for them if I want to use them on other systems.) You then select the compressed tar archive file that contains your theme and click Open. Once a theme has been added, the Themes tab looks like that shown in Figure 6-16.
