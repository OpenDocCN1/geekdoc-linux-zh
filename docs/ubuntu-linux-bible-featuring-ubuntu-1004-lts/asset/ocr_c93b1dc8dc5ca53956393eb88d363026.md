# Playing Audio CDs Using Rhythmbox

Once Rhythmbox starts, you may need to select the entry in the Device section in the pane to the left to display information about the CD you have inserted. This will initially try to look up any CD that you insert in the online CD information database freedb.org. If it finds a matching entry, it displays information about the CD and the tracks that it contains, as shown in Figure 16-10.
