+   2. Modify your /etc/network/interfaces file to add an entry for a bridge, and- connect the network device that is associated with your system's physical network inter- face to. You should also comment out any existing entry for that network device. The following is a sample entry for a bridge named br0 to which the network device eth0 is attached:

```
auto eth0
iface eth0 inet manual
 up ifconfig $IFACE 0.0.0.0 up
 up link set $IFACE promisc on
 down link set $IFACE promisc off

auto br0
iface br0 inet dhcp
bridge_ports eth0
bridge_fd 0
bridge_maxwait 0
metric 0
```

The first section defines eth0 as a TCP/IP network device that is automatically started when the network is brought up, but which is manually configured to have a static IP address of 0.0.0.0, and which is also put into promiscuous mode. Promiscuous mode is a special mode in which a network interface can receive all traffic on the network, if it is not addressed to that specific device or interface. Comment out any existing entries for your network device (eth0, as the example used in this!) The second entry says that br0 is automatically started when the network is brought up, is (because of the bridge_ports entry) that should get its configuration via DHCP, that no delay should be imposed when forwarding packets across the bridge (the bridge_fd entry), that the bridge should immediately enter forwarding mode as soon as it comes (the bridge_maxwait entry), and this interface should be considered a high-priority interface that can immediately reach a default gateway (the metric entry).
