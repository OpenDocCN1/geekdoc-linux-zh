# Other Graphics Applications

Graphics programs seem to rank second to text editors and word processors in terms of the sheer
number of available choices. Each has its own niche, fans, and detractors. Since I've already
ledged that I am not particularly good at graphics, I've covered only the graphics programs
at I have actually used at one time or another and I feel that are the best applications for creat-
ing and editing various types of graphics on Linux systems. Some other good graphics applic-
are as follows (all of which are available in the Ubuntu repositories unless noted):

+   - Blender (www.blender.org): An impressive 3D modeling graphics, rendering, and
animation package that has been used to make various animated films, video and desk-	op computer games, and so on. Blender is also a great tool for architectural or simple
wire-frame drawings.
- CinePaint (cinepaint.org): An image-editing application that began life as
an earlier version of GIMP, but has since seen a significant amount of develop-
ment since then, including adding support for 8-bit, 16-bit, and 32-bit color channels
and high-quality image formats such as DPX, 16-bit TIFF, and OpenXR. CinePaint has
been used in many feature films (the "Harry Potter" films, The Last Samurai, the Lord of
the Rings" films), so it's impossible to dispute its quality or its business value.

# Note

CinePaint is not available in the standard Ubuntu repositories but is included in the media-oriented
Ubuntu Linux distribution (http://ubuntustudio.org). ■

+   - Dia (http://1.gnome.org/dia/): A GNOME-based application for creating
editing diagrams and flowcharts on Linux systems, similar to and evocative of
Microsoft's Visio application. Dia is not installed by default on Ubuntu systems.
