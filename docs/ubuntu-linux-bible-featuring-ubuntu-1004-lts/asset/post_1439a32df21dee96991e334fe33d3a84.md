However, if you're already familiar with another editor that also uses commands consisting of combinations of Ctrl or Esc keys and the standard keys on your keyboard, your fingers are probably used to press certain keys to execute certain commands. The most common customization needed to Emacs is therefore to change the keys to which commonly used commands are associated.

Although Emacs lets you change key bindings globally or within a specific mode, it is more common to customize a specific key binding so that it works regardless of the mode in which you are using Emacs. The Emacs configuration command to set a key binding is `global-set-binding`. To set the key Ctrl+z globally to a function that scrolls the buffer up one line rather than attempting to suspend Emacs, you would use the following command in your `~/.emacs` file:

```
(global-set-key "C-Z" scroll-one-line-up)
```

In Lisp fashion, you must prefix the name of the function that you are referring to with a single quotation mark. If you are interested, the `scroll-one-line-up` function is provided as an example in the section entitled "Defining Your Own Functions" later in this chapter.

### Note

When you are specifying key bindings in an Emacs configuration file, the Ctrl is usually represented by `\C-` and the Esc key is usually represented by `\M-`.

### Setting Variables

Emacs uses several internal variables to control its behavior. You can modify these variables using the `setq` command. For example, to cause Emacs to scroll more smoothly in one-line increments, you could add the following line to your `~/.emacs` file:

```
(setq scroll-step 1)
```

Another example, the default settings in Emacs cause it to automatically save your files each time you have typed or modified 300 characters. To decrease this value to every 100 changes, you could add the following line to your `~/.emacs` file:

```
(setq auto-save-interval 100)
```

### Specifying Modes

As discussed, Emacs provides different key bindings and functions based on the types of files you are using, known as modes. The default mode used by Emacs when you start Emacs without specifying the file that you want to edit is known as the fundamental mode. You may want to customize Emacs to always use a different mode by default, regardless of the name of the file. For example, to make text default each time you start Emacs, you could add the following line to your `~/.emacs` file:

```
(setq default-major-mode 'text-mode)
```

You can see from this example, the name of the default mode in Emacs is defined through an Emacs variable, `default-major-mode`, which in this case requires the name of an Emacs function rather than a numeric value as shown in the examples in the previous section.

Each Emacs mode also enables you to specify other actions whenever you use that mode. For example, to turn on auto-fill (wrapping words to the next line when you reach a certain column on your screen), you can add the following line to your `~/.emacs` file:

```
(add-hook 'text-mode-hook 'turn-on-auto-fill)
```

### Changing File Associations

As discussed, Emacs automatically enters specific modes when you open files with a specific extension, as many as GUIs do when you click on a type of file. You may occasionally want to have Emacs automatically enter a specific mode when you open files that the specified mode is not traditionally associated with. For example, Emacs automatically enters text mode when you edit files with the .txt or text extensions. But what if you typically name text files with the .inf extension and want Emacs to automatically enter mode when entering files of that type?

The file extensions associated with different Emacs modes are stored in a list consisting of extension/mode-name pairs. To add the .inf extension to the list of extensions you would simply append the extension to the list of extensions associated with text mode, as in the following example:

```
(setq auto-mode-alist
cons '(".inf" . text-mode) auto-mode-alist)
```

This example uses the Lisp `cons` to append the function `.inf` and `text-mode` to the list of automatic file associations, and then uses the `setq` function discussed earlier in this chapter to set the `auto-mode-alist` variable to the new, expanded list.

### Defining Your Own Functions

The fact that Emacs has an internal implementation of Lisp makes it relatively easy to define your own functions and provides a practical reason for learning Lisp if you've always wanted one. Lisp functions are defined using the `defun` command, which takes a list of five values as arguments. Without turning this into a Lisp tutorial, it's just quick to look at a function definition and its components.

The following Emacs Lisp code defines a simple function that scrolls the contents of the window some number of lines, with the default number being 1:

```
(defun scroll-one-line-up
 (&optional arg)
  "Scroll the selected window one or N lines."
  (interactive "p")
  (scroll-up (or arg 1)))
```

The name of the function that you are defining is the first argument to the `defun` command. The second argument is the list of arguments that are used by the function that you are defining. In this case, `arg` uses the optional argument to state that this function can take one argument, but that argument is optional. The third argument to the `defun` command is an informational message about the function, enclosed in double quotes. The fourth argument defines whether the function is interactive (p). The fifth argument is the actual Lisp code for the function you are defining.

### Using gedit

Now that we have discussed the classic UNIX/Linux editors and their attendant philosophies, it's worth mentioning that Ubuntu provides an easy-to-use graphical editor called gedit. Figure 12-16 shows gedit displaying the text to illustrate the vi and Emacs editors earlier in this chapter.

The gedit editor is completely mouse- and menu driven and follows the standard keyboard conventions across platforms. These include the following:

- **Ctrl+c**: Copy selected text.
- **Ctrl+n**: Open a new file.
- **Ctrl+s**: Save the current file.
- **Ctrl+v**: Paste copied or cut text.
- **Ctrl+x**: Cut selected text.

As a graphical application, gedit provides convenient and more traditional dialogs for interacting with, moving around, and selecting files. It can also be customized to your specific editing needs by selecting the Edit menu's Preferences command, which displays the dialog shown in Figure 12-17.
