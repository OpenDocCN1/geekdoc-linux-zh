# Retrieving Package Source Code Using apt-get

Even in the wonderful world of constantly updated repositories with a rich collection of software, you may occasionally want to build your own versions of software packages for your system. The most common situation in which you'll want to do this is when you find patches to an existing software package that problems you're experiencing or add enhancements, and just can't wait for them to appear in the official or backports repositories. You may also have your own ideas about changes that should be made to a package and want to test and work through your ideas. Linux and its ecosystem of utilities and other applications are after all!

The apt-get command makes it remarkably easy to retrieve the source code for an installed package. The only requirement for this capability is that your /etc/apt/sources.list file includes a deb-src entry for the repository from which you retrieved the binary version of that software. For example, if you want to retrieve the source for a package in which the binary version is located in the multiverse component, you must have entries like the following (or equivalent entries) in your /etc/apt/sources.list file:

```
deb http://archive.ubuntu.com/ubuntu/ intrepid multiverse
d-src http://archive.ubuntu.com/ubuntu/ intrepid multiverse
```

Assuming that the right entries are present in your /etc/apt/sources.list file, retrieving the source code for a specified package is easy using the apt-get source command. The following example shows the retrieval of the source code for one of my favorite packages, the MyThVR video recorder:

```
$ apt-get source mythv
Reading package lists... Done
Building dependency tree... Done
Need to get 9836KB from /multiverse mythv 0.21.0+fixes18722-Ubuntu1...
Get: 1 http://.../intrepid/multiverse mythv 0.21.0. . .
Get: 2 http://.../intrepid/multiverse mythv 0.21.0. . .
Get: 3 http://.../intrepid/multiverse mythv 0.21.0. . .
Fetched 9836KB in 1s (107KB/s)
dpkg-source: extracting mythv-0.21.0
dpkg-source: unpacking mythv-0.21.0.orig.tar.gz
dpkg-source: applying ./mythv-0.21.0+fixes18722-Ubuntu1.diff.gz
```

When retrieving the source code for a package, the apt-get source utility actually retrieves multiple files. The extensions of these files are follows:

+   - diff.gz: A compressed file containing any patches to the standard source archive for the package
