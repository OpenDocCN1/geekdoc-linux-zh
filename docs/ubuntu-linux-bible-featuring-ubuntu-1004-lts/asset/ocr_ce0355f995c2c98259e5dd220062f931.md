# Chapter 23: Software Development on Ubuntu

+   * **Editor**: The pane at the top center, which differs based on the open resources in the Navigator view
* **Console**: The bottom-right view, in which messages about interactions with Eclipse are displayed. This view also provides a Problems tab that identifies any errors or warning associated with the current project, and a Properties tab that enables you to examine any properties associated with the current project.
* **Outline**: The view at the right, which shows an outline of the files and functions referenced and defined in the active project
