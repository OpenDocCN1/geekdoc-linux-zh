
## Part II: Ubuntu Desktop Users

## Using IRC

As discussed in the "Instant Messaging Overview" section of this chapter, Internet Relay Chat (IRC) was the first cross-platform mechanism for real-time Internet communications. As mentioned earlier, IRC is a client/server. IRC users connect to an IRC server using a client application that runs on their systems. IRC servers are typically themselves organized into networks of servers that share information with each other. Hundreds, if not thousands, IRC servers are publicly available and typically do not require a password in order to access them. See www.irchelp.org/irchelp/networks for a good listing of IRC servers and networks. The discussion areas on IRC are referred to as channels. Channel names are prefixed by a hash (#)—one of the most popular IRC channels for readers of this book should be the #ubuntu, which is a support channel for Ubuntu, a great place to ask Ubuntu-related questions at any level, and a generally useful resource. Most channels are accessible by anyone, but they can also be password-protected to provide private areas for communication between sets of users who know the password.

When first connect to an IRC server, you define a nickname (generally referred to as a nick), which is how you are identified on any channel that you join. Once connected, you can use commands prefixed with a slash (/) character to interact with the server itself. The following are common commands:

- /dcc nickname: Requests a direct, user-to-user chat with the user who has the specified nickname.
- /help: Summarizes IRC server commands. You can follow the /help command with another command (without the /) to get specific information about that command.
- /join #channel: Enables you to connect to a specified channel. If the channel does not already exist, it will be newly created by you as its operator, but IRC servers limit channel creation to specific users in order to cut down on the noise (and to prevent typos from automatically creating channels).
- /leave #channel: Leaves the channel.
- /list: Displays a list of available channels.
- /msg: Sends a message to the user whose name you specify.
- /nick: Enables you to define a nickname for you in IRC, typically your username.
- /quit: Drops your connection to IRC, displaying a farewell (signoff) message.
- /who #channel: Lists the users that are currently connected to a specific channel.

Although the first IRC clients were for UNIX and UNIX-like systems, IRC clients have been available for other operating systems shortly after the birth of IRC. Mac OS, Mac OS X, and Microsoft Windows systems all offer a wide selection of IRC clients. On the Windows platform, mIRC (www.mirc.com) is probably the most popular IRC client, although many others are available. The Miranda IM client for Windows (www.miranda-im.org) also supports IRC, as does Trillian (www.trillian.im). Macintosh users typically use IRC clients such as Ircle (www.inkle.com), which has been popular on Macintosh systems forever; Adium X (www.adiumx.com), which provides both IM and IRC access; and Colloquy (http://colloquy.info), which is impressive on the OS X desktop and on your iPhone.

The next two sections discuss how to connect to IRC using the Pidgin instant messaging client, and provide tips for getting more information about IRC.

## Using IRC in Empathy

As discussed in the sections on Empathy and Pidgin, IRC is one of the messaging protocols that is built into both applications. This section focuses on Empathy because it is the default IM client on Ubuntu systems. Because most IRC servers are open, you can create an IRC account and connect to an IRC server without having to pre-register, but you must create an Empathy account to do this. You will learn in this chapter, "Adding and Removing Empathy Accounts." When creating an IRC account in Empathy, your nickname is whatever you want it to_be, but it must be unique on the IRC server that you are connecting to. Empathy offers a high number of IRC servers in the Network dropdown, but if you're just getting started with IRC, the Ubuntu Servers entry is the best initial selection. This connects you to the IRC server http://irc.ubuntu.com (part of the freepode IRC network).

To join an IRC channel in Empathy, select the List dialog Join menu. The "Join Room" displays. Select your IRC account as the account to use, and enter the name of a room you want to connect to --Ubuntu is a good place to get started. A standard Empathy conversation window opens, and you'll see the ongoing public conversations between everyone else who's in that room (channel in IRC-speak). You can see a list of all the channels available on the Ubuntu IRC server at https://help.ubuntu.com/community/InternetRelChat.

At this point, you can enter other IRC commands in the text window at the bottom of the Pidgin screen, or simply enter text to send it to the channel. When you're asking questions, answering questions, or simply switching the flow of communications, you can leave the channel using the /leave command to leave a channel or the /quit command to close your connection to IRC.

## Note

If you find IRC interesting, useful, or perhaps even bob, you may want to investigate other Linux IRC clients. Empathy is fine for most users, the XChat program is a UNIX/Linux IRC client that has been around for a long time, is quite popular, and makes it very easy to connect to multiple channels and servers at the same time. XChat uses GTK, so it is well-suited for GNOME-based Ubuntu desktops. XChat is not installed by default, but is available in the default Ubuntu repositories. The latest version of XChat for Ubuntu systems is located in the xchat-gnome package, which you'll have to install using your favorite Package Management tool.

## Part II: Ubuntu Desktop Information about IRC

## Getting More Information about IRC

Regardless of how well it fits the IM model, IRC is still popular, quite fun, and occasionally useful. When you first connect to IRC, you'll probably be doing so in order to connect to a specific channel, like #ubuntu. Most of the channels on the Ubuntu IRC servers are Ubuntu-related, but you may be interested in channels such as #newirc, #newbies, and #newuser that are found on other IRC server and providing interesting starting points. If you'd like general information about IRC or have some specific questions, you may want to explore #irhelp. For information about available channels, use /list on the IRC server you're connected to, or use a Web-based resource such as ..irhelp/irhelp/list.

The following are some great sources of additional information about IRC, its culture, IRC servers, other sites, and so on:

- IRC (www.irc.org): Known as the original home of IRC, this site provides news, help IRC history and information, about ongoing developments in IRC, and a huge collection of useful links to many IRC-related sites.
- IRChelp (www.irchelp.org): The Internet Relay Chat Help provides a tremendous collection of IRC FAQs, primers, HOWTO guides, helper scripts, lists of active supported channels, and so on.
- Wikipedia (http://en.wikipedia.org/wiki/Internet_Relay_Chat): In addition to the standard "online encyclopedia" info, the Wikipedia article on IRC provides links to many other IRC-related sites—or at least it did at the time of writing.

## Other Instant Messaging Packages

Empathy and Pidgin provide all of the functionality that almost everyone needs in a multi-protocol IM client. However, Ubuntu is a Linux distribution, so you might suspect there are a huge number of other IM applications out there. Some of my favorites are the following (listed in alphabetical order):

- Google Talk (www.google.com/talk): Google Talk is a Windows and Web-based client for Google's chat, or any other XMPP-based chat service.
- Licq (licq.org): Licq is an ICQ client that uses the QQ desktop widgets. it is actively under development. Plug-ins are available to enable Licq users to communicate with AIM and MSN users.
- Meebo (www.meebo.com): Meebo is a Web-based instant messaging service that supports its own accounts as well as providing access to other IM services that Meebo supports, such as AIM, GoogleTalk, ICQ, jabber, MSN, and Yahoo. A Firefox plug-in for Meebo is also available.
- Psi (http://psi-im.org): Also in Ubuntu repositories, Psi is a free Jabber/XMPP client that is available for Linux, Macintosh, and Windows systems and uses Qt.
