# Connecting to an FTP Server Using Graphical Clients

If you need to use FTP but would prefer a stand-alone GNOME FTP client application, two-popular ones are available from the Ubuntu repositories:

+   - gtk-ftp: If you use a standard GNOME-based Ubuntu system, a GNOME FTP client that uses the GTK graphical interface. Installing this package will create an entry on the Applications Internet menu gFTP. This command makes it easy to graphically transfer files using FTP and also enables you to bookmark FTP settings (hostname, username, password, etc.) just as you would do in your favorite web browser.
