# Switching Themes

The word *theme* is the term for the combination of window and dialog controls, a color scheme, and a set of icons that gives your desktop and the windows that it displays a specific look and feel. Many themes also come with a specific desktop background to complete the visual experience that their author was trying to achieve. Experimenting with different themes can be a lot of fun, and can also be extremely useful to make it easier to read window titles and generally adjust contrast on your screen.

To change or configure the theme used on your Ubuntu system, select the System Preferences Appearance menu item. This application displays the Theme tab when it starts, as shown in Figure 5-25.
