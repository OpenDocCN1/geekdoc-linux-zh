# Fixing Virtual Machine Boot/Installation Problems

As mentioned earlier in this section, any user who wants to run VirtualBox be a member of the vboxers group. This is usually automatically for the user who installs VirtualBox, but other users will not be able to run VirtualBox until they are added to the vboxers group with a command like sudo adduser USER vboxers.

Even if the current user is a member of this group, a related problem that you may encounter is a dialog to the effect that the /dev/vboxdrv device was not accessible by the current user. This device should always be owned by the root user and the vboxers group, and should be set to 0660 so that anyone in the vboxers group can read/write it. You can change this manually with the following commands:

```
sudo chown root.vboxers /dev/vboxdrv
sudo chmod 0660 /dev/vboxdrv
```

To resolve this particular problem, all you have to do is remove the loadable kernel modules that VirtualBox is complaining about, using a command like the following:

```
sudo /sbin/rmmod kvm-intel kvm-amd kvm
```
