# Automatically Mounting Filesystems at Boot Time

When Ubuntu system boots, the boot block on your primary disk identifies the filesystem that contains the second-stage boot loader, which uses a configuration file to determine which kernels and associated boot options are available on your system. Older Linux systems used a boot loader called LiLo (Linux Loader), while Ubuntu and most other modern Linux systems use a boot loader GRUB (Grand Unified Boot Loader).

During the boot process, the root filesystem is initially mounted read-only-standard processes so that its consistency can be verified. Once this is done, it is remounted in read-write mode, and your system verifies the existence and consistency of any other filesystems that it will be using. The list of filesystems available to your system is contained in the file /etc/fstab (File System Table).

Each line in /etc/fstab provides information about one of the filesystems that should be available to your system. To add a new filesystem so that it will be mounted when your system boots, or to customize your system interfaces with a specific type of device, you need only add or customize an entry for filesystem in the /etc/fstab file. A sample section of the /etc/fstab file on one of my systems looks like the following (this file will be on your system):

```
$ cat /etc/fstab
LABEL=/               ext4 noatime,acl,user_xattr 1 2
/dev/sda3             boot      ext3 noatime,acl,user_xattr 1 2
/dev/sda8             home      ext4 noatime,acl,user_xattr 1 2
/dev/sda5             tmp       ext4 noatime,acl,user_xattr 1 2
/dev/sda6             usr       ext4 noatime,acl,user_xattr 1 2
/dev/sda7             usr/local ext4 noatime,acl,user_xattr 1 2
/dev/sda2             swap      swap      0 0
/dev/hdel             opt2      ext4 noatime,acl,user_xattr 0 0
devpts                /dev/pts devpts    mode=0620,gid=5 0 0
proc                  /proc     proc      defaults  0 0
sysfs                 /sys      sysfs     noaut     0 0
/dev/hdd0             /media/cdrom0 iso9660 user,noaut 0 0
/dev/fd0              /dev/floppy0 auto    rw,noaut 0 0
```
