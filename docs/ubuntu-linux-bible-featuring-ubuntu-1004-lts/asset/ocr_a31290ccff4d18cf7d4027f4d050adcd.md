# Converting and Reducing Images Using GIMP

Most of us nowadays have a web page that we use to share information and pictures with our friends. Most digital cameras save images in JPEG format, which can provide a balance between small file size (so that web pages containing images will load in our lifetimes) and good quality (so that you appear to know what you're doing with your digital camera). Regardless, there are going to be times when you have images in larger file sizes that you want to reduce in size and convert to other formats. For example, the TIFF files produced by scanning software today are huge and shouldn't be displayed on a web page. Similarly, most digital cameras today photos in many megixels, which are great for printing but are overskill on a web page.

Because GIMP supports many different graphics file formats, it is an excellent tool for converting images to formats that you can use elsewhere (not notably on the Web), and for reducing size without sacrificing too much quality. The sidebar "Graphics Formats Supported by GIMP shows all of the graphics file formats and associated file extensions that are supported by GIMP.
