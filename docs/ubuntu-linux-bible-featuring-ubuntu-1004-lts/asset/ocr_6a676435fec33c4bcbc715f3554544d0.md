# Chapter 19: Adding, Removing, and Updating Software

The focus of the remainder of this chapter was on the graphical installation and automatic software update applications that are available on Ubuntu (Synaptic and Update Manager) systems. The chapter also discussed how the installation utilities to identify and install software packages and how to use the update utilities to keep your system up-to-date, by installing security fixes or enhanced versions of existing software whenever they are available.

Chapter 20, "Adding Hardware and Attaching Peripherals," discusses how to add various types of hardware to your Ubuntu system. Like most modern personal computer systems, Ubuntu systems do a great job of automatically recognizing and providing access to new printers, scanners, and removable storage such as USB sticks, USB hard drives, FireWire devices, and so on. Adding new internal drives requires a bit more work, but it is a key element of permanent system upgrades and is easy enough to master.
