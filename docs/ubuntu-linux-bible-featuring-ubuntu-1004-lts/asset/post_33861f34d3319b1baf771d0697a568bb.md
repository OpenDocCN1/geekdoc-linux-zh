## Starting and Exiting Emacs

As with vi, to begin editing a file in Emacs, you can do either of the following:

- *Select the GNU Emacs command from the Applications Accessories menu.*
- In any xterm or GNOME Terminal, simply type the command Emacs filename, where *filename* is the name of the file that you want to edit. By default, starting Emacs from a terminal window on Ubuntu system creates a new window for Emacs as a result, you will probably want to follow the name of the file that you want to edit with an ampersand to start your Emacs session in the background and return control to the Terminal window so that you can type additional commands there while Emacs is running.

In either case, Emacs will create an initial window displaying any file that you are editing, as shown in Figure 12-7. If you start Emacs from the GNOME menus, Emacs displays an initial Welcome screen, as shown in Figure 12-12.

## FIGURE 12-12

To exit Emacs, you can use either the Exit Emacs command on the File menu or the Ctrl+x Ctrl+c (as a refresh, this means you to hold down the Ctrl key and press the letter x, then press the letter c, and then release the Ctrl key) combination.

If you have not modified any files while working with or have already saved all of the changes you have made, Emacs exits immediately. However, if you attempt to exit from Emacs using menu commands and have not saved any of the changes to the file(s) that you've been editing, Emacs displays the confirmation dialog shown in Figure 12-13 for each file that contains unsaved changes.

To proceed without saving your changes, click No. To save your changes and proceed, click Yes. If you save your changes by selecting Yes, Emacs exits immediately once those changes have been saved for each modified file that you were working on. If you click No, Emacs displays yet another confirmation dialog, asking you if you're really, really sure that you want to exit without saving your changes, as shown in Figure 12-14. Emacs doesn't quite beg you to save your files, but it makes every attempt to ensure that you know what you're doing and aren't accidentally exiting without saving the great American novel.

Most of us are used to working with text files in various applications, often specified by their file extension. However, the files produced by graphical word processors such as Microsoft Word (.doc) or .ppt files produced by PowerPoint, are not plain text. While it is possible to use these files, it often makes them hard to use with any application other than the one created them.

At the end of the day you may have application-specific files that are the lowest-denominator file format (like text files, or .txt). The advantage is that they can represent every symbol you find on a keyboard. The nice thing about these files is that they are easy to read, and easy to work with.

If you are using a modern Ubuntu Linux system, you will find it quite easy to edit a text file of these days. If you write code, this provides the lowest-common format that can be processed by any compiler or interpreter. It is a safe way to store text files that you can work on your Ubuntu Linux system as you can on your Mac or Windows.

## Moving Around in Emacs

There are many different keys for moving the insertion cursor in Emacs:

- Ctrl+a: Go to the beginning of the current line.
- Ctrl+e: Go to the end of the current line.
- Ctrl+f: Move forward one character.
- Ctrl+b: Move backward one character.
- Ctrl+p: Move to the previous line.
- Ctrl+n: Move to the next line.
- Ctrl+v: Scroll down one screen.
- Esc+b: Move backward one word.
- Esc+f: Move forward one word.
- Esc+v: Scroll up one screen.
- Esc<: Go to the beginning of the current buffer.
- Esc->: Go to the end of the current buffer.

These are the most common keyboard commands for moving cursor around within the current window. When using Emacs in any graphical mode, you can also scroll the screen by clicking and dragging the button in the scrollbar, or simply move the cursor by pointing and clicking.

For information about the commands used to switch or move between multiple buffers that are displayed on the screen, see the section later in this chapter entitled "Working with Multiple Windows and Buffers in Emacs."
