# Greylisting via Postgrey

In the section on "Installing Postfix and Friends," I suggested that you install postgrey, which is a greylisting application that was designed to work with Postfix. That package is set up and started automatically and requires no other mandatory configuration—if you installed it you started Postfix, it's already working for you.

As mentioned in the installation section, greylisting is a cool technique wherein your mail server rejects all incoming mail the first time a remote mail server tries to deliver it to you. Spammers try only once and move on—they cannot afford to endlessly sending mail to hosts that have already rejected once. Real mail servers that are sending real mail will try to deliver the mail, at which point your Postfix server will actually talk to them. At that point, the other techniques described in this section kick in.

# Note

If you're interested, the term greylisting is related to two other techniques for avoiding spam. The term blacklisting refers to the practice of refusing to accept mail from hosts that are on a list of known or suspicious hosts. The term whitelisting refers to the practice of accepting only mail from a short list of known hosts, specific people, and so on. It's a shame we all have to resort to these sorts of techniques to protect ourselves from idiots spammers, but that's the reality of the Internet today.

Although Postfix requires no specific manual configuration, there are several command-line options that are not active by default that you may want to take advantage of. The Postfix server also has features that you may want to take advantage of customize how greylisting is done on your system. You can whitelist specific sites by adding them to the various whitelist files in /etc/postgrey. For example, the file /etc/postgrey/whitelist_clients identifies sites where no greylisting will be done—all incoming mail from these sites will be accepted immediately. Similarly, the file /etc/postgrey/whitelist_recipients identifies users of your mail that do not work greylisting—in other words, for whom mail will be accepted immediately, regardless of the site from which it originates. You should read the online page for Postfix using the man postfix command to see if there are options that you want to take advantage of fine-tune how the Postfix service works on your system.
