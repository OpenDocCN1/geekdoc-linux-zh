# Part II: Ubuntu for Desktop Users

# ## Copying, Moving, Renaming, and Deleting Files
and Directories

Copying, moving, renaming files are some of the most common actions that any computer user performs, regardless of whether you're using the command line or working with a graphical interface. Whether you're cloning an existing file to use the former as a starting point for new work or reorganizing your files and directories to make things easier to find, copying and moving files and directories is just as easy to do from the command line as it is from a GUI, except for the fact that you have to type rather than point and click. In many cases, the trillions of options provided by many Linux command-line utilities give you much finer control over things than a generic graphical command ever.

In continuing the Linux/UNIX tradition of "Why more letters than necessary?" the Linux command to copy files and directories is the cp command. To copy one file to another, simply execute the cp command, followed by the existing file and the name that you want to have the copy. For example, to copy a named file.txt to the new file_new.txt, you would execute the command.

```
$ cp file.txt new_file.txt
```

# ## Caution

Be very careful when specifying the name of the file that is the destination of a cp command. If a file with the same name as the file to you are copying exists the cp command overwrites the existing file with the contents of the file you are copying. If you're really paranoid about this, see the section later in this chapter on "Defining and Using Aliases" for information about how to permanently set up a safe version of the cp command. 

By specifying the full pathnames of the source or destination file, the cp command can copy files anywhere in the Linux filesystem where you have permission to create files. For example, to copy the file.txt from my home directory to the new file.txt in the directory /tmp (where everyone can create files), I could execute the following command regardless of the file or directory in which I was currently working:

```
$ cp /home/wvh/file.txt /tmp/newfile.txt
```

You can also use the cp command to copy a file to different directories by specifying the name of a directory as the target of the cp operation. Continuing with the previous example, if I had wanted to copy the file.txt from my home directory to /tmp, but have the copy retain the same name as the original file, I could have done so with the following command:

```
$ cp /home/wvh/file.txt /tmp
```

This would create the file /tmp/file.txt as an exact copy of /home/wvh/file.txt.
