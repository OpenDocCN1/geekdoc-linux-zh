# Searching for Software in Synaptic

One of Synaptic's most powerful capabilities is providing a powerful and usable package search capability that doesn't involve a command line. To locate packages that are relevant to one or more keywords, you can use the "Quick Search" textbox in the main Synaptic dialog to search package descriptions and names, or click the down arrow to the right of the Quick Search area and select the Search button to display a more advanced search dialog that also enables you to specify what package fields to search, as shown in Figure 19-15.
