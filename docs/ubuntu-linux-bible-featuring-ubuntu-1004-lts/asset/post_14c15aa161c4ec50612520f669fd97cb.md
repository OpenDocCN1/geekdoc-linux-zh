
## Chapter 1: The Ubuntu Linux Project

The following lists list the complete Ubuntu-based distributions for desktop users that I am most familiar with, what differentiates them from other flavors of Ubuntu, and where to get them:

- **Edubuntu**: An official edition of Ubuntu that focuses on educational applications and popularizing the use of Linux in schools. Ubuntu uses GNOME as its default desktop environment and provides several different desktop-themes that are designed to be attractive (useful) for users of different age groups. Ubuntu provides an incredibly rich set of educational applications, such as the KDE Edutainment suite (paint, math, and typing applications), GCompris for kindergarten, Ubuntu4Kids and the OpenOffice suite of desktop applications. You can find out more about Edubuntu or download a copy from the Ubuntu web site at www.ubuntu.org. A Live CD version of Edubuntu is available if you want to experiment with it before permanently installing an Ubuntu distribution.

- **Fluxubuntu**: An extremely lightweight Linux distribution that is based on Ubuntu and targets machines with limited amounts of memory, relatively small disks, and so on. It refers to itself as a LPAE (Lightweight, Productive, Efficient) Linux distribution, which is both accurate and a fine addition to your collection of computer-related abbreviations. Fluxubuntu's official memory requirements are less than 64 MB, making it ideal for older or inexpensive machines that you don't want to invest in additional hardware. Fluxubuntu is not limited to low-power hardware—for example, a 64-bit version of Fluxubuntu is available. Fluxubuntu uses Fluxbox as its primary window manager, Gnumeric as its spreadsheet application, and lightweight web applications such as Kakehaaze, Claws (e-mail client, www.claws-mail.org), and Pidgin (instant messaging, discussed later in this book). Any Ubuntu-based distribution, many other packages are available. You can find out more about Fluxubuntu or download a copy from the Fluxubuntu web site.

- **Geubuntu**: Another lightweight Linux distribution that is based on Ubuntu. Unlike Fluxubuntu, Geubuntu uses E17, which is the window manager formerly known as *Enlightenment* (www.enlightenment.org), which now includes various desktop features and the Xcompr compositing manager. Enlightenment has always been known as one of the most attractive and configurable window managers, and this Ubuntu-based distribution is an excellent choice for lower-power machines or on systems for which you prefer to devote as much of your CPU and memory as possible to the processes you're running versus the desktop environment. The founder of Geubuntu is an Italian designer, the aesthetics of Geubuntu are attractive and compelling. Geubuntu is available both as a live/install CD and via a script that enables you to install its packages to an existing Ubuntu installation. For more information about Geubuntu or to download a copy, see the Geubuntu web site at http://geubuntu.linux.com/Home.

- **Gubuntu**: An official edition of Ubuntu that uses completely open source software with no restrictions on or re-distribution. The primary goal of Gobuntu is to provide a powerful and useful Ubuntu-based distribution that adheres to the Free Software Foundation's four freedoms (www.fsf.org/licensing/essays/free-sw.html). Ubuntu therefore does not include any firmware, drivers, applications, or other content for which the complete source code is not available and whose license does not provide the right to use, study, modify, and re-distribute the body of work. Ubuntu is the philosophically pure Ubuntu-based distribution available. However, because of the restrictive licensing terms that are greedily imposed upon device drivers and much audio, video, and other multimedia software, you may find it hard to find Ubuntu on certain hardware or to play certain types of audio or video files on Gobuntu. If this isn't critical to you and you are more philosophically pure than I am, you can find out more about Gobuntu or download a copy from the Ubuntu site at www.ubuntu.com/products/whatubuntu/gobuntu.

- **Kubuntu**: An official edition of Ubuntu that uses the KDE desktop environment instead of GNOME. The KDE desktop environment is a powerful, extremely usable desktop environment for modern UNIX and UNIX-like systems that pre-dates the GNOME desktop and has a large following for good reason. Many people prefer KDE to GNOME, and the discussions/arguments about selecting one desktop interface over the other have consumed just much time and disk space as any other type of religious argument. Kubuntu combines the traditional ease-of-use of KDE with the stability and power of Ubuntu. Old and new Linux distributions such as Arch, Core, Mand Mandrake, OpenSUSE, Sabase, and Xandros use KDE as their default desktop environment. If you are a user of one of these distributions or if you've heard about KDE, Kubuntu may be the distribution for you. For more information about KDE, see the official KDE web site at www.kde.org. A Live CD version of Kubuntu is available if you want to experiment with Kubuntu.

- **Mythuntu**: A version of Ubuntu that is customized for use with the MythTV video recorder software. If you don't have a TiVo, MythTV is an impressive package. See www.mythuntu.org for more information, including supported hardware, download links, and installation instructions.

- **Sabily**: A version of Ubuntu that has been augmented with Islamic software such as Islamical (an Islamic calendar), content-filtering packages (DansGuardian and Tinyproxy, preconfigured to filter many offensive sites), Minibar (an application that identifies daily prayer times), and Zek (a Quran tool). Sabily was previously known as Ubuntu Muslim Edition. By simply addressing some of the requirements, Sabily is available for 32-bit/64-bit systems. For more information about Sabily or to download a copy, see the Sabily web site at www.sabily.org. A Live CD version of Sabily is available if you want to experiment with it before permanently installing an Ubuntu distribution.

- **Ubuntu Studio**: A version of Ubuntu that is customized for creating and editing multimedia. Ubuntu Studio is a relatively young Ubuntu-based distribution that was first available in 2007. If you routinely work with graphics, audio, or video, Ubuntu Studio is well worth a look. It includes applications like GIMP and Inkscape, Ardour for audio recording, Blender for 3D modeling, and Kino for video editing. You can get more information about Ubuntu Studio or download a copy from the Ubuntu web site at www.ubuntu.org.

- **Ubuntu**: An official edition of Ubuntu that uses the Xfce desktop rather than GNOME. Xfce is a much lighter-weight environment than GNOME or KDE that does not spare power or usability. Using Xfce makes Ubuntu a good choice for those on older or less powerful systems where you still want a desktop rather than simply using a window manager. Ubuntu includes applications as Thunderbird (a mail client), the GIMP image editor, the AbiWord processor, the Firefox Web browser, and many popular GNOME applications. For more information about Ubuntu or to download a copy, see the Ubuntu site at www.ubuntu.org. A Live CD version of Ubuntu is available if you want to experiment with it before permanently installing an Ubuntu distribution.

## Note
Canonical's Launchpad web site (http://launchpad.net) provides a Web-based software development, source code control, and build system that has many other Ubuntu-based distributions, such as Ubuntu (with the Enlightenment window manager as its primary GUI, http://launchpad.net/ubuntu), Mint (focused on producing an elegant desktop, http://launchpad.net/11mint), and many more.
