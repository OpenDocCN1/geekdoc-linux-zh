# Chapter 2: Installing Ubuntu

# Caution

If you want to create a bootable USB flash drive manually, the folks at PenDriveLinux.com (www.pendrivellinux.com) have some truly useful tutorials that will walk you through the process of manually creating a bootable Ubuntu system on a USB stick and just anything else that you could conceivably boot from a USB stick. Their tutorials are clearly explained and eminently readable, and also include scripts and configuration files that you can download from their site to make things even easier for you. ■

Flash drives are great—they are fast, far less energy than hard drives, do not generate heat, do not noise, and have no moving parts that can stop when you drop them down a flight of stars. On the down side, they do have one potential limitation that you'll hear people talk about—you can only write to each underlying storage a certain number of times. (Flash storage units are usually referred to cells or address blocks, and are analogous to the sectors of a standard hard drive.) Luckily, most flash drives use a technique known as wear-leveling to evenly distribute writes across the drive so that no single area gets written more frequently than another. The longevity of a modern flash drive is usually predicted to be at least 5 or 10 years. If you're still running Ubuntu off the same drive 5 years now, it might be time to finally consider an upgrade. You are making your "real work" again, right?

# Note

In order to use the bootable USB flash drives discussed in this section, your computer system must be able to boot from a USB device. Most PCs support this, but you should certainly check before bothering to create a bootable USB stick that you can't use. Booting from USB devices is usually a standard BIOS boot option, but some systems also require that you manually enable USB BIOS support before you can boot from a USB device. ■

As mentioned previously, the Ubuntu Desktop provides an easy, graphical mechanism for creating a bootable USB flash drive that works much like the Desktop CD, but also provides persistent storage so that any system settings you configure, applications that you install, and files that you are preserved across reboots. This will allow you to reuse any FAT32 partition that you have on your USB stick, so if you have formatted your USB stick to use another type of filesystem or have created multiple partitions on your USB stick, you may want to see the sidebar on "Reformatting a USB Flash Drive," later in this chapter.

To use this application, do the following after booting from an Ubuntu Desktop CD using the "Try Ubuntu" option:

+   1. Select the System ➜ Startup Disk Creator menu option. A dialog like the one shown in Figure 2-17 displays.
2. Verify that the midpoint for your Ubuntu Desktop CD is listed and highlighted in the Source disk image (iso) or CD area at the top of the dialog. If not, Click Other and browse to the correct location.
