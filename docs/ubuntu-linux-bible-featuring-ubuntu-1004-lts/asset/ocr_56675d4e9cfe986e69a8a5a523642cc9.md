# # Chapter 1: The Ubuntu Linux Project

+   * Ubuntu Studio: A version of Ubuntu that targets creating and editing multimedianUbuntu Studio is a relatively young Ubuntu-based distribution that was first available in 2007. If you routinely work with graphics, audio, or other types of multimedia, Ubuntu Studio is well worth a look. It includes standard graphics applications as GIMP and Inkscape, but also includes Ardour 2, an audio recording and editing application much like ProTools and Blender, for modeling and rendering three-dimensional graphics and animations; PIVITI, Kino, and Cinevideo, for video creation and editing; and I have the graphics skills of a block of wood, and music-wise, used to play the drums, but anyone who interested in using open source software should definitely investigate Ubuntu Studio. You can get more information about Ubuntu Studio or download a copy from the Ubuntu Studio web site at www.ubuntu.org.
* Ubuntu: An official edition of Ubuntu that uses the Xfce desktop rather than GNOME or KDE. Xfce is a much lighter-weight desktop environment than GNOME or KDE that does not spare power or usability. Using Xfce makes Ubuntu a good choice for those on older or less powerful systems where you still want a desktop environment rather than simply using a window manager as provided by Fluxbox. Ubuntu environments support capabilities as drag-and-drop and other forms of application interaction rather than simply managing applications on the desktop—for more information about the differences between window managers and desktop environments, see the "What's a Desktop?" section Ubuntu includes applications as Thunderbird (a lightweight file manager), the GIMP image editor, the AbiWord processor, the Firefox Web browser, and many popular GNOME applications. For more information about Ubuntu or to download a copy, see the Ubuntu site at www.ubuntu.org. A Live CD of Ubuntu is available if you want to experiment with it before permanently installing an Ubuntu distribution.

Note
Canonical's Launchpad web site (http://launchpad.net) provides a Web-based software development, source code control, and build system that has many other Ubuntu-based distributions, such as Ubuntu (with the Enlightenment window manager as its primary GUI, http://launchpad.net/ubuntu), Mint (focused on producing an elegant desktop, http://launchpad.net/11xmint), and many more.

Other Ubuntu-based distributions are available, but not listed here I've never had the chance to experiment with them or they don't be supported by any longer. This list also does not include distributions such as FreSpring (the community version of Linux, www.freespring.org), Linspin (www.linspin.com), MEPIS (www.mepis.org), Savayon (www.savayon.org), and others that are based on the Ubuntu packages but are independent distributions in their own right. I also didn't list "distributions" such as Medibuntu (http://medibuntu.org) that only add specific sets of packages to an existing Ubuntu installation. (Medibuntu adds popular multimedia packages with various licensing encumbrances.) If I missed an installable, ready-to-run, Ubuntu-based distribution that you enjoy, let me know. I'm always happy to learn, too.
