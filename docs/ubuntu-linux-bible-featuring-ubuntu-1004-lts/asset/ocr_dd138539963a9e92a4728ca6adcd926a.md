# Chapter 5: Using the GNOME Desktop

# # GNOME Desktop Overview

Figure 5-1 shows the default GNOME desktop on an Ubuntu Linux system the first time you log in. This figure also displays a single application window as an example—you won't see that unless you explicitly select the Applications Accessories Terminal menu command, but I wanted to be able to explain the window controls that are available in any GNOME application window. The Ubuntu folks have gone through a lot of effort to create an attractive, eye-pleasing background, set of fonts, window decorations, and control buttons for any applications that you start on your Ubuntu system. These window decorations and controls are known as a *theme*, which you can easily customize yourself, as explained later in this chapter.
