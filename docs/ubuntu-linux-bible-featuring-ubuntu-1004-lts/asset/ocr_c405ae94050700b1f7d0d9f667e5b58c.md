# Note

If you have a lot of existing spreadsheets and are wondering how to transfer them to your new Ubuntu system, see Chapter 26, "File Transfer and Sharing," for detailed information on doing that. Dont worry—it really quite easy to use a network connection or even a traditional mechanism such as a floppy drive (if you still have a floppy drive) or a flash drive, or burning a CD.

For example, to open an Excel spreadsheet, simply select the File Open command. By default, the "File Selection" dialog enables you to select files with any extension, including the .xls extension used by Microsoft spreadsheets.

# Supported Import Formats

The same mechanism described in the previous section can be used to open files in any other format supported by Calc. Calc can also open spreadsheets or other data files that have been saved in any of the following formats:

+   - Com-Separated Value (.csv): A standard text-based interchange format, where each row appears on a single line and each field value is separated from the next by a comma.
