# Tip

By default, an xterm starts to copy your login shell, but one of the most common ways of using the xterm application is to automatically start another application in the xterm window using the xterm command's -e (execute) option and specifying the name of the application that you want to start. For example, the following command starts an xterm that is running the ssh command to connect to the system writing.vonhoven.org.

```
$ xterm -e ssh writing.vonhoven.org
```

This command would prompt for a login password and then give me a shell on the specified system. (For more information about connecting to remote systems, see Chapter 25, “Connecting to Other Systems.") Because xterm doesn't feature multiple tabs like the GNOME Terminal application (explained in the previous section), an xterm -e command is one of the most common ways for Ubuntu users to start a separate window that is running another graphical command.

# Moving Around in the Linux Filesystem

Just as you do when you use a graphical user interface, you will want to organize your files and directories in some logical fashion if you're working from the command line. Once you've organized things that way, you'll need to use the cd ("change directory") command, which does exactly what you'd expect. In hard-core Linux terms, the cd command changes your working directory to be the directory that you supply as an argument. For example, to change your directory into a directory named test, you'd simply execute the following command:

```
$ cd test
```

**Tip**
If you're hanging around hard-core Linux folks and want to fit in, refer to changing to another directory as cd'ing here. ■

If you don't know the name of the directory where you are currently working, use the pwd command. The pwd command displays the absolute path of your current directory. To return to your home directory, simply type cd without any arguments:

```bash
$ cd
```

To move up one level in the directory hierarchy, use the following command:

```bash
$ cd ..
```

To move up multiple levels, you can chain the double-dots:

```bash
$ cd ../..
```

The cd command can also be used to jump directly to a specific directory by providing its path:

```bash
$ cd /var/log
```

# Copying, Moving, and Deleting Files

Copying, moving, and deleting files are some of the most common actions that any user performs. In Linux, these tasks are handled by the cp, mv, and rm commands, respectively.

## Copying

The cp command is used to copy files and directories. The basic syntax is:

`cp [options] [source] [destination]`

To copy a single file to another name in the same directory, use:

```bash
$ cp file.txt file2.txt
```

To copy a file to a different directory, specify the path to the destination:

```bash
$ cp file.txt /path/to/destination/
```

To copy a directory, you must use the -r (recursive) option, which copies all files and subdirectories within:

```bash
$ cp -r directory1 directory2
```

## Moving and Renaming

The mv command is used to both move and rename files and directories. The syntax is:

`mv [options] [source] [destination]`

To rename a file, specify the current name and the new name:

```bash
$ mv oldname.txt newname.txt
```

To move a file to a different directory:

```bash
$ mv file.txt /path/to/destination/
```

## Deleting

The rm command is used to delete files and directories. **Be careful: files deleted with rm are permanent and there is no trash bin.**

The syntax is:

`rm [options] [file]`

To delete a single file:

```bash
$ rm file.txt
```

To delete an empty directory, use the rmdir command:

```bash
$ rmdir dirname
```

To delete a directory and all its contents, use the -r (recursive) option:

```bash
$ rm -r directoryname
```
