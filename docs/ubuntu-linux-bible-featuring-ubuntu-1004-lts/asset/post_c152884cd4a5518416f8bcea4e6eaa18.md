## Tip

Totem is still actively under development, and some versions have problems opening prerecorded DVDs when using the menus. If Totem has problems not being able to load the codes required to play a DVD in response to the Movie ⟳ DVD command, exit Totem, eject the DVD, and let GNOME start Totem correctly for you to reinvent the DVD. If you still have problems playing DVDs with Totem, use one of the other DVD/Video players for Linux. VLC (VideoLAN Client, installable through the vlc package) and Xine (best installed through the xine-utils package) are both excellent DVD/Video players that provide their own frameworks.

## Ripping Audio CDs

Ripping is the term used to describe the process of extracting the contents of audio CDs and converting them into audio files that you can play in other applications. It is not necessary to rip a video DVD, because it contains files in a certain order in certain directories, which you can copy from the command line or from any file manager. Audio CDs are different—they are constructed in a specific format and contain huge audio data in raw format.

The traditional UNIX philosophy has always been: "Write small applications that do one thing and do it well." That's a great philosophy for which you can string series of applications to do the same thing. That philosophy is not applicable or relevant for graphical applications that are designed for desktop use, which are somewhat self-contained by nature. Instead, graphical desktop applications are good examples of the philosophy of convergence, where single applications continue to gain related capabilities. As they grow, these convergent applications can overshadow graphical applications by making it easier for users to perform a variety of tasks within a single familiar application, set of menus, and so on. Convergence also makes life easier for the maintainers of a Linux distribution, on installing and maintaining a single application where two or more might have been required before.

## Ripping Audio CDs Using Rhythmbox

Ripping CDs in Rhythmbox is almost exactly like playing them (as shown in Figure 16-10), with the exception that you click the Copy tracks to the library button rather than the Play button to start the process. While Rhythmbox is extracting the contents of an audio CD and converting each track to a file, it displays progress information in the lower-left corner of the Rhythmbox dialog.

Before ripping a CD, you may want to specify the format of the audio files that Rhythmbox creates, the location in which it creates them, and so on. This is done through Rhythmbox's Preferences dialog. To display this dialog, select the Edit -> Preferences menu command. To specify the location to which the audio files that you extract will be saved and the format in which they will be saved, click the Music tab, which is shown in Figure 16-12.

This dialog enables you to change the following settings:

- Library Location: Enables you to select the folder in which your extracted audio is automatically created for this purpose to be stored. Although each user's home directory, I intend to create a publicly writable directory called /home/music on my systems to make it easier for multiple users to access a music collection. This also simplifies backups of all the CDs that all users of your system have extracted. If you want to be clever, you can either mount a shared network directory as /home/music using NFS or share a local /home/music directory via Samba so that users of all systems on your network have access to your music. Ask your users not to copy music from this directory, lest the RIAA sue you for a few million per song.

- Library Structure: Enables you to specify how the audio files that you extract from CDs will be organized in your music library. This section provides the following settings:
    - Folder Hierarchy: Enables you to specify the folder hierarchy in which Sound Juicer creates the audio files that it extracts. By default, the tracks of each CD are written in a folder with the name of the CD, which is itself a subdirectory of a folder with the artist's name.
    - File Name: Enables to specify the format for the filename for each audio track. The default value, "Number - Title," is a good setting to use, because this makes it easy for you to create playlists that follow the original track order of your CDs.
    - Preferred Format: Enables you to specify the format in which extracted audio files are written. Your choices are "CD Quality, Lossless" (using the FLAC codec), "CD Quality, Lossless" (using the Ogg container and Vorbis codec), "Voice, Lossless" (using the standard WAV file format), and "Voice, Lossy" (using the MP3 codec).

## Ripping Audio CDs Using k3b

k3b is a KDE application that is simply great at doing most things with CDs and DVDs. I always install it on desktop systems, even doing so requires that KDE basics and associated infrastructure are also installed. To install k3b and the underlying packages that it requires, use your favorite Package Management software to install the k3b package. k3b first tries to look up your CD in the freedb.org database. If more than one CD matches your CD or if there is no match, you will see a dialog asking you to select the appropriate entry. k3b will be populated and display the track listing based on your selection. If your CD can't be found in the database, k3b will use a generic name format such as Track 01, 02, and so on.

At this point, k3b screen will look like the screen shown in Figure 16-13. (The track listing will be different unless you own a fairly obscure CD by the French band "Heldon.")

To proceed, click the "Start Ripping" button below the title of the CD. k3b displays a dialog that enables you to specify the format in which you want to save the extracted files and the directory to which you want to save them, as shown in Figure 16-14.

The audio file formats available through this dialog are Wave (raw, lossless PCM audio), MP3, and Ogg Vorbis. You can only save audio files in MP3 format if you have previously installed the lame (LAME Ain't an MP3 Encoder) package — the MP3 option is only displayed in the list of formats if this package has already been installed.

Sadly, MP3 is probably the best format if you want to be able to clone your music to your iPod or other portable music player, play your audio files from computers running other operating systems, and so on.
