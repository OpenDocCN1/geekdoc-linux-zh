# Chapter 21: Network Configuration and Security

Whether modern Linux systems, firewalling is typically done by kernel modules that support a packet-filtering framework known as Netfilter, and an associated interface and user-space command known as iptables. *Packet filtering* refers to the ability to analyze network packets and perform various actions based on their source, destination, type, or other information they contain. Because support for packet filtering is built into the Linux kernel, a Linux system that is directly connected to the Internet serves as its firewall, monitoring and managing network traffic before it actually gets to any daemons or network-aware processes that it is running. Of course, a dedicated device or Linux system can serve as a firewall, and many vendors sell packaged solutions to do that. The fact that many of these off-the-shelf systems run Linux and use the Netfilter/iptables mechanism to implement their firewalling solutions is just proof of the power of the Linux kernel's built-in support for packet filtering.

Whether or not Linux system actually requires a firewall is a hot debate among Linux fans. Standard Ubuntu Desktop installations do not expose any open ports to an outside network, so there are no network ports that need to be protected. This is not true, of course, for Ubuntu systems that expose ports for services such as DNS, email, SSH, a Web server, and so on, so a firewall is good idea for any user system.

# Tip

If you are using your Ubuntu system in an environment that is already protected by a firewall, you probably do not need to set up a firewall on your system. You should, make sure that the firewall that your system is located behind is actually doing the thing by checking with the manufacturer, your IT group in a business or academic environment, or your Internet service provider. Just because a box has Firewall printed on it doesn't mean that it is anything anything.

As far as Ubuntu systems goes, you will find yourself opening up some ports on a desktop installation as you use your system over time, and Netfilter/iptables firewalls introduce little overhead on a desktop system, I suggest that you always install at least a simple firewall. This way, if you subsequently increase the exposure of your system by opening ports, the firewall will be in place. You may want to revisit your initial firewall implementation in the future, but yet if you have at least some protection even if you neglect firewalling in your excitement to make some new service available from your Ubuntu system. Installing a simple firewall by default is also a good idea if you are setting up systems for friends, relatives, or small businesses, where you may not always have complete control over what they add or activate on system.

# Overview of Linux Firewalling and Packet Filtering

The packet-filtering mechanism used by the current Linux kernel (2.6.xx) is a combination of a loadable kernel module framework and API called Netfilter, and an interface and associated user-administrative command called iptables. The iptables interface is one of several kernel modules based on the Netfilter framework; others include a module that handles Network Address Translation (which enables multiple machines to share one public IP address) and the module that implements and supports connection tracking.
