# Starting Evolution

You can start Evolution in a variety of different ways:

+   - Select the envelope icon in the GNOME toolbar at the top of the screen (shown in Figure 7-1) and Select Mail from the drop-down menu. This is the earliest and most common way to start Evolution.
- Select "Evolution Mail and Calendar" from the Applications Office menu.
- Type the evolution command in a GNOME Terminal or xterm window, and press Return.
