## Cutting, Copying, and Pasting in vi

It's easy enough to cut-and-paste text using a graphical text editor because a mouse-aware editor enables you to copy and cut text with a combination of the mouse and special keyboard commands. You can, of course, do the same thing in vi, but it requires a bit more knowledge of vi internals and visualization.

Cutting text is done using the delete command (explained in the previous section), which actually just puts the text in an internal storage area (known as a *buffer*) from which you can subsequently paste it back in. However, the vi editor also has the y (yank) command to copy a specified region to a buffer so you can subsequently paste it somewhere else. As with the delete command, you can delimit the area that you want to copy by following the y command with a cursor movement command. For example, `ys$` copies the text from the current cursor position to the end of the line into the buffer, or `y` if you copy anything more than a single line; the number of lines yanked into the buffer is displayed at the bottom of your window. Of course, cutting or copying text isn't all that interesting unless you paste it back in somewhere, where vi provides the p and P commands. To paste a single line from the buffer back into your text at the current cursor position, use the p command. However, if you have copied multiple lines into the buffer, you should precede the p command with the number of lines that you want to paste back in. If you didn't have to notice how many lines you yanked and simply want to paste all of the text that you recently copied to the buffer, you can simply use the P command to paste it all back in at once.

## Searching for and Replacing Text in vi

The vi editor provides separate commands for searching forward and backward in your file. Pressing the / command, followed by the case-sensitive sequence of characters that you want to search for, and pressing Return causes vi to search forward in the current file and if it locates a matching sequence of characters. Figure 12-3 shows vi running in a GNOME Terminal window, getting ready to search for the string Windows in the text. If the string is found, vi moves the cursor forward in the file to display the line of text containing the match. If no matching string is found in the text, vi displays a status message at the bottom.

## Undoing in vi

Unless you're a much better writer than I, and therefore you'll eventually find yourself making several changes to a file, vi remembers all of the commands you executed in your current session and enables you to undo to return the file to the state in which you wish you left it.

## Using Multiple Windows in vi

One of the longest-running complaints about vi is that it doesn't support multiple windows. In terminal-oriented applications like vi, multiple windows are just views onto multiple files at the same time, each having its own status. Luckily, the vim folks solved this by implementing several commands that enable you to split the window, open another file in any part of your window, cycle between multiple files displayed in different windows, and so on.
