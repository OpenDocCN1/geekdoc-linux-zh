# # Chapter 1: The Ubuntu Linux Project

Internationalization is the term for producing software that is capable of displaying all prompts, dialogs, system messages and so on, in any user's native language and any specific character set used with that language. The term internationalization is such a mouthful that it is frequently referred to as i18n because the word internationalization consists of the letter i followed by 18 letters and an n. The two aspects of i18n translation, ensuring that versions of the operating system and application messages are available in other languages; and localization, which ensures that messages and text can be displayed in a language's native character(set). Amusingly, localization is often referred to as l10n.

Linux and its applications have been focused on i18n for years, which initiatives such as the Linux Internationalization Initiative (www.i18n.net/, known as Li18n) and the Free Standards Groups' Open Internationalization Initiative (www.open18n.org/) initiatives focus on ensuring that open source applications take i18n into account when developing, maintaining, and enhancing code. Many of the structural enhancements to the last few releases of desktop environments like GNOME and KDE have been related to making sure that these environments and their applications support different language and character sets.

The key to successful internationalization is two-fold — not only do applications and graphical environments need to support multiple languages and character sets, but also the translations of prompts, dialogs, and system messages have to be available. Ubuntu's focus on a truly usable Linux distribution for an international audience has helped it become a home for translation and localization work in Linux (www.ubuntu.org/community/participatei10n) and GNOME (its primary graphical environment) — more than later through an online translation system known as Rosetta (https://launchpad.net/rosetta), documentation efforts, active mailing lists, and others.

# Tip

For additional information about Linux internationalization, see additional web resources through a simple web search for "Linux internationalization", which will turn up great documents like the Linux Internationalization HOWTO, available online at sites such as http://folk.no.net/davidjo/i18n.p.

Although many of the structural enhancements to the last few releases of desktop environments like GNOME and KDE have been related to internationalization, a great deal of work has also been done to make Linux environments easier to use by people with disabilities. Ensuring that graphical applications provide keyboard or gesture shortcuts for all menu commands and dialog interaction is a growing focus for GNOME, KDE, and graphical application development. Ubuntu's emphasis on usability is a boon to all computer users, regardless of whether or not they have a physical disability.
