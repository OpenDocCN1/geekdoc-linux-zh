Configuring printer settings

![](bbox=[0.081, 0.493, 0.428, 0.693])

To enable other hosts to see the printers that are exported by this print server, click the “Publish shared printers connected to this system” checkbox. To enable other hosts to actually print to these printers, select the “Allow printing from the Internet” checkbox that is available once you activate the “Publish shared printers...” checkbox.

To enable this system to see printers that are shared by other print servers on your network, click the “Show printers shared by other systems” checkbox. You will certainly want to do this if you are sharing printers that are directly connected to any Microsoft Windows or Mac OS X systems that are also on your network.
