# Setting Up an FTP Server

Many FTP servers are available in the Ubuntu repositories: ftppd, inetutils-ftppd, krbs-ftpd, middleftpd, proftpd, pure-ftpd, twoftpd, vsftpd, wu-ftpd, and zsftpd. The FTP protocol has been around for a long time, and many people have had to develop FTP servers! I'm not going to compare and contrast each of them, since they all have their own feature sets and clubs, and frankly, I don't think many people will care. Of these, my favorite is Pure-FTPD, which is available as the pure-ftpd package in the Ubuntu repositories. Why? It's easy to install, lightweight, trivial to configure, secure, fully internationalized, and runs in several modes, depending on the kind of FTP server that you want to run.
