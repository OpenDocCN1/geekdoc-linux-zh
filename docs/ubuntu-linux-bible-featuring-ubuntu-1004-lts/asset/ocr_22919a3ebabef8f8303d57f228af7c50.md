# Importing Thunderbird Mail into Evolution

Letting Thunderbird convert your existing Outlook/Outlook Express e-mail (as described in the section, "Migrating Mail via Thunderbird") is an excellent step for importing your Windows mail into Evolution, the GNOME PIM and mail client used by the Ubuntu desktop distribution. Both Thunderbird and Evolution store the mail for a filer in the universal mbox (mbox box) format. This makes it extremely easy to import mail from Thunderbird into Evolution.

Evolution provides an Import Wizard that imports all mail from older Linux mailers (Netscape Navigator, etc.), and also lets you import single files in formats such as Berkeley Mailbox (mbox), Evolution CSV or Tab (.csv or .tab), Mozilla CSV or Tab (.csv or .tab), Outlook CSV or Tab (.csv or .tab), VCard (vcf or .vcfd), LDAP Data Interchange Format (.ldif), vCalendar (.vcf), and iCalendar (.icf). Using Evolution's Import Wizard to import single files is discussed later in this section, and makes sense if you are importing one or two files. However, single-file import can be tedious and time-consuming if you have a large number of mailboxes that you want to import. In the latter case, you can use the import_thunderbird_mail.sh script which was discussed in the previous section to import all of your mailboxes into Evolution, adding an -imported suffix to each of their names so that you can identify the imported mailboxes.

To run this script and import mailboxes that you created by importing your Outlook/Outlook Express mail into Thunderbird on a Windows system, first change directory to the C: or network location to which you backed up the C:\Documents and Settings\USERNAME\AppData\Roaming\ThunderbirdProfiles directory. Your Thunderbird mail is actually stored in a subdirectory of that directory, with a name like xxxxxxx.default/Local Folders, where xxxxxxx is a random string that was generated when you first started Thunderbird. This directory contains files that contain your mail and auxiliary files and directories used to store Thunderbird configuration information. Change directory to the xxxxxxx.default/Local Folders directory and run the import_thunderbird_mail.sh script with the -e argument to state that you are migrating into Evolution.

The command to run this script and out its execution is as follows:

```
$ import_thunderbird_mail.sh -e
Copying ./Personal Folders.sbd/Inbox to Inbox-imported
Copying ./Personal Folders.sbd/Personal to Personal-imported
Copying ./Personal Folders.sbd/Writing to Writing-imported
```
