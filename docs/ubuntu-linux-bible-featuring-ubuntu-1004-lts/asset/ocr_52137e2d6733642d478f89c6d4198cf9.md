+   - Ubuntu: An official edition of Ubuntu that uses the KDE desktop environment instead of GNOME. The KDE desktop environment is a powerful, extremely usable desktop environment for modern UNIX and UNIX-like systems that pre-dates the GNOME desktop and has a large following for good reason. Many people prefer KDE to GNOME, and the discussions/arguments about selecting one desktop interface over the other have consumed just much time and disk space as any other type of religious argument. Kubuntu combines the traditional ease-of-use of KDE with the stability and power of Ubuntu. Old and new Linux distributions such as Arch, Core, Mand Mandrake, OpenSUSE, Sabase, and Xandros use KDE as their default desktop environment. If you are a user of one of these distributions or if you've heard about KDE, Kubuntu may be the distribution for you. For more information about KDE, see the official KDE web site at www.kde.org. A Live CD version of Kubuntu is available if you want to experiment with Kubuntu.

+   - Mythuntu: A version of Ubuntu that is customized for use with the MythTV video recorder software. If you don't have a TiVo, MythTV is an impressive package. See www.mythuntu.org for more information, including supported hardware, download links, and installation instructions.

+   - Sabily: A version of Ubuntu that has been augmented with Islamic software such as Islamical (an Islamic calendar), content-filtering packages (DansGuardian and Tinyproxy, preconfigured to filter many offensive sites), Minibar (an application that identifies daily prayer times), and Zek (a Quran tool). Sabily was previously known as Ubuntu Muslim Edition. By simply addressing some of the requirements of Muslim computer users, this distribution also demonstrates the tremendous range of available software for Linux and how easy it is to customize Ubuntu to address the requirements of a specific audience. This distribution is currently available only for the 32-bit x86 systems. The Islamic software packages can be installed on any existing Ubuntu distribution by downloading and executing a script that installs them on your current system. For more information about Sabily or to download a copy, see its web site at www.sabily.org. A Live CD version of Sabily is available if you want to experiment with it before permanently installing an Ubuntu distribution.
