# Exporting Safari Bookmarks

Strangely enough, the Safari browser that Apple provides for Mac OS X systems does not automatically the ability to save its bookmarks to an HTML. The good news is that Simoneanganelli has written an excellent (and free) application called the Safari Bookmark Exporter (http://homepage.mac.com/simx/sbe.html) that does just. After downloading the disk image for this application, you can either install it or run it directly from the image. A dialog like the one shown in Figure 9-15 (captured on a Mac OS X system) displays.

If Safari is currently running on your OS X system, click the "Don't want about active browsers" button. Next, select an output target by clicking one of the browser/file format names below the Analyze Bookmarks button—selection primarily determines where the Safari Bookmark Exporter will try to save the file containing your bookmarks. I typically select Firefox/Firebird/Phoenix in this case option not anything for Firefox, although Simple HTML is also a reasonable choice. Click "Export Bookmarks" to display a Filter dialog that enables you to identify where you want to save your bookmarks. If you have selected Firefox/Firebird/Phoenix as your browser, the suggested location will be to save the output file of your Firefox profile directory, which you may not want to do because it will overwrite any file of the same name. I typically save these files to my home directory with a name like safari-bookmarks-export.html, which makes it pretty clear what the file contains.
