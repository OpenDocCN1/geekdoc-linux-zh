# Chapter 7: Managing E-Mail and Personal Information with Evolution

Note being able to access a webmail account via POP does not enable you to send mail through that account. As mentioned several times in this chapter, retrieving incoming mail is done via protocols such as POP and IMAP, while outgoing mail is sent using a remote mail server that you communicate with using SMTP or by contacting a local mail server via a UNIX/Linux Sendmail interface. You have a few choices for sending mail using your webmail account:

+   - Continue to use the webmail interface to send mail for this account (which is something of a pain).
- Send mail for your webmail account using an existing SMTP server to which you already have access.
- Follow the instructions provided in Chapter 30 on how to install, configure, and run your own mail server. It's really not that hard, and think how powerful you'll feel!

The next two sections explain how to use FreePOPs and how to configure your mail client to access a free webmail account through it.

# Installing and Using FreePOPs!

The FreePOPs! package is available in Ubuntu's repository as the package freepops and can easily be installed using your favorite package management tools, as explained in Chapter 19. You should probably also install the freepops-doc package, which will install the FreePOPs! documentation into /usr/share/doc/freepops-doc — you cannot lose by having all of the documentation for a package.

Once you've installed the freepops package, the FreePOPs! startup file is installed as /etc/init.d/freepops. The FreePOPs! server is not started by default. For testing purposes, you can start it manually by executing a command such as sudo /etc/init.d/freepops restart (I use restart than start just in case it is already running for some reason.) You then add this startup script into your system's process tracking, typically by creating a symbolic link to the FreePOPs! startup file in the /etc/rc.2 directory to run under runlevel 2, which is the default runlevel for Ubuntu systems. You should also create an equivalent link when shutting down your system. These commands look like the:

```
sudo ln -s /etc/init.d/freepops /etc/rc.2/S999freepops
sudo ln -s /etc/init.d/freepops /etc/rc.2/K99freepops
```

After you've run the FreePOPs! startup script, the FreePOPs! daemon will be running on your system, which you should be able to see in a process listing. Now you are ready to configure your e-mail account so that you can read your webmail via POP, as described in the next section.
