## Other Text Editors for Linux Systems

Several other editors are available for Ubuntu systems. By default, the following other editors are installed as part of a standard Ubuntu installation:

- ed: A simple, line-oriented editor inspired by the original UNIX editor. Be careful when you start this, it doesn't actually display a prompt. (The command to exit is the letter q)

- nano: An enhanced clone of pico that is available under the GPL (unlike pico). ### Using Markup Languages

Long ago, when people just used terminals, "word processing" meant creating documents in text files and embedding special commands to tell them how to format. The format in which these documents were created is known as a markup language, of which the most common example is HTML. Markup languages are still popular in academic and publishing circles because many institutions and journals use text files in markup language for submissions.

### Using TeX and LaTeX

**TeX (pronounced tech)** is a typesetting program and associated markup language that is designed to produce extremely high-quality output, especially for scientific and mathematical notation. The eminent scientist Donald Knuth wrote TeX in 1977, largely because he needed TeX for producing the first three volumes of *Art of Computer Programming* series.

Many implementations of TeX are available today, all based on Knuth's original version, converted into other languages, and all enhanced with the addition of extra capabilities. The source code for TeX is freely available, but in order for anything based on TeX source to call itself, it must pass a TeX formatting system known as TRIP. The TeX provided in the Ubuntu repository (as most Linux systems nowadays) is TeX Live, a complete text distribution for UNIX-like and Windows systems that is collaboratively developed by a number of TeX user groups. The home page for TeX Live is *www.tug/texlive.*

Because it isn't, it's not installed on Ubuntu Linux systems. The Ubuntu repositories provide a huge number of TeX-related files, but the only one that you need to install is the texlive package, which depends on many others and guarantees that you'll get everything you need for a usable TeX formatting environment. You may also need to install the appropriate texlive doc package for your native language, which, for English speakers like me, would be the package texlive-doc-en. The doc packages provide FAQs, tutorials, and many other documents about the TeX system.

TeX markup is quite primitive, simple, requiring many low-level commands to do basic text formatting. To simplify creating documents using TeX, a variety of macro packages have been developed, the best known of which is Leslie Lamport's LaTeX macro package. These macro packages support different types of documents, such as articles, manuals, letters, and so on, and provide easy-to-remember macros for the traditional components of those documents.
