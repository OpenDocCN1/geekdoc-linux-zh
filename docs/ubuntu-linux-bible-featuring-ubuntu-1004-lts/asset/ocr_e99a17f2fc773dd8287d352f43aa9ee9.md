# Chapter 22: Going Wireless

If no Linux driver is available for your wireless card, all is not lost. Thanks to the cleverness of the folks in the open source community, a Linux kernel module and related utilities, called ndwrapper, enables you to use the Microsoft Windows drivers for much of the network hardware that is not natively supported by Linux. Installing these utilities, installing Windows drivers under Linux, and configuring your system to automatically start the kernel module is discussed later in this section.

Using systems that have both wired and wireless interfaces is quite common nowadays. Even though specifications such as 802.11g and 802.11n provide high communication speeds, they can't match the speed of the high-wired connections such as Gigabit Ethernet connections. It's, therefore, a shame not to use your system's wired connection whenever possible. However, it's tough to travel and get work done while dragging hundreds of miles of Ethernet cable—the convenience and flexibility of wireless access far outweigh the slower performance that it provides. The Network Manager and the Ubuntu applet configuring make it relatively easy to use a wireless network interface from a variety of locations, and are discussed in detail in Chapter 21. However, we about here, there are other alternatives. One extremely impressive alternative to the Network Manager is the wic package, which is discussed in the next section.

# Using Wicd

Wicd is an alternate Network Manager for Linux systems that makes it easy to establish connections to wired and wireless networks. Wicd is easier to use and is frequently more successful at establishing connections to secure networks than the traditional Linux Network Manager. The Network Manager is a fine piece of software that usually works—however, when it doesn't, it is a total PITA (I'm not referring to the popular Eastern branch). As a replacement for the Network Manager and related apps, Wicd conflicts with the Network Manager, and only one of these connection management packages can be installed on a system at a time. Luckily, as discussed in the next section, installing Wicd on a system where the Network Manager is installed will automatically purge the Network Manager for you. No fuss, no muss.

The next sections explain how to install, use, and configure Wicd to meet your needs. It's really a great application, which I use on all of my laptop systems (and any desktops with wired and wireless network interfaces) rather than the Network Manager.

# Installing Wicd

Ubuntu systems are currently committed to the Network Manager and related applets, so in order to install Wicd, you will first have to modify the list of sources that provide repositories from which your Ubuntu systems can install software. You can do this using Ubuntu's Software Sources application, or by directly modifying your /etc/apt/sources.list file. You will need to add the following entry in any of these locations:

```
deb http://apt.wicd.net lucid extras
```
