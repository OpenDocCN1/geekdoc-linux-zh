+   - apt-get: A command-line utility that provides subcommands, which enable you to install, remove, and manage packages on your system, both as individual packages and as components of a distribution

The aptitude utility provides both quasi-graphical, menu-screen oriented interface and the ability to install, remove, query, and manage packages from the command line. This is my preferred Package Management utility for all day-to-day package operations
- dpkg: The basic command-line tool for installing, removing, querying, and generally managing packages. This utility uses even lower-level utilities, such as dpkg-deb to perform package installation, removal, and manipulation—and dpkg-query, for packages, but these lower-level packages are not discussed in this chapter. Although you need to use 0.0001 percent of the time, the rest of the time I find more convenient to think of the capabilities provided by these low-level utilities as functionality that is provided by the dpkg utility itself
- dselect: A terminal-front-end to the dpkg utility that provides graphical menus and an interactive display within the context of xterm, GNOME Terminal, or other command-line environment. The dselect utility also accepts command-line options and arguments that you can use to initiate operations out selecting them from menus. This application is not discussed in this chapter because its functionality is available in other tools
- software-center: Discussed earlier in this chapter, this is a graphical application that is started when you select Ubuntu Software Center from the Applications menu on Ubuntu system.
- synaptic: A graphical, X Window System tool for installing, removing, querying, and managing packages on Ubuntu
- update-manager: A graphical, X Window System tool for identifying and installing updated versions of packages that are already installed on your Ubuntu Linux system

# Note

The dpkg, apt-get, and aptitude utilities use all different databases to store information about installed packages and their state, and therefore use all different mechanisms for identifying and resolving conflicts and dependencies between software packages. (The Synaptic and Adept utilities use the same database as the aptitude utility). The dpkg utility stores its information about installed and available packages in files and directories under /var/lib/dpkg. The apt-get utility stores the information that it uses in files and directories under the directory /var/lib/apt. The aptitude utility stores the information that it uses in files and directories under the directory /var/lib/apt. When using either apt-get or aptitude, it is important that you run either the apt-get update or aptitude update commands in order to ensure that the package state and availability information used by these applications are up-to-date.
