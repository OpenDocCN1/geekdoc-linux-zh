# Chapter 24: Using Virtual Machines and Emulators

Because you are creating a virtual machine, you will probably want to create a new virtual hard disk for its use. A virtual disk is a file on some storage device that the host system (the one on which you're running VirtualBox) can access. By default, new virtual disks are created in the ~/VirtualBox/VDI directory, located in your home directory, and have the file extension .vmi.

Click Next to begin the Create New Virtual Disk Wizard, which makes it easy to create a new virtual disk. The Virtual Disk Wizard's Welcome screen displays, as shown in Figure 24-7.
