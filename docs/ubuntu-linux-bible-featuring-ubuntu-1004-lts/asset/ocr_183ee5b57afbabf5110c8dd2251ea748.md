The first thing I want to change is here line 2, which sends any mail directed to the Webmaster for this site to webmaster@localhost, which probably doesn't exist on your machine. You can either set up a local alias for Webmaster in your mail server configuration (Chapter 30, "Setting Up a Mail Server," for more information) or simply change this to an explicit site-wide address that you've already assigned somewhere. I would change this to webmaster@vonhagen.org.
