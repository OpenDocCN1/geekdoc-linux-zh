
## Part I: Getting Started with Ubuntu

## Netbook/MID Users

Netbooks areably the hottest computing platforms around, offering an impressive combination of low cost, sufficient power to be usable, and network-readiness. A similar platform is growing in popularity and availability is mobile Internet device (MID) systems, which are wireless, handheld devices that typically feature a touchscreen rather than a keyboard. Several Ubuntu-based distributions targeting these types of systems are all, optimized for their smaller screens, network orientation, and audio/video capabilities:

- * *EasyPeasy*: An Ubuntu-based distribution that now supports a wide range of netbooks. See www.geteasyasy.com for more information, including links to download and install instructions.

- * *Kubuntu Netbook Edition*: A Ubuntu-based distribution that brings the power of the latest KDE 4 desktop to the netbook platform. See https://wiki.ubuntu.org/Kubuntu/Netbook for more information, including links to download and install instructions.

- * *Ubuntu Mobile Internet Device (MID) Edition*: An Ubuntu-based distribution that was originally developed by Canonical in partnership with Intel, Ubuntu Mobile seems to have largely faded on Intel MIDs in favor of the Moblin Project (www.moblin.org), a Linux Foundation Project that is now working directly with Intel. See www.ubuntu.com/products/mobile for more information about Ubuntu Mobile. Canonical's MID focus has shifted lightly to Ubuntu Remix for Intel-based netbooks and MIDs and Ubuntu Desktop Edition for ARM (www.ubuntu.com/products/whatis/ubuntu) for netbooks and MIDs that use ARM processors (www.arm.com).

- * *Ubuntu Netbook Remix (UNR)*: An official edition of Ubuntu from Canonical that provides a customized user interface that is optimized for the smaller screens of netbooks, MIDs, UNR is my favorite netbook-oriented, Ubuntu-based distribution. See www.canonical.com/projects/ubuntu/unr for more information, including links to download and install instructions.

Portable, network-aware, and small-footprint systems are still increasing in popularity, and I'm sure that many other Ubuntu-based distributions will emerge for these types of systems.

## Server Users

While it is possible to run server applications as mail systems, Web servers, DNS servers, print servers, and file servers on a desktop Linux system, this is often the wrong thing to do in enterprise or academic environments. Many servers are lean and mean, command-oriented machines that devote all available cycles to the server processes they are running, rather than “wasting” them by running a GUI (at least by default). Canonical offers the Ubuntu Server Edition, a version of Ubuntu that brings the power, stability, and easy management of Ubuntu Linux to the server room. By default, Ubuntu Server provides a basic, secure system with no open network ports, but you can install other fundamental configurations such as a LAMP (Linux, Apache, MySQL, and Perl) in system which this key server components are preconfigured to work together, minimizing your installation and administrative efforts. The Server Edition also provides out-of-the-box support for LTSP (Linux Terminal Server Project), which supports thin clients and enables one server system to satisfy the storage and application requirements of many lightweight desktop systems. Ubuntu Server Edition does not install a graphical user interface by default, but the standard GNOME desktop (or the X Window system manager of your choice) is available as a package that can be manually installed. For more information about the Ubuntu Server Edition or to download a copy, see www.ubuntu.com/products/whatubuntu/serveredition.

Canonical formerly offered a version of Ubuntu Server Edition, known as JeOS, that inserted to run virtual machines, as appliances. JeOS stands for "Just Enough Operating System," meaning that JeOS is optimized for a small disk and minimal footprint and minimal resource consumption, leaving as much of your server hardware as possible available for virtual machines. JeOS is now an optimized kernel that is bundled with the Ubuntu Server Edition distributions. For more information about JeOS, see www.ubuntu.com/products/whatubuntu/serveredition/jeos. For more information about virtualization on Ubuntu, see Chapter 24.

## Installation Requirements

As Linux distributions have moved to the 2.6 kernel and Linux is becoming more and more popular, the chances of your having hardware that is not supported by Ubuntu grow less and less. This section outlines the types of systems on which Ubuntu is supported and the general hardware requirements for a usable system.

## Note

One of the best things about Linux is the wide range of system types upon which it is supported. Most Linux distributions, Ubuntu, will run on older systems that would otherwise be discarded or used as doormats. When running on older systems, you will probably want to use the command-line interface or a lighter- environment. I use a system with exactly these characteristics for testing purposes (an old IBM ThinkPad 380XD I just can't bear to part with), and GNOME is excruciating on that. If you really need to run Ubuntu on such a system, see the note earlier in this section about alternate graphical environments for low-speed and low-memory systems.

## Supported Systems Type

Ubuntu is supported on any of the following:

- i386 or compatible processors from Intel, AMD
- ARM-based systems. ARM are low-power, high-performance CPUs that are very popular in embedded systems, including netbooks from various vendors. See www.ubuntu.com/products/whatubuntu/arm for detailed information about ARM.
- 64-bit AMD, Intel 64 processors (which include Athlon 64, Opteron, and Xeon)

## Note

Ubuntu was officially supported by Canonical on PowerPC (PPC) processors, such as those used on Macintosh computer systems, with the Ubuntu 6.10 through 7.10 distributions. This means the PPC and UltraSPARC versions of Ubuntu became community-supported distributions. This means Canonical may still produce some problems and versions of Ubuntu may not be available from all Ubuntu download sites. See the Ubuntu PowerPC FAQ at https://wiki.ubuntu.com/PowerPCFAQ for more information about the PPC.

## Hardware Requirements

With any computer software, you will have a better experience if you install and use Ubuntu on the most powerful system that you have, but Ubuntu will technically still run (slowly) on your 25 MHz i386. However, the American national slogan is eminently true here: "More is better." Taking off my linux favorit for a moment, you shouldn't really bother trying to install and run Ubuntu on a system that runs slower than 166 MHz or has less than 96 MB of memory.

The minimum hardware requirements for installing Ubuntu and having a reasonable user experience are follows:

- * *- 700 MHz or better processor
- 384 MB of memory
- CD-ROM drive
- Ethernet interface
- VGA graphics interface capable of 1024x768 resolution
- 8 GB of available disk space

## Note

If you want to use Ubuntu's composing and advanced visual effects capabilities, you should have at least a 1.2 GHz processor and a recent ATI, Intel, or NVIDIA graphics card.

> If your system satisfies or exceeds these requirements, you're good to go. Customized distributions for specific platforms such as netbooks and MID devices have different requirements, such as a USB drive rather than a CD-ROM drive. You can certainly install Ubuntu on slower systems
