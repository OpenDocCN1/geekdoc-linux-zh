# Exploring the Bash Configuration File

When you start a bash shell on your Ubuntu system, it reads a certain amount of configuration information from various text files on your system. In the order they are read, these configuration files are the following:

+   - /etc/profile (login shells only)
- /etc/bash.bashrc (all bash shells)
- ~/.bash_profile (login shells only)
- ~/.bash.bashrc (all bash shells)

# Note

The symbol is a bash shortcut for referring to any user's home directory. ~/.bashrc is the file .bashrc in my home directory; ~/.bashrc is a reference to the user called *user*'s home directory.

The first two of these are initialization files that are read and incorporated when users log in on the system (/etc/profile) or starts a bash shell (/etc/bash.bashrc). The second two are personal configuration files that are stored in each user's home directory. As with the system-wide configuration files, the ~/.bash_profile is read by the user's login shell, while the ~/.bashrc is read by any user the creates, such as in an xterm or GNOME Terminal. Of these, the .bashrc file is most important for two reasons:

+   - The default- ~/.bash_profile on Ubuntu systems reads it
- Starting a bash shell is a much more common operation than logging in. A user only logs in once, although he or she may subsequently create different xterm or GNOME Terminal windows.

The .bashrc file enables each user to customize various aspects of the bash shell, such as it looks for commands, the prompt that it displays, the number of commands that it remembers in your command-line history, and many more things. The .bashrc file enables you to create your own shortcuts for Linux commands if you still feel that you are having to type too many characters and enables you to create your custom shell commands. Lines in any bash configuration file (or shell script, for that matter) that begin with the hash mark (#) are considered to be commented and not interpreted.

All Linux shells provide a command language and constructs for supporting conditional expressions to make it easy to write shell scripts. Explaining shell programming is outside the scope of this book, but there are many excellent books and web sites to visit.
