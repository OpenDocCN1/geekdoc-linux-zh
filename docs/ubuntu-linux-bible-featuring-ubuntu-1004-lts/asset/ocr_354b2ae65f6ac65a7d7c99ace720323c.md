The testparm utility only checks the Samba configuration file—it does not consult the running Samba service for information about how it is configured and the services that it provides. To do this, use the smbclient utility, as described in the next section.

# Testing Samba Availability and Services

The Samba applications includes an application called smbclient, which is a command-line client for contacting and browsing Samba servers. You can also use this utility to test if your Samba server is up and running, and to list the services that it is providing.

If you have made any changes to your Samba configuration file, you should restart the Samba server before attempting to verify the services that it provides. To do this, execute the following command:

```
/etc/init.d/samba restart
```

This command shuts down any instance of a Samba server that is currently running and starts the Samba server again, which forces it to read your updated configuration file.
