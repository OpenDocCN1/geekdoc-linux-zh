While you probably don't care about much of this stuff (and therefore won't miss it if you don't migrate it), one thing that you do care about probably use is your collection of links to favorite sites, known as favorites to Internet Explorer and as bookmarks to the rest of the universe.

This section explains how to save your Internet Explorer or Safari bookmarks to an HTML file that you can import into the Firefox browser. As suggested in the previous paragraph, you might want to import your bookmarks when moving to a new system as part of mandatory housekeeping exercise. However, being able to create HTML files containing your bookmarks can be very useful if you need to use other computers and operating systems but will have your familiar bookmarks. Some businesses mandate a specific operating system, and some web sites require specific browsers (sad enough). In these cases, being able to import bookmarks from one browser and import them into another provides a usable, but somewhat crude, way of seeing the same bookmarks in multiple browsers.

A popular solution to the problem of seeing the same bookmarks from multiple browsers is to make your bookmarks available on the Web. You can do this by making an HTML file containing them or by using various tools to store your bookmarks on specially designed web sites. For a list of Web-based bookmark management tools, see www.dmoz.org/Computers/Internet/On_the_Web/Applications/Bookmark_Managers.

Regardless of why you want to do it, being able to save your current favorites/bookmarks to an HTML file is very convenient. Whether you're doing it for migration purposes, quick-and-dirty backups, personal convenience, or to share your favorite web time sinks with your friend, the next few sections explain how to export from and import to different popular browsers.

# Exporting Internet Explorer Bookmarks

Both Internet Explorer 6 and 7 provide a "Import and Export" dialog (shown in Figure 9-11) that makes it easy to export your favorites to a file that you can import into other browsers on other systems—only the location of the command used to display this dialog has changed to confuse the user.

To display this dialog in IE6, select the File menu's "Import and Export" menu item. To display this dialog in IE7 or IE8, click the "Add to Favorites" icon (second from left in your default toolbar), and select the "Import and Export" menu command. Click Next to proceed, which displays the dialog in Figure 9-12.
