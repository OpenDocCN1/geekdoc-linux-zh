If you are configuring a VPN connection on a laptop, it's a good idea to install all three of the VPN plug-ins. Although you'll probably use only one of these, it's convenient to have them on your laptop if you are traveling and need to connect to a site that uses a different type of VPN software.

The default mechanism for obtaining IP information is Automatic (VPN), which means that the VPN server acts as a standard DHCP server, providing an IP address, the identity of at least one DNS server for the remote network, the domain name for hosts on the remote network, and so. ### Setting Up OpenVPN Manually

If you don't use the Network Manager to set up VPN connections, you will have to install and configure your connections manually. The type of VPN connection that you use depends on the type of VPN software that is running on the system. Although many VPN mechanisms are available for Ubuntu (OpenVPN, VPNC, etc.), OpenVPN is probably the most common of these, so this section focuses on its installation and configuration.

OpenVPN is a free source VPN package that is released by the GPL and is one of the most popular VPN packages used today. OpenVPN uses the OpenSSL library and SSL/TLS (Secure Sockets Layer/Transport Security) for secure, encrypted communications, and uses prepared secret keys, certificates, or username/password combinations for authentication. Beyond its popularity on Linux systems, OpenVPN is also available for operating systems, FreeBSD, Mac OS X, NetBSD, OpenBSD, Solaris, and Microsoft Windows 2000, XP, Vista, and 2008 Server.

Installing OpenVPN on your system can be done manually by installing the openvpn package which provides the Network Manager's support as a requirement for creating and managing OpenVPN connections. As part of installing OpenVPN, it is integrated into your Ubuntu startup process. As part of startup process, OpenVPN will try to automatically initialize any VPN connections for which configuration files are present in the directory /etc/openvpn. these configuration files must have the extension .conf. Each configuration file identifies the OpenVPN parameters that are required to establish a VPN connection to a remote network, including the name and location of any certificate and key that each connection requires. However, any connections requiring a specific password to unlock or verify a private key will fail during the boot process because OpenVPN does not support storing username and password information in configuration files unless it has specially compiled to do so.
