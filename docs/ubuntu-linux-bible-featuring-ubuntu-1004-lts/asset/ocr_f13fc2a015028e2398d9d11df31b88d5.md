# Working with
Text Files

Most of us are used to working with files in various applicationspecific formats, often identified by their file extension or a special icon on our graphical desktops. We're all familiar with the doc files produced by graphical word processors such as Microsoft Word, xls files produced by spreadsheets as Excel, fim files produced by FrameMaker, ppt files produced by PowerPoint, and all of these files contain application data in a specific, often binary, format that lets the associated application make the best possible use of these files, but which often makes them hard to use with any other application than the one that created them.

At the other end of the spectrum from these application-specific files is the lowest-common-denominator file format known as text files, or to be a bit specific, ASCH text files. The contents of these files consist of only the standard letters, numbers, punctuation, and symbols that you find on a computer keyboard. The nice thing about these types of files is that they are easy to read, to process, and easy to work with in general.

Regardless of what you use your Ubuntu Linux system for, you will almost end editing a text file one of these days. If you write code, it is almost certainly in standard text files because they provide a lowest-common-denominator format that can be processed by any compiler. If you're a writer, you may want to use text files because you can work with them on any system, with any editor or word processor—so you can work on them just as easily as your Ubuntu Linux system as you can on your Mac OS X system.
