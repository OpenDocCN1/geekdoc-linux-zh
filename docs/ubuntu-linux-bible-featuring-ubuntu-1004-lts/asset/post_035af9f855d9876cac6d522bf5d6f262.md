# Resolving Installation Problems

Most of the problems you encounter when installing any operating system, including Ubuntu Linux, are fatal. Problems encountered when reading the installation media; accessing, partitioning, and formatting your system's hard drives; and other hardware-related problems must be resolved before you can successfully install Ubuntu Linux. However, you may encounter two fairly common problems when installing Ubuntu Linux that can be easily corrected. The first is a problem with automatic network configuration; the second is a problem accessing Ubuntu's online repositories and correctly configuring the Ubuntu update system.
