# Modifying Document Styles and Layout

A style is the word processing term (borrowed from more advanced page layout programs that are associated with InDesign and PageMaker) for a setting of formatting and display characteristics for a specific portion of your text, usually a paragraph When you're actually editing a document, you can apply any of the existing styles that have been defined for that document by selecting the name of a style from the dropdown list in the formatting window, or by selecting it from the Styles and Formatting window. To display the Styles and Formatting window, select the Format Styles and Formatting menu command.

All of Writer's default document templates provide a default set of styles that enable you to format the different portions of your document. To apply a style to an existing paragraph, simply click anywhere inside it using the mouse, and select the style you want to apply from the dropdown list or the Styles and Formatting window. I am using the term paragraph here because, by default, a paragraph is any element in your document that ends with a hard return, even if it's empty.
