# Tip

If you have not registered a printer yet and want to get information about Linux support for a specific printer, check out the site at www.linuxprinting.org. This site, which actually resolves to a site at the Linux Foundation (www.linuxfoundation.org/collaborate/workgroups/openprinting), provides an easy interface at www.openprinting.org/printers that enables you to get information about how specific printers (or all of the printers from a specific manufacturer) work with the Linux printing system. For more information about printing Linux, see Chapter 33, "Setting Up a Print Server."

Adding a locally attached printer has become incredibly simple thanks to the fact that most printers use USB interfaces nowadays rather than the classic Centronics parallel interface that many of us remember with varying degrees of freedom. Attaching a USB device to your system causes a recognizable event that your system can also initiate its configuration. The next few sections discuss what happens when you attach a new printer to your Ubuntu system, and how you can create or customize your printer's configuration, if necessary.

Earlier releases of Ubuntu enabled you to configure what would happen when a new printer was detected by your system. This was friendly but largely waste of time because the answer is almost always "Please configure the thing so that I can actually print on it." On modern Ubuntu systems, attaching a USB printer usually means the printer being recognized automatically—it simply appears in the System Administration Printing dialog shown in Figure 20-1—the printer is recognized, added, and configured, and your system is ready to use it.

If the printer was recognized correctly, your printer is automatically added to the list of printers that are available on your system, and you're ready to print! However, if your printer was not recognized correctly or if you simply want to test or configure it, you can-click the icon for the printer and select Properties to open the system-config-config application, which is discussed in the next section.
