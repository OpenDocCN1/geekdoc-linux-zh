```
$ ls test
libxml2 netdev system
```

The output from this command shows that the test directory itself contains three other files
or directories. I happened to know that test was a directory—if you're not sure about what types
of things are in the current directory, you can use the ls command's -F option to give you this
information. For example, here's the current directory as shown using the ls -F command:

```
$ ls -F
boot-services.txt hello.c hello.o include.example.c test/
hello* foo hello.s include_example.o
```

The ls -F option decorates any object in the current directory with an
extra character to identify any object that isn't simply a text file. An asterisk following the name
of an object shows that this is an executable file, while a slash (/) following the name of an
object shows that this is indeed, a directory.

The ls -F option is very useful, but (in true Linux) it isn't the only way to get
detailed information about objects in the current directory. You can also get this sort
of information using other options to the ls command. For example, one of the most commonly
used options to the ls command is the -l option, which means "display output in long format."
Using this option gives a variety of additional information about the objects in the current direc-
tory, in the following example:

```
$ ls -l
total 44
-rw-r--r-- 1 vwh users 783 2010-03-15 06:36 boot_services.txt
-rw-xr-xr-x 1 vwh users 9249 2010-03-15 06:37 hello
-rw-r--r-- 1 vwh users 60 2010-03-15 06:37 hello.c
-rw-r--r-- 1 vwh users 60 2010-03-15 06:37 foo
-rw-r--r-- 1 vwh users 2504 2010-03-15 06:37 hello.o
-rw-r--r-- 1 vwh users 857 2010-03-15 06:37 hello.s
-rw-r--r-- 1 vwh users 202 2010-03-15 06:37 include_example.c
-rw-r--r-- 1 vwh users 736 2010-03-15 06:37 include_example.out
drwxrxr-xr-x 5 vwh users 4096 2010-03-15 06:37 test
```

As you can see, the long option displays more complete information about the files and directo-
tries in the current directory. From left to right, this information consists of current
permissions, the number of hard links to file in the Linux filesystem (more about that later
in this section), the owner and group, the date and time at which it was last modified, and
the file or directory name.
