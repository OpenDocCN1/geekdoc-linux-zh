Aside from the fact that you didn't have to do any of the math in this example (hooray!), one of the coolest things about a spreadsheet containing calculated values is that you can update any of the other cells that are involved in those calculations, and the spreadsheet will automatically update itself to reflect the new value in any cells that are based on the contents of the modified cell. Try it yourself—as all good software should do, it just works!
