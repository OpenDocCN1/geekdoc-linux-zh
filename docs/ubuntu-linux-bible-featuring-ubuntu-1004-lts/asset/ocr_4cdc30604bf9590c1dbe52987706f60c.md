# Using PCMCIA Cards

PCMCIA (Personal Computer Memory Card International Association) cards are the original mechanism designed to support removable and insertable interfaces in portable computer systems. PCMCIA cards are now often just called PC Cards because no one can ever remember the acronym name (as suggested by the optional PCMCIA expansion, "People Can't Memorize Industry Acronyms”). Thanks to the rise of USB, PCMCIA cards are not as common as they were, but it's still useful to talk about them in case you're installing Ubuntu on an older laptop.

PCMCIA cards are available that provide wired and wireless network interfaces, modems, SCSI, USB, and FireWire interfaces for computer systems that don't have them, and so with the 2.6 kernel, the traditional Linux PCMCIA support package was integrated into the hotplug system to support the creation of appropriate device nodes nodes when PCMCIA cards are inserted.

The primary application to identify any PCMCIA cards inserted in your system is the pccardctl application (formerly known as cardctl). However, how the kernel handles devices mean that this utility may not return detailed information about a PCMCIA card. To see what cards are present in your system and to display summary information about them, execute the pccardctl ident command. That will return something like the following:

```
$ pccardctl ident
Socket 0:
 no product info available
Socket 1:
 product info: "LEXAR ATA FLASH CARD " "STORM " "TE01"
manifest: 0x04e01, 0x0200
function: 4 (fixed disk)
```

This shows that I have two PCMCIA cards inserted but that no information is available the first one. Some of the other pccardctl commands may provide more information. The pccardctl ls command, for instance, displays the following:

```
$ pccardctl ls
Socket 0 Bridge: [yenta_cardbus] (bus ID: 0000:02:03.0)
Card bus -- see "lspci" for more information
Socket 1 Bridge: [yenta_cardbus] (bus ID: 0000:02:03.1)
Socket 1 Device 0: [pata_pcmia] (bus ID: 1.0)
```

This shows that the PCMCIA network card in my first PCMCIA slot is being handled as a PCI card, while the compact card is being handled by the Parallel IDE subsystem.

In most cases, the hotplug/udev subsystems will automatically create necessary device nodes, using the standard mechanisms to notify you when new PCMCIA storage devices are attached, and when new PCMCIA wireless interfaces appear, and so on.
