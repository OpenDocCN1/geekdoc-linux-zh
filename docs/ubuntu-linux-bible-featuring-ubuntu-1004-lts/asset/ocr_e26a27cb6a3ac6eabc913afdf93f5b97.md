# Taking a Quick Tour of Calc

OpenOffice.org Calc provides excellent online help, as do all the tools in the OpenOffice.org suite, so I won't bore you by walking through each menu and entry it contains. However, as a quick overview of the Calc interface, the callouts in Figures 14-1 and 14-2 highlight the following areas:

+   - Menu: The dropdown menus in Calc are organized much like the menus in Microsoft Excel to provide a familiar user experience. Menu items with an arrow at their right edge lead to, related submenus.
- Toolbars: By default, Calc displays the Standard and Formatting toolbars, which provide one-click access to specific commands when clicking on the appropriate icon, or a Formula bar, in which you can view and edit any functions or formulas for selected cells. You can modify the list of icons displayed on a toolbar by clicking on the control for that toolbar, located at the far right. You can display other toolbars or deactivate the default toolbar by selecting the names of those from the View submenu.
- Row and column headings: These headings identify the current row and column for the cells you're viewing. They can be useful when manually entering cells or ranges in a formula.
- Context-sensitive menu: Right-clicking on any cell in a spreadsheet you are working in Calc displays the context-sensitive menu shown in Figure 14-2. This menu provides quick access to several cell-manipulation commands.
