## Enhancing Firefox

This chapter has stressed the power and usability of Firefox as it comes "out-of-the-box." However, Firefox provides a final set of capabilities that make it even more interesting: You can easily add Firefox capabilities (known as add-ons or extensions); new many ways of displaying icons, windows, backgrounds, and so on (traditionally known as themes, and supported in a lighter-weight fashion as personas, which were officially introduced in Firefox 3.6); and applets (as plug-ins) that run within the Firefox framework and add support for specific types of multimedia. This section explains how to add each of these items to customize your Web surfing. In many cases, Firefox provides extra capabilities that are worthy of being separate applications—but Firefox smoothly integrates into your Web surfing experience. Simply, everyone has their own idea of making icons and appealing graphical design. Firefox themes and personas—much like the skins that you may be familiar with popular audio applications such as Winamp or XMMS—enable you to customize your browser's appearance so that it is more attractive to you and quite possibly more for you.

# Note

Old versions of Firefox used separate dialogues for retrieving, installing, and managing extensions and themes and didn't provide a centralized mechanism for retrieving and installing plug-ins. Firefox now provides a single menu command and dialogue for performing all of these tasks.

## Registering for Add-Ons

With versions of Firefox prior to 3.0, anyone could download and install any add-on, extension, or theme from their respective websites. With Firefox 3.0, some extensions and themes are available only if you've registered with the Mozilla Add-ons site (https://addons.mozilla.org/en-US/firefox/). On the one hand, this is a pain and it's not going to help the adoption of Firefox; on the other hand, it's useful for the Mozilla Foundation and extension/theme developers to know how many people are using Firefox and which extensions and themes they are actually using.

You may not wait until you run an extension or theme that requires you to do, but that didn't take me long. You can register with the Add-ons site by clicking the link in the upper-right corner of any page, or by going directly to https://addons.mozilla.org/en-US/firefox/users/register. After entering your e-mail address, a password, and a minimal amount of personal information, you'll be sent a confirmation message via email. When you receive this, click the link in the message to confirm your subscription, and you're good to go over.

## Viewing Installed Firefox Add-Ons, Themes, and Personas

The single dialog used in Firefox for themes/personas, extensions, and add-ons makes it easy to see which of these are currently installed in Firefox, which of those add-ons are currently enabled, and which theme is currently being used. While multiple extensions can be enabled, only one theme can be used.

To see the add-ons that are currently installed in the version of Firefox you are using, select the Add-ons command from the Tools menu. If you are already viewing the Add-ons dialog, click the Extensions icon to display the pane shown in Figure 8-20. As with the list of themes, this will be almost empty, but we will fix that in the next section.
