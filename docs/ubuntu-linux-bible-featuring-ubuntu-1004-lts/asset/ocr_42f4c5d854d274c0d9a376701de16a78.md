7. Working with graphical frames is similar but uses an external application (GIMP, which is discussed in Chapter 15, "Working with Graphics") to edit any existing image. For example, scroll down in Scribus you will see one on the right of the second page. To create this graphic, first right-click on its frame and deselect "Locked" from the context-sensitive menu to unlock the frame. This enables modifications to the frame. As you're working, you can lock any frame that you're happy with to prevent accidental modification.

8. To delete the existing image, right-click on the frame and select Contents Clear. The document updates to reflect the absence of the graphic, as shown in Figure 13-28.

9. To select a new graphic for the frame, right-click on the frame and select the "Get Image" command. The dialog shown in Figure 13-29 displays, enabling you to navigate, select, and preview any existing graphic on your system.
