# Setting Up a Subversion Server

Although Subversion is based on WebDAV, and therefore, uses the HTTP protocol for basic communications between clients and servers, you can access a local Subversion repository (i.e., one that is physically located on the same machine that you are using) without running a Subversion server. You will need to be running a Subversion server on machines whose repositories you want to access from other systems. There are two common types of Subversion servers:

+   - Apache2: Apache Web server with integrated support for Subversion. For Subversion and WebDAV is easily added to an Apache or Apache2 Web server, which enables you to access your Subversion repository over the Web using http://host-name/repository or https://host-name/repository (if you configure SSL into Apache2 and Subversion). The examples in this chapter discuss Apache2 integration and configuration because Apache2 is the more modern and powerful

+   - Svnames: A stand-alone Subversion server that enables you to access your Subversion repository over the Web using URLs like svn://host-name/repository. The svnames binary is installed as part of the Subversion package.

These two servers are not mutually exclusive and can easily run on the same machine at the same time, providing access to the same repository if properly configured. The next sections explain how to configure each of these to provide access to the sample repository that you set up and populated in previous sections.

# Configuring Apache2 for Subversion Support

Configuring the Apache2 Web server to support Subversion is quite easy, only requiring that you install and integrate the right Apache2 module, configure that module, and create the authentication file that will control access to the repository.

Installing the Apache2 Web server's support for Subversion was described earlier in this chapter in the section, "Installing Subversion," and is done by installing libapache2-svn package using the Synaptic Package Manager or the apt-get utility. The Apache2 Web server for Subversion integration with Apache2 is loaded by the file /etc/apache2/mods-available/dav_svn.conf. The configuration file for this module is the file /etc/apache2/mods-available/dav_svn.conf.

After installing the Apache2 Web server for Subversion, edit this file using sudo and your favorite editor. Your configuration options are the following:

+   - Update the <Location/svn> element if you want to make your repository available through any URL other than http://Web-server/svn.
