# Part II: Ubuntu for Desktop Users

The Categories menu at the left of the Firefox Add-ons page lists a number of topics into which available add-ons are organized, making it easier to find add-ons that are related to some specific task you want to accomplish in Firefox. These categories can contain both extensions and themes, although there is a separate Themes category that I will discuss in a moment.
