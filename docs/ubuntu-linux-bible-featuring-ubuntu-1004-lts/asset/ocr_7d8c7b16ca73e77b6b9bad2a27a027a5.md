8. The partitioning screen shown in Figure 3-8 is really the only potentially complex part of the Ubuntu installation process. If you are installing the Ubuntu Server on a system with a single disk and want to devote that entire disk to Ubuntu, the installation screen should look much like the screen in Figure 3-8 except for differences in device names and sizes. This screen provides a few options:

+   - Guided resize partition and free space: This option only displays if you are installing Ubuntu Server on a computer system where disk(s) already contains file systems. Selecting this option enables you to resize an existing partition and install Ubuntu Server in the newly free space, which would give you a dual-boot system that can boot into either the operating system that is already on or Ubuntu Server. It is extremely rare to install a server system as part of dual-boot setup, servers are servers, and thus typically only one operating system in order to provide certain services. However, this option is available if you do want to do this, as in the case where you have limited hardware resources and are simply experimenting with the latest release of Ubuntu Server.
- Guided - use entire disk: Erase the entire disk, and use traditional physical partitions.
