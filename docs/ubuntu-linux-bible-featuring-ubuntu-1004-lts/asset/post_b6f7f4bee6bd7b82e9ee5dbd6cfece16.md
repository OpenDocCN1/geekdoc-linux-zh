# Tip

You should, of course, minimize the number of new styles that you create whenever possible. For example, you may be working with corporate document standards that mandate specific formatting and styles. In this case, adding new styles may be, at worst, a violation of corporate policy and, an irritation to anyone who subsequently has to work on a document you've written or modified. Always make sure it's absolutely necessary before creating a new style, but doing so is almost preferable to simply tweaking fonts and fonts throughout your documents.

# Creating and Using Templates

As mentioned in this chapter, Writer comes with a good selection of default document types, known as templates, and provides wizards to help you use or even create new templates based on those document types. The previous section described how to create your styles to further-tune the settings that you use in your documents. This is very convenient but only modifies the styles associated with a specific document — the template from which that document was created does not pick up the new styles, which makes it hard to share your stylistic insights with others. It also makes it hard for you to reuse them, unless you create every new document by copying an existing document that has the new styles, and replaces its contents. At best, this is a pain in the anatomy, and at worst, is almost completely inefficient. The right solution is to be able to create and manage your own document templates, and reuse them by starting new documents from your updated templates, and share your Writer wizardry with other users simply by giving them copies of your templates.

# Note

The process of creating a new template is initially the same as for manually creating a new document (although without using a wizard). The primary differences are that you don't need to add much content (representative elements for designing new styles) and that you can save the new document as a template rather than a document. Read on!

To create a new template, do the following:

- 1. Select File New Templates and Documents from any Writer window to display the dialog shown in Figure 13-15.
- 2. Select the New Document icon at the left, and select Text Document as the type of document that you're creating. Click Open to begin modifying the new document, which displays as an empty document in a new Writer window. In this window, create any stylistic elements and layout settings that you want to provide through your new template. (The previous section explained how to create new styles from existing ones in existing documents.)

Congratulations, you've created a document template! Once you've created a template, you can easily create new documents based on that template by doing the following:

- 2. To create a document from a specific template, click the Templates icon at the left and select the location where you saved your template (usually “My Templates”). - 3. Select the template that you want to use, and either click Open or double-click on its name to create a new document from this template.

Once you are finished editing your document, save it by the standard File ✜ Save command.

Creating and using templates is a great way to standardize the documents that you or your organization is creating.

# Tip

Modifying or otherwise updating a template does not mean that any documents that have been created from it are automatically updated. When updating a template, opening any document that was created from it will prompt you as to whether or not you want to update the document to reflect the updated template. That's usually a good idea, but it's nice that Writer is kind enough to ask you about it.
