# Sending Mail in Evolution

You can begin composing a new message in Evolution in a variety of ways, including:

- * Click the New button when you're composing mail.
- Press Ctrl+N on your keyboard.
- Select New Message from the menu.

You can reply to a message you are currently viewing by doing either of the following:

- * Click the Reply button.
- Press Ctrl+R on your keyboard.
- Select Reply from the menu.

If you want to reply to everyone who received the original message:

- * Click the Reply to All button.
- Press Ctrl+Shift+R on your keyboard.
- Select Reply to All from the menu.

If you want to forward the message to a new recipient:

- * Click the Forward button.
- Press Ctrl+F on your keyboard.
- Select Forward from the menu.

# Tip

If you want to send a copy of the mail to someone else, use the CC (Carbon Copy) or BCC (Blind Carbon Copy) fields. CC is used when you want other recipients to see the copy, while BCC is used when you want to hide the recipient's address from others. These fields are found in the header of the message.

# Setting Evolution Preferences for Sending and Viewing Mail

Evolution's Preferences dialog enables you to configure Evolution, and also to correct or change any of the basic information you supplied. This section discusses one of the most common changes, which is the format in which you send e-mail.

Two basic types of encodings are used when composing and receiving e-mail. One is plaintext, which means that your messages display as standard text that might come out of a typewriter, with no special fonts or formatting. The other is e-mail that is formatted as HTML, which lets you use different fonts, special characters for bullets, and so on. Many people prefer one or the other, and whether or not you can read mail delivered in HTML format is up to the e-mail client you're using.

# Note

Whether or not an e-mail client can send mail in HTML format is a different question from whether you should send e-mail as HTML. Many people, some government and military sites, and specific recipients as mailing lists, do not want to receive or will not accept e-mail formatted as HTML. I'm not a fan—always send text mail.

As shown in Figure 7-12, when you first compose messages in Evolution, it uses standard format for your messages by default. If you want to switch to using HTML mail, you can do this in one of two ways:

- * If you want to send just the current message in HTML format, select the HTML command from the Format menu in the window where you're composing your message. 7-13 shows the same mail composition window as in Figure 7-12, but displayed as HTML. Additional formatting buttons are active when sending an HTML message, enabling you to use different fonts, different justification formats for the graphs in your message, and so on.
- * If you want to send all of your mail as HTML, you must set that as your preference in Evolution's Preferences dialog.
