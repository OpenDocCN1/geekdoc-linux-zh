# Introduction to Mail Servers

The components of an e-mail system can be confusing, so I usually generalize them as the difference between receiving and retrieving—my mail server receives e-mail for me, and my e-mail client lets retrieve my e-mail from there to archive, delete it, and so on. In overall mail-server, there are three components involved in a mail system:

+   **Mail Transfer Agent (MTA):** A program that handles transferring e-mail from computer to another, using the Simple Mail Transfer Protocol (SMTP). Well-known examples of MTA are Microsoft Exchange, Sendmail, Postfix, qmail, and MTA are often referred to as "mail servers," which can be confusing this is also the term commonly used to identify the host MTA runs

+   **Mail Delivery Agent (MDA):** A program that actually delivers the e-mail received by an MTA into my personal mailbox and can do both preprocessing, such as spam filtering and virus detection, and auto-responder tasks, such as sending "I'm on vacation". MDA also handles the presentation of mail from the mailbox to yours, supporting protocols such as the Post Office Protocol (POP and POP3) and the Internet Message Access Protocol (IMAP) on the host where mail is stored. Common examples of MDAs on Linux systems are procmail, Qpopper, Gyrus, pop3d, Courier IMAP, and / bin/mail. MDAs can be directly integrated into an MTA, as is with the Microsoft Exchange and often with Linux systems when mail is read directly from a traditional UNIX-style mail file.

+   **User Mail Agent (MUA):** A program that lets you send and read the messages in your personal mailbox using protocols such as POP, POP3, and IMAP. Most MUAs provide support for composing and managing mail messages. Common examples of MUAs are Evolution, Microsoft Outlook, Mutt, KMail, Alpine, and Thunderbird.

In most cases, users never see the MDA because it is integrated with the MTA, either by the system administrator. Similarly, most users could care less about the MTA and use the term mail server to identify the host on whatever MTA they are using. Although the MTA is the most important component of a mail system from the user point of view, the MTA is the most important component from a mail system's and system administrator's point of view because it both performs the actual transfer of mail from one computer to another and identifies the MDA and any other applications involved in pre-processing mail on its way to the user's mailbox.
