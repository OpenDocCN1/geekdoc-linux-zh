To send an instant message to someone, regardless of whether they're shown in your Buddy List, you can always select the Buddies ⇌ New Instant Message option. (Once someone is in your Buddy List, you can send them an instant message by double-clicking on their name in the Buddy List.) If you've defined multiple instant messaging accounts, the dialog shown in Figure 10-17 displays, which you must identify both the person that you want to IM and the account that you want to use to do so. Once you do so, you'll see a dialog like the one shown in Figure 10-18. If you've only defined a single instant messaging account, you'll see a dialog like the one shown in Figure 10-18 immediat.
