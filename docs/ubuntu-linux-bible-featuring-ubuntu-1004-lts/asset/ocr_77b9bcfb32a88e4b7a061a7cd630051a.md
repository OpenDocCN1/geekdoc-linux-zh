# Getting More Information about IRC

Regardless of how well it fits the IM model, IRC is still popular, quite fun, and occasionally useful. When you first connect to IRC, you'll probably be doing so in order to connect to a specific channel, like #ubuntu. Most of the channels on the Ubuntu IRC servers are Ubuntu-related, but you may be interested in channels such as #newirc, #newbies, and #newuser that are found on other IRC server and providing interesting starting points. If you'd like general information about IRC or have some specific questions, you may want to explore #irhelp. For information about available channels, use /list on the IRC server you're connected to, or use a Web-based resource such as ..irhelp/irhelp/list.

The following are some great sources of additional information about IRC, its culture, IRC servers, other IRC sites, and so on:

+   - IRC (www.irc.org): Known as the original home of IRC, this site provides news, help IRC history and information, about ongoing developments in IRC, and a huge collection of useful links to many IRC-related sites.
- IRChelp (www.irchelp.org): The Internet Relay Chat Help provides a tremendous collection of IRC FAQs, primers, HOWTO guides, helper scripts, lists of active supported channels, and so on.
- Wikipedia (http://en.wikipedia.org/wiki/Internet_Relay_Chat): In addition to the standard "online encyclopedia" info, the Wikipedia article on IRC provides links to many other IRC-related sites—or at least it did at the time of this writing.

# Other Instant Messaging Packages

Empathy and Pidgin provide all of the functionality that almost everyone needs in a multi-protocol IM client. However, Ubuntu is a Linux distribution, so you might suspect there are a huge number of other IM applications out there. Some of my favorites are the following (listed in alphabetical order):

+   - Google Talk (www.google.com/talk): Google Talk is a Windows and Web-based client for Google's chat, or any other XMPP-based chat service.
- Licq (..licq.org): Licq is an ICQ client that uses the QQ desktop widgets. it is actively under development. Plug-ins are available to enable Licq users to communicate with AIM and MSN users.
- Meebo (www.meebo.com): Meebo is a Web-based instant messaging service that supports its own accounts as well as providing access to other IM services that Meebo supports, such as AIM, GoogleTalk, ICQ, jabber, MSN, and Yahoo. A Firefox plug-in for Meebo is also available.
- Psi (http://psi-im.org): Also in Ubuntu repositories, Psi is a free Jabber/XMPP client that is available for Linux, Macintosh, and Windows systems and uses Qt
