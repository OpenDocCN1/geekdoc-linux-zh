# Part II: Ubuntu for Desktop Users

The name of a virtual disk image is initially set to the name you specified for your virtual machine, but you can change this by entering a new name if you wish. I rarely change the name of the disk image because using the same names for both makes it easy to see which disk image goes with which machine if you explore the ~/VirtualBox folder. The default size of the disk image for a virtual machine is typically set to 8 GB, which is enough for experiment but not if you plan to install a large number of applications and/or do a significant amount of work in your virtual machine. For example, I intend to use 20 GB disk images for Windows systems to reduce the chance that I'll run out of space (and because space is cheap nowadays). If you're dynamically expanding images, you won't lose all of that disk space on your host system immediately, although you should really have that much available just in case the virtual machine actually needs it.

After making any changes to the name or maximum size of your virtual disk image, click Next to proceed. A Summary dialog like the one shown in Figure 24-10 displays.

Click Finish to proceed. The dialog shown in Figure 24-6 re-displays, this time displaying the name and location of your virtual disk as the Hard Disk for your system. Click Next to proceed. The Summary dialog shown in Figure 24-11 displays.

This dialog summarizes the name, type, memory allocation, and virtual disk image for the new virtual machine that you are creating. Assuming that you've specified the values that you want to use in the preceding dialogs, nothing on this dialog should be a big surprise. You can change these settings later anyway, so you may well proceed. Click Finish to proceed. The main VirtualBox window re-displays, showing an entry for your new virtual machine in the column.
