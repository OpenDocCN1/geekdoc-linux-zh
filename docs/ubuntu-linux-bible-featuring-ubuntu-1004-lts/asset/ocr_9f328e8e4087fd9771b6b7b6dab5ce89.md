# Networking and VirtualBox

VirtualBox includes an internal DHCP server and built-in support for NAT (Network Address Translation) that enables your virtual machines to automatically obtain IP addresses on a private Internet subnet. Virtual machines that you create in VirtualBox automatically use NAT networking to reach external networks as the Internet. Unfortunately, such communications are handled by VirtualBox rather than standard networking infrastructure. This means that, by default, you cannot use standard network commands to reach your host from your virtual machines, and you also cannot reach the host machine from your virtual machines. Bogus! Luckily, VirtualBox supports other networking mechanisms, specifically Bridged networking, eliminating these hassles by enabling your virtual machines to communicate with other hosts and networks by using a virtual interface on the host system, rather than through VirtualBox itself. This enables communication between your virtual machines and any other system, including your host system, which also enables any other system that can reach your host system to reach your virtual machines. As a plus, it's not hard at all to set this up.
