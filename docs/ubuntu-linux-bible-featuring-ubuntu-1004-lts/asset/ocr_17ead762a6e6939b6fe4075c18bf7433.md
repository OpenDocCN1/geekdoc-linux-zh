This submenu identifies packages that are normally installed with the primary package that you have selected for installation but that are not required or expected. You can select any of the additional packages listed on this menu (one by one) to schedule them for installation.

Once you have selected any suggested packages that you want to install with the primary package you have selected for installation, click Apply in the Synaptic toolbar to begin the actual installation process. This displays the dial shown in Figure 19-21, which summarizes all of the activities associated with installing the selected package(s).

Once the download process completes, Synaptic begins installing and configuring the downloaded packages. If you did not select the "Apply changes" in a Terminal window item in Synaptic's Preferences dialog, Synaptic displays a simple status dialog, as shown in Figure 19-23.
