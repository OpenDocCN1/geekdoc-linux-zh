Understanding exactly what people mean when they say “Linux” is the key to understanding how so many different versions of the same thing can be available, but requires a little insight into how personal computers actually work in terms of software.

When you install an operating system such as Linux, Microsoft Windows, or Apple's Mac OS X your computer system, you are installing some amount of software that is invisible to any regular user because it runs behind the scenes. This software handles handling, starting, and stopping different programs, communicating with your computer's hardware, communicating with peripherals such as your printer; and so on. This is generally known as system software because regular users do directly interact with it, but it needs to be present and providing the services that application software relies on. The core piece of this system is usually referred to as a kernel because it is the central piece of the operating system and everything else builds on the fundamental features of it.

By itself, a kernel isn't very interesting—people don't want to run a kernel; they want to run applications. These applications depend on services that are provided by both the kernel and by other system software. For example, if you want to print a file, whatever you're needs to create a version of the file that is formatted in a way that your printer understands, and schedule it for printing. Another piece of software handles the formatted file to printer, making sure that the file prints correctly, and so on.

In popular, Linux is the collective name for an operating system and its associated applications. In reality, Linux is technically the name of the just kernel—most of the applications that anyone uses with Linux come from other free software projects. A Linux distribution is the correct term for a Linux kernel, a set of applications that can run on top of it (regardless of where they come), and a tool to install everything and configure your system. Each company or organization provides a distribution taking advantage of the open source nature of the Linux kernel and the applications run on top of it by putting together the “right” collection of applications that anyone want to run on top of it.
