# Graphical Versions of vi

Many people, especially former users of systems such as Microsoft Windows and Mac OS X, expect applications to have a graphical user interface. This poses an interesting problem for applications like vi and emacs that were originally designed for use with terminals back when a mouse was a pesky rocky. To make people feel more at home with powerful tools such as vi (and drag them, often kicking and screaming, into the Twenty-First Century), various graphical interfaces for vi have been developed over the years.
