# Using IRC in Empathy

As discussed in the sections on Empathy and Pidgin, IRC is one of the messaging protocols that is built into both applications. This section focuses on Empathy because it is the default IM client on Ubuntu systems. Because most IRC servers are open, you can create an IRC account and connect to an IRC server without having to pre-register, but you must create an Empathy account to do this. You will learn in this chapter, "Adding and Removing Empathy Accounts." When creating an IRC account in Empathy, your nickname is whatever you want it to be, but it must be unique on the IRC server that you are connecting to. Empathy offers a high number of IRC servers in the Network dropdown, but if you're just getting started with IRC, the Ubuntu Servers entry is the best initial selection. This connects you to the IRC server http://irc.ubuntu.com (part of the freepode IRC network).

To join an IRC channel in Empathy, select the List dialog Join menu. The "Join Room" displays. Select your IRC account as the account to use, and enter the name of a room you want to connect to --Ubuntu is a good place to get started. A standard Empathy conversation window opens, and you'll see the ongoing public conversations between everyone else who's in that room (channel in IRC-speak). You can see a list of all the channels available on the Ubuntu IRC server at https://help.ubuntu.com/community/InternetRelChat.

At this point, you can enter other IRC commands in the text window at the bottom of the Pidgin screen, or simply enter text to send it to the channel. When you're asking questions, answering questions, or simply switching the flow of communications, you can leave the channel using the /leave command to leave a channel or the /quit command to close your connection to IRC.

# Note

If you find IRC interesting, useful, or perhaps even bob, you may want to investigate other Linux IRC clients. Empathy is fine for most users, the XChat program is a UNIX/Linux IRC client that has been around for a long time, is quite popular, and makes it very easy to connect to multiple channels and servers at the same time. XChat uses GTK, so it is well-suited for GNOME-based Ubuntu desktops. XChat is not installed by default, but is available in the default Ubuntu repositories. The latest version of XChat for Ubuntu systems is located in the xchat- gnome package, which you'll have to install using your favorite Package Management tool.
