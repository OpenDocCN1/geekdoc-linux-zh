### Determining What Package Provides an Existing File

After working with Ubuntu for a while and installing, updating, and removing some number of packages, you may be curious about which package provides a certain file on your system. This is easy to determine using the dpkg command's --search option, as in the following example, I'm curious about which package provides the /usr/bin/ar archiving utility:

```
$ dpkg --search /usr/bin/ar
binutils:/usr/bin/ar
```

If you know that a utility you're looking for is in your path but you don't want to have to determine the directory in which it is physically located, you can use the shell trick of using the output of an existing command as input to another one, in this case combining the which command, to determine the full pathname of an application, and the dpkg --search command, which produces exactly the same output:

```
$ dpkg --search (which ar)
binutils: /usr/bin/ar
```

When searching for files, the dpkg --search command can't find symbolic links that are created by package post-installation scripts. If you are trying to find a file that you exists but cannot locate it, make sure the file is not a symbolic link, and if it is, search for the file that actually points to. This can sometimes require a few tries, as in the following example:

```
$ dpkg --search /usr/bin/emacs
dpkg: /usr/bin/emacs not found.
```

```
$ ls -l /usr/bin/emacs
/usr/bin/emacs -> /etc/alternatives/emacs
```

```
$ dpkg --search /etc/alternatives/emacs
dpkg: /etc/alternatives/emacs not found.
```

```
$ ls -l /etc/alternatives/emacs
/etc/alternatives/emacs -> /usr/bin/emacs21-x
```

```
$ dpkg --search /usr/bin/emacs21-x
emacs21: /usr/bin/emacs21-x
```

Although sometimes tedious, symbolic links are usually not an actual part of a package, and you must ferret out a file that is part of a package.

### Tip

Another package Management utility you might want to use when determining which package provides a specific file is the locate utility. This utility is not installed on Ubuntu systems by default but can be easily installed with apt-get, aptitude, or Synaptic Package Manager. After installing this, you can search for the package that provides a file using the locate -S command, as in the following example:

```
$ locate -S /usr/bin/emacs
emacs21-bin-common: /usr/bin/emacsclient.emacs21
emacs21: /usr/bin/emacs21-x
emacs21: /usr/bin/emacs21
```
