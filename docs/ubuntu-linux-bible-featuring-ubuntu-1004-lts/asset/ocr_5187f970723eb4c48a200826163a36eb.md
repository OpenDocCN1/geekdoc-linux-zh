To make GStreamer as full-featured as possible, use your favorite Package Management software from Chapter 19 to install the following packages (or to make sure that're already installed):

- gstreamer0.10-plugins-base

- gstreamer0.10-plugins-ugly

- gstreamer0.10-tools
- toem-gstreamer

# Tip

You may not need all of these unless you are converting audio files from one format to another, and even in that case, the plugins that you depend on the types of files that you're converting. I'm assuming that you would rather err on the side of caution — that is, installing a version of the GStreamer framework that is as full-featured as possible, at the expense of a bit of disk space.

> GStreamer is a library that is used by many applications, not an application itself. The GStreamer library enables applications to access Gstream plug-ins. Having installed the suggested GStreamer plug-ins, applications such as Ryhythmbox and SoundConverter, discussed later in this chapter, will now be able to work with most types of audio files.

# Tip

For up-to-date information on using GStreamer-based applications to play proprietary audio and video formats, see https://help.ubuntu.com/community/RestrictedFormats.
