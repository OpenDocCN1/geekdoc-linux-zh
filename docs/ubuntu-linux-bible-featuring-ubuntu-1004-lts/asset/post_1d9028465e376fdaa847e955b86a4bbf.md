Changing your system's default behavior when a specific type of device is attached is a good idea if you use a specific application to work with devices of that type. For example, if you always want to use F-Spot to extract and manage photos from your digital camera, then setting F-Spot as the default action for Photos is probably a good idea. Similarly, if you always want to use another application, such as Google's Picas, to work with your photos, you may want to select "Open with other Application" and select that application from the list. If the application you want to use is not shown on the list, click "Use a custom command" and enter or browse for the location of the command that you want to use.

On the other hand, you will not want to change your system's default behavior if you differ specific types of devices and want to open each in a different application. For example, I'm a big fan of the kidpod for working with iPods, but I have a couple of generic MP3 players that I use from time to time. I, therefore, do not kidpod as my default application for music players because it has no idea how to work with generic MP3 players. Instead, I use "Open with other Application" from the menu and dialog shown in Figure 18-2 to add kidpod to the list of applications associated with music players, and then select the appropriate application from the prompt dialog whenever I attach an iPod or other MP3 player.

# Working with Your Digital Camera

This section discusses F-Spot, the primary application that Ubuntu provides for working with your digital camera. This application was introduced in the "Photo Editing Overview" section of Chapter 15, "Working with Graphics" (which also lists some alternative digital camera related applications that are available for Ubuntu systems).

Prior to Ubuntu Hardy (8.04), Ubuntu systems used a shell script named gnome-thumbnail to get the gThumb viewer to import, organize, and display your photographs. In Ubuntu Hardy and later, the thumbnail and the associated script are still available, but the default application for importing, organizing, and displaying digital photographs is not F-Spot. If you want information about using gThumb, look for a PDF copy of the first edition of this book on thepirbay.org—this section focuses on using F-Spot.

The dialog shown in Figure 18-8 provides two options that you may want to consider before importing the photographs from your camera:

- Add Tag: Add a customized tag to the set of photos that you are importing, which will make it easier to locate this set of photos in the future. Activating this checkbox enables you to select an existing tag to apply from a dropdown list, or to create your own. The predefined tags are Favorites, Hidden, People, Places, Events. You can also select the "Create Tag" option at the bottom of the list to display a dialog in which you can define your own tag, which I do often. This lets me use tags "Mom’s Birthday," "Luke’s Graduation," or any other event-specific tag that will make it easy for me to find a related set of photos in the future. You can define top-level tags like the predefined ones, or define your own tags within one of the predefined tags to help organize your photos in the way that suits you.

- Detect Duplicates: Analyze the photos that you are importing and import only those that are new. This option is active by default and can be very handy if you previously imported photos and did not remove them from your camera after importing them.

After making any changes to these settings that you want to use, click Copy to import your photos or Cancel to close the dialog without importing your digital photographs. If you click Copy, an F-Spot dialog like the one shown in Figure 18-9 displays your photos have been successfully imported. By default, photos are imported into subdirectories of the Photos directory, which is located in the Pictures directory in your home directory, based on the dates on which the photos were taken. For example, photos taken on February 1, 2010, would be stored in the directory ~/Pictures/Photos/2010/02/01. You can change this location using the Edit menu dialog, which is discussed later in this section.

# Tip

Many digital cameras automatically power down after a short period of time with no activity. This is great for saving battery life, but may cause import failures if the camera powers down while the F-Spot application is waiting for input. If you are importing photos and F-Spot creates files that do not contain your photos, try repeating the import process.

As shown in Figure 18-9, the primary F-Spot window consists of the following areas:

- **Left sidebar:** Lists the tags if no photo is selected, and also provides details about any photo once you select one.
- **Right pane:** Initially displays thumbnails of your recently imported photos.
- **Find bar:** Located above the right pane, this bar enables you to display the sets of photos based on criteria. For example, if you selected or created a tag when importing, you can select that tag in the left sidebar and drag it to the bar to display only photos that have that tag. The Find menu provides other criteria. For example, if you want to display photos with no tags associated, you can select the Find "Untagged Photos" command. You can also use the Find bar by "Rating," "By Date," or "By Import Roll" submenu to display photos by those criteria ("Import Roll" essentially identifies a set of photos that you imported at the same time, using a single import session).
- **Toolbar:** Provides easy access to all F-Spot commands.
- **Menus:** Provide easy access to all-Spot commands.

# Tip

F-Spot doesn't always display its initial layout correctly. If you start F-Spot and don't see the sidebar, you should see a slender bar with three horizontal lines in its center directly to the right of the left window border. Select this bar and drag it to the right to display the left sidebar.

After verifying that an import worked correctly, you can purge the photos from your camera (or other media) by selecting the Edit menu's "Delete from Drive" command.
