# Part II: Ubuntu for Desktop Users

The tabs of this dialog enable you to customize a disk image, add CD-TEXT to your CD, and do some other advanced customization. One that I typically selects is the Advanced's "Normalize Volume Levels" checkbox, which records all of the tracks on the CD at approximately the same volume equalization (EQ) level. (Checking this option requires that you install the normalize equalization package—it is not installed by default.)

After making any customizations that you want, click Burn to begin writing your audio CD. As your CD is created, k3b displays the dialog shown in Figure 16-34.
