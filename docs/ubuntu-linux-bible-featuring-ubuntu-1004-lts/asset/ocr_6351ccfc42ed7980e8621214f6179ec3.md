However, if you're already familiar with another editor that also uses commands consisting of combinations of Ctrl or Esc keys and the standard keys on your keyboard, your fingers are probably used to press-certain keys to execute certain commands. The most common customization needed to Emacs is therefore to change the keys to which commonly used commands are associated.

Although Emacs lets you change key bindings globally or within a specific mode, it is more common to customize a specific key binding so that it works regardless of the mode in which you are using Emacs. The Emacs configuration command to set a key binding is global-set-binding. To set the key Ctrl+z globally to a function that scrolls the buffer up one line rather than attempting to suspend Emacs, you would use the following command in your ~/.emacs file:

```
(global-set-key "C-Z" scroll-one-line-up)
```

In Lisp fashion, you must prefix the name of the function that you are referring to with a single quotation mark. If you are interested, the scroll-one-line-up function is provided as an example in the section entitled "Defining Your Own Functions" later in this chapter.

# Note

When you are specifying key bindings in an Emacs configuration file, the Ctrl is usually represented by \C- and the Esc key is usually represented by \M-.

# Setting Variables

Emacs uses several internal variables to control its behavior. You can modify these variables using the setq command. For example, to cause Emacs to scroll more smoothly in one-line increments, you could add the following line to your ~/.emacs file:

```
(setq scroll-step 1)
```

Another example, the default settings in Emacs cause it to automatically save your files each time you have typed or modified 300 characters. To decrease this value to every 100 changes, you could add the following line to your ~/.emacs file:

```
(setq auto-save-interval 100)
```

# Specifying Modes

As discussed, Emacs provides different key bindings and functions based on the types of files you are using, known as modes. The default mode used by Emacs when you start Emacs without specifying the file that you want to edit is known as the fundamental mode. You may want to customize Emacs to always use a different mode by default, regardless of the name of the file. For example, to make text default each time you start Emacs, you could add the following line to your ~/.emacs file:

```
(setq default-major-mode 'text-mode)
```
