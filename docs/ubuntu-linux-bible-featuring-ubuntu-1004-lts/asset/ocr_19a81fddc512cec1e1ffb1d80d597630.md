The command to set the active_plugins repository to a value that activates the Wobbly
Windows-plugin is something like the following:

```
$ gconftool-2 -s /apps/compix/general/allscreens/options/active_plugins \
[svg,im,jpeg,text,place,png,neg,workarounds,dbus,video,resize,\
core,vpswitch,move,resizeinfo,shift,extraw,decoration,wall,animation.\\nexpo,ezoom,switcher,fade,scaleaddon,scalefilter,wobobbly] \
--type list --type string
```

You must begin and end lists with the characters (& and #) in order to define the lists. Once you
execute this command, reexamining the value of the active_plugins key shows that the
Wobbly Windows-plugin is in the list of active-plugins:

```
$ gconftool-2 -g /apps/compix/general/allscreens/options/active_plugins \
[svg,imjpeg,text,place,png,neg,workarounds,dbus,video,regex,resize,\
core,vpswitch,move,resizeinfo,shift,extraw,decoration,wall,animation.\\nexpo,ezoom,switcher,fade,scaleaddon,scalefilter,wobobbly]
```

You can also confirm that this plug-in is enabled by using the mouse to grab the title bar of any
window and move that window. There's always room for JELL-O!

gconftool-2 can be very useful for quickly querying and manipulating GConf settings from
t command line. However, gconftool-2 is probably not the right tool for setting the "right"
GConf keys, identifying possible values, and iterating through multiple settings and values until
y get the effect that you're looking for. I'm a big fan of command-line tools, but I'm no pur-
ist— in most cases, graphical tools are more usable than command-line tools, especially when
y need to perform a number of change and test cycles when experimenting with configuration
values.

installed by default on GNOME-based Ubuntu systems. You can start the gconf-editor tool
 any command-line environment. As with gconftool-2, you want to start gconf-editor
