# Using aptitude to Add and
Remove Software

As mentioned earlier in this chapter, the dpkg utility provides the conceptual underpinnings
of much of the Package Management software provided on Ubuntu (Debian) systems. However
power it may be, it is a command-line utility, and therefore does not provide any sort of graph-
cal interface, so dselect utility was developed in order to provide at least a quasi-graphical
interface using terminal-oriented cursor-movement libraries as curses (now curses, for
"new curses"). However, dselect went quite out of its command-line roots and therefore
al provides a command-line interface.

The apt-get discussion earlier in this chapter provides a simpler, higher-level
interface than that provided by the dpkg utility. However, apt-get is YAC (“Yet Another
Command-Line Utility") and therefore does not provide any sort of graphical interface either.
The aptitude application was developed to solve this problem but couldn't quite let go of the com-\mand line itself. Thus aptitude (like dselect before it) provides both a powerful command-
interface and a terminal-oriented, quasi-graphical interface.

Personally, I find terminal-oriented graphical interfaces quaint, at best. I prefer not to use them
unless absolutely necessary, especially when they've been replaced by actual graphical user inter-
faces such as those provided by the Synaptic Package Manager.
