+   • dsContacts A TDataSource component used to establish a server-side master/detail relationship between sqlContacts and sqlTodos.
+   • pvContacts A TDataSetProvider component used to provide contacts and todo records to the client application. Because the contacts and todos are connected in a master/detail relationship, only one provider is needed at the master level (refer to Chapter 7 if you need to revisit server-side master/detail relationships).
