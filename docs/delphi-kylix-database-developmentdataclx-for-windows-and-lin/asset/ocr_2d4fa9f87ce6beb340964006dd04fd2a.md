# # BLOB Support

Like most datasets, dbExpress datasets support BLOB data. BLOB stands for Binary Large Object, and is used to store free-format data (such as images, memos, and the like).

BLOBs can easily become large, so many times you will want to limit the size of the BLOB data that is retrieved from the database to improve query performance.
