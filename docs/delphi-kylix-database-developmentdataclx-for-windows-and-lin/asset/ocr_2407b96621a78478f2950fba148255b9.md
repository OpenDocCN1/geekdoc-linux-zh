# ## Committing a Transaction

After you have issued the appropriate SQL commands inside a transaction, you want to *commit* the transaction. This ends the transaction, and saves any changes made during that transaction. Committing a transaction is as easy as calling TSQLConnection.Commit, which the following line of code illustrates:

```
```
SqlConnection.Commit(TransDesc);
```
```

# ## Rolling Back a Transaction

At times, you start a transaction only to find out later that you don’t want to save the changes made during that transaction. If that should occur, you can *roll back* the transaction rather than committing it. Rolling back a transaction ends the transaction, but all changes made in the context of the transaction are discarded.

To roll back a transaction, call TSQLConnection.Rollback, like this:

```
```
SqlConnection1.Rollback(TransDesc);
```
```
