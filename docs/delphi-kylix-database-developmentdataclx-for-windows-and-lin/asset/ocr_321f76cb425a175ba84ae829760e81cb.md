```
procedure TForm1.DBGrid1KeyDown(Sender: TObject; var Key: Word;
Shift: TShiftState);
begin
if Shift = [] then begin
case Key of
VK_F2: Key := 0;
VK_F9: DBGrid1.EditorMode := True;
end;
end;
end;
```

# NOTE

For this code to work, you must make sure the dgEditing option is set. If it isn't, the grid doesn't enter edit mode even when the code sets EditorMode to True.

# Detecting When a Column Is Resized

TDBGrid provides an OnColumnMoved event, but no OnColumnSized event. This means that you can easily tell when a column is moved, but it’s more difficult to determine when a column is resized.
