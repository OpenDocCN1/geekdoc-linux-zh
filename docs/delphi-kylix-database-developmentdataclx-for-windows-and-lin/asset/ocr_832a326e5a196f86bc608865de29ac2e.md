The **CONMAN** database contains a **CONTACTS2** table, which has a one-to-one correspondence to the **CONTACTS** table. **CONTACTS2** is only in the database for purposes of this example.

The **DataSetProvider1BeforeUpdateRecord** method handles all insert, modify, and delete requests by dynamically building the appropriate SQL statements and sending them directly to the database.

To keep the SQL statements simple, this sample application works with just two fields from the **CONTACTS** table and a single field from the **CONTACTS2** table.
