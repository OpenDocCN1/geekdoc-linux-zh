
## Linux® Routing

Linux Routing is a tutorial-reference written for experienced Linux users and administrators, as well as general network administrators, who want to set up a router instead of using the simple gateways Linux provides. This book gives you a solid grounding in the routing protocols and tools available to you, enabling you to choose which solutions make the most sense for your networks.

Picking up where most Linux titles leave off, Linux Routing familiarizes you with advanced Linux networking tools, popular routing protocols, and the implementation of a router on a Linux machine in a variety of circumstances. In other words, you’ll get the background you need in the context you need to apply it.

Joe "Zonker" Brockmeier has been using Linux since 1996 and has written and contributed to several books about Linux and Open Source technologies. He is a contributing editor for Linux Magazine and UnixReview.com.

Dee-Ann LeBlanc has been involved with Linux since 1994. Through her teaching, she’s come to understand the skills the average Linux user and administrator possess and enjoys helping people get to that next level of knowledge.

Ronald W. McCarty, Jr. has been involved with Linux since 1994, when his first experience with the operating system prompted him to immediately replace the organization’s Intel-based AT&T System V system. Ronald has deployed Linux systems as routers, firewalls, and network servers.

### If you’re looking for routing solutions using Linux, this book will help you:

- Configure gated, a complex but feature-rich routing daemon
- Utilize classless IPv4
- Understand the fundamentals of IPv6
- Generate routing solutions for LANs, WANs, and VPNs
- Discover the rich variety of network and routing tools available with Linux
- Learn to study and optimize your network traffic
- Understand the variety of unicast, multicast, and external routing protocols available
- Locate additional third-party Linux routing solutions
- Utilize traffic monitoring and basic security for three generations of Linux kernels
