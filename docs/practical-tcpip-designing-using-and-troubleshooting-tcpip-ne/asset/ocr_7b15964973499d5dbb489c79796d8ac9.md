MS-Outlook retrieves messages from Hotmail via an internal HTTP connection – you don't have to use a Web browser yourself at all.

Lynx (or a similar tool) is sometimes used embedded within programs to retrieve data via HTTP. For example, if you are installing extra software on a Debian Linux system using a suitably configured version of **APT** (Advanced Package Tool) it compares the version of the package that you have on your CD-ROM with a remote repository; if your CD-ROM version is out of date, APT downloads the latest version using HTTP. All this happens so transparently that if you don't look carefully at the screen, you won't even notice that APT has been using the Web.
