# KIP Appletalk (DDP) in UDP

Appletalk DDP packets encapsulated in UDP datagrams are de-encapsulated and dumped as DDP packets (i.e., all the UDP header information is discarded). The file /etc/altalk.names is used to translate appletalk net and node numbers to names. Lines in this file have the form

```
```
number      name
1.254       ether
16.1        icstd-net
1.254.110   ace
```
```

The first two lines give the names of appletalk networks. The third line gives the name of a particular host (a host is distinguished from a net by the 3rd octet in the number – a net number must have two octets and a host number must have three octets.) The number and name should be separated by whitespace (blanks or tabs). The /etc/altalk.names file may contain blank lines or comment lines (lines starting with a "#").

Appletalk addresses are printed in the form

```
```
net.host.port
144.1.209.2 > icstd-net.112.220
office.2 > icstd-net.112.220
jssmag.149.235 > icstd-net.2
```
```

(If the /etc/altalk.names doesn't exist or doesn't contain an entry for some appletalk host/net number, addresses are printed in numeric form.) In the first example, NBP (DDP port 2) on net 144.1 node 209 is sending to whatever is listening on port 220 of net icstd node 112. The second line is the same except the full name of the source node is known ("office"). The third line is a send from port 235 on net jssmag node 149 to broadcast on the icstd-net NBP port (note that the broadcast address (255) is indicated by a net name with no host number – for this reason it's a good idea to keep node names and net names distinct in /etc/altalk.names).

NBP (name binding protocol) and ATP (Appletalk transaction protocol) packets have their contents interpreted. Other protocols just dump the protocol name (or number if no name is registered for the protocol) and packet size.

NBP packets are formatted like the following examples:

```
```c
icstd-net.112.220>jssmag.2: nbp-lkup 190: "=:LaserWriter@*"
jssmag.209.2>icstd-net.112.220: nbp-reply 190: "RM1140:Laserwriter@*" 250
techpit.2>icstd-net.112.220: nbp-reply 190: "techpit:LaserWriter@*" 186
```
```

The first line is a name lookup request for laserwriters sent by net icstd host 112 and broadcast on net jssmag. The nbp id for the lookup is 190. The second line shows a reply for this request (note that it has the same id) from host jssmag.209 saying that it has a laserwriter resource named "RM1140" registered on port 250. The third line is another reply to the same request saying host techpit has laser-writer "techpit" registered on port 186.
