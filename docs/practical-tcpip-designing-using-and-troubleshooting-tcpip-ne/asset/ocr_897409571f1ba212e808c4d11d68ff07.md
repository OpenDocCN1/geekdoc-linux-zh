# ### 1. Establishing the connection

Before Alice can communicate with Bob over TCP, they must establish a connection. Alice initiates this by connecting to the **telnet** well-known port on Bob. However, the packets Alice and Bob exchange to establish the connection could (as always) get lost, so TCP uses a *three-way handshake* to ensure the integrity of the connection establishment:

+   1. the client sends a packet to the server, with a special “flag” set – the SYN (*synchronize*) flag
+   2. the server replies to the client, sending a packet with both the SYN flag and another flag, ACK (*acknowledge*), set
+   3. the client replies with a packet with the ACK flag set.
