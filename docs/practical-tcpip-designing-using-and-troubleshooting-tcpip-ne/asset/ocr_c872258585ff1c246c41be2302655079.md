# ## How to filter out just the packets you want to look at

By default, **`tcpdump`** prints details of *all* the packets it sees. On a busy network this can generate a huge amount of information, making it very difficult to see what you're looking for. You can tell **`tcpdump`** to show selected packets only. You can combine multiple selection criteria to give a very precise specification of what you want to see.

The tables below are for reference only – they contain a lot more detail than you need to get started. In the body of the book, whenever we use a new **`tcpdump`** feature we'll explain it. For now just quickly look over the range of options available, so you'll have an idea of the full range of **`tcpdump`**'s capabilities.

# ### Selecting by address

| Criteria | Select packets with ... |
| :--- | :--- |
| **host** `a.b.c.d`<br>**host** *name* | this machine as source or destination IP address<br>`tcpdump host 192.0.2.1` |
| **ether host** `a:b:c:d:e:f`<br>**ether host** *name* | source or destination MAC address as specified (Module 5.12)<br>`tcpdump ether host 08:00:20:0C:E4:E1`<br>`tcpdump ether host RUPERT` |
| **port** *num*<br>**port** *name* | this port as source or destination, e.g. HTTP traffic (port 80)<br>`tcpdump port 80` |
| **net** `a.b.c.d` **mask** *nmask*<br>**net** *name* **mask** *nmask*<br>**net** `a.b.c.d`/*numbits* | source or destination IP address in this range<br>`tcpdump net 192.0.2.32 mask 255.255.255.240`<br>`tcpdump net 192.0.2.32/28` |
| **net** *prefix* | again, select packets with source or destination IP address in this range, but using a non-standard notation: it matches if the specified *prefix* matches the IP address, e.g. any of “192”, “192.0”, “192.0.2” match (at least) all the addresses on the 192.0.2.0/24 network, but paradoxically, “192.0.2.0”, which is our real network, address doesn't. The **net** notation is a very quick and handy way to enter a selection, e.g.<br>`tcpdump net 192` |
| **gateway** *name* | packets forwarded via route with hostname name<br>`tcpdump gateway rupert` |
| **broadcast** | packets sent using Ethernet broadcast |
