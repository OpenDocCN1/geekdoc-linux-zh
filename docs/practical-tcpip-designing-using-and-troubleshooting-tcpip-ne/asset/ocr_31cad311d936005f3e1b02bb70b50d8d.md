# ### Introduction

This chapter gives an overview of many network applications and protocols. A common theme is that these applications provide something as a network service (rather than as a facility available only on the local machine, or built in to the end-user application). For the more important ones, we explain briefly how they work, and give an example of their use. The aim is to show you how useful some of these facilities can be, and to give you pointers if you need to explore further.
