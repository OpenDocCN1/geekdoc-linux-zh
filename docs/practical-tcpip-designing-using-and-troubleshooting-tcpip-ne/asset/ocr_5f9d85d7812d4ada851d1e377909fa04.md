# ## Introduction

Windows Networking “browsing” lets your machine automatically obtain a list of other machines, printers, and NT domains on your network, which you can view in Windows Explorer’s **Network Neighbhorld**. The browse system works without any manual pre-configuration. We explain the mechanisms that allow it to do this, and how browse clients interact with browse servers to retrieve the lists of resources on the network.
