# Outlook Express

Figure 11.10 shows Outlook Express version 5.50. Select menu Tools > Accounts > Mail. Enter the details for a new account using Add, or set details for an existing account by highlighting it and clicking on Properties. Enter the POP and SMTP server details in Properties > Servers. (In Properties > Advanced you can set “Leave a copy of messages on server” if necessary (c.f. Module 11.9).)
