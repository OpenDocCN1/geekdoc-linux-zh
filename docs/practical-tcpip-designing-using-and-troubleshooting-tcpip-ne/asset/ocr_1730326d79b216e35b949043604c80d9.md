These little services are ideal for testing; they make use of all your IP routing, DNS name resolution, and TCP and/or UDR, but impose virtually no load on your server machine, and need almost no software. We use these services frequently when installing new machines. We can check that a lot of the network infrastructure is working just by connecting to, for example, the daytime service. These services are also particularly useful when installing a firewall before any server machines have been installed on the LAN (Module 24.8).

To enable these services on Windows-NT, install the Simple TCP/IP Services network service in Control Panel > Network > Services (Figure 17.1). You can control them from Control Panel > Services.
