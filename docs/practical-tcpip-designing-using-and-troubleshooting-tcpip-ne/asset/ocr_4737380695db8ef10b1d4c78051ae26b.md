```
ip.addr == 192.0.2.5
```

and then negate it by inserting the word "**not**" at the beginning:

```
not ip.addr == 192.0.2.5
```

# Follow TCP stream

ethereal has a facility to show you the contents of a whole TCP session. This is especially useful for protocols like HTTP, SMTP, and POP that use plain-text commands and responses.

Instead of manually identifying and selecting all the packets that belong to a session, click on any packet in the session, and then menu **Tools > Follow TCP stream**. This does two things:

+   1. gives you a new window (Figure 13.15) containing a dump of the data in the session.
+   	(The radio buttons at the bottom of the window let you change the format of the dump.)
+   2. limits the display in the packet list to packets that are part of this session.

# Saving a capture session

ethereal, unlike tcpdump, saves the packets on the fly to a temporary file as they are captured. The **File > Save** menu just copies them to a permanent file.

> **Warning:** the **File > Save** and **File > Save As** menu items are inactive until you stop packet collection.

ethereal can read and write capture files in many different formats. You can use this facility to convert a capture file from one format to another. For example, you can convert a file captured using Windows Network Monitor (Module 18.6), and convert it so you can view it using tcpdump, and vice versa.
