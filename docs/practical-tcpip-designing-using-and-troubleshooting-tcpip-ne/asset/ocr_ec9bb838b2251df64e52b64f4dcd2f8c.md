# ## Introduction

E-mail is our first real application – the one that just about everyone uses. For years this was the “killer app” that drove the demand for the Internet. We explain:

+   - how messages are sent and received using the SMTP and POP protocols

+   - how mail clients locate mail servers

+   - how you can send and receive messages manually using **telnet** and avoid using a custom e-mail client, for diagnostic and test purposes.
