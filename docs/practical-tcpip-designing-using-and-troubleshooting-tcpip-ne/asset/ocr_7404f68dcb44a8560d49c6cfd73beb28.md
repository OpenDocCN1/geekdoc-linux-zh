# Figure 25.4  URL database held on firewall

Some firewalls have URL filtering built in. They can either maintain the database themselves (Figure 25.4), or merely detect the URL and pass it to the filter system for validation (Figure 25.5). The advantage of filtering in the firewall itself is the HTTP clients don't have to be configured to use the firewall as an HTTP proxy. Because the firewall sees all traffic, it can look into the HTTP request packets and perform the URL filtering on the fly.

The advantages of Figure 25.4's system over Figure 25.5's are:

+   - you don't need an extra server to run the URL filter
+   - there is no extra network traffic passed so no network traffic at all is required when deciding to accept/reject this URL.

But Figure 25.5's system probably gives you a wider range of filter systems to choose from, not just the one the firewall manufacturer supports.
