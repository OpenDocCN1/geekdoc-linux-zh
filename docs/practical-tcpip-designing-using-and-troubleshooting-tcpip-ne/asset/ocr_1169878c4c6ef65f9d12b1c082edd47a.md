This logon is transparent to you: the system doesn't give a logon dialog and you don't have to enter your username or password. (An exception is when using Windows Explorer > Tools > Map Network Drive and in the **Connect As**: box you explicitly specify a different username to the one you logged on as: you'll be prompted for a password. The same applies when you explicitly specify a username to the `net use` command, as in, for example, `"net use x:/user:test-ntd\\fred \\alacent\\datafiles"`).

Be warned that the above terms are often used loosely: some people use "pass-through authentication" exclusively for the second or third cases above.
