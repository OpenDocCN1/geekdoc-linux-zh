The lower part of Figure 15.2 shows diagrammatically how UDP and TCP are separated in the stack. When a transport protocol passes data down to the IP layer to be transmitted, it sets a special IP protocol number field in the header of the IP packet to say which protocol is being used. The protocol number for UDP is 17. When the packet arrives at the destination machine, the IP layer looks at the protocol number, and passes the packet up the appropriate protocol in the transport layer. This process of taking a single incoming stream (the IP packets from the link layer) and separating it out into its multiple constituent streams to pass up to the transport layer is called demultiplexing.
