# ### 20.2 The logon prompt and local and network logons

+   1. when Windows-NT boots, its starts a logon process called **WinLogon**. WinLogon takes control of the keyboard, so that no Trojan-horse programs can intercept what you type and steal your username and password. Then WinLogon waits until ...
+   2. you type Ctrl-Alt-Del (the *secure attention sequence* or SAS). WinLogon brings up the NT logon window (Figure 20.3).

![](bbox=[0.33, 0.23, 0.68, 0.4])

+   3. you enter your name, password, and domain
+   4. the logon process, **WinLogon**, passes the details entered to the rest of the security sub-system for validation (Figure 20.4).

![](bbox=[0.15, 0.48, 0.85, 0.75])

+   5. a. if you're logging on to the local machine (Figure 20.5), the security sub-system compares the username and password you entered with those in its security database, and allows or rejects the logon accordingly.
+   b. if you're logging on to the domain, the mechanism used is much more complicated (Figure 20.6). The **Netlogon** process on your local PC sets up a secure communications channel with a domain controller and transmits the logon details to the domain controller for validation
