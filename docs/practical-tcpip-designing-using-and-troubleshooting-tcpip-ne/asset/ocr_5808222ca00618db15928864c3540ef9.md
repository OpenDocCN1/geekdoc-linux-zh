# Introduction

In this chapter we build the simplest possible network – two machines connected over a single piece of Ethernet. The chapter is divided into two parts:

+   1. the concepts involved – IP numbers and addressing, netmasks, how Ethernet works, and how TCP/IP uses an underlying Ethernet network
+   2. practical – we cable up a simple network, configure the TCP/IP software, and finally work through potential problems, how to diagnose them and how to fix them.
