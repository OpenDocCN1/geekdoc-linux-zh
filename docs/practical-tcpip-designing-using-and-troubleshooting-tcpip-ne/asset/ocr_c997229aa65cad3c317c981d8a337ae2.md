Most Web server hostnames start with “www.” but this is only a convention. As you see above, the whole name, e.g. www.ibm.com, is treated as just a name in the DNS, so any name that you enter in the DNS, and that has an IP number, can be used as the name of a Web server, e.g.

+   - search.support.microsoft.com
+   - cgi-bin.web.cern
+   - ftp.gnu.org
+   - proxy.belnet.be
+   - ddda.ie

(Our favorite weird Web site name is cr.yp.to.)

The host address field is not case-sensitive, because hostnames in the DNS are not case-sensitive.

# Port number

The port number defaults to HTTP’s well-known port (:80) but any number can be used if the server’s configuration allows it. Other common numbers are :81 and :8080 for connecting to proxy servers.

As the Web interface is used increasingly often for configuring individual applications (e.g. mail servers, database applications, etc.), it’s not uncommon nowadays to have several different Web server applications running on a single machine. Each of course has to listen on its own port – otherwise the client would have no way of specifying which one is required. These “servers” are usually small, special-purpose servers dedicated to the one application, and may even be built into the application itself.
