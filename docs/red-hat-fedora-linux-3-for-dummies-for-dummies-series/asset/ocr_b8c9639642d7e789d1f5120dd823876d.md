Now that you have a printer connected to your Fedora Core computer, you can print from OpenOffice without any further configuration. OpenOffice uses the Fedora Core printer configuration by default. The process is easy:

+   1.  Open a file you want to print: From the OpenOffice desktop, choose File Print. 
+       2.  Choose how much of what to print.

You can choose to print the entire document, individual pages, or a range of pages.
