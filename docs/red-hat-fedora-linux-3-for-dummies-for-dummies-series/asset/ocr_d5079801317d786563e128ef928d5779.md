+   9. Inspect the summary information and click the **Finish** button if you're satisfied with the selection.
+      - If you don't want to repartition with the current choices, click the Back button to return to the preceding window, where you can make new choices.
+      - If you click the Finish button, the new partition-to-be displays in the main window. However, your disk isn't repartitioned until you click the Apply button in the lower-left corner of the PartitionMagic window.
