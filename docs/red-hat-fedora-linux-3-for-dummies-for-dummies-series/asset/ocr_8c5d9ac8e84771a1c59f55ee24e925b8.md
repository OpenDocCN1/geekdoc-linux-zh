Now you need to install the RealPlayer 10 package.

+   1. Double-click your home-directory icon on your desktop.
+   A Nautilus window opens, showing the RealPlayer10GOLD.bin package you just obtained.
+   2. Right-click the RealPlayer10GOLD.bin package and select Open With An Application.
+   3. Click the Install Packages option.
+   4. Click the OK button.
+   5. Enter the root password if prompted.
+   The Completed System Preparation dialog box opens.
+   6. Click the Continue button.
+   RealPlayer 10 is installed. (The installation makes Mozilla aware that it can handle Real Audio.)
+   7. You can test RealPlayer 10 by opening a GNOME Terminal window and entering a command.

+   • For example, the following command plays an interview that Terri Gross did with Linus Torvalds in June of 2001:
+   realplay rtp://audio.npr.org/fa/20010604.fa.rm
+   • Alternatively, you can use Mozilla to browse to the following site:
+   www.npr.org/features/feature.php?wfId=1123917
+   There you can click the Fresh Air Audio link and you'll be prompted to open the stream with RealPlayer.
