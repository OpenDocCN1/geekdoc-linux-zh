# ## Constructing a DNS server

When you know what you want your DNS server to do, it's time to build one. The steps in this section describe how to build an authoritative name server for your private network. The server provides the addresses for the private, nonroutable network we describe in Chapter 15; you don't have to register the addresses with any authority.
