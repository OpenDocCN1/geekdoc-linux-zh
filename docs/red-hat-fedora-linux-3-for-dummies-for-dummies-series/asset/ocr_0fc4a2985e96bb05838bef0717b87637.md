# ## Burning CDs

Back in the 1980s, when vinyl started to melt away under the invasion of CDs, building the factories to create the CDs cost megabucks: back then, it took a huge effort to make a CD. Now, for the handful of bucks it costs to purchase a CD burner, you can build your own personal CD factory. Amazing!

> > **TIP**: A one-time writable CD is referred to as a **CD-R**; a rewritable CD is a **CD-RW**. CD burners look like regular read-only drives and are connected with either an IDE or SCSI interface.

But what can you burn? The answer is pretty much whatever you want: data, software, digital photos, or music. We ll start by burning music.
