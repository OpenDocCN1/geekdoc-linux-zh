# vi Cursor Movement Summary

+   *   To move the cursor around the screen, **vi** must be in **command mode**.

+   *   Press <Esc> to put **vi** in command mode.

+   *   Each punctuation mark, parenthesis, or bracket is treated as a separate **small word**.

+   *   A **big word** includes attached punctuation marks, parentheses, or brackets.

+   *   Most **vi** commands can be modified by numbers.
