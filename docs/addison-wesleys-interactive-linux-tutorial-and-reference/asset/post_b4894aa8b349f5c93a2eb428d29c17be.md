## Terms to Remember

**CPU** Central processing unit; the computer’s “chip.”

**environment** The set of conditions that determines how you are able to use your computer.

**multitasking** The ability of the computer to carry out multiple tasks simultaneously.

**multiuser** The ability of the computer to allow multiple users to share the system’s resources simultaneously.

**open system** A system in which any competent programmer can extend the features of the system by adding new computer code.

**operating system** The program that controls and coordinates all the resources of a computer.

**peripheral** Any hardware device that is added to the computer system. Your keyboard and disk drives are two examples of peripherals.

**security** The aspect of the operating system that protects both the integrity of the system itself and the data that are stored on the system.

## Operating Systems Summary

- The operating system organizes and controls the computer's resources. It plays a major role in defining your computer's working environment.
- Linux is a *multiluser, multitasking* system.
- Linux is an "open source" system.
- Linux will run on both large and small computer systems.
- Linux can be used to control computer networks.
- Linux is available both as a *free download* from many Internet sources and as a low-cost, packaged "distribution."
- Linux supports an effective, *built-in security* system. This security system is designed, first of all, to protect the system itself. Second, and equally important, Linux security protects your data from unauthorized access.

# Linux Environment

## Introduction

As we described in the previous module of the CBT course, Operating Systems, your computing environment is the set of conditions that determines how you interact with the computer. The operating system and the interface—command-line based or graphical user interface (GUI)—together determine your computing environment.

In this module, Linux Environment, we explore further the ways in which Linux functions—sometimes behind the scenes, sometimes right up front—to shape your computing experience.

The behind-the-scenes operator is the kernel. You will see that the kernel is the part of the operating system that manages and controls all the system resources.

Right up front is the shell. You will see that the shell is another major factor in determining how you interact with the computer.

Finally in this section, we present the process, which simply refers to a job or task the computer will perform. As we described earlier, Linux is a multitasking operating system. This means that there are usually several processes running simultaneously. The ability of one process to communicate with another, through interprocess communication, greatly expands the power of the operating system.
