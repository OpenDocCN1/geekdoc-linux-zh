## 需牢记的命令

### 基本光标移动

| 命令 | 描述 |
|---------|-------------|
| h       | 左移 |
| j       | 下移 |
| k       | 上移 |
| l       | 右移 |
| 0       | 行首 |
| $       | 行末 |
| H       | 屏幕高点 |
| M       | 屏幕中点 |
| L       | 屏幕低点 |

### 按词移动

| 命令 | 描述 |
|---------|-------------|
| w/W     | 向前小词/大词 |
| b/B     | 向后小词/大词 |
| e/E     | 向前至小词/大词末尾 |

### 按句子/段落移动

| 命令 | 描述 |
|---------|-------------|
| )       | 向前一个句子 |
| (       | 向后一个句子 |
| }       | 向前一个段落 |
| {       | 向后一个段落 |

### 改变屏幕显示

| 命令 | 描述 |
|---------|-------------|
| Ctrl-d  | 向下半屏 |
| Ctrl-u  | 向上半屏 |
| Ctrl-f  | 向下一整屏 |
| Ctrl-b  | 向上一整屏 |
| Ctrl-e  | 向下移动一行 |
| Ctrl-y  | 向上移动一行 |
| z <Enter> | 将光标所在行移至屏幕顶部 |
| z.      | 将光标所在行移至屏幕中间 |
| z-      | 将光标所在行移至屏幕底部 |

### 其他命令

| 命令 | 描述 |
|---------|-------------|
| nG      | 移至第 *n* 行 |
| Ctrl-g  | 显示状态行信息 |
| Ctrl-l  | 清除状态行 |
| *n*<command> | 添加数字 *n* 以修改许多 vi 命令 |

## vi 光标移动总结

- 要在屏幕上移动光标，**vi** 必须处于 **命令模式**。
- 按 <Esc> 将 **vi** 置于命令模式。
- 每个标点符号、括号或方括号都被视为一个独立的 **小词**。
- **大词** 包括附加的标点符号、括号或方括号。
- 大多数 **vi** 命令都可以用数字进行修改。
