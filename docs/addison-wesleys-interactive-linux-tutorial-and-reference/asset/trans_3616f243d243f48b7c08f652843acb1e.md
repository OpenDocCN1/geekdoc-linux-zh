### 需记住的命令

- `:q` 退出 vi
- `:q!` 不保存文件直接退出 vi
- `:vi` 不引用文件名启动 vi
- `:vi filename` (1) 启动 vi 并打开 filename 以进行编辑。(2) 启动 vi 并创建 filename。

### 入门摘要

- **vi**，代表“可视解释器”，是一个文本编辑器。
- **vi** 存在于几乎每个 Linux 安装中。
- **vi** 有几种变体。
- 要启动 **vi**，请在 Linux Shell 提示符下输入“vi”。
- 通过输入“vi thisfile”，你可以使用名为“thisfile”的文件启动 **vi**。
- 当你启动 **vi** 时，你处于*命令*模式。
- 要输入文本，**vi** 必须处于*输入*模式。
