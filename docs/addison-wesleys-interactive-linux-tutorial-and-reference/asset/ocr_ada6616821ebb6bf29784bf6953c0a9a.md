# Reference features of this book/CD-ROM package

This book can be adopted as an interactive reference on Linux for use in your course. Using the combined CD and text reference options is briefly covered in the walk-through on pages xv, xv, and xvi. We have included three reference sections in the workbook: a Linux Command Reference, a vi Command Reference, and the Glossary. The Glossary lists all the terms used in this course. The two command references provide you with a list and quick review of the commands and special characters that we have presented in both the Linux Made Easy CBT and this guide. They will help you to recall command syntax and related options. The Linux Command Reference lists the commands and special characters that relate to the Linux operating system. The vi Command Reference lists the commands and special characters that relate to the vi text editor. In turn, each of these two references is divided into two parts: Part 1 lists commands by function. Part 2 is an alphabetical listing of commands.

We have made the CD-ROM usable not only as a tutorial but also as a reference. All Linux commands covered can be searched via the Index feature. All terms covered can be found via the Glossary. The Index feature takes you to the place in the CBT where the concept or command is covered.
