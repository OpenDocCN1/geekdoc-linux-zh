# Terms to Remember

+   - **account permissions** Your home directory and file access.
+   - **Message of the Day** A message displayed on some systems when you log in.
+   - **password** A code that, along with your *userid*, you must enter to be able to log in to a system.
+   - **profile** A file containing information that allows you to tailor your Linux environment to suit your needs.
+   - **shell prompt** A character displayed on the screen that indicates where the output of the next key you type will be displayed.
+   - **standard input** Your computer keyboard.
+   - **standard output** Your computer screen.
+   - **userid** A group of characters that uniquely identifies you to the system.

# Commands to Remember

| Command | Description |
| :--- | :--- |
| `chsh` | change shell |
| `chsh -l` | list shells available on your system |
| `cd` | change directory |
| `exit` | log off (on some systems) |
| `logout` | log off (on some systems) |
| `ls` | list your files |
| `ls -l` | list your files with additional information, such as file size |
| `passwd` | change password |
| `ps` | list running processes that you started |
| `ps -A` | lists all running processes |
| `ps -a` | lists all running processes from all terminals at which you are logged in |
| `<Ctrl-C>` | interrupt output |
| `<Ctrl-D>` | log off |
| `<Ctrl-H>` | erase a character |
| `<Ctrl-Q>` | resume a scrolling display |
| `<Ctrl-S>` | stop a scrolling display |
