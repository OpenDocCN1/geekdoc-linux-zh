If positions 4, 5, and 6 look like this—**rwx**—that’s OK. If either the **r** or the **x** is missing, the person who owns the directory must execute the following command *from the parent directory* of *directoryname*:

+   a. Type `chmod g+rx directoryname`

+   b. Press <Enter>

In step a, the directory’s owner will replace *directoryname* with the actual name of the directory.
