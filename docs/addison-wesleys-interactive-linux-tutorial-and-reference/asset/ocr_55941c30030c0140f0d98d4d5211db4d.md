# pwd

|  |  |
|---|---|
| What it does: | Shows you which directory is the current directory (“print working directory”). |
| Syntax: | `pwd` |

# rm

|  |  |
|---|---|
| What it does: | Deletes a file or group of files. |
| Syntax: | `rm _file_list` |
| Example 1: | `rm thisfile thatfile` will delete the two files **thisfile** and **thatfile**. |
| Example 2: | The addition of the `-i` switch to the command line `rm -i supfly` will cause **rm** to prompt you before deleting a file. |

# rmdir

|  |  |
|---|---|
| What it does: | Removes a directory. |
| Syntax: | `rmdir _dirname` |
| Example: | `rmdir newdir` will remove the directory **newdir**. Note that the directory you want to remove must be empty. |

# sort

|  |  |
|---|---|
| What it does: | Rearranges data. |
| Syntax: | `sort _filename` |
| Example 1: | `sort name.list` will alphabetize the data in the file **name.list**. The sorting will be done on the basis of the first character of the line. Lines that begin with uppercase letters will be placed ahead of lines that begin with lowercase letters. “George” will be placed before “alice.” |
| Example 2: | `sort -f name.list` will ignore case. “alice” will be placed before “George.” |
