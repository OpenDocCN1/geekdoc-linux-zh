# Try It Live!

+   1.  Log in to a Linux terminal. Use the **news** command. Is anything happening on the system that you need to know about? Something for you to take action on? (For example, perhaps the system will be down for routine maintenance tomorrow between 7:00 and 7:30 A.M. This may be the kind of information you would need to plan your day. Or there may be a reminder that it’s time to change your password.)
+   2.  Has your watch stopped? Have you forgotten what day this *is*? Use the **date** command to get both pieces of information.
+   3.  Use **who** to find out which of your friends and colleagues are currently logged in to the system.
+   4.  Once you have the information gathered in Exercise 3, use **write** to send one or more of your friends a message. (Apologize for the interruption. Tell them you need to practice!)
+       a. Type `write userid`
+           (Replace *userid* with one of the real *userids* that you uncovered in Exercise 3.)
+       b. Type in a short message. (Be creative!)
+       c. Press `<Ctrl-D>`
+   5.  At the shell prompt, enter:
+       a. Type **write**
+           That’s correct. You just entered the **write** command with no parameters.
