You can pipe output from **man** or **cat** to a printer. If you want to facilitate your use of **man** by memorizing some of its switches, having a hard copy of the list makes that task much easier than having to use the screen to study the output of **man mv**.

You can use a command line similar to

```bash
man mv | lpr
```

or

```bash
cat mv.data | lpr
```

to pipe output to a printer on your system. (As we pointed out in the “Try It Live!” section of **Linux Files**, guidelines concerning printer usage vary from system to system. Many Linux systems will provide **info** as another means for getting help from the system. **info** is a hypertext system. Is grep a search tool or is grep a filter? The answer is "both." Your point of view is likely to determine which term you use. If you think of grep as a utility to "look for stuff," it is a search tool. If you think of grep as a utility for filtering out everything except "the stuff I want," it is a filter.
