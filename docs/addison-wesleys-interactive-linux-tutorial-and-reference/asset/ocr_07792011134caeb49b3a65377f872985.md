# exit

**What it does:** Logout (on some systems)
**Syntax:** **exit**

# find

**What it does:** Finds files.
**Syntax:** **find** *path criteria action*
**Example 1:** **find** *$HOME* **-name supply -print**
In this example, **find** will search your home directory and all subdirectories for the file named “supply” and will display the results on standard output.
**Example 2:** **find . -name *.temp -exec rm {} \;**
In this example, **find** will search the working directory and all subdirectories for all files that have the extension “temp” and delete them.

# grep

**What it does:** Searches for specific text within a file.
**Syntax:** **grep** *string* (text to search for) *file list*
**grep folder ***
**Example 1:** In this example, you search through all the files in the working directory for the string “folder.”
**Example 2:** **grep -i conference ***
In this example, you search through all the files in the working directory for the string “conference.”
The **-i** switch tells **grep** to ignore case.

# --help

**What it does:** Get help with syntax for *command*.
**Syntax:** **command --help**
**Example:** **cp --help** will show you the options and correct syntax for the command **cp**.
