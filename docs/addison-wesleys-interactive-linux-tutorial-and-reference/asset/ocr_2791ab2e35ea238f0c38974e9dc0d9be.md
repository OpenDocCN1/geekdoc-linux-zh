+   g. Press <U>. This will undo all changes to the current line. You will again see the text “I don't noknow. But the sun is shining.”

+   h. Press <q> and press *Enter* to quit *vi* without saving the file. (Note that there is an exclamation point after the “q.”)

Different versions of *vi* implement the undo function in different ways. In some versions of *vi*, undo preserves your last *n* actions. (You can set the value of *n*.) The first press of <u> undoes the most recent action, the second <u> undoes the second most recent action, and so on. This is the way contemporary word processors handle undo. With other versions of *vi*, pressing <u> or <U> repeatedly will cycle you back and forth between two versions of your text. You will need to experiment with your version of *vi* to determine how it implements the undo function.
