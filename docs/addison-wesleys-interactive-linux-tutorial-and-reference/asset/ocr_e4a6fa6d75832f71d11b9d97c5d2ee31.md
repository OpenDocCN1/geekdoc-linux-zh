# Try It Live!

Keep in mind that, as with Linux itself, there are different versions of vi. We have tried to account for these variations, but some of these exercises may not work exactly as we outline.

As we have done in earlier Try It Live! sections of this guide, we will omit step-by-step instructions for some of the exercises. If you need some help refer to the Try It Live! Answer Key at the back of this guide. You will find whatever step-by-step instructions we have omitted in the exercises.

+   1.  Start vi.
+   
+       a. At the shell prompt, type vi
+   
+       b. Press <Enter>
+   
+       Your screen will look similar to Figure 10-1.

![](bbox=[0.15, 0.43, 0.93, 0.66])

On most systems, vi will open from any directory in which you are working. If vi does not start when you type vi at the shell prompt, you will need to get help from your instructor or your system administrator.

In the *Linux Made Easy CBT*, in the module entitled *The vi Tutorial: vi Advanced Commands*, we present several options for quitting vi. As you do these Try It Live! exercises, however, you will need to be able to quit vi, even though you may not have covered that module of the CBT course.
