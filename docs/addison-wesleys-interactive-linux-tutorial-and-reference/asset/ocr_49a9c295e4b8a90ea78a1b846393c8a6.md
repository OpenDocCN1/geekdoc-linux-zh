+   * o Open blank line below current line; **vi** in input mode
+   * O Open blank line above current line; **vi** in input mode
+   * p Put contents of unnamed buffer to the right or below
+   * P Put contents of unnamed buffer to the left or above
+   * r Replace character under cursor and return to command mode
+   * R Replace characters until you tap <Esc>; **vi** in input mode
+   * u Undo last action
+   * U Undo all changes to current line
+   * w Small word forward
+   * W Big word forward
+   * x Delete character under the cursor
+   * X Delete character to the left of cursor
+   * Y Yank entire line
+   * 0 Move cursor to beginning of line
+   * $ Move cursor to end of line
+   * ) Sentence forward
+   * ( Sentence back
+   * ] Paragraph forward
+   * [ Paragraph back
+   * / Find text forward
+   * ? Find text back
