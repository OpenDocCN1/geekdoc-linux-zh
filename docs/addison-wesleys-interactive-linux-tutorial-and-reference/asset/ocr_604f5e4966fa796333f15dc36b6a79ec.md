command syntax The exact characters you need to type to instruct the computer to do something.

compiler The compiler translates the source code into object code so that the computer can process the instructions.

computer network A system in which computers communicate with each other.

computing environment The set of conditions that determines how you interact with the computer. The operating system and the interface—command-line based or GUI—together determine your computing environment.

concatenate Join two or more files together to make one single file.

cp Command to copy a file.

cpio Command to back up files to an archival storage device.

CPU Central Processing Unit. This is the computer's microprocessor. Also known as the chip.

daemon A process started by the kernel.

date Command to display the date and time.

df Command that reports on free space on your hard disk.

directory A unit in the computer's file system, analogous to folders in a physical filing cabinet. Mac users and Windows users (after version 3.X) use the term "folder." The use of multiple directories enables efficient organization of a system's files.

directory structure The collection of directories and subdirectories in which information is stored in a computer.

du Command that reports on the percentage of hard disk in use.

ed Single-line text editor available on many Linux systems.

Emacs Full-screen text editor available on many Linux systems.

environment That set of conditions that determines how you interact with the computer. The operating system and the interface—command-line based or GUI—together determine your computing environment.

execute You execute a file when you run it. You have permission to execute a directory when you have permission to change (cd) to that directory.

exit On some systems, you will use this command to log off.

file mode The file mode indicates who can access any given file and what kind of access is permitted. Also referred to as access permissions.

file system The collection of directories and subdirectories in which information is stored in a computer.

filter A program that takes its data from standard input (the keyboard) and sends its results to standard output (your screen). Along the way from input to output, the filter rearranges, manipulates, or screens your data in some way.
