# Preface

# To The Student

The UNIX operating system, the precursor to Linux, has been in use since the early 1970s. While the various Microsoft operating systems may get more media attention, UNIX is nonetheless a powerful operating system and a major player in the scientific, research, business and Internet communities. Linux is a "UNIX-like" operating system which has been propelled to prominence in the few years since Linus Torvalds began to develop it, as a student project, in 1991. While it has not replaced UNIX, Linux is much less expensive and in many situations is much easier to install and maintain. To gain a professional understanding of the contemporary computer world, a knowledge of UNIX or Linux is essential. While we assume that you have no prior experience with either UNIX or Linux, we do assume that you have some experience with computers and that you are comfortable with the Windows operating system environment.

This book/CD package is a complete course and reference that consists of three parts:

+   1.  *The Linux Made Easy Computer Based Training (CBT)* course software and on-line reference. This software teaches Linux in a self-paced interactive environment. You will learn interactively. With each new command covered, you will have the opportunity to actually use that command in a simulated Linux environment, thus learning by doing. The course software includes fourteen teaching modules, which correspond to the chapters in the book. Each module teaches the topic using explanations, animated examples, and interactive simulations of working in the Linux environment. Commands and concepts on the CD can also be referenced by using the Index and the Glossary, making this an ideal on-line reference for Linux users.

+   2.  The companion workbook and reference. The book includes exercises for each module. This material reinforces concepts learned and allows you to practice at a Linux terminal. The Glossary and Command Reference included with the workbook also make it an ideal ready reference for Linux users.

+   3.  The Assessment program. This testing software randomly generates multiple-choice questions on each module completed. When you have finished the test, the program will evaluate your answers and return a customized report for you, making it easy to determine which modules require further review. The Assessment program also provides a randomly generated final exam on the material covered in the entire course.
