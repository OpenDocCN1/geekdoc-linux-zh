#### 命令 [数字] 对象

你从简短的命令列表中选择一个命令，与较大对象列表中的对象组合。 示例：你*组合*命令列表中的 `<c>` (*修改*) 和对象列表中的 `<w>` (*向前一个小写单词*) 以*生成 `<cw>`* — *向前修改一个小写单词*。 你可以用数字修改大多数此类组合。 示例：在 `<cw>` 中添加 "2" 以生成 `<2cw>` 或 `<c2w>` — *向前修改两个小写单词*。

一些命令也是对象。 你会认识到 `<l>`、`<h>`、`<j>` 和 `<k>` 是光标移动命令。 当这些命令*前面带有数字*时，命令*变成对象*。 `<k>` *单独*意味着*向下移动一行*。 `<2k>` *现在处理对象“向下移动一行”并说，“执行两次”*。 `<w>` *单独*是命令*将光标向前移动一个小写单词*。 `<2w>` *现在处理对象“向前一个小写单词”并说，“执行两次”*。

- `<dd>` 删除整行

## vi 基本操作摘要

- 要输入文本，*vi* *必须处于输入模式*。
- *vi* 的*大多数命令* 是通过使用字母表中的单个字母发出的。
- 大写字母和小写字母代表不同的、有时无关的命令。
- *物理行* 占据一行屏幕。
- *逻辑行* 可能占据多于一行的屏幕。
- 按下 `<Enter>` 结束逻辑行。
- 命令可以操作*对象*。 当在操作对象的命令行中添加数字时，将影响多个对象。
- 传统的 *vi* 不会将文本从一行换行到下一行。
