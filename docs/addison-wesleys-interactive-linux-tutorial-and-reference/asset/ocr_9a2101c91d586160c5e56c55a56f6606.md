# Linux Tools Summary

+   On many Linux installations, you will not have a floppy drive.

+   Before a new floppy disk can be used for backups, it must be formatted.

+   Before a new floppy disk can be used for routine copies and backups, two separate steps are required:
+   
+   (1) format the disk
+   
+   (2) install the file system

+   You must mount a floppy drive to the file system before it can be used.
+   This means that you must tell Linux that the floppy drive is available.

+   You must create a separate subdirectory on the hard drive to act as the host for the floppy drive.

+   You must unmount the floppy drive when you are finished using it.

+   A pipe takes the output of one program and turns it into the input of a second program.

+   A filter takes its data from standard input (the keyboard) and sends its results to standard output (your screen). A filter redirects your data.

+   sort and grep are two Linux filters.

+   Redirection acts like a traffic director. Using redirection, you can indicate the path your data is to follow. For example, you can tell sort to send its output to a file instead of to the screen—its normal destination.

+   man followed by a command name will give you detailed information about that command. This information can run to several pages.

+   command --help will give you a brief description of the syntax for command.

+   info is a hypertext help system available on many Linux installations.

+   The compiler translates the source code into object code.

+   The link editor creates links between the compiled routines in the library and the object code.
