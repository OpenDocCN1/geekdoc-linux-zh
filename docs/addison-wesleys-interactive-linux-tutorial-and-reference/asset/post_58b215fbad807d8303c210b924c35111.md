## Linux Command Reference: Special Characters

### . (single dot)

- What it does: Represents the working (or current) directory.
- Example: In the command line `find . -name file -print` the single dot indicates that **find** should search the working directory for the named file.

### .. (double dot)

- What it does: Represents the parent directory.
- Example: In Figure 15-5, *practice* is the parent directory of *catalog*. The command `cd ..` changes to the directory *practice*.

```bash
$ pwd
/usr/userid/practice/catalog
$ cd ..
$ pwd
/usr/userid/practice
$
```

![](img/cc8b9fd5970716027fba0d0a45c13900_288_0.png)

### ?

- What it does: Represents one, and only one, character.
- Example: The command `ls file?` will list `file1`, `file2`, and `file4`. It will not list `file` or `file23`.

### *

- What it does: Represents any number of characters; including zero.
- Example: The command `ls file*` will list `file`, `file1`, and `file12345`.

### []

- What it does: The square brackets, used in pairs, are used to represent a group of specific characters.
- Example: The command `ls file[134]` will list `file1`, `file3`, and `file4`. The command `ls file[1-4]` will list `file1`, `file2`, `file3`, and `file4`.

## Command Structure Summary

The most effective way to remember many of vi's commands is not to remember individual commands but to remember the command structure. This command structure is presented in Figure 15-6.

| Command List | Object List |
| :--- | :--- |
| `change` | `w` small word forward |
| | `W` big word forward |
| | `b` small word back |
| | `B` big word back |
| `delete` | `)` sentence forward |
| | `(` sentence back |
| | `]` paragraph forward |
| | `[` paragraph back |
| `yank` | `$` to end of line |
| | `0` to beginning of line |
| | `k` current line and line above |
| | `j` current line and line below |
| | `n[object]` affect n objects |

**Figure 15-6 vi's Command Structure**

In the *Linux Made Easy CBT*, we presented a quasi-algebraic expression:

```
command [number] object
```

You choose a command from a short list of commands to combine with an object from a much larger list of objects. For example: You combine `cw` (*change* from the list of commands *with* `cw`> (*small word forward* from the list of objects *to produce* `cw`: *change one small word*
