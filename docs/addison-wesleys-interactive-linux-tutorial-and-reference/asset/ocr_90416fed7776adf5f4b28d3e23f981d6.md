Some commands are also objects. You recognize that `<b>`, `<h>`, `<j>`, and `<k>` are cursor movement commands. When these commands are preceded by numbers, the commands become objects. `<k>` by itself means "Go down one line." `<2k>` now addresses the object "one line down" and says, "Do two of them." `<w>` by itself is the command to move the cursor one small word forward. `<2w>` now addresses the object "one small word forward" and says, "Do two of them."

You might be surprised at some of the commands that can be modified with a number. We urge you to experiment!

There are some special cases that are not recognized in Figure 15-6. Three that we cover in this course are:

+   • `<dd>` delete the entire line
+   • `<cc>` change the entire line
+   • `<yy>` yank the entire line
