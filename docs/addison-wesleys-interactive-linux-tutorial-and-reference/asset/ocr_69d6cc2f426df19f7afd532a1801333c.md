**Note:** Exercises 27 and 28 demonstrate the power of **find**. But we need to issue a strong caution here.

Figure 6-13 shows the results of a **find** command. Imagine the situation shown in Figure 6-13.

```
$ find $HOME -name customers -print
/dir1/customers
/dir2/customers
$ |
```

![](bbox=[0.22, 0.56, 0.83, 0.58])

You can see that there are two files named **customers** in two different directories. Let’s assume that the two files, while using the same name, have totally different information. If you used **find** with **mv** with the intention of moving both files to a third directory—say, **dir3**, **find** would do the following:

+   1. Move /dir1/customers to dir3.
+   2. Move /dir2/customers to dir3.

When /dir2/customers is moved to dir3, the first customers file is overwritten; all information in that file is lost.

For this reason, not only must you exercise great care in using find combined with -exec, it is also wise to precede any intended -exec action with find and -print to be certain you know which files will be affected.
