# Using This Book/CD Tutorial Package as a ready reference of Linux concepts, commands, and terms.

After you have completed the Linux Made Easy package, you may want to refer to the CBT course to review specific material. The flexible menu structure and Index in the CBT course will make it easy to do so. The next section explains using this book/CD package as a reference.

Both the CBT course and the book include reference material. Part 3 of this book and the index tools on the CD-ROM make this book/CD package an excellent reference tool for the Linux user. In the CBT course, you have access to the Index, the Glossary, and the vi Tutorial—a comprehensive, two-part command reference. In this workbook, you have the Glossary; the Linux Command Reference and the vi Command Reference.

Use Part 3 of the workbook to look up commands by their utility or their name.
