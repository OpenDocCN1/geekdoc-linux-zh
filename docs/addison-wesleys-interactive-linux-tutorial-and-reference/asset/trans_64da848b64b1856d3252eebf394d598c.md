# 需要记住的命令

- cal: 显示单月或单年的日历
- date: 显示当前日期和时间
- mail: 向未登录的人发送消息；发送电子邮件
- mesg n: 防止其他用户向你发送 *write* 消息
- mesg y: 启用接收 *write* 消息
- more: 防止长显示内容滚出屏幕
- news: 获取系统新闻
- who: 查找当前谁登录了系统
- write: 向当前已登录的人发送消息

# Linux 信息与通信摘要

- *cal* 让你可以显示单个月份或整个年份的日历。
- *news* 会让你了解系统上正在发生的事情。
- *date* 给你提供时间和日期。
- *who* 告诉你谁登录了系统。
- *write* 让你可以直接向当前登录系统的任何人发送消息。
- *mail* 使你能够发送消息。当你的接收者未登录时，她登录时会收到她有邮件的通知。**mail** 还允许你阅读等待你的消息。
