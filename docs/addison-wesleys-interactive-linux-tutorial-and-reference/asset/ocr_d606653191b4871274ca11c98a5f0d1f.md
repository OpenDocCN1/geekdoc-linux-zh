# Buttons on Each Module's Instructional Pages

Once you have selected a module for study, you leave the Main Menu screen and are presented with that module's menu. From this point, you select the sections you are interested in covering.

There are buttons that appear in the navigation bar located on the right side of the screen as you work through the sections. A button is displayed on the navigation bar if its function is an option at that time.

![](bbox=[0.15, 0.36, 0.225, 0.44])

Each module in the course ends with Review Questions. The QUIZ button allows you to jump directly to these questions. You might want to do this if you already have some knowledge of that particular topic and want to determine whether you know the material well enough to skip that module entirely. A detailed walk-through of the Review Questions feature of the CBT is provided later in this preface. The Progress Report displays your first review quiz score and your most recent Review Quiz score for each module of the CBT course.

![](bbox=[0.15, 0.545, 0.225, 0.625])

The INDEX button will take you to the course Index, from which you go directly to a particular task or concept.

![](bbox=[0.15, 0.655, 0.225, 0.735])

The GLOSSARY button will take you to a comprehensive glossary, which will enable you to quickly review any term we present in the course.

![](bbox=[0.15, 0.755, 0.225, 0.84])

The MENU button will take you to the previous menu. If you are within a section, it will take you to the menu for the corresponding module. If you are at the module menu, it will take you to the Main Menu of the CBT.

![](bbox=[0.15, 0.885, 0.225, 0.96])

The QUIT button will take you to the Exit menu. Always use this method of exiting the CBT. The Progress Report and the Electronic Bookmark, described above, are updated when you exit the course. However, this record keeping will be inaccurate if you do not use the Exit procedure that the course provides. If you use the standard Windows "X" in the upper right-hand corner of the screen to close the program, you will succeed in closing the program, but you won't succeed in keeping track of what you have done.
