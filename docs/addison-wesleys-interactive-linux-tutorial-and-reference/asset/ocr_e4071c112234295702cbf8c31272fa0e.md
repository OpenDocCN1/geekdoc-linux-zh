*Command Reference*

# Introduction

The purpose of this section of the guide is to provide you with a list and quick review of the commands and special characters we have presented in both the *Linux Made Easy CBT* and this guide. It will help you to recall command syntax and related options.

This section is divided into two parts. The *Linux Command Reference* lists the commands and special characters that relate to the Linux operating system. The *vi Command Reference* lists the commands and special characters that relate to the *vi* text editor.

In turn, each of these two parts is divided into two sections: commands by function followed by an alphabetical listing of commands.
