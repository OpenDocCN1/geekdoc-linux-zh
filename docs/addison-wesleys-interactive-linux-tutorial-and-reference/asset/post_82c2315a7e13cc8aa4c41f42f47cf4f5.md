# Instructions for Installing and Using the Computer-Based Training Program and Assessment Tool on the CD-ROM

## System Requirements

- Windows 95 or later
- Minimum screen display resolution should be 800 × 600 pixels with Small Fonts
- Memory: 32 MB RAM
- 15 MB hard disk space
- CD-ROM or DVD drive

## Installation Instructions

1. Start Windows 95/98 or higher and insert the Linux Made Easy CD into your CD-ROM or DVD drive.
2. Choose Run from the Start menu and type `d:\setup` in the command line box, then click OK. (If your CD-ROM drive is not d:, substitute the correct drive letter.)
3. Follow the on-screen instructions.

## Getting Started Instructions

1. Click on Start.
2. Select Programs.
3. Select Edutrends CBTs.
4. Click on Linux Made Easy.

## Tips

Most computers have the correct default settings. If the entire screen is not showing or several characters are cut off from the bottom of some CBT screens, then check your font settings. The Windows font settings should be set to Small Fonts.

## Changing the screen display in Windows 95 or Windows 98

1. Click on Start.
2. Click on Settings.
3. Click on Control Panel.
4. Click on Display icon.
5. Click on the Settings tab.
6. Set resolution. It must be a minimum of 800 × 600 pixels.
7. Click on Advanced. (Do this step in Windows 98 only.)
8. In the Font Size drop-down menu, select Small Fonts and click on OK.

# Using the CBT and Assessment Software

## Introducing Yourself

When you start the CBT course, the first screen you see after the license agreement is the screen on the left, which asks you to enter your name. The name that you enter here is important because, as we will explain in more detail below, the program keeps track of your progress through the course in two different ways: the Progress Report and the Electronic Bookmark. This record keeping is solely for your benefit. You are the only one who will see it. Be certain to remember the name you use—a nickname perhaps. Each time you re-enter the course, you should use the same name so that the program can help you keep track of what you have already accomplished.

## Navigating through the CBT

The CBT is organized much like a book. The Main Menu lists the available modules. By clicking on a module, you get to the sections within that module. By clicking on the sections, you get to the instructional pages, the main text of the CBT.

The Tools menu at the bottom of the screen presents five important options: Progress Report, Electronic Bookmark, Help, Index, and Exit.

The Progress Report is one way in which the program keeps track of your work in the CBT course. It indicates which modules you have started and which modules you have completed. It also records your scores for the Review Questions at the end of each module. For example, if you have completed modules one and two, and you click on Progress Report, you will get the report on the preceding page.

The Electronic Bookmark is another way in which the program keeps track of your work. The Electronic Bookmark acts just like placing a bookmark in your textbook; it remembers the last screen you viewed before you exited the course. Use this option if you want to continue at the exact place you last exited the program.

Detailed instructions for using the CBT course are included in the CBT’s Help screens. For example, if you have a question about using the assessment software, the answer is in the Help section.

![](img/cc8b9fd5970716027fba0d0a45c13900_24_0.png)

The course Index is a very important tool. It functions in much the same way the index in a book does. By selecting an entry in the Index—either a command, a task, or a concept, you can go directly to the section of the course that covers that material. You can make your selection from the Index in one of three ways: Double-click the item, highlight the item and press the <Enter> key, or highlight the item and click on “Go” on the bottom of the screen. If, after calling up the Index, you change your mind and want to return to the screen you just left, click the “Return” button on the bottom of the screen.

The Exit button will take you to the Exit menu. From this menu, you can choose either to Exit the program or to take the *Linux Made Easy Assessment*.

*SPECIAL NOTE ON EXITING THE COURSE*: The Progress Report and the Electronic Bookmark, described above, are updated when you exit the course. However, this record keeping will be inaccurate if you do not use the Exit procedure that the course provides. If you use the standard Windows “X” in the upper right-hand corner of the screen to close the program, you will succeed in closing the program, but you won’t succeed in keeping track of what you have done. Please exit the course using the Exit menu system provided.

## Buttons on Each Module's Instructional Pages

Once you have selected a module for study, you leave the Main Menu screen and are presented with that module's menu. From this point, you select the sections you are interested in covering.

There are buttons that appear in the navigation bar located on the right side of the screen as you work through the sections. A button is displayed on the navigation bar if its function is an option at that time.

![](img/cc8b9fd5970716027fba0d0a45c13900_25_1.png)

Each module in the course ends with Review Questions. The QUIZ button allows you to jump directly to these questions. You might want to do this if you already have some knowledge of that particular topic and want to determine whether you know the material well enough to skip that module entirely. A detailed walk-through of the Review Questions feature of the CBT is provided later in this preface. The Progress Report displays your first review quiz score and your most recent Review Quiz score for each module of the CBT course.

![](img/cc8b9fd5970716027fba0d0a45c13900_25_2.png)
