## vi 中的查找、复制和移动摘要

- 要复制文本，您*复制*（yank）它。
- 要插入您已复制的文本（在 Windows 和 Macintosh 术语中称为“粘贴”），您*放入*该文本。
- *缓冲区*是计算机内存中的临时存储区域。
- vi 使用*未命名缓冲区*来存储您复制或删除的文本。
