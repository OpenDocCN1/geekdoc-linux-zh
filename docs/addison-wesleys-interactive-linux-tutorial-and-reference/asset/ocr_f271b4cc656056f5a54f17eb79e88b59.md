# # Operating Systems

# ## Introduction

Linux is an **operating system**. So what is an operating system? In this first module of the course, we will give you a broad overview of what an operating system is and why your computer has to have one. You will see in what ways the operating system shapes and defines your computing environment. You will see why someone might prefer one operating system to another.

We then move on to a broad overview of the Linux operating system. As we briefly trace the history of Linux, you will see that what began as a student project grew to become an operating system that is making important inroads in the business, scientific, academic and Internet communities. You will see, in fact, that the Internet has played a major role in the development of Linux.

By the end of this module, when someone says that Linux is a **multiuser**, **multitasking** operating system that is designed to function in a networked environment, you will know exactly what that person is talking about.

Please read the learning objectives for this module, which follow this introduction. You will then be ready to begin your exploration of the Linux operating system with the first module of the CBT.

# ## In This Module You Will Learn:

+   - what role an **operating system** plays in a computer.
+   - the meaning of the terms **multitasking** and **multiuser**.
+   - that Linux has built-in security features.
+   - what role Linux plays in computer networks.
+   - a little of the history of Linux.
