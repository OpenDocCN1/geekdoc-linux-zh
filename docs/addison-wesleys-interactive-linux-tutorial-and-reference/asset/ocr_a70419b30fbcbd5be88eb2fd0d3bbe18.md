# Try it Live!

+   1. Log in to your Linux system. List the files in your home directory with `ls`.
+      a. Type `ls`
+      b. Press <Enter>

```
$ ls
. . . . . . [file list]
$
```

Figure 5-1 You Type `ls` at the System Prompt

+   2. List the files in your home directory with `ls -a`.
+      a. Type `ls -a`
+      b. Press <Enter>

The “-a” switch means “all.” As you can see, the `a` switch adds to the display files that are normally hidden—files that begin with a dot. We mentioned one such file in *Day to Day with Linux*. This is the file `.profile`, which you can use to customize your Linux account. Figure 5-2 shows a listing of files you might see. It is likely that some of these hidden files are housekeeping files, created by the system. In the display on your screen, note the shorthand notation—the single dot and the double dot. You remember that the single dot represents the current directory and the double dot represents the parent directory.
