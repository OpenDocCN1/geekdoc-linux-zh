
## Glossary

- **find**: Command that is used to locate files according to criteria that you specify.
- **folder**: A unit in the computer's file system, analogous to folders in a physical filing cabinet. This term is used by Mac users and Windows users (after version 3.X). Linux uses the term *directory*. The use of multiple folders enables efficient organization of a system's files.
- **format**: Prepare a disk (fixed or floppy) to accept files.
- **grep**: Command to locate specific text within text files.
- **group**: With reference to the file mode, group refers to users who are members of the owner's working group. In the file mode, the second set of characters describes the access permissions for group.
- **GUI** (Graphical User Interface): A picture- (graphic) based system through which a computer user communicates with the computer. (Compare “command-line interface.”)
- **--help**: Get a synopsis of the syntax and options for a command.
- **hierarchical file system**: A computer file system that uses a top-down structure. The ‘top’ is the ‘root.’ Beneath the root are directories and their nested subdirectories.
- **HOME**: A shortcut designation for your home directory.
- **home directory**: All Linux users are assigned their own subdirectory under the /home directory. This is called the “home directory.”
- **info**: Command to access the on-line hypertext reference system.
- **interprocess communication**: The manner in which two processes communicate with each other.
- **kernel**: The core component of an operating system. It resides in memory and manages system resources.
- **less**: A utility which gives extensive control over a scrolling screen display.
- **link**: A connection, technically called a “pointer,” from *file1* to *file2*. When *file2* is in a different directory, the link in your directory—*file1*—enables you to read and/or write to *file2* without changing to that directory.
- **link editor**: The link editor creates a link between the compiled routines in the library and the object code.
- **ln**: Command to link files.
- **man**: Command to access the on-line reference manual.
- **mesg n**: This command prevents other system users from sending you *write* messages.
- **mesg y**: This command enables you to receive *write* messages from other system users.
- **message of the day**: Some Linux systems display an opening message when you log in. The message could be, for example, a notice that the system will be going down for maintenance at a particular time. On some systems, the “message” could be a proverb.
- **mkdir**: Command to create a new directory.
- **mode**: The file mode indicates who can access any given file and what kind of access is granted. Also referred to as *access permissions*.
- **module**: Program code that can be added to an existing program (or operating system) to add features to that program.
- **more**: A utility that allows you to control the screen display so that lengthy displays pause when the screen is full.
- **mount**: A floppy drive must be integrated with the file system before it can be used. The process of establishing this connection is called mounting. Also, a command to mount a floppy drive.
- **multitasking**: An operating system is a multitasking system when it provides the ability for users to run more than one program at a time.
- **multiuser**: A multiuser operating system is designed to handle the computing needs of many people simultaneously. In a multiuser environment, usually a networked environment, the operating system enables users to share the system's resources, such as printers, disk storage systems, and communication systems.
- **mv**:
    - Command to rename or move a directory.
    - Command to rename or move a file.
- **network**: A system in which computers communicate with each other.
- **news**: Command to display updated information regarding your Linux system.
- **open system**: A computer system in which any competent programmer can add new features.
- **operating system**: The computer program that controls the computer's fundamental operations. Linux, UNIX, DOS, Windows, and the MacOS are examples of operating systems.
- **ordinary file**: A file that contains text, data, or a program.
- **other**: With reference to the file mode, other refers to users who are not in the owner's working group. In the file mode, the third set of characters describes the access permissions for other.
- **owner**: The person who created the file. With reference to the file mode, the first set of characters describes the access permissions for the file's owner. The owner is also called the user.
- **password**: To gain access to a Linux installation, you have to log in. When you log in, you must identify yourself with two codes. A password, the second of these codes, is required on most systems. (The first code is the userid.)
- **permission**: Refers to the right to have access to something on a Linux system. That something is often a particular file. But permission can refer to other aspects of the system—for example, permission to send a write message to another user.
- **pipe**: A pipe takes the output of one program and turns it into the input of another program. It is one of the basic types of interprocess communication.
- **pipeline**: Linux users often process data through a series of commands connected by pipes. This is referred to as a *pipeline*. The following command line uses a pipeline: `who | sort | tee who_list | more`. The output of the *who* command is piped to the *sort* command. The output of *sort* is piped to the *tee* command. *tee* sends the sorted output of *who* both to standard output (the screen) and to a file named *who_list*. Finally, the output of *tee* is piped through *more*, which makes certain that the display does not scroll off the screen before you have a chance to read it.
- **process**: A job or task that the computer carries out.
- **process identification number (PID)**: A number assigned by the kernel to each process.
- **.profile**: The information in this file—which is run automatically when you log in to a Linux system—allows you to tailor your Linux environment to suit your needs.
- **pwd**: Print working directory. Tells you what your working directory is.
- **queue**: A holding area that stores processes waiting for execution by the system. It is one of the basic types of interprocess communication.
- **redirection**: Linux expects to get its input from standard input (the keyboard). It is common, however, to tell Linux to take its input from some other source—from a file, for example. It is equally common to tell Linux to send its output someplace else—to a file, for example. When either standard input or standard output is not used, you are using *redirection*.
- **rm**: Command to delete a file.
- **rmdir**: Command to remove a directory.
- **root**: In a hierarchical computer file system, the root is the topmost level of the system.
- **script**: A file that contains commands to the operating system. When the file is executed (run), the commands run automatically.
- **shell**: The shell is the particular operating environment in which you work. It is your interface with Linux.
- **shell prompt**: A character displayed on the screen which indicates where the output of the next key you type will be displayed.
- **shell script**: A file that contains commands to the operating system. When the file is executed (run), the commands run automatically.
- **signal**: A code transmitted from one process to another as a means of inter-process communication.
- **sort**: A filter that rearranges data according to criteria you specify. Used, for example, to alphabetize or arrange data in numerical order. Also, the command to sort.
- **spawn**: The creation of a new process.
- **special file**: A file that enables communication with a device, such as a printer or a hard drive.
- **standard input**: Your computer keyboard.
- **standard output**: Your computer screen.
- **subdirectory**: In a hierarchical file system, a directory that is below another directory. Analogous, in a physical filing cabinet, to putting one folder inside another folder.
- **superuser**: The system administrator. The superuser has unrestricted access to the entire system. The superuser’s access is not limited by permissions.
- **switch**: One or more characters used with a command; affects the output of that command.
- **sync**: The command to be certain that files are written to the hard disk.
- **syntax**: The exact characters you need to type to instruct the computer to do something.
- **tar**: Command to back up files to an archival storage device.
- **tee**: A utility that creates simultaneous output to a file and to the screen.
- **time slicing**: The manner in which multiple processes appear to be running simultaneously. The running processes share the CPU as each gets a ‘slice’ of processing time from the CPU.
- **unmount**: A floppy drive must be disconnected from the file system when you have finished using it. The process of separation is called unmounting. Also, the command to unmount a floppy drive.
- **user**: The person who created the file. With reference to the file mode, the first set of characters describes the access permissions for user. The user is also called the owner.
