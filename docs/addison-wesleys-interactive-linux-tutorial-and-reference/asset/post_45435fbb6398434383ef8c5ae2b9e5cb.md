## Commands to Remember

### Input Mode Commands

- a: insert text one character after character position
- A: insert text at end of line
- i: insert text at cursor position
- I: insert text at beginning of line
- o: create blank line below current line
- O: create blank line above current line

## Command Structure

The most effective way to remember many of *vi’s* commands is *not* to remember individual commands but to remember the *command structure* instead. This command structure is presented in Figure 12-37.

| Command List | Object List |
|---|---|
| w | small word forward |
| W | big word forward |
| b | small word back |
| B | big word back |
| ) | sentence forward |
| ( | sentence back |
| } | paragraph forward |
| { | paragraph back |
| $ | to end of line |
| 0 | to beginning of line |
| k | current line and line above |
| j | current line and line below |
| n[object] | affect n objects |

Figure 12-37 vi’s Command Structure

In the Linux Made Easy CBT, we presented a quasi-algebraic expression:

#### command [number] object

You choose a command from a short list of commands to combine with an object from a much larger list of objects. Example: You *combine* `<c>` (*change*) from the list of commands with `<w>` (*small word forward*) from the list of objects to *produce `<cw>`* — *change one small word forward*. You can modify most such combinations with a number. Example: Add "2" to `<cw>` to produce `<2cw>` or `<c2w>` — *change two small words forward*.

Some commands are also objects. You recognize that `<l>`, `<h>`, `<j>`, and `<k>` are cursor movement commands. When these commands are *preceded by numbers*, the commands *become objects*. `<k>` *by itself* means *go down one line*. `<2k>` *now addresses the object “one line down” and says, “Do two of them.”* `<w>` *by itself* is the command to *move the cursor one small word forward*. `<2w>` *now addresses the object “one small word forward” and says, “Do two of them.”*

There are some special cases that are not recognized in Figure 12-37. Three that we cover in this course are:

- `<dd>` delete the entire line
- `<cc>` change the entire line
- `<yy>` yank the entire line

Note that the *yank* command is covered in the next module: *Find, Copy, and Move* with *vi*. We include it here to be able to present, in one place, a complete command structure reference.

## vi Basic Operations Summary

- To enter text, *vi* *must be in input mode*.
- Most of *vi* *commands* are issued by using single letters of the alphabet.
- Uppercase and lowercase letters represent different, and sometimes unrelated, commands.
- *A physical line* occupies one screen line.
- *A logical line* may occupy more than one screen line.
- Press `<Enter>` to end a logical line.
- Commands can operate on *objects*. When a number is added to a command line that operates on an object, more than one object will be affected.
- Traditional *vi* does not wrap text from one line to the next.
