
- **rm -i** permits you to say “yes” or “no” to each file when you delete a group of files.
- **mv** has two functions in relation to files:
  - (1) rename files;
  - (2) move files to a different directory.
- The [ ] brackets allow you to specify a group of files that will be affected by a command.
- **ln** allows you to create links between files. This permits access to a file that may actually reside in some other directory.
- **cat** has two uses:
  - (1) view a text file;
  - (2) join two or more text files into one file (concatenate).
- **find** is used to locate files.
- **grep** is used to locate text.
- **lpr** sends your file to a printer.
- **sync** tells Linux to make certain that all files are properly stored on the hard disk.

In this instance, the system is telling you that to use **mv**, you must indicate file arguments. The system is also telling you how you can get more information.

**ls** is a command that does not require any arguments. But there are many switches you can use with **ls** to tailor its output to your needs. If you use **help** to get a list of the switches, on most systems the **help** information will consist of more than one screen and will scroll by before you can read it. In the next three exercises, you will use different methods to solve this problem.

2. In this exercise, you will pipe the output of `help` through `more`.
   - a. Type `ls --help | more`
   - b. Press <Enter>
   - c. Press <Enter> to scroll down one screen line.
   - d. Press the <Space Bar> to scroll one full screen.
   - e. Press the <Space Bar> two times to reach the end of the file.
   - You see that when `more` has displayed the end of the file the command prompt reappears.

3. In this exercise, you will again pipe the output of `help` through `more`. This time you will return to the command prompt before the entire file has been displayed.
   - a. Type `ls --help | more`
   - b. Press <Enter>
   - c. Press the <Space Bar> to scroll down one screen.
   - d. Press the letter q to quit and return to the command prompt.
   - You can also stop the output of `more` by using <Ctrl-C>.

4. In this exercise, you will pipe the output of `help` through `less`.
   - a. Type `ls --help | less`
   - b. Press <Enter>
   - Note that the screen clears, and the display begins at the top of the new screen. You see that `less` indicates in the lower left corner of the screen which line numbers of the text are displayed. You can use a variety of cursor-movement keys to move through this display.
   - c. Press <Enter> to move down one line.
   - d. Press <Page Down> to scroll down one screen.
   - e. Press the <Up Arrow> a few times to scroll back toward the beginning of the file.

Note that, unlike **more**, when you reach the end of the file with **less**, you do not return to the command prompt. This gives you the option to continue scrolling back through the file—an option that you do not have with **more**.

- g. Press the letter **q** to quit and return to the command prompt.
  - On most systems, you cannot use <Ctrl-C> to quit **less**.

As you saw in this module of the CBT course, **less** gives you many options for controlling the output.

**help** gives you a list of the various switches, or arguments, that you can use to modify the output of a command. Even when the output is lengthy, as it is with `ls --help`, the information that **help** provides is terse and usually limited to command syntax.

While **man** files are also terse, they nonetheless provide a great deal more information about the command. For example, you will find not only a list of switches but more detail about the effect of each switch. However, the **man** files are not intended to be instructional in the sense that the *Linux Made Easy* is instructional. A certain amount of knowledge about, and experience with, Linux is often assumed. Still, reading the **man** pages can often be illuminating.
