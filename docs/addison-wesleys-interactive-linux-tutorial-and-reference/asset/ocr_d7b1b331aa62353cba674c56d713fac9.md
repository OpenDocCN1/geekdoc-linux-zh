+   :e! filename
+   	1. Open filename for editing even though current file has unsaved changes. 2. Create filename even though current file has unsaved changes.

+   :e#
+   :e#
+   Switch to other file.

+   :e!
+   :e!
+   Switch to other file even though current file has unsaved changes.

+   :nG
+   Move cursor to line number n.

+   :q
+   Quit vi.

+   :q!
+   Quit vi even though current file has unsaved changes.

+   :vi
+   Start vi with an empty buffer.

+   :vi filename
+   (1) Start vi with existing file filename. (2) Start vi and create filename.

+   :w
+   Save (write) file.

+   :wq
+   Save current file and quit.

+   :y object
+   Yank object.

+   :z <Enter>
+   Move line cursor to on to top of screen.

+   :z.
+   Move line cursor to on to middle of screen.

+   :z-
+   Move line cursor to on to bottom of screen.

+   :ZL
+   Save changed files and quit.

+   :! command
+   Access the Linux shell and execute command

+   :"cyI
+   Yank (copy) a paragraph back into named buffer "c. (Notes: (1) The letter "c" may be replaced by any letter of the alphabet. (2) The action may be d (delete) rather than yank. (3) The { may be replaced by any vi object. (4) The lowercase reference ("c") replaces whatever was in the buffer. (5) An uppercase reference ("C") appends to the buffer.)

+   :"cp
+   Put the contents of the named buffer to the right or below.

+   :"cP
+   Put the contents of the named buffer to the left or above.

+   :"1pu.u.u.
+   Cycle through the nine numbered buffers.
