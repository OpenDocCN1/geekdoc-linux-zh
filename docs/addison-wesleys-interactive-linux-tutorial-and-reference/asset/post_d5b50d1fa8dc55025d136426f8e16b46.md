## Terms to Remember

**daemon**: A process started by the kernel.

**interprocess communication**: Pipes, signals and queues are three important methods by which processes communicate with each other.

**kernel**: The core component of an operating system. It resides in memory and manages system resources.

**PID**: Process identification number.

**pipe**: A pipe takes the output of one process and turns it into the input of another process.

**process**: A job or task that the computer carries out.

**queue**: A holding area that stores processes waiting for execution by the system.

**shell**: The particular operating environment in which you work. It is your interface with Linux.

**signal**: A code transmitted from one process to another as a means of interprocess communication.

## Linux Environment Summary

- The **Linux kernel** is a resource manager—managing both memory usage and disk storage and responding to requests from system users and outsiders.
- Linux is a multitasking system. Many programs can run simultaneously.
- A **process** is a set of tasks to be done. It is a program.
- The **kernel** assigns a **PID** to each running process and makes certain that these processes do not interfere with each other.
- **Daemons** are housekeeping processes started by the kernel.
- The **shell** is a program. It defines the environment in which you work. The shell determines how you and the system will communicate and interact.
- Linux provides several different shells.
- bash is a common shell.
- When you log in to a Linux system, Linux gives you your own copy of the shell. Your shell is a separate process.
- The various processes that you begin fall under the umbrella of your shell, which is your master process.
- When you log off, all unprotected processes that you leave unfinished are terminated. To protect a process, you must indicate—at the time that you begin it—that that process is to continue after you log off.
- Processes communicate with each other through **interprocess communication**.
- Three important methods of interprocess communication are **signals**, **pipes**, and **queues**.
