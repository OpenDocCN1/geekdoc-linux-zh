# ## Edit and Undo Commands

| | |
| :--- | :--- |
| x | Delete character under cursor |
| X | Delete character to left of cursor |
| r | Replace character under the cursor and return to command mode |
| R | Replace characters; remain in input mode until `<Esc>` |
| u | Undo last change |
| U | Undo all changes to current line |

# ## Find Commands

| | |
| :--- | :--- |
| / | Find text forward |
| ? | Find text back |
| n | Repeat the find in the same direction |
| N | Repeat the find in the opposite direction |

# ## Buffer Commands

| | |
| :--- | :--- |
| y [number] object | Yank [optionally, some number of] **object** [s] into the unnamed buffer |
| p | Put the contents of the unnamed buffer to the right or below |
| P | Put the contents of the unnamed buffer to the left or above |
| “ay | Yank a sentence forward into named buffer “a |
| “dp | Put the contents of named buffer “d |
| “1pu.u.u.| Cycle through the numbered buffers. (The dot command puts the contents of the next numbered buffer.) |

# ## Other Commands

| | |
| :--- | :--- |
| J | Join line cursor is on with line below |
| G | Move cursor to the last line of the file |
| nG | Move cursor to line *n* |
