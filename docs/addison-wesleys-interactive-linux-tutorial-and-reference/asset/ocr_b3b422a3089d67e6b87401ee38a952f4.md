# The vi Tutorial

The vi Tutorial has two special features that we believe you will find very handy: the Command Summary List and the Function Summary List. Here you will find, in two different formats, a quick roundup of all the vi commands that we present in the course.

The Command Summary groups vi commands by command category.

The Function Summary is an index of actions you can accomplish with vi and the command corresponding to that action.

# Navigating through the Assessment Program

The Assessment program will provide you with important feedback on your understanding of the material you have covered. The assessment program randomly generates multiple choice questions from a large test bank of questions. Each student receives a different test with each use.

![](bbox=[0.09, 0.53, 0.56, 0.78])

The Assessment program is easy to use. The instructions are included on the bottom of each screen in this assessment software, just click on your choice in the space provided and you will automatically go to the next question. You may move up and down by using the arrow keys and Page Up and Page Down keys. You can use the mouse to easily move around the screen and click on your answers.

You can build your own test. You can choose to be tested on all modules, or select specific modules for inclusion in the test. The questions will be randomly generated for your own personalized test. This makes it an ideal assessment tool.
