You may want to save the output from **man** so that you can compare available switches between two different commands—say, **rm** and **mv**. If you redirect the output from **man** into a file, you will have that output to manipulate as you choose.

+   6. Redirect the output from **man** to the file **mv.data**. You will put the file in your directory **practice**.
+       a. Type `cd $HOME/practice` to be certain you are in the practice directory.
+       b. Press `<Enter>`
+       c. Type `man mv > mv.data`
+       d. Press `<Enter>`
