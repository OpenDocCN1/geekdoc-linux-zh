# # Find, Copy, and Move with vi

# ## Introduction

In the previous modules in this tutorial, you moved into what we might call vi\'s "ground floor"; interesting, but maybe not much more advanced than pencil and paper.

In this module, we move you "upstairs" into some parts of the vi terrain that pencil and paper can never occupy. The ability to find text in a lengthy file is a feature that you will use often. And the ability to copy and/or move text is so important that no one would even consider using a text processor that didn\'t offer this feature.

# ### In This Module You Will Learn:

+   - how to find text in your file.
+   - how to copy text and move it.
