

# 模块 13：使用 vi 进行查找、复制和移动

1. 切换到你的 *practice* 目录。
   - a. 输入 `cd $HOME/practice`
   - b. 按 `<Enter>`

2. 使用 *vi* 打开文件 *nowtime*。
   - a. 输入 `vi nowtime`
   - b. 按 `<Enter>`

4. 在这个练习中，你将搜索 "is"。
   - a. 按 `<G>`
   - b. 按 `<$>`

5. 在这个练习中，你将搜索 "right."。
   - a. 按 `<1G>`

6. 在这个练习中，你将使用 `<yws>` 向前复制一个小单词。
   - a. 按 `<1G>`
   - b. 按 `<u>`

8. 在这个练习中，你将使用 `<y2>` 向前移动（yank）两个句子。
   - a. 按 `<0>`
   - b. 按 `<3k>`
   - c. 按 `<G>`
   - d. 按 `<o>`

9. 在这个练习中，你将使用 `<y2l>` 向前移动（yank）两个段落。
   - c. 按 `<Ctrl-I>`
   - d. 按 `<G>`
   - f. 按 `<u>`

10. 在这个练习中，你将使用 *put*（放置）命令在删除命令后插入文本。
   - b. 按 `<$>`
   - d. 按 `<0>`
   - e. 按 `<3j>`
   - h. 按 `<2h>` 或按两次 `<h>`。
   - i. 在 "time" 和 "yet" 之间插入一个空格。
     - (1) 按 `<i>`
     - (2) 按 `<Space Bar>`（空格键）
     - (3) 按 `<Esc>`

11. 在这个练习中，你将使用 `<yy>` 移动整行。
   - a. 将光标向上移动一行。
     - (1) 按 <`^K`>
   - c. 将光标移动到文件顶部。
     - (1) 按 <`^G`>
   - d. 在第一行上方创建一个空行。
     - (1) 按 <`^O`>
     - (2) 按 <`Esc`>

12. 不保存文件退出 `vi`。
   - a. 输入 <`^D^D`>
   - b. 按 <`Enter`>
