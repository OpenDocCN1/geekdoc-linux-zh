# ## Introduction

In this module of the *Linux Made Easy* CBT, we introduce what we think is the most important component of this course: interactivity. With each new command that we introduce, we will guide you through a simulation of a Linux system in which you will actually use the command as you learn it. You will learn by doing—not by struggling with rote memorization.

One of the hallmarks of the Linux operating system is security. The first line of defense in this security system is control of who can access the computer system in the first place. So we begin this section with what you must do to gain access to the system: the **login** procedure.

Once you are in, you have an **account**. You will learn what a Linux account is and how it helps you to stay organized. We talked about the command line in the previous module. Here, in the Linux simulations, you will use the command line as you enter commands. You will also learn some of the techniques you can use to control the way in which Linux displays the results of these commands.

Finally, just as you must log in to a Linux installation, you must **log out**. You will do this through another simulation.

# ## In This Module You Will Learn:

+   - how to **log in** to a Linux system.
+   - what the requirements are for a valid **userid** and **password**.
+   - what the **Message of the Day** is.
+   - what your Linux **account** is.
+   - how to enter commands.
+   - how to correct typing errors and manage a scrolling screen display.
+   - how to **log off** a Linux system.
