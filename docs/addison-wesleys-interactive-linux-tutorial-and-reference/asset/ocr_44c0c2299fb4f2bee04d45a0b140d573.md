# Security

# Introduction

In any multiuser environment, security is a concern of paramount importance. In this module we touch briefly on Linux’s first line of defense, the login procedure---keeping out unauthorized users.

The primary focus of this module is the **file mode**. You will learn how to interpret file mode designations and how to change the mode of your files so that you can control both who has access to your files and directories and what kind of access they have.

# In This Module You Will Learn:

+   about the relationship between the login process and Linux security.
+   how the file **mode** determines who has access to your files.
+   how to change the **mode** of a file that you own.
