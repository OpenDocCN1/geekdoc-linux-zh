# Day to Day with Linux Summary

+   To log in to a Linux system, you need a user id and a password. · Your Linux account consists of your HOME directory and your file access privileges. · bash displays the $ prompt. · You signal the computer that you are ready for it to act on your command with the <Enter> key. On some terminals, that key will be labeled <Return> or <CR>. · Delete text with the <Backspace> key or <Ctrl-H>. · You can interrupt most forms of output with <Ctrl-C>. You can stop output from scrolling off the screen with <Ctrl-S>. You can resume the scrolling with <Ctrl-Q>. · Linux is case sensitive. To Linux, the files myfile and MyFile are different files. Most commands are entered in lowercase letters. · To log off the system, use <Ctrl-D>, <logout>, or <exit>. Be certain that the system responds with the login prompt.
