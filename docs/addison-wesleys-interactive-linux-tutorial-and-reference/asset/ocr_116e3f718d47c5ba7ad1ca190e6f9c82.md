+   * **rm -i** permits you to say “yes” or “no” to each file when you delete a group of files.
+   * **mv** has two functions in relation to files:
+       (1) rename files;
+       (2) move files to a different directory.
+   * The [ ] brackets allow you to specify a group of files that will be affected by a command.
+   * **ln** allows you to create links between files. This permits access to a file that may actually reside in some other directory.
+   * **cat** has two uses:
+       (1) view a text file;
+       (2) join two or more text files into one file (concatenate).
+   * **find** is used to locate files.
+   * **grep** is used to locate text.
+   * **lpr** sends your file to a printer.
+   * **sync** tells Linux to make certain that all files are properly stored on the hard disk.
