# **vi Command Reference:**

# *Listing by Function*



| Command | Description |
| :--- | :--- |
| `vi` | Start `vi` with no filename reference. |
| `vi filename` | (1) Start `vi` and open `filename` for editing. |
| | (2) Start `vi` and create `filename`. |
| `:q` | Quit `vi`. |
| `:q!` | Quit `vi` without saving the file. |
| `:wq` | Save the current file and quit. |
| `ZZ` | Save all unsaved files and quit. |




| Key | Action |
| :--- | :--- |
| `h` | Left |
| `j` | Down |
| `k` | Up |
| `l` | Right |
| `0` | Beginning of line |
| `$` | End of line |
| `H` | High point of screen |
| `M` | Middle point of screen |
| `L` | Low point of screen |
