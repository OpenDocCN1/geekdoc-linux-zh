# sync

What it does:   Flushes the RAM buffer and writes files to disk.
Syntax:         **sync**

# who

What it does:   Finds out who is currently logged in.
Syntax:         **who**

# write

What it does:   Sends messages to people who are currently logged in.
Syntax:         **write *user* [**tty**]**
Example 1:      **write *janesm*** will let you send a message to user **janesm**.
Example 2:      **write *janesm* tty12** will let you send a message to user **janesm** at terminal number twelve. You use this option when **janesm** is logged in at more than one terminal.
