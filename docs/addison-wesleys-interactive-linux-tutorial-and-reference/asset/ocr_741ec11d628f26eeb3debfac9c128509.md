+   7.  Use cat to read the file **mv.data**.
+   	**a.** Type `cat mv.data`
+   	**b.** Press <Enter>

If the amount of information that man provides on your system is typical, cat mv.data rolled the output right off the screen faster than you can read it. You could use <Ctrl-S> (stop) and <Ctrl-Q> (restart) to control the pace of the output. But this method is an “either on or off” method: Either the output scrolls, or it doesn’t. If you pipe the output thorough **less**, you have control.

+   8.  Use **less** to control scrolling output from a text file.
+   	**a.** Type `cat mv.data | less`
+   	**b.** Press <Enter>
+   	**c.** Press <Enter> to scroll one line.
+   	**d.** Press the <Space Bar> to scroll one screen.
+   	**e.** Press the letter q to quit the display of this file.

You can pipe output from **man** or **cat** to a printer. If you want to facilitate your use of **man** by memorizing some of its switches, having a hard copy of the list makes that task much easier than having to use the screen to study the output of **man mv**.

You can use a command line similar to

```
`man mv | lpr`
```

or

```
`cat mv.data | lpr`
```

to pipe output to a printer on your system. (As we pointed out in the “Try It Live!” section of **Linux Files**, guidelines concerning printer usage vary from system to system. For this reason, we are not including print exercises here. Check with your instructor or system administrator for information about the use of printers on your system.)
