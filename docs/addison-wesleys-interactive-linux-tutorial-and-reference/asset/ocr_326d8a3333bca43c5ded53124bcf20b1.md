Now that you have all of Robert’s supply files in one place and backed up, as well, he asks you to look for specific information in the files. For example, which file holds information about files? Folders? Tape? For this, you will use **grep**, which stands for “**g**lobally search for a regular expression and **p**rint it.”

+   36. Which files have information about pens?
+       1.  Type `grep pens *`
+       2.  Press <Enter>

The **grep** command line requires two arguments: (1) the text to search for and (2) which files to search through. The asterisk means “all files.”

The results of your search should be similar to Figure 6-17.

```
$ grep pens *
supply1:writing -- pens.
supply3:correction pens
$ 
```

If your results don’t match what you see in Figure 6-17, perhaps your typing wasn’t as careful as you had intended. If one of the files listed in Figure 6-17 doesn’t appear on your screen, use **cat** to read that file. If you find an error, use **cat > filename** to recreate the file. (You will substitute the actual name of the file for **filename**.)

With some shells, when you type **cat > filename**, if the filename already exists, you will get an error message, something similar to: **cat > filename: file exists**. The system won’t let you overwrite an existing file. In this case, you will have to delete the file using **rm** before you recreate it.
