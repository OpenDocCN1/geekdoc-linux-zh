Did you remember that `P` places to the left or above?

Keep in mind that we reference buffers by placing the double quote mark (“) before the buffer number or name. Omitting the double quote will produce completely different results. For example, `"3p` puts the contents of buffer number three. By contrast, `3p` (without the double quote) will put three copies of the contents of buffer number one.

> There is an easier way to switch between files, provided that your current file has not been changed since the last save. <Ctrl-^> (“Control-Control”) will accomplish the switch. You will probably find, however, that the actual keystroke combination you need to use is <Ctrl-6>. The “^” character is the top “half” of the “6” key.
