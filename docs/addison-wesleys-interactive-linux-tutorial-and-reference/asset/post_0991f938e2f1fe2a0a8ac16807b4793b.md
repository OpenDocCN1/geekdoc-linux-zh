## Navigating through the Assessment Program

The Assessment program will provide you with important feedback on your understanding of the material you have covered. The assessment program randomly generates multiple choice questions from a large test bank of questions. Each student receives a different test with each use.

![](img/cc8b9fd5970716027fba0d0a45c13900_27_2.png)

The Assessment program is easy to use. The instructions are included on the bottom of each screen in this assessment software; just click on your choice in the space provided and you will automatically go to the next question. You may move up and down by using the arrow keys and Page Up and Page Down keys. You can use the mouse to easily move around the screen and click on your answers.

You can build your own test. You can choose to be tested on all modules, or select specific modules for inclusion in the test. The questions will be randomly generated for your own personalized test. This makes it an ideal assessment tool.

When you have finished the test, the program will evaluate your answers and return a customized report for you that you may print. The report is divided into modules that correspond to the modules of the CBT. This makes it easy to focus only on the modules you need to review. It allows you to instantly spot your strengths and weaknesses.

![](img/cc8b9fd5970716027fba0d0a45c13900_28_0.png)

Notice in the report displayed to the left that Sam scored a 60% in Shell Scripts. Therefore Sam would need to repeat the Shell Scripts module.

If the Assessment program indicates weaknesses in your understanding of the material, we urge you to start at the beginning of the module and repeat the material. You may choose to test yourself on any module using the Assessment program as often as you like. The program selects the questions randomly; you will get a different quiz each time.

When you have completed all modules in both the CBT course and the workbook, return to the Assessment program. On the topic selection menu, click on the button labeled "Click here to select all topics." This will create one final test, which will include material from all modules in the course—your "final exam."

## Using the Linux Include Easy Reference System

In this workbook, you can quickly retrieve information about any command presented in this course—for example, **mkdir**. You can use the Glossary, which is the same as the glossary in the CBT course, reprinted here for handy reference.

You can also use the Linux Command Reference in this workbook. The Command Reference presents information about commands in two different ways:

- **First**, commands are grouped according to function. You will find **mkdir** in the "Files and Directories" section.
- **Second**, the commands are listed alphabetically. If you had no clue to the use of **mkdir**, you could use the alphabetical section of the Command Reference to quickly find out what **mkdir** is used for.

You will find the reference sections for the vi text editor in both the CBT course and in this guide. Let's begin with the reference material in the CBT.

On the *vi Tutorial* main menu, you will find one entry for "Command Summary List" and a second entry for "Function Summary List." The Command Summary list groups the various vi commands according to what you use them for. So, for example, in the section entitled "Cursor Movement," you will see that the "S" key moves the cursor to the end of the line. When you consult the alphabetical Function Summary List, scrolling down to the entry "move cursor to end of line" will show you that you use the "$" to accomplish this.

In this workbook, you will find the "vi Command Reference." The vi Command Reference is divided into two parts: "Listing by Function" and "Alphabetical Listing." Using the first part, Listing by Function, you will find—in the section entitled "Basic Cursor Movement"—the "$" and the explanation "end of line." In the second part, Alphabetical Listing, you will find—in the section titled "Single-Character Commands"—the "$" and the explanation "move cursor to end of line."

## Operating Systems

### Introduction

Linux is an **operating system**. So what is an operating system? In this first module of the course, we will give you a broad overview of what an operating system is and why your computer has to have one. You will see in what ways the operating system shapes and defines your computing environment. You will see why someone might prefer one operating system to another.

We then move on to a broad overview of the Linux operating system. As we briefly trace the history of Linux, you will see that what began as a student project grew to become an operating system that is making important inroads in the business, scientific, academic and Internet communities. You will see, in fact, that the Internet has played a major role in the development of Linux.

By the end of this module, when someone says that Linux is a **multiuser**, **multitasking** operating system that is designed to function in a networked environment, you will know exactly what that person is talking about.

Please read the learning objectives for this module, which follow this introduction. You will then be ready to begin your exploration of the Linux operating system with the first module of the CBT.

### In This Module You Will Learn:

- What role an **operating system** plays in a computer.
- The meaning of the terms **multitasking** and **multiuser**.
- That Linux has built-in security features.
- What role Linux plays in computer networks.
- A little of the history of Linux.
