## To The Instructor

Addison-Wesley's *Interactive Guide to Linux by EduTrends* provides a basic introduction to Linux. Its goal is to give students user-level familiarity with the operating system and then serve as a reference book/CD. This package assumes no prior knowledge of Linux. CBT and Assessment software runs in the Windows environment. It assumes basic familiarity with Windows and with basic computer operation, including how to load the CBT program from the CD. Instructions for installing are included in the next section and in a readme file on the CD.

There is a variety of ways in which this book/CD package can add value to your course. If you are teaching a course in which the Linux operating system is not the focus, you may find that assigning this package for independent study will provide the necessary material to supplement your course. If the Linux operating system is the focus of your course, you can use this package as the main text or as an introduction to more in-depth material that you present in class. There are probably as many different ways to use this material as there are those of us who teach.

## Different Linux Configurations

There may be some aspects of the configuration of your Linux installation that will affect the student's ability to complete some of the Try It Live! exercises. If such is the case at your institution, please provide your students with the necessary information so that they will have a satisfying and successful experience with these exercises.

## Pedagogical Features of this book/CD-ROM package

The walk-through of using the book/CD-ROM package in “To the Student” gives a brief introduction to the basic components of the CD and the text as well as how they work together. This is a listing of particular features within the CD and text.

The Linux simulations on the CBT give students a pedagogical environment in which to first practice using Linux. Typing errors are caught immediately, and the student is prompted for the correct key.

After completing a module on the CBT, the student will then go to the Try It Live! material for the corresponding chapter in the book. In this chapter the student will be guided through a series of step-by-step exercises at a Linux terminal.

To help reinforce concepts just learned in the module, there are *hints that accompany some exercises*.

This graphic calls the student's attention to a Hint, which may help to complete a particular exercise.

To check for understanding or draw connections between concepts, there are **challenge questions**. These are posed, answered, and then *re*-explained for the student.

This graphic points out a challenge question, which probes understanding of the accompanying material. Both the question and the answer to the question are identified by this graphic.

Starting with the Try It Live! exercises in Module 8, Security, the student is asked to rely on what he or she has learned in previous modules of the course to complete these exercises. The student is directed to complete a task but is not given the step-by-step instructions. This workbook/CD-ROM package is meant as a self-paced tutorial. For this reason, in Part 4 of this book we provide a Try It Live! **Answer Key** so that students who have difficulty with a certain nunguided task can get the help they need.

Following the Try It Live! exercises, there are series of questions in the **Check Yourself** and **Match** sections. These provide additional review before moving on to the final assessment (on the CD-ROM) for each module. (Answers to these questions are provided exclusively to professors using this text/CD-ROM package for their course. Please contact your Addison-Wesley representative for further information.)

*Linux Made Easy* provides several opportunities for the student to test himself or herself as he or she learns the material. On the CBT CD-ROM, there are **Check-Up Questions** in most of the modules and **Review Questions** at the end of each module. In the workbook, there are the **Check Yourself** and **Match** sections. Moreover, in omitting instructions for some of the steps in the Try It Live! exercises, students must recall what they already learned—in effect, another test situation.

In addition to these testing opportunities, the CD-ROM includes an **Assessment** program. The Assessment program randomly generates questions for each module in the course. The Assessment tests mastery of one or more modules. A student may select questions for one module, multiple modules, or all modules. The student may use the Assessment program as often as she or he wishes. The student will be presented with a different selection of questions each time she or he runs the program.

In the Assessment program, the student identifies himself or herself by entering his or her name. There is also a place for the student to enter an ID number. You may choose to have your students use this box to enter a student ID number, a class number, or some other piece of information. When the student has finished the test, the program will evaluate her or his answers and produce a personalized report. This report directly corresponds to the modules in the CBT, making it easy to see which modules the student has mastered and which modules require further study. It may be useful to you to have your students print this report and hand it in to you. This printed report can be identified by both student name and ID number. Based on the student's score, they may need to review some of the material covered in this guide and the CBT.

## Reference features of this book/CD-ROM package

This book can be adopted as an interactive reference on Linux for use in your course. Using the combined CD and text reference options is briefly covered in the walk-through on pages xv, xvi, and xvii. We have included three reference sections in the workbook: a Linux Command Reference, a vi Command Reference, and the Glossary. The Glossary lists all the terms used in this course. The two command references provide you with a list and quick review of the commands and special characters that we have presented in both the *Linux Made Easy* CBT and this guide. They will help you to recall command syntax and related options. The Linux Command Reference lists the commands and special characters that relate to the Linux operating system. The vi Command Reference lists the commands and special characters that relate to the vi text editor. In turn, each of these two references is divided into two parts: Part 1 lists commands by function. Part 2 is an alphabetical listing of commands.

We have made the CD-ROM usable not only as a tutorial but also as a reference. All Linux commands covered can be searched via the Index feature. All terms covered can be found via the Glossary. The Index feature takes you to the place in the CBT where the concept or command is covered.
