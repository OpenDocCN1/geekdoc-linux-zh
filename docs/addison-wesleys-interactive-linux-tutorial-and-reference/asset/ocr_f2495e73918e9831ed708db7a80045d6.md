+   3.  If the contents of your home directory are a little meager right now, list the */etc* directory.
+       a.  Type *ls /etc*
+       b.  Press <Enter>
+   
+   You are likely to find a long list of files in this directory. List the files with *ls -a*.
+   
+       c.  Type *ls -a /etc*
+       d.  Press <Enter>

> Remember that, if either **ls** or **ls -a** produces a file list that scrolls off the screen, you can stop the scrolling with <**Ctrl-S**> and resume the scrolling with <**Ctrl-Q**>.

+   4.  You can also *pipe* the results of **ls** through **more**. We cover pipes a little later in the course, but the procedure is simple enough to use right here. At the shell prompt:
+       a.  Type **ls /etc | more**
+   ( *Be sure to leave a space on either side of the pipe symbol, |.* )
+       b.  Press <Enter>
+       c.  Press <Enter> again to scroll down one line.
+       d.  Press the <Space Bar> to scroll down one full screen.
