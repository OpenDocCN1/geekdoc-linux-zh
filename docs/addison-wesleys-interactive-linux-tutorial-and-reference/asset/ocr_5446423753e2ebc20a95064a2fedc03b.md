# **Commands to Remember**

| Command | Description |
| :------ | :---------- |
| cat     | (1) read a text file; (2) create a text file; (3) concatenate files; (4) append text to a file |
| cp      | copy a file or group of files |
| cpio    | back up files |
| -exec   | used to specify an action to be performed on files located with the **find** command |
| find    | find files |
| grep    | search for specific text within a text file |
| ln      | link files |
| lpr     | print a text file |
| mv      | rename a file |
| -print  | used with the **find** command to tell the system to display the results on standard output |
| rm      | delete a file or group of files |
| rm -i   | In deleting multiple files, the system prompts you to confirm the deletion of each file. |
| sync    | flush the RAM buffer and write files to disk |
| tar     | back up files |

# **Special Characters**

| Character | Description |
| :------- | :---------- |
| ?        | represents one single character |
| *        | represents multiple characters |
| [ ]      | group files |

# **Linux Files Summary**

+   * Linux supports three types of files. Directories and ordinary files are the types you will deal with most of the time.
+   * Filenames can be up to 255 characters long.
+   * Nonalphanumeric characters can be used in any position in the filename.
+   * Filenames that begin with a dot are normally hidden when the directory is listed. Use `ls -a` to list hidden files.
+   * Linux recognizes the * and ? wildcards.
+   * **cp** is the copy file command.
+   * **rm** is the delete file command.
