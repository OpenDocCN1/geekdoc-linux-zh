**Figure 4-1 System Prompts You for Required Arguments**

The `write` command requires *arguments*. When you fail to enter the arguments for a command that requires them, the system will usually remind you what arguments are required. In this case, the system reminds you that you must at least enter the name of the recipient of the message. The brackets around `[tty]` tell you that specifying the terminal that your recipient is logged in to is optional. If Robert is logged in at more than one terminal, you can tell the system which terminal to send the message to.
