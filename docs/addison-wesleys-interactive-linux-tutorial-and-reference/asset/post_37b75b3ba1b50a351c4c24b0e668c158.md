### Terms to Remember

**shell script** A file that contains a series of instructions to the operating system.

**variable** An area in the computer's memory that acts as a temporary storage compartment for values (content, data or information) that you create.

### Commands to Remember

If your system doesn't run an executable shell script when you type the name of the script, you can use one of these command options to run the script.

- .scriptname
- *scriptname*
- sh *scriptname*

## Shell Scripts Summary

- A shell script is a file that contains a series of commands for Linux to execute.
- Shell scripts can be very simple or very complex. Using variables in a shell script often increases the usefulness of that script.

## Getting Started with vi

### Introduction

Text files are an everyday fact of life in the Linux environment. Whether you're sending e-mail or writing messages, creating shell scripts or other programming code, updating a text file, or keeping simple to-do lists, it is likely that you will work with text files on a regular basis.

**vi** is found on most Linux installations. While not necessarily easy to learn, **vi** is nonetheless easy to use. In this **vi** module, you will learn how to start and quit **vi** and how to distinguish between its two modes.

### In This Module You Will Learn:

- what **vi** is.
- how to start **vi**.
- the difference between **command mode** and **input mode**.

### Commands to Remember

- `:q` quit vi
- `:q!` quit vi without saving the file
- `:vi` start vi with no filename reference
- `:vi filename` (1) start vi and open filename for editing. (2) start vi and create filename.

### Getting Started Summary

- **vi**, which stands for “visual interpreter,” is a text editor.
- **vi** is found in nearly every Linux installation.
- **vi** comes in several varieties.
- To start **vi**, you type “vi” at the Linux shell prompt.
- You may start **vi** with a file named “thisfile” by typing “vi thisfile.”
- When you start **vi**, you are in *command* mode.
- To enter text, **vi** must be in *input* mode.
