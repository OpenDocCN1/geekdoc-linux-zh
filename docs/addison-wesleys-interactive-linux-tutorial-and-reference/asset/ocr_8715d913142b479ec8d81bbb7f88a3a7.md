# Control Key Commands

+   Ctrl-b Full screen back
+   Ctrl-d Half screen down
+   Ctrl-e Scroll screen up one line
+   Ctrl-f Full screen forward
+   Ctrl-g Display status line information
+   Ctrl-l Clear status line display
+   Ctrl-u Half screen up
+   Ctrl-y Scroll screen down one line
+   Ctrl-^ Switch to other file
