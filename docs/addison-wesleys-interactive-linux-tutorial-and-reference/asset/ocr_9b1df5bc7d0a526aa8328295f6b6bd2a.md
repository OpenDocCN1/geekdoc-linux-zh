# Control Key Commands

### Control Key Commands

<Ctrl-C> Interrupt output from a command.

+   <Ctrl-D>
+   (1) Log off. You must see the **login:** prompt to know that your logout was successful.
+   (2) Finish composing a **write** message.
+   (3) Finish creating a file with **cat** and redirection.

<Ctrl-H> Erase a character to the left of cursor.

<Ctrl-Q> Resume a scrolling display.

<Ctrl-S> Stop a scrolling display.
