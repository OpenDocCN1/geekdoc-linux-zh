- 16. If your Linux installation permits, log in at a second terminal. Now repeat Exercise 10.

  - b. Press <Enter>

Note that this time you are using a lowercase “a.”

You will see two copies of your shell listed—one for each terminal you log in from. This reminds you that, each time you log in, you start a new copy of your shell and each copy is a separate process. Compare the “tty” column listing with each shell process; you will see two different terminal numbers.

As we pointed out in the CBT course, there are situations in which you may legitimately need to log in at more than one terminal. In our case, however, logging in at a second terminal is just for practice purposes. Each terminal in use and each running process represents system resources. It is important not to misuse these resources. If you were successful in logging in at a second terminal, you will need to do the next exercise twice—once at each terminal.
