# Terms to Remember

**filter** A program that takes its data from standard input and sends its results to standard output.

**mount** Prepares a floppy drive to communicate with the system; integrates it with the system.

**pipe** Takes the output of one process and turns it into the input of a second process.

**redirection** A system procedure in which the expected progression from standard input to standard output is changed. Input may be some source other than keyboard; output may be something other than *screen*.

**unmount** Reverses the **mount** procedure; disables communication between the floppy drive and the system.
