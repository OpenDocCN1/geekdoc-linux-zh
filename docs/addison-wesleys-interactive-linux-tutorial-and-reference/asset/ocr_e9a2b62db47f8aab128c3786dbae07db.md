# # Linux Command Reference:

*Listing by Function*

**Logging in and Leaving the System**

| Command | Description |
| :--- | :--- |
| login: prompt | You supply userid and password. |
| <Ctrl-D> | Logout (on most systems) |
| exit | Logout (on some systems) |
| logout | Logout (on some systems) |
| passwd | Change your password. |

**Using the Shell**

| Command | Description |
| :--- | :--- |
| cshsh | Change your login shell. |
| cshsh -l | Get a list of available shells. |
| ps | Get a list of processes you have started. |
| ps -A | Get a list of all running processes. |
| ps -a | When logged in at more than one terminal, get a list of all processes you have started from all terminals. |
| <Ctrl-C> | Interrupt output from a command. |
| <Ctrl-H> | Erase character to the left of cursor. |
| <Ctrl-Q> | Resume a scrolling display. |
| <Ctrl-S> | Stop a scrolling display. |
