+   12. Unlike du, df reports on free space on an entire hard drive. To confirm that this is so, do the following:
+   a. Type cd /
+   b. Press <Enter>
+   c. Type df
+   d. Press <Enter>

+   f. Press <Enter>
+   g. Type df
+   h. Press <Enter>
