+   11. The **ps** command will usually list only the processes that you have initiated. What about the processes that the kernel starts—the daemons that we mentioned in the CBT course? To see all the currently running processes, you add a switch to **ps**:  
+   Enter the following command:
+   a. Type `ps -A`  
+   The "A" switch means “all.”  
+   b. Press <Enter>
+   
+   Linux will respond with a display similar to what you see in Figure 3-9. Note that your shell is listed as a process.
