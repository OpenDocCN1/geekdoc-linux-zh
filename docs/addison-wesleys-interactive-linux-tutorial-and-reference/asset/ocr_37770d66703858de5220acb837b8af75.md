# Getting Started with vi

# Introduction

Text files are an everyday fact of life in the Linux environment. Whether you're sending e-mail or writing messages, creating shell scripts or other programming code, updating a text file, or keeping simple to-do lists, it is likely that you will work with text files on a regular basis.

**vi** is found on most Linux installations. While not necessarily easy to learn, **vi** is nonetheless easy to use. In this **vi** module, you will learn how to start and quit **vi** and how to distinguish between its two modes.

# In This Module You Will Learn:

+   - what **vi** is.
+   - how to start **vi**.
+   - the difference between **command mode** and **input mode**.
