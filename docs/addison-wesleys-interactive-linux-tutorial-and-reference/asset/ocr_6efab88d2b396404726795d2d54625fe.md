The **tee** utility enables you to combine into one step what you accomplished in two steps in Exercises 14 and 15.

+   16.  In this exercise, you will pipe the output of the **sort** command to **tee**. This will send the output to both the screen and the new file **sorted2**.
+       a.  Type `sort supply | tee sorted2`
+       b.  Press <Enter>

+   In the *Try It Live!* section of **Linux Files**, Robert had you—his intern—search the **supply** files for references to “specialty.” In the next exercise, you will repeat that search again, using the filter **grep**. This time, you will save the information in a new file.

+   17.  Use **grep** and redirection to locate and save data from the **supply** files.
+       a.  Type `grep specialty * > specialty`
+       b.  Press <Enter>
+   
+   In English, this command syntax reads: search for the pattern “specialty” in all (*) the files in this directory and send that information to the new file **specialty**.
