# Shell Scripts

If your system doesn't run an executable shell script when you type the name of the script, you can use one of these command options:

+   .scriptname
+   no space between . and scriptname
+   .scriptname
+   space between . and scriptname
+   sh scriptname
+   space between sh and scriptname
