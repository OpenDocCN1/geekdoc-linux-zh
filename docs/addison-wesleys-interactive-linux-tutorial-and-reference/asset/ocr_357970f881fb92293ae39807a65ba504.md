# vi Advanced Commands

# Introduction

This module will introduce you to some of vi's more powerful features. Buffers will help you to recover from errors as well as move multiple blocks of text both within areas of the same document and between multiple documents. With access to the Linux shell from within vi, you can take advantage of some of the shell's power without leaving vi. You can, for example, use the shell to alphabetize a list of names and then return to your file and pick up where you left off. You will also find that vi's multiple options for quitting are both useful and potentially time saving.

# In This Module You Will Learn:

+   - how to use named and numbered buffers to retrieve or move text.
+   - how to move text between two files with vi.
+   - how to access the Linux shell from within vi and issue system commands.
+   - four different commands for quitting vi.
