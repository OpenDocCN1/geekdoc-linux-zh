请记住，我们通过将双引号（"）放在缓冲区编号或名称之前来引用缓冲区。省略双引号会产生完全不同的结果。例如，`"3p` 放置的是 3 号缓冲区的内容。相比之下，`3p`（没有双引号）将放置 1 号缓冲区内容的三个副本。
