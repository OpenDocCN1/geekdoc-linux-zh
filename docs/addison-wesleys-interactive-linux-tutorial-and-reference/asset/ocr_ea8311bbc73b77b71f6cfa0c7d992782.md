# Linux Command

# Reference:

# Alphabetical Listing

# cal

What it does: Displays a calendar for one month or one year.

Syntax: cal [month] [year]

Example 1: cal by itself displays a calendar of the current month

Example 2: cal 4 2004 displays a calendar for April 2004

Example 3: cal 2004 displays a calendar for the year 2004

# cat

What it does: (1) Reads a text file. (2) Creates a text file. (3) Concatenates (joins) files. (4) Appends text to a file.

+   Syntax:
+   
+   1. cat file
+   2. cat > file
+   3. cat file1 file2 > newfile
+   4. cat >> file1
+   5. cat > thisfile

Example 1:

```
$ cat > thisfile
This will create the text file thisfile. Press
<Ctrl-D> to signal that you have finished.
$ 
```
