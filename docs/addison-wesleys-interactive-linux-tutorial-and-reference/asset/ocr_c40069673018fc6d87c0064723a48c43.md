# # Linux Tools

# ## Introduction

A tool is a means to an end. You use a hammer to drive the nail that holds two boards in a bookcase together. The hammer is important because it helps you to accomplish the goal: building the bookcase.

In this module of the CB1, you will learn about Linux tools that help you accomplish some goal. The pipe, the filter, and redirection are three tools that you will probably use on a daily basis. With the cat command, you will read and create text files. If you have access to a floppy drive on your system, you will need to be able to mount and umount the floppy. If you issue a command that the system can't interpret, the system may send you an error message that will help you to straighten out the matter. And when you need help, help, man and info are there to assist.

# ## In This Module You Will Learn:

+   * about the fundamental role of the pipe in Linux.
+   * how to use redirection.
+   * what a filter is.
+   * how to rearrange your data with sort.
+   * how to create text files directly from standard input.
+   * how to use a floppy drive on a Linux installation.
+   * what it means to mount and umount a floppy drive.
+   * how to create a host subdirectory for a floppy drive.
+   * how to get help with help, man and info.
+   * how to interpret standard Linux error messages.
