# # Try It Live!

As we have done in earlier Try It Live! sections of this Study Guide, we will omit step-by-step instructions for some of the exercises. At the very end of this chapter of the Study Guide, you will find whatever step-by-step instructions we have omitted in the exercises.

+   1. Change to your directory **practice**.

+   2. Open vi with the file **nowtime**.

In the next group of exercises, you will search for patterns.

+   3. In this exercise, you will search for “time”.

+   a. Press `</>` to search forward in the file.

+   b. Type time

+   c. Press **Enter** to search for the pattern **time**.

+   d. Press `<n>` five times to find each occurrence of this pattern.

Note that the status line indicates */time*, to tell you that you are searching forward in the file for the pattern **time**.

+   e. Press `<n>` again to wrap the find to the top of the file.

Note the status line message when the find command wraps.

+   f. Press `<N>` to search for the same pattern in the opposite direction.

Note that the status line message changes when the find command wraps in the opposite direction.

+   g. Press `<N>` again.

Note that the status line indicates *?time* to tell you that you are searching backward in the file for the pattern **time**.

+   4. In this exercise, you will search for “is”.

+   a. Move the cursor to the bottom line of the file.

+   b. Move the cursor to the end of the line.

+   c. Press `<N>` to search backward in the file.
