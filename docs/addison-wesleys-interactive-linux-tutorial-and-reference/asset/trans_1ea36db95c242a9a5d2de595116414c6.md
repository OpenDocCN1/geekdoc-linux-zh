# 需记住的术语

- **账户权限** 你的主目录和文件访问权限。
- **当日信息** 在某些系统上登录时显示的消息。
- **密码** 一个代码，与你的*userid*一起，必须输入才能登录系统。
- **配置档案 (profile)** 一个包含信息允许你将 Linux 环境调整为适合你需求的文件。
- **Shell 提示符** 显示在屏幕上的字符，指示下一个你输入的键的输出将显示的位置。
- **标准输入** 你的计算机键盘。
- **标准输出** 你的计算机屏幕。
- **userid（用户ID）** 一组唯一标识你给系统的字符。

# Linux 日常使用总结

要登录到 Linux 系统，你需要一个用户 ID 和一个密码。· 你的 Linux 账户包括你的主目录和你的文件访问权限。· bash 显示 $ 提示符。· 你用 <Enter> 键向计算机发出信号，表示你准备好让它执行你的命令。在某些终端上，该键标记为 <Return> 或 <CR>。· 用 <Backspace> 键或 <Ctrl-H> 删除文本。· 你可以用 <Ctrl-C> 中断大多数形式的输出。你可以用 <Ctrl-S> 停止输出滚动出屏幕。你可以用 <Ctrl-Q> 恢复滚动。· Linux 区分大小写。对 Linux 来说，文件 myfile 和 MyFile 是不同的文件。大多数命令以小写字母输入。· 要注销系统，使用 <Ctrl-D>、<logout> 或 <exit>。务必确认系统响应登录提示符。

# Linux 信息与通信

# 简介

计算机网络促进通信。（互联网已经充分证明了这一点！）从最初开始，Linux 就是一个为网络设计的操作系统——提供用户之间的通信。你将使用本部分的三个命令——**mail**、**who** 和 **write**——来做到这一点：与其他系统用户通信。

**news** 提供了一种快速获取信息的方法，使你能跟上系统的动态发展。**cal** 和 **date** 提供有用的信息，帮助你掌握自己的世界。
