+   4. In this exercise, you will delete all nine lines in this file.

+   a. Be certain the cursor is on line one. Press **<dd>** to delete the line.

+   b. Press **<dd>** to delete line two.

+   c. Press **<dd>** to delete line three.

+   d. Continue until all nine lines have been deleted. **vi** will give you a message in the status line, something like “no lines in buffer.”
