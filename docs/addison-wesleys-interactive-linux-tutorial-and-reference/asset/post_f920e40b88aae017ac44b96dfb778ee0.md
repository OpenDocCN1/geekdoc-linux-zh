
## Getting Help

- `command --help`: Get help with the syntax for command.
- `info`: Hypertext help system.
- `man`: Detailed information from the system manual.

## Security

- `chmod`: Change access permissions for a file.
- `passwd`: Change your password.

## Shell Scripts

If your system doesn't run an executable shell script when you type the name of the script, you can use one of these command options:

- `.scriptname`
  - no space between . and scriptname
- `. scriptname`
  - space between . and scriptname
- `sh scriptname`
  - space between sh and scriptname

## Tools

- `more`: Prevent a long display from scrolling off the screen.
- `sort`: Rearrange your data.

# Linux Command

## Reference: Alphabetical Listing

### cal

**What it does:** Displays a calendar for one month or one year.

**Syntax:** `cal [month] [year]`

**Example 1:** `cal` by itself displays a calendar of the current month.

**Example 2:** `cal 4 2004` displays a calendar for April 2004.

**Example 3:** `cal 2004` displays a calendar for the year 2004.

### cat

**What it does:**
1. Reads a text file.
2. Creates a text file.
3. Concatenates (joins) files.
4. Appends text to a file.

**Syntax:**
1. `cat file`
2. `cat > file`
3. `cat file1 file2 > newfile`
4. `cat >> file1`
5. `cat > thisfile`

**Example 1:**

```bash
$ cat > thisfile
This will create the text file thisfile. Press
<Ctrl-D> to signal that you have finished.
$ 
```

### cd

**What it does:**
1. Changes to directory *dirname*.
2. Changes to your home directory.

**Syntax:**
1. `cd dirname`
2. `cd`

**Example 1:** `cd folio` will change to the directory **folio**.

**Example 2:** `cd` by itself will change to your home directory.

### chmod

**What it does:** Changes access permissions for a file.

**Syntax:** `chmod [u|g|a] [+=] [rwx] [filename]`

**Example:** `chmod ug+rx thisfile` adds execute permission to the file **thisfile** for the user (the file’s owner) and the group (the file owner’s working group).

### chsh

**What it does:** Changes the shell.

**Syntax:** `chsh [filename]`

**Example 1:** Use the `-l` switch to find out what shells are available.

```bash
$ chsh -l
/bin/bash
/bin/csh
/bin/sh
$ 
```

Figure 15-3 Using `chsh -l` to Find Out What Shells Are Available

**Example 2:** To change to the Bourne shell, use the command line `chsh /bin/sh`.

### cp

| Field | Description |
| :--- | :--- |
| What it does | Copies a file or group of files. |
| Syntax | `cp filename[s]` |
| Example 1 | The command line `cp file1 file2` will make `file2` a copy of `file1`. |
| Example 2 | The command line `cp file1 file2 newdir` will copy `file1` and `file2` to the directory `newdir`. |

### date

| Field | Description |
| :--- | :--- |
| What it does | Displays current date and time. |
| Syntax | `date` |

### df

| Field | Description |
| :--- | :--- |
| What it does | Reports free space remaining on a hard drive from the root directory. `df` = “disk free.” |
| Syntax | `df` |

### du

| Field | Description |
| :--- | :--- |
| What it does | Reports disk space used in current directory and all subdirectories. `du` = “disk [space] used.” |
| Syntax | `du` |

### exit

**What it does:** Logout (on some systems).

**Syntax:** `exit`

### find

**What it does:** Finds files.

**Syntax:** `find path criteria action`

**Example 1:** `find $HOME -name supply -print`
In this example, `find` will search your home directory and all subdirectories for the file named “supply” and will display the results on standard output.

**Example 2:** `find . -name *.temp -exec rm {} \;`
In this example, `find` will search the working directory and all subdirectories for all files that have the extension “temp” and delete them.

### grep

**What it does:** Searches for specific text within a file.

**Syntax:** `grep string file list` (`string` is the text to search for)

**Example 1:** `grep folder *`
In this example, you search through all the files in the working directory for the string “folder.”

**Example 2:** `grep -i conference *`
In this example, you search through all the files in the working directory for the string “conference.” The `-i` switch tells `grep` to ignore case.

### --help

**What it does:** Get help with syntax for *command*.

**Syntax:** `command --help`

**Example:** `cp --help` will show you the options and correct syntax for the command `cp`.

### info

**What it does:** Provide system information using a hypertext modality.

**Syntax:** `info [topic]`

**Example 1:** `info` by itself will open an introductory screen from which you can type “h” to start a tutorial on `info`.

**Example 2:** `info bash` will provide information about this shell.

**Example 3:** `info cp` will provide information about the command `cp`.

### less

**What it does:** Allows you to control the display of a long file.

**Syntax:**
1. `less`
2. `less filename`

**Example 1:** `ls -l | less` will pipe the output of the command `ls -l` through `less`. You can use a variety of cursor-movement keys to display the output. `less` gives you much more control over the output than does `more`.

**Example 2:** `cat longfile | less` will pipe the output of the command `cat longfile` through `less`.

**Example 3:** `less longfile` has the same effect as Example 2. The command line is simpler.

### ln

**What it does:** Creates a link to another file.

**Syntax:** `ln filename`

**Example:** The command line `ln /usr/ronsm/accounts/current` will create a link in the working directory to the file **current** in **ronsm**’s directory accounts.

### logout

**What it does:** Logout (on some systems).

**Syntax:** `logout`

### lpr

**What it does:** Sends a file to a printer.

**Syntax:** `lpr filename`

### ls

**What it does:** Lists files.

**Syntax:** `ls [file list]`

**Example 1:** `ls` by itself lists files and directories in the working directory.

**Example 2:** `ls -l` gives a “long” listing, providing detailed information about each file.

**Example 3:** `ls -F` appends an asterisk to each executable file and a slash to each directory.

### mail

**What it does:**
1. Sends messages to users on your system who are not logged in.
2. Sends e-mail.

**Syntax:** `mail userlist`

### man

**What it does:** Displays pages from the system manual. The `man` pages are part of the system’s help resources.

**Syntax:** `man command`

**Example:** `man ls` will display information about the command `ls`.

### msg n, msg y

**What it does:** Prevents or enables receipt of **write** messages from other users on your system.

- **Example 1:** `msg n` will prevent receipt of **write** messages.
- **Example 2:** `msg y` will enable receipt of **write** messages.

### mkdir

**What it does:** Creates a new directory ("make directory").

**Syntax:** `mkdir directory_name`

**Example:** `mkdir homework` will create a new directory called **homework**. This directory will be a subdirectory of the working directory.

### more

**What it does:** Prevents a long display from scrolling off the screen.

**Syntax:**
1. `more`
2. `more filename`

- **Example 1:** `ls -l | more` will pipe the output of the command `ls -l` through `more`. The <Enter> will scroll one line. The <Space Bar> will scroll one full screen.
- **Example 2:** `cat longfile | more` will pipe the output of the command `cat longfile` through `more`.
- **Example 3:** `more longfile` has the same effect as Example 2. The command line is simpler.

### mv

**What it does:**
1. Rename a file or directory.
2. Move a file or directory.

**Syntax:** `mv oldfilename newfilename`

- **Example 1:** `mv january.tax february.tax` will change the name of the file **january.tax** to **february.tax**.
- **Example 2:** `mv homedir officidir` will change the name of the directory **homedir** to **officidir**.
