# Commands to Remember

## Buffer Commands

| Command | Description |
|---|---|
| `:e#` | switch to the other file |
| `:!#` | switch to the other file without saving the current file |
| `Ctrl-A` | switch to the other file |
| `"ay` | yank a sentence forward into named buffer "a" |
| `"dp` | put the contents of named buffer "d" |
| `"1pu.u.` | cycle through the numbered buffers |
| `.` | (the dot command) put the contents of the next numbered buffer |

## Quit Commands

| Command | Description |
|---|---|
| `:q` | quit vi |
| `:q!` | quit vi without saving |
| `:wq` | save current file and quit |
| `ZZ` | save all changed files and quit |

## Other Commands

| Command | Description |
|---|---|
| `:!` | access the Linux shell. |

# Advanced Commands Summary

- **vi** uses nine *numbered buffers*.
- Numbered buffers automatically store deletions consisting of one or more whole lines.
- **vi** uses twenty-six *named buffers*.
- You control the contents of the named buffers by referencing a buffer with a letter of the alphabet.
- To move text between two or more files, you use the named buffers.
- You can access the Linux shell from within **vi**.

## Daily Communications

**cal**
Display a calendar for one month or one year.

**date**
Display current date and time.

**mail**
(1) Send messages to users on your system who are not logged in. (2) Send e-mail.

**msg n**
Prevent other users from sending you write messages.

**msg y**
Enable receipt of write messages.

**news**
Get system news.

**who**
Find out who is currently logged in.

**write**
Send messages to other users on your system who are currently logged in.

## Files and Directories

**.**
Current directory.

**..**
Parent directory.

**\***
Represents zero or multiple characters.

**?**
Represents one single character.

**[ ]**
Group files.

**cat**
(1) Read a text file. (2) Create a text file. (3) Concatenate files. (4) Append text to a file.

**cd**
Change directory.

**cp**
Copy a file or group of files.

**cpio**
Back up files.

**df**
Free space remaining on hard drive.

**du**
Space used in working directory and all subdirectories.

**find**
Find files.

**grep**
Find text within text files.

**ln**
Create a link to a file.

**lp or lpr**
Print a file.

**ls**
List files and directories.

**mkdir**
Create a new directory.
