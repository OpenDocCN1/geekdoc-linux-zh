# # Module 9 Shell Scripts

+   1. Create a subdirectory under your directory practice. Call this new directory scripts.
+   
+      a. Type `cd $HOME/practice`
+   
+      b. Press <Enter>
+   
+      c. Type `mkdir scripts`
+   
+      d. Press <Enter>

+   2. Change to the directory scripts.
+   
+      a. Type `cd scripts`
+   
+      b. Press <Enter>

+   4. Check your work. Use `cat` to read the file list.
+   
+      a. Type `cat list`
+   
+      b. Press <Enter>

+   6. List your directory scripts to be certain that the file mode for list includes both read and execute permission.
+   
+      a. Type `ls -l`
+   
+      b. Press <Enter>

+   9. The script list2 is a text file. Display the contents of the file on standard output.
+   
+      a. Type `cat list2`
+   
+      b. Press <Enter>

+   10. Make the script list2 an executable file for all.
+   
+      a. Type `chmod a+x list2`
+   
+      b. Press <Enter>

+   11. When you pipe a directory listing through `1 more`, <Enter> will scroll the screen one line. The <Space Bar> will scroll one full screen.

+   13. Check your work by displaying the contents of the file ren on standard output.
+   
+      a. Type `cat ren`
+   
+      b. Press <Enter>

+   14. Make the script ren executable by all.
+   
+      a. Type `chmod a+x ren`
+   
+      b. Press <Enter>
