Notice that the shell prompt follows the text of the file; it is on the same line. This is not a major problem, but it will tend to obscure the first line of a multiline file. On some systems or with some shells, the shell prompt will include your userid and your working directory. If that were the case here, then cat tempfile1 would produce the result you see in Figure 6-3.

```
[userid dir1]$ cat tempfile1
This is tempfile1.[userid dir1]$ 
```

Figure 6-3 Expanded Shell Prompt Next to Text of tempfile1

You can see that it might take an extra second or two to differentiate between the text of the file and the shell prompt. It is a simple matter to remove this minor annoyance with <Enter>. Keep in mind that <Enter> sends the cursor to the next line.

+   6. Create the second temporary file.

+   a. Type cat > tempfile2

+   b. Press <Enter> to get the system to respond to the command line above.

+   c. Type: This is tempfile2.

+   d. Press <Enter> to move the cursor to the next line.

+   e. Press <Ctrl-D>

The extra step in this exercise is to press <Enter> before <Ctrl-D>.

+   7. Now you will use cat to read tempfile2.

+   a. Type cat tempfile2

+   b. Press <Enter>
