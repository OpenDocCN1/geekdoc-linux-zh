# Linux Environment

# Introduction

As we described in the previous module of the CBT course, Operating Systems, your computing environment is the set of conditions that determines how you interact with the computer. The operating system and the interface—command-line based or graphical user interface (GUI)—together determine your computing environment.

In this module, Linux Environment, we explore further the ways in which Linux functions—sometimes behind the scenes, sometimes right up front—to shape your computing experience.

The behind-the-scenes operator is the kernel. You will see that the kernel is the part of the operating system that manages and controls all the system resources.

Right up front is the shell. You will see that the shell is another major factor in determining how you interact with the computer.

Finally in this section, we present the process, which simply refers to a job or task the computer will perform. As we described earlier, Linux is a multitasking operating system. This means that there are usually several processes running simultaneously. The ability of one process to communicate with another, through interprocess communication, greatly expands the power of the operating system.
