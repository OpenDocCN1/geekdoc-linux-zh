## Commands to Remember

### Basic Cursor Movement

| Command | Description |
|---------|-------------|
| h       | left |
| j       | down |
| k       | up |
| l       | right |
| 0       | beginning of line |
| $       | end of line |
| H       | high point of screen |
| M       | middle point of screen |
| L       | low point of screen |

### Move by Words

| Command | Description |
|---------|-------------|
| w/W     | forward small/big word |
| b/B     | back small/big word |
| e/E     | forward to end of small/big word |

### Move by Sentence/Paragraph

| Command | Description |
|---------|-------------|
| )       | sentence forward |
| (       | sentence back |
| }       | paragraph forward |
| {       | paragraph back |

### Change Screen Display

| Command | Description |
|---------|-------------|
| Ctrl-d  | half screen down |
| Ctrl-u  | half screen up |
| Ctrl-f  | full screen forward |
| Ctrl-b  | full screen back |
| Ctrl-e  | up one line |
| Ctrl-y  | down one line |
| z <Enter> | moves line cursor is on to top of screen |
| z.      | moves line cursor is on to middle of screen |
| z-      | moves line cursor is on to bottom of screen |

### Other Commands

| Command | Description |
|---------|-------------|
| nG      | move to line *n* |
| Ctrl-g  | display status line information |
| Ctrl-l  | clear status line |
| *n*<command> | add a number, *n*, to modify many vi commands |

## vi Cursor Movement Summary

- To move the cursor around the screen, **vi** must be in **command mode**.
- Press <Esc> to put **vi** in command mode.
- Each punctuation mark, parenthesis, or bracket is treated as a separate **small word**.
- A **big word** includes attached punctuation marks, parentheses, or brackets.
- Most **vi** commands can be modified by numbers.
