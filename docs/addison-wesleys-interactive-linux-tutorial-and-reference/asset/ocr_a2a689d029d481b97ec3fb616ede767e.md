# Try It Live!

+   1. Log in at one terminal. (If the instructions below don't work, skip down to “Oops!”)
+       1. At the `login:` prompt, enter your *userid*.
+       2. Press the `<Enter>` key.
+       3. Enter your password.
+       4. Press the `<Enter>` key.

**Oops!** If there is no `login:` prompt, it could be that someone is using that terminal and has stepped away for a moment. Ask someone in the room whether that terminal is in use. If it appears that the terminal is not in use, press `<Enter>` a few times to see whether the `login:` prompt appears. If that doesn't work, it could be that the person who used the terminal before you did not log out—a major no-no! Enter the logout command—`<Ctrl-D>`—to see if that restores the `login:` prompt.

> Remember that `<Ctrl-D>` will not work as the logout command on some systems. You may need to use either the *logout* or *exit* command.
