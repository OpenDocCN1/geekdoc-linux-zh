# vi Command Reference:
Alphabetical Listing

# Single-character Commands

| Command | Description |
| --- | --- |
| a | Append text one character past cursor; **vi** in input mode |
| A | Append text one character past end of line; **vi** in input mode |
| b | Small word back |
| B | Big word back |
| C | Change to end of line; **vi** in input mode |
| D | Delete to end of line |
| e | End of small word forward |
| E | End of big word forward |
| G | Go to last line of file |
| h | Move cursor character left |
| H | Cursor to High point of screen |
| i | Insert text at cursor; **vi** in input mode |
| I | Insert text at beginning of line; **vi** in input mode |
| j | Move cursor down one line |
| J | Join current line with line below |
| k | Move cursor up one line |
| l | Move cursor one character to the right |
| L | Move cursor to Low point of screen |
| M | Move cursor to Midpoint of screen |
| n | Find Next occurrence of *pattern* in same direction |
| N | Find Next occurrence of *pattern* in opposite direction |
