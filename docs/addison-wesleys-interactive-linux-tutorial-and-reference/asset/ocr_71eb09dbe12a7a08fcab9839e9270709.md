+   6.  Does your *shell prompt* look like this: `$ _`? If it does, you may be using bash. You can find out what shells are available on your system with the `cshsh` command.
+      - a.  At the shell prompt, type `cshsh -l`
+      - b.  Press **<Enter>**
+   
+       (Make certain that you leave a space between the second “h” and the dash but no space between the dash and the “l.”)
+   
+       The l is called a *switch or argument*. A switch affects the output of the command. In this case, it tells the system to list the shells available.
+   
+       The system will respond with a screen similar to Figure 3-2.

```
$ cshsh -l
/bin/bash
/bin/csh
/bin/ksh
/bin/tcsh
/bin/sh
/bin/zsh
$|
```
