# # vi Basic Operations

# ## Introduction

This module in *The vi Tutorial* will introduce you to operations that you will use on a regular basis. We can divide these operations into two categories: managing files and changing files.

In the first category, you will learn how to open existing files, create new files, and save files. In the second category, you will learn how to enter, change, and delete text.

# ### In This Module You Will Learn:

+   - how to enter text with vi.
+   - how to open existing files.
+   - how to create new files.
+   - how to save files.
+   - how to change text.
+   - how to delete text.
