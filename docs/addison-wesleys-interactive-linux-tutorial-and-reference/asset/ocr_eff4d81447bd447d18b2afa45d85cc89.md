# Terms to Remember

**file mode** Indicates who can access any given file and what kind of access is permitted.

# Commands to Remember

**chmod** change access permissions for a file

# Security Summary

+   - The most basic element of Linux security is the **login** procedure. Every user needs both a *userid* and a password to gain access to the system.
+   - The second element of Linux security is the **file mode**. The mode determines, for each and every file on the system, who has permission to read, write to, and execute that file.
+   - Use the **chmod** command to change the **file mode**.
