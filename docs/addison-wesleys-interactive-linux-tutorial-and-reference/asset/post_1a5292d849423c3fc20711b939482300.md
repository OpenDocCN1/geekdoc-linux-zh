
You can modify most such combinations with a number. Example: add “2” to `<cw>` to produce `<2cw>` or `<2<w>`: change two small words forward.

Some commands are also objects. You recognize that `<b>`, `<h>`, `<j>`, and `<k>` are cursor movement commands. When these commands are preceded by numbers, the commands become objects. `<k>` by itself means "Go down one line." `<2k>` now addresses the object "one line down" and says, "Do two of them." `<w>` by itself is the command to move the cursor one small word forward. `<2w>` now addresses the object "one small word forward" and says, "Do two of them."

You might be surprised at some of the commands that can be modified with a number. We urge you to experiment!

There are some special cases that are not recognized in Figure 15-6. Three that we cover in this course are:

- `<dd>` delete the entire line
- `<cc>` change the entire line
- `<yy>` yank the entire line

## Glossary

- **access permission** The right to read, write to, or execute any file (including directories) is determined by the access permission of that file. Also known as the file mode.
- **account** All users on a Linux system have an account, which is like your own private place in the system. Your account includes your home directory and file access permissions.
- **argument** A term following a command name that modifies the output of that command. The term could be an option, filename, or variable.
- **bash** A widely used Linux shell.
- **Berkeley C-shell** An available Linux shell.
- **buffer** An area in the computer’s memory where data is stored temporarily.
- **bus** The computer’s internal communications network.
- **cal** Command that displays either (1) a calendar for any year you choose, between A.D. 1 and A.D. 9999, or (2) a calendar for any month you choose.
- **cat** Command to (1) view a text file; (2) join two or more text files (concatenate); (3) append material to a text file; (4) create a text file directly from the keyboard.
- **cd** This command can be used in two different ways: (1) Followed by a directory name, change to that directory. (2) Used by itself, returns you to your home directory.
- **child process** A process created by a process. The first process is known, logically enough, as the “parent.”
- **chmod** The command that permits the file owner to change the file mode—that part of a file that determines who can access the file.
- **command-line interface** A system for communicating with the computer in which the user types all commands from the keyboard. Traditional Linux uses a command-line interface. (Compare GUI.)
- **command syntax** The exact characters you need to type to instruct the computer to do something.
- **compiler** The compiler translates the source code into object code so that the computer can process the instructions.
- **computer network** A system in which computers communicate with each other.
- **computing environment** The set of conditions that determines how you interact with the computer. The operating system and the interface—command-line based or GUI—together determine your computing environment.
- **concatenate** Join two or more files together to make one single file.
- **cp** Command to copy a file.
- **cpio** Command to back up files to an archival storage device.
- **CPU** Central Processing Unit. This is the computer's microprocessor. Also known as the chip.
- **daemon** A process started by the kernel.
- **date** Command to display the date and time.
- **df** Command that reports on free space on your hard disk.
- **directory** A unit in the computer's file system, analogous to folders in a physical filing cabinet. Mac users and Windows users (after version 3.X) use the term "folder." The use of multiple directories enables efficient organization of a system's files.
- **directory structure** The collection of directories and subdirectories in which information is stored in a computer.
- **du** Command that reports on the percentage of hard disk in use.
- **ed** Single-line text editor available on many Linux systems.
- **Emacs** Full-screen text editor available on many Linux systems.
- **environment** That set of conditions that determines how you interact with the computer. The operating system and the interface—command-line based or GUI—together determine your computing environment.
- **execute** You execute a file when you run it. You have permission to execute a directory when you have permission to change (cd) to that directory.
- **exit** On some systems, you will use this command to log off.
- **file mode** The file mode indicates who can access any given file and what kind of access is permitted. Also referred to as access permissions.
- **file system** The collection of directories and subdirectories in which information is stored in a computer.
- **filter** A program that takes its data from standard input (the keyboard) and sends its results to standard output (your screen). Along the way from input to output, the filter rearranges, manipulates, or screens your data in some way.
