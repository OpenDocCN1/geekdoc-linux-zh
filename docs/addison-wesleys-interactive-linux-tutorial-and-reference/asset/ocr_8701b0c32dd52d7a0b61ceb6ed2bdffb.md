**NAME**

du - estimate file space usage

**SYNOPSIS**

du [OPTION]... [FILE]...

**DESCRIPTION**

Summarize disk usage of each FILE, recursively for directories.

- **-a, --all**
write counts for all files, not just directories

**-block-size=SIZE** use SIZE-byte blocks

**-b, --bytes**
print size in bytes
