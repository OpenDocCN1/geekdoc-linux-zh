# logout

**What it does:** Logout (on some systems)

**Syntax:** logout

# lpr

**What it does:** Sends a file to a printer.

**Syntax:** lpr filename

# ls

**What it does:** Lists files.

**Syntax:** ls [file list]

**Example 1:** ls by itself lists files and directories in the working directory.

**Example 2:** ls -l gives a “long” listing, providing detailed information about each file.

**Example 3:** ls -F appends an asterisk to each executable file and a slash to each directory.

# mail

**What it does:** (1) Sends messages to users on your system who are not logged in. (2) Sends e-mail.

**Syntax:** mail userlist

# man

**What it does:** Displays pages from the system manual. The man pages are part of the system’s help resources.

**Syntax:** man command

**Example:** man ls will display information about the command ls.
