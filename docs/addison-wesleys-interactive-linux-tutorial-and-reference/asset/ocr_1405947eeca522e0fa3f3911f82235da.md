# Terms to Remember

**directory** A unit in the computer's file system analogous to a folder in a physical filing cabinet.

**link** A connection, technically called a “pointer,” from file1 to file2.

**ordinary file** Files that contain text, data, or programs.

**special file** A file that enables communication with a device—such as a monitor or a hard drive.

**wildcard** One character that represents other characters.
