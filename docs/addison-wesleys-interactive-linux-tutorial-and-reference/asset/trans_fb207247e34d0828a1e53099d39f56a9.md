# 高级命令总结

- **vi** 使用九个*编号缓冲区*。
- 编号缓冲区自动存储由一行或多行完整行组成的删除内容。
- **vi** 使用二十六个*命名缓冲区*。
- 您通过引用字母表中的字母来控制命名缓冲区的内容。
- 要在两个或多个文件之间移动文本，您需要使用命名缓冲区。
- 您可以在 **vi** 内部访问 Linux shell。

## 日常通信

**cal**
显示一个月或一年的日历。

**date**
显示当前日期和时间。

**mail**
(1) 向系统中未登录的用户发送消息。(2) 发送电子邮件。

**msg n**
阻止其他用户向您发送写消息。

**msg y**
启用接收写消息。

**news**
获取系统新闻。

**who**
查找当前登录的人员。

**write**
向系统中当前登录的其他用户发送消息。

## 文件和目录

**.**
当前目录。

**..**
父目录。

**\***
代表零个或多个字符。

**?**
代表单个字符。

**[ ]**
文件组。

**cat**
(1) 读取文本文件。(2) 创建文本文件。(3) 连接文件。(4) 将文本追加到文件。

**cd**
更改目录。

**cp**
复制文件或文件组。

**cpio**
备份文件。

**df**
硬盘上剩余的可用空间。

**du**
工作目录及所有子目录中使用的空间。

**find**
查找文件。

**grep**
在文本文件中查找文本。

**ln**
创建到文件的链接。

**lp or lpr**
打印文件。

**ls**
列出文件和目录。

**mkdir**
创建新目录。
