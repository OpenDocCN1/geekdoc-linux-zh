# Module 8 Security

In this section, you will find the step-by-step instructions that we omitted from the Try It Live! exercises.

+   1. Change to your home directory.
+   
+      a. Type cd
+      b. Press <Enter>
+   2. Create a new directory called newdir.
+   
+      a. Type mkdir newdir
+      b. Press <Enter>
+   3. List your home directory, and note the permissions for newdir.
+   
+      a. Type ls -1
+      b. Press <Enter>
+   10. Add write permission for the user to newdir.
+   
+      a. Type chmod u+w newdir
+      b. Press <Enter>
+   11. List your home directory, and check your work in Exercise 10.
+   
+      a. Type ls -1
+      b. Press <Enter>
+   12. Remove execute permission for others for newdir.
+   
+      a. Type chmod o-x newdir
+      b. Press <Enter>
