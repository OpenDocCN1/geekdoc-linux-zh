# Glossary

+   *   **access permission**  The right to read, write to, or execute any file (including directories) is determined by the access permission of that file. Also known as the file mode.
+   *   **account**  All users on a Linux system have an account, which is like your own private place in the system. Your account includes your home directory and file access permissions.
+   *   **argument**  A term following a command name that modifies the output of that command. The term could be an option, filename, or variable.
+   *   **bash**  A widely used Linux shell.
+   *   **Berkeley C-shell**  An available Linux shell.
+   *   **buffer**  An area in the computer’s memory where data is stored temporarily.
+   *   **bus**  The computer’s internal communications network.
+   *   **cal**  Command that displays either (1) a calendar for any year you choose, between A.D. 1 and A.D. 9999, or (2) a calendar for any month you choose.
+   *   **cat**  Command to (1) view a text file; (2) join two or more text files (concatenate); (3) append material to a text file; (4) create a text file directly from the keyboard.
+   *   **cd**  This command can be used in two different ways: (1) Followed by a directory name, change to that directory. (2) Used by itself, returns you to your home directory.
+   *   **child process**  A process created by a process. The first process is known, logically enough, as the “parent.”
+   *   **chmod**  The command that permits the file owner to change the file mode—that part of a file that determines who can access the file.
+   *   **command-line interface**  A system for communicating with the computer in which the user types all commands from the keyboard. Traditional Linux uses a command-line interface. (Compare GUI.)
