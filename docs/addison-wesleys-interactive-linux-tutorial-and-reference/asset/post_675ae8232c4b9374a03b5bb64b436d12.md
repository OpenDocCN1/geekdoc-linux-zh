
## Linux Directories

### Introduction

One of the tasks at which computers excel is the management of information. To manage information, you need some sort of organization. The method of organization that a computer uses is called the **file system**.

In this module you will learn about how the file system is structured and how to manage this file system. You will learn how to create and remove directories. You will learn how to move and rename directories. You will also learn how to tell when you are running out of file space so that you can make the appropriate decisions about what to keep and what to discard.

### In This Module You Will Learn:

- the basics of computer file systems.
- how Linux directories are structured.
- commands for listing the contents of directories.
- which command to use to find out which directory is open.
- how to delete a directory.
- how to find out how much disk space is available.
- shorthand directory notation that is applicable to all directories.
- shorthand directory notation for your account.

## Try it Live!

1. Log in to your Linux system. List the files in your home directory with `ls`.
   - a. Type `ls`
   - b. Press <Enter>

```
$ ls
. . . . . . [file list]
$
```

Figure 5-1 You Type `ls` at the System Prompt

2. List the files in your home directory with `ls -a`.
   - a. Type `ls -a`
   - b. Press <Enter>

The “-a” switch means “all.” As you can see, the `a` switch adds to the display files that are normally hidden—files that begin with a dot. We mentioned one such file in *Day to Day with Linux*. This is the file `.profile`, which you can use to customize your Linux account. Figure 5-2 shows a listing of files you might see. It is likely that some of these hidden files are housekeeping files, created by the system. In the display on your screen, note the shorthand notation—the single dot and the double dot. You remember that the single dot represents the current directory and the double dot represents the parent directory.

3. If the contents of your home directory are a little meager right now, list the */etc* directory.
   - a. Type *ls /etc*
   - b. Press <Enter>

You are likely to find a long list of files in this directory. List the files with *ls -a*.

   - c. Type *ls -a /etc*
   - d. Press <Enter>

> Remember that, if either **ls** or **ls -a** produces a file list that scrolls off the screen, you can stop the scrolling with <**Ctrl-S**> and resume the scrolling with <**Ctrl-Q**>.

4. You can also *pipe* the results of **ls** through **more**. We cover pipes a little later in the course, but the procedure is simple enough to use right here. At the shell prompt:
   - a. Type **ls /etc | more**
   - (*Be sure to leave a space on either side of the pipe symbol, |.*)
   - b. Press <Enter>
   - c. Press <Enter> again to scroll down one line.
   - d. Press the <Space Bar> to scroll down one full screen.

5. List the files in your home directory with `ls -l`.
   - a. Type `ls -l`
   - b. Press <Enter>

6. You can combine switches. List the files in your home directory with `ls -la`.
   - a. Type `ls -la`
   - b. Press <Enter>

7. `du` will tell you how much space your file system occupies. From your home directory, enter the following:
   - a. Type `du`
   - b. Press <Enter>

By default, `du` reports file size in *blocks*. A block is typically 1024 bytes. `du` will report file usage in bytes when you use the appropriate switch. The next exercise will tell you how to discover which switch is which.

8. As with many Linux commands, there are switches you can use to modify the output of the command. How do you find out what switches are available and what they do? Use `man`—which stands for manual.
   - a. Type `man du`
   - b. Press <Enter>
   - c. Press <Enter> again to scroll down one line.
   - d. Press the <Space Bar> to scroll down one full screen.
   - e. To quit the `man` display, press <q> (for “quit”).

Figure 5-3 shows a partial screen display for the `man` results for `du`.

10. You used `du` to find out how much disk space your files are taking up. Now use `du` to get the same information from some of the file systems of the members of your prearranged snoop group.

11. Remember that `du` reports on file usage starting with the current directory, including all subdirectories in that hierarchy. In Exercise 7, you used `du` to display information about your file system. Compare those results with the following:
    - a. Type cd /
    - b. Press <Enter>
    - c. Type du
    - d. Press <Enter>

> Remember that you can interrupt the output from most commands with <Ctrl-C>.

12. Unlike du, df reports on free space on an entire hard drive. To confirm that this is so, do the following:
    - a. Type cd /
    - b. Press <Enter>
    - c. Type df
    - d. Press <Enter>
    What you see on your screen is the display that df provides from your home directory.
    - e. Type cd /
    - f. Press <Enter>
    - g. Type df
    - h. Press <Enter>
    What you see on your screen is the display that df provides from the root directory. You can see that the information from the df command is the same no matter which directory you are in when you issue the command.

13. In this exercise, you will use cd to change to your home directory. Then you will create a directory called practice.
    - a. At the shell prompt, type cd
    - b. Press <Enter>
    - c. Type mkdir practice
    - d. Press <Enter>
    - e. Type ls
    - f. Press <Enter> and note the directory you have just created.

14. In this exercise, you will use `cd` to change to the directory **practice**. Next you will create a directory called **practice.temp** and use `ls` to confirm that the directory **practice.temp** exists.
    - a. Type `cd practice`
    - b. Press <Enter>
    - c. Use what you practiced in Exercise 13 to create the directory **practice.temp** and then use `ls` to confirm your success.

15. In this exercise, you will attempt to delete the directory **practice**. Our instructions will lead you through a process that will result in an error message from the system. As you go through this exercise, test yourself by trying to identify the incorrect instructions as you are carrying them out.
    - a. Type `cd`
    - b. Press <Enter>
    - c. Type `rmdir practice`
    - d. Press <Enter>

The system will respond with an error message similar to the following:

```
rmdir: practice: Directory not empty.
```

In this exercise, the first step returns you to your home directory. **practice** is one of your directories, but it is not empty. Did you remember that `rmdir` will not let you remove a directory that is not empty? To be able to delete the directory **practice**, you must first delete its subdirectory **practice.temp**.

16. In this exercise, you will delete the subdirectory **practice.temp**.
    - a. Type `cd practice`
    - b. Press <Enter>
    - c. Type `rmdir practice.temp`
    - d. Press <Enter>

17. Let's correct a typing error. Use <Ctrl-H> to change `ls -z` to `ls -l`.
    - a. Type `ls -z`
    - b. Press <Ctrl-H> to erase the "z".
    - c. Type `l`
    - d. Press <Enter>
