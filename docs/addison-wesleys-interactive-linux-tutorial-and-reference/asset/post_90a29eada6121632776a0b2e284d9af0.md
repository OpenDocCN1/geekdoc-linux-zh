
- **userid (UID)** Each user on a Linux system must have his or her own unique identifier, usually some form of his or her name. This is called the userid.
- **variable** An area in the computer's memory that acts as a storage compartment for values (content, data, or information) that you create.
- **who** Command that reports on which users are currently logged in.
- **wildcard** One character that represents other characters.
- **write** Command that sends on-line messages to users currently logged in.
- **X-Window System** The system on which most Linux GUIs are based.
