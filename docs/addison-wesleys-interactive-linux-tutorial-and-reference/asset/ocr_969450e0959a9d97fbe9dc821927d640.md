# To The Instructor

Addison-Wesley's *Interactive Guide to Linux by EduTrends* provides a basic introduction to Linux. Its goal is to give students user-level familiarity with the operating system and then become a reference book/CD. This package assumes no prior knowledge of Linux. CBT and Assessment software runs in the Windows environment. It assumes basic familiarity with Windows and with basic computer operation, including how to load the CBT program from the CD. Instructions for installing are included in the next section and in a readme file on the CD.

There is a variety of ways in which this book/CD package can add value to your course. If you are teaching a course in which the Linux operating system is not the focus, you may find that assigning this package for independent study will provide the necessary material to supplement your course. If the Linux operating system is the focus of your course, you can use this package as the main text or as an introduction to more in-depth material that you present in class. There are probably as many different ways to use this material as there are those of us who teach.

# Different Linux Configurations

There may be some aspects of the configuration of your Linux installation that will affect the student's ability to complete some of the Try It Live! exercises. If such is the case at your institution, please provide your Try It Live! the necessary information so that they will have a satisfying and successful experience with these exercises.

# Pedagogical Features of this book/CD-ROM package

The walk-through of using the book/CD-ROM package in “To the Student” gives a brief introduction to the basic components of the CD and the text as well as how they work together. This is a listing of particular features within the CD and text.

The Linux simulations on the CBT give students a pedagogical environment in which to first practice using Linux. Typing errors are caught immediately, and the student is prompted for the correct key.

After completing a module on the CBT, the student will then go to the Try It Live! material for the corresponding chapter in the book. In this chapter the student will be guided through a series of step-by-step exercises at a Linux terminal.

To help reinforce concepts just learned in the module, there are *hints that accompany some exercises*.
