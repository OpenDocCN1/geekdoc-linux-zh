# ### cd

+   * **What it does:** (1) Changes to directory *dirname*. (2) Changes to your home directory.
+   * **Syntax:** (1) `cd dirname`. (2) `cd`
+   * **Example 1:** (1) `cd folio` will change to the directory **folio**.
+   * **Example 2:** (2) `cd` by itself will change to your home directory.

# ### chmod

+   * **What it does:** Changes access permissions for a file.
+   * **Syntax:** `chmod [u|g|a] [+=] [rwx] [filename]`
+   * **Example:** `chmod ug+rx thisfile` adds execute permission to the file **thisfile** for the user (the file’s owner) and the group (the file owner’s working group).

# ### chsh

+   * **What it does:** Changes the shell.
+   * **Syntax:** `chsh [filename]`
+   * **Example 1:** Use the -1 switch to find out what shells are available.
