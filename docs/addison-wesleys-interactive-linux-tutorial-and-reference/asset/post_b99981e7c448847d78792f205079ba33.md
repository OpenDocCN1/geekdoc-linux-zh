## Find, Copy, and Move with vi

### Introduction

In the previous modules in this tutorial, you moved into what we might call vi's "ground floor"; interesting, but maybe not much more advanced than pencil and paper.

In this module, we move you "upstairs" into some parts of the vi terrain that pencil and paper can never occupy. The ability to find text in a lengthy file is a feature that you will use often. And the ability to copy and/or move text is so important that no one would even consider using a text processor that didn't offer this feature.

### In This Module You Will Learn:

- how to find text in your file.
- how to copy text and move it.

As we have done in earlier Try It Live! sections of this Study Guide, we will omit step-by-step instructions for some of the exercises. At the very end of this chapter of the Study Guide, you will find whatever step-by-step instructions we have omitted in the exercises.

1. Change to your directory **practice**.
2. Open vi with the file **nowtime**.

In the next group of exercises, you will search for patterns.

3. In this exercise, you will search for “time”.
   - a. Press `</>` to search forward in the file.
   - b. Type time
   - c. Press **Enter** to search for the pattern **time**.
   - d. Press `<n>` five times to find each occurrence of this pattern.
   
   Note that the status line indicates */time*, to tell you that you are searching forward in the file for the pattern **time**.

   - e. Press `<n>` again to wrap the find to the top of the file.
   
   Note the status line message when the find command wraps.

   - f. Press `<N>` to search for the same pattern in the opposite direction.
   
   Note that the status line message changes when the find command wraps in the opposite direction.

   - g. Press `<N>` again.
   
   Note that the status line indicates *?time* to tell you that you are searching backward in the file for the pattern **time**.

4. In this exercise, you will search for “is”.
   - a. Move the cursor to the bottom line of the file.
   - b. Move the cursor to the end of the line.
   - c. Press `<N>` to search backward in the file.

Note that the status line displays **?is**. The ? tells you that you are searching backward in the file for the pattern is.

   - g. Press `<N>` to continue the search in the opposite direction.
   
   Note that the status line now indicates /is to tell you that you are searching forward in the file for the pattern is.

5. In this exercise you will search for “right.”
   - a. Move the cursor to the first character in the file.
   - b. Press `</>`
   - c. Type **right**
   - d. Press `<Enter>` to search forward in the file for the pattern **right**.
   
   Note that the pattern **right** is part of the larger pattern **bright**.

In the next group of exercises, you will **yank**, **delete**, and **put** to copy and move text. In the Windows and Mac environments, we use the term “copy” to mean just what it says. In vi terminology, we use “yank” to copy. In the Windows and Mac environments, we “paste” to insert the contents of the buffer known as the “Clipboard.” In vi terminology, we “put” to insert the contents of the unnamed buffer. “Yank” = “copy.” “Put” = “paste.”

In step c of Exercise 7, the cursor was on a space when you used the command `<2y2b>`. In some versions of vi, yanking text back includes the character under the cursor.
