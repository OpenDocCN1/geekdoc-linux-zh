### 概述

一本最大化 Linux 系统和应用性能的必备指南。从华尔街到好莱坞，Linux 运行着世界上许多最关键的商业系统。Linux 的性能如今影响着整个企业。

在《Linux 服务器性能调优》（*Performance Tuning for Linux Servers*）一书中，一支由 IBM 最有经验的 Linux 性能专家组成的团队将向您展示如何查找瓶颈、衡量性能并识别有效的优化方案。本书不仅仅涵盖内核调优；它还展示了如何最大化在 Linux 上运行的实际应用程序和数据库的端到端性能。全书中，作者提出了基于当前最受欢迎的企业 Linux 平台的现实示例，包括基于 Intel 的 Red Hat 企业 Linux 和 Novell SUSE Linux 企业服务器。这些示例旨在简洁、清晰，并易于适应任何现代 Linux 环境。

您将发现如何：
-   从一开始就安装和配置 Linux 以实现最大性能
-   评估并选择适合您的 Linux 环境的正确硬件架构
-   理解 Linux 内核 2.4 到 2.6：组件、性能问题和优化机会
-   掌握核心 Linux 性能调优原则和策略
-   利用免费的开源工具进行测量、监控、系统跟踪和基准测试
-   解释性能数据以分析您的 Linux 服务器的实际行为
-   优化 Linux 系统调度器、内存、I/O、文件系统和网络
-   调优运行商业工作负载的 Web、文件、数据库和应用服务器
-   预测调优参数或配置变更的影响
-   调优 Linux 代码：优化设计、计时、套接字、线程、同步等
-   为最大性能进行架构设计：SMP 扩展、集群化和拓扑
-   在内核和应用调优中集成端到端系统优化项目

无论您是管理员、开发人员、集成商还是顾问，*Linux 服务器性能调优* 都提供了您所需的专长。
