This section measures the rate at which the C library's bcopy(1) function can copy unaligned data. Unaligned data often requires more time to copy than aligned data. In particular, the bcopy(1) routine needs to ensure that it never attempts to read a byte that is not present in the page. This often makes an unoptimized bcopy(1) routine extremely slow.
