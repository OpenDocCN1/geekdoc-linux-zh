Iometer provides a slightly different view of performance tuning. Its goal is not to run a task and see how quickly it completes or completes in a period of time. Instead, it provides a steady-state workload and allows you to monitor various aspects of the system under load and see how the underlying system responds. In addition, you can vary the system parameters, configuration, and software installed and see how those changes affect the system. In other words, it provides many more tuning control points for analyzing changes in workloads than any of the other benchmarking tools. Iometer was publicly available as pgmeter, also known as Penguinometer. pgmeter is available at (or <http://sourceforge.net/projects/pgmeter>.

# ## tiobench

tiobench is a file system benchmark that is threaded and can generate tests using one or more simultaneous threads of I/O. This allows applications that generate I/O in parallel, either independently of each other (truly random) or with some coordination (for example, a database with multiple backends).
