The most common error condition revolves around page faults, where the kernel has to retrieve the required page from secondary storage. Other possible error conditions may be related to or triggered by any potential page protection issues. From a physical address perspective, Linux differentiates among different memory zones (ZONE_DMA, ZONE_NORMAL, and ZONE_HIGHMEM), where each zone represents different characteristics. Most of the memory allocation happens in ZONE_NORMAL, whereas ZONE_HIGHMEM represents the physical addresses greater than 896MB. (See the later section "VM Tunables" for more information on memory zones.)
