# CHAPTER 4 • AUTOMATING STORAGE

Prior to vSphere, rescanning was an onerous task in the vSphere Client. It involved navigating to the Configuration menu for the host and moving to the Storage Adapters section and clicking the Rescan task. For a cluster with a number of hosts, this could take a long time and was very tedious. In vSphere 4, VMware added a Rescan Storage menu item to the vSphere C Client, which became whenever you right-clicked a Cluster, Folder, or Datacenter object, and it is still present in the modern-day vSphere Web Client. Consequently, it becomes much easier to rescan storage for multiple hosts in the GUI. This functionality is also available from the Get-VMStorage PowerCLI cmdlet. An advantage of Get-VMHostStorage over the GUI client is that it is particularly useful for rescanning multiple clusters.

For example, the code in Listing 4.6 rescans for new storage for clusters 01 and 02.

+   LISTING 4.6 Resanning clusters for new storage

```
Get-Cluster Cluster01, Cluster02 | Get-VMHost | \
Get-VMHostStorage -RescanAllHba
```

# Adding Datasters

Now that you have filled your servers with some local disk drives, connected them to a Fibre Channel or iKSI SAN, or set up an NFS server, you need to create some datasters that you can store your virtual machines on. To do this, use the New-Datastore PowerCLI cmdlet (The New-Datastore cmdlet can be used to create datasters for any of the supported types of storage).

The key to get it right with this cmdlet is to understand the types of path that you must provide to New-Datastore. Paths provided by Get-ScsLun cmdlet can prove useful in helping you identify the correct path for each type.

# Local Storage

Let's look at creating a new datastore on local storage. By using the Get-ScsLun cmdlet, you can identify the LUN provided by the local SCSI controller. In the next example, we used the fact that we have a Dell ESXi host with a PERC 6/i integrated RAID controller to identify the LUN it provides:

```
$LocalLun = Get-VMHost vesxi05* | Get-ScsLun -LunType disk | \
Where {$_.Model -match "PERC 6/i"}
```
