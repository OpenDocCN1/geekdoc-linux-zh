# Use Fault Tolerance

VMware Fault Tolerance (FT) was first introduced with vSphere 4.0. FT is an extension of VMware High Availability (HA) that enables guaranteed downtime. At a high level, it works by creating a secondary VM on a compatible vSphere host and replicates every external input to the CPU from the primary VM to the secondary VM. This results in the processors executing the same internal code on a per-instruction basis. Then, if the primary VM dies for any reason, the secondary VM continues executing and picks up where the primary left off. The operating system has no knowledge that it just blanked and awakened on a different physical host. More importantly, your users won't know either. So, how do you enable this uptime pixie dust? In PowerCLI, it's one line (see Listing 5.14).

# LISTING 5.14 Enabling FT

```powershell
(Get-VM "HMIC").ExtensionData.CreateSecondaryVM_Task($null)
```

Optionally, you could designate VMHost the secondary VM is created by supplying the VMHost managed object reference, or MoRef (see Listing 5.15).

# LISTING 5.15 Specifying where the secondary VM should be created

```powershell
$VMHost = Get-VM -Name 'vSphere01*'
$VM = Get-VM -Name 'HMVIC'
$VM.ExtensionData.CreateSecondaryVM_Task($VMHost.Id)
```

As we just showed, it's simple to enable FT. It's just as simple to disable, by Listing 5.16.

# LISTING 5.16 Disabling FT

```powershell
$VM = Get-VM -Name 'HMVIC' | Where-Object {
  $_.ExtensionData.Config.FtInfo.Role -eq 1}
$VM.ExtensionData.TurnOffFaultToleranceForVM()
```

You will find that this highly protected state carries with some restrictions. For instance, you cannot modify any configuration or settings for the VM while protected with FT. You will need to follow these steps:

- 1. Disable FT on the VM.
- 2. Make the change (virtual hardware, SvMotion, vSphere vStorage API for Data Protection [VADP]).
- 3. Enable FT on the VM.

Fortunately, it's relatively easy to wrap the change in a PowerShell script. Listing 5.17, we demonstrate changing the RAM allocation on an FT-protected VM.

# LISTING 5.17 Modifying FT-protected VMs

```powershell
# Get the VM
$VM = Get-VM -Name 'HMVIC' | Where-Object {
  $_.ExtensionData.Config.FtInfo.Role -eq 1}
# Disable FT
# Add memory
Set-VM -VM $VM -MemoryMB 4096 -Confirm:$false
```

# Distributed Power Management

Distributed Power Management (DPM) is an extension of the Distributed Resource Scheduler (DRS). DPM focuses on maximizing the power efficiency of your virtual environment by powering physical hosts when not needed and turning them back when the additional capacity is required. DPM is enabled on a per-cluster basis and achieves these power savings by carefully balancing the load across a cluster. Once enabled, DPM carefully monitors the resource utilization of the cluster—and particularly of each host. When it determines consolidating VMs onto fewer hosts will result in savings, it powers off unused hosts. When demand increases, it powers on hosts to handle the load.

Unfortunately, DPM doesn't offer any cmdlets for managing DPM, so we wrote the Get-DPM function to see the status of DPM across the environment.

# LISTING 5.18 Get-DPM function

```powershell
function Get-DPM {
<#
    .SYNOPSIS
    Get the status of DPM running.

    .EXAMPLE
    Get the status of DPM for a cluster
    Get-Cluster | Get-DPM
#>
[CmdletBinding()]
param(
  [parameter(
    Mandatory=$false,
    ValueFromPipelineByPropertyName=$true
  )]
  [Alias('Name')]
  [String]$Cluster
)

process {
  $ClusterObj = Get-Cluster $Cluster
  $ClusterView = $ClusterObj | Get-View -Property Configuration

  $info = [PSCustomObject]@
  $info.Name = $ClusterView.Name

  if ($ClusterView.Enabled -eq $false) {
    $info.Status = "Disabled"
  } else {
    $info.Status = "Enabled"
  }

  $info.Behavior = $ClusterView.Configuration.DefaultpmBehavior
  $info.Threshold = $ClusterView.Configuration.HostActionRate

  return $info
}
```

The Get-DPM function, you can quickly get the status of DPM running across the environment in one line:

```powershell
Get-Cluster | Get-DPM
```

Once you've identified the clusters that are not running DPM, you can use the Set-DPM function shown in 5.19 to configure DPM.

# LISTING 5.19 Set-DPM function

```powershell
function Set-DPM {
<#
    .SYNOPSIS
    Configure DPM for a cluster.

    .EXAMPLE
    Enable DPM for a cluster
    Get-Cluster clusterName | Set-DPM -Enable

    .EXAMPLE
    Enable DPM for a cluster and set it to manual
    Get-Cluster clusterName | Set-DPM -Enable -Behavior Manual

    PARAMETER Cluster
    [System.String]
    The cluster to check.

    PARAMETER Enable
    [System.Boolean]
    Enable DPM.

    PARAMETER Disable
    [System.Boolean]
    Disable DPM.

    PARAMETER Threshold
    [System.Integer]
    A value between 1 and 5 indicating the aggressiveness of DPM actions. 1 is most aggressive, 5 is least.

    PARAMETER Behavior
    [System.String]
    Manual or Automated, indicating whether DPM will automatically apply recommendations or wait for the user to apply.

    .INPUTS
    [VM.VimAutomation.ViCore.V1.Inventory.ClusterImpl]

    .OUTPUTS
    PSCustomObj
#>
[CmdletBinding(SupportsShouldProcess=$true)]
param(
  [parameter(
    Mandatory=$true,
    ValueFromPipelineByPropertyName=$true,
    ParameterSetName="EnableDpm"
  )
  [parameter(
    Mandatory=$true,
    ValueFromPipelineByPropertyName=$true,
    ParameterSetName="DisableDpm"
  )]
  [Alias('Name')]
  [String]
$Cluster,

  [System.Boolean]
$Enable,

  [System.Boolean]
$Disable,

  [System.Integer]
$Threshold,

  [System.String]
$Behavior
)

process {
  if ($PSCmdSetName -eq "EnableDpm") {
    if ($PSCmdlet.ShouldProcess($Cluster, "Enable DPM")) {
      $ClusterObj = Get-Cluster $Cluster
      $ClusterObj.ExtensionData.ReconfigDpmSettings($null, @{
        Enabled = $true
        HostActionRate = $Threshold
        DefaultpmBehavior = $Behavior
      })
    }
  } elseif ($PSCmdSetName -eq "DisableDpm") {
    if ($PSCmdlet.ShouldProcess($Cluster, "Disable DPM")) {
      $ClusterObj = Get-Cluster $Cluster
      $ClusterObj.ExtensionData.ReconfigDpmSettings($null, @{
        Enabled = $false
      })
    }
  }
}
```
