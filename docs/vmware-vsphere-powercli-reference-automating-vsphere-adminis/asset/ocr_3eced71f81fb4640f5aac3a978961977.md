# CHAPTER 8 • CONFIGURING VIRTUAL MACHINE HARDWARE

To add a new hard disk to a VM, use the New-HardDisk cmdlet. The -CapacityGB parameter allows you to specify the size of the new virtual disk.

> TIP Notice that the parameter value is in gigabytes (GB), but you may want to enter the new disk size in terabytes (TB) or eventually petabytes (PB). PowerShell comes to the rescue again. It has built-in constants-KB, MB, GB, TB (terabyte), and PB (petabyte)—for converting values. When you need to convert a disk or memory value to GB, just divide the value by 1 GB. (Note that in the code's no space between the value and the constant.)

```
[vSphere PowerShell] C:\Scripts\1.5TB/1GB

1536
```

```
Get-VM VM001 | New-HardDisk -CapacityGB 10
```

| CapacityGB | Persistence | Filename |
| --- | --- | --- |
| 10.000 | Persistent | [Datastore1] VM001/VM001_1.vmdk |

In some cases, it will be necessary to store the new hard disk on a datastore. To specify a datastore that is different from the default (the datastore where the virtual machine's configuration file [VMX] is stored), use the -Datastore

```
New-HardDisk -VM VM001 -CapacityGB 10 -Datastore Datastore2
```

| CapacityGB | Persistence | Filename |
| --- | --- | --- |
| 10.000 | Persistent | [Datastore2] VM001/VM001.vmdk |
