# Running Scripts in the Console

A nice feature of PowerActions is the ability to run a script stored on the local workstation using the vSphere Web Client. By using the Open Script toolbar button in PowerActions, it is possible to read in the contents of a PowerShell script file, execute it, and view the results in the console. Listing 23.1 contains a straightforward example that illustrates this by action creating 10 clusters in the HQ datacenter.

# LISTING 23.1 Create Ten Clusters in the HQ Datacenter

```
$Location = Get-Datacenter HQ .. ForEach-Object {New-Cluster -Name "Cluster_$" -Location $Location -HAEnabled:$true -DRSEEnabled:$true}
```
