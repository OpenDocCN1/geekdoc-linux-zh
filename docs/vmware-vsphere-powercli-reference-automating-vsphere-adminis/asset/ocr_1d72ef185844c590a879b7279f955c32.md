# Ordering the Data

PowerShell has some basic cmdlets that allow you to manipulate the data. One of these is the Sort-Object cmdlet. In the previous section, the returned objects were ordered as they were provided by PowerShell. To make your reports more readable, you can specify a specific order on the returned objects.

```
Get-VM | Select Name, PowerState,
(@($N='ProvSpaceGB'; E={
  [Math] : Round($_.ProvisionedSpaceGB,1)
}}
Sort-Object -Property Name |
Format-Table -AutoSize
```
