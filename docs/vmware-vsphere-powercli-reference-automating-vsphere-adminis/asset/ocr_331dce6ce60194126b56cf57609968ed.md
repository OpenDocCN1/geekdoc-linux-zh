Set-VMHostLockdownException -UserName dom\mySvcAcct
Set user as the only Lockdown exception for all VMHosts (effectively
removes other users)

.Example
Set-VMHost *dev.dom.int | Set-VMHostLockdownException -UserName `dom\mySvcAcct2 -Append

Add given user to the lockdown list of users for targeted VMHosts
.Example
Set-VMHostLockdownException -UserName:$null -Id $arrHostSystems.MoreRef
Clear the list of Lockdown exception for users VMHosts from myCluster;
$arrHostSystems array Host View objects for the VMHosts in cluster "cluster", and accessing the MoreRef property of the array gives all of the HostSystems' MoreRefs as the value to -Id

PSObject with information about the new lockdown exceptions for given
VMHost

```
#
[CmdletBinding(SupportsShouldProcess=$true,
DefaultParameterName="VMHost")
```

```
Param(
## User name(s) with which to update lockdown exceptions. Remove to all
## user exceptions, specify $null as the value. For Active Directory
## user, specify name in "domain\\user\]" format
[parameter(Mandatory=$true)][AllowNull()][string[]]$Username,
## VMHost for which to select lockdown exceptions. If not specified, will act
non all VMHosts
[parameter(ValueFromPipeline=$true, ParameterSetName="VMHost")
[VMware.Vim.Automation.ViCore.V1.Inventory.VMHostImpl[]]$VMHost,
## ID of VMHost for which to select lockdown exceptions
[parameter(Mandatory=$true, ValueFromPipelineByPropertyName=$true,
ParameterSetName="VMHostId") [Alias("MoreRef", "Id")
[VMware.Vim.ManagedObjectReference[]]$VMHostId,
## Switch: append given user to existing list of exceptions? If not,
## replaces current list with specified user
```
