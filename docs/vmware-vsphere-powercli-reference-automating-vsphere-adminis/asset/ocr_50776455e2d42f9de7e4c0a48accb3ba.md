This will add the group using default settings, so it's still a good idea to verify, using the GUI, the recovery plan is configured for the needs of your business. But it is a convenient method of ensuring that minimum amount of protection is available for your virtual machines.

However, having a plan in place is not the same as having a tested plan that you knows.
