# HOST POWER ACTION LEVELS

Action levels, shown in the Set-DPM function as the threshold, define the level at which a power action is recommended. A power action is when vCenter recommends that a host be either powered on or powered off. These settings have similar purpose to the DRS recommendation settings for cluster. For instance, a power action level 1 is the most aggressive for powering hosts on off. A level 5 is so conservative that it rarely, ever, powers off a host, and only powers on in the event of severe resource imbalance. The double-edged sword is that the power action is responsible for much confusion. Our advice is to never forget that this setting impacts both actions and will be right.

# Configure Host Profiles

Host profiles are used to ensure compliance across a series of hosts within vCenter Server. This is accomplished by identifying a reference host and creating a host profile. The host profile captures the configuration of that host and saves it into the vCenter Server Database. At any time after that, you can test the configuration of a given vSphere host against that profile and report on compliance. If a host has fallen out of compliance, you simply reapply the profile. As of vSphere 6, host profiles currently cover the following configuration settings:

- Advanced configuration options
- Authentication
- Date/time
- Firewall
- Groups
- Memory reservations
- Networking
- Security
- Storage
- Users

# LISTING 5.20 Creating a host profile

```powershell
New-HostProfile -Name Prod01 `
  -ReferenceHost (Get-Host prod01) `
  -Description "Host profile for cluster"
```

# LISTING 5.21 Associating a host profile and checking for compliance

```powershell
Apply-HostProfile -Entity (Get-Host prod01) `
  -Profile (Get-HostProfile prod01) `
  -AssociateOnly
```

# LISTING 5.22 Applying a host profile to any noncompliant host

```powershell
Get-Cluster Prod01 |
Get-VMHost |
Test-VMProfileCompliance |
ForEach-Object {
  $profile = Get-HostProfile $_.VMHost |
  Set-VMHost -State 'Maintenance' -VMHost $_.VMHost |
  Apply-HostProfile -Profile $profile |
  Set-VMHost -State 'Connected' |
  Test-HostProfileCompliance
}
```
