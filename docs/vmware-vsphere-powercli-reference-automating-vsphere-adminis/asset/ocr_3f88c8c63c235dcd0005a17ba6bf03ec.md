When the Get-Escli namespaces do not provide access to the command or data you want to access, you can always fall back on establishing a SSH connection to the limited ESXI console based on BusyBox. To allow the SSH connection, you first have to make sure the SSH service is running on the ESXi node. This can be done with a few cmdlets.

```
$EsXNames = 'es1.local.test', 'es2.local.test'
```

```
$Get-VMHost -Name $EsXNames | Get-VMHostService |
Where { $_.Key -eq "TSM-SSH" } |
Start-VMHostService -Confirm:$false
```

> For applications like this you might want to use, but perhaps less known, PowerShell feature known as wildcarding and match specific characters. Wildcards, the first line of your script would look like:

```
$EsXNames = 'es[1-2].local.test'
```

or

```
$EsXNames = 'es[1-2].local.test'
```

Wildcards are documented in the PowerShell User Guide:

```
https://www.vmware.com/support/developer/PowerCLI/PowerCLI60R1/
doc/vsp_powercli_60rl_us.pdf
```
