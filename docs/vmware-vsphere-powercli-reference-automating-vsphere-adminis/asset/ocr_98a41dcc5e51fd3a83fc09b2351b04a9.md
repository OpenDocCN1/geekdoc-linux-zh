# ALTERNATIVE METHOD TO THE POWERSHELL PLUGIN

**LISTING 21.12** Example of return codes: `Test-ReturnCodeLocal.ps1`

```
param ($a)

try {
    $Random = Get-Random -Minimum 10 -Maximum 21

    Write-Host "Random number is $Random"

    $Result = $Random * $a

    Write-Host "Result is $Result"

    if ($Result -lt 40){
        Write-Host "Result is less than 40"
        exit 0
    } else {
        Write-Host "Result is greater than 40"
        exit 1
    }
} catch [Exception] {
    Write-Host "There was an error"
    exit 2
}
```

Now create the new return code workflow `Invoke-PSScriptReturnCode`. On the Inputs tab, create the following inputs (Figure 21.30):

+   - powershellPath Type: `String`
- scriptPath Type: `String`
- arguments Type: `String`
