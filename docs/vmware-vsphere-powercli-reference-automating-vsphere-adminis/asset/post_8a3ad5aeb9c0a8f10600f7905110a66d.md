# Inconsistent Port Groups

If you're using standard switches, it's important that all port groups are consistently defined on all hosts in your cluster. If you fail to do so, you might encounter vm-errors. The function in A.7 will help you detect inconsistently named port groups.

```powershell
LISTING A.7 Get-MissingPortGroup
```

```powershell
function Get-MissingPortgroup {
    SYNOPSIS
    Gets the inconsistent virtual portgroups in a cluster
    .DESCRIPTION
    This function creates a report of the inconsistent portgroups in a cluster. It reports which portgroups are missing on which host.
    .NOTES
    Source: Automating vSphere Administration
    Authors: Luc Dekens, Brian Graf, Arnim van Lieshout, Jonathan Medd, Alan Renouf, Glenn Sizemore, Andrew Sullivan
    .PARAMETER Cluster
    The Cluster object to check
    .EXAMPLE
    Get-MissingPortGroup -Cluster (Get-Cluster CL01)
    .EXAMPLE
    Get-Cluster | Get-MissingPortGroup
}
```

```powershell
# create an array with all available portgroups in the cluster
$clusterHosts = @($cluster | Get-VMHost)
$refPortGroups = @($clusterHosts | Get-VirtualPortGroup -Standard)
Select-Object -Unique
```

```powershell
# compare the hosts against the reference array
foreach ($vmHost in $clusterHosts) {
    $diffPortGroups = @($vmHost | Get-VirtualPortGroup -Standard)
    $differences = @(Compare-Object $refPortGroups \
    $diffPortGroups)
    foreach ($item in $differences) {
        $objPG = "" | Select-Cluster,HostName,MissingPortGroup
        $objPG.Cluster = $cluster
        $objPG.HostName = $vmHost.Name
        $objPG.MissingPortGroup = $item.InputObject
        $objPG
    }
}
```
