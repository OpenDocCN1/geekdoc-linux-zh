# What Is in the Statistical Data?

The Get-Stat cmdlet returns the statistical data as one or more FloatSample objects. To have a good grasp of what you can do with the returned data, you should know what is present in the FloatSampleImpl object. With the Get-Member cmdlet, it is easy to check what properties are available in the object; see Listing 16.10.

# LISTING 16.10 Using the Get-Stat and Get-Member cmdlets to obtain statistical data

```
Get-Stat -Entity (Get-VMHost) | `
>> Select -First 1) -Stat "mem.usage.average" \
>> -MaxSamples 1 | Select-Object *
>>
```
