# Querying Workflow Executions

Now that we know how to obtain both workflow state and output, it may be well to obtain all executions for a given workflow so that state and output can be easily obtained for any execution. Listing 21.24 retrieves all executions for a given workflow.

LISTING 21.24 Get-vROWorkflowExecution

```
function Get-vROWorkflowExecution {
<#n  .SYNOPSIS
    Get vRO Workflow Executions
  .DESCRIPTION
    Get vRO Workflow Executions
  .PARAMETER Name
    Retrieve workflow by name
  .PARAMETER Server
    vRO Server to connect to
  .PARAMETER Credential
    PS Credential Object
#
```
