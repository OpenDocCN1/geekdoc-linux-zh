Using the New-IPPool function, create a new IP pool to be allocated to the vApp. For instance, the code in Listing 10.17 creates such a pool.

# LISTING 10.17 Creating a new IP pool

```
Get-Datacenter 'DC1' |
  New-IPPool -Name '10.10.10.0' |
  -IPv4SubnetAddress '10.10.10.0' |
  -IPv4Gateway '10.10.10.1' |
  -IPv4Netmask '255.255.255.255' |
  -IPv4Range '10.10.10.11#244' |
  -IPv4DNS '10.10.10.5' |
  -DnsDomain 'vSphere.local' |
  -DNSearchPath 'prod.vSphere.local', 'dev.vSphere.local' |
  -IP4PoolEnabled $true
```

> NOTE The IP range parameters take the starting IP address and count using the <IP Address>:<Count> format. The code in Listing 10.17 would create a new IP pool that included 10.10.10.11-10.10.10.255.
