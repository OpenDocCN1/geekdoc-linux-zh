# Adding a Virtual Disk

If there is one universal truth, it is that there is no such thing as enough storage. No how much disk space is assigned to a VM, it will inevitably need more. As a best practice, always try to right-size disks from the start and determine a reasonable amount of free space. There is no need to wastefully overallocate—more can be provisioned online. Reducing allocated space is not a trivial task.
