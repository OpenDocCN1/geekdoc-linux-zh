Use the code in Listing 19.1 to see a list of commands that can be run in vCloud Director. This will return all cmdlets available for use within vCloud Director. Notice that a majority of these command names contain the characters CI (for Cloud Infrastructure).

# LISTING 19.1 Obtaining a list of vCloud Director cmdlets

```
# Return any module ending in .Cloud and save it to a variable
$mod = Get-Module *.Cloud -ListAvailable
```

```
# Use the Get-Command cmdlet searching for the target module and
filter on Cmdlet
Get-Command -Module $mod -Type Cmdlet | Select Name, ModuleName
```

# Connecting to vCloud Director

Before you work within the vCloud Director environment, you must log on to the target private cloud to authorize the PowerShell session. You can then connect to vCloud Director using the Connect-CIServer command:

```
Connect-CIServer -Server vCD.vmwarelab.com -User Administrator
-Password VMware!
```

At times, it is beneficial to run multiple PowerShell sessions against vCloud Director at the same time. This may be through the use of PowerShell jobs, scripts invoking other scripts, and so on. You can leverage a single vCD login across multiple sessions by grabbing the SessionSecret from your main vCloud session when logging into vCloud Director:

```
$connection = Connect-CIServer -Server vCD.vmwarelab.com -User Administrator \
-Password VMware!
```

You can also run this command without placing your credentials in your code by using the Get-Credential cmdlet:

```
$connection = Connect-CIServer -Server vCD.vmwarelab.com -Credential \
(Get-Credential)
```
