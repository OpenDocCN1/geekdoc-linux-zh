Typical use of the function would be similar to the following:

```
PS C:\> Get-VMHost vsanesxi01* | New-NFS41Datastore -Name NFS26\n-NFSHost '192.168.0.106,192.168.0.107' -Path NFS26
```

| Name | FreeSpaceGB | CapacityGB |
| --- | --- | --- |
| NFS26 | 22.343 | 29.655 |

Once the NFS 4.1 datastore has been created, you can use the standard PowerShell cmdlets Get-Datastore and Remove-Datastore to manage it, just as you would for other types of datastore. For example, let's look at our NFS 4.1 datastore NFS26 and its type (NFS41), compared to the type (NFS) reported for other NFS 3 datastores.

```
PS C:\> Get-Datastore NFS* | Format-Table Name, Type -AutoSize
```

| Name | Type |
| --- | --- |
| NFS12 | NFS |
| NFS26 | NFS41 |
| NFS11 | NFS |
| NFS01 | NFS |
| NFS10 | NFS |
