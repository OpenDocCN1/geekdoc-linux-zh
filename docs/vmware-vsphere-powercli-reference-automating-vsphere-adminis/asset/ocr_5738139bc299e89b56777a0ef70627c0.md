# Change the Default PSP for an SATP

On a similar note, you can also set the Default PSP for an SATP. Listing 23.4 contains code modified from Listing 4.14 in Chapter 4 to make it useful for in PowerActions. Given the GUI-based nature of the PowerActions tool, we have added interactivity to make it more user friendly.

LISTING 23.4 Setting the Default PSP for an SATP

```
param
  [Parameter (Mandatory=$true)]
  [VMware.VimAutomation.ViCore.Types.Inventory.VMHost]

  [String]
  $SATP
```

```
  System.Management.Automation.Host.ChoiceDescription "VMW_PSP&RR", \
```
