The Get-Enumerator method that is available on the hash table will return each key-value pair that exists in the hash table. The key-value pairs are then passed, over the pipeline, to the Foreach-Object code block. In that code block, the AdvancedSetting, defined in the Name property, is updated to the new value that was specified in the Value property.
