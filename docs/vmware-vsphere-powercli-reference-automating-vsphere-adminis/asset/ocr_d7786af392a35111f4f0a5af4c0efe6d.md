# Configuring an iSCSI Target

Neither local iSCSI nor Fibre Channel requires any automation configuration from POWERCLI at the adapter level, but you can automate the configuration of the iSCSI connection. If you do not have a hardware iSCSI HBA and are planning to use the built-in software iSCSI adapter, you must first enable it, which is disabled by default. To enable this adapter for all hosts in Cluster01, use the code in Listing 4.1.

# Listing 4.1 Enabling iSCSI software adapter for all hosts in a cluster

```
Get-Cluster Cluster01 | Get-VMHost | Get-VMHostStorage
Set-VMHostStorage -SoftwareSCSIEnabled=$true
```

Your next task is to create an iSCSI target for each host using the New-iSCITarget cmdlet. This has many parameters, but the only required is one of the iSCSI target. If your organization requires the Challenge Handshake Authentication Protocol (CHAP), you will need to set specific parameters from the eight CHAP-related parameters available. You may also have to change the network port from the default of 3260 and give that a name.

In Listing 4.2, you will create a dynamic iSCSI target with an IP address of 17.20.0.10 configure CHAP parameters. Note that for each host returned in the cluster, you use the Get-VMHostHba cmdlet with the parameter and iSCSI value to ensure that you configure the iSCSI adapter.
