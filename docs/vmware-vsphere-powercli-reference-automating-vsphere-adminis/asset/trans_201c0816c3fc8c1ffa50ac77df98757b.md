# vRO New DRS Rule 工作流

创建一个新的 vRO 工作流，New-DRSRule。设置如下输入（图 21.22）：

- drsRuleName 类型：string
- cluster 类型：string
- vms 类型：描述：用逗号分隔多个虚拟机
- keepTogether 类型：boolean
- vCenter 类型：string
- username 类型：string
- password 类型：SecureString

![](img/62596f5acc979040608a4e5111beb7d6_774_0.png)
