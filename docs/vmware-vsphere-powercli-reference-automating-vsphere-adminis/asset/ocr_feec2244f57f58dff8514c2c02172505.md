The Get-VILocation retrieves the parent folder (location) of the object using
nested objects stored in the VIPath property. You need to use this filter in
-Location parameter of the New-Datacenter cmdlet:

```
ForEach ($dc in Import-Clixml C:\Export\Datacenters.xml") {
  New-Datacenter -Location ($dc.VIPath | Get-VILocation) \
  Name $dc.Name
}
```

# VM and Host Folders

Creating the vm and host folders is similar to creating the datacenter folders,
except that you need to provide the datacenter object as the parent object. Use the
GetEnumerator() method to pull all the hash items in the pipeline. This, how-
ever, will also provide the datacenter folders on the pipeline and you already imported
them, so you need to filter

```
$folderStructure.GetEnumerator() | %
if ($_.Name -ne "Datacenters") {
  $_.Value | New-FolderStructure (Get-Datacenter $_Name)
}
```

# Clusters

```
ForEach ($Cluster in Import-Clixml C:\Export\Clusters.xml") {
  $NewCluster = New-Cluster -Location ($cluster.VIPath | \
  Get-VILocation(Get-Datacenter $cluster.Datacenter)) \
  Name $Cluster
  Set-Cluster -Cluster $NewCluster -DrsEnabled:$True \
  -VMMSwapfilePolicy $cluster.VMMSwapfilePolicy \
  -DrsAutomationLevel $cluster.DrsAutomationLevel.value
}
```
