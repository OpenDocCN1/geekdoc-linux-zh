If you know the Peripheral Component Interact (PCI) information for the network card, you have to query the underlying SDK object; the information isn't available from the objects returned by the Get-VMHostNetworkAdapter cmdlet. This can be done through .ExtensionData property. Let's generate a full report like the HBA report we created with the script in Listing A.3. The script in Listing A.4 creates a report of all network interface cards on all hosts in clusters.

# A.4 Network interface card report

```powershell
$nicReport=()
foreach ($cluster in Get-Cluster) {
    foreach ($vmHost in @($cluster | Get-VMHost)) {
        foreach ($nic in @($vmHost | Get-VMHostNetworkAdapter)) {
            $objNic = "" | Select ClusterName, HostName, Pci,
DeviceName, Mac, BitRateSec, FullDuplex
            $objNic.ClusterName = $nic.ClusterName
            $objNic.HostName = $vmHost.Name
            $objNic.Pci = $nic.ExtensionData.Pci
            $objNic.DeviceName = $nic.DeviceName
            $objNic.Mac = $nic.Mac
            $objNic.BitRateSec = $nic.BitRateSec
            $objNic.FullDuplex = $nic.FullDuplex
            if ($nic.ExtensionData.Pci) {
                $nicReport += $objNic
            }
        }
    }
}
$nicReport | Export-Csv NicReport.csv
```

Begin {
  $urlPci = "http://pci-ids.ucw.cz/v2.2/pci-ids"
  $filename = "${env:Temp}\pci.ids"
  $pciDevices = @{}
  # Download file if not present or if forced download
  if (! (Test-Path $filename) -or $forcedDownload) {
    $web = New-Object Net.WebClient
    $web.DownloadFile($urlPci,$filename)
  }
  # Read file into hash table
  Get-Content $filename | Where-Object {
    $_.Length -ne 0 -and $_[0] -ne "#"
  } | Foreach-Object {
    if ($_[1] -eq "t") {
      $subdeviceId = $_.Substring(2,4)
      if (!$pciDevices[$vendorId].deviceTab.ContainsKey($subdeviceId)) {
        $pciDevices[$vendorId].deviceTab[$subdeviceId] =
          $_.Substring(6).TrimStart(" ")
      }
    } else {
      $pciDeviceId = "0x" + $_.Substring(1,4)
      if (!$pciDevices[$vendorId].deviceTab.ContainsKey($pciDeviceId)) {
        $pciDevices[$vendorId].deviceTab[$pciDeviceId] =
          $_.Substring(5).TrimStart(" ")
      }
    }
  } else {
    $vendorId = "0x" + $_.Substring(0,4)
    if (!$pciDevices[$vendorId].ContainsKey($vendorId)) {
      $pciDevices[$vendorId] = New-Object -ArgumentList @{
        Vendor = $_.Substring(4).TrimStart(" ")
        deviceTab = @{}
      }
    }
  }
}

Notice that the cluster objects returned contain only High Availability (HA) and Distributed Resource Scheduler (DRS) information. If you want to know more information, you have to use the underlying SDK object, which is accessible through the .ExtensionData property. If you want to know the number of hosts in a cluster, you can simply count the items in the .ExtensionData.Host property.

```powershell
Get-Cluster | Select Name,
@{N="NumHosts";E={$_.ExtensionData.Host.count}} | ft
```
