# FIGURE 18.9 CheckMigrate_Task

# CheckMigrate_Task

Tests the feasibility of a proposed MigrateH Task operation.

Required Privileges

Parameters

| Name | Description |
| --- | --- |
| _is | MigrateMachineReference | A reference to the VirtualMachineProvisioningChecker used to make the call. |
| vm | MigrateMachineReference | The virtual machine to migrate. |
| host | MigrateMachineReference | The target host on which the virtual machines will run. If the host represents a standalone or a DFS-enabled cluster, in the first case the host must be specified, in the second case any host can be specified. If the virtual machine is a template, then either host can be specified. |
| pool | ResourcePool | The target resource pool for the virtual machines. If the pool parameter is null, the virtual machine's current pool is used. If the virtual machine is a template, then a different pool or different center can be specified. |
| state | VirtualMachineState | The state that the virtual machines must have. If this argument is not set, the current state of the virtual machines is used. |
| testType | | The set of tests to run. If this argument is not set, all tests will be run.|

Let's take a closer look at the parameters that this method requires. (On screen, optional parameters have a red asterisk beside them.) Instead of passing an object, you can pass the `null` value.

The `testType` parameter requires an array of strings with the names of the tests that should be executed. But where can you find the tests? For such questions, it is always good to start with the enumeration types. Type **test** in the Quick Index field of Enumerated Types (Figure 18.10).
