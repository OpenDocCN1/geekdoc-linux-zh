# Using PowerShell to Automate GitHub Client Operations

The SourceTree client we have using is actually executing commands for GitHub via a number of Git command-line tools that ship as part of the SourceTree client installation. You may notice these commands listed if you look at the full output when, for example, committing a change in the client. The SourceTree client, it is possible to open a Terminal window to manage code in repositories with these tools. The Terminal window contains a number of visual enhancements, including colors, to make for a better experience. Out of this some functionality is not available in a PowerShell console. However, the PowerShell community has come to the rescue, and by using a project going the famous name posh-git, you can bring that functionality to a PowerShell console.

# Requirements

You will need the following:

+   - Git command-line tools preinstalled. You can get them from http://git-scm.com/download/win.

+   - posh-git, which is available from dahlbyk.github.io/posh-git/
