With the code in Listing 11.1, you can make a backup copy of the VMs to an alternate datastore. The script creates a snapshot of the VM and then, from this snapshot, it clones the image to create a new VM on an alternate datastore. The script can be backed up one or more VMs. As written, the log currently outputs to screen, but you can just easily write to a log file or email the details as they are completed.
