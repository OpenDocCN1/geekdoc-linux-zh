# FIGURE 17.2 Alarm creation functions

![](bbox=[0.335, 0.149, 0.858, 0.487])

The function, called New-Alarm, uses all the objects you created via the supporting functions and creates the alarm on your vCenter Server. To make the supporting functions easy to use, and consequently New-Alarm itself, we have created a PowerShell module vCenterAlarm containing all the functions you need to create an alarm. It is available for download from this book's web page at www.wiley.com/go/vmvspherepowercli2.

Once you have downloaded the vCenterAlarm module and placed it in an appropriate place on your workstation, check out Listing 17.8, which demonstrates how to import the module into your PowerShell session and how to list the functions available in the module.

# LISTING 17.8 Import and List functions in the vCenterAlarm module

```
Import-Module vCenterAlarms
Get-Command -Module vCenterAlarms -Verb New
```

Typical output would be

```
CommandType               Name
------------             -------------------
Function                  New-Alarm           vCenterAlarms
```
