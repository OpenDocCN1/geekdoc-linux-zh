# Querying a Workflow State

Once a workflow has been invoked, it may take some time to complete. The Get-vROExecutionState function in Listing 21.20 retrieves the state of a workflow by submitting the Execution state URL (the Execution output from Listing 21.19) plus the word state to make the following URL. URL could be used as the value for the ExecutionStateRef parameter in the Get-vROExecutionState function.

```
https://vro01.snutydale.local:8281/vco/api/workflows/c0278910-9ae2-46c5-b4ab-2292fe88e3ab/executions/402880244ae8e2a6014b0961089a0234/
state
```
