
## Configuring Distributed Power Management

DPM provides cost savings by dynamically consolidating VMs onto fewer hosts during periods of low usage. The VMs are consolidated onto fewer hosts, the remaining hosts that are no longer hosting any VMs are powered off to save power. Once utilization starts to increase, the Sphere Server will power these hosts back as needed.

While there are currently no options to enable DPM through the native cmdlets that are provided with PowerShell, you can address the API and create your own function to enable DPM. For more information about using the SDK/API or Project Onyx, read chapter 18, "The SDK."

Listing 1.15 shows how you can enable DPM on a cluster.

### **Listing 1.15** Configuring DPM on a cluster

```powershell
function Set-DPM {
#
.SYNOPSIS
Enables Distributed Power Management on a cluster
.DESCRIPTION
This function will allow you to configure
DPM on an existing vCenter Server cluster
.NOTES
Source: Automating vSphere Administration
.PARAMETER Cluster
The cluster on which to set DPM configuration
.PARAMETER Behavior
DPM Behavior, this can be set to "off", "manual"
or "Automated", by default it is "off"
.EXAMPLE
Set-DPM -Cluster "Cluster01" -Behavior "Automated"
#>

param(
[String]$Cluster,
[String]$Behavior
)

Process {
switch ($Behavior) {
"Off" {
$DPMBehavior = "Automated"
$Enabled = $false
}
"Automated" {
$DPMBehavior = "Automated"
$Enabled = $true
}
"Manual" {
$DPMBehavior = "Manual"
$Enabled = $true
}
default {
$DPMBehavior = "Automated"
$Enabled = $false
}
$cls = Get-Cluster $Cluster | Get-View -Property Name
$spec = New-Object VMware.Vim.ClusterConfigSpecEx
$spec.DpmConfig = New-Object VMware.Vim.ClusterDpmInfo
$spec.DpmConfig.DefaultDpmBehavior = $DPMBehavior
$spec.DpmConfig.Enabled = $Enabled
$cls.ReconfigureComputeResource_Task($spec, $true)
$cls.UpdateViewData($ConfigurationEx)
New-Object -TypeName PSObject -Property @Cluster = $cls.Name; DPMEnabled = $cls.ConfigurationEx.DpmConfigInfo.Enabled;
DefaultDpmBehavior = $cls.ConfigurationEx.DpmConfigInfo.DefaultDpmBehavior}
}
```

## Licensing

Licensing is one of the first areas that will be critical to setting up a new host. Without a valid license, you can manage and use your host-to-host VMs for a maximum of 60 days.

## CHAPTER 1 AUTOMATING VCENTER SERVER DEPLOYMENT AND CONFIGURATION

You may be surprised to learn that there are no cmdlets to help with licensing ESX hosts or viewing the current license details. However, the licensing information is available through the Get-View cmdlet, and you can manipulate the SDK to perform the actions necessary to view license information and set the license for your hosts. You can write functions to help you deal with these cmdlets and make them a little friendlier than the SDK code.

### Viewing License Information

To make things easy, you can use the functions we'll show you next to list all license registered on the vCenter Server and also set a license key on a host. The Get-LicenseKey function in Listing 1.16 lists all license keys.

  Get-LicenseKey

  $licMgr = Get-View $servInst.Content.licenseManager

### Licensing a Host

Once you have a list of the keys, you can use that information to license the ESX hosts attached to the vCenter Server. Listing 1.17 shows how you set the license key for a specific host. Once the license key is set, it will return the server and license key that were specified.

LISTING 1.17 Adding a license key to a host

```powershell
function Set-LicenseKey {
<<
.SYNOPSIS
  Sets a License Key for a host
.DESCRIPTION
  This function will set a license key for a host which is attached to a vCenter Server
.NOTES
  Source: Automating vSphere Administration
.PARAMETER Lickey
  The License Key
.PARAMETER VMHost
  The host to add
.PARAMETER Name
  The friendly name to give
.EXAMPLE
  Set-LicenseKey -Lickey "AAAA-BBBB-CCCC-DDDD-EEEEE" -VMHost "Cluster01" -Name "MyHost"
#>

param(
[String]$Lickey,
[String]$VMHost,
[String]$Name
)

Process {
$cls = Get-Cluster $VMHost | Get-View -Property Name
$spec = New-Object VMware.Vim.ClusterConfigSpecEx
$spec.DpmConfig = New-Object VMware.Vim.ClusterDpmInfo
$spec.DpmConfig.DefaultDpmBehavior = "Automated"
$spec.DpmConfig.Enabled = $false
$cls.ReconfigureComputeResource_Task($spec, $true)
$cls.UpdateViewData($ConfigurationEx)
New-Object -TypeName PSObject -Property @Cluster = $cls.Name; DPMEnabled = $cls.ConfigurationEx.DpmConfigInfo.Enabled;
DefaultDpmBehavior = $cls.ConfigurationEx.DpmConfigInfo.DefaultDpmBehavior}
}
```
