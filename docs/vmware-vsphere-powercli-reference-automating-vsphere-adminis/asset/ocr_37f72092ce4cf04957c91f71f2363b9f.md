```
$archiveFilename = 'Stat-' + $Start.ToString("MM_dd_yyyy") + '-' + \
$Finish.ToString("MM_dd_yyyy") + '.xml'
```

```
# Export statistics
Get-Stat -Entity $entities -Stat $metrics -Start $Start `
-Finish $Finish | Export-Clixml `
-Path ($archiveLocation + '\' + $archiveFilename)
```

The following script reads the archive file back into a PowerShell array. You can work with that imported array just as if you had created it with the
Get-Stat cmdlet.

```
$archiveFilename = 'C:\Archive\Stat-01_01_2015-31_01_2015.xml'
$stats = Import-Clixml -Path $archiveFilename
```

> **TIP** Make sure you use a filenames schema that clearly defines what kind of data is stored in each file. You could include the entity type, the start and finish dates, the metrics that were used, and similar information.
