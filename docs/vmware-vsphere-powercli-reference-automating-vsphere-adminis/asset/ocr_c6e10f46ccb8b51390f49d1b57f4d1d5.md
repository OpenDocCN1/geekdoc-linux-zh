# USE VMOTION AND STORAGE VMOTION

NOTE When using datastore clusters, partial moves cannot be performed. If the VM has one HardDisk on Datastore1 and a second HardDisk on a traditional datastore, the cmdlet will throw an error. These more complex partial moves can be accomplished using the SDK.

Not all moves can be done with PowerCLI cmdlets. For example, if only the VM's configuration file needs to be relocated, the Move-VM cmdlet lacks the needed parameters. In such instance, the SDK can be used. Listing 9.5 contains a function that leverages the SDK to move the registered content from one datastore to another. The function gets all VMs with a resource to the source datastore and migrates the files that are actually stored on the source datastore to the destination datastore. This function is useful when you need to migrate datastores to another storage array or to using a different block size.
