# # Create a Project Structure

Single or multiple code projects can be maintained within a repository, or depending on your requirements, multiple repositories can be used to store single or multiple projects. A single repository lends itself to lower levels of ongoing server maintenance tasks; conversely, multiple repositories can give more flexibility for different projects in terms of items such as trigger or email notifications. You need to create at least one project within your repository to store the example code.

> The VisualSVN website contains some excellent guidance on how to plan for your VisualSVN Server repositories: https://www.visualsvn.com/support/svn/reposadmin/planning/. You'll also find more information on using the default folders that are created within each project.

From within the VisualSVN Server management console, right-click the Repository01 repository that you just created and choose New > Project Structure.
