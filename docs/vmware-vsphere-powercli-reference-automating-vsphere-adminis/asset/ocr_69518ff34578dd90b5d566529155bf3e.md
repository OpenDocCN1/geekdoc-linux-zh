# Backup Job Template

You now have all the elements in place required to create a backup job template. Listing 11.17 creates a backup job for all VMs in the cluster named Cluster01, will store the data in the SynologySMB repository, and a schedule of weekdays starting at 8 a.m. It is well worth checking the help for creating backup job templates, as Add-VBRViBackupJob, Set-VBRViJobRepository, and Set-VBRViJobSchedule to see what is available.

# 11.17 Creating a backup job template

```
$ClusterEntity = Find-VBRViEntity -Name Cluster01 -ResourcePool
$Repository = Get-VBRBackupRepository -Name SynologySMB
Add-VBRViBackupJob -Name Cluster01 -Entity $ClusterEntity \
-Repository $Repository

$Job = Get-VBRJob -Name Cluster01
$Job | Set-VBRJobSchedule -DailyKind Weekly
$JobOptions = Get-VBRJobOptions -Job $Job
$JobOptions.RunManually = $false
Set-VBRJobOptions -Job $Job -Options $JobOptions
```
