The next vNetwork guideline needs some PowerCLI help for vNet-work.limit-network-healthcheck. The Hardening Guide recommends, "Enable VDS network healthcheck if you only need it." Because there is no cmdlet for directly checking and managing these healthcheck options, we created the function in Listing 13.8.

# LISTING 13.8 Assessing and remediating network healthcheck options

```powershell
function Assert-HardeningGuideVNetworkHealthChk {
<#Description
Function to assess and/or remediate the VMware Hardening Guide item with
Guideline "vNetwork.limit-network-healthcheck" (which do not have
PowerCLI assessment/remediation code in the guide). The guideline
recommends disabling these health check items, since, as the guide states,
"once enabled, the healthcheck packets contain information on host,
vds# port#, which an attacker would find useful"
.Example
Assert-HardeningGuideVNetworkHealthChk
Report on the current values of the health check configuration items for
all virtual distributed switches
.Example
Get-VDSwitch myVDSwitch0, myVDSwitch1 |
Assert-HardeningGuideVNetworkHealthChk -Remediate:$true

Disable any enabled health check setting on vDSitches, as the hardening
guide recommends

.Outputs
If remediating, the VMware.VimAutomation.Vds.Impl.V1.VmwareVDSwitchImpl
object for each VDSwitch updated. If just reporting, the
Selected.Vmware.Vim.VmwareVDSwitchV1MinutHealthCheckConfig and
Selected.Vmware.Vim.VmwareDVSteamingHealthCheckConfig object for each
VDSwitch involved

```powershell
#
[CmdletBinding(SupportsShouldProcess=$true)]
Param(
    ## Virtual distributed switch to assess/remediate. If none specified, will
    # only report
    # act on all VDSitches in the VIServer to which current session is
    # connected
    [parameter(ValueFromPipeline=$true)] [PSObject[]]$VDSwitch,
    ## Switch: Remediate the entity? Default is $false, which causes changes to
    [switch]$Remediate = $false
)
begin {
    ## the desired value for the HealthCheckConfig properties
    $DesiredConfigValue = $false
}

process {
    $ArrVDSwitchOfInterest = if ($PsBoundParameters.ContainsKey("VDSwitch")) {
        if ($VDSwitch.GetType().Name -eq "VmwareVDSwitchImpl") {$VDSwitch}
        else {Get-VDSwitch -Name $VDSwitch}
    } else {Get-VDSwitch}
}

```powershell
## get the HealthCheckConfig information for the VDSwitch(es)
$arrHealthCheckConfigInfo = $VDSwitchOfInterest | Foreach-Object {
  $ThisVDSwitch = $_
  $ThisVDSwitch.ExtensionData.HealthCheckConfig |
    Select-Object @(n="VDSwitch"; e=$($ThisVDSwitch),
    @(n="HealthCheckType"; e={$_.GetType().Name}),
    @(n="Enabled"; e={$_.Enable}),
    @(n="SuggestedValue"; e={$DesiredConfigValue -eq $_.Enable})
}

if ($Remediate) {
  # get the VDSwitches who have a healthcheckconfig value that is
  # not the suggested value
  $arrVDSwitchToRemediate = $arrHealthCheckConfigInfo |
    Where-Object {$_.IsSuggestedValue -eq $false}
    Select-Object -Unique -ExpandProperty VDSwitch
  # make the healthCheckConfig items to use for updating the
  # DVSHealthCheckConfig
  $arrVDSHealthCheckConfigItems = @(
    "VMware.Vim.VmDVSTeamingHealthCheckConfig",
    "VMware.Vim.VmDVVSlanMtuHealthCheckConfig"
  )
  $arrVDSwitchToRemediate | ForEach-Object {
    $ThisVDSwitch = $_
    if ($ShouldProcess($ThisVDSwitch, "Disable health check on $($ThisVDSwitch.Name)")) {
      try {
        $Task = $ThisVDSwitch.ExtensionData.UpdateHealthCheckConfig($arrVDSHealthCheckConfigItems | ForEach-Object {
            @{ Name = $_; Enabled = $DesiredConfigValue }
        })
        Wait-Task -Id $Task.Id | Out-Null
        $TaskFinal = Get-Task -Id $Task.Id
        if ($TaskFinal.State -eq "Success") {
            Get-VDSwitch -Name $ThisVDSwitch
        } else {
            Write-Error "Problem setting Health Config on $($ThisVDSwitch.Name). The task result: $($TaskFinal.Result). And the task error: $($TaskFinal.ExtensionData.Info.Error)"
        }
      } catch {
        Write-Error "Problem initiating the configuration task for $($ThisVDSwitch.Name)""
      }
    }
  }
} else {
  # else just return the health check info
  $arrHealthCheckConfigInfo
}
```
