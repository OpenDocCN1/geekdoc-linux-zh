| vmstores | | | VimDatastore | \VCenter |

Name the vmstore drive. You can use this drive to browse the datructures just like you browse your local drive. (Note that the drive names are case-sensitive). So, use the Get-ChildItem cmdlet, its alias dir, or even ls if you prefer the Unix style:

```
dir vmstore:
```

| Name | Type | Id |
| --- | --- | --- |
| DC01 | Datacenter | Datastore-d... |

```
Get-ChildItem vmstore:\DC01
```

To find all VMX files, you just have to provide the -Include *.vmx and -Recourse parameters. To register the found VMX files, you'll use the New-VM cmdlet.

```
Get-ChildItem vmstore: -Include *.vmx -Recurse | % {
New-VM -VMHost (Get-Datastore $_.Datastore | Get-VMHost) |
Get-Random -VMFilePath $_.DatastoreFullPath
}
```
