# LISTING 5.22 Applying a host profile to any noncompliant host

```
Get-Cluster Prod01 |
Get-VMHost |
Test-VMHostProfileCompliance |
ForEach-Object {
  $profile = Get-VMHostProfile $_.VMHost |
  Set-VMHost -State 'Maintenance' -VMHost $_.VMHost |
  Apply-VMHostProfile -Profile $profile |
  Set-VMHost -State 'Connected' |
  Test-VMHostProfileCompliance
}
```

Of course, no environment is static. From time to time, you will need to make changes to hosts under the control of a host profile. As fantastic as vMotion is, it does take quite a bit of time to evacuate a host—and applying a profile requires that a host be in Maintenance mode. Therefore, when you are making changes we highly recommend using the following workflow:

+   1. Script the change needed to update all affected vSphere hosts in PowerShell.
2. Update the host profile.
3. Test for compliance.
