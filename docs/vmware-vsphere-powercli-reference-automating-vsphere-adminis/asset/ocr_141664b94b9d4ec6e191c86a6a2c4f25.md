# Manage Organizations

vCloud Director Organizations (also known as orgs) are the topmost containers
where the rest of the private cloud is created. Within these organizations, admin-
istrators can create vDCs (virtual datacenters), add local users, create vApps,
manage items, and allocate virtual resources. Service providers may find it
necessary to create new orgs from time to time, as well as disable or remove orgs.
This section will cover the administration and management of orgs.

# Creating Organizations

Organizations are one of the objects that can be created using PowerCLI. The cmd-
New-Org requires two parameters: Name and FullName.

```
New-Org -Name Customer1 -FullName Customer_X_Seattle
-Description "This is Customer X in Seattle"
```

Org names and descriptions can be easily updated using the Set-Org cmdlet as:

```
Get-Org -Name Customer1 | Set-Org -FullName Customer_Y_Orlando \
-Description "This customer is based out of Orlando"
```

# Enabling/Disabling Organizations

Once a new org is created, it is enabled by default. Generally this is fine, but some-
times administrators need to disable an organization. When this happens, it is fine
to use PowerCLI to disable the target organizations:

```
Get-Org -Name Customer1 | Set-Org -Enabled:$false
```
