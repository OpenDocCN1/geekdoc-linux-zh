# Start Rules

Once the vApp has been created or imported into vCloud Director, you can set rules for the virtual machines in vApp. Each virtual machine in a vApp has a default Start Rule of PowerOn with no delay. If, for example, a vApp contained an Active Directory server, a database server, and an application server, you could setting start rules that start the AD server at the same time as the database server, or delay the application given a number of seconds to allow the database server to be up and running before the application tries to connect.

Changing the rules for our example of the three virtual machines will not be beneficial at this moment, we will still use that to vApp to demonstrate how these rules can be set:

```
$TargetvApp = Get-CIVApp TestvApp\nGet-CIVAppStartRule -vApp $TargetvApp
```

When you run that, you will see that this vApp has the default start rules. Using the next example code, we will set Apache04 and Apache05 for a delay of 20 seconds before Apache03 to start immediately:

```
$vm = Get-CIVM -Name Apache04,Apache05 $TargetvApp\n$startrule = Get-CIVAppStartRule -vApp $TargetvApp -VM $vm\nSet-CIVAppStartRule -StartRule $startrule -StartDelaySeconds20
```
