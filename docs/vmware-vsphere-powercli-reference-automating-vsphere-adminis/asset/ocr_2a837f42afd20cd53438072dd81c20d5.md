# Using Workflows

In PowerShell v3 the concept of workflows was introduced. One of the nice features that PowerShell offers is the concept of parallelism. In other words, you can run multiple instances of the same code. This allows you to split single-threaded long jobs into many smaller jobs, each running against a specific instance or entity.
