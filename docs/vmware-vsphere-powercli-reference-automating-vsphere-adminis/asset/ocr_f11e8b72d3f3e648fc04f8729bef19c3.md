# CHAPTER 12 • ORGANIZE YOUR DISASTER RECOVERY

When it comes to designing your disaster recovery strategy, there are several aspects you should take into account. The vCenter Server installation consists of two parts: an application server and a backend database. While the application server services the user interface, the heart of the vCenter Server is stored in the backend database. In this chapter, you'll learn how to back up and restore your vCenter Server database when you have SQL Server Management Studio available. We'll explore methods to export and import specific items of your vCenter Server inventory.
