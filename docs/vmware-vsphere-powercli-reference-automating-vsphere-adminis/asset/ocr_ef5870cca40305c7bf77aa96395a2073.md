Once the new adapter has been added, it is possible to change its settings using the Set-NetworkAdapter cmdlet. Perhaps there is a need to change the MAC address address used to create the product license for your application. Use the code below; substitute your static address for the one used in the -NetworkAdapter parameter:

```
Get-VM VM001 | Get-NetworkAdapter -Name "Network adapter 2" | \\Set-NetworkAdapter -MacAddress 00:50:56:03:15:10 -Confirm:$false
```

As a best practice, it is recommended that all unused hardware be removed from your systems. (You can learn more about hardening your VM in Chapter 13, "Hardening theSphere Environment.") Suppose your backup application has been upgraded and uses array-backed snapshots to create full-image backups. The extra network adapters connected to the redundant backup network will no longer be used and need to be removed. Removing an adapter is done using the Remove-NetworkAdapter cmdlet. This cmdlet accepts only one parameter:-NetworkAdapter. The parameter specifies the NetworkAdapter object to be removed. You can retrieve NetworkAdapter objects using the Get-NetworkAdapter cmdlet.

Remember, removing a network adapter from a powered-on machine is supported only on virtual hardware version 7 or later—and only if the guest supports hot remove. Be sure to pow the VM before running this code if you are working with an earlier virtual hardware version:

```
Get-VM VM001 | Get-NetworkAdapter | ?{$_.NetworkName -eq ' \
"BACKUPVLAN10" | Remove-NetworkAdapter -Confirm:$false
```
