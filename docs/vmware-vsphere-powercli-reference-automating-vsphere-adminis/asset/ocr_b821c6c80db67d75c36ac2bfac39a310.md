# PCI Devices

Besides storage adapters and network cards, there is a lot of other hardware present in your hosts. The function in Listing A.5 generates a report of all hardware devices present in your host. The function downloads PCI information from http://pci-ids.ucw.cz/ to provide more information on each PCI device found. To use the function, one or more VMHost objects through the pipeline or use

```
    Get-VMHost "ESX001" | Get-VMHostPciDevice | Format-Table
```
