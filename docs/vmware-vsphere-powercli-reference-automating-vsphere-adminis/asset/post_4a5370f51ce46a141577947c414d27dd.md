PowerCLI growth provides us with a way to check and set vSphere distributed group port-level overrides, from the cmdlets Set-VDPortGroupOverridePolicy and Set-VDPortGroupOverridePolicy, both available since PowerCLI 5.5 Release 1. The Set-VDPortGroupOverridePolicy cmdlet from PowerCLI 6.0 allows you to set any of the nine DVPortGroupPolicy and VMwareDVSPortGroupPolicy OverrideAllowed properties. The PowerCLI helps you how to use the cmdlet.

To add a little value, we created an advanced function (see List 13.9) that you can use to assess and remediate all the vSphere distributed port group (VDPortgroup) override configurations for this guideline.

## 13.9 Assessing and remediating VDPortgroup override options

```powershell

Function to assess and remediate the VMware Hardening Guide item with

If remediating, the VMware.VimAutomation.Vds.Impl.V1.VMwareVDPortGroupImpl

and whether the VDPortgroup config is as suggested in the hardening guide
#>
```

```powershell
else {
    $ArrVDPGToRemediate | Foreach-Object {
        $ThisVDPG = $_
        if ($PSCmdlet) ShouldProcess($ThisVDPG,Name,
            "Reconfigure OverrideAllowed policies to '$DesiredConfigValue'") {

    # make a new DVPGConfigSpec with the config version and policy

    (@ConfigVersion = $_.ExtensionData.Config.ConfigVersion; policy = $oDVSPolicy_thisPG)

    try {
        $oTaskId = $ThisVDPG.ExtensionData.ReconfigureDVportgroupTask($NewDVPGConfigSpec)
        # wait for the task; this task should return nothing, but \
        # sending to Out-Null for cleanliness
        Wait-Task -Task (Get-Task -Id $oTaskId) | Out-Null
        $oTask_final = Get-Task -Id $oTaskId
        # if the task succeeded, return the newly updated VPDG
        if ($oTask_final.State -eq "Success") {Get-VDPortgroup -Id $ThisVDPG.Id}
        else {Write-Error "Problem reconfiguring VDPortgroup \
'$($ThisVDPG.Name)'. The reconfiguration task result:
'$($oTask_final.Result)'. And, the task error:
'$($oTask_final.ExtensionData.Info.Error)'"}
    } catch {
        Write-Error "Problem initiating the reconfiguration task for VDPortgroup '$($ThisVDPG.Name)'"
    }
}
```

## vCenter Server

Again, as VMware has gone the route of more secure default settings in vSphere products, the number of security concern has dropped. There is but one remaining vCenter . programmatic guideline in the 6.0 version of the Hardening Guide, and the guide includes the PowerShell commands for assessment and remediation of that recommended setting.

As other vCenter considerations, you should follow relevant community best practices for your vCenter Server if it is running in a Windows-based OS, such as antivirus, antimaler, and security-related OS configurations. These practices are outside the scope of this book. For vCenter running as the vCenter Server Appliance (VCSA), VMware already applies hardening recommendations to the appliance—hurray for VMware!
