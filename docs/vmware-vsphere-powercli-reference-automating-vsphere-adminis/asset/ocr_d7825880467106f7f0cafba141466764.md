# TortoiseSVN Client

TortoiseSVN (http://tortoisesesn.net/) is also free to use, even in a commercial environment. It provides a client implemented as a Windows shell extension—essentially a nice GUI for Subversion.

# System Requirements

TortoiseSVN can run on any Windows system that is Windows XP SP3 or later, in both 32-bit and 64-bit editions. Administrative privileges are required for installation.

# Installation and Initial Configuration

Download the latest version of TortoiseSVN and install the software onto a Windows client machine that meets the system requirements. Accept all the defaults (Figure 24.3).
