Param(
    # the VMHost to enable or disable lockdown down
    Parameter(
        Mandatory=$true,
        ValueFromPipeline=$true,
        HelpMessage="VMHost"
    )
)
[VMware.VimAutomation.ViCore.Impl.V1.Inventory.VMHostImpl]
$VMHost

# enable/disable lockdown
[Parameter(Mandatory=$true)]
[switch]
$Enable

Process {
    $HostView = $VMHost | Get-View -Property Name

    if ($Enable) {
        $msg = "Entering lockdown mode"

        if ($PsCmdlet.ShouldProcess($VMHost.Name, $msg)) {
            $HostView.EnterLockdownMode()
        } else {
            $msg = "Exiting lockdown mode"

            if ($PsCmdlet.ShouldProcess($VMHost.Name, $msg)) {
                $HostView.ExitLockdownMode()
            }
        }
    }
}

## Working with Host Profiles

At this point, you have a fairly high level of automation in play. Let's bring it to the next level by leveraging host profiles. Keep in mind that you must have the Enterprise Plus license to take advantage of host profiles, but remember that you can use PowerShell to apply all the settings manually.

Most settings within host profiles have three possible settings:

- User Setting Will Be Applied
- Prompt User If Default Is Provided
- Use The Following When Applying

As shown in Figure 2.4, your selection within the host profile will determine how. If you select User Setting Will Be Applied, you will always have to supply the setting. If you prompt User If No Default Is Provided, you should test whether a value is necessary before providing one. Finally, if you choose a static or dynamic value—that is, a static IP or DHCP—you don't have to provide a value. The interdependency of host profiles led to a lot of confusion on the topic. We'll go over several techniques to show how to handle each scenario before we circle back and use host profiles in a vSphere host configuration.

## FIGURE 2.4 Host profile selection

Regardless of how your settings are applied, automating host profiles is a three-step process:

1. Attach a profile.
2. Apply the profile and test only for needed values.
3. Apply the profile.
