create a new port group with the new name for the port group, and move the VMs from the old new port group.

You can also use the Move-VMToNewPortGroup function to migrate VMs from a standard vSwitch to a newly distributed vSwitch. In fact, it is no different from moving between two standard vSwitches (Listing 3.25).

# Listing 3.25 Migrating VMs from a standard to a distributed port group

```
`Move-VMToNewPortGroup -Source StandardPortGroup01 -Target DistributedPortGroup01 -Cluster Cluster01`
```

# VMware NSX

Now that we have discussed ways to configure and administer both standard and distributed switches, we will briefly discuss another aspect of virtual networking. NSX, VMware's product for software-defined networking (SDN) has a number of advanced features that allow for even more control and configuration of the net-working aspect of your virtual environment.

To cover NSX in its entirety would require a whole book dedicated to descriptions of the features and how to configure them. To remain in the confines of this networking chapter, we will briefly discuss the steps to deploy NSX and configure its prerequisites. The requirements for NSX are also outside the scope of this book. However, before deploying and using NSX, you must ensure that all requirements have been satisfied.
