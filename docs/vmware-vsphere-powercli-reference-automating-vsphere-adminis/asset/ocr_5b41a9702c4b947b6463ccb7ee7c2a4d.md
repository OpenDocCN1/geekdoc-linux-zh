# CHAPTER 3 • AUTOMATING NETWORKING

# LISTING 3.26 Deploying NSX with a configuration

```
$ovfconfig = Get-OvfConfiguration -Ovf Z:\NSX\VMware-NSX-Manager-6.1.2-2318232.ova

$ovfconfig.common.vsm_cli_passwd_0.value = "VMware!"
$ovfconfig.common.vsm_cli_passwd_0.value = "VMware!"
$ovfconfig.common.vsm_hostname = "NSX.MyDomain.local"
$ovfconfig.common.vsm_ip_0.value = "10.144.99.21"
$ovfconfig.common.vsm_netmask_0.Value = "255.255.255.0"
$ovfconfig.common.vsm_gateway_0.value = "10.144.99.1"
$ovfconfig.common.vsm_dns_0.value = "10.144.99.55"
$ovfconfig.common.vsm_isSSHEnabled.value = $true

Import-Vpf -Source Z:\NSX\VMware-NSX-Manager-6.1.2-2318232.ova \
-OvfConfiguration Ovfconfig -Name "MGMT-NSX" \
-Datastore "ISCSI-SSD-900GB" -DiskStorageFormat thin \
-VMHost (Get-Cluster "Main-Cl") | Get-VMHost | where \
{$_.ConnectionState -eq "Connected" -and $_.PowerState -eq "PoweredOn"} | Get-MGMT-NSX" | Start-VM
```

Once NSX is up and running, you can communicate with it via a REST-based API. If this is your first time using REST, it may seem a little daunting. However, once you have the basic properties set for the REST call, you'll notice it is much easier than it looks. There are plenty of helpful tutorials online as well as a section on REST in Chapter 21, "Realize Orchestrator."

> NOTE The starting point for information about using REST with NSX can be found at the URL of your NSX installation: https://<nsxmanager-ip>/api/.API Guide will give you detailed information on the full address to use for each command being performed. What we show here is only an ink of the capabilities of configuring and administering NSX from PowerShell.

> NOTE The URL https://<manager-ip>/api/ is best accessed via a REST-based client (such as Postman, at https://www.getpostman.com/) since an authentication token is required. We recommend using this URL since it gives you the proper documentation for the NSX version being used. If you prefer to use a web browser you can search the web for the correct NSX API Guide. For example, the guide for NSX 6.2 can be found here: http://vmw.re/1lh0f6B.
