The new report shown in Figure 15.4 probably isn't the best you've seen, but it gives you an idea of the possibilities. You'll want your reports to use your company's style. In that case, you can use the -CssUri parameter to include your company's CSS style:

```
$nicReport |
ConvertTo-Html -CssUri c:\mylesheet.css > nicereport.html
```

If you don't want to create a full HTML document but rather an HTML table, use the -Fragment parameter. That way, you can build your own custom HTML
