# # Create REST HEADERS

```
$Auth = "admin" + '+' + $NSPassword
$Encoded = [System.Text.Encoding]::UTF8.GetBytes($Auth)
$EncodedPassword = [System.Convert]::ToBase64String($Encoded)
$Headers = @{"Authorization="Base $($EncodedPassword)"};
```
