# Calling vRO Workflows from PowerShell

vRO is manageable via a REST-based API. Since PowerShell is able to work with
REST systems, it is possible to interact with vRO workflows in an automated way.
The following examples illustrate how to retrieve details about existing workflows,
invoke a vRO, and subsequently retrieve the results.

> NOTE The starting point for the vRO API is the following URL:

```
https://vROServer:8281/vco/api/
```

From here it is possible to discover more opportunities. In this chapter, we are merely
scratching the surface of what is available.

# Retrieving Workflow Details

The Get-vROWorkflow function presented in Listing 21.16 will retrieve all work-
flows in a vRO system or a category (folder), or search by workflow name.

Listing 21.16 Get-vROWorkflow

```powershell
function Get-vROWorkflow {
<#
.SYNOPSIS
  Get vRO Workflows
.DESCRIPTION
  Get all workflows
.PARAMETER All
  Retrieve workflows
.PARAMETER Category
  Retrieve workflow by category
.PARAMETER Name
  Retrieve workflow by name
.PARAMETER Wildcard
  Perform a wildcard search using the Name parameter
.PARAMETER Server
  vRO Server to connect to
.PARAMETER Credential
  Credential Object
.EXAMPLE
$Credential = Get-Credential
Get-vROWorkflow -All -Server vRO01 -Credential
Get-vROWorkflow -Category -Name 'New' -Server vRO01 -Credential
Get-vROWorkflow -Name 'New' -Wildcard -Server vRO01 -Credential
#>
[CmdletBinding(DefaultParameter="All")]
Param(
    [Parameter(Mandatory=$false, ParameterSetName="All")]
    [switch]$All,

    [Parameter(Mandatory=$false, ParameterSetName="Category")]
    [string]$Category,

    [Parameter(Mandatory=$false, ParameterSetName="Name")]
    [string]$Name,

    [Parameter(Mandatory=$false, ParameterSetName="Wildcard")]
    [switch]$Wildcard,

    [Parameter(Mandatory=$true)]
    [string]$Server,

    [Parameter(Mandatory=$true)]
    [PScredential]$Credential
)
try {
    using System.Net;
    using System.Security.Cryptography;
    class TrustAllCerts : ICertificatePolicy {
        public bool CheckValidationResult(WebRequest request, X509Certificate certificate) {
            return true;
        }
    }
    [ServicePoint]::CertificatePolicy = New TrustAllCerts

    # --- Create REST Headers
    $Auth = $Credential.Username + ':' + $Credential.Password
    $Encoded = [System.Text.Encoding]::UTF8.GetBytes($Auth)
    $EncodedPassword = [Convert]::ToBase64String($Encoded)
    $Headers = @{"Authorization"="Basic $EncodedPassword"}

    # -- Send REST call and process results
    switch ($Cmdlet.ParameterName) {
        "All" {
            $URI = "https://$Server:8281/vco/workflows"
        }
        "Category" {
            $URI = "https://$Server:8281/vco/workflows/?categoryName=$Category"
        }
        "Name" {
            if ($PSBoundParameters.ContainsKey('Wildcard')) {
                $URI = "https://$Server:8281/vco/workflows/?name=$Name*"
            } else {
                $URI = "https://$Server:8281/vco/workflows/?name=$Name"
            }
        }
    }

    $Workflows = Invoke-RestMethod -Method Get -Uri $URI -Headers $Headers -ContentType "application/xml"

    foreach ($Workflow in $Workflows.link) {
        $Object = [psustomobject]@{
            Name = ($Workflow.attributes | Where-Object { $_.name -eq 'name' }).value
            Server = $Server
            ID = ($Workflow.attributes | Where-Object { $_.name -eq 'id' }).value
            Description = ($Workflow.attributes | Where-Object { $_.name -eq 'description' }).value
            ItemRef = ($Workflow.attributes | Where-Object { $_.name -eq 'itemHRef' }).value
            Version = ($Workflow.attributes | Where-Object { $_.name -eq 'version' }).value
            CategoryName = ($Workflow.attributes | Where-Object { $_.name -eq 'categoryName' }).value
            CategoryHRef = ($Workflow.attributes | Where-Object { $_.name -eq 'categoryHRef' }).value
            CustomIcon = ($Workflow.attributes | Where-Object { $_.name -eq 'customIcon' }).value
            Execute = ($Workflow.attributes | Where-Object { $_.name -eq 'canExecute' }).value
            CanEdit = ($Workflow.attributes | Where-Object { $_.name -eq 'canEdit' }).value
        }
        Write-Output $Object
    }
}
catch [Exception] {
    throw "Unable to get vRO Workflows"
}
}
```
