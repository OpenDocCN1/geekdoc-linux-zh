A run of the Get-StatTypeDetail function returns detailed information about the available metrics for the entity. Note that if you use the -Realtime switch, the switch should be accessible. An ESXI host, for example, has to be in the Connected state.

```
Get-StatTypeDetail \
>>Entity(Get-VMHost |$ Select-Object -First 1) -Realtime \
>>SelectCounterId, Name, Group, Rollup \
>>ftAutoSize -Force
```
