# Configuring Distributed Power Management

DPM provides cost savings by dynamically consolidating VMs onto fewer hosts during periods of low usage. The VMs are consolidated onto fewer hosts, the remaining hosts that are no longer hosting any VMs are powered off to save power. Once utilization starts to increase, theSphere Server will power these hosts back as needed.

While there are currently no options to enable DPM through the native cmdlets that are provided with PowerShell, you can address the API and create your own function to enable DPM. For more information about using the SDK/API or Project Onyx, read chapter 18, "The SDK."
