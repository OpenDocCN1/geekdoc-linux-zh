> NOTE It is possible to use the Git command-line tools without the addition of posh-git. However, with the nice features posh-git brings, it feels more PowerShell like. The upcoming Listings 24.6 and 24.7 contain examples for using the Git command-line tools, but we recommend you use posh-git to enhance your experience of those examples.

# Add Code to a Repository with posh-git

To add the Test-Function03.ps1 file to the repository with posh-git, navigate to the C:\GitHub\Test01 folder via a PowerShell console and use the commands git add, git commit, and git push in Listings 24.6. You will be prompted to authenticate with GitHub after the push command.

> TIP Using the Git command git config --global credential.helper wincred save you from having to enter your GitHub credentials more than once during the PowerShell session for any subsequent tasks carried out on GitHub. This will persist until subsequent PowerShell sessions.

# LISTING 24.6 Adding code to a repository with posh-git

```
cd C:\GitHub\Test01
git config --global credential.helper wincred
git add C:\GitHub\Test01\Test-Function03.ps1
git commit -m 'Initial draft'
git push origin master
```

# Check for Changes in a Repository with posh-git

To check for changes in the repository, navigate to the C:\GitHub\Test01 folder and use the commands git fetch and git pull as you did in Listing 24.7. If you used the credential helper, you won't be prompted for GitHub credentials again; otherwise, you will need to authenticate.

# LISTING 24.7 Checking for changes in a repository with posh-git

```
git fetch origin
git pull origin master
```

These examples of using Git commands and posh-git merely scratch the surface of what can be achieved. We recommend you look into it further once you are comfortable with the GitHub system.
