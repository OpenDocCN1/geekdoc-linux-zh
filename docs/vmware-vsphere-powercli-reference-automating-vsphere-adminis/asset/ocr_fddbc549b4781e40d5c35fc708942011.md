This example with the AlarmManager shows that there is a method, called GetAlarm. This GetAlarm method will return an array of MoRefs and each MoRef points to an actual alarm managed object. We verify this by examining the default formatter shows the type retuned and the parameter overload for each method. Get more details by drilling into the object itself.

The Alarm method has one parameter, where you can pass the MoRef of a vSphere entity. A vSphere entity is a managed object, such as a host, a virtual machine, or a folder. When you call GetAlarm the method will return all alarms defined on that specific entity and all the entity's children.

```
$AlarmMgr.GetAlarm($null)
```
