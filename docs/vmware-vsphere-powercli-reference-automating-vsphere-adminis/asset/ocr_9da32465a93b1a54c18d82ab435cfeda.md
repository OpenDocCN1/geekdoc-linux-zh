As you can see, the root folder is always called Datacenters. This is because at this level the objects you can create (other than subfolders) are datacenter objects. To retrieve the subfolders, you use the root folder object and pass it along the pipeline to create using the Get-Folder cmdlet again:

```
Get-Folder -NoRecursion | Get-Folder -NoRecursion
```

| Name | Id |
|---|---|
| EMEA | Folder-group-d2058 |
| US | Folder-group-d2059 |

You can continue this recursive process for every child folder over and again to retrieve the full folder structure. This is illustrated in the Get-FolderStructure function created in Listing 12.2.
