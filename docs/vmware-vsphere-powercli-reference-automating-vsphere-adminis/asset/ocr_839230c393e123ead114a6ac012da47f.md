An example case is shown in Listing 21.21. In this example, we query the state of the workflow executed in Listing 21.19.

# LISTING 21.21 Using Get-vWorkflowExecutionState

```
$Credential = Get-Credential
Get-vWorkflowExecutionState \
    -ExecutionStateRef = //vro1.sunnydale.local:8281/vco/api/
    workflows/c278910-9a2e-46c5-bb45-2292fe88e3ab/state -Credential $Credential
40288244a8e2a601b40961089a0234
```

```

```
