# MANAGE VDCS 675

You can get a list of org VDCs using the Get-OrgVdc cmdlet. This cmdlet will return the same type of information that was returned in the previous section with
Get-ProviderVdc, only for the org subset:

```
Get-OrgVdc
```

You can narrow the results by provider vdc using the -ProviderVdc parameter:

```
Get-OrgVdc -ProviderVdc MainpVDC
```

Listing 19.3 shows how to export a report to CSV on all of your org VDCs along with critical information about CPU, storage, memory, and overall.
