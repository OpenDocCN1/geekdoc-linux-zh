```
#>
function Get-vAppIPAssignment {
    [CmdletBinding()]
    Param(
        [parameter(ValueFromPipeline=$true)
        [VMware.Automation.ViCore.Impl.V1.Inventory.VApp]
        $vApp
    )
    Process {
        $vApp.ExtensionData.VAppConfig.IpAssignment | Foreach-Object {
            New-Object PSObject -Property @{
                'vApp' = $vApp
                'IpProtocol' = $_.IpProtocol
                'IpAllocationPolicy' = $_.IpAllocationPolicy
                'SupportedIpAllocation' = $_.SupportedAllocationScheme
                'SupportedIpProtocol' = $_.SupportedIpProtocol
            }
        }
    }
}
```

The Get-vAppIPAssignment function retrieves the current settings for any vApp. Out of the box, a new vApp is configured to use static IP assignment, as shown in Listing 10.23.
