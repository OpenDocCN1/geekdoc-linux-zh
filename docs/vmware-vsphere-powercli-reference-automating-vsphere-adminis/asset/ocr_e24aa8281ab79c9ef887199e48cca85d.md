# Install Network Virtualization Components

Once you've added the NSX controllers, you can prepare the hosts in your selected cluster for NSX. Each host in the target cluster must be prepared by installing additional software on the host to handle the network traffic. You can complete this process by clicking Installation > Host Preparation > Install in the vSphere Client; the software will be installed on all hosts in the target cluster. You can perform this function using the REST-based API, as as shown in Listing 3.30.

LISTING 3.30 Performing host preparation tasks for NSX

