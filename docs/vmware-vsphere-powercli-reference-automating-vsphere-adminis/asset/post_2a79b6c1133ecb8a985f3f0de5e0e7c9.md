# Tasks and Events

With tasks and events, you can report on all activity that takes place in your vSphere environment. The tasks and events data contains everything you see in the Tasks & Events tab in vSphere Client—and more. In all inventory views, vSphere offers two ways of looking at tasks and events. In Tasks view, you can view a list of all the tasks (upper pane), with the related events for each task (lower pane). There are two sources of tasks and events available on vSphere servers:

- On the ESXi nodes, where the data is stored for approximately one day
- On the vCenter server, where the tasks and events data is defined in your vCenter settings

To check what is currently configured on your vCenter, use the following:

```bash
Get-AdvancedSetting -Entity $global:DefaultServer |
  where {$_.Name -match '^task|^event' } |
  Select Name,Value
```

| Name | Value |
| --- | --- |
| event.maxAge | 100 |
| event.maxEnabled | True |
| task.maxAge | 100 |
| task.maxEnabled | False |

On this specific vCenter, the events are retained for 100 days, but the tasks are not. With the Set-AdvancedSetting cmdlet, you can change these settings. You can do something like this:

```bash
$tab = @{
  'event.maxEnabled'=$true
  'event.maxAge'=365
  'task.maxEnabled'=$true
  'task.maxAge'=365
}
```

```bash
$tab.GetEnumerator() % {
  Get-AdvancedSetting -Entity $global:DefaultServer -Name $_Name |
  Set-AdvancedSetting -Value $_Value -Confirm:$false |
  Select Name,Value
}
```

| Name | Value |
| --- | --- |
| event.maxAge | 365 |
| event.maxEnabled | True |
| task.maxAge | 365 |
| task.maxEnabled | True |

Notice how we used a hash table to define the Name and Value for the advanced settings. The Get-Enumerator method that is available on the hash table will return each key-value pair that exists in the hash table. The key-value pairs are then passed, over the pipeline, to the Foreach-Object code block. In that block, the AdvancedSetting, defined in the Name property, is updated to the new value that was specified in the Value property.
