# FIGURE 18.14 CheckRelocate_Task

CheckRelocate_Task

Tests the feasibility of a proposed RelocateVch Task.

Required Privileges

| NAME | DESCRIPTION |
| --- | --- |
| _task | The reference to the task (IVirtualMachineRelocationTask) used to make the method call. |
| _machine | The reference to the VirtualMachine which we propose to relocate. |
| spec | The VirtualMachineLocationSpec object which contains the details. In cases where DRS automatically selects a host, all hosts are tested. If the priority for the new host is specified, DRS selects the specified service. If the compute resource associated with the target pool is not specified, DRS selects the best host. Each connected host in the cluster that is in maintenance mode represented to the target pool is listed as a target host. |

Parameters

test not set
