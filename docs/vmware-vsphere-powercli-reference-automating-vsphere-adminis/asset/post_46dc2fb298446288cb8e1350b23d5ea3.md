# Other Sources

You can use any kind of data in your reports, and numerous other sources are available directly or indirectly linked to your vSphere environment. Several of the vSphere products, for example, with PowerShell and the `Invoke-WebRequest` cmdlet, make it easy to access.

# Report Formats

Once you have collected the data for your report, you will need to present it in one form or another. With PowerShell, many formats for presenting your data are available.

# On the Screen

This is the simplest way to visualize results from a script. As you have seen in examples of this chapter, when you use the `Select-Object` cmdlet and do not redirect the output to another destination, the results will be displayed in the console of PowerShell session.

# OutGridView

If you want to quickly view your report in a nice interactive table, you can use the OutGridView cmdlet. Remember that this feature requires .NET Framework Service Pack 1 to work. Using the interactive table, you can sort your data on any column by clicking the header, hide or reorder columns, and also apply a search filter by using the window. # Files

From within PowerShell you can create multiple file formats. The following sections show how to use some of the more commonly used file types.

# Plain Text

Plain text is the simplest way to produce output from your scripts. In the previous examples in this chapter, several used `Select-Object` to display the results. By default, this output will appear on the console of PowerShell session.

# Spreadsheet

You can export your report to a CSV file using the Export-Csv cmdlet. This way, the report can be easily imported into a spreadsheet program, like Microsoft Excel:

```powershell
$report | Export-Csv c:\temp\MyReport.csv -NoTypeInformation
```

By default, the first line of the CSV file contains `TYPE`, the fully qualified name of the .NET object. To omit the type information, use the `-NoTypeInformation` parameter. You can also produce Excel spreadsheets from your PowerShell scripts. There are several functions that produce XLSX files. One example is the `Export-Xls` function, which is published on LucD here:

www.lucd.info/2013/01/03/export-xls-the-sequence-and-data/

# Email

When you're scheduling reports to run on a regular basis, it is always nice to receive the generated report in your inbox. In PowerShell, you can send an email using the `Send-MailMessage` cmdlet. You can send a simple mail message that has the report as an attachment; or if you've created an HTML report, you can include it in the body of the mail message.

# To email a fancy-looking HTML report to your manager:

```powershell
Send-MailMessage -SmtpServer "MyMailServer@mydomain.local" 
-From "myServer@mydomain.local"
-To "me@mydomain.local","Manager@mydomain.local" 
-Subject "My management report"
-Body $HtmlReport -BodyAsHtml
```

# To email some detailed reports as attachments to yourself:

```powershell
Send-MailMessage -SmtpServer "myMailServer@mydomain.local" 
-From "myServer@mydomain.local"

-Body "Please review the attached detailed reports" 
-Attachments "c:\temp\report1.csv","c:\temp\report2.csv"
```

# Web Page

Although exporting to a CSV file is nice, if you want to do calculations, sorting, or filtering afterward, the format is not always well suited for a readable and distributed-report. To create a more portable report, HTML is the preferred format. To create an HTML report, use the ConvertTo-Html cmdlet. Let's use an example NIC report and convert it into an HTML page like the one in Figure 15.3:

```powershell
$nicReport=@()
foreach ($cluster in $Cluster) {
  foreach ($VMHost in @($cluster | Get-VMHost)) {
    foreach ($nic in @($VMHost | Get-NetworkAdapter)) {
      $objNic = "" | Select ClusterName,HostName,Pci,DeviceName,Mac,BitRateSec,FullDuplex
      $objNic.ClusterName = $cluster.Name
      $objNic.HostName = $VMHost.HostName
      $objNic.Pci = $nic.ExtensionData.Pci
      $objNic.DeviceName = $nic.DeviceName
      $objNic.Mac = $nic.Mac
      $objNic.BitRateSec = $nic.BitRateSec
      $objNic.FullDuplex = $nic.FullDuplex
      if ($nic.ExtensionData.Pci) {
        $nicReport += $objNic
      }
    }
  }
}
$nicReport | ConvertTo-Html -Body $header -Head $style > nicreport.html
```
