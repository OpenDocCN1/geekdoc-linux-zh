A virtual machine contains numerous metrics, including usage, snapshots, snapshots, compression metrics, etc.

A virtual machine can have more virtual disks than datasets.

The instance ID is used to identify the object associated with a metric returned from the system.

Details, information can be found in the set property of the HostSystem's optional method

or in the getProperty method for specific virtual machine metrics. Descriptions are in the table below.

These counters are available from vCenter Server (only from direct ESX).

Values are updated every 30 minutes.

| Metric | Unit | FOR DEVICE SERVICES | FOR DATASETS | LABEL | INSTANCE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| capacity | bytes | 1 | 1 | capacity | 0.0 |
| usage | bytes | 1 | 1 | usage | 0.0 |
| free | bytes | 1 | 1 | free | 0.0 |
| instance | bytes | 0 | 1 | instance | 0.0 |
| space | bytes | 0 | 1 | space | 0.0 |
| free | bytes | 0 | 1 | free | 0.0 |

Configured size of the disks. Available from a dataset entity unit.

Amount of disk space used by a dataset or a virtual machine. Since the dataset or virtual machine can expand, this may not be exceeded. Available from dataset and virtual machine metric entities.

To configure aggregate pool settings for the entire dataset, set the property of the HostSystem to the dataset.

To get a metric for a specific virtual machine on the dataset, set the property of the virtual machine.

To get aggregate settings specified for the virtual machine target, set the property of the virtual machine.

Amount of space associated exclusively with a virtual machine. Available from dataset and virtual machine target.

You can compile your report of provisioning based on the provided and used metrics. See Chapter 16, "Using Statistical Data," for further details on working with metrics and statistical data.
