At this point, you are ready to apply the profile. To accomplish this, omit any optional switches and provide the variable parameter with your additional settings. We will take advantage of the PowerShell pipeline and drop your host in and out of Maintenance mode all in one command:

```
Set-VMHost -VMHost $VMHost \
-State 'Maintenance' \
Invoke-VMHostProfile -Variable $AdditionalConfiguration \
Set-VMHost -State 'Connected'
```
