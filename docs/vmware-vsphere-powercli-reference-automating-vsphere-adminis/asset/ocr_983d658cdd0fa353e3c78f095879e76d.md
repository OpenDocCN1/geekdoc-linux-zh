In this case, we will create a vRO workflow using PowerShell plug-in that maps to the functionality of the Create A User With A Password In Organizational Unit workflow that is part of the vRO Active Directory plug-in.

# Requirements

Ensure that the vRO Windows server has been configured for executing local processes and that the Microsoft AD PowerShell module has been installed and available on it. For use of, the vRO server should be joined to the Windows domain where the user account needs to be created.

![](bbox=[0.21, 0.355, 0.253, 0.393])

> NOTE The AD PowerShell module is available to be installed on most recent Windows Server operating systems and for clients via the Remote Server Administration tools. For Windows Servers 2012 R2, it can be installed via the PowerShell command Add-WindowsFeature RSAT-AD-PowerShell.

Ensure credentials are available to connect to AD and create user accounts in the desired organizational unit (OU).

You need a PowerShell script to create the AD user account. Listing 21.14 contains the code we use to achieve this and send back return codes based on the outcome.
