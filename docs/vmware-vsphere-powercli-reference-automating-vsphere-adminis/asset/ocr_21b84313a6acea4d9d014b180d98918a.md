# DEFINE USERS AND THEIR PRIVILEGES

.DESCRIPTION

The function will import all permissions from a CSVnfile and apply them to the vCenter Server objects.

.NOTES

Source: Automating vSphere Administration

.PARAMETER Filename

The path of the CSV file to be imported

.EXAMPLE

```
Import-Permissions -DC -Filename "C:\Temp\Permissions.csv"
#
```

```
param(
[String]$Filename
)
```

```

$permissions = @()
$permissions = Import-Csv $Filename
foreach ($perm in $permissions) {

	$entity = (Get-View -Id $perm.EntityId -Property Name).MoRef

	$object = $object | where {$..Id -eq $perm.EntityId}
```
