If a distributed switch is imported back into the same vCenter from which it was exported, the vmics of the hosts that were connected to that vDS will reconnect accurately, providing that those vmics have not been reconfigured and attached to a different switch. However, if the exported vDS is imported into a different vCenter and the original hosts that had been connected to the original vDS are also connected to this new vCenter, the host's vmics will need to be re-added to their uplink port groups. Listing 12.6 is a function that exports information on every vDS, including uplinks which each ESXI host's vmics are connected to. This ensures that the vmics connected to each port group before the export of this if the networking has to be re-added to the correct port groups is restored at a later date.
