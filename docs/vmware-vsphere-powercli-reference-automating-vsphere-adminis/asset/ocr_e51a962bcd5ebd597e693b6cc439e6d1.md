# Managed Object References

What is a MoRef? The acronym stands for managed object reference. A MoRef is a data object that is used as a kind of pointer or link to a managed object. You can use the Get-View cmdlet to retrieve a copy of the managed object from the MoRef. All managed objects have a property called MoRef, which points to the object itself.
