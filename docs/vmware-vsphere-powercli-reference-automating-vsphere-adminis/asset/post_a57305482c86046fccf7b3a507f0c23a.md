## Removing a Virtual Disk

Sometimes it may be necessary to remove a disk from a VM. Removal is accomplished with the Remove-HardDisk cmdlet. This cmdlet only requires one parameter: -HardDisk. The -HardDisk parameter specifies the hard disk to be removed.

> WARNING If you do not specify a particular hard disk(s) or a particular drive type, all hard disks will be removed from the VM.

To remove all hard disks from a VM named VM001, use the following:

```
Get-VM VM001 | Get-HardDisk | Remove-HardDisk -Confirm:$false
```

This may not be useful if a specific disk needs to be removed. For example, to remove all RDM disks from a virtual machine, using:

```
Get-HardDisk -VM VM001 -DiskType rawVirtual,rawPhysical | Remove-HardDisk -Confirm:$false
```

To remove only one specific disk, specify the filters to filter out using a unique property like Name, Id, or Filename. Assuming a VM disk named Hard Disk 2 needed to be removed from virtual machine VM001:

```
Get-HardDisk -VM VM001 -Name "Hard disk 2" | Remove-HardDisk -Confirm:$false
```

Notice that the Remove-HardDisk cmdlet removes the modified hard disk from the virtual machine. It does not delete the actual virtual disk file from the datastore.

## ADD, CONFIGURE, AND REMOVE VIRTUAL HARDWARE

To permanently delete the files from the datastore itself and not simply remove the hard disk from the virtual machine, add the -DeletePermanently switch:

```
Get-HardDisk -VM VM001 -Name "Hard disk 19" | \
Remove-HardDisk -Confirm:$false -DeletePermanently
```

The hardest part of removing a virtual disk can be finding the right virtual disk. It starts simply enough. For a virtual machine that uses only two virtual disks, chances it's straightforward. But what about removing a disk from a virtual machine running multiple Microsoft SQL Server instances that happens to have 26 disks?

To make matters worse, the SQL administrator plainly said, "Remove the K" or "Remove Windows disk 21."

What then? How does one determine which virtual disk to remove? The probable problem arises when extending disks, but first things first.

Listing 8.4 contains a function to assist in identifying the right virtual disk. Get-VMDiskMapping function can be used on hardware level 4 and up. Using SCSI adapter types is not supported on hardware level 4, however.
