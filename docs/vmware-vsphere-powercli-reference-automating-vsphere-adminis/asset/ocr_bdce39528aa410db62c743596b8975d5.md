So it comes as no great surprise, when adding a permission through PowerShell, you must consider three areas:

+   * Role The role that you will assign to the user

+   * Principal The user or group to which you wish to grant permissions

+   * Entity The object, folder, cluster, datacenter, resource pool for which you wish to grant permissions to the user

In the code that follows, we grant a `VSPHERE.local\User01` access to New Custom Role at the datacenter level:

```
New-ViPermission -Role 'New Custom Role' \
-Principal 'VSPHERE.local\User01' \
-Entity (Get-Datacenter)
```
