# Configure Active Directory Integration

Active Directory (AD) integration has been refined over the last versions of PowerCLI and has been simplified down to just two commands: Get-VMHostAuthentication (Listing 5.24) and Set-VMHostAuthentication (Listing 5.25). Using AD to authenticate users for vSphere Hypervisor is a simple, easy-to-maintain, and efficient method of ensuring that only authorized users are able to connect to the hosts using the CLI or vSphere Client. Using this method provides a quick and easy way to ensure that when administrators join or leave your team, their can quickly be updated from a single point.

Note that for the particular ESXi host in Listing 5.24 no Active Directory authentication has been defined; hence no domain membership is listed. To join the host to a domain, pipe the output of the Get-VMHostAuthentication cmdlet into the Set-VMHostAuthentication command.

# LISTING 5.25 Joining an ESXi host to a domain

```powershell
$domainname = "powercli.lan"
$credential = Get-Credential
$hostname = "esxi-01.powercli.lan"

$splat = @{
  'Domain' = $domainname;
  'Credential' = $credential;
}

Get-VMHost $hostname | 
  Set-VMHostAuthentication @splat -JoinDomain
```

Now when you execute the Get-VMHostAuthentication against the host, you can see that it is joined to the domain.

By the default administrators group for the ESXi host is for ESX Admins, but since this is a well-known group, it may be undesirable to leave it from a security perspective. You can change the administrators group for the host by adjusting the value of a particular option: Config.HostAgent.plugins.hostsvc.exadmins-Group. You can use the web or desktop clients to modify the settings or use a simple PowerShell function, as shown in Listing 5.26.

# LISTING 5.26 Set-VMHostADAdminGroup function

```powershell
function Set-VMHostADAdminGroup {
  <#SYNOPSIS
  Sets the Active Directory group to be used for ESXi host administrators.

  .EXAMPLE
  Get-VMHost host1 | Set-VMHostADAdminGroup -Group "VM Admins"

  .PARAMETER VMHost
  [VMware.Automation.ViCore.Impl.V1.Inventory.VMHost]
  The host to modify.

  .PARAMETER GroupName
  [System.String]

  The name of the group to assign as the ESXi administrator.

  .INPUTS
  [VMware.VimAutomation.ViCore.Impl.Vl1.Inventory.VMHostImpl]

  .OUTPUTS
  PSCustomObj

```powershell
#
[CmdletBinding(SupportsProcess=$true)]
param(
  parameter(
    Mandatory=$true,
    ValueFromPipeline=$true
  )
  [VMware.VimAutomation.ViCore.Impl.Vl1.Inventory.VMHost]
)
[Parameter(Mandatory=$true)]
  [String]$Group
)
process {
  $VMHost | ForEach-Object {
    if ($PSCmdlet.ShouldProcess(
      $_Name,
      "Setting esxadminsGroup to $($Group)"
    )) {
      # if the user approves, update the advanced
      # setting for this host
      $_ | Get-AdvancedSetting -Name \
        Config.HostAgent.plugins.hostsvc.esxadminsGroup |
        Set-AdvancedSetting -Value $Group -Confirm:$false |
        Out-Null
```

```powershell
# create an anon object to return the current setting
$obj = "" | Select-Object "AdminGroup"
```

```powershell
# get the current setting and populate the property
$obj.AdminGroup = ($VMHost) | Get-AdvancedSetting -Name `
Config.HostAgent.plugins.hostsvc.esxAdminGroup).Value
```

```powershell
# return/display the current value
$obj
}
}
}
```
