# CHAPTER 15 * REPORTING AND AUDITING

.PARAMETER Finish

The end of the time range in which to look for tasks.
If not specified, the function will use the current time as the end of the time range.

.PARAMETER State

The state of the tasks. Valid values are error, queued, running, success

.PARAMETER User

If specified will only return tasks started by this user.
If not specified the function will return tasks started by any user.

.EXAMPLE

```
Get-Cluster -Name "MyCluster" | Get-VITaskSDK
```

.EXAMPLE

```
Get-VITaskSDK -Entity (Get-VM myVM) -State "error"
```
