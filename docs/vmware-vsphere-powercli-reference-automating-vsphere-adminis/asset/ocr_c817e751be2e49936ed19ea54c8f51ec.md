The download schedule for new patches is typically once a day. Should you need to initiate a one-off outside of this schedule, a Download-Patch Async generates a task object, which can be managed with any of the PowerShell cmdlets. For instance, running Get-Task returns details of the Download-Patch task:

```
Get-Task
```

| Name | State | % Complete Start Time | Finish Time |
