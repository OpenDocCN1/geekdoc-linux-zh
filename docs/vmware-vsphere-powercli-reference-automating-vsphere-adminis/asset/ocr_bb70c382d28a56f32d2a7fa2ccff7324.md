Remember that you may need to adjust which user is executing the task to ensure that you have permissions to access the files and other resources that may be needed.

Alternatively, you can use PowerShell to create the scheduled task:

```
# The action is what the scheduled task will execute
$action = New-ScheduledTaskAction -Execute "powershell.exe" \
-Argument "-File C:\path\script.ps1"
```

```
# execute the task every day at a specific time
$trigger = New-ScheduledTaskTrigger -Daily -At 4am
```

```
# Finally, create the scheduled task
Register-ScheduledTask -TaskName "My PowerShell Script" \
-Action $action -Trigger $trigger
```

# Loading PowerShell

Did you know that the PowerShell window is special? When PowerShell is started using the Desktop or Start menu shortcuts, it executes a series of commands to load the cmdlets, aliases, and other preferences to make PowerShell easier. Prior to PowerShell version 6, the cmdlets were loaded using PSSnapins, which means they had to be deliberately loaded when needed.
