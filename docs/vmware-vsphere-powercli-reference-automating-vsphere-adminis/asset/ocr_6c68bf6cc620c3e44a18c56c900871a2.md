# Make the First Commit

The web interface for GitHub is currently more featured than VisualSVN Server, and it is possible (although not necessarily recommended) to make edits to files directly via the site. Once you've followed the process to create the new repository, its homepage will be displayed. If you selected the option to create a README, click the .md file in the repository's list of files. Above the file's content click the pencil icon to edit the file (Figure 24.43).
