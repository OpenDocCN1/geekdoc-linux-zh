# List the Default PSP for SATPs

Chapter 4, "Automating Storage," contains a section on working with ESXi multipath policies and using a combination of standard PowerCLI cmdlets and escli via PowerCLI to complete tasks that are not possible with the out-of-the-box commands. Listing 23.3 shows the code we created to use in a PowerAction script to list the Default Path Policies (PSP) for all Storage Array Type Plugins (SATPs) on an ESXi host.

LISTING 23.3 List the Default PSP for SATPs - PowerActions

```powershell
<#.NGC_REPORT
#
param
{
    [Parameter(Mandatory=$true)]
    [VMware.VimAutomation.ViCore.Types.V1.Inventory.VMHost]
$vParam
}
$esXcli = Get-EsXCli -VMHost $vParam
$result = $esXcli.storage.nmp.satp.list() | Select-Object-Name, DefaultPSP
Write-Output $result
```

To create the script, navigate to Home > PowerCLI scripts in the Web Client. Click the Create Script button to begin the wizard and select Host for Target Type. Click Next (Figure 23.21).
