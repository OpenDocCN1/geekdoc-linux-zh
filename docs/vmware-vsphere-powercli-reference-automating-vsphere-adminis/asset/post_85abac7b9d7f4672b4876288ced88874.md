# Data Objects and Their Methods

The properties in a object contains data objects. The data objects can be simple types—for example, the Name property is a String—or they can be other objects—like the AvailableField, which is a CustomField.

The methods in the managed objects are, simply said, functions you can invoke on these objects. For example, the RenameDatastore method on the Datastore object obviously renames a datastore. The API reference includes a detailed of all.

The documentation for each managed object follows a similar layout in the vSphere API Reference. First there is a section that lists the following:

* Property of: Where the managed object is used
* Parameter to: Which methods use the managed object
* Returned by: Which methods return the managed object
* Extends: The type on which this managed object is based
* See also: The data objects that are used in the managed object

The next section contains a description of the managed object. This is a must-read section if you are serious about working with managed objects. The description is followed by a tabular list of all the properties of the managed object and a list of all the methods available for the managed object.

If you look at the list of methods for the Datastore object in the vSphere API Reference, you will notice that there are a number of methods that are marked as inherited. Let's take the inherited method Rename that exists in addition to the more specific RenameDatastore method. In the case of the Datastore object, you can see (Figure 18.15) that a Rename_Task method inherited from the ManagedEntity object, which is itself a managed object.

# Figure 18.15 Rename_Task method

![](img/62596f5acc9790406084e5111beb7d6_670_0.png)

So what's the real deal? We have to two methods—one called DatastoreRename and another called Rename_Task. And both seem to be doing the same thing: renaming a datastore. The explanation for this can be found in the vSphere API Reference. The RenameDatastore method is marked as Deprecated, and it says you should use the Rename_Task method. This is obviously something that the vSphere API developers introduced with version 4.0 of the API. Historically most of the managed objects had their own rename method; in our example, that would be the RenameDatastore method.
