## What is SRM?

Site Recovery Manager (SRM) is a software product that automates the protection of virtual machines by enabling disaster recovery. It provides a centralized management and orchestration of disaster recovery plans.

## Exploring the SRM Cmdlets

SRM provides a set of PowerShell cmdlets that allow you to interact with the SRM server.

### Connecting to the SRM Server

The first step to automating SRM tasks is, of course, connecting to the server. Before connecting to an SRM instance, you must connect to vCenter. After that, it's as simple as calling the cmdlet, as we did in 22.1.

- **22.1** Connecting to the SRM server instance
