
All is not lost for our report, though we must simply work harder and use what are calculated as properties to get the desired output for the Baseline column in the CSV file. When using `Select-Object`, you can create your own property by using this syntax:

```powershell
Select-Object @{Name='PropertyName';Expression={Scriptblock}}
```
(Name and Expression can be shortened to N and E, respectively). In Listing 14.15, we created our Baseline property using the -ExpandProperty parameter of the Select-Object cmdlet to expand the Baseline object and then pick the Name property.

## LISTING 14.15 Exporting a compliance report to CSV

```powershell
Get-Compliance -Entity (Get-Datacenter -Prod1) |
@{N='Baseline';E={$_.Baseline.Name}},Status |
Export-CSV ComplianceStatus.csv -NoTypeInformation -UseCulture
```
