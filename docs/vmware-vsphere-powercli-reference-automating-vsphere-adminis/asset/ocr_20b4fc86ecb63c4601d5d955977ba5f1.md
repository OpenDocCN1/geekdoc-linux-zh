If you know the Peripheral Component Interact (PCI) information for the network card, you have to query the underlying SDK object; the information isn't available from the objects returned by the Get-VMHostNetworkAdapter cmdlet. This can be done through .ExtensionData property. Let's generate a full report like the HBA report we created with the script in Listing A.3. The script in Listing A.4 creates a report of all network interface cards on all hosts in clusters.

# A.4 Network interface card report

```
$nicReport=()
foreach ($cluster in Get-Cluster) {
    foreach ($vmHost in @($cluster | Get-VMHost)) {
        foreach ($nic in @($vmHost | Get-VMHostNetworkAdapter)) {
            $objNic = "" | Select ClusterName, HostName, Pci, \
DeviceName, Mac, BitRateSec,FullDuplex
            $objNic.ClusterName = $nic.ClusterName
            $objNic.HostName = $vmHost.Name
            $objNic.Pci = $nic.ExtensionData.Pci
            $objNic.DeviceName = $nic.DeviceName
            $objNic.Mac = $nic.Mac
            $objNic.BitRateSec = $nic.BitRateSec
            $objNic.FullDuplex = $nic.FullDuplex
            if ($nic.ExtensionData.Pci) {
                $nicReport += $objNic
            }
        }
    }
}
$nicReport | Export-Csv NicReport.csv
```
