An example case is shown in Listing 21.19. The Test-Output workflow contains two parameters text of type String and a type Number, so we will use XML to supply the parameter information.

LISTING 21.19 Using Invoke-VWorkflow with ParameterXML

```
$Credential = Get-Credential
$ParameterXML =
<execution xmlns="http://www.vmware.com/vco">
  <parameters>
    <parameter type="string" name="text" scope="local">
      <string>Apple</string>
    </parameter>
    <parameter type="number" name="a" scope="local">
      <number>7</number>
    </parameter>
  </parameters>
</execution>
Invoke-VWorkflow -Server vro01.sunnydale.local -ID 0c278910-9ae2-46c5-bb45-2292fe88e3ab -ParameterXML -Credential $Credential
```

The output would be like this:

```
StatusCode : 202
StatusDescription : Accepted
Execution : https://vro01.sunnydale.local:8281/vco/api/workflows/0c278910-9ae2-46c5-bb45-2292fe88e3ab/executions/40280244ae82e6014b0961089a0234/
```
