# HOST POWER ACTION LEVELS

Action levels, shown in the Set-DPM function as the threshold, define the level at which a power action is recommended. A power action is when vCenter recommends that a host be either powered on or powered off. These settings have similar purpose to the DRS recommendation settings for cluster. For instance, a power action level 1 is the most aggressive for powering hosts on off. A level 5 is so conservative that it rarely, ever, powers off a host, and only powers on in the event of severe resource imbalance. The double-edged sword is that the power action is responsible for much confusion. Our advice is to never forget that this setting impacts both actions and will be right.
