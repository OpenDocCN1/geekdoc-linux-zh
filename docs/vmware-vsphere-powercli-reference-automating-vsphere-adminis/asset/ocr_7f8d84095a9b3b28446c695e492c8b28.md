The only thing left is assign hosts to the DVUplink ports and you're ready to host VMs. To do this, first test a host for compatibility. To assist in this task, you can enlist the Get-DistributedSwitchCandidate function, which was originally included in the previously mentioned distributed switch module created for the first edition of this book. Since this functionality is not included in the official PowerShell VDS module, it is included in Listing 3.14 for your convenience.

function Get-DistributedSwitchCandidate {
#
