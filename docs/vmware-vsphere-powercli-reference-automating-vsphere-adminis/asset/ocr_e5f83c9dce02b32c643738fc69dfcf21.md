# LISTING 16.13 Average transmit rate per pNIC on a single server

```
$exsName = "exsl1.test.local"
$metric = "net.transmitted.average"
```

```
# Define the time frame
$todayMidnight = (Get-Date -Hour 0 -Minute 0 -Second 0)
$Start = $todayMidnight.AddDays(-1).AddSeconds(1)
$Finish = $todayMidnight
```

```
# Get the entity
$exsImpl = Get-VMHost -Name $exsName
```

```
# Produce the report
Get-Stat -Entity $exsImpl -Stat -Start $Start -Finish | Group-Object -Property Instance | Where {$_.Name -ne ""} | %{ New-Object PSObject -Property @ pNIC = $_.Name AvgKps = [Math]::Round(($.Group | Measure-Object -Property Value -Average).Average, 1) TotalKps = [Math]::Round(($.Group | Measure-Object -Property Value -Sum).Sum, 1) }
```

The script produces a simple table that lists the average and total transmit rate per physical NIC for the previous day, like the one shown in the code below. This allows you to see if your load balancing is performing as expected.

TotalKps pNIC AvgKps

| pNIC AvgKps |
|---|---|
| 282 vmnic0 | 5,9 |
| 35338 vmnic1 | 736,2 |
| 5 vmnic6 | 0,1 |
| 0 vmnic7 | 0 |

In this case, vmnic0 and vmnic7 were in a port group without load balancing active.
