# CHAPTER 14 • MAINTAIN SECURITY IN YOUR SPHERE ENVIRONMENT

# LISTING 14.1 Retrieving a set of VUM patches

```
$Patches = Get-Patch -TargetHost -Vendor VMware -Product \
  'embeddedESX 5.5.0' -After '01 Oct 2014'
```

The Patches variable will contain similar to this:

| Name | ReleaseDate | Severity | IDByVendor |
| --- | --- | --- | --- |
| Updates esx-base | 15/10/2014 | Important | ESXI550-20141010-SG |
| Updates esx-base | 15/10/2014 | Critical | ESXI550-20141041-BG |
| Updates misc-drivers | 15/10/2014 | Important | ESXI550-20141042-BG |
| Updates sata-ahci | 15/10/2014 | Important | ESXI550-20141043-BG |
| Updates xhci-xhci | 15/10/2014 | Important | ESXI550-20141044-BG |
| Updates tools-light | 15/10/2014 | Important | ESXI550-20141045-BG |
| Updates net-vmxnet3 | 15/10/2014 | Important | ESXI550-20141046-BG |
| Updates esx-base | 02/12/2014 | Important | ESXI550-201412401-BG |

Now that your required patches are stored in the $Patches variable, these patches can be provided as part of a new static baseline created with New-PatchBaseline (Listing 14.2).

# LISTING 14.2 Creating a static patch baseline

```
$New-PatchBaseline -Static -TargetTypeHost -Name \
  'ESXI Current (Static)' -Description \
  'ESXI 5.5 patches since 01Oct2014 - 22Jan2015' \
  -IncludePatch $Patches
```

In a similar vein, you could create a new dynamic baseline, which will essentially start out like the static one. This baseline would be for host machines from VMware for ESXI which have been released since October 1, 2014 (Listing 14.3).

# LISTING 14.3 Creating a dynamic baseline

```
$New-PatchBaseline -Dynamic -TargetTypeHost -Name \
  'ESXi Current (Dynamic)' -Description 'to the current date -SearchPatchVendor \
  'VMware*' -SearchPatchProduct 'embeddedESX 5.5.0' \
  -SearchPatchStartDate '01 Oct 2014'
```
