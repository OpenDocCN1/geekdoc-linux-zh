The Get-Event cmdlet returns all events within a specific time frame. Sometimes, it could be handy to retrieve only events' children that were produced by a specific entity, including all the entity's children. The function in Listing 15.6 can be run against either vCenter server or an ESXI server. When you run it against an ESXI server, it returns the 1,000 events or all events since the reboot of the server if there are fewer than 1,000 events.

## CIM Interface

With PowerShell 3, a number of CIM cmdlets were introduced. These CIM cmdlets allow interaction with the Common Information Model (CIM), an open standard for querying managed objects in an IT environment. VMware uses CIM on ESXi hypervisor to monitor the hardware on the server. You can see this information under Configuration - Health Status when connected to an ESXI server and under Hardware Status when connected to vCenter.

The CIM classes provided by VMware are documented in the CIM SMASH/Server Management API Reference:

`http://pubs.vmware.com/vsphere-60/topic/com.vmware.sdk.doc/GUID-4406C028-AD55-4349-A6B8-09150B561438.html`

Listing 15.7, on a function published by Carter Franklin PowerCLI Product Manager, wraps a call to the ESXi CIM API.
