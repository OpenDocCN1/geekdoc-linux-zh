# Adding a Protection Group to a Recovery Plan

Since a protection group by itself contains the virtual machines that you wish to associate together as a group, you want to make sure that the protection group has been added to a recovery plan. A recovery plan is where the action takes place, as is where things like recovery order, pre- and post-scripts, and other actions can be configured. Unfortunately, at this time, there is no way to configure these settings using the API and PowerShell, so you must rely on the GUI to perform them.
