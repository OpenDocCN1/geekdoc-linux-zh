# PowerShell Host

vRO needs to communicate with a PowerShell host to execute PowerShell commands and scripts. If you are using the Windows install of vRO, it is possible to use vRO as a PowerShell host. However, for the purposes of this book, we are using another Windows Server 2012 R2 machine as a PowerShell host. This also meets the PowerShell host requirement if a vRO Linux appliance is being used.

# Configuration

You must take a number of steps to correctly configure the remote PowerShell Host and vRO before you use the PowerShell plug-in. These are primarily based on what protocol and authentication methods you will use to communicate with the remote PowerShell host. The nature of such decisions is beyond the scope of this book. For our purposes, we will be using HTTP and Kerberos.

# Time Sync

Since we will be using Kerberos for our authentication, it is important to ensure that all servers being used are synchronized to the same time source.
