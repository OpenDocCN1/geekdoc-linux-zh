Generating this report for just one cluster is nice, but what about your other clust-	ers? The benefit of writing the Get-ClusterSummary code as a function that you can-use the code with any cluster object you like. To generate a report for all your clust-	ers, you only have to put them all in the pipeline by just removing the cluster name
from the Get-Cluster cmdlet

```
Get-Cluster | Get-ClusterSummary | Format-Table
```
