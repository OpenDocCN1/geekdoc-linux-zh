A similar admin task is to rename a port group. If you carry out this task on a standard vSwitch in the vSphere client, then any VM with a connection to that port group will appear to be disconnected from the vSwitch. This will have no immediate impact on a running VM; however, upon restart of the VM NIC will be disconnected and consequently it will not be able to communicate on the network.
