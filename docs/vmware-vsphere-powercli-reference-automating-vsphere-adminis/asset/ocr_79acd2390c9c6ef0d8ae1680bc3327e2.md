$body += "<vmknicCount>$$vmknicCount</vmknicCount>

$body += "</resourceConfig></nwFabricFeatureConfig">

# Further Configuration and Administration of NSX

You have now some examples of REST calls using PowerShell to configure NSX. Once VXLAN is configured on all the hosts in the cluster, you are ready to finalize the logical network settings, creating logical networks, and benefit from all of the capabilities and functionality of NSX. To continue REST calls to configure NSX, you may refer to VMware's NSX API Guide. The guide for NSX 6.2, for example, can be found here: http://vmw.re/1Llhf06B.
