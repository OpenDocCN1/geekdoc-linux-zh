## Add Code to a Project with TortoiseSVN

We now have a repository and project on the VisualSVN Server and a local copy of the folder structure on the client machine, so we're in a position to add some code. Let's create a function and save it in a `Test-Function01.ps1` file in the C:\Code\Project01\trunk folder. For the purposes of this example, it doesn't matter what code you use, but we were using the following:

```hell
function Test-Function01 {
  Write-Host "This is test 01"
}
```

In Windows Explorer, navigate to the C:\Code\Project01\trunk folder and find the Test-Function01.ps1 file; in particular, notice the question mark icon to the left of the filename (see Figure 24.17). This indicates that the file has not yet been added to the project and is a useful visual when selecting multiple files that do not yet belong to the project.

> TIP If you experience SVN with the overlay icons not appearing in Windows Explorer, check out the TortoiseSVN FAQ for suggested, http://tortoisesvn.net/faq.

Add the code to the project:

1. Right-click the Test-Function01.ps1 file and choose TortoiseSVN Add from the context menu (Figure 24.17).

## FIGURE 24.17 Adding code file to your project

![](img/62596f5acc979040608a4e5111beb7d6_886_0.png)

2. At this point there will be no noticeable changes and no stats. This is because a second step is required. Right-click the Test-Function01.ps1 file again and notice that there is a new option: SVN Commit (Figure 24.18). Select SVN Commit.

## FIGURE 24.18 Committing a code file to your project

![](img/62596f5acc979040608a4e5111beb7d6_887_0.png)

It is a good practice to add a comment to each commit so that you or somebody else retrieves the change at a later date, the thought process behind that change is obvious. We added an initial message that seemed to be the most helpful information at this point.

5. If all is successful, then the Commit Finished! dialog box will open with a summary of changes and a new revision level, which is useful for future reference. We were given Revision 2 (Figure 24.20). Click OK to close the dialog box.
