Typically with Fibre Channel SANs, you will be working with LUNs, not
just three as in the previous example. Even making the change for the PSP to
Round Robin via the GUI for three LUNs would soon become tedious, so by using
this via PowerCLI can save you a lot of time. By-MultipathPolicy parameter of the Set-ScsLun cmdlet, you can make the change
across your Fibre Channel LUNs in one line of code. You can also use Where-
Object to filter out non-Fibre Channel LUNs, as we did in Listing 4.13.

# Listing 4.13 Setting multipath policy for multiple LUNs

```
GetVMHost vesxi05* | Get-ScsLun | Where {$_.CanonicalName \
-like 'naa.6000*'} | Set-ScsLun -MultipathPolicy "RoundRobin"
```

# Setting the Default PSP for an SATP

Once LUNs have been updated with the correct PSP, you may wish to update the
Default PSP for the SATP in use so that any additional LUNs added in the future
will be correct at the time of creation.

![](bbox=[0.242, 0.513, 0.288, 0.548])

> NOTE An alternative method to explicitly setting the Multipath policy via Set-
ScsLun in Listing 4.13 is to set the default PSP (as we are about to demonstrate), place
host in Maintenance mode, and reboot. This has the advantage that LUNs would not
tied to a specific PSP should future changes to the Default PSP be necessary and only
reboot necessary again to change LUNs to a new PSP.

We can achieve this via the Get-ExCli method described earlier in the chapter.
Listing 4.14 demonstrates how, for example, to set the default PSP for the SATP
VMW_SAT_ALUA to Round Robin (VMW_PSP_RR).

# Listing 4.14 Setting the default PSP for an SATP

```
$DefaultPSP = 'VMW_PSP_RR'
$SATP = 'VMW_SAT_ALUA'
$EsxCli = Get-ExCli -VMHost vesxi05*
$EsxCli.storage.nmp.satp.set($null,$DefaultPSP,$SATP)
```
