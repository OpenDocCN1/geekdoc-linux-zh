When using the Search-Cloud cmdlet, if you do not specify which properties you retrieved using the -Property parameter, the result will display all properties of the objects returned. The -Filter parameter can be used to narrow the search results. Note that you can add multiple filter criteria on each search. The criteria must be separated by a semicolon (;). For more information on the filter syntax, refer to the vCloud API Programming Guide.

You can also search for a particular org vDC. In our next example, we'll search for an org vDC named OrgVDC1:

```
Search-Cloud -QueryType OrgVdcNetwork -Filter 'VdcName==OrgVDC1'
```

That code returns all properties of OrgVDC1. You can simplify the results by using the -Property parameter mentioned earlier:

```
Search-Cloud -QueryType OrgVdcNetwork -Filter 'VdcName==OrgVDC1' \
-Property 'Name', 'DnsSuffix', 'DefaultGateway', 'Dns1'
```

The return now presents only the data specified.

# Connecting to vCloud Air

Connecting to vCloud Air became a very simple task with the release of PowerCLI 6.0. PowerCLI 6.0 introduced cmdlets that allow you to connect and disconnect from vCloud Air: `Connect-PSIServer` and `Disconnect-PSIServer`.

The cmdlets allow you to log into vCloud Air without having to specify a vCloud API URL or vCloud Org based on your entitlements. `Connect-PSIServer` requires only your username and password. There are three ways that you can connect to vCloud Air with this cmdlet. The first is hardcoding your username and password in the command. This approach is not recommended for scripts, but if you are logging into vCloud Air manually, you would type it out like this:

```bash
Connect-PSIServer -User BrianGraf@contoso.com -Password VMware!
```

The second method uses the -Credential parameter with the Get-Credential cmdlet to prompt for the username and password upon execution:

```bash
Connect-PSIServer -Credential (Get-Credential)
```

The third method leverages the Credential Store. Beginning with PowerCLI 4.1, VMware included what is known as the Credential Store, which is populated with credentialStoreItems. These items, which are encrypted in the `${env:APPDATA}\VMware\credentialstore\credentials.xml` file on your local machine. Using the Credential Store, you can input your username and password for a given host once, which can then be used to connect to hosts with much less effort:

```bash
New-CredentialStoreItem -Host vchs.vmware.com -User BrianGraf@contoso.net -Password VMware!
```

This Credential Store code sets the username and password for the host, vchs.vmware.com, so that any future attempts to log into vCloud Air using the Connect-PSIServer cmdlet will not require credentials. You can also store your vCloud Air credentials in the Credential Store using the Connect-PSIServer cmdlet and by adding the -SaveCredentials parameter, which will eliminate the need to run the New-CredentialStoreItem command.
