# Interruption Vector Table

PA-RISC uses an Interruption Vector Table (IVT) to determine how to handle each type of inter-ruption. The address of the beginning of the IVT is stored in control register CR14. Each entry in the table is 32 bytes (8 words) long. Note that these entries are not just pointers to routines—they are actual code, up to eight instructions. In many cases that code will just be a BRANCH to the correct handler, but this doesn’t have to be the case.
