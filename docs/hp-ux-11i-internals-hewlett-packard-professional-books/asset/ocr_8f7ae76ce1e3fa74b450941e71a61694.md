# Shared Memory, System-V, and POSIX

In a very similar manner system-V, shared memory regions are also maintained by first allocating an entry from the system’s shared memory descriptor table, `shmem[ ]`. An active table entry points to a pseudo `vas`, `region`, and `region` created to manage the shared memory space (see Figure 9-8). The System-V shared memory allocation, attach, detach, and deallocation requests are mapped through this table and its related structures.
