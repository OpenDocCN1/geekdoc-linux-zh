A count of the number of waiting POSIX threads that have not specified an `MPC_MANDATORY` binding preference

32 0 4 0 int rts_ready_free

To examine the POSIX rtssched run queues using q4, launch a q4 session against the running kernel:

```
# load all of the POSIX run queues
q4> load struct rtssched_info from &rtssched_info
q4> load struct mp_threadhd from rts_qp max rts_numpr1
q4> print -> addrfox th_link th_rlink
# next make a pile of all the threads on nonempty run queues
# (hint: empty queues point to themselves.)
q4> keep th_think != addr0
q4> load thread_1 from th_link next kt_link until addr0f max 100
# to see much you should try this on a multiprocessor system with running
# POSIX real-time processes
```
