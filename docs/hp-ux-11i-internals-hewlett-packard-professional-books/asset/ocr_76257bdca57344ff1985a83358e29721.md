Beginning with HP-UX 11.1, the kthread table is now a dynamic linked list. As with the proc table, entries no longer needed are placed on a free list (as opposed to having their space returned to the kernel memory allocation arena), and new entries are allocated as needed, up to a tunable limit, when the free list is empty.
