# Signal Anticipation

*Signal anticipation* is what an application can do to plan for signals. From the application's point of view, the preferred method of planning for signals is with the *sigation()* system call. Other system calls are available too, but they have essentially the same functionality. *Sigation()* is the POSIX standard and should be used in all new development.

*Sigation()* expects three arguments: the signal number, a struct *sigation* containing new values to be used for that signal, and a struct *sigation* into which the old values can be returned. The file */usr/include/sys/signal.h* includes symbolic definitions of the signal numbers, the definition of the *sigation* structure, and a variety of other signal-related declarations. The *sigation* structure contains a pointer to a handler routine, a mask that indicates what signals should be blocked while handling this signal, and a set of flags for modifying the signal-handling behavior. We'll see how these are used shortly.

If the user has specified a non-NULL value for the second argument, indicating that he or she wants to change the existing values for the signal, *sigation()* first does a few sanity checks to make sure that the values passed in the *sigation* structure are valid. We first check to see if the user is trying to change the action for SIGKILL, SIGSTOP, or SIGCANCEL. These signals cannot be caught. Any attempt to change the handler to anything other than SIG_DFL (the default handler) will cause *sigation()* to return EINVAL. Next, we validate the flags to make sure that there are no unsupported bits set in the flags field. If any bits other than those defined in *signal.h* are set, *sigation()* will again return EINVAL. Finally, if the user is trying to change the behavior of the SIGFALLFAULT signal, or he she must also have the _SA_SIGFAALLFAULT flag set in the flags field. SIGFALLFAULT is used by the graphics libraries and should normally not be changed by a user application. This flag is a way of saying, “Yes, I really do want to change SIGFALLFAULT.”

Once we've passed the sanity checks, the next thing *sigation()* does is call *setsgvec_setup()*. This routine is responsible for allocating any needed memory and for acquiring any locks needed to ensure that the operation will be atomic and can't be interrupted.
