By maintaining this degree of separation between a file's attributes (its inode data) and its name (directory entry), it is a simple task to create multiple file names pointing to the same inode. This is the basis for the creation of hard links (referenced the 1m command).

To study the structure of a HFS inode, let's examine the icommon structure in the HP-UX kernel (Listing 8.1).
