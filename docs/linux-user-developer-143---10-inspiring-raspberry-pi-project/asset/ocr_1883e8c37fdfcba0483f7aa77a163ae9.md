# Spot the difference

Still not sure if you want to upgrade? Here’s a close-up look at the specific differences between the Model B and the Model B+

![](bbox=[0.05, 0.3, 0.95, 0.93])

**Video out** In case you don’t have a TV with HDMI input, the original Model B also came with a classic analogue video out port for standard definition display. This has been removed from the Model B+

**GPIO pins** An array of GPIO pins make up the GPIO port, used for connecting the Raspberry Pi to a multitude of other physical devices from simple electronic circuits to touch screens and robots

**MicroUSB power** The B takes its power via a microUSB port. While it technically can be run off a PC’s USB port it won’t adequately power the device for everything. Use a 1.5 A adapter for the best performance

**Headphone jack** Analogue audio-out in case you can’t use the HDMI port for digital sound. It fits all headphones or speakers that use the industry standard 3.5 mm jack. It doesn’t include a microphone in function though

**HDMI port** The main video and audio-out port for the Raspberry Pi, outputting up to 1080p video along with digital audio. Even though the Pi is small, it can easily decode and run high-definition video

**Dual-USB port** Having two USB 2.0 ports was a luxury compared to the Model A with its singular port. It can’t power much, though, so expanding it required a USB hub with an external power source

**Ethernet port** Exclusive to the B, the ethernet port gives the option of wired networking, which is useful for updating and maintaining your Pi if drivers don’t work for a Wi-Fi dongle or you run out of USB ports
