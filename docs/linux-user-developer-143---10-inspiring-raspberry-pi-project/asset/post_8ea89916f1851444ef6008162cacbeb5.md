
## Upgrade your private cloud with ownCloud 7

Access, sync and share your data much more effectively

TUTORIAL

![](img/daaca9116bc2b1db669c224de81abc7c_34_0.png)

### Your data - under your control

With ownCloud you can sync & share your files, calendar, contacts and more. Access your data from all your devices, on an open platform you can extend and modify.

### 01 The UI

With ownCloud 7, the old UI has made way for a neat and clean new UI – with clear focus on sharing and segregation of features. Almost all of the pages you go to now have an option to share. If you’ve used the older versions you’ll notice a lot of changes: the left menu panel now only shows options specific to the section that you are currently in. You can select various sections using the drop-down at the top-left; the various sections available are Files, Activity, Pictures, Contacts, Calendar, Bookmarks and Apps. So, for instance if you are in “Files”, you can see options related to files only, and these options change as you move to other sections. The user related menu remains unchanged though; you can access it by clicking the drop-down next to your login name on the top-right corner.

### 02 Files

As a cloud storage tool, file handling is probably the most important aspect of ownCloud, and the latest version takes it a notch higher. While earlier it was difficult to keep track of files shared by someone else (with you) and your own files, with ownCloud 7 you get the option to separately view the files shared to you or shared by you. Even the files shared via links can now be viewed separately. The act of sharing remains the same, though; just hover on the file to be shared and you can see the share icon along with download and versions. As earlier, files can be shared to your ownCloud groups and users or to someone not on your ownCloud via a link. The old rename option has been now reduced to just an icon, placed closer to the file name.

### 03 Activity

Before, while using ownCloud, you’d be pretty much on your own. Even if there were other users doing their stuff, it was all pretty much invisible to you. There was no way to actually have a clear picture of what is going on. Considering how important online interaction is these days, it was something of a mild annoyance. With the latest release has been taken care of. Activity is a section now available under the top-left corner menu, which lets you see (and can even send you email notifications about) the activity going on around you. You can see if someone has shared a file, renamed or deleted it, etc. Again, here you have the option to view just yours, or others, or both activities.

### 04 Contacts & Calendar

Contacts have been completely revamped with this version of ownCloud. While earlier there were only a few fields with very little relevant information stored, the contacts section now captures complete data such as email addresses, phone numbers, and more. You even have the option to add extra fields to contacts as per your needs. Head over to the contacts section to view it in action. Calendar also seems like a brand new feature (though there was a minimal calendar on the old ownCloud, every option was hidden behind the settings icon on the right side). The calendar is now clearly visible in the left side panel. There are no extra features added here, but the positioning of the links is definitely better and would improve the feature usability.

### 05 Collaborative editing

As a cloud platform for data sharing, ownCloud does great, but collaboration using ownCloud was a little difficult. This is no more the case now. OwnCloud now allows up to five different users to edit the same ODT files simultaneously. There is no need to even enable this app; it is enabled right off the bat. Here’s what you need to do: go to the “Documents” section, and upload a file you’d like to collaborate on. After you upload it, share it with relevant users/groups by clicking on the “Share” button on the far left. (Take care to give sufficient privileges while sharing). Now that it is shared, the other user(s) can just go to the “Documents” section while they are logged in and edit the document even when it is opened somewhere else. To make things clearer, names of all the users currently accessing the document are shown in the document-editing page, and all the edits are colour-coded.

### 06 Configuring external storage

Since ownCloud 6, we’ve had the option to enable the external storage app and add a secondary storage to ownCloud installations. You can use a local drive – Dropbox, Google Drive, even an Amazon S3 server – as a secondary storage. You can then encrypt the data stored in ownCloud and external storage using the encryption app. Let’s take the example of adding a local storage and then encrypting the contents (note that only the newly-added data to external storage gets encrypted). Let’s assume you have added a new USB drive to your system and wish to add it to your ownCloud as storage space. Enable the “External storage support” app. After the app is enabled, go to the admin page’s “External Storage” section. Now select the storage type as “Local” from the drop-down, fill in the absolute path of the external drive under configuration, and finally add the users/groups you like to give access to the drive. If everything is fine, you should be able to see the green light on the far left. If it’s red, there is a problem. This drive should now be seen under the “Files” section as “External storage”. To encrypt the files, just enable the “Encryption” app and re-login to generate the encryption keys and encrypt the data.

### 07 Tasks enhanced

Collaboration generally depends on how clearly the tasks are defined for each of the collaborators. While core ownCloud doesn’t support tasks or lists, the “Tasks enhanced” app comes in handy in managing tasks. This plug-in doesn’t come bundled with the default installation, though. You need to download the files from the app store and place them in the ownCloud/Apps folder. Then, when you visit the apps page in ownCloud, you should be able to view the “Tasks” plug-in, so just select it and click enable. As the plug-in is enabled you can see a new option “Tasks” in the top left menu. In the tasks page, you can add lists, and then tasks within the lists. As you add a list, corresponding calendar gets created, thus the whole list and the related tasks can be shared across ownCloud (you can share your calendars with other users).

### 08 ocDashboard

Have you experienced a sudden urge to look something up on Google while working? Maybe you like to check on what the weather will be like at the weekend, or see what's happening in the news. These kinds of distractions are plentiful on the internet, and most of the time that's fine. But if you find your productivity suffering, then the dashboard app is a great way to cut them out. It needs to be downloaded and installed as the earlier app. Once installed, you get the “Dashboard” option in the top left menu. To manage the dashboard settings, go to your personal page (top-right menu » Personal). Here you can add various dashboard items like clock, calendar, weather, search, activity, news and much more. It even supports the tasks; you can enable the tasks app and then view them on your dashboard.

### 09 Files move

The default file management in ownCloud allows you to rename or download files and move files using drag and drop. While this is fine if there are fewer files to handle, it may prove to be inefficient when you have to handle lots of files, as many files means many folders to segregate related files! The “Files move” app can be of help in such cases. Just download it from the ownCloud apps website and enable it. Once enabled, you can directly visit the files page. Here you can see the option to move files when you hover on a file/folder.

As you click on the move icon, all the available destinations for the file are automatically listed. You just need to select the proper destination and click Move.

### 10 ocGame

Well, so much for productivity! Now we can have a brief look at the ocGame app, which integrates some of the more traditional computer games to your ownCloud installation. As usual, enable it after download, and you get the “Games2+” link in the top left menu. This page you have games like Minesweeper, Tic-tac-toe, Fire In A Row and others. While these are not on quite the same level as smartphone games, they are briefly entertaining and can definitely help you ease your nerves after hectic work.
