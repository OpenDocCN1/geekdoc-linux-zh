# Upgrade your private cloud with ownCloud 7

Access, sync and share your data much more effectively using ownCloud 7's brand new features and built-in apps

+   **Resources**
+   * ownCloud website [owncloud.org](https://www.owncloud.org)
+   * ownCloud app page [apps.owncloud.com](https://apps.owncloud.com)

Some time back in LUbD 135, we ran a tutorial on setting up your own private cloud using **ownCloud 5.0.13**. Along with installation, we also saw how to set up desktop syncing and the ways to extend ownCloud functionality using various apps. Today we revisit ownCloud – version 7.0.0. The new ownCloud 7 was released recently with several new features and a revamped UI. As per the ownCloud website, the main focus with this version is to help you in accessing, syncing and sharing your data.

In this latest incarnation, the ownCloud UI has been tweaked heavily, with the main focus on sharing. Also the functionality is now clearly segregated with related functionality grouped together. But the changes are not only skin deep; several new features have been added as well. ownCloud 7 now has external storage, which lets you add extra storage from Dropbox, Google Drive and others, and collaborative editing, which enables up to five people to work on a doc simultaneously, along with many other enhancements. We will have a look at the new features in this tutorial, as well as check out ways to extend ownCloud functionality using apps. As you're aware, apps are integral parts of ownCloud – adding them is as simple as selecting the app and clicking Enable. Some of the apps like calendar, contacts etc. are enabled out of the box in your ownCloud installation.
