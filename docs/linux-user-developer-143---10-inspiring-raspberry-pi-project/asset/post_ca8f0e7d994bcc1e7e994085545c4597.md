### How to burn an ISO

Want to try a new distro ISO? Here's how to get started...

- **STEP 1: Grab a new ISO**
  - Copy the distro's ISO from our cover disc to your hard drive: go to the Distros tab, click ISO and choose to Save. Alternatively, find an ISO online to download. If you're not sure if you need a 32-bit or 64-bit version, go with the former to be safe.
  
  ![Step 1 Screenshot](placeholder_for_step1_screenshot)

- **STEP 2: Open or install Brasero**
  - Brasero is the most popular open source disc-burning utility. If it's not already installed on your distro, locate it in your distro's repository and install it. Then open the program and select 'Burn image' from the Projects tab on the left.
  
  ![Step 2 Screenshot](placeholder_for_step2_screenshot)

- **STEP 3: Burn your disc image**
  - On the Image Burning Setup menu, click the first box - marked 'click here to select a disc image' - and navigate to the ISO you just put on your hard disk. Once selected, ensure you've got a CD or DVD writable disc inserted and click 'Create Image'.
  
  ![Step 3 Screenshot](placeholder_for_step3_screenshot)

### Editor’s picks

**Hugin** The possibilities for image editing on Linux can often feel quite limited, so Hugin is refreshing for being not just another GIMP clone but a unique tool in itself. Use it to stitch together a mosaic of overlapping photos into a single immersive panorama. It’s good fun.

**Geany** This is essentially a text editor using the GTK2 toolkit, offering the features of a basic integrated development environment. Aside from being lightweight and fast, it’s also designed to be independent from DEs such as KDE or Gnome, requiring just the GTK2 library.

**Tor** If you don’t want to hop onto Tails for some safe surfing then you can always set up Tor for yourself. It seems to be making the news almost every week now, and Tor is popular for a reason – get ahead of the curve and protect your privacy now.

### Complete index

#### Operating systems

**Tails 1.1** This updated version of Tails now includes some user-visible changes in addition to security and bug fixes, such as UEFI boot support and VirtualBox guest modules.

**CentOS 7** With the recent release of RHEL 7, CentOS has gone up a version number as well. Among the improvements is the inclusion of systemD, Gnome3 and a default XFS file system.

**Ubuntu 14.04.1** The first of many more point updates to come, this release includes security updates and updated installation media, to reduce the amount of updates needed post-installation.

**GParted Live** This great tool provides you with a graphical environment for any partitioning tasks you need to carry out. It contains all the tools you’d find in the GParted application.
