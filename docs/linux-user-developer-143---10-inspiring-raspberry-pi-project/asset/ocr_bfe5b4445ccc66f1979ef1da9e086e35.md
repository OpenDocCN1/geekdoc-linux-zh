# ## How to burn an ISO
Want to try a new distro ISO? Here's how to get started...

+   **STEP 1: Grab a new ISO**
+   Copy the distro's ISO from our cover disc to your hard drive: go to the Distros tab, click ISO and choose to Save. Alternatively, find an ISO online to download. If you're not sure if you need a 32-bit or 64-bit version, go with the former to be safe.
+   
+   ![Step 1 Screenshot](placeholder_for_step1_screenshot)
+   
+   **STEP 2: Open or install Brasero**
+   Brasero is the most popular open source disc-burning utility. If it's not already installed on your distro, locate it in your distro's repository and install it. Then open the program and select 'Burn image' from the Projects tab on the left.
+   
+   ![Step 2 Screenshot](placeholder_for_step2_screenshot)
+   
+   **STEP 3: Burn your disc image**
+   On the Image Burning Setup menu, click the first box - marked 'click here to select a disc image' - and navigate to the ISO you just put on your hard disk. Once selected, ensure you've got a CD or DVD writable disc inserted and click 'Create Image'.
+   
+   ![Step 3 Screenshot](placeholder_for_step3_screenshot)
