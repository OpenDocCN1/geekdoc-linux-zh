Well there are a couple of things this could be caused by. *Firstly*, does your stick have one of those switches on the side that makes it write-protected? You may have accidentally activated that and not quite realised it.

# Configuring wireless drivers

I've just installed a driver for the Linksys AE2500 wireless adapter using ndiswrapper and was able to set up the wireless network configuration for WPA-WPA2 security mode. My Linux distribution is Ubuntu 12.04.

The driver is bcmwl-hid and the device's MAC is c0:c1:03:0a:d2:d7 ndiswrapper -l reports the following status:

**bcmwl-hid: driver installed**
**device (13b1:003a) present**

I am puzzled by the driver's failure to detect the wireless network, which normally works with several other wireless adapters. But then sudo lshw does not report this device either.

I'd be very grateful if you could give me a hand with this.

**Julian**

**What may well be happening is that the module is not loading properly.** This can happen with any kind of driver or module but to fix this specific case use

`$ modprobe ndiswrapper`

...followed up by adding ndiswrapper to the end of /etc/modules file. It will autoload ndiswrapper at boot time and get your wireless working as soon as you log in.
