# LINUX Linux dominates TOP500 supercomputing

# Powers 97% of high-performance systems

GNU/Linux has retained its position as the most popular operating system for high-performance computing (HPC), according to the most recent TOP500 survey results.

Published twice a year, the TOP500 List records the 500 most powerful supercomputer systems in the world. This year's list shows a continued dependence on Linux variants, with an impressive 486 of the 500 computers listed using a Linux variant — including the world's fastest supercomputer, China's Tianhe-2 (MilkyWay-2), and a mixed-platform Blue Gene system in Saudi Arabia which couples SUSE Linux Enterprise Server 9 with IBM's Compute Node Kernel (CNK).

The remaining systems in the latest TOP500 list use Unix (12 systems), with Microsoft's proprietary Windows platform running on only two — one of which, at position 433, is the company's own Azure cloud computing platform.

## Google Launches Project Zero

Aims to boost web security for all

Advertising giant Google has announced the foundation of Project Zero, a security programme that the company hopes will help increase the safety of the web – and, crucially, consumer confidence in that safety in the wake of highly publicised vulnerabilities like OpenSSL's Heartbleed.

“You should be able to use the web without fear that a criminal or state-sponsored actor is exploiting software bugs to infect your computer, steal secrets or monitor your communications,” claimed Google security researcher Chris Evans in the Project Zero launch announcement. “Yet in sophisticated attacks, we see the use of zero-day vulnerabilities to target, for example, human rights activists or to conduct industrial espionage. This needs to stop. We think more can be done to tackle this problem. Project Zero is our contribution, to start the ball rolling.”

Similar to the Linux Foundation's Core Infrastructure Initiative, in which resources and funding are applied to selected open-source projects to improve their security, Project Zero differs with a significantly wider focus. “We're not placing any particular bounds on this project and will work to improve the security of any software depended upon by large numbers of people, paying careful attention to the techniques, targets and motivations of attackers,” Evans explained.

The programme will see a “new, well-staffed team” employed by Google spend the entirety of their working day on investigating ways to improve the security of internet-facing software.

This, Evans explained, includes locating and reporting vulnerabilities, researching mitigations, explorations, doing formal program analysis and “anything else our researchers decide is a worthwhile investment.”

The results of Project Zero will initially be shared only with the software vendor or open source development team, in an example of responsible disclosure. When a patch has been issued or accepted for a particular vulnerability, the report will be made public along with statistics such as vendor-time-to-fix performance and copies of historical exploitation information and crash traces. “We also commit to sending bug reports to vendors in as close to real-time as possible,” added Evans, “and to working with them to get fixes to users in reasonable time.”

Google has indicated that it is still actively hiring team members, with one of the first confirmed Project Zero staffers named as George Hotz. Better known by the handle 'geohot', Hotz made a name for himself with the development of 'jailbreak' exploits for the Apple iPhone and the Sony PlayStation 3.

“We believe that most security researchers do what they do because they love what they do. What we offer that we think is new is a place to do what you love—but in the open and without distraction,” Evans concluded. “We'll also be looking at ways to involve the wider community, such as extensions of our popular reward initiatives and bug-glob posts.”

“You should be able to use the web without fear.” Evans asserted.

## VolksPC merges Debian with Android

ARM focus for MicroXwin team's new distro

The team behind MicroXwin has announced a new distribution which aims to make Debian a more tempting proposition for ARM-based devices by adding in support for native execution of Android applications.

The team's distribution, based on Debian Wheezy compiled for ARM with hard-float support, will come with several Debian packages pre-installed including the kernel-based MicroXwin implementation and an XFCE desktop. Its biggest feature over stock Debian is the ability to run Android applications direct from the Google Play market.

The team has announced plans to produce hardware under the VolksPC brand with the distribution pre-loaded. A desktop system based on a low-cost Rockchip RK3066 dual-core 1.4GHz ARM processor and 1GB of RAM has been confirmed, with plans for a future tablet with keyboard dock should the initial device prove successful.

The VolksPC hardware has not yet been given a price, and the VolksPC software is not yet available for public download. No time-frame has been offered for either by the developers.

# Mayhem malware spotted in the wild

> ‘Restricted privileges offer little protection’

A new malware package, dubbed Mayhem, has been spotted in the wild on Linux web servers and other “nix-based systems, providing its creators with remote control in a similar fashion to Windows-based botnets.”

According to an analysis of the malware by Yandex employees Andrew Kovalev, Konstantin Orashkevich and Evgeny Sidorov published in Virus Bulletin, Mayhem is capable of running on a system even under restricted privileges. It is dropped via a malicious PHP script and has been found on systems worldwide, with the biggest number of infections found in the USA, Russia, Germany and Canada and smaller pockets of infection in the UK, Europe and Australia.

Its primary use appears to be to create a botnet of infected systems, which are then sent the command from a command and control server to begin attempts to brute-force administrative logins to public-facing WordPress installations. The nature of the malware would allow it to be used for other purposes; however, “We can confidently say that botnets made up of “nix web servers are becoming more and more popular as a modern trend in malware,” the team claimed. “Web servers have good uptime, network callbacks and are more powerful than ordinary personal computers. In the “nix world, autoupdate technologies aren’t widely used, especially in comparison with desktops and smartphones. [Additionally,] the use of anti-virus technologies isn’t widespread. A lot of vendors don’t offer any proactive defence or process memory-checking modules.”

With a surprisingly high infection rate, web admins are advised to check their systems for the presence of the Mayhem malware.

# Zero-day vulnerabilities found in Tails

Tails, the privacy-enhancing Linux distribution favoured by whistleblower Edward Snowden, has been found to have several major security vulnerabilities, according to a report by cash-for-bugs firm Exodus Intelligence.

Details of the precise vulnerabilities have been provided by the company to the Tails project, which has stated that it will be addressing them as soon as possible. In the meantime, Exodus Intelligence has indicated that it will be selling vulnerability details to its customers – likely to include, among others, the US National Security Agency. The vulnerabilities have been fixed upstream in the Invisible Internet Project (I2P), but at the time of writing the Tails team had not announced a timescale for a fixed release.
