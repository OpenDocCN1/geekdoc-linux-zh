# ## Piping Netflix

I have been using the Netflix Desktop solution to watch Netflix on my computer for a while now, however as I'm using Firefox as my browser anyway and I've just done a big operating system update on it, I'd rather it just work straight from there. I am having trouble getting Pipelight to work, though. The test pages worked fine, Truetype installed and all, but when I get to Netflix, the video just does not play. I tried:

```
`firefox &> pipelight.log`
```

...and it came up with an error telling me that my 32-bit OpenGL drivers for my Nvidia card haven't been installed properly. It works fine for everything else but frustratingly just not Pipelight. I'm using an Nvidia 660 GTX Ti on Fedora 20 64-bit, is there anything I can do?

*Hans*

*Nvidia cards are always a bit dodgy when it comes to drivers and this kind of support. What you'll need to do is install 32-bit MESA from the repos and look into recompiling your standard drivers with 32-bit support or looking for restricted drivers and have a go installing them.*

*It's a bit of a shame that Netflix still blocks Linux from the site. We've heard from developers in the past it's because they're worried that the more tech-savvy Linux users would be able to "steal their bytes". Hopefully they learn to properly trust us soon because these solutions don't seem to be giving them any cause for concern.*
