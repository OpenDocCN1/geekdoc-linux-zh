# 01 Setting up your Dropbox app

In order to upload files and folders to your Dropbox, we need to create an app with read and write permissions. If you browse to www.dropbox.com/developers/apps you'll be presented with a list of apps that have access to your Dropbox account in one form or another.

Hit the 'Create app' button in the top right corner of the window and you'll be presented with two options: to create an app for 'Drop-ins' or to create an app that uses the Dropbox API. We're going to be using the Core data API, so select the second option, then select the 'Files and Datasources' option that appears. The final question before you get set up is 'Can your app be limited to it's own folder?' While it's not necessary to do so, it's always handy to keep a degree of separation between an app and your precious data when you're handling things programmatically. Long story short, in this instance, select yes. Enter an app name, and you're good to go. You'll now be presented with the settings view for this app. Jot down your app key and secret, as you'll be needing things shortly. Before we start, head to the root folder for your app and create two new folders – one name 'Files' and another named 'Folders'. These will be useful later on.

Now, when we authenticate our app in the future, our token will be stored. Let's write a check for its existence. Create a new function called run():

Inside run, we're going to check if a file called token.txt exists. If it does, then we'll read the contents, try to create a Dropbox session with it, and if that fails (expired/maformed token) for any reason, request a new one. We can do that with the following:

```
```python
def run():
    haveTokenFile = os.path.isfile('token.txt')
    if haveTokenFile is True:
        f = open('token.txt', 'r')
