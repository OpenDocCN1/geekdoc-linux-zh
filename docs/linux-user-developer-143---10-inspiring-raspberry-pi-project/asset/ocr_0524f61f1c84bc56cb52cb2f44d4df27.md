# # Firefox OS app development
Create, edit and test web apps in the Firefox browser

app zip files, and packaged apps from a directory of source code. Let's assume you're working on a packaged app. You have a directory layout like this:

```
www/
    index.html
    manifest.webapp
css/
    style.css
i/
    icon-256.png
    icon-128.png
    icon-64.png
js/
    main.js
```

You can build a testable Android app with the following:

```
mozilla-apk-cli /www/my_test_app.apk
```

This will produce my_test_app.apk which can be side-loaded to your phone in one of two ways: put it on the web and download/install from a browser on your Android device, or instead use adb to install the app:

```
adb install my_test_app.apk
```

# The Future: Developing for the Whole Web

At the heart of the WebIDE is the Firefox Remote Debugging Protocol. The Firefox Developer Tools work on remote devices running over USB. Right now this protocol is useful for Firefox Desktop, Firefox Android, and Firefox OS. But it won't stop there. In the future, a protocol adapter that will allow developers to use the Firefox Remote Debugging Protocol – including the Developer Tools and WebIDE – will talk to all mobile browsers, regardless of rendering engine or runtime.

This web-everywhere project isn't yet ready for testing, but if you're excited to get involved or see how it is being implemented, it currently lives at github.com/camp/fxd-adapters.

If you're building a tool and want to start playing with the protocol, then you can start now, developing against Firefox Desktop, Firefox Android, and Firefox OS. For information about the Remote Debugging Protocol, take a look at the documentation at mozilla/teardown. If you want to see the WebIDE in action, check out this screencast: at bit.ly/1nFcn3U.

# Synthesised APKs

The APK Factory Service takes your code and sends it to a reviewer instance of the service (as opposed to the production release environments).

This service synthesises a native Android app, builds it with the Android SDK and finally signs it with a development cert. As mentioned, this synthesised APK is debuggable and should not be distributed.

The nice thing about the service is that you do not have to have Java, erd, the Android SDK, and other Android development tools installed on your local computer. You can focus on the web and test on whatever device you have handy.
