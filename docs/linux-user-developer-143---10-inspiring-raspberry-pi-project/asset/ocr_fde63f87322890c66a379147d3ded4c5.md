# ## X and mouse

I have a bluetooth mouse, and when I use it, I disable the touchpad on my laptop. If my mouse does not connect for some reason (it's happened before), I have no easy way to turn the touchpad back on.

I can enable the touchpad using a terminal in X with synclient TouchpadOff=0, but I can't get to a terminal in X with no mouse! If I switch to another terminal (Ctrl+Alt+F1), synclient fails with the error message "Failed to connect to X Server". I have tried DISPLAY=":0" with no effect. How can I get this to work? Is there a way to run a command on a terminal other than the one that I am logged into?

Robin Allan

**Your synclient needs to use environment variables set by X, which you can grab using the following while logged in as a normal user:**

```
$ export -p > envars
```

**Log in as root in another terminal and copy the envars file into the home folder. Open it up in nano and remove all the variables but \_XAUTHORITY and DISPLAY, followed by sourcing the file from root. You could try writing a little script to do it automatically for you that looks something like this:**

```
#!/bin/bash
```

```
declare -x DISPLAY="[variable]"
declare -x XAUTHORITY="[variable]"

if [ $1 is "on" ]
then
    synclient TouchpadOff=0
fi

if [ $1 is "off" ]
then
    synclient TouchpadOff=1
fi
```

# ## FAQ: Steam on Linux

**Q: What distros is Steam officially available for?**

A: Right now it's just Ubuntu that officially supports Steam, although that means it leaks into any distro based on Ubuntu.

**Q: Can I get Steam for any other distros?**

A: Absolutely. At the very least, Valve distributes a deb file that will work on any Debian-based distro, and a few other distros have their own build of Steam in their repos.

**Q: What's the state of SteamOS?**

A: It's still being updated and still published by Valve. The in-home streaming has been added recently and some of the Debian elements are slowly being removed where necessary. It can still be a little tricky to install, though.
