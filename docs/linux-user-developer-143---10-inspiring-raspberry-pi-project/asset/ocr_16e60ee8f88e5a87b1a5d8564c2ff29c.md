We're still a couple of functions short of a backup solution. You may have noticed in our createClient function we make a call to load_list_of_watched_files_and_folders(). It's function is just a descriptive way to start reading our JSON file. (**Fig. 07**).

The now_my_watch_begins function is slightly more interesting, depending on whether or not we determined a folder or file will be stored in our JSON file. now_my_watch_begins will delegate each item to an appropriate function to allow for its checking and upload. After each file and folder has been checked and uploaded/updated appropriately, it will rewrite all of the items processed back to our JSON file, reset any variables that will have been changed in the script's execution and then wait for a set amount of time (five minutes by default, but it can be as frequent as you like) before reloading and re-checking our JSON file and all of the files/folders contained within.
