Prototype programs for any language

**15 Break it down**

Programming, in its essence, is breaking down complex tasks into simple parts. Implementing these parts varies with a language's syntax and capabilities, but the initial analysis can be put into comments.

FizzBuzz is a simple program – counting out integers, but replacing every number in the 3 times table with “Fizz”, and every multiple of 5 with “Buzz” – based on a children's game. Nevertheless, the majority of CS graduates applying for coding jobs couldn't implement it even in pseudocode.

LUGO readers should have little problem here – we're confident – so let's get scripting.

![](bbox=[0.07, 0.37, 0.36, 0.53])

**16 Testing, testing**

The script has to loop through 100 consecutive numbers. It's best to start with the loop – when we know that's okay, we can move the done and exit to the end, and start on the number replacement.

![](bbox=[0.07, 0.63, 0.36, 0.81])

**17 FizzBuzz!**

Divisible by both 3 and 5 is the first to test for – otherwise testing for just one will replace the number with whichever we test for first. `&&` is the logical operator and, which is used to check both conditions are true.

![](bbox=[0.38, 0.18, 0.63, 0.36])

**18 Double parentheses**

Fizz is simply checking for divisibility by 3. Note the double parentheses around the arithmetic expression – allowing C-style arithmetic operations, such as `(n++)`.

**19 Remainder 0**

Add an `n%5` for buzz, and don't forget to test the script at each change. The modulo operator – `%` – common to many languages, shows the remainder result of an integer division.

**20 Just a number**

If none of the fizz/buzz cases have been met, the remaining option is just to print the number. Now we end the conditional with `fi`, and the loop with `done`. It works – but one result per line is not good formatting...

![](bbox=[0.38, 0.61, 0.63, 0.8])

**21 Pretty printing**

Replacing `echo` with `printf` – again, familiar from C programming – means we can incorporate tabs and newlines into the script, useful for outputting in tabular form. We put newlines for both Buzz and FizzBuzz.

![](bbox=[0.66, 0.18, 0.92, 0.34])

**22 Tabled**

Such a mixture of program logic and formatting may make the purists shudder – but on a small program like this we're interested in results. And re-factoring to a larger prototype can wait until you've transferred it to another language.
