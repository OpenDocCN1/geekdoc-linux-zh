# # On the DVD

Welcome to the Linux User & Developer DVD

# ## Editor’s picks

**Hugin** The possibilities for image editing on Linux can often feel quite limited, so Hugin is refreshing for being not just another GIMP clone but a unique tool in itself. Use it to stitch together a mosaic of overlapping photos into a single immersive panorama. It’s good fun.

**Geany** This is essentially a text editor using the GTK2 toolkit, offering the features of a basic integrated development environment. Aside from being lightweight and fast, it’s also designed to be independent from DEs such as KDE or Gnome, requiring just the GTK2 library.

**Tor** If you don’t want to hop onto Tails for some safe surfing then you can always set up Tor for youself. It seems to be making the news almost every week now, and Tor is popular for a reason – get ahead of the curve and protect your privacy now.

# ## Complete index

# ### Operating systems

**Tails 1.1** This updated version of Tails now includes some user-visible changes in addition to security and bug fixes, such as UEFI boot support and VirtualBox guest modules.

**CentOS7** With the recent release of RHEL 7, CentOS has gone up a version number as well. Among the improvements is the inclusion of systemD, Gnome3 and a default XFS file system.

**Ubuntu 14.04.1** The first of many more point updates to come, this release includes security updates and updated installation media, to reduce the amount of updates needed post-installation.

**GParted Live** This great tool provides you with a graphical environment for any partitioning tasks you need to carry out. It contains all the tools you’d find in the GParted application.
