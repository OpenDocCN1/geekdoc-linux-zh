# ## Firefox OS app development

Create, edit and test web apps in the Firefox browser

FEATURE

![](bbox=[0.08, 0.19, 0.81, 0.52])

With Firefox OS, an operating system completely based on open-web standards and on the Linux kernel, Mozilla wants to prove that the web is the platform for development, regardless of tools, languages or devices. As part of this initiative, it's recently introduced a powerful new design to the OS, and in-browser performance debugging features. The real unique new feature is a full-fledged development IDE in Firefox Nightly that will make it easier to create and build web apps without any overhead.

With so many different tools and templates available when creating and designing your app, it can be hard to know where to start. In this article, we'll be looking at the in-built Firefox features, where to find the right tools to help you use them and giving you handy hints and tips on how to improve and progress your development.

# ### Getting started

To get started on the WebIDE, This can be found in your developer tools bar menu. Once open, select 'new app' from the menu bar and you will find a number of example starter templates to choose from. Save the template to your desktop. Within the template you can select the index.html file to view the blueprint app and source files that are already set up for you.

> > The community is working hard to bring an even greater choice of templates for different use cases

Advanced developers can work with Mozilla to build these starter templates. So while a good few are available already, the community is working hard to bring an even greater choice of templates for different use cases. If you would like to become part of the community and contribute templates then visit github.com/mozilla/mortar.
