# What is the Raspberry Pi B+?

A new version of the Raspberry Pi is out, but what exactly is it and what does it mean by B+?

There's a new version of the Raspberry Pi out, then? That's absolutely correct – the Raspberry Pi Model B+, the latest version of the Raspberry Pi.

I have some questions about this in relation to the name. This is the first one, model B? Was there a model A? Absolutely, and there still is a model A as well. It's the cheaper version of the Raspberry Pi and it's got a lot less features than what the normal model B has/had.

So what features is the model A missing, then? The model A does not include an ethernet port; it only has one USB port and it has a bit less RAM than the model B doe – half as much, in fact, at 256 Mb of memory.

If it's the 'inferior' version then why is it still being sold? It was actually released after the original model B and it's a bit cheaper than the model B as well. It's mainly for people that only really need the Pi for its computing capabilities in projects and other maker builds. It will also remain available now the model B+ is out.

I see. Back to the B+ then: so it's the second version of the model B? No, technically it's the third version of the model B. Shortly after its initial release the model B got a minor upgrade to double its RAM to 512 Mb, as it initially had the same amount as the model A.
