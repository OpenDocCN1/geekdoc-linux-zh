# Can you volunteer for Code Club?

Code Club is a nationwide network of volunteer-led after school coding clubs for children aged 9-11.

We need people who know how to program computers to volunteer to run a club at their local primary school, library or community centre for an hour a week.

We create the projects for our volunteers to teach, the projects we make teach children how to program by showing them how to make computer games, animations and websites.

Get involved, let’s teach the next generation to code!

# Welcome

to issue 143 of Linux User & Developer

Your team of Linux experts...

![](img/daaca9116bc2b1db669c224de81abc7c_2_0.png)

**Rob Zwetsloot** studied aerospace engineering, using Python to model complex simulations. After striking an undisclosed deal with the sentient Makeblock tank, Rob’s video player was returned to him and he began working on his next Pi-powered projects (page 50). Arduino-powered Robot-chan was not amused.

![](img/daaca9116bc2b1db669c224de81abc7c_2_1.png)

**Richard Smedley** started using computers long before WSIWYWG and still maintains that the command line, and Emacs, is the most productive working environment. This month Richard continues his shell scripting series, this time looking at prototyping programs through the example of a simple FizzBuzz game (page 26).

![](img/daaca9116bc2b1db669c224de81abc7c_2_2.png)

**Nitish Tiwari** is a software developer by profession and an open source enthusiast by heart. As well as writing for leading open source magazines, he helps firms set up and use open source software for their business needs. This issue he explains OWASP practices (page 30) and the new ownCloud 7 (page 34).

![](img/daaca9116bc2b1db669c224de81abc7c_2_3.png)

**Mihaliss Tsoukalos** is a UNIX system administrator with expertise in programming, databases and maths. He has been using Linux since 1993. Mihaliss shows us how to perform scientific computing and mathematical operations this month, with the help of NumPy, SciPy and Matplotlib (page 38).

![](img/daaca9116bc2b1db669c224de81abc7c_2_4.png)

**Jon Masters** is a Linux kernel hacker who has been working on Linux for some 19 years, since he first attended university at the age of 13. Jon lives in Cambridge, Massachusetts, and works for a large enterprise Linux vendor. You can find his brilliant Kernel Column on pages 12-13 this month.

![](img/daaca9116bc2b1db669c224de81abc7c_2_5.png)

**Gareth Halfacree** is our resident news reporter and brings us the latest developments from all over the open source world, starting on page 6. Over on page 80, Gareth reviews the new Banana Pi and asks whether it’s a worthy successor to the Raspberry Pi.

Welcome to the latest edition of *Linux User & Developer*, the UK and America’s favourite Linux and open source magazine.

![](img/daaca9116bc2b1db669c224de81abc7c_2_6.png)

With the release of the new Model B+ back in July (see pages 70 and 82 for more on this), it seems that all eyes have turned to the Raspberry Pi again. We’re seeing more and more Pi clones emerging too, and some of them are actually pretty good, like the Banana Pi we review over on page 80. So, naturally, we felt that it’s about time for another swathe of Raspberry Pi projects for you. This time we based them on ideas that you can combine into more complex projects if you fancy it, like turning a private cloud into a private cloud-based media streamer. Grab your Pi and turn to page 50 to get started.

Also this month, Richard Hillesley goes right back to the early days of Linux (when it was just an announcement on a message board) to illuminate its storied history and show us the origin of the inquisitive spirit that’s currently embodied by the Pi community – it’s a fascinating read (page 18).

We have another round of great tutorials for you, as well. This month we take a look at scientific computing in Python, creating Android and Firefox OS apps, automating Dropbox, upgrading a private cloud setup and more. Enjoy the issue.

Gavin Thomas, Deputy Editor
