# Design advanced user interfaces for Android

Create complex GUIs with minimal effort and learn your way around the system

The previous instalment of our Android tutorial concluded with a small RSS reader, which displayed the results of the downloading process in a text view. This is not particularly elegant: using a list and a dedicated form would lead to a much nicer app.

Both Palm OS and Windows Mobile provided developers with an easy-to-use list box. Developers provided the widget with a batch of strings, which were then displayed. Android’s list architecture is more academic, forcing applications to be designed around a relatively complex set of classes which act as a broker between the stored data and the widgets used for its display.

Tablets provide a new source of grief. Their larger screens can not be utilised efficiently by “normal” programs, instead demanding a complete redesign of your interface. Fragments can be used to simplify this process by dividing the user interface into smaller components. These can then be arranged in order to form different layouts that are ideally suited to the screen at hand.

```
<xml version="1.0" encoding="utf-8">
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android" android:layout_width="match_parent" android:layout_height="wrap_content" android:orientation="horizontal">

<TextView android:id="@+id/textLarge" android:textSize="38sp" android:textStyle="bold" android:textColor="#FF0000" android:layout_width="40dp" android:layout_height="wrap_content"/>

<TextView android:id="@+id/textSmall" android:textSize="16sp" android:textColor="#000000" android:layout_width="fill_parent" android:layout_height="wrap_content"/>

</LinearLayout>
```
