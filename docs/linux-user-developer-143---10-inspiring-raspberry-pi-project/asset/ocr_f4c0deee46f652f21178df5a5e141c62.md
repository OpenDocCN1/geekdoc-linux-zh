# 04 Passing arguments to our script

We don’t want to be constantly uploading files to Dropbox when they haven’t changed, so now we’ll put together some code that will keep track of the files and folders on our system that we’re syncing to Dropbox. In our run() function we’re going to add some code that will let us change the script’s behaviour based on arguments – or ‘modes’, if you will – we pass through to it. The first thing to add is a check for how many arguments have been passed through to our script. If it’s less than two, then only the filename of the script has been passed. That doesn’t help us greatly: let’s add the requirement that we have to pass the word ‘run’ to execute the script we have so far. (Fig. 03) And add an edit to the statement we just wrote. (Fig. 04)

Now we have a way of passing items through to our script to store – but why have we made the distinction between files and folders? In order to upload a folder, we need to pass all of the files in said folder to Dropbox with a defined path. If we try to upload to a folder that isn’t already in our Dropbox account, it will receive an error. By tracking folders and files separately, we’ll be able to check for their existence and state before we try and upload anything.
