| Red Hat | rpm -U package_file |

Example: Updating an existing installation of emacs to the version contained in the package file emacs-22.1-7.fc7-1386.rpm on a Red Hat system:

```
rpm -U emacs-22.1-7.fc7-1386.rpm
```

> Note: dpkg does not have a specific option for upgrading a package versus installing one as rpm does.
