The first call to find_first_of() locates the first of the characters in the vowels string. To continue the search at the next character, the last statement in the loop searches at the former position plus one. Compiling and running this code displays the index and character values:

```
a[ 0] == 'a'
a[ 4] == 'e'
a[ 8] == 'i'
a[14] == 'o'
a[20] == 'u'
```
