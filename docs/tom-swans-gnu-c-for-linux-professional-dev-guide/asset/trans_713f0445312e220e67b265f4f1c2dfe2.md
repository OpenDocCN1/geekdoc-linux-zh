
关闭输入文件之后，你尝试读取文件的内容，方法是构造一个输入流对象并使用如下语句：

```
ifstream ifs("test.dat", ios::in | ios::binary);
if (ifs) {
    double d;
    ifs >> d;  // ???
    cout << "d == " << d << endl;
    ifs >> d;  // ???
    cout << "d * d == " << d << endl;
}
```

程序看起来运行得很顺利，但报告的结果明显是错误的。程序显示的内容如下：

```
$ ./a.out
d == 3.1416
d * d == 0.86959
```

哪里出了问题？第一个值看起来没问题，但π的平方几乎不可能是0.86959。使用Linux的hexdump工具检查文件数据，为解开这个神秘的bug提供了线索。如果你已经编译并运行了wrong.cpp程序，请输入以下命令来检查test.dat的内容：

```
$ hexdump -bc test.dat
0000000 063 035 056 061 064 061 065 071 071 056 071 070 066 071 065 071
0000020 3   . 1 4 1 5 9 9 . 8 6 9 5 9
```

文件的内容表明，尽管文件是以二进制I/O方式打开的，但数据却以文本形式存储。这是因为C++ I/O流的设计目标是将二进制值转换为文本，并且它们不会根据文件的打开方式以任何方式改变这一行为。

当程序读取文件时，标准输入语句执行相反的任务：在这种情况下，读取的第一个值为3.141599，第二个值为0.86959。由于这两个值是一个接一个写入的，文件中没有任何迹象表明第二个值实际上应该是9.86959，于是输入流错误地“假定”小数点分隔了两个值。

这是一个有趣的问题，不过幸运的是，正如下一节所解释的，解决起来并不太难。

## 正确的解决方案

要读写二进制数据，需要从ifstream和ofstream派生新类。由于C++中的char与一个字节相同，因此可以使用一个char值数组作为缓冲区，来存放以二进制形式表示任意值的一系列字节。要以二进制形式写入一个值，程序会将该值的字节复制到输出缓冲区，然后将该缓冲区作为一系列字节写入磁盘。类似地，要读取二进制值，程序会把字节读入一个char数组，然后将这些字节复制到一个适当类型的变量中。

实际上，如果我们只是简单地把二进制值看作一组字节——这当然也描述了所有数据对象的本质——那么缓冲区数组并不是必需的。清单20.5（wdouble.cpp）演示了将一些double值以二进制形式写入磁盘文件的基本方法。

## 注意

在使用本节和下一节中的二进制文件方法时，请注意其他C++编译器可能使用不同的格式来表示二进制数据。不要指望能够编写一个二进制double值文件，并在另一个操作系统上正确读取它。

## 清单20.5 WDOUBLE.CPP

```
#include <iostream.h>
#include <fstream.h>
#include <stdlib.h>

#define FILENAME "test.dat"

class bofstream: public ofstream {
public:
bofstream(const char *fn)
: ofstream(fn, ios::out , ios::binary) { }
void writeBytes(const void *, int);
bofstream & operator<< (double);
};

bofstream & bofstream::operator<< (double d)
{
writeBytes(&d, sizeof(d));
return *this;
}

int main()
{
bofstream bofs(FILENAME);
if (!bofs) {
cerr << "Error: unable to write to " << FILENAME << endl;
exit(1);
}
cout << "Writing to " << FILENAME << endl;
double d = 3.14159;
bofs << d;
bofs << d * d;
bofs << 9.999999;
d = 4.7E-8;
bofs << d;
return 0;
}

void bofstream::writeBytes(const void *p, int len)
{
if (!p) return;
if (len <= 0) return;
write((char *)p, len);
}
```

使用以下命令编译并运行wdouble.cpp程序。除了一条确认消息，程序不会显示其他输出：

```
$ g++ -o wdouble wdouble.cpp
$ ./wdouble
Writing to test.dat
```

为了以二进制形式写入double值，程序从ofstream派生了一个新类bofstream（binary-output-file-stream，二进制输出文件流）。这个新类提供了三个成员函数。

第一个是构造函数，声明并内联实现如下：

```
bofstream(const char *fn):
    ofstream(fn, ios::out | ios::binary) { }
```

构造函数只是以文件名以及所示的两个open_mode常量调用其祖先ofstream类的构造函数。要使用该构造函数，程序只需构造一个bofstream类的对象：

```
bofstream bofs(FILENAME);
```

成员函数writeBytes()向已打开的文件写入若干字节。该函数在bofstream中声明如下：

```
void writeBytes(const void *, int);
```

函数writeBytes()不返回任何值。它的第一个参数是一个常量void指针，指向要写入磁盘的对象。第二个int参数等于该对象的大小（以字节为单位）。仔细检查该函数的实现：

```
if (!p) return;
if (len <= 0) return;
write((char *)p, len);
```

如果指针为NULL，该函数只是返回，不采取任何进一步的操作。类似地，如果指定的长度小于或等于零，也不会发生任何事情。第三条语句调用继承来的write()函数，将指针p所保存地址开始的len字节数据作为一系列char值——也就是作为字节流——写入文件。

为了支持写入特定类型的数据，bofstream类声明了第三个成员函数：

```
bofstream & operator<< (double);
```

这重载了输出流运算符<<，用于向bofstream类的对象写入double类型的值。为了完成这项工作，重载的运算符函数执行以下语句：

```
writeBytes(&d, sizeof(d));
return *this;
```

参数d是要写入磁盘的double对象。首先，writeBytes()将位于d中地址处的sizeof(d)字节写入文件。最后，该函数返回其自身对象，这样如下所示的级联输出语句就会写入同一个目标（假定所有变量都是double类型）：

```
bofs << d1 << d2 << d3;
```
