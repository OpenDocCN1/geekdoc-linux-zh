# SUMMARY

The C++ standard template library (STL) is a comprehensive collection of data structures and algorithms. Two features characterize the STL (Standard Template Library): the separation of data structures from algorithms and its non-object-oriented nature. Access to objects is provided by iterators, which in use resemble pointers. Containers are data structures such as lists and vectors and are provided as class templates. Algorithms are function templates that operate on data in containers. Because the STL is template-based, its components work with just about any data type and structure.
