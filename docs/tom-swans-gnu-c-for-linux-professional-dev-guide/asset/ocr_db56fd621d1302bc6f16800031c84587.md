# SUMMARY

This book's CD-ROM provides the full Linux-Mandrake 6.0 operating system, including GNU C++, plus all utilities and programming tools. Also on the CD-ROM are this book's source code files and the V C++ class library for programming X windowed client applications for Linux and Microsoft Windows. This chapter gives hardware and software requirements for running Linux and GNU C++. It also lists overviews of the book's six parts and 30 chapters. The next two chapters provide additional tips and instructions for installing and configuring Linux and GNU C++.
