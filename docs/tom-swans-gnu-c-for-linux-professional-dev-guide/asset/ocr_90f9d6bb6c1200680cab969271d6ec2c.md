Compare the output from `rdouble.cpp` with the statements in `dwouble.cpp` that write binary values to disk. They are consistent with the expected results. This indicates that, instead of writing and reading data in text form, the derived `bifstream` and `bofstream` classes now handle data in native, binary format. The new `bifstream` (binary-input-file-stream) class is derived from `ifstream`. Its constructor is declared and implemented inline as follows:

```
```cpp
bifstream(const char *fn):
  ifstream(fn, ios::in | ios::binary) { }
```
```

As in the `bofstream` constructor, this code merely calls its ancestor class constructor, passing a filename string and the two open constants that open the file for binary input. The `bifstream` class also declares a function, `readBytes()`, as follows:

```
```cpp
void readBytes(void *, int);
```
```

This is the counterpart to the `bofstream::writeBytes()` function, and it declares the same parameters—a pointer to the data object to write and its size in bytes. The `readBytes()` function executes three statements to read a value in binary:

```
```cpp
if (!p) return;
if (len <= 0) return;
read((char *)p, len);
```
```

If the pointer is NULL, or the requested size is less than or equal to zero, the function does nothing. Otherwise, it calls the inherited `read()` function to input `len` bytes from the open file into the address at pointer `p`.

Finally, the `bifstream` class overloads the C++ input stream operator `>>` with the following declaration:

```
```cpp
bifstream & operator>> (double &);
```
```

Because of this declaration, any statements that write a double variable to a `bifstream` object call the overloaded function. Its implementation calls the `readBytes()` function to perform the actual input duty:

```
```cpp
readBytes(&d, sizeof(d));
return *this;
```
