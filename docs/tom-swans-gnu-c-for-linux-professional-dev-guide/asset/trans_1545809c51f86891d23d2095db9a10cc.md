
创建t4，并将t3的值复制到新变量中。第五个声明将t5声明为t4的副本。最后两个声明在功能上是相同的。

你可以用几乎相同的语句以这些相同的方式构造类对象。清单12.3（construct.cpp）演示了构造一个稍作修改的TDate类类对象的五种方式。

## 清单12.3 CONSTRUCT.CPP

```
#include <iostream.h>

// A class that encapsulates data and functions
class TDate {
private:
    int dt_month;
    int dt_day;
    int dt_year;
public:
    TDate();
    TDate(int month, int day, int year);
    void Display();
};

int main()
{
    TDate t1;                 // Requires default constructor
    TDate t2 = TDate(12, 31, 1999);  // Impractical, but allowed
    TDate t3(1, 1, 2000);     // Uses parameterized constructor
    TDate t4(t3);             // Makes t4 a copy of t3
    TDate t5 = t4;            // Copies t4 into t5

    t1.Display(); // Call member function for each object
    t2.Display();
    t3.Display();
    t4.Display();
    t5.Display();

    return 0;
}

// The TDate class default constructor
TDate::TDate()
{
    dt_month = 0;   // Initialize private data members to zero
    dt_day = 0;
    dt_year = 0;
}

// The TDate class parameterized constructor
TDate::TDate(int month, int day, int year)
{
    dt_month = month; // Assign values to private data members
    dt_day = day;
    dt_year = year;
}
```

```
// The TDate class Display member function
void TDate::Display()
{
 cout << dt_month << "/" << dt_day << "/" << dt_year << endl;
}
```

该程序构造了五个TDate对象t1到t5，然后为每个对象调用Display()成员函数。下面的语句构造了一个名为t1的TDate类对象：

```
TDate t1;
```

这是构造类对象最常见的方式之一，其方法完全等同于声明任何其他类型的未初始化对象，例如double变量：

```
double f1;
```

但是，当类型是类时，它必须有一个默认构造函数来处理没有参数值声明的对象的创建。（本章后面“默认构造函数”一节将对此进行更多讨论。）

示例程序演示了构造对象的第二种但不切实际的方式。虽然你不太可能使用这种方法，但它演示了临时对象这一重要概念。这条语句：

```
TDate t2 = TDate(12, 31, 1999); // ???
```

大致等同于常见的传统语句：

```
double f2 = 3.14159;
```

这是创建和初始化double等简单类型对象的常见方式，但在使用类时，前面的TDate对象构造会使程序做比必要更多的工作。这是因为赋值运算符右侧的表达式创建了一个临时TDate对象，然后将其复制到一个新的TDate对象t2中。临时对象只在需要时存在，并且在其值被复制到t2后自动销毁。正如我在第13章“创建和销毁对象”中所解释的，临时对象很麻烦，并且可能导致错误。通常最好尽可能避免创建临时对象。

（它们也可以是相关类的对象，正如第14章“投资继承”所解释的那样。）下面的语句使用t3值的副本创建了一个名为t4的TDate对象：

TDate t4( t3 );

这会创建一个新对象t4，并将t3的值复制到其中。该语句等同于下面的原生类型声明，后者创建一个double变量t4并将f3的值赋给它：

double f4(f3);

构造类对象的第五种也是最后一种方法也是将一个对象复制到另一个对象：

TDate t5 = t4;

这会创建一个新的TDate对象t5，其值等于t4。这与前一种方法完全相同，但使用了更直观的赋值运算符。它完全等同于原生类型语句：

double f5 = f4;

## 默认构造函数

默认构造函数没有参数，并且与所有构造函数一样，其名称与其类相同。在示例construct.cpp程序中，TDate()默认构造函数单独实现如下（为了节省空间，我将各个语句移到了一行）：

```
TDate::TDate()
{
    dt_month = 0;  dt_day = 0;   dt_year = 0;
}
```

在程序的其他地方，用无参数创建对象会调用默认构造函数，该函数将对象中的每个数据成员赋值为零。默认的TDate()构造函数使诸如

TDate t1;

这样的声明成为可能。这会调用TDate()默认构造函数来初始化t1对象。然而，与原生类型变量不同，无论前面的声明是否在函数内部，这种情况都会发生——这是类对象声明与原生类型声明之间一个微妙但重要的区别。类对象总是由构造函数初始化。函数局部的原生类型变量在赋值之前是未初始化的。

## 复制构造函数

导致一个对象被复制到新创建对象的语句会调用一种特殊的构造函数，称为复制构造函数。当你使用如下语句创建对象时会发生这种情况（但请记住，第三个语句虽然允许，但不切实际，因为它会浪费地创建一个临时对象）：

```
TDate t4(t3);
TDate t5 = t4;
TDate t2 = TDate(12, 31, 1999);  // ???
```
