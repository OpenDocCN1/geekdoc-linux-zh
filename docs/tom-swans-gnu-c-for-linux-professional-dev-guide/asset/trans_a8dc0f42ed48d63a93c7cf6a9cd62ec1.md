

## 第24章
### 构建标准容器

标准模板库（STL）以类模板的形式提供了10种容器数据结构。由于它们是模板，容器可以自我调整以容纳任何类型的对象。如前章所述，通过使用迭代器访问容器中的对象。这使得容器本质上完全通用，你可以用它们存储简单值、结构、类对象或指向对象的指针。为了创建多层结构，容器甚至可以存储其他容器。使用STL容器模板进行数据存储的可能性是无限的。

本章探讨STL的容器模板，并展示如何创建和使用每种类型的示例。

## 标准容器简介

表24.1列出了STL的10种容器类模板，大致按复杂度排列。

| 表24.1 标准C++容器类模板 |
| 类模板 | 描述 |
| vector | 线性序列，类似于数组 |
| list | 双向链表 |
| deque | 双端队列 |
| set | 唯一键的关联数组 |
| multiset | 非唯一键的关联数组 |
| map | 唯一键和值的关联数组 |
| multimap | 非唯一键和值的关联数组 |
| stack | 后进先出（LIFO）数据结构 |
| queue | 先进先出（FIFO）数据结构 |
| priority_queue | 关键事件排序队列或向量 |

以下是一些有助于解释STL容器重要方面的规则、规定和定义：

- 容器可以存储任何类型的对象，包括int和double类型的基本值、字符串、结构、类对象和指针。但是，容器不能存储对象的引用。
- 类的拷贝构造函数处理对象到容器中的插入。通过重载赋值运算符=()函数并提供拷贝构造函数，你可以完全控制容器的插入操作——在管理将一个容器复制到另一个容器等操作的效果时尤其有价值。有关拷贝构造函数的更多信息，请参阅第12章“类介绍”和第21章“磨砺你的C++技能”。
- 容器根据需要自动分配和释放内存以存储对象。容器可以是全局或局部变量，也可以由new创建并由delete销毁。
- vector可以增长以容纳新数据，但不会自动缩小。其他容器如list、deque和set会根据需要增长和缩小，以高效使用内存。
- 当程序销毁容器时，它首先调用其拥有的任何对象的析构函数。这意味着你可以安全地销毁容器，而无需先移除其内容。
- 但是，当容器存储指向对象的指针时，上述规则不适用。在这种情况下，与C++数组一样，在销毁容器之前，你有责任销毁所指向的对象并释放任何已分配的内存。

> 提示
> 有关由指针指向的对象的安全销毁细节，请参阅第25章“应用标准算法”结尾附近的“容器中的指针”。

## 向量

vector就像一个智能数组，它维护大小信息，并且可以增长以容纳更多数据。vector通过C++下标运算符[]( )函数提供对数据的随机访问。vector模板类还提供了许多有用的成员函数，你可以调用这些函数来操作对象值。

因为vector提供立即、随机的数据访问，访问vector容器中的最后一个元素所花的时间与访问第一个元素相同。然而，由于vector中的元素物理上存储在一起，向vector中间插入元素会导致其他元素移动，这一操作所花的时间与移动对象的数量成正比。在vector末尾插入是高效的，除非插入需要vector扩容。发生这种情况时，vector会扩展，这意味着其数据可能必须被复制到另一个内存块。因此，vector扩容可能暂时需要超过已占用内存两倍以上的空间。如果你的程序进行了大量插入操作，你可能希望使用list或本章描述的其他内存效率更高的数据结构。
