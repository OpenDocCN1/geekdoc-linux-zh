

接下来的几步相对简单。此时你可以设置网络、配置系统时钟，并选择一些其他服务，如打印机支持。除非你有充分的理由不这样做，否则选择默认设置即可。

最后，你来到了最重要的一步——输入root密码。对于那些从未使用过Linux或UNIX的人来说，“root”是所谓超级用户的名称。以root身份登录时，你拥有对所有文件的写入、移动、更改和删除权限，包括系统文件。这种权力对操作系统的健康可能很危险——一个意外命令就能轻易摧毁整个文件系统。因此，请小心输入root密码，如果有其他人会使用此系统，请确保你选择的密码不易被猜到。你必须输入两次密码，以确保输入正确。

输入root密码后，系统会要求你创建一个“普通”用户。大多数时候你使用该用户，除非你需要成为超级用户来执行系统任务。输入一个简短的登录名（例如，我使用 tswan）、你的真实姓名（仅用于身份识别）以及一个密码，密码需要输入两次以进行验证。你还可以选择一个shell。这是运行控制台的软件，允许你运行其他程序，并接受文件系统命令。除非你熟悉UNIX或Linux的shell，否则请选择默认的Bash（Bourne Again Shell）。

> **注意：** 此时你必须输入一个普通用户，以便能够登录Linux。超级用户可以在以后添加其他用户——例如，如果你正在设置网络安装。

继续操作后，最终会询问你将“引导加载程序”安装在哪里。（如果你事先看到其他屏幕，对于任何不确定的选项选择默认设置。）引导加载程序，即Lilo（Linux系统加载器），是一个启动Linux或其他操作系统内核的小型实用程序。通常，Lilo的最佳安装位置是主引导记录（MBR）。对于独立系统和双启动系统都是如此。在前一种情况下，Lilo会在短暂停顿后自动启动Linux。在双启动设置中，Lilo让你有机会输入dos来启动Microsoft Windows（或其他操作系统），或者直接按Enter键启动Linux。不将Lilo安装到MBR的唯一原因是，如果你正在运行其他网络操作系统（如Windows NT），或者你使用其他实用程序来启动多个操作系统。

接下来的最后几步是配置X，如果你选择安装这个图形界面的话。此过程的第一步是安装XFree86——一组为Intel 80x86处理器编写的X服务器。之后，系统会要求你提供有关视频系统的信息。如果幸运的话，你的显示器会列在屏幕上显示的长数据库中。在这种情况下，只需选择你的显示器并继续。如果你的显示器未列出，你必须手动输入其同步频率。为此，请选择Custom并按照屏幕上的说明操作。

> **警告：** 如果你不知道显示器的同步频率，不要随意尝试数值。输入错误的频率可能会永久损坏显示器！

即使你不确定显示器的确切同步频率，也可以选择Custom。但在这种情况下，你应该选择一个相对安全的选项，如Standard VGA、640x480 @ 60 Hz或Super VGA、800x600 @ 56Hz，然后继续下一步。至少，这能让你开始使用Linux，直到你弄清楚正确的设置，之后你可以再进行指定。

选择Probe命令开始安装的自动检测阶段，该阶段会尝试识别你的视频硬件。除了配置显示器之外，还要进行此操作——自动检测会探测你的显卡或电路，以确定有多少可用内存以及支持哪些显示模式。大多数现代视频系统都能被正确识别，如果显示的测试屏幕看起来正常，你就可以继续。但是，如果自动检测失败，你必须输入视频系统的内存量、位平面数，并选择一个或多个分辨率。如果你不确定这些设置，请尝试看起来能正常工作的最大值。（为了获得最佳效果，X需要至少800×600的分辨率。在640×480的显示下，它仅能勉强工作。）

最后，系统会询问你是以图形模式还是控制台模式启动Linux。我更喜欢控制台模式，因为它缩短了启动时间，但这需要我先登录，然后输入*startx*来运行X。如果你想在启动时运行X，那也可以。

> **提示** 安装完成后，所执行步骤的完整日志会存储在文件 `/tmp/install.log` 中。

## 启动 Linux

你现在已经安装了Linux，准备开始使用你的新操作系统。取出所有软盘和光盘，然后重新启动。如果你将计算机设置为独立系统，Lilo会在5秒停顿后直接启动Linux。如果你有双启动系统，Lilo会短暂等待你选择操作系统。输入*dos*启动到Microsoft Windows，或者直接按Enter启动到Linux。如果Lilo超时，它会自动启动Linux内核（但请参阅本节末尾的提示以更改暂停时间）。

启动后的第一步是以root身份登录。即使你在独立工作站上运行Linux，也必须这样做。在安装过程中，你有机会创建登录名和密码。现在在登录提示符下输入这些信息。

有些用户在登录时会看到图形显示；其他用户在基于字符的终端上登录。无论哪种方式，登录后，你应该在终端窗口中看到某种提示符，可能是一个闪烁的美元符号（$）。如果没有，请查找某种打开终端窗口的按钮、命令或图标。这可能被称为控制台或终端。你将使用这种控制台模式来编译和运行本书中的示例程序，如下面的章节所述。
