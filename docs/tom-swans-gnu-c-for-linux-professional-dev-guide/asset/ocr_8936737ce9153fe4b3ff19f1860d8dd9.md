# SUMMARY

The standard string class provides a new way to create and use character strings in C++ programs. Although you may continue to use C-style null-terminated arrays of char as strings, the ANSI C++ string class described in this chapter is superior for many reasons. For example, string objects report errors by throwing exceptions, and because the string class is designed as a template, it can use characters of any type and size. This chapter introduced the string class and showed several examples of how to create string objects and call string-class member functions.
