V calls a toolbar a command pane. In it are one or more command objects such as buttons, spinners, and other visual components. Some of those objects need associated structures, as demonstrated for the spinner object that lets you select line widths using the mouse. To identify the component, the module defines a new constant, m_SpinWidth, with a value unique from others, including any menu items. The spinner object's data is stored as a small array of int values that specify the minimum value, maximum value, and step size for each mouse click.
