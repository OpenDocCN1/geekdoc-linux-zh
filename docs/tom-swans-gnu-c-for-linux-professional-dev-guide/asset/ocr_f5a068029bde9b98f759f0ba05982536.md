As with template functions, template classes are typically declared in header files. For example, Listing 17.3, db.h, demonstrates how to create a template class that can store a small database of records. The actual type of those records comes later when the program creates an object of the template class. At that time, C++ generates an actual class to handle the object's creation.

# LISTING 17.3 DB.H

```
#include <string>

class DBError {
private:
    string msg;
public:
    DBError(const string &msg_arg): msg(msg_arg) { }
    const string & what() const { return msg; }
};

template<class T>
class TDatabase {
private:
    T *rp;    // Records pointer
    int num;  // Number of records
public:
    TDatabase(int n): num(n)
    { rp = new T[num]; }
    ~TDatabase()
    { delete[] rp; }
    T &GetRecord(int recnum) throw (DBError);
};

template<class T>
T &TDatabase<T>::GetRecord(int recnum) throw (DBError)
{
    if (0 <= recnum && recnum < num)
        return rp[recnum];
    else
        throw DBError("Bad record number");
}
```

The header file declares two classes. DBError is a normal C++ class that the template class TDatabase uses to report errors. The template class TDatabase is declared using a single placeholder data type:

```
template<class T>
class TDatabase { ...
```

That creates the template, TDatabase, as a template class for an as-yet-unknown type of data, T. The template's private section declares a pointer rp to an object of the unknown type, and also an integer variable that counts how many records the database holds:

```
private:
    T *rp;    // Records pointer
    int num;  // Number of records
```
