

## 第10章

## 创建与调用函数

编写计算机程序就像建造桥梁。你不能在半空中浇筑混凝土；必须先在地面上打好地基，才能跨越水面。

函数之于C和C++，就像钢梁、缆索和石块之于桥梁建造者。借助函数，你可以将大型程序划分为易于管理的部分，并逐一构建。你还可以创建计算公式以及执行程序中所需其他操作的函数。

本章介绍函数，并展示C++中独有的某些“函数式”特性，例如内联函数和默认函数参数。本章最后将介绍一些适用于调试函数代码和数据的GNU调试器命令。

### 函数简介

如你所知，每个C和C++程序都至少有一个函数：main()。然而，大多数程序还有许多其他函数，每个函数都执行特定任务。函数最常见的任务之一是计算公式的结果。例如，考虑第7章“应用基本运算符”中的kilo.cpp程序如何使用以下语句计算给定英里数对应的公里数：

```
kilometers = miles * 1.609344;
```

通过将该公式转换为名为kilos()的函数，如清单10.1（fnkilo.cpp）所示，该函数不仅可以使用一次，还可以根据需要多次使用。在此示例中，程序多次调用kilos()，以显示英里和公里的对照表。

```cpp
#include <iostream.h>
#include <iomanip.h>      // Need setw() manipulator

// Function prototype
double kilos( double miles );

int main()
{
    cout << "Miles   Kilometers" << endl;
    cout << "=================" << endl;
    for (int miles = 10; miles <= 100; miles += 10) {
        cout << setw(5) << miles << " " << kilos( miles ) << endl;
    }
    return 0;
}

// Function implementation (convert miles to kilometers)
double kilos( double miles )
{
    double kilometers = miles * 1.609344;
    return kilometers;  // Function result
}
```

按通常方式编译并运行该程序。输入以下命令，程序将显示一个对照表（此处省略了几行以节省空间）：

```
$ g++ fnkilo.cpp
$ ./a.out
Miles   Kilometers
=================
   10 16.0934
   20 32.1869
...
  100 160.934
```

### 函数原型

清单10.1中的fnkilo.cpp程序展示了声明、实现和使用大多数类型函数的正确方法。在C和C++中，由于项目必须在使用前声明，因此创建函数的第一步是声明函数原型。以下是示例代码中kilos()函数的原型：

```
double kilos( double miles );
```

函数原型包含编译器使用该函数所需的三个重要元素：

1.  函数的返回类型——在本例中为double。这表示该函数返回一个指定类型的值。如果函数不返回值而仅执行操作，其返回类型可能为void。函数可以返回任何有效C或C++类型的对象。

2.  函数名称。这必须是一个唯一标识符，遵循第6章“创建数据对象”中列出的规则。尽量为函数选择具有明确意义的名称。名称kilos()暗示了该函数的功能。如果我将它命名为convert()，其具体用途就不那么清晰了。

3.  函数所需的任何参数作为输入数据。在本例中，括号中的double类型参数miles表示该函数需要一个要转换为公里的英里数。如果函数不需要输入数据，则用一对空括号声明其原型。

> 提示
>
> 函数原型始终以分号结尾。

程序可以根据需要声明任意多个函数原型。编译器只需函数的原型即可处理调用函数的语句。因此，通常将函数原型存储在头文件中，并在单独的模块中实现这些函数（参见本章后面的“函数与分离编译”一节中的示例）。不过，为了简单起见，本书的清单在单个源代码文件中声明并实现大多数函数。
