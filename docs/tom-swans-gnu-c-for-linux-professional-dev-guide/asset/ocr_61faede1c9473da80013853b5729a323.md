Function getCommand() declares a reference char parameter named command. When the function executes the statement

cin >> command;

your entry in response to the input statement is passed back to the function's caller. In this case, that happens in the main() program, at the following statement:

getCommand(choice);

Because getCommand()'s parameter is passed by reference, the function's input statement deposits the entered character into choice. Similarly, getValue()'s input statement

cin >> value;

directly affects the object passed by reference to the function.

# POINTER PARAMETERS

This chapter wouldn't be complete without a mention of pointer parameters. However, you haven't met pointers yet (see Chapter 11, "Managing Memory with Pointers"), so I'll be brief.

A pointer parameter is similar to a reference parameter in that it points to an object of a specified type. However, pointer parameters require you to specify the object's address when calling the function. Reference parameters do that automatically.

One common use for pointer parameters is to pass C-style string buffers to and from functions. Listing 10.5, getstr.cpp, demonstrates the basic technique.
