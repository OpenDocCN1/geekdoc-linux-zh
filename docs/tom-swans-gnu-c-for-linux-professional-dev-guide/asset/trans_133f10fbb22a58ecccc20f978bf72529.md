## 比较和搜索 string 对象

对字符串数据执行的两项最常见操作是比较和搜索。对于C风格字符串，这些工作通常需要重新查阅`strcmp()`和`strstr()`等函数的在线文档——至少对我来说是这样，因为我总记不住按什么顺序使用哪些参数。正如以下几节所述，使用string类对象进行比较和搜索非常直观，也不太可能导致难以发现的bug。

### 比较 string 对象

使用与数学表达式中相同的逻辑运算符来比较string对象。例如，如果`s1`和`s2`是string类对象，则可以在如下语句中对它们进行比较：

```cpp
if (s1 == s2) ...  // Do if s1 equals s2
if (s1 <  s2) ...  // Do if s1 is less than s2
if (s1 >  s2) ...  // Do if s1 is greater than or equal to s2
if (s1 != s2) ...  // Do if s1 is not equal to s2
```

这些表达式及类似表达式之所以可行，是因为string类重载了C++逻辑运算符。string类并未重载所有C++运算符，只重载那些对string对象有实际意义的运算符。例如，你不能对string对象应用自增运算符。以下语句无法编译：

```cpp
s1++;  // ???
s2++;  // ???
```

如果你更愿意调用函数来比较string对象，可以使用string类的`compare()`成员函数。该函数还可用于比较字符串的一部分。若要尝试`compare()`，请定义如下变量：

```cpp
int result, pos, count;
string s1, s2;
```

> **注意**
>
> 本节中的程序取自随附CD-ROM中src/c22目录下的compare.cpp文件。

`compare()`有三种基本形式，都返回整数结果：

```cpp
result = s1.compare(s2, pos, count);
result = s1.compare("Literal string", pos);
result = s1.compare("Literal string", pos, count);
```

语句显示一个大于alphabet长度的值，表明alphabet中没有White Elephants。

除了字面字符串，你还可以将string对象传递给`find()`和`rfind()`来执行搜索。以下语句显示12，即string对象search在alphabet中的索引：

```cpp
string search = "mnop";
cout << alphabet.find(search) << endl;
```

与`compare()`一样，你也可以指定起始位置，从字符串的开头或末尾以外的某个位置开始搜索：

```cpp
cout << alphabet.find(search, 4) << endl;
```

这同样显示12，但若将4改为15，`find()`的返回值将表明它无法找到该子字符串。要从起始位置向后搜索，请向`rfind()`指定一个索引值。下面这行代码在alphabet中找不到xyz，因为它从索引10开始向开头搜索：

```cpp
cout << alphabet.rfind("xyz", 10) << endl;
```

`find()`和`rfind()`函数还可以在string对象中搜索字符：

```cpp
cout << alphabet.find('z') << endl;
cout << alphabet.rfind('a') << endl;
```

其他字符串搜索函数会定位某个字符集（由string对象表示）中的第一个字符。给定本节开头定义的alphabet字符串，以下语句演示了如何使用`find_first_of()`和`find_last_of()`这两个函数：

```cpp
string vowels("aeiou");
cout << alphabet.find_first_of(vowels) << endl;  // 0
cout << alphabet.find_last_of(vowels) << endl;   // 20
```

使用`find_first_of()`定位参数字符串（本例中为vowels）中任意字符首次出现的索引。使用`find_last_of()`定位最后一个此类索引。前面的语句报告0和20，如注释所示。

使用这两个函数的"not"对应函数，即`find_first_not_of()`和`find_last_not_of()`，可以定位某个集合中第一个不匹配的字符。以下语句在alphabet字符串中查找第一个和最后一个非元音字符的索引（函数结果以注释形式显示）：

```cpp
cout << alphabet.find_first_not_of( vowels ) << endl;  // 1
cout << alphabet.find_last_not_of( vowels ) << endl;   // 25
```

指定起始索引，即可从开头或末尾以外的位置在字符串中搜索字符集。这对于继续搜索字符很有用，如下面的while循环所示，该循环查找alphabet中的所有元音字母：

```cpp
int p = alphabet.find_first_of( vowels );
while ( p < alphabet.length() ) {
    cout << "'" << setw(2) << p << "] == ";
    cout << alphabet[p] << "'" << endl;
    p = alphabet.find_first_of( vowels, p + 1 );
}
```
