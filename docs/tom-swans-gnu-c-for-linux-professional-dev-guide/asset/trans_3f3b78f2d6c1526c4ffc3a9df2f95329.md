

这与前面列出的#define指令具有相同的效果。enum保留字后面是一个由逗号分隔、用花括号括起来并以分号结尾的标识符列表（通常为大写）。每个符号都被赋予一个从0开始的连续整数值。在本例中，RED等于0，ORANGE等于1，YELLOW等于2，依此类推，直到VIOLET等于6。

鉴于前面的声明，要声明一个名为color的int变量并为其赋BLUE的颜色值，可以这样写：

```
int color = BLUE;
```

与其使用int类型的对象来存储枚举值，不如为枚举类型命名更清晰。为此，可以使用保留字typedef（表示“类型定义”），如下面的彩虹颜色枚举所示：

```
typedef enum
{
    RED, ORANGE, YELLOW, GREEN, BLUE, INDIGO, VIOLET
} TColors;
```

typedef保留字创建了新的数据类型名称TColors，它与颜色名称的枚举列表相关联。既然TColors被定义为一个新的数据类型，程序就可以像这样声明该类型的变量：

```
TColors oneColor;
```

这使得oneColor成为TColors类型的变量，并可以通过如下语句将颜色符号常量赋值给oneColor：

```
oneColor = INDIGO;
```

编译器会自动枚举enum声明中的元素。然而，有时需要接管这项工作，为一个或多个符号指定显式的值。例如，考虑为一年中的月份创建枚举类型的问题。你可能会尝试这样：

```
enum { JAN, FEB, MAR, APR, MAY, JUN,
      JUL, AUG, SEP, OCT, NOV, DEC };
```

问题在于，因为枚举列表中的第一个符号被赋值为0，所以JAN等于0而不是1——而1才是与一年中第一个月份相关联的正常值。要解决这个问题，可以为枚举列表中的某个成员指定一个显式的起始值。例如，要将JAN设为1，请将前面的声明改为：

```
enum { JAN = 1, FEB, MAR, APR, MAY, JUN,
      JUL, AUG, SEP, OCT, NOV, DEC };
```

表达式JAN = 1将1赋给符号JAN。随后的符号从该点继续序列，使FEB等于2，MAR等于3，APR等于4，DEC等于12。你同样可以初始化枚举类型的任何元素。

使用枚举变量时要记住的一点是，诸如RED、ORANGE、SEP和DEC之类的符号名称只是预处理符号，类似于在#define指令中声明的那些符号。因此，这些符号只存在于程序的源代码中，在编译后的代码中会被替换为其底层的数值。许多不熟悉枚举的程序员错误地认为写出它们会显示关联的名称，但正如清单6.5（enum.cpp）所示，情况并非如此。

## 清单6.5 ENUM.CPP

```
#include <iostream.h>

typedef enum
{
    RED, ORANGE, YELLOW, GREEN, BLUE, INDIGO, VIOLET
} TColors;

int main()
{
    TColors acolor = INDIGO;
    cout << "acolor == " << acolor << endl;
    return 0;
}
```

使用以下命令编译并运行程序。程序创建并显示一个TColors枚举变量acolor的值：

```
$ g++ enum.cpp
$ ./a.out
acolor == 5
```

如你所见，程序报告acolor等于5。它并不会像你预期的那样写出关联的符号名称INDIGO，因为该符号在编译期间被其枚举值替换了。枚举符号有助于澄清程序的逻辑，但这些符号仅存在于源代码层面。

> 提示
> 本章的“初始化字符串数组”一节介绍了一种技术，你可以使用该技术为TColors等枚举类型提供字母名称。

## 布尔变量

C++提供了bool数据类型，用于表示两个符号值true或false之一。bool变量也称为布尔变量或真假变量，经常用作标志来表示各种条件。当你在第9章“控制程序流程”中学习while和if等控制语句时，它们会变得更加重要。要创建布尔变量，可以使用如下语句：

```
bool error = false;
```

这声明了一个bool类型的变量error，并为其赋初始值false。假设error是一个全局变量，在程序的其他位置，如果检测到错误条件，可以使用如下语句将true赋给error：

```
error = true;
```
