The type cast expression (long) converts the objects involved in addition expressions to long integer values via the type conversion operator function. Because this is a member function, the expression (long)*this converts the object for which the operator+() function was called. The expression (long)b does the same for the function’s TStrOp parameter. The class’s GetValue() member function along with other overloaded functions, operator-() and unary operator-(), are similarly simplified by the new type conversion rule.
