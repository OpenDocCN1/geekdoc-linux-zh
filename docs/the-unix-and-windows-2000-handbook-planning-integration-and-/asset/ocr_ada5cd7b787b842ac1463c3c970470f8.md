# Process Viewer

Process Viewer (pviewer.exe) is part of the Windows 2000 Resource Kit. It allows you to monitor running processes on a local or remote system. It is a Windows-based tool very similar to pview.exe. This is a great tool to kill a non-essential process or change a process' priority. Figure 14.19 shows you the Process Viewer screen. The process, processor time, process memory used, and priority of the process are the important fields.

> pviewer.exe—Is part of the Windows 2000 Resource Kit and allows you to monitor running processes on a local or remote system.

# Summary

Performance monitoring is an essential but difficult part of system administration. It begins with the installation of a system and continues as long as the system is in use. In most cases, however, systems are not monitored until they exhibit some difficulty. Performance monitoring requires a thorough understanding of all areas of system administration.
