| Table 10.5 Printer Security Options |  |
|---|---|
| Security Option | Description |
| Print | Allows/denies the user or group permission to print to the network printer. |
| Manager Printers | Allows/denies the user or group permission to modify printer settings. |
| Manage Documents | Allows/denies the user or group permission to pause, resume, restart, or cancel print jobs. |

You can also modify the hours a particular printer is available. Use the following steps to modify the hours your printer is available:

+   1. Open the Printers folder as follows: from the Start menu → Settings → Printers.
+   2. Right-click the printer you wish to modify and select Properties from the list. The printer's Properties window in Figure 10.17 will be displayed.
+   3. Select the Advanced tab to display the advanced settings for the printer. You should see a window similar to the one in Figure 10.19.
