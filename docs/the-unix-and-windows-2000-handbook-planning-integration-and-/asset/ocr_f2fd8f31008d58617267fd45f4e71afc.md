# APACHE WEB SERVER CONFIGURATION

All platforms (UNIX and Windows 2000) utilize the same configuration files. The directives that control the Web server are the same for all platforms (Windows 2000 contains a few additional directives that are covered in the "Windows 2000 Installation" section). The following sections highlight the main configuration files, directives contained in configuration files, and guidelines on securing a Web server.

# Configuration Files

The configuration files for the Apache Web Server are text files, and are located in the conf directory under the top-level directory specified by the --prefix option to configure. There are three configuration files. The httpd.conf file is processed first by the httpd daemon.
