+   - `vmstat`—Provides statistics on processes, virtual memory, disk, interrupts, and CPU activity. CPU utilization and virtual memory monitoring are the primary uses for this command.
+   - `ypcat`—provides a listing of an NIS map.
+   - `ypmatch`—returns the match of a search key within a map, if any exist.
+   - `yppush`—is used only on the server to transfer files to a slave.
+   - `ypwhich`—returns the name of the server to which a client is bound. The `-m` option provides a listing of available maps.
+   - `ypxfr`—transfers NIS maps from the master server to one slave.
