The first field of each entry must start at the left-hand margin and contain a list of names for the printer, separated by a (|). Listing 10.1 is a sample of /etc/printcap

```
Listing 10.1 | /etc/printcap

line|line310|Lineprinter in 310:\
        :lp=:\
        :rm=rserver1.sniglets.com:\
        :rp=line1:\
        :sd=/var/spool/lp/line:\
        :lf=/var/spool/lp/perrlog:

swat|lj440|Laserjet in 440:\
        :lp=:\
        :rm=swat.sniglets.com:\
        :rp=swat:\
        :sd=/var/spool/lp/swat:\
        :lf=/var/spool/lp/errlog:
```

The most commonly used field variables are listed in Table 10.2. The first entry in our sample printcap file is for a remote printer, line. The printer can also be referred to as line310 and “Lineprinter in 310”.

| Name | Description |
|---|---|
| af | Accounting filename |
| If | Text filter |
| lf | Error logging filename |
| lp | Device name to open for output |
| mx | Maximum file size (in BUFSIZ blocks). zero=unlimited |
| rm | Machine name for remote printer |
| rp | Remote printer name |
| sd | Spool directory |
