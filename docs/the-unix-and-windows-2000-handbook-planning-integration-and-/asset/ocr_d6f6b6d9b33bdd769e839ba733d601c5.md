3. Enter the share name and select the machine and NFS filesystem to mount from the Network Resources section. A network resource can also be entered manually using the universal naming convention. The final step is to create a share on the local machine to allow SMB clients to access this NFS directory via the SMB share on the Windows 2000 gateway.

> The Gateway for NFS service should be configured for client machines that have minimal NFS activity.
