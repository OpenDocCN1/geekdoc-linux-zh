```
rpm -e --test -vv xpuzzles
```

The result is a listing of every file that will be deleted when the xpuzzles package is deleted. Now that you are sure there aren't any files that you need, you can do the dirty deed:

```
Rpm -e xpuzzles
```

Check your work by entering:

```
Rpm -q xpuzzles
```
