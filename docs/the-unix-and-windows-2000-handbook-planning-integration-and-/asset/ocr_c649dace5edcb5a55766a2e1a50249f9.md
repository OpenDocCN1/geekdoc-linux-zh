first configuration entry (:lp:\) for l1ne specifies the device name for this printer. Printer l1ne is a remote printer, so we don't need to assign a value for lp. The second configuration entry for l1ne specifies the remote machine name (server1.sniglets.com), that lpd connects to for transferring the control and data files. The third configuration entry (:rp:l1nel:) specifies the name of this printer on the remote machine. The fourth configuration entry specifies the spool directory for this printer on the local machine. The final configuration entry specifies the error log file.

Notice that both printers share the same error logging file (/var/spool/lp/errlog). Each entry in the error log file contains the name of the printer that generated the error line. The error log file is important for troubleshooting problems with local printers and determining communication problems with remote printers. The error logging file can get quite large over time. A simple shell script to rotate the logs should be run weekly to limit the growth of this file. The following shell script should be run weekly by cron and will keep four weeks of compressed log files in the /var/spool/lp directory.

```
#!/bin/sh
# Rotate printer error logfile
#
SPOOLDIR=/var/spool/lp
if test -d $SPOOLDIR
then
    cd $SPOOLDIR
    if test -s $ERRLOG
    then
        test -f $ERRLOG.1.gz && mv $ERRLOG.1.gz $ERRLOG.2.gz
        test -f $ERRLOG.0.gz && mv $ERRLOG.1.gz
        mv $ERRLOG $ERRLOG.0
        /usr/local/bin/gzip -9 $ERRLOG.0
        cp /dev/null $ERRLOG
        chmod 644 $ERRLOG
    fi
fi
```

Printers can share the same error log file, but should not share a spool directory. A spool directory must be created for all locally attached and remote printers. The control and data files for a print job are stored in this directory before being sent to a local printer or transferred to a remote machine. This directory must be created by the system administrator when a new printer is added. The steps in creating the spool directory are covered in the next paragraph.
