# LPRng

LPRng is an enhanced print services package based on BSD. It includes the familiar lpr, lpc, and lprm commands. It also includes dynamic redirection of print queues, multiple printers serving a single queue, and greatly enhanced security checks. LPRng is compatible with remote printers using the BSD services, and it has been ported to HPUX, Solaris, Linux, and AIX.
