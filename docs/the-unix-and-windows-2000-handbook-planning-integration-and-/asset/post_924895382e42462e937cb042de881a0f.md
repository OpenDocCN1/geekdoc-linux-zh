## Exchange Server Naming Options

The naming options in Exchange Server are actually quite simple. In a nutshell, the naming options specify two things: 1) How a user's name is displayed, and 2) How each user's email address is generated. By default, each user's mailbox is created in a “firstname lastname” format and each user's email address is created in a “firstname+last initial@yourdomain” format. While this is probably acceptable for most installations, we felt it significant enough to mention how to change this option here. - 1. Open the Exchange Server Administrator from the Microsoft Exchange Start menu program group. You will see a window similar to the one in Figure 9.12.
