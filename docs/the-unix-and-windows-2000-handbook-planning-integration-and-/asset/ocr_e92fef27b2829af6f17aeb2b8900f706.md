# Configuring Internet Mail Service

The Internet Mail Service is necessary to send or receive email messages over the Internet. If you do not intend to send or receive email messages over the Internet, you can ignore this section. The first step to configuring the Internet Mail Service is to install it as a connection in Exchange Server. To do this, complete the following steps:

+   1. Launch the Exchange Server Administrator from the Microsoft Exchange Start menu program group. You will be asked to select a server to administer, where you should select the current server. You will see a window similar to the one in Figure 9.12.
