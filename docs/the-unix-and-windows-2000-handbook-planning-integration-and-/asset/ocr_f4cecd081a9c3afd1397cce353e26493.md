The final three entries consist of the `VirtualHost` block directives. Notice that the default server (`www.sniglets.com`) is also treated as a virtual host.

# .htaccess

The `.htaccess` file allows you to change directives in a directory without restarting Apache, and `.htaccess` is the default filename for file access directives. This file allows users to control their own Web pages without the assistance of the webmaster. These files must be parsed on each request and impose a small performance penalty. The `AccessFileName` directive can specify the name of files to check for file access directives. `AccessFile-Name` is a global directive. The `AllowOverride` directive tells the server which directives in the `.htaccess` file can override directives previously set. For the latest options for the `AllowOverride` directive, check the Apache documentation.
