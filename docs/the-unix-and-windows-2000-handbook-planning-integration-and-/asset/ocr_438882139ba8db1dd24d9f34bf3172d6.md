# UNIX GROUPS

One of the founding principles of UNIX was the ability to easily share files between users. As was discussed in Chapter 11, each file in UNIX has the ability to allow access to a user, group, or other. While user-level access allows only one user access to a file, group access allows members of a group to have that privilege. With the use of group permissions, a file owner can grant read, write, and/or execute access to any file to a subset of all users that are part of a given UNIX group. Following is a standard Solaris /etc/group file:

```text
root::0:root
other::1:

mail::6:root
