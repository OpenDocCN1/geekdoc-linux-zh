# WINDOWS 2000 DHCP SERVERS

Windows 2000 Server ships with a DHCP server. If you did not install the DHCP server during installation, you can add it using the Add/Remove Programs applet in the Control Panel. The DHCP server that ships with Windows 2000 is more than adequate for most networks. However, if you require special functionality (such as access restrictions), then you should investigate commercial packages, which are available for both UNIX and Windows platforms. The DHCP server service will allow you to dynamically configure your clients and can also be integrated with your WINS and DHCP servers. This section will walk you through a typical DHCP scope configuration.
