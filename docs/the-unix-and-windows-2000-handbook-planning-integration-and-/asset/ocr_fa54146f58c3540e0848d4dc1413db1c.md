# Host Intrusion Scanner, or Find the Holes before the Intruder

Host intrusion scanners check for the appropriate setting of file permissions. For UNIX, this type of scanner searches for world-writable files or directory permissions, as well as setuid or setgid files owned by root. More advanced commercial scanners check for missing security patches or known vulnerabilities of system-installed components.
