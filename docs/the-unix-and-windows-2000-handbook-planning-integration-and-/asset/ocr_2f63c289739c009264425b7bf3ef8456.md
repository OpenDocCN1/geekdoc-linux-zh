# Command Line

The Software Distributor HPUX commands (SD-UX) manage software on the local host only. SAM utilizes this command set in the Software Management menu. A list of the SD-UX commands and a brief explanation of the actions they perform are provided in Table 5.3. The first three commands in the table, invoked without any arguments, will run interactively in an X11 window or in character mode. You should recognize the look and feel from the SAM interface.

You can establish a software depot with the swcopy command. The first step is to download a patch from the Hewlett Packard Electronic Support Center.
