# AIX: SMIT and FixDist

The System Management Interface Tool (SMIT) is AIX’s menu-driven system administration and management tool. SMIT will automatically detect a user’s environment variables and run in either an X11 display (Figure 5.4) or a character mode interface (Figure 5.5). To ensure a character interface, utilize the following:

```
smit -C

or

smitty
```

![](bbox=[0.036, 0.568, 0.936, 0.637])

SMIT can be invoked with the FastPath switch install to immediately place you in the software installation and maintenance portion of SMIT. Here, the character interface provides quicker response.

SMIT automatically creates two files in the user’s home directory ($HOME) during each session. The smit.log file contains the sequence of submenus visited during the session. The smit.script file contains the AIX command that SMIT invoked in response to your selections. The script file is a great resource for understanding the switches and inputs required in command-line software maintenance. This file can also be used to automate redundant software installs.
