| Directive | Value |
|---|---|
| `User UNIX-userid` | UNIX userid under which server will answer requests<br>Default is -1 |
| `Group UNIX-groupid` | UNIX group under which server will answer requests<br>Default is -1 |
| `DocumentRoot directory-filename` | Server serves documents from `directory-filename`<br>Default is `/usr/local/apache` |
| `PidFile file` | Places PID of httpd in `file` |
| `KeepAlive number` | Keeps connection open for number of requests<br>Default is 5 |
| `TimeOut seconds` | Server will wait for receipt of request and then completion block by block for seconds. Default is 1200 |
| `MaxClients number` | Limits simultaneous request to `number`<br>Default is 150 |
| `StartServers number` | Number of servers started initially<br>Default is 5 |
| `MaxSpareServers number` | No more than number of servers left running and unused<br>Default is 10 |
| `MinSpareServers number` | Server keeps at least this number of servers running<br>Default is 5 |
