To determine a user's group members, as root, or as the user, run the groups command:

```
# groups jsmith
students math101
```

This indicates that jsmith is a member of the groups students and math101.

# Default Group

Each user has a default group that will be assigned to each file they create. Since users can be members of any number of UNIX groups, files are only created with ownership assigned to the default group. To determine the default group of a user, run the id command:

```
# id -a jsmith
uid=1001(jsmith) gid=14(students) groups=100(students),150(math101)
```

In this example, the gid identifies the default group to which user jsmith belongs. Upon login, jsmith can only create group files in the group students. However, jsmith can interact with any files that have math101 ownership, given the proper permissions. It is convenient to be able to create files with the appropriate group, especially if you have a number of files to create. While using the chgrp command is an option, using the newgrp command as user jsmith:

```
#newgrp math101
```

will set jsmith is default group for that shell instance to the new group:

```
# id -a jsmith
uid=1001(jsmith) gid=150(math101) groups=100(students),150(math101)
```

To return to the default group, type newgrp students, or exit the current login shell.
