# The UNIX Filesystems

Files in the UNIX universe reside within a filesystem, which in turn makes up the file tree. The file tree on a UNIX system can contain filesystems from multiple disks or even multiple machines. The basic tree consists of a root filesystem and subsequent directories or branches. Figure 4.1 shows a local-only file tree.

Some of the subdirectories shown in the tree are on the same physical partition as the root directory, and others are on different partitions. Add local partitions to the file tree with the mount command as follows.

```
mount -F ufs /dev/dsk/c0t0d0s3 /var
```

The mount command associates the block device specified with the directory name given, using the filesystem type provided. There are many filesystem types available. Usually, the -F option can be omitted and the system's default filesystem will be used. A commonly used filesystem type is
