+   4. Select (highlight) Internet Protocol (TCP/IP) from the list and click the Properties button. The Internet Protocol (TCP/IP) Properties window will be displayed, as shown in Figure 6.3.
+   5. Click the Advanced button to display the Advanced TCP/IP Settings window, as shown in Figure 6.4.
+   6. Click the DNS tab and you will see the window shown in Figure 6.5.
+   7. In the DNS server addresses box, click the Add button to add each of your DNS servers to the list in the order you wish the servers to be used.
+   8. Select the Append these DNS suffixes option and add the DNS suffixes you wish to query when an unqualified hostname is being searched (i.e., mypc instead of mypc.mycompany.com).
+   9. Enter your machine's DNS suffix in the DNS suffix for this connection box.
+   10. If you are using Dynamic DNS, place a check mark next to Register this connection's addresses in DNS; otherwise, uncheck the box.

> The DNS suffix order should always be configured to have your local domain as the first domain in the list. You should order your domains so that the most common ones are searched after the local domain.
