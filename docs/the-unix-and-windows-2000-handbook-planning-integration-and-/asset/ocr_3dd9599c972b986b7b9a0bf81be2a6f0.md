# USING DHCP

DHCP dynamically assigns IP addresses to networked client machines. In addition to the IP address, the DHCP server also assigns the default router, DNS servers, WINS servers, and the NBT node type. With DHCP, the only parameter that must be set locally on the client machines is the host name and (optionally) the domain name and domain search order. DHCP, DNS, and WINS can provide a seamless name resolution and registration infrastructure.
