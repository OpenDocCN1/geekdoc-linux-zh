# PERFORMANCE-TUNING TOOLS FOR WINDOWS 2000

This subsection contains Windows 2000 performance-tuning commands. Some of these commands also provide a performance-monitoring capability. The tools covered in this subsection fall into two categories. The first category consists of tools/commands (at and the Task Scheduler) that allow job scheduling. The second category consists of tools (Task Manager and Process Viewer) that allow you to monitor the performance of the Windows 2000 workstation and to kill or change the priority of running processes. Both categories aid in extracting the best performance from your Window 2000 workstations or servers.
