The final section contains settings for virtual hosts. Virtual hosting allows a single Apache Web Server process to process requests for different IP addresses or hostnames. Settings in this section will override settings contained in the second section. The following listing is the third section of the httpd.conf file:

```
```apache
### Section 3: Virtual Hosts
#
# VirtualHost: If you want to maintain multiple domains/hostnames on your
# machine you can setup VirtualHost containers for them.

# for further details before you try to setup virtual hosts.
# You may use the command line option '-S' to verify your virtual host
# configuration.
#
# If you want to use name-based virtual hosts you need to define at
# least one IP address (and port number) for them.
