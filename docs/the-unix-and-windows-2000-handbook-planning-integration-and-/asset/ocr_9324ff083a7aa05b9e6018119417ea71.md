# Creating Groups

Creating groups is very similar to creating user accounts. When creating groups, keep the following in mind:

+   - Use functional/intuitive names for your groups.
+   - Create groups in the Users container, or a container you have created specifically for groups.

For our purposes, we are going to walk through creating a Global group, and then describe how to add users to the new group. Refer to the following steps to complete this task:

+   1. Log on to your Windows 2000 domain controller as Administrator.
+   2. Open the Active Directory Users and Computers MMC snap-in as follows: from the Start menu → Programs → Administrative Tools → Active Directory Users and Computers. You will see a window similar to the one in Figure 12.6.
+   3. Make sure the Users folder in the left pane is selected.
+   4. From the Action menu, select New and then Group to display the New Object-Group properties window in Figure 12.10.
