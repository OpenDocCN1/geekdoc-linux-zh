# 由浅入深，透视CLR和.NET精髓，知其然
蜕茧入里，探究CLR和.NET机理，知其所以然

要想深入探究并掌握CLR(公共语言运行时)、C#和.NET开发，其实很简单。

享有全球盛誉的编程专家Jeffrey Richter，微软.NET团队合作长达十几年的资深技术顾问，在本书中以简洁流畅的语言和读者分享他毕生的经验和心得，他的见解独到、深刻，他的洞悉熟虑和远见卓识，为开发人员构建健壮、可靠和响应快的应用程序与组件奠定了良好的基础。

《CLR via C#(第4版)》针对.NET Framework 4.5和多核编程进行了全面更新和修订，是帮助读者深入探索和掌握公共语言运行时、C#和.NET开发的重要参考。

# 本书重要主题

+   - 根据.NET Framework 4.5和Visual Studio 2012全面更新
+   - 深挖.NET Framework架构、运行时环境和其他关键主题，包括异步编程和最新的Windows Runtime
+   - 提供丰富的Visual C# 2012范例代码
+   - 对泛型和线程处理等难以理解的概念提供实际有用的指导和讲解

# 作者简介

# Jeffrey Richter

Winellect联合创始人、著名畅销书作家。Windows和.NET的大师级、设计与实践方面的专家，著有多部经典著作。他长期关注多线程、进程管理与并发等主题，并致力于编写清晰易懂的技术书籍，帮助读者深入理解相关知识。

Jeffrey出版过12本Windows、.NET畅销书，曾经担任过MSDN Magazine的特约编辑，并为Q&A杂志撰稿。他曾在微软和其他公司担任顾问、讲师和技术作者，广泛参与软件开发与技术交流。

Jeffrey对于线程、垃圾回收机制和并发编程等主题有深入研究，并以通俗易懂的方式介绍复杂概念。他与妻子Kristin及子女在华盛顿州生活。
