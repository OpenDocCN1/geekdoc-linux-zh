    if some condition is true
    then
        if some other condition is true
        then

```
```

Using a nested if inside of a Linux shell script is not much different. Let's look at an example of a nested if. Type the following code into your favorite text editor and save it as scriptnine.sh.

```
```
#!/bin/bash
age=0
echo Please enter your age
read age
if test $age -gt 16
then
    if test $age -gt 18
    then
        echo You are old enough to vote!
    else
        echo you are old enough to drive, but not to vote.
    fi
else
    echo You are too young to drive.
fi
exit 0
