# **Chapter 9**

+   1. Name one feature found in Calc, not present in Microsoft Excel.
+   2. Why might you want to add some drawing to your spreadsheet?
+   3. What would you find on the Object toolbar?
+   4. What is one thing that Excel and all Microsoft Office products do that Calc does not do?
+   5. How would you compute the standard deviation of a column or row?
+   6. How do you customize the toolbars in Calc?
+   7. What is the difference using autofill on numbers and dates?

# **Answers**

+   1. The ability to insert Java applets and plug-ins.
+   2. To add visual impact to your data.
+   3. The Object toolbar consists a set of tools that are specific to calculation and cell formatting.
+   4. Keep a recently opened files list.
+   5. By clicking the Autopilot button and selecting the stdev function, after highlighting the cells you want to compute the function for.
+   6. Right-click on the button on the toolbar.
+   7. Dates are incremented to the next month or day, whereas numbers are simply incremented by one.
