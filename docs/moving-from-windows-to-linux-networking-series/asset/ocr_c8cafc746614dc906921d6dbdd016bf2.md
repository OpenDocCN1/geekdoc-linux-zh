Of even more interest is the Insert Object option. This option enables you to insert sounds, videos, OLE objects, Java applets, and more. This enables you to add a whole new dimension to your spreadsheets. For example, if you are doing a budget spreadsheet for a construction project, you could add a video of a building being built.
