+   2.  What type of functions are found on the second toolbar in Writer?

+   3.  Name an advantage that Microsoft Word has over Open Office Writer.

+   4.  What is a common document tool used to organize data in an easily read format?

# Answers

+   1.  **Bold**, *italic*, and <u>underline</u>.
