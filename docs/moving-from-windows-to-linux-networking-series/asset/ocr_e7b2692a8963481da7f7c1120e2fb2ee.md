Virtually all local area networks must use DNS service in order to use the World Wide Web. DNS is a networking protocol that translates the URL you enter (such as www.chuckeasttom.com) into an IP address. If you are on a network that uses DNS, you can enter the settings for it on the DNS tab. These settings will be provided by your network administrator. The screen is shown in Figure 4.23.
