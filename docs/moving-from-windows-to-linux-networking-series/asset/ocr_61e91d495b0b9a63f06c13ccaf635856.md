While we are on the topic of color selection, it is a good time to point out that you can select the color for any painting tool by using the squares at the bottom-left side. Click on the square, and you are presented with the Color Selection screen shown in **Figure 12.33**, where you can select the color for that tool to paint with. This is exactly the same way Adobe Photoshop does color selection.
