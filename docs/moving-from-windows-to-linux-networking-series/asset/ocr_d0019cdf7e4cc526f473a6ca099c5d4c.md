# # Servers

There are a number of different server-related packages available. These include Web servers, database servers, and news servers. Some of these packages will apply only to network servers, but some may be applicable to small businesses and personal use. The individual packages are described in Table 2.3.

# Table 2.3: Server Packages

| Package | Purpose |
|---|---|
