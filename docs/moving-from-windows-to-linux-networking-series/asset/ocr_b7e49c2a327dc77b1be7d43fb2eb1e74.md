# Review Questions

+   1. What protocol do Web browsers use?

+   2. What is the default port for Web servers to listen on?

+   3. In simple terms, what is a Web server?

+   4. What is HTTP return code 301?

+   5. How did Apache server get its name?

+   6. What is the name of the Apache configuration file?

+   7. What is the ServerAdmin setting in the configuration file?

+   8. What are four basic troubleshooting steps should you first take when having an Apache problem?

# Answers

+   1. HTTP (Hypertext Transfer Protocol)

+   2. 80

+   3. A computer with a program running that can listen to port 80 and respond.

+   4. The page has been moved and you are being redirected to the new address.

+   5. Because its creators thought it was A Patchy Server.

+   6. httpd.conf

+   7. The e-mail address for the Web server administrator.

+   8. 1. Is your Web server running? 2. Is it connected to the Internet? 3. Did you type in the address correctly without misspelling it? 4. Have you checked the error log for error messages?
