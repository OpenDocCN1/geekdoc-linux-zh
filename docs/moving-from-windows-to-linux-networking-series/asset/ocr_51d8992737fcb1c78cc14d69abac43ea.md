# **Figure 14.10:** The Panel Hide configuration.

The third tab is even more interesting and is shown in **Figure 14.11**. This tab allows you to set what if any submenus your panel will have. You also can decide how long the History will be. The History in any application is a list of the most recently used files. For most applications in Linux and Windows the default is four. But you can set that to whatever you want.
