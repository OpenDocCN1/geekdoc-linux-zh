# Kandalf’s Tips

This is a very useful application for the Linux beginner. Kandalf’s Tips, shown in Figure 14.19, will show you all of the various tips that you might normally see when the system starts up. You can peruse these tips and learn many interesting things about Linux. For any beginner, it is a very good idea to spend a bit of time perusing these tips.
