# # Configuring Samba

In the past the only way to configure Samba was via shell commands. Fortunately, that is no longer the case. You can go to the Start menu, find Server Settings, select More Server Settings, and choose Samba Settings. You will then see a screen like the one shown in Figure 22.1.

![](bbox=[0.0, 0.16, 0.65, 0.46])

**Figure 22.1:** The Samba Server Configuration screen.

This screen is simple. Adding a Samba service to your Linux machine with this utility is probably easier than many of the other tasks we have performed. At this point you can either click the Add button on the toolbar or select File and Add Share from the drop-down menu. When you choose that you will see a screen much like the one shown in Figure 22.2.

![](bbox=[0.0, 0.56, 0.65, 0.87])

**Figure 22.2:** Adding a new share.
