# Chapter 13: Web Browsers, E-Mail, and Internet Applications

# Introduction

In an earlier chapter we discussed briefly the basics of using Mozilla and Evolution for Web browsing and e-mail, respectively. In this chapter we are going to examine several different Web utilities in depth. It is hoped that after completing this chapter, you will be comfortable using the various Linux Web utilities you have available to you. The Internet is one of the primary reasons why many people get a home computer. Fortunately, Linux ships with all the applications needed to use all aspects of the Internet.
