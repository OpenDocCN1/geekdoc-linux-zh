# Review Questions

+   1. Does Open Office Impress support automatic slide show presentation?

+   2. What drop-down menu would you use to change the toolbars that are displayed?

+   3. What drop-down menu would you use to add three-dimensional effects to text?

+   4. What is the purpose of the Slides view?

+   5. What is the difference between reharase timings in PowerPoint and in Impress?

# Answers

+   1. No

+   2. Go to View, then select Toolbars.

+   3. Go to Format and then select Text.

+   4. To arrange your slides in some particular order.

+   5. In Impress it is simply for your own rehearsal. In PowerPoint the timings are recorded.
