A common question is how to delete a file whose name begins with a minus (-). Suppose, for example, a file in your home directory is named `-foo. The command `rm -foo` fails and generates the following error:

```
$ rm -foo
corm: invalid option - o
```

This problem occurs because most Linux commands interpret a minus sign followed by a letter as a command option, and anything following that as an argument to the command. So, the argument to the `rm` command, `-foo`, looks like invalid syntax, not a filename. The solution is to use two minus signs (-- ) between `rm and `-foo`. Most Linux commands interpret two minus signs standing alone as the end of all options; everything afterward is interpreted as an argument. So, to remove that file named `-foo`, try `rm -- -foo,` as follows:

```
$ rm -- -foo
```
