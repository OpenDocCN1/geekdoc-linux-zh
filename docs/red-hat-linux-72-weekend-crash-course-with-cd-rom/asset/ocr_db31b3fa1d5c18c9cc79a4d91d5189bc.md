# REVIEW

This session introduced you to the subject of security for your Red Hat Linux system. You learned the importance of establishing a security policy for a medium to large organization. Next, this session showed you how to secure two key elements—the passwords and the network services—on your Linux system. Finally, this session included a discussion of how to review log files for signs of intrusion attempts and how to keep up with any late-breaking security news. Because this session could not cover many security topics, it provided you with some additional online resources from which you can learn more about securing your Red Hat Linux system.
