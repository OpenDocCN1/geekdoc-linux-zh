If you really ruin the configuration of your screen savers and want to restore their default settings, you can delete or, better still, rename the following files in your home directory:

+   * .xscreensaver (may not exist)
+   * .gnome/Screensaver
+   * .kde/share/config/kdesktoprc

The second entry is GNOME-specific. The third file is for KDE. Note that kdesktoprc also controls other elements of your KDE desktop, so you might simply want to edit it (it is a text file) and remove all of the entries in the section that begin with the heading [ScreenSaver].
