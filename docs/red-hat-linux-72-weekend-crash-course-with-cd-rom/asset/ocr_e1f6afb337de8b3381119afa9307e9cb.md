# Exploring KDE

To try the KDE GUI, you must have installed the KDE package as part of the Red Hat Linux during Session 1. Typically, the installation program makes GNOME your default GUI. For now, you can change the GUI for the next session by selecting Session \ KDE from the graphical login window.

+   **Note**
+   Don't confuse the term *session* as used in the login window, which refers to the period of time you are logged in, and the term *session* as used in this book, which refers to the 30 lessons or chapters.

+   **Cross-Ref**
+   In Session 17, you learn how to change the default GUI from GNOME to KDE and vice versa.

When you log in, you should get the KDE desktop for the current session. The next time you log in, the system reverts to GNOME (assuming that is your default GUI).
