# Changing Text in Files

Another useful Linux command is the tr (for translate) command, which you can use to change one character to another or to delete certain characters without editing the file using an editor like vi or gedit.

# Deleting text

Suppose you want to replace the tab characters in the phnlist.txt file with a single space. To do so, execute the command, tr "\t" " " < phnlist.txt. This command instructs tr to replace each tab character it encounters, denoted by "\t", with a single space character, denoted by " ".
