# ### Troubleshooting

When you click Yes to import the Red Hat public key, the Update Agent may not continue. Simply restart the Update Agent after importing the public key to restart the update process.

If the Update Agent starts but displays an error message that it is not configured properly, log into the Red Hat Network and activate your Software Manager subscription. The Update Agent requires a valid Software Manager subscription in order to function.

If the Update Agent does not show all of the RPMs installed on your system, log in as root, open a terminal window, and execute the command `up2date -p` to synchronize the system profile with the list of packages installed and maintained by the RPM database.
