The other, more recent and more popular alternative is Ethernet over *unshielded twisted pair (UTP)* cable, known as *10BaseT*. A 10BaseT cable resembles a standard telephone cable with slightly fatter cables and wider connectors.

To set up a 10BaseT Ethernet, you need an Ethernet hub —a hardware box with RJ-45 jacks. You build the network by running *twisted-pair wires* from each PC’s Ethernet card to this hub. (The twisted-pair wires are usually *Category 5*, or *Cat5*, cables.) Currently, you can buy an 8-port 10BaseT hub for about $50 (U.S.).
