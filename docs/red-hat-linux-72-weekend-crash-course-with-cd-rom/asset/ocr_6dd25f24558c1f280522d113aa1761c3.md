# **CD-ROM Installation Instructions**

The CD-ROM that comes with this book contains a copy of Red Hat Linux 8.0 Publisher's Edition.

The most common installation method is to insert the installation CD-ROM into your CD-ROM drive and restart your computer. When the computer restarts, the CD-ROM will start the installation procedure.

Follow the instructions to install Red Hat Linux 8.0.

Enjoy!
