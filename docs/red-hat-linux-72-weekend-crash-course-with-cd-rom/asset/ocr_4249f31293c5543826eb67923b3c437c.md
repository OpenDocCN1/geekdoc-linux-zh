# Starting Red Hat Linux for the First Time

After the installation is complete, the Red Hat Linux installation program automatically reboots the system. The PC goes through its normal power-up sequence, loads LIL0 from the C: drive, and a screen appears with the names of the partitions that LIL0 can boot.
