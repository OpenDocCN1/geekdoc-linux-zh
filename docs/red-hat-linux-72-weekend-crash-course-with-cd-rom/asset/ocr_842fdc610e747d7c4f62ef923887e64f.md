# Maintaining Calendars

The companion CD-ROMs contain several calendar programs. The GNOME desktop comes with its own calendar program. Additionally, when you install the X Window System following the steps outlined in Session 1, you also install *ical*, which is an X Window System-based calendar program. You can start both calendars from the GNOME Panel’s Main Menu button or the KDE main menu.

# *ical* Calendar

To start *ical*, select Main Menu\>* Programs*\>* Applications*\>*ical* from the GNOME desktop. (You can also simply type *ical* in a terminal window.) The program displays a full-screen window where you can click a date to view that day’s schedule. To add appointments for a specific time, click the time and type a brief description of the appointment.
