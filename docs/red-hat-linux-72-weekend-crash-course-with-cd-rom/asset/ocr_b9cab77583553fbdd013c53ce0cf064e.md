We do not have enough time to discuss all of the KOffice applications, so we'll only introduce you to KSpread and KWord. Figure 19-2 shows KSpread with the same spreadsheet shown in Figure 19-1. To start KSpread from KDE, select K-> Office -> KSpread.

As you can see in Figure 19-2, KSpread's interface is similar to Microsoft Excel's and, in its default configuration, most of the functions you will need are already available. KSpread can open about a dozen spreadsheet formats, including Excel 97, but will only save new sheets in its own format, .ksp, or as CSV (Comma separated value) data.

Even though KOffice was written with KDE in mind, it runs just fine under GNOME. To start KOffice applications while using the GNOME desktop, select Main Menu-> KDE Menu-> Office, and then select the application you want to run.
