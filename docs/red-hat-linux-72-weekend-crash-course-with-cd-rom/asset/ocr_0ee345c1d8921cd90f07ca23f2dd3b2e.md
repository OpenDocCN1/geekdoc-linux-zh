# ## Using the Help Viewers

Both GNOME and KDE desktops come with help viewers—the GNOME Help Browser and KDE Help—that enable you to view online help information.

# ### GNOME Help Browser

From the GNOME desktop, select Main Menu→Programs→Help System or click the question mark icon on the GNOME Panel to launch the GNOME Help Browser. The GNOME Help Browser
