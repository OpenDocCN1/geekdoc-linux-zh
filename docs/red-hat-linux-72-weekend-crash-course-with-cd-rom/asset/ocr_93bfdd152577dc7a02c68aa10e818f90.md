xsms-1.2.5/config.guess

The output of this command shows you the contents of the archive and gives you an idea of the directories that are created once you unpack the archive. In this case, a directory named `xsms-1.0.1` is created in the current directory, in this case, `/usr/local/). From the listing, you also learn the programming language used to write the package. If you see `.c` and `.h` files, that means the source files are in the C programming language, which is used to write many open source software packages.

# Unpacking the software

To extract (or unpack) the contents of the tar archive, type the following tar command:

```
tar zxvf xsms*.gz
```

You again see the long list of files as they are extracted from the archive and copied to the appropriate directories on your hard disk.

If you downloaded an archive with `.bz2` at the end instead of `.gz`, it means the archive was compressed with the `bzip2` utility. In order to unpack this kind of archive, replace `z` with `j` in the tar command. That is, type `tar xjvf xsms*.bz2`.

Now you are ready to build the software.

# Building the Software from Source Files and Installing It

After you unpack the compressed tar archive, all source files are in a directory whose name is usually that of the software package with a version number suffix. For example, the XMSM version 1.2.5 source files are extracted in the `xsms-1.2.5` directory. To start the process of building the software, change the directory with this command:

```
cd xsms*
```

You don't have to type the entire name. The shell can expand the directory name and change it to to the `xms-1.0.1` directory.

Nearly all software packages come with one or more `README` or `INSTALL` files, or something similarly named. These files are text files containing instructions on what to do to build and install the packages. XMSM is no exception; it comes with a `README` file that you should read by typing more `README`. There is also an `INSTALL` file that contains instructions for building and installing XMSM.
