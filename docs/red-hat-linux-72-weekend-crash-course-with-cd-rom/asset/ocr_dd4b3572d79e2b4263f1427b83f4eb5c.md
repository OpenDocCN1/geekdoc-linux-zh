You can go to a different month or year by clicking the arrows next to the month and the year. After you finish adding events and appointments, select File↵Save to save the calendar.

To start the GNOME calendar program, select Main Menu↵Programs↵Applications↵Calendar from the GNOME Panel. The GNOME calendar's main window appears. The GNOME calendar's toolbar buttons give you quick access to the most commonly needed functions, such as moving to a different date or adding a new appointment. Underneath the toolbar, a number of tabs display the appointments in four different views: Day View, Week View, Month View, and Year View. If you are unsure about what a button does, simply hover the mouse pointer over the button and a small pop-up help message gives you some information.

To add an appointment, you can double-click the date in the right side of the window and then click the New button on the toolbar. This brings up a dialog box where you can enter information about the appointment. Select File↵Save to store the appointments on disk.
