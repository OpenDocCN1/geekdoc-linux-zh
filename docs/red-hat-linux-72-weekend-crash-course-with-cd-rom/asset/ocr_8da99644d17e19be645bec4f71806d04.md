# Troubleshooting

If the Apache Web server is not installed on your system, use the following instructions to install it:

+   1. Log in as the root user.
+   2. Mount the Red Hat Linux installation CD-ROM (disk 1).
+   3. Type the following command to install Apache and its supporting packages (replace /mnt/cdrom with the mount point of your CD-ROM drive if it is different):

```
# rpm -ivh /mnt/cdrom/RedHat/RPMS/apache*rpm
```

To start the Apache Web server if it is not running, type the following command as root:

```
/etc/rc.d/.init.d/httd start
```

If the FTP server is not installed on your system, use the following instructions to install it:

+   1. Log in as the root user.
+   2. Mount the Red Hat Linux installation CD-ROM (disk 1).
+   3. Type the following command to install Apache and its supporting packages (replace /mnt/cdrom with the mount point of your CD-ROM drive if it is different):

```
# rpm -ivh /mnt/cdrom/RedHat/RPMS/wu-ftp\**rmp*
```
