# Booting from Another Partition

If you want to boot from another partition (such as Windows), press the Tab key. LILO displays the names of the available bootable partitions. For example, a typical display might be:

```
linux dos
```

You can then type the name of the partition you want to boot (1inux or dos, in this case) or press Enter to boot from the first partition, also referred to as the default, partition.

When you install LILO, if you specify the Linux partition as the default, you can simply wait; after a few seconds, LILO boots Linux.

After LILO boots Linux, you should see a long list of opening messages—including the names of the devices that Linux detects. At the end of all the messages, you see a graphical login screen like the one in Figure 3-1.

![](bbox=[0.19, 0.48, 0.83, 0.82])

Figure 3-1 Graphical login screen in Red Hat Linux

The window in the middle of the screen displays a welcome message with your system’s host name—the name you assign to your system when you configure the network. If the network is not configured, localhost.localdomain is used as the host name. Now you can log into your new Red Hat login system for the first time.
