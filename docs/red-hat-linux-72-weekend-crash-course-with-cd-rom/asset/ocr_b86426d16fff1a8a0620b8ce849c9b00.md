# Session 30—Getting Help from Available Resources

![](bbox=[0.11, 0.09, 0.85, 0.44])

**Figure 30-1** Partial list of HOWTO files accessible through the GNOME desktop's LDP icon

Each HOWTO file contains information about some area of Linux, such as how to configure hardware in Linux or how to create a boot disk. To view any of these HOWTO files, click the name and the Web browser loads the full text file. For example, Figure 30-2 shows the result of clicking the CD-Writing HOWTO, which explains how to record a CD using a CD-ROM recordable (CD-R) device installed in a Linux system.

You should browse through the list of HOWTO files (see Figure 30-1) and view one or more that interest you.

At the very end of the list of HOWTO files, you see a folder named mini. Click that link to view the list of mini-HOWTOs, which cover many more narrowly focused topics.
