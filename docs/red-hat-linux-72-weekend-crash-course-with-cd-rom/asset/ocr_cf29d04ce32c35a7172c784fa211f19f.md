If your system is set to boot to run level 5 but X Window is having trouble initializing, change *initdefault* in `/etc/inittab` to 3 while troubleshooting the problem and test your fixes using the *init 5* command. Once you have solved the problem, change *initdefault* back to 5 to restore the graphical login when the system boots.

If you forget the syntax of the *chkconfig* command, type *chkconfig* and press Enter to see a short usage message.
