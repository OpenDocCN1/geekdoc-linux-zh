To add a new user, follow these steps:

+   Select the **Users Accounts** item, and then select the **User accounts** item in the Normal tab. This causes Linxconf to display the **Users Accounts** dialog box, as shown in Figure 10-2.

+   Click the **Add** button in the **Users Accounts** dialog box of Figure 10-2. This brings up the **User Account Creation** dialog box.

+   Fill in the requested information. In particular, you must enter the **login name** and the **home directory**. For example, create an account with a login name of **gnuser** with **/home/gnuser** as the home directory. After filling in all of the fields, click the **Accept** button. If the **/home/gnuser** directory does not exist, Linxconf creates the directory.

+   The **Linxconf** tool displays the **Changing Password** dialog box, in which you enter the **password** for the new account. Enter the **password**, click the **Accept** button, and then retype the **password** for confirmation. Notice that **Linxconf** warns you if the password is a combination of words that you can find in the dictionary. After entering the password, click the **Dismiss** button in the **Users Accounts** dialog box.

+   To **quit** Linxconf, click the **File** ⋄ **Quit** from the menu in the main window. The **Linxconf** tool displays the **Status of the System** dialog box that asks you if you want to activate the changes. Click the **Do It** button to finish the task and exit **Linxconf**.
