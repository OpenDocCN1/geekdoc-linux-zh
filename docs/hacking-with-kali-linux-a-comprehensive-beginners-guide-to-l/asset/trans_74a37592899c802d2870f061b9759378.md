## VPN、TOR 和代理链是什么，以及如何将它们用于安全

### 什么是 VPN？

VPN 是虚拟专用网络（virtual private network）的缩写，通常由组织使用，以提供对安全组织系统的远程访问。例如，你在家工作，需要访问办公室电脑中的文件或连接到仅通过办公室网络可用的应用程序。如果你的办公室安装了 VPN，并且你的笔记本电脑或家用计算机已配置为连接到它，你可以从办公室获取所需内容，而无需担心通过 Internet 传输的数据的安全性。

VPN 也用于掩盖 Internet 中单个计算机的 IP 地址。这些允许人们匿名浏览 Internet 或访问基于位置限制的服务，如互联网电视。

普通用户最有可能在第二种场景中使用的 VPN。Internet 上提供多种 VPN 服务。对于简单的匿名浏览，你可以找到低至每月 5 美元甚至免费的服务！

但是，要获得完全匿名的体验，建议使用高级 VPN 账户。大多数提供商为潜在客户提供了尽可能简便的体验——无需在 Web 应用程序中配置 IP 地址，无需安装软件，设置 VPN 的说明易于遵循等。

话虽如此，在订阅 VPN 服务之前，请决定你将如何用它：仅仅是浏览网站内容吗？下载种子文件？观看互联网电视？每个提供商都有其服务条款和条件，有些将包括针对“非法”活动的限制，例如 P2P 知识产权保护文件共享。最好在承诺任何事项之前查找并阅读细则。

另一个技巧是寻找为潜在客户提供商试验期的提供商。这表明提供商对其产品有信心，并且你将能够判断服务是否适合你。检查 Internet 速度：速率是否可靠，或者在一天中的某些时间浏览或下载是否不方便？评估其技术支持的时效性和质量：他们在回应问题或帮助请求前需要多长时间？他们多大程度上理解你的关切，并且他们是否提供了帮助？底线：这项服务是否物有所值？

在线论坛是获取特定 VPN 服务提供商反馈的良好来源。客户证词当然是好的，但在那里你很少读到任何负面内容。在在线论坛上，如果你从不同的人那里读到关于某个提供商的大量负面反馈，这可能是一个你不应该与该提供商做生意的迹象。无论如何，你应该在订阅之前尽可能多地获取信息。

### 你需要知道的关于 VPN 服务的一切

什么是 VPN？VPN 是虚拟专用网络（virtual private network）的缩写。可以将其定义为通常用于增加公共和私人网络、互联网和 Wi-Fi 热点隐私和安全性的方法。

VPN 通常由不同类型的公司使用，以保护它们可能拥有的任何敏感数据。然而，如今个人 VPN 选项的使用有所增加。这可以归因于互联网今天面临的各种转变。

当你使用 VPN 时，隐私会得到相当程度的改善。使用 VPN 获得更好隐私的原因是，你可能一直在使用的第一个 IP 地址被你的 VPN 提供商提供的地址所取代。只要 VPN 提供商提供该服务，订阅者有一种出色的方式从他们可能想要的网关城市获取 IP 地址。你可以使用 VPN 来改变你的位置。你可能住在纽约，但你可以使用 VPN 让你看起来像在伦敦等。每个 VPN 提供商都提供不同的网关城市供你选择。
