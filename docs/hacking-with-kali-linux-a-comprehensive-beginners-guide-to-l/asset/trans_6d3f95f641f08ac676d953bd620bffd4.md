此处将解释的所有方法都要求您登录接入点的用户界面并修改其部分选项。如果您不知道如何操作，请访问您的接入点制造商的网站，查找适用于您特定型号的指导手册。请查找关于如何访问该路由器 Web 界面的信息。

## 1. 使用安全加密

使用安全加密是必不可少的措施，这确保了只有使用密码才能连接。通常，这些选项是在无线设置菜单的安全选项卡中选择的。您通常可以从三个或四个选项中选择：禁用、WEP、WPA、WPA2。您应该选择 WPA2 或 WPA——在任何情况下都绝对不要选择“禁用”或 WEP！WEP 加密是一种极其脆弱的加密算法，一个完全没有经验的黑客只需几分钟就能破解它。如果您的路由器仅支持 WEP 加密而不支持 WPA，则应立即更换该路由器。

## 2. 使用强加密密码

我相信你经常听到“使用强密码”这一短语，许多人可能在想，在 Wi-Fi 上这并不太重要——在 Wi-Fi 上，使用强密码至关重要。对于黑客来说，使用扫描数百万种密码组合并在短短几分钟内破解 Wi-Fi 的程序易如反掌。请使用至少 8 到 10 个字符，并混合数字、特殊符号和字母。避免使用日期、姓名或电话号码——这是黑客首先尝试的内容。

## 3. 修改 SSID 名称

SSID 是您的无线网络名称，也是您在尝试加入网络时从附近网络列表中选择的名称。建议修改该名称，不要使用默认名称。将其修改为一个不会暴露该无线网络所有者的名字，例如您的姓氏——如果您居住在高密度人口区域（例如公寓楼），这一点尤其重要。

## 4. 限制 Wi-Fi 范围

限制传输范围会降低有人试图黑客入侵您的网络的可能性。在许多家庭中，无线信号可以在外部检测到，通常没有理由这样做。限制传输范围，走出您的财产范围，看看是否能在外部发现信号。如果可能，您可以将路由器移至家庭中心，以获得最佳覆盖范围，同时避免因有限的无线网络范围造成的盲点。

## 5. 修改路由器的界面安全密码

路由器的密码是每次登录 Web 界面时需要输入的密码。从技术角度看，如果黑客能够连接到接入点的 Web 界面，那就为时已晚，黑客已经获得了无线网络的访问权限，但这是一个很好的预防措施，它将限制黑客对无线网络的 control 能力。

## 6. 检查谁连接到了网络

如果您怀疑有入侵者在使用您的 Wi-Fi，那么大多数无线路由器都具有允许您检查登录到接入点的每个设备的 IP 和 MAC 地址的功能。您可以查看该列表，确保您认识每个设备。此列表通常被称为活动 DHCP 列表或类似名称。

当您实施这些提示时，即使面对最具动机的黑客，您也有很大的胜算。启用这些选项只需很少的时间，而安全性的提升却极其显著。所有提示都很重要。但是，最重要的一条是加密密码；如果您不采纳这条建议，那么您的网络安全性将完全失效。

## 如何检测黑客攻击

大多数计算机漏洞可以通过多种方式被利用。黑客攻击可能使用单一特定的漏洞、同时使用多个漏洞、系统组件中的配置错误，甚至是先前攻击留下的后门。

因此，检测黑客攻击并非易事，尤其是对于不熟练的用户而言。本文提供了一些基本准则，帮助您判断您的计算机是否正受到攻击，或者您的系统安全是否已受损。请记住，就像病毒一样，没有 100% 的保证能通过这种方式检测到黑客攻击。然而，如果您的系统被黑客入侵，它很有可能表现出以下一种或多种行为。

### Windows 机器：

- 异常高的出站网络流量。如果您使用拨号账户或 ADSL，并且注意到网络流量异常高，尤其是在计算机空闲或未专门上传数据时，您的计算机可能已受损。您的计算机可能正被用于发送垃圾邮件，或者被网络蠕虫利用，后者正在复制自身并发送副本。对于电缆连接，这一点不太相关——即使您只是浏览网站或从互联网下载数据，出站流量与入站流量相当也是相当常见的。

- 磁盘活动增加或任何驱动器的根目录下出现可疑文件。入侵系统后，许多黑客会运行大规模扫描，寻找包含银行或支付账户（如 PayPal）密码或登录凭据的新文档或文件。同样，一些蠕虫会搜索包含电子邮件地址的文件用于传播。如果您注意到系统空闲时磁盘活动显著，并且标准文件夹中存在可疑命名的文件，这可能是系统被黑客入侵或恶意软件感染的迹象。

- 来自单一地址的大量数据包被个人防火墙阻止。在定位目标（例如公司的 IP 范围或家庭电缆用户池）后，黑客通常运行自动探测工具，尝试利用各种漏洞入侵系统。如果您运行个人防火墙（这是防止黑客攻击的基本要素），并且注意到来自同一地址的停止数据包数量异常高，那么这是您的机器正在遭受攻击的良好迹象。好消息是，如果您的防火墙正在报告这些攻击，您可能相对安全。在这种情况下，解决方案是暂时阻止肇事 IP，直到连接尝试停止为止。许多个人防火墙和 IDS 都内置了此功能。

- 常驻杀毒软件突然开始报告检测到后门或木马，即使您没有做任何异常操作。虽然黑客攻击可能复杂且具有创新性，但许多攻击依赖于已知的木马或后门来获取受感染系统的完全访问权限。如果您的杀毒软件的常驻组件检测到并报告此类恶意软件，这可能表明您的系统可以从外部访问。

### Unix 机器：

- /tmp 文件夹中的可疑命名文件。Unix 世界中的许多漏洞利用依赖于在 /tmp 标准文件夹中创建临时文件，这些文件在系统黑客入侵后并不总是被删除。对于某些已知感染 Unix 系统的蠕虫也是如此；它们在 /tmp 文件夹中重新编译自身，并将其用作“主目录”。

- 修改过的系统二进制文件，如 'login'、'telnet'、'FTP'、'finger' 或更复杂的服务 'sshd'、'ftpd' 等。入侵系统后，黑客通常试图通过在拥有直接互联网访问权限的服务中植入后门，或修改用于连接其他系统的标准系统工具来确保安全访问。修改过的二进制文件通常是 rootkit 的一部分，并且通常对直接的简单检查具有“隐蔽性”。在所有情况下，保持一个包含所有系统实用程序校验和的数据库，并在系统离线、单用户模式下定期验证它们，是一个好主意。

- 修改的 /etc/passwd、/etc/shadow 或 /etc 文件夹中的其他系统文件。有时，黑客攻击可能会在 /etc/passwd 中添加一个新用户，以便在稍后远程登录。请检查密码文件中的任何可疑用户名，并监控所有添加操作，特别是在多用户系统上。
