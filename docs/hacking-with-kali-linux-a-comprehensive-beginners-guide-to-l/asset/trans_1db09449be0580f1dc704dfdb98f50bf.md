

## 在 OS X 上创建可启动的 Kali USB 驱动器

OS X 基于 UNIX，因此在 OS X 环境中创建可启动的 Kali Linux USB 驱动器与在 Linux 上的操作类似。一旦你下载并验证了所选的 Kali ISO 文件，就可以使用 `dd` 将其复制到 USB 驱动器中。

**警告**：尽管将 Kali 镜像写入 USB 驱动器的过程很简单，但如果你不了解自己正在做什么，或者指定了错误的输出路径，你很可能会用 `dd` 覆盖掉并非打算覆盖的磁盘驱动器。在做之前务必仔细检查操作内容，事后就无法挽回了。

特此警告。

在 USB 驱动器未插入系统的情况下，打开一个终端窗口，并在命令提示符下输入命令 `diskutil list`。

你将获得挂载在系统上的磁盘设备路径（看起来像 `/dev/rdisk0`、`/dev/rdisk1` 等）的列表，以及每个驱动器上分区的相关信息。

将 USB 设备插入 Apple 电脑的 USB 端口，并第二次运行命令 `diskutil list`。你的 USB 驱动器的路径很可能是最后一个。无论如何，它将是之前不存在的某个路径。在本示例中，你可以看到现在有一个 `/dev/disk6`，之前并不存在。

卸载该驱动器（在此示例中，USB 键是 `/dev/disk6` — 不要直接复制此路径，请验证你系统上的正确路径！）：

```bash
diskutil unmount /dev/disk6
```

接下来（小心地！）将 Kali ISO 文件写入 USB 设备。以下命令假设你的 USB 驱动器位于路径 `/dev/disk6`，且你当前目录包含名为“Kali-Linux-2017.1-amd64.iso”的 Kali Linux ISO 文件：

```bash
sudo dd if=Kali-Linux-2017.1-amd64.iso of=/dev/disk6 bs=1m
```

注意：增加块大小（`bs`）会加速写入进度，但也会增加创建损坏 USB 驱动器的风险。在 OS X 上使用给定的值已始终产生良好的镜像效果。

镜像写入 USB 驱动器可能需要相当长的时间，超过半小时并不罕见，如下面的示例输出所示。请耐心等待！

`dd` 命令在未完成之前不会提供任何反馈，但如果你的驱动器有访问指示灯，你可能会不时看到它闪烁。写入镜像所需的时间取决于所用系统的速度、USB 驱动器本身以及插入的 USB 端口。当 `dd` 完成镜像写入后，它会输出类似以下内容：

```text
2911+1 records in
2911+1 records out
3053371392 bytes transferred in 2151.132182 secs (1419425 bytes/sec)
```

就这样了！你现在可以使用该 USB 设备启动进入 Kali Live / 安装环境。

要在 OS X 系统上从备用驱动器启动，请在设备开机后立即按下 Option 键以调出启动菜单，并选择你要使用的驱动器。

## 无线网络黑客入门及网络扫描方法

### 无线网络类型与安全

如今，无线网络连接越来越普及。这种连接方式设置简单，且大多数情况下，只要设置正确，可靠性较高。许多家庭甚至办公室都使用无线网络连接。然而，未受保护的无线网络对于无线连接窃取者和窃听者而言是危险的。了解两种无线网络设置类型以及保护无线连接的两种方法。

### 基础设施无线网络连接

有两种类型的无线网络连接：基础设施网络连接和 Ad-hoc 网络连接。基础设施网络使用路由器或网关，为每个设备提供 IP 地址并共享互联网连接。例如，你有一台台式机和一台笔记本电脑。要让计算机或台式机无线连接，路由器或网关必须具备无线功能。标准设置是调制解调器连接到路由器，然后笔记本电脑和台式机可以通过有线或无线方式连接。

### Ad-hoc 无线网络连接

这种连接类型不需要路由器或网关。Ad-hoc 连接涉及两个直接通信的无线设备。一个好的例子是两台笔记本电脑。你可以在其中一台计算机上设置 Ad-hoc 连接。其中一台机器将充当服务器，并广播其 Ad-hoc 名称。第二台计算机将扫描 Ad-hoc 信号，并应检测到第一台计算机。你将获得连接到 Ad-hoc 网络的选项。

### 无线安全

你的路由器广播的无线信号可以是受保护的或不受保护的。未受保护的消息允许未经授权的用戶连接到你的信号并获得免费的互联网连接。如果大量未授权用户连接到你的路由器，会消耗你的带宽，导致互联网速度变慢。更不用说，由于你已经连接到同一个网络，他们还可以入侵你的计算机。

### 有线等效隐私 (WEP)、Wi-Fi 保护访问 (WPA) 及 MAC 地址

这种无线安全方式因其简单性而被广泛使用。WEP 和 WPA 都允许用户生成密码，并由此密码转换为十进制或十六进制。由密码生成的字符串更长。因此它们很安全。

无线适配器有一个称为媒体访问控制 (MAC) 地址的唯一识别号。未注册的 MAC 地址将不被路由器允许连接。

### 保护家庭无线网络并将黑客拒之门外

家庭无线网络最重要的功能之一，却也是最容易被忽视的功能，就是安全。许多人只担心文件共享和网络打印。但许多人低估了安全的必要性或对此缺乏理解。安全性很重要，因为与传统有线网络不同，无线信号在更宽的频谱上传输，因此容易被截获。

随着身份盗窃威胁的不断增长，你需要采取必要的步骤来保护家庭无线网络。对你的个人信息存在轻微威胁和重大威胁。在轻微威胁方面，入侵者可以轻松连接到你的未受保护的无线网络并免费使用互联网访问。这些被称为“搭便车”。这些对你的隐私构成轻微威胁。

重大威胁是寻找攻击你的网络、入侵并访问你的文件和个人数据的数据的黑客。一旦他们做到了这一点，他们可以迅速开始窃取你的身份，或者将其出售给愿意这么做的人。

无线安全可以通过遵循一些准则快速实施。其中一个基本功能是 MAC 地址过滤。每台计算机都有一个唯一的 MAC 地址。在你的网络配置中，你输入你的 PC 和笔记本电脑的 MAC 地址。任何在你的网络中指定的其他设备将被阻止访问。

另一个重要的网络安全功能是禁用 SSID（即你的网络名称）的广播。最好参考制造商的文档以了解具体细节。大多数必需的安全功能都内置在无线路由器中，这是需要首先确保安全的一点。许多安全设置默认是关闭的。确保你打开它们以获得最佳安全性。

如果你有时间，可以自己保护和管理网络，或者你可以购买一个家庭网络软件包来自动完成这些工作。有一些优秀的程序价格在 30 美元以下，可以保护并修复你的家庭网络。

### 设置安全的家庭无线网络 - 保护隐私的 2 个简单步骤

保护家庭无线网络是一个两步过程。第一步是通过保护无线接入点或路由器来确保网络安全。通常可以通过在设备的基于 Web 的软件界面中输入默认地址 '192.168.0.1' 或 '192.168.1.1' 来完成所有这些操作。

需要更改的第一件事是管理员用户名和密码。许多网络被黑客攻击，仅仅是因为没有人费心更改默认值。这就像大多数 VCR 仍在闪烁中午一样，因为没有人调好时间。完成后，启用 MAC 地址过滤，并根据其 MAC 地址添加计算机。此选项将仅允许指定的计算机连接到网络，但不会保证完全安全。

网络 SSID 定义了网络的名称。此值的默认值应更改为一个松散且长的字符串。应将此值记录在安全的地方，并输入到允许连接的机器中。禁用网络 SSID 的广播也提供了额外的安全层，因为网络不会向外部人员宣传自己。

还应启用加密。默认加密通常较弱，容易破解。通常使用 WEP（有线等效隐私）进行数据加密。然而，在可用的情况下，请尝试使用 WPA-PSK 加密。该方法使用 256 位加密来传输数据，并且密钥也会改变，因此与 WEP 相比，它提供了安全得多的替代方案。
