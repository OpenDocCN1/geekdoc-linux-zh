# How to Secure wireless networks

In minimizing wireless network attacks; an organization can adopt the following policies
Changing default passwords that come with the hardware
Enabling the authentication mechanism
Access to the system can restrict by allowing only registered MAC addresses.
Use of strong WEP and WPA-PSK keys, a combination of symbols, number, and characters reduce the chance of the keys been cracking using a dictionary and brute force attacks.
Firewall Software can also help reduce unauthorized access.
