
## 第二章
## 如何安装 KALI LINUX 以及如何制作 KALI 可启动 USB 驱动器

有时，我们拥有敏感数据，并倾向于使用全磁盘加密进行加密。使用 Kali 安装程序，您可以启动 LVM 加密安装，目标可以是硬盘或 USB 驱动器。安装过程与“常规 Kali Linux 安装”非常相似，只是在安装过程中需要选择加密的 LVM 分区。

### Kali Linux 加密安装要求

在您的计算机上安装 Kali Linux 是一个自然的过程。首先，您需要兼容的计算机硬件。硬件要求很低，如下所列，但性能更好的设备自然会提供更好的性能。i386 映像默认为 PAE 内核，因此您可以在拥有超过 4GB 内存的系统上运行。下载 Kali Linux，然后将 ISO 烧录到 DVD 或准备一个装有 Kali Linux Live 的 USB 驱动器作为安装介质。

### 安装先决条件

- Kali Linux 安装至少需要 20 GB 的磁盘空间。
- 对于 i386 和 amd64 架构的 RAM，最低要求：1GB，推荐：2GB 或更多。
- CD-DVD 驱动器 / USB 启动支持

### 安装准备

- 下载 Kali Linux。
- 将 Kali Linux ISO 烧录到 DVD 或将 Kali Linux Live 映像写入 USB。
- 确保您的计算机在 BIOS 中设置为从 CD / USB 启动。

要开始安装，请使用您选择的安装介质启动。最好您能看到 Kali Linux 启动菜单。选择图形界面或文本模式安装。在本例中，我们决定进行 GUI 安装。

选择您首选的语言，然后选择您的国家/地区位置。系统还会提示您使用适当的键盘映射配置键盘。

安装程序会将映像复制到您的硬盘，探测您的网络接口，然后提示您输入系统的主机名。在下面的示例中，我们输入了 "kali" 作为主机名。

为 root 账户输入一个强密码。

安装程序现在将探测您的磁盘并提供四个选项。对于加密 LVM 安装，选择“引导 – 使用整个磁盘并设置加密 LVM”选项，如下所示。

选择安装 Kali 的目标驱动器。在这种情况下，我们选择了一个 USB 驱动器作为目标。我们将使用这个 USB 驱动器来启动加密版本的 Kali。

确认您的分区方案并继续安装。

## 如何制作 KALI 可启动 USB 驱动器

### 制作 Kali 可启动 USB 驱动器

我们最快且最喜爱的启动 Kali Linux 的方法是从 USB 驱动器“实时”运行它。这种方法有几个优势：

- 它是非破坏性的——它不会更改主机系统的硬盘或已安装的操作系统，要恢复正常操作，只需移除“Kali Live” USB 驱动器并重启系统即可。
- 它是便携的——您可以将 Kali Linux 放在口袋里，并在可用的系统上几分钟内让它运行起来。
- 它是可定制的——您可以制作自定义的 Kali Linux ISO 映像，并使用相同的程序将其放入 USB 驱动器。
- 它是潜在持久的——稍加努力，您可以配置 Kali Linux“实时” USB 驱动器具有持久存储，这样您收集的数据在重启后会被保存。

为此，我们首先需要创建一个可启动的 USB 驱动器，该驱动器已由 Kali Linux 的 ISO 映像设置好。

### 您需要什么

最新 Kali 版本中适当 ISO 映像的经过验证的副本，该版本针对您要运行的系统进行了建模：请参阅下载官方 Kali Linux 映像的详细信息。

如果您在 Windows 下运行，您还需要下载 Win32 Disk Imager 实用工具。在 Linux 和 OS X 上，您可以使用预装在那些平台上的 dd 命令。

一个 4GB 或更大的 USB 拇指驱动器。（具有直接 SD 卡插槽的系统可以使用容量类似的 SD 卡。程序是相同的。）

### Kali Linux Live USB 安装步骤

此程序的具体细节将根据您是在 Windows、Linux 还是 OS X 系统上进行操作而有所不同。

#### 在 Windows 上创建可启动的 Kali USB 驱动器

将您的 USB 驱动器插入 Windows PC 上的可用 USB 端口，记录它挂载时使用的驱动器标识符（例如，“F:\”），并启动您下载的 Win32 Disk Imager 软件。

选择要映像化的 Kali Linux ISO 文件，并确认要覆盖的 USB 驱动器是正确的。点击“写入”按钮。

映像完成后，从 Windows 机器上安全弹出 USB 驱动器。现在您可以使用该 USB 设备启动进入 Kali Linux。

#### 在 Linux 上创建可启动的 Kali USB 驱动器

在 Linux 环境中创建可启动的 Kali Linux USB 键很简单。一旦您下载并验证了 Kali ISO 文件，您可以使用 dd 命令按照以下程序将其复制到您的 USB 驱动器中。请注意，您需要以 root 身份运行，或使用 sudo 执行 dd 命令。以下示例假设是 Linux Mint 17.1 桌面环境——根据您使用的发行版，一些具体细节可能略有不同，但总体思路应该非常相似。

警告：虽然将 Kali Linux 映像化到 USB 驱动器的过程很直接，但如果您不理解自己在做什么，或者指定了错误的输出路径，您同样可以轻易地用 dd 覆盖您本不打算覆盖的磁盘驱动器。在做之前仔细检查您在做什么，因为之后为时已晚。

特此警告。

首先，您需要识别用于将映像写入 USB 驱动器的设备路径。在未插入 USB 驱动器的情况下，执行命令：

```
sudo fdisk -l
```

在终端窗口的命令提示符下（如果您没有使用提升的特权运行 fdisk，您将不会得到任何输出）。您将获得如下所示的输出（不完全相同），显示一个单独的驱动器——“/dev/sda”——包含三个分区（/dev/sda1、/dev/sda2 和 /dev/sda5）：

现在，将您的 USB 驱动器插入系统上的可用 USB 端口，并第二次运行相同命令 “sudo fdisk -l”。现在，输出将如下所示（再次，不完全相同），显示一个之前没有的额外设备，在此示例中为 “/dev/sdb”，一个 16GB 的 USB 驱动器：

继续（小心地！）将 Kali ISO 文件映像到 USB 设备上。下面的示例命令假设您要写入的 ISO 映像名为 “Kali-Linux-2017.1-amd64.iso”，并且位于您当前的工作目录中。可以增大块大小参数，虽然它可能会加快 dd 命令的运行速度，但根据系统和许多不同因素，它有时会产生无法启动的 USB 驱动器。推荐的值 “bs=512k” 是保守且可靠的。

```
dd if=kali-Linux-2017.1-amd64.iso of=/dev/sdb bs=512k
```

对 USB 驱动器进行映像化可能需要相当长的时间，超过十分钟并不罕见，如下面的示例输出所示。请耐心！

dd 命令在完成之前不会提供反馈，但如果您的驱动器有访问指示灯，您可能会看到它不时闪烁。dd 映像化完成所需时间取决于所用系统的速度、USB 驱动器本身以及插入的 USB 端口，一旦 dd 完成驱动器的映像化，它将输出类似这样的内容：

```
5823+1 records in
5823+1 records out
```
