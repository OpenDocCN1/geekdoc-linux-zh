能够以这种方式控制你电脑的黑客可以随时开始在你的系统中活动。然而，他们通常会等到电脑长时间闲置（例如在凌晨时分）后才会开始使用它。因此，在晚上关闭电脑并物理断开其与互联网的connection至关重要。

黑客会利用他们远程打开和关闭程序的能力入侵你的银行账户并转移资金、买卖你的股票和股份，并实施各种其他恶意行为来窃取你的财富。

**应对措施：** 如果你的电脑某天晚上突然开始自动运行，你应该尽快将其关闭。但是，在关闭之前，先弄清楚黑客的兴趣所在以及他们试图做什么。如果你手头有数码相机或智能手机，拍摄几张屏幕照片以记录黑客正在进行的操作。

关闭电脑后，将其从互联网断开，并寻求专业帮助。要解决这个问题，你需要来自在线电脑维护公司的专家协助。

但在求助之前，请使用另一台已知状态良好的电脑更改你所有在线账户的登录信息。检查你的银行账户、股票经纪账户。如果你发现丢失了金钱或其他贵重物品，请报警并进行投诉。

你必须认真对待这种攻击，如果需要进行彻底清理和重新安装操作系统及应用程序，这是你唯一应该选择恢复选项。

但在执行此操作之前，如果你遭受了经济损失，请允许取证团队访问你的电脑，以便他们检查发生了什么。你可能需要他们的报告，以便从保险公司、银行、经纪人或在线商户处追回你的经济损失。

## [6] 防病毒软件、任务管理器或注册表编辑器被禁用且无法重启

意外情况时有发生，这三个应用程序中的某一个可能会自行发生故障。在百万分之一的巧合中，其中两个可能会同时出错。但当三者同时失灵时，问题就严重了。

许多恶意软件确实会试图通过降低这三个应用程序的功能来保护自身，导致它们无法启动，或者只能在受限状态下启动。**应对措施：** 你无法确定具体发生了什么，因此你应该对电脑系统进行完全恢复。
