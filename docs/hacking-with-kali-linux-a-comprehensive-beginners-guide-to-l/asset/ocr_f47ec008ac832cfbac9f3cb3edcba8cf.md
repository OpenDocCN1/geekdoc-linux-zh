### HOW TO HACK A WIRELESS NETWORK

How to Hack WiFi (Wireless) Network

Wireless networks are accessible to anyone within the router’s transmission radius. These make them vulnerable to attacks. Hotspots are available in public places such as airports, restaurants, parks, etc.

In this tutorial, we will introduce you to conventional techniques used to exploit weaknesses in wireless network security implementations. We will also look at some of the countermeasures you can put in place to protect against such attacks.

What is a wireless network?

A wireless network is a network that uses radio waves to link computers and other devices together. The implementation is done at Layer 1 (physical layer) of the OSI model.

How to access a wireless network?

You will need a wireless network-enabled device such as a laptop, tablet, smartphones, etc. You will also need to be within the transmission radius of a wireless network access point. Most devices (if the wireless network option is turned on) will provide you with a list of available networks. If the system is not password protected, then you have to click on connect. If it is password protected, then you will need the password to gain access.

Wireless Network Authentication

Since the network is easily accessible to everyone with a wireless network-enabled device, most systems are password protected. Let’s look at some of the most commonly used authentication techniques.
