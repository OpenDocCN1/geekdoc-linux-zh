据报道，互联网服务提供商（ISPs）已对 Tor 用户的带宽进行节流，甚至已联系客户告知他们停止使用 Tor 浏览器。用户可能会受到 ISP 的询问，了解他们通过 Tor 连接到哪些网站。

当局本身可能会对 Tor 用户产生怀疑，并仅基于此对他们在 Tor 上的活动进行调查，尽管目前没有关于对使用 Tor 进行罚款或指控的报道。

### 使用 Tor 有任何缺点吗？

Tor 在许多用户中很受欢迎——目前，在任何给定时间都有大约 200 万用户连接到中继节点。

但它确实存在一些缺点。以下是使用 Tor 的主要缺点：
-   速度缓慢
-   可被 ISP 检测
-   被网络管理员封锁
-   易受攻击

让我们更详细地看看这些问题。

### 速度缓慢

使用 Tor 的主要缺点是它相当安静（流量分散）。流量不会直接到达其目的地，因此这会减慢速度。此外，节点之间流动的流量速度可能比你的常规互联网连接更慢，这进一步削弱了整体势头。

更重要的是，与通过网络流动的流量相比，可用的志愿者节点数量很少。由此产生的拥塞将减慢流量，尤其是在高峰时段。

由于这些问题，Tor 的主要用途是一般浏览。它不适合流媒体或种子下载，也不适合任何其他需要大量带宽的活动。

### 可被 ISP 检测

另一个缺点是你的 ISP 能够看到你正在使用 Tor。它无法读取你的流量内容，但检测到你在这一点可能会产生一些后果。如前所述，仅仅使用 Tor 就足以引起 ISP 和当局的怀疑。绕过此问题的一种方法是使用带有 Tor 的 VPN（下文将有更多介绍）。

### 被网络管理员封锁

单个网络的管理员通常会封锁 Tor。绕过此问题的一种方法是使用桥接（bridges），它们不应该被检测为 Tor 节点。如果封锁更加复杂并使用了深度包检查，你可能需要使用额外的工具，例如可插拔传输协议（Pluggable Transports，见下文）。这些工具会将你的 Tor 流量伪装成常规流量，以绕过封锁。

### 易受攻击

虽然尚未得到证实，但有报道称，针对 Tor 的流量分析已成功用于寻找有罪证据。其中一个引人注目的案例是 2013 年的“丝绸之路”行动。丝绸之路是通过 Tor 网络运营的 marketplace，涉及估计价值 10 亿美元的毒品交易，以及其他非法商品和服务。

此外，也要注意上面提到的关于出口节点监控的传闻。请记住，这些报告似乎尚未得到证实，因此可以持怀疑态度看待它们。

## 如何使用 Tor Browser 在线保护你的隐私

如果你想保持网络浏览的私密性，你可以使用 Chrome 的无痕模式、Firefox 的隐私浏览、Microsoft Edge 的 InPrivate 模式等。虽然这会阻止使用你电脑的其他人查看你的浏览历史，但它并不能限制你的 ISP 监控你访问的网站。你可能由于各种原因希望完全匿名地浏览互联网，而这正是 Tor Browser 所提供的。

Tor 代表 The Onion Router（洋葱路由器），它提供多层次的保护，以确保你的在线活动、位置和身份完全私密。以下是安装和使用 Tor Browser 所需遵循的步骤。

### 1. 安装和配置 Tor Browser

首先下载并安装 Tor Browser。安装完成后，点击“完成”，Tor 将首次启动。你会看到一个用于控制如何连接到 Tor 网络的设置对话框。

在大多数情况下，你应该可以点击“连接”按钮，但如果你通过代理连接互联网，则需要点击“配置”按钮以输入你的设置。

### 2. 使用 Tor 上网

在 Tor 通过中继节点建立与网络的连接时会有轻微的延迟——程序警告初始连接可能需要几分钟——但一旦建立连接，Tor 浏览器将启动并准备好使用。

Tor 基于与 Firefox 相同的代码，因此如果你使用过 Mozilla 的网页浏览器，一切似乎都会相当熟悉。即使你以前没有使用过 Firefox，你也不需要太久就能感觉宾至如归——它与 Edge、Chrome 和 Safari 等浏览器并无太大不同。

### 3. 选择你的安全级别

在开始之前，值得注意的是，使用 Tor Browser 是在隐私/安全和网页可用性之间寻求平衡。默认情况下，安全级别设置为“标准”——尽管这仍然比任何其他网页浏览器安全得多。

如果你想增加安全级别，请点击地址栏左侧的洋葱图标并选择“安全设置”。使用“安全级别”滑块选择你首选的保护级别，同时留意关于可能会在你访问的网站停止工作的功能的警告。

### 4. 重新思考你的浏览习惯

为了充分利用 Tor，你需要改变一些浏览习惯——其中第一个就是你使用的搜索引擎。

与其选择 Google 和 Bing 等搜索引擎，建议改为使用 Disconnect.me。这是一个防止搜索引擎在线跟踪你的网站，你可以将其与 Bing、Yahoo 或 DuckDuckGo 一起使用。

既然提到了改变习惯，你还需要避免安装浏览器扩展程序，因为这些扩展程序可能会泄露私人信息。

### 5. 理解 Tor 电路

当你浏览互联网时，Tor 浏览器通过避免直接连接到网站来帮助你保持安全。相反，你的连接会在 Tor 网络上的多个节点之间跳跃，每次跳跃都包含匿名化过程。

这不仅使网站几乎不可能追踪你是谁以及你身在何处，也是导致你在使用 Tor 浏览时注意到稍慢性能的原因。

如果你觉得性能异常低或页面不再响应，你可以通过点击汉堡图标并选择“为此网站创建新的 Tor 电路”选项来开始一个新的 Tor 电路，这将强制 Tor 寻找到该网站的新路线。

### 6. 创建新的身份

新电路选项仅适用于当前活动的标签页，你可能需要更严格的隐私安全网。点击汉堡图标并选择“新身份”，请记住这将关闭并重启 Tor 以获得新的 IP 地址。

当你使用 Tor 连接到网站时，你可能会注意到出现一个弹出窗口，警告你某个特定网站正在尝试做一些可能会用于跟踪你的事情。这些消息出现的频率不仅取决于你访问的网站，还取决于你设置的隐私设置。

### 7. 使用 HTTPS

在线保持安全和匿名的一个重要部分是确保你使用网站的 HTTPS 版本而非 HTTP 版本。为了让你不必记住每个访问的网站都要这样做，Tor Browser 默认安装了 HTTPS Everywhere 扩展程序。如果网站提供安全版本，它将尝试将你重定向到该版本，但你应密切关注地址栏作为额外的保障措施。

如果你连接到安全网站，你将看到一个绿色的锁图标。如果不存在此图标，请点击“i”图标以获取更多信息。

### 8. 访问 .onion 网站

然而，通过 Tor 连接互联网的最安全方式是访问 .onion 网站。这些也被称为隐藏 Tor 服务，搜索引擎无法访问；要找到它们，你必须直接访问。

这些网站只能使用 Tor 访问，但你需要注意——遇到包含非法内容、销售非法产品或推广非法活动的网站相当常见。

### 9. 尝试 Tor over VPN

如果你想将隐私提升到下一个级别，你可以在启动 Tor 浏览器之前连接到 VPN。VPN 无法看到你在 Tor 浏览器中做什么，你将获得额外的好处，即没有 Tor 节点能够看到你的 IP 地址。它还将防止你的网络运营商甚至知道你正在使用 Tor，如果你所在的地区恰好封锁了 Tor 网络，这将很有帮助。
