
# 破解无线网络密钥

破解无线网络密钥需要上文提到的耐心和大量资源。至少，你需要以下工具：

- 具有数据包注入功能的无线网络适配器（硬件）
- Kali 操作系统
- 位于目标网络的辐射范围内。如果目标网络的用户正在积极使用并连接该网络，那么破解成功的几率将显著提高。
- 耐心，根据几个因素，破解密钥可能需要一些时间，其中一些因素可能超出了你的控制范围。超出控制范围的因素包括你嗅探数据包时，目标网络的用户正在积极使用该网络。

## 如何保障无线网络的安全

为了减少无线网络攻击，组织可以采取以下策略：

- 更改随硬件附带的默认密码
- 启用身份验证机制
- 通过仅允许已注册的 MAC 地址来限制系统访问。
- 使用强大的 WEP 和 WPA-PSK 密钥，符号、数字和字符的组合会降低密钥被字典攻击和暴力破解攻克的几率。
- 防火墙软件也可以帮助减少未授权的访问。

## 总结

- 外部人员可以看到无线网络传输波；这带来了许多安全风险。
- WEP 是 Wired Equivalent Privacy（有线等效隐私）的缩写。它存在安全缺陷，与其他安全实现相比更容易被破解。
- WPA 是 Wi-Fi Protected Access（Wi-Fi 保护接入）的缩写。与 WEP 相比，它更安全。
- 入侵检测系统有助于检测未授权的访问。
- 良好的安全策略有助于保护网络。

## 什么是道德黑客 EC0-350 认证考试？

道德黑客与对策 6（CEHv6）认证也称为 EC0-350 考试。该考试由 EC-Council 主办，是道德黑客领域最负盛名的认证之一。

在当今快速变化的经济环境中，安全的重要性日益凸显。任何组织的 IT 部门都是黑客最寻求且最脆弱的领域。正是 IT 决定了许多组织的工作方式，其安全上的任何漏洞都令人头疼。无论是银行、金融、制造、生产、软件、电信、电影、娱乐还是航空业，数据和机密信息的安全性正变得越来越重要。竞争对手不择手段地试图获取对手的内部情报。

据估计，到 2010-2011 年，各行业需要近 200 万名道德黑客，以保护其资产免受危险和反社会分子的侵害。

在 9/11 美国恐怖袭击事件之后，国际电子商务顾问委员会或 EC-Council 成立，旨在提供应对全球此类信息系统攻击所需的缓冲。这一组织很快得到了全球各领域专家的 ủng持，并据此开发了多项认证和标准。

道德黑客与对策 6 是这些认证之一，旨在面向那些在该领域寻求长期职业生涯的爱好者。挫败任何黑客意图的决心以及编程领域的专业知识是该认证的唯一先决条件。

EC0-350 考试总共包含 150 个问题，分配给答题的总时间为 4 小时。该考试的及格百分比为 70%。

成功的考生可以申请道德黑客认证（Certified Ethical Hacker）和安全科学硕士认证（Master of Security Science）。

## 深入审视网络罪犯

我在家工作，这是我能想到的最宁静的职场。作为一名家庭主妇和兼职自由撰稿人，我提交文章，订阅各种正规写作通讯，并进行无止境的在线研究。但在注册之前，我会阅读隐私政策，有些简短，有些则冗长乏味。

我只是数百万匿名但诚实的互联网用户之一。在我看来，我为什么要如此担心互联网社区中的任何人对我进行恶意戏弄或骚扰？

尽管如此，知道那些引起我兴趣的网站在安全方面运行着严格的政策感，让我感到安心。

但几个月前，当我的电脑屏幕开始闪烁，仿佛在喘息，然后慢慢死机时，我以为是电流波动。但当我的文件消失，电脑变得异常不配合时，我将此案交给专家，即我的丈夫。

我第一次被计算机病毒感染了。

事情并不是像拔掉电脑连接，睡几天觉，让电脑外科医生处理损坏，让一切恢复如初那么简单。

我看到几个月辛勤的研究、完成的手稿存储在我的硬盘里、花费在网上的漫长时间、我的配偶为建立整个系统所投入的时间、金钱和精力，全部付诸东流，变得一无所有。

经历修复和重建的过程是痛苦且繁琐的，耗时且昂贵。

随后发生的一系列令人不安却又颇具趣味的网络入侵促使我满足好奇心，并对驱动这些破坏性网络追求及使诚实互联网用户生活困苦的其它电子小罪行的行为背后的动机进行个人研究。

## 网络罪犯

任何未经你同意进入你家的人理论上都在实施违法行为。你的计算机系统是你边界的延伸，不容侵犯。当某人以任何方式获得对你计算机的未授权访问，或利用计算机技术实施重罪时，他/她就犯了网络犯罪。

一提到网络空间的违规行为，黑客总是第一个进入脑海的人。毕竟，还有谁能有知识储备且足够大胆去闯入别人的计算机系统呢？

黑客曾经有更崇高的目标。在计算机技术的早期，他们是计算机专家/天才，在所有者同意下测试计算机系统，查找漏洞，并推荐更好的程序或自行修复错误，以挫败利用缺陷系统更危险的“生物”的努力。他们甚至有自己的黑客行为准则。

有两种类型的黑客：道德专业人士，这些是高技能的专业人士，他们将技能租赁给关注自身网络安全性的组织。他们代表了早期一代的 hackers。另一种类型是 CyberRamboes 或单纯的破解者——被精英黑客所鄙视。破解者为了肤浅的原因破坏系统。（UC 圣地亚哥分校心理学部：计算机与网络资源）

无论他们被称为什么，这些网络罪犯对他们的受害者来说已变得完全匿名且无名的“黑客”。

- **新手/工具包（NT）**：黑客新手，计算机/编程能力有限；依赖互联网上现成的软件（工具包）；
- **内部人员（IT）**：对公司内部系统运作熟练的失望员工或前员工；
