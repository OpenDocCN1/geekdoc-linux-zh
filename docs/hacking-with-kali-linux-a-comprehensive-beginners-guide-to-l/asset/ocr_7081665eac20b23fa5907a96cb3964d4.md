Sometimes we install a proxy server, but only specific programs such as Firefox and Google chrome provide proxy settings. Luckily, we can use a command-line utility called proxy chains to redirect any application to go through our proxy server. This tutorial will show you how to set it up on Debian, Ubuntu, OpenSUSE, Fedora, CentOS/Redhat, Arch Linux, and their derivatives.

If you don’t know how to set up a proxy server, then check out this post to learn shadowsocks proxy. After that, come back here.

Install proxy chains on Linux

Debian/Ubuntu/Linux Mint/Elementary O S

```
sudo apt-get install proxy chains
```

OpenSUSE Leap 42.1

Proxy chains are available from the packman repository.

```
sudo zypper install proxy chains
```

Fedora

```
sudo dnf install proxy chains
```

CentOS/Redhat

```
sudo yum install proxy chains
```

Archlinux

```
sudo Pacman -S proxy chains-ng
```

On Kali Linux, proxy chains are installed by default.

Add a Proxy Server to Proxychains

Open the configuration file.

```
sudo nano /etc/proxychains.conf
```

At the end of the file, add your proxy like this

```
socks5 127.0.0.1 1080
```
