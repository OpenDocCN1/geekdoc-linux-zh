## 引言

### 道德黑客 – 为什么需要学习

这个过程由计算机和网络专家完成，他们被称为道德或白帽黑客。这些人分析和攻击组织的安全系统，以发现并暴露那些可以被破解者利用的弱点。理解与破解者不同，道德黑客在测试信息系统的安全性之前会获得相关当局的许可，这一点至关重要。Cookie（此处原文可能存在误译，通常指黑客或恶意软件）会对组织造成伤害和损失，并对信息系统的完整性、可用性和机密性产生负面影响。那么，道德黑客的概念是如何产生的，又是如何实施的？

道德黑客领域在计算机世界中已经存在了一段时间。如今，由于计算机资源和互联网可用性及使用量的增加，该主题继续受到广泛关注。这种计算机基础设施的增长和扩展提供了另一种互动途径，因此吸引了商业和政府中的大型组织。这些机构希望充分利用技术带来的好处，以提高他们向客户提供的服务质量。例如，组织希望利用互联网进行电子商务和广告等。

另一方面，政府希望利用这些资源向公民分发信息。组织担心其计算机信息系统被破解并被未经授权的人员访问的可能性。另一方面，这些服务的潜在客户和用户担心他们被要求提供的信息的安全性。他们担心这些信息，如信用卡号、社会安全号、家庭住址和联系人，将被入侵者或外人访问，并被用于原本意图之外的其他目的。这样做，他们的隐私将受到干扰，这是许多人，如果不是所有人的话，所不希望的。

由于上述提到的担忧，组织寻求寻找一种方法来接近和解决这一问题。他们发现，限制和控制未经授权个人对安全系统构成的威胁的最佳方法之一，是聘请独立的安全专业人员来测试系统的安全措施。在此方案中，黑客使用与入侵者相同的工具和技术，但他们不破坏系统，也不从中窃取数据。他们评估系统并向所有者报告其系统容易遭受的漏洞。他们还建议需要对系统做些什么以使其更安全。

如上所述，道德黑客与安全强化是相辅相成的。虽然它在提高安全方面做了很多工作，但仍需做更多。获得绝对安全是不可能的，但是，对计算机安全无所作为是危险且不可取的。

## 提升你的网络安全 - 初学者指南

最近的一项 Eurobarometer（欧洲晴雨表）民调揭示了一些相对令人担忧的统计数据。首先，约 10% 的欧洲互联网用户在某种形式上经历过网络欺诈或身份盗窃，并且 74% 的受访者认为网络犯罪是“日益增加的风险”。其次，只有略高于 50% 的人在电脑上安装了某种防病毒软件，并且 57% 的人会打开来自他们不认识的地址的电子邮件。

McAfee 在另一项研究中，最近公布了一份其认为明年主要在线威胁的列表。在提及的风险中，它提到了作为公司目标员工的“门户”绕过安全防线，以及旨在窃取银行信息的高级病毒。这些与 Eurobarometer 民调的结果相结合，对欧洲公民构成了令人担忧的风险。如果受访者意识到了互联网固有的危险，但却没有采取保护措施，那么可能的原因只有少数几种。首先，他们不感到受到网络犯罪的威胁；然而，鉴于有 10% 的人曾是此类犯罪的受害者，这一原则不太可能是普遍适用的。第二种可能性是，在保护方面存在广泛的意识缺乏。研究发现，即使是最基本的安全协议也被忽视，因此，我们将考察一些适合初学者的安全技巧。

### 防病毒软件

虽然你选择的操作系统可能具有内置软件来处理特定威胁，但如果没有安装完整、专用的防病毒程序，很难获得针对不断变化的病毒世界频繁更新的保护。许多此类软件可以便宜购买，并收取年度费用，但如果你负担不起，那么有很多可靠的提供商提供其产品的免费版本。任何保护都比没有保护好。

### 常识

作为一般法则，不要打开那些你未预期的或来自你不认识的地址的电子邮件。然而，无论来源如何，使用电子邮件时都要谨慎。某些病毒可以访问你朋友的电子邮件账户，并转发充满病毒的垃圾邮件给该地址簿中的所有人。如果你突然收到来自朋友的消息，也许只需快速核实一下那是不是真的。

### 安全上的谨慎

许多网站和在线服务要求用户注册账户并提供密码，这是好事：它们保护你的详细信息（以及你在那里保存的任何其他内容）。然而，要谨慎使用一个“通用”密码。如果黑客掌握了它，他们将能够访问所有内容，甚至可以利用它更改你的详细信息，并将你锁在你的账户之外。修复此类损害将非常耗时。

### 警惕“云存储”

云存储是一种完全在线进行的数据存储形式。它向用户提供免费或廉价使用其服务器的机会，许多人用它来“归档”文档等。这是一项创新且有用的服务。然而，要警惕在“云”中存储任何包含个人或机密信息的内容，因为它因不安全而声名狼藉。

## 学习网络安全基础

如今，电脑已成为我们生活中不可或缺的一部分。这要求 IT 专业人员对 IT 安全基础有很好的理解。这些安全基础需要了解保护信息保密性、完整性和可用性所需的控制措施。

如果没有健康的控制措施，网络黑客和网络犯罪分子可以威胁系统、泄露信息，并可能中断运营。这类攻击会造成严重的业务损失。网络犯罪分子和网络黑客可以攻击防火墙、IDS（入侵检测系统）和访问控制以进入网络，从而造成严重损害。网络犯罪的问题催生了对网络安全培训和动态控制的需求，以保护数据。任何考虑学习网络安全基础的人都可以学习敏感企业数据的正确处理方法。

此类培训的目的是解决 IT 安全与保护、处理信息的人员职责、数据可用性与保密性，以及如何处理未经授权的数据修改、中断、破坏和信息滥用等问题。

任何网络安全基础培训必须涵盖网络安全与管理、安全软件开发、电子取证和渗透测试等方面。以下是此类课程至少应包含的内容：

- 安全区域的基本元素，以便你了解纵深防御
- 审计要求

看起来你每看新闻，都会了解到新的重大安全漏洞或企业黑客攻击丑闻。心脏滴血（Heartbleed）和 Shellshock 事件让许多互联网用户感到恐惧，很快，关于增强网络安全的文章便铺天盖地出现。由于小型企业的业务在很大程度上基于网络，因此企业主在网络安全方面尤其需要精明和敏感。以下是你需要了解的有关保持在线业务安全的事项，以及发生安全泄露时应采取的措施。



## 网络安全建议

- 没有哪家企业小到不会受到黑客攻击。根据国家网络安全联盟的数据，71% 的网络攻击针对小型企业，近半数的受访小型企业报告称曾遭到攻击。更令人担忧的是，益博睿（Experian）发现，60% 遭受网络攻击的小型企业在六个月内倒闭。NCSA 指出小型企业经常成为目标的原因有三点：它们没有资源应对攻击；像信用卡号等信息通常保护力度较弱；小型企业可能与大型公司合作，从而让黑客有机会接触到这些公司。

- 确保所有处理公司网络或任何公司数据的设备都安装了可靠的反病毒和反恶意软件。这些是针对恶意文件和其他攻击的基本且容易忽视的预防措施。你的网络还应配备防火墙，以保护整个网络。

- 教育你的员工。除了确保公司每个人都熟悉你的安全系统外，对员工进行基本的互联网安全和安全培训可能也是很有用的。有很多在线资源可以提高人们对钓鱼诈骗、安全证书和其他网络安全基础知识的认识。

- 创建强密码。对于系统中任何需要密码的资源，请创建（并要求员工创建）复杂的密码，使其不受社会工程攻击或容易猜测的影响。网上有许多关于如何创建强密码的指南可供参考。

- 如果你经常处理敏感信息，请使用加密软件。这样，即使你的数据被泄露，黑客也无法读取它。

- 限制系统上的管理员权限。为没有管理员权限的员工设置适当的访问边界，特别是在使用非公司设备时。将管理员权限限制在需要的人员范围内，并按时间和地点限制对敏感信息的访问。

- 研究网络保险。网络安全泄露通常不在责任保险的覆盖范围内，但如果你希望保护敏感数据，请咨询保险代理人了解你的选择。

- 每周备份你的数据，要么备份到安全的云位置，要么备份到外部硬盘。这样，如果你的服务器宕机，你仍然可以访问你的数据。Boardroom Executive Suites 提供的 SkySuite 云计算服务在此领域是一个理想的工具。

- 如果你确定发生了安全泄露，请确定攻击的范围。这是聘请网络安全专家顾问的最佳时机。这将使你了解需要减轻哪些损害，并指出这是一次通用的批量攻击还是专门针对性的攻击。

- 一旦完成这项调查，将所有系统离线以遏制损害。

- 修复受影响的系统。你可以使用主光盘重新安装设备上的程序。然后，在顾问的帮助下，找出安全系统中的漏洞。为了防止再次发生攻击，请将此作为一次学习经验来加强你的保护措施。

- 与客户沟通时，要诚实、透明且及时。让他们知道发生了什么，以及你正在采取什么措施来修复它。

## 大多数公司犯下的 5 个网络安全错误

网络安全是每个人的责任，而不仅仅是信息技术专业人士的责任。与个人安全一样，个人必须关注周围的环境和自己的行为。

关于网络安全，企业和员工在多个领域未能给予足够关注。这些领域没有重要性排序，因为所有方面都很关键。

### 员工缺乏培训

当我们养育孩子时，我们会确保他们知道过马路前要看两边，不要接受陌生人的糖果，也绝不与陌生人上车。对我们所有人来说，这些都是常识，因为我们也接受过同样的教育。

在网络安全方面，同样的原则适用。不要打开来自未知来源的附件。不要访问看起来可疑的网站。不要告诉任何人你的密码。

企业必须确保对所有员工进行关于这些以及其他基本网络安全概念的教育。培训应在新员工入职时进行，并进行年度或半年度复审也是合理的。

### 未能限制/记录访问权限

谁有权访问哪些数据？哪位 IT 管理员修改了目录结构？谁更改了权限？所有员工是否都能访问人事档案？是否有不必要的人员访问财务记录？是否有日志显示谁访问了哪些数据？

这些问题的大部分答案将是“我们不知道”，这是一个需要承认和解决的问题。公司需要利用内置工具来记录访问，并在必要时购买第三方软件以获得更大的控制和粒度。不仅跟踪访问可以防止数据泄露，还能使组织在发生数据丢失时查明发生了什么。

### 关心公司数据

大多数员工关注的是他们的日常工作。他们并不一定关心公司的知识产权。大量员工甚至不知道哪些数据对公司成功至关重要。

员工理解财务和人力资源记录需要保护；但这还不够。

员工还必须了解对公司至关重要的核心数据，以便在处理这些信息以及负责保护该数据的他人时，确保并采取适当的行动。

### 理解网络威胁

钓鱼。欺骗。蠕虫。木马。伪装网络攻击。劫持攻击。这些都是网络安全领域的重要术语，除少数例外，大多数人并不知道这些表达的含义。

除了基础教育外，组织确保员工了解这些攻击是什么以及如何防范也是合理的。有些术语和威胁是个人熟悉的；帮助企业员工理解额外的危险是企业的责任。常识很重要，通过简单的沟通，公司可以确保员工知道要注意什么，并在问题出现时如何行动。

### 把钱花错地方，或者完全不花

很多时候，企业在花钱时关注的是收入生成机会和投资回报率。公司也必须采取防御姿态。这并不意味着只在保护信息资产的网络设备和边缘设备上花钱，而且必须了解威胁的范围并在多个领域进行投资。

防火墙、外网和入侵检测系统都很好；然而，它们只保护公司免受特定类型攻击的影响。企业必须对网络安全采取整体视角并必要地投资。网络安全是一项投资，在预算过程中应被视为如此。

每个人都必须对网络安全负责。在当今世界，重大的数据泄露似乎每周都在发生，影响数百万人，因此关注并共同承担数据保护责任至关重要。

通过教育、日志记录、公司对数据的理解、对威胁的了解以及适当的网络安全投资，公司会发现更大的安全性。当公司具备数据保护时，投资者、员工和消费者将获得安心和明确感，知道他们尽可能安全。

## 如何安装 Kali Linux 以及如何制作 Kali 可启动 USB 驱动器

## 第 3 章

## 无线网络黑客入门及网络扫描方法

### 无线网络类型与安全

如今，无线网络连接越来越普及。这种连接方式设置简单，且大多数情况下，只要设置正确，可靠性较高。许多家庭甚至办公室都使用无线网络连接。然而，未受保护的无线网络对于无线连接窃取者和窃听者而言是危险的。了解两种无线网络设置类型以及保护无线连接的两种方法。

### 基础设施无线网络连接

有两种类型的无线网络连接：基础设施网络连接和 Ad-hoc 网络连接。基础设施网络使用路由器或网关，为每个设备提供 IP 地址并共享互联网连接。例如，你有一台台式机和一台笔记本电脑。要让计算机或台式机无线连接，路由器或网关必须具备无线功能。标准设置是调制解调器连接到路由器，然后笔记本电脑和台式机可以通过有线或无线方式连接。

### Ad-hoc 无线网络连接

这种连接类型不需要路由器或网关。Ad-hoc 连接涉及两个直接通信的无线设备。一个好的例子是两台笔记本电脑。你可以在其中一台计算机上设置 Ad-hoc 连接。其中一台机器将充当服务器，并广播其 Ad-hoc 名称。第二台计算机将扫描 Ad-hoc 信号，并应检测到第一台计算机。你将获得连接到 Ad-hoc 网络的选项。

### 无线安全

你的路由器广播的无线信号可以是受保护的或不受保护的。未受保护的消息允许未经授权的用戶连接到你的信号并获得免费的互联网连接。如果大量未授权用户连接到你的路由器，会消耗你的带宽，导致互联网速度变慢。更不用说，由于你已经连接到同一个网络，他们还可以入侵你的计算机。

### 有线等效隐私 (WEP)、Wi-Fi 保护访问 (WPA) 及 MAC 地址

这种无线安全方式因其简单性而被广泛使用。`WEP` 和 `WPA` 都允许用户生成密码，并由此密码转换为十进制或十六进制。由密码生成的字符串更长。因此它们很安全。

无线适配器有一个称为媒体访问控制 (`MAC`) 地址的唯一识别号。未注册的 `MAC` 地址将不被路由器允许连接。

### 保护家庭无线网络并将黑客拒之门外



家庭无线网络最重要的功能之一，却也是最容易被忽视的功能，就是安全。许多人只担心文件共享和网络打印。但许多人低估了安全的必要性或对此缺乏理解。安全性很重要，因为与传统有线网络不同，无线信号在更宽的频谱上传输，因此容易被截获。

随着身份盗窃威胁的不断增长，你需要采取必要的步骤来保护家庭无线网络。对你的个人信息存在轻微威胁和重大威胁。在轻微威胁方面，入侵者可以轻松连接到你的未受保护的无线网络并免费使用互联网访问。这些被称为“搭便车”。这些对你的隐私构成轻微威胁。

重大威胁是寻找攻击你的网络、入侵并访问你的文件和个人数据的数据的黑客。一旦他们做到了这一点，他们可以迅速开始窃取你的身份，或者将其出售给愿意这么做的人。

无线安全可以通过遵循一些准则快速实施。其中一个基本功能是 `MAC` 地址过滤。每台计算机都有一个唯一的 `MAC` 地址。在你的网络配置中，你输入你的 `PC` 和笔记本电脑的 `MAC` 地址。任何在你的网络中指定的其他设备将被阻止访问。

另一个重要的网络安全功能是禁用 `SSID` 即你的网络名称的广播。最好参考制造商的文档以了解具体细节。大多数必需的安全功能都内置在无线路由器中，这是需要首先确保安全的一点。许多安全设置默认是关闭的。确保你打开它们以获得最佳安全性。

如果你有时间，可以自己保护和管理网络，或者你可以购买一个家庭网络软件包来自动完成这些工作。有一些优秀的程序价格在 30 美元以下，可以保护并修复你的家庭网络。

## 设置安全的家庭无线网络 - 保护隐私的 2 个简单步骤

保护家庭无线网络是一个两步过程。第一步是通过保护无线接入点或路由器来确保网络安全。通常可以通过在设备的基于 Web 的软件界面中输入默认地址 `192.168.0.1` 或 `192.168.1.1` 来完成所有这些操作。

需要更改的第一件事是管理员用户名和密码。许多网络被黑客攻击，仅仅是因为没有人费心更改默认值。这就像大多数 `VCR` 仍在闪烁中午一样，因为没有人调好时间。完成后，启用 `MAC` 地址过滤，并根据其 `MAC` 地址添加计算机。此选项将仅允许指定的计算机连接到网络，但不会保证完全安全。

网络 `SSID` 定义了网络的名称。此值的默认值应更改为一个松散且长的字符串。应将此值记录在安全的地方，并输入到允许连接的机器中。禁用网络 `SSID` 的广播也提供了额外的安全层，因为网络不会向外部人员宣传自己。

还应启用加密。默认加密通常较弱，容易破解。通常使用 `WEP` 有线等效隐私进行数据加密。然而，在可用的情况下，请尝试使用 `WPA-PSK` 加密。该方法使用 256 位加密来传输数据，并且密钥也会改变，因此与 `WEP` 相比，它提供了安全得多的替代方案。

一些路由器内置了防火墙。如果可用，请确保启用此选项。

保护家庭无线网络的第二步是保护每个人的 `PC`。这可以通过安装软件防火墙如果已安装硬件防火墙，则可能并非总是必要、防病毒软件、反垃圾邮件软件以及弹出窗口拦截软件来完成。务必保持这些软件的更新，同时下载你所使用的操作系统和网页浏览器的最新安全更新。

如果你有时间和精力，可以自行管理家庭网络，也可以购买一套家庭组网软件来监控系统，并在发现入侵者或安全漏洞时发出警报，费用大约为30美元。无论选择哪种方式，都要确保你的家庭无线网络得到妥善保护。

## 无线网络的常见问题及手机解决方案

随着无线网络的引入，我们现在看到更少的电线了。手机在很大范围内已经取代了固定电话，而 `WI-FI` 正处于即将取代有线网络的边缘。

如此多的人欣然接受这项服务，原因有很多。无线网络的一些优势包括：
- 赋予设备移动性，这实际上是最大的好处。
- 比有线网络更便宜。在租线、布线和安装方面可以节省大量资金。
- 容易访问且可触达。电线很难跨越河流和山脉，而无线网络没有这样的问题。
- 灵活性强，许多设备可以轻松连接，几乎不需要人工干预。
- 对于任何临时或永久设置，安装都迅速且容易。

现在看看硬币的另一面。无线网络也存在一些缺点。这些缺点包括：
- 有时速度比有线网络低。
- 安全性较低，容易被黑客攻击。由于信号以频率形式传播，人们可以使用黑客技术轻松捕获它们。
- 受周围环境影响，如墙壁、围栏等。
- 经常出现“死区”，即没有网络覆盖的地方。
- 受天气影响极大。降雨和风暴等天气条件会产生非常负面的影响。

公司正在不断努力改进无线网络系统。是的，存在缺点，但通过利用各种可用的解决方案中的任何一种，许多这些劣势是可以消除的。

一些消除负面因素并享受无线覆盖的方法包括：
- 更换网络
有时罪魁祸首是网络提供商。在这种情况下，人们剩下的唯一解决方案就是更换网络。建议确认提供商提供的服务质量，以便避免此类问题，因为更换网络提供商通常并非易事。
- 检查手机

### 如何保护你的无线网络免受黑客攻击

在家里创建一个无线网络是一个极好的主意；它操作简便，还让你可以从家里的任何地方方便地浏览网络。问题在于，许多人不知道以不安全方式使用家庭无线网络所带来的危险。

如果你想保护你的 `WiFi` 以防止邻居用尽你的带宽，那当然是一个保护 `WiFi` 的合理原因。但这不应该是你的首要担忧。不安全的 `Wi-Fi` 最严重的问题发生在黑客能够连接到你的 `WiFi` 时，如果他成功了，他就能够轻松读取信息

在您的设备与路由器之间传输的数据，无论是否使用 `SSL`，都可能暴露您的用户名、密码以及所有其他传输内容。这种攻击被称为“中间人”攻击 `MITM`，即使是新手黑客也能迅速执行。加强无线网络的安全性将显著降低此类攻击发生的概率。绝大多数试图入侵 `Wi-Fi` 网络的攻击者都会很快放弃对安全无线网络的尝试，因为外存在许多不安全的网络，它们提供了更简单的目标。

此处将解释的所有方法都要求您登录接入点的用户界面并修改其部分选项。如果您不知道如何操作，请访问您的接入点制造商的网站，查找适用于您特定型号的指导手册。请查找关于如何访问该路由器 Web 界面的信息。

### 使用安全加密

使用安全加密是必不可少的措施，这确保了只有使用密码才能连接。通常，这些选项是在无线设置菜单的安全选项卡中选择的。您通常可以从三个或四个选项中选择：禁用、`WEP`、`WPA`、`WPA2`。您应该选择 `WPA2` 或 `WPA`——在任何情况下都绝对不要选择“禁用”或 `WEP`！`WEP` 加密是一种极其脆弱的加密算法，一个完全没有经验的黑客只需几分钟就能破解它。如果您的路由器仅支持 `WEP` 加密而不支持 `WPA`，则应立即更换该路由器。



## 2. 使用强加密密码

我相信你经常听到“使用强密码”这一短语，许多人可能在想，在 Wi-Fi 上这并不太重要——在 Wi-Fi 上，使用强密码至关重要。对于黑客来说，使用扫描数百万种密码组合并在短短几分钟内破解 Wi-Fi 的程序易如反掌。请使用至少 8 到 10 个字符，并混合数字、特殊符号和字母。避免使用日期、姓名或电话号码——这是黑客首先尝试的内容。

## 3. 修改 SSID 名称

`SSID` 是您的无线网络名称，也是您在尝试加入网络时从附近网络列表中选择的名称。建议修改该名称，不要使用默认名称。将其修改为一个不会暴露该无线网络所有者的名字，例如您的姓氏——如果您居住在高密度人口区域（例如公寓楼），这一点尤其重要。

## 4. 限制 Wi-Fi 范围

限制传输范围会降低有人试图黑客入侵您的网络的可能性。在许多家庭中，无线信号可以在外部检测到，通常没有理由这样做。限制传输范围，走出您的财产范围，看看是否能在外部发现信号。如果可能，您可以将路由器移至家庭中心，以获得最佳覆盖范围，同时避免因有限的无线网络范围造成的盲点。

## 5. 修改路由器的界面安全密码

路由器的密码是每次登录 Web 界面时需要输入的密码。从技术角度看，如果黑客能够连接到接入点的 Web 界面，那就为时已晚，黑客已经获得了无线网络的访问权限，但这是一个很好的预防措施，它将限制黑客对无线网络的 control 能力。

## 6. 检查谁连接到了网络

如果您怀疑有入侵者在使用您的 Wi-Fi，那么大多数无线路由器都具有允许您检查登录到接入点的每个设备的 IP 和 MAC 地址的功能。您可以查看该列表，确保您认识每个设备。此列表通常被称为活动 `DHCP` 列表或类似名称。

当您实施这些提示时，即使面对最具动机的黑客，您也有很大的胜算。启用这些选项只需很少的时间，而安全性的提升却极其显著。所有提示都很重要。但是，最重要的一条是加密密码；如果您不采纳这条建议，那么您的网络安全性将完全失效。

## 如何检测黑客攻击

大多数计算机漏洞可以通过多种方式被利用。黑客攻击可能使用单一特定的漏洞、同时使用多个漏洞、系统组件中的配置错误，甚至是先前攻击留下的后门。

因此，检测黑客攻击并非易事，尤其是对于不熟练的用户而言。本文提供了一些基本准则，帮助您判断您的计算机是否正受到攻击，或者您的系统安全是否已受损。请记住，就像病毒一样，没有 100% 的保证能通过这种方式检测到黑客攻击。然而，如果您的系统被黑客入侵，它很有可能表现出以下一种或多种行为。

### Windows 机器：

- 异常高的出站网络流量。如果您使用拨号账户或 `ADSL`，并且注意到网络流量异常高，尤其是在计算机空闲或未专门上传数据时，您的计算机可能已受损。您的计算机可能正被用于发送垃圾邮件，或者被网络蠕虫利用，后者正在复制自身并发送副本。对于电缆连接，这一点不太相关——即使您只是浏览网站或从互联网下载数据，出站流量与入站流量相当也是相当常见的。
- 磁盘活动增加或任何驱动器的根目录下出现可疑文件。入侵系统后，许多黑客会运行大规模扫描，寻找包含银行或支付账户（如 `PayPal`）密码或登录凭据的新文档或文件。同样，一些蠕虫会搜索包含电子邮件地址的文件用于传播。如果您注意到系统空闲时磁盘活动显著，并且标准文件夹中存在可疑命名的文件，这可能是系统被黑客入侵或恶意软件感染的迹象。
- 来自单一地址的大量数据包被个人防火墙阻止。在定位目标（例如公司的 IP 范围或家庭电缆用户池）后，黑客通常运行自动探测工具，尝试利用各种漏洞入侵系统。如果您运行个人防火墙（这是防止黑客攻击的基本要素），并且注意到来自同一地址的停止数据包数量异常高，那么这是您的机器正在遭受攻击的良好迹象。好消息是，如果您的防火墙正在报告这些攻击，您可能相对安全。在这种情况下，解决方案是暂时阻止肇事 IP，直到连接尝试停止为止。许多个人防火墙和 `IDS` 都内置了此功能。
- 常驻杀毒软件突然开始报告检测到后门或木马，即使您没有做任何异常操作。虽然黑客攻击可能复杂且具有创新性，但许多攻击依赖于已知的木马或后门来获取受感染系统的完全访问权限。如果您的杀毒软件的常驻组件检测到并报告此类恶意软件，这可能表明您的系统可以从外部访问。

### Unix 机器：

- `/tmp` 文件夹中的可疑命名文件。Unix 世界中的许多漏洞利用依赖于在 `/tmp` 标准文件夹中创建临时文件，这些文件在系统黑客入侵后并不总是被删除。对于某些已知感染 Unix 系统的蠕虫也是如此；它们在 `/tmp` 文件夹中重新编译自身，并将其用作“主目录”。
- 修改过的系统二进制文件，如 `login`、`telnet`、`FTP`、`finger` 或更复杂的服务 `sshd`、`ftpd` 等。入侵系统后，黑客通常试图通过在拥有直接互联网访问权限的服务中植入后门，或修改用于连接其他系统的标准系统工具来确保安全访问。修改过的二进制文件通常是 `rootkit` 的一部分，并且通常对直接的简单检查具有“隐蔽性”。在所有情况下，保持一个包含所有系统实用程序校验和的数据库，并在系统离线、单用户模式下定期验证它们，是一个好主意。
- 修改的 `/etc/passwd`、`/etc/shadow` 或 `/etc` 文件夹中的其他系统文件。有时，黑客攻击可能会在 `/etc/passwd` 中添加一个新用户，以便在稍后远程登录。请检查密码文件中的任何可疑用户名，并监控所有添加操作，特别是在多用户系统上。
- 检测到向 `/etc/services` 添加了可疑服务。在 Unix 系统中打开后门有时只需添加两行文本即可实现。这通过修改 `/etc/services` 和 `/etc/inetd.conf` 完成。请密切监视这两个文件的任何新增内容，这可能表明有绑定到未使用端口或可疑端口的后门。

## 保护无线保真免受入侵者攻击

无线网络已成为最潮的联网方式。它非常方便，并且由于与移动设备和工具兼容，赋予用户极高的移动性。然而，无线网络极易遭受入侵者攻击，特别是如果你未对其进行保护的话。随着大多数美国家庭订阅无线网络，保护这些网络及其连接的计算机变得愈发重要，需采用不同级别的安全措施。

### 级别 1：加密

加密技术会对网络上的数据和通信进行 scrambling（扰乱/加密处理），这使得你的信息对于试图黑客入侵系统的人不可读。这些加密技术以密码或口令短语的形式出现，在允许连接到私有网络之前，你需要输入这些内容。`WEP/WPA` 安全机制确保只有知道口令短语的人才能连接到系统并利用其互联网连接。

创建网络密码时，避免使用电话号码、出生日期或任何可能包含易被猜测的个人信息的密码。创建强密码是保护网络免受潜在威胁的关键。

### 级别 2：SSID 广播

默认情况下，你网络的默认名称是你路由器的品牌。这个网络名称也被称为 `SSID`。禁用 `SSID` 广播可以保护你免受黑客、身份盗窃罪犯以及其他怀有恶意动机、可能入侵你网络的人的侵害。

禁用 `SSID` 会使你的网络“不可见”。没有人能探测到你的系统是开放的，因此，如果周围有正在扫描策略以寻找下一个受害者目标的黑客，他们也不会扫描到你的网络。

### 级别 3：路由器配置页面上的预设密码和用户名

每个路由器页面都有用户名和密码。默认情况下，用户名是“`admin`”，密码是“`admin`”或“`password`”。有一个所有路由器品牌通用的密码。当然，任何黑客或犯罪分子都知道这些密码，因此如果他们能连接到你的网络，就可以调整路由器的配置页面，这可能导致你的系统或路由器无法使用。

### 级别 4：防火墙设置

你的路由器内置防火墙。此防火墙阻止其他人访问你的网络及连接的计算机。你可以调整防火墙设置，允许网络中的所有应用程序上网，或根据设置精确调整，仅允许特定应用程序连接。根据版本和品牌，你的操作系统可能也有自己的防火墙设置，这也有助于保护网络安全。

### 级别 5：防病毒和反间谍软件

无论强调多少次都不为过：保护计算机免受病毒、间谍软件和恶意软件侵害有多么重要。每天都有成千上万个这类恶意程序被创建，如果你不更新安全软件，你很可能会感染，因为计算机上的病毒定义未更新。

## VPN 的工作原理

随着我们中越来越多的人在移动中工作，从家中或携带个人设备到办公室，日益重要的是要拥抱 VPN 背后的技术，这些技术允许我们“远程接入”办公室网络，赋予我们利用这些灵活工作方式的优势。以下文章提供了关于它们如何工作的简要指南。

### 一个简短的定义

VPN 是 Virtual Private Network（虚拟专用网络）的缩写，是一个涵盖各种技术的术语，这些技术允许用户通过公共网络（在实践中，通常指互联网）从远程位置安全地连接到网络。

VPN 大致分为两种类型。第一种可以描述为远程访问，允许单个用户或设备通过互联网访问位于另一位置的网络。第二种可以称为站点到站点，涉及将一处的系统连接到另一处的网络。

VPN 的关键特性在于它们允许不同网络之间的通信保持安全。也就是说，它们允许数据在系统之间传输，而不会被那些无权查看或访问的人看到或访问。为此，VPN 需要 a) 首先确保正确的人能够访问虚拟网络，并 b) 防止人们在数据通过互联网传输时被拦截。

VPN 在互联网上创建所谓的“隧道”，信息通过这些隧道传输，从而免受窥探者（也称为嗅探器）的触及。在纯概念上，隧道涉及在数据传输的一端加密信息，然后在另一端进行解码。

它们通过在互联网上传输加密的数据包，并将发送和接收计算机视为已知设备（具有预定义地址），实际上将二者置于同一个（尽管是断开的）网络中，以此工作。为此，数据包由内部和外部包装组成。外部容器的职责是将内部包装从发送者网络的网关服务器传输到接收者网络的网关服务器，因此只包含关于其往返的网关服务器的信息。如果嗅探器拦截了数据包，他们只能看到这些信息，而看不到外部包装传输的数据，或者它正前往的目标终端计算机/设备，因为这些内容都是加密的。加密的内部数据包包含正在传输的实际数据，并包含有关目标网络上目标计算机地址以及发送网络上发送计算机地址的进一步信息——两者都被分配了 IP 地址，定义了它们处于同一个虚拟（远程连接）网络中。外部数据包在到达目标网络上的 VPN 服务器时被解密，然后内部包装被路由到正确的目标计算机。

这类似于在加密的内部数据包通过公共网络传输时在其周围放置一个保护气泡——嗅探器可以看到这个气泡要去哪里，但他们不知道里面有什么。气球只有在到达其目标网络时才能被剥离，而指定的目标计算机只能在该网络上解密其内容。

有各种技术用于生成和解释这些加密数据包，例如 IPSec（Internet Protocol Security，互联网协议安全）和 TLS（Transport Layer Security，传输层安全），以及一些取决于特定 VPN 提供者的专有技术。然而，它们都有相同的目的和目标：允许计算机通过开放的公共网络安全地加入远程网络。

### VPN 有多安全？

谈到互联网安全，用户应当小心。在许多 Wi-Fi 热点中都有恶意方，正等待黑入用户的个人信息。如果未得到适当保护，电子邮件、即时消息和信用卡信息等敏感信息都有被黑客窃取的风险。这时，虚拟专用网络（或称 VPN）就派上了用场。然而，大多数不了解 VPN 构成的用户可能会质疑其安全性。VPN 可以以反病毒软件和防火墙无法做到的方式保护用户。尽管这些程序可以与 VPN 配合使用，但它们只保护设备本身。它们并不保护传输到设备或从设备传输出的数据。

以下是 VPN 在 internet 安全方面可以带来的一些优势：

- 防止深度包检测

互联网服务提供商（ISP）以追踪用户在线活动而闻名。ISP 利用这些信息作为检查、限速和优先处理从用户设备发送和接收的数据的手段。这意味着未使用 VPN 连接的用户速度会变慢。当用户使用安全的 VPN 访问互联网时，他们克服了深度包检测。ISP 无法看到用户的活动。他们只能看到用户正在与 VPN 服务器通信。用户发送和接收的所有信息都是加密且私密的。

- 放心通过 Wi-Fi 连接

使用移动设备连接互联网的用户会利用咖啡馆、餐厅、机场、图书馆等地的免费 Wi-Fi 连接。这样做会使用户的信息面临风险。Wi-Fi 连接通常没有安全性。任何人都可以使用。这意味着黑客和其他恶意第三方可以轻松地访问用户的设备。他们窃取未受保护设备上的敏感信息并安装恶意软件。使用 VPN 可以确保无论用户在哪里连接互联网，其数据都不会受到威胁。

- 消除数据包嗅探器的威胁

数据包嗅探器是一种可以合法和非法使用的软件。黑客使用数据包嗅探器窃取用户的个人信息和其他有价值信息。这可能包括即时通讯对话、敏感的信用卡信息和电子邮件。有了 VPN，数据包嗅探器最初只会看到乱码。它无法解密。

- 适用于各种设备

VPN 可用于许多设备，包括台式计算机、笔记本电脑、平板电脑、智能手机，甚至许多无线路由器。在设置 VPN 时，用户可以有多种协议选项可供选择

## VPN 的工作原理

下面简要介绍 VPN 是如何工作的。当你在互联网上浏览时，你实际上是在公共网络上。这意味着，如果你的系统完全没有保护，任何怀有恶意的人都可以给你制造各种麻烦。这些问题包括间谍软件、病毒、入侵攻击等。

为了防止这种情况发生，你可以安装额外的硬件或软件。当你安装了作为活动防火墙作用的新设备时，这可能有助于阻止许多攻击。有些人更喜欢用软件来实现，这就是 VPN 的用武之地。

## Tor 是什么，它是如何工作的？

Tor 网络，通常被称为“Tor”，是一个由志愿者运行的系统，有助于让互联网使用更加匿名。

当用户连接到 Tor（通常是通过 Tor 浏览器）时，他们的出站互联网流量在到达目的地（用户想要访问的网站）之前，会先被重新路由通过一系列至少三个随机节点（称为中继）。你的电脑连接到一个入口节点，流量最后通过的节点是出口节点，之后它才到达目的地（你想访问的网站）。传入流量以类似的方式重新路由。

Tor 工作原理的简化版（来源：EFF 通过 Wikimedia）



除了通过多个节点外，流量还会被加密，事实上是多次加密。它在每个节点失去一层加密，但在离开出口节点到达目的地之前，永远不会被完全解密。

每个节点都有一个标识性的 IP 地址，这也是经过加密的。目的地网站看到的唯一 IP 地址是最终节点，即出口节点的 IP 地址。

目前，Tor 网络总共由大约 7,000 个中继（节点）和 800 个桥组成。桥与中继类似，但它们未列在 Tor 目录中。当网站或应用程序阻止来自已检测到的 Tor 节点的流量时，也可以使用桥。

## Tor 会隐藏 IP 地址吗？

当连接到 Tor 网络时，活动永远无法追溯回你的 IP 地址。同样，你的互联网服务提供商（ISP）将无法查看关于你流量内容的信息，包括你正在访问哪个网站。

你的 ISP 会看到你在连接到 Tor 入口节点，而你访问的网站将知道 Tor 出口节点的 IP 地址。

## Tor 能让你匿名吗？

要在网上实现真正的匿名是复杂的，甚至是不可能的，但 Tor 无疑可以帮助你接近这一目标。所有到达目的地的流量看起来都来自一个 Tor 出口节点，因此会被分配该节点的 IP 地址。由于流量在加密状态下经过了多个额外节点，因此无法追溯回你。

然而，其中一个问题在于信任出口节点的运营商。如果你访问的是一个未加密（非 HTTPS）的网站，节点运营商可能会跟踪你的活动并查看你的信息。他们可以收集诸如你正在浏览哪些网页、你的登录信息、你的消息或帖子内容以及你执行的搜索等数据。虽然，没有办法将这些信息追溯回你，甚至追溯回入口节点。

值得注意的是，使用 Tor 浏览器仅保护通过该连接的流量，不会匿名化你电脑上的其他应用程序（尽管许多应用程序可以通过其他方式配置为通过 Tor 网络）。此外，你的 ISP 仍然可以看到你正在使用 Tor。为了提高隐私，你可以同时使用 VPN 和 Tor 浏览器。

## 什么是暗网，Tor 与它有什么关系？

此外，深网中包含暗网。这些内容通常只能使用像 Tor 这样的特殊工具访问。暗网包含一些合法的网站，但它更以充斥非法活动的地方而闻名。

你可以用 Tor 访问明网，但你也可以访问暗网站点，特别是 .onion 网站。这些网站只有使用 Tor 浏览器的人才能访问，并且它们的 URL 中包含 .onion。它们也被称为“Tor 隐藏服务”。

它们未被搜索引擎索引，如果你不知道去哪里查找，很难找到它们。Tor 保护 .onion 网站运营商的匿名性，因此很难查明是谁在运营它们。当然，运营商和用户匿名性的结合正是暗网成为犯罪活动理想场所的原因。

## 使用 Tor 合法吗？

Tor 的性质确实使其成为犯罪分子访问暗网某些更阴暗部分并进行犯罪活动的热门选择。这些包括买卖非法产品或服务，或参与传播仇恨言论和鼓励极端主义的论坛。

### 使用 Tor 有任何缺点吗？

Tor 在许多用户中很受欢迎——目前，在任何给定时间都有大约 200 万用户连接到中继节点。

但它确实存在一些缺点。以下是使用 Tor 的主要缺点：

- 速度缓慢
- 可被 ISP 检测
- 被网络管理员封锁
- 易受攻击

让我们更详细地看看这些问题。

### 速度缓慢

使用 Tor 的主要缺点是它相当安静（流量分散）。流量不会直接到达其目的地，因此这会减慢速度。此外，节点之间流动的流量速度可能比你的常规互联网连接更慢，这进一步削弱了整体势头。

更重要的是，与通过网络流动的流量相比，可用的志愿者节点数量很少。由此产生的拥塞将减慢流量，尤其是在高峰时段。

由于这些问题，Tor 的主要用途是一般浏览。它不适合流媒体或种子下载，也不适合任何其他需要大量带宽的活动。

### 可被 ISP 检测

另一个缺点是你的 ISP 能够看到你正在使用 Tor。它无法读取你的流量内容，但检测到你在这一点可能会产生一些后果。如前所述，仅仅使用 Tor 就足以引起 ISP 和当局的怀疑。绕过此问题的一种方法是使用带有 Tor 的 VPN（下文将有更多介绍）。

### 被网络管理员封锁

单个网络的管理员通常会封锁 Tor。绕过此问题的一种方法是使用桥接（bridges），它们不应该被检测为 Tor 节点。如果封锁更加复杂并使用了深度包检查，你可能需要使用额外的工具，例如可插拔传输协议（Pluggable Transports，见下文）。这些工具会将你的 Tor 流量伪装成常规流量，以绕过封锁。

### 易受攻击

虽然尚未得到证实，但有报道称，针对 Tor 的流量分析已成功用于寻找有罪证据。其中一个引人注目的案例是 2013 年的“丝绸之路”行动。丝绸之路是通过 Tor 网络运营的 marketplace，涉及估计价值 10 亿美元的毒品交易，以及其他非法商品和服务。

此外，也要注意上面提到的关于出口节点监控的传闻。请记住，这些报告似乎尚未得到证实，因此可以持怀疑态度看待它们。

### 2. 使用 Tor 上网

在 Tor 通过中继节点建立与网络的连接时会有轻微的延迟——程序警告初始连接可能需要几分钟——但一旦建立连接，Tor 浏览器将启动并准备好使用。



Tor 基于与 Firefox 相同的代码，因此如果你使用过 Mozilla 的网页浏览器，一切似乎都会相当熟悉。即使你以前没有使用过 Firefox，你也不需要太久就能感觉宾至如归——它与 Edge、Chrome 和 Safari 等浏览器并无太大不同。

### 3. 选择你的安全级别

在开始之前，值得注意的是，使用 Tor Browser 是在隐私/安全和网页可用性之间寻求平衡。默认情况下，安全级别设置为“标准”——尽管这仍然比任何其他网页浏览器安全得多。

如果你想增加安全级别，请点击地址栏左侧的洋葱图标并选择“安全设置”。使用“安全级别”滑块选择你首选的保护级别，同时留意关于可能会在你访问的网站停止工作的功能的警告。

### 4. 重新思考你的浏览习惯

为了充分利用 Tor，你需要改变一些浏览习惯——其中第一个就是你使用的搜索引擎。

与其选择 Google 和 Bing 等搜索引擎，建议改为使用 Disconnect.me。这是一个防止搜索引擎在线跟踪你的网站，你可以将其与 Bing、Yahoo 或 DuckDuckGo 一起使用。

既然提到了改变习惯，你还需要避免安装浏览器扩展程序，因为这些扩展程序可能会泄露私人信息。

### 5. 理解 Tor 电路

当你浏览互联网时，Tor 浏览器通过避免直接连接到网站来帮助你保持安全。相反，你的连接会在 Tor 网络上的多个节点之间跳跃，每次跳跃都包含匿名化过程。

这不仅使网站几乎不可能追踪你是谁以及你身在何处，也是导致你在使用 Tor 浏览时注意到稍慢性能的原因。

如果你觉得性能异常低或页面不再响应，你可以通过点击汉堡图标并选择“为此网站创建新的 Tor 电路”选项来开始一个新的 Tor 电路，这将强制 Tor 寻找到该网站的新路线。

### 6. 创建新的身份

新电路选项仅适用于当前活动的标签页，你可能需要更严格的隐私安全网。点击汉堡图标并选择“新身份”，请记住这将关闭并重启 Tor 以获得新的 IP 地址。

当你使用 Tor 连接到网站时，你可能会注意到出现一个弹出窗口，警告你某个特定网站正在尝试做一些可能会用于跟踪你的事情。这些消息出现的频率不仅取决于你访问的网站，还取决于你设置的隐私设置。

### 7. 使用 HTTPS

在线保持安全和匿名的一个重要部分是确保你使用网站的 HTTPS 版本而非 HTTP 版本。为了让你不必记住每个访问的网站都要这样做，Tor Browser 默认安装了 HTTPS Everywhere 扩展程序。如果网站提供安全版本，它将尝试将你重定向到该版本，但你应密切关注地址栏作为额外的保障措施。

如果你连接到安全网站，你将看到一个绿色的锁图标。如果不存在此图标，请点击“i”图标以获取更多信息。

### 8. 访问 .onion 网站

然而，通过 Tor 连接互联网的最安全方式是访问 `.onion` 网站。这些也被称为隐藏 Tor 服务，搜索引擎无法访问；要找到它们，你必须直接访问。

这些网站只能使用 Tor 访问，但你需要注意——遇到包含非法内容、销售非法产品或推广非法活动的网站相当常见。

### 9. 尝试 Tor over VPN

如果你想将隐私提升到下一个级别，你可以在启动 Tor 浏览器之前连接到 VPN。VPN 无法看到你在 Tor 浏览器中做什么，你将获得额外的好处，即没有 Tor 节点能够看到你的 IP 地址。它还将防止你的网络运营商甚至知道你正在使用 Tor，如果你所在的地区恰好封锁了 Tor 网络，这将很有帮助。

## 如何使用 Proxychains 通过代理服务器重定向流量

有时我们安装代理服务器，但只有特定程序（如 Firefox 和 Google Chrome）提供代理设置。幸运的是，我们可以使用一个名为 `proxychains` 的命令行实用工具来将任何应用重定向通过我们的代理服务器。本教程将向您展示如何在 Debian、Ubuntu、OpenSUSE、Fedora、CentOS/Red Hat、Arch Linux 及其衍生版本上进行设置。

如果您不知道如何设置代理服务器，请查看这篇文章以了解 `shadowsocks` 代理。之后，再回到这里。

### 在 Linux 上安装 proxychains

#### Debian/Ubuntu/Linux Mint/Elementary OS

```
sudo apt-get install proxychains
```

#### OpenSUSE Leap 42.1

Proxy chains 可从 packman 仓库获取。

```
sudo zypper install proxychains
```

#### Fedora

```
sudo dnf install proxychains
```

#### CentOS/Red Hat

```
sudo yum install proxychains
```

#### Arch Linux

```
sudo pacman -S proxychains-ng
```

在 Kali Linux 上，`proxy chains` 是默认安装的。

### 在 Proxychains 中添加代理服务器

打开配置文件。

```
sudo nano /etc/proxychains.conf
```

在文件末尾，像这样添加您的代理：

```
socks5 127.0.0.1 1080
```

`socks5` 是代理类型，您也可以根据情况添加其他类型，如 HTTP、https、socks4 等。`127.0.0.1` 是代理主机，`1080` 是代理服务器监听的端口。再次强调，请根据您的具体情况更改它们。

默认代理为 `socks4 127.0.0.1 9050`，您可以安全地将其移除。

### 设置默认 DNS 服务器

强烈建议您将默认的 `4.4.2.2` DNS 服务器更改为其他服务器，例如 Google 的 DNS 服务器 `8.8.8.8` / `8.8.4.4`。或者 OpenDNS 服务器 `203.67.222.222` / `203.67.220.220`。打开 resolv 配置文件。

#### Debian/Ubuntu

```
sudo nano /usr/lib/proxyresolv
```

#### Linux Mint/Elementary OS

```
sudo nano /usr/lib/proxychains3/proxyresolv
```

#### Fedora/CentOS/Red Hat/OpenSUSE

```
sudo nano /usr/bin/proxyresolv
```

找到以下行：

```
DNS_SERVER=4.4.2.2
```

将其值更改为类似 `8.8.8.8` 的值。然后保存并关闭文件。在 Arch Linux 上，没有 `proxyresolv` 配置文件。

### 测试

只需在执行的任何命令前加上 `proxychains`，如下所示。

```
proxychains youtube-dl -citv https://www.youtube.com/channel/<channel-id>
```

如果您使用 `youtube-dl`，您可能知道它没有内置的 socks 代理支持，但 Proxychains 会将 `youtube-dl` 重定向通过代理服务器。

### 静默模式

默认情况下，`proxychains` 会将其活动输出到终端。如果您不想看到此信息，则可以通过编辑 `/etc/proxychains.conf` 文件来禁用它。

### 如何入侵 WiFi（无线）网络

无线设备在路由器的传输半径内对任何人都是可访问的。这使得它们容易受到攻击。机场、餐厅、公园等公共场所都有热点网络。

### 什么是无线网络？

无线网络是使用无线电波将计算机和其他设备连接在一起的计算机网络。其实施是在 OSI 模型的第 1 层（物理层）完成的。

### 如何访问无线网络？

您需要一个支持无线网络的设备，例如笔记本电脑、平板电脑、智能手机等。您还需要位于无线网络接入点的传输半径内。大多数设备（如果打开无线网络选项）都会为您提供可用网络列表。如果系统没有密码保护，则必须点击连接。如果它受密码保护，则需要密码才能获取访问权限。

但在执行此操作之前，如果你遭受了经济损失，请允许取证团队访问你的电脑，以便他们检查发生了什么。你可能需要他们的报告，以便从保险公司、银行、经纪人或在线商户处追回你的经济损失。

### 6. 防病毒软件、任务管理器或注册表编辑器被禁用且无法重启

意外情况时有发生，这三个应用程序中的某一个可能会自行发生故障。在百万分之一的巧合中，其中两个可能会同时出错。但当三者同时失灵时，问题就严重了。

许多恶意软件确实会试图通过降低这三个应用程序的功能来保护自身，导致它们无法启动，或者只能在受限状态下启动。**应对措施：** 你无法确定具体发生了什么，因此你应该对电脑系统进行完全恢复。
