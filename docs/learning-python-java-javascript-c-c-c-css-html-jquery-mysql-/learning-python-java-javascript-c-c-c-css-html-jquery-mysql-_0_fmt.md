在我的整个教育过程中（从本科到博士），我发现比较学习材料以及解决更多问题是促进理解的最佳方式之一。本书将引导你这样做。

本书将你连接到来自世界优秀程序员的最相关的计算机编程学习资源。它将让你能够快速在线探索或免费下载：
