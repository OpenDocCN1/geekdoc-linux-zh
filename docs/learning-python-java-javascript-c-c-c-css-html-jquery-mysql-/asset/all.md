# Introduction

As you might be aware, the internet contains lots of excellent computer programming learning materials for students, lecturers, professional and people who want to master programming or coding. These resources include; many open/accessible textbooks, incredible reference guides and video lectures/tutorials. The challenge is, these resources are widely dispersed, crowded and masked with adverts and browsing nuisance. Most-a-times, you will need to do multiple clicks to be able to lay your hands on good web material if you are lucky. Hence it is very frustrating and time consuming looking online for critical computer programming materials you can read or download for free. This is where this book comes in, bringing you closer to the most relevant and exciting links the internet has to offer.

These links can help you to get a supplementary reading, find more worked examples, codes, cheat sheets and have fun while learning or using  python, java, javascript, C, C++, C#, CSS, HTML, jQuery, MySQL, SQL, LINUX, Perl, PHP, Ruby, BASH, D, Unix and XML . Most importantly, this book can save you plenty of time and money.

Throughout my education  (undergraduate to PhD level), I have found comparing learning materials as well as solving more questions to be one of the best ways to facilitate comprehension. This book will lead you to do exactly that.

This book will connect you to the most relevant computer programming learning resources from great programmers around the world. It will enable you to quickly explore online or download for FREE:

•Multiple textbooks

•Multiple video tutorials

•Plenty worked examples

•Key cheat sheets and reference guides

•Incredible YouTube channels devoted to the featured programming languages

•And many more interesting stuff.

How cool is it to find all these links collated at one convenient location?

It is envisaged that this book will guide you to find useful learning resources which will go a long way to enhance your understanding of any of the featured programming languages. You are just a click away from landing on a great book or reference guide you can read online now or download for free!
