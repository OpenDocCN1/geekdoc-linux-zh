## UNIX Security

presents top-notch, practical advice on system and network security methods. From the editors of Sys Admin magazine, this desktop reference focuses on the day-to-day security issues faced by system administrators everywhere. Each chapter is a complete statement of problem and solution. All the code presented is included on disk, making these solutions easy to implement.

UNIX Security includes nineteen chapters explaining methods for checking user security, timing out idle users, coordinating password and group files, managing super-user privileges, restricting machine access, building firewalls, login surveillance, secure net connections, remote password updating, automating network maintenance, and much more.

UNIX Security is a must-have resource for any system administrator wanting to maintain a secure UNIX system.
