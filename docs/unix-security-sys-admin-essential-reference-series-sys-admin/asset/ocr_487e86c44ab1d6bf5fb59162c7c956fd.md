The syslog file with no extension is the current file in use by the system. After aging, logit uses kill to force syslogd to reread its configuration file. This is necessary after the current file has been aged: without the kill, messages will go to syslog.1 instead of syslog. I fire logit nightly by cron.

Aging the syslog file and purging the oldest each night ensures that syslog will not grow to unlimited proportions. Unfortunately, it does not guarantee that I’ll remember to look at the log or that I’ll find the right information buried in it. To help
