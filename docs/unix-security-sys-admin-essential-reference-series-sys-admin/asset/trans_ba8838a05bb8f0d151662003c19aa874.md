## Login via the Modem

通过调制解调器的拨号连接与网络连接以类似的方式受到保护。getty 程序通过串行线路或调制解调器管理登录。它监听调制解调器载波信号，并在尝试连接时启动登录程序。对于调制解调器登录，我们修改了 getty 程序（代码片段见 Listing 13.4），使其启动我们的登录包装程序而不是标准登录程序。如果挑战被正确回答，用户会看到正常的登录提示。如果挑战回答错误，getty 会立即退出，连接将被切断。
