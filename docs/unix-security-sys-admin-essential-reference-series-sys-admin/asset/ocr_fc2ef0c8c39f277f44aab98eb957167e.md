top(1) A system monitoring utility that combines the functionality of ps(1), uptime(1), renice(8), and kill(1). It can be found at ftp://eecs.nwu.edu/pub/top/ and used to reliably check for the existence of rogue programs in the case of a SunOS host, since the SunOS version of Rootkit does not contain top(1).

lsof List Open Files (ftp://vic.cc.purdue.edu/pub/tools/unix/lsof/) lists all open files, including open network sockets.
