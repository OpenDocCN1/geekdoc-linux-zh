As shown in Listing 16.1, adding a host is done in the function addhost. It will first scan the active sys file to see if the host is already present. If so, it will issue a warning mail to root and exit. If not, it makes a backup of the sys file, opens the template, and adds the host to the bottom of the sys file. The sys file also replaces the %%% tokens with the name of the new system.

# Delete all hosts from sendmail.uunames
sub delmail
{
  local( $sysnam, $backup, $dummy );
  local( $uid, $gid, $mode );

# Back up older versions
&backupfile( $mailnam );
$backup = $mailnam . ".o";
open ORIGINAL, "$backup" || warn "Cannot open $mailnam, $!\n" && link $backup,
$mailnam && return;
open NEW, ">$mailnam" || warn "Cannot creat $mailnam, $!\n" && link $backup,
$mailnam && return;

while( <ORIGINAL> ) {
  if( /^#/ || /^\s*$/ ) {
    print NEW;
  }
  next;
}
chomp;
print NEW if (exists $delete{$_});

close ORIGINAL;
close NEW;
# Set ownership and permissions
&setperm( $backup, $mailnam );
} # delmail
