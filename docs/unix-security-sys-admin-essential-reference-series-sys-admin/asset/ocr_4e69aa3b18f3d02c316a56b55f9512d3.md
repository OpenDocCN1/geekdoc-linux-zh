# Figure 15.1 A diagram of the password protocol shows processes run on the client and on the server.

On the Client

User runs /bin/passwd.

passwd says "Connecting."
passwd rlogins to server.

User enters old password.

User enters new password.

User enters password again.

On the Server

Server runs passwd.

passwd says "Old Password."

passwd checks password.
If valid, execs /bin/passwd.
passwd says "New Password."

passwd asks for password again.

passwd updates /etc/password.
