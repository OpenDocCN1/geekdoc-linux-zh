logintimes Login times for this user. Syntax is the same as in /etc/security/login.cfg.

pwdwarntime Number of days a warning message indicates a required password change.

pwdchecks Defines a local password verification program (Listing 9.1).

dictlist Filename of password dictionary used for password checking. The file contains one word per line. If the new password is found in this file, the password is rejected.

loginretries Number of failed logins before an account is disabled.

histexpire Time in weeks before a password can be reused.

histsize Number of previous passwords a user cannot reuse.
