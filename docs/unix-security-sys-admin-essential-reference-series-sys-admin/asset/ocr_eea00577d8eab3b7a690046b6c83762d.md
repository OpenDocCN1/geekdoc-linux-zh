# Administering the SLIP Users

Setting up a SLIP user requires several administrative steps. Once the setup is completed, though, the user will be able to connect to the SLIP server and have the server call the user back at a predetermined number. The user can then use all the services available on the Internet and the LAN.

The first step is to create the user ID under which the user will login to the SLIP server and assign a password to the new user ID. The actual name of the user ID is not important, although by convention all SLIP login IDs start with a capital S followed by the user's initials (e.g., Sm d). The user ID must have /usr/sbin/slcallback as the login shell and must also have the class remote to login without needing SecureNet authentication. The UID and GID are not important, except that the UID must be unique across all SLIP logins. A sample /etc/passwd entry for a SLIP user would look as follows.

```
Srbm::500:9999:remote:0:0:Slip Callback (Rob Mackinnon): /tmp:/usr/sbin/slcallback
```
