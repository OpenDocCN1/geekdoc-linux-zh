| T | This line describes bandwidth allocation details and information specific to ISO and INTR transfers. This includes total bandwidth allocated to this bus, number of interrupt requests, and isochronous requests in the particular bus |
| B | This line provides device description information. This includes device USB version, class, subclass, protocol, max packet size, and number of configurations |
| D | This line describes product-related information. This includes product ID, its version, and vendor ID |
| P | This line provides product-related information as a string. This includes details of product, manufacturer, and serial number |
| S | This line provides configuration-related information. This includes active configuration detail, number of interfaces, configuration number, its attributes, and max powers |
| C | This line provides interface-related information. This includes interface number, active alternate setting, its number, number of endpoints, interface class and protocol information, and driver name |
| E | This line provides endpoint-related information. This includes information on endpoints like endpoint number, maxpacket size, its intervals, and attributes |
