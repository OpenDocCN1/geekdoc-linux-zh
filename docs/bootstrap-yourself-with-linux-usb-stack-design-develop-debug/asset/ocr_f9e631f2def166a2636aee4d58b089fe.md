# DEBUG USING UBSFS_SNOOP

The previous section discussed usbmon, a low-level tool that captures UR transactions in the USB flow to debug a USB system using Linux. Sometimes such detailed information is not required to debug a Linux USB subsystem. This paves the way to a simpler approach available on Linux that can snoop USB transactions. The usbfs_snoop is one such debug mechanism available as part of the uscore that can snoop USB data at a higher level of the USB transaction and print it as part of the system log.
