The complete source code of this driver is available on the book’s CD as uio_usb_example.c. Now build the source to create a uio_usb_example.ko and insert it into the kernel. Before loading the kernel module, ensure the UIO framework is loaded to the kernel. The following terminal activity captures the commands to be executed.

```
root@arajam-linux-desktop:~\#
root@arajam-linux-desktop:~\# modprobe uio
root@arajam-linux-desktop:~\# insmod uio_usb_example.ko
root@arajam-linux-desktop:~\#
```

A successful registration of the USB PCI driver creates device files in the /dev/uio* and /sys/class/uio/ directories. You can also confirm registration by invoking the lsio command. The lsio utility can be downloaded from http://www.osard.org/projects/downloads/UIO/user/lsio-0.2.tar.gz. These files allow user space applications to access and collect information on the device.

The next step is to develop a user driver for the USB controller using the UIO driver being developed. Access the USB hardware, open the device using the device name: /dev/uio0. The name uio0 could be different, based on how many UIO devices you have registered.

```
fd = open("/dev/uio0", 0|RDWR|0_SYNC);
```

After successfully opening the device, it’s time to map the memory collected during the probe routine to the user space.
iomem = mmap(0, size, PROT_READ|PROT_WRITE, MAP_SHARED, fd, addr);

A successful mmap routine running in the complete hardware to the user space. The example program usb_uio_application.c on the CD is a simple application to read register controllers. You can use the UIO framework to develop a complete USB firmware driver; the complete hardware is available in the user space.
