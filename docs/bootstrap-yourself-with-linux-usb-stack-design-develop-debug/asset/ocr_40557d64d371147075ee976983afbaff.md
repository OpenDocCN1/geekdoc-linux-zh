# SUMMARY

Power management is essential for embedded systems, especially if they’re battery operated. The beginning of this chapter explored data structures of the Linux power management framework that are essential to understanding the Linux USB power management framework, followed by details of the Linux USB host power management framework. This chapter concluded with details on configuring Linux USB host power management from user space. The next chapter explores the hub system software requirements and their implementation.

# MORE READING

The USB specification defines the power management requirements for a USB system. You need to understand the power management framework of the Linux kernel; Documentation/power/*.txt offers further insights. In addition to these, Documentation/usb/power-management.txt and Documentation/usb/persist.txt provide information on the Linux USB power management framework.
