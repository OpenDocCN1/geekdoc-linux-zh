# LINUX USB DEVICE FILE SYSTEM

The Linux USB file system framework is part of the uscore module. Its key functionality is to implement VFS files to represent the devices connected to the USB host system. The Linux USB device file, referred to as usbfs, creates a devices file in the root of the mount path, directories to represent USB, and files to represent USB devices. The USB file system implementation is mostly implemented across the files of uscore, mainly drivers/usb/core/inode.c, drivers/usb/core/devices.c, and drivers/usb/core/devio.c. In these files, the inode.c implements the VFS framework, and the later files provide necessary file operations to allow users to access the file information.
