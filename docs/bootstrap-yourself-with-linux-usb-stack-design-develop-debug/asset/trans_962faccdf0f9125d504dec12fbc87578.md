# 通过 Linux-USB 栈实现自强

嵌入式 USB 设计、开发、调试与验证

- 通过 UML 活动图和时序图直观地展示 Linux-USB 子系统框架，阐明复杂的概念
- 全面探索了使用 Linux-USB 框架开发用户空间 USB 驱动的方法，以及使用该框架调试和测试 USB 设备的方法
- 附带的光盘提供了书中讨论的所有示例程序，以及一个用于进行 USB 系统回归测试的专用工具
