
## Bootstrap: USB Monitor

usbmon operates like any other device: it extends its resources (the hooked information) through file operations. For a USB developer, it is unnecessary to look into the implementation details of this module. To expand your understanding, refer to the “More Reading” section at the end of this chapter.

`drivers/usb/mon.c` defines the data structure `mon_event` that maps URB information when any of the following events take place in the host controller: a URB is submitted, a URB is completed, or an error occurs.

```c
struct mon_event {
    list_head e_link;
    int type;
    unsigned long id;
    unsigned int timestamp;
    int busnum;
};
```

The `busnum` variable indicates the USB bus in which URB event took place. The Linux kernel assigns a unique number to each bus, starting from 1.

## Debugging Using Linux USB

The `devnum` variable indicates the device for which URB event took place. The Linux kernel assigns a unique number to each USB device, starting from 1. The `epnum` variable indicates the endpoint to which URB is processed. The value starts from 0.

The `is_in` variable represents the direction of URB event, with true indicating an IN transfer and false indicating an OUT transfer. The `xtype` variable represents different transfer types available on USB. The variable can hold bulk, interrupt, isochronous, or control transfers, respectively.

The `length` member maps the length of data transferred in URB. This could be the actual buffer length or the transferred length. The `status` member indicates the status of URB transfer. This field is valid for non-isochronous URB transfers. The return status is based on the values defined in `linux/errno.h`.

The `interval` variable indicates the transfer period for time-bounded transfers as interrupt and isochronous transfers. It is based on device configuration. The `start_frame` member is specific to isochronous transfers and indicates the initial frame of the isochronous transfer. The `error_count` variable is also specific to isochronous transfers and indicates the number of errors in the isochronous transfer.

The `setup_flag` variable indicates whether the data structure object is a setup packet and can hold the following values: 0 (Setup data captured), - (Unable to capture Setup Packet), and Z (invalid).

The `data_flag` variable indicates whether the data structure object holds data as part of the event information. It can hold the following values: 0 (data available), <= (IN Completion), >= (OUT Submit), L (Length is 0), and Z (invalid).

The `numdesc` member maps `number_of_packets` from the URB structure that indicates the number of isochronous packets. Because this is a debug mechanism for USB transfers, a complete hook of data from the URB is not required. Therefore, the text version of usmon maps part of the URB data. The following members capture/hold data based on the transfer type:

```c
struct mon_iso_desc isodes[ISODESC_MAX];
unsigned char setup[SETUP_MAX];
unsigned char data[DATA_MAX];
```

From the preceding macros, you can understand that the data field contains only part of the data. The binary version of usmon provides complete information for the URB. However, this extra data is mostly class-specific, and packet analyzers that are specific to those modules are more effective than usmon. For example, there are class-specific packet monitors for classes such as mass storage and scsi.

Having a brief overview of the data structure that handles usmon’s URB event, the subsequent section focuses on the sequence flow inside the usmon, how it hooks information, and how it shares hooked information with the user space.

## USB Monitors Internals

Like any other module, usmon extends the Linux kernel details to the user space through a file system. Because the usmon module is for debugging, it uses debugfs.

## USB Monitor: usbmon

The `usb_mon_operations` uses the callback methods exported by the usbcore.

```c
struct usb_mon_operations {
    void (*submit)(struct usb_bus *bus, struct urb *urb);
    void (*submit_error)(struct usb_bus *bus, struct urb *urb, int err);
    void (*complete)(struct usb_bus *bus, struct urb *urb, int status);
    void (*unlink)(struct usb_bus *bus, struct urb *urb);
};
```
