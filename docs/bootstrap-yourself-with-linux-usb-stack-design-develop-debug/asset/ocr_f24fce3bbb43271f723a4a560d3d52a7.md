# Chapter 9 = Generic Driver

The state member variable holds the state information of the device. The state of the device is set using the interface function usb_set_device_state. The state can hold values such as USB_STATE_NOT_ATTACHED, USB_STATE_ATTACHED, USB_STATE_POWERED USB_STATE_ADDRESS, and USB_STATE_CONFIGURED.

enum usb_device_state state;

The speed member variable holds the speed information of the device. It can hold values such as USB_SPEED_LOW, USB_SPEED_FULL, USB_SPEED_HIGH, and USB_SPEED_UNKNOWN.

Having explored the key infrastructure data structures, you’ll now look at the interface methods that manage these drivers.

+   * int usb_register_driver(struct usb_driver *, struct module *,const char *);

This method registers a USB interface driver with the USB core. It returns 0 when successful and a negative value on failure.

+   * void usb_deregister(struct usb_driver *);

This method unlinks a USB interface driver from the usbcore. The method also updates the USB device file system indicating the unlink.

+   * int usb_register_device_driver(struct usb_device_driver *,struct module *);
