The USB power management framework supports the automatic suspend and resume feature of idle devices. To enable another host framework to use this feature, the Linux USB host power management framework exports interfaces. These routines enable other USB modules to communicate suspend and resume requirements to the usbcore.

+   - int usb_enable_autosuspend(struct usb_device *udev)
nThe usb_enable_autosuspend interface enables a USB device for power management. It sets the autosuspend_disabled flag to 0 to enable auto suspend. The suspend takes when the device becomes idle and the auto suspend delay expires.
- int usb_disable_autosuspend(struct usb_device *udev)
The usb_disable_autosuspend routine prevents the USB device from going to low power suspend mode by setting the autosuspend_disabled flag's value to true.
- int usb_autopm_get_interface(struct usb_interface *intf);
- int usb_autopm_get_interface_async(struct usb_interface *intf);
Both these interface routines increment the power management's usage counter and auto resume if the device is suspended. The major difference between the two interfaces routines is that the async method can operate in an atomic context.
- void usb_autopm_put_interface(struct usb_interface *intf);
- void usb_autopm_put_interface_async(struct usb_interface *intf);
The _put routine decrement the power management usage counter of the device and try auto-suspending the device if the usage counter is 0. Like the previous sync routine, you can execute this sync routine in an atomic context.
