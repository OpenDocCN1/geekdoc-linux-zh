The drivers/usb/host/Kconfig file contains the host controller driver configuration menu options, which allow you to choose the necessary host controller interface (HCI) drivers. The host controller driver configuration depends on USB support, which you enabled earlier.

The following configuration from drivers/usb/host/Kconfig shows that host-controller drivers depend on USB configuration.

# Enable EHCI HCD Support

An EHCI allows you to connect to USB 2.0 high-speed devices. When you configure the USB EHCI option, it generates the ehci-hcd.ko kernel module.
