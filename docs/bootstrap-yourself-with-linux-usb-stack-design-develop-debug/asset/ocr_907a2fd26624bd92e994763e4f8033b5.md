# Enable UHCI HCD Support

The Universal Host Controller is a proprietary interface specific to Intel for full- and low-speed devices. When you configure the USB UHCI option, it generates the uhci-hcd.ko kernel module.

The following configuration from drivers/usb/host/Kconfig shows the UHCI driver configuration and its dependency.

```
config USB_UHCI_HCD
tristate "UHCI HCD (most Intel and VIA) support"
depends on USB && PCI
```

Figure 3.5 illustrates the menuconfig option available as part of the UHCI menu.

```
<M> UHCI HCD (most Intel and VIA) support
```
