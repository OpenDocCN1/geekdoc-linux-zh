In the example setup, a USB mass storage is connected to the system, which adds the usb-storage entries. The following terminal illustrates usb-storage directory contents. These files provide details on the driver and control over its loading. Later in the "Application of sysfs: /sys/bus/usb Files" section, you can read how to use these files to load and unload driver modules.

```
- usb-storage
  |-- 2-3:1.0 ->../../devices/pci0000:00:0000:01d.7/usb2/7-3/7-3: 1.0
  |-- bind
  |   -- module ->../../module/usb_storage
  |-- new_id
  |-- uevent
  '-- unbind
```

The files drivers_probe and drivers_autprobe include an option to configure automatic probing and loading of drivers by the USB driver. Chapter 6, "Device File System", goes into more detail about the data structures of the USB subsystem and exports in sysfs.

# Application of sysfs: /sys/bus/usb Files

The sysfs files contain information on the USB devices and interfaces with the user space exported by the uscore module. You can read the sysfs files to learn about the device and write to the files to control the device and driver activity.
