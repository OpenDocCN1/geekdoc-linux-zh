The preceding section covered the VFS framework that enable you to understand the Linux USB file system. Detailed information on all these data structures and methods is available in /Documentation/filesystems/vfs.txt from the kernel package.

The VFS infrastructure extends interface methods to add new file systems and to remove them from the kernel. The register_filesystem adds the new file system to the kernel. A successful operation returns 0, and failure returns a negative error code.

```
extern int register_filesystem(struct file_system_type*);
extern int unregister_filesystem(struct file_system_type*);
```
