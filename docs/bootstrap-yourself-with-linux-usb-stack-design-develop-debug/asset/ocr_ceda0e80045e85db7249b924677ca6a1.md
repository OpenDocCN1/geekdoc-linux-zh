The Linux USB community is an active one. Companies such as IBM, Google, Samsung, Texas Instruments, and Nokia play important roles. The Linux USB mailing list typically gets 1,000 e-mails or per month (http://marc.info/?l=linux-usb).

The official Web site of the Linux USB subsystem is http://www.linux-usb.org/. Refer to the Web site if you want to better understand the transformation of the Linux USB stack from Linux kernel 2.2.7 to where it is. The Linux-USB community's current goals for the 2.6 kernel are correctness, reliability, performance, functionality, power management, and driver coverage.
