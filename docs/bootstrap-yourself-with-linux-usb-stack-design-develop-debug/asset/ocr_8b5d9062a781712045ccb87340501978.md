# USB SYSTEM ARCHITECTURE

A USB system can be divided into three major areas: the USB device, the USB host, and the USB interconnect. The USB device refers to the physical entity that performs the required function. The USB host system refers to the system that installs the host controller to interface with the devices. Finally, the interconnect refers to the manner in which USB devices are connected to and communicate with the host.
