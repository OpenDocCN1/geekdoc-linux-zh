Another important framework is the optional composite driver framework, which sits on top of the gadget driver and provides a framework to build multifunction devices. To support multiple functions, the composite framework provides methods to add functionalities, configurations, and data structures to maintain them. The composite framework uses two data structures to manage the framework: struct usb_function and struct usb_configuration. It is defined in include/linux/usb/composite.h. The usb_function holds information and callbacks of a function in the gadget driver; similarly, the struct usb_configuration maintains details on the gadget configurations.

```
struct usb_function {
const char *name;
struct usb_gadget_strings **strings;
struct usb_descriptor_header **descriptors;
struct usb_descriptor_header **hs_descriptors;
struct usb_configuration *config;
int (*bind)(struct usb_configuration *, struct usb_function *);
void (*unbind)(struct usb_configuration *, struct usb_function *);
```
