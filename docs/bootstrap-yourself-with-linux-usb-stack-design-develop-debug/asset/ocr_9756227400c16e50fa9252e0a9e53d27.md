# Overview of sysfs

mounted in the / The contents of the USB sysfs directory
are all illustrated here.

```
rajaram@rajaram-laptop:/sys/bus/usb$ ls
devices drivers_autoprobe drivers_probe uevent
```

The devices directory contains information on the USB devices connected to the system. The following terminal activity illustrates the /sys/bus/usb/devices directory.

```
rajaram@rajaram-laptop:/sys/bus/usb/devices$ ls
1-0:1.0 3-0:1.0 5-0:1.0 6-1 6-1:1.1 7-3 us1 usb3 usb5 usb7
2-0:1.0 4-0:1.0 6-0:1.0 6-1:1.0 7-0:1.0 7-3:1.0 us2 usb4 usb6
```

The usb* directories represent USB controllers connected to the system; the * indicates the bus number assigned to each controller. From the log, you can infer that each setup has seven usb host controllers. The other entries in the directory with the format bus-port.port.port:config.interface represent the devices and their interfaces. For 7-3:1.0 represents a device connected to port 3, bus 7, configuration 1, interface 0. The other devices with format bus-0:1.0 represents the root hub's interface.

The device 7-3:1.0 connected to the system is a mass storage device. The following terminal activity illustrates the content of the 7-3:1.0 directory, which provides details of the connected device. Some information is read only, such as the bEndpoints and interfaceclass.
