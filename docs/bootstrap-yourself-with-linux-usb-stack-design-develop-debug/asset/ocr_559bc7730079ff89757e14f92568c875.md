# Appendix = USB Regression Tool

+   - int write_usb_bulk(int busid, int devid, int ep, char* data, int size, int timeout);

This script function transfers bulk data to the USB device specified by the busid and devid parameters. You should call this function after successfully opening and claiming a device.

+   - int read_usb_bulk(int busid, int devid, int ep, char* data, int size, int timeout);

This script function receives bulk data to the USB device specified by the busid and devid parameters. You should call this function after successfully opening and claiming a device.

+   - int write_usb_interrupt(int busid, int devid, int ep, char* data, int size, int timeout);

This script function transfers interrupt data to the USB device specified by the busid and devid parameters. You should call this function after successfully opening and claiming a device.

+   - int read_usb_interrupt(int busid, int devid, int ep, char* data, int size, timeout);

This script function receives interrupt data for the USB device specified by the busid and devid parameters. You should call this function after successfully opening and claiming a device.

+   - int usb_control_message(int busid, int devid, int requesttype, int request, int value, int index, char* data, int size, int timeout);

This script function transfers control messages to the USB device specified by the busid and devid parameters. You should call this function after successfully opening and claiming a device.

+   - int claim_usb_interface(int busid, int devid, int interface);

This function allows you to claim a particular interface of a USB device specified by the busid and the devid. You should call this function after successfully opening a a device.
