The universal serial bus (USB) host system software is responsible for managing control and data flow between the host and devices, power management, and enumeration. The USB host system software is complex, and the design is specific to the operating system. In Linux, the USB host system software module is referred to as usscore, which implements these host functionalities. Previous chapters explored features such as power management, the hub, and other miscellaneous functionalities, such as the device file system. This chapter explores the framework that implements control and data flow of part of the system software along with the framework that develops class drivers. Figure 9.1 is a simple representation of this framework within the Linux USB host system.

Because this part of the usbcore module is responsible for most of the USB host functionality, we provide a hypothetical name for this framework, say, uscore-generic for ease of reference.
