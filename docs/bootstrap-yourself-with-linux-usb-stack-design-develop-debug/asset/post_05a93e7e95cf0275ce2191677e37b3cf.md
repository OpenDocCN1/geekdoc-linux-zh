Design, Develop, Debug, and Validate Embedded USB

- Clarifies complex concepts with UML activity diagrams and sequence diagrams that present the Linux-USB subsystem framework visually
- Comprehensively explores methods to develop user space USB drivers and debug and test USB devices using the Linux-USB framework
- The accompanying CD-ROM provides all the sample programs discussed in the book, as well as an exclusive tool to perform regression tests of a USB system
