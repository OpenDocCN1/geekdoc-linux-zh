occurs when suspending a USB device using auto suspend. During the process, only USB interfaces and the device activities are suspended.

A USB device can resume activity either from user space by writing to *power/file* or by remote wakeup activity. Figure 7.4 illustrates the sequence of activities that occurs when a USB device is activated through *power/file*. The resume operation is started by writing "on" to the *power/level* of the USB device.
