# Linux USB Host Subsystem

Having gathered a basic understanding of how the source code of the Linux USB subsystem is placed in the kernel tree, the following sections provide a brief overview of the Linux USB subsystem, with various configuration options available in those subsystems that can help you add specific USB functionalities to the platform.

# LINUX USB HOST SUBSY

The Linux USB host subsystem, or the system software, referred to by the USB specification, consists of drivers for the host controller, driver modules that implement the USB protocol, and functional drivers. There are additional driver modules, such as the file system and debugging functionalities as part of the host subsystem. Figure 3.1 illustrates an architectural view of the Linux USB subsystem.
