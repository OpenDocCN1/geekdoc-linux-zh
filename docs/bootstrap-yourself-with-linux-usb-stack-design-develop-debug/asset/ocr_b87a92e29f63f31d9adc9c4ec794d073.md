# SUMMARY

A key factor in successful software development is having proper internal debug
mechanisms. The Linux USB subsystem provides solid debug methods and
makes development using the Linux USB subsystem easy. The tools compre-
hensively cover different functionalities of the subsystem. This chapter explored
these tools and discussed how to use them during development. You need to
understand their design and apply them in proper places.

In the next chapter, you will learn various options available to test a USB system
using the Linux framework.
