The universal serial bus (USB) On-the-Go (OTG) specification, a supplement to the USB 2.0 specification that evolved in early 2000, was introduced to enable USB devices to support minimal USB host capability that enables point-to-point communication. Such a setup allows embedded devices such as digital cameras, mobile phones, and printers to connect to each other directly, as illustrated in Figure 15.1.

An embedded USB device that switches roles, referred as dual role device, has features that include minimal USB host capability, Session Request Protocol (SRP), Host Negotiation Protocol (HNP), and 8mA on VBUS. You should read the OTG specification regarding these protocols and how the role switching takes place; the topic is beyond the scope of this chapter.
