The EHCI HCD support is provided by USB_EHCI_HCD. There are other EHCI-specific menu options that you might need to choose if the support for transaction translators or big endian mode is required for certain controllers.

The following configuration from drivers/usb/host/Kconfig shows the EHCI driver configuration and its dependency.

```
config USB_EHCI_HCD
tristate "EHCI HCD (USB 2.0) support"
depends on USB && USB_ARCH_HAS_EHCI
```

The configuration (drivers/usb/host/Kconfig) also provides an option to selectively enable the transaction translator feature, which enables the HCI driver to support full- and low-speed devices.

```
config USB_EHCI_ROOT_HUB_TT
bool "Root Hub Transaction Translators"
depends on USB_EHCI_HCD
config USB_EHCI_TT_NEWSCHED
bool "Improved Transaction Translator scheduling (EXPERIMENTAL)
depends on USB_EHCI_HCD && EXPERIMENTAL
```
