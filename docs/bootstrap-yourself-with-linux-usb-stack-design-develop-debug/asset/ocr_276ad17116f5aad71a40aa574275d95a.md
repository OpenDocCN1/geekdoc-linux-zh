The next important data structure of a VFS framework is struct file_operations, which allows you to access the created files. The file operation decides how to manage the information in the file. It offers methods to read, write, and move file pointers using lseek operations. Files may not support such operations as lseek. It is not necessary to implement all methods.

```

struct module *owner;
```
