+   - void usb_ep_autoconfig_reset(struct usb_gadget * )

This method resets previously auto-configured gadget endpoints. Internally, it clears states such as ep->driver_data and the record of assigned endpoints used by usb_ep_autoconfig().

# Gadget Driver: Design

The gadget driver implementation is part of the Linux USB gadget subsystem; its implementation is generally coupled along the PDC driver implementation. The data structures required for the gadget framework are defined in include/linux/usb/gadget.h.
