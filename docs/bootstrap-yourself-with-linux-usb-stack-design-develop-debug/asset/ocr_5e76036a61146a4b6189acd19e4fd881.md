# ## OVERVIEW OF UBSFS

From the previous chapters, you know that the USB host file system is part of the uscore implementation. When the uscore module is loaded into the kernel, the USB host VFS is initialized, and it is ready to be mounted in the user space. The usbfs files are generally mounted to the /proc directory. The following terminal activity illustrates the step to mount the usbfs virtual file:
root@rajaram-laptop:/proc/bus/usb# mount -t usbfs none /proc/bus/usb

**Tip**

> The VFS of uscore was initially referred to as usdevfs and later renamed to usbfs to avoid confusion with the devfs file system.
