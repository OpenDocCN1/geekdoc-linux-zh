# LINUX USB UNIT TEST DRIVER

The Linux test module is part of the Linux USB subsystem's miscellaneous configuration that is implemented in drivers/usb/misc/usbtest.c. You can configure this module through the kernel menu configuration and generate usbtest.ko. You can control the test cases implemented in this module user space applications. The tests include control transfer and data transfers such as bulk and isochronous (ISO). These tests exercise the host controller driver (HCD) and the gadget framework. Some of these tests must run continuously to ensure that both the USB hardware and software are error free.

There are approximately 16 test scenarios. Table 19.1 explores the available as part of the usbtest module.

| Table 19.1 Test Case Scenarios of usbtest module |
| Test Scenario | Test Description |
| Test Case 1: Write data bytes N times | This scenario writes data to a bulk endpoint of the device for N times, as specified by the user space application. Internally, the USB test driver calls the leaf function simple_io with the number of times data to be written and executed for the test scenario. The simple_io submits the URBs using the usb_submit_urb formed by the simple_alloc_urb routine. This test scenario effectively tests the endpoints for contiguous operations. The user space applications effectively design the data patterns. |
| Test Case 2: Read data bytes N times | This scenario reads a bulk endpoint of the device for N times, as specified by the user space application. In this scenario, the test driver calls simple_io to submit the URBs by usb_submit_urb. The user space applications need exercise hardware endpoints to effectively pass on the loop count. |
| Test Case 3: Write data (varying length) bytes N times | This scenario writes data of variable lengths to a bulk endpoint of the device for N number of times, as specified through the user space application. In this scenario, the test driver invokes simple_io but varies the data size. Such test cases can exercise the hardware with data of various sizes.
