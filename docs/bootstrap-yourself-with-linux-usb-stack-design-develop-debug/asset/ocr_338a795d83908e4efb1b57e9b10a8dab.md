The id_table holds information to match the device of interest to the device driver, generally the vendor ID and the product ID.

When the device exits or is unloaded from the kernel, remove the driver from the usbcore module using usb_deregister.

```
static void __exit usb_skel_exit(void)
{
    /* deregister this driver with the USB subsystem */
    usb_deregister(&skel_driver);
}
```
