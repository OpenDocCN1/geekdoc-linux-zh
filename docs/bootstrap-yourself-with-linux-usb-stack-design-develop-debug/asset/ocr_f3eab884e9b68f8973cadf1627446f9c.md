Linux is part of the usbcore, which implements USB requirements such as remote wakeup. The power management framework also provides a VFS to manage the framework from user space.

# **USB Hub Driver**

The USB hub driver framework implements the USB hub requirements and is part of the usbcore. The hub framework is responsible for resetting the device and announcing new devices to other modules.

# **USB Host Driver**

The USB host driver framework implements USB transfers and other USB Block requirements. The host driver also manages USB Request Block (URB) transfer from the class drivers to the HCDs.
