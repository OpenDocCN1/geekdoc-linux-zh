# 234 Part II: Using Fedora and RHEL

Installation consists of three steps: Installing Wine in RPM format, installing the guest operating system (Windows 98, 2000, or ME; XP is still experimental), and setting up a guest session. Then you run a full Windows system from Linux desktop, installing and running any applications you choose.

+   - QEMU — QEMU (http://bellard.org/qemu/) is an open source project that acts as processor emulator. It can emulate a full system or work in mode emulation (where it can be used to test processes compiled for different CPUs). In this system emulation, QEMU can run a variety of operating systems, including Windows 3.11, 95, 98SE, ME, 2000, and possibly XP.

For applications intended for other operating systems, QEMU can also run several Linux (KNOPPI, Mandrake, Morpheus, Debian), and other UNIX-like systems (NetBSD, Solaris, and others). QEMU can take advantage of virtualization features, KVM, which have recently been added to the Linux kernel (described later in this chapter).

The rest of this section describes how to get and use Wine applications in Linux. To get WINE for your Windows system, you can go to the following places:

+   - WINE in Fedora —As of Fedora 7, Wine became part of the main Fedora software repository. The wine and wine-core packages are needed to use WINE. Additional support follows: wine-cap (ISDN support), wine-cms (color management), wine-jack (JACK sound support), wine-ldap (LDAP support), wine-nas (NAS sound support), wine-tools (useful Windows utilities), and wine-twin (scanner support). Add wine-docs for further documentation or wine-devel, for WINE development components.

+   - Cega — A commercial version of WINE called Cega (formerly called WineX) is available from TransGaming, Inc.(http://www.transgaming.com). TransGaming focuses on running Windows games in Linux, using WINE as its base. See Chapter 7 for descriptions of Cega.

+   - CodeWeavers — If you need Microsoft Office or web browser plug-ins, CodeWeavers (http://www.codavers.com) offers CrossOver Linux. Although CrossOver costs money, it offers free interfaces for installing and managing Windows software. A 30-day free trial is available.

While it's true that you can run many Windows applications using WINE, some fiddling is still required to get many Windows applications to work. If you are considering your desktop systems from Windows to Linux, the current state of WINE provides an opportunity to see if Windows applications you might need run in Linux.
