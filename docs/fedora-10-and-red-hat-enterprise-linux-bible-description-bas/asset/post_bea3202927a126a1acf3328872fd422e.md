# Training and Certification

If you are looking for a career in Linux, Red Hat offers some well-respected programs for becoming a certified expert in Red Hat software. You can learn about available programs from Red Hat's training Web site (https://www.redhat.com/training).

If you plan to pursue any of the Red Hat certification programs, don't be surprised after some theoretical training you are given a misconfigured computer and asked to fix it. Those who get Red Hat certifications are expected to be able to clean and run Linux systems in the real world.

Here is a list of available certifications from Red Hat:

- * Red Hat Certified Technician (RHCT) — An RHCT is the most basic Red Hat certification. It focuses on core skills needed by a Red Hat system administrator. Besides being able to install and configure an RHEL system to come up on a corporate network, you are also expected to understand basic troubleshooting.
- * Red Hat Certified Engineer (RHCE) — The RHCE program builds on the skills developed in RHCT program. For RHCE, however, additional capabilities in security and deploying network services are expected.
- * Red Hat Certified Security Specialist (RHSS) — As the name implies, becomes proficient in security-related aspects of managing Red Hat Enterprise systems. Courses with this certification include Network Security, SELinux Policy and Administration.
- * Red Hat Certified Architect (RHCA) — An RHCA skills are expected to go beyond those of RHCT or RHCE. RHCA program focuses on deploying and managing multiple Linux systems across an enterprise, with special attention given to systems management, storage management, performance tuning, and directory services.

For courses on RHCT, RHCE, RHSS, and RHCA, visit the Red Hat Certified Engineer page (https://www.redhat.com/training/). Before taking RHCT exams, check out RHCE and Exam Preparation Guide (http://www.redhat.com/certification/rhce/prep_guide/). Red Hat offers many courses for Red Hat training, as well as courses in networking, programming (Java, Object, Web, and IT management).

# Managing RHEL Systems

The ability to manage and grow your Linux infrastructure efficiently are probably the best reasons for using RHEL systems. Red Hat created Red Hat Network to allow you to track and update RHEL systems properly. With different subscription levels come increased levels of support and features for maintaining anywhere from one to thousands of systems. Using features including global file systems (GFS) and high performance computing (HPC) clustering techniques, Red Hat offers help creating a flexible and efficient Linux infrastructure. This infrastructure lets you expand your computing capacity incrementally without discarding.

# Using Red Hat Network

Red Hat Network (https://rhn.redhat.com) offers a service for managing your Linux systems. You can try Red Hat Network with an evaluation subscription. From the Red Hat Network site, you can upgrade your system to a paid subscription or sign up for additional entitlements to manage multiple RHEL systems.

Red Hat Network developed to help companies implement and manage their Linux infrastructure. There are several different architectures in which Red Hat Network can be configured. These different architectures allow you to choose whether your RHEL systems talk directly to Red Hat Network (to manage system entitlements and updates), or to a satellite or proxy server set up on your premises.

The architecture you choose will impact the level of control you can exert over your RHEL systems. Here are the choices:

- **Hosted model** — With a hosted model, each RHEL system communicates directly with Red Hat Network for managing the updates it gets. Updates are based on the appropriate channel for the hardware and software you are using. Information is stored by Red Hat servers, as opposed to being managed locally on your own network.
- **Proxy model** — The proxy model works similarly to the hosted model, but instead of having each system get updates individually from Red Hat Network, a proxy server is set up on the customer premises, so each update needs to be downloaded to your network only. Individual systems then get the updates they need from the local proxy server. Although updates are stored locally, information about channels and entitlements are still managed by Red Hat Network servers.
- **Satellite model** — All Red Hat features (system management, updates, and so on) are located on your local network. Updates are downloaded from Red Hat Network to your satellite, or proxy server. Features for managing custom channels and other tasks normally done by RHN are offloaded to the satellite server. The satellite model is typically used for large enterprises that want to maintain more control and security over their deployment of service. Different levels of support and training are available, although the intent is to have Red Hat act as technical consultant while your employees manage system and database administration for your network server.

Beyond the basic Update service, there are levels of support you can purchase from Red Hat. The Management and Provisioning programs are aimed at helping you RHEL systems across an entire organization. Here's what you get with those:

- **Management** — With this subscription level, an organization can assign administrative users to manage groups of systems. An Organization Administrator has the ability to assign those users and the systems to which they have access. To manage your systems, a user can do such as complete package sets installed on different systems, search groups of systems for installed packages or hardware tags, group systems together so they can be managed as a group, and adding or removing software packages for a batch of systems.
- **Provisioning** — The Provisioning subscription level includes all features of the Update and Management levels, but adds further features for managing multiple systems. For example, you can create profiles that allow you to install groups of systems with many features preset (such as time zone, GPG and SSL keys, and specific package sets).
