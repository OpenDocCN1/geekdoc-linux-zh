After logging in to Mugshot, you'll see the following information, starting from the top of the Big Sidebar in Figure 3-17:

+   * User Information—The name and face image appears in the top box of the Mugshot desktop. Select that box to logout of the desktop, view the Mugshot account page, or minimize the sidebar.

+   * Tiny Icons—The tiny icons below the User Information represent the online services you have configured for your Mugshot account. Beginning with the top-left icon in the example, these icons represent Digit, Picasa, Amazon, Netflix, Del.icio.com, your home URL, Reddit, Twitter, and Flickr.
