# Using Samba from Nautilus

To connect to a Samba share from Nautilus, use the Location Box by clicking File -> Open Location. Then type **smb:** into your Nautilus file manager Location box.

A list of SMBwork groups on your network appears in the window. You can select a workgroup, choose a server, and select a resource to use. This should work for shares requiring no password.

The Nautilus interface requires you to send clear-text passwords or type the user and password into your location box. For example, to get your home directory (/home/chris) through Nautilus, I can type my user name, password, server name, and share name as follows:

```
smb://chris:my72rgb@toys/chris
```
