+   7. Grab the slider bar from the right and move it to how much you want to resize your partition. The New Size box shows the new size of your partition. The Free Space Following MiB shows how much free space you will have after you are done. In my example, on a small disk I resized /dev/sda to about 15GB, leaving me about 5GB of free space that I can use to install Fedora (normally, you would want more for Fedora, if space is available). Figure 2-1 shows the GParted window resizing about a 20GB partition to about 15GB.

+   8. Click Resize/Move to begin resizing your partition. When it is done, you will see the resized partition and a new entry showing the free space.

> CAUTION: The resize is committed in the next step. You can quit without making any changes if you are nervous. In any case, make sure that the partition you are resizing is not mounted. (In this example, I'd type /dev/sda as root user from a shell before beginning the next step)

+   9. If the partition size looks alright, click Apply to commit the changes.

+   10. At this point, you can use the GParted window and begin the installation procedure for Fedora or RHEL, using the disk space you have just freed.

After you have installed Fedora or RHEL, there are a few useful things you might want to do when you manage your partitions in Linux.

> NOTE: By default, Fedora and RHEL are configured to hide the GRUB boot screen that lets you select which operating system to boot. You will have to press any key, as the Fedora boot counts down 5 seconds, to see the GRUB boot screen. You might consider editing the grub.conf file, as described later in this chapter. Personally, I removed the hiddenmenu line and increased the timeout from 5 to 10 seconds.
