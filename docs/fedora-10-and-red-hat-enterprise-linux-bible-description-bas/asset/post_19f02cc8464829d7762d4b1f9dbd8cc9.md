# Adding more games from Fedora repository

As Fedora continued its role as a proving ground for the Red Hat Enterprise Linux products, some-just-for software packages were pushed out of what was called Core. Luckily, many of them were pushed into Fedora Extras. With the merging of Fedora Extras and Core, all games are now back in the main repository.

Because the Fedora Games SIG is an on-going initiative, you can check the Fedora Project Web site to see if there are more games than shown in Table 7-3 available in Fedora by opening the PackageKit and selecting games.

You can install each game from the Fedora DVD included with this book. Most, but not all, of the games available in the Fedora repository are included on the DVD. To check packages that have been added later, type yum groupinfo games. To install a version of the game from the Fedora repository, use the following type, replacing game with the name of one of the games listed in Table 7-3:

```
# yum install game
```

Table 7-3 contains a sample from the growing list of games available from the Fedora repository. There are now over 200 games packages in Fedora. Except where noted, all games in Table 7-3 can be launched from the Games list on the Applications menu.

## Chess games

Chess was one of the first games played on computer systems. While the game hasn't changed over the years, the way it's played on computers has. The Chess programs (represented by xboard and gnchess) describes itself as a communal program. It has many contributors, and it seeks to advance a “more open and friendly environment of sharing” among the chess community. With xboard, you can move pieces with your mouse.

To play against the computer, use xboard from a Terminal window. Then just start moving a piece with your mouse. While in the xboard window, select Menu -> Two Machines to have the computer play itself. Select File -> Load Game to load a game in Portable Game Notation (PGN). Figure 7-1 shows the xboard window with Two Machines

You can use chess to play against others by connecting your session to Internet Chess Server (ICS). To start xboard as an interface to an ICS, you type the following command line:

```
$ xboard -ics -ichost name
```

In this example, name should be replaced with the name of the ICS host (see the list of hosts below). In ICS mode, you can just watch games, play against others, or replay games that have finished. The ICS host acts as a gathering place for enthusiasts who want to play chess against others on the Internet, watch games, participate in tournaments, or just meet chess people. Here is an example of an ICS session at chess.net from a Terminal window:

```
$ xboard -ics -ichost chess.net
```

When you first visit, type guest and press Enter. If there are not too many guests already, you are logged into the chess server as a guest. (You can add a real account later by typing /register). The chess window opens on your screen. Keep an eye on the Terminal window where the session started. Someone will probably challenge you to a game within a few moments. For example, if a challenge ends with Type '/accept 102' to accept the sought challenge, you type:

```
chess% /accept 102
```

You can begin playing. Learn more about how to play, visit http://chess.net/help. Select the Beginners Manual to start. Other chess servers you can include the Internet
