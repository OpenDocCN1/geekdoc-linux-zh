# Chapter 1: An Overview of Fedora and Red Hat Enterprise Linux

With the addition of yum software repositories on the Internet that include Fedora packages, whole sets of RPM software packages can be updated with a yum update command. The PackageKit facility provides graphical tools with Fedora to install from multiple software repositories on the Internet (as opposed to local CD or DVD media) A desktop applet automatically alerts when updated packages are available to download and install. See Chapter 5 for descriptions of these tools.

# New Features in Fedora 10

When it comes to versions of different software projects that come with Fedora, the major components in Fedora 10 include (with version numbers):

+   * Linux kernel: version 2.6.27
* GNOME (desktop environment): version 2.24
* KDE (desktop environment): version 4.1.2
* X Window System (X.org graphical windowing): version 11, Release 1.5
* OpenOffice.org (office suite): version 3
* GIMP (image manipulation application): version 2.6.1
* GCC (GNU C language compilation system): version 4.3.62
* Apache (Web server): version 2.2.9
* Samba (Windows SMB file/printer sharing): version 3.2.6
* CUPS (print services): version 1.3.9
* Sendmail (mail transport agent): version 8.14.3
* vsFTPd (Usenet FTP server): version 2.0.7
* INN (Usenet server): version 2.4.5
* MySQL (database server): version 5.0.67
* BIND (Domain name server): version 9.5.1

> TIP: These features are constantly being updated. Fedora ships with tools to help keep your system to date with the latest versions of software.
