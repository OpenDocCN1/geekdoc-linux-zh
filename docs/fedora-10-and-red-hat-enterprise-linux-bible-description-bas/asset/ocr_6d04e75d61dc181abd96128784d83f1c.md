# Burning an ISO image to CD

Before your songs are copied to CD, they are gathered together into a single archive, referred to as an ISO image. You can download ISO images of software (such as the DVD or CD images used to install Fedora). Although an ISO only looks like one big file before you burn it, if it is burned to a CD it appears as a filesystem containing multiple files. To burn any of the images you described to a CD using K3b, do the following:

+   1. Download or otherwise copy an ISO image to a directory on your hard disk. A CD image will be up to 700MB, while a DVD can be over 4GB.
2. From the K3b window, select Tools $ightarrow$ Burn CD Image. A Burn CD Image window appears.
3. Next to the Image burn box, select the folder icon to browse your file system to find the ISO image. If you select the image, it is loaded into the Burn CD window, which will display information about the image, including its MD5sum.
4. Check the MD5sum and compare it with the MD5sum with the image you downloaded. (There is likely a file ending with .md5 in the directory which you downloaded the image).
5. If the MD5sums match, continue by checking the settings on the CD Image window. I had generally good luck using the default settings. However, I find that if I get a bad burn, often changing the setting from Auto to a slower speed is what allows the result to be a good burn.
6. Click Start to begin burning the image to CD. When the writing is done, K3b tells you whether it the burn process was successful.

The descriptions for burning CDs apply to DVDs as well (provided you have a DVD burner). Remember that you are going to need a lot more temporary space on your hard disk to work with DVDs than you would to work with CDs.
