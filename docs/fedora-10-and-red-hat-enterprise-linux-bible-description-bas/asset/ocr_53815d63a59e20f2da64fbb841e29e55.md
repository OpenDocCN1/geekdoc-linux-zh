The following describes the basic Internet structure in more detail:

+   - IP addresses — These are the numbers that uniquely define each computer known to the Internet. authorities assign pools of IP addresses (along with network masks, or netmasks) so that administrators can assign addresses to each individual computer that they control. An alternative to assigned addresses is to use a reserved set of private IP addresses, so multiple computers in your home or business can share a single IP address.

CROSS-REFERENCE — See Chapter 15 for a further description of IP addresses.

+   - Port numbers — Port numbers provide access points to particular services. Port numbers are like channels on a television. While all ports are inherently the same, many ports are associated with a particular service. A server computer will listen on the network for packets addressed to its IP address, ... For example, a Web server will listen to port 80 to respond to requests for HTTP content. A browser will know, by default, to make its request for HTTP (in other words, a Web page) to port 80 on the server.

> NOTE: In reality, you can assign any service to any port you choose. In fact, administrators sometimes assign services to unused ports for the purpose of keeping most outsiders from finiding them. If you decide to use a non-standard port for a service, you should try to avoid port numbers that are already assigned for common services, these ports might end up scanned by an intruder anyway. A client of your service would have to know that port specifically. For example, http://www.example.com:4863 would request content from port 4863 from the host www.example.com.
