## Connecting to NFS from the command line

You might well not have any control over how the Linux NFS server is configured. So if the insecure option isn't set, you will fail to mount an directory from the Mac's Connect to Server. A possible workaround is to manually mount the NFS directory from Mac OS X use a secure port. Here's how:

- 1. On the Mac OS X, gain access to the root user account as follows:
    a. With the Folder icon selected, select Go $\rightarrow$ Applications. The Applications folder appears.
    b. Open the Utilities folder, then the NetInfo Manager utility.
    c. Click the lock icon on the NetInfo Manager window so that it unlocks.
    d. Select $\rightarrow$ Root User. (If you see a NetInfo error, click OK.).
    e. Type in and verify the new root password, and then click Verify. (Remember that password!)
    f. Click the open lock icon to close it and prevent further changes.

- 2. On the Mac OS X, click the Terminal icon to open a shell and log in as root:
```bash
$ su -
Password: ********
```

- 3. Create a directory that is accessible to the user account of the person who wants to use the shared NFS directory on the Mac. For example, the user chris you might type:
```bash
# mkdir /Users/chris/music
# chown chris /Users/chris/music
```

- 4. Mount the NFS shared directory on the directory you just created. For example:
```bash
# mount -o "-P" jukebox.linuxtoys.net:/var/music /Users/chris/music
```

The -P says to use a privileged port. Replace jukebox.linuxtoys.net and /var/music with the server's name and the shared directory, respectively. The user can now access /var/music from the /Users/chris/music directory on the Mac OS X client.

## Installing Fedora on an Intel-based Mac

The Apple computers feature Intel-based computer architecture. The Fedora Project has enhanced Fedora so that it can be installed (by either itself or dual booting with Mac OS X) on this new hardware. Reasons you might want to install Fedora on any of these "Macel" computers:

- Dual booting — You might like the Mac OS X desktop (Aqua) and proprietary applications (such as iPod or iTunes) for yourself or family members of the time. However, you might want access to server applications, administration tools, development environment, or thousands of free applications you can get with Fedora.

- Fedora only — Although you pay a bit of a premium for Apple hardware (though not much as you used to), you might like the features and those of cute Apple Mac computers enough to pay a bit extra to have as your primary desktop computer.

This section describes how to start with an Intel-based Apple Mac computer (I used a Mac Mini for this) and configure it to either dual boot with Mac OS X or run on Fedora.

> CAUTION: Installing Fedora on Intel-based hardware is still a technology that is experimental in the Fedora community. Some hardware still require extra tweaking or won't work at all. I recommend that you do not do this procedure if you cannot afford the possibility that your disk may be blown away and have to be reinstalled from scratch.

## Before installing Fedora on your Mac

Let's start with a reminder that this procedure is only for Apple Mac computers that are based on Intel architecture. I ran this procedure on a new Mac Mini 1.1 (Intel Core Duo CPU, 512MB RAM). However, the same procedure would work for Intel-based iMac, MacBook, MacBook Pro, or Mac Pro computers.

This procedure is not for Macs with PowerPC architectures. Fedora supports such configuration, but you need to download the pcs installation media from Fedora instead of using the DVD that comes with this. (Get the media for installing on PowerPCs from http://fedaproject.org/wiki/Distribution/) When you purchase your Mac, the hard disk is devoted to Mac OS. To keep your you need to reduce the amount of space devoted to Mac OS X. Then you need to use that space to create or more partitions for installing Fedora.

Although the procedure for resizing and repartition your disk is fairly safe, there is some risk that you could corrupt your Mac OS X partition or make the machine (temporarily) unbootable. For that reason, before starting the procedure that follows, please ... BACK ANY IMPORTANT DATA!

Mac OS X Leopard offers called Boot Camp that can be used to resize Mac hard disks (using the default HFS+ file system). Until Leopard was released, the beta version of Boot Camp was available as a free download from Apple. The following procedure describes how to update your firmware, resize your disk, and install Fedora.

> NOTE: Because Boot Camp is no longer available for Mac OS X versions prior to Leopard, there is no official way to resize your disk to allow multiple boots on your Mac. However, in theory you should be able to use a partitioning tool that supports HFS+ resizing to prepare your disk to install Fedora along side Mac OS X. Refer to Chapter 2 for information on how GPTart can be used to resize partitions, such as HFS+ partitions. If you decide to try it, your results come without warranty. (In other words, you're on your own.)

- Insert Fedora DVD — When partitioning is done, instead of inserting a Windows Installation CD as requested, insert a Fedora installation CD or DVD and Restart Mac OS X or Install Windows to reboot the computer. When reboots, you should see the Fedora installer boot screen.

- Reboot and Alt key — When Fedora installation is complete, reboot. Hold the Alt key as the machine reboots. When you see the Boot Camp menu, select Windows and the computer will boot to Fedora. Just use the default boot entry for Fedora because trying to change GRUB will probably cause the computer to lock up.

If some reason you don't have your DVD handy, you can find information on how to download live and install CDs and DVDs from the Project Web site at http://fedaproject.org. If you have a DVD drive on another computer on your LAN, see Chapter 2 for information on setting up a Fedora installer, so you can install Fedora on your chosen machine over your LAN.

## Summary

Because Darwin, a UNIX-like operating system, lies at the heart of Mac OS X, you can find many similarities between Fedora and Mac. In this chapter we have covered how to install Fedora on Mac. You can install any other software you need from online repositories or you can share files with others using Samba and NFS.
