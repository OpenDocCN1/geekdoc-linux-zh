value set. (Remember to remove the export from the $HOME/.bashrc file — if you added it
there — or it will return the next time you open a shell.)

# Managing background and foreground processes

If you are using Linux or from a dumb terminal (a monitor that allows only
text with no GUI support), your shell may be all that you have. You may be used to a
windowing environment where you have a log of programs active at the same time that you
can switch them as needed. This thing can seem pretty limited.

NOTE: One way to overcome the limitations of a single shell is to use the screen command. Screen
allows you to have multiple shells open at the same time, as well as disconnect and reconnect to
shell sessions without completely closing them. Install the screen package to use the screen command.
Type man to read about the screen command.

The bash shell doesn't include a GUI for running many programs, but it lets you
move programs between the background and foreground. In this way, you can have a
lof stuff running, while selectively choosing the one you want to deal with.

There are several ways to place an active program in the background. One mentioned earlier
to add an ampersand (&) to the end of a command line. Another way is to use the at
commands in a way in which they are not connected to the shell. (See Chapter 12
for information about the @ command)

To stop a command and put it in the background, press Ctrl+z. After the command is
stoped, you can either bring it to the foreground to run (the fg command) or start it running
in the background (the bg command).

# Starting background processes

If you have programs you want to run while you continue to work in the shell, you can
place the programs in the background. To place a program in the background at the time you
run the program, use an ampersand (&) at the end of the command line. For example:

```
$ usr > /tmp/allusrfiles &
```

This command finds all files on your Linux system (starting from /usr), prints those
filenames, and puts those names in the file /tmp/allusrfiles. The ampersand (&) runs
command in the background. To check which commands you are running in the
background, use the jobs command, as follows:

```
$ jobs
[1] Stopped (tty output) vi /tmp/myfile
[2] Running /usr -print > /tmp/allusrfiles &
[3] Running nroff -man /usr/man2/* >/tmp/man2 &
[4] Running nroff -man /usr/man3/* >/tmp/man3 &
[5]+ Stopped nroff -man /usr/man4/* >/tmp/man4
```
