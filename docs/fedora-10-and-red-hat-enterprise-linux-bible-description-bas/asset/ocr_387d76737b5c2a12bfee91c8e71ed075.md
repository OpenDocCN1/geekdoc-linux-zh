# Fixing Your System with FirstAidKit

Starting with Fedora 10, a new package FirstAidKit helps you fix any issues that may strike your system. Built on top of a pluggable architecture, FirstAidKit is an automated recovery tool that applies common techniques to rescue your system.

To use the FirstAidKit, you first need to install the package:

```
# yum install firstaidkit
```

The most common way to run the program is to let it do what it thinks it ought to be done—it is the whole automated part of the recovery tool. To do so, run the following command:

```
# firstaidkit -a
```

The program reports what it finds and the actions it takes.

To see the available plug-ins, use the the following command:

```
# firstaidkit --list
```

See https://fedorahost.org/firstaidkit/ for more on the FirstAidKit

# Choosing Software Alternatives

Because several software packages are available for every service available in Linux (such as mail, printing, Java environments, and so on), there will be times when people using the system will prefer one over another. Software packages that have been designed to work with the alternatives system can be configured in Fedora or RHEL to let an administrator choose which of the alternatives to a particular service he or she to use by default.

# Selecting Java alternatives

If you are developing Java applications, an addition to the alternatives feature lets switch between using a proprietary Java virtual machine (JVM) to using the GNU compiler for Java (gcj). Type the following to see which implementation of java is currently in use on your system:

```
# alternatives --display java
```
