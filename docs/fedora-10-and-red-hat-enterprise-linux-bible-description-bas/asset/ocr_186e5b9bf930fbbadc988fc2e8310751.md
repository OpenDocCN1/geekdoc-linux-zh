# Using the rpm command

The command used to work with RPM package files is rpm. To manage RPM packages, the
rpm command has options that you list all the packages that are installed, upgrade existing
packages to newer versions, and query packages for information (such as the files or
documentation included with the package). There is also a verify option to check that all files
make up the package are present and unchanged.
