# Chapter 2: Installing Fedora

CAUTION: Setting up a dual-boot system is discouraged by Red Hat and people who use Linux books (like me) because something goes wrong you lose all your data or make your computer unbootable (usually temporarily). New users often won't have a backup and will simply erase their hard disk if the computer won't boot after a process like the following. They complain a lot. So, I'm officially recommending against setting up a dual-boot system, and telling you how to do it.

Red Hat, Inc. encourages you to use VFAT file systems for your Windows partitions if you plan to boot your computer with Linux. Fedora also offers support for the NTFS file type. You can use tools from Fedora to resize your Windows partitions. Note that FAT32 partitions can only have a maximum size of 32GB.

If, after resizing your partitions and installing Fedora or RHEL, your computer becomes unbootable, refer to the "Troubleshooting Installation" section later in this chapter for advice on how to.

Before you begin your Windows system, boot Windows and do the following:

+   Back up your data! Of course, you should always have a backup of your important data. Now is a particularly good time to do a back up, just in case of those disc catastrophes you are actually about.

+   Defragment your disk. Before you resize your hard disk, use a defragmenting utility in Windows to have all files stored on the disk. That way, when you are freeing space to Linux partitions, you will have a continuous area of the disk to work with. To defr a disk in Windows XP, click Start -> All Programs -> Accessories -> System Tools -> Selecting Defragment from the Disk Defragmenter window. Defragmenting can take a while, depending on your processor speed and disk size.

While you have the Disk Defragmenter window displayed, note a few things about your hard disk that you will need to know:

+   File System The file system type will most likely be NTFS, although it may also be VFAT. If you have the option to install Windows from scratch, selecting VFAT as the file type will work much better for Linux. Support for writing to NTFS has been considered unreliable from Linux, although reading from NTFS seems to work well VFAT file systems, will work well for both Linux and Windows.

+   Free Space If your hard disk consists of a single Windows partition, you can resize your existing partition to use some of the free space to assign to Linux partitions. Note the amount of free space you have here and compare it to the amount you will need to install Linux (described earlier).

Despite the fact that I have successfully resized NTFS partitions using the GParted utility, I still recommend caution (a good backup of your data) before proceeding.
