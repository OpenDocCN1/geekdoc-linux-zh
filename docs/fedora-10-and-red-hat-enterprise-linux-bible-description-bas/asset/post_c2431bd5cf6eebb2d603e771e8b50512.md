# Understanding MySQL Tables

You have a lot of flexibility when setting up MySQL tables. To have your MySQL database operate as efficiently as possible, you want the columns to be assigned to the most appropriate size and data type to hold the data you need to store.

# Part IV: Fedora RHEL Network and Server Setup

Using the following tables as a reference to the different data types that can be assigned to your columns. Data types available for use in MySQL fall into these categories: numbers, time and date strings. There are a few things you need to know before you read these tables:

- The maximum display size for a column is 255. An M data type opts the number of characters that are displayed and, in most cases, stored for the column.
- There can be up to 30 digits following the decimal point for floating-point or fixed-point data types. D option to a data type indicates the number of digits allowed for a number following the decimal point. (The value should be no more than two digits less than the value of the display size being used).
- The UNSIGNED option (shown in brackets) indicates that only positive numbers are allowed in the column. This allows the column to hold larger positive numbers.
- The ZEROFILL option (shown in brackets) indicates that the data in the column will be padded with zeros. For example, the 25 in a column with a data type of INTEGER(7) would appear as 000025. (Any ZEROFILL column automatically becomes UNSIGNED).
- All values shown in brackets are optional.

The parentheses around the (M) and (D) values are necessary if you enter either of those values. In other words, don't type the brackets, but do type the parentheses.
