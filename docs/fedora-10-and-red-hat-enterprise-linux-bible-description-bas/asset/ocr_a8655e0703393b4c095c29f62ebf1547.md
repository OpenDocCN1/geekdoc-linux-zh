# Mounting Samba directories in Linux

Linux view shows shared directories as it does any other method (hard disk, NFS shares, CD-ROM, and so on). Using the mount command, you can mount a Samba shared file system that is permanently connected to your Linux file system.

The following example of mount command shows how I would mount my home directory (/home/chris) from a computer toys on a local directory (mnt/toys). As root user, from a Terminal window, type:

```
# mount /mnt/toys
# mount -t cifs -o username=chris,password=a72mg //toys/chris /mnt/toys
```

The file system for a Samba share is cifs (-t). I pass the user name (chris) and password (a72mg) as options (-o). The remote share of my home directory is //toys/chris. The local mount point is /mnt/ . At this point, you can access the contents of /home/chris on toys as you would any file or directory locally. You will have the same permission to access and change the contents of that (and its subdirectories) as if you were the user chris using those contents directly from toys.

To mount Samba shared directory personally, you can add an entry to your /etc/fstab file. For the example just described, you could add the following line (as root user):

```
//toys /mnt/toys cifs username=chris,password=a72mg
```

You can create a credentials file to use to contain your user name and password, instead of exposing that information to the command line. That way, someone running the ps command on your system will not be able to see that information. For example, you could create a file named /etc/samba/creds.smbpub containing the following lines:

```
username=chris
password=a72mg
```

You could then change the mount command shown earlier to appear as follows:

```
# mount -t cifs -o credentials=/etc/samba/creds.smbpub //toys/chris
```
