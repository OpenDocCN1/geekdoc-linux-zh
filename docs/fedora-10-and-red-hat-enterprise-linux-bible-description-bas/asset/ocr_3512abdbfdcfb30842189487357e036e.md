# Primary Advantages of Linux

When compared to commercially available operating systems, Linux's best assets are its price, reliability, and the freedom it gives you. With the latest 2.6 Linux kernel, we also argue that scalability is one of its greatest assets. The reliability of Linux includes its built-security features and architecture, both of which make Linux much more secure than Windows.

Most people know that its initial price is free (or at least $50 when it comes in a box or with a book). However, when people talk about Linux's affordability, they are usually thinking of its total cost, which includes no (or) licensing fees, the ability to use any of the code you choose, and the capability of using inexpensive hardware and compatible free add-on applications. Although commercial operating systems tend to encourage upgrading to more powerful hardware, Linux doesn't require that (although faster hardware and larger disks are nice to have).

In terms of reliability, the general consensus is that Linux is comparable to many commercial UNIX systems but more reliable than most desktop-oriented operating systems. This is especially true if you run on your computer to stay up it is a Web server or a file server. (You don't have to reboot every time you change something, unless you've replaced the kernel itself.)

This reliability also extends into the realm of safety. While there have been exploits at Linux software, Linux users are for the most part safe from the culture of malware and viruses that plague Windows users. With so many people peering at the Linux source code, a benefit of its freedom, mistakes are often fixed in time. Large-scale Linux deployments don't need to install anti-virus software, a situation you would never have with Windows in a corporate setting. Furthermore, when people install anti-virus software on Linux, it is usually to scan files and e-mail messages for Windows viruses, to help the distraught users of Windows.
