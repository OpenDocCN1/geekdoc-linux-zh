
## Chapter 2: Installing Fedora 55

NOTE: For further details about how to use kickstart, refer to the Red Hat Linux Configuration Guide. You can get this guide from any Red Hat mirror site. To use a more graphical tool for configuring kickstart, run the system-config-kickstart command (after installing the package of the same name with your yum system-config-kickstart command).

To start, log in as the root user. Then make a copy of the anaconda-ks.cfg file to work on.

```bash
# cp anaconda-ks.cfg ks.cfg
```

Use any editor to edit the ks.cfg file. Required that items should be in order and that any time you open an item, the user will be prompted for an answer. Entries from a ks.cfg file that was created from a DVD installation of Fedora are used as a model for the descriptions below. You should start with your anaconda-ks.cfg file, and as a result, your file will start out somewhat differently. Commented lines begin with a pound sign (#).

The first uncommented line in the ks.cfg file should indicate whether the installation is an upgrade or an install. The install option runs a new installation. You can use the upgrade keyword to upgrade an existing system. (For an upgrade, the only requirements are a language, an install method, a device, and a boot loader).

```bash
install
```

The method of installation is indicated on the next line. Possible locations for the installation media include: NFS (nfs ---servername --installdir), FTP (url ftp://user:password@server/dir), HTTP (url --url http://server/dir), or hard drive (harddrive --dir=/dir--partition=/dev/partition). For the DVD or CD installation, you will see:

```bash
cdrom
```

The required lang command sets the language (and to be more specific, the country as well) in which Fedora is installed. The value is US English (en_US.UTF-8) by default:

```bash
lang en_US.UTF-8
```

You can install multiple languages to be supported in Fedora. Here is an example of the default being set to: English:

```bash
langsupport --default en_US.UTF-8 en_US.UTF-8
```

The required keyboard command identifies a United States (us) keyboard by default. Han than 70 other keyboard types are supported. (Run system-config-keyboard to see a list of available keyboard types.)

```bash
keyboard us
```

The optional xconfig command can be used to configure your monitor and video card. If you use the skipx command (as in the following code sample), no X configuration is done. (After the system is installed, run system-config-desktop to set your X configuration). When you use the xconfig command, you can identify the type of X server based on your video card (--card) and monitor specs (--hync and --vsync). A handful of other options enable you to set the color depth in bits (--depth), the screen resolution (--resolution), whether the default is GNOME or KDE (--defaultdesktop), whether the login screen is graphical (--startxboot), and the amount of RAM on your video card (--videoram). All the information from xconfig should actually appear on one line.

```bash
skipx

or

xconfig --card="NVIDIA GeForce GTX" --videoram=131072 --hync=31.5-37.9 --resolution=800x600 --depth=16 --startxboot defaultdesktop gnome
```

The optional network command lets you configure your Fedora or RHEL system's interface to your network. The example tells your computer to get its IP address and related network information from a DHCP server (--bootproto dhcp). If you want to assign a particular IP address, use the --bootproto static option. Then the IP address (--ip), netmask (--mask), IP address of the gateway (--gateway), and IP address of the DNS server (--nameserver) to suit your system. You can also add a hostname (--hostname).

> NOTE: Although the network values appear to be on three lines, all values must be on the same line.

```bash
network --device eth0 --bootproto dhcp or network --device=eth0 --bootproto static --ip=192.168.0.1 --netmask 255.255.255.0 --gateway 192.168.0.1 --nameserver 192.168.0.254 --hostname duck.example.com
```

The rootpw command sets the password to word forms (in the following example, passWORD). It is a security risk to leave this password hanging around, so you should change this password (with the passwd command) after Linux is installed. You also have the option of adding an encrypted password instead (--encrypted g.UJ.RQeOV3Bg --enablemd5).

```bash
rootpw passWORD or rootpw --encrypted g.UJ.RQeOV3Bg --enablemd5
```

The firewall command lets you set the default firewall used by Fedora or RHEL system. The default value is disabled (if firewall is turned on). You can also set firewall to disabled (no firewall). (These values are described in the installation procedure earlier in this chapter.) As you can see in the example, you can optionally indicate that there be no restrictions from host customers a particular interface.

```bash
(--trust eth0). You can also allow an individual service (--ssh) or a particular port=protocol --port 1234:udp).
firewall --enabled --trust=eth0 --ssh --port 1234:udp
```

The required authconfig command sets the type of authentication. The following is example:

```bash
authconfig --enabled --shadow
```

The selinux command indicates whether Enhanced Linux is enabled. The following is example:

```bash
selinux --enforcing
```

The timezone command sets the time zone. The following is example:

```bash
timezone America/Eastern
```

The bootloader command sets the boot loader. The following is example:

```bash
bootloader --grub --location=mbr
```
