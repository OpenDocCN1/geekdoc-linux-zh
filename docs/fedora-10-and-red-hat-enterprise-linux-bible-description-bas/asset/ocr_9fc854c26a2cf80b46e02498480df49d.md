# Downloading with user name and password

If you are using an FTP file to log in as a user other than yourself, you can
add information to the command line or a .netrc file in your home directory (type
man netrc to see the format of that file). Here is an example of adding the password to the
command line:

> $ wget http://joe:my67chevy@ftp.handsonhistory.com/memol.doc

CAUTION: Adding a password to a command line exposes the password to onlookers. This
pract generally discouraged, except in cases where no one can see your monitor or your history files
or view your command line by running the ps command. You can add passwords to ~/.wgetrc
file, to keep your password from being seen. If you do, ensure that no one else can read this file by
running the chmod 400 .wgetrc

In the previous example, the user logs in as joe with the my67chevy. The wget
command copies the file memol.doc from the current directory from the host computer
named ftp.handsonhistory.com. That current directory is most likely /home/joe.
