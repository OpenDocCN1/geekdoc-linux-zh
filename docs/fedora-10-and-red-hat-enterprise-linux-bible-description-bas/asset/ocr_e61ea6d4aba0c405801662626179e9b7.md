# # Chapter 14: Computer Security Issues 579

Each line in this listing corresponds to a single user account on the Linux system. Each line is
made up of seven fields separated by colon (:). From left to right the fields are
login name, the encrypted password, the user ID, the group ID, the description (usually
person’s name), the home directory, and the default shell. Looking at the first line, you see
it is for the root account and has an encrypted password DkS6uke799FQ. You can also see
that root has a user ID of zero, a group ID of zero, and a home directory /root, and root’s
default shell is /bin/sh.

All of these values are quite normal for a root account, but seeing that encrypted password
should off alert bells in your head. It confirms that your system is not using the shadow
password file. If so you should immediately convert your password so that it uses
/etc/shadow to store the password information. You can do this using the pwconv
command. Simply log in as root (or use the su command to become root) and enter the
pconv command at a prompt. It will produce no messages, but when your shell returns,
y should have a /etc/shadow file and your /etc/passwd file should now look like this:

```
root:x:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin/sh
daemon:x:2:daemon:/sbin
```

```
mary:x:500:100:Mary Smith:/home/mary:/bin/sh
joe:x:501:100:Joe Johnson:/home/joe:/bin/sh
jane:x:502:100:Jane Anderson:/home/jane:/bin/sh
bob:x:503:100:Bob Renolds:/home/bob:/bin/sh
```

Encrypted password is replaced with an x. Password data has been moved to
/etc/shadow.

To check the type of password authentication your system is using, opening the Authentication
window (System -> Administration -> Authentication to the GNOME desktop). This tool
let you choose use MDS passwords, LDAP authentication, Kerberos 5, or other
authentication methods.

To work with groups, you can use the grpasswd command to convert passwords
in /etc/groups to shadowed groups in /etc/gshadow. If you change passwd
or group passwords and something breaks (you are unable to log in to the accounts), you can
use the pwconv and grpasswd commands, respectively, to reverse password conversion.

So, now you are using the shadow password file and picking good passwords. You have made
a great start toward securing your system. You may have noticed by now that security is
not just a one-time job. It is an ongoing process, as much about policies as programs. Keep
reading to learn more.
