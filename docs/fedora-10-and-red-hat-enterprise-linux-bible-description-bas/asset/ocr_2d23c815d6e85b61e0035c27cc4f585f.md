# Freecivic

Freecivic is a free clone of the Civilization game series from Atari. With Freeciv, you create a civilization that challenges competing civilizations for world dominance.

The version of Freeciv that is included in Fedora contains both client software (to play the game) and server software (to connect players together). You can connect to your server and try the game yourself (or with a network connection) play against up to 14 players on the Internet.

> NOTE: A commercial port of Civilization for Linux (Civilization: Call to Power) was created a few years ago by Loki Games. The game is described later in this.

You can start Freeciv from the Applications menu (as a non-root user) by clicking Games -> Freeciv. If Freeciv doesn't, try starting it from a Terminal window by typing

```
$ civclient &
```
