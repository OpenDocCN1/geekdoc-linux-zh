Let's say you downloaded a directory of RPMs and you want to selectively freshen the
ones you have installed. With the directory of RPMs as your current directory, you could type:

```
# rpm -Fv * .rpm
```

Packages already installed are updated with the new RPMs. All other RPMs are skipped.

> CAUTION: Again, note that you should not freshen or upgrade kernel packages because it might
cause your only working kernel to be removed when you add the new one.

# Removing packages with rpm

If you no longer want to use a package (or you just want to recover some disk space), use the
-e option to remove a package. In its simplest form, you use rpm with the -e option as
follows:

```
# rpm -e package
```

If there are no dependencies on this package, it is silently removed. Before you remove a
package, you may want to do a quick check for dependencies. The -q option is used
a a variety of queries. (Checking for dependencies isn't necessary because rpm checks
for dependencies before it removes a package. You may want to do this for your own
information, --whatrequires.) To check for dependencies, the following:

```
# rpm -q --whatrequires package
```

If you decide to remove the package, I recommend using the -vv option with rpm -e. This
lets you see the actual files that are being removed. I also suggest that you direct the
to output to a file or to least command make the output runs off the screen.
For example:

```
# rpm -evv jpilot | less
```

This example removes the jpilot package and shows you the files that are being removed
page at a time. (Press the Spacebar to page through the output.)

Other options that you can use with rpm -e can be used to override conditions that would
prevent the package from being removed or prevent some processing (such as not running
preinstall or postinstall scripts). Three of these are as follows:

+   - --nodeps -- Uninstall the package without checking for dependencies

+   --noscripts -- Uninstall the package without running any preinstall or postinstall
scripts

+   --notriggers -- Uninstall the package without executing scripts that are triggered by
removing the package
