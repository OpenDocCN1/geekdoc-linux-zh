NOTE: If you want to offload the processing of mail for a particular domain that is currently being directed to your sendmail, you can use the /etc/mail/mailertable file. After setting up a DNS MX record to point to your sendmail for this domain, and listing that domain name in the mailertable file, you can identify another computer that sendmail will forward all the traffic to that domain. For example:

example.com

```
smtp:mxl.linuxuxtoys.net
```

This example shows that all messages destined for example.com are received by your sendmail server are forwarded to the server named mxl.linuxuxtoys.net. The smtp indicates that the server supports Simple Mail Transfer Protocol.

# Configuring virtual users

Incoming mail to your sendmail will be directed to a machine with a request to deliver the message to a particular person at a particular domain name. For each domain the sendmail server supports, you can identify e-mail to mail recipients of that domain is treated.

With sendmail, you set up virtual user definitions in the /etc/mail/virtertable file. Essentially are telling sendmail to redirect messages addressed to particular user names or domain names based on definitions you set up.

Configuring the virtertable file is particularly important if your server is handling mail for multiple domains. That's because, default for the same user (regardless of the domain name) will be stored in the same mailbox. For example, if your server handles mail for example.com and linuxuxtoys.net, mail for chris@example.com and chris@linuxuxtoys.net, would all be directed to /var/spool/mail/chris mailbox. With the virtertable file, you can change behavior in a lot of ways.

The virtertable file is empty by default. The following are some examples of how incoming messages can be directed in different ways based on virtualuser domains.

| chris@linuxuxtoys.net | chris |
| cnegus@linuxuxtoys.net | chris |
| francois@linuxuxtoys.net | francois@spidermaker.com |
| info@linuxuxtoys.net | info-list |
| bogus@linuxuxtoys.net | error:noser No such user here |
| @example.net | example-catchall |
| %1@linuxuxtoys.net |

In the first two lines, incoming mail destined for chris or cnegus at linuxuxtoys.net is directed to the mailbox for the local server named chris. In the any line, e mail directed to the mailbox in the same domain goes to francois@spidermaker.com. After that, e-mail sent to the info user name is saved to the local info-list mail account.
