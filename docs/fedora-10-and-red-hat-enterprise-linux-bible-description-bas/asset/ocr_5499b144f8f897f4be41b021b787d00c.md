# Table 12-3: Valid init Actions

| Action | How the Command Is Run |
|---|---|n| once | The command is executed once when entering the specified run level. |
| wait | The same as once, but waits for the command to finish before continuing with other initab entries. |
| respawn | The process is monitored, and a new instance is started if the original process terminates. |
| powerfail | The command is executed on receiving a SIGPWR signal from software associated with a UPS unit. This assumes a few minutes of power are left so, by the system can shut down the system in two minutes. |
| powerwait | The same as powerfail, but waits for the command to finish. |
| powerokwait | The command is executed on receiving a SIGPWR signal if the /etc/powerstatus file contains the word OK. This is generally accompanied by the UPS software and indicates that a normal power level has been restored. |
| powerfailnow | The local system may be able to detect that an external UPS is running out of power and is about to fail immediately. |
| demand | The command is executed when init is manually instructed to enter one of the special run levels, a, b, or c (equivalent to A, B and C, respectively). No change in run level actually takes place. The program is restarted if the original process terminates. |
| sysinit | The command is executed during the system boot phase; the runlevels is ignored. |
| boot | The command is executed during the system boot phase, after all sysinit entries have been processed; the runlevels is ignored. |
| bootwait | The same as boot, but waits for the command to finish before continuing with other initab entries; the runlevels is ignored. |
| default | The run level to enter after completing the boot and sysinit actions. |
| off | Nothing happens (perhaps useful for testing and debugging). |
| ctrlltdel | Traps the Ctrl+Alt-Del key sequence and is typically used to gracefully shut down the system. |
| kbrequest | Used to trap special key sequences, as interpreted by the keyboard handler.
