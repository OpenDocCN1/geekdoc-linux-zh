To fill in your home locations, you can also select buttons. Use Current Pages adds the current pages on all tabs of your browser or Use Bookmarks button lets you choose pages from your bookmarks list. Selecting Blank Page sets your home page to about:blank.

+   **Saving browsing information** — Select the Privacy tab to choose how information about your browsing is saved. On the Privacy tab, you can choose how to save data related to your history, data you enter into forms, passwords, downloaded files, and cookies. You can select to clear your history, forms data, passwords, download history, and cached Web pages. Clearing this information is a good idea if you are Firefox on someone else’s machine and want to keep your browsing private.

+   **Setting languages** — Set a list of preferences for the particular language a Page should be displayed, if the page is available in several languages, by selecting the Content category and selecting the Choose under Languages.

+   **Enabling or disabling content** — Some content you encounter can be annoying or dangerous to display or play from your browser. From the Content tab, select what to allow and block in pop-up windows, still to install extensions or themes, display image, a content, and javascript content. You can also set exceptions to the general rules you set for handling the content mentioned. There are numerous Firefox extensions you can use in blocking content as well.

> NOTE: The latest Firefox release helps you block Web sites by displaying a Suspected Forgery popup message when it encounters a page that has been reported as forged. You can choose to not display the page or ignore the warning. If you suspect a forged page that doesn’t display that message, select Help → Report Web Forgery to try to add the page to the Google Web Forgery list.

+   **Tabbed browsing** — Use selections on the Tabs tab to determine how tabs are used when opening new content or closing the browser.

+   **Download manager and folder** — Choose whether or not to see a download manager when files are being downloaded. Also, you can choose to be asked where to place each file download or select a default folder to automatically download your files. Select View & Edit Actions to configure what actions to take.

+   **General settings** — Some settings on the General tab in the Advanced section let you change accessibility settings, browsing features (such as auto resizing of windows and scrolling) and system theme.
