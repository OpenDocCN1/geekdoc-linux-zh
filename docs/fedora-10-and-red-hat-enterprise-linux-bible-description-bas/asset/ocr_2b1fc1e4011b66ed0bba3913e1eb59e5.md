# Statistics Packages Available for Fedora and RHEL

Analyzing the transfer log by hand isn't much fun. Several packages have been written to automate this task, including the following two:

+   - **Analog**: This free-log analyzer is very fast and easily configurable, and produces very detailed output (including bar graphs and hyperlinks). More information can be found at http://www.analog.cx.
- **AWStats**: The Advanced Web Statistics tool (awstats package) produces graphical statistics representing Web-server access. AWStats can work with log files in the Apache log format, as well as log from sendmail, FTP, and other network servers. It can report statistics, such as the number of people who have visited, visits made per person, the domain and country of each visitor, and the number of visits made by robots.

# Summary

Web servers are responsible for storing and delivering the vast amount of content available on the World Wide Web to clients over all world. Although several Web-server software packages are available for Fedora and RHEL systems, the most popular is by the Apache server.

This chapter describes how to install, configure, and run an Apache server in Fedora. The httpd daemon processes requests for Web content (HTTP). Configuration files define what content is available and how it can be accessed. In particular, the /etc/httpd/conf/httpd.conf file is used to configure the server.

The Apache package also includes facilities for logging error and transfer messages. You can look for the access_log and error_log files in the /etc/httpd/logs directory. The access_log file contains information on content requests that have been served by the server. The error_log file lists error conditions that have occurred and times when service was denied. You can use tools such as Webizer to simplify the viewing of Apache log data.
