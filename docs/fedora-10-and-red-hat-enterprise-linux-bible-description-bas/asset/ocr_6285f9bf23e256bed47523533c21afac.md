# # Listing modules

To see which modules are currently loaded into the running kernel on your computer, you can use the lsmod command. Here's an example:

```
# lsmod
Module             Size      Used by
snd_seq_oss        38912     1 snd_seq_oss
snd_seq_midi_event 9344      0
snd_seq            67728     4 snd_seq_oss,snd_seq_midi_event
snd_seq_device     8328      2 snd_seq_oss,snd_seq
.
autofs             16512      0
e2k_pci            9056      0
8390               13568     1 ne2k_pci
ohci1394         41860      0
ieeei1394          284464    1 ohci1394
floppy             65712      0
sg                 36120      0
scsi_model         124600     1 sg
parport_pc         39724      0
parport            47336      1 parport_pc
ext3               128424     2 ext3
jbd                86040      1 ext3
```

This output shows a variety of modules that have been loaded on a Linux system. The modules loaded on this system include several to support sound, including some that provide OSS compatibility (snd_seq_oss).

To find information about any of the loaded modules, you can use the modinfo command. For example, you could type:

```
# modinfo snd_seq-oss
filename:           /lib/modules/2.6.25-28-i686/kernel/sound/core/seq/snd-seq-oss.ko
alias:             sound-device?-?
alias:             sound-device?-8
license:            GPL
description:        OSS-compatible sequencer module
version:           Takashi Iwai <iwai@itvausa.de>
depends:            snd-seq-oss,snd-mid-midevent,snd-seq-device
vermagic:           2.6.25-28-i686 SMP SMP unload 686 4STACKS
parm:               maxlen=maximum queue length (int)
parm:               seq_oss_debug=debug option (int)
```
