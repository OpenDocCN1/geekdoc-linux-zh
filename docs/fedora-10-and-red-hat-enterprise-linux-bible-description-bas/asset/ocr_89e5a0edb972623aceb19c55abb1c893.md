# Adding environment variables

You may consider adding a few environment variables to your .bashrc file. These can help making with your shell more efficient and efficient:

+   - TMOUT—This sets how long the shell can be inactive before automatically exits. The value is the number of seconds for the shell has not received input. This can be a nice security feature, in case you leave your desk while you are logged in to Linux. To avoid logging off while you are working, you may want to set the value to something TMOUT=1800 (to allow 30 minutes of idle time), or simply not set this variable to disable this feature.
- PATH—As described earlier, the PATH variable sets the directories that are searched for commands you use. If you use commands that are not in your PATH, you can permanently add them. To do this, add a PATH variable to your .bashrc file. For example, to add a directory called /getstuff/bin, 

```
PATH=$PATH:/getstuff/bin; export PATH
```

This example finds all the current paths into the new PATH ($PATH), adds the /getstuff/bin directory, and exports the PATH.
