```
# tar tvf package.tar.gz
```

> NOTE: Use the command tar xjf tar tvf if the file is compressed using bzip2.

+   3. Assuming the file is compressed using gzip, uncompress the file using the following
command:

```
# gunzip package.tar.gz
```

The result is that file is uncompressed and the .gz is removed from the package
name (for example, package.tar). (If your package ends in b2, use the bzip2
command instead of gunzip above).

+   4. From the resulting tar archive, run the tar command as follows:

```
# tar xvf package.tar
```

This command extracts the files from archive and copies them to a subdirectory of
the current directory. (Using tar xvf file package.tar.gz you can do steps 2 and 3 in
one step. For a compressed bzip2 file, run tar xjf package.tar.bz2 instead).

+   6. Look for a file INSTALL or README. One of these files will give you
instructions on how to proceed with the installation. In general, the make command is
used to install the package. Here are a few things to look for in the current directory:

If there is a Make.in file, try running:

```
# ./configure --prefix=/usr/local
```

```
# make all
```

If there is an Imake file, try running:

```
# xmkmf -a
```

```
# make all
```

If there is a Makefile, try running:

```
# make all
```

After the program is built and installed, you might have to do additional configuration. You
should consult the man pages or the HOWTOs that come with the software for information
how to proceed.
