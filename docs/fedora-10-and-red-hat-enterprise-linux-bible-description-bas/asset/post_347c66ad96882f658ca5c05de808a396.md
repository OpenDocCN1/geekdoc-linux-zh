## Running yum to download and install RPMs

With the repositories identified, downloading and installing an RPM is as simple as running yum with the install option to request the RPM. With an active connection to the Internet, open a Terminal window as root user.

The first thing yum does is download metadata and headers for all packages you might want from each repository. After presenting you with the list of dependencies it thinks you need, if you want to install the necessary packages. Here is an example of using the yum command to download the madwifi media player:

```
# yum install madwifi
Setting up install Process
Parsing package install arguments
fedora           100% ========== 2.1 kB 00:00
atprms           100% ========== 951 B 00:00
Reading repository metadata in from local files
primary.xml.gz  100% ============ 2.5 MB 00:04

Transaction Summary
Install           4 Package(s) ==========================
Update             0 Package(s) ==========================
Remove             1 Package(s) ==========================
Total download size: 17M
Is this ok [y/N]: y
Downloading Packages
```

As you can see from this example, yum checked two different software repositories, Fedora and atprms packages, for the current Fedora release. After listing the dependencies, yum asks if it is OK to install them. Type y and the package and all its dependencies are installed. Note that the madwifi package comes from the atprms and RPMForge site. You need to add at least one of these repositories.

Some packages, including the madwifi package shown in the previous example, need to install a version that matches the kernel that you are running. For that reason, installing such a package might also bring an updated kernel package with it.

## Using yum to install packages locally

If you want to install RPM packages that yum are available from your local system (by inserting the Fedora DVD or copying an RPM to a local directory), you can use the localinstall option to yum. For example, if you were to insert the Fedora DVD that comes with this book (and it was mounted on /media/disk), you could type the following to install the gftp package:

```
# yum localinstall /media/disk/Fedora/Packages/gftp-*
yum localinstall /media/disk/Fedora/Packages/gftp-2.0.18-4.fc10.rpm
```

Resolving Dependencies
---> Running transaction check
---> Package gftp.i386 1:2.0.18-4.fc10 set to be updated
Dependencies Resolved

| Package Arch Version | Repository | Size |
|---|---|---|---|

Installing:
gftp i386 1:2.0.18-7.fc9 /media/disk/Fedora/Packages/gftp-2.0.18-4.fc10.rpm | 94 k

Transaction Summary
Install 1 Package(s)
Update 0 Package(s)
Remove 0 Package(s)

Total download size: 94 k
is this ok [y/N]: y

> TIP: Using an asterisk on the command line, as shown above, may include more files than you intend. It is best to check first and only install the packages you want. A good reason for using localinstall instead of the rpm command to install RPM packages is that yum will check whether the package you are installing is dependent on any other packages. If yum finds it needs other packages, it will search any repositories configured (at least the Fedora repository) to download and install what you need. In this example, yum found that gftp didn't require any additional packages installed.

## Using yum for listing packages

Besides downloading and installing new packages, yum can also be used to list available packages as well as those already installed. The following examples illustrate some uses.

If you want to see a list of all packages that are available from the repositories you have configured, type the following:

```
# yum list | less
```

Adding the less command to the end you scroll through the list (it could be long, depending on your configuration). If you try to install a package and it fails with a message "package needs xyzfile (not provided)", you can check for packages including the missing file using the provides option as follows:

```
# yum provides missingfile
```

With the provides option, yum will search your repositories for whatever you enter (instead of missingfile) and return the name of any packages that it finds that.

To search descriptions in repositories for a particular string, use the search option. For example, the following command searches for arcade in any package description (this search will find some games):

```
# yum search arcade
```

Because yum packages are not automatically deleted after being installed, you might want to go through on occasion and clean them out. To clear out packages from subdirectories of /var/cache/yum directory, type the following:

```
# yum clean packages
```

If you would like to check which RPMs are installed from repositories outside of the main Fedora repository, you can do so using the list extras option. Here is an example:

```
# yum list extras
```

Extra Packages

The list that appears may include a lot of packages, depending on your configuration. Note that this list includes all packages from repositories configured for your system that are outside of Fedora. (For example, it would list packages installed from Livna and ATRPRMS, if those repositories were configured.)
