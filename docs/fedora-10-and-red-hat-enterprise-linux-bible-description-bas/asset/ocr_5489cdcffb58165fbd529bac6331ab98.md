# Setting default index files for directories

The DirectoryIndex directive establishes a list of files that is used when an incoming request specifies a directory rather than a file. For example, a client requests the URL http://www.mybox.com/~jsmith/. Because it is a directory, it is automatically translated to http://www.mybox.com/~jsmith/. Now that directory searches for any of the files listed in the DirectoryIndex directive. The first match (from the default list of index.html and index.var) is used as the default document in that directory. If none of the files exist and the Indexes option (in the httpd.conf file) is selected, the server will automatically generate an index of the files in the directory.

```
# DirectoryIndex: sets the file that Apache will serve if a directory
# is requested.
# The index.html.var file (a type-map) is used to deliver content-\n# negated documents. The MultiViews Option can be used for the
# same purpose, but it is much slower.
DirectoryIndex index.html index.var
```

Sometimes dynamic content (like index.php or index.cgi) will be added to the DirectoryIndex to make that dynamic content is accessed before static content when a user requests a domain name or directory.

# Setting directory-access control

You and users can add an access file for each directory to access to that directory. By default, the AccessFileName directive sets .htaccess file containing the information. The following lines set this filename and prevent the contents of that file from being viewed by visitors to the Web site. If you change the file to a name other than .htaccess, be sure to change the line below ("^\\.ht") denies access to that file.

```
# AccessFileName: The name of the file to look for in each directory
# for access control information.
AccessFileName ~"\.ht"
```

```
<Files ~"\\.ht">
Order allow, deny
Deny from all
</Files>
```

You can add the same access directives to a .htaccess file as you do to the httpd.conf file. In general, it is more efficient to use a <Directory> directive in the httpd.conf file than it is to create a .htaccess file. With a <Directory> directive, you can specifically identify the access associated with that directory alone.
