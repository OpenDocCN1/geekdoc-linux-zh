**NOTE: binary-only drivers are not part of the Linux kernel, if you update your kernel at some point, you will need to update your NVIDIA driver as well. The rpm.livna.org site offers a nice service by packaging NVIDIA and ATI video cards as RPMs to make new Fedora kernel updates. Refer to this for information:http://rpm.livna.org/liwiki/LivnaSwitcher. Because the drivers from NVIDIA have been overwritten shared Xorg files in Fedora, breaking your ability to use other video cards with the system, the RPMs from livna.org is, in cases, the best way to install NVIDIA drivers to Fedora.

During Fedora 10 development, the livna site was transitioning to a new rpmfusion.org. By the time you read this, you may need to go to that to find the NVIDIA drivers described here.

A new, experimental driver called nouveau aims at providing 3D effects for NVIDIA cards. The driver requires DRI support in the kernel and Mesa support for 3D effects, only 2D rendering is working with the nouveau driver delivered by Fedora. Eventually you should be able to use features such as the AGLX-enabled Compiz window and OpenGL screens with the nouveau driver.

+   **AMD's ATI Technologies** — In 2006, Advanced Micro Devices (AMD) purchased graphics maker ATI Technologies. ATI chips that support DRI include the Mach64 (Rage, Radeon X7000 (R100), Radeon 2 / 8500 (R200), and Rage 128 (Standard, Pro, Mobility). Cards based on this chip set include All-in-Wonder 128, Rage Fury, Rage Magnum, X Magnum, Xpert 99, Xpert 128, and Xpert 2000. DRI support for Radeon chips up to 9200 has been added. Proprietary, binary-only drivers for ATI cards are available directly from the AMD site at
http://ati.amd.com/support/
driver.html/ or packaged as RPMs from the rpm.livna.org site.

A recent announcement from AMD regarding its ATI graphics chips promises strong support for Linux in the future. AMD has expanded features in its Catalyst software to support ATI Radeon 2000 series graphics processors. Features for the near future are expected to produce significant performance improvements in Linux games (Doom 3 and Quake 4) as well as supporting for accelerated GLX (AGLX) for 3D accelerated effects.

+   **3fx** — If you find a used unit on ebay, there are several 3fx cards that support 3D. In particular, the Voodoo (3, 4, and 5) and Banshee chips have drivers that support 3D Voodoo5 supports 16 and 24 bpp. Scan Line Interleaving (SLI), where two or more 3D processors work in parallel (to result in higher frame rates), is not supported for 3fx cards.

+   **Intel** — Supported video chips from Intel include the i810 (e, e2, and -dc100), i815, and i815e. Intel has released some of the drivers for these and other graphics chips to the open source community. You can find out more about these drivers from the Linux Graphics Drivers from Intel (http://www.intelluxgraphics.org).
