# FirstAidKit

This project consolidates a number of system recovery tools into one framework and application. The goal is that if your system shows problems, you can run the FirstAidKit and it will do what is necessary to fix your system. FirstAidKit does this by supporting plugins. Each plug-diagnoses and fixes a different part of your system. In Fedora 10, the FirstAidKit ships with three plug-ins. Many more are under development.

# OpenOffice.org 3

OpenOffice.3.0 provides a major upgrade to the 2.4 versions of this office suite. OpenOffice was designed as a drop-in for Microsoft Office. Major improvements in OpenOffice 3.0 include support for Microsoft Office 2007 file formats, a numeric solver, and for over 1024 columns per sheet (up from 256) in the spreadsheet package, called Calc. See Chapter 6 for more detail on OpenOffice.org.

# Faster Boot Times

No one likes for their computer to boot up. And even Linux systems tend to boot faster than Windows boxes, the Fedora project called 30-second boot aims at providing just: a maximum of 30 seconds for booting your computer, from power to the login screen. Another effort in Fedora 10 provides a better-looking screen and improves the overall system experience.

# K Desktop Environment (KDE) 4

KDE 4 makes a major revision of the popular desktop environment. The new Plasma desktop should provide a framework for KDE 4 enhancements. With Plasm, you get a new look-and-feel, new ways of finding applications, files and URLs, and new "widget" technology that lets you run the mini-applications on the desktop or on panels.

The Dolphin File Manager was added to provide a more streamlined tool for managing files and folders for daily use. Desktop configuration features are now available on a New System Settings. For details on using the KDE 4 desktop, refer to Chapter 3.

To let you immediately try out KDE 4, we have included the Fedora 10 KDE desktop live CD. You can boot live CD directly to a KDE 4 desktop system, if you choose, you can install that desktop system directly to your hard disk if you choose.
