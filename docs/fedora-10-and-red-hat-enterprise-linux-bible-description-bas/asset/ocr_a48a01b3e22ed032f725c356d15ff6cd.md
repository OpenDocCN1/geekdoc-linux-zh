# About the Companion Media

The Fedora 10 DVD that accompanies this book provides the software you need for a complete Fedora system. With this software, you can install sets of software packages that result in an installation from a few hundred megabytes to over 10 gigabytes of software.

We also include a Fedora 10 KDE Live/install CD. That CD can be booted to run a live KDE desktop system, without touching the contents of your hard disk. You can install the contents of the live CD to your hard disk, to use that desktop permanently from your hard disk.

This book describes how to configure and use the software for those different media. See Appendix A for specifics on the media.

Like the binary packages, the source code packages are available from the Fedora Project site (http://fedoraproject.org/get-fedora.html). You may also order the source code directly from Wiley, using the coupon at the end of the book.

# About the Companion Web Site

If are not finding the answer you need in this book, go to the book's Web site at www.wiley.com/go/fedoralible and see if new information on the subject is available. Start with the advanced links page, specially geared toward helping you overcome common problems with Fedora

Even in a book that pushes the 1,000-page boundary, a few topics don't seem to make the cut. The companion Web site contains some bonus material on topics such as using the X Window system, finding add-on-software, exploring alternative administrative interfaces, Logmetry, and Portentry. Other topics moved to the Web site from previous editions of this book includes information on using UNIX remote commands (login, rcp, and the like), running Tripwire to manage system security, running a NetWare server in Linux (mars_nwe) and using crack password protection tools. Features moved from more recent editions include descriptions of the LILO bootloader, we-Ftp FTP server, ANN news and the sendmail.cf file.
