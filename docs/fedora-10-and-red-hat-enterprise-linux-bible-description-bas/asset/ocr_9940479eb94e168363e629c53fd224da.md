# Configuring an OpenVPN Server

Virtual private networks were created to allow computer systems to secure connections using insecure public networks. Setting up an OpenVPN server at your place of business can provide an inexpensive way for branch offices or telecommunications to securely access your company's private network.

Because VPN technologies, such as OpenVPN, provide encrypted connections between two transport-level network interfaces, applications communicating between those two systems are secure. This is as opposed to user-space applications, such as SSL, that must implement features for every application they want to offer to users.

For Linux systems, OpenVPN provides a very good choice of software for configuring a VPN server. The following are some of the features of OpenVPN:

+   - A single port can provide access to 128 clients.
- The server can control client setup, doing tasks as pushing configuration data to clients through the VPN tunnel.
- You can use telnet to access the server.
- OpenVPN includes TUN/TAP virtual network interface drivers at the networking layer, with device names /dev/tunX and /dev/tapX. Applications can use the TUN devices as point-to-point interface to VPN partner (routed). TAP devices provide a virtual Ethernet adapter, so daemons on TAP can capture Ethernet frames.

The OpenVPN procedure in this chapter describes how to set up an OpenVPN server. This includes:

+   - Setting up information needed to create authority certificates and keys. In the process you create a RSA Private Key (ca.key) that you need to keep confidential and a root certificate (ca.crt) that you share.
- Setting up configuration files and starting the OpenVPN service.
