It is important to remember that there is no warranty on GNU software. If something goes wrong, the original developer of the software has no obligation to fix the problem. However, the Linux culture has provided resources for that event. Experts on the Internet can help you iron out problems, or you can access any of the many Linux newsgroups or forums to read how others have dealt with their problems and post your own questions about how to fix them. # Summary

Linux is a free operating system that was created by Lin Torvalds in 1991 and has grown from contributions from software developers all over the world. Fedora and Red Hat Enterprise versions of Red Hat Linux are distributions of Linux that package together the software needed to run Linux and make it easier to install and use.

This book specially describes Fedora 10, a complete version of which is included on the DVD that comes with this book, as well as Red Hat Enterprise Linux 5. Fedora includes cutting-edge Linux technology that is slated for inclusion in commercial Red Hat Linux systems. Features in Fedora 10 include the recent Online desktop feature, PulseAudio sound server, and an enhanced Firewall Configuration window. You can get different “spins” of Fedora (live and install CDs) from the Internet or from distributions that come with this one.

Linux is based on a culture of free exchange. Linux’s roots are in the UNIX operating system. UNIX provided most of the framework that was used to create Linux. This framework came from the POSIX standard, the System V Interface Definition, and the Berkeley Software Distribution, pieces of which have all found their way into Linux. Now the Linux Standard Base creates the standards to provide consistency among Linux distributions.

A simplified installation procedure is one of the best reasons for using a Linux distribution such as Fedora or RHEL. In the past few releases of Fedora, the project has made some great improvements to the installation process. Most notably, a recent feature in anaconda (the Fedora installer) lets you install software from multiple online repositories during the initial Fedora.

# Understanding Fedora Installation Media

In earlier releases, the Fedora Project packaged its operating system as both 5-CD and 1-DVD installation media. Extra software packages could be downloaded from the Fedora Extras repository and installed over the Internet. In the past few releases, that arrangement has changed in several major ways:

- Fedora Repository — Instead of separate Core and Extras repositories, there is just a single Fedora repository that includes all the software.

- New Installation Media — The merged Fedora repository contains too much software to expect the average user to download. The Fedora Project offers reasonable-sized installation media that include a 3.5G installation DVD, a Desktop Live CD, and a KDE Desktop Live CD. Either of the live CDs can be used to install the Fedora desktop system on CD hard drive. After the release, look for custom Fedora spins that might include CD and DVD sets, as well as specialized live CDs for games, software development, and other special topics (http://spins.fedaproject.org/). A spin is just a grouping of Fedora software into a live CD or DVD image.

- New Build Tools — To help put together the mass of Fedora software into a form that is useful to them, the Fedora Project created several software tool projects. Using Fedora and optionally other software repositories, Pungi can be used to create a new set of installation media, which-creator can build a live CD or live DVD. (See descriptions of these tools at the end of this chapter.)

# Using the Fedora 10 Live CD

The official Fedora 10 KDE Live CD that comes with this book is a great way to try out Fedora before you commit to installing. In addition to answering the obvious question of "does Fedora run on your PC at all?" the CD itself contains useful tools for examining your hardware and preparing your computer for installation.

A live CD is a bootable media (usually a CD, but other removable media, such as DVDs or USB flash drives can be used the same way) that contains an entire operating system. In most cases, you can boot the live CD without touching the contents of your hard drive.

## Chapter 2: Installing Fedora 25

With Fedora 10 Desktop Live CD, you can boot up to a KDE desktop that works like most desktop systems installed to hard disk. If you don't like the system, reboot, remove the CD, and your computer will return to the way it was. If you like it, you can click a single button and install the same desktop system to your hard disk.

Here's a quick set of steps to try out the Fedora 10 KDE Desktop Live CD (included with this book):

> NOTE: The live CD will not run well on less than 256MB of RAM. Also, if you find the live CD hangs at some point in the boot process, refer to boot options in this chapter. With the boot label highlighted on the menu bar, press the Tab key to be able to add options to the boot command.

1. Insert the Fedora 10 KDE Desktop Live CD into your drive and reboot.

2. From the boot screen, let the CD timeout and press any key to see other selections. From the boot menu, highlight either Boot or Verify, and press Enter. (The verify step makes the medium isn't corrupted.)

3. When you see the login screen, you can select a language or let the login prompt timeout. (No password is required). The KDE starts up.

4. From the KDE desktop, here are a few things you can try from the live CD:
- Run applications — Try any of the applications you choose from menus in the top panel. If you have an Internet connection (Fedora will automatically configure your Wired cables), you can try Web browsing and other Internet applications. You can even add more applications. Select Applications → Add/Remove Software to select applications to install over the Internet. (Because the live CD is a read-only medium, software you add will disappear when reboot.)
- Check hardware — Refer to the “Preparing for Installation using the Live CD” section in this chapter for suggestions on how to check out your computer hardware.
- Prepare for dual booting — If you want to keep an installed Windows system that is already on your computer's hard disk, you can prepare your computer to be able to dual boot Linux and Windows and a new install of Fedora. Refer to the “Setting up to dual boot Linux and Windows” section in this chapter for resizing your computer's hard partitions to make room for Fedora.

If you like the live CD, and your computer is prepared for you to install it, you can immediately install the contents of the live CD to your computer drive. Select the Hard Drive icon from the desktop, and then follow along the installation procedure in the next sections.

> NOTE: If you prefer the GNOME Desktop Environment over KDE, Fedora offers a live CD spin based on the GNOME desktop. You can download that live CD from Fedora mirror site.
