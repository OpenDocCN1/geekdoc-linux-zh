# Getting alerted to available updates

The first time you log in to Fedora and display the desktop, you will probably see an orange star icon in the upper-right, alerting you that updates are available. That icon represents the PackageKit Update Applet. Any time updates are available, that will appear.

Click the button on the app, and then Select Updates. The PackageKit Update window opens, listing the number of available updates. You can select Review Updates to view and optionally select only particular packages to update. Click the Apply button and all selected updates will be downloaded to your computer and installed.
