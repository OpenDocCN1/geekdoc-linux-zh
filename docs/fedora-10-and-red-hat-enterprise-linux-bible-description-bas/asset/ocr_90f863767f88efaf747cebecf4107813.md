# # Configuring the CUPS server (cups.conf)

The cups daemon listens for requests to your CUPS print server and responds to those requests based on settings in the /etc/cups/cups.conf file. The configuration variables in cups.conf file are in the same form as those of the Apache configuration file (httpd.conf). After changing cups.conf, restart the server for changes to take effect.

The Printer configuration window adds access information to the cups.conf file. You can step through the cups.conf file to further tune your CUPS server. There are a few suggestions:

# Classification topsecret

No classification is set by default. With the classification set topsecret, you can have Top Secret displayed on all pages that go through the print server. Other classifications can substitute for topsecret include: classified, confidential, secret, and unclassified.

```
ServerCertificate /etc/cups/ssl/server.cert
ServerKey /etc/cups/ssl/server.key
```

The ServerCertificate and ServerKey lines (not set by default) can be set up to indicate where the certificate and key are stored, respectively. Activate these two lines if you want to do encrypted connections. Then add your certificate and key to the files noted. Keep in mind that these keys are for the CUPS Web interface and are not used for sending print jobs.
