# Chapter 13: Backing Up and Restoring Files 549

If you need any files that were copied to the CD, just return the CD to the CD drive. If it doesn't automatically open a window displaying the contents of the CD, type mount **/media/cdrecorder**. Open /media/cdrecorder in a folder and copy the files you want.

Note that the mount point for the CD drive may be something other than **/media/cdrecorder**. The way that the udev facility works in the latest version of Fedora is to use generic names as crecorder, cdisc, or cdrom for CDs and DVDs with no volume ID. However, if a volume ID was added to the CD header when the CD was created, that name will be used as the mount point. For example, a game CD with a volume ID GAMDISK would be mounted as /media/GAMDISK.

> CROSS-REFERENCE: Chapter 8 for more information on crecorder. You can also learn about installing and troubleshooting CD drives from the CD-Writing-HOWTO. If you are using a desktop Fedora or RHEL system, you might want to use a graphical CD writer instead. Chapter 8 also describes the K3B tool for copying and burning CDs and DVDs.

# Writable drives

In previous versions of Fedora and RHEL, the dvdrecord command was used to write DVDs. Now, crecorder can be used to write CDs and DVDs. Using a Writable drive and the dvdrecord command, you can back up your data to DVD-R, DVD-RW, DVD+ and DVD+RW disks.

> NOTE: DVD-R is a write-once format with a capacity of 4.7GB. Dis in the DVD-RW format can be written and rewritten many times. DVD-RW is a read-write format that provides for faster writing of data, and DVD+ is a similar write-once format. Typically, a DVD-burning drive will support the plus (DVD+RW, DVD+R) or the minus (DVD-RW, DVD-R) formats. Some drives support both. It is important to purchase discs compatible with your hardware.

The first trick with recording DVDs in Linux is to make sure you have a drive that supports DVD writing. You can check by removing any disks in the CD/DVD drive and typing the following:

```
$ crecorder -prcap -dev=/dvd/cdrom | less
Crecord-Clone 2.01-dvd (i686-pc-linux-gnu)
```
