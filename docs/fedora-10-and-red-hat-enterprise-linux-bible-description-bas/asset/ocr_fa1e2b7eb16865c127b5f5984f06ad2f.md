# Working with files

Because most of the using of files in both Konqueror and Dolphin are intuitive (by intuition), I'll give you a quick rundown of how to do basic file manipulation:

+   - **Open file** — Click a file. The file will open in the Konqueror or Dolphin window, if or in the default application set for the file type. You can also open a directory (to make it the current directory), application (to start the application), or link (to open the target of a link) in this
- **Choose an application** —Right–click to open a menu. When you right-click a data file, select the Open Menu. The menu that appears which applications are set up to open the file.
- **Delete file** — Right–click and move to Trash. If you are brave, you can delete the file. Click Trash to move the item to the Trash folder. Or use Shift+Delete to permanently delete a selected file. Just keep in mind that you won't be able to restore it from Trash if you change your mind.
- **Copy a file** — Right–click and select Copy. This copies the file to your clipboard. After that, you can paste it to another folder. Click the Klipper (clipboard) icon in the panel to see a list of copied files. (See the Move file item for a drag-and-drop method of moving)
- **Paste a file** — Right–click (an open area of a folder) and select Paste. A copy of the file you previously is pasted in the current folder.
- **Move a file** — With the original folder and target folder both open on the desktop, press and hold the mouse button on the file you want to move, drag it to an open area of the new folder, and release the button. From the menu that appears, click Move Here. (You could also copy or create a file using this method)
- **Link a file** — Drag and drop a file from one folder to another. When the menu appears, click Link Here. (A linked file lets you access a file from a new location without having to make a copy of the original file. When you open the link, a pointer to the original file causes it to open).
