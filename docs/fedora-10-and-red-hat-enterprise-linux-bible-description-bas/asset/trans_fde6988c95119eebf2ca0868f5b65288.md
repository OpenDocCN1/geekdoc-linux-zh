

## 第 7 章：在 Fedora 和 RHEL 299 中游戏

将来自《Quake III Arena》光盘 `file` 和 `q3key` 拷贝到 /usr/share/quake3/baseq3 目录。通过选择“应用程序 -> 游戏 -> Quake 3 Arena”来启动 Quake III Arena。

Fedora 仓库提供了 Quake III Arena 演示版（`yum install quake3-demo`）。除了 `quake3` 软件包包含的内容外，运行游戏还需要数据文件。虽然这些数据文件可以从互联网自由下载，但它们不会随 Fedora 一起发行。因此，当你启动 Quake III Arena 演示版时，系统会询问你是否要在继续之前下载演示数据文件。点击“接受”并同意许可协议即可开始游戏。图 7-5 显示了 Quake III Arena 的截图。

安装了 Quake III Arena 源引擎后，你还可以运行使用该引擎的其他第一人称射击游戏。例如，安装 Urban Terror 包（`yum install urbanterror`），你可以启动 Urban Terror 下载程序下载运行该游戏所需的数据文件（Urban Terror 数据文件压缩后 700MB，需要 1.4GB 磁盘空间）。此外，还可以从 Fedora 仓库直接下载 OpenArena 游戏（`yum install openarena`），这是一个基于 Quake III Arena 类型的游戏。

### 城堡要沃尔芬斯坦

将第二次世界大战的动作与与盟军战斗相结合，以摧毁第三帝国。《城堡要沃尔芬斯坦》基于 Quake III 引擎。该游戏提供单机模式以及基于团队的模式。

### 使用 Fedora RHEL

如果你购买了 Linux 版《城堡要沃尔芬斯坦》，实际上获得的是带有额外 Linux 安装程序的 Windows 版本。如果你已经有了 Windows 版本，可以下载 Linux 安装程序并按照某些说明获取：从 ftp.idsoftware.com/idstuff/wolf/ 下载 `wolf-linux-1.4bx86`。位于 /usr/local/games/wolfenstein 下的 `INSTALL` 文件描述了你需要从 Windows 光盘中拷贝的文件。你可以从 http://www.linuxgaming.com 购买 Linux 安装程序。

要获取《城堡要沃尔芬斯坦》的演示版，请访问 http://www.idsoftware.com/games/wolfenstein/rtcw/index.php?game_section=overview。单机和多人演示版均可提供。

> 注意：你需要 NVIDIA 显卡来运行《城堡要沃尔芬斯坦》。

### 使用 Cedega 游戏

TransGaming Technologies (http://www.transgaming.com) 为 Linux 带来了目前在 Windows 平台上的一些热门游戏。通过与 Wine 开发者合作，TransGaming 正在开发 Cedega，它允许你在 Linux 上运行许多原本为 Windows 开发的不同游戏。虽然 TransGaming 正在制作少数单独打包并针对 Linux 优化的游戏，但在大多数情况下，它向你出售 Cedega 的订阅服务而不是游戏。该订阅服务让你跟进 Cedega 的持续开发，从而运行更多的 Windows 游戏。

> 注意：在使用 Cedega 运行游戏之前，你可能需要从 kernel.org 获取一个原生内核并在你的系统上引导它。

为了让 Windows 游戏在 Linux 中运行得良好，Cedega 需要开发许多当今游戏所需的 DirectX 特性。还有与 CD 密钥以及接入 Windows 系统的钩子（如 Microsoft 活动桌面）相关的问题必须解决。事实上，Cedega 订阅是有价值的，部分原因在于允许你投票决定希望看到 TransGaming 哪些哪些游戏。

TransGaming 的完整游戏列表（以及关于它们受欢迎程度和运行效果的指示说明）可以在 TransGaming.org 网站 (http://games.cedega.com/db) 获取。你可以按类别或字母顺序浏览游戏。由 TransGaming 官方支持的游戏用星号标记。在每个游戏描述页面上都有指向相关 Wiki 的链接，其中提供了有关游戏在 Cedega 下运行情况的详细信息以及使其运行更好的提示。

TransGaming 为 Cedega GUI（原名为 Point2）添加了新功能。Cedega GUI 提供了一个图形窗口用于在你的计算机上安装、配置和测试 Cedega。它还允许你安装和组织游戏，以便通过图形界面启动它们。图 7-7 显示了 Linux 中 Cedega GUI 的示例。

新 Cedega GUI 的功能包括新的外观以及单独配置每个游戏在 Cedega 下运行方式的工具。（如果游戏无法从 GUI 运行，请尝试从终端窗口启动。）

你可以下载 Cedega 的 14 天免费试用版，在限制时间内其功能完备。要获得 Cedega 的全部收益，你需要订阅 TransGaming。有关如何成为“TransGamer”的详细信息，请点击 TransGaming 首页 (http://www.transgaming.com) 上的“Subscribe Here”。目前的福利包括：

- 下载最新版本的 Cedega
- 访问 Cedega 支持论坛
- 能够对你希望 TransGaming 下一个支持的游戏进行投票
- 订阅 Cedega 时事通讯

Cedega 曾被称为 WineX。WineX 的源代码可能在不久后可用，直到你构建自己的 WineX/Cedega 软件包。要检查可用性，请访问 WineX 的 SourceForge.net 项目站点 (sourceforge.net/projects/winex)。
