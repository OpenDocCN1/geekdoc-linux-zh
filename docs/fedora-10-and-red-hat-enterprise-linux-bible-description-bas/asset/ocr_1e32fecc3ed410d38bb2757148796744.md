If the Samba server doesn't appear on the Connect to Server window, you can type the name or IP address of the server, followed by the name you want in the address box on the bottom of the window. Here's an example of accessing for a Samba share from the Connect to Server window:

```
smb://192.168.0.3/toyprojects
```

In this example, Mac OS X that at it is looking for a Samba share. The Samba server in this example is located at IP address 192.168.0.3 (you could use NetBIOS instead of an IP address). The name of the share is toyprojects. You could also add the group and user name to the command line. Here's an example that for a shared name toyprojects on a named toys, in the ESTREET workgroup, as the user name chris:

```
smb://ESTREET:chris@toys/toyprojects
```

Here are a few things you should know about accessing shares from Mac OS X:

+   * When authenticating your password (see Figure 26-4), Mac OS X sends your password in clear text. When authenticating an AppleTalk share, there is no way to select to send encrypted passwords from this window

+   * The example of setting up Linux Samba shares in Chapter 18 shows how to set up Samba to ask for encrypted passwords (and therefore fail authentication from Mac OS X). To get around the problem (on a secure network), you can create a share that either accepts clear-text passwords or have the share be available to guest users.
