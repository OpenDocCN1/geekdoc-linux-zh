# Web Publishing

The final destination for your documents and images doesn't have to be paper. Publishing on the Web has become commonplace in the past few years. If you want to control your Web site for publishing your thoughts and pictures to the web. Linux systems includes many software packages to help you do.

If you are creating simple HTML pages, you can create basic HTML documents using word processors such as OpenOffice.org Writer or SeaMonkey. If you are brave, you just try a plain editor and add the HTML markup manually. For complex sites, however, there are lots of options.

The following lists open source software packages that can be used for publishing on the Web. All of the software packages described here are packaged for Fedora, as well as other Linux distributions.

> WARNING: Web servers are constant targets for bad guys on the Internet. If you decide to try of the software described below, be sure to check with the project site to make sure you get the latest patches and updates.

+   - Image galleries The Gallery project (http://gallery.melento.com) lets you create online photo albums. Gallery makes it easy for you to organize photos into albums, edit your images, tag them, and present them using a variety of themes and colors. In Fedora, install the gallery2 package.

+   - Blogging software—The popular WordPress site (http://www.wordpress.org) uses its open source WordPress software (http://www.wordpress.org) to offer blogging accounts to others. If you want your blogging site, you can either sign up for a free account on WordPress.com or you can use software to set up your own blogging site. Install the wordpress package in Fedora to get started.
