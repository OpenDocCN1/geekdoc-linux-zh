# Choosing wireless hardware

Getting cards working in Fedora and RHEL, without some scrambling around, has been hit-or-miss recently. In a recent release of Fedora, the project made the decision to track and include firmware drivers for as many wireless LAN cards as they found (provided they could be legally redistributed with Fedora). You can follow the progress of this effect here:

```
http://fedaproject.org/wiki/Releases/FeatureWirelessFirmware
```

Some of the results are that follow the Fedora software packages that include support for different wireless cards:

+   - amtel-firmware Contains firmware needed for Amtel at76c50x wireless network chips.

+   - ip2100-firmware Contains firmware needed for Intel PRO/Wireless 2100 Network Connection mini PCI adapters in Linux. Read about the driver for these cards at the project's Web site (http://ip2100.sourceforge.net/index.php).

+   - ip2200-firmware Contains firmware needed for Intel PRO/Wireless 2915ABG Network Connection and Intel PRO/Wireless 2200BG Network Connection mini PCI
