# Quickstart the Apache Web

If Apache was not installed during the Fedora installation, you can install it from the DVD or CD that you need. You will need the httptd package and the optional httpd-docs-manual package (apache and apache-manual in earlier versions).

Here's a quick way to get your Web server going. From here, you will need to customize it to match your needs and environment (as described in the section that follows).

+   Make that Apache is installed by following this from a Terminal window:
```bash
$ rpm -qa | grep httpd
system-config-httpd-1.4.4-1.fc9
httpd-tools-2.2.8-3.1386
httpd-devel-2.2.8-3.1386
httpd-2.2.8-3.1386
httpd-manual-2.2.8-3.1386
```

The version you may see be different. If you only the httpd package to get started. I recommend httpd-manual because it has excellent information on the whole Apache setup. The httpd-devel package includes the axs tool for building and installing extension modules. The httpd-tools package includes tools for running benchmarks and managing passwords for Apache.

The system-config-httpd package contains a GUI-based Apache Configuration tool. Depending on the type of content you are serving, you might also add modules to run code within the Apache server (such as mod_perl, mod_python, and mod_mono).

+   A valid host name is recommended if it is a public Apache server (for example, www.handsonsistory.com). If you don't have a real, fully qualified domain name, you can edit the /etc/httpd/conf/httpd.conf file and define the ServerName as your computer's IP address. Open the httpd conf file (as the root user) in any text editor, search for the line containing ServerName www.example.com:80, and uncomment it.

ServerName www.example.com:80
