With your camera connected and the gThumb window open, here are some things you can do with the images on your camera:

- **Download images** Click a single image or select Edit $\rightarrow$ Select All to highlight all images from your digital camera. Then select File $\rightarrow$ Import Photos. From the Import window you can select the destination where you want the images to be downloaded. As an alternative, you can download selected images to a folder on the GNOME desktop.

- **View Slideshow** Select View $\rightarrow$ Slide Show. A full-screen slideshow appears on your display, with images changing every few seconds. The toolbar that appears at the top lets you display information about the photo name, date, and size (click Image Info), go forward and back through the images, and zoom in or out.

- **Manipulate images** Double-click an image to open it, and select the Image menu. That menu offers a set of tools for enhancing, resizing, cropping, or otherwise transforming the image. You can also adjust the color balance, hue/saturation, and brightness contrast.

- **Assign categories** With an image selected, click the Categories button. The Categories pop-up window lets you assign the image to a category to help you organize your photos. Assign available categories (such as birthday, family, holidays, or games) or click New and add your own categories.

Once images are downloaded to your computer's hard disk, you can continue to work with them using gThumb or use any number of tools available for manipulating digital images (GIMP, KView, and Quickshot, to name a few).

# Using your camera as a storage device

## Using the Web

The Internet has become an essential part of modern life. In this chapter, we will explore the various ways to use the Internet with Linux. We will look at web browsers, e-mail clients, FTP clients, BitTorrent, and more.

### Web browsers

A web browser is an application used to view pages on the Web. There are many web browsers available for Linux, each with its own features.

- Firefox: The most popular web browser for Linux. It is fast, secure, and has many extensions.
- Chrome: Google's web browser, which is also very popular and powerful.
- Mid: A lightweight web browser that is good for older computers.
- Lynx: A text-based web browser for those who prefer the command line.

### E-mail clients

E-mail is a common way to send and receive messages. There are many e-mail clients available for Linux:

- Thunderbird: A powerful and feature-rich client that supports many protocols.
- Evolution: A simple and effective email client that integrates with GNOME.
- KMail: An email client that integrates with the KDE desktop.

### FTP clients

FTP (File Transfer Protocol) is used to transfer files between a client and a server. There are many FTP clients available for Linux:



- FileZilla: A graphical FTP client that is easy to use.
- lftp: A command-line FTP client that is very powerful.
- wget: A command-line tool for downloading files from the Internet.

### BitTorrent

BitTorrent is a protocol for sharing files among many users. It is particularly useful for downloading large files, such as Linux distributions.

- Torrent: The most popular BitTorrent client for Linux.
- Transmission: A simple and lightweight BitTorrent client.

### Instant messaging and chats

Instant messaging allows you to send real-time messages to others. There are many clients available for Linux:

- Pidgin: A client that supports many messaging protocols.
- XChat: A popular IRC client.
- Kopete: An instant messaging client that integrates with KDE.

### Remote commands

Remote commands allow you to log in and control a remote computer over the network.

- SSH: A secure protocol for remote login and execution.
- sc: A tool for copying files over SSH.
- rsync: A powerful tool for synchronizing files and directories.
