# Part IV: Fedora and RHEL Network and Server Setup

> NOTE: Although most of the files and folders described in the following section are invisible to Mac clients, if you share the directories with Samba or some Linux file-sharing feature (such as NFS), they will be visible. You can use the veto files of Samba to hide these files from Windows users.

# Securing netatalk volumes

Some Linux and netatalk features can be used to secure your volumes from unwanted access or misuse. The following sections describe how to protect your netatalk servers at the user, host, and file directory levels.

# User-level security

When you share a volume (in AppleVolumes.default), you can indicate which users can access that volume. Users can be authenticated using clear-passwords (to log in to their basic Linux user accounts) or by setting up a encrypted password file using netatalk.

Users can be assigned to particular volumes when you define those volumes in the AppleVolumes.default file as described earlier. Here's an example where the users mike and jojo in the group wheel are allowed access to a volume:

```
/var/homework "History homework" allow:mike,jojo,@wheel
```

To use the default passwords, you need only set up accounts as you normally would in Linux (see Chapter 11). However, to use encrypted passwords in the afpd.conf file as described earlier, you must create an AppleTalk password file (/etc/atalk/affpasswd). As root, type the:

```
# affpasswd -c
```

This command guards all regular users (UID 100 and above) and the guest user (nobody) and adds them to the affpasswd file.

Next, you to add proper passwords for each of the users added to your netatalk servers. For example:

```
# affpasswd jake
Enter NEW AFP password: ********
Enter NEW AFP password again: ********
```

After you create affpasswd, you can later add individual users manually to file (provided they have valid Linux accounts). Do that using -a option to affpasswd:

```
# affpasswd -a cindy
Enter NEW AFP password: ********
Enter NEW AFP password again: ********
```
