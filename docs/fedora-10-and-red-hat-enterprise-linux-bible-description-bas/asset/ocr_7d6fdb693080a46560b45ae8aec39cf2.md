The Xine player is an excellent application for playing a variety of video and audio formats. You can get Xine from http://xinehd.de (which takes some work to get going) or by downloading RPMs from http://rpm.livna.org/fedora. (See Chapter 5 for information on using Livina and other software repositories for getting Fedora and RHEL software. Note that the Livina repository is migrating to the new RPMMFusion.org site.) If Yum is configured to one of those repositories, you should be able to install Xine by typing `yum install xine`.

You can start the Xine player by typing xine& a Terminal window. Figure 8-12 shows an example of the Xine player window and controls.

The Xine Setup window (shown to the right) lets you choose various settings for the video player, such as a different user interface, if one is available. Below the Xine window is the Xine controller, which has buttons that work like many physical DVD players. Right-click the main window to see a menu of options. Select Settings -> Video to display another controller (shown at the Bottom of Figure 8-12) lets you adjust hue, saturation, brightness, and contrast.

Xine supports a bunch of video and audio file formats and codecs. However, not all of these codecs are distributed with Xine:

+   - MPEG (1, 2, and 4)
- QuickTime (see “Xine tips” if this content won't play)
- RealMedia (see “Xine tips” if this content won't play)
- WMV (see “Xine tips” if this content won't play)
- Motion JPEG
- MPEG audio (MP3)
- AC3 and Dolby Digital audio
- DTS audio
- Ogg Vorbis audio
