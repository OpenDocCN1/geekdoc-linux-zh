# Part II: Using Fedora RHEL

+   1. Open a Terminal window from your desktop (look for a Terminal icon on your Panel or a Terminal selection on a menu.)

+   2. Type

```
$ echo $DISPLAY
```

The result should be something similar to the following:

```
:0.0
```

This indicates that the Terminal window will, by default, direct any X application you run from this window to display 0.0 on your local system. (If you don't see a value when you type that command, export DISPLAY=0:0 to set the display value.)

+   3. With the mmms package installed, type the following command:

```
$ mmms &
```

The mmms program should appear on your desktop, ready to work with. If you do not have the mmms command, use the yum install mmms to install the program. You should note the following:

+   * The mmms command runs in the background of the Terminal window (&). This means that you can continue to use the Terminal window while mmms is running.
* I encountered no errors running mmms on this occasion. With other applications, however, sometimes appeared in the Terminal window after the command was run. The next may say that the command can't find certain information or that certain fonts or colors cannot be displayed. That information have been lost if the command was run from a menu.

+   4. If you want to know what options are available, type:

```
$ mmms --help
```

+   5. Try it with a few options. For example, if you want to begin playing a file and you have a Ogg Vorbis audio file named file.ogg, you could type:

```
$ mmms file.ogg
```

+   6. When you are ready to close the mmms window, you can either do so from the mmms box (right-click on the mmms window and select Exit) or you can kill the process in the Terminal window. Type jobs to see the job number of the process. If it was job 2, you would type kill %2 to kill the mmms program. If instead you want to continue running mmms in the background, press Ctrl+Z (to put it in the background) and bg (to continue running it in the background).

You should try running a few X commands. A couple of old X commands might try xeyes or xcalc.
