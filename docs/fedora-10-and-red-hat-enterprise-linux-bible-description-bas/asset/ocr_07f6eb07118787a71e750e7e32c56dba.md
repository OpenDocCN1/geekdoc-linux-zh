The commands for copying, moving, and removing files from a shell in Linux on your yetalak server volumes are apple_cp, apple_mv, and apple_rm. For example:

```
# apple_cp memol.doc /var/avi/memos/
```

This command copied my memol.doc file from my current directory to the /var/av2/memos/ (presumably on the same yetalak volume). This action also copies the resources associated with the file to .AppleDouble directory to you are moving. Here are examples of move and remove commands:

```
# apple_mv memol.doc /var/avi/memos/oldmemos/
# apple_rm memol.doc
```

The apple_mv moves the memol.doc file from the current directory to the oldmemos directory (moving attribute information from .Apple to the new .AppleDouble directory). The apple_rm command deletes memol.doc and removes its attribute information.

# Sharing files with netalak and Samba

A common practice if you have both Mac and Windows clients on the same network that need to share files is to have both Samba and netalak configured to share the same volume (that is, set of directories). Before you do that, be aware of the following:

+   - By default, creating files from Mac clients (on netalak volumes) will make the files easiest to work with the Mac.
- You can hide files from Mac users with the veto option in AppleVolumes.default.
- The veto option for Samba (in smb.conf) can be used to hide Mac files (such as .AppleDouble directories) from Samba users.
- If you don't, you can set the noadouble option in AppleVolumes.default to create files without them.
- Avoiding certain characters in your file and directory names can make it easier for you to share items among different types of clients. When possible, avoid characters as slash (/), backslash (\) and colon (:) when naming files. Also, wildcard characters as asterisks (*) and pound signs (#) can cause problems.

Here’s an example of a veto file you might want to add to /etc/samba/smb.conf It prevents Samba users from accessing hidden netalak-specific directories:

```
veto files = /.AppleDouble/Desktop/Network Trash
Folder/TheVolume/SettingsFolder
```
