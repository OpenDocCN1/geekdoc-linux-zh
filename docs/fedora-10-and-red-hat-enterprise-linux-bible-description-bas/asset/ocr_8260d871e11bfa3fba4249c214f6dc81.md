# Installing software in SRPM format

To install a source package from the Fedora source directory, do the following:

+   1. Refer to Appendix A for information on obtaining Fedora source code.
2. Download the package you want to the current directory.
3. Install the source code package using the following command:

```
# rpm -iv packagename*.rpm
```

(Replace packagename with the name of the package you are installing.) Starting with Fedora 10, the source is installed by default in a directory called
(/usr/src/rpmsbuild/SOURCES) in your home directory. Spec files are copied to
rpmbuild/SPECS. Prior to Fedora 10, the default was /usr/src/redhat/SOURCES
and /usr/src/redhat/SPECS.

+   4. Change to the SPECS directory as follows:

```
# cd ~/rpmbuild/SPECS
```

+   5. Unpack the source code as follows (note that you may need to install the rpm-build package):

```
# rpmbuild -bp packagename*.spec
```

+   6. The package's source code is installed to the rpmbuild/BUILD/package directory, where package is the name of the software package.

+   7. You can now make changes to files in the package's BUILD directory. Read the README, Makefile, and other documentation files on how to build the individual package.
The--rebuild option to rpbuild can be used to rebuild the rpmbuild without installing it first. The resulting binary will be in rpmbuild/RPMS/arch, where arch is replaced by i386 or other architecture you are building the RPM.
