# ssh for remote login/remote execution

Although the telnet and login commands and rsh execution command have become much older, the ssh command is the preferred tool for remote logins and executions. The reason is that ssh provides encrypted communication so you can use it securely over infine, public networks between hosts that don't know each other.

```
# ssh maple
root@maple's password:
```

If you wanted to log in as a different user, you could use the -l option. For example, to log in to the computer named jake as the user name jake, you could type the following:

```
# ssh jake@maple
jake@maple's password:
```

The ssh command can also be used to execute a command on the remote computer. For example, if you wanted to monitor the files on a remote computer for a minute, you could type the following:

```
# ssh root@maple 'tail -f /var/log/messages'
root@maple's password:
```

After you typed the password in the preceding case, the last lines of /var/log/messages file on the remote computer would be displayed. As messages were received, they would continue to be displayed until you exit (Ctrl+C to exit the tail command).

> NOTE: To learn how to use public keys for passwordless login to ssh, refer to Chapter 14. About the ssh command from the SSH Web site (http://www.openssh.org).

# Using scp for remote file copy

The scp command is simple yet secure way of copying files among Linux systems. It uses the underlying ssh, so if ssh is enabled, so is scp. Here is an example of using scp to copy a file from one computer to another:

```
# scp myfile toys.linuxtoys.net:/home/chris
root@toys.linuxtoys.net's password: *****
```
