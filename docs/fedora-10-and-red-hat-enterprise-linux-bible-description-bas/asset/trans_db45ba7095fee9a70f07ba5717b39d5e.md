## 创建新文件和文件夹

你可以使用 Dolphin 窗口创建各种类型的文件。选择“文件” -> “新建”，然后选择“文件夹”（以创建新文件夹）或使用以下子菜单中的其中一种类型：

- **HTML 文件** — 打开一个对话框，允许你输入要创建的 HTML 文件名。

- **应用程序链接** — 打开一个窗口，允许你输入应用程序名称。点击“权限”（Permissions）选项卡设置文件权限（如果想作为应用程序运行该文件，请勾选“执行”）。点击“执行”（Execute）选项卡并输入要运行的程序名称（在“执行”字段中）以及应用程序标题栏的标题（在“窗口标题”字段中）。如果是基于文本的命令，勾选“在终端运行”（Run in terminal）复选框。勾选“以不同用户运行”（Run as a different user）复选框并添加用户名。点击“应用程序”（Application）选项卡将应用程序分配给处理特定 MIME 类型的文件。点击确定。

- **位置链接 (URL)** — 选择此菜单项将让你创建一个指向 Web 地址的链接。输入一个代表该地址的名称，并输入该文件的 URL（Web 地址）名称。（务必添加 http://、ftp:// 或其他前缀）。

- **文本文件** — 打开一个对话框，允许你创建一个文本格式的文档并将其放入 Konqueror 窗口。输入要创建的文档名称并点击确定。

## 第 3 章：桌面入门

在“链接设备”（Link to Device）子菜单下，你可以从许多不同的设备类型中进行选择。以下你可以使用的一些示例：

- **CD-ROM 设备** — 打开一个对话框，允许为新的 CD-ROM 设备命名。点击“设备”（Device）选项卡并输入设备名称（/media/cdrecorder）、挂载点（如 /media/cdrecorder）以及文件系统类型（标准 CD-ROM 文件系统可以使用 iso9660，Linux 使用 ext2，DOS 使用 mdos）。当图标出现时，你可以打开 CD-ROM 并显示其内容。
- **CDWRITER 设备** — 在打开的窗口中，输入你的 CD 刻录机设备名称。
- **DVD-ROM 设备** — 打开一个对话框，允许为新的 DVD-ROM 设备命名。点击“设备”（Device）选项卡并输入设备名称（/dev/cdrom）、挂载点（如 /media/cdrecorder）以及文件系统类型（标准 CD-ROM 文件系统可以使用 iso9660，Linux 使用 ext2，DOS 使用 mdos）。当图标出现时，你可以打开 DVD-ROM 并显示其内容。
- **相机设备** — 在打开的对话框中，识别提供数字相机访问的设备名称。
- **软磁盘设备** — 打开一个对话框，你会看到一个新的软盘。点击“设备”（Device）选项卡并输入设备名称（/dev/fd0）、挂载点（如 /media/floppy）以及文件系统类型（可以使用 auto 自动检测，Linux 使用 ext2，DOS 使用 mdos）。当图标出现时，你可以打开软盘并显示其内容。
- **硬盘设备** — 打开一个对话框，允许你输入新的硬盘或硬盘分区名称。点击“设备”（Device）选项卡并输入设备（如 /dev/sda1）、挂载点（如 /mnt/win）以及文件系统类型（可以使用 auto 自动检测，Linux 使用 ext3，Windows 文件系统使用 vfat）。当图标出现时，你可以打开文件系统并显示其内容。

创建 MIME 类型和应用程序的说明将在章的后部分介绍。

## 使用 Konqueror 浏览器功能

由于 Konqueror 作为文件管理器表现类似于 Web 浏览器，因此它包含了其他几个浏览器功能。例如，你可以使用书签功能为你访问过的网站创建书签。你添加到书签列表的任何书签都会出现在点击“书签”时显示的下拉菜单中。从该列表中选择即可返回站点。有几种方法可以添加到书签列表：

- **添加书签** — 要将当前显示的页面地址添加到书签列表，请选择“书签” -> “添加书签”。书签会被静默添加。下次你点击书签时，你会在书签菜单中看到刚刚添加的书签。除了 Web 地址外，你还可以书签任何文件或文件夹。

- **编辑书签** — 选择“书签” -> “编辑书签”来打开书签的树视图。在出现的书签编辑器窗口中，你可以更改书签的 URL、图标或其他功能。还有一个非常好的功能，可以让你检查书签的状态（即地址是否仍然有效）。

- **将书签标签作为文件夹** — 你可以为你的 Konqueror 列表添加一个新的书签文件夹。要创建书签文件夹，选择“书签” -> “将书签标签作为文件夹”。然后为新的书签文件夹输入名称并点击确定。新的书签文件夹将出现在你的书签菜单中。你可以通过点击文件夹名称并添加书签来将当前位置添加到其中。

- **新建书签文件夹** — 你可以通过选择“书签” -> “新建书签文件夹”创建一个新的书签文件夹。当弹出窗口出现时，输入新的文件夹名称并选择确定。

## 配置 Konqueror 

你可以更改 Konqueror 的视觉属性。你可以选择 Konqueror 窗口中显示哪些工具栏。例如：菜单栏、位置工具栏、书签工具栏。选择“设置”（Settings）然后点击你想要显示的工具栏（或不显示）。你可以通过选择“设置” -> “配置 Konqueror”来修改 Konqueror 的选项。Konqueror 设置提供了以下选项：

- **外观** — 更改字体和颜色。

- **预览与元数据** — Konqueror 文件夹中的图标可以类似于它代表的内容。例如，如果文件是 JPEG，代表文件的图标可以是该图片的缩小版本。你可以限制文件的大小（默认为 1MB），因为许多大文件刷新可能时间过长。（注：此处原文存在大量重复性错误，翻译已按意译处理）
