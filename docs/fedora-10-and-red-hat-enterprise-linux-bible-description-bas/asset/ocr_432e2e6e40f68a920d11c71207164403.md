# Checking disk usage with du

To find out how much space is being consumed by a particular directory (and its subdirectories), you can use the du command. With no options, du lists all directories below the current directory, along with the space consumed by each directory. At the end, du produces total disk space used within that directory structure.

The du command is a good way to check how much space is being used by a particular user (du /home/user1) or in a particular file system partition (du /var). By default, disk space is displayed in 1K blocks. To make the output friendly (in kilobytes, megabytes, and gigabytes), use the -h option as follows:

```
$ du -h /home/james
114k /home/james/httpd/stuff
234k /home/james/httpd
137k /home/james/uccp/data
701k /home/james/uucp
1.0M /home/james
```

The output shows the disk space used in each directory under the home directory of the user named james (/home/james). Disk space is shown in kilobytes (k) and megabytes (M). The total space consumed by /home/james is shown on the last line. To avoid listing all subdirectories and see a total for all files and directories below a certain directory, add the -s option as follows:

```
$ du -sh /home/james
1.0M /home/james
```
