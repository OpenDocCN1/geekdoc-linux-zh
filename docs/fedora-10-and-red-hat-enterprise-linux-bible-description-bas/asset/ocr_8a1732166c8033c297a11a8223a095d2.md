# Part II: Using Fedora and RHEL

Because the Internet applications featured in Fedora and RHEL are designed to be intuitive, if you are accustomed to using the Internet from Windows or Macintosh the transition to Linux shouldn't be difficult. While I describe many of the basic features that come in these Internet applications, there are a few tricks you should learn to get the most out of:

+   **Tuning your browser** — While Firefox has great strides in different kinds of Web content, getting multimedia, image, and document formats to play in Firefox can require some extra steps. In most cases, this is because software for playing many popular multimedia formats cannot be freely distributed, so you will have to add them later. I describe many plug-ins and other software that you will add to Firefox (or another Web browser) to get it to play many popular types of content that it can't handle by default.

+   **Managing e-mail** — With e-mail increasing every day, tools for managing your e-mail are becoming more important. In the e-section, I explain how to use filters to sort your e-mail and how to identify junk mail. I also discuss ways to manage mailing lists effectively.

+   **Useful command options** — Besides identifying some commands for remote login, file copying, and command execution, I identify options that are particularly helpful to use with them.

To get started with Internet applications in Linux, you need to set up a connection to the Internet system (as described in Chapters 15 and 16). Most graphical Internet applications in Fedora and RHEL are available from menus on the GNOME or KDE desktops. Click Applications $ightarrow$ to see a list of Internet applications you can choose from. Icons to launch the Firefox browser and Evolution e-mail client are directly on the panel on top of the display.

# Browsing the Web

The most important Internet program these days is the Web browser. In Fedora and RHEL, you have several choices of Web browsers, including the following:

+   **Firefox** — The Firefox browser is touted as the flagship Web browser for the Mozilla project and is aimed at the dominance of Microsoft Internet Explorer in the browser space. Firefox offers easy-to-use features for dealing with issues that have wreaked havoc with other browsers, such as viruses, spyware, and pop-ups. Firefox is the featured web browser in Fedora and RHEL.

+   **Epiphany** — The Epiphany browser is the official Web browser of the GNOME. It is powered by the Mozilla Layout Engine (sometimes referred to as Gecko). While Epiphany doesn't have all the features you find in Firefox, it is designed to be fast and efficient.
