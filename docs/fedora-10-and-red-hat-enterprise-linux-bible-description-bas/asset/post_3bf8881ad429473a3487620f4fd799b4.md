
4. Use the fdisk command to create partitions on the new disk. For example, if you are formatting the second hard disk (sdb), you could type the following:

## RAID (Redundant Arrays of Independent Disks)

RAID (Redundant Arrays of Independent Disks) spreads data across multiple hard disks to improve performance and/or redundancy. During installation of Fedora or RHEL, you can use the following:

- **Improved performance**: RAID0 uses striping, dividing the device into stripes across RAID partitions you have selected. However, it does not provide redundancy.
- **Mirroring**: RAID1 uses mirroring so that the data is duplicated across all RAID partitions.
- **Parity**: RAID5 uses parity, so there is always one disk disk worth of data if a disk goes bad. You need at least three RAID partitions to use RAID5.

To set up RAID during installation:

1. From the Disk Setup window, click the RAID button. RAID Options window appears.
2. Select Software RAID and click OK. Add partition window appears.
3. With Software RAID selected, choose the drive you want to create and choose the size (in megabytes). Then OK.
4. Repeat Steps 2 and 3 until you have created all the RAID partitions you want to use.
5. Click the RAID button again. Select a RAID Device [default=/md0] and click OK. Make RAID Device window appears.
6. You need to select the following information about your RAID device and click OK:
- **Mount Point**: The point in the file system associated with the RAID device. You might be creating the RAID device for a part of the file system for which you expect a lot of hits (such as the /var partition).
- **File System Type**: For a regular Linux partition, choose ext3. You can also select LVM, swap, or VFAT as the file system.
- **RAID Device**: The first RAID device is typically md0 (for /dev/md0).
- **RAID Level**: Allowable RAID levels are RAID0, RAID1, and RAID5. RAID0 is for stripping dividing the device into stripes across RAID partitions you have selected. RAID1 is for mirroring so that the data is duplicated across all RAID partitions. RAID5 is for parity, so there is always.
- **RAID Members**: From the partitions you created, select which ones are going to be members of the RAID device you are creating.
- **Number of spares**: Select how many spares are available to the RAID device.

The new RAID device should appear on the Disk Setup window. Click Next to continue with installation.

Once installation is complete, you can check your RAID devices by a variety of tools that come with Fedora or RHEL. Commands for working with RAID partitions can come in the dmraid package. Using dmraid commands, you can list and reconfigure your RAID partitions.
