## Downloading and installing applications with yum

The Yellow Dog Updater, Modified (yum) software package lets you install and update selected software packages in RPM format from software repositories on the Web. Once you know the package that you want, yum is the best way to download and install that package. There are also features in yum for listing and RPMs after they are installed.

Yum is the foundation for software updates in Fedora and RHEL 5. Beside the yum command, the PackageKit windows and the Fedora installer itself (anaconda) now use yum as the underlying mechanism for generating and updating software in Fedora.

The yum is included on the Fedora DVD that comes with this. To use yum to install RPM software packages, follow these basic steps:

1. **Determine the software package you want.** Yum is delivered with the current Fedora repository already configured. Use yum or PackageKit search tools (described later) to find packages you want. Or add more repositories for yum to search to your `/etc/yum.conf` file or `/etc/yum.repos.d` directory (also described later). Many software repositories offer RPM packages that automatically configure entries in the `yum.repos.d` directory to point to those repositories.)

2. **Configure yum.** You have the option to configure the `/etc/yum.conf` file to set options that allow you to use your repositories, as described in the next section. Add any repositories, outside of Fedora, that you want to get packages from. Several popular Fedora repositories offer RPMs that install the installation yum needs to access others.

3. **Run yum.** The yum command can be used to download and install any package from the yum repository, including any packages the one want depends on.

> CAUTION: In Fedora and RHEL, Red Hat, has gone to lengths to ensure that software it provides is of good quality and unimpaired by legitimate patent claims. When you download packages that are not official packages for RHEL or Fedora, you are on your own to check the quality and legality of that software.

- **Getting metadata** — The metadata describes the contents of a repository downloaded to your computer when you run the yum command. If you run the command again after the metadata expires (30 minutes by default), you will have to wait again for the metadata.
- **If you configured to access several repositories, it can take long to repeatedly download the metadata.** To get around this problem, you can extend the metadata_expire value or run yum with a -C on the command line (to use existing metadata). The downside is that if the repository data has changed, you might not getting the latest packages.
- **Excluding repositories** — Excluding repositories on the yum command is another way to save time by preventing unneeded metadata from being downloaded. For example, if you know the package you want is Fedora, you can disable the repository by adding --disablepo=livna to the yum command.
- **Plugins** — Fedora comes with the plugins feature enabled in the yum.conf file. This file causes plugins in /usr/lib/yum-plugins directory to be enabled. When you start out, you may have no plugins or only plugins to notify the yum-updates daemon to refresh yum metadata. For information on other available plugins, refer to the YumPlugins Wiki
http://wiki.linux.duke.edu/YumPlugins.

For more information about the yum.conf file, type man yum.conf from a shell.
