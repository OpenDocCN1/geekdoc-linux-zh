## Fedora 10 Quick Install

Follow these steps to install Fedora 10 from the CD or DVD included with this book.
(See Chapter 2.) For non-x86 PCs, download PPC or x86_64 Fedora software from http://fedoraproject.org/get-fedora.html.

1. Get Media:
2. Reboot:
3. Start Install:

Insert the Fedora 10 CD or DVD into your computer's drive.
Reboot your computer.
To start the install:
* For the DVD, press Enter to begin the installation.
* For the live CD, press Enter to boot the live CD.
After the desktop appears, select the install icon from the desktop.
The complete CD installs to hard disk.

4. Media Check:
5. Language Selection:
6. Keyboard Configuration:
7. Install or Upgrade:
8. Network Configuration:

For the DVD, select media to be sure it is not damaged or corrupted.
Choose the installation language (you can add other languages later).
Choose your keyboard type.

With an earlier Fedora version installed, you can choose Upgrade (upgrade) over your system without losing data. Otherwise, continue with a new installation.

Set up your LAN connection (not dial-up). You typically select DHCP to have your network addresses assigned automatically. Or, you can manually enter your computer's address information.

9. Time Zone Selection:
10. Set Root Password:
11. Disk Partitioning Setup:

Identify the time zone in which you are located.
Add the root user account password.
Choose to install Fedora on existing Linux partitions, existing free space, or the entire hard disk (everything). See Chapter 5 before proceeding, if you are not sure which option to choose.

12. Boot Loader Configuration:
13. Choose Software:
14. Installation Categories:
15. About to install:

Add the GRUB boot manager to control the boot process. Install the boot loader to your hard disk's master boot record if no other operating system is installed.

Select one of the preset install classes, including Office and Productivity, Software Development, and Web Server. Select "Customize now" to go through the packages in more detail. Add other software repositories to install packages outside Fedora.

If you selected "Customize now", go through each category to install groups. Then select the Options button to add or subtract packages from each group.

To this point, you can quit the install process without having to restart. When you select Next, the disk is formatted (as you choose) and selected packages are installed.

When installation is done, remove the Fedora DVD or CD and click Exit to reboot your computer. During the first boot, the Fedora Setup Agent runs to configure some basic settings. After that, log in and begin using Fedora!
