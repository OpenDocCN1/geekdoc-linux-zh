# Part IV: Fedora RHEL Network and Server Setup

```
Type 'help'; or '\h' for help. Type '\c' to clear the buffer
mysql>
```

Type in the root's MySQL password as prompted. (If no password has been set, you can skip the -p option.) The mysql> prompt appears to accept commands for working with the MySQL default database on the localhost. If you are connecting to the MySQL server from another computer, use -h hostname to the command line (where hostname is the name or IP address of the computer on which the MySQL server is running). Remember that you can also log in as any valid mysql login you created, regardless of which Linux account you are logged into.

As the MySQL monitor welcome text, be sure to end each command you type with a semicolon (;) or \g. If you type a command and it appears to be waiting for more input, it's probably because you forgot to put a semicolon at the end.
