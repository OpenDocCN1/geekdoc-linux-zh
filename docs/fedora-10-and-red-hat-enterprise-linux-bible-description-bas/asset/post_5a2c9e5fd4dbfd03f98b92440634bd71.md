> NOTE: Instead of the cdrecord package, Fedora now uses the wodim package (http://www.cdrkit.org) to implement the cdrecord command. Fedora and other Linux switched to the CDR Kit project because cdrecord licensing was changed to the CDDL, which is believed to be incompatible with the GPL. Now cdrecord is a link to the wodim command, although it supports the same options as before.

This section focuses on using cdrecord to create audio CDs. The cdrecord command uses audio files in .au, .wav, or .cdr format, automatically translating them when necessary. If you have audio files in other formats, you can convert them to one of the supported formats.

CROSS-REFERENCE: See Chapter 13 for information on how to use cdrecord to create data CDs.

After extracting music tracks from your audio CD (using a tool such as cdparanoia), after you have created a directory of tracks in WAV format you can copy those files to your CD writer as:

```
cdrecord -v /dev/cdrom *.wav
```

The options to tell the command to create an audio CD (-audio) on the writable device located at /dev/cdrom. The cdrecord command writes all files from the directory that ends in .wav. The -v option causes verbose output.

If you want to change the order of tracks, you can name them as you want (instead of using *.wav). If you don't indicate a recording speed, cdrecord will try to choose an appropriate one. If you get errors while recording, sometimes reducing the recording speed can help; for example, speed=2 or speed=4.

After you have created the music CD, it should now be ready to play on any standard CD player.

## Creating a new audio CD

If you have audio tracks you want to put together for your own CD, here is how to do that from Kiso:

1. Select New Audio CD icon from the main Kiso window.
2. Open a folder window and go to the folder that contains the music files you want to burn to CD.
3. Drag and drop the music tracks you want to the Projects pane on the bottom of the Kiso screen.
4. Right-click on any track to see properties or to add information. To change the order, you can drag tracks to different locations within the pane.
5. Select the Burn button in the upper-left corner of the Projects screen.
6. From the Audio Project window that appears, select options for the burn and click the Burn button to burn the CD. As an alternative, you can select Only Image to create an ISO image of all the files you can burn to CD at a later time.

## Copying a CD

If there is an audio or data CD you want to copy, you can do so from Kiso as follows:

1. Insert the CD you want to copy into your CD drive.
2. Select Tools -> Copy CD from the Kiso window. The CD Copy window appears (as shown in Figure 8-8).
3. Choose options for the CD copy, such as the CD reader and burner devices (they can be the same if you have only one). You can also choose to do a normal copy or clone copy. Assuming you have only one drive and burner, you need to set a temporary directory that can hold the entire contents of the CD.
4. When you are happy with the options, click Start. Kiso begins copying the source disk to the temporary directory.
5. When prompted, remove the original CD and insert a blank CD into the CD drive.
6. Click Start to continue. Kiso will tell you when the copy is complete.
7. Eject the CD and mark it appropriately.

## Burning an ISO image to CD

Before your songs are copied to CD, they are gathered together into a single archive referred to as an ISO image. You can download ISO images of software (such as the DVD or CD images used to install Fedora). Although an ISO only looks like one big file before you burn it, if it is burned to a CD it appears as a filesystem containing multiple files. To burn any of the images you described to a CD using Kiso, do the following:

1. Download or otherwise copy an ISO image to a directory on your hard disk. A CD image will be up to 700MB, while a DVD can be over 4GB.
2. From the Kiso window, select Tools -> Burn CD Image. A Burn CD Image window appears.
3. Next to the Image burn box, select the folder icon to browse your file system to find the ISO image. If you select the image, it is loaded into the Burn CD window, which will display information about the image, including its MD5.
4. Check the MD5sum and compare it with the MD5 of the image you downloaded (there is likely a file ending with .md5 in the directory where you downloaded the image).
5. If the MD5sums match, continue by checking the settings on the CD Image window. I had generally good luck using the default settings. However, I find that if I get a bad burn, often changing the setting from Auto to a slower speed is what allows the result to be a good burn.
6. Click Start to begin burning the image to CD. When the writing is done, Kiso tells you whether the burn process was successful.

The descriptions for burning CDs apply to DVDs as well (provided you have a DVD burner). Remember that you are going to need a lot more temporary space on your hard disk to work with DVDs than you would to work with CDs.

## Creating CD labels with clabelgen

The clabelgen command can be used to create CD labels. The clabelgen produces a PostScript file that you can print. To see an example of how to use it, see the following:

```
clabelgen -o /dev/cdrom *.wav
```
