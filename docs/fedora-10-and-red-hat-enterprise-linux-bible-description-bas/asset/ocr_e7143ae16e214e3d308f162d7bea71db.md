# ntsysv
A screen appears with a list of available services. Use the up and arrow keys to locate the service you want. With the cursor on a service, press the Spacebar to toggle the service on or off. Press the Tab key to highlight the OK button, and press the Spacebar to save the change and exit. The ntsysv tool only changes services for the current run level. You can run ntsysv with --level option, where # is replaced by the run level for which you change services.

# Adding run-level scripts

Suppose you want to create and configure your run-level script. For example, installing the binaries for the fictitious my_daemon program, needs to be configured to start up in run levels 3, 4, and 5, and in any other run level. You can add the script to the /etc/init.d directory, then use the chconfig command to configure it.

To use chconfig, ensure that the following links are included in the /etc/init.d/my_daemon script:

```
# chconfig: 345 82 28
# description: Does something pretty cool - you really \
# have to see it to believe it!\n# processname: my_daemon
```

> NOTE: The line chconfig:345 82 28 sets the script to start in run levels 3, 4, and 5. It sets scripts to be set to 82 for run levels. It sets stop scripts to be set to 28 in all other levels.

With lines in place, simply run the following command:

```
# chconfig --add my_daemon
```

Appropriate links are created automatically. This can be verified with the following command:

```
# chconfig --list my_daemon
```

The resulting output should look like this:

```
my_daemon 0:off 1:off 2:off 3:on 4:on 5:on 6:off
```

The script names are created by chconfig to make this all are:

```
/etc/rc0.d/K28my_daemon
/etc/rc1.d/K28my_daemon
/etc/rc2.d/K28my_daemon
/etc/rc3.d/S82my_daemon
/etc/rc4.d/S82my_daemon
/etc/rc5.d/S82my_daemon
/etc/rc6.d/K28my_daemon
```
