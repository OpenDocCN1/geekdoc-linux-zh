# Loki Software game demos

To encourage people to know what it is, Loki offered a demo program that lets you choose from more than a dozen Loki games to download and try. Loki also offered boxed sets of its commercial games for purchase. Although Loki Software, is no longer in business, you can still find some of its games for sale. For example, a recent search for Loki Amazon.com turned up 16 Loki games (including the ones described here), many selling for $9.99.

WARNING: If you try to download any of the demos described in the next sections, you may have plenty of disk space available and a fast connection. It is common for one of these to require several hundred megabytes of disk space.

The Loki Launcher for downloading demos is still available from the Demo Launcher page (http://www.lokigames.com/products/demos.php3). From that page, there are links to FTP sites from which you can download the Demo Launcher. The file that you want to save is loki_demos-full-1.0e-x86.run. Save it to a directory (such as /tmp/loki) and do the following:

+   1. Change to the directory where you downloaded the Demo. For example:

```
# cd /tmp/loki
```

> NOTE: You may need to be root user to install these games. However, the default paths where the Demo Launcher tries to write by default are only accessible to the root user.

+   2. As root user, run the following command (the program may have a different name if it has been updated):

```
# sh loki_demos-full-1.0e.x86.run
```

If you have not used the Demo Launcher before, you are asked to identify the paths to place the Install Tool.

+   3. If the default locations shown are okay with you, press Enter (or add a different path if you need to assign a location with more disk space). You will then be asked to identify other locations for Uninstall and Demo files.

When all locations are defined, the Loki Update window appears.
