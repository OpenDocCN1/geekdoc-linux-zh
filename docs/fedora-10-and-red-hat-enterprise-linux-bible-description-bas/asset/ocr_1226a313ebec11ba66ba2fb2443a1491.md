# What's New in RHEL 5.2?

A range of desktop and server features were added to Red Hat Enterprise Linux 5.3. Desktop features include new versions of popular desktop applications, such Evolution 2.12.3, Firefox, OpenOffice 2.3 and Thunderbird 2.0. Improvements in clustering, storage, and virtualization have led the way to the server side of this release. Using virtualization within Red Hat's Linux Automation, a customer can deploy an application as an instance that includes not only the application itself, but also the specific operating system and settings needed to run it. Each instance can be deployed to multiple locations and easily moved to different servers to make best use of available computing resources.

Within the RHEL 5.2 framework, virtualized applications can actually be running on Linux or Windows operating systems (Windows XP, Windows 2000, Windows Server 2003, and others), so even existing applications can take advantage of Red Hat's framework for deploying and managing applications.

# Choosing an RHEL System

Red Hat, Inc. is not geared up selling and supporting only one or two systems at a time, so the packaging and pricing of Red Hat systems is aimed at orders of multiple systems. With RHEL, you're not really paying for the software. Instead, you're paying for a subscription, which includes access to all released versions of RHEL, support from Red Hat, and maintenance updates for seven years.
