## Using AppleTalk (netatalk) from Mac OS X

AppleTalk is the traditional set of protocols used by Apple computers to share files and printers over a LAN. Although Mac OS X can support Samba file sharing, AppleTalk is still a familiar way for Mac users to get to networked printers and files.

Fedora and RHEL include a software package called netatalk that you can use to configure Linux as an AppleTalk file and printer server. To a Mac client, the netatalk server looks different than any other AppleTalk server.

> CROSS-REFERENCE: Refer to the "Setting up the netatalk server" section later in this chapter.

To access a shared directory from an AppleTalk server, click Go in the Finder bar at the top of the screen, and then select Connect to Server. The Connect to Server window appears, as shown in Figure 26-2.

## Using AppleTalk from Mac OS 8 or OS 9

Prior to Mac OS X, clients access AppleTalk shares from the Chooser window. The procedure for accessing a netatalk (or other AppleTalk) server went something like this:

- 1. Click the menu and select Chooser. The Chooser window appears.
- 2. Click AppleShare. The file servers available on the local network appear in the Select a File server window.
- 3. Click the file to access and click OK. You are prompted for a user name and password (or just presented with a guest login).
- 4. Add the requested name and click OK. An icon representing the server appears on the desktop.

At this point, you can open the icon representing the shared directories and begin using the files and subfolders contained within.

## Using Mac, Windows, and Linux servers (Samba)

The procedure for accessing Samba servers from your Mac OS system is similar to the procedure for accessing an AppleTalk server from Mac OS X. As with the AppleTalk procedure, you open the Go menu from the Finder bar and select Connect to Server window, do the following:

- 1. Click the Browse button, and then click the workgroup name that contains the Samba server that you want.

> TIP: If you're not sure if the server is a Samba or AppleTalk server, look at the address at the bottom of the window after you click the server name. A Samba (SMB) address begins with `smb://`, while an AppleTalk server begins with `afp://`.
- 2. Choose the server you want to open and double-click it. You will likely be prompted for your Samba user name and password from the SMB/CIFS Filesystem Authentication window (see Figure 26-4).

## Sharing applications

Most UNIX-like systems rely on X Window System (also referred to as X11 or simply X) to display over a network. Sharing applications over the network requires little more than having X running and making it to your.

Although the default graphical interface for Mac OS is a facility called Aqua, there is now an X11 for users. The latest version of Mac OS includes a native installation. You must choose a Custom install or upgrade when you install Mac OS to get the X packages on your system. For further information on the X Window System in Mac OS, go to http://www.apple.com/features/x11. To download your own copy of X11 for Mac OS, visit this site:

http://www.apple.com/downloads/macos/macos_updates/x11.html

When I checked the site have the latest version available. For my new Mac Mini, I was able to install X11 from the installation disks that came with the computer. Open DVD D1 and select the Optional Installs package. Under applications, select the X11 package.

With X11 installed and running on your Mac OS, you can run the same X applications on Linux systems. However, you can also launch X applications from your Linux system and have them appear on your Mac OS desktop. From my Mac Mini (Mac OS 10.4.8), I did the following to start X and display an application from Fedora on my Mac desktop:

- 1. Start X11 on the Mac (from the Finder bar, select Go → Applications → X11), X11 starts and opens a Terminal.
- 2. From the Terminal window on the Mac, use the xhost command to tell X11 that it's okay to display an application from your Fedora machine. For example, to open permission to display X clients from the Fedora machine at IP address 10.0.0.100, type the following:

```
$ xhost + 10.0.0.100
```
- 3. Open a Terminal window on the Fedora machine and set your DISPLAY variable to the X11 instance on the Mac machine.
