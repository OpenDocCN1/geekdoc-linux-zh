**Figure 3-1:** A graphical login screen greets Fedora desktop users.

Notice the several menu buttons and user names are on the login screen. If you don't see the user name you, simply select Other and type your user name and password as prompted.

To log in, type your user name and, when prompted, your password. Or when you click on a Firefox Browser user. You can log in as a regular user or as the root user:

+   - **A regular user** — As someone using the Linux system, you probably have your own unique user name and password. Often, that name is associated with your real name (such as john, susanj, or jones). If you are still not sure why you need a user login, see the sidebar “Why Do I Need a User Login?” You probably have at least one user account available that was the first time you booted Fedora.
- **The root user** — Every Linux system has a root user when Linux is installed. The root user (literally the user name root) can run programs, use files, and change the computer setup in any way. The root user has special powers, and can do special manage, you usually log in as a regular user (which allows access only to that user’s files and those that are open to everyone). Logging in as the root user isn't given an option on the graphical login screen. You need to select Other to manually log in as root.
