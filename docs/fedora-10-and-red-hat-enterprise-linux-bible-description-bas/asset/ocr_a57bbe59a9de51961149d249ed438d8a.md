# Part II: Using Fedora and RHEL

There are also a variety of graphics formats. Fedora and RHEL come with lots of utilities to convert documents and graphics from one to another. The Following is a list of document and graphics conversion utilities:

+   **dosunix** — Converts a DOS file to a UNIX (Linux) text file. A reason you might want to use this command is that DOS text files include double-character carriage returns, whereas Linux (UNIX) text files have a single-character linefeed.
- **fax2ps** — Converts TIFF image files to a compressed PostScript format. The PostScript output is optimized to send to a printer on a low-speed line. This format is less efficient for images with a lot of black or continuous tones. (In those cases, tiffps might be more effective).
- **fax2tiff** — Converts fax data (Group 3 or Group 4) to a TIFF format. The output is either low-resolution or medium-resolution TIFF format.
- **gif2tiff** — Converts a GIF (8) file to a TIFF format.
- **man2html** — Converts a man to an HTML format.
- **pal2rgb** — Converts a TIFF (palette color) to a full-color RGB.
- **pdf2dsc** — Converts a PDF to a PostScript DSC file. The PostScript file conforms to Adobe Document Structuring Conventions (DSC). The output enables PostScript readers (like Ghostview) to read the PDF file at a time.
- **pdf2ps** — Converts a PDF to a PostScript file (level 2).
- **pfb2fa** — Converts Type 1 PostScript font (binary MS-DOS ) to ASCII-readable.
- **pk2bm** — Converts a TeX pfont file to a bitmap (ASCII file).
- **ppm2tiff** — Converts a PPM image file to a TIFF format.
- **ps2ascii** — Converts PostScript or PDF files to ASCII text.
- **ps2eps** — Converts a PostScript file to Encapsulated PostScript (EPSI). Some word processing and graphics programs can read EPSI. Output is often low quality.
- **ps2pdf** — Converts a PostScript file to Portable Document Format (PDF).
- **ps2pk** — Converts a Type 1 PostScript font to a TeX pkfont.
- **ras2tiff** — Converts a raster file to a TIFF format.
- **tiffbw** — Converts an RGB or Palette TIFF image to a grayscale TIFF image.
- **tiffps** — Converts a TIFF image to PostScript.
- **unix2dos** — Converts a UNIX (Linux) file to a DOS text file.

Besides these tools, many graphical applications, such as The GIMP, enable you to save images into several different formats (BMP, JPEG, PNG, TIFF, and so on), using the Save As feature.
