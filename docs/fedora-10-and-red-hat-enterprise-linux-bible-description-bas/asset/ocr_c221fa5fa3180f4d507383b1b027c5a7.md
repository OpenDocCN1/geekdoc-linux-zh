# Chapter 26: Integrating Fedora with Apple Macs 1009

Mac OS X Leopard offers called Boot Camp that can be used to resize Mac hard disks (using the default HFS+ file system). Until Leopard was released, the beta version of Boot Camp was available as a free download from Apple. The following procedure describes how to update your firmware, resize your disk, and install Fedora.

> NOTE: Because Boot Camp is no longer available for Mac OS X versions prior to Leopard, there is no official way to resize your disk to allow multiple boots on your Mac. However, in theory you should be able to use a partitioning tool that supports HFS+ resizing to prepare your disk to install Fedora along side Mac OS X. Refer to Chapter 2 for information on how GPTart can be used to resize partitions, such as HFS+ partitions. If you decide to try it, your results come without warranty. (In other words, you're on your own.)

+   - Insert Fedora DVD — When partitioning is done, instead of inserting a Windows Installation CD as requested, insert a Fedora installation CD or DVD and Restart Mac OS X or Install Windows to reboot the computer. When reboots, you should see the Fedora installer boot screen.

+   - Reboot and Alt key — When Fedora installation is complete, reboot. Hold the Alt key as the machine reboots. When you see the Boot Camp menu, select Windows and the computer will boot to Fedora. Just use the default boot entry for Fedora
