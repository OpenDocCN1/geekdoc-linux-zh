| Format | Extension | Description |
| --- | --- | --- |
| gzip file | .gz or .bz | File was compressed with the GNU gzip utility. It can be uncompressed using the gzip or gunzip utilities (they are the same). |
| tar file | .tar | File was archived using the tar command, is used to gather multiple files into a single archive file. You can expand the archive into separate files using tar with different options. |
