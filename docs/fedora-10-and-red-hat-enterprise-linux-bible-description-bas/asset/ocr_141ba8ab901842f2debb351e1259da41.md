BitTorrent is an excellent tool for the free and open source software community. For example, when a new release of Fedora comes out (including more than 13GB of software), using BitTorrent means you don't have to wait for days for traffic on the Fedora servers to cool down. Likewise, those who want to share videos with the world can do so without having an industrial-size server and bandwidth. Of course, there are also those who are concerned that BitTorrent makes it easy to share people shouldn't, such as commercial movies, music, and software.

Both a text-based and graphical (bittorrent-gui) BitTorrent client are available from the Fedora repository. You can get clients by installing the following as root user from a Terminal window:

```
# yum install bittorrent-gui
```

To Use BitTorrent, visit a Site that offers downloads and look for a link to a torrent file representing the software, video, or other type of file to download. Download the torrent file to your computer. Open the BitTorrent Window (select Applications -> Internet -> BitTorrent File Transfer). Open the torrent file (look for a file with a .torrent extension) you downloaded selecting File -> Open torrent.

The slider on the Torrent window controls how much bandwidth you will allow for others to upload the files that you are downloading. The more you supply, the faster you will be allowed to download the file. You can continue to make the file available to others after you are finishing downloading.

To create your own torrent for a file or directory of files you want to share, select File -> Make new torrent. While you can always publish your torrent on a public server, your firewall may limit your ability to publish your own torrent to the Internet. For more information on BitTorrent, refer to the BitTorrent Introduction at http://www.bittrent.org/introduction.html.

# Using Remote Login, Copy, and Execution

This section describes some features for allowing users to use resources across a network. They are telnet, ssh, and get commands.

> CROSS-REFERENCE: The only ssh service is turned on by default in Fedora because the other remote login, execution, and copy commands described here do not provide encrypted communications by default, so they can represent significant security risks. For information on how to turn on the services described in this chapter on a Fedora or RHEL server, refer to Chapter 14 and Appendix B.

Two of the commands described in this section are generally available remote login and file transfer programs: telnet and ftp, respectively. Other commands for accessing FTP servers are nfcftp and gFTP. The ssh command is typically used as a secure login command, although it can be used for remote execution as well.
