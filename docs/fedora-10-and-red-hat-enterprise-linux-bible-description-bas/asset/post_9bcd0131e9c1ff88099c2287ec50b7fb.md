- **/dev/dsp1,/dev/adsp** — Digital sampling devices, which many audio applications identify to access your sound card.

- **/dev/sequencer** — Device that provides a low-level interface to MIDI, FM, and GUS.

During the first-start after you install Fedora, the Firstboot setup agent tries to detect and configure your sound. If that was not successful, Red Hat will recommend you a bug report. ## Adjusting sound levels

Every audio output (Playback) and input (Capture) device associated with your sound cards can be adjusted or muted using one of different tools. To control volume on multiple audio applications, you can use the PulseAudio Volume Control window.

The PulseAudio Volume Control window displays slider bars for each audio application on the system (typically with right and left channels). Besides controlling volume, you can also select the default input and output devices, or associate each audio application with particular input and output devices. From the Applications menu, select Sound & Video -> PulseAudio Volume Control to see that.

Figure 8-2 shows an example of the PulseAudio Volume Control window with two audio applications. The Totem Movie Player is playing a video in this example. A lock button lets you lock or unlock the two channels for each application. You can use the slider to adjust volume levels together or separately. A mute button lets you mute or unmute sound for each application.
