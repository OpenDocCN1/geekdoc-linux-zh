+   **KsCD Player (ksed)** — The KsCD player comes with the KDE desktop. To use KsCD, the kmultimedia package must be installed. From the Applications menu (KDE desktop), select Sound & Video → KsCD (or type ksed from a Terminal window). This player lets you cite, track, and artist information from the CD database, and lets you submit information you type in a CD database (if your CD isn't found there).

+   **Rhythmbox (rhythmbox)** — Import and manage your music collection with Rhythmbox music management and playback software for GNOME. Rhythmbox uses Gstreamer and Sound Juicer to extract music from CD, and compresses it using Ogg Vorbis, FLAC, or a low-quality WAV (for speech) audio format. Besides allows you to create playlists of your music library, Rhythmbox also has features for playing radio stations. Open Rhythmbox from the Applications menu by selecting Sound & Video → Music Player.

+   **XMMS (xmms)** — The X Multimedia System (XMMS) audio player provides a simple, graphical player for Ogg Vorbis, WAV, FLAC, and other audio formats. XMMS has a simple windows-like look and feel, which you can adjust using a few dozens. The xmms package is available in the Fedora repository. To add CD player support to yours, install the xmms-crepage package as well.

+   **ogg123, mpg321, aplay, or** — If you don't have access to the desktop, you can use the text-based ogg123, mpg321, or play commands. The ogg123 command with the vorbis-tools package, aplay is part of the als-utils package, and play comes with the sock package in Fedora and RHEL. The mpg321 command is available from the Livna.org RPM site. There is an mpg123 project, which is no longer maintained and is not fully covered under the GPL.

The default CD player is Rhythmbox for the current release. One advantage of Rhythmbox, and other Gstreamer audio applications, is that it will work with the free and legal MP3 codes you can download.

> NOTE: If you try some of these CD players and your CD-ROM drive is not working, see the sidebar "Troubleshooting Your CD-ROM" for further information.
