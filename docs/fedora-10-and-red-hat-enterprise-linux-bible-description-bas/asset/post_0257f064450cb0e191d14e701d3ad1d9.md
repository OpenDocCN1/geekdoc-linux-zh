- **Account name and password** — This information is used to verify that you have an Internet account with the ISP. This is referred to as an *account name* when you connect to a Linux or UNIX system. (When connecting to an NT server, the account name may be referred to as a *system name.*).

- **An IP number** — Most ISPs use Dynamic IP numbers, which means that you are assigned an IP number temporarily when you connect. Your ISP assigns a permanent IP when it uses static IP addresses. If your computer or all the computers on your LAN need to have a permanent presence on the network, you may be given one static IP address or a set of IP addresses to use.

- **DNS IP addresses** — Your computer translates Internet host addresses by querying a Domain Name System (DNS) server. Your ISP should give you at least one IP address for the preferred (and potentially alternate) DNS server.

- **PAP or CHAP secrets** — You may need a PAP id or CHAP id as instead of a login and password when connecting to a Windows NT system at your ISP. These features are used with authentication on Microsoft operating systems, as well as other systems. Linux and other servers don't typically use this type of authentication, although they support PAP and CHAP on the client side.

Besides providing an Internet connection, your ISP typically provides services for your Internet connection. Although you do not need this information to create your connection, you will need soon afterward to configure these useful services. Here is some information you should acquire:

- **Mail server** — If your ISP is providing you with an e-mail account, you must know the address of the mail server, the type of mail service (such as Post Office Protocol or POP3), and the authentication password for the mail server in order to get your e-mail.

- **News server** — To enable you to participate in newsgroups, the ISP may provide the name of a news server. If the server requires you to log on, you will also need a password.

After you have gathered this information, you are ready to set up your connection to the Internet. To configure Fedora or RHEL to connect to your ISP, follow the PPP procedure described in that section follows.

# Setting up dial-up PPP

Point-to-Point Protocol (PPP) is used to create Internet Protocol (IP) connections over serial lines. Most often, the serial connection is established over a modem; however, it will also work over serial cables (null modem cables) or digital lines (including ISDN and DSL).

Although one side must dial out while the other side must receive the call to create a PPP connection over a modem, after the connection is established, information can flow in both

For the sake of clarity, however, I refer to the computer placing the call as the client and the computer receiving the call as the server.

To simplify the process of configuring PPP (and other network interfaces), Fedora and RHEL let you configure dial-up by either the Network Configuration Window or another tool, such as:

- **Network Configuration Window** — From the GNOME desktop panel, choose System Administration -> Network. From the Network Configuration window, select New. The Select Device Type window lets you configure and test your dial-up PPP connection.
- **KPPP Window** — Select Applications -> Internet -> KPPP, or from a Terminal run the `kppcm` command. From the KPPP window you can set up a dial-up connection and launch it. (You must have the knetwork package installed to get KPPP.)

Before you begin either of the two dial-up procedures, please connect your modem to your computer, plug it in, and connect it to your telephone line. You will probably see a telephone port on the back of your computer that you need to connect. If your modem is not detected, you can reboot your computer or run `wdialconf create` (as described later in this chapter) to have it detected.

# Creating a dial-up connection with the Network Configuration window

You can use the Network Configuration window to set up dial-up networking. To start it, choose System Administration -> Network from the desktop panel. (Type the root password, if prompted.) Select New and a Select Device Type window appears to help you select the device for your Internet connection (a dial-up connection, in this case), as shown in Figure 16-1.

Follow the below from the first Select Device Type window.

- 1. From the Select Device Type window that appears, select Modem connection and click Forward. The utility searches for a modem and the Select Modem window appears.
- 2. Selecting the following modem properties:
    - **Modem Device** — If the modem is connected to your first serial port (COM1) you can select `/dev/tty0`; for the second serial port (COM2) choose `/dev/tty1`. (By convention, the device is often linked to `/dev/modem`. Use `ls -l /dev/modem` to see if it is linked to a tty device.)

**Figure 16-1:** The Network Configuration Window helps you set up a PPP Internet connection.

NOTE: If you see the message **no such file or directory** when you list /dev/modem, it is possible that dial-up will fail later. If you determine that your modem's serial port is /dev/ttyS0, you can create the network link by typing the following command (as root user):

```
# ln -s /dev/ttyS0 /dev/modem
```

- **Baud Rate** — This is the rate at which the computer talks to the modem (which is typically faster than the modem can talk over the phone lines). For dial-up connections, the value of 57600 is probably fine.
- **Flow Control** — Check the modem documentation to see if the modem supports hardware flow control (CRTSCTS). If it doesn't, select software control (XON/XOFF).
- **Modem Volume** — This is off by default, because the modem can be noisy. However, I usually select it while I am setting up the modem. Then I turn it off everything is working. The sound can give you a sense of where things are stopping if you can't get a connection.
- **Use tone dialing** — Leave this check on in most cases. For some reason your system doesn't support tone-dialing, you can turn it off. Click Forward. The Select Provider appears.

- 3. Enter the following information:

- **Internet Provider** — If your ISP is providing you with an e-mail account, you must know the address of the mail server, the type of mail service (such as Post Office Protocol or POP3), and the authentication password for the mail server in order to get your e-mail.

- **Phone Number** — Enter the telephone number of the ISP you want to dial. (An optional prefix is available in case you need to dial 9 or some other number.)

- **Provider Name** — The name of your Internet service. For multiple dial-up accounts, use ppp1, ppp2, and so on.

- **Login Name** — The name assigned to you from the ISP. The ISP may have called the login name login ID or something similar.

- **Password** — The password associated with the login name.

- 4. With a dial-up connection, you would typically select Automatically obtain IP settings. If the ISP has a static IP address you can use, click the Statically set IP addresses checkbox, and then enter your IP address, Subnet Mask, and Default Gateway Address. Then click Forward to continue.

- 7. Click the new dial-up entry → Save to save the dial-configuration you just created.

- 8. Click the pp device name and click the Activate Button. The Internet dialer starts up and dials your ISP.

# Launching your PPP connection

Although your dial-up connection should now be configured (as described in the previous section), it is not set to connect automatically. One way to start the connection is to set it up to launch from the desktop panel. Here's how:

From the KDE desktop (after installing the kppp package):

-1. Right-click the panel and then choose Add Application to Panel → Internet → KPPP.

-2. Select the KPPP icon from the panel (type the root password, if prompted). A KPPP window appears.
