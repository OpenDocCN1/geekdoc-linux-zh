# Understanding dump levels

The dump command can back up all files on a system, or selectively back up only those files that have changed recently. The dump level parameter is used to specify this behavior. A dump level 0 results in a full backup of all files on the system. Specifying a higher number (1–9) backs up only those files that have changed or added since the most recent dump of the same or lower level. I recommend using dump levels to implement a full and incremental backup schedule like the one shown in Table 13-4.

# Table 13-4: Recommended dump Schedule

| Day of Week | Dump Level |
|---|---|n| Sunday | Level 0 (full dump). Eject the tape when done. |
| Monday | Level 9 (incremental dump). |
| Tuesday | Level 8 (incremental dump). |
| Wednesday | Level 7 (incremental dump). |
| Thursday | Level 6 (incremental dump). |
| Friday | Level 5 (incremental dump). |
| Saturday | Level 4 (incremental dump). |

Note that the full backup on Sunday, a level 9 incremental dump is the next day, and a successively lower dump level is each day after that. This results in all the files that have changed since Sunday being backed up every single incremental backup. Each backup is larger than the previous one; the backup contains all of the files from the previous incremental backup plus any that changed since. This might seem wasteful of storage space on the backup tape, but it will save a lot of time and effort there should be a need to restore the file system (This is referred to as a differential backup.).
