# 在 Linux 中听音乐

良好的音学硬件被认为是今天桌面系统和笔记本电脑系统的必需品。在播放从互联网下载的歌曲、数字电影的音轨或来自电视采集卡的音频时，任何用户友好的操作系统都必须支持一套健康的音学硬件和音频应用程序列表。

大多数 PC 的流行声设备（无论是独立声卡还是集成在计算机主板上）会在 Fedora 或 RHEL 系统启动时被自动检测。系统将加载相应的模块，因此你可以立即开始使用声卡。

从 Fedora 8 开始，PulseAudio (http://www.pulseaudio.org) 成为 Fedora 的默认音频系统，接替了高级 Linux 声学架构 (ALSA) 的位置。PulseAudio 基本上提供了音频应用程序与声卡之间的接口。与其他音频系统相比的一个主要改进是，它允许你对不同的应用程序单独控制音量。此外，通过引入插件，PulseAudio 让你可以可以使用为 ALSA 设计的音频应用程序。

为了控制播放音量以及音频输入输出设备，`pulseaudio` 包包含了 PulseAudio 音量控制器（PulseAudio Volume Control）。`alsa-utils` RPM 包包含了你可以用于调节声卡和调整音频电平的命令和配置文件。GNOME 和 KDE 项目还使用了其他友好的图形工具来管理声音。

在声卡工作并调整好音频电平后，你可以使用 Linux 自带的数十种音频应用程序来配合你的声卡。这些应用程序包括音乐播放器、视频播放器、视频会议应用、游戏和音频录音机等。

至于音频内容，以下列表描述了你可能想要播放的音频内容类型、每种内容可以使用哪些播放器，以及该软件是否随 Fedora 或 RHEL 提供。（如果没有，我将描述从哪里获取播放这些内容的软件，以及获取和使用这些内容相关的问题。）

- **音乐 CD (CDDA)** —— 商业音乐 CD 几乎都存储在紧凑数字音频系统 (CDDA)。可以播放音乐 CD 的 Fedora 和 RHEL 应用程序包括 CD Player (gnome-cd) 和 KsCD (kscd)。Rhythmbox 可以播放音乐 CD，还可以将其导入你的硬盘（使用 Sound Juicer），这样你就可以从一个地方管理音乐。Fedora 中其他从 CD 播放音频文件的应用程序还包括 xms 和 grimp。

- **Ogg Vorbis** —— 如果你是从零开始压缩和存储音乐，如果你想完全避免任何版税，那么 Ogg Vorbis 是最佳选择。`libvorbis` 解码器包含在 Fedora 和 RHEL 中，使得可以在多种 Linux 音乐播放器中播放 Ogg Vorbis 编码的音频，包括 xms、Rhythmbox、ogg123 等。`vorbis-tools` 包还包含了用于将 Ogg Vorbis 内容转换为 WAV 或原始音乐格式的编码 (oggenc) 和解码 (oggodec) 工具。Xiph.Org 基金会开发 Ogg Vorbis 音频格式和视频格式。

- **MP3 音频** —— MPEG Layer 3 (MP3) 已成为通过计算机网络（如互联网）传输的音频文件的标准格式。由于分发播放器的许可问题，红帽在其任何发行版中均不包含编码或解码 MP3 文件的解码器。然而，Fedora 提供了机会从 Fluendo 下载免费、合法的 MP3 解码器（如本章较早所述）。

获取 MP3 支持的另一种方法（在你的所在地可能不合法法）是安装 `xms-mp3` 包，它包含了 Linux 音频播放器所需的软件，用于将 WAV、AIFF 或原始音频文件转换为 MP3 并在 MP3 播放器上播放。许多人可能需要 `lame` 包来创建压缩音频文件。许多人使用 `mpg321` 命令行 MP3 播放器，它可以在 `mpg321` 包可用。（这些包都可以从 Livna RPM 仓库获取。请参见第 5 章关于从 Livna 仓库安装软件的内容。）

- **FLAC 音频** —— FLAC 是一种开源无损格式。无损意味着它在压缩时不会丢失任何数据，这对于高质量音频非常理想。许多播放器支持 FLAC，包括 Rhythmbox 等。如果你需要将文件编码为 FLAC，可以使用 `flac-tools` 包中提供的工具。

- **其他格式** —— 还有许多其他音频格式，如 WAV、AIFF 和 WMA。WAV 是未压缩格式，而 WMA 是微软的专用格式。关于这些格式的更多信息，请参阅本章节的视频播放器部分。

# 配置声卡

在 Linux 中配置声卡包括拥有正确的模块（通常在启动时发生）以及使用声音工具（如 PulseAudio 音量控制、alsamixer 或 amixer）来调整声卡。今天的声卡具有更多的 Mic-In、Line-In 和 Speaker-out 端口。

# 声卡功能

现在的声卡可以配备惊人的功能。大多数 PC 都自带声音。如果你想购买声卡，这里是你应该寻找的一些功能：

- **音频录制和播放质量** —— 当你录制和播放音频时，质量由字长（用于存储数值的位数）和采样率决定。典型的长度包括 8 位（不常用）、16 位或 24 位。为了转换声音，主板以 8 kHz 到 96 kHz 的频率进行采样，即每秒 8,000 到 96,000 次。（当然，采样率越高，声音越好。）

- **全双工支持** —— 这允许同时录制和播放。对于双向互联网通信或同步录制和播放特别有用。

- **PCI 或 USB 接口** —— 大多数人购买 PCI 声卡放入桌面系统，是因为计算机主板上的声音端口不足。如果你在使用插槽有限的 PC（如 Shuttle）或笔记本电脑，有支持的 USB 声卡。

主板上的不同端口允许你连接输入/输出设备。这些端口可能包括以下全部端口：

- **线路输入 (蓝色)** —— 连接外部 CD 播放器、磁带机、合成器、MiniDisc 或或其他设备进行录制或播放。如果你有电视采集卡，你可以将该卡的线路输出连接到声卡的线路输入。

- **麦克风 (红色)** —— 连接麦克风用于音频录制或通信。

- **耳机/线路输出/扬声器输出 (绿色)** —— 连接扬声器、耳机或立体放大器。（在我测试的声卡上，这在混合器工具中被标记为耳机。）
