Let's say you downloaded a directory of RPMs and you want to selectively freshen the ones you have installed. With the directory of RPMs as your current directory, you could type:

```
# rpm -Fv * *.rpm
```

Packages already installed are updated with the new RPMs. All other RPMs are skipped.

## Removing packages with rpm

If you no longer want to use a package (or you just want to recover some disk space), use the -e option to remove a package. In its simplest form, you use rpm with the -e option as follows:

```
# rpm -e package
```

If there are no dependencies on this package, it is silently removed. Before you remove a package, you may want to do a quick check for dependencies. The -q option is used for a variety of queries. (Checking for dependencies isn't necessary because rpm checks for dependencies before it removes a package. You may want to do this for your own information, --whatrequires.) To check for dependencies, the following:

```
# rpm -q --whatrequires package
```

If you decide to remove the package, I recommend using the -vv option with rpm -e. This lets you see the actual files that are being removed. I also suggest that you direct the output to a file or to least command make the output runs off the screen. For example:

```
# rpm -evv jpilot | less
```

This example removes the jpilot package and shows you the files that are being removed page at a time. (Press the Spacebar to page through the output.)

Other options that you can use with rpm -e can be used to override conditions that would prevent the package from being removed or prevent some processing (such as not running preinstall or postinstall scripts). Three of these are as follows:

- --nodeps -- Uninstall the package without checking for dependencies
- --noscripts -- Uninstall the package without running any preinstall or postinstall scripts
- --notriggers -- Uninstall the package without executing scripts that are triggered by removing the package

## Querying packages with rpm

You can use the query options (-q) to get information about RPM packages. This can be simply listing the packages that are installed or printing detailed information about a package. Here is the basic format of an rpm query command (at least one option is required):

```
# rpm -q [options]
```

The following list shows some useful options you can use with an rpm query:

- -qa — Lists all installed packages.
- -qf — Lists the package that owns file. (The file must include the full path name or rpm assumes the current directory.)
- -qi package — Lists lots of information about a package.
- -QR package — Lists components (as libraries and commands) that package depends on.
- -ql package — Lists all the files contained in package.
- -qd package — Lists all documentation files that come in package.
- -qc package — Lists all configuration files that come in package.
- -qp [option] package — Query packages that are not yet installed. Using this option, along with other query options, allows you to query packages that are not yet installed.

To list all the packages installed on your computer, use the -qa query option. Because this is a long list, you should pipe the output to less or, possibly, use grep to find the package want. The following command line displays a list of all installed RPM packages, and shows only names that include the string of characters xfree. The (-i option to grep says to ignore case.)

```
# rpm -qa | grep -i xorg
```

If you are interested in details about a package, you can use the rpm -i query. In the following example, information about the dosstools package (for working with) is:

```
# rpm -qi dosstools
Name: dosstools Relocations: (not relocatable)
Version: 3.0 Vendor: Fedora Project
Release: 1.fc10 Build Date: Tue 30 Sep 2008 09:58 AM host: x86_64
Install Date: 04 Oct 2008 11:29 AM Source: RPM
Size: 14236
Group: Applications License: GPL
URL: http://dosstools.com
Summary: Utilities for working with
Signature: GPG Sig: Matthias Shaou, Wed 30 May 2007 01:02:58 GMT, Key ID: 692ac459e254d574
```

If you want to know which command or configuration file came from, you can use the -qf option. In this example, the -qf displays the fact that `chgrp` came from the coreutils package:

```
# rpm -qf /bin/chgrp
coreutils-6.12-10.fc1.i86
```

## Querying files and documentation

Many packages have configuration files associated with them. To see what configuration files are associated with a package, use the -c option. For example, this is what you would type to find:

```
# rpm -qc ppp
/etc/logrotate.d/ppp
/etc/pam.d/ppp
/etc/ppp/chap-secrets
/etc/ppp/options
/etc/ppp/pap-secrets
```

If you want to see the documentation for a package, use the -d option. This will show you man pages, READMEs, and so on. For example:

```
# rpm -qd xorg
/usr/share/man/1/
```

If you want to see all the files contained in a package, use the -ql option. This will show you the full path of every file in the package. For example:

```
# rpm -ql dosstools
/sbin/fsck
/sbin/mkfs
/sbin/mkdos
/sbin/mkfat
/usr/share/man8/fsck
```

```
# rpm -evv --test | less
```
