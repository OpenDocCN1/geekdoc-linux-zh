

# 神话II：灵魂掠夺者 (Soulblighter)

如果你喜欢骑士、矮人以及攻占城堡，那么 Linux 版《神话II：灵魂掠夺者》可能适合你。在《神话II》中，你将获得一项任务以及拥有各种技能的部队。从那里开始，你需要策略以及洒大量虚拟血的渴望来实现你的目标。

《神话II》由 Bungie Software (http://www.bungie.net) 创建，并由 Loki Entertainment Software (http://www.lokigames.com) 移植到 Linux。这个版本的热门《神话》游戏包含了改进的图形和新的场景。

目前提供演示版本，可以在 Fedora 和 RHEL 上良好运行。一如既常，你需要一台至少配备 Pentium 133 MHz处理器、32MB 内存、80MB 交换空间和 100MB 空闲磁盘空间的计算机。如果进行多人游戏，你需要网络硬件（网卡或拨号上网），如果你想要音频，还需要一张声卡。图 7-9 显示了《神话II》的一张截图。

# 第 7 章：在 Fedora 和 RHEL 中玩游戏

## 异教者II (Heretic II)

基于 Quake 引擎，《异教者II》让你踏上了一条清除世界上致命魔法瘟疫的道路。作为主角 Corvus，你将探索地下城、沼泽和城市，以揭露并阻止瘟疫。画面丰富，游戏非常引人胜。

你在直接运行《异教者II》时可能会遇到一些崩溃问题。请务必检查 http://updates.lokigames.com 获取《异教者II》的更新，这将解决大部分问题。

## 永恒之夜 (Neverwinter Nights)

BioWare (http://www.biow.com) 为热门游戏《永恒之夜》推出了 Linux 客户端，涉足 Linux 游戏领域。《永恒之夜》是剑与魔法世界中的经典角色扮演游戏。你可以开发自己的角色进行冒险，或通过局域网或互联网与其他一起玩。你甚至可以构建自己的世界并担任地下城主（DM）。《永恒之夜》获得了海岸巫师授权，可以使用《地下城与》规则和素材。

要使用《永恒之夜》的 Linux 客户端，你必须从 BioWare 购买游戏本身。你还必须拥有来自 Windows 安装版的游戏文件。如果你或你的朋友已经有了 Windows 版本，可以从该版本中获取文件。否则，你可以在网上多个地方找到它们。请查看 http://nwn.biow.com 的安装说明获取链接。

# 总结

随着《毁灭战士3》、《遥远极线》(Far Cry) 和《魔兽世界2》等热门标题加入可玩游戏列表，Linux 作为游戏平台正在不断增长。你可以花费许多深夜在 Linux 上玩游戏。流向进入 Linux 的旧版 UNIX 游戏包括各种基于 X Windows 的游戏。对于那些不倾向于花 36 小时玩《毁灭战士3》的人来说，还有卡牌游戏、策略游戏以及一些动作游戏。

在商业方面，《文明：权力之召唤》(Civilization: Call to Power) 和《神话II》可以在你的 Fedora 或 RHEL 系统上使用。遗憾的是，这些可能会消失，因为 Loki Software（将这些应用程序移植到 Linux 的公司）已经倒闭。幸运的是，高端 Linux 游戏的未来似乎在 TransGaming Technologies 手中，他们根据之前的 WINE 技术创建了 Cega，允许 Windows 游戏在 Linux 上运行。它还在尖端开发者（id Software）和硬件制造商（NVIDIA 和 AMD）手中，他们正在扩展对 Linux 的驱动和应用程序支持。

今天提供的几乎每种音频和视频格式都可以在 Linux 中播放、显示、编码、解码和管理。随着 Theora 视频编码器的发展，现在每种主要类型的多媒体内容都有了免专利、免版税的格式。如果你是从零开始，可以使用所有的应用程序和解码器从 Linux 合法地创建、处理和共享自己的多媒体内容。

本章涵盖了 Fedora 和 RHEL 自带的许多用于播放或显示数字音乐、视频和图像的不同工具。它还尝试解释了在 Linux 中播放商业电影 DVD、MP3 音乐以及其他各种视频格式周围的一些法律问题。

互联网上 easily获取的用于电影片段、商业电影和其他内容的视频内容可以通过多个播放器查看，或在 Fedora 和 RHEL 上可用。此外，你还可以使用电视卡和摄像头查看电视和视频。

由于 CD-ROM 是录制音乐的首选物理介质，本章描述了如何设置和使用 CD 刻录机创建自己的音乐 CD。设置 CD 刻录机录制音乐后，可以使用同一个刻录机备份数据或创建软件 CD。（这些工具也可以用于刻录 DVD）。

与用于存储、编码和解码内容的格式相关的专利声明会阻止与该内容工作的开源软件被自由分发。

包括红帽（Red Hat）在内的商业 Linux 供应商决定不添加软件解码器（用于编码和解码多媒体格式），即使这些解码器是从头编写并受 GPL 保护的，它们也受到争议软件专利的限制。

在 2002 年，当 Thompson 和 Fraunhofer Gesellschaft（控制 MP3 专利）开始请求每系统 507 美元的费用后，红帽删除了 MP3 支持。（详情请参阅 http://www.mp3licensing.com/royalty。）

为了澄清，我讨论的不是版权，没有人可以声称复制他人的代码并作为免费软件发布是合法的，这显然违反了版权法。我们讨论的是专利。

专利的想法允许控制谁可以制造、销售、报价出售、使用专利申请人想出的发明。特别是对于多媒体软件，音频和视频内容的编码和解码受专利保护。因此，即使开源开发者从头编写编码和解码内容的代码，在不向专利所有者支付版税的情况下分发它们可能是不合法的。

目前正在进行反对软件专利的大规模工作。获取更多信息请参考自由基础设施基金会网站 (http://fii.org)。争议在于，许多与软件相关的项目被授予专利，这可能会严重破坏创新能力（特别是对于没有大型法律团队的开源开发者或小型软件公司而言）。

欧洲已为网页上可能出现的常见物品授予专利，例如通过网络销售物品、使用电子购物车和折扣码（参见 http://webshop.fii.org）。尽管欧洲现在有了旨在防止进一步软件专利的法律，但某些软件专利仍在授予，且现有专利仍被用于阻碍创新。
