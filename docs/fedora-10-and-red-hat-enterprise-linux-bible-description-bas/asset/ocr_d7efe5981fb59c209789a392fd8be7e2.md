# Selecting wireless LAN cards

Wireless LAN card manufacturers have not shown much interest in providing Linux drivers. Most wireless card drivers that are native to Linux were created without the help of those manufacturers. Also, in many cases Linux drivers are not available at all.

Another issue with purchasing a wireless LAN card is that manufacturers often change their hardware without notice. Wireless cards with the same name and model number may include different chipsets. While this might be a problem for Windows users (because the vendor will include a Windows driver to match), the card may fail on your Linux machine despite the fact that others using a card of the same name in Linux swear it working fine.
