Figure 10-6: System Monitor graphically displays your system's CPU and memory usage.

On the Resource Monitor window, lines scroll from right to left, indicating the percentage of your CPU being used as it rises and falls. You can also see how much of your total memory (RAM) is being used at the moment (and over time), as well as the amount of swap space being used. The bar at the bottom of the window shows the amount of data being sent and received over your computer network interfaces.

Click the Processes tab to see a listing of processes that are running for the current user. Click the columns in that tab to sort processes by name, memory use, percentage of CPU being consumed by the process, and process ID. There are also columns showing the security context of the process (if SELLinux is enabled) and the arguments associated with the process.

Click the Files tab to see the storage devices (hard disks, CD, USB flash drive, or other) that are currently mounted on your computer. Click columns to sort the devices by device name, name, file system, disk size, free space, or used disk space.

The example in Figure 10-6 shows a computer that is running with over 700MB of RAM. Although there is still fair amount of activity on the System Monitor in this example, there is still User memory available. However, if on your User memory is running near the maximum, it would indicate the likely occurrence of performance problems as RAM fills and data has to be moved to swap space. The CPU used is only about 15 percent, which indicates that the CPU is keeping up with the demand.
