# Step 3: Configure your panels

Most people manage their desktops from panels that appear at the top and bottom of the screen. These panels provide an intuitive way to:

+   - Launch applications
- Change workspaces
- Add useful information (clocks, news tickers, CD players, and so on)

Step through the following procedure to learn about the desktop (GNOME) panels:

+   1. **Applications menu — Click Applications in the top panel.** Most useful GUI applications and system tools that work with Fedora and RHEL are available from the menus and submenus of this Applications menu.
   - **Start an application —** Click Accessories, Education, Games, Graphics, Internet, Office, or Sound & Video items (assuming applications for those categories are installed), and then select any application to run.
   - **Try system tools — Select System Tools from the Applications menu.** The submenu that contains some tools for managing certain applications.
2. **System menu — Click System in the top panel.** There are several actions you can do from that menu:
   - **Change your settings — Click the Preferences item to change preferences or the Administration task item to change system-wide settings.
   - **Do administrative tasks —** Click Administration to select from a menu of administrative tasks, to do such things as configure your network, firewall, printers, sound cards, or system services. You need the password to do most of these tasks.
   - **Log out or shutdown — Click the Log Out item to log out from your current desktop session.** Click Shut Down to shutdown, restart, or hibernate (for laptop computers) your computer.
3. **Places — Click Places in the top panel.** From the menu, you can open your Home Folder, with special folders to help your Documents, Music, Pictures, Videos, and Downloads in Nautilus file manager. You can also select Connect to Server, to network servers using SSH (remote login), FTP (file transfer), Windows share (file and printing sharing), and WebDAV (HTTP file sharing). Select Search to search for selected files.
