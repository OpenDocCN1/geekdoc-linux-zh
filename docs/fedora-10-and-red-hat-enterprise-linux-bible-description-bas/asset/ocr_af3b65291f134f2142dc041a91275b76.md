# Automatically mounting an NFS file system

To set up an NFS file system to mount automatically each time you start your Fedora RHEL system, you need to add an entry for NFS file system to the /etc/fstab file. The /etc/fstab file contains information about all kinds of mount (and available to be mounted) file systems for your Fedora or RHEL.

The format for adding an NFS file system to your system is the following:

| host:directory mountpoint nfs options 0 0 |

The first item (host:directory) identifies the NFS server server and shared directory. mountpoint is the local mount point where the NFS file system is mounted, followed by the file system type (nfs). Any options related to the mount appear next in a comma-separated list. (The last two zeros tell Fedora or RHEL not to dump the contents of the file system and not run fsck on the file system.)

> NOTE:System-entries in /etc/fstab for hard disk mounts will likely show a UUID, or universal identifier, in place of the host:directory entry. For example, UUID=8366273bb-d845-4117-alb2-e286d056f561. You can view these entries under /dev/by-uuid.

The following are examples of NFS entries in /etc/fstab:

```
maple/home/chris/files /media/maple nfs size=8192,wsize=8192 0 0
oak/apps /oak/apps nfs nauto,ro 0 0
```
