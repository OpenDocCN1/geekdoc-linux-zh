```
client

proto udp
ns-cert-type server

remote example.com 1194

resolv-retry infinite

obind

persist-key
persisttun

ca /etc/openvpn/keys/ca.crt
cert /etc/openvpn/keys/client01.crt
key /etc/openvpn/keys/client01.key

comp-lzo
verb 3
```

To test your VPN client configuration is working, type the following:

```
# openvpn --config client.conf
```

The output you see from this command will help you debug any problems you have
connecting to the OpenVPN server. If you use a GUI interface to start your OpenVPN client,
be sure to identify the location of your client configuration files and keys.

# Setting Up Linux as a Proxy Server

You have a Linux set up, and your Linux computer has both a connection to the LAN and a
connection to the Internet. One way to provide Web-browsing services to the computers on the
LAN without setting routing is to configure Linux as a proxy.
The Squid proxy server software package comes with Fedora and RHEL. In a basic
configuration, you can get the software very quickly. However, the package is full of
features that let you adapt it to your needs. You can control which hosts have access to proxy
services, how memory is used to cache data, how logging is done, and a variety of other
features. Here are the basic proxy services available with Squid:

+   - Allowing HTTP proxy services are the primary reason to use Squid. This is
what lets client computers access Web pages on the Internet from their browsers
(through your Linux computer). In other words, HTTP proxy services will find and
return the content to you for addresses that look similar to this: www.ab.com.
