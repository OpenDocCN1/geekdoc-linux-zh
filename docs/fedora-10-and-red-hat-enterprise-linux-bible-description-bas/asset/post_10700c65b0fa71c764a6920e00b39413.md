## Adding a JetDirect printer

A JetDirect printer (AppSocket/HP JetDirect) is one that is connected directly to your Ethernet network via a JetDirect device. You typically use port 9100 to print to a JetDirect printer, 742 Part IV: Fedora and RHEL Network and Server Setup, although additional interfaces use ports 9101, 9102, and so on. To use a JetDirect printer from Fedora or RHEL, enter the following information:

- Enter the name of the JetDirect printer.
- Enter the port number (typically 9100) to identify the interface to the JetDirect printer.

## Using Web-based CUPS administration

The Printer configuration window effectively hides the underlying CUPS facility. There may be times, when you want to work with the tools and configuration files that come with CUPS. The following sections describe how to use special CUPS features.

> CAUTION: Plain-text configuration files are at the base of the CUPS printing facility. When different tools, such as the CUPS Web-based interface and Printer Configuration window, manipulate the same config files, these become unusable by the other tools. When possible, you should use the system-config-printer (Printer configuration window) to work with printers in Fedora and RHEL. You will see warnings to this effect if you start to use the CUPS interface.

Although the preferred way to configure CUPS printing in Fedora or RHEL is with the Printer configuration window, CUPS offers its own Web-based administrative tool.

If CUPS is already running on your computer, you can immediately use CUPS Web-based administration from your Web browser. If CUPS is not running yet, refer to the following section describing the cupsd daemon for information on starting it.

CUPS lists listen on port 631 to provide access to the CUPS Web-based administrative interface. On the local computer, type the following into your Web browser's location box:

```
http://localhost:631/admin
```

A screen like the one shown in Figure 17-4 appears.

By default, Web-based CUPS administration is available only from the localhost. To access Web-based CUPS administration from another computer, you must change the /admin section in the /etc/cups/cupsd.conf file. As recommended in the text of this file, you should limit access to CUPS administration from the Web. Also keep in mind that passwords are passed as clear text, so someone sniffing your network could see your password.
