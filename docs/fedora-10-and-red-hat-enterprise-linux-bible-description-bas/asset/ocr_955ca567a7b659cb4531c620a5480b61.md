```
define(CONTRY_NULL_MX_LIST, `True`)dnl
define(CONFDONT_PROBE_INTERFACES, `True`)dnl
```

With CONFTRY_NULL_MX_LIST true, if a receiving server is the best exchange (MX) for a host, sendmail will try connecting to that host directly. If CONF_PROBE_INTERFACES is true, sendmail will not insert local network interfaces into the list of known addresses.

```
define(`PROMAIL_MAILER_PATH`, `/usr/bin/procmail1`)dnl
define(`ALIAS_FILE`, `/etc/aliases`)dnl
dnl define(`STATUS_FILE`, `/var/log/mail/statistics`)dnl
```

The next three lines (PROMAIL_MAILER_PATH, ALIAS_FILE, STATUS_FILE) set locations for the program that distributes incoming mail (procmail, by default), the alias file, and the mail statistics, respectively.


The UOCP_MAIL_max size limits the maximum size (in bytes) for messages received by the UOCP mail. The CONFUSERDB_SPEC line sets the location of the database (which you can override the default mail server for specific users). The CONFPRIVACY_FLAGS flags cause sendmail to insist on certain mail protocols. For example, authwarnings X-Authentication headers are to be used and noted in log files. The novry and noexpn restrict option prevents them from being requested. The -q option to sendmail.
