# Binding to specific addresses

You can bind to IP addresses using the Listen directive. Listen directives can be used to add to the default bindings you already have:

```
# Listen: Allows you to bind Apache to specific IP addresses and/or
# ports, in addition to the default. See also the <VirtualHost>
# directive.
#nn# Change this to Listen on specific IP addresses as shown below to
# prevent Apache from glitchming onto all bound IP addresses (0.0.0.0)
#Listen 12.34.56.78:80
Listen 80
```

The Listen directive is more flexible than the BindAddress directive. Multiple Listen commands can be specified, enabling you to specify several IP address/port combinations. It can also be used to specify just IP addresses or port numbers.

By default, Apache listens to port 80 (for standard http services) and port 443 (for secure https services) on all interfaces on the local machine (which is Web browsers expect to find Web content). Listening on only localhost:80 restricts access to only the local machines. A web server run by a non-privileged user will bind to port 8080 (only root can bind to ports lower than 1024). If you have multiple network cards, you can limit which Apache listens on (for example, you can have a Web server only intended for the company LAN which is not exposed to your Internet interface.
