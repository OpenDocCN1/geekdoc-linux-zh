## Creating new files and folders

You can create a variety of file types using the Dolphin window. Choose File -> Create New, and select Folder (to create a new folder) or one of the types using the following submenu:

- **HTML File** — Opens a dialog box that lets you type the name of an HTML file to create.

- **Link to Application** — Opens a window that lets you type the name of an application. Click the Permissions tab to set file permissions (Exec be on if you want to run the file as application). Click the Execute tab and type the name of the program to run (in the field: Execute on click) and a title to the title bar of the application (in the field: Window Title). If it is a text-based command, select the Run in terminal check box. Click the check box to Run as a different user and add the user name. Click the Application tab to assign the application to handle files of particular MIME types. Click OK.

- **Link to Location (URL)** — Selecting this menu item opens lets you create a link to a Web address. Type a name to represent the address and type the name of the URL (Web address) for the file. (Be sure to add the http://, ftp://, or other prefix).

- **Text File** — Opens a dialog box that lets you create a document in text format and place it in the Konqueror window. Type the name of the document to create and click OK.

## Chapter 3: Getting Started with the Desktop

Under the Link to Device submenus, you select from many different device types. Here are examples of some you can use:

- **CD-ROM Device** — Opens a dialog box that lets you name a new CD-ROM device name. Click the Device tab and type the device name (/media/cdrecorder), the mount point (such as /media/cdrecorder), and the file system type (you can use iso9660 for the standard CD-ROM file system, ext2 for Linux, or mdos for DOS). When the icon appears, you can open it to the CD-ROM and display its contents.
- **CDWRITER Device** — From the window that opens, enter the device name of your CD writer.
- **DVD-ROM Device** — Opens a dialog box that lets you a new DVD-ROM device name. Click the Device tab and type the device name (/dev/cdrom), the mount point (such as /media/cdrecorder), and the file system type (you can use iso9660 for the standard CD-ROM file system, ext2 for Linux, or mdos for DOS). When the icon appears, you can open it to the DVD-ROM and display its contents.
- **Camera Device** — In the dialog box opens, identify the device name for the camera devices that provide access to your digital camera.
- **Floppy Device** — Opens a dialog box to you will see a new floppy. Click the Device tab and type the device name (/dev/fd0), the mount point (such as /media/floppy), and the file system type (you can use auto autodetect the contents, ext2 for Linux, or mdos for DOS). When the icon appears, you can open it to the floppy and display its contents.
- **Hard Disc Device** — Opens a dialog box that lets you type the name of a new hard disk or hard-disk partition. Click the Device tab and type the device (such as /dev/sda1), the mount point (such as /mnt/win), and the file system type (you can use auto autodetect the contents, ext3 for Linux, or vfat for a Windows file system). When the icon appears, you can open it to the file system and display its contents.

Creating MIME types and applications is described later in this chapter.

## Using the Konqueror browser features

Because Konqueror performs like a Web browser as a file manager, it includes several other browser features. For example, you can create a bookmark of Web sites you have visited, using the bookmarks feature. Any bookmarks that you add to your bookmarks list show up in the drop-down menu appears when you click Bookmarks. Select from that list to return to a site. There are several ways to add to your bookmarks list:

- **Add Bookmark** — To the address of the page that is currently being displayed to your bookmark list, choose Bookmarks -> Add Bookmark. The bookmark is silently added. The next time you click bookmarks, you will see the bookmark you just added to the bookmarks menu. In addition to Web addresses, you can also bookmark any file or folder.

- **Edit Bookmarks** — Select Bookmarks -> Edit Bookmarks to open a tree view of your bookmarks. From the Bookmark Editor window that appears, you can change the URLs, the icon, or other features of the bookmark. There is also a nice feature that lets you check the status of the bookmark (that is, whether the address is still valid).

- **Bookmark Tabs as Folder** — You can add a new folder of bookmarks to your Konqueror list. To create a bookmarks folder, choose Bookmarks -> Bookmark Tabs as Folder. Then type a name for the new bookmarks folder and click OK. The new bookmark folder appears on your bookmarks menu. You can add the current location to that by clicking on the folder name and Adding Bookmark.

- **New Bookmark Folder** — You can create a new bookmark folder by choosing Bookmarks -> New Bookmark Folder. When a pop-up appears, type a new folder name and select OK.

## Chapter 3: Getting Started with the Desktop

- **AdBlock Filters** — Click here to create lists of filters. You can also import and export lists.

- **Fonts** — Choose fonts to use, by default, fixed font, serif font, sans serif font, cursive font, and fantasy font. The serif fonts are typically used in body text, while sans serif fonts are often used in headlines. You can also set the Minimum and Medium sizes.

- **Web Shortcuts** — Click the Web Shortcuts to see a list of keyword shortcuts you can use to go to different sites. For example, follow the word “ask” with a search string.

- **History Sidebar** — Click here to modify the behavior of the list of sites you have visited. By default, 500 URLs are stored, and after 90 days, a URL is dropped from the list. You will also find a button to clear your history. (To view your list in Konqueror, use the left panel, and then click the scroll icon.)

- **Cookies** — Click the Cookies button to select whether not cookies are enabled in Konqueror. By default, you are asked to confirm that it is okay each time a site creates or modify a cookie. You can change that to accept or reject all. You can also set policies for acceptance or rejection of cookies based on host and domain names.

- **Cache** — Click the Cache button to indicate how much space on your hard disk can be used to store the sites you have visited (based on the value in the Disk Cache Size).

- **Proxy** — Click the Proxy button if you are accessing the Internet through a proxy server. You need to enter the address and port number of the computer providing HTTP or FTP proxy servers.

- **Stylesheets** — Click the Stylesheets select whether to use the default stylesheet, a user-defined stylesheet, or a custom stylesheet. The stylesheet sets the font family, sizes, and colors are applied to Web pages. (This won’t change particular requests made by the Web page.) If you select a custom stylesheet, click the Customize to customize your own fonts and colors.

- **Crypto** — Click the Crypto button to display a list of secure certificates that can be accepted by the Konqueror browser. By default, Secure Socket Layer (SSL) version 2 and 3 certificates are accepted, as TLS support (if supported by the server). You can also select to be notified when you are entering or leaving a secure site.

- **Browser Identification** — Click the Browser Identification button to set how Konqueror identifies itself when it accesses a Web site. By default, Konqueror tells the Web site that it is the Mozilla browser. You can select Konqueror to appear as different Web browsers to specific sites.
