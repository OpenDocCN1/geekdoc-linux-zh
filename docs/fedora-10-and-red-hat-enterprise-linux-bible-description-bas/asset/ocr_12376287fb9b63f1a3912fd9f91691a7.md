# Creating CD labels with clabelgen

The clabelgen command can be used to create trays and front cards to fit in CD jewel cases. You gather information about the CD and clabelgen produces a PostScript output file that you send to the printer. The clabelgen package also comes with graphics (in /usr/share/clabelgen) that you can incorporate into your labels. Install the package by typing install clabelgen.

Here is an example of clabelgen command line that you can use to generate a CD label file in PostScript format. (Type it on one line or use backslashes, as shown here, to put it on multiple lines.)

```
clabelgen -o "Grunge is Gone" -s "Yep HipHop! \\
i "If You Feel Me$Sock Years&city Road&Platinum and Copper&Fly \\
Fly$Best Man Spins&What A Headache&Stayin Put Feelin&Dreams Do Go \
Blue$0$Mildest Schemes" -o yep.ps
```

In this example, the title of the CD is indicated by -c "Grunge is Gone" and the artist by the -s "Yep HipHop" option. The tracks are entered after the -i option, with each line separated by a % sign. The output file is sent to the file yep.ps with the -o option. To view and print the results, you can use the evince command as follows:

```
$ evince yep.ps
```
