## Using more controls and actions

Now that you have some understanding of the controls and actions, the game can begin taking a lot of different directions. Here are a few things that might happen next and things you can do:

- After you take a tour, the computer gets a chance to play as well. As it plays, actions are reported to you. You can make decisions on what to do about those actions. Choose Game -> Message Options. The Message options window appears, containing a listing of different kinds of messages that can come from the server and how they will be presented to you. 
- As you explore, you will run into other explorers and eventually other civilizations. Continue exploring by selecting directions on your numeric keypad.
- Continue to move the Settler one at a time, after it has finished the road. (The Settler will blink again when it is available) Click Turn.
- At this point, you will see a message that your city has finished building Warriors. When buildings and units are complete, you usually check out what has happened. Click the message associated with the city, and then popup City. The city window appears, showing that you has additional population. The food storage may appear, but the new cities are working to increase the food and trade. You may see an additional warrior unit.
- A science advisory may also appear at this point to let you choose your city's research goals. Click Change and select Writing as your new research goal. You can then select a different long-term goal as well. Click when you are done.
- If your Warrior is now blinking, press the s key to assign sentry mode to the Warrior.

You should be familiar with some of the actions of Freecv at this point. To learn some basic strategies for the game, help Help -> Playing.

## Commercial Linux Games

When Loki Software, Inc., closed its doors a few years ago, the landscape of commercial gaming changed. Loki produced Linux ports of popular games, including Myth II and Civilization: Call to Power, name a few, and many hoped it would help Linux become the premier gaming platform. Today, commercial games that run natively are led by several popular games from Loki Games Demo and id Software (described in the next section).

Although Loki Software, Inc. is gone, certain Loki Games are still available for purchase on the Web. Although they sell for a fraction of their original price, you are on your own if they don't work because Loki Software is no longer there to support them. The Loki Games are still around, if Loki want to get a feel for a particular Loki game before it disappears (I describe how to find and packaged Loki Games later in this chapter).

In the wake of Loki's demise, TransGaming Technologies has been working on an approach to bringing popular games to Linux that relies on a version of WINE Cedega (formerly WineX). In most cases, instead of having different ports of popular games (as Loki did), TransGaming enables users to run existing Windows games in Linux by adapting Cedega to each game that needs a tweak here and there. For many Windows gamers, however, the performance isn't up to acceptable rates.

## Getting Started with commercial games in Linux

How you start with Linux gaming depends on how you are serious about it. If all you want to do is play a few games to pass the time, I've already described diverting X Windows games to Linux. If you want to play more powerful commercial games, you can choose from:

- **Games for Microsoft (Cedega 6.0)** — Many of the most popular games created to Windows operating systems will run in Linux using Cedega. To get RPM versions of Cedex, you must sign up for a Cedega subscription at http://www.transgaming.com. To see if your favorite game will run in Linux, refer to the TransGamingOrg Games Database at http://cedega.com/gamesdb.
- **Independent Linux Game Developers**— Several small companies are currently producing games for Linux. Notable Linux game developers include Introversion Software (http://introversion.co.uk) and Frictional Games (http://www.frictionalgames.com). Introversion's games include Uplink, Darwinia, and Defcon. By the time you read this, Multivia should also be available. Frictional games include Penumbra: Overture and Penumbra: Black Plague, both of which portray 3D horror.
- **Games for Linux (id Software and others)** — Certain popular games have Linux versions available. Most notably, id Software offers its DOOM and Return to Castle Wolfenstein in Linux versions. Other popular games that run natively in Linux include Unreal Tournament 2004 and 2005 from Atari (http://www.unrealtournament.com). Commercial games that run in Linux without WINE, Cedex, or some sort of Windows emulation typical a boxed version for Windows with some sort of Linux installer.
