# Configuring sendmail

To configure sendmail facility, you edit configuration files in /etc/mail and /etc that are then used by the sendmail start-up script to create database files. Those database files are, in turn, used by the sendmail daemon to control the behavior of your sendmail server. Once sendmail is configured, you can begin adding user accounts to mailboxes on your server. The steps I describe in this section for configuring sendmail are:

+   1. **Getting a domain name** — You need a unique Internet domain name to assign to your mail server, and then can purchase an Internet domain name from one of many different places, and then have DNS mail exchange (MX) records for your domain point to the mail server you are creating.
2. **Configuring basic sendmail settings** — In this step, you edit the /etc/mail/sendmail.mc file. That file defines things such as the locations of other configuration and log files, as well as letting you configure some behavior of the sendmail daemon.
3. **Defining owning mail access** — The most critical security associated with your mail server is which messages it will accept to relay to other mail servers. By editing the /etc/mail/access file, you can indicate the hosts and users from which your server will accept mail for local delivery or relay.
4. **Configuring virtual servers** — By default, sendmail assumes that you are setting up the mail server for the domain of which the server is a member. To have sendmail on a single computer be the mail server for multiple domains (referred to virtual servers), you need to define each domain name in the /etc/mail/local-host-names file. (You must create local-hosts manually, since it is not in the sendmail package).
5. **Configuring virtual users** — Using the /etc/mail/virtertable configuration file, you can instruct the sendmail daemon to do with what it receives for the users and domains it's configured to handle. This gives you a lot of flexibility to take mail addressed to a particular mailbox, forward it to a different mail address, or reject that mail in various ways. To use virtertable you must create the file manually, since it is not in the sendmail package.
6. **Adding user accounts** — You need to add a user account for every user that has a mailbox on your mail server.
