# Administering Your Linux System

Your Linux administrator duties don't end after you have installed Fedora or RHEL. Your ongoing job as a Linux system administrator includes the following tasks:

+   * **Configuring hardware** — When you add hardware to Fedora or RHEL computer, that will be automatically detected and configured by tools such as HAL. In those cases where the hardware was not properly set up, you can use commands as ismod, modprobe, insmod, and rmod to configure the right modules to get the hardware working.

+   * **Managing file systems and disk space** — You must keep track of the disk space being consumed, especially if your Fedora or RHEL system is shared by multiple users. At some point, you may need to add a hard disk or track what is eating up your disk space (you can use commands like find, du, and df to do this).

+   * **Monitoring system performance** — You may have a run-away process on your system or you may be experiencing slow performance. Tools that work with Fedora and RHEL can help you determine how much of your CPU and memory are being consumed.

The aforementioned administrative tasks are described in the rest of this chapter. Other chapters cover other administrative topics, such as managing user accounts (Chapter 11), automating system tasks (Chapter 12), system backups and restores (Chapter 13), and securing your system (Chapter 14). Tasks related to network and server administration are covered in Chapters 15 through 26. Ways of getting updates to your Linux software (using the Add/Remove Software window and yum command) are described in Chapter 5.
