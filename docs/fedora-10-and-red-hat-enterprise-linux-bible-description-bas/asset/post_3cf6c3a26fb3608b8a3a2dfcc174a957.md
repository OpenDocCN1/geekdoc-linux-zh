## Beginning the installation

If you feel you have prepared to install Fedora, you can begin the installation procedure. Throughout most of the procedure, you can click Back to make changes to earlier screens. once you go forward after being warned that packages are about to be written to disk, there's no turning back. Most items that you configure can be changed after Fedora is installed.

> CAUTION: If your computer contains any data that you want to keep, be sure to back it up. If you have multiple partitions, and don't expect to over-write the partitions, a backup is a good de-fact-precaution in case something goes wrong.

- 1. **Insert the DVD or CD.** This procedure ensures you are booting and installing from either DVD or CD that comes with this. (If you are not able to boot from any of media, refer to the "Alternatives for starting installation" section. If you are booting from DVD or CD, but installing the software packages from a network or hard disk, refer to the "Installing from Other Media" section.)

The DVD can be used for any type of install; the CD with this can only be used to copy the Fedora 10 desktop system on the CD to hard disk.

- 2. **Start your computer.** If you see the Fedora boot screen, continue to the next step.

> TIP: If you don't see the boot screen, your DVD or CD-ROM drive may not be booting. Creating a bootable floppy is no longer an option because the 2.6 kernel doesn't fit on a floppy. You may have the choice of making your DVD or CD-ROM drive boot or copying a boot image to a boot USB device (such as a pen drive). Restart the computer. Immediately, you will see a message telling you how to go into, such as by pressing the F1, F2, or Del key. Enter setup and look for an option such as "Options" or "Boot from." If the value is "A: First, C" change it to "CD-ROM First, C" or similar. Save the changes and try to install again.

If installation succeeds, you may need to restore the boot settings. If your DVD or CD drive still won't boot, you need to use an alternative method to boot Fedora installation (described in "Alternatives for stalling" in this chapter).

- 3. **Start the boot procedure.** At the boot screen do one of the following, depending on whether you are installing from the DVD or CD:

- * **Fedora 10 Install DVD** — With "Install or upgrade" highlighted on the boot menu, press Enter to begin the installation.

- * **Fedora 10 Desktop Live CD** — Either wait for the boot screen to time out or Boot highlighted on the boot menu, press Enter to start the live CD. When the CD boots up to a KDE desktop, double-click the Install to Hard Drive icon to begin the installation.

- **Media check.** At this point, you may be asked to check your installation media. If so, press Enter to check that the DVD is in order. If a disk is damaged, this saves you the trouble of getting deep into the install before failing. After the DVD is checked, Skip to continue.

- **Continue.** When the welcome screen appears, click Next when you're ready to continue.

- **Choose a language.** When prompted, indicate the language that you would like to use during the installation procedure by moving the arrow keys and selecting Next. (Later, you will be able to add additional languages.) You are asked to choose a keyboard.

- **Choose a keyboard.** Select the correct keyboard layout (U.S. English, with Generic 101-key PC keyboard by default). Some layouts enable dead keys (on default). Dead keys let you use characters with special markings (such as circumflexes and umlauts).

- **Choose fresh install or upgrade.** Select either "Install Fedora" for a new install or "Upgrade an existing installation" to upgrade your version of Fedora.

- 5. **Set the hostname.** Enter a hostname for your system. This is the name identifying your computer within your domain. For example, if your computer were named "baskets" in the handshistory.domain, your full hostname would be baskets.handshistory.domain. You can enter the domain name, or have it assigned automatically using DHCP.

- 6. **Choose a time zone.** Select the time zone. Either click a spot on the map or choose from the drop-down box. Before you click your location on the map, click the area of the map to zoom in. Then select the city. Click "System clock use UTC" Coordinated Universal Time (also known as Greenwich Mean Time).

## Choosing Install Modes

Although many of the steps are the same, the DVD and CD installs are different in a few ways. In particular, the DVD install lets you select which packages to install. The CD install simply copies what is essentially an installed system from the live CD to your hard disk. Some of the steps that won't apply to the live CD install.

The boot screen is menu-driven. So if you want to change any options for the menu selection, highlight and select the Tab key. You can then remove or add options before pressing Enter to continue. For example, to install from a different medium (such as over the network), use the as method boot option. See the sidebar "Choosing Install Modes" for more boot options.

The following is a list of different installation options you can use to start the install process. To use these options, highlight the first entry on the boot menu and press Tab. When the boot command appears at the bottom of the screen, type the options you want at the end of that line and press Enter to boot the process.

- **text: Type Text** to run installation in a text-based mode. Do this if installation doesn't recognize your graphics card. The installation screens aren't pretty, but they work just as well.

- **ks: Type ks** to run a Fedora installation using a kickstart file. A kickstart file provides some or all of the installation options you would otherwise have to select manually. (A section on creating and using kickstart files is contained in later.)

- **lowres: Type lowres** to run installation in 640 x 480 screen resolution for graphics cards that can't support the higher resolution. To choose a particular resolution, use the resolution option. For example:resolution=1024x768.

- **noprobe: Type noprobe** to determine what hardware you have on your computer. In **noprobe** mode, installation will not probe to determine hardware; you will be asked to load any special drivers that might be needed to install it.

- **mediacheck: Type mediacheck** to check your DVD before installing. Media checking is done next in the normal installation process, you should do this only to test the media on a computer you are not installing on. For Fedora CDs, select the Verify and Boot option to check the CD before booting.

- **rescue: The rescue mode** is not really an installation mode. This mode boots from DVD or CD, mounts your hard disk, and lets you access useful utilities to correct problems preventing your Linux system from operating properly.
