# Sending Mail to All Users

Occasionally, you need to send messages to all users on your system. Warning users of planned downtime for hardware upgrades is a good example. Sending e-mail to each user individually is extremely consuming and wasteful; this is precisely the kind of task that aliases and mailing lists were invented for. Keeping a mailing list of all the users on your system can be problematic, however. If you are not diligent about keeping the mailing list current, as you add and delete users. Also, if your system has many users, the size of the alias list can become unruly.

The following script, mailfile, provides a simple method of working around these problems. It gets the login names from /etc/passwd file and sends e-mail to all users.

> NOTE: Because user accounts begin with UID 500 in Fedora and RHEL systems, the script excludes UIDs under 500 (which are typically administrative accounts). It also skips UID 65534, which is the anonymous NFS user account.
