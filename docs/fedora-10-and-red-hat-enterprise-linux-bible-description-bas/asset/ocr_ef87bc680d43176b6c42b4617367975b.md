To select a file for background transfer, use the bgget command. Here is an example:

```
ncftp /pub > bgget_wireless.doc
Spooled: get wireless.doc
cftp /pub > jobs
---Scheduled-For---Host---------Command-----------------------
2008-06-01  18:38 maple      GET wireless.doc
cftp /pub > bgstart
Background process started.
Watch the "/home/./nr.spool/log" file to see how it is progressing
```

In this example, the bgget command pools the wireless.doc file from the remote directory (/pub) and sets it to the local current directory. Typing the command that shows the job (GET wireless.doc), from the host name, is scheduled to run immediately (6:38 p.m., June 1, 2008). By running the bgget command, this process, and any other pooled jobs, are run immediately.

Instead of starting the background transfers immediately you can do them later. For background jobs spooled for transfer, the transfer begins when you quit nftp, leave your current FTP site, or go to another FTP site. In this way, the program that does the transfer (ncftpbatch) can catch your current login session to the transfer.

If you want to wait longer to do the transfers, you can pass an option to the bgget command to start the transfer at a particular time. Here is an example:

```
ncftp /pub > bgget -e 200810041000 wireless.doc
```

With this command, the transfer is set to run at 1 a.m. on October 4, 2008 to transfer the file called wireless.doc. Again, you can check the .ncftp/spool/log file in your home directory to see if the transfer has completed. The transfer is completed by an ncftp daemon process.

# Using the gFTP window

If you prefer a more graphical interface for accessing FTP servers, you can use the gFTP window. Install gFTP by typing yum gftp. You can open a gFTP window by typing gftp. Figure 9-9 shows an example of the gFTP window.

Unlike the ftp command, the gFTP window lets you see the contents of the current remote and local directories. To transfer a file from one site to the other, simply double-click it or drag and drop it to the other pane. (Normally, you will just be copying files from FTP sites, unless a site provides you with permission to write to it.)
