## Getting Add-ons

To extend Firefox to handle content what is delivered by Fedora or RHEL, start from the Mozilla.org Firefox product page (http://www.mozilla.com/en-US/firefox/). From there, follow links to Firefox Add-ons. Here are some of the most popular add-ons to Firefox that are available from Mozilla.org:

> NOTE: Some Add-ons have been known to cause performance problems with Firefox, primarily from using excessive amounts of memory. If you are having poor performance with Firefox, close all Firefox windows, restart Firefox in safe mode from a Terminal window by typing the following:

`firefox -safe-mode`

Refer to httpkb.mozillazine.org/Safe_Mode for further information on using and debug firefox problems.

- **Downloading tool (FlashGot)** — If you want to download groups of files from your Web browser, FlashGot can be a very useful tool. With FlashGot installed, you can select to download an individual file, files identified by highlighting links on a Web page, or all files linked from the current Web page. There is also a Gallery feature that lets you identify a range of filenames to download at once. When FlashGot is installed, you can access it from Firefox by selecting Tools → FlashGot, and then choosing a feature from the menu. In Fedora, Flash passes requests to Kget complete the download. You can get other download tools to instead of kGet, such as wget.

- *Selectively block ads (Adblock)* — Using Adblock, you can selectively prevent ads from being displayed on the Web pages. With Adblock installed, Adblock appears on the lower-right corner of Firefox. Click that to see a window containing items on the current page you want to block. Right-click on an image and select Adblock Image to choose that image to block. Use an asterisk to block all content from a particular site (for example, www.example.com/). Open the Adblock preferences from Firefox → Adblock → Preferences to see, edit, or remove blocked sites. With Firefox 1.5 or later, you should use Adblock instead of Adblock.
- *Access FTP servers (FireFTP)* — Contains a client application that runs in Firefox for accessing with FTP servers. There is also a FireFTP button add-on for accessing from the toolbar.
- *Block animations (Flashblock)* — Prevent animations from playing in your Firefox browser window. Can be particularly useful for dial-up users who don't want a performance hit when a visited site tries to play unrequested Flash content.

- *Improve browsing (Tabrowser Preferences)* — Although Firefox already gives you some features for tabs to keep multiple Web pages open in the Firefox window, Tabrowser Preferences takes these features a step further. Select Edit tabs work in Firefox. You can set motion selects tabs (such as mouse-over as opposed to clicking), put tabs on the bottom of the top, or choose whether or not to load the page in a new tab.

- *Watch your weather (ForecastFox)* — With ForecastFox, the latest weather for your region can be just a click away in Firefox. After you install ForecastFox and restart Firefox, a pop-up window enables you to configure ForecastFox options. Select at least Code, choose the area where you want to keep on weather. Save your options and a weather icon in the lower-right corner of Firefox. Move your mouse over icon to see a quick view of the current weather. Double-click the icon to have a more detailed weather report displayed from http://www.weather.com.

After you have installed an add-on, you need to restart Firefox for it to take effect. In some cases, a add-on will also require you to restart Firefox.

If you want to uninstall an add-on, change an add-on's options, or get more adds-ons, select Tools → Add-ons from Firefox. The window that appears shows you a list of installed add-ons and lets you change them. Select Browse All Addons to go directly to the Mozilla Firefox Add-ons page.

## Securing Firefox

Security has one of the strongest reasons for people switching to Firefox. By prohibiting the most unsafe types of content from playing in Firefox, and by warning you of potentially dangerous or annoying content before displaying it, Firefox becomes the browser of choice for many security-conscious people. Here are some ways that Firefox makes your browsing secure:

- **ActiveX**: Because of security flaws found in ActiveX, Firefox will not play ActiveX content. If you must be able to play ActiveX content, a plug-in is in development to provide controlled support for ActiveX. Follow the progress of the project at the ActiveX project home (http://www.iol.ie/addons/mozilla.htm). I don't recommend doing this, but it's up to you.
- **Pop-ups**: Pop-ups are disabled by default in Firefox. You can set preferences to enable all pop-ups or to enable only pop-ups from selected sites.
- **Privacy preferences**: From the window in Firefox (select Edit -> Preferences, and then click the Privacy button), you can clear different categories of stored information from your browser in a single click. This is a particularly good feature if you have just used a computer that is not yours to browse the Web. You can select to clear your History, information saved in forms you might have filled in, passwords saved by the browser, history of what you have downloaded, cookies, and cached files.
- In Firefox, you can install and manage certificates that can be used for validating a Web site and safely performing encryption of communications to that site.
