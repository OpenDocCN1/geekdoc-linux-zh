# Adding administrative users

To administer MySQL, you need to have at least one administrative account. By default, the root user has full access to your MySQL server database and no password assigned. You can assign a password to the root user using the mysqladmin command, once the mysql server is running. To add the root user as a MySQL administrator, log in as the root and type the following from a Terminal window (substituting your own password in place of myownpassword):

```
# mysqladmin -u root password myownpassword
```

After this command is run, the MySQL root user can run any MySQL administrative commands using the password.

MySQL maintains a list of users and passwords that is separate from the list maintained by Fedora. If you do not provide a user on the command line (in -u root shown above), MySQL assumes you use your current Fedora username to log in. However, you will still need to provide the MySQL password (not the Fedora password) for that user to use the MySQL service.

If you want to add MySQL administration, simply add the -u root argument to the command line of the MySQL command you are running. The Linux root user account has no connection to the MySQL root user account after the MySQL account is created. You would typically use different passwords for the two accounts.

> TIP: To save yourself the trouble of typing the password each time you run a MySQL client command, you can add a password option under the [client] group in one of the option files. The most secure way to do that is to create a .my.cnf file in the root user's home directory that can only be accessed by root (chmod 600 /root/.my.cnf) and contains the following lines (substituting your password for the last argument shown):
[client]
password=myownpassword

# Setting MySQL options

You can set options how the MySQL applications behave by using option files or command-line arguments. The MySQL server (as well as other administrative tools) reads the following files when it starts up (if they exist):

+   - /etc/my.cnf Contains global options read by mysql (server daemon) and mysql.server (script to start the server daemon).
- --defaults-extra-file — You can identify a file on the command line that contains options to be used by the server. For example, the following command would cause the file /home/jim/my.cnf to be read for options after the global options before the user-specific options:

```
# mysql --defaults-extra-file=/home/jim/my.cnf
```
