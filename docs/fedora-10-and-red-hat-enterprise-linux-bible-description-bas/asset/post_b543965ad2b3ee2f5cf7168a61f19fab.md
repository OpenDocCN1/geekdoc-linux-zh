To find out DRI is working on your current video card, you can use the glxinfo command (available from the glx-utils package). Type the following:

```
$ glxinfo | grep rendering
directing: Yes
```

This example shows that direct rendering is supported. If it were not supported, the output would say No instead of Yes DRI. Even if unsupported, you may experience the best game with a high-end card from NVIDIA, in particular, and ATI to a lesser extent. While DRI support can be important, many games support OpenGL rendering, a feature supported by both NVIDIA and ATI video cards. Both companies have specific driver requirements, so make sure re the cards, driver requirements, and any game-specific issue before you blow money on a top-tier 3D video card.

## Running Open Source Games

A lot of diverting source games come with Fedora and RHEL and in X. The GNOME and KDE environments although Fedora include a set of games that are installed by default with those desktops. Beyond that, many games can be installed from the Fedora repository.

Much of the recent increase in Fedora games has come from the Fedora Games SIG (Special Interest Group). You can check out SIG's activities for information on other games of interest that have not made it to Fedora if you know of a popular game that runs in Linux that is not currently available in Fedora, chances there have been discussions among the Fedora Games SIG of the pros and cons including it.

```
http://fedoraproject.org/wiki/SIGs/Games
```

Discussions on the fedora-games-mailing list provide insights into why some games are difficult to package for Fedora and why some games cannot get into Fedora because they don't meet the licensing requirements. Discussion relating to whether or not to include Doom first-person shooter game in Fedora, for example, was an interesting example of how licensing issues are addressed. Although the Doom license prevents people from modifying, disassembling, or reverse engineering the software. For that reason, the Fedora project decided to include the prbboom open source Doom clone and the freedom data files.

An on-going activity of the Fedora Gaming SIG is a Fedora LiveCD/LiveDVD. Check out the games slated for live media on the Games LiveCD/LiveDVD page (http://fedoraproject.org/wiki/SIGs/Games/GamesLive).
