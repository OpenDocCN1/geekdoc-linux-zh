Acrobat Reader has a lot of features. For example, you can display a list of bookmarks alongside the document and click on a bookmark to take you to a particular page. You can also display thumbnails of the pages to quickly scroll through and select a page.

Using the menu or buttons, you can page through the PDF document, zoom in and out, to go to the beginning or end of the document, and display different views of the document (as well as display bookmarks and page thumbnails). To print a copy, select File -> Print.

# Doing Page Layout with Scribus

For brochures, magazines, newsletters, catalogs and other materials that need sophisticated layouts you can do with a word processor, the most popular open source page layout application is called Scribus (http://www.scribus.net).

Although Scribus is intended to produce print publications, you can also use Scribus to produce what are referred to as intelligent PDFs. With PDFs you create with Scribus, you can include JavaScript and other features to let other interact with your text (such as filling forms). Scribus is similar to the Publisher application available with Windows.

To use in Fedora, install the Scribus package. The package comes with templates and samples you can use to start your projects (usually in /usr/share/scribus/).

With the Scribus package installed, you can start Scribus from the GNOME desktop by selecting Applications Office -> Scribus. Figure 6-8 shows an example of a brochure layout in Scribus.

After Scribus is running on your desktop, you can start by selecting a template (select File -> New from Template). Choose a brochure, newsletter, presentation, or text-based layout to begin. Here are some steps you can take on the sample layout to get used by using Scribus:

+   **Edit text**—Right-click in a text box and select Edit Text. In the Editor window that appears, change the text, point size, scaling/height of the text, font, text alignment, color, and other attributes. Select File -> Update Text Frame and Exit to save changes.

+   **Add images**—Right-click an image and select Image. Browse your folders for the image you want. If the image doesn't fit, right-click the image and select Edit Image to open the image in the GIMP to either resize or modify it. Right-click the image and Adjust Frame to resize it to fit your image.

+   **Change existing frames**—Right-click in any frame, then click Is Locked so the text box disappears. Once it is unlocked, you can do a lot to change it. Grab a corner or side of the frame to resize it. Right-click it and select Sample Text (to fill it with text), or Cut, Copy, or Delete it. Grab the frame with your mouse to drag and drop it somewhere. If you are done the frame, select Is Locked to lock the frame in place again.
