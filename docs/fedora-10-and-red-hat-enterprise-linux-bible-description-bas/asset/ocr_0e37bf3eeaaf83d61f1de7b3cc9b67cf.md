# # Appendix A

# # About the Media

If you have a CD-ROM or DVD drive on a standard PC (32-bit i386 architecture), you can install Fedora Linux from the media that come with this book. These media include:

+   - **Fedora 10 Install DVD**— This is the official Fedora 10 Install DVD. It represents the combination of what was called Fedora Core and Fedora Extras in versions of Fedora prior to 7.
- **Fedora 10 KDE Live/Install desktop CD**—This is an official CD from the Fedora project. It boots to a KDE desktop with a nice variety of applications, regardless of what is installed on your computer's hard drive. You can install the contents of this CD to hard by starting the installer icon from the live CD's desktop. Once the software is installed, you can install any other software you need from online repositories.

If you have a drive that supports both DVDs and CDs, use the DVD to install repositories to give you greater options for selecting software and does not require access to online repositories to go beyond a basic system setup. For the average desktop user, the CD will work well as a starting point for a usable Fedora desktop system.

> NOTE: The CD and DVD included with this book are 32-bit PC architectures. They will not work on other computer architectures. You can download images of Fedora live and installation CDs and DVDs for x 64-bit (x86, x64), PowerPC (ppc) or PowerPC 64-bit (ppc64) architectures from the Fedora webpage http://fedaproject.org/get-fedora.html.

To install Fedora 10 from the CD or follow the instructions in Chapter 2 and the README file on the DVD or CD.

If some reason you don't have your DVD handy, you can find information on how to download live and install CDs and DVDs from the Project Web site at http://fedaproject.org. If you have a DVD drive on another computer on your LAN, see Chapter 2 for information on setting up a Fedora installer, so you can install Fedora on your chosen machine over your LAN.

Repositories such as http://rpm.livna.org can help you find extra, useful software packages that are not in Fedora (or any other Red Hat distribution). Some of these act as yum or apt repositories that allow you to download sets of dependent packages the descriptions of yum and useful third-party Fedora software repositories in Chapter 5.
