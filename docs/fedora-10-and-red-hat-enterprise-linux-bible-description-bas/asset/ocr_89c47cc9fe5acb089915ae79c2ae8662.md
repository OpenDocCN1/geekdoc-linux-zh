# Part III: Administering Fedora RHEL

+   **Full Name** — The user's full name (usually first name, middle initial, and last name). This name is typically used for display, so using upper- and lowercase is fine.

+   **Password** — The user's initial password. (Ask the user to change this password the first time he logs in to the new account, which the user can do by running the `passwd` command.)

+   **Confirm Password** — Type the password again, to make sure you entered it correctly.

+   **Login Shell** — The default shell (for entering typed commands) that the user sees when logging in to Fedora or RHEL, from a character display.

+   **Create home directory** — By default, this box is selected and the user's home directory (as indicated by the Home Directory field) is created automatically.

+   **Create a private group for the user** — Check this box if you want to create a group by the same name as the user, created for this user. The name is added to the /etc/group file. This is referred to as user private groups (UPGs).

+   **Specify user ID** — Typically, you would not check this box, so the UID for the new user would be assigned automatically. New UIDs for regular users start at 500. However, if you want to assign a particular UID for a user (for example, if you want to match the UID with the user's UID from another computer on your network), select this box and type the number you want to use in the UID box.

+   **Specify group ID** — As with the user ID, you would typically have the group ID assigned automatically. However, you can assign a different GID to have the user assigned to a particular group.

Click OK when you are done. The user is added to the /etc/passwd and /etc/group files. The user account is now available for that to log in.

> TIP: Using private groups (UPGs) can be a benefit for sharing a directory of files among several users. Here's an example:

```
# useradd -m projectx
# mkdir /usr/local/x
# chown root.projectx /usr/local/x
# chmod 2775 /usr/local/x
# ls -ld /usr/local/x
drwxrxr-x 2 root projectx 4096 Aug 18 01:54 /usr/local/x
# gpasswd -a nextuser projectx
```
