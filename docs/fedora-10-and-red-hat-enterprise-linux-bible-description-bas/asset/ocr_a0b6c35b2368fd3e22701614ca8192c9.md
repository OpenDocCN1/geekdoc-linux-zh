> TIP: The window shade feature, where double-click in the title bar rolls up the window instead of maximizing or restoring it, is not on default. To turn on that feature from the Desktop menu, click System → Look and Feel → Windows. From the pop-up window that appears, change Maximize to Roll Up (Under double-click Title Bar to Perform this Action).

+   - Close — Click the X (upper-right corner of the title bar) to close the window.

# Step 2: Change some preferences

More than 20 preference categories are available from the GNOME desktop. Select the System menu, and then choose Preferences. From submenus on the Preferences menu, there are few preferences you might want to modify when you start out (see the GNOME and KDE preferences list in this chapter for further details):

+   - Change background — Select Look and Feel → Appearance, and select the Background tab. The Appearance Preferences window, as shown in Figure 3-3. To change the background image, select one of the Desktop Wallpaper images. To add your own image, click the Add button (to choose a file from your disk) or drag and drop image onto the Location box. Select a Style, such as Centered, Full Screen, Tiled, Zoomed or Scale. To use a color, select the blank wallpaper in the upper-left corner of the Wallpaper box and a color under the Colors selector. You can choose a solid color or a vertical or horizontal gradient

The default background for Fedora 10 is actually an animated background. The background consists of a series of images and a specially formatted XML file that indicates when and how the images are changed. See /usr/share/backgrounds/solar.xml. Read the comments in that XML file to see how the background images change to reflect different times of day.
