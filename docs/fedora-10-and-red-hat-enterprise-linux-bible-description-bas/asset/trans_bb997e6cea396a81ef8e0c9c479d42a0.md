接下来，选择身份验证框输入用户名和密码，如果访问访问共享打印机时需要这些信息：

- 用户名 — SMB 服务器需要用户名以便您访问 SMB 打印机。如果您是基于共享级别而非用户级别的访问控制对打印机进行验证，则不需要用户名。在共享级别访问下，您可以为每个共享打印机或文件系统添加密码。
- 密码 — 与 SMB 用户名或共享资源相关的密码，取决于所使用的访问控制类型。点击“验证”按钮检查用户名和密码是否正确。

> 注意：当您输入 SMB 的用户名和密码时，这些信息将以未加密的形式存储在 `/etc/cups/printers.conf` 文件中。请确保该文件保持 root 的只读权限。

点击“下一步”并完成配置，您应该能够使用标准的 `lpr` 命令将文件打印到打印机。在本示例中，您可以使用以下命令进行打印：

```
$ cat file.ps | lpr -P hp210m
```

> 提示：如果您收到失败消息，请确保打印目标计算机是可以访问的。对于之前的示例，您可以使用 `smclient -L NS1 -JJones`。输入密码（在此情况下为 `my9password`）。如果在输入密码后获得有效的名称查询响应，您将看到该服务器的共享打印机和文件列表。检查名称并重试。

## 添加 JetDirect 打印机

JetDirect 打印机（AppSocket/HP JetDirect）通过 JetDirect 设备直接连接到您的以太网打印机。您通常使用端口 9100 打印到 JetDirect 打印机，742 第四部分：Fedora 和 RHEL 网络与服务器设置，尽管其他接口使用端口 9101、9102 等。要从 Fedora 或 RHEL 使用 JetDirect 打印机，请输入以下信息：

- 输入 JetDirect 打印机的名称。
- 输入端口号（通常为 9100）以识别指向 JetDirect 打印机的接口。

## 使用基于 Web 的 CUPS 管理

打印机配置窗口有效地隐藏了底层的 CUPSset。有时您可能希望使用随 CUPS 附带的工具和配置文件。以下章节介绍了如何使用特殊的 CUPS 特性。

> 注意：明文配置文件是 CUPS 打印设施的基础。当不同的工具（如 CUPS Web 界面和打印机配置窗口）操作同一个配置文件时，这些文件将无法被其他工具使用。可能，您应该使用 `system-config-printer`（打印机配置窗口）在 Fedora 和 RHEL 中处理打印机。如果您开始使用 CUPS 界面，将看到此类提示的警告。

虽然在 Fedora 或 RHEL 中配置 CUPS 打印的首选方法是使用打印机配置窗口，但 CUPS 也提供了自己的基于 Web 的管理工具。

如果 CUPS 已经在计算机上运行，您可以立即通过浏览器使用基于 Web 的 CUPS 管理。如果 CUPS 尚未运行，请参考描述 `cupsd` 守护进程的后续章节获取启动它的信息。

CUPS 监听端口 631，以提供对 CUPS Web 管理界面的访问。在本地计算机上，在浏览器的地址栏中输入以下内容：

```
http://localhost:631/admin
```

将如图 17-4 所示的屏幕。

默认情况下，基于 Web 的 CUPS 管理仅从 localhost 可。要从另一台计算机访问 Web 的 CUPS 管理，您必须更改 `/etc/cups/cupsd.conf` 文件中的 `/admin` 部分。正如该文件内容建议的，您应该限制从 Web 对 CUPS 管理的访问。还要记住，密码是以明文传输的，因此嗅探网络的人可能会看到您的密码。如果您想在网络上进行 CUPS 管理，请考虑通过 ssh 隧道访问此服务。
