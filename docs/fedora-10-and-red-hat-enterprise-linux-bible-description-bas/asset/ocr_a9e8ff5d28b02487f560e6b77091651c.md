# 48 Part I: Getting Started in Fedora and RHEL

+   - Configure your boot loader to tell your computer's master boot record about those installation files.

This document presumes that there is already a Fedora or Red Hat Enterprise Linux system running on the computer (so you are doing an upgrade or a fresh install of Fedora). It also presumes that you can find a way to get these files onto the hard disk (I will describe how to do that from a DVD or CD that can be mounted even if it can't be booted).

> NOTE: See the section later in this chapter on setting up servers because presumably you need the contents of the Fedora installation DVD accessible from somewhere other than the DVD itself.

+   1. Insert the Fedora DVD into the DVD drive Fedora or Red Hat Enterprise Linux is running.

If the DVD isn't automatically mounted, as root user use the following to mount it:

```
# mount /media/disk
```

Note that the mount point for the DVD may be in a different location. Another option if the DVD isn't mounted is to create a mount point and mount the DVD there. For example, you could mkdir /mnt/dvd ; /dev/dvd /mnt/dvd.

```
# cd /media/disk/isolinux
# cp initrd.img /boot/initrd-boot.img
# cp vmlinuz /boot/vmlinuz-boot
```

> NOTE: If you are not able to mount a DVD or CD on the machine, you could copy the files from another machine on the network using scp. Or you could download those files to your /boot directory from a Fedora FTP site that contains the Fedora distribution.

+   3. Change your /boot/grub/grub.conf file to include an entry for the vmlinux and initrd files you just added to your boot directory. For example:

```
title Fedora 10 installation
root (hd0,0)
kernel /vmlinuz-boot
initrd /initrd-boot.img
```

This example assumes your /boot partition exists on the first partition of your IDE hard drive (hd0, 0) which is /dev/sda1). You can type df to see where your /boot partition is located.

+   4. Reboot your computer.

+   5. When the boot countdown message appears, press the down key to move to the entry titled "Fedora 10 installation" screen. From there, press the down arrow and press Enter. Here you will be able to start installation normally.
