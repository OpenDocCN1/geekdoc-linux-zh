# Part II: Using Fedora and RHEL

> TIP: With some tar.gz files that include an RPM spec file, you could run the rpm -ta file.gz and the rpm command will build an RPM from that tarball.

To try this procedure, I downloaded the package, which includes utilities that you can find manual pages by entering keywords. The file I downloaded, whichman-2.2.tar.gz, was placed in a directory I created /usr/src/which. I then ran the gunzip and tar commands, whichman-2.2.tar.gz and whichman-2.2.tar as arguments, respectively.

I changed to the new directory, /usr/sw/which/whichman-2.2. I listed its contents. The README file contained information about the contents of the package and how to install it. As the README file suggested, I typed make, and then make install. The commands whichman, ftwich, and fft were installed in /usr/bin. At this point, you can check the man page for each component to see what it does.

The last thing I found in the README file was a bit of configuration needed to be done. I added a MANPATH variable to $HOME/.bashrc to identify the location of man pages on my computer to be searched by the whichman utility. The line I looked like this:

```
export
MANPATH=/usr/share/man:/usr/man/man:/usr/X11R/man:/usr/share/doc/samba-2.2.3/docs
```

If you are wondering, whichman, ftwich, and fft are commands that you can use to search for man pages. They can be used to find several locations of a man page, man pages that are close to the name you enter, or man pages that are located beneath a point in the directory structure, respectively.
