
# Checking system space

Running out of disk space on your computer is not a happy situation. Using tools that come with Fedora and RHEL, you can keep track of how much disk space has been used on your computer, and you can keep an eye on users who consume a lot of disk space.

## Checking Disk Space with Disk Usage Analyzer

The Disk Usage Analyzer, which is part of the gnome-utils package, provides an easy way to see how and where space is being consumed on your hard disk. To start Disk Usage Analyzer from the GNOME desktop, select System Tools -> Disk Usage Analyzer.

At first, Disk Usage Analyzer displays only the size of the hard disk and amount of space that has been consumed on that disk. However, you can see how much disk space is consumed by files in a particular folder (and its subfolders) by selecting the Folder button and browsing for the folder that insert. Figure 10-5 shows an example of a music folder containing several folders of music. You can sort each sub alphabetically or by disk space consumed.

## Displaying system space with df

You can display the space available on all of the mounted file systems using the df command. To see the amount of space available on all of the mounted file systems on your Linux computer, df with no options:

| Filesystem | 1k-blocks | Used | Available | Use% | Mounted on |
|---|---|---|---|---|--|
| /dev/sda3 | 30645460 | 2958356 | 26130408 | 11% | / |
| /dev/sda2 | 46668 | 8340 | 35919 | 19% | /boot |
| /dev/fd0 | 1412 | 13 | 1327 | 1% | /mnt/floppy |

The output here shows the space available on the hard disk partition mounted on the root partition (/dev/sda), boot partition (/dev/sda2), and the floppy disk mounted on the /mnt/floppy directory (/dev/fd0). Disk space is shown in 1K blocks. To output in a more human-readable format, use the -h option as follows:

```
$ df -h
Filesystem      Size Used Avail% Mounted on
/dev/sda       29G  2.9G  24G 11% /
/dev/sda2      46M  8.3M  35M 19% /boot
/dev/fd0       1.4M  13k  1.2M 1% /mnt/floppy
```

With the -h option, output appears in friendly megabytes or gigabytes with options:

- Print only files of a particular type (-t)
- Exclude file systems of a particular type (-x)
- Include file systems that have no space, such as /proc (-a)
- List all available and used blocks (-i)
- Display disk space in certain sizes (--size)

## Checking disk usage with du

To find out how much space is being consumed by a particular directory (and its subdirectories), you can use the du command. With no options, du lists all directories below the current directory along with the space consumed by each. At the end, du produces total disk space within that directory.

The du command is a good way to check how much space is being used by a particular user (/home/user) or in a particular file system (/var). By default, disk space is displayed in 1K blocks. To make the output friendly (in kilobytes, megabytes, and gigabytes), use the -h option as follows:

```
$ du -h /home/james
114k /home/james/httpd
234k /home/james/data
137k /home/james
701k
1.0M /home/james
```

The output shows the disk space used in each directory under the user named james (/home/james). Disk space is shown in kilobytes (k) and megabytes (M). The total consumed by /home/james is shown on the last line. To avoid listing all subdirectories and see a total for all files and directories below a certain directory, add the -s option as follows:

```
$ du -sh /home/james
1.0M /home/james
```

## Finding disk consumption with find

The find command is a great way to find disk consumption of your hard disk using a variety of criteria. You can get a good idea of where space can be recovered by finding files that are over a certain size or created by a particular person.

NOTE: You must be root user to run this command effectively unless you are just checking your personal files.

In the following example, the find command searches the root system (/) for any files owned by the user jane (-user) and prints the filenames. The output of the find command is then listed with a long listing in size order (ls -l). Finally, output is sent to the file /tmp/jane. When you read the file /tmp/jane, you will find all the files owned by jane, listed in size order. Here is the command:

```
find / -user jane -print | xargs ls -l > /tmp/jane
```

TIP: The -x option prevents file systems other than the selected from being searched. This is a good way to cut out lines that may come from the /proc file system. It could also keep remotely mounted file systems from being searched.

The next example is similar to the previous one, except instead of looking for users, this command looks for files that are larger than 1000 kilobytes (-size +1000k):

```
find / -x -size +1000k -print | xargs ls -l > /tmp/size
```

You can save yourself a lot of disk space by removing some of the largest files that are no longer needed. Open the /tmp/size file in this example where files are sorted by size.

## Monitoring System Performance

If your Linux is used as a multiuser, sharing the processing power of that computer can be a major issue. Likewise, anytime you stop a runaway process or reduce the overhead of an unnecessary program running, your Linux server can do a better job serving web pages or email to the people they rely on.

Utilities are included with Linux that can help you monitor the performance of your Linux system. The kinds of systems you want to monitor in Linux include CPU usage, memory usage (RAM and swap space), and overall load on the system. The following sections describe tools for monitoring Linux.

## Watch computer usage with System Monitor

If you like visual representations of how your system being used, the System Monitor provides a great way to see how your system is being used. To open the System Monitor from the Applications menu on the GNOME panel, select System Tools -> System Monitor. Figure 10-6 shows the System Monitor window with the Resources tab selected.

![](img/63c86e1d25a0e2be7e9f6de6b6f02530_496_0.png)

Figure 10-6: System Monitor graphically displays your system's CPU and memory usage.

On the Resource Monitor window, lines scroll from right to left, indicating the percentage of your CPU being used as it rises and falls. You can also see how much of your total memory (RAM) is being used at the moment (and over time), as well as the amount of swap space being used. The bar at the bottom of the window shows the amount of data being sent and received over your computer network interfaces.

Click the Processes tab to see a listing of processes that are running for the current user. Click the columns in that tab to sort processes by name, memory use, percentage of CPU being consumed by the process, and process ID. There are also columns showing the security context of the process (if SELinux is enabled) and the arguments associated with the process.

Click the Files tab to see the storage devices (hard disks, CD, USB flash drive, or other) that are currently mounted on your computer. Click columns to sort the devices by device name, name, file system, disk size, free space, or used disk space.
