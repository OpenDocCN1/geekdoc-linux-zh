# Beginning the installation

If you feel you have prepared to install Fedora, you can begin the installation
procedure. Throughout most of the procedure, you can click Back to make changes to earlier
screens. once you go forward after being warned that packages are about to be
written to disk, there's no turning back. Most items that you configure can be changed
after Fedora is installed.

> CAUTION: If your computer contains any data that you want to keep, be sure to back it up. If
yave multiple partitions, and don't expect to over the partitions, a backup is a good
precaution in case something go wrong.

+   1. **Insert the DVD or CD.** This procedure ensures you are booting and installing from
either DVD or CD that comes with this. (If you are not able to boot from any of
of media, refer to the "Alternatives for starting installation" section. If you are booting
from DVD or CD, but installing the software packages from a network or
hard disk, refer to the "Installing from Other Media" section.)

The DVD can be used for any type of install; the CD with this can only be used to
copy the Fedora 10 desktop system on the CD to hard disk.

+   2. **Start your computer.** If you see the Fedora boot screen, continue to the next step.

> TIP: If you don't see the boot screen, your DVD or CD-ROM drive may not be booting. Creating a
bootable floppy is no longer an option because the 2.6 kernel doesn't fit on a floppy. You may
have the choice of making your DVD or CD-ROM drive boot or copying a boot image to a boot USB
device (such as a pen drive). Restart the computer. Immediately, you will see a message
telling you how to go into, such as by pressing the F1, F2, or Del key. Enter setup and look for an
option such as "Options" or "Boot from." If the value is "A: First, C" change it to "CD-ROM First,
C" or similar. Save the changes and try to install again.

If installation succeeds, you may need to restore the boot settings. If your DVD or CD drive still won't boot,
y you need to use an alternative method to boot Fedora installation (described in "Alternatives for
stalling" in this chapter).

+   3. **Start the boot procedure.** At the boot screen do one of the following, depending on
whether you are installing from the DVD or CD:

+   * **Fedora 10 Install DVD** — With "Install or upgrade" highlighted on the boot menu,
press Enter to begin the installation.

+   * **Fedora 10 Desktop Live CD** — Either wait for the boot screen to time out or
Boot highlighted on the boot menu, press Enter to start the live CD. When the CD
boots up to a KDE desktop, double-click the Install to Hard Drive icon to begin the
installation.
