This output shows the PPP connection on /dev/modem. After verifying that the modem is working, the chat script sends the telephone number. The connection is made, and the PPP interface is started. After some parameter negotiations, the server assigns IP addresses to both sides of the communication, and the connection is ready to use.

If you get connected, but none of your applications (Web browser, FTP, and so on) seem to work, check that your PPP interface is noted as the default route (/sbin/route -n). If it is, check that you have the DNS servers specified correctly in /etc/resolv.conf file. Use the `ping` command on those DNS servers IP addresses to make sure you can get through.

# Connecting Your LAN to the Internet

Users on your LAN are happy that you made it so that they can share files and printers with each other. With your users already connected on a LAN, the next logical step is to set up a connection to the Internet that everyone can share. The advantages of this are:

+   - Save on modems — Instead of each computer having its own modem, you can have one high-speed device (such as a DSL router or cable modem) that routes all traffic to the Internet.
