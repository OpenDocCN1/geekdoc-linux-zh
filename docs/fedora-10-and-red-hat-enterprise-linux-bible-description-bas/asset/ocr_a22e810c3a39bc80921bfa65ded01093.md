8. Configure TCP/IP. For any of the network install types (NFS, FTP, HTTP), you are prompted to configure TCP/IP for your computer. (See the section on configuring networking earlier in this chapter for information on how to add these fields.)

9. Identify the location of the Fedora distribution. You must identify the NFS server, FTP site, or Web site that contains the Fedora directory that holds the distribution. Or, if you are installing from hard disk, you must identify the partition containing the distribution and the directory actually contains the Fedora distribution.

> NOTE: For an FTP install, if you are not downloading from a public FTP site that allows anonymous login, you must select the "Use non-anonymous FTP" check box when you identify the server and directory. You will need a user name and password to access the shared directory.

10. Continue with installation. If the distribution is found in the location you indicated, continue the installation as described in the previous section.

The next section describes how to set up your server for installing Fedora.

# Setting up HTTP, FTP, or NFS install server

If you have a LAN connection from your computer to a computer that has at least 2.5GB of disk space and offers NFS, FTP, or Web services, you can install Fedora from that server. Likewise, you can install from a spare partition by using a hard disk install. The following procedures let you to set a Linux install server by copying all files from the DVD or by copying images of the DVD.

# Configuring an install server using files

If you do an FTP or HTTP install, you must copy the files from the installation DVD to a directory that you make available to the network. For example, you can do the following:

```
# mkdir /tmp/rh
# mount /media/disk
# cp -r /media/disk/* /tmp/rh/
# umount /media/disk; eject /media/disk
With DVD inserted
```

In this example, all files were copied. Setting up an NFS install server or hard disk requires copying the DVD image to the shared NFS directory.

# Configuring an install server using disk images

Instead of copying files from the installation DVD, you can copy the entire DVD image to your hard disk for NFS or hard disk installs. To install the DVD, do the following:

```
# mkdir /tmp/rh
# dd if=dev/cdrom of=/tmp/rh/diski.iso With DVD inserted
# umount /media/disk; eject /media/disk
```
