# 使用 GNOME 桌面

GNOME（读作 gob-name）提供了您在安装 Fedora 或 RHEL 时默认使用的桌面环境。该桌面环境提供了位于您的 X Window 系统与窗口管理器提供的视觉效果之间的软件。GNOME 是一个稳定且可靠的桌面环境，包含了一些功能。

GNOME 2.24 桌面随最新版本的 Fedora 发布。如果您使用过更早版本的 GNOME，以下是您在使用 GNOME 功能时会发现的一些新增内容：

- **摄像头照片和视频** — 使用新的 Cheese 应用程序（安装 `cheese` 软件包并选择“应用程序 -> 附件 -> Cheese”），您可以从网络摄像头拍摄单独的照片或视频。安装 `cheese` 软件包以使用 Cheese 应用程序。关于 Cheese 的描述请参阅第 8 章。
- **改进的 Nautilus 文件管理器** — Nautilus 文件管理器为访问本地和远程文件系统提供了新的协议和功能。使用 `cddaa://cdrom` 协议查看音频 CD 的轨道信息，或使用 `gphoto2://` 访问连接的数字相机。信息栏将显示，以便让某些应用程序处理文件管理器中显示的内容（例如音乐播放器或图像查看器）。
- **多个时间位置** — 使用 GNOME 钟允许您选择世界上的多个位置，这样当您打开日历时，您就能看到这些位置的当地时间和天气。
- **Google 日历** — 您可以将 Google 日历添加到您的 Evolution 日历中。
- **键盘偏好设置简化** — 键盘布局和辅助功能窗口的设置已合并到单一的“键盘偏好”对话框中。
- **辅助功能改进** — 几项辅助功能的改进让残障人士更容易使用 GNOME。Orca 读器包含了 Firefox 和 Web 应用程序的辅助功能。支持 2 级点盲字。

要使用您的 GNOME 桌面，请熟悉以下组件：

- **Metacity（窗口管理器）** — Fedora 和 RHEL 中 GNOME 的默认窗口管理器是 Metacity。窗口管理器提供了主题、窗口、边界和控制等功能。如果您启用 3D 加速，将自动切换到 Compiz 管理器（如果您的硬件支持 AIGLX）。
- **Nautilus（文件管理器/图形外壳）** — 当您打开文件夹时（例如，通过双击桌面上的图标），Nautilus 会打开并显示所选文件夹的内容。Nautilus 还可以显示其他类型的内容。
- **GNOME 面板（任务栏）** — 信息栏将显示，以便让某些应用程序处理文件管理器中显示的内容（例如音乐播放器或图像查看器）。
- **GNOME 面板（任务栏）** — 信息栏将显示，以便让某些应用程序处理文件管理器中显示的内容（例如音乐播放器或图像查看器）。这些面板可以通过拖拽来切换应用程序。
- **桌面** — 桌面区域支持拖放操作。

除了上述的组件外，GNOME 还包含了通过“系统 -> 偏好设置”来更改桌面背景纸、颜色、字体等功能。

# 使用 Metacity 窗口管理器

Metacity 窗口管理器被选为默认管理器是因为其简单性。为 Metacity 命名以及更改颜色和装饰是通过其 GLX 扩展完成的（参见后文“运行 3D 桌面效果”）。

# 第一部分：在 Fedora 和 RHEL 中开始

您可能感兴趣的基础 Metacity 功能是快捷键和工作区切换器。表 3-1 显示了用于 Metacity 管理器的快捷键。

另一个您可能感兴趣的 Metacity 功能是工作区切换器。GNOME 面板上的工作区切换器显示四个虚拟工作区。工作区切换器有以下操作：

- **选择当前工作区** — 工作区切换器显示四个虚拟工作区。点击任何一个虚拟工作区即可将其变为当前工作区。
- **将窗口移动到其他工作区** — 点击工作区切换器中的任何窗口（由一个小矩形表示），将其拖放到另一个工作区。同样地，您可以从窗口列表拖动应用程序将其移动到另一个工作区。
- **添加更多工作区** — 右键点击工作区切换器并选择“偏好设置”。您可以添加工作区（最多 32 个）。
- **命名工作区** — 右键点击工作区切换器并选择“偏好设置”。点击“工作区”窗格将工作区更改为您选择的任何名称。
