# Chapter 17: Setting Up Printers and Printing 747

```
<DefaultPrinter hp2100>
Info HP LaserJet 2100M
Location HP LaserJet 2100M in hall closet
DeviceURI=/par/HP_LaserJet_2100_Series?device=/dev/parport0
State Idle
Accepting Yes
Shared Yes
JobSheets none none
QuotaPeriod 0
PageLimit 0
KLimit 0
OpPolicy default
ErrorPolicy stop-printer
</DefaultPrinter>
```

This is an example of a local printer that serves as the default printer for the local system. The most interesting information relates to the DeviceURI, which shows that the printer is connected to parallel port /dev/parport0. The State is Idle and the Accepting value is Yes (the printer is accepting jobs by default).

The DeviceURI has several ways to identify the name of a printer, reflecting how the printer is connected. Here are some examples in the printers.conf file:

```
DeviceURI parallel:/dev/lp0
DeviceURI serial:/dev/ttyUSB0?baud=38400+size=8+parity=none+flow=soft
DeviceURI scsi:/dev/scsi1
DeviceURI socket://hostname:port
DeviceURI tftp://hostname/path
DeviceURI http://hostname[port]/path
DeviceURI ipp://hostname/port
DeviceURI smb://hostname/printer
```

The first three examples show the form for local printers (parallel, serial, and scsi). The other examples are remote hosts. In each case, hostname is the host's name or IP address. Port numbers or paths identify the locations of each printer on the host.

> TIP: If you find that are not able to print because a particular printer driver is not supported in CUPS, you can set your printer to accept jobs in raw mode. This can work if you are printing from Windows clients that have the correct driver installed on those. To allow raw printing in CUPS, uncomment the following line from the /etc/cups/mime.types file in Linux:

```
application/octet-stream
```

And uncomment the following line from the /etc/cups/mime.types file:

```
application/octet-stream
```

After that, you can print files as raw to your printers without using the -raw option to print commands. As an alternative, you can just select the Raw Print Queue driver when first configure printing through the Printer configuration.
