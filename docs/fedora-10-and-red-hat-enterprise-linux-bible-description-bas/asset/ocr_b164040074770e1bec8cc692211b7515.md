# Configuring video cards for gaming

Some games and video players require special features to work properly (or all, in some cases). For games that require 3D hardware acceleration, including some that run under TransGaming's WineX, TransGaming recommends using NVIDIA GeForce cards.
Because only basic NVIDIA video drivers are included in Fedora (NVIDIA's own drivers are not open source), you need to get NVIDIA drivers to use those cards for gaming. You can get NVIDIA drivers from www.nvidia.com/object/linux.html or install them from rpm.livna Fedora repository.

> CAUTION: Some components of the video drivers from NVIDIA can conflict with those that come with Fedora or RHEL. See the section on choosing a video card for gaming in Chapter 7 for further information on getting and using NVIDIA drivers. Games that don't require 3D hardware acceleration should work fine with most video cards that are supported by the X.Org server drivers.

> TIP: To use DRI acceleration on Voodoo 3 cards, you must have your display set to use 16bpp resolution. On Voodoo 5 cards, only 16bpp and 24bpp resolutions are supported. Voodoo chipsets and other 3DFX technology is now owned by NVIDIA.

# Getting information

If you tried configuring X and you still have a server that crashes or has a garbled display, your video card may be unsupported or may require special configuration. Here are several locations you can check for further information:

+   **X.Org (http://www.x.org)** — The latest information about the X servers come with Fedora and RHEL is available from the X.Org web site. X.Org is the freeway version of X recently used by many Linux distributions to replace the XFree86 server.
**X documentation** — README files that are specific to different types of video cards are delivered with the X.Org X server. A lot of good information can also be found on the xorg.conf page (type man xorg.conf).
