## Adding a drawer

By adding a drawer to your GNOME panel, you can add several applets and launchers and have them take only one slot on your panel. You can use the drawer to show the applets and launchers as though they were being pulled out of a drawer icon on the panel.

To add a drawer to your panel, right-click the panel and select Add to Panel → Drawer. The drawer should appear on the panel. The drawer behaves just like a panel. Right-click the drawer area, and add applets or launchers to it as you would to a panel. Click the drawer icon to retract the drawer.

Figure 3-10 shows a portion of the panel that includes an open drawer. This example includes an icon for launching a Terminal window, a custom folder icon, a volume monitor, and the weather applet.

## Changing panel properties

Properties you can change that relate to a panel are limited to the orientation, size, hiding policy, and background. To open the Panel properties window that applies to a specific panel,

## Part I: Getting Started in Fedora and RHEL

right-click on an open space on the panel, and then choose Properties. The Panel Properties window includes the following values:

- Orientation — You can move the panel to different locations on the screen by clicking on a new position.
- Size — You can select the size of your panel by choosing its height in pixels (24 pixels by default).
- Expand — Click this check box to have the panel expand to fill the entire side or unselect the check box to make the panel only wide as the applets it contains.
- Autohide — You can select whether or not the panel is automatically hidden (appearing only when the mouse is in the area).
- Show hide buttons — You can choose whether or not the Hide/Unhide buttons (with pixmap arrows over them) appear on the edges of the panel.
- Arrows on hide buttons — If you select hide buttons you can select to either those on buttons or not.
- Background — From the Background, you can assign a color to background of the panel, assign a background image, a Style (using a slider to go Transparent to Opaque) or leave it as None (which causes the panel to get its background from the current system). Click the Background Image radio button if you want to select an image for the background, and then select an image, as a tile from /usr/share/backgrounds/tiles or other directory.

> TIP: usually turn on the AutoHide feature and turn off the Hide buttons. Using AutoHide gives you more space to work with your desktop. When you move your mouse to the edge where the panel is, it pops up — so you do not need Hide buttons.

## Using the Nautilus file manager

At one time, file managers did little more than to run applications, create data files, and open folders. These days, file managers are expected to offer different browsing choices, preview file content, select different applications to use and access files on other computers. The Nautilus file manager, which is the default GNOME file manager, is an example of just a file manager.

When you open the Nautilus file manager window (from a GNOME menu or by opening the Home icon or other folder on your desktop), you see the name of the location you are viewing (such as the folder) and what that location contains (files, folders, and applications).
