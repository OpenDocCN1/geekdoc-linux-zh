# Features

With its Red Hat Enterprise Linux (RHEL) commercial product line, Red Hat, Inc. is clearly positioning itself to go after customers looking to put Linux computing infrastructures in place. So, when you look at the differences between features in Fedora distributions and RHEL products, many features RHEL products are geared toward deploying multiple desktop and server systems within a large organization.

Despite the fact that Red Hat is aimed primarily at customers who want to build large-scale Linux infrastructures, there are ways of starting with RHEL that require a much smaller investment. Later in this appendix, I describe how to get an evaluation copy of RHEL to turn out that you can upgrade to an affordable subscription program.

The current major of Red Hat Enterprise Linux, RHEL 5, was released in March 2007 and is generally available. The latest point release is RHEL 5.2, released in May 2008. Information about RHEL and related products is available from the Red Hat Web site: http://www.redhat.com/rhel.

# ## What’s in RHEL 5?

Red Hat, Inc. released RHEL 5 in March, 2007, based on software that was changed. Since RHEL 4, RHEL software product names changed. Of Workstations, Desktops, Enterprise servers, and Application servers, there are two main categories: Servers and Clients.

+   - **RHEL 5 Servers** — Subsets of RHEL 5 server products include storage, cluster, and virtualization systems. The RHEL 5 Advanced Platform allows unlimited virtualization, GFS filesystem support, and improved clustering.
- **RHEL 5 Desktops** — For desktop systems, there are Workstation, Desktop, and virtualization systems.
