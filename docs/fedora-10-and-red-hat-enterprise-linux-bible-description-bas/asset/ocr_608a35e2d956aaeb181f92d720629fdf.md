# Chapter 3: Getting Started with the Desktop

+   - **Search Box** — Type a term into the search box (flash memory appears in this example) and press Enter. A pop-up lets you select for search at Amazon.com, Answers.com, Creative Commons, eBay, Google, or Yahoo.

+   - **Files** — See the files that you opened recently under the Files box. Select More to search or browse for local files.

+   - **Applications** — Your most-used applications appear in the Applications box, ready to start at any time. Select More to search for an application or see statistics about the applications you use most.

+   - **People** — The people you added to your Mughot account, with their names and icons, in the People box. Click on a photo or name to go to that person's Mughot page.

+   - **Calendar** — Connect to your online Google calendar from this box.

+   - **Mughot Home** — In the example, a web browser is open to your Mughot home page. From the Mughot home page, you can access the same services that are loaded on your Online Desktop, as well as configure all the features that are picked up by your Desktop.

+   - **Mughot Stacker** — Click the Mughot icon in the panel to see the Mughot stacker. That shows information about your activities, as well as activities of others you have added to your People list. In this example, can you joined a group, other another, and added a movie to my Netflix queue.

Because Online Desktop is still under development, expect to have many more features and services available by the time you read this. In particular, work is being done to integrate online applications, so you will be able to work with Web applications to use your documents, spreadsheets, and other important information.

# Switching Desktop Environments

If you want to try a different desktop environment, the Desktop Switch provides a graphical means of changing your environments to KDE, GNOME, Xfce and several window managers (including TWM) depending on what is installed. To open the Desktop Switch, type switchdesk from a Terminal window and select the new desktop you want to use.

From the Desktop Switch, select the desktop environment (GNOME, KDE, or XFree) or window manager (TWM) you want to use. You can have that apply to the current display (just the next time you restart X only) or make the change permanently. Click OK. Then the next time you log in, the new environment or window manager will take effect.

> NOTE: To use the Desktop window, you must have the switchdesk-gui package installed. Otherwise, you can use the switchdesk command, followed by the name of the Desktop you want to switch to, from a Terminal window to change your Desktop.
