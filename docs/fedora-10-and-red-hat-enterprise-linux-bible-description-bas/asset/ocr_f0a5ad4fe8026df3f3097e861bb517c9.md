# Creating self-signed certificates

Generating and running a self-signed SSL certificate is easier than having a signed
certificate. To generate a self-signed SSL certificate, do the following:

+   1. Remove the key and certificate that currently exist:

```
# rm /etc/pki/tls/certs/local.crt
```

+   2. Create your own server key:

```
# make genkey
```
