# Understanding video content types

Before launching into the video players themselves, I want to try to clear up bit of confusion relating to video files and formats:

- Video file formats — A video file essentially describes the structure of a video file for combining audio and video content. That structure can also define things as subtitles and how audio and video are synchronized. However, a variety of video and audio codecs may have been used to encode content. So, just because you can play a video file that is marked as MPEG (.mpg), Audio Video Interleaved (.avi), QuickTime (.mov), RealMedia (.rm), Windows media (.wmv), Advanced Streaming Format (.asf), or other file, doesn't mean you can play all video files marked as.

- Video and audio codecs — Codecs are used to encode and decode video and audio content. A video encoded entirely with free software might use Theta to encode the video and Ogg Vorbis to encode the audio. Popular video codecs include MPEG-4, DivX, Xvid, RealVideo, and MJPEG.

Not all video codecs and file formats are suitable for streaming video. For example, AVI and MPEG-2 are not streamable. However, RealMedia, MPEG-4, and ASF format can be streamed, which reduces the load on a server and means you do not have to download an entire video to start watching. Check the descriptions of video players in the following sections for information on which players can support codecs.

If you have a video player on your hard disk and you'd like to know what type of content it contains, you can use the **file command**. Here's an example of the file command for checking the contents of a movie trailer:

```
$ file movie.avi
movie.avi: RIFF (little-endian) data, AVI 640 x 272, 23.98 fps, video: DivX 3, audio: MPEG-1 Layer 3 (stereo, 44100 Hz)
```

This example shows that the file contains DivX 3 video and MPEG-1 Layer 3 audio. The size of the video is 640 x 272 pixels. Video was captured at 23.98 frames per second. This can lead you to the type of video you need to play. Given that the right codecs are installed, MPlayer, Xine, VLC, or several other players would be able to play this content.

# Converting Video to Theora

There are not a lot of tools yet for creating Theora. To get a video to try out, I shot a video with my Sony Handycam, which stores video in 30-minute, 1.4GB DVDs. I downloaded a tool, recommended from the Theora.org site, called ffmpegtheora (http://www.v2.cc/~j/ffmpegtheora). My video camera recorded my home movie as a VOB file, which I copied to my hard and converted to Theora/Ogg Vorbis as follows:

```
$ ffmpegtheora VTS_01_1.VOB
Input #0, mpeg, from 'VTS_01_1.VOB'
Duration: 00:00:00.6, start: 0.197311, bitrate: -2147483 kb/s
Stream #0.0: Video: ffmpeg2, 704x480, 29.97 fps, 9300 kb/s
Stream #0.1: Audio: ac3, 48000 Hz, stereo, 256 kb/s
Resize: 704x480 => 320x240
Resample: 48000Hz => 44100Hz
```

The original file was in mpeg-2 video (720 x 480 pixels) and ac3 audio (48,000 Hz). The **ffmpegtheora** command resized the video to 704 x 480 pixels and resampled the audio to 44,100 Hz. The result was a second file (filename with an .ogg extension) that was 82MB, compared to the original 1.1GB.

# Watching video with Xine

At the base of the Xine video player (http://xineh.de) is the xine-lib core engine. While Xine has its own xlib-based user interface, you can choose different video player front-ends to use with the core engine installed (including Fedora, Totem, Kaffine, and axamine). You can also use Xine as a Mozilla plugin-in, to have videos play in a browser window.

The Xine player is an excellent application for playing a variety of video and audio formats. You can get Xine from http://xinehd.de (which takes some work to get going) or by downloading RPMs from http://rpm.livna.org/fedora. (See Chapter 5 for information on using Livina and other software repositories for getting Fedora and RHEL software. Note that the Livina repository is migrating to the new RPMFusion.org site.) If Yum is configured to one of those repositories, you should be able to install Xine by typing `yum install xine`.

You can start the Xine player by typing xine& a Terminal window. Figure 8-12 shows an example of the Xine player window and controls.

Xine can understand different file formats representing streaming audio and video. These include .mpg (MPEG program streams), .ts (MPEG transport streams), .mpv (raw MPEG audio/video streams), .avi (AVI format), and .asf (Advanced streaming format). While Xine can play CDs and DVDs containing other content, it can't play encrypted DVDs video-on-CD hybrid format without adding other software (of the legal issues mentioned earlier related to decrypting DVDs).

# Using Xine

With started, right-click in the Xine window to see the controls. The quickest way to play video is to click one of the following buttons, and then press the Play button (right arrow or Play, depending on the skin you are using):

- VCD (looks for a video CD)
- DVD (looks for a DVD in /dev/dvd)
- CDA (looks for a music CD in /dev/cdaudio)
- DVB (looks for a DVB device supported by linux drivers)
