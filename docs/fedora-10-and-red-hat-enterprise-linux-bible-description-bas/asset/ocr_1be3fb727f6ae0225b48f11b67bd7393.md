+   **Popular folder or Web site** — Folders or Web sites you visit often should be easily accessible. Click Add to Drawer -> Custom Application Launcher and select Add. From the Create Launcher window, select Location or Application (as the Type) and type *nautilus folder* (where *folder* is replaced by the name of the folder you want to open). To add a launcher for that, I select Application from Launcher Properties (*nautilus* / /home/chris/ToysII). Then I assign an icon (an image of the book cover) to the launcher. # Tips for configuring your desktop

Now that you have experimented with a few items on the desktop, you should configure certain features to get Fedora and RHEL really working well for you. Most of the tips I describe here help you get Fedora and RHEL working on the network.

> NOTE: Some of the tips described here should be carried out by the system administrator. They apply to you if you are the system administrator for your organization, or if you are configuring your home or office network.
