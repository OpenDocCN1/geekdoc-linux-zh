# Configuring Amanda for Network Backups

Using Amanda (the Advanced Maryland Network Disk Archiver), you can use a single large-capacity tape drive on a server to back up files from multiple computers over the network. The Amanda packages (amanda, amanda-client, and amanda-server) include a variety of commands. The online manual for Amanda describes the commands as shown in Table 13-.

# Table 13-7: Backup Commands Used with Amanda

| Command | Description |
| --- | --- |
| amdump | Automatic Amanda backups. This command is normally run by cron on a computer called the tape server host requests backups of file systems located on backup clients, amdump backs up all disks in the disklist to tape or, if there is a problem, to a special holding disk. After all backups are done, amdump sends mail failures and successes. |
| amflush | Flush backups from the holding disk to tape. amflush is used after amdump has reported it no writes to tape. When this happens, backups stay in the holding disk. After the tape problem is corrected, run amflush to write backups from the holding disk to the tape. |
| amcleanup | Clean up after an interrupted amdump. This command is needed only if amdump was unable to complete for some reason, usually because the tape server crashed while amdump was running. |
| amrecover | Provide an interactive interface to browse the Amanda index files and select which tapes to recover from. amrecover can also run amrestore and the system program (such as tar) to restores. |
| amrestore | Read an Amanda tape, searching for requested backups. amrestore is suitable for everything from interactive restores of single files to a full restore of all partitions on a disk. |
| amlabel | Write an Amanda format label onto a tape. All Amanda tapes must be labeled with amlabel. amdump and amflush will not write to an unlabeled tape. |
| amcheck | Verify the correct tape is in the tape drive and that all file systems on all backup client systems are ready to be backed up. Optionally can be run by cron before amdump, so someone will get mail warning that backups will fail unless corrective action is taken. |
