# # How This Book Is Organized

The book is organized into four parts.

# ## Part I: Getting Started in Fedora and RHEL

Part 1 consists of Chapters 1 through 4. Chapters 1 and 2 contain brief descriptions of the Linux technology and tell you what you need to get the operating system installed. Chapter 1 serves as an introduction to the Linux operating system and to Fedora in particular. I also pay attention to the division Red Hat, Inc., makes between the Fedora Project and Red Hat Enterprise Linux. Chapter 2 discusses what you need to install Fedora and how to make the decisions you'll be faced during installation. It includes procedures for installing from DVD, CD-ROM, disk hard, or network connection (NFS, FTP, or HTTP servers).

In Chapter 3, you learn about the GNOME, KDE, and desktop environments, as well as the X Window system. These GUIs provide graphical means of using Fedora and RHEL. Chapter 4 describes ways of exploring and understanding Fedora and RHEL, primarily from the Linux command interpreter. You learn how to use the `bash` shell, the `vi` text editor, and the commands for moving around the Linux file system.

# ## Part II: Using Fedora and RHEL

Part 2 consists of Chapters 5 through 9, which includes information for the average user who wants to use Linux for applications and access the Internet.

Chapter 5 contains information on obtaining, installing, and running Linux applications. It also helps you run applications from other operating systems in Linux. Chapter 6 describes how old-time publishing tools and new, graphical word processors are available with Fedora and RHEL. Old tools include the treat and TeX processing tools, whereas publishing software includes OpenOffice.org utilities (included on the DVD) and StarOffice (commercially available).

GNOME and KDE chapters are described in Fedora and RHEL. Chapter 7 chapter also describes how to run commercial Windows games using Cedega, and commercial Linux games, such as Civilization: Call to Power and Myth II of which have demo versions available. Chapter 8 describes how to use audio and video players, as well as how to configure sound cards and CD burners. Chapter 9 describes tools for browsing the Web (such as the Firefox browser) and related tools (such as e-mail clients and newsreaders).
