# Loading data from a command

Using the LOAD DATA command from a mysql session, you can load a file containing database records into your MySQL database. Here are a few things you need to know about creating a file to be loaded into MySQL:

+   * You can create the file using any Linux text editor.
* Each record, consisting of all the columns in the table, must be on its own line. (A line indicates the start of the next record).
* Separate each column by a Tab character.
* You can leave a column blank for a particular record by placing a \N in that column.
* Any blank line in the file results in a blank line in the database table.

In this example, the following text is edited into a plain-text file. This is in a format that can be loaded into the make table created in this chapter. To try out, type the text into a file. Make sure you insert a Tab character between each value.

| Chris Smith 175 Harrison Street Gig Harbor WA 99999 |
| John Jones 18 Talbot Road Coventry NJ 54889 |
| Howard Manty 1515 Broadway New York NY 10028 |

When you are entering the data, save the text to any filename that is accessible to the mysql server daemon (for example, /tmp/name.txt). Remember the filename so that you can use it later.
