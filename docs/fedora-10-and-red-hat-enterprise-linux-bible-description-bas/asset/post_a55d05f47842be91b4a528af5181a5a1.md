## Part I: Getting Started in Fedora RHEL

## Step 1: Checking out your home folder

Double-click the user's Home icon on the desktop (it should say something like “bill’s Home” or “julie’s Home,” depending on your user name). The window that appears shows your file manager (Nautilus in GNOME or Dolphin in KDE) as it displays the contents of your home folder.

Notice that your home folder contains several folders that were added by GNOME: Desktop (containing the items you see on your desktop), Documents, Download, Music, Public, Templates, and Videos.

The location of the home folder (also referred to as a home directory) on your computer is usually `/home/user`, where user is replaced by your user name. Here are some things to try out with your home folder (assuming the GNOME Nautilus is your file manager):

- 1. **Folders** — Create folders and folders to store your work (click File → Create Folder, and then type the name of the new folder; something like Images, Memos, or Projects).
- 2. **Open Location** — To open another folder on your computer, click File → Location and type a directory name. For our tour, open a folder that has different file types in it (for example, `/usr/share/doc/bash-3.2/` contains some text, PostScript and HTML files).
- 3. **Open With** — Click any object in a folder with the right mouse button, and select Open With. You should be able to see programs you can use to open the object. For example, you can choose to open a Web page (.html file) with Firefox, Konqueror, or Text Editor (depending on what is installed, you may see different options).
- 4. **Side Pane** — Right-click any folder in the Nautilus file manager window, and select Browse to the new folder with a Side Pane displayed. From the drop-down box at the top of the Side Pane, choose Information about the selected folder or File. Next to History to see folders and folders previously viewed. Choose Tree to see a hierarchical representation of your file system. Select Places to see folders from removable media and your home folder. Using the button above the side pane, you can choose to have your location box text-based or represented by buttons.
- 5. **Backgrounds** — Click Edit → Backgrounds and Emblems. Drag and drop patterns and colors you like into your folder (I personally like camouflage). Click Emblems, then drag and drop an emblem on a file or folder. Use the emblem to remind yourself of something about the object (such as the fact that it's your personal document or of urgent nature)

## Step 2: Change some preferences

More than 20 preference categories are available from the GNOME desktop. Select System, and then choose Preferences. From submenus you might want to modify:

- Change background — Select Look and Feel → Appearance, and select the Background tab. The Appearance window, as shown in Figure 3-3. To change the background image, select one of the Desktop images. To add your own image, click the Add button. Select a Style, such as Centered, Full Screen, Tiled, Zoomed or Scale. To use a color, select the blank wallpaper in the upper-left corner of the box

The default background for Fedora is actually an animated background. The background consists of a series of images and a specially formatted XML file that indicates when and how the images are changed. See /usr/share/backgrounds/solar.xml. Read the comments in that XML file to see how the background images change to reflect different times of day.

- Select Personal -> Preferred Applications. When you open a Web page, mail, mail composer, or shell from the desktop, these preferences window lets you choose which Web browser, mail reader, media player or Terminal window to open. Firefox is the default Web browser, but you can choose Epiphany or Konqueror (the KDE browser) to run on your GUI. If you want a text-based Web browser, W3M or Mutt. To use a different Web browser, select Custom and type the command line for the browser you want to use into the Command box.

Available Mail Readers include Evolution (the default), KMail, Thunderbird, and Mutt. On the System tab, GNOME Terminal is assigned as the default when you need a shell prompt (you can change that to KDE Console or a standard xterm). To add a different terminal, select Custom Terminal and enter the command that starts the Terminal you want. You can also choose default multimedia and accessibility applications.

> TIP: The console command starts the Konsole (KDE) terminal window. Programmers who use many terminal windows at once often prefer Konsole over gnome-terminal (finding it to be more efficient and feature-rich). Monitoring a session for silence or activity when compiling long programs or waiting for a process to finish are examples of Konsole features that are useful to programmers.
