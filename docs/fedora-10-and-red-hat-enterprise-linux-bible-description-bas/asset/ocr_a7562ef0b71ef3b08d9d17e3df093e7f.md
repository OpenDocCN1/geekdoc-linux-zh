# Taking Webcam videos and snapshots with Cheese

Fedora has a new application as part of GNOME desktop for taking snapshots and videos from your Webcam. With a supported Webcam (described earlier), you can use the new Cheese application (http://www.gnome.org/projects/cheese) to capture images from your Webcam with a few mouse clicks.

To install Cheese, type the following from a Terminal as root user:

```
# yum install cheese
```

Then, with your Webcam connected, either select Applications -> Cheese from the GNOME menu or type cheese from a Terminal to launch Cheese. Figure 8-11 shows an example of the Cheese window.

As your Webcam output is displayed in the top of the Cheese window, you can use the Photo or Video buttons to select what you want to capture. The middle button toggles to let you take a Photo or Start Recording. For photos, you have a three-second pause to get ready for the shot. For videos, recording starts and you need to click Stop Recording when you have captured all you want.
