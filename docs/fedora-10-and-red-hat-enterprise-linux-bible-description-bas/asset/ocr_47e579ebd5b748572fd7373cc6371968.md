+   - OmniVision Webcams (ov511 driver) — Webcams supported by this driver include USB bands from OmniVision chips (http://www.ovt.com/products/app2_table.asp?id=4). Webcam Webcam 3, MediaFactory MV300, AVERmedia Webcam, and D-Link DSB-C300.
- Philips Webcams (pwc driver) — This driver supports a variety of USB Webcams, including PCA645, PCA646, PCVC675, PCVC690, PCVC730, PCVC740, and Askey V0C10. This also includes several inexpensive Logitech Webcams, including the QuickCam Pro 3000.
- EndPoints Webcams (se401 driver) — Supports Webcams that contain the EndPoints SE401 sets. These include the Kensington VideoCam PC (67014, 67015, 67016, and 67017) and the Axe se401 camera (se401).
- SONIC PC Cameras (sn9e02 driver) — USB cameras supported by the SONIC camera controllers are supported by this driver. The Swee 100K, X-Eye and Chichony Twinkle Webcam. The sn9e10x is maintained by Linux Projects (http://www.linux-projects.org).
- STMicroelectronics Webcams (stv680 driver) — Contains the USB version of STV0680 chips from STMicroelectronics (http://www.st.com) is supported by this driver. Cameras include the Aiptec Pencil and Niss Quickpix 2 (Vendor/product ID 0553/2020). For information on the driver, refer to the STV0680 USP Support page (http://stv680-usb.sourceforge.net).
- Ultracram Webcams (ultracram driver) — Supports Webcams such as the IBM UltraPort II. See the webcam driver at http://www.gutwin.org/cam/source)
- Vicam Webcams (vicam driver) — The 3Com HomeConnect USB Webcam is supported by this driver. Refer to the driver's project for further information (http://homeconnect.sourceforge.net).
- Winbind Webcams (w9968cf) — Supports the W9968cf JPEG dual mode camera chip from Winbind Electronics. Webcams that use the SDG-5000 Aroma Digi Pen, Zonzics EZ-802 EZMega Cam, and the Pretec DigiPen-480. Refer to the Linux Projects site (http://www.linux-projects.org) for further information.
