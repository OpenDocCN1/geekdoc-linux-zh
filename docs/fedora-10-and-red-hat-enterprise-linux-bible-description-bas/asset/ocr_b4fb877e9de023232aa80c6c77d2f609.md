+   * Windows file and printer sharing — If your computer is connected to a LAN on which
Windows computers are sharing files and printers, you can view those resources from
autilus. Click File -> Open Location from a Nautilus window, and then type smb:
to see available workgroups. Click a group to see computers from that workgroup
sharing files and printers. Figure 3-12 shows an example of Nautilus displaying an
icon representing a folder on a Windows computer called einstein (smb://einstein).

+   * MIME types and file types — To handle different types of content that may be
encountered in the Nautilus window, you can set applications to respond based on
MIME type and file type. With a folder being displayed, right-click a file for which you
want to assign an application. Click Open With Other Application. If no application has
assigned for the file type, click Associate Application to be able to select an
application. From Add File Types window, you can add an application based on the
file extension and MIME type representing the file.

> CROSS-REFERENCE: For more information on MIME types, see the description of MIME types
in "Changing GNOME preferences" section later in this chapter.
