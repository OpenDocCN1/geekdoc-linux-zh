# Doing a Simple Backup with rsync

Cheap hard disk space, fast networks, and really neat new tools have given Linux users some nice alternatives to the old reliable removable media (such as tapes and CDs). To back up your personal data or the data from a small office computer, the examples in this section provide fairly simple ways of creating backups of your data.

To do this procedure, you need to have hard disk space on a computer that is at least larger than the hard disk you are backing up. That hard disk space could be on:

+   * **A partition** — By backing up to a separate disk partition, you are protected in the case the partition you are backing becomes corrupt. However, you are not protected if your hard disk goes bad.
* **A hard disk** — Backing up to a separate hard disk can protect from a corrupted disk, but won't help if your computer is hit by lighting, a flood, or other acts of God.
* **A different computer** — By backing over the network, you can back up to another computer that is as far away from the source of your data as makes you comfortable. You can back up to the computer down the hall or one another country.

To do the actual backup, you use the rsync command. The rsync command is like a remote copy command (similar to *rcp*) on steroids. In essence, rsync lets you copy files from one location to another. However, it also has some nice extras that enable you to do the following:

+   * **Transfer data securely** — If you transfer a file that was transferred during an earlier backup, rsync uses a checksum-algorithm to determine the differences between the old file and the new one. It then sends the data needed to account for the differences between the two files.
* **Transfer data securely** — rsync combines with *ssh* (or another remote shell) to encrypt the data, so it can travel across a network.
* **Maintain ownership** — The transferred files can keep their permissions, ownership, timestamps, and group designations. (Because ownership is based on numeric UID and GID, matching user and group accounts must be set up between machines for the files to appear to be owned by the same users and groups after copied.)
