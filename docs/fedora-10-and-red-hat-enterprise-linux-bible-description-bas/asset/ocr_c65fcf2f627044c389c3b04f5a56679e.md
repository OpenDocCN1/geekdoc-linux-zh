# Chapter 10: Understanding System Administration 413

+   - Server Settings — This submenu accesses the following server configuration windows.

+   - Domain Name System (system-config-bind) — Create and configure zones if your computer is acting as a DNS server.

+   - FTP (system-config-vsftpd) — Configure the vsftpd FTP server. You may also see this under the System Tools menu under the Applications.

+   - HTTP (system-config-httpd) — Configure your computer as an Apache web server. You may also see this under the System Tools menu under the Applications.

+   - NFS (system-config-nfs) — Set up directories from your system to be shared with other computers on your network using the NFS service.

+   - Authentication (authconfig-gtk) — Change how users are authenticated on your system. Usually, Shadow Passwords and MD5 Passwords are selected. However, if your network supports LDAP, Kerberos, NIS, or Hesiod authentication, you can select to use any of those methods.

+   - Boot Loader (system-config-boot) — Configure the default boot entry and timeout (seconds) for GRUB boot loader.

+   - Date & Time (system-config-date) — Set the date and time or choose to have an NTP server system time in sync. Figure 10-2 shows the Date/Time Properties window.
