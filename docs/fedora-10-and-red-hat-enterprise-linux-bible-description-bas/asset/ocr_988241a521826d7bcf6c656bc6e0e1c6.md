# Partitioning your disks

The hard disk (or disks) on your computer provides the permanent storage area for your data files, applications programs, and the operating system (such as Fedora or RHEL). Partitioning is the act of dividing a disk into logical areas that can be worked with separately. There are several reasons you may want to partition:

+   * Multiple operating systems — If you install Fedora or RHEL on a PC that already has a Windows operating system, you may want to keep both operating systems on the computer. To run efficiently, they must exist on completely separate partitions. When your computer boots, you can choose which one to run. Note that you are limited in the number of partitions you can have (with IDE devices you can have 63 partitions; with SCSI devices, you are limited to 15 partitions per device).
* Multiple partitions within an operating system — To protect your entire operating run out of disk space, people often assign separate partitions to different areas of the Linux file system. For example, if /home and /var were assigned to separate partitions, a gluttonous user who fills up the /home partition wouldn't prevent daemons from continuing to log files in the /var/log directory.
* Different file types — Different kinds of file systems have different structures. File systems of different types must be on their own. In Fedora and RHEL, you need at least one file system for (typically ext3) and one for your swap area. File systems on CD-ROM use the iso9660 file system.

> TIP: When you create partitions for Fedora or RHEL, you will often assign the file system type as Linux native (using the ext3 type). Another type, ext4, is also available. Reasons to use other types include needing a file system that allows long filenames or inodes (each file consumes an inode).

For example, if you set up a news server, it can use inodes to store news articles. Another reason for using a different file system type is to copy an image backup tape from another operating system to your local disk (such as one from OS/2 or Mini operating system).

If you have used only Windows operating systems, probably you would had your hard disk assigned to C: and never thought about partitions. With Fedora and RHEL, you can select to have Linux erase the whole disk, take it over, partition it and have Linux keep separate partitions for Windows 9/2000/NT/XP/Vista/Linux. The Fedora and RHEL install processes also give you the opportunity to change the default partitioning for the different installation types.
