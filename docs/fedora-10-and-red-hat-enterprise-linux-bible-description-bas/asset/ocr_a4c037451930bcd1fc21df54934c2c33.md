# GNOME games

The GNOME games consist of some old games from Windows systems and a bunch of games that look suspiciously like games you would find on Windows. If you are afraid of losing your favorite desktop diversion (as Solitaire, FreeCell, or Mineseper) when you leave Windows, have no fear. You can find clones of many of them under GNOME games.

Table 7 lists the games that are part of the gnome-games software package. After that package is installed, the games are available by selecting Games from the Applications menu. If you install the kgames package, many KDE games (shown in Table 7-2) are also available on this menu.

# Table 7-1: GNOME Games

| Game | Description |
|---|---|
| AisleRiot (solitaire) | Lets you select from among 28 different solitaire games. |
| Blackjack | The popular card game where you get to 21. |
| Five or More | Form lines to remove colored balls from the board. |
| Four-In-A-Row | Drop balls to beat the game at making four in a row. |
| FreeCell Solitaire | A popular solitaire card game. |
| lagno | Flip black and white chips to maneuver past the opponent. |
| Klotski | Move pieces around to allow one piece to escape. |
| Mahjongg | Classic Asian tile game. |
| Mines | Mineseper clone. Click safe spaces and avoids the bombs. |
| Nibbles | Steer a worm around the screen while avoiding walls. |
| Robots | Version of Gnobots, which includes movable junk heaps, where you try to get robots to destroy themselves before they get you. |
| Same GNOME | Eliminate clusters of balls for high score. |
| Sudoku | Popular Japanese logic game. |
| Tali | Yahtzee dice to fill in categories. |
| Tetrave | Puzzle game where numbers on adjacent pieces match. |

# KDE games

If you install KDE, there are a bunch of games in the kgames package. If you did not install the KDE desktop, you can install the kgames package separately from the DVD that accompanies this book or using yum over the Internet (yum install kgames). To see the KDE games (along with some GNOME games) on the Applications menu, select Games and then choose the game you want. The games from the kgames package are listed by category in Table 7-2.
