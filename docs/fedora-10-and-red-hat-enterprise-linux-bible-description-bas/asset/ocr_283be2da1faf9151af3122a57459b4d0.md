# Chapter 6: Publishing with Fedora and RHEL 269

+   Change attributes—Select File -> Document Setup. From the Document window that appears, you can change the size and orientation of the page, as well as the type of page (single, double-sided, three-fold, or four-fold). Likewise, you can change all margins. Select topics from the left to add as author, title, and keywords. You can also change fonts and hyphenation to add a table of contents.

+   Drawing—You can freehand drawing anywhere on Scribus. Select the Insert Freehand Line (pencil icon) or Insert Bezier curve (pink icon), then use the mouse to draw lines on the page. You can also draw boxes, polygons or lines using the toolbar. Right-click the draw element and change the shape, line and colors of the drawing.

When you are done creating your layout, you can print it by selecting File -> Print. The Preflight Verifier window appears within information about the printed document. At the top right corner of the page, you can select to change PostScript to one of several PDF versions. You can choose now to direct the output to the printer or have it go to a PDF or PostScript file.
