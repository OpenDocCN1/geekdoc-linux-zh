Groff macro packages are stored in /usr/share/groff*/tnac. The man macros are called from an .tmac file, mm macros are from .tmac, and me macros are from .etmac. The naming convention for each macro package is xxx.tmac, where xxx is replaced by one or more letters representing the macro package. In each case, you can understand it by adding an to the beginning of the suffix file.

> TIP: Instead of noting a specific macro package, you can use -mandoc to choose a macro package.

When you run the groff formatting command, you can indicate on the command line which macro packages you are using. You can also indicate that the document should be run through any of the following commands that preprocess text for specific formats:

# Formatting and printing documents with Groff

You can try and formatting an existing Groff document using any pages on your Fedora or RHEL system (such as those in /usr/share/man/*). Those pages are compressed, so you can copy them to a temporary directory and unzip them to get out by Groff.

These commands copy the man chown page to the /tmp directory and unzip it. Then Groff formats the man page in plain text so you can print it over your screen.

```
$ cp /usr/share/man/man/chown.1.gz /tmp
$ gzip /tmp/chown.1.gz
$ groff -Tascii -man /tmp/chown.1 | less
```

In the previous example, the man chown page (chown.1.gz) is copied to the /tmp directory, is unzipped (using gzip), and is output in plain text using the man macros (-man). The output is piped to less, which goes through over your screen. Instead of piping to less (| less), you can direct the output to a file (>tmp/chown.txt).
