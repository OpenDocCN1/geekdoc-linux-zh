# Chapter 2: Installing Fedora 81

> CAUTION: Some video card drivers from NVIDIA and ATI will overwrite Xorg drivers. If you later change to a different video card, features of the new card (such as DRI) might fail. The solution is to entirely remove the NVIDIA and ATI drivers and reinstall your xorg and mesa packages.

+   - If installation completes successfully, your screen is garbled when you reboot, should try to get Fedora or RHEL to boot to a text-login prompt. To do this, add 3 to the number of the kernel boot line in GRUB. Linux will start with the GUI temporarily disabled. Run system-config-display to try to fix the problem. (See Chapter 3 for other advice regarding fixing your GUI).
- If your mouse is not detected during installation, you can use arrow keys and the Tab key to make selections. Then use mouse-test to track down the problem.
- If installation improperly probes your hardware or turns on a feature that causes problems with your hardware, you might be able to solve by disabling the offending feature at the install boot prompt. Try adding one of the following after the word linux=nodma (if your system hangs while downloading the image), amoff or acpi= (if you experience crashes during install), or nousb, nopcem, or norefire (if you suspect that install is hanging on devices of those types).
- If you are still having problems installing Fedora, searching FedoraForum.com to see if you have an answer. Sign up for an account and you can ask a question. The best result for troubleshooting your installation problems for RHEL systems is the Red Hat Support site (http://www.redhat.com/apps/support). Links from that page you can take to documentation, updates and errata, and information about support programs. If you are having problems with a particular piece of hardware, try searching the Solutions Database, using the name of the hardware in the search box. If you are having problems with particular hardware, chances are someone else did, too.

# Spinning Your Own Fedora Install or Live Media

All software in Fedora can be redistributed. Because of that, you can not only use the software as you please, but can also repack and redistribute it if you care to. It is only the Fedora Project committed to protecting your rights to redistribute Fedora, but it has gone so far as give you the tools to build your own new Fedora-based distribution to your needs.

Fedora has created several tools that let you build your own or live media. Using these tools, you can pick the packages you want from the Fedora repository, add new repositories, and combine the content into ISO images that can be burned to CDs, DVDs, USB flash drives or other media. In short, you can make your own custom Linux distribution.
