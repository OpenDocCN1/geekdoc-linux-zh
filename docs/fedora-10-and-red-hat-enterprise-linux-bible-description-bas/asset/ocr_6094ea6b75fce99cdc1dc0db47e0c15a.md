CAUTION: Getting software from any sites that are not sanctioned by the Fedora Project presents potential problems. The Fedora Project works hard to make sure that package dependencies across all official packages are handled consistently, you don't get the same guarantees with other repositories. While some repositories make commitments to build their packages on the official Fedora repository, others don't. In the latest Fedora release, several of these repositories (Dribble, Fresnel, and Livre) are in the process of joining together to form the RPM Fusion Project (http://rpmfusion.org/), to help eliminate inconsistencies among most popular repositories.

+   **Extra Packages for Enterprise Linux (EPEL)** — Because Red Hat Enterprise Linux is designed to be a stable distro derived from Fedora packages, some packages are not included with RHEL. While many of these extra packages to RHEL users (as well as RHEL such as CentOS), the Fedora project sponsored the EPEL software repository. If you are using EPEL 4.x or 5.x systems, the appropriate epel release package to your system, then you would need any other software repository (as described later in this chapter). For more on EPEL FAQ (http://fedoraject.org/wiki/EPEL).
* **Software project sites** — Individual software projects will offer their own set of RPM packages for this is particularly useful for projects under continuous development (such as the WINE project). If the project doesn't offer RPMs, they typically offer code in what is called a *tarball*. The tarball may include binary code, or more, source code you can use for your environment. (Describe how to install from source code tarballs later in this chapter.)

If you know what software you want and it is available from more one location, you should choose one from an official Fedora repository. Besides, a repository outside of Fedora's committed to being compatible with the main Fedora repository is your next best choice, which will help take care of any dependency problems.

Most Fedora repositories are with descriptions of the packages they offer. The following lists summarizes over other Web sites that you can browse to find detailed information about software that runs in Linux. You can then search Fedora repositories (described later in this chapter) for Fedora- or RHEL-specific versions of these packages.

+   * **Freshmeat** (http://freshmeat.net) — This maintains a massive index of Linux software. You can keyword search for software projects or browse by category.
* **SourceForge** (http://sourceforge.net) — This site holds thousands of open source projects. You can download software and documentation from those projects through the SourceForge site.
* **Rpmfind** (http://www.rpmfind.net) — Provides a way of searching for open source software that is packaged in the RPM Package Management (RPM) format across a variety of repositories. You can do a keyword search from this Web site.
