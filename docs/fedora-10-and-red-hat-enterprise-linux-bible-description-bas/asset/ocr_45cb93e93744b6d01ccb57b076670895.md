+   * **Multiple wireless access points and roaming** — Each wireless network can be configured as a separate cell. Multiple cells can be joined together in what is called a Managed Wireless LAN. In this arrangement, each cell's access point acts as a bridge (in fact, its actions are referred to as bridging) passing all data from the cell to others without changing any node's MAC address. In other words, the managed LAN masks the fact that there are multiple wireless cells invisible to the clients on them. This arrangement allows users to roam among cells which they come in and out of range losing continuity of communication.

> NOTE: Linux does not support any wireless LAN cards that can act as a bridging access point, you can have the Linux system act as a client to a bridging access point. Set your card to Managed mode and identify the MAC address for your wireless LAN's access point. For information on the current state of Ethernet bridging, refer to the Bridge page at the OSDL Web site (http://linux-net.osdl.org/index.php/Bridge).

For our purposes, we focus on star (wired) and peer-to-peer (wireless) topologies. Common to both of these topologies is the protocol used to send data over those wired and wireless media — the Ethernet protocol.
