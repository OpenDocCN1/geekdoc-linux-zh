# Browsing On
BrowseProtocols cups
BrowseOrder Deny,Allow
BrowseAllowfrom @LOCAL
BrowseAddress 255.255.255.255
Listen :*631

Browsing is the feature where you broadcast information about your printer on your local network and listen for other servers'. Browsing is by default, but for the local host (@LOCAL). You can allow including CUPS browser information for additional selected addresses. Browsing information is broadcast, by default, at address
255.255.255.255.

To enable Web-based CUPS administration, the cuspd daemon listens on port 631 for all network interfaces to your computer by entry: Listen :*631.
BrowseRelay source-address destination-address

By turning BrowseRelay (it's off by default), you can allow CUPS browser information to be passed among two or more networks. The source-address and destination-address can be individual IP addresses or represent network numbers. This is a good way to allow users on several connected LANs to use printers on nearby LANs.

You can allow or deny access to different features of the CUPS server. An access definition for a CUPS printer (from the Printer configuration window) might appear as follows:

```
<Location>/printers/nsl-hpl>
Order Deny,Allow
Deny From
Allow From 127.0.0.1
AuthType None
</Location>
```

Here, to the nsl-hpl printer is allowed for the settings in the cuspd.conf file, you must reload the CUPS service to have the changes take effect. As root user, type service reload. (The reload option reads the new configuration without restarting the daemon).

If you change any of the settings in the cuspd.conf file, you must reload the CUPS service to have the changes take effect. As root user, type service reload. (The reload option reads the new configuration without restarting the daemon).
