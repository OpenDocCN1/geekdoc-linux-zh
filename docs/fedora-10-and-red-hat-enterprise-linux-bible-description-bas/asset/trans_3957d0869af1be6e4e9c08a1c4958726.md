图 8-3 显示了一个默认的 Fedora 系统，其中 PulseAudio 是主系统，alsamixer 不直接控制声卡。它仅作为 PulseAudio 的主控制器。如果你不需要安装 GNOME 实用程序（如音量栏），可以使用 Fedora 和 RHEL 中 `al-utils` 软件包提供的实用程序。特别是，该包包含 `alsamixer` 实用程序，它可以让你调整或静音各种声音。它还让你选择用于录制或其他捕获音频输入的设备。

`alsamixer` 实用程序是一个应用程序，这意味着它可以从终端以图形化方式查看。它可以用于管理计算机上多个声卡的音平，用多个设备来表示。在终端窗口中输入 `alsamixer` 进入播放模式（调整音频输出），或输入 `alsamixer -V capture`（选择音频采集设备并调整音频采集电平）。

以下是使用 `alsamixer` 调整音频的一些方法：

- 使用左右箭头键在不同的声音音量轨道之间移动。
- 使用上、下箭头键调整当前轨道的电平。
- 按 `m` 静音或取消静音当前轨道（仅限播放模式）。
- 按空格键标记采集设备，例如适用于捕获音频的麦克风或线路输入设备。然后调整条形框以设置音频捕获的电平。（注意，这仅在采集模式下有效：`alsamixer -V capture`。）

被静音的轨道在滑块底部显示为 `MM`。取消静音后，会显示 `0`。如果可用轨道多于屏幕能显示的数量，使用右箭头键可以让你向右滚动以显示额外的轨道条。

如果一个轨道上有两个通道，你可以单独调整它们。选中轨道后，使用 `q`、`w` 和 `e` 键分别调高左声道、右声道和通道。

# 设置声卡进行录制

我添加这个关于设置声卡录制的章节，是因为人们经常错过这一步。你可能运行许多应用程序（如 Skype）并疑惑为什么没有录制。原因在于你需要在录制前识别采集设备，并确保其电平足够高工作。

使用通道进行音频采集的最简单方法是使用之前描述的 GNOME 音量控制窗口。点击下拉列表并选择控制麦克风（或其他输入设备）的采集设备。确保除你想要录制的设备外，所有音频设备都已静音。可用设备包括麦克风、线路输入和 DAC。每个采集设备下方的麦克风输入处的红色“X”表示它处于静音状态。

将你的采集设备的滑块向上移动到适当电平。连接你的麦克风或输入设备（到线路输入）并启动你想录制的应用程序。

# 选择音频播放器

Fedora 和 RHEL 中有用于播放各种格式的音乐和声音文件的音频播放器。在不添加任何软件的情况下，你可以播放音乐 CD 和 Ogg Vorbis 音频（你可以自己进行刻录和编码）。某些播放器可以添加 MP3 支持，而红帽发行版之外的 MP3 播放器也可用。

- **KsCD Player (ksed)** — KsCD 播放器随 KDE 桌面一起。要使用 KsCD，必须安装 `kmultimedia` 软件包。从应用程序菜单（KDE 桌面）选择“音频与视频” → KsCD（或在终端窗口中输入 `ksed`）。此播放器允许从 CD 数据库中获取引用、跟踪和艺术家信息，并允许你提交 CD 数据库中输入的信息（如果你的 CD 在那里未被找到）。

- **Rhythmbox (rhythmbox)** — 使用用于 GNOME 的 Rhythmbox 音乐管理和播放软件导入并管理你的音乐收藏。Rhythmbox 使用 Gstreamer 和 Sound Juicer 从 CD 中提取音乐，并使用 Ogg Vorbis、FLAC 或低质量 WAV（用于语音）音频格式对其进行压缩。除了允许你为音乐库创建播放列表外，Rhythmbox 还有播放广播电台的功能。从应用程序菜单中选择“音频与视频” → “音乐播放器”打开 Rhythmbox。

- **XMMS (xmms)** — X 多媒体系统 (XMMS) 音频播放器为 Ogg Vorbis、WAV、FLAC 和其他音频格式提供了一个简单的图形化播放器。XMMS 具有类似 Windows 的外观和感受，你可以通过 xmms 软件包获取它。

- **ogg123, mpg321, aplay** — 如果你没有桌面，可以使用 ogg123, mpg321 或 aplay 命令。ogg123 软件包在 Fedora 中可用，aplay 属于 al-utils 软件包，而 play 随 RHEL 带有。mpg321 命令来自 Livna.org 网站。对于当前发布版，ogg123 项目不再维护，且完全受 GPL 覆盖。默认的 CD 播放器是 Rhythmbox。

> 注意：如果你尝试这些 CD 播放器，请查看“排除 CD-ROM故障”获取更多信息。

# 自动播放 CD

当你将 CD 插入 CD-ROM 时，桌面图标（Rhythmbox）会自动弹出并播放 CD。如果你不想 CD 自动启动，或者想使用不同的播放器，可以在 Nautilus 的媒体选项卡中更改该行为。

# 排除 CD-ROM故障

如果你无法在 CD-ROM 上播放，可以检查以下几点：

- 验证你的声卡已安装并正常工作（参见“配置声卡”）。
- 验证在启动时是否检测到了 CD-ROM 驱动器。如果你的 CD-ROM 驱动器是 IDE 驱动器，输入 `dmesg | grep -i cd`。你应该看到关于 CD-ROM 的信息，类似于 `ata2:0: ATAPI: HL-DT-RW/DVD DRIVE GCC-424N, 0201, max UDMA/33`。
- 如果没有任何，验证电源电缆是否连接。为了确保硬件正常，你也可以启动到 DOS 并访问 CD。
- 检查 CD-ROM 驱动器是否由于固件或其他问题被列黑名单。访问 www.tlid.org/HOWTO/Hardware-HOWTO/cdrom.html。
- 如果你让 CD-ROM 工作了但在非 root 用户尝试播放时出现“CDROM device: Permission denied”错误，可能是因为媒体设备不允许 root 以外的用户读取。输入 `grep media` 查看设备名称。如果是 `/dev/scd0`，输入 `chmod 644 /dev/scd0` 以允许所有用户读取。
