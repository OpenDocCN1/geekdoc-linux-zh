# Setting up Firefox

There are many things you can do to configure Firefox to run like a champ. The following sections describe some ways to customize your browsing experience in Firefox.

# Setting Navigator preferences

You can set your Firefox preferences in the Preferences window. To open Firefox Preferences, click Edit -> Preferences. The Preferences window appears, as shown in Figure 9-5.

![](img/63c86e1d25a0e2be7e9f6de6b6f02530_416_0.png)

Figure 9-5: Change settings for navigating the Web from the Firefox Preferences window.

The following list shows some preferences that you might want to change from the Firefox Preferences:

- *Choosing a home page* — To choose a home page from the Main tab, you can simply type a URL in the Location box. It can be a local file (file://) or a Web page (http://). You can also have multiple home pages, with each appearing on a separate tab when Firefox starts, by separating URLs with a pipe (for example, `http://linuxtoys.net|http://redhat.com`).

- To fill in your home locations, you can also select buttons. Use Current Pages adds the current pages on all tabs of your browser or Use Bookmarks button lets you choose pages from your bookmarks list. Selecting Blank Page sets your home page to about:blank.

- **Saving browsing information** — Select the Privacy tab to choose how information about your browsing is saved. On the Privacy tab, you can choose how to save data related to your history, data you enter into forms, passwords, downloaded files, and cookies. You can select to clear your history, forms data, passwords, download history, and cached Web pages. Clearing this information is a good idea if you are Firefox on someone else’s machine and want to keep your browsing private.

- **Setting languages** — Set a list of preferences for the particular language a Page should be displayed, if the page is available in several languages, by selecting the Content category and selecting the Choose under Languages.

- **Enabling or disabling content** — Some content you encounter can be annoying or dangerous to display or play from your browser. From the Content tab, select what to allow and block in pop-up windows, still to install extensions or themes, display image, a content, and javascript content. You can also set exceptions to the general rules you set for handling the content mentioned. There are numerous Firefox extensions you can use in blocking content as well.

> NOTE: The latest Firefox release helps you block Web sites by displaying a Suspected Forgery popup message when it encounters a page that has been reported as forged. You can choose to not display the page or ignore the warning. If you suspect a forged page that doesn’t display that message, select Help → Report Web Forgery to try to add the page to the Google Web Forgery list.

- **Tabbed browsing** — Use selections on the Tabs tab to determine how tabs are used when opening new content or closing the browser.

- **Download manager and folder** — Choose whether or not to see a download manager when files are being downloaded. Also, you can choose to be asked where to place each file download or select a default folder to automatically download your files. Select View & Edit Actions to configure what actions to take.

The Advanced Preferences tab can be used to fine-tune your Web browsing experience. Here are some Advanced Preferences that may interest you:

- **General settings** — Some settings on the General tab in the Advanced section let you change accessibility settings, browsing features (such as auto resizing of windows and scrolling) and system theme.

- **Choosing connection settings** — If you have direct access to the Internet, you don’t need to change any proxy settings. However, if you need to access the Internet via a proxy server, you can identify the location of that server (or) by selecting Network -> Connection Settings from the Advanced tab. To access the Web via proxy servers, you must explicitly identify the proxy server for each type of content you request (HTTP, SSL, FTP, Gopher, and SOCKS).

- **Get updates** — From the Update tab, Firefox can be set to automatically check for updates the search engine or installed extensions and themes. Select Show Update History.

- **Security settings** — From the Security tab, you can configure how Firefox handles security and certificates. You can choose to ask you, always allow, or block block sites with invalid certificates. You can also manage the list of trusted and revoked certificate authorities.

- **Advanced settings** — From the Advanced tab, you can configure how Firefox handles various tasks, such as caching, proxies, and performance. You can also customize how Firefox handles different types of content.

- **Content settings** — From the Content tab, you can configure how Firefox handles different types of content, such as pop-ups, plugins, and JavaScript. You can also set exceptions for specific websites.

- **General settings** — From the General tab, you can configure various settings, such as the home page, language, and privacy settings.

- **Extensions and themes** — From the Extensions and themes tab, you can manage, disable, or remove the extensions and themes installed in Firefox.
