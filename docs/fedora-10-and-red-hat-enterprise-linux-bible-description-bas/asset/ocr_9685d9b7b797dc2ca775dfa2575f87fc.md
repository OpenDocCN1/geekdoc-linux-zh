# Creating the amanda.conf file

Next, as the amanda user, you must create two configuration files for Amanda and store them in the /etc/amanda/normal directory: amanda.conf and disklist. You can start by copying samples of these files from the /etc/amanda/DailySet1 directory as:

```
$ cd /etc/amanda/DailySet1
$ cp amanda disklist /etc/amanda/normal
```

The amanda.conf file defines a set of general values, and the disklist defines machines and partitions to back up. The amanda.conf file can be rather complicated but, fortunately, most of its values can be left at their default values. Here is a simplified amanda.conf with some comments embedded in it to help explain things:

```
# amanda.conf - sample amanda configuration file. This started life as
# the actual config file in use at CS.UMD.EDU.

org "GLACI" # your organization name for reports
mailto "amanda" # space separated list of operators at your site
dumpuser "amanda" # the user to run dumps under

# Specify tape device and/or tape changer. If you don't have a tape
# changer, and you don't want to use more than one tape per run of
# amdump, just comment out the definition of tpchanger.

untapes 1
# number of tapes to be used in a single
# run of amdump
tapedev "/dev/nrft0" # the no-rewind tape device to be used
rawtapeev "/dev/rft0" # the raw device to be used (ftape only)

taptype HF-DAT # what kind of tape it is
# (see typesetypes below)
labelstr "normal[0-9]*" # label constraint all
# # tapes must match

# Specify holding disks. These are used as a temporary
# staging area for dumps before they are written to tape and
# we are recommended for most sites.

holdingdisk hdl {
comment "main holding disk"
directory "/home/amanda" # where the holding disk is
# # how much space we can use on it
use 290 Mb
chunksize -1 # size of chunk
```
