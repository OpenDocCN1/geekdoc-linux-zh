# 176 Part I: Getting Started in Fedora RHEL

The nine bits assigned to each file for permissions define the access that you and others have to your file. Permission bits appear as rwxrwxrwx. The first three bits apply to the owner's permission, the next three to the group assigned to the file, and the last three to all others. The r stands for read, the w stands for write, and the x stands for execute permissions. If a dash appears instead of the letter, it means permission is off for that associated read, write, or execute.

You can see the permission for any file or directory by typing the ls -ld command. The named file and directory appears shown in the following example:

```
$ ls -ld ch3 test
-rw-r--r-- 1 chris    4983 Jan 18 22:13 ch3
dr-xr-x 2 sales     1024 Jan 24 13:47 test
```

The first line shows that (ch3) has read and write permission for the owner and group. All others have read permission, which means they can view the file but cannot change its contents (although a user may be allowed to remove the file, since the ability to remove a file is based on directory permissions). The second line shows a directory (indicated by the d letter before the permission bits). The owner has read, write, and execute permission, as a result, the owner can add, change, or delete files in that. Any other user, however, can only read the contents, change to that directory, and list the contents of the directory. (Note that by using -d option, the test directory entry is listed without listing its contents.)

If you own a file, you can change its permission as you please. You can do this with the chmod command. For each of the sets of permission on a file (read, write, execute), r is assigned to the number 4, w to 2, and x to 1. To make permissions open for yourself alone, you would set the first number to 7 (4 plus 2 plus 1). The same would be true for group or other permission. Any combination of permissions can result from 0 (no permission) through 7 (full permission).

Here are examples of how to change a permission on a file and what the resulting permission would be:

```
chmod 777 files -> rwxrwxrwx
chmod 755 files -> rxr-xr-x
chmod 644 files -> rw-r--r--nchmod 000 files -> ------
```

You can also turn file permissions on and off using (+) and minus (-) signs, respectively. This can be done for the owner user (u), owner group (g), others (o), and all users (a). For example, starting with a file with all permissions open (rwxrwxrwx), here are some chmod resulting permissions using a minus sign:

```
chmod a-w files -> rwxr-xr-r-
chmod o-x files -> r--xr--x-
chmod go-wx files -> ---------
```
