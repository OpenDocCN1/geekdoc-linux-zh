If you are interested in details about a package, you can use the rpm -i query. In the following example, information about the dosstools package (for working with DOS file system in Linux) is displayed:

```
# rpm -qi dosstools
Name: dosstools Relocations: (not relocatable)
Version: 3.0.0 Vendor: Fedora Project
Release: 1.fc10 Build Date: Tue 30 Sep 2008 09:58:44 AM CD Build host: x86_64-fedora.px.redhat.com
Install Date: 04 Oct 2008 11:29:13 PM CD Source RPM: dosstools-2.0.0-1.fc10.src.rpm 14236
Group: Applications/System License: GPLv3+
Size: 14236
Signature: 17 Oct 2008 09:51:09 AM CD Key ID da84cd830c9ecff8
Packager: Fedora Project
URL: http://daniel-bauman.com/software/dosstools
Summary: Utilities for making and checking MS-FAT filesystems on Linux
```

The dosstools package includes the mkdos and dosfsck utilities, which respectively make and check MS-DOS FAT filesystems on hard drives or floppies.\ To find out about a package's contents, use the -1 option with your query. The following example shows the complete path names of files found in the dosstools package:

```
# rpm -ql dosstools | less
/sbin/dosfsck
/sbin/fsck.msdos
/sbin/fsck.vfat
/sbin/mkdos
/sbin/mkfs.msdos
/sbin/mkfs.vfat
/usr/share/man/man8/dosfsck.8.gz
```

Would you like to know how to use the components in a package? Using the -d option with a query will display the documentation (man pages, README files, HOWTOs, and so on) that is included with the package. If you are having trouble getting your Windows System running properly, you can use the following command line to find documents that may help:

```
# rpm -qd xorg-x11-server-Xorg | less
/usr/share/man/man1/Xorg.1.gz
```
