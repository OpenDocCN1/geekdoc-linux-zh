With Linux, corporations that deploy hundreds or even thousands of systems can create a great deal of control over the security and features in their employees' systems. In addition, Linux administration can be done remotely using ssh which offers encryption and authentication, with all the advantages of a Linux shell.

In the long run, as Linux systems become more profitable for viruses and malware, learning good practices in using software, file ownership/permission, and monitoring system resources will become more important. However, such tools (including virus scanners like clamav and clamscan) are already available for any Linux system that chooses to include them. The bottom line is that it will take some effort for most people to discard their Microsoft Windows operating systems completely. If you are committed to making Fedora your sole application platform, there are several ways to ease that transition. Emulation programs you run many programs that were created for other operating systems. Conversion programs can help convert graphics and word processing data files from other formats to supported by Linux applications.

If you are running Linux on a PC, chances are that you already paid for a Microsoft Windows 95, 98, ME, XP, NT, 2000, or Vista operating system. You can run Linux on a different PC than you use for Windows or have Windows and Linux on separate partitions of your hard disk on the same. The latter requires that you reboot each time you want to switch operating systems. (See Chapter 2 for information on setting up a Linux/Windows dual-boot system.) Recently, a third choice has been added, where you can run a virtual Windows system on your Linux desktop (see the descriptions of Xen and KVM later in this chapter).
