
# Part IV: Fedora and RHEL Network and Server Setup

Using the Network Configuration window, the IP address and host names can be assigned statically to an Ethernet interface or retrieved dynamically at boot from a DHCP server.

> NOTE: A computer can have more than one IP address because it can have multiple network interfaces. Each interface connected to the network must have an IP address (even if the address is assigned temporarily). So, if you have two Ethernet cards (eth0 and eth1), each needs its own IP address. Also, the address 127.0.0.1 represents the local host, so on the local computer can access services in loopback.

To use the Network Configuration window to define your IP address for your Ethernet interface, follow this procedure:

- 1. Start the Network Configuration. From the top panel, click System -> Administration Network, or as root user from a Terminal window, use system-config-network. (If prompted, type the root password.) The Network Configuration window appears and is shown in Figure 15-9.

![](img/63c86e1d2a0e2be7e9fde6b6f02530691_0.png)
Figure 15-9: Configure your LAN interface using the Network Configuration window.

- 2. Click the Devices tab. A listing of existing network interfaces appears.
- 3. Double-click the eth0 interface (representing your first Ethernet card). A pop-up window appears, enabling you to configure eth0. Figure 15-10 shows the pop-up Ethernet window configuring eth0.

![](img/63c86e1d2a0e2be7e9fde6b6f02530692_0.png)
Figure 15-10: Configure eth0 using the Ethernet Device window.

- 4. On the Ethernet window that appears, you can enter the following:
- Activate device when starts: Check here to have eth0 start at boot.
- Allow all users to enable and disable: Check to let non-root users enable and disable the network.
- Enable IPv6 configuration for this interface: Check here if you are connected to an IPv6 network (Most networks are still IPv4).

- 5. On the same window, you must choose whether to get IP addresses from another computer at boot time or enter them yourself:
- Automatically obtain IP address settings: Select this box if you have a DHCP or BOOTP server on the network from which you can obtain your computer's IP address, mask, and gateway. DHCP is the most common way to connect to your ISP. You should consider setting up your own DHCP server if you have more than a few computers on your LAN (See Chapter 23 for how to set up a DHCP server). You can optionally set your own hostname which can be just a name (such as linux) or a fully qualified domain name (such as linux.local).
- Statically set IP addresses: If there is no DHCP or other server on your LAN, you can add necessary IP information statically by selecting this option and adding the following:
- Address: Type the IP address of this computer into the box. This number must be unique on your network. For your private LAN, you can use private IP addresses (see the "Understanding IP Addresses" section later in chapter).
- Subnet Mask: Enter the mask to indicate what part of the IP address represents the network (Netmask is described later in the chapter).
- Default Gateway: If a computer or router connected to your LAN is providing routing to the Internet or other network, type the IP address of the computer into this (Chapter 16 describes how to use NAT or RHEL as a router).
- Set MTU: The maximum transfer unit (MTU) sets the number of bytes available to the Internet Protocol in a link-layer frame. Click the check box and enter a number to change from the default 1500 MTU used by Ethernet interfaces in Linux. Lower rates can result in packets being dropped over unreliable networks (some users like to lower the rate slightly so smaller actions are dropped). Higher rates can improve performance of large transfers over networks. In most cases, you don't need to modify this.

- 6. Click OK in the Ethernet window to save the configuration and close the window.
- 7. Click File -> Save to save the information you entered.
- 8. Click Activate in the Network Configuration window to start your connection to the LAN.

## Identifying other computers (hosts and DNS)

Each time you name a computer, as when browsing the Web or an e-mail address, the computer name must be translated into an IP address. To resolve names to IP addresses, Fedora and RHEL should go through a search order (based on the contents of three files in the /etc directory: resolv.conf, nsswitch.conf, and hosts.conf). By default, it checks:

- Hostnames and IP addresses (which end up in the /etc/hosts file).
- Hosts available via NIS (if an NIS server is configured as described in Chapter 23).
- Hostnames available via DNS.

You can use the Network Configuration window to add:

- Hostnames and IP addresses. You must do this to identify hosts on your LAN that are not configured on a DNS server.
- DNS search path. By adding domain names to a search path (such as linux.local), you can browse to a site by its hostname (such as linux), and Linux will use the domains you added to the search path to find the host you are looking for (such as linux.local). 
- DNS servers. A DNS server can resolve addresses for the domains it serves and contact other DNS servers to get addresses for all other DNS domains.

> NOTE: If you are configuring a DNS server, you can use that server to centrally store names and IP addresses for your LAN. This saves you the trouble of updating every computer's /etc/hosts file time you add or change a computer on your LAN. Refer to Chapter 25 to learn how to set up a DNS server.

To add hosts, IP addresses, search paths, and DNS servers, do the following:

- Start the Network Configuration. As root user from a Terminal window, type system-config-network or from the Desktop menu, click System Settings -> Network. The Network Configuration window appears.
- Click the Hosts tab. A pop-up window appears to add hosts to /etc/hosts.
- Click New. A pop-up window appears to add IP addresses and hostname.

![](img/63c86e1d2a0e2be7e9fde6b6f02530694_0.png)
Figure 15-11: Add hosts to /etc/hosts using the Network Configuration window.

- Type the IP address of your primary and secondary DNS servers.
- Click OK.
- Click the DNS tab.
