# Investigating your desktop

More and more high-quality desktop applications are being packaged with or made available for Fedora and RHEL, as part of the GNOME or KDE desktop environments. In other words, to start finding some excellent office applications, games, multimedia players, and communications tools, you don't have to look any further than the Applications menu button on your desktop panel.

So before you start hunting the Internet for the software you need, see if you can use something already installed for Fedora or RHEL. The chapters that follow one describe how to use publishing tools, games, work with multimedia, and communicate over the Internet — all with programs that are either on the DVD that comes with this book or are easily obtainable.

Using your Fedora or RHEL to run applications is relatively easy. If you have used Microsoft Windows operating systems, you already know the most basic ways of running an application from a graphical desktop. X, however, provides a much more flexible environment for running native Linux applications.
