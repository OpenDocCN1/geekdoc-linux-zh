```
# webalizer
```

If all goes well, the command should run for a few moments and exit silently. Based on the information in the /etc/webalizer.conf file, the /var/log/httpd/access_log file is read and an index.html file is copied to the /var/www/html/usage/ directory. You can view the output by opening the file in any browser. For example, you can type the following in the location box:

```
http://localhost/usage
```

The output report shows a 12-month summary of Webalizer activity. On the bar chart, each month a blue bar represents the number of hits on the Web site, a dark blue bar shows the number of different files, and a light blue bar shows the number of pages opened. It also shows data for the number of visitors and the number of sites visited in the right column. The amount of data transferred, in kilobytes, is displayed as well.
