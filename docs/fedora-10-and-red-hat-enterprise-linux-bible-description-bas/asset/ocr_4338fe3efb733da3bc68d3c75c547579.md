Scalable Vector Graphics (SVG) format — an open standard from the W3C (http://www.w3.org/Graphics/SVG). Thousands of SVG graphics and clipart elements are available in the public domain or under Creative Commons licenses.

In Fedora, install the inkscape package to get Inkscape. I recommend you install the openclart package, which will give you hundreds of clipart items to use in your Inkscape creations. With the inkscape and openclart packages installed, select Applications -> Graphics $ightarrow$ Inkscape Vector Graphics Editor to open an Inkscape window.
