At this point, you can use the MySQL Administrator window to find information about your MySQL server, backup and restore data, or select Catalogs to display information about each database. You can select the Health option to all kinds of information about activity and usage of your mysql server. # Configuring the MySQL Server

Like most server software in Fedora and RHEL, the MySQL server relies on a startup script and a configuration file to provide the service. Server activities are logged to mysqld.log file in the /var/log directory. There are also mysql user and group accounts for managing MySQL activities. The following sections describe how these components work together.

> TIP: For many of the steps described in this section, the MySQL daemon must be running. Starting the server is described in detail later in this chapter. For the moment, you can start the server temporarily (root, type service mysql start). Then add a password, as shown in the next section.

# Using user/group accounts

When the MySQL software is installed, it automatically creates a mysql user account and a mysql group account. These user and group accounts are assigned to MySQL files and activities. In this way, someone can manage the MySQL server without needing to root permission.

The mysql user entry appears in the /etc/password file as follows:

```
mysql:x:27:MySQL Server:/var/lib/mysql:/bin/bash
```

The mysql entry just indicates that the UID and GID for the mysql user are 27. The text identifying this user account is MySQL Server. The home directory is /var/lib/mysql and the default shell is /bash. The home directory identified will contain directories for each table of data you define for the MySQL server.

The group entry for mysql is even simpler. The following entry in the /etc/group file indicates that the mysql group has a group ID (GID) of 27.

```
mysql:x:27:
```

If you care to check the ownership of files associated with MySQL, you will see that most of these files have mysql assigned as the user account and group account that each file. This allows daemon processes that are run by the mysql user to access the database files.
