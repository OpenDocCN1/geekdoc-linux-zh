+   Add an administrative e-mail address where someone can contact you in case an error is encountered with your server. In the /etc/httpd/httpd.conf file, the default administrative address appears as follows:

```
ServerAdmin root@localhost
```

Change root@localhost to the e-mail address of your Apache administrator.

+   Start the http server. As root user, type the following:

```
# service httpd start
```

If all goes well, this message should appear: Starting http: [OK]. Now you're ready to go.

+   To make httpd start every time you boot your system, run the command as root:

```
# chkconfig httpd on
```

+   To make sure the Web server is working, open Firefox (or another Web browser) and type the following into the location box and press Enter:

```
http://localhost/
```

+   You should see the Test Page for the Apache server, as shown in Figure 21-1. To access this page from another computer, you will need to enter your Apache server's host name or IP address.
