CAUTION: Some people add the current directory to PATH by adding a directory identified simply as a dot (.), as follows:

PATH=::$PATH ; export PATH
This lets you run commands in your current directory (which people may be used to if they have used DOS). The security risk with this procedure is that you can be in a directory that contains a command that you don't intend to run from that. For example, a malicious person could put an ls command in a directory, instead of listing the content of your directory, does something.

+   - WHATEVER — You can create your own environment variables to provide shortcuts in your work. Choose one name that is not being used and assign a useful value to it. For example, if you do a lot of work with files in the /work/time/files/info/memos, you could create the following:

```
M=/work/time/files/info/memos ; export M
```

You can make your current directory by typing cd $M. You can run a program called hotdog by typing $M/hotdog. You can edit a file called bun by typing vi $M/bun.

# Adding aliases

Setting aliases can save you even more than setting environment variables. With aliases, you can bind a string of characters to execute an command line. You can add and list aliases with the alias command. Here are some examples:

```
alias p='pwd ; ls -CF'
alias rm='rm -i'
```

In the first example, the letter p is assigned to the run command pwd, and then to run ls -CF to print the current working directory and list its contents in column format. The second returns the rm command with the -i option each time you type rm. This is an alias that is set automatically for the root user, so that instead of removing files, you are prompted for each individual file removal. This prevents you from removing all files in a directory by mistakenly typing something such as rm *.

While you are in the shell, you can check which aliases are set by typing the alias command. If you want to remove an alias, you use unalias. (Remember that if the alias is set in a configuration file, it will be set again when you open another shell.)
