NOTE: The Trial File Protocol server (ftp-server package), which is distributed with Fedora and RHEL systems, can also be used to provide FTP service. The ftp daemon is primarily used to provide support for disk devices, which gather the files they need to boot and run from a TFTP server. TFTP is not intended for general, public FTP service. Because FTP is a security risk to use publicly, it is generally used on private LANs that are not accessible to public networks. Other FTP server package now available from the Fedora repository ProFTPTP (http://proftpd.org) and Pure-FTPD (http://pureftpd.org).

Red Hat, itself uses vsTP on its own FTP servers (ftp.redhat.com). Other organizations in the open source software world have also made the switch to vsTPD, including Debian Linux (ftp.debian.org), OpenBSD (ftp.openbsd.org) and the GNU Project (ftp.gnu.org).

Beyond security and scalability, vsTPD was designed for simplicity. Therefore, fewer options exist for configuring vsTPD that you find in WU-FTPD, an older FTP server package that is commonly used, so you are expected to run on standard Linux file and directory permissions to provide refined access to your server. Getting started with vsTPD, using it to replace WU-FTPD, is fairly straightforward.

> NOTE: Although vsTPD is the recommended FTP software in Fedora and RHEL, the WU-FTPD FTP server software, which was once part of Red Hat Linux, is still available on the Web. However, WU-FTPD is considered to be far less secure than vsTPD and, therefore, not be used in most cases.

# Quick-starting vsFTPD

By enabling the vsFTPD service, you can almost instantly have an FTP service running with the default values (set in the /etc/vsftpd/vsftpd.conf file). The following is a quick procedure for getting your FTPD server up and running. In case you didn't install vsFTPD, install it by typing:

```
# yum install vsftpd
```

Here's how to start and try out the vsFTPD service.

+   1. To use the vsFTPD server, you must make sure that the vsFTPD software package is installed.

```
# rpm -q vsftpd
```

+   2. Enable the vsFTPD server by typing the following line (as root user):

```
# chkconfig vsftpd
```

+   3. Start the vsFTPD server as follows:

```
# service vsftpd
```
