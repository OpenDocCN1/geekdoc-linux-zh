# Redirecting requests for old content

As content changes on your Web server, some content will become obsolete while other content may move to a different place in the file system or to a different server. Using the Redirect directive, you can redirect requests for old content to new locations.

By default, there are no Redirect directives for your Apache server. However, you can uncomment the following example and tailor it to your needs:

```
# Redirect permanent /foo http://www.example.com/bar
```

Redirect can be used to instruct clients that the document they seek has moved elsewhere (the same server or an external location) by simply indicating the old and new locations. If the previous Redirect option was in place, a client's attempt to access http://www.mybox.com/ would redirect to http://www.example.com/bar.

Besides using permanent as the service for Redirect (which results in a redirect status 301), you could use temp (a redirect status of 302), seeother (a replaced status of 303), or gone (a permanently removed status of 401). You could also use any status code between 300 and 399 as the service, which represent different error responses. (These are HTTP status codes).

> CROSS REFERENCE: The HTTP status codes are defined as part of the HTTP protocol in RFC 2616. Refer to that document at www.w3.org/Protocols/rfc2616/rfc2616.txt.

# Defining indexing

It's possible to have your Apache server show different icons for different types of files. To use this feature, IndexOptions should be set to FancyIndexing, and AddIconEncoding, AddIconByType, and AddIcon directives should be:

```
# Directories controlling display of server-generated directory listings.
# FancyIndexing is whether files containing version numbers should be
# pareled in the natural way, so that 'apache-1.3.9.tar' is placed
# before 'apache-1.3.12.tar'.
IndexOptions FancyIndexing VersionSort NameWidth*=HTMLTable
# AddIcon* directives tell the server which icon to show for different
# files or filename extensions. These are only displayed for
# FancyIndexed directories.
```

```
AddIconEncoding(CMP,/icons/compressed.gif) x-compress x-gzip
AddIconByType(TXT,/icons/text.gif) text/*
AddIconByType(IMG,/icons/image2.gif) image/*
```
