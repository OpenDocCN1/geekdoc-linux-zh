> NOTE: When you begin setting user quotas, keep track of the total amount of disk space that can be consumed by the users you assign. Although quotas can limit how much each user can consume, it doesn't prevent your system from running out of disk space when the total amount of disk space exceeds the total amount available.

The procedure spans the next few assumptions that you have a separate /home partition on your computer for which you may create quotas. You could use any partition, not just the /home partition shown in the procedure. For example, if you have only one partition mounted at the root of the system (/), you could set quotas for your entire file system by replacing /home with / in the following example.

## Editing the /etc/fstab file

You need to add usquota option to support the file system. To do that, edit the /etc/fstab file and add the usquota option to field number four of the partition for which you want to set quotas. Here is an example of a line from /etc/fstab:

```
/dev/sda2 /home  ext3 defaults,usquota,grpquota  1 2
```

Here, the file system is used to allow disk quotas for all users /home directories in the /home directory.

Before the usquota option can take effect, the file system must be reloaded. This happens automatically when you reboot, which you will have to do if you are setting quotas for the root (/) system. You might be able to use the ummount and mount commands to cause the usquota option to take effect or run mount with the remount option.

## Creating quota files

You need to have aquota.user and/or aquota.group files in the root directory of the partition on which you want to establish disk quotas. To add quotas based on individual users, you need an aquota.user file, while aquota.group is needed to set quotas based on groups. One way to create these files is with the quotacheck command. Here's an example of a quotacheck command to create an initial aquota.user file:

```bash
# quotacheck -c /home
```

A /home/aquota.user file is created from the previous command. (To create an initial aquota.group file, type touch /home/aquota.group.) Next, you must create the disk usage table for the partition. Here's an example of how to do that:

```bash
# quotacheck -vug /home
```

The quotacheck command in this example looks at the file system partition mounted on /home and builds a table of usage. The -v option produces verbose output from the command, the -u option causes user quotas to be examined, and the -g option causes group quotas to be examined.

## Creating a quota startup script

If the quota package doesn't include a startup script (and it doesn't with the current Fedora RHEL distributions), you can create your own. This script to check quotas (quotacheck command), start the quota service (quotaon command), and turn off the service (quotaoff command).

Open a new file called /etc/init.d/quota as root user, using any text editor. Here is an example of the content you can add to that file:

```bash
#!/bin/bash

# init file for quota
#
# description: Checks disk quotas
#
# processname: quota
# chkconfig - 90 90
# source function library
# /etc/rc.init.d/quota

case "$1" in
  start)
    echo -n "Checking quotas:"
    daemon /sbin/quotacheck -avug
    echo
    echo -n "Starting quotas:"
    daemon /sbin/quotaon -avug
    echo
    ;;
  stop)
    echo -n "Shutting down quotas:"
    daemon /sbin/quotaoff -a
    echo
    ;;
  restart)
    $0 stop
    $0 start
    ;;
  *)
    echo "Usage: quota {start|stop|restart}"
    exit 1
esac

exit 0
```

The quota script, when started, first runs the quotacheck command to check all file systems for which quota checking is on. Then it turns on quota checking with the quotaon command.
The line # chkconfig - 90 90 identifies the names assigned to the startup script.

### Creating quota rules

Instead of assigning quotas to users, you can assign quotas to any group listed in the /etc/group file. Instead of the -u option to edquota, use the -g option followed by a group name.

To set limits for a user, use the edquota command. Here is an example of how to set limits for jake:

```bash
# edquota -u jake
```

The edquota command allows you to specify the quota limits for a user or group. Here is an example of how to set limits for a group:

```bash
# edquota -g groupname
```

The edquota command allows you to specify the quota limits for a user or group.

## Part III: Administering quotas

### Checking quotas

To report on how much space and how many inodes each user on your computer (for which you have set quotas) has consumed, use the repquota command. Here's an example of the repquota command for reading quota data to all partitions that are using quotas:

```bash
# repquota -a
*** Report for user quotas on device /dev/sda2
Block grace time: 7days: In grace time: 7days
Block limits File limits
User soft | hard | grace used | soft | hard | grace
root -- 1973984 | 0 | 0 | 2506 | 0 | 0
jake -- 1296 | 700 | 1700 6days | 3 | 0
```

In this example, jake has exceeded his soft limit of 700 blocks. He currently has six days in his grace period to remove enough files so that the soft limit does not become the hard limit.
