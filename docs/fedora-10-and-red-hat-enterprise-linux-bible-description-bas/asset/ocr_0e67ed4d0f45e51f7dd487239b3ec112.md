# Finding disk consumption with find

The find command is a great way to find file consumption of your hard disk using a variety of criteria. You can get a good idea of where disk space can be recovered by finding files that are over a certain size or were created by a particular person.

> NOTE: You must be root user to run this command effectively, unless you are just checking your personal files.

In the following example, the find command searches the root system (/) for any files owned by the user name jane (-user jake) and prints the filenames. The output of the find command is then listed with a long listing in size order (ls -lDS). Finally, output is sent to the file /tmp/jake. When you read the file /tmp/jake, you will find all of the files that are owned by user jake, listed in size order. Here is the command:

```
# / -xdev user jake -print | xargs ls -lDS > /tmp/jake
```

> TIP: The -xdev option prevents file systems other than the selected file from being searched. This is a good way to cut out a line of jump that may come from the /proc file system. It could also keep remotely mounted file systems from being searched.

The next example is similar to the previous one, except instead of looking for files, this command looks for files that are larger than 1000 kilobytes (-size +1000k):

```
# / -xdev -size +1000k -print | xargs ls -lDS > /tmp/size
```

You can save yourself a lot of disk space by removing some of the largest files that are no longer needed. Open the /tmp/size file in this example and large files are sorted by size.

# Monitoring System Performance

If your Linux is used as a multiuser, sharing the processing power of that computer can be a major issue. Likewise, anytime you can stop a runaway process or reduce the overhead of an unnecessary program running, your Linux server can do a better job serving Web pages, or e-mail to the people they rely on.

Utilities are included with Linux that can help you monitor the performance of your Linux system. The kinds of systems you want to monitor in Linux include CPU usage, memory usage (RAM and swap space), and overall load on the system. The following sections describe tools for monitoring Linux.
