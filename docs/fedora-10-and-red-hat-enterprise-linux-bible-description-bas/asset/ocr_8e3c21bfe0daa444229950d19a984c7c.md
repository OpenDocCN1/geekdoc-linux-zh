# Using Windows partitions from Linux

With some space available on your disk, when go to install Linux, consider adding a small FAT16 or FAT32 partition (maybe 2GB) on your disk. Every x86 operating system (Linux, Windows 95, NT, 2000, XP, Vista and DOS) supports those types. With that, you will be able to freely exchange files between your Linux and Windows system on the FAT16 partition.

With FAT partitions, keep in mind that there are limitations. FAT16 is limited to between 2GB and 4GB file sizes. Also, FAT16 does not support large files. Total partition size for file systems is 32GB.

After you have installed Linux in the space freed up by the previous procedure, you should be able to choose between Linux and Windows when the Fedora or RHEL boot screen appears during boot time. Press any key to get to the GRUB boot screen. Move the arrow key to choose boot Linux or Windows.

The first time you boot Windows, you might be asked to check your disk (because Windows partition will be a different size than expected). After that, there should be no change in how you use your Windows system. Your disk space will be smaller.

Now, when you boot Linux, if you have a lot of documents, digital images, music, or other content on your Windows partition, you probably will be able to use that content from Linux. To do that, you need:

+   - Determine which partition is your Windows partition.
- If you didn't so during installation, add support for the file system type of your Windows to Linux. Since VFAT is already built in, means adding NTFS support if that is the file system type.
- Mount the Windows partition on your Linux file system.

The following procedure describes how to do those things.

**1. Check partitions.** To determine which partition contains your Windows file system, use the fdisk command as:

```
# fdisk -l

Units = cylinders of 1008 * 512 = 516096 bytes
```
