# TextMaker

TextMaker is another popular commercial word processing package for Linux (http://www.softmaker.com/english/tml_en.htm). This word processor carries much less memory than OpenOffice Writer, but still contains many powerful features. With TextMaker, interchanging documents between different operating systems is easy because there are also versions of TextMaker for Windows, Pocket PCs, Handheld PCs, FreeBSD, and Zaurus.
