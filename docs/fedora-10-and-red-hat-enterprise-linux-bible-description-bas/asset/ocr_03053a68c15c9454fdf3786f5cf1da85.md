+   * The ftp command and other FTP client programs let you log in and operate from a command interpreter (similar to a very simple shell). Many of the commands that you use from command interpreter are UNIX commands. You change directions with cd, list permissions with ls, change permissions your location with pwd (to name a file). When you find where you want to be, you use the get to download a file or the put to upload one.

As an administrator of an FTP server, it is your responsibility to make sure that you share your files in a way that give people access to the information you want them to have without compromising the security of your system. This means implementing a strong security policy and relentlessly monitoring your system to prevent abuse.

# FTP user types

Different types of users can log in and use an FTP server. Real users represent the category of users who have login accounts to the Fedora or RHEL system that contains your FTP server (that is, you know them and given them permission for other uses besides FTP). With vsFTPd (described in the following section), you can configure settings for each real user separately, if you choose.

A guest user is similar to a real user account, except guest user access to the computer's file system is more restricted. The user name anonymous is the most common for providing public (guest) access.

The vsFTPd also supports the concept of virtual users. The recommended method for creating virtual users for vsFTPd is to configure PAM (pluggable authentication modules) to point to per-user configuration files. Sample files for configuring virtual users are included with the vsFTPpd package. Refer to the /usr/share/doc/vsftpd*/EXAMPLE directory for directories containing virtual user example configuration files.

# Using the Secure FTP Server

The Secure FTP Server (vsFTPd) is the only general-purpose FTP server software included in Fedora and RHEL distributions, vsFTPd is becoming the FTP server of choice for sites that need to support thousands of concurrent downloads. It was also designed to secure your systems against most common attacks.
