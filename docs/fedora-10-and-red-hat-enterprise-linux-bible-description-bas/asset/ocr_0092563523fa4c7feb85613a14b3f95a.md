Some of Conqueror's greatest strengths over earlier file managers are the following:

+   Network desktop — If your computer is connected to the Internet or a LAN, features built into Conqueror let you create links to files (using FTP) and Web pages (HTTP) on the network and open them within the Conqueror window. These links can appear as file icons in a Conqueror window or on the desktop. When a link is opened (single-click), the contents of the FTP site or Web page appears right in the Conqueror window. Given proper folder permission, you could drag and drop files to your FTP server in this.

+   Web browser interface — The Conqueror interface works like Firefox, Internet Explorer, or any other browser in the you select files, directories, and Web. You can open Web content by typing Web-style addresses in a Location box.

> TIP: Web pages that contain Java content will run by default in Conqueror. To double-check that Java is supported on, choose Settings -> Configure Conqueror. From the Settings window, click Java & JavaScript and select the Java tab. To enable Java, click the Enable Java Globally box and click Apply. Try a game from Java.com to see if Java is working. If you need a later version of Java Runtime Environment (JRE), you can download it from http://www.java.com/en/download. After downloading the new JRE, change Path to Java Executable to /usr/java/jre1.5.0_02/bin/java to get it to work.
