# ## Using telnet for remote login

Telnet is a service provided by many types of computer systems to enable remote users to log in to their machines over TCP/IP networks. The telnet command is the client program that you use to do the remote login. The most common way to use telnet is with a hostname. The following is a typical session:

```
$ telnet maple
trying 10.0.0.1 ...
Connected to maple.linuxtoys.net 10.0.0.11
Escape character is '^'
Fedora release 9
Kernel 2.6.25-234.fc9 on an i686
login: mike
Password: ********
Last login: Mon Jun 16 13:15:57 from mine
[mike@maple ~]$
```

This example shows what happens when the telnet command is used to log in from a computer named pine to a computer named maple by typing telnet maple. My computer tries to connect to the telnet port on maple (IP address 10.0.0.11). Because maple is also a Fedora system, the connection is established. I see the standard login: prompt. I type the user name (mike) and the password when prompted. When the login and password are accepted, I see the shell prompt for the user named mike.

The telnet service is disabled by default on Fedora and RHEL systems (as are most network services). To be able to log in to your computer using telnet, refer to Appendix B for information on how to turn on the telnet service.

Here are a few options you can use with telnet:

+   - **a — Automatic login.** With this option, your computer attempts to log in the remote computer using your user name. If you are already logged in your computer as mike, when you use telnet to log in to a remote computer, the remote computer assumes you want to log in as mike. It simply prompts you for mike's password.
- **u — User name.** This option is similar to the -a option, except instead of using your current user name, you can log in using any user name you choose.
- **r — Rlogin-style interface.** This option lets you use tilde (~) options. For example, to disconnect from rlogin mode, type ~, (tilde+dot), or to suspend the telnet session, type ~^Z (tilde+carat+z).
