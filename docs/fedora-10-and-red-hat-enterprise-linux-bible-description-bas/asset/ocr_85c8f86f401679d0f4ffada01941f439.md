# Part IV: Fedora RHEL Network and Server Setup

+   **Printer Options** — Click Printer Options to set defaults for options for the printer driver. The available options are different for different printers. Many of these options can be overridden when someone prints a document. Here are a few of the options you might have to select:

+   **Watermark** — There are several Watermark settings that let you add and change watermarks on your printed. By default, Watermark and Overlay are off (None). By selecting Watermark (behind the text) or Overlay (over the text), you can set the other Watermark settings to determine how watermarks and overlays are done. Watermarks can go on every page (ALL) or only the first page (First Only).
Select Watermark to choose what words are used for the watermark or overlay (Draft, Copy, Confidential, Final, and so on). You can then select the font type, size, style, and intensity of the watermark or overlay.

+   **Resolution Enhancement** — You can use the printer's current settings or choose to turn resolution enhancement on off.

+   **Page Size** — The default is U.S. size, but you can also add the printer to print legal size, envelopes, ISO A4 standard or other page sizes.

+   **Media Source** — Choose which to print from. Select Tray 1 to insert pages manually.

+   **Levels of Gray** — Choose to use the printer's current levels of gray or have enhanced standard gray levels turned on.

+   **Resolution** — Select the default printing resolution (such as 300, 600, or 1,200 dots per inch). Higher resolutions result in better quality, but take longer to print.

+   **EconoMode** — Either use the printer's current setting or choose a mode where you save time or one which has the highest possible quality.

+   **Job Options** — Click the Job Options item to set common default options that will be used for this printer if the application printing the job doesn't already set them. Include Common Options (number of copies, orientation, scale to fit, and pages per side), Image Options (scaling, saturation, hue, and gamma), and Text Options (characters/inch, lines, and margin settings).

> NOTE: For a description of other driver options, refer to the CUPS Software User Manual (/usr/share/doc/cups-*.html) under the Standard Printer Options heading.

Click Apply or OK when you are satisfied with the changes you made to the local printer. To make this printer the default, right-click the printer icon in the Main Printer configuration window and select As Default. The default printer's icon shows a green check mark.
