+   * Selectively block ads (Adlock) — Using Adblock, you can selectively prevent ads from being displayed on the Web pages. With Adblock installed, Adblock appears on the lower-right corner of Firefox. Click that to see a window containing items on the current page you want to block. Right-click on an image and select Adblock Image to choose that image to block. Use an asterisk to block all content from a particular site (for example, www.example.com/). Open the Adblock preferences from Firefox → Adblock → Preferences to see, edit, or remove blocked sites. With Firefox 1.5 or later, you should use Adblock instead of Adblock.
* Access FTP servers (FireFTP) — Contains a client application that runs in Firefox for accessing with FTP servers. There is also a FireFTP button add-on for accessing from the toolbar.
* Block animations (Flashblock) — Prevent animations from playing in your Firefox browser window. Can be particularly useful for dial-up users who don't want a performance hit when a visited site tries to play unrequested Flash content.

+   * Improve browsing (Tabrowser Preferences) — Although Firefox already gives you some features for tabs to keep multiple Web pages open in the Firefox window, Tabrowser Preferences takes these features a step further. Select Edit tabs work in Firefox. You can set motion selects tabs (such as mouse-over as opposed to clicking), put tabs on the bottom of the top, or choose whether or not to load the page in a new tab.

+   * Watch your weather (ForecastFox) — With ForecastFox, the latest weather for your region can be just a click away in Firefox. After you install ForecastFox and restart Firefox, a pop-up window enables you to configure ForecastFox options. Select at least Code, choose the area where you want to keep on weather. Save your options and a weather icon in the lower-right corner of Firefox. Move your mouse over icon to see a quick view of the current weather. Double-click the icon to have a more detailed weather report displayed from http://www.weather.com.

After you have installed an add-on, you need to restart Firefox for it to take effect. In some cases, a add-on will also require you to restart Firefox.

If you want to uninstall an add-on, change an add-on's options, or get more adds-ons, select Tools → Add-ons from Firefox. The window that appears shows you a list of installed add-ons and lets you change them. Select Browse All Addons to go directly to the Mozilla Firefox Add-ons page.
