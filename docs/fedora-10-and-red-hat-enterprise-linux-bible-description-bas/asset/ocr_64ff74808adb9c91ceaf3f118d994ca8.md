# Basic Linux Gaming Information

There are more than 200 software packages in the Games group in the Fedora software repository. So if you are just looking for a few diverting or old commercial games that are now publicly available, you can start by looking within that repository. However, if you are interested in learning about more new games that run in Linux, or finding out about the general state of Linux gaming, there are several sites on the Web you should check out.

# Where to get information on Linux gaming

To find news of the latest games available for Linux, as well as links to download sites, go to some of the Web sites available. Here are a few to get started:

+   * TransGaming Technologies (http://www.transgaming.com) — This company's mission is to bring games from other platforms (Windows) to Linux. TransGaming is the provider of Cega, formerly known as WineX, a powerful tool that allows you to play hundreds of PC games on your Linux system.

+   * The Linux Game Tome (http://happyppenguin.org) — This site features a database of descriptions and reviews of games that run on Linux. You can keyword search for games listed at this site. The site also includes links to where you can get the different games, as well as links to other gaming sites.

+   * Linuxgames.com (http://www.linuxgames.com) — This site can give you very good insight into the state of Linux gaming. There are links to HOW-TOs and Frequently Asked Questions (FAQs), as well as forums for discussing Linux games. There are also links to Web sites that have information on particular games.

+   * Wikipedia (http://en.wikipedia.org) — In the past few years, Wikipedia has become a wonderful resource for information on both commercial and open source games available for Linux. From Wikipedia, there is a list of open source games (http://en.wikipedia.org/wiki/List_of_open_source_games) and a general Linux games page (http://en.wikipedia.org/wiki/Linux_games).

+   * id Software (http://www.idsoftware.com) — Linux versions of Doom 3, the Quake series and Return to Castle Wolfenstein from id Software.

+   * Garage Games (http://www.garagegames.com) — Garage Games is a site that publishes games from independent game. Many of the games sold at the Garage Games store (http://www.garagegames.com/pj) have ports of games specifically for Linux.

+   * Linuxgamepublishing.com (http://www.linuxgamepublishing.com) — A relatively new entrant into the Linux gaming world, linuxgamepublishing.com aims to be a one-stop portal for native Linux games, as well as for ports of games from other platforms. At this time they offered 28 games. Note that to purchase games from this site, you must create a user account.
