Another browser comes with Fedora is the Konqueror browser/file manager. The Mozilla suite was renamed SeaMonkey and is available with Fedora in the seamonkey package.

Relatively new ways for gathering content from the Web include RSS news feed readers, such as the lifera RSS/RDF feed reader. There are also several browsers, such as lynx and w3m, that can run from the command line (with no graphical interface required).

+   **E-mail clients** — The Evolution of e mail has evolved into a full-fledged groupware suite, combining an mail reader for managing contacts, calendars, and tasks, as well as connecting to Microsoft Exchange servers. Thunderbird is an up-coming email client from the Mozilla project SeaMonkey mail is also available from the same organization). For those who prefer old-school email readers, mitt, and mail commands let you read mail from the command line, with limited abilities to handle attachments, HTML, or other modern e-mail features.

+   **FTP** — Use the FTP protocol to download files from FTP servers, or to upload pages to your server, graphical tools for doing tasks include the gFTP and kget Applications. There are also many commands available for accessing FTP servers to look for, download files, or upload files. Those commands include ftp, nceftp, and tftp.

+   **BitTorrent clients/servers** — BitTorrent is the popular open source project for sharing many files at the same time. With BitTorrent, you can simultaneously upload download a file to same others. BitTorrent is particularly useful for publishing CD or DVD images containing large size distributions (such as Fedora) the minute they become available, without overstress the original servers releasing the software.

+   **Instant messaging and chats** — Typing live messages to friends, family, and associates has become a popular activity in recent years. Pidgin is an instant messaging client that lets you to AIM, IRC, MSN, Google, and IC servers. XChat is a popular Internet Relay Chat (IRC) client (a protocol among Linux enthusiasts for online chats). Kopete is an instant messaging client that integrates with a KDE desktop.

+   **Remote commands (login, file copy, and so on)** — As you spend more working time with Linux, you will find that it is often quicker and more convenient to run commands that is to run graphical applications. Some very powerful command-line tools exist in Linux for doing such as remote login and remote execution (ssh) and remote file copy (wget, sc, rsync).

> NOTE: Besides the applications mentioned here, more Internet-enabled applications are described in other parts of the book. For example, music players and video players described in Chapter 8 can grab audio and video files or streaming media from the Internet. Likewise, software installation tools such as yum are made to get software from software repositories on the Internet.
