To experiment with virtual hosts, you can add the new host name to your local /etc/hosts file and point at your localhost IP address. For example:

```
127.0.0.1               www.linuxtoys.net
```

If you see the content you set up for your virtual host, and not the Fedora error or default content you set up, then you probably set up your host properly.

# Configuring modules and related services (/etc/httpd/conf.d/*)

Any module that requires special configuration (.conf file) in the /etc/httpd/conf.d/ directory. Here are popular configuration files that might be contained in there, along with some ways of using those files and the packages associated with them (use yum install package to install each package you want):

+   * auth_kerb.conf— Configure Kerberos authentication over a Web (HTTP) connection. The example in this file suggests Kerberos authentication over an SSL connection. (Install the mod_auth_kerberos package.)

+   * auth_mysql.conf— Configure authentication based on data you add to a MySQL database. The comments in the file describe how to set up the database and use it to your user or group authentication before allowing a client to access your Web content. (Install the mod_auth_mysql package.)

+   * auth_pgsql.conf— Configure authentication based on a PostgreSQL database. (Install the mod_auth_pgsql package.)

+   * auth_idap.conf— Configure authentication to access an LDAP database to authenticate users. (Install the mod_authz_ldap package.)

+   * htdig.conf— Identify the location of the hdig search content that can be used on your Web site (/share/htdig is the default location). To see the hdig search results from a browser, type http://localhost/htdig. The hdig system lets you use tools for indexing and searching your Web site or content online. It is optional for your Web server. (Install the htdig-web package.)

+   * mailman.conf— Set up mail list server software to allow features such as making mailing-lists archives available from Apache. (Install the mailman package.)

+   * manual.conf— Defines the location of Apache manuals (/var/www/manual/) on the server for different languages. Type http://localhost/manual in a browser window. (Install the httpd-manual package.)

+   * mrtg.conf— Defines the location of daily mrtg output (/var/www/mrtg), which tracks network traffic. Type http://localhost/mrtg in a browser. (Install the mrtg package.)

+   * perl.conf— Identifies and loads the mod_perl module so that your Web pages can include Perl code. (Install the mod_perl package.)
