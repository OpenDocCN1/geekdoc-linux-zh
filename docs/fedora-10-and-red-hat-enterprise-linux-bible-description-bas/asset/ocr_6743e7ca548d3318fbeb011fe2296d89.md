```
socket=/var/lib/mysql/mysql.sock
user=mysql
# Default to using old password format for compatibility with mysql 3.x
# clients (using the mysqlclient10 compatibility package)
old_passwords=1
[mysql_safe]
log-error=/var/log/mysql.log
pid-file=/var/run/mysql/mysql.pid
```

Most of the settings in the default my.cnf file define the locations of files and directories needed by the mysql server. Each option is associated with a particular group, with each group identified by a name in square brackets. The particular options are associated with the mysql daemon ([mysql]) and the safe_mysql script that starts the mysql daemon ([mysql_safe]). (Refer to Table 24-1 for a list of these groups.)

The datadir value indicates that /var/lib/mysql is the directory that stores the MySQL databases you create. The socket option identifies /var/lib/mysql/mysql.sock as the socket that is used to create the MySQL communications end-point associated with the mysql server. The user option identifies the mysql user as has permission to do administration of the MySQL service. Based on the old_passwords=1 value, your MySQL database will use the password format used in MySQL 3.x.

The log-error and pid-file options specify the locations of the error log (/var/log/mysql.log) and the file that stores the process ID of the mysql daemon when it is running (/var/run/mysql/mysql.pid). The safe_mysql script actually starts the mysql daemon from the mysql startup script.

> NOTE: Each option follows a group name assigned to that group. Group assignments end when a new group begins or when the end of a file is reached.

# Choosing options

Many values used by the MySQL server that are not explicitly defined in the my.cnf file. The easiest way to find which options are available for MySQL server and clients is to run each command with the --help option. For example, to view the available mysql options (as well as other information) type the following from a Terminal:

```
# /usr/libexec/mysql --help | less
```

Then press Space to find the information one screen at a time. (An example of this output is shown in the next section.)

You can also use the man command to find which options are available. For example, to see which options are available to set for the mysql daemon, type the following:

```
man mysql
```
