You find the following in each field of the fstab file:

+   Field 1 — The name of the device representing the file system. The word name is often placed in this field for file systems (such as /proc and /dev/pts) that are not associated with special devices. Notice that this file can now include the LABEL or UUID options. Using UUID, you can identify universally unique identifier (UUID). LABEL identifies a volume label instead of a device name. The advantage approach is that, since the partition is identified by volume name, you can move a volume to a different device name and not have to change the fstab file.

+   Field 2 — The mount point in the file system. The file system contains all data from the mount point down the directory tree structure, unless another file system is mounted at some point beneath it.

+   Field 3 — The file system type. Valid file system types are described in the “Supported file systems” earlier in the chapter.

+   Field 4 — The options to the mount command. In the previous example, the auto option prevents the indicated file system from being mounted at boot time. Also, ro which is reasonable for a CD-ROM drive). Commas must separate options. See the mount command manual page (under the -o option) for information on supported options.

> TIP: Normally, only the root user is allowed to mount a file system using the mount command. However, to allow any user to mount a file system (such as a file system on a floppy disk), you could add the user option to Field 4 of /etc/fstab.
