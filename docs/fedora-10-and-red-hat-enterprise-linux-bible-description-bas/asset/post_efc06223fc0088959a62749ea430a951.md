## Administering Your Linux System

Your Linux administrator duties don't end after you have installed Fedora or RHEL. Your ongoing job as a Linux system administrator includes the following tasks:

- **Configuring hardware** — When you add hardware to Fedora or RHEL computer, that will be automatically detected and configured by tools such as HAL. In those cases where the hardware was not properly set up, you can use commands as ismod, modprobe, insmod, and rmod to configure the right modules to get the hardware working.

- **Managing file systems and disk space** — You must keep track of the disk space being consumed, especially if your Fedora or RHEL system is shared by multiple users. At some point, you may need to add a hard disk or track what is eating up your disk space (you can use commands like find, du, and df to do this).

- **Monitoring system performance** — You may have a run-away process on your system or you may be experiencing slow performance. Tools that work with Fedora and RHEL can help you determine how much of your CPU and memory are being consumed.

The aforementioned administrative tasks are described in the rest of this chapter. Other chapters cover other administrative topics, such as managing user accounts (Chapter 11), automating system tasks (Chapter 12), system backups and restores (Chapter 13), and securing your system (Chapter 14). Tasks related to network and server administration are covered in Chapters 15 through 26. Ways of getting updates to your Linux software (using the Add/Remove Software window and yum command) are described in Chapter 5.

## Configuring Hardware

For many hardware items that you attach to your computer, Linux will simply detect them and configure them. During system boot, the kernel will probe and identify your IDE drives, SCSI drives, PCI cards, and other devices. After Linux is running, USB devices that plug in (such as pen drives or digital cameras) will be detected and any file systems they contain will be automatically mounted.

The following section describes how to add and reconfigure hardware in Linux. This includes sections on configuring your hardware, HAL (for detecting and configuring hardware) and commands for working with loadable modules when hardware isn't being detected and properly configured.

## Checking your hardware

Sometimes the fact that Fedora or RHEL can't properly detect and configure your hardware may make it impossible for you to install Linux. In those cases, I suggest you try to determine what hardware you have before you install. See Chapter 2 for information on checking your hardware before installing Fedora or RHEL (you can try the bootable Fedora live CD that comes with this book to test your hardware).

## Managing Hardware with HAL

## Reconfiguring hardware with kudzu

Prior to the move to HAL, kudzu was the tool used to manage hardware configuration. In older versions of Fedora, kudzu ran at boot time and checked hardware against a saved configuration. Kudzu allowed you to reconfigure your hardware when it detected new devices.

To run kudzu, either reboot (during the reboot, kudzu is run automatically) or simply run the kudzu command (as root user from the shell). For any hardware that has been added or removed since the last time kudzu was run, you are asked if you want to configure it, not configure it, or do nothing.

The following is a list of what kudzu does:

1. It checks the hardware connected to your computer.
2. It compares it to the database stored in /etc/sysconfig.
3. It alerts you to hardware added or removed.

The following is a list of actions taken when a device is added:

- Network — Adds an Ethernet interface (eth0, eth1, and so on).
- SCSI — Adds aliases for scsi_hostadapter.
