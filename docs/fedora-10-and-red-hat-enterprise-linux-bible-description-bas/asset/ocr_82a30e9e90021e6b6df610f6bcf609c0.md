# Managing File Systems and Disk Space

File systems are organized in a hierarchy, beginning from root (/) and continuing downward in a structure of directories and subdirectories. As administrator of Fedora or RHEL system, it is your duty to make sure all the disks that represent your file system are available to the users of the computer. It is also your job to make sure there is enough disk space for the file system to store what they need.

File systems are organized differently in Linux than they are in Windows operating systems. Instead of drive letters (A:, B:, C:) for each local disk, network file system, CD-ROM, or other type of storage medium, everything fits neatly into the the directory structure. For hard drive partitions, it is up to an administrator to create a mount point in the file system and then connect the disk to the point in the file system. For removable media (such as CD, DVD, USB flash drives, or digital cameras), mount points are automatically created and connected (in the /media directory) when those items are connected or loaded.

> CROSS-REFERENCE: Chapter 2 provides instructions for using Disk Setup (or Disk Druid) to configure disk partitions. Chapter 4 describes how the Linux file system is organized.

The organization of your file system when you install Linux. Part of the process is to divide your hard disk (or disks) into partitions. Those partitions can be assigned to:

+   - A part of the Linux system
- Swap space for Linux, or
- Other file system types (perhaps containing other bootable operating systems)

For our purposes, we want to focus on partitions that are used for the Linux file system. To see what partitions are currently set on your hard disk, use the fdisk command as follows:

