
# Installing the kickstart file

Once the ks.cfg file is created, you need to put it somewhere accessible to the computer doing the installation. Typically, you will place the file on a floppy disk. However, you can also put the file on a computer that is reachable on the network or on a hard disk.

To copy the file to a floppy disk, create a DOS floppy and copy the file as follows:

```bash
# mcopy ks.cfg a:
```

When you do the kickstart installation, this floppy will work with you. As an alternative, you can copy the ks.cfg file to a hard disk partition, CD drive, Web server, or NFS share.

Being able to place the ks.cfg file on a computer on the network requires a bit more configuration. The network must have DHCP or BOOTP server configured that is set up to provide network information to the new installer. NFS server containing the ks.cfg file must export it so that is accessible to the computer installing Linux. You can use a ks.cfg file from the hard disk, you can place the file on any partition that is Windows (VFAT) or Linux (ext3) partition.

If kickstart (ks.cfg) has been created and installed in an accessible location, you can start kickstart installation. Here is an example of how you can do kickstart installation using Fedora DVD and a floppy containing ks.cfg:

1. Insert the Fedora DVD and restart the computer.
2. When you see the boot screen, insert the floppy containing ks.cfg, highlight the first entry and press the Tab key. When the boot line appears, modify it to the following: `ks=floppy`
3. Remove the floppy; then press the Spacebar to restart your computer (the DVD should eject automatically).

You should see messages about formatting the file system and reading the package list. Packages should install without any intervention. Next you will see a post-install message. Finally, you should see the Complete message.

TIP: You can install using kickstart over NFS (`ks=nfs:server/path/ks.cfg`), from Web server (`ks=http://server/path/ks.cfg`), or from your hard drive (`ks=hd:device:/ks.cfg`).

# Special Installation Topics

Some things that you run during installation not everyone needs, I have included instructions in this section to address issues such as setting up dual-boot Linux and Windows, partitioning, and boot loaders.

# Setting up dual-boot Linux and Windows

It is possible to set up your computer so that you can have two (or more) operating systems installed on it. When you power up your computer, you may choose which operating system you want to boot. This setup is referred to as dual-boot.

If a Windows operating system was installed on your PC, it is likely that the entire disk is devoted to Windows. Fedora installation procedures retain existing partitions by default, but they don't take space from existing disk without destroying them. If you want to be able to run Linux on that machine, you will need to do one of the following:

- Erase the disk. If you wanted Windows partitions in the first place (or if Windows is badly broken), you may decide to completely erase it. In this case you won't have dual-boot system, but you can jump right to Fedora installation.
- Add a second disk. This lets you maintain Windows installation without having to potentially resize your Windows partitions. Refer to Chapter 10 for information on adding a second disk.
- Resize your Windows partitions. Many people choose this route for dual-booting Windows and Linux. If done successfully, you don't have to add hardware and can keep your Windows system.

The rest of this section is devoted to discussion and procedure for resizing your Windows partitions to create a dual-boot computer with Windows and Linux.

# Resizing your Windows partitions

By resizing your Windows partitions you can free up disk space that can be used for Fedora or RHEL installation. Because there is some danger in resizing your disk and changing how your computer boots, you should carefully read the Caution that follows.

# Chapter 2: Installing Fedora

CAUTION: Setting up a dual-boot system is discouraged by Red Hat and people who use Linux because something goes wrong you lose all your data or make your computer unbootable (usually temporarily). New users often won't have a backup and will simply erase their hard disk if the computer won't boot after process. They complain a lot. So, I officially recommend against setting up dual-boot system, telling you how to do it.

Red Hat, Inc. encourages you to use VFAT file systems for your Windows partitions if you plan to boot your computer with Linux. Fedora also offers support for NTFS type. You can use tools from Fedora to resize your Windows partitions. Note that FAT32 partitions can only have a maximum size of 32GB.

If, after resizing your partitions and installing Fedora or RHEL, your computer becomes unbootable, refer to the "Troubleshooting Installation" section later in this chapter for advice on how to.

Before you begin resizing your Windows system and do the following:

- Back up your data! Of course, you should always have a backup of your important data. Now is a particularly good time to do a backup, just in case of those catastrophes you are about.
- Defragment your disk. Before you resize your hard disk, use a defragmenting utility in Windows to have all files stored on the disk. That way, when you are freeing space to Linux partitions, you will have a continuous area of the disk to work with. To defrag a disk in Windows XP, click Start -> All Programs -> Accessories -> System Tools -> Selecting Defragment from the Defragmenter window. Defragmenting can take a while, depending on your processor speed and disk size.

While you have the Disk Defragmenter window displayed, note a few things about your hard disk that you will need to know:

- File System The file system type will most likely be NTFS, although it may also be VFAT. If you have the option to install Windows from scratch, selecting VFAT as the file type will work much better for Linux. Support for writing to NTFS has been considered unreliable from Linux, although reading from NTFS seems to work well. VFAT file systems will work well for both Linux and Windows.
- Free Space If your hard disk consists of a single Windows partition, you can resize your existing partition to use some of the free space to assign to Linux partitions. Note the amount of free space you have here and compare it to the amount you will need to install Linux (described earlier).

Despite the fact that I have successfully resized NTFS partitions using the GParted utility, I still recommend caution (a good backup of your data) before proceeding. If you feel more comfortable using commercial products to resize your partitions, I have listed a few of those below. I have not tested the products so I name them here only because I have good reports of success from others:

# Part I: Getting Started in Fedora and RHEL

- **Partition Magic**: I've heard good reports from people using Partition Magic (http://www.symantec.com/norton/partitionmagic) to resize NTFS partitions. Partition Magic also helps you create new partitions and manage them. It supports Windows Professional/Home, Windows 95b-98SE, Windows 2000 Professional, and NT 4.0 SP6a. The cost is $69.95.
- **Acronis OS Selector**: This is another well-regarded tool for managing, creating, and resizing partitions, which is now included in Acronis Disk Suite. It supports a variety of file systems, including FAT12, FAT16, FAT32, NTFS, and Linux partition types (ext2, ext3 and ReiserFS). It also supports the same Windows platforms that Partition Magic does. The cost is currently $49.99 from http://www.acronis.com.

> NOTE: Earlier releases of Fedora included a FIPS utility for resizing FAT and VFAT file systems. FIPS is no longer included with Fedora or RHEL, so no description of FIPS is included here. A description of FIPS from an earlier edition of this book is at the Wiley site: http://www.wiley.com/fedoraBible.

Microsoft Windows still comes with tools for resizing your partitions. From the Start menu, right-click on Computer and select Manage. In the left pane that appears, select Storage and click Disk Management. Right-click on the window you want to resize and select Extend Volume to change its size.

The open source tool I describe for resizing your disk is called GParted. It can be used to resize partitions that contain a variety of file system types.
