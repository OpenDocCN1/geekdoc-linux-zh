Follow this procedure to connect to an FTP site:

+   1. Type the name of the FTP server where you want to connect (for, example,
   ftp.dulug.duke.edu) into the Host box.
2. Type the port number on the FTP server (you can leave this blank to use the default port
21).
3. Type the user name used to log in to the FTP server. Use the default anonymous if you
   not have a specific user name and the server is publicly accessible.
4. Type the password for the user name you entered. The convention with anonymous FTP
   servers is to use your e-mail address as the password.
5. Click the icon displaying two little monitors to connect to the FTP site.
