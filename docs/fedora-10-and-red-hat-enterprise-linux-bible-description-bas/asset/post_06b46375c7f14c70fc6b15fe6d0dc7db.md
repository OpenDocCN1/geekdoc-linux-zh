## Using OpenOffice.org

Some have called OpenOffice.org a significant threat to Microsoft’s dominance of the desktop market. If there is a need to work with documents in Word format and you are using Linux as your desktop computer, OpenOffice.org is a big step toward removing that obstacle.

> NOTE: If you are willing to pay a few dollars, CrossOffice from Codewavers lets you install and run different versions of Microsoft Office (97, 2000, XP, 2003) from your Linux desktop. See Chapter 5 for further information or check out http://www.codewavers.com/products/cxoffice.

Fedora and RHEL include the entire OpenOffice.org suite of desktop applications. The latest OpenOffice.org version (3.0) is included with this release of Fedora. Based on the StarOffice source code, OpenOffice.org consists of the following office-productivity applications:

- **OpenOffice.org Writer** — A drawing application that can work with documents in file formats from Microsoft Word, StarOffice, and several others. Writer also has a full set of features for using templates, working with fonts, navigating your documents, including images and effects, and generating tables of contents.
- **OpenOffice.org Calc** — A spreadsheet application that lets you incorporate data from Microsoft Excel, StarOffice, Dbase, and several other spreadsheet formats. Some features in Calc allow you to create charts, set up database ranges (easily sort data in an area of spreadsheet), and use the data tool to align data in different points of view.
- **OpenOffice.org Draw** — A drawing application that lets you create, edit, and align objects; include textures and colors; and work with layers of objects. It lets you incorporate images, vector graphics, AutoCAD, and a variety of other file formats into your drawings. Then, you can save your drawing in the OpenOffice Drawing or StarOffice Draw formats.
- **OpenOffice.org Math** — A calculation program that lets you create mathematical formulas.
- **OpenOffice.org Impress** — A presentation application that includes a variety of slide effects. Using Impress, you can create and save presentations in the Microsoft PowerPoint, Draw, and Impress formats.

- *OpenOffice.Base* — A low-end database, similar to Microsoft's Access database. Base can also act as a front-end to other databases.

Unlike other applications that were created with Microsoft document and data formats, OpenOffice.org (although not perfect) does a very good job of opening and saving files from many different versions of Microsoft Word (.doc) and Excel (.xls) formats with fewer problems. Very basic styles and formatting that appear in OpenOffice.org often don't look noticeably different from the way they appear in Microsoft Word. In fact, some older Word documents will actually work better in OpenOffice.org Writer than they do in the latest Microsoft Office suites.

> NOTE: The OpenOffice XML (OOXML) format, a 6,000-page tome, represents Microsoft's recent efforts to claim support for standard document formats. This format is the default document type in Word 2007. Some people in the open source community, however, claim that OOXML is specific in requiring support for Microsoft product features, without providing any guidance in how Microsoft proprietary features can be implemented, that it is unusable as a standard. In other words, don't think that Microsoft is claiming to support standards that you will ever be able to fully use Microsoft documents on platforms.

The controls in OpenOffice.org are similar to the ones you found in Word prior to Word 2007. So if you were comfortable with those controls, you should find it easy to transition to OpenOffice.org Writer. In fact, you might find it easier than using Microsoft Word 2007, since many people have found the transition to Word 2007 difficult.

Toolbars in OpenOffice.org Writer include boxes for identifying filenames, and changing styles, font and types. Buttons allow you to save and print the file, change the text alignment, and cut, copy, and paste text. In other words, Writer includes everything you expect in an advanced word processor. In addition, Writer includes a handy PDF button to output a file to the PDF format. This is very useful for exchanging documents or placing data on the Internet.

If you are just out with OpenOffice.org Writer, here are a few features you can try:

- Use a wizard to start a letter, fax, agenda, presentation, Web page, Document Converter, or Euro Converter. Select File -> Wizards and choose one of the document types you mentioned. The Document Converter Wizard lets you convert a directory of Microsoft or StarOffice to OpenDocument format. The Euro Converter lets convert files containing different European currencies to Euros.
- Document styles and formatting — Create the format of your documents using character, paragraph, frame, page, and numbering styles (select Format -> Styles and Formatting). From the Styles window, choose the type of style you want to change, right-click in the Styles box, and choose to create your own style.
- Checking Documents — Try features for checking and correcting your documents. Writer includes features such as spell checking (Tools -> Spelling and Grammar) and autocorrection (Tools -> AutoCorrect). You can display the content as a Web page or in layout view and find character markup (View -> Nonprinting Characters).
- Drawing and images — Using tools (View -> Toolbars -> Drawing) to create drawings, flows, charts, callouts, or symbols in your documents. Insert background colors or graphics on your pages (Format -> Page, select background tab, and choose color or graphic). To insert a graphic, select Insert -> Picture, and insert the image from a file or from your scanner.
- Outputting PDF or other formats — Writer provides a toolbar that will output your current document to PDF format. PDF is a good format for sharing documents that you want to read or print, but not necessarily to give them the original source file. You can also use Writer to create other formats, including HTML (to publish your document to the Web) or Rich Text Format (to be able to share the document with different word processors).

## Other Word Processors

There are many different word processors available from the Fedora software repository. Popular lightweight word processors such as AbiWord and KOOffice (which is part of the KDE desktop) can now be easily installed with a single yum command the Fedora repository. As for commercial offerings, there is StarOffice from Sun Microsystems and TextMaker.

## StarOffice

The StarOffice productivity suite (http://www.sun.com/staroffice) from Sun Microsystems is a commercial product that runs on Linux, UNIX, and Windows operating systems. StarOffice contains applications for word processing, spreadsheets, presentation graphics, e-mail, news, charts, and graphics. OpenOffice.org, StarOffice contains many features that make it compatible with Microsoft Office applications. In particular, it includes the capability to import Microsoft Word and Excel files.

StarOffice is probably the most complete office suite for Linux. If you are working in a cross-platform environment, you can also get StarOffice for Sun Solaris and Microsoft Windows operating systems. StarOffice includes:

- StarOffice Writer — This is the StarOffice word processing application. You can import documents from a variety of formats, with special emphasis on Word documents.
- StarOffice Calc — This is this program that comes with StarOffice. You can import spreadsheets from Microsoft Excel and other popular programs.
- StarOffice Impress — This module enables you to create presentations.
- StarOffice Draw — This is a vector-oriented drawing program. It includes the capability to create 3D objects and to texturing.
- StarOffice Base — You can manage your data with StarBase, a friendly front end for databases. It can access a variety of database interfaces.

There are also other tools in StarOffice to enable you to create business graphics, raster images, and edit mathematical formulas (StarOffice Math).

You can download StarOffice 8 for Linux or purchase a boxed set from the StarWeb site at http://www.sun.com/software/star/staroffice/. Although StarOffice was once free for download, the current price to download the software for home users is $69.99.

## AbiWord

The AbiWord word processor 8 (abiword command) is a very nice, free word processor from the AbiSource project (http://www.abisource.com). If you are creating documents from scratch, AbiWord includes many of the basic functions you need to create good-quality documents. In addition to working with files in its own format (.abw and .zab), AbiWord can import files in Microsoft Word and several other formats.
