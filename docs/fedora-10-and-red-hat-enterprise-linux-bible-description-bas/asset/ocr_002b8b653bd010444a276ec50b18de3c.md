Any users with local accounts (/etc/passwd) and valid passwords can log into the FTP
server with local_enable set to YES. Exception to this rule is that, by default, all user
accounts in the /etc/vsftpd/user_list file are denied access.

> NOTE: Before you start logging into an FTP server with your personal name and password, keep in
mind that FTP login services use clear text passwords. Because of this fact, a network sniffer is capable of\seeing this. If you want to use an FTP interface to access files on an FTP server using your
personal account, consider using the OpenSSH (http://www.openssh.org/) sftp command
in of a normal FTP client. If the FTP server includes an SSH server, you can use sftp to connect
trough encrypted passwords.

Check the user_list file to see which users are denied access to the vsFTPpd server. Note
that root and administrative logins are excluded. You can add other users to this list or
change the location of the file by setting the user_list parameter to the file you want.
To add a user to the user_list or use the user_list parameter to create a new list,
you also have userlist_enable set to YES (as it is by default). For example:

```
userlist_file=/etc/vsftpd/user_list_local
userlist_enable=YES
```

If you like, you can change the meaning of the /etc/vsftpd/user_list file so that only
the users in that list are allowed to use the vsFTPpd server. Set userlist_deny=NO and
change the /etc/vsftpd/user_list to include only names of users to whom you want to
grant access to the server. All other users, including anonymous and ftp, will be denied
access.

# Setting FTP access

The vsFTPpd server software provides a simple and secure approach to access
permissions. By using settings in the FTP service to selectively prevent downloads and
uuploads of particular directories (as FTP servers as WU-FTPpd do), you can use standard
Linux file and directory permissions to limit access. There are, however, the general
settings in the /etc/vsftpd/vsftpd.conf file to let users get files from and put into
yoursFTPpd server.
