# Other web servers available for Fedora and RHEL

Some other servers that can run on Fedora and other Red Hat distributions are described in the following list, with URLs that provide more detailed information.

+   - lighttppd — The lighttppd web server (http://www.lighttppd.net) is built for security, speed, compliance and flexibility. It is particularly optimized for high performance environments because it has a low footprint and balances cpu-load. Sites such as YouTube, Wikipedia, and meebo have used lighttppd for some web applications.

+   - telchtpd — TheTelThtpd web server (telchtpd package) is included in the Tool Command Language (TCL). Acting as a web server, TelThtpd can also be used in a TCL application server.

+   - httpd — The httpd HTTP server (http://acme.com/software/httpd) was designed to be simple, small, portable, and fast. Its creators call it a tiny, turbo, throttling HTTP server. It implements less than the minimum needed to be HTTP/1.1 compliant, so it can run much faster than many large Web servers under extreme loads.

+   - XSP — The XSP web server (xsp package) can run ASP.NET applications, as well as related services for working with ASP.NET applications.
