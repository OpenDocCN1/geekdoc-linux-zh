This output shows the partitioning for a computer able to run both Linux and Microsoft Windows. You can see that the Linux partition on /dev/sda3 has most of the space available for data. There is a Windows partition (/dev/sda1) and a Linux swap partition (/dev/sda5). There is also a small /boot partition (46MB) on /dev/sda2. In this case, the root partition for Linux is 3.3GB of disk space and resides on /dev/sda3.

Next, to see what partitions are actually being used for your Linux system, you can use the mount command (with no options). The mount command can show which of the available partitions are mounted and where they are mounted.

```
# mount
/dev/sda3 / type ext3 (rw)
/dev/sda2 / boot type ext3 (rw)
/dev/sda1 / /mnt/win vfat (rw)
none / /proc type proc (rw)
none / /sys type sysfs (rw)
none / /dev/pts type devpts (rw,gid=5,mode=620)
none / /dev/shm type tmpfs (rw)
none / /proc/sys/fs/binfmt_misc type binfmt_misc (rw)
/dev/cd0 / /media/recorder type iso9660
ro,nosuid, nodev,uhelper=hal
```

> NOTE: You may notice /proc,/sys,/dev/pts,/proc/sys/fs/binfmt_misc, /dev/shm, and other different types not relating to a partition as file systems. This is because they represent different file system types (proc and devpts, and so on). The word none, however, indicates that they are not associated with a separate partition.

The mounted Linux directories in this case are /dev/sda2, which provides space for the /boot directory (which contains data for booting Linux), and /dev/sda3, which provides space for the rest of the Linux system beginning from the root directory (/). This particular system also contains a Windows partition that was mounted in the /mnt/win directory.

Beginning with Fedora Core 3 and RHEL 4, mount points for removable media (CDs, DVDs, USB pen drives, and so on) moved from /mnt to the /media directory. In this example, an IDE combination CDRW/DVD-ROM drive was mounted on /media/recorder. Most GUI interfaces, the CD or DVD is typically mounted automatically when you insert it. In this example, the uhelper (privileged unmount helper) is assigned to the hold daemon so that the half system can mount the CD as another non-privileged user.

> NOTE: See a description of the GNOME Volume Manager in Chapter 3 for information about removable media are handled in the current Fedora and RHEL releases.
