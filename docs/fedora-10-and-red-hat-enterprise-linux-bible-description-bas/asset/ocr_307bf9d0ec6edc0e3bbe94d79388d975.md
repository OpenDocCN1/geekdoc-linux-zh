# # Rerunning commands

It's annoying, after typing a long or complex command line, to learn that you mistyped something. Fortunately, some features let you recall previous command lines, edit those lines, or complete a partially typed command line.

The shell history is a list of the commands that you have entered before. Using the history command, you can view your previous commands. Then, using various shell features, you can recall individual command lines from that list and change them whenever you please.

The rest of this section describes how to command-editing, how to complete parts of command lines, and how to recall and work with the history list.

# ## Command-line editing

If you type something wrong on a command line, the bash shell ensures that you don't have to delete the entire line and start over. Likewise, you can recall a previous command line and change the elements to make a new command.

By default, the bash shell uses command-line editing that is based on the emacs text editor. So, if you are familiar with emacs, you probably know most of the keystrokes described here.

> TIP: If you prefer the vi command for editing shell command lines, you can easily make that happen.
set -o vi to the .bashrc file in your home directory. The next time you open a shell, you can use vi commands (as described in the tutorial later in this chapter) to edit your command lines.

To do editing, you can use a combination of control keys, meta keys, and arrow keys. For example, Ctrl-f means to hold the Control key and Alt+f means to hold the Alt key and f. (Instead of the Alt key, your keyboard may use a meta key or the Esc key instead. On a Windows keyboard, you can sometimes use the Windows key.)

To try a bit of command-line editing, typing the following command:

```
$ /usr/bin | sort -f | less
```

This list counts the contents of the /usr/bin directory, sorts the contents in alphabetical order (regardless of upper- and lowercase), and pipes the output to less. Now, suppose you want to change /usr/bin to /bin. You can use the following steps to change the command from the shell:

+   - Press Ctrl+a. This moves the cursor to the beginning of the command line.
- Press Ctrl+f or the right arrow (→) key. Repeat this command a few times to position the cursor under the first slash (/
- Press Ctrl+d. Type this command four times to delete /usr.
- Press Enter. This executes the command line.
