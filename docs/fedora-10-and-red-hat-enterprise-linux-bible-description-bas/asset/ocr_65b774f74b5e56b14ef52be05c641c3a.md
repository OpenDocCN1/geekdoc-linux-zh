+   - Fedora Updates (fedora-updates.repo) — As updates become available from Fedora, you can automatically access those updates from mirror sites listed in fedora-updates.repo.

The following is a list of other repositories you might consider adding to your /etc/yum.repos.d/ files. Several of these repositories have made it easy for you by offering an RPM that adds the gpgkey and yum.repos.d file needed to access their repositories.

Keep in mind that these repositories change over time, as new ones are added, some are neglected and others. The consolidation of repository directories and GPG keys can change without notice. In fact, the RPM Fusion Project (http://rpmfusion.org) is gearing up to merge the Dribble, Freshprms and Livna repositories.

> NOTE: I recommend adding only repositories you need. Adding unnecessary repositories can slow down the performance of yum.

+   - Livna.org (http://rpm.livna.org) — Begun as an entry of the Fedora site, rpm.livna.org contains RPM software packages that are outside of the Fedora Project. This is a good place to get audio and video players (such as hine, mplayer, ffmpeg, og, and so on) that may not meet the licensing requirements adhered to by Hat Inc. By installing the livna-RPM, yum is configured to access the rpm.livna.org. Look for the Fedora 10 livna-release RPM at the following URL:
http://rpm.livna.org/rowiki/

+   - Dag (http://dag.wieers.com/packages) — This site contains more than 45,000 RPMs from more than 2400 projects. Currently, the repository has not been updated for the latest release and there is no RPM to automatically set up that repository from you. You can, look for Dag packages from the merged RPMForge.net.

+   - FreshRPMs (http://freshprms.net) — Another site with a good selection of high-quality RPMs is FreshRPMs.net. This site has a good selection of audio and video players that are outside of the mainstream Fedora repositories. By installing the freshprms-repo, yum is configured to access the FreshRPMs repository.

+   - Dribble (http://dribble.org.uk) — RPM packages focused on fun software are contained in the Dribble repository. Many of the packages are for games and console emulators. For a dribble-release package, which you can use to automatically enable the Dribble repository for your Fedora system, at this URL:
http://dribble.org.uk/listrpms1.html
