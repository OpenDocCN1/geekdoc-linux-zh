# Thunderbird client

As a companion to the Firefox Web browser, the Mozilla project created the Thunderbird mail client. If you installed Thunderbird (thunderbird package) from the Fedora media that comes with this book, you can launch it from your Applications by selecting Internet -> Thunderbird Email.

The first time you run Thunderbird, an import window opens, allowing you to import preferences, account settings, address books, and other data from e-mail clients. Have information about your e-mail account (user name, incoming, and outgoing servers, and so) ready so you can enter it before Thunderbird starts up.
