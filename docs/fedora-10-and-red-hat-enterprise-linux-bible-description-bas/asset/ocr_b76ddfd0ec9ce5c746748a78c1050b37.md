If you want to change your default e-mail application in GNOME on Evolution, select System -> Preferences -> Preferred Applications. When the Applications window appears, select the Mail Reader tab and choose the mail reader you want from the Select drop-down box. (You can also change your Web browser and Terminal window from the Preferred Applications window.) In KDE, from the KDE menu, select System Setting -> Default Applications -> Email Client. Then use the default KMail client or select "Use a different client" select the button to select from a list of known applications you can choose as your email client.

# Evolution e-mail

Evolution is the preferred application for sending and managing e-mail on default GNOME desktops for Fedora and RHEL. Fedora developers get a prime spot on the desktop, just to the right of the System menu and Web browser icon. After you launch Evolution for the first time and run the Startup Assistant, Evolution window appears, showing the different types of operations you can perform.
