5. **Configure server settings (/etc/atalk/apd.conf)** — Configuring apfd.conf lets you set up specific settings for your netatalk server (you can have multiple, virtual servers configured that look different from the outside world). The contents of the apfd.conf file affect how the AppleTalk filing protocol daemon (apfd) shares volumes with Macs.

6. **Set up users** — The Netatalk server can run on the Linux users you add to the computer (using clear-text passwords), limit access to your shared volumes based on permissions. Or, you can configure netatalk to use encrypted passwords to validate users.

7. **Shared volumes (/etc/atalk/AppleVolumes.default)** — When Netatalk starts, each user with a valid login login to your computer, by default, access his or her own home directory as an AppleTalk share from a Mac client. You can (probably) have more shared volumes by configuring them in the AppleVolumes.default file.

8. **Securing shared volumes** — Netatalk can take advantage of Linux security features to protect shared volumes. You can secure volumes for the host, user, and file and directory

9. **Share printers (/etc/atalk/papd.conf)** — Netatalk can share any printer you have connected to Linux (or otherwise configured locally) by adding a definition to the papd.conf file. No printers are shared until you add them
