```
# mkdir /media/maple
# mount maple:/home/chris/files /media/maple
```

The first command (mkdir) creates the mount point directory (/media is a common place to put put temporarily mounted disks and NFS file systems. The mount command identifies the remote computer and shared file system by a colon (maple:home/chris/files). Then, the local mount point follows (/media/maple).

> NOTE: If the mount failed, make sure the NFS service is running on the server and your firewall rules don't deny access to the service. From the server, type ps | grep nfs. You should see a list of nfs processes. If not follow as described in the previous section. View your firewall rules, type iptables -l (see Chapter 14 for a description of firewalls). By default, the nfs daemon listens for NFS requests on port number 2049. Your firewall must accept udp requests on ports 2049 (nfs) and 111 (rpc).

To ensure that the mount occurred, this command lists all mounted disks and NFS file systems. Here is an example of the command and its output:

```
# mount
/dev/sda3 on type ext3 (rw)
none on /proc type proc (rw)
none on /sys types nfs (rw)
none on /dev/pts type devtmpfs (rw,gid=5,mode=620) usdevfs on
/proc/bus/usb type usdevfs (rw)
/dev/sdal on type ext3 (rw)
none on /dev/shm type tmpfs (rw)
maple:home/chris/files on /media/maple type nfs (rw,addr=10.0.0.1)
```

The output from the command shows your disks partition, special file, and NFS file systems. The output line shows your disks (/dev/sda3), mounted on the root file /, with read/write permission (rw), with a file system type of ext3 (the standard Linux system type). The /boot file system is also of type ext3. /proc, /sys, /dev/shm, and usdevfs points represent special file types. The just-mounted NFS file system is /home/chris/files directory from maple (maple:home/chris/files). It is mounted on /media/maple and its type is nfs. The file system was mounted read/write (rw) and the IP address of maple is 10.0.0.11 (addr=10.0.0.11).

I showed a simple case of using NFS. The mount is temporary and is not remounted when you reboot your computer. You can also add options to the command line for NFS mounts:

+   -a Mount all file systems in /etc/fstab (except those indexed as noauto).
