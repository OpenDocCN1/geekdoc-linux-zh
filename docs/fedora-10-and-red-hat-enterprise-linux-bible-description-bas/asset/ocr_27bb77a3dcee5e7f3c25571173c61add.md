Every piece of information you store in your LDAP directory must fall under a base distinguished (or base dn). Because many organizations these days can be represented by a unique Domain name, the domain name is a popular way to identify your LDAP base dn. For the examples in this chapter, the base distinguished name I use is linuxtoys.net. If you are creating an LDAP directory for an organization that can be represented by a domain name, you can replace linuxtoys.net with your domain name.

If you are creating an LDAP directory structure for a larger organization (or other words, more than just a simple address book as I am doing here), you need to think about how your directory structured. You may want to add country codes (us, it, and so on) under your base distinguished name for a multinational company.

# Setting Up the OpenLDAP Server

All the software packages you need to set up an OpenLDAP server are included on the DVD that comes with Fedora and RHEL distributions. As an alternative, you can easily install the packages over the Internet using yum. With those packages installed, you can start configuring your OpenLDAP server.

# Installing OpenLDAP packages

To configure your OpenLDAP server, you should start by installing all the openldap packages from your Fedora or RHEL distribution. First, check which openldap packages are installed:

```
# rpm -qa "openldap*"
```

You need the openldap-devel package only if you are developing LDAP applications. Otherwise, you can install the openldap, openldap-clients, and openldap-servers packages from the DVD that comes with books.

# Configuring the OpenLDAP server (slapd.conf)

You configure the access and use of your OpenLDAP databases in the configuration file, /etc/openldap/slapd.conf.

> NOTE: For a complete description of features you can use in slapd.conf file, refer to the slapd.conf man page.
