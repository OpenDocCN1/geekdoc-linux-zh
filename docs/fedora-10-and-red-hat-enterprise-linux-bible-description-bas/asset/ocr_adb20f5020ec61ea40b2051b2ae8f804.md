> NOTE: Instead of the cdrecord package, Fedora now uses the wodim package (http://www.cdrkit.org) to implement the cdrecord command. Fedora and other Linux switched to the CDR Kit project because cdrecord licensing was changed to the CDDL license, which is believed to be incompatible with the GPL. Now, cdrecord is a link to the wodim command, although it supports the same options cdrecord supported before the switch to wodim.

This section focuses on using cdrecord to create audio CDs. The cdrecord command uses audio files in .au, .wav, or .cdr format, automatically translating them when necessary. If you have audio files in other formats, you can convert them to one of the supported formats using the sock command (described previously in this chapter).

CROSS-REFERENCE: See Chapter 13 for information on how to use cdrecord to create data CDs.

After extracting music tracks from your audio CD (using a tool such as cdparanoia, described earlier in this chapter). After you have created a directory of tracks (WAV format) from your CD, you can copy those files to your CD writer as:

```
# cdrecord -v /dev/cdrom -audio *.wav
```

The options to tell the command to create an audio CD (-audio) on the writable CD device located at /dev/cdrom. The cdrecord command writes all files from the directory that ends in .wav. The -v option causes verbose output.

If you want to change the order of the tracks, you can name the tracks in the order you want them (instead of using *.wav). If you don't indicate a recording speed, cdrecord will try to choose an appropriate one. If you get errors while you are recording, sometimes reducing the recording speed can help. For example, speed=2 or speed=4 on the cdrecord command line.

After you have created the music CD, indicate the contents of the CD on the label side of the CD. The CD should now be ready to play on any standard CD player.
