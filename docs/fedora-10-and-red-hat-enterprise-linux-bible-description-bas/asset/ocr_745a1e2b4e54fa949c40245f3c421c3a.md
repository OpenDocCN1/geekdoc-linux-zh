Before you try, however, you can check a few things about your Samba configuration.

# Checking your Samba setup with SWAT

From the SWAT window, select the STATUS button.

From this window, you can restart the smbd and nmbd processes. Likewise, you can see lists of active connections, active shares, and open files. The preferred way is to set the smbd and nmbd daemons to set up the samba service to start automatically. Type chkhconfig smb in a Terminal window to set the service to start at boot time.
