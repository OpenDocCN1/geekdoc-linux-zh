# Part I: Getting Started in Fedora and RHEL

In this example, the current or working directory is /usr/bin. To find the name of your home directory, type the echo command, followed by the $HOME variable:

```
$ echo HOME
/home/chris
```

In the preceding example, the home directory is /home/chris. To get back to your home directory, you can simply type the change directory (cd) command. Although cd, followed by a directory name, changes the current directory to the directory that you choose, simply typing cd (with no directory name) takes you to your home directory:

```
$ cd
```

You can also use the tilde (~) to indicate the home directory. cd ~ would have the same result as cd .. This is useful when typing long paths in your home directory (such as ~/local/files, instead of /home/chris/files).
At this point, you list the contents of your home directory, using the ls command. You can either use the full path to your home directory to list its contents, or use the ls command without a directory name to list the contents. Using the -l enables you to see the hidden files (dot files) well as all other files. With the -l option, you can see a long, detailed list of information on each file. You can put multiple single-letter options together after a dash, for example, -la.

```
$ ls -la ~/home/chris
total 158
drwxrxr-x 2 root 1024 2008-05-12 01:49 ..
-rw-xr-r-- 1 chris sales 224 2008-05-21 21:30 .bash_history
-rw-r--r-- 1 chris sales 240 2008-05-21 01:50 .bash_logout
-rw-r--r-- 1 chris sales 230 2008-05-10 01:50 .bash_profile
-rw-r--r-- 1 chris sales 124 2008-05-10 01:50 .bashrc
drwxr-xr-x 1 chris sales 4096 2008-05-10 01:50 .kde
-rw-r--r-- 1 chris sales 149872 2008-05-11 22:49 letter
```

Displaying a list (-l) of the contents of your home directory shows you more about files and directories. Directories such as the current directory (.) and the above directory (..) are noted by the letter d at the beginning of each entry. In this case, (.) represents /home/chris and two dots (..), which is also referred to as the parent directory, /. The home directory is owned by root. All other files are owned by the user chris (who belongs to the sales group).
The file or directory name shown on the left are mostly dot (.) properties that are used to store GUI properties (.kde directory) or shell properties (.bash files). The only non-dot file shown in this example is one named letter. At the beginning of each line are the permissions set for each file. (Permissions and configuring file properties are described later in this chapter.) Other information in the listing includes the size of each file in bytes (column 4) and the date and time each file was most recently modified (column 5).
