# # Chess games

Chess was one of the first games played on computer systems. While the game hasn't changed over the years, the way it's played on computers has. The Chess programs that are available in Fedora let you play against the computer (in text or graphical modes), have the computer play itself, or replay stored chess games. You can even play chess against other users on the Internet using Chess Servers (ICS).

The board program is an X-based chess game that provides a graphical interface for gnu. GNU Chess (represented by the xboard and gnchess packages) describes itself as a communal chess program. It has many contributors, and it seeks to advance a “more open and friendly environment of sharing” among the chess community. With xboard, you can move pieces with your mouse.

To play against the computer, use xboard from a Terminal window. Then just start by moving a piece with your mouse. While in the xboard window, select Menu -> Two Machines to have the computer play itself. Select File -> Load Game to load a game in Portable Game Notation (PGN). Figure 7-1 shows the xboard window with a Two Machines

You can use chess to play against others by connecting your session to an Internet Chess Server (ICS). To start xboard as an interface to an ICS, you type the following command line:

```
$ xboard -ics -ichost name
```

In this example, name should be replaced with the name of the ICS host (see the list of hosts below). In ICS mode, you can just watch games, play against others, or replay games that have finished. The ICS host acts as a gathering place for enthusiasts who want to play chess against others on the Internet, watch games, participate in tournaments, or just meet chess people. Here is an example of an ICS session at chess.net from a Terminal window:

```
$ xboard -ics -ichost chess.net
```

When you first visit, type guest and press Enter. If there are not too many guests already, you are logged into the chess server as a guest. (You can add a real account later by typing /register). The chess window opens on your screen. Keep an eye on the Terminal window where the session started. Someone will probably challenge you to a game within a few moments. For example, if a challenge ends with Type '/accept 102' to accept the sought challenge, you type:

```
chess% /accept 102
```

You can begin playing. Learn more about how to play, visit http://chess.net/help. Select the Beginners Manual to start. Other chess servers you can include the Internet
