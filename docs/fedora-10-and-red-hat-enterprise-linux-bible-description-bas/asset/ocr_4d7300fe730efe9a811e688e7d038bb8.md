# Choosing computer hardware

This may not be a choice. You may just have an old PC lying around that you want to try Fedora. Or you may have a killer workstation with some extra disk space and want to try Fedora on a separate partition or drive. To install the 32-bit version of Fedora successfully (that is, the version of the accompanying DVD), the computer must have the following:

+   * **x86 processor** — Your need an Intel-compatible CPU. With the latest version, Fedora recommends that you have at least a Pentium-class processor to run Fedora. For a text-only installation, a 200 MHz Pentium is the minimum, while a 400 MHz Pentium II is the minimum for a GUI installation.
* **DVD or CD-ROM drive** — You need to be able to boot up the installation process from a DVD, CD-ROM, or other bootable drive. (Other drives can use a USB flash memory that you can use with a diskboot image included on the DVD.) Once you have booted from the media used, you can use the Internet, a LAN connection to install Fedora software packages from a server on the network or find a way to copy the contents of the DVD to a local hard disk to install from there.
* **Hard disk** — The minimum amount of space you need varies on on installation type and packages you select. If you are an inexperienced user, you want at least 2.3GB of space so to get the GUI (with some Office and Productivity apps) or 3GB for a Software Development install (if you want to do software development). Although different install types are no longer supported in Fedora, the following items roughly how much disk space you need to install different types of desktop or server systems:
* **Office and Productivity** — Requires 2.3GB of disk space.
* **Software Development** — Requires 3.0GB of disk space.
* **Web Server** — Requires 1.1GB of disk space.
* **Minimal** — Requires at least 620MB of disk space.
* **RAM** — You should have at least 64MB of RAM to install Fedora (text mode only). If you are running in graphical mode, you will want to at least 192MB. The recommended minimum RAM (for decent performance) for GUI is at least 256MB.
