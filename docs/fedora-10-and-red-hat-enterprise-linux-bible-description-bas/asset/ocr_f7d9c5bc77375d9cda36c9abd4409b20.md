# Getting a domain name

For people to be able to send to the users on your mail server, you must have your own domain name. Chapter 25 describes how to get your own domain names and set up a DNS server. The critical issue for your mail server is to make sure that the MX record for your domain on the DNS server points to that of your mail server.

> NOTE: It is possible that your ISP will not allow you to have a private mail server on your residential Internet account. To enforce this, the ISP may block packets from being addressed to port 25. You may need to contact them to open that port you can set up a mail server on that connection. Because many spamming and otherwise evil (or at least poorly controlled) e-mail servers to hide behind dynamic IP addresses, many will neither allow e-mail addresses from dynamic IP addresses nor accept e-mail sent from those servers.

# Configuring basic sendmail settings (sendmail.mc)

Much of the configuration of your mail server comes from information in your /etc/mail/sendmail.mc file. This file sets sendmail default values that can be used in most cases, you may not have to do with sendmail.mc. I recommend you to check this section so you understand how your mail server is configured.

Changes you make to the sendmail.mc file do not immediately take effect. First you must compile the sendmail.mc settings to generate the /etc/mail/sendmail.cf file. I describe how to do in the "Starting sendmail and generating database files" section.

The resulting /etc/mail/sendmail.cf file contains over 1,800 lines of settings and comments that are used to direct the behavior of your sendmail daemon. The m4 macros you use in sendmail.mc file are different from the settings in sendmail.cf file.

> NOTE: The m4 utility can be used to process text files containing macros in IEEE Standard 1003.1-2001 format (Section 12.2. Utility Syntax Guidelines). This is particular about how you use single quotes backticks, to be careful editing sendmail.mc. For details on the m4 utility, type info m4.

To find which macros to use for setting up your sendmail.cf file, refer to the /usr/share/doc/sendmail*/README.cf file. If you are interested in details on the contents of your sendmail.cf file, I have included an exhaustive description of sendmail.cf in the download files at the Fedora 10 and Red Hat Enterprise Linux Bible site (http://www.wiley.com/go/fedora10bible).
