#  Looking Mac OS X

Apple computers for the past few years is an operating system referred to as Mac OS X. You might also hear Mac OS referred to as Jaguar, Panther, Tiger, or Leopard. As with Linux, OS X has a UNIX-like operating system at its core, in this case, has been turned into a commercial product. That core, instead of a Linux kernel, was originally based on a BSD-derived open source project called Darwin.

Although Mac OS X and Linux are very different on the surface, there are many striking similarities. If you use a Terminal (shell) window on your Mac, you'll find that you can use many of the same basic commands that you can use from Linux. In addition, many of the same open source projects are included in both operating systems. These include:

+   - Samba (Windows file/printer server)
- Apache (Web server)
- CUPS (CommonUNIX Printing Solution)
- Sendmail (mail transport agent)
- BIND (DNS server)

There are also few differences:

+   - Fedora is primarily covered under the General Public License, while OS X is based on partly Open Source license and partly a proprietary license. In August, 2003, the Apple Public Source License (APSL 2.0) was released (http://www.opensource.apple.com/apsl) and is now certified as a Free Software License from the Free Software Foundation.
- Fedora uses the Linux kernel; Mac OS X is based on a Micro-kernel surrounded by FreeBSD services. (Apple refers to this kernel as XNU and released it as a component of the Darwin open operating system).
- Most configuration in Fedora and RHEL is done using system-config windows, which often create text-based configuration files (mostly in the /etc directory) from command-line or GUI applications; Mac OS X stores the configuration file in its NetInfo database, which is manipulated primarily by GUI tools as well as by the niutil command.
