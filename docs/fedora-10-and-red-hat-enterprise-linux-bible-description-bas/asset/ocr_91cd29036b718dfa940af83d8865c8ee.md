# Chapter 2: Installing Fedora 65

In this example, the Windows partition is on device /dev/sda and is an NTFS file system. (The other common type of file system is VFAT.)

+   Get NTFS support. If you have a VFAT file system, you can skip this step. If you have an NTFS file system, and NTFS support is not already installed, you can install the necessary drivers and tools to be able to mount and use your NTFS file system in Linux by running the following command as root user from a terminal:

```
# yum install ntfprogs ntfs-3g
```

Assuming you have an active connection to the Internet, this will install the NTFS support you need to access your NTFS partitions from Linux.

+   Mount file system. You can access your Windows file system from Linux using the mount. Assuming your Windows partition is an NTFS file system on /dev/sda (as in the example above), you could type the following to create the Windows mount point and find the file system:

```
# mkdir /mnt/win
# chmod 755 /mnt/win
# mount -o -t ntfs /dev/sda /mnt/win
# chmod 755 /mnt/win
# ls /mnt/win
```

The -ro option to mount the file system read-only. Write support is not considered to stable (if you remove the -ro option to mount write, you do so at your own risk). Replace the ntfs with vfat if your Windows partition is a VFAT file system. The ls command is just to find out if you can see the contents of your Windows partition.

You can have the mount occur by adding an entry to the /etc/fstab file. Here's an example of the line you could add to /etc/fstab to have the partition mounted every time you reboots:

| /dev/sda | /mnt/win | ntfs | ro | 0 0 |

At this point, you can use the files from your Windows partition as you would any other files on your system. You can open a folder or change directories to the /mnt/win directory to see the contents. Then you use any applications you choose to open your documents (OpenOffice.org), music (Rhythmbox), images (Gimp), or any other type you want to use from your Windows partition in Linux.

> NOTE: If your Linux system uses an ext2 or ext3 file system (as Fedora typically does), you can the reverse of what was just described as well: access your Linux partition from Windows. How to do this, use the Ext2 Installable File System for Windows (http://www.fs-driver.org).
