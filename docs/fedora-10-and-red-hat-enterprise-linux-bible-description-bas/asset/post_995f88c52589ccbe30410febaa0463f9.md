## Administering a Mailing List with mailman

Mailman is a popular open source package for managing e-mail discussion lists. Besides offering flexible administrative interfaces for setting up and managing mailing lists, it also has Web-based interfaces that make it easy for people to join lists, access discussion archives, and tune their own preferences.

If you need more information about configuring mailman, there are places to go. Check the mailman Web site at http://www.gnu.org/software/mailman/mailman.html. Also view README files in `/usr/share/doc/mailman-*.`.

> NOTE: If you used mailman in an earlier version of Fedora or Red Hat Linux, note that the mailman installation directory has moved from `/var/mailman` to `/usr/lib/mailman`. If you made any changes to files in the `/var/mailman` directory, you need to move those files to the `/var/lib/mailman` directory after you upgrade the mailman software package.

The following is a brief procedure for configuring a discussion list using mailman:

- 1. Install the mailman RPM from the Fedora DVD or type `yum install mailman`.

- 2. Start your web server (if it's not already running) as follows:

```
# service httpd start
# chkconfig httpd on
```

- 3. Create a password for your user as follows:

```
/usr/lib/mailman/bin/mmsetpass
New site password: *****
Again to confirm password: *****
```

- 4. Edit the `/usr/lib/mailman/Mailman/mm_cfg.py` file and change the `DEFAULT_URL_HOST` and `DEFAULT_EMAIL_HOST` values. For example, the hostname of the computer I'm configuring my mail list is `toys.luinuxtoys.net`. The values would appear as follows:

```
DEFAULT_EMAIL_HOST = 'toys.luinuxtoys.net'
DEFAULT_URL_HOST = 'toys.luinuxtoys.net'
```

You can leave these values as fqdn to simply use the local computer's fully qualified domain name.

- Edit the `/etc/conf.d/mailman.conf` file. To cause queries, uncomment the RedirectMatch line at the bottom of the file and change that to include your fully qualified domain name. For example, when I did this for linuxtoys.net mailing list, the line appeared as follows:
```
RedirectMatch ^/mailman/(.*)$ http://linuxuxtoys.net/mailman/listinfo
```

To create a mailing list, you must first create an unpopulated mailing list mailman. With that, you must enter the e-mail and initial password for the person responsible for administering the list. To do that, type the following:

```bash
# /usr/lib/mailman/bin/newlist mailman
Enter the email of the person running the list: chris@linuxuxtoys.net
Initial mailman password: ********
enter to notify mailman owner...
```

- Restart the Web (httpd) service and start the mailing list as follows:

```bash
# service httpd restart
# service mailman start
# httpconfig config on
```

Create a new mailing list, using the newlist command as follows:

```bash
# /usr/lib/mailman/bin/newlist
Enter the email of the list: pro
Enter the email of the person running the list: chris@linuxuxtoys.net
Initial password: ******
```

To finish creating your mailing list, you must edit /etc/aliases (or equivalent) file by adding the following lines, and running the 'newaliases' program:

```
## pro mailing list
pro: |/usr/lib/mailman/mail/mailman post pro
pro-admin: |/usr/lib/mailman/mail/mailman admin pro
pro-bounces: |/usr/lib/mailman/mail/mailman bounces
```
