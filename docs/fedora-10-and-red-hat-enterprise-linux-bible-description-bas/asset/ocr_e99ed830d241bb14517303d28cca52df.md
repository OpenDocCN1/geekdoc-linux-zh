After you install the CrossOver Plugin, you will see a nice Plugin Setup window that enables you to selectively install plug-ins for QuickTime, Windows Media Player, Shockwave, Flash, iTunes, and Lotus Notes, as well as Microsoft Word, Excel, and PowerPoint viewers. (Support for later versions of these content formats may be available by the time you read this.) You can also install other multimedia plug-ins, as well as a variety of fonts to use with your plug-ins.

For some plug-ins, you will be prompted for where you want to put the plug-in. You can either install them so they are available to all users on the system or to the current user. To add a plug-in for all users who run Firefox on the system, put the plug-in in the `~/.mozilla/plugins` directory or `/usr/lib/firefox/*` directories.

> NOTE: When Firefox doesn't have a plug-in assigned to handle particular data, a pop-up window asks if you want to use the default application from your desktop environment to handle the data. GNOME, the `/usr/share/applications/defaults.list` file defines system-wide applications. For your own desktop, you can change the defaults to open a particular file type as follows: Open the Nautilus file manager; right-click on any file of the type you want to change; select Properties; select the Open With tab; and choose the application you want to use for that file type from the list. If the application you want to add is not on the list, click Add to it

While plug-ins are available for playing selecting types of content, add-ons can also be used to add features to the browser itself.
