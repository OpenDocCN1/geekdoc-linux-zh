## Partitioning with Disk Setup installation

During installation, you are given the opportunity to change how your hard disk is partitioned. Fedora recommends using the Disk Setup. Disk Setup is divided into two sections. The top shows general information about each hard disk. The bottom shows details of each partition. Figure 2-2 shows an example of the Disk Setup window.

For each hard disk, you can see:

- **Device** — The device is the name representing the hard disk partition in the /dev directory. Each partition device begins with two letters: sd for IDE disks or SCSI disks, ed for XT disks. After that is a single letter representing the number of the disk (disk 1 is a, disk 2 is b, disk 3 is c, and so on). The partition number for that disk (1, 2, 3, and so on) follows.

![](img/63c86e1d25a0e2be7e9f6de6b6f02530_114_0.png)

- **Mount Point/Raid/Volume** — The directory where the partition is connected into the Linux file system (if it is). You must assign the root partition (/) to a native Linux partition before you can proceed. If you are using RAID or LVM, the name of the RAID device or LVM volume appears here.

- **Type** — The type of file system that is installed on the partition. In most cases, the file system will be Linux (ext3), Win FAT (vfat), or Linux swap. However, you can also use the previous Linux file system (ext2), physical volume (LVM), or software RAID. In fact, LVM is used by default for your root file system when you install Fedora or RHEL. This will allow you to add more disk space to later that partition, if needed, without creating a new partition.

- **Format** — Indicates whether (checkmark) or not (no check) the installation process should format the hard disk partition. Partitions marked with a check are erased! So, on a multiboot system, be sure your Windows partitions, as well as other partitions containing data are not checked!

- **Size (MB)** — The amount of disk space allocated for the partition. If you selected to let the partition grow to fill the space, this number may be much larger than requested.

- **Start/End** — Represents the partition's starting and ending cylinders on the hard disk.

## Reasons for partitioning

There are different opinions about how to divide up a hard disk. Here are some issues:

- **Do you want to install another operating system?** If you want Windows on your computer along with Linux, you will need at least one Windows (Win95 FAT16, VFAT, or NTFS type), one Linux (Linux ext3), and one Linux swap partition.

- **Is it a multiserver system?** If you are using the system yourself, you probably won't need many partitions. One reason for partitioning an operating system is to keep the entire system running out of disk space at once. That also serves to put boundaries on what an individual can use in his or her home directory (although disk quotas are good for that as).

- **Do you have multiple hard disks?** You need at least one partition per hard disk. If your system has two hard disks, you may assign one to / and one to /home (if you have lots of users) or /var (if the computer is a server sharing lots of data).

## Deleting, adding, and editing partitions

Before you add a partition, there needs to be some free space available on your hard disk. If all space on your hard disk is currently assigned to one partition (as it is in DOS or Windows), you must delete or resize partition before you can claim space on another partition. The section "Resizing your Windows partitions" earlier in this chapter discusses how to take disk space from an existing Windows partition to use later for Linux partitions, losing information in your existing single-partition system.

> CAUTION: Make sure that any data that you want to keep backed up before you delete the partition. When you delete a partition, all its data is gone.

Disk Setup is less flexible, but more intuitive, than the fdisk utility. Disk Setup lets you delete, and edit partitions.

> TIP: If you create multiple partitions, make sure there is enough room in the right places to complete the installation. For example, most of the Linux software is installed in the /usr directory and subdirectories, whereas most user data are eventually added to the /tmp,/home or /var directories. It's a good idea to have separate partitions for every directory structure users can write to. Likewise, NFS shares are often put on separate partitions.

To delete a partition in Disk Setup, do the following:

1. Select a partition from the list of Current Disk Partitions on the Main Disk Setup window (click it or use the arrow keys).
2. To delete the partition, click Delete.
3. When asked to confirm the deletion, click Delete.
4. If you made a mistake, click Delete.

To add a partition in Disk Setup, do the following:

1. Select a partition from the list of Current Disk Partitions on the Main Disk Setup window (click it or use the arrow keys).
2. Click New. A window appears, let you create a new partition.
3. Type the mount point (the directory where the partition is connected into the Linux file system).
4. Select the type of file system that is installed on the partition.
5. Type the size in megabytes for the partition.
6. Select one of the following Size Options:
    - **Fixed size**: Click here to use only the number of megabytes you entered.
    - **Fill all space up to (MB)**: Click here.
    - **Fill to maximum allowable size**: Click here.
7. Optionally Select Free as Primary Partition or Check for Bad Blocks if you want to check for errors.
8. Select OK if everything is.

To edit a partition in Disk Setup, follow these steps:

1. Click the partition you want to edit.
2. Click the Edit button. A window appears, let edit the partition.
3. Change any of the attributes (as described in the add partition process).
4. Select OK.
