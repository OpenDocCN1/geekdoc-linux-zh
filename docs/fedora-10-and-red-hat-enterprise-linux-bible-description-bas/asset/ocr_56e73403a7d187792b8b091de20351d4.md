Next, identify the database (allusers in this example) as the current database by typing the following:

```
mysql> USE allusers;
Database changed
```

To actually load the file into the allusers database, type the following command to load the file (in this case, /tmp/name.txt) from the mysql> prompt.

> NOTE: Either the full path to the file or have it in the directory where the mysql command starts. In the latter case, you can type the filename indicating its full path.

```
mysql> LOAD DATA INFILE "/tmp/name.txt" INTO table name;
Query OK, 3 rows affected (0.02 sec)
Records: 3 Deleted: 0 Skipped: 0 Warnings: 0
```

Type the following at the mysql> prompt to make sure that the records have been added correctly:

```
mysql> SELECT * FROM name;
street
```
