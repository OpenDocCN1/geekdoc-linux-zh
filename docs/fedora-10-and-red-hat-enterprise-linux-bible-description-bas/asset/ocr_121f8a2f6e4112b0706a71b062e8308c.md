# Creating new files and folders

You can create a variety of file types using the Dolphin window. Choose File -> Create New, and select Folder (to create a new folder) or one of the types using the following submenu:

+   **HTML File** — Opens a dialog box that lets you type the name of an HTML file to create.

+   **Link to Application** — Opens a window that lets you type the name of an application. Click the Permissions tab to set file permissions (Exec be on if you want to run the file as application). Click the Execute tab and type the name of the program to run (in the field: Execute on click) and a title to the title bar of the application (in the field: Window Title). If it is a text-based command, select the Run in terminal check box. Click the check box to Run as a different user and add the user name. Click the Application tab to assign the application to handle files of particular MIME types. Click OK.

+   **Link to Location (URL)** — Selecting this menu item opens lets you create a link to a Web address. Type a name to represent the address and type the name of the URL (Web address) for the file. (Be sure to add the http://, ftp://, or other prefix).

+   **Text File** — Opens a dialog box that lets you create a document in text format and place it in the Konqueror window. Type the name of the document to create and click OK.
