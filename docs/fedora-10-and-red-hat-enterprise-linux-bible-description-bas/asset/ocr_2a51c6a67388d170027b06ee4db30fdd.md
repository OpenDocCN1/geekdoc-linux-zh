# Using your camera as a storage device

As I noted with my example of an Olympus camera with a USB connector, the GNOME Volume Manager is capable of detecting camera once it is connected, and mounting its contents as a storage device. With the contents of a digital camera mounted, you can use your camera as a USB storage device:

+   - Opening the mounted directory in a folder window and using any file managers to work with the images.
- Changing the mounted directory from the shell and using commands to copy, move, rename, or delete digital images.

Of course, with your camera mounted as a file system, you are not limited to using it only for digital images. You can use it to store any kind of files you like, essentially using the camera as a storage device.
