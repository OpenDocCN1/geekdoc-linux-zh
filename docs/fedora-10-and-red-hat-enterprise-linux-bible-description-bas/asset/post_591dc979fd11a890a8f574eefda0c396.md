## Using Windows partitions from Linux

With some space available on your disk, when go to install Linux, consider adding a small FAT16 or FAT32 partition (maybe 2GB) on your disk. Every x86 operating system (Linux, Windows 95, NT, 2000, XP, Vista and DOS) supports those types. With that, you will be able to freely exchange files between your Linux and Windows system on the FAT16 partition.

With FAT partitions, keep in mind that there are limitations. FAT16 is limited to between 2GB and 4GB file sizes. Also, FAT16 does not support large files. Total partition size for file systems is 32GB.

After you have installed Linux in the space freed up by the previous procedure, you should be able to choose between Linux and Windows when the Fedora or RHEL boot screen appears during boot time. Press any key to get to the GRUB boot screen. Move the arrow key to choose boot Linux or Windows.

The first time you boot Windows, you might be asked to check your disk (because Windows partition will be a different size than expected). After that, there should be no change in how you use your Windows system. Your disk space will be smaller.

Now, when you boot Linux, if you have a lot of documents, digital images, music, or other content on your Windows partition, you probably will be able to use that content from Linux. To do that, you need:

- Determine which partition is your Windows partition.
- If you didn't so during installation, add support for the file system type of your Windows to Linux. Since VFAT is already built in, means adding NTFS support if that is the file system type.
- Mount the Windows partition on your Linux file system.

## Partitioning your disks

The hard disk (or disks) provides the permanent storage area for data, programs and the operating system. Partitioning is the act of dividing a disk into logical areas that can. There are several reasons you may want to partition:

- Multiple operating systems — If you install Fedora or RHEL on a PC that already has a Windows operating system, you may want to keep both operating systems. When your computer boots, you can choose which to run. Note that you are limited in the number of partitions you can have (with IDE devices you can have 63 partitions; with SCSI devices you are limited to 15 partitions per device).
- Multiple partitions within an operating system — To protect your entire run out of disk space, people often assign separate partitions to different areas of the file system. For example, if /home and /var were assigned to separate partitions, a gluttonous user who fills up the /home partition wouldn't prevent daemons from continuing to log files in the /var/log.
- Different file types — Different kinds of file systems have different structures. File systems of different types must be on their own. In Fedora and RHEL, you need at least one file system for (typically ext3) and one for your swap area. File systems on CD-ROM use the iso960 file system.

> TIP: When you create partitions for Fedora or RHEL, you will often assign the file system type as Linux native (using the ext3 type). Another type, ext4, is also available. Reasons to use other types include needing a file system that allows long filenames or inodes (each file consumes an inode).

For example, if you set up a news server, it can use inodes to store news articles. Another reason for using a different file system type is to copy an image backup tape from another operating system to your local disk (such as one from OS/2 or Mini operating).
