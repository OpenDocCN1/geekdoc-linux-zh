To edit a partition in Disk Setup from the main Disk Setup window, follow these steps:

+   1. Click the partition you want to edit.

+   2. Click the Edit button. A window appears, let you edit the partition.

+   3. Change any of the attributes (as described in the add partition process). For a new install, you may need to add the mount point (/) for your primary Linux partition.

+   4. Select OK. (The changes don't take effect until several steps later, when you are asked to begin installing the packages).

# Partitioning with fdisk

The fdisk utility does the same as Disk Setup, but it's longer offered as an option during Fedora or RHEL installations. (If you are old school, you could press Ctrl+Alt+F2 to run fdisk from the shell to partition your disk.)

The following procedures are performed from the command line as root user.

> CAUTION: Remember that any partition changes can easily erase your disk or make it inaccessible. Back up critical data before using any tool to change partitions! Then be very careful about the changes you do make. Keeping an emergency disk handy is a good idea, too.
