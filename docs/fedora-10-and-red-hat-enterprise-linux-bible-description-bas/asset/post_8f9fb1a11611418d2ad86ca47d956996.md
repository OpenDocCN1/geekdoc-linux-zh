- Third-party packages — If you have installed packages from third-party repositories that are specific to your current kernel (such as drivers for NVIDIA video cards or wireless LAN cards) you will need to get new versions of those packages that match your upgraded kernel.

- Kernel requires — To upgrade, you must have at least a Linux 2.0 kernel installed on the system you are upgrading.

- Configuration files — With an upgrade, your configuration files are replaced as filename.rpmsave, the host file is saved as hosts.rpmsave. More often, however, your old configuration files will remain in place, while the system copies new configuration files for filename.rpmnew. The locations of these files, as well as other upgrade information, is written to /root/upgrade.log. The upgrade installs the new kernel, any changed software packages, and any packages that the installed packages depend on being being. Your data files and configuration information should remain intact.

- Java — If you use the Java RPM from Sun Microsystems to provide Java support, conflicts with that package may cause it to be erased during an upgrade. If that occurs, you can install the Java RPM from package.org or install the Java tarball from Sun Microsystems into your /opt directory. You can also consider removing that version of Java from your system and installing the open source IceTea packages included with Fedora to provide Java support.

A feature that is available when you are upgrading to Fedora 10 is the preupgrade package. By installing preupgrade on a Fedora 9 system (yum install preupgrade), you can prepare your system to upgrade to Fedora 10 by launching a single application:

- Determine which packages need to be downloaded to upgrade to Fedora 10.
- Download the packages needed to complete the upgrade (while Fedora 9 is still running)
- Download the boot images needed for the upgrade.

The advantage of using preupgrade is that you can continue using your system while you do most of the time-consuming work (such as downloading packages) that need to be done an upgrade. Also, before you get into the installer, you will be able to see if there are any package dependencies you should deal with (before committing to the actual upgrade).

With the preupgrade package installed, you can start the GUI version of preupgrade by typing preupgrade from a Terminal window as Files needed for the upgrade are copied to /var/cache/yum/anaconda-upgrade directory. Once preupgrade is complete, you can reboot to a Fedora 10 install DVD and build the upgrade.

# Chapter 2: Installing Fedora

## From DVD, network, or hard disk?

When you install Fedora, the distribution doesn't have to come from the installation DVD or CD. After booting the installation DVD, press Tab with the Install selection highlighted. Then type the word install at the end of the boot command line and press Enter. You are offered the choice of installing Fedora from the following locations:

- **Local DVD or CDROM** — This is the most common method of installing Fedora and the one you by simply pressing Enter from the boot prompt. All packages needed to complete the installation are on the DVD that comes with this.

- **Hard drive** — If you can place a copy of the Fedora distribution on your hard drive, you can install it from there. (Presumably, the distribution is on a hard drive partition to which you are not installing.)

- **NFS directory** — Allows you to install from any shared directory on your network using the Network File System (NFS) facility.

- **HTTP** — Lets you install from a Web page address (http://) or FTP site (ftp://).

If you don't have a DVD, you can use the boot.iso CD image that comes on the DVD with the boot (see below) to start a network install (HTTP, FTP, or NFS). Just type install method at the boot prompt to begin the installation process.

If you don't have a bootable DVD or CD drive, there are other ways to start the Fedora installation. Unlike earlier Fedora and Red Hat Linux versions, Fedora doesn't support floppy disk images (the Linux kernel is too large to fit on a floppy disk). Therefore, if you don't have a bootable DVD or CD drive, you need to start the install process from some other medium (such as a USB device, PXE server, or hard drive, as described later in this chapter).

The following installation types may also be of interest to:

- **Boot CD** — You can create a boot CD from the boot images contained on the DVD that comes with this. Copy and burn the boot.iso from the images directory on the DVD. You can use the CD you create to begin the install process if you have a DVD drive that is not bootable or if you have the Fedora 10 software available on any of the media described in the linux method section.

- **USB or other bootable media** — If your computer can be configured to boot from alternate bootable media, such as a USB pen drive, that is larger than a floppy disk, you can copy the diskboot.img file to that medium and install from there. That image is contained in the images directory on the DVD.

# Choosing computer hardware

This may not be a choice. You may just have an old PC lying around that you want to try Fedora. Or you may have a workstation with extra disk space and want to try Fedora on a separate partition or drive. To install the 32-bit version of Fedora successfully (that is, the accompanying DVD), the computer must have the following:

- **x86 processor** — Your need an Intel-compatible CPU. With the latest version, Fedora recommends that you have at least a Pentium-class processor to run Fedora. For a text-only installation, a 200 MHz Pentium is the minimum, while a 400 MHz Pentium II is the minimum for a GUI installation.
- **DVD or CD-ROM drive** — You need to be able to boot up the installation process from a DVD, CD-ROM, or other bootable drive. (Other drives can use a USB flash memory that you can use with a diskboot image included on the DVD.) Once you have booted from the media used, you can use the Internet, a LAN connection to install Fedora software packages from a server on the network or find a way to copy the contents of the DVD to a local hard disk to install from there.
- **Hard disk** — The minimum amount of space you need varies on installation type and packages you select. If you are an inexperienced user, you want at least 2.3GB of space so to get the GUI (with some Office and Productivity apps) or 3GB for a Software Development install (if you want to do software development). Although different install types are no longer supported in Fedora, the following items roughly how much disk space you need to install different types of desktop or server systems:
- **Office and Productivity** — Requires 2.3GB of disk space.
- **Software Development** — Requires 3.0GB of disk space.
- **Web Server** — Requires 1.1GB of disk space.
- **Minimal** — Requires at least 620MB of disk space.
- **RAM** — You should have at least 64MB of RAM to install Fedora (text mode only). If you are running in graphical mode, you will want to at 192MB. The recommended minimum RAM (for decent performance) for GUI is at least 256MB.
