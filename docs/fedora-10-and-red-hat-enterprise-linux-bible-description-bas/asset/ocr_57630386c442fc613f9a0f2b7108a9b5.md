# Part I: Getting Started in Fedora RHEL

# Step 1: Checking out your home folder

Double-click the user's Home icon on the desktop (it should say something like “bill’s Home” or “julie’s Home,” depending on your user name). The window that appears shows your file manager (Nautilus in GNOME or Dolphin in KDE) as it displays the contents of your home folder.

Notice that your home folder contains several folders that were added by GNOME: Desktop (containing the items you see on your desktop), Documents, Download, Music, Public, Templates, and Videos.

The location of the home folder (also referred to as a home directory) on your computer is usually `/home/user`, where user is replaced by your user name. Here are some things to try out with your home folder (assuming the GNOME Nautilus is your file manager):

+   1. **Folders** — Create folders andfolders to store your work (click File → Create Folder, and then type the name of the new folder; something like Images, Memos, or Projects).
2. **Open Location** — To open another folder on your computer, click File → Location and type a directory name. For our tour, open a folder that has different file types in it (for example, `/usr/share/doc/bash-3.2/` contains some text, PostScript and HTML files).
3. **Open With** — Click any object in a folder with the right mouse button, and select Open With. You should be able to see programs you can use to open the object. For example, you can choose to open a Web page (.html file) with Firefox, Konqueror, or Text Editor (depending on what is installed, you may see different options).
4. **Side Pane** — Right-click any folder in the Nautilus file manager window, and select Browse to the new folder with a Side Pane displayed. From the drop-down box at the top of the Side Pane, choose Information about the selected folder or File. Next to History to see folders and folders previously viewed. Choose Tree to see a hierarchical representation of your file system. Select Places to see folders from removable media and your home folder. Using the button above the side pane, you can choose to have your location box text-based or represented by buttons.
5. **Backgrounds** — Click Edit → Backgrounds and Emblems. Drag and drop patterns and colors you like into your folder (I personally like camouflage). Click Emblems, then drag and drop an emblem on a file or folder. Use the emblem to remind yourself of something about the object (such as the fact that it's your personal document or of urgent nature)
