You have learned a vi editing commands. I describe more commands in the following sections. However, before I do, here are a few tips to smooth out your first trials with vi:

+   - Esc — Remember that Esc gets back to command mode. (I've watched people every key on the keyboard typing to get out of a file.) Esc by ZZ gets you out of input mode, saves the file, and exits.

+   - u — Press u to undo the previous command. Continue to press u to undo the change before that, and the one before. (With the traditional vi, undoes a single command and returns what you just undone.)

+   - Ctrl+r — If you didn't want to undo the previous edit, use Ctrl+r for Redo. Essentially, this command undoes undo.

+   - Caps Lock — Beware of hitting Lock. Everything you type in vi has a different meaning when the letters are capitalized. You don't get a warning that you are typing things — just start acting wildly.

+   - !command — You can run a shell command while you are in vi using followed by a command name. For example, type !date to see the current date and time, type !pwd to see what your current directory is, or !jobs to see if you have any jobs running in the background. When the command completes, press Enter and go back to editing the file. You could exit (:bash) to run a few commands from the shell, then type exit to return to vi. (I recommend saving a before escaping to the shell, just in case you forget to go back to vi.)

+   - INSERT — When you are in mode, the word INSERT appears at the bottom of the screen. Other messages also appear at the line at the bottom of the screen.

+   - Ctrl—If you forget what you are editing, pressing these keys displays the name of the file that you are editing and the line you are on. It also displays the total number of lines in the file, the percentage of how far you are from the file, and the column number is on. This helps you keep your bearings after you've stopped for a cup of coffee at 3 a.m.
