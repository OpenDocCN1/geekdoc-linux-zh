# Turn on the quota startup script

If you created a quota file, as described in the previous step, you will need to make it executable and set it to start automatically when you start Fedora or RHEL. To do those things, type the following as root:

```
# chmod 755 /etc/init.d/quota
# chconfig --add quota
# chconfig quota on
```

At this point, links are created so that your quota script starts when Fedora or RHEL boots.

# Creating quota rules

You can use the edquota command to create quota rules for a particular user or group. (Valid users and groups are listed in the /etc/passwd and /etc/group files, respectively). Here is an example of an edquota command to set quotas for a user named Jake.

> NOTE: edquota command uses the vi text editor to edit your quota files. To use a different editor, change the value of the EDITOR or VISUAL environment variable before running edquota. For example, use the emacs editor, type the following before running edquota:

```
# export EDITOR=emacs
# edquota -u jake
```

This example shows that quotas can be set for the user jake on the /dev/sda2 partition (which is home in my example). Currently, jake has 596 blocks (a block equals 1K on this ext 3 file system). One was created by jake (represented by 1 inode). To change the disk usage limits (unlimited use) you can edit the zeros under the soft and hard heading for quotas and inodes.

Soft limits set limits that you don't want a user or group to exceed. Hard limits set the boundaries that will not let a user or group exceed. After a grace period that a soft limit is exceeded (which is seven days, by default), the soft limit becomes a hard limit. edquota -t to check and change the grace periods that you have set.
