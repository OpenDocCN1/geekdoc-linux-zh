# Alternatives for starting installation

Your computer may not have a DVD or CD drive or may have one that is unbootable, so you need to find an alternative way to boot the installation. Although booting installation from 1.44MB floppy disks is no longer supported (the 2.6 kernel won't fit on one), you have a few alternatives:

+   - Boot installation from hard disk
- Boot from a USB flash drive or other USB drive
- Do a PXE install

Procedures for starting installation in those ways are described in the following sections.
