To determine if your link is saturated, the act of pinging an outside host can tell much of the story. Much higher than usual usage is a dead giveaway. Normal ping latency (that is, the time it takes for a ping to come back from a remote host) looks like the following:

```
# ping www.example.com
PING www.example.com (192.0.34.166) from 10.0.0.11: 56(84) bytes
64 bytes from 192.0.34.166: icmp_seq=1 ttl=49 time=40.1 ms
64 bytes from 192.0.34.166: icmp_seq=2 ttl=42 time=42.5 ms
64 bytes from 192.0.34.166: icmp_seq=3 ttl=39 time=39.5 ms
64 bytes from 192.0.34.166: icmp_seq=4 ttl=38 time=38.4 ms
64 bytes from 192.0.34.166: icmp_seq=5 ttl=39 time=39.0 ms
```

```
--- www.example.com ping statistics ---
5 packets transmitted, 5 received, 0% loss, time 4035ms
rtt min/avg/max/dev = 38.472/39.971/42.584/1.432 ms
```

In the preceding example, the average time for a ping packet to make the round trip was about 39 thousands of a second.

A ping to a nearly saturated link will look like this:

```
# ping www.example.com
PING www.example.com (192.0.34.166) from 10.0.0.11: 56(84)bytes
64 bytes from 192.0.34.166: icmp_seq=1 ttl=62 time=1252 ms
64 bytes from 192.0.34.166: icmp_seq=2 ttl=62 time=1218 ms
64 bytes from 192.0.34.166: icmp_seq=3 ttl=62 time=1290 ms
64 bytes from 192.0.34.166: icmp_seq=4 ttl=62 time=1288 ms
64 bytes from 192.0.34.166: icmp_seq=5 ttl=62 time=1241 ms
```

```
--- www.example.com ping statistics ---
5 packets transmitted, 5 received, 0% loss, time 5032ms
rtt min/avg/max/dev = 1218.059/1258.384/1290.861/28.000 ms
```

In this example, a ping packet took, 1.3 seconds to make the round trip. From the first to the second, latency increased by a factor of 31! A data link that from working normally to slowing down by a factor of 31 is a clear sign that link utilization should be investigated.

For a more accurate measure of data throughput, a tool such as ttcp can be used. To test your connection with tcp you must have installed the tcp package on machines inside and outside of your network.(The tcp package comes on the DVD included with this book.) If you are not sure whether the package is installed, simply type ttcp at a command prompt. You should see something like the following:

```
# ttcp
Usage: ttcp -t [-options] host [ < in ]
ttcp -r [-options] > out]
Common options:
-4 Use IPv4
```
