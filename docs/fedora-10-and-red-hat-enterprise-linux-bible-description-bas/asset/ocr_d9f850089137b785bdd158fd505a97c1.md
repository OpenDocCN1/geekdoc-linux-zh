# Understanding OIDs

If you look into a schema file (/etc/ldap/schema/*), you will see that every LDAP object class and attribute is mapped to a dot-separated number. That number is a hierarchical string that is referred to as an Object Identifier (OID).

Because LDAP is intended to be a global directory (where all entries are unique), if you want to create a directory that can be accessed globally, you should try to use items that have existing OIDs whenever possible. However, if you find that you need to create object classes or attributes that are not already defined, you can consider getting an Object Identifier (OID) for your organization. The alternative is to make up your own name and OID, which in case you either never expect that data to be globally accessible or try not to conflict with existing OIDs.

Like a name, an OID assignment enables you to create branches under OID as you need them. If your organization has its own OID assigned, you are guaranteed of every item you create that number be globally unique (as long as you maintain those assignments properly).

Private enterprise numbers are examples of useful information that is stored as OIDs. Private enterprise numbers used primarily for companies using SNMP are stored under the OID number 1.3.6.1.4.1. Companies represented under OID include IBM (1.3.6.1.4.2), Cisco Systems (1.3.6.1.4.1.9), and Hewlett Packard (1.3.6.1.4.1.11). For Red Hat Software, the OID is 1.3.6.1.4.1.2312.

If you break down each number into its components, that you will start with the top-level OID 1 (for ISO-identified organizations), 3 (ISO-identified organizations), 6 (U.S. Department of Defense), 1 (Internet), 4 (private), 1 (enterprise).

You can see the complete list of enterprise numbers on the Private Enterprise Numbers list at http://www.iana.org/assignments/enterprise-numbers. Search for OID assignments (from the top node) at http://www.alvestrand.no/objectid/top.html. You can get your OID from the Internet Assigned Numbers Authority (http://www.iana.org/cgi-bin/mediatypes.pl).
