# Gaming in Fedora and RHEL

Every type of PC gaming is available now with Linux. Whether you are looking for a solitaire game to fill time or a full-blown online 3D gaming experience, you will have dozens (or hundreds) of choices on the Linux desktop. A strong gaming special interest group within the Fedora project has insured that many open source games not only run, but run well, in Fedora.

Although some companies, such as ID (Quake) and Epic Games (Unreal Tournament) have done to port their games to Linux, others have used third-party developers (such as RuneSoft) to port commercial games to Linux. Independent developers, such as FrictionalGames (http://fictionalgames.com) and Introversion Software (http://www.introversion.co.uk) are now producing high-quality gaming experiences in Linux. Clients for commercial online gaming, such as EVE Online (http://www.eve-online.com), are also available.

Some experts predict that gaming will be the software category that brings Linux into homes. The unfortunate truth is that many of the current 'hot' titles still need to be coaxed onto Linux with some kind of Win32 emulation (such as Cedex). But this is getting easier and more dependable. While the number of popular games is fairly limited at the moment, everything in Linux, more games are becoming each day.

One area where gaming-related software has grown in Linux is in tools for producing high-quality 3D animations. For example, Blender (http://www.blender.org) is an open source project for doing animations, 3D models, post-production, and rendering that is being used to produce commercial games and movie animations. Blender's features are beginning to rival those of commercial 3D animation software such as 3D Studio Max (http://www.autodesk.com/3dsmax), Maya (http://www.autodesk.com/maya) and SoftImage SXI (http://www.softimage.com).
