
## Monitoring CPU usage with top

Start the top utility in a Terminal, and it displays the CPU consuming processes on your computer. Every five seconds, top will determine which processes are consuming the most CPU time and display them in descending order on your screen.

By adding the -s option to top, you can have the display show the cumulative CPU time that the process, as well as child processes that may already have exited, spent. If you want to change how often the screen is updated, you can add the -d secs where secs is replaced by the number of seconds between updates.

By default, processes are sorted by CPU usage. You can sort processes numerically by PID (press N), by age (press A), by resident memory usage (press M), by time (press T), or back to CPU usage (press P). The following output shows an example of top running, with information sorted by memory. The system is running a GNOME desktop, with Office.org, Firefox browser and all other applications. Notice that the amount of memory used is very low. To get good performance out of a Fedora system, 256MB may not be enough to start a lot of big applications.

## Monitoring power usage on laptop computers

To effectively use a laptop, you need to be able to monitor and manage your laptop’s power. Using tools provided in Fedora or RHEL, you can configure your laptop to:

- The battery is low.
- Notify you when the battery is low.
- Notify you when the laptop is plugged in.
- Show when the laptop is plugged.
- Suspend the current session.

Fedora and RHEL offer two facilities that do power management: APM and ACPI.

- **Advanced Power Management (APM)** — APM can be used to monitor the battery of your notebook and notify user-level programs to tell you your battery is low. It can also be used to put your laptop into sleep mode.

- **Advanced Configuration and Power Interface (ACPI)** — Besides monitoring features on your laptop, ACPI can also do thermal control, motherboard configuration, and change power states.

Many older laptops do not include support for ACPI in the BIOS, so you must use APM to monitor and manage your batteries. For some newer laptops, ACPI may be required. In general, ACPI offers a more complete feature set for power management, but APM has more user-level support.

To check whether ACPI or APM are supported on your Linux system, you can use the `dmesg` command after a reboot. For example:

```
# dmesg | less
```

The following procedure was performed on a laptop that used ACPI to manage power events. It describes how to use the GNOME Power Manager applet on the desktop to monitor your battery.

> NOTE: If it seems either ACPI or APM are interfering with the power of your laptop, you can turn off each service when you boot your computer. Add `acpi=off` or `apm=off` to the end of the kernel line (from the GRUB boot screen or `/boot/grub/grub.conf` file) to turn off ACPI or APM, respectively.

## Fixing Your System with FirstAidKit

Starting with Fedora 10, a new package FirstAidKit helps you fix any issues that may strike your system. Built on top of a pluggable architecture, FirstAidKit is an automated recovery tool that applies common techniques to rescue your system.

To use the FirstAidKit, you first need to install the package:

```
# yum install firstaidkit
```

The most common way to run the program is to let it do what it thinks it ought be done—it is the whole automated part of the recovery tool. To do so, run the following command:

```
# firstaidkit -a
```

The program reports what it finds and the actions it takes.

To see the available plug-ins, use the following command:

```
# firstaidkit --list
```

## Choosing Software Alternatives

Because several software packages are available for every service available in Linux (such as mail, printing, Java environments, and so on), there will be times when people using the system will prefer one over another. Software packages that have been designed to work with the alternatives system can be configured in Fedora or RHEL to let an administrator choose which of the alternatives to a particular service he or she to use by default.

## Selecting Java alternatives

If you are developing Java applications, an addition to the alternatives feature lets switch between using a proprietary Java virtual machine (JVM) to using the GNU compiler for Java (gcj). Type the following to see which implementation of java is currently in use on your system:

```
# alternatives --display java
```
