# Chapter 3: Getting Started with the Desktop

+   **Add a screensaver** — Select Look and Feel -> Screensaver. Try out a few screensavers (the default screensaver is floating Fedora logos). Click different screensavers to see them and click Preview to try them. (If you see only a few screensaver options, install the rss-glx-gnome-screensaver package to install lot more screensavers.)

> TIP: Click the Lock When Screensaver is Active check box and set the number of minutes after which the screensaver comes on and locks. This is a good option for an office environment, where you want your screen locked if you wander away for a few minutes. If you logged into a virtual terminal (for example, you pressed Ctrl+Alt+F2, then logged in, returned to the desktop with Ctrl+Alt+F7), be sure to log off the terminal as before leaving your desk.

+   **Change the theme** — Select Look and Feel -> Appearance and select the Theme tab. You can change the entire theme (colors, icons, borders, and so on) for your desktop. The default theme is Nodoka. Try any of the others to find one that suits you. Click Custom to mix and match attributes from different themes. Figure 3-4 shows the window for selecting a theme.
