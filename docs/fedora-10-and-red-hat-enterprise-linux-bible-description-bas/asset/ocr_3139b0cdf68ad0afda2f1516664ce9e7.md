Instead, you can use the chsh command to change the shell. The following is an example:

```
$ chsh -s /bin/tcsh jenny
```

The chsh command is handy because it enables a user to change his or her shell setting to any shell listed in the /etc/shells file. (The root user can change his own shell to any command he chooses.) Simply leave the user name currently logged-in user as the account to change.

Users can also change their user information using the chfn command. This information is stored in the /etc/passwd file and displayed when you type the finger command (for example, finger jenny). In this example, the full name, office name, office, home phone, and work phone are set by the user manager:

```
$ chfn -f "J Smith" -o "A-111" -p 555-1212 -h 555-2323 jenny
```

Users can also add information about themselves into the .project, and .pgpkey file in their home directory. That information will then be picked up by the finger command.

> NOTE: The finger command opens potential security issues. Finger gives out personal information that can be useful to those who want to crack your system. In addition, malicious users can flood your servers with finger requests.

# Modifying user accounts with User Manager

To use the desktop to change an existing account, you can use the User Manager. Here's how to add a new user to the User Manager window:

+   1. Select System -> Administration -> Users and Groups (or type system-config-users from a Terminal as root user). The main User Manager appears.

+   2. Select the user name of the account you want to modify, and then click the Properties button to open the Properties window (see Figure 11-3).

+   3. There are four tabs of information you can modify for the user selected:
* User Data — This tab contains the user information you created when you first added the account.
* Account Info — Select the Enable Account Expiration check box, and then type a date if you want the account to become inaccessible after a particular date.
