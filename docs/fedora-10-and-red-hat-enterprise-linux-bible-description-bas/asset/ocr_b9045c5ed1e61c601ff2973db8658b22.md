+   2. To create the user named bobby and a password i8er2shuz, use the GRANT command as follows:

```
mysql GRANT USAGE ON *.* IDENTIFIED BY "i8er2shuz";n-> TO bobby@localhost;
```

At this point, you can log in from the localhost using the name bobby and i8er2shuz password (mysql -u bobby -p). The user would have no privilege to work with any of the databases. Next you to grant privileges.

+   3. To grant privileges to the database called allusers, type the following:

```
mysql GRANT DELETE, INSERT, SELECT, UPDATE ON allusers.*
-> TO bobby@localhost;
```

In this example, the user named bobby is allowed to log in to the MySQL server on the localhost and access all tables from the allusers database (USE allusers). For that database, bobby can use the DELETE, INSERT, SELECT, and UPDATE commands.

+   4. To select the privileges you just granted, select mysql as your current database, and select the db table as:

```
mysql> USE mysql;
database changed
mysql> SELECT * FROM db WHERE="allusers";
```

The output shows all users who are specifically granted privileges to the allusers database. Only part of the output is shown here because it is very long.
