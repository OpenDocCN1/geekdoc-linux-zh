# Chapter 2: Installing Fedora 39

# Choosing Different Install Modes

Although most computers with more than 192M of RAM automatically install Fedora in the default mode (graphical), there may be times when your video card does not support that mode. Also, although the install process will detect most computer hardware, there may be times when your hard disk, Ethernet card, or critical piece of hardware cannot be detected and you'll need to enter special information at boot time.

The following is a list of different installation options you can use to start the Fedora install process. You would typically try these only if the default mode failed (that is, if the screen is garbled or installation failed at some point). For a list of supported modes, refer to the `/usr/share/anaconda/anacondaline.txt` file (if you have a running Fedora system with the anaconda package installed) or press F1 through F5 keys to see some descriptions of these types.

To use these options, highlight the first entry on the boot menu and press Tab. When the boot command appears at the bottom of the screen, type the options you want at the end of that line and press Enter to boot the install process.

+   **text: Type Text** to run installation in a text-based mode. Do this if installation doesn't seem to recognize your graphics card. The installation screens aren't pretty, but they work just as well.

+   **ks: Type ks** to run a Fedora installation using a kickstart file. A kickstart file provides some or all of the installation options you would otherwise have to select manually. (A section on creating and using kickstart files is contained in this later.)

+   **lowres: Type lowres** to run installation in 640 x 480 screen resolution for graphics cards that can't support the higher resolution. To choose a particular resolution, use the **resolution option**. For example:resolution=1024x768.

+   **noprobe: Type noprobe** to run determine what hardware you have on your computer. In **noprobe** mode, installation will not probe to determine hardware; you will be asked to load any special drivers that might be needed to install it.

+   **mediacheck: Type mediacheck** to check your DVD before installing. Media checking is done next in the normal installation process, you should do this only to test the media on a computer you are not installing on. For Fedora CDs, select the Verify and Boot option to check the CD before booting.

+   **rescue: The rescue mode** is not really an installation mode. This mode boots from DVD or CD, mounts your hard disk, and lets you access useful utilities to correct problems preventing your Linux system from operating properly.
