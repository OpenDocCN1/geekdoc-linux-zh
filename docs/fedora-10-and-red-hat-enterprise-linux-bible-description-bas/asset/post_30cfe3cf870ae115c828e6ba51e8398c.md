
# Chapter 1: An Overview of Fedora and Red Hat Enterprise Linux

Despite its lack of formal support, however, Fedora is used today in many businesses, schools, and homes around the world. In whatever way you plan to ultimately use Fedora, it is without a doubt a good way to learn and use the latest Linux technology as it is released to the Linux community before it makes its way to Red Hat Enterprise Linux.

Many companies and organizations choose between Fedora and RHEL, but instead offer a mixed-environment. As someone learning to use Fedora with this, you can quickly scale your use of this technology as far as you want to.

# Why Choose Fedora or Red Hat Enterprise Linux?

To distinguish itself from other versions of Linux, each addition includes in Linux distributions from established source projects (such as Apache, Samba, KDE, and so on), often enhancements for a particular distribution exist to make it easier to install, and use Linux. Also, because there are different software packages available to do the same jobs (such as window managers or a particular service), a distribution distinguishes itself by which packages it chooses to include and feature with its default installations.

Fedora is continuing the Red Hat tradition by offering features that set it apart from other Linux distributions. These features include:

- **Cutting-edge Linux technology** — In Fedora 10, major features include the KDE 4 Desktop, Firefox 3, OpenOffice.org, new Ext4 file system, and the latest Linux kernel.

- **Software packaging** — Red Hat, Inc. created the RPM Package Management (RPM) method of packaging Linux. RPMs allow less technically inclined users to easily install, search, manage, and verify Linux packages. With RPM tools, you can install from CD, hard disk, or over the Internet. It's easy to track which packages are installed or to look at the contents of a package. Because RPM is available to the Linux community it has one of the facto standards for packaging Linux.

Tools such as yum and PackageKit, which are built to take advantage of RPM technology, have been added to Fedora to extend your ability to install and update packages. These tools can point to online repositories, so the latest packages are often only a click away.

> CROSS-REFERENCE: Chapter 5 describes how to install RPM packages and use yum repositories.

- **Easy installation** — The Fedora installation software (called anaconda) provides easy steps for installing Linux. During installation, anaconda also helps you take the first few steps toward configuring Linux. You can choose which packages to install and how to partition your hard disk. You can even get your desktop GUI ready to go by configuring user accounts, keyboard, mouse and your network connection. With Fedora 10, you can install directly from a running live CD, or choose from several different install-only media.

CROSS-REFERENCE: Chapter 2 covers Fedora installation.

- **UNIX V-style run-level scripts** — To have your system services (daemon processes) start up and shut down in an organized way, Fedora and RHEL support the Unix V mechanism for starting and stopping services. Shell scripts (that are easy to read and change) are contained in subdirectories of /etc. When the run level changes, as when the system boots up or goes to single-user mode, messages tell you whether each service started correctly or failed to execute properly. Chapter 12 describes how to runlevel scripts and how these services are evolving away from System V.

- **Desktop environments (GNOME and KDE)** — To make it easier to use Linux, Fedora and RHEL come packaged with the GNOME and KDE desktop environments. GNOME is installed by default and offers some new features that include drag-and-drop protocols and tools for configuring the desktop look and feel. KDE is another popular desktop manager that includes a wide range of tools tailored for the KDE environment, such as the Konqueror web Browser. You can try out Fedora live CDs for GNOME and KDE, and then install software from those CDs directly to your hard disk. (This book includes the KDE CD.)

- **GUI Administration tools** — There are many helpful configuration tools for setting up some of the trickier tasks in Linux. Several different GUI tools provide a graphical, form-driven interface for configuring networking, users, file systems, and initialization services. Instead of creating command line orders or having to edit tricky configuration files, these graphical tools can set those files automatically.

> NOTE: There are advantages and disadvantages of using a GUI-based program to manage text-based configuration files. GUI-based configuration tools can lead you through a setup procedure and error-check the information you enter. However, some features cannot be accessed through the GUI, and if something goes wrong, it can be tricky to debug. With Linux, you have the command-line options available as well as the GUI administration tools.

- **Testing** — The exact configuration that you get on the Fedora or RHEL distribution has been thoroughly tested by experts around the world. Because Fedora is represented by a single huge software repository, the most intensely tested software will be that is offered in official CD and DVD versions of Fedora.

- **Automatic updates** — The software packages that make up Fedora are constantly fixed in various years. To provide a mechanism for the automatic selection, download, and installation of updated software packages, Fedora and RHEL rely primarily on the yum facility.

With the addition of yum software repositories on the Internet that include Fedora packages, whole sets of RPM software packages can be updated with a yum update command. The PackageKit facility provides graphical tools with Fedora to install.

# Better Printing

In a revamp aimed at making life easier, the system-config-printer got an overhaul. Printing has long been an area where Linux was difficult to use. In addition, you no longer need to be the root user to modify printers.

# FirstKit

This project consolidates a number of system tools into one application. The goal is that if your system shows problems, you can run FirstKit and it will do what is necessary to fix it. FirstKit does this by supporting plugins. Each plugin diagnoses a different part of the system. In Fedora 10, FirstKit ships with three plugins. Many more are under development.

# OpenOffice.org 3

OpenOffice.3.0 provides a major upgrade to the 2.4 versions of this office suite. OpenOffice was designed as a drop-in for Microsoft Office. Major improvements in OpenOffice.3.0 include support for Microsoft Office 2007 file formats, a numeric solver, and over 1024 columns per sheet (up from 256) in the spreadsheet package, called Calc. See Chapter 6 for more detail on OpenOffice.org.

# K Desktop Environment (KDE) 4

KDE 4 makes a major revision of the popular desktop environment. The new Plasma desktop should provide a framework for KDE 4 enhancements. With Plasma, you get a new look-and-feel, new ways of finding applications, files and URLs, and new "widget" technology that lets you run the mini-applications on the desktop or on panels.

The Dolphin File Manager was added to provide a more streamlined tool for managing files and folders for daily use. Desktop configuration features are now available on New System Settings. For details on using the KDE 4 desktop, refer to Chapter 3.

To let you immediately try out KDE 4, we have included the Fedora 10 KDE desktop live CD. You can boot live CD directly to a KDE 4 desktop system, if you choose, you can install that desktop system directly to your hard disk if you choose.
