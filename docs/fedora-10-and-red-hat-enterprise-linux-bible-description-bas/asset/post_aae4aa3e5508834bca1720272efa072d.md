
# Working with Graphics

Tools for creating and manipulating graphics are becoming both more plentiful and more powerful in Linux. Leading the list is the GNU Image Manipulation Program (The GIMP), or sometimes just GIMP. GIMP lets you compose and retouch images as you retouch photographs. Other tools that come with Fedora and RHEL for creating graphics include knsnapshot (a program for taking screen captures) and Inkscape for creating graphics vectors.

# Manipulating images with GIMP

The GIMP is a free software program that comes with Fedora and RHEL for manipulating photographs and graphical images. To create images with GIMP, you can either import a drawing, or 3D image, or you can create one from scratch. From the Applications menu by clicking Graphics -> The GIMP or by typing gimp from a Terminal.

GIMP 2.6 represents one of the most significant new releases of GIMP for some time. Many of the new features aim at improving the needed by professional designers. All selection tools let designers select rectangular areas with rounded corners. A slider was added to let you more specifically select brush sizes. New grid and alignment features make it easier to align layers, paths or guides. Digital photo editing has with built-in red-eye removal, free-screen editing, and new cropping and pruning tools.

In many ways, GIMP is similar to Adobe Photoshop. Some people feel that GIMP's scripting features are comparable to, or even better than, Actions in Adobe Photoshop. One capability in GIMP which has been behind Photoshop has the area of color management. The latest features of GIMP, however, you can calibrate screens and work with color profiles from your cameras and scanners (http://docs.gimp.org/en/gimp-color-management.html).

One of the easiest to become familiar with GIMP is to crop, or trim an image already on your computer. To crop a file, follow these steps:

1. Start GIMP and open an image file.
2. Right-click on the image. From the contextual menu that appears, select Tools -> Transform Tools -> Crop. The crop cursor appears (a cross and knife icon).
3. Position the cursor at the upper-left corner of the area that you want to crop. Click and drag the cursor to the lower-right corner of the area to be cropped. A selection rectangle will appear around the selected area as you do.
4. Release the mouse button. Four selection squares appear in the corners of the border around the selected area. Click and drag the handles to resize the border.
5. When the border is in the right place, press the Enter key. The image will be cropped to the border.

> TIP: If you make a mistake, select Edit -> Undo from the GIMP menu or press the Ctrl+Z key combination. Ctrl+Y to redo changes.

# Taking screen captures

If you want to show examples of the work you do on Fedora or RHEL, you can use the Screen Capture to capture screen images. The knapshot command is part of kdegraphics package contained on the media that comes with this book.

> NOTE: If you don't have knapshot installed, you can also use gnome-screenshot to capture screenshots of your desktop.

To open Screen Capture, from the Applications menu click Graphics -> Knapshot (or type knapshot). Figure 6-10 shows an example of the Screen Capture program.

# Part II: Using Fedora RHEL

When Screen Capture first opens, it takes a snapshot of the full desktop. Buttons on the window offering the following options:

- **Snapshot** — Select the capture mode (Full Screen, Window under cursor, or Region).
- **Save As** — Save the snapshot to a file in X bitmap, Windows icon, PNG, portable pixmap, JPEG, X pixmap, Encapsulated PostScript, or Windows BMP formats.
- **Copy to Clipboard** — Copy the image to the clipboard, so it can be pasted into a document, image editor, or other application.
- **Print** — Have the snapshot to your printer.

You can select a capture mode other than the default Full Screen. For example you can choose to capture the window under the cursor, a particular region of the desktop (hold down the mouse and drag a box open), or a section of a window (the element of the window to be captured will highlight). You can also delay the snapshot for a set number of seconds.

# Creating vector graphic images with Inkscape

When you need to have maximum flexibility with graphics and text, a vector graphic editor can deal with geometric elements (such as lines, curves, and boxes) instead of dots (as you do with image editors). As a result, you usually get cleaner edges on your fonts and graphics the ability to bind and shape elements as you like. Inkscape (http://www.inkscape.org) is a popular vector graphics editor that is available with Fedora.

With Inkscape, you have an application with features similar to those you would find in commercial products such as Adobe Illustrator and CorelDraw. Inkscape creates images in Scalable Vector Graphics (SVG) format — an open standard from the W3C (http://www.w3.org/Graphics/SVG). Thousands of SVG graphics and clipart elements are available in the public domain or under Creative Commons licenses.

In Fedora, install the inkscape package to get Inkscape. I recommend you install the openclart package, which will give you hundreds of clipart items to use in your Inkscape creations. With the inkscape and openclart packages installed, select Applications -> Graphics -> Inkscape Vector Graphics Editor to open an Inkscape window. You can start by opening one of the dozens of templates available (File -> New and choose from banner, business card, cover, or others). With the window there are some ways to get started:

- **Add text** — From the toolbar, select text tool.
- **Add graphical elements** — From the toolbar, select rectangle, circles.
- **Add clipart** — If you opened the clipart gallery, you can import from there. Select File -> Import and browse /usr/share/clipart.
- **Group objects** — Select a text or clipart object, hold the Shift key and select other objects. When all the objects in your group are selected, choose Object Group.
- **Use layers** — Select the Layer to add, delete, raise or lower.

When you are creating your graphic, you can print that graphic by selecting File -> Print. From the printer window, you can select the image in vector or bitmap format from the Rendering tab.
