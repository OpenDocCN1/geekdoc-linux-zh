### Return to Castle Wolfenstein

Mixing World II action with creatures battle with the Allies to destroy the Third Reich. Return to Castle Wolfenstein is based on the Quake III engine. The game offers single-player mode as well as team-based multiplayer mode.

### Using Fedora RHEL

If you purchase Return to Castle Wolfenstein for Linux, you actually get the Windows version with an extra Linux installer. If you already have the Windows version, you can download the Linux installer and follow some instructions to get it: wolf-linux-1.4bx86 from ftp.idsoftware.com/idstuff/wolf/. The INSTALL file (in /usr/local/games/wolfenstein) describes what files you need to copy from the Windows CD. You can buy the Linux installer from http://www.linuxgaming.com.

To get a demo of Return to Castle Wolfenstein, go to http://www.idsoftware.com/games/wolfenstein/rtcw/index.php?game_section=overview. Both single-player and multiplayer demo are available.

> NOTE: You need an NVIDIA card to run Return to Castle Wolfenstein.

### Gaming with Cedega

TransGaming Technologies (http://www.transgaming.com) brings to Linux some of the most popular games that currently run on Windows platforms. Working with Wine developers, TransGaming is developing Cedega, which enables you to run many different games on Linux that were originally developed for Windows. Although TransGaming is producing a few games that are packaged separately and tuned for Linux, in most cases it sells you a subscription service to Cedega instead of the games. That subscription service lets you stay up-to-date on the continuing development of Cedega so you can run more more Windows games.

> NOTE: You may need to obtain a vanilla kernel from kernel.org and boot that on your system before running games with Cedega.

How well Windows games run in Linux, Cedega needs to develop DirectX features that are required by many of today's games. There are also issues relating to CD keys and hooks into the Windows system that must be overcome (like Microsoft Active Desktop). In fact, a Cedega subscription has value, in part, because it lets you vote on which games you'd like to see TransGaming work on.

A full list of games by TransGaming, also with indications of how popular they are and how well they work, is available from the TransGaming.org site (http://games.cedega.com/db). Browse games by category or alphabetically. Games that are officially supported by TransGaming are marked by an asterisk. On each game description page is a link to a related Wiki, which gives details about how well the games work under Cedega and tips for getting it to work better.

TransGaming added new features to the Cedega GUI (formerly Point2). The Cedega GUI provides a graphical window for installing, configuring, and testing Cedega on your computer. It also lets you install and organize your games so you can launch them graphically. Figure 7-7 shows an example of the Cedega GUI in Linux.

![](img/63c86e1d25a0e2be7e9f6deb6f02530_348_0.png)

Figure 7-7: Use the Cedega GUI window to check computer hardware and tools for features.

Features in the new Cedega GUI include a new look-and-feel and tools for individually configuring how each game runs under Cedega. (If a game won't run from the GUI, try launching it from a terminal window.)

You can download a free 14-day trial of Cedega that is fully functional for that limited time. To get the full benefits of Cedega, you need to subscribe to TransGaming. For details how to become a “TransGamer,” click Subscribe Here on the TransGaming home page (http://www.transgaming.com). Benefits currently include:

- Downloads of the latest version of Cedega
- Access to Cedega support forums
- Ability to vote on which games you want TransGaming to support next
- Subscription to the Cedega newsletter

Cedega used to be known as WineX. The source code for WineX may become available in the near future until you build your own WineX/Cedega package. To check availability, the SourceForge.net project site for WineX (sourceforge.net/projects/winex).
