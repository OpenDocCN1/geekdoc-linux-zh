# Detecting your sound driver

During the first-start after you install Fedora, the Firstboot setup agent tries to detect and configure your sound. If that was not successful, Red Hat will recommend you a bug report. Unlike previous releases, sound detection “just work” in current releases. You can adjust settings with the Sound choice or the Preferences menu.

For Fedora 8 and prior releases, you can use the system-config-soundcard command, described following. This command no longer ships with Fedora starting with Fedora 9.

> TIP: Audio may be muted when you first install Fedora or RHEL. If you are not able to hear the test of your sound card, use Volume Control or alsamixer (as described in this chapter) to unmute and adjust the volume on your audio input.

To open the Audio Configuration window, use the system-config-soundcard command. If your sound card was detected, the Audio Configuration window should appear, as shown in Figure 8-1. Click the button to the left of the slider and you will hear a test sound. You can move the slider to make sure volume is high enough to hear it.

The Audio Configuration window contains three tables of settings you want to adjust:

+   - Sound test — In addition to letting you test your sound card, this shows information about each sound card you have installed. If your sound card isn't working, using the Vendor, Model, and Module information when you ask for help. You can also change the PCM device from this table, to try different outputs from the card.
- Settings — If you have multiple sound cards, you can select which card to use by default (Default Audio Card) and the Default PCM Device for that card (identifying where output is). From the Settings tab, you can also select Disable Specific Card Configuration, to override default settings. Likewise, you can change the order in which audio cards are used on your system.
