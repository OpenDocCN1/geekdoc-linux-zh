Here are some other options you could add along the mount command:

+   - t auto — If you're not exactly what type of file system is contained on the floppy disk (or what medium you are mounting), use the -t auto option to indicate the file system type. The mount command will query the disk to try to get what type of data it contains.
- -r — If you don't want to make changes to the file system (or it is a read-only medium), use this option when you mount it. This will mount read-only.
- -w — This mounts the file with read/write permission.

# Mount CD or DVD images

Another valuable way is to use the mount command to view ISO disk images. If you download a CD, DVD, or floppy disk image any from the Internet and want to see what it contains, you can do so without burning it to CD or floppy. With the image on your hard disk, you can create a mount point and use the -o loop option to mount it locally. Here's an example of what to type (as root user):

```
# mkdir /mnt/mycdimage
# mount -o loop whatever-i386-discl.iso /mnt/mycdimage
```

In this example, the disk image (whatever-i386-discl.iso) residing in the directory is mounted on the /mnt/mycdimage directory I created. I can now do that to view the directory, view its contents, or copy any of them. This is useful for downloaded CD images that you want to install software without having to burn the image to CD. When you are done, use type mount /mnt/mycdimage to unmount it.

Other options to mount are available only for a specific file system type. The mount manual for those and other useful options.
