# Mounting removable media

If you want to mount a file system manually, the /etc/fstab file makes it simple to mount a file system from any partition, floppy disk, or a CD-ROM. Although Fedora no longer adds entries for CDs and floppy disks to the /etc/fstab file, you could manually add entries, if you want to mount those media in different locations. Here are examples of entries you could add to your /etc/fstab file:

```
/dev/cdrom /mnt/cdrom auto noauto,user,exec,ro 0 0
/dev/fd0 /mnt/floppy auto noauto,owner 0 0
```

The /media directory is traditionally used to mount removable or temporary file systems in Linux. If you are adding points manually, it's best to use a location such as /mnt, instead of the newer /media directory, so you don't conflict with any file systems the Hal service (half daemon) mounts automatically in the /media directory.

With entries such as those shown, you can use the mount command with a single option to indicate what you want, and information is taken from the /etc/fstab file to fill in the other cases. The following are examples where you could mount a CD or floppy disk system using a single option (based on the /etc/fstab file shown above):

+   CD-ROM — If you are mounting a CD-ROM that is in the standard ISO 9960 format (as most CD-ROMs are), you can mount the CD-ROM by placing it in your CD-ROM drive and typing the following:

```
# mount /mnt/cdrom
```

By default, your CD-ROM is mounted on a point in the /media directory. The command shown above, mounts the /dev/cdrom device on the /mnt/cdrom directory.

+   Floppy Disk — If you are mounting a floppy disk that is in the standard Linux file system (ext3), based on the /etc/fstab file entry shown above, you can mount that floppy disk by inserting it in your floppy drive and typing the following:

```
# mount /mnt/floppy
```

The file system type (ext3), (/dev/fd0), and mount options are filled in from the /etc/fstab file. You should be able to change the floppy disk directory (cd /mnt/floppy) and list the contents of the floppy's top directory (ls).

> NOTE: In both of the previous cases, you could get the device name (/dev/cdrom or /dev/fd0) instead of the mount point directory to get the results.

Of course, it is possible that you may get floppy disks to use that are in all formats. Someone might give you a floppy containing files from a Microsoft operating system (MS-DOS format). Or you may get a file from another UNIX system. In those cases, you can fill in your own options, instead of relying on options from the /etc/fstab file.
