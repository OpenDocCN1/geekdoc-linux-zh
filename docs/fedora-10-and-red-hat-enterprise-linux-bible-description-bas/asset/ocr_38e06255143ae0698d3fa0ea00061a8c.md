# Running yum to download and install RPMs

With the repositories identified, downloading and installing an RPM is as simple as
running yum with the install option to request the RPM. With an active connection to the
Internet, open a Terminal window as root user.

The first thing yum does is download metadata and headers for all packages you might want
from each repository. After presenting you with the list of dependencies it thinks you
need, if you want to install the necessary packages. Here is an example of using the yum
command to download the madwifi media player:

```
# yum install madwifi
Setting up install Process
Parsing package install arguments
fedora           100% ========== 2.1 kB 00:00
atprms           100% ========== 951 B 00:00
Reading repository metadata in from local files
primary.xml.gz  100% ============ 2.5 MB 00:04

Transaction Summary
Install           4 Package(s) ==========================
Update             0 Package(s) ==========================
Remove             1 Package(s) ==========================
Total download size: 17M
Is this ok [y/N]: y
Downloading Packages
```

As you can see from this example, yum checked two different software repositories, Fedora
and atperms packages, for the current Fedora release. After listing the dependencies, yum asks
if it is OK to install them. Type y and the package and all its dependencies are installed. Note
