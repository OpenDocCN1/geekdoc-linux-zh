# Chapter 2: Installing Fedora

+   **Web Server** — Installs the packages that you would typically need for a Linux server types (in particular, Apache web server and print server). It does not include many other server types by default (FTP, DHCP, DNS, FTP, SQL, or news servers). The default server install also a GUI (GNOME only).

A recent feature in Fedora lets you select software repositories out of Fedora, from which you can select packages to install during the initial Fedora installation. Use the check box to be able to install from other software repositories. Select additional software repositories to add other repositories (such as Livna or ATRpm repositories, described in Chapter 5). Then, select the Customize Now button if you want to further select which packages in the selected tasks are installed:

+   **Customize Now** — Select the Customize Now button after selecting the task (or tasks) you want to install. This lets you see which categories from each task and packages within those categories are selected to be installed. It also adds or remove package selections. Note that packages from multiple repositories appear in the same category (for example, you would see games from both Fedora and Livna packages appearing in the Games category if the Livna packages were enabled).

Unlike previous versions, this version of Fedora does not offer an Everything type or a Minimal install. Select class instances you want, choose Customize Now to see the packages to be installed (based on install categories and package groups). Unselecting the major categories can get you a pretty good install, if you like to build from a bare-bones install. In the following step, the procedure will continue as though you had chosen Customize Now.

+   **13. Customize categories.** If you selected Customize Now, you are presented with categories of software on the left side of the screen and package groups on the right side.

Select a category to see which groups it contains. Select a group and click the Optional packages to see which optional packages are available in group and which are selected to be installed. Categories include:

+   **Desktop Environments** — The GNOME desktop environment is selected by default. KDE, SUGAR, and XCFE are the other available desktop environments. (Desktop environments are described in Chapter 3.)

+   **Applications** — This category includes packages of office applications, games, sound and video players, Internet tools, and other applications. (Many of these applications are described in Chapters 5 through 9.)

+   **Development** — General and specialized software development tools are included in packages in this category.

+   **Servers** — Packages in this category are for Web, mail, FTP, database, and a variety of other network server types.
