> NOTE: If you are a Linux user with a Win-modem and you are still baffled after referring to the linmodems.org site, you might consider getting a serial or USB modem. To try to get your Win-modem working, you might need to download, compile and load a modem driver. Especially with some older Win-modems, drivers have not been updated to work with the latest kernels. Picking up a cheap serial modem (under $20) from a used computer store can save hours of frustration that may still result in failure.

# Checking that your PPP interface is working

One way to check that the PPP interface is working is with the ping command. The Terminal window, type ping with any Internet address you know. For example:

```
$ ping handshistory.com
PING handshistory.com (198.60.22.28) from 192.168.0.43 : 56(84) bytes of data.
64 bytes from handshistory.com (198.60.22.28) : icmp_seq=0 ttl=240 time=120 ms
64 bytes from handshistory.com (198.60.22.28) : icmp_seq=1 ttl=240 time=116 ms
64 bytes from handshistory.com (198.60.22.28) : icmp_seq=2 ttl=240 time=120 ms
---
--- handshistory.com ping statistics
4 packets transmitted, 3 packets received, 25% packet loss
round-trip min/avg/max/mdev = 116.816/119.277/120.807/1.779 ms
```

Press Ctrl+C to end the ping command. The previous lines show the responses from handshistory.com send back packets from the IP address 198.60.22.8 to each one it received. You can see the sequence of packets (icmp_seq) and the time it took for each response (in milliseconds). If you receive packets in return, you will know two things: first, that your connection is working and second, that your name address translation (the DNS addresses in /etc/resolv.conf) is working.

