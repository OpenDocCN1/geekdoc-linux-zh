# Using the Nautilus file manager

At one time, file managers did little more than to run applications, create data files, and open folders. These days, file managers are expected to offer different browsing choices, preview file content, select different applications to use and access files on other computers. The Nautilus file manager, which is the default GNOME file manager, is an example of just a file manager.

When you open the Nautilus file manager window (from a GNOME menu or by opening the Home icon or other folder on your desktop), you see the name of the location you are viewing (such as the folder) and what that location contains (files, folders, and applications).
