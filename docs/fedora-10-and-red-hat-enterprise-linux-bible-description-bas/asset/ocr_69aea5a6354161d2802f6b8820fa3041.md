If you've ever suffered a hard drive crash, you just know how aggravating it can be. You lose irreplaceable countless hours reinstalling your operating system and applications. It is not a fun experience. It need happen only once for you to learn the importance of making regular backups of your critical data.

Today, larger and faster backup media can simplify the process of backing up your data. Fedora and RHEL support many different types of media — such as writable CD (CD-R and CD-RW), DVD (DVD-R, DVD+, DVD-RW, DVD-RW), and magnetic tape — for creating backups. Using tools such as cron, you can configure backups to run unattended at scheduled times.

This chapter describes how to create a backup strategy and how to select run for backing up data on your Fedora or RHEL system. It tells you how to do automated backups and backups over a network. It also describes how to restore individual files, or entire file systems, using tools such as the `restore` command.
