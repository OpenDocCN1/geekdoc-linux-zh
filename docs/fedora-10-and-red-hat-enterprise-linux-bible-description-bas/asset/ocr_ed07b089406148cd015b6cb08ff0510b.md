# Logging hits

Every incoming HTTP request generates an entry in the transfer log (by default, /etc/httpd/logs/access_log, which is a link to /var/log/httpd/access_log). Statistics packages and log file analysis programs use this file because manually reading it can be a tedious exercise. (See the information on the logwatch facility in Chapter 14).

The format of the log can be altered by the LogFormat and CustomLog directives in the httpd.conf file, as is defined in the "Configuring the Web server (httpd.conf)" section. If you attempted to access http://localhost/ (the "common" format) it would be written as Figure 21-1), the following lines (in the "common" format) would be: access_log:

```
127.0.0.1 - [28/Apr/2008:02:23:33 -0600] "GET /HTTP/1.1" 403 3931 -"Mozilla/5.0 (X11; Linux i6686; rv:7.3) Gecko/20040102 Firefox/0.10.1"
127.0.0.1 - [localhost] [28/Apr/2008:02:23:34 -0600] "GET /icons/powered_pb2.gif HTTP/1.1" 200 2414 -"Mozilla/5.0 (X11; Linux i6686; rv:7.3) Gecko/20040102 Firefox/0.10.1"
127.0.0.1 - [localhost] [28/Apr/2008:02:23:44 -0600] "GET /icons/powered_by_fedora.png HTTP/1.1" 200 2243 -"Mozilla/5.0 (X11; Linux i6686; rv:7.3) Gecko/20040102 Firefox/0.10.1"
```

The Apache Test Page actually is an error condition (403), which indicates that the Apache server is running, but the administrator of the server hasn't added a home page yet. The next two lines show the Apache (apache_pb2.gif) icons that appear on the test page, respectively, for Fedora (powered_by_fedora.png) icons. (RHEL systems have a Red Hat icon).

Viewing the server-info and server-status pages (as shown in Figures 21-3 and 21-4, respectively) generated the following events:

```
127.0.0.1 - [26/Apr/2008:23:40:41 -0400] "GET /server-info HTTP/1.1" 200 42632
127.0.0.1 - [26/Apr/2008:23:41:49 -0400] "GET /server-status HTTP/1.1" 200 1504
```

The denied attempt to access the server-status page logged the following line (note the 403 server response code):

```
127.0.0.1 - [26/Apr/2008:23:43:07 -0400] "GET /server-status HTTP/1.1" 403 211
```
