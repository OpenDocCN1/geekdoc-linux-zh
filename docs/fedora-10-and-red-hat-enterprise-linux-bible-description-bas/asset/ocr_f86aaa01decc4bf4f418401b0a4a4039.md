TIP: It is not necessary to be connected to a network (even to have a network connection) just to test the server or to view the files on your local Apache machine. Rather than specify the server's real name in the URL, just use "localhost" (that is, http://localhost/) from a browser on the same computer. In fact, it is best to test the configuration before making the server accessible on an unprotected network.

The Test Page is actually an error condition, indicating that you haven't added any content to your Web site. To get started, you can add an index.html file that contains your own home page content in the /var/html directory. Then you can continue to add your own content to that directory.

# # Configuring the Apache Server

The primary file for configuring your Apache Web server is httpd.conf (located in the /etc/httpd/conf directory). After a few ages, the Apache project began recommending not using additional configuration files, such as rm.conf and access.conf, and simply putting everything in httpd.conf. In recent releases, however, has been a trend toward having modules and other components that are used with Apache have their own configuration files (usually located in the /etc/httpd/conf/ directory).

All Apache configuration files are plain-text files and can be edited with your favorite text editor. The /etc/httpd/conf/httpd.conf file is reproduced in its entirety in the following section, with conflations inserted after related blocks of options (intended to supplement the comments with each file).

Some modules, scripts and other services related to Apache, such as perl, php, ssl, webizer, and mysql, have individual configuration files that may interest you. Those files are contained in the /etc/httpd/conf.d/ directory. The “Configuring modules and related services (/etc/httpd/conf.d.*conf)” section later in this chapter discusses modules and related features.
