# Printer Sharing

You can print sharing using netalk so that Macs using the standard AppleTalk print service (called Printer Access Protocol, or PAP) can print to your Linux computer. To do that, you must:

+   - Configure a local Linux printer (see Chapter 17).
- Set up the /etc/atalk/papd.conf file to point to that printer.
- Restart the netalk service (or, more specifically, the papd daemon).

When a client prints to a Linux configured in this way, the job is handled by the standard Netalk lpd daemon and put into a spool file for printing, with Apple Linux print jobs for the printer.

> NOTE: Mac OS X computers can print directly to Linux print services (CUPS or LPRng) without requiring netalk printing. Older Mac OS 9 clients however, might need to see an AppleTalk printer that you set up in this way with netalk.

The papd.conf file follows the same basic format as the /etc/printcap file (traditionally used for printing). Here's an example of a configured in the papd.conf file:

```
LaserJet2100M:
pr=:usr/bin/lpr -P hp01:
ppd=/etc/atalk/laserjet.ppd:
oproot=\nam:uams_quest.so.
```

The printer in this example is named LaserJet2100M. To print the file from the Mac client, it takes the output and pipes it to the lpr -P hp0 command (hp01 is the name of the local printer). The ppd file is /etc/atalk/laserjet.ppd. The root user is the operator, and guests are allowed to the printer (no password is needed).

The printer definition file (ppd) must be installed on both the netalk server (at the location noted in the papd.conf file) and on the Mac client.
