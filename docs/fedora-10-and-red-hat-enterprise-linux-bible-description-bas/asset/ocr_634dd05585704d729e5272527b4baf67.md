The bottom of the server-status pages lists each server by process ID (PID) and indicates its state, using the same possible values. Figure 21-4 shows an example of this page.

The server-status page can also perform automatic updates to provide even monitoring of the server. If the URL http://localhost/server-status?refresh=40 is specified, the server-status page displayed in your browser will be updated every 40 seconds. This enables a browser window to continuously monitor the activities of the Web server.
