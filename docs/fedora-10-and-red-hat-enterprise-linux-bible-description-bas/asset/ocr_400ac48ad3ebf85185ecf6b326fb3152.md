Many packages have configuration files associated with them. To see what configuration files are associated with a particular package, use the -c option with a query. For example, this is what you would type to find configuration files that are used with the *ppp* package:

```
# rpm -qqc ppp
/etc/logrotate.d/ppp
/etc/pam.d/ppp
/etc/ppp/chap-secrets
/etc/ppp/options
/etc/ppp/pap-secrets
```

If you want to know which particular command or configuration file came from, you can use the -qf option. In this example, the -qf option displays the fact that the `chgrp` command came from the fileutils package:

```
# rpm -qf /bin/chgrp
coreutils-6.12-10.fc1.i386
```

Before you install a package, you can do the same on it that you would do on an installed package. If it is in your current directory, or in a software repository, here is an example of using the -qp option with -i to see the description of a package in a software repository:

```
# rpm -qp -i \
http://aio.fshprnms.net/fedora/Linux/9/i386/FreeDahls/RPMs/a52dec-0.7.4-8.fc7.i386.rpm
```
