The primary function of Wireshark is to take a snapshot of packets coming across your network interfaces and display data in the Wireshark window. You can filter the data based on a variety of filters. When the capture is done, you can step through and sort the data based on the different columns. Optionally, you can save the captured data to a file to study the data at a later time.

> TIP: If you cannot use Wireshark because you don't have a GUI application, you can use the tcpdump command from the shell. It is not as friendly as Wireshark, but it supports the filtering syntax. tcpdump can produce a lot of output, you will probably want to use some form of filtering or direct the output of the command to a file. (Type tcpdump for information on filter options.)
