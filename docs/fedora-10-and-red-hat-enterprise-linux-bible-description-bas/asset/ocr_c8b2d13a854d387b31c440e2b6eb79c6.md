The required authconfig command sets the type of authentication to protect your user passwords. The --shadow option enables the /etc/shadow file to store your passwords. The --passalgo=sha512 option enables SHA512-based encryption for the passwords. (You would typically use both.)

```
authconfig --enabled --passalgo=sha512
```

The selinux command indicates whether or not Security Enhanced Linux is enabled. The following line shows it as enabled and enforcing:

```
selinux --enforcing
```

The timezone command sets the time zone for your Linux system. The default, shown here is United States, New York (America/New_York). The --utc option indicates that the computer's hardware clock is set to UTC time. If you don't set a time zone, US/Eastern is used. Run the timezone command to see other time zones.

```
timezone --utc America/New_York
```

The bootloader command sets the location of the boot loader (GRUB, by default). For example, --mbr adds GRUB to the master boot record. (Use --location=none to not add GRUB.) The driveorder option describes which hard disk to look on for the master boot record. You can also add kernel options to be read at time using the append option (--append=id-scsi) or an optional password for GR (--password=GRUBpassword).

```
bootloader --location=mbr --driveorder=sda --append=rhgb quiet
password=GRUBpassword
```

The clearpart linux removes Linux partitions (or use --clear all partitions) on the first hard drive (--drives=sda). The part / swap sets the file system type (--fst) and partition name (onpart) for each partition assignment. You can also set sizes of the partitions to have many megabytes you want. You can also create logical volume group (volgroup) and individual volume entries for your partitioning.
