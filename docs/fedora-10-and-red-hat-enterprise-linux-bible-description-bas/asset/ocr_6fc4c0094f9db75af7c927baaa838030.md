+   - **FTP** — This represents File Transfer Protocol (FTP) proxy services. When you enable HTTP for a client, you enable FTP automatically (for example, `http://ftp.ab.com`).

+   - **Gopher** — The gopher protocol proxy service was one of the first mechanisms for organizing and searching documents on the Internet ( predates the Web by more than a decade). Nobody uses gopher. However, gopher is automatically supported when you use HTTP for a client.

Besides allowing proxy services, Squid can also be part of an Internet cache hierarchy. C occurs when content is taken from the original server and copied to a caching server that is local. When you, or someone else in the caching hierarchy, requests that contain content, it can be taken from the caching server instead of the original server.

You don't have to cache Internet content for other computers to participate in caching with Squid. If you have a parent caching-computer that will allow you access, you can identify that computer in Squid and speed up your Web browsing.

Caching services in Squid are provided through your Linux system's IPC port. Besides IPC services, you can also enable Simple Network Protocol (SNMP) services. SNMP lets you provide statistics and status information about itself to SNMP agents on the network. SNMP is a feature for monitoring and maintaining computer resources on a network.

> CAUTION: SNMP poses a potential security risk if it is not configured properly. Use caution when configuring SNMP with Squid.

The squid daemon /usr/sbin/squid can be started automatically at system boot time. After it is set up, the configuration for Squid is done in the /etc/squid/squid.conf file. The Squid.conf file contains lots of information about how to configure Squid (the file contains more than 4300 lines of comments and examples, although there are only 35 lines of active settings).

For further information about the Squid proxy server, refer to the Squid Web Proxy Cache page (www.squid-cache.org).

# Starting the squid daemon

When you install Fedora or RHEL, you have an opportunity to install Squid (squid package). If you are not sure whether or not Squid is installed, the type following:

```
rpm -q squid
squid-3.0.STABLE10-1.fc10.i386
```

If squid is not installed, you can install it from the DVD with this book or by typing yum install to install it over the network. Next you can check whether or not squid is configured to run. To do that, type the following:

```
chkconfig --list squid
squid 0:off 1:off 2:off 3:off 4:off 5:off 6:off
```
