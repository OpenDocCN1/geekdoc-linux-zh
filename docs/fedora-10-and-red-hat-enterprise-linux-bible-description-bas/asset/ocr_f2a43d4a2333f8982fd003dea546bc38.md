# Setting file and directory permissions

Permissions on shared volumes tend to be wider open than would typically be the
case on shared Linux directories in order to match the expectations that Mac users generally
have permissions.

In particular, the set-GID (group) bit is often turned on for directories. By using the set G
feature, any file or directory created will be owned by the associated group.
For example, follow these steps as root user from the shell (creating any directory name
to share):

```
# mkdir /var/toyprojects
# chown chris /var/toyprojects
# chgrp toygroup /var/toyprojects
# chmod 2775 /var/toyprojects
# ls -ld /var/toyprojects
drwxr-x 2 chris 4096 Mar 16 13:32
/var/toyprojects
```

In this example, I prepared a directory to be shared by called /var/toyprojects. I
made the owner of the directory (use your user name). I created a group
(see Chapter 11 for creating groups) and called it toygroup. Then I set the permission to
2775 on the directory, which means that the set-GID bit is on, the owner (chris)
has full read/write/execute permission (7), the group (toygroup) has full read/write/execute
permission (7), and other have only read and execute permissions (5).
