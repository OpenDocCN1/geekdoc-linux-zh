The previous block of options deals with how server-generated indexes are handled. The Options FancyIndexing VersionSort NameWidth=* directive enables an autogenerated directory index to include several bits of information about each file directory, including an icon representing the file type, the last modification time for the file, the file's size, and a description of the file. Figure 21-2 shows an example of a directory using FancyIndexing settings.

The VersionSort option allows files that version numbers to be sorted as most natural (so, for example, version-2 comes before version-10 with this option). The NameWidth=* option allows filenames of any length to be displayed. You change the asterisk to represent the maximum number of characters that can be displayed in the Name column. If Indexes is not set to FancyIndexing, the index lists only the file's name.

The AddIconByEncoding directive is used to configure the output of FancyIndexing. It causes a particular icon to be displayed for files matching a particular MIME encoding. The AddIconByEncoding line in the previous example, compressed.gif (with an alternative image tag of CMP for browsers that don't load images) files with a MIME encoding of x-gzip and x-zip. The AddIconByType has the same syntax as matches files based on their MIME type.
