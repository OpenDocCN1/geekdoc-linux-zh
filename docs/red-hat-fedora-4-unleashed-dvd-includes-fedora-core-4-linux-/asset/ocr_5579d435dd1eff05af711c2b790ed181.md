# Automounting with the Automount Daemon (amd) and autofd

The automount daemon will watch specified devices and will mount the devices when they are accessed and unmount them when there has been no activity. The configuration files are /etc/auto.master and /etc/auto.misc. The former file contains only comments; the latter contains examples and the sole entry used by Fedora Core to automount the CD-ROM drive. If you insert a CD, after a long pause, a file browser will appear on your desktop. Many people find this behavior annoying and prefer to disable automount.
