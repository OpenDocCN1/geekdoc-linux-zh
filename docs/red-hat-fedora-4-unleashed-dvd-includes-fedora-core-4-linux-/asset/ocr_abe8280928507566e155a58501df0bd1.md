Note that using a reverse lookup does not tell you the Fully Qualified Domain name of the server using that IP address. To determine that, we need to use the whois client.

# **whois**

A command-line utility from the whois package, whois queries the database at whois. networksolutions.com.

For an IP lookup

```
```
$ whois 165.193.130.83
