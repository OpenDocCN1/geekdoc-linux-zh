# FIGURE 3.9  Set partition information about a selected or new partition on a hard drive.

You use the Add Partition dialog to assign a mount point (such as /boot or /), assign a filesystem (such as ext2, ext3, RAID, swap, or vfat) by using the drop-down menu set at ext3 by default, and assign the size of the partition. Remember that, at a minimum, your system should have a root (/) and swap partition.
