Several programs are available for Unix systems to connect to news servers to read and post articles in newsgroups. The following sections describe the newsreaders that are available with the Fedora Core Linux distribution.

# The s1rn News Client

The s1rn program is a text-based newsreader program included with the Fedora Core distribution. It uses the ncurses package to paint text-based windows on the terminal screen. s1rn can be used to both read and post articles to newsgroups on a configured news server. If you want to use the same newsreader on different platforms, s1rn runs on Linux, Mac, OS2, BeOS, Windows, and VMX. It now provides true offline reading capabilities.

The s1rn program is included in the s1rn RPM package; you install it by using the yum or rpm command. After you have installed s1rn, you need to create a local configuration file. Begin by setting an environmental variable:

```
$ export NNTSERVER=news.andbhudson.co.uk
```

Of course, you will use your own news servers' domain name.

Then create you local configuration file with

```
$ s1rn -f .jnews.rc -- create
```

and launch s1rn. The configuration file, located at /etc/s1rn.rc, is a well-commented file that is easy to modify and customize.

When s1rn starts, it displays a list of the groups that are available on the news server. You select the group you want to read articles from, and then select the individual articles. Figure 8.15 shows a s1rn screen example.

# The Pan News Client

Pan is a graphical newsreader client that works with GNOME and is the default newsreader for Fedora. If you have the GNOME libraries installed (and they usually are installed by default), you can also use Pan with the K Desktop Environment (KDE). Pan has the capability to download and display all the newsgroups and display posted news articles. You can launch it by using the GNOME or KDE desktop panel or from the command line of an X terminal window with the command pan 8. Pan supports combining multipart messages and the yec encoding/decoding protocol. Figure 8.16 shows a sample Pan display. Unlike the s1rn program, Pan does not require a systemwide default or user-defined NNTPSERVER environment variable to define the news server address, but you do need to configure Pan.
