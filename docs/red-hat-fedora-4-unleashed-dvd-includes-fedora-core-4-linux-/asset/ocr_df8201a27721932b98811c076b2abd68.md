# Math

Like any modern programming language, PHP gives you a number of functions that handle a variety of mathematical functions, from calculating sine and cosine values to generating random numbers.

As with strings, we cover the most important subset, ordered from easiest to hardest.

First up are round(), floor(), and ceil(), which are functions that handle the rounding of floating-point numbers in different ways. The floor() function rounds a number down to its nearest whole integer, so 14.1, 14.5, and 14.9 all are rounded down to 14. The ceil() function does the opposite: It rounds numbers up to the nearest whole integer, meaning that 14.1, 14.5, and 14.9 are all rounded to 15. The round() function sits in the middle. If the fraction is 0.5 or greater, it rounds up; otherwise, it rounds down. Here's an example:

```
```
<?php
    echo floor(14.5) . "\n";
    echo ceil(14.5) . "\n";
    echo round(14.5) . "\n";
    echo round(14.4) . "\n";
?>
```
```

That outputs 14, 15, 15, and 14 because floor() rounds 14.5 down, ceil() rounds 14.5 up, round() also rounds 14.5 up, but round() rounds 14.4 down.

Performing any sort of trigonometry makes sine, cosine, and tangent calculation a must, and PHP provides the sin(), cos(), and tan() functions for this purpose. Each of these accepts a parameter in radians and returns the sine value for that input. If you are used to working with degrees rather than radians, you can convert them with the deg2rad() function, like this:

```
```php
 echo sin(deg2rad(90));
```
```

That returns the sine of 90°. Calculating cosine and tangent is as easy as replacing sin() with cos() or tan(). Keep in mind that the actual values of these mathematical functions are rounded internally by PHP and so cannot be relied on for very precise mathematics.

Another common mathematical function is calculating the square root of a number, which can be accomplished in PHP with the sqrt() function. This works precisely as you would imagine: You pass in the number you want to square root, and it returns the result:

```
```php
 echo sqrt(2);
```
```

You can also calculate the square root of a number by using the pow() function, which is designed to raise a number to a certain power. Used normally, pow() takes two numerical parameters (we will call them X and Y) and returns the value of X multiplied by itself Y times. So, rather than writing 6 × 6 × 6 × 6 × 6 × 6 × 6 × 6 × 6 × 6, you can use pow(6, 10). If you use 0.5 as the second parameter, pow() calculates the square root of the first parameter.
