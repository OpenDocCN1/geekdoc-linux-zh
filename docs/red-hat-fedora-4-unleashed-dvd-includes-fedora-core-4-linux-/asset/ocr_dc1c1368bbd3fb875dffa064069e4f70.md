# # Introduction to PHP

In terms of the way it looks, PHP is a cross between Java and Perl, having taken the best aspects of both and merged them successfully into one language. The Java parts include a powerful object-orientation system, the capability to throw program exceptions, and the general style of writing that both languages borrowed from C. Borrowed from Perl is the “it should just work” mentality where ease of use is favored over strictness. As a result, you will find a lot of “there is more than one way to do it” in PHP.

If you have no previous experience using PHP, these next five sections are just for you: how to start and stop PHP processing, use variables, run operations, control program flow, and work with multiple files. If you have more experience, you can skip to the section “Basic Functions.”

# ## Entering and Exiting PHP Mode

Unlike PHP’s predecessors, you embed your PHP code inside your HTML as opposed to the other way around. Before PHP, many websites had standard HTML pages for most of their content, linking to Perl CGI pages to do back-end processing when needed. With PHP, all your pages are capable of processing and containing HTML.

Each .php file is processed by PHP that looks for code to execute. PHP considers all the text it finds to be HTML until it finds one of four things:

+   * `<?php`
+   * `<?`
+   * `<%`
+   * `<script language="php">`

The first option is the preferred method of entering PHP mode because it is guaranteed to work. The second method, known as short tags, is disabled by default and is also likely to cause problems if you are serving XML documents along with your PHP. The third option is known as ASP tags because it mimics the manner in which Microsoft’s ASP enters code blocks—this is rarely used. The last option is a last resort if you are using oddball code generators that don’t like `<?php`—it looks like the same script blocks that are used to encapsulate JavaScript, and most editors leave it alone.

You can enter and exit PHP mode whenever you like, as often as you like, and—contrary to popular belief—there is little speed difference between printing your HTML in HTML mode or printing it in PHP mode.

Once in PHP mode, you can exit it by using ?> (for `<?php` and `<?`); %>; for `<%>` or `</script>` (for `<script language="php">`). This code example demonstrates entering and exiting PHP mode:

```
In HTML mode
<?php
   echo "In PHP mode";
```
