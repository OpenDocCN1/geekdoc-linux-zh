# Variable Variables

Although variable variables are not used frequently, it is at least important that you understand how they work so you will recognize them when you see them. A variable variable allows you to access the value of another variable indirectly by using its name as a string. That is, if you have a variable called $foo with a value "Hello, world!" and another variable called $bar set to "foo", you can use $$bar (yes, two dollar signs) to refer to "Hello, world!". When it sees two dollar signs, PHP looks at the value of the variable and treats that as the name of another variable; then it uses that value.

You can have as many layers of indirection as you like—for example, you could have $$$bar, $$$$person, and so on. That said, anything past two dollar signs is probably not smart.

Listing 31.3 demonstrates variable variables in action.

**LISTING 31.3**  Variable Variables in Action

```php
<?php
  $name = "Paul";
  $indirect1 = "name";
  $indirect2 = "indirect1";

  echo $name . "\n";
  echo $$indirect1 . "\n";
  echo $$$indirect2 . "\n";
?>
