# **Root doesn't ask anyone!**

The root user doesn't need anyone's permission to view any folder or file on the system. They don't call root **superuser** for nothing! In fact, root has the power to lock you out of your own folders and files and even to change their ownership!

# ### Sorting your folder listing

Click the buttons above the listing on the right side of File Manager to sort the folder's contents by Name, Size, Attributes, and Modified date. Click the same button twice to sort the listing in reverse order. Figure 11-8 shows the list sorted in reverse order by size. Note how the little sort triangle moved over to the Size button and now points upward.
