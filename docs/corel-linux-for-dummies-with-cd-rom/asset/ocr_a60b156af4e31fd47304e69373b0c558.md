# # E-Mail Facilities in Corel Linux

Corel Linux comes with a couple of e-mail facilities:

+   - The Messeneger component in Netscape Communicator
+   - The Kmail utility from KDE

The Messeneger facility, which is shown in Figure 16-1, is nicely integrated with the browser. Plus, it’s a more mature application than Kmail that handles newsgroups as well, so it’s one I use in this chapter. If you decide to use Kmail, the setup procedures and operations are similar.
