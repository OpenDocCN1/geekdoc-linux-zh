# File Manager clicking school

You have several click choices while browsing folders in File Manager. They’re all pretty intuitive, but you might want to practice them a bit:

+   - Click the \+ and \- buttons in the tree view to alternately expand and collapse the tree branches.
+   - Click a folder in the tree view to display its contents in the right pane of File Manager.
+   - Double-click a folder to both alternately expand or collapse its branch *and* display its contents in the right pane.
+   - Double-click a folder in the contents display to view that folder’s contents *and* expand its branch in the tree view.

Try all these tricks and observe what happens and then send away for your Clicking-School diploma.
