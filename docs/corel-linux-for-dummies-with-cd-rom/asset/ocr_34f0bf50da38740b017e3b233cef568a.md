# ## Logging In as a Regular User

If there’s one thing for you to remember, it’s to avoid logging in as the root superuser, because this gives you the power to screw up critical system files. Make a habit of logging in under your regular user name instead. When you do need root access to, say, add a new user or install fonts in WordPerfect 8, remember to log out when your root tasks are finished and then log back in under your regular user name.
