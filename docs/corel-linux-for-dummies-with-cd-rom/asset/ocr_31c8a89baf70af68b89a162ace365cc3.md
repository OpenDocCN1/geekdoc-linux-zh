# Moving Files with Drag and Drop

Another great File Manager trick is to move files with drag and drop. Select the files and folders with your mouse, drag them to the new location, and then drop them into place, as shown in Figure 19-8. (This procedure normally removes the files from the original location. This is not the case, however, in the initial release of Corel Linux, so the files are copied instead.)

![](bbox=[0.13, 0.51, 0.21, 0.61])

To copy the selected items rather than move them, hold the Ctrl key as you drop them into place. See Chapter 11 for more details.

# Fishing Stuff out of the Trash

Have you ever dropped stuff in the trash, only to go back later to fish it out? No need to be embarrassed. Anyway, you can do the same with files you've trashed. Click the Trash icon on your desktop and then select the files or folders you want to retrieve. Choose File ➔ Restore, or right-click and choose Restore, as shown in Figure 19-9. This sends the files or folders back from where they came.

![](bbox=[0.13, 0.89, 0.21, 0.97])

When you're sure there's nothing worthwhile in the trash, right-click the Trash icon to empty the trash can. You'll find more trash tips in Chapter 11.
