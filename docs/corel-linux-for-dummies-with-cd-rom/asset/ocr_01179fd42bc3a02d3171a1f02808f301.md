# Sending messages later

To compose messages now to send later:

+   1. Create each message in the normal manner.
+   2. Choose File ⇔ Send Later.
+   3. When you’re ready to send your messages, choose File ⇔ Send Unsent Messages.

![](bbox=[0.05, 0.31, 0.12, 0.4])

This feature enables you to compose your messages while you’re offline, either because you don’t have access at the moment or you want to save online charges.

# Drafting a message

To draft a message and then complete and send it later:

+   1. Create the message in the normal manner.
+   2. Click the Save button and choose As Draft.
+   3. When you’re ready to complete the message, display the Drafts folder under Local Mail and double-click the message in the listing.

# Replying to a message

To reply to a message you received:

+   1. Click the Reply button (or right-click the message and choose Reply to Sender Only).
+   
+   Click the Reply All button to reply to the sender and all recipients.
+   2. Type your reply above, below, or within the quoted message (wherever seems most appropriate).
+   
+   You can also delete superfluous parts of the quoted message to focus your reply.
+   3. Click the Send button.
