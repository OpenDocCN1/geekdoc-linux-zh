# # Making a Joyful Noise

If you don’t want the pizzaz you can still have the jazz. Here’s how to add a little noise to your computing life:

+   1.  **Choose Application Starter \ Control Center.**
+   2.  **Double-click Sound and then choose System Sounds.**
+   3.  **Click to add a check mark to the enable system sounds option.**
+       The events and sounds shown in Figure 10-16 appear.
+   4.  **In the Events list, select an event to which you want to apply a sound.**
+   5.  **In the Sounds list, select an associated sound.**
+       To turn off sound for a particular event, select the (none) option.
+   6.  **Click Apply.**
+   7.  **For additional event and sound associations, repeat Steps 4 through 6.**
+   8.  **When you’re finished, click OK.**

![](bbox=[0.03, 0.46, 0.12, 0.58])

System sounds are in the /usr/X11R6/share/sounds folder. The files you add to the folder, as root, appear in the list of selections.
