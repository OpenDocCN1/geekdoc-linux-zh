# Cruising in Cyberspace

Netscape Navigator, shown in Figure 15-1, is your ticket to cruising the virtual universe. It comes bundled with all versions of Corel Linux.

And look at Figure 15-2 — you can access Web sites through File Manager as well! A file on your computer, a folder on the network, or a Web page in Timbuktu — they’re all the same to File Manager!

The great thing about the Web isn’t the software or the commercial sites — it’s the people. Instead of being a couch potato watching television, you can be couch potato communicating with others on the Internet.

Interested in Cajun cooking, raising goats, riding the Earth of land mines, or tricks on using Corel Linux? You’ll find many others on the Web who share your interests and concerns.
