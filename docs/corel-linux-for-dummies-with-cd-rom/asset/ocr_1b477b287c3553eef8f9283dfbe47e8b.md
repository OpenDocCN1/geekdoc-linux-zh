# ## Appendix A: Commands to the Rescue!

**Table A-1** Essential Linux Commands

| Command | Examples | Results |
| :--- | :--- | :--- |
| `ls <file names/ directories> <options>` | `ls -l /usr/local` | Lists all files in `/usr/local` |
| | `ls *.wpd` | Lists .wpd files in the current directory |
| | `ls -F /usr/local/data` | Displays the file type |
| | `ls -lF` | Displays the file size and permissions |
| `cd <directory>` | `cd /usr/local` | Goes to the `/usr/local` directory |
| | `cd ../local/data` | Goes to the parent of `/local/data` |
| | `cd..` | Goes to the parent of the current directory |
| `cp <options> <file names> <destination> <R>` | `cp *.wpd /usr/local/data` | Copies all files with the .wpd extension from the current directory to the `/user/local/data` directory |
| | `cp /data/*. * /disks/c/temp` | Copies all files in the data directory to the disks/c/temp directory |
| | `cp /root/Desktop/X11R6 /usr/X11R6 -R` | Recursively copies all files and subdirectories from `/root/Desktop/X11R6` to `/usr/X11R6` |
| `mv <file names> <destination>` | `mv *.wpd /usr/local/data` | Moves all files with the .wpd extension from the current directory to the `/user/local/data` directory |
