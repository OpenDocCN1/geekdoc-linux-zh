# Step 7: Off you go!

The decisive moment has arrived! If you are really, really, really, sure, click Install to start the process. The Installing Components screen of Figure 2-7 tells you what's happening as it partitions your hard disk and installs your base system and packages.

Coffee break time! How long does the installation take? That depends on you hardware and how you installation selections, but figure between ten minutes and half an hour. Don't be alarmed if the install seems to hang at some place, such as 25% or 98%; the install isn't adept at calculating its progress.

# Step 8: Entering the promised land

When the installation is finished, remove the floppy (if you used one). Click OK to reboot Corel Linux. You are presented with the startup selections in Figure 2-8. You made it (enthusiastic applause)!
