# Stopping a search in its tracks

Sometimes you want to stop a search before it’s finished. Perhaps what you’re looking for has already shown up in the list, or the search is going on forever, or you’re searching for the wrong thing. Simply click the **Stop Search** button to end it now (or choose **File** \[icon\] **Stop Search**).
