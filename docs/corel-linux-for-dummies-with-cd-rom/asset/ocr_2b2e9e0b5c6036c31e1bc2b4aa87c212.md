# # Changing your preferred language

To change the preferred language for your menus, dialog boxes, and online help:

+   1.  Choose **Application Starter**  Control Center (KDE Kontrollzentrum), double-click **Desktop**, and then choose **Language** (Sprache).
+   2.  Select your **first language** and then select your **second** and **third backup languages** in order of preference, as shown in Figure 4-1.
+   3.  Click **OK** to change the language for any applications you now open.

If the first language is not available, Corel Linux tries your second and third choices. If none of your preferred languages is available, Corel Linux uses the default, which is Esperanto. Just kidding, the default language is English.
