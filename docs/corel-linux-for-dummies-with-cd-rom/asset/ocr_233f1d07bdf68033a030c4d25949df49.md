# # Sounding Off

If you want to hear what you're doing, try adding a little noise to your computing life:

![](bbox=[0.09, 0.24, 0.15, 0.3])

+   1.  Choose **Application Starter Control Center**, double-click **Sound**, and then choose **System Sounds**.

+   2.  Choose the **enable system sounds** option.

+   3.  Select an event to which you want to apply a sound, select an associated sound, and then click **Apply**, as shown in **Figure 19-4**.

+   4.  Repeat Step 3 for additional event/sound associations.

![](bbox=[0.16, 0.4, 0.79, 0.76])

Figure 19-4: Associating sounds with your desktop happenings.
