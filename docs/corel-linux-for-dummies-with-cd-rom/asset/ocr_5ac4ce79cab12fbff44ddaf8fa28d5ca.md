# ## Disconnecting a Network Share

You can disconnect a network share if it's no longer needed:

+   1. Click the File Manager button on the panel.
+   2. Choose Tools ↔ Disconnect Network Share.
+   3. Select the share to disconnect, as shown in Figure 12-10.

![](bbox=[0.15, 0.66, 0.64, 0.8])

+   4. Click OK.
+   5. If you're prompted, click Yes if you want to automatically remount the network share the next time you log in or click No if you don't.
