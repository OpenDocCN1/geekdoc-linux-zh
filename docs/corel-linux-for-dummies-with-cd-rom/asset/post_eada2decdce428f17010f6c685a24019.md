# If You Have Problems of the CD Kind

I tried my best to supply programs that work on most computers that meet the minimum system requirements. Alas, your computer might differ, and some programs might not work properly for some reason. The most likely problem is that you have a Winmodem or some other hardware that is not yet supported by Corel Linux, as described in Chapter 2.

If your machine meets the hardware requirements and you still have trouble installing the items from the CD, please call the IDG Books Worldwide Customer Service phone number at 800-762-2974 (outside the United States, call 317-596-5430).
