# Welcome to Mission Control

So where do you go to tweak? Most settings are conveniently gathered under the big tent of the Corel Linux Control Center, similar to the Windows Control Panel. The one exception in this chapter is the dial-up Internet connection, made through the Dial-Up utility on the Network submenu.
