# Extracting an archive

You can extract all or part of an archive to the location you specify:

+   1.  Choose **Application Starter** **Applications** **Utilities** **Archive**
+       **Administrator.**
+   2.  Click the **Open** button in Archive Administrator, browse to select the
+       archive, and then click **OK**.
+   3.  Select the particular files you want to extract, if you're not extracting
+       them all, and then click the **Extract** button, as shown it **Figure 12-15**.
