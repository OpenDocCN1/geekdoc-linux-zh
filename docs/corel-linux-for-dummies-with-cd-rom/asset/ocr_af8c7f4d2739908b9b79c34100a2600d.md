Linux Applications

Linux is available in several formats, called distributions. Each distribution has it's own set of features and functionality that makes it unique - some distributions are available for a one time charge, others are provided on CD or floppy disk, and have a (usually) minimal charge associated with them.

In each section below, you'll find not a list of applications, tools, and utilities, but links to web sites providing support, reviews, and other useful information. Looking for something you can't find on our list? Try the Linux Software Map, which contains a wide variety of applications that function with Linux.
