# In this part...

When I was a kid, we had used-car dealers — now these guys are selling not used cars but preowned automobiles, as though they've improved with age by bashing into telephone poles or by grinding piston rings and bearings to dust. They spray that new-car-plastic smell like it was the refined bouquet of a vintage wine.

Well, here are some preowned appendixes that are honestly better for it. You get some true-to-life chronicles in using Linux commands, and I used the glossary in writing this book — honing the definitions as I went. Nothing preowned about the CD, of course — it has spanking new software on a shiny disk.
