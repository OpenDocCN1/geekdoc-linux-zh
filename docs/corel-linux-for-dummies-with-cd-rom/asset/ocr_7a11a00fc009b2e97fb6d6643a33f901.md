# Installing Debian Packages from Your Hard Drive

Suppose you already have a Debian package that you got from some other source sitting on your hard drive (or on a network drive). Can you use Corel Update to install it? Yup, sure can! (I love answering my own questions.)

+   1. From Corel Update, choose File Install Deb File and then locate the file, as seen in Figure 17-8.

![](bbox=[0.23, 0.68, 0.61, 0.83])

Figure 17-8: Select the Debian package you want to install.

+   2. Click OK to install the file.
+      It's that simple!
