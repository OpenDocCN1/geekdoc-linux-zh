# What's the Web?

If you're new to the Web, some explanation might be in order. The Web, also known as the World Wide Web, WWW, and W3, has taken the computer industry by storm. Politicians try to censor it and giant corporations vie to control it, but the infant Web (for now) is toddling off in its own direction and growing at its own pace - which happens to be a breakneck speed.

The Web supports

+   *   Information, such as reports, files, and bulletins
+   *   Communication, including e-mail, forums, and conferences
+   *   Services, such as banking, airline reservations, and catalog shopping

To the user, the great thing about the Web is its simplicity. It appears on the screen one richly formatted hypertext page at a time. The next page you click to can be in the same folder as the current one or on another site a continent away.
