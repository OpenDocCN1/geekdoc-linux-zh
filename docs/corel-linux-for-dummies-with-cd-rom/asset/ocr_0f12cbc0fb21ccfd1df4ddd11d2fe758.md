When you delete an item, it’s gone and you can’t get it back. For a more cautious approach, drag the item in the listing over to the trash can on your desktop.

+   * **Add to Archive** adds the item to an existing file archive. (You can’t create a new one.)
+   * **Save Search Results** creates a file of clickable links from your listing.

# *Sophisticated searching*

In most cases, a basic search is all you need to quickly locate something. If you’re having trouble, though, try a sophisticated search:

+   1. Choose **Application Starter ⌘ Find ⌘ Files or Folders**.
+   2. Type the name of the folder or file you’re searching for, where you want to search from, and whether to include subfolders in your search.
+   3. Choose the **Date Modified** tab and make your selections.

You can specify dates to search between, as shown in Figure 12-3, or you can search during a previous number of months or days.
Enter “between” dates in the dd/mm/yyyy format.
