This option can be turned on by itself, and will override other options when enabled. The results are placed in `/proc/sys/kernel/preempt_max_latency`. To disable wakeup latency timing and let other configured options be available, just set `/proc/sys/kernel/wakeup_timing` to zero.

Be warned, though, that until recently the latency tracer has been considered a debug tool only for the RT patch developers.
