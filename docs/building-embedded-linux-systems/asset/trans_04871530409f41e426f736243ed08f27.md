# 构建嵌入式 LINUX 系统

![](img/617fee0f2d5cdaf31b3f8601bc6c454f_1_0.png)

尽管许多公司在使用 Linux 构建从手机、汽车 ABS 系统到水处理厂的嵌入式系统，但关于创建、安装和测试 Linux 内核及相关工具的信息来源却出人意料地少。*《构建嵌入式 Linux 系统》* 是构建这些系统的深度指南。你不仅能获得基本原理，还能学习如何配置、设置和使用 40 多种不同的开源和免费软件包。本第二版针对最新版本的 Linux 内核进行了更新，并收录了此前未公开记录的步骤，帮助你：

- * 构建你自己的 GNU 开发工具链
- * 选择、配置、构建并安装特定目标的内核
- * 创建完整的目标根文件系统
- * 设置、操作和使用固态存储设备
- * 安装并配置目标设备的引导加载程序
- * 交叉编译大量的实用工具和软件包
- * 使用多种工具和技术调试你的嵌入式系统
- * 使用 uClibc、BusyBox、U-Boot、OpenSSH、httpd、tftp、strace 和 gdb 软件包
- * 利用 Xenomai 或 RT 内核补丁来发挥实时功能

本第二版教你如何构建操作系统组件，简化维护嵌入式系统完全控制权的艰巨任务。

> *“[本书] 并不假设你手头有什么样的工具或项目的范围。所需的一切 . . . 只是一个互联网连接，用于下载必要的软件包，浏览特定的在线文档，并受益于其他开发者的经验，以及分享你自己的。*
>
> *除了提供最大程度的设计和自由度与控制力外，这种方法也最接近那些为 Linux 在嵌入式系统中的使用开路的前辈们所遵循的方法。”*
>
> —来自前言
