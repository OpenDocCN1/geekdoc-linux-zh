*xin*ed is distributed at http://www.xinetd.org/ under a BSD-like license. For our SYSM module, we used *xin*ed version 2.3.14. Download and extract the *xin*ed package into your $(*PRJROOT*)/*sysapps* directory, and move into the package's directory for the rest of the procedure:

```
$ cd ${PRJROOT}/sysapps/xinetd-2.3.14
```

As with *inetd*, *xin*ed can't be compiled with *uClibc* if it lacks certain features. In particular, *xin*ed will fail to build with *uClibc* if it doesn't support RPC and C99. In addition to the C library, *xin*ed depends on the math library (*libm*) and the cryptography library (*libcrypt*).
Configure, compile, and install *xin*ed:

```
$ CC=arm-linux-gcc ./configure --host=$TARGET --prefix=$${TARGET_PREFIX}
$ make
$ make install
```

*xin*ed builds quite rapidly. The dynamically linked, stripped binary itself is quite large at 126 KB in size with either *uClibc* or *glibc*. When statically linked and stripped, the binary's size is 650 KB with *glibc* and 210 KB with *uClibc*. The *xin*ed package installs its components in the ${*TARGET_PREFIX*} directory. The build also installs manpages. The *xin*ed binary itself is installed in ${*TARGET_PREFIX*/sbin/}. Copy it from that directory to your target's root filesystem and strip it:

```
$ cp ${TARGET_PREFIX}/sbin/xinetd ${PRJROOT}/rootfs/usr/sbin
$ arm-linux-strip ${PRJROOT}/rootfs/usr/sbin/xinetd
```

A sample configuration file is provided with *xin*ed, named *xinetd/sample.conf*. Use this sample as the basis for configuring your target. Copy it to your target's root filesystem and edit it according to your needs:

```
$ cp xinetd/sample.conf ${PRJROOT}/rootfs/etc/xinetd.conf
```

Here is the entry in our SYSM module's *xinetd.conf* for the Telnet daemon discussed later in "Network Login Through Telnet":

```
service telnet
{
socket_type   = stream
wait          = no
user          = root
server        = /usr/sbin/inetd
bind          = 127.0.0.1
log_on_failure    += USERID
}
```
