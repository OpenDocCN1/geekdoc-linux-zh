# Making the best choice

What should you use? At the time of writing, the choice is either the 8.04 LTS release, released April 2008, or the newer 8.10 release, released October 2008. There's no point using an earlier release than this because its support period will soon expire, if it hasn't already.

> NOTE Releases prior to 8.04 don't include the Wubi software.

8.04 LTS offers support for a longer period, and is designed to be stable and reliable, so is the logical choice. Non-LTS releases are used to experiment with new features and software, so can be unpredictable and even buggy.

If you simply want to switch to Ubuntu for a fuss-free life then, undoubtedly, 8.04 LTS is best. It's also ideal for corporate or home office environments. It is supported with updates until April 2011.

However, if you'd like to use cutting-edge software, and really see what the world of Linux has to offer right now, you might choose the 8.10 release. It is supported until April 2010.

> NOTE The 8.10 release also has much better wireless network and Bluetooth support than 8.04.
