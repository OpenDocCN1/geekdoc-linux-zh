## 管理打印任务

要查看或取消打印任务，请点击“应用程序”（Applications）⇨“附件”（Accessories）⇨“管理打印任务”（Manage Print Jobs）。这将显示当前的打印队列。要删除某个任务，请右键点击列表中的对应条目并选择“取消”（Cancel）。

如果打印任务因任何原因停滞，屏幕右上角会出现一个图标。双击该图标会自动弹出打印机队列窗口。

## 安装网络打印机

要在 Ubuntu 8.10 中安装共享网络打印机（例如连接到家中或办公室另一台计算机上的打印机），请点击“系统”（System）⇨“管理”（Administration）⇨“打印”（Printing），然后点击工具栏中的“新建”（NEW）按钮（如果使用 Ubuntu 8.04，则点击“新建打印机”（NEW PRINTER））。然后选择你希望通过网络连接的网络打印机类型。

对于使用网络服务器设备（通常仅在企业环境中出现）的打印机，请选择“AppSocket/HP JetDirect”。在程序窗口右侧输入地址信息。这通常采用 IP 地址和队列名称的形式——请向管理员或查阅打印服务器文档获取这些信息。

如果要连接到 Windows 电脑上的共享打印机，请选择“通过 SAMBA 连接 Windows 打印机”（Windows Printer via SAMBA），然后点击“浏览”（BROWSE）按钮，让 Ubuntu 自动检测本地网络上的共享打印机，如图 2-3 所示。点击每个标题旁边的箭头以“展开”它们，找到你要找的打印机后，选中它并点击“确定”（OK）按钮。

返回父窗口后，点击“立即设置身份验证详细信息”（Set Authentication Details Now）旁边的单选按钮（在 Ubuntu 8.04 下点击“需要身份验证”（Authentication Required）复选框），然后输入访问共享打印机的 Windows 账户所需的 Windows（而非 Ubuntu！）登录用户名/密码。点击“验证”（VERIFY）以检查这些信息是否有效。

完成后点击“前进”（Forward）以安装打印机驱动程序。系统不太可能自动检测到它，你需要通过浏览打印机厂商和型号列表来手动选择。

> 提示：你可能需要调整 Windows 电脑上的防火墙和/或共享设置，才能访问该打印机。

## 可移动存储

可移动存储是一个统称，指任何用于存储数据的即插即用硬件。例如：

- USB 闪存盘；
- 外置硬盘或 CD/DVD-ROM 光驱；
- 数码相机；
- 存储卡读卡器（包括内置在计算机中的以及通过 USB 连接的）；
- 媒体播放器，如 iPod 和其他 MP3 播放器。

在 Ubuntu 下，所有此类设备都以类似的方式访问。每当你连接它们时，会自动出现一个文件浏览窗口，显示设备的内容，并且桌面会出现一个图标；如果你关闭了该窗口，可以双击图标重新打开。此外，“位置”（Places）菜单（屏幕顶部）中会添加一个条目，选择它也可以浏览该设备。

> 注意：如果你连接的是存储卡读卡器，在真正插入存储卡之前，它不会显示为已连接状态。

对于某些具有特定用途的可移动存储设备（如数码相机或 MP3 播放器），相关的 Ubuntu 应用程序可能也会启动；例如，插入数码相机后，F-Spot 照片管理器（F-Spot Photo Manager）会启动。如果你当时不想使用该应用程序，只需点击其关闭按钮即可。

> 提示：要更改在连接某些类型的可移动存储设备时启动的应用程序，或阻止它们启动，请打开文件浏览窗口（点击“位置”（Places）⇨“主文件夹”（Home Folder）），然后在文件浏览器菜单中点击“编辑”（Edit）⇨“首选项”（Preferences）。在出现的窗口中选择“媒体”（Media）选项卡，然后从出现的下拉列表中进行选择。

在 Ubuntu 中使用可移动存储设备时，与 Windows 相比有一个重要区别。在从 USB 插座中物理移除设备之前，你必须先卸载它。这可以通过右键点击桌面图标并选择“弹出”（Eject）、“卸载”（Unmount）或“卸载卷”（Unmount Volume）选项来完成（术语根据上下文而异）。或者，在 Ubuntu 8.10 中，你可以点击文件浏览窗口左侧可移动存储设备图标旁边的弹出图标。

设备被卸载后，其 LED 指示灯停止闪烁后，即可将其从计算机上物理移除。

> 注意：其他 USB 设备（如打印机或蓝牙适配器）可以随意直接拔出——无需卸载——但要注意带有内置读卡器的打印机。如果插入了任何存储卡，必须先卸载它们。

## 扫描仪

扫描仪的安装和配置会自动完成。Ubuntu 提供了一些优秀的扫描软件，即“XSane 图像扫描仪”（XSane Image Scanner），可在“应用程序”（Applications）⇨“图形”（Graphics）菜单中找到。其操作方式与 Windows 扫描仪驱动程序非常相似。

> 提示：如果你想使用光学字符识别（OCR），请安装 gocr 软件包。软件安装将在第 6 章中说明。gocr 安装后，你可以在扫描后点击 Xsane 查看器窗口中的“文件”（File）⇨“OCR-另存为文本”（OCR-Save as Text）来启动它。

## 蓝牙

如果你的计算机具有蓝牙功能，屏幕右上角会出现一个蓝牙图标。此图标可用于配置蓝牙连接的所有方面。
