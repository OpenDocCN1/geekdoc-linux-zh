*History:* This mode presents a list of locations you've visited in the current file browsing session, arranged in sequence. Clicking any entry will jump to that location.

*Notes:* Folders can have written notes invisibly attached to them, and the Notes mode lets you add, edit, or view this text. This can be useful in a very complex filesystem with lots of folders.

**NOTE** Both files and folders can have notes attached, although the side pane doesn't offer the ability to add them to files. To manually add a note to a file or folder, right-click it, click Properties in the menu, and select the Notes tab in the dialog box.

*Emblems:* Files and folders can have small icons affixed to them for informational purposes. Some of these have specific filesystem meanings, as discussed in the *Emblems* section below, but others are for the user's *aide mémoire* only. By selecting this side pane mode, a list of emblem icons are shown and these can be dragged and dropped onto any file or folder within the browsing window. To remove an emblem, just reapply the same emblem to the file/folder.
