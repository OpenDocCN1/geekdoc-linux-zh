# Sending a file to Ubuntu

Right-click the Bluetooth icon and select Preferences in the menu that appears. In the dialog box, ensure the first tab is selected and click the Temporary Visible entry (this is referred to as Limited Discoverable and Connectable under Ubuntu 8.04). Initiate file transfer on the Bluetooth device, and respond to the prompts that appear on the Ubuntu desktop.
