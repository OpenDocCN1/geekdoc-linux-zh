## 安装

### 制作启动盘

制作启动盘之前，你需要一个至少 4GB 空间的 U 闪盘。首先，从官方网站下载 Linux Mint 21.3 Cinnamon ISO 镜像。然后插入 U 盘，并使用像 Disk Etcher 这样的工具将镜像写入驱动。

### 安装过程

一旦启动盘准备就绪，重启电脑进入启动菜单（通常在启动期间按下 `F12` 或 `Esc`）。选择从 U 盘启动。按照屏幕指令将 Linux Mint 安装到你的硬盘。你可以选择语言、键盘布局和分区方案。

## 使用 Linux Mint 21.3 Cinnamon

安装完成后，重启电脑并登录你的新桌面。

要开始配置系统，点击左下角的菜单按钮并选择“偏好设置”。在这里你可以根据需要调整各种设置。

## 硬件

### 蓝牙

- 我们要处理的第一项硬件配置是 `Bluetooth`（蓝牙）。
- 在 `System Settings`（系统设置）窗口中，点击 `Hardware` 下的 `Bluetooth` 图标。

![](img/image_rsrc1ZF.jpg)

- 在打开的 `Bluetooth Devices`（蓝牙设备）窗口中，点击 `Search`（搜索）按钮，让电脑搜索范围内的任何外部蓝牙设备。

![](img/image_rsrc1ZG.jpg)

- 在下图，你可以发现了一个蓝牙设备，那就是 `ZK606`。这里描述的 `ZK606` 蓝牙设备只是一个例子。在你情况下，会有你已开启且在范围内的外部蓝牙设备，它们将显示在 `Bluetooth Devices` 窗口中。
- 点击找到的蓝牙设备进行选择。

![](img/image_rsrc1ZH.jpg)

- 点击 `Pair`（配对）按钮，让电脑内部的蓝牙与外部蓝牙设备配对。蓝牙设备需要配对才能工作。

![](img/image_rsrc1ZJ.jpg)

- 同时，点击 `Trust`（信任）按钮，让你的电脑蓝牙在连接时“信任”该外部蓝牙设备。

![](img/image_rsrc1ZK.jpg)

- 现在，在下方的图中，你可以看到窗口右侧有一些绿色指示器，针对 `ZK606` 蓝牙设备，这显示你的外部蓝牙设备已连接并正常工作。

![](img/image_rsrc1ZM.jpg)

- 在打开的 `Bluetooth Devices`（蓝牙设备）窗口中，点击 `Device`（设备）选项卡。
- 从下拉菜单中，点击 `Audio Profile`（音频配置文件）选项。
- 然后，在打开的子菜单中点击 `High Fidelity Playback`（高保真播放）选项。这是我推荐的 `Audio Profile` 选项。

![](img/image_rsrc1ZN.jpg)

- 当你想要移除已配置为与电脑工作的外部蓝牙设备时，只需在打开的 `Bluetooth Devices` 窗口中点击选择该设备，然后点击像减号一样的 `Remove`（移除）按钮，该外部蓝牙设备将不再被连接，并且无法再次与你的电脑工作。

![](img/image_rsrc1ZP.jpg)

![](img/image_rsrc1ZU.jpg)

![](img/image_rsrc1ZV.jpg)![](img/image_rsrc1ZW.jpg)

![](img/image_rsrc1ZX.jpg)

- 如果你查看 `Panel` 的左下角，你会看到法国旗和英国国旗都显示了，这样你可以点击其中任何一个并随时切换布局。

![](img/image_rsrc1ZY.jpg)

- 当你想要从电脑中移除键盘布局时，点击左侧键盘布局列表中显示的某个布局，然后点击左下角的减号。

## 网络

- 在这一步中，我们将配置你的 `Linux Mint 21.3 Cinnamon` 网络。配置将主要针对 `WiFi` 无线网络，因为如果你在家中使用电脑和路由器，`Ethernet`（以太网）连接非常简单易于操作。
- 在打开的 `System Settings` 窗口中点击 `Network`（网络）图标。

![](img/image_rsrc20C.jpg)

- 点击打开窗口左侧的 `WiFi` 图标。



- 你可以看到附近已经有一些可用的 WiFi 无线连接。例如，在接下来的图中，你可以看到 Dani 无线网络。
- 请记住，`Linux Mint 21.3 Cinnamon` 会自动找到并显示范围内的 `WiFi` 无线网络，包括来自你开启的路由器的 WiFi 连接名称。
- 确保窗口右侧的 WiFi 无线连接按钮已开启，以便启用无线连接。

![](img/image_rsrc20D.jpg)

- 现在，在这个示例中，我们将查看可用的无线连接 `Nedko-71 EXT` 是如何配置的。
- 点击打开窗口左侧列表中的设置小图标，打开 `Nedko-71 EXT` 无线网络的设置。

![](img/image_rsrc20E.jpg)

- 现在，`Nedko-71 EXT` 无线连接的设置窗口已打开。
- 点击打开窗口左侧列表中的 `Details（详情）`，查看无线连接的一些详细信息。

![](img/image_rsrc20F.jpg)

- 点击打开窗口左侧列表中的 `Security（安全）`。

![](img/image_rsrc20G.jpg)

- 对于 `Security` 选项，从下拉菜单点击并选择 `WPA & WPA2 Personal` 选项。

![](img/image_rsrc20H.jpg)

- 配置 WiFi 无线连接密码，点击打开窗口中的 `Password（密码）` 字段，并输入从运营商提供的无线连接密码。该密码是在路由器设置中配置的。如果你更改了运营商提供的默认无线连接密码，请输入新的无线连接密码。
- 点击 `Apply（应用）` 按钮应用新设置。

![](img/image_rsrc20J.jpg)

- 点击打开窗口左侧设置列表中的 `Identity（标识）` 类别。
- 对于 `SSID`（即你的 WiFi 无线连接的名称），在字段中输入该名称。在此示例中，它是 `Nedko-71 EXT` 无线连接。
- 将 `Identity` 类别的其他设置保持为默认值即可。
- 确保窗口底部的两个复选框 `Connect automatically`（自动连接）和 `Make available to other users`（其他用户可用）已选中。
- 点击 `Apply（应用）` 按钮。

![](img/image_rsrc20K.jpg)

- 你是否看到打开窗口左下角的小加号？那是用于为你的电脑添加新连接的。

![](img/image_rsrc20M.jpg)

## 制作启动盘

首先，我将向你展示如何创建一个带有 Linux Mint 21.3 Cinnamon 的启动型 U 闪盘。你需要制作一个启动型 U 闪盘，并将 Linux Mint 21.3 Cinnamon ISO 文件安装在其中。完成后，你可以将该启动型 U 闪盘插入电脑的 USB 接口，重启电脑，Linux Mint 21.3 Cinnamon 就会开始加载。一旦加载到桌面，桌面上有一个安装图标，点击它将开始从启动型 U 闪盘将 Linux Mint 21.3 Cinnamon 安装到你的电脑上。但现在，让我们按照下面的步骤先制作启动型 U 闪盘。

### 创建启动型 U 闪盘

- 你将使用一个名为`BalenaEtcher`的免费工具。只需访问以下网站：[`www.balena.io/etcher`](https://www.balena.io/etcher) 并在电脑上下载该免费程序。一旦从互联网下载了`BalenaEtcher`，你甚至不需要安装它。如果你使用的是 Windows 或 Linux 电脑来下载`BalenaEtcher`免费程序，你只需要点击下载的`BalenaEtcher`程序，几秒钟后它就会打开并准备就绪。

- 这是`BalenaEtcher`程序打开后的截图。请查看下图。

![](img/image_rsrc27J.jpg)

- 如你从上面的图片所示，使用`BalenaEtcher`工具制作启动型 U 闪盘只需三个简单的步骤。一旦你已从 Linux Mint 21.3 Cinnamon 官方网站下载了 ISO 格式的 Linux Mint 21.3 Cinnamon 文件，你只需要在`BalenaEtcher`程序中按照图中三个简单的步骤操作即可。不要担心那个`ISO`文件是什么！它只是你从 Linux 官方网站下载的 Linux Mint 21.3 Cinnamon 文件的扩展名。



如你在上方 `BalenaEtcher` 程序图中蓝色所示，第一步 `Flash from file` 是蓝色按钮，点击它可以选择你已经从网上下载的 Linux Mint 21.3 Cinnamon 操作系统文件。完成后，继续进行制作启动型 U 闪盘的第二步。

第二步是选择你正在使用的 U 闪盘，使其成为带有 Linux Mint 21.3 Cinnamon 的启动型 U 闪盘。因此，只需点击已打开的 `BalenaEtcher` 程序中的 `Select target`，然后从选项中选择你要制作成启动型的 U 闪盘。

下一步是点击打开的 `BalenaEtcher` 程序中的 `Flash` 按钮。让它"小火慢炖"几分钟，换句话说，让它完成该做的工作几分钟，哒！你就制作好了一个带有 Linux Mint 21.3 Cinnamon 操作系统的启动型 U 闪盘。现在，这个带有 Linux Mint 21.3 Cinnamon 的启动型 U 闪盘被称为"现场操作系统"（live operating system），这意味着这个启动型 U 闪盘可以插入任何电脑，你可以从 U 闪盘运行并使用 Linux Mint 21.3 Cinnamon，就像使用已安装在任何电脑上的其他操作系统一样。它就像是任何电脑上的 Windows 操作系统一样，准备好处理你所需的各种任务。唯一的区别是，你制作的启动型 U 闪盘上的 Linux Mint 21.3 Cinnamon 操作系统仅从该启动型 U 闪盘现场运行，尚未安装到任何电脑上，甚至尚未安装到可以运行它的你的电脑上。它在插入了启动型 U 闪盘的电脑上现场运行，而尚未安装在该电脑上。你只需开启已插入启动型 U 闪盘的电脑，电脑就会从该启动型 U 闪盘以现场模式启动 Linux Mint 21.3 Cinnamon，即使电脑上已经安装了 Microsoft Windows。不要担心，从启动型 U 闪盘现场运行 Linux Mint 21.3 Cinnamon **不会** 影响、更改或影响同一台电脑上的任何其他操作系统，例如该电脑上已存在的 Windows。你在该带有 Linux Mint 21.3 Cinnamon 的启动型 U 闪盘上进行的所有操作都仅在该闪盘中完成。当然，你可以在你选择的任何时候，从启动型 U 闪盘在电脑上安装 Linux Mint 21.3 Cinnamon。
