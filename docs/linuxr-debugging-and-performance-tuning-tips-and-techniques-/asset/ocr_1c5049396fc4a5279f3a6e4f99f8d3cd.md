# 13.3 Dynamic Translation of Program Messages

void copyright(void)
{
  int i;

  for (i = 0; copyrights[i] != NULL, i++)
    printf("%s\n", gettext(copyrights[i]));

Here, we'd like to be able to print the translations of the copyright strings if they're available. However, how is the `xgettext` extractor supposed to find these strings? We can't enclose them in calls to `gettext()` because that won't work at compile time:

# 13.3.4.1 Portable Programs: "gettext.h"

We assume here that you wish to write a program that can be used along with the GNU `gettext` library on any Unix system, not just GNU/Linux systems. The next section describes what to do for GNU/Linux-only programs.

The solution to marking strings involves two steps. The first is the use of the `gettext.h` convenience header that comes in the GNU `gettext` distribution. This file handles several portability and compilation issues, making it easier to use `gettext()` in our own programs:

```
```
#define ENABLE_NLS 1
#include "gettext.h"
```
```

If the `ENABLE_NLS` macro is not defined⁹ or it's set to zero, then `gettext.h` expands calls to `gettext()` into the first argument.
