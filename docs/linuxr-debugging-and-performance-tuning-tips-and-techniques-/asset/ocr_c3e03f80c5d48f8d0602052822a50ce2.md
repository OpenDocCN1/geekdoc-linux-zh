This is low-level, detailed code. However, once you understand how the information in the `struct tm` is presented, the code is straightforward to read (and it was straightforward to write).

# 13.2.7 Formatting Date and Time Values: `ctime( )` and `strftime( )`

Section 6.1, “Times and Dates,” page 166, described the functions for retrieving and formatting time and date values. The `strftime( )` function is also locale-aware if `setlocale( )` has been called appropriately. The following simple program, `ch13-times.c` demonstrates this:

```
```c
/\* ch13-times.c --- demonstrate locale-based times \*/

#include <stdio.h>
#include <locale.h>
#include <time.h>

int main(void)
{
    char buf[100];
    time_t now;
    struct tm *curtime;

    setlocale(LC_ALL, "");
    time(& now);
    curtime = localtime(& now);
    (void) strftime(buf, sizeof buf,
        "It is now %A, %B %d, %Y, %I:%M %p", curtime);

    printf("%s\n", buf);

    printf("ctime( ) says: %s", ctime(& now));
    exit(0);
}
```
