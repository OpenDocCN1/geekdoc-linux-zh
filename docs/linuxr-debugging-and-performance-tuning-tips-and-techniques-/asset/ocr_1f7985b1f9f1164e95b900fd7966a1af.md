# 13.2.6 Example: Formatting Numeric Values in gawk

gawk implements its own version of the *printf()* and *sprintf()* functions. For full locale awareness, gawk must support the ' flag, as in C. The following fragment, from the file *builtin.c* in gawk 3.1.4, shows how gawk uses the *struct lconv* for numeric formatting:

```
1    case 'd':
2    case 'i':
3    ...
4    tmpval = force_number(arg);
5    ...
6    uval = (uintmax_t) tmpval;
7    ...
8    ii = jj = 0;
9    do {
10   *--cp = (char) ('0' + uval % 10);
11 #ifdef HAVE_LOCAL_H
12   if (quote_flag && loc.grouping[ii] && ++jj == loc.grouping[ii]) {
13   /*--CP = loc.thousands_sep[0]; */ XXX - assumption it's one char */
14   if (!loc.grouping[ii+1] == 0)
15   jj = 0; /* keep using current val in loc.grouping[ii] */
16   else if (loc.grouping[ii+1] == CHAR_MAX)
17   quote_flag = FALSE;
18   else {
19   ii++;
20   jj = 0;
21   }
22 } 
23 #endif
24   uval /= 10;
25 } while (uval > 0);
```

(The line numbers are relative to the start of the fragment.) Some parts of the code that aren't relevant to the discussion have been omitted to make it easier to focus on the parts that are important.

The variable *loc*, used in lines 13--17, is a *struct lconv*. It's initialized in *main()*. Of interest to us here are *loc.thousands_sep*, which is the thousands-separator
