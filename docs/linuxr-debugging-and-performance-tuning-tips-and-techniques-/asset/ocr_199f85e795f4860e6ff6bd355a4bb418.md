In particular, the *SI\_USER* value is useful; it allows a signal handler to tell if the signal was sent by *raise*() or *kill*() (described later). You can use this information to avoid calling *raise*() or *kill*() a second time.

The third argument to a three-argument signal handler, *void \*context*, is an advanced feature, not otherwise discussed in this volume.
