# POSIX file-type and permission bitmasks in <sys/stat.h>

| Mask | Value | Meaning |
|---|---|---|
| S_IFMT | 0170000 | Bitmask for the file type bitfields. |
| S_IFSOCK | 0140000 | Socket. |
| S_IFLNK | 0120000 | Symbolic link. |
| S_IFREG | 0100000 | Regular file. |
| S_IFBLK | 0060000 | Block device. |
| S_IFDIR | 0040000 | Directory. |
| S_IFCHR | 0020000 | Character device. |
| S_IFIFO | 0010000 | FIFO. |
| S_ISUID | 0004000 | Setuid bit. |
| S_ISGID | 0002000 | Setgid bit. |
| S_ISVTX | 0001000 | Sticky bit. |
| S_IRWXU | 0000700 | Mask for owner permissions. |
| S_IRUSR | 0000400 | Owner read permission. |
| S_IWUSR | 0000200 | Owner write permission. |
| S_IXUSR | 0000100 | Owner execute permission. |
| S_IRWXG | 0000070 | Mask for group permissions. |
| S_IRGRP | 0000040 | Group read permission. |
| S_IWGRP | 0000020 | Group write permission. |
| S_IXGRP | 0000010 | Group execute permission. |
| S_IRWXO | 0000007 | Mask for permissions for others. |
| S_IROTH | 0000004 | Other read permission. |
| S_IWOTH | 0000002 | Other write permission. |
| S_IXOTH | 0000001 | Other execute permission. |
