# TABLE 10.5
XSI si_code values for SIGCHLD

| Value | Meaning |
| :---- | :------- |
| CLD_CONTINUED | A stopped child has been continued. |
| CLD_DUMPPED | Child terminated abnormally and dumped core. |
| CLD_EXITED | Child exited normally. |
| CLD_KILLED | Child was killed by a signal. |
| CLD_STOPPED | The child process was stopped. |
| CLD_TRAPPED | A child being traced has stopped. (This condition occurs if a program is being traced—either from a debugger or for real-time monitoring. In any case, you're not likely to see it in run-of-the-mill situations.) |
