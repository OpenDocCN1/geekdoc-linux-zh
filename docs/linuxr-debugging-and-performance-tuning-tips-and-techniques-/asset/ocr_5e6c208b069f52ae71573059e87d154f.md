Lines 68–70 handle the case in which the system call was interrupted. In this case, a goto back to the waitpid() call is the cleanest way to handle things. (Since main() causes all signals to be blocked when the signal handler runs [line 96], this interruption shouldn’t happen. But this example shows you how to deal with all the cases.)

Lines 71–76 handle any other error, printing an appropriate error message.
