To save space, we've omitted main(), which is unchanged from the other programs presented earlier, and we've also omitted process(), which now calls do_statfs() instead of do_statvfs().

Lines 13-35 contain the list of filesystem magic numbers from the statfs(2) manpage. Although the numbers could be retrieved from kernel source code header files, such retrieval is painful (we tried), and the presentation here is easier to follow. Lines 86-125 define type2str(), which converts the magic number to a printable string. It does a simple linear search on a table of (value, string) pairs. In the (unlikely) event that the magic number isn't in the table, type2str() creates an "unknown type" message and returns that (lines 123-124).

do_statfs() (lines 129-153) prints the information from the struct statfs. The f_fsid member is omitted since fsid_t is an opaque type. The code is straightforward; line 145 uses type2str() to print the filesystem type.
