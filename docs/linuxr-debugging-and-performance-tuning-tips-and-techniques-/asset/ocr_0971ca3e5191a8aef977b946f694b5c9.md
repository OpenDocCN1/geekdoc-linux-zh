# 14.3.1 Microsecond Times: gettimeofday()

The first task is to retrieve the time of day:

```
```c
#include <sys/time.h>
```
```

```
```c
int gettimeofday(struct timeval *tv, void *tz);
```
```

`gettimeofday()` gets the time of day.<sup>5</sup> The return value is 0 on success, -1 for an error. The arguments are as follows:

```
```c
struct timeval *tv
```
```

This argument is a pointer to a struct `timeval`, described shortly, into which the system places the current time.

```
```c
void *tz
```
```

This argument is no longer used; thus, it's of type `void *` and you should always pass `NULL` for it. (The manpage describes what it used to be and then proceeds to state that it's obsolete. Read it if you're interested in the details.)

The time is represented by a struct `timeval`:

```
```c
struct timeval {
    long tv_sec;     /* seconds */
    long tv_usec;    /* microseconds */
};
```
```

The `tv_sec` value represents seconds since the Epoch; `tv_usec` is the number of microseconds within the second.

The GNU/Linux `gettimeofday(2)` manpage also documents the following macros:

```
```c
#define timerisset(tvp) ((tvp)->tv_sec || (tvp)->tv_usec)

#define timercmp(tvp, uvp, cmp) \
    ((tvp)->tv_sec cmp (uvp)->tv_sec || \
    (tvp)->tv_sec == (uvp)->tv_sec && \
    (tvp)->tv_usec cmp (uvp)->tv_usec)

#define timerlear(tvp) ((tvp)->tv_sec = (tvp)->tv_usec = 0)
```
```
