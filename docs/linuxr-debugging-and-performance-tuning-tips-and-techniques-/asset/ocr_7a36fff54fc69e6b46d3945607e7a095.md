> NOTE What’s unusual about these debugging functions is that *application code never calls them*. They exist *only* so that they can be called from a debugger. Such functions should *always* be compiled in, without even a surrounding `#ifdef`, so that you can use them *without having to take special steps*. The (usually minimal) extra code size is justified by the developer’s time savings.
