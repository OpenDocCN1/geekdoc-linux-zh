# Set up the disk

**07**  Before we get to playing any games, we need to make sure that RetroPie is able to use all of it's data on the micro SD card. This will allow you to store ROMs and save your games. Select “Raspberry Pi” from the menu. You will be presented with several configuration options. Select “Raspberrypi Configuration Tool/RASPI-CONFIG”. You can change the default username and password at a later date, for now just use the current username: pi password: raspberry. Next, highlight the “Select” button and display settings and check to see if a “success screen” — press OK and you will be taken to the configuration screen. Press right until “finish” is highlighted, then click on it. You should now reboot your Raspberry Pi.

# Adding ROMs

**08**  The final step is adding new ROMs. Once you’ve legally purchased and downloaded ROMs to the computer, we next need to copy them onto the micro SD card. ROMs are stored in a separate folder for each system. So, for example, you need to place your Sega Master System ROMs at ~~/RetroPie/roms/smastersystem~~. Once you’ve downloaded your files, you’re ready to play!

# Playing

**09**  Once booted, you’ll see a menu with all the available game systems on it. Some emulators will only show up once game ROMs for that system are installed. Scroll until you find the game you want to play — then hit: run! You can always return back to RetroPie if you want to change any of the configuration options, or update the software. And that’s all there is to it! Time to sit back and play some games. If you want to find out more about the RetroPie software, visit http://blog.petrockblock.com/retropie
