# Download and install Node.js

**02** Next, we're using *node* and its package APIs to the Node package manager (npm). Type `sudo wget https://nodejs.org/dist/v8.18.21/node-v8.18.21-linux-arm6l.tar.gz` (This will download a fairly recent version of Node.js -- the version RaspiOS has in its repositories is way too old and just doesn't work with the newer technologies we're about to use. Extract the node package by typing `sudo tar -xzvf node-v8.18.21-linux-arm-pi.tar.gz`

# Configure Node.js

**03** To make it easy to run from everywhere you will create symbolic links for Node and npm binaries. Type `sudo ln -s ~/src/node/v8.21.1inux-arm6/pi/bin/node ~/bin/node` and then `sudo ln -s ~/src/node/v8.18.21-linux-arm-pi/bin/npm ~/bin/npm`. Then, to get the extra modules, type `npm install socket.io` under-static socket, `lib` and `serial`-`pc-dm-pi` driver. `sleep` until 31

# Get to know the project

**04** Now we have everything, you should see three files: the server (app.js), the client (socket.html), and the jQuery *jquery*.js library for the client. The server not only drives the servos, but it is a web server and sends the *socket.html* file and *jquery*.js to the browser when requested -- it's a really neat and simple setup and just right for what we're trying to achieve.

# Test the servos

**05** Our handly little program (app.js) has a special mode just for testing. We use two keywords: *pilot*--Beta for servo 0 (steering) and *servo* for servo 1 (motor control). Type node app is test=100. You should see the two from left to right in the numbers next 400, *was*--right--340 was left, 400, was centre and 470 was right. Do the same for the motor by typing node app.js gamma=-400 and take note of the various limits of your car.
