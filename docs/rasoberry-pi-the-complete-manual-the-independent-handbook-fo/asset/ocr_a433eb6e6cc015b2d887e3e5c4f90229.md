# Turn overscan on and off

+   07 You may have noticed one of two behaviours if you’re using your Pi with a modern HDTV. There’s a black border the whole way around the image cut off by the Pi – it just doesn’t fit correctly. This is caused by underscan.\n*   If you can’t see the edges of your screen to get to turn them up, suffering from overscan.

*   If you have the former issue, you may need to either turn up on overscan, or enable a “zoom” mode or similar on your TV.\n*   If you have the latter issue, you need to turn overscan off so that you can see the edges.

# Update rapsi-config

+   08 The rapsi-config tool receives updates from time to time.\nThis is generally to either add more features or fix small bugs, or both!\nIt’s not a bad idea to run the update at when you use the tool – before you start changing any system settings. While it’s much more likely that it’ll be updated to look better or do more things, it’s not impossible there could be misinterpreted bugs hidden within that would otherwise cause you some grief.\nRemember, though, when you re-run rapsi-config tool you’ll need an internet connection, either through a LAN cable or wireless. Without them, it’s never going to get any newer. Always try to make sure you on the latest version.

# Configure your location

+   03 Locale is the language and regional settings that your Pi is using – while this generally has little impact on how you’ll use it, it is reasonable to use a default currency settings, etc. So could prove to be an irritant at a later time if wrong.\nUpon selecting the option, you’ll be taken through a wizard. Use the arrow keys to check the built-in locale before you continue (it takes a while).\nTimezone will take you to a timezone screen where you can adjust it.

# Overclock your Pi

+   04 You can set the clock speed and voltage of your Pi to several different presets. Setting the clock speed and voltage at higher rates than the specification may cause instability, so do so in small increments.

![](bbox=[0.03, 0.95, 0.33, 0.99])

and ensure good airflow around your Pi.\nIf you see any noticeable instability, run this wizard again and set the clock speed back down to something slightly lower – repeat until your system is completely stable.

From the start of this tutorial, a Model/ Medium overlock is recommended. It seems to give a little extra performance with no noticeable side effects. It’s also recommended to reboot your system after making the change. Hold the Shift key to temporarily disable overlocking.

# Change the memory split

+   05 Changing the memory split of the Pi allows you to give either the system or the graphics processor a larger amount of memory.\nThe value you give to it must be either 16/32/64/128/256, to use memory settings for graphics.\n3D GPU performance for basic desktop where video and 3D rendered games.\n64MB GPU memory for desktop use that requires video playback or 3D effects enabled.\n128MB GPU memory for graphical applications and games that do extensive multimedia or play 3D rendered games.\nFor most people, a 64MB split for graphics will suffice.
