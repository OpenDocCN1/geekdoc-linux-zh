# Fitting the Pi-mote

03 Before fitting the Pi-mote, remember to shut down your Raspberry Pi with sudo poweroff. Next, unplug the power supply and fit the module onto your Raspberry Pi. The L part of the board fits opposite the HDMI port. Power up the Pi and plug in one of your Enel genie sockets in the same room or area that your Pi is in.

The device's range is fairly good, but furniture, walls and other objects may sometimes block the transmission signal. You can test that the socket is working by plugging in something like a desk lamp and then pressing the green button that is located on the socket. This will trigger the socket on and off, turning the lamp on and off in turn.

# Download the set-up code

04 Before the Raspberry Pi can interact with the socket and switch it on/off, it requires programming to learn a control code that is sent from the transmitter. Each socket has its own unique code so that you can control up to four individually. Enel genie provides the set-up program which can be found inside our tutorial resources (available at bit.ly/21ZKMQ4).

# Set up in your socket

05 Once you have downloaded the set-up program, run it. This should place the socket into 'learning mode', which will be indicated by the LED on the front of the socket housing slowly flashing. Do not do this, press and hold the green button for at least five seconds and release it when the LED starts to flash at a one-second interval. Run the program and it will send a signal out. Follow the on-screen prompts, pressing the button key when required.

When the code is accepted, success will be indicated with a brief flashing of the LED on the housing. If you have more than one socket to set up, simply use the same program and method to do so for as many times as required.

# A quick test

06 Before you get to the task of creating your Python code to control your socket, it is always advisable to test that the socket is working correctly. Ensuring that the power is turned on at the wall plug and that the lamp is switched on, you can turn the lamp off by pressing the green button on the front of the Enel genie socket. The lamp should turn back on again when the button is next pressed.

# Code to turn the socket on

07 The Python Enel genie library makes it incredibly easy to create a code to turn the socket on, which will then turn your lamp on. Before you know it, you'll be using your Raspberry Pi to turn the kettle on (if that on/off)!

Open your Python editor and start a new program. Next, import the Raspberry Pi GPIO library (line 1, below), then import the Enel genie library (lines 2 and 3). Finally, add in the code to switch the socket on (line 4). Save and then run your program. The socket will turn on, you may hear a click, and then your lamp will come on.

```python
import RPi.GPIO as GPIO
import enelgeenie
from enelgeenie import switch_on
enelgeenie.switch_on(1)
