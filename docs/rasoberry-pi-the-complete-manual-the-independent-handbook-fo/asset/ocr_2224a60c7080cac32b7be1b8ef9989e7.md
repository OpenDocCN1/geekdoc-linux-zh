# Install to card

**03** Open up the terminal and use `fdisk` to determine where your SD card is allocated on your system (depending on the pre-allocated system/swap/boot/control size). Navigate to the image using `cd` and install with `dd using`

```
$ dd bs=1M if=openELEC-RPi2-arm-5.5.5.img of=/dev/
```

# First boot

**04** Plug in your Raspberry Pi and either use your HDMI connection or wait until it’s ready to reserve and run it on. On OpenELEC, you’ll reserve the SD card partitions and write a few extra programs before finally booting into Kodi.

# Configure Kodi

**05** Get the OpenELEC web interface to get through the first interface. If you’re connecting via Wi-Fi, you’ll need to go to OpenELEC in the System menu, and activate the wireless network options selector if your network and then entering your password

> “It’s a great use for the Pi – it works just well enough that you can easily play media locally or over the network”

# Add network shares

**07** Placement of your Raspberry Pi is important. As it’s going to be out all the time, we highly recommend getting a case for it – the Aboz cases from Pimoroni are quite well suited to this type of use as they are sturdy and can be attached to the rear of some TVs.

# IR sensors and controllers

**08** You can be controlled with a number of different things – including USB game controllers and compatible IR sensors. We’ve used FLIRC in the past, but if you need a sensor on a wire that can stretch to a useful position.

# Future updates

**09** OpenELEC has the excellent ability to update itself without needing you to restart it every few months, meaning you won’t need to do much maintenance on it at all. Now you can sit back and enjoy your media much easier than before.

# Add network shares

**06** You can attach a portable hard drive or USB stick to the Pi for storage, but it is likely to stream over the network. Go to File manager under System and add source. Go to Browse and choose the TV, your network protocol to browse the network or alternatively add it manually.
