# Scratch block help

02 As we’ve seen, there are many blocks, each with their own specific functionality and capabilities.

In one way this is great news: A large block collection means Scratch can be used in a vast range of software projects, such as games, animation, music, graphics, math, science, robots, electronics and much more.

However, the wide selection of blocks can be quite a challenge for the novice Scratch coder. To help with this problem the Scratch Studio designers have included an informative set of block-centric help pages.

A simple right click on any block will display a pop-up help page option. The help page contains context-specific descriptions, graphical images and, where appropriate, a script example of how to use this particular block (Fig 4). It’s a terrific feature which greatly simplifies the process of decoding which blocks to use. More importantly, studying these help pages is a highly effective way to enhance our scripting skills and discover the potential contained within Scratch’s feature-rich block collection.

# Block script walkthrough

03 Let’s step deeper into how a block script works in practice. For this, we will use a simple Aquarium project block script. From the 'Sprite collection' panel select the 'Stage' tab. Then go back to the central 'Edit Panel' and select the 'Scripts' tab.

Here’s just a block block script. Starting at the top throws a green flag that starts/block to kick off the activity. Next there’s a 'forever' loop. The block's inside this loop are activated until the stop button is pressed. This forever loop block contains two other blocks.

The first inner script block selects the next background image. Click on the 'Backgrounds' tab to view all the stage images. The second inner block simply pauses execution for a number of seconds. Setting the value to 11 means that this script will pause for a second before then performing the action specified by the next block.

It’s important that you remember these two blocks are enclosed in the forever loop block. So, the stage background images will be displayed in sequence for one second each.
