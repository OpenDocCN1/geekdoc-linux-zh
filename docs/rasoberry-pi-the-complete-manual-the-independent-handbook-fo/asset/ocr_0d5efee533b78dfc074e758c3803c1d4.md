# Create a Snake clone in Scratch

# Projects

# Paint the Egg sprite

**17** Click the New Sprite Paintbrush can to paint a new sprite. In the Paint Editor, draw a small yellow ellipse. Name the sprite Egg. The Egg will appear randomly on the stage and cause the snake to grow and increase its score.

![](bbox=[0.04, 0.22, 0.29, 0.29])

![](bbox=[0.04, 0.29, 0.29, 0.35])

# Add Egg sound

**18** Go to the Sounds tab for the Egg sprite and import the percussion-Cymbal sound. Or you can choose a different sound if you like. This sound will play when the snake eats an egg.

![](bbox=[0.04, 0.47, 0.29, 0.55])

# Add Egg scripts

**19** Copy the Egg script so that the Egg appears randomly at the start of the game. When the Egg senses that it has been eaten, it must hide, play the Cymbal sound (or whatever you chose in Step 18), update the score, broadcast the Egg Eaten event and then randomly appear again. When the Game Over event is received, it must stop.

# Make Bad Egg

**20** Create the black Bad Egg in the same way as the Egg but using a different shape and the instruments-String/Pluck sound. Drag the Egg’s green flag script onto the Bad Egg to copy them – just change the sound and replace it with a random bonus.

![](bbox=[0.37, 0.22, 0.58, 0.35])

# Grow Bad Egg

**21** Add another ‘when green flag clicked’ script to the Bad Egg so it resets its size to the default 100% when a new game is started and then increases its size by ten every ten seconds. The Bad Egg will get bigger and bigger and harder to avoid.

![](bbox=[0.65, 0.22, 0.9, 0.35])

# Create Bonus sprite

**22** Create the Bonus sprite in Scratch. Then you can choose the shape and sound for the Bonus. Its scripts are similar to the Egg ones so you could drag one of those to the Bonus sprite and work from that. Make sure you change the sound and increase the score by a random bonus.
