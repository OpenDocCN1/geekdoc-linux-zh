# Configure the breadboard

For the Raspberry Pi GPIO to control the camera, we need to connect a short cable between a pin on the GPIO (in this case, pin 23) on the 40-pin GPIO, the actual physical pin 16, and the pin that connects to the head or foot of the camera cable that activates the shutter when connected. The base of the connector is always ground, so make sure you ground the GND pin on the Cobbler and the middle pin on the audio jack. With the circuit complete, we can focus on the code.

# The Time-lapse Photography Tool

We've created a small 55-line Python utility called the Linux User's Time-lapse Photography Tool, which acts like a camera remote. It takes the commands and uses that to fire the Pi's camera and shut it down using GPIO pin 16. You don't need to use the project in the field. We recommend using the Android app "Connect to the Pi" app to use the tool via your phone, and you don't need an SD card. Once written, you can start your script with the command `sudo python time_lapse_camera.py`.
