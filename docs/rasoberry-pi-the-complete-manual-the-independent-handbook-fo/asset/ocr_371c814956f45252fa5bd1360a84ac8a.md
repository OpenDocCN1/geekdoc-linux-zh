```
# Configuring VNC server

That's the VNC server installed up and running. Now we need to make sure it loads up as a service every time the Raspberry Pi reboots, so you can access it even if the Pi undergoes a power cycle. To configure the Pi to do this, type the following in the terminal and press Enter.

```
```bash
sudo nano /etc/init.d/
tightvnserver
```
```

# Configuring boot service

We're back in nano, and we need to enter some lines of commands in order to allow the Raspberry Pi to activate the VNC server when it boots. In the editor, type:

```
```bash
#!/bin/sh
#if [unit /etc/init.d/tightvnserver]
# Set the NUMBER to start
# the tightvnserver user
# NUMBER='pi'
case "$1" in
start) su NUMBER -c '/usr/bin/
tightvnserver -c '
# echo "Starting TightVNC
# server for "'$NUMBER"'
#;;
stop)
pkill xtigntVnc
echo "TightVncserver stopped"
#;;
*)
echo "Usage: /etc/init.d/
tightvnserver
start|stop"
#;;
exit 0
```
```

# Reboot and ready to go

Now press **Ctrl-X**, then **Y** and **Enter**. To save. Follow that a couple of tries to get you back into the Terminal. Now we need to do now is edit the permissions of the script we've just created so that it's executable and active. Do this by typing the following commands into the terminal, ensuring that you press Enter after each one otherwise it will not be registered!

```
```bash
sudo chmod 755 /etc/init.d/
tightvnserver
sudo rc-tightvnserver defaults
sudo reboot
```
