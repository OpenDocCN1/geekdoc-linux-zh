# Check connection

+   04 Our running on the desktop will be an internet- or Android device. We’ll connect the Pi and its IP address.
+   $ ifconfig

# Quick connect

+   05 You can connect from the terminal right now to access the Internet. You should be able to do this by typing the following into your terminal.
+   $ sudo dhclient usb0
+   This will automatically grab any available IP address; that’s your phone acting as a router.

# Test connection

+   06 Open your web browser and head to google.com. If you can load the site, you’re all set up.
+   $ nano /etc/network/interfaces

![](bbox=[0.04, 0.58, 0.66, 0.81])

# Save the settings

+   07 After you connect your Raspberry Pi it should automatically access the internet. You can use $ sudo nano /etc/network/interfaces to make these changes permanent.

# Tether on the go

+   09 Now, when you’re out and about, your phone can tether your Pi. This will give you Internet access wherever you go, as long as you have a cellular connection.

# Interface settings

+   08 Here you’ll find at the current settings. Your might look different from ours depending on if you have added any fixed IP address settings or other stuff. Using the same syntax as the eth0 line, add:
+   iface usb0 inet dhcp
