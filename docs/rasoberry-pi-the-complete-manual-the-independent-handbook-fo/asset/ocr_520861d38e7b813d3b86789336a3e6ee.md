# Split the Raspbian partitions

**11** Usually the boot partition should remain on the SD card while the root filesystem is run from the external HDD or USB thumb drive. Using your preferred partition manager (Disk Utility is in most distros), unmount and delete the root filesystem from the SD card (ensuring you have retained the boot partition). After removing the SD card, connect your USB device and delete the boot partition, taking care to leave the root filesystem intact. Then resize the root filesystem on the USB device, making sure your 10MB remains.

# Identify the root filesystem

**12** You're going to have the SD card and the external USB storage connected, so you need to tell the Pi where the root filesystem is. On the Pi, insert your external USB drive and, with the SD card inserted, run:

```
$ sudo nano /boot/cmdline.txt
```

Find **root=/dev/mmcblk0p2** (or similar) and change it to read **root=/dev/sdb2**, which is your external USB storage. Save and exit.

# Add other USB devices

**13** Now you can now restart your Pi. Plug in the storage devices and watch them attach. As soon as you connect further USB media you'll suffer problems. Avoid by installing gdisk:

```
$ sudo apt-get install gdisk
```

Then run gdisk.

```
$ sudo gdisk /dev/sdb
```

Enter 'h' to display the options and select **Recovery and Transformation Options** (usually 'r', followed by 'L' and 'M2'). **Build Fresh GPT: Tap 'Y'.** One last time and we're done. Write 'Backup to Disk' last. This will take the USB drive and create a GPT with a 10MB partition. You'll use the last partition as your time. You'll use 1 as the root filesystem.

# Make your Pi fast and reliable

**14** Now make a note of the GUID and then switch to the SD card. Reopen cmdline.txt and change root=/dev/mmcblk0p2 to root=PARTUUID=XXXXXX, where the numerical string from the partition unique GUID should replace the XXXXXX. When you're done, save and exit. You can then start your Raspberry Pi. Congratulations, your Raspberry Pi is now faster and more reliable to use.

# Boost performance with overclocking

**15** There's little from your Pi that's possible to overclock the computer. Although you should be aware of the risk, proceed with this activity. You should also ensure that your Raspberry Pi's processor is suitably cooled—heat sinks for the CPU, Ethernet controller and power regulator can be purchased online.

# Overclock your Pi

**16** Overclocking a available through rasp-config. Launch from the command line: **sudo raspi-config** and navigate to Advanced Options. Then select Overclocking. Three options are available: **Modest**, **Medium**, **High** and **Turbo**. With your ideal clock speed selected, exit. Choose **Yes** to apply.
