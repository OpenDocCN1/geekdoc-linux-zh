### Install to card

**03** Open up the terminal and use `fdisk` to determine where your SD card is allocated on your system (depending on the pre-allocated system/swap/boot/control size). Navigate to the image using `cd` and install with `dd` using:

```
$ dd bs=1M if=openELEC-RPi2-arm-5.5.5.img of=/dev/sda1
```

**04** Plug in your Raspberry Pi and either use your HDMI connection or wait until it’s ready to boot and run it. On OpenELEC, you’ll reserve the SD card partitions and write a few extra programs before finally booting into Kodi.

**05** Get the OpenELEC web interface to get through the first interface. If you’re connecting via Wi-Fi, you’ll need to go to OpenELEC in the System menu, and activate the wireless network options selector for your network and then enter your password.

**06** You can attach a portable hard drive or USB stick to the Pi for storage, but it is likely to stream over the network. Go to File manager under System and add source. Go to Browse and choose the TV, your network protocol to browse the network or alternatively add it manually.

## Print wirelessly with your Pi

### What you'll need...

- Latest Raspbian image
- USB printer
- USB wireless card

Breathe new life into an old printer by using your Raspberry Pi as a wireless print server.

Wireless printing has made it possible to print to devices stored in cupboards, sheds and remote rooms. You don't have to own a shiny new printer for this to work; old printers without native wireless support don't have to end up in the bin, thanks to the Raspberry Pi.

The setup is simple. With your Pi set up with a wireless USB dongle, you connect your printer to a spare USB port on the computer. With Samba and CUPS (Common Unix Printing System) installed on the Raspberry Pi, all that is left to do is connect to the wireless printer from your desktop computer, install the appropriate driver and start printing.

CUPS gives the Raspberry Pi a browser-based admin screen that can be viewed from any device on your network, enabling complete control over your wireless network printer.

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_79_0.png)

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_79_1.png)

### Check your printer works

**01** Before starting, check that the printer you're pairing to has ink for the project still works and has enough ink. The easiest way to do this is to check the documentation (online if you can't find the manual) and run a test print.

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_80_0.png)

### Join a Windows workgroup

**02** With these additions made, search for “workgroup” in the configuration file and then add your workgroup:

```
workgroup = your_workgroup_name
wins support = yes
```

Make sure you uncomment the second setting so that the print server can be seen from Windows. Next, save your changes and then restart Samba:

```
sudo /etc/init.d/samba restart
```

### Detect your printer

**03** With your Raspberry Pi set up as usual and the printer connected to a spare USB port, enter:

```
lsusb
```

This will confirm that the printer has been detected by your Raspberry Pi; in most cases you should see the manufacturer and model displayed.

### Install Samba and CUPS

**04** Install Samba on your Pi to enable file and print sharing across the entire network:

```
sudo apt-get install samba
```

Next, install CUPS:

```
sudo apt-get install cups
```

With a print server created, begin configuration by adding default user pi to the printer-admin group:

```
sudo usermod -aG lpadmin pi
```

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_80_1.png)

### Set up print admin

**05** Set up the CUPS print admin tool. Boot into the GUI (startx) and launch the browser, entering 127.0.0.1:631. Switch to Administration, before ensuring that the “Share printers” and “Allow remote administration” boxes are selected. Select Add Printer and proceed to enter your Raspberry username and password.

### Add your printer

**06** A list of printers will be displayed, so select yours to proceed to the next screen where you can confirm the details, add a name and check the "Share This Printer" box. Click Continue to load the list of printer drivers and select the appropriate one from the list.

### Accessing your printer

**07** Meanwhile, it's also easier to access your wireless printer from a Linux, Mac OS X or other Unix like system, thanks to CUPS. All you need to do is add a new network printer in the usual way and the device will be displayed.

### Configure Samba for network printing

**08** Using a Windows computer for printing? Samba will need some configuration added. Open /etc/samba/smb.conf in nano, search for [HwAwI] for [printers] and find guest ok which you should change as follows:

```
guest ok = yes
```

Next, search for [print$]: then change the path as follows:

```
path = /usr/share/cups/drivers
```

### Add AirPrint compatibility

**09** We also make it possible to print wirelessly from your Apple devices using Apple's AirPrint system. To do this, you need to add the Avahi Discover software:

```
sudo apt-get install avahi-discover
```

Your wireless printer will now be discoverable from your iPad or iPhone and will be ready to print.

## Control lights with your Pi

### What you'll need...

- Pi-Mote (RF control board with RC sockets)
- 4G / MSF / 38
- Desk lamp
- Accessories

### Did you know...?

Every project on the market on a smartphone platform is not accessible off-line. The Pi-Mote is open and closed. In your home or office, you can use a Python or C script to control your devices. The software is open source, and the code is available on GitHub. The Pi-Mote can be used with any Raspberry Pi model number 3B, 3B+, or your Raspberry Pi 4 Model B.

### Remote control

Take control of your home environment using your smartphone's browser

The winter nights are getting longer: use a Pi and mobile device to remotely control your lights.

The folks at Energenie have created some genius plug sockets that can be turned on and off via your Raspberry Pi. You can buy a starter kit which includes the RF transmitter add-on board and two sockets to get you started. The add-on board connects directly to the GPIO pins and is controlled with a Python library. Once everything is installed and set up, your Raspberry Pi can be used with the Pi-mote to control up to four Energenie sockets using a simple program. This tutorial covers how to set up the software, the sockets and how to adapt the program so that it can run on your mobile device.

### Set up

**01** To get started, boot up your Raspberry Pi and load the LXDE Terminal, then update your software by typing:

```
sudo apt-get update
sudo apt-get upgrade
```

Depending on which version of the OS you're using, you may need to install the Python GPIO libraries. (Debian Jessie comes with this library pre-installed, so you can skip this step.) Type the following into the command line:

```
sudo apt-get install python-rpi.gpio
```

On completion, reboot your Pi. This will install the Python GPIO libraries, meaning you can access and control the pins with Python code.

### Install the Energenie library

**02** Next, install the Energenie libraries. These enable the Pi-Mote board and Raspberry Pi to interact with Python. Inside the LXDE Terminal, depending on which version of Python you are using, type either:

```
sudo apt-get install python-pip
sudo pip 3.2 install energecie
```

... for Python 3, or

```
sudo apt-get install python-pip
sudo pip install energecie
```

...for an older version. In the future, Energenie will update its software and you may need to run a check for updates to ensure that you have the most recent version. To update the software, type the code:

```
sudo pip install energecie --update
```

> “Your Pi can control up to four Energenie sockets using this simple program”
