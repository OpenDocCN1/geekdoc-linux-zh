# ## Debugging

To collect I²C-specific debugging messages, turn on a relevent combination of *I2C Core debugging messages*, *I2C Algorithm debugging messages*, *I2C Bus debugging messages*, and *I2C Chip debugging messages* under Device Drivers → *I2C Support* in the kernel configuration menu. Similarly, for SPI debugging, turn on *Debug Support for SPI drivers* under Device Drivers → *SPI Support*

To understand the flow of I²C packets on the bus, connect an I²C bus analyzer to your board as we did while running Listing 8.1. The lm-sensors package contains a tool called i2cdump that dumps register contents of devices on the I²C bus.

There is a mailing list dedicated to Linux I²C at http://lists.lm-sensors.org/mailman/listinfo/i2c.
