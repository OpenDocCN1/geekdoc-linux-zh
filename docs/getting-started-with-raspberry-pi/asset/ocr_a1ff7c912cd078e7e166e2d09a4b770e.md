# Version Control

You can't execute a serious project without the services of a robust version control repository. A version control system helps manage multiple versions of source code and regulates file accesses by team members.
Concurrent Versions System or CVS ([www.nongnu.org/cvs](www.nongnu.org/cvs)) is an open source revision control software that has been around for a long time and comes bundled with many Linux distributions. Another versioning system called subversion ([http://subversion.tigris.org](http://subversion.tigris.org)) was developed as an intended replacement for CVS. Git ([http://git.or.cz](http://git.or.cz)) is the version control system of choice for kernel developers and is used to maintain several open source projects, including the Linux kernel. Ample documentation on these systems is available on the Internet.
