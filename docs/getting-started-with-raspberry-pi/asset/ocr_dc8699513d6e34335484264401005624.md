# Looking at the Sources

In the Linux source tree, the *drivers/pmcia/* directory contains the sources for Card Services, Driver Services, and host controller drivers. Look at *drivers/pmcia/yenta_socket.c* for the host controller driver that runs on many x86-based laptops. Header files present in *include/pmcia/* contain PCMCIA-related structure definitions.

Client drivers live alongside other drivers belonging to the associated device class. So, you will find drivers for PCMCIA networking cards inside *drivers/net/pmcia/*. The client driver for PCMCIA memory devices that emulate IDE is *drivers/ide/legacy/ ide-cs.c*. See *drivers/serial/serial_cs.c* for the client driver used by PCMCIA modems.

Table 9.2 summarizes the main data structures used in this chapter and their location in the kernel tree. Table 9.3 lists the main kernel programming interfaces that you used in this chapter along with the location of their definitions.

**Table 9.2. Summary of Data Structures**

| Data Structure | Location | Description |
| :--- | :--- | :--- |
| pmcia_device_id | include/linux/mod_devicetable.h | Identity of a PCMCIA card. |
| pmcia_device | include/pmcia/ds.h | Representation of a PCMCIA device. |
| pmcia_driver | include/pmcia/ds.h | Representation of a PCMCIA client driver. |
| tuple_t | include/pmcia/cistpl.h | CIS manipulation routines use a tuple_t structure to hold information. |
| cistpl_cftable_entry_t | include/pmcia/cistpl.h | Configuration table entry in the CIS space. |
| cisparse_t | include/pmcia/cistpl.h | A parsed CIS tuple. |

**Table 9.3. Summary of Kernel Programming Interfaces**

| Kernel Interface | Location | Description |
| :--- | :--- | :--- |
| pmcia_register_driver() | drivers/pmcia/ds.c | Registers a driver with the PCMCIA core |
| pmcia_unregister_driver() | drivers/pmcia/ds.c | Unregisters a driver from the PCMCIA core |
| pmcia_get_first_tuple()<br>pmcia_get_tuple_data()<br>pmcia_parse_tuple() | include/pmcia/cistpl.h<br>drivers/pmcia/cistpl.c | Library routines to manipulate CIS space |
| pmcia_request_irq() | drivers/pmcia/pmcia_resource.c | Gets an IRQ assigned for a PCMCIA card |
