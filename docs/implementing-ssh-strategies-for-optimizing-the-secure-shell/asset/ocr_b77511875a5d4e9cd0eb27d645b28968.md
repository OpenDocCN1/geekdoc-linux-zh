Figure 9.9 shows a SOCKS configuration on Internet Explorer. To reach this screen, open Internet Explorer ⊕ Tools ⊕ Internet Options ⊕ Connections ⊕ LAN Settings ⊕ Check Use Proxy Server ⊕ select Advanced ⊕ enter SOCKS information.

Figure 9.10 shows a SOCKS configuration on Netscape Messenger. To reach this screen, open Netscape Messenger ⊕ Edit ⊕ Properties ⊕ Advanced ⊕ Proxies ⊕ Manual Proxy Configuration ⊕ View. Then enter SOCKS information.
