1. SSH client makes a connection to the SSH server with dynamic port forwarding enabled. After a connection is established, a SOCKS server is enabled on the SSH client, on the loopback address, 127.0.0.1, using port 1080.

2. The web browser is configured to use a SOCKS server with an IP address of 127.0.0.1 on port 1080. When the web browser makes a web request, it sends the request to the local SOCKS server on port 1080 on the loopback address (127.0.0.1).

3. The dynamic port forwarding connection (the “Dynamic port” box) takes the web request and forwards it to the SSH server over the established SSH tunnel (over port 22).

4. SSH server sends the request to the Internet.
