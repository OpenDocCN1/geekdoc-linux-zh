# Compromising a System with Remote Execution (Rexec)

Remote Execution (Rexec) is also a client/server technology wherein the client, Rexec, connects to a rexec server (Rexe cd), usually listening on port 512. Rexec executes a remote command on a remote Rexec server as if the command came from the machine itself. Rexec also uses the username and password information from the Unix password file, such as /etc/passwd or /etc/shadow. As with RSH, Rexec has connections that are in clear-text, which allows a passive attacker to sniff the connection and access the username and password information on the remote operating system or device. Once an unauthorized user obtains the information, the system is virtually compromised.
