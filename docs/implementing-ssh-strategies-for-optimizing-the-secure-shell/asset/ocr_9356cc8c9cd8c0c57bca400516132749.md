# **Table 2.3** Rhost Configuration Options

| OPTION | DESCRIPTION |
|---|---|
| RhostAuthentication | To allow rhhosts authentication |
| Ignore Rhosts | To ignore (yes) or read (no) rhosts files in the users home directory, stored in .rhosts or .shosts files |
| RhostsRSAAuthentication | To atempt rhosts authentication from RSA host keys |
| HostbasedAuthentication | Enable (yes) or disable (no) host-based authentication under SSH version 2 |
| IgnoreUserKnownHosts | Ignore (no) or read (yes) the known hosts file in the users' home directory |

# **Table 2.4** Password and Kerberos Options

| OPTION | DESCRIPTION |
|---|---|
| PasswordAuthentication | To enable (yes) or disable (no) password authentication. |
| PermitEmptyPasswords | To allow (yes) or disallow (no) the use of blank passwords. |
