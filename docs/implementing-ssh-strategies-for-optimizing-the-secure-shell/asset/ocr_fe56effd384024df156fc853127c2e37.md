| OPTION | DESCRIPTION |
|---|---|
| MapFile | Identifies the keyword-mapping file for the preceding PKI keyword. |
| LDA PServers | Identifies the LDAP server to be used for CRLs. |
| SocksServer | Identifies the name of the SOCKS server, which is used for certificate CRL on remote servers. |
| PKIDisableCRLs | Disables CRL checking. |
