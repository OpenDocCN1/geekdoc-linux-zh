The Windows version of sshd_2_config file is similar to the Unix version; however, many differences distinguish the two versions. The following sections address the Windows sshd_2_config file.

# General Settings

The general section of the sshd_2_config file should look like the following:

```
```# General settings
    MaxConnections                          0
    EventLogFilter                          error, warning
    IdleTimeout                             0
    BannerMessageFile                       " "
    TerminalProvider                        "cmd.exe"
    DoubleBackspace                         yes
#     ProtocolVersionString```
```
