# SSH Server Configuration

The first order of business is to configure OpenSSH on the Windows file server. (For more information on the installation process, see Chapter 1.) The Windows file server basically has two partitions with two separate disk drives. Partition 1 is for the operating system’s files, including binaries, libraries, and support files, to keep the operating system running. Partition 2 is a separate 100GB disk that is mounted as drive D. After the OpenSSH server has been installed from the Windows file server, you will need to mount the D partition for all SSH clients on the Linux workstations. To mount the D partition, complete the following steps:

+   1. Open the passwd file from c:\Program Files\OpenSSH\etc\.
