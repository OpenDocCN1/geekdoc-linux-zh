The field options shown in Table 3.13 are available in the Quick Connect display.

# Table 3.13  Field Options in the Quick Connect Display

| FIELD | DESCRIPTION |
| --- |
| Protocol | Option to use SSH1, SSH2, or other non-SSH connections, such as Telnet, Rlogin, serial interfaces, or TAPI. |
| Hostname | The fully qualified host name for DNS resolution, such as sshserver.Aum.com. The dot notation of an IP address can also be used (for example, 10.8.15.47). |
| Port | The port number to use for the remote SSH server. Default SSH port is 22. The use firewall to connect checkbox enables firewall settings in the Global Options menu, such as SOCKS or Proxy settings. |
| Username | The username used on the remote SSH server. |
| Cipher | The encryption algorithm used for the SSH connection. Available options are DES, 3DES, RC4, and Blowfish. |
| Authentication | Authentication mechanism to be used for the SSH connection. Possible choices are RSA authentication (requires RSA ACE server on the server side of the connection), password, and TIS (requires TIS firewall server on the server side of the connection). |
