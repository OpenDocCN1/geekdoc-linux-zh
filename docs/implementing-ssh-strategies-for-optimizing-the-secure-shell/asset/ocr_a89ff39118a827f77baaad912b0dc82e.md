# ## Secure E-mail with SSH

The use of common e-mail protocols, such as SMTP, POP3, and IMAP, greatly increases the security exposures in an organization's e-mail architecture. Nevertheless, while there may be the availability of SSL-enabled POP3 and IMAP, the use of SMTP still allows outgoing e-mail exchanges to go over clear-text. While the use of clear-text protocols for any type of application, including e-mail, management, and file transfer, is just a bad idea, the use of clear-text protocols on the Internet is an even worse idea. The use of SSH can help mitigate some of the issues with clear-text e-mail protocols by using port forwarding with an SSH server to tunnel the SMTP and POP3/IMAP protocols over the Internet inside an SSH tunnel. This not only prevents unauthorized users from sniffing and reading other people's e-mail but also offers the ability to enforce two-factor authentication with the SSH connection, thus increasing the overall security of the e-mail architecture.
