# **Server Public Key Configuration**

The Server Public Key Configuration section of the sshd2_config file should look like the following:

```
<pre><code>#     HostKeyFile                hostkey
#     PublicHostKeyFile          hostkey.pub
</code></pre>
```

# **Table 2.22** Options in the Server Public Key Configuration Section (Windows)

| OPTION | DESCRIPTION |
| :--- | :--- |
| HostKeyFile | Identifies the location of the private host-key file. The default location is in the /etc/sshd2 directory, located on the local file system. |
