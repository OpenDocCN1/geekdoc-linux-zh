Table 2.40 Options in the Port-Forward Filters Section (Vshell)

| OPTION | DESCRIPTION |
| --- | --- |
| Filter Entries | Describes the filters that have been set. Options are either Allow or Deny, based on a particular IP address, hostname, network mask, or Domain.
