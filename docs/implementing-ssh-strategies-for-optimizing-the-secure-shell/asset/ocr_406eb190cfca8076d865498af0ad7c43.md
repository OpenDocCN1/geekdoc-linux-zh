+   1.  For OpenSSH, enter the following command:
+       `ssh 6.12.11.30 -p 22 -1 <username> -D 1080`
+   2.  For SSH Communications' SSH server, enter the following command:
+       `ssh2 6.12.11.30 -p 22 -1 <username> -L socks/1080`
+   3.  On the SSH client, configure any relevant applications to use a SOCKS server for outbound connections. Enter the loopback address (127.0.0.1) for the IP address and port number 1080.
