# ## MacSSH

MacSSH is an SSH client for Macintosh environments. MacSSH supports SSH2 only, with no support for SSH1. MacSFTP is similar to MacSSH but is used for the file-transfer portion of the connection. There are some other good clients for the Macintosh environment, including JellfySSH (www.arenasof-tware.com/grepsoft/) and RBrowser (www.rbrowser.com).
