# SSH User Restrictions

User restrictions are available with SSH Communications' Windows SSH server. SSH user restrictions are very similar to VShell's user access controls. Both are simple access-control lists applied to the usernames on the SSH server. To view the User Restrictions screen in SSH Communications' SSH server, complete the following steps:

+   1. Select Start Program SSH Secure Shell Server Configuration.
+   2. Highlight the User Restrictions section.

The SSH Communications' User Restrictions screen (see Figure 5.10) shows two separate sections, the Allow login for users and the Deny login for users.
