## 安装

Linux 难安装吗？并不难。大多数人从未在电脑上安装过 Windows，因为它是预装的。与 Windows 相比，Linux 安装更容易。你可以通过图形用户界面进行安装。但真正让人们困惑的是，在想要使用两个系统时，将 Linux 安装在硬盘的第二个分区上。

分区是组织硬盘空间的一种，通过创建相互独立的虚拟区域来实现。大多数运行 Windows 的计算机都有一个大空间存放操作系统，即 C 盘。大硬盘可能会被分成较小的部分，称为分区，帮助你更好地组织数据。这些分区通常命名为 D:、E: 等。你可以在任何一个分区上安装 Linux。

## Linux 与 Windows 区别

这个子主题将讨论 Linux 和 Windows 区别，我会讨论每个系统的某些方面。让我们先从 Linux 系统的概览开始。Linux 最基本的形式是计算机内核。内核是底层代码，用于与硬件和其他系统软件通信，它还运行计算机的所有基本功能。Linux 内核是一个操作系统，运行在各种硬件上并用于多种目的。Linux 能够运行在手表或手机等简单设备上，也可以运行在使用 Intel 或 AMD 处理器的家用电脑上，甚至能够运行在使用 Sun CPUs 或 IBM power PC 处理器的高端服务器上。某些 Linux 发行版只能运行一个处理器，而其他可以同时运行多个。Linux 的常见用途包括家用桌面计算系统，或者更常见的服务器应用程序，例如作为 Web 服务器或邮件服务器。





一位名为 Linus Torvalds 的程序员在 1991 年首次创建了 Linux，作为 Unix 操作系统的一个变体。Linus Torvalds 通过 GNU (GPL)（通用公共许可证）使 Linux 开源，这样其他程序员就可以免费下载源代码并按照他们认为合适的方式进行修改。全球成千上万的程序员开始下载并修改 Linux 源代码，应用补丁、修复错误以及其他改进，使该操作系统变得越来越好。多年来，Linux 已从一个简单的基于文本的 Unix 克隆版本演变为一个强大的操作系统，具有功能全桌面环境、前所未有的移植性以及多种用途。多年来，大部分原始的 Unix 代码也逐渐从 Linux 中被编写移出。

由于 Linux 是开源软件，因此没有单一的 Linux 版本；相反，许多不同的 Linux 版本或发行版，它们适用于不同的用户和任务。某些 Linux 发行版包括 Gentoo 和 Slackware，由于缺乏完整的图形环境，这些版本最适合 Linux 专家、程序员以及其他熟悉命令行提示符的用户。缺乏图形环境的发行版最适合缺乏处理图形所需计算能力的旧电脑，或者用于执行处理器密集型任务的计算机，在这种情况下，人们希望将所有系统资源集中于当前任务，而不是通过处理图形来浪费资源。

其他发行版旨在让计算体验尽可能简单。诸如 Ubuntu 等发行版通过提供功能全图形环境来帮助消除对命令行提示符的需求，使 Linux 变得更加易用。当然，易用性的缺点是配置性较低，并且在图形处理上浪费了系统资源。其他发行版如 FUSE 则试图在易用性和可配置性之间寻找平衡点。

## 安装
Windows 的安装通常比安装 Linux 简单。“对于 Windows XP 有三种主要的安装方式。一种是纯净安装，即在空白硬盘上安装 Windows。另一种是升级安装，你从旧版本的 Windows 开始并‘升级’到新版本。升级的优点是旧系统上的所有文件在整个过程中应该保持不变。你还可以执行修复安装，即在原有 Windows 之上安装相同版本的 Windows 以修复损坏的版本。

还有一种恢复，从技术上讲它不是安装；它用于将 Windows 副本恢复到设置状态。恢复 Windows 的缺点是你将丢失所有留留在损坏 Windows 副本上的数据。”（ref#1）此外，使用 Windows 你可以确保你的硬件很可能会被软件支持，尽管对于 Linux 来说这并不是什么大问题（它不支持的硬件很少）。Linux 的安装因发行版而异很大。你可能会遇到图形化安装，也可能是基于文本的安装；这些版本使得 Linux 的安装比 Windows 困难一些甚至不可能（尽管这种难度正在消失）。你可以对 Linux 进行纯净安装，或进行双启动以与另一个操作系统共存。使用 Linux，你不需要购买 CD，可以在桌面运行时通过下载并安装更新来完成更新。在 Linux 中，大多数大多数升级后不需要重启电脑，只有在内核内核升级后才需要重启。

在不需要将其安装到硬盘的情况下运行 Linux 也是可能的；许多 Linux 发行版允许你直接从 live cd 运行。这种方式的优点是，你不需要修改系统就可以尝试 Linux。你可以从 CD 运行 Linux，而无需损坏你的 Windows 分区。其他优点包括救助损坏的 Linux 系统的能力。如果你的 Linux 电脑无法启动，你可以插入一个 live cd 并从它启动，从而修复损坏的 Linux 版本。此外，你可能可以使用 Linux live cd 从不再启动的损坏 Windows 电脑恢复文件。由于 Linux 能够读取 NTFS 文件，你可以将文件从 Windows 电脑复制到 USB 闪盘或软磁盘等。

Linux 和 Windows 之间的另一个主要区别是你在两个操作系统上使用的应用程序。Windows 包含的商业支持的应用程序比 Linux 丰富得多。在 Windows 上找到你寻找的软件比在 Linux 上容易得多，因为有许多软件供应商仅让他们的产品兼容 Windows。在 Linux 上，你大多数情况下将被迫放弃你已经习惯的 Windows 家族应用程序，转而使用为 Linux 制作的开源应用。诸如 Microsoft Office、Outlook、Inkscape、Adobe Creative suite 以及作为聊天工具的 chat 无法在 Linux 上原生运行。尽管在 Linux 上，你可以使用名为 Over Office 的软件让 Microsoft office 和 Adobe 套件运行。在使用这些应用程序时，你需要使用 Open Office、GIMP 图像编辑器、Thunderbird 邮件客户端。在使用 MSN 时，你可以使用 GAIM 聊天工具，并可以使用 Firefox 作为网络浏览器。此外，在 Linux 上即使软件是为 Linux 制作的，安装也可能困难。这是由于 Linux 有许多不同的版本。为某个版本制作的安装软件在另一个版本上可能可能需要某些配置。例如，如果你尝试在 GNOME 上安装为 KDE 图形环境制作的软件，该应用在 GNOME 上无法在 GNOME 上轻松安装，并需要一些配置。Linux 和 windows 运行的硬件类型也导致了它们的不同。Linux 可以运行在许多不同的平台上，从 Intel 和 AMD 芯片到运行 IBM 处理器的电脑。Linux 将运行从最慢的 386 机器到地球上最大的主机。新版本的 Windows 无法在 Linux 相同数量的硬件上运行。

两个操作系统之间另一个显著的区别是 Windows 臭名的恶意代码问题，即病毒和间谍软件。病毒、间谍软件和泛缺乏安全性是 Windows 社区面临的最大问题。在 Windows 下，病毒和间谍软件能够在无需或很少用户输入的情况下自行执行。这使得防御它们成为任何 Windows 用户持续的担忧。”



Windows 用户被迫使用第三方杀毒软件，以帮助限制恶意代码导致计算机报废的可能。杀毒软件通常具有占用系统资源的负面影响，从而减慢整台电脑的速度；此外，大多数杀毒软件要求你支付订阅费用，并且你需要不断下载更新以防范入侵者。

相比之下，Linux 的病毒问题几乎不存在，事实上，你甚至不需要为 Linux 机器准备病毒防护。病毒和间谍软件对 Linux 不是问题，原因之一仅仅是因为为 Linux 开发的病毒要少得多。更重要的原因是，在 Linux 机器上运行病毒更加困难，并且需要用户提供更多的输入。在 Windows 上，你可能会通过打开邮件附件或双击包含恶意代码的文件无意运行并执行病毒。然而，在 Linux 中，病毒需要在终端中运行，这需要用户给文件赋予执行权限，然后在终端中打开它。

而且为了对系统造成任何实际破坏，用户必须以 root 身份登录，在运行病毒之前切换用户名和密码。例如，要运行嵌入在邮件附件中的病毒，用户必须：打开附件，然后保存它，然后右键点击文件并在菜单中选择“属性”，在属性中他们可以赋予其执行权限，然后他们就能在终端中打开文件来运行病毒。即便如此，用户也只能损坏自己的文件夹，所有其他用户将保持不受影响，所有 root 文件也将保持完好，因为 Linux 需要 root 密码才能对这些文件进行更改。

用户损坏整个电脑的唯一方法是向终端提供 root 用户名和密码以 root 身份登录。与 Windows 不同，Linux 中的可执行文件不会自动运行，必须手动赋予权限，这显著提高了安全性。在 Linux 中，你需要病毒防护的唯一理由是你与 Windows 用户共享文件，这样做是为了保护他们，以免无意中将病毒传递给你共享的 Windows 电脑。

以上是 Windows 操作系统和 Linux 之间某些差异的概概述。总结一下：Windows 只有一个供应商发布软件，而 Linux 则来自全球数百万个不同的代码。此外还提到了 Linux 内核以及与其一起的大部分应用程序都是完全免费的，而在 Windows 上，你被迫为大多数软件付费。与 Windows 不同，Linux 往往缺乏专业支持，Linux 用户通常需要自力解决技术问题。Linux 用户可以购买支持，也可以依靠互联网上提供的许多 Linux 论坛和群组。由于内核是开源的，Linux 在可配置性方面具有相对于 Windows 的巨大优势。你可以通过操纵内核配置 Linux 以按照你看到的任何方式运行。

Linux OS 确实更优的软件。除了一些微小的困扰外，Linux 在大多数类别中都优于 Windows。Linux 更安全这一事实是关键点，天平向 Linux 倾斜。Windows 在所有桌面环境中面临着更多的安全漏洞。

# 设置 Linux 硬盘分区

你可以使用大多数发行版的安装程序以及 `fdisk` 来设置和配置你的 Linux 分区。此外，作为 Linux 系统管理员，你还需要对现有 Linux 系统（在操作系统安装后）进行分区管理（创建、删除和修改）。为了实现这一点，你使用 `fdisk` 工具或 `parted` 命令——以及其他磁盘分区命令。Linux 有几种 Linux 硬盘分区类型，例如主分区、扩展分区和逻辑分区——对于使用这些分区类型也有严格的规则。

## Linux 主分区

Linux 安装程序中的磁盘分区工具和 `fdisk` 命令（以及其他分区命令）每个硬盘驱动器最多可以创建四个主分区（Primary partitions）。如果你需要四个以上的硬盘分区，你需要至少创建一个扩展分区（Extended partition），然后在扩展分区中创建一个或多个逻辑分区（Logical partitions）。要在已有四个主分区的硬盘上创建扩展分区，你需要删除其中一个主分区然后创建扩展分区。因此，如果你在 Linux 硬盘上创建扩展分区，你最多只能有三个主分区。

## Linux 扩展分区

Linux 硬盘在拥有扩展分区之前必须至少有一个主分区。`fdisk` 无法每个驱动器创建超过一个扩展分区。为了能够使用扩展分区中的磁盘空间，它必须至少有一个逻辑分区（在扩展分区内部）。

## 逻辑分区

扩展分区包含一个或多个逻辑分区。扩展分区是不被直接访问的。它是通过扩展分区内的一个或多个逻辑分区访问的。如果一个硬盘有一个扩展分区，那么它就至少有一个逻辑分区。

## 分区编号

`fdisk` 可以创建的主分区最大数量为四个，创建的扩展分区最大数量为一。记住，在使用最常用的分区工具 `fdisk` 之前，你必须至少有一个主分区。你可能可以使用其他磁盘实用程序打破这些规则。

# 如何使用 Linux 命令组件

Linux 命令 - 命令的伟大之处在于它们在不同发行版（版本）之间几乎是相同的。因此，真正的管理工作是在命令行中运行命令完成。对于 Linux 新手来说，学习如何运行 Linux 命令可能困难，因此这里有一些提示可以帮助你在命令行提示符工作时学习如何使用 Linux 命令。

一个 Linux 命令主要包含三个部分：

1. Linux 命令名
2. 可与 Linux 命令配合使用的选项
3. Linux 命令所运行的“项(item)”

当你运行 Linux 命令时，命令名、命令选项和命令所运行的“项”之间会使用空格。“项”可以是 Linux 目录、文件或其他软件组件。例如，你在目录上运行 Linux 命令 `ls`（用于 list）来查看目录中的文件列表。你在目录上运行 Linux 命令 `rm`（remove）来从 Linux 文件系统中删除该目录。要运行 Linux 命令，你输入命令名称以及命令的其他任何部分（如选项），并按下 Enter 键。你可以在下方看到创建新 Linux 用户的 Linux 命令示例。`useradd` 命令正在用户名 bthatcher 上运行以创建此 Linux 用户。

Linux 提示：Linux 命令在 Linux 命令行提示符运行，该提示符显示为命令左侧的 `#`。你不需要输入提示符，而是在提示符右侧输入 Linux 命令。

Linux 提示：Linux 命令提示符也可能显示为 `$` 或其他符号，而不是 `#` 或 `$`。

```
useradd -c "Becky Thatcher" bthatcher
```

这条 Linux 命令创建一个名为 bthatcher 的新 Linux 用户，全名为 "Becky Thatcher"。`-c`（用于 comment）选项在此命令中使用，用于将全名作为注释添加到 Linux 用户名 bthatcher 中。获取 Linux 培训最简单、最好的方法之一是在 Linux 视频教程中查看 Linux 命令的运行。通过这种方法——你可以看到、听到并实操。在 Linux 视频教程中，你可以看到并听到如何运行 Linux 命令，并看到和听到命令输出的描述。你可以学会自己运行命令！
