Part of the IP protocol, ICMP gets an IP header and adds its own header. Listing 3.2 shows a definition of the structure.

# LISTING 3.2 ICMP Structure Definition

```
/*** structure definition ***
/*** ICMP structure definition ***/
/*** Formal definition in netinet/ip_icmp.h */***/
typedef unsigned char u18;
typedef unsigned short int u16;

struct ICMP_header {
    u18 type;       /* Error type */
    u18 code;       /* Error code */
    u16 checksum;   /* Message checksum */
    uchar msg[1];   /* Additional data description */
};
```
