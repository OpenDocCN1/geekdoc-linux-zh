# Linux®

## Socket 编程

*Linux Socket 编程* 是您编写高性能 C 风格套接字所需的书籍。本书为另一位专业人士提供了从入门到精通的完整实用技巧，用于编写网络客户端、服务器和对等节点。学习如何编写客户端和服务器套接字，并在现有协议（HTTP）中工作或建立新协议。通过快速但可靠性较低的对等 UDP 通信来提高网络吞吐量。

TCP/IP 协议支持几种特定的消息类型，提供广泛的连接性和可靠性。选择合适的消息类型有助于您在性能和可靠性之间取得平衡。本书描述了每种类型（raw, ICMP, UDP 和 TCP）并介绍了其优缺点。此外，通过遵循某些编程实践，您可以从已建立的 IPv4 过渡到下一代 IPv6。

网络编程不仅限于套接字和协议。为了最大限度地利用应用程序，您应该考虑不同的多任务技术、服务器和 I/O 控制。此外，应用程序必须包括措施以确保网络安全，减少破解，并保护服务器上的宝贵数据。

本书还介绍了使用支持对象的编程语言（如 Java™ 和 C++™）进行套接字编程。Java 2.0 提供了几个用于处理套接字、I/O 和异常的类。

本书包括关于远程过程调用（RPC）、广播和多播以及安全套接字层（SSL）的章节。这些和其他章节将您的编程提升到新的水平，以解决更复杂的问题。
