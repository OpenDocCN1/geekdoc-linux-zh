Depending on the implementation of poll( ), your threads may have to time out frequently so that they can pick up any changes to the descriptor array. A few implementations simply cycle through testing each descriptor; others (more likely used in Linux) actually register the descriptors into a system call. The system call waits and reports on descriptor activity.

Therefore, if the parent adds a new descriptor, the thread must call poll( ) again to begin processing it.
