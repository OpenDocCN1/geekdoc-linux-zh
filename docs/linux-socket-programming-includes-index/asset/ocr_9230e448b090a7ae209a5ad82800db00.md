# Possible Errors

EBADF
The argument sd is not a valid descriptor.
ENOTSOCK
The argument sd is a file, not a socket.
ENOPROTOOPT
The option is unknown at the level indicated.
EFAULT
The address pointed to by optval is not in a valid part of the process address space.

# Example

```
const int TTL=128;
/*---Change the time-to-live to 1208 hops----*/
if ( setsockopt(sd, SOL_IP, SO_TTL, &TTL, sizeof(TTL)) != 0 )
    perror("setsockopt() failed");
```

# getsockopt()

Get the socket configuration.

# Prototype

```
#include <sys/types.h>
#include <sys/socket.h>
int getsockopt(int sd, int level, int optname, void *optval,
              socklen_t *optlen);
```

# Return Value

Zero if everything goes well. If an error occurs, you can find the cause in `errno`.

# Parameters

sd
The socket to read.
level
The feature level (SOL_SOCKET, SOL_IP, SOL_TCP, SOL_IPV6).
optname
The option to revise.
optval
Place for value.
optlen
The length of value in bytes. This field is passed by reference.
