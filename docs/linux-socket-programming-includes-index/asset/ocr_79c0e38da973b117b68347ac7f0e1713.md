== -1 Wait for any child process; this is the same behavior that
**wait()** exhibits.
== 0 Wait for any child process whose process group ID is
equal to that of the calling process.
> 0 Wait for the child whose process ID is equal to the value
of PID.

+   **options**
+   WNOHANG Return immediately if no child has exited.
+   WUNTRACED Return for children who are stopped and whose statu-
+   s has not been reported.

# **Possible Errors**

ECHILD If the process specified in PID does not exist or is not a child of
the calling process. (This can happen for one’s own child if the
action for **SIGCHLD** is set to **SIG_IGN**.)
EINVAL If the **options** argument was invalid.
EINTR If **WNOHANG** was not set and an unblocked signal or a **SIGCHLD** was
caught. Just try again.

# **Example**

```
void sig_child(int signum) /* This handler only gets one waiting zombie */
{
int status;
wait(&status);
if ( WIFEXITED(status) )
printf("Child exited with the value of %d\n", WEXITSTATUS(status));
if ( WIFSIGNALED(status) )
printf("Child aborted due to signal %d\n", WTERMSIG(status));
if ( WIFSTOPPED(status) )
printf("Child stopped on signal %d\n", WSTOPSIG(signal));
}

void sig_child(int signum) /* This handler removes all waiting zombies */
{
while ( waitpid(-1, 0, WNOHANG) > 0 );
}
```
