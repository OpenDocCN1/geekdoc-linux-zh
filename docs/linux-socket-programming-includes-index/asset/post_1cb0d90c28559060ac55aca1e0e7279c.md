
## Linux Socket Programming

### Master the concepts
- Network/distributed programming
- Networking clients, servers, and peers
- I/O control and multitasking
- Unicast, broadcast, and multicast messages
- Security and Secure Sockets Layer (SSL)

### Build the applications
- Clients and servers (simple, multitasked, and multithreaded)
- OpenSSL programs that connect to commercial products
- Tools that use Remote Procedure Calls (RPCs)
- Multicast and broadcast messengers

## Who Should Buy This Book

This book is intended for professionals, students, and experimenters who want to take programming beyond linear algorithms and multiprogramming and into network programs. With this book, you can write beginning- and advanced-level network clients, servers, and peers. This book explains essentials and techniques for effective and extensible programs that can use current or new technologies.

## What You Need to Use This Book

The book contains many code examples that illustrate the topics. Read the sections and try the programs. You will need to know how to do the following:
1. Create a C or Java source file (in whatever editor you desire)
2. Compile it using a C or Java compiler
3. Run the program

Some examples may require changing the kernel (broadcasting and multicasting). Most Linux distributions install and run the network even if you are not connected to a physical network. To run all programs in this book, you must:
- Be able to program and compile C, C++, and Java code
- Have all the compilers installed
- Be able to configure the kernel for networking, broadcasting, and multicasting
- Compile and install the new kernel

## After Reading This Book, You Will Be Able To
- Differentiate basic datagrams from streaming sockets
- Differentiate unicast, broadcast, and multicast sockets
- Write socket-based network programs
- Write portable code for various operating systems
- Implement client/server and peer communication
- Increase network throughput using connectionless communication
- Manage I/O, asynchronous I/O, and multiple sockets
- Use signals, threading, and processes to manage socket connections
- Understand new socket technologies like Mbone and 6bone
- Understand remote procedure calls and how to implement them
- Understand the different socket addressing types
