# ## Java Multicast-Specific Configurations

This section lists the options you can set on a `MulticastSocket` object. These functions determine how many router hops the socket allows before a packet should die.

The following methods expose the `IP_MULTICAST_TTL` socket option. (Strangely, Java does not let you specify the `TTL` for the other socket types.)
```java
getTimeToLive()
setTimeToLive(int ttl)
```

The next methods set the primary network interface for multicast transmissions by exposing the `IP_MULTICAST_IF` socket option.
