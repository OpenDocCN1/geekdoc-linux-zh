
## Linux 套接字编程

### 掌握核心概念
- 网络/分布式编程
- 网络客户端、服务器和对等节点
- I/O 控制与多任务处理
- 单播、组播和广播消息
- 安全与 Secure Sockets Layer (SSL)

### 构建应用程序
- 客户端和服务器（简单、多任务和多线程）
- 连接商业产品的 OpenSSL 程序
- 使用远程过程调用 (RPC) 的工具
- 组播和广播消息发送者

## 谁应该购买这本书

本书面向那些希望将编程从线性算法和多程序处理提升到网络程序领域的专业人士、学生和实验者。通过这本书，你可以编写初级和高级的网络客户端、服务器和对等节点。本书介绍了用于编写高效且可扩展的程序的关键要素和技术，这些程序可以支持当前或新的技术。

## 使用本书所需条件

书中包含许多阐明相关主题的代码示例。请阅读各章节并尝试运行这些程序。你需要知道如何执行以下操作：
1. 创建 C 或 Java 源文件（使用任意编辑器均可）
2. 使用 C 或 Java 编译器进行编译
3. 运行程序

一些示例可能需要修改内核（广播和组播）。大多数 Linux 发行版即使未连接到物理网络也会安装并运行网络服务。要运行本书中的所有程序，你必须：
- 能够编写和编译 C、C++ 和 Java 代码
- 安装所有必要的编译器
- 能够配置内核以支持网络、广播和组播
- 编译并安装新的内核

## 读完本书后，您将能够
- 区分基本的数据报流套接字和流套接字
- 区分单播、广播和组播套接字
- 编写基于套接字的网络程序
- 为各种操作系统编写可移植代码
- 实现客户端/服务器和对等通信
- 使用无连接通信增加网络吞吐量
- 管理 I/O、异步 I/O 和多个套接字
- 使用信号、线程和进程来管理套接字连接
- 理解新的套接字技术，如 Mbone 和 6bone
- 理解远程过程调用及其实现方法
- 理解不同的套接字寻址类型
