2: A[i] = store r0 (same as A[i + 1] in previous iteration) 
3: r0 = r1 + C (same as A[i + 2] in previous iteration) 
4: r1 = load A[i + 2] (not from any previous iterations)

Now there are no RAW dependencies and the loop will still work, because when i==0 4 will load A[2], when i==1 3 will add A[2], and when i==2 2 will store A[2].

The only problem is that the loop never loads A[0] and A[1], never adds A[0], never stores A[n-1] and A[n-2], and never adds A[n-1]. To solve this, add a prologue and epilogue to the loop:

# Prolog

+   1: r0 = load A[0]
2: r0 = r0 + C
3: r1 = load A[1]

# Main loop:

+   4: For i = 0 to n-3
5: A[i] = store r0
6: r0 = r1 + C
7: r1 = load A[i + 2]

# Epilog:

+   8: A[n-2] = store r0
9: r0 = r1 + C
10: A[n-1] = store r0
