# 5.3.4 Platform layer: Initializing the devices

This section describes device-specific functions in the platform layer.

**In Practice:**

Once the host has obtained handles to the platforms, it must obtain handles to the devices. Optionally it can query the devices for information.

The example code calls the `clGetDeviceIds()` and `clDeviceInfo()` to obtain handles to the devices associated with each platform.
