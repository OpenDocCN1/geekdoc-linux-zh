# 1.6 Assembly Optimization #1: Sorting 21

Recall that performance is impacted by many factors, including:

+   - number of instructions executed,
- stalls from data dependencies and branch mispredictions,
- data dependencies and resource constraints that prevent multiple-issue, and
- stalls from cache misses.

All of these factors, including the cache miss rate, can potentially be changed in a way that improves performance by changing the assembly code implementation of the algorithm.
