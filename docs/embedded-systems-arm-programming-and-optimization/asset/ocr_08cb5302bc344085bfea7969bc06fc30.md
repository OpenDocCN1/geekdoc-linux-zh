# C.10.7 Conversions

OpenCL supports C99-style typecasting, but also has conversion extensions to support saturation and rounding modes.

```
a = convert_T_R(b):    convert to type T with rounding mode R
a = convert_T_sat_R:   convert to type T with saturation and rounding mode R
```

where R is one of

+   * _rte (to nearest even)
* _rtz (toward zero)
* _rtp (toward + infinity)
* _rtn (toward - infinity)
