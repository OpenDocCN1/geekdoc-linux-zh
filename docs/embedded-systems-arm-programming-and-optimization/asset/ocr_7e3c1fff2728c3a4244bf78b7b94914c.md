A row filter is performed using

```
$O_{r,c} = \sum_{i=1}^{n} G_{l,r,c-|i|/2-1}$
```

...and a column filter is performed using

```
$O_{r,c} = \sum_{i=1}^{n} G_{l,r-|i|/2-1,c}$
```

Figure 4.2 shows these two passes. The dashed rectangle shows which input elements are used to compute each output. The shaded coloration shows which output elements have already been computed. The outputs from the row pass are used as inputs for the column pass, but one pass must complete before the next pass may begin. As such, the output elements need not be computed in any particular order.

This approach requires $n$ multiplies and $n$ adds per output pass, or $4n$ ops per output in total. This reduces the computational load from $2n^2$ to $4n$.
