# 1.13.1 Integer arithmetic instructions

Table 1.4 shows a list of integer arithmetic instructions. All of these support conditional execution, and all will update the status register with the S suffix specified. Some of these instructions—those with "operand2"—support the second operand as described earlier in this chapter. This allows these instructions to have either a register, a shifted register, or an immediate as second operand.

# 1.13.2 Bitwise logical instructions

Table 1.5 shows a list of bitwise logical instructions. All of these support conditional execution, all can update the flags when the S suffix is specified, and all support a flexible second operand.

# 1.13.3 Shift instructions

Table 1.6 shows a list of shift instructions. All of these support conditional execution, all can update the flags when the S suffix is specified, but note that these instructions do not support the flexible second operand.

| Instruction | Description | Function |
|---|---|---|
| ADCS|<cond> Rd, Rn, operand2 | Add with carry | R[Rd] = R[Rn] + operand2 + Cflag |
| ADDS|<cond> Rd, Rn, operand2 | Add | R[Rd] = R[Rn] + operand2 |
| MLA |<cond> Rd, Rn, Ra | Multiply-accumulate | R[Rd] = R[Rn] * R[Ra] |
| MULS|<cond> Rn, Rm | Multiply | R[Rd] = R[Rn] * R[Rm] |
| RSBS|<cond> Rd, Rn, operand2 | Reverse subtract | R[Rd] = operand2 - R[Rn] |
| RSCS|<cond> Rd, Rn, operand2 | Reverse subtract with carry | R[Rd] = operand2 - R[Rn] - (not C) |
| SBC|<cond> Rd, Rn, operand2 | Subtract with carry | R[Rd] = operand2 - R[Rn] - C |
| SMALS|<cond> RdLo, RdHi, Rn, Rm | Signed accumulate | R[RdHi] = upper32bits(R[Rn] * R[Rm]) + R[RdHi]
R[RdLo] = lower32bits(R[Rn] * R[Rm]) |
| SMULL|<cond> RdLo, RdHi, Rn, Rm | Signed multiply long | R[RdHi] = upper32bits(R[Rn] * R[Rm]) |
R[RdLo] = lower32bits(R[Rn] * R[Rm]) |
| SUB|<cond> Rd, Rn, operand2 | Subtract | R[Rd] = operand2 - R[Rn] |
| UMALS|<cond> RdLo, RdHi, Rn, Rm | Unsigned accumulate | R[RdHi] = upper32bits(R[Rn] * R[Rm]) + R[RdHi]
R[RdLo] = lower32bits(R[Rn] * R[Rm]) + R[RdLo] |
| UULL|<cond> RdLo, RdHi, Rn, Rm | Unsigned multiply long | R[RdHi] = upper32bits(R[Rn] * R[Rm]) |
R[RdLo] = lower32bits(R[Rn] * R[Rm]) |
