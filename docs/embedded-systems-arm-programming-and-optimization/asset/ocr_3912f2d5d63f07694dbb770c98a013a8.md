Enqueues a command to map a region of the buffer given by the host address space and returns a pointer to this mapped region.

This function allows an array in host memory and an array in device memory to be linked, such that updates to one array update the other.

```
cl_int clRetainMemObject (cl_mem memobj);
```

Increments the memory object reference count.

This function prevents an OpenCL buffer from being deleted by the runtime.

```
cl_int clReleaseMemObject (cl_mem memobj);
```

Decrements the memory object reference count.

This function is typically called during program cleanup to free all OpenCL buffers.
