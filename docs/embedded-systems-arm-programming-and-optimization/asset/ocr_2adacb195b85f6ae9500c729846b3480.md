Webcams may also use a technique to reduce the number of bits required for each pixel. Of these techniques, YUYV is a variation on YUV that stores the chroma information at half the resolution of the luminance. This reduces the average number of bits per pixel from 24 bits (assuming 8-bit values for Y, U, and V) to 16 bits per pixel.

As shown in Figure-4.17, in this format there is a luminance for each pixel, but there is only one chromance value for every two horizontally adjacent pixels.
