# 5.4 Kernel Workload Distribution 221

Since the code enabled profiling support when creating the command queue,
t OpenCL runtime will return the kernel's execution time (note that thenhost code also uses its own timing to):

```
ret = clGetEventProfilingInfo(horner,
CL_PROFILING_COMMAND_START,
sizeof(cl_ulong),&start_t,
&return_size);
CHECK_STATUS(ret);
ret = clGetEventProfilingInfo(horner,
CL_PROFILING_COMMAND_END,
sizeof(cl_ulong),&end_t,
&return_size);
CHECK_STATUS(ret);
float runtime = (float)(end_t - start_t) / 1.0e9;
```

The kernel must retrieve the output array of the kernel using
EnqueueReadBuffer() for validation using a CPU-based verification
routine as in Chapter 2 (the verify() function is also shown in
Section 5.5.1).

Notice the third argument to clEnqueueReadBuffer, blocking_read,
is is set to CL_TRUE to prevent the function from returning until the copy
completes.

```
ret = clEnqueueReadBuffer(queue,outputBuffer,CL_TRUE,
0,N,d,0,0,0);
```

CHECK_STATUS(ret);
