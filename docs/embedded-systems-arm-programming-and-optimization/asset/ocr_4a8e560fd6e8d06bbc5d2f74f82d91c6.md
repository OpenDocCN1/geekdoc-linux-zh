# 3.6.6 Efficient fixed-point multiplication

Unlike addition and subtraction, any two-point values (n1,m1) and
(n2,m2) can be multiplied without first aligning the radix point, the
multi will position the product's radix point to bit m1+m2. In order
to repositioning the product's radix point at bit m1 or m2, the program must
perform adjustments to the product.

adjusted *prior* to performing the operation while in multiplication the
