As such, the programmer must choose the group size (WGS), number of workgroups (NWG), and kernel vector size (VS).

5.2 shows how of these parameters affects the hierarchical way the workload associated with the input data is subdivided among the work items.

The top of the figure shows x, the input array. The array is evenly divided into each of the workgroups, which themselves are divided into work items. Each work item can optionally process input elements using vector operations and/or a for-loop.

The number of iterations performed by the for-loop is a function of the values N, WGS, NWG, and VS. In other words, if N/4 < NWG × WGS × VS, then the for-loop within the work-items balances the out load by looping through N/(4 × NWG × WGS × VS) iterations.
