# C.6 Command Queue Functions 283

Enqueues a wait for a specific event or a list of events to complete before any future commands queued in the command-queue are executed. [OpenCL 1.1 only]

This synchronization primitive prevents any commands queued after this primitive to wait until all the specified events have triggered.

```
cl_int clEnqueueMarkerWithWaitList(
    cl_command_queue command_queue,
    cl_uint num_events_in_wait_list,
    cl_event *event_wait_list,
    cl_event *event)
```

Enqueues a marker which waits for either a list of events to complete, or all previously enqueued commands to complete. [OpenCL 1.2 ONLY]

This synchronization primitive triggers and ever after all specified events have triggered.

```
cl_int clEnqueueBarrierWithWaitList(
    cl_command_queue command_queue,
    cl_uint num_events_in_wait_list,
    cl_event *event_wait_list,
    cl_event *event)
```

A synchronization point that enqueues a barrier operation. [OpenCL 1.2 ONLY]

This function prevents any commands enqueued afterward from executing until either all previously enqueued commands completed or all the specified events have triggered. This synchronization can also trigger its own event.
