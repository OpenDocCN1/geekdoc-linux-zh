In order to avoid data dependencies, this implementation will maintain two versions of each operand: the original value and the shifted and rounded version. To support this, the code begins by copying the operand values to register r1 and r2.

```
asm("mov r1,[op1val]\n\t\
```

```
mov r2,[op2val]\n\t\
```

Subtract the radix positions and the difference in register r0.

```
sub r0,[rp1val],[rp2val]\n\t
```

Right-shift operand 1 by the difference in radix points. From this point on, r1 will be the shifted version of operand 1.

Refer to %[opval] as the original value of operand 1, which substitutes for another register holding the original value.

Instead of using the flexible second, use the stand-alone instruction to shift operand 1, but also use the s-suffix. This way, the bit shifted out will be stored in the carryout (c) flag, for rounding later. Note that this flag is not written when the shift amount is zero, so the code must account for this possibility.

```
asrs r1,r1,r0\n\t
```

Add 1 to the shifted value if the c-flag is set.

```
addhs r1,r1.#1\n\t
```

Subtract the radix positions in reverse order and store the result in r0.

```
sub r0,[rp2val],[rp1val]\n\t
```

Shift the original value of operand 2 and round if necessary. This version of operand 2 will now reside in register r2.

```
asrs r2,r2,r0\n\t
```

```
addhs r2,r2.#1\n\t
```

Now subtract the radix positions again to reset the flags.

```
subs r0,[rp1val],[rp2val]\n\t
```
