Get specific information about the OpenCL platform.

This function retrieves information regarding the available platform(s), such as the version of OpenCL and set of extensions supported. This is most useful for writing portable OpenCL applications, allowing the application to adapt to the capabilities of the available platforms.

This function retrieve device handle(s). Every OpenCL application must call this function in order to access a device.
