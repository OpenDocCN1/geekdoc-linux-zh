This can be performed with the following loop nest:

```
for (i=2;i>=0;i--) {
    for (j=i+1;j<4;j++) {
        coeff = -a[i*4+j]/a[j*4+j];
        for (k=0;k<4;k++) {
            b[i*4+k]+=coeff * b[j*4+k];
            a[i*4+k]+=coeff * a[j*4+k];
        }
    }
}
```

Again the innermost loop can be replaced with two NEON intrinsics:

```
*((float32x4_t*)(&b2[i*4])) = =
    vmlaq_f32*((float32x4_t*)(&b2[i*4])),
    *((float32x4_t*)(&b2[j*4])),
    vdupq_n_f32(coeff));

*((float32x4_t*)(&a2[i*4])) = =
    vmlaq_f32*((float32x4_t*)(&a2[i*4])),
    *((float32x4_t*)(&a2[j*4])),
    vdupq_n_f32(coeff));
```

As a final step, divide each row by its diagonal value to complete the transformation into the identity matrix:

+   1. set element (0,0) to one R0--R0/A_{0,0}
2. set element (1,1) to one R1--R1/A_{1,1}
3. set element (2,2) to one R2--R2/A_{2,2}
4. set element (3,3) to one R3--R3/A_{3,3}
