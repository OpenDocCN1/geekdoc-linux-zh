|---|---|--|

| MSR(<cond> SPSR_<fields>, Rm | Move one's complement | |

# Table 1.8 ARM Load and Store Instructions

| Instruction | Description | Functionality |
|---|---|--|
| LDM(cond)< address mode > Rn(!), <reg list in braces > | Load multiple | Loads multiple registers from consecutive words at R[Rn]
Bang (!) will autoincrement base register
Address:
IA = increment after
IB = increment before
DA = decrement after
DB = decrement before
Example:
LDMIA r2, (r3,5-r7)|
DR(cond)[B|H][SB][SH] Rd, <address> | Load register | Loads from memory to Rd.
Optional size specifiers:
B = byte
H = halfword
SB = signed
SH = signed
STM(cond)< address mode > Rn, <registers> | Store multiple | Stores multiple registers
Bang (!) will autoincrement base register
Address:
IA = increment after
IB = increment before
DA = decrement after
DB = decrement before
Example:
STMIA r2, (r3,5-r7)|
STR(cond){B|H} Rd, <address> | Store register | Stores from memory to Rd.
Optional size specifiers:
B = byte
H = halfword
SWP(cond)< B> Rd, Rm, [Rn] | Swap | Swap a word (or byte) between registers and memory |
