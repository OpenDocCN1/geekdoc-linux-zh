In order to verify the correctness of the implementation, the program must compare results of the optimized code with the original C implementation. When verifying floating-point code should not expect the results to match bit-for-bit due to differences in rounding error between different assembly implementations. Instead of checking for equivalence, make the results differ by no more than 1%:
