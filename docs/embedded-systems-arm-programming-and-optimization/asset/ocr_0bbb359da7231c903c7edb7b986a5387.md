Returns information about the kernel object that may be specific to a device.

The kernel compiler is able to determine from the kernel source information such as its maximum workgroup size and local memory size. For example, the register requirement of a kernel may prevent it from executing with the device's maximum workgroup size. This function allows the platform layer to determine this information prior to having set the execution parameters such as workgroup size.

# C.6 COMMAND QUEUE FUNCTIONS

The OpenCL command queue is the method by which the host controls the device(s). The host can use the command queue to send simple, in-order commands to the device, or it can configure the command queue as being an out-of-order queue, which allows it to construct complex task graphs.

A task graph is comprised of nodes representing kernels, and uses events to control when each kernel executes according to the data dependencies defined by the graph's arcs.

The command queue can contain commands, which execute code or exchange data with buffers. Commands are kernels, tasks, native kernels, read buffers, or write buffers.
