# OpenCL reference

This appendix provides a reference for the most common features of OpenCL versions 1.1 and 1.2. These are older versions of OpenCL but are the most likely to be supported on embedded GPUs at the time of this writing.

Annotations throughout the appendix note any differences between OpenCL versions 1.1 and 1.2 where appropriate.

**This appendix is intended only as a quick reference; it provides only a brief summary of the relevant information.** For a more thorough description of any feature, the reader should refer to the official OpenCL documentation.

Much of this information is from Chronos Group OpenCL documentation, available at the Chronos Group website at https://www.khronos.org.

# C.1 PLATFORM LAYER

The platform layer includes a set of functions called by the host to query coprocessor communications and instantiate communication channels to the device, called contexts. This section lists the most commonly used of these.

```
cl_int clGetPlatformIDs (cl_uint num_entries,

cl_platform_id *platform_ids,

cl_uint *num_platforms);
```

Obtain the list of platforms available.

*This function retrieves the number of available platforms (if platforms is NULL) or retrieves handles to the actual platforms themselves (if num_platforms contains a value or NULL).*
