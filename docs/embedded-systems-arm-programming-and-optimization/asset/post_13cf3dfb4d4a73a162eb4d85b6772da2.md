src_pixel array remember that each pixel at location (x,y) is stored at pixel location (y × cols + x) since getting to rows requires that the skip-down rows each of size cols, but this value must be multiplied by 3 to reach the byte offset. This gives us:

- (y × cols + x) × 3 for the red channel
- (y × cols + x) × 3 + 1 for the green channel
- (y × cols + x) × 3 + 2 for the blue channel

Declare three 4-element integer arrays for each color channel, that is, r[4], g[4], b[4]. The three-color channels of the four pixels around the source pixel can be extracted using the following code:

```
r[0] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1])*3];ng[0] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1])*3+1];nb[0] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1])*3+2];nr[1] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1]+1)*3];ng[1] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1]+1)*3+1];nb[1] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1]+1)*3+2];nr[2] = src_image((src_pixel_int[0]+1)*cols+src_pixel_int[1])*3];ng[2] = src_image((src_pixel_int[0]+1)*cols+src_pixel_int[1])*3+1];nb[2] = src_image((src_pixel_int[0]+1)*cols+src_pixel_int[1])*3+2];
```

The framebuffer is organized in a similar way to our image but it will likely be larger than our image. However, the pixels will not necessarily consist of 24-bits. To check, you can use the "fbset" tool at the command line.

## 3.5 Analysis of Floating-Point Performance

The last value on the right line indicates the color depth. In our case it is 16-bits. The fourth line displays the format of each pixel, in which the red value is 5 bits starting at offset 11 (spanning bits 15 down to 11), the green value is 6 bits starting at offset 5 (spanning bits 10 down to 5), the blue value is 5 bits starting at offset 0 (spanning bits 4 down to 0), and the alpha (transparency) value uses 24- or 32-bit color you can change to 16 bits using the fbset command with superuser credentials (see the main page for details).

To paint the interpolated value to the framebuffer, calculate the pixel offset in the framebuffer while simultaneously converting the 24-bit pixel to a 16-bit pixel. Each 8-bit color channel can be converted into a 5- or 6-bit value by shifting to the right. The resulting value must be shifted to the left according to the offsets defined by the framebuffer:

```
((unsigned short *) (fbp + i*row_size + j*2)) = (red >> 3 << 5) | (green >> 2 << 5) | (blue >> 3));
```

Finally, recall that this code is executed only if the source pixel corresponding to the destination pixel being considered falls within the boundaries of the original image. Otherwise write a black (zero) pixel.

```
*((unsigned short *) (fbp + i*row_size + j*2)) = 0;
```

Applications such as this are typically concerned with maximizing the number of frames (or pixels) per second. This metric is affected by the number of executed instructions per pixel, average cycles per instruction (CPI) the number of floating operations per second (flops), and the cache miss rate.

To measure each of these metrics you can use the performance monitoring code from Chapter 1 and customize the cnts_dump() function.
