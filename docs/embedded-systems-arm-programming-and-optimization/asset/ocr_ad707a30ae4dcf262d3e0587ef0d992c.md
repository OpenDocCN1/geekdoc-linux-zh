# Using Performance Counters with Linux Perf_Event

This chapter introduced a methodology for runtime profiling through code instrumentation to measure key system performance metrics, such as instruction and memory throughput. The Linux Perf_Event functionality provides this ability without needing to drive a custom kernel module.

Looking forward, Chapter 2 uses a specific floating-point subroutine as a running case study on how to use assembly-level code optimizations to substantially improve performance. Chapter 2 will also describe how to use performance counters to gain more insight into program behavior and how it relates to processor performance.
