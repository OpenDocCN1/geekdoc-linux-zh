# 1.13.4 Movement instructions

Table 1.7 shows a list of data movement instructions. Most useful of these is the MOV instruction, since its flexible second operand allows for loading immediates and register shifting.

# 1.13.5 Load and store instructions

Table 1.8 shows a list of load and store instructions. The LDR/STR instructions are ARM's bread-and-butter load and store instructions. The memory address can be specified using any of the modes described earlier in this chapter.

The LDR instruction can also be used to load symbols into base registers, e.g. `ldr r1,=data`.

The LDM and STM instructions can load and store multiple registers and are often used for accessing the stack.
