# B.2 READING AND WRITING VECTOR VARIABLES

There are several methods for reading and writing NEON vector variables outside of the intrinsics. The simplest way is to treat them as any standard C array.

For example:

+   * Initialize on declaration:
int8x8_t a=(0,0,2,2,4,4,6,6);
