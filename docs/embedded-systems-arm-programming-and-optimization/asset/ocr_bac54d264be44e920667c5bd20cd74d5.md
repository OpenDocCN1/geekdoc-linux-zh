Our objective is to generate a video consisting of a sequence of frames depicting the image smoothly rotating around all three axes. Graphically, this will appear as a 2D image rotating in 3D space.

To do this, gradually change the X, Y, and Z rotation of the image in each frame. For this program need to call a function before each frame that computes the transformation matrix for a given X, Y, and Z rotation angles. Since this function is called once per frame (as opposed to once per pixel), it is reasonable to expect it to have a negligible effect on performance.
