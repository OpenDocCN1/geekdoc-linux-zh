src_pixel array remember that each pixel at location (x,y) is stored at pixel location (y × cols + x) since getting to rows requires that the skip-down rows each of size cols, but this value must be multiplied by 3 to reach the byte offset. This gives us:

(y × cols + x) × 3 for the red channel
(y × cols + x) × 3 + 1 for the green channel
(y × cols + x) × 3 + 2 for the blue channel

Declare three 4-element integer arrays for each color channel, that is, r[4], g[4], b[4]. The three-color channels of the four pixels around the source pixel can be extracted using the following code:

```
r[0] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1])*3];ng[0] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1])*3+1];nb[0] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1])*3+2];nr[1] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1]+1])*3];ng[1] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1]+1])*3+1];nb[1] = src_image[(src_pixel_int[0]*cols+src_pixel_int[1]+1])*3+2];nr[2] = src_image((src_pixel_int[0]+1)*cols+src_pixel_int[1])*3];ng[2] = src_image((src_pixel_int[0]+1)*cols+src_pixel_int[1])*3+1];nb[2] = src_image((src_pixel_int[0]+1)*cols+src_pixel_int[1])*3+2];
```
