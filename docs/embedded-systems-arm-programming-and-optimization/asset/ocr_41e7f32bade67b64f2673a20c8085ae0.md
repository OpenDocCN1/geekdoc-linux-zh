# Table 1.2 ARM Memory Addressing Modes

| Example Instruction | Effective Address Calculation |
|---|--|
| 1dr r0, [r1] | address = R[r1] |
| 1dr r0, [r1], #4] | address = R[r1] + 4 |
| 1dr r0, [r1], #4]! | preincrement:
address = R[r1] + 4
R[r1] = R[r1] + 4
postincrement:
address = R[r1]
R[r1] = R[r1] + 4
address = R[r1] + R[r2] |
| 1dr r0, [r1, r2] | |
| 1dr r0, [r1, r2, #4] | address = R[r1] + R[r2] × 4 |
| 1dr r0, [r1, r2, lsl1 #2] | address = R[r1] + R[r2] × 4
(shift the address left 2 bits) |
| 1dr r0, [pc, #8192] | address = R[PC] + 8192 |

1drh/strh load/store halfword (16 bits)
1drsb load signed byte (8 bits)
1dsrb/strb load/store byte (8 bits)

Load and store instructions can also be conditional. For example, 1dreq only loads if the z flag is set.

The memory address is specified using register in square brackets. An optional constant offset, index register, and scaling factor can be specified. ARM also supports auto-incrementing of registers.
