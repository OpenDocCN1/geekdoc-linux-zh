# 2.10.2 ARM Cortex NEON instructions

ARM Cortex processors support SIMD floating point with NEON instructions. NEON instruction mnemonics begins with the letter V. When compiling with NEON instructions, make sure you use the “-compile withmfpu-neon” GCC compiler flag.

To support SIMD NEON instructions, ARM increased the number of overlapping 64-bit d-registers to 32 and added a new set of 16 overlapped 128-bit registers q0-q15 that each overlaps a pair of d-registers.

Like VFP, there are still only 32-3bit s-registers and 16 64-bit d-registers for use with scalar single- and double-precision instructions. The extended set of d-registers and new set of q-registers are only usable for NEON SIMD instructions.
