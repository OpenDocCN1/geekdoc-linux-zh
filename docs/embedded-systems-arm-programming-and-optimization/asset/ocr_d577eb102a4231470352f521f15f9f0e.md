# 1.13 Basic ARM Instruction Set

In order to describe floating point and single instruction, multiple data (SIMD) programming techniques that are applicable to both the ARM11 and ARM Cortex processors, this section and Chapter 2 will cover both VFP and NEON instructions.

Table 1.11 lists the VFP and NEON versions of commonly used floating-point instructions, like the integer arithmetic instructions, support conditional execution, but there is a separate set of flags for floating-point instructions located in the 32-bit floating-point status and control register (FPSCR), NEON instructions use only bits 31 down to 27 of this register, while VFP instructions use additional fields.

# Table 1.11 Floating-Point Instructions

| VFP Instruction | Equivalent NEON Instruction | Description |
| --- | --- | --- |
| FADD[S|D](cond) Fd, Fm | VADD[F32:64] Fd, Fm | Single and double precision add |
| FSUB[S|D](cond) Fd, Fm | VSUB[F32:64] Fd, Fm | Single and double precision subtract |
| FMUL[S|D](cond) Fd, Fm | VMUL[F32:64] Fd, Fm | Single and double precision multiply-and-negate |
| FNUL[S|D](cond) Fd, Fm | VMNUL[F32:64] Fd, Fm | Single and double precision square root |
| FDIV[S|D](cond) Fd, Fm | VDIV[F32:64] Fd, Fm | Single and double precision division |
| FABS[S|D](cond) Fd, Fm | VABS[F32:64] Fd, Fm | Single and double precision absolute value |
| FNEG[S|D](cond) Fd, Fm | VNEG[F32:64] Fd, Fm | Single and double precision negate |
| FSQRT[S|D](cond) Fd, Fm | VSQRT[F32:64] Fd, Fm | Single and double precision precision |
| FCVTS[S|D](cond) Fd, Fm | VCVT[F32:64] Fd, VCVT[S|D][32][16], #fbits | Convert double precision to single precision |
| FCVTDS[S|D](cond) Fd, Fm | VCVT[F32:64] Fd, Fm, VCVT[S|U][32][16], #fbits | Convert single precision to fixed point |
| FMAC[S|D](cond) Fd, Fm | VMLA[F32:64] Fd, Fm | Single and double precision floating point multiply-accumatively, calculates Rd= Rm * Fm + Fn |

| FLD[S|D](cond) Fd, <address> | VLDR Rd, <address> | Single and double precision floating point load/store |
| FST[S|D](cond) Fd, <address> | LSTR Rd, <address> | Single and double precision floating point load/store |
| FLDM[S|D](cond) <address>, <<FPRegs> | VLDM Rn(l), <FPRegs> | Single and double precision floating point load/store |
| FSTM[S|D](cond) <address>, <<FPRegs> | VSTM Rn(l), <FPRegs> | Single and double precision floating point load/store |
| FMRX(cond) Rd | FMRX Rd | Move from/floating point status and control register |
| FMRR(cond) Rm | FMR Rm | |
| FCPY[S|D](cond) Fd, Fm | VMOV(cond) Fd, Fm | Copy floating point register |
