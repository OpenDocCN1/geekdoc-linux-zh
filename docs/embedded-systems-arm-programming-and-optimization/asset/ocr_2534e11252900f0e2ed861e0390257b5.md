# 3.8.2 Zooming in

When rendering each frame of the Mandelbrot set, the program should maintain the c-value of the nonmember point requiring the greatest of evaluations before disqualification. This point can serve as the central point when zooming, referred to as the target point, (target,target).

The program will begin by plotting the entire Mandelbrot set (often initially in the range $-2.5 \leq x < 1.0, -1 \leq y < 1$) and then zoom in a closer look at a target point within each frame. This produces a visually appealing sequence video.

Our first challenge is to develop a method to determine the c-value for each pixel given a specified zoom level.

Establish variables to keep track of the minimum and maximum values for the $X$- and $Y$-axes. This way, the frame area is discretized at regular intervals.

This way, for a given frame $(x_{min},x_{max}), (y_{min},y_{max})$, the $x$ and $y$ values for any (row,col) is computed as

```
$$
c_{real} = x = \frac{col}{pixels_{width}} \cdot (x_{max} - x_{min}) + x_{min}\nc_{imag} = y = \frac{pixels_{height} - 1}{pixels_{height}} \cdot (y_{max} - y_{min})$$\$$
```

The range of values in each dimension are determined by the center point $(target_x,target_y)$, the aspect ratio, the zoom level, and the room rate.
