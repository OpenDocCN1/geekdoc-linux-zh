Use bitwise AND operation to extract the fractional portion of src_pixel. To extract the m bits from some value, perform a bitwise-AND with 2^m-:

```
frac[0] = src_pixel[0] & (FRAC_SIG-1); // (32, FRACBITS)
frac[1] = src_pixel[1] & (FRAC_SIG-1);
```

When calculating the weights, subtract the fractional point of each source pixel location from 1. Since it must be expressed in the fixed-point format as the fractional values computed (32,m) produces the defined value for 2^m. Multiplying two (32,m) produces a (32,2) product.

```
weights[0] = (FRAC_SIG-frac[0]) * (FRAC_SIG-frac[1]); // (32,2x
// FRACBITS)

weights[1] = (FRAC_SIG-frac[0]) * (frac[1]);
weights[2] = (frac[0]) * (FRAC_SIG-frac[1]);
weights[3] = (frac[0]) * (frac[1]);
```
