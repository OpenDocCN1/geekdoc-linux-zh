### 4.3.2 The Sobel filter

Conceptually, a grayscale image can be represented as a function $I(x,y)$, which evaluates to the pixel intensity at pixel location $(x,y)$. Many computer vision tasks require, as input, the partial derivatives of the image, that is, $\partial(x,y)/\partial x$, $\partial(x,y)/\partial y$ in the X and Y direction. These partial derivatives are often abbreviated as $I_x(x,y)$ and $I_y(x,y)$. The Sobel filter is a popular method to calculate these partial derivatives.

### 4.3.3 The Harris corner detector

Some computer vision applications require a method for identifying anchor points in an image for the purpose of establishing correspondence between multiple images taken of the same scene from different perspectives. This is useful for video tracking, image stitching, and 3D modeling.

One way to identify anchor points is to find corners, an intersection of at least two edges. More generally, a corner is any point on the image whose patch, or square subregion centered on the point, would change significantly if the patch area shifted in any direction.

This is depicted in Figure 4.7.

These are many methods for detecting corners in an image. One of the most commonly used is the Harris detector. The Harris detector looks for pixels that has a large "shift difference" when shifted by (u,v):

```
$E(u,v) = \sum_{x,y} w(x,y)|I(x+u,y+v) - I(x,y)|^2$
```

$I$ represents the image, and $w$ represents the weights of the pixels in the patch.

This section examines a simple case where the weights are set to all ones. As such this term is dropped from the equation.

![](img/e6ebc663bbb86c6e7bf9ef22ad13e66f_159_0.png)

**FIGURE 4.7** Two candidate pixels evaluated for their suitability as corners. The pixel on the left is near an edge and its corresponding patch would only change with a horizontal or diagonal movement. The pixel on the right is located on a corner, and its corresponding patch would change the patch significantly for any movement.

Despite the ready availability of the pixel values $I()$, the Harris detector is normally evaluated as the first-order Taylor expansion of the above expression:

$$E(u, v) = \sum_{x,y} [I(x+u, y+v) - I(x, y)]^2$$

$$= \sum_{x,y} [I(x,y) + u I_x(x,y) + v I_y(x,y) - I(x,y)]^2$$

where $I_x$ and $I_y$ are the partial derivatives of $I$ with respect to $x$ and $y$.

The Harris response matrix $M$ is defined as:

$$M = \sum_{x,y} w(x,y) \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix}$$

The corner response $R$ is given by:

$$R = \det(M) - k(\text{trace}(M))^2$$

where $k$ is a constant typically between 0.04 and 0.06. If $R$ is large, the point is a corner. If $R$ is small but the trace is large, it is an edge. If both are small, it is a flat region.
