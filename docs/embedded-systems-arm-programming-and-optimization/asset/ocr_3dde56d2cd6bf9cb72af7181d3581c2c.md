# 4.11 APPLYING THE SEPARATED 2D TILED FILTER

When processing a separated 2D filter using a 1D row pass followed by a 1D column filter pass, you must make sure the halo region pixels passed to the second pass reflect the updates generated by the first pass in the tiles above, below, to the left, and to the right of the current tile.

The easiest way to guarantee this is to process the image using the row filter before applying the column filter. However, since all tiles must be processed by one pass before the second pass, this will cause a long delay between the row pass writes its pixels and when the column reads the same pixels. We leave the details of this implementation as an exercise.
