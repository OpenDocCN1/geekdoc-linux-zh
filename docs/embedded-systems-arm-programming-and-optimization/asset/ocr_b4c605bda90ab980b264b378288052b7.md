# 4.3.2 The Sobel filter

Conceptually, a grayscale image can be represented as a function I(x,y), which evaluates to the pixel intensity at pixel location (x,y). Many computer vision tasks require, as input, the partial derivatives of the image, that is, ∂(x,y)/∂x, ∂(x,y)/dy in the X and Y direction. These partial derivatives are often abbreviated as I_x(x,y) and I_y(x,y). The Sobel filter is a popular method to calculate these partial derivatives.
