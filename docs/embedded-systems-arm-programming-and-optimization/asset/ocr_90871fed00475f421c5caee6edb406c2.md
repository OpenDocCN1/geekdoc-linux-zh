The efficiency is the ratio of actual performance and the resulting performance bound. This efficiency is determined by the overheads in the generated assembly code (in terms of instructions per flop), the instruction and data cache miss rate, and cycles per instruction (CPI), which is largely determined by memory performance and stalls caused by data dependencies.
