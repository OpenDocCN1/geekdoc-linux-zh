The problem is described using linear algebra as shown below:

Let

```
$A = \begin{bmatrix} I_x(x-1, y-1) & I_y(x-1, y-1) \ I_x(x, y-1) & I_y(x, y-1) \end{bmatrix}$
```

and

```
$b = \begin{bmatrix} -I_y(x-1, y-1) \ -I_x(x, y-1) \end{bmatrix}$
```

Then:

```
$\begin{bmatrix} v_x \ v_y \ v_y \end{bmatrix} = b$\n$\begin{bmatrix} v_x \ v_y \ v_y \end{bmatrix} = A^{-1}A^T b$\n$\begin{bmatrix} v_x \ v_y \ v_y \end{bmatrix} = \left(\sum \begin{bmatrix} I_x(x,y)^2 & I_x(x,y)I_y(x,y) \ I_y(x,y)I_x(x,y) & I_y(x,y)^2 \end{bmatrix}\right)^{-1}A^T b$
```

The inverse of a $2 \times 2$ matrix is computable. $A^T$ is a $2 \times n$ matrix and $b$ is an $n \times 1$ vector, so $A^T b$ evaluates to a $2 \times 1$ vector.

This simple version of optical flow is another example of a memory bounded stencil loop.
