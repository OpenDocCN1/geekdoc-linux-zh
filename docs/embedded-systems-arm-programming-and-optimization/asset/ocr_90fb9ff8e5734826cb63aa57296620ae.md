Enqueues a command to execute a kernel on a device.

This function is the same as clEnqueueNDRangeKernel() but only executes one work-item, i.e., equivalent to calling clEnqueueNDRangeKernel() with work_dim=1, global_work_offset=NULL, global_work_size[0] set to 1, and local_work_size[0] set to 1.

```
cl_int clEnqueueNativeKernel(cl_command_queue command_queue,
void (*user_func)(void *),
void *args, size_t cb_args,
cl_uint num_mem_objects,
const cl_mem *mem_list,
const void **args_mem_loc,
cl_uint num_events_in_wait_list,
const cl_event *event_wait_list,
cl_event *event)
```
