Enqueue commands to write to a buffer object from host memory.
The name of this function can potentially be confusing. "Write" is from the perspective of the host, so this function is normally applied to an input array of the kernel. In other words, the programmer refers to the output array as a write buffer, since it is written by the host prior to being sent to the device.
