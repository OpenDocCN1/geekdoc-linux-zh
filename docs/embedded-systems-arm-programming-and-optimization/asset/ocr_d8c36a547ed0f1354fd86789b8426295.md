# C.6 Command Queue Functions 279

cl_int clRetainCommandQueue (cl_command_queue command_queue)

Increments the command_queue reference count.

This function prevents a command queue from being de-allocated by the runtime.

cl_int clReleaseCommandQueue (cl_command_queue command_queue)

Decrements the command_queue reference count.

This function is typically used in the program's "cleanup" code to de-allocate a command queue.
