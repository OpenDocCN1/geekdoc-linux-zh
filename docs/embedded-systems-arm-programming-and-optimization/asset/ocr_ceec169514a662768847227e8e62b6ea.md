When converting from a single grayscale value to RGB, the program can assign the grayscale value to all three color components.

Each pixel value is stored as a normalized value in the range [0,1], so the program can separately compute the red, green, and blue values by multiplying against their maximum value and converting back to integer. In 16-bit RGB, maximum value for red is 31 and for green is 63.
