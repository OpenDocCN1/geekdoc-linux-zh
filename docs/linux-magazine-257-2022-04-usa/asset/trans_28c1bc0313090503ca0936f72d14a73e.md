```
01 #!/usr/bin/python3
02 import time
03 import struct
04
05 DEBUG = False
06
07 DMX1_MASTER = 525
08 DMX1_RED = 526
09 DMX1_GREEN = 527
10 DMX1_BLUE = 528
11
12 DMX2_MASTER = 533
13 DMX2_RED = 534
14 DMX2_GREEN = 535
15 DMX2_BLUE = 536
16
17 class RevPi:
18     _rev_pi = open('/dev/piControl0', 'wbr+', 0)
19
20    def _init_(self):
21        pass
22
23 class DMX(RevPi):
24    _green = 0
25    _red = 255
26    _blue = 0
27
28    def _init_(self, master, adr_green, adr_red, adr_blue):
29        self.adr_green = adr_green
30        self.adr_red = adr_red
31        self.adr_blue = adr_blue
32        self._rev_pi.seek(master)
33        self._rev_pi.write(struct.pack('<H', 255))
34
35    def update_color(self, adr, val):
36        self._rev_pi.seek(adr)
37        self._rev_pi.write(struct.pack('<H', val))
38
39    def set_step(self, mode_val):
40        if mode_val == 1:
41            self._green += 16
42        elif mode_val == 2:
43            self._red += -16
44        elif mode_val == 3:
45            self._blue += 16
46        elif mode_val == 4:
47            self._green += -16
48        elif mode_val == 5:
49            self._red += 16
50        elif mode_val == 6:
51            self._blue += -16
52
53    def do_green(self):
54        if DEBUG:
55            print('GREEN: %d' % self._green)
56        self.update_color(self.adr_green, self._green)
57
58    def do_red(self):
59        if DEBUG:
60            print('RED: %d' % self._red)
61        self.update_color(self.adr_red, self._red)
62
63    def do_blue(self):
64        if DEBUG:
65            print('BLUE: %d' % self._blue)
66        self.update_color(self.adr_blue, self._blue)
67
68 DMX_1 = DMX(DMX1_MASTER, DMX1_GREEN, DMX1_RED, DMX1_BLUE)
69 DMX_2 = DMX(DMX2_MASTER, DMX2_GREEN, DMX2_RED, DMX2_BLUE)
70
71 while 1:
72    for mode in range(1, 7):
73        if DEBUG:
74            print('mode=%d' % mode)
75        for i in range(0, 15):
76            if DEBUG:
77                print('i=%d' % i)
78            DMX_1.set_step(mode)
79            DMX_2.set_step(mode)
80            DMX_1.do_red()
81            DMX_2.do_red()
82            DMX_1.do_green()
83            DMX_2.do_green()
84            DMX_1.do_blue()
85            DMX_2.do_blue()
86            time.sleep(0.05)
```

同样可以使用偏移量来访问 DMX 地址。列表 2 利用了这一功能再次关闭灯具。原则上，你可以使用一些 Shell 脚本技巧来自动控制灯光，但由于 Shell 编程并非人人擅长，我将在下一节中介绍如何使用 Python 脚本控制 DMX 灯具。

## 程序

Python 脚本（列表 3）首先加载所有需要的库。接下来的代码块为偏移量创建了一些变量和常量。如前几节所示，RevPi Core 上的值可以通过其纯文本名称或偏移量来访问。

借助 `fcntl` 库，可以设计该脚本以在后台确定偏移量并以此替代纯文本名称。此处的脚本通过使用偏移量直接访问，避免了这种复杂的流程。由于示例中这些值始终递增 1，你不需要通过试错法来确定所有值。使用纯文本名称的代码示例可以在 Kunbus 主页上找到 [5]。

两个类（第 17 行和第 23 行）建立与 RevPi 的连接（`RevPi`）并控制灯光的颜色变化（`DMX`）。`open()` 命令允许你打开与硬件驱动程序的连接，并将其存储在 `_rev_pi` 变量中。然后，所有对硬件的访问都将通过该变量进行。

在 `DMX` 类中，`do_<color>` 方法使用 `update_color()` 语句确保将适当的颜色发送到灯具。颜色由 `set_step()` 方法计算，并由 `mode_val` 变量控制。由于灯具只能处理比较粗糙的调光，每种颜色的值始终递增或递减 16。两盏灯和三种颜色允许六种可能的颜色过渡，这就是为什么当 `mode` 变量达到 7 时立即重置为 1 的原因（第 72 行）。`time.sleep(0.05)` 命令控制颜色过渡的速度。`DMX` 类的 `__init__` 方法将主调光器设置为 100%，以充分利用每种颜色的调光器。`while 1` 命令告诉程序在无限循环中运行，你可以使用 Ctrl + C 键盘组合取消它。在此循环中，代码更改变量 `mode` 并将其传递给两个灯具对象，打开或关闭特定颜色。当颜色达到其新值时，`mode` 变量递增 1。要完全循环一次颜色过渡，你需要调用 `set_step()` 方法 16 次，如第二个 for 循环所示（第 75 行）。你可以通过以下命令启动演示程序

```
python3 dmx_demo.py
```

在 RevPi Core 的命令提示符下。你可以在 YouTube 上找到一个展示演示程序运行效果的视频 [6]。

### 结论

`DMX` 模块让创建自己的灯光秀变得轻而易举。在 Internet 上浏览一番就会发现许多可以通过 DMX 控制的有趣设备。除了经典的舞台灯光外，产品还涵盖家庭自动化的照明系统。在 DMX 设备中，一个真正的亮点是一个会移动、会说话的头骨 [7]。祝你享受自己的 DMX 实验。
