## Subplots and Extra Axes

You can combine different plots into one Matplotlib Figure, add Axis elements, and link them to each other using the techniques in Listing 7.

Using more or less the same syntax shown in the previous examples, Listing 7 creates three distinct functions: a parabola (lines 5 and 8), a normal sinuoid (line 11), and a growing sinuoid (line 13). What is new is that these plots are grouped into two subplots (shown in Figure 5), whose Axis objects are indeed linked to each other. A full explanation of the code is beyond the scope of this article, but here are the main points you need to understand to create similar charts.

Line 7 splits the main Figure into two subplots, each with its own Axes, called ax1 and ax3. Then, the first subplot gets the ax2 of line 9, which is a 'twin' of the ax1 of line 8, for a very precise purpose: to show the very different scales of both the parabola and the sinuoid separately, but as clearly as possible, on opposite sides of the subplot. Meanwhile, the growing sinusoid is plotted in the right subplot, with its own labels and titles, but also using another feature of Matplotlib (line 16): the `secondary_xaxis` method creates an extra horizontal Axis (ax4) at the top of that subplot that shows the same variable as the bottom Axis (ax3) but with a different unit (radians instead of degrees).

### Listing 5: Plotting Data from a CSV File

```python
import Matplotlib.pyplot as plt
import csv

x = []
y = []

with open('csv-data.csv', 'r') as csvfile:
    plots = csv.reader(csvfile, delimiter=',')

for row in plots:
    x.append(row[0])
    y.append(int(row[1]))

plt.bar(x, y, color='g', width=0.72, label='Age')
plt.xlabel('Names')
plt.ylabel('Ages')
plt.title('Customers ages')
plt.legend()
plt.savefig('03-csv.png')
plt.show()
```

### Listing 7: Connecting Subplots

```python
import Matplotlib.pyplot as plt
import NumPy as np

t = np.arange(0.0, 40.0, 0.8)
s = t**2 #parabola

fig, (ax1, ax3) = plt.subplots(1, 2, figsize=(12, 5))

11, = ax1.plot(t, s)
ax2 = ax1.twinx()
12, = ax2.plot(t, np.cos(-1*t/2), 'C1')
ax2.legend([11, 12], ['Parabola (left)', 'Sinusoid (right)'])

ax3.plot(t, 20 - t*np.sin(20 - t))
ax3.set_xlabel('Angle [°]')

ax4 = ax3.secondary_xaxis('top', functions=(np.rad2deg, np.deg2rad))
ax4.set_xlabel('Angle [rad]')

plt.savefig('extra-axes.png')
```

### Adding Text in Plots

You already know how to add legends to charts, but what about other text, maybe in nonstandard parts of a plot? Listing 8 shows the simplest way to add the captions and annotations shown in Figure 6.

Lines 11 and 13 of Listing 8 describe the function that generates the "local maximum" annotation shown in Figure 6. This syntax is relatively simple to describe: `plt.annotate` takes as arguments the string to insert, its starting position (`xytext`), the point where the arrow should end (`xy`), and its style (`arrowprops`). In line 11, `plt.text` has even fewer arguments: just the coordinates where a string should be inserted and preceded by an r suffix, which means that what follows is "raw" text that uses LaTeX syntax and symbols (e.g., `\mu` and `\sigma`).

Also note that in these strings blank spaces must be escaped to tell Python that they are actual spaces that should just be printed instead of separators of function arguments.
