
# Linux 初学者指南 - 分步操作指南

## 引言

我想感谢并祝贺你下载了《Linux 操作系统》。这本书包含了关于如何运行 Linux 以获得真实体验的验证步骤和策略、获取系统管理命令的 Linux 书籍，以及在 Windows 上安装 Linux 等你在目录中看到的更多内容。听到 Linux 这个词时不要皱眉。它像 Windows 一样用户友好。

它是一个可以下载的免费操作系统，但你必须支付少量的费用来订购或从公司购买。Linux 诞生于 22 年前——它是由芬兰 Linux 之友（Linux Tords）与开源软件运动的一组程序员共同开发的。

Linux 一年一年都在稳步增长。在充满热情的社区支持下，在 IBM 和 HP 等大公司的支持下，难怪 Linux——这一曾经属于服务器的奇迹操作系统也进入了如今的桌面。

Linux 基于 Unix。大多数用户熟悉 Windows，但 Linux 可能有所不同。然而，它是强大且免费的。在本书中，我将引导你了解 Linux 的基础，让你习惯。

## 关于 Linux 的迷思

### 安装：

Linux 安装很难，对吗？其实并不难。大多数人也没有安装过 Windows——因为它是预装的。Linux 和 Windows 一样易于安装。你可以通过图形化界面安装它。如今的 Linux 版本比 Windows 更容易安装。但困扰大多数人的是在硬盘的第二个分区上安装 Linux，当他们想要同时使用两个操作系统时。

分区是组织硬盘空间的一种方式，通过创建相互独立的虚拟区域来实现。大多数运行 Windows 或 MS DOS 的计算机只有一个巨大的操作系统空间。这个空间就是 C 盘。如果你有一个大硬盘，它可能被分成了较小的分区。这些分区通常被称为 D:、E: 等，你可以在任何分区上安装 Linux。

Windows 98 在整个硬盘上创建 FAT32 文件系统，DOS 和 Win95 使用 FAT16。Linux 有许多文件系统，最流行的是 ext3。但你也可以在 Fat32 分区上安装 Linux。

你会觉得自己像在 Windows 中工作一样！GNOME 和 KDE 是这些系统中最流行的。GNOME 代表 GNU 网络模型环境（GNU Network Model Environment），KDE 代表 K 桌面环境。它们拥有允许拖放操作的工具，拥有面板和任务栏——几乎就像 Windows 的克隆。

### 硬件兼容性问题以及在 Linux 上运行的少数应用程序

嗯，大多数新发行版都能在短时间内检测并配置你的硬件，除非你拥有一些非常老旧或奇特的硬件。所有硬件都能被正确检测并安装驱动程序。只有由 Windows 驱动程序驱动的现代 Windows 系统才会遇到问题。

至于软件，有非常多。而且其中大部分都是免费提供给你，你可以根据自己的需要进行使用、修改和配置。几乎所有优秀的 Linux 软件都是免费的，你尝试一下也不会损失任何东西。你可以在网络上快速获得你可能有的任何查询的免费支持。你甚至不需要删掉 Windows。只需将 Linux 安装在不同的硬盘分区上，并根据你的意愿在它们之间切换即可。

其他软件包是商业性的，你必须购买软件——但这主要是是为了软件以及对你的培训，而不是为了软件本身。有时，如果你有 Windows 版本（作为一种保险），你可以下载一个小型程序，允许你在 Linux 中运行该游戏。Linux 中的游戏质量非常高且功能强大。你会喜欢它们的。这里有：

- 办公套件：`Star Office`, `Open Office`, `Appixware`, `Corel WordPerfect`
- 图形：`GIMP`, `Corel Photo pear`
- 音乐：`XMMS`, `Free amp`, `Real Player`
- 视频：`MTV`, `Xine`
- 游戏：`FreeCiv`, `Tux racer`, `Doom`, `Quake`, `Heretic`, `Unreal`，列表仍在不断增长。

### 适用于家庭用户的 Linux 种类：

既然有这么多人在开发它，很可能也有很多 Linux 版本。许多致力于 Linux 的公司都开发了所谓的 Linux 发行版（Linux distributions）。有些 Linux 版本是经过编译、打包并附带额外软件释放的。

- **`RedHat` (红帽)**：可能是最流行且在许多方面处于领先的版本。它目前是第 9 版本。安装和配置非常简单。蓝色的文件管理器和默认的 `GNOME` 桌面看起来非常惊艳。它有一系列工具，可以作为服务器和工作站使用。由红帽开发的红帽软件包管理器 (`RPM`) 格式几乎已经成为 Linux 世界软件分发的标准。安装新软件轻而易举。它还有一个先进且易用的字体管理系统，使得 `X Windows` 中的字体看起来非常漂亮。

- **`Mandrake Linux`**：现在是第 10 代。它可以使用 `Lin4Win` 工具安装在原生 Windows 分区上，这可能会减慢机器速度。它还允许你在自己的分区中进行传统的 Linux 安装。`Mandrake` 的配置和软件安装是非常轻松的。它遵循一种略微修改的 `RPM` 架构，称为 `mdk.rpm`，但大多数红帽软件也可以用于 `Mandrake`。该版本的显著特征是窗口管理器集合——视觉狂热者会度过一段极快的时光。

- **`SUSE` (苏萨)**：来自德国的“变色龙”`SUSE`。现在处于 8.x 版本，它拥有编译最全面的软件包集合之一，通过 `yast`（Yet Another Software Tool，又一个软件工具）可以轻松获取它们，`yast` 提供了一个集中式界面，你可以在从中选择要安装的软件。除外，`SUSE` 还带有一些惊艳的 3D 游戏，展示了 Linux 的游戏实力。

- **`Corel/Xandross`**：几年前带着 `Core Linux` 进入了 Linux 市场。现在它已合并为基于 `Core Linux` 的 `Xandross OS`。这是一个 `Debian` 类型的版本，在调整 Windows 分区大小后可以无需费力地安装。`Xandross` 包含了 `Crossover office`，这是 `WINE` 的精简零售版，你可以在其中安装并运行许多微软应用程序。

### Linux 中的 Windows 应用程序

某些应用程序已经移植到 Linux，另一些通过一个名为 `WINE` 的程序运行（`Wine` 并不是模拟器）。`Crossover` 这种商用可用软件也允许你在 Linux 上使用你的 Windows 程序。`VMware` 是另一个允许你在 Linux 上运行 Windows 的程序。现在许多软件公司开始为 Linux 开发高级软件。Linux 的酷炫之处在于大多数软件都是免费的，你可以合法盗版地使用它们。如果你担心 Linux 不像 Windows 那么漂亮，只需查看一些有趣的 Linux 界面和窗口管理器。如果你有一台运行两者的电脑，就可以轻松地在它们之间切换，获得两者的优点。

### Linux 与 Windows 的区别

本主题将讨论 Linux 和 Windows 之间的区别，我们将讨论每个系统的优缺点。

让我们先从 Linux 系统的通用概览开始。Linux 在最基本的形式是一个计算机内核（`Kernel`）。内核是用于与硬件和其他系统通信的底层计算机代码，它运行计算机的所有基本功能。

Linux 内核是一个运行在各种硬件和各种用途上的操作系统。Linux 能够运行在如手表或手机等简单设备上，也可以运行在家用电脑（例如 `Intel` 或 `AMD` 处理器），甚至运行在使用 `Sun` CPU 或 `IBM` PC 处理器的高端服务器上。某些 Linux 发行版只能运行一个处理器，而另一些可以同时运行多个。

Linux 的常见用途包括家庭计算系统，或者更常见的服务器应用程序，例如作为 Web 服务器或邮件服务器。你可以将 Linux 作为专用的防火墙来帮助保护同一网络上的其他机器。

使用命令行提示符的优点是它消耗系统资源较少，并让计算机将更多精力放在当前任务上。命令示例包括用于更改目录的 `cd` 命令、用于关闭系统的 `halt` 命令以及用于重启电脑的 `reboot` 命令。

现在我们对 Linux 操作系统有了了了解，可以注意到 Linux 与世界上最流行的操作系统——微软 Windows 之间的许多不同。从现在开始，我们将讨论 Linux 与 Windows 之间的一些最显著的不同。

首先，只有一家公司发布 Windows 操作系统，那就是微软。所有的 Windows 版本，无论是 `Windows XP` 家庭版、商业版还是 `Vista` 版，其所有更新、安全补丁和服务补丁均来自微软。相比之下，Linux 并不是由某一家公司发布的。

Linux 全范围内有数百万编码者和公司投入时间开发更新、新版本和软件应用程序。尽管有些公司对技术支持收费，另一些公司则对他们的 Linux 发行版收费，但通过将其与非免费软件打包，你始终可以免费获得 Linux 内核，并且可以免费获得带有所有通用所需应用程序的全功能 Linux 桌面。那些对 Linux 发行版收费的供应商也必须根据 `GPL` 许可协议发布免费版本。而微软 Windows 则需要你向微软支付软件费用，你还必须为你使用的大多数应用程序付费。



Windows 和 Linux 在技术支持问题上也有不同。Windows 由微软公司支持，这意味着如果你的任何产品出现问题，该公司应该负责解决。例如，如果微软 `Windows` 无法运行，你应该能够拨打微软并利用他们的技术支持来修复问题。技术支持通常在购买产品时包含在一段时间内（也许是两年），此后你可能需要支付服务费。尽管 `IBM` 支持他们的 `Linux` 产品，但对于大多数使用 `Linux` 的人来说，你需要自力更生。如果你在 `Ubuntu` `Linux` 上遇到问题，你无法致电 `Ubuntu` 并获得任何帮助。尽管缺乏专业帮助，你仍然可以从网络上的成千上万个 `Linux` 论坛获得良好的技术建议。你还可以通过 `Myspace` 等社交网络网站，通过在许多 `Linux` 群组中提问来获得巨大的帮助。你通常可以在几小时内收到专业人士对你问题的回复。

可配置性是这两个操作系统之间的另一个关键区别。尽管 `Windows` 提供了控制面板帮助用户按照喜好配置计算机，但它无法比 `Linux` 提供的配置选项，特别是如果你是一个精通的编码者。在 `Linux` 中，内核是开源的，因此如果你拥有相关知识，你可以以任何你认为合适的方式对其进行修改。此外，`Linux` 还提供了多种图形环境，如 `KDE` 这样的全功能图形环境，或者更轻量级、节省资源的 `GUI`（如 `Fluxbox` 或 `Blackbox`），以适应其他计算机的用户。还有一些 `Linux` 版本旨在尽可能地模拟 `Windows` 的外观和感受。像 `Linspire` 这样的发行版最适合从 `Windows` 世界迁移过来的用户。

还有一些完全不包含图形环境的发行版，以更好地适用于需要为各种计算活动榨出所有计算能力的用户，以及那些比他人更高级的用户。所有这些可配置性有时可能会带来问题，因为你必须决定哪个桌面最适合你，而且为了让操作变得更简单，你还需要安装与你的发行版和图形环境原生的应用程序。

(ref #1) `Linux` 的性价比是它区别于 `Windows` 的另一种方式。对于家庭使用，`Linux` 非常廉价，且在大多数情况下是完全免费的，而 `Windows` 的成本取决于你使用的版本。对于 `Linux`，大多数应用程序也将是免费的，但对于 `Windows`，在大多数情况下你必须为应用程序付费。对于大多数情况，使用 `Linux` 在安装时不需要输入产品激活密钥，你可以随心所欲地在许多计算机上安装。而 `Windows` 只允许在一台计算机上安装，`微软` 使用产品激活软件来执行这一规则。

在安装 `Windows` 时，你必须输入产品激活密钥，该密钥在多次使用后过期。如果你愿意，可以从各种供应商处购买 `Linux`，这将包含一套盒装光盘、手册以及大约 40-130 美元的技术支持。当然，如果你购买用于服务器的高端 `Linux` 版本，可能可能花费 400-2000 美元。

使用由 `CodeWeavers` 开发的 `Over Office` 软件来替代 `Adobe` `Creative` 套件。与其使用这些应用程序，你将使用 `Linux` 应用，例如 `OpenOffice`、`Gimp` 图像编辑器、`Thunderbird` 邮件客户端。你可以使用 `GAIM` 聊天软件代替 `MSN` `Messenger`，并可以使用 `Firefox` 作为你的网络浏览器。

此外，在 `Linux` 上即使软件是为 `Linux` 开发的，安装起来也可能困难。这是因为 `Linux` 有许多不同的版本。在某个版本上开发的软件可能在另一个版本上安装时需要进行某些配置。例如，如果你尝试在 `GNOME` `GUI` 上安装为 `KDE` 图形界面环境开发的软件，该程序将无法在 `GNOME` `GUI` 上轻松安装，并且需要你亲自进行一些配置才能成功安装。

`Linux` 和 `Windows` 运行的硬件类型也导致了它们的不同。`Linux` 可以运行在许多不同的硬件平台上，从 `Intel` 和 `AMD` 芯片到运行 `IBM` `Power` 处理器的计算机。`Linux` 可以在从最慢的 386 机器到地球上最大的大型主机上运行，而较新版本的 `Windows` 运行的硬件范围并没有 `Linux` 相同。`Linux` 可以配置为运行在苹果设备、`iPod` 或智能手机上。`Linux` 的一个缺点是在使用打印机、扫描仪或数码相机等硬件设备时。

虽然这些设备的驱动软件在 `Windows` 上通常很容易获得，但在 `Linux` 上，你大部分时候只能靠自己寻找这些设备的驱动程序。大多数 `Linux` 用户会感到安慰，因为世界各程序员正在不断为最新硬件编写驱动程序，并且通常会很快发布。

(ref #1) 这两个操作系统之间最显著的区别之一是 `Windows` 在恶意代码方面的臭名问题，即病毒和间谍软件。病毒、间谍软件以及通用安全性的缺乏是 `Windows` 社区面临的最大问题。在 `Windows` 下，病毒和间谍软件能够在几乎没有或完全没有用户输入的情况下自执行。这使得防御它们成为任何 `Windows` 用户长久以来的的担忧。

`Windows` 用户被迫使用第三方杀毒软件来帮助限制计算机被恶意代码变得无用的可能性。杀毒软件通常具有占用系统资源的负面影响，会减慢整台电脑的速度；此外，杀毒软件还需要你支付订阅费用，并要求你不断下载更新以领先入侵者。

相比之下，`Linux` 的病毒问题几乎不存在，实际上，你的 `Linux` 机器不需要病毒防护。病毒和间谍软件对 `Linux` 来说不是问题的一个原因仅仅是因为为 `Linux` 开发的病毒要少得多。更重要的原因是是在 `Linux` 机器上运行病毒要困难得多，并且对用户的要求更高。在 `Windows` 上，你可能会通过打开邮件附件或双击包含恶意代码的文件无意运行并执行病毒。然而在 `Linux` 上，病毒需要用户执行文件权限操作，然后在终端中打开它。

为了对系统造成任何实际破坏，用户必须在运行病毒之前以 `root` 身份登录，输入用户名和密码。

例如，要运行嵌入在邮件附件中的病毒，用户必须：打开附件，保存它，然后右键点击文件并从菜单中选择“属性”，在属性中他们可以赋予其执行权限，他们将能够在终端中打开文件来运行病毒。然后用户只能损坏他自己或他的家目录，所有其他用户的数据都将保持完好，所有 `root` 系统文件也将保持完好，因为 `Linux` 修改这些文件需要 `root` 密码。

用户能够损坏整台电脑的唯一方法是他们在运行病毒之前，通过终端提供 `root` 用户名和密码以 `root` 身份登录。与 `Windows` 不同，`Linux` 中的可执行文件不能自动运行，它需要手动赋予执行权限，这显著提高了安全性。在 `Linux` 中，你需要病毒防护的唯一现实理由是你与 `Windows` 用户共享文件，那是为了保护他们而不是你，以免无意中将病毒传递给与你共享文件的 `Windows` 计算机。

### 1. 记录你的 Linux 安装设置

### 3. 指定你的 Linux 安装设置

### 4. 创建普通（“非 root”）用户

你以 Linux “用户”的身份登录并在 Linux 系统上工作，拥有用户名和密码。你可以以“root”用户身份，也可以以“非 root”用户身份登录。

当你安装 Linux 时，系统总是会自动创建 `root` 用户用于执行 Linux 系统管理任务。然而，出于安全考虑，你永远不要以 `root` 用户身份登录 Linux 桌面。

在安装过程的某个时刻，系统会询问你是否想再创建一个“普通”（非 `root`）Linux 用户。请务必至少创建一个普通 Linux 用户，并使用该用户处理日常任务。

### 5. 让 Linux OS 安装在硬盘上

在指定 Linux 安装设置并创建一个或多个新 Linux 用户后，安装程序会将 Linux OS 和 Linux 软件程序复制到系统的硬盘上，然后重启。

### 6. 登录并测试系统

系统重启后，以“普通”（非 `root`）Linux 用户身份登录，测试你是否可以以此用户身份工作。此时，Linux 桌面会出现，你可以运行 Linux 程序来测试系统。

# 如何使用 Linux 命令行组件

Linux 命令 - Linux 命令的伟大之处在于它们从一个 Linux 发行版（版本）到另一个几乎是相同的。因此，真正的专业人士进行 Linux 管理的方法是在 Linux 命令行中工作并运行 Linux 命令。

对于 Linux 新手来说，学习如何运行 Linux 命令可能非常困难，因此这里有一些 Linux 技巧可以帮助你在操作 Linux 提示符时学习如何使用 Linux 命令。

一个 Linux 命令由三个主要部分组成：

1. Linux 命令名
2. 可以与 Linux 命令配合使用的选项（`Options`）
3. Linux 命令运行的“项目(项)”

当你运行 Linux 命令时，Linux 命令名、命令选项和所运行的“项目”之间使用空格。该“项目”可以是 Linux 目录、文件、用户或其他 Linux 软件组件。

例如，你运行名为 `ls`（list，列出）的 Linux 命令，“作用于”Linux 目录以查看目录中的文件列表。你运行名为 `rm`（remove，删除）的 Linux 命令，“作用于”Linux 目录以从 Linux 文件系统中删除该目录。
