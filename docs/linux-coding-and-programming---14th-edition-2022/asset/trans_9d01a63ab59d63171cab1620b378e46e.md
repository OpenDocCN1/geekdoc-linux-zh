

## 命令行快速参考

### 有用的帮助/信息命令

以下命令在你想要了解正在 Linux 中操作的系统或程序时非常有用。你可能不需要每天都使用它们，但当需要时，它们会非常有价值。

![](img/d501697c83491ed0bb4b382b0d28ef0a_80_0.png)

**free**
`free` 命令显示系统中已用和空闲的物理内存及交换内存的总量。例如，`free -m` 以兆字节为单位提供信息。

**sed**
`sed` 命令打开一个流编辑器。流编辑器用于对输入流（文件或管道输入）执行文本转换。

**df**
`df` 命令显示所有分区的文件系统磁盘空间使用情况。`df -h` 命令可能最有用（-h 表示人类可读格式）。

**adduser**
`adduser` 命令向系统添加新用户。类似地，`addgroup` 命令向系统添加新组。

**top**
`top` 程序提供运行中系统的动态实时视图。它可以显示系统摘要信息以及进程列表。

**deluser**
`deluser` 命令从系统中移除用户。若要移除用户的文件及主目录，你需要添加 `--remove-home` 选项。

**uname -a**
带 `-a` 选项的 `uname` 命令打印所有系统信息，包括机器名称、内核名称、版本和其他一些细节。

**delgroup**
`delgroup` 命令从系统中移除组。无法移除任何用户的 primary 组（主要组）。

**ps**
`ps` 命令允许你查看机器上正在运行的所有进程。每个操作系统的 `ps` 版本略有不同，但它们的作用相同。

**man man**
`man man` 命令显示 `man` 命令的手册条目，这是使用该命令的一个很好的起点。

**grep**
`grep` 命令允许你在多个文件中搜索特定的搜索模式，然后打印匹配的行。示例如下：`grep blah file`。

**man intro**
`man intro` 命令特别有用。它显示“用户命令简介”，这是一篇写得很好且相当简明的 Linux 命令行介绍。

## Linux 命令 A-Z 索引

Linux 命令有成千上万种，虽然这不是一份完整的 A-Z 列表，但它确实包含了你最可能需要的大多数命令。你可能会发现，最终你反复使用的是一小部分命令，但拥有整体知识仍然非常有用。

- **adduser**：添加新用户
- **arch**：打印机器架构
- **awk**：在文件内查找和替换文本
- **bc**：任意精度计算器语言
- **cat**：连接文件并在标准输出上打印
- **cd**：更改工作目录
- **chgrp**：更改文件的组所有权
- **chroot**：更改根目录
- **cksum**：打印 CRC 校验和及字节计数
- **cmp**：比较两个文件
- **comm**：逐行比较两个已排序的文件
- **cp**：将一个或多个文件复制到另一个位置
- **crontab**：安排命令在稍后时间运行
- **csplit**：将文件分割为上下文决定的片段
- **cut**：将文件分成几部分
- **date**：显示或更改日期和时间
- **dc**：桌面计算器
- **dd**：数据转储，转换并复制文件
- **diff**：显示两个文件之间的差异
- **dirname**：将完整路径名转换为仅路径
- **du**：估算文件空间使用量
- **echo**：在屏幕上显示消息
- **ed**：面向行的文本编辑器（edit）
- **egrep**：搜索匹配扩展表达式的文件行
- **env**：显示、设置或删除环境变量
- **expand**：将制表符转换为空格
- **expr**：计算表达式
- **factor**：打印质因数
- **fdisk**：Linux 分区表操作工具
- **fgrep**：搜索匹配固定字符串的文件行
- **find**：搜索符合预期标准的文件
- **fmt**：重新格式化段落文本
- **fold**：将文本折叠以适应指定宽度
- **format**：格式化磁盘或磁带
- **fsck**：文件系统一致性检查和修复
- **gawk**：在文件内查找和替换文本
- **grep**：搜索匹配给定模式的文件行
- **groups**：打印用户所属的组名
- **gzip**：压缩或解压缩指定文件
- **head**：输出文件的开头部分
- **hostname**：打印或设置系统名称
- **id**：打印用户和组 id
- **info**：帮助信息
- **install**：复制文件并设置属性
- **join**：基于公共字段连接行
- **kill**：停止进程运行
- **less**：一次显示一屏输出
- **ln**：在文件之间创建链接
- **locate**：查找文件

### M

- **man**：查看帮助手册
- **mkdir**：创建新文件夹
- **mkfifo**：创建 FIFO（命名管道）
- **mknod**：创建块或字符特殊文件
- **more**：一次显示一屏输出
- **mount**：挂载文件系统

### N

- **nice**：设置命令或作业的优先级
- **nl**：给行编号并写入文件
- **nohup**：运行对挂断信号免疫的命令

### P

- **passwd**：修改用户密码
- **paste**：合并文件行
- **patchck**：检查文件名可移植性
- **pr**：将文本文件转换为打印格式
- **printcap**：打印机功能数据库
- **printenv**：打印环境变量
- **printf**：格式化并打印数据

### Q

- **quota**：显示磁盘使用量和限制
- **quotacheck**：扫描文件系统以查找磁盘使用情况
- **quotactl**：设置磁盘配额

### R

- **ram**：RAM 磁盘设备
- **rcp**：在两台机器之间复制文件
- **rm**：删除文件
- **rmdir**：删除文件夹
- **rpm**：移除包管理器
- **rsync**：远程文件复制（同步文件树）

### S

- **screen**：终端窗口管理器
- **sdiff**：交互式合并两个文件
- **select**：接受键盘输入
- **seq**：打印数字序列
- **shutdown**：关闭或重启 Linux
- **sleep**：延迟指定时间
- **sort**：排序文本文件
- **split**：将文件分割为固定大小的片段
- **su**：替代用户身份
- **sum**：为文件打印校验和
- **symlink**：为文件创建新名称
- **sync**：同步磁盘与内存中的数据

### T

- **tac**：反向连接并写入文件
- **tail**：输出文件的末尾部分
- **tar**：磁带归档器
- **tee**：将输出重定向到多个文件
- **test**：计算条件表达式
- **time**：测量程序资源使用
- **touch**：更改文件时间戳
- **top**：列出系统上正在运行的进程
- **traceroute**：追踪到主机的路由
- **tr**：转换、压缩或删除字符
- **tsort**：拓扑排序

### U

- **umount**：卸载设备
- **unexpand**：将空格转换为制表符
- **uniq**：去重文件
- **units**：将一个尺度的单位转换为另一个尺度
- **unshar**：解压 shell 归档脚本
- **useradd**：创建新用户账户
- **usermod**：修改用户账户
- **users**：列出当前登录的用户

### V

- **vdtr**：详细列出目录内容（'ls -4B'）

### W

- **watch**：定期执行或显示程序
- **wc**：打印字节、单词和行计数
- **whereis**：报告命令的所有已知实例
- **which**：在用户路径中定位程序文件
- **who**：打印所有当前登录的用户名
- **whoami**：打印当前用户 id 和名称

### X

- **xargs**：执行实用程序，传递构造的参数列表

### Y

- **yes**：打印字符串直到中断
