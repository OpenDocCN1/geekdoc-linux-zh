**STEP 6**

**STEP 7**
In the Terminal, go to the Downloads folder by entering `cd Downloads`. Then unzip the contents of the downloaded Python source code with `tar -xvf Python-3.Y.Y.tar.xz` replacing the Y’s with the version numbers you downloaded. Now enter the newly unzipped folder with `cd Python-3.Y.Y`.

```bash
david@david-Mint:~$ tar -xvf Python-3.7.2
david@david-Mint:~$ cd Python-3.7.2
```

**STEP 8**
Within the Python folder, enter:

```bash
./configure
$ sudo make install
```

This could take a while depending on the speed of your computer. Once finished, enter `python3.7 --version` to check the installed latest version. You now have Python 3.7 installed, alongside either Python 3.x.x and Python 2.

# Starting Python for the First Time

We're going to be using the Raspberry Pi as our Python 3 hardware platform. The latest version of Raspbian comes preinstalled with Python 3, version 3.4.2 to be exact, so as long as you have a version 3 Shell, all our code will work.

### STARTING PYTHON

We're not going to go into the details of getting the Raspberry Pi up and running, there's plenty of material already available on that subject. However, once you're ready, fire up your Pi and get ready for coding.

- **STEP 1** With the Raspbian desktop loaded, click on the Menu button followed by Programming > Python 3 (IDLE). This opens the Python 3 Shell. Windows and Mac users can find the Python 3 IDLE Shell from within the Windows Start button menu and via Finder.

- **STEP 2** The Shell is where you can enter code and see the responses and output of code you've programmed into Python. This is a kind of sandbox, where you're able to try out some simple code and processes.

![](img/d501697c83491ed0bb4b382b0d28ef0a_91_0.png)

![](img/d501697c83491ed0bb4b382b0d28ef0a_91_1.png)

- **STEP 3** For example, in the Shell enter: `2+2` After pressing Enter, the next line displays the answer: 4. Basically, Python has taken the `code` and produced the relevant output.

- **STEP 4** The Python Shell acts very much like a calculator, since code is basically a series of mathematical interactions with the system. Integers, which are the infinite sequence of whole numbers can easily be added, subtracted, multiplied and so on.

![](img/d501697c83491ed0bb4b382b0d28ef0a_91_2.png)

![](img/d501697c83491ed0bb4b382b0d28ef0a_91_3.png)

- **STEP 5**
While that's very interesting, it's not particularly exciting. Instead, try this:

`print("Hello everyone!")`

Just enter it into the IDLE as you've done in the previous steps.

![](img/d501697c83491ed0bb4b382b0d28ef0a_92_0.png)

- **STEP 6**
This is a little more like it, since you've just produced your first bit of code. The Print command is fairly self-explanatory, if printer things. Python 3 requires the brackets as well as quote marks in order to output content to the screen, in this case the 'Hello everyone!' bit.

![](img/d501697c83491ed0bb4b382b0d28ef0a_92_2.png)

- **STEP 7**
You may have noticed the color coding within the Python IDLE. The colors represent different elements of Python code. They are:

- Black – Data and Variables
- Green – Strings
- Purple – Functions
- Orange – Commands
- Blue – User Functions
- Dark Red – Comments
- Light Red – Error Messages

- **STEP 8**
The Python IDLE is a configurable environment. If you don't like the way the colors are represented, then you can always change them via Options > Configure IDLE and clicking on the Highlighting tab. However, we don't recommend that, as you won't be seeing the same as our screenshots.

![](img/d501697c83491ed0bb4b382b0d28ef0a_92_1.png)

- **STEP 9**
Just like most programs available, regardless of the operating system, there are numerous shortcut keys available. We don't have room for them all here but within the Options > Configure IDLE and under the Keys tab, you can see a list of the current bindings.

![](img/d501697c83491ed0bb4b382b0d28ef0a_92_3.png)

### IDLE Colour Coding

| Colour | Use for | Examples |
| :--- | :--- | :--- |
| Black | Data & Variables | 23.6 axes |
| Green | Strings | "Hello World" |
| Purple | Functions | len() print() |
| Orange | Commands | if for else |
| Blue | User functions | get _area() |
| Dark red | Comments | #Remember VAT |
| Light red | Error messages | SyntaxError: |

- **STEP 10**
The Python IDLE is a power interface and one of the available GUI toolkits. If you want to know the many ins and outs of the Shell, we recommend you take a few moments to view www.docs.python.org/3/library/idle.html, which details many of the IDLE's features.

Running the IDLE

By default, Python comes with an IDLE that you can use to interactively run Python programs and to write and run Python scripts in a windowed environment. The IDLE is currently provided on all platforms, but on Windows, it is only available if you select the 'install for all users' option during the install process.
