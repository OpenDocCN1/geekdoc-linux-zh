# Cisco Learning Institute's  
Linux+ Fundamentals and Certification

The need for a comprehensive Linux certification is simple: Linux is vendor-independent. Linux-certified professionals must know basic installation, operation, and troubleshooting of Linux operating systems.

Linux+ Fundamentals and Certification covers all of the exam requirements and provides a solid foundation on installation requirements, administration basics, and administrative tasks. It also covers networking basics such as network addresses and configuring remote client access, managing services, hardware configuration, security, and troubleshooting.

Linux+ Fundamentals and Certification ensures that you can explain fundamental open source resources/licenses, demonstrate knowledge of user administration, understand file permissions/software configurations, and manage local storage devices and network protocols.

Key features include:

+   - The main text, printed in two-color and filled with numerous illustrations, contains Linux+ objectives, performance objectives, and end-of-chapter review questions to aid in understanding and retention.
+   - The lab manual accompanying the main text includes discussions and instructions on how to complete the hands-on exercises.
+   - The certification kit on the accompanying CD includes hands-on, Web-based activities as well as hundreds of questions to help you prepare for the exam.
+   - A Student Resource CD containing hundreds of questions to help you prepare for the Linux+ Certification exam.
+   - Authentication to access the Web-based curriculum, which contains hands-on labs through an authorized training site.
