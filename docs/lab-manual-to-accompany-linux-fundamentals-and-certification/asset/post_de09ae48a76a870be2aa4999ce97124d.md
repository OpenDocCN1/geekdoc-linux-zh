## Troubleshooting Connection Status

### LAB 13.3

Check the network connection from your computer to a remote Web site, for example, www.cisco.com.

1. Ping the remote connection. Identify the IP address and make sure that the system responds to the ping.
2. Use `traceroute` to determine the network path to the remote system.
3. Use `nslookup` to ensure that the remote connection has a DNS entry and to identify the DNS servers that service the entry.
4. Determine whether the remote connection has any mail servers using the `host` command.
