# Linux Distribution

**LAB 3.1**

Install a distribution of the Linux operating system. Use a CD distribution set. Choose a custom installation type. Choose default values for all entries, except the following:

+   * Use your first initial and last name as the host name of the computer.
+   * Select no firewall.
+   * Use **LinuxPlus** as the root password.
+   * Select *shadow passwords*.
+   * Install all packages.

Add an account for yourself. Always log on with your account and use the `su` command to connect as root when needed.
