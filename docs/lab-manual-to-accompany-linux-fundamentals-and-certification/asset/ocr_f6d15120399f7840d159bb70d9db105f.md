# # Preface

Merriam-Webster's Collegiate Dictionary defines a computer as a programmable electronic device that can store, retrieve, and process data. A more inclusive definition would be that it operates under the control of instructions stored in its own memory and can accept data, manipulate the data, produce results, and store the results for future use. A computer has two principal characteristics: It responds to a specific set of instructions and it can execute a prerecorded list of instructions called a program.

The set of machine-language instructions that a computer will respond to is embedded in the central processing unit. These instructions are the basic building blocks of all instructions that the computer will follow. Before your word processing or game program will execute on a computer, the computer has to be programmed, using these basic instructions, to accomplish a wide range of tasks. These tasks include reading and writing to the disk drives, interpreting the keyboard strokes, interpreting the mouse movements, and many other hardware-related jobs. A set of instructions that accomplishes these critical tasks is called an *operating system* (OS).

Every computer system must have an operating system. The OS is a set of programs that coordinates all the tasks of the computer system. For example, if you want to print a document to the printer, the OS must translate your text to code that the printer will understand, then send the code to the printer. Every task, no matter how small, must be controlled by the operating system.

The operating system consists of a group of related programs needed to accomplish these individual tasks. The rationale for having a group of programs, rather than one program, is that not everyone needs all the programs that are available. In most cases, if you installed all the available programs, you would run out of space on your hard drive and in your computer's memory.

At the core of the operating system is the program called the kernel. The kernel maintains the computer's clock, starts applications, and assigns resources such as devices, programs, and data. The kernel is memory resident, which means that it is in memory once the operating system starts and remains there while the computer system is running. Other programs are often nonresident, which means that they have to be read from an external storage device into memory when needed.

There are many different operating systems. The most commonly used operating systems in personal computers today are Linux, Windows, Mac OS, and Unix. Of the operating systems listed, only Linux may be freely copied and distributed.
