# # X Windows Configuration

## LAB

![](bbox=[0.79, 0.08, 0.94, 0.16])

Manually configure X. Copy the /etc/X11/XFree86Config file before beginning this procedure.

+   1. Use the /usr/sbin/ddcprobe command to probe the hardware for monitor and video card information. Write down your results.
+   2. Generate a configuration file skeleton using the XFree86 program with the -configure option.
+   3. Test the configuration using XFree86 with the -xf86config option.
+   4. Replace the existing XF86Config file with your new file.
