## 故障排除连接状态

### 实验 13.3

检查从你的计算机到远程网站（例如 www.cisco.com）的网络连接。

1. Ping 远程连接。识别 IP 地址并确保系统对 ping 有响应。
2. 使用 `traceroute` 确定到远程系统的网络路径。
3. 使用 `nslookup` 确保远程连接有 DNS 条目，并识别服务于该条目的 DNS 服务器。
4. 使用 `host` 命令确定远程连接是否有邮件服务器。
