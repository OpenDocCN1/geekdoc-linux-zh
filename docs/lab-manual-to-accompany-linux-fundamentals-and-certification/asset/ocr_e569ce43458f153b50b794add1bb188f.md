# Using vi

![](bbox=[0.69, 0.07, 0.95, 0.15])

Change your bash profile using vi to include the following:

+   * Your script directory (/*home/userid/scripts*) in the path environment variable
+   * A command-line prompt that includes the date and time on a line above the default line
+   * A list of the contents of your home directory

Test your script.
