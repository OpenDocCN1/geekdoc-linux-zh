# # Budgets

# LAB 2.1

Create a budget for a three-workstation implementation in a small business. The work-
stations will be used to develop a C++ programming project. Include in your project bud-
get the following:

+   1. **Hardware**—The developers will be developing a high-end GUI application. They
+   want three computers with the following characteristics:
+   
+       a. High-performance video cards and monitors
+   
+       b. 1 GB of internal memory
+   
+       c. Two 80 GB hard drives/machines
+   
+       d. Gigabit network interface cards
+   
+       e. An 8-port switch to work at gigabit speed
+   
+       f. Moderate-quality color laser printer

+   2. **Software**—Each machine will have a Linux distribution with the latest stable kernel.
+   In addition the developers want the following applications:
+   
+       a. StarOffice productivity software
+   
+       b. Intel® C++ Compiler 7.1 for Linux

+   3. **Maintenance**—At least two years on-site for computer hardware

+   4. **Support**—At least a year of phone support for the C++ compiler

+   5. **Training**—Training will be done in-house by the system administrator. Budget the
+   time requirement of the administrator for a beginning usage training course.
