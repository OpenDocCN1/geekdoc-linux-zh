# Secure Updates

# LAB 12.1

Use the RedHat up2date program to update your operating system.

+   1. The latest SSL certificate for Red Hat Network (RHN) is located at https://rhn.redhat.com/help/ssl_cert.px. Follow the onscreen instructions to download, verify, and install the new certificate.

+   2. Execute the **up2date** program from the command line. You must be logged in as root to run this program (su root).

+   3. Follow the onscreen prompts to register an account, send your computer information, download the latest updates, and install the updates.
