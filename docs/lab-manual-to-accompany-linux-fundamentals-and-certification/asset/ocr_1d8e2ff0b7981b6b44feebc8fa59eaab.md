# # Linux Distribution

![](bbox=[0.73, 0.07, 0.95, 0.15])

**Scenario:** You have an older Pentium II 333 MHz computer with a 256 MB RAM, a 4 GB EIDE/ATA hard drive, and a 100Base-T network card. You have decided to install the Linux operating system on the computer to use it as a personal desktop and an FTP server. For a personal desktop system, you need a word processing and spreadsheet application. The FTP server needs to use a secure protocol that only those with authorization can access. The Linux distribution should have a package management system.

**Action:** Research at least three different Linux distributions to assure they meet the criteria described above. Compare each distribution's features using a spreadsheet (rows and columns). Based on the compared criteria, choose a distribution to install.
