# # User Configurations

# ## LAB 8.2

Configure your directory * /home/username/scripts * to share to others using NFS.

+   * Configure * /etc/exports * , * /etc/hosts.allow * , and * /etc/hosts.deny * .
+   * Start the NFS service.

Configure your directory * /home/username/scripts * to share to others using Samba.

+   * Configure * /etc/samba/smb.conf * .
+   * Create Samba users.
+   * Start Samba.
