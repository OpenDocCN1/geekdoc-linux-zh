The next example will be looking into how the inline input operator can be used with the bc command in a script.

```
#!/bin/bash
var1=8
var2=1.75
var3=3
varF=$(bc << EOF # EOF stands for End of File
scale = 4
v1 = ( $var1 * $var2)
v2 =($var1 / $var3)
v1 + v2
EOF
)
echo The final calculation is: $varF
```
