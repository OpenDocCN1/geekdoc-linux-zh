| Run-Level Scripts | What Does It Do? |
| :--- | :--- |
| <code>nfs</code> | Starts or stops the NFS-related daemons (<code>rpc.nfsd</code>, <code>rpc.mountd</code>, <code>rpc.statd</code>, <code>rpc.rquotad</code>) and exports shared file systems. |
| <code>pcmcia</code> | Loads or unloads modules, drivers, and programs (including the <code>cardmgr</code> daemon) to support PCMCIA cards (Ethernet adapters, modems, memory cards, and so on) in laptop computers. |
| <code>portmap</code> | Starts or stops the <code>portmap</code> daemon, which manages programs and protocols that utilize the Remote Procedure Call (RPC) mechanism. |
| <code>random</code> | Loads or saves the current state of the machine’s random number generator’s random seed to ensure more random randomness. |
| <code>route</code> | Starts or stops the <code>route</code> daemon, which controls dynamic routing table updates via the Router Information Protocol (RIP). |
| <code>rwiod</code> | Starts or stops the <code>rwiod</code> daemon, which enables others on the network to obtain a list of all currently logged-in users. |
| <code>sendmail</code> | Controls the <code>sendmail</code> daemon, which handles incoming and outgoing SMTP (Simple Mail Transfer Protocol) mail messages. |
| <code>single</code> | Terminates all running processes and enters run level 1 (single user mode). |
| <code>smbd</code> | Starts or stops the <code>smbd</code> and <code>nmbd</code> daemons for allowing access to Samba file and print services. |
| <code>snmpd</code> | Starts or stops the <code>snmpd</code> (Simple Network Management Protocol) daemon, which enables others to view machine-configuration information. |
| <code>squid</code> | Starts or stops the <code>squid</code> services, which enables proxy service to clients on your network. |
| <code>syslog</code> | Starts or stops the <code>klogd</code> and <code>syslogd</code> daemons that handle logging events from the kernel and other processes, respectively. |
| <code>xfs</code> | Starts or stops <code>xfs</code>, the X Window font server daemon. |
| <code>xinetd</code> | Sets the machine’s host name, establishes network routes, and controls <code>xinetd</code>, the network services daemon which listens for incoming TCP/IP connections to the machine. |
| <code>ypbind</code> | Binds to an NIS (Network Information Service) master server (if NIS is configured), and starts or stops the <code>ypbind</code> process, which communicates with the master server. |

Each script representing a service that you want to start or stop is linked to a file in each of the run-level directories. For each run level, a script beginning with K stops the service, whereas a script beginning with S starts the service.
