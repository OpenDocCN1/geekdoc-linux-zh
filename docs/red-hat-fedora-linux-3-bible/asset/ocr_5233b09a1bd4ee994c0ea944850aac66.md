# # Working with Graphics


Tools for creating and manipulating graphics are becoming both more plentiful and more powerful in Fedora. Leading the list is the GNU Image Manipulation Program (GIMP). GIMP lets you compose and author images as well as retouch photographs. Other tools that come with Fedora for creating graphics include *ksnapshot* (a program for taking screen captures) and *kpaint* (for working with bitmap images).

# ## Manipulating images with GIMP


The GIMP is a free software program that comes with Fedora for manipulating photographs and graphical images. To create images with GIMP, you can either import a drawing, photograph, or 3D image, or you can create one from scratch. You can start GIMP from the system menu by clicking Graphics $\rightarrow$ GIMP Image Editor or by typing `gimp&` from a Terminal window.
