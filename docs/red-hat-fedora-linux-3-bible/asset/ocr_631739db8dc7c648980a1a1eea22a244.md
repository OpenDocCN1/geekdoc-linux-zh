-iuse UDP instead of TCP
-p #-# port number to send to or listen at (default 5001)
-s-t: source a pattern to network
-r: sink (discard) all data from network
-Allign the start of buffers to this modulus (default 16384)
-Ostart buffers at this offset from the modulus (default 0)
-vverbose: print more statistics
-dset SO_DEBUG socket option
-b # set socket buffer size (if supported)
-F X format for rate: K,M = kilo[bit,byte]; m,M = mega; g,G = giga
Options specific to -t:
-#W number of source bufs written to network (default 2048)
-ldon't output TCP writes (sets TCP_NODELAY socket option)
Options specific to -r:
-Bfor -8, only output full blocks as specified by -1 (for TAR)
-T"touch": access each byte as it's read

The first step is to start up a receiver process on the server machine:

```
# tcp -rs
tcp-r: buflen=8192, nbuf=2048, align=16384/0, port=5001 tcp
tcp-r: socket
```

The -r flag denotes that the server machine will be the receiver. The -s flag, in conjunction with the -r flag, tells tcp that we want to ignore any received data.

The next step is to have someone outside of your data link, with a network link close to the same speed as yours, set up a tcp sending process:

```
# tcp -t8 server.example.com
tcp-t: buflen=8192, nbuf=2048, align=16384/0, port=5001 tcp  -->
server.example.com
tcp-t: socket
tcp-t: connect
```

Let the process run for a few minutes and then press Ctrl+C on the transmitting side to stop the testing. The receiving side will then take a moment to calculate and present the results:

```
# tcp -rs
tcp-r: buflen=8192, nbuf=2048, align=16384/0, port=5001 tcp
tcp-r: socket
tcp-r: accept from 64.223.17.21
tcp-r: 2102496 bytes in 70.02 real seconds = 29.32 KB/sec ***
tcp-r: 1226 I/O calls, msec/call = 58.49, calls/sec = 17.51
tcp-r: 0.0user  0.0sys  1.10real  0% 0+0d Omxrss 0+2pf 0+0cw
```

In this example, the average bandwidth between the two hosts was 29.32 kilobytes per second. On a link suffering from a DDOS, this number would be a mere fraction of the actual bandwidth the data link is rated for.
