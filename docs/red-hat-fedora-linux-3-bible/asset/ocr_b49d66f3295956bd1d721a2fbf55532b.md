+   1. Determine the kind of wireless card you are using. If you have a PCI card, type:
+   ```bash
+   # lspci -v | less
+   ```
+   ```
+   00:0a.0 Network controller: Broadcom Corporation BCM4306 802.11b/g Wireless LAN Controller (rev 03)
+   Subsystem: Linksys: Unknown device 0014
+   Flags: bus master, fast devsel, latency 32, IRQ 5
+   Memory at ee000000 (32-bit, non-prefetchable) [size=8K]
+   ```
+   In this example, the PCI card is a BCM4306 802.11b/g Wireless Controller from Broadcom Corporation.

+   2. Check the following list of wireless card drivers known to run under ndiswrapper:
+   `http://ndiswrapper.sourceforge.net/wiki/index.php/List`

+   3. If your card is on the list, download the driver recommended on that page. I used the Linksys WMP54GS Wireless-G PCI Adapter (which was reflected by the chipset BCM4306 802.11g, rev 03 shown in the lspci output above). So I downloaded the driver as follows:
+   ```bash
+   # mkdir wireless
+   # cd wireless
+   # wget ftp://ftp.linuxys.com/pub/network/wpc54g_v2_driver_utility_v2.0.zip
+   ```

+   4. After the file is done downloading, unzip the driver file. For the example, I typed:
+   `# unzip wpc54g_v2_driver_utility_v2.0.zip`

+   5. Next, get the ndiswrapper software (currently only source code is available) by downloading it to your Fedora Core system from the following site:
+   `http://sourceforge.net/projects/ndiswrapper`

+   6. With the ndiswrapper source code package in the current directory, unzip and untar it as follows:
+   `# tar xvfz ndiswrapper-*tar.gz`

+   7. Change to the ndiswrapper directory and run the `make` command as follows:
+   ```bash
+   # cd ndiswrapper*
+   # make install
+   ```

+   8. Get the INF file from the unzipped driver package. From our example, the file we needed was `1sbcmds.inf`. Then run the `ndiswrapper -i` command to install the driver. For example, with the `1sbcmds.inf` file in the current directory, I ran:
+   `# ndiswrapper -i 1sbcmds.inf`
