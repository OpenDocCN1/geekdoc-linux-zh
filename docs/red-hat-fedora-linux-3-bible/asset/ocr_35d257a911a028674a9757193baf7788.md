+   4. On the Mac OS X client, type the address of the share directory into the Address box. For example, to connect to the shared NFS (`nfs://`) directory called `/var/music` from the computer named `jukebox.linuxtoys.net`, you can type the address:

If everything is working properly, an icon representing the server should appear on your Mac OS X desktop. Open that icon to see the contents of the shared directory. You can use the shared files and directories as though they were on your Mac (if permissions on the server permit you to do so). Drop the icon in the trash when you are done.

**NOTE:** If you are unable to connect to the shared directory, go through the NFS procedures in Chapter 18 more carefully. In particular, make sure that firewall ports are open on the server and that the user and host permissions are set to allow the level of access that you require.
