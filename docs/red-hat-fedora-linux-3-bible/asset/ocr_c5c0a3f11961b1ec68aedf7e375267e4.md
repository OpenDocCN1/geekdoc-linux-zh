About the DVD-ROM

The DVD that accompanies this book consists of the complete set of installation packages and all source code related to the Red Hat–sponsored Fedora Project called Fedora Core 3. To install the DVD:

+   * Follow the instructions provided in Chapter 2 and on the DVD.
+   * Refer to Appendix B for a complete list of the Fedora Core 3 software packages.

If for some reason you don’t have your DVD handy, you can find information on how to download a set of four installation CDs from the Fedora Project Web site at fedora.redhat.com/download. If you don’t have a DVD drive, you can download those four installation CD images, burn them to CDs, and install from those CDs.

Web sites such as Fedora.us, rpm.livna.org, and RPMfind.net can help you find extra, useful software packages that are not in Fedora (or any other Red Hat distribution). Some of these sites act as repositories that allow you to download sets of dependent packages (see the descriptions of yum in Chapter 5).

# **Fedora Source Code**

From time to time, you may want to recompile the Linux kernel. Doing so requires the kernel source code, which you can find in the kernel package included on this book’s companion DVD in the SRPMS / directory. (Note that the kernel package used to be called kernel-sources and reside on an installation CD.) The source code for every other package included on the DVD is also in the SRPMS / directory. As with the installation CDs, if you want to download source CDs, you can get them from a Fedora download site. There are four CD images containing Fedora source code (each iso image has SRPMS in its name).

# **Fedora Rescue CD**

The Fedora Project provides a rescue CD with the Fedora Core 3 software set. The CD image The Fedora Core 3 Rescue CD contains those features needed to recover your Fedora system if, for example, the system fails to boot because of a corrupted file system.
