> **TIP:** It is not necessary to be connected to a network (or even to have a network connection) just to test the server or to view the files on your machine. Rather than specify the server’s real name in the URL, just use *localhost* (that is, `http://localhost/`) from a browser on the same computer. In fact, it’s best to fully test the configuration before making the server accessible on an unprotected network.
