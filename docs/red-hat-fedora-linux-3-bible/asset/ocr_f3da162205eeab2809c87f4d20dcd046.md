TIP: The konsole command starts the Konsole (KDE) terminal window. Programmers who use many terminal windows at once often prefer Konsole over gnome-terminal (finding it to be more efficient and feature-rich).

+   • Add a screensaver — Select Screensaver. Try out a few screensavers (screensaver is blank, by default). Click the Only One Screen Saver check box in the Mode box.
+   Click different screensavers to see them and click Preview to try them out. Try T3D for a bizarre clock or Rubick to watch how to solve a Rubick’s cube.

TIP: Click the Lock Screen After check box and set the number of minutes after which the screen will be locked. This is a good option for an office environment, where you want your screen locked if you wander away for a few minutes. (Be sure to log off of any virtual terminals you may have open.)

+   • Change the theme — Select Theme. You can change the entire theme (colors, icons, borders, and so on) for your desktop. The Bluecurve theme is the default theme used by Fedora. Try any of the others to find one that suits you. Click Theme Details to mix-and-match attributes from different themes. Figure 3-4 shows the window for selecting a theme.
