
## UNIX COMMAND REFERENCE

| COMMAND | RESULT |
|---|---|
| man [section] <command> | Look up a command |
| pwd | Display current directory |
| ls [-al] | List directory contents |
| cd <directory> | Change to another directory |
| rm <filename> | Delete file |
| cp <filename> <ending filename> | Copy file to new location |
| mv <filename> <ending filename> | Move file to new location |
| cat <filename> | Display entire file |
| more <filename> | Display file one page at a time |
| wc [-l|-w|-c] <filename> | Return file statistics: number of words, lines, and characters |
| uudecode/uuencode <filename> | Encode/decode binary file to transmit through email |
| bg/fg <process> | Move process to the foreground/background |
| ps [ax or ef] | List processes running on the system |
| kill -<signal> <process ID> | Send end signal to a running process |
| lp -d<printer name> <filename> | Send job to the named printer |
| lpr -P<printer name> <filename> | Send job to the named printer |
| lpstat -t | Show current list of jobs waiting at a printer |
| lpq -P<printer name> |  |
| telnet <remote machine> | Connect to a remote hostname or IP |
| ftp <remote machine> | Create an FTP connection to a remote hostname or IP |
| lynx <URL> | Connect to a Web server using a text-based browser |
