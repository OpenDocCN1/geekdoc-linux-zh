Use the following steps to create a new folder:

+   1. Right-click in the location where you want the folder to appear.
+   2. Choose New from the pop-up contextual menu.
+   3. Select Folder from its submenu.

> Getting Home If you need to get to your home directory in KDE, just look for the icon of a folder with a little house on it. Clicking on this icon opens a KDE file manager window showing your home directory.
