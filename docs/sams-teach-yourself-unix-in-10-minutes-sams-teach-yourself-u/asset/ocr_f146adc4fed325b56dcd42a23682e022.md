+   - top—The command top shows the current top CPU-usage processes that are running on the system. The display continuously updates, so you can view how much CPU time new processes take as they are added to the system.
+   - at/crontab—You can schedule commands to run at certain times on your system by using the at and crontab functions. You will want to check with your system administrator and read the appropriate man pages before attempting to do so.
+   - The X Window System (X Windows)—Programs running under the X Window System all execute simultaneously. There is no need to worry about backgrounding or foregrounding processes manually. You can, however, adjust the priority of X Windows applications from the command line, just as you do with any other process.
