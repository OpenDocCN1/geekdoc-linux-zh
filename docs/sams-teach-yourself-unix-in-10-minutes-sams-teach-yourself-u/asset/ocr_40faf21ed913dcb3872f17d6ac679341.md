# FINDING A FILE BY DATE

Imagine you just created a document file on the system but you can’t remember its name. How in the world can you find it? One possible solution is to search by time, finding files that are younger than a certain time. To search for a file by its creation date do the following:

+   1. Determine the relative age of your file in days.
+   2. Choose a starting directory for the search. Remember, / searches the entire file system, whereas ~/ searches only your personal directory.
+   3. Invoke find using the -ctime option: `find <starting directory> -ctime <days old> -print`.

For example:

```
>find ~/ -ctime 2 -print
/home/jray/getip.c
/home/jray/a.out
/home/jray/getip2.c
/home/jray/.saves-8395-postoffice
```

If you entered this command, you’d have searched your home directory for files that have been modified in the last two days (48 hours). If these were your results, one of these four files would be the one that you were trying to find.
