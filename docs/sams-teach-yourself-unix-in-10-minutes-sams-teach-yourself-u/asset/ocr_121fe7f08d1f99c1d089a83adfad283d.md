# ALIASES

One of the most useful features that shells provide to the user is the capability to create command aliases. Aliases are, quite simply, aliases. If, for example, you're a long-time DOS user, you might find yourself typing del instead of rm to delete files. Want to change this? Just set an alias with the alias command. The syntax is as follows: `alias <newname> <command to run>`. If you actually want to make that alias for del, type the following: `alias del rm`. After setting this alias, any time you type del, it executes the command rm.

More useful than simply renaming commands, you can use the alias command to create meta commands that enforce certain options. For example, it's always a good idea to force rm to be in interactive mode
