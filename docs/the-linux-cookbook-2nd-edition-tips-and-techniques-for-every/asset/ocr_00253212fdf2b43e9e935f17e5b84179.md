**Freebirth**  
Sequencer, bass synthesizer, and sample player.  
DEB: `freebirth`  
RPM: `freebirth`  
WWW: http://www.hitsquad.com/smm/programs/Freebirth/

**GLAME**  
Audio editor described as “the GIMP of audio.” GLAME is an acronym for “GNU/Linux Audio Mechanics.”  
DEB: `glame`  
RPM: `glame`  
WWW: http://glame.sourceforge.net/

**Pure Data**  
Powerful system for programming real-time audio.  
DEB: `pd`  
WWW: http://www-crca.ucsd.edu/~msp/software.html

**Rosegarden**  
MIDI sequencer, music notation (score) editor, and music composition editor.  
DEB: `rosegarden`  
RPM: `rosegarden`  
WWW: http://www.rosegardenmusic.com/

**Tapiir**  
Graphical, real-time audio effects processor inspired by old magnetic-tape delay effects.  
DEB: `tapiir`  
WWW: http://www.iua.upf.es/~mdeboer/projects/tapiir/

**XWave**  
A simple sound editor that performs the basic functions you would expect in a WAV file editor.  
DEB: `xwave`  
WWW: http://www.ibiblio.org/pub/linux/apps/sound/editors/
