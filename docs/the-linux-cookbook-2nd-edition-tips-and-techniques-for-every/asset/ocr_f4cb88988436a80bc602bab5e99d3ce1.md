+   • To generate a Dissociated Press cut-up from the current buffer, always overlapping by one word, type:
+     CTRL-U -1 ALT-X dissociated-press RET

# 30.7 Undergoing Psychoanalysis

Emacs has a special mode called doctor, which is an implementation of the famous ELIZA program. As with “real” psychoanalysis, you talk out your troubles and the doctor asks you for more—only in this case it doesn’t cost as much, and sessions last as long as you like. And since the “session” is an Emacs buffer, you can save it to a file for posterity.

⇒ To begin a session of psychoanalysis in Emacs, type:
  ALT-X doctor RET
