# D.3 Linux News and Commentary

These are the essential sources of news and opinion on Linux and free software.

The **Free Software Foundation’s** Web site is a source for both philosophical readings and news about the GNU Project, its free software operating system.  
[http://gnu.org/]

**Linux.Com** provides feature stories, links, and a database of Linux User Groups (LUGs). [http://linux.com/]

**Linux Journal** is the oldest print magazine devoted to Linux. Monthly. [http://linuxjournal.com/]

**Linux Today** aggregates and publishes “Linux News on Internet Time.”  
[http://linuxtoday.com/]

**Linux Weekly News** has covered Linux and the free software movement since 1998. [http://lwn.net/]

**Slashdot** is a popular news and discussion site for enthusiasts of Linux and free software; newshounds usually check Slashdot several times daily.  
[http://slashdot.org/]
