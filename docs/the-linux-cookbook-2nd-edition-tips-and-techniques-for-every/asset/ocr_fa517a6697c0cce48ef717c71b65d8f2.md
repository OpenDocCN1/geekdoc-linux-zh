# 18.1.6 Making an Image Montage

To make a montage of several images, use **montage**. It takes as arguments the names of the images to use followed by the name of the output file to write the montage image to.

The montage image is made by scaling all of the input images to fit the largest size possible, up to 120x120 pixels, and tiling these images in rows of five and columns of four.

⇒ To create a montage from the files **owl.jpeg**, **thrush.jpeg**, and **warbler.jpeg** and write it to **ohio-birds.png**, type:

```
$ montage owl.jpeg thrush.jpeg warbler.jpeg ohio-birds.png [RET]
```

**NOTES:** In this example, three JPEGs were read and output to a PNG file; to specify the format to use in the output, give the appropriate file extension in the output file name.
