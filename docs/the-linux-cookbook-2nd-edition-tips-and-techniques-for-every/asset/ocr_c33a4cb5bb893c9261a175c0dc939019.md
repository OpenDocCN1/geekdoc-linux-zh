# 32.4.3 Counting How Many Messages You Have

Elm

```
DEB: mailutils
RPM: elm
WWW: http://www.instinct.org/elm/
```

Use the messages tool, distributed with Elm.⁶ to count the number of mail messages in a folder or file. Give the name of a mail folder as an argument; with no arguments, it counts the mail you have waiting in your inbox.

> ⁶ On Debian systems, messages comes with the GNU Mailutils package.
