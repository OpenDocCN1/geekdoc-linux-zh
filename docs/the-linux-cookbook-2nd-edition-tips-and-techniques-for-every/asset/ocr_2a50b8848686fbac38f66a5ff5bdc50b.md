# 23. Editing Sound Files

All kinds of tools and applications exist to edit sound files. This chapter describes some of those tools, and gives methods for cutting and pasting sound files, applying effects and filters, and converting sound files between formats.

# 23.1 Manipulating Selections from Sound Files

Snd
DEB: snd
RPM: snd
WWW: http://www-ccrma.stanford.edu/software/snd/

Snd is a sound-file editing environment for X, and it aims to be for sound what Emacs is to text. (It also uses Emacs-style key bindings.)

You'll find a complete manual for it in the /usr/doc/snd directory; this section explains how to use Snd to work with selections from sound files.

To open a sound file in Snd, give the name of the file to be opened as an argument to snd.

⇒ To open the sound file mixdown.wav in Snd, type:

```
$ snd mixdown.wav RET
```
