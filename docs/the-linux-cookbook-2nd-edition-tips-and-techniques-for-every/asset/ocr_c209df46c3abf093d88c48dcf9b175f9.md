⇒ To burn the data track band-info, plus all the audio tracks in the current directory that have a .cdda extension, to the CD-R drive whose target ID is 2 on the primary SCSI bus, type:

```
$ cdrecord dev=0,2,0 band-info -audio *.cdda [RET]
```

NOTES: When writing an audio CD, you should have as few processes running as possible. If cdrecord has to pause even momentarily to let the system shuffle other processes, the CD-R could be ruined! For this reason, it is advisable to avoid switching between consoles—or between windows, if running X—during the CD-R burning process.
