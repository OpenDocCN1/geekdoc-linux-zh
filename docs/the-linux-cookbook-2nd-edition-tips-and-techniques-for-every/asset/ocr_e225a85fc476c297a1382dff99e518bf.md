# 8.6.4 Checking In Many Files

There are a few considerations when checking in lots of files at once.

Sometimes you may want to check in a group of files and specify a particular revision number to use. Do this by giving the revision number to use as an argument to the -r option. The ci command does not take space characters between an option and its argument, so be sure to follow the option immediately with the revision number.
