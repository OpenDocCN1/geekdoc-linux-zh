# Vi

Vi is a visual, or full-screen, editor. It is probably the most popular editor on Linux, and on UNIX-based systems in general. Touch typists often find its keystroke commands enable very fast editing. A section all about it is located earlier in this chapter (see Recipe 10.2 [Using Vi], page 244).

```
DEB: nvi
RPM: nvi
WWW: http://www.bostic.com/vi/
```

# Vim

Like the Elvis editor, Vim ("Vi improved") is a modern implementation of Vi; it has more commands and versatility, and new features include syntax coloring, scrollbars and menus, mouse support, and built-in help.

```
DEB: vim
RPM: vim
WWW: http://www.vim.org/
```
