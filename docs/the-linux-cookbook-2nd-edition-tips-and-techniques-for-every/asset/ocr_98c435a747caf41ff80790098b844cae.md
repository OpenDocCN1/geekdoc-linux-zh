⇒ To replace the text “day” with the text “night” in the current buffer, type:

```
ALT - X replace-regexp RET
Replace regexp: day RET
Replace regexp day with: night RET
Replaced 7 occurrences
```

In the preceding example, the regexp “day” was found (and replaced by the regexp “night”) seven times from point to the end of the buffer.

This function is especially useful for replacing control characters with text, or for replacing text with control characters, which you can specify with CTRL - Q, the quoted-insert function (see Recipe 10.1.4 [Inserting Special Characters in Emacs], page 239).

⇒ To replace all the “Control-M” characters in the current buffer with regular linefeeds, type:

```
ALT - X replace-regexp RET
Replace regexp: CTRL - Q CTRL - M RET
Replace regexp "M" with: CTRL - Q 012 RET RET
Replaced 101 occurrences
```

In this example, 101 “Control-M” characters were found (and replaced) from point to the end of the buffer.
