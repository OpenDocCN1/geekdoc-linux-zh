The GIMP runs under X and is started by running gimp or choosing it from your window manager's menu. Give the names of any image files to open as arguments.

⇒ To start the GIMP in the background from a shell prompt, type:

```
$ gimp & [RET]
```

When started, any image files you give as arguments are opened in their own windows. The main GIMP panel will open in a window of its own, as in Figure 18-10.
