⇒ To view the iso 8859-1 character set, type:

```
$ man iso_8859_1 [RET]
```

You can use this page to see all of the characters in this character set and how to input them.

**NOTES:** There's a special way to “quote” these characters in Emacs; this technique is described in Recipe 10.1.4 [Inserting Special Characters in Emacs], page 239.

The `miscfiles` package also contains charts for these character sets, as explained in Recipe 11.4 [Using Word Lists and Reference Files], page 289.
