Finally, right-click on the image window for a pop-up menu containing a few of the most frequently-used commands; to choose one of these commands, drag the mouse pointer over the command and release the right button. Commands in the pop-up menu include Quit, which exits display, and Image Info, which displays information about the image file itself, including the number of colors, image depth, and resolution.
