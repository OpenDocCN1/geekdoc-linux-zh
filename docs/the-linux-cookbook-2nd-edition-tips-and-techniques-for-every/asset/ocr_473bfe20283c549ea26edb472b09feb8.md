# Nano

Gnu Nano is a free software editor inspired by PICO, the editor that is included with the University of Washington's proprietary PINE email program. It's also faster than PICO, and comes with more features.

```
DEB: nano
RPM: nano
WWW: http://www.nano-editor.org/
```
