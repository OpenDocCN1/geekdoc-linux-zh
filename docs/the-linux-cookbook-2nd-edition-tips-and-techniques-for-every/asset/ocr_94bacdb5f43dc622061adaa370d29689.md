# Xedit

Xedit is a simple text editor that comes with, and works in, X. It lets you insert, delete, copy, and paste text as well as open and save files—the very basics.

DEB: xbase-clients
RPM: XFree86
WWW: http://www.xfree86.org/

# XEmacs

XEmacs is a version of Emacs with advanced capabilities for use in X, including the ability to display images.
