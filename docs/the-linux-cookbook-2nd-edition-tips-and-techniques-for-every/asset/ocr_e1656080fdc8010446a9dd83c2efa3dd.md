# 22.1.6 Ejecting an Audio CD

Use cdeject to eject the disc in the CD drive. If the disc is currently playing, play will stop and the disc will eject.

⇒ To eject a CD, type:

```
$ cdeject RET
```

NOTES: This command will also eject a data CD, if the data CD is not currently mounted (see Recipe 24.4 [Using Data CDs], page 506).
