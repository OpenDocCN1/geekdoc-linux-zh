# Appendix B: Conventional File Name Extensions

| Extension | Type | Description |
|---|---|---|
| `.pict` | IMAGE | Apple Macintosh QuickDraw format. |
| `.png` | IMAGE | Portable Network Graphics format (usually pronounced “ping”). |
| `.pnm` | IMAGE | Portable “anymap” format. |
| `.ppm` | IMAGE | Color portable pixmap format. |
| `.ps` | IMAGE | Adobe PostScript format. |
| `.ra` | AUDIO | RealAudio file. |
| `.raw` | AUDIO | Raw audio data. |
| `.rgb` | IMAGE | Raw red, green, and blue bytes. |
| `.s3m` | AUDIO | MOD file. |
| `.sf` | AUDIO | IRCAM SoundFile format, used by some music composition software, such as CSound and MIXVIEWs. |
| `.sgml` | TEXT | SGML (“Standardized General Markup Language”) format. |
| `.stm` | AUDIO | MOD file. |
| `.tex` | TEXT | TeX or LaTeX document. |
| `.text` | TEXT | Plain, unformatted text. |
| `.tga` | IMAGE | TrueVision Targa image format. |
| `.tif` | IMAGE | Tagged Image File Format. |
| `.tiff` | IMAGE |  |
| `.txt` | TEXT | Plain, unformatted text. |
| `.ult` | AUDIO | MOD file. |
| `.uni` | AUDIO | MOD file. |
| `.voc` | AUDIO | SoundBlaster VOC file. |
| `.wav` | AUDIO | Microsoft RIFF format (aka WAV). |
| `.xbm` | IMAGE | X Window System bitmap format. |
