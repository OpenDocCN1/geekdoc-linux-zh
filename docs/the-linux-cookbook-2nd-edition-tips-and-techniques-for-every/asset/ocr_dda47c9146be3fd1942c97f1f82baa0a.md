## Gnus

Emacs newsreader (pre-installed with XEmacs) that can also be used to read and send mail. It has many features and should appeal to Emacs lovers—but a warning: Some find it daunting!

![](bbox=[0.381, 0.227, 0.705, 0.386])

*Figure 32-5. Gnus.*

```
DEB: gnus
RPM: gnus
WWW: http://gnus.org/
```

## MEW

Emacs mail and news facility developed in Japan, “Messaging in the Emacs World” has many features for handling mail in complex ways.
