Texinfo
Texinfo is the GNU Project’s documentation system, and it is excellent for writing certain kinds of technical manuals. While not extensible enough out-of-the-box for production of serious non-technical publications, it does allow for the inclusion of in-line EPS images and can produce TeX-based, HTML, and Info output. Use it if this matches your needs.
DEB: tetex-base
RPM: texinfo
WW: http://www.gnu.org/software/texinfo/
