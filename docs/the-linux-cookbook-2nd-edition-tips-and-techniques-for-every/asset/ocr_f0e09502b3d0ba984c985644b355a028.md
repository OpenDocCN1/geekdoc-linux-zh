# Wily

Wily, an interesting mouse-centric editor, is inspired by the Acme editor from AT&T’s Plan 9 experimental operating system. Wily commands consist of various combinations of the three mouse buttons, called chords.

```
DEB: wily
WWW: http://www.cs.yorku.ca/~oz/wily/
```
