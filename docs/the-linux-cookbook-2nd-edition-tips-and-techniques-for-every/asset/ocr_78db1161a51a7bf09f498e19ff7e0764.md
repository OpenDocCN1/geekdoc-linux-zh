# Ted

Ted is a WYSIWYG, typewriter-like text editor for use in X. It reads and writes RTF files (Microsoft's "Rich Text Format").

DEB: ted
RPM: Ted
WWW: http://www.nllgg.nl/Ted/

# THE

The Hessling Editor (THE) is a configurable editor that uses the Rexx macro language. It was inspired by the XEDIT editor for VM/CMS and the Kedit editor for DOS.

DEB: the
the-doc
RPM: THE
WWW: http://hessling-editor.sourceforge.net/
