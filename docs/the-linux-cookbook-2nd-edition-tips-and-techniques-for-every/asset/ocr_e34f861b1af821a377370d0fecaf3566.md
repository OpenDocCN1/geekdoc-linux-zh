+   To output a list of all the URLs contained in the text of the URL http://news.example.com/, type (all on one line):

```
$ lynx -dump -nolist http://news.example.com/ | sed -n
's.*/\(\(http(s)?\|ftp\|gopher\|telnet\|news\):\/\/\|mailto:\)\([^ SPACEBAR ,;\<CTRL>-\(V\) TAB\<*>*\[^ SPACEBAR ,;\<CTRL>-\(V\) TAB\<*>\).*\/l1p' RET
```

+   To output a list of the URLs contained in the HTML source file of http://news.example.com/, type (all on one line):

```
$ wget -q -O - http://news.example.com/ | sed -n
's.*/\(\(http(s)?\|ftp\|gopher\|telnet\|news\):\/\/\|mailto:\)\([^ SPACEBAR ,;\<CTRL>-\(V\) TAB\<*>*\[^ SPACEBAR ,;\<CTRL>-\(V\) TAB\<*>\).*\/l1p' RET
```

NOTES: The regexp used in these methods, although complex, is not exhaustive—it won't find every possible URL, but it will do a perfect job in most instances.

The PERL regexp that can match all possible URLs is described in Regex for URLs [http://www.foad.org/~abigail/Perl/url2.html], and it can be seen here: http://www.foad.org/~abigail/Perl/url.regexp.
