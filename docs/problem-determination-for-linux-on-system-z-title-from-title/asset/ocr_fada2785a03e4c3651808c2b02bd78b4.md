# Survey in the TCP/UDP layer

To survey in the TCP/UDP layer, one of the best methods is to use the netstat command to check the status of the TCP or UDP socket.

![](bbox=[0.25, 0.2, 0.48, 0.68])

+   - netstat -nat
+     - the status of TCP socket
+   - netstat -nau
+     - the status of UDP socket
+   - netstat -s
+     - check the network statistics
+   - telnet
+     - check the TCP socket of the other side
