# 3.3.6 zFCP/SCSI

The zFCP trace feature enables the debugging of the zfcp device driver and the flow of the Fibre Channel protocol. zFCP trace should be used with the SCSI trace for any debugging.

The following trace information can be selected according to the problem target areas:

+   - loglevel_erp
+   - loglevel_fsf
+   - loglevel_fc
+   - loglevel_qdio
