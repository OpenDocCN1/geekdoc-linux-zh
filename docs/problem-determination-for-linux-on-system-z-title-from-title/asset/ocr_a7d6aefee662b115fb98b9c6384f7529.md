+   • Setting the host name
+       • Activating the loop back device and mounting it
+       • Setting the time slice of scheduler
+       • Setting the IP setting (parameter settings related to N/W such as IP forwarding)
+       • Setting the kernel parameter setting specified in etc/sysctl.conf

**Note:** At /etc/init.d/boot.d, processes that start with Sxxx (for example, S12SuSEfirewall2_init) start when the machine boots, while processes that start with Kxxx (for example, K20boot.rootfsck) are used to kill when the machine boots or is powered off.

When then service start process has finished, the getty program is started by the init process, and the login prompt is displayed. As a result, login of the system becomes possible.
