# 8.3.3 Approach for hardware problems

The approach that you should take to solving hardware problems would be to first contact your hardware support personnel. You will need the hardware support person to further investigate the hardware problem.

Some basic information that they will need is:

+   1. Machine type
+   2. Serial number
+   3. Telephone number of the machine room

Information that is necessary to provide to your support person is:

+   1. A description of the problem
+   2. What you were doing when the problem occurred
+   3. When it occurred
+   4. Whether you changed any of the settings just before the problem occurred
+   5. The information to specify the hardware
+   6. Information about the hardware (for example, address)
+   7. Error messages on Linux
+   8. The information that you can get from HMC

# Specify the device

If we can specify the device in error clearly, the following two cases are possible.:

+   1. One device is in error.
+   2. The device status is not normal.

If we cannot specify the device in error, then:

+   1. The performance trouble could be disk I/O, which may be on different storage systems.
+   2. There may be network connection problems in an environment that has multiple NICs.

After specifying the device in error, check the status and distinguish the error (hardware or software).
