The REDISP screen allows you to view a maximum of the current day's history data simultaneously, but you have to detect any correlations between different variables yourself. To get into the REDISP screen type the command redisp or simply press the PF2 key from the IBM z/VM Performance Toolkit main menu. The screen displayed looks similar to Figure 2-21 on page 51. Every 60 seconds a new set of variables is written. There are more columns of data available than displayed on the screen. To navigate to the left or right use the PF10 and PF11 keys. Note the ESCN field. This is a good indicator to see whether the system is in emergency scanning mode. The value can be between 0 and 100% (the percent of demand scans that did not complete with scan 1). We discuss a scenario where emergency scanning occurs in Chapter 11, “Case study: slow responding Web site” on page 313.
