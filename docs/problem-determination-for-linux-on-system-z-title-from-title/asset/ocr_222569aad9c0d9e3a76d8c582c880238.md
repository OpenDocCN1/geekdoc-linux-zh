+   - loglevel_cio
+   - loglevel_scsi
+   - loglevel_other

In Example 3-50 we are enabling zFCP driver with the log level of loglevel_erp to 1.

# Example 3-50 Enabling zfcp

```
echo 1 > /sys/bus/ccw/drivers/zfcp/loglevel_erp
```

The log level for zFCP traces has four different levels from 0 to 3. The larger the value becomes, the more detailed is the information that is obtained The log levels of all areas are set to 0 by default, and only minimum information is output. The debug message is written in the /var/log/messages by setting the log level of zfcp. To stop the zFCP trace, see Example 3-51.

# Example 3-51 Disabling zfcp

```
echo 0 > /sys/bus/ccw/drivers/zfcp/loglevel_erp
```
