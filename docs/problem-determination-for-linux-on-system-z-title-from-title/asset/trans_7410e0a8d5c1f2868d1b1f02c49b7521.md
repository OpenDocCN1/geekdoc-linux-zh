在调查网络利用率时，需要调查每个接口的利用率（分析发送和接收的数据包数量、错误和冲突发生的频率等）。如果存在大量冲突数据包，则可能存在硬件故障或网络环境故障的可能性。对于 OSA 卡，必须检查通道利用率。通过参考性能报告，调查 OSA 或 HiperSockets 的带宽是否已满。在 Linux 端检查带宽瓶颈、配置错误等。
