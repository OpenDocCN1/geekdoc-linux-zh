

# 发行版

## 新一代

看看这些工艺精湛的发行版，它们足以让那家名字里有水果的公司（暗示苹果）的操作系统有得忙活了。

Ubuntu 衍生版多如牛毛。有些你甚至可以通过安装桌面环境并更改默认应用程序来自己复刻。但有些版本确实卓越非凡，它们在 Ubuntu 坚如磐石的基底之上，添加了独特而强大的功能。

elementary OS 便是其中之一。它通过自有的 Pantheon 桌面环境，带来了可与 Mac OS 相媲美的精致与简约。与其强迫用户阅读手册（在很多情况下，手册只会引发更多疑问），elementary 的目标之一便是将文档最小化。它力求足够直观，让用户能够自行摸索出操作方法。其设计目标之一还包括“简洁”，保持简单并避免臃肿。最后，它追求“可访问的配置”：不向用户灌输过多选项，也不索要本可自动获取的信息。这一切听起来可能像是花哨的设计行话，但当你看到应用程序指示器如何含蓄地传达有用信息，信息栏如何温和地通知你紧急状况，以及万事万物如何完美集成（就像新时代打字员感叹‘万物一体，兄弟’那样），你就会发现其中大有文章。

## 为 elementary OS 做贡献

Elementary OS 并非“免费”（指免费啤酒，现在啤酒免费了吗？–编者按）。它采用“乐意支付”模式，下载时会被要求做出贡献。Ubuntu 和其他一些发行版也采用这种模式，如果你选择支付 $0，也不会发生什么坏事。为软件收费——即使是“自由”（指言论自由）的软件——本身并没有错。GPL 甚至明确允许这样做。Elementary 要求捐赠而非直接标价，是在寻求一种平衡。它既确保了开发人员的工作得到回报，同时让软件对所有人可用。如果你不认同这种立场，你并没有义务使用它。如果你想以其他方式做出贡献，你可以帮忙修复 bug 或在论坛上帮助用户（这对任何软件都适用）。甚至还有 bug 赏金计划，如果你愿意为某个功能付费（或者希望为修复某个问题获得报酬），在得到团队批准并有人编码实现的前提下，你可以这样做。

抛开财务模式不谈，elementary OS 非常美丽。Pantheon 程序坞可轻松访问常用应用程序，且内置应用均遵循统一的设计规范。它们都用 Vala 编写，这使它们能与 GTK（或 elementary 自定义的超集，名为 Granite）轻松集成。它们没有不必要的配置选项，证明了合理的默认设置是可能的。最有趣的是，许多应用没有显式的“保存”选项。它们会随着你的操作自动保存，并重新打开到上次离开的状态。应用中心（App Center）包含一个精选程序区域（符合 elementary 设计哲学并经过团队审核）以及你在 Ubuntu 旧版软件中心（现为 Snap 商店）中能找到的所有内容。通过自定义工具 Side，Flatpaks 也开箱即用。与 Apple 的“围墙花园”方式不同，elementary 让敢于冒险的用户能够偏离精选的基地，去闯荡开源的丛林。

除了外观漂亮、使用愉悦，elementary OS 还注重隐私。入门向导（在 5.1 版本中首次推出）提供开启位置服务或自动删除临时文件（并可选项将其移至回收站）的功能。该向导在每个用户首次登录时启动（顺便一提，新的用户选择界面也很漂亮），并引导用户查看文档、夜间模式设置和应用中心。许多用户可能早已放弃电子邮件客户端，转而使用提供商基于 Web 的服务。但 elementary 的邮件程序可能恰好促使这些用户重新将收件箱本地化。

我们期待基于 Ubuntu 20.04 的 elementary OS 6.0，但团队在 6 月悄悄发布了一个点版本 5.1.5，带来了更多精妙的细节。偶尔被要求输入密码可能显得并不特别繁重，但当你每天都要面对密码提示时，这会让人疲惫不堪。Elementary 旨在通过情境认证（contextual authentication）来解决这种“认证疲劳”，即只在有意义时才要求输入密码。如果你的笔记本电脑（通常只有一人使用）在登录时要求密码，那么它就不应该在应用更新甚至安装新软件时再次询问你。同样，如果你只是查看（但不修改）防火墙设置，也不应该被提示输入密码。你可以在 GitHub 上的 https://github.com/orgs/elementary/projects/74 关注所有情境认证工作。

## 见证，漂亮的 Pop!_OS

在一篇关于漂亮发行版的专栏中，如果我们不提及 Pop!_OS，那将是我们失职之举。我们对 4 月份发布的 20.04 版本印象极其深刻（参见我们在 LXF284 中的热情评测）。Pop（除了那个尴尬的标点符号，我们喜欢它的一切）是由科罗拉多州的 Linux 系统制造商 System76 制作的。作为 OEM，他们希望能发布一款保证与其硬件兼容的操作系统。但除此之外，正如本页面提到的其他发行版一样，他们也希望用户能轻松地完成想做的任何事。Pop 的桌面更接近 Gnome 3，不同于 Mint、elementary 和 Solus 提供的风格，但请不要害怕。也不要担心最新版本以非常温和的方式让你体验平铺窗口管理器乐趣的事情。

Pop!_OS 提供两个版本：一个配备 Nvidia 专有显卡驱动程序，另一个配备开源驱动程序（用于 AMD 和 Intel 硬件）。你可以在虚拟 DVD 上找到后者，或者直接下载以节省一些字节。System76 对 Linux 贡献巨大，包括通过 fwupd 更新固件的固件管理器前端。在 Pop 中，这集成在 Gnome 设置应用程序的更新选项卡中。自然地，这不仅仅适用于 System76 硬件，还适用于任何 fwupd 支持的硬件（其中有很多）。Pop 还为多显示器和混合显卡等常见抱怨提供了一系列调整。

## 父子关系

如今的桌面发行版往往都有一个父发行版。这可能是仍在运行的（如 Ubuntu、Debian），或者是已停办的（如 Mandrake，OpenMandriva 和 Mageia 的根源在于此）。这些发行版可能是分支（拥有独立的代码库），也可能保留与父版本兼容性。Ubuntu 在技术上属于 Debian unstable 的分支，而 Mint 是 Ubuntu 的衍生版。无论如何，完全独立的发行版很少见。这就是为什么我们必须向 Solus 项目致敬。

Solus 始于 2013 年 Ikky Doberzy 的 Evolve OS。该项目的包管理器 eopkg 是土耳其发行版 Pardus Linux 的 PISI 分支（参见 LXF259 评测）。当时（Evolve 直到 2015 年才结束 alpha 阶段），大部分兴趣集中在其独特的 Budgie 桌面环境上，该环境利用 GNOME 3 的基础构建了时尚且传统的体验。由于商标冲突（甚至涉及当时的英国国务卿），Evolve 更名为 Solus，Solus 1.0 于 2015 年底发布。那时 Budgie 已获得了标志性的 Raven 侧边栏（从此不必再深入挖掘以调整音频或查看 Lenore 的约会），并积累了大量的追随者。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_14_0.png)

到 2017 年，Doberzy 宣布他将全职参与该项目，Solus 也转向滚动发布模式。团队开发了自己的工具 ferryQ，以快速向仓库部署变更。虽然并非严格的 Solus 项目，但其 Linux Steam 集成工具（强制 Steam 使用发行版库而非自身运行时中的古老版本）的工作仍在继续。Solus 的驱动管理工具发布了第一个版本，Ubuntu Budgie（该桌面环境早已在 Solus 之外可用）成为 Ubuntu 的官方口味。Ikky 在 2018 年离开项目，将其交给了能干的合作贡献者手中，剩下的，如人们所说，就是历史了。Budgie 使用半经典的 Bisku 菜单，该菜单与 Ubuntu MATE 协同设计，并且（与 elementary 的 Pantheon 一样）所有开发均使用 Vala 进行。

> 我们很难决定捕捉 Solus 哪个绝美的背景来配合 Raven 侧边栏，但猫咪图片总是赢家。

### 支持你的发行版

Elementary OS 并非免费（指免费啤酒）。它采用“乐意支付”模式，当你下载 ISO 时会被要求做出贡献。

当前 Solus 版本 4.1 提供四个版本（Budgie、Gnome、MATE 和 Plasma），并打包了一系列多媒体功能。对于游戏玩家，默认文件限制值已提高，以便使用 ESync 获得 Wine（或 Steam 的 Proton）中的更好性能。

## 寻求软件慰藉

由于 Solus 维护自己的仓库，你找不到像 Ubuntu 传统 .deb 仓库那样多的软件包。然而，Snap 已开箱即用，因此你现在可以利用 Snapcraft 商店中的许多资源。Flatpak 和 Flathub 远程源也只需两行命令即可配置。

```bash
$ sudo eopkg install flatpak flatpak-tdg-desktop-portal-gtk
$ flatpak remote-add --if-not-exists flathub
```

最终，这些将集成到基于新插件的软件中心中，eopkg 将被下一代包管理器 Sol 取代。我们期待下一个 Solus 版本，以及 Budgie 11。
