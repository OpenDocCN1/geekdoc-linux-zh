## 视频编辑器

**Shashank Sharma** 急切地想将他拍摄电影的业余尝试转化为值得称赞的杰作，于是他开始尝试各种视频编辑器。

### 我们的测试方法...

我们在配备了四核处理器和 12GB 内存的机器上，运行了本次*综述*中介绍的各工具的最新版本。除了大量的内存和处理能力以确保最佳性能外，还需要大量的剩余磁盘空间来折腾视频编辑器。

这些项目都相当流行，许多发行版都将其包含在软件仓库中。这里介绍的一些工具还提供了 Snap 和 AppImage 软件包，以便于安装。除了安装的便捷性外，文档对于帮助新用户适应这些项目中包含的最新功能集也至关重要。

我们将讨论这些工具提供的最实用的一些功能，以及它们的界面是否直观，还是在你装饰家庭视频时碍手碍脚。虽然手机摄像头很流行，但许多人仍使用专用设备来拍摄电影，因此我们还将考虑这些工具支持的不同文件格式。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_147_1.png)

无论是静态摄影还是电影录制，为了铭记日常生活中的点滴，有些人天生就懂得如何取景。他们甚至能让风中飘扬的塑料袋看起来令人着迷。只需一点点创意，付出更多的耐心，你也可以将业余的拍摄转化为专业级别的视频，如果你喜欢的话，还可以配上背景音乐。但这只有在有意愿投入时间和精力来掌握这些庞大、功能丰富的项目时才可能实现。

我们选择了那些对新手易用，但功能又足以让熟练视频编辑者感兴趣的工具。随着消费级硬件价格的不断下降，令人惊讶的是，这些资源密集型的工具在过去 15 年或更长时间里，始终受到开发人员和用户的青睐。我们列表中较年轻的应用程序 *Flowblade* 最早发布于 2011 年，而最老的 *Kdenlive* 和 *LiVES* 都始于 2002 年。

使用这些工具，你可以为视频添加特效，剪切不必要的或失焦的部分，移动元素，或者以其他方式将不同的片段拼接或合并为一个有意义的叙事。世界就是你的剪辑乐土！

# 安装

跨出第一道障碍（开启灯光）有多容易？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_148_0.png)

当你尝试安装像本次综述中介绍的那些庞大项目时，你真正会体会到 Linux 发行版中包管理工具的美感。这些工具不仅需要许多不同的第三方应用程序和库来提供许多基本功能，你还需要大量的其他库和资源。更糟糕的是，一些附加软件本身具有巨大的依赖关系。

这就是为什么像 AppImage 和 Snap 这样与发行版无关的打包格式受到许多不同应用程序开发人员的青睐。这类软件包的另一个优点是它们无需安装，使软件具有可移植性。你只需运行 `chmod +x <filename>` 命令使下载的文件可执行，即可完成设置。

Kdenlive、OpenShot 和 Shotcut 各自提供可移植的 64 位 AppImage 软件包。Kdenlive 帮助手册还描述了你可以获取 deb 或 RPM 二进制文件的不同资源，如果你更喜欢将应用程序集成到桌面环境中。

除了官方的 deb 二进制软件包外，Flowblade 不为其他流行发行版提供任何二进制文件。其网站上的下载页面建议使用软件仓库安装该项目，但也提醒你，软件仓库中并不一定总是提供最新发布的版本。幸运的是，你可以在 RPMfusion 等第三方网站上找到最新版本的 RPM 软件包。

Kdenlive 和 Shotcut 在你首次运行 AppImage 二进制文件时，会提供在菜单中创建条目的选项。

LiVES 本身不为不同发行版生成二进制软件包，但建议 Ubuntu 用户使用 PPA 进行安装。Fedora 用户同样可以在 RPMfusion 上找到最新版本的 RPM 软件包。如果你对自己的依赖项解析能力很有信心，你可以自己从源代码编译。但对于这里介绍的绝大多数项目来说，这并不明智。

安装后启动 LiVES 时，与其他工具不同，它会启动一个配置向导，检查你的系统是否已安装所有依赖项。接下来，你会被要求选择一个音频播放器，包括 pulse-audio（推荐）、jack audio、sox 或 mp layer。最后，你会被要求在两种不同的启动界面之间进行选择：片段编辑或多轨模式。

# 文档

如果没有文档，没人能“阅读故障手册”！

Flowblade 提供了关于如何使用该应用程序的简短说明，但缺乏合适的截图使得遵循这些简明的说明变得困难。更糟糕的是，说明已经过时，未能反映最近版本中引入的变更。

Kdenlive 的情况要好得多，它拥有一份详尽的用户手册，托管在 https://userbase.kde.org/Kdenlive/Manual 上。你还会找到一个讨论项目不同方面（如安装、视频特效与转场、音频）的论坛版块。用户还可以在 Kdenlive 图库论坛中分享他们自己的内容。

LiVES 用户手册首次发布于 2009 年，现在已不再那么相关，对新手也没有太大帮助。《初学者快速入门》是一个更好的选择，结合网站上文档页面的多个视频教程。你也可以在 lives-users 邮件列表中寻求帮助。

OpenShot 用户指南的每个部分都充满了该工具的有用截图。如果你已经熟悉视频编辑软件，或者甚至只是对流程有大致了解，快速教程会带你走过主要步骤。然后，你可以导航侧边栏以深入了解使用细节。托管在 openshotusers.com 上的论坛版块并不活跃，几乎一年没有新帖了。但专门用于用户推荐教程的子论坛绝对值得你花一些时间。

Shotcut 提供多种语言版本的“入门”指南，包括英语。此外，还提供涵盖多轨时间线基础等关键主题的视频教程。

# 用户体验

界面对于普通人来说是直观的，还是只对赛博迪恩 T-800 机器人有效？

无论其界面和设计哲学如何，所有视频编辑器执行的功能都类似。首先，这些工具允许你操作单个视频文件或一系列文件，并将它们排列成一个序列。在整个过程中，你可以部署不同的特效，以实现从一个片段平滑过渡到下一个片段。你还可以为视频插入标题，以提供适当的介绍。

通俗来说，一条轨道包含视频片段、特效和标题文件。这些工具使你能够同时处理多个不同的轨道，其中一条用于音频，另一条用于特效，等等。所有轨道都在称为时间线的单一界面上可见。使用这些编辑器工作的最后一部分是渲染，它将你的工作转换为选定的输出格式，如 DVD、在线发布等。

我们在寻找一种工具，能够将这些不同的任务无缝集成到一个易于导航的界面中。

### Flowblade

6/10

*Flowblade* 首次启动时呈现出一个简单的界面。虽然界面上满是按钮，但你不会感到选项过载。你无法最大化应用程序窗口，而且界面似乎在底部突然中断，但别担心，这就是应用程序界面的全部内容。

底部的时间线由一系列灰色矩形组成，你将把构成电影的画面拖放上去。

所有媒体文件都存储在 *Flowblade* 所称的“箱（bins）”中，你的项目必须至少有一个箱。要应用滤镜，你必须将其拖放到时间线上的片段上。应用程序会自动弹出一个对话框，提供有关该滤镜功能的有用信息。

撤销/重做操作的有限性以及文档的不足，是我们无法推荐 *Flowblade* 的主要原因，尽管它的界面很简洁。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_149_0.png)

### Kdenlive

9/10

在其他任何事情之前，你必须阅读 *Kdenlive* 的文档。这不仅有助于你理解 *Kdenlive* 的工作原理，也是对视频编辑的一般绝佳介绍。当然，不同的工具在工作流方面有不同的方法，但理解该过程将帮助你轻松掌握不同的工具。

最左侧的面板保存了你希望操作的不同片段。屏幕右侧保留用于监视器。*Kdenlive* 具有一个片段监视器，显示你正在操作的片段。点击项目监视器按钮，以查看完成的项目在所有特效和转场下的样子。监视器下方是时间线，你将在其中操作音频和视频文件。如果你将视频文件拖放到时间线上的音频轨道上，*Kdenlive* 会从片段中提取音频进行操作。

# 支持的文件格式

即使是电影杰作也是编码的 MP4，对吧？

至少，视频编辑器应该能够处理各种文件格式，并生成适合在不同平台（如在线发布）上出现的输出文件。

得益于对 *FFmpeg* 的依赖，我们列表中的大多数工具几乎可以处理任何视频格式，并渲染为你所需格式的文件。所有工具在完成视频编辑后，都会展示一个可滚动的大列表，列出你可以将项目导出到的格式。

使用 *Flowblade* 和其他工具，你还可以创建项目的配置文件，这取决于你希望处理的源视频文件。所有工具都能正确识别文件的来源，如果与视频文件不同，会建议更改配置文件。

*LiVES* 与其他工具的不同之处在于，它在处理不同格式时依赖于 *mplayer* 解码器。*Kdenlive* 和 *LiVES* 都支持 Firewire 输入，但此选项目前对其他工具尚不可用。

*LiVES* 的另一个有用功能是，它可以通过鼠标点击捕获外部窗口。结合它支持从外部源录制音频的功能，你可以轻松使用该应用程序创建专业级别的屏幕录制视频。

你同样可以使用 *OpenShot*，它在捕获网络摄像头馈送方面非常便捷。除了选择视频编解码器、分辨率、宽高比等之外，工具还会选择音频通道、比特率等。这些每项的默认设置因所选输出格式而异，格式可以是 Webm、Matroska、OGG、SWF 等。
