
## 自由及开放源代码软件

### 在线/离线

运行它需要互联网连接吗？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_157_0.png)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_157_1.png)

Google Drawings 仅作为在线应用程序提供，这意味着它运行在你的浏览器中。相反，Inkscape 和 LibreOffice Draw 只能在你的 PC 上本地运行。虽然有一个名为 LibreOffice Online 的应用程序，但它仅以软件形式提供，而非作为在线托管服务。另一方面，Gravit 和 Vectr 既可以在线运行也可以离线运行。严格来说，这里评测的 Gravit Designer 仅供离线使用，但同一发布者也提供了 Gravit Cloud，它提供相同的功能，但运行在云端。

这两种方法都有支持者，但与其自动倾向于某一种解决方案，不如考虑仅拥有在线方案或仅拥有离线方案的利弊。显然，如果你只有在线绘图软件，当你没有互联网连接时（比如坐在飞机上，或者不想支付 Wi-Fi 费用）就没法使用它。

你可能认为因此离线选项更好，但这只有在你手边有安装了该软件的 PC 时才是真的。对于在线软件，只要有互联网连接，你就可以在任何 PC 上工作，甚至可以在任何操作系统上运行。因此，双轨方法似乎提供了一个双赢的解决方案。这可能看似偏向 Gravit 和 Vectr，但后者情况并不那么简单，因为即使你在本地 PC 上安装了它，你也只能通过在线连接登录才能使用它——这是那些有利于发布者而非用户的功能之一。

### 结论

- GOOGLE DRAWINGS 6/10
- LIBREOFFICE DRAW* 6/10
- GRAVIT DESIGNER 10/10
- VECTR 6/10
- INKSCAPE 6/10

*Gravit 独特地提供了在线编辑和完整的离线服务，而其他软件在功能上各不相同。

### 协作

帮助你团队协作。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_157_2.png)

当你作为团队的一部分工作时，无论是在企业中还是俱乐部中，有时与他人协作是必需的。这涉及几个方面，其中一些我们此前已考虑过。即使你的协作仅仅涉及通过电子邮件来回发送文件，或通过在线文件共享服务分享文件，拥有广泛的支持基于矢量的文件格式进行导入和导出也是有用的。这可能会让你能够与使用不同软件的人进行协作。

除了 Google Drawings 之外，所有软件包都至少有一种用于导入和导出的基于矢量的格式。然而，这并不意味着 Google 不适合协作，正如我们即将看到的。

确保协作的另一种方式是要求团队所有成员使用相同的软件。然而，如果你的同事使用多种操作系统，这可能很困难。Inkscape 和 LibreOffice Draw 可以在 Windows 和 macOS 以及 Linux 下运行，Vectr 可以在 Windows 和 ChromeOS 下运行，而 Gravit 可以在所有这三种系统上运行。这个问题不适用于 Google 提供的产品，因为它是通过在线访问的。更进一步，一些软件具有特定的功能以启用协作。例如，作为在线工具，Google Drawings 允许多个用户同时在同一张图纸上工作。Vectr 表示它正在开发类似的功能，但在此期间，考虑到 Vectr 即使使用离线版本也会始终在线保存你的工作，你可以与其他用户分享你的作品。尽管 Gravit Designer 的在线版本 Gravit Cloud 存在，Gravit 在提供协作方面仍落后一步，仅表示正在考虑中。在线的 Gravit Cloud 确实使流程稍微简化，因为团队可以共享同一账户。不用说，在这种场景下，你必须确保多人不要同时尝试编辑同一个项目。

### 结论

- GOOGLE DRAWINGS 10/10
- LIBREOFFICE DRAW* 5/10
- GRAVIT DESIGNER 7/10
- VECTR 7/10
- INKSCAPE 6/10

*正如你从一款纯在线应用所期望的那样，Google Drawings 在支持协作式同时编辑方面无与伦比。

## 矢量图形

### 评测结论

最初，我们并不清楚五款产品中的哪一款会占据榜首——毕竟，它们各有优劣——但将每项测试的平均分数计算出来后，给出了一个明确的答案。请注意，虽然有三款产品的分数显示为 6/10，但它们的排序绝对是如所示的那样，因为当计算出显示小数值的精确分数时，分数都是不同的。

虽然综合分数有利于 Inkscape，它略微领先于 Gravit Designer，但它并不一定是适合所有人的最佳产品，因为不同用户有不同的需求。如果我们仅看提供的绘图功能，前两名与平均排名相同，Inkscape 是明确的领导者，Gravit Designer 第二。

然而，除非你想超越技术图表或商业图表，否则这本身不应成为你的主要考虑因素。如果你对更艺术性的用途感兴趣，高级功能将很重要，否则其他方面将变得突出。

生产力当然特别重要，尤其是对于商业用户而言。然而，易用性以及用户文档和教程的提供等方面，结合起来并没有表明该领域有明确的领导者。

许可证问题会让一些潜在用户担忧，虽然所有软件都是免费的，但只有 Inkscape 和 LibreOffice Draw 是开源的。鉴于 Gravit Designer 的免费版现在已被商业 Pro 版本加入，其免费版的未来也是一个问题。

关于生产力，同时提供在线和离线版本会有所帮助，但 Gravit Designer 和 Vectr 都提供两者，而本地安装的 Vectr 副本只能在有互联网连接的情况下使用。

协作对某些用户很重要，软件包在支持协作方面有所不同，通过支持广泛的导入和导出文件格式，并在多个操作系统上可用。在这方面，Inkscape 远远高于其他软件。

然而，就支持协作编辑的具体功能而言，Google Drawings 是明确的赢家，尽管其非常基础的绘图功能在某种程度上落后于竞争对手。

### 其他考量

对于一般用途，我们很难相信这里评测的软件包中没有一款能满足需求，但如果你确实想进一步挖掘，其他免费选项——无论是在 Linux 下运行还是通过浏览器访问——包括 Dia、Method Draw、sK1 和 SVG-edit。

如果你有非常具体的应用，例如创建流程图、组织图等，可能还有其他一些程序值得考虑。虽然这些程序的功能远不如我们在此看过的软件多，但它们现有的功能是针对其利基应用量身定制的，这使得它们更容易使用。例如，Diagramoo 自称是一个流程图程序，尽管样本展示了其他类型的块图。其他旨在用于各种类型图表应用的软件包，通常被描述为类似于 Microsoft Visio，包括 Calligra Flow、Dynamic 和 yEd Graph Editor。
