## 我们的专家

迈克·贝德福德发现自己不断被吸引回嵌入式计算领域。

**快速提示**

如果你喜欢使用 Elegoo UNO 项目基础入门套件学习嵌入式计算，并且想要了解更多，你可能会感兴趣的是，同一家公司提供了一款更高级的套件，可以教你更多知识。它被称为 Elegoo UNO 项目超级入门套件，价格大约是基础套件的倍。

单板计算机（SBC）通常呈信用卡大小或更小，如今已成为计算领域熟悉的组成部分，这在很大程度上归功于树莓派（Raspberry Pi）系列产品。树莓派催生了几家公司的类似产品，这些产品也吸引了自己的支持者，但也许不太为人知的是那些专为嵌入式应用设计的 SBC。我们在这里的目标是介绍这一类 SBC，并展示你如何使用只需几英镑就能买到的入门套件来将它们投入实际使用。

不过，首先，以防这是一个新概念，让我们描述一下我们所说的嵌入式应用是什么意思。这是一种在后台运行的应用，用户甚至可能意识不到自己正在使用计算机，以最广泛意义上的定义来说。例如，微波炉或洗衣机等家用电器通常由嵌入式软件控制。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_103_1.png)

机器人技术是嵌入式应用的绝佳例子，该示例基于 Arduino 硬件。

如果你已经深入研究过树莓派，你无疑会注意到它有几个 GPIO（通用输入输出）引脚。这些引脚可用于连接外部组件，如按钮、LED、电机、传感器等，因此可以用于控制机器人或各种其他现实世界设备。从这个意义上说，树莓派可以被视为一个嵌入式计算平台，但它与那些专门用于嵌入式用途的 SBC 有很大不同。

树莓派是一种通用 SBC；事实上，许多人用它来学习编程，完全忽略其接口功能。这种双重性质有一个重要后果：树莓派计算机运行操作系统，通常是某种 Linux 版本。相比之下，专用的嵌入式 SBC 通常不运行操作系统。

缺乏操作系统可能看起来是一个严重的缺点，但对于嵌入式应用来说，这是一个优势。如果你使用 SBC 只是为了了解嵌入式计算，树莓派的方法效果很好，但如果你想在真实应用中使用 SBC，操作系统是你没有的开销。也许操作系统的主要缺点是启动所需的时间。我们可以想象，如果你必须等待 30 秒让 Ubuntu 启动才能开车，汽车就不会太受欢迎。它还对所需硬件的数量有影响。许多嵌入式应用使用比运行操作系统所需处理器弱得多的处理器也能完美工作。不仅仅是处理器——通常嵌入式应用不需要任何图形硬件，而且通常不需要 Wi-Fi 或以太网等众多接口。这不仅具有成本效益，还降低了功耗，这对于电池供电设备是一个主要优势。

## 介绍 Arduino

在无人机、电视遥控器或食物处理器里，你很少能找到现成的 SBC。相反，为了最小化此类大批量产品的成本并减小尺寸，计算硬件通常被整合到定制设计的电路板上，与其他所有电子电路一起。然而，对于小批量的 DIY 应用，特别是为了在不被操作系统阻碍的情况下学习嵌入式计算，专用的嵌入式 SBC 非常合理。这正是 Arduino 板大放异彩的地方。

树莓派和类似的 SBC 通常围绕某种 Arm 处理器构建。相比之下，许多 Arduino 板基于 Microchip 的 ATmega328。分离它们的不仅仅是名称，几个数字就会揭示这一点。Pi 类型板上的处理器具有 32 位或 64 位架构，通常有两、四或八个核心，时钟频率通常在 1GHz 到 1.8GHz 之间。ATmega328 具有 8 位架构、单个核心，时钟速度通常仅为 16MHz。

内存和存储方面的差异同样巨大。Arduino 板通常拥有 32KB 闪存用于程序，以及几 KB 的 RAM 和用户存储，以及相似数量的非易失性 EEPROM。对于不需要支持操作系统的嵌入式应用，你可能会惊讶于使用如此看似简陋的规格能做什么。

最后，在转到稍微更实际的内容之前，我们需要说明当谈论 Arduino 时我们的意思。Arduino 是为教育用途在意大利的 Isera 交互设计研究所开发的。官方 Arduino 板——有几种——可在 www.arduino.cc 获取。该设计是开源的，几家公司生产了兼容的设计。这些不应该被称为 Arduino 板，因为该名称已注册，尽管第三方可以称其为“Arduino 兼容”；几家公司使用以“duino”或类似后缀结尾的名称来强调这一点。

通常，第三方设计比 Arduino 出售的更便宜。市场上也有一些看起来与 Arduino 产品完全相同的板，但非法使用 Arduino 名称和标志——应避免这些。哦，还有关于“Arduino 兼容”短语含义的简短说明：底线是，不同的制造商可能用它来表示不同的含义，因此如果兼容性很重要，请仔细阅读相关资料。在软件层面，这意味着它将与 Arduino IDE 一起工作——这是你在单独 PC 上开发代码并将其上传到 Arduino 之前使用的集成开发环境。大多数兼容品提供这种级别的支持。在硬件层面，对兼容性的最常见理解是 I/O 引脚兼容，因此板子可以与 Arduino 盾牌（shield）一起使用：在树莓派世界中大致相当于 HAT 的附加板。大多数所谓的兼容品也提供这种级别的兼容性，但已有关于少数不提供的报告。

### Arduino IDE

由于 Arduino 类型板不运行操作系统，而且它们不容易连接键盘、鼠标和显示屏，软件在单独的 PC 上开发，然后下载到 Arduino。最简单的做法是使用 Arduino IDE，它适用于所有主要操作系统，但请注意它在 Java 下运行，因此如果你的 PC 上尚未安装 Java，你需要安装它。与许多 IDE 一样，Arduino 的 IDE 提供了代码开发所需的所有工具。特别是，它包括一个文本编辑器，你可以在其中创建和修改源代码；一个编译器和链接器；以及将编译后的代码下载到 Arduino 板的方法。因为所有第三方 Arduino 兼容板

### 代码调试

我们有一些好消息和一些坏消息。好消息是，你将要编写的许多控制应用程序的软件——至少最初——不会非常复杂，因此引入编程错误的可能性低于许多编码任务。坏消息是，如果你的软件出错，调试在 Arduino SBC 上运行的代码很棘手。特别是，标准 IDE 不提供设置断点、单步执行、读取内存位置等功能。

然而，可能的做法是利用 SBC 和 PC 之间的 USB 连接——用于向 Arduino 下载代码的同一连接——将数据传输回 IDE。这需要在代码中添加专门用于调试的指令。通常你会使用 serial.write() 或 serial.print() 指令将调试数据——例如内存位置的值——输出到串行端口，前提是你已经使用 serial.begin() 初始化了该端口。然后你可以利用 IDE 的串行监视器功能检查 sketch 所写入的内容。

请记住，连接到板子输入/输出引脚的电子电路中的错误往往才是问题所在。许多用户报告硬件错误比软件错误更常见。
