

## 音频和视频

对视频进行细致入微的编辑，并整理你的音乐库。

### UMS

这款流媒体服务器将把你的 Linux 桌面终极化，使其成为向其他计算机、智能手机、平板电脑、游戏机甚至电视广播媒体的终极媒体流站。UMS 通过通用即插即用 (UPnP) 协议向任何符合 DLNA 标准的设备流式传输媒体。你需要部署 UMS，尽管过程相当简单。

首次启动时，UMS 会引导你完成一个基础的三步配置向导。虽然你可以在没有进一步配置的情况下开始流媒体传输，但 UMS 确实包含一个管理面板，提供可自定义的选项和提示来引导新用户。它还包括一个极简的 Web 界面用于流式传输你的内容。 [www.universalmcidaserver.com](http://www.universalmcidaserver.com)

### EMBY

这是一个功能全面的媒体服务器，包含大量功能。Emby 是在任何设备上访问和查看你所有媒体的一站式商店：从其他计算机和移动平台到 Android TV、Chromecast、Roku、Xbox 等。除了本地文件夹外，Emby 允许你添加网络共享，如果你的媒体位于网络中的不同计算机上，这将是一个极大的省时功能。Emby 服务器提供预打包的二进制文件，其网站上有适用于所有流行发行版（包括 Arch、CentOS、Fedora 和 Ubuntu）的安装说明。你可以右键点击项目以显示有用的选项，例如下载它们、将它们添加到播放列表和集合中、转换它们或编辑其元数据。你可以在播放过程中更改流媒体质量并显示全屏。Emby 还允许你设置家长控制，你可以阻止评级高于你定义的最大值的项目。 [https://emby.media](https://emby.media)

### MPV

一款资源意识型视频播放器，在现代机器上同样表现出色。基于 mplayer2，MPV 通过引入优化和清理后的代码以及新的配置选项和功能，延续了命令行界面（CLI）的传统。它提供一个极简的用户界面，不会打扰你，让你可以安心观看视频。 [https://mpv.io](https://mpv.io)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_168_0.png)

### SHOTCUT

Shotcut 是一款相当先进的视频编辑器，是少数支持编辑 4K 视频的工具之一。该程序支持多种音频和视频格式以及各种过渡和效果。它拥有一份令人印象深刻功能清单和一个视频教程集合，以帮助首次接触的用户熟悉操作。 [https://shotcut.org](https://shotcut.org)

### CURLIEW

由 ffmpeg 库提供支持，Curliew 是一个易于使用的媒体转换器。它具有裁剪和填充视频的能力，并且可以只转换文件的指定部分。选择其预设置之一，用于各种设备和格式，你还可以在转换前预览文件。 [https://curliew.sourceforge.io](https://curliew.sourceforge.io)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_168_1.png)

### AIRSONIC (35)

基于现已停止开发并转为闭源的项目，Airsonic 音频流媒体播放器让你的音乐无处不在。它支持即时转换，并能够同时向多个播放器流式传输几乎任何格式的文件。 [https://airsonic.github.io](https://airsonic.github.io)

### TUPITUBE

TupiTube 是一套鼓励儿童创建 2D 动画的工具，拥有一个易于使用的界面，功能数量恰到好处，并配有大量文本和视频文档帮助入门。 [www.maofloresta.com](http://www.maofloresta.com)

### PICARD

Picard 是一个小巧而精细的工具，能让你的音乐收藏恢复整齐。该程序可以整理你的音乐库，填充缺失的标签，重命名命名混乱的文件，并识别不完整的专辑。 [https://picard.musicbrainz.org](https://picard.musicbrainz.org)

### TRAVERSO DAW

一个强大的音频录制和编辑平台。Traverso 是一个数字音频工作站工具，可以从创建简单录音到编辑多轨音频无所不能。 [https://traverso-daw.org](https://traverso-daw.org)

### MIXXX

如果你需要在活动中担任 DJ，使用 mixxx 浏览你的音乐库，并使用其可抓动的波形来循环节拍，调整音轨的节奏和改变音高以创建你自己的混音。 [www.mixxx.org](http://www.mixxx.org)

## 磁盘工具

保持你的硬盘处于最佳状态，恢复丢失的数据或安全地删除它。

### FOG

不间断地执行重复任务，如运行检查、排查错误、更换故障硬盘、一遍又一遍地进行全新安装，这会耗尽任何系统管理员的精力，无论其网络规模大小。使用 *FOG*，你可以从管理中心的舒适环境中对机器进行镜像和克隆。

*FOG* 是一个复杂的软件，提供大量选项，具有各种字段来描述主机镜像。它还可以将它们分组以便于管理。还有几个选项用于安排镜像过程。*FOG* 还可以用于调试镜像过的计算机，远程擦除主机等。服务器还处理常规管理任务，如安装软件，甚至可以管理网络中的打印机。*FOG* 服务器具有可扩展性，可以管理分布在同一建筑物内或地球另一端的大网络。*FOG* 服务器最有用的功能之一，尤其对于较大网络的管理员来说，是组播能力。使用此功能，你可以一次部署多台机器。为了在这样的大网络上补充它，你可以配置多个 *FOG* 安装作为存储服务器，以帮助在对计算机进行镜像时减轻主 *FOG* 服务器的负载。 [https://fogproject.org](https://fogproject.org)

### DUPLICATI

一款易于使用的备份应用程序，*Duplicati* 允许你通过定义过滤器或切换预定义选项来排除特定类型的文件，从而精细调整你想要保留的位置列表。你可以通过基于浏览器的界面管理该工具。该程序将关键任务分解为向导，并恰好提供手头工作需要数量的功能，而高级选项只需拉下一个菜单即可到达。文件使用 AES-256 加密，你也可以在将备份发送到目的地之前使用 GPG。*Duplicati* 还会在加密之前压缩所有数据。它支持 Zip 和 7Z 压缩，并且可以跳过对已压缩文件（如 MP3 和 JPG）的压缩。 [www.duplicati.com](http://www.duplicati.com)

### PHOTOREC

*Photorec* 是一个巧妙的基于命令行的小工具，可以恢复意外删除的文件。当你删除一个文件时，文件系统只是将其标记为已删除，并使该文件占据的空间可供其他文件使用。*Photorec* 的工作原理是恢复那些缺少常规元数据（如文件名）的文件。尽管名为 Photorec，但该命令行工具可以嗅探各种格式的文件。 [www.cgsecurity.org/wiki/PhotoRec](http://www.cgsecurity.org/wiki/PhotoRec)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_169_0.png)

Photorec 几乎每个恢复发行版的一部分，并随 TestDisk 一起分发。

### GPARTED

这是管理分区的最佳图形化工具之一，你可以使用 *GParted* 创建、删除、调整大小、移动和复制分区，同时保留其中存储的数据。该程序适用于各种硬盘、SSD 和 RAID 设备，并支持所有流行的文件系统。 [https://gparted.org](https://gparted.org)

### SECURE-DELETE

secure-delete 软件包包含各种实用工具，用于安全地删除文件并清除磁盘空闲空间中数据的所有痕迹。有 *shred* 使任何已删除的文件无法恢复，*sfill* 用于清除磁盘空闲空间中的所有数据，以及 *sswap* 用于清除交换分区中的数据。 [https://smr.sourceforge.net](https://smr.sourceforge.net)

### CDEMU

*CDEmu* 工具允许你挂载各种格式的磁盘镜像，包括 ISO、bin 和 img。*CL 工具* 还针对 Gnome 和 KDE 桌面环境提供了多个图形前端。 [https://cdemo.sourceforge.io](https://cdemo.sourceforge.io)

### DUC

如果你想释放一些磁盘空间，首先使用 *Duc* 来更好地了解占用空间的文件。该工具在检查硬盘方面比文件管理器做得更好。 [https://duc.zew.nl](https://duc.zew.nl)

### DDRESUE

在尝试恢复之前，先尝试使用 *ddrescue* 对故障驱动器进行镜像。该实用工具不会向坏扇区写入零，并试图在不覆盖已恢复数据的情况下填补空白。 [www.gnu.org/software/ddrescue](http://www.gnu.org/software/ddrescue)

### PYDF

作为 *df* 的替代，*pydf* 是一个高亮显示不同文件系统类型的 Python 脚本。它有一组大量可配置的参数和各种选项来控制其输出。 [https://pypi.org/project/pydf](https://pypi.org/project/pydf)

### SMARTCTL

作为 smartmontools 软件包的一部分附带，*smartctl* 实用工具控制和监控内置于硬盘中的 SMART 系统。定期使用该工具对磁盘运行自检健康检查。 [www.smartmontools.org](http://www.smartmontools.org)
