
# 安全特性

防御互联网上的诸多风险。

本综述中介绍的所有应用程序都提供了不同的工具和解决方案，以保护您的隐私、社区以及您的机器安全。除了默认设置外，大多数应用程序还提供额外的机制，借助插件来保护您。

在使用 Evolution、KMail 和 Claws 时，您可以选择使用 Bogofilter 或 SpamAssassin 来检测和清除垃圾邮件。对于 Claws，核心软件包包含几个有用的插件，其中包括 Bogofilter，但如果您使用发行版管理软件管理工具安装了它，则必须额外安装 claws-mail-plugins 软件包。

KMail 的反垃圾邮件和反病毒向导可帮助您配置相应的工具。您必须已经安装了处理这些操作的工具，例如 Bogofilter 或 ClamAV。如果未找到任何工具，向导仅会告知您此情况。它不会推荐任何工具。一些用户报告说向导在检测其反病毒工具时存在问题。更糟糕的是，当与反病毒实用程序连接时，KMail 的性能明显变慢，因为每条消息都会进行病毒扫描。

Thunderbird 拥有高级垃圾邮件过滤器，它会根据您标记为垃圾邮件的内容学习和改进其过滤效果。所有传入消息都会通过该过滤器，您可以让 Thunderbird 在潜在的网络钓鱼邮件以及消息中的链接将您引向与 URL 中指示的不同的网站时发出警告。

除了 MailSpring 之外，所有客户端都可以配置为通过流行的 GnuPG 实用程序与垃圾邮件检测和加密功能协同工作。

# 其他特性

它会为你做早餐吗？

除了网页浏览器，电子邮件应用程序是桌面环境中最具辨识度的组件之一。

电子邮件最初只是与联系人轻松沟通的手段，现在已经扩展为拥有庞大功能集的大型项目。并非所有用户都希望他们的电子邮件客户端设置提醒并充当日历。但如果这些是您每天使用的功能，最好使用单一工具，而不是多个工具。

Evolution 是 GNOME 的官方个人信息管理器 (PIM)，提供日历、通讯录和任务管理器。如果您在 KDE 桌面上运行，也可以在 KMail 中获得相同的功能，它可以与其他知名的 KDE 组件（如 Kontact 和 Korganizer）连接。

如果您经常通过电子邮件与非英语使用者合作，您将欣赏 MailSpring 将英文消息翻译成西班牙文、俄文、简体中文、法文和德文的能力。它可以自动检测您的语言，并在不改变语言设置的情况下执行拼写检查。它还专门针对触控设备进行了优化，支持许多可配置的手势，如向左或向右滑动。

与其他工具不同，Thunderbird 还可以连接各种服务的聊天账户，使一个应用程序即可记录您与所有联系人的所有通信。其多渠道聊天支持的优势在于，您可以使用搜索功能回顾与所有联系人的过往对话和邮件。如果您确实需要在网络上进行搜索，您可以在应用程序本身的搜索栏中进行，而不是切换到网页浏览器，甚至可以选择您想使用的搜索引擎。

Claws 开箱即用的功能不多，但您可以借助插件获得几乎相同的功能。它可以轻松地充当新闻聚合器，管理预约等。Evolution 和 Thunderbird 比其他应用程序消耗更多资源。如果您决定将这些应用程序用于电子邮件以外的用途，这一点需要考虑。

# 电子邮件客户端：最终评价

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_124_0.png)

**M**ailspring 是本 *Roundup* 中最年轻的工具。其他工具在过去几年里都受到了广泛的报道，我们当然也在过去几页中详细讨论过它们。与我们的 *Roundups* 传统不同，我们通常会花一些时间概述优胜者的优缺点，但这次我们将花更多时间谈论最后一名，而不是其他所有工具。这是因为我们很少遇到如此让我们印象深刻的软件。同时，一些流行的选择以及缺乏对提供关键功能的兴趣，也使其成为 *Roundup* 中最令人失望的工具之一。

仅凭不同测试中的得分，你可以看到 *Mailspring* 仅在插件和安全功能方面落后于其他工具。在当今时代，一个不能加密消息或提供过滤垃圾邮件手段的电子邮件应用程序是不可想象的。这就是 *Mailspring* 排名最后的原因。除此之外，该工具迅捷的性能让我们震惊。它的搜索功能、快速配置和几乎即时的启动是您必须亲自体验的，因为言语无法公正地描述它。尽管该项目依赖通过付费专业版获取资金，但它仍为免费用户提供了对其部分最佳功能（如送达通知）的有限访问，这备受赞赏。诚然，其中一些功能（如送达通知）也可在 *Thunderbird* 上获得，但与我们在 Budgie 安装中的 *Mailspring* 相比，它没有如此完美地融入桌面，后者会通过弹出窗口告知我们何时有人读取了邮件，或何时有人访问了我们分享的链接。

自 **LXFLS1** 中我们查看 *KMail* 以来，它已经做出了惊人的改进，配置新账户现在相当容易。不幸的是，*Claws Mail* 仍然远未达到 *Thunderbird* 和 *Evolution* 的简洁程度。话虽如此，*Claws Mail* 没有任何问题，如果您受限于低规格机器，我们不会推荐其他任何工具。*Evolution* 是紧随其后的第二名，但 *Thunderbird* 凭借其默认功能、搜索流程和众多扩展功能胜出。

- **1 名 Thunderbird** 10/10
  - 网络: www.thunderbird.net
  - 许可证: GPL 及其他 版本: 60.0
  - 应向 *Mailspring* 寻求灵感。
- **2 名 Evolution** 9/10
  - 网络: https://wiki.gnome.org/Apps/Evolution
  - 许可证: GPL 及其他 版本: 3.28
  - 需要改进账户设置流程。
- **3 名 KMail** 8/10
  - 网络: http://userbase.kde.org/KMail
  - 许可证: GPLv3 版本: 5.73
  - 可以从 *Thunderbird* 和 *Mailspring* 中吸取一些技巧。
- **4 名 Claws Mail** 7/10
  - 网络: www.claws-mail.org
  - 许可证: GPLv3 版本: 3.16
  - 新账户设置和文档是其弱点。
- **5 名 Mailspring** 5/10
  - 网络: https://getmailspring.com
  - 许可证: GPLv3 版本: 1.4.2
  - 需要尽快添加加密和垃圾邮件过滤支持！

### 其他考虑

通常情况下，我们将本月的 *Roundup* 限定为图形应用程序。在我们转向命令行替代方案之前，仍有一些图形应用程序必须提及。如果您喜欢 *Claws Mail*，那么您还应该关注 *Sylpheed*，因为 *Claws* 是 2005 年从它分叉出来的。有趣的是，这两个工具的功能集几乎相同。Gnome 用户也可以尝试 *Geary*，但它没有 *Evolution* 功能丰富。

如果您感到怀旧，记得 *Netscape* 的日子，*Seamonkey Mail* 是一个可行的替代方案，并提供了与其他工具相同的所有有用功能，如垃圾邮件检测和消息过滤。还有 *Mutt*，这是一个非常强大的邮件客户端。您需要安装和配置其他命令行实用程序（如 *Procmail*）来过滤消息。*Alpine* 是另一个控制台应用程序，类似于 *Mutt*，但设计得对初学者更友好。
