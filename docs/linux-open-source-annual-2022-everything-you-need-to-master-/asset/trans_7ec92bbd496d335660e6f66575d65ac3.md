一旦拥有最新版本的 Nextcloud，开发人员建议在你的 Web 服务器上设置几个请求头。例如，在 Apache 上，应将以下内容添加到你的站点配置中：

- **Header set X-Frame-Options sameorigin**
- **Header set X-Content-Type-Options nosniff**

第一行将阻止现代浏览器在框架中加载该网站，除非它来自同一 Web 服务器。第二行防止 MIME 类型嗅探，并防止使用外部 CSS 和 JavaScript 资源，如果它们未以正确的 text/html MIME 类型提供服务。此类请求会被阻止，且该选项还会阻止 HTML、文本、XML 和 JavaScript 资源从外部加载。有关加固请求头的更多信息，请访问 OWASP（开放 Web 应用程序安全项目）基金会在 www.owasp.org/index.php/OWASP_Secure_Headers_Project#tab=Headers 上关于该主题的深入介绍。

来自你可信服务器的目的地。如果你希望在家中这样做，IPRFire 只需几次点击即可设置好。你也可以订阅商业 VPN 服务，但尽管你会发现许多提供最佳 VPN 提供商列表的精美赞助文章，实际上并没有充分的理由信任这些实体——即使那些拥有非常华丽网站的公司也是如此。毕竟，你赋予了它们完全访问你所有连接数据的权限。如果你的目标仅仅是向 ISP 隐藏这些数据，或者绕过他们实施的封锁，那没问题，但请考虑一下他们最初封锁这些材料的原因，以及绕过该封锁是否构成违法。

## 是否启用 OTP

如果你想在自己的应用程序中使用 YubiKey，并向受信任的用户直接发放物理密钥，请查看开发人员指南：https://developers.yubico.com/OTP。YubiCloud 服务为 YubiKey 提供免费身份验证（YubiKey 出厂即设置为 OTP 模式），但他们也提供开源软件，让你可以托管自己的身份验证服务器，符合去中心化的精神。YubiKey 随附其独特的 AES 密钥，这使得它们可以由 YubiCloud（持有该密钥副本）进行验证。在本地，对称密钥被锁定在硬件中，虽然它对软件不可见，但仍可更改。

如果你进行自己的身份验证，这没什么问题，但即使你可以将新密钥注册到 YubiCloud，由于新生成的密钥在生成过程中有可能被拦截，信任级别并未完全恢复。因此，一些服务不信任密钥已被更改的 YubiKey 发出的 OTP 响应。你现在应该能够在 https://demo.yubico.com/otp/verify 测试你的 OTP 设置。正如该网站提到的，使用硬件令牌作为单因素身份验证机制并不明智，因为如果被窃取，其访问的所有内容都可能被泄露。

## 小心勒索软件

Jonni Bidwell 知道许多不该做的事，包括如何不支付赎金以及如何不被社会工程骗局蒙骗……

我们仍在耐心等待“Linux 桌面年”，但 Linux 成为主流的一个迹象是，它现在正积极地被恶意软件推广者针对。也许不如 Windows 那么严重，也许那些小生物更感兴趣的是攻击服务器而非桌面，但继续吹嘘“Linux 不会感染病毒”并不能造就可信的新闻报道。（不要使用 J 这个词！– 编辑）

Linux 服务器经常被入侵。对于普通的脚本小子来说，在 Metasploit 中找到他们最喜欢的利用漏洞，通过 Shodan.io 找到一些易受攻击的服务器并制造混乱，这也太容易了。攻击桌面 Linux 稍显微妙，但这并不意味着它不会发生。流氓网站可能会提供路过式下载，合法网站可能会被黑客入侵，或者内核中的长期存在的 bug 可能会被发现。所有这些都可能导致你的数据终结。

然而，更大的威胁是社会工程学。这基本上与操作系统无关——它依赖于人性中的弱点，而非软件中的弱点——因此，即使你使用其他操作系统，也有一些技巧可以帮助到你。一封精心制作的邮件可能会诱骗疲惫的目标打开错误的文件类型，披露他们的密码（或其他个人信息），甚至向陌生人汇钱。其中一些骗局很容易发现，但另一些则不然。在过去五年中，网络犯罪分子（我们承诺不会过多使用这个前缀）已经意识到人们关心他们的文件，因此一种常见的作案手法是加密文件并以此勒索。受害者通常被“邀请”支付赎金，通常以加密货币支付，以获取解密密钥，但往往从未提供该密钥。有时勒索软件考虑不周，专家可以逆向工程所使用的加密方式并提供免费的解密工具。但你不应指望这一点。相反，请遵循我们的指南——保持坚强，保持警惕并行为端正。

## 勒索与欺骗

骗子们发现你的数据对你来说比对他们更有价值。不要让他们利用这一事实。

尽管我们不久前做了一期关于恶意软件的封面故事（LXF251），但我们尖端状态的分析引擎（即 *我* – 编辑）告诉我们，你希望听到更多关于某类特定恶意软件——勒索软件——以及一种特定投递手段——社会工程学——的细节。

扣押物品以索取赎金是一个古老的想法，并且已被证明非常有效。自古以来，国王、贵族和珍贵的艺术品就曾被勒索。同样，使用花言巧语欺骗人们去做他们可能不应该做的事情——如果可以的话，称之为诈骗。但在数字时代，这些做法呈现出全新的、阴险的维度。表面上看，文件被扣押与家庭成员被绑架完全不在同一级别。但如果人们的生活依赖于这些文件的完整性呢？令人恐惧的是，这种情况已不止一次发生。

2017 年的 WannaCry 勒索软件爆发感染了 150 个国家的大约 30 万台计算机——根据资深安全研究员 Mikko Hypponen 的说法，这是“历史上最大的勒索软件爆发”。人们到达工作岗位时，迎接他们的是计算机要求支付相当于 300 至 600 美元的比特币以解密其文件。在英国，这使我们的（已经举步维艰——不包括威尔士）国家医疗服务体系（NHS）陷入瘫痪。患者看到手术被取消，并被建议仅在紧急情况下寻求医疗护理。失去网络和电话访问权限的员工不得不求助于手动方法来提供关键的医疗服务。

评论人士很快指出，NHS 拥有并仍然拥有许多运行 Windows XP 的机器；但这些并不是真正的问题——其中大多数是嵌入式安装，无法升级，甚至没有连接到网络。问题在于大量未打补丁的 Windows 7/8/2000 系统，这些系统易受 SMB 协议中一个 bug 的攻击，事实证明，NSA 早就知道这一点。事实上，NSA 已经将所述 bug 武器化，供其定制的访问操作单元使用，并将该漏洞命名为 EternalBlue。

不幸的是，该漏洞落入一个名为 Shadow Brokers 的黑客团体手中。NSA 警告微软可能的窃取事件，并在 2017 年 3 月发布了补丁。2017 年 4 月，EternalBlue 与其他 NSA 漏洞（名为 EternalChampion 和 EternalRomance）一起被 Shadow Brokers 泄露，一个月后，由于许多系统仍未打补丁，WannaCry 利用它在全球范围内制造混乱。请参阅后文的方框了解更多关于 WannaCry 结构的信息。

我们很想说有一些神奇的开源工具，只需一点命令行魔力就能帮助你从任何勒索软件攻击中恢复，但事实并非如此。而且将来也不会。不过，有几件事肯定对你有帮助，这些都是每个人都应该练习的技能。

### 付钱，否则数据就没了

一些知名机构支付了赎金，除非我们集体的安全意识提高，否则我们可能会看到更多此类事件。拥有松懈安全实践的大型机构（不应该，但可能会）因员工落入电子邮件骗局而陷入瘫痪。这可能是一种未定向的攻击，其中勒索软件操作者预期目标是不知情的家庭用户，在这种情况下，要价相当低廉。或者，它可能是某种鱼叉式钓鱼活动，针对高管或系统管理员，以便掠夺他们的权限或资金充裕的银行账户。如果你打算瘫痪一家大型机构，你可能要的就不止是零钱。

今年六月，佛罗里达州 Riviera Beach 市议会同意在系统瘫痪后向黑客支付 600,000 美元（65 BTC）的赎金。他们加入了越来越多的机构行列，这些机构选择支付六位数的金额以恢复关键服务。SentinelOne 在 2018 年的一份报告调查了大约 500 家大型机构，发现其中遭受勒索软件攻击的机构中，45% 支付了赎金，但其中只有 26% 解开了文件锁。所谓“劫匪间的荣誉”，由此可见一斑。
