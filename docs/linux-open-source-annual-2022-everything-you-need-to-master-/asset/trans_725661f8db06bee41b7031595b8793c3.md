
## 自由开源软件 (FOSS)

新功能（以及更多的 bug 修复）正不断被添加，因此请访问该项目的 GitHub 仓库：https://github.com/scummvm/scummvm。

2002 年，LucasArts 向 ScummVM 团队发送了停止侵权函，但最终（这一过程耗时约四年），双方达成了一项协议，允许项目继续开发。此后，引擎重实现开始被视为一种不侵犯版权的活动，与版权所有者的后续对话也 largely 持积极态度。Revolution Software 和 Adventure Soft 甚至提供了源代码，以帮助支持其游戏所使用的引擎。《神秘岛》三部曲 25 周年特别版中有三分之二的游戏由 ScummVM 驱动（《神秘岛 III》则由 ResidualVM 驱动，ResidualVM 重新实现了其 Springtime 引擎，以及 Grim E——这是用于《猴岛的小魔怪》和《格里姆传奇》的 SCUMM 继任者）。你可以在 www.pcgamer.com/how-scummvm-is-keeping-adventure-games-alive-one-old-game-at-a-time 上阅读更多关于 ScummVM 的内容。

正如你可能想象的那样，重新分发商业游戏的资产通常是非法的。上一页的方框中提供了更多细节，但简而言之，你最好避免从随机网站下载任何东西。早在 2018 年 7 月，流行的模拟网站 LoveROMs 和 LoveRETRO 就遭遇了来自任天堂可能非常昂贵的诉讼。受这些法律行动的影响，著名的 EmuParadise (www.emuparadise.me) 移除了其网站上所有的下载链接。

许多游戏被称为“废弃软件”（abandonware），指它们不再由原始制造商销售或支持。然而，这个术语并不提供任何法律保护：版权持有者可能采取实用主义态度，选择不关心侵权行为，甚至如果足够多的人礼貌地请求，他们可能会免费提供这些游戏。或者，它们可能像任天堂那样，专门有一个页面来说明如果你不尊重其财产，他们会如何严惩你 (www.nintendo.com/corp/legal.jsp)。

## 香料必须流动

对于 OpenRA（经典《命令与征服》(CnC) 引擎的重新实现）来说，情况更加令人 melancholic（忧郁/哀愁）。为了庆祝原始《命令与征服》（在某些圈子中被称为《泰伯利亚的黎明》）发布 12 周年，EA 在 2007 年将原始 ISO 文件作为免费软件发布。为了庆祝下一个周年纪念日（同时也是《红色警戒 3》的发布），EA 在 2008 年将原始的《红色警戒》和《泰伯利亚之日》ISO 文件作为免费软件发布。EA 不再托管这些文件，但表示很高兴让其他人重新分发它们。因此，如果你没有原始安装介质，OpenRA 可以查找并下载玩这三个游戏所需的所有文件（除了音乐和视频过场动画）。在 OpenRA 的术语中，引擎复活的游戏被称为模组（mods）。OpenRA 项目已采用新的打包格式，你可以直接从 www.openra.net 下载官方模组的近似版本。这些下载有两种版本：稳定版和试玩版。后者是包含最新引擎开发进展的预览版，因此可能不如前者稳定。

除了官方模组外，还有许多社区提供的资源（参见 www.moddb.com/games/openra/mods）。目前正在进行工作，将 OpenRA 引擎与其驱动的官方 CnC 模组解耦，使其可以作为一个通用的即时战略引擎使用。该项目已经提供了地图编辑器和源代码开发套件 (SDK) 等工具，以帮助新兴开发者构建他们战争梦想中的游戏。读者可能还记得 90 年代后期的《崩溃：杀死与摧毁》游戏。这些读者可能会欣喜地得知，目前正在使用 OpenRA 引擎复活这些核战后的标题方面开展工作。

另一个相关项目是 CnCN，自 2009 年以来一直存在。他们提供启动器，使 CnC 系列（包括所有扩展和模组）能够像粉丝们记忆中的那样完美运行，并额外增加了在线游戏功能。最近，它用 GDI（用于较新版本的 Windows）和 OpenGL（用于 Wine 用户）补充了 CnC 的 DirectDraw 渲染器。CnCN 支持免费发布的标题，以及《泰伯利亚之日》（OpenRA 正在开发中）、《红色警戒 2》和《尤里的复仇》。Linux 软件包（适用于 Fedora、Debian、Ubuntu 甚至 Arch 及其衍生版）可用于免费的 CnC 标题。这些只是设置合适的 Wine 前置条件并下载游戏文件和 CnCN 启动器的脚本。

CnCN 支持的其他标题只能通过 EA 的 Origin 平台获得，作为《命令与征服终极集合》（售价 25 英镑）的一部分，但让 Wine 和 Origin 友好合作可能有些棘手。对于这些游戏，你最好寻找光学介质，CnCN 启动器非常乐意支持。

原始的 Westwood Online 服务器在 2005 年过渡到了由社区运营、EA 赞助的 XWIS 服务器，该服务器至今仍活跃。较新的 CnC 标题运行在 GameSpy 服务器上，这些服务器在 2014 年关闭。这次关闭影响了大量标题，其中许多转移到了其他网络。CnC 标题转移到了 C&C:Online (https://cnc-online.net)，在那里它们至今仍生机勃勃。

## 直到暮色降临 (Morrowind)

《晨风》是 Bethesda 备受赞誉的《上古卷轴》RPG 系列的第三部作品，于 2002 年发布。其广阔的开放世界由 Gamebryo 引擎驱动，该引擎已被 OpenMW 重新实现。

除了修复长期存在的 bug（《晨风》在 2003 年收到了最后一个官方补丁），该引擎还添加了新功能，当然，它还能让游戏在 Linux 上原生运行。需要原始游戏资产，但这没问题，因为你可以从 **gog.com** 以 13 英镑的价格获得一份无 DRM 的《晨风》（全价年度游戏版）。它经常有特价优惠，所以如果你手头紧，把它加入你的愿望清单。

*OpenMW* 通过渲染远处的地形（增加了原始游戏的绘制距离，这原本会严重降低性能）、使用 TrueType 字体以及支持 FFmpeg 支持的所有多媒体格式，使原始游戏现代化。原始《晨风》的一些第三方模组可以在 *OpenMW* 上工作，但这目前并不是该项目的严格目标。许多模组依赖于原始引擎中的 bug 或对未记录怪癖的假设。

*OpenMW* 还附带 *OpenMW-CS*，这使得用户能够创建自己的资产：角色、地图、任务……应有尽有。这使得有抱负的用户可以基于 *OpenMW* 创建完整的游戏。熟练的 3D 雕刻师可以使用 Blender 创建龙和地牢杂物的模型，并使用 NIF（许多其他游戏使用的专有格式）或 OSQ（*OpenMW* 自己的开放格式）插件进行导出。

还有许多其他我们没有机会讨论的开源游戏引擎（如果某人没有把全部时间都花在玩 *红色警戒* 而不是写这篇文章，我们可能会讨论一下 – 编辑语）。查看 **https://osgamemclones.com** 上令人印象深刻的列表。但为了怀旧，我们要向 Freezerf (**https://github.com/freezerf/freezerf**) 致敬，它使得（再次配合原始数据文件）可以玩 1993 年的经典中世纪王国模拟游戏 *The Settlers*。读者们，如果您发现任何通过开源的魔力而复活的童年经典，请让我们知道（但不要告诉 Jonni，因为他被像素化的事物和老笑话分心了 – 编辑语）。

## » 但它可以运行 DOOM 吗？

在各种从未打算运行 Doom 的硬件上运行共享ware 经典 **Doom** 已成为一种传统（参见例如 **www.gamesradar.com/12-things-that-prove-that-doom-will-run-on-literally-anything**）。然而，这种愚蠢的大部分是通过 **Doom** 引擎的许多重新工作实现的，id Software 在 1997 年发布了其源代码（可在 **https://github.com/id-Software/DOOM** 获取）。

最早的移植之一包括 **GLDoom**，它将为 *Doom* 带来 OpenGL 支持，但这仅适用于 DOS。**Boom** 对 *Doom* 引擎进行了彻底改造，修复了许多 bug 和怪癖，并移除了对于（当时）现代硬件不再合理的限制。*Boom* 最初不是开源的，但代码于 1999 年发布，由此诞生了用于 Linux 的 **LxDoom** 和用于 Windows 的 **PrBoom**。这两个项目最终在 **PrBoom** 名称下合并。**PrBoom** 后来被移植到许多平台。

还有许多其他 *Doom* 克隆，其中一些添加了新的先进功能，但有些人珍视原版。对于这些人，有 **Chocolate Doom**（参见 **LXF228**）。它尽可能忠实地重现 DOS 体验，甚至重新实现了后来被修复的 bug。这意味着可以播放原始演示，小恶魔一如既往地愚蠢，原始关卡依赖的一些轻微伪影也被忠实地重现。
