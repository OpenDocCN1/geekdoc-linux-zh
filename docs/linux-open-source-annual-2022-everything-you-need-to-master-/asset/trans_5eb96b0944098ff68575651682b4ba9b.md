

## 备份你的文件

有人说，世界上有两种人：一种人不备份文件，另一种人从未经历过数据丢失。

Linux 的备份工具并不缺乏。**Timeshift** 非常适合备份系统文件。它大致相当于 Windows 中的系统还原或 macOS 上的时间机器，并且是 Linux Mint 的标准组件（这非常方便）。对于备份个人文件，我们推荐 **DéjàDup**（[https://wiki.gnome.org/Apps/DéjàDup](https://wiki.gnome.org/Apps/DéjàDup)）——它具有简单的图形用户界面（GUI），并可以为你自动完成所有操作。用它的原话说，“它隐藏了以正确方式（加密、异地、定期）进行备份的复杂性”。它也是 Ubuntu 的默认组件，因此请参见我们对面提供的方便使用它的六步指南。在幕后，**DéjàDup** 使用了 **Duplicity** 命令行工具，所以如果你更喜欢老派做法，你可以编写一些脚本、*cron* 任务等来直接调用它。所有魔法（增量备份、加密、调度）都发生在 **Duplicity** 中，所以如果你的命令行和脚本能力很强，这可能适合你。它非常适合服务器类任务，在这种情况下你不一定有 GUI 的奢侈条件。

对于典型的家庭使用，我们认为个人文件比系统的其他部分重要得多。无论你的 Linux 是什么版本，如果你的系统崩了，你可以在几分钟（Ubuntu）到几天（Arch）内重新安装它以及所有应用程序。好吧，复制你一路添加的所有小调整可能需要更长时间，也许最终它不会完全一样。不过，你的照片、文档和电影要珍贵得多。

## 保持规律

第一次备份可能会给你一种安全感，这是理所当然的。但备份应该是一种生活方式，而不是一次性事件，甚至也不是你临时做的事情。除非你将其融入你的数字例行程序，否则你冒着所有最新、最伟大的工作（或新鲜记忆）丢失的风险。备份，备份，再备份。幸运的是，得益于现代工具，这比以往任何时候都更容易。

当然，如果你的文件处于某种有序状态，生活会轻松得多，但并非我们所有人都能成为梅尔维尔·杜威（首先，想象一下每个人的通讯录会是什么样 – 编辑注）。根据你的资料量，第一次备份可能需要很长时间，所以去烧壶开水吧。或者，当你意识到某些目录应该被包含或排除时，你可能不得不取消它。但一旦完成，我们将对此感到满意，并且不要过多地打乱你的文档结构，后续的备份会容易得多。后来的备份可能会快得多，因为它们是增量进行的——只存储自上次备份以来发生更改的文件。

如果你使用的是 Mint，你可能更喜欢使用它自己的 **Backup Tool**，它易于使用但没有调度功能。它非常适合对你的主目录进行随意备份，但没有 **DéjàDup** 所有的调度和其他功能。你可以使用以下命令在 Mint 和其他类 Debian 系统上安装它（如果你使用 Ubuntu，你已经有它了）：

`$ sudo apt install deja-dup`

然后启动它，并遵循这个方便的指南来保护你的珍贵文件。

## 使用 DÉJÀDUP 进行备份

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_62_0.png)

### 1 设置备份位置

你可以使用 GNOME 的在线账户功能备份到 Google Drive、Nextcloud 实例等。你还可以使用 Samba 或 SSH 等网络位置，或本地文件夹。我们建议使用外部硬盘，之后将其断开连接。如果你使用真正的本地文件夹，请注意，任何你可以写入的地方都可能遭受勒索软件攻击。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_62_1.png)

### 2 选择要保存的内容

添加你想包含在备份中的主目录外的任何文件夹，并排除你不想要的内部文件夹。*‘.cache/* 文件夹不是必需的，并且通常占用大量空间——它是 Chromium 缓存的存储位置。如果你使用 Steam，你还需要排除 */Steam*。Gnome 的磁盘使用分析器是一个查看什么占用了空间的有用工具。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_62_2.png)

### 3 发起备份

点击“立即备份”按钮。你可能会被提示安装 *Duplicity*，并且你会被提示输入密码。如果你使用一个（加密异地备份是个好主意），那么拜托，不要忘记它；事实上，就像我们在本文稍后告诉你的那样，直接使用密码管理器。点击“下一步”按钮，并开始因为知道你的文件安全而感到放心。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_62_3.png)

### 4 设置计划

就像瑜伽一样，定期练习是通往备份天堂的关键。点击 *Schedule*（计划）选项卡来选择备份的频率和保留时间。如果你备份的位置在自动备份启动时不可用，别担心，你会收到警告。也要警惕空间不足——在此情况下，旧备份将被静默删除，这可能不是理想的。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_62_4.png)

### 5 确保万无一失

这一步是可选的，但如果你真的关心你的数据，双保险的方法总是好的。因此，考虑手动将你的加密备份复制到其他位置：USB 密钥、你的家庭服务器、云中的某个地方，这不重要。冗余是好的，由于你加密了你的备份（对吧？），失去存储设备不应该是一个问题。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_62_5.png)

### 6 测试你的备份

制作备份本身没什么不好，但你需要确保它们是可用的，并且你知道恢复它们的流程。点击 *Restore*（恢复）按钮，插入你的存储设备（如果你是这样做的），选择你的备份位置并选择要恢复的日期。最近的会首先显示。对于这个测试，恢复到特定文件夹，这样什么也不会被覆盖。

## 勒索软件攻击的解剖

你是否曾好奇所有这些高科技金融恐慌和数据加密是如何运作的？不用再好奇了。

不幸的是，如果你成为勒索软件攻击的受害者且没有任何备份，可能已经太晚无法做什么了。通常的解锁要价约为 500 美元，但许多变种会威胁在几天后增加这个金额，甚至可能威胁在更长一段时间后使解密变得不可能。这些威胁只会引发受害者的焦虑，使他们在考虑合理性之前更可能付款。

重要的是要记住，虽然控制该恶意软件的人可能有理由提供解密密钥，但也不可能他们不会。毕竟，他们的商业模式是收取款项，所以为什么要麻烦在达成此目标后发送邮件进行额外的管理呢？收到密钥的人不太会向朋友推荐该特定类型的恶意软件。无论如何，无论你是否有权访问它，解密密钥可能存在于某处。有一类恶意软件只删除所有内容——这类恶意软件被称为擦除器，在 D&D（龙与地下城）中属于混沌邪恶类别——但这并没有为罪犯提供多少收入来源。由于加密很难，销售勒索软件的人经常出错，因此在不成为敲诈受害者的情况下恢复解密密钥是可能的。为了理解这是如何可能的，有必要理解所有这些密钥生成乱象（哈 – 编辑注）是如何运作的。

传统对称加密依赖于两个人能够通过安全信道商定一个秘密密钥。该信道可能是森林中的会面，或密封消息由受信任的中介传递。今天众多、遥远的电子交易不给我们这种奢侈。我们不能每次在网上支付时都去耳语给 Paypal 的朋友；每笔交易都需要协商新密钥。

幸运的是，我们现在拥有公钥（非对称）加密，它使我们可以与远程的另一方（无论是人还是机器）协商共享秘密，即使我们从未见过他们。这是 SSL/TLS（用于 HTTPS）、SSH 和 PGP 通信中密钥交换部分的基础。公钥密码学也是所有加密货币工作原理的内在部分。这是一个迷人的主题，也是一个难以理解的概念，但我们可以留给你自行斟酌（或查看我们在 LXF247 中的加密特性）。你需要知道的只是它要求各方持有两个密钥——一个密钥对；其中只有一个需要保密；并且涉及随机数。

## 让你想哭

WannaCry 的危害本可能更严重，如果没有 Marcus Hutchins（又名 MalwareTech） 的行动，他是一位安全研究员，注意到 WannaCry 试图联系一个未注册域名的服务器。出于好奇，他注册了该域名并设置了一个黑洞，一个旨在捕获信息的服务器，这使恶意软件失效。一旦受感染的机器能够联系该域名，它们就停止尝试感染其他机器：简而言之，Hutchins 找到了一个关闭开关。

在 WannaCry 的后果中出现了进一步的变种，谢天谢地，这些变种也找到了关闭开关域名。Hutchins 一夜之间成为了某种英雄，这使得故事的下一部分相当令人不安。2017 年 8 月，他在拉斯维加斯参加 Def Con 黑客大会时，因与 Kronos 银行木马有关的黑客行为被联邦调查局（FBI）逮捕，他承认青少年时曾为此贡献代码。2019 年 7 月，Hutchins 实际上获得了自由，法官判处他已服刑的时间，甚至建议他寻求大赦。对 Hutchins 来说情况本可能更糟；他接受的认罪协议可能让他坐牢十年。

我们长期以来一直评论技术发展快于法律所能跟上的速度。从事安全研究的人必须走一条细细的线。他们受名为《瓦森纳协定》的条约约束，签署国同意实施管理可能恶用的软件的规定。该协定在 2017 年 12 月重新措辞，为安全研究人员做出特别规定，他们之前可能因跨边界共享工具或漏洞而面临起诉风险。
