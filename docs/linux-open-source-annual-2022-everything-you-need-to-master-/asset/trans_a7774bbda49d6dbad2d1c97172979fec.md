
# 勒索软件密钥管理

向中央服务器发回报文（phoning home）的勒索软件可以使用对称加密来执行其肮脏的混淆操作。在目标机器上可以生成一个随机密钥和一个唯一标识符，这两个数值随后会被发送到命令与控制（C2）服务器并存储在那里。一旦文件被适当地打乱，受害机器上密钥的所有痕迹都会被移除，随后茫然的受害者会将要求的赎金及其唯一标识符一起发送给勒索者。

如果这些勒索者还有那么一点体面的话，他们会提供解密密钥，生活也将恢复正常。这一切都依赖着某种程度的中心化：在某个地方，必须存储一个密钥和令牌列表。对于大规模攻击来说，这并非理想方案——通常，为了实现冗余，会使用多个命令与控制服务器——就地存储这些密钥在逻辑上更为合理。如果没有公钥加密，这就会变成一个徒劳的第二十二条军规式死循环。你可以加密密钥并将其存储在本地，但那么用来加密该密钥的密钥又该存放在哪里呢？

相反，攻击者可以使用一种混合方案，其中用于混淆所有文件的对称密钥（或密钥）存储在受害者的机器上，但以非对称方式加密。这类方案最简单的实现要求攻击者只需要管理一个私钥，而公钥则可以存储在本地——例如，存储在解密程序中。

因此，为了找回他们的文件，受害者需要支付赎金，这会释放攻击者的私钥，该私钥将与公钥结合，这两个密钥随后用于解密本地存储的对称密钥。很简单，对吧？正如某人所说，这些人可不是白拿钱的……

## 卑鄙小人，恶劣的小人

实际上，他们确实白拿钱。勒索软件和命令与控制服务器可以很容易地在暗网的阴暗角落买到或租到，所有这些密钥管理事务都可以通过在友好界面上点击几下就处理完毕。拥有一个私钥管理所有受害者也是一个不太聪明的主意。保护它通过 HTTPS 或 SSH 从 C2 服务器传输到受害者机器上的过程是可行的，但一位足够细心的研究人员，只要有足够的时间和报酬，就能在解密阶段从内存中提取出该密钥。通过这种方式，支付一次（或几次）赎金就能为每个人提供解密能力。这并不是恶意软件作者真正想要的，因此通常使用更先进的密钥分发方式。

有许多高知名度案例显示赎金已支付且数据已获释。例如，2015 年，洛杉矶的一家医院在感染 Locky 勒索软件后掏出了 40 个比特币（当时价值 17,000 美元）。在生死攸关的情况下，很容易理解为什么支付赎金是一个合理的选择。所涉及的金额可能远小于绕过瘫痪网络的每日成本。

即使骗子没有提供解密密钥，赎金也可能被这些成本所掩盖，因此从记账（虽然原则性不太高）的角度来看，受害者的处境并没有那么糟糕。医院，以及实际上所有有信誉的组织，都应该建立滴水不漏的备份机制，但在巨大压力下恢复整个网络是一项复杂的业务。想象一下，在被清除了之后，恢复你机器的软件堆栈、配置和数据需要多长时间，然后将这个数字乘以至少几百倍。Locky 在 2016 年演变成野外检测率最高的恶意软件之一，最终被本地化为 30 种不同语言，并且不再需要 C2 基础设施——如果它位于友好司法管辖区，一旦疫情变得普遍，当局关闭它也就比较容易了。

有些恶意软件对加密对象是有选择性的；它可能只加密文档（基于文件扩展名）并保持操作系统其余部分完好。这样做意味着它只需要用户权限即可运行。如果幸运的话，这意味着清理起来相对容易，至少在追踪到感染源并且已创建备份的情况下如此。当然，人们想出了巧妙的方法来隐藏脚本，使这些感染能够自我复活。没有什么比认为你已经将一切恢复到疫情前状态，结果又全盘皆输更令人沮丧的了。

“无文件恶意软件”正在成为新的常态。这通常通过中毒文档（特别是 PDF）传播，其中包含一些脚本或代码，用于从互联网获取恶意代码并直接将其注入内存。这使得检测变得极其困难。

肆无忌惮的骗子会使用各种狡诈手段来获取不明真相的受害者的数据——无论是诱骗他们安装勒索软件或键盘记录器等其他类型的恶意软件，还是让他们访问设有陷阱的网站并输入有价值的凭证。如今大多数人已经知道，不要回复那些声称来自需要帮助组织大额电汇的尼日利亚王子的邮件。事实上，大多数骗子不再费心使用这类诡计；他们的套路已经大大升级了。

他们可能会利用当地事件，特别是自然灾害。他们也可能根据从目标社交媒体账户收集到的公开信息发送有针对性的电子邮件。因此，你应该非常谨慎地公开分享关于自己的信息。了解你的兴趣、地点，甚至你朋友的这些信息，就足以建立数据侦查立足点。WannaCry 等恶意软件利用 Windows 中未修补的漏洞进行传播，但这种情况相对少见。大多数勒索软件，实际上大多数未经授权的计算机访问，都是由不明真相的用户被算计和欺骗而安装的。

## 交钱，否则孩子就遭殃了

> “忧心忡忡的家长，特别是那些不太懂技术的家长，如果他们认为孩子处于某种危险之中，会毫不迟疑地交出钱财。”

诈骗者会从乍一看似乎合法的域名发送电子邮件——例如，`linux@rmat.com`——或者将你引导至此类域名下的假冒网站。

使用具有合法用途的开源爬虫工具在外观上克隆整个网站非常容易。小部件和搜索功能较难复制，但如果你能诱骗受害者认为网站是真实的，并且让他们输入用户名和密码，那么你就已经赢了。当人们觉得他们正在与朋友交流时，往往会大大降低警惕，因此从被掠夺的电子邮件客户端中获取的联系人列表也很有价值。随后，社交媒体账户对骗子来说就成了黄金。

我们更希望你不要使用 Facebook 之类，但如果你要用，它提供了一些保护账户的方法。特别是，你可以指定你信任的一或多个人，以便在你被黑时，他们能为你触发密码重置。你可以在 Facebook 设置的“安全与登录”部分找到这些和其他选项。

你可能已经目睹过被劫持的账户发送诸如“救命，我被困在廷巴克图。请汇款”之类的信息，这些信息很容易识别。但如果有一点想象力，并了解一些关于受害者的信息——如果你有权访问他们的社交媒体，你就有充足的资源——就可以设计出更具说服力的骗局。忧心忡忡的家长，特别是那些不太懂技术的家长，如果他们认为孩子处于某种危险之中，会毫不犹豫地交出钱财（*不是我 – 编辑注*）。

人类并不是真的设计用来记住密码或生成安全密码的，因此密码重置机制或其伪造形式成为劫持账户的流行手段也就不足为奇了。如果在 Troy Hunt 的 <https://haveibeenpwned.com> 网站上搜索你的电子邮件地址，你很可能会发现它出现在许多已泄露凭证列表中，这些列表现在永远处于公共领域。

这并不意味着该电子邮件地址被攻破了，只是与之相关的账户已被公开——可能是一件无关紧要的事情，甚至可能是后来已经加强了安全措施的事情。出于显而易见的原因，实际凭证并未列出，因此你无法检查其有效性。但进行彻底的密码审计永远是个好主意。如果你 12 年前在论坛上使用过的、与今天使用的类似密码以任何方式被追踪到另一个账户，那么该账户就有风险。
