
## 保护您的服务器

Linux 服务器比 Linux 桌面系统提供了更有吸引力的攻击目标，而且与接管 Windows 桌面机器相比，它们可能更具利用价值。互联网上有大量的 Linux 服务器，其中许多拥有可观的计算能力，并连接着带宽极大的网络链路。因此，它们是挖矿攻击或将其转化为垃圾邮件僵尸网络（spam-spewing zombies）的理想目标。

这类机器可能永远保持开机状态，且很少重启，因此一旦沦陷，可被用于长期运行的攻击。对于黑客而言，如果其已入侵的机器突然消失或像家用设备那样更改 IP 地址，将是相当不便的。遗憾的是，互联网上许多 Linux 服务器都处于被忽视的状态。由于缺乏定期更新，它们成了脚本小子（script kiddies）的活靶子，这些人正将最新武器化的概念验证（PoC）代码据为己有。

系统管理员可能像家庭用户一样，通过社会工程学手段被诱导出密码或运行可疑程序（尽管当他们这样做时理应感到羞耻），但另一条途径是攻击运行在其服务器上的服务。驱动流行网站的开源软件——Apache、Drupal、PHP、MySQL、WordPress 以及几乎任何你能想到的——在某个阶段都遭受过某种类型的漏洞影响。Linux 机器上常见的其他软件也是如此；当 2015 年和 2014 年分别爆发 Heartbleed 和 Shellshock 漏洞时，*OpenSSH* 和 *Bash* 中的漏洞导致了相当数量的系统管理员头发脱落（夸张手法，指压力巨大）。

除了传统的 Linux 服务器外，蓬勃发展的物联网（IoT）世界提供了一类新的（通常是）基于 Linux 的目标。这种情况在某种程度上与入侵服务器相反。对于攻击者来说，服务器是单一且强大的机器。然而，如果攻击者发现某种流行品牌家用安防摄像头存在漏洞，那么他们——通过诸如 **www.shodan.io**（一个针对服务器和 IoT 设备的搜索引擎）等服务——就可以发现并接管一支庞大的（不太强大的）设备大军。总体而言，它们可能拥有相当可观的计算能力（*比特币您好！——编辑注*）或带宽，而现在这些资源都在攻击者的掌控之中。

这正是 Mirai 僵尸网络能够发起大规模 DDoS（分布式拒绝服务）攻击以打击 DNS 提供商 Dyn 的原因，导致 2016 年主要网站从互联网上消失。Mirai（参见采访 [LXF244]）之所以能变得如此庞大，是因为许多设备运行易于发现的 telnet 服务器，并使用众所周知、且通常硬编码的用户名和密码组合。Mirai 的源代码很容易在线找到，且如今新的变种仍层出不穷。2017 年，有人发现一个变种正在感染华为路由器。2018 年，一个被称为 Satori 的变种甚至通过流行软件 *Clamyo* 的漏洞攻击加密货币挖矿业务。

### 威胁永无止境

“蓬勃发展的物联网世界提供了一类新的（通常是）基于 Linux 的目标。”

如果安全意识强的人说了算，IoT 设备绝不应出厂时附带默认凭据，但营销人员似乎占了上风。在使用你的智能联网冰箱摄像头（或类似设备）之前，设置新的凭据似乎被视为对用户不友好。非常有必要主动更改网络摄像头、路由器、NAS 设备等的默认密码。

对于已经强化了这些方面的设备，应设置防火墙，使其无法从外部世界访问——或者干脆退货。在你的网络上运行端口扫描也很有价值，以查看哪些设备上运行着什么服务。我们最喜欢的工具是 *Nmap*，你可以在所有好的软件仓库中找到它，它可以通过类似以下命令告诉你关于你网络的一切：*`$ sudo nmap 192.168.0.*`*
以 root 用户身份如此运行 Nmap 允许其通过 MAC 描述符来识别设备。 [iv]

### 全面基准测试你的 PC

**Ed Bennett** 展示了如何应用用于基准测试世界最快超级计算机的相同技巧来胜过你的朋友……

**你** 可能已经看到过关于各种流行设备的基准测试统计数据，但基准测试究竟是什么，以及如何在自己的系统上运行它？

基准测试最初指的是步枪的测试过程，其中枪支被固定在测试台（bench）上，而不是由人类射手手持：测试台充当瞄准点（mark），因此称为基准测试（benchmark）。通过多次试射，可以测量弹着点的分散程度——分散越小，枪的性能越好。然而如今，它指的是任何允许基于标准参考直接比较不同方法、设备或过程的过程。

在计算领域，这是通过取一组参考任务（每次运行所需资源完全相同）并测量系统完成这些任务时的表现来实现的。这些任务可能旨在对特定组件施压——例如，硬盘写入速度；或者测量机器的绝对性能极限（合成基准测试）；或者它们可能代表系统将用于处理的工作类型（应用基准测试）。游戏基准测试可能会运行游戏的一段固定路线并测量帧率，而 3D 渲染基准测试可能会选择一个复杂的 3D 场景并测量计算机渲染它所花费的时间。

基准测试通常以基准测试套件的形式分发；由于计算机很少仅用于单一任务，因此基准测试套件通过包含各种典型任务的贡献来衡量综合性能。

在本文中，我们将探讨 Sombreo 基准测试套件。Sombreo 是一组针对用于理论粒子物理计算的高性能研究软件的应用基准测试。其中的基准测试以不同程度对处理器原始速度、数据从系统内存进入处理器的速度以及不同 CPU 核心和合作解决问题的计算机之间数据通信的速度进行压力测试。

尽管在推广替代方案方面做出了一些努力，但在高性能计算领域，命令行依然占据主导地位。因此，以下所有操作均在终端中进行。首先，你需要安装依赖项：Git、make、GCC、bc、gnuplot、OpenSSH 和 Open MPI。在 Ubuntu 上，可以使用以下命令安装：

```
$ sudo apt install git make gcc bc gnuplot\
openssh-server openmpi-bin openmpi-common
```

由于你已安装 Git，你可以从仓库 https://github.com/sa2c/sombremo 更新到 Sombreo 的最新版本：

```
$ cd ~/sombreo
$ git pull
```

默认设置足以让你开始运行，因此输入 **make** 后 Sombreo 将自行构建。它包含六个不同的基准测试，每个都来自理论物理学家正在研究的不同公式，以查看其是否能描述现实。因此，在 Sombreo 构建过程中，你会看到相同的文件被编译六次，每次针对一个基准测试。此外，它还包含一个 shell 脚本，该脚本依次运行每个基准测试并给出结果摘要。由于 Sombreo 是一个专为世界上最大的一些计算机设计的高度并行基准测试套件，你需要告诉它你希望在单个 CPU 核心上运行它，并使用其已知最小的问题规模。为此，请使用：

```
$ ./sombreo.sh -n1 -s small
```
