
## 开发者工具

利用这套功能强大的实用工具合集，让你的编码生活更轻松。

### ATOM

Atom 自称是一款可自定义（hackable）的文本编辑器。由 GitHub 开发，该工具内置了包管理器，允许用户在其内部搜索并安装插件。默认情况下，该实用工具附带约 80 个插件。它更有趣的功能之一是查找和替换功能，当你输入时，它可以同时修改多个文件中的文本。Atom 也可以用作 IDE，其亮点之一是智能自动补全功能。此外还有一个括号匹配功能，它会高亮显示与光标所在位置的括号相对应的闭合括号的行号。你还可以定义自定义按键绑定，并通过为小地图和特定语法的片段库等项目添加软件包来增加更多功能。 [https://atom.io](https://atom.io)。

### BPYTHON

这是一个在终端窗口中提供现代 IDE 般功能的 Python shell。你可以先使用默认设置开始使用，然后通过编辑其配置文件进行自定义。该 shell 提供代码自动补全，并且还会显示预期参数列表。它会在你输入时高亮显示语法，并且 Rewind 功能会检查整个代码，这些代码都保存在内存中。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_176_0.png)

bpYthon 允许你将会话保存到文件，甚至将其发送到 pastebin。 [https://bpYthon-interpreter.org](https://bpYthon-interpreter.org)。

### ETHERPAD

协作是任何项目的关键。Etherpad 文本编辑器允许用户实时协作编辑文本。它在 Web 浏览器中运行，并允许参与者通过基于文本的聊天进行互动。它功能丰富，你可以在其网站上试一试。 [http://etherpad.org](http://etherpad.org)。

### VIRT-MANAGER

虚拟管理器（Virtual Machine Manager）是一个开源图形前端，用于创建基于 KVM 的虚拟机。它使用 qemu-kvm  hypervisor（这是一个版本的 qemu 机器模拟器），并包含一个 VNC 和 SPICE 客户端，向运行中的虚拟机显示图形控制台。 [https://virt-manager.org](https://virt-manager.org)。

### TURKEY APPLIANCES

在服务器上安装可网络访问的软件或 Web 应用可能是一项艰巨的任务，因为它们需要大量的基础设施软件，组装起来可能花费你数小时的时间。从数据库服务器到基础库，在你能够在网络上部署应用程序之前，必须花相当长的时间来组装一个完全功能正常的 Web 服务器。

此外，如果你计划为网络外部用户提供服务，你需要彻底检查你的 Web 服务器是否存在任何安全漏洞。这本身就是一个巨大的工程。

这正是 Turkey-Linux 大放异彩的地方。使用其虚拟设备（virtual appliances），你可以瞬间部署一个新的服务器应用。简而言之，TurnKey 虚拟设备是一个自包含的系统，它打包了一个完全功能正常的 Web 应用实例，并仅包含驱动该工具所需的操作系统组件。该系统开箱即用，可以部署在裸金属上或虚拟硬件之上。

根据你想要部署的硬件，从裸金属到 OpenStack 云，TurnKey Linux 虚拟设备提供多种形式。重要的是，一旦它们正常运行，无论平台如何，它们都为你提供了相同的界面来管理和配置 Web 应用。 [www.turnkeylinux.com](www.turnkeylinux.com)。

#### OCLOTEL GUI

该数据库客户端可以连接并与 MySQL 或 MariaDB 服务器进行交互。你可以使用它创建查询，它可以高亮显示语法，并可以从数据库获取和显示结果。 [https://github.com/ocelot-inc/ocelotgui](https://github.com/ocelot-inc/ocelotgui)。

#### DOXYGEN

使用这个 CLI 工具从代码注释中生成 HTML 文档。该工具支持许多编程语言，并可以交叉引用文档和代码以进行参考。 [www.doxygen.nl](www.doxygen.nl)。

#### FINKF

如果你使用 Java、C、C++ 或 Objective C 进行开发，请使用 infer 来排除 bug。该工具包含各种分析，其最有趣的功能是它可以跨越多个文件中的多个过程进行处理。 [https://fbinfer.com](https://fbinfer.com)。

#### MARKTEXT

该 Markdown 编辑器支持 GitHub markdown 规范和 CommonMark 规范。它具有实时预览、多种编辑模式、内联数学公式支持，并且可以导出文档。 [https://marktext.github.io/website](https://marktext.github.io/website)。

#### MANTA

完成项目后，使用 Manta 生成发票和收据。该发票应用拥有简洁的界面，以及几个你可以按照需求进行自定义的模板。 [https://github.com/hq1287/Manta](https://github.com/hq1287/Manta)。
