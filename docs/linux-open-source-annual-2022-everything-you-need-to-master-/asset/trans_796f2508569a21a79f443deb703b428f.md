
# OpenIndiana

仅适用于 64 位计算机。OpenIndiana 针对光盘介质和 USB 设备提供了不同的镜像。这些镜像会启动到 Live 环境，在此环境中你可以启动图形化或基于文本的安装程序，其运行完全符合预期。

由于使用了 MATE 桌面环境以及大量知名的开源应用程序，OpenIndiana 不会像本测试中的其他操作系统那样给你带来那种“替代操作系统”的感觉。就操作系统的易用性而言，主要的缺点在于缺乏图形化包管理器。虽然命令行版本并不难以掌握，但它会让许多初次使用者感到疏离，这些人本来就已经在一个陌生的操作系统中处于不舒服的状态了。

缺乏内置文档也无助于此——但 OpenIndiana 是你能找到的最接近典型 Linux 安装体验的系统。

# ReactOS

ReactOS 是一个基于 Windows NT 设计原则的开源操作系统。它完全从头编写，旨在为用户提供一个开源平台，通过与其专有操作系统在二进制上的兼容性，来运行专为 Windows 设计的软件。

该项目提供了一张 Live CD 以帮助探索操作系统，以及一张带有易于导航的安装程序的安装 CD。无论你是否使用过 Windows，你都会发现 ReactOS 的操作非常直观。当然，默认情况下它并没有附带很多应用，但你可以通过包管理器来丰富它。

除了物理硬件外，你还可以在虚拟硬件上安装 ReactOS，鉴于其 alpha 状态，这实际上是该操作系统的特长。尽管其需求非常小，但 ReactOS 仅支持有限的设备和外设。当它正常工作的时候，最大的阻碍是偶尔出现的蓝屏死机（Blue Screen of Death）。

# Visopsys

考虑到它主要是一个教育系统，Visopsys 的易用性让我们感到惊讶。我们原以为它是“另当考虑”箱里的理想候选者，但它的功能和性能却让我们感到意外。操作系统启动速度极快，并允许你选择启动安装程序或进入 Live 会话。安装程序中包含一个功能强大的分区工具，这是另一个令人愉快的惊喜。

桌面导航相当简单，包含了一些必备应用，以及便捷的管理和配置工具。但试图将其用于常规桌面任务并不能走得太远，因为该操作系统缺少 Web 浏览器，并且没有包管理系统来帮助你拉入额外的应用程序和工具。Visopsys 很好地伪装成了一个普通桌面，但它确实是一个非常强大的操作系统项目，应当以此对待。

# 硬件支持和需求

它们甚至能在你的计算机上工作吗？

另一个阻碍这些操作系统成为主流的因素是它们缺乏硬件支持。另一方面，在兼容的硬件上，其中大多数性能会超过你喜爱的 Linux 发行版。

例如，Visopsys 可以在任何拥有 64MB 内存的 Pentium 计算机上驱动图形化桌面。该操作系统支持 FAT 文件系统的所有变体，并对 ext4 提供只读支持。在外设方面，它支持 PS/2 和 USB 输入设备、IDE 和 SATA 磁盘，以及 PNetEthernet 网卡。

同样，你可以仅在拥有 256MB 内存的任何 Pentium 级别 x86 机器上运行 ReactOS。ReactOS 与包括 Haiku 在内的其他项目合作以提供硬件支持，但与本次综述中的其他一些操作系统相比，其硬件支持仍然相当有限。

KolibriOS 也差别不大。它是一个仅支持 32 位的操作系统，所需的资源极少。其开发者声称它甚至可以在搭载原始 Pentium 处理器的机器上运行。该操作系统支持 USB 2.0，以及许多流行的以太网设备，还有 Radeon 和 Intel 图形驱动。

OpenIndiana 需要一台至少拥有 4GB 内存的 64 位计算机才能获得不错的性能。该项目还托管了一个由社区维护的支持外设列表，内容相当详细。

Haiku 为 32 位和 64 位机器都生成了镜像。该项目通过 KPI 兼容层从 FreeBSD 借用其以太网和 Wi-Fi 驱动程序。这些驱动程序已升级为 FreeBSD 11.1 的版本，支持 Atheros 9300-9500 系列、Intel 较新的“双频段”系列、Realtek 的某些 PCI 芯片组，以及所有其他现有驱动程序中较新型号的芯片组。

# 包管理

它们的仓库中有哪些可用应用？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_31_0.png)

本次综述中的一些操作系统附带了很多应用，但其他一些则相当简陋，安装完成后并没有太大用处。你将不得不丰富这些内容，以便在桌面上生产性地使用该操作系统。不幸的是，并非所有操作系统都允许你安装额外的应用，且有些操作系统的努力程度比其他的多得多。

KolibriOS 和 Visopsys 属于前一类：没有途径为它们安装额外的包。虽然 OpenIndiana 拥有包管理系统，且相当熟练，但丰富操作系统内容是该操作系统最薄弱的环节之一。该操作系统使用映像打包系统（Image Packaging System），但功能上是命令行包管理器 *pkg*，而不是图形化的。虽然 *pkg* 与 *apt* 和 *dnf* 非常相似，但对于添加存储库等任务，你将不得不阅读 man 页面和其他文档。

相反，包管理是 ReactOS 原始安装的唯一亮点。该操作系统使用类似 Sysntropic 的应用商店，当你使用控制面板中的添加/删除程序功能时，它会弹出。ReactOS 应用程序管理器操作直观，允许你批量安装多个程序。你还可以在它下载和安装软件时继续使用应用程序。同样，最新版本的 Haiku 的一个亮点是其图形化包管理器 HaikuDepot。它操作直观，运作方式基本上与 Linux 上的包管理系统类似。

> 除了 LibreOffice 和 Firefox 等应用外，你还可以使用 ReactOS 应用程序管理器下载 Adobe AIR 和 Microsoft .NET 框架等库。

# 日常使用

你能把它们用作你的日常桌面吗？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_31_1.png)

你绝对可以将 OpenIndiana 用作常规桌面，特别是考虑到它附带了熟悉的环境和主流开源应用。然而，该操作系统并不包含你需要的所有应用，你将不得不使用其命令行包管理器获取额外的应用，这打断了原本流畅的用户体验。

虽然 Visopsys 是一个功能完整的操作系统，但你无法真正将其作为传统意义上的日常桌面使用。该操作系统由个人开发，更多是一种教育工具，而不是你可以用于日常任务的实际操作系统。它还缺乏关键的生产力应用，如互联网浏览器和包管理系统。

ReactOS 已被弃用，因为该项目自己承认，它尚未准备好用作你的日常桌面。就应用可用性而言，它不会让你失望，但系统还不够稳定，无法可靠地用于生产性工作。Live CD 仅在我们将其中一台测试机器上正常工作，而安装 VirtualBox Additions 则引发了臭名昭著的类 Windows 蓝屏死机。

与前两者相比，KolibriOS 开箱即带大量应用。不幸的是，许多关键应用相当原始。例如，Web 浏览器是基于文本的，虽然它在渲染像 KolibriOS 网站这样的简单网站时没有问题，但每当我试图使用它访问数据密集型的网站（如 YouTube）时，它都会崩溃。我们绝对推荐该操作系统的唯一任务是复古游戏，在这方面它仍然无与伦比。

总的来说，你会最舒适地用于日常桌面任务的操作系统是 Haiku。它具有令人印象深刻的硬件支持，并且在安装过程中不会抛出任何意外错误。桌面上的应用程序集合，如由 WebKit 驱动的 Web 浏览器，以及包管理工具中可用应用程序的丰富性，无疑有助于满足大量人员的桌面计算需求。

> OpenIndiana 中的 Time Slider 工具利用 ZFS 文件系统，按时间间隔对安装进行快照。
