

## 照片编辑器

### 结论

本月*综述*的赢家很容易确定。**GNU 图像处理程序**，即 **Gimp**，是毫无争议的冠军，也是摄影师的最佳选择，无论其工作流程如何。Gimp 最适合绘画和修饰，但得益于 G'MIC 和 FX Foundry 提供的第三方扩展，它也是修复、修饰以及应用各种恢复技术的最合理选择。如果你需要处理 RAW 图像，Gimp 可以整合 UfRaw 和 *Rawtherapee*，并将它们用作图像源。它是一个功能多样且全面的软件包。

决定剩余程序的排名更具挑战性，因为它们彼此非常接近。*Rawtherapee* 凭借出色的色彩校正工具和更强的降噪算法占据了第二名。很难说 *Rawtherapee* 是否真的比 *Darktable* 更好——两者只是不同，但在功能上可以相提并论。不过，在我们的测试中，*Darktable* 速度较慢，且缺乏有效的白平衡校正器，因此失分了。

令人惊讶的是，*Pixeluvo* 名列第三。这款知名度较低的商业应用缺乏专业工具，并缺少其他 RAW 处理器所具备的许多高级（且常常重叠的）功能。然而，*Pixeluvo* 配备了出色的编辑工具、实用的色彩调整功能、快速特效、图层，甚至拥有自己的 RAW 导入对话框。它是功能最均衡的编辑器（可能）物有所值。

这意味着 *Lightzone* 垫底，但这并不意味着它本身是个糟糕的程序。然而，我们对此感到失望，*Lightzone* —— 自称是专业级 RAW 图像处理器 —— 却拥有如此糟糕的噪点去除工具。*Lightzone* 在修复色彩和去除斑点方面表现良好，但降噪效果本可以再好一点。

因此，对于大多数使用场景，我们建议使用 *Gimp* 和 *Rawtherapee*，无论是单独使用，还是将 *Rawtherapee* 转换为 *Gimp* 的 RAW 导入插件。如果你不需要减少噪点和颗粒，不妨看看 *Pixeluvo*，它具备业余照片处理所需的一切功能。也不要放弃 *Lightzone*：作为优秀的二线照片编辑程序，它有其特定的优势。

### 也可考虑

有些人会认为我们忽略了 Corel 的 *AfterShot Pro*，以及一些重量级的开源软件包，如 *Digikam* 或 *Krita*。好吧，*AfterShot Pro* 是专有软件，而且价格不菲，我们 certainly 不想将我们的团体测试变成开源软件与专有软件之战。*Digikam* 确实非常好，且令人愉悦，但它侧重于收集和整理照片，而不是编辑和处理。最后，*Krita* 是数字艺术家、漫画家和技术设计人员的绝佳工具，但用于编辑照片时，其稳健性远不如前者。还有其他替代方案存在，你可能已在 *Linux Format* 的往期问题中读过关于它们的文章（例如，*Photivo*（参见 **LXF238**）和 *Fotoxx*，仅举两例）。当然，我们承认这些程序和其他用于编辑照片的免费软件包，但在这期*综述*中，我们选择了最强大且功能最丰富、可日常使用的标题。

## 拓展你的边界

“不要让那些低质量、无人维护的程序数量阻碍你的探索”

主流 Linux 发行版花费大量时间来选择其默认程序组合。毕竟，他们需要工具来满足最大多数用户的需求。当然，这些程序在其擅长领域表现卓越，但在像 GitHub 和 Sourceforge 这样的代码共享孤岛中，甚至在你喜欢发行的官方仓库中，还潜伏着成千上万其他出色的软件，等待着被发现。

然而，现实地说，你有时间尝试所有这些工具吗？考虑到你的需求已由发行版的默认选项很好地满足，你甚至想要这样做吗？再加上事实是，我们大多数人都偏爱自己的开源应用，并坚信它们比任何可用的替代方案都更适用于我们。话虽如此，我们将鼓励你迈出舒适区一步，惊叹于 Linux 宇宙的多样性。并且，不要让那些低质量、无人维护的程序数量阻碍你的探索。

在 LXF 总部，我们花费大量时间翻遍源代码镜像和其他地方，以发现新的瑰宝并在杂志中报道。本期我们决定整理我们在旅途中遇到的所有最佳工具。我们避免包含流行的主流工具，但你可能仍然熟悉其中一些，因为它们实在太好了。不过，大部分情况下，接下来的几页将向你介绍你从未见过的图形应用程序和 CLI 实用工具。无论你是谁类型的用户，或者你如何使用 Linux，以下页面将为你提供大量的开源好东西，以提升你的 Linux 机器。

## 图像工具

查看这些管理或编辑图像集合的巧妙选项。

### PENCIL 2D

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_167_0.png)

你可以使用 *Pencil 2D* 创建静态和动画绘图。这是一个全面的程序，将帮助数字设计师在多个图层中创建专业级的卡通和动画。其直观的工具得到了其网站上视频教程的完美补充。 [www.pencil2d.org](http://www.pencil2d.org)

### DARKTABLE

如果你处理 RAW 图像，*darktable* 将帮助你创建一个专业的数字暗房来处理它们。该工具的界面让你可以访问全套图像操作和编辑工具，可与 Adobe 和 Apple 等商业重量级应用相媲美。 [www.darktable.org](http://www.darktable.org)

### FOTOTXX

一个全面的图像处理程序，拥有丰富的修饰和编辑功能，超越了改变亮度、对比度和颜色。与大多数专用图像编辑器一样，*Fototxx* 允许你使用各种工具（如自由手绘轮廓、跟随边缘和选择匹配色调）选择图像中的对象或区域。该工具的另一独特功能是它允许你在不使用图层的情况下编辑图像。你还可以使用 Fototxx 创建 HDR 和全景图像，减少噪声，去除灰尘斑点，制作拼贴画、混合体和带动画的幻灯片。还有几种艺术特效，可将照片转换为线条画、素描、绘画、浮雕、卡通、点阵图像或马赛克。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_167_1.png)

你可以在资源受限的机器上使用 Fototxx，并且程序可以完全通过键盘导航。

首次启动时，Fototxx 会在 web 浏览器中打开其快速入门指南，并弹出一个索引你的图像库的对话框。这个过程可能需要一些时间，具体取决于你的图像库中有多少图像。其所有功能都可以通过左侧面板中清晰标记的相关选项来访问。 [https://kornelix.net/fototxx/fototxx.html](https://kornelix.net/fototxx/fototxx.html)

### RAPID PHOTO DOWNLOADER

考虑到大多数照片管理工具本身都可以导入照片，这个程序看起来可能是多余的。然而，*Rapid Photo Downloader* 专为传输照片和视频而设计。它提供了更多的功能，使其成为下载、处理和组织照片和视频的完美工具。

该工具让你控制它如何处理和排序下载的照片。程序的默认规则自动将下载的照片转移到基于日期的子文件夹中。你也可以根据你的要求定义自定义规则。例如，你可以要求程序按类型对照片进行排序，如果你同时拍摄 RAW 和 JPEG，这将非常有用。实际上，你可以基于 Exif 值（如焦距、ISO 等）定义命名规则，从而创建复杂的子文件夹层次结构。你还可以指定外部 USB 存储设备作为备份目的地，程序会在从相机下载照片时自动备份照片。

[https://damiennynch.net/rapid](https://damiennynch.net/rapid)

### CONVERSEEN

Converseen 是一个针对各种命令行转换实用程序的简单前端，可以在比手动执行这些任务快得多的时间内将图像转换到 100 多种格式之间、旋转和翻转它们、更改其尺寸并重命名它们。

[http://Converseen.tasterland.net](http://Converseen.tasterland.net)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_167_2.png)

### FROGR

使用此工具将内容上传到 Flickr，并访问其基本上传功能，例如描述图像、设置特定许可以及将它们分类到集合和组池中的能力。
[https://mariospr.org/category/frogr](https://mariospr.org/category/frogr)

### NOMACS

此图像查看器可以显示所有流行图像格式的图像。除了常规功能外，它还有一些令人惊讶的功能，例如在多个网络实例之间同步查看的能力。
[https://nomacs.org](https://nomacs.org)

### ENTANGLE

使用此工具从计算机连接和控制你的相机。*Entangle* 还将帮助你通过调整光圈、快门速度、ISO 和其他设置来设置拍摄，然后下载图像。
[https://entangle-photo.org](https://entangle-photo.org)

### FLAMESHOT

你可以使用 Flameshot 捕获整个屏幕或特定部分。此外，它还为你提供了一整套绘图工具，为你的屏幕截图添加注释。
[https://github.com/lupoDharkael/flameshot](https://github.com/lupoDharkael/flameshot)

### LYCHEE

Lychee 具有简单的用户界面，是一个存储和共享照片的平台。你可以从 SBC（如 Raspberry Pi）运行它，并使用它来上传、管理和共享照片。
[https://lychee.electricious.com](https://lychee.electricious.com)
