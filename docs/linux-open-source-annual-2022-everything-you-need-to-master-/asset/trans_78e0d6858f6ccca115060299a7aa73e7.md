# Ellego UNO

我们现在将向你展示如何使用 Ellego UNO 基础入门套件获得嵌入式计算的动手实践经验。Ellego 直接通过其网站（[www.ellego.com](https://www.ellego.com)）以美元销售，但也在多个国家通过亚马逊以更有竞争力的价格销售。在撰写本文时，该基础入门套件在英国亚马逊上的价格仅为 13.99 英镑，在美国亚马逊上为 14.99 美元。

顾名思义，该套件包含一块与 Arduino UNO R3 兼容的单板计算机（SBC）。我们不会列出该板的具体规格；只需说它足以满足套件中记录的所有项目以及更多需求即可。套件还包含一根用于将 UNO 连接到 PC 的 USB 电缆，以及一张包含教程文档和所有项目代码的迷你 CD，尽管这些内容也可在线获取。套件的其他部分包括多个电子元件以及将它们彼此连接并连接到 SBC 的工具。

## Arduino 系列

Arduino 系列——即使我们只考虑官方板——也比树莓派（Raspberry Pi）系列更多样化，当我们将第三方产品纳入其中时，这种多样性更加明显。然而，它们的名称并不真正反映其在等级体系中的位置，因此你需要查阅比较表来决定使用哪一个。与运行 Linux 的 SBC 类似，Arduino 板以处理器的性能和内存大小进行区分，但程度有限。你可能会用到比 UNO 上 16MHz 8 位处理器更强的处理器，但你不会找到与树莓派处理器相当的东西，只有少数型号拥有超过 256KB 的程序闪存或 32KB RAM。除了顶级嵌入式应用外，你可能更关注 I/O 引脚的数量以及尺寸和外形，而在这方面 Arduino 的差异相当大。你还会发现有些板没有 I/O 连接的插针。虽然这些插针对于学习和开发至关重要，或者如果你想要添加盾牌（shield）时必不可少，但对于实际应用来说，使用仅带有“焊盘”的板，并将在外部组件的引线焊接到焊盘上，可以实现更大的可靠性。

首先是面包板，你将在上面安装各种电子元件并建立它们之间的电气连接。有公对公跳线用于建立面包板上组件之间的连接，以及将面包板上的组件连接到 UNO 的输入/输出引脚，还有一些公对母跳线。转到组件本身，有各种颜色的 LED、按钮、蜂鸣器、光敏电阻和倾斜开关。还有几个用于接口的组件，主要是电阻，包括一个 74HC595 IC——一种用于某些项目的串行到并行转换器。

要看到 UNO 的工作状态，只需使用随附的 USB 电缆将其连接到你的 PC。小心不要把板放在导电表面上，因为这可能会导致 UNO 底部焊点短路。一旦连接到 PC，你会注意到绿色电源 LED 亮起，橙色 LED 开始闪烁。UNO 中已经预置了一个简单的程序，正是这段代码负责闪烁 LED，并证明板子工作正常。现在是启动 IDE 的时候了，我们假设你已经安装好了；这不会阻止 LED 闪烁。你现在已准备好迈出嵌入式编程的第一步。

## 在 UNO 上进行编程

首先，我们将查看如何将代码上传到 UNO，并修改该代码。这对应于 Ellego UNO 基础入门套件 CD 上的第二课，第一课是安装 IDE。这是一个很好的起点，因为它不需要你将任何外部组件布线到 UNO 的 I/O 引脚上。在做任何事情之前，有必要告诉 IDE 你正在使用哪块 Arduino 板，尽管它可能默认为 UNO。要检查并在必要时更改它，请前往 工具 > 开发板。我们不会创建新的代码开始，也不会使用入门套件提供的代码，而是使用 IDE 提供的示例代码。通过 文件 > 示例 > 01.Basic > Blink 打开它，它将出现在 IDE 的编辑窗口中。在 Arduino 术语中，该代码被称为草图（sketch）。

这种语言通常被描述为与 C/C++ 非常相似，并带有用于处理 Arduino 板类的库。无论你如何称呼它，只要你有一定的编码经验，很快就会掌握它。事实上，即使你是编程新手，只要有在线教程作为指导，你应该也能毫不费力地掌握它。

这段代码的目的是闪烁板载橙色 LED，因此它与已经烧录到 UNO 中的代码几乎相同。即便如此，为了检查一切是否正常，点击工具栏中带有右向箭头的圆形图标。观察底部的蓝色状态栏，你应该看到“正在编译草图...”随后是“正在上传...”然后是“上传完成。”你可能还注意到另外两个板载橙色 LED 短暂闪烁，指示 PC 和 Arduino 之间的数据传输。一旦你确认 IDE 工作正常，我们将更改那个闪烁 LED 的行为。

在草图的底部附近，你会找到一行将 LED 打开的代码，接着是一行等待 1,000 毫秒（一秒）的代码，然后是一行将其再次关闭的代码，最后一行是再等待一秒的代码。这四条指令位于一个循环中，因此它们会永远执行。一个简单的修改是将两次等待的时间从 1,000 毫秒更改为 500 毫秒，因此请相应地编辑草图并上传新代码。在另外两个 LED 闪烁之后，你会注意到板载橙色 LED 开始闪烁得更快。如果你想保存修改后的代码，请将其保存为新名称，因为示例文件是只读的。

## 掌握硬件

我们不会逐一讲解入门套件文档中的所有教程，因为那将是重造轮子。提供的说明非常出色，既有操作指令也有解释，建议你按顺序全部阅读一遍。我们在这里的目标只是激发你的兴趣，希望你拿到这个入门套件，从而掌握嵌入式计算。为此，我们将重点介绍一个教程，第 5 课，它是嵌入式计算中一个经典案例的略微扩展版本。该案例允许使用一个按钮打开 LED，使用另一个按钮关闭它，从而说明了数字输入和数字输出的使用。你可以将其视为“你好，世界”程序的等价物，这是许多人在学习编码时编写的第一个程序。

在这个例子中，我们将使用一些 UNO 外部的硬件，这是嵌入式计算的本质。我们将在入门套件中提供的那块面包板上安装并连接几个电子组件。面包板永远不会用于现实世界中的设备，因为印刷电路板要紧凑和可靠得多。不过，对于学习或尝试想法，它们是非常理想的。面包板有一排排孔，你可以将组件的引线插入其中，孔后面有电气连接，因此无需焊接即可将组件连接在一起。这意味着你不需要购买烙铁，且组件可以重复使用。

要理解面包板内部连接，请手持面包板，使红色和蓝色线条在顶部和底部水平运行。在螺丝后面，顶行的所有孔都相互连接，第二行的孔也相互连接，底行以及从底部数起第一行的孔也是——这些是用于电源的。面包板其余部分的孔在垂直列中相互连接，但在你可以看到槽（gutter）的地方有一个水平间隙。

现在，按照入门套件手册所示，将各种组件添加到面包板上。你会注意到，当你将引线插入孔中时，它会“抓住”引线，从而在物理上固定它并连接到内部的其他孔。只要组件彼此定位正确，使用与文档中完全相同的孔并不重要。接下来，从入门套件的光盘中加载第 5 课的代码到 IDE 中。

如果一切按计划进行，你会发现左侧按钮打开 LED，右侧按钮关闭它。如果一开始不起作用，请尝试晃动面包板上的组件引线，因为在将组件添加到板子时很容易做出不良连接。最后，在我们让你去完成其他课程之前，何不试着通过修改草图来动手编写代码呢？
