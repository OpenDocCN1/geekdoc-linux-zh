
## 生产力

使用这些财务、网页过滤和管理工具，为您的生活增添秩序。

### OSMO

个人信息管理器（PIM）帮助您追踪和整理来自各种来源的信息。Osmo 是一个轻量级的 PIM，有助于管理日程、任务、联系人和笔记。该应用程序具有简洁且集成的界面，顶部有四个标签页，分别是日历、任务、联系人和笔记。

该程序没有菜单，但顶部的操作链接按钮会随着您在四个组件之间切换而改变。日历面板提供了一个简单且功能性的日历，以及一些相关信息，例如周数和距年底的天数。您可以双击日期添加笔记，或右键单击日期添加任务。

在 Osmo 中定义任务的选项位于基本和高级选项卡内。使用基本选项卡定义截止日期和时间并为任务分配优先级，而高级选项卡允许您将任务标记为重复并定义相关属性。您可以使用联系人面板存储联系人的地址。它提供了额外的功能，包括搜索功能、生日浏览器，以及能够在 Google 地图上指出联系人地址的能力。笔记面板允许您使用富文本编辑功能记录文本，并且您可以选择使用密码加密所有笔记。

http://clayo.org/osmo

### FOCUSWRITER

使用全屏运行的文本编辑器 FocusWriter 进行无干扰书写，它使用自动隐藏菜单以保持工作区的整洁。该编辑器支持流行的文本格式，并基本支持 ODT 文件。FocusWriter 的主要目标是让您专注于写作，因此虽然该工具可能缺乏一些主流文本编辑器的灵活性，但它具有多个更符合此目标的独特功能。您可以设置闹钟，在特定时间间隔过后或特定时间触发，也可以在 FocusWriter 中为自己设定目标。一个有趣的特性是专注文本（Focused Text），它会淡出除您正在输入的章节以外的所有内容——整个段落、三行的文本块或仅当前行。

https://gotcode.org/focuswriter

### GATESENTRY

一款简单的网页过滤器，GateSentry 在 Linux 和 Raspberry Pi 上都能运行。它易于部署和配置。GateSentry 验证用户身份，并根据网站、内容类型以及时间过滤流量。简单的代理服务器可以显示数据消耗统计信息，还可以允许您远程禁用用户的访问权限。

http://gatesentryfilter.abdullahfarhan.com

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_172_0.png)

一旦您设备上安装了其证书，GateSentry 还可以过滤 HTTPS 流量。

### KIMAI V2

Kimai 记录工作时间并输出您的活动摘要。它可以用于单个用户或多个用户，并可以管理多个客户和项目。该程序有一个基于浏览器的仪表盘，您可以在项目主页上的演示安装中进行试用。

https://V2.kimai.org

### SIMPLESCREEN RECORDER

与它的名字相反，SSR 功能丰富，并赋予用户大量的屏幕录制控制权限。该工具可以记录整个屏幕，还可以选择并记录桌面窗口和区域。

www.maartenbaert.be/simplescreenrecorder

### TURTL

Turtl 是一款注重隐私的笔记工具，拥有令人印象深刻的功能列表。它可以创建不同类型的笔记，并允许您将图像和其他文件附加到您创建的笔记中。

https://turtlapp.com

### DICTION

一款命令行（CLI）实用工具，Diction 有助于标记常见拼写错误的单词。它可以通过标记通常与初学者错误相关的单词来创建更好的副本，甚至可以建议更好的措辞。

www.gnu.org/software/diction

### TASK COACH

一个简单的待办事项管理器，Task Coach 简化了定义和跟进任务的过程。您还可以使用该工具为任务分配优先级、完成日期以及可选的提醒。

www.taskcoach.org

### EQONOMIZE

Eqonomize 是一款个人支出管理器，具有简洁的界面和整理财务所需的所有功能。该程序可以跟踪单个或多个账户并设定预算。

https://eqonomize.github.io

### STRETCHLY

一个简单的应用程序，会弹出提醒您休息一下。它具有几个预设的休息间隔，休息窗口会分享帮助您放松的建议。您可以通过其托盘图标控制该工具。

https://hovanic.net/stretchly

## 系统管理

确切地了解您的 Linux 机器内部正在发生的事情。

### GLANCES

*Glances* 是一个 Python 脚本，智能地在标准终端窗口内显示有关当前会话的大量信息。您可以使用该工具监控远程机器，并使用内置的 Web 界面通过 Web 浏览器监控机器。

[https://nicolargo.github.io/glances](https://nicolargo.github.io/glances)

### PORTAINER

通过终端使用 Docker 并没有那么麻烦，并且该工具文档完善。不过，为了让您的生活更轻松，您可以使用 *Portainer*，这是一个开源的基于 Web 的图形前端，支持 Docker API 公开的所有功能。您可以使用它管理容器、镜像、网络和卷，它可以管理独立的 Docker 环境，也可以管理 Docker Swarm。从其仪表盘，您可以创建容器，并查看和管理所有可用的容器。您可以获取实时统计数据，如 CPU 和内存使用情况以及运行容器的其他各种详细信息，甚至可以从浏览器窗口内访问容器控制台。*Portainer* 可作为 Docker 容器提供，因此您可以用一条命令安装它。要创建容器，您可以使用数十个预定义模板中的一个。该工具可由多个用户使用，并具有有用的用户管理功能。例如，您可以使用它来定义其他用户对 *Portainer* 的访问级别，以及他们在 *Portainer* 内部可以管理的 Docker 方面。

[https://portainer.io](https://portainer.io)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_173_0.png)

您可以使用 Portainer 从 Docker Hub 或私有注册表拉取镜像。

### FIREJAIL

*Firejail* 通过将程序和进程隔离在有限的沙箱环境中来增强安全性。通过锁定网页浏览器或任何可能被入侵的工具，*firejail* 防止被入侵的程序访问文件系统的关键区域。

[https://firejail.wordpress.com](https://firejail.wordpress.com)

### BOOTCHART

启动时间较长的主要原因之一是您的系统在启动过程中启动了不必要的工具和服务。但在采取行动之前，最好先了解一下您的发行版启动时发生的事情。*Bootchart* 是一个简单的实用工具，允许您分析 Linux 启动过程并帮助测量不同服务的加载时间。它现在已与 Systemd 合并。打开一个终端并输入 `systemd-analyze time` 以了解启动时长的分解情况。同样，`systemd-analyze blame` 将按启动所需时间列出所有正在运行的单元。要生成启动过程的图像，请键入 `systemd-analyze plot > boot.svg`。从该图像中，您可以找到所有活动进程，并删除您不需要的任何进程。例如，如果您偶尔打印，可以禁用 CUPS 在启动时运行。此外，该图像还有助于发现占用所有资源并迫使其他进程等待从而减慢启动速度的进程。

www.bootchart.org

### GRUB CUSTOMIZER

您可能想要更改默认引导加载程序行为的原因有很多，而 *Grub Customizer* 工具将帮助您做到这一点。该图形工具可以修改启动过程的所有方面，甚至可以调整 Grub 屏幕的外观。

[https://launchpad.net/grub-customizer](https://launchpad.net/grub-customizer)

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_173_1.png)

Grub Customizer 还可以在您不小心彻底清除 MBR 时帮助恢复。

### REMMINA

一个非常易用的远程桌面客户端。*Remmina* 支持广泛的协议。它性能良好，并提供了有用的功能，例如灵活地随时更改连接的质量设置。

[https://remmina.org](https://remmina.org)

### INXI

一个列出计算机硬件信息的命令行（CLI）工具。使用 *inxi*，您可以汇总有关设备的详细信息，包括供应商详细信息、设备驱动程序配置等。

[https://github.com/smxi/inxi](https://github.com/smxi/inxi)

### POWERTOP

Intel 开发了 *PowerTOP* 实用工具来追踪消耗笔记本电脑电池电量的应用程序。该命令行实用工具提供了建议，以调整耗电工具，从而从笔记本电脑电池中榨取更多电量。

[https://01.org/powertop](https://01.org/powertop)

### STACER

*Stacer* 是一个系统监视器，可帮助您跟踪安装的不同方面。当某个参数的值超过特定阈值时，它还可以显示警报消息。

[https://kuzuhannan.github.io/Stacer-Web](https://kuzuhannan.github.io/Stacer-Web)

### LOGWATCH

*Logwatch* 解析、分析和过滤日志，然后生成有关系统日志活动的每日报告。该实用工具还允许您控制报告详述程度。

[https://sourceforge.net/projects/logwatch](https://sourceforge.net/projects/logwatch)
