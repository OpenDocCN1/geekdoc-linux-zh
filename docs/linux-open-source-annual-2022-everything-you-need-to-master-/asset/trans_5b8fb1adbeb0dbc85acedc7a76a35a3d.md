## 基于 Arch 的发行版

越来越多的发行版开始构建在 Arch Linux 之上。曾经，**Jonni Bidwell** 会称其为亵渎，但现在他发现这是一种辉煌的发展。

### 我们的测试方法...

我们将每个发行版安装在 Dell XPS13 上，这让我们能够测试 HiDPI 和触摸屏支持。我们确认这些发行版可以愉快地与其他操作系统共存，而不会破坏它们。进一步测试在虚拟机中进行（限制为 3GB 内存），这让我们对发行版在较旧硬件上的运行情况有了一个大致的了解。

我们查看了开箱即用的安装内容，以及这些内容是否在用例性和臃肿之间取得了正确的平衡。由于我们专注于提供桌面的发行版，我们查看这些桌面的时尚程度和有效性。请记住，您可以按照喜好安装和配置替代的桌面。

我们将这些发行版的软件仓库与 Arch Linux 的仓库进行了比较，后者以提供最新软件和对上游发行版进行最少更改而闻名。特别是，我们查看了每个发行版使用的桌面软件包。我们还检查了每个发行版如何与 Arch 用户仓库 (AUR) 集成。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_17_0.png)

很少有人会不同意 Arch 是一个优秀的发行版：处于前沿、可定制、拥有热情的社区和出色的文档。但它并不适合每个人。许多人被缺乏安装器所劝退：不得不手动分区磁盘并 chroot 到引导安装中以开始工作，这在用户友好性方面没有任何加分。克服这一障碍的人将面临一个新的挑战：即将最小化安装构建为可用的东西。如果你是为了桌面使用而安装它，你会发现让那个桌面看起来并运行良好绝非易事。

简而言之，这真的让你欣赏其他发行版所做出的努力，以便所有这一切都能开箱即用。但 Arch 的优点可以与其他发行版的便利性相结合。想象一下，你永远不会需要添加 PPA 来获取新发布版本。想象一下，你可以重建标准软件的自定义版本。想象一下，然后不再想象。这里我们将关注桌面变体，因此我们将特别关注现代桌面创新，但人们已将 Arch Linux 用作所有种类事物的基础（安全、树莓派、32 位硬件，列表还在继续），比如其灵活性。

### 安装与首次运行

安装程序是否欢迎你？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_18_0.png)

Antergos 一开始就以其时尚的 Cnchi 安装器给人印象深刻。你可以选择设置流行的应用程序和桌面。这些都需要下载，这使得离线安装变得不可能，但它通过提供寻找最快镜像的功能提供了便利。如果你担心安装失败而必须重新开始，你可以选择在目标设备上创建恢复分区。这是一个贴心的设计，但庆幸的是，我们没有理由使用它。你甚至可以在 GRUB2 和 systemd-boot 之间选择，进行加密安装，甚至使用 ZFS。

Manjaro 的实时介质从一个简朴的菜单开始，用于选择键盘映射、免费与非免费驱动或添加内核参数。一旦 Calamares（参见 LFK233）安装器启动，我们将遇到通常的选项（LVM 和加密），你可以选择擦除驱动器、与其他操作系统并排安装或手动分区。一旦启动进入 Manjaro，欢迎屏幕将显示发布信息，并提供指向 Wiki 的链接。还有一个用于安装流行应用程序的便捷工具。

Netrunner 作为 Manjaro 的后裔，具有类似的安装过程。新人可能会发现桌面上的 Readme 图标将他们带到 404 页面并伴随混合内容警告，有点不习惯，但这只是表面问题。KaOS 也使用 Calamares 安装器。XFS 作为默认文件系统是一个略显得古怪的选择，但为什么不呢？安装完成后，Croeso（威尔士语中的“欢迎”）工具会迎接你，并提供指向文档和常见系统设置的快捷方式。如果你不知道 Plasma 将这些东西隐藏在何处，这会很方便，即使你知道，也能将它们都集中在一个地方是很棒的。Croeso 比 Manjaro 的欢迎工具有更多选项。

> Antergos 是某种桌面变形者。就像它的 Arch 父母一样，它可以是你想要的任何样子。

ArchLabs 的 Ncurses 安装器对新用户不友好，但提供了与 Antergos 相同的选项，并在重启前执行完整的系统更新。由于实时介质自 2018 年 7 月以来未更新，这是一个相当长的过程。一旦重启，一个菜单允许你安装流行的应用程序、字体等。如果你不喜欢从控制台登录，LightDM 显示管理器也可以轻松从这里获得。

Antergos 的 Cnchi 为 Linux 安装器设定了新标准。ArchLabs 的文本体验无法竞争，但控制台战士不会介意。

### 软件仓库

这些仓库如何保持更新？

请注意，我们在此使用标准的 Arch 仓库作为基准，除非你自己打包或使用 snaps，否则这几乎是获取最新上游发行版的最快方式。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_18_1.png)

Manjaro 借鉴了 Debian 的做法，提供 Stable、Testing 和 Unstable 分支。Unstable 包通常滞后 Arch 仓库三天左右，这应该对任何人来说都足够新鲜。当软件包“准备好”时会进入 stable 分支，但通常这非常快，除非出现紧急情况。

在撰写本文时，新版本 Systemd 存在稳定性问题，但除此之外我们未发现重大差异。Netrunner Rolling 基于 Manjaro 的 Stable 频道（尽管少数自定义包来自其自己的仓库），因此它可以享受 Manjaro 仓库中 12,000 多个包。

> KaOS 在其仓库中只有几千个包。这比 Arch 能提供的少得多，但也许这已经是你需要的全部。

KaOS 往往落后得更多一些，你在其仓库中找到的图形应用程序只有 Qt 应用程序，例如其侧重于 KDE Plasma 的特性。如果你需要其他东西，你就得自己构建它。你可以从 KaOS 社区包仓库这样做，鉴于 KaOS 仓库有限，这极大地扩展了其兴趣范围。KaOS 使用 Plasma 5.14，而 Netrunner 使用 Plasma 5.12，两者目前都使用 KDE 应用程序套件 18.08 版本，希望刚发布的 18.12 应用程序包很快能祝福这些 KDE 发行版。最后，Antergos 维护少量自己的包，但否则依赖 Arch Linux 仓库，而 ArchLabs 仅使用 Arch 仓库。

## 发行版

### 风格

**哪个发行版提供桌面的风采？**

比较不同的桌面是一件棘手的事，尤其当我们拥有来自整个频谱的各种物种时。我们不会因为 ArchLabs 使用轻量级窗口管理器而扣分，也不会因为 Antergos 使用现成（虽然不可否认很酷）的图标主题而加分。相反，我们将关注每个桌面相对于已安装组件的风格。我们关注图标和配色方案的协作、精心考虑的布局以及无杂乱。由于我们熟悉在 Arch 中从头设置各种桌面环境，我们将为整理常见怪癖或偏离默认设置（只要这些偏离是有用的）给予认可。无论你最终使用什么桌面，由于 Arch 始终提供最新发行版，你最终可能会得到看起来和运行起来比其他发行版更好的东西。如果没有，好吧，你至少可能发现了一个全新的 bug，或者你可能瞥见了一些其他发行版用户几个月后将要抱怨的内容。

#### **Antergos GNOME** 7/10

Antergos 是我们唯一的 Gnome 提供方案，但即使在我们到达那里之前，我们在启动期间看到的时尚控制台字体设置就给我们留下了深刻印象。Dash-to-dock 在左侧提供了一个启动器（类似 Unity 和 Budgie），装饰着以粗体 Nurmix Square 主题风格的图标，该主题贯穿整个桌面。Files 中明亮的橙色目录图标可能不符合每个人的口味，但我们很喜欢。Tweaks 和 User Themes 扩展已安装，用于按你的喜好调整和更改主题。

如果你选择使用 Antergos 的 Gnome，你可能希望用 GDM 替换看起来笨重的 LightDM 登录界面，有一个专门的 Wiki 页面用于此目的。如果有“最大标题栏”奖项，Antergos 会赢，但使用新型 GTK3 标题栏的 Gnome 应用程序看起来很适应它们。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_19_0.png)

#### **ArchLabs** 9/10

我们喜欢应用于 OpenBox 和 Polybar 面板的极简主义深色风格。得益于 Compton，一些阴影和淡入淡出效果意味着桌面，尽管低调，但仍然看起来现代。ArchLabs 的彩色图标主题与所有的黑暗形成鲜明的对比。你可以从偏好菜单中轻松地将 Polybar 切换为 Tint2，或添加一个 dock（如 Plank 或 Docky）。

如果你觉得 Conky 污染了你的桌面背景，它也可以被移除。不过它确实提供一些有用的提示，最重要的是，Drun 启动器可以通过按 Super 键访问。桌面分页器上的视觉提示（Home、Web、Files 和 Pictures）对于充分利用四个虚拟桌面非常棒。使用了一些 Xfce 组件，还可以从欢迎菜单中添加更多 - 甚至整个 Xfce。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_19_1.png)

### 软件包管理

**我们的候选者如何驯服 Pacman 并与 AUR 集成？**

所有发行版都允许使用优秀的 Arch Pacman 工具，但这对于想要图形化操作的人来说可能不是理想的。Pacmac GUI 包含在 Antergos 以及 Manjaro 的 Xfce 和 Gnome 版本中。这比 Netrunner 和 KaOS（以及 Manjaro KDE）使用的类似 Synaptic 的 Octopi 稍微流畅一点。KaOS 包含一个 GUI 缓存清理器和软件包日志，但命令行工具也可以同样好地执行这些任务。Netrunner 还提供类似应用商店的 KDE Discover。ArchLabs 允许从其欢迎菜单安装 Pacman，但在此处以 CLI 方式操作似乎更合适，说到这一点，它包含基于文本的 Pacif 前端。Pacif 可以帮助降级软件包，这是 Arch Linux 不支持但偶尔必要的功能。Manjaro 的内核工具会建议你新的内核，Netrunner 中也有，但我们发现必须手动调用它才能升级到新的主要版本。这可能是我们的误操作。Pacman 可以通过各种助手进一步增强，用于构建和安装来自著名且非常有用的 Arch 用户仓库 (AUR) 的自定义软件包。Pacmac 和 Octopi 都显示新软件包通知，并可选择与 AUR 集成。然而，AUR 软件包可能与来自 Arch 仓库外部的任何内容不兼容，因此在使用自定义仓库的发行版上，特别是 Manjaro，应当谨慎。目前，ArchLabs（你最不可能遇到 AUR 冲突的地方）使用 AuRman 助手，但由于该工具的开发正在放缓，Yay 可能是更好的选择。或者，Pacif 也可以作为曾经首屈一指、如今已不幸停用的 Yaourt AUR 助手的前端。
