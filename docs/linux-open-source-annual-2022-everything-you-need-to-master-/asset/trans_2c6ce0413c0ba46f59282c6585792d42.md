
首先，在较新的安装环境中（基于 18.04.1 点发布的版本），需要启用 Multiverse 和 Restricted 仓库：

```bash
$ sudo add-apt-repository multiverse
$ sudo add-apt-repository restricted
```

我们还需要添加 node.js 和 Yarn 仓库，这使用了一种略显不雅但不可否认的便捷做法：将 curl 的输出通过管道传递给 bash：

```bash
$ curl -sL https://deb.nodesource.com/setup_8.x | sudo bash -
$ curl -sS https://dl.yarnpkg.com/debian/pubkey.gpg | sudo apt-key add -
$ echo "deb https://dl.yarnpkg.com/debian/ stable main" | sudo tee /etc/apt/sources.list.d/yarn.list
$ sudo apt update
```

现在我们可以安装依赖项了，依赖项很多（你可能想从之前链接的 Tootsuite GitHub 页面复制并粘贴此命令 – 只需跟随 Standalone Installation 链接即可）：

```bash
$ sudo apt -y install imagemagick ffmpeg libpq-dev libvips-dev libssl1.1-dev file git-core \
libprotobuf-dev protobuf-compiler pkg-config nodejs gcc autoconf build-essential libssl-dev \
libyaml-dev libreadline6-dev zlib1g-dev libncurses5-dev libffi-dev libgdbm5 libgdbm-dev \
nginx redis-server redis-tools postgresql postgresql-contrib certbot yarn libidn11-dev libicu-dev
```

接下来，我们将设置一个 Mastodon 用户并构建 Ruby 环境，步骤如下：

```bash
$ sudo adduser mastodon
$ su - mastodon
$ git clone https://github.com/rbenv/rbenv.git ~/.rbenv
$ cd ~/.rbenv && src/configure && make -C src
$ echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
$ echo 'eval "$(rbenv init -)"' >> ~/.bashrc
```

### 社交网络的开源探索

我们在这里专注于 Mastodon，但还有各种其他开源的、去中心化的流行社交媒体平台替代品。PeerTube 是一个使用 WebTorrent 技术来减轻服务器负担的视频共享平台（同样，任何人都可以托管服务器，且服务器之间可以联合）。当用户观看视频时，他们也会将其分享给其他用户，为热门视频创造了一种正向反馈循环。

对于静态图片，以及那些寻找 Instagram 或 Flickr 之外归宿的人，这里有 Pixelfed (https://pixelfed.org)。与 Mastodon 类似，你可以托管自己的 Pixelfed 实例并与其他实例联合，比如你在 https://pixelfed.social 可以找到的那个实例。对于更偏向 Facebook 而非 Twitter 类型的去中心化社交网络，你应该关注 Diaspora* (https://diasporafoundation.org)。实例被称为“pods”，而 pods 可以基于地理位置、兴趣、酷炫的域名或受欢迎程度。对于拿不定主意的人，The Federation (https://the-federation.info) 收集了不仅限于 diaspora* pods 的自愿统计数据，还包括本文提到的所有网络以及更多网络的实例数据。联邦制模糊了传统的边界，因此许多这些网络可以互相通信，无论是通过交叉发帖工具还是通过 ActivityPub 原生实现。

我们需要重启 shell 以应用这些环境变更，然后安装 ruby-build 并安装所需的 Ruby 版本：

```bash
$ exec bash
$ git clone https://github.com/rbenv/ruby-build.git ~/rbenv/plugins/ruby-build
$ rbenv install 2.5.1
$ rbenv global 2.5.1
```

现在我们可以克隆 Mastodon 仓库，检出最新的稳定版本（撰写本文时为 v2.5.0），并安装所需的 Ruby gems 和 node.js 包。请将 bundle 命令中的 `--jobs` 参数更改为机器上的核心数，如下所示：

```bash
$ cd -
$ git clone https://github.com/tootsuite/mastodon.git live
$ cd live
$ git checkout $(git tag -l | grep -v 'rc[0-9]*$' | sort -V | tail -n 1)
$ gem install bundler
$ bundle install --jobs 2 --deployment --without development test
$ yarn install --pure-lockfile
```

### 你的数据命运

> “自雅虎收购 Flickr 以及 YouTube 被谷歌同化以来，人们一直担心他们的图片和视频被如何使用”

```bash
$ sudo -u postgres psql
postgres=# CREATE USER mastodon CREATEDB;
postgres=# \q
```

设置 Web 服务器和 https 证书超出了本文范围，因此我们假设你已经运行了 Nginx，并拥有该域名的域名和 SSL 证书。为你的 Mastodon 站点创建一个空的配置文件，例如 (/etc/nginx/sites-available/lxfmastodon.net.conf)，并将此名称更改以匹配你的域名。然后复制、粘贴并修改来自 https://github.com/tootsuite/documentation/blob/master/Running-Mastodon/Production-guide.md 中示例 Nginx 配置文件的 example.com URLs（大约在页面中间位置）。你还会在那里找到使用 Let's Encrypt 生成和续订免费 SSL 证书的说明。现在我们可以使用 `sudo ln -s /sites-available/lxfmastodon.net.conf /etc/nginx/sites-enabled/` 激活我们的 Mastodon 站点。

所有部件现已就位，我们可以运行 Mastodon 设置向导，我们将以之前设置的 mastodon 用户身份执行：`sudo su - mastodon`，`cd ~/live`，`RAILS_ENV=production bundle exec rake mastodon:setup`。

系统会提示你输入你的域名，是否使用单用户模式（用于测试目的很有用），是否正在使用 Docker（这次不是），PostgreSQL 详细信息（除非你更改了某些设置，否则默认值是正确的 – 数据库用户故意没有密码）。Mastodon 可以发送邮件（用于账户验证和恢复目的），可以使用本地服务器或通过 Mailgun 等外部服务。也可以运行一个不发送邮件的实例。你会被提示设置一个管理员用户，你应该这样做，因为你需要管理你的实例。会为你生成一个密码：请记下来并在登录时更改。

### 设置服务

我们的工作即将完成，我们只需要设置三个 Systemd 服务：`mastodon-web`、`mastodon-sidekiq` 和 `mastodon-streaming`，它们应放置在 `/etc/systemd/system/` 中。同样，你可以从之前链接的设置指南中找到并复制粘贴它们的内容。我们可以使用 `sudo systemctl enable --now /etc/systemd/system/mastodon-*.service` 一次性启动并启用这三个服务。

现在，祝你好运，你应该能够通过 Web 浏览器访问你的 Mastodon 实例了。使用你注册的电子邮件地址和提供的密码登录，并告诉你的所有朋友来注册！

### SOLID 与去中心化 Web

蒂姆·伯纳斯-李教授（Professor Tim Berners-Lee）发明了万维网，所以当他宣布他的发明“已经演变成不公和分裂的引擎”时（参见 https://medium.com/@timberners_lee/one-small-step-for-the-web-87f92217d085），人们往往会倾听。该教授及其在 MIT 的团队提出了一个重新发明它的计划。建立在现有 Web 之上的 Solid 平台旨在赋予用户选择数据存储位置、谁可以查看数据以及如何使用数据的能力。Solid 是“Social Linked Data”（社会关联数据）的合成词，而关联数据的理念并不新鲜 - 伯纳斯-李在 2006 年引入了它，同时也引入了语义 Web 的理念。它使发布的数据能够根据上下文进行链接，并源自外部来源，使其不再受制于特定的提供商或应用程序。如果出现新的、更好的应用程序，它可以访问并重新使用与其较差的前任相同的数据。

这是一项雄心勃勃的努力，但 Solid 并不是唯一旨在实现对 Web 的去中心化重构的项目。ZeroNet、SAFE（Secure Access For Everyone）网络和 PiperNet 都希望通过各自的方式实现这一目标。
