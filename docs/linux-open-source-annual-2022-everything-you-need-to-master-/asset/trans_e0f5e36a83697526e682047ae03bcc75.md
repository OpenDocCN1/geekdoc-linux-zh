

## 文件管理

掌控你的数据，决定其可访问的位置，并进行归档。

### Eiciel (45)

在 Linux 中，一切都以文件形式存在，而访问控制列表（ACL）有助于确定每个文件的访问权限。你可以通过命令行修改权限，也可以使用大多数发行版官方软件源中提供的图形化 *Eiciel* 工具。

https://rofi.roger-ferrier.org/eiciel

### Nextcloud

在线存储服务是在全球任何地方访问和共享数据的便捷选择。使用 *Nextcloud*，你可以部署一个托管存储服务器，从而享受无处不在的存储服务的便利，而无需向第三方支付大量费用并交付你的数据。

安装和部署 *Nextcloud* 是一个相对简单且文档完善的过程。它拥有一个功能丰富且直观的 Web 界面，即使是首次用户也不难掌握其导航方式，考虑到它背后的庞大功能数量，这一点本身就值得称赞。该项目具有良好的可扩展性，既可用于家庭网络，也可用于企业网络。你可以使用其管理部分将其与其他相关的网络服务（如目录服务器）集成，以导入用户。

通过网络上的其他用户或公共 URL 共享文件非常简单。服务器确保对共享文件所做的更改同步到所有用户。它还可以访问存储在 Amazon、Google 和 Dropbox 等多种云服务上的文件。

https://nextcloud.com

### FSLint

你可以使用图形化的 *FSLint* 工具对文件系统进行全面清理。它可以删除重复文件、临时文件，以及其他难以定位和删除的文件，例如名称无效的文件、空目录和无效的 ID。

www.pixelbeat.org/fslint

### Open Media Vault

如果你对数据的安全保护需求超出了简单的备份方案，那么你需要将一台闲置的电脑（甚至树莓派）转换为基于 Debian 的 *Open Media Vault* (OMV) 服务器的专用网络附加存储（NAS）设备。

*OMV* 部署简单，管理方便，这得益于其设计良好的基于浏览器的用户界面，使其甚至适合非技术用户。它支持所有流行的部署机制，包括多级软件 RAID，你可以使用所有流行的网络协议（如 SSH、SMB/CIFS、FTP 和 Rsync）访问其中存储的数据。服务器还拥有一个详尽的权限系统，用于控制对共享卷和文件夹的访问。该服务器采用模块化设计，可以通过各种官方和第三方插件进行扩展。例如，你可以将 NAS 变成一个 torrent 客户端，直接下载数据到 NAS 存储中，或者用它来在网络上流式传输存储的音乐。

www.openmediavault.org

### Syncthing

作为流行但专有的 *BitTorrent Sync* 的开源替代品，Syncthing 可以在局域网内或全球范围内同步你的文件。该服务使用全球发现服务来连接互联网上的客户端。

https://syncthing.net

### Catfish

作为 find 和 locate CLI 工具的图形化替代品，*Catfish* 是一个多功能工具，具有各种选项，可帮助你筛选搜索结果并找到你正在寻找的文件。

www.twotoast.de/index.php/catfish

### PeaZip

该图形化压缩工具可以读取大多数归档格式，并拥有一些有用的数据安全功能，例如创建带有加密和双因素身份验证的归档文件。

www.peazip.org

### ExifTool

这是一个用于处理图像元数据的 CLI 工具，*ExifTool* 帮助你基于元数据操作文件。用户还可以使用它在在线分享图像之前剥离所有元数据。

www.sno.phy.queensu.ca/~phil/exiftool/

### Tkdiff

这是 *diff* 工具的图形化前端，你可以使用 *Tkdiff* 来比较两个文件。该工具可以连接多种源代码管理系统，并具有其他多种功能。

https://tkdiff.sourceforge.io

### Ranger

*Ranger* 拥有一个基于 curses 的界面，可在控制台内运行。该工具支持 VI 键位绑定，利用文件启动器，并且能够预览图像和视频。

https://github.com/ranger/ranger

## 通信

安全聊天或建立你自己的社交网络。面对面的，Facebook！

### Jitsi

作为一款全能即时通讯应用，Jitsi 拥有令人印象深刻的音频和视频会议功能集。作为 VoIP 客户端，它允许你使用会话初始协议（SIP）进行通话。它具备软电话预期的所有功能，可以静音、保持、转移和录制通话。它还可以对本地网络上的其他 Jitsi 用户进行无需注册表的 SIP 通话。

你可以使用 Jitsi 通过 SIP 和 XMPP 网络与单个用户或多个用户进行视频通话，同时使用 Jitsi Videobridge，你可以主持多人视频通话。它也是一个功能强大的即时消息客户端，具有多项独特功能，包括能够同时流式传输和共享通话两端用户的桌面。

https://jitsi.org

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_171_0.png)

### Rocket.Chat

自称“终极聊天平台”的 Rocket.Chat 充满了有用的功能。除了线程对话以及编辑和删除消息等基本功能外，这个协作通信服务器还提供了多项有趣的功能，例如实时聊天，你可以使用 Rocket.Chat 与访问你网站的用户进行交流。

你可以在支持 snap 的发行版上通过单条命令部署 Rocket.Chat，它还支持通过 Docker 和广泛的 PaaS 服务进行部署。它还可以从 Slack 或 Hipchat 等其他服务导入你的数据，并通过 SlackBridge 插件将 Slack 频道或私人组中收到的消息实时镜像到 Rocket.Chat 中。

### Tox

如果你认为常规即时通讯客户端不够安全，请使用 Tox IM 协议，该协议使用 NaCl 加密库对所有聊天进行加密，并且不使用中央服务器，而是通过用户之间的直接 P2P 连接进行路由。该即时消息使用 Tox ID（即对等方的公钥）代替用户账户，并允许更高的匿名性。

https://tox.chat

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_171_1.png)

有几个应用程序可以使用 Tox 协议进行通信，其中最受欢迎的是 Qtox，它支持多个平台。

Rocket.Chat 还允许你与团队进行视频通话。你還可以录​​制并向公共或私人对话发送语音消息。

https://rocket.chat/community

### BeeBEEP

BeeBEEP 是一款与众不同的即时通讯客户端，旨在直接连接你与网络上的对等节点。它会自动检测网络上的其他 BeeBEEP 用户，并提供现代聊天客户端的所有功能，除了加密文本消息外，还可以共享文件。

http://beebep.sourceforge.net

### Openfire

虽然有许多基于 XMPP 的即时通讯服务器可用，但 Openfire 是最易于管理的一个。它实现了 XMPP 协议中许多常用的功能。虽然你可以使用任何兼容 XMPP 的即时通讯客户端通过 Openfire 进行聊天，但它与自家的 Spark 客户端配合效果最佳。

www.igniterealtime.org/projects/openfire

### Signal

https://signal.org
