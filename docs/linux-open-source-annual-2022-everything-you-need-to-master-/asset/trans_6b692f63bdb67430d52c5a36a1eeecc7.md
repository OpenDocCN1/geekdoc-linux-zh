
## 深入探索

### 漏洞与利用

恶意软件始于程序被攻破，终于泪流满面。看看我们如何将其驯服。

缺乏对内存管理、指针和执行栈的一些了解，就很难严格地解释程序是如何被攻陷的，从而使恶意软件得以作恶。现在既非深入探究之时，亦非其地，但我们至少可以提供一种略带含糊其辞的说法，来描述程序可能如何被利用。

程序处理输入，这些输入可能来自用户、网站、其他程序、某件硬件（如键盘或传感器）或文件。为了让程序正确运行，该输入必须是正确格式化的。如果并非如此，它就无法完美地装入内存，可怕的事情就会发生。稍后我们会更具体地说明那些可怕的事情是什么，请耐心等待。因此，某种形式的输入验证应该进行。如果没有，程序将试图消化一些大小或形状不适合其分配内存的东西。可想而知，这种不相容性的结果可能是不可预测的。为了把这个比喻说透，你可能会目睹介于反刍和食物昏迷之间的任何一种数字等价物。这可能是应用程序崩溃或系统减速。

### CVE、Bug 与赏金

报告新发现的漏洞有好办法也有坏办法。在披露给相关供应商或项目之前，这些被称为零日漏洞（zero-day bugs）。零日即披露发生之日。如果你掌握了一个零日漏洞，你可以在 Twitter 上吹嘘（并在允许超过 280 字符的某个媒介上发布完整细节）——这会让受影响方，尤其是相关项目，陷入恐慌，并可能引发一波脚本小子（script-kiddie）的攻击。

更好的做法是负责任地私下披露漏洞，以便在事态失控之前推出修复方案。一些项目甚至运行着 Bug 赏金计划，以奖励此类努力。漏洞被分配了 ID，列在 Mitre 的通用漏洞和暴露（CVE）列表中，一旦合适的补丁就位，将在 https://cve.mitre.org 提供该漏洞的公开细节。这将迅速被所有优秀的发行版捡起并打包，因为此事刻不容缓。相关方可能不会在合理的时间框架内回应，或者对此不感兴趣，此时公开化就成了一个选择。

在我们撰写本文时，最近可能影响我们的漏洞是 CVE-2019-5953，即古老 wget（一个通过 HTTP 获取事物（很可能是网页）的命令行实用程序）中的缓冲区溢出。使用此工具下载恶意构造的文件可能导致任意代码执行，以及非常糟糕的一天。

### 克服缓冲区溢出

程序员们花了 30 年时间试图避免导致这些漏洞及其利用的那种疏忽。但正如我们引用对 Mozilla 程序员 Jim Blandy 的 **2015** 年采访所言：“实验已经完成。不能指望人来编写那种代码”。相反于放弃编写代码，专家们提出了新的“内存安全”语言，如 Mozilla 的 Rust、Google 的 Go 和 Apple 的 Swift，这些语言虽然并非完全无法被利用，但至少扼杀了许多常见的内存漏洞。

但用这些语言重写大型项目不可能一蹴而就，而且对于依赖 C 语言特性和速度的大型项目（如 Linux 内核）来说，这也不是一个选项。不过，并非全是悲观景象——这些语言在许多地方已被有效使用。Mozilla 自 2012 年起一直在开发基于 Rust 的 Web 引擎 Servo，Go 继续是时髦系统程序员的首选语言。Swift 也很流行，但与其引用一个实际例子，我们不妨把你引向 **@swift_on_security** Twitter 账号，在那里你会发现当今信息安全的离经叛道之述。

颠覆利用的一个重大突破在 2005 年左右成为主流，形式为地址空间布局随机化（ASLR，原始 PaX 内核补丁出现在 2000 年）。这在程序加载时打乱了所需的内存中的数据。在 ASLR 之前，攻击者可以弄清楚程序的资源（如堆栈和库）在内存中的位置。因此，如果程序存在某种漏洞，可以通过写入数据来利用，这些数据保证会覆盖，例如，堆栈。

在 Word 宏病毒和电子邮件蠕虫如潮水般涌来的中潮中——与数据执行保护（防止指定地址既可写又可执行）一起——这对 Windows 来说是个好消息。它消除了一整类漏洞。不再能仅找到任意漏洞并将其用于将任意 shellcode 粘入执行堆栈。不幸的是，不法之徒与时俱进，新的、更邪恶的技术（如返回导向编程和堆喷射）演化出来，且至今利用案例层出不穷。

幸运的是，像 **Valgrind** 这样的工具使检测其中的一些（至少）稍微容易一些。

**ASLR** 在 2014 年被扩展到 Linux 内核本身，创造了一个新缩写（**KASLR**），并防御恶毒的内核利用。然而，事实证明，KASLR 可以通过现代 CPU 上的计时漏洞来击败，因此需要进一步的防御。这些以内核页表隔离（**KPTI**）的形式出现，旨在解决 Meltdown 漏洞——尽管该漏洞在 2018 年 1月公开之前一直被保密。Meltdown 意味着通过利用竞态条件，非授权进程可以提取特权信息。

最终，它使流氓进程能够读取内核或其他进程（如密码管理器）的内存。由于可以通过 JavaScript 利用，这也意味着一个标签页可以访问另一个标签页中的信息，这相当可怕。欲了解有关 Meltdown（及相关 Spectre）漏洞的更多信息，请参见我们在 **LXF235** 中的精彩专题。

## 唯一的 Linux 杀毒软件……

你的桌面可能不需要它，但 Linux 也有杀毒软件。

许多流行的 Windows 杀毒程序都有 Linux 对应版本（Sophos、ESET NOD32、Comodo、F-PROT）。但通常这些程序做的无非是扫描 Windows 病毒的签名。这并不意味着应完全忽略它们：如果你使用 Wine 运行 Windows 程序，可能会无意中运行 Windows 恶意软件。此外，如果你运行电子邮件服务器，扫描传入消息中的 Windows 威胁绝对符合你的利益。即使你不运行，也许你更想知道你那个记不清下载的文件是否包含 Windows 病毒，并且也许从 Linux 扫描它会让你感觉更安全。

### 猖獗的恶意软件

随着世界陷入地缘政治混乱，我们越来越多地听到关于国家阴影般的“网络行动”及其内部居住的邪恶天才黑客的消息。朝鲜、俄罗斯、中国和伊朗都被西方政府指责犯有各种网络不法行为。基于泄露的 NSA 利用工具 EternalBlue 的 WannaCry 勒索软件，通常被认为来自朝鲜。这差点使英国的医疗服务瘫痪，若非安全研究员 Marcus Hutchins 的灵巧工作，情况可能会更糟，他能够分析恶意软件并找到一个终止开关。不幸的是，Hutchins 最近承认在 2014 年涉及恶意软件研究的阴影面，犯有电信欺诈罪。自去年发现以来，俄罗斯 VPNFilter 恶意软件已在半百台路由器上检测到。思科研究人员将其描述为“瑞士军刀式黑客工具”，因为它具有模块化结构以及通过固件注入在重启后持续存在的能力。一个模块试图降级 TLS 连接，以便可以嗅探并可能篡改 Web 流量。一个主要的命令和控制（CnC）服务器被 FBI 没收，但感染仍在继续，表明僵尸网络具有相当的韧性。该恶意软件通过从 **Photobucket.com** 下载图像来寻找其他服务器，这些图像的 EXIF 数据中隐藏了 IP 地址。

我们将研究看起来唯一的开源杀毒软件 ClamAV。实际上我们在 LXF131 中很久以前就研究过了，老实说，除了版本号更高，它变化不大。Ubuntu 19.04 仓库包含几乎最新的 ClamAV 版本（其网站上的 0.100.3 对 0.101.2）。旧版本的程序可用于以前的 Ubuntu 版本，或者如果你胆子大可以自行编译——PPA 已不存在。一般来说，使用旧版本没问题，因为它仍会下载最新的定义。安装只需：

```
$ sudo apt update
$ sudo apt install clamav
```

ClamAV 核心包含三个主要组件：

- **clamscan** – 用于扫描文件和目录的命令行工具。
- **clamd** – 在后台运行，允许在访问时扫描文件的守护进程。
- **freshclam** – 用于更新病毒签名数据库的工具。

守护进程包含在一个单独的包中，因此如果你对按需扫描（可能会减慢系统或消耗大量内存）不感兴趣，别担心：

```
$ sudo apt install clamav-daemon
```

你可以手动运行：

```
$ sudo freshclam
```

来更新数据库，但提供了一个 systemd 服务文件来自动执行此操作。事实证明，如果在服务器运行时尝试运行该命令，你会得到错误。可以使用以下命令停止该服务：

```
$ sudo systemctl stop clamav-freshclam
```

这对于想要设置 cron 任务的人可能感兴趣（本着 LXF131 的精神）。与此同时，让我们继续测试我们光荣的杀毒软件。我们将下载 EICAR 测试文件，其中包含 ClamAV 应当识别的（无害的！）签名：

```
$ wget https://www.eicar.org/download/eicar.com.txt
$ clamscan eicar.com.txt
```

你应该看到与截图匹配的输出（见右上）。对于通用按需使用，你只需调用 **clamscan** 并附带你想扫描的文件或目录。若要深入目录或整个文件系统，请使用命令：

```
$ clamscan --recursive /
```

如果你感到偏执，可以从 **https://github.com/extremeshock/clamav-unofficial-signatures** 仓库下载一些第三方签名。这些来自各种来源（包括专注于 Linux 的 Linux Malware Detect，另一种开源恶意软件扫描器），会增加误报几率，但也可能增加你的安心感。
