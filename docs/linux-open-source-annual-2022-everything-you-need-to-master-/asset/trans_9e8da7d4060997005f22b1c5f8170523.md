
## 易用性

它们的亮点是什么？

与桌面应用程序不同，磁盘克隆工具是管理型软件，具有基于向导的前端界面以进行导航。我们绝不期望这些工具能够满足那些不了解自己正在进行什么操作的非技术受众的需求，但逻辑布局清晰、流程路径明确的界面将有助于充分利用这些工具。易于部署和合理的默认设置是锦上添花，虽然它们并非选择优秀管理工具的关键，但也不会对工具的表现产生负面影响。

### Clonezilla

**8/10**

凭借直观的[真的吗？——编者按]导航界面，Clonezilla 是 Linux 论坛中备受推荐的将旧磁盘镜像到更大新磁盘的工具之一。在后台，Clonezilla 使用一系列脚本以及 Partimage、ntfsclone、Partclone 和 dd 等多个开源磁盘实用工具，帮助您复制单个分区和完整磁盘。

菜单提供了合理的默认值，因此你通常会选择推荐选项。请确保要克隆的分区未挂载。此外，尽管其基于文本的界面不起眼，但 Clonezilla 并不令人生畏，因为其屏幕内容非常详尽。每一步都标有相关信息，帮助你做出明智的选择。尽管如此，Clonezilla 并不是在没有足够知识和经验的情况下可以随意操作的工具。

### Deepin Clone

**8/10**

如果说在易用性方面 Deepin Clone 胜过其他竞争产品，那确实是如此：这个应用真的非常简单。

在第一个屏幕上，它会询问你是希望克隆整个磁盘还是单个分区。根据你的选择，它会显示另一组选项，帮助你缩小想要克隆的磁盘/分区范围。

在随后的屏幕上，你会看到磁盘或分区的列表。与本次测试中的其他一些选项不同，如果你选择了克隆分区选项，该应用不允许你一次性克隆多个分区。此外，其默认的克隆模式是直接进行磁盘到磁盘或分区到分区的数据传输，这种方式相当不安全，也是我们绝不建议的做法。

另外，如果要使用 Deepin Clone 为当前安装环境创建镜像，你需要通过 Deepin 恢复环境运行它。

## 支持的文件系统

它们能在网络中的所有机器上正常工作吗？

Clonezilla 支持大量文件系统，从流行的 ext2/3/4、ReiserFS4、Btrfs、FAT16/32 和 NTFS 到专业的 XFS、JFS 和 UFS。但这并不意味着它对不支持的文件系统完全无法使用。对于支持的文件系统，Clonezilla 仅镜像已使用的块，以实现更好的恢复功能。如果遇到它无法识别的文件系统，Clonezilla 会使用 dd 按原样镜像内容，你可以轻松地将这些数据恢复到相同大小的磁盘上。

与 Clonezilla 类似，G4L 也工作于两种模式。在文件系统层面，它使用 NTFSclone 和 FSArchiver 等实用工具直接克隆支持的文件系统，包括几乎所有流行的文件系统。如果你处理的是小众文件系统或需要克隆整个磁盘，可以使用 G4L 的 RAW 模式来复制任何文件系统的原始位数据。

FOG Project 在后台使用 Partimage 和 PartClone，因此它支持所有流行的文件系统。其镜像功能还允许你使用 dd 创建驱动器的扇区级镜像。

相比之下，关于 Deepin Clone 工作原理的互联网信息不多，它也没有提供任何暗示其支持哪些文件系统的可配置参数。然而，在我们的测试中，它能在 ext4 和 NTFS 分区上正常工作，这就足够了。

与同类工具相比，WereSync 使用 rsync 复制驱动器内容，可以对 GPT、MBR 和 LVM 驱动器的内容创建镜像。根据官方文档，你甚至可以通过指定 IMG 扩展名类型来强制将工具内容复制到文件中。

## FOG Project

**8/10**

与本文中的其他解决方案相比，FOG Project 的安装过程要复杂得多。与 Clonezilla 和 G4L 不同，你首先需要设置一个镜像服务器。虽然初始部署可能比较耗时，但 FOG Project 的 Web 界面让这一努力物有所值，因为它可以轻松地对多台计算机同时进行镜像和部署。

FOG Project 的 Web 界面对于熟悉镜像过程复杂性的用户来说相当直观。菜单排列符合逻辑，首次使用的用户应该能轻松导航。设置也具有可扩展性，你可以设置专用的存储节点，如果需要对大量计算机托管和部署镜像，这可以帮助减轻主 FOG Project 服务器的负载。你可以使用 Web 界面管理所有已镜像的计算机及其克隆镜像。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_134_0.png)

## G4L

**8/10**

与 Clonezilla 一样，G4L Live CD 的界面是基于文本的，并使用 ncurses 编写。然而，它更加冗长。创建和恢复镜像的过程会引导你通过几个向导，每个向导都包含大量步骤。与 Clonezilla 不同，G4L 附带四个不同的内核，因此你首先需要根据硬件选择其中一个。如果你在一台较旧的机器上使用 G4L，请使用较旧的内核以获得更好的兼容性。

启动时，Live 环境首先会在多个页面上显示一些基本使用说明。高级用户可以直接发出克隆或恢复命令；或者使用界面通过各种菜单构建命令。随着你进入每个屏幕，G4L 会弹出另一个屏幕，询问完成该任务所需的更多相关选项。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_134_1.png)

## WereSync

**6/10**

安装 WereSync 相当简单，因为你可以通过 Python 的 PIP 包管理器用一条命令获取它。然后你可以启动图形界面，该界面相当直观，尽管有些选项并不是一目了然的。

建议快速浏览文档，以熟悉该工具的特性。一些选项在应用本身中也附有简要说明。尽管有这些帮助途径，但仍难以区分哪些选项是必需的，哪些是可选的，以及它们包含或排除对克隆过程的影响。

令人失望的还有缺乏有意义的错误提示。默认情况下，应用的配置使得一旦开始，所有克隆任务都会以成功消息结束，即使过程已经失败。

## 帮助和支持

### 遇到麻烦时你该去哪里求助？

Clonezilla 在其网站上托管了相当全面的常见问题解答（FAQ），你应该在尝试使用该工具之前先浏览一遍。你还可以通过官方论坛直接与 Clonezilla 开发者互动，他在论坛中相当活跃。新手还可以在网络各处找到入门信息，包括 YouTube。

关于 G4L 的主要信息来源是其冗长的界面。该项目托管在 SourceForge 上，除了内置的帮助外，其网站上几乎没有其他信息。G4L 确实有一个活跃的论坛，你可以与开发者互动，开发者同样相当活跃。再次强调，就像 Clonezilla 一样，G4L 的信息覆盖很广，你可以在互联网各处找到大量的入门信息和教程。

新手会得到 FOG Project 的良好照顾。该项目在其网站上有详尽的文档，包括维基（Wiki）和详细的常见问题解答。还有一个带有针对特定发行版安装说明的安装指南。如果在 FOG Project 安装过程中遇到任何麻烦，你可以从其非常活跃的论坛板块获得帮助，甚至可以通过其 IRC 频道找到开发者和资深用户。

虽然 Deepin Clone 的界面非常直观，但正如我们所说，关于它的信息不多。除了主发行版的渠道外，它没有任何专门的支持渠道。

WereSync 工具分为两部分，一个是命令行实用程序，另一个是图形界面实用程序。该项目网页上有足够的信息来指导新手使用这两个实用程序，包括对其所有 CLI 参数的深入解释。
