## 照片编辑器

热衷摄影的亚历山大·托尔斯泰使用 Linux 上一些最好的照片编辑器，保留那些不完美的照片，以便日后修复。

### 我们是如何测试的...

编辑照片与编辑普通图像有所不同。因此，我们决定对比 Linux 上一些最佳的图像编辑器，重点关注修复常见故障、增强色彩以及找回那些可能被认为已永久丢失的细节。我们的目标是帮助你选择功能最齐全且最实用的软件，让暗淡的图像重获新生。我们将深入了解它们的先进功能，如自动增强、修复暗淡、模糊、曝光不足或过度曝光图像的能力，以及它们是否处理 RAW 文件。

这并不是我们第一次对图像或照片编辑器进行综述，但本组测试包含了不同的软件选择。五个软件中有四个是开源工具（尽管 **Lightzone** 过去曾是专有应用程序）。第五个是商业选项，读者可能不太熟悉，但对于照片编辑爱好者来说，它应该极具吸引力。继续阅读以了解更多！

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_159_1.png)

在选择照片编辑器时，选择非常丰富。有像 GIMP 或 Pinta 这样的通用编辑器，有带编辑功能（如 Digikam 或 Shotwell）的图像库管理器，还有为数字艺术家设计的软件（想想 Krita）。我们的兴趣在于修复照片和处理 RAW 文件，因此我们获取了 GIMP，并配备了其内置特效、Ufrav 插件以及来自 FX Foundry 和 G'MIC 的大量第三方插件。随后我们纳入了 Darktable 和 RawTherapee——两款经典的暗房编辑器，拥有用于提取肉眼难辨细节的工具。Lightzone 与这两款程序类似，但界面更面向大众。最后但同样重要的是 Pixelluvo，这是一款付费程序，编辑功能有限。GIMP 是唯一一个默认不使用深色 UI 主题的竞争者。虽然深色主题能给程序带来一种“专业”的感觉，但它不会掩盖我们综述中的真相！

### 获取方式
如何让程序运行起来...

有时需要额外努力才能获得并安装程序。你可能需要访问其网站并找到正确的下载选项。GIMP 不存在此类问题，因为它包含在每个 Linux 发行版中，但我们处理的是一个超级增强版 GIMP 安装，其中填充了额外的插件。GREYC’s Magic for Image Computing 可能存在于你的系统包存储库中，但如果不存在，你可以从 https://gmic.eu 获取，解压缩归档文件并将可执行文件放入 `~/.config/GIMP/2.10/plug-ins`。FX Foundry 软件包在 www.gimpfx-foundry.sourceforge.net 有自己的页面，同样需要解压缩到 `~/.config/GIMP/2.10/scripts` 中的相邻目录。虽然这一要求并不困难，但新手用户可能认为这些额外操作是高阶任务。

**RawTherapee** 和 **Darktable** 已经在软件包中捆绑了所需的一切。这两个程序很少作为默认提供包含在发行版中，但它们始终可以在在线存储库中找到——只需通过你的软件商店或包管理器检查即可。然而，**Darktable** 在本项测试中得分更高，因为它还可在 Snapstore 和 Flathub 中获取，而 **RawTherapee** 只有 AppImage 格式。

**Lightzone** 的分发方式略显繁琐。由于专有遗留原因，官方项目网站列出的信息已过时，这可能会混淆想要获取该应用的用户。不过，**Lightzone** 基于 Java，这意味着它应该是一个平台无关的应用程序，因此它通常被打包用于许多 Linux 发行版。Ubuntu、Fedora 和 openSUSE 以及其他许多发行版都有即用型包。对于 Ubuntu 兼容的发行版，你可以使用 **ppa:lightzone-team/lightzone** 处的 PPA。

**Pixelluvo** 是收费的，确切地说价格 34 美元。官方网页提供 30 天试用版下载，分别为 Ubuntu 和 Fedora 提供 DEB 和 RPM 包。这些包也可以用于其他基于 RPM 和 DEB 的发行版，或者重新打包用于 Linux 的其他变体（将 **Pixelluvo** 下载文件视为归档文件）。**Pixelluvo** 在 `/opt/pixelluvo/libs64` 包含一组旧的静态 Qt4 库，你可能需要删除它们以强制程序使用系统库。我们承认，这对于许多用户来说并非易事。此外，试用版不允许保存尺寸大于 800×600 的修改后图像。我们建议进行这些微调！

### 易用性
这五个竞争者中每一个的用户友好度如何？

此前，GIMP 是一堆浮动窗口的混乱集合，需要大量手动排列。如今，程序默认使用单窗口模式。其照片编辑功能位于 Filters > Enhancing 菜单、Filters > G'MIC-Qt 以及 FX Foundry 的独立顶级菜单下的不同位置。除非你事先知道工具在哪里，否则找起来并不容易。

**Darktable** 没有这种碎片化。然而，你首先需要让应用程序指向存放图像的目录，然后选择一个进行编辑。默认情况下，编辑工具隐藏在屏幕右侧的分类下。**RawTherapee** 拥有更深思熟虑的 UI 设计。它与 Darktable 的类似，但在编辑图像时，你不会丢失左侧的文件管理器树。此外，所有有用的工具在右侧面板中已经展开。与 Darktable 类似，Lightzone 建议用户在浏览模式和编辑模式之间切换。编辑时，每个滤镜或工具都像一个单独的浮动面板，你可以开启或关闭它们。

我们剩下的程序 Pixelluvo 在易用性方面也表现出色。照片编辑功能可以在顶部菜单栏的 Colour 和 Effect 部分找到。Pixelluvo 旨在简洁，因此在其清晰简单的可用工具列表中迷失方向几乎是不可能的。

### 修复色彩、阴影及其他
想要让你的照片拥有自然的外观吗？

我们可能仅因主观原因而偏好某种工具胜过另一种，但有一些实用测试可以揭示每个照片编辑程序的真正价值。

在此次综述中，我们在探索这五个程序时使用了几张图像作为测试对象。一张是扫描的历史彩色胶片框架，光照不足、有胶片颗粒且曝光不充分；另一张是未处理的夜间城市景观 RAW 照片，有照明但也曝光不足。

目标是在我们的五个程序中尽可能好地处理这两张照片。我们特别关注白平衡修复器和任何可用的色彩调节滑块，以及阴影、高光和级别校正工具。

归根结底，一个好的程序要么能用自动算法修复一切，要么提供足够的手动操作工具。不言而喻，唯一可接受的编辑模式是非破坏性的，用户始终可以回滚到原始图像而不会不可逆地丢失任何东西。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_161_0.png)

**Gimp**

在色彩校正方面，Gimp 凭借其快速的 GEGL 引擎表现出色。修复测试照片的颜色不需要任何第三方插件。Colour > Levels 菜单让我们能够修复白平衡（寻找三个选择器来选择黑色、灰色和白色斑点），但我们也通过仅手动调整绿色通道的级别，成功去除了图像某些部分令人不悦的绿色色调。使用 Gimp 的标准功能调整级别和曲线比使用 RawTherapee 和 Digikam 等专用软件更容易。并非一种应用程序优于另一种，而是 Gimp 对普通用户来说只是更容易使用。

在处理 RAW 文件时，Gimp 可以整合 UFRaw、RawTherapee 以及其他类似工具。结果取决于用户处理 RAW 处理器众多工具的能力。

*得分：10/10*

**Darktable**

Darktable 拥有一些高级的色彩处理工具，包括专门的白平衡部分。中性色彩拾取器工具位于级别部分下，但直觉性不强，修复白平衡需要花费相当多的时间。让该工具在 Darktable 中正常工作至关重要。我们通过单独调整色温和 RGB 各通道获得了可接受的结果。我们认为 Darktable 工具太多，许多功能重叠，因此该程序更有可能帮助你实现艺术效果，而非恢复自然色彩。

Darktable 的积极面在于处理 RAW 文件。例如，应用程序提供了原始算法用于曝光补偿，结果生成了噪点更少、局部对比度更好的愉悦图像。另一个 Darktable 独有的工具是 Velvia，它仅增强图像较亮部分的饱和度。

*得分：6/10*

### 去除图像噪声
这些程序在消除噪点并恢复细节方面表现如何？

我们之所以为 Gimp 配备第三方插件，是因为它们赋予程序先进的对抗彩色噪点和去除颗粒的工具。G'MIC 界面中的 Repair 类别包含一些高级降噪滤镜，其中最强大的也许是 Iain’s Noise Reduction。该滤镜包含一系列可配置选项，可有效去除由高 ISO 值产生的胶片颗粒或彩色噪点。

我们仅通过连续结合几个滤镜就达成了合理的结果。然而，Darktable 内置的降噪和去颗粒选项被证明甚至更有效，因为它们能更有效地保留细节。Darktable 拥有针对高 ISO 的双边降噪功能；非局部工具可用于镀铬和亮度降噪；有专门的彩色降噪工具用于 RAW 图像；通用的均衡器（Equalizer）工具可以增强许多方面，包括清晰度，并减少彩色噪点。RawTherapee 的降噪工具效力稍弱，但在处理高 ISO 的 RAW 文件时，我们认为 RawTherapee 占优，因为它生成的 JPEG 比 Darktable 处理的要平滑得多。

与其他程序相比，Lightzone 仅有一个简单的降噪工具，只有两个用于颜色和颗粒的滑块。遗憾的是，对于我们的一些测试图像，该降噪滤镜几乎没有任何效果。

最后，Pixelluvo 的 Reduce Noise 功能仅是为了勾选项而存在。它作为一个原始的中值滤波器工作，在去除噪点的同时也去除了宝贵的细节。除非你想改变原始照片的本质，否则最好避免使用。

| 裁决 | GIMP | LIGHTZONE | DARKTABLE | PIXELUVO | RAWTHERAPEE |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **得分** | 8/10 | 5/10 | 8/10 | 5/10 | 10/10 |

修复旧照片请选择 Gimp，用 RAW 照片制作完美 JPEG 请选择 RawTherapee。
