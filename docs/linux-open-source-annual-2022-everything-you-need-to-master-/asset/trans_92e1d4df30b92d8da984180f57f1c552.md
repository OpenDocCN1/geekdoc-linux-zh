### 办公套件

从最初的桌面套件和单个软件包，到如今，办公套件也已进军在线领域。**Shashank Sharma** 为您评测目前市面上最优秀的办公套件。

### 我们的测试方法...

我们在 Budgie 桌面环境中运行所有应用程序的最新版本。WPS Office 和 OnlyOffice 均提供 Snap 软件包，因此安装过程非常轻松。您可以在许多发行版的软件仓库中找到最新的 LibreOffice 和 Caligra。这就是我们没有测试它们安装便捷性的原因。不过，如果您的发行版仓库中没有最新的 Caligra，我们要提醒您避免尝试手动安装。编译过程耗时极长，最终却只会导致无法逾越的错误。

虽然我们测试了办公套件的三个常见组件，但如果有其他组件可供使用，我们同样感兴趣。另一个重要因素是对不同格式的支持，包括 ODF 以及微软 Office 的专有格式，以及它们渲染文件的方式。通过插件扩展的功能，以及帮助用户适应不同工具的相关文档，也是重要的评估标准。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_113_0.png)

自我们在 LXF167 期关注办公套件以来，为 Linux 用户提供的核心生产力应用程序已经发生了巨变。一方面，这些应用程序现在宣称对专有格式的兼容性更好。另一项重大进展是推出了类似 Google Docs 的多个在线办公套件。事实上，许多主要厂商，如微软 Office 甚至 LibreOffice，如今都提供在线解决方案。

桌面办公套件通常包含许多不同的应用程序。通常会有专门用于文字处理、电子表格制作和演示文稿创建的程序。有些套件还包含数据库或笔记应用程序。大多数 Linux 发行版，即使是轻量级变体，如 Damn Small Linux，都附带办公套件或提供相同工具的程序。如果您只 interested 在文字处理器，并不总是需要 resort 到一个庞大的项目。在这种情况下，您也可以选择不安装独立的 Abiword（用于文字处理）和 Gnumeric（用于电子表格）等应用程序。

这些应用程序之间的区别在于默认功能集。当你将在线解决方案与离线桌面应用程序进行比较时，这一点变得显而易見。

### 文字处理器

**让你的内在莎士比亚闪耀光芒！**

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_114_0.png)

Caligra Suite 的文字处理器被称为 Words。与其他文字处理器不同，Caligra Words 在右侧有一个侧边栏，用于调整文档的不同格式选项，例如插入评论、页眉和页脚等。

除了这个默认且无法关闭的侧边栏外，该应用程序还提供了许多不同的元素，称为停靠器（dokers）。这些包括文档统计、添加形状等。每个元素都占据了屏幕上相当大的空间，留给你实际文档的空间非常宝贵且有限。尽管你不断地调整不同停靠器的大小并关闭不需要的停靠器，你最终会发现几乎没有空间来访问评论区！由于其截然不同的设计，该工具使用起来并不容易，特别是如果你之前使用过文字处理器的话。

Google Docs 允许你在线搜索主题，并将结果拖入文档中，自动添加引用，但除了在线之外，这就是其独特销售点（USP）的全部了。

LibreOffice Writer 和 Caligra Words 都支持开箱即用的多种格式，包括开放文档格式（Open Document Format）和微软 Office 的专有格式。不幸的是，这两个应用程序在处理 doc 或 docx 文件时往往会扭曲文档的外观。LibreOffice Writer 经常失败，无法识别文本格式，导致渲染出的文档与原文有很大不同；而 Caligra Words 表现要好得多。然而，即使是 Caligra Words 有时也难以渲染编号列表，并会破坏边距。

在本次综述中介绍的所有应用程序中，OnlyOffice 对微软 Office 格式的支持最好，并完美地打开了我们测试的所有文件。与其他工具不同，添加到文档中的评论显示在左侧，但界面总体上与微软 Office 的选项卡式风格非常相似。

WPS Writer 最大的缺点是不支持开放文档格式（ODF）。FAQ 本身解释说，当开发团队扩大或收集到足够多的用户以证明投入时间和精力实施 ODF 支持是合理的时，开发者可能会考虑添加 ODF 功能。但就目前而言，ODF 仍搁置在 WPS Writer 的待办事项中。

### 电子表格

**让数字计算变得简单。**

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_114_1.png)

不同办公套件中的电子表格应用程序提供几乎相同的功能。至少，它们各自都提供用于创建公式和执行复杂计算的一组函数。除了执行基本数学功能外，所有电子表格应用程序都内置了用于常见财务和统计操作的函数。这些现代替代手工和纸张工作表的最佳功能之一是所谓的“假设分析”，即你更改一个数据字段，工具会自动更改相关字段的值。

LibreOffice Calc 和 WPS Spreadsheets 被认为是最易于使用的应用程序之一。此外，Calc 拥有许多向导，帮助你使用其高级功能。你可以轻松地从数据库中提取数据，并与其他用户协作，使其非常适合大多数办公环境。

Google Spreadsheets 并不落后于前者，与其他 Google Docs 应用程序一样，它也提供了许多不同的模板可供选择。文档恰到好处，提供的帮助精准。

所有程序都支持多种格式，并允许你将数据导出为 PDF 或 CSV 文件，除了 Calc 和 Sheets 外，其他默认都使用 xlsx 格式。这些应用程序外观也相当相似，Caligra Sheets 是唯一例外。再一次，依赖停靠器来提供不同功能使得使用 Caligra 变得不直观，尽管它提供与其他应用程序（如 LibreOffice Calc）相同的功能。

### 用户体验

**它们看起来都很相似，但行为也一样吗？**

“生产力应用程序”是如今经常使用的术语。在 20 世纪 80 年代之前，世界还在靠打字机或纸笔运作，但随着办公套件的引入，这些最古老的生产力应用程序改变了我们在家里和工作时使用计算机的方式。因此，在当今世界，很少有工作不需要基本的办公软件技能，这并不令人惊讶。

虽然这些套件在一个或两个组件应用程序中提供相似的功能，但它们的工作流程足够独特，以至于在它们之间切换可能需要大量学习才能让你在日常使用中感到舒适。

如果你只对单个办公组件（如电子表格或文字处理器）感兴趣，请参见本月综述末尾的“也请考虑”部分，获取一些建议。

#### Google Docs ***8/10***

其独特之处在于它是本次综述中唯一的在线办公套件。但公平地说，OnlyOffice 也提供基于云的解决方案。虽然该套件最初在 Chrome 浏览器上运行效果最佳，但在使用 Firefox 等替代浏览器时，你也不会遇到性能问题或缺失功能。

每个组件应用程序都有大量的模板，这是 Google Docs 最大的独特优势。它与 Google 的轻松集成，用于执行搜索、整合结果或与其他用户一键共享文件，也是一个额外的奖励。如果你经常需要与用户协作，或者经常外出且无法承受将紧急文件留在身后的风险，使用 Google Drive 作为存储提供了极大的便利，因为它允许你随时随地访问你的工作——只要你有可用的互联网连接。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_115_0.png)

#### Caligra Suite ***7/10***

Caligra 本身没什么大问题，但你可能会对其晦涩的工作流程感到吃力。例如，如果不访问“添加形状”停靠器，你就无法在演示文稿或文档中插入任何形状。事实上，在停靠器之间切换以访问元素和功能的过程令人费解且不直观，而这些功能在其他套件的菜单栏中很容易访问。

我们通常不会谴责不同的工作方式，但对于此类应用程序，文档的易获取性变得非常重要。虽然一些组件应用程序（如 Sheets 和 Stage）有大量的文档，但你无法从应用程序内部访问它们。

但如果你愿意花时间掌握其工作方式，或者你在使用旧机器，你会欣赏 Caligra 在低规格系统上运行的能力。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_115_1.png)

### 帮助与支持

**当你不知道自己该怎么做时，你可以向谁求助？**

从这些程序执行工作的性质来看，你可能会认为它们相当易用。虽然这在很大程度上是正确的，特别是对于 Google Docs 的直截了当的功能，但其他应用程序可能需要一些指导。例如，当你试图弄清楚如何在 WPS Writer 上安装插件，或者是否有可供使用的插件时。

虽然所有应用程序都是跨平台的，但 WPS Writer 的 Linux 版并没有得到与其 Microsoft 版同等的关注。这就是为什么你可能会在官方文档中找到某些问题的解决方案，但这些解决方案并不适用于 Linux 版。例如，官方帮助会告诉你如何使用邮件合并功能，但该功能在 Linux 上甚至不可用。

OnlyOffice 网站上的文档不多，除了涵盖安装和基本使用的说明外，你不会找到更多信息，但你可以在程序内部找到更多有用的信息。根据你运行的应用程序，点击“文件 > 帮助”会显示一个分类列表，如果你正在寻找特定内容，还有一个搜索栏。

相比之下，Caligra 的文档不存在。从程序内部启动手册会将你带到不存在的 KDE 手册页面。当你最终设法在 KDE Userbase 上找到一些文档时，它只列出了几个孤立的功能。幸运的是，你可以在官方论坛版块上利用用户社区获取建议和帮助。

LibreOffice 拥有详细的用户指南，可以从每个组件应用程序内部访问。除了其详尽的文档指南外，该项目还有一个名为 Ask LibreOffice 的问答网站。
