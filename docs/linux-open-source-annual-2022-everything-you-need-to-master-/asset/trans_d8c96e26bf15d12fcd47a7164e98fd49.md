

# 评估客户端的可用性

它们是助力还是阻碍你的工作？

尽管雅虎和 Gmail 等在线服务每隔几年就会调整其界面，但桌面邮件客户端在外观上却宽松得多，自数十年前的现代电子邮件客户端引入以来，似乎没有任何变化。

那么，如何解释桌面客户端的流行和持续存在？原因之一是它们与桌面环境的紧密集成，这意味着接收新消息时会弹出通知。再加上消息排队功能、反垃圾邮件措施以及对消息加密的支持，不难理解为什么这些应用程序拥有如此庞大的用户群。

邮件客户端应该做好的首要且唯一的任务是轻松连接不同的账户并收发邮件。我们需要的是一个能做到这一点，但不会让用户体验其众多功能变得令人疲惫的客户端。

## 爪子邮件（Claws Mail）7/10

界面左侧有一个边栏，显示每个文件夹中已读、未读和总消息数。您可以通过点击“视图->设置显示列->在文件夹列表中”来调整此设置。如果您不喜欢默认布局，也可以从“视图->布局”中切换到其他布局，并从五个不同的选项中进行选择。网站上还有几个可供下载的主题，但它们只会改变界面内的图标。尽管如此，某些主题为原本单调的外观增添了一些色彩。您可以为消息应用不同的颜色标签。您甚至可以使用这种颜色作为查找消息时的搜索标准。与全局可访问的搜索栏不同，该工具要求用户先选中边栏中的文件夹，然后点击“编辑->搜索文件夹”以启动搜索对话框。

## Evolution 8/10

界面中遍布按钮、选项卡和侧边栏。这个设计直观的应用程序相当容易掌握，即使是从未使用过桌面邮件客户端的初学者也不例外。

默认安装为您提供访问其所有功能的能力，包括日历、任务和便签。应用程序默认进入邮件界面，但您可以使用左侧边栏右下角的按钮切换到其他任务。右侧边栏显示您所有即将开始的约会，您可以通过右键点击日期来创建新的约会。默认情况下，应用程序采用线程化消息视图，将一封电子邮件的所有回复归类在一起。您可以通过按 Ctrl+T 关闭线程视图。事实上，大量操作可以使用默认快捷键执行。点击“帮助->快速参考”查看这些快捷键的完整列表。

# 配置和文档

在入门和陷入困境之间（以及更远处）的路径导航。

在此测试中，得分是根据文档质量到配置新账户难易程度的累积评估。与能够完美配合大多数 IMAP 和 POP 账户的其他工具不同，Gmail 将 Claws Mail 视为不安全的应用程序。您需要先在 Gmail 中启用“访问“较低安全级别应用”的权限”，然后才能配置 Claws 以获取消息。未能这样做会导致登录失败信息，即使您提供了正确的密码。不幸的是，尽管网站上有用户手册和常见问题解答，但 Claws 的文档并未讨论与 Gmail 配合使用时的这一故障。配置 Evolution 与 Yahoo 同样困难，但与其他工具一样，该程序在配置 Gmail 时会自动获取所有相关详细信息。您可按 F1 键在应用程序内部访问详尽的文档。快速参考 PDF 提供了您可以使用的全部快捷键。

与大多数 KDE 应用程序一样，KMail 拥有一本完整的手册，讨论其所有功能。它可以连接大量服务，无需您手动输入任何设置，连接 Yahoo 和 Gmail 以及托管在 GoDaddy 上的邮件服务器只需几秒时间！

除了涵盖其不同使用方面的详尽文档外，您还可以在 Thunderbird 的支持页面上找到关于定制选项等技巧的细节。由于 Mailspring 强制要求创建账户，它会定期发送邮件通知用户其众多功能。与其他工具一样，其在线帮助提供了易于遵循的说明，用于配置、启用和使用不同功能。

## KMail 8/10

您可以将经常访问的所有电子邮件文件夹拖放到应用程序界面左上角的框中。这将创建经常访问的文件夹列表，为您节省在左侧边栏中查找这些文件夹的时间。所有电子邮件都按日/月/年分组。消息折叠在相应的日/月/年标题下，您需要双击标题才能获取消息列表。与其他工具相比，KMail 在线程视图中做得更好，使用行间距来表示线程中消息的回复。顶部的搜索栏可用于执行基本搜索操作，但如果想要更多功能，必须先点击“工具->查找消息”。

对于需要某些操作的消息，点击顶部菜单栏上的“创建待办事项”按钮。然后，您可以填写所有相关详细信息来创建提醒。

## Mailspring 10/10

除非您不介意向所有同行宣告邮件是通过 MailSpring 发送的，否则默认签名需要立即关注。这与“发自我 iPhone”不完全相同，但仍然缺乏创意。

与 Claws 和 Thunderbird 一样，MailSpring 支持主题。点击“编辑->更改主题”可在默认安装的六个选项中进行循环。

与其他工具不同，MailSpring 采用四面板布局。最左侧的边栏与其他所有应用程序相同。旁边是所选文件夹中所有消息的列表。其右侧是选定的消息。最后，在第四个窗格中，您可以获得关于对话中所有人的详细信息，但它仅告知对话参与者的姓名。在此右侧边栏的底部是与同一人过往交换的所有电子邮件列表。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_122_1.png)

## Thunderbird 10/10

尽管提供了几种布局选择，如宽视图、垂直视图和文件夹窗格，但最佳外观是经典视图，它呈现三面板界面。

在电子邮件中遇到不熟悉的单词时，您可以选中该单词并右键点击，然后点击“在 Bing 中搜索“单词””。您可以从“首选项”对话框中更改默认搜索引擎。

搜索消息时，结果显示在新标签页中，左侧边栏上的筛选器有助于根据您是发件人还是收件人以及消息是否包含附件来区分不同的消息。

撰写消息时，如果您希望获得送达确认，可以点击“选项”并切换“返回收据”。通过点击“菜单->首选项->高级”，然后单击“返回收据”，可以为所有发出的消息配置此功能。

# 使用插件进行定制

因为基于标准安装构建还远远不够……

Mailspring 的默认安装是所提供内容的全部。如果您选择订阅专业版，每月费用为 8 美元（6 英镑），您将获得更多功能，但与其他工具相比，功能仍显不足。

Claws 是一个简洁的电子邮件客户端，如果您想要额外功能（如新闻聚合器），必须依靠其插件。例如，ACPI 通知插件可以让某些笔记本电脑型号（例如 Acer 和 Asus）上的新邮件指示灯亮起。您还可以选择几个主题之一来更改界面外观。

Evolution 的默认安装已安装了多个插件并处于启用状态。事实上，其许多基本电子邮件功能（如新邮件通知）也是通过插件提供的。

KMail 的许多功能由其本身识别为插件的内容驱动。点击“设置->配置 KMail”，然后在侧边栏中点击“插件”以查看列表。您可能特别会感兴趣广告拦截插件。

Thunderbird 提供数十种主题选择以更改外观，此外还有用于调整菜单项和进行其他界面更改的特定扩展。您还可以获得如自动字典等功能。该扩展可用于记住您与特定个人或群组通信时使用的语言，并自动切换拼写检查器。插件页面提供了可用扩展的分类列表，如联系人、文件夹和过滤器、消息和新闻阅读、隐私和安全，以及标签。您还可以在左侧滚动查看最流行列表。
