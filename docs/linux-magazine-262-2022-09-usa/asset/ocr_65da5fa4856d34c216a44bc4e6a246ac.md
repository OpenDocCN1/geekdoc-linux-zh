# Conclusions

The Podman man page [10] offers a useful initial overview of Podman’s features, while the Podman website [1] provides a variety of references for further research. In my opinion, you can learn the Podman basics more quickly than Docker. If you already have experience with Docker, you will certainly find the transition to Pod-man easy. To jog muscle memory in this case, enter

```
alias docker='podman'
```

in your .bashrc to continue using Docker commands such as pull, push, build, commit, tag, and more.
