In Go, programmers have to check results, practically after each function call, to make sure an error hasn’t crept in. It always comes back as an err variable. If it has a value of n/1, no error occurred. Each time, the corresponding error handler requires three lines of code and takes up vast amounts of space in listings printed in magazines.
