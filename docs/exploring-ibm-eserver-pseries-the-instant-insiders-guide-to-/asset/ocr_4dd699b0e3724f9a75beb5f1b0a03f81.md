# 134 Exploring IBM@server pSeries

The EXP Plus can attach to pSeries servers using a variety of SCSI adapters: SCSI-2 Fast and Wide, Ultra-SC2-SCSI, Ultra-3-SCSI. For the highest performance and availability, the enclosures can be combined with the IBM PCI 4-channel SCSI RAID adapter (#2498), enabling Ultra-3SCSI 160 Mbps performance and multiple RAID options. The EXP Plus can be attached to a second pSeries server by adding an additional, optional SCSI port. Distances up to 20 meters are supported between disk enclosures and pSeries servers using Ultra-3SCSI adapters. High Availability Cluster Multiprocessing (HACMP) is supported for the EXP Plus when used with appropriate adapters in HACMP-supported configurations.

# 7133 TotalStorage® Serial Disk System

The 7133 TotalStorage Serial Disk System employs IBM's Serial Storage Architecture, which was discussed in Chapter 1. The 7133 comes in both rack-mounted (Model D40) and desktop tower (Model T40) configurations. The models are functionally similar and can be populated with up to 16 autoloading, user-replaceable, SSA disk drive modules. The available 10K rpm disk drive modules are 18.2 GB, 36.4 GB, 72.8 GB, and 145.6 GB. Also available are 15K rpm disks in capacities of 36.4 GB and 72.8 GB. Maximum storage capacity per 7133 system is 2.3 TB (up to 14 TB per host adapter). These SSA systems provide redundant power and cooling units that are autoloading (like the drives) and user replaceable. In addition to their capacity and reliability, these provide outstanding performance.

The 7133 subsystem connects to pSeries computers via 4-port adapters including the Advanced RAID Adapter (#6230). The SSA Fast-Write Cache adapter (#6235) can be added to the Advanced adapter for even greater performance in single- or dual-host environments. A single 4-port adapter can support up to 96 drives, which would be housed in six 7133 units (each unit accommodates 16 drives). Up to 16 adapters may be used within a single pSeries server, so it is possible to configure very large SSA RAID arrays.

The 7133 can have independent connections to different pSeries servers. This capability, along with the mirroring support in AIX, makes high-availability pSeries configurations possible.
