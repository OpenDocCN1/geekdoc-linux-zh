The pSeries class of servers has three models—p660-6H0, p660-6H1, and p660-6M1—all of which have a rack-mounted CEC (Central Electronics Complex) drawer containing processors, memory, and I/O subsystem interface, plus one or more I/O drawers containing 14 PCI adapter slots, a service processor, memory devices, and integrated I/O ports. The p660 midrange rack-mount systems are optimized for database and transaction processing servers. The pSeries 660 Models 6H0 and 6H1 are electronically equivalent to the p620-6F0 and p620-6F1 for the rack-mount packaging. The p660-6M1, which offers up to eight RS64 IV processors at 750 MHz, provides outstanding performance in industry-standard benchmarks for transaction processing, Web serving, and Java application.

The p670 is a 4-, and 16-way midrange server, positioned between the p650 and the p690. It features POWER+4 processor multipch modules (MCMs) running at 1.5 GHz, LPAR support, and up to 256 GB of memory, and can attach to three IBM I/O expansion unit as for the high-end-p690. For the p670, at the top of the pSeries midrange line, IBM offers a model conversion to the p690 for customers whose business growth requires such expansion.

The flagship of the pSeries family is the p690, a datacenter-class UNIX server announced in October 2001. It was the first pSeries server to use the POWER4 processor, and now it offers up to 32-way SMP configurations of POWER4 processors running at 1.5 GHz or 1.7 GHz, with half a terabyte (512 GB) of memory capacity. The multipich packaging technology of the POWER4 architecture enables configurations optimized for the technical and scientific markets. The p690 also introduced to the pSeries family logical partitioning, developed from IBM’s extensive mainframe systems experience. Logical partitioning allows a system administrator to allocate system resources (processors, memory, I/O devices) to specific applications, creating several independent systems for each application or group of applications. Each logical partition runs its own instance of the operating system, AIX 5L or Linux, so the LPAR capability allows users to run both AIX 5L and Linux applications simultaneously. LPAR, which is supported on most POWER4-based pSeries servers, is described in greater detail in “A Closer Look” later in this chapter.
