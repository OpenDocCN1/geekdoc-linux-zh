# 7332 4-mm Tape Autoloader

The IBM 7332 4-mm DDS-3 Tape Autoloader Models 220 and 110 provide outstanding tape storage capacity for save and restore operations using the DDS-4 and DDS-3 formats. The Model 220 uses 20 GB cartridges in a six-cartridge magazine to store up to 240 GB of data with compression or 120 GB without compression. The 7332 Model 110 uses 12 GB cartridges to obtain 48 GB of storage capacity with the four-cartridge magazine. With 2x compression, the Model 110 autoloader can contain up to 96 GB with the four-cartridge magazine. Compression values are data and application dependent, so actual results may vary.

The 7332 can read and write tape cartridges in either compressed or uncompressed format and support data transfer rates of 1.1 Mbps to 6 MBps, depending on the model. Its magazine indexing time (the time to unload one cartridge and load another) is less than nine seconds.

For backing up amounts of data greater than 240 GB, one of the high-performance TotalStorage Enterprise Tape Library systems should be considered.

# 7208 Model 345 External 8-mm Tape Drive

The 7208-345 External 8-mm Drive is a 5.25-inch device that can be used with all pSeries models. Of course, many pSeries servers offer an internal 8-mm tape option (#6156). The 7208 is a standalone device designed to be placed beside a pSeries system and attached to the pSeries systems through a SCSI port. It can be used for data interchange with other systems and for data backup. The Model 345 uses a cartridge capable of natively holding up to 60 GB of information. In addition, the Model 345 supports a data-compression function that allows up to 150 GB of data to be stored on a single cartridge. It supports a maximum information transfer rate of 12 Mbps in normal mode and 30 Mbps when data compression is being used.

# DLT Options

# 7205 Model 440 Digital Linear Tape Drive

The 7205-440 employs DLT8000 technology and is designed for users who have large amounts of data to back and/or limited time for system backup. It is read/write compatible with previous DLT tape technologies. Each cartridge can hold up to 40 GB of data (80 GB compressed) and provides an Ultra2-SCSI LVD data rate of 6 Mbps (12 Mbps compressed).

# 7205 Model 550 Digital Linear Tape Drive

The 7205-550 also employs DLT8000 technology, but offers four times the capacity of the 7205-440 at a data rate up to 16 Mbps using an Ultra2-SCSI LVD interface. It is read/write compatible with previous DLT tape technologies. Each cartridge can hold up to 160 GB of data (320 GB compressed).

# IBM TotalStorage Tape Library 3582

The Ultrium Tape Library 3582 is an entry-level LTO Ultrium tape offering, designed for small to medium-sized companies. It features one or two Ultrium 2 tape drives and 23 cartridge slots plus an I/O cartridge slot. It has a barcode scanner for verifying and inventing cartridges. With high-capacity Ultrium 2 cartridges, the maximum storage capacity of the 3582 is 48 TB and 9.6 TB compressed, with data transfer rates of 35 Mbps and 70 Mbps compressed. It can be mounted in a 19-inch rack or used in a standalone configuration. The 3582 offers one or two host attachments—either Ultra3-SCSI or 2 Gbps Fibre Channel. It supports a wide range of IBM and non-IBM systems, including simultaneous attachment of heterogeneous servers.

# IBM TotalStorage Ultrium Tape Library 3583

The Ultrium Tape Library 3583 is scalable from one to six Ultrium 2 tape drives and comes in three models with capacities for 18 cartridges (3583-L18), 36 cartridges (3583-L36), and 72 cartridges (3583-L72). The Model L72 also offers a 12-cartridge port. Like the 3592, 3583 uses Ultrium 2 data cartridges, with a barcode scanner, offers Ultra3-SCSI and 2 Gbps Fibre Channel, and supports data rates up to 70 Mbps. Maximum capacities range from 7.2 TB (3583-L18) to 28.8 TB (3583-L72).

# IBM TotalStorage UltraScalable Tape Library 3584

The UltraScalable Tape Library 3584 is a datacenter-class system designed for use in high-end environments, such as pSeries 690. Since it supports heterogeneous servers and operating systems, a pSeries server could be just one of systems sharing the 3584 tape library. It can scale up to six frames with 12 tape drives per frame. The 3584 can handle up to 496 TB (992 TB compressed) of archival information and, with all 72 tape drives operating, can transfer data at an aggregate rate of 19.4 TB per hour. It uses Ultra3-SCSI and 2 Gbps Fibre Channel, and offers many design features to ensure high availability.
