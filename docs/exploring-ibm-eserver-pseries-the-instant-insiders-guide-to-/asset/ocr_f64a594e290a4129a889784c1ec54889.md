Total system memory requirements for an LPAR system will include the memory needed for the software to be run in LPAR (256 MB increments) and the additional memory required per system when running in LPAR mode. The hypervisor itself requires 256 MB. Translation Control Entries for mapping I/O addresses require 256 MB (for up to four I/O drivers) or 512 MB (if more than four I/O drivers are attached). Finally, pages associated with each LPAR require a variable amount of memory. With the exception of the 256 MB required for the hypervisor, these memory requirements for control tables also exist when the system is running as a full system partition (SMP mode). So they are not additional overhead associated uniquely with LPAR. A pSeries server with LPAR, particularly larger models like p650, p670, or p690, must be carefully planned. IBM provides several white papers to assist with planning LPAR on the pSeries Web site. For a link to the IBM information, see the companion Web site (www.maxpress.com) for this book.

Resources (processors, memory, I/O slots) are not moved directly between LPARs. They first reside in a pool of unassigned resources, from which the system administrator can assign them to LPARs as required. If the target LPAR is running AIX 5L v5.2, resources can be added or removed dynamically. When using processor or memory Capacity Upgrade on Demand features on the p650, p670, and p690, newly activated resources go into the unassigned pool, from which the administrator can assign them to LPARs either dynamically or statically (AIX 5L v5.1 or Linux).

# Main Memory

The main memory, set of electronic chips that provide a “workspace” for the main processor, is also a very important part of a computer. It holds the information (program instructions and data) being used by the main processor. The main memory is called RAM because it can store and retrieve information independent of the sequential order in which the information was originally stored.

The smallest RS/6000 system available, the Model 150, stands with 128 MB (about 128 billion bytes) of main memory, and the least amount of standard memory on pSeries servers is the 256 MB on the p640.
