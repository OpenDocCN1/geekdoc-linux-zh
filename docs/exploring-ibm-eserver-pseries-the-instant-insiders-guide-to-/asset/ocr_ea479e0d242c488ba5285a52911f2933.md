Since AIX 5L provides either a 32-bit kernel or a 64-bit kernel (selection at installation), a word about compatibility using AIX 5L is in order. The 32-bit kernel provides compatibility with existing 32-bit AIX applications, while the 64-bit kernel includes 64-bit device drivers and APIs, enabling increased use of resources and larger application workflows on 64-bit hardware. Obviously, most pSeries systems have 64-bit architecture, it is advantageous to install the 64-bit kernel in most situations.

From a compatibility standpoint, applications written to earlier AIX 32-bit versions are binary compatible and will run on AIX 5L (both 32-bit and 64-bit), except in some unusual circumstances, such as the programmer having used undocumented software interfaces. Note that 64-bit applications produced using AI Version 4 will not execute directly on AIX 5L. Those applications must be recompiled before they execute on AIX 5L.

The next question you may have about your 32-bit applications is, "Should I recompile them to 64 bits to gain further performance advantage?" The answer is simple: Unless your application is under stress constraint, you will not improve performance by a recompile. In fact, you will really end up is increasing the application footprint because your pointers take twice as much in 64-bit applications.

One last point about compatibility between 32-bit and 64-bit systems is this: Application developers can develop 64-bit applications even if they are using AIX 5L on a 32-bit system. The ability to build 64-bit objects does not depend on having 64-bit hardware. Of course, running these objects do require the full 64-bit environment.
