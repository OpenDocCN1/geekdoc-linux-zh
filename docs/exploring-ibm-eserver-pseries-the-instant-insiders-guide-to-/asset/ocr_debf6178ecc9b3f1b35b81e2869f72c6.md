The Open Group (discussed earlier in this chapter in “AIX 5L—An Executive Overview”) has selected and endorsed a set of distributed computing technologies taken from many different vendors and collectively called them the distributed computing environment. IBM’s AIX DCE products are built on the Open Group’s DCE.

Many of the base “run-time” services of DCE and its major service, the Distributed File System (DFS), are integrated into AIX 5L. These clients include configuration, security, cell directory, time, RPC, and DFS. The DCE base services allow users to share files stored in a network of computers without knowing the physical location of the files.

# Communications Support

Communications facilities included in AIX 5L allow a properly equipped pSeries system to communicate with almost any variety of ways. Traditional open systems used terminals and printers that communicated with the computer system over asynchronous communications using the American Standard Code for Information Interchange protocol. With this communications method, character at a time (letter, number, period, comma, and so on) was sent from the computer’s communications port through a simple cable to the port of the attached device. This is how ASCII terminals and printers communicated with the UNIX operating system. This simple ASCII method was also used to send information from one computer to over a similar type of cable. Although pSeries systems and AIX 5L still use ASCII communications with other computer systems, they are much less used than the methods described here.

As more and more vendors offered computer systems and the need for intercomputer protocols evolved, the Transmission Control/Internet Protocol (TCP/IP) was developed. As an industry standard, TCP/IP allows systems from many vendors to communicate with each other in a single network. The AIX 5L operating system supports TCP/IP over Ethernet/802.3 networks, Token-Ring networks, the Enterprise Systems Connection (ESCON7), Asynchronous Transfer Mode (ATM), and the Block Multiplexer Channel Adapter if the computer systems are near each other (for example, on the same campus).
