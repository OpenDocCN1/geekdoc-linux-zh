# pSeries 660 Model 6M1 Specifics

The pSeries 660 Model 6M1 is a very powerful and scalable member of the 64-bit family of SMP enterprise servers. Positioned above the Models 6H1 and 6H0, the p660-6M1 provides the power, capacity, and expandability needed for mission-critical applications.

The Model 6M1 provides excellent midrange performance for transaction processing (TPC-C), Web serving (Specweb99), and server-side Java application processing (Specjb2000). The p660-6M1 derives its power from two, four, six, or eight RS64 IV microprocessors running at 750 MHz, each with 8 MB of L2 cache. Also available for p660-6M1 entry-level configurations are two and four RS64 III 500 MHz processors with 4 MB of L2 cache. The unique IBM cooler and SOI technology used in the RS64 IV chips produces faster and more reliable processors, improving speed and reducing the heat generated. The processors are packaged onto cards that hold two or four processors.

Model 6M1 like the Models 6H1 and 6H0, the Model 6M1 is packaged as a rack-mounted CEC drawer that can be attached to rack-mounted I/O drawers. The CEC and I/O drawers offer redundant power and cooling, both of which are hot-pluggable for concurrent maintenance. The CEC drawer contains the system processors, up to 64 GB of memory, and supporting system logic.
