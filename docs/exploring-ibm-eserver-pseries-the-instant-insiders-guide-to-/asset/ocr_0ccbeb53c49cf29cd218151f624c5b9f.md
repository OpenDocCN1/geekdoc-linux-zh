Communications functions have emerged to meet the needs of sophisticated communications environments, such as the Network File System (NFS) and the Distributed Computing Environment, both of which are supported in the AIX5 operating system. The NFS and application programs written to use allow one computer system to access information located on another computer system over a local network or other networks using TCP/IP. This allows information to be distributed in a network so as to make that information most available to those who need it and that it can be managed. The DCE extensions to AIX5L application programs designed to take advantage of DCE by distributing a computer’s workload across the various computer systems in a network. However, with recent advances in communications technology, DCE is of less importance today than in the past.

Although the requirement for pSeries users to access applications on other types of systems in native mode (e.g., emulating an IBM 3270 or 5250 terminal) is rapidly going away, AIX5 supports the IBM Host Client Package for Multiplatforms v3.0 product. IBM Host Client Package provides access to applications and data on iSeries (5250), zSeries7 (3270), and DEC/UNIX (VT) hosts for traditional and Web users in either intranet or SNA networks. AIX5L is supported by both a client and as a server.

Tivoli NetView7 provides network management tools based on the Simple Network Management Protocol (SNMP) commonly used in the open-system environment. NetView works like this: When a device in the network (the SNMP agent) senses a problem, it sends an SNMP message to the computer running NetView (the SNMP manager). NetView notifies the network support personnel that a problem has been detected and provides detailed information about the problem. Thus, NetView allows for centralized management of a distributed, open-system network, which typically improves the productivity of the network support personnel and the availability of the network. Tivoli NetView also provides firewall support with a single unidirectional port for e-business networks and provides the systems administrator tools for managing the network, including diagnostic aids and a graphical representation of the network.
