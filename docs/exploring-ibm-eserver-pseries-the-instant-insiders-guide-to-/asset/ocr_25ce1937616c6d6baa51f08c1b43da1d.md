Having said who is using the pSeries, let's talk about what they are doing. The pSeries is being employed to implement all of the latest information technologies—client/server, rightsizing, Web sites, data mining, application consolidation, and so on. The pSeries models are also employed in more traditional roles—database servers OLTP
(Online Transaction Processing), accounting, human resources, inventory management, entry servic, scientific computing, and so on. Every industry has found a use for UNIX systems and has included the pSeries in its information technology.

Why UNIX at all? What about personal computers, or PCs? Although this book is about pSeries systems, it is important to understand how they differ from the PC family in order to make good buying decisions. In fact, because PCs can run the Linux operating system or versions of UNIX for Intel-based systems, many of the applications available for pSeries systems can also be on PCs.

Key differentiators between pSeries (or many other UNIX servers, for that matter) and PCs are performance and the robustness of the hardware and operating system. pSeries systems combine high-performance integer and floating-point processing power with very high memory and data bandwidth and extensive scalability for storage and communications options. There are pSeries models suitable for the full range of application environments—both commercial workloads, as large-scale database and transaction processing, and engineering and scientific applications.

The kinds of business-critical applications run on pSeries servers require high levels of reliability and system availability. PCs have been designed more for low cost and performance for personal productivity applications, games, and the like. It should be noted that Intelbased servers on the market have some of the system robustness features that are common on most UNIX servers, and the performance of some systems using the latest 64-bit Intel processors is excellent, so the boundary between UNIX servers and Intel-based systems is not always crystal clear.

Another distinguishing characteristic of pSeries systems is the capacity for scaling of processor power, both within individual models and across the pSeries family.
