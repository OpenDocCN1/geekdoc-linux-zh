# 7212 Model 102 TotalStorage Storage Device Enclosure

For situations in limited, or when it is desirable to consolidate the media devices into a single location, the 7212-102 Storage Device Enclosure provides two media bays in a 1 rack drawer that mounts in a 19-inch rack. It is supported on all pSeries systems and currently available RS/6000 systems, with the exception of the pSeries 635, 670, and 690, which use 24-inch-wide racks. There is a media drawer available for the p670 and p690, which is designed for a 24-inch wide rack.

7212-102 can accommodate any two of the following storage devices:

+   * Digital Data Storage 4-mm (DDS-4) tape drive
* 40H CD-ROM drive

+   * These devices are the same technologies as described later in this section for the 4-mm tape, CD-ROM, and DVD-RAM drives available as features to be installed internally in a pSeries system. See those sections for further technical information.

# RAID Technology

RAID technology is used in many systems, especially those with large amounts of disk storage, to help improve reliability and data integrity. The acronym RAID originally stood for Redundant Arrays of Inexpensive Dis, since the technology was developed to provide improved data integrity for systems using inexpensive disk drives designed for the personal computer (PC) market, but now many people say that RAID stands for Redundant Arrays of Independent Disks, since the disks used in modern RAID arrays are state-of-the-art devices—not just the expensive disks available. Whichever definition of the acronym you use, the important point is that RAID technology allows data to be written and stored on two or more drives, that in the event of a disk failure, data integrity can be maintained.
