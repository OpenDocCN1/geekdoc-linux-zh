# Meet the Family

The IBM pSeries family is IBM’s third generation of computers based on the Reduced Instruction Set Computing (RISC) architecture developed by IBM in the late 1970s. With this concept, a very simple set of programming instructions is used to perform work within the computer system. Because the instructions are very simple, they can be executed at extremely high speed, and also lend themselves to a more efficient implementation of the program being executed. The RISC architecture was first introduced in the IBM RT Personal Computer, later renamed the IBM RT System.
