# High-end pSeries Servers

IBM offers only one UNIX and Linux server classified as high-end—the
pSeriesSeries 690.

# pSeries 690 Specifics

With the announcement in October 2001 of the high-end pSeries 690,
IBM introduced a new class of pSeries server capable of datacenter op-
erations previously associated with mainframe computers. The p690,
flagship of the IBM Server pSeries family of UNIX servers, offers conf-
figurations optimized for commercial applications as well as options
designed for large-scale HPC or “scientific and technical computing”
environments. The pSeries 690 is supported by AIX 5L v5.1 and v5.2,
as well as by Linux (SuSE SLES 8).

In May 2003, the p690 was completely refreshed with the fastest
POWER4+ processors, high-speed memory, additional on demand fea-
tures, and I/O subsystem improvements. It continues to offer the great-
estperformance of any pSeries server. At the time of this edition, the
p690 is the fastest transaction processing system on the market (see
Figure 1.23).

The p690 introduced several technological advances to the
pSeries family, which are now offered across the pSeries family in the
focus servers listed at the beginning of this section:

+   * POWER4 processor architecture (the latest high-speed process-
sors are called POWER4+)

+   - Available in p615, p630, p650, p655, p670, and p690

+   - Multichip module (MCM) packaging used in p655, p670,
and p690
