# Performance Overview

One important aspect of a computer system is the speed at which the computer can perform work, known as the performance of the computer. The greater the performance, the more work the computer can do. Many things—such as the processor, cache memories, main memory, disk storage, and program efficiency—affect the performance of a computer system. It is difficult and often misleading to predict overall performance by looking at selected specifications of the individual components that make up the system. Things like as drive rotational velocity, seek times, and processor clock speeds are important, but they do not get the whole picture.

A better way to compare the overall performance of different computers is to perform benchmark testing. This testing involves running the same set of programs on each computer being compared and measuring how each system behaves under the workload. Many elements of the system come into play through this benchmark testing, and the overall performance of selected systems can be meaningfully compared.

The best programs to use for a benchmark test are the application programs that are actually going to run on the system. The widely varying characteristics of application programs can have a significant effect on overall system performance. Therefore, running the actual programs on each computer will give the most realistic comparison. In many cases this is not practical, so computer manufacturers and others in the industry typically perform benchmark testing using industry-standard programs specially designed to quantify and document the performance characteristics of various computers.
