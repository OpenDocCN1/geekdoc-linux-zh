# Three-Button Mouse

The Three-Button Mouse (#6041 and #8741) is an input device that can be used with all pSeries systems. The user slides the mouse on a desktop to control cursor movement, draw lines, define points, and so on. The three buttons provided on the mouse are typically used to select a menu item or take other action after the cursor is positioned on the screen. The mouse augments the keyboard as a means of interacting with pSeries systems. It attaches to the standard mouse port.

Also available is #8841, which provides a stealth black three-button mouse with a cable for attachment to a keyboard. This mouse is used in conjunction with USB keyboards (see below) and does not attach to the standard mouse port of pSeries systems.

# Keyboards

Unless a pSeries server is controlled over a network or a Hardware Management Console, a keyboard is required. The IBM Enhanced Keyboard used for several years has 101 keys and the same layout as used by other IBM products (including the IBM PCs and many different types of terminals). This means that once familiar with this layout, a user will not have to adapt to different keyboard layouts when using other IBM computer equipment. The Quiet Touch Keyboard (Figure 2.17) is available for use when a keyboard is needed. The key tops are engraved with characters in many different languages. The number for a specific keyboard depends on the language (U.S. English, U.K. English, French, German, Japanese, Spanish, and many more) and color (pearl white or black) selected. The keyboard cable plugs into the keyboard port on the pSeries system. Small retractable legs on the bottom of the keyboard can be extended to change the angle of the keyboard if desired.
