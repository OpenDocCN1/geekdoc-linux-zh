And, partitions running AIX 5L v5.1 or Linux may benefit from the availability of a standby processor in the event of failure of an active processor—though not operations continue running. When the partition (or the entire system) is rebooted, a standby processor will be activated in place of the failed processor. This “hot sparing” capability is available at no charge if a CuOD processor option is installed and an inactive processor is still available.

# Memory Capacity Upgrade on Demand

The p690 offers memory CuOD, an innovation that works with AIX 5L v5.2 (not AIX 5L v5.1 or Linux) to allow standby memory to be dynamically activated in 4 GB increments. Memory CuOD is available on p670 and p650 systems, as well. The memory CuOD options are the following:

+   * pSeries 690—16 GB with 8 GB active and 32 GB with 16 GB active
* pSeries 670—16 GB with 8 GB active and 32 GB with 16 GB active
