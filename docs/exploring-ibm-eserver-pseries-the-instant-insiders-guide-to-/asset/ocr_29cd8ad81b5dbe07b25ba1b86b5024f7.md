The RS/6000 Model 170 was the first 64-bit uniprocessor worksta-
in the product line. Its POWER3-II microprocessor, employing IBM’s
innovative copper design, runs at speeds of 333 MHz, 400 MHz, or
450 MHz. The Model 170 has outstanding floating-point performance,
and when configured with a 3D graphics adapter (also called a "graph-
ics accelerator"), it is an impressive graphics workstation and technical
workload system at a very attractive price. As the least expensive 64-bit
s system, it is a good choice for software development and test-
ing addition to being a very cost-effective entry-level server for both
technical and commercial workloads.

The RS/6000 Model 270 is a 1- to 4-way SMP system using
POWER3-II multiprocessors running at 375 MHz or 450 MHz.
Equipped with a 3D graphics adapter card, the Model 270 workstation
divers excellent 3D graphics performance. It is also a very cost-effec-
tive midrange server for both technical and commercial workloads.
