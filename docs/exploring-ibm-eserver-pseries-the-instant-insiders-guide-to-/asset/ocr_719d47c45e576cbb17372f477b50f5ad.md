In support of the open-system concept, IBM has also made a sig-
ificant commitment to supporting Linux on all pSeries systems. IBM
ends I/O driver software to the Open Source community,
thus enabling Linux distributors to support pSeries servers, and also
works closely with Linux distributors to help test pSeries servers run-
ing the Linux operating system. At the time of writing this edition,
most pSeries servers are supported on SuSE Linux Enterprise 8
(SLES 8) for iSeries™ and pSeries. In Japan and some other Asia Pa-
tific countries, Turbolino distributes its Turbolinux Linux Enterprise
Server 8 (TLES 8), which supports the same pSeries servers as does
SLES 8 from SuSE.
