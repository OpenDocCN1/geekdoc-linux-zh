Note that high-speed (567 MHz) and older (500 MHz) memory cards are available in the capacities of 4 GB and 8 GB. Memories of both speed can coexist in a system, but all memory will run at the lower 500 MHz rate. 567 MHz memory must be used with 1.7 GHz POWER4+ MCMs. If the lower speed memory is used, it will seriously degrade the performance of processor technology.

The p670 has only two MCM locations, each with two memory slots, so it has only four memory slots per system. The p670 requires only the inward-facing memory features. The memory feature numbers for the p670 are as follows:

+   - 4 GB memory card, inward facing (#4196)

+   - 8 GB memory card, inward facing (#4181)

+   - 16 GB memory card, 567 MHz, inward facing (#4484)

+   - 32 GB memory, 567 MHz, inward facing (#4486)

+   - 64 GB memory, 567 MHz, inward facing (#4488)

Memory must be installed in identical pairs, and memory card sizes should be balanced as closely as possible (identical is best) across all
