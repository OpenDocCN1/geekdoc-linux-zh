The p620 provides hot power supply available and cooling fans, with an optional third power supply available for redundancy. When the third power supply is ordered, additional fans are installed as well that the cooling becomes redundant and concurrently maintainable. The p620 runs on standard 115-volt or 220-volt AC power.

A significant RAS function included in the p620 is Dynamic Process Deallocation, which monitors recovered processor errors and predicts when a processor is getting close to a failure. If the threshold is reached for one of the processors, the processor is dynamically deconfigured from the system and the system continues to run with one fewer processor. A notification is sent that this has taken place, and service can be performed at a convenient time. The obvious value here is that no failure occurred before the likely bad processor was out of service.

A feature available in the pSeries 620 is Chipkill memory, originally developed for the S/390+ mainframe systems. Chipkill technology detects multit errors and corrects most of them transparently to the user. By comparison, ECC memory—although an important feature and one used in all pSeries systems—can correct only single-bit errors. With Chipkill memory, if a critical threshold is exceeded, the affected memory is taken off-line and a service action is initiated to be completed when the user desires. According to IBM studies, systems without Chipkill technology are as much as 100 times more likely to have an outage due to memory failure.

In summary, the pSeries 620 Model 6F1 and 6F0 servers have the performance, expandability, and high availability required for the mission-critical applications of medium-sized enterprises.

The p630 is positioned as the leading pSeries entry server. It addresses applications for which the 1- and 2-way capability of the p615 is not sufficient, and it is the POWER4+ replacement for the older 1- to 4-way POWER3-II and RS64 IV servers—p620-6F0, p640, and RS/6000 Model 270.

The base configurations of both p630-6C4 and p630-6E4 include the following:

- 1 GB of Chipkill memory with ECC
- 18.2 GB Ultra3-SCSI disk drive
- CD-ROM drive
- Built-in service processor
- Integrated I/O ports (do not require use of PCI slots):
- Two 10/100 Mbps Ethernet
- Two Ultra3-SCSI ports (internal and external)
- Two HMC
- Two RIO-2 (Model 6C4 only)
- One parallel
- Three serial
- Keyboard

Both p630 models are expandable to four 1.2 GHz or 1.45 GHz processors, 32 GB of memory, four hot-swappable disk drive bays, two media bays, and six hot-plug PCI-X slots. In addition, the rack-mount p630-c4 offers DC power, NEBS Level 3 compliance for harsh environments, and further expansion with up to two IBM 7311-D20 I/O adapters running at a 1 GHz clock rate. Each 7311-D20 drawer provides 12 hot-swappable disk bays and seven hot-plug PCI-X I/O adapters. So, a fully configured p630-c4 with two I/O drawers can handle 20 I/O adapters for storage.

As shown in the p630 system diagram (Figure 1.10), there are two processor cards, each of which may have one or two processors on a single chip. The processor cards communicate with each other and memory over a Fabric Bus that provides a bandwidth of 11.6 Gbps. The GX bus provides an almost 4 Gbps interface to the I/O subsystem (PCI-X slots, internal controllers, service processor, and RIO-20 ports for attaching a 7311-D20 I/O drawer).

An important feature of the p630, particularly for the entry UNIX server market, is LPAR support. LPAR is a flexible and powerful configuration option for system administrators who need to configure multiple "virtual servers" to meet their computing requirements, as opposed to simply running applications on a 4-way SMP server. In addition to the expandability of the p60 server itself and the ability to configure it into logical partitions, each running an independent copy of the operating system, the rack-mount p60-6C4 is supported, along with other pSeries servers, in massively Cluster 1600 systems. Up to 32 Model c64 SMP servers can be clustered. Or, p60 LPARs can be managed in a Cluster 1600 system, which can support a total of 128 operating system images, whether servers or LPARs.

The power and configuration flexibility of the p60 are supported by the same broad range of RAS capabilities as high-end pSeries servers. Functions such as First Failure Capture, predictive failure analysis, ECC protection on memory and caches, Chipkill memory, Dynamic Processor Deallocation, PCI slot deallocation, and hotplug components—to name a few—provide high availability and make the p60 easy to service when necessary.

The p60 is supported by AIX 5L v5.1 and v5.2 and by SuSE SLE 8. IBM pSeries offers Express Configurations for AIX 5L and Linux Ready Express Configurations. These are fixed configurations that include all the specified components without substitutions, but to which other features may be added—such as additional memory, disk drives, and I/O adapters. The Linux Express Configurations do not include an AIX 5L license or IBM Software Maintenance for AIX; customers must purchase Linux and the associated support from a Linux distributor.

To sum up, the p60 is an extremely versatile system. Standing alone, it provides the high performance, flexible configuration and physical packaging choices, and extensive growth of I/O and storage required by small and mid-size businesses. When used in clusters, the p60-6C4 or LPARs of the p60-6C4 can function as a powerful, compact processing node designed for applications to take advantage of parallel computation.
