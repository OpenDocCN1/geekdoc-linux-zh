# pSeries 670 and pSeries 690 Memory Expansion

The pSeries 670 and the pSeries 690 use the same memory packaging technique, although the p690 supports features that are not available on the p670. Both systems use Chipkill for high memory reliability. Minimum memory capacity on a p670 is 4 GB and on the p690 is 8 GB. The p670 maximum is 256 GB, and the p690 maximum is 512 GB. The p670 and p690 are complex systems, and the rules for populating memory are more involved than other pSeries servers. We first list the number of memory slots available for each system configuration and make a few remarks about memory balancing.

As described in Chapter 1, the pSeries 690 can have one to four MCMs (MultiChip Modules). Each MCM has two memory slots, so there is a maximum of eight memory slots per system. The physical packaging requires that four of these use “inward-facing” memory cards, and four “outward-facing” memory cards. Hence, there are two feature numbers for each memory card used in the p690:

+   - 4 GB memory card, inward facing (#4196)

+   - 4 GB memory card, outward facing (#4197)

+   - 4 GB memory card, 567 MHz, inward facing (#4480) (POWER4+ only)

+   - 4 GB memory card, 567 MHz, outward facing (#4481) (POWER4+ only)

+   - 8 GB memory card, inward facing (#4181)

+   - 8 GB memory card, outward facing (#4182)
