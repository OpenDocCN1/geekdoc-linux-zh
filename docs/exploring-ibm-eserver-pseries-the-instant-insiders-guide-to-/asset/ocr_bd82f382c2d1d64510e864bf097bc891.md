AIX 5L v5.2 supports “dynamic” LPAR. This means that resources (processors, memory, I/O slots) can be assigned or removed from LPAR AIX 5L v5.2 without rebooting partition. AIX 5L v5.1 and Linux support “static” LPAR, meaning that a partition must be rebooted in order to modify the resources assigned to it.

Why is logical partitioning needed? It allows customers to select a single system and allocate it to many applications (application consolidation) according to their workload requirements. This helps reduce total cost of ownership—lowering the costs of physical space and systems, and making more efficient use of all the power available in the hardware system. Other benefits include: (1) isolating applications from one another so that software failures in one application don't cause the entire system to go down, (2) establishing development and production partitions as new software is being implemented and tested, and (3) allowing different versions of the operating system to run in each partition.
