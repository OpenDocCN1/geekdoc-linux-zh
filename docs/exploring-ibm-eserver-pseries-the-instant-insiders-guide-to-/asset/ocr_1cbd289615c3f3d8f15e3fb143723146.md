# IBM 2-Port Gigabit Ethernet-SX PCI-X Adapter (#5707)

The 2-Port Gigabit Ethernet-SX Adapter (#5707), like its countpart #5706, provides two full-duplex 1 Gbps Ethernet connections, but in this case using the LC-type connector to standard shortwave multimode fiber. Depending on the cable, the adapter can support distances up to 550 meters. This adapter also provides the “large send” and “checksum offload” functions described above. It supports NIM and requires AIX 5L v5.1 or v5.2. For optimum performance, this adapter should be placed in a PCI-X slot.

# IBM Token-Rings PCI Adapter (#4959)

The IBM Token-Rings PCI Adapter (#4959) is a high-performance, 32-bit master adapter. Featuring an enhanced system interface for higher throughput and lower system utilization, coupled with RJ-45 and DB9 connectors, this adapter is well equipped to handle the LAN environment requirements of today’s servers and high-end workstations running I/O-intensive applications on the network. It supports network boot capability. Additional features and support include the following:

+   Operation at either 16 Mbps or 4 Mbps per twisted-pair or shielded twisted-pair (STP) via the RJ-45 and the 9-pin D-shell connectors.

+   Automatic ring speed detection. To simplify installation and reduce network downtime, the adapter automatically determines the ring speed and mode of an operating network and configures itself accordingly.

+   External status light-emitting diodes (LEDs), providing visual indication of adapter and ring status without disrupting operation.
