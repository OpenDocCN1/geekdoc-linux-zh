The industry-standard PCI subsystem supports both 32-bit and 64-bit PCI adapters. Greater application throughput is achieved via independent PCI buses for each of the 14 PCI slots in the I/O drawer. The independent buses for each slot also enhance reliability by isolating adapters from other adapters in the drawer. This hot-plug nature of these adapters allows for the removal and replacement of failed adapters without any impact on other areas in the drawer.

For customers who must provide for rapidly increasing workloads, the Model 6M1 offers Capacity Upgrade on Demand. This allows the customer to begin with a minimum 4-way 750 MHz system and, for free, install a second 4-way processor option with two or four of the processors initially desired. When the need for additional processing power arises, an AIX 5 command is used to activate these inactive processors in increments of two. The AIX 5 Workload Manager (a standard feature of the AIX 5 operating system) is used to allocate resources to the newly activated processors. After activation, the customer will be invoiced for payment of the processors then in use. p650-6M1 CUoD offers a demand solution for activating processors quickly when required, the process just described is less flexible and responsive than the methods used for the latest demand offers on p650, p670, and p690 systems. The p660-6M1 CUoD has been superseded by the process described in “pSeries 690 Specifics” in this chapter.

Like the other p660 models, the p660-6M1 is NEBS Level 3 compliant, offering special features such as 48-volt DC power for telecommunications central office operations. The Model 6M1 delivers the performance, expandability, and reliability required for e-business, enterprise resource planning, business intelligence, and other database serving applications. For value and convenience of ordering, IBM offers several standard p660-6M1 Express Configurations.

# pSeries 670 Specifics

The pSeries 670 is a 4-, 8- and 16-way server offering 1.5 GHz POWER4+ and 1.1 GHz POWER processors. The electronics design and packaging of the p670 are identical to those of the high-end p690. As a server targeted for the upper end of midrange businesses, the p670 is more limited than the p690 in terms of processor speeds, memory capacity and scalability, and I/O expandability. In all other respects, it is equivalent. The p670 uses MCM packaging, offering the following processor options:

- 4-, 8-, and 16-way 1.1 GHz POWER4
- 4-, 8-, and 16-way 1.5 GHz POWER4+

The 4-way and 8-way configurations use one MCM, and 16-way systems have two MCMs. Each MCM includes 128 MB of L3 cache. Main memory begins at 4 GB and can be increased to 256 GB.

The p670 is packaged in a single 24-inch-wide 42U rack (Figure 1.18) which accommodates the p670 system unit, from one to three IBM 7040-61D I/O Drawers, a media drawer, and a 350-volt bulk power subsystem. In a minimum p670 configuration, the I/O drawer and media drawer include the following:

- Two 18.2 GB Ultra-SCSI disk drives
- Eight hot-swappable disk bays (two occupied by the base disk drives), expandable to 16 in a single I/O drawer
- Five media bays
- One planar with 10 hot-plug PCI-X slots (an optional second planar allows 20 slots in a single I/O drawer)

The p670 has the full set of RAS features as described for the p690, which provide the almost continuous availability required for mission-critical business applications. Most failures can be predicted and corrective actions (as deallocating processors, PCI buses, or caches) so that operations continue and service actions may be done on a scheduled basis. Even replacement of disk drives, I/O adapters, and power supplies or cooling fans can be done while the p670 continues to run.

The p670 also supports dynamic LPAR and the full range of demand capabilities as described in the p690 description later in this chapter. Capacity Upgrade on Demand for processors, CuOD for memory, OnOff Capacity on Demand and Trial CoD are features that allow processors and memory to be installed in the p670 but remain in a standby mode until needed. They are priced at only a portion of the price of an equally activated processor or memory feature, with the balance being made up as resources are activated. This gives users a way to respond to rapidly changing workloads without having to invest the total system price up front. These functions are explained more fully in the p690 description later in this chapter.

The p670 is supported by AIX 5L v5.1 and v5.2, as well as Linux (SuSE SLES 8). With LPAR capability, each partition can run its instance of one of these operating systems. Not all system capabilities are supported by Linux, including dynamic LPAR and CuOD for memory.

In summary, the p670 provides a midrange solution with the latest pSeries technology and significant expandability for businesses whose requirements exceed the capacity of an 8-650, but who do not need or cannot economically justify the enterprise-class p690 server. However, for systems in which a company out the p670 and needs more processing power and more I/O expansion, IBM offers a model conversion from a 4-way to a 16-way.
