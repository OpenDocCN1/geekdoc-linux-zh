# POWER4 and POWER4+ Microprocessors

IBM's POWER4 microprocessors, running at clock rates of 1.1 GHz and 1.3 GHz (more than one billion cycles per second), were introduced on the pSeries 690. Using the same architecture, coupled with enhanced chip fabrication technology, POWER4+ processors running at clock rates from 1.2 to 1.7 GHz are now available on all focus pSeries servers—p615, p630, p650, p655, p670, and p690. POWER4+ processors, which contain more than 180 million transistors, are manufactured with IBM's 0.13 micron fabrication process, whereas the 0.18 micron process was used for POWER4 chips. The energy-saving copper and SOI technology is used in both POWER4 and POWER4+ processors. The combination of smaller chip size and SOI technology make it possible for the higher processor speeds available with POWER4+ processors. The same architecture is used for the original POWER4 and the latest POWER4+ processors. The POWER4 processor architecture is the result of a long development cycle guided by several goals: optimization for SMP designs and ability to extend to very high frequency, and binary compatibility with 32-bit and 64-bit PowerPC applications.

The POWER4 chip (Figure 1.20, shown previously) has two processors, each with an L1 data and instruction cache, sharing a L2 cache structure through a crossbar switch (CIU). Each of the three independent L2 cache controllers can provide 32 bytes (256 bits) from L2 to either the data cache or the instruction cache in one of the processors per cycle. The Fabric Controller is the hub of the chip, providing the high-bandwidth paths required to meet the objectives of a balanced design for memory and I/O access, and for optimized SMP performance.
