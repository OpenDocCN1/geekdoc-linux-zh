# RS/6000 Model 270 Specifics

The RS/6000 Model 270 is a 1 to 4-way SMP system with 64-bit POWER3-II processor options that allow users to configure with great flexibility for use either as a deskside server or as a workstation, depending on the application requirements. The Model 270 uses the same basic electronics design as that found in the pSeries 640. It has two processor card slots into which one or two of the following processor cards may be installed.

+   - 1- or 2-way 375 MHz POWER3-II with 4 MB of L2 cache per processor
- 2-way 375 MHz POWER3-II with 8 MB of L2 cache per processor
- 2-way 450 MHz POWER3-II with 8 MB of L2 cache per processor

Using the 375 MHz processor options with 4 MB of L2 cache, one can configure the Model 270 as a 1-, 2-, 3-, or 4-way system. Using either of the options with 8 MB of L2 cache, only 2- or 4-way configurations are possible. As in all pSeries and RS/6000 systems, multiple processor options are available, all processor cards in a system must be of the same type. Processor upgrades to add a second processor card or to move from a less powerful to a higher performance processor(s) are available. The upgrades require simply removing the old card(s) and plugging in the new(s). They are priced based return of the old cards to IBM.

The Model 270 is a deskside system packed with the features sought for a powerful workstation or an entry-level midrange server. It is a full 64-bit platform, capable of running 64-bit or 32-bit AIX applications. In particular note for technical computing and workstation applications is the high floating-point performance of the POWER3-II processors.

An entry-level Model 270 configuration includes the following:

+   - 1-way 375 MHz POWER3-II processor with 4 MB of L2 cache
- 256 MB of SDRAM with ECC
- 18.2 GB Ultra2-SCSI disk drive
