
## 12 Exploring IBM @server pSeries

IBM eServer Cluster 1600 is not a product per se, but a name under which all of IBM's AI-based clustering technologies (pSeries servers, interconnect options, and software products) may be ordered and managed. Cluster 1600 is the logical extension of the RS/6000 SP technologies which allowed hundreds of processors to be combined in massively parallel systems, such as Deep Blue (the system that defeated chess master Gary Kasparov in 1997) and ACI World (the world's fastest supercomputer in 2000 at Lawrence Livermore National Lab). Initially, the servers in an RS/6000 SP system were specially designed and packed SP nodes, based on the same PowerPC and POWER architectures as those used in RS/6000 SMP computers. Within the past few years, support for attaching pSeries and RS/6000 servers as “nodes” in an SP system has grown. The pSeries 65 is packed similarly to the earlier SP nodes, making it an ideal choice for applications in which the maximum processor density (least “footprint”) is required. Cluster 1600 allows users to integrate pSeries servers and/or LPARs of those servers, existing SP nodes, and high-speed interconnect technologies in unified systems with a single point of control running IBM Parallel System Program for AIX (PSSP) software.

As been mentioned, pSeries servers like the p620 and p660 replaced older RS/6000 models, offering similar performance points and packaging options but using later technologies. Other pSeries models—such as the p610, p640, and p690—are designed to meet the requirements of users in new market segments. Most recently, systems designed with the latest POWER4 and POWER4+ technologies, logical partitioning, the industry-standard I/O architectures, and support for both AIX 5L and Linux have established the unique “identity” of pSeries servers, as differentiated from the predecessor RS/6000 family.

At this time, several RS/6000 systems are still available, addressing primarily workstation and low-cost server requirements. But it is anticipated that these products will be withdrawn from marketing in the near future. The RS/6000 Model 150 is a PowerPC 604e system available in either 250 MHz or 375 MHz speeds. It is also very well suited for use as a workload group.

The RS/6000 B150 is a compact rack-mountable server using the same PowerPC 604e electronics as those used in the Model 150 at 375 MHz. At only 2U, many B50s can be mounted in an industry-standard 19-inch rack. The B150 is targeted for Internet Service Providers (ISPs) and Application Service Providers (ASPs) for such applications as Web hosting, firewalls, and Web caching.

The RS/6000 Model 170 was the first 64-bit uniprocessor workstation in the product line. Its POWER3-II microprocessor, employing IBM’s innovative copper design, runs at speeds of 333 MHz, 400 MHz, or 450 MHz. The Model 170 has outstanding floating-point performance, and when configured with a 3D graphics adapter (also called a "graphics accelerator"), it is an impressive graphics workstation and technical workload system at a very attractive price. As the least expensive 64-bit system, it is a good choice for software development and testing in addition to being a very cost-effective entry-level server for both technical and commercial workloads.

The RS/6000 Model 270 is a 1- to 4-way SMP system using POWER3-II multiprocessors running at 375 MHz or 450 MHz. Equipped with a 3D graphics adapter card, the Model 270 workstation excels in 3D graphics performance. It is also a very cost-effective midrange server for both technical and commercial workloads.

## pSeries 610 Specifics

The pSeries 610 provides a new price point in the pSeries family between the RS/6000 Models 170 and 270, which are 64-bit systems with 333 MHz, 375 MHz, or 450 MHz processors. The pSeries 610 offers a range of performance for many users. On the other hand, uniprocessor models do not offer the flexibility to start and grow. The pSeries 610 includes the following:
- 333 MHz POWER3-II processor
- 512 MB of RAM (Error Correction Code)
- 18 GB of SCSI drive
