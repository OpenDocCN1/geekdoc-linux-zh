# Exploring IBM @serverSeries

The electronics of the p640 are essentially identical to that of the Model 270, but there are significant differences in other features of the design that optimize it for the intended market segment. The base configuration of the p640 includes the following:

+   - 1-way 375 MHz POWER3-IE processor with 4 MB of L2 cache
- 256 MB of SDRAM with ECC
- 18.2 GB Ultra2-SCSI disk drive
- Built-in service processor
- Integrated I/O ports (do not require use of PCI slots)
  - 100/100 Mbps Ethernet (with two ports)
  - Ultra2-SCSI (internal) and Ultra2-SCSI (external) ports
  - One parallel
  - Three serial
  - Keyboard
  - Mouse

Although there is no diskette or CD-ROM drive in the base configuration, there is one media bay that can accept an optional CD-ROM, DVD-RAM, or tape drive. In the server farm environments for which the p640 is designed, system management, including software installation, is usually done over a LAN. For the convenience of systems administrators, one of the serial ports is accessible from the front, so that a hand-held device like the IBM Workpad® or a Palm device can be quickly and easily connected to any p640 in the server farm. With software available at no charge from IBM, the p640 (or other pSeries servers) can be monitored and controlled remotely using a hand-held wireless device, such as those named.
