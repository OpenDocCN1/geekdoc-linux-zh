The 270 contains several advanced reliability and fault-tolerance features in addition to ECC memory. A service processor is standard, providing a means to diagnose, check status, and sense operational conditions of a remote system, even when the main processor is inoperable. The system runs a BIST (Built-In Self-Test) and a POST (Power-On Self-Test), which check the processor(s), memory, L2 cache, and other hardware. Non-critical errors and errors on resources that can be critically removed are logged while still allowing the system to boot.

Temperature is monitored, and the fan speed is increased if needed to maintain proper cooling. DC voltages are also monitored to provide warning and orderly system shutdown if they vary outside of operational specifications.

The Model 270 is designed to allow on-line diagnostics, or the ability to investigate malfunctions without interrupting end-user operation. It also has an auto-restart option that, if enabled, will allow the system to automatically rebooting an unrecoverable software error, a software hang, or a hardware failure.

Since it is up to 4-way SMP system, the Model 270 also offers Dynamic Processor Deallocation, an IBM innovation involving both hardware design and the AIX 5L operating system. With Dynamic Processor Deallocation, the processors are constantly monitored for errors. If the error reaches a threshold that indicates a likely failure, workload for the potentially failing processor is automatically reassigned to the remaining processors and the bad processor is taken off. Even this system performance will be slightly lower with one less processor, this feature helps avoid a possible system outage and allows the failing processor to be serviced at a planned future time. This capability is active only in systems with two or more processors.

In addition to its performance and scalability as a server, the RS/6000 Model 270 provides the I/O support (3D graphics and stereo audio) required for a workstation for applications that need high-performance 3D graphics presentation. Since the graphics API in AIX 5L has been specifically designed to exploit SMP capabilities, applications like CATIA will have very good scaling with the multiple processors available in the Model 270. But since of SMP system design, users may find that the uniprocessor Model 170 (which offers the powerful 450 MHz POWER-3 II processor with 8 MB of L2 cache) may be the cost-effective RS/6000 workstation choice for their applications. The GXT135P, GXT4500P, and high-end GXT6500P graphics accelerators are all available for the Model 270.

With its performance, SMP configuration, and advanced graphics, the RS/6000 Model 270 is well positioned as an entry-level deskside server for commercial or technical applications and as a high-end MCAD workstation.

## RS/6000 Model B50 Specifics

The last server in the entry category is the RS/6000 Model B50, a compact rack-mounted server that satisfies requirements for front-end Internet applications for high-density, small-footprint, and low-cost implementations for e-business opportunities. It is targeted principally for applications such as Web hosting, firewalls, directory services, e-commerce, caching, and messaging. Internet Service Providers and Application Providers are likely to be interested in this model, which is based on the same technology as the RS/6000 Model 150, but in a rack drawer.

Like the Model 150, the B50 is a 32-bit system using the 375 MHz PowerPC 604e microprocessor with 1 MB of L2 cache. The system configuration includes a minimum of 128 MB memory expandable to 1 GB, a diskette drive, a CD-ROM drive, an integrated Ultra-SCSI controller and 10/Ethernet. ## Midrange Servers

The IBM @serverSeries—An Overview

The range of IBM @serverSeries extends from entry-level B50 to high-end p-series. For more processing power, the p650 offers 1.45 GHz processor cards with 32 MB of L3 cache. As shown in Figure 1.12, the p650 can be configured with one to 2-way processor cards. All processors must be of the same speed, either 1.2 GHz or 1.45 GHz. Packaged on each processor card is L3 cache, which stages data and instructions between the processor chips and main memory. Memory DIMMs are distributed in a balanced fashion across the processor “books” (IBM’s name for the physical unit containing processor cards and memory DIMMs). These books protect the components from damage in handling and help manage air for cooling. Each processor book has eight DIMM slots, and must be installed in quads (four DIMMs), Since the largest available memory DIM is 2 GB (4 x 1024 MB), the maximum memory capacity of a 2-way system is 16 GB, of a 4-way system is 32 GB, and so on to 64 GB for an 8-way p650.

The interface to the I/O subsystem is through the RIO-2 hubs. For the first processor, the RIO-2 hub connects to the internal I/O subsystem (PCI-X slots, integrated controllers, service processor) and up to two RIO-2 ports for an I/O drawer loop.
