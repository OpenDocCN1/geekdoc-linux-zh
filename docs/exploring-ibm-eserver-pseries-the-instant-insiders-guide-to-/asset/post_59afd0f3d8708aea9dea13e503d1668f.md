The electronics architecture of the p640 is the same as that of the RS/6000 Model 270, in that it is a 1- to 4-way SMP server using POWER3-II processors running at either 375 MHz or 450 MHz. The processor options are following:

- 1- or 2-way 375 MHz POWER3-II with 4 MB of L2 cache per processor
- 2-way 375 MHz POWER3-II with 8 MB of L2 cache per processor
- 2-way 450 MHz POWER3-II with 8 MB of L2 cache per processor

Using the 375 MHz processor options with 4 MB of L2 cache, one can configure a pSeries 640 as a 1-, 2-, or 4-way system. Using either of the options with 8 MB of L2 cache, only 2- or 4-way configurations are possible. Processor upgrades to add a second processor card or to move from a less powerful to a higher performance processor(s) are available. Upgrades require simply removing the old card(s) and plugging in the new one(s).

# Exploring IBM @serverSeries

The electronics of the p640 are essentially identical to that of the Model 270, but there are significant differences in other features of the design that optimize it for the intended market segment. The base configuration of the p640 includes the following:

- 1-way 375 MHz POWER3-IE processor with 4 MB of L2 cache
- 256 MB of SDRAM with ECC
- 18.2 GB Ultra2-SCSI disk drive
- Built-in service processor
- Integrated I/O ports (do not require use of PCI slots)
  - 100/100 Mbps Ethernet (with two ports)
  - Ultra2-SCSI (internal) and Ultra2-SCSI (external) ports
  - One parallel
  - Three serial
  - Keyboard
  - Mouse

Although there is no diskette or CD-ROM drive in the base configuration, there is one media bay that can accept an optional CD-ROM, DVD-RAM, or tape drive. In the server farm environments for which the p640 is designed, system management, including software installation, is usually done over a LAN. For the convenience of systems administrators, one of the serial ports is accessible from the front, so that a hand-held device like the IBM Workpad® or a Palm device can be quickly and easily connected to any p640 in the server farm. With software available at no charge from IBM, the p640 (or other pSeries servers) can be monitored and controlled remotely using a hand-held wireless device, such as those named. All system status indicators are located on both front and rear, including a program-able alarm light to help systems administrators locate a failing system in a server farm environment.

The p640 has four front-accessible hot-swappable disk bays, for a maximum storage capacity of 293.6 GB. Features for high availability are redundant hot-plug power supplies and cooling fans. The pSeries 640 meets the stringent environmental conditions of NEBS Level 3 standards, which means that it can operate at temperatures higher than those found in computer room or office environments and can withstand severe vibrations and air quality conditions. In addition to operating on either 110 or 220 volts AC, the p640 offers optional 48-volt DC power, a feature required by many telecommunications providers.

Like the Model 270, pSeries 640 systems with two or more processors offer Dynamic Processor Deallocation, the IBM feature involving both the hardware design and the AIX 5 operating system and resulting in higher system availability, even if one processor should fail.

The p640 runs AIX 5 Version 5.1 or later and AIX Version 4.3.3. Many users in the markets for which the p640 is designed are moving to the Linux operating system. Although IBM itself does not distribute or support Linux, IBM is working closely with the Open Source community to enable third parties to distribute Linux for IBM servers. At this time, Linux distributions for the p640 are available from Red Hat and SuSE.

# RS/6000 Model 150 Specifics

The Model 150 is positioned as a 32-bit entry-level server. It employs the PowerPC 604e microprocessor driven at either 250 MHz or 375 MHz, with 1 MB of L2 cache, allowing users to choose either the absolutely lowest cost computer or a still attractively priced but more powerful system. With five PCI slots, memory capacity of 1 GB, and up to 54 GB of disk storage, the Model 150 has sufficient expansion room for many business applications.

A minimal configuration for the Model 150 includes an 18.2 GB Ultra-SCSI hard drive, a CD-ROM drive, a diskette drive, and 128 MB of ECC SDRAM. Built into the system is a 10/100 Mbps Ethernet controller and an Ultra-SCSI controller. Also standard are two serial ports and a parallel port, as well as ports for a keyboard, mouse, tablet, and plenty of connectivity choices without requiring a PCI slot or the cost of purchasing additional adapters. The Model 150 can run either AIX v4.3 or AIX 5.

# RS/6000 Model 170 Specifics

The RS/6000 Model 170 is a powerful 64-bit uniprocessor system, offering a great range of price and performance for both server and workstation applications. This system is slightly larger than the Model 150, providing one PCI slot and one more disk bay, as well as offering a second integrated Ultra-SCSI port for attachment of external devices. More important, its range of performance options is quite broad, with microprocessors running at 333 MHz (with 1 MB of L2 cache), 400 MHz (4 MB of L2 cache), or 450 MHz (8 MB of L2 cache). An upgrade to a more powerful processor is simple matter of changing the processor card. Floating point in particular is more than four times greater than the 450 MHz version of this system, compared to the 250 processor processor on Model 150. Beyond just the faster processors, the 170 employs a faster memory bus matched to the speed of the processor. The bus speeds are 95 MHz and 100 MHz for the 333 MHz and 400 MHz respectively.

A minimal configuration of this model will have a 333 MHz processor with 256 MB of RAM, an 18.2 GB Ultra-SCSI disk drive, a CD-ROM drive, and a diskette. The motherboard has an integrated 10/100 Mbps Ethernet controller, internal Ultra-SCSI and external Ultra-SCSI ports, a parallel port, two serial ports, and stereo audio. For input I/O and communication capability, the Model 170 has four 32-bit and two 64-bit PCI slots. Three disk bays (beyond those used by the disk drive and CD-ROM drive) are available, bringing internal capacity to 293.6 GB. Memory is expandable to 2 GB. A service processor to help system availability is standard. The Model 170 supports all of the latest graphics adapters, from the entry GXT135P for entry 2D work to 3D graphics accelerators such as the GXT4500P and GXT6500P.

# RS/6000 Model 270 Specifics

The RS/6000 Model 270 is a 1 to 4-way SMP system with 64-bit POWER3-II processor options that allow users to configure with great flexibility use either as a deskside server or as a workstation, depending on the application requirements. The Model 270 uses the same basic electronics design as that found in the pSeries 640. It has two processor card slots into which one or two of the following processor cards may be installed:

- 1- or 2-way 375 MHz POWER3-II with 4 MB of L2 cache per processor
- 2-way 375 MHz POWER3-II with 8 MB of L2 cache per processor
- 2-way 450 MHz POWER3-II with 8 MB of L2 cache per processor

Using the 375 MHz processor options with 4 MB of L2 cache, one can configure the Model 270 as a 1-, 2-, 3-, or 4-way system. Using either of the options with 8 MB of L2 cache, only 2- or 4-way configurations are possible. As in all pSeries and RS/6000 systems, multiple processor options are available; all processor cards in a system must be of the same type. Processor upgrades to add a second processor card or to move from a less powerful to a higher performance processor(s) are available. The upgrades require simply removing the old card(s) and plugging in the new(s). They are priced based on return of the old cards to IBM.

The Model 270 is a deskside system packed with the features sought for a powerful workstation or an entry-level midrange server. It is a full 64-bit platform, capable of running 64-bit or 32-bit AIX applications. In particular note for technical computing and workstation applications is the high floating-point performance of the POWER3-II processors.

An entry-level Model 270 configuration includes the following:

- 1-way 375 MHz POWER3-II processor with 4 MB of L2 cache
- 256 MB of SDRAM with ECC
- 18.2 GB Ultra2-SCSI disk drive
