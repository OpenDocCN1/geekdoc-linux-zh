The reasons are that each memory slot is used by certain processors on each MCM and the p670 and p690 use memory in a round-robin fashion across the four memory controllers on an MCM, referred to as “memory interleaving.” If memory were not installed in pairs, then all the memory traffic would be routed through only half the control circuitry available on the MCM, thus reducing the available bandwidth from processors through L3 cache to memory and affecting system-level performance.

IBM provides detailed memory configuration rules in its on-line manual. Of course, servers of the power and complexity of the pSeries 670 and p690 require careful planning by competent technical personnel to ensure that the configuration, including the memory subsystem, is designed optimally for the intended applications workloads. A good reference available on the IBM Web site is a white paper entitled “IBM eServer pSeries 690, Configuring for Performance.” In addition to configuring memory for optimum performance, this paper also discusses how to best configure the I/O subsystem. The companion Web site (www.maxpress.com) for this book has a link to IBM information such as this paper.
