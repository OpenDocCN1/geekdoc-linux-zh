# Logical Partitioning

The Series 690 offers dynamic logical partitioning of system resources—processors, memory, and I/O slots (and the attached devices). System administrators can assign these resources in any combination, unconstrained by physical packaging boundaries, to form virtual systems within the p690. The design of the p690 LPAR capability is based on the experience IBM brings from its mainframe-class systems, which have offered logical partitioning capability for over 25 years.

The p690 allows up to 32 LPARs to be formed, with each partition running its copy of the operating system—AIX 5L v5.1, AIX 5L v5.2, or Linux. The system protects each partition from software errors in other partitions, and the hardware is designed with isolation to prevent propagation of hardware failures. Resource allocation requires careful planning by systems administrators. The smallest units of resources that can be allocated are one processor, 256 MB of memory (expandable in units of 256 MB), and one I/O adapter slot. Each partition must have its own device and associated adapter and Ethernet attachment to the IBM 7315-C02 Hardware Management Console. Special consideration must be given to handling devices that may be needed at times by multiple partitions (e.g., CD-ROM or tape). Media devices should be attached to an adapter or integrated controller that can be reassigned among LPARs as required for installing software or backup operations.

# On Demand Capabilities

In 2003, the Series family introduced a set of what IBM calls “on demand” capabilities. The functions described in this section are offered on p690, p670, and p650.

# Processor Capacity on Demand

Processor CUOD was actually introduced on the p690. It allows processors to be installed but remain inactive until workload requires activation. CUOD features are the following:

- p690—8-way MCM (1.1, 1.3, 1.5, or 1.7 GHz) with 4-way active
- p670—8-way MCM (1.1 or 1.5 GHz) with 4-way active
- p650—2-way (1.45 GHz) with no active

The p670 has only two MCM positions. The minimum configuration with 1 GHz processors is 12-way (one fully active 8-way MCM and one CUOD MCM). With the 1.5 GHz POWER4+ processors, both MCMs may be CUOD, allowing an 8-way active and 8-way standby configuration—just like the p690. Since all processor cards on the p650 are 2-way, the minimum on demand configuration is two cards with two active and two standby.

Standby processors are activated in pairs by purchasing the activation feature number for the system and processor speed involved. When an order is placed for has provided the necessary system information (done electronically via the Internet), IBM provides an encrypted key, or activation code, within one business day. The key is posted to a Web site for immediate access and confirmed by a hard copy sent by mail.
