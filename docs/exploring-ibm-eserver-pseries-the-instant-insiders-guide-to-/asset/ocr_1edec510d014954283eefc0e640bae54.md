The p610 has six hot-swappable front-accessible disk drive bays, which allow disks to be replaced while the system is still running. If the optional redundant third power supply is installed, the system will not go down if one power supply fails, and the hot-plug supplies allow the failing one to be replaced while power is on. Similarly, if one of the four cooling fans fails, the remaining three fans operate at a higher speed to keep the system cool and the hot-plug fans units can be replaced while the system is running. Finally, like most pSeries systems, the p610 has a built-in service processor that performs such functions as error tracking and accounting (if certain policy flags are set), and, if configured with a modem, can automatically dial a preprogrammed telephone number (“call home”) in the event of system errors.

In summary, the pSeries 610, with both rack-drawer and desks packaging, is a powerful system that provides users with the potential for expansion when required by business growth and with many features to help keep the system running and make it easy to replace components if failures occur.

# pSeries 615 Specifics

The pSeries 615, IBM’s most recent pSeries model, is an entry server offering 1-way and 2-way configurations of 1.2 GHz POWER4+ processors. Like the p610, which it will eventually replace in the pSeries lineup, the p615 is available in two models—the rack-mount pSeries 615 Model C63 and the deskside pSeries 615 Model 6E3 (Figure 1.5). However, the p615 offers higher performance and more expansion capacity into a more compact rack drawer (p615-6C3 is a 4U package, compared to the 5U p610-C1) and a deskside p615-6E3 package large in size to the p610-6E1.

The p615 offers from 1 to 16 GB of memory, six hot-plug PCI-X slots, either four or eight hot-swappable disk drive bays, and three media bays. The deskside p615-6E3 and rack-mount p615-6C3 have the same electronics design and expansion capacity. Unlike other servers, the p615 is available only in what IBM calls “Express Configurations.” These are fixed configurations that must include all the specified components without substitutions, but to which other features may be added—such as additional memory, disk drives, or I/O adapters.
