# Theft Prevention

Theft prevention deals deals with protecting sensitive information from unauthorized disclosure. Security requirements vary widely from environment to environment and should be considered early in your planning.

pSeries systems provide various levels of security that help deter unauthorized access. Security is provided by the computer system itself along with the operating system. In fact, pSeries systems and the AIX 5L operating system have been designed to meet the stringent security requirements defined by the National Security Center Trusted Computer System Evaluation Criteria C2.

On the needs of the environment, various levels of security can be activated, from no security to detailed access control. A security officer is usually assigned to manage the security of the system.

For sensitive environments, some customers may consider restricting access to areas where pSeries systems or associated terminals are located. These site-planning considerations should be considered early in a computer automation project.

# Service

Although every effort has been made to make pSeries systems as reliable as possible, some computers will fail, and if a computer does have a problem, there must be a way of getting it fixed. All pSeries systems come with a warranty from IBM. For many systems, the standard offering is a 1-year warranty that provides free on-site repairs from IBM’s service division 24 hours a day, 7 days a week. In order to be competitive in the entry and midrange UNIX server markets, IBM has begun to offer on some models a 1-year warranty with “9 to 5, nextbusiness-day” service. Upgrading to “7 x 24” support is available for an additional charge on these systems.
