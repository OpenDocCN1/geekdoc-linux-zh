# pSeries 690 Overview

The p690 is an 8- to 32-way SMP server using POWER4+ processors
running at 1.5 GHz and 1.7 GHz and POWER4 processors running
her at 1.1 GHz or 1.3 GHz. The 24-inch-wide system rack (Fig-
ure 1) holds the processor drawer, an integrated power system, and
up to four I/O racks. With a second rack, up to eight I/O drawers can
be supported. If the system configuration requires additional rack-mounted
devices, such as SCSI storage units or tape drives, they are
mount in standard 19-inch-wide IBM 7014-T00 or 7014-T42 racks.
With the expandability in the p690 I/O drawers and the addition of
other subsystems as required, the scalability of the p690 is virtually
unlimited.
