It is the latest generation of low-cost 2D graphics options for pSeries systems. Maximum resolution at the digital interface is 1600 × 1200. # Three-Dimensional Graphics Accelerators

Although 2D graphics support is adequate for the applications run on pSeries servers, workstations used for automotive and aircraft design require high-performance three-dimensional graphics accelerators. The following 3D graphics adapters support the application programming interfaces (APIs) for three-dimensional graphics: OpenGL and graphHIGS. Each API tends to be used in its own specialized set of applications. Since all of them support both OpenGL and graphHIGS, selecting the right graphics adapter depends on what performance the application requires. In words, the traditional price/performance criteria should be used in selecting a 3D graphics adapter. The more expensive (and better performing) adapters implement more graphics features within the adapter hardware, whereas the lower-priced adapters will leave more of the processing to the host system's processor.
