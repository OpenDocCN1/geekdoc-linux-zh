# pSeries and Your Environment 267

The iSeries systems architecture includes a built-in relational database. In other words, the iSeries hardware and operating system have been designed specifically to provide the database function commonly needed in business environments. Most other computer systems (including the pSeries) require separately purchased database systems that sit on top of the operating system to provide users with a relational database. Because the iSeries system's database is implemented in the hardware- and operating system, the performance and elegance of database implementation are improved. Further, the programmer productivity afforded by the built-in iSeries database makes it a good system for those writing and maintaining their own application programs. iSeries systems are designed around an advanced application architecture that facilitates the implementation of distributed computing environments. Other things being equal, if there is a requirement to coexist with a network of other IBM systems following this application-centric architecture or to run applications for the OS/400 operating system, then an iSeries system is probably the right choice. iSeries computers can also participate in “open” environments through their support of TCP/IP communications.

The pSeries has no built-in database, but many relational database programs are available that add this capability to the system. For those who currently a multiuser computer system running the UNIX operating system, migrating to a pSeries system will be much more natural than migrating to an iSeries system. If there is a need to coexist with computer systems of many different brands, the open-system approach taken by the pSeries system will be a plus. By supporting many industry standards, pSeries systems and the AIX 5L operating system are designed to participate with other types of computing equipment. For more information about the iSeries family, read Exploring IBM eServer iSeries by Jim Hoskins and Roger Dimmick (Maximum Press).
