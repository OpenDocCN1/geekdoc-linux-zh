The answers to these questions depend largely on the specifics of a given environment and are beyond the scope of this book. However, a few basics remain the same whether a program is being selected for a multinational corporation or for a corner fish market. First of all, the task to be done must be precisely understood before pursuing any application program alternatives. A thorough knowledge of the task helps to identify specific requirements an application program must meet. After a detailed understanding of the task is attained, a search can begin through the sea of prewritten, or "off-the-shelf," application programs. If an appropriate prewritten application program is found that fits a company’s needs, then the expense, delay, and effort associated with custom application program development can be avoided. Good prewritten application programs can be quite flexible. However, because everyone has slightly different needs and methods, within a given business function, it is likely that any prewritten application will have features not needed in a specific company and won't have some features that would be desirable.

There are many sources of information about the prewritten application programs. Software companies and consultants can recommend application programs to fit the needs of a business. Many popular computer magazines consistently extend reviews of prewritten application programs. These can be excellent and timely sources of information.

For specific or highly specialized needs, prewritten application programs may not be adequate. In this case, custom-developed software may be desirable. The development and maintenance of custom software involves a long-term commitment that typically is expensive, but it may be costly in the long run to pay for the development of custom software than to settle for a prewritten application program that does not do the job. If the custom software is chosen, an important step is to select the proper developer. Organizations that have their own programming staff can do their own custom application program development. Companies that do not have their own programmers (probably small and medium-sized businesses) will find it necessary to seek help (i.e., an outside software developer). In either case, it is the developer who will have the largest effect on the ultimate success or failure of the custom development activity. The developer’s job is not an easy one. Besides programming expertise, developers must become experts in all aspects of the organization's activities right down to every step performed.
