# pSeries 610 Specifics

The pSeries 610 (Figure 1.3) provides a new price/performance point in the pSeries family between uniprocessor models and the previously available entry SMP models, which were 1- to 4-way systems. Although an up to 4-way system provides excellent performance and a lot of room for users to start small and grow, some additional cost is required in the electronics infrastructure to allow for that much expansion. On the other hand, uniprocessor models do not offer the range of performance needed for many small business or departmental applications. So the p610 strikes a middle ground with two POWER3II processors at 333 MHz, 375 MHz, or 450 MHz (the same 64-bit, copper-based processors used in the popular p640 and the RS/6000 Models 170 and 270), along with five PCI slots, seven disk bays, and a maximum memory capacity of 8 GB. In addition, p610 is available as a deskside server (p610-6E1) and as a 5U rack-drawer server (p610-C61), both having the same electronics design and expansion capacity.

The minimum configuration of the pSeries 610 includes the following:

+   333 MHz POWER3-II processor with 4 MB of cache

+   512 MB of SDRAM (Synchronous Dynamic Random Access Memory) with ECC (Error Checking and Correcting)

+   18.2 GB Ultra3-SCSI disk drive
