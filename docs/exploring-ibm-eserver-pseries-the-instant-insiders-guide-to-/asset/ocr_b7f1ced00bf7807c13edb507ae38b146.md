The smallest piece of information the main processor and main memory use is called a bit. These bits are grouped into bytes (8 bits), half-words (16 bits), words (32 bits), and double words (64 bits) to form the computer's representation of numbers, letters of the alphabet, instructions in a program, and so on. With this basic knowledge, let's take a closer look at the system's main processor and main memory.

# The Processor

The processor is the heart of a computer system because it is the control center for information flow inside the computer. It is the main processor that does the data manipulation or “thinking” necessary to perform tasks for the user. The speed of the circuits making up the main processor, along with its architecture, determines the overall processing speeds achievable by the computer.

Many different (though compatible) RISC processor designs have been used in the RS/6000 and pSeries families. The following section gives an overview of the original implementation and describes some of the enhancements that have been made over the years as new generations of RISC processor technology were developed. Finally, there is a more detailed description of the latest IBM RISC processors—POWER4 and POWER4+.
