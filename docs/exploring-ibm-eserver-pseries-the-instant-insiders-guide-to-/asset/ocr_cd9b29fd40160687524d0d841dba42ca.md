# 12 Exploring IBM @server pSeries

IBM eServer Cluster 1600 is not a product per se, but a name under which all of IBM's AI-based clustering technologies (pSeries servers, interconnect options, and software products) may be ordered and managed. Cluster 1600 is the logical extension of the RS/6000 SP technologies which allowed hundreds of processors to be combined in massively parallel systems, such as Deep Blue (the system that defeated chess master Gary Kasparov in 1997) and ACI World (the world's fastest supercomputer in 2000 at Lawrence Livermore National Lab). Initially, the servers in an RS/6000 SP system were specially designed and packed SP nodes, based on the same PowerPC and POWER architectures as those used in RS/6000 SMP computers. Within the past few years, support for attaching pSeries and RS/6000 servers as “nodes” in an SP system. The pSeries 65 is packed similarly to the earlier SP nodes, making it an ideal choice for applications in which the maximum processor density (least “footprint”) is required. Cluster 1600 allows users to integrate pSeries servers and/or LPARs of those servers, existing SP nodes, and high-speed interconnect technologies in unified systems with a single point of control running IBM Parallel System Program for AIX (PSSP) software.

As been mentioned, pSeries servers like the p620 and p660 replaced older RS/6000 models, offering similar performance points and packaging options but using later technologies. Other pSeries models—such as the p610, p640, and p690—designed to meet the requirements of users in new market segments. Most recently, systems designed with the latest POWER4 and POWER4+ technologies, logical partitioning, the industry-standard I/O architectures, and support for both AIX 5L and Linux have established the unique “identity” of pSeries servers, as differentiated from the predecessor RS/6000 family.

At this time, several RS/6000 systems are still available, addressing primarily workstation and low-cost server requirements.
