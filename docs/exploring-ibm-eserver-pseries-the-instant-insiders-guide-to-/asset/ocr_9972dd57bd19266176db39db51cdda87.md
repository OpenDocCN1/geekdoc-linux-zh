**Figure 1.17.** pSeries 660 Model 6M1 system design.

The industry-standard PCI subsystem supports both 32-bit and 64-bit PCI adapters. Greater application throughput is achieved via independent PCI buses for each of the 14 PCI slots in the I/O drawer. The independent buses for each slot also enhance reliability by isolating adapters from other adapters in the drawer. This the hot-plug nature of these adapters allows for the removal and replacement of failed adapters without any impact on other areas in the drawer.
