Serial ports transfer bytes (one bit at a time) using the asynchronous communications protocol at a rate of 38.4 Kbps. ## Graphics

Images presented on a computer’s display are used to present information to the user. pSeries servers support two-dimensional graphics, which are adequate for graphical user interfaces (GUIs) and for Internet access. As has stated earlier, many users of pSeries systems will actually be working at a PC attached to LAN to the server. Even for 2D graphics, the quality of images can directly affect the user's productivity, effectiveness, and enjoyment during a work session. Graphics image quality becomes even more important to workstation users in computer-aided design applications that depend on 3D graphics capability. Let’s take a closer look at 3D graphics, remembering that this discussion applies only to the pSeries 630, the pSeries 640, and the RS/6000 Models 150, 170, and 270.

Two hardware elements work together to generate computer graphics: the display (sometimes referred to as a “monitor”) and the graphics adapter (often calls a “graphics accelerator”). Most readers are familiar with displays used on their PCs and generally know that they come in different sizes and can display images with different degrees of resolution. They know, too, that the larger display and the higher its resolution capability, the more expensive it is likely to be.

The ability to display graphics at high performance (for rapidly moving images) and with a large range of colors depends even more on the graphics adapter. Graphics adapters are circuit boards that convert the bits and bytes inside the computer system to the electrical signals that are used by the display to create the image you see. The images Exploring IBM @serverSeries generated by the graphics adapters are made up of patterns of many individual dots on the display, called PELs or pixels, that blend together to form the desired image. This technique is depicted in Figure 1.36.

Each individual PEL on the display screen can be independently turned on or off by writing the appropriate bit pattern to its associated location within a special-purpose memory area on the graphics adapter called the frame buffer. The buffer determines the number of PELs that make up the image (or resolution of the image) seen on the surface of the computer's display. The more PELs represented in the frame buffer, the higher the resolution of the image (assuming the display can also support that resolution). The latest 3D graphics accelerators support resolutions up to 2048 by 1536 PELs.

The number of bits associated with a single PEL determines how many colors or how much brightness it can have. The graphics adapters for pSeries and RS/6000 systems support up to 24 bits per PEL

A buffer of a given size can be used to represent different numbers of PELs (that is, different resolutions) with different numbers of bits per PEL (that is, different numbers of maximum colors) under the control of the graphics software. Some graphics accelerators have two full-frame buffers. This allows one frame buffer to be displayed while the second is updated by the application program. When it is time to display the updated image, the second frame buffer is displayed, allowing the first frame buffer to be updated, and so on. The result of this dual-frame-buffer technique is a smoother transition from one image to another. Because screens are not being displayed at the same time as they are being updated, no transitional layer is displayed, improving overall image quality. This is especially useful for applications that operate animation.

Some other bits associated with each PEL should be mentioned. The overlay frame is a separate part of the buffer used to quickly overwrite portions of the display screen. If the overlay frame is empty, the image in the normal part of the graphics memory will be displayed in its entirety. If an image (such as some text or a pop-up window) is written to the overlay frame, it takes precedence over what is in the normal part of the frame buffer and is displayed on the screen. Once the overlay frame is reset, the original image is restored automatically. This allows an application program to quickly overwrite sections of the display screen and then restore the original image without having to re-create it. Multiple overlay frames mean that each PEL has multiple bits in the overlay frame, which allows the image to be overwritten using more colors.

## The Quiet Touch Keyboard

The pSeries systems use the IBM Quiet Touch Keyboard shown in Figure 1.38. This keyboard has the same layout as the keyboard used by IBM'S ASCII displays, the PC family, and the InfoWindow family of displays used with other IBM computer systems. This means that familiar with this layout, the user will not have to adapt to different keyboard layouts when using other IBM computer equipment. This same keyboard is available in different languages to fill the needs of many different users around the world. The keyboard cable plugs into the pSeries systems. Small retractable legs on the bottom of the keyboard can be extended to change the angle of the keyboard if desired.
