When a 3D object is generated, moved, or otherwise manipulated on the display screen, many complex (floating-point) calculations must be performed. The speed at which these calculations can be performed determines how quickly and smoothly the object appearing on the screen can be rotated, moved, enlarged, reduced, and so on. Performance limitations in this area can paralyze a computer system and make it unsuitable for graphics-intensive applications such as computer-aided design and publishing.
