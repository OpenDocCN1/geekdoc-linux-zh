# pSeries 610 Models 6C1 and 6E1 Memory Expansion

The p610-6C1 and p610-6E1 use 200-pin 10-ns SDRAM DIMMs, which must be installed in pairs. There is one 16-position (8 DIMM pairs) memory card. The minimum memory configuration is 512 MB, consisting of two 256 MB DIMM pairs are available in two sizes: 512 MB (2 x 256 MB, #4120) and 1,024 MB (2 x 512 MB, #4121). The maximum memory is 8 GB, which is achieved with the installation of eight feature #4121 (16 DIMMs). Note that features #4120 and #4121 are also used in the p640-B80 and in RS/6000 Models 170 and 270.

# pSeries 615 Models 6C3 and 6E3 Memory Expansion

The p615-6C3 and p615-6E3 use 200-8-ns DDR (Double Data Rate) SDRAM DIMMs, which must be installed in quads in the eight DIMM slots on the system planar. The p615 supports Chipkill memory. Each memory feature is a quad, the maximum is two features. The minimum memory configuration is 1 GB, consisting of four 256 MB DIMMs. DIMM quads are available in four sizes: 1 GB (4 x 256 MB, #4446), 2 GB (4 x 512 MB, #4447), 4 GB (4 x 1,024 MB, #4448), and 8 GB (4 x 2,048 MB, #4449). The maximum memory is 16 GB, which is achieved with the installation of two feature #4449 (eight DIMMs).

# pSeries 630 Models 6C4 and 6E4 Memory Expansion

The p630-6C4 and p630-6E4 use 208-pin ns DDR SDRAM DIMMs, which are installed in quads in the eight DIMM slots on each processor card. The p630 supports Chipkill memory. Each memory feature is a quad, the maximum per processor card is two features. The minimum memory configuration is 1 GB, consisting of four 256 MB DIMMs. DIMM quads are available in four sizes: 1 GB (4 x 256 MB, #4451), 2 GB (4 x 512 MB, #4452), 4 GB (4 x 1,024 MB, #4453), and 8 GB (4 x 2,048 MB, #4454).
