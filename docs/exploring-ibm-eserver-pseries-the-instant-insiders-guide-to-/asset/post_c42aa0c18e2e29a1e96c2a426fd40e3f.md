## Asynchronous Communications Adapters

### 8-Port Asynchronous Adapter EIA-232/RS-422, PCI Bus (#2943)

The 8-Port Async Adapter allows for the attachment of eight asynchronous (async) devices, such as ASCII terminals and ASCII printers. All eight ports are software programmable to support EIA-232E or RS-422A protocols at 230 Kbps. Async devices can be attached via an EIA-232 cable up to 200 feet (61 meters) long, and the RS-422A interface supports cables up to 4,000 feet (1,200 meters) long. Some larger systems, such as the pSeries 660 Model 6M1, support up to 32 async adapters, so it is possible to configure support for more than 250 terminals.

### 128-Port Asynchronous Controller, PCI Bus (#2944)

An efficient way to connect large numbers of async terminals is with the 128-Port Asynchronous Controller (#2944). This subsystem provides attachment for a high concentration of asynchronous lines (up to 128) from a single bus slot, giving the ability to serve a large number of users of EIA-232 or RS-422 devices as terminals, printers, and monitors. Two 2.4 Mbps (megabits per second) link the adapter to a maximum of 16-Port Remote Async Nodes (RANs). Up to 4 RANs can be linked to each synchronous channel.

The most announced RANs provide 16 EIA-232 (#8137) or 16 RS-422 (#8138) ports, yielding a total of 128 ports in a maximum configuration. Existing RANs with feature numbers #8130, #8134, or #8136 can also be used with this adapter. If these RANs are connected to the synchronous channel, the data rate drops down to 1.2 Mbps. For the best results, keep the previous and new RANs on separate synchronous channels.

First, the 128-Port Async Adapter is installed in a pSeries PCI slot. it is then attached to one to eight Remote Async Node 16-Port Concentrator boxes, providing up to 128 async ports for ASCII terminals and printers. The concentrator boxes communicate with the 128-Port Controller using a synchronous protocol. This allows the concentrator boxes to be attached to the pSeries system either locally or over a communications link (e.g., a leased telephone line) using synchronous modems.

## LAN Communications Adapters

All pSeries systems can participate in Ethernet and Token-Ring local area networks. Although a Token-Ring adapter is still available, Token-Ring LAN is being phased out in favor of the industry-standard Ethernet technology. In fact, all the pSeries and R/6000 servers, except the p670 and p690 servers, have at least one integrated Ethernet controller. The new p615 has an integrated Gigabit Ethernet controller and 10/100 Mbps Ethernet port.

## Ethernet Adapters

All of these adapters allow a pSeries system to connect to an Ethernet Version 2 or IEEE 802.3 LAN. Ethernet networks initially transferred information at a rate of at least 10 Mbps using the CSA/CD protocol discussed earlier. This speed has increased to 100 Mbps and to gigabit (1,000 Mbps) capability in recent years. Two types of connection are now common—Category 5 (CAT-5) unshielded twisted-pair (UTP) and fiber. Older cards supported thick (50-ohm) or thin (RG-58A/U) coaxial, but now a faster Ethernet standard has emerged that allows rates of 100 Mbps and 1000 Mbps using Category 5 cabling. ### Gigabit SX Ethernet PCI Adapter (#2969)

The IBM Gigabit SX Ethernet PCI Adapter (#2969) provides a 1 Gbps full-duplex Ethernet connection using a 1000 Base-SX fiber connection to an Ethernet switch. This adapter provides full 64-bit operation and requires a 64-bit PCI slot in the host pSeries server. The adapter is supported by both AIX 5L, v5.1 and v5.2, and AIX v4.3. When used this adapter offers a function called 'large send' in which the resegmentation of TCP transmissions is off-loaded to the adapter, enhancing throughput and reducing processing load on the host server.
