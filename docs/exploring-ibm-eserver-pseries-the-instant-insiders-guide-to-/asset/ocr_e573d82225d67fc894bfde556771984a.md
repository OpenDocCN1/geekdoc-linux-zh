# IBM TotalStorage 2-inch Tape Libraries

# IBM TotalStorage Enterprise Tape System 3590

Although the new LTO Ultrium tape technology offers many advantages for pSeries systems, IBM continues to offer 2-inch tape automation systems. IBM introduced this technology in its mainframe products in the 1980s, and it has become a mainstay for many businesses. The TotalStorage Enterprise Tape System 3590 (formerly known as the 3590 Magstar Tape Subsystem) in Figure 2 provides high levels of performance and capacity. It uses a 16-track serpentine longitudinal recording technique with improved compaction technology. It uses a 1-cartridge Automatic Cartridge Facility (ACF), with each cartridge providing capacity for 40 GB of uncompressed data. This data can be tripled with compression, for a total capacity of 1.2 TB in the Model E11, and can be mounted in a pSeries rack. The Model E1A is used within a 3594-B10/B20 Tape Library (discussed next) for even greater capacity. The 3590 has an uncompressed data transfer rate of 14 Mbps, making it the fastest tape drive available for pSeries systems. The 3590 can be simultaneously attached to multiple systems, including iSeries, pSeries, HP, NT, SGI, Cray, and Sun using a SCSI-2 differential fast/wide interface.
