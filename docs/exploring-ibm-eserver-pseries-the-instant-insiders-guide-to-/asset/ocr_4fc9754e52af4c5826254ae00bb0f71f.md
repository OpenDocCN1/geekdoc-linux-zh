In addition to the expandability of the p60 server itself and the ability to configure it into logical partitions, each running an independent copy of the operating system, the rack-mount p60-6C4 is supported, along with other pSeries servers, in massively Cluster 1600 systems. Up to 32 Model c64 SMP servers can be clustered. Or, p60 LPARs can be managed in a Cluster 1600 system, which can support a total of 128 operating system images, whether servers or LPARs.

The power and configuration flexibility of the p60 are supported by the same broad range of RAS capabilities as high-end pSeries servers. Functions such as First Failure Data Capture, predictive failure analysis, ECC protection on memory and caches, Chipkill memory correction, Dynamic Processor Deallocation, PCI slot deallocation, and hotplug components—to name a few—provide high availability and make the p60 easy to service when necessary.

The p60 is supported by AIX 5L v5.1 and v5.2 and by SuSE SLE 8. IBM pSeries offers Express Configurations for AIX 5L and Linux Ready Express Configurations. These are fixed configurations that include all the specified components without substitutions, but to which other features may be added—such as additional memory, disk drives, and I/O adapters. The Linux Express Configurations do not include an AIX 5L license or IBM Software Maintenance for AIX; customers must purchase Linux and the associated support from a Linux distributor.

To sum up, the p60 is an extremely versatile system. Standing alone, it provides the high performance, flexible configuration and physical packaging choices, and extensive growth of I/O and storage required by small and mid-size businesses. When used in clusters, the p60-6C4 or LPARs of the p60-6C4 can function as a powerful, compact processing node designed for applications to take advantage of parallel computation.
