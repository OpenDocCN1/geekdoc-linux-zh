# SSA Adapters

Unlike SCSI adapters, there have been several earlier Serial System Architecture (SSA) adapters for RS/6000 and pSeries servers, some of which are supported on current pSeries models. However, the only available adapter for attaching SCSI disk drives to pSeries servers is the Advanced SerialRAID Plus SSA Adapter (#6230), which offers the most current level of SSA attachment capability.

# Advanced SerialRAID Plus SSA Adapter (#6230)

This RAID adapter supports up to two loops of 48 devices (a total of 96 disks, with an instantaneous data transfer rate of 160 Mbps per loop. The adapter can be configured for several modes of operation.
In 8-way or eight-initiator-RAID mode, up to eight adapters can operate on the same loops of disks, allowing multiple server hosts to share loops of SSA disks. The adapter allows 2-way or two-initiator RAID 1 (mirroring), RAID 0+1 (striping with mirroring), and RAID 5 (striping with distributed parity) modes, as well as single-initiator RAID 0 operation. This adapter provides the necessary functionality for shared data access and high-availability configurations. The adapter supports hot spares in RAID 5 and RAID 0+1 configurations, as well as system boot from a non-RAID SSA disk.
