The Model 270 is designed to allow on-line diagnostics, or the abil-
ity to investigate malfunctions without interrupting end-user operation.
It also has an auto-restart option that, if enabled, will allow the system
to automatically rebooting an unrecoverable software error, a
software hang, or a hardware failure.

Since it is up to 4-way SMP system, the Model 270 also offers
Dynamic Processor Deallocation, an IBM innovation involving both
t hardware design and the AIX 5L operating system. With Dynamic
Processor Deallocation, the processors are constantly monitored for
errors. If the error reaches a threshold that indicates a likely failure,
workload for the potentially failing processor is automatically reassigned
to the remaining processors and the bad processor is taken off.
Even this system performance will be slightly lower with one less
processor, this feature helps avoid a possible system outage and allows
t failing processor to be serviced at a planned future time. This capita-
bility is active only in systems with two or more processors.
