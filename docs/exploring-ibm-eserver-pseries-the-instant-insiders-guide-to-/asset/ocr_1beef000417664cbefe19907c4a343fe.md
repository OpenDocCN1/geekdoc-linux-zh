Using up to 16.7 million colors in a single image is called true color and results in extremely lifelike images.

A buffer of a given size can be used to represent different numbers of PELs (that is, different resolutions) with different numbers of bits per PEL (that is, different numbers of maximum colors) under the control of the graphics software. Some graphics accelerators have two full-frame buffers. This allows one frame buffer to be displayed while the second is updated by the application program. When it is time to display the updated image, the second frame buffer is displayed, allowing the first frame buffer to be updated, and so on. The result of this dual-frame-buffer technique is a smoother transition from one image to another. Because screens are not being displayed at the same time as they are being updated, no transitional layer is displayed, improving overall image quality. This is especially useful for applications that operate animation.

Some other bits associated with each PEL should be mentioned. The overlay frame is a separate part of the buffer used to quickly overwrite portions of the display screen. If the overlay frame is empty, the image in the normal part of the graphics memory will be displayed in its entirety. If an image (such as some text or a pop-up window) is written to the overlay frame, it takes precedence over what is in the normal part of the frame buffer and is displayed on the screen. Once the overlay frame is reset, the original image is restored automatically. This allows an application program to quickly overwrite sections of the display screen and then restore the original image without having to re-create it. Multiple overlay frames mean that each PEL has multiple bits in the overlay frame, which allows the image to be overwritten using more colors.

The 3D graphics adapters used with pSeries and RS/6000 workstations are specially designed to generate and manipulate multidimensional images. In 3D adapters, the area in graphics memory used in the generation of three-dimensional graphics is called the Z-buffer. Although not actually part of the frame buffer itself, the Z-buffer is a special purpose memory area that is used for hidden-line and hidden-surface removal.
