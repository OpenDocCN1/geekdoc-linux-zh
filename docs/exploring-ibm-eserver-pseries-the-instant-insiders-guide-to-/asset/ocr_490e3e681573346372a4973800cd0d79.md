A single PSeries system might run one application program at a time, or it might run many application programs simultaneously.

The arrows in the figure indicate how users “see” the computer system. The user usually interacts with the application program layer and (less frequently) the operating system layer. By working closely with the other software layers, the application program processes the various keystrokes by the user and responds information on the computer’s display or some other output device.

As we will later in the chapter, many programs for other computers run UNIX operating systems (i.e., open systems) can be migrated to the PSeries and the AIX5 operating system by the software developer. This allows PSeries users to capitalize on many applications originally developed for other systems. There is an application program to help users with just about anything they wish to do. Examples of common functions that application programs provide include e-business (Web serving, secure on-line shopping, customer support, etc.), accounting, statistical analysis, database, banking, telecommunications, and computer-aided design.

The application software layer is more familiar to the user because it provides a business function and is the layer with which he or she interfaces. However, the operating system and device driver layers are equally vital, they provide the framework or “infrastructure” that controls the hardware (PSeries system and attached I/O devices) and allow many independent applications to execute. The interactions between the application and operating system layers, as well as between the operating system and device driver layers, are very complex. Although it is important for programmers and administrators to understand these layers in detail, it is sufficient for most readers to think of the operating system and device drivers as a single entity that supports application software on one side and system hardware on the other. The next two sections give a high-level description of the specific roles of the operating system and device driver layers.
