"Availability" is a term used to describe the degree of access a computer user has to a computing resource. For example, an environment in which the users are frequently prevented from logging on to a computer system because of computer system failures, communications network failures, scheduled maintenance, or any other reason is said to have poor availability. An environment in which the needed computing resources seem always to be available the users is said to have very good availability.

Now let's consider a LAN environment in which we have one server and a group of client computers/users that rely heavily on the server. These clients might be workstations or a network computer that cannot perform any useful work without the server's help, or might be workstations that frequently need the server's help to do useful work. If the server has a hardware or software failure, the server goes down. When the server goes, the users immediately and unexpectedly unable to do useful work until the server is fixed.

The degree of pain felt when a group of users is interrupted widely from one environment to another. If the users are simply doing word processing, being down for four hours might not be a problem, because the letters can go out in tomorrow's mail rather than today's. However, if the LAN is supporting the front desk of a large resort hotel, for four hours of downtime mean hours of delay for check-ins, check-outs, reservations, wake-calls, and room service—and a hotel full of angry guests. When you are selecting and configuring servers in a LAN, you must consider the availability requirements of the environment.

Many things have been done in the design of both hardware and the AIX operating system to maximize the reliability and availability of pSeries systems. Still, computer systems fail, and it is difficult to predict exactly when the failure will occur—and, of course, there is always the risk of software errors in the applications being run that could cause system outages. If failures are critical to the particular business being served, steps should be taken to increase the availability of computer resources. There are two basic techniques or approaches to increasing the availability of LAN resources: Rely on a specially designed fault-tolerant computer that has redundant hardware elements, or make the resource available from more than one computer in the LAN.
