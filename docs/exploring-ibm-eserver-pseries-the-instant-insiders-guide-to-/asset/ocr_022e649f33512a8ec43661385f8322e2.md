# Asynchronous Communications Adapters

# 8-Port Asynchronous Adapter EIA-232/RS-422, PCI Bus (#2943)

The 8-Port Async Adapter allows for the attachment of eight asynchronous (async) devices, such as ASCII terminals and ASCII printers. All eight ports are software programmable to support EIA-232E or RS-422A protocols at 230 Kbps. Async devices can be attached via an EIA-232 cable up to 200 feet (61 meters) long, and the RS-422A interface supports cables up to 4,000 feet (1,200 meters) long. Some larger systems, such as the pSeries 660 Model 6M1, support up to 32 async adapters, so it is possible to configure support for more 250 terminals.

# 128-Port Asynchronous Controller, PCI Bus (#2944)

A efficient way to connect large numbers of async terminals is with the 128-Port Asynchronous Controller (#2944). This subsystem provides attachment for a high concentration of asynchronous lines (up to 128) from a single bus slot, giving the ability to serve a large number of users of EIA-232 or RS-422 devices as terminals, printers, and monitors. Two 2.4 Mbps (megabits per second) link the adapter to a maximum of 16-Port Remote Async Nodes (RANs). Up to 4 RANs can be linked to each synchronous channel.

The most announced RANs provide 16 EIA-232 (#8137) or 16 RS-422 (#8138) ports, yielding a total of 128 ports in a maximum configuration. Existing RANs with feature numbers #8130, #8134, or #8136 can also be used with this adapter. If these RANs are connected to the synchronous channel, the data rate drops down to 1.2 Mbps. For the best results, keep the previous and new RANs on separate synchronous channels.
