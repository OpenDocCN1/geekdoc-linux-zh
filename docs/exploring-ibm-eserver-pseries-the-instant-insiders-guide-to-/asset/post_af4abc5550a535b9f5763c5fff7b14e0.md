## p650 Memory Expansion

The p650 uses 208-8ns SDRAM DIMMs, which are installed in quads of eight DIMM slots on each processor card. The p650 supports Chipkill. Each memory feature is a quad, the maximum per processor is two features. The minimum configuration is 2 GB, consisting of four 512 MB DIMM quads are available in three sizes: 2 GB (4 x 512 MB, #4452), 4 GB (4 x 1,024 MB, #4453), and 8 GB (4 x 2,048 MB, #4454). The maximum memory for systems with one processor card (2-way p650s) is 16 GB, which is achieved with the installation of two feature #4454 (8 DIMMs), while 2-, 4-, and 8-way p650s can accommodate 32 GB, 48 GB, and 64 GB, respectively, using two feature #4454 on each processor card. Note that these memory features are also used on the p630 system.

## p655 Memory Expansion

The p655 uses memory cards that plug into four system planar. Memory feature sizes of 4 GB (#4456) and 8 GB (#4457) are available with both POWER4 and POWER+, MCMs, and a 16 GB memory feature (#4458) is available with POWER+ MCMs only. The maximum standard memory capacity available is 32 GB, using four 8 GB memory cards (feature #4457) on 1.1 GHz and 1.3 GHz POWER4 systems or two 16 GB cards (feature #4458) on 1.5 GHz and 1.7 GHz POWER+ systems. By special request, up to four of the 16 GB memory cards can be supported on selected p655 systems with POWER4+ processors.

## pSeries 660 Model 6M1 Memory Expansion

Memory for the p660-6M1 is installed as one or two memory boards, with each 32 DIMM slots. The feature number for this board is #4073. The machine must be populated with at least 2,048 MB (2 GB) of memory with a maximum of 64 GB, 32 GB on each of two boards. The memory modules are ECC 10-ns 200-pin SDRAM DIMMs.

Memory is installed in groups of eight DIMMs (octals). All DIMMs in a particular octal must be of the same capacity, but different octals can have different capacity DIMMs. A minimum of eight DIMMs must be installed on each memory board.

p660-6M1 memory is accessed via two related but distinct ports. Balancing memory across two memory boards allows memory accesses in a coordinated parallel fashion and can be utilized to obtain optimal performance. Configurations containing a single memory board will function properly, but the memory will only be accessed through one port and will not use of the full memory bandwidth. Plans for future upgrades should be taken into account to obtain optimal performance without limiting future memory expansion—in other words, it is preferable to install fewer of the larger DIMMs than more of the smaller ones. Memory features for the p660-6M1, except features #4110 and #4133, support Chipkill memory technology.

The DIMM features are as follows:

- 1,024 MB memory (8 × 128 MB DIMMs) (#4133)
- 2,048 MB memory (8 × 256 MB DIMMs) (#4134)
- 4,096 MB memory (8 × 512 MB DIMMs) (#4135)
- 8,192 MB memory (8 × 1,024 MB DIMMs) (#4136)

For model conversions from p660-6H1 only, the following features may be ordered only in sufficient quantity to complete the required octal when combined with like-capacity memory DIMMs being migrated:

- 256 MB memory (2 × 128 MB DIMMs) (#4110)
- 512 MB memory (2 × 256 MB DIMMs) (#4119)
- 1,024 MB memory (2 × 512 MB DIMMs) (#4100)
- 2,048 MB memory (2 × 1,024 MB DIMMs) (#4137)

## pSeries 670 and pSeries 690 Memory Expansion

The pSeries 670 and pSeries 690 use the same memory packaging, although p690 supports features that are not available on p670. Both systems use Chipkill for high reliability. Minimum memory capacity on a p670 is 4 GB and on p690 is 8 GB. The p670 maximum is 256 GB, and p690 maximum is 512 GB. The p670 and p690 are complex systems, and the rules for populating memory are more involved than other pSeries servers.

As described in Chapter 1, the pSeries 690 can have one to four MCMs (Memory Modules). Each MCM has two memory slots, so there is a maximum of eight memory slots per system. The packaging requires that four of these use “inward-facing” memory cards, and four “outward-facing” memory cards. Hence, there are two feature numbers for each memory card used in p690:

- 4 GB memory card, inward facing (#4196)
- 4 GB memory card, outward facing (#4197)
- 4 GB memory card, 567 MHz, inward facing (#4480) (POWER4+ only)
- 4 GB memory card, 567 MHz, outward facing (#4481) (POWER4+ only)
- 8 GB memory card, inward facing (#4181)
- 8 GB memory card, outward facing (#4182)
- 8 GB memory card, 567 MHz, inward facing (#4482) (POWER4+ only)
- 8 GB memory card, 567 MHz, outward facing (#4483) (POWER4+ only)
- 16 GB memory card, 567 MHz, inward facing (#4484)
- 16 GB memory card, 567 MHz, outward facing (#4485)
- 32 GB memory card, 567 MHz, inward facing (#4486)
- 32 GB memory card, 567 MHz, outward facing (#4487)
- 64 GB memory card, 567 MHz, inward facing (#4488)
- 64 GB memory card, 567 MHz, outward facing (#4489)

Note that high-speed (567 MHz) and older (500 MHz) memory cards are available in the capacities of 4 GB and 8 GB. Memories of both speed can coexist in a system, but all memory will run at the lower 500 MHz rate. 567 MHz memory must be used with 1.7 GHz POWER4+ MCMs. If the lower speed memory is used, it will seriously degrade the performance of processor technology.

The p670 has only two MCM locations, each with two memory slots, so it has only four memory slots per system. The p670 requires only the inward-facing memory features. The memory feature numbers for p670 are as follows:

- 4 GB memory card, inward facing (#4196)
- 8 GB memory card, inward facing (#4181)
- 16 GB memory card, 567 MHz, inward facing (#4484)
- 32 GB memory card, 567 MHz, inward facing (#4486)
- 64 GB memory card, 567 MHz, inward facing (#4488)

Memory must be installed in identical pairs, and memory card sizes should be balanced as closely as possible (identical is best) across all populated MCM locations. The reasons are that each memory slot is used by certain processors on each MCM and the p670 and p690 use memory in a round-robin fashion across the four memory controllers on an MCM, referred to as “memory interleaving.” If memory were not installed in pairs, then all the memory traffic would be routed through only half the control circuitry available on the MCM, thus reducing the available bandwidth from processors through L3 cache to memory and affecting system-level performance.

IBM provides detailed memory configuration rules in its on-line manual. Of course, servers of the power and complexity of the pSeries 670 and p690 require careful planning by competent technical personnel to ensure that the configuration, including the memory subsystem, is designed optimally for the intended applications workloads. A good reference available on the IBM Web site is a white paper entitled “IBM eServer pSeries 690, Configuring for Performance.” In addition to configuring memory for optimum performance, this paper also discusses how to best configure the I/O subsystem. The companion Web site (www.maxpress.com) for this book has a link to IBM information such as this paper.
