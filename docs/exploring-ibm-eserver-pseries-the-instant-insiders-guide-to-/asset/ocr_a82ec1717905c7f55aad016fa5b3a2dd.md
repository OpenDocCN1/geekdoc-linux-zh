Next is the bisync (short for Binary Synchronous Communications, or BSC). The “synchronous” means that a special character preceding the information synchronizes the receiver with the incoming information. This synchronization allows many bytes of information to be sent as a single block, in contrast to the asynchronous protocol, in which transmission occurs one by a time. The ability to send blocks of characters makes bisync more efficient than the asynchronous protocol. Bisync is an older protocol used by various kinds of equipment and different computers, including IBM's System 360 and 370 mainframes. As a result of its popularity, many of today's systems use bisync.

The Synchronous Data Link Control is basically an updated version of bisync. As with bisync, SDLC is a synchronous protocol. However, SDLC is a more flexible protocol that is part of IBM's Systems Network Architecture (SNA), which is a set of communications standards published by IBM that was used for many years as a road map to ensure compatible communications are provided for current and future computer systems and software.
