The Bonus Pack contains both ready-to-use evaluation software packages. Over time, IBM plans to phase out the Bonus Pack on CD-ROM and provide these programs for users via the Web Download Pack. At this time, the following are some of the Bonus Pack contents:

+   * Adobe Reader 5.06
* AIX Developer Kit, Java 2 Technology Edition, Version 1.3.1, both 32-bit and 64-bit versions
* AIX Fast Connect V3.1.2, Evaluation Software
* Geodesic Systems Great Circle Version 6.0.1.5, Evaluation Software
* Modular I/O Library V2.3

The contents of the AIX 5L Expansion Pack are primarily security and encryption tools.
