# Trial Capacity on Demand

The last innovative “on demand” function available on p690, p670, and p650 systems is Trial CoD. Trial CoD is a no-charge function provided to customers who either processor or memory CuOD features. They allow them a one-time opportunity to activate all or part of their standby resources (processors or memory) for a period of 30 consecutive days. Use of Trial CoD might be for a company to activate standby resources in order to evaluate the effect on system operations. Another situation could be when immediate activation of resources to meet rapidly increasing workload demands is needed, but it will take a few days to process a purchase order for a permanent CuOD activation feature.

If processor and memory CuOD features are installed, the trial opportunities for processors and memory may be executed independently. There is no need to get an activation code or key from IBM for Trial CoD. System firmware allows one processor when memory CuOD is installed for the first time. In the case of processor CuOD, a new trial opportunity is enabled when a permanent CuOD activation feature is installed. For memory CuOD, the trial opportunity is one time system.

# Reliability, Availability, and Serviceability (RAS)

In addition to the POWER4 processor architecture and logical partitioning, the third major innovation in the pSeries 690 design is the intent of the RAS capabilities provided. The p690 offers all the advanced self-managing features available in other pSeries servers—hot-swappable disk drives, hot-plug PCI slots, Chipkill memory, bit-steering memory redundancy, Dynamic Processor Deallocation, persistent memory deallocation, redundant hot-plug power and cooling, and a built-in service processor. In addition, it offers:

+   - Deallocation of memory, L2 and L3 caches, and PCI buses

+   - Optional redundant battery backup units

+   - “Blind-swap” PCI slots (allowing adapters to be hot-plugged without moving the I/O drawer to a service position)

+   - PCI bus parity error recovery
