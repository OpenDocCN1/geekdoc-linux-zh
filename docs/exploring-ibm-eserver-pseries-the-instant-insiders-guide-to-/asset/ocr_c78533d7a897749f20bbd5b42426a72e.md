# AIX 5L Development Tools

With the AIX 5L operating system, several development tools are avail-able to you. AIX 5L comes with the "vi" full-screen editor and tools to support the development and maintenance of custom application pro-grams. These include traditional UNIX commands and utilities such as the Make command, used to easily rebuild complex systems of pro-grams after changes have been made. Another UNIX oper-ating system function supported by AIX 5L is the Source Control System, which provides a mechanism to record and control when, why, and by whom changes are made to the source of a program during development. Subroutine libraries provided include libc.a, the enhanced floating-point math library, the 4.3 BSD compatibility library, and a DCE compatibility library.

AIX 5L also provides a type of programming structure for automat-ing a series of operating system commands, called "shell scripts." Shell scripts can be used to issue a single operating system command or to define a complex series of operating system commands with menus and initiate other application programs.
