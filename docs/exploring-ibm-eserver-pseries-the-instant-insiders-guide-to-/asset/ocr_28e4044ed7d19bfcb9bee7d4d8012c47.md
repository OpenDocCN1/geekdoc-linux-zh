A shared network printer, such as the IBM Bformat 1140, which
print about 40 pages per minute, will be managed by the p630-E64
and will be available to all employees. An auteed color plotter (e.g.,
Tektron) will be used by the Art Department for high-quality image
copies. A desirable plotter would be one that can create eight-color draw-
ings and text on A- or B-sized paper or transparencies. The automatic
sheet feed will allow the plotter to print multiple drawings unattended.

The pSeries 630 will be used as a database, file, and printing server
by all PC users on the network. The DB2 UDB Workgroup database
will be the central repository for demographic information, which
needed by many PC users performing market research, and for the graph-
ics to be shared by users in the Art Department. The relational data-
base application, such as DB2 UDB, allows files of various kinds to be
indexed with multiple keywords so that users can search and sort in-ormation. As a file server, the p630-E64 in effect becomes a giant PC disk
shared by all PCs. As a print server, it will allow all PC users to
document on either the IBM Network Printer or the plotter just if
these devices were attached to their PCs. These files will be stored in
Windows or Mac format on the pSeries disk so that the PC users can
use the data with the application programs they currently use. The file
and printing servers will be provided by AI Connections in
TheAIX 5L operating system.
