# Desktop User Interface

AIX 5L includes the industry-standard graphical user interface called the Common Desktop Environment. This is a Motif-based user interface on the joint development efforts of IBM, Hewlett-Packard, Sunsoft, and others. CDE is an easier to use, iconic interface for the graphics system user. It includes productivity tools such as a calendar system, e-mail, and an editor, clock, file manager, icon painter, and trash can. In addition, AIX 5L includes the GNOME and KDE desktop environments familiar to Linux users.
