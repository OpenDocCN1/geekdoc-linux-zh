# IBM eServer Cluster 1600

The IBM eServer Cluster 1600 was announced in November 2001 to bring together into a single system identified by one serial number all the elements of UNIX nodes, including RS/6000 SP nodes, although SP nodes are no longer available for purchase. Long leader in UNIX cluster technology, IBM now offers cluster software products—IBM Parallel System Support Programs for AIX, IBM Cluster Systems Management for AIX 5L, and the General File System (GPFS)—and its SP Switch2 high-speed interconnect technology as building blocks for configuring large UNIX clusters using the latest pSeries servers. Even though the hardware packaging of these servers (except for the pSeries 635) differs from the form factor of the older RS/6000 SP nodes, the architecture based on a single point of control using PSSP is unchanged. The SP Switch2, available in a standalone frame, provides a high-speed, low-latency, point-to-point connection to make distributed applications more efficient. The supported interconnection options for Cluster 1600 are the following:

+   - Ethernet LAN (gigabit or 10/100 Mbps)
