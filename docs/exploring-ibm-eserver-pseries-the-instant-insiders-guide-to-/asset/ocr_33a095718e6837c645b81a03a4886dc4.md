# pSeries Hardware Architecture

The internal organization of the hardware elements composing a pSeries system is known as the system's hardware architecture. The architecture of pSeries computers contributes a great deal to the performance offered by these systems. The architectures of pSeries servers are enhanced versions of the Reduced Instruction Set Computing architecture originally developed by IBM in the 1970s. As the name RISC implies, the instruction set or total number of instructions that can be executed within the computer is reduced compared with more traditional Complex Instruction Set Computing (CISC). Because the instructions in RISC systems are very simple, they can be executed using high-speed computer hardware within a very short period of time (for example, one clock cycle). Further, the simple instruction set of a RISC computer typically can be carefully employed to perform even complex functions in a more efficient manner.

This original RISC architecture was first used in the IBM RT system, which had limited success. The RS/6000 family employed IBM's second-generation RISC architecture, called the Performance Optimized With Enhanced RISC architecture. This architecture used a blend of the original RISC architecture and some traditional CISC concepts with an emphasis on doing multiple operations at the same time.
