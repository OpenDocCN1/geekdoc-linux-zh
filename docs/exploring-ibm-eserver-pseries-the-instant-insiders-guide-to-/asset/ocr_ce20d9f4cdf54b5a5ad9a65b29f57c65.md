The pSeries uses several techniques to protect the integrity of its main memory. The ECC technique used in the pSeries family can detect single-bit and double-bit errors and correct single-bit errors. This is done by appending several bits (called ECC bits) onto every word (32 bits) in main memory. The seven ECC bits are automatically generated by the ECC circuitry based on the value of the associated word and are stored in main memory alongside it. New ECC bits are calculated and stored every time a word is written to main memory. Later, when a word is read back from main memory, the value stored in the corresponding ECC bits is checked to make sure the word didn't somehow get corrupted through some type of main memory failure. The most common type of failure is to have a single bit in the word accidentally changed to the wrong value. In this case, the ECC circuitry can use the value stored in the ECC bits to correct the error on the fly and allow normal operations to continue undisturbed. On rare occasions, a main memory failure will cause two bits in a single word to be changed. In this case, the ECC circuitry can only detect and report the error. In addition to monitoring all activity in main memory, the ECC circuitry periodically scans all of main memory to ensure the integrity of the information, a process called memory scrubbing or scrubbing. The pSeries main memory also employs others techniques to ensure the integrity of the system: bit scattering, memory bus parity, and steering.

Bit scattering means that memory chips used to make up the memory system are organized in a way that minimizes the impact of a single chip failure. Memory bus parity refers to an extra bit appended to the parallel group of wires (called a bus) to transfer information to and from main memory. This extra bit, called parity bit, is used to detect any errors that may occur as the information is transferred along the memory bus. In fact, parity bits are used on chip-to-chip data buses and throughout internal chip data paths. Finally, bit steering is a concept in which extra memory bits designed into the main memory system can be used to replace failing bits, in many cases without disrupting normal operation. The extra bit is “steered” onto the memory bus in place of the failing bit. All of these things help protect the integrity of the information in a pSeries system and allow it to recover from errors without disturbing users.
