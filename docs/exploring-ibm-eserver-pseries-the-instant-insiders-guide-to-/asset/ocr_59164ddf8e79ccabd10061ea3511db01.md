# p650 Memory Expansion

The p650 uses 208-8ns SDRAM DIMMs, which are installed in quads of eight DIMM slots on each processor card. The p650 supports Chipkill. Each memory feature is a quad, the maximum per processor is two features. The minimum configuration is 2 GB, consisting of four 512 MB DIMM quads are available in three sizes: 2 GB (4 x 512 MB, #4452), 4 GB (4 x 1,024 MB, #4453), and 8 GB (4 x 2,048 MB, #4454). The maximum memory for systems with one processor card (2-way p650s) is 16 GB, which is achieved with the installation of two feature #4454 (8 DIMMs), while 2-, 4-, and 8-way p650s can accommodate 32 GB, 48 GB, and 64 GB, respectively, using two feature #4454 on each processor card. Note that these memory features are also used on the p630 system.

# p655 Memory Expansion

The p655 uses memory cards that plug into four system planar. Memory feature sizes of 4 GB (#4456) and 8 GB (#4457) are available with both POWER4 and POWER+, MCMs, and a 16 GB memory feature (#4458) is available with POWER+ MCMs only. The maximum standard memory capacity available is 32 GB, using four 8 GB memory cards (feature #4457) on 1.1 GHz and 1.3 GHz POWER4 systems or two 16 GB cards (feature #4458) on 1.5 GHz and 1.7 GHz POWER+ systems.
