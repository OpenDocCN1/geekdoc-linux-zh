Overall, the 7133 provides excellent reliability, performance, price/performance, capacity, and ease of use. It should be considered in any environment where moderate to large amounts of high-performance disks are required. The 7133's high number of I/O operations per second adapter also make it ideal for transaction processing environments in which a large number of requests are made for small blocks of data.

# 7204 External Disk Drive

Figure 2.2 shows an IBM 7204 External Disk Drive, which can be used with all models using either a single-ended Ultra-SCSI, Ultra2-SCSI Diffential (low voltage differential) or LVD/DE adapter. Unlike the external disk systems previously described, the 7204 provides a single 18.2 GB or 36.4 GB disk drive attached to a SCSI I/O controller via a cable. For environments with stringent data requirements, the 7204 unit can be detached from the pSeries system and from its electrical socket nightly to allow storage in a vault. The drives are shock-mounted to help prevent damage as they are moved about.
