Chances are, not every problem you will uncover with a computer solution. For example, an inventory management application program will not solve inventory problems in a business if unauthorized people can walk into the storeroom and get what they need. Computers and application programs are simple tools that can be used to effectively manage an organi-zation. People, not computer systems, manage organizations.

After the current operation has been examined with a critical eye, it will become whether a computer solution makes sense for an or-ganization. In a small organization, this type of analysis can be done in a matter of weeks or even days. In larger organizations, it can span months or years and typically is done on ongoing basis. Some organizations choose to do the analysis on their own. For assistance in solving problems with computers, there are plenty of places to turn to, such as consultants, software companies, and computer manufacturers.

# Choosing the Software

Computer systems become a useful tool only when they are executing the appropriate application programs. There are many ways of generating a strategy for introducing computers, but considering software needs before selecting detailed hardware configurations usually makes sense. The hardware requirements, such as processor speed, memory size, disk space, and so on, will be based in part on the needs of the application program(s) selected.

The application programs selected must perform the tasks needed by the end users in a company—both today and in the foreseeable future. Chapter 3 has already discussed some basic types of application programs commonly used today. Selecting the best type of application program usually is fairly simple. For example, an accounting department needs an accounting application program, a secretary needs a wordprocessing application program, and an engineer needs a computer-aided design application program. What is more difficult the specific application program that fits a company’s needs. Is a custom application program preferred, or will a prewritten application program be acceptable? If a prewritten application program is desired, exactly which one is best? If a custom application program is desired, who should write it and what should it include?
