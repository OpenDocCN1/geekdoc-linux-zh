# Exploring IBM @server pSeries

The 4-way and 8-way configurations use one MCM, and 16-way systems have two MCMs. Each MCM includes 128 MB of L3 cache. Main memory begins at 4 GB and can be increased to 256 GB.
The p670 is packaged in a single 24-inch-wide 42U rack (Figure 1.18) which accommodates the p670 system unit, from one to three IBM 7040-61D I/O Drawers, a media drawer, and a 350-volt bulk power subsystem. In a minimum p670 configuration, the I/O drawer and media drawer include the following:

+   - Two 18.2 GB Ultra-SCSI disk drives
- Eight hot-swappable disk bays (two occupied by the base disk drives), expandable to 16 in a single I/O drawer
- Five media bays
- One planar with 10 hot-plug PCI-X slots (an optional second planar allows 20 slots in a single I/O drawer)
