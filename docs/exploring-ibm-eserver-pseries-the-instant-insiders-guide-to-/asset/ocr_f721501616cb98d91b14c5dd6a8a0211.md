# RS/6000 Model B50 Specifics

The last server in the entry category is the RS/6000 Model B50, a compact rack-mounted server that satisfies requirements for front-end Internet applications for high-density, small-footprint, and low-cost implementations for e-business opportunities. It is targeted principally for applications such as Web hosting, firewalls, directory services, e-commerce, caching, and messaging. Internet Service Providers and Application Providers are likely to be interested in this model, which is based on the same technology as the RS/6000 Model 150, but in a rack drawer.

Like the Model 150, the B50 is a 32-bit system using the 375 MHz PowerPC 604e microprocessor with 1 MB of L2 cache. The system configuration includes a minimum of 128 MB memory expandable to 1 GB, a diskette drive, a CD-ROM drive, an integrated Ultra-SCSI controller and 10/Ethernet. Two disk bays and thirty-two bit PCI slots are available as well as an external Ultra-SCSI port, two serial ports, a parallel port, and keyboard and mouse ports. The Model B50 system supports AIX 4.3.3 or AIX 5.

The Model B50 drawer is only 2U, or 3.5 inches, in height. Up to twenty B50 servers can be installed in a 19-inch IBM Model T42 rack. This space-saving design delivers more servers per square foot than before. The pricing is extremely aggressive, with a list price of less than $3,600 per fully featured unit.
