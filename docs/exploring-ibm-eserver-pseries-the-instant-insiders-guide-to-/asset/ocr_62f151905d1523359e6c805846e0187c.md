# Graphics Adapters

To support these displays, pSeries or RS/6000 system must be equipped with a graphics adapter (IBM terminology “accelerator”), which translates the information stored in the system into the electronic signals necessary to create images on the displays. These unfamiliar with computer-generated graphics terminology may want to refer to the section titled “Graphics” in Chapter 1 before reading about the graphics accelerator options.

For several reasons, pSeries systems except for p630 and p640 support only 2D graphics accelerators. in which case the systems administrator needs a native graphics interface and display for use as the system console. In addition, many pSeries servers are managed in server farms and are controlled over a LAN from a PC with a console. Finally, even pSeries systems that are used by one person often runs applications that require only 2D support, such as scientific and technical computing, complex financial analysis, or software development. All pSeries use GXT135P graphics accelerator.
