# RS/6000 Model 170 Specifics

The RS/6000 Model 170 is a powerful 64-bit uniprocessor system, offering a great range of price and performance for both server and workstation applications. This system is slightly larger than the Model 150, providing one PCI slot and one more disk drive bay, as well as offering a second integrated Ultra2-SCSI port for attachment of external devices. More important, its range of performance options is quite broad, with POWER3IB co-processor microprocessors running at 333 MHz (with 1 MB of L2 cache), 400 MHz (4 MB of L2 cache), or 450 MHz (8 MB of L2 cache). An upgrade to a more powerful processor is simple matter of changing the processor card. These processors are among the most powerful offered anywhere. Floatingpoint in particular is more than four times greater than the 450 MHz version of this system, compared to the 250 MHz processor on Model 150 (see Figure 1.1b). Beyond just the much faster processors, the 170 employs a faster memory bus matched to the speed of the processor. The bus speeds are 95 MHz and 100 MHz for the 333 MHz and 400 MHz versions respectively.

A minimal configuration of this model will have a 333 MHz processor with 256 MB of RAM, an 18.2 GB Ultra-SCSI disk drive, a CD-ROM drive, and a diskette. The motherboard has an integrated 10/100 Mbps. Ethernet controller, internal Ultra-SCSI and External Ultra2SI ports, a parallel port, two serial ports, and stereo audio. For input I/O and communication capability, the Model 170 has four 32-bit and two 64-bit PCI adapter slots. Three disk bays (beyond those used by the disk drive and CD-ROM drive) are available, bringing internal disk capacity to 293.6 GB. Memory is expandable to 2 GB. A service processor to help system availability is standard. The Model 170 supports all of the latest graphics adapters, from the entry GXT135P for entry 2D work 3D graphics accelerators such as the GXT4500P and GXT6500P.
