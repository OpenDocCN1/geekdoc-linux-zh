# 10/100 Mbps Ethernet PCI Adapter II (#4962)

The 100/100 Mbps Ethernet PCI Adapter II (#4962) is a small-factor, high-performance, low-power Ethernet adapter. Like the other #2968, it supports 10 Base-T attachment using either CAT-3 or CAT-5 unshielded twisted pair and 100 Base-TX using CAT-5 UTP. This adapter supports network boot and AIX Network Install Manager.

# IBM Gigabit Ethernet-SX PCI-X Adapter (#5700)

The Gigabit Ethernet-SX PCI-X Adapter (#5700) provides a full-duplex 1 Gbps Ethernet connection with the smaller, LC-type connector to standard hardware multimode fiber-optic cable. Depending on the cable, the adapter can support distances up to 550 meters. It supports NIM for boot capability. For optimum performance, this adapter should be placed in a PCI-X slot. It is supported on AIX 5L v5.1 and v5.2.

# IBM 10/100/1000 Base-TX Ethernet PCI-X Adapter (#5701)

The 10/100/1000 Base-TX Ethernet PCI-X Adapter (#5701) is the counterpart of #5700 for UTP interfaces up to 1 Gbps, rather than fiber. The UTP cable distance supported is up to 100 meters. This adapter also supports NIM and requires AIX 5l.1 or v5.2. For optimum performance, it should be placed in a PCI-X slot.

# IBM 2-Port 10/100/1000 Base-TX Ethernet PCI-X Adapter (#5706)

The 2-Port 10/100/1000 Base-TX Ethernet PCI-X Adapter (#5706) provides two full-duplex UTP connections to 10, 100, or 1,000 Mbps. Using 4-pair CAT-5 UTP cable, it can be attached to other devices or an Ethernet switch at distances up to 100 meters.
