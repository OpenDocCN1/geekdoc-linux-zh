Given these requirements and the design of the p630 electronics complex, it is possible to define up to four partitions on a p630-64E and to four LPARs on a p630-6C4 with a 7311-D20 I/O drawer. All four internal disks are attached to the same LPAR, so each LPAR beyond the first requires attachment to an external disk, whether in a 7311-D20 drawer or in a separate storage subsystem. LPAR operation is controlled from an IBM 7315-C02 HMC, which may be shared with other pSeries servers running LPAR. LPAR is described in greater detail in “A Closer Look” later in this chapter.
