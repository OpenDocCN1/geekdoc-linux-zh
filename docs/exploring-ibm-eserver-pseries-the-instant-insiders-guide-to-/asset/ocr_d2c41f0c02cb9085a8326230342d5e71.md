The 2 Gigabit Fibre Channel Adapter for the 64-bit PCI Bus (#6228) is, as the name suggests, a full 64-bit adapter capable of supporting Fibre Channel connections up to 2 Gbps. Depending on the cabling and the attached devices, the adapter autonegotiate for the higher data rate—either 1 Gbps or 2 Gbps. Distances from the adapter to the attached device or switch up to 500 meters running at 1 Gbps and to 300 meters running at 2 Gbps are supported. As for the Gigabit Fibre Channel Adapter (#6227), use of an IBM Fibre Channel Hub extends those distances to 10 km at either speed. To attach a device with an SC-type fiber connector, the LC-SC Fibre Channel Connection (#2456) is required.

The 2 Gigabit Fibre Channel PCI-X Adapter (#6239) autonegotiates for either the 1 Gbps or 2 Gbps data rate and supports the same fibre channel cabling options as #6228. This adapter is supported by AIX 5L v5.1 or v5.2, and it should be placed in a PCI-X slot in order to operate at optimum performance.

# Cryptographic Coprocessors

The pSeries servers offer several adapters that provide data encryption capability meeting industry standards for data security. These adapters are called coprocessors because they handle much of the processing by complex data encryption algorithms, off-loading that workload from the server and providing enhanced throughput and security. They are used for secure Internet transactions, such as secure data exchange, electronic signature verification, and bulk data encryption and verification.

The IBM e-business Cryptographic Accelerator (#4960) provides PCI Secure Socket Layer (SSL) hardware acceleration for secure Web transactions. Public-key cryptographic operations use the SSL handshake protocol to provide secure Web transactions, and this adapter is a hardware solution that provides data encryption over the PCI bus to the pSeries servers, thus, off-loading this computation-intensive workload from the server into it is installed and improving overall cryptographic performance.
