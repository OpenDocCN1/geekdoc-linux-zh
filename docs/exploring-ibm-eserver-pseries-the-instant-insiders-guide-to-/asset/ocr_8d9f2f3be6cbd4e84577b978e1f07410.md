# How To Use This Book

Chapter 1 first introduces the entire pSeries family and provides an-view of each chapter. The latter part of the chapter examines the-elements (architecture, graphics, auxiliary storage, etc.) that make up pSeries computers.

Chapter 2 surveys the many hardware options available for pSeries systems, including storage devices, communications adapters, and at-ached devices such as displays and printers. This information is pro-vided as a reference to inform you about the types of options that are available and to help you select the proper options for your pSeries computer. It should not be used as a comprehensive catalog of features available for any specific model. You should contact IBM or refer to their on-line product information (www.maxpress.com) available to you with this book has links to IBM Web sites for such information.

Chapter 3 discusses operating systems and some basic types of industry-specific application programs. The question of "prewritten" versus "custom" programs is addressed. The chapter contin-ues with discussion of operating systems. First, basic operating system concepts such as "multiuser" and "interactive processing" are defined in nontechnical terms. The AIX 5L™ operating system and its optional extension products are described, and a description of pSeries support for the increasingly popular Linux operating sys-tem is given.
