ESSL provides prewritten routines for such things as matrix operations, eigensystem analysis, interpolation, linear algebraic equations, Fourier transforms, convolutions and correlations, and others. This subroutine library is designed to accelerate program development by allowing the programmer to employ highly tuned, prewritten mathematical routines rather than write them from scratch.

Through the X development environment, AIWindows (discussed earlier in the chapter) provides a multivindow (on OSF/Motif) programming environment. This allows an application programmer to do such things as executing source code in one window and monitor the program in another. Alternately, programmers may be accessing X 5L on-line documentation in one window while writing a program in another, looking at both simultaneously. AIWindows also provides tools to ease the development of graphical user interfaces for programs—namely, the X Windows Graphics Support Library and Display PostScript for AIWindows products.

Support for three-dimensional (3D) graphics is provided by two components for use with IBM's UNIX workstations—OpenGL and GL 3.2, and PHIGS. The OpenGL and GL 3.2 component provides support for the popular Graphics Library developed by Silicon Graphics. The PHIGS component provides a set of subroutines for generating and manipulating images through the ANSI and ISO standard as the Programmer Hierarchical Interactive Graphics System (PHIGS). Programs specifically written to these APIs can usually be migrated to AIWindows with minimal programming efforts.

Although CASE methods were developed to address the needs of large application development projects, CASE concepts and tools can be employed for any size project.
