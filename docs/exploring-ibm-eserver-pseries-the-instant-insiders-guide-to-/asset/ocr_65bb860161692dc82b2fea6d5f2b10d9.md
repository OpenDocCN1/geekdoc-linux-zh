Figure 2.12 shows these elements work together. First, the 128-Port Async Adapter is installed in a pSeries PCI slot. it is then attached to one to eight Remote Async Node 16-Port Concentrator boxes, providing up to 128 async ports for ASCII terminals and printers. The concentrator boxes communicate with the 128-Port Controller using a synchronous protocol. This allows the concentrator boxes to be attached to the pSeries system either locally or over a communications link (e.g., a leased telephone line) using synchronous modems.
