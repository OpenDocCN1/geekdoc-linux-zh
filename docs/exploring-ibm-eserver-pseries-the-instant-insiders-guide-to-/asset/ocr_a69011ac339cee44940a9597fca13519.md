RAID 5 all stripes data, but it maintains parity data as well. RAID 5, data that might be lost because of a disk failure can be rebuilt using the parity data. RAID 5 will obviously cost more because of the extra disk space, but it provides a better balance between performance and data protection/availability. RAID 1, often called mirroring environments. Two or three separate copies of all data are kept on separate disk disks. In the event of a disk failure, AIX uses another copy of the data from a surviving disk. Although performance is higher than RAID 5, RAID 1 also requires the use of more disks. Options also exist to combine multiple RAID functions such as striping with mirroring (RAID 0+1) using hardware and/software. RAID 10, which combines striping (RAID 0) and mirroring (RAID 1), offers some performance advantages over mirroring by itself, but not all controllers provides RAID 10 mode of operation. AIX provides software implementations of striping or mirroring using host CPU processing. Hardware RAID adapters and external controller-based systems off-load the CPU processing and implement the RAID function in their microprocessors.

There are two ways to provide external storage with RAID capacity in pSeries systems. One method is to attach the 2104 Expandable Storage Plus and the 7133 Serial Disk System described in the previous section using a RAID controller, as the PCI Ultra2-SCSI Ultra3-SCSI RAID adapters or the SSA multi-initiator/RAID adapter. The electronics to control the RAID functions are on the adapter, not in the external disk system. The other alternative is to attach an external system that incorporates RAID technology within the unit itself and is attached to the pSeries system by a non-RAID adapter. Several disk systems with integrated RAID capability are available from IBM.
