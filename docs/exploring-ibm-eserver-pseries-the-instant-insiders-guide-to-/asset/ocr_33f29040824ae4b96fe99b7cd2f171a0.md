# pSeries 640 Model B80 and RS/6000
Model 270 Memory Expansion

The p640 and the Model 270 use pairs of 200-pin 10-ns SDRAM DIMMs. Memory is installed on one or two memory expansion cards (#4098), at least one of which is required. Each of these memory cards has 16 slots for the DIMMs. There are three memory features: 256 MB (two 128 MB DIMMs, feature #4110), 512 MB (two 256 MB DIMMs, feature #4120), and 1,024 MB (two 512 DIMMs, feature #4121). These features can be installed in any configuration up to two cards.

The minimum configuration for the p640-B80 and the Model 270 is 256 MB (one 256 MB memory feature), and the maximum configuration is 16 GB, or two memory cards, each populated with eight 1,024 MB features.

# pSeries 620 Models 6F0/6F1 and pSeries
660 Models 6H0/6H1 Memory Expansion

There is an interest and somewhat twisted to memory expansion on the p620-6F0/6F1 and p660-6H0/6H1 systems. To save cost on an entry-level machine, the 1-way processor package (called a “book") contains eight DIMM slots on the processor board and a single 16-position memory board (see Figure 1.8b). The eight DIMM slots on the processor board can be populated, to a maximum of 8 GB. If more capacity is required, then the currently installed DIMMs must be moved to the memory board and the next increment be made as a quad. If the memory board is used, then the DIMM slots on the processor board may be populated. All DIMMs in each pair or quad must be the same capacity. The maximum memory on a 1-way system is 16 GB, using 1,024 MB DIMMs, and the minimum capacity is 256 MB.
