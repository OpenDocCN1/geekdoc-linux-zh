Both the pSeries 620 Model 6F1 and the Model 6F0 offer sufficient scalability in processing power, memory, storage capacity, and I/O at-tachment capability to handle Web hosting and database applications, such as Supply Chain Management, Enterprise Resource Planning, and Customer Relationship Management.

The system architecture of Models 6F1 and 6F0 is shown in Figures 1.8a and 1.8b. In the p620, processor(s) with L1 and L2 caches, and the memory controllers are packaged in a unit called a processor book. This “book” is the physical unit that is exchanged to upgrade from one processor type to another or replace a failing processor. The system board for the 1-way processor options (Figure 1.8) is a simpler, cost-reduced design that includes some memory DIMM slots on the system board and allows for a maximum memory capacity of 8 GB. The system board for the 2-, 4-, and 6-way (Model 6F1 only) options is more complex and allows for the full 32 GB maximum memory capacity on one or two memory riser cards. As shown in Figure-1.8a, the 6-way configuration of p620-6F1 consists of two cards, a 4-way and a 2-way card. However, this detail does not really matter to the user because the book is the unit until installed in the system.

The p620 derives its performance not from fast processors, but also from wide, high-speed buses from processor to memory and to the I/O (RIO) subsystem. The interface from processors to the memory controller is the 16-byte-wide PowerPC6XX bus. The interfaces from memory controller to memory DIMMs (labeled SMI bus) are 8 bytes wide, but the bandwidth of the total path from processor to memory controller to memory IV processors is well matched. For 2-, 4-, and 6-way systems using the RS64 IV port bandwidth is greater than 2 Gbps. Each remote I/O port can operate at 1 Gbps (500 Mbps bidirectional). However, since the second RIO port is used internally as a failover in the event of failures, the theoretical maximum system I/O bandwidth is also 1 Gbps (500 Mbps bidirectional). Three PCI bridges drive the 10 PCI slots and integrated Ethernet and SCSI controllers, while an ISA bridge is used for other devices (ser-vice processor, diskette, serial and parallel ports, keyboard, mouse).
