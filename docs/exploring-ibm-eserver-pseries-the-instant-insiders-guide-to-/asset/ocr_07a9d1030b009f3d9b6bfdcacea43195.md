# Exploring IBM @serverSeries

It has already been mentioned that there are 12 hot-swappable disk bays and 10 hot-plug PCI slots to allow failing parts to be replaced while the system continues to run (with the exception, of course, that applications using a failing disk or PCI adapter would have to be stopped and restarted when replacement of the failing part has made). The p620 provides hot power supply available and cooling fans, with an optional third power supply available for redundancy. When the third power supply is ordered, additional fans are installed as well that the cooling becomes redundant and concurrently maintainable. The p620 runs on standard 115-volt or 220-volt AC power.

A significant RAS function included in the p620 is Dynamic Process Deallocation, which monitors recovered processor errors and predicts when a processor is getting close to a failure. If the threshold is reached for one of the processors, the processor is dynamically deconfigured from the system and the system continues to run with one fewer processor. A notification is sent that this has taken place, and service can be performed at a convenient time. The obvious value here is that no failure occurred before the likely bad processor was out of service.

A feature available in the pSeries 620 is Chipkill memory, originally developed for the S/390+ mainframe systems. Chipkill technology detects multit errors and corrects most of them transparently to the user. By comparison, ECC memory—although an important feature and one used in all pSeries systems—can correct only single-bit errors. With Chipkill memory, if a critical threshold is exceeded, the affected memory is taken off-line and a service action is initiated to be completed when the user desires. According to IBM studies, systems without Chipkill technology are as much as 100 times more likely to have an outage due to memory failure.

In summary, the pSeries 620 Model 6F1 and 6F0 servers have the performance, expandability, and high availability required for the mission-critical applications of medium-sized enterprises.
