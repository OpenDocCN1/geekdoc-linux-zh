## IBM 2-Port Gigabit Ethernet-SX PCI-X Adapter (#5707)

The 2-Port Gigabit Ethernet-SX Adapter (#5707), like its counterpart #5706, provides two full-duplex 1 Gbps Ethernet connections, but in this case using the LC-type connector to standard shortwave multimode fiber. Depending on the cable, the adapter can support distances up to 550 meters. This adapter also provides the “large send” and “checksum offload” functions described above. It supports NIM and requires AIX 5L v5.1 or v5.2. For optimum performance, this adapter should be placed in a PCI-X slot.

## IBM Token-Rings PCI Adapter (#4959)

The IBM Token-Rings PCI Adapter (#4959) is a high-performance, 32-bit master adapter. Featuring an enhanced system interface for higher throughput and lower system utilization, coupled with RJ-45 and DB9 connectors, this adapter is well equipped to handle the LAN environment requirements of today’s servers and high-end workstations running I/O-intensive applications on the network. It supports network boot capability. Additional features and support include the following:

- Operation at either 16 Mbps or 4 Mbps per twisted-pair or shielded twisted-pair (STP) via the RJ-45 and the 9-pin D-shell connectors.
- Automatic ring speed detection. To simplify installation and reduce network downtime, the adapter automatically determines the ring speed and mode of an operating network and configures itself accordingly.
- External status light-emitting diodes (LEDs), providing visual indication of adapter and ring status without disrupting operation.

## TURBOWAYS ATM Adapters

The TURBOWAYS ATM Adapter and the TURBOWAYS ATM LAN Emulation function that is shipped with provide it the pSeries with direct access to high-bandwidth and high-speed Asynchronous Transfer Mode (ATM) LANs. Local area network emulation provides the ability to run IP or non-IP protocols. The TURBOWAYS adapters are intelligent adapters capable of supporting applications requiring greater bandwidth than is available with current LAN technology. They support full-duplex attachment to 155 Mbps and 622 Mbps ATM networks, and some adapters provide function such as TCP checksum to minimize processing load on the host pSeries server. Three ATM adapters are available. The MMF (multimode fiber) adapters attach with dual-SC type, multimode fiber MMF cables, while the UTP adapters connect to CAT-5 UTP. The adapters are the following:

- Turnboways 622 Mbps PCI MMF ATM Adapter (#2946)
- IBM 64-bit/66 MHz PCI ATM 155 UTP Adapter (#4953)
- IBM 64-bit/66 MHz PCI ATM 155 MMF Adapter (#4957)

## WAN Communications Adapters

All pSeries systems can participate in a variety of wide area networks. Unlike LANs, WANs allow computers to communicate with other computers and remote devices over global distances. For more about WANs, see Chapter 4.

## Multiprotocol Communications Adapters

There are two adapters that allow pSeries systems to simultaneously participate up to four different communications networks. These adapters work in conjunction with software provided with AIX to attach using multiple communications protocols (bisync, SDLC, X.25) and various physical connections. Cable options are available for configuring the system for the particular network in which the pseries is attached. These multiprotocol adapters are part of the AIX Realtime Interface Coprocessors (ARTIC) family of adapters designed to remove the burden of communications traffic from the pseries by handling the detailed processing associated with communications links and nonstandard device interfaces.

The IBM AIX960Hx 4-Port Multiprotocol PCI Adapter (#2947) provides four ports for EIA-232, EIA-530, RS-449, X.21, or V.35. Each port can support speeds up to 2 Mbps. Using the appropriate software support provided with AIX, this adapter provides SDLC, bisync, or X.25 packet-switched communications capability. The adapter requires one full-length 32-bit PCI slot.

The 2-port Multiprotocol PCI Adapter (#2962) provides high-speed connections between standalone systems on a WAN, connected via external communications equipment such as Service Units (CSUs), Data Service Units (DSUs), and synchronous mediums. Using the appropriate cable, the 2-Port Multiprotocol PCI Adapter connects to X.25 packet-switched networks compatible with X.21 DCE (Distributed Computing Environment) Cable (X.21, #2954), with V.24 DCE (2-Port Cable, V.24/EIA-232, #2951), with V.35 DCE (2-Port Cable, V.35, and V.36 DCE (2-Port Cable, V.36/EIA-449, #2954).
