# 94 Exploring IBM@serverpSeries

Web site technical white papers that explain the POWER4 architecture in great detail.

Each POWER4 processor core has 64 KB of L1 instruction cache and 32 KB of L1 data cache, and shares the approximately 1.5 MB of L2 cache. Off-chip is L3 cache, ranging from 8 MB to 32 MB of L3 cache for each POWER4 chip, depending on the pSeries model. MCMs used in p655, p670, and p90 servers have four processor chips, they have 128 MB of L3 cache. L3 caches on the processor cards for other models range from 8 MB to 32 MB.

Between the L3 cache and main memory is a memory controller for interfacing to memory cards or memory DIMMs. The memory interface provides ECC to correct single-bit and detect double-bit errors, as with memory scrubbing to correct soft errors. As will be explained later, on the POWER4-based pSeries servers uses the Chipkill memory design to reduce even further the likelihood of system outage due to memory errors.

The POWER4 I/O structure is shown in Figure 1.29. Using the GX bus, the POWER4 chip attaches to a remote I/O (RIO) controller, which is the interface to the I/O drawers and any internal PCI-X slots (depending on pSeries model). In the I/O drawers and/or on the system planar design for internal slots are bridge chips which drive the PCI-X buses for the I/O slots and integrated devices. The POWER4 architecture provides a well-balanced system design that will be able to extend to higher frequencies as technologies develop.

# Logical Partitioning

Logical partitioning technology, introduced to the pSeries family by the p690 and supported only on systems using the POWER4 architecture, is also available on p630, p650, p655, and p670 systems. The only POWER4-based system that does not support LPAR is the 1- and 2-way p615, which is too small a server to take advantage of the benefits of logical partitioning.

LPAR allows the system administrator to assign processors, memory, and I/O slots (and the attached devices) to create, in effect, several independent systems or "virtual servers" running on a single server. Each partition can run different operating systems—AIX 5L v5.1, AIX 5L v5.2, or Linux.
