# 7332 4-mm Tape Autoloader

The IBM 7332 4-mm DDS-3 Tape Autoloader Models 220 and 110
provide outstanding tape storage capacity for save and restore operations\using the DDS-4 and DDS-3 formats. The Model 220
uses 20 GB cartridges in a six-cartridge magazine to store up to 240 GB
of data with compression or 120 GB without compression. The 7332
Model 110 uses 12 GB cartridges to obtain 48 GB of storage capacity
with the four-cartridge magazine. With 2x compression, the Model 110
autoloader can contain up to 96 GB with the four-cartridge magazine.
Compression values are data and application dependent, so actualesults may vary.

The 7332 can read and write tape cartridges in either compressed or
uncompressed format and support data transfer rates of 1.1 Mbps to
6 MBps, depending on the model. Its magazine indexing time (the time
to unload one cartridge and load another) is less than nine seconds.

For backing up amounts of data greater than 240 GB, one of the
high-performance TotalStorage Enterprise Tape Library systems should
be considered.
