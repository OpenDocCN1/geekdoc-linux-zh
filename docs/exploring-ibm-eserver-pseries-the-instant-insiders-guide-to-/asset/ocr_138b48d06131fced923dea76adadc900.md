# POWER GXT6500P

The POWER GXT6500P 3D Graphics Accelerator is IBM's current highperformance graphics adapter. When used in a 64-bit PCI or PCI-X slot, the GXT6500P provides extremely high performance, even for the largest MCAD models. Like the GXT4500P, it has a 128 MB unified frame buffer and supports resolution up to 2048 x 1536. Its rasterizer draws lines, characters, and smoothed polygons, and has advanced texture mapping for high image quality. Like the GXT4500P, this accelerator provides digital monitor support and can be used with the L200p and T541H Flat Color Monitors, as well as the ISO 9241-compliant P260/P275 CRT monitor.

The GXT6500P derives its power from the IBM-designed processing chip used in its design. This hard-wired logic (not a generic CPU or digital signal processor requiring microcode) implements the OpenGL and graPHIS APIs by 3D graphics software natively on the adapter card, giving the maximum in performance. Offloading the graphics processing to the hardware on the GXT6500P minimizes load on the system and therefore helps provide the best overall system performance.
