Two disks are included in the enclosure, as are three media bays, initially populated with a CD-ROM drive and a 1.44 MB 3.5-inch diskette drive. Internal disk capacity is 220.2 GB, using three 73.4 GB drives (one media bay can accept a disk drive). The Model 270 provides five PCI slots, two 64-bit slots, and three 32-bit slots.
M memory of 256 MB is expandable to 16 GB. The Model 270 slots for two memory cards, each of which can contain up to 16 DIMMs. The DIMMs must be installed in pairs, and the memory features available from IBM come in pairs. So, for example, using 16 of the feature with two 512 MB DIMMs, would have 32 DIMMs and could populate a Model 270 to its maximum memory capacity of 16 GB.
The 270 contains several advanced reliability and fault-tolerance features in addition to ECC memory. A service processor is standard, providing a means to diagnose, check status, and sense operational conditions of a remote system, even when the main processor is inoperable.
