The most recent pSeries memory innovation is Chipkill memory (Figure 1.30), used in every pSeries server except the p60. Chipkill, which supplements ECC, bit steering, and data scrubbing, was originally developed by IBM for the S/390 mainframe computer. Chipkill allows the system to continue running in the presence of complete chip failure (i.g., multibit failures). Whereas bit steering redirects bits of memory, the Chipkill design scatters all bits of chip into four ECC words. Even if the entire chip fails, the ECC algorithms recover the data of those four bits. When a threshold is reached, a service action notice is automatically sent and the system can continue to run until a scheduled repair action can be taken. IBM estimates that systems with Chipkill design are 100 times less likely to have a system outage due to a memory failure moving in systems without this design.

In any computer system, a great deal of information is moving in and out of main memory. For this reason, the design of the main memory significantly affect overall system performance. There are two reasons why so much time is spent moving information in and out of the main memory. First, the programming instructions of the program(s) reside in the main memory. Therefore, every instruction in the program must at some point be retrieved from the main memory. Second, the main memory holds and data used in the program(s) being executed. If the overall information flow to and from main memory (assisted by the instruction cache unit and the data cache unit) cannot keep pace with the main processor, the main processor will be delayed and system performance will suffer. For this reason, the main memory must be designed to keep up with the speeds achievable by the main processor. The design of the pSeries processor and its main memory are balanced through the use of separate data and instruction caches and the wide path between main memory and the caches, or "bus" discussed earlier. To further balance the system, the path or bus between caches and main memory (which can exceed 200 Gbps in the p690) is independent from the I/O bus used for input/output activity as disk information transfers. This prevents interference between main memory activity and input/output activity, which can increase the overall performance of the system.
