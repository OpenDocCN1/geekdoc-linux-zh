In addition to the primary I/O drawer, up to three secondary I/O drawers can be added to provide a total of 56 PCI slots and eight media bays. All drawers are mounted in a standard IBM rack, for example, the 36U Model T00 or the 42U Model T42. Additional space in the rack may be used for various storage and communications subsystems. The reliability and availability features discussed in the pSeries 620 Models 6F1 and 6F0 and the pSeries 660 Models 6H1 and 6H0 to the pSeries 660 Model 6M1 as well, including the Dynamic Processor Deallocation capability and the Chipkill memory technology.

Performance and scalability are the major factors that distinguish the Model 6M1 from the other p660 models and pSeries servers. Based on relative performance (rPerf), commercial applications can experience as much as 60% better performance on an 8-way Model 6M1 compared to a 6-way Model 6F1 or Model 6H1.Perf" is an IBM metric used in "Performance Overview"; it is explained in later chapter. Much of this performance gain can be attributed to the high-bandwidth design of the Model 6M1, which allows concurrent flows of data within the system itself. The system schematic in Figure 1.17 shows that there are two independent memory buses (with bandwidth of 4.8 Gbps each) and 6 XX buses to each pair of processors (at 2.4 Gbps bandwidth each). With the total aggregate memory and processor bandwidth being 19.2 Gbps (calculated as 2 x 4.8 Gbps plus 4 x 2.4 Gbps), which can be an enormous amount of data flowing internally between processors, memory, and I/O. The aggregate I/O bandwidth with four I/O drawers is 4 Gbps. With these large data rates, processors have shorter wait times to get the information needed to continue carrying out their computations.
