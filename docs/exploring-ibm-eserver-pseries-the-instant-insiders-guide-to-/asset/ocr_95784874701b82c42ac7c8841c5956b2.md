# Digital Trunk Adapters

The IBM ARTIC960RxD Quad Digital Trunk PCI Adapter (#6310) provides voice processing for up to 4 T1 or E1 digital lines. This trunk translates up to 96 T1 voice channels or 120 E1 voice channels in a single slot of a pSeries server. Using touch-tone telephone keypad buttons, the IBM Voice Response for AIX Version 2.2 LLP (Licensed Program Product) provides the interactive voice response function. There are several cable options to be used with this adapter, depending on the physical trunk connections of the installation.

# SP Switch and SPSwitch2 Attachment Adapters

The IBM RS/6000 System Attachment Adapter (#8396) allows selected pSeries and RS/6000 servers to be integrated into a Cluster 1600 system through the SP Switch interconnect. Support for attaching via the SP Switch is available for pSeries 660, pSeries 670, and pSeries 690 servers, as well as for several pSeries and RS/6000 servers that are no longer available. High-speed communication between the attached server and the SP nodes is enabled over the SP switch. Demand for this feature has been seen from SP customers who require a single SMP database server for their internal SP-node application servers.

The Switch2 Attachment Adapter (#8397) provides attachment to Cluster 1600 systems at even higher performance and lower latency than the SP Switch technology, and this adapter is supported on current pSeries servers. Even though the RS/6000 SP system and SP nodes have now been withdrawn from marketing, the SP Switch2 is available in a frame by itself, effectively creating a high-speed switch fabric through pSeries servers using this adapter can be clustered.
