If the MCM contains POWER4 or POWER4+ chips with two processors, then there are eight processors per MCM. These are called 8-way MCMs. If, on the other hand, the MCM contains POWER4/ POWER4+ chips it is a 4-way MCM. Although the p690 offered a 4-way HPC option, the only 4-way MCMs offered with POWER4+ processors are on the p655 (4-way 1.7 GHz) and p670 (4-way 1.5 GHz). Although 4-way MCMs offer only half as many processors, their performance for selected HPC applications is increased because the L2/L3 caches and memory interface are shared by fewer processors. (Note: The POWER4 processor architecture is described in more detail later in this chapter.)

The base p690 configuration offers one 8-way MCM at any of the four speeds supported (1.1, 1.3, 1.5, or 1 GHz), 8 GB of memory, one I/O drawer, and the media drawer. Also required is an IBM 7315-C02 Hardware Management Console—a PC-based workstation that runs applications with a graphical interface to configure and manage the p690, and to help with problem determination and resolution. The I/O drawer and media drawer include:

+   - Two 18.2 GB Ultra-SCSI disk drives

+   - Sixteen hot-swappable disk bays (two occupied by the base disk drives)

+   - Five media bays

+   - Twenty hot-plug PCI-X slots

+   - Integrated controllers:
  - Two Ultra3-SCSI
  - Two serial
  - Two HMC
