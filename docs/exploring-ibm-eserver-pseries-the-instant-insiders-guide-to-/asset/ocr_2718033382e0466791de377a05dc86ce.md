For more processing power, the p650 offers 14.5 GHz processor cards with 32 MB of L3 cache. The compact 8U rack drawer provides expandability up to 2-way processor cards, as much as 64 GB of memory, four hot-swappable disk bays that can accommodate drives as large as 146.8 GB, two media bays, and seven hot-plug PCI-X adapter slots.

As shown in Figure 1.13, the p650 can be configured with one to 2-way POWER+ processor cards. All processors must be of the same speed, either 1.2 GHz or 1.45 GHz. Packaged on each processor card is L3 cache, which stages data and instructions between the processor chips and main memory. On 1.45 GHz processors, the L3 cache is 32 MB (as depicted), while on 1.2 GHz processors is 8 MB. Memory DIMMs are distributed in a balanced fashion across the processor “books” (IBM’s name for the physical unit containing processor cards and memory DIMMs). These books protect the components from damage in handling and help manage air for cooling. Each processor book has eight DIMM slots, and must be installed in quads (four DIMMs), Since the largest available memory DIM is 2 GB (4 x 1024 MB), the maximum memory capacity of a 2-way system is 16 GB, of a 4-way system is 32 GB, and so on to 64 GB for an 8-way p650.

The interface to the I/O subsystem is through the RIO-2 hubs. For the first processor, the RIO-2 hub connects to the internal I/O subsystem (PCI-X slots, integrated controllers, service processor) and up to two RIO-2 ports for an I/O drawer loop.
