# KEYEPPBLE VNC VIEWER

Very often, users incorrectly configure their VNC servers with weak or no passwords. An intruder who has gained access to an organization's intranet can use a VNC viewer to connect to vulnerable VNC servers in order to take control of the misconfigured hosts (see the next illustration). One such viewer, the Keyeppble VNC viewer, is available for the Sharp Zaurus PDA and can be downloaded from http://kilelez.de/ zaurus/showdetail.php?app=186.

# SMBMOUNT

The Smbmount tool allows users to mount Samba network shares. Often, users misconfigure their Samba file shares with weak or no passwords. The Smbmount tool can be used by intruders to access such shares. (Please see Chapter 4 for details on Samba misconfigurations.) A Zaurus port for the Smbmount tool can be found at http://www .dasgehtdichnichts.an/zaurus/smbmount.html.
