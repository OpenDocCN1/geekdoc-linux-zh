# THE PRACTICAL XILINX® DESIGNER LAB BOOK 1.5

Field programmable logic devices (FPLDs) provide a complete TTL parts cabinet in a single chip. Each FPLD contains thousands of digital logic gates interconnected by internal electronic switches. The switches can be reprogrammed at any time to create a completely different logic circuit.

This book shows the reader how to construct digital logic circuits using two types of FPLDs from XILINX, inc.: programmable gate arrays (FPGAs) and complex programmable logic devices (CPLDs). The text's philosophy is based on the idea that digital design expertise is acquired by building circuits to see how they work. Each chapter presents working examples of logic circuits which the reader can experiment with by loading into either a XILINX FPGA or CPLD. While some theory of logic design is presented, the overall tone is more practical. It can be understood by anyone with a knowledge of binary arithmetic and elementary logic operations

# CONTENTS

Chapter 1: The Digital Design Process discusses the steps involved in designing a digital circuit and shows how to build a circuit using TTL chips.
Chapter 2: Programmable Logic Design Techniques discusses the advantages of using programmable logic and introduces the XILINX M1 based implementation tools.
Chapter 3: Combinational Logic describes common-place logic functions (such as encoders, decoders, multiplexers, parity generators, and adders) and shows how to implement them using ABEL, VHDL and schematic editors.
Chapter 4: Modular Designs and Hierarchy discusses the advantages of stepwise refinement and encapsulation in the design of digital circuits using parity generators and binary adders as examples.
Chapter 5: Electrical Characteristics covers the various types of digital I/O pins, propagation delays, and power usage of programmable devices.

Chapter 6: Flip-Flops describes how various unclocked, clocked, and edge-triggered flip-flops operate and gives a working design for each one.
Chapter 7: State Machine Design covers Mealy and Moore machines using the examples of a counter and a drink machine controller.
Chapter 8: Memories discusses the various components of semiconductor memories and then shows how to build one using the flip-flops in a CPLD or FPGA. An example using the built-in RAMs of an FPGA is also shown.
Chapter 9: The GNOME Microcomputer covers the instruction set design for a 4-bit processor, the construction of it within both a CPLD, and an FPGA, along with its use for performing binary multiplication.
Chapter 10: The DWARF Microcomputer extends the GNOME microcomputer design by adding an 8-bit datapath, new addressing modes, I/O ports, nested subroutines, and interrupt processing.
