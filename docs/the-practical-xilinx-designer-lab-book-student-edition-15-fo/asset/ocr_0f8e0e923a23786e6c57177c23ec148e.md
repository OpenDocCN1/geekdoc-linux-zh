# Functional Simulation of the Design

At this point, we have entered the logic for the Hwy3 output of the Trip-Genie. Now it is a good idea to use the functional simulator to see if what we have entered is working correctly.

Start the functional simulator by clicking the button in the Flow tab of the Project Manager window. This will bring up the Logic Simulator-Xilinx Foundation F1.5 window and a single, empty Waveform Viewer window (Figure 2.21).

The first thing we must do is add the inputs and output of the Hwy3 logic circuit to the Waveform Viewer so we can see what is happening as the circuit is simulated. Do this by selecting the Signal → Add Signals... menu item.
