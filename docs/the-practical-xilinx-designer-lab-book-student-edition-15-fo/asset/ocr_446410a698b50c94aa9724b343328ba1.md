The ALU (Figure 10.3, right side) contains the circuitry for adding and XORing values and for storing the accumulator and carry and status flags. The 8-bit operands ands enter the ALU through the [R7..R0] inputs from the register set's A_OUT output and through the [A7..A0] inputs from the D bus. The ADD and PASS inputs control the arithmetic operation performed on these operands as follows:

| PASS | ADD | ALU Operation |
|---|---|---|
| 0 | 0 | ACC ← ACC⊕REGA |
| 0 | 1 | ACC ← ACC + REGA + CARRY |
| 1 | X | ACC ← D Bus |

The details of the arithmetic circuitry are shown in Figure 10.5. The PASS and ADD inputs control a pair of byte-wide multiplexers (identifiers H2 and H5). The multiplexers select either the [A7..A0] input, the output of an 8-bit adder (ADD8), or the output of a module that does a bitwise XOR on two 8-bit values (XOR_8X8).
