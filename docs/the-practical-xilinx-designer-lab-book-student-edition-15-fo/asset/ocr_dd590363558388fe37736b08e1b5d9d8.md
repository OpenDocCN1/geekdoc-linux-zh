# 1-Bit Adder in VHDL

In this section we will create the 1-bit adder circuit using VHDL and the HDL design flow mode of the Xilinx Foundation Series software. We will target this to the XC4005XL FPGA, so start by creating a project called ADD1_40 in the XCPROJ-V directory (Figure 3.17). Make sure to click on the HDL radio button so the HDL design flow mode is enabled.

Start the HDL editor and elect to use the Design Wizard. Choose VHDL as the HDL and set the name of the VHDL design to FULLADD. Then use the Design Wizard-Ports window to set-up the inputs and outputs. From the circuit schematic, we know we need 3 inputs. Click the New button and type CARRY_INPUT into the Name field. Repeat these actions for the INPUT0 and INPUT1 inputs.

Click New again and enter CARRY_OUTPUT in the Name field. Click on the Output radio button to set this as an output bit. Repeat these actions for the SUM output. Figure 3.18 shows the assignment of I/O ports for the 1-bit adder.
