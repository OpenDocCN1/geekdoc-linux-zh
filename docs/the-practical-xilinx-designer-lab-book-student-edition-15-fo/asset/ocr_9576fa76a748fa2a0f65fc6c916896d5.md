# **Listing 5.3**  The led package and the LED decoder module description from the XSE.VHDL library VHDL source code. (Cont'd.)

```
042-  "0101111" WHEN "1011",
043-  "1100101" WHEN "1100",
044-  "0011111" WHEN "1101",
045-  "1101101" WHEN "1110",
046-  "1101100" WHEN "1111",
047-  "0000000" WHEN OTHERS;
048- END ledcd_arch;
```

Or put these constraints into the BLANK_95.UCF file if you are going to use the XS95 Board:

```
NET D<0>        LOC=P46;
NET D<1>        LOC=P47;
NET D<2>        LOC=P48;
NET D<3>        LOC=P50;
NET BLANK       LOC=P51;
NET S<0>        LOC=P21;
NET S<1>        LOC=P23;
NET S<2>        LOC=P19;
NET S<3>        LOC=P17;
NET S<4>        LOC=P18;
NET S<5>        LOC=P14;
NET S<6>        LOC=P15;
```

Once the design is compiled, you can download it to the XS40 Board:

```
C:\XCPROJ_V\BLANK_40> XSLOAD BLANK_40.BIT
```

Or compile the design, create the SVF file, and download to the XS95 Board:

```
C:\XCPROJ-V\BLANK_95> XSLOAD BLANK_95.SVF
```

After the download is complete, the following mapping between the XSPORT arguments and the circuit inputs is in effect:

| XSPORT Bit | LED Decoder Input |
|---|---|
| $b_0$ | D<0> |
| $b_1$ | D<1> |
| $b_2$ | D<2> |
| $b_3$ | D<3> |
| $b_4$ | BLANK |
| $b_5$–$b_7$ | *** Not Used *** |
