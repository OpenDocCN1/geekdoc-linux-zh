# Listing 5.1 LED decoder with blanking input and tristate outputs.

```
001- MODULE LEDBLANK
002- TITLE 'LED decoder WITH blanking input'
003-
004- DECLARATIONS
005-
006- BLANK PIN; *blank LEDs when high
007- D3..D0 PIN;
008- D = [D3..D0];
009- S6..S0 PIN ISTYPE 'COM';
010- S = [S6..S0];
011-
012- EQUATIONS
013-
014- [S6..S0].OE = !BLANK; *disable LED drivers when BLANK=1
015-
016- TRUTH_TABLE
017- (D -> [S6, S5, S4, S3, S2, S1, S0])
018- 0 -> [1, 1, 1, 0, 1, 1, 1];
019- 1 -> [0, 0, 1, 1, 0, 1, 0];
020- 2 -> [1, 0, 1, 1, 1, 0, 1];
021- 3 -> [1, 0, 1, 1, 0, 1, 1];
022- 4 -> [0, 1, 1, 1, 0, 1, 0];
023- 5 -> [1, 1, 0, 1, 1, 1, 1];
024- 6 -> [1, 1, 0, 1, 1, 1, 1];
025- 7 -> [1, 0, 1, 0, 0, 1, 0];
026- 8 -> [1, 1, 1, 1, 1, 1, 1];
027- 9 -> [1, 1, 1, 1, 0, 1, 1];
028-
029- END LEDBLANK
```

Once the design is compiled and converted to SVF, then download it to an XS95 Board like so:

```
C:\XCPROJ\BLANK_95> XSLOAD BLANK_95.SVF
```
