+   3. Connect the outputs of the LEDDCD module through a 7 bit bus to the inputs of an OBUFT8 buffer (this is a group of 8 tristate buffers). Connect the buffer output to a 7-bit output bus.

+   4. Connect an input terminal named BLANK through an IBUP to the T control input of the OBUFT8 symbol. When BLANK is driven high, it will cause all the tristate buffers to enter a high-impedance state.

+   5. Connect terminals through IBUP input buffers to the data inputs of the LEDDCD symbol.
