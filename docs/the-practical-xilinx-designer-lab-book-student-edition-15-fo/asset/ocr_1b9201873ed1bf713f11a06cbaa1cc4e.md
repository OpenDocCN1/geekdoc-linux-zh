**Asynchronous Delay Report:** The propagation delays for each routed signal are listed in this report.

**Post Layout Timing Report:** This report lists any paths through the placed&routed logic which violate timing constraints. **Bitgen Report:** This report records all the options that were in effect when the bitstream file was generated. Any errors that occurred during the bitstream generation are also listed here.
