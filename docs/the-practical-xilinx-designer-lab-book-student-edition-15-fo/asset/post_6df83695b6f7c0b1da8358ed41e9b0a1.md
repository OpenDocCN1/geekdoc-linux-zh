# Discussion

So far, you have written ABEL and VHDL and drawn schematics that describe logic circuits, compiled them, simulated them, downloaded them to your XS40 or XS95 Board, and—magically—they seem to do what you expected. With all the emphasis placed on entering and simulating the design files, it is easy to forget that there is actually something happening electrically. This chapter will discuss and examine some simple electrical characteristics of digital circuits that you will need to know so you can figure out why things sometimes do not work as expected.

# I/O Characteristics

A simple inverter gate with a standard output is shown in Figure 5.1a. The inverter has two transistors: Tₖ which is connected between the output pin of the inverter and the +5 V supply, and T₁ which is connected between the output pin and the ground. When the input of the inverter is pulled to ground (Figure 5.1b), transistor T₁ is turned off and T₁ is turned on. This means that T₁ acts like an open switch while T₁ acts like a closed switch. Thus, there is now a low-resistance path between the output pin and the +5 V supply. This pulls the output pin up to +5 V. When the input is tied to +5 V (Figure 5.1c), the opposite set of actions occurs: Tₖ turns off and T₁ turns on, thus creating a low-resistance path from the output pin to ground. This drags the output to the ground potential.

What happens if we apply a voltage to the input that is between +5 V and ground? In this case, both T₁ and T₁ could turn on and "fight" each other. T₁ tries to pull the output to ground while T₁ tries to pull the output to +5 V.
