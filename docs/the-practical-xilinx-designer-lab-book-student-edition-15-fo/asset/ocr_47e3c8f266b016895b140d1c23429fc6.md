Now you can do actual tests on the parity generator. For example, the command

C:\XCPROJ\EVPAR_40> XSPORT 00101100

will light up the S0 segment of the 7-segment LED because the input pattern contains an odd number of 1 bits. On the other hand, the command

C:\XCPROJ\EVPAR_40> XSPORT 10110001

will extinguish the S0 segment because the input pattern contains an even number of 1 bits.
