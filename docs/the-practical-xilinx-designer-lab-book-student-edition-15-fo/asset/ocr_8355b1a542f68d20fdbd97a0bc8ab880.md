Changing the values in these storage elements changes the state of the switches and alters the functions of the programmable device. These switches can be repeatedly programmed to implement new designs (or repair faulty designs), eliminating the need to buy a new device for each design modification. The XC9500 CPLDs use nonvolatile FLASH-based storage cells so the device retains its programming even if the power is turned off. The XC4000 FPGAs, however, employ static random access memory (RAM) storage cells so they need to be reprogrammed each time power is interrupted.
