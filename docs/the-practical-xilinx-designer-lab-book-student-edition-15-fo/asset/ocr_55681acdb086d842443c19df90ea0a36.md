Now click on the button to start compiling the design. Then click on the Options... button in the Implement Design window that appears. In the Options window, type the name of the UCF you generated, C:\XCPROJ\LEDDCD95\LEDDCD95.UCF, into the User Constraints box (or use the Browse... button to select the UCF). Then click OK to return to the Implement Design window and click the Run button to start the compilation process. It should complete successfully and uneventfully.

After the compiling is done, select the Reports tab in the right pane of the Project Manager window. Then double-click on the Fitting Report so we can check how much of the XC95108 CPLD was used to build the LED decoder. The following lines tell the story:
