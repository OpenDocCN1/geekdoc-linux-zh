# Measuring Gate Delay

Figure 5.12 shows a simple circuit, DELAY, that demonstrates gate delays. When INP transitions to a logic 0 value, the outputs should go to logic 0 after 1 gate delay. Then when INP rises back to logic 1, OUT1 will go high after 1 gate delay. This places a logic 1 on both inputs to the second AND gate so OUT2 will go high 1 gate delay after OUT1 did. And OUT3 will go to logic 1 after another gate delay, followed by OUT4 1 gate delay later.
