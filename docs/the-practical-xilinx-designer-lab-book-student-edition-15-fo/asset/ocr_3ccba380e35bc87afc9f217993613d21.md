As a simple test of the FIFO, you can reset the FIFO and write in the sequence of values 0, 1, 2, 3, 4, 5, 6, 7. Then when you read the FIFO you will see the same sequence of values displayed on the LED digit. No new numerals will be displayed once all the values have been read from the FIFO.
