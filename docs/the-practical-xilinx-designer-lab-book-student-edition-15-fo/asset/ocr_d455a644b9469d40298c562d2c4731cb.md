# Figure 2.28 Implement window.

In the Implement window, click on the Options... button. This will bring up the window used to set the control parameters for the Foundation Series Implementation tools run the UCF using the User Constraints box. You can use the Browse... button to find the UCF, or you can type in its location. Then click on OK to return to the Implement Design window.

After returning to the Implement Design window, click on Run. The Flow Engine window appears which has a graphical rendition of the stages required to map a netlist into an FPLD (in this case, Figure 2.30 shows the steps needed to map into an XC5000 CPLD). The Foundation Series Implementation tools run these stages.

Translate: The EDIF netlist is converted to an internal netlist format, design-rule checks are performed, and various optimizations of the logic circuit are tried to increase the speed of the circuit and/or decrease the number of gates used.

Fit: The gates in the netlist are assigned to specific macrocells and their interconnections are routed through the FastCONNECT matrix.

Timing: The propagation delays through the macrocells and the FastCONNECT matrix are computed and stored in a file for use during a timing simulation.

Bitstream: The stream of bits is generated which will be downloaded into the chip to make it carry out the logic functions described in the ABEL or schematic file.

If you are implementing the design for the XC4000XL FPGA and the XS40 Board, then the Flow Engine window shown in Figure 2.31 will appear. There are more stages in the implementation process when targeting an FPGA.
