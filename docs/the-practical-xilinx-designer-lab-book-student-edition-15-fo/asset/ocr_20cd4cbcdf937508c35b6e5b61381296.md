Next, the TDI input (pin 15) is connected to the DIN input (pin 71), and the TCK input (pin 16) is connected to the CCLK input (pin 73). This connects the data and clock inputs of both the JTAG and configuration circuitry together.

All the other pins of the FPGA are collected together into the 84-line XCbus. You don’t have to physically construct this bus right now—it just serves as a notational convenience that makes it easy to see which FPGA pins are connected to pins on the other chips.
