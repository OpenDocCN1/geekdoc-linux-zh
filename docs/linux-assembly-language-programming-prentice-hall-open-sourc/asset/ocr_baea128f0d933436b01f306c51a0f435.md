# 3.1.4 Gate Level Diagrams

A logic circuit diagram which shows the individual logic gates but not their internal make-up is called a *gate level diagram*. In a gate level diagram, the power terminals on the logic gates are usually not shown. The symbol for the NOT gate used in gate level diagrams shows only two terminals, the input and the output:

![](bbox=[0.06, 0.26, 0.56, 0.41])

The wire shown on the left represents the input; the wire on the right is the output.

In this figure, the only battery connection is at the signaling input to the NOT gate. Although the power connections are not shown, they must be there or the circuit will not work.
