```
1
1101
+ 110
011
```

The fourth column also totals two, which is again 0 carry 1:

```
1101
+ 110
10011
```

This is exactly how a computer adds thirteen and six. We can check that the result is nineteen.

```
1 x 16 = 16
0 x  8 =  0
0 x  4 =  0
1 x  2 =  2
1 x  1 =  1
--
19
```
