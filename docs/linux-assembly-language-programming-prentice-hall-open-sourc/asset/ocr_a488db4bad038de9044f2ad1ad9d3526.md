This section shows how addition is done using logic circuits.

Consider the addition of 13 and 6 again and observe that in each column, we have two digits to add along with a carry digit from the preceding column.

![](bbox=[0.06, 0.13, 0.36, 0.24])

An addition circuit which can do the work involved in one column of such an addition is called a *full adder*. It produces the sum of the two digits in that column and a carry digit from the previous column. It also produces an output carry digit. The addition of 13 and 6 as shown requires the use of four full adder circuits. Because the binary system is being used, the Boolean truth values 0 and 1 may be used as binary digits. *Table 3.7* shows the truth table for a full adder circuit. It is not hard to construct a full adder. The Output Sum circuit can be built from two *XOR* circuits. The Output Carry circuit can be built from three ANDs and two ORs. See Figure 3-5. A full adder has three inputs and two outputs, which together function as one column of an adding machine.
