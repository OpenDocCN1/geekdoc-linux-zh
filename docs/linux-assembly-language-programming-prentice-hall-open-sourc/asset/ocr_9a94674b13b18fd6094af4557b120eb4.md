Figure 3-11 shows a memory consisting of four of these circuits. Two address wires suffice to address this memory. This memory circuit has four words. Each word holds four bits. The data wires D0, D1, D2, and D3 are all shared. The address wires A0 and A1 control the four different Sel inputs. The address wires select which of the four Sel wires is selected. The other three will have the value 0. It is not possible to turn on two at a time.
