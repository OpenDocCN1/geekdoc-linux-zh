There is no load immediate command for segment registers. The following command, for example, is illegal.

```
```text
MOV DS, 1234H
```
```

Suppose that DS, ES, and SS have values stored in them via the following commands:

```
```text
MOV AX, 2000H
MOV DS, AX
MOV AX, 5000H
MOV ES, AX
MOV AX, 0C800H
MOV SS, AX
```
```

So then DS holds 2000H, ES holds 5000H, and SS holds C800H. Figure 12-2 shows the three segments which are enabled by these three register loads. The entire memory consists of the addresses from 0 through FFFFFH. The DS segment consists of the addresses from 20000H through 2FFFFH. The ES segment ranges from 50000H through 5FFFFH. The SS segment goes from C8000H through D7FFFFH.
