# **TABLE 4.13**
tracroute Protocol

| DESCRIPTION | PROTOCOL | REMOTE ADDRESS | REMOTE PORT / ICMP TYPE | IN/OUT | LOCAL ADDRESS | LOCAL PORT / ICMP TYPE |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Outgoing traceroute probe | UDP | ANYWHERE | 33434:33523 | Out | IPADDR | 32769:66535 |
| Time exceeded (intermediate hop) | ICMP | ANYWHERE | 11 | In | IPADDR | - |
| Port not found (termination) | UDP | ANYWHERE | 3 | In | IPADDR | - |
| Incoming traceroute probe | UDP | ISP | 32769:66535 | In | IPADDR | 33434:33523 |
| Time exceeded (intermediate hop) | ICMP | ISP | - | Out | IPADDR | 11 |
| Port not found (termination) | ICMP | ISP | - | Out | IPADDR | 3 |

*tracroute* can be configured to use any port or port range. As such, it's difficult to block all incoming *tracroute* packets by listing specific ports. However, it often uses source ports in the range from **32,769** to **65,535** and destination ports in the range from **33,434** to **33,523**. Because *tracroute* can be configured to use any source and destination port, the most effective way to block incoming *tracroute* is to block the outgoing ICMP messages generated in response. Symbolic constants are defined for *tracroute*'s default source and destination ports:

```
TRACROUTE_SRC_PORTS="32769:66535"
TRACROUTE_DEST_PORTS="33434:33523"
```
