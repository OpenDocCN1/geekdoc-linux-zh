# # Outgoing FTP Client Request

```
S IPT -A FORWARD -i SDMZ_INTERFACE -o S_EXTERNAL_INTERFACE -p tcp \
-s $LAN_ADDRESSES --sport $UNPRIVPORTS --dport 21 \
-m state --state NEW -j ACCEPT

S IPT -A FORWARD -i SDMZ_INTERFACE -o S_EXTERNAL_INTERFACE -p tcp \
-s $CHOKE_IPADDR --sport $UNPRIVPORTS --dport 21 \
-m state --state NEW -j ACCEPT
```

The **ip_conntrack_ftp** module takes care of the port or passive mode data connection as part of the RELATED rules. Specific rules for the data connection aren't required.

The two pairs of data channel connection request rules are included here for the sake of completeness:
