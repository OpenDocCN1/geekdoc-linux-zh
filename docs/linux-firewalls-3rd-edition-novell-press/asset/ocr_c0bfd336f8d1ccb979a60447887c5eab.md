# APPENDIX B: Firewall Examples and Support Scripts

```
SIPT -A FORWARD -i SLAN_INTERFACE -o $DMZ_INTERFACE -p tcp \
-s $LAN_ADDRESSES --sport SUNPRIVPORTS --dport 22 \
-m state --state NEW -j ACCEPT
```

```
SIPT -A FORWARD -i $DMZ_INTERFACE -o $LAN_INTERFACE -p tcp \
-s $SSH_CLIENT --sport SUNPRIVPORTS \
-d $SSH_CLIENT --dport 22 \
-m state --state NEW -j ACCEPT
```

```

-m state --state NEW -j ACCEPT
```
