
## 你会提供哪些信息？

事故报告必须包含足够的信息，以帮助事故响应团队追踪问题根源。在联系攻击源所在网站时，请记住，你的联系人可能就是那个故意发动攻击的人。你从以下列表中提供的信息取决于你联系的是谁，你有多放心包含这些信息，以及当前生效的隐私和其他政策：

-   你的电子邮件地址
-   你的电话号码（如果合适的话）
-   你的 IP 地址、主机名和域名
-   涉及攻击的 IP 地址和主机名（如果可用）
-   事故发生日期和时间（包括你相对于 GMT 的时区）
-   对攻击的描述
-   你是如何检测到该攻击的
-   展示该事件的日志文件条目示例
-   日志文件格式的描述
-   引用描述攻击性质和重要性的公告和安全通知
-   你希望该人员做什么（修复、确认、解释、监控或知悉）

## 六、关于《语料库》新版的一些评论和建议

新版编辑为我们提供了两部非常优秀的卷册。文本和辅助资料的质量得到了非常仔细和认真的处理，在使批判性辅助资料尽可能有用方面付出了巨大的努力和注意力。然而，我想就文本本身、辅助资料以及新《语料库》版式布局的某些方面向新版编辑提出几个问题。

I. 在我看来，辅助资料应该更加清晰和完整。首先，很难确定哪个读法属于哪个手稿（MS），也不清楚批判性辅助资料中是否已经给出了注释。在许多情况下，给出了简单的注释，但在其他情况下，不清楚它是针对手稿的读法还是针对之前的版本。

II. 在我看来，新版的《语料库》还应该包含一个人名索引和专有名词对照表。拥有一个主题索引和词汇登记簿也将非常有用的。这样的索引将对所有《语料库》读者大有裨益，对批判性辅助资料的准备也将是一个极大的帮助。

III. 我相信新版编辑会给我们提供一部非常好的《语料库》版本，它将对所有研究希腊小说的学者大有裨益。我期待新版《语料库》的第三卷，希望它很快出版。

Giovanni

## 入侵检测工具

在前一章中，你学习了入侵检测和入侵响应的概念。极少有两次攻击是完全相同的，尽管所用技术经常依赖于一套常见的方法，并导致许多相同症状，如前章所述。正是通过这些常见的方法和症状，入侵检测工具能够协助入侵分析员完成工作。

在寻找协助问题关联、诊断和解决问题的软件工具时，入侵分析员有很多选择。本章侧重于入侵检测中使用的软件工具以及管理员工具包中可能用到的工具。本章从网络嗅探器开始，继续讨论用于检查根套件的工，以及文件系统检查器和日志文件监控。

## 入侵检测工具包：网络工具

安全管理员和网络管理员的主要工具之一都是网络分析工具。这包括网络嗅探器、入侵检测软件和网络分析仪。

网络嗅探器是一种被动监听网络接口接收和发送流量的软件。首选的主力嗅探器是 TCPDump。TCPDump 简单得让初学者也能快速上手，但又足够强大，能在多种情况下为多种协议提供必要的功能。使用 TCPDump，可以以多种格式（包括 ASCII）查看流量，并使用表达式精细调整通过工具查看的确切流量。

TCPDump 是手动且原始的入侵检测软件。如果你知道自己在找什么，TCPDump 可以帮助你识别通过网络的异常流量。单靠 TCPDump 本身并不能知道刚刚发生了一次攻击；那是入侵分析员（以及其他软件）的工作。然而，TCPDump 几乎总是成为调查主动攻击的必要工具，因为它允许分析员实时监视攻击。

TCPDump 在第 11 章“网络监控和攻击检测”中有深入介绍。在那里，你将发现对正常协议活动的覆盖，以及一些通过 TCPDump 的“眼睛”（或者说是“鼻子”）视角查看的利用案例。

当涉及到监听网络并对流量进行一定程度分析的工具时，没有比 Snort 更好的了。Snort 是一款提供者和企业级入侵检测软件，部署广泛且成熟。Snort 利用入侵签名的概念工作。其理论是，许多攻击在网络层面遵循相同的模式，或看起来相同或非常相似。

考虑这个例子：假设在某个端口接收到一个数据包，其头部标志以特定方式设置。当这种情况发生时，它总是攻击的前兆或尝试利用某个漏洞。可以说，因此，这种特定攻击具有一个标识其为恶意流量的签名。该签名，对于利用此漏洞而言是独一无二的，然后可以被 Snort 等软件用来检测是否有人试图利用该漏洞。Snort 随后可以基于此检测执行操作（或者不执行任何操作）。

Snort 非常强大，当与名为 ACID 的报告软件结合时，除了入侵检测的主要功能外，还可以生成复杂的报告。

Ntop 是网络分析软件，不同于产生基于协议、流、主机和其他参数使用报告的嗅探器。建议在网络的战略要点使用 ntop 来建立正常流量流基线。图 10.1 展示了 ntop 报告之一的示例页面。

Ntop 只是此类分析器中的一种。我选择在此介绍 ntop，因为它可以快速上手。然而，我也推荐其他用于网络流量的分析器软件。在其他分析软件中，MRTG 和 Cacti 是流量分析的两个优秀选择。

创建基线流量报告并保持其更新，不仅有助于发现异常（包括流量的意外增加和减少），还有助于跟踪何时可能需要新的带宽。正是这种双重用途——安全异常和带宽使用监控——使得流量分析极具价值。

要在大型网络上使用 Snort 和 TCPDump 建立流量基线并有效监控网络入侵，重要的是将工具放置在网络内的战略位置。大多数大型网络（甚至中型和小型网络）都使用交换机来传递流量。
