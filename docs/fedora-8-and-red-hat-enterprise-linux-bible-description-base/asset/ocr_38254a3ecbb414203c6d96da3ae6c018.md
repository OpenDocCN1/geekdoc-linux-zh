If you wanted to wait even longer to do the transfers, you can pass an option to the `bgget` command to have it start the transfer at a particular time. Here is an example:

```
nftp /pub > bgget -@ 2007100410000 wireless.doc
```

With this command, the transfer is set to run at 1 a.m. on October 4, 2007 to transfer the file called `wireless.doc`. Again, you can check the `.nftp/spool/log` file in your home directory to see if the transfer has completed.
