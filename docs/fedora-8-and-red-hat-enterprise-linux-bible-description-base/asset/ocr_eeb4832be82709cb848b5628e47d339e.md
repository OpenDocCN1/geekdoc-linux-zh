# **Adding more games from Fedora repository**

As Fedora continued its role as a proving ground for the Red Hat Enterprise Linux products, some just-for-fun software packages were pushed out of what was called Fedora Core. Luckily, many of them were pushed into Fedora Extras. With the merging of Fedora Extras and Core, all those games are now back in the main Fedora repository.
