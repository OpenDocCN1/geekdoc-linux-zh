The commented lines above actually show the default values set for certain timeout conditions. You can remove comments and change these values if you like. The `confTO_QUEUEWARN` option sets how long after delivery of a message has been deferred to send a warning message to the sender. Four hours (*4h*) is the default. The `confTO_QUEUERETURN` option sets how long before an undeliverable message is returned.
