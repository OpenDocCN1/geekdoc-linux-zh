The following sections describe major new features of Fedora 8 (besides the latest versions of those basic components just named).

### Getting custom Fedora spins

Fedora used to be released as a set of CDs or a DVD containing all the Fedora packages that could be installed from those media. The results of new tools first added in Fedora 7 for creating custom software repositories (Pungi) and custom live CDs (livecd-creator) are coming to fruition in Fedora 8 in the form of a growing set of custom spins.

A custom spin of Fedora is a CD, DVD, or USB flash drive image that can be run as a live CD and/or Fedora installer. Official Fedora spins include:

- **Fedora DVD** — Contains about a 2.9GB cross-section of desktop, server, and software development software packages that is similar to what used to be in Fedora Core.
- **Fedora Desktop Live CD (GNOME)** — From this single, 700MB live CD you can run a GNOME desktop Fedora 8 system. An install icon on the desktop then lets you install that desktop system to your hard disk. (This CD is included with this book.)
- **Fedora Desktop Live CD (KDE)** — Fedora is showing KDE some love by offering a KDE desktop live/install CD of Fedora 8. As with the GNOME desktop, you can select the install icon to install the KDE desktop system to your hard disk.
- **Everything DVD Set** — An "Everything" 2-DVD set containing the entire Fedora 8 repository (over 8GB) is expected to be produced shortly after Fedora 8 is released. This set is for people who want every installable software package with Fedora 8. (The DVD that comes with this book contains most of the contents of the two Everything DVDs, respump onto a high-capacity DVD-9.)

The GNOME desktop CD and Nearly-Everything DVD included with this book are for standard 32-bit PCs (i386). If you need media to install Fedora on PowerPC (PPC) or 64-bit PC (X86\_64) computer architectures, you can download ISO images for those media either using Bittorrent (http://torrent.fedoraproject.org) or an official Fedora public mirror site (http://mirrors.fedoraproject.org). Refer to Chapter 2 for information on using and installing Fedora from these different media.

Unofficial custom spins are also available from the Custom Spins page (http://fedoraproject.org/wiki/CustomSpins). So far there are already Fedora Live Developer, Games, Art, Xfce Desktop, and Electronic Lab spins. (The term spin means a compilation of software from the Fedora software repository, combined into the form of one or more bootable images (typically to fit on a CD or DVD), that lets you either run live or install that set of software.)

### Creating your own spins

The same tools that the Fedora Project uses to build packages and create live CDs and installation CDs are themselves distributed with Fedora. That means that anyone can use those tools to create their own installation package sets, and then turn those package sets into their own repositories. Using those repositories, you could then create your own CD or DVD images to later install or run live.

Pungi (http://fedoraproject.org/projects/pungi) is the project created for Fedora 8 to build the Fedora system itself. The pungi package contains the pungi command and related configuration files. You can use the pungi command to fashion your own installation trees that result in installable ISO images.

The Fedora Live CD project (http://fedoraproject.org/wiki/FedoraLiveCD) has produced tools for building your own live CDs from Fedora software repositories. The primary tool for creating those live CDs is called livecd-creator. Refer to the Live CD HOWTO (http://fedoraproject.org/wiki/FedoraLiveCD/LiveCDHowTo) for information on using livecd-creator.

A nice addition to livecd-creator for Fedora 8 is that you can create kickstart files (described in Chapter 2) to direct the creation of live CDs. This means that the same format you use to automate installs with anaconda can be used to save the package list and other settings you use to create your live CDs.

### The GNOME Online Desktop

By combining the Big Board side bar project with the ability to group together the online services you use most (such as Facebook, Moshupshot, YouTube, Netflix and others), the GNOME Online Desktop project takes a big step toward the future of Web-connected desktop computing. You start by setting up accounts with Moshupshot (to gather your personal online services) and GNOME.org (to gather information about the applications you use). Then log in to your Online Desktop to have all your personal files, applications, and online services available from your GNOME desktop. While Online Desktop is still considered to be experimental, it is already lots of fun to play with.

### Infinity look-and-feel and Nodoka theme

In Fedora 8, the look-and-feel of the Fedora desktop, boot screens, login screens, backgrounds and other visual elements have been greatly simplified with the new Infinity look-and-feel (http://fedoraproject.org/wiki/Artwork/F8Themes/Infinity) and Nodoka Theme (http://fedoraproject.org/wiki/Artwork/NodokaTheme).

### PulseAudio sound system

The PulseAudio sound system (www.pulseaudio.org) has replaced ALSA as the default sound system used with Fedora. By providing plug-ins, PulseAudio can provide interfaces to audio applications that expect to use ALSA or other Linux sound systems.

### Cocomac utility for getting codecs

The Cocomac utility provides a means of getting legal software for playing MP3, Windows Media, MPEG4 and other multimedia software that cannot be freely distributed with Fedora because of software patents. With Cocomac, you can connect to the Fluendo.com site and download a free MP3 decoder or purchase several other multimedia codecs.

> **NOTE:** The addition of Cocomac brings to light a major issue that every Linux distribution faces: How to offer non-free software to those who need or want it. Helping to connect you to a commercial software vendor has raised a lot of questions about how Fedora should deal with that issue. On what basis should one vendor get special treatment over another and how should Fedora control the influence of those vendors? For example, what if a vendor tries to cripple applications that compete with those it supports? Although there are no perfect answers yet, in the meantime there is at least a solution to overcome the multimedia problem that in the past has prevented a lot of people from fully adopting Fedora.

### Package Manager

The latest version of Package Manager offers several improvements. For one, you should get much better performance from the underlying yum facility. Secondly, new features in Package Manager allow you to add more software repositories to the list of repositories from which you can install software for your Fedora system.

### IcedTea Java environment

The IcedTea project set out in this release to work toward creating a completely free Java environment. IcedTea tries to achieve this goal by replacing binary Java plug-ins used with OpenJDK with compatible open source plug-ins. Chapter 7 describes how to enable IcedTea to play your Java content from within a Firefox browser.

### Firewall Configuration

A new Firewall Configuration window replaces the Security Level Configuration window used in previous releases. With the new window, you can not only open and close access to ports. You can also configure your Firewall Configuration Window to create custom firewall rules and even configure IP Masquerading.
