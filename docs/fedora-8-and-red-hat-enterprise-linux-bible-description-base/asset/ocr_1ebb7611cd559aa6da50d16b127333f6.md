The Audio Configuration window contains three tabs of settings you might want to adjust:

+   - **Sound test** — In addition to letting you test your sound card, this tab shows information about each sound card you have installed. If your sound card isn't working, use the Vendor, Model, and Module information when you ask for help. You can also change the PCM device from this tab if you want, for example, to try different outputs from the card.

+   - **Settings** — If you have multiple sound cards, you can select which card to use by default (Default Audio Card) and the Default PCM Device for that card (identifying where sound is output). From the Settings tab, you can also select Disable Specific Card Configuration, to allow plug-ins to override default settings. Likewise, you can change the order in which audio cards are used on your system.

+   - **System** — You can view information about the ALSA sound system (driver versions, library packages, and utility packages) from this tab.
