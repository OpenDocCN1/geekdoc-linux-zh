# Deleting User Accounts

Occasionally, it is necessary to remove a user account from your Linux system. This can be
done with either the `userdel` command or the User Manager window.

# Deleting user accounts with `userdel`

The `userdel` command takes a single argument, which is the login name of the account to
delete. If you supply the optional `-r` option, it also deletes the user’s home directory and all
the files in it. To delete the user account with login name mary, you would type this:

```
`# userdel mary`
```

To wipe out her home directory along with her account, type this:

```
`# userdel -r mary`
```
