# Creating your own spins

The same tools that the Fedora Project uses to build packages and create live CDs and installation CDs are themselves distributed with Fedora. That means that anyone can use those tools to create their own installation package sets, and then turn those package sets into their own repositories. Using those repositories, you could then create your own CD or DVD images to later install or run live.

Pungi (http://fedoraproject.org/projects/pungi) is the project created for Fedora 8 to build the Fedora system itself. The pungi package contains the pungi command and related configuration files. You can use the pungi command to fashion your own installation trees that result in installable ISO images.

The Fedora Live CD project (http://fedoraproject.org/wiki/FedoraLiveCD) has produced tools for building your own live CDs from Fedora software repositories. The primary tool for creating those live CDs is called livecd-creator. Refer to the Live CD HOWTO (http://fedoraproject.org/wiki/FedoraLiveCD/LiveCDHowTo) for information on using livecd-creator.

A nice addition to livecd-creator for Fedora 8 is that you can create kickstart files (described in Chapter 2) to direct the creation of live CDs. This means that the same format you use to automate installs with anaconda can be used to save the package list and other settings you use to create your live CDs.

# The GNOME Online Desktop

By combining the Big Board side bar project with the ability to group together the online services you use most (such as Facebook, Mughshot, YouTube, Netflix and others), the GNOME Online Desktop project takes a big step toward the future of Web-connected desktop computing. You start by setting up accounts with Mughshot (to gather your personal online services) and GNOME.org (to gather information about the applications you use). Then log in to your Online Desktop to have all your personal files, applications, and online services available from your GNOME desktop. While Online Desktop is still considered to be experimental, it is already lots of fun to play with.
