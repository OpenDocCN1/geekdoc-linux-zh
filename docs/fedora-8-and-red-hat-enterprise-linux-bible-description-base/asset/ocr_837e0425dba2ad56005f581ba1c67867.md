You can see that the document begins and ends with HTML tags (\ `<html>` and \ `</html>`). The beginning part of the Web page is contained within the `head` tags. The body of the page is contained within the `body` tags. The title of the page is set apart by `title` tags.

Between the beginning and ending `body` tags, you can add all kinds of stuff. You can have headings, images, and text. More different types of bulleted or numbered lists. You can add forms, dynamic HTML (which changes the content as you move or select items), or special data. Figure 9-2 shows an example of a Web page as it appears in Firefox.
