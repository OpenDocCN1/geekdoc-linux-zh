# # Writable DVD drives

In previous versions of Fedora and RHEL, the *dvdr* command was used to write DVDs. Now, *cdrecord* can be used to write both CDs and DVDs. Using a writable DVD drive and the *cdrecord* command, you can back up your data to DVD-R, DVD-RW, DVD+R, and DVD+RW disks.

The first trick with recording to DVDs in Linux is to make sure that you have a drive that supports DVD writing. You can check by removing any disks in the CD/DVD drive and typing the following:
