# Working with Graphics

Tools for creating and manipulating graphics are becoming both more plentiful and more powerful in Linux. Leading the list is the GNU Image Manipulation Program (The GIMP, or sometimes simply GIMP). GIMP lets you compose and author images as well as retouch photographs. Other tools that come with Fedora and RHEL for creating graphics include `ksnapshot` (a program for taking screen captures).
