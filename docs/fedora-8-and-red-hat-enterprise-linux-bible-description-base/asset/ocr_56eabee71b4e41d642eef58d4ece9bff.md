There are other messaging protocols supported by Pidgin as well. These include Jabber (which is used by GoogleTalk and available from www.jabber.org), Napster (instant messaging and buddy lists, but not music downloads), Groupwise Messenger (Novell’s instant messaging), Sametime (Lotus messaging from mme.while.sourceforge.net), TOC (rarely used AOL AIM service for unofficial clients), and Zephyr (IM system from MIT). Pidgin not only supports multiple protocols, but also allows you to communicate over multiple protocols at the same time. There are also available Jabber servers you can get to run your own Jabber instant messaging server, such as Ejabberd (http://ejabberd.jabber.ru). (Type yum install ejabberd to install that package.)

If you have never used instant messaging before, you can sign up for free accounts from AOL (https://my.screenname.aol.com/) or MSN (http://messenger.msn.com). Click Accounts from the initial Pidgin window and add your account. Select your account from the Account list, enter the password, and select Sign on.

Once you are signed on, for example, to AOL, from the Buddy List that appears select the IM button to connect to another IM user who is online. Or select Chat to enter the name of a chat room you want to enter. You can add buddies to your list as appropriate.
