For demonstration purposes, the procedure below shows how to install a Fedora 7 instance as a virtual guest operating system on Fedora 8. Before you start, you need a network connection and the location of an online Fedora 7 software repository. That location can be a local DVD that is shared via an NFS connection. This procedure gives you an idea of how the feature works, before you try installing other operating systems.

+   **Start `xenuget-install`** — As root user from a Terminal window, type the following:

```
```bash
# /usr/sbin/virt-manager
```
```

+   **Select Xen host** — Select Local Xen host and click File → Open Connect.

+   **Create new guest** — Right-click on local host and click New. When the Create a new virtual system pop-up appears, click Forward. You are asked to name your virtual system.

+   **Virtual machine name** — Type a name to represent this virtual machine and click Forward. Keep the name simple (one word, fairly short, and no special characters) because the name is used to represent the virtual machine in file names and on menus. You are asked the location of the media.

+   **Virtualization method** — Select Paravirtualization (for faster, lightweight virtualization) or Fully Virtualized (slower, but supports more operating systems) and click Forward.

+   **Installation Media** — Type the location of an online software repository (you can also enter a kickstart file, if you have one). To use your Fedora DVD instead of an online repository, you export it as an NFS share (see the following Note). Here’s an example of a software repository for Fedora 7 so you can create a Fedora 7 system to run on your Fedora 8 system:

```
http://download.fedora.redhat.com/pub/fedora/linux/releases/7/Fedora/i386/os
```

> **NOTE:** Here’s how to use your Fedora DVD as a Xen guest repository. Install the `nfs-utils` package. Insert the DVD. Assuming it is mounted as `/media/disk`, add the line:
> 
> `/media/disk *( ro)`
> 
> to the `/etc/exports` file. Start `nfs` (`/etc/init.d/nfs start`). When you are prompted for a software repository, enter this address: `nfs:localhost:/media/disk`. If localhost doesn’t work, try using your computer’s IP address.

+   **Storage location** — Choose to either use a file on an existing file system or the device name of a disk partition to store the installed system. For example, you could name the disk image `/home/chris/xenimage` as the file to use. I created a new disk partition as I was doing this procedure. Just make sure that the location you use has enough disk space to hold the operating system you are about to install. You are asked to allocate memory.
