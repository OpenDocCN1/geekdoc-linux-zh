The open source tool I describe here for resizing your disk is called GParted. It can be used to resize partitions that contain a variety of file system types.

If your Windows system is backed up and your disk defragmented, you can begin the process of resizing your NTFS or VFAT disk partition with GParted using the Fedora 8 Desktop Live CD included with this book. Here’s how to resize your NTFS partitions using that CD:

+   Insert the Fedora 8 Desktop Live CD and reboot your computer.

+   At the boot prompt, with the first entry highlighted, press Enter.

+   When the live CD boots to a GNOME desktop, to begin resizing your hard disk select Applications System Tools GParted from the top panel. The GParted graphical partitioning tool opens, displaying your current disk partitions.

+   Select the partition you want to resize. The Resize/Move button should become available.

+   Select the Resize/Move button to open a Resize/Move pop-up windows.

+   Grab the slider bar from the right and move it to select how much you want to resize your partition. The New Size box shows the new size of your partition. The Free Space Following MiB box shows how much free space you will have after you are done. In my example, I resized /dev/sda1 to about 15GB, leaving me about 5GB of free space that I can use later to install Fedora (normally, you would want more for Fedora, if space is available). Figure 2-1 shows the GParted window resizing about a 20GB partition to about 15GB.

+   Click Resize/Move to begin resizing your partition. When it is done, you will see the resized partition and a new entry showing the free space.

> **CAUTION:** The resize is committed in the next step. You can quit now without making any changes if you are nervous. In any case, make sure that the partition you are resizing is not mounted. (In this example, I’d type `umount /dev/sda1` as root user from a shell before running the next step.)

+   If the new partition sizes look alright, click Apply to commit the changes.
