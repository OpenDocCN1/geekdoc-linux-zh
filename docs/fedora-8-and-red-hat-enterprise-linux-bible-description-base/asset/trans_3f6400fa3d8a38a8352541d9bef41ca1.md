## 搜索文件

如果你正在寻找特定的文件或文件夹，可以使用 Konqueror 的查找功能。要打开查找窗口以搜索文件，请选择 **工具 → 查找文件**，查找框将出现在你的 Konqueror 窗口中。你还可以通过在终端窗口中输入 **kfind** 来启动 kfind 窗口。图 3-20 展示了 kfind 窗口。

只需在 **名称** 文本框中输入你要搜索的文件名，并在 **查找位置** 文本框中输入你要搜索的文件夹（包括所有子文件夹）。然后点击查找按钮。可以使用元字符来辅助搜索。例如，搜索 `*.rpm` 以查找所有以 `.rpm` 结尾的文件，或搜索 `z*.doc` 以查找所有以 z 开头且以 `.doc` 结尾的文件。你还可以选择让搜索区分大小写，或点击帮助按钮获取更多关于搜索的信息。

![](img/fb202c163797a743c3c6cf236316bc96_159_0.png)

为了进一步限制搜索范围，你可以点击 **属性** 选项卡，然后输入日期范围（介于...之间）、早于今天若干个月（过去 x 个月内）或早于今天若干天（过去 x 天内）的条件。选择 **内容** 选项卡，可以选择将搜索限制为特定类型的文件（**类型**为...）、包含你输入文本的文件（**包含文本**...），或特定大小（**大小是**...，单位为千字节）的文件。

## 创建新文件和文件夹

在使用 Konqueror 窗口时，你可以创建多种类型的文件。选择 **编辑 → 新建**，然后选择 **文件夹**（用于创建新文件夹）或文件子菜单下的以下类型之一：

- **HTML 文件** — 打开一个对话框，允许你输入要创建的 HTML 文件名。
- **应用程序链接** — 打开一个窗口，允许你输入应用程序的名称。点击权限选项卡以设置文件权限（如果你希望将文件作为应用程序运行，则必须开启 **执行**）。点击执行选项卡，输入要运行的程序名称（在 **单击时执行** 字段中）以及要在应用程序标题栏中显示的标题（在 **窗口标题** 字段中）。如果是基于文本的命令，请选中 **在终端中运行** 复选框。点击复选框 **以不同用户身份运行** 并添加用户名。点击 **应用程序** 选项卡，将应用程序分配给处理特定 MIME 类型的文件。点击 **确定**。
- **位置链接（URL）** — 选择此菜单项将打开一个对话框，允许你创建一个指向 Web 地址的链接。输入一个名称来代表该地址，并输入该网站的 URL（Web 地址）名称。（务必添加 `http://`、`ftp://` 或其他前缀。）
- **文本文件** — 打开一个对话框，允许你创建文本格式文档并将其放置在 Konqueror 窗口中。输入要创建的文本文档名称并点击 **确定**。

在 **链接到设备** 子菜单下，你可以进行以下选择：

- **CD-ROM 设备** — 打开一个对话框，允许你输入新的 CD-ROM 设备名称。点击 **设备** 选项卡并输入设备名称（`/dev/cdrecorder`）、挂载点（例如 `/media/cdrecorder`）以及文件系统类型（对于标准 CD-ROM 文件系统可以使用 `iso9660`，对于 Linux 使用 `ext2`，对于 DOS 使用 `msdos`）。当图标出现时，你可以打开它以挂载 CD-ROM 并显示其内容。
- **CDWRITER 设备** — 从打开的窗口中，输入你的 CD 写入器的设备名称。
- **DVD-ROM 设备** — 打开一个对话框，允许你输入新的 DVD-ROM 设备名称。点击 **设备** 选项卡并输入设备名称（`/dev/cdrom`）、挂载点（例如 `/media/cdrecorder`）以及文件系统类型（对于标准 CD-ROM 文件系统可以使用 `iso9660`，对于 Linux 使用 `ext2`，对于 DOS 使用 `msdos`）。当图标出现时，你可以打开它以挂载 DVD-ROM 并显示其内容。
- **相机设备** — 在打开的对话框中，识别提供数字相机访问权限的相机设备名称。
- **软盘设备** — 打开一个对话框以输入新的软盘名称。点击 **设备** 选项卡并输入设备名称（`/dev/fd0`）、挂载点（例如 `/media/floppy`）以及文件系统类型（可以使用 `auto` 自动检测内容，`ext2` 用于 Linux，或 `msdos` 用于 DOS）。当图标出现时，打开它以挂载软盘并显示其内容。
- **硬盘设备** — 打开一个对话框，允许你输入新硬盘或硬盘分区名称。点击设备选项卡并输入设备（例如 `/dev/sda1`）、挂载点（例如 `/mnt/win`）以及文件系统类型（可以使用 `auto` 自动检测内容，`ext2` 或 `ext3` 用于 Linux，或 `vfat` 用于 Windows 文件系统）。当图标出现时，你可以打开它以挂载文件系统并显示其内容。

本章稍后部分将描述创建 MIME 类型和应用程序。

## 使用其他浏览器功能

由于 Konqueror 既像文件管理器又像一个 Web 浏览器，它还包含其他几种浏览器功能。例如，你可以使用书签功能保存你访问过的网站书签列表。你添加到书签列表中的任何书签都会显示在点击书签时出现的下拉菜单中。从该列表中选择即可返回到某个网站。添加和修改书签列表有几种方法：

- **添加书签** — 要将当前显示页面的地址添加到你的书签列表中，请选择书签 → 添加书签。书签将被静默添加。下次你点击书签时，你会在书签菜单上看到刚才添加的书签。除了 Web 地址外，你还可以为任何文件或文件夹添加书签。
- **编辑书签** — 选择书签 → 编辑书签以打开书签的树状视图。从出现的书签编辑器窗口中，你可以更改书签的 URL、图标或其他属性。还有一个很好的功能，允许你检查书签的状态（即地址是否仍然有效）。
- **将标签页书签为文件夹** — 你可以向 Konqueror 书签列表中添加一个新的书签文件夹。要创建书签文件夹，请选择书签 → 将标签页书签为文件夹。然后输入新的书签文件夹名称并点击确定。新的书签文件夹将显示在书签菜单中。你可以通过点击文件夹名称并选择添加书签，将当前位置添加到该文件夹中。
- **新建书签文件夹** — 你可以通过选择书签 → 新建书签文件夹来创建新的书签文件夹。当弹出窗口出现时，输入新的文件夹名称并选择确定。

## 配置 Konqueror 选项

你可以更改 Konqueror 窗口的许多视觉属性。你可以选择显示哪些菜单栏和工具栏。你可以让以下任何工具栏显示在 Konqueror 窗口中：菜单栏、工具栏、额外工具栏、位置工具栏、书签工具栏。选择设置，然后点击你希望显示（或不显示）的工具栏的菜单项。当工具栏旁边出现对勾时，该工具栏就会显示。

通过选择设置 → 配置 Konqueror，你可以修改 Konqueror 的各种选项。Konqueror 设置窗口将出现，提供以下选项：

- **行为（文件）** — 更改文件管理器行为。
- **外观** — 更改文件管理器的字体和颜色。
- **预览 & 元数据** — Konqueror 文件夹中的图标可以被设置为看起来像它所代表的文件内容。例如，如果文件是 JPEG 图像，代表该文件的图标可以是该图像的小版本。使用预览功能，你可以限制所用文件的大小（默认为 1MB），因为许多大文件可能需要太长时间才能刷新到屏幕上。你还可以选择将嵌入在文件中的任何缩略图用作图标，或者让图标的大小反映所用图像的形状。
- **文件关联** — 描述每种文件类型启动哪个程序。
- **Web 行为** — 点击行为（浏览器）按钮以打开窗口来配置 Konqueror 的 Web 浏览器功能。通过启用表单自动完成，Konqueror 可以保存你输入的表单数据，并在稍后时将该信息填入其他表单。如果你的计算机资源有限，你可以通过清除自动加载图像复选框或禁用动画来加快页面显示速度。
- **Java 和 JavaScript** — 使用此选择来启用或禁用 Konqueror 窗口中 Web 页面包含的 Java 和 JavaScript 内容。
- **AdBlock 过滤器** — 点击此处以创建在浏览 Web 时过滤的 URL 列表。过滤基于框架和图像名称。被过滤的 URL 要么被丢弃，要么被替换为图像。你还可以在此处导入和导出过滤器列表。
- **字体** — 选择默认情况下用于 Web 页面所需的各种字体（标准字体、固定字体、衬线字体、无衬线字体、手写体和幻想字体）。衬线字体通常用于正文文本，而无衬线字体常用于标题。你还可以设置最小和中等字体大小。
- **Web 快捷方式** — 点击 Web 快捷方式按钮以查看可用于访问不同 Internet 站点的关键词快捷方式列表。例如，在单词“ask”后跟上搜索字符串，以在 Ask Jeeves (www.ask.com) 网站上进行搜索。
- **历史侧边栏** — 点击此处以修改你所访问网站列表（历史记录）的行为。默认情况下，存储最近的 500 个 URL，90 天后，URL 将从列表中删除。你还可以找到一个清除历史的按钮。（要在 Konqueror 中查看你的历史列表，打开左侧边栏，然后点击微小的滚动图标。）
- **Cookies** — 点击 Cookies 按钮以选择是否启用 Konqueror 中的 cookies。默认情况下，每当网站尝试创建或修改 cookie 时，你都会被要求确认是否允许。你可以将其更改为接受或拒绝所有 cookies。
