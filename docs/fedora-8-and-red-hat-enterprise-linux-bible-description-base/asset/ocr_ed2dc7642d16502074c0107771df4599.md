**NOTE:** Using the Appearance Preferences window, you can now use animated backgrounds. The background consists of a series of images and a specially formatted XML file that indicates when and how the images are changed. See *usr/share/backgrounds/infinity/infinity.xml* for an example of the format of an animated background file to use with GNOME. Drag that file to your Background tab just shown to enable the animated background.

+   - **Choose browsers and other apps** — Select Personal → Preferred Applications. When you open a Web page, mail composer, or shell from the desktop, this preferences window lets you choose which Web browser, mail reader, or Terminal window to open by default. Firefox is the default Web browser, but you can choose Epiphany or Konqueror (the KDE browser) to run on your GUI. If you want a text-based Web browser, select W3M or Links. To use a different Web browser, select Custom and type the command line for the browser you want to use into the Command box.

Available Mail Readers include Evolution (the default), KMail, Thunderbird, and Mutt.  
On the System tab, GNOME Terminal is assigned as the default when you need a shell prompt (you can change that to use KDE Konsole or a standard xterm Terminal). To add a different default terminal, select Custom Terminal and enter the command that starts the Terminal you want. You can also choose default multimedia players and accessibility applications.

> **TIP:** The *konsole* command starts the Konsole (KDE) terminal window. Programmers who use many terminal windows at once often prefer Konsole over *gnome-terminal* (finding it to be more efficient and feature-rich).
