# ### Adding Windows computers to your LAN

It is likely that you have other types of computers on your LAN in addition to those running Linux systems (at least for a few more years). If a DHCP server is available on your LAN (or if you have configured one yourself as described in Chapter 23), Windows and most other computer systems can simply start up and begin using the network. In cases where your network card is not properly detected, or you want to set static IP addresses, you need to do some extra configuration.

If you are using Windows Vista, Vista will detect when you connect a network cable. A Set Network Location window appears, allowing you to choose whether the network is a Home, Work, or Public location. After you choose the connection type, you can take the defaults or select to change or view your network and sharing settings.
