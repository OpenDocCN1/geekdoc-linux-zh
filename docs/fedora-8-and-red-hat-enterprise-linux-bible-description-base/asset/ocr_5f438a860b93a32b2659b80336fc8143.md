+   * **Automatic updates** — The software packages that make up Fedora are constantly being fixed in various ways. To provide a mechanism for the automatic selection, download, and installation of updated software packages, Fedora and RHEL rely primarily on the yum facility.

With the addition of yum software repositories on the Internet that include Fedora packages, whole sets of RPM software packages can be updated with a single `yum update` command. Updated Package Manager and Package Updater (Pup) windows provide the first graphical tools with Fedora to install from multiple software repositories on the Internet (as opposed to local CD or DVD media). Pup, in particular, can be used to easily get the latest software enhancements and fixes. A desktop applet automatically alerts you when Pup has updated packages available to download and install. See Chapter 5 for descriptions of these tools.
