## 设置无线局域网

有时，将线缆铺设到网络中的所有计算机并不方便。穿过现有墙壁拉以太网线可能是一项痛苦的工作。将线拖到花园里以便您坐在躺椅上上网可能会破坏氛围。如今，随着廉价且高速的无线设备变得可用，无线局域网（WLAN）是一个经济实惠的解决方案。

尽管您可以在其他计算机系统上使用无线局域网卡，但您可能希望将 Linux 系统用作无线网络中的一个或多个节点。例如，Linux 中的功能可以消除购买其他类型设备的需要。一些让 Linux 在无线局域网中成为宝贵资产的其他功能包括：

-   **Internet 访问** — 您不需要单独的路由器或网关机器即可将无线局域网连接到 Internet。在 Linux 系统上同时拥有有线和无线以太网网卡，可使您的无线客户端通过您的 Linux 系统访问 Internet。
-   **防火墙** — 由于无线加密协议存在一些固有的安全弱点，您可能希望通过配置防火墙来为网络增加额外的安全措施。在您的无线局域网与更大网络之间的边界部署 Linux 防火墙（iptables），即使有人破解了您的无线局域网，您仍然可以对更大的网络提供一定程度的保护。
-   **监控和日志记录** — 您在 Linux 中用于监控有线网络活动的工具也可用于您的无线网络。

> **注意：** 请记住，您不必使用 Fedora 或 RHEL 来提供 Internet 访问、防火墙和监控服务。有一些专为此目的创建的 Linux 防火墙发行版，它们可以从 Live CD 甚至软盘运行。

本节描述了如何使用在运行 Fedora 或 RHEL 的计算机上的无线局域网设备来创建无线以太网局域网。它侧重于配置两个 Linux 系统进行无线通信；然而，一旦您配置了这些节点，您可以通过在每个系统上安装兼容的无线网卡，将 Windows、Linux 或其他类型的系统添加到您的无线局域网中。

## 理解无线网络

无线局域网最适合线缆无法使用的环境。尽管存在安全和干扰等挑战，无线局域网提供了以下优势：

-   您不必在难以触及的地方铺设线缆。在许多情况下，单个无线局域网可以将您的网络扩展至整栋建筑或另一栋建筑，而无需在每个节点之间铺设线缆。
-   只需支付无线网卡的价钱，您就能节省线缆、网络交换机（空气就是您的交换机）以及墙壁修复（修补拉线造成的孔洞）的费用。
-   您可以自由地在环境允许的信号传输范围内移动计算机（距离受天线功率、障碍物和传输速率等变量限制）。

尽管存在多种不同的无线网络标准，但本章重点介绍相对低成本的标准 IEEE 802.11b 和 802.11g 无线网络设备的安装。802.11b 或 802.11g 无线网络使用对公众可用的频谱空间（换句话说，您使用的是无需特殊许可的空中的频谱空间）。802.11 标准通常被称为 Wi-Fi 或无线保真（Wireless Fidelity）标准。

802.11 网络具有以下特征：

-   它提供高达 11 Mbps（802.11b）或高达 54 Mbps（802.11g）的传输速率。传输速率也可以设置（或自动检测）为每种标准的较低速率。
-   它使用 2.4 GHz 频段的频谱。微波炉、蓝牙设备和一些高端移动电话也使用此频段。（如果您在美国境外设置 802.11 网络，请检查当地法规。）为了减少拥堵，在 2.4 GHz 范围内提供了 14 个独立信道。
-   它允许传输距离短至几米（台式机距离）长至几英里（使用特殊天线）。通过降低传输速度可以获得更远的距离。
-   在多个客户端之间或客户端与基站（通常称为*接入点*）之间建立连接。在客户端上，无线网卡运行在 Ad hoc 模式，而基站使用基础设施模式（也称为管理模式）。

还有其他 802.11 标准（例如 802.11a，它可以以更高的速度运行，但大部分时候无线设备制造商最初是支持 802.11b 标准，现在则支持 802.11g 标准（它也能以较低速度与 802.11b 设备通信）。如今 802.11b 和 802.11g 设备的价格非常接近，因此在大多数情况下，您会想要 802.11g 设备。

> **交叉引用：** 要查看完整的 Wi-Fi 认证产品列表，请访问 WECA 网站（www.wirelessthernet.org，并点击 Wi-Fi Certified™ Products）。虽然这些产品应该能够相互通信；但它们并不都具有与 Linux 兼容的驱动程序。

配置好无线网络后，您可以像使用普通有线以太网连接一样使用无线连接。例如，您可以配置无线网络上的 TCP/IP，使其充当网络 Internet 连接的网关。如果您也使用 Linux 作为无线客户端，您可以充分利用防火墙、伪装、网络代理或其他网络功能来保护并充分利用您的无线网络。

## 选择无线硬件

最近之前，让无线网卡在 Fedora 和 RHEL 中正常工作（而无需大量摸索）一直不稳定。在 Fedora 的一个新版本中，Fedora 项目决定追踪并尽可能多地包含他们能找到的无线局域网卡所需的固件驱动程序（前提是可以合法地随 Fedora 重新分发）。您可以在此处跟踪这一努力的进展：

```
http://fedoraproject.org/wiki/Releases/FeatureWirelessFirmware
```

该努力的一些成果包括以下支持不同无线网卡的 Fedora 软件包：

-   **ipw2100-firmware** — 包含 Linux 中 Intel PRO/Wireless 2100 网络连接迷你 PCI 适配器所需的固件。在项目网站上阅读关于这些卡的 Linux 驱动程序的信息（`http://ipw2100.sourceforge.net/index.php`）
-   **ipw2200-firmware** — 包含 Linux 中 Intel PRO/Wireless 2915ABG 网络连接和 Intel PRO/Wireless 2200BG 网络连接迷你 PCI 适配器所需的固件。在项目网站上阅读关于这些卡的 Linux 驱动程序的信息（`http://ipw2200.sourceforge.net/index.php`）。
-   **zd1211-firmware** — 包含与基于 ZyDAS ZD1211 和 ZD1211B 芯片的无线局域网 USB 闪存盘配合工作所需的固件。这些无线卡的 Linux 驱动程序的源代码和文档可在此处找到：`www.deine-taler.de/zd1211/`。
