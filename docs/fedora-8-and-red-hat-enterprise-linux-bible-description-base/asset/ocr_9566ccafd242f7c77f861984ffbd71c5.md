# PulseAudio sound system

The PulseAudio sound system (www.pulseaudio.org) has replaced ALSA as the default sound system used with Fedora. By providing plug-ins, PulseAudio can provide interfaces to audio applications that expect to use ALSA or other Linux sound systems.

# Cocaina utility for getting codecs

The Codeina utility provides a means of getting legal software for playing MP3, Windows Media, MPEG4 and other multimedia software that cannot be freely distributed with Fedora because of software patents. With Codeina, you can connect to the Fluendo.com site and download a free MP3 decoder or purchase several other multimedia codecs.

> **NOTE:** The addition of Codeina brings to light a major issue that every Linux distribution faces: How to offer non-free software to those who need or want it. Helping to connect you to a commerical software vendor has raised a lot of questions about how Fedora should deal with that issue. On what basis should one vendor get special treatment over another and how should Fedora control the influence of those vendors? For example, what if a vendor tries to cripple applications that compete with those it supports? Although there are no perfect answers yet, in the meantime there is at least a solution to overcome the multimedia problem that in the past has prevented a lot of people from fully adopting Fedora.

# Package Manager

The latest version of Package Manager offers several improvements. For one, you should get much better performance from the underlying yum facility. Secondly, new features in Package Manager allow you to add more software repositories to the list of repositories from which you can install software for your Fedora system.

# IcedTea Java environment

The IcedTea project set out in this release to work toward creating a completely free Java environment. IcedTea tries to achieve this goal by replacing binary Java plug-ins used with OpenJDK with compatible open source plug-ins. Chapter 7 describes how to enable IcedTea to play your Java content from within a Firefox browser.

# Firewall Configuration

A new Firewall Configuration window replaces the Security Level Configuration window used in previous releases. With the new window, you can not only open and close access to ports. You can also configure your Firewall Configuration Window to create custom firewall rules and even configure IP Masqeuading.
