# Create a Technical Glossary

A very useful tool for your help desk is a technical glossary that contains definitions for common technical and internet terms. You should also populate it with your own organization's terms and acronyms to speed up the pace of the learning curve for new employees.

# Using FAQ (Frequently Asked Questions) Lists at the Help Desk

learned a bit about FAQ lists in Chapter 3, "Deploying Your Systems." A frequently asked questions list, or FAQ, details commonly asked questions or problems along their solutions. Many organizations create FAQs for their end users so they can get answers to questions on their own without having to bother your help desk. However, in a multi-tiered support system, higher levels of support can create FAQs to reduce the number of problems that are escalated. FAQs are especially useful at the help desk level where they prevent tickets from being opened in the first place.

A question from an end user FAQ regarding password changes might look like this:

| Q: | How do I change my password? |
| A: | Log in to the server, type **passwd**, and press Enter.
At the **Old Password**: prompt, type in your current password.
At the **New Password**: prompt, type in your new password.
At the **Repeat New Password**: prompt, type in your new password again for confirmation.
If you have forgotten your password or cannot log in to the server to change it, call the help desk at 555-1234. | |

someone reading this FAQ couldn't change his or her password, the help desk could help the user by reading its own FAQ:

| Q: | How do I reset a user's password? |
| A: | Log in to the help desk tools site at `http://intranet/tools.html` using your username and password.
Click on the **Change User Password** link.
ter the username in the **Username** field. A new password will be generated automatically and displayed on the page. Tell the user this new password.
Advise the user to change his or her password immediately using the procedures for the End User FAQ. | |
