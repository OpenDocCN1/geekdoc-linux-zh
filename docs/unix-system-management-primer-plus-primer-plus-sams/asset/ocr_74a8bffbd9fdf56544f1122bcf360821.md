# Chapter 2 • DESIGNING THE DATA CENTER INFRASTRUCTURE

KVM switch in a densely populated rack requires a significant amount of cabling; usually three cables connecting each machine to the KVM (and the video cables used to connect the monitor aren't exactly low profile). In addition, you must be physically present at the KVM console in order to use it, so a KVM switch does not provide remote access to the server. Another, often overlooked, disadvantage is that each connected to the KVM needs a video card, which can take up valuable expansion slots in a low-profile server and add to the total cost of your deployment.

Remote consoles provide the functionality of a KVM switch, combined with remote access—which is achieved through a network. Remote consoles are much less common than KVMs, but one manifestation of a remote console is the Compaq Insight Lights-Out Edition (http://www.compaq.com/manage/remote-lights.html). This remote console is an expansion card for Compaq servers that serves the console's keyboard, video, and mouse over the network—even over a Web browser.

Only if you use physically separate hardware for network access it can be considered truly out-of-band. Programs like Windows Terminal Services and VNC provide in-band console functionality that runs on top of the operating system and the network.

As previously discussed, a serial console is a textual interface served over a serial port. Most modern Unix operating systems support serial consoles to varying degrees. Both Sun hardware and the Solaris operating system offer native support for serial consoles. You can access everything from the POST (power-on self test) diagnostics to the boot prompt to the login shell on a serial port, just as if you were on a real console with a keyboard and monitor.

Popular free operating systems like Linux and OpenBSD rely on commodity hardware, and only support serial consoles after they start the boot process. Therefore, on Intel-compatible motherboards, you will not be able to access the BIOS diagnostics or setup menus from a serial console. This limitation can reduce the utility of a serial console, especially during hardware failures. Still, the potential for remote console access is usually worth the trade-off.

The advantages of using serial consoles are as follows:

+   * They require only a single cable, rather than the three cables required for a typical monitor/keyboard/mouse configuration.
* No video card is required, saving both money and expansion slots.
* Their text-based interface allows for easy out-of-band access from anywhere.

The disadvantages of using serial consoles are as follows:

+   * Every task must be performed from the command line.
* Serial lines are slow, usually between 9,600 and 115,200 baud. Any significant output will take some time to scroll off the screen.
