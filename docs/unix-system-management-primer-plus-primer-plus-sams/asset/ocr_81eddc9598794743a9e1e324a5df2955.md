# Recovering from a System Compromise

The realization that you have been attacked and your system has been compromised is a very humbling experience. You will suffer an attack at least once in your career, however, you should be prepared to deal with the situation. Here are five steps you should follow to recover from attacks with minimal damage and maximum protection from future incidents:

+   1. Quarantine the compromised systems.
2. Gather evidence.
3. Report the incident.
4. Back up system data.
5. Reload the compromised systems.

The following sections discuss each of these steps in detail.

# Quarantining the Compromised Server

Once you have confirmed that a machine has been compromised, you should remove it from your network and isolate it, either without a network or on a quarantined network whose sole purpose is to examine compromised systems. This stops any hacker activity in its tracks and prevents the perpetrators from cleaning up after themselves (important for step 2). Additionally, if a hacker has installed a network sniffer, a worm, or any other code that can potentially affect other systems on your network, quarantining that server prevents that from doing any damage.

# Disable User Accounts

You should also disable any compromised user accounts at this point to prevent hackers from breaking into other systems using those same accounts. Make sure you-disable accounts on all servers as well as central authentication services like NIS and Kerberos.

# Gathering Evidence

Make copies of log files, changed configuration files, exploited code, and anything else that would indicate the presence of a hacker. If any user accounts were compromised, thoroughly investigate the contents of their home directories and search the entire file system tree for files owned by those users. You would be surprised at the places a hacker will store files once or she has root access. Some hackers have used such obscure locations as a hidden directory in /dev—the last place anyone would look for a file. Hackers have also created directories that look like “...”, which will appear next to “.” and “..” (current and parent directories) in a directory listing.
