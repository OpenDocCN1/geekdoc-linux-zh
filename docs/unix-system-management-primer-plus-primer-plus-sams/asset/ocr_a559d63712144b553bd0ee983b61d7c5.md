Software RAID is naturally slower than hardware RAID, as the host CPU must perform all calculations. Software RAID is extremely flexible, however; it can use internal hard drives, external disks arrays, and any other RAID devices to form its own RAID partitions. Software RAID is an extremely cost-effective solution as well, because it does not require the purchase or installation of extra drives. Most Unix operating systems come with some form of software RAID functionality, making it a convenient alternative as well. # A Representative RAID Solution: Solstice DiskSuite

Solstice DiskSuite is a software package for Solaris that offers most of the RAID functionality you've learned about this chapter. It provides both command-line and graphical interfaces, the GUI is as functional as the command line, so you can use whichever interface you are more comfortable with.

DiskSuite uses metadrives, which are virtual disks that can be used just like physical disks. DiskSuite uses these metadrives to abstract the actual physical storage configuration: The metadrives can represent entire physical disks, individual slices (Sun's name for partitions), and RAID devices built from these disks and slices. Many software implementations use virtual disks.

DiskSuite is unique in that it can work with a slice or partition, instead of an extra disk. This means you can mirror one file system on a disk but not the others. For example, you can use two slices on two physical disks to create one mirrored device by creating two metadrives, one for each slice, as follows:

```
# maintain d11 1 1 c0t00s0
d11: Concat/Stripe is setup
# maintain d12 1 1 c0tid0s0
d12: Concat/Stripe is setup
```
