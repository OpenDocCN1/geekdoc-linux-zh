You can use these primitives to automatically restart an Apache Web server on each server after
all of its configuration files are updated:

```
WEBSERVERS = ( dope grumpy sneaky doc )
FILES = ( /usr/local/apache/conf )
```

```
web: ${FILES} -> ${WEBSERVERS}
cmdspecial "/usr/local/apache/bin/apachectl restart" ;
```

# Running the rdist Command

Now that you have created the distfile, it is time to run the rdist command to actually dis-
tribute our files. Its usage is
rist [options] [name ...]

Like rsync, rdist requires a separate command to provide the network transport for the file
dist. By default, this command is ssh and cannot be changed in the original BSD 4.2
version of rdist. However, Magiccomps provides a flag for specifying alternate rsh-
like commands as ssh. This and a few other useful command-line options are listed here:

| -f distfile | Specifies an alternate distfile |
| -m host | Only runs rules for the destination host |
| -P rsh-command | Specifies path to an alternate rsh-like command |

Assuming your distfile is named Distfile and is located in the current working directory,
you can run rdist as, using ssh as the transport command:

```
# rdist -P /usr/local/bin/ssh
sneeze: updating sneeze
sneeze: /usr/local/apache/conf/httpd.conf: updating
sneeze: /usr/local/apache/conf/mime.types: updating
sneeze: cmdspecial "/usr/local/apache/bin/apachectl restart"
sneeze: http restarted
sneeze: updating of sneeze finished
```

Note how Apache was restarted after all of the files were updated; if you had used special
stead of cmdspecial, Apache would have been restarted after each file was updated. That
arrangement would have added a lot of overhead and potentially downtime to the distribution
process.
