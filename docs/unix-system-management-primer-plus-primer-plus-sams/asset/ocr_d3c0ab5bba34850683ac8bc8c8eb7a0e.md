# Summary

Security is an increasingly important part of system administration. The Internet has introduced a host of security problems, including script kiddies, hackers, and other malicious people. Not only do you need to be worried about someone breaking into your system, but you also need to worry about denial-of-service attacks designed to stop your services in their tracks. Familiarity with your systems, a thorough understanding of your vulnerabilities, and a working knowledge of techniques for eliminating is critical to maintaining a secure system. This chapter has introduced many of the important concepts, techniques, and tools used to implement secure systems, including the AAA concept, managing access to root accounts, delegating authority, encryption, choosing secure passwords, access control, and forums for asking questions and keeping up to date on current security issues; you should keep up with current events and exploits by subscribing to the various security-related mailing lists and reading newsgroups. An informed system administrator is an effective system administrator.
