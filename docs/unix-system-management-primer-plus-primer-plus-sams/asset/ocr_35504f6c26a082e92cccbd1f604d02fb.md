# Adjust Reserved Space on Large Systems

Considering that modern disks are 20GB or more in capacity, reserving the historical 10% space on each file system could potentially set aside 2GB of space. Consider reducing the minimum free space to a lower value to decrease wasted space; 3% or less is common for larger file systems.
You can calculate the reserved space on a file system without root access by applying the following equation to the output of df -k:
((used space) + (available space))/(total space)

# Determining Inode Usage

Inodes are a valuable commodity for any Unix system. When a file system runs out of inodes, no new files or directories can be created until others are deleted. You can use df to display the inode usage on each file system, but its usage differs depending on the operating system. On Solaris, df -F us -s i will print inode usage for all UFS file systems; Red Hat Linux, the BSD family, and other Unix variants use df -1, as follows:

$ df -i
| Filesystem | Inodes | IUsed | IFree | IUse% | Mounted |
| /dev/hda8 | 128520 | 17241 | 111279 | 14% | |
| /dev/hda1 | 52288 | 31 | 52257 | 1% | /boot |
| /dev/hda5 | 1026144 | 12836 | 1014108 | 2% | /home |
| /dev/hda6 | 513024 | 86465 | 426559 | 17% | /usr |
| /dev/hda7 | 128520 | 285 | 128325 | 1% | /var |

# Locating Files and Directories

When it comes to trim down a file system's disk usage, the first step is to figure out where the majority of the space is being used. The find and du commands will help you do this.
The -size option to find the command can help find large files by printing the paths to files with sizes over a certain limit. The limit is specified in 512-byte blocks by default, though different versions of find support other units like bytes and kilobytes. Finding all files 1MB in /usr/local is as easy as:

```
bash
find /usr/local -size +2000
/usr/local/bin/bash
/usr/local/lib/gcc-spac-sun-solaris2.8/2.95.2/cc1
```
