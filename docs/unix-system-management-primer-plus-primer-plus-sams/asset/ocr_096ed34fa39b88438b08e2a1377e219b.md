# Viewing RCS Logs

Sometimes you need to look at the log entries for older versions of a file to revert back to a recent usable configuration or just to see who made a change. You can use the rlog command to do this (note that times in RCS logs are reported in GMT).

```
$ rlog httpd.conf

head: 1.3

```

# Viewing Changes Between Revisions

One of the most powerful features of RCS is its ability to display the differences between any two versions of a file. The rcsdiff command displays output similar to that of the Unix diff command. Specify the two versions with distinct -r flags; lines starting with "<" mark lines in the version specified by the first -r flag, and lines starting with ">" mark those from the version in the second -r flag. Compare versions 1.1 and 1.3 of the httpd.conf file used in previous examples, type the following command:

```
bash rcsdiff -r1.1 -r1.3 httpd.conf
==================================================================
RCS file: RCS/httpd.conf,v
retrieving revision 1.1
retrieving revision 1.3
diff -r1.1 -r1.3
==================================================================
237c237
< Port 80

> Port 8080
```
