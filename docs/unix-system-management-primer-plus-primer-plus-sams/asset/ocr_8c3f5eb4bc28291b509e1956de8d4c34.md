You can easily set up cfengine as a front end for cron; the only decision you need to make is the granularity of your scheduling. Should actions be able to run every minute, or are 15-minute intervals adequate? The overhead involved in this use of cfengine is the configuration file parsing, so you have nothing to lose by scheduling cfengine to run often. You can make this decision by looking at your current cron jobs. If none run more than once per hour, you should schedule cfengine to run at least once per month.

Scheduling cfengine to run every 15 minutes from cron is easy, as follows:

```
0,15,30,45 * * * /usr/local/bin/cfengine -f /etc/cfengine
```

# Running cfengine in Daemon Mode

cfengine version 1 includes a daemon cfd that runs on each system using cfengine's control. cfd is controlled remotely by another program called cfrun, allowing you to invoke cfengine remotely. This is very useful when you need to effect a change immediately on all of your systems. cfd requires a configuration file to specify what users and machines are allowed to remotely invoke cfengine. cfd authentication employs a host-user trust mechanism similar to that of hosts authentication, but uses its own file format. See the cfengine documentation for more details about configuring cfd.

# Configuring cfengine

cfengine provides a rich configuration language that can be used to perform tasks from commenting a line in file to scheduling the mass transfer of files across the network. This section introduces the important concepts in cfengine configuration and how to perform some basic tasks. The documentation on the cfengine Web site is highly recommended as a supplement to this section.

# Defining Actions

The cfengine configuration file is usually named cfengine.conf and is divided into sections identified by the name of an action followed by a colon. Actions are predefined and are considered the commands of the cfengine language. For example, the copy action copies files, and the edits action makes changes to lines in configuration files. cfengine version 1 uses 21 total actions; some of the most useful includes the following:

| | |
| --- | --- |
| classes | Defines classes representing groups of hosts |
| control | Defines variables |
| copy | Copies files and sets ownership and permissions |
| edits | Performs various edits on a file, for example, commenting lines and substituting for regular expressions |
| files | Modifies file attributes as owner, group, and permissions |
| links | Creates and removes hard and symbolic links |
