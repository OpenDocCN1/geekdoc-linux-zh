The Linux version of top reports process states a bit differently. The most common states you will see the following:

| | |
|---|---|
| R | Process is currently executing on the CPU |
| S | Process is blocking for I/O |
| T | Process has stopped execution |
| Z | Process is defunct, waiting to be reaped |

# Use prstat on Solaris

Solaris 8 comes with its own top-like called prstat. This CPU-usage by process monitor Solaris-specific, incurs less processing overhead than top, and can report additional details, such as how many threads exist for a particular process.

On a heavily loaded server, you see processes in the run state. This means that the processes are in the run queue waiting for a CPU to become available. Here is the top output for a very busy dual-CPU Oracle server:

```
load averages: 4.51, 4.25, 3.97                11:00:22
149 processes: 143 sleeping, 4 running, 2 on cpu
CPU states: 0.0% idle, 90.8% user, 9.2% kernel, 0.0% swap
Memory: 2048M, 860M free, 688M swap free, in 895M swap free
```
