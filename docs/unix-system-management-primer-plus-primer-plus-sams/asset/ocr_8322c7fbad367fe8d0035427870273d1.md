# UNIX SYSTEM MANAGEMENT PRIMER PLUS

An endless number of vendors sell serial console solutions; this chapter discusses two representative solutions. Both use an RJ45-to-serial connection using standard category 5 cabling, requiring a 9-pin (DB-9) or 25-pin (DB-25) adapter at the server end of the connection. This configuration allows for very densely packed ports on the console hardware and uses standard cabling.

The Digi Terminal Server (www.digi.com) line lies at the low end of the serial console spectrum. These are low-footprint devices that provide up to 32 RJ-45 ports for serial connections. Different models provide different numbers of ports and different access methods. The Digi servers require a server referred to (hereafter as the console server) for remote connectivity, port configuration, and serial communications software, and they're relatively dumb devices.

Two methods are offered: Ethernet and Ethernet. The Ethernet terminal is physically attached to the Ethernet bus on the server (and can be daisy-chained), and the Ethernet model (called EtherLite) can be physically located anywhere, as long as it is accessible through the network from the console server. The Digi hardware is relatively cheap and very effective, but it requires a separate console server to provide the communications software.

At the high-end, enterprise level of the console spectrum is the Lightwave Communications Console Server (http://lightwave.com). Like the Digi console solutions, the Lightwave provides RJ-45 ports for serial connectivity, but that is where the similarity ends. Most obvious difference between the two solutions is that the Lightwave is an all-in-one console; it provides the ports, configuration, network access, and communications software all in one package. It's also modular and capable of taking 4-port cards for additional network, serial, or modem ports. On the software side, the Lightwave server provides more advanced features, such as offline scroll buffers that enable you to see what happened on the console before you actually connected to the port. All of these features come with a price tag, which can add up to ten times more the Digi solution.

# Other Hardware for Out-of-Band Management and Remote Access

Out-of-band management applies to more than just serial consoles. A perfect example of this is remote power control. Have you ever wanted to power on a server from your desk, without having to go to your data center? Perhaps a server is hung completely, and only a power cycle will reset it; in that scenario, a networked or serial power controller is your answer. These power controllers allow you to establish a networked or serial connection to the server and provide an interface for controlling the power on each outlet. It's much better to Telnet and use commands to power cycle your server than it is to drive down to the data center to flip a switch.

Some servers provide their own power management. Sun's Netra line of servers contain a "lights out management" (LOM) module running on a separate circuit from the mother-board.
