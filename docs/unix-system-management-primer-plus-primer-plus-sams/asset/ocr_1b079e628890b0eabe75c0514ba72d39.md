# UNIX SYSTEM MANAGEMENT PRIMER PLUS

The problem with using email to communicate with system users is that sending a single message to thousands of users in a large organization or network can use tremendous system resources. If your user base is more than a hundred people, you would be wise to invest in mailing list software that can create form letters and manage these mailings for you.

Some powerful commercial software can send mass mails like this from your own server, and some companies also provide this functionality on the Web. Some of the well-known mailing list software and Web sites include the following:

+   * Yahoo Groups http://groups.yahoo.com
* Mailman http://www.list.org
* Majordomo http://www.greatcircle.com/majordomo
* LISTSERV http://www.lsoft.com/products/default.asp?item=listserv

# Use a Combination of Communication Methods

Whenever possible, do not limit your communications to a single forum, such as a Web site. You will reach a much wider audience in a shorter period of time if you distribute your message across multiple-forums, since everyone will prefer to use a different forum. Some users may not have access to certain forums at various times (that is, a person on a business trip may only have access to email on his or her pager). As an example, you might announce a Web site outage on the Web site itself, as well as on newsgroup and via email to your clients.

# Dealing with Problem Users

Unfortunately, some users can cause problems for both the administrators of a system and for other users. These "problem users" can range from a newbie who accidentally runs a program that brings a system to its knees, to experienced hackers who are using your server to launch a distributed denial-of-service attack on another site. The following sections take a close look at the problems a user can potentially create and some practical solutions for those.
