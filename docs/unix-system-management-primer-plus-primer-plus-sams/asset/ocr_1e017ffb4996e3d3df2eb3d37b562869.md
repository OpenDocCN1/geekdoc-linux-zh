# Twist-Lock Plugs Secure Connections

Some NEMA plugs and outlets offer twist-lock connections. Twist-lock plugs insert into the appropriate outlet just like any other plug, but then are locked into place when turned. This protects the cable from being accidentally unplugged. A loose plug connection to a high-voltage circuit can be dangerous; twist-lock connections eliminate this danger.
