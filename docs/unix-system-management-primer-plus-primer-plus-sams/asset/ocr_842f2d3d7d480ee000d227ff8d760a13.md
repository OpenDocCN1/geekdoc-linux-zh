# Creating Distfile Rules

distfile rules have the following format:

```
label: source_list -> destination_list command_list
source_list contains the files to be distributed, destination_list contains the list of hosts where the files should be distributed, and command_list is a list of optional commands to run on the remote host before or after copying files. If one of the sources is a directory, it is recursively copied to the destinations. label is an optional label that can be used on the command line to selectively run just parts of the distfile. Wildcards such as * and ? can be used in the list of source files.
```

Using the previously listed variable declarations to distribute the directory specified in the FILES to the hosts in WEBSVERS, you can write the following distfile:

```
WEBSVERS = (dopy grumpy sneaky doc )
FILES = ( /usr/local/apache/conf
```

web: ${FILES} -> ${WEBSVERS}
Rules can also contain primitives, which are actions that rdist should take when updating remote files. Primitives are listed just below each rule, one ending with a semicolon. Some of the more useful primitives are as follows:

| except filename... | Omits files from distribution |
|---|---|
| except_pat pattern... | Omits files that match the patterns from distribution |
| install [options] destination-name | Installs a file with a different name than its source, which is useful for installing in a different directory than the location of the source files. . |
| notify address... | Sends email to each address that lists the updated files and any errors that occurred. |
| special [filename]...command-line | Runs a shell command after each file listed is updated. If no files are specified, run the command for every file that is updated under that rule. |
| cmdspecial command-line | Runs a shell command after all of the files are updated. |
