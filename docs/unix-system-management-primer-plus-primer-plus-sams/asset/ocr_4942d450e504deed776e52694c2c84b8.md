# UNIX SYSTEM MANAGEMENT PRIMER PLUS

The message of the day is a simple text file, located at /etc/motd, that is displayed every time a user logs in. Among other notices, you should mention where to go for help with the particular system user has logged into. Provide as much information as possible, including Web sites, phone numbers, without going overboard; users won't read long overlooked messages, Here's an example of such a message:

********* NOTICE ********

This system is part of the Fictional Production Environment. Use of this system implies consent to the monitoring and logging of all activities and data on this machine.\ All questions, comments and suggestions should be sent to admin@example.com or call extension 4500 to reach the help desk.

Although a message in the motd can be very effective, users may not always remember what it said hour their session. There are many other mechanisms for disseminating this kind of information to your users, including Web sites and paper documentation, which you can read more about Chapter 15, "Interacting with Users."

# Summary

Support is a critical part of any IT infrastructure. If you have a product, which in our case is a collection of systems and software, you need to support the people using them. Although not all organizations need a three-tiered model, some sort of support system should be in place to appease the masses. In a 24/7 production environment, system administrators at the very least should be available on the back end of this support infrastructure in an on-call capacity, and implementing a rotation schedule to prevent system administrator burnout during heavy "fighting" periods.

The tools used by support staff are also important. Both complex help desk management systems like Remedy and simple banner messages like a note in the message of the day may make communication between customers, the help desk, and engineers' much easier. At the end of the day, happy engineers are those who spend their day engineering, not managing trouble.
