The most significant feature that logsurfer offers is the addition of dynamic rules. Dynamic rules are created on the fly to handle certain situations as they happen. For example, in what, if the /var file system filled up a server, your email, pager, and every other mechanism you set up for notification will be full of thousands of messages like this:

Nov 26 18:43:03 server1 ufs: NOTICE: /var: file system full

You'd receive thousands of these messages because they would be generated by the kernel for every unsuccessful write to the fully full file. Swatch would act on each of them independently; if you paged for file system full errors, your battery would soon need replaced.

Logsurfer can handle this much more gracefully. You could create a dynamic rule that ignores file system errors for a particular server after the first message had been received, as follows:

+   "file system full" . . 0 continue
pipe `/usr/local/bin/logmail`
"file system full" . . 0
rule top "file system full" . . 900 ignore

The first rule pipes the first message to logmail. The second rule creates a new rule that ignores the file system full pattern for 900 seconds (15 minutes). It does this by inserting the rule on top of all other rules (in the top in rule). Instead of getting thousands of notifications that the file system was full, you'd get one every 15 minutes, a more subtle reminder that your server needs you.

# Notification

All the monitoring in the world won't do any good if you're not notified about outages. There are various notification methods to choose from, and picking the right one depends on your needs and capabilities. The most important factor to consider when making this choice is reliability, emergencies can happen at any time, and your notification system needs to be able to get in touch with you any time. Systems use a variety of notification systems, including pagers, cell phones, email, and instant messaging. The following sections describe using these options individually or in combination to provide emergency notification for your system.
