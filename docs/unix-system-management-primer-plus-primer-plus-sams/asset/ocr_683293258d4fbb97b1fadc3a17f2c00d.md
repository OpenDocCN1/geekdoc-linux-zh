# More Data Points Equals Greater Accuracy

When plotting a graph to look for patterns, you should plot as many data points as possible. An ample number of data points reveals the true pattern of the graph and produces more accurate results.

# Identifying Linear Versus Geometric Relationships Between Load Increases and System Stress

In the last phase of load testing, you must determine whether the load increases linearly or geometrically as you add stress to the system. The relationship between the inputs to your system and its resulting performance is important, both for the testing phase and capacity planning down road. In the previous section, you could interpolate the number of connections it took to reach the 7-second response time threshold because that relationship was linear; the response time always increased by the same amount for each concurrent connection added to the system.

In the example, each additional connection incurred an average of 0.035 seconds of additional response time. The graph verifies this by showing a fairly straight line through the data points. Linear relationships are a boon to testing and capacity planning because they make it easy to predict unknown performance numbers from known inputs.
