# Load Testing

Load tests measure the performance of a system under stress. These tests try to mimic the worst of conditions the system might experience in production, and they attempt to answer the following questions:

+   - Can the system function normally within the required performance specifications?
- At what point does the system not meet the requirements?
- Does load increase linearly or geometrically as you add stress to the system?

# Determining Load Test Parameters

A load test stresses a system and monitors its performance under this load. The numbers a load test reports back to mean nothing, however, without context. In general, you structure the load test with the following specifications to obtain valuable results:

+   - The mechanism used to stress the system
- How much load to introduce into the system
- The units in which performance will be measured (for example, pages served per second on a web server)
- Range of acceptable performance levels

These specifications enable you to assess the level of performance exhibited by the system under a certain type of load, based on your range of acceptable performance.

# Conducting Load Tests

Specific load test procedures, like the procedures for other system tests, vary according to the application you are testing. The requirements for load tests, however, are always the same. Typically you need a source of stress, also known as a load generator. The load generator need to know what to stress and how much load to introduce into the system.

There are two major types of load tests:

+   - Constant load tests introduce constant levels of stress (usually in the form of service requests) into a system and report performance based on the average time it takes to complete each request. This data is useful for predicting a system's performance under known conditions. For example, if an ISP's trends indicate that 5,000 users would be reading their mail at the same time within a year, the ISP could load its mail servers with 5,000 concurrent mail operations to ascertain its performance under those conditions.
