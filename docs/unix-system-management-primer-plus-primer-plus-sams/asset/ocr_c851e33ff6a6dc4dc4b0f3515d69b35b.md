# SainsEnt

SainsEnt (http://www.sainsaint.org) is a free, open-source network monitor. Building from source code is hassle free, and once configured, it is mostly maintenance free—an excellence in a monitoring system. SainsEnt is not a full-featured enterprise system such as Netcool. Instead, SainsEnt does one thing—monitoring—and it does well.

SainsEnt plugins allow for a variety of standard and third-party service monitors. Old favorites like HTTP, FTP, POP3, and NNTP code standard, as well as an Oracle plugin that makes sure applications can connect to your Oracle databases. These service monitors work much like Netcools; they run from the monitoring server and access services as a user. If you have an in-house application, you can use your own plugin to monitor it—just one of the benefits of open source.

SainsEnt's user interface is provided by a CGI applications and requires a Web server like Apache. Most monitoring functions can be accessed via the Web, including the status of each host and summary views (see Figure 6.5), and the history of all for your systems.
