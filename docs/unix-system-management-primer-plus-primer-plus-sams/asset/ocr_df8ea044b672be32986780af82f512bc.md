The crontab is made up of fields, listed in Table 12.1.

# TABLE 12.1 crontab Field Descriptions, in Order from Left to Right (When Read from the
crontab)

| Field | Format |
|---|---|
| Minute | Integers from 0–59 or * |
| Hour | Integers from 0–23 or * |
| Day of month | Integers from 1–31 or * |
| Month of year | Integers from 1–12 or * |
| Day of week | Integers from 0–6 (0=Sunday) or * |
| Command | The commands to execute |

Each field can contain multiple values separated by commas, and the asterisk is used to indi-
cate possible values of the field. Alternatively, vixie-cron, which is available on most
Linux distributions, allows you to specify time intervals as well as absolute times using a slash
followed by the interval. For example, to run the command /usr/local/bin/cleanup every 5
minutes, you could type

```
*5 * * * * /usr/local/bin/cleanup
```

while a System V crontab would be forced to specify each time individually, as follows:
0,5,10,15,20,25,30,35,40,45,50,55 *usr/local/bin/cleanup

# Edit Crontabs

Using the crontab command to edit propagates your changes and even
checks for errors in your entries. If you edit a crontab file directly (usually found in a subdirect of
/var/spool/cron) without running crontab, you may have to restart the cron daemon cron to
make those changes effective.
