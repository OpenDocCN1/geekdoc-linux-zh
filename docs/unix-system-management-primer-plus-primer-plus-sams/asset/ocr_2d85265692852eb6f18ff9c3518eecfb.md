Unix was not originally designed with security in mind; but as time passed, operating system vendors and third-party developers realized the importance of system security and began to integrate security features into applications and operating systems. As the Internet enabled more and more people to access remote computing resources, the security of those resources became a growing concern. The 1990s saw a boom in local and remote exploits—mechanisms used to gain unauthorized access to a system—that allowed unauthorized access to unsecured systems. The system administration community and the vendors that served them were forced to respond to these security breaches. Today, every Unix operating system contains advanced security features that allow administrators to implement and fine-tune security measures such as authentication, authorization, accounting, and data encryption. This chapter explores security on Unix systems; it discusses how hackers find and exploit weaknesses, and how a system administrator can take advantage of the security features available on an operating system to prevent such exploits.
