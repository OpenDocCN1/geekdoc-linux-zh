# UNIX SYSTEM MANAGEMENT PRIMER PLUS

To detect unnecessary services, check `inetd.conf` and note every line that is uncommented. Determine whether you really need each service, and comment out the ones you don't need. If you are unfamiliar with any particular service, check your operating system documentation to see if it is critical. You may end up with only one or two services left, such as `telnet` and `ftpd`. When you have finished eliminating unnecessary services, restart `inetd` by sending a HUP signal to the process (`kill -HUP PID`).

# OpenBSD Security

OpenBSD is famous for being "secure by default." This security is apparent in its `inetd.conf` file, where most services are actually disabled. Other operating systems typically leave everything enabled for a friendlier user experience.

# Requiring Secure Passwords

Your users are responsible for maintaining system security, too. One of the simplest contributions a user can make to system security is choosing a secure password. A secure password is one that cannot be easily guessed or cracked using a dictionary attack.

Secure passwords contain a combination of letters, numbers, and punctuation. Many Unix implementations of `passwd` require passwords of six or more characters in length containing at least one letter, one number, and one punctuation character; some even allow you to tune this policy.

An example of an insecure password is "secure", which is an easily guessable word. A more secure password would be `tlavsp!`, which is derived from the phrase, "this is a very secure password." It contains letters, numbers, punctuation, and does not contain any recognizable words.

To maintain password security, users should change their passwords periodically. This practice makes passwords a moving target for anyone trying to break into an account. Password aging policies force users to change their passwords on a regular basis and are tunable on every Unix system. # Password Aging for Applications That Do Not Use PAM

Third-party applications that do not use PAM or a PAM-enabled login program support password aging policies on their own. This group includes all of the services available on OpenBSD, which does not natively support PAM.
