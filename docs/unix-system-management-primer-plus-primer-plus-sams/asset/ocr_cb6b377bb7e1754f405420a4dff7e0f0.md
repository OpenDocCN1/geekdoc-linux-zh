The statistic most directly related to disk performance is avserv: The average service time is the time it takes to fulfill a request for disk I/O from the operating system. This transaction involves many individual processes, for seeking the physical position of the data on the disk platters to the actual transfer of data. Service times in the hundreds of milliseconds should be considered excessive for modern disks, but disk activity can skew this data.

A disk with files that are not actively being used may have cached data flushed periodically by the kernel. This activity can interfere with user disk I/O, causing high service times. You can use vmstat to check file system activity, fpi, fpo, and fpf report system page-ins, page-outs, and page-frees respectively. If file system activity is low (zero or intermittent single-digit values), you can safely ignore the high service times on them. If the file system activity is high, however, you may want to examine the usage of the file systems (and potentially swap space) on the disk and spread the more active files across multiple disks.
