# Staying Up-to-Date Through Security Forums

Security is a dynamic field, with new bugs, exploits, patches, global incidents, and applications being announced every day. A number of forums, including security mailing lists, security Web sites, newsgroups, and conferences, can help you learn more about security and keep abreast of any new developments.

Following are some of the most popular security mailing lists. You should also subscribe to lists for your own operating system.

+   * **Bugtrap** Moderated list for discussion of security vulnerabilities and fixes. `http://www.securityfocus.com/popups/bugtraq/intro.shtml`
* **CERT Advisory List** Authoritative source of security advisories and summaries. `http://www.cert.org/contact_cert-certmaillist.html`
* **INCIDENTS** Lightly moderated forum for discussing actual security incidents and how to manage them. `http://online.securityfocus.com/popups/forums/incidents/intro.shtml`
* **Red Hat Linux Mailing List** Announcements about Red Hat Linux security vulnerabilities, fixes, and patches. `http://www.redhat.com/mailing-lists/linux-security`
* **Sun Mailing List** Announcements about Sun security vulnerabilities, fixes, and patches. Send email to `security-alert@sun.com` with the content "subscribe cws_your-address@".

You might want to visit these Security Web sites:

+   * **Coordination Center** Comprehensive site containing information about alerts, incident management, and security research. `http://www.cert.org`
* **COAST** The Computer Operations, Audit, and Security Technology home page. Security research and papers. `http://www.cerias.edu/coast`
* **Security Focus** A security portal. `http://www.securityfocus.com`

These security newsgroups are valuable sources of information:

+   * comp.security.misc General security issues
* comp.unix.security Unix security issues
