# Solaris Buffer Overflow Protection

Solaris 2.6 and later are able to detect, log, and prevent attempts to execute code on the stack. This eliminates many but not all, buffer overflows. Just put the following lines in /etc/system, reboot, and watch your system logs:

```
set noexec_user_stack=1
set noexec_user_stack=1
```

When a user runs a program that executes code on the stack, that program is killed and a message like the following is sent to syslog:
myprog[6617] attempt to execute code on stack by uid 1000
