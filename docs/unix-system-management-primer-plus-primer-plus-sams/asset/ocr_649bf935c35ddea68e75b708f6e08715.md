This problem can be solved by enhancing the other methods of load balancing with server weighting. Weighting associates a weight, or ratio, with each server on the back end that determines what ratio of requests should be sent to each server (see Figure 10.3). If server2 can handle twice as many requests as server1(because, for example, server2 has two CPUs as server1 has), its weight should be double that of server1. The load balancer will take this into account and send two requests to server2 for every one it sends to server1. otherwise, capable load balancing makes efficient use of the resources on the back end; otherwise, less-capable machines would be overloaded while more-capable machines were partially idle.

# Choosing Load-Balancing Schemes for Unix Applications

It's not always easy to determine which type of load-balancing scheme is best suited to your network application. Sometimes only trial and error can provide the answers for you. Table 10.1 is a list of common Unix network applications and the load-balancing schemes that have proven to be the most efficient for those applications. Your results may vary, but this data is a good starting point.
