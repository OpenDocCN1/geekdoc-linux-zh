Specify Titles, Not Names
Always use titles instead of individual names in your security policy. You want to be able to apply this document to the whole of your organization without changing it every time someone is hired or fired.

# Controlling Electronic Data Security

The security and integrity of electronic data is critical to every organization with a computing infrastructure. Your security policy should define how your data is to be protected on the system level. Some things you might find in this part of a security policy include the following:

+   - Password selection guidelines
- Password expiration schedule
- File permission guidelines
- Group membership guidelines
- File encryption requirements
- Network traffic encryption requirements
- Remote access requirements
- Privacy requirements
- Email content restrictions
- Procedures for granting access to new hires and revoking access from terminated employees
