# Chapter 4 • TESTING YOUR SYSTEMS

Experimentation is also a valuable method to determine the average end user response. This is especially true if you don't have pre-existing logs. Try using the site yourself and see how long it takes for you to fill out each form.

To understand the load-testing process in action, return to the bank Web-server example. Nearest Integer Savings is pleased with the deployment of its new online banking servers, but you must now test the servers to determine whether they can handle the load they are expected to carry.

The marketing department estimates that up to 5,000 customers might register and use the new service at the same time, following major advertising campaigns; then usage should level off at a peak of 3,000 concurrent users. The system must serve each page in less than 7 seconds (an average standard for how long the end user will wait for a page to load). Load the Web servers by introducing an artificial representative load on the system.

# Functioning Within Specifications

The first phase of the load test in this example determines whether the bank's Web server functions within specifications—in other words, can it serve in 7 seconds or under with 5,000 concurrent user sessions? You can't expect to have 5,000 people available to use the site at any given time, so use one of the countless load simulator tools online.

For this phase of the test, you will test the site with up to 333 concurrent connections (the average number you've calculated on user practice calculations, system logs, and so on). In this example, you test with the load-simulator tool Siege, an open source tool (http://joedog.org/siege) Siege can submit all kinds of HTTP requests concurrently and report the results at the end of the test.

Begin the test by establishing a baseline against which you will compare future results. Tell Siege to request a minimal amount of dynamic pages, say 30 seconds of 3 concurrent requests with a random delay of up to 20 seconds between requests to simulate human interaction. Here's the output:
