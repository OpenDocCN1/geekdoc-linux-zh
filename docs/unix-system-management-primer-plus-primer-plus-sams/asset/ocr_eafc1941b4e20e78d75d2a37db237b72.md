# Monitoring the Integrity of Your File Systems

With hundreds of thousands of files on the average Unix system, it can be hard to keep up with all of the changes. In fact, without safeguards in place, many file changes can go unnoticed by system administrators for days, even weeks. You don't need to worry about changes made by other administrators, but you must be immediately aware of changes resulting from hacker hacking into your system and tampering with configuration files.

Various tools are available to monitor the contents of your file systems, the most popular being Tripwire®. You can download Tripwire from http://www.tripwiresecurity.com/products/index.cfm?-it is now a commercial product purchasing, but older versions are freely available from this and other sites.

Tripwire works by creating a database of file metadata such as permissions, ownership, modification time, and MD5 checksums. Subsequent runs of Tripwire check each file on the system against the information in its database and report any inconsistencies. It can also report any new or missing files. Exceptions can be made for files that are expected to change, such as log files.

# Maintain Database Security

The most important factor in maintaining file integrity systems is to keep the file database secure. The database should never be stored on the same machine used to generate it; if you have no other choice, store the database in a read-only format (like a CD-ROM) so there is no chance of compromise.
