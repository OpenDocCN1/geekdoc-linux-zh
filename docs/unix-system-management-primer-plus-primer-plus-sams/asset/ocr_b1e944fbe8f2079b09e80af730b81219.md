# Gauging Storage Performance and Capacity

The performance of storage devices, hard disks in particular, is vital to the performance of a system because absolutely everything is stored there, including the operating system, applications, and data type. Swap space is located on disk as well—a poorly performing swap partition can severely degrade the performance of a system, especially in low-memory conditions.

To fully understand how to assess and optimize storage performance and capacity, you must first understand certain basic concepts and terms, including storage capacity, disk architecture, bandwidth, latency, sequential and random access, block and character I/O, and inodes. After defining each of these items, the following sections also discuss some of the most useful tools and techniques for examining disk performance and capacity.

# Understanding Storage Capacity

One of the most confusing issues in computing is the conflict between the definition of a kilobyte on disk and in memory. A kilobyte is defined as $2^{10}$ or 1,024 bytes, and larger units are multiples of number. These measurements are based on the fact that computers work in binary, and 1,024 is the power of two closest to 1,000.

Disk terminology evolved in a different fashion, using powers of ten instead of powers of two. On disk, a kilobyte is equal to 1,000 bytes (a metric measurement). Table 11.2 shows the version between the two measurements.

**Table 11.2** Disk Capacity Versus Memory Capacity

| Unit | Bytes on Disk | Bytes in Memory |
|---|---|--|
| Kilobyte | 1,000 | 1,024 |
| Megabyte | 1,000,000 | 1,048,576 |
| Gigabyte | 1,000,000,000 | 1,073,741,824 |
| Terabyte | 1,000,000,000,000 | 1,099,511,627,776 |
