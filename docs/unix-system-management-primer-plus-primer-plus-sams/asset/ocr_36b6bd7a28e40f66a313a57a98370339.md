Description:
The sed (StreamEditor) editor is a stream or batch (non-interactive) editor. sed takes input, performs an operation or series of operations on the text and outputs the modified text. The operations that perform substitutions (substitutions, deletions, insertions, etc.) can be specified in a script file or from the command line.

RPM really excels in its dependency engine—though Although RPM dependency checking works well, it only works if all of a package's dependencies were installed with RPM. In other words, RPM knows only about things it worked before. If you install Perl by hand (without RPM), and a new package requires Perl, RPM won't see it in the database. In situation, RPM tells you that the dependency check failed, even if Perl is installed on your machine. This limitation can be very frustrating; fortunately, you can force the installation of packages even when the dependency checks fail, although this circumvents a lot of RPM consistency checking.

To better understand dependencies, consider sed, the Unix stream editor. On Red Hat 7.0, it has nine different dependencies; each of these must have been installed by RPM for the dependency check to work properly.

# Use Source RPMs to Tweak Software Code

RPM can either install binary packages or build from source. If you download a source RPM, you get the original source code, which you can tweak to your heart's content. RPM will take care of compiling and installing everything for you. All of Red Hat software is available in RPM format to boot. And you can turn and build your own custom RPMs that include scripts at the end, so you can take whatever fussed through on one machine and automate on other machines that need the same setup. You can also build your own RPMs, with or without source code. The process can be quite lengthy, but the "HOWTO" document at
://www.rpm.org/RPM-HOWTO describes it very well.
