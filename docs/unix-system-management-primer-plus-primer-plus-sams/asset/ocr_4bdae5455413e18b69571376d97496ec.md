# Removing World-Writable Permissions (find Command)

World-writable files and directories have the other bit set in their permissions, allowing anyone to write to them. This permission can have the following consequences:

+   - Users can change the contents of another user's files or even a system configuration file.
- In world-writable directories, users can delete or rename other users' files.
- Users can fill up file systems like / and /var to capacity.
- Users can use world-writable directories as personal file stores that may not count against their quota.

To remove these permissions, you must first locate the directories and files that have them. The following find command locates all world-writable files and directories on a system, ignoring symbolic links:

```
# find / -perm -+w -type l
```

# Don't Change Permissions on /dev Device Files

Most files in /dev need to have world-writable permission. Don't change permissions on these unless you know exactly what you are doing.

Some directories like /tmp and /var/tmp are meant to store files from any user temporarily, as they need to be world writable. However, in a standard world-writable directory, users can delete or rename other users' files, which is an unacceptable situation. The sticky bit (the "t" at the end of the permissions output in ls) alleviates this problem by preventing other users from deleting or renaming files they do not own. Note the "t" in the permissions for /tmp in ls output:

```
drwxrwxrwt  3  root  1024 Apr 20 16:53 /tmp
```

If you need to create a world-writable directory for any reason, activate the sticky bit by typing chmod +t directory.

# Installing TCP Wrappers

The TCP Wrappers package is briefly discussed in Chapter 15, "Interacting with Users." This software allows you to "wrap" almost any network service to provide address-based security. For example, you can choose to allow only your internal network to Telnet to your servers, and deny everyone else. You can also log attempts to access your services and even launch supplementary processes for each connection. TCP Wrappers is installed by default on Linux distributions and OpenBSD; for other operating systems, you can download it from ftp://ftp.cerias.purdue.edu/pub/tools/unix/netutils/tcp_wrappers.
