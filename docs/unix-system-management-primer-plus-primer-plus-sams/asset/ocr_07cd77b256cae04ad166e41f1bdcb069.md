# Using rdist to Distribute Files

All of the tools mentioned so far are concerned with copying or synchronizing files and directories; they have no provisions for relocating or renaming individual files in a large directory, or for copying more than one destination. rdist is a program for distributing files from a central repository to multiple remote hosts based on rules contained in a configuration file.

Almost all Unix distributions include a version of rdist, though it is usually an older version based on the original BSD 4.2 rdist. Newer versions with more functionality exist; the most popular of them is Magnicmp's rdist, which can be downloaded at http://www.magnicomp.com/rdist.

The rdist configuration file is called the distfile; it contains all of the definitions and rules rdist needs to properly distribute files. You can specify the distfile to use with the -f flag; otherwise rdist looks for a named distfile in the current directory.

The two major components of distfile are variables and rules. Variables are useful for creating a single name that refers to multiple files or hostnames, which in a larger distfile could become quite confusing. Rules dictate which distfile are used to distribute remote hosts. The following sections describe how to use these distfile components.

# Using Variables in a distfile

The parentheses are required when assigning list of values to a variable. A typical distfile for an Apache Web server configuration may have variable assignments like these:

```
WEBSERVERS = ( dopey grumpy sneaky doc )
DEVSERVERS = ( sleepy happy bashful )
FILES = ( /usr/local/apache/conf )
```

The value of a variable is referenced with the ${ construct; the value of the FILES variable in the previous example is ${FILES}.
