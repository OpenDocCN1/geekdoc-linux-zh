Where NetSaint fails to fall short in its configuration. In a very obfuscated and busy-looking file; it contains every host and service that NetSaint monitors, in addition to contact information, notification methods, and host dependencies. Other files store contact information and monitoring commands. The distribution itself provides no configuration application; you have to create the configuration files on your own using a set of sample files.

A variety of third-party NetSaint configuration applications are available, and they make administration of the server much easier. The most popular of these is NEAT (NetSaint Easy Administration Tool), another CGI program that provides a Web-based administration tool for editing NetSaint configuration files. If you use a large network, use of an administration tool like NEAT is highly recommended. You can find it on the NetSaint downloads page at http://www.netsaint.org/download.

That said, once NetSaint is configured, it does the job well, and quite at that. Months pass without notifications from NetSaint; it is not chatty and won't produce many (if) false alarms. If you don't have the budget to spend money on something like NetCool, NetSaint is a nice (and free) alternative.

# Big Brother

Big Brother (http://www.bb4.com) is a monitoring system that takes a slightly different approach to system monitoring. In services like POP and HTTP from a central server

You configure Big Brother through various confusing configuration files, which can be frustrating to work with. But as a Unix administrator, you should be able to manage this task.

The Big Brother user interface is Web based and can display the status of all of your hosts in a table on one Web page. This all-in-one view is a real time saver, as you can see the status of your entire network with a quick glance. Icons indicate the status of each monitored service, which is one of following: OK, attention, trouble, report, unavailable, or offline.

Many people shy from Big Brother because it is more difficult to configure and doesn't look as pretty as other systems. It is very effective and has a large following on the Internet, where you can always find help with configuration, bugs, and plugins. In addition to the help you'll receive from those sources, Big Brother is available for an annual fee, as well.

Big Brother is free for non-commercial use, but if you're a business, you'll have to spend some money for a license. Fortunately, as of time of this writing, the licenses are not expensive by any means compared to other solutions.
