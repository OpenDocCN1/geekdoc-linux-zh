# Gauging CPU Performance and Capacity

The CPU is the heart of any system and as such plays a central role in the system's overall performance. Many aspects of a system can affect its processors, so CPU tuning and capacity planning can be a very complex task. The next sections detail the nature of Unix CPU usage and how to use Unix tools to diagnose CPU problems and plan for the future.

# Interpreting Load Averages

Many users and administrators associate a high load average with overworked CPUs, yet they don't know what a load average really is. A load average is number of runnable processes active on the system over a set period of time. Runnable processes currently running processes and those on the run queue. Run queues are Unix kernel structures that hold pointers to processes that are able to run but are not currently running on any CPU.

# Not All Processes Are Included in a Load Average

The run queue used to calculate a load average does not include queues for processes that are blocking (usually waiting for I/O) or swapped out to disk. The existence of these processes is not related to a CPU's performance.

The uptime command is universal to all Unix flavors and can be used to examine the load averages for a machine, as follows:

```
$$ sh sh uptime
7:02pm up 143 day(s), 13:44, 0 users, load average: 1.87, 0.92, 0.81
```

# An Alternate Way to Report Load Averages

Load averages are also reported in the first line of the output of the w command.

The three averages reported in the example represent the load over a period of 1, 5, and 15 minutes respectively (when read from left to right). The 1-minute load average is representative of the short-term processing load, while the 15-minute average is a long-term load measurement. During bursts of CPU activity, high 1-minute load averages alongside low 15-minute load averages can occur.

A load average is significant in terms of the number of processors on a machine. In general, a load average that is less than the number of installed processors means that a system has adequate processor power. A four-processor machine with a load average of 3.5 is not overloaded—it's fully utilizing its resources.
