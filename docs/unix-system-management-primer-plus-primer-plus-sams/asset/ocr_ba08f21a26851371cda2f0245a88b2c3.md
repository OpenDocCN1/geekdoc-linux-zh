# # Redirecting Output from at and cron

Both at and cron run with no controlling terminal, but their output needs to be sent some-where. By default the output is mailed to the local user on the local machine, which may or may not be checked often or forwarded to another address. An alternative is to redirect the output to a file using the > or >> redirection operators. Many administrators choose to ignore the output of their jobs; if you choose this approach, you can redirect to /dev/null, the black hole of Unix devices.

```
30 1 * * /usr/local/bin/cleanup > /dev/null 2>&1
```

2&1 is necessary to redirect standard error to /dev/null as well as standard output.

# # Controlling Access to at and cron

at and cron are very useful scheduling tools, but it is all too easy for the uninitiated user to abuse this privilege. Users might, for example, schedule several CPU-intensive tasks during peak usage times, or do something more malicious, such as launching scheduled denial of service attacks against other servers without being logged into the machine. Both at and cron support "allow" and "deny" files: you can use these files to specify which users are allowed to use these facilities, and which are not.

These access-controlling files, called cron.allow, cron.deny, at.allow, and at.deny, are located in /etc/cron.d on Solaris, and in /etc on Red Linux. The behavior of at and cron depends on which of these files exist, and whether they are populated with usernames. Table 12.2 summarizes this behavior.

TABLE 12.2 Access Control Behavior for at and cron
| Allow File | Deny File | Resulting Access |
| No | No | Site dependent |
| Yes | No | Users listed in allow file |
| No | Yes | Users not listed in deny file |
| Yes | Yes | Users in allow file but not in deny file |

> No Allow or Deny Files?
Neither the allow nor deny file exists, the resulting access depends on your operating system; in most cases only root has access. If neither the allow nor deny files exist on Solaris 8, only users with the solaris.jobs.user authorization can submit a job.
