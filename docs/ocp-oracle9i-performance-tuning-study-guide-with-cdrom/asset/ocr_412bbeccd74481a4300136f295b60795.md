# **FIGURE 10.2** Sample top output

The top portion of the output in Figure 10.2 shows that this server has two CPUs (0 and 1) that are currently 99.8 percent and 98.6 percent idle, respectively. Further down in the output, you can see that six Oracle processes are running, each utilizing one or the other of the CPUs to perform their processing.

> Oracle recommends keeping CPU utilization below 90 percent for optimal performance. Oracle also recommends configuring multiple CPU servers so that each CPU performs approximately the same amount of processing.

The Windows 2000 Task Manager’s Performance tab discussed in the previous section can also be used to monitor CPU utilization, as shown in Figure 10.3.
