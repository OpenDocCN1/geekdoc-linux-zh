+   **10. C.** Doing a SHUTDOWN ABORT does not cause a checkpoint to occur, so no dirty blocks will be written by DBW0. A shutdown of this type means that instance recovery is necessary when the database is restarted. Placing the database in hot backup mode, shutdown immediate, and forcing a log switch all cause DBW0 to write dirty blocks to disk. See Chapter 5 for more details.

The Database Buffer Cache is the location where Oracle retains the most-recently used data. The Redo Log Buffers contain recovery information for recently executed data modifications, and the large pool is used for, among other things, the Oracle Shared Server. See Chapter 4 for more details.
