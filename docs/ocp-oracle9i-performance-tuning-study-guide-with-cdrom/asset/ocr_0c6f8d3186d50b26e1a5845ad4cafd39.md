# The Alert Log

The Oracle Alert log records informational and error messages for a variety of activities that have occurred against the database during its operation. These activities are recorded in chronological order from the oldest to most recent. The Alert log is found in the directory specified by the init.ora parameter BACKGROUND_DUMP_DEST. On systems that follow the Optimal Flexible Architecture (OFA) model recommended by Oracle, this directory will be $ORACLE_BASE\admin/SID/bdump on Unix systems and %ORACLE_BASE%\admin/SID/bdump on Windows 2000 systems, where SID represents the name of the Oracle instance that will be creating the Alert log.
