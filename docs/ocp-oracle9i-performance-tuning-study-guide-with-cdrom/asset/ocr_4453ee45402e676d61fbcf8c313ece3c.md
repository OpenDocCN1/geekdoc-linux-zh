# ## Measuring Java Pool Performance Using V$SGASTAT

You can use the POOL column in the dynamic performance view V$SGASTAT to track how the memory allocated to the Java Pool is being utilized:

```
```
SQL> SELECT name, bytes
2    FROM v$sgastat
3    WHERE pool = 'java pool';
```
```

| NAME | BYTES |
| --- | --- |
| free memory | 58720256 |
| memory in use | 277821 |

The value for free memory shown in this view can be used to help tune the size of the Java Pool. If V$SGASTAT shows high or increasing values for free memory when compared to memory in use, you have probably overallocated space to the Java Pool. If you have low or decreasing values for Free memory, you may need to consider increasing the Java Pool size.
