**During application design**  As mentioned previously, the majority of application performance problems stem from poor design decisions made early in the development process. One example of this is excessively normalized database designs that require extensive joins to produce useful output.

**Configuring a new system**  Whenever new systems are implemented, important decisions regarding the choice of operating system, server hardware, optional Oracle features, and network connectivity will all have an impact on the performance of the system.
