The `SWITCH_TIME` parameter (default value 1,000,000) is used to specify the duration, in seconds, that a session must be active before Resource Manager switches the session to the group specified by `SWITCH_GROUP` parameter (default value NULL). If the `SWITCH_ESTIMATE` parameter (default value FALSE) is set to TRUE, then Resource Manager will use the estimated execution time to decide whether to assign the session to the `SWITCH_GROUP` before execution even begins, without waiting for the execution time to actually exceed the value specified by `SWITCH_TIME`.

# ## Setting Instance Resource Objectives

Any of the defined resource plans can be activated for the instance. However, only one resource plan can be active at a time. The active resource plan for the instance can be defined using the `RESOURCE_MANAGER_PLAN` parameter in `init.ora`, or by dynamically issuing the `ALTER SYSTEM SET RESOURCE_MANAGER_PLAN` command to specify which resource plan is active for the instance. If this parameter is not set, then the features of Resource Manager are disabled.
