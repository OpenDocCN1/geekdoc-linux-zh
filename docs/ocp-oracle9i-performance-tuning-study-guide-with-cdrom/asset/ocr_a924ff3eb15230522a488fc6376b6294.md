# **TABLE 10.3** Commands to Monitor Paging and Swapping on Unix Systems (*continued*)

| Command | Description |
| :--- | :--- |
| vmstat | Displays system-wide information about the paging activities on the server. |
| sar | Used with the -r, -g, and -p flags, this command also displays system-wide paging information. |

Windows 2000 systems utilize paging only for their memory management; swapping is not considered. The Kernel Memory section of the Performance tab in the Windows 2000 Task Manager utility is an easy way to monitor paging activities on a Windows 2000 server.
