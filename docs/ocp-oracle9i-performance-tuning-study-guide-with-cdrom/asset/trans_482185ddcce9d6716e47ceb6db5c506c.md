
## 术语表

哈希值
将值传入哈希算法后，该算法返回的值。

堆表
其行未按任何特定顺序存储的表。相反，行的存储顺序取决于可用块进入和离开自由列表的顺序。

高水位标记
用于存储表数据的最高块编号所对应的块ID。在执行全表扫描期间，会读取高水位标记块及之前所有块。

提示
嵌入在SQL语句注释中的关键字，这些关键字会导致Oracle优化器以特定方式运行。

直方图
用于告知基于成本的优化器特定列中数据实际分布的统计信息。

命中率
用于计算用户多频繁地发现其请求的SQL和数据缓冲区已经缓存在内存中的指标。

即时闩锁
一种闩锁类型，立即重试获取先前忙碌的闩锁，而不等待。

索引集群
一种技术，用于将来自一个或多个表的数据存储在同一物理块中。

索引组织表 (IOT)
数据在物理上存储在索引中找到的相同B-树结构中的表。

init.ora
包含数据库和实例配置参数的物理文件。

实例
与Oracle数据库关联的内存结构集合。这些结构包括系统全局区以及所有的Oracle后台进程（例如，PMON、SMON等）。

## J

Java池
共享池中预留出来用于在Java程序执行期间缓存会话特定的Java代码和应用程序变量的部分。

Java虚拟机
将Java代码转换为特定操作系统机器语言并随后执行它的软件。

## K

保留池
数据库缓冲区缓存中用于缓存频繁使用段的缓冲区池。

内核
服务器操作系统的核心基本组件。

## L

大池
共享全局区中预留出来用于缓冲I/O密集型操作（如恢复管理器）和I/O从进程的活动以及共享服务器信息的部分。

闩锁
用于保护对Oracle共享内存结构访问的机制。

最近最少使用 (LRU)
Oracle服务器用来确定哪些对象应移出共享全局区以为新对象腾出空间的算法类型。

库缓存
共享池中用于缓存SQL语句、PL/SQL块、触发器和序列的部分。

列表分区
一种分区技术，根据分区键列中的字符值将表数据存储在分区中。

本地管理表空间
其空间分配和管理由表空间数据文件头中的扩展区映射处理，而不是由数据字典中的条目处理的表空间。

锁争用
由于锁限制性过强或持有时间过长而导致的过多等待。

日志写入器 (LGWR)
负责将重做日志缓冲区的内容清空到联机重做日志的Oracle后台进程。

LRU列表
Oracle用于维护共享池和数据库缓冲区缓存内容的机制。这些内存结构中不常用的项将被新项覆盖。

## M

映射表
位图索引在索引组织表上构建位图索引时，用于将物理行ID映射到逻辑行ID。

物化视图
一种视图，在物理上存储查询对其基表的汇总结果。

MAX_DUMP_FILE_SIZE
指定用户跟踪文件可以增长到的最大大小的 `init.ora` 参数。

## O

联机重做日志
当前正在由日志写入器 (LGWR) 写入的活动重做日志组。

联机事务处理
由强调响应时间的短DML事务为特征的系统。

优化灵活架构
Oracle相关产品及文件所在的设备和目录的命名约定。

Oracle 诊断包
一组用于执行数据库监控、调优和故障排除的GUI工具。

Oracle 企业管理器 (OEM)
使DBA能够在GUI环境中管理和监控Oracle数据库的一组工具。

Oracle 企业管理器仓库
存储Oracle Expert规则库、调优首选项和收集统计信息的表的集合。

Oracle Expert
Oracle Enterprise Manager Oracle Performance Pack 的组件，用于收集和分析性能统计信息，以便根据存储的规则库提出调优建议。

Oracle 智能代理
在由Oracle Enterprise Manager控制台管理的每个服务器节点上运行的自主OS进程。智能代理监控其节点上的数据库，并代表OEM控制台执行事件通知和作业调度操作。

Oracle 性能管理器
允许您以图形方式监控所选数据库性能的Oracle Enterprise Manager GUI工具。

Oracle 服务器
组成Oracle系统的所有逻辑和物理组件，包括系统全局区、后台进程、用户进程、数据文件、重做日志、控制文件和配置文件。

Oracle SQL 分析
企业管理器调优包的组件，此GUI工具分析SQL语句并建议可能提高其性能的更改。

Oracle TopSessions
用于识别和监控与实例交互的用户和后台进程的Oracle Enterprise Manager GUI工具。

Oracle 跟踪数据查看器
Enterprise Manager 诊断包的组件，用于查看用户跟踪文件的内容。

## P

P-代码
SQL语句的编译版本，缓存在共享池中。

解析
SQL语句处理阶段，在此阶段检查语句的语法正确性、安全性和对象解析。

解析锁
在解析时获取的锁类型。

分区
表中存储相关数据的子集，基于指定分区键列中的值。

分区裁剪
基于成本的优化器用于排除与特定查询不相关的表分区的处理过程。

密码文件
Oracle用于验证以SYSDBA或SYSOPER权限连接的数据库用户的物理文件。

挂起区
资源使用者组、资源计划和资源计划指令临时存储的地点，直到提交到数据库。

物理内存
由服务器中安装的物理内存芯片定义的内存量。

固定
将PL/SQL包锁定到共享池中，使其永不被共享池的LRU机制老化的过程。

计划等价性
决定存储的大纲是否用于执行特定查询的决定因素。如果计划等价，则使用存储的大纲。

主块大小
在数据库创建时指定的块大小。此值由 `init.ora` 中 DB_BLOCK_SIZE 参数的设置建立。

私有大纲
仅对修改它的会话可见的存储大纲。

进程
在操作系统上独立运行并消耗自身OS资源（如CPU和内存）的实体。

进程全局区
用于支持每个用户服务器进程活动的内存空间。

进程监视器 (PMON)
负责清理失败用户连接的Oracle后台进程。

## R

RAID
一种旨在通过跨多个设备条带化数据来最小化停机时间的硬件解决方案。任何单个设备的故障都不会中断
