# DBA_RSRC_MANAGER_SYSTEM_PRIVS

The DBA_RSRC_MANAGER_SYSTEM_PRIVS view contains information about which users have been granted the ADMINISTER_RESOURCE_MANAGER privilege. Table 10.13 lists the columns found in this view.

# TABLE 10.13 Contents of the DBA_RSRC_MANAGER_SYSTEM_PRIVS View

| Column | Description |
| --- | --- |
| GRANTEE | User to whom the ADMINISTER_RESOURCE_MANAGER privilege has been granted. |
| PRIVILEGE | The system privilege that was granted to the user. |
| ADMIN_OPTION | Indicates whether the user has the ability to grant the privilege to other users. |

# DBA_USERS

The DBA_USERS view has a single column, INITIAL_RSRC_CONSUMER_GROUP, which indicates the resource consumer group that has been assigned to a user as their default. The following query shows the initial resource consumer group assigned to Betty in a previous example:

```
SQL> SELECT username, initial_rsrc_consumer_group
2   FROM dba_users
3   WHERE username = 'BETTY';
```
