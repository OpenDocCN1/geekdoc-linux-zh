You can manage the Alert log’s size by regularly renaming, trimming, or deleting it. You may want to perform this maintenance following your nightly or weekly database backups. Oracle automatically creates a new Alert log if the prior one was renamed or deleted.

# # Background, Event, and User Trace Files

Oracle trace files are text files that contain session information for the process that created them. Trace files can be generated by the Oracle background processes, through the use of init. ora trace events, or by user Server Processes. Many of these trace files contain useful information for performance tuning and system troubleshooting. We will look at back-ground, event, and trace files in the following sections.
