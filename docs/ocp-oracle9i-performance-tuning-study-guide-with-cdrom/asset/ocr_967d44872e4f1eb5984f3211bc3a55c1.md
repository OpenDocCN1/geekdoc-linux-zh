# Using REPORT.TXT output

The REPORT.TXT file generated by running UTLBSTAT.SQL and UTLESTAT.SQL also contains a section that shows the statistics needed to calculate the Database Buffer Cache hit ratio. These statistics include the same Physical Reads, Physical Reads Direct, Physical Reads Direct (LOB), and Session Logical Reads statistics that were queried from V$SYSSTAT in Figure 5.2. The relevant sections of a sample REPORT.TXT are shown in Figure 5.4.
