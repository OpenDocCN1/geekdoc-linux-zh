# **TABLE 2.6** Components of the Base Oracle Enterprise Manager Console

| Component | Purpose |
|---|---|
| Instance Manager | Starting, stopping, and managing Oracle instances |
| Schema Manager | Creating and managing Oracle database objects. |
| Security Manager | Creating and managing Oracle users, privileges, and roles |
| Storage Manager | Creating and managing tablespaces and datafiles |
| Replication Manager | GUI environment for managing Oracle snapshots and replication features |
| Workspace Manager | Virtual workspace that allows changes to be made to the data in the database. |
