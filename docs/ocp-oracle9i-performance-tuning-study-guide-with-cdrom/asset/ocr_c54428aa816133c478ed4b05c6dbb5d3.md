# **Table 3.2.5** Description of Partition Data Dictionary Views (continued)

| View Name | Description |
| --- |
| DBA_LOB_PARTITIONS | Contains partition details about large object partitions |
| DBA_LOB_SUBPARTITIONS | Contains partition details about large object subpartitions |
| DBA_PART_COL_STATISTICS | Contains columns statistics for partitioned tables |
| DBA_PART_HISTOGRAMS | Contains histogram statistics for partitioned tables |
| DBA_PART_INDEXES | Contains details about each partitioned index |
| DBA_PART_KEY_COLUMNS | Contains the partition key columns for all partitioned tables and indexes |
| DBA_PART_LOBS | Contains details about each partitioned large object |
| DBA_PART_TABLES | Contains details about each partitioned table |
| DBA_SUBPART_COL_STATISTICS | Contains subpartition column statistics |
| DBA_SUBPART_HISTOGRAMS | Contains subpartition histogram statistics |
| DBA_SUBPART_KEY_COLUMNS | Contains the partition key column for each subpartitioned table or index |
| DBA_TAB_PARTITIONS | Contains details about each table's individual partitions |
| DBA_TAB_SUBPARTITIONS | Contains details about each table's individual subpartitions |
