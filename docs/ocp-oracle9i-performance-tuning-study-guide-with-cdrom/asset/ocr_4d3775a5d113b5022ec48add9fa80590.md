# **DBA_RSRC_CONSUMER_GROUPS**

The DBA_RSRC_CONSUMER_GROUPS view contains information on each resource consumer group in the database. These are the same parameters that are specified at the creation of the resource consumer group. Table 10.9 lists the contents of this view.

**TABLE 10.9** Contents of the DBA_RSRC_CONSUMER_GROUPS View

| Column | Description |
|:-------------|:-------------------------------------------------------------------|
| CONSUMER_GROUP | The name of the resource consumer group. |
| CPU_METHOD | The CPU allocation method used to assign CPU resources to this consumer group. |
| COMMENTS | The comments (if any) specified for the resource consumer group at its creation. |
| STATUS | The status of the resource consumer group. New, uncommitted RCGs have a status of PENDING. Committed RCGs have a status of ACTIVE. |
| MANDATORY | Indicates whether or not the resource consumer group is mandatory. Mandatory RCGs cannot be deleted or modified. |

The following query on DBA_RSRC_CONSUMER_GROUPS shows how the summary information for the POWER_USERS resource consumer group created earlier can be examined:

```
```
SQL> SELECT consumer_group, cpu_method,
   2    status, mandatory
   3  FROM dba_rsrc_consumer_groups
   4 WHERE consumer_group = 'POWER_USERS';
