# Add More Undo Segments to Improve Performance

The easiest way to minimize contention for both rollback segment headers and rollback segment extent blocks is to make more of those two resources available. To add these resources, you have to add more rollback segments to the database. To further enhance I/O performance, any additional rollback segments that may be added can be created in a new tablespace, separate from the existing rollback segments.

> **TIP**
> Oracle recommends 1 rollback segment for every four concurrent transactions, for up to a maximum of 20 rollback segments.

# Make Undo Segments Bigger to Improve Performance

Not only do you need to have enough rollback segments available in the database, but you must also make sure that they are large enough to handle the before-images that will be placed in them.
