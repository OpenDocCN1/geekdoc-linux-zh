# ## Oracle Expert

*Oracle Expert* is a GUI tool that gathers and analyzes performance tuning data according to your specifications. Once the data is analyzed, Oracle Expert then uses its built-in inference engine to formulate tuning recommendations. These recommendations can be presented in a summary report along with SQL scripts and new `init.ora` files that can be used to help you implement the recommended changes.

The Oracle Expert tuning methodology consists of the following steps:

+   1.  Define the tuning scope
+   2.  Collect data
+   3.  View and edit the collected data and adjust tuning rules
+   4.  Analyze the collected data
+   5.  Generate tuning recommendations and review the results
+   6.  Create SQL scripts needed to implement the recommendations
