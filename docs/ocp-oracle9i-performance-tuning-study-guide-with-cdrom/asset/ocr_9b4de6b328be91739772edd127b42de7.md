Unless you ask for a specific rollback segment using the SET TRANSACTION USE ROLLBACK SEGMENT command, the Oracle Server assigns transactions to rollback segments in such a way as to try and have each rollback segment manage about the same number of transactions. The total number of transactions a rollback segment can handle is dependent on the Oracle block size of your database.

Table columns that use Large Object (LOB) datatypes will not use rollback segments to store LOB before-images. These segments use space associated with the PCTVERSION value, assigned to the segment at creation to store LOB before-images.
