4. B, D. CPU utilization and the number of active session can also be defined using resource plan directives.

5. C. Varying degrees of CPU allocation can be defined at up to eight levels. Each succeeding level receives CPU access whenever excess CPU time is left over from the previous level.

11. D. The `OTHER_GROUPS` resource consumer group is used to assign resource privileges to a user who is not a member of the resource plan that is currently active at the instance level.

# Glossary

## A

**Absolute Method** A method of assigning resources to consumer groups by designating a specific value allowed for each resource. Parallel query degree-of-parallelism resources are assigned in this manner.

**Active Session Pool** A Resource Manager component that allows you to limit the number of active, concurrent sessions associated with a particular resource group.

**Alert Log** Text file generated by the Oracle instance that contains information about instance-level activity against the database.

**Archived Redo Log** A copy of a Redo log created at a Redo log switch when the database is operating in Archive Log Mode. The Archived Redo logs are written to the location specified by the LOG_ARCHIVE_DEST or LOG_ARCHIVE_DEST_n parameters in the init.ora.

**Archiver (ARC0)** The Oracle background process responsible for copying the contents of the redo log files to archive logs in the archive destination.

**Archiving** The process of copying the contents of the redo logs to a secondary location prior to being reused by LGWR.

**Asynchronous** A method of performing disk I/O that does not require the assistance of an OS layer. These are usually referred to as “raw” devices.

**Automatic Segment-space Management** Tablespaces using this feature utilize bitmaps found in the tablespace's datafile headers (instead of Free Lists) to allocate space to segments stored in that tablespace.

**Automatic Undo Management** Allows the Oracle Server to dynamically control the number and size of rollback segments in the database.

**Autotracer** The utility for generating Explain Plan and resource usage information for SQL statements from within SQL*Plus.
