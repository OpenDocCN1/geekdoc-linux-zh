# Index Organized Tables

The performance gain offered by the use of B-Tree, Bitmapmed, and Reverse Key indexes results from the fact that the entries in these indexes point directly to the row ID of the corresponding data in the index’s underlying table. This is an effective way to retrieve rows from a table whose rows are not physically stored in any particular order. Tables of this type are referred to as *Heap Tables*. Oracle stores row data in a heap fashion in most tables because the rows are assigned to blocks within the table in a more or less random fashion.
