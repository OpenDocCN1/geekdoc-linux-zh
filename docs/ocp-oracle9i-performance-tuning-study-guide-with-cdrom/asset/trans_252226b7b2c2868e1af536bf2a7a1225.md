
## R

**范围分区（Range Partitioning）** 一种对表内容进行分区的技术，通过比较分区键列中的值与构成表分区的互不重叠的值范围，来确定新插入的行应放置在哪个分区中。

**回收池（Recycle Pool）** 数据库缓冲区高速缓存中用于缓存不常用段的缓冲区池。

**重做日志（Redo Log）** 存储事务恢复信息的物理数据库文件。

**重做日志缓冲区（Redo Log Buffer）** 系统全局区（SGA）中用于存储恢复用户事务所需信息的部分。

**REPORT.TXT** 执行 ULTBSTAT.SQL 和 ULTESTAT.SQL 脚本生成的文本文件。REPORT.TXT 文件包含 ULTBSTAT.SQL 和 ULTESTAT.SQL 执行期间详尽的性能调优相关统计信息。

**请求队列（Request Queue）** 共享服务器环境中，分发程序将客户端请求放置到 SGA 中以便共享服务器执行的位置。

**资源使用者组（Resource Consumer Group）** 对数据库资源需求相似的一组用户。

**资源计划（Resource Plan）** 用于实现资源管理的资源计划指令集合。

**资源计划指令（Resource Plan Directive）** 指定分配给特定资源计划的 CPU、并行度、撤销、会话和执行时长资源。

**响应队列（Response Queue）** 共享服务器将已完成的客户端请求放置到 SGA 中的位置。每个分发程序都有自己独立的响应队列。

**响应时间（Response Time）** 在系统上执行特定操作所需的时间。

**反转键索引（RKI）** 一种 B 树索引类型，在创建索引前反转被索引列的内容。

**回滚（Rollback）** 撤销事务并将修改的数据恢复至其原始状态的过程。

**行链接（Row Chaining）** 当表中的行过大，无法容纳在单个 Oracle 块中，从而跨越两个或更多块时发生的情况。

**行迁移（Row Migration）** 表数据行原本适合放在单个数据库块中，但在行更新时被移动到拥有更多可用空间的新块中。

**基于规则的优化器（Rule-Based Optimizer）** Oracle 优化器模式，在确定给定 SQL 语句的最佳执行计划时使用一组预定义规则。

## S

**可扩展性（Scalability）** 系统在承受额外需求时仍能正常运行的能力。

**段头（Segment Header）** 存储段（即表、索引或回滚段）存储信息的块或块组。

**服务级别协议（Service Level Agreement）** 阐述用户群体对系统可用性和性能期望的书面文件。

**共享池（Shared Pool）** 系统全局区（SGA）中用于缓存针对实例发出的 SQL 语句的部分。

**共享池保留区域（Shared Pool Reserved Area）** 共享池中可以专门划拨给大型 PL/SQL 包和触发器使用的部分。

**共享服务器（Shared Server）** 负责在多线程服务器环境中执行客户端请求的 Oracle 进程。

**排序（Sort）** 每当需要将数据按特定顺序排列时就会发生排序。例如，在 SQL 语句中使用 ORDER BY 子句。

**STATSPACK** Oracle 提供的实用工具，用于捕获和分析多个用户定义时间段内的数据库和实例性能统计信息。

**条带深度（Stripe Depth）** 在 RAID 集中，从一个设备移动到下一个设备之前，将写入该设备的数据量。

**条带宽度（Stripe Width）** 创建 RAID 集所跨越的物理设备数量。

**条带化（Striping）** 使数据文件跨越多个物理设备以提高 I/O 性能的过程。

**存储大纲（Stored Outlines）** 针对给定 SQL 语句的预先确定并存储的执行计划，该语句每次发出时都会使用此计划。

**同步（Synchronous）** 一种执行磁盘 I/O 的方法，需要操作系统层的服务。这些通常被称为文件系统或“已处理”设备。

**系统全局区（SGA）** Oracle 的共享内存结构，用于缓存 SQL 语句、数据缓冲区和事务恢复信息。

**系统监视器（System Monitor）** 负责执行实例恢复、管理排序段以及合并表空间中空闲空间的 Oracle 后台进程。

**系统管理撤销（System-managed Undo）** 参见自动撤销管理。

## T

**表空间（Tablespace）** 数据库内存储的逻辑划分。通常创建多个表空间来存储每种类型的应用程序段（例如表、索引、回滚段）。每个表空间由一个或多个数据文件组成。

**临时文件（Tempfile）** 用于创建临时表空间的特殊类型数据文件。

**线程（Thread）** 在单个操作系统进程内执行的独立指令序列。

**吞吐量（Throughput）** 系统在给定时间段内执行的工作量。

**TKPROF** Oracle 命令行实用工具，用于格式化用户跟踪文件，以便检查调优信息。

**跟踪（Trace）** 创建包含用户或后台进程执行的操作详情的文本文件的过程。

**跟踪文件（Trace File）** 包含在跟踪激活期间用户或后台进程执行的所有操作信息的文本文件。

## U

**撤销段（Undo Segments）** 撤销段（也称为*回滚段*）用于存储用户已修改数据的前像。这些前像既用于读一致性，也用于事务恢复。

**用户全局区（User Global Area）** 在使用多线程服务器模式时，用于缓存共享用户信息的共享池部分。

**用户服务器进程（User Server Process）** 当实例在专用服务器模式下运行时，每个连接的数据库用户在服务器上拥有的操作系统进程。用户服务器进程代表用户与系统全局区通信。

**USER_DUMP_DEST** 指定 Oracle 服务器进程生成的跟踪文件应创建目录的 `init.ora` 参数。

**UTLBSTAT.SQL** 在要检查的调优期间开始时运行的 Oracle 提供脚本。

**UTLESTAT.SQL** 在要检查的调优期间结束时运行的 Oracle 提供脚本。该脚本还生成输出文件 `REPORT.TXT`。

## V

**虚拟内存（Virtual Memory）** 当对服务器物理内存的需求超过其物理大小时，操作系统用于临时缓存内存进程或内存页的磁盘空间。

## W

**愿意等待闩锁（Willing-to-Wait Latch）** 一种闩锁类型，在再次尝试获取先前忙碌的闩锁之前会等待。

**写列表（Write List）** 数据库缓冲区高速缓存中管理脏缓冲区的机制。它跟踪所有已通过使用 INSERT、DELETE 或 UPDATE 语句被应用程序用户修改但尚未写入磁盘的块。
