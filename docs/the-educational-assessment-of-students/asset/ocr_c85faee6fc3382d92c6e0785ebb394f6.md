# Table J.2 Example of how to compute the Kuder-Richardson Formula 20 (KR20) and the Kuder-Richardson Formula 21 (KR21) reliability estimates.

# A. Computing KR20

| Pupils | Items on test* |  |  |  | Total score†(X) |
|---|---|---|---|---|---|
|  | 1 | 2 | 3 | 4 | |
| Alan | 1 | 0 | 0 | 0 | 1 |
| Isaac | 1 | 1 | 0 | 0 | 2 |
| Leslie | 0 | 0 | 1 | 1 | 2 |
| Miriam | 0 | 0 | 0 | 0 | 0 |
| Rebecca | 1 | 1 | 0 | 1 | 3 |
| Robert | 1 | 1 | 1 | 1 | 4 |
| Fraction passing each item (p-values) | 0.67 | 0.50 | 0.33 | 0.50 | M = 2.0 (SD_X)² = 1.667 |
| (1-p) | 0.33 | 0.50 | 0.67 | 0.50 | |
| p(1-p) | 0.222 | 0.250 | 0.222 | 0.250 | Σ p(1-p) = 0.944 |

KR20 = [k/(k-1)] {1 - [Σ p(1-p) / (SD_X)²]} = [4/(4-1)] {1 - [0.944 / 1.667]} = (1.333)(1 - .566) = (1.333)(.434) = 0.58

*An item is scored 1 if it is answered correctly; 0 otherwise.
†The mean and variance are computed in Appendix I.

# B. Computing KR21

| Pupils | Total score* (X) |
|---|---|
| Alan | 1 |
| Isaac | 2 |
| Leslie | 2 |
| Miriam | 0 |
| Rebecca | 3 |
| Robert | 4 |
| M = 2.0; (SD_X)² = 1.667 | |

KR21 = [k/(k-1)] {1 - [M(k-M) / k(SD_X)²]} = [4/(4-1)] {1 - [2(4-2) / 4(1.667)]} = (1.333) {1 - 4/6.668} = (1.333)(1 - .600) = 0.53

†The mean and variance are computed in Appendix I.
