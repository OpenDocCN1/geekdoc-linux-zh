# Table J.4 Example of computing the general Spearman-Brown reliability estimate.

# A. Formula

rₙₙ = (n r₁₁) / [1 + (n − 1) r₁₁]

# B. Example

Q. A teacher has a 10-item test with reliability coefficient equal to 0.40. What would be the reliability if the teacher added 15 new items similar to those currently on the test?

A. Here r₁₁ = 0.40 and n = 25/10 = 2.5. (The new test would be 25 items long and, hence, 2.5 times as long as the original test.) Thus, the new test reliability is:

rₙₙ = (2.5)(0.40) / [1 + (2.5 − 1)(0.40)] = 1.00 / (1 + 0.6) = 1.0 / 1.6 = 0.625
