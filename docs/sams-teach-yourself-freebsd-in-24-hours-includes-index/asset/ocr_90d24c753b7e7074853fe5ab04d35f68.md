# Basic Email Services

Any multiuser operating system on the Internet must give its users the ability to send email messages to users of other systems. This is one of the oldest uses of the Internet, and certainly it has lately become an integral part of any computer user's life. However, in its current form, email is a bit different from how it used to be.

FreeBSD is configured "out of the box" to provide email services for local users of the system; if you make certain changes to the default configuration, it can also act as a relay so that people on dial-up machines can use your server to convey their messages to their destination servers. However, this also means that mass mailers ("spammers") can also use your server as a broadcasting station without your permission.

In this hour's lesson, we will cover Sendmail, the venerable *Mail Transfer Agent (MTA)* that still transmits the majority of the world's email and that is bundled as part of FreeBSD. You will learn

+   - Using the various files that comprise the configuration of Sendmail
+   - Customizing the Master Config file and regenerating Sendmail's runtime configuration file
