# Workshop

The following section contains exercises and quiz questions designed to help you solidify your understanding of basic UNIX shell use.

# Quiz

+   1. Which of the following is not a valid shell in FreeBSD?
+      A. POSIX shell
+      B. Corn shell
+      C. Bash shell
+      D. C shell
+   
+   2. Which of the following options to the man command allows you to search the man pages?
+      A. -s
+      B. -f
+      C. -k
+      D. None of these
+   
+   3. Which of the following commands displays a list of processes running on the system?
+      A. ps
+      B. plist
+      C. process
+      D. p1
+   
+   4. Which of the following commands will terminate a process running on the system?
+      A. term
+      B. stop
+      C. end
+      D. kill
+   
+   5. Which of the following key sequences will stop a job that is currently running in the foreground?
+      A. Alt+s
+      B. Ctrl+s
+      C. Ctrl+z
+      D. Alt+z
