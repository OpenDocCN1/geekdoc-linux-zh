StarOffice is not technically available for FreeBSD; rather, it's a Linux-native software suite, and it runs under FreeBSD through its Linux compatibility layer. After you have downloaded the StarOffice file (so-6_0-ga-bin-linux-en.bin), move it into /usr/ports/distfiles and then use cd to go into /usr/ports/editors/staroffice60. After you have done this, you can type make and make install to install StarOffice into your system with the necessary FreeBSD patches. The installation procedure in the port will ask you a few questions, such as whether you want to do a "network install" or a "local install"; you will probably want to do a network install so you can put the StarOffice binaries into a location where all users can access them.

After this process has been completed, running StarOffice is a matter of typing soffice at the command prompt. You will be launched into the StarOffice Desktop, shown in Figure 20.7.
