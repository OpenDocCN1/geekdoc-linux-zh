# Quiz

+      B. They're installed automatically as part of KDE.

+   2. How do I activate menu functions within the GIMP?

+      D. Type menu while the program is in the foreground to activate the floating menu toolbar.

+      B. Double-click on a KWord document in the file browser or on the desktop.

+      A. Type gimp at the command line.
+      B. Double-click on an image file in the file browser on the desktop.
+      C. Add the GIMP application to your K menu or the taskbar, and then double-click on it there.
