# The K Desktop Environment (KDE)

In the previous hour, you learned how to configure the X Window System to work with your hardware. In this hour, you will learn how to actually work with the X Window System using KDE (the K Desktop Environment).

In this hour, you will learn:

+   - What a desktop environment is
+   - How to make KDE your default desktop
+   - How to navigate in KDE
+   - About the applets (mini-applications) available in KDE
+   - How to manage files in KDE
+   - How to customize your KDE desktop
