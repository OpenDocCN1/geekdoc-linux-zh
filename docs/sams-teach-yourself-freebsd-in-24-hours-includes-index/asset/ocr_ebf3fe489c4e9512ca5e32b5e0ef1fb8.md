Before you can use FreeBSD, you need to install it on your computer's hard disk. In this hour, we will discuss the background information needed to make the best decision about how to install FreeBSD. Of course, the first thing you might want is a little bit of background on FreeBSD.

# What Is FreeBSD?

FreeBSD is a freely available and open source implementation of the Berkeley version of the UNIX operating system. In many ways, it is similar to Linux, but it also has some important differences.
