## 18 – 搜索文件

随着我们在 Linux 系统中的漫游，有一件事变得非常清楚：典型的 Linux 系统拥有大量文件！这就引出了一个问题：“我们如何找到所需的东西？”我们已经知道 Linux 文件系统是按照代代相传的约定来组织的，但 sheer 的文件数量可能构成一个令人望而生畏的问题。

在本章中，我们将介绍两种用于在系统上查找文件的工具。这些工具是：

- `locate` – 按名称查找文件
- `find` – 在目录层次结构中搜索文件

我们还将介绍一个常与文件搜索命令一起使用的命令，用于处理 resulting 的文件列表：

- `xargs` – 从标准输入构建并执行命令行

此外，我们还将介绍几个帮助我们探索的命令：

- `touch` – 修改文件时间
- `stat` – 显示文件或文件系统状态

### locate – 简单的查找文件方式

`locate` 程序对路径名执行快速数据库搜索，并输出与给定子字符串匹配的每个名称。举例来说，假设我们想找到所有名称以“zip”开头的程序。由于我们要找的是程序，可以假设包含程序的目录会以“bin/”结尾。因此，我们可以这样使用 `locate` 来查找文件：

```
[me@linuxbox ~]$ locate bin/zip
```

`locate` 将搜索其路径名数据库并输出包含字符串

"bin/zip" 的内容：

```
/usr/bin/zip
/usr/bin/zipcloak
/usr/bin/zipgrep
/usr/bin/zipinfo
/usr/bin/zipnote
/usr/bin/zipsplit
```

如果搜索要求不那么简单，locate 可以与其他工具如 grep 结合使用来设计更有趣的搜索：

```
[me@linuxbox ~]$ locate zip | grep bin
/bin/bunzip2
/bin/bzip2
/bin/bzip2recover
/bin/gunzip
/bin/gzip
/usr/bin/funzip
/usr/bin/gpg-zip
/usr/bin/preunzip
/usr/bin/prezip
/usr/bin/prezip-bin
/usr/bin/unzip
/usr/bin/unzipsfx
/usr/bin/zip
/usr/bin/zipcloak
/usr/bin/zipgrep
/usr/bin/zipinfo
/usr/bin/zipnote
/usr/bin/zipsplit
```

locate 程序已经存在多年，常见的使用变体有几种。现代 Linux 发行版中最常见的两个是 slocate 和 mlocate，尽管它们通常通过名为 locate 的符号链接访问。locate 的不同版本具有重叠的选项集。某些版本包含正则表达式匹配（我们将在即将到来的章节中介绍）和通配符支持。请查阅 locate 的手册页以确定安装了哪个版本的 locate。
