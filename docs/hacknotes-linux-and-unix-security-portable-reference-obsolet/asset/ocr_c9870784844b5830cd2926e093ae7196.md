# BING

Bing, shown in the following dialog box, is a simple script that automates port scanning. When executed, it discovers live hosts on the current subnet by broadcasting ping requests. It then presents a list of hosts on the subnet that respond to ICMP echo requests. You can then pick a host from the given list to perform a port scan against (using Nmap). Download Bing’s package file from http://www.claustyckey.com/chad/bing_0.0.1_arm.ipk.
