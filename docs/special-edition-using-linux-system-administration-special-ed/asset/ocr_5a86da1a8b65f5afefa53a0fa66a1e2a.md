# COMMERCIAL X SERVERS

Commercial X servers provide support for cards not supported by XFree86, and might give better performances for cards that are supported by XFree86. In general they support many more cards than XFree86, so I'll only list cards that aren't supported by XFree86 here. Contact the vendors directly or check the Commercial HOWTO for more info.
