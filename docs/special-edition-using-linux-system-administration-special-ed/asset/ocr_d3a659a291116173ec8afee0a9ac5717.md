+   - Using the `<?php` and `?>` opening and closing tags:
+   
+     ```php
+     <?php
+     PHP code goes here
+     ?>
+     ```

+   - Using the `<SCRIPT LANGUAGE="php">` and `</SCRIPT>` opening and closing tags:
+   
+     ```html
+     <SCRIPT LANGUAGE="php">
+     </SCRIPT>
+     ```

+   - Using the `<%` and `%>` opening and closing tags:
+   
+     ```php
+     <%
+     PHP code goes here
+     %>
+     ```

By far the most common format for PHP code is the `<? PHP code goes here ?>` format.

PHP code normally consists of a series of statements. A statement can be one of the following:

+   - A single statement ending with a semi-colon:
+   
+     ```php
+     phpinfo();
+     ```

+   - A series of statements enclosed in parentheses:
+   
+     ```php
+     {
+         $a = 1;
+         $b = 2;
+         $c = a + b;
+     }
+     ```

+   - A flow control command followed by a statement (either of the following):
+   
+     ```php
+     if ($x > 1)
+         phpinfo();
+   
+     if ($x > 1) {
+         $a = 1;
+         $b = 2;
+         $c = a + b;
+     }
+     ```

PHP supports a variety of basic data types:

+   - Integers
+   - Floating point numbers
+   - Strings

Complex data types are also available:

+   - Arrays
+   - Objects
