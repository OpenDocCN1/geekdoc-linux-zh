# ## Kickstart Using a Boot Floppy Disk

To run a Kickstart installation from the boot floppy disk requires copying the Kickstart configuration file to the boot floppy. This can be done using the following command from the system where you created the Kickstart configuration file:

```
```text
# mcopy ks.cfg a:
```
```

If the Red Hat boot floppy is very full and you don’t have room to add the ks.cfg file, you can delete the message files from the boot floppy using the following command:

```
```text
# mdel a:\*.msg
```
```

To start a Kickstart installation from the boot floppy, enter the following command at the boot prompt when the system boots from the installation floppy disk:

```
```text
LILO boot: linux ks=floppy
```
```

You can edit the file syslinux.cfg on the boot floppy to automatically enter Kickstart installation mode when booting from the floppy. For automatic Kickstart installation, edit the syslinux.cfg file to have the following contents:

```
```text
default ks
        prompt 0
        label ks
                kernel vmlinuz
                append ks=floppy initrd=initrd.img
```
```

# ## Kickstart Using a DHCP Server

The Kickstart configuration file can be fetched from the network. This requires setting up a DHCP server, an NFS server, and a DNS server.

The Kickstart configuration file must be modified for network installation. DHCP and NFS options must be configured to boot using DHCP and to receive the Linux distribution from an NFS server. A sample pre-installation section of the Kickstart configuration file for a network installation is shown in the following table:

```
```text
lang en
network --bootpoption dhcp
nfs --server linux.bwc.org --dir /redhat/i386
device ethernet 3c59x
keyboard us
zerombr yes
clearpart --linux
part /boot --size 10
part swap --size 128
part / --size 1000
install
mouse microssoft --emulthree
timezone Israel
xconfig --server "SVG A" --monitor "Sony CPD100SF"
rootpw --iscrypted $1$1SlZGxZx$yL5tB2qwsJzzNBlA9kt5A0
auth --useshadow --enabledms
timezone --location mbr
```
