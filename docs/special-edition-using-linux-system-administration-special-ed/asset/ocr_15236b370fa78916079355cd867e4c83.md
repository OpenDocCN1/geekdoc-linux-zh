# UNSUPPORTED

+   - Supermicro P5MMA with BIOS versions 1.36, 1.37, and 1.4. Linux will not boot on this motherboard. A new (beta) release of the BIOS which makes Linux boot is available at `ftp.supermicro.com/mma9051.zip`.
+   - Supermicro P5MMA98. Linux will not boot on this motherboard. A new (beta) release of the BIOS which makes Linux boot is available at `ftp.supermicro.com/a8905.zip`.
+   - DataExpert Corp. ExpertColor TX531 V1.0 motherboard with chipset ACER M1531 (Date: 9729, TS6) and ACER M1543 (Date: 9732 TS6) seems to present not reproducible segmentations faults, kernel oops, and kernel hangs under heavy load and tape access. The problem seems to be the PCI-bus, respectively the ACER chipset.
