The long options are those which start with two dashes such as `--compress` or `--port=<port>`.

These options take a slightly different form in the options files as outlined in Table 24.3.

**TABLE 24.3  OPTIONS IN OPTIONS FILES**

| Command-Line Format | Options File Format |
|---|---|
| `--<option>` | `<option>` |
| `--<option>=<value>` | `<option>=<value>` |
| `--set-variable`<br>`<variable>=<value>` | `set-variable=<variable>=<value>` |

For instance, a typical global options file in `/etc/my.conf` or in `/usr/local/var/my.conf` might look like the following:

```
[client]
port=3306
socket=/tmp/mysql.sock

[mysqld]
port=3306
socket=/tmp/mysql.sock
set-variable = max_allowed_packet=1M

[mysqldump]
quick
```
