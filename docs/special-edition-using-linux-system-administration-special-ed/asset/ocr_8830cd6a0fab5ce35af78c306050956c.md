# NETWORK ADAPTERS

Ethernet adapters vary greatly in performance. In general the newer the design the better. Some very old cards such as the 3Com 3c501 are only useful because they can be found in junk heaps for $5 apiece. Be careful with clones—not all are good clones, and bad clones often cause erratic lockups under Linux. Read the Ethernet HOWTO, `http://metalab.unc.edu/ LDP/HOWTO`, for detailed descriptions of various cards.
