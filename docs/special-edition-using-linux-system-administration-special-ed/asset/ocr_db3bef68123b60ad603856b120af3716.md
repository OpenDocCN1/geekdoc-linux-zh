The query.php3 script can be broken down as follows:

+   - Lines 1-10: These commands connect to the MySQL server, open the mydbase database, and then perform the appropriate query based on whether the user has submitted an ID number or a last name.
+   - Lines 17-40: One table row is displayed for each record in the returned results. For each record, the record is fetched from the results and stored in an array and then the contents of the array are displayed in the appropriate table cell.
+   - Line 42: If no results were obtained from the database, this information is displayed.
