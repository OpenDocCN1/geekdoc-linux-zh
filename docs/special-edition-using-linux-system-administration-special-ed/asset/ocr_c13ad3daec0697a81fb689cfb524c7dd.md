# DESCRIPTION

Concatenate FILE(s), or standard input, to standard output.

+   - `-A`, `--show-all`—Equivalent to `-vET`
+   - `-b`, `--number-nonblank`—Numbers nonblank output lines
+   - `-e`—Equivalent to `-vE`
+   - `-E`, `--show-ends`—Displays `$` at end of each line
+   - `-n`, `--number`—Numbers all output lines
+   - `-s`, `--squeeze-blank`—Never more than one single blank line
+   - `-t`—Equivalent to `-vT`
+   - `-T`, `--show-tabs`—Displays TAB characters as `^I`
+   - `-u`—(ignored)
+   - `-v`, `--show-nonprinting`—Uses `^` and `M-` notation, except for LFD and TAB
+   - `--help`—Displays this help and exits
+   - `--version`—Outputs version information and exits

With no FILE, or when FILE is `-`, read standard input.
