# # TAR

# ## NAME

tar—The GNU version of the tar archiving utility.

# ## DESCRIPTION

This manual page documents the GNU version of tar, an archiving program designed to store and extract files from an archive file known as a tarfile. A tarfile can be made on a tape drive; however, it is also common to write a tarfile to a normal file. The first argument to tar must be one of the options: Adtcrux, followed by any optional functions. The final arguments to tar are the names of the files or directories that should be archived. The use of a directory name always implies that the subdirectories below should be included in the archive.

# ## FUNCTION LETTERS

One of the following options must be used:

+   - `-A, --catenate, --concatenate`—Append tar files to an archive
+   - `-c, --create`—Create a new archive
