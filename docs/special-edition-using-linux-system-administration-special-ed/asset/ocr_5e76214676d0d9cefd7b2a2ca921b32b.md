**RAID:** Redundant Arrays of Inexpensive Disks. The basic idea of RAID is to combine multiple small, inexpensive disk drives into an array of disk drives that yields performance exceeding that of a single large expensive drive. The five types of redundant array architectures are RAID-1 through RAID-5. A nonredundant array of disk drives is referred to as RAID-0. Some RAID systems can mix formats. Information is available at http://www.uni-mainz.de/~neuffer/scsi/what_is_raid.html.

**SCSI:** Small Computer Systems Interface. A standard interface defined for all devices in a computer. It makes possible the use of a single adapter for all devices.
