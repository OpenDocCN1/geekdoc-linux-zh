Lines 4-8 set global options. The weekly directive sets the default log rotation interval to once a week. The rotate 4 directive specifies maintaining 4 history files. The errors directive specifies to whom errors generated during log processing are mailed. In this example `root@some.host` gets all error output, unless overridden by local options. The compress directive specifies that history logs should be compressed after they are rotated.

The include directive on line 12 specifies that additional log rotation configuration files might need to be read from the `/etc/logrotate.d` directory. The contents of this directory on a particular Linux system show the following:
