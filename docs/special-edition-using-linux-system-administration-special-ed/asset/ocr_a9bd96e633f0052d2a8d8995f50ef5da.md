Clients attempting to mount remote NFS directories across slow connections can compensate for this by adjusting some of the options of the mount command:

+   - Never use *soft* mounts. Only use hard mounts.
+   - Increase the value of `timeo` until you can get a connection without numerous retries.

With Samba, after you have your installation configured correctly, the most common problem is that the smbd or nmbd daemon can become non-responsive or produce false authentication errors and need to be restarted.
