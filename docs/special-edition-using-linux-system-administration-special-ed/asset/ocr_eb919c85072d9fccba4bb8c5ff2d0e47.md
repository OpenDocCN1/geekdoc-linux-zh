# SYNC

# NAME

sync—Flush file system buffers

# SYNOPSIS

```
sync [OPTION]
```

# DESCRIPTION

Force changed blocks to disk, update the super block.

+   - `--help`—Display this help and exit
+   - `--version`—Output version information and exit
