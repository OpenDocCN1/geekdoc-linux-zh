# TROUBLESHOOTING

Generally, NIS works smoothly, especially where your distribution installs and performs the initial NIS setup (as is done with Red Hat 6.0). Still, there are some problems related to NIS that you may encounter; the following are among them:

+   - If you use ypbind earlier than version 3.3, and if your NIS stops and then restarts, ypbind may generate an error message such as `yp_match: clnt_call: RPC: Unable to receive; errno = Connection refused`. After this, login fails. To solve the problem, log in as root on the server and kill and restart ypbind. Alternately, upgrade to ypbind version 3.3 or newer.
