# EXAMPLES

To see every process on the system using standard syntax:

+   - `ps -e` — To see every process on the system using BSD syntax
+   - `ps ax` — To see every process except those running as root (real & effective ID)
+   - `ps -U root -u root` — To see every process with a user-defined format
+   - `ps -eo pid,tt,user,pmem,tmout,f,wchan` — Odd display with AIX field descriptors
+   - `ps -o '%u : %U : %p : %P : %a'` — Print only the process IDs of syslogd: `ps -C syslogd -o pid=`
