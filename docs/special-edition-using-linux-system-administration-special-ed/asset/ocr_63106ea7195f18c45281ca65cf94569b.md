The general format of a TCP packet is as follows:

```
<time stamp> <source host>:<port> > <destination host>:<port>:\
    <flags> <data sequence number> <other fields>
```

Example TCP packets to and from a squid server running on port 8083 are shown here:

```

60 (DF)
23:39:41.826379 cstlx001.bwc.org.8083 > shjws159.bwc.org.1879: FP 1461:1653(192)
ack 451 win 32120 (DF)
```
