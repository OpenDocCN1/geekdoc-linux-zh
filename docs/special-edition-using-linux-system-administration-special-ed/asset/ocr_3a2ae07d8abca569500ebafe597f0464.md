# IP PORT FORWARDING

IP port forwarding is needed if you must provide access to an internal masqueraded host from the Internet. As a general rule, it is preferable to locate the servers that need access from the Internet in your DMZ network. However, this might not always be possible and you might have to devise a way to access one of your internal masqueraded servers from the external network.

This is best done on Linux kernel 2.2.x, using a tool called ipmasqadm. You must also select the IPPORTFW option when compiling the Linux kernel for the IP port-forwarding feature to be available. You can download the package ipmasqadm-0.4.2.tar.gz from http://juanjox.kernelnotes.org.
