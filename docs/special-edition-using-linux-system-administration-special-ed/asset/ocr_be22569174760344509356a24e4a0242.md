# VERIFY THAT THE SERVER IS RUNNING

You can verify that your MySQL installation is functioning properly using the `mysqladmin` command. First, display current version information:

```
```text
# /usr/local/bin/mysqladmin version
/usr/local/bin/mysqladmin  Ver 7.15 Distrib 3.22.30, for pc-linux-gnu on i686
TCX Datakonsult AB, by Monty

Server version          3.22.30
Protocol version        10
Connection              Localhost via UNIX socket
UNIX socket             /tmp/mysql.sock
Uptime:                 3 min 10 sec

Threads: 1  Questions: 1  Slow queries: 0  Opens:
➜ 6  Flush tables: 1  Open tables: 2
```
```
