tput smso - Enter standout mode (bold on rxvt)
tput rms0 - Exit standout mode
tput sgr0 - Turn off all attributes

Color Code for tput:

+   - 0 – Black
- 1 – Red
- 2 – Green
- 3 – Yellow
- 4 – Blue
- 5 – Magenta
- 6 – Cyan
- 7 - White
