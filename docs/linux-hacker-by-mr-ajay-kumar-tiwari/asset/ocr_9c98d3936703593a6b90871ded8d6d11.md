# Hack 91. Ps Command

ps command (process status) will display snapshot information of all active processes.

Syntax: ps [options]

# How to display all the processes running in the system?

Use “ps aux”, as shown below.

```
# ps aux | more
```

```
USERPID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
root10.00.0 2044 588 ?SsJun27
0:00 init [5]
apache 311860.01.6 23736 17556 ?SJul26
0:40 /usr/local/apache2/bin/httpd
apache 311870.01.3 20640 14444 ?SJul26
0:37 /usr/local/apache2/bin/httpd
```

You can also use “ps -ef | more”, to get a similar output

# Print the Process Tree

You can use either ps axuf or ps –ejH to display processes in a tree format.

The tree structure will help to visualize the process and it’s parent process immediately. For clarity purpose, few columns have been cut-off in the output below.

```
# ps axuf
```
