# Shell script and output WITH PS3:

```
```bash
ramesh@dev-db ~> cat ps3.sh
PS3="Select a day (1-4): "
select i in mon tue wed exit
do
  case $i in
  mon) echo "Monday";;
  tue) echo "Tuesday";;
  wed) echo "Wednesday";;
  exit) exit;;
  esac
done
```
```

```
```
ramesh@dev-db ~> ./ps3.sh
1) mon
2) tue
3) wed
4) exit

Monday
Select a day (1-4): 4
