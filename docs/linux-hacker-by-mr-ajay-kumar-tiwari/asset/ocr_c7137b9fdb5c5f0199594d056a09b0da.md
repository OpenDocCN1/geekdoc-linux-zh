# Hack 40. Change the prompt color using tput

You can also change color of the PS1 prompt using tput as shown below:

```
$ export PS1="[$(tput bold)$(tput setb 4)$(tput setaf 7)]\u@\h:\w $ [$(tput sgr0)]"
```
