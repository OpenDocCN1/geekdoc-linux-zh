### Vmstat procs 部分

r 字段：可运行进程的总数

b 字段：阻塞进程的总数

### 内存部分

Swpd 字段：已使用的交换空间

Free 字段：可用空闲 RAM

Buff 字段：用于缓冲区的 RAM

Cache 字段：用于文件系统缓存的 RAM

### 交换部分

Si 字段：每秒从磁盘交换到内存的内存量

So 字段：每秒从内存交换到磁盘的内存量

### IO 部分

Bi 字段：从磁盘接收的块数

Bo 字段：发送到磁盘的块数。

### 系统部分

In 字段：每秒中断数。

Cs 字段：每秒上下文切换数。

## Hack 99. Sysctl 命令

Linux 内核参数可以使用 sysctl 命令实时更改。

## Linux 技巧
Ajay Kumar Tiwari

Sysctl 有助于在运行时配置 Linux 内核参数。

```
# sysctl -a
```

```
dev.cdrom.autoclose = 1
fs.quota.writes = 0
kernel.ctrl-alt-del = 0
kernel.domainname = (none)
kernel.exec-shield = 1
net.core.somaxconn = 128
net.ipv4.tcp_window_scaling = 1
net.ipv4.tcp_wmem = 409616384
net.ipv6.route.mtu_expires = 600
sunrpc.udp_slot_table_entries = 16
vm.block_dump = 0
```

### 在 /etc/sysctl.conf 中修改内核参数以实现永久更改

修改 /etc/sysctl.conf 中的内核参数后，执行 sysctl -p 以提交更改。重启后更改仍然存在。

```
# vi /etc/sysctl.conf
```

```
# sysctl -p
```

### 临时修改内核参数

要临时修改内核参数，请执行以下命令。

请注意，重启后这些更改将会丢失。

```
# sysctl -w {variable-name=value}
```

## Hack 100. Nice 命令

内核根据 nice 值决定进程所需的处理器时间。可能的 nice 值范围为：-20 到 20。nice 值为 -20 的进程优先级非常高。nice 值为 20 的进程优先级非常低。
