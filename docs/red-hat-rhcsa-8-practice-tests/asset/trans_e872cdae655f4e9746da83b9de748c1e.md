## RHCSA 练习考试 1

欢迎来到红帽认证系统管理员（RHCSA）完整视频课程第三版的第一次练习考试。本次考试预计将花费一小时。

此测试考试需要以下设置：

- 一个名为 server3 的全新安装的 RHEL 8 虚拟机。
- 除非另有说明，接下来描述的所有任务都应在虚拟机上执行。

- 1. 停止您预装的虚拟机，并在 KVM 软件中为虚拟机添加额外的 5GiB 硬盘。

- 2. 在 http://rhatcert.com/repo 有一个可用的仓库。配置您的 server3 使用该仓库并禁用任何其他仓库的使用。

- 3. 创建四个用户：bill, bob, betty 和 belinda。将他们的密码设置为在 120 天后过期，并确保他们在 /home/users 中拥有家目录。（这意味着，例如，bill 的家目录为 /home/users/bill）。

- 4. 创建两个组：consultants（顾问）和 trainers（培训师）。将 bill 和 bob 设置为 consultants 组的成员，而不覆盖他们当前的任何组组成。将 belinda 和 bety 设置为 trainers 组的成员，而不改变他们当前的任何组组成。

- 5. 创建符合以下要求的共享组环境：

    - consultants 组对 /groups/consultants 目录具有完全读写权限。
    - trainers 组对 /groups/consultants 目录具有完全读写权限。
    - bill 是 consultants 部门的负责人，能够删除 /groups/consultants 中由任何用户创建的文件。consultants 组的其他成员不应有权删除他们不是自己创建的文件。
    - betty 是 trainers 部门的负责人，能够删除 /groups/trainers 中由任何用户创建的文件。trainers 组的其他成员不应有权删除他们不是自己创建的文件。

- 6. 创建一个 LVM 卷，格式化为 ext4。除了以流式文本格式显示代码和配置外，我们还包含了代码的图像，模拟打印版中的显示效果；因此，流式格式可能会影响代码列表的显示。

- 7. 创建一个性能优化的系统配置文件，每小时发送 "hello"。

- 8. 创建一个定时任务的系统。

- 9. 启用 systemd 日志。

## RHCSA 练习考试 2

欢迎来到红帽认证系统管理员（RHCSA）完整视频课程第三版的第二次练习考试。本次考试预计将花费两个小时。

- 1. 创建名为 server4 的虚拟机，满足以下要求：

    - 有可用的 20GiB 硬盘。
    - root 密码设置为 "password"。
    - 创建用户 "student"，其密码为 "password"。
    - 使用自定义分区创建一个 1GiB 分区。

- 2. 配置您的安装磁盘为默认。禁用其他仓库。

- 3. 配置您的系统每小时清理 /tmp。

- 4. 为您的虚拟机添加两个 10GiB 硬盘。在磁盘上创建一个名为 myvol 的 Stratis 卷，并确保它在启动后挂载。

- 5. 编写一个脚本：

    - 它评估第一个参数。
    - 如果未提供参数，它将提示用户输入。
    - 它评估提供的参数是文件还是目录。
    - 如果是文件，脚本应显示该文件的详细列表。
    - 如果是目录，脚本应显示该目录的详细列表。
    - 如果提供的参数不存在，脚本应以代码 6 退出。

- 6. 查找所有设置了 SUID 权限的文件并将结果写入 /tmp/suid.txt。

- 7. 创建 lisa。确保她每 30 天重置一次密码。确保她能够管理所有用户但不是 root。

- 8. 确保 lisa 有权修改 /etc 目录下的所有文件，而不更改用户或组所有。

- 9. 在主硬盘上使用所有剩余空间创建一个 LVM 卷组。在此卷组中创建一个 2GiB 的逻辑卷作为交换空间。

- 10. 在主网络接口上配置辅助 IP 地址 10.0.0.10/24。

- 11. 练习重置 root 密码的方法，假设不知道当前的 root 密码。

- 12. 安全 SSH 服务，只允许 lisa 用户登录。

- 13. 确保系统重启后，默认进入图形界面环境。（如果系统已经是这样设置，请再次输入 Bash 历史记录中的命令。）

- 14. 配置 Bash 历史记录，将最后使用的 2500 条命令写入历史文件。

- 15. 安装 vsftpd 服务。确保它在重启后自动启动，并配置为匿名用户可以上传文件。

- 16. 配置您的系统使用 PHP 7.1 作为默认版本。
