The following configuration options are available:

+   - **Authentication Domains.** Lets you change or add the eDirectory server URLs and contexts that are required by NetStorage. This allows you to access two or more eDirectory trees.
+   This page also lets you change the eDirectory server that is designated as the Primary.

+   - **Browse Files.** Displays the NetStorage web page.

+   - **Current Sessions.** Displays a report with information on the current NetStorage sessions.

+   - **General.** Lets you configure items such as location, certificate name, session timeout, janitorial level, and LDAP port.
