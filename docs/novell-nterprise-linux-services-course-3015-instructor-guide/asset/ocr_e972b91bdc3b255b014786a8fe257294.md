| Agent | Function |
| --- |
| List Server Agent | The List Server Agent enables your NetMail system to function as a list server. |
| The list server works in conjunction with the NDS Mailing List and Mailing List objects. |
| NDS-based mailing lists are built from Container, Group, Role, or User objects. General mailing lists require the full email address of each subscriber. |
| When you send messages to a mailing list, undeliverable status information is not returned if one of the messages is rejected. |
