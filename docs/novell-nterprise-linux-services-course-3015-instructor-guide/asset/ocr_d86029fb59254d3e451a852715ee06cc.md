# Installation Directories

During a default installation, NetMail files are copied to the `/var/opt/novell/netmail` and the `/opt/novell/netmail` directories.

The `/var/opt/novell/netmail` directory contains the single copy, message store and the user directories. The `/opt/novell/netmail` directory contains the NetMail binaries.

The mail NetMail binary is named **ims** and is located in `/opt/novell/netmail/bin`. Each NetMail agent binary is also located in this directory, as shown below:

# WebAdmin

WebAdmin is a browser-based, platform-independent, system management tool.

WebAdmin is not represented by an **Agent** object in eDirectory. Instead, the agent is manually launched at the server.

You access WebAdmin through your browser by accessing iManager and selecting Launch NetMail Management.
