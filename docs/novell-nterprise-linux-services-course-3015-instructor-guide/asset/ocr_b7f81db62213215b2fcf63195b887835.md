# Use the Conflict Bin

The iFolder client has a feature called the Conflict Bin. A user will rarely need to access this option; however, understanding this feature is useful. The following scenario illustrates what the Conflict Bin is and how it works.

Suppose that John is one of your iFolder users. John has the iFolder client installed on two computers: computer A and computer B. At some point in the day, John disconnects both of these computers from the network and continues to work from both computers offline.

While he is working, he makes a change to one of his iFolder files on computer A and then, later in the day, he makes a different change to the same file on computer B.
