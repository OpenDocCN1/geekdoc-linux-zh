# **Table 8-1** *(continued)*

| Agent | Function |
| :--- | :--- |
| SMTP Agent | The SMTP Agent is the gateway between the Internet and your messaging system. Its primary function is to transfer messages to and from the Internet. |
| | This agent must be running on at least one messaging server for users to send local messages from POP or IMAP clients or to send messages over the Internet. |
| | It controls which domains are recognized by the messaging system. |
| | The SMTP Agent also provides most of NetMail's UBE protection features, including |
| | • Reverse DNS look-ups |
| | • Real-time Black Hole (RBL) look-ups |
| | • Host blocking by IP address |
| | • ESMT authentication |
| | • SMTP-after-POP |
| | • Restrictions on remote sending by IP address |
| | Additional SMTP Agent options include the following: |
| | • A message size limit for inbound and outbound Internet messages |
| | • Controls on standard SMTP commands that pose security risks or facilitate connections with offices that have intermittent Internet connections |
| | • A Mail Relay Host definition that allows you to funnel all remote messages through a single SMTP server rather than having every SMTP Agent individually access the Internet |
