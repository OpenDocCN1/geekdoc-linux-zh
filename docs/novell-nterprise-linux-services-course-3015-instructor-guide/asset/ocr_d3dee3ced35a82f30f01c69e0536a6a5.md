To select the default template, do the following:

+   1. In **WebAdmin**, expand **Internet Services**.
+   2. Expand **Messaging Server**.
+   3. Select **Modular Web Agent**.
+   4. Scroll down to the **Default Template** field, as shown in the following:

![](bbox=[0.08, 0.24, 0.91, 0.45])

+   5. Select the **magnifying glass** icon.
+   6. Browse to and select the *template object* you want to use.
+   7. By default, the templates are located in **Templates.Internet Services**.
+   8. Select **Save**.

> If you enter incorrect login information to access WebAccess or WebMail when using a Mozilla browser, the login dialog box is not displayed.
> 
> You must either refresh the window or re-enter the URL. If you click the Log In Again link after logging out of WebAccess or WebMail, you are taken to the logged-out page. You must start a new browser to get to the login prompt.
