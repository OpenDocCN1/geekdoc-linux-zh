To block a user, do the following:

+   1. On the **Virtual Office** main page, open your team.

+   2. In the **Team Membership** column, select **Show Blocked Users**.

The following appears:

![](bbox=[0.08, 0.2, 0.92, 0.46])

+   3. Select **Add**.

+   4. Enter the *name* of the user you want to block; then select **Search**.
+   If you want to see all users, leave these fields blank and select **Search**.

+   5. Select the *users* you want to block; then select **Add**.

# Edit Team Properties

After you set up and configure a virtual team, you can modify your property settings to reflect any changes or updates. Team properties include a list of team members and the components they can access.
