Install NetMail** | NetMail can be configured in 2 ways:<br><ul><li><strong>Single-Server Messaging</strong></li><li><strong>Distributed-Server Messaging</strong></li></ul> When designing your NetMail system, you need to identify the following:<br><ul><li>Which servers will host NetMail agents?</li><li>Which agents will be located on a given server?</li><li>Which domains will be serviced by each messaging server?</li><li>Does your organization need fault tolerance and scalability by deploying the same agents on multiple servers?</li></ul> To install NetMail, you must meet the following system requirements:<br><ul><li>Ensure you're running 1 of the following:<ul><li>Red Hat Linux AS 2.1</li><li>Red Hat Linux ES 2.1</li><li>SuSE 8.0</li></ul></li><li>Ensure eDirectory 8.7.3 or later for Linux is installed.</li><li>Ensure your system CPU is at least a 750 MHz Pentium III or Athlon.</li><li>Ensure you have at least 512 MB of system RAM.</li></ul> |
