# The following appears:

![](bbox=[0.1, 0.13, 0.9, 0.4])

There are three levels you can set for the Global Client Policies:

+   *   **Default Settings**. Set the default settings for the configurable features in the iFolder client.
+       Select the check box or fill in a value to enable that option by default in the iFolder client. The user can view the settings and can change them.
+   *   **Enforced**. Select the check box to enforce the default setting you specified for a configurable feature in the iFolder client.
+       If enforced, the user can view the settings, but cannot change them. The features and settings are grayed out in the iFolder client interface.
+   *   **Hidden**. Select the check box to hide the configurable feature and its default setting in the iFolder client.
