| Agent | Function |
|---|---|
| NMAP Agent | The NMAP Agent is responsible for managing message processing and delivery.\nIt coordinates everything that happens from the time a message enters the message queue to when it is delivered to the user's mailbox or passed off for delivery via the Internet.\nIt is the only agent that has direct access to the message store. Consequently, every messaging system requires at least one NMAP Agent and every user within the messaging system must be included in one of the NMAP Agent's contexts.\nThe NMAP Agent's 3 primary functions are\n\n*   Managing the message store: By default, the NMAP Agent creates a mailbox directory for every User object within its assigned contexts.\nBecause NMAP is the only agent with physical access to the message store, the message store directories are always created on servers running the NMAP Agent.\n\n*   Managing the message queue: The NMAP Agent coordinates all message processing in the message queue. The Mail Load utility monitors and regulates the NMAP Agent's thread usage to maintain optimal efficiency.\n\n*   Providing IP access to the message store and message queue for the other NetMail agents.\n| POP Agent | The POP Agent enables POP3 mail clients to download mail from the messaging system.\nFor users to access their mailboxes, your messaging system must include at least 1 POP, IMAP, or Modular Web Agent. |
