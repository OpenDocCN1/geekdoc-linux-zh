# *Steps for Installing NetStorage*

The general steps for installing iFolder are

+   - Meet NetStorage Dependencies
+   - Gather Required Information
+   - Use the NNLS Install Feature

# Meet NetStorage Dependencies

NetStorage is installed with Virtual Office. The dependencies for Virtual Office include

+   - Apache 2.0.45 on the same NNLS server
+   - JVM 1.4.1_02 on the same NNLS server
+   - Tomcat 4.1.24 on the same NNLS server
+   - eDirectory 8.7.1 or later anywhere within the network
+   - iManager 2.0 on the same NNLS server

The NNLS install program will select the required components, along with their dependencies, when you select the Virtual Office component. They will all be installed in the same process.
