# ## Introduction

For any business, providing reliable, standards-based e-mail and calendaring is essential to success.

Organizations that support a large number of deskless workers face the challenge of implementing a scalable, reliable system that is economical to deploy and easy to manage.

In addition, these organizations must ensure that the e-mail system is secure and accessible from anywhere in the world.
