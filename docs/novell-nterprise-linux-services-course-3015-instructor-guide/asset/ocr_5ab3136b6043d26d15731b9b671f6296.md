To change this on Red Hat, open a terminal session as root and enter `chkconfig --level 2345 sendmail off`. To change this on SuSE, open a terminal session as root and enter `chkconfig sendmail off`.

+   - Check the /etc/syslog.conf file for a line that starts with mail*. If it exists, comment it out. In debug mode, mail produces enough syslog messages to fill most disks in a short period of time.
