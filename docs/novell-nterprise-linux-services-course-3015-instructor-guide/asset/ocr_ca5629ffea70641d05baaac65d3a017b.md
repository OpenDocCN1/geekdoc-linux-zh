# Change Password

This parameter specifies whether users are allowed to change their eDirectory passwords. To configure this, do the following:

+   1. Open iManager.

+   2. Select **Virtual Office Management > Services Administration > Change Password**.

Point out that changing the password here changes the eDirectory password. This, of course, changes the password for all other NNLS services.
