+   Enter the following settings:
+   
+   - **Enable Team Creation**: Select **On** to let users create teams.  
+   This setting is turned on by default.
+   - **Team File Share**: Specify the *path* to the file-sharing location.
+   - **SMTP Address**: Specify the address for e-mail notifications.
+   - **Chat Server IP Port**: Specify the port for applet-to-server communication.
+   - **Manage Team Access**: This option lets you deny a user the ability to create a virtual team. Select **Edit > Search**, search for and select a *user*, and then select **Select**.

+   Select **Save**.
