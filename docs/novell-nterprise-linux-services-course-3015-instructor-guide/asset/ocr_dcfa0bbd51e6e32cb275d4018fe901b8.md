**Table 8-2** (*continued*)
| Directory | Function |
| :---- | :---- |
| .users/user_name | A unique directory for each user's mailbox. |
| .users/user_name/Inbox.box | The file containing all messages in the user's InBox (text and attachments). New messages are appended to the end of the file. |
| .users/user_name/Inbox.idx | The index of all messages in the inbox.box file. |
| .users/user_name/mail.cal | The calender store. This file contains the user's calender items, such as tasks, appointments, and notes. |
| .users/user_name/main.idc | The index of all items in the mail.cal file. |
| .users/user_name/folder_name.box | A unique file for each folder in the user's mailbox. It contains the folder's messages (text and attachments). New messages are appended to the end of the file. |
| .users/user_name/folder_name.idx | The index of all messages in the folder_name.box file. |
