+   13. To save this file to the `/var/opt/novell/httpd/htdocs/ippdocs` directory on your Linux server, do the following:
+   
+   a. Share your **tmp** folder (or wherever it is that you saved your map file to) on your Windows workstation.
+   
+   - Open Windows Explorer.
+   - Browse to and right click the **tmp** directory.
+   - Select the **Sharing** tab.
+   - Select **If you understand the security risks but want to share files without running the wizard, click here**.
+   - Select **Just enable file sharing**.
+   - Select **OK**.
+   - Select **Share this folder on the network**.
+   - Select **OK**.
+   
+   b. On your Linux server, log in as root.
+   
+   - Select the Gnome footprint.
+   - Select **Log out**.
+   - Select **Yes**.
+   - Enter **root** at the Login screen.
+   - Enter your password.
+   
+   c. On your Linux server, open the Nautilus window by double-clicking the **Start Here** icon on the desktop.
+   
+   d. In the Location field of the Nautilus window, enter `smb://`. Wait a moment for any shared servers on the network to appear.
+   
+   e. Open **Workgroup**.
+   
+   f. Open *your workstation*.
+   
+   g. Open the **tmp** folder (or other folder that you saved your map file to) of your Windows workstation.
+   
+   h. Right-click your map and select **Copy File**.
+   
+   i. Select the **Tree** tab in the left frame of your Nautilus window.
