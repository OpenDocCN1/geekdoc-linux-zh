| Directory | Function |
|---|---|
| .Jusers\user_name\folder_name\ | A unique directory for each folder that contains subfolders.<br><br>More disk space is required to maintain directories than files on the messaging server.<br><br>Consequently, subfolders are very expensive in terms of server resources. |
| .Jusers\user_name\folder_name\ subfolder_name.box | A unique file for each subfolder in the parent folder. It contains the subfolder’s messages (text and attachments). New messages are appended to the end of the file. |
| .Jusers\user_name\folder_name\ subfolder_name.id | The index of all messages in the subfolder_name.box file. |

# Single Copy Message Store

If a message is sent to 2 or more multiple recipients and the message is over 2 KB, NMAP does not replicate the message in all the users’ mailboxes.

Instead, a pointer message is sent to the individual mailboxes directing NMAP to the complete message in the Single-Copy Message Store (SCMS) directory.

When the last user downloads or deletes the message, it is deleted from the shared directory.
