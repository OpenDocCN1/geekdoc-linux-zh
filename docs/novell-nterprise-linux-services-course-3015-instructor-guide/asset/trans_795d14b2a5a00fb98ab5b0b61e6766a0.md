## 虚拟办公环境管理

# 团队配置

此参数提供虚拟团队的配置选项。*虚拟团队*是虚拟办公中的一个中心位置，用户可以在其中交换信息、共享文件并维护事件日历。

虚拟办公允许您创建自己的团队并成为其他团队的成员。例如，您可以为一个人力资源组创建一个社区。通过该社区共享的所有信息和文件都可以直接与人资任务相关。

当您创建一个虚拟团队时，您将成为团队的所有者兼团队成员。虚拟团队可以拥有多个所有者。如果您希望授予另一个用户对您团队的管理权限，您必须使该用户成为所有者。

所有者拥有平等的权利。所有者可以将其他所有者从社区中移除——甚至包括创建该社区的个人。所有团队都显示在虚拟团队列表中，但仅团队成员可以访问这些团队。

要配置团队，请执行以下操作：

1. 打开 iManager。
2. 选择**虚拟办公管理 > 环境管理 > 团队配置**。

将显示以下内容：

![](img/d63035f3fce0eaaf97203dde900affb7_253_0.png)

输入以下设置：

- **启用团队创建**：选择**开**以允许用户创建团队。此设置默认开启。
- **团队文件共享**：指定文件共享位置的*路径*。
- **SMTP 地址**：指定电子邮件通知的地址。
- **聊天服务器 IP 端口**：指定小程序到服务器通信的端口。
- **管理团队访问**：此选项允许您拒绝用户创建虚拟团队的能力。选择**编辑 > 搜索**，搜索并选择一个*用户*，然后选择**选择**。

选择**保存**。

# 日志记录

此参数确定记录在虚拟办公日志中的信息量。这些设置仅对当前的门户服务器有效。它们不会保存到 PortalServlet.properties 文件中。

要配置此参数，请执行以下操作：

1. 打开 iManager。
2. 选择**虚拟办公管理 > 环境管理 > 日志记录**。

将显示以下内容：

![](img/d63035f3fce0eaaf97203dde900affb7_254_0.png)

3. 配置以下设置：
    - **日志记录**：选中日志记录旁边的复选框以启用日志记录。
    - **日志级别**：指定日志中包含的信息量：
        - **高**：记录特定信息。
        - **中**：记录特定信息和一些通用消息。
        - **低**：记录所有消息。
    - **日志记录模块**：列出包含在日志记录中的模块。如果该字段为空，则日志记录包括所有模块。
    - **记录到标准错误**：启用记录到标准错误。
    - **记录到标准输出**：启用记录到标准输出。
    - **记录到文件**：将日志报告发送到 /var/opt/novell/iManager/nps/WEB-INF/debug.xml 文件。选择**查看全部**以查看该文件中的消息。选择**清除全部**以清除文件。
4. 选择**确定**。
