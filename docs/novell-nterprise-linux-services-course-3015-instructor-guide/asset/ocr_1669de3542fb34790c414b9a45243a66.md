# *Internet Services Container*

During your initial NetMail installation, the installation program extends the Novell eDirectory schema and creates the *Internet Services Container* object at the root of your eDirectory tree.

Because it is part of NetMail, the Internet Services container differs from other eDirectory Container objects.

There can only be one Internet Services container per tree and, as the messaging system container, it contains only NetMail component objects.
