# Logging

This parameter determines the amount of information that is recorded in Virtual office logs. These settings are only effective on the current portal server. They are not saved to the PortalServlet.properties file.

To configure this parameter, do the following:

+   1. Open iManager.
+   2. Select Virtual Office Management > Environment Administration > Logging.
