    <li>AutoReply Agent</li>
    <li>Calendar Agent</li>
    <li>Connection Manager</li>
    <li>IMAP Agent</li>
    <li>List Server Agent</li>
    <li>Modular Web Agent</li>
    <li>NMAP Agent</li>
    <li>POP Agent</li>
    <li>Proxy Agent</li>
    <li>SMTP Agent</li>
    <li>WebAdmin</li>
    </ul>
    During a default installation, NetMail files are copied to the /var/opt/novell/netmail and /opt/novell/netmail directories.</li>
