# **Table 8-1** *(continued)*

| **Agent** | **Function** |
|---|---|
| **Calendara Agent** | The Calendaring Agent provides automatic status-tracking information for scheduled appointments, tasks, and notes. <br>When a user schedules a calendar event, the Calendaring Agent processes all "Accept" and "Decline" responses and automatically updates the event's status information in the organizing user's calendar. <br>Only the user who schedules the event can view who has accepted or declined a calendar event. Attendees only see their own status; every other attendee is viewed as pending. <br>If you choose not to run the Calendaring Agent, users receive I-cal status messages in their Inbox. Because the status information is in I-cal format, the event organizer might not be able to discern whether a recipient has accepted or declined the appointment. <br>I-cal mail clients, such as Microsoft Outlook* XP, also provide automatic status tracking for scheduled appointments. <br>If you are exclusively using an I-cal compliant mail client, you can choose to either have NetMail manage status tracking via the Calendaring Agent or to have the mail client manage status tracking. <br>If you are using the Modular Web client, you must run the Calendaring Agent to provide automatic status tracking for scheduled appointments. |
