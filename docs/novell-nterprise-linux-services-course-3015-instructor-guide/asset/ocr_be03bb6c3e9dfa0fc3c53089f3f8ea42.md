Novell Nterprise Linux Services provides the following file services from a Linux server:

+   * **Novell iFolder.** This product provides access, storage, and synchronization of files between a workstation and a central iFolder server.

+   * **NetStorage.** This product provides secure Internet-based access to files and folders on a Linux server in your network through a browser.

# Describe the Purpose and Architecture of iFolder

Novell iFolder is a Net services software solution that lets mobile professionals access their local files from anywhere—online, offline, all the time—across multiple workstations and the Net.

iFolder automatically and intelligently updates your files across desktop computers, laptops, and other connected devices you use, letting you use them wherever you happen to be—at the office, at home, or in a hotel.

All the you need is an active network or Internet connection and the iFolder client, a Web browser, or NetDrive.

For a user, iFolder is like having a single, virtual work folder accessible from any computer. It provides a simple, convenient, and secure way to access, back up, and synchronize files.
