The following describes the information you need to know before installing Samba:

# Gather Required Information

![](bbox=[0.09, 0.19, 0.16, 0.21])

| Configuration Data Required | Description |
| eDirectory Server IP Address or DNS Hostname | The IP address or DNS name of the server on which you are installing iFolder. The primary IP address of the eDirectory server to which Windows users will authenticate using LDAP authentication for access to the directories and files on the NNLS server. |
| Admin Name with Context | The fully distinguished name of the Admin for the eDirectory server specified for Samba. The name and context must be specified using typeful syntax (cn=name.ou= organizational-unit.o=organization). |
| Admin Password | The password for the Admin. |
| LDAP Server IP Address or DNS Hostname | The primary IP address of the eDirectory server to which Windows users will authenticate using LDAP authentication for access to the directories and files on the NNLS server. |
| Samba Proxy User Name with Context | The name of the proxy user you want eDirectory to configure for Samba. The installation script creates this user object for you. |
| Samba Proxy User Password | The password for the Samba proxy user. |
