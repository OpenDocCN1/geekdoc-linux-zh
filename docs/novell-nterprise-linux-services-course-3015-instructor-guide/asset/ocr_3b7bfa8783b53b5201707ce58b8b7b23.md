| Agent | Function |
| :---- | :------- |
| Proxy Agent | The Proxy Agent allows users to manage several email accounts from a central mailbox. |
|  | Users can retrieve messages from up to 3 POP3 or IMAP4 email accounts on other messaging systems. All messages retrieved from these accounts are stored in the user’s NetMail mailbox as if it were the original destination. |
|  | Depending on the user settings, a copy of retrieved messages can be left in the original mailbox or the messages can be deleted from the host server. All proxy information is stored in the User object. |
