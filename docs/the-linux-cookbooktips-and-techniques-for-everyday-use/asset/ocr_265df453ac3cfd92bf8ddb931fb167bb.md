# 19.4 Interactive Image Editors and Tools

There are all kinds of image-editing software applications available for Linux—and there are as many way to make and edit an image as there are tools to do it with.

The following table lists some other popular tools and applications for making and editing images—including CAD engineering software—that you may want to explore. It is not exhaustive.

| TOOL | DESCRIPTION |
|------|-------------|
| bitmap | Use the bitmap editor to edit bitmap files, which are used for icons and tile patterns in the X Window System. {@sf{Debian}}: `xbase-clients` |
| drgeo | drgeo is a program for drawing interactive geometric figures. {@sf{Debian}}: `drgeo` {@sf{WWW}}: http://members.xoom.com/FeYiLai/dr_geo/doctor_geo.html |
| dia | Use dia to draw simple charts and diagrams. It saves files in its own format, but you can export files to EPS (see section PostScript); if you plan on editing a diagram file again, however, be sure you keep the `.dia` file since, as of this writing, dia cannot import EPS files. {@sf{Debian}}: `dia` {@sf{WWW}}: http://www.lysator.liu.se/~alla/dia |
