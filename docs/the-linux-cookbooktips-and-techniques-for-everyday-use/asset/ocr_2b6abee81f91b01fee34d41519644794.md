# 8.3.1 Finding the Largest Files in a Directory

To find the largest files in a given directory, use ls to list its contents with the `-S` option, which sorts files in descending order by their size (normally, ls outputs files sorted alphabetically). Include the `-1` option to output the size and other file attributes.

+   - To list the files in the current directory, with their attributes, sorted with the largest files first, type:

```
$ ls -1S RET
```
