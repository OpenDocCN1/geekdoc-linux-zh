hyphen (`-`) and caret (`^`) characters have special meanings when used inside brackets:

The hyphen specifies a range of characters, ordered according to their ASCII value (see section Viewing a Character Chart). For example, [0-9] is synonymous with [0123456789]; [A-Za-z] matches one uppercase or lowercase letter. To include a literal `-` in a list, specify it as the last character in a list: so [0-9-] matches either a single digit character or a `-`.x

As the first character of a list, the caret means that any character except those in the list should be matched. For example, [^a] matches any character except `a`, and [^0-9] matches any character except a numeric digit.
