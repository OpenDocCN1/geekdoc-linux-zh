• To make a banner containing the text `Happy Birthday Susan` at a width of 23 text columns, type:

```
banner -w 23 'Happy Birthday Susan' RET
```

• To make a banner containing the text `Happy Birthday Susan` at a width of 80 text columns, type:

```
banner -w 'Happy Birthday Susan' RET
```

**NOTE:** A method of making a horizontal text banner with `figlet` is described in [Outputting Text in Landscape Orientation](#).
