# The Linux Cookbook: Tips and Techniques for Everyday Use:

**C-a z**: from this menu, you can press **P** to set the communications parameters, **T** to set the terminal settings, **O** to configure *minicom*, or **D** to enter the dialing directory.

To dial a number from the main screen, type **ATDT** followed by the number to dial.

+   - To dial the number `368-2208`, type:

```
ATDT3682208 RET
```

When you type **RET**, *minicom* will begin dialing the number; type any key to interrupt the dialing and hang up the line. Once connected, type **C-a h** to hang up the line and type **C-a x** to hang up the line and exit the program.

> *NOTE:minicom* isn't really a way to connect your system to the Internet; to do that, you normally start a PPP connection, as described earlier in this chapter.(37)
