# **Wireless**

A NeoPixel Ring shines through this magic lamp when it is activated by the embedded Qi charger, which can also be used with mobiles.

# **Computer**

The display uses the Raspberry Pi 2, with a keyboard- and-mouse combo hidden on the underside of the desk with a Velcro mount.

# **Contactless**

Frederick made his own breakout board for the hover buttons, combining the Atmel AT42QT1070 touch sensor with a PCB.

# **Lights**

The LED strip shines through the Plexi surface, and Frederick’s script alters the LED’s colour when the computer is popping up or down.

# **Components list**

+   * 12V power supply
+   * 12V-to-5V DC-DC converter
+   * 2 WiFi USB dongles
+   * Desk Raspberry Pi B+, USB sound card, 2 5V Class D amplifier, Garminot, 2 stepper motors, 2m LED strip, capacitive touch sensor, 2 microswitches (on/off), mini speaker
+   * Computer Raspberry Pi 2, 2.5W Class D amplifier, laptop LCD display, LCD display controller, 2 speakers
+   * Magic lamp Qi wireless charger, Qi wireless receiver, Adafruit NeoPixel Ring, Adafruit Trinket
