## 引言

是什么让 KALI LINUX 与其他 Linux 发行版不同？
KALI 专门为满足专业渗透测试、黑客攻击、计算机安全研究、逆向工程、计算机取证或安全审计的需求而开发。为了实现这一点，Offensive Security 对原始 Linux 源代码进行了各种核心更改，以构建满足以下要求的系统：

*a) 定制 Linux 内核* ：驱动 KALI 的 Linux 内核是上游版本，专门为随时随地的无线注入进行了特殊修补。

*b) 默认具有 root 访问权限的单用户操作系统* ：由于安全测试和渗透的性质，KALI LINUX 被设计为默认授予 root 访问权限的单用户系统。毕竟，KALI LINUX 附带的大多数工具都需要提升的权限。

*c) 网络服务默认禁用* ：默认情况下，网络服务通过系统钩子被禁用。这使用户能够安装各种服务，而不会危及其使用的计算机的安全性。一些连接服务（如蓝牙）也被默认列入黑名单。

*d) 可信的软件源集* ：考虑到 KALI 的目的，维护整个系统的完整性至关重要。KALI 开发人员为此将系统自带的上游软件集保持在最低限度。如有需要，你可以向 *sources.list* 添加更多软件源。

## 为什么你需要防火墙的安全保障

事实是，一台没有防火墙保护的电脑，可能会在几分钟内被互联网上众多自动化黑客程序中的任何一个入侵。确保你的电脑及其包含的信息安全的唯一方法是使用防火墙保护它。

从很多方面来说，在没有防火墙保护的情况下运行一台充满个人数据的电脑，就像把车钥匙留在点火器上，车门敞开一样。网络罪犯从你的电脑窃取数据，就像窃贼偷走你的汽车一样容易。事实上，窃取你电脑上的数据可能更容易得多。

因此，正如你应该通过锁门来保护你的汽车一样，你应该使用可靠的防火墙来保护你的电脑。防火墙程序，与反病毒软件、反间谍软件程序和其他互联网保护工具一起，为你和你的家人提供安全可靠的计算环境。

但是，在安装任何类型的防火墙程序之前，下载并安装操作系统的所有必要更新非常重要。这是因为如果操作系统存在安全漏洞，基于软件的防火墙本身也可能面临风险。

此外，保持系统最新始终是一个好主意，因为总是有新的安全威胁和安全漏洞被发现。因此，让你的操作系统保持最新，将为你提供一个良好的基础。

## 设置虚拟环境

从两大主流虚拟化程序 [VMware Workstation](https://www.vmware.com/products/workstation.html) 或 [VirtualBox](https://www.virtualbox.org/) 中任选其一，然后下载并安装。这两种产品各有优缺点，谨慎起见，您在选择使用哪个系统之前最好做一些简单的研究。软件的下载和安装过程直接明了，对于立志成为黑客的人来说应该不会构成挑战。

使用这些软件的一大好处是，除了无需额外配备一台电脑外，您还可以在不同模式下运行它们，其中一些模式允许您桥接虚拟网络和真实网络，从而像在真实网络上一样测试您的网络渗透技能。例如，VirtualBox 就具有 NAT、桥接和内部网络模式，这些模式使得托管操作系统能够像指定类型网络上的一台计算机一样运行。

在设置虚拟环境时，请密切关注配置细节，例如分配给虚拟机的内存（RAM）容量。分配的内存过少会阻碍虚拟化操作系统的速度和性能，而分配过多则会对宿主操作系统的性能产生负面影响。

# 第三章 网络基础

当然，访问特定系统最直接的方式是从目标设备的接口终端直接进入。这给黑客带来了许多障碍，因为它要求黑客获得系统的物理访问权限，使其暴露于被发现或留下其存在痕迹的风险之中。然而，大多数计算机和信息技术的网络化特性提供了更安全、更不易被察觉的利用途径——网络。

广义上讲，网络是任何互连部分的集合。存在由人、组织、政治实体、机器以及几乎所有信息在成员间传递的实体团体组成的网络。计算机和信息技术网络已经发展和融合，连接了数十亿个节点，从小型家庭网络（包含一两台个人计算设备）到需要自己发电厂的大型服务器农场。

无论是通过蓝牙连接将联系信息从一部智能手机发送到另一部，还是通过互联网将电影从莫斯科流式传输到布宜诺斯艾利斯，网络和通信的基础原理都是相同的。理解计算机网络和通信协议对于成为有效的黑客至关重要。

# 网络组件与架构

任何具备某种连接能力的设备都可以构成网络上的一个节点。传统的用户平台，如服务器、台式机、笔记本电脑、平板电脑以及智能手机等个人手持设备，在网络上很常见。此外，联网外设和独立智能设备的数量也在不断增加，例如打印机、电视、游戏平台、网络摄像头、娱乐控制台、音频设备和手表。每台设备通常可以通过各种通信介质连接到多个其他设备。铜缆和光纤等物理连接构成了全球互联网的骨干，并将大多数网络连接到局域网的主要接入点。在局域网内部，可能存在多种类型的连接方式，包括物理布线和 Wi-Fi。在短距离内，设备可以通过蓝牙或近场通信（NFC）技术连接。与这种架构并行发展的是日益增长的宽带蜂窝网络，它由一系列连接到互联网骨干网和各种卫星的射频塔组成。随着宽带蜂窝技术的改进，其用途正在超越电话领域，正成为许多个人设备和小型网络的主要互联网接入方式。

# 网络模型与协议

无论节点类型或通信介质如何，两个设备必须使用某种通用协议进行通信。整个网络上所有设备都使用的标准协议对于防止通信错误是必需的。自网络最早期以来，互联网协议（IP）就一直存在。尽管其形式和功能有所变化，它仍然是网络通信的事实标准。IP 与另一个称为传输控制协议（TCP）的标准相结合，形成了一种称为 TCP/IP 的分层网络范式。该方案将网络从基础网络硬件到用户应用程序划分为不同的层次。这组协议是一个概念性的网络通信模型，称为 TCP/IP 模型或 TCP/IP “协议栈”。还有另一个模型称为开放系统互连（OSI）模型，它在层次数量上更为细粒度。OSI 模型可以更广泛地应用，但它描述的基本原理与 TCP/IP 模型相同。

## TCP/IP 模型

TCP/IP 模型由四个堆叠的概念层组成，每一层在数据从网络中一点准备和传输到另一点的过程中都扮演着角色。它们是应用层、传输层、网络层和数据链路层（或链路层）。

## 网络数据分层流动 (infosecinstitute.com)

TCP/IP 协议栈的应用层（被认为是“顶层”）是用户最可见和最可访问的一层。这是在通信内容或有效载荷被打包以进行传输之前被创建的地方。电子邮件客户端、网络浏览器、文件共享软件、视频流应用程序和其他联网应用程序都在应用层运行。值得注意的是，应用层执行驻留在 TCP/IP 内部（或之上）的其他协议。这包括 Web 应用程序的超文本传输协议（HTTP）、电子邮件的 SMTP 以及文件传输协议（FTP）等。

传输层的功能是一个高级概念，但可以说这一层有助于通过错误检查和其他方式确保通信质量。此外，传输层是来自应用程序的信息被初始分成数据包的地方，然后为这些数据包附加适当的头部。TCP 在这一层运行，但它并非唯一可用的协议。用户数据报协议（UDP）在需要牺牲少数数据包的成功到达以换取信息的实时交付时使用。UDP 是音频和视频流媒体的首选传输协议。

网络层，通常称为互联网层，是执行数据包路由工作的层。在这一层，确定数据包的最佳网络路由，然后将源 IP 地址和目标 IP 地址附加到数据包头部，随后将其转发到网络接口硬件。其他协议也可以在这一层运行，但 IP 是迄今为止最普遍的，是大多数全球数据通信的基础结构。在传输各个阶段对 IP 头部的操纵是许多黑客攻击的基础。

TCP/IP 模型的底层是硬件或数据链路层。硬件层是数据包在离开源机器并通过物理介质到达下一个目的地之前的最后一站。参与数据包中继的网络硬件的 MAC 地址在这一层被附加到数据包头部。

## 网络协议

当网络中的一个节点与另一个节点通信时，它会将其消息分成小的、独立的数据包。每个数据包在通过每一层时都会附加一个头部，以便在目的地被正确地重新组装成消息。TCP/IP 的美妙之处在于每个单独的数据包可能采用不同的路由，并且如果丢失可以重新发送，从而确保高度的效率和消息保真度。



TCP/IP的核心是IP地址。网络上的每台设备都有一个唯一的地址，用于标识其在该网络及所属任何子网中的位置。理解IP寻址使黑客能够精确锁定特定目标。此外，黑客可能需要隐藏或操纵自己的IP地址，以保持不引人注目。

IP的标准版本多年来一直是IP v4，用于大多数网络和设备。IP v6是一种新标准，可以容纳更多的地址。在单个局域网内，IP地址的第一个八位字节通常表示主网络的指定，后续的八位字节则指定子网和单个机器。

## IP地址表示法

关于IP寻址，最重要的一点是要理解，本地网络中给定节点的IP地址与它通过互联网通信时被分配的地址是不同的。这是因为无法控制或防止两个独立网络上的两台机器意外或有意地被赋予相同的地址。

从黑客的角度来看，IP地址为任何单个网络提供了一个路线图，以识别和区分单个机器。此外，在网络上传输时拦截单个数据包也能带来很多好处。数据包的头部信息包含源和目标的IP地址。正是通过操纵这些头部信息，黑客才能进行中间人攻击和拒绝服务攻击。

IP地址被视为逻辑地址，这意味着它们通过软件分配，可以由用户直接分配，也可以通过某种过程自动分配。IP地址位于网络层。在许多情况下，IP地址可以在数据包头部被欺骗或伪造。这样做可以混淆电子邮件或其他攻击载荷的来源，或者恶意重路由数据包。

重要的是要理解，IP伪造不能用于隐藏任何双向通信。为了让两台机器交换信息，它们的地址必须有效，否则交换的数据包将无法到达目的地。这就是为什么在点对点服务上操作时，试图隐藏或更改自己的IP地址是徒劳的，或者隐藏下载节点的地址也是徒劳的。在这种情况下，人们能做的最好的事情是通过大量地理位置和逻辑上不同的代理来路由信息。作为暗网基础的TOR网络，就是通过创建多层信息传输层来运作的。

另一种重要的设备标识符是媒体访问控制（MAC）地址。MAC地址被认为是永久物理地址，分配给单个网络接口设备。MAC寻址方案的设计使得理论上没有两台设备应该拥有相同的指定。地址被烧入设备的ROM中，因此不易更改。MAC地址是数据链路层的一部分。

尽管MAC地址旨在永久，但有办法通过将虚假地址写入数据包头部来“欺骗”地址。这不会改变设备的永久地址，但允许黑客避免通过其网络接口被识别。如果攻击者使用伪造的MAC地址获得了对网络的本地访问，特别是通过无线方式，他们可以避免通过其硬件被追踪。

# 第6章 基于 Web 的利用

既然你已经了解了网络漏洞攻击的工作原理，现在是时候探索基于 Web 的利用了。如今，一切都以这样或那样的方式连接到互联网，因此 Web 漏洞极其普遍。要找一家没有网络存在的公司是很难的。过去，网站非常基础，仅使用 HTML 编码，不涉及其他更复杂的编程语言。它们由简单的静态页面组成。然而，今天的网站涉及复杂的编程、混合数据库和身份验证服务器。每种类型的计算机，无论是智能手机还是台式机，都连接到互联网。

由于向网络世界的这种大量扩展，我们需要理解并进一步发展基于 Web 的利用手段。例如，计算机过去在本地安装和使用文字处理器和其他工具，如 Microsoft Office。现在，许多此类工具存在于云端，因此不再需要任何本地安装。一个常见的例子是 Google Docs。现在一切都连接在一起，对于有志成为道德黑客的人来说，充分理解基于 Web 的利用基础知识非常重要。

在本章中，我们将讨论 Web 黑客的基础知识以及一些概念，如网络爬虫和代码注入。一如既往，请花时间探索所有技术并练习它们，直到你不再需要使用任何备忘单。

## Web 黑客的基础知识

有许多专为 Web 应用程序黑客设计的基于 Web 的框架和工具。然而，只要你理解了基础知识，使用什么工具其实并不重要，因为它们大多数的工作原理完全相同。目的是拥有攻击 Web 所需的功能。基本原理是通过你的浏览器像往常一样访问任何网站，但你使用代理来发送流量。这样，你就可以收集并检查你向任何应用程序发送和接收的所有数据。让我们看看为了成为一名有效的 Web 黑客，你需要从这些工具中获得的一些最重要的功能。

拦截请求



能够在请求离开浏览器时立即拦截它们，是备受推崇的工具包功能。其核心思路是利用拦截代理作为关键，赋予你在请求到达目标——即基于Web的应用程序——之前修改任何变量的能力。这种拦截代理几乎是所有Web黑客工具都提供的功能。那么，它是如何工作的呢？

所有Web交易的基础，都托管着一个运行在Web服务器上的应用程序。其目的是接受你的浏览器请求，并根据这些请求显示相应的页面。请求中包含一系列变量，这些变量决定了应返回给浏览器的页面。例如，当你在进行在线购物时，这些变量规定了你添加到购物车的商品以及要检索的支付信息。作为黑客或渗透测试人员，你可以利用这些变量，因为借助Web黑客工具，你可以修改它们。这意味着你可以创建新变量、编辑现有变量，或完全删除它们。

## 查找所有网页

当你准备进行基于Web的攻击时，需要先勘察战场。这通过使用能够帮助你找到目标Web应用程序所有相关页面、目录和文件的工具来完成。提供此功能的工具被称为“爬虫”程序。你只需输入网页的URL，然后爬虫就会被释放。听起来相当戏剧化，但你必须明白，这种Web信息收集方法并不微妙。

该工具会一次发出成千上万的网站请求。每次发出请求，爬虫都会收到HTML代码。这些代码会被分析，如果发现更多Web链接，爬虫会向所有这些链接发送更多请求。最终，网站的所有信息都将被爬虫分析和归类。Web请求将一直发送，直到发现每一个攻击点。然而，请记住，爬虫会跟踪它找到的所有链接。这包括任何登出链接。如果发生这种情况，爬虫实际上会在不通知你的情况下登出网站。这意味着，如果你不小心，可能会因为登出链接而遗漏掉一些尚未发现的潜在有价值信息。务必分析爬虫抓取的内容，确保你感兴趣的所有区域都已被探索。

爬虫工具还允许你指定应重点关注哪些目录。这让你拥有更多控制权，并能更精确地分析目标。

## 分析响应以发现漏洞

你需要寻找的第三大重要功能是分析来自Web应用程序的响应的能力。这个过程类似，但应用于基于Web的应用程序。目标是找到漏洞。

当你借助拦截代理修改变量时，目标应用程序会对你做出响应。然后，该工具会检查所有这些响应，以寻找应用程序中的任何漏洞。许多漏洞可以被自动化的Web漏洞扫描器检测到，但其中一些可能不会被注意到。幸运的是，我们只对那些我们可以轻松找到的漏洞感兴趣。为什么？很简单，因为其中许多可以用来执行SQL注入攻击。自动化工具可能无法发现所有关键漏洞，但其中足够多的漏洞对我们来说将被证明是有用的。

## 爬虫

爬虫的概念可能是Web黑客中最重要的概念之一。在本讨论中，我们将使用一个已安装在Kali系统上的框架，即WebScarab。这个工具深受许多黑客和渗透测试人员的喜爱，因为它是模块化的。这意味着你可以借助插件对其进行自定义，直到它完美满足你的需求。现在，让我们以默认配置来进一步讨论WebScarab。

结果，我们获得了可用于访问受限页面或文件的有用数据。打开终端，输入以下命令启动WebScarab：

    webscarab

先别急着释放爬虫。首先，你应该确保程序是以“全功能界面”模式运行的。该工具的一些版本启动时是精简界面，这无法满足我们的目的。你可以点击“工具”选项卡来查看此选项是否已勾选。程序启用后，你需要通过先配置浏览器来使用代理。此操作的目的是强制所有Web流量通过WebScarab，就像它是一个过滤器一样。然后，该工具就能够操纵任何进行中的Web流量。

为了将Web浏览器设置为使用代理，你需要进入其网络选项。在我们的示例中，我们将使用Firefox，因此请转到“编辑”>“首选项”，然后点击“高级”选项卡，再点击“网络”选项卡。如果你使用不同的浏览器，设置路径应类似。只需查找任何与网络选项相关的选项卡。进入“网络”菜单后，点击“设置”。将打开一个“连接设置”窗口，你将使用它来将Firefox配置为使用WebScarab作为代理。现在勾选“手动代理配置”复选框，并在“HTTP代理”字段中输入127.0.0.1。接下来，你需要在“端口”字段中输入8008。最后，你应该勾选“为所有协议使用此代理服务器”复选框，然后点击“确定”以应用所有这些设置。

从现在开始，所有Web流量都将通过WebScarab这个中间人进行引导。但是，请记住，你需要该工具处于活动状态才能浏览任何网站。如果你停用WebScarab，每次尝试访问网站时都会收到连接错误，因为我们已将网络设置为使用它作为代理。另一件需要记住的事情是，所有网站都将显示“无效证书”消息。不要理会那个警告，因为在使用代理时遇到它是正常的。

配置完成后，你就可以开始爬虫过程了。在URL字段中输入目标网站的地址。一旦网站加载，它就会通过WebScarab运行。为了爬取你的目标，你需要在工具内右键点击URL并选择“爬虫树”。现在你可以探索与网站相关的每个文件。务必仔细检查它们，因为你可能会发现一些对你的渗透测试范围有用的信息泄露。

## 拦截请求

记住，我们的WebScarab工具充当你的Web浏览器和目标Web服务器之间的过滤器。所有互联网流量都流经此工具，这使我们能够在数据进入浏览器之前以及离开浏览器之前与之交互。这对我们意味着什么？我们获得了对传输中信息进行任何更改的能力。目前仍有大量网站编码不良，依赖隐藏字段与Web客户端之间来回传递信息。在这种情况下，程序员可能假设用户无法访问这些隐藏字段。然而，借助WebScarab这样的工具，我们可以操纵这些信息。让我们讨论一个场景，以便更好地理解如何利用这一功能。

假设我们正在一家如上述编码不良的在线商店购买一些钓竿。我们浏览网站，选择产品，将其添加到购物车，看到价格是100美元。现在，如果我们运行一个代理服务器，我们可能会看到一个隐藏字段，该字段在按下“添加到购物车”选项时用于向Web服务器发送100美元的值。因为我们将网站流量通过WebScarab运行，我们可以看到这个隐藏字段，甚至可以修改存储在其中的变量。我们可以简单地将100美元的值更改为1美元。这就是WebScarab工具所能实现的，然而，请记住，周围编码如此糟糕的网站并不多。无论如何，通过这样一个例子来演示借助WebScarab这样的程序拦截请求的力量是值得的。

现在让我们使用这个工具作为拦截器。为此过程，你需要将WebScarab切换回精简界面。转到“工具”面板并选择“使用精简界面”。接下来，你需要转到“拦截”菜单，并勾选“拦截请求”和“拦截响应”选项。现在切换到Firefox或你选择的浏览器。你现在可以通过允许WebScarab简单地拦截请求，然后找到你想更改的变量来更改字段的值。输入新值，点击“插入”按钮，就完成了！

## SQL注入攻击

代码注入攻击在在线世界中已经存在多年。有许多类型的代码注入，但由于我们的目标是掌握黑客基础知识，我们将只讨论SQL注入，这是一种至今仍在使用的经典技术。SQL注入大多用于绕过Web身份验证，但也可用于查看和操纵特定类型的数据。



当今运行的大多数基于网络的应用程序都使用解释型编程语言，并拥有某种后端数据库来存储数据或生成某种形式的动态内容。SQL 就是这种流行解释型语言的一个例子，被许多网站（例如在线商店）所使用。

想想在在线商店购物的过程。假设你正在寻找一根钓鱼竿。你访问一家销售户外产品的在线商店，在搜索引擎中输入“钓鱼竿”。点击“搜索”按钮后，应用程序会获取你的数据（钓鱼竿）并构建一个查询，以在数据库中搜索任何包含“钓鱼竿”字样的内容。任何包含这些关键词的内容都会以结果的形式返回给你。

通过使用 SQL，我们可以与数据库中的信息交互，甚至可以修改它（如果我们选择这样做的话）。但请记住，SQL 有多个版本，并非所有在线商店都使用相同的版本。例如，一条 MySQL 语句与 MSSQL 或 Oracle 语句并不兼容。在本节中，我们将只讨论如何与使用 SQL 的应用程序交互。如果你理解了基础知识，你总可以通过探索 MSSQL 或 MySQL 来扩展你的知识。

这里有一个例子：

```
SELECT * FROM product WHERE category = 'fishing rod';
```

在这个例子中，我们有第一个动词“SELECT”，它指示 SQL 在表中进行搜索。接着使用“*”符号来返回表中的所有列。下一个词“FROM”用于指定表。最后，我们有“WHERE”来指定应返回并显示哪一行。换句话说，“SELECT”命令将找到“product”表，并返回“category”列中包含“fishing rod”字样的所有行。在这个查询中需要注意的重要一点是，等号（=）左侧的所有内容是由应用程序的原始程序员创建的，而左侧（此处原文应为右侧，但根据上下文逻辑翻译为左侧更符合SQL注入的描述，原文可能为笔误）的内容则来自用户的指令。

我们可以利用这些知识来导致应用程序表现出非预期的行为。让我们不要在网站的搜索框中输入“钓鱼竿”，而是输入：

‘fishing rod’ or 1 = 1--

在这个例子中，我们使用单引号来关闭包含“钓鱼 rod”字样的字符串，然后我们添加了一个将被执行的命令（1 = 1--）。我们在搜索框中添加的“or”语句实际上是 SQL 中的一个条件，用于在两个语句中的任何一个为真时返回记录。行尾的“--”符号用于告诉 SQL 忽略其后的所有内容。这是一种防止任何其他代码可能干扰我们命令的方法。我们制作的新语句实际上告诉程序返回“category”等于“fishing rod”或“1 = 1”的表中的所有内容。由于“1 = 1”语句显然为真，我们将收到表中包含的所有内容。这可能看起来像是一个无聊的攻击，因为我们没有得到“fishing rod”的结果，而是得到了所有结果，但它在另一种场景中可能会很有用。

请记住，SQL 被用于许多 Web 应用程序的身份验证。让我们探讨另一个例子。假设你的一个朋友创建了一个网站，他的业务合作伙伴使用它来发送或下载重要文件。他们都有自己的独特账户，需要这些账户才能访问数据。这个朋友知道你是一名道德黑客，所以他要求你对他的网站进行渗透测试。我们现在将使用与上述示例相同的原理来绕过该网站的身份验证系统。首先在用户名文本框中输入以下文本：

‘or’ 1 = 1--

当你不知道账户的用户名时，你可以使用上述语句，它总是导致条件为真。这样做而不是输入用户名，大多数 SQL 数据库会选择第一个用户账户。在许多情况下，列表中的第一个用户是拥有系统完全权限的管理员。然而，使用这种方法的最大好处是，你甚至不需要知道账户的密码。输入任何随机密码，因为数据库会忽略它。为什么？因为我们的语句中的“--”部分。永远记住，这些符号之后的所有内容都将被注释掉，因此不会被执行。这包括密码。

然而，如果你确实知道用户名，并且出于任何原因想专门访问它，你可以使用相同的命令。

只需将指令输入到密码字段中，由于“1=1”始终为真，应用程序会认为密码正确，你将获得对指定账户的访问权限。

# 第 7 章 渗透测试的类型

渗透测试有助于测试计算机安全系统中的弱点。通常，这种漏洞可能是由于系统中的后门、软件错误或软件未按预期方式使用造成的。渗透测试旨在发现这些漏洞，并提供有关如何纠正情况的信息。

在选择渗透测试类型时，你需要根据测试的目标和范围来指导。有三种主要的渗透测试类型可供选择。这些类型包括：

- 白盒渗透测试
- 黑盒渗透测试
- 灰盒渗透测试

### 黑盒渗透测试

黑盒渗透测试模拟现实世界中的网络攻击，攻击者并不了解被测试计算机系统的所有内部细节。在黑盒测试中会发生类似的情况，测试人员只获得 IP 和一些其他重要信息，然后被要求自己收集信息并测试系统。渗透测试人员没有获得编程代码或任何内部人员可能获得的其他信息。

由于缺乏内部信息，这种渗透测试可能需要更长时间才能发现给定计算机系统内的漏洞和风险。通常，测试人员必须尝试几种方法才能发现任何东西。因此，有时黑盒渗透测试被称为“试错”测试。

#### 优点

以下是黑盒测试的一些重要优点：

- 测试人员发现了黑帽黑客会攻击的真实弱点，这使得安全地保护计算机系统免受此类攻击成为可能。
- 此测试的结果有助于验证系统规范与实际系统之间的差异。
- 不需要成为专家即可执行此操作。

#### 缺点

黑盒渗透测试的缺点包括：

- 该测试难以设计，因为它更像是一个试错过程。
- 它消耗大量时间。
- 可能无法捕捉系统中的所有问题。

### 白盒渗透测试

在白盒渗透中，测试人员了解给定计算机系统的所有内部细节。事实上，测试人员可能能够访问被测试应用程序的架构和源代码，以及只有内部人员才能获得的其他重要细节。由于渗透测试人员可以获取这些信息，与黑盒测试相比，此测试不需要大量时间。

白盒渗透测试是内部攻击的模拟。因此，测试结果在加强系统抵御内部攻击的安全性方面将更为有效，尽管也可能为抵御外部攻击提供重要建议。

#### 优点

白盒测试的优点包括：

- 它涵盖了被测试系统的所有区域。
- 它使得在执行任务时验证逻辑决策变得容易。
- 它涵盖了与漏洞相关的排印错误以及语法检查。

#### 缺点

白盒渗透测试的缺点包括：

- 它仅从内部人员的角度审视系统安全性。
- 由于测试人员掌握所有信息，他可能在选择测试区域时存在偏见。

## 灰盒渗透测试

这种测试类型是白盒和黑盒渗透测试的结合。它被认为是模拟黑客对系统有一定内部信息的攻击。渗透测试人员仅获得关于被测应用程序的有限信息以开始工作。

由于仅提供有关被测系统的部分信息，渗透测试可以同时使用自动化和手动测试流程。测试人员可以首先使用给定信息进行自动化测试，然后针对不太清楚的领域使用手动测试。该系统能够从外部和内部视角提供结果，从而帮助加强计算机系统抵御来自双方攻击的安全性。

## 优势

灰盒渗透测试的优势包括：

- 由于提供的信息有限，测试人员是公正且非侵入式的。
- 渗透测试人员与开发人员之间没有接触，因此不存在个人冲突的风险。

## 渗透测试团队

对于任何给定系统，通常由多人团队进行渗透测试，尤其是在处理大型复杂计算机系统时。这些团队根据团队成员的工作方式分为不同类型。以下是渗透测试团队的三种主要类型：

- 蓝队
- 红队
- 紫队

*红队*

这是一个主要由个人渗透测试人员组成的团队。团队的主要目标是模拟攻击，并在给定计算机系统中发现漏洞和风险。他们的工作还包括编制并提出针对已识别风险和漏洞的最佳可能解决方案的建议。

*蓝队*

蓝队通常被认为是内部人员团队。它由来自特定组织内部的计算机安全专家组成。其在渗透测试期间的主要任务是抵御来自红队的任何形式的攻击。参与该团队的人员完全了解系统，并共同努力保护其免受任何形式的攻击。

在实际工作环境中，红队和蓝队就像同一枚硬币的两面一样工作。因此，团队需要共同努力保护他们正在处理的计算机系统。这需要共享反馈并积极主动地开发新的系统解决方案。

*紫队*

## 密码哈希

您输入计算机的密码以哈希形式存储在磁盘上。它们不是以明文形式存储，而是加密的，您需要root/系统管理员权限才能访问它们。在Windows操作系统上，这些哈希存储在本地磁盘的SAM文件中，而在Linux系统上，它们存储在etc./shadow文件中。解密和破解这些密码非常耗时，您必须确保在需要的时间内完全访问所述PC。

第一种方法是使用字典——使用字典查找隐藏在这些哈希中的密码是最快、最简单的方法。系统会遍历字典中的单词，并尝试访问每一个。手动执行此操作似乎几乎不可能，但您的PC能够在几分钟内遍历这些并破解密码。

其次是彩虹表——此过程基本上是对字典已发现内容的再次检查。它重新哈希密码并将其与原始哈希进行比较。这是一个耗时的过程。

第11章　黑客攻击——人人都会遭受的影响

在公众看来，黑客攻击的许多影响都是负面的，因为公众并不总是能看到黑客攻击也有积极的一面。

凡事都有利弊，黑客攻击也不例外。当你入侵他人时，无论你是否有意，你总会让他们暴露在黑客攻击所带来的恶意影响之下。

当你入侵一台计算机时，你实际上是在突破计算机的安全防线。这将使受害者的敏感数据和隐私面临风险。这些黑客活动通常是为了获取人们倾向于存储在网络中的机密信息，例如社会安全号码、银行账户数据、信用卡号码和个人照片。有些黑客倾向于利用这些信息来伤害被他们入侵的对象。还有一些黑客则只是"获取"这些信息，以向他们的"受害者"证明存在的重大安全问题，促使他们修复这些漏洞，从而防止他们已经获取的个人敏感信息再次被盗。

一旦计算机的安全系统被攻破，数据还有可能丢失甚至被篡改。黑客一旦获得访问权限，就可以进入网络删除存储在其中的任何敏感信息。一旦你的系统被入侵，你计算机上的所有数据都面临着极大的丢失或被篡改的风险，这种篡改可能会且极有可能会对你造成伤害。

人们与黑客联系最密切的事情之一就是身份盗窃。身份盗窃是指未经授权的人冒用你的身份。你的身份不仅仅局限于你的社会安全号码、出生日期或其他任何可以证明你身份的信息。这种行为通常带有恶意，用于黑客的个人利益或目的。

当你被入侵后，黑客可以借助技术的进步追踪你在计算机上的一切操作。键盘记录软件被用来追踪你在计算机上敲击的每一个按键。多亏了这种软件，黑客可以立即获取你的密码、银行账户信息以及任何其他可以用来伤害你的信息——所有这些都只需一个小小的程序。

DOS是指拒绝服务攻击。当黑客入侵你的网络和计算机时就会发生这种情况。这会导致授权用户无法使用计算机的资源。通常，DOS攻击会针对某个网站，导致该网站长时间无法访问。这会给网站用户带来不便，同时也会影响网站的正常运营。

与身份盗窃一样，信息泄露也是有人出于恶意入侵你网络时经常发生的事情。这对任何人都可能造成危害，但尤其对那些最终被入侵的企业危害最大，因为它们不想公开的敏感信息会被泄露出去。不仅如此，电子邮件地址、客户信息等等也可能被盗取和泄露。

在黑客攻击方面，国家安全甚至也会面临风险。入侵政府网络的黑客可以接触到国防系统以及许多其他系统，这将对国家的安全福祉造成严重后果。当有人入侵政府系统时，不仅国家安全面临风险，美国公民的福祉也同样面临威胁。

黑客攻击的另一个影响是欺诈。黑客可以通过让计算机感染联网病毒，将其变成"僵尸"计算机。这些计算机随后被用于被认为是欺诈性的活动，例如向其他网络发送垃圾邮件和网络钓鱼攻击。

你如何知道自己被入侵了？你的计算机性能速度很可能会下降。你可能还会开始注意到出现了一些不该存在的文件。这些文件的大小可能会增加，也可能在你从未操作过的情况下被修改。你还可能开始注意到网络设置发生了变化，甚至是频繁的磁盘崩溃。

保护计算机的唯一方法是安装可靠的杀毒软件，并确保在连接互联网之前启用防火墙。此外，请确保定期安装系统更新。

# 第12章 I2P

I2P，亦称“隐形互联网项目”（https://en.wikipedia.org/wiki/Invisible_Internet_Project），是人们用于隐藏在线IP地址的另一种选择。它与其他网络共享许多相同特性，即通过相邻节点路由流量。开发者表示，他们的主要目标并非实现100%的匿名性（有人认为这不可能），而是使系统从外部攻击起来过于棘手且成本高昂。这是一个匿名网络，通过系统传输的所有数据都包裹着多层加密。

### I2P 与 Tor 的比较

你可能觉得这听起来很像Freenet，但相似性其实更接近Tor网络。I2P提供与网站、博客、论坛、聊天和搜索引擎的交互功能，且无需在本地安装任何此类服务。这些都是I2P的标志性特征。存在于I2P网络中的网站被称为Eepsites，它们通过I2P进行匿名托管，访问这些网站严格要求使用I2P。从这个意义上说，它类似于只能通过Tor访问的.onion网站。每一台连接到I2P网络的PC都参与转发加密数据包，在最终目的地之前通过代理传递。每个后续代理在不同间隔剥离一层加密，直到加密完全移除。关键在于：无人知晓这些数据包的来源，这也是Tor共有的特性。虽然Tor和I2P的目标确实不同，但存在许多相似之处：

- 两者都作为匿名网络存在
- 两者都使用分层加密来传输数据
- 两者都有隐藏服务
- Tor有出口节点，I2P有出站代理

### Tor 相对于 I2P 的优势

- 用户基础比I2P更大；获得学术机构支持，稳定性和抗攻击能力持续改进
- 资金来源于全球多个国家
- 拥有大量出口节点
- 已翻译成多种语言
- 针对出口流量进行优化
- 内存优化优于I2P
- 使用C语言编写

### I2P 相对于 Tor 的优势

- 隐藏服务速度远快于Tor网络。
- 遭受拒绝服务攻击的次数少于Tor。
- 兼容P2P文件共享（Tor不支持）。
- Tor隧道持续时间比I2P长得多。这减少了攻击机会，因为黑客可用的样本数量有限。
- 每个节点都为他人路由数据。
- 提供TCP/UDP支持。
- 使用Java编写。

如你所见，两个网络对匿名性来说都足够安全，只要你不是全球通缉的目标。通常，用户的匿名性会因其自身疏忽行为而被打破——在大多数情况下，他们的过度自信是最薄弱的环节（在多个网站使用相同登录名，将其与Tor和非Tor网站混用，以及启用JavaScript/Flash）。由于I2P并非设计为WWW的代理，如果你想匿名浏览网页，应该使用Tor。I2P上的出站代理，正如你可能猜到的，类似于Tor的出口节点，但它们获得的支持较少，且往往不稳定。因此，你应该用Tor进行匿名网页浏览，用I2P访问I2P的Eepsites。一个选择是使用Foxy Proxy（https://addons.mozilla.org/en-US/firefox/addon/foxyproxy-standard/）自己测试。但请注意，由于出站代理数量少于Tor出口节点，对手可能更容易识别你的活动。这完全取决于你愿意承担多少风险，以及如果被抓获（在哪个国家）会有什么后果。

你也可以将I2P用于BitTorrent和iMule以及其他P2P应用。与Freenet类似，你会发现I2P的使用时间越长且不间断，速度就越快。种子下载会更快。数据将如闪电般下载。Tor用户会为此感谢你。Tor上已经有太多种子用户，他们堵塞了网络，使得那些比下一张Incubus CD更需要匿名进行政治行动的人们陷入困境。

虽然I2P是匿名性的技术利器，但它可能有点像纸牌屋。一旦从底层抽出一张A（由你），它就可能变得无用。I2P只是一个工具，Tor和Freenet也是如此。它不是隐形斗篷。做一些愚蠢的事情，比如在一群兽人看向你方向时移动太多，你肯定会被一支箭射中最意想不到的地方。因此，通过主动采取匿名措施来明智行事：

### 1.) 关闭Javascript

是的，这值得重复，我们挥手强调并大声疾呼。Javascript不仅是Tor的克星，也是其他依赖隐藏IP地址网络的祸害。让这个可怕的插件保持开启状态允许代码在你的机器上运行，这些代码会揭露你。查看你的浏览器设置并禁用它。同时禁用Cookie。超级Cookie已被部署在野外用于追踪Tor用户。不要让它在I2P上发生在你身上。Javascript可以泄露大量用户指纹的度量标准。显示分辨率、页面宽度、字体等都可以被偷偷发送给对手。如果你有疑问，请查看Mozilla的Web API：

[https://developer.mozilla.org/en-US/docs/Web/API](https://developer.mozilla.org/en-US/docs/Web/API)

### 2.) 沉默是金！

别吭声。当然，你可以说话。但请避免讨论：天气、你的地理位置、你的爱好、你所在城市刚因嫖娼被捕的政治人物。如果有人问，“你镇上的天气怎么样？”你就说：“晴天。”每次都这样。或者，你可以提供错误信息。中情局这么做，你为什么不行？他们的整个组织都建立在保密和欺骗之上。不要对一些善意的谎言过于内疚。散布关于天气和地方政治等琐事的错误信息，真的能让对手束手无策。就业情况也一样。如果你被问到工作，而你是个程序员，就说你在邮局当分拣员。他们不会问你关于最新的猫王邮票的事。

### 3.) 轮换用户名/昵称

# 第13章 防范网络攻击

你能做些什么来防范网络攻击？你是否拥有合适的系统和流程来保护你的公司免受攻击？在2017年至2018年间，许多组织遭受了某种形式的网络攻击。其中大部分归因于不当的安全措施。一些组织根本没有建立强大的安全平台，因此黑入它们基本上就像黑入当地图书馆的个人电脑一样容易。

## 网络攻击的类型

人类行为是网络攻击最糟糕的诱因之一。让犯罪分子进入你的安全平台非常容易。他们只需要获得某人的信任，你就完了。因此，学习如何识别威胁以及如何保护自己免受这些潜在威胁的侵害非常重要。

网络攻击有两个大类：语义攻击和语法攻击。

### 语义攻击

语义攻击涉及社会工程学。这些攻击是通过改变黑客目标组织内某人的行为来进行的。与语法攻击不同，所涉及的软件只扮演非常次要的角色。语义攻击基本上是关于感知的（[Noor 等人，2017](https://example.com)）。

网络钓鱼是最流行的语义攻击之一，黑客发送电子邮件，希望能从受害者那里收集一些信息。你可能直到为时已晚才意识到网络钓鱼攻击，因为黑客克隆了你经常往来的通信方的电子邮件。这些人是你信任的，因此你几乎不会反复核实以确保电子邮件是合法的。

一旦你点击了电子邮件中的链接，你就会被要求提供一些信息来帮助他们验证你的账户。这样做时，你自愿提供了黑客击垮你所需的所有访问凭证。一些网络钓鱼攻击还可能包含病毒和蠕虫。然而，其操作手法是诱骗你相信电子邮件地址是合法的，从而自愿提供黑客需要的信息。社会工程学最糟糕的一点是，一些攻击是语义攻击和语法攻击的结合，因此，其影响可能是毁灭性的。

### 语法攻击

语法攻击是通过不同渠道针对你的网络发起的。这些攻击通常通过恶意程序进行。用于语法攻击的最常见的程序详述如下。

*特洛伊木马* - 特洛伊木马看起来是无害的。你会允许它进入你的系统，而没有意识到它带来的危险。如今，特洛伊木马可以通过多种方式发送，包括黑客克隆的电子邮件。该电子邮件看起来像是来自你认识或信任的人，但其主要目的是窃取你的信息或破坏你的系统——无论黑客发送它的原因是什么。

*蠕虫* - 蠕虫是独特的。它们不需要其他程序的操作就能通过你的计算机或网络传播。蠕虫通常被部署为秘密代理。它们收集有关你网络的信息并报告给黑客。它们在网络中传播非常快，一旦黑客达到目的，就可以使网络瘫痪。

*病毒* - 病毒基本上是附加到另一个程序或文件上的程序。当你访问受感染的程序或文件时，它们会复制。病毒在共享和下载的文件以及通过电子邮件发送的附件中很常见。当病毒被激活时，它会将自己发送给你联系人列表中的每个人。

## 如何保护你的业务

你需要实施一个好的安全计划和一些策略，以帮助你保护平台并维护你的利益。鉴于 GDPR（通用数据保护条例）的实施，许多公司正在改变其运营方式。（也许巨额罚款的威胁最终还是奏效了。）GDPR 的一个好处是，它允许普通消费者重新控制他们的数据以及如何访问这些数据。考虑到这一点，当客户认为公司没有采取足够的措施来保护他们的数据时，他们也可以随时举报。为了确保你不会发现自己站在法律的对立面，我们提供了一些指南，可以帮助你保护网络并防止网络攻击。

## 威胁识别

养成向你的系统报告任何威胁的习惯。像未经授权访问这样简单的事情，在为时已晚之前对你来说可能意义不大。在网络安全方面，任何事情都不算太小，不值得报告。随后发生的信息丢失或无法访问重要服务就是证明。

如今，许多公司处理非常敏感的信息。这些信息会吸引大多数黑客，尤其是当他们意识到你的系统使用了弱安全协议时。记住，黑客总是在网上搜寻可以利用的漏洞。你不应该给他们这个机会。

如果有人要攻击你，至少要在他们尝试时让他们的生活变得艰难。采取适当的预防措施，确保公司的重要信息的安全。在威胁发生时及时识别并报告，以便相关方和当局能够调查它们，并在事情失控、你失去一切之前，让你安心。

## 预期会受到攻击

在当今的数字世界中，预期攻击随时可能发生是谨慎的做法。这样，你将在运营时时刻准备好应对攻击。考虑到这一点，所有业务运营都将在适当的制衡机制下进行。

尝试确定你处理的信息类型，并将那些对黑客可能极其重要的信息与那些不那么重要的信息分类。黑客可能会为了任何种类的信息而攻击你的公司。有些人可能会潜伏在你的系统中，希望能找到进入其他公司系统的突破口，尤其是如果你与作为第三方的其他大公司打交道的话。

敏锐的风险评估流程将帮助你在问题出现时就确保拥有正确的解决方案。你可能不确定你处理的信息类型是否对黑客有吸引力，因此最好的方法是确保所有信息都受到保护。

## 员工管理

没有人比你的员工更了解你的业务。他们是维持你业务运转和生存的人。让他们保持快乐并有动力朝着你业务设定的相同目标努力，这是理所当然的。

在数字时代，忠诚度很难获得。你希望员工竭尽全力保护你组织的神圣性的愿望可能难以实现。然而，你可以采取措施确保你永远不会冒被你信任的人从背后捅刀子的风险。一支有积极性的员工队伍总是一件好事。

除了激励员工之外，还要努力确保他们了解自己在组织中的角色以及法律要求的数据保护措施。确保每个人都理解他们的责任以及他们所处理或保护的数据的责任范围。有时人们会无意中泄露信息，因为他们不了解所涉及的风险或其行为的法律后果。从长远来看，对员工进行适当的法律责任教育可以拯救你。

尝试培养一种让人们对自己行为负责的环境。这鼓励员工诚实，并意识到他们控制着某些东西。他们是重要事物的照料者和保护者。话虽如此，你还必须采取预防措施，在你期望员工完成的本职工作之外，安装额外的安全层。你的员工并不总是与你朝着相同的目标努力。在可能的情况下，使用密码管理器确保每个人都使用合适的密码。

## 双重身份验证

每个人都在使用它，为什么不在你的公司实施它呢？你可能已经注意到，你使用的大多数应用程序都已经切换到双重身份验证。从 Facebook 到 Gmail，每个人都在为你的数据增加一层额外的保护。尝试为你的公司做同样的事情。

双重身份验证通过增加额外的验证步骤来访问账户，从而帮助保护你的系统和数据安全。鼓励你所有的员工使用它。一旦你输入密码，你会收到一条带有验证码的消息，以验证是否是你本人。只有输入这个代码后，你才能访问你的账户。



在你的手机上，没有它你就无法访问账户。这使得攻击者很难针对你的系统，迫使他们寻找其他途径。

虽然你可能无法阻止黑客试图攻击你的系统，但你可以尽力完全劝阻他们。让访问过程尽可能不便和困难是实现这一目标的最佳方式之一。

## 系统审计

你上次对网络进行系统审计是什么时候？你确定你的网络健康状况吗？你需要进行内部审计和外部审计，以确保你的系统没有受损。

通过彻底的审计，你可以了解到自己暴露的漏洞。外部系统审计员还将根据行业法规对你的当前状况提出建议，以便你可以改进系统并运营合规的业务。

当你以小公司的形式创业时，系统审计之类的事情对你来说几乎没有意义，而且看起来你只是在花你没有的钱。你可能很久才会考虑一次。然而，随着业务的增长，你会达到系统审计成为强制性需求的地步。审计有助于降低被黑客攻击的风险。行业内有很多专家可以帮助你进行系统审计，包括那些在网络安全行业工作多年的人。他们对网络安全的理解将对你有利，并帮助你保护业务。

## 离职签归策略

如果你向员工发放移动设备、平板电脑和笔记本电脑，请确保他们在离职前将其归还签收。这一点很重要，以免机密信息泄露。你还必须研究通过网络和设备传递的任何信息的加密协议。这里的目标是维护机密性和完整性。

## 保险政策

在这个数字时代，针对网络攻击购买保险是明智的。黑客无处不在，考虑到你处理的数据和信息的性质，强烈建议你找到一份适合你业务的保险政策。在与你的保险商讨论相关风险时，你可以了解到很多关于未来挑战的信息，并以此作为解决可能风险场景的动力。在发生网络攻击时，保险政策将为你的业务提供保障。

## 网络攻击恢复能力

一旦你的业务连接到互联网，你所面临的风险性质是巨大的。黑客可能对你的运营产生极其有害的影响。如今，许多公司依赖互联网、社交网络和技术来在行业中保持竞争力。你需要确保你的公司具备网络恢复能力，从而避免与业务停机、收入损失以及你可能尚未意识到的许多其他成本相关的风险。

公司的规模并不重要。任何人都可能成为网络攻击的受害者。采取预防措施保护你的业务将有助于你在降低风险敞口方面获得优势，从而保护你的业务。此外，明智的安全状况也将对你有利，帮助你改善品牌形象和业务声誉，并能提高你对投资者的吸引力。

## 软件更新

保护你的业务免受攻击最简单的方法之一是确保使用更新的软件。科技巨头惠普透露，及时应用软件补丁可以防止至少 85% 的针对性网络黑客攻击。软件开发人员通常会根据需要频繁发布程序补丁，而且更常见的是为了应对当前全球商业世界中的网络威胁。考虑到这一点，请确保你获得所使用任何软件的最新更新。定期更新可保护你的系统免受漏洞影响。这就是开发人员不时发布更新的原因。

## 渗透测试

并非所有黑客都是坏人。有些黑客对你的业务有益。为了确保你运行一个技术上健康健全的业务，你应该考虑聘请专家进行渗透测试，并评估你系统的漏洞。这是一件你应该定期做的事情。你可以每月、每季度甚至每年进行一次，具体取决于最适合你的方式。这些测试的结果将帮助你识别弱点所在，顾问还将就如何处理这些弱点为你提供建议。

## 适当培训的必要性

如果你拥有世界上最好、最安全的系统，但你的员工不知道如何管理它，那就毫无意义。培训对于保护你的业务至关重要。大多数员工在不知不觉中欢迎黑客进入你的世界。他们缺乏对安全政策和实践以及如何避免攻击的基本了解。

许多公司的员工使用官方业务账户在网吧登录计算机，同时，他们完成后忘记注销并清除浏览历史记录。

除了培训员工外，你还必须经常提醒他们所学的政策以及如何执行这些政策。确保每个人都遵守既定准则，否则你的员工将成为最薄弱的环节，就像他们一直以来那样。除了培训，确保每个人都明白为自己的行为负责的重要性。员工必须保护他们的部门和职责范围。数据访问是当今一个关键方面，不应掉以轻心。一旦每个人都明白他们的责任以及对所负责设备的问责，你将更容易减轻网络黑客攻击。

## 保护你的电子邮件

在众多攻击中，网络钓鱼攻击主要通过电子邮件传播。这是一种精心设计的社会工程形式，黑客说服收件人相信他们是值得信任的人。考虑到电子邮件是目前主要的通信形式，使用不受保护的电子邮件存在许多风险。为了保护你的电子邮件，你应该投资于筛选公司电子邮件的反垃圾邮件服务。

## 虚拟专用网络（VPN）

建议你购买 VPN 软件，并确保所有员工安装。如果他们需要访问公司服务且不在公司内部，必须先连接 VPN。VPN 加密通过它们交换的所有信息，从而提高你的安全性。通过这样的政策，所有通信都在加密通道上进行。有些组织甚至在工作中运行 VPN 服务，使得任何人难以侵入他们的系统。

## 灾难管理计划

确保你有一个可靠的灾难管理计划。在发生数据泄露时，你应该有一个恢复计划，以便在你尝试在幕后解决问题的同时，让业务尽快恢复全面运行。灾难管理计划不是一次性的事情。该计划必须定期测试和更新，以满足当前的业务需求，并突出对当前网络攻击风险的恢复能力。

rsyslog是一个守护程序，负责在UNIX或Linux系统中创建日志文件。每个Linux发行版使用不同的技术来部署日志文件。Arch Linux使用与Debian rsyslog功能不同的过程。由于我们讨论的是作为Debian系统的Kali Linux，我们将继续解释rsyslog并提供一些示例。

## 使用 TOR 和 VPN 保护自己

显而易见，对任何黑客来说最重要的是匿名性。如今，由于政府限制和持续监控，人们不得不寻找 TOR 和 VPN 等替代方案来保持匿名。在学习如何在 Kali Linux 中保持匿名之前，我们将详细介绍在这个万物互联的“矩阵世界”中保护自己的各种选择。

## 什么是代理服务器？

代理是你与目标服务器之间的中间人。想象一下，如果你想把一个包裹从纽约（你的所在地）送到科罗拉多（服务器所在地），而不是亲自前往递送，你会请朋友代为送达。在这里，你的朋友就充当你的代理。这就是代理服务器的工作原理。

存在多种代理服务器，例如 Socks4、http、https 和 Socks5。

## 黑客如何使用代理服务器？

进行密码攻击时，网站通常会因为请求过多而将你封禁。在这种情况下，你可以使用大量免费代理随机占据代理地址，然后攻击登录页面。这是一种被称为“cracking（破解）”的著名技术，常被新手黑客用来获取系统访问权限。

## 什么是 VPN？

VPN 是一种非常常见的广告，你可能在 YouTube 上观看广告时见过。虚拟专用网（Virtual Private Network，简称 VPN）充当中间人，但会以加密形式将你的请求发送给服务器，使服务器无法识别你。当服务器向你发送响应时，它也会再次加密并发回给你。请看下面的例子以更好地理解 VPN 的工作原理。假设你想给同学送一封情书，但除了你最好的朋友外，你不希望其他人读到它。于是你以一种无人理解的方式写好信，再由你的朋友转交给同学。请记住，你的朋友知道如何读懂它。他会将其解密后交给她，她也会以同样的方式回复。这就是 VPN 的基本工作原理。

## 互联网如何运作？

每台联网设备都有一个 IP 地址，政府可以通过不同技术轻易追踪它。当你发送邮件或浏览互联网而不使用任何匿名服务时，你只不过是 Google 等科技巨头的产品。他们会从你身上收集大量信息，并将你作为广告（ads）出售给企业。此外，你的一举一动都会被追踪，并帮助他们开发新产品。

通常，当你点击一个 URL 时，包含你请求的数据包也会同时包含你的 IP 地址和你要访问的服务器的 IP 地址。在通信过程中，它会经过多个称为 hops（跳）的路由器，最终到达目的地。数据包在传输过程中很容易被嗅探，并被用来获取关于你的信息。

例如，使用 traceroute 命令查看某个网站需要经过多少 hops，如下所示：

```
root @ kali: traceroute bing.com
```

你会得到输出，显示它到达最终目的地需要经过的路由器数量。当数据包传输时，任何人都可以嗅探它，并获取有关你和你的请求的敏感信息。

## 什么是 TOR？

出于对互联网安全性的关注，一些独立安全研究人员开发了一种名为 TOR 的网络，它会加密我们所经过的每一跳。TOR 基本上会让你的请求通过它的服务器中转，同时使你的数据加密且不可追踪。这将大幅提高系统的安全性。但请记住，这可能会降低你的网络速度，因为数据需要在多个节点之间传输。



> 加密服务器。但当你试图攻击目标主机时，最好使用TOR网络。

要通过命令行界面访问TOR，你可以输入以下命令。

```
root@kali:~# tor service start
```

这将为你启动TOR桥接电路，并使你系统发出的每一个请求都通过TOR服务器传输以到达目标服务器。

你也可以使用TOR项目包，其中包含浏览器，用于日常用途。TOR浏览器的一个好处是你的信息不会被追踪。
