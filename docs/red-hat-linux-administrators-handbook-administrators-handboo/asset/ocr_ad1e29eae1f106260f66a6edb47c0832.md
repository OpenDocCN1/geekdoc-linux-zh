# gunzip

Syntax:

```
gunzip [-v] file(s)
```

To decompress files to their original form, use the gunzip command.

gunzip attempts to decompress files ending with the extensions: .gz, -gz, .z, _z, Z, or .tgz.

The -v option displays a verbose output when decompressing a file:

```
gunzip -v README.txt.gz
README.txt.gz:      65.0% -- replaced with
README.txt
```

# gzip

Syntax:

```
gzip [-rv9] file(s)
```

The gzip command is another compression program. It is known for having one of the best compression ratios, but at a cost of being considerably slow. Files compressed with gzip are replaced by files with a .gz extension.

The -9 option yields the best compression, but at the sacrifice of speed.

The -v option is the verbose option which lists the size, and compression ratios for each file. Also, the -r option recursively transverses each directory, compressing all the files along the way.
