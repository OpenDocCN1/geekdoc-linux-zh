# Understanding File/Directory Permissions

As do all other UNIX and UNIX-like operating systems, Linux associates a file or directory with a user and a group. Consider an example:

```
-rw-rw-r-- 1 sheila intranet 512 Feb 6 21:11
milkyweb.txt
```

The preceding line is produced by the ls -l milkyweb.txt command on my Red Hat Linux system. The ls program lists files and directories. The -l option shows the complete listing for the milkyweb.txt file. Table 3-1 shows the same information in a tabular format.

# Table 3-1 Output of an Example ls -l Command

| Information Type | ls Output |
|---|---|
| File access permission | -rw-rw-r-- |
| Number of links | 1 |
| User (file owner) | sheila |
| Group | intranet |
| File size (in bytes) | 512 |
| Last modification date | Feb 6 |
