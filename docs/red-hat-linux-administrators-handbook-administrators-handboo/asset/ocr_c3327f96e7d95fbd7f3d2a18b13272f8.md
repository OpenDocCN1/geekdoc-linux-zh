# Setting executable file permissions

Program files that can be run by regular users should never have write permission set for anyone but the owner. For example, the program files in /usr/bin should have permission settings such that only root can read, write, and execute, and everyone else can only read and execute these files. Allowing others to write into a program file can create serious security holes. For example, if someone other than the root is allowed to write to a program such as /usr/bin/zip, a malicious user can replace the real Zip program with a Trojan-horse program that compromises system security and does damage to files and directories as it pleases. So, always check to make sure that the program files on your systems have proper permissions. You should run COPS frequently to detect permission-related problems.
