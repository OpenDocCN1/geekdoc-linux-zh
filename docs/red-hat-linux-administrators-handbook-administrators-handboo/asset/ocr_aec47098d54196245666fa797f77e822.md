# wc

Syntax:

```
wc [-lwc] filename
```

The wc (word count) command counts lines, characters, and words. If the wc command is used without any options, the output displays all the statistics of the file. The example file test.txt contains the following text:

```
the quick brown fox jumps over the lazy dog
```

```
wc test.txt
```

```
1  9  44 test.txt
```

The results indicate that the test.txt file has 1 line with 9 words containing 44 characters. To display only the number of lines, the -l option is used. The -w option displays only the number of words. The -c option displays only the total number of characters.
