# O: set option

The O lines are used to set global options for sendmail. The syntax for such a line is as follows:

```
O option name = value
```

Table 9-1 shows all the options available in the latest version (8.9.x) of sendmail.

# Table 9-1 Sendmail Options

|---|---|
| AliasFile=/etc/mail/aliases | Sets the name of the alias database file. Change only if you keep the aliases database some place other than /etc/mail/aliases. |
