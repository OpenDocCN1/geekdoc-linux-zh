Although the idea behind Linuxconf is very impressive, I'm not quite sold on the current state of the application. I found a number of annoying problems that are likely to be fixed in future versions. For example, many of the important help pages are missing or not done yet, and the error messages generated by Linuxconf itself are a bit cryptic in nature. Apart from these annoyances, it functions as expected. In short, I recommend that you consider Linuxconf as an ongoing development project that is very close to being mature.
