# ping

Syntax:

```
ping [-c count] [-s packet size] [-I interface]
```

This is one of the programs most widely used by network administrators, ping is used to check whether a remote computer is reachable via the TCP/IP protocol. Technically, this program sends an Internet Control Message Protocol (ICMP) echo request to the remote host. Because the response to an echo request is required by the protocol, the remote host is bound to send an echo response back. This allows the ping program to calculate the amount of time it takes to send a packet to a remote host. For example,

```
ping blackhole.nitec.com
```

sends ping messages to the blackhole.nitec.com host on a continuous basis. To stop the ping program, press Ctrl+C, which causes the program to display a set of statistics. Here is an example of output of the ping requests generated by the preceding command:
