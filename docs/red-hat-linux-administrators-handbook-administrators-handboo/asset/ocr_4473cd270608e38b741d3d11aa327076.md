# Using netcfg to configure a network interface card

You need to have X Windows working on your system to use netcfg. This program allows you to configure all aspects of the basic network configuration. You must run this as a superuser from X Windows. The initial window, shown in Figure 7-5, displays the current host name, domain name, and name server configuration.

![](bbox=[0.05, 0.35, 0.55, 0.65])

Figure 7-5 The Names tab of the Network Configurator window

To change the host name, the domain name, or the name servers, first click the Names tab. Simply modify the values and click Save. The program doesn't display any status message when you click Save, so it's a bit confusing at first. Also, the domain name displayed in the program comes from the search list (first entry in the list) in the /etc/resolv.conf file, so if you don't have any search list set up in this file, netcfg will not display any domain name.

To add, modify, or remove a network interface, click the Interfaces tab, shown in Figure 7-6, which displays the current network interfaces.
