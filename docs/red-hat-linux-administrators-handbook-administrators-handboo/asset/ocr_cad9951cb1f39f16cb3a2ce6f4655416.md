# Choosing Your Platform

Red Hat Linux runs on many hardware platforms, such as x86 PC clones, Alpha, and Sparc. This chapter focuses on x86-based installation, because it is the dominant Linux platform. Installation tasks on other platforms will vary slightly; consult the Red Hat Web site for the details.

# Checking Your Hardware Requirements

From the beginning, Linux has required minimum hardware to run. This has not changed yet. Red Hat Linux runs on very minimal hardware, but just being able to run Linux is different than running it to create a server-class operation. To find out whether your hardware is supported by Red Hat Linux, check the following Web site: http://www.redhat.com/support/docs/rh1.
