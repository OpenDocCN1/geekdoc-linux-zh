```
status)
status httpd
;;
restart)
$0 stop
$0 start
;;
reload)
echo -n "Reloading httpd: "
[ -f /var/run/httpd.pid ] && {
kill -HUP `cat /var/run/httpd.pid`
echo -n httpd
}
echo
;;
*)
echo "Usage: $0 {start|stop|restart|reload|status}"
exit 1
esac

exit 0
```

This is sh script is really a simple case (conditional) statement. You now are going to see an example of how you can create a new service script from an existing service script. Assume that your new service is called webmonitor and the executable is stored in /usr/sbin/webmonitor.
