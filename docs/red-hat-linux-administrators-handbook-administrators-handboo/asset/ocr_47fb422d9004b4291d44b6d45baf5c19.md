You have configured the new interface and set up a default gateway. Test your new interface by pinging a computer on your network, using the ping IP address command. If you can ping a remote host, you have successfully configured the new interface.

To modify an existing network interface, do the following:

+   1. Click Interfaces. Double-click the existing network interface line. Make changes as appropriate.
+   2. After you make and save the changes, deactivate the interface first and then activate it.

# Caution

If you are using X Windows on a remote terminal to run the netcfg program, do not ever deactivate the interface being used to provide network connectivity to your terminal. If you deactivate the interface that is needed for your remote X connection, your X session will not work any longer and you will not be able to activate the interface without local access.

To delete an existing network interface, do the following:

+   1. Click Interfaces. Select the existing network interface.
+   2. Click Delete to complete the process. The statements in the preceding Caution apply here.
