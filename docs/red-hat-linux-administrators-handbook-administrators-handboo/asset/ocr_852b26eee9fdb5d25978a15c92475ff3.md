This command adds a zone statement such as the following in the /etc/named.conf file:

```
// newdomain.com was created on^1999-02-03-13-30
```

```
zone "newdomain.com" {
    type master;
    file "newdomain.db";
};
```

This statement creates a newdomain.db file in /var/named (the working directory for my name server), which is shown in Listing 8-7

# Listing 8-7 The /var/named/newdomain.db File

```
@ IN SOA newdomain.com. hostmaster.newdomain.com. (
    19990206000  ; serial YYYYMMDDXX
    7200         ; refresh
    3600         ; (1 hour) retry
    1728000      ; (20 days) expire
    3600)        ; (1 hour) minimal TTL

; Name Servers
    IN NS ns.nitec.com.
    IN MX 10 mail.nitec.com.

; CNAME records
www IN CNAME www.nitec.com.
```

The script then appends the following lines to the end of the Apache server configuration (httpd.conf) file:

```
#
# Domain Configuration for www.newdomain.com
#
```
