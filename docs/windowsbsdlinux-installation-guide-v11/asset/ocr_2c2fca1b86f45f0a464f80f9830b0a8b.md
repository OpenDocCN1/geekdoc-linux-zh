the other hand, selecting "Windows" and pressing enter utilizes the "chain loading" mechanism, and invokes the "FreeBSD boot loader". The FreeBSD boot loader then loads Microsoft Windows 98 (SE) into the computer's memory.

10. That explains pretty much everything. After adding GRUB to your Master Boot Record (MBR), proceed with the installation as usual. The reader must note that he/she may install GRUB in one of two places, either the MBR or in the boot sector of the active partition. If you plan to use another boot loader on your system (for example, OS/2's Boot Manager, or Windows NT's NT Boot loader, or any commercial boot loaders like System Commander and Partition Magic), add GRUB to the "first sector of your root partition" and then configure the other boot loader to start GRUB (which will then boot Red Hat Linux).
