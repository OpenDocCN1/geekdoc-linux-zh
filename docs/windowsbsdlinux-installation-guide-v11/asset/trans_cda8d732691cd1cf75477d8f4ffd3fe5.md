- 8. 一旦切片创建完成并且 FreeBSD 切片内的分区设置完毕，我们就继续选择要在系统上安装的内容。根据预期用途以及你可用的资源，你必须做出正确的选择，决定安装什么以及不安装什么。你自己最能判断这一点。例如，A 先生只是为了好玩想试试 FreeBSD 4.8-RELEASE！那么“最小安装”就是他最好的选择。它既节省时间又节省硬盘空间。他的兄弟 B 先生是一名顶尖的内核开发者。他想要访问文档、完整的系统二进制文件和内核源代码。他会选择“Kern-Developer”预设发行版集。而如果你手头有足够的资源，或者你不想以后使用 pkg_add 工具安装软件包或手动从 ports 集合安装，那么你也可以选择“全部”安装选项。这将把所有内容都安装到系统上。因此，我们可以看到预定义选项的范围从安装最小可能的配置（最小）到全部内容（全部）。对于刚接触 Unix 和/或 FreeBSD 的人来说，几乎肯定应该选择其中一个预设选项。读者须注意：如果需要图形用户界面，则应选择以 X 开头的发行版集。XFree86 的配置和默认桌面的选择是安装后步骤的一部分。

- 9. 接下来，从可用选项列表中选择安装介质。我想你和我一样正在进行本地 CD/DVD-ROM 安装！使用方向键高亮显示“从 FreeBSD CD/DVD 安装”，然后按 Enter 继续安装。 （担心，[OK] 被高亮显示）。如果恰好你想进行不同类型的安装，请选择适当的选项并按照步骤操作。

- 10. 接下来会出现“确认安装”屏幕。你将被问及是否确定要在该系统上安装 FreeBSD。选择 [ 是 ] 并按回车键继续。如果需要，安装现在可以继续进行。读者须注意：这是中止安装以防止对硬盘进行更改的绝对最后机会。

- 11. 安装时间会根据所选的发行版、使用的安装介质以及计算机的速度而有所不同。会显示一系列消息以指示状态。当显示以下消息时，安装即完成：“恭喜！你现在已在系统上安装了 FreeBSD...”。

- 12. 接下来是安装后步骤。它通常涉及诸如“网络设备配置”、“配置网关”、“配置 Internet 服务”、“匿名 FTP”、“NFS 服务器”、“NFS 客户端”、设置“安全配置文件”、“系统控制台设置”、“设置时区”、“添加用户和组”等任务。有关每个步骤的详尽说明以及有用的屏幕截图，请参阅 FreeBSD 手册，网址为 http://www.freebsd.org。

- 13. 完成安装后步骤后，退出 /stand/sysinstall 系统安装实用程序，取出 CD-ROM，然后重新启动系统。当计算机重新启动时，由于你已将 FreeBSD 启动加载程序安装到硬盘的 MBR（主引导记录）中，你通常会在屏幕上看到类似以下的提示。它显示类似：F1 DOS，F2 FreeBSD，F3 Linux；每行一个。还显示默认：F1。FreeBSD 默认使用 3 阶段引导程序，这实际上是位于主引导记录上的引导块 /boot/boot0，主引导记录是系统引导程序查找并运行的磁盘的特殊部分，它只是显示可引导的切片列表。

- 14. 按 F1 引导进入 Microsoft Windows 操作系统。在我的电脑上，我成功引导进入了 Windows 98（SE）。到目前为止一切顺利！我重新启动并这次按了 F2，我也成功引导进入了 FreeBSD。 Bingo！你已经拥有一个双启动系统，它使用 FreeBSD 启动加载程序来引导 2 个操作系统。

- 15. 根据计算机的配置，首次引导进入 FreeBSD 时屏幕上会出现启动消息。尽管消息滚动得相当快，无法让你阅读任何有用的内容，但你始终可以使用 “/sbin/dmesg | more” 命令稍后阅读。最后，你将到达登录提示。使用安装期间设置的用户名/密码登录。读者须注意：Linux 切片尚未准备就绪，因为我们尚未定义根（/）目录和交换文件系统的挂载点。因此，为此以及更多内容，我们继续进行第 6 章：安装 Red Hat Linux 7.3（Valhalla）。读者须注意，如果你已经安装了 FreeBSD，可以跳过接下来的 2 章，直接进行 Linux 安装。
