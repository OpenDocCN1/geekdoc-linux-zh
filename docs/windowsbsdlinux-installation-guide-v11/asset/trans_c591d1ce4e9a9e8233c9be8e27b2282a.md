## 1.7 关于作者

Subhasis “savvy” Ghosh 从学生时代起就从事 GNU/Linux 和 FreeBSD（以及最近的 OpenBSD、NetBSD、Sun Solaris 和其他 UNIX 变体）操作系统方面的工作，至今已有约 7 年。在此期间，Ghosh 参与了多个 Linux 及 Linux 相关项目，包括 Linux 内核源代码的修改；在 Linux 和 FreeBSD 中分析、设计和实现进程间通信（IPC）机制；以及 Red Hat Linux 桌面、工作站和服务器的安装、配置和故障排除等工作。此外，在过去几年中，Ghosh 为 Linux.com、Linuxgazette.com 和 Linuxfocus.org 在线杂志撰写了许多关于 Linux 内核编译、GNOME 编程及其他主题的文章。

目前，22 岁的 Ghosh 是俄罗斯联邦莫斯科动力工程学院（Technical University）的工程专业学生，专攻“信息学与计算机科学工程”领域。他是微软认证专家（MCP）、MCSD，并持有 NT 4.0 的 MCP 认证；此外还拥有许多其他 GNU/Linux 及计算机行业相关认证。他的网页可在 http://groups.msn.com/Linuxdump 访问。

## 2. 常见问题（FAQ）

读者会有问题。因此，本 FAQ 部分旨在从读者的角度回答一些最明显的问题。请所有读者通读本节，找到个人问题的答案。

通读整个 FAQ 后，如果读者仍觉得自己还有“一两个问题”要问，请随时发邮件至 sahibshah_ghosh@linuxwaves.com。

- 1. *本指南的目的/宗旨是什么？*
- 2. *你为什么在本指南中使用“3”个操作系统？*
- 3. *你自己尝试过本指南中提到的步骤吗？你测试本指南所有内容所用的计算机系统配置是什么？*
- 4. *你的所有安装都是基于“CD-ROM”的安装类型。那么“Ethernet”、“FTP”、“HTTP”、“NFS”安装类型呢？*
- 5. *为什么有人需要在同一台计算机的同一硬盘上运行 3 个操作系统？我想在 2 个独立硬盘上运行 3 个操作系统。这本指南到底有什么特别之处？*
- 6. *为什么选 Red Hat？为什么不是 Debian GNU/Linux、Slackware、Caldera、SuSE、TurboLinux 等？*
- 7. *为什么选 FreeBSD、OpenBSD 和 NetBSD 操作系统？为什么不是 BSD/OS、Darwin、Irix、Sun Solaris、Digital UNIX、HP-UX、IBM–AIX 等？*
- 8. *你为 GNU/Linux 使用了哪个内核版本？*
- 9. *我按照本指南中的说明在计算机上安装了 3 个操作系统。但不幸的是，某个地方出了点问题。*
- 10. *你使用 GNU GRUB 引导全部 3 个操作系统。能告诉我原因吗？为什么不使用流行的 Linux Loader（LILO）或 FreeBSD 或 NT 引导加载程序？*
- 11. *我有较旧的 Red Hat、FreeBSD 和 OpenBSD 发行版和/或版本。它们能用吗？*
- 12. *我想获得有关 Linux 和 FreeBSD 的好资源。你能推荐一些吗？*
- 13. *我有一些建议、新想法和令人兴奋的评论。我可以发给你吗？*
- 14. *我有“安装相关”的问题/疑问，或者某些东西“失败了”，或者“这完全不奏效”？我可以把这些报告发给你吗？*
- 15. *你会不时更新本指南吗？我的“问题”会被列在这里吗？*
- 16. *本指南在互联网上有最新版本吗？*
- 17. （面向居住在俄罗斯莫斯科及周边地区的人们）*我有一台计算机系统，我很想在上面安装 3 个操作系统。你能否好心到我家来帮我安装和配置？*
- 18. （面向俄罗斯人民）*我们喜欢微软 Windows、FreeBSD 和 OpenBSD 操作系统。但“为什么”你没有使用常见的俄罗斯 GNU/Linux 发行版？我指的是“ASP Linux”、“Black Cat Linux”、“ALT ...”。*
