

## 3.7 挂载文件系统

你的电脑现在安装了 Microsoft Windows 操作系统，要么是 FreeBSD 4.8-RELEASE，要么是 OpenBSD 3.2-RELEASE 或 NetBSD 1.6.1 以及 Red Hat Linux 7.3，并且它们和平共处。够了吗？够了吗？我敢肯定，不够！我之所以在我的电脑上同时运行 Microsoft Windows 98(SE) + FreeBSD 4.8-RELEASE + Red Hat Linux 7.3（我正在用这台电脑编写你现在阅读的本指南的一部分），其中一个最重要的原因是我大部分时间都在 FreeBSD 和 Linux 上工作，但由于大学的项目，我需要访问 Windows。因此，我需要不时地访问 Windows 分区上存储的数据。但是，每当我在 FreeBSD 上工作并且需要访问 Windows 分区上的某些数据时，我根本负担不起重新启动电脑，登录 Windows，将文件复制到软盘，然后注销，再次重新启动，登录 FreeBSD，然后将软盘的内容复制到 FreeBSD 系统上的 /home/ghosh 目录的过程。这种过程既不漂亮，也不合逻辑，更不可行。多亏了 FreeBSD 和 Linux 系统上的 "mount" 命令，我每次偶尔需要访问 Windows 分区上的某些数据时，就不必经历这个“不漂亮，也不合逻辑，更不可行”的过程。

mount 命令绝对是 *nix 系统上超级用户（或 root）账户可用的最重要的命令之一。它允许 *nix 系统的 root 用户挂载文件系统（供普通用户访问和使用），这些文件系统可能位于同一台计算机上，也可能不在同一台计算机上。换句话说，mount 命令允许你使用访问远程节点的适当路径来挂载本地文件系统（物理上存在于同一台计算机上）或远程文件系统。mount 命令首次出现在 Version 1 ATTUNIX 中。请参阅你 FreeBSD 或 OpenBSD 或 Linux 系统上 mount 命令的手册页，以深入分析可以传递给 mount 命令的所有可能选项。

尽管它在 Unix 或类 Unix 系统上是一个非常强大的命令，但 mount 命令本身非常简单易用。mount 命令的语法是：mount -t filesystem device_name mount_point。这意味着你指示 mount 命令考虑名为 device_name 的设备文件，其文件系统类型由开关 -t filesystem 指定，然后将其 graft 到现有 FreeBSD/OpenBSD/Linux 系统的名为 mount point 的目录上。很可爱！

本章分为以下几个部分：

- 1. 在 FreeBSD 中挂载文件系统
- 2. 在 Linux 中挂载文件系统

### 1. 在 FreeBSD 中挂载文件系统

要在 FreeBSD 系统上挂载 Linux 第二扩展文件系统（ext2fs），我必须构建并安装一个定制的 FreeBSD 内核。在 FreeBSD 中构建和安装自定义内核很容易。我以 "root" 身份登录并执行以下步骤来构建一个：

- 1. 我从命令行执行：`cd /usr/src/sys/i386/conf`。如果你的系统上没有 `/usr/src/sys` 目录，则内核源代码尚未安装。最简单的方法是以 root 身份运行 `/stand/sysinstall`，选择 Configure，然后选择 Distributions，然后选择 src，然后选择 sys。
- 2. 我通过执行以下命令创建原始内核配置文件的一个副本：`cp GENERIC GHOSH`。在这里，我将要构建的内核命名为 GHOSH。请随意另行命名。
- 3. 我使用 ee 或 vi 编辑器打开 GHOSH 文本文件。尽管配置文件的总体格式相当简单，但所有可能的内核选项的完整解释超出了本指南的范围。请参阅 FreeBSD 手册以获取更多详细信息。添加以下行：`options EXT2FS` 这提供了识别 ext2fs Linux 原生文件系统的支持。如果愿意，可以调整其他选项，或者简单地保持不变。
- 4. 保存并退出。完成后，我输入以下命令来编译和安装新内核：`/usr/sbin/config GHOSH`。
- 5. 然后执行：`cd .././compile/GHOSH`
- 6. 执行："make depend"，然后执行 "make"，最后通过执行 "make install" 完成。
- 7. 新内核将被复制到根目录作为 /kernel，而旧内核将被移动到 /kernel.old。现在，重新启动系统以使用新内核。

完成此操作后，我尝试使用命令挂载 Linux 分区：`mount -t ext2fs /dev/ad0s3 /mnt/linux`；假设 /dev/ad0s3 是代表 Linux 文件系统的 FreeBSD 分区，并且 /mnt/linux 目录存在。文件系统应在指定的目录作为挂载点处挂载。

要挂载 MSDOS 分区以及 Windows 95/98(SE)/ME 格式的 FAT16 和/或 FAT32 文件系统，我执行以下命令：`mount -t msdos /dev/ad0s1 /mnt/windows` 其中，/dev/ad0s1 是代表我电脑上 Windows 98(SE) 分区的 FreeBSD 分区，并且 /mnt/windows 目录存在。要卸载，我简单地执行：`umount /mnt/windows`。要挂载基于 MSDOS 的软盘，我执行：`mount -t msdos /dev/fd0 /mnt/floppy`。要卸载，我简单地执行：`umount /mnt/floppy`。对于拥有 NTFS 文件系统的人，他们可以尝试使用命令挂载：`mount -t ntfs /dev/fd0 /mnt/floppy` 并使用以下命令卸载：`umount -t ntfs /dev/fd0 /mnt/floppy`。读者必须注意：NTFS 文件系统的写入支持有限。
