
## 计算机：

- 将 Red Hat Linux 7.3 可启动光盘放入光驱，然后重新启动计算机。我在此假设读者拥有 Red Hat Linux 7.3 发行版光盘。如果你使用的是较旧的发行版，那也完全没有问题。你随时可以使用它们。所有发行版的基本安装步骤都是相同的。请确保在 BIOS 设置中计算机可以从 CD-ROM 启动。如果无法从光驱启动，还可以使用其他启动方法。有关制作“本地”、“网络”和“PCMCIA”启动盘的更多信息，请参阅 Red Hat 安装指南。
- 稍等片刻后，应会出现包含 boot: 提示符的 Red Hat Linux 7.3 界面。该界面包含各种启动选项的信息。按“Enter”键进入基于 GUI 的安装设置，或在 boot: 提示符下输入“linux text”以进入基于 ncurses 的文本安装类型。我总是倾向于文本安装。观察启动信息，看看 Linux 内核是否检测到你的硬件。如果未能正确检测到你的硬件，你可能需要以专家模式重新启动安装。使用以下启动命令进入“专家”模式：boot: linux expert，然后按回车。
- 像往常一样继续，配置语言、键盘和鼠标。然后会出现“欢迎使用 Red Hat Linux”界面。继续前进，直到到达“安装”或“升级”界面。由于这是我们第一次安装 Linux，我们选择“安装”。现在这里出现的问题是：应该选择哪种安装类型，为什么？Red Hat Linux 7.3 提供 4 个选项：桌面、工作站、服务器和自定义。出于显而易见的原因，我们“不”考虑桌面、工作站和服务器的设置。因为它们不能为用户提供自定义特性和功能。因此，我们继续进行“自定义”安装。
- 像往常一样继续，在分区界面，系统会要求你在“fdisk”和“disk druid”之间进行选择。对于 Linux 专家来说，fdisk 是显而易见的选择工具。Disk druid 是 Red Hat 的图形工具，用于查看、编辑、添加和删除硬盘驱动器上的分区。你可以按自己的意愿选择。我在本指南中选择了“disk druid”。在下一个界面，你会看到整个硬盘驱动器的几何结构。请努力理解屏幕上显示的内容，并尝试结合本章前面的信息进行分析，我在前面详细讨论了分区问题。尝试将所显示的分区映射到 Windows 术语中。
- 在我的系统上，Disk Druid 最初将 /dev/hda 表示为 /dev/hda1、/dev/hda2 和 /dev/hda3 分区。/dev/hda1 是 FAT32 分区，（在我的计算机上）它包含 Microsoft Windows 98 (SE)，/dev/hda2 是 FreeBSD（或 OpenBSD）分片，/dev/hda3 是 Linux 分区。读者必须注意：/dev/hda3 分区是我在 FreeBSD 磁盘标签编辑器中通过将 131 分配给底层文件系统而创建的分片。
- 我保留 /dev/hda1 和 /dev/hda2 不变，并删除 /dev/hda3。结果，我获得了一些可用空间。然后我添加一个约 100MB 的 /boot 作为 ext2fs，接着添加一个约 128MB 的交换分区，最后通过将驱动器上的剩余空间分配给它来创建根分区（“/”）。这就是需要做的全部工作。因此，我们得到如下内容：

- 像往常一样继续安装，直到到达提示你选择引导加载程序的界面。这是本次安装中非常重要的一步，事实上，是最重要的一步。引导加载程序可以说是打开计算机后运行的第一个软件程序。主引导记录（MBR）是硬盘驱动器上的一个特殊区域，由计算机的 BIOS 自动加载。它是引导加载程序（无论是 LILO 还是 GRUB）控制整个引导过程的最早时机。GRUB 运行时，会读取其自身配置文件传递给它的指令（例如，Linux 加载程序的配置文件是 /etc/lilo.conf，GRUB 的配置文件是 /boot/grub/grub.conf），将重要指令传递给 BIOS，然后将相应的操作系统引导文件加载到计算机内存中。这进而使正确的文件系统能在正确的挂载点被挂载，从而让计算机为接下来的使用做好准备。因此，引导加载程序对于操作系统能否正确引导至关重要。
- 你可以使用 Linux 中可用的 2 个引导加载程序中的任意一个：Linux 加载程序（LILO）或 GNU 大统一引导加载程序（GRUB）。读者可以自由选择自己喜欢的任何一个。出于 FAQ 中所述的原因，我更喜欢使用 GNU GRUB。读者必须注意，本指南省略了 GRUB 的设计、实现和配置细节，因为这些内容超出了本指南的范围。互联网上有大量关于这些及其他“自由”和“专有”引导加载程序的信息。如果需要，可以去了解一下。

GRUB 是一个非常强大的基于 x86 的引导加载程序，可用于引导多种操作系统。GRUB 直接支持所有 GNU/Linux 发行版、FreeBSD、NetBSD、OpenBSD、Sun Solaris 等。它还支持使用“链式加载”技术引导其他专有操作系统。无论你的计算机上首先安装的是 Microsoft Windows 95/98 (SE)/Millennium Edition/NT/2K/XP，然后是 FreeBSD 4.8-RELEASE 或 OpenBSD 3.2-RELEASE；尽管放心，因为 GRUB 会凭借其强大的功能和动态特性处理好一切。如果你的计算机安装的是默认没有引导加载程序的 Microsoft Windows 95/98 (SE)/Millennium Edition（不同于 Microsoft Windows NT/2K/XP），那么就“将 GRUB 添加到 MBR”。

- 启动后，你会看到 GRUB 界面，提示你选择操作系统。如果你的计算机安装的是 Microsoft Windows NT/2K/XP，它默认使用“NT 引导加载程序”来引导操作系统软件，那么也请“将 GRUB 添加到 MBR”。不要惊慌！这完全不会造成任何问题。只是在这种情况下，成功启动后，你会看到 GRUB 界面提示你选择操作系统。列表中会有 2 个条目，例如，我有“Windows”和“Linux”。选择“Linux”并按回车会将 Red Hat Linux 引导文件加载到计算机内存中，然后计算机自举进入 Linux。然而，在
