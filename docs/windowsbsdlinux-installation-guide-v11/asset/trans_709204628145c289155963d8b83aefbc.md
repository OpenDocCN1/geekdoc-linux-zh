
editor. 读者必须注意：输入 “quit” 表示保存更改后退出编辑器，而 “exit” 表示不保存任何更改就退出编辑器。因此，我们执行 “quit”，而不是 “exit”。

- 13. 接下来必须设置磁盘标签以定义 OpenBSD 文件系统的布局。安装脚本将调用一个交互式编辑器让你进行此操作。我创建了一个约几千字节的交换分区，并将剩余空间分配给 “a” 分区，即文件系统上的 “root” 目录。安装程序现在将为你的磁盘进行标签设置并询问应在哪些分区上创建哪些文件系统。它将自动选择 ‘a’ 分区作为根文件系统。接下来它会询问你要在哪个磁盘和分区的哪个分区上创建文件系统。

- 14. 在所有文件系统创建完成后，安装程序将给你一个配置网络的机会。接下来，你将被提示配置网络接口、默认路由、主名称服务器的 IP 地址以及主机表。

- 15. 一旦所有这些完成，你就可以将发行版集提取到你的系统上。从 CD-ROM 安装时，系统会询问哪个设备保存发行版集。这通常是 “cd0”。接下来会询问要从 CD-ROM 的哪个分区加载发行版。这通常是分区 “a”。

- 16. 接下来你必须确定用于在 CD-ROM 上创建发行版的文件系统类型，这可以是 FFS 或 ISO CD9660。OpenBSD CD 发行版使用 CD9660 格式。

- 17. 你还必须提供 CD 上保存发行版的目录的相对路径，对于 i386 来说这是 “/3.2/386”。

- 18. 当所有选定的发行版集被提取后，你将被允许选择系统将使用的时区，安装系统所需的所有设备节点将为你创建，并且文件系统将被卸载。为使此操作正常工作，预计你已安装了至少 “base32”、“etc32” 和 “bsd” 发行版集。

- 19. 屏幕上会出现一条消息，告诉你 OpenBSD 3.2 操作系统已成功安装在你的计算机上。输入 halt 以停止系统并重新启动。

- 20. 当我第一次重新启动时，屏幕上会出现以下提示：F1 DOS，F2 BSD，每行一个。我按下 F1 功能键启动到 Windows 98（SE）并检查一切是否完美运行。事实证明，确实如此！然后我重新启动，这次我按下 F2，这将我登录到 OpenBSD 3.2。

- 21. 根据计算机的配置，当你第一次启动到 OpenBSD 时，屏幕上会出现启动消息。尽管消息滚动得相当快，无法阅读任何有用的内容，但你始终可以使用 “/sbin/dmesg | more” 命令稍后阅读。最后，你将到达登录提示。使用安装期间设置的用户名/密码登录。检查一切是否就位并尝试探索新系统。

- 22. 读者必须注意：就这样，这次关于 OpenBSD 的内容就全部结束了。我们仍有 Linux 需要安装和配置。因此，为此以及更多内容，我们继续下一章。第 6 章：安装 Red Hat Linux 7.3（Valhalla）。

## 3.5 安装 NetBSD 1.6.1

本章重点介绍安装 NetBSD 1.6.1 并多重启动系统，使其能够与计算机上已存在的 Windows 操作系统成功共存。与 Windows、FreeBSD 和 OpenBSD 安装一样，它也侧重于基于 CD-ROM 的安装。专家可以照常进行，无需帮助，对于新手来说，请确保查看 NetBSD 主页 http://www.netbsd.org 上提供的文档。这些和其他可在 NetBSD 1.6.1 CD-ROM 上获得的文档提供了有关 NetBSD 的所有方面的详尽和广泛的覆盖。在继续本指南之前，请确保从该网站获取尽可能多的信息。

**Note:** 我在此假设执行本章的读者在继续之前对 BSD 风格的硬盘分区和标签方案、设备命名约定等具有扎实的理解和知识。如果在这种情况下你对我所谈论的内容完全没有概念，或者一般对 NetBSD 一无所知，我强烈建议你回到涵盖 FreeBSD 的章节。

需要记住的几点重要事项：NetBSD 与 OpenBSD 类似地标记硬盘，使用 /dev/wd0 表示第一个硬盘，/dev/wd1 表示第二个硬盘，依此类推。NetBSD disklabel 允许最多 16 个分区。它可以检测并表示硬盘上存在的所有主分区。NetBSD disklabel 虽然可以看到扩展分区内的所有分区，但它不会列出扩展分区容器。读者必须注意 NetBSD 保留 c: 分区，该分区代表整个硬盘。i: 到 p: 保留给属于 NetBSD 以外的其他操作系统（例如 Windows 或 Linux 分区）的分区，而 a:、b: 和 d: – h: 可用于 NetBSD 特定分区。

### 安装步骤摘要

有关 NetBSD 安装的完整逐步介绍，请参阅 NetBSD 项目网站上提供的文档。与上一章一样，在这里我也只会提及安装的重要步骤。使用这些步骤在你的计算机上安装 NetBSD 并为其配置“多重启动”：

- 1. 现在，我们有一台运行 Microsoft Windows 操作系统的计算机。在我的 PC 上，它是 Windows 98（SE）。我将一张可启动的 NetBSD 1.6.1 CD-ROM 放入 CD-ROM 驱动器并重新启动系统。
- 2. 计算机启动，读取 CD-ROM，在屏幕上显示通常的硬件探测消息并为你呈现一个安装程序。读者必须注意：有几种方法可以将 NetBSD 安装到磁盘上。最简单的方法，如果你的计算机支持的话，就是从 CD-ROM 启动。否则，你可以从 3.5" 1.44MB 软盘启动。你现在应该准备好安装 NetBSD。
- 3. 蓝色的 NetBSD 1.6.1 安装工具称为 sysinst。一开始，你会收到一个 “Welcome to sysinst” 屏幕。选择选项 “Install NetBSD to hard disk” 并按回车。
