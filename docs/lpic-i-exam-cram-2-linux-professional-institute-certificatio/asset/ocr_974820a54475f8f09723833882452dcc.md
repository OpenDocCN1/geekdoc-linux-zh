# ## The ping Command

The `ping` command uses Internet Control Message Protocol (ICMP) `ECHO_REQUEST` and `ECHO_RESPONSE` packets to determine whether a host is functioning, or is at least able to respond to a ping.

`ping` is used for many things, including finding if a host is available, if a network can be reached, if a gateway is functioning, and so on.

`ping` is the simplest and easiest way to determine whether a host is alive, and it can show up to nine devices with the `-R` option. If you need to determine the route taken by a set of packets, it's more useful and accurate to use the `tracertoute` command, covered next.

To determine whether a host is functioning (or at least responding to an ICMP request), use this command:

```
`ping 192.168.1.1`
```
