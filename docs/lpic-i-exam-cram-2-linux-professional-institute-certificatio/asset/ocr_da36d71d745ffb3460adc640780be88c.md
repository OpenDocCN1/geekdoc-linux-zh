+   5. What is the purpose of running the **ldd** program?
+   
+   ○ A. Rebuilding links to library files
+   ○ B. Creating a link to a library file
+   ○ C. Displaying a program's required libraries
+   ○ D. Reading a program's library capabilities
+   
+   Answer C is correct because the **ldd** program, when used with a program name as the argument, shows the necessary libraries for the program's functionality. Answer A is incorrect because **ldconfh** is used to rebuild links to library files, not **ldd**. Answer B is incorrect because creating a link to a library file is done by the **1bconfig** or **ln** command, not **ldd**. Answer D is incorrect because the **ldd** command does not read a program's library capabilities; instead it reads its dependencies.
