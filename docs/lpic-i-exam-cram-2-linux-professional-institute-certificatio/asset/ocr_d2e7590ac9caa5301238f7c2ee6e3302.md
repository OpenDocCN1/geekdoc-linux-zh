The numbered steps in Figure 17.5 represent the steps that would be fol-
lowed during a normal name resolution. The following examples show how
different variations would work on a system with this configuration.

For example, we have issued the following command on a host with the sam-
ple configuration shown in Figure 17.5:

```
ping snowblower
```

When a name is used instead of an IP, the client software asks the system to
resolve that name. The system follows these steps:

+   1. The system first refers to the `/etc/nsswitch.conf` file and the `hosts:` line
+   for the order in which it should look for the name’s resolution. In
+   Figure 17.5, the `hosts:` line is set to first look at the local files, then `dns`,
+   and then `nis`:
+   
+   hosts: files dns nis

+   2. The system looks in the file `/etc/hosts` for the resolution of the name
+   `snowblower` to an IP; in this case, it finds a matching entry with an IP of
+   `10.0.0.2`.

+   3. The system returns the IP to the client and the name resolution por-
+   tion of the transaction is complete.
