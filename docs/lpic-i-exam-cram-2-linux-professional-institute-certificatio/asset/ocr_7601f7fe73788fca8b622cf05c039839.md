top reads its configuration from /etc/topre or .topre, where it can be restricted for use by users, removing some of the dangerous features. top runs interactively by default, refreshing every 5 seconds.

To make top do some fun things, try these:
top d 1 (runs and refreshes every 1 secs.)
top i (shows only active processes, toggleable)

Some of the interactive (inside top) options you can use are

+   > space—Updates the display immediately
+   > n—Provides help for top
+   > k—Kills a process; a prompt appears for the PID
+   > i—Either displays or ignores zombie/idle processes
+   > n—Is prompted for the number of processes to display
+   > r—Prompts for the PID to affect and then the new priority
