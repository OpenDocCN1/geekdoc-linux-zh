To display the *ifcfg-eth0* file, you would use the command shown here:

```
cat /etc/sysconfig/network-scripts/ifcfg-eth0
```

With a static configuration, you would see output similar to

```
DEVICE=eth0
ONBOOT=yes
BOOTPROTO=static
IPADDR=192.168.1.73
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
```

If the interface is configured for DHCP, you would see output similar to this:

```
DEVICE=eth0
ONBOOT=yes
BOOTPROTO=dhcp
```

Whichever method you decide to use can be implemented by editing this file and setting the parameters you desire. The parameters are self-explanatory, with the possible exception of the **BOOTPROTO** parameter. The **BOOTPROTO** parameter, when set to either static or dhcp, tells the network daemon how to configure this interface, either by reading the other parameters in the *ifcfg-eth0* file or by using DHCP to get the address.
