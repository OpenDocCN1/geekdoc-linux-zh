The /proc file system is where the SCSI device information is kept, in the /proc/scsi/scsi directory. You can view the devices and other information with the following command:

```
cat /proc/scsi/scsi
```

This produces the following output:

```
Attached devices:
Host: scsi0 Channel: 00 Id: 00 Lun: 00
    Vendor: VMware,   Model: VMware Virtual S Rev: 1.0
    Type:  Direct-Access        ANSI SCSI revision: 02
```
