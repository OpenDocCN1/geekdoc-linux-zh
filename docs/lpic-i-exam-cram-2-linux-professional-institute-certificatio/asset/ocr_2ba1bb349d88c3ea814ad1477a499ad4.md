+   10. Which of the following commands is valid to determine the authenticity or validity of a compressed archive of kernel source code or kernel patch code? (Choose all that apply.)

+   A. `rpm -K`

+   B. `md5sum`

+   C. `pgp`

+   D. `gpg`

Answers B and D are correct because the `md5sum` and `gpg` commands are used to establish the validity or authenticity of compressed archives of kernel code and patches. Answer A is incorrect because the `rpm -K` command helps verify an RPM package file, not compressed archives of code. Answer C is incorrect because there isn’t a command named `pgp` on a Linux system.
