Take a moment to understand why this command works the way it does. The \texttt{chmod} command has an \texttt{-R} recursive option that affects the object named and all its child objects. However, \texttt{bertrand} didn't ask you to change his home directory and all the contents, but just the contents, which is why the slash and asterisk characters are on the end of the target. This command acts on the entire \emph{contents} of \texttt{bertrand}'s home directory but leaves the directory alone.

The \texttt{chmod} command has surprisingly few options:

+   - \texttt{-c}---Reports only changed files
+   - \texttt{-v}---Reports all files
+   - \texttt{-n}---Changes symbolic links, not the original file
+   - \texttt{-f}---Suppresses error messages
+   - \texttt{-R}---Operates recursively through directories

> The \texttt{chmod} command's recursive option is an uppercase \texttt{R}, not a lowercase \texttt{r} as in some other commands. Familiarize yourself with the case of the various command options, and you will be fine.

# Symbolic Mode

When using \texttt{chmod} with symbolic values, keep in mind that you can force the permissions like the numeric mode, but a much longer command results. The primary reason to use symbolic mode is to affect, or alter, permissions rather than to set or overwrite them.

The symbolic mode uses a letter to identify the trios (user \texttt{=} \texttt{u}; group \texttt{=} \texttt{g}; other \texttt{=} \texttt{o}; and all \texttt{=} \texttt{a}), a qualifier (\texttt{+}, \texttt{-}, or \texttt{=} ), and then the permissions being altered or set (\texttt{r} \texttt{=} read; \texttt{w} \texttt{=} write; and \texttt{x} \texttt{=} execute).

To use the symbolic values to set permissions, you can do them all at once, like so:

```
chmod a=rwx file
```

This produces permission trios that are set to \texttt{-rwxrwxrwx} .

Or you can use each one of the identifiers with its qualifier and permissions separated by commas:

```
chmod u=rw,g=rx,a=
```

This produces a file that has its permissions set to \texttt{-rw-r-x\_\_\_} .
