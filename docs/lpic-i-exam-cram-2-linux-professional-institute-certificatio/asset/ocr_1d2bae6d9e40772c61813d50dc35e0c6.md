When you find the share's names on the target server, you can easily mount the share on a Linux system. You could mount the share from the command line or, even better, put an entry in the `/etc/fstab` file to have it mounted automatically.

Here's an example of syntax for the `fstab` entry:

```
//server/share    /mnt/mtpt    smb    user=user    1 1
```

# Domain Name System

DNS is how names are resolved to IPs across networks. As you saw in the discussion of name resolution in Chapter 17, “Basic Networking,” a host can refer to a number of sources to resolve a name for which it needs to know the IP.

At its simplest, a DNS server provides name resolution for hostnames to IPs, with a slightly more complex operation being to provide confirmation of a host's belonging to a particular domain.
