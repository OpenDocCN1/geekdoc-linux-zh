A, D. The *-J* option creates a disc with Joliet extensions, and *-udf* creates one with the UDF filesystem. Recent versions of Windows understand both of these extensions. The *-r* option creates a disc with Rock Ridge extensions, while *-hfs* creates one with an Apple HFS filesystem. Windows won’t understand either of these without special drivers, although Windows will still be able to read the underlying ISO-9660 filesystem (with 8.3 filenames).
