  - Apache: Maintain PHP settings (php.ini), Edit Apache configuration files (Enable and disable modules), Containers (Virtual hosts, Directories), Access control (.htaccess), CGI (ExecCGI, ScriptAlias), Commands: apache21 (–t, –S, graceful, restart), Configuring apache logs

  - Enable and disable queues
