
## OpenOffice.org Word Processor

### To Start with Word Processor

Click on Applications → Office → OpenOffice.org Word Processor

![](img/9a5b9efff92da1263a1b04aa9d4ae262_23_0.png)

The screen will be as follows:

![](img/9a5b9efff92da1263a1b04aa9d4ae262_23_1.png)

### Keyboard

![](img/9a5b9efff92da1263a1b04aa9d4ae262_24_0.png)

- 1. The keyboard has keys that can be pressed to make characters (letters, numbers, and symbols) appear on the screen.
- 2. Press means to touch a key on the keyboard hard enough to cause the character to appear on the screen and then release it immediately.
- 3. Press the "H" key now. (An "h" appears on the screen.) Next to the "h" is a blinking vertical line. This blinking line is the cursor which indicates the place on the page where something will be placed when you press a key. Press the "E" key, then press the "L" key and the "P" key. (The word "help" appears on the screen.)

### Space Bar

![](img/9a5b9efff92da1263a1b04aa9d4ae262_24_1.png)

The [Space Bar] key is the long key in the middle at the bottom of the keyboard. Press the [Space Bar] key. (The cursor moves one space to the right.)

### Shift key

![](img/9a5b9efff92da1263a1b04aa9d4ae262_25_0.png)

Pressing the [Shift] key along with a letter key makes the letters appear in capitals.

Type the word "Help" by doing the following:

- 1. Press and hold down the [Shift] key as you press the "H" key. Release the [Shift] key. (The letter "H" appears in capitals on the screen.)
- 2. Press the "E" key, then press "L", then press "P". (The word "Help" appears on the screen.)

### Mouse

![](img/9a5b9efff92da1263a1b04aa9d4ae262_26_0.png)

The device next to the keyboard is called a Mouse.

- 1. Moving the mouse causes the mouse pointer, I, to move on your screen.
- 2. Move the mouse up and down on the table top or the mouse pad. Notice that the pointer, I, also moves up or down on your screen.
- 3. Move the mouse to the left and to the right on the table top or the mouse pad. Notice that the pointer, I, also moves to the left or to the right on your screen.
- 4. Move the mouse so the pointer, I, is somewhere on the word “Help” that you just typed.
- 5. To click, put your right hand on the mouse. Put your index finger (the finger that you use to point) on the left button, press it and release the button.
- 6. Notice that the cursor (blinking vertical line) moves to where you click the mouse. Press the letter X. Letter x appears at the place where the blinking cursor was seen.

> **Think Tank**
>
> Can you see a small wheel on the mouse between the left and right buttons? Try to rotate the wheel and observe what happens.

### Commands

**To Open a New File**

![](img/9a5b9efff92da1263a1b04aa9d4ae262_28_0.png)

Click on File → New → Text Document. The text document Untitled 1 : OpenOffice.org Writer appears on your screen. The screen is where you see things happen like on a TV screen.

**To Save a File**

Click on File → Save

The Save dialog box appears.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_29_0.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_29_1.png)

Type the name of your file in the Name text box.

Click on Save button to save your text document.

**To Open an Existing File**

![](img/9a5b9efff92da1263a1b04aa9d4ae262_30_0.png)

The Open command is used to open an already saved file in Word Processor. Click on File → Open. The Open dialog box appears.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_30_1.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_30_2.png)

Choose the name of the file to be opened. Then click on Open button.

**To Close a File**

Click on File → Close

### Text Editing Features

![](img/9a5b9efff92da1263a1b04aa9d4ae262_34_0.png)

**To Undo Changes done in a Text Document**

Click on Edit -> Undo

Alternatively, you can press [Ctrl+Z] (a keyboard shortcut for Undo). This command will undo the last change done to the file.

**To Redo Changes done in a Text Document**

Click on Edit -> Redo

Alternatively, you can press [Ctrl+Y] (a keyboard shortcut for Redo). This command will reverse the action of the undo command.
