# OpenOffice.org Word Processor
Activity Sheet 5

Some suggested activities are:

+   1. Write a paragraph on ‘My Friend Computer’.
+   2. Use Spellcheck and Thesaurus to check your document and make appropriate changes.
+   3. Find the word ‘Friend’ and replace it with ‘Dear’ in the whole document.
+   4. Select difficult words from the English textbook. Type them in Word Processor and find out their meanings. Also find out the antonyms and synonyms of the words.

# Teacher’s Note

By clicking on Tools→ Language option in the menu bar, the teacher can select the desired dictionary.
