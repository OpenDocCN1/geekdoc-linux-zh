# Using Thesaurus

The Thesaurus helps you to improve your vocabulary by providing a list of synonyms (words with similar meaning) and related words.  
Click on Tools→ Language→ Thesaurus or press [Ctrl+F7]

![](bbox=[0.22, 0.26, 0.76, 0.55])

The Thesaurus dialog box is displayed. In the Meaning list, select the definition that matches the context of the word. Select the replacement word in the Synonym list. Click OK.
