# OpenOffice.org Word Processor

# Activity Sheet 2

Some suggested activities are:

+   1. Open Word Processor. Type your name, your class with section and the name of your school.
+      For example,
+      Ankita Kapoor
+      II A
+      Mayoor School

+   2. Save the file in Documents folder by the name "Myself".

+   3. Close the file.

+   4. Open the file and add the current date and day. Save your work and exit Word Processor.

+   5. Open the file and add the names of all family members. Save the file and exit.

+   6. Create a new file and type 5 sentences about any object in your Computer Lab. For example, computer, air conditioner, projector, etc.
