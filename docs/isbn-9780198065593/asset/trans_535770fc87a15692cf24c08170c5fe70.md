
## OpenOffice.org 文字处理

### 从文本文档中剪切文本

第一步是选择你想要剪切的文本。文本选择是通过按住鼠标左键并将鼠标指针拖过你想要选择的文本来完成的。一旦选定的文本被高亮显示，释放鼠标左键以完成选择。然后单击“编辑” → “剪切”。

或者，你可以按 Ctrl+X（剪切的键盘快捷键）。选定的文本将从屏幕上消失，并被粘贴到系统的临时内存（即剪贴板）中。

### 从文本文档中复制文本

第一步是选择你想要复制的文本。然后单击“编辑” → “复制”。

或者，你可以按 Ctrl+C（复制的键盘快捷键）。选定的文本仍将显示在屏幕上，并且也会被粘贴到系统的临时内存（即剪贴板）中。

### 在文本文档中粘贴文本

要粘贴你已剪切或复制的文本，请将光标放置在你想要粘贴文本的位置。然后单击“编辑” → “粘贴”。

或者，你可以按 Ctrl+V（粘贴的键盘快捷键）。

### 文本格式化功能

文字处理器允许许多种格式化样式。

### 格式化文本

第一步是选择要格式化的文本。然后单击“格式” → “字符”。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_36_0.png)

将显示字符对话框。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_37_0.png)

在字符对话框中，单击**字体**选项卡。

要选择字体，请滚动字体列表并停在你想要使用的字体上。字体列表显示了你当前使用的计算机上可用的所有字体。当你滚动字体列表时，预览窗口中会显示所选字体的预览。

要更改字体的字形，请从**字形**列表框中选择所需的字形。可用的字形类型包括：常规、常规斜体、粗体、中等斜体。

要更改字体大小，请从大小滚动框中选择。字体大小通常以点为单位表示。

单击**确定**按钮以将更改应用到所选文本。

### 进一步格式化文本

第一步是选择要格式化的文本。然后单击“格式” → “字符”。

将显示字符对话框。在字符对话框中，单击字体效果选项卡。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_38_0.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_38_1.png)

在颜色字段中，选择下划线颜色。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_39_0.png)

在删除线字段中，选择样式。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_39_1.png)

在字体颜色字段中，选择你要应用的颜色。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_39_2.png)

在效果字段中，选择效果样式。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_40_0.png)

在浮雕字段中，选择纹理样式。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_40_1.png)

此外，你可以从以下选项中勾选复选框，为所选文本添加额外效果。

- 轮廓
- 阴影
- 闪烁
- 隐藏

### 设置文本定位

选择要格式化的文本。然后单击“格式” → “字符”。将显示字符对话框。

在字符对话框中，单击位置选项卡。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_41_0.png)

在位置区域，为所选文本设置上标或下标选项。

上标用于减小所选文本的字体大小并将其提升到基线以上。

正常设置可去除上标或下标设置。

下标用于减小所选文本的字体大小并将其降低到基线以下。

### 为文本应用彩色背景

选择要格式化的文本。然后单击“格式” → “字符”。将显示字符对话框。

在字符对话框中，单击背景选项卡。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_42_1.png)

单击你想要作为所选文本背景的颜色，然后单击确定按钮。

### 文本对齐

### 使用菜单进行文本对齐

从菜单栏中选择“格式” → “段落”。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_44_0.png)

将打开段落对话框。

选择段落对话框的对齐方式选项卡。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_44_1.png)

有四种可用的对齐选项。选择所需的对齐方式，然后单击确定按钮。

左对齐

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_0.png)

段落的所有行都从左边距开始，右边距间距不均匀。

居中对齐

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_1.png)

每行在页面上居中。

右对齐

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_2.png)

段落的所有行都在右边距结束，左边距间距不均匀。

两端对齐

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_3.png)

段落的所有行都在左边距开始，并在右边距均匀结束。
