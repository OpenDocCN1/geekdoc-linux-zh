# OpenOffice.org Word Processor

# Drawing Toolbar

Click on View→ Toolbars-> Drawing.  
	The Drawing toolbar will be displayed.

![](bbox=[0.04, 0.21, 0.94, 0.27])

You can click on various shapes and draw attractive drawings. You can even use the Fontwork Gallery for attractive display.

![](bbox=[0.14, 0.39, 0.82, 0.77])
