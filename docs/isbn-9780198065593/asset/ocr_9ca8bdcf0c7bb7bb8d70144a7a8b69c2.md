# OpenOffice .org Word Processor

# Activity Sheet 4

Some suggeted activities are:

+   1. Create a bulleted list of fruits and a list of vegetables.

+   2. Create a numbered list of 'Things to do today’.

+   3. Create a numbered list of grocery items to be purchased. The teacher can first discuss the various items of grocery with the students and then the students can create lists.

+   4. Create a list of animals, birds, aquatic animals, etc., and apply different kinds of numbering styles to it.

+   5. Create a list of friends and apply different styles of coloured bullets to it.

+   6. Create a list of occupations, for example, doctor, tailor, lawyer, teacher, engineer, astronaut, etc.

+   7. Type and format a newspaper article. Use the drop cap feature and appropriate formatting features.

# Teacher's Note

Learners can be asked to write a newspaper article about the activities organized in the school. Learners will type the article and apply appropriate formatting features to it. The news can then be read in the Assembly.

For example,

> Inter-School Drawing competition, for children of age group 5-7, was Organized at Mayoor School, Ajmer. The theme of the event was ‘Conservation’ . Akshita Mehra of class II A, Mayoor School, won the first prize. She depicted ways to save water, electricity and our environment. Her efforts were praised by the judges.
