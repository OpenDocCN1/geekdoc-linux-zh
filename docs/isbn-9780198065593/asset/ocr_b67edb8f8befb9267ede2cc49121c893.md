# OpenOffice.org Word Processor

# To Open an Existing File

![](bbox=[0.42, 0.09, 0.52, 0.16])

The Open command is used to open an already saved file in Word Processor. Click on File→ Open The Open dialog box appears.

![](bbox=[0.27, 0.25, 0.7, 0.39])

![](bbox=[0.24, 0.39, 0.74, 0.69])

Choose the name of the file to be opened. Then click on Open button.

# To Close a File

Click on File→ Close
