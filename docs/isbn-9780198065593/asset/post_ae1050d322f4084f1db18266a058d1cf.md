## Create Bulleted and Numbered Lists

![](img/9a5b9efff92da1263a1b04aa9d4ae262_49_0.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_49_1.png)

We can make two kinds of lists in Word Processor: Bulleted List and Numbered List.

Bullets are symbols used to highlight items in a list. It is used in lists which do not have any particular order.

A numbered list is used to display information in a particular order.

You can use the default Bullets and Numbering settings by clicking on the appropriate button on the Toolbar.

Click on Format→ Bullets and Numbering

![](img/9a5b9efff92da1263a1b04aa9d4ae262_49_2.png)

### OpenOffice.org Word Processor

Bullets and Numbering dialog box appears.

Select the bullet style from the various options available.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_50_0.png)

You can also select colored bullets from the *Graphics* tab.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_50_1.png)

### OpenOffice.org Word Processor

Click on **Numbering type** tab to create numbered lists.
Select the style you want from the available styles.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_51_0.png)

Click on **Outline** tab to create sub-bulleted and sub-numbered lists.
Select the style you want from the available styles.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_51_1.png)

Click on **OK** button to apply the changes.

## More Text Editing Features

## Find and Replace

This is a very useful feature of Word Processor. It is used to search a particular word in the whole document and then replace it with the correct one. It is generally used to rectify a mistake that has occurred repeatedly in the document.

Click on Edit→ Find & Replace

![](img/9a5b9efff92da1263a1b04aa9d4ae262_56_0.png)

## OpenOffice.org Word Processor

The Find & Replace dialog box will be displayed.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_57_0.png)

Type the word to be searched for in the **Search for** text box. Type the correct word to replace it in the **Replace with** text box.

Click on **Find** or **Find All** button.

Then click on **Replace** or **Replace All** button.

## Using Spellcheck and Thesaurus

## Using Spellcheck

OpenOffice.org Word Processor has a built-in dictionary to check the spellings in the document. The Spellcheck proceeds from the current position of the cursor and checks the complete document.

## To Run Spellcheck

Click on Tools→ Spelling and Grammar

![](img/9a5b9efff92da1263a1b04aa9d4ae262_58_0.png)

## OpenOffice.org Word Processor

Spelling dialog box displays the first incorrectly spelled word in the document, as well as suggestions in the form of closest possible matches available in the dictionary.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_59_0.png)

1. **Ignore Once**, to ignore the spelling for just one occurrence.
2. **Ignore All**, to ignore the spelling in the complete document.
3. **Change**, to accept and change the spelling for just one occurrence.
4. **Change All**, to accept and change the spelling in the complete document.

## Using AutoSpellcheck

![](img/9a5b9efff92da1263a1b04aa9d4ae262_59_1.png)

AutoSpellcheck easily identifies incorrectly spelt words on the page as you type the document. The incorrectly spelt words can be seen with a single red wavy line beneath them. Right-click on the incorrectly spelt word and choose a suggested replacement from the list that appears. The correction is applied to the document.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_59_2.png)
