
## OpenOffice.org Word Processor

### Using Thesaurus

The Thesaurus helps you to improve your vocabulary by providing a list of synonyms (words with similar meaning) and related words. Click on Tools → Language → Thesaurus or press [Ctrl+F7].

![](img/9a5b9efff92da1263a1b04aa9d4ae262_60_0.png)

The Thesaurus dialog box is displayed. In the Meaning list, select the definition that matches the context of the word. Select the replacement word in the Synonym list. Click OK.

### Working with Graphics

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_0.png)

#### Insert Graphic as a Copy

1. Open the **Gallery** by clicking the **Gallery** icon on the Standard toolbar, or by selecting Tools → Gallery.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_1.png)

2. Select a **theme**.

3. Select an **object** using a single click.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_2.png)

4. Drag the object into the document, or right-click to open the context menu and select Insert → Copy.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_63_0.png)

#### Insert Graphic as a Background

1. Open the Gallery by clicking the **Gallery** icon on the Standard toolbar, or by selecting **Tools → Gallery**.
2. Select a theme.
3. Select an object by a single click.
4. Open the context menu and choose **Insert → Background → Page or Paragraph**.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_63_1.png)

#### Insert a Border around a Graphic

Select the graphic, then click on Format \ Picture...

Alternatively, you can right-click the graphic and select Picture...

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_0.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_1.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_2.png)

The Picture dialog box opens. Select the **Borders** tab.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_0.png)

In the **Line arrangement** area, select one of the five buttons to:

- set no border,
- set all four borders,
- set left and right borders only,
- set top and bottom borders only, or
- set left border only.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_1.png)

In the **Line** area, select an entry that determines the thickness and color of the line.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_2.png)

Click on **OK** button.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_3.png)

#### Drawing Toolbar

Click on View → Toolbars → Drawing. The Drawing toolbar will be displayed.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_66_0.png)

You can click on various shapes and draw attractive drawings. You can even use the Fontwork Gallery for attractive display.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_66_1.png)

### Function Keys for OpenOffice.org Word Processor

| Shortcut keys | Effect |
|---|---|
| [F3] | Complete AutoText |
| [Ctrl+F3] | Edit AutoText |
| [F7] | Spellcheck |
| [Ctrl+F7] | Thesaurus |
| [F12] | Numbering on |
| [Shift+F12] | Bullets on |
| [Ctrl+Shift+F12] | Numbering / Bullets off |
