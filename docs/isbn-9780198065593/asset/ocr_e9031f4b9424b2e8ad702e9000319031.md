# To apply Colored Background to the Text

Select the text to be formatted.
Then click on Format → Character. The Character dialog box will appear.
Click the Background tab in the Character dialog box.

![](bbox=[0.1, 0.45, 0.9, 0.83])

Click on the color you want as a background for the selected text and then click on OK button.
