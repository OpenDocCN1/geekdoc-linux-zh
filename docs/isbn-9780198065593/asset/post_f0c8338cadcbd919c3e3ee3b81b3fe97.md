
## OpenOffice.org Word Processor

### To Cut Text from a Text Document

First step is to select the text which you want to cut. Text selection is done by pressing and holding down the left mouse button and dragging the mouse pointer over the text you wish to select. Once the desired text is highlighted, release the left mouse button to complete the selection. Then click on Edit → Cut.

Alternatively, you can press Ctrl+X (a keyboard shortcut for Cut). The selected text will disappear from the screen and will be pasted in the temporary memory known as Clipboard of the system.

### To Copy Text from a Text Document

First step is to select the text which you want to copy. Then click on Edit → Copy.

Alternatively, you can press Ctrl+C (a keyboard shortcut for Copy). The selected text will still appear on the screen and will also be pasted in the temporary memory known as Clipboard of the system.

### To Paste Text in a Text Document

To paste text that you have cut or copied, place the cursor where you want to paste the text. Then click on Edit → Paste.

Alternatively, you can press Ctrl+V (a keyboard shortcut for Paste).

### Text Formatting Features

Word Processor allows many kinds of formatting styles.

### To Format Text

The first step is to select text to be formatted. Then click on Format → Character.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_36_0.png)

The Character dialog box will appear.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_37_0.png)

Click the **Font** tab in the Character dialog box.

To select a font, scroll through the font-list and stop at the one you want to use. The font-list shows all the fonts available on the computer you are using. As you scroll through the list of fonts, a preview of the font selected is displayed in the preview window.

To change the typeface of a font, select the desired typeface from the **Typeface** list box. Available typeface types are: Regular, Regular Italic, Bold, Medium Italic.

To change the size of a font, select from the Size scroll box. Font-size is commonly expressed in points.

Click on **OK** button to apply the changes to the selected text.

### To Set the Positioning of Text

Select the text to be formatted. Then click on Format → Character. The Character dialog box will appear.

Click the Position tab in the Character dialog box.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_41_0.png)

In the Position area, set the superscript or subscript option for the selected text.

Superscript is used to reduce the font-size of the selected text and raise it above the base line.

Normal setting removes the superscript or subscript setting.

Subscript is used to reduce the font-size of the selected text and lower it below the base line.

### To apply Colored Background to the Text

Select the text to be formatted. Then click on Format → Character. The Character dialog box will appear.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_42_1.png)

### Text Alignment

### Text Alignment using Menu

Choose Format → Paragraph from the menu bar.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_44_0.png)

The Paragraph dialog box will open.

Select the Alignment tab of the Paragraph dialog box.

![](img/9a5b9efff92da1263a1b04aa9d4ae262_44_1.png)

There are four types of alignment options available. Select the desired alignment and then click on OK button.

Align Left

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_0.png)

All the lines of the paragraph start from the left margin with uneven spacing on the right.

Centered

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_1.png)

Each line is centered on the page.

Align Right

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_2.png)

All the lines of the paragraph end at the right margin with uneven spacing on the left.

Justified

![](img/9a5b9efff92da1263a1b04aa9d4ae262_45_3.png)

All the lines of the paragraph start at the left margin and end at the right margin evenly.
