# Create Bulleted and Numbered Lists

![](bbox=[0.63, 0.1, 0.7, 0.14])

![](bbox=[0.72, 0.1, 0.8, 0.14])

We can make two kinds of lists in Word Processor: Bulleted List and Numbered List.

Bullets are symbols used to highlight items in a list. It is used in lists which do not have any particular order.

A numbered list is used to display information in a particular order.

You can use the default Bullets and Numbering settings by clicking on the appropriate button on the Toolbar.

Click on Format→ Bullets and Numbering
