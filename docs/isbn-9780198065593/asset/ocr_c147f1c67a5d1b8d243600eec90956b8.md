# Applying Drop Caps

Select the **Drop Caps** tab of the Paragraph dialog box.

![](bbox=[0.08, 0.19, 0.87, 0.58])

Select the **Display drop caps** check box.

This feature is generally used in newspaper and magazine articles to display the first character in a larger font size and common character for more than one (1) line. An example of drop cap is shown in the following picture:

![](bbox=[0.02, 0.73, 0.93, 0.89])
