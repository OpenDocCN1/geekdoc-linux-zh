# OpenOffice.org Word Processor

# To Further Format Text

The first step is to select text to be formatted. Then click on Format-> Character

The Character dialog box will appear. Click the Font Effects tab in the Character dialog box.

![](bbox=[0.1, 0.28, 0.9, 0.68])

In the Underlining field, select the style.
