# OpenOffice.org Word Processor

The Picture dialog box opens. Select the **Borders** tab.

![](bbox=[0.15, 0.13, 0.84, 0.47])

In the **Line arrangement** area, select one of the five buttons to

+   1. set no border,
+   2. set all four borders,
+   3. set left and right borders only,
+   4. set top and bottom borders only, or
+   5. set left border only.

![](bbox=[0.74, 0.49, 0.96, 0.66])

In the **Line** area, select an entry that determines the thickness and color of the line.

![](bbox=[0.74, 0.69, 0.96, 0.86])

Click on **OK** button.

![](bbox=[0.05, 0.79, 0.45, 0.91])
