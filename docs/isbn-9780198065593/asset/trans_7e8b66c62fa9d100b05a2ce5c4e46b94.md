
## OpenOffice.org 文字处理器

### 使用同义词词典

同义词词典通过提供同义词列表（意思相近的词语）和相关的词语，帮助你改进词汇量。点击 工具 → 语言 → 同义词词典，或按 [Ctrl+F7]。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_60_0.png)

同义词词典对话框将显示出来。在“含义”列表中，选择与上下文相符的定义。在“同义词”列表中选择要替换的词语。点击“确定”。

我是一名优秀的**学生**。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_60_1.png)

- 从英语课本中选择难懂的单词。把它们输入到文字处理器中，查找它们的含义。同时查找这些单词的反义词和同义词。

### 处理图形

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_0.png)

#### 将图形作为副本插入

1. 点击标准工具栏上的**图库**图标，或通过选择 工具 → 图库 来打开**图库**。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_1.png)

2. 选择一个**主题**。

3. 单击选择要使用的**对象**。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_62_2.png)

4. 将对象拖入文档中，或者右键打开上下文菜单并选择 插入 → 复制。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_63_0.png)

#### 将图形作为背景插入

1. 点击标准工具栏上的**图库**图标，或通过选择**工具 → 图库**来打开图库。
2. 选择一个主题。
3. 单击选择要使用的对象。
4. 打开上下文菜单并选择**插入 → 背景 → 页面或段落**。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_63_1.png)

#### 在图形周围添加边框

选择图形，然后点击 格式 \ 图形...

或者，你可以右键点击图形并选择 图形...

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_0.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_1.png)

![](img/9a5b9efff92da1263a1b04aa9d4ae262_64_2.png)

图形对话框将打开。选择**边框**标签。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_0.png)

在**线条排列**区域，选择五个按钮中的一个：

- 设置无边框，
- 设置所有四条边框，
- 仅设置左右边框，
- 仅设置上下边框，或
- 仅设置左侧边框。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_1.png)

在**线条**区域，选择一个条目，以确定线条的粗细和颜色。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_2.png)

点击**确定**按钮。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_65_3.png)

#### 绘图工具栏

点击 查看 → 工具栏 → 绘图。绘图工具栏将显示出来。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_66_0.png)

你可以点击各种形状并绘制精美的图形。你甚至可以使用艺术字图库来美化显示效果。

![](img/9a5b9efff92da1263a1b04aa9d4ae262_66_1.png)

#### 思考角

点击 查看 → 工具栏。你将看到 OpenOffice.org 文字处理器中可用的工具栏列表。这些工具栏的用途是什么？

### OpenOffice.org 文字处理器的功能键

| 快捷键 | 效果 |
|---|---|
| [F3] | 完成自动套用文字 |
| [Ctrl+F3] | 编辑自动套用文字 |
| [F7] | 拼写检查 |
| [Ctrl+F7] | 同义词词典 |
| [F12] | 编号 |
| [Shift+F12] | 项目符号 |
| [Ctrl+Shift+F12] | 关闭编号 / 项目符号 |

### OpenOffice.org 文字处理器的快捷键

| 快捷键 | 效果 |
|---|---|
| [Ctrl+A] | 全选 |
| [Ctrl+J] | 两端对齐 |
| [Ctrl+D] | 双下划线 |
| [Ctrl+E] | 居中对齐 |
| [Ctrl+F] | 查找和替换 |
| [Ctrl+Shift+P] | 上标 |
| [Ctrl+L] | 左对齐 |
| [Ctrl+R] | 右对齐 |
| [Ctrl+Shift+B] | 下标 |
| [Ctrl+Y] | 重做上一个操作 |
| [Ctrl+Enter] | 手动分页符 |
| [Ctrl+Shift+Enter] | 在分栏文本中插入分节符 |
