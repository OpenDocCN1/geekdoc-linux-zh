# Maelstrom from the Mac

Mac OS arcade fans are sure to remember Maelstrom, by Andrew Welch. This shareware arcade game was originally ported to X and retains its excellent animation, fast play, and great sounds. Start game play from the command line of a terminal window, like this:

```
$ Maelstrom &
```

You will see an initial splash window, then a control window. Press the p key to start the game. If you need help, press the a key, then press Enter to see the cast of animated goodies in the game, as shown in Figure 18.9.

# Building and Playing 1xdoom

The DOOM arcade game ushered in a new era of game play on personal computers. Although it was not the first 3D game, it definitely popularized the first-person shooter and alienated a generation of parents with its sounds and gory action.

You can now run and play the game in all its original glory while using Linux and X. For full play, you will need a commercial DOOM WAD (data) file, though you can use the original three-level shareware WAD file. Building and installing 1xdoom is a snap when using PPC Linux, and only takes a minute or so, providing you have the proper development tools and libraries installed on your system.
