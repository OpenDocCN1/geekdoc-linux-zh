This chapter introduces a few utilities you can use with Linux that can help you bridge the gap between different operating systems. You will see how to run other desktops remotely during an X session, and how you can set up users of other operating system to use Linux remotely.

You will also get a basic introduction to the Mac-on-Linux emulator that allows you to run Mac OS in a window on your X desktop. Finally, you will get a quick introduction to other operating systems for your Power Mac, such as the BSD (*Berkeley Software Distribution*) UNIX.

# ## Using Xvnc

AT&T Laboratories in Cambridge, England distributes a free software package named `xvnc`. This virtual networking software enables you to run remote computers using operating systems different from your desktop. This means that if you have computers using Windows or Mac OS on your LAN, you can run each computer in a window on your Linux desktop. This also means that you can sit down at a computer running Windows or Mac OS and run your Linux computer in a window from a remote desktop.

`xvnc` is a specialized variant of the X server installed on your system. Versions of `xvnc` are available for a number of computers, such as:

+   DEC Alpha OSF1 3.2
+   Java
+   Macintosh OS (68K and PPC)
+   Palm OS
+   PocketPC
+   Solaris 2.5 (SPARC)
+   Win32 (such as Windows 9x/2000/NT)

The `xvnc` package provides a shell script named `vncserver`, the `xvnc` modified X server, and a remote desktop viewer client named `vncviewer`. There are versions of `xvnc` for all Linux PPC distributions.

After installing the software (most likely using the `rpm` command or `yast`), you can start `xvnc` on your system by using the `vncserver` script. This script allows you to set the default screen size and color depth by using its `-geometry` and `-depth` settings. For example, to start a session that offers an 800x600 desktop in thousands of colors, use the `vncserver` script, like this:

```
$ vncserver -geometry 800x600 -depth 16
```
