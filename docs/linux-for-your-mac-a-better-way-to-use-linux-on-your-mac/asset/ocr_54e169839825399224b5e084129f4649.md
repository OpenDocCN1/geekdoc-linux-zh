The X server will determine if your system can support the requested color depth and resolutions defined for your system. Typical values used for different color depths are 8, 15, 16, 24, or 32. If you use XFree86 version 3.3.6, the command line looks like this:

```
# startx -- -bpp 8 -dpi 100
```

You can even use the *startx* command to launch multiple X sessions, useful to test new window managers or run X sessions at different color depths. Thanks to Linux support of *virtual consoles*, or its console displays that are accessible through the keyboard, you can quickly navigate between sessions.

Start your first X session by using the *startx* command, along with a *display number*, which specifies an X server instance. You can include a color depth setting, and a number representing a virtual console like this:

```
# startx kde2 -- :0 -bpp 16 vt7
```

After the X session starts (using KDE2), press Ctrl+Alt+F2 to jump back to a text-only login prompt. Log in, and again use *startx* like this:

```
# startx afterstep -- :1 vt8
```
