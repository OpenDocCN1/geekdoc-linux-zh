# ## Arcade

PPC Linux distributions include a variety of exciting and fun-filled arcade games that you will enjoy for hours at a time. This section introduces just some of these games. Nearly all these games can use your system’s sound card. In order to fully enjoy the gaming experience, make sure you have a properly configured sound card for your system. You will also see how to build 1xdoom, an Open Source version of DOOM!, which is the first-person shooter game by ID Software.

# ### XBoing II

Justin C. Kibel’s xboing client has a long and happy history with X, and has been available for Linux for several years. This arcade breakout-style game features wacky sounds and fast-paced, furious action. Do not forget to include the -sound option to turn on sound when you start the game from the command line, like this:

```
```
$ xboing -sound &
