## Electronic Mail

Electronic mail is one of the most important functions and one of the main reasons many people connect to the Internet. If one had to choose between Web browsing and electronic mail (and its ability to send and receive attachments), the choice might be pretty hard. Even though there are a number of free e-mail sites on the Internet, which are fine for casual use, you will want to use electronic mail on your system so that you have control of your messages.

The Messenger component is Communicator's electronic mail handler. In order to use Messenger, you must have a valid electronic mail account with a username and password, along with the name of your ISP's incoming and outgoing mail server(s).

To configure Messenger for sending and receiving electronic mail, click the Edit menu, select Preferences, and then click the Mail and Newsgroups menu item. Next, click the Identity menu item. You will see a dialog box, as shown in Figure 9.13.

Enter your name and e-mail address, such as `jdoe@mydomain.com`. If you would prefer that your recipients see a `Reply-to:` address, enter the address in the `Reply to: address` field.

- Have a personal business card? You can create an electronic business card that will automatically be attached to each message by clicking the `Edit Card` button and clicking the `Attach personal card` button. These cards, known as vCards, are used by different programs on different operating systems. The cards are usually imported to address book components of e-mail programs or a PIM (Personal Information Manager) application.

Enter the name of your ISP's mail server. This is the name of the mail server from which you will retrieve mail. ## Using E-Mail Clients

If you choose to use more traditional e-mail clients with Linux, you will need to use Eric S. Raymond's `fetchmail` command to retrieve your messages. This program can be used to retrieve e-mail from a variety of mail servers, and works by using a resource file in your home directory named `.fetchmailrc` (although you can define other resource files and use them by using `fetchmail`'s `-f` option, followed by the resource file's name).

For example, a simple `.fetchmailrc` may look like this:

```
poll pop.mysp.com protocol POP3 username yourusername password yourpassword
```

The file should have permissions of at least 710 (allowing you to read, write and execute the file, but restricting read and write access to other programs), which you can assign with the `chmod` command, like this:

```
$ chmod 710 .fetchmailrc
```

You can then retrieve your e-mail (assuming you have an active Internet connection), like this:

```
$ fetchmail
```

If you create a different resource file, you can retrieve mail, like this:

```
$ fetchmail -f .erolsrc
1 message for bballetaubee at pop.erols.com (1486 octets).
reading message 1 of 1 (1486 octets). flushed
You have new mail in /var/spool/mail/bball
```

The `fetchmail` command has many different command-line options. Read its manual page for more information.

Using legacy, or text-based e-mail clients can be an advantage, especially if you have a shell account on a remote system. Coverage of these clients, such as `mail`, `pine`, or `mutt` is included for completeness, but you will have to experiment and read about these clients to learn more.
