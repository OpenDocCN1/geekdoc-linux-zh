For example, the PostgreSQL database system includes 43 different commands and programs used to create and manage one or more databases. The system features user management, access permissions, and graphical shells for queries and reporting.

Another Linux SQL database is MySQL, a database management system with RDBMS features. In this system data is stored in separate files (or tables), then linked to provide data when queried (because of the relational aspect). While MySQL is quite capable of handling large databases (i.e., 50,000,000 records) and integrates well with other computer languages and Web server operations, PostgreSQL is generally given the nod for use in enterprise-class operations on larger computers that provide even larger databases. However, for most users, MySQL should be more than adequate for the task of handling database operations.

Like other services on your Linux system, PostgreSQL and MySQL services and database daemons may be started through initialization scripts under the */etc/rc/init.d* directory. For PostgreSQL, the script is named *postgresql*, MySQL, the script is named *mysql*. The first time you run this script (on a SuSE Linux system), you will see:

```
Creating MySQL privilege database and starting MySQL.
Creating db table
Creating host table
Creating user table
Creating func table
Creating tables_priv table
Creating columns_priv table
...
```

The startup script will normally report:

```
Starting service MySQL.
Starting mysqld daemon with databases from /var/mysql
done
```

You can then log into the server by using the **mysql** command like this:

```
$ mysql

Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 1 to server version: 3.22.32

Type 'help;' for help.

mysql>
```

Documentation for each of the database systems described here may be found installed under your **/usr/doc** directory, various manual pages, or through the Internet (see "Resources" at the end of this chapter).

## Spreadsheet Applications

Some people view computers as nothing more than fancy calculators. In fact, it was not until the advent of early financial calculation software such as VisiCalc (first introduced for Apple Computer hardware) that people started taking personal computers seriously. Before this, "serious" financial calculations were always conducted on "Big Iron," or huge mainframe computers.

Today, Apple G4 users can snicker about comparisons between their computers' power compared to the size and cost of those big computers of even 10 years ago. Today's Macs routinely sport more than 1GB RAM and provide hard drive storage only dreamed of a decade ago.

The various clients and programs discussed here run the gamut from GPLd projects and open source packages, to the public domain. You are sure to find a program that can fit your needs. These programs rival and often exceed the capabilities of commercial spreadsheet programs that cost computer users hundreds of dollars only a few years ago.

### Using gnumeric

The *gnumeric* spreadsheet client requires an active X session, and is part of the GNOME software library distribution. This program, initially started as a simple table editor, has rapidly evolved into a capable spreadsheet client.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_306_0.png)

**Figure 12.13** The gnusmeric spreadsheet is a GNOME-compliant client that provides financial calculations during your X sessions.

You can start gnusmeric from the GNOME desktop panel menu, or the command line of an X11 terminal window like this:

```
# gnusmeric &
```

After you press Enter, you will see the opening gnusmeric document window as shown in Figure 12.13.

Your spreadsheet data may be saved in a variety of formats, such as gnusmeric XML, comma-separated values, LaTeX, HTML, ASCII, and even PDF (Portable Document Format). In addition, data may be imported in nearly as many formats. Unfortunately, the gnusmeric spreadsheet does not yet support the automatic creation of graphics from its tabular data, unlike the kspread client discussed next.

## Using kspread

The kspread spreadsheet client is part of KDE's KOffice office suite, and requires an active X session. This program, like gnusmeric, has rapidly evolved into a capable spreadsheet client.

You can start kspread from the KDE desktop's panel menu, or the command line of an X11 terminal window like this:

```
# kspread &
```

## Using *sc*

The *sc* command is a public-domain spreadsheet program with a long history as open source. Originally designed as a simple table editor, hundreds of programmers have worked on *sc* to add numerous features. You will find various incarnations of the *sc* program available for Linux, but in its simplest form, this editor works quite well and is more than adequate for the task of maintaining simple spreadsheets.

This spreadsheet may be used at the Linux console, and does not require an X session, making it ideal for use in dial-up situations or for users with a simple shell account. Weighing in at barely 200,000 characters in binary form, this program has one of the smallest footprints of any spreadsheet program, matched only by the *teapot* editor (discussed next).

You can start *sc* at the command line like this:

```
$ sc
```

After you press Enter, its main window will appear. You can navigate through different cells by using the cursor keys, or by pressing Ctrl+f (right), Ctrl+h (left), Ctrl+p (up), and Ctrl+n (down). Numeric values and functions are entered by prefacing the data with an equals (=) sign. For example, move the highlighted (current) cell at A0, then type:

```
=1456
```

Press Enter and then move to cell A1 and type:

```
=9378
```

Press Enter and finally move to cell A2, and use *sc*’s *sum()* function to add the contents of cells A0, A1, and then in cell A2, like this:

```
=@sum(a0:a1)
```

After you press Enter, you will see the result, as shown in Figure 12.16.

Despite its simple appearance, *sc* has many complex functions such as range, numeric, string, financial, and time and date functions. You can get help at any time by typing a question mark (?). You can also read *sc*’s manual page, or use its companion *scqref* command to print a nine-page quick-reference sheet like this:

```
$ scqref | nroff -ms | lpr
```

# Other Calculation Commands

You will find other calculation commands included with your Linux distribution. These include graphic calculators, such as *xcalc*, KDE’s *kscalc*, and the GNOME calculator, *gcalc*. Command-line calculators include the *units* program, the *dc* calculator, and the *bc* calculating language interpreter.

# Using teapot

Michael Haarndt’s Table Editor and Planner, or *teapot*, is another console, or text-based spreadsheet that you can use for simple or complex calculations. This editor features an easy-to-use menu system, but also offers a sophisticated, three-dimensional calculation space that you can use to perform complex monitoring, calculation or data hiding.

Cursor movement is similar to that in *sc*, except that Ctrl+b is used instead of Ctrl+h to move the cursor left, or backward along a row. Calculations can become somewhat complicated, as most functions may require a third cell reference.
