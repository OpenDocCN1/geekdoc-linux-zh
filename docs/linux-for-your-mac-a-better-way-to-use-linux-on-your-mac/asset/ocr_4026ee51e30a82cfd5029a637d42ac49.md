Its support files, libraries, tools, and filters will be found under the `/usr/share/gimp` and `/usr/lib/gimp` directories.

The GIMP may be launched via the desktop panel or from the command line of an X terminal window, like this:

```
$ gimp &
```

When the GIMP is run for the first time, an installation dialog box will appear. You will be asked for approval in order to start the install, which involves the creation of a resource directory in your home directory and the copying of resources into your personal GIMP directory. You will see a list of the intended contents, and will be asked to confirm the install. You will also be asked to select a file cache size and a temporary file location, as shown in Figure 13.1.

If you have access to another partition and anticipate editing large graphics documents, tell the GIMP to use a file location other than your home directory. This can avoid any “disk full” errors. Temporary files can sometimes be three times larger than the document being edited, and a full-page (letter size) color document at 600 dots-per-inch will require nearly 100MB. You can also limit graphics document sizes through settings for the Maximum Document Size in the GIMP’s Preferences menu.

Use the Continue button to finish the installation. When the GIMP launches, you will see a splash dialog box, and the GIMP’s Tip of the Day. The floating main toolbox will appear, as shown in Figure 13.2.
