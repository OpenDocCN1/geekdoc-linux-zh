
## Troubleshooting

Problems in getting connected to the Internet are generally related to proper set up and configuration of Linux. Make sure that your modem is working and recognized by Linux before attempting to connect. Try using a terminal application, such as minicom, to dial out and test your modem. Diagnosing problems with DSL connections is a bit trickier, but chances are very good that if your connection works using another operating system, then it will work with Linux too.

Not all internal modems on Apple PowerPC computers work with Linux. Some models, such as the PowerBook 3400 or the Apple Cube, may never be supported. The workaround is to try to use an external modem with a serial or USB-to-serial adapter. Realize that various hardware support will improve with each new version of the Linux kernel and as each PPC Linux distribution matures. What is not supported today may be supported tomorrow. Legacy hardware has a good chance of being supported; however, the latest and greatest on the market may not be supported right away. A pleasant surprise is the Apple TiBook, which works out of the box with LinuxPPC 2000 Q4, even though that Linux distribution was available months before Apple released the TiBook.

## Chapter 10: Using the K Desktop Environment

### Introduction to the KDE Desktop

This chapter introduces the K Desktop Environment, or simply KDE, one of the most popular desktops used with X11 and Linux. KDE has won a large following of users and developers from around the world, and is under active development. New versions are regularly released, and new KDE clients appear every day.

As you learn more about Linux and chat (online or with other users), you will discover that one commonly asked question (or troll) is: “What window manager do you use?” Minions of the Dark Side and spreaders of FUD (Fear, Uncertainty and Doubt) love to argue that the Linux user base has fragmented and split into two camps—those who use KDE and those who use GNOME.

This is of course, ridiculous. As you have learned so far, Linux is not a graphical interface. Linux users have a choice, and you can choose to use Linux with a GUI or without one. If you choose to use a GUI, you are free to customize your computer’s desktop. The technologies and advances made by GPL and open source programmers in GUI design have been so successful, that companies such as Sun Microsystems and Hewlett-Packard have adopted GUIs originally developed by and for Linux users.

After reading Chapter 7, “X11 and Window Managers,” you should know that there are many different X clients you can use to manage a graphical desktop. The K Desktop Environment, part of a project founded in October 1996, was released July 12, 1998, as version 1.0, following a long period as a beta product. Version 2.0 was released October 23, 2000, and development has continued at a rapid pace.

KDE generated quite a bit of excitement, because it provided the first free, open-source suite of X clients that offered a comprehensive desktop environment. The commercial Unix consortium attempted a similar effort, termed the CDE (Common Desktop Environment), but its commercial status did not appeal to the Linux market.

KDE is a desktop environment that includes more than 200 different clients, nearly 12,000 files, and requires nearly 150MB of hard drive space. Hundreds of additional clients, which are not part of the standard distribution, are available through various developer pages on the Web. The current base source code distribution eclipses that of the current PowerPC Linux kernel, and consists of 800,000 lines of C and C++ programming.

KDE is popular for a number of reasons, but perhaps some of the most enticing features are:

- **Network transparency for the desktop environment.** This means that listings of remote files in a browser or FTP window can be used as if representing local files. You can click on the name of a graphic image, and it will automatically be downloaded and displayed.
- Ease of use. Though Mac OS users may scoff, KDE provides nearly all the features found in modern GUI designs for the desktop, including drag- and-drop, graphical symbolic links, active icons, and customization of nearly any desktop element.
- Stability. KDE is quite stable and even clients that are “works in progress” and crash will not affect the operation of the desktop.
- Source code. KDE is built using open source libraries named Qt from Troll Tech AS. Although a possible bone of contention in the development of proprietary software, the Qt libraries and nearly all KDE clients come with source code and are free for personal use. This is in direct contrast to the GNOME libraries and clients, which are distributed free under the GNU General Public License, and unencumbered by any restrictions.
- Client development tools. KDE also provides GUI development tools, such as KDevelop, to use for quickly prototyping and building clients.
- An office application suite. KDE developers from around the world have also been working hard to produce an integrated office suite named KOffice. Consisting of six components, KOffice includes a workspace manager, charting client, word processor, spreadsheet, illustration program, and a presentation development client. All clients can communicate, share, and update information in each other’s documents.
- Themes. Themes, also known as color schemes, provides a way to customize, dress up, or alter how your session’s clients or desktops are displayed. Developers can create new themes by saving collective desktop and window-decoration changes.
- Session management. Session management, or the ability to save the state of the desktop and running clients, is a timesaving feature, especially if you need specific applications active when getting to work. KDE provides that compliant clients will be restarted the next time you begin your session. You also have the choice of saving or not saving your session.
- A wealth of applications. KDE’s base distribution, in addition to the number of supplemental programs, provides many programs you can use during your X sessions to be more productive.

You will immediately notice that KDE clients share a consistent interface, such as menus, windows, buttons, dialog boxes, and other controls. Another useful feature is that nearly every client has a Help menu you can use to get more information.
