# ## Using the Desktop

Launch new programs by clicking on an icon on your desktop's panel or by clicking the panel's start menu to access other menu items that will launch the KDE client. You will most likely want to have an open terminal window for access to the shell (which you can use to run command-line programs or launch other X clients). If you do not want to use a terminal to launch other clients, press Alt+F2 to launch a mini-command-line dialog box, as shown in Figure 10.5.
