The entries in the .xclclock file take the form:

```
hh:mm [dd] MM/DD/YY message; program
```

Time is represented as 24 hours (i.e., 23:00 is 11 PM). Days of the week use a single letter, with Sunday represented by a ‘u.’ For example, a .xclclock file could look like this:

```
# my .xclclock file

# start the day with a bright root desktop
08:00; xsroot -solid lightblue &
# at noon, sky is brightest, so set desktop
12:00; xsroot -solid blue &
# starting to get dark now, so set desktop
18:00; xsroot -solid darkblue &
# daily reminders
18:30 mwtwf * Carpool leaves\mnin 15 minutes!
# quarterly, annual reminders
08:00 9/15/* Federal Taxes Due!
08:00 1/15/* Federal Taxes Due!
08:00 4/15/* Fed Filing Due!;play /usr/share/sounds/dlirge.wav
08:00 5/1/* State Tax Filing Due!
08:00 6/1/* Federal Taxes Due!
# my appointments
14:30 03/15/2001 Rabies shot at vet.
```

In this example file, the color of the root display is changed during the day. Every weekday at 6:30 PM, a message box will appear on the desktop as a reminder. Once every quarter, a reminder appears telling you about taxes (with an accompanying death march on April 15th). Finally, appointments may be set for a specific time and day. For additional examples of scheduling and appointments, see the xclock man page.
