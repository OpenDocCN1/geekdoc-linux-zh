The `knode` client is a KDE 2.0 newsreader, used to read Usenet news. In order to use this client, you must have an active Internet connection and access to a Usenet news server. When you first launch `knode`, you will be asked to enter several bits of information in its Preferences dialog box, as shown in Figure 10.16.

Enter your personal information, including a signature file if you wish, then click the drop-down Accounts menu item. Click the News icon next, and then click the Add button and enter an account name and information about your ISP's news server. When finished, click the OK button and your new account will appear.

In order to read news, `knode` needs to know what newsgroups you would like to read. Traditionally, each user's list of newsgroups is kept in a file named `.newsrc` in the home directory. This file usually looks like:

```
comp.os.linux.advocacy:
comp.os.linux.setup:
comp.os.linux.powerpc:
```
