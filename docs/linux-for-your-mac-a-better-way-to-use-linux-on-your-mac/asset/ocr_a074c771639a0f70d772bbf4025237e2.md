# ### Using *emacs*


Although best known as an editing environment, the *emacs* editor also features a number of calendars. You can use *emacs* to quickly display a three-month calendar by using its *calendar* keyword at the command prompt (located at the bottom line of the editor window). In addition to displaying a calendar, *emacs* also provides appointment scheduling and alarms.

To begin, start *emacs* from the command line of the console or the X terminal window. If you are using X, but want to keep *emacs* inside the terminal window instead of launching its own X window, use the *-nw* (no window) option like this:

```
`$ emacs -nw`

```

To display a three-month calendar, press Cmd+x, then type *calendar* at the command prompt and press Enter. A three-month calendar with the current day marked by a block cursor will appear in the lower half of the screen, as shown in Figure 12.3.

> Intel-based Linux users should note that instead of pressing Cmd+x (which is unavailable on PC keyboards), one can simply tap Esc then x, or press Alt+x, and then type *calendar* to display the *emacs* calendar. Your PowerPC Linux distribution may set up your keyboard differently, and you may have to experiment to find the right editing keys when using *emacs*.

To scroll the calendar forward or backward, press Ctrl+x, then tap the greater or less than (*>x*) keys (you will have to hold a Shift key down, or the interperated keys will be a comma or a period). You can also scroll back and forth one day at a time by using Ctrl+p or Ctrl+n.
