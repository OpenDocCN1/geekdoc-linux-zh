## pico or nano?

If you are a Debian PPC Linux user, do not despair if you are looking for an easy-to-use text editor. You can use the **nano** editor, which is a **pico** clone with additional features, such as a free license (GNU GPL), a goto-line command, case-sensitive searches, interactive search and replace, editable Tab columns, and commands to toggle features interactively. This program may be down-loaded in source or binary form from http://www.nano-editor.org, and works with all Linux PPC distributions.

## Using jed

If you would prefer a colorful and fun-to-use editor with drop-down menus, the ability to send mail, start a new shell, and spell-check, then you may enjoy using `jed`, by John E. Davis. Like `vim`, this editor includes a version for the console (`jed`) and another that works with X and your pointer.

The `jed` editor by default uses keyboard commands similar to those used by the `emacs` editor. But you can create custom keystrokes and commands by editing its user's resource file (named `.jedrc` in your home directory). Copy the file `/usr/share/jed/lib/jed.rc` to your home directory as `.jedrc`, then edit to incorporate your changes.

If you are familiar with computers and know who Mr. Peabody and Sherman are, you most likely remember the WordStar word processing program and the diamond, a use of the Ctrl key and the `e`, `r`, `a`, `s`, `d`, `f`, `x`, and `c` keys for cursor navigation. This system was eliminated by the introduction of the PC keyboard (the Caps Lock key is where the Ctrl key should be). You can now operate the diamond by using a Happy Hacking keyboard (which has the keys in the right place), and by starting `jed` in WordStar mode. Do this by inserting the following command in your `.jedrc` home directory:

```
"wordstar.sl"       evalfile    pop
```

You can start `jed` from the command line of the console or an X terminal window like this:

```
$ jed myfile.txt
```

After you press Enter, the file `myfile.txt` will be opened for editing or created if it does not exist. To start the X version, `xjed`, type at the command line of an X11 terminal window like this:

```
$ xjed &
```

After you press Enter, you will see the `xjed` editor, as shown in Figure 6.3.

When you launch `jed` in X mode, you can use your mouse to click on and activate its menu items.

## The Basics of emacs

One of the most popular and powerful software packages installed on nearly every Linux system and available with every Linux distribution is Free Software Foundation founder Richard M. Stallman's `emacs` text editor. Although a resource hog that can weigh in with a 30MB appetite for hard drive space, `emacs` has endeared hordes of Linux users and users of many other operating systems.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_141_0.png)

**Figure 6.3** The *emacs* editor features drop-down menus and recognizes pointer movement and left-button (button 1) mouse-clicks.

This popularity, of course, has spawned a legion of imitators and *emacs* clones. The original *emacs* editor from the GNU’s Not UNIX, project is known as **GNU** *emacs*. Another popular version is *xemacs*, a splinter version with some differences that is also included with nearly every Linux distribution. Like *vi*, you will find a version of *emacs* for nearly every operating system.

What makes this editor so popular? Well, *emacs* is not just a text editor, it is an editing *environment*. You can use *emacs* as a text editor, a programming editor, a programming environment (used to write, compile, and test programs), a productivity application (with a diary, calendar, and appointments), an Internet tool (used to compose, send and receive mail, and read Usenet news), and even Web-browse. On top of all this, *emacs* can also be used to play games!

Much of this power comes from the internal Lisp programming language interpreter built into the editor. You will find that many different contributors have written small loadable programs that add features to *emacs*. The most popular add-ons then become part of the standard distribution from the GNU Project.

Some users have criticized the *emacs* editor for doing too much and for using cryptic and convoluted keystrokes to accomplish simple editing tasks. While it is true that *emacs* responds to an incredible number of commands, you can use *emacs*, like *vim*, by learning just a few initial key combinations to accomplish basic editing tasks. For example, to create or edit the file *myfile.txt*, start *emacs* on the command line like this:

```
$ emacs myfile.txt
```

After you press Enter, the file will be opened for editing, or created if it does not exist. You can then get by with just the following keyboard commands:

- Ctrl+b: Move cursor left one character.
- Ctrl+n: Move cursor down one line.
- Ctrl+f: Move cursor right one character.
- Ctrl+p: Move cursor up one character.
- Ctrl+d: Delete character at cursor.
- Ctrl+k: Delete current line.
- Ctrl+x, u: Undo (or Ctrl+z)
- Ctrl+x, Ctrl+s: Save the file.
- Ctrl+x, Ctrl+w: Save as.
- Ctrl+x, Ctrl+c: Quit editing session (you will be prompted to save or discard changes if the file has changed since your last save.)

Other helpful commands include Ctrl+h to get help and Ctrl+h, t to enter the *emacs* tutorial mode. Note that if you start *emacs* from the command line of an X terminal window during an active X session, the graphical X version of *emacs* will be launched, as shown in Figure 6.4.

This version may be a bit easier to use than the text-only, or console, version. To force *emacs* to run inside an X terminal window, use its *-nw* (no window) command-line option like this:

```
$ emacs -nw
```

After you press Enter, you will see *emacs* inside a window, as shown in Figure 6.5.

The *xemacs* client is just as capable as GNU *emacs*. You can tell the difference between the editors because *xemacs*, when launched, has a fancier splash screen with the XEmacs logo. To start *xemacs*, type:

```
$ xemacs &
```

The editor will start as shown in Figure 6.6.

This editor also obeys the *-nw* option, and may be used inside an X terminal window. Both *emacs* and *xemacs* recognize and use X Toolkit command-line options, such as *-geometry*, *-fg*, and *-bg* for window size, placement, text color and background color. Read the *emacs* and *xemacs* manual and *info* pages for more options.

```
(setq default-major-mode 'text-mode)

(setq text-mode-hook 'turn-on-auto-fill)

```

> SuSE PPC Linux provides a default `.emacs` file, but defines a separate *GNU emacs* customization file that you should use instead. The name of the file is: `.gnu-emacs-custom`, and you should create and edit this file for your personal entries. If you use *xemacs*, the name of this file should be: `.xemacs-custom`. If you do not want to use this separate file for *GNU emacs*, delete the following two lines:

```
(setq custom-file "~/.gnu-emacs-custom")
(load "~/.gnu-emacs-custom" t t)
```

To delete the entry for xemacs, delete these following lines:

```
(cond
   ((string-match "XEmacs" emacs-version)
    (setq custom-file "~/.xemacs-custom")
    (load "~/.xemacs-custom" t t)))
```

You can then use the `.emacs` file for your tweaks!
