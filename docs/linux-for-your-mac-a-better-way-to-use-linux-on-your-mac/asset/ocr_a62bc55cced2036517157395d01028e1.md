# Figure 12.3 The emacs editor can display a three-month calendar during your editing sessions at the console or while using X.

To jump to a different month, tap the o key, press Enter, then enter a month’s name. The calendar will then move to the specific month. If you tap the period (.), the calendar will shift to the current day. To quit the calendar, type a q.

In order to use the appointment feature, you must first create a file named diary in your home directory. The emacs editor will use this file as a place to search for appointments. You can create your diary by using the touch command before using emacs, or create a file, then save the file with name diary. To jump to emacs’ diary mode, press Cmd+x, then type diary and press Enter.

To add an appointment, press Cmd+x, then type appt+add and press Enter. You will be prompted for the time like this:

Time (hh:mm [am/pm]):

After you enter a time and press Enter, you will then be asked for a message:

Message:

Type a message and press Enter. While emacs is running, you will be reminded by a system beep, and a new “mode” line in the emacs window. You can also enter appointment times in your diary in the form:

hh:mm [am/pm] message

Remember that emacs must be running in order for your appointment schedule to work!
