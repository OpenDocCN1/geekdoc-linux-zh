# # Usenet Etiquette

The following is a short list of things to keep in mind when reading Usenet news. If you choose to participate in discussions, you will need to keep an open mind and should be on your best behavior. Although no one can be forced to follow any sort of rules on Usenet, there are some generally accepted mores that most users adhere to, which include:

+   - Do expect to get help with a Linux problem when asking for help on Usenet.
+   - Do ask your question in the right Linux news group.
+   - Don't expect to get an answer to your Linux question right away.
+   - Don't *cross-post*, or post the same message in a number of Linux newsgroups.
+   - Do edit out potential cross-posting message headers when replying to a Linux question.
+   - Do realize that Usenet is global—not everyone is from your country.
+   - Do realize that humor is global and that jokes may not be.
+   - Don't ever SPAM a Linux newsgroup—you will be sorry.
+   - Do be civil, even when someone asks what seems like a dumb Linux question.
+   - Do be objective in your views about free software.
+   - Don't denigrate free software—it is a gift from someone.
+   - Do ask specific questions and provide as much information or details as possible when posting a Linux question (i.e., version numbers, type of distribution, or hardware).
+   - Don't chime in on “me-too” messages.
+   - Do post helpful information.
+   - Do be friendly.
+   - Don't post in anger or frustration—wait a few minutes to cool down.
+   - Do post a summary if you get several responses to a Linux question.
+   - Don't be surprised if someone is nasty—there are a lot of troubled people out there.
+   - Don't be surprised when a fellow Linux user is very helpful.
