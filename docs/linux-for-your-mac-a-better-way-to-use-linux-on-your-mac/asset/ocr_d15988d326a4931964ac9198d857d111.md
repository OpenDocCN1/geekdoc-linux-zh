This is an excellent way to run Linux without partitioning your Mac hard drive, because the emulator uses a virtual filesystem, or a large file on your hard drive, to support the foreign operating system.

Even with the advent of Mac OS X, which uses BSD UNIX along with a new Mach kernel at the core, and supports a selective port of XFree86, you will still find that Linux for the PowerPC is a viable alternative computing environment and platform. It has an overwhelming number of applications you can use immediately.
