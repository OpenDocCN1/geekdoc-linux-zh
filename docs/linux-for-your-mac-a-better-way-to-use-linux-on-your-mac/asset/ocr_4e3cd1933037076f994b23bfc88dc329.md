> By the way, if you have an Apple G4 Cube or Titanium G4 PowerBook, you have probably discovered that no current Linux PowerPC distribution can recognize or use the media ejection key used with these slot-loading computers. Do not worry! You do not have to resort to using an emergency CD-ROM eject pin. Instead, use the `eject` command! This command will also attempt to unmount the media before performing an eject.

To unmount a filesystem, use the `umount` command, followed by the mount point, like this:

```
# umount /mnt/cdrom
```

If you attempt to unmount a device, you may receive an error message:

```
# umount /cdrom
umount: /cdrom: device is busy
```

This indicates that a user is operating the device, or has a current working directory in the path of the device (perhaps you are still inadvertently there; use the `pwd` command to check your current path). Your Linux system will use `umount` to unmount all active filesystems as part of the reboot or shutdown process. This is essential, as data in Linux memory is flushed and saved to your system’s hard drive(s). With today’s modern hard drives, this process may not happen immediately, as the disk cache needs to be written to disk.

To mount an HFS volume, use the `mount` command, the `hfs` option, device name, and mount point like this:

```
# mount -t hfs /dev/hda10 /mnt/mac
```

This will allow you to copy files back and forth between your Linux filesystem and Mac OS.

# # Using the find Command

The `find` command is an indispensable tool for system administrators. It is used to quickly locate files across one or more filesystems according to a variety of search expressions, such as name, date, time, owner, and size. This command is used to quickly build practical logs of information about your system that can be used for back up operations or security.
