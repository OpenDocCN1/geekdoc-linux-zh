You can also use ispell to interactively check or look up individual words by using its -a command-line option.

Multiple documents can also be checked by specifying an expression on the command line like this:

```
$ ispell my*.txt
```

In this example, all files beginning with my and a .txt extension will be checked. You can learn more about ispell, including how to build your own dictionaries, by reading its manual page and documentation.

# Dictionary Lookups

As you have seen, Linux comes with utilities you can use to quickly verify the spelling of a word, based on the system dictionary. However, you will also find other utilities that can help you not only check the spelling of a word, but also its definition, synonyms, antonyms, and usage. Although this function is available from various Web sites on the Internet, using them requires an active browser, such as Netscape Navigator, which may not be convenient. The following section introduces two graphical clients included with KDE and GNOME that you can use to directly query online Internet dictionary databases.

# Online Dictionary Lookups

The kdict client is an easy to use dictionary lookup utility that is KDE-compliant and can be used to find word definitions. Launch this client from the KDE desktop panel or the command line of an X terminal window like this:

```
$ kdict &
```
