# # Using tkaysv

The `tkaysv` client is a runlevel editor that presents the myriad of inter-depen-
dencies of various runlevels matched against installed system services. Launch this
client by clicking its icon or from the command line of a terminal window like this:

```
```text
# tkaysv &
```
```

After you press Enter, you will see its window, as shown in Figure 14.2.

This editor can be used to rearrange, create, or delete services for various runlevels.
Use its interface to assign actions for different services listed in its Available field.
Note that the editor will not work on runlevels 0, 1, or 6. This is because these are
the halt, single-user (maintenance), and reboot runlevels. This tool can be handy,
for example, when having certain services start before or after each other (such as
starting PCMCIA services and then starting networking after the interface has
been configured).

# # Using the timetool

The `timetool` client is used to set the system date and time. Launch this tool by
clicking its icon in the panel window, or by typing its name at the command line of
an X11 terminal window like this:

```
```text
# timetool &
```
```

After you press Enter, you will see its window, as shown in Figure 14.3.
