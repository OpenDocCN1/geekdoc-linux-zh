If you have entered multiple at commands, you can view the list of entries by using the atq command like this:

```
$ atq
3     2001-03-10 13:50 a bball
4     2001-03-10 14:50 a bball
5     2001-03-11 00:00 a bball
```

To manage your queue of at jobs, use the atrm command, along with a job number to delete like this:

```
$ atrm 3
```

This example will remove job number 3 from the list of pending at jobs.

# Scheduling with the rclock Client

The rclock client, originally by Rob Nation, which is usually included as part of the xvrt X11 terminal client software package, is more than just another X11 clock client. In its own right, rclock is a highly configurable clock that may be customized to fit nearly any X11 desktop. This clock recognizes many of the X11 Toolkit command-line options. You can use the -display option to send the clock to a remote computer, the -geometry option to create a clock with a specific size, and the -bg, -fg, and -fn options to specify a background, foreground, and font for the clock face. If you use the -update option with a value of 1, then a second hand appears on the clock’s face.

For example, to create a 100x100-pixel clock with blue hour, minute, and second hands on a yellow clock face at the upper-right corner of your display, use a rclock command line like this:

```
$ rclock -geometry 100x100+0-0 -fg blue -bg yellow -update 1 &
```

After you press Enter, you will see a clock, as shown in Figure 12.1.

More importantly, rclock may also be used in lieu of the biff or xbiff command. If you use the -mail option, rclock will check for any incoming mail at a preset interval, then flash its face when mail arrives.

The most important feature may be rclock’s scheduling and appointments alarm. Every 10 minutes, rclock will check a file named .rclockrc in your home directory. This file can contain regular, recurring notifications, or one-time only appointments. As an added bonus, rclock can also launch other applications at a specified time as part of the alarm or notification process!
