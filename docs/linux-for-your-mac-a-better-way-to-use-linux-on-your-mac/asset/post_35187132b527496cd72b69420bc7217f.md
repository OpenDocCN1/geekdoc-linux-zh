
## Appendix: PPC Linux Resources

This appendix provides additional information about X, and related links to more information about Linux, various distributions, and other hardware. When looking for information regarding Linux on your PPC computer, start your search at your distribution's Web site. If you fail to find information from your vendor, follow up by looking for Web sites describing Linux on your hardware. Finally, you can also turn to various Usenet newsgroups to ask for information.

### PPC Linux Web Sites

Here is a short list of essential Web sites with information about PowerPC Linux. There are many hundreds of Web sites devoted to Linux, but these pages provide a good starting place for more information if you run into trouble.

- **http://www.yellowdoglinux.com**. The home page for the Red Hat-based Yellow Dog Linux from Terra Soft
- **http://www.linuxppc.org**. A must-visit site for the latest developments and software for PPC Linux
- **http://www.suse.com**. Home page for SuSE, Inc., where you will find links to its latest distribution of Linux for the PowerMac models and other PowerPC-enabled computers
- **http://www.debian.org**. Visit this site to learn more about the philosophy of Debian Linux. You should also explore to find a version of Linux for your PowerPC computer
- **http://www.linuxppc.com**. Site of the now non-profit Linux PPC 2000 Q4 distribution
- **http://www.linux-laptop.net/apple.html**. If you have a PowerBook and are interested in using Linux, check this site for links to current and legacy Apple notebook computers. You will find owners who are willing to share their experiences
- **http://penguinppc.org/~benh/**. Ben Herrenschmidt's page for the latest BootX and Yaboot utilities
- **http://www.wrietman.com/**. All about using Linux on an iBook
- **http://www.rapierbit.org/linux/**. Information about using Linux on the PowerPC
- **http://www.fsmlabs.com/linuxppcbk.html**. You can find some of the latest PPC Linux kernel source here
- **http://penguinpc.org/usr/hardware/edge.shtml**. A great place for more information about PPC Linux, with links to the latest software and information
- **http://students.washington.edu/mpaleczew/**. A place to check for iBook Linux kernels that support sound
- **http://www.rahul.net/kenton/xsites.framed.html**. The best site on the Internet for learning more about X
