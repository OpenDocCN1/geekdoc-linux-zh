On the other hand, to view your computer's hardware clock and its time, use the `clock` command with its `-r` option, like this:

```
# /sbin/clock -r

time in rtc is Fri May 11 23:07:07 2001

Fri May 11 23:07:07 2001
```

> On Intel-based Linux systems, `hwclock` is traditionally used to show and set the system's hardware clock. This command is only supported when using Linux on CHRP or PREP workstations, not Apple Power Macs. Use the `clock` command instead.

The `clock` command has a terse syntax that looks like this:

```
# /sbin/clock --help

/sbin/clock: unrecognized option '-help'

`clock` [-u] -r|w|s|a|v

r: read and print CMOS clock

w: write CMOS clock from system time

s: set system time from CMOS clock

a: get system time and adjust CMOS clock

u: CMOS clock is in universal time

v: print version (1.4) and exit
```

This command, found under the `/sbin` directory, should not be confused with the OpenWindows `clock` client, which displays the current time in a graphical clock during an X session. The `/sbin/clock` command should only be run by the root operator (root should explicitly call `clock` using its full path). This command can be used to display and sync your computer's hardware clock with the Linux system clock by using its `s` option. To adjust the system time to the hardware clock, use the `s` option.

If you use a Red Hat-based distribution such as Yellow Dog Linux or LinuxPPC 2000, you can also use Red Hat's `timetool` client to set your system time. This X11 client may be started from the command line of an X11 terminal window, like this:

```
# timetool &
```
