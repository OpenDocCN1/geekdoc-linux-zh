# Configuring Apache

Apache is the *de facto* standard Web server for Linux, although there are some commercial alternative software packages, such as *Zeus*. As you’ve already learned, the system script that starts, stops, and restarts Apache under SuSE Linux is named `/etc/rc.d/init.d/apache`, while under LinuxPPC 2000 (and other Red Hat-based systems) will be named `/etc/rc.d/init.d/htpd`.

With SuSE Linux, Apache is configured by editing the file named `/etc/httpd/httpd.conf`. With Red Hat-based systems, the `httpd.conf` file may be found under the `/etc/httpd/conf` directory. One of the most important settings is `DocumentRoot`, which specifies where your system’s initial Web page is located. For example:

```
#
# DocumentRoot: The directory out of which you will serve your
# documents. By default, all requests are taken from this directory, but
# symbolic links, and aliases may be used to point to other locations.
#
DocumentRoot  "/home/httpd/html"
```
