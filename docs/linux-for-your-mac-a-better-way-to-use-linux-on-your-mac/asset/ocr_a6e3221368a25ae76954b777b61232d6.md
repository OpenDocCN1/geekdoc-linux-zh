# ### Using the Kcontrol Client

Normal users or the root operator may use the control center. If kcontrol detects an action not permitted to a system user, a temporary root operator log in dialog box will appear, as shown in Figure 10.8.

This will happen if you try editing the desktop panels' main menus, try to change log in permissions or display of KDE's kdm display manager, or perform any action that will affect KDE on a system-wide basis.
