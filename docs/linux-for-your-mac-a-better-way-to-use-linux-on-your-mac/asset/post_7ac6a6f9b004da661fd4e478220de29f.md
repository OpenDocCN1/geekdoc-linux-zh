In the file `/etc/inetd.conf`, by default, LinuxPPC 2000 Q4 does not use wuftpd, but instead uses proftpd, as shown in the following line:

```
#  ftp  stream tcp nowait  root  /usr/sbin/tcpd in.proftpd
```

To change your FTP server, change the line to read:

```
ftp  stream tcp nowait root /usr/sbin/tcpd  in.wuftpd
```

You will then need to restart the Internet superserver, `inetd`, like this:

```
# /etc/rc.d/init.d/inet restart
```

With SuSE Linux, this command line should be:

```
# /etc/rc.d/init.d/inetd restart
```

Alternatively, you can (as root) send a *Hangup*, or HUP signal to the superserver using its process ID. For example:

```
# ps aux | fgrep inet
root      407  0.0  0.3  1320  580 ?      S    13:38  0:00 /usr/sbin/inetd
# kill -HUP 407
```

In this example, the superserver (process ID 407) is restarted using the shell's `kill` command. You can learn more about your system's services and FTP servers by reading the various FTP manual pages, or documentation under the /usr/doc directory.

### Internet Clients

The `konqueror` client, introduced with KDE 2.0, has become the ubiquitous KDE application. This client is used for file management, online and context-sensitive help, or Web browsing, and may even be used to help in HTML (*HyperText Markup Language*) page editing! You will use `konqueror` quite often during your KDE sessions, and may find that it has replaced Netscape on your desktop's panel (it is the default when using KDE with LinuxPC 2000 Q4).

Launch `konqueror` from either the desktop panel, the start menu, the start menu's Internet menu item, or the command line like this:

```
$ konqueror &
```

After you press Enter, you will see the `konqueror` window, as shown in Figure 10.4. By default, `konqueror` will display any files in the current directory, using various icons associated with a file's extension. Therefore, files such as text documents (with names ending in .txt) will have a different icon than a graphic (which could have a name ending in .ps, .jpg, .png, etc.). The `konqueror` client will also recognize the contents and permissions of files. For example, create a file named `myterm` that contains:

```
#!/bin/sh
/usr/X11R6/bin/xterm &
```

Then save the file and make it executable using the `chmod` command like this:

```
$ chmod +x myterm
```

If you hover your pointer over this file when displayed in the konqueror window, it will properly report the file as a shell script and assign a designated icon. Unrecognized files will be assigned an icon with a question mark.

You can also use konqueror from the command line to launch and display a specific Web page. For example, type konqueror, followed by a specific URL like this:

```
$ konqueror http://www.prima-ech.com
```

After you press Enter, the Web page will be displayed in konqueror’s window. You can quickly see other command-line features by using the --help command-line option, or by using konqueror’s Help menu.

The `knode` client is a KDE 2.0 newsreader, used to read Usenet news. In order to use this client, you must have an active Internet connection and access to a Usenet news server. When you first launch `knode`, you will be asked to enter several bits of information in its Preferences dialog box, as shown in Figure 10.16.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_264_0.png)

Enter your personal information, including a signature file if you wish, then click the drop-down Accounts menu item. Click the News icon next, and then click the Add button and enter an account name and information about your ISP's news server. When finished, click the OK button and your new account will appear.

In order to read news, `knode` needs to know what newsgroups you would like to read. Traditionally, each user's list of newsgroups is kept in a file named `.newsrc` in the home directory. This file usually looks like:

```
comp.os.linux.advocacy:
comp.os.linux.setup:
comp.os.linux.powerpc:
comp.sys.mac.portable:
comp.sys.linux.portable:
...
```

Note that the above is just a representative list of Linux newsgroups (see this book's Appendix for a more complete list). To build your list of newsgroups for knode, click your new account in the main window, then click the Subscribe button. The knode client will ask if you want to download a list of newsgroups and descriptions from your ISP's server. If you click OK, knode will obtain the list (which could be nearly 2MB in size). When finished, you will see a list in a subscription dialog box as shown in Figure 10.17.
