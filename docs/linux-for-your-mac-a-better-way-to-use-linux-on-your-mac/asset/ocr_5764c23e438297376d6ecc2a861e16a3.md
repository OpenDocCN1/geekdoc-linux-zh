# # GNOME

The GNOME (*GNU Network Object Model Environment*) is not a window man- ager, but a set of software libraries derived from a programming project, which is used to create the GIMP (*GNU Image Manipulation Program*). GNOME includes a suite of clients that have sophisticated windowing, event, and drawing capabili- ties. GNOME provides the framework for GNOME-aware window managers to support these features. These features include session-management, drag-and-drop, animation, and a consistent client interface during the X session.

GNOME includes a control center client that hosts a window manager-specific configuration client. For example, note a typical GNOME desktop, and the *saw- fish* window manager's *sawfish-ui* client running in the GNOME control center, which is shown in Figure 7.3.
