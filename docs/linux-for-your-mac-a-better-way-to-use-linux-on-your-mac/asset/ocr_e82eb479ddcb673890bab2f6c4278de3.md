You can then use the `dmesg` command to determine the proper serial device to use for your modem or serial operations, like this:

```
# dmesg
...
usbsuerial.c: Looking at Keyspan PDA Vendor Id=06dc Product Id=0104
usbsuerial.c: descriptor matches
usbsuerial.c: found interrupt in
usbsuerial.c: found bulk out

usbsuerial.c: Keyspan PDA converter detected
usbsuerial.c: get_free_serial -
usbsuerial.c: get_free_serial - minor base = 0
usbsuerial.c: Keyspan PDA converter now attached to ttyUSB0 (or usb/tts/0 for devfs)
```

Note that not all the output is shown here. In this example, the new serial port is designated as `/dev/ttyUSB0`. You can then use this port for modem operations.

> At the time of this writing, the speed of the serial port using this adapter (which works fine under Intel-based Linux) is limited to 9600 baud. Hopefully the USB drivers will be fine-tuned over the next several PPC kernel releases.

You can also try using a USB modem with Linux. At the time of this writing, the following units were reportedly working and fully supported:

+   - 3Com OfficeConnect Analog Modem.
+   - 3Com 56k Voice Faxmodem Pro.
+   - Diamond Supraexpress 56k USB Modem.
+   - Zoom Telephonics, Inc. 2985L Zoom V90 USB Faxmodem.

However, some of these modems may require the `acm` kernel module. Support for various USB kernel modules may be different between Intel-based kernel distributions and your PPC Linux kernel. When in doubt, always ask someone who is using similar equipment and software. You should also research hardware before you buy!
