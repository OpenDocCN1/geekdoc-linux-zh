# ### Configuring DSL with rp-pppoe

The latest rage in broadband access is the Digital Subscriber Line (DSL). This Internet service, unlike slightly faster cable modems (to which Linux can easily connect and use), uses a server form of PPP instead of Ethernet, and is known as PPPoE. Low-end package deals from big providers such as Verizon generally provide 640Kbps download and 90Kbps upload speeds. Despite the growth pains, poor management, and initial incompetence by big telephone companies shouldering smaller ISPs out of the ISP business, consumers have been flocking to DSL service in droves.

A typical connection involves the use of a DSL modem connected to the home phone line. An Ethernet cable is then run from the modem to the Linux computer. The premiere DSL connection software for Linux is from Roaring Penguin, a small computer consultant shop in Ottawa, Ontario. Without the wonderful efforts and generosity of rp-pppoe's author, David F. Skoll, life would be more difficult for Linux DSL users.

The primary components in the `rp_pppoe` package are the following commands:

| Command | Description |
| :--- | :--- |
| `adsl-setup` | A configuration utility used to set up DSL service |
| `adsl-start` | A script used to start a DSL connection |
| `adsl-stop` | A script used to stop the DSL connection |
| `adsl-connect` | The command used in the connection script |
| `adsl-status` | A client that reports on the connection's status |
| `pppoe` | A client that works with the `pppd` daemon |

To get connected, you must have an active account, including a username and password. You will most likely need the DNS addresses from your DSL provider. Make sure all cables are connected properly. Setting up your connection is a snap once all the hardware is in place and your provider has properly set up your account.

Start the `adsl-setup` script (as root) from the command line of your console or an X terminal window, like this:

```
# adsl-setup
```
