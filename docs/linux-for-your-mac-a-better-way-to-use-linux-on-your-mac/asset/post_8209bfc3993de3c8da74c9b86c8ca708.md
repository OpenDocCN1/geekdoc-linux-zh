### What Is GNOME?

The GNOME Project grew out of a graphics software project for the GIMP (GNU Image Manipulation Program). GNOME is a set of software libraries that evolved from the need for a base set of drawing functions used to create an interface for the GIMP. These drawing functions, also known as APIs (Application Programming Interfaces), grew to form a construction set for an X desktop environment.

A desktop environment, such as GNOME and KDE (discussed in more detail in Chapter 10), includes a window manager, but also provides additional elements that enable support beyond traditional window management. These elements may include additional software libraries for standard client GUIs, server-client communications protocols to support drag-and-drop, object-linking and other data sharing, a set of matching clients, and traditional features such as graphic configuration tools and session management (also known as state-saving).

GNOME’s suite of clients and the GNOME office suite of applications comprise a complete GNOME installation. This can require 200MB or more, depending on the number of clients and window managers you have installed on your system. The current version of GNOME is 1.4, and typical GNOME installations for PowerPC Linux include nearly 200 GNOME clients.

Newer GNOME installations also include elements of the GNOME Office. This entails a suite of advanced applications that are described, according to GNOME developers, to accommodate the need for a full, free suite of office productivity applications. The GNOME Office suite of applications is listed in Table 11.1.

GNOME is a staple desktop for nearly all Red Hat Linux-based distributions, such as LinuxPPC 2000 Q4. The individual GNOME clients usually reside under the /usr/X11R6 directory, while configuration files, libraries, and other files are stored under the /etc/gnome and /usr/share/gnome directories. Under SoSF PPC Linux, these files reside under the /opt/gnome directory and are not part of the /etc:* directories. Individual settings are stored in a user’s home directory under a directory named .gnome, or various other directories with names starting with _gnome.

### Choosing a Window Manager for GNOME

Unlike KDE, GNOME is made up of software libraries and a set of clients that use the software libraries. It does not, however, include a window manager. This means that you are free to use any GNOME-aware window manager to run your desktop.

Some window managers that work well with GNOME include:

### Using the GNOME Desktop

Using a GNOME desktop environment for your X sessions is convenient and easy. Like KDE, the GNOME desktop includes several major elements:

- **Root display**. Also known as the *desktop*, this is the main work area and hosts floating windows, toolbars, and icons. You may generally have up to eight desktops available during your X sessions. The root display can be configured by using the GNOME control center, or through menu items accessed by pressing the right mouse button in a blank area of the display. Files may be copied, deleted, moved, and renamed by right clicking and dragging.
- **Taskbar**. This is a configurable menu most often found across the top of the display which hosts a Programs, Favorites, Settings and Desktop menu, along with the time (and date) and a drop-down Web browsing menu.
- **Panel**. This is a configurable window that hosts the Start menu, along with dockable applications (known as *applets*), a task area to navigate tasks running in the current desktop, icons (for launching clients), and a *pager*, used to navigate virtual desktops known as *workspaces*. Special icons, known as *drawers*, can be added to the panel in order to group icons by type or task. You can automatically or manually hide and unhide the panel by clicking a small arrow on either end. The panel's size and orientation (i.e., vertical or horizontal) can be changed by using its configuration dialog boxes.
- **Start menu**. This is a pop-up menu that hosts menu items for nearly every GNOME and X client installed on your system. The contents of this menu can be changed by using the GNOME menu editor. The menus are echoed by the taskbar's menus and by a pop-up menu accessed by pressing the middle mouse button in a blank area of the desktop.
- **Home directory**. Like KDE, GNOME includes a graphical home directory containing your files. The icons on the desktop are represented by files located in the directory named `.gnome-desktop` in your home directory.
