Give the printer entry a local name, and then specify the name of the remote host and the printer's name (the remote queue) on the remote host. You then need to select an appropriate printer filter for the remote printer entry that matches the remote printer. Save the definition. You can then print to the remote printer, like this:

```
# lpr -Premoteprintername mydocument.ps
```

# # Serial Ports and Modems

No newer Power Mac comes with a serial (RS-232 or RS-422) port, although every PowerBook and some desktops, such as the Apple G4 Cube, come with an internal modem. Most internal modems are supported. For more information about using serial ports, see Chapter 9, "Connecting to the Internet." This chapter contains additional details about detecting, configuring, and setting up a serial port or modem, and some possible workaround solutions for adding a serial port to your computer.

Fax services are provided by several utilities included with most Linux distributions. SuSE Linux includes a complex fax support system named HylaFax. However, you may want to explore the use of the efax software. Using this software is very easy. First, use your favorite text editor (as root) to edit the file named \texttt{fax} under the \texttt{/usr/bin} directory. Look for various entries, such as:

```
...

# Your fax number in international format, 20 characters maximum.
# Use only digits, spaces, and the "*" character.

FROM="+0 000 000 0000"

# Your name as it should appear on the page header.

NAME="from a Red Hat Linux system"
...
```

Change these entries to include your fax number and name. If you have properly configured your modem, you can then turn your Linux system into a fax machine waiting for faxes, like this:

```
# efax

efax: Sun May 13 16:18:27 2001 efax v 0.9 Copyright 1999 Ed Casas

efax: Sun May 13 16:18:27 2001 efax v 0.9 Copyright 1999 Ed Casas

efax: 18:27 compiled Aug 21 2000 01:25:22

efax: 18:30 opened /dev/modem

efax: 18:31 using V2.300-V90_2M_DLS CONEXANT AC/K56 in class 2
```
