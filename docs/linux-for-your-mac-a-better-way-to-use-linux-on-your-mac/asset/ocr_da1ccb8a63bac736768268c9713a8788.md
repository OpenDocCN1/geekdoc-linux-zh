Under LinuxPPC 2000 and other Red Hat-based systems, the superuser can use the graphical utilities such as the `ntsysv` (console-based) or `tksysv` (X11-based) commands to reconfigure services and runlevels. In turn, these commands use the `chkconfig` command to rebuild script dependencies.

For example, under LinuxPPC 2000, the `ntsysv` command may be started (by root) from the console command line or the command line of an X11 terminal like this:

```
# ntsysv
```

After you press Enter, you'll see a dialog box, as shown in Figure 15.1.

Use the Tab key to navigate to different buttons on the dialog box. Use the cursor keys to scroll through each service. Use the spacebar to toggle selection of a service. This command is an easy way to handle the chore of determining what services to run when Linux boots.

For more fine-tuned control, such as determining when a service starts or stops and at which runlevel, try the `tksysv` command, which requires an active X session. Start `tksysv` (as root) from the command line of an X11 terminal like this:

```
# tksysv
```
