# Chapter 10: Using the K Desktop Environment

This chapter introduces the K Desktop Environment, or simply KDE, one of the most popular desktops used with X11 and Linux. KDE has won a large following of users and developers from around the world, and is under active development. New versions are regularly released, and new KDE clients appear every day.

As you learn more about Linux and chat (online or with other users), you will discover that one commonly asked question (or troll) is: “What window manager do you use?” Minions of the Dark Side and spreaders of FUD (Fear, Uncertainty and Doubt) love to argue that the Linux user base has fragmented and split into two camps—those who use KDE and those who use GNOME.

This is of course, ridiculous. As you have learned so far, Linux is not a graphical interface. Linux users have a choice, and you can choose to use Linux with a GUI or without one. If you choose to use a GUI, you are free to customize your computer’s desktop. The technologies and advances made by GPL and open source programmers in GUI design have been so successful, that companies such as Sun Microsystems and Hewlett-Packard have adopted GUIs originally developed by and for Linux users.

After reading Chapter 7, “X11 and Window Managers,” you should know that there are many different X clients you can use to manage a graphical desktop. The K Desktop Environment, part of a project founded in October 1996, was released July 12, 1998, as version 1.0, following a long period as a beta product. Version 2.0 was released October 23, 2000, and development has continued at a rapid pace.

KDE generated quite a bit of excitement, because it provided the first free, open-source suite of X clients that offered a comprehensive desktop environment. The commercial Unix consortium attempted a similar effort, termed the CDE (Common Desktop Environment), but its commercial status did not appeal to the Linux market.

KDE is a desktop environment that includes more than 200 different clients, nearly 12,000 files, and requires nearly 150MB of hard drive space. Hundreds of additional clients, which are not part of the standard distribution, are available through various developer pages on the Web. The current base source code distribution eclipses that of the current PowerPC Linux kernel, and consists of 800,000 lines of C and C++ programming.

KDE is popular for a number of reasons, but perhaps some of the most enticing features are:

+   - **Network transparency for the desktop environment.** This means that listings of remote files in a browser or FTP window can be used as if representing local files. You can click on the name of a graphic image, and it will automatically be downloaded and displayed.
