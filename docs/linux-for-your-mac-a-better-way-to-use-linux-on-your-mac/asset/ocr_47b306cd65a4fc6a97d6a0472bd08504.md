# # Network Configuration

Creating a network interface (see Chapter 9, "Connecting to the Internet") is relatively easy using Linux and certainly won't involve a number of robots as with other commercial operating systems. Like Mac OS, once your internal hardware (such as the network interface) is recognized, you can set up your Power Mac to run Linux. This allows you to become a member of the LAN in a matter of 30 seconds.

If you have a computer with an internal Ethernet interface, check the diagnostic output provided by the Linux kernel during the boot process. Use the `dmesg` command to display this information, and look to see if your internal card has been recognized, like this:

```
$ dmesg | less
...
eth0: GMAC at 00:30:65:fd:df:a0, driver v1.3k2
3c59x.c © 1999/200 Donald Becker and others http://www.scyclad.com/network/vortex.html
...
```

In this example from an Apple TiBook running LinuxPPC 2000, the output of the `dmesg` command is *piped* through the `less` pager. This means that the output, a stream of text, is sent through the `less` command, which allows you to scroll (page) through text. Press the q key when finished.
