This chapter introduces the Linux shell. The concept of using a shell may seem foreign to some Mac users and even repugnant to die-hard GUI (*Graphical User Interface*) fans. The shell, however, is an integral part of Linux, and can be used with or without the Linux GUI known as the *X Window System*.

Understanding how to use the shell can save you time and effort while learning Linux. Although you can jump right into using Linux without using the shell, you will find that there are some tasks more easily accomplished at the command line, especially if a comparable GUI client does not exist for a task.

In fact, there are many experienced Linux users who have happily abandoned the resource overhead imposed by a GUI and conduct productive and efficient on- and off-line sessions using Linux in its text-only, or *console* mode. Although you do not have to become proficient in using the shell in order to use Linux productively, knowing how to use a shell can certainly help during troubleshooting and maintenance sessions. Working behind the GUI is a commonplace task when using Linux, especially if you want to make quick modifications to your system.

Finally, you should know that many GUI clients available during an *X* session incorporate command-line utilities and use the shell during file or other operations.

# Linux without a Shell?

It is possible to use Linux without a shell. You can do this by editing a user's */etc/passwd* entry on your system, and replacing the field denoting what shell to run upon login with the pathname to a particular program (this is also a good way to check what type of shell you are using by default). When the user logs in, the program will run, instead of a shell. For example, a typical *passwd* entry looks like:

```
bball:x:500:100:William Ball:/home/bball:/bin/bash
```

In this example, the *bash* shell is designated as the login shell. You can replace this with the pathname to another program, such as the *emacs* editor like this:

```
bball:x:500:100:William Ball:/home/bball:/usr/bin/emacs
```

Note that this approach will only work if Linux is set to boot to *console mode*, and not a graphical login.
