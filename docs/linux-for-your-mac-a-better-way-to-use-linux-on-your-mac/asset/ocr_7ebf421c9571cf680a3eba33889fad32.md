| **binary** | Download the desired file in binary form. |
| **exit** | Log off and quit the `ftp` command. |
| **get file** | Retrieve designated file. |
| **mget pattern** | Get one or more files with names that match the pattern. |
| **mput pattern** | Send one or more files with names that match the pattern. |
| **prompt** | Toggle `mget` or `mput` yes and no prompting. If the command is off, then matching files are retrieved or sent without intervention. |
| **put file** | Send designated file from your current directory. |

Other clients you can use for retrieving files using FTP include the `ncftp` command and the `wget` command. The `ncftp` client features a graphical indicator of the download progress, while `wget` has the ability to retrieve entire directory trees of HTML files or FTP directories—a very handy way to quickly mirror, or copy, one or more Web or FTP sites.

# # Graphical FTP Utilities

Combining the power of the `ftp` command with a graphical interface provides a great way to transfer files quickly and easily across computers on a LAN or over the Internet. This section introduces the `gftp` client, one of several graphical FTP clients you can use during your Linux, X, and Internet session to send or retrieve files.

Using `gftp` is easy. You can launch this command from the command line of an X terminal or menu item (if available) from your GNOME desktop panel menu. For example:

```
$ gftp &
```

After you press Enter, `gftp`'s main window will appear. You can then type in the name of a remote host, your username and password (or an anonymous name and e-mail address). When you press Enter, the client will appear as shown in Figure 9.26.

One of the great features of `gftp` is that it can be used to transfer entire directories of files. This is similar to using the `ftp` command's `mget` command; however, destination directories will be created automatically, and the task of transferring entire server sites can be reduced to a single mouse click!

The `gftp` client also features bookmarks. If you have favorite FTP sites for retrieving software, images, or other documents, then you can quickly navigate and log into the remote site using a menu item.
