Fill in the blank fields, then click the Add button. This is one way of creating a user account. Another way is to use the `useradd` (or `useradd`) commands. Under LinuxPPC 2000, the `adduser` command is a symbolic link to `useradd`. Under SuSE Linux, there is only the `useradd` command. Use this command (as root), followed by the name of a new user like this:

```
# useradd fsmith
```

This will create an entry for Fred Smith in the system's /etc/passwd file, along with a home directory named /home/fsmith. The /etc/passwd file contains a list of your system's users, along with various information in different colon-delimited fields. Next, assign a password using the passwd command, like this:

```
# passwd fsmith
Changing password for user fsmith
New UNIX password:
Retype new UNIX password:
passwd: all authentication tokens updated successfully
```

The entry for fsmith in /etc/passwd could look like this:

```
fsmith:x:502:100::/home/fsmith:/bin/bash
```
