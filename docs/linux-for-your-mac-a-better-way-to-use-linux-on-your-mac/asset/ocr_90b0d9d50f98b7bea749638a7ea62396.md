# pico or nano?

If you are a Debian PPC Linux user, do not despair if you are looking for an easy-to-use text editor. You can use the **nano** editor, which is a **pico** clone with additional features, such as a free license (GNU GPL), a goto-line command, case-sensitive searches, interactive search and replace, editable Tab columns, and commands to toggle features interactively. This program may be down-loaded in source or binary form from http://www.nano-editor.org, and works with all Linux PPC distributions.
