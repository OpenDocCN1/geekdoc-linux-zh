
## Time and Service Configuration

The installer asks for your time zone, and whether or not your computer's hard-ware clock is set to Greenwich Mean Time. Use your keyboard or mouse to make a choice and press Enter to continue. You are asked to select various software and network services to start when Linux boots. If you are not sure, just highlight the OK button and press Enter. You can always control these services later on.

## System Security and Accounts

You can also choose a method of system security. If you're not sure, just use the OK button to continue.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_49_0.png)

See Chapter 3, “Post-Installation Configuration,” for tips on setting up a printer. Chapter 6, “Using Text Editors,” has tips on how to print.

In the Account Creation section, you are asked to enter a password for the root user. This is extremely important. Enter the same password twice and do not forget it! You are then asked for approval of the default authentication mechanism. Highlight the OK button and press Enter. Now you can create additional users for your system. You should always create a username for yourself!

The installer offers to configure your sound system. Click OK to continue.

You can create a bootstrap partition or boot directly from Open Firmware. Older Power Macs may be able to use BootX, while newer Power Macs must use yaboot.

## X Configuration

The installer probes your hardware and reports on the video card. You may also be offered the chance to define your monitor settings for horizontal and vertical resolutions, along with color depth settings. Press Enter to continue, and the XFree86 server is installed. After installation, you will be informed that you can choose to use the startx command to launch an X session rather than booting YDL, or boot directly to a graphical session. If you are not sure about your settings, choose to boot to a text-based, not graphical, session.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_49_1.png)

See Chapter 7, “X11 and Window Managers,” for tips on configuring X for your system.

You have now installed Linux. Press Enter and reboot to Mac OS.

## Configuring BootX

The BootX control panel can be used to boot PPC Linux on older machines. This section details configuration of BootX to boot a YDL installation as an example. This approach will work on all Power Macs up to the early iBook. Using BootX does not require the use of an HFS Linux boot volume.

Copy the BootX Stuffit file to your Mac OS Desktop and double-click it. From the Install directory on your YDL CD-ROM, copy the file `vmlinix` into the folder named Linux Kernels inside the BootX 1.2 folder. Next, select BootX, the BootX extension, and the Linux Kernels folder and drag them to the Mac OS System Folder and release.

Go to the Apple menu and choose Control Panels, BootX. In the `/dev/` field, enter the partition number of your root Linux partition (such as `hda10`). If you wish to pass any kernel arguments (such as `adb_btnson=103,111` for the Apple iBook to set F11 and F12 at the middle and right mouse buttons) enter them in the More kernel arguments field. Make sure that the Kernel pop-up menu has your desired kernel listed. If you wish, check the No video box, and then click the Save to prefs button.

To boot Linux, click the Linux button. Each time you boot your computer, you are presented with the BootX dialog box to choose either Mac OS or Linux.

If you run into trouble following installation, first check Terra Soft’s Web site at http://www.yellowdoglinux.com for any bug fixes, errata, or security updates.

## Installing LinuxPPC 2000 Q4

Prepare your hard drive as described in the “Partitioning” section earlier in this chapter. Insert the LinuxPPC 2000 Q4 Install CD-ROM and reboot your computer with the c key held down. When the GNU/Linux splash screen appears, press the spacebar.

You see a screen with a dozen icons. This is a graphical boot menu you can use to choose different Linux kernels to boot, reboot, shut down, or go to Apple’s Open Firmware prompt.

> See Chapter 4, “All about Booting,” for more details about Open Firmware.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_50_0.png)

If you are not sure about the video capabilities of your computer, use the right and left arrow keys to highlight the Safe or Ultra-safe video install icons. This ensures that you are able to boot to the installer. After you select an icon, press Enter.

LinuxPPC 2000 Q4 boots and starts a graphical installer. When the screen clears, you see a dialog box with five buttons: Instructions, Language, Select Partitions, Choose Packages, and Reboot. Click the Select Partitions button to begin.

## Choosing Partitions

In the Mount Partitions and Setup Swap dialog box, click in the A/UX root partition’s Mount Point field and enter the root (``/``) partition. That is, click next to your root partition and type in a forward slash (``/``). Next, click the root partition’s Mount button, and then click the Done button.

A Choose Packages dialog box appears with a default selection of software packages already highlighted. Click each package category to select or unselect a category. If you click the small plus sign to the left of the category name, the list of software packages in that category appears. You can then click to select individual software packages.

As you select or unselect a software package, the disk requirement field at the bottom of the dialog box is updated. This is a handy way to customize the size of your installation according to desired software. When finished, click the Install button. The installer starts copying Linux to your hard drive. Go have a cup of coffee.

When the software has been installed, the screen clears, and a new dialog box asks if you want to reboot or choose additional options. Also, note that the dialog box displays the device for your root Linux partition (such as `/dev/hda10`). Don’t forget this information!

Click the Additional Options button. Another dialog box appears. Use this dialog box to set your root password, the system date and time, the time zone, network settings, and to perform other administrative tasks. The very least you should do is set the root password, time zone, and system date and time. Do not forget your root password! When finished, click the Quit button, and then click the Reboot button.

Reboot to Mac OS. To configure your boot loader, drag the copy of the System Folder from the LinuxPPC 2000 Q4 Install CD-ROM to your HFS boot partition. Next, drag a copy of an appropriate Linux kernel from the Install CD-ROM’s Linux Kernels folder to the System Folder on your HFS boot partition (most likely `vmlinux-2.2.18-4hpmac`).

Double-click the file `yaboot.conf` inside the System Folder on your HFS boot partition. Using the SimpleText editor, look for:

```
...
default = LinuxPPC Installer
...
```

Change this entry to:

```
...
default = Boot LinuxPPC -- Ultra safe video
...
```

Save your changes, and then quit the application. Go to the **Apple menu**, select **Control Panels**, **Startup Disk**. Click to select the boot partition in the **Startup Disk** dialog box, and then choose **Restart from the Special menu**.

The screen clears, the **LinuxPPC 2000 Q4** splash menu appears, and you reboot to Linux. If you want to reboot to Mac OS, press the spacebar. When the desktop icons appear, use the cursor keys to navigate to the **CD-ROM** icon (make sure there is no CD-ROM in your computer), and then press Enter. You reboot to Mac OS. After booting to Mac OS this way, you again have to use the **Startup Disk** control panel in order to reset your computer to boot to Linux.

## Installing SuSE PPC Linux

This section details an installation of SuSE PPC Linux 7.1. Insert Disk 1 from the **SuSE PPC CD-ROM** set, and then reboot your computer. Hold down the e key to boot from the CD-ROM. If you cannot boot from the CD-ROM, boot to Mac OS, open the **Blueboot** folder on the CD-ROM, and then double-click the **BootX** app. When **BootX** appears, click the **No Video** check box and click the **SuSE Linux** button to launch the installer.

Linux boots up on your computer while Tux the penguin dances. Be patient while the installer goes through initial hardware detection. When the screen clears, you are presented with a dialog box that asks you to choose a type of install using `yast` or `yast2`. Use the Tab key to navigate the cursor through the dialog boxes. Use the up and down arrow keys to scroll. Press Enter after highlighting a desired button or menu item.

Try the `yast2` graphical install. If the screen clears and the `yast2` dialog box appears, you can proceed. Your mouse may also be recognized and functional. If `yast2` fails, reboot and use `yast`. The rest of this install describes the graphical install.
