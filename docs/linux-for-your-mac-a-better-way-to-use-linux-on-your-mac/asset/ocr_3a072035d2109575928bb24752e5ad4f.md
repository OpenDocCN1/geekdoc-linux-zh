Newer graphics hardware in G4 Power Macs, such as the ATI Rage video chips, is supported by XFree86 4.0.1 and its xfree86 server. # Whoops! Am I Being Too Helpful?

One potential problem is that both LinuxPPC 2000 Q4 and SuSE Linux include automatic X configuration utilities that can be set up to generate a new configuration file every time Linux is booted. This is OK if that is what you want, but if the automatically generated configuration file does not work, and you have set Linux to boot directly to an X session, you will not be able to log in. Instead, the X server will repeatedly attempt to start, then fail, then attempt to start again in an endless loop. Your best resort is to reboot Linux in single user mode, or to a runlevel where X is not active, then disable automatic configuration, and attempt a proper configuration. With SuSE Linux, the potentially troublesome automatic X configuration is started through the /sbin/init.d/xsfb script (and can be controlled by editing /etc/rc.conf's `CREATE_FBCONF=""` setting), while under LinuxPPC 2000 Q4, the `xautoconf` service is used (and can be controlled by) the `ntsysv` command. These services can be helpful if you change video cards in your computer, but can cause trouble if your system requires a custom configuration.

There are a number of ways to configure X to work with your system. One method is through the auto probing of your graphics hardware. Another method is to use a console-based configuration program. Choosing an X configuration tool is generally a matter of personal preference or the choice of tools included with a distribution. Each tool aims to create a working XFree86 configuration file using the highest resolution (width and height of screen in pixels) and the greatest color depth (or number of colors available for the session). These values are generally expressed as 1600x1200 and 16bpp (*bit-planes per pixel*). Common resolutions are 1280x1024, 1152x768 (for the TiBook), 1024x768, 800x600, and 640x480. Common color depths are 8bpp (256 colors), 16bpp (thousands of colors), 24bpp (millions of colors), and possibly 32bpp (millions of colors).
