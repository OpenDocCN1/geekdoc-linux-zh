## KDE Desktop Elements

You will use different elements of your KDE desktop at different times. For example, when you first start using KDE, you will want to explore different menus. Navigate through the menu system to find out how applications are organized on the menus. You will also want to learn how to use the desktop to mimic shell command-line features, such as deleting files, creating new directories, and so on. What follows are short descriptions of the various desktop elements.

### KDE Panel

The KDE panel is a re-sizable, movable object that may be displayed or hidden with a single click of the pointer (located on the arrow at each end of the panel). The panel is an important part of conducting work while using KDE, and offers quick access to menus, lists of windows, your home directory, new terminals, help, configuration dialog boxes, and other applications. The panel also features navigation buttons you can use to jump to different virtual desktops (similar to legacy X window manager clients known as pager). Active clients will dock a window button in the panel, and you can hide or show windows by clicking on the client's panel button. You will also find some KDE clients, known as applets that are designed to work in the panel (such as the clock applet). Applications may be easily added to the panel for convenient launching.

### K Menu

The K menu (represented by the capital 'K' on the desktop panel) is the entry point to KDE's clients and other applications. You can use this menu to log out, lock the screen, get information about your system and KDE, get help, manage the panel, and launch applications. A KDE menu editor is available to help you customize the menu.

### Desktop Menu

The desktop menu is an optional menu that may be displayed across the top of the screen. This menu provides access to the same menus provided by the panel, and may be used to create new files, directories, icons, URLs, or client-launching icons. A new feature in KDE 2.0 and beyond is a Bookmarks menu. This menu is a copy of your Netscape Navigator bookmarks, and may be used to launch KDE's konqueror client, which allows you to quickly jump to a favorite Web site. The desktop menu also provides a Desktop, Windows, and Help menu, which are used to manage the root display, navigate windows and the desktop, and get help with KDE.

### The Konqueror Client

KDE's capable konqueror client may be used as a file manager. If you click the home icon on the desktop panel, konqueror will launch and display the contents of your home directory. However, konqueror is much more than a simple file- and icon-management client. You can use the Location field of konqueror's window to not only view your Linux file system, but the file systems of any locally mounted remote computer's hard drive or CD-ROM. You can also enter Web addresses in the Location field, as konqueror may be used as a Web browser (see Figure 10.2).

If you type in an FTP URL, such as `ftp://ftp.tux.org`, you can then use drag-and-drop to copy files or even entire directories of files using FTP! Finally, konqueror is also used to display help and manual pages for KDE and its clients, and will display the contents of any text file and the image of many different graphics files.

### Desktop Icons

KDE builds a set of desktop icons, partially based on your system's capabilities and previously installed hardware. For example, if KDE finds a CD-ROM with a configured mount point, you will see a CD-ROM drive icon on your root display. If you configure a printer, you may find an active printer icon, and documents may be dragged and released on the icon for printing. You will also find Web icons, representing handy URLs that will be displayed in a konqueror window if you have an active Internet connection.

### Using Basic Features

Most basic features of KDE can be explored using the left mouse button in 20 minutes. To practice, click on various menus, launch clients, resize windows, close windows, or read help. When using the pointer in the root display, however, you will find the middle and right mouse buttons indispensable.

As with other window managers, KDE uses the left mouse button to click, select, launch, drag, resize, or controls objects. Under KDE, when you click the right mouse button in a blank area of the desktop, you’ll see a short menu, as shown in Figure 10.3.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_252_0.png)

Figure 10.3 *The KDE desktop responds to middle and right mouse button clicks.*

This menu is used to create new desktop items, jump to a bookmark, get help, configure the background or desktop, manage windows and icons, and lock or unlock the screen. The middle mouse button, if clicked in the root display, is used as a navigation tool, enabling you to jump to different windows or desktops.

Files, represented by icons, may be dragged to and from the root display or desktop. You can delete files by dragging them to your desktop’s Trash. Trash may be emptied by right-clicking the can, and selecting the Empty trash bin menu item.

Desktop files may be renamed, deleted, or copied by right-clicking and selecting the appropriate menu. If you select the Delete menu item, the file is sent to the Trash. If you select the Shred menu item, the file is deleted automatically. If the file’s icon is a CD-ROM, hard drive, or floppy you can mount or unmount the device by using the mount menu item (or unmount if the device is mounted).

## Using the Desktop

Launch new programs by clicking on an icon on your desktop's panel or by clicking the panel's start menu to access other menu items that will launch the KDE client. You will most likely want to have an open terminal window for access to the shell (which you can use to run command-line programs or launch other X clients). If you do not want to use a terminal to launch other clients, press Alt+F2 to launch a mini-command-line dialog box, as shown in Figure 10.5.

Click the Run in terminal check box, then enter the name of a program, such as `pico` or `mc`. After you press Enter, the program will appear in a terminal window.

If you use X with a resolution of 800x600 or even 1024x768, you know that room for multiple windows and other screen real estate is at a premium! Getting the most out of your display can be an important issue. If you have a lot of open windows, your screen can quickly become cluttered. Try organizing your display or use KDE's window controls to send a client's window to a different virtual desktop. Using virtual desktops can help reduce cramped workspaces and organize your work.

Of course, there are several ways to organize your display. For example, you can double-click on a client's titlebar and its main window will roll up like a window shade, leaving a thin titlebar.
