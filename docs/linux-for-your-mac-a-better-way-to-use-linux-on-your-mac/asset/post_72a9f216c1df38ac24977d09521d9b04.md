
## Arcade

PPC Linux distributions include a variety of exciting and fun-filled arcade games that you will enjoy for hours at a time. This section introduces just some of these games. Nearly all these games can use your system’s sound card. In order to fully enjoy the gaming experience, make sure you have a properly configured sound card for your system. You will also see how to build 1xdoom, an Open Source version of DOOM!, which is the first-person shooter game by ID Software.

### XBoing II

Justin C. Kibel’s xboing client has a long and happy history with X, and has been available for Linux for several years. This arcade breakout-style game features wacky sounds and fast-paced, furious action. Do not forget to include the -sound option to turn on sound when you start the game from the command line, like this:

```bash
$ xboing -sound &
```

After you press Enter, press the spacebar to begin a game. The game appears as shown in Figure 18.8.

### Maelstrom from the Mac

Mac OS arcade fans are sure to remember Maelstrom, by Andrew Welch. This shareware arcade game was originally ported to X and retains its excellent animation, fast play, and great sounds. Start game play from the command line of a terminal window, like this:

```bash
$ Maelstrom &
```

You will see an initial splash window, then a control window. Press the p key to start the game. If you need help, press the a key, then press Enter to see the cast of animated goodies in the game, as shown in Figure 18.9.

### Building and Playing 1xdoom

The DOOM arcade game ushered in a new era of game play on personal computers. Although it was not the first 3D game, it definitely popularized the first-person shooter and alienated a generation of parents with its sounds and gory action.

You can now run and play the game in all its original glory while using Linux and X. For full play, you will need a commercial DOOM WAD (data) file, though you can use the original three-level shareware WAD file. Building and installing 1xdoom is a snap when using PPC Linux, and only takes a minute or so, providing you have the proper development tools and libraries installed on your system.

Download the `ixdoom` and music server sources, decompress them, and then build and install the software (as root). For example, you can install `ixdoom`, like this:

```bash
# tar xzf ixdoom-1.4.4.tar.gz
# cd ixdoom*
# ./configure ; make install
```

> If the `ixdoom` build barfs during the linking process, edit the file `ixdoom*/src/l_video_svgalib.c` and comment out the offending function calls. Then perform:
> `make clean` ; `make install`

![](img/1ea833f5a3e3c1547e3dd2891f52804a_468_0.png)

Next you must decompress, configure, build, and install the music server (as root), like this:

```bash
# tar xzf ixmuserv-0.94.2.tar.gz
# cd ixmus*
# ./configure ; make install
```

You should now copy your WAD file to `/usr/local/share/games/doom`. If you have a **DOOM II WAD**, such as `doom2.wad`, copy the file (as root) to this directory as `doom2.wad`. Finally, navigate to a command line, sit back, and launch into a game with a specific window size, like this:

```bash
$ /usr/local/games/ixdoom -height 600 -width 840 &
```

The game will start and display, as shown in Figure 18.10.

### Miscellaneous fun Clients

Just because X is the world's premiere graphical networking software does not mean that it is all business. You find several clients for X that do not fall into the categories of a game, but are fun to use. The first is the `xroach` client. This client unleashes an infestation of pixel-driven roaches upon your desktop. When the lights go in the night, these animated roaches scurry around your desktop, and then quickly hide under any windows or icons, imitating the live insects.

You may not want to use the `-display` option to send an infestation to a fellow worker's remote display, but you may want to try the `-squish` option for a little target practice with your pointer, like this:

```bash
$ xroach -squish -speed 1 &
```

After you press Enter, 10 roaches will roam around your desktop. Click on a roach, and you will understand the `-squish` option.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_469_0.png)

### Virtual Fish

While you can use various X clients to set the desktop color or place images in the root window, only the xfishtank client provides an animated desktop with swimming fish. Start the client from the command line of an X terminal window, like this:

```bash
$ xfishtank &
```

> Note that the xroach and xfishtank clients may only work with legacy X window managers such as fvwm2 or twm. For example, KDE maintains private versions of its desktops, and the clients will not work.

## Commercial Linux Games

As Linux becomes more popular, commercial game developers are seeing market opportunities that did not exist before. And because of the increasing portability of software, writing games for Linux makes it easy to port exiting games to new versions.

By their nature, commercial games are polished, professional products with sophisticated graphics, music, video, and sound. However, all share some common traits including large hard drive storage requirements for full installation, enormous CPU resources, and extra memory requirements. More than any other type of application, games tax a computer's resources to the limits. This is necessary to support detailed graphics and long sound clips in use during play.

### Myth II

Myth II: Soulblighter is a strategy simulation that combines role-playing, sound, and animation to provide lots of action. You are in charge of a band of soldiers, knights, dwarves, and other creatures, and are assigned missions as part of your tasks. A version of this game from Loki Entertainment is available for PPC Linux (and was included with *LinuxPPC 2000 Q4* for a time).

Insert and mount the game CD-ROM, and then start the install as root. After Myth II is installed, the software resides under the `/usr/local/games/myth2` directory. A full installation requires nearly 650MB of hard drive space. Start the game, like this:

```bash
$ /usr/local/bin/myth
```

After the introduction finishes, run through the game's tutorial mode to learn more about using the keyboard and mouse. When ready, play a new game by clicking the game button. Game play is as shown in Figure 18.11.

### Railroad Tycoon II

Railroad Tycoon II combines strategy simulation and adds a great deal of detail in its animation. As you wheel and deal your way to buy and build your railroad empire, you can watch trains run across the track you have laid and bridges you’ve built.

Although released only to work with Intel-based PCs running Linux, there are two patches you can download to enable the install and play of Railroad Tycoon II while using PPC Linux. Here are the basic steps needed to patch and install and play the game. First, download two PPC patches, like this:

```text
rt2-1.54b-ppc.run
rt2-dynamic-1.54b-ppc.run
```

You will find copies at: `ftp://boudicca.tux.org/misc/lokigames/patches/rt2/`

Next, insert mount the game CD, then run the first patch (as root), like this:

```bash
# sh rt2-1.54b-ppc.run
```

This will allow you to install RailroadTycoon onto your PowerPC hard drive, with a 200MB install typical. You can choose various types of installation, but more complex scenarios and campaigns are available if you insert and mount your Railroad Tycoon CD-ROM during game play.

During the install, the second patch should automatically be used. After the software is installed, you must run the game in a window (instead of the default full-screen), like this:

```bash
$ rt2 --windowed
```

Game play is as shown in Figure 18.12. The only thing you will miss by using the patch to make this game work is video (which is only used in the introduction or cutaway scenes).
