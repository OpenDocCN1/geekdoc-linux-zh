# Resources

+   http://www.keyspan.com/. One of the growing numbers of companies that deserve credit for being Linux-friendly and adding developers with information regarding its products, such as the Keyspan family of PDA USB-to-serial adapters.
+   http://www.linux-usb.org. The place to check for support for various USB devices. However, you should know that support is biased towards Linux on Intel-based hardware. Always research carefully before buying USB hardware with the aim of looking for support under PPC Linux.
+   http://axion.physics.ubc.ca/ppp-linux.html. A gentle introduction to using PPP and Linux.
+   http://www.geocities.com/SiliconValley/Pines/9247/. An index to nearly every known Netscape Easter egg.
+   http://www.ling.helsinki.fi/users/erikso/mail/procmail-debug.html. Tips and hints on using procmail to fight SPAM.
+   http://spam.abuse.net/. Where to learn more about SPAM.
+   http://www.cauce.org/. Home page for the Coalition Against Unsolicited Commercial E-mail, and a great place to learn about fighting SPAM.
+   http://www.kde.org. The place to start for the latest version of different KDE clients, such as kmail or knode.
+   http://kalamazoolinux.org/tech/ns-wheel.html. Links to various documents detailing how to enable a scroll mouse with different versions of Netscape Communicator.
+   http://www.gnome.org. Home page for the GNOME project. You will find links to many new Internet utilities through this site.
+   http://www.ietf.org/rfc/rfc0821.txt. The technical description of the Simple Mail Transfer Protocol.
+   http://www.tuxedo.org/~esr/fetchmail/. Home page for the fetchmail program—you can get tips and hints on troubleshooting through this site.
+   http://freenews.maxboud.net/. A site with a list of freely accessible Usenet news servers.
+   http://library.shastaollege.edu/email.htm. A site with links to free electronic mail services.
