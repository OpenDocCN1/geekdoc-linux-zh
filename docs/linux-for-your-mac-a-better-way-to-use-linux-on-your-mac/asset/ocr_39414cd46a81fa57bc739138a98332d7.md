You can verify the contents of an archive by using *zasc*'s option to list pathnames and files in an archive. For example, to decompress and see the contents of the new archive, use the tar command like this:

```
# tar txf home01.tgz
home/bball/Xdefaults
home/bball/Xresources
home/bball/.bashrc
home/bball/.dayplan
home/bball/.dayplan.priv
home/bball/.dviprc
home/bball/.emacs
home/bball @exrc@
home/bball/.ginitrc
home/bball/.grok
...
```

Note that not all the output is shown here, and that the leading directory path designator (.) is not present. This is important to remember when restoring files to their proper directories in your filesystem. Decompressing an archive is easy. Use the tar command, along with its *z* or *extract* option, and if extracting from a compressed archive, include the *z* option like this:

```
# tar xzvf home01.tgz
```

The *v* or verbose option will list the files being extracted, or else the action occurs silently.

By combining the power of the tzms command and the archive creation and compression features of *tar*, even novice system administrators can quickly build backup scripts to accomplish the hard work of performing backup operations. This task becomes even easier when you add automation, and perform these tasks unaided on a regularly scheduled basis. To learn how to do this, read the next section about using cronab for system administration.

# Scheduling with cronab

Every Linux distribution includes the exsm daemon, or some other software mechanism for performing regularly scheduled tasks. While the ar command helps users to perform specific tasks at a specified time, the *exsm* daemon is generally used for system-wide administrative tasks that need to be performed repeatedly.
