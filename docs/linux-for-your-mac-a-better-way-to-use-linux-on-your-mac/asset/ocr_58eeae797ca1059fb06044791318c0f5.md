# Ripping Audio CDs to .mp3

Using .mp3 audio provides a great way to store lots of music in a compressed format. For example, you can store 10 audio CDs’ worth of .mp3 files on a single CDR, enabling you to compress your music collection and archive your original music CDs. Many Linux users convert their entire audio CD collection into .mp3 format and store the collection on a local server.

You will need several easily available commands and clients in order to convert your audio CDs into .mp3 format. Once installed, the process of converting audio CDs into .mp3 format is automatic.

# Encoders and Decoders

Most of the work in converting analog audio to digital form is done by the cdparanoia client, known as a ripper, and a command such as lame, known as an encoder. You will need approximately 200MB or so of extra hard drive storage while ripping and encoding .mp3 files (i.e., a single audio track in .wav format can require more than 25MB). With multiple tracks residing on your hard drive awaiting the encoding process, you can see that storage requirements grow quickly.

The “LAME Ain’t an Mp3 Encoder,” or lame client is distributed in source code form. In order to use lame you must download, decompress, configure, build, and then install the client, like this:

```
$ tar xvf lame*gz
$ cd lame*
$ make
$ su -c "make install"
```

Note that you must have Linux development tools and libraries installed in order to build software packages. The last command line uses the su command to install
