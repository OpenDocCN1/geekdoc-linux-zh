Since the `yast` command was designed to create legacy type parallel-port printers, any newly created printer uses `/dev/lp*` device names, such as `/dev/lp0`. You can still use `yast` to create a printer definition for your USB printer, but afterwards, you need to edit the resulting `/etc/printcap` entries. Look for the following:

```
```
...
   :lp:/dev/lp0:\n...
```
```

To set the correct device, change this entry to look like this:

```
```
...
   :lp:/dev/usb/lp0:\n...
```
```

This ensures that printing works after configuring your printer using `yast`.

# ## Creating Remote Printers

Linux has many great networking features. If you use PPC Linux and have access to a LAN, you can set up remote printing services. This is relatively easy.

First, go to the remote computer with the attached printer. Make sure that the printer is attached, configured properly, and working. Next, sit down and edit the system's `/etc/hosts.1pd` file and insert the name or names of various hosts you would want to have access to the local printer. Also note the printer's name on the remote computer. Save the file, and then restart the `lpd` daemon on the computer like this:

```
# /etc/rc.d/init.d/lpd restart
```
