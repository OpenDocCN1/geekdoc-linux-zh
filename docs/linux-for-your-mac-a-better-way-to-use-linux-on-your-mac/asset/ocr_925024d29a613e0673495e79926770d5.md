Each application-specific file contains strings of text that may be used to alter a client's appearance. For example, in the file named `xcalc`, you will, in part, find:

```
...  
*Title: Calculator
*Cursor:		hand2
...
```

These two settings, in the form of `*resource name: resource_setting`, define the title used in the `xcalc` client's window and the type of pointer that appears when you use the client. If you change the resource setting, you will modify how that client appears. For example, you may change the `xcalc` settings to:

```
...
Xcalc.Title:  This Calculator belongs to Willie
Xcalc*Cursor: gumbly
...
```

The resource settings may then be stored in your home directory's `.Xdefaults` or `.Xresources` file to suit your system or personal preferences. You can also create your own `app-defaults` file, and then use the `XUSERFILESEARCHPATH` environment variable to point clients to your settings, like this:

```
$ export XUSERFILESEARCHPATH=$HOME/app-defaults/*
```

To find the settings that are recognized by your favorite client, see its manual page, documentation, or sample entry under the `app-defaults` directory.

# **My .Xdefaults Changes Are Not Recognized!**

You may have to merge the changes into your current X resource settings using the `xrdp` client. You can do this quickly and easily by using `xrd`'s `-merge` option, followed by the name of the resource file like this:

```
$ xrdp -merge .Xdefaults
```

After you press Enter, the affected client(s) should use your new settings. If not, make sure that your resource strings are correct. You can also use the `apres` or `editres` client to see and verify other client resource settings.
