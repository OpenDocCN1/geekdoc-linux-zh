# FVWM95

Robert Nation's f**wm95** window manager is based on f**vwm2**, but also includes a start menu and a task bar like GNOME and KDE. Like the earlier versions, you can build custom menus and change effects by editing a configuration file.

Under SuSE PPC Linux, this window manager's support files are located under the `/usr/X11R6/lib/X11/f**vwm95**` directory, along with its system-wide configuration file, *system.f**vwm95rc***. This file may be customized on a per-user basis if copied to the home directory with the name .f**vwm95rc*.

One customization, called *focus*, pertains to pointer movement and window placement. This shows when or how a window should be made active. It can have one of the following modes:

```
#Style *** ClickToFocus
Style *** MouseFocus
#Style *** SloppyFocus
```
