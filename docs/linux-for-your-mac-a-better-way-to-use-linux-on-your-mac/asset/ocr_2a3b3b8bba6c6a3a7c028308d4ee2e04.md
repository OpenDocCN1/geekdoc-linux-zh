### Table 5.2 Common Built-in Shell Commands

**Name** | **Description**
---|---
alias | Define abbreviated commands
bg | Send current program to background
cd | Change directory (for navigating)
cls | Clear the terminal screen
copy | Copy a file
date | Print the date
del | Delete a file
dir | Print a directory listing
echo | Echo a text or character string
exec | Execute command in new shell
export | Create new in-memory values or variables
exit | Exit the shell
fg | Bring background program to foreground
help | Show help
history | Scroll through or execute previous commands
jobs | Control or display background processes
kill | Terminate background programs or shells
logout | Exit the shell and terminal session
mkdir | Create a directory
pwd | Print the current working directory
ren | Rename a file or directory
rmdir | Remove a directory
set | Display or configure in-memory values or variables
time | Print the time
ulimit | Set specific resource values, such as core size
unalias | Delete an alias
unset | Delete or remove in-memory value or variable
