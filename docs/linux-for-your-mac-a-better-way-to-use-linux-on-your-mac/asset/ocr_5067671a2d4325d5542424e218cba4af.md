> SuSE PPC Linux provides a default _.emacs_ file, but defines a separate *GNU emacs* customization file that you should use instead. The name of the file is :_.gnu-emacs-custom_, and you should create and edit this file for your personal entries. If you use *xemacs*, the name of this file should be :_.xemacs-custom_. If you do not want to use this separate file for *GNU emacs*, delete the following two lines:

```
(setq custom-file "~/.gnu-emacs-custom")
(load "~/.gnu-emacs-custom" t t)
```

To delete the entry for xemacs, delete these following lines:

```
(cond
   ((string-match "XEmacs" emacs-version)
    (setq custom-file "~/.xemacs-custom")
    (load "~/.xemacs-custom" t t)))
```

You can then use the _.emacs_ file for your tweaks!
