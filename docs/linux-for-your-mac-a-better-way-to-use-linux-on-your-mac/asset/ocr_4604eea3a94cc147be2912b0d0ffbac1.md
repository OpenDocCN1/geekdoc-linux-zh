*Figure 14.9 The linuxconf client is a comprehensive tool you can use to manage your system.*

If you run `linuxconf` for the first time, you will see a large introductory dialog box. Press the *Quit* button, and its main dialog box will appear, as shown in Figure 14.9. The `linuxconf` dialog box splits tasks into configurations and controls. Configuration tasks include:

+   * **Networking.** Client tasks, such as hostname, nameserver, routing, and PPP configuration; server tasks such as NFS (*Network File System*), Apache, DNS (*Domain Name Server*), mail, Samba, and FTP; and miscellaneous tasks such as administrative network access.
+   * **User Accounts.** Normal users and groups; special accounts, such as PPP, SLIP, and POP; e-mail aliases; policies such as passwords expiration, shells, and the MOTD (*Message Of The Day*).
+   * **Filesystems.** Accessing mounted volumes; swap file management; and quotas.
+   * **Miscellaneous services.** Initial system services to use and modem management.
+   * **Boot mode.** Boot prompt management and shell assignment.

Control tasks available through the `linuxconf` dialog box include:

+   * **Control panel.** Change activation; reboot and shutdown; mounting and unmounting of filesystems; superserver schemas; configuration archiving.
+   * **Control files and systems.** Configure configuration; files; commands; file permissions; `linuxconf` modules and addons.
+   * **Logs.** Date, time, timezone control; `linuxconf` keyboard controls.
