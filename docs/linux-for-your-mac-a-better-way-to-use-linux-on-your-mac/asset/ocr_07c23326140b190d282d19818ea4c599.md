+   • http://www.yellowdoglinux.com. Yellow Dog Linux 2.0 is the current release of Linux for the PowerPC from Terra Soft Solutions, Inc. Earlier versions of this distribution of Linux closely resembled the Intel-based Red Hat Linux distribution, and features many familiar administrative and management tools, such as printtool, timedtool, rpm, netcfg, etc. If you are familiar with Red Hat Linux on Intel-based PCs, you will feel right at home after installing YDL. This distribution includes three CD-ROMs and printed documentation.

+   • http://www.suse.com/us/products/susesoft/ppc/index.html. SuSE Linux 7.1 PPC for PowerPC-based computers provides SuSE's brand of Linux, along with five CD-ROMS of software. This is in keeping with SuSE's tradition of providing a nearly complete snapshot of every available software package that has been ported to a particular platform. The Intel-based SuSE Linux distribution is also available on DVD-ROM (a PPC version should appear soon). SuSE Linux provides a unique Linux experience, with nearly all of the administrative functions under the control of YaST (yet-another-setup-tool). This distribution also includes a 480-page book covering technical details.

+   • http://www.debian.org/ports/powerpc/. The PowerPC port of Deiban GNO/Linux is one of a family of nearly one dozen different versions of Linux for different CPUs and computer platforms. Debian GNU/Linux is considered the "purest" Linux distribution, because the only software included with the distribution is distributed under the GNU GPL. This means you will not find shareware or crinnpled demo-ware versions of commercial software packages included with this distribution. You will only receive Linux and GPL software. This port of Linux was started in 1997, and closely resembles its Intel-based cousin, including software package management using .deb archives and the apt-get networking software installer. You can purchase a three CD-ROM set of CDs for the PowerPC from http://www.cheapybytes.com for a nominal fee; the Debian Linux maintainers do not sell CD-ROMs.

+   • http://www.rocklinux.org/. One of the newest ports of Linux for the PowerPC is Rock Linux, which provides a minimalist, but functional, Linux installation that uses a script-based installation rather than a network. You can find complete directions on how to install Rock Linux on your PowerPC box at: http://www.rocklinux.org/projects/doc/GUIDE/GUIDE.ext. The Rock Linux installer, a 1.5MB utility, is used to download the 300MB distribution, which consists of more than 200 software packages. Various CD-ROM sets are available for purchase (payment in Euros).
